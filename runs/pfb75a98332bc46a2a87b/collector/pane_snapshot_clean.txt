## Proof

**Answer: Yes, such a sequence exists.**

**Construction.** Define
$$g_n(x) = \max_{1 \le k \le n} |f_k(x)|.$$
Clearly $g_n \ge 0$, $g_n \ge |f_n|$, and $g_n$ is increasing (as a running maxi
mum over a growing set). It remains to show $\{\int_E g_n\}$ is bounded.

**Key observation.** Since $(f_n)$ is increasing, for every $k \le n$ we have $f
_1 \le f_k \le f_n$ pointwise. Hence each $f_k(x)$ lies in the interval $[f_1(x)
, f_n(x)]$, and the maximum of $|{\cdot}|$ over this interval is attained at an
endpoint:
$$g_n(x) = \max\bigl(|f_1(x)|,\; |f_n(x)|\bigr).$$

**Bounding $\int |f_n|$.** From $f_n \ge f_1$ we get $f_n^- = \max(-f_n,0) \le \
max(-f_1,0) = f_1^-$, so
$$\int_E f_n^- \le \int_E f_1^-.$$
Writing $f_n^+ = f_n + f_n^-$ and using $M := \sup_n \int_E f_n < \infty$ (the s
equence $\int f_n$ is increasing and bounded, so it converges to a finite suprem
um):
$$\int_E f_n^+ = \int_E f_n + \int_E f_n^- \le M + \int_E f_1^-.$$
Therefore
$$\int_E |f_n| = \int_E f_n^+ + \int_E f_n^- \le M + 2\int_E f_1^-.$$

**Bounding $\int g_n$.** Using $g_n = \max(|f_1|, |f_n|) \le |f_1| + |f_n|$:
$$\int_E g_n \le \int_E |f_1| + \int_E |f_n| \le \int_E |f_1| + M + 2\int_E f_1^
-.$$

The right-hand side is a finite constant independent of $n$ (here we use that $f
_1$ is integrable, which is guaranteed since each $\int_E f_n$ is a finite real
number by hypothesis). Thus $\{\int_E g_n\}$ is bounded.

**Conclusion.** The sequence $g_n = \max(|f_1|, |f_n|) = \max_{k\le n}|f_k|$ is
non-negative, increasing, dominates $|f_n|$, and has bounded integrals. $\blacks
quare$
