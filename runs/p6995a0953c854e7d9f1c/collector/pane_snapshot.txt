## Proof

We evaluate
$$L = \lim_{n\to\infty}\left\|e^{(A+B)/n} - e^{A/n}e^{B/n}\right\|$$
and show the quantity inside is $O(1/n^2)$, hence $o(1/n)$.

### Step 1. Matrix-exponential expansion

For any bounded operator $X$ and small parameter $t$,
$$e^{tX} = I + tX + \tfrac{t^2}{2}X^2 + R_X(t), \qquad \|R_X(t)\| \le C_X\,|t|^3
,$$
where $C_X$ depends only on $\|X\|$ (this follows from the norm-convergent power
 series; the remainder is bounded by $\sum_{k\ge 3}\|X\|^k|t|^k/k! \le (\|X\||t|
)^3 e^{\|X\||t|}/6$).

Apply this with $t = 1/n$ to $A$, $B$, and $A+B$:

$$e^{A/n} = I + \frac{A}{n} + \frac{A^2}{2n^2} + R_A, \qquad e^{B/n} = I + \frac
{B}{n} + \frac{B^2}{2n^2} + R_B,$$
$$e^{(A+B)/n} = I + \frac{A+B}{n} + \frac{(A+B)^2}{2n^2} + R_{A+B},$$
with $\|R_A\|,\|R_B\|,\|R_{A+B}\| = O(1/n^3)$.

### Step 2. Expand the product $e^{A/n}e^{B/n}$

$$e^{A/n}e^{B/n} = \left(I + \frac{A}{n} + \frac{A^2}{2n^2} + R_A\right)\left(I
+ \frac{B}{n} + \frac{B^2}{2n^2} + R_B\right).$$

Keeping terms through order $1/n^2$:
$$= I + \frac{A+B}{n} + \frac{A^2 + 2AB + B^2}{2n^2} + \widetilde{R},$$
where $\widetilde{R}$ collects all $O(1/n^3)$ contributions (cross terms of $R_A
$, $R_B$ with bounded operators, and the $A\cdot B^2/(2n^3)$, $A^2\cdot B/(2n^3)
$ terms, etc.). Concretely
$$\|\widetilde{R}\| \le \|R_A\|\,e^{\|B\|/n} + \|R_B\|\,e^{\|A\|/n} + \frac{\|A\
|\|B\|^2+\|A\|^2\|B\|}{2n^3} = O(1/n^3).$$

### Step 3. Take the difference

$$e^{(A+B)/n} - e^{A/n}e^{B/n} = \frac{(A+B)^2 - (A^2 + 2AB + B^2)}{2n^2} + (R_{
A+B} - \widetilde{R}).$$

Since $(A+B)^2 = A^2 + AB + BA + B^2$,
$$(A+B)^2 - (A^2 + 2AB + B^2) = BA - AB = -[A,B].$$

Therefore
$$e^{(A+B)/n} - e^{A/n}e^{B/n} = -\frac{[A,B]}{2n^2} + O(1/n^3).$$

### Step 4. Norm bound and the limit

Taking operator norms and using the triangle inequality,
$$\left\|e^{(A+B)/n} - e^{A/n}e^{B/n}\right\| \le \frac{\|[A,B]\|}{2n^2} + \frac
{C}{n^3}$$
for some constant $C$ depending only on $\|A\|,\|B\|$. Hence

$$\left\|e^{(A+B)/n} - e^{A/n}e^{B/n}\right\| = O(1/n^2).$$

Since $1/n^2 = o(1/n)$, the quantity is bounded above by a term that is $o(1/n)$
.

Finally,
$$L = \lim_{n\to\infty}\left\|e^{(A+B)/n} - e^{A/n}e^{B/n}\right\| = \lim_{n\to\
infty} O(1/n^2) = 0.$$

### Conclusion

$$\boxed{\lim_{n\to\infty}\left\|e^{(A+B)/n} - e^{A/n}e^{B/n}\right\| = 0, \qqua
d \left\|e^{(A+B)/n} - e^{A/n}e^{B/n}\right\| \le \frac{\|[A,B]\|}{2n^2} + O(1/n
^3) = o(1/n).}$$

The leading correction is governed by the commutator $[A,B]=AB-BA$, which vanish
es precisely when $A$ and $B$ commute — consistent with the fact that $e^{A+B}=e
^A e^B$ iff $[A,B]=0$.
