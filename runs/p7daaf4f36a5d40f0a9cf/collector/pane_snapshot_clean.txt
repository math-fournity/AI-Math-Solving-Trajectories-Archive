## (a) Euler-Lagrange Equations

The Lagrangian is $L(t,x,y,x',y') = (x')^2 + (y')^2 + 2xy$.

**For $x$:** $\dfrac{\partial L}{\partial x} = 2y$, $\dfrac{\partial L}{\partial
 x'} = 2x'$, so the Euler-Lagrange equation gives
$$2y - \frac{d}{dt}(2x') = 0 \implies \boxed{x'' = y.}$$

**For $y$:** $\dfrac{\partial L}{\partial y} = 2x$, $\dfrac{\partial L}{\partial
 y'} = 2y'$, so
$$2x - \frac{d}{dt}(2y') = 0 \implies \boxed{y'' = x.}$$

---

## (b) All Extremals

From the system $x'' = y$, $y'' = x$, differentiate the first equation twice:
$$x^{(4)} = y'' = x \implies x^{(4)} - x = 0.$$

The characteristic equation $r^4 - 1 = 0$ factors as $(r^2-1)(r^2+1)=0$, giving
roots $r = \pm 1, \pm i$. The general solution is
$$x(t) = A\cosh t + B\sinh t + C\cos t + D\sin t,$$
and since $y = x''$:
$$y(t) = A\cosh t + B\sinh t - C\cos t - D\sin t.$$

**Applying boundary conditions at $t=0$:**
$$x(0) = A + C = 0, \qquad y(0) = A - C = 0.$$
Adding and subtracting: $A = 0$, $C = 0$.

**Applying boundary conditions at $t = \pi/2$:**
$$x(\pi/2) = B\sinh(\pi/2) + D\sin(\pi/2) = B\sinh(\pi/2) + D = 1,$$
$$y(\pi/2) = B\sinh(\pi/2) - D\sin(\pi/2) = B\sinh(\pi/2) - D = 1.$$
Adding: $2B\sinh(\pi/2) = 2 \implies B = \dfrac{1}{\sinh(\pi/2)}$. Subtracting:
$2D = 0 \implies D = 0$.

The **unique extremal** is:
$$\boxed{x(t) = y(t) = \frac{\sinh t}{\sinh(\pi/2)}.}$$

---

## (c) Global Minimum

**Diagonalization.** Set $u = x + y$, $v = x - y$, so $x = \frac{u+v}{2}$, $y =
\frac{u-v}{2}$. Then
$$(x')^2 + (y')^2 = \tfrac{1}{2}[(u')^2 + (v')^2], \qquad 2xy = \tfrac{1}{2}(u^2
 - v^2),$$
so
$$J = \underbrace{\frac{1}{2}\int_0^{\pi/2}\!\bigl[(u')^2 + u^2\bigr]\,dt}_{J_1[
u]} + \underbrace{\frac{1}{2}\int_0^{\pi/2}\!\bigl[(v')^2 - v^2\bigr]\,dt}_{J_2[
v]}.$$

The boundary conditions decouple:
- $u(0) = 0$, $u(\pi/2) = 2$,
- $v(0) = 0$, $v(\pi/2) = 0$.

**$J_1$ is positive definite.** For any admissible $u$, write $u = u^* + w$ with
 $w(0)=w(\pi/2)=0$, where $u^*(t) = \frac{2\sinh t}{\sinh(\pi/2)}$ is the extrem
al (satisfying $u^{*''} = u^*$). Then
$$J_1[u] = J_1[u^*] + \underbrace{\int_0^{\pi/2}(u^{*'}w' + u^* w)\,dt}_{=\,0\te
xt{ (IBP + extremal eq.)}} + \frac{1}{2}\int_0^{\pi/2}\!\bigl[(w')^2 + w^2\bigr]
\,dt \geq J_1[u^*],$$
with equality iff $w \equiv 0$. So $u^*$ is the **unique global minimizer** of $
J_1$.

**$J_2$ is non-negative.** For $v$ with $v(0) = v(\pi/2) = 0$, the Poincaré ineq
uality on $[0, \pi/2]$ gives
$$\int_0^{\pi/2}(v')^2\,dt \geq \lambda_1 \int_0^{\pi/2} v^2\,dt,$$
where $\lambda_1 = (2)^2 = 4$ is the smallest eigenvalue of $-d^2/dt^2$ with Dir
ichlet boundary conditions (eigenfunction $\sin 2t$). Therefore
$$J_2[v] = \frac{1}{2}\!\left[\int (v')^2\,dt - \int v^2\,dt\right] \geq \frac{1
}{2}(4-1)\int v^2\,dt = \frac{3}{2}\int v^2\,dt \geq 0,$$
with equality iff $v \equiv 0$.

**Conclusion.** Since $J = J_1 + J_2 \geq J_1[u^*] + 0$, with equality iff $u =
u^*$ and $v = 0$ (i.e., $x = y = \frac{\sinh t}{\sinh(\pi/2)}$), the **global mi
nimum exists** and is attained at the unique extremal.

**Minimum value.** With $u^* = \frac{2\sinh t}{\sinh(\pi/2)}$:
$$J_1[u^*] = \frac{1}{2}\cdot\frac{4}{\sinh^2(\pi/2)}\int_0^{\pi/2}\!\cosh(2t)\,
dt = \frac{2}{\sinh^2(\pi/2)}\cdot\frac{\sinh\pi}{2} = \frac{\sinh\pi}{\sinh^2(\
pi/2)}.$$
Using $\sinh\pi = 2\sinh(\pi/2)\cosh(\pi/2)$:
$$\boxed{J_{\min} = \frac{2\cosh(\pi/2)}{\sinh(\pi/2)} = 2\coth(\pi/2).}$$

---

## (d) Global Maximum

We show $J$ is **unbounded above**, so no global maximum exists.

Keep $u = u^*$ (so $J_1 = J_1[u^*]$ is fixed) and choose $v_k(t) = \sin(2kt)$ fo
r $k = 1, 2, 3, \ldots$ These satisfy $v_k(0) = 0$ and $v_k(\pi/2) = \sin(k\pi)
= 0$, so all boundary conditions on $x, y$ are met. Then
$$J_2[v_k] = \frac{1}{2}\int_0^{\pi/2}\!\bigl[4k^2\cos^2(2kt) - \sin^2(2kt)\bigr
]\,dt = \frac{1}{2}\cdot\frac{\pi}{4}(4k^2 - 1) = \frac{\pi}{8}(4k^2 - 1).$$

As $k \to \infty$, $J_2[v_k] \to \infty$, hence
$$J = J_1[u^*] + J_2[v_k] \to \infty.$$

Therefore **no global maximum exists**: the functional is unbounded above.
