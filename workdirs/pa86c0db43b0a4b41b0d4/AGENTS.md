The logistics manager needs to recover the exact numerical value represented by these two missing digits. Specifically, you must calculate the value of the two-digit base-30 segment $(d_1 d_2)_{30}$, which is defined by the expression $30 d_1 + d_2$.

Find the value of $30 d_1 + d_2$.
