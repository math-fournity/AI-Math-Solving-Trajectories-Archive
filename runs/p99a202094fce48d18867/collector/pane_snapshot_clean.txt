## Proof that the statement is false

We construct a set $E \subseteq \mathbb{R}$ with $m^*(E) > 0$ that contains **no
** Borel subset of positive Lebesgue measure.

### Construction (Vitali set)

Define an equivalence relation on $[0,1]$ by
$$x \sim y \iff x - y \in \mathbb{Q}.$$
By the Axiom of Choice, select exactly one representative from each equivalence
class. Denote the resulting set by $V \subseteq [0,1]$.

### Claim 1: $m^*(V) > 0$.

The distinct rational translates $\{V + q : q \in \mathbb{Q}\}$ are pairwise dis
joint. Indeed, if $(V+q) \cap (V+r) \neq \emptyset$, then $v_1 + q = v_2 + r$ fo
r some $v_1, v_2 \in V$, giving $v_1 - v_2 = r - q \in \mathbb{Q}$, hence $v_1 \
sim v_2$. Since $V$ contains exactly one representative per class, $v_1 = v_2$,
so $q = r$.

Now consider the countable family $\{V + q : q \in \mathbb{Q} \cap [-1,1]\}$. Th
ese sets are pairwise disjoint, and
$$[0,1] \subseteq \bigcup_{q \in \mathbb{Q} \cap [-1,1]} (V+q) \subseteq [-1, 2]
.$$
The first inclusion holds because every $x \in [0,1]$ belongs to some equivalenc
e class whose representative $v \in V$ satisfies $x - v \in \mathbb{Q} \cap [-1,
1]$, so $x \in V + (x - v)$.

If $m^*(V) = 0$, then by countable subadditivity and translation-invariance of $
m^*$,
$$m^*\!\Big(\bigcup_{q \in \mathbb{Q}\cap[-1,1]}(V+q)\Big) \le \sum_{q \in \math
bb{Q}\cap[-1,1]} m^*(V+q) = \sum_{q} m^*(V) = 0.$$
But this union contains $[0,1]$, which has outer measure $1$. Contradiction. Hen
ce $m^*(V) > 0$.

### Claim 2: $V$ contains no Borel subset of positive measure.

We use **Steinhaus's theorem**: if $A \subseteq \mathbb{R}$ is Lebesgue measurab
le with $m(A) > 0$, then the difference set
$$A - A = \{a - a' : a, a' \in A\}$$
contains an open interval around $0$.

*Proof of Steinhaus.* Take a bounded piece $A' = A \cap [a,b]$ with $m(A') = d >
 0$. For $|h| < \varepsilon$, both $A'$ and $A'+h$ lie inside $[a-\varepsilon,\,
 b+\varepsilon]$, which has measure $(b-a)+2\varepsilon$. If $A' \cap (A'+h) = \
emptyset$, then
$$2d = m(A') + m(A'+h) = m\big(A' \cup (A'+h)\big) \le (b-a) + 2\varepsilon.$$
Choosing $\varepsilon < d - \tfrac{b-a}{2}$ (possible since $d \le b-a$ is not f
orced, but we may shrink $[a,b]$ so that $d$ is close to... ) — more cleanly: pi
ck $[a,b]$ so that $A' = A \cap [a,b]$ has $m(A') > 0$, and note $d \le b-a$. Ch
oose $\varepsilon$ small enough that $2d > (b-a) + 2\varepsilon$, i.e. $\varepsi
lon < d - \frac{b-a}{2}$. This requires $d > \frac{b-a}{2}$. To guarantee this,
use the density theorem: there is an interval $I$ with $m(A \cap I) > \frac{3}{4
} m(I)$; set $[a,b] = I$ and $A' = A \cap I$, so $d > \frac{3}{4}(b-a) > \frac{1
}{2}(b-a)$. Then for all $|h| < \varepsilon$, $A' \cap (A'+h) \neq \emptyset$, g
iving $h \in A' - A' \subseteq A - A$. ∎

Now suppose, for contradiction, that $B \subseteq V$ is Borel with $m(B) > 0$. S
ince $B$ is Borel it is Lebesgue measurable, so by Steinhaus, $B - B$ contains a
n open interval around $0$, and in particular contains some nonzero rational $q
\in \mathbb{Q} \setminus \{0\}$.

Then $q = b_1 - b_2$ for some $b_1, b_2 \in B \subseteq V$. Since $q \neq 0$, we
 have $b_1 \neq b_2$, yet $b_1 - b_2 = q \in \mathbb{Q}$, so $b_1 \sim b_2$. Thi
s means two **distinct** elements of $V$ lie in the same equivalence class — con
tradicting the definition of $V$ as containing exactly one representative per cl
ass.

Therefore no Borel subset $B \subseteq V$ can have $m(B) > 0$.

### Conclusion

Setting $E = V$, we have exhibited a set with $m^*(E) > 0$ that contains no Bore
l subset of positive measure. The statement is **false**.
