## Solution

**Observation.** The ODE has a structure that allows exact integration. Note tha
t

$$\frac{d}{dx}\big[(\sin x)\,y\big] = (\cos x)\,y + (\sin x)\,y'.$$

Therefore the original equation can be rewritten as

$$y'' + \frac{d}{dx}\big[(\sin x)\,y\big] = 0 \;=\; \frac{d}{dx}\Big[y' + (\sin
x)\,y\Big] = 0.$$

**First integration.** Integrating once,

$$y' + (\sin x)\,y = C_1.$$

Applying the initial conditions at $x=0$: $y'(0)+(\sin 0)\,y(0) = 1 + 0 = 1$, so
 $C_1 = 1$. The equation reduces to the first-order linear ODE

$$y' + (\sin x)\,y = 1.$$

**Integrating factor.** With $\mu(x) = e^{\int \sin x\,dx} = e^{-\cos x}$, multi
plying through gives

$$\frac{d}{dx}\Big[e^{-\cos x}\,y\Big] = e^{-\cos x}.$$

**Second integration.** Integrating from $0$ to $x$,

$$e^{-\cos x}\,y(x) - e^{-\cos 0}\,y(0) = \int_0^x e^{-\cos t}\,dt.$$

Since $y(0)=0$, the boundary term vanishes, leaving

$$e^{-\cos x}\,y(x) = \int_0^x e^{-\cos t}\,dt.$$

**Solution.**

$$\boxed{\,y(x) = e^{\cos x}\int_0^x e^{-\cos t}\,dt\,}$$

**Verification.**

- *Initial value:* $y(0) = e^{\cos 0}\int_0^0 e^{-\cos t}\,dt = e\cdot 0 = 0$. ✓
- *Initial derivative:* Differentiating,
$$y' = -(\sin x)\,e^{\cos x}\!\int_0^x e^{-\cos t}dt + e^{\cos x}\cdot e^{-\cos
x} = -(\sin x)\,y + 1,$$
so $y'(0) = -\sin 0\cdot 0 + 1 = 1$. ✓
- *ODE:* From $y' + (\sin x)\,y = 1$, differentiating yields $y'' + (\cos x)\,y
+ (\sin x)\,y' = 0$, i.e. $y'' + (\sin x)\,y' + (\cos x)\,y = 0$. ✓

All conditions are satisfied. The integral $\int_0^x e^{-\cos t}\,dt$ is not exp
ressible in elementary functions, so the solution is given in this closed integr
al form.
