# Problem

A specialized logistics grid is composed of a rectangular arrangement of docking stations. These stations are divided into two categories: "Primary Hubs" (Red) and "Secondary Hubs" (Green). The grid is networked with fiber-optic cables following specific security protocols:
- Pairs of Primary Hubs are linked by Red cables.
- Pairs of Secondary Hubs are linked by Green cables.
- Connections between a Primary Hub and a Secondary Hub are made via Black cables.

The grid is defined such that every hub is connected to every other hub by exactly one cable. Within this network, there are exactly 219 Red cables in total. Furthermore, the four hubs located at the extreme corners of the rectangular grid are all Primary Hubs; a census of the Red cables reveals that there are exactly 39 Red cables that do not connect to any of these four corner hubs.

If there are 237 Black cables currently active in the system, calculate the total number of Green cables.
