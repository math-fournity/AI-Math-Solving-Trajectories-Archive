## Setup

Since every Yᵢ entry is 0 or 1, and every position of X must appear in at least
one Yᵢ (to be determinable), all xⱼ ∈ {0,1}. So X is a binary string of length 9
.

**Counting ones.** Let k = number of 1s in X. Each Yᵢ has (k − ones deleted) one
s. The Yᵢ have 2,3,3,3,5,5,4 ones respectively. Since Y₅,Y₆ have 5 ones, k ≥ 5.
Since Y₁ has 2 ones and only 3 deletions, k ≤ 5. So **k = 5**: X has 5 ones and
4 zeros.

**Deletion structure.** Let the one-positions be o₁ < o₂ < o₃ < o₄ < o₅ and gaps
 g₀,...,g₅ (zeros before o₁, between consecutive ones, after o₅), with Σgᵢ = 4.

- **Y₁** (2 ones): deletes 3 ones, 0 zeros → keeps all 4 zeros + 2 ones. Subsequ
ence (0,0,0,1,0,1) means: 3 zeros, then one (α), then 1 zero, then one (β), then
 0 zeros after β.
- **Y₅** (5 ones): deletes 3 zeros → keeps all 5 ones + 1 zero (a₅). Subsequence
 (1,0,1,1,1,1) → a₅ is between o₁ and o₂, so **g₁ ≥ 1**.
- **Y₆** (5 ones): keeps all ones + 1 zero (a₆). Subsequence (1,1,1,1,0,1) → a₆
between o₄ and o₅, so **g₄ ≥ 1**.

From Y₁: "0 zeros after β" means gⱼ+...+g₅ = 0 where β = oⱼ. Since g₄ ≥ 1, we ne
ed j > 4, forcing **β = o₅** (and g₅ = 0). The "1 zero between α and β" gives gᵢ
+...+g₄ = 1, so g₄ = 1 and gᵢ = ... = g₃ = 0. Since g₁ ≥ 1 and gᵢ...g₃ = 0, we n
eed α ∈ {o₂, o₃, o₄}.
