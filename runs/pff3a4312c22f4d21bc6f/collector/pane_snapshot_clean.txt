**From NQ ∥ AB (horizontal):** Q has y-coordinate n sin α. Requiring Q on BC giv

## Concyclicity

The circle through A has equation x² + y² + Dx + Ey = 0.

- **M = (m,0):** m² + Dm = 0 → D = −m.
- **N = (n cos α, n sin α):** n² + Dn cos α + En sin α = 0 → E = (m cos α − n)/s
in α.

**Substituting P** = (m + s cos α, s sin α) with s = b(c−m)/c:

$$m^2 + 2ms\cos\alpha + s^2 - m^2 - sn = 0 \implies n = 2m\cos\alpha + s$$

$$\boxed{n = 2m\cos\alpha + \frac{b(c-m)}{c}} \quad \text{(I)}$$

**Substituting Q** = (c(1−n/b) + n cos α, n sin α):

$$(1-n/b)\big[c^2(1-n/b) + 2cn\cos\alpha - mc\big] = 0$$

Since Q ≠ C, the second factor vanishes:

$$\boxed{m = c\!\left(1-\frac{n}{b}\right) + 2n\cos\alpha} \quad \text{(II)}$$

## Solving the system

Let u = 2cos α − b/c, v = 2cos α − c/b. Then (I),(II) become n = b + mu, m = c +
 nv. Solving:

$$m = \frac{c+vb}{1-uv}, \quad n = \frac{b+cu}{1-uv}$$

Computing the numerators: c + vb = c + 2b cos α − c = 2b cos α, and b + cu = 2c
cos α.

Computing 1 − uv = 2cos α(c/b + b/c − 2cos α). Using the law of cosines a² = b²
+ c² − 2bc cos α, we get c/b + b/c = a²/(bc) + 2cos α, so:

$$1 - uv = \frac{2a^2\cos\alpha}{bc}, \quad m = \frac{b^2 c}{a^2}, \quad n = \fr
ac{bc^2}{a^2}$$

## Applying the ratio condition

$$t_P = \frac{c-m}{c} = \frac{a^2-b^2}{a^2}, \quad t_Q = \frac{n}{b} = \frac{c^2

$$\frac{a^2-b^2}{a^2-c^2} = \frac{c}{b} \implies b(a^2-b^2) = c(a^2-c^2)$$

$$a^2(b-c) = (b-c)(b^2+bc+c^2)$$

$$a^2 = b^2 + bc + c^2$$
