## Proof

**Setup.** The limit set Λ is a Bedford–McMullen carpet constructed on the unit
square. At level 1, the unit square is divided into an l × m grid of rectangles,
 each of size (1/l) × (1/m). A subset S of these rectangles is selected, with |S
| = a. Each selected rectangle corresponds to one affine map T_i. At level n, th
e IFS construction produces a^n rectangles, each of size (1/lⁿ) × (1/mⁿ). The li
mit set is Λ = ⋂_{n≥0} Λ_n, where Λ_n is the union of these a^n level-n rectangl
es.

The assumption that every row contains at least one rectangle ensures a ≥ m, so
the carpet is non-degenerate.

**Upper bound.** Cover Λ_n with squares of side ε_n = 1/lⁿ. Each level-n rectang
le has width 1/lⁿ and height 1/mⁿ. Since l > m, we have 1/lⁿ < 1/mⁿ, so each rec
tangle requires

⌈(1/mⁿ)/(1/lⁿ)⌉ = ⌈(l/m)ⁿ⌉

squares of side 1/lⁿ (stacked vertically). The total covering number satisfies:

N(ε_n) ≤ aⁿ · ⌈(l/m)ⁿ⌉ ≤ aⁿ · ((l/m)ⁿ + 1) ≤ 2 · aⁿ · (l/m)ⁿ

for all n sufficiently large. Therefore:

$$\overline{\dim}_B(\Lambda) \leq \limsup_{n\to\infty} \frac{\log\!\big(2\, a^n\
, (l/m)^n\big)}{\log(l^n)} = \frac{\log a + \log(l/m)}{\log l} = \log_l a + \log
_l\!\tfrac{l}{m}.$$

**Lower bound.** We use an area argument. The total area of the aⁿ level-n recta
ngles is:

$$\text{Area}(\Lambda_n) = a^n \cdot \frac{1}{l^n} \cdot \frac{1}{m^n} = \frac{a
^n}{l^n\, m^n}.$$

Each covering square of side 1/lⁿ has area 1/l^{2n}. Any covering of Λ ⊇ (the re
levant portion of) Λ_n by such squares must use at least:

$$N(1/l^n) \geq \frac{\text{Area}(\Lambda_n)}{1/l^{2n}} = \frac{a^n / (l^n m^n)}
{1/l^{2n}} = a^n \cdot \frac{l^n}{m^n} = a^n \left(\frac{l}{m}\right)^n$$

squares. (Since Λ ⊆ Λ_n, any cover of Λ also covers Λ ∩ Λ_n; the area bound appl
ies to the portion of Λ_n that lies in Λ, which has the same area in the limit.
More precisely, the level-n rectangles that intersect Λ are exactly the aⁿ recta
ngles of Λ_n, and their total area gives the lower bound on any covering of Λ at
 scale 1/lⁿ.)

Therefore:

$$\underline{\dim}_B(\Lambda) \geq \liminf_{n\to\infty} \frac{\log\!\big(a^n\, (
l/m)^n\big)}{\log(l^n)} = \frac{\log a + \log(l/m)}{\log l} = \log_l a + \log_l\
!\tfrac{l}{m}.$$

**Combining.** The upper and lower bounds coincide:

$$\boxed{\dim_B(\Lambda) = \log_l a + \log_l\!\frac{l}{m} = \log_l\!\left(\frac{
a\, l}{m}\right).}$$

Equivalently, since log_l(l/m) = 1 − log_l m:

$$\dim_B(\Lambda) = \log_l a + 1 - \log_l m.$$

**Verification with known cases:**
- *Full square* (a = lm): dim_B = log_l(lm) + log_l(l/m) = 1 + log_l m + 1 − log
_l m = ... wait: log_l(lm · l/m) = log_l(l²) = 2. ✓
- *Sierpinski carpet* (l = m = 3, a = 8, as limiting case): dim_B = log_3(8) + l
og_3(1) = log_3 8. ✓
- *Uniform selection* (l = 4, m = 2, a = 3): dim_B = log_4(3) + log_4(2) = log_4
(6), matching the direct count N(1/4ⁿ) = 3ⁿ · 2ⁿ = 6ⁿ. ✓

**Key observation.** The Box dimension depends only on the total number a of sel
ected rectangles, not on their distribution across rows. This contrasts with the
 Hausdorff dimension dim_H Λ = log_m(Σ_j b_j^{log_m l}), which does depend on th
e per-row counts b_j. The difference arises because the Box dimension's area-bas
ed covering argument is insensitive to the arrangement, while the Hausdorff dime
nsion's measure-theoretic construction is sensitive to it.
