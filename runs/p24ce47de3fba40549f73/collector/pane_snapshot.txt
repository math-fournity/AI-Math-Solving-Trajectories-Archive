nstraint requires: if distinct $a,b$ share a color and $a+b<13$, then $a+b$ has
that same color. Both color classes must be *sum-closed* (for distinct elements,
 sums $<13$).

By symmetry (swapping B↔G), I count colorings with $c(1)=\text{B}$ and double th

**Key cascade lemma.** If $c(1)=c(k)$ for any $k\in\{2,\dots,11\}$, then $c(1+k)
=c(1)$ (since $1+k<13$). Applying this repeatedly: if $c(1)=c(2)$, then $c(3)=c(
1)$, then $c(4)=c(1)$, ..., $c(12)=c(1)$. Everything becomes the same color.

**Case A: $c(2)=\text{B}$.** By the cascade lemma, $c(3)=c(4)=\cdots=c(12)=\text
{B}$. All crates in B; G is empty (trivially closed). **1 coloring.** ✓

**Case B: $c(2)=\text{G}$.** Now $c(1)=\text{B}$, $c(2)=\text{G}$. Branch on $c(
3)$.

**Case B1: $c(3)=\text{B}$.** Then $1+3=4$ forces $c(4)=\text{B}$; $1+4=5$ force
s $c(5)=\text{B}$; ...; $1+11=12$ forces $c(12)=\text{B}$. So $B=\{1,3,4,5,\dots
,12\}$, $G=\{2\}$.
- **G closed:** Only one element, no pairs. ✓
- **B closed:** Smallest sum of two distinct elements in B is $1+3=4$; all sums
in $\{4,\dots,12\}\subset B$. ✓

**1 coloring.**

**Case B2: $c(3)=\text{G}$.** Now $G$ contains $\{2,3\}$. The sum-closure of G i

- $2+3=5\Rightarrow c(5)=\text{G}$

- If $c(4)=\text{B}$: $1+4=5$ requires $c(5)=\text{B}$, but $c(5)=\text{G}$. **C

- **B closed:** Single element, no pairs. ✓
- **G closed:** Smallest sum of two distinct elements is $2+3=5$; all sums in $\

$<13$.) ✓
