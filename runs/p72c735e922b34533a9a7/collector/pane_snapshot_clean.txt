## Proof

The ordinal in question is the **Hartogs number** of $S$, denoted $h(S)$ (also c
alled the *Hartogs-Zahl*).

### Definition

For a partially ordered set $(S, \leq)$, the **Hartogs number** $h(S)$ is the sm
allest ordinal number that is not ordinally similar (order-isomorphic) to any we
ll-ordered subset of any chain in $S$.

### Existence in ZF (without the Axiom of Choice)

We prove $h(S)$ exists using only ZF axioms.

**Step 1: The collection of realized ordinals forms a set.**

Let $H = \{\alpha \in \mathrm{Ord} : \alpha \text{ is ordinally similar to some
well-ordered subset of some chain in } S\}$.

Every $\alpha \in H$ is ordinally similar to a well-ordered subset $A \subseteq
S$ (since every chain is a subset of $S$, and every subset of a chain is a subse
t of $S$). The ordinal similarity provides a bijection between $\alpha$ and $A$,
 so $|\alpha| = |A| \leq |S|$. Thus every ordinal in $H$ injects into $S$.

By **Hartogs' theorem** (1915, provable in ZF): the collection of all ordinals i
njectible into a fixed set $S$ is a set, not a proper class. (The proof uses Rep
lacement: the set of all well-orderings of subsets of $S$ exists by Power Set an
d Separation; mapping each well-ordering to its order type uses Replacement; the
 image is a set of ordinals.) Since $H$ is contained in this set, $H$ is itself
a set.

**Step 2: $H$ is an initial segment of the ordinals.**

$H$ is downward closed: if $\beta < \alpha$ and $\alpha \in H$, then $\alpha$ is
 ordinally similar to some well-ordered chain $C \subseteq S$ with order type $\
alpha$. The initial segment of $C$ of order type $\beta$ is a well-ordered subse
t of the same chain, so $\beta \in H$.

**Step 3: $h(S)$ exists.**

Since $H$ is a set of ordinals that is downward closed, $H$ is itself an ordinal
. The smallest ordinal not in $H$ is $H$ itself (viewed as an ordinal). We defin
e:

$$h(S) := H = \sup\{\alpha + 1 : \alpha \in H\}.$$

This is the smallest ordinal not ordinally similar to any well-ordered subset of
 any chain in $S$. Its existence is established **in ZF alone**, without the Axi
om of Choice. $\square$

### In ZFC (with the Axiom of Choice)

With AC, every set can be well-ordered (Zermelo's theorem). Therefore $|S|$ is a
 well-defined cardinal (initial ordinal), and:

$$h(S) = |S|^+,$$

the **successor cardinal** of $|S|$ — the smallest cardinal strictly greater tha
n $|S|$.

**Proof of the ZFC value:**

- **$h(S) \leq |S|^+$**: Every ordinal $\alpha < |S|^+$ satisfies $|\alpha| \leq
 |S|$, so $\alpha$ injects into $S$. By AC, we can well-order the image of this
injection, realizing $\alpha$ as the order type of a well-ordered subset of $S$
(equipped with a suitable well-order extending any given partial order via Szpil
rajn's order-extension theorem, which follows from AC). Thus $\alpha \in H$, so
$h(S) \geq |S|^+$...

  More precisely: in ZFC, every partial order on $S$ can be extended to a total
order (Szpilrajn), and $S$ can be well-ordered. For any ordinal $\alpha$ with $|
\alpha| \leq |S|$, there exists an injection $f: \alpha \hookrightarrow S$; the
image $f[\alpha] \subseteq S$ has cardinality $|\alpha|$, and by well-ordering $
f[\alpha]$ with order type $\alpha$ (using AC), we obtain a well-ordered subset
of $S$ ordinally similar to $\alpha$. Hence $\alpha \in H$.

- **$h(S) \geq |S|^+$**: The ordinal $|S|^+$ has cardinality $|S|^+ > |S|$, so i
t cannot inject into $S$. Therefore no subset of $S$ can be ordinally similar to
 $|S|^+$, giving $|S|^+ \notin H$, so $h(S) \leq |S|^+$.

Combining: $h(S) = |S|^+$. $\square$

### Summary

| Theory | Name | Value |
|--------|------|-------|
| **ZF** | Hartogs number $h(S)$ | Exists (Hartogs' theorem, 1915); well-defined
 without AC |
| **ZFC** | Hartogs number $h(S)$ | $= |S|^+$, the successor cardinal of $|S|$ |

The **Hartogs number** is the smallest ordinal not ordinally similar to any well
-ordered subset of any chain in $S$. Its existence is guaranteed in ZF by Hartog
s' theorem — a landmark result showing that one can produce well-ordered sets "b
eyond" any given set without invoking the Axiom of Choice. In ZFC, where every s
et is well-orderable, it specializes to the successor cardinal $|S|^+$.
