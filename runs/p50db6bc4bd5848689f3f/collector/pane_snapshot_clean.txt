## Proof of the Steinerberger Generalization (Part iii)

**Theorem.** Let $p$ be prime, $p \leq n$. Let $m = \lfloor \log_p n \rfloor$ so
 $p^m \leq n < p^{m+1}$, and let $k = \lfloor n/p^m \rfloor$ (the leading digit
of $n$ in base $p$, so $1 \leq k \leq p-1$). Then:
$$p \mid \gcd(a_n, L_n) \iff p \mid \operatorname{num}\!\left(\sum_{i=1}^{k} \fr
ac{1}{i}\right).$$

**Proof.** Since $p \leq n$, we have $p \mid L_n$, so $p \mid \gcd(a_n, L_n) \if
f p \mid a_n$.

**Step 1: $p$-adic valuation of $L_n$.** Since $p^m \leq n < p^{m+1}$, the highe
st power of $p$ not exceeding $n$ is $p^m$, so $v_p(L_n) = m$. Write $L_n = p^m
\cdot M$ with $\gcd(M, p) = 1$.

**Step 2: Reduce the sum modulo $p$.** We have $a_n = \sum_{j=1}^{n} L_n/j = \su
m_{j=1}^{n} p^m M / j$. For each $j$, since $\gcd(M,p)=1$:
$$v_p(p^m M / j) = m - v_p(j).$$

- If $v_p(j) \leq m-1$: then $v_p(p^m M/j) \geq 1$, so $p^m M/j \equiv 0 \pmod{p
}$.
- If $v_p(j) = m$: then $v_p(p^m M/j) = 0$, so $p^m M/j$ is a unit mod $p$.
- $v_p(j) > m$ is impossible since $j \leq n < p^{m+1}$ forces $v_p(j) \leq m$.

Therefore, modulo $p$, only terms with $v_p(j) = m$ survive:
$$a_n \equiv \sum_{\substack{1 \leq j \leq n \\ v_p(j) = m}} \frac{p^m M}{j} \pm
od{p}.$$

**Step 3: Identify the surviving terms.** The integers $j$ with $1 \leq j \leq n
$ and $v_p(j) = m$ are exactly $j = p^m \cdot t$ where $p \nmid t$ and $1 \leq t
 \leq \lfloor n/p^m \rfloor = k$. Since $n < p^{m+1}$, we have $t < p$, so autom
atically $p \nmid t$ for all $t \in \{1, \ldots, k\}$. Thus:
$$a_n \equiv \sum_{t=1}^{k} \frac{p^m M}{p^m \cdot t} = M \sum_{t=1}^{k} \frac{1
}{t} \pmod{p},$$
where $1/t$ denotes the multiplicative inverse of $t$ modulo $p$.

**Step 4: Conclude.** Since $\gcd(M, p) = 1$:
$$p \mid a_n \iff \sum_{t=1}^{k} t^{-1} \equiv 0 \pmod{p}.$$

Now consider $H_k = \sum_{t=1}^{k} 1/t$ as a rational number. Since $k \leq p-1$
, every denominator $t$ satisfies $\gcd(t, p) = 1$. Writing $H_k = A/B$ in lowes
t terms, we have $p \nmid B$, so:
$$p \mid A = \operatorname{num}(H_k) \iff H_k \equiv 0 \text{ in } \mathbb{Z}_p
\iff \sum_{t=1}^{k} t^{-1} \equiv 0 \pmod{p}.$$

Combining: $p \mid \gcd(a_n, L_n) \iff p \mid \operatorname{num}(H_k)$. $\blacks
quare$
