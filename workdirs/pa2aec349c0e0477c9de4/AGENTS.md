# Problem

In a specialized logistics center, a security protocol defines an integer $n$ as "efficient" if it satisfies a specific distribution requirement.

The requirement involves two different ways of storing a total quantity of cargo, denoted as $a$. 

1.  **Initial Storage Format**: The total quantity $a$ must be able to be expressed as the product of $n^2$ and the sum of the squares of $n$ individual integer weights $x_1, x_2, \ldots, x_n$.
2.  **Required Redistribution**: If $a$ can be stored in the initial format, it must also be possible to redistribute that exact same total quantity $a$ into a new sum of the squares of $n$ integer weights $y_1, y_2, \ldots, y_n$, such that none of these new weights $y_i$ are divisible by $n$.

An integer $n$ is considered "efficient" only if the redistribution is possible for every single value of $a$ generated by the initial storage format.

Let $G$ be the set of all "efficient" integers. Consider the reference set of candidates $S = \{1, 2, 3, 4, 5, 6\}$. 

Calculate the sum of all integers that are members of $S$ but are not members of $G$.
