## Proof

Place the circumcircle of $ABCD$ as the unit circle in the complex plane with $O
$ at the origin. Let $A=a, B=b, C=c, D=d$ with $|a|=|b|=|c|=|d|=1$, so $\bar{a}=
1/a$, etc.

**Line equations.** The line through two points $u,v$ on the unit circle has equ
ation $z + uv\,\bar{z} = u+v$. Thus:
- Line $AB$: $z + ab\,\bar{z} = a+b$
- Line $AD$: $z + ad\,\bar{z} = a+d$
- Line $CB$: $z + cb\,\bar{z} = c+b$
- Line $CD$: $z + cd\,\bar{z} = c+d$
- Line $AC$: $z + ac\,\bar{z} = a+c$

Since $I$ lies on line $AC$, we have the key relation:
$$i + ac\,\bar{i} = a + c. \tag{$\star$}$$

**Circle through $O, A, I$.** A circle through the origin has equation $z\bar{z}
 + \bar{\alpha}\,z + \alpha\,\bar{z} = 0$ for some complex $\alpha$. Passing thr
ough $A=a$ and $I=i$ gives:
$$\bar{\alpha}\,a + \alpha\,\bar{a} = -1, \qquad \bar{\alpha}\,i + \alpha\,\bar{
i} = -i\bar{i}. \tag{1}$$

**Finding $Q$ (on line $AB$).** Substituting $\bar{z} = (a+b-z)/(ab)$ from line
$AB$ into the circle equation and simplifying yields a quadratic in $z$ whose ro
ots are the intersection points. One root is $z=a$ (point $A$); the other is:
$$q = \frac{-\alpha(a+b)}{a}.$$
(The product of roots equals $-\alpha(a+b)$, and one root is $a$.)

**Finding $P$ (on line $AD$).** By identical computation with line $AD$:
$$p = \frac{-\alpha(a+d)}{a}.$$

**Circle through $O, C, I$.** Write its equation as $z\bar{z} + \bar{\alpha}'\,z
 + \alpha'\,\bar{z} = 0$ with:
$$\bar{\alpha}'\,c + \alpha'\,\bar{c} = -1, \qquad \bar{\alpha}'\,i + \alpha'\,\
bar{i} = -i\bar{i}. \tag{2}$$

**Finding $R$ and $S$.** Similarly:
$$r = \frac{-\alpha'(c+b)}{c}, \qquad s = \frac{-\alpha'(c+d)}{c}.$$

**Key claim:** $\alpha' = \frac{c}{a}\,\alpha$.

*Verification.* If $\alpha' = \frac{c}{a}\alpha$, then $\bar{\alpha}' = \frac{\b
ar{c}}{\bar{a}}\bar{\alpha} = \frac{a}{c}\bar{\alpha}$ (using $\bar{a}=1/a$, $\b
ar{c}=1/c$).

- **First equation of (2):** $\bar{\alpha}'\,c + \alpha'\,\bar{c} = \frac{a}{c}\
bar{\alpha}\cdot c + \frac{c}{a}\alpha\cdot\frac{1}{c} = a\bar{\alpha} + \frac{\
alpha}{a} = a\bar{\alpha} + \alpha\bar{a} = -1.$ ✓ (by the first equation of (1)
)

- **Second equation of (2):** We need $\frac{a}{c}\bar{\alpha}\,i + \frac{c}{a}\
alpha\,\bar{i} = -i\bar{i} = \bar{\alpha}\,i + \alpha\,\bar{i}$. Rearranging:
$$\bar{\alpha}\,i\!\left(\frac{a}{c}-1\right) + \alpha\,\bar{i}\!\left(\frac{c}{
a}-1\right) = (a-c)\!\left(\frac{\bar{\alpha}\,i}{c} - \frac{\alpha\,\bar{i}}{a}
\right) = 0.$$
Since $a \neq c$, we need $\frac{\bar{\alpha}}{\alpha} = \frac{c\,\bar{i}}{a\,i}
$.

**Establishing $\frac{\bar{\alpha}}{\alpha} = \frac{c\,\bar{i}}{a\,i}$.** From e
quations (1), solving for $\alpha$:
$$\alpha = \frac{a\,i\,(\bar{i}-\bar{a})}{\bar{a}\,i - a\,\bar{i}}, \qquad \bar{
\alpha} = \frac{-1 - \alpha\,\bar{a}}{a}.$$
A direct computation gives:
$$\frac{\bar{\alpha}}{\alpha} = \frac{\bar{i}(a - i)}{a^2\,i\,(\bar{i} - \bar{a}
)}.$$
Setting this equal to $\frac{c\,\bar{i}}{a\,i}$ and cancelling $\bar{i} \neq 0$
(note $i \neq 0$ since $O \notin AC$ while $I \in AC$):
$$\frac{a - i}{a^2(\bar{i}-\bar{a})} = \frac{c}{a} \iff a - i = ca(\bar{i} - \ba
r{a}) = ca\,\bar{i} - c \iff a + c = i + ac\,\bar{i},$$
which is exactly relation $(\star)$ — the fact that $I$ lies on line $AC$. ✓

**Conclusion.** With $\alpha' = \frac{c}{a}\alpha$ established:
$$p - q = \frac{-\alpha(a+d) + \alpha(a+b)}{a} = \frac{\alpha(b-d)}{a},$$
$$s - r = \frac{-\alpha'(c+d) + \alpha'(c+b)}{c} = \frac{\alpha'(b-d)}{c} = \fra
c{\frac{c}{a}\alpha\,(b-d)}{c} = \frac{\alpha(b-d)}{a}.$$
Therefore $p - q = s - r$, equivalently $p + r = q + s$.

This means the midpoint of $PR$ equals the midpoint of $QS$, so the diagonals of
 $PQRS$ bisect each other. Hence **$PQRS$ is a parallelogram**. $\blacksquare$
