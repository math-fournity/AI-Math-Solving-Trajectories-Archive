# Problem

In a remote digital library, a database contains a linear sequence of $N+2$ server nodes. At the start of a synchronization event, the two outermost nodes (the 1st and the $(N+2)$-th) are already activated, while the $N$ internal nodes remain inactive.

The system performs an automated update protocol through a series of discrete cycles. In each cycle, the central processor selects one of the currently inactive nodes uniformly at random. After selecting an inactive node, the processor then flips a fair coin to choose one of that node's two immediate neighbors. If the chosen neighbor is not yet activated, the processor activates it immediately.

This update protocol continues automatically, cycle after cycle, until a specific termination state is reached: the process stops only when every remaining inactive node is found to have activated neighbors on both its left and right sides.

Let $w(N)$ represent the expected number of nodes that remain inactive when the protocol terminates. Calculate the value of the following limit:
\[ \lim_{N \rightarrow \infty} \frac{w(N)}{N} \]
