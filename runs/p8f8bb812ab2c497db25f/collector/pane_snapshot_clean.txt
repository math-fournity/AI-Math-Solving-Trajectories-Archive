# Solution

**Answer: No.** The product need not be absolutely continuous. We give an explic
it counterexample.

## Counterexample

Let $f(x) = x$ and let $g(x) = c(x)$, the **Cantor–Lebesgue function** (Devil's
staircase).

**Verification of hypotheses:**
- $f(x)=x$ is absolutely continuous on $[0,1]$, and $f(0)=0$. ✓
- $c$ is continuous, monotone non-decreasing (hence of bounded variation), and $
c(0)=0$. ✓

Set $h(x) = f(x)\,g(x) = x\,c(x)$. We show $h$ is **not** absolutely continuous.

## Proof that $h$ is not AC

Suppose for contradiction that $h$ is absolutely continuous. Then the fundamenta
l theorem of calculus for AC functions gives:
$$h(1) - h(0) = \int_0^1 h'(t)\,dt. \tag{$\star$}$$

**Left-hand side.** $h(1)-h(0) = 1\cdot c(1) - 0\cdot c(0) = 1\cdot 1 - 0 = 1$.

**Right-hand side.** Since $f(x)=x$ is AC and $c$ is continuous, $h = x\,c$ is d
ifferentiable a.e. with
$$h'(x) = c(x) + x\,c'(x).$$
The Cantor function is constant on each removed middle-third interval and the Ca
ntor set has Lebesgue measure zero, so $c'(x)=0$ for a.e. $x\in[0,1]$. Hence $h'
(x) = c(x)$ a.e., and
$$\int_0^1 h'(t)\,dt = \int_0^1 c(t)\,dt.$$

**Computing $\int_0^1 c(t)\,dt$.** Using the self-similar structure of $c$:
- On $[0,\tfrac13]$: $c(x) = \tfrac12 c(3x)$, so $\displaystyle\int_0^{1/3} c =
\tfrac{1}{6}\int_0^1 c$.
- On $[\tfrac13,\tfrac23]$: $c(x) = \tfrac12$, so $\displaystyle\int_{1/3}^{2/3}
 c = \tfrac{1}{6}$.
- On $[\tfrac23,1]$: $c(x) = \tfrac12 + \tfrac12 c(3x-2)$, so $\displaystyle\int
_{2/3}^{1} c = \tfrac{1}{6} + \tfrac{1}{6}\int_0^1 c$.

Let $I = \int_0^1 c(t)\,dt$. Summing:
$$I = \frac{I}{6} + \frac{1}{6} + \frac{1}{6} + \frac{I}{6} = \frac{I}{3} + \fra
c{1}{3},$$
which gives $I = \tfrac12$.

Therefore $\int_0^1 h'(t)\,dt = \tfrac12$.

**Contradiction.** Equation $(\star)$ would require $1 = \tfrac12$, which is imp
ossible. Hence $h=fg$ is not absolutely continuous. $\square$

## Conceptual explanation (integration by parts)

The failure has a clean structural explanation. For $f$ AC and $g$ continuous BV
 with $f(0)=g(0)=0$, the Lebesgue–Stieltjes integration by parts formula gives:
$$f(x)\,g(x) = \int_0^x f\,dg + \int_0^x g(t)\,f'(t)\,dt.$$
If $g$ is **singular** (i.e., $g'=0$ a.e., as for the Cantor function), then $h'
 = f'g$ a.e., so AC-ness of $h=fg$ would require
$$h(x) = \int_0^x g(t)\,f'(t)\,dt \quad\text{for all }x,$$
i.e., $\int_0^x f\,dg = 0$ for all $x$. But $dg$ is the Cantor measure (singular
 w.r.t. Lebesgue measure), and $\int_0^1 f\,dg = \int_0^1 x\,dc(x) = \tfrac12 \n
eq 0$. This nonzero singular Stieltjes integral is exactly the obstruction: the
product $fg$ carries a singular component inherited from $g$, preventing absolut
e continuity.

In general, writing $g = g_{\mathrm{AC}} + g_{\mathrm{sing}}$ (Lebesgue decompos
ition of the BV function), we get $fg = f\,g_{\mathrm{AC}} + f\,g_{\mathrm{sing}
}$. The first term is AC (product of two AC functions), but the second term $f\,
g_{\mathrm{sing}}$ is AC only if $\int_0^x f\,dg_{\mathrm{sing}} = 0$ for all $x
$, which fails whenever $f$ is nonzero on a set of positive $dg_{\mathrm{sing}}$
-measure. The conditions $f(0)=0$, $g(0)=0$ do not remove this obstruction.
