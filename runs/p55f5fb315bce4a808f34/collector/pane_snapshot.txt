# 解答

**建立坐标系。** 设 $A = (0,0)$，$B = (c, 0)$，$C = (b\cos\alpha,\, b\sin\alpha)
$，其中 $\alpha = \angle A = 15°$，$b = CA$，$c = AB$。由余弦定理，$a = BC$ 满足
 $a^2 = b^2 + c^2 - 2bc\cos\alpha$。

**关键点坐标。** $M$ 为 $BC$ 中点，$BE = BM = CF = a/2$（$E$ 在射线 $BA$ 上，$F$
 在射线 $CA$ 上），故：

$$M = \tfrac{1}{2}(c + b\cos\alpha,\; b\sin\alpha),\quad E = (c - \tfrac{a}{2},\
; 0),\quad F = (b - \tfrac{a}{2})(\cos\alpha,\;\sin\alpha).$$

**利用正弦定理建立半径比。** 对 $\triangle AEF$，$\angle EAF = \alpha$，故 $R_2
= \dfrac{EF}{2\sin\alpha}$。对 $\triangle MEF$，$R_1 = \dfrac{EF}{2\sin\angle EM
F}$。因此

$$\frac{R_1^2}{R_2^2} = \frac{\sin^2\alpha}{\sin^2\angle EMF}.$$

**计算 $\angle EMF$（证明它与 $b,c$ 无关）。** 令 $\vec{ME} = E - M$，$\vec{MF}
= F - M$：

$$\vec{ME} = \tfrac{1}{2}(c - a - b\cos\alpha,\; -b\sin\alpha),\quad \vec{MF} =
\tfrac{1}{2}((b-a)\cos\alpha - c,\; (b-a)\sin\alpha).$$

叉积（$z$ 分量）：

$$\vec{ME}\times\vec{MF} = \frac{\sin\alpha}{4}\big[(c - a - b\cos\alpha)(b-a) +
 b((b-a)\cos\alpha - c)\big] = \frac{\sin\alpha}{4}\,a(a - b - c) = -\frac{a(b+c
-a)\sin\alpha}{4}.$$

点积（展开后利用 $b^2+c^2 = a^2 + 2bc\cos\alpha$ 化简）：

$$\vec{ME}\cdot\vec{MF} = \frac{a(1-\cos\alpha)(b+c-a)}{4}.$$

因此

$$\tan\angle EMF = \frac{|\vec{ME}\times\vec{MF}|}{\vec{ME}\cdot\vec{MF}} = \fra
c{\sin\alpha}{1 - \cos\alpha} = \frac{2\sin\frac{\alpha}{2}\cos\frac{\alpha}{2}}
{2\sin^2\frac{\alpha}{2}} = \cot\frac{\alpha}{2}.$$

故 $\angle EMF = \dfrac{\pi}{2} - \dfrac{\alpha}{2}$，$\sin\angle EMF = \cos\dfr
ac{\alpha}{2}$。

**代入得半径比。**

$$\frac{R_1}{R_2} = \frac{\sin\alpha}{\cos(\alpha/2)} = \frac{2\sin(\alpha/2)\co
s(\alpha/2)}{\cos(\alpha/2)} = 2\sin\frac{\alpha}{2}.$$

$$\frac{R_1^2}{R_2^2} = 4\sin^2\frac{\alpha}{2} = 2(1 - \cos\alpha).$$

**代入 $\alpha = 15°$。** $\cos 15° = \dfrac{\sqrt{6}+\sqrt{2}}{4}$，故

$$\frac{R_1^2}{R_2^2} = 2 - \frac{\sqrt{6}+\sqrt{2}}{2}.$$

注意到 $\left(\dfrac{\sqrt{6}+\sqrt{2}}{2}\right)^2 = \dfrac{8 + 4\sqrt{3}}{4} =
 2 + \sqrt{3}$，因此

$$\frac{R_1^2}{R_2^2} = 2 - \sqrt{2 + \sqrt{3}}.$$

**读出参数。** $a = 2,\; b = 2,\; c = 3$。

$$a^{b^c} = 2^{2^3} = 2^8 = 256.$$
