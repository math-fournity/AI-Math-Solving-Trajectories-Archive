## Proof

We show that the hypothesis forces $a = 0$.

**Key observation.** The set $\{b^*b : b \in A\}$ is exactly the set of positive
 elements of $A$.

- Every $b^*b$ is positive by definition.
- Conversely, if $p \geq 0$ is positive, then $p = (p^{1/2})^*\,p^{1/2}$ since $
p^{1/2}$ is self-adjoint, so $p$ is of the form $b^*b$ with $b = p^{1/2}$.

Hence the hypothesis
$$\forall b \in A,\quad a\,b^*b = 0$$
is equivalent to
$$(\dagger)\qquad a\,p = 0 \quad\text{for every positive } p \in A.$$

**Case 1: $A$ is unital.** The unit $1$ is positive since $1 = 1^*\!\cdot 1$. Ap
plying $(\dagger)$ with $p = 1$ gives $a\cdot 1 = a = 0$.

**Case 2: general $A$ (covers the non-unital case).** Every $C^*$-algebra admits
 a bounded approximate identity $\{e_\lambda\}_{\lambda\in\Lambda}$ consisting o
f positive elements with $0 \le e_\lambda \le 1$, satisfying
$$\lim_\lambda x\,e_\lambda = x \quad\text{and}\quad \lim_\lambda e_\lambda\,x =
 x \qquad \forall\, x \in A.$$
Each $e_\lambda$ is positive, so by $(\dagger)$ we have $a\,e_\lambda = 0$ for e
very $\lambda$. Taking the limit,
$$a = \lim_\lambda a\,e_\lambda = \lim_\lambda 0 = 0.$$

In both cases $a = 0$, so the implication holds. $\blacksquare$
