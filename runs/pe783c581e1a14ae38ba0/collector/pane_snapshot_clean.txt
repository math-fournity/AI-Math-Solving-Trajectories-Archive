# Proof

**Claim:** There exists a dense open subset of ℝ whose complement is uncountable
.

**Construction.** Let $C \subset [0,1]$ be the standard middle-thirds Cantor set
, obtained by repeatedly removing the open middle third from each remaining inte
rval. We take $U = \mathbb{R} \setminus C$.

**$U$ is open.** The Cantor set $C$ is closed (it is an intersection of the clos
ed sets $C_n$, each a finite union of closed intervals), so its complement $U =
\mathbb{R} \setminus C$ is open.

**$U$ is dense in $\mathbb{R}$.** A set is dense iff its complement has empty in
terior. The Cantor set $C$ contains no open interval: at stage $n$, every remain
ing interval has length $3^{-n} \to 0$, so no interval of positive length is con
tained in $C$. Hence $\operatorname{int}(C) = \varnothing$, which gives $\overli
ne{U} = \mathbb{R}$, i.e., $U$ is dense.

**The complement $\mathbb{R} \setminus U = C$ is uncountable.** The Cantor set i
s uncountable. One standard proof: the map $\varphi : \{0,1,2\}^{\mathbb{N}} \to
 C$ is not needed; instead use binary expansions. Every point of $C$ corresponds
 to a ternary expansion using only digits $0$ and $2$:
$$x = \sum_{n=1}^{\infty} \frac{2a_n}{3^n}, \qquad a_n \in \{0,1\}.$$
The map $(a_n)_{n\geq 1} \mapsto x$ sends $\{0,1\}^{\mathbb{N}}$ onto $C$. Since
 $\{0,1\}^{\mathbb{N}}$ is uncountable (it bijects with $\mathcal{P}(\mathbb{N})
$), and the map is surjective, $C$ is uncountable. (The map is in fact injective
 up to the countable set of ternary rationals, but surjectivity alone already fo
rces $C$ to be uncountable.)

**Conclusion.** $U = \mathbb{R} \setminus C$ is a dense open subset of $\mathbb{
R}$, and its complement $C$ is uncountable. Therefore such a set exists. $\black
square$
