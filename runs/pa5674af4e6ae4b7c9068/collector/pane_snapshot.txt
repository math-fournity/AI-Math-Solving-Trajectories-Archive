## Proof

We seek
$$\sup_{\|x\|=1,\; x\in H}\;\sup_{\substack{y\in S\\\|y\|\le 1}} |\langle x,y\ra
ngle|.$$

**Inner supremum (fix $x$).** For a fixed unit vector $x\in H$, consider the lin
ear functional $L_x:S\to\mathbb{C}$ (or $\mathbb{R}$) defined by $L_x(y)=\langle
 x,y\rangle$. By the Riesz representation theorem (applied within the Hilbert sp
ace $S$), there exists a unique vector $z_x\in S$ such that
$$\langle x,y\rangle = \langle z_x, y\rangle_S \quad\text{for all } y\in S.$$
In fact $z_x = P_S x$, the orthogonal projection of $x$ onto $S$, since for all
$y\in S$,
$$\langle x,y\rangle = \langle P_S x + (x-P_Sx), y\rangle = \langle P_S x, y\ran
gle + \langle x-P_Sx, y\rangle = \langle P_S x, y\rangle,$$
because $x - P_Sx \in S^\perp$.

The norm of this functional is $\|z_x\|=\|P_S x\|$, so
$$\sup_{\substack{y\in S\\\|y\|\le 1}} |\langle x,y\rangle| = \|P_S x\|.$$
The supremum is attained at $y = P_S x / \|P_S x\|$ (when $P_S x \neq 0$), confi
rming it is a maximum.

**Outer supremum (vary $x$).** Now we compute
$$\sup_{\|x\|=1} \|P_S x\|.$$
The operator $P_S:H\to S$ is an orthogonal projection, hence $\|P_S\|\le 1$ (sin
ce $P_S^2=P_S=P_S^*$ implies $\|P_S\|=\|P_S^2\|=\|P_S\|^2$, so $\|P_S\|\in\{0,1\
}$).

- If $S=\{0\}$, then $P_S=0$ and the supremum is $0$.
- If $S\neq\{0\}$, pick any unit vector $u\in S$. Then $P_S u = u$, so $\|P_S u\
|=1$, giving $\|P_S\|=1$.

**Conclusion.** Combining both steps,
$$\sup_{\|x\|=1,\;x\in H}\;\sup_{\substack{y\in S\\\|y\|\le 1}} |\langle x,y\ran
gle| = \|P_S\| = \begin{cases} 0 & \text{if } S=\{0\},\\ 1 & \text{if } S\neq\{0
\}. \end{cases}$$

Equivalently, the expression equals $\|P_S\|$, the operator norm of the orthogon
al projection onto $S$, which is $1$ for any nonzero closed subspace $S$.
