## Proof

**Claim.** The pairs $(n, k)$ satisfying the condition are exactly $(1, k)$ for
every positive integer $k$.

### Part 1: $(1, k)$ works for every positive integer $k$.

When $n = 1$, the exponents are $1^2, 2^2, 3^2, \ldots, (k+1)^2$, i.e., $1, 4, 9
, \ldots, (k+1)^2$. The representation becomes:
$$m = a_1^{1} + a_2^{4} + a_3^{9} + \cdots + a_{k+1}^{(k+1)^2} = a_1 + a_2^4 + \
cdots + a_{k+1}^{(k+1)^2}.$$

For **any** positive integer $m$ (odd or even), set $a_2 = a_3 = \cdots = a_{k+1
} = 0$ and $a_1 = m$. Then the right-hand side equals $m + 0 + \cdots + 0 = m$.
Since $m \geq 1$, we have $a_1 = m \geq 0$, which is a valid non-negative intege
r.

Thus every positive integer $m$ is representable (not just sufficiently large od
d ones), so the condition is satisfied trivially for every $k \geq 1$.

### Part 2: $n \geq 2$ is impossible for any $k$.

Suppose $n \geq 2$. The exponents are $e_i = (n + i - 1)^2$ for $i = 1, 2, \ldot
s, k+1$, and every exponent satisfies $e_i \geq n^2 \geq 4$.

**Counting argument.** Consider all tuples $(a_1, \ldots, a_{k+1})$ of non-negat
ive integers such that $a_i^{e_i} \leq M$ for each $i$. The number of choices fo

$$\prod_{i=1}^{k+1} 2\, M^{1/e_i} = 2^{k+1} \cdot M^{S}, \quad \text{where } S =
 \sum_{i=1}^{k+1} \frac{1}{e_i} = \sum_{j=n}^{n+k} \frac{1}{j^2}.$$

Each such tuple produces a value at most $(k+1)M$, so the number of representabl

**Bounding $S$.** Since $n \geq 2$:
$$S = \sum_{j=n}^{n+k} \frac{1}{j^2} \leq \sum_{j=2}^{\infty} \frac{1}{j^2} = \f
rac{\pi^2}{6} - 1 \approx 0.645 < 1.$$

**Conclusion of the counting argument.** Setting $M' = (k+1)M$, the number of re
presentable integers in $[0, M']$ is $O(M'^{S})$ (absorbing constants). Since $S
 < 1$, we have $O(M'^S) = o(M')$.

The number of odd integers in $[0, M']$ is $\lfloor (M'+1)/2 \rfloor \sim M'/2$,

xist infinitely many odd integers that are **not** representable. In particular,
 it is impossible for all sufficiently large odd integers to be representable.

### Conclusion

The condition is satisfied if and only if $n = 1$. For $n = 1$, every positive i
nteger $k$ works. For $n \geq 2$, no $k$ works.

The set of all pairs is $\boxed{(n, k) = (1, k) \text{ for all positive integers
