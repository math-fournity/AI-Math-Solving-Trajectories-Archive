## Proof

**Claim**: Yes. For every $\delta \in (0,\pi)$, there exists $C>0$ such that
$$\sup_{s\in[-\delta,\delta]}\left|\int_0^s D_N(t)\,dt\right|\le C \quad\text{fo
r all } N\in\mathbb{N}.$$

---

### Step 1: Reduction to $s\ge 0$

Since $D_N(-t)=D_N(t)$ (the Dirichlet kernel is even), the map $s\mapsto \int_0^
s D_N(t)\,dt$ is odd. Hence $\left|\int_0^{-s}D_N\right|=\left|\int_0^s D_N\righ
t|$, and it suffices to bound over $s\in[0,\delta]$.

### Step 2: Key decomposition

Fix $\delta\in(0,\pi)$. Write
$$\int_0^s D_N(t)\,dt = \int_0^s \frac{\sin\!\bigl((N+\tfrac12)t\bigr)}{\sin(t/2
)}\,dt = I_1(N,s)+I_2(N,s),$$
where
$$I_1(N,s)=\int_0^s g(t)\,\sin\!\bigl((N+\tfrac12)t\bigr)\,dt,\qquad I_2(N,s)=2\
int_0^s \frac{\sin\!\bigl((N+\tfrac12)t\bigr)}{t}\,dt,$$
and
$$g(t)=\frac{1}{\sin(t/2)}-\frac{2}{t},\quad t\in(0,\delta],\qquad g(0)=0.$$

**Regularity of $g$**: Since $\sin(t/2)=t/2 - t^3/48+O(t^5)$, we have $1/\sin(t/
2)=2/t+t/12+O(t^3)$, so $g(t)=t/12+O(t^3)$. Thus $g$ extends to a $C^1$ function
 on $[0,\delta]$ (in fact $C^\infty$). Set $K_g=\|g\|_{L^\infty[0,\delta]}+\delt
a\|g'\|_{L^\infty[0,\delta]}<\infty$.

### Step 3: Bounding $I_1$ via integration by parts

Since $g\in C^1([0,\delta])$ and $g(0)=0$, integration by parts gives (with $\al
pha=N+\tfrac12$):
$$I_1(N,s)=\left[-\frac{g(t)\cos(\alpha t)}{\alpha}\right]_0^s+\frac{1}{\alpha}\
int_0^s g'(t)\cos(\alpha t)\,dt
= -\frac{g(s)\cos(\alpha s)}{\alpha}+\frac{1}{\alpha}\int_0^s g'(t)\cos(\alpha t
)\,dt.$$

Therefore, for all $N\ge 1$ and $s\in[0,\delta]$:
$$|I_1(N,s)|\le \frac{\|g\|_\infty}{\alpha}+\frac{1}{\alpha}\int_0^s|g'(t)|\,dt
\le \frac{\|g\|_\infty+\delta\|g'\|_\infty}{\alpha}\le K_g.$$

### Step 4: Bounding $I_2$ via the sine integral

Substituting $u=\alpha t$ (with $\alpha=N+\frac12$):
$$I_2(N,s)=2\int_0^{\alpha s}\frac{\sin u}{u}\,du = 2\,\operatorname{Si}(\alpha
s),$$
where $\operatorname{Si}(x)=\int_0^x \frac{\sin u}{u}\,du$.

**Lemma**: $0\le \operatorname{Si}(x)\le \operatorname{Si}(\pi)$ for all $x\ge 0
$.

*Proof of Lemma*: $\operatorname{Si}'(x)=\sin(x)/x$, so $\operatorname{Si}$ has
critical points at $x=n\pi$. It increases on $(0,\pi)$, decreases on $(\pi,2\pi)
$, and so on. The local maxima are at $x=(2k+1)\pi$ and local minima at $x=2k\pi
$. Since $|\sin u|/u$ is decreasing in amplitude, each successive maximum is sma
ller and each minimum is larger (closer to $\pi/2$). The global maximum is $\ope
ratorname{Si}(\pi)\approx 1.852$. For the minima: $\operatorname{Si}(0)=0$, and
for $k\ge 1$,
$$\operatorname{Si}(2k\pi)=\operatorname{Si}(\pi)+\sum_{j=1}^{k}\int_{(2j-1)\pi}
^{2j\pi}\frac{\sin u}{u}\,du.$$
Each term $\int_{(2j-1)\pi}^{2j\pi}\sin(u)/u\,du$ is negative but satisfies $\le
ft|\int_{(2j-1)\pi}^{2j\pi}\sin(u)/u\,du\right|<\int_{(2j-2)\pi}^{(2j-1)\pi}\sin
(u)/u\,du$ (since $1/u$ is smaller on the later interval where $\sin<0$), so the
 partial sums remain positive. Hence $\operatorname{Si}(x)\ge 0$ for all $x\ge 0
$. $\square$

By the Lemma, $|I_2(N,s)|=2\,\operatorname{Si}(\alpha s)\le 2\,\operatorname{Si}
(\pi)$ for all $N$ and $s\ge 0$.

### Step 5: Combining the bounds

For $N\ge 1$ and $s\in[0,\delta]$:
$$\left|\int_0^s D_N(t)\,dt\right|\le |I_1|+|I_2|\le K_g + 2\,\operatorname{Si}(
\pi).$$

For $N=0$: $D_0(t)=1$, so $\int_0^s D_0(t)\,dt=s\le\delta$.

Setting
$$C=\max\!\Bigl(\delta,\; K_g+2\,\operatorname{Si}(\pi)\Bigr),$$
we obtain $\left|\int_0^s D_N(t)\,dt\right|\le C$ for all $N\in\mathbb{N}$ and $
s\in[0,\delta]$, and by odd symmetry also for $s\in[-\delta,0]$.

### Step 6: Sharpness remark

The bound is essentially tight: at $s_N=2\pi/(2N+1)$ (the first positive zero of
 $D_N$), one checks via the same substitution that
$$\int_0^{s_N}D_N(t)\,dt \;\longrightarrow\; 2\,\operatorname{Si}(\pi)\approx 3.
704 \quad\text{as }N\to\infty,$$
confirming that the supremum is finite and approached but never exceeded. $\blac
ksquare$
