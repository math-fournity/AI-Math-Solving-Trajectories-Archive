## Solution

Let
$$I(c) = \int_0^\infty \frac{dx}{(1+x^2)(1+x^c)}, \qquad c > 0.$$

**Convergence check.** Near $x=0$ the integrand is $\sim 1$, and as $x\to\infty$
 it is $\sim x^{-(2+c)}$, which is integrable since $c>0$. So $I(c)$ converges f
or all $c>0$.

**Key substitution: $x \mapsto 1/x$.** Set $u = 1/x$, so $x = 1/u$, $dx = -du/u^
2$. The limits swap ($0\leftrightarrow\infty$), and:

$$I(c) = \int_0^\infty \frac{du/u^2}{\left(1+\frac{1}{u^2}\right)\left(1+\frac{1
}{u^c}\right)}.$$

Rewriting the denominator:
$$1+\frac{1}{u^2} = \frac{u^2+1}{u^2}, \qquad 1+\frac{1}{u^c} = \frac{u^c+1}{u^c
}.$$

Therefore
$$I(c) = \int_0^\infty \frac{1}{u^2}\cdot\frac{u^2}{u^2+1}\cdot\frac{u^c}{u^c+1}
\,du = \int_0^\infty \frac{u^c}{(1+u^2)(1+u^c)}\,du.$$

Renaming the dummy variable back to $x$:
$$I(c) = \int_0^\infty \frac{x^c}{(1+x^2)(1+x^c)}\,dx.$$

**Adding the two forms.** Combining the original expression with the transformed
 one:

$$2I(c) = \int_0^\infty \frac{1+x^c}{(1+x^2)(1+x^c)}\,dx = \int_0^\infty \frac{1
}{1+x^2}\,dx = \frac{\pi}{2}.$$

Hence

$$\boxed{I(c) = \int_0^\infty \frac{dx}{(1+x^2)(1+x^c)} = \frac{\pi}{4}} \quad \
text{for all } c > 0.$$

The result is independent of $c$.
