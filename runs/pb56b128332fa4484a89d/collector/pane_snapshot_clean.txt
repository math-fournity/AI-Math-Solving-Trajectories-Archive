Center $O = \left(28,\, \tfrac{7\sqrt{3}}{3}\right)$, radius $R = \tfrac{49\sqrt

**Triangle $ABC$ is equilateral.** Compute:
$$AB^2 = \left(\tfrac{91}{2}\right)^2 + \left(\tfrac{21\sqrt{3}}{2}\right)^2 = 2

$$AC^2 = 7^2 + (28\sqrt{3})^2 = 2401 \Rightarrow AC = 49.$$
$$BC^2 = 56^2 + 35^2 - 2\cdot 56\cdot 35\cdot\cos 60^\circ = 2401 \Rightarrow BC

So $\triangle ABC$ is equilateral with side $49$, and each minor arc $\widehat{A
B}, \widehat{BC}, \widehat{CA}$ subtends $120^\circ$ at the center.

**Arc structure.** The cyclic order (counterclockwise) is $B, C, P, A$, so $P$ l

*Verification:* Let $\text{arc } CP = 2\alpha$ with $\sin\alpha = \tfrac{5\sqrt{

**Locate $D$.** The condition that $C$ does not lie on arc $\widehat{BDP}$ force

$$\sin\gamma = \frac{BD}{2R} = \frac{39}{98\sqrt{3}/3} = \frac{39\sqrt{3}}{98},

$$AD = 2R\sin(60^\circ - \gamma) = 2R\left(\sin 60^\circ\cos\gamma - \cos 60^\ci

$$= \frac{98\sqrt{3}}{3}\left(\frac{\sqrt{3}}{2}\cdot\frac{71}{98} - \frac{1}{2}

$$= \frac{98\sqrt{3}}{3}\cdot\frac{32\sqrt{3}}{196} = \frac{98\cdot 32\cdot 3}{3
