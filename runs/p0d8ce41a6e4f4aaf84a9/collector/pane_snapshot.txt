**Answer: Yes, the boundary is necessarily path-connected.**

**Proof.**

Let $C \subseteq \mathbb{R}^n$ ($n > 1$) be convex with $\partial C$ connected.
We show $\partial C$ is path-connected.

**Reduction to closed case.** For convex $C$, $\operatorname{int}(C) = \operator
name{int}(\overline{C})$, so $\partial C = \overline{C} \setminus \operatorname{
int}(C) = \overline{C} \setminus \operatorname{int}(\overline{C}) = \partial(\ov
erline{C})$. We may assume $C$ is closed.

**Case 1: $C$ has empty interior.** Then $\partial C = C \setminus \varnothing =
 C$, which is convex, hence path-connected. ✓

**Case 2: $C$ has nonempty interior.** We prove $\partial C$ is *locally path-co
nnected*. Then, since $\partial C$ is connected (given) and locally path-connect
ed, a standard theorem (connected + locally path-connected ⟹ path-connected) yie
lds the result.

*Local path-connectedness.* Let $x \in \partial C$. Since $C$ is convex with non
empty interior, $\overline{\operatorname{int}(C)} = \overline{C} = C$, so $x \in
 \overline{\operatorname{int}(C)}$: interior points of $C$ accumulate at $x$. Pi
ck $q \in \operatorname{int}(C)$ near $x$ and choose coordinates centered at $x$
 with $e_n$ pointing toward $q$, so $q = (0,\dots,0,\delta)$, $\delta > 0$.

Since $q \in \operatorname{int}(C)$, there is $r > 0$ with $B(q,r) \subset \oper
atorname{int}(C)$. For each $u \in \mathbb{R}^{n-1}$ with $\|u\| < r$, the verti
cal line through $(u,0)$ meets $\operatorname{int}(C)$ (at height $\delta$), so
$C \cap \{(u,t): t \in \mathbb{R}\}$ is a closed interval $[a(u), b(u)]$ with $a
(u) < \delta < b(u)$. The function $a$ is convex (lower envelope of a convex set
), hence continuous on $\{\|u\|<r\}$. We have $a(0) = 0$ since $x=(0,0)\in\parti
al C$ and $(0,t)\in\operatorname{int}(C)$ for $t\in(0,\delta]$.

For $\varepsilon < \delta/2$, any point $(u,t) \in \partial C \cap B(x,\varepsil
on)$ satisfies $|t| < \varepsilon < \delta/2 < \delta < b(u)$, so it lies on the
 *lower* boundary: $t = a(u)$. Conversely, $(u, a(u)) \in \partial C$ whenever $
\|u\|<r$. Thus:
$$\partial C \cap B(x,\varepsilon) = \{(u, a(u)) : u \in U_\varepsilon\}, \quad
U_\varepsilon := \{u : \|u\|<r,\ \|(u,a(u))\|<\varepsilon\}.$$
The set $U_\varepsilon$ is open (by continuity of $a$) and contains $0$. The pro
jection $(u,a(u)) \mapsto u$ is a homeomorphism from $\partial C \cap B(x,\varep
silon)$ onto $U_\varepsilon$. Since $U_\varepsilon$ is an open subset of $\mathb

\varepsilon)$.

ed and locally path-connected, $\partial C$ is path-connected. $\blacksquare$
