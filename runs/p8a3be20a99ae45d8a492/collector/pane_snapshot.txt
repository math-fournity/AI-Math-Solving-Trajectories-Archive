$$L = \mathbb{Q}(\alpha, \zeta).$$

every prime $q \mid n$ (and, when $4 \mid n$, $a \notin -4F^4$). For $n = p$ pri
me, the only condition is $a \notin F^p$. Here $F = \mathbb{Q}$ and $F^p = \math

$$x^p - a \text{ is irreducible over } \mathbb{Q}, \quad \text{hence } [\mathbb{
Q}(\alpha):\mathbb{Q}] = p.$$

$$p(p-1) \mid [L:\mathbb{Q}].$$
On the other hand, $L = \mathbb{Q}(\alpha,\zeta)$ is generated by an element of

$$[L:\mathbb{Q}] = p(p-1).$$

In particular $\zeta \notin \mathbb{Q}(\alpha)$ (otherwise $[L:\mathbb{Q}(\alpha

The domain has size $p(p-1)$, equal to the size of the codomain, so the map is a

$$\sigma_{i,j} \circ \sigma_{k,\ell} = \sigma_{\,i + jk,\; j\ell}.$$

$$(i, j)\cdot(k, \ell) = (i + jk,\; j\ell).$$
