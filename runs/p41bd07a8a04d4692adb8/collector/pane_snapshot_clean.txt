## Proof

**Claim.** The set of all WFFs is countably infinite, i.e., has cardinality $\al
eph_0$.

**Upper bound: the set of WFFs is at most countable.**

Consider the alphabet $\Sigma$ consisting of the symbols $P$, the digits $0,1,\d
ots,9$, the connective symbols $\neg$ and $\rightarrow$, and the parentheses $($
 and $)$. This is a finite alphabet.

Every WFF, by the inductive definition of the grammar, is a finite string over $
\Sigma$:
- Each atom $P_n$ is the finite string "$P$" followed by the decimal digits of $
n$.
- If $\phi, \psi$ are finite strings, then $(\phi \rightarrow \psi)$ and $\neg\p
hi$ are finite strings.

Hence the set of WFFs is a subset of $\Sigma^* = \bigcup_{k=0}^{\infty} \Sigma^k
$, the set of all finite strings over $\Sigma$.

Since $\Sigma$ is finite, each $\Sigma^k$ is finite, and a countable union of fi
nite sets is countable. Thus $\Sigma^*$ is countable. Any subset of a countable
set is at most countable, so the set of WFFs is at most countable.

**Lower bound: the set of WFFs is infinite.**

For every $n \in \mathbb{N}$, the atom $P_n$ is a WFF by the base case of the gr
ammar. The map $n \mapsto P_n$ is injective (distinct $n$ yield distinct strings
), so the set $\{P_n : n \in \mathbb{N}\}$ is an infinite subset of the WFFs. In
 fact this subset is countably infinite, so the set of WFFs is at least countabl
y infinite.

**Conclusion.**

The set of WFFs is at most countable (upper bound) and at least countably infini
te (lower bound). Therefore it is countably infinite:

$$|\{\text{WFFs}\}| = \aleph_0.$$
