## Proof

We consider the integral operator on L²([0,1]) with kernel

$$a(t,t') = t_<(1-t_>), \qquad t_< = \min(t,t'),\quad t_> = \max(t,t').$$

The eigenvalue problem is

$$\int_0^1 a(t,t')\,\varphi(t')\,dt' = \lambda\,\varphi(t), \qquad t\in[0,1]. \t
ag{1}$$

**Step 1. Identify the kernel as a Green's function.**

Recall that the Green's function of the Sturm–Liouville operator $L = -\tfrac{d^
2}{dt^2}$ on $[0,1]$ with Dirichlet boundary conditions $u(0)=u(1)=0$ is exactly
 $G(t,t') = t_<(1-t_>)$. Let us verify the defining properties:

- For $t < t'$: $G(t,t') = t(1-t')$, so $-G_{tt} = 0$, and $G(0,t') = 0$. ✓
- For $t > t'$: $G(t,t') = t'(1-t)$, so $-G_{tt} = 0$, and $G(1,t') = 0$. ✓
- Continuity at $t = t'$: both pieces give $t'(1-t')$. ✓
- Jump in the derivative: $\partial_t G|_{t'^-} = (1-t')$, $\partial_t G|_{t'^+}
 = -t'$, so the jump is $-t' - (1-t') = -1$, hence $-G_{tt} = \delta(t-t')$. ✓

Thus $a(t,t')$ is precisely the Green's function of $L = -d^2/dt^2$ with Dirichl
et boundary conditions.

**Step 2. Convert the integral equation to an ODE.**

Let $(A\varphi)(t) = \int_0^1 a(t,t')\varphi(t')\,dt'$. Applying $-d^2/dt^2$ to
both sides of (1) and using $-G_{tt} = \delta(t-t')$:

$$-\frac{d^2}{dt^2}(\lambda\varphi)(t) = \int_0^1 \delta(t-t')\varphi(t')\,dt' =
 \varphi(t),$$

so

$$-\varphi''(t) = \frac{1}{\lambda}\,\varphi(t). \tag{2}$$

The boundary conditions follow from the kernel: since $a(0,t') = a(1,t') = 0$, e
quation (1) gives $\varphi(0) = \varphi(1) = 0$.

**Step 3. Solve the eigenvalue problem for the ODE.**

Equation (2) with $\varphi(0)=\varphi(1)=0$ is the classical Dirichlet eigenvalu
e problem for $-d^2/dt^2$ on $[0,1]$. Its eigenvalues are

$$\mu_n = (n\pi)^2, \qquad n = 1, 2, 3, \dots$$

with eigenfunctions $\varphi_n(t) = \sin(n\pi t)$.

Since $\mu_n = 1/\lambda_n$, the eigenvalues of the integral operator are

$$\lambda_n = \frac{1}{\mu_n} = \frac{1}{(n\pi)^2}, \qquad n = 1, 2, 3, \dots$$

**Step 4. Compute $\lambda_2$.**

$$\lambda_2 = \frac{1}{(2\pi)^2} = \frac{1}{4\pi^2}.$$

Numerically, $\pi^2 \approx 9.8696$, so $4\pi^2 \approx 39.478$, giving

$$\boxed{\lambda_2 = \frac{1}{4\pi^2} \approx 0.02533}.$$
