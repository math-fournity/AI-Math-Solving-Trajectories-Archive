## Proof

**Setup.** Let $f: \mathbb{C}^n \to \mathbb{C}$ be holomorphic and define
$$f_a(z) = \sum_{i=1}^n a_i z_i + f(z).$$
The holomorphic Hessian of $f$ at $z$ is the symmetric bilinear form
$$H_f(z)(u,v) = \sum_{i,j=1}^n \frac{\partial^2 f}{\partial z_i \partial z_j}(z)
\, u_i v_j,$$
and a critical point $z_0$ of $f_a$ is **nondegenerate** if $\det\!\left(\frac{\
partial^2 f}{\partial z_i \partial z_j}(z_0)\right) \neq 0$.

**Key observation: the gradient map.** Define the holomorphic map
$$\nabla f : \mathbb{C}^n \to \mathbb{C}^n, \quad z \mapsto \left(\frac{\partial
 f}{\partial z_1}(z), \dots, \frac{\partial f}{\partial z_n}(z)\right).$$

The critical points of $f_a$ are exactly the solutions of $\frac{\partial f_a}{\
partial z_i} = 0$ for all $i$, i.e.,
$$\frac{\partial f}{\partial z_i}(z) = -a_i \quad \text{for all } i,$$
which is $\nabla f(z) = -a$. So the critical points of $f_a$ are precisely $\nab
la f^{-1}(-a)$.

**The Hessian of $f_a$ equals the Hessian of $f$.** Since the linear term $\sum
a_i z_i$ has vanishing second derivatives, we have $H_{f_a}(z) = H_f(z)$ for all
 $z$. Therefore a critical point $z_0$ of $f_a$ is nondegenerate if and only if
$\det H_f(z_0) \neq 0$.

**Connection to regular values.** The Jacobian matrix of the holomorphic map $\n
abla f$ is exactly the Hessian matrix $\left(\frac{\partial^2 f}{\partial z_i \p
artial z_j}\right)$. Viewing $\nabla f$ as a smooth map $\mathbb{R}^{2n} \to \ma
thbb{R}^{2n}$, its real Jacobian determinant at $z$ is $|\det H_f(z)|^2$ (a stan
dard fact for holomorphic maps). Thus the critical set of $\nabla f$ (as a smoot
h map) is:
$$\operatorname{Crit}(\nabla f) = \{z \in \mathbb{C}^n : \det H_f(z) = 0\}.$$

A point $z_0 \in \nabla f^{-1}(-a)$ is a regular point of $\nabla f$ if and only
 if $\det H_f(z_0) \neq 0$, which is exactly the nondegeneracy condition for $z_
0$ as a critical point of $f_a$. Therefore:

> $-a$ is a **regular value** of $\nabla f$ $\iff$ every critical point of $f_a$
 is **nondegenerate**.

**Applying Sard's theorem.** The map $\nabla f: \mathbb{R}^{2n} \to \mathbb{R}^{
2n}$ is smooth (in fact real-analytic). By **Sard's theorem**, the set of critic
al values of $\nabla f$,
$$\nabla f\!\left(\operatorname{Crit}(\nabla f)\right) = \nabla f\!\left(\{z : \
det H_f(z) = 0\}\right),$$
has Lebesgue measure zero in $\mathbb{R}^{2n} \cong \mathbb{C}^n$.

**Conclusion.** The set of "bad" parameters $a$ — those for which $f_a$ has a de
generate critical point — is exactly $\{-\nabla f(z) : \det H_f(z) = 0\}$, which
 is the negative of the set of critical values of $\nabla f$. By Sard's theorem,
 this set has measure zero. Therefore, for $a$ outside a set of measure zero (i.
e., for a **general** choice of $a$), the value $-a$ is a regular value of $\nab
la f$, and consequently **every critical point of $f_a$ is nondegenerate** (with
 respect to the holomorphic Hessian bilinear form).

**Remark on the degenerate case.** If $\det H_f \equiv 0$ everywhere (e.g., $f(z
