## Solution

We compute $f(n)$ for $n \ge 1000$ directly: $f(n) = n - 3$.

**Claim:** For all $n \le 999$, $f(n) = 998$ if $n$ is odd, and $f(n) = 997$ if
$n$ is even.

**Proof by strong induction** (downward, on $n$ from 999).

**Base cases.** Compute directly:
- $f(999) = f(f(1004)) = f(1001) = 998$. ✓ (999 odd)
- $f(998) = f(f(1003)) = f(1000) = 997$. ✓ (998 even)
- $f(997) = f(f(1002)) = f(999) = 998$. ✓ (997 odd)
- $f(996) = f(f(1001)) = f(998) = 997$. ✓ (996 even)
- $f(995) = f(f(1000)) = f(997) = 998$. ✓ (995 odd)
- $f(994) = f(f(999)) = f(998) = 997$. ✓ (994 even)

**Inductive step.** Assume the claim holds for all $k$ with $n < k \le 999$. We
show it for $n \le 993$.

Since $n \le 993$, we have $n + 5 \le 998 < 1000$, so $f(n+5)$ is governed by th
e recursive case (or the base cases already established).

**Case 1: $n$ is odd.** Then $n+5$ is even, so by the induction hypothesis $f(n+
5) = 997$. Then
$$f(n) = f(f(n+5)) = f(997) = 998,$$
since $997$ is odd. ✓

**Case 2: $n$ is even.** Then $n+5$ is odd, so by the induction hypothesis $f(n+
5) = 998$. Then
$$f(n) = f(f(n+5)) = f(998) = 997,$$
since $998$ is even. ✓

This completes the induction. $\square$

**Applying to $f(84)$:** Since $84$ is even and $84 \le 999$, we have
$$f(84) = 997.$$
