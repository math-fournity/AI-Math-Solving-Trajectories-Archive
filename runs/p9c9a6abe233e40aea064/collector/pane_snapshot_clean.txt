## Proof

We claim the Moore–Penrose pseudoinverse of the centering matrix is the matrix i
tself:

$$H_n^+ = H_n = I_n - \tfrac{1}{n}\,1_n 1_n^T.$$

**Step 1. $H_n$ is symmetric.**

$$H_n^T = \left(I_n - \tfrac{1}{n}1_n 1_n^T\right)^T = I_n^T - \tfrac{1}{n}(1_n
1_n^T)^T = I_n - \tfrac{1}{n}1_n 1_n^T = H_n.$$

**Step 2. $H_n$ is idempotent ($H_n^2 = H_n$).**

Using $1_n^T 1_n = n$,

$$H_n^2 = \left(I_n - \tfrac{1}{n}1_n 1_n^T\right)\left(I_n - \tfrac{1}{n}1_n 1_
n^T\right) = I_n - \tfrac{2}{n}1_n 1_n^T + \tfrac{1}{n^2}1_n(1_n^T 1_n)1_n^T$$
$$= I_n - \tfrac{2}{n}1_n 1_n^T + \tfrac{1}{n^2}\cdot n \cdot 1_n 1_n^T = I_n -
\tfrac{2}{n}1_n 1_n^T + \tfrac{1}{n}1_n 1_n^T = I_n - \tfrac{1}{n}1_n 1_n^T = H_
n.$$

**Step 3. A symmetric idempotent matrix equals its Moore–Penrose pseudoinverse.*
*

Let $A$ be symmetric ($A^T = A$) and idempotent ($A^2 = A$). We verify the four
defining conditions of the Moore–Penrose pseudoinverse with $A^+ := A$:

1. $AA^+A = A\cdot A\cdot A = A^2\cdot A = A\cdot A = A^2 = A$. ✓
2. $A^+AA^+ = A\cdot A\cdot A = A^2\cdot A = A\cdot A = A^2 = A = A^+$. ✓
3. $(AA^+)^T = (A^2)^T = (A^2) = A = A^T = A = AA^+$, using symmetry and idempot
ence. ✓
4. $(A^+A)^T = (A^2)^T = A^2 = A = AA^+ = A^+A$, by the same reasoning. ✓

All four conditions hold, so $A^+ = A$.

**Step 4. Conclusion.**

Since $H_n$ is symmetric (Step 1) and idempotent (Step 2), by Step 3,

$$\boxed{H_n^+ = H_n = I_n - \tfrac{1}{n}\,1_n 1_n^T.}$$

**Geometric remark.** $H_n$ is the orthogonal projector onto $\operatorname{span
}(1_n)^\perp$, the subspace of vectors whose entries sum to zero. An orthogonal
projector is always its own pseudoinverse, since on its range it acts as the ide
ntity and on its nullspace ($\operatorname{span}(1_n)$) it acts as zero — exactl
y the behavior of the pseudoinverse.
