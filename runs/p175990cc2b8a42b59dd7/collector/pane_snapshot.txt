## Proof

**Key characterization.** An ordinal α > 0 is a limit ordinal if and only if α =
 ω·β for some ordinal β ≥ 1.

*Proof of characterization.* In Cantor normal form, α = ω^{n₁}·a₁ + ⋯ + ω^{nₖ}·a
ₖ with n₁ > ⋯ > nₖ ≥ 0 and aᵢ ≥ 1. Then α is a successor ordinal iff nₖ = 0 (the
 last term is a positive integer), and α is a limit ordinal iff nₖ ≥ 1. When nₖ
≥ 1, every exponent is ≥ 1, so we factor out ω:
$$α = ω\cdot\bigl(ω^{n_1-1}\cdot a_1 + \cdots + ω^{n_k-1}\cdot a_k\bigr) = ω\cdo
t β,\quad β \geq 1.$$
Conversely, if α = ω·β with β ≥ 1, writing β in CNF as ω^{m₁}·b₁ + ⋯ + ω^{mⱼ}·bⱼ
 gives ω·β = ω^{m₁+1}·b₁ + ⋯ + ω^{mⱼ+1}·bⱼ, whose every exponent is ≥ 1, so α is
 a limit ordinal. ∎

**Determining the range of β.** The set of limit ordinals in ω^ω is
$$L = \{ω\cdot β : 1 \leq β \text{ and } ω\cdot β < ω^{\omega}\}.$$

We compute the threshold. Using ordinal arithmetic:
$$ω \cdot ω^{\omega} = ω^{1}\cdot ω^{\omega} = ω^{1+\omega} = ω^{\omega},$$
since 1 + ω = ω. The map β ↦ ω·β is strictly increasing (left multiplication by
a nonzero ordinal is strictly monotone), so:
$$ω\cdot β < ω\cdot ω^{\omega} = ω^{\omega} \iff β < ω^{\omega}.$$

Therefore
$$L = \{ω\cdot β : 1 \leq β < ω^{\omega}\}.$$

**Order-isomorphism.** The map
$$\varphi : [1, ω^{\omega}) \to L, \qquad \varphi(β) = ω\cdot β$$
is strictly increasing (hence injective) and surjective by the computation above
, so it is an order-isomorphism.

**Order type of the domain.** The interval [0, ω^ω) has order type ω^ω. Since [0
, ω^ω) = {0} ⊔ [1, ω^ω) as an ordered sum, if τ denotes the order type of [1, ω^
ω), then 1 + τ = ω^ω. Because ω^ω is a limit ordinal, for any τ < ω^ω we have 1
+ τ ≤ τ + 1 < ω^ω (as a limit has no greatest element), contradicting 1 + τ = ω^
ω. Hence τ = ω^ω.

**Conclusion.** The set L of all limit ordinals in ω^ω is order-isomorphic to [1
, ω^ω), which has order type **ω^ω**.

$$\boxed{\omega^{\omega}}$$
