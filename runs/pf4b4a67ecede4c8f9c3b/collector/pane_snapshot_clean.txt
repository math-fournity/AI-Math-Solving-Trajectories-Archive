# Graph of the Base-13 Function is Connected

**Problem.** Let $f:\mathbb{R}\to\mathbb{R}$ be the (Conway) base-13 function, w
hich takes every real value on every open interval (and is consequently disconti
nuous everywhere). Let $G=\{(x,f(x)):x\in\mathbb{R}\}\subset\mathbb{R}^2$ be its
 graph. We show $G$ is connected.

---

## Step 1. The graph $G$ is dense in $\mathbb{R}^2$.

Let $U=I\times J\subset\mathbb{R}^2$ be any nonempty open rectangle ($I,J$ open
intervals). Pick any $y\in J$. By the defining property of $f$, there exists $x\
in I$ with $f(x)=y$. Then $(x,f(x))=(x,y)\in G\cap U$. Since $G$ meets every non
empty open set, $G$ is dense in $\mathbb{R}^2$.

## Step 2. $G$ is connected.

Suppose for contradiction that $G=A\sqcup B$ is a **separation**: $A,B$ nonempty
, disjoint, and both open (equivalently both closed) in the subspace topology of
 $G$.

**Closure interaction with $G$.** Since $A$ is closed in $G$, write $A=G\cap F_A
$ for some closed $F_A\subset\mathbb{R}^2$. Then $\overline{A}\subset F_A$, so
$$\overline{A}\cap G \;\subset\; F_A\cap G = A \;\subset\; \overline{A}\cap G,$$
hence $\overline{A}\cap G=A$. Likewise $\overline{B}\cap G=B$.

**The closures must overlap.** Since $G$ is dense in $\mathbb{R}^2$:
$$\mathbb{R}^2 = \overline{G} = \overline{A\cup B} = \overline{A}\cup\overline{B
}.$$
If $\overline{A}\cap\overline{B}=\varnothing$, then $\mathbb{R}^2=\overline{A}\s
qcup\overline{B}$ would be a disconnection of $\mathbb{R}^2$ into two nonempty c
losed sets, contradicting the connectedness of $\mathbb{R}^2$. Therefore there e
xists
$$p=(x_0,y_0)\in\overline{A}\cap\overline{B}.$$

**Deriving the contradiction.** The point $(x_0,f(x_0))$ lies in $G$, hence in $
A$ or in $B$.

*Case 1:* $(x_0,f(x_0))\in A$. Since $A$ is open in $G$, there is an open rectan
gle $R=I\times J$ containing $(x_0,f(x_0))$ with $G\cap R\subset A$; equivalentl
y, $(x,f(x))\in A$ for all $x\in I$.

Since $p\in\overline{B}$, there is a sequence $(u_n,f(u_n))\in B$ with $(u_n,f(u
_n))\to p$, so $u_n\to x_0$. As $I$ is an open interval containing $x_0$, for al
l large $n$ we have $u_n\in I$, forcing $(u_n,f(u_n))\in G\cap R\subset A$. But
$(u_n,f(u_n))\in B$—contradicting $A\cap B=\varnothing$.

*Case 2:* $(x_0,f(x_0))\in B$. By the symmetric argument (using a sequence from
$A$ converging to $p$, which exists since $p\in\overline{A}$), we again obtain a
 point in $A\cap B=\varnothing$.

Both cases are impossible, so no separation $G=A\sqcup B$ exists.

## Conclusion

The graph of the base-13 function is **connected**. $\blacksquare$

**Remark.** The proof uses only that $G$ is dense in $\mathbb{R}^2$, which follo
ws from the stronger property that $f$ attains every real value on every interva
l. The argument applies to any function $f:\mathbb{R}\to\mathbb{R}$ whose graph
is dense in the plane: such a graph is always connected. The everywhere-disconti
nuity of $f$ ensures $G$ is *not* homeomorphic to $\mathbb{R}$ (the projection $
G\to\mathbb{R}$ is a continuous bijection but not a homeomorphism), so $G$ is a
connected set that is not an arc—a genuinely "wild" connected subset of the plan
e.
