# Minimal Surface of Revolution: The Catenoid

## Problem

Minimize $J(y) = 2\pi\int_{\alpha}^{\beta} y\sqrt{1+y'^2}\,dx$ subject to $y(\al
pha)=a,\; y(\beta)=b$, with $y>0$.

## Step 1 — Euler–Lagrange equation

The integrand $F(y,y') = y\sqrt{1+y'^2}$ is autonomous (no explicit $x$-dependen
ce), so the Beltrami identity applies:

$$F - y'\,F_{y'} = \text{const} = C.$$

Computing $F_{y'} = y\cdot\dfrac{y'}{\sqrt{1+y'^2}}$, hence

$$F - y'F_{y'} = y\sqrt{1+y'^2} - \frac{y\,y'^2}{\sqrt{1+y'^2}} = \frac{y(1+y'^2
)-y\,y'^2}{\sqrt{1+y'^2}} = \frac{y}{\sqrt{1+y'^2}} = C.$$

## Step 2 — Solving the first-order ODE

From $\dfrac{y}{\sqrt{1+y'^2}}=C$ (note $C>0$ since $y>0$):

$$y^2 = C^2(1+y'^2)\;\;\Longrightarrow\;\; y'^2 = \frac{y^2-C^2}{C^2},\qquad y\g
e C.$$

Substitute $y = C\cosh u$. Then $y' = C\sinh u\cdot u'$ and $\dfrac{y^2-C^2}{C^2
} = \cosh^2 u - 1 = \sinh^2 u$, so

$$C^2\sinh^2 u\,(u')^2 = \sinh^2 u \;\;\Longrightarrow\;\; u' = \frac{1}{C}.$$

Integrating: $u = \dfrac{x-x_0}{C}$ for a constant $x_0$. Therefore

$$\boxed{\,y(x) = C\cosh\!\left(\frac{x-x_0}{C}\right)\,}$$

— a **catenary**. The constants $C>0$ and $x_0$ are fixed by the boundary condit
ions

$$a = C\cosh\!\left(\frac{\alpha-x_0}{C}\right),\qquad b = C\cosh\!\left(\frac{\
beta-x_0}{C}\right).$$

## Step 3 — The extremal is a minimum (sufficient conditions)

**Legendre condition.** $F_{y'y'} = \dfrac{y}{(1+y'^2)^{3/2}}>0$ for $y>0$, so t
he strengthened Legendre condition holds everywhere.

**Jacobi condition (conjugate points).** The Jacobi equation for the accessory (
second-variation) problem along the catenary $y=C\cosh\!\bigl(\tfrac{x-x_0}{C}\b
igr)$ reduces (after the standard change of variable $t=(x-x_0)/C$) to

$$\eta''(t) - \eta(t) = 0,$$

whose general solution is $\eta = A\cosh t + B\sinh t$. A conjugate point to $t=
\tau_0$ occurs at $t=\tau_0$ shifted by... solving $\eta(\tau_0)=0,\;\eta'(\tau_
0)\neq 0$ and finding the next zero: the solution vanishing at $t_0$ is proporti
onal to $\sinh(t-t_0)$, which has **no other real zero**. Hence there is **no co
njugate point** on $(-\infty,+\infty)$, and in particular none on $[\alpha,\beta
]$.

With the strengthened Legendre condition satisfied and no conjugate point in $[\
alpha,\beta]$, the **Jacobi sufficient condition** for a (weak) minimum is met.
Combined with the global convexity argument below, the catenary gives the **mini
mum**.

**Global argument (Weierstrass).** The Weierstrass excess function is

$$\mathcal{E}(y,y',p) = F(y,p) - F(y,y') - (p-y')F_{y'}(y,y') = y\!\left[\sqrt{1
+p^2}-\sqrt{1+y'^2}-\frac{y'(p-y')}{\sqrt{1+y'^2}}\right].$$

The function $q\mapsto\sqrt{1+q^2}$ is strictly convex, so by the supporting-hyp
erplane inequality $\sqrt{1+p^2}\ge\sqrt{1+y'^2}+\dfrac{y'(p-y')}{\sqrt{1+y'^2}}
$ for all $p$, with equality iff $p=y'$. Since $y>0$, $\mathcal{E}\ge 0$ for all
 $p$, with equality only at $p=y'$. The Weierstrass necessary-and-sufficient con
dition for a **strong minimum** is therefore satisfied.

## Step 4 — Minimal value of the functional

On the catenary, $y' = \sinh\!\bigl(\tfrac{x-x_0}{C}\bigr)$, so $\sqrt{1+y'^2}=\
cosh\!\bigl(\tfrac{x-x_0}{C}\bigr)=\dfrac{y}{C}$. Thus

$$J_{\min} = 2\pi\int_{\alpha}^{\beta} y\cdot\frac{y}{C}\,dx = \frac{2\pi}{C}\in
t_{\alpha}^{\beta} y^2\,dx = \frac{2\pi}{C}\int_{\alpha}^{\beta} C^2\cosh^2\!\le
ft(\tfrac{x-x_0}{C}\right)dx.$$

Using $\cosh^2 t = \tfrac{1+\cosh 2t}{2}$ and $t=(x-x_0)/C$,

$$J_{\min} = 2\pi C\int_{\alpha}^{\beta}\frac{1+\cosh\!\bigl(\tfrac{2(x-x_0)}{C}
\bigr)}{2}\,dx = \pi C\!\left[(x-x_0)+\frac{C}{2}\sinh\!\left(\tfrac{2(x-x_0)}{C
}\right)\right]_{\alpha}^{\beta}.$$

Equivalently, using $\sinh(2t)=2\sinh t\cosh t$ and $\cosh t = y/C$, $\sinh t =
y'$:

$$J_{\min} = \pi C(\beta-\alpha) + \pi C^2\!\left[\sinh\!\left(\tfrac{x-x_0}{C}\
right)\cosh\!\left(\tfrac{x-x_0}{C}\right)\right]_{\alpha}^{\beta} = \pi C(\beta
-\alpha) + \pi C\!\left[y\,y'\right]_{\alpha}^{\beta}.$$

So

$$\boxed{\,J_{\min} = \pi C(\beta-\alpha) + \pi C\bigl[\,b\,y'(\beta) - a\,y'(\a
lpha)\,\bigr]\,}$$

with $y'(x)=\sinh\!\bigl(\tfrac{x-x_0}{C}\bigr)$, i.e.

$$J_{\min} = \pi C(\beta-\alpha) + \pi C\!\left[b\sinh\!\left(\tfrac{\beta-x_0}{
C}\right) - a\sinh\!\left(\tfrac{\alpha-x_0}{C}\right)\right].$$

## Step 5 — Existence caveat (Goldschmidt competitor)

For completeness: when the boundary data are too far apart relative to $a,b$, th
e global infimum is attained not by the catenary but by the discontinuous **Gold
schmidt solution** (two disks joined by a segment on the axis), giving $J = \pi(
a^2+b^2)$. The catenary above is the smooth minimizer whenever it exists and sat
isfies $J_{\text{catenary}}\le \pi(a^2+b^2)$; the constants $C,x_0$ are determin
ed (when a real solution exists) by the two boundary equations in Step 2.

## Conclusion

The minimal surface of revolution between the two coaxial annuli of radii $a$ (a
t $x=\alpha$) and $b$ (at $x=\beta$) is the **catenoid** — the surface obtained
by rotating the catenary

$$y(x) = C\cosh\!\left(\frac{x-x_0}{C}\right)$$

about the $x$-axis, where $C>0$ and $x_0$ are determined by $y(\alpha)=a$ and $y
(\beta)=b$:

$$a = C\cosh\!\left(\frac{\alpha-x_0}{C}\right),\qquad b = C\cosh\!\left(\frac{\
beta-x_0}{C}\right).$$

The minimal value of the functional is

$$J_{\min} = \pi C(\beta-\alpha) + \pi C\!\left[b\sinh\!\left(\frac{\beta-x_0}{C
}\right) - a\sinh\!\left(\frac{\alpha-x_0}{C}\right)\right].$$
