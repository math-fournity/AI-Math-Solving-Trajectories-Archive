## Proof

**Reformulation.** Rearranging the equation gives:
$$f(p)^{f(q)} - f(q)^{f(p)} = p^q - q^p \quad \text{for all } p,q \in \mathbb{P}
.$$

Define $h(x,y) = x^y - y^x$. The condition becomes $h(f(p), f(q)) = h(p,q)$ for
all primes $p,q$.

**Step 1: Forcing $f(2) = 2$.**

Suppose for contradiction that $f(2) = a$ where $a$ is an odd prime ($a \geq 3$)
. Setting $p=2, q=3$:
$$a^{f(3)} - f(3)^a = h(2,3) = 2^3 - 3^2 = -1.$$

Let $b = f(3)$ (a prime). We show $a^b - b^a = -1$ has no solution with $a \geq
3$ prime and $b \geq 2$ prime.

- **$b = 2$:** Need $a^2 - 2^a = -1$. For $a=3$: $9 - 8 = 1 \neq -1$. For $a \ge
q 5$: $2^a \geq 32 > 26 = 5^2+1 \geq a^2+1$, so $a^2 - 2^a < -1$. No solution.

- **$b \geq 3, b = a$:** $a^a - a^a = 0 \neq -1$.

- **$b \geq 3, b > a$:** Since $a \geq 3$ and $b > a \geq 3$, the function $\fra
c{\ln t}{t}$ is strictly decreasing for $t > e$, so $\frac{\ln a}{a} > \frac{\ln
 b}{b}$, giving $a^b > b^a$, hence $a^b - b^a > 0 > -1$.

- **$b \geq 3, b < a$:** By the same argument, $b^a > a^b$, so $a^b - b^a < 0$.
We need $b^a - a^b = 1$. But for primes $3 \leq b < a$ (so $a \geq b+2$):
$$b^a - a^b \geq b^{b+2} - (b+2)^b = b^b\!\left(b^2 - \left(1+\tfrac{2}{b}\right
)^b\right) > b^b(b^2 - e^2).$$
For $b \geq 3$: $b^2 = 9 > e^2 \approx 7.39$, so $b^a - a^b > 0$; in fact $b^a -
 a^b \geq 3^5 - 5^3 = 118 > 1$. No solution.

All cases exhausted, so $f(2) = 2$.

**Step 2: $f(2) = 2$ forces $f = \mathrm{id}$.**

Setting $p = 2$ in the reformulated equation:
$$2^{f(q)} - f(q)^2 = 2^q - q^2 \quad \text{for all primes } q.$$

Define $g(x) = 2^x - x^2$. Then $g(f(q)) = g(q)$ for all primes $q$.

**Claim:** $g$ is injective on $\mathbb{P}$.

Compute: $g(2) = 0$, $g(3) = -1$, $g(5) = 7$, $g(7) = 79$, $g(11) = 1927$, $\ldo
ts$

For $x \geq 4$: $g'(x) = 2^x \ln 2 - 2x$. At $x=4$: $16\ln 2 - 8 \approx 11.09 -
 8 = 3.09 > 0$, and $g'(x)$ is increasing (since $g''(x) = 2^x(\ln 2)^2 - 2 > 0$
 for $x \geq 4$). So $g$ is strictly increasing on $[4, \infty)$, hence on prime
s $\geq 5$.

The values $g(2) = 0$ and $g(3) = -1$ are distinct from each other and from all
$g(p)$ for primes $p \geq 5$ (since $g(p) \geq g(5) = 7$). Therefore $g$ is inje
ctive on $\mathbb{P}$.

Since $f(q) \in \mathbb{P}$ and $g(f(q)) = g(q)$ with $g$ injective on $\mathbb{
P}$, we conclude $f(q) = q$ for every prime $q$.

**Step 3: Verification.** For $f(p) = p$: $p^q + q^p = q^p + p^q$. ✓

## Conclusion

The unique solution is $\boxed{f(p) = p \text{ for all } p \in \mathbb{P}}$.
