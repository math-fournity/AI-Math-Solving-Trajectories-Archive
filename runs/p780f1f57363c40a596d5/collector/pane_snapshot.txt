**Answer: Yes, such disjoint sets exist.**

## Proof

We interpret "$A$ and $B$ in $\mathcal{P}(\mathbb{R})$" as $A, B \subseteq \math
bb{R}$ (elements of the power set), on which the Lebesgue outer measure $\lambda
^*$ is defined. We construct the required sets using a **Vitali set**.

---

### Construction of the Vitali set

Define an equivalence relation on $[0,1)$ by
$$x \sim y \iff x - y \in \mathbb{Q}.$$
By the Axiom of Choice, let $V \subseteq [0,1)$ be a set containing exactly one
representative from each equivalence class.

---

### Claim 1: $\lambda^*(V) > 0$.

Consider the family $\{V + q : q \in \mathbb{Q} \cap [-1,1]\}$.

**Pairwise disjointness.** If $(V+q_1) \cap (V+q_2) \neq \emptyset$ with $q_1 \n
eq q_2$, then $v_1 + q_1 = v_2 + q_2$ for some $v_1, v_2 \in V$, giving $v_1 - v
_2 = q_2 - q_1 \in \mathbb{Q} \setminus \{0\}$. Hence $v_1 \sim v_2$ with $v_1 \
neq v_2$, contradicting that $V$ contains exactly one representative per class.

**Covering property.** For any $x \in [0,1)$, there exists $v \in V$ with $x \si
m v$, i.e., $x - v \in \mathbb{Q}$. Since $x, v \in [0,1)$, we have $x - v \in (
-1,1) \subseteq [-1,1]$, so $x = v + (x-v) \in V + (x-v) \subseteq \bigcup_{q \i
n \mathbb{Q}\cap[-1,1]}(V+q)$. Thus
$$[0,1) \subseteq \bigcup_{q \in \mathbb{Q}\cap[-1,1]}(V+q) \subseteq [-1,2).$$

**Deriving the contradiction.** If $\lambda^*(V) = 0$, then by translation-invar
iance $\lambda^*(V+q) = 0$ for all $q$, and by countable subadditivity:
$$\lambda^*\!\Big(\bigcup_{q \in \mathbb{Q}\cap[-1,1]}(V+q)\Big) \leq \sum_{q} \
lambda^*(V+q) = 0.$$
But $[0,1) \subseteq \bigcup_q (V+q)$ implies $1 = \lambda^*([0,1)) \leq \lambda
^*\!\big(\bigcup_q (V+q)\big) = 0$, a contradiction. Hence $\lambda^*(V) > 0$.

---

### Claim 2: There exist disjoint $A, B \subseteq \mathbb{R}$ with $\lambda^*(A
\cup B) < \lambda^*(A) + \lambda^*(B)$.

Enumerate the countable set $\mathbb{Q} \cap [-1,1] = \{q_1, q_2, q_3, \ldots\}$
. For each $n \geq 1$, define
$$S_n = \bigcup_{i=1}^{n}(V + q_i).$$

The sets $V+q_1, \ldots, V+q_n$ are pairwise disjoint (by Claim 1's disjointness
 argument), and $S_n \subseteq [-1,2)$, so $\lambda^*(S_n) \leq 3$.

By translation-invariance, $\lambda^*(V+q_i) = \lambda^*(V) > 0$ for every $i$.

**Suppose**, for contradiction, that $\lambda^*$ is finitely additive on every p
air of disjoint sets. Then for each $k = 2, \ldots, n$, since $S_{k-1}$ and $V+q
_k$ are disjoint:
$$\lambda^*(S_k) = \lambda^*(S_{k-1}) + \lambda^*(V+q_k).$$
By induction, $\lambda^*(S_n) = \sum_{i=1}^{n}\lambda^*(V+q_i) = n \cdot \lambda
^*(V)$.

Since $\lambda^*(V) > 0$, choosing $n > 3/\lambda^*(V)$ gives $\lambda^*(S_n) =
n\cdot\lambda^*(V) > 3 \geq \lambda^*(S_n)$, a contradiction.

Therefore, finite additivity must fail at some step: there exists $k$ such that
$$\lambda^*(S_k) < \lambda^*(S_{k-1}) + \lambda^*(V + q_k).$$

Set $A = S_{k-1} = \bigcup_{i=1}^{k-1}(V+q_i)$ and $B = V + q_k$. Then:
- $A$ and $B$ are **disjoint** (since $V+q_k$ is disjoint from all $V+q_i$ for $
i < k$),
- $A \cup B = S_k$,
- $\lambda^*(A \cup B) = \lambda^*(S_k) < \lambda^*(S_{k-1}) + \lambda^*(V+q_k)
= \lambda^*(A) + \lambda^*(B)$.

---

### Conclusion

Such disjoint sets $A, B \in \mathcal{P}(\mathbb{R})$ with $\lambda^*(A \cup B)
< \lambda^*(A) + \lambda^*(B)$ **do exist**. The existence follows from the non-
measurability of the Vitali set: if outer measure were finitely additive on all
disjoint sets, the outer measure of $V$ would have to be zero (contradicting Cla
im 1), so finite additivity must fail, and by subadditivity the failure must be
a strict inequality. $\blacksquare$
