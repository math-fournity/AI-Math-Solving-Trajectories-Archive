**Problem.** Find an example of an unbounded set $A$ such that every function fr
om $A$ to a metric space is uniformly continuous.

**Answer leak check.** The problem statement contains only the question; no solu
tion, hint, or answer is embedded. Proceeding.

---

**Example.** Take $A = \mathbb{Z} \subset \mathbb{R}$, the set of integers with
the usual metric inherited from $\mathbb{R}$.

**Claim.** $A = \mathbb{Z}$ is unbounded, and every function $f : \mathbb{Z} \to
 (M, d_M)$ into any metric space $M$ is uniformly continuous.

**Proof.**

*Unboundedness.* For every $R > 0$ there exists $n \in \mathbb{Z}$ with $|n| > R
$ (e.g. $n = \lceil R \rceil + 1$). Hence $\mathbb{Z}$ is not contained in any b
all of finite radius, so $A$ is unbounded.

*Uniform discreteness.* The set $\mathbb{Z}$ has the key property that distinct
points are separated by at least $1$:
$$
\forall x, y \in \mathbb{Z},\quad x \neq y \implies |x - y| \geq 1.
$$
Equivalently, taking $\delta_0 = 1$,
$$
|x - y| < \delta_0 \implies x = y.
$$

*Every function is uniformly continuous.* Let $f : \mathbb{Z} \to (M, d_M)$ be a
n arbitrary function, and let $\varepsilon > 0$ be given. Choose $\delta = \delt
a_0 = 1$ (in fact any $\delta \in (0, 1]$ works). For any $x, y \in \mathbb{Z}$
with $|x - y| < \delta = 1$, the uniform discreteness of $\mathbb{Z}$ forces $x
= y$, whence
$$
d_M(f(x), f(y)) = d_M(f(x), f(x)) = 0 < \varepsilon.
$$
Thus for every $\varepsilon > 0$ there exists $\delta > 0$ (namely $\delta = 1$)
 such that $|x - y| < \delta \implies d_M(f(x), f(y)) < \varepsilon$ for all $x,
 y \in \mathbb{Z}$. This is exactly the definition of uniform continuity. Since
$f$ was arbitrary, **every** function from $\mathbb{Z}$ to any metric space is u
niformly continuous. $\blacksquare$

---

**Remark on the underlying principle.** The argument works for any *uniformly di
screte* unbounded set: a set $A \subseteq \mathbb{R}$ for which there exists $\d
elta_0 > 0$ such that $0 < |x - y| \implies |x - y| \geq \delta_0$ for all $x, y
 \in A$. On such a set the $\varepsilon$–$\delta$ condition for uniform continui
ty is satisfied *vacuously* for $\delta \leq \delta_0$, since no two distinct po
ints ever get within $\delta$ of each other. The integers $\mathbb{Z}$ are the c
anonical unbounded example; other choices such as $\{n\alpha : n \in \mathbb{Z}\
}$ for fixed $\alpha > 0$, or $\mathbb{Z}^k \subset \mathbb{R}^k$, work equally
well.
