## Proof

Let $C = (t, t^2)$ for some $t \in (0,1)$, since $C$ lies on $y=x^2$ between $A$
 and $B$.

The condition $AC = CB = r$ gives $AC^2 = CB^2$:

$$t^2 + t^4 = (1-t)^2 + (1-t^2)^2.$$

Factor the right side using $1-t^2 = (1-t)(1+t)$:

$$(1-t)^2 + (1-t)^2(1+t)^2 = (1-t)^2\bigl[1 + (1+t)^2\bigr] = (1-t)^2(2+2t+t^2).
$$

Expanding $(1-2t+t^2)(2+2t+t^2)$:

$$= 2 + 2t + t^2 - 4t - 4t^2 - 2t^3 + 2t^2 + 2t^3 + t^4 = 2 - 2t - t^2 + t^4.$$

So the equation becomes:

$$t^2 + t^4 = 2 - 2t - t^2 + t^4,$$

$$2t^2 + 2t - 2 = 0,$$

$$t^2 + t - 1 = 0.$$

The positive root in $(0,1)$ is $t = \dfrac{\sqrt{5}-1}{2}$.

Now compute $r^2 = AC^2 = t^2 + t^4 = t^2(1+t^2)$. From $t^2 + t - 1 = 0$ we hav
e $t^2 = 1 - t$, hence $1 + t^2 = 2 - t$. Therefore:

$$r^2 = (1-t)(2-t) = 2 - 3t + t^2 = 2 - 3t + (1-t) = 3 - 4t.$$

Substituting $t = \dfrac{\sqrt{5}-1}{2}$, so $4t = 2(\sqrt{5}-1) = 2\sqrt{5}-2$:

$$r^2 = 3 - (2\sqrt{5}-2) = 5 - 2\sqrt{5}.$$

**Numerical check:** $t \approx 0.618$, $t^2 \approx 0.382$, $t^4 \approx 0.146$
, so $r^2 \approx 0.528$. Meanwhile $5 - 2\sqrt{5} \approx 5 - 4.472 = 0.528$. ✓

$$\boxed{r^2 = 5 - 2\sqrt{5}}$$
