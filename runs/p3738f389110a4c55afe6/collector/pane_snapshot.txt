**Evaluate** $I = \int_{0}^{\pi/4} \frac{\sin 2x}{\sin x + \cos x}\,dx$.

**Substitution.** Let $u = \sin x - \cos x$. Then
$$du = (\cos x + \sin x)\,dx = (\sin x + \cos x)\,dx.$$
Also $u^2 = 1 - \sin 2x$, so $\sin 2x = 1 - u^2$, and
$$(\sin x + \cos x)^2 = 1 + \sin 2x = 2 - u^2.$$
Bounds: $x=0 \Rightarrow u=-1$; $x=\pi/4 \Rightarrow u=0$.

Since $dx = \frac{du}{\sin x + \cos x}$,
$$I = \int_{-1}^{0} \frac{1-u^2}{(\sin x+\cos x)^2}\,du = \int_{-1}^{0} \frac{1-
u^2}{2-u^2}\,du.$$

**Decompose the integrand:**
$$\frac{1-u^2}{2-u^2} = -1 + \frac{1}{2-u^2}.$$

**First piece:** $\displaystyle\int_{-1}^{0}(-1)\,du = -1.$

**Second piece:** Using $\displaystyle\int\frac{du}{a^2-u^2}=\frac{1}{2a}\ln\lef
t|\frac{a+u}{a-u}\right|$ with $a=\sqrt2$:
$$\int_{-1}^{0}\frac{du}{2-u^2}=\left[\frac{1}{2\sqrt2}\ln\left|\frac{\sqrt2+u}{
\sqrt2-u}\right|\right]_{-1}^{0}.$$
At $u=0$: $\frac{1}{2\sqrt2}\ln 1 = 0$. At $u=-1$: $\frac{1}{2\sqrt2}\ln\!\left(
\frac{\sqrt2-1}{\sqrt2+1}\right)$.

So the second piece equals
$$-\frac{1}{2\sqrt2}\ln\!\left(\frac{\sqrt2-1}{\sqrt2+1}\right).$$

Rationalize: $\dfrac{\sqrt2-1}{\sqrt2+1} = (\sqrt2-1)^2 = 3-2\sqrt2$, hence
$$\ln\!\left(\frac{\sqrt2-1}{\sqrt2+1}\right) = 2\ln(\sqrt2-1) = -2\ln(\sqrt2+1)
.$$

Therefore the second piece
$$= -\frac{1}{2\sqrt2}\cdot(-2\ln(\sqrt2+1)) = \frac{1}{\sqrt2}\ln(\sqrt2+1) = \
frac{\sqrt2}{2}\ln(1+\sqrt2).$$

**Combine:**
$$I = -1 + \frac{\sqrt2}{2}\ln(1+\sqrt2).$$

**Match to the form** $a + b\sqrt2\ln(c+d\sqrt2)$:
$$a = -1,\quad b = \tfrac{1}{2},\quad c = 1,\quad d = 1.$$

**Final value:**
$$a+b+c+d = -1 + \tfrac{1}{2} + 1 + 1 = \boxed{\tfrac{3}{2}}.$$
