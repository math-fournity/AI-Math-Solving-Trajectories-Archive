Looking at this problem, I need to find the maximum radius of a sphere containin
g three pairwise perpendicular chords of lengths 5, 6, 7 intersecting at a commo
n interior point.

## Setup

Let the intersection point be the origin $O$. Since the three chords are pairwis
e perpendicular and pass through $O$, align the coordinate axes with them. Each
chord is divided by $O$ into two segments:

- **Chord 1** (along $x$-axis, length 5): endpoints $(-a, 0, 0)$ and $(b, 0, 0)$
, with $a + b = 5$, $a, b > 0$.
- **Chord 2** (along $y$-axis, length 6): endpoints $(0, -c, 0)$ and $(0, d, 0)$
, with $c + d = 6$, $c, d > 0$.
- **Chord 3** (along $z$-axis, length 7): endpoints $(0, 0, -e)$ and $(0, 0, f)$
, with $e + f = 7$, $e, f > 0$.

Let the sphere have center $C = (h, k, l)$ and radius $R$.

## Finding the Center

All six endpoints satisfy $(x - h)^2 + (y - k)^2 + (z - l)^2 = R^2$. Equating th
e two $x$-axis endpoints:

$$(a + h)^2 + k^2 + l^2 = (b - h)^2 + k^2 + l^2$$

This gives $a + h = b - h$ (the other sign yields $a = -b$, impossible), so $h =
 \frac{b - a}{2}$. Similarly:

$$k = \frac{d - c}{2}, \qquad l = \frac{f - e}{2}.$$

## Expressing $R^2$

Substituting back into the sphere equation for each pair of endpoints:

- **Chord 1:** $a + h = \frac{a+b}{2} = \frac{5}{2}$, so $R^2 = \frac{25}{4} + k
^2 + l^2$. &ensp; (I)
- **Chord 2:** $c + k = \frac{c+d}{2} = 3$, so $R^2 = h^2 + 9 + l^2$. &ensp; (II
)
- **Chord 3:** $e + l = \frac{e+f}{2} = \frac{7}{2}$, so $R^2 = h^2 + k^2 + \fra
c{49}{4}$. &ensp; (III)

## Solving the System

From (I) − (II): $k^2 - h^2 = 9 - \frac{25}{4} = \frac{11}{4}$.

From (II) − (III): $l^2 - k^2 = \frac{49}{4} - 9 = \frac{13}{4}$.

From (I) − (III): $l^2 - h^2 = \frac{49}{4} - \frac{25}{4} = 6$. &ensp; (Consist
ent: $\frac{11}{4} + \frac{13}{4} = 6$ ✓)

Let $h^2 = t \geq 0$. Then:
$$k^2 = t + \frac{11}{4}, \qquad l^2 = t + 6.$$

Substituting into (I):
$$R^2 = \frac{25}{4} + \left(t + \frac{11}{4}\right) + (t + 6) = 15 + 2t.$$

## Constraints and Maximization

**Interior condition:** $O$ is inside the sphere, so $h^2 + k^2 + l^2 < R^2$:
$$t + \left(t + \frac{11}{4}\right) + (t + 6) < 15 + 2t \implies 3t + \frac{35}{
4} < 15 + 2t \implies t < \frac{25}{4}.$$

**Positivity of chord segments:** From $a = \frac{5 - 2h}{2} > 0$ and $b = \frac
{5 + 2h}{2} > 0$, we need $|h| < \frac{5}{2}$, i.e., $h^2 < \frac{25}{4}$. Simil
arly:
- $|k| < 3 \implies k^2 < 9 \implies t + \frac{11}{4} < 9 \implies t < \frac{25}
{4}$.
- $|l| < \frac{7}{2} \implies l^2 < \frac{49}{4} \implies t + 6 < \frac{49}{4} \
implies t < \frac{25}{4}$.

All constraints coincide: $0 \leq t < \frac{25}{4}$.

## Result

Since $R^2 = 15 + 2t$ is increasing in $t$, the supremum is:

$$R^2 = 15 + 2 \cdot \frac{25}{4} = 15 + \frac{25}{2} = \frac{55}{2}.$$

This value is approached as $t \to \frac{25}{4}^-$ (the intersection point appro
aches the sphere's boundary, with one segment of each chord shrinking to zero).
The maximum possible radius satisfies:

$$\boxed{R^2 = \dfrac{55}{2}}$$
