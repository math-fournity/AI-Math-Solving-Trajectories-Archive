## Solution

**Coordinate setup.** Place the cube with
- A=(0,0,0), B=(1,0,0), C=(1,1,0), D=(0,1,0),
- A₁=(0,0,1), B₁=(1,0,1), C₁=(1,1,1), D₁=(0,1,1).

**Locate X, Y, Z.**
- X = center of square AA₁B₁B = (½, 0, ½).
- Y = center of square BB₁C₁C = (1, ½, ½).
- Z on diagonal BD with DZ = 3·ZB, so Z divides BD in ratio DZ:ZB = 3:1 (closer
to B):
  Z = D + (3/4)(B−D) = (0,1,0) + (3/4)(1,−1,0) = (3/4, 1/4, 0).

**Circumscribed sphere.** Center O = (½, ½, ½), radius R = √3/2, so R² = 3/4.

**Equation of plane XYZ.** Two in-plane vectors:
- XY = Y − X = (½, ½, 0),
- XZ = Z − X = (¼, ¼, −½).

Normal n = XY × XZ:
- i: (½)(−½) − (0)(¼) = −¼,
- j: −[(½)(−½) − (0)(¼)] = ¼,
- k: (½)(¼) − (½)(¼) = 0.

So n = (−¼, ¼, 0) ∝ (−1, 1, 0). The plane is −x + y = c; substituting X: −½ + 0
= −½, giving

  x − y = ½.

Verify: Y gives 1 − ½ = ½ ✓; Z gives ¾ − ¼ = ½ ✓.

**Distance from O to the plane.**

  d = |½ − ½ − ½| / √(1² + (−1)²) = ½ / √2 = √2/4,  so  d² = 2/16 = 1/8.

**Cross-section radius.** The plane cuts the sphere in a circle of radius

  r² = R² − d² = 3/4 − 1/8 = 6/8 − 1/8 = 5/8.

**Area of the cross-section:**

  S = π·r² = π·(5/8) = **5π/8**.
