## Proof

**Goal.** Let $X$ be a compact metric space and $T:X\to X$ continuous. We show t
here exist $x_0\in X$ and a strictly increasing sequence $(n_k)$ with $T^{n_k}(x
_0)\to x_0$.

---

### Step 1. Existence of a minimal invariant set

Call a set $F\subseteq X$ *$T$-invariant* if $F\neq\varnothing$, $F$ is closed,
and $T(F)\subseteq F$. The family $\mathcal{F}$ of all $T$-invariant sets is non
-empty since $X\in\mathcal{F}$.

Order $\mathcal{F}$ by **reverse inclusion** ($F_1\preceq F_2 \iff F_1\supseteq
F_2$). Let $\{F_\alpha\}$ be a chain (totally ordered). Since the $F_\alpha$ are
 non-empty closed subsets of the compact space $X$ and are nested (totally order
ed by inclusion), the finite-intersection property gives
$$F^*:=\bigcap_\alpha F_\alpha\neq\varnothing.$$
Clearly $F^*$ is closed. For $y\in F^*$ we have $y\in F_\alpha$ for every $\alph
a$, so $T(y)\in F_\alpha$ for every $\alpha$, hence $T(y)\in F^*$; thus $T(F^*)\
subseteq F^*$. So $F^*\in\mathcal{F}$, and $F^*\supseteq F_\alpha$ for all $\alp
ha$ means $F^*$ is an upper bound of the chain. By **Zorn's Lemma**, $\mathcal{F
}$ has a maximal element $M$, which is a **minimal** $T$-invariant set under inc
lusion.

### Step 2. $T(M)=M$

$T(M)$ is compact (continuous image of compact), hence closed; it is non-empty s
ince $M\neq\varnothing$. It is $T$-invariant:
$$T(T(M))=T^2(M)\subseteq T(M).$$
So $T(M)\in\mathcal{F}$ and $T(M)\subseteq M$. By minimality of $M$, $T(M)=M$. T
hus $T|_M:M\to M$ is **surjective**.

### Step 3. Every orbit in $M$ is dense in $M$

Fix $x\in M$ and let $\overline{O(x)}=\overline{\{T^n(x):n\ge 0\}}$. This is clo
sed and non-empty (it contains $x$). It is $T$-invariant: if $y\in\overline{O(x)
}$, pick $n_j$ with $T^{n_j}(x)\to y$; by continuity $T^{n_j+1}(x)\to T(y)$, so
$T(y)\in\overline{O(x)}$. By minimality, $\overline{O(x)}=M$.

### Step 4. The shifted orbit is also dense

Apply Step 3 to the point $T(x)\in M$: the orbit $\{T^n(T(x)):n\ge 0\}=\{T^n(x):
n\ge 1\}$ is dense in $M$.

### Step 5. $x$ is a returning point

Since $\{T^n(x):n\ge 1\}$ is dense in $M$ and $x\in M$, we have
$$x\in\overline{\{T^n(x):n\ge 1\}}.$$

**Case 1.** $x\in\{T^n(x):n\ge 1\}$, i.e. $T^m(x)=x$ for some $m\ge 1$. Then $x$
 is periodic; set $n_k=km$. Clearly $T^{n_k}(x)=x\to x$.

**Case 2.** $x\notin\{T^n(x):n\ge 1\}$. Then $x$ is a **limit point** of $\{T^n(
x):n\ge 1\}$: for every $\varepsilon>0$ there exists $n\ge 1$ with $0<d(T^n(x),x
)<\varepsilon$.

For each $k\ge 1$ choose $n_k\ge 1$ with $0<d(T^{n_k}(x),x)<1/k$. We claim $n_k\
to\infty$. Indeed, if $\{n_k\}$ were bounded, some value $n^*$ would repeat infi
nitely often, giving $0<d(T^{n^*}(x),x)<1/k$ for all $k$—a contradiction. Hence
$n_k\to\infty$, and we may pass to a strictly increasing subsequence (still deno
ted $n_k$). Then
$$d\bigl(T^{n_k}(x),\,x\bigr)<\frac{1}{k}\xrightarrow{k\to\infty}0,$$
so $T^{n_k}(x)\to x$.

In both cases, $x_0:=x\in M\subseteq X$ is a returning point for $T$. $\blacksqu
are$
