## Proof

We compute $\operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$ where $
X = \int_0^1 W^2(t)\,dt$.

**Step 1: Compute $\mathbb{E}[X]$.**

By Fubini and the fact that $\mathbb{E}[W^2(t)] = t$ for a Wiener process,

$$\mathbb{E}[X] = \int_0^1 \mathbb{E}[W^2(t)]\,dt = \int_0^1 t\,dt = \frac{1}{2}
.$$

**Step 2: Compute $\mathbb{E}[X^2]$.**

$$\mathbb{E}[X^2] = \mathbb{E}\!\left[\left(\int_0^1 W^2(s)\,ds\right)\!\left(\i
nt_0^1 W^2(t)\,dt\right)\right] = \int_0^1\!\!\int_0^1 \mathbb{E}[W^2(s)W^2(t)]\
,ds\,dt.$$

Since $(W(s), W(t))$ is jointly Gaussian with $\mathbb{E}[W(s)]=\mathbb{E}[W(t)]
=0$ and $\operatorname{Cov}(W(s),W(t))=\min(s,t)$, Isserlis' theorem (Wick's for
mula) gives

$$\mathbb{E}[W^2(s)W^2(t)] = \mathbb{E}[W^2(s)]\,\mathbb{E}[W^2(t)] + 2\bigl(\ma
thbb{E}[W(s)W(t)]\bigr)^2 = st + 2\min(s,t)^2.$$

Therefore

$$\mathbb{E}[X^2] = \underbrace{\int_0^1\!\!\int_0^1 st\,ds\,dt}_{=\,1/4} + 2\un
derbrace{\int_0^1\!\!\int_0^1 \min(s,t)^2\,ds\,dt}_{J}.$$

**Step 3: Evaluate $J$.**

Splitting the unit square along $s=t$ and using symmetry,

$$J = 2\int_0^1\!\!\int_0^t s^2\,ds\,dt = 2\int_0^1 \frac{t^3}{3}\,dt = \frac{2}
{3}\cdot\frac{1}{4} = \frac{1}{6}.$$

**Step 4: Combine.**

$$\mathbb{E}[X^2] = \frac{1}{4} + 2\cdot\frac{1}{6} = \frac{1}{4} + \frac{1}{3}
= \frac{7}{12}.$$

$$\operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = \frac{7}{12} - \
frac{1}{4} = \frac{7}{12} - \frac{3}{12} = \frac{4}{12} = \frac{1}{3}.$$

$$\boxed{\operatorname{Var}(X) = \dfrac{1}{3}}$$
