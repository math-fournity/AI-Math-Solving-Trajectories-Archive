# Proof

**Claim:** Yes, $Y$ is necessarily a Banach space.

Let $T: X \to Y$ be a continuous linear open mapping, with $X$ a Banach space.

**Step 1: $T$ is surjective.**

Since $T$ is open, $T(B_X)$ is open in $Y$, where $B_X = \{x \in X : \|x\| < 1\}
$ is the open unit ball of $X$. We have $0 = T(0) \in T(B_X)$, so $T(B_X)$ is an
 open neighborhood of $0$ in $Y$. Hence $T(X) \supseteq T(B_X)$ contains an open
 ball around $0$. Since $T(X)$ is a linear subspace of $Y$ containing a neighbor
hood of $0$, we conclude $T(X) = Y$. Thus $T$ is surjective.

**Step 2: $\ker T$ is closed, so $X / \ker T$ is a Banach space.**

$T$ is continuous and $\{0\}$ is closed in $Y$, so $\ker T = T^{-1}(\{0\})$ is c
losed in $X$. Since $X$ is Banach and $\ker T$ is a closed subspace, the quotien
t $X / \ker T$ equipped with the quotient norm
$$\|[x]\| = \inf_{z \in \ker T} \|x + z\|$$
is a Banach space.

**Step 3: The induced map $S: X/\ker T \to Y$ is a continuous linear bijection.*
*

Define $S([x]) = T(x)$. This is well-defined (since $T$ vanishes on $\ker T$), l
inear, and bijective (surjectivity of $T$ gives surjectivity; $\ker S = \{[0]\}$
 gives injectivity). For continuity:
$$\|S([x])\| = \|T(x)\| = \|T(x+z)\| \le \|T\|\,\|x+z\| \quad \text{for all } z
\in \ker T.$$
Taking the infimum over $z \in \ker T$:
$$\|S([x])\| \le \|T\|\,\|[x]\|,$$
so $S$ is continuous.

**Step 4: $T$ open implies $S^{-1}$ is continuous (equivalent norms).**

Since $T$ is open, $T(B_X)$ is open in $Y$ and contains $0$, so there exists $\d
elta > 0$ with $B_Y(0, \delta) \subseteq T(B_X)$. This means: for every $y \in Y
$ with $\|y\| < \delta$, there exists $x \in X$ with $\|x\| < 1$ and $T(x) = y$.

For any $y \in Y$, $y \neq 0$, and any $\varepsilon > 0$, set $y' = \frac{\delta
}{\|y\| + \varepsilon}\, y$, so $\|y'\| < \delta$. Then $y' = T(u)$ for some $\|
u\| < 1$, giving $y = T\!\left(\frac{\|y\|+\varepsilon}{\delta}\, u\right)$. Hen
ce
$$\|S^{-1}(y)\| = \inf\{\|w\| : T(w) = y\} \le \frac{\|y\| + \varepsilon}{\delta
}.$$
Letting $\varepsilon \to 0$:
$$\|S^{-1}(y)\| \le \frac{1}{\delta}\|y\|.$$
So $S^{-1}: Y \to X/\ker T$ is continuous.

**Step 5: $Y$ is complete.**

From Steps 3 and 4, $S$ is a linear homeomorphism with equivalent norms:
$$\delta\,\|[x]\| \le \|S([x])\| \le \|T\|\,\|[x]\|.$$
Thus $Y$ is isomorphic to the Banach space $X/\ker T$ via a norm-equivalent line
ar bijection. Completeness is preserved under equivalent norms, so $Y$ is comple
te.

Therefore $Y$ is a Banach space. $\blacksquare$
