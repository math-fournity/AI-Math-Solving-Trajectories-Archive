Looking at this problem, I need to determine which values of n ≥ 8 allow a graph
 with the given degree sequence to exist.

## Setting Up the Degree Sequence

The degree sequence is:
- S_k for 1 ≤ k ≤ n−6: degree k+3, giving 4, 5, 6, …, n−3
- S_{n−5}, S_{n−4}, S_{n−3}: degree n−2 (three vertices)
- S_{n−2}, S_{n−1}, S_n: degree n−1 (three vertices)

In non-increasing order: **n−1, n−1, n−1, n−2, n−2, n−2, n−3, n−4, …, 5, 4**.

## Key Reduction

The three vertices of degree n−1 are **universal** (connected to all others). Re
moving them yields a graph on n−3 vertices where every remaining vertex loses ex
actly 3 from its degree. The reduced degree sequence becomes:

**1, 2, 3, …, n−6, n−5, n−5, n−5** (on n−3 vertices)

The original graph exists **if and only if** this reduced sequence is graphical
(add three universal vertices back to recover the original).

## Parity Condition

Sum of reduced degrees = (1+2+…+(n−6)) + 3(n−5) = (n−6)(n−5)/2 + 3(n−5) = n(n−5)
/2.

This must be even, so n(n−5) ≡ 0 (mod 4). Checking n mod 4:
- n ≡ 0: 0·(−1) = 0 ✓
- n ≡ 1: 1·(−4) = 0 ✓
- n ≡ 2: 2·(−3) = 2 ✗
- n ≡ 3: 3·(−2) = 2 ✗

**Necessary: n ≡ 0 or 1 (mod 4).**

## Erdős–Gallai Analysis

The reduced sequence in non-increasing order is: **n−5, n−5, n−5, n−6, n−7, …, 2
, 1**, where for position j ≥ 4: d_j = n−j−2.

**Critical check at k = 4:**

L(4) = 3(n−5) + (n−6) = **4n − 21**

R(4) = 12 + Σ_{i=5}^{n−3} min(d_i, 4)

For n ≥ 11: the values d_5, …, d_{n−3} are n−7, n−8, …, 1. Those ≥ 4 contribute
4 each (there are n−10 of them), and 3, 2, 1 contribute themselves:

R(4) = 12 + 4(n−10) + 3 + 2 + 1 = **4n − 22**

So **L(4) − R(4) = 1 > 0** for all n ≥ 11. The Erdős–Gallai condition **fails at
 k = 4**.

For n = 10: parity already fails (n ≡ 2 mod 4).
For n = 11: parity already fails (n ≡ 3 mod 4).

So no n ≥ 10 can work.
