## Proof

We minimize $I(f) = \int_0^1 (1+x^2)(f(x))^2\,dx$ over $f \in C[0,1]$ with $\int
_0^1 f(x)\,dx = 1$.

**Step 1: Lower bound via Cauchy–Schwarz.**

Apply the Cauchy–Schwarz inequality to the functions
$$g(x) = \sqrt{1+x^2}\,f(x), \qquad h(x) = \frac{1}{\sqrt{1+x^2}}.$$

Then
- $\int_0^1 g(x)h(x)\,dx = \int_0^1 f(x)\,dx = 1$,
- $\int_0^1 g(x)^2\,dx = \int_0^1 (1+x^2)(f(x))^2\,dx = I(f)$,
- $\int_0^1 h(x)^2\,dx = \int_0^1 \frac{dx}{1+x^2} = \arctan(1) - \arctan(0) = \
frac{\pi}{4}$.

Cauchy–Schwarz gives
$$1 = \left(\int_0^1 g\,h\right)^2 \le \left(\int_0^1 g^2\right)\left(\int_0^1 h
^2\right) = I(f)\cdot\frac{\pi}{4}.$$

Hence
$$I(f) \ge \frac{4}{\pi} \qquad \text{for all } f\in\mathcal{A}.$$

**Step 2: Equality is attained.**

Equality in Cauchy–Schwarz holds iff $g$ and $h$ are proportional: $g(x) = \lamb
da\, h(x)$, i.e.
$$\sqrt{1+x^2}\,f(x) = \frac{\lambda}{\sqrt{1+x^2}} \implies f(x) = \frac{\lambd
a}{1+x^2}.$$

The constraint $\int_0^1 f = 1$ forces
$$\lambda\int_0^1 \frac{dx}{1+x^2} = \lambda\cdot\frac{\pi}{4} = 1 \implies \lam
bda = \frac{4}{\pi}.$$

So the candidate minimizer is
$$f_*(x) = \frac{4}{\pi(1+x^2)},$$
which is continuous on $[0,1]$, hence $f_* \in \mathcal{A}$.

**Step 3: Verify the value.**

$$I(f_*) = \int_0^1 (1+x^2)\cdot\frac{16}{\pi^2(1+x^2)^2}\,dx = \frac{16}{\pi^2}
\int_0^1 \frac{dx}{1+x^2} = \frac{16}{\pi^2}\cdot\frac{\pi}{4} = \frac{4}{\pi}.$
$

This matches the lower bound, so the minimum is achieved.

**Conclusion.** The minimum value is

$$\boxed{\dfrac{4}{\pi}}.$$
