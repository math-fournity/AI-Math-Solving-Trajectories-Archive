## 证明

我们分析各个情况。可用的操作包括：逐项 $+,-,\times,\div$ 和移位（移除 $k$ 个初始
项，即 $n \mapsto n+k$）。我们将序列视为 $n$ 的有理函数；移位对应于 $h(n) \mapst
o h(n+1)$，而差分 $\Delta(h) = h(n+1) - h(n)$ 是通过移位后逐项相减得到的。

### a) $a_n = n^2$: $f = 1$

- $\Delta(n^2) = (n+1)^2 - n^2 = 2n+1$.
- $\Delta(2n+1) = 2$，得到常数序列 $\{2\}$。
- $\{2\}/\{2\} = \{1\}$。
- $(2n+1) - \{1\} = 2n$。
- $2n / \{2\} = n$。

因此 $\{n\}$ 是可获取的，且 $f(n^2) = 1$。

### b) $a_n = \frac{n^{2000}+1}{n} = n^{1999} + \frac{1}{n}$: $f = 1$

**第一步 — 2000 次差分。** 多项式部分 $n^{1999}$ 在 2000 次差分后消失（次数 $199
9 < 2000$）。对于 $1/n$ 部分，可以归纳验证 $\Delta^k(1/n) = \frac{(-1)^k\, k!}{n
(n+1)\cdots(n+k)}$。因此

$$s_n := \Delta^{2000}(a_n) = \frac{2000!}{n(n+1)\cdots(n+2000)} \neq 0.$$

**第二步 — 提取常数。** 计算：
- $p_n := s_n / s_{n+1} = \frac{n+2001}{n}$.
- $q_n := p_n - p_{n+1} = \frac{2001}{n(n+1)}$.
- $r_n := q_n / q_{n+1} = \frac{n+2}{n}$.
- $t_n := r_n - r_{n+1} = \frac{2}{n(n+1)}$.

那么 $q_n / t_n = \frac{2001}{2}$，这是一个**常数序列**。从中我们得到 $\{1\} = \
{2001/2\}/\{2001/2\}$，然后是 $\{2001\} = \{2001/2\}\cdot\{2\}$，其中 $\{2\}=\{1
\}+\{1\}$。

**第三步 — 得到 $\{n\}$。** 由 $p_n = 1 + \frac{2001}{n}$:

$$p_n - \{1\} = \frac{2001}{n}, \qquad \frac{2001/n}{\{2001\}} = \frac{1}{n}, \q
quad \frac{\{1\}}{1/n} = n.$$

所有步骤仅使用了允许的操作，因此 $f\!\left(\frac{n^{2000}+1}{n}\right)=1$。

### c) $a_n = n + \sqrt{2}$: $f = 0$

每个可达序列都是 $\mathbb{Q}(n,\sqrt{2})$ 的一个元素，形式为 $f(n)+g(n)\sqrt{2}$
，其中 $f,g\in\mathbb{Q}(n)$。移位 $a_n \mapsto a_{n+1}=(n+1)+\sqrt{2} = a_n + 1
$，因此 $a_{n+1}-a_n=1$，得到常数 $\{1\}$，从而得到所有 $\mathbb{Q}$。

**关键主张：** 所有可达序列都属于子域 $\mathbb{Q}(n+\sqrt{2}) \subsetneq \mathbb
{Q}(n,\sqrt{2})$，且 $n \notin \mathbb{Q}(n+\sqrt{2})$。

*证明.* 生成元是 $a_n = n+\sqrt{2}$ 和 $\mathbb{Q}$（来自常数）。$a_n$ 的所有移
位都是 $(n+k)+\sqrt{2} = (n+\sqrt{2})+k \in \mathbb{Q}(n+\sqrt{2})$。域操作（$+,
-,\times,\div$）将 $\mathbb{Q}(n+\sqrt{2})$ 闭包内的元素映射到 $\mathbb{Q}(n+\sq
rt{2})$ 闭包内的元素。因此，每个可达序列都在 $\mathbb{Q}(n+\sqrt{2})$ 中。

现在，$\alpha := n+\sqrt{2}$ 在 $\mathbb{Q}$ 上是超越的，所以 $\mathbb{Q}(\alpha
) \cong \mathbb{Q}(t)$（纯超越扩张）。$\mathbb{Q}$ 在 $\mathbb{Q}(t)$ 中的代数闭
包是 $\mathbb{Q}$ 本身。由于 $\sqrt{2}$ 在 $\mathbb{Q}$ 上是代数的，且 $\sqrt{2}
\notin\mathbb{Q}$，我们得到 $\sqrt{2}\notin\mathbb{Q}(\alpha)$。因此 $n = \alpha
 - \sqrt{2} \notin \mathbb{Q}(\alpha)$。

由于 $\{n\}$ 对应于元素 $n \notin \mathbb{Q}(n+\sqrt{2})$，它是**不可达的**。因
此 $f(n+\sqrt{2})=0$。

### 最终计算

$$100\cdot f(n^2) + 10\cdot f\!\left(\tfrac{n^{2000}+1}{n}\right) + f(n+\sqrt{2}
) = 100\cdot 1 + 10\cdot 1 + 0 = \boxed{110}.$$
