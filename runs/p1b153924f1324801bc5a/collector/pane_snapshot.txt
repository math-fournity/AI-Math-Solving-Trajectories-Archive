Looking at this problem, I need to determine whether every sequence of compact o
perators (norm 1, eigenvalue 1) on a separable infinite-dimensional Hilbert spac
e must admit a subsequence sharing a common eigenvector (for eigenvalue 1).

**Answer: No, it is not always possible.**

**Proof.**

We construct an explicit counterexample.

Let $H = \ell^2(\mathbb{N})$ with standard orthonormal basis $\{e_1, e_2, e_3, \
dots\}$. For each $n \in \mathbb{N}$, define
$$A_n := P_n,$$
the orthogonal projection onto $\operatorname{span}\{e_n\}$, i.e., $A_n x = \lan
gle x, e_n\rangle\, e_n$.

**Verification of the hypotheses:**

1. **Compactness:** Each $A_n$ has rank 1, hence is a finite-rank operator and t
herefore compact.

2. **Norm one:** $A_n$ is an orthogonal projection, so $\|A_n\| = 1$.

3. **$1$ is an eigenvalue:** $A_n e_n = e_n$, so $1$ is an eigenvalue with eigen
vector $e_n$.

**No common eigenvector exists for any subsequence:**

The eigenspace of $A_n$ for eigenvalue $1$ is
$$E_n = \ker(A_n - I) = \operatorname{span}\{e_n\}.$$

Consider any subsequence $(A_{n_k})_{k=1}^{\infty}$ with the $n_k$ distinct. A c
ommon eigenvector $v \neq 0$ for eigenvalue $1$ would require
$$v \in \bigcap_{k=1}^{\infty} E_{n_k} = \bigcap_{k=1}^{\infty} \operatorname{sp
an}\{e_{n_k}\}.$$

But for any $k_1 \neq k_2$, the vectors $e_{n_{k_1}}$ and $e_{n_{k_2}}$ are orth
ogonal, so
$$\operatorname{span}\{e_{n_{k_1}}\} \cap \operatorname{span}\{e_{n_{k_2}}\} = \
{0\}.$$

Therefore $\bigcap_{k=1}^{\infty} E_{n_k} = \{0\}$, and no nonzero common eigenv
ector exists for any subsequence.

**Conclusion.** The sequence $(A_n)$ of rank-one projections satisfies all the s
tated hypotheses — each $A_n$ is compact, $\|A_n\|=1$, and $1$ is an eigenvalue
— yet no subsequence (of size $\geq 2$) shares a common eigenvector for eigenval
ue $1$. Hence it is **not** always possible to find such a subsequence. $\blacks
quare$
