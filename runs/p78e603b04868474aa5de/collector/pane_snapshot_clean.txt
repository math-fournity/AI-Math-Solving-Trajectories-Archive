Looking at this problem, I need to determine whether a subset $T \subset \mathbb
{Q}$ exists such that every integer $z$ has a **unique** representation as a sum
 of a finite subset of $T$.

## Proof

**Yes**, such a subset exists. Let $T = \{(-2)^k : k \geq 0\} = \{1, -2, 4, -8,
16, -32, 64, \ldots\}$.

Since each $(-2)^k \in \mathbb{Z} \subset \mathbb{Q}$, we have $T \subset \mathb
b{Q}$.

I will show that every integer $z$ has a unique representation $z = \sum_{k \in
S_z} (-2)^k$ for a finite subset $S_z \subset \mathbb{N}_0$, which is equivalent
 to the unique finite subset $A_z = \{(-2)^k : k \in S_z\} \subset T$.

### Existence of representation

**Algorithm.** Given any integer $n$, define the negabinary digits $a_0, a_1, a_
2, \ldots \in \{0,1\}$ recursively:
- If $n$ is even, set $a_0 = 0$ and $q = n/(-2)$.
- If $n$ is odd, set $a_0 = 1$ and $q = (n - 1)/(-2)$.

Then $n = a_0 + (-2)q$, and we recurse on $q$ to obtain $q = a_1 + (-2)q'$, etc.
 This produces $n = \sum_{k=0}^{d} a_k (-2)^k$.

**Termination.** We show $|q| < |n|$ for $|n| \geq 2$, so the process terminates
:
- If $n$ is even: $|q| = |n|/2 < |n|$ for $|n| \geq 2$. ✓
- If $n$ is odd and $n \geq 3$: $|q| = |n-1|/2 = (n-1)/2 < n = |n|$. ✓
- If $n$ is odd and $n \leq -3$: $|q| = |n-1|/2 = (|n|+1)/2$. For $|n| \geq 3$:
$(|n|+1)/2 \leq |n|$ iff $|n| \geq 1$, which holds. In fact $(|n|+1)/2 < |n|$ if
f $|n| > 1$, so for $|n| \geq 3$ we get $|q| < |n|$. ✓

For $|n| \leq 1$ (i.e., $n \in \{-1, 0, 1\}$), the process terminates in at most
 2 steps:
- $n = 0$: $a_0 = 0, q = 0$. Done. Representation: $\emptyset$ (empty sum = 0).
✓
- $n = 1$: $a_0 = 1, q = 0$. Done. Representation: $\{1\}$. ✓
- $n = -1$: $a_0 = 1, q = 1$; then $a_1 = 1, q = 0$. Done. Representation: $1 +
(-2) = -1$. ✓

So every integer $n$ has a finite negabinary representation $n = \sum_{k \in S}
(-2)^k$ with $S$ finite, giving the finite subset $A_n = \{(-2)^k : k \in S\} \s
ubset T$.

### Uniqueness of representation

Suppose $\sum_{k=0}^{d} a_k (-2)^k = \sum_{k=0}^{d} b_k (-2)^k$ where $a_k, b_k
\in \{0, 1\}$ (padding with zeros as needed). Then:

$$\sum_{k=0}^{d} (a_k - b_k)(-2)^k = 0, \quad \text{where } a_k - b_k \in \{-1,
0, 1\}.$$

Let $j$ be the **largest** index with $a_j \neq b_j$. Then:

$$(a_j - b_j)(-2)^j = -\sum_{k=0}^{j-1} (a_k - b_k)(-2)^k.$$

The left side has absolute value $\geq |(-2)^j| = 2^j$ (since $|a_j - b_j| \geq
1$).

The right side has absolute value $\leq \sum_{k=0}^{j-1} |(-2)^k| = \sum_{k=0}^{
j-1} 2^k = 2^j - 1 < 2^j$.

This is a contradiction. Therefore $a_k = b_k$ for all $k$, proving uniqueness.

### Verification of all conditions

1. **Every integer is representable**: Established by the existence algorithm ab
ove.

2. **Uniqueness for each integer**: Established by the uniqueness proof above.

3. **$A_z$ is a finite set**: The negabinary representation of any integer is fi
nite (the algorithm terminates), so $S_z$ is finite, hence $A_z$ is a finite sub
set of $T$.

4. **$A_0 = \emptyset$ is the unique representation of 0**: The negabinary repre
sentation of 0 is all zeros, so $S_0 = \emptyset$ and $A_0 = \emptyset$. By uniq
ueness, no nonempty finite subset of $T$ sums to 0. In particular, $0 \notin T$
(since $(-2)^k \neq 0$ for all $k$). ✓
