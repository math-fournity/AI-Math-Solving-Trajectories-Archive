## 问题重述

设 $n \ge 3$ 为奇数，且对于 $n$ 的每个素因子 $p$，都有 $\gcd(p-1, n) = 1$。求满
足以下条件的 $(a,b,c) \in \mathbb{Z}_n^3$ 的三元组数量：$\gcd(a,b,c,n)=1$ 且存在
 $\{1,2,\dots,n\}$ 的一个排列 $(x_1,\dots,x_n)$ 使得对所有 $1 \le k \le n$（下标
模 $n$），有 $n \mid a x_{k+2} + b x_{k+1} + c x_k$。

## 答案

$$\boxed{n^2 \prod_{p \mid n}\left(1 - \frac{1}{p^2}\right)}$$

## 证明

**第 1 步：排列条件等价于循环卷积恒等式。**

设 $\zeta = e^{2\pi i/n}$。对于序列 $x = (x_1, \dots, x_n)$，定义其离散傅里叶变
换 (DFT) $\hat{x}_j = \sum_{k=1}^{n} x_k \zeta^{jk}$，其中 $j = 0, 1, \dots, n-1
$。线性递推 $a x_{k+2} + b x_{k+1} + c x_k \equiv 0 \pmod{n}$（循环地）等价于：
对于每个 $j$，

$$\hat{x}_j \cdot (a \zeta^{2j} + b \zeta^j + c) \equiv 0 \pmod{n}.$$

由于 $x$ 是 $\{1,\dots,n\}$ 的排列，我们有 $\hat{x}_0 = \sum_{k=1}^n k = \frac{n
(n+1)}{2}$，且对于 $j \ne 0$，$\hat{x}_j$ 是 $\zeta^j$ 的某个整数系数多项式。

**第 2 步：素数幂约简。**

由于 $\gcd(p-1, n) = 1$，特别地，对于不同的素因子 $p, q \mid n$，有 $p \nmid (q-
1)$，因此 $n$ 的素因子分解 $n = \prod p_i^{e_i}$ 满足：对于 $i \ne j$，有 $p_i \
nmid (p_j - 1)$。由中国剩余定理 (CRT)，该问题在 $\mathbb{Z}_{p_i^{e_i}}$ 上进行
分解。该条件对每个 $p_i^{e_i}$ 独立成立，且 $\gcd(a,b,c,n)=1$ 当且仅当对于每个 $
p_i$，$(a,b,c) \not\equiv (0,0,0) \pmod{p_i}$。

因此，满足条件的 $(a,b,c)$ 的数量为 $\prod_{p \mid n} N_p$，其中 $N_p$ 是满足 $(
a,b,c) \in \mathbb{Z}_{p^e}^3$，$(a,b,c) \not\equiv (0,0,0) \pmod p$，且存在 $\{
1,\dots,p^e\}$ 的排列使得循环递推成立的元组数量。

b,c) \in \mathbb{Z}_{p^e}^3$ 的数量为 $p^{3e} - p^{3e-2}$...
