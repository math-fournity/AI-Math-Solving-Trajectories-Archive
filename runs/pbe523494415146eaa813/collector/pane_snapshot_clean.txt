## Setup

**Condition for a group:** A group S of size k satisfies the condition if some e
lement x ∈ S equals the average, i.e., sum(S) = k·x for some x ∈ S.

## Set A (two trucks, n even)

Let m = n/2. Partition {1,...,n} into S₁, S₂ of size m. We need sum(S₁) = m·a (a
 ∈ S₁) and sum(S₂) = m·b (b ∈ S₂).

Since sum(S₁) + sum(S₂) = n(n+1)/2, we get **a + b = n+1**, with a ∈ S₁, b ∈ S₂,
 a ≠ b.

**Key observation for size-2 groups:** If a group has 2 distinct elements {p, q}
 with average equal to one of them, say p = (p+q)/2, then p = q — impossible. So
 any n with m = 2 (i.e., n = 4) fails.

**n = 2:** m = 1. Groups {1}, {2}. Each single element trivially equals its own
average. ✓ **A contains 2.**

**n = 4:** m = 2. Impossible as shown above. ✗
