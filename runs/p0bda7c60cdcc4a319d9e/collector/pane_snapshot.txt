## Solution

**Setup.** Place $A$ at the origin with the angle bisector $AD$ along the positi
ve $x$-axis, so $D = (1, 0)$. Since $\sin A = \frac{4}{5}$ and $A$ is acute, $\c
os A = \frac{3}{5}$. The half-angle values are:
$$\cos\frac{A}{2} = \frac{2}{\sqrt{5}}, \qquad \sin\frac{A}{2} = \frac{1}{\sqrt{
5}}.$$

Let $AB = m$, $AC = n$. Then:
$$B = \left(\frac{2m}{\sqrt{5}},\; \frac{m}{\sqrt{5}}\right), \qquad C = \left(\
frac{2n}{\sqrt{5}},\; -\frac{n}{\sqrt{5}}\right).$$

**Computing the key distances.**
$$BD^2 = \left(1 - \frac{2m}{\sqrt{5}}\right)^2 + \frac{m^2}{5} = 1 - \frac{4m}{
\sqrt{5}} + m^2,$$
$$CD^2 = 1 - \frac{4n}{\sqrt{5}} + n^2,$$
$$BC^2 = \frac{4(m-n)^2 + (m+n)^2}{5} = m^2 - \frac{6mn}{5} + n^2.$$

**Condition 1: $\angle BDC = 90°$** gives $BD^2 + CD^2 = BC^2$:
$$\left(1 - \frac{4m}{\sqrt{5}} + m^2\right) + \left(1 - \frac{4n}{\sqrt{5}} + n
^2\right) = m^2 - \frac{6mn}{5} + n^2,$$
$$\frac{6mn}{5} = \frac{4(m+n)}{\sqrt{5}} - 2 \quad\Longrightarrow\quad 6mn = 4\
sqrt{5}\,(m+n) - 10. \tag{I}$$

**Condition 2: $\frac{BD}{CD} = \frac{3}{2}$** gives $4\,BD^2 = 9\,CD^2$:
$$4m^2 - 9n^2 - \frac{16m}{\sqrt{5}} + \frac{36n}{\sqrt{5}} - 5 = 0. \tag{II}$$

**Solving the system.** Let $s = m+n$, $d = m-n$. From (I):
$$s^2 - d^2 = \frac{8\sqrt{5}\,s - 20}{3}. \tag{I'}$$

Substituting $m = \frac{s+d}{2}$, $n = \frac{s-d}{2}$ into (II) and simplifying:
$$5s^2 - 26sd + 5d^2 - 8\sqrt{5}\,s + \frac{104\sqrt{5}}{5}\,d + 20 = 0. \tag{II
'}$$

Using (I') to eliminate $d^2$ from (II') and solving for $d$:
$$d = \frac{5(3s - 4\sqrt{5})}{39}.$$

Substituting back into (I') yields a quadratic in $s$:
$$324s^2 - 864\sqrt{5}\,s + 2035 = 0,$$
with discriminant $468^2 \cdot 5$, giving:
$$s = \frac{37\sqrt{5}}{18} \quad \text{or} \quad s = \frac{11\sqrt{5}}{18}.$$

**Selecting the correct root.** Since $D$ is **outside** the triangle, $AD = 1$
must exceed the bisector length $AE$ to side $BC$, meaning the triangle is small
. The root $s = \frac{37\sqrt{5}}{18}$ gives a large triangle (with $AE > 1$, pl
acing $D$ inside), so we discard it. The valid solution is:
$$s = m + n = \frac{11\sqrt{5}}{18}, \qquad d = -\frac{5\sqrt{5}}{18}.$$

This gives $m = \frac{\sqrt{5}}{6}$, $n = \frac{4\sqrt{5}}{9}$.

**Verification.**
- $BD^2 = 1 - \frac{4}{6} + \frac{5}{36} = \frac{17}{36}$, $\;CD^2 = 1 - \frac{1
6}{9} + \frac{80}{81} = \frac{17}{81}$. Ratio: $\frac{BD^2}{CD^2} = \frac{81}{36
} = \frac{9}{4}$ ✓
- $BD^2 + CD^2 = \frac{17}{36} + \frac{17}{81} = \frac{221}{324} = BC^2$ ✓ (righ
t angle confirmed)
- $\sin A = 2 \cdot \frac{1}{\sqrt{5}} \cdot \frac{2}{\sqrt{5}} = \frac{4}{5}$,
$\cos A = \frac{3}{5} > 0$ (acute) ✓

**Result.** $AB + AC = \frac{11\sqrt{5}}{18}$, in the form $\frac{a\sqrt{b}}{c}$
 with $a = 11$, $b = 5$, $c = 18$. These are pairwise relatively prime ($\gcd(11
,5) = \gcd(11,18) = \gcd(5,18) = 1$).

$$a + b + c = 11 + 5 + 18 = \boxed{34}$$
