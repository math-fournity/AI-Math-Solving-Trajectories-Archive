## Solution

**Interpreting the problem:** The phrase "all polygons" with a fixed perimeter,
seeking a maximum area expressible as $\frac{a\sqrt{b}}{c}$, corresponds to the
classical isoperimetric problem for **triangles** (the only fixed-side-count int
erpretation consistent with the required answer form). I solve it for triangles
with perimeter $20$.

---

**Setup.** Let the triangle have side lengths $a, b, c > 0$ with $a + b + c = 20
$, and semi-perimeter $s = 10$. By Heron's formula,

$$A = \sqrt{s(s-a)(s-b)(s-c)} = \sqrt{10(10-a)(10-b)(10-c)}.$$

**Applying AM–GM.** Note that
$$(10-a) + (10-b) + (10-c) = 30 - (a+b+c) = 30 - 20 = 10.$$
All three terms $10-a,\, 10-b,\, 10-c$ are positive (triangle inequality gives e
ach side $< 10$). By the AM–GM inequality,

$$(10-a)(10-b)(10-c) \le \left(\frac{(10-a)+(10-b)+(10-c)}{3}\right)^3 = \left(\
frac{10}{3}\right)^3 = \frac{1000}{27},$$

with equality if and only if $10-a = 10-b = 10-c$, i.e., $a = b = c = \tfrac{20}
{3}$ (the equilateral triangle).

**Bounding the area.** Therefore

$$A \le \sqrt{10 \cdot \frac{1000}{27}} = \sqrt{\frac{10000}{27}} = \frac{100}{\
sqrt{27}} = \frac{100}{3\sqrt{3}} = \frac{100\sqrt{3}}{9}.$$

Equality is attained by the equilateral triangle of side $\tfrac{20}{3}$, whose
area is

$$A = \frac{\sqrt{3}}{4}\left(\frac{20}{3}\right)^2 = \frac{\sqrt{3}}{4}\cdot\fr
ac{400}{9} = \frac{100\sqrt{3}}{9}.$$

**Extracting $a, b, c$.** We have

$$A = \frac{100\sqrt{3}}{9}, \qquad a = 100,\; b = 3,\; c = 9.$$

Check the conditions:
- $b = 3$ is square-free (not divisible by the square of any prime). ✓
- $\gcd(a, c) = \gcd(100, 9) = 1$. ✓

**Final answer.**

$$a + b + c = 100 + 3 + 9 = \boxed{112}.$$
