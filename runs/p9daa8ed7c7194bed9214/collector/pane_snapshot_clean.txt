**第 1 步：直线 MN 的方程。**

点 $M(m, m^2)$ 和 $N(n, n^2)$ 位于抛物线 $y = x^2$ 上。直线 $MN$ 的斜率为 $\frac
{n^2 - m^2}{n - m} = m + n$，因此直线方程为：

$$y = (m+n)x - mn, \quad \text{i.e.,}\quad (m+n)x - y - mn = 0.$$

**第 2 步：利用韦达定理。**

对于 $\sin\theta\, x^2 + \cos\theta\, x - 1 = 0$，有 $m + n = -\frac{\cos\theta}
{\sin\theta}$ 和 $mn = -\frac{1}{\sin\theta}$（其中 $\sin\theta \neq 0$）。

**第 3 步：从原点到直线 $MN$ 的距离。**

$$\text{dist} = \frac{|mn|}{\sqrt{(m+n)^2 + 1}} = \frac{1/|\sin\theta|}{\sqrt{\c
os^2\theta/\sin^2\theta + 1}} = \frac{1/|\sin\theta|}{\sqrt{1/\sin^2\theta}} = \
frac{1/|\sin\theta|}{1/|\sin\theta|} = 1.$$

**第 4 步：确定 $d$。**

圆 $O: x^2 + y^2 = 1$ 的圆心在原点，半径为 $1$。由于从圆心到直线 $MN$ 的距离等于
半径，**直线 $MN$ 与圆 $O$ 相切**。因此，圆上点到直线的距离范围从 $0$（切点）到
$2$（对径点），所以：

$$d = 2, \quad \text{hence}\quad abc + b^2 + c^2 = 4d = 8.$$

**第 5 步：最大化目标函数。**

$$\log_4 a + \log_2 b + \log_2 c = \tfrac{1}{2}\log_2 a + \log_2(bc) = \log_2\!\
big(\sqrt{a}\cdot bc\big).$$

设 $t = \sqrt{a} > 0$ 且 $u = bc > 0$。约束条件变为 $t^2 u + b^2 + c^2 = 8$。

根据 AM-GM 不等式，$b^2 + c^2 \ge 2bc = 2u$，当且仅当 $b = c$ 时等号成立。因此：

$$8 = t^2 u + b^2 + c^2 \ge t^2 u + 2u = u(t^2 + 2) \implies u \le \frac{8}{t^2+
2}.$$

因此 $\sqrt{a}\cdot bc = tu \le \frac{8t}{t^2+2}$。通过求导最大化 $f(t) = \frac{
8t}{t^2+2}$：

$$f'(t) = \frac{8(2 - t^2)}{(t^2+2)^2} = 0 \implies t = \sqrt{2}, \quad f(\sqrt{
2}) = \frac{8\sqrt{2}}{4} = 2\sqrt{2}.$$

当 $t = \sqrt{2}$（即 $a = 2$）且 $b = c$ 时等号成立，此时 $u = \frac{8}{4} = 2$
，因此 $b = c = \sqrt{2}$。

验证：$abc + b^2 + c^2 = 2\cdot\sqrt{2}\cdot\sqrt{2} + 2 + 2 = 4 + 4 = 8$. ✓
