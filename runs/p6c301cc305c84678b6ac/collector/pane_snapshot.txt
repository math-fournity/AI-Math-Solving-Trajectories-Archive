## Solution

We seek the last 5 digits of \(N = 2003^{(2005^{2007})}\), i.e. \(N \bmod 10^5\)
. Since \(10^5 = 32 \times 3125\) with \(\gcd(32,3125)=1\), we compute \(N \bmod
 32\) and \(N \bmod 3125\) separately, then recombine via CRT.

Let \(E = 2005^{2007}\).

### Step 1: \(N \bmod 32\)

\(2003 \equiv 19 \pmod{32}\). Compute the order of \(19\) mod \(32\):
- \(19^2 = 361 \equiv 9\)
- \(19^4 \equiv 9^2 = 81 \equiv 17\)
- \(19^8 \equiv 17^2 = 289 \equiv 1 \pmod{32}\)

So the order divides \(8\). Reduce \(E \bmod 8\): \(2005 \equiv 5 \pmod 8\), and
 \(5^2 \equiv 1\), so \(5^{2007} \equiv 5 \pmod 8\) (odd exponent). Thus \(E \eq
uiv 5 \pmod 8\).

\[
2003^E \equiv 19^{8k+5} \equiv 19^5 = 19^4\cdot 19 \equiv 17\cdot 19 = 323 \equi
v 3 \pmod{32}.
\]

So \(N \equiv 3 \pmod{32}\).

### Step 2: \(N \bmod 3125\)

\(\varphi(3125) = 3125 - 625 = 2500\), and \(\gcd(2003,3125)=1\) (since \(5\nmid
 2003\)), so \(2003^{2500}\equiv 1\pmod{3125}\). Reduce \(E \bmod 2500\).

\(2500 = 4\times 625\). Since \(2005 = 5\cdot 401\), the power \(2005^{2007}\) i
s divisible by \(5^{2007}\), hence by \(625\): \(E\equiv 0\pmod{625}\). Also \(2
005\equiv 1\pmod 4\), so \(E\equiv 1\pmod 4\). CRT gives \(E\equiv 625\pmod{2500
}\) (since \(625\equiv 1\pmod 4\)).

Thus \(N \equiv 2003^{625}\pmod{3125}\). Repeated squaring (with \(a=2003\)):

| power | value mod 3125 |
|---|---|
| \(a^1\) | 2003 |
| \(a^2\) | \(2003^2=4012009\equiv 2634\) |
| \(a^4\) | \(2634^2\equiv 491^2=241081\equiv 456\) |
| \(a^8\) | \(456^2=207936\equiv 1686\) |
| \(a^{16}\) | \(1686^2=2842596\equiv 1971\) |
| \(a^{32}\) | \(1971^2=3884841\equiv 466\) |
| \(a^{64}\) | \(466^2=217156\equiv 1531\) |
| \(a^{128}\) | \(1531^2=2343961\equiv 211\) |
| \(a^{256}\) | \(211^2=44521\equiv 771\) |
| \(a^{512}\) | \(771^2=594441\equiv 691\) |

Since \(625 = 512+64+32+16+1\):

\[
a^{625} \equiv 691\cdot 1531\cdot 466\cdot 1971\cdot 2003 \pmod{3125}.
\]

Multiplying stepwise:
- \(691\cdot 1531 = 1057921 \equiv 1671\)
- \(1671\cdot 466 = 778686 \equiv 561\)
- \(561\cdot 1971 = 1105731 \equiv 2606\)
- \(2606\cdot 2003 = 5219818 \equiv 1068\)

So \(N \equiv 1068 \pmod{3125}\).

### Step 3: CRT recombination

Find \(N\) with \(N\equiv 3\pmod{32}\) and \(N\equiv 1068\pmod{3125}\). Write \(
N = 1068 + 3125k\). Then
\[
1068 + 3125k \equiv 3 \pmod{32}.\]
\(1068\equiv 12\), \(3125\equiv 21\pmod{32}\), so \(21k\equiv -9\equiv 23\pmod{3
2}\). The inverse of \(21\) mod \(32\) is \(29\) (since \(21\cdot 29=609\equiv 1
\)). Thus
\[
k \equiv 23\cdot 29 = 667 \equiv 27 \pmod{32}.
\]
Taking \(k=27\):
\[
N = 1068 + 3125\cdot 27 = 1068 + 84375 = 85443.
\]

Verification: \(85443 \bmod 32 = 85443 - 32\cdot 2670 = 85443-85440 = 3\) ✓; \(8
5443 \bmod 3125 = 85443 - 3125\cdot 27 = 1068\) ✓.

### Answer

The last 5 digits of \(2003^{(2005^{2007})}\) are \(\boxed{85443}\).
