## Setting Up the Quadratic Structure

Since α satisfies α² + pα + q = 0 with integer p, q, every power reduces to αᵏ =
 cₖα + dₖ (integer coefficients). For a sum to be an integer, the α-coefficient
must vanish: ∑ aₖcₖ = 0, and then n = a₀ + ∑ aₖdₖ.

The recurrence is: c₁=1, d₁=0; c₂=−p, d₂=−q; and c_{k+1} = dₖ − p·cₖ, d_{k+1} =
−q·cₖ.

## Determining the Base

With only the 1-ruble coin (digits 0–6), we make integers 0 through 6. To make *
*7**, we need non-1 coins to produce an integer with zero α-coefficient.

The simplest representation: a₂=1 coin of α² and a₁=p coins of α, giving integer
 value −q·1 = −q, with α-coefficient −p·1 + p = 0. So the smallest representable
 integer from non-1 coins is m = −q.

**Coverage requirement:** The intervals [km, km+6] must cover all integers ≥ 0,
requiring m ≤ 7. Also m ≥ 7 is needed (since 7 must be reachable and 0–6 only gi
ves up to 6), so **m = 7**, meaning **q = −7**.

## Verifying the Representation System

The key identity: **α + α² = 7**, so **7αᵏ = αᵏ⁺¹ + αᵏ⁺²**.

This gives the **carry rule**: 7 coins at position k → 1 coin at k+1 and 1 coin
at k+2.

**Termination:** Each carry reduces total coin count by exactly 5 (remove 7, add
 2). Since the count is always non-negative, the process terminates in finitely
many steps, producing all digits in {0,...,6}.

**Completeness:** Starting from n ones (a₀ = n, α-coefficient = 0), repeated car
rying produces a valid representation for every natural number n. The carry pres
erves both the integer value and the zero α-coefficient.
