## Proof

**Yes, it is possible.** We construct an explicit example.

**Setup.** Let $X = \mathbb{N}$ and $\mathcal{A} = 2^{\mathbb{N}}$, which is an
algebra closed under finite intersection, union, and complements, and contains $
\emptyset$.

**Free ultrafilter measure.** Let $\mathcal{U}$ be a free (non-principal) ultraf
ilter on $\mathbb{N}$. Recall that a free ultrafilter exists by Zorn's lemma app
lied to the Fréchet filter (the filter of cofinite sets). Define
$$\mu(A) = \begin{cases} 1 & \text{if } A \in \mathcal{U}, \\ 0 & \text{if } A \
notin \mathcal{U}. \end{cases}$$

**Claim:** $\mu$ is a finitely additive probability measure on $\mathcal{A}$ wit
h $\mu(X)=1$.

*Proof of claim.* Since $X \in \mathcal{U}$, we have $\mu(X)=1$, and $\emptyset
\notin \mathcal{U}$ gives $\mu(\emptyset)=0$. For finite additivity, let $A, B$
be disjoint. An ultrafilter has the property that for any set $S$, exactly one o
f $S, S^c$ belongs to $\mathcal{U}$.

- If $A \in \mathcal{U}$ and $B \in \mathcal{U}$, then $A \cap B \in \mathcal{U}
$, but $A \cap B = \emptyset \notin \mathcal{U}$, contradiction. So at most one
of $A, B$ lies in $\mathcal{U}$.
- If $A \in \mathcal{U}$ and $B \notin \mathcal{U}$: then $B^c \in \mathcal{U}$,
 so $A \cap B^c = A \setminus B = A \in \mathcal{U}$. Since $A \subseteq A \cup
B$, upward closure gives $A \cup B \in \mathcal{U}$. Thus $\mu(A \cup B) = 1 = 1
 + 0 = \mu(A) + \mu(B)$. ✓
- If neither $A$ nor $B$ is in $\mathcal{U}$: then $A^c, B^c \in \mathcal{U}$, s
o $(A \cup B)^c = A^c \cap B^c \in \mathcal{U}$, hence $A \cup B \notin \mathcal
{U}$. Thus $\mu(A \cup B) = 0 = 0 + 0 = \mu(A) + \mu(B)$. ✓

By induction, $\mu$ is finitely additive. $\square$

**The decreasing sequence.** Define $A_n = \{n, n+1, n+2, \dots\}$ for $n \geq 1
$. Then $A_1 \supset A_2 \supset \cdots$ and
$$\bigcap_{n=1}^{\infty} A_n = \emptyset,$$
since no natural number belongs to every tail.

**Key point: each $A_n \in \mathcal{U}$.** Because $\mathcal{U}$ is *free*, it c
ontains every cofinite set (the Fréchet filter is contained in every free ultraf
ilter). Each $A_n$ is cofinite (its complement $\{1, \dots, n-1\}$ is finite), s
o $A_n \in \mathcal{U}$, giving $\mu(A_n) = 1$ for every $n$.

**Conclusion.** Therefore
$$\lim_{n \to \infty} \mu(A_n) = \lim_{n \to \infty} 1 = 1 \neq 0,$$
while $\bigcap_n A_n = \emptyset$.

This shows that for a merely finitely additive measure, continuity from above at
 $\emptyset$ (equivalently, countable additivity) can fail: the limit of the mea
sures can remain strictly positive even as the sets shrink to nothing. $\blacksq
uare$
