Looking at this problem, I need to find polynomials $P(x) = ax^2 + bx$ with $0 \
le a,b < M$ (where $M = 2010^{18}$) such that for every $n \in \{0, \ldots, M-1\
}$, there exists $Q(x) = cx^2 + dx$ with $Q(P(n)) \equiv n \pmod{M}$.

## Step 1: Reformulating the Condition

For fixed $n$, the set $\{c \cdot P(n)^2 + d \cdot P(n) \pmod{M} : c,d \in \math
bb{Z}/M\mathbb{Z}\}$ is the ideal generated by $P(n)$ in $\mathbb{Z}/M\mathbb{Z}
$, which equals $\gcd(P(n), M) \cdot \mathbb{Z}/M\mathbb{Z}$.

So $P$ is good iff for all $n \in \{0, \ldots, M-1\}$: $\gcd(P(n), M) \mid n$.

## Step 2: Prime Decomposition

Since $M = 2010^{18} = 2^{18} \cdot 3^{18} \cdot 5^{18} \cdot 67^{18}$, the cond
ition $\gcd(P(n), M) \mid n$ decomposes via CRT into: for each prime $p \mid M$
and all $n$:
$$\min(v_p(P(n)), 18) \le v_p(n)$$

Since $P(n) = n(an+b)$, we have $v_p(P(n)) = v_p(n) + v_p(an+b)$.

- **If $v_p(n) \ge 18$:** $\min(v_p(n) + v_p(an+b), 18) = 18 \le v_p(n)$. ✓ (aut
omatic)
- **If $v_p(n) < 18$:** we need $v_p(n) + v_p(an+b) \le v_p(n)$, i.e., $v_p(an+b
) \le 0$, i.e., $p \nmid (an+b)$.

**The condition becomes:** For each prime $p \mid M$ and all $n$ with $v_p(n) <
18$: $p \nmid (an+b)$.

## Step 3: Determining Conditions on $a, b$

**Case $p \nmid a$:** The congruence $an + b \equiv 0 \pmod{p}$ has a unique sol
ution $n_0 \equiv -ba^{-1} \pmod{p}$.
- If $p \nmid b$: $n_0 \not\equiv 0 \pmod{p}$, so $v_p(n_0) = 0 < 18$ and $p \mi
d (an_0 + b)$. Condition **fails**.
- If $p \mid b$: $n_0 \equiv 0 \pmod{p}$. Take $n = p$ (with $v_p(p) = 1 < 18$):
 since $p \mid a$ is false but $p \mid ap$ and $p \mid b$, we get $p \mid (ap +
b)$. Condition **fails**.

**Case $p \mid a$, $p \mid b$:** Then $an + b \equiv 0 \pmod{p}$ for all $n$. Ta
king $n = 1$ (with $v_p(1) = 0 < 18$): $p \mid (a+b)$. Condition **fails**.

**Case $p \mid a$, $p \nmid b$:** Then $an + b \equiv b \not\equiv 0 \pmod{p}$ f
or all $n$. Condition **holds**. ✓

**Conclusion:** For each prime $p \in \{2, 3, 5, 67\}$, we need $p \mid a$ and $
p \nmid b$.

## Step 4: Counting

The conditions across the four distinct primes are independent (by CRT).

**Counting valid $a$:** Need $2010 \mid a$ with $0 \le a < 2010^{18}$. The multi
ples of $2010$ in this range are $0, 2010, 2\cdot2010, \ldots, (2010^{17}-1)\cdo
t2010$, giving $2010^{17}$ values.

**Counting valid $b$:** Need $\gcd(b, 2010) = 1$ with $0 \le b < 2010^{18}$. The
 count is:
$$2010^{18} \cdot \frac{\varphi(2010)}{2010} = 2010^{17} \cdot \varphi(2010)$$

Computing $\varphi(2010) = \varphi(2)\varphi(3)\varphi(5)\varphi(67) = 1 \cdot 2
 \cdot 4 \cdot 66 = 528$.

So valid $b$ count: $2010^{17} \cdot 528$.

## Step 5: Final Answer

Total good polynomials:
$$2010^{17} \times 2010^{17} \times 528 = 528 \cdot 2010^{34}$$

**Verification with small case:** For $M = 2010$ (exponent 1), the analysis give
s $a = 0$ only, and $b$ coprime to $2010$ (528 values). With $a=0$, $P(n) = bn$,
 and $\gcd(bn, 2010) = \gcd(n, 2010) \mid n$ when $\gcd(b, 2010) = 1$. ✓

The number of good polynomials is $\boxed{528 \cdot 2010^{34}}$.
