**Problem.** Find constant $a$ such that $M(t) = (aB(t) - t)\exp(2B(t) - 2t)$ is
 a martingale, where $B(t)$ is a standard Brownian motion.

---

## Proof

Define the function
$$f(b, t) = (ab - t)\,e^{2b - 2t},$$
so that $M(t) = f(B(t), t)$. We apply Itô's lemma. Since $dB(t)^2 = dt$, we have
$$dM(t) = f_b\,dB(t) + \left(f_t + \tfrac{1}{2}f_{bb}\right)dt.$$

For $M$ to be a (local) martingale, the drift term must vanish identically, i.e.
$$f_t + \tfrac{1}{2}f_{bb} = 0 \quad\text{for all } (b,t).$$

**Compute the partial derivatives.** Writing $E = e^{2b-2t}$ for brevity:

- $f_b = aE + (ab - t)\cdot 2E = E\bigl[a + 2(ab - t)\bigr] = E\bigl[a + 2ab - 2
t\bigr].$
- $f_t = -E + (ab - t)\cdot(-2)E = E\bigl[-1 - 2(ab - t)\bigr] = E\bigl[-1 - 2ab
 + 2t\bigr].$
- $f_{bb} = \partial_b\bigl(E[a + 2ab - 2t]\bigr) = 2E[a + 2ab - 2t] + E\cdot 2a
 = E\bigl[2a + 4ab - 4t + 2a\bigr] = E\bigl[4a + 4ab - 4t\bigr].$

**Form the drift.**
$$f_t + \tfrac{1}{2}f_{bb} = E\bigl[-1 - 2ab + 2t\bigr] + \tfrac{1}{2}E\bigl[4a
+ 4ab - 4t\bigr]$$
$$= E\bigl[-1 - 2ab + 2t + 2a + 2ab - 2t\bigr] = E\bigl[-1 + 2a\bigr].$$

Since $E = e^{2b-2t} > 0$ for all $(b,t)$, the drift vanishes identically if and
 only if
$$-1 + 2a = 0 \quad\Longrightarrow\quad a = \tfrac{1}{2}.$$

**It remains to confirm $M$ is a true martingale (not merely a local one).** Wit
h $a = \tfrac{1}{2}$,
$$M(t) = \left(\tfrac{1}{2}B(t) - t\right)e^{2B(t) - 2t},$$
and the Itô integrand is
$$f_b(B(t),t) = e^{2B(t)-2t}\bigl[\tfrac{1}{2} + B(t) - 2t\bigr].$$
On every finite interval $[0,T]$, $B(t) \sim \mathcal{N}(0,t)$ with $t \le T$, a
nd $e^{2B(t)-2t}$ is the exponential of a Gaussian. The product of a polynomial
in $B(t)$ with an exponential of a Gaussian has finite moments of every order on
 bounded time intervals (Gaussian tails dominate polynomial growth, and the expo
nential-of-Gaussian has finite expectation since $2B(t)-2t$ has negative drift).
 Concretely, for $b \sim \mathcal{N}(0,t)$,
$$\mathbb{E}\bigl[e^{4b}\bigr] = e^{8t} < \infty,$$
so $\mathbb{E}\bigl[e^{2B(t)-2t}\bigr]^2 = e^{-4t}\,e^{4t}\cdot e^{4t}$ is finit
e, and similarly all polynomial–exponential mixed moments are finite. Hence
$$\mathbb{E}\!\left[\int_0^T f_b(B(s),s)^2\,ds\right] < \infty,$$
so the Itô integral $\int_0^t f_b\,dB$ is a true martingale, and therefore $M(t)
$ is a true martingale.

## Conclusion

The unique constant making $M(t) = (aB(t) - t)\exp(2B(t) - 2t)$ a martingale is

$$\boxed{a = \dfrac{1}{2}}.$$
