## Proof

**Claim:** Not every Baire function $f: \mathbb{R} \to \mathbb{N}$ is constant.

**Counterexample.** Define $f: \mathbb{R} \to \mathbb{N}$ by
$$f(x) = \begin{cases} 0 & \text{if } x \le 0, \\ 1 & \text{if } x > 0. \end{cas
es}$$
This function is not constant (e.g. $f(-1)=0 \ne 1 = f(1)$). We show it is a Bai
re function.

**$f$ is a Baire function.** For each $n \ge 1$, define $g_n: \mathbb{R} \to \ma
thbb{R}$ by
$$g_n(x) = \min\bigl(1,\; \max(0,\; nx)\bigr).$$
Each $g_n$ is continuous (it is a composition of continuous functions: $x \mapst
o nx$, then clamp to $[0,1]$). We claim $g_n \to f$ pointwise.

- If $x > 0$: for all $n$ large enough, $nx \ge 1$, so $g_n(x) = 1$. Hence $\lim
_{n\to\infty} g_n(x) = 1 = f(x)$.
- If $x \le 0$: $nx \le 0$, so $g_n(x) = 0$ for every $n$. Hence $\lim_{n\to\inf
ty} g_n(x) = 0 = f(x)$.

Thus $f$ is the pointwise limit of the sequence of continuous functions $(g_n)$.
 Since the class of Baire functions contains all continuous functions and is clo
sed under pointwise limits, $f$ is a Baire function (in fact, of Baire class $1$
).

**Conclusion.** We have exhibited a non-constant Baire function $f: \mathbb{R} \
to \mathbb{N}$. Therefore, it is **not** the case that every Baire function $\ma
thbb{R} \to \mathbb{N}$ must be constant. $\blacksquare$
