## Proof

We compute $\operatorname{Cov}(Y, X)$ where
$$Y = \int_0^{2} B(s)\,ds, \qquad X = B(2).$$

**Step 1: Means vanish.** Since Brownian motion has $\mathbb{E}[B(t)] = 0$ for a
ll $t \geq 0$,
$$\mathbb{E}[Y] = \int_0^{2} \mathbb{E}[B(s)]\,ds = 0, \qquad \mathbb{E}[X] = \m
athbb{E}[B(2)] = 0.$$

Hence
$$\operatorname{Cov}(Y, X) = \mathbb{E}[Y X] - \mathbb{E}[Y]\mathbb{E}[X] = \mat
hbb{E}[Y X].$$

**Step 2: Exchange expectation and integration.** Using Fubini's theorem (justif
ied since $B$ has continuous paths and the interval is compact),
$$\mathbb{E}[Y X] = \mathbb{E}\!\left[\int_0^{2} B(s)\,ds \cdot B(2)\right] = \i
nt_0^{2} \mathbb{E}[B(s) B(2)]\,ds.$$

**Step 3: Apply the covariance kernel of Brownian motion.** For standard Brownia
n motion,
$$\mathbb{E}[B(s) B(t)] = \min(s, t).$$

For $s \in [0, 2]$, we have $\min(s, 2) = s$, so
$$\mathbb{E}[B(s) B(2)] = \min(s, 2) = s.$$

**Step 4: Evaluate the integral.**
$$\operatorname{Cov}(Y, X) = \int_0^{2} s\,ds = \left[\frac{s^2}{2}\right]_0^{2}
 = \frac{4}{2} = 2.$$

**Conclusion.**

$$\boxed{\operatorname{Cov}(Y, X) = \operatorname{Cov}\!\left(\int_0^{2} B(s)\,d
s,\; B(2)\right) = 2.}$$
