## Proof

Let $A = (X^2) \subseteq \mathbb{C}[X]$, the ideal generated by $X^2$.

**Compute $Z(A)$.** A polynomial $g \in A$ has the form $g = X^2 h$ for some $h
\in \mathbb{C}[X]$, so every $g \in A$ vanishes at $X = 0$. Conversely, $0$ is a
 zero of $X^2 \in A$. Hence
$$Z(A) = \{0\}.$$

**Compute $I(Z(A))$.** By definition,
$$I(Z(A)) = \{f \in \mathbb{C}[X] : f(z) = 0 \text{ for all } z \in Z(A)\} = \{f
 \in \mathbb{C}[X] : f(0) = 0\}.$$
A polynomial vanishes at $0$ if and only if it is divisible by $X$. Therefore
$$I(Z(A)) = (X).$$

**Verify $A \subseteq I(Z(A))$.** Every element of $A$ is of the form $X^2 h = X
 \cdot (Xh)$, which is a multiple of $X$, hence lies in $(X) = I(Z(A))$. So $A \
subseteq I(Z(A))$.

**Verify the containment is strict.** The polynomial $X$ belongs to $I(Z(A)) = (
X)$, since $X(0) = 0$. However, $X \notin A = (X^2)$: if $X = X^2 h$ for some $h
 \in \mathbb{C}[X]$, then comparing degrees forces $\deg h = -1$, which is impos
sible for a polynomial. Equivalently, $X^2 \nmid X$ in $\mathbb{C}[X]$.

Thus $X \in I(Z(A)) \setminus A$, proving
$$A = (X^2) \subsetneq (X) = I(Z(A)).$$
