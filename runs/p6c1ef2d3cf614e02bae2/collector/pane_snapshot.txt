## Proof

The rotation group of the tetrahedron is isomorphic to $A_4$, the alternating gr
oup on 4 letters (the 4 vertices). It has order $12 = 2^2 \cdot 3$.

### Conjugacy classes of $A_4$

Label the vertices $1,2,3,4$. The elements of $A_4$ are:

- **Identity** $e$: 1 element.
- **Eight 3-cycles** (order 3): rotations by $\pm120°$ about the 4 axes through
a vertex and the centroid of the opposite face. In $S_4$ these form one class of
 size 8; in $A_4$ the centralizer of a 3-cycle has order 3, so each $A_4$-class
has size $12/3 = 4$. They split into two conjugacy classes of size 4:
$$C_3 = \{(123),(134),(243),(142)\}, \qquad C_3' = \{(132),(143),(234),(124)\}.$
$
- **Three double transpositions** (order 2): $(12)(34),(13)(24),(14)(23)$, the $
180°$ rotations about the 3 axes through midpoints of opposite edges. These form
 a single conjugacy class of size 3 (centralizer in $A_4$ has order 4, so class
size $12/4=3$).

So the conjugacy classes have sizes $1,\,3,\,4,\,4$ (summing to 12). ✓

### Determining the normal subgroups

A normal subgroup is a union of whole conjugacy classes containing $\{e\}$, and
its order must divide $|A_4|=12$. The possible orders are $1,2,3,4,6,12$; we che
ck which can be realized as $1 + (\text{sum of some of } \{3,4,4\})$:

| Order | Needed beyond $\{e\}$ | Achievable? |
|---|---|---|
| 1 | 0 | Yes → $\{e\}$ |
| 2 | 1 | No (no class of size 1 other than $\{e\}$) |
| 3 | 2 | No (no way to make 2 from $\{3,4,4\}$) |
| 4 | 3 | Yes: take the class of size 3 |
| 6 | 5 | No (cannot make 5 from $\{3,4,4\}$) |
| 12 | 11 | Yes: $3+4+4=11$ → whole group |

This leaves exactly three candidates, each of which is indeed a subgroup:

1. **$\{e\}$** — trivially a normal subgroup.
2. **$V = \{e,\,(12)(34),\,(13)(24),\,(14)(23)\}$** — the Klein four-group $V_4$
. It is a union of classes $\{e\}\cup\{\text{double transpositions}\}$, hence no
rmal. It is a subgroup since every nonidentity element has order 2 and the produ
ct of any two distinct ones gives the third.
3. **$A_4$ itself** — normal.

No other union of conjugacy classes yields a subgroup, so these are **all** the
normal subgroups.

### Corresponding quotient groups

1. $A_4/\{e\} \cong A_4$ (order 12).
2. $A_4/V$: order $12/4 = 3$, hence cyclic, so $A_4/V \cong \mathbb{Z}_3$. (Geom
etrically, the 4 vertex-to-face axes give rotations of order 3; modulo the $180°
$ edge-rotations in $V$, these collapse to a single cyclic structure of order 3.
)
3. $A_4/A_4 \cong \{e\}$ (trivial group).

### Summary

| Normal subgroup | Geometric description | Quotient |
|---|---|---|
| $\{e\}$ | identity only | $A_4$ |
| $V_4=\{e,(12)(34),(13)(24),(14)(23)\}$ | identity + the three $180°$ rotations
 about axes through midpoints of opposite edges | $\mathbb{Z}_3$ |
| $A_4$ | the whole rotation group | $\{e\}$ |

These are all the normal subgroups of the rotation group of the tetrahedron, and
 the corresponding quotient groups are $A_4$, $\mathbb{Z}_3$, and the trivial gr
oup respectively.
