# Solution

## Setup

The curve is $C: y^2z = x^3 - xz^2$ in $\mathbb{P}^2$, and $P = (0:0:1)$. The ra
tional map $\phi(x:y:z) = (x:y)$ is undefined at $P$ since $x = y = 0$ there. We
 restrict to $C$ and extend to a morphism $\psi: C \to \mathbb{P}^1$.

## Local analysis at $P$

Work in the affine chart $z = 1$. The curve becomes
$$y^2 = x^3 - x = x(x-1)(x+1),$$
and $P = (0,0)$.

**Smoothness check:** $\nabla(y^2 - x^3 + x) = (-3x^2+1,\; 2y)$, which at $(0,0)
$ equals $(1, 0) \neq (0,0)$. So $P$ is smooth, confirming $\psi$ extends.

**Tangent line:** The linear term of $y^2 - x^3 + x$ at $P$ is $x$, so the tange
nt line is $x = 0$ (the $y$-axis).

**Vanishing orders:** Since the tangent is $x = 0$, the function $x$ vanishes to
 order $\geq 2$ along $C$ at $P$, while $y$ (transverse to the tangent) vanishes
 to order 1 and serves as a **uniformizer** (local parameter).

From the curve equation: $y^2 = x(x^2 - 1)$. Near $P$, the factor $x^2 - 1$ eval
uates to $-1 \neq 0$, so it is a unit in the local ring $\mathcal{O}_{C,P}$. The
refore
$$x = \frac{y^2}{x^2 - 1} = y^2 \cdot u, \qquad u \in \mathcal{O}_{C,P}^{\times}
,$$
confirming $\operatorname{ord}_P(x) = 2$ and $\operatorname{ord}_P(y) = 1$.

## Evaluating $\psi(P)$

The morphism $\psi = (x : y)$ can be evaluated at $P$ by choosing the chart on $
\mathbb{P}^1$ where the second coordinate is nonzero, i.e., writing
$$\psi = \left(\frac{x}{y} : 1\right).$$

Using $x = y^2/(x^2-1)$:
$$\frac{x}{y} = \frac{y}{x^2 - 1}.$$

At $P$, $x^2 - 1 = -1$ (a unit), so $x/y = -y$ in the local ring, which vanishes
 to order 1. Thus
$$\psi(P) = \left(\frac{x}{y}(P) : 1\right) = (0 : 1).$$

**Cross-check via the other chart:** Writing $\psi = (1 : y/x)$, we get $y/x = (
x^2-1)/y$, which has a simple pole at $P$ (value $\to \infty$). So $(1 : y/x) \t
o (1 : \infty) = (0:1)$. Consistent.

**Cross-check via parametrization:** Set $y = t$ as uniformizer. Then $t^2 = x^3
 - x$ gives $x \approx -t^2$ for small $t$, so $x : y \approx -t^2 : t = -t : 1
\to 0 : 1$ as $t \to 0$.

## Conclusion

$$\boxed{\psi(P) = (0 : 1)}$$
