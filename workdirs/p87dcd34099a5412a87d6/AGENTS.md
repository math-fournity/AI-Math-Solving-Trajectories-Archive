# Problem

In a specialized logistics warehouse, there is a long, straight automated track. Currently, there are only two active docking beacons installed: one at the **0-meter** mark and one at the **1-meter** mark.

The facility uses a robotic arm to install new beacons. To place a new beacon, the robot must select two existing beacons, located at positions $a$ and $b$, and swing a new marker to the position $2b - a$ (effectively reflecting the position of $a$ across $b$). Each time the robot performs this action, it counts as exactly one deployment operation.

The management wants to expand the track's reach to include beacons at the **100-meter** mark and the **-100-meter** mark. Let $f(n)$ represent the minimum number of deployment operations required to mark a beacon at the integer position $n$ starting from the original two beacons.

Calculate the value of $f(100) + f(-100)$.
