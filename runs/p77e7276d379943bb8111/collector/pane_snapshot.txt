Looking at this problem, I need to determine whether a continuous function $f$ o
n $\mathbb{R}^2$ with zero integral over every area-1 rectangle must be identica

**Proof.**

Assume rectangles are axis-aligned (the weaker condition; if it holds here, it h
olds for arbitrary orientations too). The condition states: for all $x_0, y_0 \i
n \mathbb{R}$ and $a > 0$ (with $b = 1/a$),

$$\int_{x_0}^{x_0+a}\int_{y_0}^{y_0+1/a} f(x,y)\,dy\,dx = 0. \tag{1}$$

**Step 1: Differentiate to obtain a pointwise condition.**

Since $f$ is continuous, define $G(x_0,y_0,a) = \int_{x_0}^{x_0+a}\int_{y_0}^{y_
0+1/a} f$. By Leibniz's rule, $G$ is smooth in its parameters and $G \equiv 0$ i
mplies all derivatives vanish. Computing $\frac{\partial^2 G}{\partial x_0\,\par
tial y_0}$:

$$f(x_0{+}a,\, y_0{+}1/a) - f(x_0{+}a,\, y_0) - f(x_0,\, y_0{+}1/a) + f(x_0,\, y
_0) = 0$$

for all $x_0, y_0, a>0$. Denoting $\Delta_a^x g(x,y) = g(x{+}a,y)-g(x,y)$, this
reads:

$$\Delta_a^x\,\Delta_{1/a}^y\, f(x,y) = 0 \quad \forall\, x,y\in\mathbb{R},\; a>
0. \tag{2}$$

**Step 2: Periodicity of the horizontal increment.**

Equation (2) says $\Delta_a^x f(x,\,y+1/a) = \Delta_a^x f(x,\,y)$, i.e., for eac
h $a>0$ and each $x$, the function $y \mapsto \Delta_a^x f(x,y)$ is **$1/a$-peri
odic** in $y$.

**Step 3: A second, rationally independent period.**

Fix $a_1 > 0$ and choose $a_2 = a_1\sqrt{2}$ (so $a_2/a_1 = \sqrt{2}$ is irratio
nal). Using the telescoping identity

$$\Delta_{a_1+a_2}^x f(x,y) = \Delta_{a_2}^x f(x{+}a_1,\,y) + \Delta_{a_1}^x f(x
,\,y),$$

the left side is $1/(a_1{+}a_2)$-periodic in $y$, the first term on the right is
 $1/a_2$-periodic, and the second is $1/a_1$-periodic. Set $\varphi(y) = \Delta_
{a_1}^x f(x,y)$ and $\psi(y) = \Delta_{a_2}^x f(x{+}a_1,y)$, so $\varphi + \psi$
 is $T_3$-periodic with $T_3 = 1/(a_1{+}a_2)$.

From $\varphi(y{+}T_3)+\psi(y{+}T_3)=\varphi(y)+\psi(y)$, the function $h(y) :=
\varphi(y{+}T_3)-\varphi(y)$ equals $-(\psi(y{+}T_3)-\psi(y))$, so $h$ is both $
1/a_1$-periodic (from $\varphi$) and $1/a_2$-periodic (from $\psi$). Since $a_2/
a_1$ is irrational, these two periods are rationally independent, and $h$ (being
 continuous) must be **constant**: $h(y)=C$.

Then $\varphi(y+nT_3)=\varphi(y)+nC$ for all $n\in\mathbb{Z}$. But $\varphi$ is
$1/a_1$-periodic, hence bounded, forcing $C=0$. Thus $\varphi$ is also $T_3$-per
iodic.

**Step 4: $\Delta_a^x f$ is independent of $y$.**

Now $\varphi(y) = \Delta_{a_1}^x f(x,y)$ has two periods: $T_1 = 1/a_1$ and $T_3
 = 1/(a_1{+}a_2)$. Their ratio is $T_1/T_3 = (a_1{+}a_2)/a_1 = 1+\sqrt{2}$, whic
h is irrational. A continuous function with two rationally independent periods i
s constant (the set $\{mT_1+nT_3\}$ is dense in $\mathbb{R}$, giving arbitrarily
 small periods).

Since $a_1 > 0$ was arbitrary, $\Delta_a^x f(x,y)$ is **independent of $y$** for
 every $a > 0$.

**Step 5: $f$ is additive.**

$\Delta_a^x f(x,y) = f(x{+}a,0)-f(x,0)$ (evaluating at $y=0$). So $f(x{+}a,y)-f(
x,y) = f(x{+}a,0)-f(x,0)$, giving $f(x,y)-f(x,0) = f(0,y)-f(0,0)$, independent o
f $x$. Thus

$$f(x,y) = p(x) + q(y)$$

where $p(x) = f(x,0)$ and $q(y) = f(0,y)-f(0,0)$.

**Step 6: The integral condition forces $f \equiv 0$.**

Substituting into (1):

$$\frac{1}{a}\int_{x_0}^{x_0+a} p(x)\,dx \;+\; a\int_{y_0}^{y_0+1/a} q(y)\,dy =
0 \quad \forall\, x_0,y_0,a>0. \tag{3}$$

Fix $a>0$ and $y_0$; vary $x_0$. The second term is fixed, so $\int_{x_0}^{x_0+a
} p$ is constant in $x_0$. Differentiating: $p(x_0{+}a)=p(x_0)$ for all $x_0, a>
0$, so **$p$ is constant**. Similarly, varying $y_0$ shows **$q$ is constant**.

With $p \equiv c_1$, $q \equiv c_2$, equation (3) gives $c_1 + c_2 = 0$, hence

$$f(x,y) = c_1 + c_2 = 0 \quad \text{for all } (x,y)\in\mathbb{R}^2.$$

**Conclusion.** Yes, $f$ must be identically zero. $\blacksquare$
