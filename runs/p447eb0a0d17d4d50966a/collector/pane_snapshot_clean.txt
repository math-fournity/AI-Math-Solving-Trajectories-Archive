## Solution

**The statement is false.** We provide a counterexample.

**Setup.** Work in $M_2(\mathbb{R})$. Let
$$J = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}, \qquad X = 2\pi J = \begin{
pmatrix} 0 & -2\pi \\ 2\pi & 0 \end{pmatrix}, \qquad Y = \begin{pmatrix} 1 & 0 \
\ 0 & 0 \end{pmatrix}.$$

**Step 1: Compute $e^X$.** Since $J^2 = -I$, the matrix $J$ satisfies the same a
lgebraic relation as the imaginary unit. Hence, by the standard power-series arg
ument (or equivalently by diagonalizing $J$ over $\mathbb{C}$ as $J \sim \mathrm
{diag}(i, -i)$),
$$e^{tJ} = (\cos t)\, I + (\sin t)\, J \quad \text{for all } t \in \mathbb{R}.$$
Setting $t = 2\pi$ and using $\cos(2\pi) = 1$, $\sin(2\pi) = 0$:
$$e^X = e^{2\pi J} = (\cos 2\pi)\, I + (\sin 2\pi)\, J = I.$$

**Step 2: Verify $[e^X, Y] = 0$.** Since $e^X = I$ is the identity matrix, it co
mmutes with every matrix; in particular
$$[e^X, Y] = [I, Y] = 0.$$

**Step 3: Verify $[X, Y] \neq 0$.** Compute directly:
$$XY = 2\pi J \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} = 2\pi \begin{pmatrix
} 0 & 0 \\ 1 & 0 \end{pmatrix},$$
$$YX = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} 2\pi J = 2\pi \begin{pmatrix
} 0 & -1 \\ 0 & 0 \end{pmatrix}.$$
Therefore
$$[X, Y] = XY - YX = 2\pi \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \neq 0.$$

**Conclusion.** We have exhibited $X, Y \in M_2(\mathbb{R})$ with $[e^X, Y] = 0$
 yet $[X, Y] \neq 0$. The implication "$[e^X, Y] = 0 \Rightarrow [X, Y] = 0$" is
 therefore **not true** in general.

The essential reason is that the matrix exponential is not injective: a non-scal
ar matrix $X$ (here a rotation by $2\pi$) can exponentiate to the identity, whic
h commutes with everything, while $X$ itself does not.
