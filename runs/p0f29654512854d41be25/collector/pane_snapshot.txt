## Proof

**Claim.** Yes. There exist a set $B$ and a proper subset $A \subsetneq B$ such
that the Lebesgue measure of $A$ equals the Lebesgue measure of $B$.

**Construction.** Let $B = [0,1]$, and let
$$A = [0,1] \setminus \mathbb{Q} = \{x \in [0,1] : x \text{ is irrational}\}.$$

**Step 1: $A$ is a proper subset of $B$.** Every rational number $q \in [0,1]$ (
e.g., $q = 1/2$) belongs to $B$ but not to $A$. Hence $A \subsetneq B$.

**Step 2: $B$ is Lebesgue measurable with $m(B) = 1$.** The interval $[0,1]$ is
a Borel set, hence Lebesgue measurable, and its Lebesgue measure is its length,
$1$.

**Step 3: $\mathbb{Q} \cap [0,1]$ is Lebesgue measurable with measure $0$.** The
 set $\mathbb{Q} \cap [0,1]$ is countable (the rationals are countable). Every c
ountable set is Lebesgue measurable with measure zero: enumerate it as $\{q_1, q
_2, \dots\}$ and cover each $q_i$ by an interval of length $\varepsilon/2^i$; th
e total outer measure is at most $\varepsilon$, and $\varepsilon > 0$ is arbitra
ry, so $m^*(\mathbb{Q}\cap[0,1]) = 0$.

**Step 4: $A$ is Lebesgue measurable with $m(A) = 1$.** Since $A = B \setminus (
\mathbb{Q}\cap[0,1])$ is the difference of two Lebesgue measurable sets, $A$ is
Lebesgue measurable. By countable additivity (or the fact that removing a null s
et does not change measure),
$$m(A) = m(B) - m(\mathbb{Q}\cap[0,1]) = 1 - 0 = 1.$$

**Step 5: Conclusion.** We have $A \subsetneq B$ with
$$m(A) = 1 = m(B).$$

Therefore, there exist cases where a proper subset of a set has Lebesgue measure
 equal to that of the original set. $\blacksquare$

**Remark.** The essential mechanism is that the removed part $B \setminus A = \m
athbb{Q}\cap[0,1]$ is a null set (measure zero). In general, for any Lebesgue me
asurable set $B$ with $m(B) < \infty$ and any null set $N \subset B$, the proper
 subset $A = B \setminus N$ satisfies $m(A) = m(B)$ whenever $N$ is nonempty. Th
is shows the phenomenon is not isolated but systematic: Lebesgue measure cannot
"see" null sets, so removing a nonempty null set from a set of positive (or infi
nite) measure leaves the measure unchanged.
