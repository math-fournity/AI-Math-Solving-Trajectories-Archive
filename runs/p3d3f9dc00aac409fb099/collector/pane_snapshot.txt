## Proof

Let $\ell = \operatorname{lcm}(n, n+1, \ldots, 2n-1)$. Since $k \mid m$ for ever
y $n \le k \le 2n-1$, we have $\ell \mid m$. Write $m = \ell q$ for a positive i
nteger $q$.

For each $k \in [n, 2n-1]$, set $b_k = \ell/k \in \mathbb{Z}^+$. Then $\frac{m}{
k} = b_k q$, and
$$L = \prod_{k=n}^{2n-1}(b_k q + 1).$$

Expanding the product, $L = \sum_{j=0}^{n} q^j S_j$, where $S_0 = 1$ and $S_j$ i
s the $j$-th elementary symmetric polynomial in $\{b_k : n \le k \le 2n-1\}$. Si
nce $L \equiv 1 \pmod{q}$, we get $q \mid (L-1)$, and writing
$$T = \sum_{j=1}^{n} q^{j-1} S_j = S_1 + qS_2 + \cdots + q^{n-1}S_n,$$
we have $L - 1 = q \cdot T$, with $T \equiv S_1 \pmod{q}$.

### Key Lemma

**$S_1 = \sum_{k=n}^{2n-1} b_k$ is odd.**

*Proof.* Let $M' = v_2(\ell) = \max_{n \le k \le 2n-1} v_2(k)$. We first show $2
^{M'} \in [n,\, 2n-1]$ and $2^{M'+1} > 2n-1$.

- If $n = 2^j$ is a power of 2, then $2^j \in [n, 2n-1]$ and $2^{j+1} = 2n > 2n-
1$, so $M' = j$.
- If $2^j < n < 2^{j+1}$, then $2^{j+1} > n$ and $2^{j+1} < 2n$ (since $n > 2^j$

 so $M' = j+1$.

In both cases $2^{M'} \in [n, 2n-1]$ and $2^{M'+1} > 2n-1$. Since $2^{M'+1}$ is
the next multiple of $2^{M'}$ after $2^{M'}$, the number $2^{M'}$ is the **uniqu
e** multiple of $2^{M'}$ in $[n, 2n-1]$.

Now $v_2(b_k) = v_2(\ell) - v_2(k) = M' - v_2(k)$. Thus $b_k$ is odd if and only

e even. Therefore $S_1 = \sum b_k$ is a sum with exactly one odd term, hence $S_
1$ is odd. $\square$

### Case Analysis

**Case 1: $q$ has an odd prime factor $p$.**
Since $q \mid (L-1)$, we have $p \mid (L-1)$. Then $L-1$ has an odd divisor $p >

**Case 2: $q = 2^s$ for some $s \ge 1$.**
Then $T \equiv S_1 \pmod{2^s}$, and since $S_1$ is odd, $T$ is odd. Each factor

$$L \ge (q+1)^n \ge (q+1)^2, \qquad L - 1 \ge (q+1)^2 - 1 = q(q+2).$$
Thus $T = (L-1)/q \ge q + 2 \ge 4$. Since $T$ is odd and $T \ge 4$, we have $T \
ge 5 > 1$. Therefore $L - 1 = 2^s \cdot T$ with $T$ odd and $T > 1$, so $L - 1$
is **not** a power of $2$.

**Case 3: $q = 1$ (i.e., $m = \ell$).**
Then $L = \prod(b_k + 1)$. By the Key Lemma, exactly one $b_k$ is odd (namely $b
