$$\tan^{n-1}x + \tan^n x + \tan^{n+1}x = \tan^{n-1}x\,(1 + \tan x + \tan^2 x).$$

Thus
$$I_n = \int_0^1 e^{n\arctan t}\, t^{n-1}\,\frac{1+t+t^2}{1+t^2}\,dt.$$

### Step 2: Laplace form

Rewrite the exponential part:
$$e^{n\arctan t}\,t^{n-1} = e^{n(\arctan t + \ln t)}\cdot t^{-1}.$$

Set
$$g(t) = \arctan t + \ln t, \qquad h(t) = \frac{1+t+t^2}{t(1+t^2)},$$
so that
$$I_n = \int_0^1 e^{n\,g(t)}\,h(t)\,dt.$$

$$g'(t) = \frac{1}{1+t^2} + \frac{1}{t} = \frac{t + 1 + t^2}{t(1+t^2)} > 0 \quad
 \text{for all } t \in (0,1].$$

So $g$ is **strictly increasing** on $(0,1]$, and its maximum on $[0,1]$ is at t

$$g(1) = \arctan(1) + \ln(1) = \frac{\pi}{4}.$$

### Step 4: Apply Laplace's method (endpoint maximum)

$$I_n \sim \frac{h(1)\,e^{n\,g(1)}}{n\,g'(1)}.$$

$$g'(1) = \frac{1}{2} + 1 = \frac{3}{2}, \qquad h(1) = \frac{1+1+1}{1\cdot(1+1)}

$$I_n \sim \frac{\tfrac{3}{2}\,e^{n\pi/4}}{n\cdot\tfrac{3}{2}} = \frac{e^{n\pi/4
