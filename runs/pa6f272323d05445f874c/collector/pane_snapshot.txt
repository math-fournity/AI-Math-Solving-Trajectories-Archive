## Proof

We consider the stochastic differential equation (SDE) for geometric Brownian mo
tion:

$$dx_t = r\, x_t\, dt + \sigma\, x_t\, dB_t, \qquad x_0 \text{ given.}$$

### Step 1. Solve the SDE via Itô's formula

We apply Itô's formula to $f(x,t) = \ln x_t$. Setting $Y_t = \ln x_t$, with part
ial derivatives $f_t = 0$, $f_x = 1/x$, $f_{xx} = -1/x^2$, Itô's formula gives:

$$dY_t = \frac{1}{x_t}\,dx_t + \tfrac{1}{2}\!\left(-\frac{1}{x_t^2}\right)(dx_t)
^2.$$

Substituting $dx_t = r x_t\,dt + \sigma x_t\,dB_t$ and using $(dx_t)^2 = \sigma^
2 x_t^2\,dt$ (the quadratic variation, since $(dB_t)^2 = dt$ and cross terms van
ish):

$$dY_t = \left(r - \tfrac{1}{2}\sigma^2\right)dt + \sigma\,dB_t.$$

Integrating from $0$ to $t$:

$$\ln x_t - \ln x_0 = \left(r - \tfrac{1}{2}\sigma^2\right)t + \sigma B_t,$$

so the explicit solution is

$$x_t = x_0 \exp\!\left(\left(r - \tfrac{1}{2}\sigma^2\right)t + \sigma B_t\righ
t).$$

### Step 2. Compute the expectation

Taking expectations:

$$\mathbb{E}[x_t] = x_0 \exp\!\left(\left(r - \tfrac{1}{2}\sigma^2\right)t\right
)\,\mathbb{E}\!\left[\exp(\sigma B_t)\right].$$

Since $B_t \sim \mathcal{N}(0, t)$, the random variable $\sigma B_t \sim \mathca
l{N}(0, \sigma^2 t)$. Using the moment-generating function of a normal random va
riable, $\mathbb{E}[\exp(\sigma B_t)] = \exp\!\left(\tfrac{1}{2}\sigma^2 t\right
)$.

Therefore:

$$\mathbb{E}[x_t] = x_0 \exp\!\left(\left(r - \tfrac{1}{2}\sigma^2\right)t\right
)\exp\!\left(\tfrac{1}{2}\sigma^2 t\right) = x_0 \exp(rt).$$

### Result

$$\boxed{\mathbb{E}[x_t] = x_0\, e^{rt}}$$

The drift parameter $r$ alone determines the growth of the mean, while the volat
ility $\sigma$ — which contributes the Itô correction $-\tfrac{1}{2}\sigma^2 t$
to the log-process — is exactly canceled by the moment-generating function facto
r $\exp(\tfrac{1}{2}\sigma^2 t)$.
