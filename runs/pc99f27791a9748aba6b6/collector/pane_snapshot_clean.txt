Looking at this problem, I need to find the minimum number of drives in a 10×10
grid satisfying two conditions: (1) no row/column is entirely filled with identi
cal drives, and (2) maximality — filling any empty slot with either type creates
 a monochromatic row or column.

## Proof

**Setup.** Let the grid have entries in {X, O, E} (E = empty). Condition 1 forbi
ds any row or column that is entirely X or entirely O. Condition 2 requires that
 for every empty cell (i,j), placing X there creates a monochromatic line, **and
** placing O there creates a monochromatic line.

**Key observation on empty cells.** When we place X at empty cell (i,j), a monoc
hromatic line is created only if some row or column becomes all-X. This requires
 either:
- Row i has 9 X's and (i,j) is its only empty cell, or
- Column j has 9 X's and (i,j) is its only empty cell.

Similarly for placing O. For **both** placements to create a monochromatic line,
 we need one of:
- **(A)** Row i is all-X-except-j **and** Column j is all-O-except-i, or
- **(B)** Row i is all-O-except-j **and** Column j is all-X-except-i.

(The other two combinations require a single row/column to be both all-X-except-
j and all-O-except-j, which is impossible.)

**Consequence: every row/column with an empty cell has exactly 9 of one type.**
If (i,j) is empty, row i must be an "X-row" (9 X's + 1 empty) or "O-row" (9 O's
+ 1 empty). No row can have two empty cells, since that would contradict "all-X-
except-j" (the second empty cell wouldn't be X). Same for columns.

**Counting.** Define:
- $a$ = number of X-rows, $b$ = number of O-rows
- $c$ = number of X-columns, $d$ = number of O-columns

Each X-row's empty cell lies in an O-column (type A), and each O-column's empty
cell lies in an X-row. This gives a bijection between X-rows and O-columns, so $
a = d$. Similarly, O-rows pair with X-columns, so $b = c$.

**Bounding $a$ and $b$.** Suppose $a \geq 2$. Then there are $a$ X-rows and $d =
 a$ O-columns, giving $a^2$ cells at their intersections, but only $a$ are bijec
tion-paired (empty). Consider a non-paired intersection $(r, c)$ where $r$ is an
 X-row and $c$ is an O-column:
- Since $r$ is an X-row, all its cells are X except its paired empty cell — so $
(r,c) = \text{X}$.
- Since $c$ is an O-column, all its cells are O except its paired empty cell — s
o $(r,c) = \text{O}$.

This is a contradiction. Therefore $a \leq 1$. By the identical argument, $b \le
q 1$.

**Maximum empty cells.** Total empty cells = $a + b \leq 2$, so minimum drives =
 $100 - 2 = 98$.

**Construction achieving 98.** Let row 1 be the X-row, row 2 be the O-row, colum
n 1 be the X-column, column 2 be the O-column. Set:
- (1,2) = empty (X-row ↔ O-column pair)
- (2,1) = empty (O-row ↔ X-column pair)
- Row 1: X everywhere except (1,2)
- Row 2: O everywhere except (2,1)
- Column 1: X everywhere except (2,1)
- Column 2: O everywhere except (1,2)
- Rows 3–10, columns 3–10: fill arbitrarily (e.g., all X)

**Verification of Condition 1:** Rows 1, 2 and columns 1, 2 each have an empty c
ell, so they aren't "entirely filled." Rows 3–10 contain X (at col 1) and O (at
col 2), so non-monochromatic. Columns 3–10 contain X (at row 1) and O (at row 2)
, so non-monochromatic. ✓

**Verification of Condition 2:** The only empty cells are (1,2) and (2,1).
- X at (1,2): row 1 becomes all X. ✓
- O at (1,2): column 2 becomes all O. ✓
- X at (2,1): column 1 becomes all X. ✓
- O at (2,1): row 2 becomes all O. ✓

Both conditions are satisfied with 98 drives.

## Answer

The minimum total number of drives is $\boxed{98}$.
