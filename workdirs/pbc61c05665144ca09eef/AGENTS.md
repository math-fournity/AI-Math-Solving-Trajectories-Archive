# Problem

In a remote research laboratory, an automated system is initialized with a single data packet containing a signal intensity value of $r^n$, where $r$ is a positive rational number and $n$ is an integer greater than 1.

The system performs a data transformation protocol every minute. During each cycle, the operator selects two values, $a$ and $b$, currently stored in the system’s memory (the operator may select the same value twice). The system then processes these to generate two new values: the arithmetic mean of the pair, $\frac{a+b}{2}$, and the ratio of the first selected value to the second, $\frac{a}{b}$. These two new values are added to the memory, while all previous values remain stored.

Find all possible values of the exponent $n$ such that there exists some initial base $r$ allowing the specific value 17 to eventually appear in the system’s memory.
