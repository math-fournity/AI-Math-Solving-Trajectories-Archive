# Problem

A specialized digital server node begins its lifecycle with exactly one active data packet. At the end of every processing cycle, the node attempts to replicate every packet currently in its buffer simultaneously. For each individual packet, there is a 50% chance of a "successful sync" and a 50% chance of a "sync error." 

If a packet results in a successful sync, it generates one additional identical packet into the buffer. If a packet results in a sync error, that specific packet is corrupted and deleted from the buffer. This collective update happens once per cycle. The node continues this automated process cycle after cycle until the buffer is completely empty, at which point the node permanently shuts down.

The probability that the node shuts down precisely at the end of the fifth cycle (and not before or after) can be expressed in the form $\frac{a}{2^b}$, where $a$ and $b$ are positive integers and $a$ is odd. 

Find the value of $a + b$.
