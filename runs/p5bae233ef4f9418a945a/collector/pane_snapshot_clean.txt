**Substitution.** Let $y_n = 1/x_n$, so $y_1 = 20$, $y_2 = 13$. Substituting $x_
k = 1/y_k$ into the recurrence and simplifying (the factors $y_n^2 y_{n+1}^2$ ca
ncel between numerator and denominator):

$$y_{n+2} = \frac{y_n^2 + y_{n+1}^2}{2(y_n + y_{n+1})}.$$

Using $\dfrac{a^2+b^2}{2(a+b)} = \dfrac{a+b}{2} - \dfrac{ab}{a+b}$, we get

$$y_{n+2} = \frac{y_n + y_{n+1}}{2} - \frac{y_n y_{n+1}}{y_n + y_{n+1}}.$$

**Identifying the summand.** The term we sum is

$$\frac{1}{x_n + x_{n+1}} = \frac{1}{1/y_n + 1/y_{n+1}} = \frac{y_n y_{n+1}}{y_n
 + y_{n+1}}.$$

Denote this $s_n$. Then the relation above gives

$$s_n = \frac{y_n + y_{n+1}}{2} - y_{n+2}.$$

**Telescoping.** Summing from $n=1$ to $N$:

$$\sum_{n=1}^{N} s_n = \frac{1}{2}\sum_{n=1}^{N}(y_n + y_{n+1}) - \sum_{n=1}^{N}
 y_{n+2}.$$

The first sum is $\tfrac12\bigl(y_1 + 2y_2 + 2y_3 + \cdots + 2y_N + y_{N+1}\bigr
) = \tfrac{y_1}{2} + \sum_{k=2}^{N} y_k + \tfrac{y_{N+1}}{2}$.

The second sum is $\sum_{k=3}^{N+2} y_k = \sum_{k=3}^{N} y_k + y_{N+1} + y_{N+2}
$.

Subtracting (the middle sums $\sum_{k=3}^N y_k$ cancel):

$$\sum_{n=1}^{N} s_n = \frac{y_1}{2} + y_2 - \frac{y_{N+1}}{2} - y_{N+2}.$$

**Limit $y_n \to 0$.** Let $M_n = \max(y_n, y_{n+1})$. WLOG $y_n \ge y_{n+1}$ an
d set $r = y_{n+1}/y_n \in [0,1]$; then

$$\frac{y_{n+2}}{y_n} = \frac{1+r^2}{2(1+r)} \le \frac12 \quad\Longleftrightarro
w\quad r^2 \le r \Longleftrightarrow r \le 1,$$

so $y_{n+2} \le \tfrac12 \max(y_n,y_{n+1}) = \tfrac12 M_n$ (the case $y_{n+1}\ge
 y_n$ is symmetric). Consequently $y_{n+3} \le \tfrac12 M_{n+1} \le \tfrac12 M_n
$, and thus

$$M_{n+2} = \max(y_{n+2}, y_{n+3}) \le \tfrac12 M_n.$$

Iterating, $M_n \le M_1 \cdot 2^{-\lfloor (n-1)/2\rfloor} \to 0$. Since $0 \le y
_n \le M_n$, we conclude $y_n \to 0$.

**Final value.** Taking $N \to \infty$:

$$\sum_{n=1}^{\infty} \frac{1}{x_n + x_{n+1}} = \frac{y_1}{2} + y_2 - 0 - 0 = \f
rac{20}{2} + 13 = 10 + 13 = 23.$$
