## 解答

**答案：** $k(n)$ 是满足 $n \mid k!$ 的最小正整数 $k$。特别地，$k(10^6) = 25$。

---

### 证明

**关键引理（Newton 级数判据）。** 设 $f(x) \in \mathbb{Z}[x]$，将其在二项式基底
下展开为 Newton 级数
$$f(x) = \sum_{i=0}^{d} a_i \binom{x}{i}, \qquad a_i = \Delta^i f(0) \in \mathbb
{Z},$$
其中 $\Delta$ 是向前差分算子。则
$$n \mid f(x)\ \forall\, x \in \mathbb{Z} \iff n \mid a_i\ \forall\, i \ge 0.$$

**引理证明。** 对 $m = 0, 1, 2, \ldots$ 归纳。因 $\binom{m}{i} = 0$（$i > m$ 时
），有 $f(m) = \sum_{i=0}^{m} a_i \binom{m}{i}$。
- $m=0$：$f(0) = a_0$，故 $n \mid f(0) \iff n \mid a_0$。
- 归纳步：$f(m) = a_m + \sum_{i < m} a_i \binom{m}{i}$。由归纳假设 $n \mid a_i$
（$i < m$），故 $n \mid f(m) \iff n \mid a_m$。

对负整数 $x$，$\binom{x}{i} = (-1)^i \binom{-x-1+i}{i} \in \mathbb{Z}$，故 $n \m
id a_i\ \forall i$ 蕴含 $n \mid f(x)\ \forall x \in \mathbb{Z}$。引理得证。$\squ
are$

**下界。** 设 $f$ 为首一 $k$ 次多项式。在 Newton 级数中，$\binom{x}{k} = \frac{x
^k}{k!} + \cdots$，故首项系数 $1 = a_k / k!$，即 $a_k = k!$。由引理，$n \mid f(x
)\ \forall x$ 要求 $n \mid a_k = k!$，即 $n \mid k!$。因此
$$k(n) \ge \min\{k : n \mid k!\}.$$

**上界。** 取 $f(x) = \prod_{i=0}^{k-1}(x - i) = k!\,\binom{x}{k}$。此为首一 $k$
 次多项式，且 Newton 系数 $a_k = k!$，$a_i = 0$（$i < k$）。当 $n \mid k!$ 时，$
n \mid a_i\ \forall i$，由引理 $n \mid f(x)\ \forall x$。因此
$$k(n) \le \min\{k : n \mid k!\}.$$

**结论：**
$$\boxed{k(n) = \min\{k \ge 1 : n \mid k!\}}.$$

### 计算 $k(10^6)$

$10^6 = 2^6 \cdot 5^6$。需 $2^6 \mid k!$ 且 $5^6 \mid k!$，即 $v_2(k!) \ge 6$ 且
 $v_5(k!) \ge 6$（Legendre 公式 $v_p(k!) = \sum_{j \ge 1} \lfloor k/p^j \rfloor$
）。

**$v_2(k!) \ge 6$：**
- $v_2(7!) = 3 + 1 = 4 < 6$；
- $v_2(8!) = 4 + 2 + 1 = 7 \ge 6$。

故最小 $k$ 为 $8$。

**$v_5(k!) \ge 6$：**
- $v_5(24!) = 4 + 0 = 4 < 6$；
- $v_5(25!) = 5 + 1 = 6 \ge 6$。

故最小 $k$ 为 $25$。

取两者最大值（$v_2(25!) = 12+6+3+1 = 22 \ge 6$ 自动满足）：

$$\boxed{k(10^6) = 25}.$$
