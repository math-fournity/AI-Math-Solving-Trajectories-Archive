## Proof

We work in the Hilbert space $H = L^2([0,\pi])$ with inner product $\langle f, g
\rangle = \int_0^\pi f(x)g(x)\,dx$. We minimize $\|f\|^2 = \langle f, f\rangle$
subject to the two linear constraints
$$\langle f, \sin\rangle = 1, \qquad \langle f, \cos\rangle = 1.$$

**Step 1: The minimizer lies in $\operatorname{span}\{\sin, \cos\}$.**

Let $V = \operatorname{span}\{\sin, \cos\}$ and decompose any $f \in H$ as $f =
f_\parallel + f_\perp$ with $f_\parallel \in V$ and $f_\perp \in V^\perp$. Since
 $\sin, \cos \in V$,
$$\langle f, \sin\rangle = \langle f_\parallel, \sin\rangle, \qquad \langle f, \
cos\rangle = \langle f_\parallel, \cos\rangle.$$
Thus the constraints depend only on $f_\parallel$. Meanwhile,
$$\|f\|^2 = \|f_\parallel\|^2 + \|f_\perp\|^2 \geq \|f_\parallel\|^2,$$
with equality if and only if $f_\perp = 0$. Hence any minimizer must lie in $V$,
 i.e. $f(x) = a\sin x + b\cos x$.

**Step 2: Compute the Gram matrix.**

$$\langle \sin,\sin\rangle = \int_0^\pi \sin^2 x\,dx = \frac{\pi}{2}, \qquad \la
ngle \cos,\cos\rangle = \int_0^\pi \cos^2 x\,dx = \frac{\pi}{2},$$
$$\langle \sin,\cos\rangle = \int_0^\pi \sin x\cos x\,dx = \frac{1}{2}\int_0^\pi
 \sin 2x\,dx = \frac{1}{2}\left[-\frac{\cos 2x}{2}\right]_0^\pi = \frac{1}{2}\cd
ot\frac{-\cos 2\pi+\cos 0}{2} = 0.$$

So $\sin$ and $\cos$ are **orthogonal**, and the Gram matrix is $\frac{\pi}{2}I$
.

**Step 3: Solve for $a, b$.**

The constraints become
$$a\cdot\frac{\pi}{2} + b\cdot 0 = 1 \;\Longrightarrow\; a = \frac{2}{\pi}, \qqu
ad a\cdot 0 + b\cdot\frac{\pi}{2} = 1 \;\Longrightarrow\; b = \frac{2}{\pi}.$$

Thus the unique minimizer is
$$f(x) = \frac{2}{\pi}\bigl(\sin x + \cos x\bigr).$$

**Step 4: Compute the minimum value.**

$$\int_0^\pi f^2(x)\,dx = \frac{4}{\pi^2}\int_0^\pi (\sin x + \cos x)^2\,dx = \f
rac{4}{\pi^2}\int_0^\pi \bigl(1 + 2\sin x\cos x\bigr)\,dx.$$

Using $\int_0^\pi \sin x\cos x\,dx = 0$ (computed above) and $\int_0^\pi 1\,dx =
 \pi$:

$$\int_0^\pi f^2(x)\,dx = \frac{4}{\pi^2}\cdot\pi = \frac{4}{\pi}.$$

**Verification.** Check the constraints:
$$\int_0^\pi \frac{2}{\pi}(\sin x+\cos x)\sin x\,dx = \frac{2}{\pi}\left(\frac{\
pi}{2}+0\right) = 1.\;\checkmark$$
$$\int_0^\pi \frac{2}{\pi}(\sin x+\cos x)\cos x\,dx = \frac{2}{\pi}\left(0+\frac
{\pi}{2}\right) = 1.\;\checkmark$$

The minimum value is $\boxed{\dfrac{4}{\pi}}$.
