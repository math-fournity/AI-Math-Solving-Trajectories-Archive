## Proof

Let $\delta = \ln(a/b)$. By symmetry (swapping $a \leftrightarrow b$ and $x \lef
trightarrow 1-x$ leaves the inequality invariant), we may assume $a \ge b$, so $
\delta \ge 0$.

**Key observation.** Define for $k \ne 0$:
$$f_k(x) = \frac{a\,\sinh(kx) + b\,\sinh(k(1-x))}{\sinh(k)}.$$

Then $f_k(0) = b$, $f_k(1) = a$, and $f_k''(x) = k^2 f_k(x)$.

The left-hand side is $g(x) = a^x b^{1-x} = b\,e^{\delta x}$, which satisfies $g
(0)=b$, $g(1)=a$, $g'' = \delta^2 g$, so **$g = f_\delta$**. The right-hand side
 is **$h = f_u$**. The inequality becomes $f_\delta(x) \le f_u(x)$ for all $x \i
n (0,1)$.

---

### Step 1: The inequality holds for $0 < |u| \le \delta$ (when $\delta > 0$).

Since both sides are even in $u$ (as $\sinh(ux)/\sinh(u)$ is even in $u$), assum
e $u > 0$. Set $w(x) = f_u(x) - f_\delta(x)$. Then $w(0) = w(1) = 0$ and:
$$w''(x) = u^2 f_u(x) - \delta^2 f_\delta(x) = u^2 w(x) + (u^2 - \delta^2)\,f_\d
elta(x).$$

Since $u \le \delta$, we have $u^2 - \delta^2 \le 0$, and $f_\delta(x) > 0$ for
$x \in (0,1)$ (as $a,b > 0$ and $\sinh(\delta x), \sinh(\delta(1-x)) > 0$). Ther
efore:
$$w''(x) - u^2 w(x) \le 0 \quad \text{on } (0,1).$$

**Maximum principle.** Suppose $w(x_0) < 0$ for some $x_0 \in (0,1)$. Since $w(0
) = w(1) = 0$, the function $w$ attains a negative interior minimum at some $x_1
 \in (0,1)$, where $w''(x_1) \ge 0$ and $w(x_1) < 0$. Then:
$$w''(x_1) - u^2 w(x_1) \ge 0 - u^2 \cdot (\text{negative}) > 0,$$
contradicting $w'' - u^2 w \le 0$. Hence $w \ge 0$ on $[0,1]$, i.e., $f_\delta \
le f_u$. $\checkmark$

At $u = \delta$: $f_u = f_\delta$, so equality holds everywhere — consistent.

---

### Step 2: The inequality fails for $|u| > \delta$.

At $x = 1/2$:
$$f_k(1/2) = \frac{(a+b)\sinh(k/2)}{\sinh(k)} = \frac{(a+b)\sinh(k/2)}{2\sinh(k/
2)\cosh(k/2)} = \frac{a+b}{2\cosh(k/2)}.$$

This is **strictly decreasing** in $k > 0$. So if $u > \delta > 0$:
$$f_u(1/2) = \frac{a+b}{2\cosh(u/2)} < \frac{a+b}{2\cosh(\delta/2)} = f_\delta(1
/2),$$
and the inequality $f_\delta(1/2) \le f_u(1/2)$ **fails**. $\checkmark$

---

### Step 3: The case $a = b$ ($\delta = 0$).

When $a = b$, the LHS equals $a$ and the RHS equals $a\,\frac{\cosh(u(x - 1/2))}
{\cosh(u/2)}$. Since $|x - 1/2| < 1/2$ for $x \in (0,1)$, we have $\cosh(u(x-1/2
)) < \cosh(u/2)$ for $u \ne 0$, so RHS $< a =$ LHS. The inequality fails for eve
ry $u \ne 0$, giving $c = 0 = |\delta|$. $\checkmark$

---

### Conclusion

Combining all cases: the inequality holds for all $x \in (0,1)$ and all $u$ with
 $0 < |u| \le c$ if and only if $c \le |\delta|$. The largest such $c$ is:

$$\boxed{c = \left|\ln\frac{a}{b}\right| = |\ln a - \ln b|}$$
