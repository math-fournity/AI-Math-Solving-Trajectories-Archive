## Solution

**Setup.** Encode each configuration as a vector in $\mathbb{F}_2^{54}$, where c
oordinate $i$ is $1$ if terminal $i$ is Active and $0$ if Inactive (indices take
n mod $54$). A maintenance operation toggling terminals $i$ and $i+1$ adds the v
ector $g_i = e_i + e_{i+1}$ to the state. Two configurations are equivalent iff
they differ by an element of

$$V = \operatorname{span}\{g_1, g_2, \dots, g_{54}\} \subseteq \mathbb{F}_2^{54}
.$$

The number of equivalence classes is $2^{54}/|V| = 2^{54 - \operatorname{rank}(V
)}$.

**Computing the rank.** Consider the linear map $\varphi: \mathbb{F}_2^{54} \to
\mathbb{F}_2^{54}$ sending a coefficient vector $c = (c_1,\dots,c_{54})$ to $\su
m_i c_i g_i = \sum_i (c_i + c_{i-1})\,e_i$. Its image is $V$, so $\operatorname{
rank}(V) = 54 - \dim\ker\varphi$.

Now $\varphi(c) = 0$ iff $c_i + c_{i-1} = 0$ for every $i$, i.e., $c_i = c_{i-1}
$ for every $i$. Since the indices form a single cycle, this forces $c_1 = c_2 =
 \cdots = c_{54}$. Thus

$$\ker\varphi = \{(0,\dots,0),\,(1,\dots,1)\}, \qquad \dim\ker\varphi = 1.$$

Therefore $\operatorname{rank}(V) = 54 - 1 = 53$.

**Identifying $V$.** Each generator $g_i = e_i + e_{i+1}$ has Hamming weight $2$
 (even), so $V$ is contained in the even-weight subspace $E = \{x : \sum x_i = 0
\}$, which has dimension $53$. Since $\dim V = 53 = \dim E$, we get $V = E$.

So two configurations are equivalent **iff they differ by an even-weight vector*
*, i.e., **iff they have the same parity of the number of Active terminals**.

**Counting classes.** The parity (even/odd number of Active terminals) is the un
ique invariant, giving exactly two equivalence classes:
- the class of configurations with an even number of Active terminals,
- the class with an odd number of Active terminals.

The number of distinct, non-equivalent configurations is

$$2^{54 - 53} = 2^1 = \boxed{2}.$$
