## Solution

We analyze the series $\displaystyle\sum_{n=1}^{\infty}\left[\frac{x(x+n)}{n}\ri
ght]^n$, whose general term is

$$a_n = \left[\frac{x(x+n)}{n}\right]^n = \left[x + \frac{x^2}{n}\right]^n.$$

### Root test

Compute

$$|a_n|^{1/n} = \left|x + \frac{x^2}{n}\right| \xrightarrow{n\to\infty} |x|.$$

Set $L = \lim_{n\to\infty}|a_n|^{1/n} = |x|$.

- **If $|x|<1$**: $L<1$, so by the root test the series converges absolutely.
- **If $|x|>1$**: $L>1$, so $|a_n|^{1/n}>1$ for all large $n$, hence $|a_n|\not\
to 0$, and the series diverges.

### Boundary cases $|x|=1$

**$x=1$:** $a_n = \left(1+\dfrac{1}{n}\right)^n \to e \neq 0$, so the series div
erges.

**$x=-1$:** For $n\ge 2$,
$$|a_n| = \left|-1+\frac{1}{n}\right|^n = \left(1-\frac{1}{n}\right)^n \to e^{-1
}\neq 0,$$
so the series diverges.

### Conclusion

The series converges if and only if $|x|<1$, i.e.

$$\boxed{x\in(-1,\,1).}$$
