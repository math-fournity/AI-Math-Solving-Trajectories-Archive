} + \frac{1}{\sqrt[n]{\det A \det B \det(A-B)}}$ over Hermitian positive definit

## Proof

**Key tool — Minkowski's determinant inequality.** For positive definite Hermiti
an matrices $P, Q \in M_n(\mathbb{C})$:
$$\det(P+Q)^{1/n} \geq \det(P)^{1/n} + \det(Q)^{1/n},$$
with equality if and only if $P = \lambda Q$ for some $\lambda > 0$.

**Setting up variables.** Let
$$x = \det(A)^{1/n}, \quad y = \det(B)^{1/n}, \quad z = \det(A-B)^{1/n}, \quad x
, y, z > 0.$$
Since $A = (A-B) + B$ with both $A-B$ and $B$ positive definite, Minkowski gives
$$x = \det(A)^{1/n} \geq \det(A-B)^{1/n} + \det(B)^{1/n} = z + y. \tag{1}$$

The objective becomes
$$f = x + \frac{1}{xyz}, \quad \text{subject to } x \geq y+z,\; x,y,z > 0. \tag{
2}$$

---

**Step 1: Reduce to two variables.** Fix $x > 0$ and $w := y + z \leq x$. By AM–
GM, $yz \leq \frac{w^2}{4}$ with equality iff $y = z = w/2$. Since $\frac{1}{xyz
}$ is decreasing in $yz$:
$$f = x + \frac{1}{xyz} \geq x + \frac{4}{x\,w^2}, \quad \text{equality iff } y
= z = \tfrac{w}{2}. \tag{3}$$

**Step 2: Optimize $g(x,w) = x + \frac{4}{xw^2}$ over $x \geq w > 0$.**

For fixed $w$, $\frac{\partial g}{\partial x} = 1 - \frac{4}{x^2 w^2}$, giving c
ritical point $x^* = \frac{2}{w}$.

- **Case $w \leq \sqrt{2}$** (so $x^* = 2/w \geq w$): $g(x^*,w) = \frac{2}{w} +
\frac{4}{(2/w)\,w^2} = \frac{4}{w}$, minimized at $w = \sqrt{2}$, yielding $g =
2\sqrt{2} \approx 2.828$.

- **Case $w > \sqrt{2}$** (so $x^* < w$; $g$ increasing on $[w,\infty)$): minimu
m at $x = w$:
$$g(w,w) = w + \frac{4}{w^3}, \qquad g'(w) = 1 - \frac{12}{w^4} = 0 \implies w =
 12^{1/4}.$$
Check $12^{1/4} > \sqrt{2}$: since $12^{1/2} = 2\sqrt{3} > 2 = (\sqrt{2})^2$, ye
s. ✓

$$g\bigl(12^{1/4},\, 12^{1/4}\bigr) = 12^{1/4} + \frac{4}{12^{3/4}} = \frac{12 +
 4}{12^{3/4}} = \frac{16}{12^{3/4}} = \frac{4\sqrt[4]{12}}{3}.$$

Numerically $\frac{4\sqrt[4]{12}}{3} \approx 2.482 < 2\sqrt{2} \approx 2.828$, s
o the **global minimum** is
$$f_{\min} = \frac{4\sqrt[4]{12}}{3}.$$

---

**Step 3: Verify achievability.** The optimum requires:
- $x = y + z$ (equality in Minkowski (1)) $\Longrightarrow$ $A - B = \mu B$, i.e
., $A = (1+\mu)B$.
- $y = z$ (equality in AM–GM) $\Longrightarrow$ $\det B = \det(A-B) \Longrightar
row \mu = 1$, so $A = 2B$.
- $w = x = 12^{1/4}$, $y = z = 12^{1/4}/2$.

Take $B = c\,I_n$ with $c = (3/4)^{1/4}$, and $A = 2c\,I_n$. Then:
$$\det(A)^{1/n} = 2c, \quad \det(B)^{1/n} = c, \quad \det(A-B)^{1/n} = c,$$
$$f = 2c + \frac{1}{2c \cdot c \cdot c} = 2c + \frac{1}{2c^3}.$$
With $c^4 = 3/4$:
$$f = 2\left(\tfrac{3}{4}\right)^{1/4} + \frac{1}{2\left(\tfrac{3}{4}\right)^{3/
4}} = \frac{2\left(\tfrac{3}{4}\right)^{1/4}\cdot 2\left(\tfrac{3}{4}\right)^{3/
4} + 1}{2\left(\tfrac{3}{4}\right)^{3/4}} = \frac{4\cdot\tfrac{3}{4} + 1}{2\left
(\tfrac{3}{4}\right)^{3/4}} = \frac{4}{2\left(\tfrac{3}{4}\right)^{3/4}} = \frac
{2}{(3/4)^{3/4}}.$$
$$= \frac{2 \cdot 4^{3/4}}{3^{3/4}} = \frac{2 \cdot 2\sqrt{2}}{3^{3/4}} = \frac{
4\sqrt{2}}{3^{3/4}} = \frac{4\sqrt{2}\cdot 3^{1/4}}{3} = \frac{4\sqrt[4]{12}}{3}
. \quad\checkmark$$

---

**Conclusion.** The minimum value of $f(A,B)$ is

$$\boxed{\dfrac{4\,\sqrt[4]{12}}{3}}.$$
