## 解答

**该命题为真。**

**证明。**

设 $\mathcal{A}$ 为一个加法范畴，设 $X \in \mathcal{A}$，并设 $\Delta_X : X \to
X \oplus X$ 为对角态射，其定义为 $\pi_1 \Delta_X = \mathrm{id}_X = \pi_2 \Delta_
X$，其中 $\pi_1, \pi_2 : X \oplus X \to X$ 为双积投影，$\iota_1, \iota_2 : X \to
 X \oplus X$ 为内射。回顾双积恒等式：$\pi_j \iota_k = \delta_{jk}\,\mathrm{id}_X
$ 且 $\iota_1\pi_1 + \iota_2\pi_2 = \mathrm{id}_{X\oplus X}$。

**($\Rightarrow$)** 假设 $X$ 是一个零对象。那么 $X \oplus X$ 也是零对象（两个零
对象的双积是零对象）。由于 $\Delta_X$ 是两个零对象之间的态射，且零对象之间的态射
唯一且为同构，因此 $\Delta_X$ 是同构。

**($\Leftarrow$)** 假设 $\Delta_X$ 是同构。由 $\pi_1\Delta_X = \pi_2\Delta_X = \
mathrm{id}_X$ 且 $\Delta_X$ 是满态射，可得 $\pi_1 = \pi_2$；记此公共态射为 $p$。
则 $p\,\Delta_X = \mathrm{id}_X$，又因为 $\Delta_X$ 是同构，故 $p = \Delta_X^{-1
}$，即 $\Delta_X\, p = \mathrm{id}_{X\oplus X}$。

现在计算内射：
$$\iota_1 = \mathrm{id}_{X\oplus X}\,\iota_1 = \Delta_X\, p\, \iota_1 = \Delta_X
(\pi_1\,\iota_1) = \Delta_X(\mathrm{id}_X) = \Delta_X,$$
$$\iota_2 = \mathrm{id}_{X\oplus X}\,\iota_2 = \Delta_X\, p\, \iota_2 = \Delta_X
(\pi_2\,\iota_2) = \Delta_X(\mathrm{id}_X) = \Delta_X.$$
因此 $\iota_1 = \iota_2$。应用 $\pi_1$ 得到 $\pi_1\iota_1 = \pi_1\iota_2$，即 $\
mathrm{id}_X = 0_{X,X}$。

一旦 $\mathrm{id}_X = 0_{X,X}$，对于任意对象 $Y$：任意 $f : X \to Y$ 满足 $f = f
\,\mathrm{id}_X = f\,0_{X,X} = 0_{X,Y}$，故 $X$ 是始对象；任意 $g : Y \to X$ 满
足 $g = \mathrm{id}_X\, g = 0_{X,X}\, g = 0_{Y,X}$，故 $X$ 是终对象。因此 $X$ 是
零对象。$\blacksquare$
