## Proof

**Setup and digit decomposition.** Let $n = 1010$ and $m = 2023 = 2n+3$. Every $
k \in \{0,\dots,3^n-1\}$ has a unique base-3 representation $k = \sum_{i=0}^{n-1
} d_i 3^i$ with $d_i \in \{0,1,2\}$. Since $f(k)$ counts digits equal to 1, we h
ave $(-2)^{f(k)} = \prod_{i=0}^{n-1} g(d_i)$ where $g(0)=g(2)=1$, $g(1)=-2$. Thu
s

$$S(z) := \sum_{k=0}^{3^n-1} (-2)^{f(k)}(z+k)^m = \prod_{i=0}^{n-1}\bigl(E_0 - 2
E_{3^i} + E_{2\cdot 3^i}\bigr)[z^m],$$

where $E_a[p](z)=p(z+a)$. Since $E_0 - 2E_{3^i}+E_{2\cdot 3^i} = (e^{3^i D}-1)^2
$ with $D=d/dz$,

$$S(z) = \prod_{i=0}^{n-1}(e^{3^i D}-1)^2\,[z^m] = \left(\prod_{i=0}^{n-1}(e^{3^
i D}-1)\right)^{\!2}[z^m].$$

**Step 1: $S(z)$ has degree 3.** Since $e^{3^i D}-1 = (e^D-1)\cdot(1+e^D+\cdots+
e^{(3^i-1)D})$, we get

$$\prod_{i=0}^{n-1}(e^{3^i D}-1) = (e^D-1)^n \cdot Q(D)$$

where $Q$ is a power series in $e^D$ with $Q(0)=1$ (hence invertible). Since $e^
D-1 = D\cdot(1+D/2+\cdots)$, the operator $(e^D-1)^{2n}$ equals $D^{2n}$ times a
 unit, so it annihilates polynomials of degree $<2n$ and maps degree $m$ to degr
ee $m-2n$. With $m=2n+3$, **$S(z)$ is a polynomial of degree exactly 3**.

**Step 2: Symmetry — $S$ is odd about $z = -c$.** Set $c = \frac{3^n-1}{2}$ and
$w = z+c$. The map $k \mapsto 3^n-1-k$ sends each digit $d_i$ to $2-d_i$, preser
ving the count of 1's, so $(-2)^{f(3^n-1-k)} = (-2)^{f(k)}$. Also $a_k := k - c$
 satisfies $a_{3^n-1-k} = -a_k$. Therefore

$$S = \sum_k w_k(w+a_k)^m = \sum_k w_k(w-a_k)^m,$$

so $S(w) = \frac{1}{2}\sum_k w_k\bigl[(w+a_k)^m+(w-a_k)^m\bigr]$, which contains
 only **odd** powers of $w$ (since $m$ is odd). Being cubic and odd:

$$S(w) = Aw^3 + Bw$$

for constants $A \neq 0$, $B \neq 0$. The roots are $w=0$ and $w = \pm\sqrt{-B/A
}$.

**Step 3: Computing $B/A$ via a generating function.** Define

$$F(t) = \sum_k w_k\, e^{t a_k}, \qquad \text{so } \sum_k w_k\, a_k^j = F^{(j)}(
0).$$

Then $F(t) = e^{-ct}\sum_k w_k e^{tk} = e^{-ct}\prod_{i=0}^{n-1}(e^{t3^i}-1)^2$.

Using $(e^x-1)^2 = x^2 + x^3 + \frac{7}{12}x^4 + \cdots$, each factor $(e^{t3^i}
-1)^2 = t^2 3^{2i}\bigl(1 + t3^i + \frac{7}{12}t^2 3^{2i} + O(t^3)\bigr)$. Thus

$$F(t) = t^{2n}\cdot 3^{n(n-1)}\cdot G(t), \quad G(t) = e^{-ct}\prod_{i=0}^{n-1}
\Bigl(1 + t3^i + \tfrac{7}{12}t^2 3^{2i} + O(t^3)\Bigr).$$

Write $G(t) = 1 + g_1 t + g_2 t^2 + \cdots$. The moments are $M_j := \sum_k w_k
a_k^j = j!\cdot 3^{n(n-1)}\cdot g_{j-2n}$ for $j \geq 2n$ (and $0$ for $j < 2n$)
.

**Computing $g_1$ and $g_2$:** Let $P(t) = \prod_{i=0}^{n-1}\bigl(1 + t3^i + \fr
ac{7}{12}t^2 3^{2i}+\cdots\bigr)$. Its coefficients:
- $[t]\,P = \sum_i 3^i = c$,
- $[t^2]\,P = \frac{7}{12}\sum_i 9^i + \sum_{i<j}3^{i+j} = \frac{7}{12}\cdot\fra
c{9^n-1}{8} + \frac{c^2 - \frac{9^n-1}{8}}{2} = \frac{c^2}{2} + \frac{9^n-1}{96}
$.

Since $G(t) = e^{-ct}P(t) = \bigl(1 - ct + \frac{c^2}{2}t^2+\cdots\bigr)\bigl(1
+ ct + (\frac{c^2}{2}+\frac{9^n-1}{96})t^2+\cdots\bigr)$:

$$g_1 = c - c = 0, \qquad g_2 = \frac{c^2}{2} + \frac{c^2}{2} + \frac{9^n-1}{96}
 - c^2 = \frac{9^n-1}{96}.$$

(The vanishing of $g_1$ confirms the odd symmetry: all odd-indexed $g$'s are zer
o.)

**Step 4: Extracting $A$ and $B$.** Since $S(w) = \sum_{j=0}^{m}\binom{m}{j}w^{m
-j}M_j$ and only $j \in \{2n, 2n+2\}$ contribute (as $j=2n+1$ gives $g_1=0$ and
$j > 2n+2$ exceeds $m$):

$$A = \binom{m}{2n}M_{2n} = \binom{2n+3}{3}\cdot(2n)!\cdot 3^{n(n-1)},$$

$$B = \binom{m}{2n+2}M_{2n+2} = (2n+3)\cdot(2n+2)!\cdot 3^{n(n-1)}\cdot g_2.$$

Therefore

$$\frac{B}{A} = \frac{(2n+3)(2n+2)!\,g_2}{\binom{2n+3}{3}(2n)!} = \frac{(2n+3)(2
n+2)(2n+1)\,g_2}{\frac{(2n+3)(2n+2)(2n+1)}{6}} = 6g_2 = \frac{9^n - 1}{16}.$$

**Step 5: The roots.** From $S(w) = Aw^3 + Bw = 0$:

$$w = 0 \quad\text{or}\quad w^2 = -\frac{B}{A} = -\frac{9^n-1}{16}.$$

Since $n=1010 \geq 1$, we have $9^n - 1 > 0$, so $w = \pm\,\frac{i}{4}\sqrt{9^n-
1}$. Recalling $z = w - c = w - \frac{3^n-1}{2}$:

$$\boxed{z = -\frac{3^{1010}-1}{2}, \qquad z = -\frac{3^{1010}-1}{2} \pm \frac{i
}{4}\sqrt{9^{1010}-1}.}$$

**Verification with small cases.** For $n=1, m=5$: $S(z) = z^5 - 2(z+1)^5 + (z+2

 Our formula gives $c=1$, $w^2 = -\frac{8}{16}=-\frac{1}{2}$, so $z = -1\pm\frac

For $n=2, m=7$: our formula gives $c=4$, $w^2 = -\frac{80}{16}=-5$, so $z = -4\p
