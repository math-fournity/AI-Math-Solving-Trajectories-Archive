# Solution

**Answer: Yes, such functions exist.**

## Proof

We work on the interval $[a,b] = [0,1]$ (the construction generalizes to any $[a
,b]$). Consider the function
$$f(x) = x^2, \quad x \in [0,1].$$

**Step 1: $f$ is everywhere differentiable, neither linear nor constant.**

$f$ is a polynomial, hence differentiable at every point of $[0,1]$ (with one-si
ded derivatives $f'(0)=0$ and $f'(1)=2$ at the endpoints). It is not constant si
nce $f(0)=0 \neq 1 = f(1)$. It is not linear since $f''(x) = 2 \neq 0$.

**Step 2: Construct a sequence of continuous piecewise linear functions convergi
ng to $f$.**

For each $n \geq 1$, partition $[0,1]$ into $n$ equal subintervals with nodes $x
_k = k/n$, $k = 0, 1, \ldots, n$. Define $f_n$ to be the continuous piecewise li
near function that interpolates $f$ at each node:
$$f_n(x_k) = f(x_k) = (k/n)^2, \quad k = 0, 1, \ldots, n,$$
and $f_n$ is affine on each subinterval $[x_k, x_{k+1}]$.

Each $f_n$ is continuous (it agrees with $f$ at every node, so consecutive piece
s match at shared endpoints) and piecewise linear by construction.

**Step 3: $f_n \to f$ uniformly (hence pointwise) on $[0,1]$.**

On each subinterval $[x_k, x_{k+1}]$ of length $h = 1/n$, the function $f_n$ is
the linear interpolant of $f$ at the endpoints. A standard error bound for linea
r interpolation of a twice-continuously-differentiable function gives:
$$|f(x) - f_n(x)| \leq \frac{h^2}{8}\max_{[x_k, x_{k+1}]}|f''| = \frac{(1/n)^2}{
8}\cdot 2 = \frac{1}{4n^2}, \quad \text{for all } x \in [x_k, x_{k+1}].$$

This bound holds on every subinterval, so
$$\|f - f_n\|_\infty \leq \frac{1}{4n^2} \to 0 \quad \text{as } n \to \infty.$$

Thus $f_n \to f$ uniformly on $[0,1]$, and in particular $f = \lim_{n\to\infty}
f_n$ pointwise.

**Conclusion.**

The function $f(x) = x^2$ on $[0,1]$ is everywhere differentiable, is neither li
near nor constant, and is the limit of the sequence $\{f_n\}$ of continuous piec
ewise linear functions. Therefore, such functions exist. $\blacksquare$
