## Proof

Let the arithmetic progression be $s_n = a + (n-1)d$, where $a = s_1$ is the fir
st term and $d > 0$ is the common difference (positive integers).

**Step 1: Express $s_{s_k}$ in terms of $a$ and $d$.**

Since $s_1 = a$, $s_2 = a+d$, $s_3 = a+2d$, we compute:

$$s_{s_k} = a + (s_k - 1)d = a + (a + (k-1)d - 1)d = a(1+d) - d + (k-1)d^2.$$

Therefore:
- $s_{s_1} = a(1+d) - d$
- $s_{s_2} = a(1+d) - d + d^2$
- $s_{s_3} = a(1+d) - d + 2d^2$

**Step 2: Use the consecutive differences.**

The key observation is that consecutive values of $s_{s_k}$ differ by exactly $d
^2$:

$$s_{s_2} - s_{s_1} = d^2, \qquad s_{s_3} - s_{s_2} = d^2.$$

Substituting the given telemetry values:

$$s_{s_2} - s_{s_1} = (x^2 + 18) - (x + 2) = x^2 - x + 16,$$

$$s_{s_3} - s_{s_2} = (2x^2 + 18) - (x^2 + 18) = x^2.$$

**Step 3: Equate the two expressions for $d^2$.**

Since both differences equal $d^2$:

$$x^2 = x^2 - x + 16.$$

Solving:

$$x = 16.$$

**Step 4: Verify consistency.**

With $x = 16$: $d^2 = x^2 = 256$, so $d = 16$ (taking the positive value).

Now solve for $a$ using $s_{s_1} = x + 2 = 18$:

$$a(1 + d) - d = 18 \implies a \cdot 17 - 16 = 18 \implies 17a = 34 \implies a =
 2.$$

Check all three conditions:
- $s_{s_1} = 2 \cdot 17 - 16 = 18 = 16 + 2$ ✓
- $s_{s_2} = 18 + 256 = 274 = 16^2 + 18 = 256 + 18$ ✓
- $s_{s_3} = 18 + 512 = 530 = 2 \cdot 256 + 18$ ✓

The progression is $s_n = 2 + (n-1)\cdot 16 = 16n - 14$, which gives positive in
tegers for all $n \geq 1$ ($s_1 = 2$).

**Conclusion:** The calibration constant is

$$\boxed{x = 16}.$$
