# Steenrod Squares on Powers of a Degree-1 Class

**Problem.** Compute $Sq^{i}(\alpha^{n})$ for $\alpha \in H^{1}(X; \mathbb{Z}_{2
})$.

## Answer

$$\boxed{Sq^{i}(\alpha^{n}) = \binom{n}{i}\,\alpha^{n+i}}$$

where the binomial coefficient is reduced mod $2$ (so the result is $0$ whenever
 $\binom{n}{i}$ is even, in particular when $i > n$).

---

## Proof

We use three standard properties of the Steenrod algebra $\mathcal{A}_2$ acting
on $H^*(X;\mathbb{Z}_2)$:

**(P1) Instability / Top square.** For $x \in H^d(X;\mathbb{Z}_2)$:
$$Sq^d(x) = x^2, \qquad Sq^i(x) = 0 \text{ for } i > d, \qquad Sq^0(x) = x.$$

**(P2) Cartan formula.**
$$Sq^i(x \smile y) = \sum_{j+k=i} Sq^j(x)\smile Sq^k(y).$$

**(P3) Action on degree 1.** Since $\deg \alpha = 1$, by (P1):
$$Sq^0(\alpha) = \alpha, \quad Sq^1(\alpha) = \alpha^2, \quad Sq^j(\alpha) = 0 \
;\text{for}\; j \ge 2.$$

### Induction

We prove by induction on $n \ge 1$ that

$$Sq^i(\alpha^n) = \binom{n}{i}\,\alpha^{n+i} \quad \text{for all } i \ge 0,$$

with the convention $\binom{n}{i}=0$ for $i>n$ (so the formula automatically enc
odes the instability vanishing $Sq^i(\alpha^n)=0$ for $i>n$, since $\deg(\alpha^
n)=n$).

**Base case $n=1$.** By (P3): $Sq^0(\alpha)=\alpha=\binom{1}{0}\alpha^1$ and $Sq
^1(\alpha)=\alpha^2=\binom{1}{1}\alpha^2$, and $Sq^i(\alpha)=0=\binom{1}{i}\alph
a^{1+i}$ for $i>1$. ✓

**Inductive step.** Assume the formula holds for $\alpha^{n-1}$. Write $\alpha^n
 = \alpha \smile \alpha^{n-1}$ and apply the Cartan formula (P2):

$$Sq^i(\alpha^n) = \sum_{j+k=i} Sq^j(\alpha)\smile Sq^k(\alpha^{n-1}).$$

By (P3), $Sq^j(\alpha)$ is nonzero only for $j \in \{0,1\}$, so the sum collapse
s to two terms:

$$Sq^i(\alpha^n) = \underbrace{Sq^0(\alpha)}_{=\,\alpha}\smile Sq^i(\alpha^{n-1}
) \;+\; \underbrace{Sq^1(\alpha)}_{=\,\alpha^2}\smile Sq^{i-1}(\alpha^{n-1}).$$

Applying the induction hypothesis to each term:

$$Sq^i(\alpha^n) = \alpha \smile \binom{n-1}{i}\alpha^{(n-1)+i} \;+\; \alpha^2 \
smile \binom{n-1}{i-1}\alpha^{(n-1)+(i-1)}.$$

Both terms land in degree $(1)+(n-1+i) = (2)+(n-2+i) = n+i$, and equal

$$Sq^i(\alpha^n) = \binom{n-1}{i}\,\alpha^{n+i} + \binom{n-1}{i-1}\,\alpha^{n+i}
 = \left[\binom{n-1}{i}+\binom{n-1}{i-1}\right]\alpha^{n+i}.$$

By **Pascal's identity** $\binom{n-1}{i}+\binom{n-1}{i-1}=\binom{n}{i}$, and sin
ce we work over $\mathbb{Z}_2$ the addition is mod $2$:

$$Sq^i(\alpha^n) = \binom{n}{i}\,\alpha^{n+i}. \qquad \blacksquare$$

---

## Remarks

- **Mod-2 binomial coefficients.** The coefficient $\binom{n}{i} \bmod 2$ is det
ermined by **Lucas' theorem**: $\binom{n}{i}\equiv 1\pmod 2$ if and only if ever
y binary digit of $i$ is $\le$ the corresponding binary digit of $n$ (equivalent
ly, $i\;\&\;n = i$ bitwise). Otherwise the square vanishes.

- **Consistency checks.**
  - For $i=0$: $Sq^0(\alpha^n)=\binom{n}{0}\alpha^n=\alpha^n$. ✓ (identity axiom
)
  - For $i=n$: $Sq^n(\alpha^n)=\binom{n}{n}\alpha^{2n}=\alpha^{2n}=(\alpha^n)^2$
. ✓ (top square / instability)
  - For $i>n$: $\binom{n}{i}=0$, so $Sq^i(\alpha^n)=0$. ✓ (instability vanishing
)

- **Example.** $n=2$: $Sq^1(\alpha^2)=\binom{2}{1}\alpha^3 = 0$ (since $2$ is ev
en), and $Sq^2(\alpha^2)=\alpha^4$. This reflects the Adem relation $Sq^1Sq^1=0$
 applied via $Sq^1(\alpha^2)=Sq^1(\alpha\smile\alpha)=Sq^0(\alpha)Sq^1(\alpha)+S
q^1(\alpha)Sq^0(\alpha)=\alpha^3+\alpha^3=0$.
