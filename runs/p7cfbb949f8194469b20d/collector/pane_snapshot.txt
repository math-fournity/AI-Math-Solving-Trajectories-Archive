## Solution

**Claim:** The only function satisfying the condition is $f(x) = \dfrac{1}{x}$.

---

### Verification

For $f(x)=1/x$, the expression becomes $xf(y)+yf(x)=\dfrac{x}{y}+\dfrac{y}{x}\ge
q 2$ by AM-GM, with equality if and only if $x=y$. Thus for each $x$, the unique
 $y$ satisfying $\leq 2$ is $y=x$. ✓

---

### Proof of Uniqueness

For each $x>0$, let $\phi(x)$ denote the unique $y>0$ with $xf(y)+yf(x)\leq 2$.

**Step 1: $\phi$ is an involution.** The expression $F(x,y)=xf(y)+yf(x)$ is symm
etric: $F(x,y)=F(y,x)$. If $y=\phi(x)$, then $F(x,y)\leq 2$, so $F(y,x)\leq 2$,
meaning $x$ satisfies the inequality for the given $y$. By uniqueness, $\phi(y)=
x$. Hence $\phi(\phi(x))=x$.

**Step 2: $\phi(x)=x$ for all $x$.** Suppose for contradiction that $\phi(a)=b\n
eq a$. Since $\phi(a)\neq a$, the value $y=a$ does **not** satisfy the inequalit
y for $x=a$, so $F(a,a)=2af(a)>2$, giving $f(a)>1/a$. Similarly $F(b,b)=2bf(b)>2
$, giving $f(b)>1/b$.

Now using these bounds in $F(a,b)$:
$$F(a,b)=af(b)+bf(a)>\frac{a}{b}+\frac{b}{a}\geq 2,$$
where the last inequality is AM-GM, strict since $a\neq b$. This contradicts $F(
a,b)\leq 2$. Therefore $\phi(x)=x$ for all $x$.

**Step 3: Derive $f(x)=1/x$.** With $\phi(x)=x$, two conditions hold for every $
x>0$:

1. **Inequality holds at $y=x$:** $2xf(x)\leq 2$, so $f(x)\leq \dfrac{1}{x}$.
2. **Inequality fails for all $y\neq x$:** $xf(y)+yf(x)>2$ for all $y>0,\; y\neq
 x$.

Fix any $c>0$ and set $A=cf(c)$. From condition (1), $A\leq 1$.

From condition (2), for all $y\neq c$: $cf(y)+yf(c)>2$. Since $f(y)\leq 1/y$ (co
ndition (1) applied to $y$), we get
$$\frac{c}{y}+yf(c)\;\geq\; cf(y)+yf(c)\;>\;2.$$
Substituting $y=ct$ (with $t>0,\; t\neq 1$):
$$\frac{1}{t}+At>2 \quad\text{for all } t>0,\; t\neq 1.$$

The function $h(t)=\frac{1}{t}+At$ (for $t>0$) attains its minimum $2\sqrt{A}$ a
t $t=1/\sqrt{A}$.

- If $A<1$: then $2\sqrt{A}<2$ and the minimizer $t=1/\sqrt{A}\neq 1$, so $h(t)=
2\sqrt{A}<2$ at some $t\neq 1$—**contradiction**.
- If $A=1$: then $h(t)=\frac{1}{t}+t\geq 2$ with equality iff $t=1$, so $h(t)>2$
 for all $t\neq 1$. ✓

Therefore $A=cf(c)=1$, i.e., $f(c)=\dfrac{1}{c}$.

Since $c>0$ was arbitrary, $f(x)=\dfrac{1}{x}$ for all $x\in\mathbb{R}^+$.
