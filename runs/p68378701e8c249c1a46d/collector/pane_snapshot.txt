## Solution

**Setup.** Label the 21 sensors by precision rating 1–21; Alice owns sensor 11.
Represent the process as a random permutation π(0), π(1), …, π(20) of all 21 sen
sors, where π(0) is the initial primary and π(j) is the sensor drawn from standb
y at stage j (j = 1,…,20). After each stage the primary is the maximum-rated sen
sor among all tested so far.

**Linearity of expectation.** Let I_j be the indicator that sensor 11 participat
es in stage j. Then E = Σ_{j=1}^{20} P(I_j = 1).

Sensor 11 participates in stage j iff either:
- **(A)** It is the current primary at the start of stage j (i.e., it is the max
 of {π(0),…,π(j−1)} and belongs to that set), or
- **(B)** It is drawn at stage j (π(j) = 11).

These are mutually exclusive, so P(I_j = 1) = P(A) + P(B).

**Computing P(B).** Since π is a uniform random permutation, P(π(j) = 11) = 1/21
.

**Computing P(A).** The first j positions hold a uniform random j-subset of the
21 sensors.
- P(sensor 11 ∈ first j positions) = j/21.
- Given this, sensor 11 is the maximum iff all other j−1 sensors come from {1,…,
10}, which has probability C(10, j−1)/C(20, j−1) (zero when j−1 > 10).

So: P(A) = (j/21) · C(10, j−1)/C(20, j−1).

**Summing.**

$$E = \sum_{j=1}^{20}\left[\frac{j}{21}\cdot\frac{\binom{10}{j-1}}{\binom{20}{j-
1}} + \frac{1}{21}\right] = \frac{20}{21} + \frac{1}{21}\sum_{j=1}^{20} j\cdot\f
rac{\binom{10}{j-1}}{\binom{20}{j-1}}.$$

Substituting m = j−1 (and noting C(10,m)=0 for m>10):

$$T := \sum_{m=0}^{10}(m+1)\frac{\binom{10}{m}}{\binom{20}{m}} = \underbrace{\su
m_{m=0}^{10}\frac{\binom{10}{m}}{\binom{20}{m}}}_{A} + \underbrace{\sum_{m=0}^{1
0} m\frac{\binom{10}{m}}{\binom{20}{m}}}_{B}.$$

**Evaluating A.** Using the identity C(10,m)/C(20,m) = C(20−m,10)/C(20,10) and t
he hockey-stick identity:

$$A = \frac{1}{\binom{20}{10}}\sum_{m=0}^{10}\binom{20-m}{10} = \frac{\binom{21}
{11}}{\binom{20}{10}} = \frac{21}{11}.$$

**Evaluating B.** Similarly:

$$B = \frac{1}{\binom{20}{10}}\sum_{m=0}^{10} m\binom{20-m}{10}.$$

Substituting r = 20−m:

$$\sum_{m=0}^{10} m\binom{20-m}{10} = \sum_{r=10}^{20}(20-r)\binom{r}{10} = 20\b
inom{21}{11} - \sum_{r=10}^{20}r\binom{r}{10}.$$

Using r·C(r,10) = 10·C(r,10) + 11·C(r,11) and hockey-stick:

$$\sum_{r=10}^{20} r\binom{r}{10} = 10\binom{21}{11} + 11\binom{21}{12}.$$

Since C(21,12)/C(21,11) = 10/12 = 5/6:

$$\sum_{m=0}^{10} m\binom{20-m}{10} = 10\binom{21}{11} - 11\cdot\frac{5}{6}\bino
m{21}{11} = \frac{5}{6}\binom{21}{11}.$$

Therefore:

$$B = \frac{5}{6}\cdot\frac{\binom{21}{11}}{\binom{20}{10}} = \frac{5}{6}\cdot\f
rac{21}{11} = \frac{35}{22}.$$

**Combining.**

$$T = A + B = \frac{21}{11} + \frac{35}{22} = \frac{42+35}{22} = \frac{77}{22} =
 \frac{7}{2}.$$

$$E = \frac{20}{21} + \frac{1}{21}\cdot\frac{7}{2} = \frac{40+7}{42} = \frac{47}
