## Solution

Let $\hat a, \hat b, \hat c$ be unit vectors along $OA, OB, OC$. The given angul
ar separations at $O$ are:

$$\hat a\cdot\hat b = \cos 60^\circ = \tfrac12,\quad \hat a\cdot\hat c = \cos 12
0^\circ = -\tfrac12,\quad \hat b\cdot\hat c = \cos 90^\circ = 0.$$

The dihedral angle $\theta$ between the planes $OAB$ and $OAC$ is measured along
 their common edge $OA$. Its cosine is given by the angle between the two plane
normals $\hat n_1 = \hat a\times\hat b$ and $\hat n_2 = \hat a\times\hat c$:

$$\cos\theta = \frac{(\hat a\times\hat b)\cdot(\hat a\times\hat c)}{|\hat a\time
s\hat b|\,|\hat a\times\hat c|}.$$

Using the vector identity $(\hat a\times\hat b)\cdot(\hat a\times\hat c) = (\hat
 a\cdot\hat a)(\hat b\cdot\hat c) - (\hat a\cdot\hat c)(\hat b\cdot\hat a)$:

$$\text{numerator} = 1\cdot 0 - \left(-\tfrac12\right)\left(\tfrac12\right) = \t
frac14.$$

The magnitudes are $|\hat a\times\hat b| = \sin 60^\circ$ and $|\hat a\times\hat
 c| = \sin 120^\circ = \sin 60^\circ$, so

$$\cos\theta = \frac{\tfrac14}{\sin^2 60^\circ} = \frac{\tfrac14}{\tfrac34} = \f
rac13.$$

Since $\cos\theta = \tfrac13 > 0$, $\theta$ is already acute, confirming $\theta
$ is the acute dihedral angle. Therefore

$$\cos^2\theta = \frac19.$$

In lowest terms, $m = 1$ and $n = 9$ (relatively prime), so

$$100m + n = 100\cdot 1 + 9 = \boxed{109}.$$
