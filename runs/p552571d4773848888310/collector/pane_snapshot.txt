Looking at this problem, I need to analyze what constraints the pointwise conver
gence of $e^{ix_ny}$ to a **real-valued** function $f$ on a positive-measure set
 imposes, and whether $f$ must have a nonzero integral over some interval.

**Answer: Yes, there exists an interval $I$ such that $\int_I f(y)\,dy \neq 0$.*
*

**Proof.**

Let $S = \{y \in \mathbb{R} : \lim_{n\to\infty} e^{ix_n y} = f(y)\}$ with $m(S)
> 0$.

**Step 1. $f(y) \in \{-1,+1\}$ on $S$.**

Since $|e^{ix_n y}|=1$ for all $n,y$, any pointwise limit satisfies $|f(y)|=1$.
As $f:\mathbb{R}\to\mathbb{R}$, we get $f(y)\in\{-1,+1\}$ for every $y\in S$.

**Step 2. $e^{2ix_ny}\to 1$ on $S$.**

For $y\in S$: $e^{2ix_ny}=(e^{ix_ny})^2 \to f(y)^2 = 1.$

**Step 3. $x_n \to 0$.**

Since $m(S)>0$, by the Steinhaus theorem $S-S$ contains an open interval $(-\del
ta,\delta)$ for some $\delta>0$. For any $z\in(-\delta,\delta)$, write $z=y_1-y_
2$ with $y_1,y_2\in S$. Then
$$e^{2ix_nz}=e^{2ix_ny_1}\cdot e^{-2ix_ny_2}\to 1\cdot\overline{1}=1.$$
By dominated convergence (the integrands are bounded by $1$):
$$\int_{-\delta}^{\delta}e^{2ix_nz}\,dz \;\to\; \int_{-\delta}^{\delta}1\,dz = 2
\delta.$$
Computing the left side:
$$\int_{-\delta}^{\delta}e^{2ix_nz}\,dz = \frac{2\sin(2x_n\delta)}{2x_n}=\frac{\
sin(2x_n\delta)}{x_n},$$
so $\frac{\sin(2x_n\delta)}{2x_n\delta}\to 1$. Since $\operatorname{sinc}(t):=\f
rac{\sin t}{t}$ equals $1$ only at $t=0$ and $\operatorname{sinc}(t)\to 1$ force
s $t\to 0$ (for $|t|\geq\epsilon>0$, $|\operatorname{sinc}(t)|\leq\min(1,1/|t|)<
1$ and the Taylor expansion $1-t^2/6+O(t^4)$ bounds it away from $1$), we conclu
de $2x_n\delta\to 0$, hence $x_n\to 0$.

**Step 4. $f(y)=1$ on $S$.**

Since $x_n\to 0$, for every $y\in\mathbb{R}$ we have $e^{ix_ny}\to e^{0}=1$. Thu
s $f(y)=1$ for all $y\in S$.

**Step 5. There exists an interval $I$ with $\int_I f(y)\,dy\neq 0$.**

Since $m(S)>0$ and $\mathbb{R}=\bigcup_k[-k,k]$, some bounded interval $I_0$ sat
isfies $m(S\cap I_0)>0$. The function $f$ is measurable (the question about $\in
t_I f$ presumes $f\in L^1_{\mathrm{loc}}$, hence measurability), and $f=1$ on $S
$ with $m(S)>0$, so $f$ is **not** zero almost everywhere.

Suppose for contradiction that $\int_I f(y)\,dy=0$ for every interval $I\subsete
q\mathbb{R}$. Set $F(x)=\int_0^x f(y)\,dy$. Then $F(b)-F(a)=\int_a^b f=0$ for al
l $a<b$, so $F$ is constant and $F'(x)=0$ everywhere. By the Lebesgue differenti
ation theorem, $F'(x)=f(x)$ for a.e. $x$, giving $f=0$ a.e. This contradicts $f=
1$ on $S$ with $m(S)>0$.

Therefore, there exists an interval $I$ such that $\int_I f(y)\,dy\neq 0$. $\bla
cksquare$
