Looking at this problem, I need to evaluate:

$$L = \lim_{x\to \infty} \frac{\int_{1}^{x} t^{t-1} ( t + t\ln t +1 )\, dt}{x^x}
$$

## Step 1: Decompose the integrand

I recognize that $\frac{d}{dt}[t^t] = t^t(\ln t + 1) = t^{t-1}\cdot t(\ln t + 1)
 = t^{t-1}(t\ln t + t)$.

Therefore:
$$t^{t-1}(t + t\ln t + 1) = \underbrace{t^{t-1}(t\ln t + t)}_{\frac{d}{dt}[t^t]}
 + \, t^{t-1}$$

## Step 2: Integrate

$$\int_1^x t^{t-1}(t + t\ln t + 1)\,dt = \big[t^t\big]_1^x + \int_1^x t^{t-1}\,d
t = (x^x - 1) + \int_1^x t^{t-1}\,dt$$

## Step 3: Compute the limit

$$L = \lim_{x\to\infty}\frac{x^x - 1 + \int_1^x t^{t-1}\,dt}{x^x} = 1 - \underbr
ace{\lim_{x\to\infty}\frac{1}{x^x}}_{=\,0} + \lim_{x\to\infty}\frac{\int_1^x t^{
t-1}\,dt}{x^x}$$

It remains to show $\displaystyle\lim_{x\to\infty}\frac{\int_1^x t^{t-1}\,dt}{x^
x} = 0$.

## Step 4: Bound the remaining integral

Since $\frac{d}{dt}[t^{t-1}] = t^{t-1}\!\left(\ln t + 1 - \tfrac{1}{t}\right) >
0$ for $t > 1$, the function $t^{t-1}$ is **increasing** on $[1,\infty)$.

**Split the integral:** $\displaystyle\int_1^x t^{t-1}\,dt = \int_1^{x-1} t^{t-1
}\,dt + \int_{x-1}^{x} t^{t-1}\,dt$.

**First piece** ($t \in [1, x-1]$): Since $t^{t-1}$ is increasing, $t^{t-1} \le
(x-1)^{x-2}$, so
$$\int_1^{x-1} t^{t-1}\,dt \le (x-1)^{x-2}\cdot(x-2).$$
Dividing by $x^x$:
$$\frac{(x-1)^{x-2}(x-2)}{x^x} = \frac{x-2}{x^2}\cdot\left(1-\frac{1}{x}\right)^
{x-2} \;\longrightarrow\; 0\cdot\frac{1}{e} = 0.$$

**Second piece** ($t \in [x-1, x]$): Since $t^{t-1}$ is increasing, $t^{t-1} \le
 x^{x-1}$, so
$$\int_{x-1}^{x} t^{t-1}\,dt \le x^{x-1}\cdot 1 = \frac{x^x}{x}.$$
Dividing by $x^x$:
$$\frac{1}{x} \;\longrightarrow\; 0.$$

Both pieces vanish, so $\displaystyle\lim_{x\to\infty}\frac{\int_1^x t^{t-1}\,dt
}{x^x} = 0$.

## Conclusion

$$L = 1 - 0 + 0 = \boxed{1}$$
