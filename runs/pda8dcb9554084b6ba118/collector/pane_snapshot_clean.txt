## Proof

Let $f(t,w) = (w+t)\,e^{-w+kt}$. Then $Y_t = f(t,W_t)$, and we apply Itô's lemma
 to $f(t,W_t)$, where $W_t$ satisfies $dW_t = dW_t$ (zero drift, unit diffusion)
 and $dt = dt$.

**Partial derivatives.**

$$f_w = e^{-w+kt} + (w+t)(-1)e^{-w+kt} = e^{-w+kt}\bigl(1 - (w+t)\bigr).$$

$$f_{ww} = -e^{-w+kt}\bigl(1-(w+t)\bigr) + e^{-w+kt}(-1) = e^{-w+kt}\bigl((w+t)-
2\bigr).$$

$$f_t = (w+t)\,k\,e^{-w+kt} + e^{-w+kt}\cdot 1 = e^{-w+kt}\bigl(1 + k(w+t)\bigr)
.$$

**Itô's formula.**

$$dY_t = \left(f_t + \tfrac{1}{2}f_{ww}\right)dt + f_w\,dW_t.$$

So the drift coefficient of $Y_t$ is

$$f_t + \tfrac{1}{2}f_{ww} = e^{-w+kt}\left[1 + k(w+t) + \tfrac{1}{2}\bigl((w+t)
-2\bigr)\right].$$

Expanding the bracket:

$$1 + k(w+t) + \tfrac{1}{2}(w+t) - 1 = (w+t)\left(k + \tfrac{1}{2}\right).$$

Hence

$$\text{drift}(Y_t) = e^{-W_t+kt}\,(W_t+t)\left(k + \tfrac{1}{2}\right).$$

**Zero-drift condition.** The prefactor $e^{-W_t+kt}(W_t+t)$ is not identically
zero (e.g. at $t>0$ with $W_t = 0$ it equals $t\,e^{kt}\neq 0$). Therefore the d
rift vanishes for all $t\ge 0$ and all sample paths if and only if

$$k + \tfrac{1}{2} = 0,$$

i.e.

$$\boxed{k = -\dfrac{1}{2}.}$$

**Verification.** With $k=-\tfrac{1}{2}$, the drift bracket becomes $(W_t+t)(-\t
frac{1}{2}+\tfrac{1}{2}) = 0$, so

$$dY_t = e^{-W_t - t/2}\bigl(1-(W_t+t)\bigr)\,dW_t,$$

a (local) martingale with zero drift, as required. The integrand satisfies the u
sual integrability conditions on compact time intervals, so $Y_t$ is a true mart
ingale up to any finite horizon.
