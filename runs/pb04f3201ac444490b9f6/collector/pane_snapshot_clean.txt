## Proof

**Setup.** Recall the exponential generating function (EGF) for permutations who
se cycles all have length $> k$. A permutation is a set of cycles, and the EGF f
or a single cycle of length $j$ is $z^{j}/j$. Hence the EGF for permutations wit
h every cycle longer than $k$ is

$$\exp\!\Big(\sum_{j>k}\frac{z^{j}}{j}\Big).$$

Using $\sum_{j\ge 1} z^{j}/j = -\log(1-z)$, we split off the first $k$ terms:

$$\sum_{j>k}\frac{z^{j}}{j} = -\log(1-z) - \sum_{j=1}^{k}\frac{z^{j}}{j},$$

so that

$$\exp\!\Big(\sum_{j>k}\frac{z^{j}}{j}\Big) = \frac{1}{1-z}\,\exp\!\Big(-\sum_{j
=1}^{k}\frac{z^{j}}{j}\Big) = D^{(k)}(z).$$

Thus $[z^{n}]\,D^{(k)}(z) = \dfrac{1}{n!}\,\#\{\text{permutations of }[n]\text{
with shortest cycle } > k\}$, i.e. it is the probability that a uniform random p
ermutation of $n$ has no cycle of length $\le k$.

**Singularity structure.** Write

$$D^{(k)}(z) = \frac{A(z)}{1-z}, \qquad A(z) := \exp\!\Big(-\sum_{j=1}^{k}\frac{
z^{j}}{j}\Big).$$

The exponent $P_{k}(z) := \sum_{j=1}^{k} z^{j}/j$ is a polynomial, so $A(z) = e^
{-P_{k}(z)}$ is an **entire** function. Consequently $D^{(k)}(z)$ is meromorphic
 in the whole plane, with a single pole at $z = 1$ (simple pole coming from $1/(
1-z)$). There are no other singularities on $|z| = 1$ or anywhere else.

**Coefficient extraction.** Let $a_{m} := [z^{m}]\,A(z)$. Since $A$ is entire, i
ts Taylor series converges absolutely everywhere, in particular at $z = 1$:

$$\sum_{m\ge 0} a_{m} = A(1).$$

Now $D^{(k)}(z) = A(z)\cdot\frac{1}{1-z} = A(z)\sum_{r\ge 0}z^{r}$, so by Cauchy
 convolution

$$[z^{n}]\,D^{(k)}(z) = \sum_{m=0}^{n} a_{m} = A(1) - \sum_{m > n} a_{m}.$$

Because $A$ is entire, $a_{m}\to 0$ faster than any geometric rate; in fact $|a_
{m}| = O\!\big((1/m!)^{\text{const}}\big)$-type decay holds (the coefficients of
 an entire function of finite order decay super-exponentially). Therefore the ta
il $\sum_{m>n} a_{m}$ is $o(1)$, indeed exponentially (even super-exponentially)
 small:

$$\sum_{m > n} a_{m} \xrightarrow{n\to\infty} 0.$$

**Evaluating the limit.** At $z = 1$,

$$A(1) = \exp\!\Big(-\sum_{j=1}^{k}\frac{1}{j}\Big) = e^{-H_{k}},$$

where $H_{k} = 1 + \tfrac{1}{2} + \cdots + \tfrac{1}{k}$ is the $k$-th harmonic
number.

**Conclusion.** For fixed $k$, as $n\to\infty$,

$$\boxed{[z^{n}]\,D^{(k)}(z) \;\sim\; e^{-H_{k}} \;=\; \exp\!\Big(-\sum_{j=1}^{k
}\frac{1}{j}\Big).}$$

Equivalently, the probability that a uniform random permutation of $n$ has short
est cycle of length strictly greater than $k$ tends to $e^{-H_{k}}$ as $n\to\inf
ty$. This agrees with the classical Poisson–Dirichlet / Feller interpretation: f
or fixed $j$, the number of $j$-cycles in a uniform permutation of $n$ converges
 in distribution to independent $\mathrm{Poisson}(1/j)$ random variables, so the
 probability of having no cycles of lengths $1,\dots,k$ is $\prod_{j=1}^{k}e^{-1
/j} = e^{-H_{k}}$.
