Looking at this problem, I need to determine the asymptotic distribution of a on
e-sided likelihood ratio test statistic under $H_0: \mu = \mu_0$.

## Proof

**Setup.** Let $X_1, \dots, X_n \stackrel{iid}{\sim} N(\mu, \sigma^2)$. The stat
istic

$$\text{LR}(\mu_0,\mu_1) = -2\ln\frac{L(\mathbf{x}\mid\mu_0,\sigma^2)}{\max\{L(\
mathbf{x}\mid\mu_0,\sigma^2),\, L(\mathbf{x}\mid\mu_1,\sigma^2)\}}$$

corresponds to testing $H_0: \mu = \mu_0$ against a **one-sided** alternative, w
here $\mu_1$ represents the constrained MLE over the alternative parameter space
 $\mu \geq \mu_0$ (WLOG; the case $\mu \leq \mu_0$ is symmetric). The $\max$ in
the denominator equals $\sup_{\mu \geq \mu_0} L(\mu)$, achieved at $\hat{\mu}_c
= \max\{\bar{X},\, \mu_0\}$.

---

**Case 1: $\sigma^2$ known.**

The log-likelihood is $\ell(\mu) = -\frac{1}{2\sigma^2}\sum_{i=1}^n (X_i - \mu)^
2 + \text{const}$. The unconstrained MLE is $\hat{\mu} = \bar{X}$; the constrain
ed MLE over $\mu \geq \mu_0$ is $\hat{\mu}_c = \max\{\bar{X},\, \mu_0\}$.

$$\text{LR} = -2\bigl[\ell(\mu_0) - \ell(\hat{\mu}_c)\bigr] = \frac{n}{\sigma^2}
\Bigl[(\bar{X}-\mu_0)^2 - (\bar{X}-\hat{\mu}_c)^2\Bigr].$$

- **If $\bar{X} \geq \mu_0$:** $\hat{\mu}_c = \bar{X}$, so $\text{LR} = \frac{n(
\bar{X}-\mu_0)^2}{\sigma^2}$.
- **If $\bar{X} < \mu_0$:** $\hat{\mu}_c = \mu_0$, so $\text{LR} = 0$.

Under $H_0$, define $Z = \frac{\sqrt{n}(\bar{X}-\mu_0)}{\sigma} \sim N(0,1)$. Th
en:

$$\text{LR} = \begin{cases} Z^2 & \text{if } Z \geq 0, \\ 0 & \text{if } Z < 0,
\end{cases} \;=\; \bigl(\max\{0,\, Z\}\bigr)^2 = (Z^+)^2.$$

**CDF.** For $x > 0$:

$$P(\text{LR} \leq x) = P(Z < 0) + P(0 \leq Z \leq \sqrt{x}) = \tfrac{1}{2} + \b
igl[\Phi(\sqrt{x}) - \tfrac{1}{2}\bigr] = \Phi(\sqrt{x}).$$

Since the CDF of $\chi^2_1$ is $F_{\chi^2_1}(x) = 2\Phi(\sqrt{x}) - 1$ for $x >
0$:

$$P(\text{LR} \leq x) = \tfrac{1}{2} + \tfrac{1}{2}\,F_{\chi^2_1}(x), \qquad x \
geq 0.$$

This is exactly the CDF of $\;\frac{1}{2}\,\delta_0 + \frac{1}{2}\,\chi^2_1$, a
50–50 mixture of a point mass at $0$ and a $\chi^2_1$ distribution.

---

**Case 2: $\sigma^2$ unknown (profile likelihood).**

With $\hat{\sigma}^2(\mu) = \frac{1}{n}\sum(X_i - \mu)^2 = S^2 + (\bar{X}-\mu)^2
$ where $S^2 = \frac{1}{n}\sum(X_i-\bar{X})^2$:

$$\text{LR} = n\ln\frac{\hat{\sigma}^2(\mu_0)}{\hat{\sigma}^2(\hat{\mu}_c)} = n\
ln\frac{S^2 + (\bar{X}-\mu_0)^2}{S^2 + (\bar{X}-\hat{\mu}_c)^2}.$$

- **If $\bar{X} \geq \mu_0$:** $\hat{\mu}_c = \bar{X}$, so $\text{LR} = n\ln\!\B
igl(1 + \frac{(\bar{X}-\mu_0)^2}{S^2}\Bigr)$.

  Under $H_0$: $\frac{n(\bar{X}-\mu_0)^2}{\sigma^2} = Z^2$ and $S^2 \xrightarrow
{p} \sigma^2$, so $\frac{(\bar{X}-\mu_0)^2}{S^2} = \frac{Z^2}{n}\cdot\frac{\sigm
a^2}{S^2} \xrightarrow{p} 0$. Using $\ln(1+u) \sim u$ for $u \to 0$:

  $$\text{LR} = n\ln\!\Bigl(1 + \frac{Z^2}{n}\cdot\frac{\sigma^2}{S^2}\Bigr) \xr
ightarrow{d} n\cdot\frac{Z^2}{n}\cdot 1 = Z^2.$$

- **If $\bar{X} < \mu_0$:** $\hat{\mu}_c = \mu_0$, so $\text{LR} = 0$.

Thus $\text{LR} \xrightarrow{d} (Z^+)^2 \sim \frac{1}{2}\,\delta_0 + \frac{1}{2}
\,\chi^2_1$, the same result.

---

**Why Wilks' standard theorem fails.** The null value $\mu = \mu_0$ lies on the
**boundary** of the one-sided alternative parameter space $\{\mu : \mu \geq \mu_
0\}$. The standard Wilks theorem requires the null to be an interior point, so $
\chi^2_1$ does not apply. Instead, by the boundary case results (Self & Liang, 1
987), the asymptotic distribution is the **chi-bar-squared** distribution:

$$\boxed{\text{LR} \;\xrightarrow{d}\; \tfrac{1}{2}\,\delta_0 + \tfrac{1}{2}\,\c
hi^2_1 \;=\; \bar{\chi}^2_1.}$$

Equivalently, $P(\text{LR} = 0) \to \frac{1}{2}$ and, conditional on $\text{LR}
> 0$, $\text{LR} \xrightarrow{d} \chi^2_1$.
