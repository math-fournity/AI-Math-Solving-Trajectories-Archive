## Solution

We compute $\displaystyle I = \int \frac{x\,dx}{\sin^3 x} = \int x\,\csc^3 x\,dx
$ by **integration by parts**, taking $u = x$ and $dv = \csc^3 x\,dx$.

### Step 1. Antiderivative of $\csc^3 x$

Integrate by parts with $u=\csc x$, $dv=\csc^2 x\,dx$, so $du=-\csc x\cot x\,dx$
, $v=-\cot x$:

$$\int \csc^3 x\,dx = -\csc x\cot x - \int \csc x\cot^2 x\,dx = -\csc x\cot x -
\int \csc x(\csc^2 x-1)\,dx$$

$$= -\csc x\cot x - \int \csc^3 x\,dx + \int \csc x\,dx.$$

Using $\displaystyle\int \csc x\,dx = \ln\!\left|\tan\tfrac{x}{2}\right|+C$ and
solving for the integral:

$$\boxed{\;\int \csc^3 x\,dx = -\tfrac{1}{2}\csc x\cot x + \tfrac{1}{2}\ln\!\lef
t|\tan\tfrac{x}{2}\right| + C\;}$$

### Step 2. Integration by parts on $I$

Set $v = -\frac{1}{2}\csc x\cot x + \frac{1}{2}\ln\!\left|\tan\frac{x}{2}\right|
$, $du=dx$:

$$I = x\!\left(-\tfrac{1}{2}\csc x\cot x + \tfrac{1}{2}\ln\!\left|\tan\tfrac{x}{
2}\right|\right) - \int\!\left(-\tfrac{1}{2}\csc x\cot x + \tfrac{1}{2}\ln\!\lef
t|\tan\tfrac{x}{2}\right|\right)dx$$

$$= -\tfrac{x}{2}\csc x\cot x + \tfrac{x}{2}\ln\!\left|\tan\tfrac{x}{2}\right| +
 \tfrac{1}{2}\int \csc x\cot x\,dx - \tfrac{1}{2}\int \ln\!\left|\tan\tfrac{x}{2
}\right|dx.$$

Since $\dfrac{d}{dx}(\csc x) = -\csc x\cot x$, we have $\displaystyle\int \csc x
\cot x\,dx = -\csc x + C$. Substituting $\csc x\cot x = \dfrac{\cos x}{\sin^2 x}
$:

$$\boxed{\;I = -\frac{x\cos x}{2\sin^2 x} - \frac{1}{2\sin x} + \frac{x}{2}\ln\!
\left|\tan\frac{x}{2}\right| - \frac{1}{2}\int \ln\!\left|\tan\frac{x}{2}\right|
dx + C\;}$$

### Step 3. Verification by differentiation

Let $G(x) = \int \ln\!\left|\tan\frac{x}{2}\right|dx$, so $G'(x) = \ln\!\left|\t
an\frac{x}{2}\right|$, and note $\dfrac{d}{dx}\ln\!\left|\tan\frac{x}{2}\right|
= \csc x$. Define

$$F = -\frac{x\cos x}{2\sin^2 x} - \frac{1}{2\sin x} + \frac{x}{2}\ln\!\left|\ta
n\tfrac{x}{2}\right| - \frac{1}{2}G.$$

Differentiating term by term:

- $\dfrac{d}{dx}\!\left[-\dfrac{x\cos x}{2\sin^2 x}\right] = \dfrac{-\sin x\cos
x + x + x\cos^2 x}{2\sin^3 x}$,
- $\dfrac{d}{dx}\!\left[-\dfrac{1}{2\sin x}\right] = \dfrac{\cos x}{2\sin^2 x} =
 \dfrac{\sin x\cos x}{2\sin^3 x}$,
- $\dfrac{d}{dx}\!\left[\dfrac{x}{2}\ln\!\left|\tan\tfrac{x}{2}\right|\right] =
\dfrac{1}{2}\ln\!\left|\tan\tfrac{x}{2}\right| + \dfrac{x}{2\sin x} = \dfrac{1}{
2}\ln\!\left|\tan\tfrac{x}{2}\right| + \dfrac{x\sin^2 x}{2\sin^3 x}$,
- $\dfrac{d}{dx}\!\left[-\dfrac{1}{2}G\right] = -\dfrac{1}{2}\ln\!\left|\tan\tfr
ac{x}{2}\right|$.

The logarithmic terms cancel. Collecting the remaining terms over the common den
ominator $2\sin^3 x$:

$$F' = \frac{(-\sin x\cos x + x + x\cos^2 x) + \sin x\cos x + x\sin^2 x}{2\sin^3
 x} = \frac{x(1+\cos^2 x+\sin^2 x)}{2\sin^3 x} = \frac{2x}{2\sin^3 x} = \frac{x}
{\sin^3 x}.\;\checkmark$$

### Remark on the remaining integral

The term $\displaystyle\int \ln\!\left|\tan\frac{x}{2}\right|dx$ is **non-elemen
tary**: with $t=x/2$ it becomes $2\int\ln|\tan t|\,dt = 2\int\ln|\sin t|\,dt - 2
\int\ln|\cos t|\,dt$, which is expressible only through the Clausen function $\m
athrm{Cl}_2$ (equivalently, the dilogarithm). The formula above is therefore the
 closed-form reduction of the original integral, with the single non-elementary
remainder isolated explicitly — the standard form of the answer for this problem
.
