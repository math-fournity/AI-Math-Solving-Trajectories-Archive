## Proof

**Answer: Yes, there exist uncountably many such functions.**

**Construction.** For each real number $c \in \mathbb{R}$, define the constant f
unction
$$g_c : \mathbb{R} \to \mathbb{R}, \qquad g_c(x) = c.$$

**Verification of the required property.** Each $g_c$ is differentiable everywhe
re, with
$$g_c'(x) = 0 \quad \text{for all } x \in \mathbb{R}.$$
In particular, for every rational $q \in \mathbb{Q}$,
$$g_c'(q) = 0 \in \mathbb{Q}.$$
So every $g_c$ satisfies the condition $g'(q) \in \mathbb{Q}$ for all $q \in \ma
thbb{Q}$.

**Uncountability.** The map $c \mapsto g_c$ is a bijection from $\mathbb{R}$ ont
o the family of constant functions $\mathbb{R} \to \mathbb{R}$: if $c_1 \neq c_2
$, then $g_{c_1}(0) = c_1 \neq c_2 = g_{c_2}(0)$, so $g_{c_1} \neq g_{c_2}$. Sin
ce $\mathbb{R}$ is uncountable, the family $\{g_c : c \in \mathbb{R}\}$ is an un
countable family of distinct differentiable functions, each satisfying $g'(q) \i
n \mathbb{Q}$ for all $q \in \mathbb{Q}$.

**Remark.** The construction is not limited to constant functions. More generall
y, for any $a, b \in \mathbb{Q}$ and any $c \in \mathbb{R}$, the quadratic $g(x)
 = ax^2 + bx + c$ satisfies $g'(q) = 2aq + b \in \mathbb{Q}$ for all $q \in \mat
hbb{Q}$, and the free real parameter $c$ again yields uncountably many distinct
functions. But the constant-function family above already suffices to establish
the claim.

Therefore, there exist uncountably many differentiable functions $g : \mathbb{R}
 \to \mathbb{R}$ such that $g'(q) \in \mathbb{Q}$ for all $q \in \mathbb{Q}$.
