## Solution

**Functional equation:** $x(f(x+n) - f(x)) = n\,f(1/x)$ for all positive integer
s $n$ and positive rationals $x$, with $f(2017)=2017$.

### Step 1: Values at positive integers

Set $x=1$: $f(1+n) - f(1) = n\,f(1)$, so $f(1+n) = (1+n)\,f(1)$. Thus $f(k) = k\
,f(1)$ for every positive integer $k$. Since $f(2017) = 2017\,f(1) = 2017$, we g
et $f(1)=1$, hence

$$f(k) = k \quad\text{for all positive integers } k.$$

### Step 2: Values at unit fractions

Set $x = m$ (integer), $n=1$: $m(f(m+1)-f(m)) = f(1/m)$, giving $f(1/m) = m\cdot
 1 = m$. So

$$f(1/m) = m \quad\text{for all positive integers } m.$$

### Step 3: General formula $f(p/q) = pq$

The functional equation rewrites as $f(x+n) = f(x) + \frac{n}{x}\,f(1/x)$.

**Claim:** $f(p/q) = pq$ for all positive rationals $p/q$ in lowest terms.

*Verification of the equation.* Let $x = p/q$ with $\gcd(p,q)=1$. Then $x+n = (p
+nq)/q$, and $\gcd(p+nq,\, q) = \gcd(p,q) = 1$, so $f(x+n) = (p+nq)\,q = pq + nq
^2$. Also $f(1/x) = f(q/p) = qp$. Then

$$\text{LHS} = \frac{p}{q}\bigl(pq + nq^2 - pq\bigr) = \frac{p}{q}\cdot nq^2 = p
nq,$$
$$\text{RHS} = n\cdot qp = npq. \quad\checkmark$$

Also $f(2017) = 2017\cdot 1 = 2017$. ✓

*Uniqueness.* The recurrence $f(p/q) = f((p+nq)/q) - \frac{nq}{p}\,f(q/p)$ reduc
es the pair $(p,q)$ via the Euclidean algorithm (replacing the larger of $p,q$ b
y its remainder mod the smaller), terminating at the base cases $f(k)=k$ (intege
rs, $q=1$) and $f(1/m)=m$ (unit fractions, $p=1$), both of which are uniquely de
termined. Hence $f(p/q)=pq$ is the **unique** solution.

### Step 4: Compute the sum

$$f\!\left(\tfrac{2}{3}\right) = 2\cdot 3 = 6, \quad f\!\left(\tfrac{3}{4}\right
) = 3\cdot 4 = 12, \quad f\!\left(\tfrac{4}{5}\right) = 4\cdot 5 = 20, \quad f\!
\left(\tfrac{5}{6}\right) = 5\cdot 6 = 30.$$

$$S = 6 + 12 + 20 + 30 = \boxed{68}.$$
