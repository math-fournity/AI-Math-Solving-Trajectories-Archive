# Problem

A massive logistics grid is arranged in a perfect $16 \times 16$ formation of server nodes. Each node is either a "Ruby" server or a "Sapphire" server. Communication cables are laid between every pair of nodes that are horizontally or vertically adjacent. 

The protocol for cabling is as follows:
1. If two adjacent nodes are both Rubies, they are connected by a **Red cable**.
2. If two adjacent nodes are both Sapphires, they are connected by a **Blue cable**.
3. If two adjacent nodes are of different types (one Ruby, one Sapphire), they are connected by a **Yellow cable**.

The grid contains exactly 133 Ruby servers. Out of these Ruby servers, 32 are located on the boundary of the grid (the outermost rows and columns), and exactly 2 are located specifically at the four corners of the grid. 

An audit of the infrastructure reveals that there are exactly 196 Yellow cables currently installed. Based on this information, how many Blue cables are in the grid?
