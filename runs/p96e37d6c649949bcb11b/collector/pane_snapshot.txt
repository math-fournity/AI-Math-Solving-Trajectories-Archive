## Solution

**The order of $K$ is $120$.**

### Proof

Consider the determinant homomorphism:
$$\det: GL(2, GF(5)) \to GF(5)^*$$

This is a surjective group homomorphism from $GL(2,GF(5))$ onto the multiplicati
ve group $GF(5)^* = \{1, 2, 3, 4\}$, which has order $4$.

**Step 1: Compute $|GL(2, GF(5))|$.**

The order of $GL(2, GF(q))$ is $(q^2 - 1)(q^2 - q)$. For $q = 5$:
$$|GL(2, GF(5))| = (25 - 1)(25 - 5) = 24 \cdot 20 = 480.$$

**Step 2: Use the First Isomorphism Theorem.**

By the First Isomorphism Theorem, $GL(2, GF(5)) / \ker(\det) \cong GF(5)^*$, so:
$$|\ker(\det)| = \frac{|GL(2, GF(5))|}{|GF(5)^*|} = \frac{480}{4} = 120.$$

The kernel $\ker(\det) = SL(2, GF(5))$ is the set of matrices with determinant $
1$.

**Step 3: All fibers have equal size.**

For any $a \in GF(5)^*$, the preimage $\det^{-1}(a)$ is a coset of $\ker(\det)$.
 Specifically, if $M_0$ is any matrix with $\det(M_0) = a$, then:
$$\det^{-1}(a) = M_0 \cdot SL(2, GF(5)),$$
a left coset of the kernel. Since all cosets of a subgroup have the same cardina
lity:
$$|\det^{-1}(a)| = |SL(2, GF(5))| = 120 \quad \text{for every } a \in GF(5)^*.$$

**Step 4: Identify $K$.**

The set $K = \left\{\begin{pmatrix} a & b \\ c & d \end{pmatrix} \in GL(2, GF(5)
) : ad - bc = 2\right\}$ is exactly the fiber $\det^{-1}(2)$, which is a coset o
f $SL(2, GF(5))$.

Therefore:
$$|K| = 120.$$
