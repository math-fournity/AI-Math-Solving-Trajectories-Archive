## Solution of the Riemann Problem for $u_{x_1} + u_{x_2} = 0$

### The Cauchy problem

We solve the first-order linear PDE
$$u_{x_1} + u_{x_2} = 0 \quad \text{in } \mathbb{R}^2,$$
with initial data prescribed on the line $\Gamma = \{x_2 = 0\}$:
$$u(x_1, 0) = g(x_1) = \begin{cases} u_l, & x_1 < 0, \\ u_r, & x_1 > 0, \end{cas
es} \qquad u_l \neq u_r.$$

### Characteristics

The PDE is of the form $a \cdot \nabla u = 0$ with constant vector $a = (1,1)$.
The characteristic system is
$$\frac{dx_1}{ds} = 1, \qquad \frac{dx_2}{ds} = 1, \qquad \frac{du}{ds} = 0.$$

Integrating:
- $x_1(s) = s + c_1$,
- $x_2(s) = s + c_2$,
- $u(s) = \text{const}$.

Hence every characteristic is a straight line of slope $1$ in the $(x_1, x_2)$-p
lane, i.e. a line $x_1 - x_2 = \text{const}$, and $u$ is constant along each suc
h line.

### Parameterizing by the initial line

Each characteristic line $x_1 - x_2 = \xi$ meets the initial line $\Gamma = \{x_
2 = 0\}$ at the point $(\xi, 0)$. Since $u$ is constant along the characteristic
, its value everywhere on that line equals the initial value at $(\xi, 0)$:
$$u(x_1, x_2) = g(\xi) = g(x_1 - x_2).$$

This is the general solution of the Cauchy problem (valid wherever characteristi
cs from $\Gamma$ cover the plane, which here is all of $\mathbb{R}^2$).

### Evaluating in the two regions

The initial data $g$ changes value at $\xi = 0$. The line $\xi = 0$, i.e. $x_1 =
 x_2$, is the characteristic issuing from the origin — the discontinuity point o
f $g$. It separates the plane into the two regions given in the problem:

- **Region $\Omega_1 = \{x_1 > x_2\}$**: here $\xi = x_1 - x_2 > 0$, so $g(\xi)
= u_r$.
  $$\boxed{u(x_1, x_2) = u_r \quad \text{in } \Omega_1.}$$

- **Region $\Omega_2 = \{x_1 < x_2\}$**: here $\xi = x_1 - x_2 < 0$, so $g(\xi)
= u_l$.
  $$\boxed{u(x_1, x_2) = u_l \quad \text{in } \Omega_2.}$$

The discontinuity $\{u_l \neq u_r\}$ propagates from the origin along the charac
teristic $x_1 = x_2$, which is the boundary $\partial\Omega_1 \cap \partial\Omeg
a_2$.

### Verification

1. **PDE**: In each region $u$ is constant, so $u_{x_1} = u_{x_2} = 0$ and $u_{x
_1} + u_{x_2} = 0$. ✓

2. **Initial condition**: On $\Gamma$ we have $x_2 = 0$, so $\xi = x_1$. For $x_
1 < 0$ (hence $x_1 < x_2 = 0$, i.e. the point lies in $\Omega_2$) we get $u = u_
l = g(x_1)$. For $x_1 > 0$ (point in $\Omega_1$) we get $u = u_r = g(x_1)$. ✓

3. **Characteristic propagation**: The jump set is exactly the characteristic $x
_1 = x_2$ through the jump point of $g$, consistent with the fact that informati
on travels along characteristics of slope $1$. ✓

### Interpretation

This is the prototype linear Riemann problem. The "shock" is not a shock in the
nonlinear sense but a **contact discontinuity**: the jump in the initial data is
 simply transported along the characteristic $x_1 = x_2$ issuing from the origin
. The two constant states $u_l$ and $u_r$ fill the two half-planes $\Omega_2$ an
d $\Omega_1$ respectively, separated by this characteristic.
