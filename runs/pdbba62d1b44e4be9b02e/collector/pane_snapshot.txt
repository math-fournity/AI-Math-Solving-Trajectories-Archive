## Upper Bound: n ≤ 9

Let S be the common sum on each sheet. Let 2^t be the largest power of 2 with 2^
t ≤ S (so t = ⌊log₂ S⌋).

**Key observation:** Any power 2^k with k > t satisfies 2^k > S. Such a power ca
nnot appear on any sheet, since a sheet containing 2^k would have sum ≥ 2^k > S,
 contradicting that every sheet sums to S. So only powers 2⁰, 2¹, …, 2^t can be
used, each at most 5 times.

Let c_k = number of times 2^k appears across all sheets (0 ≤ c_k ≤ 5). Then:

$$nS = \sum_{k=0}^{t} c_k \cdot 2^k \leq 5\sum_{k=0}^{t} 2^k = 5(2^{t+1}-1)$$

Since S ≥ 2^t:

$$n \leq \frac{5(2^{t+1}-1)}{2^t} = 5\left(2 - \frac{1}{2^t}\right) = 10 - \frac
{5}{2^t}$$

For **n = 10** to be possible, we'd need 10 ≤ 10 − 5/2^t, i.e., 5/2^t ≤ 0, which
 is impossible for any finite t. Since n is an integer and n < 10, we get **n ≤
9**.
