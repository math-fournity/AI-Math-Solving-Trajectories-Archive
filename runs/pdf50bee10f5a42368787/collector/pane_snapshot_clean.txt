## Proof

**Step 1: Both p and q are nonzero.** If p ≡ 0 or q ≡ 0, the left-hand side is 0
 ≠ 1. So both are nonzero polynomials. Let m = deg(p), n = deg(q), with leading
coefficients a, b respectively (a, b ≠ 0).

**Step 2: Degree analysis when m ≠ n.** Expanding the leading terms:

- p(x)q(x+1): the coefficient of x^{m+n} is ab, and the coefficient of x^{m+n-1}
 is a(bn + b') + a'b, where a' is the coefficient of x^{m-1} in p and b' is the
coefficient of x^{n-1} in q.
- p(x+1)q(x): the coefficient of x^{m+n} is ab, and the coefficient of x^{m+n-1}
 is ab' + (am + a')b.

The x^{m+n} terms cancel. The coefficient of x^{m+n-1} in the difference is:

a(bn + b') + a'b − ab' − (am + a')b = abn − amb = ab(n − m).

Since m ≠ n, we have ab(n − m) ≠ 0, so deg(LHS) = m + n − 1. For the LHS to equa
l the constant 1, we need m + n − 1 = 0, i.e., **m + n = 1**, giving (m, n) ∈ {(
1, 0), (0, 1)}.

**Step 3: Degree analysis when m = n.** Write p(x) = (a/b)·q(x) + s(x), where s(
x) is the remainder upon dividing p by q (both degree n), so deg(s) < n. Then:

p(x)q(x+1) − p(x+1)q(x) = [(a/b)q(x) + s(x)]q(x+1) − [(a/b)q(x+1) + s(x+1)]q(x)
= (a/b)[q(x)q(x+1) − q(x+1)q(x)] + s(x)q(x+1) − s(x+1)q(x)
= s(x)q(x+1) − s(x+1)q(x).

So **(s, q) is also a solution** with deg(s) < n = deg(q). Note s ≢ 0, since oth
erwise the LHS would be 0 ≠ 1.

Now deg(s) < deg(q) = n, so by **Step 2** (the m ≠ n case applied to (s, q)), we
 need deg(s) + n = 1. Since deg(s) ≥ 0 and n ≥ 1, this forces **deg(s) = 0 and n
 = 1**, hence m = n = 1.

**Conclusion of degree analysis:** In all cases, deg(p) ≤ 1 and deg(q) ≤ 1.

**Step 4: Finding all solutions with deg ≤ 1.** Write p(x) = ax + c and q(x) = b
x + d (allowing a = 0 or b = 0 for constant polynomials). Compute directly:

p(x)q(x+1) = (ax + c)(b(x+1) + d) = (ax + c)(bx + b + d)
= abx² + (ab + ad + bc)x + c(b + d).

p(x+1)q(x) = (a(x+1) + c)(bx + d) = (ax + a + c)(bx + d)
= abx² + (ad + ab + bc)x + (a + c)d.

Subtracting:

p(x)q(x+1) − p(x+1)q(x) = c(b + d) − (a + c)d = bc + cd − ad − cd = **bc − ad**.

So the equation becomes **bc − ad = 1**.

**Step 5: Verification.** For any real numbers a, b, c, d with bc − ad = 1, the
polynomials p(x) = ax + c, q(x) = bx + d satisfy the equation (by the computatio
n above). The condition bc − ad = 1 automatically ensures (a, b) ≠ (0, 0) and (c
, d) ≠ (0, 0), so both p and q are nonzero.

**Examples:**
- p(x) = 1, q(x) = x: bc − ad = 1·1 − 0·0 = 1. ✓ (Check: 1·(x+1) − 1·x = 1.)
- p(x) = x + 1, q(x) = x: bc − ad = 1·1 − 1·0 = 1. ✓ (Check: (x+1)² − x(x+2) = 1
.)
- p(x) = x, q(x) = −1: bc − ad = 0·0 − 1·(−1) = 1. ✓ (Check: x·(−1) − (x+1)·(−1)
 = 1.)

## Answer

All pairs of polynomials (p, q) with real coefficients satisfying p(x)q(x+1) − p
(x+1)q(x) = 1 are exactly:

$$p(x) = ax + c, \qquad q(x) = bx + d,$$

where $a, b, c, d \in \mathbb{R}$ satisfy $\boxed{bc - ad = 1}$.

Equivalently, p and q are polynomials of degree at most 1, and the "determinant"
 $\begin{vmatrix} a & c \\ b & d \end{vmatrix} = ad - bc$ equals $-1$.
