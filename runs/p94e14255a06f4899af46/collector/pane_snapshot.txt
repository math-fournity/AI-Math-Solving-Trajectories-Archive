## Proof of `coP_eq_P`: {L | Lᶜ ∈ P} = P

We prove both inclusions.

**(⊇)** Let `L ∈ P`. By definition, `L` is computable in polynomial time by a de
terministic Turing machine `M`. The boolean negation function `¬ : Bool → Bool`
is computable in constant time (hence polynomial time). The composition of poly-
time computable functions is poly-time computable. Therefore `Lᶜ = ¬ ∘ L` is com
putable in polynomial time, i.e., `Lᶜ ∈ P`. This means `L ∈ {L | Lᶜ ∈ P}`.

**(⊆)** Let `L ∈ {L | Lᶜ ∈ P}`, so `Lᶜ ∈ P`. Then `Lᶜ` is computable in polynomi
al time. Since boolean negation `¬` is poly-time computable and compositions of
poly-time functions are poly-time, `L = (Lᶜ)ᶜ = ¬ ∘ Lᶜ` is computable in polynom
ial time. Hence `L ∈ P`.

By double inclusion, `{L | Lᶜ ∈ P} = P`. ∎

## Proof of `P_subset_NP`: P ⊆ NP

Let `L ∈ P`. Then there exists a deterministic Turing machine `M` deciding `L` i
n polynomial time.

To show `L ∈ NP`, we must exhibit a polynomial `p : Polynomial ℕ` and a poly-tim
e computable relation `R : (List Bool × List Bool) → Bool` such that for all `x`
:

$$L(x) = \text{true} \iff \exists\, w,\; |w| \leq p(|x|) \wedge R(x, w) = \text{
true}.$$

**Construction.** Take `p` to be the constant polynomial `0` (so the witness bou
nd is `|w| ≤ 0`, i.e., `w` must be the empty list). Define:

$$R(x, w) = L(x)$$

That is, the verifier `R` **ignores the witness** `w` and simply runs the poly-t
ime decider `M` on input `x`.

**Poly-time computability of R.** Since `L` is poly-time computable (by assumpti
on `L ∈ P`), and `R` merely evaluates `L` on the first component of its input (d
iscarding the second), `R` is poly-time computable. Formally, the projection `π₁
 : (List Bool × List Bool) → List Bool` is poly-time computable, and `R = L ∘ π₁
` is a composition of poly-time functions.

**Correctness.**
- *(⇒)* If `L(x) = true`, take `w = []` (the empty list). Then `|w| = 0 ≤ 0 = p(
|x|)`, and `R(x, []) = L(x) = true`. ✓
- *(⇐)* If there exists `w` with `|w| ≤ p(|x|) = 0` and `R(x, w) = true`, then `
L(x) = R(x, w) = true`. ✓

Therefore `L ∈ NP`, and since `L` was arbitrary, `P ⊆ NP`. ∎

## Note on `P_subset_coNP`

This theorem is already proven in the file using `coP_eq_P` and `P_subset_NP`:

```lean
theorem P_subset_coNP : P ⊆ coNP := by
  rw [coNP, ← coP_eq_P]
  simp only [Set.setOf_subset_setOf]
  intros L hL
  exact P_subset_NP hL
```

The argument: `coNP = {L | Lᶜ ∈ NP}`, and by `coP_eq_P`, `{L | Lᶜ ∈ P} = P`. So
`P ⊆ coNP` reduces to: if `L ∈ P` then `Lᶜ ∈ NP`, which follows from `Lᶜ ∈ P` (b
y `coP_eq_P`) and `P ⊆ NP` (by `P_subset_NP`). ∎
