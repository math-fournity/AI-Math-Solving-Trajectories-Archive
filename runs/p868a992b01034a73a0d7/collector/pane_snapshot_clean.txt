## Solution

**Setup.** The sphere of radius $r$ is parametrized by $(x^1, x^2)$ with
$$y^1 = r\sin x^1\cos x^2,\quad y^2 = r\sin x^1\sin x^2,\quad y^3 = r\cos x^1.$$
Here $x^1$ is the polar angle and $x^2$ the azimuthal angle. The fundamental met
ric tensor is $g_{ij} = \vec r_i\cdot\vec r_j$ where $\vec r_i = \partial\vec y/
\partial x^i$.

**Tangent vectors.**
$$\vec r_1 = (r\cos x^1\cos x^2,\; r\cos x^1\sin x^2,\; -r\sin x^1),$$
$$\vec r_2 = (-r\sin x^1\sin x^2,\; r\sin x^1\cos x^2,\; 0).$$

**Metric tensor components.**
$$g_{11} = r^2\cos^2 x^1\cos^2 x^2 + r^2\cos^2 x^1\sin^2 x^2 + r^2\sin^2 x^1 = r
^2(\cos^2 x^1 + \sin^2 x^1) = r^2.$$
$$g_{22} = r^2\sin^2 x^1\sin^2 x^2 + r^2\sin^2 x^1\cos^2 x^2 = r^2\sin^2 x^1.$$
$$g_{12} = g_{21} = -r^2\cos x^1\sin x^1\cos x^2\sin x^2 + r^2\cos x^1\sin x^1\s
in x^2\cos x^2 + 0 = 0.$$

Therefore
$$\boxed{g_{ij} = \begin{pmatrix} r^2 & 0 \\[4pt] 0 & r^2\sin^2 x^1 \end{pmatrix
}}.$$

The contravariant (inverse) metric is
$$g^{ij} = \begin{pmatrix} \dfrac{1}{r^2} & 0 \\[6pt] 0 & \dfrac{1}{r^2\sin^2 x^
1} \end{pmatrix}.$$

**Christoffel symbols.** Using
$$\Gamma^k_{ij} = \tfrac{1}{2}g^{kl}\bigl(\partial_i g_{jl} + \partial_j g_{il}
- \partial_l g_{ij}\bigr),$$
the only non-vanishing derivative of a metric component is
$$\partial_1 g_{22} = 2r^2\sin x^1\cos x^1.$$

Computing each component:

- $\Gamma^1_{11} = \tfrac{1}{2}g^{11}\partial_1 g_{11} = \tfrac{1}{2}\cdot\tfrac
{1}{r^2}\cdot 0 = 0.$
- $\Gamma^1_{12} = \Gamma^1_{21} = \tfrac{1}{2}g^{11}(\partial_1 g_{21} + \parti
al_2 g_{11} - \partial_1 g_{12}) = 0.$
- $\Gamma^1_{22} = \tfrac{1}{2}g^{11}(\partial_2 g_{21} + \partial_2 g_{12} - \p
artial_1 g_{22}) = \tfrac{1}{2}\cdot\tfrac{1}{r^2}(0 + 0 - 2r^2\sin x^1\cos x^1)
 = -\sin x^1\cos x^1.$
- $\Gamma^2_{11} = \tfrac{1}{2}g^{22}(\partial_1 g_{12} + \partial_1 g_{12} - \p
artial_2 g_{11}) = 0.$
- $\Gamma^2_{12} = \Gamma^2_{21} = \tfrac{1}{2}g^{22}(\partial_1 g_{22} + \parti
al_2 g_{12} - \partial_2 g_{12}) = \tfrac{1}{2}\cdot\tfrac{1}{r^2\sin^2 x^1}\cdo
t 2r^2\sin x^1\cos x^1 = \dfrac{\cos x^1}{\sin x^1} = \cot x^1.$
- $\Gamma^2_{22} = \tfrac{1}{2}g^{22}\partial_2 g_{22} = 0.$

**Result.** The only non-zero Christoffel symbols are
$$\boxed{\Gamma^1_{22} = -\sin x^1\cos x^1, \qquad \Gamma^2_{12} = \Gamma^2_{21}
 = \cot x^1,}$$
with all other $\Gamma^k_{ij} = 0$.

**Verification (consistency check).** The geodesic equations $\ddot x^k + \Gamma
^k_{ij}\dot x^i\dot x^j = 0$ become
$$\ddot x^1 - \sin x^1\cos x^1\,(\dot x^2)^2 = 0,\qquad \ddot x^2 + 2\cot x^1\,\
dot x^1\dot x^2 = 0,$$
which are precisely the standard geodesic equations on a sphere of radius $r$ (t
he radius $r$ correctly cancels out of the Christoffel symbols, as expected sinc
e they depend only on the dimensionless metric structure up to the conformal fac
tor $r^2$). The Gaussian curvature computed from these symbols,
$$K = \frac{1}{r^2},$$
matches the known curvature of a sphere of radius $r$, confirming the result.
