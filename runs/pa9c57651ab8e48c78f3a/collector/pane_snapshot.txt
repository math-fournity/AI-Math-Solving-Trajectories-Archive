## Solution

**Setup with symmetric functions.** Let $p = a+b+c$, $q = ab+bc+ca$, $r = abc$.
The constraint becomes

$$\frac{pq}{r} = 10 \implies r = \frac{pq}{10}.$$

Using $a^3+b^3+c^3 = p^3 - 3pq + 3r$:

$$S = \frac{p^3 - 3pq + 3r}{r} = \frac{p^3 - 3pq}{r} + 3 = \frac{10(p^3-3pq)}{pq
} + 3 = \frac{10(p^2-3q)}{q} + 3.$$

Setting $t = \frac{p^2}{q}$, this simplifies to

$$S = 10(t-3)+3 = 10t - 27.$$

**Normalizing.** Both the constraint and $S$ are homogeneous of degree 0, so set
 $p=1$. Then $q = 1/t$ and $r = 1/(10t)$. The values $a,b,c$ are the three roots

$$f(u) = u^3 - u^2 + \frac{u}{t} - \frac{1}{10t} = 0.$$

0$ (with $p,q,r>0$ ensuring positivity once roots are real). Computing the discr
iminant of $u^3 - u^2 + \frac{u}{t} - \frac{1}{10t}$ with $b=-1, c=1/t, d=-1/(10
t)$:

$$\Delta = \frac{253}{100t^2} - \frac{2}{5t} - \frac{4}{t^3}.$$

$$100t^3\Delta = 253t - 40t^2 - 400 = -(40t^2 - 253t + 400).$$

5}{8}$. Since the parabola opens upward:

$$t \in \left[\frac{25}{8},\, \frac{16}{5}\right].$$

**Positivity of roots throughout.** At both endpoints ($\Delta=0$, repeated root

root being $0$). Hence all roots are positive throughout the interval.
