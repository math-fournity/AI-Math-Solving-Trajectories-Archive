## Solution

**Setup.** The robot generates $X = 0.b_1b_2\ldots \in [0,1)$ uniformly, and set
s $K = \lceil 2014X \rceil$. The bay intervals are $((i-1)/2014,\, i/2014]$ for
$i=1,\dots,2014$, with jump points (boundaries) at $i/2014$ for $i=1,\dots,2013$
.

After $k$ bits, we know $X \in [j/2^k, (j+1)/2^k)$. The value of $K$ is determin
ed iff $\lceil 2014X\rceil$ is constant on this dyadic interval, which fails iff
 some boundary $i/2014$ lies in the **half-open** interval $[j/2^k, (j+1)/2^k)$.

**Key observation on the dyadic boundary.** Among the 2013 boundaries, $1007/201
4 = 1/2$ is the only dyadic rational. At level $k \ge 1$, $1/2$ is the left endp
oint of dyadic interval $[1/2, 1/2+2^{-k})$, so it makes that interval bad (the
function jumps from $1007$ to $1008$ there). The remaining 2012 boundaries are n
on-dyadic.

**Counting bad intervals $B_k$.** Let $B_k$ = number of level-$k$ dyadic interva
ls containing a boundary in $[j/2^k, (j+1)/2^k)$.

- **$k=0$:** The single interval $[0,1)$ contains all boundaries. $B_0 = 1$.

- **$1 \le k \le 10$:** Each dyadic interval has length $2^{-k} \ge 2^{-10} = 1/
1024 > 1/2014$ (the boundary spacing). So every dyadic interval contains at leas
t one non-dyadic boundary, making all $2^k$ intervals bad. The dyadic boundary's
 interval already contains a non-dyadic boundary (since $2^{-k} > 1/2014$ means
$1008/2014 \in [1/2, 1/2+2^{-k})$), so it adds nothing new. Thus $B_k = 2^k$.

- **$k \ge 11$:** Now $2^{-k} \le 2^{-11} = 1/2048 < 1/2014$, so each non-dyadic
 boundary occupies its own dyadic interval (no collisions). The 2012 non-dyadic
boundaries give 2012 bad intervals. The dyadic boundary $1/2$ gives one **additi
onal** bad interval $[1/2, 1/2+2^{-k})$, which contains no non-dyadic boundary (
since $1008/2014 - 1/2 = 1/2014 > 2^{-k}$). So $B_k = 2013$.

**Expected number of bits.** Using $E = \sum_{k=0}^{\infty} P(\text{need more th
an } k \text{ bits}) = \sum_{k=0}^{\infty} B_k/2^k$:

$$E = \underbrace{1 + 1 + \cdots + 1}_{11 \text{ terms } (k=0,\dots,10)} + \sum_
{k=11}^{\infty} \frac{2013}{2^k} = 11 + \frac{2013}{2^{10}} = 11 + \frac{2013}{1
024}$$

$$= \frac{11 \times 1024 + 2013}{1024} = \frac{11264 + 2013}{1024} = \frac{13277
}{1024}.$$

**Verification with small cases.**
- $N=2$: boundary at $1/2$ (dyadic). $B_0=1$, $B_k=1$ for $k\ge1$. $E = 1 + \sum
_{k\ge1}1/2^k = 2$. ✓ (matches direct computation: $P(\text{stop at }k)=2^{-k}$,
 $E=2$).
- $N=3$: boundaries $1/3, 2/3$ (non-dyadic). $B_0=1$, $B_k=2$ for $k\ge1$. $E =
1+2=3$. ✓ (matches direct computation).

**Reducing to lowest terms.** $\gcd(13277, 1024)$: since $1024 = 2^{10}$ and $13
277$ is odd, $\gcd = 1$.

So $m = 13277$, $n = 1024$.

$$100m + n = 100 \times 13277 + 1024 = 1327700 + 1024 = \boxed{1328724}$$
