Let $C = \{A_\alpha\}_{\alpha < \lambda}$ be a well-ordered cofinal subset of $T
$ with $\lambda = \operatorname{cf}(T)$, which exists by the definition of cofin
ality for linear orders. Since $T$ is totally ordered by inclusion and all its e

ta$ for all $\alpha < \beta$.

At each successor step $\alpha \to \alpha+1$, the inclusion is strict, so $A_{\a
lpha+1} \setminus A_\alpha \neq \emptyset$. Pick $x_\alpha \in A_{\alpha+1} \set
minus A_\alpha$. Since the chain is increasing:
- $x_\alpha \notin A_\beta$ for all $\beta \leq \alpha$ (as $x_\alpha \notin A_\
alpha$ and $A_\beta \subseteq A_\alpha$),
- $x_\alpha \in A_\gamma$ for all $\gamma \geq \alpha+1$ (as $A_{\alpha+1} \subs
eteq A_\gamma$).

Therefore the elements $\{x_\alpha : \alpha \text{ is a successor ordinal},\; \a
lpha < \lambda\}$ are **pairwise distinct**.

Now fix any $\beta < \lambda$. All the elements $x_\alpha$ for successor ordinal

$$|A_\beta| \geq |\beta|.$$
Since $A_\beta$ is countable, $|\beta| \leq \aleph_0$, i.e., $\beta < \omega_1$.

As this holds for every $\beta < \lambda$, we conclude $\lambda \leq \omega_1$.
Combined with $\operatorname{cf}(T) \geq \omega_1$, we obtain:
$$\operatorname{cf}(T) = \omega_1.$$

### Step 3: $|U| = \aleph_1$.

Since $C$ is cofinal in $T$, every $E \in T$ is contained in some $A_\alpha$, so

$$|U| \leq \aleph_1 \cdot \aleph_0 = \aleph_1.$$

$$|U| \geq \aleph_1.$$

Combining both bounds:
$$|U| = \aleph_1. \qquad \blacksquare$$
