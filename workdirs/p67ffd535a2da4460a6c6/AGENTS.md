# Problem

In a specialized logistics hub, there are 10 cargo containers, each marked with a unique ID number from 1 to 10 inclusive. A technician is tasked with a specific "Efficiency Calibration" protocol.

The protocol requires the technician to identify any two containers whose ID numbers are not a divisor-multiple pair (meaning neither ID number divides the other evenly). When such a pair is found, the technician must relabel them: one container is assigned a new ID equal to the Greatest Common Divisor (GCD) of the original two IDs, and the other is assigned the Least Common Multiple (LCM) of the original two IDs.

The technician repeats this calibration process as long as there exists at least one pair of containers in the set of ten whose IDs are not in a divisor-multiple relationship. The process must stop immediately when every possible pair of IDs currently on the containers satisfies the condition where one number in the pair divides the other.

What is the maximum number of times the technician can perform this calibration operation before the process is forced to stop?
