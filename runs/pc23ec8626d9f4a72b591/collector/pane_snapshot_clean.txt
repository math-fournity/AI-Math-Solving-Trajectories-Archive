# Answer: No

A subset $M \subseteq \mathbb{R}^n$ with Hausdorff dimension $n$ need not contai
n an open ball.

## Construction

Let $C \subset \mathbb{R}$ be a **fat Cantor set** (Smith–Volterra–Cantor set):
a closed, nowhere-dense subset of $[0,1]$ with positive Lebesgue measure (e.g. $
|C| = 1/2$). Such a set is built by the standard Cantor construction, but removi
ng middle intervals whose total length is strictly less than $1$, so the remaini
ng set has positive measure yet empty interior.

Set
$$M := \underbrace{C \times C \times \cdots \times C}_{n \text{ factors}} \subse
t \mathbb{R}^n.$$

## $M$ has Hausdorff dimension $n$

Since $|C| > 0$ in $\mathbb{R}$, the product set $M = C^n$ has positive $n$-dime
nsional Lebesgue measure:
$$|M| = |C|^n > 0.$$
Any set of positive $n$-dimensional Lebesgue measure has Hausdorff dimension exa
ctly $n$ (Lebesgue measure is comparable to $n$-dimensional Hausdorff measure on
 $\mathbb{R}^n$). Hence
$$\dim_H(M) = n.$$

## $M$ contains no open ball

$C$ is closed with empty interior, i.e. $C$ is nowhere dense. The product $M = C
^n$ is closed. Suppose for contradiction that $M$ contained an open ball $B \sub
set M$. Since open boxes form a basis for the topology of $\mathbb{R}^n$, there
would exist a non-empty open box
$$(a_1,b_1)\times\cdots\times(a_n,b_n) \subset M = C^n.$$
Projecting onto the $i$-th coordinate gives $(a_i, b_i) \subset C$ for every $i$
, contradicting the fact that $C$ has empty interior. Therefore $M$ has empty in
terior and contains no open ball.

## Conclusion

$M = C^n \subset \mathbb{R}^n$ has Hausdorff dimension $n$ yet contains no open
ball. The answer is **no**.
