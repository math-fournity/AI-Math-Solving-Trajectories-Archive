## Proof

**Claim:** Yes, $(a_i)$ is necessarily bounded.

**Proof by contradiction.** Suppose $(a_i)$ is unbounded. Then for every $M > 0$
 there exists an index $i$ with $|a_i| > M$. We construct a subsequence $i_1 < i
_2 < i_3 < \cdots$ inductively as follows. Since $(a_i)$ is unbounded, for each
$k \ge 1$ we can find an index $i_k > i_{k-1}$ (with $i_0 = 0$) such that

$$|a_{i_k}| \ge k^2.$$

This is possible because unboundedness guarantees arbitrarily large values at ar
bitrarily large indices.

Now define a sequence $(x_i)$ by

$$
x_i = \begin{cases} \dfrac{1}{k^2} & \text{if } i = i_k \text{ for some } k, \\[
6pt] 0 & \text{otherwise.} \end{cases}
$$

Then

$$\sum_{i=1}^{\infty} |x_i| = \sum_{k=1}^{\infty} \frac{1}{k^2} = \frac{\pi^2}{6
} < \infty,$$

so $(x_i) \in \ell^1$. However,

$$\sum_{i=1}^{\infty} |a_i|\,|x_i| = \sum_{k=1}^{\infty} |a_{i_k}| \cdot \frac{1
}{k^2} \ge \sum_{k=1}^{\infty} k^2 \cdot \frac{1}{k^2} = \sum_{k=1}^{\infty} 1 =
 \infty.$$

This contradicts the hypothesis that $\sum_{i=1}^{\infty} |a_i|\,|x_i| < \infty$
 for **every** $\ell^1$ sequence $(x_i)$.

Therefore our assumption that $(a_i)$ is unbounded must be false, and $(a_i)$ is
 necessarily a bounded sequence. $\blacksquare$
