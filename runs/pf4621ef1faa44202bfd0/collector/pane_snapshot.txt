## 证明

将 $E$ 置于原点。设直线 $AB$ 为 $x$ 轴，直线 $CD$ 与 $x$ 轴的夹角为 $\theta$（因
为 $AB$ 和 $CD$ 是相交于 $E$ 的不同直线，所以 $\theta \neq 0, \pi$）。

**参数化。** 使用带符号的实数 $a, b, c, d$：
- $A = (a, 0)$, $B = (b, 0)$ 在直线 $AB$ 上，
- $C = (c\cos\theta,\, c\sin\theta)$, $D = (d\cos\theta,\, d\sin\theta)$ 在直线
$CD$ 上。

**圆心 $O$。** $AB$ 的垂直平分线为 $x = \tfrac{a+b}{2}$。$CD$ 的垂直平分线经过点
 $(\tfrac{c+d}{2}\cos\theta,\,\tfrac{c+d}{2}\sin\theta)$，方向为 $(-\sin\theta,\
,\cos\theta)$。求解可得：

$$O = \left(\frac{a+b}{2},\;\; \frac{(c+d)-(a+b)\cos\theta}{2\sin\theta}\right).
$$

**直线 $BC$、$AD$ 及法向量。**

直线 $BC$（经过 $B=(b,0)$, $C=(c\cos\theta,c\sin\theta)$）具有法向量 $\mathbf{n}
_1 = (c\sin\theta,\; b-c\cos\theta)$，方程为 $\mathbf{n}_1\cdot\mathbf{x} = bc\s
in\theta$。

直线 $AD$（经过 $A=(a,0)$, $D=(d\cos\theta,d\sin\theta)$）具有法向量 $\mathbf{n}
_2 = (d\sin\theta,\; a-d\cos\theta)$，方程为 $\mathbf{n}_2\cdot\mathbf{x} = ad\s
in\theta$。

因为 $EP \perp BC$，直线 $EP$ 过原点，方向为 $\mathbf{n}_1$。因为 $ER \perp AD$
，直线 $ER$ 过原点，方向为 $\mathbf{n}_2$。

**点 $Q$ 和 $S$。** 令 $M = \mathbf{n}_1\cdot\mathbf{n}_2 = ab + cd - (ac+bd)\co
s\theta$。注意 $M \neq 0$，否则 $\mathbf{n}_1 \perp \mathbf{n}_2$，即 $BC \paral
lel AD$，这与假设矛盾。

- $Q = EP \cap AD$：设 $Q = t\,\mathbf{n}_1$，代入 $AD$ 方程得 $t\,M = ad\sin\th
eta$，因此 $Q = \frac{ad\sin\theta}{M}\,\mathbf{n}_1$。
- $S = ER \cap BC$：设 $S = s\,\mathbf{n}_2$，代入 $BC$ 方程得 $s\,M = bc\sin\th
eta$，因此 $S = \frac{bc\sin\theta}{M}\,\mathbf{n}_2$。

**中点 $K$。**

$$K = \frac{Q+S}{2} = \frac{\sin\theta}{2M}\big(ad\,\mathbf{n}_1 + bc\,\mathbf{n
}_2\big).$$

计算分量：

$$ad\,\mathbf{n}_1 + bc\,\mathbf{n}_2 = \big(acd\sin\theta + bcd\sin\theta,\;\;
abd - acd\cos\theta + abc - bcd\cos\theta\big)$$
$$= \big(cd(a+b)\sin\theta,\;\; ab(c+d) - cd(a+b)\cos\theta\big).$$

因此：

$$K = \frac{\sin\theta}{2M}\Big(cd(a+b)\sin\theta,\;\; ab(c+d)-cd(a+b)\cos\theta
\Big).$$

**关键恒等式（圆幂定理）。** 因为 $ABCD$ 内接于 $\omega$，且 $E = AB \cap CD$，
所以 $E$ 关于 $\omega$ 的圆幂为：

$$EA \cdot EB = EC \cdot ED \implies ab = cd.$$

**共线性。** 因为 $E$ 是原点，所以 $E, K, O$ 共线当且仅当向量 $K$ 和 $O$ 平行。

*情况 1：$a+b \neq 0$。* 计算分量比值：

$$\frac{K_x}{O_x} = \frac{\frac{\sin\theta}{2M}\,cd(a+b)\sin\theta}{\frac{a+b}{2
}} = \frac{cd\sin^2\theta}{M}.$$

对于 $y$ 分量，利用 $ab = cd$：

$$ab(c+d) - cd(a+b)\cos\theta = cd\big((c+d)-(a+b)\cos\theta\big),$$

所以：

$$\frac{K_y}{O_y} = \frac{\frac{\sin\theta}{2M}\,cd\big((c+d)-(a+b)\cos\theta\bi
g)}{\frac{(c+d)-(a+b)\cos\theta}{2\sin\theta}} = \frac{cd\sin^2\theta}{M} = \fra
c{K_x}{O_x}.$$

因此 $K = \lambda\, O$，其中 $\lambda = \frac{cd\sin^2\theta}{M}$，证明了 $E, K,
 O$ 共线。

*情况 2：$a + b = 0$。* 则 $O_x = 0$ 且 $K_x = 0$，所以 $O$ 和 $K$ 都位于过 $E$
（原点）的 $y$ 轴上。共线成立。（如果 $c + d = 0$，同理；如果 $a+b=0$ 且 $c+d=0$
，则 $O = E$，结论显然成立。）

在所有情况下，$E, K, O$ 均共线。$\blacksquare$
