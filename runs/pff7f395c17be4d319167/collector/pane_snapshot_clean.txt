**Theorem (Rado).** *For every $f:[\omega]^2\to k$ and every nonprincipal ultraf

th $\bigcup_i A_i = \omega$ such that each $A_i$ is either empty or the vertex s

**Proof.**

**1. The function $g$ is well-defined.**

For each $x\in\omega$ and each color $i<k$, set $S_i(x)=\{y\neq x : f(x,y)=i\}$.
 The sets $S_0(x),\dots,S_{k-1}(x)$ are pairwise disjoint and their union is $\o
mega\setminus\{x\}$. Since $U$ is nonprincipal, $\omega\setminus\{x\}\in U$. By
the ultrafilter property: (i) at most one $S_i(x)$ can belong to $U$ (disjoint s
ets cannot both be in $U$), and (ii) at least one must belong to $U$ (their unio
n is in $U$, and a finite union being in $U$ forces at least one member to be in
 $U$). Hence there is a unique $i$ with $S_i(x)\in U$; we set $g(x)=i$. ∎

**2. Inductive construction.**

We build finite sets $A_0^j,\dots,A_{k-1}^j$ and end-vertices $y_i^j$ (when $A_i
^j\neq\emptyset$) by induction on $j$, maintaining:

- **(P1)** $A_0^j,\dots,A_{k-1}^j$ are pairwise disjoint and finite.
- **(P2)** $\{0,\dots,j-1\}\subseteq\bigcup_i A_i^j$.
- **(P3)** Each $A_i^j$ is the vertex set of a path in color $i$.
- **(P4)** If $A_i^j\neq\emptyset$ then $g(y_i^j)=i$, where $y_i^j$ is the desig
nated end-vertex.

*Base case* $j=0$: Set $A_i^0=\emptyset$ for all $i$. All conditions hold vacuou
sly.

*Inductive step* $j\to j+1$: Assume (P1)–(P4) hold at stage $j$.

**If $j\in\bigcup_i A_i^j$**: set $A_i^{j+1}=A_i^j$ for all $i$. All conditions
are preserved.

**If $j\notin\bigcup_i A_i^j$**: let $i=g(j)$.

*Subcase 2a: $A_i^j=\emptyset$.* Set $A_i^{j+1}=\{j\}$, $y_i^{j+1}=j$, and $A_\e
ll^{j+1}=A_\ell^j$ for $\ell\neq i$. A single vertex is trivially a path. We hav
e $g(y_i^{j+1})=g(j)=i$, so (P4) holds. Disjointness and coverage are immediate.

*Subcase 2b: $A_i^j\neq\emptyset$.* We must find a vertex $z\notin\bigcup_\ell A
_\ell^j$ with $f(j,z)=f(y_i^j,z)=i$. Consider:
$$S \;=\; \{t : f(j,t)=i\}\;\cap\;\{t : f(y_i^j,t)=i\}.$$

- Since $g(j)=i$, by definition $\{t:f(j,t)=i\}\in U$.
- Since $A_i^j\neq\emptyset$, by (P4) we have $g(y_i^j)=i$, so $\{t:f(y_i^j,t)=i
\}\in U$.

Because $U$ is closed under finite intersections, $S\in U$. Since $U$ is **nonpr
incipal**, every member of $U$ is infinite; in particular $S$ is infinite. Since
 $\bigcup_\ell A_\ell^j$ is finite (by (P1)), the set $S\setminus\bigcup_\ell A_
\ell^j$ is nonempty. Choose any $z$ in this set.

Now extend the path: $A_i^j$ is a path in color $i$ with end-vertex $y_i^j$. App
end the edge $y_i^j\text{---}z$ (color $i$, since $f(y_i^j,z)=i$) and then the e

$$A_i^{j+1}=A_i^j\cup\{z,j\},\qquad y_i^{j+1}=j,\qquad A_\ell^{j+1}=A_\ell^j\;\;
(\ell\neq i).$$

Then $A_i^{j+1}$ is a path in color $i$ with end-vertex $j$, and $g(y_i^{j+1})=g
(j)=i$, so (P3) and (P4) hold. The vertices $z$ and $j$ were both outside $\bigc
up_\ell A_\ell^j$, so (P1) is preserved. Since $j\in A_i^{j+1}$, condition (P2)
holds at stage $j+1$. ∎

**3. Passing to the limit.**

For each $i<k$, set $A_i=\bigcup_{j<\omega}A_i^j$. Since the sequence $\{A_i^j\}
_{j}$ is increasing (each step only adds vertices to one $A_i$), this is well-de
fined.

- **Pairwise disjoint**: Disjointness is preserved at every finite stage, so the
 unions remain disjoint.
- **Covering**: For every $j\in\omega$, at stage $j+1$ either $j$ was already co
vered or it was added to some $A_i^{j+1}$. Hence $j\in\bigcup_i A_i$ for every $
j$, giving $\bigcup_i A_i=\omega$.
- **Monochromatic paths**: Each $A_i$ is the union of an increasing chain of fin

This gives the desired partition of $\omega$ into $k$ pairwise disjoint monochro
