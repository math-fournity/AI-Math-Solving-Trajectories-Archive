# Problem

A high-tech communications firm is designing a network consisting of $n$ distinct server hubs ($n > 2$). A network is considered "fully operational" if it is connected, meaning every hub can communicate with every other hub through some sequence of fiber-optic cables.

The firm is researching a specific reliability standard. They define $f(n)$ as the minimum number of cables required in a network of $n$ hubs to guarantee a specific redundancy property: no matter how the cables are arranged (as long as the network is connected and contains no self-loops or duplicate cables between the same two hubs), there must exist at least one cycle of cables such that, if every cable in that cycle were to fail simultaneously, the remaining network would still be fully operational.

Calculate the value of the following sum:
$$\sum_{n=4}^{100} f(n)$$
