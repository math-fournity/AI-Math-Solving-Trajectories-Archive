Looking at this problem, I need to find the size of the union of 1987 sets, each
 of size 45, where every pair of sets has union of size 89 (equivalently, inters
ection of size 1).

## Setting Up the Key Question

Each pair of sets shares exactly $45 + 45 - 89 = 1$ element. The critical questi
on is whether all sets must share a **common** element (sunflower structure), wh
ich would force the union to be $1 + 1987 \times 44 = 87429$.

## Proof by Contradiction

**Assume** not all sets share a common element. Then there exist three sets $A,
B, C$ with:
- $A \cap B = \{x\}$, $A \cap C = \{y\}$, $B \cap C = \{z\}$, where $x, y, z$ ar
e distinct.

(If all pairwise intersections among any triple were the same element, that elem
ent would be common to all sets containing any of those pairs, which propagates
to all sets.)

Since $x \in A \cap B$ but $A \cap C = \{y\} \neq \{x\}$, we get $x \notin C$. S
imilarly $y \notin B$ and $z \notin A$.

## Classifying the Remaining 1984 Sets

For any other set $D$, it must intersect each of $A, B, C$ in exactly one elemen
t. Careful case analysis yields four types:

- **Type X** ($D \ni x$): $D \cap A = D \cap B = \{x\}$, $D \cap C = \{c\}$ for
some $c \in C \setminus \{y,z\}$. Two Type X sets share $x$, so they need distin
ct $c$-values. **At most** $|C \setminus \{y,z\}| = 43$.

- **Type Y** ($D \ni y$): $D \cap A = D \cap C = \{y\}$, $D \cap B = \{b\}$ for
$b \in B \setminus \{x,z\}$. **At most** $|B \setminus \{x,z\}| = 43$.

- **Type Z** ($D \ni z$): $D \cap B = D \cap C = \{z\}$, $D \cap A = \{a\}$ for
$a \in A \setminus \{x,y\}$. **At most** $|A \setminus \{x,y\}| = 43$.

- **Type W** ($D$ contains none of $x,y,z$): $D \cap A = \{a\}$, $D \cap B = \{b
\}$, $D \cap C = \{c\}$ with $a \in A\setminus\{x,y\}$, $b \in B\setminus\{x,z\}
$, $c \in C\setminus\{y,z\}$.

## Bounding Type W Sets

Two Type W sets with the **same** $a$-value both contain $a$, so their intersect
ion is at least $\{a\}$. Since the intersection must be exactly 1, they share no
thing else — in particular, they must have **distinct** $b$-values. There are on
ly $|B \setminus \{x,z\}| = 43$ possible $b$-values, so:

$$\text{Type W sets per } a\text{-value} \leq 43$$
