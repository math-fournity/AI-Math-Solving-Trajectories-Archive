## Proof

**Claim.** The only complete set is $\mathbb{R}$.

It is clear that $\mathbb{R}$ is complete (since $a+b \in \mathbb{R}$ and $ab \i
n \mathbb{R}$ always hold, the condition is vacuously satisfied for all pairs).

We show every complete set equals $\mathbb{R}$.

**Step 1: $0 \in A$.**

Since $A$ is non-empty, pick any $c \in A$. Set $a = c$, $b = 0$. Then $a + b =
c \in A$, so by completeness $ab = c \cdot 0 = 0 \in A$.

**Step 2: $(-\infty, 0] \subseteq A$.**

Since $0 \in A$, for any $t \in \mathbb{R}$, set $a = -t$, $b = t$. Then $a + b
= 0 \in A$, so $ab = -t^2 \in A$. As $t$ ranges over $\mathbb{R}$, $-t^2$ ranges
 over $(-\infty, 0]$. Hence $(-\infty, 0] \subseteq A$.

**Step 3: $A = \mathbb{R}$.**

For any $c \in A$ and any $t \in \mathbb{R}$, set $a = c - t$, $b = t$. Then $a
+ b = c \in A$, so
$$ab = (c - t)\,t = ct - t^2 \in A \quad \text{for all } t \in \mathbb{R}.$$

Now take any $n > 0$. Since $-n \in (-\infty, 0] \subseteq A$, we may set $c = -
n$ above:
$$-nt - t^2 = -\!\left(t + \tfrac{n}{2}\right)^2 + \tfrac{n^2}{4} \in A \quad \t
ext{for all } t \in \mathbb{R}.$$
As $t$ ranges over $\mathbb{R}$, the expression $-\!\left(t + \frac{n}{2}\right)
^2 + \frac{n^2}{4}$ ranges over $\left(-\infty,\, \frac{n^2}{4}\right]$. Therefo
re
$$\left(-\infty,\, \tfrac{n^2}{4}\right] \subseteq A \quad \text{for every } n >
 0.$$

Given any real $M$, choose $n > 2\sqrt{\max(M,0)}$. Then $\frac{n^2}{4} > M$, so
 $M \in A$. Since $M$ was arbitrary, $A = \mathbb{R}$.

**Conclusion.** The only complete set of real numbers is $\mathbb{R}$ itself. $\
blacksquare$
