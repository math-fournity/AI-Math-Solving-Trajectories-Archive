# IMO 1962, Problem 2

**Problem.** Determine all real numbers $x$ satisfying $\sqrt{3-x} - \sqrt{x+1}
> \tfrac{1}{2}$.

## Domain

For both square roots to be real we need $3 - x \ge 0$ and $x + 1 \ge 0$, i.e.
$$-1 \le x \le 3.$$

## Monotonicity

Define $f(x) = \sqrt{3-x} - \sqrt{x+1}$ on $[-1, 3]$. Then
$$f'(x) = -\frac{1}{2\sqrt{3-x}} - \frac{1}{2\sqrt{x+1}} < 0$$
on $(-1, 3)$, so $f$ is strictly decreasing. At the endpoints:
$$f(-1) = 2 - 0 = 2 > \tfrac12, \qquad f(3) = 0 - 2 = -2 < \tfrac12.$$
By continuity and strict monotonicity, there is a **unique** $x_0 \in [-1, 3]$ w
ith $f(x_0) = \tfrac12$, and the inequality $f(x) > \tfrac12$ holds exactly for
$x < x_0$ (within the domain).

## Finding $x_0$

Solve $\sqrt{3-x} - \sqrt{x+1} = \tfrac12$:
$$\sqrt{3-x} = \tfrac12 + \sqrt{x+1}.$$
Both sides are non-negative, so squaring is valid:
$$3 - x = \tfrac14 + \sqrt{x+1} + (x+1) = x + \tfrac54 + \sqrt{x+1},$$
$$\sqrt{x+1} = \tfrac74 - 2x. \qquad (\star)$$
This requires $\tfrac74 - 2x \ge 0$, i.e. $x \le \tfrac78$. Squaring $(\star)$:
$$x + 1 = \left(\tfrac74 - 2x\right)^2 = 4x^2 - 7x + \tfrac{49}{16},$$
$$0 = 4x^2 - 8x + \tfrac{33}{16}.$$
Multiplying by $16$: $64x^2 - 128x + 33 = 0$, giving
$$x = \frac{128 \pm \sqrt{16384 - 8448}}{128} = \frac{128 \pm \sqrt{7936}}{128}
= \frac{128 \pm 16\sqrt{31}}{128} = 1 \pm \frac{\sqrt{31}}{8}.$$

Now apply the constraint $x \le \tfrac78$:
- $x = 1 + \tfrac{\sqrt{31}}{8} \approx 1.697 > \tfrac78$: **rejected** (it is a
n extraneous root introduced by squaring).
- $x = 1 - \tfrac{\sqrt{31}}{8} \approx 0.304 < \tfrac78$: **accepted**.

**Verification.** At $x_0 = 1 - \tfrac{\sqrt{31}}{8}$: from $(\star)$, $\sqrt{x_
0+1} = \tfrac74 - 2x_0 = \tfrac{\sqrt{31}-1}{4} > 0$, and $\sqrt{3-x_0} = \tfrac
12 + \sqrt{x_0+1} = \tfrac12 + \tfrac{\sqrt{31}-1}{4} = \tfrac{\sqrt{31}+1}{4} >
 0$. Then $\sqrt{3-x_0} - \sqrt{x_0+1} = \tfrac{(\sqrt{31}+1) - (\sqrt{31}-1)}{4
} = \tfrac24 = \tfrac12$. ✓

## Solution

Since $f$ is strictly decreasing and $f(x_0) = \tfrac12$, the inequality $f(x) >
 \tfrac12$ holds for all $x$ in the domain with $x < x_0$:

$$\boxed{\;-1 \le x < 1 - \dfrac{\sqrt{31}}{8}\;}$$
