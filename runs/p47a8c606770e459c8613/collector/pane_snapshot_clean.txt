## Proof

Let $Y = X \oplus U$. We prove that $H(Y) \ge n - \epsilon$ and that this bound
is tight.

**Step 1: Relate $H(Y|X)$ to $H(U|X)$.**

For any fixed value of $X$, the map $U \mapsto X \oplus U$ is a bijection on $\{
0,1\}^n$ (XOR with a constant is invertible). Therefore conditioning on $X$:

$$H(Y \mid X) = H(U \mid X).$$

**Step 2: Use the mutual information bound.**

Since $U$ is uniform over $\{0,1\}^n$, $H(U) = n$. By definition,

$$I(X;U) = H(U) - H(U \mid X) = n - H(U \mid X).$$

The hypothesis $I(X;U) \le \epsilon$ gives

$$H(U \mid X) \ge n - \epsilon.$$

Combining with Step 1:

$$H(Y \mid X) = H(U \mid X) \ge n - \epsilon.$$

**Step 3: Lower bound on $H(Y)$.**

Entropy is always at least its conditional version:

$$H(Y) \ge H(Y \mid X) \ge n - \epsilon.$$

This establishes $H(X \oplus U) \ge n - \epsilon$.

**Step 4: The bound is tight.**

We decompose:

$$H(Y) = H(Y \mid X) + I(Y;X) = H(U \mid X) + I(Y;X) = \bigl(n - I(X;U)\bigr) +
I(Y;X).$$

So $H(Y) = n - \epsilon + I(Y;X)$, and equality $H(Y) = n - \epsilon$ holds iff
$I(Y;X) = 0$, i.e., $Y$ is independent of $X$.

We construct an example achieving equality for every $\epsilon \in [0, n]$.

- Choose $Y$ taking values in $\{0,1\}^n$ with $H(Y) = n - \epsilon$ (such a dis
tribution exists for every entropy value in $[0,n]$, e.g., $Y$ uniform on a subs
et of size $2^{n-\epsilon}$ when $\epsilon$ is an integer, or a suitable Bernoul
li-product distribution for non-integer $\epsilon$).
- Choose $X$ uniform over $\{0,1\}^n$, **independent** of $Y$.
- Define $U = X \oplus Y$.

**Verification:**
- *$U$ is uniform:* Since $X$ is uniform and independent of $Y$, for every $u$,
$\Pr(U=u)=\sum_y \Pr(Y=y)\Pr(X=u\oplus y) = \sum_y \Pr(Y=y)\cdot 2^{-n} = 2^{-n}
$. So $H(U)=n$. ✓
- *$I(X;U)=\epsilon$:* $I(X;U)=H(U)-H(U|X)=n - H(Y|X)=n - H(Y) = n-(n-\epsilon)=
\epsilon$. ✓
- *$H(Y)=n-\epsilon$:* By construction. ✓
- *$Y$ independent of $X$:* By construction. ✓

Thus $H(X\oplus U) = H(Y) = n - \epsilon$ is achieved, confirming tightness.

**Conclusion.** The tightest lower bound is

$$\boxed{H(X \oplus U) \ge n - \epsilon},$$

and this is achievable with equality for every $\epsilon \in [0, n]$.
