## Proof

**Claim:** Yes. Every subspace $Y$ of a separable Hilbert space $X$ possesses a
countable orthonormal system $\{z_k\}_{k\in\mathbb{N}}$ (obtainable via Gram–Sch
midt from a countable set $\{y_k\}$ whose span is dense in $Y$) such that $\over
line{\operatorname{lin}}\{z_k\}_{k\in\mathbb{N}} = \overline{Y}$.

### Step 1. $Y$ is separable

A standard theorem of metric-space topology states that **every subspace of a se
parable metric space is separable**. Since $X$ is a separable Hilbert space (hen
ce a separable metric space under its norm-induced metric) and $Y \subseteq X$,
the subspace $Y$ is separable.

*Proof of the theorem (for completeness):* Let $D = \{d_j\}_{j\in\mathbb{N}}$ be
 a countable dense subset of $X$. For each pair $(j, n) \in \mathbb{N}\times\mat
hbb{N}$, if $B(d_j, 1/n) \cap Y \neq \emptyset$, select one point $y_{j,n} \in B
(d_j,1/n)\cap Y$. The collection $\{y_{j,n}\}$ is countable. Given any $y \in Y$
 and $\varepsilon > 0$, pick $n$ with $1/n < \varepsilon/2$ and $d_j \in D$ with
 $\|y - d_j\| < 1/n$; then $y_{j,n} \in Y$ satisfies $\|y - y_{j,n}\| \leq \|y -
 d_j\| + \|d_j - y_{j,n}\| < 2/n < \varepsilon$. Hence $\{y_{j,n}\}$ is dense in
 $Y$. $\square$

### Step 2. Construct the countable set $\{y_k\}$ and apply Gram–Schmidt

Let $\{d_k\}_{k\in\mathbb{N}}$ be a countable dense subset of $Y$ with each $d_k
 \neq 0$ (discard any zeros). Apply the **Gram–Schmidt process** to $\{d_k\}$:

- Set $k = 1$. Maintain an index $j$ for the orthonormal output.
- For each $d_k$: if $d_k \in \operatorname{span}\{d_1, \dots, d_{k-1}\}$, **ski
p** it. Otherwise, set
$$y_j = d_k, \qquad z_j = \frac{d_k - \sum_{i=1}^{j-1}\langle d_k, z_i\rangle z_
i}{\left\|d_k - \sum_{i=1}^{j-1}\langle d_k, z_i\rangle z_i\right\|},$$
and increment $j$.

This produces a (finite or countably infinite) orthonormal sequence $\{z_j\}$ an
d a corresponding linearly independent subsequence $\{y_j\}$ of $\{d_k\}$.

### Step 3. Verify condition (1): $\{y_k\}$ is a basis for $Y$ (topological sens
e)

Gram–Schmidt preserves the linear span at each step:
$$\operatorname{span}\{z_1, \dots, z_j\} = \operatorname{span}\{y_1, \dots, y_j\
} = \operatorname{span}\{d_1, \dots, d_k\} \quad \text{(at the corresponding sta
ge)}.$$
Taking the union over all stages:
$$\operatorname{span}\{y_j\}_{j} = \operatorname{span}\{d_k\}_{k}.$$
Since $\{d_k\}$ is dense in $Y$ and $\{d_k\} \subseteq \operatorname{span}\{d_k\
} = \operatorname{span}\{y_j\}$, the set $\{y_j\}$ has **span dense in $Y$**. Th
us $\{y_k\}$ serves as a (topological) basis for $Y$: every element of $Y$ is a
norm-limit of finite linear combinations of the $y_k$.

### Step 4. Verify condition (2): Gram–Schmidt transforms $\{y_k\}$ into $\{z_k\
}$

By construction, $\{z_k\}$ is obtained from $\{y_k\}$ by the Gram–Schmidt proces
s, and $\{z_k\}$ is orthonormal by the standard Gram–Schmidt argument:
$$\langle z_j, z_i \rangle = 0 \quad (i < j), \qquad \|z_j\| = 1.$$

### Step 5. Verify condition (3): $\overline{\operatorname{lin}}\{z_k\} = \overl
ine{Y}$

**Each $z_k \in Y$:** Since $Y$ is a *linear subspace* and each $z_k$ is a finit
e linear combination of $\{d_1, \dots, d_k\} \subset Y$, we have $z_k \in Y$. Co
nsequently $\operatorname{span}\{z_k\} \subseteq Y$, and taking closures in $X$:
$$\overline{\operatorname{span}\{z_k\}} \subseteq \overline{Y}. \tag{$\subseteq$
}$$

**Reverse inclusion:** Since $\operatorname{span}\{z_k\} = \operatorname{span}\{
d_k\} \supseteq \{d_k\}$ and $\{d_k\}$ is dense in $Y$:
$$Y \subseteq \overline{\{d_k\}}^X \subseteq \overline{\operatorname{span}\{d_k\
}}^X = \overline{\operatorname{span}\{z_k\}}^X.$$
Taking closures of both sides in $X$:
$$\overline{Y} \subseteq \overline{\operatorname{span}\{z_k\}}^X. \tag{$\supsete
q$}$$

Combining ($\subseteq$) and ($\supseteq$):
$$\overline{\operatorname{lin}}\{z_k\}_{k\in\mathbb{N}} = \overline{Y}.$$

### Step 6. Edge cases

- **$Y = \{0\}$:** The empty orthonormal set satisfies all conditions vacuously;
 $\overline{\{0\}} = \{0\} = \overline{\operatorname{lin}}\,\emptyset$.
- **$Y$ finite-dimensional ($\dim Y = n < \infty$):** Gram–Schmidt terminates af
ter $n$ steps, producing a finite orthonormal set $\{z_1, \dots, z_n\}$ with $\o
peratorname{span}\{z_1,\dots,z_n\} = Y$. Finite-dimensional subspaces of a Hilbe
rt space are closed, so $\overline{Y} = Y = \operatorname{span}\{z_1,\dots,z_n\}
 = \overline{\operatorname{lin}}\{z_1,\dots,z_n\}$. A finite set is countable.
- **$Y$ infinite-dimensional, not closed:** The general case handled above; the
orthonormal sequence is countably infinite.

### Conclusion

In all cases, $Y$ possesses a countable (or finite) set $\{y_k\}$ whose linear s
pan is dense in $Y$, which Gram–Schmidt transforms into an orthonormal system $\
{z_k\}$, and the closed linear span of $\{z_k\}$ equals $\overline{Y}$. The key
ingredients are:

1. **Separability of subspaces of separable metric spaces** — guarantees a count
able dense subset of $Y$.
2. **Gram–Schmidt preserves linear spans** — ensures $\operatorname{span}\{z_k\}
 = \operatorname{span}\{d_k\}$.
3. **$Y$ is a linear subspace** — ensures each $z_k \in Y$, giving the inclusion
 $\overline{\operatorname{span}\{z_k\}} \subseteq \overline{Y}$.
4. **Density of $\{d_k\}$ in $Y$** — gives the reverse inclusion $\overline{Y} \
subseteq \overline{\operatorname{span}\{z_k\}}$.

The answer is **yes**.
