## 解答

**答案：** $\alpha = 1$，且解为 $u(t,x) = 4\sin\!\tfrac{x}{2c}\,\cos\!\tfrac{t}{
2} + \beta\, x$，其中 $\beta \in \mathbb{R}$ 为任意常数。

---

### 证明

通解为 $u(t,x) = u_1(x - ct) + u_2(x + ct)$，其中在区域 $Q$ 内，$x - ct < 0$ 且
$x + ct > 0$，因此 $u_1$ 定义在 $(-\infty, 0]$ 上，$u_2$ 定义在 $[0, \infty)$ 上
。

**第一步：边界 $x = 0$。** 条件 $u(t,0) = 0$ 给出

$$u_1(-ct) + u_2(ct) = 0 \quad \forall\, t \ge 0.$$

令 $s = ct \ge 0$：$u_2(s) = -u_1(-s)$，因此 $u_2'(s) = u_1'(-s)$（通过对 $-s$
求导）。

**第二步：边界 $x = ct$（特征线）。** 我们有 $u_t = -c\,u_1'(x-ct) + c\,u_2'(x+c
t)$。在 $x = ct$ 处：$x - ct = 0$，$x + ct = 2ct$，因此

$$u_t(t,ct) = -c\,u_1'(0) + c\,u_2'(2ct) = -c\,u_1'(0) + c\,u_1'(-2ct) = \cos t
- \alpha. \tag{$*$}$$

**第三步：相容性条件（确定 $\alpha$）。** 在 $(*)$ 中令 $t \to 0^+$。由于 $u \in
 C^1(\overline{Q})$，函数 $u_1'$ 在 $0$ 处连续，因此 $u_1'(-2ct) \to u_1'(0)$。
由此可得：

$$-c\,u_1'(0) + c\,u_1'(0) = \cos 0 - \alpha \implies 0 = 1 - \alpha \implies \b
oxed{\alpha = 1}.$$

这是必要条件：如果 $\alpha \ne 1$，$(*)$ 在 $t = 0$ 处会产生矛盾，因此不存在 $C^
1(\overline{Q})$ 解。

**第四步：当 $\alpha = 1$ 时构造解。** 令 $r = -2ct$（故 $t = -r/(2c)$，且当 $t
\in [0,\infty)$ 时，$r \in (-\infty, 0]$）。由 $(*)$ 且 $\alpha = 1$ 得：

$$c\,u_1'(r) = \cos\!\tfrac{r}{2c} - 1 + c\,u_1'(0), \qquad r \le 0.$$

记 $A = u_1'(0)$。积分可得：

$$u_1(r) = 2\sin\!\tfrac{r}{2c} - \frac{r}{c} + Ar + B, \qquad r \le 0,$$

其中 $B$ 为常数。由 $u_2(s) = -u_1(-s)$：

$$u_2(s) = 2\sin\!\tfrac{s}{2c} - \frac{s}{c} + As - B, \qquad s \ge 0.$$

**第五步：组合并化简。**

$$u(t,x) = u_1(x-ct) + u_2(x+ct) = 2\sin\!\tfrac{x-ct}{2c} + 2\sin\!\tfrac{x+ct}
{2c} + 2x\!\left(A - \tfrac{1}{c}\right).$$

（含 $B$ 的项和含 $r/c$ 的项抵消了。）利用和差化积公式 $\sin P + \sin Q = 2\sin\
frac{P+Q}{2}\cos\frac{P-Q}{2}$，其中 $P = \frac{x-ct}{2c}$，$Q = \frac{x+ct}{2c}
$：

$$\sin\!\tfrac{x-ct}{2c} + \sin\!\tfrac{x+ct}{2c} = 2\sin\!\tfrac{x}{2c}\cos\!\t
frac{t}{2}.$$

因此：

$$\boxed{u(t,x) = 4\sin\!\frac{x}{2c}\,\cos\!\frac{t}{2} + \beta\, x}, \qquad \b
eta = 2\!\left(A - \tfrac{1}{c}\right) \in \mathbb{R} \text{ 任意。}$$

**第六步：验证。**

- **波动方程：** $u_{tt} = -\sin\frac{x}{2c}\cos\frac{t}{2}$，$u_{xx} = -\frac{1
}{c^2}\sin\frac{x}{2c}\cos\frac{t}{2}$，因此 $u_{tt} - c^2 u_{xx} = 0$。$\checkm
ark$
- **$u(t,0) = 0$：** $4\sin 0 \cdot \cos\frac{t}{2} + 0 = 0$。$\checkmark$
- **$u_t(t,ct) = \cos t - 1$：** $u_t = -2\sin\frac{x}{2c}\sin\frac{t}{2}$；在 $
x = ct$ 处：$-2\sin\frac{t}{2}\sin\frac{t}{2} = -2\sin^2\frac{t}{2} = \cos t - 1
$。$\checkmark$
- **正则性：** $u$ 在 $\overline{Q}$ 上是光滑的，因此 $u \in C^2(Q) \cap C^1(\ov
erline{Q})$。$\checkmark$

自由参数 $\beta$ 对应于齐次部分 $\beta x$（满足波动方程及两个边界条件且 $u_t \eq
uiv 0$）。$\alpha = 1$ 的唯一性来自角点 $(0,0)$ 处的相容性，其中两个边界相交。
