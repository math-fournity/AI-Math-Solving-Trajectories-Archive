## Proof

**Claim:** The only value is $m = 1$.

### Case 1: $m = 1$ works

When $m=1$, the variety is $V = \{(a,b) : a = b^2\} = \{(b^2, b) : b \in \mathbb
{R}\}$. Take $R(x,y) = y$, $P(x) = x^2$, $Q(x) = x$. Then $P(R(a,b)) = b^2 = a$
✓ and $Q(R(a,b)) = b$ ✓ on $V$.

### Case 2: Even $m = 2k$ does not work

$V = \{(a, a^k)\} \cup \{(a, -a^k)\}$, two branches meeting only at the origin.
Set $f(a) = R(a, a^k)$ and $g(a) = R(a, -a^k)$, both polynomials in $a$.

From $P(f(a)) = a$ on branch 1: $P \circ f = \mathrm{id}$ as polynomials, so $\d
eg(P)\cdot\deg(f) = 1$, forcing $\deg(f) = 1$.

From $P(g(a)) = a$ on branch 2: similarly $\deg(g) = 1$.

So $f$ and $g$ are linear, hence surjective $\mathbb{R} \to \mathbb{R}$. Pick an
y $c \neq f(0)=g(0)$; there exist $a_1 \neq 0$ with $f(a_1)=c$ and $a_2 \neq 0$
with $g(a_2)=c$. Then $R(a_1, a_1^k) = R(a_2, -a_2^k) = c$, so $P(c) = a_1 = a_2
$, and $Q(c) = a_1^k = -a_2^k = -a_1^k$, giving $a_1^k = 0$, contradicting $a_1
\neq 0$. $\square$

### Case 3: Odd $m \geq 3$ does not work

Since $m$ is odd, $a^m = b^2 \geq 0$ forces $a \geq 0$. The variety is the singl
e curve $V = \{(t^2, t^m) : t \in \mathbb{R}\}$ (verified: $a = t^2 \geq 0$, $b
= t^m$ ranges over all reals, and $(t^2)^m = t^{2m} = (t^m)^2$).

The coordinate ring of $V$ is $\mathbb{R}[t^2, t^m]$. Since $\gcd(2, m) = 1$ wit
h $m \geq 3$ odd, the semigroup $\langle 2, m \rangle$ contains all non-negative
 integers except $1, 3, 5, \ldots, m-2$. In particular, **$t^1 \notin \mathbb{R}
[t^2, t^m]$**.

Any polynomial $R(x,y)$ restricts to $h(t) = R(t^2, t^m) \in \mathbb{R}[t^2, t^m
]$, so $h$ has no $t^1$ term. The conditions become:
$$P(h(t)) = t^2, \qquad Q(h(t)) = t^m.$$

Taking degrees: $\deg(P)\cdot\deg(h) = 2$ and $\deg(Q)\cdot\deg(h) = m$. Since $
m$ is odd, $\gcd(2, m) = 1$, so $\deg(h) \mid \gcd(2,m) = 1$, forcing $\deg(h) =
 1$.

But $h(t) = \alpha t + \beta$ with $\alpha \neq 0$ requires a $t^1$ term, which
is impossible since $h \in \mathbb{R}[t^2, t^m]$ and $t^1 \notin \mathbb{R}[t^2,
 t^m]$ for odd $m \geq 3$. Contradiction. $\square$

### Conclusion

Only $m = 1$ admits the required polynomials.
