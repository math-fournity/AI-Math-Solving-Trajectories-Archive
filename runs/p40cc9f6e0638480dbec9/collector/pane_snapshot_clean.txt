## Proof

Let $S_n = \sum_{k=1}^{2011} k\, x_k^n$ and let $M = \max(x_1, \ldots, x_{2011})
$.

### Step 1: The case $M = 1$ is impossible

If all $x_k = 1$, then $S_n = \sum_{k=1}^{2011} k = \frac{2011 \cdot 2012}{2} =
2023066$ for all $n$. We would need $a^{n+1} = 2023065$ for all $n$. Taking $n=1
$ and $n=2$ gives $a^2 = a^3 = 2023065$, forcing $a \in \{0,1\}$, but $2023065 \
neq 0$ and $2023065 \neq 1$. Contradiction. So $M \geq 2$.

### Step 2: For large $n$, the integer $a$ equals $M$

Let $v_1 < v_2 < \cdots < v_r = M$ be the distinct values among the $x_k$, and s
et $c_j = \sum_{k:\, x_k = v_j} k > 0$, so $S_n = \sum_{j=1}^r c_j\, v_j^n$.

Since $v_{r-1} \leq M-1$ (all values are positive integers), we have $S_n = c_r
M^n + O((M-1)^n)$.

- If $a \geq M+1$: then $a^{n+1} \geq (M+1)^{n+1} \gg c_r M^n$ for large $n$, so
 $a^{n+1} + 1 > S_n$. Impossible.
- If $a \leq M-1$: then $a^{n+1} \leq (M-1)^{n+1} \ll c_r M^n$ for large $n$, so
 $a^{n+1} + 1 < S_n$. Impossible.

Therefore $a = M$ for all sufficiently large $n$, say $n \geq N$.

### Step 3: Determining the sequence via exponential independence

For all $n \geq N$:
$$\sum_{j=1}^r c_j\, v_j^n = M \cdot M^n + 1 \cdot 1^n.$$

Let $B = \{v_1, \ldots, v_r\} \cup \{M, 1\}$ be the set of all bases appearing,
and for each $b \in B$ let $d_b$ be (coefficient on the left) $-$ (coefficient o
n the right). Then $\sum_{b \in B} d_b\, b^n = 0$ for all $n \geq N$.

Taking $|B|$ consecutive values $n = N, N+1, \ldots, N+|B|-1$ yields a Vandermon
de system $V\mathbf{d} = \mathbf{0}$. Since the bases in $B$ are distinct positi
ve integers, $V$ is invertible, so $\mathbf{d} = \mathbf{0}$.

**Consequence 1:** The base $1$ must appear among $\{v_1, \ldots, v_r\}$ (otherw
ise $d_1 = 0 - 1 = -1 \neq 0$). So some $v_s = 1$ with $c_s = 1$.

**Consequence 2:** The coefficient of $M$ gives $c_r = M$.

**Consequence 3:** No other bases exist — for any $v_j \notin \{1, M\}$, we'd ne
ed $c_j = 0$, but $c_j > 0$. So the distinct values are exactly $\{1, M\}$.

### Step 4: Uniqueness

From $c_s = \sum_{k:\, x_k = 1} k = 1$, exactly one index has $x_k = 1$, namely
$k = 1$. So $x_1 = 1$.

All remaining indices $k = 2, 3, \ldots, 2011$ satisfy $x_k = M$, and:
$$M = c_r = \sum_{k=2}^{2011} k = \frac{2011 \cdot 2012}{2} - 1 = 2023066 - 1 =
2023065.$$

### Step 5: Verification

With $x_1 = 1$ and $x_k = 2023065$ for $k \geq 2$:
$$S_n = 1 \cdot 1^n + \sum_{k=2}^{2011} k \cdot (2023065)^n = 1 + (2023065)^n \c
dot \underbrace{\sum_{k=2}^{2011} k}_{= 2023065} = 1 + (2023065)^{n+1}.$$

Setting $a = 2023065$ gives $S_n = a^{n+1} + 1$ for every positive integer $n$.
