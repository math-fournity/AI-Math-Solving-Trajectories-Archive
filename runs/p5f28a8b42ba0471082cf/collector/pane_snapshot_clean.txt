**Solution.** We claim the unique solution is $f(x)=\dfrac{1}{x}$.

**Step 1. $f$ is injective and $f(1)=1$.**

Set $x=1$: $f(f(y))=yf(1)$ for all $y>0$. Denote $c=f(1)>0$, so
$$f(f(y))=cy. \tag{1}$$
If $f(a)=f(b)$, then applying $f$ and using (1): $ca=cb$, hence $a=b$. So $f$ is
 injective.

Set $y=1$: $f(xf(1))=f(x)$, i.e. $f(cx)=f(x)$. Injectivity gives $cx=x$ for all
$x>0$, hence $c=1$. Thus
$$f(1)=1,\qquad f(f(y))=y. \tag{2}$$
So $f$ is an involution (hence bijective).

**Step 2. $f$ is multiplicative.**

In the original equation $f(xf(y))=yf(x)$, put $y=f(s)$ (valid since $f$ is surj
ective by (2)):
$$f\bigl(xf(f(s))\bigr)=f(s)\,f(x)\;\Longrightarrow\; f(xs)=f(x)f(s). \tag{3}$$
So $f(xy)=f(x)f(y)$ for all $x,y>0$.

**Step 3. Reduction to an additive Cauchy equation.**

Define $g:\mathbb{R}\to\mathbb{R}$ by $g(t)=\ln f(e^t)$. By multiplicativity,
$$g(s+t)=g(s)+g(t), \tag{4}$$
so $g$ is additive. The involution $f(f(x))=x$ becomes $g(g(t))=t$. The limit $f
(x)\to 0$ as $x\to\infty$ becomes
$$g(t)\to -\infty\quad\text{as }t\to+\infty. \tag{5}$$

**Step 4. $g$ is linear.**

From (5), there exists $M$ such that $g(t)<0$ for all $t>M$; i.e. $g$ is bounded
 above (by $0$) on the interval $(M,\infty)$, a set of positive measure. A stand
ard theorem on additive functions states: *if an additive function is bounded ab
ove on a set of positive measure, then it is linear* (continuous). Hence $g(t)=\
alpha t$ for some constant $\alpha\in\mathbb{R}$.

**Step 5. Determine $\alpha$.**

The involution $g(g(t))=t$ gives $\alpha^{2}t=t$, so $\alpha=\pm1$. Condition (5
), $g(t)\to-\infty$ as $t\to+\infty$, forces $\alpha<0$, hence $\alpha=-1$.

Therefore $g(t)=-t$, i.e. $f(e^{t})=e^{-t}$, which gives
$$f(x)=\frac{1}{x}\qquad(x>0).$$

**Verification.** $f(xf(y))=f\!\left(\dfrac{x}{y}\right)=\dfrac{y}{x}=y\cdot\dfr
ac{1}{x}=yf(x)$, and $f(x)=\dfrac{1}{x}\to 0$ as $x\to\infty$. Both conditions a
re satisfied.

The unique solution is $\boxed{f(x)=\dfrac{1}{x}}$.
