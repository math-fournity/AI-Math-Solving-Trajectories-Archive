# 证明

我们需要计算：

$$I_n = \int_{[0,1]^n} \cos^2\!\left(\frac{\pi}{2n}\sum_{i=1}^n x_i\right) dx_1\
cdots dx_n$$

并求 $\lim_{n\to\infty} I_n$。

## 第 1 步：余弦平方的半角公式

使用恒等式 $\cos^2\theta = \frac{1+\cos 2\theta}{2}$：

$$I_n = \frac{1}{2}\int_{[0,1]^n} dx_1\cdots dx_n + \frac{1}{2}\underbrace{\int_
{[0,1]^n} \cos\!\left(\frac{\pi}{n}\sum_{i=1}^n x_i\right) dx_1\cdots dx_n}_{J_n
}$$

第一项为 $\frac{1}{2}$，因为 $[0,1]^n$ 的体积为 $1$。因此 $I_n = \frac{1}{2} + \
frac{1}{2}J_n$。

## 第 2 步：将 $J_n$ 表示为乘积

记 $S = \sum_{i=1}^n x_i$。利用 $\cos\theta = \operatorname{Re}(e^{i\theta})$ 以
及指数函数的乘法性质：

$$\cos\!\left(\frac{\pi}{n}S\right) = \operatorname{Re}\!\left[\prod_{i=1}^n e^{
i\pi x_i/n}\right]$$

由于被积函数在变量中是分离的，且积分域是乘积域，因此：

$$J_n = \operatorname{Re}\!\left[\prod_{i=1}^n \int_0^1 e^{i\pi x_i/n}\,dx_i\rig
ht] = \operatorname{Re}\!\left[\left(\int_0^1 e^{i\pi x/n}\,dx\right)^{\!n}\righ
t]$$

## 第 3 步：计算内层积分

$$\int_0^1 e^{i\pi x/n}\,dx = \frac{e^{i\pi/n}-1}{i\pi/n} = \frac{n}{i\pi}\left(
e^{i\pi/n}-1\right)$$

提取中心相位：

$$e^{i\pi/n}-1 = e^{i\pi/(2n)}\left(e^{i\pi/(2n)}-e^{-i\pi/(2n)}\right) = e^{i\p
i/(2n)}\cdot 2i\sin\frac{\pi}{2n}$$

因此：

$$\int_0^1 e^{i\pi x/n}\,dx = \frac{n}{i\pi}\cdot e^{i\pi/(2n)}\cdot 2i\sin\frac
{\pi}{2n} = \frac{2n\sin(\pi/(2n))}{\pi}\,e^{i\pi/(2n)}$$

## 第 4 步：$n$ 次幂

$$\left(\int_0^1 e^{i\pi x/n}\,dx\right)^n = \left(\frac{2n\sin(\pi/(2n))}{\pi}\
right)^{\!n} e^{in\cdot\pi/(2n)} = \left(\frac{2n\sin(\pi/(2n))}{\pi}\right)^{\!
n} e^{i\pi/2}$$

由于 $e^{i\pi/2} = i$，且幅度因子 $\left(\frac{2n\sin(\pi/(2n))}{\pi}\right)^n$
是**实数**，因此：

$$J_n = \operatorname{Re}\!\left[\left(\frac{2n\sin(\pi/(2n))}{\pi}\right)^{\!n}
\cdot i\right] = 0$$

因为 $i$ 是纯虚数，任何实数倍乘以 $i$ 的实部均为零。

## 第 5 步：结论

由于对于所有 $n \geq 1$，都有 $J_n = 0$：

$$I_n = \frac{1}{2} + \frac{1}{2}\cdot 0 = \frac{1}{2} \quad \text{对所有 } n \g
eq 1 \text{ 成立}$$

因此：

$$\lim_{n\to\infty} I_n = \lim_{n\to\infty} \frac{1}{2} = \boxed{\dfrac{1}{2}}$$

**注：** 该积分对于每一个 $n$ 都恰好等于 $\frac{1}{2}$，而不仅仅是在极限情况下。
关键的机制是相位累积：每个变量贡献相位 $e^{i\pi/(2n)}$，经过 $n$ 次乘法后，总相
位为 $e^{i\pi/2} = i$，这使得余弦积分的实部恰好为零。
