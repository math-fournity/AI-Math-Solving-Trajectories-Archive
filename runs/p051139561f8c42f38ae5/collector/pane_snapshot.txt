## Spectrum of $T: \ell^2(\mathbb{Z}) \to \ell^2(\mathbb{Z})$, $(Tx)_n = x_{n+1}
+x_{n-1}$

**Claim.** $\sigma(T) = [-2,2]$, and it is entirely continuous spectrum (no eige
nvalues, no residual spectrum).

### 1. Setup: $T = S + S^{-1}$ with $S$ the bilateral shift

Let $S$ be the bilateral (right) shift on $\ell^2(\mathbb{Z})$, $(Sx)_n = x_{n-1
}$. Then $S$ is unitary: $S^* = S^{-1}$, with $(S^{-1}x)_n = (S^*x)_n = x_{n+1}$
. Hence
$$T = S + S^{-1} = S + S^*.$$
Being a sum of a unitary and its adjoint, $T$ is **bounded and self-adjoint**, w
ith
$$\|T\| \le \|S\| + \|S^{-1}\| = 2.$$

### 2. $\sigma(T) \subseteq [-2,2]$

Since $T$ is self-adjoint, $\sigma(T) \subseteq \mathbb{R}$. Also $\|T\| \le 2$,
 so for a self-adjoint operator $\sigma(T) \subseteq [-\|T\|,\|T\|] \subseteq [-
2,2]$.

### 3. $[-2,2] \subseteq \sigma(T)$ via approximate eigenvectors

Fix $\lambda \in [-2,2]$ and write $\lambda = 2\cos\theta$ for some $\theta \in
[0,\pi]$. Define, for each $N \ge 1$,
$$x^{(N)}_n = \begin{cases} \dfrac{1}{\sqrt{2N+1}}\, e^{in\theta}, & |n| \le N,
\\[4pt] 0, & |n| > N. \end{cases}$$
Then $\|x^{(N)}\|_2 = 1$. Compute $(Tx^{(N)})_n = x^{(N)}_{n+1} + x^{(N)}_{n-1}
= 2\cos\theta\, x^{(N)}_n = \lambda\, x^{(N)}_n$ **whenever** $|n\pm 1| \le N$,
i.e. for $|n| \le N-1$. The only contributions to $(T-\lambda I)x^{(N)}$ come fr
om the boundary indices $n = \pm N$ (where one neighbor falls outside the suppor
t):
$$\bigl((T-\lambda I)x^{(N)}\bigr)_n \ne 0 \text{ only for } n \in \{-N-1,\,-N,\
,N,\,N+1\},$$
and each nonzero entry has magnitude $\frac{1}{\sqrt{2N+1}}$. Therefore
$$\|(T-\lambda I)x^{(N)}\|_2^2 \le \frac{4}{2N+1} \xrightarrow[N\to\infty]{} 0.$
$
So $\lambda$ is an approximate eigenvalue, hence $\lambda \in \sigma(T)$. Since
$\lambda \in [-2,2]$ was arbitrary,
$$[-2,2] \subseteq \sigma(T).$$

### 4. No eigenvalues (purely continuous spectrum)

Suppose $Tx = \lambda x$ for some $x \in \ell^2(\mathbb{Z})\setminus\{0\}$, $\la
mbda \in \mathbb{R}$. The recurrence $x_{n+1} + x_{n-1} = \lambda x_n$ has chara
cteristic equation $r^2 - \lambda r + 1 = 0$ with $r + r^{-1} = \lambda$.

- **Case $|\lambda| < 2$:** write $\lambda = 2\cos\theta$, $\theta \in (0,\pi)$.
 General solution $x_n = A e^{in\theta} + B e^{-in\theta}$, which is bounded and
 non-decaying. Such a sequence is in $\ell^2(\mathbb{Z})$ only if $A = B = 0$, c
ontradiction.

- **Case $|\lambda| = 2$:** repeated root $r = \pm 1$. General solution $x_n = (
A + Bn)(\pm 1)^n$, which grows linearly unless $B = 0$; then $x_n = A(\pm 1)^n$
is constant-modulus, not in $\ell^2$ unless $A = 0$. Contradiction.

- **Case $|\lambda| > 2$:** roots $r, r^{-1}$ with $|r| > 1 > |r^{-1}|$. General
 solution $x_n = A r^n + B r^{-n}$. For $x \in \ell^2(\mathbb{Z})$ we need $A =
0$ (to decay as $n \to +\infty$) and $B = 0$ (to decay as $n \to -\infty$), so $
x = 0$. Contradiction.

Hence $T$ has **no eigenvalues**: the point spectrum is empty. Since $T$ is self
-adjoint, the residual spectrum is also empty. The entire spectrum $[-2,2]$ is t
herefore **continuous spectrum**.

### 5. Conclusion

Combining parts 2 and 3,
$$\boxed{\sigma(T) = [-2,\,2]},$$
with $\sigma_p(T) = \sigma_r(T) = \emptyset$ and $\sigma_c(T) = [-2,2]$.
