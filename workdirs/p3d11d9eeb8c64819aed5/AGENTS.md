# Problem

In a specialized logistics hub, a manager is designing experimental storage grids for a fleet of drones. Each grid is an $n \times n$ square array of docking stations, where $n$ is a positive integer between 1 and 100, inclusive.

Each station in the grid must be assigned a "power status" value from the set $\{-1, 0, 1\}$. Once the values are assigned, the manager calculates the "environmental impact" of each row by summing the values of the stations in that row, and the "thermal load" of each column by summing the values of the stations in that column.

A grid size $n$ is classified as "efficiently balanced" if it is possible to assign the power status values such that the resulting $n$ environmental impacts and $n$ thermal loads together form a collection of $2n$ unique integers.

How many integers $n \in \{1, 2, \dots, 100\}$ represent grid sizes that are "efficiently balanced"?
