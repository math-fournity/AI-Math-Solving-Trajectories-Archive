## Solution

**Setup.** Let $S_n = X_1 + \cdots + X_n$. Each $X_k$ is independent with
$$\mathbb{P}(X_k = 1) = \tfrac{1}{2}(1 + k^{-1/2}), \qquad \mathbb{P}(X_k = -1)
= \tfrac{1}{2}(1 - k^{-1/2}).$$

**Mean and variance.**
$$\mathbb{E}[X_k] = \tfrac{1}{2}(1+k^{-1/2}) - \tfrac{1}{2}(1-k^{-1/2}) = k^{-1/
2}, \qquad \operatorname{Var}(X_k) = \mathbb{E}[X_k^2] - (\mathbb{E}[X_k])^2 = 1
 - k^{-1}.$$

Set $Y_k = X_k - k^{-1/2}$ (centered), so $\mathbb{E}[Y_k]=0$ and $\operatorname
{Var}(Y_k) = 1 - k^{-1}$. Define
$$\mu_n := \sum_{k=1}^n k^{-1/2}, \qquad s_n^2 := \sum_{k=1}^n (1 - k^{-1}) = n
- H_n,$$
where $H_n = \sum_{k=1}^n 1/k \sim \ln n$.

**Asymptotics.** By comparison with the integral $\int_1^n x^{-1/2}\,dx = 2\sqrt
{n}-2$,
$$\mu_n = \sum_{k=1}^n k^{-1/2} \sim 2\sqrt{n}.$$
Also $s_n^2 = n - H_n \sim n$, so $s_n \sim \sqrt{n}$. Therefore
$$\frac{\mu_n}{s_n} \longrightarrow 2.$$

**Lindeberg CLT applies.** The $Y_k$ are independent, centered, with $|Y_k| = |X
_k - k^{-1/2}| \leq 1 + k^{-1/2} \leq 2$. For any $\varepsilon > 0$, once $n$ is
 large enough that $\varepsilon\, s_n > 2$, every indicator $\mathbf{1}_{\{|Y_k|
 > \varepsilon s_n\}}$ vanishes, so
$$\frac{1}{s_n^2}\sum_{k=1}^n \mathbb{E}\!\left[Y_k^2\,\mathbf{1}_{\{|Y_k|>\vare
psilon s_n\}}\right] = 0 \quad\text{for all large } n.$$
The Lindeberg condition holds, hence by the Lindeberg CLT
$$Z_n := \frac{S_n - \mu_n}{s_n} = \frac{\sum_{k=1}^n Y_k}{s_n} \xrightarrow{d}
\mathcal{N}(0,1).$$

**Taking the limit.** Since $S_n \leq 0 \iff Z_n \leq -\mu_n/s_n$,
$$\mathbb{P}(S_n \leq 0) = \mathbb{P}\!\left(Z_n \leq -\frac{\mu_n}{s_n}\right).
$$
We have $Z_n \xrightarrow{d} Z \sim \mathcal{N}(0,1)$ and $-\mu_n/s_n \to -2$. S
ince the standard normal CDF $\Phi$ is continuous, by the portmanteau/convergenc
e-of-CDF theorem (the limit point $-2$ is a continuity point of $\Phi$),
$$\lim_{n\to\infty}\mathbb{P}(S_n \leq 0) = \Phi(-2) = 1 - \Phi(2).$$

**Answer:**
$$\boxed{\lim_{n\to\infty}\mathbb{P}(X_1+\cdots+X_n \leq 0) = 1 - \Phi(2) \appro
x 0.0228,}$$
where $\Phi$ is the standard normal cumulative distribution function.
