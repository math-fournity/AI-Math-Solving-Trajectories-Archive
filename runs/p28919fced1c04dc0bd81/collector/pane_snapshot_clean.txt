## Solution

**Setup.** Let $\angle ABC = \beta$ and $\angle ACB = \gamma$. Since $\angle BAC
 = 30°$, we have $\beta + \gamma = 150°$. Point $D$ lies on segment $BC$, so $\a
ngle ADB = 180° - \angle ADC = 30°$.

**Angles in the two sub-triangles.**

In $\triangle ABD$: $\angle ADB = 30°$, $\angle ABD = \beta$, so $\angle BAD = 1
50° - \beta$.

In $\triangle ADC$: $\angle ADC = 150°$, $\angle ACD = \gamma$, so $\angle DAC =
 30° - \gamma$.

(Check: $\angle BAD + \angle DAC = (150°-\beta)+(30°-\gamma) = 180°-(\beta+\gamm
a) = 30°$. ✓)

**Using the condition $DC = AB$ via the sine rule.**

In $\triangle ABD$: $\dfrac{AB}{\sin 30°} = \dfrac{AD}{\sin\beta}$, so $AB = \df
rac{AD\sin 30°}{\sin\beta}$.

In $\triangle ADC$: $\dfrac{DC}{\sin(30°-\gamma)} = \dfrac{AD}{\sin\gamma}$, so
$DC = \dfrac{AD\sin(30°-\gamma)}{\sin\gamma}$.

Setting $DC = AB$ and cancelling $AD$:

$$\frac{\sin(30°-\gamma)}{\sin\gamma} = \frac{\sin 30°}{\sin\beta}.$$

Since $\beta = 150° - \gamma$, $\sin\beta = \sin(150°-\gamma)$. Cross-multiplyin
g:

$$\sin(30°-\gamma)\sin(150°-\gamma) = \sin 30°\sin\gamma.$$

**Simplifying.** Using product-to-sum on the left:

$$\sin(30°-\gamma)\sin(150°-\gamma) = \tfrac{1}{2}\bigl[\cos(-120°)-\cos(180°-2\
gamma)\bigr] = \tfrac{1}{2}\bigl[-\tfrac{1}{2}+\cos 2\gamma\bigr] = \tfrac{1}{2}
\cos 2\gamma - \tfrac{1}{4}.$$

The right side is $\tfrac{1}{2}\sin\gamma$. Substituting $\cos 2\gamma = 1 - 2\s
in^2\gamma$:

$$\tfrac{1}{2}(1-2\sin^2\gamma) - \tfrac{1}{4} = \tfrac{1}{2}\sin\gamma \;\;\Lon
grightarrow\;\; \tfrac{1}{4} - \sin^2\gamma = \tfrac{1}{2}\sin\gamma.$$

Setting $s = \sin\gamma$: $\;4s^2 + 2s - 1 = 0$, giving

$$s = \frac{-1 + \sqrt{5}}{4} \quad (s>0\text{ branch}).$$

Recognizing $\dfrac{\sqrt{5}-1}{4} = \sin 18°$, and noting $0 < \gamma < 30°$ (s
o $\angle DAC > 0$), we get $\gamma = 18°$.

**Result.** $\beta = 150° - 18° = 132°$.

**Verification.** With $\beta = 132°$, $\gamma = 18°$: $\angle BAD = 18°$, $\ang
le DAC = 12°$. From the sine rule, $AB = \dfrac{AD\sin 30°}{\sin 132°}$ and $DC
= \dfrac{AD\sin 12°}{\sin 18°}$. Numerically: $\sin 12°/\sin 18° \approx 0.6727$
 and $\sin 30°/\sin 132° = \tfrac{1}{2}/\sin 48° \approx 0.6727$. ✓

$$\boxed{\angle ABC = 132°}$$
