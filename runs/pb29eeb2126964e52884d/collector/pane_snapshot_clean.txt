## Solution

**Yes**, such a sequence exists. We exhibit an explicit example.

### Construction

For each $n \geq 1$, define
$$f_n : [-1,1] \to \mathbb{R}, \qquad f_n(x) = \frac{1}{n}\sin(n^2 x).$$

### Verification of the required properties

**1. Each $f_n$ is continuously differentiable.**
Each $f_n$ is a composition of smooth functions, hence $f_n \in C^1([-1,1])$ (in
 fact $C^\infty$).

**2. $f_n \to 0$ uniformly on $[-1,1]$.**
For every $x \in [-1,1]$ and every $n$,
$$|f_n(x)| = \frac{1}{n}|\sin(n^2 x)| \leq \frac{1}{n}.$$
Therefore
$$\|f_n\|_\infty = \sup_{x \in [-1,1]} |f_n(x)| \leq \frac{1}{n} \xrightarrow{n\
to\infty} 0,$$
which is precisely uniform convergence to the zero function.

**3. $\{N_2(f_n)\}$ is unbounded.**
We compute:
- $f_n(0) = \frac{1}{n}\sin(0) = 0$, so $|f_n(0)| = 0$.
- $f_n'(x) = n\cos(n^2 x)$, hence
$$\sup_{x \in [-1,1]} |f_n'(x)| = n \cdot \sup_{x \in [-1,1]} |\cos(n^2 x)| = n,
$$
since $\cos(n^2 \cdot 0) = \cos(0) = 1$, so the supremum equals $n$ (attained at
 $x = 0$).

Therefore
$$N_2(f_n) = |f_n(0)| + \sup_{x \in [-1,1]} |f_n'(x)| = 0 + n = n \xrightarrow{n
\to\infty} \infty.$$
In particular, $\{N_2(f_n)\}_{n \geq 1}$ is unbounded.

### Conclusion

The sequence $\{f_n\}$ with $f_n(x) = \frac{1}{n}\sin(n^2 x)$ consists of contin
uously differentiable functions on $[-1,1]$, converges uniformly to zero, yet sa
tisfies $N_2(f_n) = n \to \infty$. Hence such a sequence exists.

**Remark.** This also shows that the norm $N_2(f) = |f(0)| + \|f'\|_\infty$ is *
not* equivalent to the supremum norm $\|f\|_\infty$ on $C^1([-1,1])$. The one-si
ded inequality $\|f\|_\infty \leq |f(0)| + 2\|f'\|_\infty \leq 2\,N_2(f)$ (from
$f(x) = f(0) + \int_0^x f'(t)\,dt$) holds, but the reverse inequality fails, as
the example above demonstrates: $\|f_n\|_\infty \leq 1/n$ while $N_2(f_n) = n$.
