## Proof

**Interpretation.** Let $A=(a_{ij})$ be an $n\times n$ symmetric matrix with non
negative integer entries and column sums $\sum_i a_{ij}=1$ for every $j$. Since
$A$ is symmetric, the row sums equal the column sums, so every row also sums to
$1$. A sum of nonnegative integers equal to $1$ forces exactly one entry in each
 row to be $1$ and all others $0$. Hence $A$ is a $0$-$1$ matrix with exactly on
e $1$ in each row and each column — a permutation matrix. The symmetry condition
 $a_{ij}=a_{ji}$ makes this permutation matrix symmetric, which is equivalent to
 the corresponding permutation $\sigma\in S_n$ being an **involution** ($\sigma=
\sigma^{-1}$, i.e. $\sigma^2=\mathrm{id}$).

Therefore $S_n$ equals the number of involutions on $n$ elements.

---

### (a) The recurrence $S_{n+1}=S_n+n\,S_{n-1}$

Consider an involution $\sigma$ on $\{1,2,\dots,n+1\}$. There are two disjoint c
ases according to what happens to the element $n+1$:

- **$n+1$ is a fixed point** ($\sigma(n+1)=n+1$). Then $\sigma$ restricted to $\
{1,\dots,n\}$ is an arbitrary involution on $n$ elements. This gives $S_n$ invol
utions.

- **$n+1$ lies in a transposition** ($\sigma(n+1)=k$ for some $k\in\{1,\dots,n\}
$). There are $n$ choices for $k$. Once the pair $\{k,n+1\}$ is fixed, $\sigma$
restricted to the remaining $n-1$ elements $\{1,\dots,n\}\setminus\{k\}$ is an a
rbitrary involution. This gives $n\cdot S_{n-1}$ involutions.

These cases are exhaustive and mutually exclusive, so
$$S_{n+1}=S_n+n\,S_{n-1}. \qquad\blacksquare$$

*(Check: $S_0=1,\ S_1=1,\ S_2=S_1+1\cdot S_0=2,\ S_3=S_2+2S_1=4,\ S_4=S_3+3S_2=1
0$, matching the involution counts.)*

---

### (b) The exponential generating function $\displaystyle\sum_{n=0}^\infty S_n\
frac{x^n}{n!}=\exp\!\Big(x+\frac{x^2}{2}\Big)$

An involution on $n$ elements is uniquely a product of disjoint **fixed points**
 (1-cycles) and **transpositions** (2-cycles). Suppose an involution has exactly
 $k$ transpositions; then it uses $2k$ elements in transpositions and $n-2k$ fix
ed points. The number of such involutions is

$$\binom{n}{2k}\cdot\frac{(2k)!}{k!\,2^k}=\frac{n!}{(n-2k)!\,k!\,2^k},$$

where $\binom{n}{2k}$ chooses the $2k$ elements participating in transpositions,
 and $(2k)!/(k!\,2^k)$ partitions them into $k$ unordered pairs (dividing by $k!
$ for the order of the pairs and by $2^k$ for the order within each pair). Hence

$$S_n=\sum_{k=0}^{\lfloor n/2\rfloor}\frac{n!}{(n-2k)!\,k!\,2^k}.$$

Now compute the exponential generating function:

$$\sum_{n=0}^{\infty}S_n\frac{x^n}{n!}
=\sum_{n=0}^{\infty}\sum_{k=0}^{\lfloor n/2\rfloor}\frac{x^n}{(n-2k)!\,k!\,2^k}.
$$

Setting $m=n-2k\ge 0$ (so $n=m+2k$) and summing over all $m,k\ge 0$:

$$=\sum_{m=0}^{\infty}\sum_{k=0}^{\infty}\frac{x^{m+2k}}{m!\,k!\,2^k}
=\left(\sum_{m=0}^{\infty}\frac{x^m}{m!}\right)\!\left(\sum_{k=0}^{\infty}\frac{
(x^2)^k}{k!\,2^k}\right)
=e^x\cdot e^{x^2/2}
=\exp\!\Big(x+\frac{x^2}{2}\Big). \qquad\blacksquare$$

---

**Consistency check.** From $F(x)=\exp(x+x^2/2)$ we get $F'(x)=(1+x)F(x)$. Extra
cting the coefficient of $x^n/n!$ on both sides gives $S_{n+1}=S_n+nS_{n-1}$, co
nfirming that parts (a) and (b) agree.
