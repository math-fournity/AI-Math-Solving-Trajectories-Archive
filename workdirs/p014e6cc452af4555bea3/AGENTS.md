# Problem

In the high-tech logistics hub of Neo-Zion, an automated shipping system processes packages using a specific power-efficiency protocol. Every package must be assigned a "Value Unit" which is always a natural number raised to the power of 966.

A quality control engineer is tasked with assembling a shipment consisting of $n$ such packages. The protocol requires that the total sum of the Value Units in the shipment satisfies two strict security conditions:
1. The sum must be perfectly divisible by the facility’s primary security code, 2021.
2. To prevent a system overflow, the sum must not be divisible by the facility's "Maximum Capacity Threshold," which is defined as $2021^{966}$.

Find the smallest natural number $n$ for which it is possible to select $n$ such power-based Value Units that satisfy both conditions.
