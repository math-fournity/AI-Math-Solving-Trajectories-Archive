**第二步：特征线法。**

该 PDE 是一阶拟线性方程：
$$(x_2^2 + u)\,u_{x_1} + x_2\,u_{x_2} = 0.$$

特征线方程为：
$$\frac{dx_1}{x_2^2+u} \;=\; \frac{dx_2}{x_2} \;=\; \frac{du}{0}.$$

**第一个不变量。** 由 $du = 0$ 得到
$$c_1 = u \quad(\text{沿每条特征线为常数}).$$

**第二个不变量。** 利用 $u = c_1$（常数），通过 $dx_1/dx_2$ 进行参数化：
$$\frac{dx_1}{dx_2} = \frac{x_2^2 + c_1}{x_2} = x_2 + \frac{c_1}{x_2}.$$

积分：
$$x_1 = \frac{x_2^2}{2} + c_1\ln|x_2| + c_2.$$

因此第二个不变量为
$$c_2 = x_1 - \frac{x_2^2}{2} - u\ln|x_2|.$$

**通解。** 任意函数 $F$ 下的通积分为：
$$x_1 - \frac{x_2^2}{2} - u\ln|x_2| = F(u). \tag{$\ast$}$$

**第三步：应用初始条件。**

初始曲线为 $(x_1, x_2) = (s^2/2,\, s)$，且 $u = 0$。代入 $(\ast)$：
$$\frac{s^2}{2} - \frac{s^2}{2} - 0\cdot\ln|s| = F(0) \;\;\Longrightarrow\;\; F(
0) = 0.$$

选择满足此条件的最简单函数 $F$，即 $F \equiv 0$，得到：
$$x_1 - \frac{x_2^2}{2} - u\ln|x_2| = 0,$$

求解 $u$ 得到：
$$\boxed{u(x_1,x_2) = \frac{x_1 - \dfrac{x_2^2}{2}}{\ln|x_2|}}.$$

**第四步：验证。**

令 $w = x_1 - x_2^2/2$ 且 $L = \ln|x_2|$，因此 $u = w/L$。

$$u_{x_1} = \frac{1}{L}, \qquad u_{x_2} = \frac{-x_2\,L - w/x_2}{L^2} = \frac{-x
_2^2 L - w}{x_2\,L^2}.$$

代入 PDE：
$$(x_2^2 + u)\,u_{x_1} + x_2\,u_{x_2} = \left(x_2^2 + \frac{w}{L}\right)\frac{1}
{L} + x_2\cdot\frac{-x_2^2 L - w}{x_2\,L^2}$$
$$= \frac{x_2^2}{L} + \frac{w}{L^2} - \frac{x_2^2 L}{L^2} - \frac{w}{L^2} = \fra
c{x_2^2 L}{L^2} - \frac{x_2^2 L}{L^2} = 0.\;\checkmark$$

初始条件：
$$u\!\left(\frac{x_2^2}{2},\, x_2\right) = \frac{\frac{x_2^2}{2}-\frac{x_2^2}{2}
}{\ln|x_2|} = 0.\;\checkmark$$

该解在 $\ln|x_2|\neq 0$（即 $x_2\neq\pm1$）且 $x_2\neq 0$ 的区域内是经典的（光滑
的）。
