## 证明

设 $t = \ln x$，因此 $x = e^t$ 且 $x > 1$ 对应于 $t > 0$。则

$$f(x) = \frac{\sin t + \cos t}{e^t} = e^{-t}(\sin t + \cos t) = \sqrt{2}\,e^{-t
}\sin\!\left(t+\tfrac{\pi}{4}\right).$$

设 $g(t) = e^{-t}(\sin t + \cos t)$。因为 $\frac{df}{dx} = \frac{g'(t)}{x}$，$f$
 的临界点对应于 $g'(t)=0$。计算如下：

$$g'(t) = -e^{-t}(\sin t+\cos t)+e^{-t}(\cos t-\sin t) = -2e^{-t}\sin t.$$

因此 $g'(t)=0 \iff \sin t = 0 \iff t = k\pi$，其中 $k\in\mathbb{Z}$。对于 $t>0$
，候选点为 $t=k\pi$，$k=1,2,3,\dots$。

**极大值分类。** 在 $t=k\pi$ 附近，$\sin t \approx (-1)^k(t-k\pi)$，因此 $g'(t)=
-2e^{-t}\sin t \approx -2e^{-k\pi}(-1)^k(t-k\pi)$。
- $k$ 为奇数：$g'$ 从 $-$ 变为 $+$ $\Rightarrow$ 极小值。
- $k$ 为偶数：$g'$ 从 $+$ 变为 $-$ $\Rightarrow$ 极大值。

因此，$x>1$ 时 $f$ 的局部极大值出现在 $t_m = 2m\pi$，$m=1,2,3,\dots$，即

$$x_m = e^{2m\pi},\qquad \ln x_m = 2m\pi.$$

在这些点处，

$$f(x_m)=g(2m\pi)=e^{-2m\pi}\bigl(\sin(2m\pi)+\cos(2m\pi)\bigr)=e^{-2m\pi}\cdot
1 = e^{-2m\pi}.$$

因此 $\{f(x_m)\}^{1/n} = e^{-2m\pi/n}$，求和式变为

$$S_n = \sum_{k=1}^{n}\frac{e^{-2k\pi/n}\cdot 2k\pi}{n^2} = 2\pi\sum_{k=1}^{n}\f
rac{k}{n}\,e^{-2\pi k/n}\cdot\frac{1}{n}.$$

这是一个黎曼和。当 $n\to\infty$ 时，取 $u_k = k/n$ 和 $\Delta u = 1/n$，

$$\lim_{n\to\infty} S_n = 2\pi\int_0^1 u\,e^{-2\pi u}\,du.$$

**计算积分。** 通过分部积分法，令 $v=u$，$dw = e^{-2\pi u}du$，$w=-\frac{1}{2\pi
}e^{-2\pi u}$：

$$\int_0^1 u\,e^{-2\pi u}\,du = \left[-\frac{u}{2\pi}e^{-2\pi u}\right]_0^1 + \i
nt_0^1\frac{1}{2\pi}e^{-2\pi u}\,du = -\frac{e^{-2\pi}}{2\pi}+\frac{1}{2\pi}\cdo
t\frac{1-e^{-2\pi}}{2\pi}.$$

乘以 $2\pi$：

$$2\pi\int_0^1 u\,e^{-2\pi u}\,du = -e^{-2\pi}+\frac{1-e^{-2\pi}}{2\pi} = \frac{
1-e^{-2\pi}-2\pi e^{-2\pi}}{2\pi} = \frac{1-(1+2\pi)e^{-2\pi}}{2\pi}.$$

因此

$$\boxed{\lim_{n\to\infty}\sum_{k=1}^{n}\frac{\{f(x_k)\}^{1/n}\ln x_k}{n^2} = \f
rac{1-(1+2\pi)e^{-2\pi}}{2\pi}}.$$
