## Solution

The rational map is
$$\hat{\phi}:(t_0:t_1:t_2)\mapsto\left(\tfrac{1}{t_0}:\tfrac{1}{t_1}:\tfrac{1}{t
_2}\right).$$

The point $(1:1:0)$ lies in the domain $\mathbb{P}^2\setminus\{(1:0:0),(0:1:0),(
0:0:1)\}$, since it has only one zero coordinate, not two. However, the coordina
te $t_2=0$ makes the expression $1/t_2$ undefined, so we must evaluate the ratio
nal map via an equivalent representative that is regular at this point.

**Clearing denominators.** Multiplying all three homogeneous coordinate function
s by the common factor $t_0 t_1 t_2$ gives the equivalent expression
$$\hat{\phi}(t_0:t_1:t_2)=\left(t_1 t_2 : t_0 t_2 : t_0 t_1\right).$$

This is the same rational map (defined wherever $t_0 t_1 t_2\neq 0$), but the ri
ght-hand side is now a triple of polynomial (hence regular) functions on all of
$\mathbb{P}^2$, so we may evaluate it directly at $(1:1:0)$:
$$\left(1\cdot 0 : 1\cdot 0 : 1\cdot 1\right)=(0:0:1).$$

**Sanity check.** Approaching $(1:1:0)$ along the curve $(1:1:\varepsilon)$ as $
\varepsilon\to 0$:
$$\hat{\phi}(1:1:\varepsilon)=\left(1:1:\tfrac{1}{\varepsilon}\right)\sim\left(\
varepsilon:\varepsilon:1\right)\to(0:0:1).$$
