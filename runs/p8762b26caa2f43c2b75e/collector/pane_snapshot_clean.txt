## Solution

**Model as a graph.** Let $G$ be a graph on $n$ vertices (edges = acquaintance).
 The conditions are:
- Adjacent vertices have 0 common neighbors (so $G$ is triangle-free).
- Non-adjacent distinct vertices have exactly 2 common neighbors.

**Step 1: Minimum degree ≥ 2.** If vertex $v$ has degree 0, then for any $u \neq
 v$, the pair $(v,u)$ is non-adjacent with 0 common neighbors — contradiction. I
f $v$ has degree 1 with only neighbor $w$, then for any $u \neq v,w$, the pair $
(v,u)$ is non-adjacent but common neighbors ⊆ $\{w\}$, giving at most 1 — contra
diction.

**Step 2: The graph must be regular.** Let $A$ be the adjacency matrix, $D = \te
xt{diag}(d_1,\dots,d_n)$ the degree matrix, $J$ the all-ones matrix. The conditi
ons give:

$$A^2 = D + 2(J - I - A)$$

since $(A^2)_{ij}$ counts common neighbors: it equals $0$ when $A_{ij}=1$, equal
s $2$ when $A_{ij}=0, i\neq j$, and equals $d_i$ when $i=j$. So:

$$A^2 = D - 2I + 2J - 2A \quad (\star)$$

Applying $(\star)$ to $\mathbf{1}$: $A\mathbf{d} = -\mathbf{d} + 2(n-1)\mathbf{1
}$, i.e., $\sum_{j\sim i} d_j = 2(n-1) - d_i$.

Applying $A$ again and also computing $A^2\mathbf{d}$ from $(\star)$ directly (u
sing $D\mathbf{d} = (d_1^2,\dots,d_n^2)^T$, $J\mathbf{d} = 2m\mathbf{1}$), equat
ing both expressions yields:

$$d_i^2 - (2n-1)d_i + (4m - 2n + 2) = 0 \quad \text{for all } i.$$

So every degree is a root of the **same quadratic** $x^2 - (2n-1)x + (4m-2n+2) =
 0$. There are at most 2 distinct degrees $a, b$ with $a + b = 2n - 1$. But sinc
e $2 \leq d_i \leq n-1$ for all $i$, we get $a + b \leq 2(n-1) = 2n - 2 < 2n - 1
$ — **contradiction** if $a \neq b$. Therefore $G$ is **regular** of degree $k$.

**Step 3: Parameter equation.** For a $k$-regular graph, $m = nk/2$ and the quad
ratic becomes $k^2 + k = 2(n-1)$, giving:

$$n = \frac{k^2 + k + 2}{2}.$$

This is a strongly regular graph $\text{srg}(n, k, 0, 2)$.

**Step 4: Eigenvalue integrality.** The non-principal eigenvalues satisfy $x^2 +
 2x + (2-k) = 0$, giving $x = -1 \pm \sqrt{k-1}$. Let $t = \sqrt{k-1}$ (need $k-
1$ a perfect square for rational eigenvalues). Then $k = t^2 + 1$ and $n = \frac
{t^4 + 3t^2 + 4}{2}$.

The multiplicities $f, g$ of eigenvalues $-1+t$ and $-1-t$ satisfy $f+g = n-1$ a
nd $k + f(-1+t) + g(-1-t) = 0$, giving $f - g = \frac{(n-1) - k}{t}$. This must
be a non-negative integer.

- **$k = 2$ ($t=1$):** $n = 4 < 5$. Too small.
- **$k = 3$ ($t=\sqrt{2}$, irrational):** $n = 7$. Need $f - g = 3/\sqrt{2}$, no
t an integer. **No graph exists.**
- **$k = 4$ ($t=\sqrt{3}$, irrational):** $n = 11$. Need $f - g = 6/\sqrt{3} = 2
\sqrt{3}$, not an integer. **No graph exists.**
- **$k = 5$ ($t=2$):** $n = 16$. Eigenvalues $1$ and $-3$. Multiplicities: $f +
g = 15$, $f - g = 5$, so $f = 10, g = 5$. All non-negative integers. ✓

**Step 5: The Clebsch graph realizes $n = 16$.** Construct $G$ on the 16 subsets
 of $\{1,2,3,4\}$: vertices $A, B$ are adjacent iff $|A \triangle B| \in \{1, 4\
}$.

- **Degree:** Each set $A$ of size $s$ has $s(4-s)$ neighbors at symmetric diffe
rence 1, plus 1 neighbor ($\bar{A}$) at symmetric difference 4. Total: $s(4-s) +
 1$. For $s=0$: $0+1=1$...

  Actually, let me recompute: $|A \triangle B| = 1$ means $B = A \triangle \{x\}
$ for some $x$, giving $4$ choices. $|A \triangle B| = 4$ means $B = \bar{A}$, g
iving $1$ choice. Total degree $= 4 + 1 = 5$. ✓

- **Adjacent pairs ($|A\triangle B|=1$):** Common neighbor $C$ needs $|A\triangl
e C|, |B\triangle C| \in \{1,4\}$. Since $A \triangle B = (A\triangle C)\triangl
e(B\triangle C)$ has size 1, but the symmetric difference of two sets each of si
ze 1 or 4 cannot have size 1 (two singletons give size 0 or 2; singleton and 4-s
et give size 3 or 5; two 4-sets give size 0). So **0 common neighbors**. ✓

- **Non-adjacent pairs ($|A\triangle B| \in \{2,3\}$):**
  - If $|A \triangle B| = 2$: Common neighbors from $|A\triangle C|=|B\triangle
C|=1$ require two distinct singletons whose symmetric difference is $A\triangle
B$ (size 2) — exactly 2 choices. The complement cases give symmetric difference
2 (not in $\{1,4\}$). So **exactly 2 common neighbors**. ✓
  - If $|A \triangle B| = 3$: $C = \bar{A}$ gives $|B \triangle \bar{A}| = 1$ ✓,
 and $C = \bar{B}$ gives $|A \triangle \bar{B}| = 1$ ✓. The $|A\triangle C|=|B\t
riangle C|=1$ case requires symmetric difference of two singletons to have size
3 — impossible. So **exactly 2 common neighbors**. ✓

**Conclusion.** The graph must be regular with $n = \frac{k^2+k+2}{2}$. For $k =
 2,3,4$ we get $n = 4, 7, 11$ — either too small or the strongly regular graph d
oesn't exist (eigenvalue multiplicities non-integral). For $k = 5$ we get $n = 1
6$, realized by the Clebsch graph.

$$\boxed{n = 16}$$
