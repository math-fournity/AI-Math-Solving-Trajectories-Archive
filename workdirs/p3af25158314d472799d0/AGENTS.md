# Problem

In a massive logistics warehouse, there are 9 horizontal conveyor belt levels and 2008 vertical storage chutes, forming a grid of 18,072 slots. The facility is tasked with processing 2008 unique types of packages, labeled with identification numbers 1 through 2008. Each package ID appears exactly 9 times across the entire grid.

The facility’s sorting protocol dictates a strict "proximity rule": for any two packages resting in the same vertical storage chute, the absolute difference between their identification numbers cannot exceed 3.

Safety inspectors are calculating the "load weight" of each chute, which is defined as the sum of the identification numbers of the 9 packages currently stored in that vertical column. The warehouse manager wants to organize the packages to ensure the weakest chute stays as safe as possible. 

What is the maximum possible value for the minimum load weight among all 2008 chutes?
