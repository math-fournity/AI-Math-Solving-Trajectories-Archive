## Proof

**Answer: Yes.** For every continuous function $f:[0,1]\to\mathbb{R}$, there exi
sts a sequence of continuous functions $\{f_n\}$ converging pointwise to $f$ but
 not uniformly.

**Construction.** It suffices to find a sequence of continuous functions $g_n:[0
,1]\to\mathbb{R}$ with $g_n\to 0$ pointwise but **not** uniformly, for then $f_n
 := f + g_n$ is continuous, $f_n\to f$ pointwise, and $\|f_n-f\|_\infty = \|g_n\
|_\infty \not\to 0$, giving non-uniform convergence.

Define the "tent" functions $g_n$ piecewise-linearly:

$$
g_n(x) = \begin{cases}
2n\,x, & 0 \le x \le \tfrac{1}{2n},\\[4pt]
2 - 2n\,x, & \tfrac{1}{2n} \le x \le \tfrac{1}{n},\\[4pt]
0, & \tfrac{1}{n} \le x \le 1.
\end{cases}
$$

Each $g_n$ is continuous: it is linear on each piece and the values agree at the
 breakpoints $x=\tfrac{1}{2n}$ (both give $1$) and $x=\tfrac{1}{n}$ (both give $
0$), and $g_n(0)=0$.

**Pointwise convergence to 0.** Fix $x\in[0,1]$.
- If $x=0$: $g_n(0)=0$ for all $n$, so $g_n(0)\to 0$.
- If $x>0$: choose $N$ with $\tfrac{1}{N}<x$. Then for all $n\ge N$, $\tfrac{1}{
n}\le \tfrac{1}{N}<x$, so $x\in[\tfrac{1}{n},1]$ and $g_n(x)=0$. Hence $g_n(x)\t
o 0$.

Thus $g_n\to 0$ pointwise on $[0,1]$.

**Not uniform.** The peak value is $g_n\!\left(\tfrac{1}{2n}\right)=1$ for every
 $n$. Therefore

$$
\|g_n\|_\infty = \sup_{x\in[0,1]}|g_n(x)| = 1 \quad\text{for all } n,
$$

which does not tend to $0$. Hence $g_n\not\to 0$ uniformly.

**Conclusion.** Setting $f_n := f + g_n$:
- Each $f_n$ is continuous (sum of continuous functions).
- $f_n(x) = f(x) + g_n(x) \to f(x) + 0 = f(x)$ pointwise for every $x\in[0,1]$.
- $\displaystyle\sup_{x\in[0,1]}|f_n(x)-f(x)| = \sup_{x\in[0,1]}|g_n(x)| = 1 \no
t\to 0$,

so $f_n\to f$ pointwise but **not** uniformly.

Since $f$ was an arbitrary continuous function on $[0,1]$, such a sequence **alw
ays** exists. $\blacksquare$
