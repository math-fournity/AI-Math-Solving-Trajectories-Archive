## Proof

**Setup.** Number rows $1,\dots,2017$ and columns $1,\dots,100$. The checkerboar
d color of cell $(i,j)$ is $(i+j)\bmod 2$. A grasshopper at $(i,j)$ attacks:
- every cell $(i,j')$ in its row with $j'\equiv j\pmod 2$ (same color), and
- every cell $(i',j)$ in its column with $i'\not\equiv i\pmod 2$ (opposite color
).

Since the attack relation is symmetric (both directions give the same two condit
ions), two grasshoppers at $(i_1,j_1)$ and $(i_2,j_2)$ conflict iff
- **(R)** $i_1=i_2$ and $j_1\equiv j_2\pmod 2$ (same row, same column parity), o
r
- **(C)** $j_1=j_2$ and $i_1\not\equiv i_2\pmod 2$ (same column, opposite row pa
rity).

**Classify cells by type** $(i\bmod 2,\,j\bmod 2)\in\{0,1\}^2$:

| Type | Row parity | Col parity | # rows | # cols |
|------|-----------|-----------|--------|--------|
| $A$ | even | even | 1008 | 50 |
| $B$ | even | odd  | 1008 | 50 |
| $C$ | odd  | even | 1009 | 50 |
| $D$ | odd  | odd  | 1009 | 50 |

**Upper bound.** Condition (R) says: within a fixed row and fixed column parity,
 at most one grasshopper. Since type determines column parity, this means **at m
ost one grasshopper of each type per row**. Hence
$$|A|\le 1008,\quad |B|\le 1008,\quad |C|\le 1009,\quad |D|\le 1009,$$
so the total is at most $1008+1008+1009+1009 = \boxed{4034}$.

(Condition (C) only further restricts; it cannot raise this bound.)

**Construction achieving 4034.** Condition (C) forces, in each even column, that
 types $A$ and $C$ do not mix; in each odd column, types $B$ and $D$ do not mix.
 We assign:
- even column $2$ to type $A$; even column $4$ to type $C$ (the remaining even c
olumns unused);
- odd column $1$ to type $B$; odd column $3$ to type $D$ (the remaining odd colu
mns unused).

Place:
- $A$: $(2,2),(4,2),\dots,(2016,2)$ — all $1008$ even rows, column $2$.
- $C$: $(1,4),(3,4),\dots,(2017,4)$ — all $1009$ odd rows, column $4$.
- $B$: $(2,1),(4,1),\dots,(2016,1)$ — all $1008$ even rows, column $1$.
- $D$: $(1,3),(3,3),\dots,(2017,3)$ — all $1009$ odd rows, column $3$.

**Verification of no conflicts.**
- *Within each type:* all cells share one column and have the same row parity, s
o (C) is not triggered (it requires opposite row parity); all rows are distinct,
 so (R) is not triggered. ✓
- *$A$ vs $C$:* different columns ($2$ vs $4$), so (C) not triggered; rows have
opposite parity so they are never equal, hence (R) not triggered. ✓
- *$B$ vs $D$:* different columns ($1$ vs $3$); rows opposite parity, never equa
l. ✓
- *$A$ vs $B$:* same even rows possible, but column parities differ ($2$ even, $
1$ odd), so (R) not triggered; different columns, so (C) not triggered. ✓
- *$C$ vs $D$:* same odd rows possible, but column parities differ ($4$ even, $3
$ odd); different columns. ✓
- *$A$ vs $D$, $B$ vs $C$:* different rows and different columns. ✓

All $1008+1009+1008+1009=4034$ grasshoppers are mutually non-attacking.

**Conclusion.** The maximum number is $\boxed{4034}$.
