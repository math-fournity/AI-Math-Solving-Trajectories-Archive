## Solution

We count functions $f:\{1,2,3\}\to\{1,2,3\}$ satisfying $f(f(x))=f(f(f(x)))$ for
 all $x$, i.e., $f^2 = f^3$. Equivalently, $f(f^2(x)) = f^2(x)$ for every $x$, m
eaning **$f^2(x)$ is a fixed point of $f$ for every $x$**.

We partition all $3^3=27$ functions by the number of fixed points of $f$.

---

**Case 1: 3 fixed points (the identity).** $f=\mathrm{id}$, so $f^2=f^3=\mathrm{
id}$. ✓
Count: **1**.

---

**Case 2: exactly 2 fixed points.** Say $a,b$ are fixed and $c$ is not, with $f(
c)\in\{a,b\}$. Then $f^2(c)=f(f(c))=f(a)=a$ or $f(b)=b$, and $f^3(c)=f(f^2(c))=f
^2(c)$ since $a,b$ are fixed. Likewise $f^2(a)=a=f^3(a)$, $f^2(b)=b=f^3(b)$. All
 work.
Choices: $\binom{3}{2}\cdot 2 = 6$. Count: **6**.

---

**Case 3: exactly 1 fixed point.** Say $a$ is fixed; $b,c$ are not. Then $f(b)\i
n\{a,c\}$ and $f(c)\in\{a,b\}$, giving 4 subcases:

- $f(b)=a,\; f(c)=a$: $f^2(b)=a=f^3(b)$, $f^2(c)=a=f^3(c)$. ✓
- $f(b)=a,\; f(c)=b$: $f^2(c)=f(b)=a$, $f^3(c)=f(a)=a$. ✓; $f^2(b)=a=f^3(b)$. ✓
- $f(b)=c,\; f(c)=a$: $f^2(b)=f(c)=a$, $f^3(b)=f(a)=a$. ✓; $f^2(c)=a=f^3(c)$. ✓
- $f(b)=c,\; f(c)=b$: this is a 2-cycle on $\{b,c\}$. Then $f^2(b)=b$ but $f^3(b
)=f(b)=c\neq b$. ✗

So 3 of 4 subcases work, for each of 3 choices of $a$. Count: $3\times 3 =$ **9*
*.

---

**Case 4: 0 fixed points.** Here $f(x)\neq x$ for all $x$. Take any $x$; set $y=
f(x)\neq x$ and $z=f(y)=f^2(x)$. Since $f^2(x)$ must be a fixed point (the condi
tion), but $f$ has **no** fixed points, this is impossible — *unless* the condit
ion fails. Indeed for each such function, $f^2(x)$ is required to be a fixed poi
nt, yet none exist, so no function with 0 fixed points can satisfy $f^2=f^3$.

(Concretely, all 8 such functions fail: e.g., $f=(2,1,1)$ gives $f^2(1)=1$ but $
f^3(1)=2\neq 1$; the two 3-cycles give $f^2\neq f^3$; etc.)
Count: **0**.

---

**Verification of partition:** $1+6+12+8=27$ ✓ (3 fixed: 1; 2 fixed: 6; 1 fixed:
 12; 0 fixed: 8).

**Total:** $1 + 6 + 9 + 0 = \boxed{16}$.
