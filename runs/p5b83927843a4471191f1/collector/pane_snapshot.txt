Looking at this problem, I need to prove that in a $2n \times 2n$ matrix with en
tries in $[-1,1]$ and total sum $0$, there exists a row or column whose sum has
absolute value at most $n$.

**Proof.**

We prove by contradiction. Assume every row sum and every column sum has absolut
e value strictly greater than $n$.

**Setup.** Let $r_i$ denote the row sums and $c_j$ the column sums. Since $\sum
r_i = \sum c_j = 0$, no sum can be zero (otherwise its absolute value is $0 \leq
 n$, contradicting our assumption). Partition the rows into $\mathcal{R}^+$ (pos
itive sums) and $\mathcal{R}^-$ (negative sums), and columns into $\mathcal{C}^+
$ and $\mathcal{C}^-$. Let $r = |\mathcal{R}^+|$, $s = |\mathcal{C}^+|$, so $|\m
athcal{R}^-| = 2n - r$, $|\mathcal{C}^-| = 2n - s$.

Define:
$$T_r = \sum_{i \in \mathcal{R}^+} r_i > 0, \qquad T_c = \sum_{j \in \mathcal{C}
^+} c_j > 0.$$

Since each positive row sum exceeds $n$ and each negative row sum is less than $
-n$:
$$T_r > n \cdot \max(r,\; 2n - r), \qquad T_c > n \cdot \max(s,\; 2n - s). \tag{
1}$$

**Four-block decomposition.** Split the matrix into four blocks according to $(\
mathcal{R}^{\pm}, \mathcal{C}^{\pm})$ and let $X, Y, Z, W$ be the sums of entrie
s in $\mathcal{R}^+\times\mathcal{C}^+$, $\mathcal{R}^+\times\mathcal{C}^-$, $\m
athcal{R}^-\times\mathcal{C}^+$, $\mathcal{R}^-\times\mathcal{C}^-$ respectively
. Then:
$$X + Y = T_r, \quad X + Z = T_c, \quad Z + W = -T_r, \quad Y + W = -T_c,$$
which gives $Y = T_r - X$, $Z = T_c - X$, $W = X - T_r - T_c$.

Since each entry has absolute value $\leq 1$:
$$|X| \leq rs, \quad |Y| \leq r(2n-s), \quad |Z| \leq (2n-r)s, \quad |W| \leq (2
n-r)(2n-s). \tag{2}$$

**Deriving the key inequality.** From (2), $X$ must lie in all four intervals:
$$X \in [T_r - r(2n\!-\!s),\; T_r + r(2n\!-\!s)], \quad X \in [T_c - (2n\!-\!r)s
,\; T_c + (2n\!-\!r)s],$$
$$X \in [-rs,\; rs], \quad X \in [T_r + T_c - (2n\!-\!r)(2n\!-\!s),\; T_r + T_c
+ (2n\!-\!r)(2n\!-\!s)].$$

For a valid $X$ to exist, the lower bound of the fourth interval must not exceed
 the upper bound of the third:
$$T_r + T_c - (2n-r)(2n-s) \leq rs \iff T_r + T_c \leq rs + (2n-r)(2n-s). \tag{3
}$$

We now show (3) is **violated** in every case, using (1). Note that $rs + (2n-r)
(2n-s) = 4n^2 - 2n(r+s) + 2rs$.

**Case 1: $r \leq n$, $s \leq n$.** Then $\max(r, 2n-r) = 2n-r$, $\max(s, 2n-s)
= 2n-s$. By (1):
$$T_r + T_c > n(4n - r - s).$$
We need $n(4n - r - s) \geq 4n^2 - 2n(r+s) + 2rs$, i.e., $n(r+s) \geq 2rs$. Sinc
e $r \leq n$ and $s \leq n$: $2rs \leq 2n\min(r,s) \leq n(r+s)$. Equality holds
only when $r = s = n$. When $r = s = n$: $T_r + T_c > 2n^2 = n^2 + n^2 = rs + (2
n-r)(2n-s)$, strict. Otherwise the inequality is strict. So $T_r + T_c > rs + (2
n-r)(2n-s)$. ✗

**Case 2: $r \leq n$, $s > n$.** Then $\max(r, 2n-r) = 2n-r$, $\max(s, 2n-s) = s
$. By (1):
$$T_r + T_c > n(2n - r + s).$$
We need $n(2n - r + s) \geq 4n^2 - 2n(r+s) + 2rs$. Substituting $r = n - \alpha$
 ($\alpha \geq 0$), $s = n + \beta$ ($\beta > 0$):
$$n(2n - r + s) - [4n^2 - 2n(r+s) + 2rs] = n(\alpha + \beta) + 2\alpha\beta > 0.
$$
So $T_r + T_c > rs + (2n-r)(2n-s)$. ✗

**Case 3: $r > n$, $s \leq n$.** Symmetric to Case 2. ✗

**Case 4: $r > n$, $s > n$.** Then $\max(r, 2n-r) = r$, $\max(s, 2n-s) = s$. By
(1):
$$T_r + T_c > n(r + s).$$
We need $n(r+s) \geq 4n^2 - 2n(r+s) + 2rs$, i.e., $3n(r+s) \geq 4n^2 + 2rs$. Sub
stituting $r = n + \alpha$, $s = n + \beta$ ($0 < \alpha, \beta < n$, strict sin
ce we need at least one negative row/column for the total sum to be $0$):
$$3n(r+s) - 4n^2 - 2rs = n(\alpha + \beta) - 2\alpha\beta.$$
Since $\alpha < n$ and $\beta < n$: $2\alpha\beta < 2n\min(\alpha,\beta) \leq n(
\alpha + \beta)$, so this is strictly positive. Thus $T_r + T_c > rs + (2n-r)(2n
-s)$. ✗

**Conclusion.** In all cases, $T_r + T_c > rs + (2n-r)(2n-s)$, contradicting the
 necessary condition (3). Therefore, no such matrix exists under our assumption,
 and there must exist a row or column whose sum has absolute value at most $n$.
$\blacksquare$
