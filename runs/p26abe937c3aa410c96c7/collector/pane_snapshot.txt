## Proof

Let $X = \mathbb{R}^{\mathbb{R}}$ equipped with the product topology, and let
$$C = \{f \in \mathbb{R}^{\mathbb{R}} : \{x \in \mathbb{R} : f(x) \neq 0\} \text
{ is countable}\}.$$

We claim **$C$ is dense in $X$**.

**Basis of the product topology.** A basic open set in $\mathbb{R}^{\mathbb{R}}$
 has the form
$$B = \prod_{x \in \mathbb{R}} U_x$$
where each $U_x \subseteq \mathbb{R}$ is open and $U_x = \mathbb{R}$ for all but
 finitely many $x$. Equivalently, $B$ is determined by a finite set $F = \{x_1,
\dots, x_n\} \subseteq \mathbb{R}$ and nonempty open sets $U_{x_1}, \dots, U_{x_
n} \subseteq \mathbb{R}$, and
$$B = \{f \in \mathbb{R}^{\mathbb{R}} : f(x_i) \in U_{x_i} \text{ for all } i =
1, \dots, n\}.$$

**Density criterion.** $C$ is dense in $X$ iff every nonempty basic open set $B$
 intersects $C$.

**Construction.** Let $B$ be any nonempty basic open set, determined by $F = \{x
_1, \dots, x_n\}$ and nonempty open sets $U_{x_1}, \dots, U_{x_n}$. For each $i$
, pick a point $y_i \in U_{x_i}$ (possible since each $U_{x_i}$ is nonempty and
open). Define $f \colon \mathbb{R} \to \mathbb{R}$ by
$$f(x) = \begin{cases} y_i & \text{if } x = x_i \text{ for some } i \in \{1, \do
ts, n\}, \\ 0 & \text{otherwise.} \end{cases}$$

**$f \in C$.** The set $\{x \in \mathbb{R} : f(x) \neq 0\}$ is contained in $F$,
 which is finite (hence countable). So $f \in C$.

**$f \in B$.** For each $i$, $f(x_i) = y_i \in U_{x_i}$. Hence $f$ satisfies all
 the finitely many constraints defining $B$, so $f \in B$.

**Conclusion.** Every nonempty basic open set $B$ in $X$ contains an element of
$C$. Therefore $C \cap B \neq \emptyset$ for every nonempty open set $B$, which
means $\overline{C} = X$. Hence $C$ is dense in $X = \mathbb{R}^{\mathbb{R}}$ wi
th the product topology. $\blacksquare$
