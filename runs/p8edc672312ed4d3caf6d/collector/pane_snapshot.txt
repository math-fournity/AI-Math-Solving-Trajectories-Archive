## Proof

We determine the cardinality of $S$, the set of all infinite subsets of $\mathbb
{Q}$.

**Step 1: The power set of $\mathbb{Q}$.** Since $\mathbb{Q}$ is countably infin
ite, $|\mathbb{Q}| = \aleph_0$. The power set $\mathcal{P}(\mathbb{Q})$ therefor
e has cardinality $|\mathcal{P}(\mathbb{Q})| = 2^{\aleph_0}$, the cardinality of
 the continuum.

**Step 2: The set of finite subsets of $\mathbb{Q}$ is countable.** Let $\mathca
l{F}$ denote the collection of all finite subsets of $\mathbb{Q}$. We can write
$\mathcal{F} = \bigcup_{n=0}^{\infty} \mathcal{F}_n$, where $\mathcal{F}_n$ is t
he set of subsets of $\mathbb{Q}$ of size $n$. Each $\mathcal{F}_n$ is in biject
ion with $\mathbb{Q}^n / S_n$ (ordered $n$-tuples modulo permutation), and since
 $\mathbb{Q}^n$ is a countable set (a finite product of countable sets is counta
ble), each $\mathcal{F}_n$ is countable. A countable union of countable sets is
countable, so $|\mathcal{F}| = \aleph_0$.

**Step 3: Decompose $\mathcal{P}(\mathbb{Q})$.** Every subset of $\mathbb{Q}$ is
 either finite or infinite, so
$$\mathcal{P}(\mathbb{Q}) = \mathcal{F} \sqcup S,$$
a disjoint union. Therefore
$$|\mathcal{P}(\mathbb{Q})| = |\mathcal{F}| + |S|.$$

**Step 4: Compute $|S|$.** We have $2^{\aleph_0} = \aleph_0 + |S|$. Since $2^{\a
leph_0} > \aleph_0$ (by Cantor's theorem), and $2^{\aleph_0}$ is an infinite car
dinal, adding the countable cardinal $\aleph_0$ to $|S|$ satisfies $\aleph_0 + |
S| = \max(\aleph_0, |S|)$. For this to equal $2^{\aleph_0} > \aleph_0$, we must
have $|S| = 2^{\aleph_0}$.

**Conclusion.** The set $S$ of all infinite subsets of $\mathbb{Q}$ has cardinal
ity

$$\boxed{2^{\aleph_0}}$$

the cardinality of the continuum.
