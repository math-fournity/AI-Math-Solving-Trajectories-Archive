## Proof

Assume GCH. We work with cardinal arithmetic.

**Setup and notation.** Let $\mathfrak{n}=|\mathbb N|=\aleph_0$ and $\mathfrak{c
}=|\mathbb R|=2^{\aleph_0}$. Under GCH, $2^{\aleph_0}=\aleph_1$, so $\mathfrak{c
}=\aleph_1$.

We are told $\mathfrak{n}\le |I|\le \mathfrak{c}$, i.e. $\aleph_0\le |I|\le \ale
ph_1$. Since $\aleph_1$ is the immediate successor of $\aleph_0$, the only possi
ble values are
$$|I|\in\{\aleph_0,\,\aleph_1\}.$$

**Computing $|\mathbb R^I|$.** For any set $I$,
$$|\mathbb R^I|=|\mathbb R|^{|I|}=(2^{\aleph_0})^{|I|}=2^{\aleph_0\cdot |I|}.$$

We use the standard cardinal identity $(2^\kappa)^\lambda=2^{\kappa\cdot\lambda}
$, valid for all infinite cardinals.

**Case 1: $|I|=\aleph_0$.** Then
$$|\mathbb R^I|=2^{\aleph_0\cdot\aleph_0}=2^{\aleph_0}=\mathfrak{c}=|\mathbb R|.
\quad\checkmark$$
This is consistent with the hypothesis $|\mathbb R^I|=|\mathbb R|$.

**Case 2: $|I|=\aleph_1$.** Then, since $\aleph_0\cdot\aleph_1=\aleph_1$,
$$|\mathbb R^I|=2^{\aleph_0\cdot\aleph_1}=2^{\aleph_1}.$$
By GCH, $2^{\aleph_1}=\aleph_2$. Hence
$$|\mathbb R^I|=\aleph_2\ne\aleph_1=\mathfrak{c}=|\mathbb R|.\quad\text{contradi
ction.}$$
So $|I|=\aleph_1$ is incompatible with $|\mathbb R^I|=|\mathbb R|$.

**Conclusion.** The only value consistent with both $\aleph_0\le|I|\le\aleph_1$
and $|\mathbb R^I|=|\mathbb R|$ is $|I|=\aleph_0$.

$$\boxed{|I|=|\mathbb N|=\aleph_0.}$$
