## Proof

**Notation.** Let $\Phi(z) = \frac{2}{\sqrt{\pi}}\int_0^z e^{-s^2}\,ds$ (error f
unction), so $\Phi(0)=0$, $\Phi(\infty)=1$, $\Phi'(z)=\frac{2}{\sqrt{\pi}}e^{-z^
2}$, $\Phi''(z)=-2z\,\Phi'(z)$.

### Step 1: Similarity ansatz for the free boundary

We seek a self-similar solution with the freezing front $\xi(t) = 2a\sqrt{t}$ fo
r a constant $a>0$ to be determined. This is the natural scaling: the heat equat
ion has diffusion length $\sim\sqrt{t}$, so the interface must move as $\sqrt{t}
$.

### Step 2: Similarity solutions of the heat equation

For $u_t = a_i^2 u_{xx}$, set $\eta_i = \frac{x}{2a_i\sqrt{t}}$. The function $\
Phi(\eta_i)$ satisfies the heat equation:

$$u_t = \Phi'(\eta_i)\left(-\frac{\eta_i}{2t}\right), \quad a_i^2 u_{xx} = \frac
{\Phi''(\eta_i)}{4t} = \frac{-2\eta_i\,\Phi'(\eta_i)}{4t} = -\frac{\eta_i\,\Phi'
(\eta_i)}{2t} = u_t. \quad\checkmark$$

By linearity, the general similarity solutions are:
$$u_1 = A_1 + B_1\,\Phi\!\left(\tfrac{x}{2a_1\sqrt{t}}\right), \qquad u_2 = A_2
+ B_2\,\Phi\!\left(\tfrac{x}{2a_2\sqrt{t}}\right).$$

At the interface $x=\xi(t)=2a\sqrt{t}$, the similarity variables evaluate to:
$$\eta_1\big|_\xi = \frac{a}{a_1}, \qquad \eta_2\big|_\xi = \frac{a}{a_2}.$$

### Step 3: Determine coefficients from boundary/initial/interface conditions

**(a) Left boundary** $u_1(0,t)=U_1$: Since $\Phi(0)=0$, we get $A_1 = U_1$.

**(b) Right boundary** $u_2(+\infty,t)=U_2$: Since $\Phi(\infty)=1$, we get $A_2
 + B_2 = U_2$.

**(c) Initial condition** $u_2(x,0)=U_2$ for $x>0$: As $t\to 0^+$, $\eta_2\to\in
fty$, so $u_2\to A_2+B_2=U_2$. ✓ (automatically satisfied)

**(d) Interface temperature** $u_1(\xi,t)=u_2(\xi,t)=0$ (freezing point = 0):

- From $u_1(\xi,t)=0$: $\;U_1 + B_1\,\Phi\!\left(\frac{a}{a_1}\right)=0 \;\Longr
ightarrow\; B_1 = -\dfrac{U_1}{\Phi(a/a_1)}$.

- From $u_2(\xi,t)=0$: $\;A_2 + B_2\,\Phi\!\left(\frac{a}{a_2}\right)=0 \;\Longr
ightarrow\; A_2 = -B_2\,\Phi\!\left(\frac{a}{a_2}\right)$.

- Combined with $A_2+B_2=U_2$: $\;B_2\!\left(1-\Phi\!\left(\frac{a}{a_2}\right)\
right)=U_2$, giving
$$B_2 = \frac{U_2}{1-\Phi(a/a_2)}, \qquad A_2 = -\frac{U_2\,\Phi(a/a_2)}{1-\Phi(
a/a_2)}.$$

### Step 4: Stefan condition → transcendental equation for $a$

Compute the fluxes at the interface:
$$\frac{\partial u_i}{\partial x}\bigg|_{\xi} = \frac{B_i}{2a_i\sqrt{t}}\,\Phi'\
!\left(\frac{a}{a_i}\right) = \frac{B_i}{a_i\sqrt{\pi\,t}}\,e^{-a^2/a_i^2}.$$

The interface velocity is $\xi'(t) = \frac{a}{\sqrt{t}}$.

The Stefan condition $k_1\,u_{1x}\big|_\xi - k_2\,u_{2x}\big|_\xi = Q\rho\,\xi'(
t)$ becomes:

$$\frac{k_1 B_1}{a_1\sqrt{\pi t}}\,e^{-a^2/a_1^2} - \frac{k_2 B_2}{a_2\sqrt{\pi
t}}\,e^{-a^2/a_2^2} = Q\rho\,\frac{a}{\sqrt{t}}.$$

Multiplying through by $\sqrt{\pi\,t}$:

$$\frac{k_1 B_1}{a_1}\,e^{-a^2/a_1^2} - \frac{k_2 B_2}{a_2}\,e^{-a^2/a_2^2} = Q\
rho\,a\sqrt{\pi}.$$

Substituting $B_1 = -\frac{U_1}{\Phi(a/a_1)}$ and $B_2 = \frac{U_2}{1-\Phi(a/a_2
)}$:

$$-\frac{k_1 U_1}{a_1\,\Phi(a/a_1)}\,e^{-a^2/a_1^2} - \frac{k_2 U_2}{a_2\!\left(
1-\Phi(a/a_2)\right)}\,e^{-a^2/a_2^2} = Q\rho\,a\sqrt{\pi},$$

or equivalently:

$$\boxed{\frac{k_1\,U_1\,e^{-a^2/a_1^2}}{a_1\,\Phi(a/a_1)} + \frac{k_2\,U_2\,e^{
-a^2/a_2^2}}{a_2\!\left(1-\Phi(a/a_2)\right)} = -\,Q\rho\,a\sqrt{\pi}.}$$

This is the **transcendental equation for $a$**. Under physically meaningful con
ditions ($U_1 < 0$ for the supercooled solid side, $U_2 > 0$ for the warm liquid
), the left-hand side is a strictly decreasing function of $a>0$ (each term decr
eases as $a$ increases), guaranteeing a **unique positive root** $a$.

### Step 5: Complete solution

With $a$ determined by the transcendental equation, the solution is:

$$u_1(x,t) = U_1\left[1 - \frac{\Phi\!\left(\frac{x}{2a_1\sqrt{t}}\right)}{\Phi(
a/a_1)}\right], \qquad 0 < x < 2a\sqrt{t},$$

$$u_2(x,t) = \frac{U_2\left[\Phi\!\left(\frac{x}{2a_2\sqrt{t}}\right) - \Phi(a/a
_2)\right]}{1 - \Phi(a/a_2)}, \qquad 2a\sqrt{t} < x < \infty,$$

with the freezing front $\xi(t) = 2a\sqrt{t}$.

### Step 6: Verification of all conditions

4. **$u_2(x,0) = U_2$ for $x>0$:** $\eta_2\to\infty \Rightarrow u_2\to U_2$. ✓
5. **$u_1(\xi,t) = 0$:** $\Phi(a/a_1)=\Phi(a/a_1) \Rightarrow u_1 = U_1[1-1] = 0

6. **$u_2(\xi,t) = 0$:** $\Phi(a/a_2)=\Phi(a/a_2) \Rightarrow u_2 = 0$. ✓
7. **Continuity $u_1(\xi,t)=u_2(\xi,t)$:** Both equal $0$. ✓
8. **Stefan condition:** Satisfied by construction of $a$ (Step 4). ✓
