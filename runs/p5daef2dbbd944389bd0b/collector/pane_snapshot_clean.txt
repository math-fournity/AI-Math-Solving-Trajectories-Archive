## Solution

**Key observation:** $\tau(k)$ is odd if and only if $k$ is a perfect square. Th
erefore $S(n) = \sum_{k=1}^{n}\tau(k)$ is odd if and only if the number of perfe
ct squares in $\{1,2,\dots,n\}$ is odd, i.e., $\lfloor\sqrt{n}\rfloor$ is odd.

So:
- $a = \#\{n\le 2005 : \lfloor\sqrt{n}\rfloor \text{ is odd}\}$
- $b = \#\{n\le 2005 : \lfloor\sqrt{n}\rfloor \text{ is even}\}$

**Block structure.** Since $\sqrt{2005}\approx 44.7$, we have $\lfloor\sqrt{2005
}\rfloor = 44$. For each $m\ge 1$, the integers $n$ with $\lfloor\sqrt{n}\rfloor
 = m$ are $n \in [m^2, (m+1)^2-1]$, a block of size $2m+1$. The last block ($m=4
4$) is truncated: $n\in[1936, 2005]$, size $2005-1936+1 = 70$.

**Computing $a$ (odd $m$).** Odd $m$ from $1$ to $43$: $m = 2k-1$, $k=1,\dots,22
$, with block size $2m+1 = 4k-1$.
$$a = \sum_{k=1}^{22}(4k-1) = 4\cdot\frac{22\cdot 23}{2} - 22 = 1012 - 22 = 990.
$$

**Computing $b$ (even $m$).** Even $m$ from $2$ to $42$: $m=2k$, $k=1,\dots,21$,
 block size $2m+1 = 4k+1$.
$$\sum_{k=1}^{21}(4k+1) = 4\cdot\frac{21\cdot 22}{2} + 21 = 924 + 21 = 945.$$
Adding the truncated block $m=44$ (even): $b = 945 + 70 = 1015$.

**Check:** $a + b = 990 + 1015 = 2005$. ✓

**Result:**
$$|a - b| = |990 - 1015| = \boxed{25}.$$
