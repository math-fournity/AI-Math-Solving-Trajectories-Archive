We seek all integers $t$ with $\dfrac{t^3-t^2}{3t+10}\in\mathbb{Z}$, i.e. $(3t+1
0)\mid t^2(t-1)$.

**Step 1: Reduce to a divisibility condition on $d=3t+10$.**

Set $d=3t+10$, so $t=(d-10)/3$ (integer iff $d\equiv 1\pmod 3$), and $d\neq 0$.

Compute $27\,t^2(t-1)=(3t)^2(3t-3)=(d-10)^2(d-13)$. Modulo $d$:
$$(d-10)^2(d-13)\equiv (-10)^2(-13)=-1300\pmod d.$$
So $27\,t^2(t-1)\equiv -1300\pmod d$.

**Step 2: Necessary condition.** If $d\mid t^2(t-1)$, then $d\mid 27\,t^2(t-1)$,
 hence $d\mid 1300$.

ivisor $d$ of $1300$ satisfies $\gcd(d,27)=1$. Thus $d\mid 27\,t^2(t-1)$ implies
 $d\mid t^2(t-1)$. So the condition is exactly:
$$d\mid 1300,\quad d\equiv 1\pmod 3,\quad d\neq 0.$$
