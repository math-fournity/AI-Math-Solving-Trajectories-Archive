## 解答

**在 (1,1) 处的平滑性。** 定义多项式为 $F(z,w) = z^3 + w^3 - 2$。在 $(1,1)$ 处，
梯度为 $(3z^2, 3w^2) = (3,3) \neq 0$。由于 $\partial F/\partial w = 3w^2 = 3 \ne
q 0$，隐函数定理允许我们在 $u=0$ 附近将 $w$ 表示为 $z$ 的全纯函数。因此 $u = z -
 1$ 是一个有效的局部坐标，且 $w = 1 + v(u)$，其中 $v(0)=0$。

**参数化。** 令 $z = 1+u$，$w = 1+v$。代入 $z^3+w^3=2$：

$$
(1+u)^3 + (1+v)^3 = 2 \implies 3(u+v) + 3(u^2+v^2) + (u^3+v^3) = 0.
$$

将 $v = a_1 u + a_2 u^2 + a_3 u^3 + \cdots$ 代入，并合并 $u$ 的幂次：

- **$u^1$:** $3(1+a_1)=0 \implies a_1 = -1$.
- **$u^2$:** $3a_2 + 3 + 3a_1^2 = 0 \implies 3a_2 + 6 = 0 \implies a_2 = -2$.
- **$u^3$:** $3a_3 + 6a_1 a_2 + 1 + a_1^3 = 0 \implies 3a_3 + 12 + 0 = 0 \implie
s a_3 = -4$.

因此
$$
v(u) = -u - 2u^2 - 4u^3 + \cdots
$$

**计算 $f = zw - 1$。**
$$
zw - 1 = (1+u)(1+v) - 1 = u + v + uv.
$$

各项为：
$$
u + v = u + (-u - 2u^2 - 4u^3 + \cdots) = -2u^2 - 4u^3 + \cdots,
$$
$$
uv = u(-u - 2u^2 - 4u^3 + \cdots) = -u^2 - 2u^3 + \cdots.
$$

求和：
$$
f = (u+v) + uv = (-2u^2 - 4u^3 + \cdots) + (-u^2 - 2u^3 + \cdots) = -3u^2 - 6u^3
 + \cdots
$$

最低次项为 $-3u^2$，系数 $-3 \neq 0$。由于 $u$ 是点 $(1,1)$ 处的局部坐标，$f$ 在
该点的零点阶数为 $\boxed{2}$。
