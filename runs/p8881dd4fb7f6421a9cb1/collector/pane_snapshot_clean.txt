## Proof

Let $a > 1$ be given. Set $r = 2^{-a} \in (0,\tfrac{1}{2})$ and define constants
$$D = \frac{1-r}{2(1-2r)}, \qquad c_k = D\, r^k \quad (k \ge 0).$$

For each nonnegative integer $n$, let $b_k(n)\in\{0,1\}$ denote the $k$-th binar
y digit of $n$ (so $n=\sum_{k\ge0} b_k(n)\,2^k$), and define
$$s_k(n)=\Bigl(\sum_{j=0}^{k} b_j(n)\Bigr)\bmod 2.$$

Now define the sequence
$$\boxed{x_n = \sum_{k=0}^{\infty} (-1)^{s_k(n)}\, c_k.}$$

---

### Boundedness

Since each summand has absolute value $c_k$ and $\sum c_k = D/(1-r)$,
$$|x_n| \le \sum_{k=0}^{\infty} c_k = \frac{D}{1-r} = \frac{1}{2(1-2r)} =: C < \
infty.$$
The series converges absolutely (geometric with ratio $r<1$), so $x_n$ is well-d
efined and $|x_n|\le C$ for every $n$.

---

### Spreading condition

Let $i\neq j$ be nonnegative integers. Let $m$ be the position of the **least si
gnificant** binary digit at which $i$ and $j$ differ:
$$m = \min\{\,k : b_k(i)\neq b_k(j)\,\}.$$

**Key observations:**

1. **Lower bits agree:** $b_k(i)=b_k(j)$ for all $k<m$, hence $s_k(i)=s_k(j)$ fo
r $k<m$.

2. **Bit $m$ flips:** $b_m(i)\neq b_m(j)$ while $b_0,\dots,b_{m-1}$ agree, so $s
_m(i)\neq s_m(j)$.

3. **Index gap:** $|i-j|$ has bit $m$ set, so $|i-j|\ge 2^m$, giving $|i-j|^a \g
e (2^m)^a = r^{-m}$.

From observation (1), the terms for $k<m$ cancel in $x_i - x_j$, so
$$x_i - x_j = \sum_{k=m}^{\infty}\bigl[(-1)^{s_k(i)}-(-1)^{s_k(j)}\bigr]\,c_k.$$

The $k=m$ term contributes $\pm 2c_m$ (since $s_m(i)\neq s_m(j)$). Each subseque
nt term ($k>m$) contributes $0$ or $\pm 2c_k$. Therefore
$$|x_i - x_j| \;\ge\; 2c_m - 2\sum_{k=m+1}^{\infty} c_k \;=\; 2\!\left(c_m - \su
m_{k>m} c_k\right).$$

**Evaluating the tail:**
$$\sum_{k>m} c_k = D\sum_{k=m+1}^{\infty} r^k = \frac{D\,r^{m+1}}{1-r},$$
so
$$c_m - \sum_{k>m} c_k = D\,r^m - \frac{D\,r^{m+1}}{1-r} = D\,r^m\cdot\frac{1-2r
}{1-r}.$$

Hence
$$|x_i - x_j| \;\ge\; \frac{2D(1-2r)}{1-r}\;r^m.$$

**Combining with the index gap** (observation 3):
$$|x_i - x_j|\cdot|i-j|^a \;\ge\; \frac{2D(1-2r)}{1-r}\;r^m \cdot r^{-m} \;=\; \
frac{2D(1-2r)}{1-r}.$$

Substituting $D = \frac{1-r}{2(1-2r)}$:
$$|x_i - x_j|\cdot|i-j|^a \;\ge\; \frac{2\cdot\frac{1-r}{2(1-2r)}\cdot(1-2r)}{1-
r} \;=\; 1.$$

This holds for **every** pair of distinct nonnegative integers $i,j$. $\blacksqu
are$

---

**Remark.** The bound is $C = \frac{1}{2(1-2^{1-a})}$, which is finite for all $
a>1$ (since $2^{1-a}<1$). The construction uses the binary digits of $n$ to assi
gn signs via the partial digit-sum parity $s_k(n)$, with geometrically decaying
weights $c_k = D\cdot 2^{-ak}$. The least-significant differing bit $m$ controls
 both the minimum index gap ($\ge 2^m$) and the minimum value gap ($\ge 2c_m$ mi
nus tail), and the choice of $D$ makes these balance exactly.
