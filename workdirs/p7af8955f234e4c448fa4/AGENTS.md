# Problem

In a specialized laboratory, a cubic data-storage module is being prepared for a high-security network. The module has six identical square ports, one on each of its faces. To designate specific access protocols, an engineer must install green fiber-optic sensors into these ports.

The engineer is required to install a sensor into at least one port, but can choose to install them in as many as all six. Because the cubic module is suspended in a zero-gravity chamber and can be freely rotated into any orientation, two configurations are considered identical if one can be transformed into the other simply by rotating the cube.

How many distinct ways are there for the engineer to install the green sensors?
