## Solution

Let $n = 2015 = 5\cdot 13\cdot 31$ (odd, squarefree). We evaluate
$$P = \prod_{a=1}^{n}\prod_{b=1}^{n}\left(1+e^{2\pi iab/n}\right),\qquad \text{t
hen compute } \log_2 P.$$

**Inner product for fixed $a$.** Set $d=\gcd(a,n)$ and write $a=d\alpha$, $n=d\m
u$ with $\gcd(\alpha,\mu)=1$. Then
$$e^{2\pi iab/n}=e^{2\pi i\alpha b/\mu}.$$
As $b$ runs over $1,\dots,n=\mu d$, the exponent $\alpha b\pmod{\mu}$ runs throu
gh all residues mod $\mu$ exactly $d$ times (since $\alpha$ is invertible mod $\
mu$). Hence
$$\prod_{b=1}^{n}\left(1+e^{2\pi iab/n}\right)=\left(\prod_{\zeta^{\mu}=1}(1+\ze
ta)\right)^{d}.$$

**Root-of-unity identity.** From $x^{\mu}-1=\prod_{\zeta^{\mu}=1}(x-\zeta)$, set
ting $x=-1$:
$$\prod_{\zeta^{\mu}=1}(1+\zeta)=1-(-1)^{\mu}.$$
This equals $2$ if $\mu$ is odd, and $0$ if $\mu$ is even.

**Applying to $n=2015$.** Since $n$ is odd, every divisor $\mu=n/d$ is odd, so $
1-(-1)^{\mu}=2$ for every $a$. Therefore
$$\prod_{b=1}^{n}\left(1+e^{2\pi iab/n}\right)=2^{d}=2^{\gcd(a,n)},\qquad\text{a
nd}\qquad P=2^{\sum_{a=1}^{n}\gcd(a,n)}.$$
Thus $\log_2 P = \sum_{a=1}^{2015}\gcd(a,2015)$.

**Evaluating the GCD sum.** Using $\sum_{a=1}^{n}\gcd(a,n)=\sum_{d\mid n}d\,\var
phi(n/d)$, which is multiplicative. For a prime $p$ (exponent $1$):
$$\sum_{d\mid p}d\,\varphi(p/d)=\varphi(p)+p\,\varphi(1)=(p-1)+p=2p-1.$$
By multiplicativity,
$$\sum_{a=1}^{2015}\gcd(a,2015)=\prod_{p\in\{5,13,31\}}(2p-1)=(9)(25)(61).$$
$$9\cdot 25=225,\qquad 225\cdot 61=225\cdot 60+225=13500+225=13725.$$

**Verification via divisor expansion** ($\sum_{d\mid n}d\,\varphi(n/d)$ over $d\
in\{1,5,13,31,65,155,403,2015\}$):
$$1440+1800+1560+1488+1950+1860+1612+2015=13725.\;\checkmark$$
