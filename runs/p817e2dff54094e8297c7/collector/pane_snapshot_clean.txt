### Setting up the path-sum structure

Kevin's path visits a sequence of cells. If the path visits row $i$ a total of $
r_i$ times and column $j$ a total of $c_j$ times, then the sum of values on the
path is

$$\sum_{\text{cells}} (a_i + b_j) = \sum_{i=1}^{100} r_i\, a_i + \sum_{j=1}^{200
} c_j\, b_j.$$

Since each step changes the row by at most 1 and the column by at most 1, any pa
th from $(1,1)$ to $(100,200)$ must pass through **every** row $1,\dots,100$ and
 **every** column $1,\dots,200$. Therefore $r_i \ge 1$ for all $i$ and $c_j \ge
1$ for all $j$. If the path has $N$ cells, then $\sum r_i = \sum c_j = N$, and $
N \ge \max(100,200) = 200$.

### Lower bound for any path

Since $r_i \ge 1$ and $\sum r_i = N$:

$$\sum r_i\, a_i = \sum a_i + \sum (r_i - 1)\,a_i \ge \sum a_i + (N-100)\min_i a
_i.$$

Likewise $\sum c_j\, b_j \ge \sum b_j + (N-200)\min_j b_j$. Hence for any path:

$$\text{sum} \ge \sum a_i + \sum b_j + (N-100)\min a + (N-200)\min b.$$

### The optimal path is monotone with $N=200$

A monotone path (only right, down, or down-right moves) from $(1,1)$ to $(100,20
0)$ uses exactly 199 moves: 99 diagonal + 100 horizontal, giving $N=200$ cells,
each column visited exactly once ($c_j=1$), and $\sum r_i = 200$ with $r_i\ge 1$
.

For $N=200$: the bound gives $\sum a_i + \sum b_j + 100\min a + 0$.

For $N>200$ (any non-monotone path): the bound gives $\sum a_i + \sum b_j + 100\
min a + (N-200)(\min a + \min b)$, which is **strictly larger** since $\min a +
\min b \ge 2 > 0$.

So the minimum is achieved by a monotone path with $N=200$. Among such paths, $c
_j=1$ for all $j$ (column contribution $= \sum b_j$, fixed), and we minimize $\s
um r_i a_i$ subject to $r_i \ge 1$, $\sum r_i = 200$. The minimum puts all 100 u
nits of extra weight on the row with smallest $a_i$:

$$M = \sum_{i=1}^{100} a_i + \sum_{j=1}^{200} b_j + 100\min_i a_i.$$

### Computing the expectation

The $a_i$ (resp. $b_j$) are chosen uniformly as distinct values from $\{1,\dots,
2016\}$. By symmetry each has marginal mean $\frac{1+2016}{2} = \frac{2017}{2}$.

$$E\!\left[\sum a_i\right] = 100\cdot\frac{2017}{2} = 100850, \qquad E\!\left[\s
um b_j\right] = 200\cdot\frac{2017}{2} = 201700.$$

For the minimum of $k$ distinct values chosen from $\{1,\dots,n\}$, the classica
l identity gives

$$E[\min] = \frac{n+1}{k+1}.$$

(Proof: $E[\min]=\sum_{m\ge 1}\Pr(\min\ge m)=\frac{1}{\binom{n}{k}}\sum_{t=k}^{n
}\binom{t}{k}=\frac{\binom{n+1}{k+1}}{\binom{n}{k}}=\frac{n+1}{k+1}$, using the
hockey-stick identity.)

With $n=2016$, $k=100$: $E[\min a] = \frac{2017}{101}$.

### Final computation

$$E[M] = 100850 + 201700 + 100\cdot\frac{2017}{101} = 302550 + \frac{201700}{101
} = \frac{302550\cdot 101 + 201700}{101} = \frac{30557550 + 201700}{101} = \frac
{30759250}{101}.$$

Check coprimality: $101$ is prime and $30759250 = 101\times 304547 + 3$, so $\gc
d(30759250,101)=1$.

Thus $p = 30759250$, $q = 101$, and

$$p + q = 30759250 + 101 = \boxed{30759351}.$$
