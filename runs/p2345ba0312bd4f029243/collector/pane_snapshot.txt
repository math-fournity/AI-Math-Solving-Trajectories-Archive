## Solution

We seek a closed form for $\displaystyle S(z) = \sum_{k=0}^{\infty} \frac{z^k}{(
k!)^2}$.

**Recall the modified Bessel function of the first kind of order $n$:**

$$I_n(x) = \sum_{k=0}^{\infty} \frac{1}{k!\,\Gamma(k+n+1)}\left(\frac{x}{2}\righ
t)^{2k+n}.$$

For $n=0$, using $\Gamma(k+1)=k!$:

$$I_0(x) = \sum_{k=0}^{\infty} \frac{1}{(k!)^2}\left(\frac{x}{2}\right)^{2k}.$$

**Substitution.** Set $x = 2\sqrt{z}$ (for $z$ in a domain where $\sqrt{z}$ is d
efined; the result extends by analytic continuation). Then

$$\left(\frac{x}{2}\right)^{2k} = \left(\frac{2\sqrt{z}}{2}\right)^{2k} = \left(
\sqrt{z}\right)^{2k} = z^k.$$

Substituting into the series for $I_0$:

$$I_0(2\sqrt{z}) = \sum_{k=0}^{\infty} \frac{z^k}{(k!)^2} = S(z).$$

**Verification of convergence.** The ratio test gives

$$\left|\frac{a_{k+1}}{a_k}\right| = \left|\frac{z^{k+1}/((k+1)!)^2}{z^k/(k!)^2}
\right| = \frac{|z|}{(k+1)^2} \to 0 \quad\text{as } k\to\infty,$$

so the series converges for all $z \in \mathbb{C}$ (entire function), matching t
he known fact that $I_0$ is entire and $2\sqrt{z}$ composed with $I_0$ gives an
entire function of $z$ (the branch cut of $\sqrt{z}$ is harmless since $I_0$ is
an even function: $I_0(-w)=I_0(w)$, so $I_0(2\sqrt{z})$ depends only on $z$, not
 on the choice of branch).

**Sanity check at $z=0$:** $S(0) = 1$ and $I_0(0) = 1$. ✓

**Sanity check at small $z$:** $S(z) = 1 + z + \frac{z^2}{4} + \cdots$, and $I_0
(2\sqrt{z}) = 1 + \frac{(2\sqrt{z})^2}{4} + \cdots = 1 + z + \frac{z^2}{4} + \cd
ots$. ✓

### Closed-form expression

$$\boxed{\displaystyle \sum_{k=0}^{\infty} \frac{z^k}{(k!)^2} = I_0\!\left(2\sqr
t{z}\right)}$$

where $I_0$ is the **modified Bessel function of the first kind of order zero**,
 defined by $I_0(x)=\sum_{k=0}^{\infty}\frac{(x/2)^{2k}}{(k!)^2}$. The function
$I_0(2\sqrt{z})$ is entire in $z$.
