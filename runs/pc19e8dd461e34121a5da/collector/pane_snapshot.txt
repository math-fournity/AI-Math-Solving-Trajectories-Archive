# Solution

## Setup

Let $\alpha = 1 + \sqrt{2}$ and $\beta = 1 - \sqrt{2}$. Note:
- $\alpha\beta = (1+\sqrt{2})(1-\sqrt{2}) = 1 - 2 = -1$
- $\alpha + \beta = 2$, so $\alpha, \beta$ are roots of $x^2 - 2x - 1 = 0$.

Define $a_n = \alpha^n + \beta^n$. Then $a_n$ satisfies the integer recurrence:
$$a_n = 2a_{n-1} + a_{n-2}, \quad a_0 = 2,\ a_1 = 2$$

So every $a_n$ is a **positive integer**.

## Key decomposition

Since $|\beta| = |1-\sqrt{2}| = \sqrt{2}-1 \approx 0.4142 < 1$, we have $|\beta|
^n \to 0$.

For $n = 3000$ (even), $\beta^{3000} = (\sqrt{2}-1)^{3000} > 0$. Denote $\vareps
ilon = (\sqrt{2}-1)^{3000}$.

Then:
$$\alpha^{3000} = a_{3000} - \varepsilon$$

where $a_{3000}$ is a positive integer and $\varepsilon$ is a small positive rea
l number.

## Estimating $\varepsilon$

Compute $\log_{10}(\sqrt{2}-1)$. Using $\sqrt{2}-1 = \frac{1}{\sqrt{2}+1}$:

$$\log_{10}(\sqrt{2}-1) = -\log_{10}(1+\sqrt{2}) = -\frac{\ln(1+\sqrt{2})}{\ln 1
0} = -\frac{\operatorname{arcsinh}(1)}{\ln 10} = -\frac{0.881374\ldots}{2.302585
\ldots} = -0.382775\ldots$$

Therefore:
$$\log_{10}(\varepsilon) = 3000 \times (-0.382775\ldots) = -1148.326\ldots$$

So $\varepsilon = 10^{-1148.326\ldots} = 10^{-1149} \times 10^{0.674\ldots} \app
rox 4.72 \times 10^{-1149}$.

This means $\varepsilon$ has **1148 leading zeros** after the decimal point:
$$\varepsilon = 0.\underbrace{00\ldots0}_{1148}472\ldots$$

## Decimal representation of $\alpha^{3000}$

Since $0 < \varepsilon < 1$:
$$\alpha^{3000} = a_{3000} - \varepsilon = (a_{3000}-1) + (1 - \varepsilon)$$

The integer part is $a_{3000}-1$ and the fractional part is $1-\varepsilon$.

Now:
$$1 - \varepsilon = 1 - 0.\underbrace{00\ldots0}_{1148}472\ldots = 0.\underbrace
{99\ldots9}_{1148}527\ldots$$

The first 1148 digits after the decimal point are all **9**.

## Conclusion

Since $100 \leq 1148$, the 100th digit to the right of the decimal point in the
decimal representation of $(1+\sqrt{2})^{3000}$ is:

$$\boxed{9}$$
