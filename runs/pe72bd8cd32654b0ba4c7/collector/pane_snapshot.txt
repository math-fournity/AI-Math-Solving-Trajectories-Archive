# Derivation of Stirling's Formula

## 1. Setup: Logarithm of the Gamma Function

We work with $\log \Gamma(x)$ for $x > 0$. Since $n! = \Gamma(n+1)$, an asymptot
ic formula for $\Gamma$ yields one for $n!$.

Recall the integral representation:
$$\Gamma(x) = \int_0^\infty t^{x-1} e^{-t}\, dt.$$

A more convenient starting point is the **Euler–Maclaurin formula**, which for a
 smooth function $f$ on $[1, n]$ states:

$$\sum_{k=1}^{n} f(k) = \int_1^n f(t)\,dt + \frac{f(n)+f(1)}{2} + \sum_{j=1}^{m}
 \frac{B_{2j}}{(2j)!}\!\left(f^{(2j-1)}(n) - f^{(2j-1)}(1)\right) + R_m,$$

where $B_{2j}$ are Bernoulli numbers and $R_m$ is a remainder that is $O$ of the
 next term.

## 2. Applying Euler–Maclaurin to $f(t) = \log t$

Set $f(t) = \log t$. Then $\sum_{k=1}^n \log k = \log(n!)$, and:

- $\int_1^n \log t\, dt = n\log n - n + 1$,
- $f'(t) = 1/t$, $f^{(2j-1)}(t) = \dfrac{(-1)^{j}(2j-2)!}{t^{2j-1}}$ for $j \ge
1$.

Substituting:

$$\log(n!) = n\log n - n + 1 + \frac{\log n}{2} + \frac{1}{2}\cdot\frac{1}{2}\cd
ot\frac{1}{n}\cdot(\text{correction}) + \sum_{j=1}^{m} \frac{B_{2j}}{(2j)!}\cdot
\frac{(-1)^{j+1}(2j-2)!}{n^{2j-1}} + \cdots$$

More carefully, the boundary term at $t=1$ contributes a constant, and the bound
ary terms at $t=n$ give the asymptotic series in descending powers of $n$. Colle
cting:

$$\log(n!) = \left(n + \tfrac{1}{2}\right)\log n - n + C + \frac{1}{12n} - \frac
{1}{360 n^3} + \cdots$$

where $C$ is a **constant** (independent of $n$) collecting all the lower-limit
contributions from Euler–Maclaurin. The key task is to **determine** $C$.

## 3. Identifying the Constant via the Gamma Function

Define the **remainder** more precisely. Consider

$$\log \Gamma(x) = \left(x - \tfrac{1}{2}\right)\log x - x + \frac{1}{2}\log(2\p
i) + \sum_{j=1}^{m} \frac{B_{2j}}{2j(2j-1)\, x^{2j-1}} + \cdots$$

This is the standard Stirling series for $\log\Gamma$. Comparing with the Euler–
Maclaurin result for $\log(n!) = \log\Gamma(n+1)$, one finds the constant $C$ mu
st equal $\tfrac{1}{2}\log(2\pi)$. We now **derive** this value of $C$ using **W
allis' formula**, rather than assuming it.

## 4. Determining $C = \tfrac{1}{2}\log(2\pi)$ via Wallis' Formula

**Wallis' formula** states:
$$\prod_{k=1}^{\infty} \frac{(2k)^2}{(2k-1)(2k+1)} = \frac{\pi}{2}, \qquad\text{
i.e.,}\quad \lim_{n\to\infty} \frac{2^{4n}(n!)^4}{((2n)!)^2(2n+1)} = \frac{\pi}{
2}.$$

Equivalently, taking the asymptotic form:
$$\frac{\pi}{2} = \lim_{n\to\infty} \frac{2^{4n}(n!)^4}{((2n)!)^2\,(2n+1)}.$$

Now insert the **partial** Stirling approximation (with unknown constant $C$):
$$\log(n!) = \left(n + \tfrac{1}{2}\right)\log n - n + C + o(1).$$

Exponentiating: $n! \sim e^{C}\, n^{n+1/2}\, e^{-n}$.

Compute the Wallis ratio asymptotically. Let $a_n = e^{C} n^{n+1/2} e^{-n}$, so
$n! \sim a_n$.

**Numerator:** $2^{4n}(n!)^4 \sim 2^{4n}\, e^{4C}\, n^{4n+2}\, e^{-4n}$.

**Denominator:** $((2n)!)^2(2n+1) \sim \left(e^{C}(2n)^{2n+1/2}e^{-2n}\right)^2
\cdot 2n = e^{2C}\, (2n)^{4n+1}\, e^{-4n}\cdot 2n = e^{2C}\, 2^{4n+1}\, n^{4n+1}
\cdot n \cdot e^{-4n}\cdot 2$.

Wait — let me redo this cleanly. $(2n)! \sim e^C (2n)^{2n+1/2} e^{-2n}$, so $((2
n)!)^2 \sim e^{2C}(2n)^{4n+1}e^{-4n} = e^{2C}\, 2^{4n+1}\, n^{4n+1}\, e^{-4n}$.
Multiplying by $(2n+1)\sim 2n$:

$$((2n)!)^2(2n+1) \sim e^{2C}\, 2^{4n+2}\, n^{4n+2}\, e^{-4n}.$$

**Numerator:** $2^{4n}(n!)^4 \sim 2^{4n}\, e^{4C}\, n^{4n+2}\, e^{-4n}$.

**Ratio:**
$$\frac{2^{4n}\, e^{4C}\, n^{4n+2}\, e^{-4n}}{e^{2C}\, 2^{4n+2}\, n^{4n+2}\, e^{
-4n}} = \frac{e^{4C}}{e^{2C}\cdot 2^{2}} = \frac{e^{2C}}{4}.$$

By Wallis' formula this ratio tends to $\pi/2$, so:

$$\frac{e^{2C}}{4} = \frac{\pi}{2} \implies e^{2C} = 2\pi \implies C = \tfrac{1}
{2}\log(2\pi).$$

This determines the constant.

## 5. Stirling's Formula

Substituting $C = \tfrac{1}{2}\log(2\pi)$ back:

$$\log(n!) = \left(n + \tfrac{1}{2}\right)\log n - n + \tfrac{1}{2}\log(2\pi) +
\frac{1}{12n} - \frac{1}{360\, n^3} + \cdots$$

Exponentiating the leading terms:

$$\boxed{\,n! \sim \sqrt{2\pi\, n}\,\left(\frac{n}{e}\right)^{\!n}\,}$$

as $n \to \infty$, with the full asymptotic expansion

$$n! \sim \sqrt{2\pi n}\left(\frac{n}{e}\right)^n \exp\!\left(\sum_{j=1}^{\infty
} \frac{B_{2j}}{2j(2j-1)\, n^{2j-1}}\right).$$

## 6. Summary of the Logic

1. **Euler–Maclaurin** applied to $f(t)=\log t$ on $[1,n]$ yields $\log(n!) = (n
+\tfrac12)\log n - n + C + (\text{asymptotic series in }1/n)$, with $C$ an undet
ermined constant arising from the lower limit of integration.

2. The **Gamma function** $\Gamma(x+1)=x!$ extends the factorial and inherits th
e same asymptotic structure, so the same constant $C$ appears in $\log\Gamma(x)$
.

3. **Wallis' formula** $\prod_{k\ge1}\frac{(2k)^2}{(2k-1)(2k+1)}=\frac{\pi}{2}$,
 combined with the partial approximation $n!\sim e^C n^{n+1/2}e^{-n}$, forces $e
^{2C}=2\pi$, i.e. $C=\tfrac12\log(2\pi)$.

4. Exponentiating gives **Stirling's formula**: $n! \sim \sqrt{2\pi n}\,(n/e)^n$
.
