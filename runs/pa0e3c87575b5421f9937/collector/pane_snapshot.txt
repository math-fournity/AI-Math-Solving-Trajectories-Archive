## Proof

**Setup.** The space $H^1(\mathbb{T}^N)$ is a Hilbert space with inner product
$$\langle u, v \rangle_{H^1} = \int_{\mathbb{T}^N} u\,v\,dx + \int_{\mathbb{T}^N
} \nabla u \cdot \nabla v\,dx.$$
Let $V \subseteq H^1(\mathbb{T}^N)$ be a closed subset (in the norm topology of
$H^1$). The orthogonal complement of $V$ is
$$V^\perp = \{\, u \in H^1(\mathbb{T}^N) : \langle u, v \rangle_{H^1} = 0 \text{
 for all } v \in V \,\}.$$

**Key observation: $V^\perp$ is always a closed subspace.**

For each fixed $v \in V$, the map $L_v : H^1(\mathbb{T}^N) \to \mathbb{R}$ defin
ed by $L_v(u) = \langle u, v \rangle_{H^1}$ is a continuous linear functional (b
y Cauchy–Schwarz, $|L_v(u)| \leq \|u\|_{H^1}\|v\|_{H^1}$). Its kernel $\ker L_v
= \{u : \langle u, v\rangle = 0\}$ is a closed hyperplane. Therefore
$$V^\perp = \bigcap_{v \in V} \ker L_v$$
is an intersection of closed sets, hence closed. It is also clearly a subspace (
if $u_1, u_2 \in V^\perp$ and $\alpha, \beta \in \mathbb{R}$, then $\langle \alp
ha u_1 + \beta u_2, v\rangle = \alpha\langle u_1,v\rangle + \beta\langle u_2,v\r
angle = 0$ for all $v \in V$).

**Density of a closed subspace forces it to be the whole space.**

Since $V^\perp$ is a closed subspace of $H^1(\mathbb{T}^N)$, if $V^\perp$ were d
ense in $H^1(\mathbb{T}^N)$, then we would have $\overline{V^\perp} = H^1(\mathb
b{T}^N)$. But $V^\perp$ is already closed, so $\overline{V^\perp} = V^\perp$, gi
ving $V^\perp = H^1(\mathbb{T}^N)$.

**When does $V^\perp = H^1(\mathbb{T}^N)$ hold?**

$V^\perp = H^1(\mathbb{T}^N)$ means $\langle u, v \rangle_{H^1} = 0$ for **all**
 $u \in H^1(\mathbb{T}^N)$ and all $v \in V$. Taking $u = v$ for any $v \in V$ g
ives $\|v\|_{H^1}^2 = 0$, hence $v = 0$. So $V^\perp = H^1(\mathbb{T}^N)$ if and
 only if $V \subseteq \{0\}$.

**Conclusion.**

For any closed subset $V$ of $H^1(\mathbb{T}^N)$, the orthogonal complement $V^\
perp$ is a **closed** subspace. A closed subspace is dense if and only if it equ
als the entire space. This happens if and only if $V = \{0\}$ (or $V = \emptyset
$).

Therefore, **the orthogonal complement of a closed subset $V$ in $H^1(\mathbb{T}
^N)$ is dense in $H^1(\mathbb{T}^N)$ if and only if $V$ is trivial (i.e., $V \su
bseteq \{0\}$).** In general, for any nontrivial closed subset $V$, the answer i
s **no**, $V^\perp$ is not dense.

The essential reason is that the orthogonal complement of *any* set in a Hilbert
