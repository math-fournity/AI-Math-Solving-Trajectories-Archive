## Solution

We solve $u_t = k u_{xx}$ on $0 < x < L$, $t > 0$, with
- $u(0,t) = 0$ (Dirichlet),
- $u_x(L,t) = -h\,u(L,t)$ (Robin),
- $u(x,0) = f(x)$.

### Separation of variables

Set $u(x,t) = X(x)T(t)$. Then $XT' = kX''T$, giving
$$\frac{T'}{kT} = \frac{X''}{X} = -\lambda, \qquad T(t) = e^{-\lambda k t},$$
and the spatial eigenvalue problem
$$X'' + \lambda X = 0,\qquad X(0) = 0,\qquad X'(L) = -h\,X(L). \tag{SL}$$

This is a regular Sturm–Liouville problem, so eigenfunctions corresponding to di
stinct eigenvalues are orthogonal on $[0,L]$ with weight $1$.

### Analysis of the spectrum

**Positive eigenvalues** $\lambda = \alpha^2 > 0$. Then $X = A\cos\alpha x + B\s
in\alpha x$. From $X(0)=0$: $A=0$, so $X = B\sin\alpha x$. The Robin condition g

$$\alpha\cos(\alpha L) + h\sin(\alpha L) = 0.$$
Setting $\beta = \alpha L$ and dividing by $\cos\beta$ (the case $\cos\beta=0$ i

$$\boxed{\;\tan\beta = -\frac{\beta}{hL}\;} \tag{E}$$
Each positive root $\beta_n$ ($n=1,2,\dots$) yields an eigenvalue $\lambda_n = (
\beta_n/L)^2$ with eigenfunction $\phi_n(x) = \sin(\beta_n x/L)$.

**Zero eigenvalue** $\lambda = 0$. Then $X''=0$, $X = Ax+B$, $X(0)=0 \Rightarrow
 B=0$, $X = Ax$. The Robin condition: $X'(L) = A = -hX(L) = -h(AL)$, i.e. $1 = -
hL$. Hence
$$\lambda = 0 \text{ is an eigenvalue } \iff hL = -1, \quad\text{with eigenfunct

**Negative eigenvalues** $\lambda = -\mu^2 < 0$. Then $X = B\sinh\mu x$ (after $

$$\gamma\coth\gamma = -hL.$$
Since $g(\gamma) = \gamma\coth\gamma$ satisfies $g(\gamma) > 1$ for all $\gamma
> 0$ (with $g\to 1^+$ as $\gamma\to 0^+$ and $g\to\infty$), a negative eigenvalu

**Conclusion on the spectrum:**
- If $hL > -1$: no zero and no negative eigenvalue; the spectrum is $\{(\beta_n/

- If $hL = -1$: $\lambda_0 = 0$ is an eigenvalue (eigenfunction $x$), no negativ

This is precisely the dichotomy in parts (a) and (b).
