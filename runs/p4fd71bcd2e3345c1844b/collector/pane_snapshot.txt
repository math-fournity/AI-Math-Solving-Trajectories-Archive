## Solution

**Reformulating the integral.** Observe that
$$\frac{e^x - 1}{e^x + 1} = \tanh\!\left(\frac{x}{2}\right).$$

**Computing the antiderivative.**
$$\int \tanh\!\left(\frac{x}{2}\right) dx = 2\ln\cosh\!\left(\frac{x}{2}\right)
+ C.$$

Applying the limits $0$ to $a_n$ (and using $\cosh(0)=1$):
$$\int_{0}^{a_n} \frac{e^x-1}{e^x+1}\,dx = 2\ln\cosh\!\left(\frac{a_n}{2}\right)
 = \ln n.$$

**Solving for $a_n$.** Dividing by 2 and exponentiating:
$$\cosh\!\left(\frac{a_n}{2}\right) = \sqrt{n}.$$

Using $\operatorname{arccosh}(y) = \ln\!\left(y + \sqrt{y^2-1}\right)$ with $y=\
sqrt{n}$:
$$\frac{a_n}{2} = \ln\!\left(\sqrt{n} + \sqrt{n-1}\right), \qquad a_n = 2\ln\!\l
eft(\sqrt{n}+\sqrt{n-1}\right).$$

**Evaluating the limit.**
$$a_n - \ln n = 2\ln\!\left(\sqrt{n}+\sqrt{n-1}\right) - 2\ln\sqrt{n} = 2\ln\!\l
eft(\frac{\sqrt{n}+\sqrt{n-1}}{\sqrt{n}}\right) = 2\ln\!\left(1+\sqrt{1-\tfrac{1
}{n}}\right).$$

As $n\to\infty$, $\sqrt{1-\tfrac{1}{n}}\to 1$, so by continuity of $\ln$:
$$\lim_{n\to\infty}(a_n - \ln n) = 2\ln(1+1) = 2\ln 2 = \ln 4.$$
