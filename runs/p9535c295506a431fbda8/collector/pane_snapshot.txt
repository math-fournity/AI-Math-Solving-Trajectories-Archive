**Problem.** Find all functions $f : \mathbb{N}^+ \to \mathbb{N}^+$ such that $m
^2 + f(n) \mid m\,f(m) + n$ for all $m, n \in \mathbb{N}^+$.

**Answer.** The unique solution is $f(n) = n$.

---

**Proof.**

**Step 1: Two key specializations.**

Let $c = f(1)$.

*Setting $m = 1$:* $1 + f(n) \mid f(1) + n = c + n$ for all $n$. In particular $
f(n) \le c + n - 1$. \hfill (1)

*Setting $n = 1$:* $m^2 + c \mid m\,f(m) + 1$ for all $m$. Write $m\,f(m) + 1 =
p_m\,(m^2 + c)$ with $p_m \ge 1$. Then
$$f(m) = \frac{p_m(m^2+c)-1}{m} = p_m\,m + \frac{p_m\,c - 1}{m}.$$
Since $f(m) \in \mathbb{N}^+$, we need $m \mid p_m\,c - 1$, i.e. $p_m\,c \equiv
1 \pmod{m}$. \hfill (2)

**Step 2: Prove $c = 1$.**

Condition (2) says $\gcd(c, m) = 1$ for **every** $m \in \mathbb{N}^+$ (since $p
_m\,c \equiv 1 \pmod m$ is solvable only when $\gcd(c,m)\mid 1$).

Suppose $c > 1$. Take $m = c$: then $\gcd(c, c) = c > 1$, contradicting (2). Hen
ce $c = 1$, i.e. $\boxed{f(1)=1}$.

**Step 3: Pin down $f$.**

With $c = 1$, condition (2) becomes $p_m \equiv 1 \pmod{m}$, so $p_m = 1 + m\,t_
m$ for some integer $t_m \ge 0$. Substituting:
$$f(m) = \frac{(1+m\,t_m)(m^2+1)-1}{m} = \frac{m^2 + m\,t_m(m^2+1)}{m} = m + t_m
\,(m^2+1). \hfill (3)$$

Meanwhile, (1) with $c=1$ gives $f(n) \le n$ for all $n$. Applying this at $n =
m$ to (3):
$$m + t_m\,(m^2+1) \le m \implies t_m\,(m^2+1) \le 0 \implies t_m = 0.$$

Therefore $f(m) = m$ for every $m \in \mathbb{N}^+$.

**Step 4: Verification.**

For $f(n) = n$: $m^2 + f(n) = m^2 + n = m\,f(m) + n$, so the divisibility $m^2+n
 \mid m^2+n$ holds trivially. $\checkmark$

Thus the unique function is $f(n) = n$. $\blacksquare$
