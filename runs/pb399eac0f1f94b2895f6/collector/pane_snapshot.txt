## Proof

**Real projective space** $\mathbb{P}^n$ is the quotient of $\mathbb{R}^{n+1}\se
tminus\{0\}$ by the equivalence relation $x \sim \lambda x$ for all $\lambda \in
 \mathbb{R}\setminus\{0\}$. We write $[x_0:x_1:\cdots:x_n]$ for the equivalence
class of $(x_0,\ldots,x_n)$, equipped with the quotient topology.

**The affine charts.** For each $i \in \{0,1,\ldots,n\}$, define
$$U_i = \{[x_0:x_1:\cdots:x_n] \in \mathbb{P}^n : x_i \neq 0\}.$$

**Claim 1: Each $U_i$ is open.** The set $U_i$ is the image under the quotient m
ap $q:\mathbb{R}^{n+1}\setminus\{0\}\to\mathbb{P}^n$ of the open set $\{x \in \m
athbb{R}^{n+1}\setminus\{0\} : x_i \neq 0\}$, which is saturated with respect to
 the equivalence relation (scaling by a nonzero $\lambda$ preserves the conditio
n $x_i\neq 0$). By definition of the quotient topology, $U_i$ is open.

**Claim 2: $\bigcup_{i=0}^{n} U_i = \mathbb{P}^n$.** Every point $[x_0:\cdots:x_
n]\in\mathbb{P}^n$ is represented by a nonzero vector $(x_0,\ldots,x_n)$, so at
least one coordinate $x_i$ is nonzero. Hence $[x_0:\cdots:x_n]\in U_i$.

**Claim 3: Each $U_i$ is homeomorphic to $\mathbb{R}^n$.** Define
$$\varphi_i : U_i \longrightarrow \mathbb{R}^n, \qquad \varphi_i([x_0:\cdots:x_n
]) = \left(\frac{x_0}{x_i},\ldots,\widehat{\frac{x_i}{x_i}},\ldots,\frac{x_n}{x_
i}\right),$$
where the hat denotes omission of the $i$-th entry (which equals $1$).

*Well-defined:* If we replace $(x_0,\ldots,x_n)$ by $(\lambda x_0,\ldots,\lambda
 x_n)$ with $\lambda\neq 0$, every ratio $x_j/x_i$ is unchanged.

*Continuous:* $\varphi_i$ is induced by the continuous map $(x_0,\ldots,x_n)\map
sto (x_0/x_i,\ldots,\widehat{1},\ldots,x_n/x_i)$ on the saturated open set $\{x_
i\neq 0\}$, so it is continuous by the universal property of the quotient.

*Bijective with continuous inverse:* Define
$$\psi_i : \mathbb{R}^n \longrightarrow U_i, \qquad \psi_i(t_1,\ldots,t_n) = [t_
1:\cdots:t_{i}:\underbrace{1}_{\text{position }i}:t_{i+1}:\cdots:t_n],$$
i.e., the homogeneous coordinates with $1$ inserted in position $i$. Then $\varp
hi_i\circ\psi_i = \mathrm{id}_{\mathbb{R}^n}$ and $\psi_i\circ\varphi_i = \mathr
m{id}_{U_i}$, so $\varphi_i$ is a bijection with inverse $\psi_i$. The map $\psi
_i$ is continuous (it is the composition of the continuous inclusion $\mathbb{R}
^n\hookrightarrow\{x_i=1\}\subset\mathbb{R}^{n+1}\setminus\{0\}$ with the quotie
nt map $q$).

Therefore $\varphi_i$ is a homeomorphism, and $U_i\cong\mathbb{R}^n$.

**Conclusion.** The $n+1$ open sets $U_0, U_1, \ldots, U_n$ cover $\mathbb{P}^n$
, and each is homeomorphic to $\mathbb{R}^n$. $\blacksquare$
