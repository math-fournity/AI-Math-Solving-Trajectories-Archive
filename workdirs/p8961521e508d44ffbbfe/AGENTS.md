# Problem

A high-security data vault uses a system of unique two-digit passcodes. Each passcode is a subset $\{a, b\}$ containing two distinct integers chosen from the server identification set $M = \{1, 2, \dots, 10\}$. 

The vault’s security protocol requires that any two distinct passcodes $\{a, b\}$ and $\{x, y\}$ stored in the active directory $T$ must satisfy a specific "interference" constraint: when the numbers are cross-multiplied and summed, the product of the two possible combinations—specifically $(ax + by)(ay + bx)$—must not be divisible by the prime security constant $11$.

If the directory $T$ is populated with the maximum possible number of these binary subsets such that every pair of subsets in the set obeys this rule, what is the total number of passcodes currently stored in $T$?
