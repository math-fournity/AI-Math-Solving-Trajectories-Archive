**Riemann–Roch analysis.** For a rank $r$, degree $d$ bundle on a genus $g$ curv
e:
$$h^0(E) - h^1(E) = d + r(1-g).$$
With $r=2$, $d = 2g-2$:
$$h^0(E) - h^1(E) = (2g-2) + 2(1-g) = 0,$$
so $h^0(E) = h^1(E)$ for every such bundle. By Serre duality, $h^1(E) = h^0(E^*
\otimes K)$, and $E^* \otimes K$ has rank 2 and degree $-\deg(E) + 2\deg(K) = -(
2g-2) + 2(2g-2) = 2g-2$, the same invariants. The condition $h^0(E)=0$ is thus s
elf-dual.

**Construction for each $g \geq 0$.** I exhibit explicit bundles.

**Case $g = 0$:** $C = \mathbb{P}^1$, degree $= -2$. Every rank 2 bundle splits

\oplus\mathcal{O}(-1)$. Then $h^0(E) = h^0(\mathcal{O}(-1))+h^0(\mathcal{O}(-1))
 = 0+0 = 0$. ✓

**Case $g \geq 1$:** Degree $= 2g-2$, so set $E = L \oplus M$ with $L, M \in \op
eratorname{Pic}^{g-1}(C)$ line bundles of degree $g-1$. Then $\deg(E) = 2(g-1) =
 2g-2$ and $h^0(E) = h^0(L) + h^0(M)$. It suffices to find degree $g-1$ line bun
dles with no sections.

The **theta divisor** $W_{g-1} = \{L \in \operatorname{Pic}^{g-1}(C) : h^0(L) \g
eq 1\}$ is a proper closed subvariety of $\operatorname{Pic}^{g-1}(C)$:
- For $g = 1$: $W_0 = \{\mathcal{O}_C\}$ is a single point in the $1$-dimensiona

Therefore, for every $g \geq 1$, there exist degree $g-1$ line bundles $L, M$ wi

The values of $g$ are: **all $g \geq 0$** (i.e., $g \in \{0, 1, 2, 3, \dots\}$).
