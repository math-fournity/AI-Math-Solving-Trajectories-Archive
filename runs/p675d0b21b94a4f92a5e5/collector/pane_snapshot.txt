## Proof

Let $\alpha$ be a root of $f(t) = t^p - t - a$ in some extension of $F$, so $\al
pha^p - \alpha = a$.

**Step 1: Identify all roots.** For each $c \in \mathbb{F}_p$ (the prime subfiel
d of $F$), we have $c^p = c$, hence
$$(\alpha + c)^p - (\alpha + c) = \alpha^p + c^p - \alpha - c = (\alpha^p - \alp
ha) + (c^p - c) = a + 0 = a.$$
So $\alpha, \alpha+1, \alpha+2, \ldots, \alpha+(p-1)$ are all roots of $f$. Thes
e are $p$ distinct roots, and $\deg f = p$, so these are precisely all the roots
. They all lie in $F(\alpha)$, hence the splitting field is $K = F(\alpha)$.

**Step 2: $f$ is irreducible over $F$.** The polynomial $f$ is an Artin–Schreier
 polynomial. Its derivative is $f'(t) = -1 \neq 0$, so $f$ is separable. By the
Artin–Schreier theorem, $t^p - t - a$ either splits completely over $F$ (equival
ently, has a root in $F$, i.e., $a = b^p - b$ for some $b \in F$) or is irreduci
ble over $F$. The hypothesis $a \neq b^p - b$ for all $b \in F$ rules out the fi
rst case, so $f$ is irreducible. Therefore $[K : F] = [F(\alpha) : F] = p$.

**Step 3: $K/F$ is Galois.** Since $K$ is the splitting field of the separable p
olynomial $f$ over $F$, the extension $K/F$ is Galois.

**Step 4: Determine the Galois group.** Any $\sigma \in \operatorname{Gal}(K/F)$
 is determined by $\sigma(\alpha)$, which must be a root of $f$, so $\sigma(\alp
ha) = \alpha + c_\sigma$ for a unique $c_\sigma \in \mathbb{F}_p$. The map
$$\varphi: \operatorname{Gal}(K/F) \to (\mathbb{F}_p, +), \quad \sigma \mapsto c
_\sigma$$
is a group homomorphism, since for $\sigma, \tau \in \operatorname{Gal}(K/F)$,
$$(\sigma\tau)(\alpha) = \sigma(\alpha + c_\tau) = \sigma(\alpha) + c_\tau = \al
pha + c_\sigma + c_\tau,$$
so $c_{\sigma\tau} = c_\sigma + c_\tau$. The map is injective (it determines $\s
igma$), and $|\operatorname{Gal}(K/F)| = [K:F] = p = |\mathbb{F}_p|$, so $\varph
i$ is an isomorphism.

Therefore
$$\boxed{\operatorname{Gal}(K/F) \cong (\mathbb{Z}/p\mathbb{Z},\, +) \cong \math
bb{F}_p,}$$
the cyclic group of order $p$.
