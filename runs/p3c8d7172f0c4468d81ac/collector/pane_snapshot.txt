# IMO 1961, Problem 3

**Problem.** Solve $\cos^n x - \sin^n x = 1$, where $n$ is a given positive inte
ger.

**Answer.**
- If $n$ is **odd**: $x = 2k\pi$ or $x = -\dfrac{\pi}{2} + 2k\pi$, $\;k \in \mat
hbb{Z}$.
- If $n$ is **even**: $x = k\pi$, $\;k \in \mathbb{Z}$.

---

## Proof

Set $c = \cos x$, $s = \sin x$, so that $c^2 + s^2 = 1$ and $|c|, |s| \le 1$.

### Key inequality

For every integer $n \ge 2$ and every real $t$ with $|t| \le 1$,
$$|t|^n \le |t|^2, \qquad\text{hence}\qquad |t|^n + |t|^2\text{ comparison holds
.}$$
More precisely, $|t|^n = |t|^2 \cdot |t|^{n-2} \le |t|^2$ since $|t|^{n-2} \le 1
$.

---

### Case 1: $n$ even, $n \ge 2$

Here $c^n \ge 0$ and $s^n \ge 0$. Using $c^n \le c^2$ and $s^n \le s^2$ (both fr
om $|c|,|s|\le 1$, $n\ge 2$):
$$c^n - s^n \;\le\; c^n \;\le\; c^2 \;\le\; c^2 + s^2 = 1.$$
For equality $c^n - s^n = 1$ we need **both** $s^n = 0$ (otherwise $c^n - s^n <
c^n \le 1$) and $c^n = 1$.

- $s^n = 0 \Rightarrow s = 0 \Rightarrow \sin x = 0 \Rightarrow x = k\pi$.
- $c^n = 1 \Rightarrow |c| = 1$, automatically satisfied when $s = 0$.

Conversely, $x = k\pi$ gives $c = \pm 1$, $s = 0$, so $c^n - s^n = (\pm 1)^n - 0
 = 1$ (since $n$ is even). ✓

**Even $n$: $x = k\pi$.**

---

### Case 2: $n$ odd, $n \ge 3$

By the triangle inequality,
$$c^n - s^n \;\le\; |c|^n + |s|^n.$$
Since $n \ge 2$,
$$|c|^n + |s|^n = |c|^2|c|^{n-2} + |s|^2|s|^{n-2} \;\le\; |c|^2 + |s|^2 = 1,$$
because $|c|^{n-2} \le 1$ and $|s|^{n-2} \le 1$.

Hence $c^n - s^n \le 1$. For equality $c^n - s^n = 1$ **all** of the following m
ust hold:

**(a)** $|c|^n + |s|^n = 1$ (triangle inequality is tight $\Rightarrow$ $c^n \ge
 0$ and $s^n \le 0$, i.e. $c \ge 0$, $s \le 0$).

**(b)** $|c|^{n-2} = 1$ or $|c|^2 = 0$, and $|s|^{n-2} = 1$ or $|s|^2 = 0$ (each
 term must saturate the bound $|t|^{n-2}\le 1$ or vanish).

From $c^2 + s^2 = 1$, not both of $|c|,|s|$ equal $1$ and not both equal $0$. Th
us (b) forces exactly one of:

- $|c| = 1,\; s = 0$: then $c = \pm 1$. With $c \ge 0$ from (a), $c = 1$, giving
 $c^n - s^n = 1 - 0 = 1$. ✓ This is $x = 2k\pi$.
- $c = 0,\; |s| = 1$: then $s = \pm 1$. With $s \le 0$ from (a), $s = -1$, givin
g $c^n - s^n = 0 - (-1)^n = 0 - (-1) = 1$ (since $n$ is odd). ✓ This is $x = -\t
frac{\pi}{2} + 2k\pi$.

Conversely, both values are easily checked to satisfy the equation. ✓

**Odd $n \ge 3$: $x = 2k\pi$ or $x = -\frac{\pi}{2} + 2k\pi$.**

---

### Case 3: $n = 1$

The equation becomes $\cos x - \sin x = 1$, i.e.
$$\sqrt{2}\cos\!\Big(x + \tfrac{\pi}{4}\Big) = 1 \;\Longrightarrow\; \cos\!\Big(
x + \tfrac{\pi}{4}\Big) = \tfrac{1}{\sqrt{2}}.$$
Thus $x + \tfrac{\pi}{4} = \pm\tfrac{\pi}{4} + 2k\pi$, giving
$$x = 2k\pi \quad\text{or}\quad x = -\tfrac{\pi}{2} + 2k\pi.$$

This coincides exactly with the odd case above.

---

### Summary

| $n$ | Solutions |
|-----|-----------|
| $n$ odd | $x = 2k\pi \;\text{ or }\; x = -\dfrac{\pi}{2} + 2k\pi,\quad k \in \
mathbb{Z}$ |
| $n$ even | $x = k\pi,\quad k \in \mathbb{Z}$ |
