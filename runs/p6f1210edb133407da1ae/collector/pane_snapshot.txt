## Proof

**Step 1: Symmetry reduction.**

The summand $\frac{1}{k^{2019}(n-k)^{2019}}$ is symmetric under $k \leftrightarr
ow n-k$, so
$$\sum_{k=1}^{n-1} \frac{1}{k^{2019}(n-k)^{2019}} = 2\sum_{k=1}^{\lfloor (n-1)/2
\rfloor} \frac{1}{k^{2019}(n-k)^{2019}} + \varepsilon_n,$$
where $\varepsilon_n = 0$ if $n$ is odd, and $\varepsilon_n = \frac{1}{(n/2)^{40
38}} = \frac{2^{4038}}{n^{4038}}$ if $n$ is even. In either case $\varepsilon_n
= O(n^{-4038})$, which is negligible compared to $n^{-2019}$.

**Step 2: Asymptotics of the half-sum.**

For $1 \le k \le \lfloor(n-1)/2\rfloor$, write
$$\frac{1}{k^{2019}(n-k)^{2019}} = \frac{1}{n^{2019}} \cdot \frac{1}{k^{2019}(1-
k/n)^{2019}}.$$

Set $f_n(k) = \frac{1}{k^{2019}(1-k/n)^{2019}}$ for $1 \le k \le \lfloor(n-1)/2\
rfloor$, and $f_n(k)=0$ for $k > \lfloor(n-1)/2\rfloor$. Since $k/n \le 1/2$ on
the support, $(1-k/n)^{2019} \ge (1/2)^{2019}$, so
$$f_n(k) \le \frac{2^{2019}}{k^{2019}},$$
and $\sum_{k=1}^{\infty} \frac{2^{2019}}{k^{2019}} = 2^{2019}\zeta(2019) < \inft
y$ (since $2019 > 1$). For each fixed $k$, as $n\to\infty$ we have $k/n \to 0$,
hence $f_n(k) \to \frac{1}{k^{2019}}$. By the Dominated Convergence Theorem (app
lied to counting measure),
$$\sum_{k=1}^{\lfloor(n-1)/2\rfloor} \frac{1}{k^{2019}(1-k/n)^{2019}} \;\longrig
htarrow\; \sum_{k=1}^{\infty} \frac{1}{k^{2019}} = \zeta(2019).$$

**Step 3: Combine.**

Therefore
$$\sum_{k=1}^{n-1} \frac{1}{k^{2019}(n-k)^{2019}} = \frac{2\zeta(2019)}{n^{2019}
}\,(1+o(1)),$$
and consequently
$$S_n(a) = n^a \cdot \frac{2\zeta(2019)}{n^{2019}}\,(1+o(1)) = 2\zeta(2019)\, n^
{a-2019}\,(1+o(1)).$$

**Step 4: Determine $a$.**

- If $a > 2019$: $n^{a-2019}\to\infty$, so $S_n(a)\to +\infty$.
- If $a < 2019$: $n^{a-2019}\to 0$, so $S_n(a)\to 0$.
- If $a = 2019$: $S_n(2019) \to 2\zeta(2019)$.

Since $\zeta(2019) = \sum_{k=1}^{\infty} k^{-2019} > 1 > 0$, the limit $2\zeta(2
019)$ is a positive real number.

**Conclusion.** The unique value of $a$ for which $\{S_n(a)\}_{n\ge 2}$ converge
s to a positive real number is

$$\boxed{a = 2019}.$$
