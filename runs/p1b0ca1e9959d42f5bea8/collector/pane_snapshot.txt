Looking at this problem, I need to determine whether a curl-free tempered distri
bution vector field on ℝ³ is necessarily a gradient of some tempered distributio
n.

**Answer: Yes.**

**Proof.**

Let $f = (f_1, f_2, f_3) \in \mathcal{S}'(\mathbb{R}^3)^3$ with $\operatorname{c
url} f = 0$, i.e., $\partial_j f_i = \partial_i f_j$ for all $i,j$.

**Step 1: Fourier transform.** Using the convention $\mathcal{F}[\varphi](\xi) =
 \int \varphi(x)e^{-ix\cdot\xi}\,dx$, we have $\mathcal{F}[\partial_j T] = i\xi_
j \mathcal{F}[T]$. Set $\hat{f} = \mathcal{F}[f] \in \mathcal{S}'(\mathbb{R}^3)^
3$. The condition $\partial_j f_i = \partial_i f_j$ becomes

$$\xi_j \hat{f}_i = \xi_i \hat{f}_j \quad \text{for all } i,j. \tag{$\ast$}$$

We seek $u \in \mathcal{S}'(\mathbb{R}^3)$ with $\partial_i u = f_i$, i.e., $i\x
i_i \hat{u} = \hat{f}_i$. Setting $h_i := -i\hat{f}_i$, this becomes $\xi_i \hat
{u} = h_i$, and ($\ast$) gives the compatibility $\xi_j h_i = \xi_i h_j$.

**Step 2: Splitting.** Choose $\chi \in C^\infty(\mathbb{R}^3)$ with $\chi \equi
v 0$ near $0$ and $\chi \equiv 1$ for $|\xi| \geq 1$. Set $h^{\mathrm{out}} = \c
hi h$ and $h^{\mathrm{in}} = (1-\chi)h$. Since multiplication by $\chi$ commutes
 with multiplication by $\xi_i$, both parts retain the compatibility $\xi_j h^{\
bullet}_i = \xi_i h^{\bullet}_j$.

**Step 3: Away from the origin.** On $\operatorname{supp}(\chi) \subset \{|\xi|
\geq \varepsilon\}$, the function $\xi_j/|\xi|^2$ is smooth. Define

$$\hat{u}^{\mathrm{out}} = \sum_{j=1}^3 \frac{\xi_j}{|\xi|^2}\,\chi\, h_j.$$

The function $(\xi_j/|\xi|^2)\chi$ is smooth (the singularity at $0$ is killed b
y $\chi$) and bounded, hence of polynomial growth. Multiplication of a tempered
distribution by such a function is well-defined, so $\hat{u}^{\mathrm{out}} \in
\mathcal{S}'(\mathbb{R}^3)$. Using $\xi_i h_j = \xi_j h_i$:

$$\xi_i \hat{u}^{\mathrm{out}} = \sum_j \frac{\xi_i \xi_j}{|\xi|^2}\,\chi\, h_j
= \sum_j \frac{\xi_j}{|\xi|^2}\,\chi\,(\xi_j h_i) = \chi\, h_i = h^{\mathrm{out}
}_i. \quad\checkmark$$

**Step 4: Near the origin.** Here $h^{\mathrm{in}} = (1-\chi)h$ is compactly sup
ported, so $h^{\mathrm{in}} \in \mathcal{E}'(\mathbb{R}^3)^3$. Take the Fourier
transform $\mathcal{F}_\eta$ in the $\xi$-variable (dual variable $y$): set $H_i
(y) = \mathcal{F}_\eta[h^{\mathrm{in}}_i](y)$. By the Paley–Wiener–Schwartz theo
rem, each $H_i$ is a smooth (entire) function of polynomial growth. The compatib
ility $\xi_j h^{\mathrm{in}}_i = \xi_i h^{\mathrm{in}}_j$ transforms via $\mathc
al{F}[\xi_j T] = i\partial_j \mathcal{F}[T]$ to

$$\partial_j H_i = \partial_i H_j. \tag{$\ast\ast$}$$

So $H = (H_1,H_2,H_3)$ is a smooth vector field of polynomial growth with $\oper
atorname{curl} H = 0$. By the Poincaré lemma on the star-shaped domain $\mathbb{
R}^3$, define

$$\widehat{U}(y) = -i\sum_{k=1}^3 y_k \int_0^1 H_k(ty)\,dt.$$

Since $H_k$ is smooth, $\widehat{U}$ is smooth. Since $|H_k(y)| \leq C(1+|y|)^N$
, we get $|\widehat{U}(y)| \leq 3|y|\cdot C(1+|y|)^N = O(|y|^{N+1})$, so $\wideh
at{U}$ has polynomial growth. A direct computation using ($\ast\ast$) and integr
ation by parts verifies $\partial_i \widehat{U} = -iH_i$:

$$\partial_i \widehat{U} = -i\int_0^1 H_i(ty)\,dt - i\sum_k y_k\int_0^1 t\,(\par
tial_k H_i)(ty)\,dt = -i\int_0^1 H_i(ty)\,dt - i\int_0^1 t\,\tfrac{d}{dt}H_i(ty)
\,dt = -i\big[t\,H_i(ty)\big]_0^1 = -iH_i(y).$$

Since $\widehat{U}$ is smooth of polynomial growth, $\widehat{U} \in \mathcal{S}
'(\mathbb{R}^3_y)$. Set $\hat{u}^{\mathrm{in}} = \mathcal{F}_\eta^{-1}[\widehat{
U}] \in \mathcal{S}'(\mathbb{R}^3_\xi)$. Then

$$\mathcal{F}_\eta[\xi_i\,\hat{u}^{\mathrm{in}}] = i\,\partial_i \widehat{U} = i
(-i)H_i = H_i = \mathcal{F}_\eta[h^{\mathrm{in}}_i],$$

so $\xi_i\,\hat{u}^{\mathrm{in}} = h^{\mathrm{in}}_i$. $\checkmark$

**Step 5: Combine.** Set $\hat{u} = \hat{u}^{\mathrm{out}} + \hat{u}^{\mathrm{in
}} \in \mathcal{S}'(\mathbb{R}^3)$. Then

$$\xi_i\,\hat{u} = h^{\mathrm{out}}_i + h^{\mathrm{in}}_i = h_i = -i\hat{f}_i,$$

so $i\xi_i\,\hat{u} = \hat{f}_i = \mathcal{F}[f_i]$, which gives $\partial_i u =
 f_i$ for $u = \mathcal{F}^{-1}[\hat{u}] \in \mathcal{S}'(\mathbb{R}^3)$.

Therefore $\nabla u = f$ with $u \in \mathcal{S}'(\mathbb{R}^3)$. $\blacksquare$
