$$Tf(x,y) = w(x,y)\, f\big((x+\alpha)\!\!\mod 1,\; y\big),$$
where $w(x,y) = 1$ if $x \in (0, 1-\alpha)$ and $w(x,y) = \tfrac{1}{2}$ if $x \i
n (1-\alpha, 1)$.

**Iterates.** By induction,
$$T^n f(x,y) = \prod_{k=0}^{n-1} w\big(\phi_y^k(x),\, y\big)\cdot f\big(\phi_y^n
(x),\, y\big),$$
where $\phi_y^k(x) = (x + k\alpha)\!\!\mod 1$. Since $w \in \{1, \tfrac12\}$,
$$\|T^n\| = \operatorname*{ess\,sup}_{(x,y)} \prod_{k=0}^{n-1} w(\phi_y^k(x),y)
= 2^{-\,\operatorname*{ess\,inf}_{(x,y)} N(x,y,n)},$$
where $N(x,y,n) = \#\{k \in \{0,\dots,n-1\} : \phi_y^k(x) \in (1-\alpha, 1)\}$.

**Counting visits.** The condition $\phi_y^k(x) \in (1-\alpha,1)$ is equivalent
to a *wrap-around* occurring when passing from step $k$ to step $k+1$, i.e., $\l
floor x+(k+1)\alpha\rfloor > \lfloor x+k\alpha\rfloor$. The total number of wrap
-arounds over $k=0,\dots,n-1$ is therefore
$$N(x,y,n) = \lfloor x + n\alpha\rfloor - \lfloor x\rfloor.$$
Since $x \in (0,1)$, we have $\lfloor x\rfloor = 0$, and $x + n\alpha \in (n\alp
ha,\, n\alpha+1)$, so $\lfloor x+n\alpha\rfloor \in \{\lfloor n\alpha\rfloor,\,
\lfloor n\alpha\rfloor+1\}$. (The boundary case where $\{x+k\alpha\} = 1-\alpha$
 exactly occurs on a set of measure zero in $x$ and does not affect the essentia

**Essential infimum over $x$.** For a.e. $x \in (0,1)$:
- If $\{n\alpha\} \in (0,1)$: $\lfloor x+n\alpha\rfloor = \lfloor n\alpha\rfloor
$ for $x \in (0,\, 1-\{n\alpha\})$, which is a set of positive measure.
- If $n\alpha \in \mathbb{Z}$: $\lfloor x+n\alpha\rfloor = n\alpha$ for all $x \
in (0,1)$.

In all cases, $\operatorname*{ess\,inf}_{x\in(0,1)} N(x,y,n) = \lfloor n\alpha\r
floor = \lfloor n\,y/b\rfloor$.

**Essential infimum over $y$.** Since $y/b \in (a/b, 1)$ and $\lfloor n\,y/b\rfl
oor$ is minimized as $y/b \to a/b^+$:
$$\operatorname*{ess\,inf}_{(x,y)} N(x,y,n) = \lfloor n\,a/b\rfloor.$$

**Conclusion.** We obtain the exact formula
$$\|T^n\| = 2^{-\lfloor n\,a/b\rfloor}.$$
Therefore
$$\frac{\log\|T^n\|}{n} = -\frac{\log 2}{n}\lfloor n\,a/b\rfloor \;\longrightarr
ow\; -\frac{a}{b}\log 2.$$
Since $0 < a < b$, we have $a/b > 0$, so
$$\lim_{n\to\infty}\frac{\log\|T^n\|}{n} = -\frac{a}{b}\log 2 < 0.$$

The statement is **true**. $\blacksquare$
