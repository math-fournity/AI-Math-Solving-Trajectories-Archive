## Solution

Let $u = \frac{p}{q}$, $v = \frac{q}{r}$, $w = \frac{r}{p}$. Note that $uvw = 1$
, and the **Total Relative Load** is $S = u + v + w$.

**Reformulating the first equation.** Write $p+q = q(u+1)$, $q+r = r(v+1)$, $r+p
 = p(w+1)$. Then
$$\frac{(p+q)(q+r)(r+p)}{pqr} = (u+1)(v+1)(w+1) = 24.$$
Expanding using $uvw=1$:
$$(u+1)(v+1)(w+1) = uvw + (uv+vw+wu) + (u+v+w) + 1 = 2 + T + S,$$
where $T = uv+vw+wu$. Hence
$$S + T = 22. \tag{1}$$

**Reformulating the second equation.** Write $p-2q = q(u-2)$, $q-2r = r(v-2)$, $
r-2p = p(w-2)$. Then
$$\frac{(p-2q)(q-2r)(r-2p)}{pqr} = (u-2)(v-2)(w-2) = 10.$$
Expanding:
$$(u-2)(v-2)(w-2) = uvw - 2T + 4S - 8 = 1 - 2T + 4S - 8 = 4S - 2T - 7.$$
So
$$4S - 2T = 17. \tag{2}$$

**Solving the system.** From (1): $T = 22 - S$. Substituting into (2):
$$4S - 2(22 - S) = 17 \implies 6S - 44 = 17 \implies 6S = 61 \implies S = \frac{
61}{6}.$$

**Verification of consistency.** The values $S = \tfrac{61}{6}$, $T = \tfrac{71}
{6}$, $uvw=1$ give the cubic $6t^3 - 61t^2 + 71t - 6 = 0$ for $u,v,w$. Its discr
iminant is positive (one checks the three roots are real), confirming the system
 is physically consistent with the given readings.

**Final answer.** The Total Relative Load is $\frac{61}{6}$, with $\gcd(61,6)=1$
 (61 is prime). Thus $m = 61$, $n = 6$, and
$$m + n = 67.$$
