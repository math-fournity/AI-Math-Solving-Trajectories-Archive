## Solution

Let $f:[0,2]\to\mathbb{R}$ be defined by

$$f(x)=\begin{cases}1,&x\notin\mathbb{Q},\\0,&x\in\mathbb{Q}.\end{cases}$$

**Goal.** Compute $\displaystyle\int_{[0,2]} f\,d\mu$ where $\mu$ is Lebesgue me
asure.

---

### Step 1. The rationals form a null set

The set $\mathbb{Q}\cap[0,2]$ is countable (the rationals are countable, and int
ersecting with $[0,2]$ preserves countability). Every countable set has Lebesgue
 measure zero: enumerating it as $\{q_1,q_2,\dots\}$ and covering each $q_n$ by
an interval of length $\varepsilon/2^n$ gives an outer measure $\le\varepsilon$,
 for arbitrary $\varepsilon>0$. Hence

$$\mu\bigl(\mathbb{Q}\cap[0,2]\bigr)=0.$$

### Step 2. The function equals 1 almost everywhere

Since $\mu(\mathbb{Q}\cap[0,2])=0$, the function $f$ differs from the constant f
unction $g\equiv 1$ only on a set of measure zero. Two measurable functions that
 agree almost everywhere have the same Lebesgue integral, so

$$\int_{[0,2]} f\,d\mu=\int_{[0,2]} 1\,d\mu.$$

### Step 3. Measurability

The function $f$ is measurable: $\mathbb{Q}\cap[0,2]$ is a Borel set (countable,
 hence $F_\sigma$), so $\{f>1/2\}=[0,2]\setminus\mathbb{Q}$ is measurable, and s
imilarly all sublevel sets are measurable. Thus the integral is well defined.

### Step 4. Evaluate

The integral of the constant $1$ over $[0,2]$ is the Lebesgue measure of $[0,2]$
:

$$\int_{[0,2]} 1\,d\mu=\mu\bigl([0,2]\bigr)=2.$$

---

### Conclusion

$$\boxed{\displaystyle\int_{[0,2]} f\,d\mu = 2.}$$
