**Key observation:** If ker(T*) ≠ {0}, any nonzero x ∈ ker(T*) satisfies T*x = 0

## Proof

**Setting.** Let X = ℓ²(ℕ) with standard orthonormal basis {e₁, e₂, e₃, ...}. De
fine the bounded linear operator T : X → X by

$$T e_n = 2\, e_{2n}, \quad n = 1, 2, 3, \ldots$$

**T is bounded.** For x = Σ aₙ eₙ, we have Tx = 2 Σ aₙ e_{2n}, and since the ind
ices {2n} are distinct, ‖Tx‖² = 4 Σ|aₙ|² = 4‖x‖². So ‖T‖ = 2.

**Claim 1: Every nonzero orbit under T is unbounded.**

Compute Tⁿ: T²eₙ = T(2e_{2n}) = 2·2·e_{4n} = 4e_{4n}. By induction,

$$T^n e_k = 2^n\, e_{2^n k}.$$

For a general nonzero x = Σ aₖ eₖ, the indices {2ⁿk : k ≥ 1} are pairwise distin
ct for each fixed n (since 2ⁿk₁ = 2ⁿk₂ ⟹ k₁ = k₂). Therefore

$$\|T^n x\|^2 = \sum_{k \geq 1} |a_k|^2 \cdot |2^n|^2 = 4^n \sum_{k \geq 1} |a_k
|^2 = 4^n \|x\|^2.$$

So ‖Tⁿx‖ = 2ⁿ‖x‖ → ∞ for every x ≠ 0. **The hypothesis is satisfied.**

**Claim 2: ker(T*) is infinite dimensional.**

Compute the adjoint. Since ⟨Teₙ, eₘ⟩ = ⟨2e_{2n}, eₘ⟩ = 2δ_{m,2n}, we get

$$T^* e_m = \begin{cases} 2\, e_{m/2} & \text{if } m \text{ is even}, \\ 0 & \te
xt{if } m \text{ is odd}. \end{cases}$$

Thus ker(T*) = {x ∈ ℓ²(ℕ) : x has support only on odd indices} = closure of span
{e₁, e₃, e₅, ...}, which is **infinite dimensional**.

**Claim 3: There exist nonzero vectors with bounded orbit under T*.**

Take any nonzero x ∈ ker(T*), e.g., x = e₁. Then T*e₁ = 0, so (T*)ⁿe₁ = 0 for al
l n ≥ 1. The orbit {e₁, 0, 0, ...} is bounded (in fact, eventually zero).

**Conclusion.** We have constructed a bounded operator T on ℓ²(ℕ) such that:
- Every nonzero vector has unbounded orbit under T (‖Tⁿx‖ = 2ⁿ‖x‖ → ∞),
- ker(T*) is infinite dimensional,
- Every nonzero vector in ker(T*) has a bounded (eventually zero) orbit under T*

Therefore, the answer is **no**: it does not necessarily follow that the orbit o
