## 证明

我们要研究当 $t \to \infty$ 时，$I(t) = \displaystyle\int_0^{at} \dfrac{e^{-u}}{
\left(t - \dfrac{u}{a}\right)^{\beta}}\,du$ 的渐近行为，其中 $\beta < 1$ 且 $a >
 0$。

**步骤 1：代换化简。**

令 $v = u/a$，则 $du = a\,dv$，积分限从 $v \in [0, t]$ 变为：

$$I(t) = a\int_0^t \frac{e^{-av}}{(t-v)^\beta}\,dv.$$

现在令 $s = t - v$（即 $v = t - s$，$dv = -ds$），积分限从 $s \in [t, 0]$ 变为：

$$I(t) = a\int_0^t e^{-a(t-s)}\,s^{-\beta}\,ds = a\,e^{-at}\int_0^t e^{as}\,s^{-
\beta}\,ds.$$

**步骤 2：对内层积分应用 Laplace 方法。**

定义 $J(t) = \displaystyle\int_0^t e^{as}\,s^{-\beta}\,ds$。被积函数中的指数 $e^
{as}$（其中 $a>0$）在 $s = t$（即积分上限）处达到最大值，因此根据 Laplace 方法，
主要贡献来自于 $s$ 附近的区域。令 $s = t - r$，其中 $r \in [0, t]$：

$$J(t) = e^{at}\int_0^t e^{-ar}\,(t-r)^{-\beta}\,dr.$$

因此

$$I(t) = a\int_0^t e^{-ar}\,(t-r)^{-\beta}\,dr = a\,t^{-\beta}\int_0^t e^{-ar}\l
eft(1 - \frac{r}{t}\right)^{-\beta}dr.$$

**步骤 3：控制收敛性论证。**

我们将积分在 $r = t/2$ 处拆分：

$$\int_0^t = \int_0^{t/2} + \int_{t/2}^t.$$

*第一部分* ($r \in [0, t/2]$)：此处 $r/t \le 1/2$，因此 $\left(1 - r/t\right)^{-
\beta} \le 2^{|\beta|}$（有界）。由于 $e^{-ar}\,2^{|\beta|}$ 在 $[0,\infty)$ 上
可积，由控制收敛定理（Dominated Convergence Theorem）可得：

$$\int_0^{t/2} e^{-ar}\left(1-\frac{r}{t}\right)^{-\beta}dr \;\longrightarrow\;
\int_0^\infty e^{-ar}\,dr = \frac{1}{a}.$$

*第二部分* ($r \in [t/2, t]$)：令 $r = t - \rho$，其中 $\rho \in [0, t/2]$：

$$\int_{t/2}^t e^{-ar}(t-r)^{-\beta}dr = e^{-at}\int_0^{t/2} e^{a\rho}\,\rho^{-\
beta}\,d\rho \le e^{-at}\cdot e^{at/2}\cdot\frac{(t/2)^{1-\beta}}{1-\beta} = O\!
\left(t^{1-\beta}\,e^{-at/2}\right),$$

当 $t \to \infty$ 时，该项指数级趋近于 $0$。

**步骤 4：结论。**

综合以上两部分：

$$\int_0^t e^{-ar}\left(1-\frac{r}{t}\right)^{-\beta}dr = \frac{1}{a} + O(1/t) +
 O\!\left(t^{1-\beta}e^{-at/2}\right) = \frac{1}{a} + O(1/t).$$

因此

$$I(t) = a\,t^{-\beta}\left(\frac{1}{a} + O(1/t)\right) = t^{-\beta}\left(1 + O(
1/t)\right).$$

**下一阶项**（通过展开 $(1 - r/t)^{-\beta} = 1 + \beta r/t + \cdots$）：

$$I(t) = a\,t^{-\beta}\left[\frac{1}{a} + \frac{\beta}{a^2 t} + O(1/t^2)\right]
= t^{-\beta} + \frac{\beta}{a}\,t^{-\beta-1} + O(t^{-\beta-2}).$$

**结果。** 当 $t \to \infty$ 时，该积分满足

$$\boxed{\int_0^{at} \frac{e^{-u}}{\left(t-\frac{u}{a}\right)^\beta}\,du \;\sim\
; t^{-\beta}}, \qquad \beta < 1,\; a > 0,$$

更精确地表示为 $I(t) = t^{-\beta}\!\left(1 + \dfrac{\beta}{at} + O(t^{-2})\right
)$。

### 证明完成
