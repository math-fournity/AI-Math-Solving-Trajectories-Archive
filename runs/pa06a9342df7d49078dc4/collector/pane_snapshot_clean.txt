**Claim:** $f$ is uniquely determined (up to a.e. equivalence) as $f(x) \equiv 1
$.

**Proof.**

Define $F(x) = \int_0^x f(t)\,dt$ for $x \in [0,1]$. Since $f$ is Lebesgue integ
rable, $F$ is absolutely continuous on $[0,1]$ with $F(0) = 0$, and $F'(x) = f(x
)$ for a.e. $x \in (0,1)$.

The hypothesis states
$$f(x) = \frac{1}{x}\int_0^x f(t)\,dt = \frac{F(x)}{x} \quad \text{for a.e. } x
\in (0,1).$$

Combining with $F'(x) = f(x)$ a.e., we obtain
$$F'(x) = \frac{F(x)}{x} \quad \text{for a.e. } x \in (0,1). \tag{1}$$

Consider the function $G(x) = \dfrac{F(x)}{x}$ on $(0,1)$. Since $F$ is absolute
ly continuous and $x \mapsto 1/x$ is $C^\infty$ on $(0,1)$, the function $G$ is
absolutely continuous on every compact subinterval $[a,1] \subset (0,1)$, hence
continuous on $(0,1)$. Differentiating (wherever $F'$ exists, which is a.e.):
$$G'(x) = \frac{xF'(x) - F(x)}{x^2} = \frac{F(x) - F(x)}{x^2} = 0 \quad \text{fo
r a.e. } x \in (0,1),$$
using (1). An absolutely continuous function on $[a,1]$ with derivative $0$ a.e.
 is constant on $[a,1]$. Since this holds for every $a > 0$, $G$ is constant on
the connected interval $(0,1)$: there exists $C \in \mathbb{R}$ such that
$$G(x) = \frac{F(x)}{x} = C \quad \text{for all } x \in (0,1).$$

Hence $F(x) = Cx$ for all $x \in (0,1)$, and by continuity also $F(0) = 0 = C \c
dot 0$. Therefore
$$f(x) = \frac{F(x)}{x} = C \quad \text{for a.e. } x \in (0,1).$$

Now use the normalization $\int_0^1 f(x)\,dx = 1$:
$$1 = \int_0^1 f(x)\,dx = \int_0^1 C\,dx = C.$$

Thus $C = 1$, and consequently
$$f(x) = 1 \quad \text{for a.e. } x \in (0,1).$$

**Uniqueness:** The constant $C$ was forced to equal $1$ by the normalization co
ndition, so no other value is possible. Any $f$ satisfying the hypotheses must a
gree with $1$ a.e.

**Verification:** For $f \equiv 1$: it is non-negative, integrable, $\int_0^1 1\
,dx = 1$, and $\frac{1}{x}\int_0^x 1\,dt = \frac{x}{x} = 1 = f(x)$. All conditio
ns hold.

Therefore $f$ is uniquely determined (up to a.e. equivalence) as the constant fu
nction $f(x) \equiv 1$. $\blacksquare$
