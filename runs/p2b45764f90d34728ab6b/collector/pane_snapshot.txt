## Solution

Let $G(x) = e^{kx}|F(x)| \geq 0$. Then $|F(s)| = e^{-ks}G(s)$, and the inequalit
y becomes:

$$\sup_{x \in [0,r]} e^{kx}\int_0^x e^{-ks}G(s)\,ds \;\leq\; \frac{c}{M}\sup_{s
\in [0,r]} G(s). \qquad (\star)$$

We seek all $k$ for which some $c < 1$ makes $(\star)$ hold for every continuous
 $G \geq 0$ on $[0,r]$ and every $r > 0$.

---

**Case 1: $k \geq 0$ — fails.**

Take $F \equiv 1$, so $G(x) = e^{kx}$ and $\sup G = e^{kr}$. Then

$$e^{kx}\int_0^x e^{-ks}\cdot e^{ks}\,ds = e^{kx}\cdot x,$$

so $\sup_{x\in[0,r]} e^{kx}x = e^{kr}\cdot r$ (for $k>0$; for $k=0$ it is $r$).
The ratio LHS$/\sup G$ equals $r$, which is unbounded as $r\to\infty$. No finite
 $\frac{c}{M}$ suffices. ✗

---

**Case 2: $k < 0$ — the bound $\frac{1}{|k|}$.**

For any $G \geq 0$ on $[0,r]$ with $A = \sup_{[0,r]} G$:

$$e^{kx}\int_0^x e^{-ks}G(s)\,ds \;\leq\; A\cdot e^{kx}\int_0^x e^{-ks}\,ds \;=\
; A\cdot\frac{1-e^{kx}}{-k} \;=\; \frac{A(1-e^{kx})}{|k|}.$$

Since $k<0$, $e^{kx}$ is decreasing, so $1-e^{kx}$ is increasing in $x$, giving

$$\sup_{x\in[0,r]} \frac{1-e^{kx}}{|k|} = \frac{1-e^{kr}}{|k|} < \frac{1}{|k|} \
quad\text{for all finite } r>0.$$

Therefore $(\star)$ holds with $\frac{c}{M} = \frac{1}{|k|}$, i.e. $c = \frac{M}
{|k|}$, since the left side is **strictly** less than $\frac{A}{|k|}$ for every
finite $r$. ✓

---

**Sharpness — the constant $\frac{1}{|k|}$ cannot be reduced.**

Take $G \equiv A$ (constant). Then equality holds throughout:

$$\sup_{x\in[0,r]} e^{kx}\int_0^x e^{-ks}A\,ds = \frac{A(1-e^{kr})}{|k|} \;\xrig
htarrow{r\to\infty}\; \frac{A}{|k|}.$$

So $\sup_{G,\,r>0}\frac{\text{LHS}}{\sup G} = \frac{1}{|k|}$ (a supremum, approa
ched but never attained at finite $r$). Any $\frac{c}{M} < \frac{1}{|k|}$ is vio
lated by choosing $r$ large enough with constant $G$.

---

**Conclusion.**

The inequality $(\star)$ holds for all $F$ and all $r>0$ if and only if $\frac{c
}{M} \geq \frac{1}{|k|}$, i.e. $c \geq \frac{M}{|k|}$.

For a constant $c < 1$ to exist satisfying this, we need

$$\frac{M}{|k|} < 1 \quad\Longleftrightarrow\quad |k| > M \quad\Longleftrightarr
ow\quad k < -M.$$

The boundary $k = -M$ gives $\frac{M}{|k|}=1$, forcing $c \geq 1$, which contrad
icts $c<1$.

$$\boxed{k \in (-\infty,\, -M)}$$
