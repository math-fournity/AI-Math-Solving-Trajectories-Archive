## Proof

**Notation.** Let $C \subset [0,1]$ be the standard middle-thirds Cantor set, co
nstructed as $C = \bigcap_{n=0}^{\infty} C_n$ where $C_0 = [0,1]$ and $C_{n+1}$
is obtained from $C_n$ by removing the open middle third of each constituent int
erval. Equivalently, $C_n$ consists of all $x \in [0,1]$ whose first $n$ ternary
 digits belong to $\{0,2\}$.

**Step 1: $C_n + C_n = [0,2]$ for every $n \geq 0$.**

Every element of $C_n$ can be written as
$$x = \sum_{k=1}^{n} 2a_k\, 3^{-k} + r, \qquad a_k \in \{0,1\},\; r \in [0,\, 3^
{-n}].$$
Therefore
$$C_n + C_n = \Bigl\{\sum_{k=1}^{n} 2c_k\, 3^{-k} + t \;:\; c_k \in \{0,1,2\},\;
 t \in [0,\, 2\cdot 3^{-n}]\Bigr\}.$$
The set $\bigl\{\sum_{k=1}^{n} 2c_k\, 3^{-k} : c_k \in \{0,1,2\}\bigr\}$ equals
$\bigl\{2j\cdot 3^{-n} : j = 0, 1, \dots, 3^n - 1\bigr\}$. Hence
$$C_n + C_n = \bigcup_{j=0}^{3^n - 1} \bigl[\,2j\cdot 3^{-n},\; 2(j+1)\cdot 3^{-
n}\,\bigr].$$
Consecutive intervals share an endpoint ($2(j+1)\cdot 3^{-n}$), so the union is
the single interval
$$C_n + C_n = \bigl[0,\; 2\cdot 3^n \cdot 3^{-n}\bigr] = [0,2].$$

**Step 2: $C + C = [0,2]$.**

Since $C \subseteq C_n$, we have $C + C \subseteq C_n + C_n = [0,2]$ for all $n$
, giving $C + C \subseteq [0,2]$.

For the reverse inclusion, let $x \in [0,2] = \bigcap_n (C_n + C_n)$. For each $
n$ choose $a_n, b_n \in C_n$ with $a_n + b_n = x$. Since $[0,1]$ is compact, a s
ubsequence $a_{n_k} \to a \in [0,1]$; then $b_{n_k} = x - a_{n_k} \to x - a =: b
$. For any fixed $m$, we have $a_{n_k} \in C_{n_k} \subseteq C_m$ for all large
$k$; since $C_m$ is closed, $a \in C_m$. Thus $a \in \bigcap_m C_m = C$, and lik
ewise $b \in C$. Therefore $x = a + b \in C + C$, proving $[0,2] \subseteq C + C
$.

**Step 3: $C + C + C = [0,3]$.**

Using Step 2,
$$C + C + C = (C + C) + C = [0,2] + C = \{s + c : s \in [0,2],\; c \in C\}.$$
Since $C \subseteq [0,1]$, we have $[0,2] + C \subseteq [0,3]$.

For the reverse: $0 \in C$ gives $[0,2] + 0 = [0,2] \subseteq [0,2] + C$, and $1
 \in C$ gives $[0,2] + 1 = [1,3] \subseteq [0,2] + C$. Since $[0,2] \cup [1,3] =
 [0,3]$, we obtain $[0,3] \subseteq [0,2] + C$.

Therefore $C + C + C = [0,3]$.

$$\boxed{C + C + C = [0,\, 3]}$$
