## Proof

We are given that $h:\mathbb{C}\to\mathbb{C}$ is holomorphic (since $h'$ exists
and $g(z)=h'(z)-1$ is stated to be holomorphic), with
$$h(0)=0,\qquad h'(0)=1,\qquad |h'(z)|\le 1 \text{ for all } |z|\le 5.$$

**Key observation.** The function $h'$ is holomorphic on the closed disk $\overl
ine{D(0,5)}=\{z:|z|\le 5\}$. By hypothesis,
$$|h'(z)|\le 1 \quad\text{for every } z\in \overline{D(0,5)},$$
and at the **interior** point $z=0$ we have
$$|h'(0)| = |1| = 1.$$

Thus $h'$ attains its maximum modulus on the closed disk at an interior point.

**Applying the Maximum Modulus Principle.** The Maximum Modulus Principle states
 that if a holomorphic function on a domain attains its maximum modulus at an in
terior point, then the function is constant.

Since $h'$ is holomorphic on the domain $D(0,5)$ and $|h'|$ attains its maximum
value $1$ at the interior point $z=0$, we conclude
$$h'(z) \equiv 1 \quad\text{for all } z\in D(0,5).$$

By the identity theorem (holomorphic functions agreeing on a domain are identica
l), $h'(z)=1$ everywhere on $\mathbb{C}$.

**Integrating to recover $h$.** Since $h'(z)=1$ for all $z\in\mathbb{C}$,
$$h(z) = z + C$$
for some constant $C\in\mathbb{C}$. Applying the initial condition $h(0)=0$:
$$0 = h(0) = 0 + C \implies C = 0.$$

Therefore
$$\boxed{h(z) = z.}$$

**Verification.** With $h(z)=z$: $h(0)=0$ ✓; $h'(z)=1$ so $h'(0)=1$ ✓; $|h'(z)|=
|1|=1\le 1$ for all $z$ with $|z|\le 5$ ✓. All three conditions are satisfied.

**Remark on the hint.** The suggested function $g(z)=h'(z)-1$ is holomorphic wit
h $g(0)=0$. The bound $|h'(z)|\le 1$ together with $h'(0)=1$ forces $h'(0)$ to b
e a maximum-modulus point; equivalently $g(0)=0$ is a minimum-modulus point of $
h'-1$, and the same maximum-modulus argument (or Schwarz lemma applied to $h'$ o
n $D(0,5)$ after rescaling) yields $h'\equiv 1$, recovering $h(z)=z$.
