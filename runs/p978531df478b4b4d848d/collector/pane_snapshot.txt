## Proof

**Setup.** We have $c(t) = (\cos t, b\sin t)$ with $a=1>b>0$, so the ellipse is
$\{(x,y): x^2 + y^2/b^2 = 1\}$. The derivative is $c'(t) = (-\sin t,\, b\cos t)$
.

**Key computation: $\lambda_i = 1$ for all $i$.**

The condition states $x_i = c(t_i) = \lambda_i\, c'(t_{i-1})$ for some $\lambda_
i > 0$. Since $x_i$ lies on the ellipse, substitute $\lambda_i(-\sin t_{i-1},\,
b\cos t_{i-1})$ into the ellipse equation $x^2 + y^2/b^2 = 1$:

$$\lambda_i^2 \sin^2 t_{i-1} + \frac{\lambda_i^2 b^2 \cos^2 t_{i-1}}{b^2} = \lam
bda_i^2(\sin^2 t_{i-1} + \cos^2 t_{i-1}) = \lambda_i^2 = 1.$$

Since $\lambda_i > 0$, we get $\lambda_i = 1$ for every $i$. Thus $x_i = c'(t_{i
-1})$ exactly, and the point $x_i$ is **uniquely determined** (the ray of positi
ve multiples of $c'(t_{i-1})$ meets the ellipse at exactly one point).

**Deriving the recurrence on $t_i$.**

From $c(t_i) = c'(t_{i-1})$:

$$\cos t_i = -\sin t_{i-1}, \qquad b\sin t_i = b\cos t_{i-1}.$$

These give $\cos t_i = \cos(t_{i-1}+\tfrac{\pi}{2})$ and $\sin t_i = \sin(t_{i-1
}+\tfrac{\pi}{2})$, so:

$$t_i \equiv t_{i-1} + \frac{\pi}{2} \pmod{2\pi}.$$

**The sequence is periodic with period 4.**

Iterating: $t_i \equiv t_1 + (i-1)\frac{\pi}{2} \pmod{2\pi}$. Since $\frac{\pi}{
2}$ has order 4 modulo $2\pi$, we get $t_{i+4} \equiv t_i \pmod{2\pi}$, hence $x
_{i+4} = x_i$ for all $i$. The sequence is:

$$x_1,\; x_2,\; x_3,\; x_4,\; x_1,\; x_2,\; x_3,\; x_4,\; \ldots$$

**The four points are distinct.**

Since $0 < t_1 < \pi/2$, the four parameter values modulo $2\pi$ fall in four di
stinct quadrants:

| Point | $t$ value (mod $2\pi$) | Quadrant | Coordinates |
|-------|------------------------|----------|-------------|
| $x_1$ | $t_1 \in (0,\pi/2)$ | I | $(\cos t_1,\; b\sin t_1)$ — both positive |
| $x_2$ | $t_1+\pi/2 \in (\pi/2,\pi)$ | II | $(-\sin t_1,\; b\cos t_1)$ — $x<0,\

| $x_3$ | $t_1+\pi \in (\pi,3\pi/2)$ | III | $(-\cos t_1,\; -b\sin t_1)$ — both
negative |
| $x_4$ | $t_1+3\pi/2 \in (3\pi/2,2\pi)$ | IV | $(\sin t_1,\; -b\cos t_1)$ — $x>
0,\, y<0$ |

Since $b>0$ and $t_1 \in (0,\pi/2)$, none of the coordinates is zero, so each po
int lies strictly in its respective quadrant. Four points in four distinct quadr
ants are necessarily distinct. (Equivalently, the parametrization $c(t)=(\cos t,
 b\sin t)$ is injective on $[0,2\pi)$ for $b>0$, and the four $t$-values are dis
tinct modulo $2\pi$.)

**Counting limit points.**

The sequence takes values only in $\{x_1, x_2, x_3, x_4\}$, and each value appea
rs infinitely often (at indices $i \equiv 1,2,3,4 \pmod{4}$ respectively). There
fore:

- Each $x_j$ ($j=1,2,3,4$) is a **limit point**: every neighborhood of $x_j$ con
tains $x_j$ itself infinitely many times.
- No other point is a limit point, since the sequence never takes any other valu
e.

**Conclusion.** The sequence $\{x_n\}$ has exactly **4 limit points**, namely $x
_1, x_2, x_3, x_4$.
