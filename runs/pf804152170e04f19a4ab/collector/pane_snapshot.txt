## Solution

We compute $E[(be^{-X}-a)^+]$ where $X \sim \mathcal{N}(0,1)$, $a > 0$, $b < 0$.

**Key observation.** Since $b < 0$ and $e^{-X} > 0$ for every real $X$, we have
$$be^{-X} < 0 \quad \text{for all } X \in \mathbb{R}.$$

Therefore
$$be^{-X} - a < 0 - a = -a < 0 \quad \text{for all } X \in \mathbb{R},$$
using the hypothesis $a > 0$.

**Conclusion.** The random variable $be^{-X} - a$ is strictly negative almost su
rely (in fact, surely). Hence its positive part vanishes identically:
$$(be^{-X} - a)^+ = \max(be^{-X} - a,\, 0) = 0 \quad \text{a.s.}$$

Taking expectations,
$$E[(be^{-X}-a)^+] = E[0] = 0.$$
