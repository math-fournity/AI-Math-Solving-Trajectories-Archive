# Problem

A specialized architectural firm is constructing a geometric sculpture by applying a recursive expansion process to a base structure. The project begins with a blueprint featuring two foundational anchor points positioned at coordinates (0, 0) and (2, 0) on a two-dimensional construction grid.

The architects use a specific "Expansion Protocol" to grow the sculpture. In each step of the protocol, every existing anchor point $(x, y)$ in the current set is replaced by two new points derived from its coordinates. Specifically, for every point $(x, y)$, the expansion generates the following pair of new coordinates:
1. $(x - y, x + y)$
2. $(x + y, y - x)$

This transformation is applied simultaneously to all points in the set to create the next stage of the sculpture. If multiple points result in the same coordinate location, they are treated as a single structural anchor.

If the firm repeats this Expansion Protocol exactly 14 times, starting from the original two anchor points, how many unique anchor points will be in the final set?
