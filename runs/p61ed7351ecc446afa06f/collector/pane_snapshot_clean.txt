## 解答

我们计算 $I = \mathrm{PV}\!\int_{-\infty}^{\infty}\frac{\cos^3 x}{x^3}\,dx$（在
$x=0$ 处取 Cauchy 主值，因为被积函数有一个三阶奇点）。

### 步骤 1. 三角恒等式化简

利用 $\cos^3 x = \dfrac{3\cos x + \cos 3x}{4}$：

$$I = \frac{3}{4}\,\mathrm{PV}\!\int_{-\infty}^{\infty}\frac{\cos x}{x^3}\,dx \;
+\; \frac{1}{4}\,\mathrm{PV}\!\int_{-\infty}^{\infty}\frac{\cos 3x}{x^3}\,dx.$$

只需证明对所有 $a>0$ 有 $\mathrm{PV}\!\int_{-\infty}^{\infty}\frac{\cos(ax)}{x^3
}\,dx = 0$。

### 步骤 2. 围道设置

固定 $a>0$，考虑 $f(z)=\dfrac{e^{iaz}}{z^3}$，在 $z=0$ 处有三阶极点。

取正向围道 $C$：
- 实轴段 $[-R,-\varepsilon]$，
- 小半圆 $C_\varepsilon:\ z=\varepsilon e^{i\theta},\ \theta:\pi\to 0$（上半平面
，顺时针），
- 实轴段 $[\varepsilon, R]$，
- 大半圆 $C_R:\ z=Re^{i\theta},\ \theta:0\to\pi$（上半平面）。

极点 $z=0$ 在围道**外部**，故由 Cauchy 定理：

$$\oint_C f(z)\,dz = 0.$$

### 步骤 3. 大半圆估计

$z=Re^{i\theta},\ \theta\in[0,\pi]$ 时 $\operatorname{Im}z\ge 0$，故 $|e^{iaz}|=
e^{-a\,\operatorname{Im}z}\le 1$。由 Jordan 引理（$a>0$）：

$$\left|\int_{C_R}\frac{e^{iaz}}{z^3}\,dz\right| \le \frac{\pi R}{R^3} = \frac{\
pi}{R^2}\;\xrightarrow{R\to\infty}\;0.$$

### 步骤 4. 小半圆——取实部

参数化 $C_\varepsilon$：

$$\int_{C_\varepsilon}f\,dz = \frac{i}{\varepsilon^2}\int_{\pi}^{0}e^{-2i\theta}
\,e^{ia\varepsilon e^{i\theta}}\,d\theta.$$

展开 $e^{ia\varepsilon e^{i\theta}} = 1 + ia\varepsilon e^{i\theta} - \dfrac{a^2
\varepsilon^2}{2}e^{2i\theta} + O(\varepsilon^3)$，逐项积分：

- **第一项**：$\dfrac{i}{\varepsilon^2}\displaystyle\int_{\pi}^{0}e^{-2i\theta}\
,d\theta = \dfrac{i}{\varepsilon^2}\cdot\frac{e^{-2i\theta}}{-2i}\bigg|_{\pi}^{0
} = \frac{-1}{2\varepsilon^2}(1-e^{-2i\pi})=0.$

- **第二项**：$\dfrac{-a}{\varepsilon}\displaystyle\int_{\pi}^{0}e^{-i\theta}\,d
\theta = \dfrac{-a}{\varepsilon}\cdot\frac{e^{-i\theta}}{-i}\bigg|_{\pi}^{0} = \
dfrac{-a}{\varepsilon}\cdot\frac{2}{-i} = \dfrac{-2ia}{\varepsilon}$（纯虚）。

- **第三项**：$\dfrac{i}{\varepsilon^2}\!\left(-\dfrac{a^2\varepsilon^2}{2}\righ
t)\!\displaystyle\int_{\pi}^{0}d\theta = \dfrac{-ia^2}{2}\cdot(-\pi)=\dfrac{i\pi
 a^2}{2}$（纯虚）。

因此

$$\operatorname{Re}\!\left(\int_{C_\varepsilon}f\,dz\right) = O(\varepsilon)\;\x
rightarrow{\varepsilon\to 0}\;0.$$

关键点：三阶极点的小半圆积分虽然整体发散（含 $1/\varepsilon$ 项），但发散部分**
全部是纯虚的**，实部仍然趋于零。

### 步骤 5. 取实部并取极限

由 $\oint_C = 0$ 取实部，令 $R\to\infty$、$\varepsilon\to 0$：

$$\mathrm{PV}\!\int_{-\infty}^{\infty}\frac{\cos(ax)}{x^3}\,dx \;+\; \lim_{\vare
psilon\to 0}\operatorname{Re}\!\left(\int_{C_\varepsilon}f\,dz\right) \;+\; \lim
_{R\to\infty}\operatorname{Re}\!\left(\int_{C_R}f\,dz\right) = 0.$$

由步骤 3、4，后两项为零，故

$$\mathrm{PV}\!\int_{-\infty}^{\infty}\frac{\cos(ax)}{x^3}\,dx = 0,\qquad \foral
l\, a>0.$$

### 步骤 6. 结论

$$I = \frac{3}{4}\cdot 0 + \frac{1}{4}\cdot 0 = 0.$$

**注.** 此结果与初等观察一致：$\dfrac{\cos(ax)}{x^3}$ 是 $x$ 的奇函数（偶/奇 =
奇），故其关于对称区间 $(-\infty,\infty)$ 的 Cauchy 主值为零。复分析计算独立地确
认了这一点——三阶极点缩进积分的发散部分全部是纯虚的，使得实部（即余弦积分）恰好为
零。

$$\boxed{\displaystyle\int_{-\infty}^{\infty}\frac{\cos^3 x}{x^3}\,dx = 0.}$$
