## Proof

We compute $\mathbb{E}[\tilde{X}_t]$ for the process
$$\tilde{X}_t = (1-t)\int_0^t \frac{1}{1-s}\,dW_s, \quad 0 \le t < 1, \qquad \ti
lde{X}_1 = 0.$$

**Step 1: Verify the Itô integral is well-defined.**

The integrand is the deterministic function $f(s) = \frac{1}{1-s}$ for $s \in [0
,t]$ with $t < 1$. For the Itô integral $\int_0^t f(s)\,dW_s$ to be well-defined
 (as an $L^2$ martingale), we need
$$\int_0^t f(s)^2\,ds = \int_0^t \frac{1}{(1-s)^2}\,ds < \infty.$$

Computing directly,
$$\int_0^t \frac{1}{(1-s)^2}\,ds = \left[\frac{1}{1-s}\right]_0^t = \frac{1}{1-t
} - 1 = \frac{t}{1-t} < \infty \quad \text{for } t < 1.$$

Hence $f \in L^2([0,t])$ for every $t < 1$, and the Itô integral $M_t := \int_0^
t \frac{1}{1-s}\,dW_s$ is a well-defined square-integrable martingale with respe
ct to the Brownian filtration $(\mathcal{F}_t)$.

**Step 2: Apply the martingale property.**

A fundamental property of the Itô integral with a deterministic (hence adapted,
square-integrable) integrand is that it is a martingale starting at $0$. In part
icular,
$$\mathbb{E}[M_t] = \mathbb{E}[M_0] = \mathbb{E}\!\left[\int_0^0 \frac{1}{1-s}\,
dW_s\right] = 0.$$

This follows because the Itô integral of an $L^2$ integrand has zero expectation
: by construction as an $L^2$-limit of elementary (Riemann-type) stochastic sums
, each of which is a sum of independent, mean-zero Gaussian increments $\Delta W
_{s_i}$ weighted by $\mathcal{F}_{s_i}$-measurable (here deterministic) coeffici
ents, and the $L^2$-limit preserves the zero-mean property.

**Step 3: Compute $\mathbb{E}[\tilde{X}_t]$.**

For $0 \le t < 1$,
$$\mathbb{E}[\tilde{X}_t] = \mathbb{E}\!\left[(1-t)\int_0^t \frac{1}{1-s}\,dW_s\
right] = (1-t)\,\mathbb{E}[M_t] = (1-t)\cdot 0 = 0.$$

For $t = 1$, by definition $\tilde{X}_1 = 0$, so
$$\mathbb{E}[\tilde{X}_1] = \mathbb{E}[0] = 0.$$

**Conclusion.**

$$\boxed{\mathbb{E}[\tilde{X}_t] = 0 \quad \text{for all } 0 \le t \le 1.}$$

*Remark.* This is consistent with the interpretation of $\tilde{X}_t$ as a Brown
ian bridge from $0$ to $0$ on $[0,1]$: it is a continuous Gaussian martingale-de
rived process with identically zero mean. The factor $(1-t)$ precisely counterac
ts the blow-up of the integrand $\frac{1}{1-s}$ as $s \to 1^-$, yielding $\tilde
{X}_t \to 0$ almost surely as $t \to 1^-$, which justifies the continuous extens
ion $\tilde{X}_1 = 0$.
