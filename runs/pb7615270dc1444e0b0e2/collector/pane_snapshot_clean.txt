## Counterexample

Let $p$ be a prime, and let $K = \mathbb{F}_p(s,t)$ be the rational function fie
ld in two algebraically independent variables over $\mathbb{F}_p$. Set
$$a_1 = s^{1/p}, \qquad a_2 = t^{1/p},$$
taken in some algebraic closure of $K$, and choose $c_1 = c_2 = 1$.

### Step 1. $a_1, a_2$ are non-zero and $K$-linearly independent.

They are clearly non-zero. Suppose $\alpha a_1 + \beta a_2 = 0$ with $\alpha, \b
eta \in K$. If $\beta \neq 0$, then
$$\frac{\alpha}{\beta} = -\frac{t^{1/p}}{s^{1/p}} = -\left(\frac{t}{s}\right)^{1
/p}.$$
Raising to the $p$-th power gives $(\alpha/\beta)^p = t/s$. But $t/s$ is **not**
 a $p$-th power in $\mathbb{F}_p(s,t)$: writing $t/s = (f/g)^p$ with $f,g \in \m
athbb{F}_p[s,t]$ would give $t g^p = s f^p$, which is impossible since $s$ and $
t$ are independent variables (the $s$-adic and $t$-adic valuations don't match).
 Hence $\beta = 0$, and then $\alpha = 0$. So $a_1, a_2$ are $K$-linearly indepe
ndent.

### Step 2. $[a_1, a_2] : K] = p^2$.

The polynomial $x^p - s$ is irreducible over $K$ (since $s$ is not a $p$-th powe
r in $K$), so $[a_1]:K] = p$. Over $K[a_1] = \mathbb{F}_p(s^{1/p}, t)$, the el
ement $t$ is still not a $p$-th power (it remains an independent variable), so $
x^p - t$ is irreducible over $K[a_1]$, giving $[a_1,a_2]:K[a_1]] = p$. Therefo
re
$$[a_1,a_2]:K] = p^2.$$

### Step 3. $K[a_1 + a_2] \neq K[a_1, a_2]$.

Let $\theta = a_1 + a_2 = s^{1/p} + t^{1/p}$. Then
$$\theta^p = (s^{1/p})^p + (t^{1/p})^p = s + t \in K,$$
where we used that we are in characteristic $p$ (the Frobenius is additive). Hen
ce $\theta$ is a root of $x^p - (s+t) \in K[x]$, so
$$[\theta]:K] \leq p.$$
Since $p < p^2 = [a_1,a_2]:K]$, we have
$$K[\theta] = K[c_1 a_1 + c_2 a_2] \subsetneq K[a_1, a_2].$$

### Conclusion

With $K = \mathbb{F}_p(s,t)$, $a_1 = s^{1/p}$, $a_2 = t^{1/p}$ (which are non-ze
ro and $K$-linearly independent), and $c_1 = c_2 = 1 \in K^\times$, the extensio
n $K[c_1 a_1 + c_2 a_2]$ has degree $\leq p$ over $K$, while $K[a_1, a_2]$ has d
egree $p^2$. Thus
$$K[c_1 a_1 + c_2 a_2] \neq K[a_1, a_2].$$

The answer is **yes, it is possible**. The obstruction is inseparability: the pr
imitive element theorem guarantees that a *generic* linear combination generates
 the whole extension only under the separability hypothesis. In the purely insep
arable case above, *every* $K$-linear combination $c_1 a_1 + c_2 a_2$ has $p$-th
 power in $K$ (since $(c_1 a_1 + c_2 a_2)^p = c_1^p s + c_2^p t \in K$), so $K[c
_1 a_1 + c_2 a_2]$ always has degree $\leq p$ over $K$ and can never equal the d
egree-$p^2$ extension $K[a_1, a_2]$.
