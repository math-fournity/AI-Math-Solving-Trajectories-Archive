**Setup.** On $H = L^2[0,1]$, write $A = I - K$ where
$$(Kx)(t) = \tfrac{1}{2}\int_0^1 x(s)\,ds = \tfrac{1}{2}\langle x,\mathbf{1}\ran
gle\,\mathbf{1}(t),$$
with $\mathbf{1}$ the constant function. $K$ is a self-adjoint rank-one operator
.

**Eigenstructure of $K$.** $K\mathbf{1} = \tfrac{1}{2}\langle\mathbf{1},\mathbf{
1}\rangle\mathbf{1} = \tfrac{1}{2}\mathbf{1}$, so $\mathbf{1}$ is an eigenvector
 with eigenvalue $\lambda = \tfrac{1}{2}$. Every $x\perp\mathbf{1}$ (zero-mean)
satisfies $Kx=0$. Hence
$$\sigma(K)=\{0,\tfrac12\}.$$

**Invertibility of $A$.** $\sigma(A)=\{1-\lambda:\lambda\in\sigma(K)\}=\{1,\tfra
c12\}$, so $0\notin\sigma(A)$ and $A^{-1}$ exists (bounded, since $A$ is self-ad
joint).

**Explicit inverse.** Compute $K^2$:
$$K^2 x = K\!\left(\tfrac12\langle x,\mathbf1\rangle\mathbf1\right)=\tfrac12\lan
gle x,\mathbf1\rangle\,K\mathbf1=\tfrac12\langle x,\mathbf1\rangle\cdot\tfrac12\
mathbf1=\tfrac12\,Kx,$$
so $K^2=\tfrac12 K$. The Neumann series converges (since $\|K\|=\tfrac12<1$):
$$(I-K)^{-1}=I+K+K^2+\cdots=I+K(1+\tfrac12+\tfrac14+\cdots)=I+2K.$$
Verification: $(I-K)(I+2K)=I+2K-K-2K^2=I+K-2\cdot\tfrac12 K=I$. ✓

Thus
$$(A^{-1}x)(t)=x(t)+\int_0^1 x(s)\,ds.$$

**Spectrum of $A^{-1}$.** $A^{-1}=I+2K$ is self-adjoint, with eigenvalues
- on $\operatorname{span}\{\mathbf1\}$: $1+2\cdot\tfrac12 = 2$,
- on $\mathbf1^\perp$: $1+2\cdot 0 = 1$.

So $\sigma(A^{-1})=\{1,2\}$.

**Norm.** For a self-adjoint (indeed normal) operator on a Hilbert space, the op
erator norm equals the spectral radius:
$$\|A^{-1}\|=\max_{\lambda\in\sigma(A^{-1})}|\lambda|=\max\{1,2\}=2.$$

**Direct confirmation of the lower bound.** Taking $x=\mathbf1$ (unit vector sin
ce $\|\mathbf1\|_2=1$):
$$\|A^{-1}\mathbf1\|_2=\|2\,\mathbf1\|_2=2\|\mathbf1\|_2=2,$$
so $\|A^{-1}\|\ge 2$. Combined with the spectral-radius upper bound $\|A^{-1}\|\
le 2$, equality holds.
