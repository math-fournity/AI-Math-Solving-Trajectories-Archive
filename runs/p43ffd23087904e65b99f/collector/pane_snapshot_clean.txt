The problem: If κ is an inaccessible cardinal, determine whether every function
f: α → κ is bounded for all α < κ.

Let me think about this carefully.

An inaccessible cardinal κ is an uncountable, regular, strong limit cardinal.

- Regular: cf(κ) = κ, meaning no set of size < κ cofinal in κ.
- Strong limit: for all λ < κ, 2^λ < κ.

The question: for every α < κ and every function f: α → κ, is f bounded (i.e.,
sup of range < κ)?

Since α < κ and κ is regular, the range of f has cardinality ≤ |α| < κ. If f
were unbounded in κ, then the range would be a cofinal subset of κ of size ≤ |α|
< κ, which would mean cf(κ) ≤ |α| < κ, contradicting regularity of κ.

So yes, every such f is bounded. This follows directly from regularity of κ.

Let me write the proof.

Proof

Claim: If $\kappa$ is an inaccessible cardinal, then every function $f:
\alpha\to\kappa$ is bounded (i.e., $\sup f[\alpha]<\kappa$) for all $
\alpha<\kappa$.

Answer: Yes, every such function is bounded.

Recall that an inaccessible cardinal $\kappa$ is, in particular, an uncountable
regular strong limit cardinal. The key property we need is regularity:

$$\operatorname{cf}(\kappa)=\kappa.$$

Equivalently, $\kappa$ is regular iff every cofinal subset $C\subseteq\kappa$
has cardinality $|C|=\kappa$, i.e., no subset of $\kappa$ of size $<\kappa$ is
cofinal in $\kappa$.

────────────────────────────────────────────────────────────────────────────────

Proof. Let $\alpha<\kappa$ and let $f:\alpha\to\kappa$ be any function. Consider
the range (image) of $f$:

$$R := f[\alpha] = {f(\xi):\xi<\alpha}\subseteq\kappa.$$

Since $|\alpha|<\kappa$, we have $|R|\le|\alpha|<\kappa$.

Suppose, for contradiction, that $f$ is unbounded in $\kappa$, i.e., $\sup
R=\kappa$. Then $R$ is a cofinal subset of $\kappa$ (for every $\beta<\kappa$
there exists $\xi<\alpha$ with $f(\xi)\ge\beta$, so $\sup R=\kappa$). But $|R|
<\kappa$, which means $\kappa$ has a cofinal subset of size $<\kappa$, i.e.,

$$\operatorname{cf}(\kappa)\le|R|<\kappa.$$

This contradicts the regularity of $\kappa$ ($\operatorname{cf}
(\kappa)=\kappa$).

Therefore $f$ must be bounded: $\sup f[\alpha]<\kappa$. $\blacksquare$

────────────────────────────────────────────────────────────────────────────────

Remark. Only regularity of $\kappa$ is needed; the strong limit property is not
used here. In fact, the statement "every $f:\alpha\to\kappa$ with $
\alpha<\kappa$ is bounded" is equivalent to $\kappa$ being regular. The strong
limit condition (the other ingredient of inaccessibility) is what makes $\kappa$
a model-theoretically significant closure point (e.g.,
$V_\kappa\models\mathsf{ZFC}$), but it is regularity alone that guarantees the
boundedness of all small-domain functions into $\kappa$.
