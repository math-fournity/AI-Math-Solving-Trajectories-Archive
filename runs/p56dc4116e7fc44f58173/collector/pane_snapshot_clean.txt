## Proof

Let $f_n(z) = \sum_{k=0}^{n-1}(n-k)z^k = n + (n-1)z + \cdots + z^{n-1}$.

**Key identity.** We compute $(1-z)f_n(z)$ by telescoping:

$$(1-z)f_n(z) = \sum_{k=0}^{n-1}(n-k)z^k - \sum_{k=0}^{n-1}(n-k)z^{k+1}.$$

The constant term is $n$. For $1 \leq k \leq n-1$, the coefficient of $z^k$ is $
(n-k)-(n-k+1) = -1$. The coefficient of $z^n$ is $-(n-n+1) = -1$. Therefore:

$$(1-z)f_n(z) = n - \sum_{k=1}^{n} z^k. \tag{$\ast$}$$

We now show $f_n(z) \neq 0$ for all $|z| \leq 1$ by considering three cases.

---

**Case 1: $|z| < 1$.**

By the reverse triangle inequality applied to $(\ast)$:

$$|(1-z)f_n(z)| = \left|n - \sum_{k=1}^{n} z^k\right| \geq n - \left|\sum_{k=1}^
{n} z^k\right| \geq n - \sum_{k=1}^{n} |z|^k.$$

Since $|z| < 1$, we have $|z|^k < 1$ for every $k \geq 1$, so $\sum_{k=1}^{n}|z|
^k < n$. Thus:

$$|(1-z)f_n(z)| > n - n = 0.$$

Since $|z| < 1$ implies $1 - z \neq 0$, we conclude $f_n(z) \neq 0$.

---

**Case 2: $|z| = 1$, $z \neq 1$.**

Since $|z| = 1$:

$$\left|\sum_{k=1}^{n} z^k\right| = |z|\cdot|1 + z + z^2 + \cdots + z^{n-1}| = |
1 + z + z^2 + \cdots + z^{n-1}|.$$

By the triangle inequality:

$$|1 + z + z^2 + \cdots + z^{n-1}| \leq \sum_{k=0}^{n-1}|z^k| = n,$$

with equality if and only if all the complex numbers $1, z, z^2, \ldots, z^{n-1}
$ share the same argument. Since $1$ has argument $0$, equality requires $\arg(z
) = 0$ (from the term $z$), so $z$ is real and positive. Combined with $|z| = 1$
, this forces $z = 1$, contradicting our hypothesis. Therefore:

$$\left|\sum_{k=1}^{n} z^k\right| < n.$$

Applying the reverse triangle inequality to $(\ast)$:

$$|(1-z)f_n(z)| \geq n - \left|\sum_{k=1}^{n} z^k\right| > 0.$$

Since $z \neq 1$, we have $1 - z \neq 0$, so $f_n(z) \neq 0$.

---

**Case 3: $z = 1$.**

$$f_n(1) = n + (n-1) + (n-2) + \cdots + 1 = \frac{n(n+1)}{2} \neq 0.$$

---

**Conclusion.** In every case, $f_n(z) \neq 0$ for $|z| \leq 1$. Therefore $f_n$
 has no roots in the closed unit disk $\{z \in \mathbb{C} : |z| \leq 1\}$. $\bla
cksquare$
