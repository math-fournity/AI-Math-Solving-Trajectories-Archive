## Proof

The problem asks for the expression of $\nabla g$ when the connection $\nabla$ i
s metric preserving. By definition, a connection is **metric preserving** precis
ely when the covariant derivative of the metric tensor vanishes identically:

$$\nabla g = 0.$$

Let me make this fully explicit in local coordinates.

**Setup.** On a smooth manifold $M$ with local coordinates $\{x^i\}$, the metric
 is the symmetric $(0,2)$-tensor

$$g = g_{ij}\,(dx^i \otimes dx^j + dx^j \otimes dx^i),$$

where $g_{ij} = g_{ji}$ are the components of the metric. A connection $\nabla$
on $M$ has Christoffel symbols $\Gamma^k_{ij}$ defined by $\nabla_{\partial_i}\p
artial_j = \Gamma^k_{ij}\partial_k$.

**Covariant derivative of a $(0,2)$-tensor.** For any $(0,2)$-tensor $T = T_{ij}
\,dx^i\otimes dx^j$, the covariant derivative $\nabla T$ is the $(0,3)$-tensor w
ith components

$$(\nabla_k T)_{ij} = \partial_k T_{ij} - \Gamma^l_{ki}\,T_{lj} - \Gamma^l_{kj}\
,T_{il}.$$

Each lower index of $T$ picks up a correction term $-\Gamma^l_{k\cdot}T_{l\cdot}
$.

**Applying to $g$.** Since $g$ is symmetric, $g_{ij} = g_{ji}$, and the covarian
t derivative respects the tensorial (linear) structure, we compute:

$$(\nabla_k g)_{ij} = \partial_k g_{ij} - \Gamma^l_{ki}\,g_{lj} - \Gamma^l_{kj}\
,g_{il}.$$

**Metric-preserving condition.** The connection $\nabla$ is *metric preserving*
(or *compatible with $g$*) by definition when

$$\nabla g \equiv 0,$$

i.e., for the Levi-Civita connection (the unique torsion-free metric-compatible
connection), the above expression vanishes for all indices:

$$(\nabla_k g)_{ij} = \partial_k g_{ij} - \Gamma^l_{ki}\,g_{lj} - \Gamma^l_{kj}\
,g_{il} = 0, \qquad \forall\, i,j,k.$$

**Conclusion.** When $\nabla$ is metric preserving, the covariant derivative of
the metric is identically zero. In full coordinate form:

$$\boxed{\nabla g = 0, \qquad\text{i.e.,}\qquad (\nabla_k g)_{ij} = \partial_k g
_{ij} - \Gamma^l_{ki}\,g_{lj} - \Gamma^l_{kj}\,g_{il} = 0 \;\;\forall\, i,j,k.}$
$

This is precisely the condition that defines metric compatibility: the parallel
transport induced by $\nabla$ preserves inner products, so the metric is covaria
ntly constant.
