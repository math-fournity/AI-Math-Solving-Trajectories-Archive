## Solution

The three internal angles of a triangle sum to 180°, so:

$$(5x+3y) + (3x+20) + (10y+30) = 180$$

$$8x + 13y + 50 = 180$$

$$8x + 13y = 130$$

We need positive integers $x, y$ satisfying $8x + 13y = 130$.

**Solving the linear congruence.** Rearranging, $8x = 130 - 13y$, so we need $13
0 - 13y > 0$ and $8 \mid (130 - 13y)$.

Reducing modulo 8:
$$13y \equiv 130 \pmod{8}$$
$$5y \equiv 2 \pmod{8}$$

Multiplying both sides by $5$ (since $5 \cdot 5 = 25 \equiv 1 \pmod{8}$):
$$y \equiv 10 \equiv 2 \pmod{8}$$

So $y = 2, 10, 18, \ldots$

**Testing candidates:**

- $y = 2$: $8x = 130 - 26 = 104 \Rightarrow x = 13$. Both positive. ✓
- $y = 10$: $8x = 130 - 130 = 0 \Rightarrow x = 0$. Not a positive integer. ✗
- $y \geq 10$: $13y \geq 130$, so $x \leq 0$. ✗

**Verification** of the unique solution $(x, y) = (13, 2)$:
- $(5x+3y) = 65 + 6 = 71°$
- $(3x+20) = 39 + 20 = 59°$
- $(10y+30) = 20 + 30 = 50°$
- Sum: $71 + 59 + 50 = 180°$ ✓
- All three angles are positive and strictly between $0°$ and $180°$, so they fo
rm a valid triangle. ✓

Therefore:

$$x + y = 13 + 2 = 15$$

The only value that $x + y$ can take is $\boxed{15}$.
