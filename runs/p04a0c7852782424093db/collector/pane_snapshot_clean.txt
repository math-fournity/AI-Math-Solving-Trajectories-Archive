# Solution

## Setup

Let $\mathcal{C} \cong [3]$ be the category associated to the poset $\{0 \leq 1
\leq 2 \leq 3\}$: four objects, with a unique morphism $i \to j$ whenever $i \le
q j$. We work in the functor category $\mathbf{Set}^{\mathcal{C}}$ (covariant fu
nctors $\mathcal{C} \to \mathbf{Set}$).

The representable functor $Y_0 = \mathrm{Hom}_{\mathcal{C}}(0, -) : \mathcal{C}
\to \mathbf{Set}$ is:

$$Y_0(i) = \mathrm{Hom}(0, i) = \begin{cases} \{*\} & \text{if } 0 \leq i \ (\te
xt{i.e., all } i \in \{0,1,2,3\}) \\ \emptyset & \text{otherwise.} \end{cases}$$

So $Y_0(i) = \{*\}$ for every $i$, and every transition map $Y_0(i \leq j): \{*\
} \to \{*\}$ is the identity on the singleton.

## Sub-instances (subfunctors) of $Y_0$

A subfunctor $S \hookrightarrow Y_0$ assigns to each $i$ a subset $S(i) \subsete
q Y_0(i) = \{*\}$, so $S(i) \in \{\emptyset, \{*\}\}$, subject to the subfunctor
 condition: for every $i \leq j$,

$$x \in S(i) \implies Y_0(i \leq j)(x) \in S(j).$$

Since $Y_0(i \leq j)$ maps $* \mapsto *$, this becomes:

$$S(i) = \{*\} \implies S(j) = \{*\} \quad \text{whenever } i \leq j.$$

Thus the set $I_S = \{i : S(i) = \{*\}\} \subseteq \{0,1,2,3\}$ must be **upward
 closed**: $i \in I_S$ and $i \leq j$ implies $j \in I_S$.

The upward-closed subsets of the chain $0 \leq 1 \leq 2 \leq 3$ are exactly:

| $I_S$ | Subfunctor $S$ | Label |
|---|---|---|
| $\{0,1,2,3\}$ | $S(i) = \{*\}$ for all $i$ (i.e. $S = Y_0$) | **yes** |
| $\{1,2,3\}$ | $S(0) = \emptyset$; $S(1)=S(2)=S(3)=\{*\}$ | **in 1** |
| $\{2,3\}$ | $S(0)=S(1)=\emptyset$; $S(2)=S(3)=\{*\}$ | **in 2** |
| $\{3\}$ | $S(0)=S(1)=S(2)=\emptyset$; $S(3)=\{*\}$ | **in 3** |
| $\emptyset$ | $S(i) = \emptyset$ for all $i$ (empty subfunctor) | **never** |

There are exactly **5** sub-instances of $Y_0$.

## The subobject classifier $\Omega_{\mathcal{C}}(0)$

In the topos $\mathbf{Set}^{\mathcal{C}}$, the subobject classifier $\Omega$ is
the functor assigning to each $c$ the set of **cosieves on $c$** (subsets of mor
phisms out of $c$, closed under postcomposition). Equivalently, $\Omega(c) \cong
 \{\text{subfunctors of } Y_c\}$, classified by the characteristic morphism.

For $c = 0$, a cosieve is a subset $Q \subseteq \{\mathrm{Hom}(0,j) : j \in \{0,
1,2,3\}\}$ such that $0 \to j \in Q$ and $j \leq k$ implies $0 \to k \in Q$. Ide
ntifying each morphism $0 \to j$ with its target $j$, a cosieve on $0$ is exactl
y an upward-closed subset of $\{0,1,2,3\}$. Hence:

$$\Omega_{\mathcal{C}}(0) = \big\{\ \{0,1,2,3\},\ \{1,2,3\},\ \{2,3\},\ \{3\},\
\emptyset\ \big\} = \{\text{yes, in 1, in 2, in 3, never}\}.$$

## The correspondence

Every subfunctor $S \hookrightarrow Y_0$ has a characteristic morphism $\chi_S :
 Y_0 \to \Omega$. Evaluating at $0$ gives

$$\chi_{S,0}(* ) \in \Omega_{\mathcal{C}}(0),$$

the "truth value of the unique element $* \in Y_0(0)$ belonging to $S$." This va
lue records **the earliest stage at which $*$ enters $S$**:

- $* \in S(0)$: the element is present from the source. $\chi_{S,0}(*) = $ **yes
** (maximal cosieve $\{0,1,2,3\}$).
- $* \notin S(0)$ but $* \in S(1)$: the element first appears at stage 1. $\chi_
{S,0}(*) = $ **in 1** (cosieve $\{1,2,3\}$).
- $* \notin S(0),S(1)$ but $* \in S(2)$: first appears at stage 2. $\chi_{S,0}(*
) = $ **in 2** (cosieve $\{2,3\}$).
- $* \notin S(0),S(1),S(2)$ but $* \in S(3)$: first appears at stage 3. $\chi_{S
,0}(*) = $ **in 3** (cosieve $\{3\}$).
- $* \notin S(i)$ for all $i$: never appears. $\chi_{S,0}(*) = $ **never** (empt
y cosieve).

This is a **bijection** between sub-instances of $Y_0$ and elements of $\Omega_{
\mathcal{C}}(0)$: the upward-closed set $I_S$ *is* the cosieve $\chi_{S,0}(*)$,
and conversely every cosieve on $0$ defines a unique upward-closed subset, hence
 a unique subfunctor.

## Intuition

$Y_0$ is "the instance generated by a single element born at stage $0$." A sub-i
nstance either **includes this element from birth** ("yes"), **adopts it at some
 later stage** $k \in \{1,2,3\}$ ("in $k$" — the element is absent before $k$ an
d present from $k$ onward, forced by upward closure), or **never includes it** (
"never" — the empty sub-instance). The five truth values in $\Omega_{\mathcal{C}
}(0)$ are precisely these five "adoption times" for the unique element of $Y_0(0
)$, and the Yoneda/characteristic-map correspondence makes this identification c
anonical.
