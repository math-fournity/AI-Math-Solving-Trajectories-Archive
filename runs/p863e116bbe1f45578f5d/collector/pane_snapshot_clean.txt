## 证明

我们要计算

$$L = \lim_{x\to 0} \frac{\sinh(x)}{\cos(x)-1} \int_{0}^{x} \sqrt{e^t-t^4} \, dt
.$$

**第一步：对被积函数在 $t=0$ 处进行展开。**

首先注意 $\sqrt{e^0 - 0^4} = \sqrt{1} = 1 > 0$，因此被积函数在 $0$ 附近是光滑的
，我们可以进行泰勒展开。

$$e^t = 1 + t + \tfrac{t^2}{2} + \tfrac{t^3}{6} + \tfrac{t^4}{24} + O(t^5),$$

$$e^t - t^4 = 1 + t + \tfrac{t^2}{2} + \tfrac{t^3}{6} - \tfrac{23}{24}t^4 + O(t^
5).$$

令 $u = t + \tfrac{t^2}{2} + \tfrac{t^3}{6} - \tfrac{23}{24}t^4 + O(t^5)$，应用
$\sqrt{1+u} = 1 + \tfrac{u}{2} - \tfrac{u^2}{8} + \tfrac{u^3}{16} - \tfrac{5u^4}
{128} + O(u^5)$：

- $t^1$ 项：$\tfrac{1}{2}$
- $t^2$ 项：$\tfrac{1}{4} - \tfrac{1}{8} = \tfrac{1}{8}$
- $t^3$ 项：$\tfrac{1}{12} - \tfrac{1}{8} + \tfrac{1}{16} = \tfrac{1}{48}$
- $t^4$ 项：$-\tfrac{23}{48} - \tfrac{7}{96} + \tfrac{3}{32} - \tfrac{5}{128} =
-\tfrac{191}{384}$

因此

$$\sqrt{e^t - t^4} = 1 + \tfrac{t}{2} + \tfrac{t^2}{8} + \tfrac{t^3}{48} - \tfra
c{191}{384}t^4 + O(t^5).$$

**第二步：对积分进行展开。**

逐项积分：

$$\int_0^x \sqrt{e^t - t^4}\,dt = x + \tfrac{x^2}{4} + \tfrac{x^3}{24} + \tfrac{
x^4}{192} + O(x^5).$$

**第三步：对分子 $\sinh(x)\cdot\int_0^x$ 进行展开。**

由于 $\sinh(x) = x + \tfrac{x^3}{6} + O(x^5)$，

$$\sinh(x)\int_0^x \sqrt{e^t-t^4}\,dt = \left(x + \tfrac{x^3}{6} + O(x^5)\right)
\left(x + \tfrac{x^2}{4} + \tfrac{x^3}{24} + O(x^4)\right).$$

$$= x^2 + \tfrac{x^3}{4} + \left(\tfrac{1}{24}+\tfrac{1}{6}\right)x^4 + O(x^5) =
 x^2 + \tfrac{x^3}{4} + \tfrac{5}{24}x^4 + O(x^5).$$

**第四步：对分母进行展开并计算极限。**

$$\cos x - 1 = -\tfrac{x^2}{2} + \tfrac{x^4}{24} + O(x^6) = x^2\!\left(-\tfrac{1
}{2} + O(x^2)\right).$$

因此

$$\frac{\sinh(x)\int_0^x \sqrt{e^t-t^4}\,dt}{\cos x - 1} = \frac{x^2\left(1 + \t
frac{x}{4} + O(x^2)\right)}{x^2\left(-\tfrac{1}{2} + O(x^2)\right)} = \frac{1 +
\tfrac{x}{4} + O(x^2)}{-\tfrac{1}{2} + O(x^2)}.$$

令 $x\to 0$：

$$L = \frac{1}{-1/2} = -2.$$

**合理性检验（主项）：** $\sinh x \sim x$，$\cos x - 1 \sim -x^2/2$，$\int_0^x \
sqrt{e^t-t^4}\,dt \sim \int_0^x 1\,dt = x$。因此 $\frac{x\cdot x}{-x^2/2} = -2$
，与完整展开结果一致。

$$\boxed{L = -2}$$
