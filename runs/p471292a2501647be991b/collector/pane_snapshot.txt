Looking at this problem, I need to find the curve minimizing $J = \int_0^{x_1} \
frac{\sqrt{1-y'^2}}{y}\,dx$ (with $y>0$, $|y'|\le 1$) joining the line $x=0$ to
$(x_1,y_1)$.

## Solution

**Euler–Lagrange equation.** The integrand $F(y,y')=\frac{\sqrt{1-y'^2}}{y}$ is
independent of $x$, so we apply the Beltrami identity $F - y'F_{y'} = C$.

Computing:
$$F_{y'} = \frac{-y'}{y\sqrt{1-y'^2}}$$

$$F - y'F_{y'} = \frac{\sqrt{1-y'^2}}{y} + \frac{y'^2}{y\sqrt{1-y'^2}} = \frac{1
-y'^2+y'^2}{y\sqrt{1-y'^2}} = \frac{1}{y\sqrt{1-y'^2}} = C$$

Setting $a = 1/C > 0$, the first integral is:
$$y\,\sqrt{1-y'^2} = a \quad\Longrightarrow\quad y^2(1-y'^2)=a^2. \tag{1}$$

**Parametric solution.** Set $y' = \sin\varphi$, so $\sqrt{1-y'^2}=\cos\varphi$
and (1) gives $y = a\sec\varphi$. Then:
$$\frac{dy}{d\varphi} = a\sec\varphi\tan\varphi, \qquad dx = \frac{dy}{y'} = \fr
ac{a\sec\varphi\tan\varphi\,d\varphi}{\sin\varphi} = a\sec^2\varphi\,d\varphi$$

Integrating: $x = a\tan\varphi + b$. Eliminating $\varphi$ via $a\tan\varphi = x
-b$ and $y = a\sec\varphi$:
$$y^2 = a^2\sec^2\varphi = a^2(1+\tan^2\varphi) = a^2 + (x-b)^2$$

$$\boxed{y^2 - (x-b)^2 = a^2} \tag{2}$$

This is a branch of a **hyperbola**.

**Transversality condition at $x=0$.** The left endpoint lies on the vertical li
ne $x=0$ with $y(0)$ free. The transversality condition for a free endpoint on a
 vertical line is $F_{y'}\big|_{x=0}=0$:
$$\frac{-y'(0)}{y(0)\sqrt{1-y'(0)^2}} = 0 \quad\Longrightarrow\quad y'(0)=0.$$

From (1) at $x=0$: $y(0)^2\cdot 1 = a^2$, so $y(0)=a$. Substituting into (2) at
$x=0$:
$$a^2 - b^2 = a^2 \quad\Longrightarrow\quad b=0.$$

So the extremal is $y^2 - x^2 = a^2$.

**Right endpoint condition.** Requiring $y(x_1)=y_1$:
$$y_1^2 - x_1^2 = a^2 \quad\Longrightarrow\quad a = \sqrt{y_1^2 - x_1^2}$$

(valid when $y_1 > x_1$; note $|y'| = |x|/y < 1$ automatically since $y^2 = x^2+
a^2 > x^2$).

**The extremal is:**
$$\boxed{y = \sqrt{x^2 + y_1^2 - x_1^2}\,,\qquad\text{i.e.,}\quad y^2 - x^2 = y_
1^2 - x_1^2.}$$

**Value of the functional.** On this curve, $y' = x/y$ and $\sqrt{1-y'^2} = a/y$
, so:
$$J = \int_0^{x_1}\frac{a}{y^2}\,dx = \int_0^{x_1}\frac{a}{x^2+a^2}\,dx = \arcta
n\!\left(\frac{x_1}{a}\right) = \arctan\!\frac{x_1}{\sqrt{y_1^2-x_1^2}} = \arcsi
n\!\frac{x_1}{y_1}.$$

**Nature of the extremum.** Since $F_{y'y'} = \frac{-1}{y(1-y'^2)^{3/2}} < 0$, t
he Legendre condition for a *minimum* is violated; the hyperbola is in fact a **
maximum** of $J$ among smooth admissible curves. The global minimum $J=0$ is att
ained by the straight line $y = x + (y_1 - x_1)$ (slope $y'=1$, giving $\sqrt{1-
y'^2}=0$), which is admissible when $y_1 > x_1$ (ensuring $y>0$ on $[0,x_1]$). T
he nontrivial extremal delivered by the Euler–Lagrange equation with the transve
rsality condition is the hyperbola arc above, which **maximizes** the functional
.
