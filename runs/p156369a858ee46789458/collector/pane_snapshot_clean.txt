## Proof

**Step 1: Simplify the integral.**

The integrand is
$$f_n(x) = \prod_{k=1}^n \frac{1}{2^{2^k}}\left(1-\frac{1}{2^{2^k}}\right),$$
which is a **constant** with respect to $x$ (no $x$ appears in any factor). Ther
efore:
$$\int_0^1 f_n(x)\,dx = \prod_{k=1}^n \frac{1}{2^{2^k}}\left(1-\frac{1}{2^{2^k}}
\right) =: P_n.$$

**Step 2: Express the $n$-th root via logarithms.**

We need $\lim_{n\to\infty} P_n^{1/n}$. Taking logarithms:
$$\ln\left(P_n^{1/n}\right) = \frac{1}{n}\sum_{k=1}^n \ln\!\left(\frac{1}{2^{2^k
}}\left(1-\frac{1}{2^{2^k}}\right)\right) = \frac{1}{n}\sum_{k=1}^n \Big[\underb
race{-2^k \ln 2}_{\text{Term A}} + \underbrace{\ln\!\left(1-2^{-2^k}\right)}_{\t
ext{Term B}}\Big].$$

**Step 3: Analyze Term A.**

$$\frac{1}{n}\sum_{k=1}^n (-2^k \ln 2) = -\frac{\ln 2}{n}\sum_{k=1}^n 2^k = -\fr
ac{\ln 2}{n}(2^{n+1}-2).$$

Since $2^{n+1}/n \to \infty$, this term $\to -\infty$.

**Step 4: Analyze Term B (show it is negligible).**

For $k \geq 1$, $0 < 2^{-2^k} \leq 2^{-2} = 1/4$. Using $\ln(1-t) \geq -2t$ for
$0 \leq t \leq 1/2$:
$$\ln\!\left(1-2^{-2^k}\right) \geq -2\cdot 2^{-2^k}.$$

Also $\ln(1-2^{-2^k}) \leq 0$. Therefore:
$$-\frac{2}{n}\sum_{k=1}^n 2^{-2^k} \leq \frac{1}{n}\sum_{k=1}^n \ln\!\left(1-2^
{-2^k}\right) \leq 0.$$

The series $\sum_{k=1}^\infty 2^{-2^k}$ converges (it is dominated by $\sum 2^{-
k}$), so $\sum_{k=1}^n 2^{-2^k} \leq C$ for some constant $C$. Hence:
$$-\frac{2C}{n} \leq \frac{1}{n}\sum_{k=1}^n \ln\!\left(1-2^{-2^k}\right) \leq 0
 \xrightarrow{n\to\infty} 0.$$

**Step 5: Combine.**

$$\ln\left(P_n^{1/n}\right) = \underbrace{-\frac{\ln 2}{n}(2^{n+1}-2)}_{\to\, -\
infty} + \underbrace{\frac{1}{n}\sum_{k=1}^n \ln\!\left(1-2^{-2^k}\right)}_{\to\
, 0} \;\longrightarrow\; -\infty.$$

Since $\ln(P_n^{1/n}) \to -\infty$, we conclude:
$$P_n^{1/n} = e^{\ln(P_n^{1/n})} \longrightarrow 0.$$
