## Proof

Let $f(x) = x^5 + x + 1 = \prod_{k=1}^{5}(x - x_k)$, where $x_1,\dots,x_5$ are t
he roots.

**Key factorization.** For each root $x_k$,
$$x_k^2 + 2 = (x_k - i\sqrt{2})(x_k + i\sqrt{2}),$$
since $(i\sqrt{2})^2 = -2$. Therefore
$$\prod_{k=1}^{5}(2 + x_k^2) = \prod_{k=1}^{5}(x_k - i\sqrt{2})\;\prod_{k=1}^{5}
(x_k + i\sqrt{2}).$$

**Relating to $f$.** Since $f(a) = \prod_{k=1}^{5}(a - x_k)$, we have
$$\prod_{k=1}^{5}(x_k - a) = (-1)^{5}\prod_{k=1}^{5}(a - x_k) = -f(a).$$

Applying this with $a = i\sqrt{2}$ and $a = -i\sqrt{2}$:
$$\prod_{k=1}^{5}(x_k - i\sqrt{2}) = -f(i\sqrt{2}), \qquad \prod_{k=1}^{5}(x_k +
 i\sqrt{2}) = -f(-i\sqrt{2}).$$

Hence
$$\prod_{k=1}^{5}(2+x_k^2) = \bigl(-f(i\sqrt{2})\bigr)\bigl(-f(-i\sqrt{2})\bigr)
 = f(i\sqrt{2})\,f(-i\sqrt{2}).$$

**Evaluating $f$ at $i\sqrt{2}$.** Using $(i\sqrt{2})^2 = -2$, so $(i\sqrt{2})^4
 = 4$ and $(i\sqrt{2})^5 = 4i\sqrt{2}$:
$$f(i\sqrt{2}) = 4i\sqrt{2} + i\sqrt{2} + 1 = 1 + 5i\sqrt{2}.$$

Similarly $( -i\sqrt{2})^5 = -4i\sqrt{2}$, so
$$f(-i\sqrt{2}) = -4i\sqrt{2} - i\sqrt{2} + 1 = 1 - 5i\sqrt{2}.$$

**Final computation.**
$$f(i\sqrt{2})\,f(-i\sqrt{2}) = (1 + 5i\sqrt{2})(1 - 5i\sqrt{2}) = 1 - (5i\sqrt{
2})^2 = 1 - (25)(-2) = 1 + 50 = 51.$$

Therefore
$$\prod_{k=1}^{5}(2 + x_k^2) = \boxed{51}.$$

### PROOF COMPLETE
