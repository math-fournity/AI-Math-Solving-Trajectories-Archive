# Problem

In a remote desert territory, a telecommunications company is planning to install a new network. There are exactly 998 isolated villages, which we can represent as distinct locations on a flat map such that no three villages lie on the same straight line.

The company's security protocol requires that for every possible set of three villages, a signal relay station must be positioned somewhere within the triangular region formed by those three villages. These relay stations can be placed at any location on the map.

The regional director needs to know the minimum number of relay stations, $k$, that must be commissioned to guarantee that this requirement is met, regardless of how the 998 villages are distributed across the territory.

Find the smallest $k$ such that for any configuration of the 998 villages, it is possible to place $k$ relay stations so that every triangle with villages as vertices contains at least one station.
