## Solution

We evaluate $I = \int_0^{2\pi} \log|1 - ae^{i\theta}|\,d\theta$ with $|a|=1$.

**Step 1: Reduce to a single canonical integral.**

Since $|a|=1$, write $a = e^{i\phi}$ for some $\phi\in\mathbb{R}$. Then
$$|1-ae^{i\theta}| = |1 - e^{i(\theta+\phi)}|.$$
By the $2\pi$-periodicity of the integrand, the substitution $\theta \mapsto \th
eta - \phi$ (mod $2\pi$) leaves the integral over $[0,2\pi]$ unchanged, so
$$I = \int_0^{2\pi} \log|1 - e^{i\theta}|\,d\theta.$$

**Step 2: Express the modulus explicitly.**

Using $1 - e^{i\theta} = e^{i\theta/2}(e^{-i\theta/2} - e^{i\theta/2}) = -2i\,e^
{i\theta/2}\sin(\theta/2)$, we get
$$|1 - e^{i\theta}| = 2\,|\sin(\theta/2)|.$$
Hence
$$I = \int_0^{2\pi} \log\!\big(2\,|\sin(\theta/2)|\big)\,d\theta = 2\pi\log 2 +
\int_0^{2\pi} \log|\sin(\theta/2)|\,d\theta.$$

(The integrand has a logarithmic singularity at $\theta=0$, but $\log|\sin(\thet
a/2)|\sim \log|\theta|/1$ near $0$, which is integrable, so $I$ is well-defined.
)

**Step 3: Evaluate the remaining integral.**

Substitute $u = \theta/2$, $d\theta = 2\,du$:
$$\int_0^{2\pi} \log|\sin(\theta/2)|\,d\theta = 2\int_0^{\pi} \log|\sin u|\,du =
 2\int_0^{\pi} \log(\sin u)\,du,$$
since $\sin u \ge 0$ on $[0,\pi]$.

We use the classical identity
$$\int_0^{\pi} \log(\sin u)\,du = -\pi\log 2.$$
*Proof of the identity:* Let $J = \int_0^{\pi}\log(\sin u)\,du$. By the substitu
tion $u\mapsto \pi - u$, also $J = \int_0^{\pi}\log(\sin u)\,du$ (no change). Us
ing $\sin u = 2\sin(u/2)\cos(u/2)$ and the substitution $v = u/2$ on each half,
or more directly via the standard argument:
$$J = \int_0^{\pi}\log(2\sin(u/2)\cos(u/2))\,du = \pi\log 2 + \int_0^{\pi}\log\s
in(u/2)\,du + \int_0^{\pi}\log\cos(u/2)\,du.$$
With $t = u/2$:
$$\int_0^{\pi}\log\sin(u/2)\,du = 2\int_0^{\pi/2}\log\sin t\,dt,\qquad \int_0^{\
pi}\log\cos(u/2)\,du = 2\int_0^{\pi/2}\log\cos t\,dt.$$
By $t\mapsto \pi/2 - t$, $\int_0^{\pi/2}\log\cos t\,dt = \int_0^{\pi/2}\log\sin
t\,dt$. Also $J = 2\int_0^{\pi/2}\log\sin t\,dt$ (splitting $[0,\pi]$ at $\pi/2$
 and substituting on $[\pi/2,\pi]$). Therefore
$$J = \pi\log 2 + J + J = \pi\log 2 + 2J \cdot \tfrac{1}{1} \;\;\Longrightarrow\
;\; -J = \pi\log 2 \;\;\Longrightarrow\;\; J = -\pi\log 2.$$
(More carefully: $J = \pi\log 2 + 2\int_0^{\pi/2}\log\sin t\,dt = \pi\log 2 + J$
, giving $J = -\pi\log 2$.) ∎

**Step 4: Combine.**

$$\int_0^{2\pi} \log|\sin(\theta/2)|\,d\theta = 2\cdot(-\pi\log 2) = -2\pi\log 2
.$$

Therefore
$$I = 2\pi\log 2 + (-2\pi\log 2) = 0.$$

## Result

$$\boxed{\int_0^{2\pi} \log|1-ae^{i\theta}|\,d\theta = 0 \quad\text{for } |a|=1.
}$$

This is consistent with Jensen's formula: for $|a|<1$ the integral equals $0$ (s
ince $z\mapsto 1-az$ has no zeros in $|z|\le 1$ and equals $1$ at $z=0$), and th
e value extends continuously to the boundary $|a|=1$ because the logarithmic sin
gularity at the single boundary zero is integrable.
