## Proof

**Setup.** The Upper Track is $y = x^2 + 2$ and the Lower Track is $y = -2 - x^2
$. We seek all lines $y = mx + b$ tangent to both parabolas simultaneously.

**Tangency to the Upper Track.** Substituting gives $x^2 + 2 = mx + b$, i.e. $x^
2 - mx + (2-b) = 0$. Tangency requires discriminant zero:

$$m^2 - 4(2-b) = 0 \implies b = 2 - \frac{m^2}{4}.$$

The tangent point is $x_1 = \frac{m}{2}$, $y_1 = x_1^2 + 2 = \frac{m^2}{4} + 2$.

**Tangency to the Lower Track.** Substituting gives $-2 - x^2 = mx + b$, i.e. $x
^2 + mx + (b+2) = 0$. Tangency requires:

$$m^2 - 4(b+2) = 0 \implies b = \frac{m^2}{4} - 2.$$

The tangent point is $x_2 = -\frac{m}{2}$, $y_2 = -2 - x_2^2 = -2 - \frac{m^2}{4
}$.

**Dual-tangency condition.** The same line must satisfy both expressions for $b$
:

$$2 - \frac{m^2}{4} = \frac{m^2}{4} - 2 \implies 4 = \frac{m^2}{2} \implies m^2
= 8.$$

So $m = \pm 2\sqrt{2}$, giving exactly **two** valid tangent lines.

**Computing the coordinates.** With $m^2 = 8$:

$$y_1 = \frac{8}{4} + 2 = 4, \qquad y_2 = -2 - \frac{8}{4} = -4.$$

$$x_1 = \frac{m}{2}, \qquad x_2 = -\frac{m}{2}.$$

**Sum of squares of slopes:**

$$\sum m^2 = 8 + 8 = 16.$$

**Sum of squares of coordinates (per line):**

$$x_1^2 + y_1^2 + x_2^2 + y_2^2 = \frac{m^2}{4} + 16 + \frac{m^2}{4} + 16 = \fra
c{m^2}{2} + 32 = \frac{8}{2} + 32 = 4 + 32 = 36.$$

Over both lines: $36 \times 2 = 72$.

**Final total:**

$$16 + 72 = \boxed{88}.$$
