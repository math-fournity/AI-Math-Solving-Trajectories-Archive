# Proof

**Answer: No, not necessarily.** Monotonicity alone does not force $\mathbb{T}$
to be finitary. A counterexample is the (covariant) power set functor.

---

## The Counterexample

Let $\mathbb{T} = \mathcal{P}$, the covariant power set functor on $\mathsf{Set}
$:

- On objects: $\mathcal{P}(X) = \{A \mid A \subseteq X\}$.
- On morphisms: for $f : X \to Z$, $\mathcal{P}(f) : \mathcal{P}(X) \to \mathcal
{P}(Z)$ sends $A \mapsto f[A]$ (direct image).

**$\mathcal{P}$ restricts to $\mathsf{FinSet}$.** If $X$ is finite, $\mathcal{P}
(X)$ is finite, and the direct image of a finite set under any function is finit
e. So $\mathcal{P}$ is an endofunctor on $\mathsf{FinSet}$.

**$\mathcal{P}$ is monotone.** If $Y \subseteq Z$ with inclusion $i : Y \hookrig
htarrow Z$, then $\mathcal{P}(i) : \mathcal{P}(Y) \to \mathcal{P}(Z)$ sends $A \
mapsto i[A] = A$, which is exactly the inclusion $\mathcal{P}(Y) \hookrightarrow
 \mathcal{P}(Z)$. Hence $Y \subseteq Z \implies \mathcal{P}(Y) \subseteq \mathca
l{P}(Z)$.

---

## The Directed Colimit Is Strictly Smaller

Let $X$ be an **infinite** set. The finite subsets $Y \subseteq X$ form a direct
ed poset under inclusion. By monotonicity, each $\mathcal{P}(Y) \subseteq \mathc
al{P}(X)$, and the bonding maps are inclusions, so the directed colimit in $\mat
hsf{Set}$ is the union:

$$\varinjlim_{Y \subseteq X \text{ finite}} \mathcal{P}(Y) \;=\; \bigcup_{Y \sub
seteq X \text{ finite}} \mathcal{P}(Y) \;=\; \{A \subseteq X \mid A \text{ is fi
nite}\} \;=\; [X]^{<\omega}.$$

Indeed, $A \in \mathcal{P}(Y)$ for some finite $Y$ iff $A \subseteq Y$ iff $A$ i
s finite.

But $\mathcal{P}(X)$ contains **infinite** subsets of $X$ (which exist since $X$
 is infinite). Therefore:

$$[X]^{<\omega} \;\subsetneq\; \mathcal{P}(X).$$

---

## Conclusion

For the monotone endofunctor $\mathcal{P}$ (which restricts to $\mathsf{FinSet}$
) and any infinite set $X$:

$$\varinjlim_{Y \subseteq X \text{ finite}} \mathbb{T}Y \;=\; [X]^{<\omega} \;\n
eq\; \mathcal{P}(X) \;=\; \mathbb{T}X.$$

The equality fails. Monotonicity guarantees $\bigcup_{Y} \mathbb{T}Y \subseteq \
mathbb{T}X$ (since each $\mathbb{T}Y \subseteq \mathbb{T}X$), but it does **not*
* guarantee the reverse inclusion. The reverse inclusion is precisely the condit
ion that $\mathbb{T}$ be **finitary** (i.e., preserve filtered colimits), which
is strictly stronger than monotonicity. $\blacksquare$
