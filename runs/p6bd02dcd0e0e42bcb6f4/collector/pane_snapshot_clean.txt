**Answer: Yes, a weakly closed graph is also closed in the strong topology.**

**Proof.**

Let $X, Y$ be Banach spaces and $T \colon X \to Y$ a linear operator with graph
$$\Gamma(T) = \{(x, Tx) \in X \times Y : x \in X\} \subseteq X \times Y.$$

Denote by $\tau_{\mathrm{wk}}$ the weak topology on $X \times Y$ (equivalently,
the product of the weak topologies $\sigma(X, X^*) \times \sigma(Y, Y^*)$, which
 coincides with $\sigma(X\times Y, (X\times Y)^*)$), and by $\tau_{\mathrm{st}}$
 the strong (norm) topology on $X \times Y$.

**Key topological fact.** The weak topology is coarser than the strong topology:
$$\tau_{\mathrm{wk}} \subseteq \tau_{\mathrm{st}}.$$
Indeed, every weakly open set is strongly open: the weak topology is the coarses
t topology making all bounded linear functionals continuous, and every bounded l
inear functional is continuous with respect to the norm topology, so the norm to
pology is one of the topologies with respect to which all functionals in $(X\tim
es Y)^*$ are continuous; hence it refines the weak topology.

**General principle.** If $\tau_1 \subseteq \tau_2$ are two topologies on a set
$S$, then every $\tau_1$-closed set is $\tau_2$-closed. Reason: if $C$ is $\tau_
1$-closed, then $S \setminus C$ is $\tau_1$-open, hence $\tau_2$-open (since $\t
au_1 \subseteq \tau_2$), so $C$ is $\tau_2$-closed.

Applying this with $\tau_1 = \tau_{\mathrm{wk}}$ and $\tau_2 = \tau_{\mathrm{st}
}$:

$$\Gamma(T) \text{ is } \tau_{\mathrm{wk}}\text{-closed} \;\Longrightarrow\; \Ga
mma(T) \text{ is } \tau_{\mathrm{st}}\text{-closed}.$$

Therefore, if the graph of $T$ is weakly closed, it is automatically closed in t
he strong topology of $X \times Y$.

**Remark on the converse.** The converse is generally false: a strongly closed g
raph need not be weakly closed. The closed graph theorem guarantees that a stron
gly closed graph of an everywhere-defined operator between Banach spaces yields
a bounded (hence continuous) operator, and a continuous linear operator has a we
akly closed graph — but for operators not everywhere defined, or in settings whe
re closed-graph-theorem hypotheses fail, strong closedness does not imply weak c
losedness in general. The implication we proved here uses only the purely topolo
gical fact that closed sets in a coarser topology remain closed in any finer top
ology, requiring no completeness or linearity.
