## Proof

**Step 1: Diagonalize via $\alpha = 1+\sqrt{2}$.**

The eigenvalues of $A$ are $\lambda = 3 \pm 2\sqrt{2} = (1\pm\sqrt{2})^2$. Set $
\alpha = 1+\sqrt{2}$, $\beta = 1-\sqrt{2}$, so $\lambda_1 = \alpha^2$, $\lambda_
2 = \beta^2$, with $\alpha\beta = -1$ and $|\beta| = \sqrt{2}-1 < 1$.

Diagonalizing $A$, the entries of $A^n$ are:
$$A^n = \begin{pmatrix} a_n & b_n \\ 2b_n & a_n \end{pmatrix}, \quad a_n = \frac
{\alpha^{2n}+\beta^{2n}}{2}, \quad b_n = \frac{\alpha^{2n}-\beta^{2n}}{2\sqrt{2}
}.$$

(The ratio $c_n/b_n = 2$ is preserved under multiplication by $A$, and the diago
nal entries are equal since $A$ has the form $\begin{pmatrix} a & b \\ 2b & a \e
nd{pmatrix}$ with $a^2 - 2b^2 = 1$.)

Thus $A^n - I = \begin{pmatrix} a_n-1 & b_n \\ 2b_n & a_n-1 \end{pmatrix}$, and
$$d_n = \gcd(a_n-1,\; b_n).$$

**Step 2: Introduce $P_n, Q_n$.**

Define integers (satisfying the recurrence $x_n = 2x_{n-1}+x_{n-2}$):
$$P_n = \frac{\alpha^n+\beta^n}{2}, \qquad Q_n = \frac{\alpha^n-\beta^n}{2\sqrt{
2}},$$
with $P_0=1, P_1=1$ and $Q_0=0, Q_1=1$. The key identity is:
$$P_n^2 - 2Q_n^2 = (\alpha\beta)^n = (-1)^n.$$

Using $\alpha^{2n}+\beta^{2n} = (\alpha^n+\beta^n)^2 - 2(\alpha\beta)^n = 4P_n^2
 - 2(-1)^n$ and $\alpha^{2n}-\beta^{2n} = (\alpha^n-\beta^n)(\alpha^n+\beta^n) =
 4\sqrt{2}\,P_n Q_n$:

$$a_n = 2P_n^2 - (-1)^n, \qquad b_n = 2P_n Q_n.$$

**Step 3: Compute $d_n$ for odd $n$.**

For odd $n$: $(-1)^n = -1$, so $a_n - 1 = 2P_n^2$ and $b_n = 2P_n Q_n$.

$$d_n = \gcd(2P_n^2,\; 2P_n Q_n) = 2P_n\,\gcd(P_n, Q_n).$$

If a prime $p \mid \gcd(P_n, Q_n)$, then $p \mid P_n^2 - 2Q_n^2 = -1$, a contrad
iction. So $\gcd(P_n, Q_n)=1$, giving:

$$\boxed{d_n = 2P_n = \alpha^n + \beta^n \quad \text{(odd } n\text{)}.}$$

**Step 4: Compute $d_n$ for even $n$.**

For even $n$: $(-1)^n = 1$, so $a_n - 1 = 2(P_n^2 - 1) = 2(P_n-1)(P_n+1)$ and $b
_n = 2P_n Q_n$.

$$d_n = 2\,\gcd\big((P_n-1)(P_n+1),\; P_n Q_n\big).$$

Since $\gcd(P_n, P_n \pm 1)=1$, we have $\gcd(P_n,\,(P_n-1)(P_n+1))=1$, so:
$$d_n = 2\,\gcd\big((P_n-1)(P_n+1),\; Q_n\big).$$

Using $P_n^2 - 2Q_n^2 = 1$ (even $n$), we get $(P_n-1)(P_n+1) = P_n^2-1 = 2Q_n^2
$. Therefore:
$$\gcd(2Q_n^2,\; Q_n) = Q_n, \qquad \boxed{d_n = 2Q_n = \frac{\alpha^n - \beta^n
}{\sqrt{2}} \quad \text{(even } n\text{)}.}$$

**Step 5: Verify (sanity check).**

- $n=1$ (odd): $d_1 = \alpha+\beta = 2$. ✓ ($\gcd(2,2)=2$)
- $n=2$ (even): $d_2 = \frac{\alpha^2-\beta^2}{\sqrt{2}} = \frac{4\sqrt{2}}{\sqr
t{2}} = 4$. ✓ ($\gcd(16,12)=4$)
- $n=3$ (odd): $d_3 = \alpha^3+\beta^3 = (7+5\sqrt{2})+(7-5\sqrt{2}) = 14$. ✓

**Step 6: Conclude $d_n \to \infty$.**

Since $|\beta| = \sqrt{2}-1 < 1$, we have $|\beta|^n \to 0$.

- **Odd $n$:** $\beta^n < 0$, so $d_n = \alpha^n + \beta^n = \alpha^n - |\beta|^
n \geq \alpha^n - 1 \to \infty$.
- **Even $n$:** $\beta^n > 0$ and $\beta^n \leq 1$, so $d_n = \frac{\alpha^n - \
beta^n}{\sqrt{2}} \geq \frac{\alpha^n - 1}{\sqrt{2}} \to \infty$.

Since $\alpha = 1+\sqrt{2} > 1$, in both cases $d_n \to \infty$ as $n \to \infty
$. $\blacksquare$
