# Problem

In a futuristic circular city, there are 2014 distinct subway stations located along the perimeter. To improve transit efficiency, a network of 1007 high-speed underground tunnels is constructed. Each of the 2014 stations serves as the starting or ending point for exactly one tunnel.

The tunnels are designed following strict architectural constraints:
1. Every single tunnel must cross every other tunnel at a unique intersection point inside the city.
2. No more than two tunnels are allowed to cross at any single intersection point.

These 1007 intersecting tunnels partition the city's underground area into several smaller, non-overlapping polygonal transit zones. Some of these zones are bounded by exactly three segments (either tunnel segments or sections of the city’s outer perimeter), making them triangular zones.

What is the minimum possible number of these transit zones that are triangles?
