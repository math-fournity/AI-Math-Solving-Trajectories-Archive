## Analysis

We work in $X = c_0$, the space of real null sequences with the sup norm $\|x\|_
\infty = \sup_n |x_n|$. The set $E$ is the collection of non-negative null seque
nces.

## Statement 1: "$E$ is not connected" — FALSE

$E$ is **convex**. If $x, y \in E$ (both $x_n \geq 0$, $y_n \geq 0$, both null)
and $t \in [0,1]$, then
$$z_n = t\,x_n + (1-t)\,y_n \geq 0, \qquad z_n \to 0,$$
so $z = tx + (1-t)y \in E$. The segment $[x,y] \subset E$ is a continuous path i
n $E$ from $x$ to $y$. Hence $E$ is path-connected, therefore connected. Stateme
nt 1 is **false**.

## Statement 2: "$E^\circ = \emptyset$" — TRUE

Let $x = \{x_n\} \in E$ and $\varepsilon > 0$. Since $x_n \to 0$, there exists $
N$ with $x_N < \varepsilon/2$. Define
$$y_n = \begin{cases} x_n & n \neq N, \\ -\varepsilon/2 & n = N. \end{cases}$$
Then $y_n \to 0$ (changing one term of a null sequence preserves nullity), so $y
 \in X$. Also
$$d(x,y) = \sup_n |x_n - y_n| = |x_N - y_N| = x_N + \tfrac{\varepsilon}{2} < \va
repsilon.$$
But $y_N = -\varepsilon/2 < 0$, so $y \notin E$.

Thus every ball $B(x,\varepsilon) \subset X$ meets $X \setminus E$, so no point
of $E$ is interior. Therefore $E^\circ = \emptyset$. Statement 2 is **true**.

## Statement 3: "$E' \neq E$" — FALSE

**$E$ is closed:** If $\{x^{(k)}\} \subset E$ and $x^{(k)} \to x$ in sup norm, t
hen for each fixed $n$,
$$|x^{(k)}_n - x_n| \leq \|x^{(k)} - x\|_\infty \to 0,$$
so $x^{(k)}_n \to x_n$. Since $x^{(k)}_n \geq 0$ for all $k$, we get $x_n \geq 0
$. Also $x_n \to 0$ (as a sup-norm limit in $c_0$). Hence $x \in E$, proving $E$
 is closed, so $E' \subseteq E$.

**Every point of $E$ is a limit point:** For any $x \in E$, define
$$x^{(k)}_n = x_n + \frac{1}{k\,n}, \qquad k = 1, 2, \dots$$
Then $x^{(k)}_n \geq 0$ and $x^{(k)}_n \to 0$ as $n \to \infty$ (since both $x_n
 \to 0$ and $1/(kn) \to 0$), so $x^{(k)} \in E$. Moreover $x^{(k)} \neq x$ (the
perturbation is strictly positive), and
$$d(x^{(k)}, x) = \sup_n \frac{1}{kn} = \frac{1}{k} \to 0.$$
So $x^{(k)} \to x$ with $x^{(k)} \in E \setminus \{x\}$, making $x$ a limit poin
t. Hence $E \subseteq E'$.

Combining: $E' = E$. Statement 3 is **false**.

---

## Statement 4: "$E$ is not closed" — FALSE

As shown in Statement 3's analysis, $E$ is closed: sup-norm convergence implies
coordinatewise convergence, which preserves the pointwise inequality $x_n \geq 0
$. Statement 4 is **false**.

---

## Conclusion

Only **Statement 2** is true: $E^\circ = \emptyset$.

- Statement 1 is false ($E$ is convex, hence connected).
- Statement 2 is true ($E$ has empty interior in $c_0$).
- Statement 3 is false ($E' = E$).
- Statement 4 is false ($E$ is closed).
