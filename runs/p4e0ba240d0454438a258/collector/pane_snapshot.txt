### Stage 1: $\mathcal{F}_{T+} = \bigcap_n \mathcal{F}_{T_n+}$ (no right-continu

*Proof of monotonicity:* If $A \in \mathcal{F}_{S+}$, then $A \cap \{S < t\} \in

S < t\}$, so
$$A \cap \{S' < t\} = (A \cap \{S < t\}) \cap \{S' < t\}.$$
Since $S'$ is a stopping time, $\{S' < t\} = \bigcup_{k} \{S' \leq t - 1/k\} \in

**Key observation:** Since $T_n \downarrow T$ (i.e., $T_1 \geq T_2 \geq \cdots \

$$\{T < t\} = \bigcup_{n=1}^{\infty} \{T_n < t\}.$$

*Proof of the equality:* ($\supseteq$) If $T_n < t$ for some $n$, then $T \leq T
_n < t$, so $T < t$. ($\subseteq$) If $T < t$, pick $\varepsilon > 0$ with $T +
\varepsilon < t$. Since $T_n \to T$, for all sufficiently large $n$, $T_n < T +
\varepsilon < t$, so $T_n < t$ for some $n$.

Therefore:
$$A \cap \{T < t\} = A \cap \bigcup_n \{T_n < t\} = \bigcup_n \bigl(A \cap \{T_n

This establishes $\mathcal{F}_{T+} = \bigcap_n \mathcal{F}_{T_n+}$. $\checkmark$
