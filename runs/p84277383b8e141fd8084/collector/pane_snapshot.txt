## Setup

For each prime p, v_p(d) = min over n > 2023 (n ≠ k³) of Σ_{k=1}^{40} v_p(n - k³
).

**Key criterion:** p divides d iff {k³ mod p : k=1..40} covers ALL residues mod
p. If some residue is missed, choosing n in that residue gives v_p(P(n)) = 0.

- **p ≡ 2 mod 3** (or p=3): cube map is bijective mod p, so k³ mod p = k mod p.
Covers all residues iff p ≤ 40.
- **p ≡ 1 mod 3, p > 3:** cubes form a subgroup of size (p-1)/3 + 1 < p, so not
all residues are hit. v_p(d) = 0.
- **p > 40:** only 40 residues hit (fewer than p). v_p(d) = 0.

So only primes p ∈ {2, 3, 5, 11, 17, 23, 29} (primes ≡ 2 mod 3 up to 40, plus p=
3) divide d.
