## 证明

**主张**：是的，可以从联合高斯随机变量的四阶矩计算出二阶矩（协方差矩阵元素），而
无需求解一组耦合二次方程组。

**关键工具**：Isserlis 定理（也称为矩的 Wick 定理）。

**设定**：设 $X_1, \ldots, X_n$ 为联合高斯随机变量。不失一般性，假设均值为零（非
零均值的情况将在最后讨论）。记 $C_{ij} = E[X_i X_j]$（协方差矩阵元素）和 $M_{ijk
l} = E[X_i X_j X_k X_l]$（四阶矩）。

**Isserlis 定理**：对于零均值联合高斯随机变量：
$$M_{ijkl} = C_{ij}C_{kl} + C_{ik}C_{jl} + C_{il}C_{jk}$$

**步骤 1：恢复对角线元素 $C_{ii}$（方差）。**

令 $i = j = k = l$：
$$M_{iiii} = E[X_i^4] = 3C_{ii}^2$$

由于 $C_{ii} = \text{Var}(X_i) \geq 0$：
$$C_{ii} = \sqrt{\frac{M_{iiii}}{3}}$$

这是对每个 $i$ 独立进行的简单平方根运算——不同变量之间没有耦合。

**步骤 2：恢复非对角线元素 $C_{ij}$（协方差）。**

令三个索引等于 $i$，一个等于 $j$（$i \neq j$）：
$$M_{iiij} = E[X_i^3 X_j] = 3C_{ii}C_{ij}$$

（Isserlis 定理中的三个配对均得出 $C_{ii}C_{ij}$。）

由于 $C_{ii}$ 已在步骤 1 中确定：
$$C_{ij} = \frac{M_{iiij}}{3C_{ii}}$$

这是一个简单的除法——在已知 $C_{ii}$ 的情况下，关于 $C_{ij}$ 是线性的。无需求解二
次方程。

**边界情况**：如果 $C_{ii} = 0$，则 $X_i$ 几乎必然是常数（在零均值情况下为零），
因此对于所有 $j$，$C_{ij} = 0$。

**非零均值情况**：如果变量具有非零均值 $\mu_i = E[X_i]$，且一阶矩可用，则定义 $Y
_i = X_i - \mu_i$（零均值联合高斯）。中心四阶矩 $E[Y_i Y_j Y_k Y_l]$ 可从原点矩
和均值计算得出，上述过程同样适用于恢复 $C_{ij} = \text{Cov}(X_i, X_j) = E[Y_i Y_
j]$。

**为什么这避免了耦合二次方程组**：一般的 Isserlis 关系 $M_{ijkl} = C_{ij}C_{kl}
+ C_{ik}C_{jl} + C_{il}C_{jk}$ 是关于 $C_{ij}$ 的耦合二次方程组。然而，通过选择
特定的索引模式：
- $(i,i,i,i)$：方程简化为单变量二次方程 $3C_{ii}^2 = M_{iiii}$，可通过平方根求解
。
- $(i,i,i,j)$：方程（在已知 $C_{ii}$ 的情况下）关于 $C_{ij}$ 变为线性方程，可通
过除法求解。

这种顺序解耦——先求解方差，再求解协方差——完全避免了同时求解整个耦合系统的需要。

**一致性检查**：对于联合高斯变量，所获得的值保证是一致的（形成有效的半正定协方差
矩阵），因为四阶矩源于实际的高斯分布。作为验证，可以检查 $M_{iiij}/(3C_{ii}) = M
_{jjji}/(3C_{jj})$ 是否成立，以及 $M_{ijij} = C_{ii}C_{jj} + 2C_{ij}^2$ 是否得到
满足。

**结论**：是的，这是可能的。利用 Isserlis 定理，联合高斯随机变量的四阶矩可以通过
一系列独立的平方根（用于方差）和除法（用于协方差）来反求二阶矩（协方差矩阵元素）
，而无需求解任何耦合二次方程组。
