**Problem.** Determine all polynomials $P(x) \in \mathbb{Z}[x]$ such that $P(n)
\mid n!+2$ for all positive integers $n$.

---

**Answer.** The only solutions are $P(x) = 1$ and $P(x) = -1$.

---

**Proof.**

**Step 1: Constant polynomials.**

If $P(x) = c$ is constant, then $c \mid n!+2$ for all $n \geq 1$. From $n=1$: $c
 \mid 3$. From $n=2$: $c \mid 4$. Hence $c \mid \gcd(3,4) = 1$, so $c = \pm 1$.
Both work since $\pm 1$ divides every integer.

**Step 2: Setup for the non-constant case.**

Suppose for contradiction that $P$ is non-constant of degree $d \geq 1$. Since $
P(n) \mid n!+2$, we have $P(n) \neq 0$ for every positive integer $n$.

**Step 3: No odd prime divides any value $P(n)$.**

Let $p$ be an odd prime. For every $n \geq p$, we have $p \mid n!$ (since $p \le
q n$), so
$$n! + 2 \equiv 2 \pmod{p}.$$
Since $p \geq 3$, we have $p \nmid 2$, so $p \nmid n!+2$. Because $P(n) \mid n!+
2$, it follows that $p \nmid P(n)$ for all $n \geq p$.

Now the set $\{n \bmod p : n \geq p\}$ is all of $\{0, 1, \dots, p-1\}$. Since $
P(n) \bmod p$ depends only on $n \bmod p$, we conclude $P(r) \not\equiv 0 \pmod{
p}$ for every residue $r \in \{0,1,\dots,p-1\}$. Therefore $P$ has **no root mod
ulo $p$**.

Since this holds for every odd prime $p$, no odd prime divides $P(n)$ for any po
sitive integer $n$. Combined with $P(n) \neq 0$, we get:
$$|P(n)| = 2^{v_2(P(n))} \quad \text{for all } n \geq 1,$$
i.e., every value $P(n)$ (for positive $n$) is of the form $\pm 2^k$ with $k \ge
q 0$.

**Step 4: Counting contradiction.**

vative $P'$ has finitely many real zeros, so $P$ is strictly monotone on $\{N_0,

ots, P(N)$ are **distinct** for all $N \geq N_0$ — giving $N - N_0 + 1$ distinct
 values.

On the other hand, for $n \leq N$, we have $|P(n)| \leq C N^d$ for some constant

$$|P(n)| = 2^k \leq C N^d = 2^{d\log_2 N + \log_2 C},$$
so $k \leq d\log_2 N + O(1)$. The number of possible values $\pm 2^k$ with $0 \l

$$2\bigl(d\log_2 N + O(1)\bigr) = O(\log N).$$

$$N - N_0 + 1 > 2\bigl(d\log_2 N + O(1)\bigr),$$
which is a contradiction (the left side grows linearly in $N$, the right side lo
garithmically).

The contradiction shows that no non-constant polynomial satisfies the condition.

$$\boxed{P(x) = 1 \quad \text{and} \quad P(x) = -1.}$$
