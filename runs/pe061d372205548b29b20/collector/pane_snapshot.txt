## Solution

**Setting up coordinates.** Let the circumcircle have center O at the origin wit
h radius 1. Since OX is the perpendicular bisector of BC (because the polar of X
 = l_B ∩ l_C is line BC, and OX ⊥ BC), I place OX along the y-axis with B, C sym
metric about it.

With central angle BOC = 2A, I set:
- B = (sin A, cos A), C = (−sin A, cos A) at angles π/2 ∓ A
- A at angle π/2 + A + 2B, giving A = (−sin(B/2), −cos(B/2)) since A + 2B = π −
B/2.

**Tangent lines** (tangent at (cosθ, sinθ) is x cosθ + y sinθ = 1):
- l_B: x sin A + y cos A = 1
- l_C: −x sin A + y cos A = 1
- l_A: x sin(B/2) + y cos(B/2) = −1

**Key intersections:**
- X = l_B ∩ l_C = (0, 1/cos A) — on the y-axis ✓
- Solving l_A ∩ l_B yields **Z = (sin B / cos(3B/2), −cos B / cos(3B/2))**
- Solving l_C ∩ l_A yields **Y = (sin(3B/2) / cos B, −cos(3B/2) / cos B)**

**Finding P.** Since OX is the y-axis (x = 0), P = YZ ∩ {x = 0}. Parametrizing P
 = Y + t(Z − Y), setting x = 0:

$$t = \frac{-x_Y}{x_Z - x_Y} = \frac{\sin(3B/2)/\cos B}{\sin(3B/2)/\cos B - \sin
 B/\cos(3B/2)} = \frac{\sin(3B)}{\sin(3B) - \sin(2B)}$$

So ZP/YP = (1−t)/t = **−sin(2B)/sin(3B)**.

**Solving for B.** From AC/AB = sin B / sin(3B/2) = 15/16, i.e., 16 sin B = 15 s
in(3B/2). Let u = B/2:

$$32 \sin u \cos u = 15(3\sin u - 4\sin^3 u) = 15\sin u(4\cos^2 u - 1)$$
$$60\cos^2 u - 32\cos u - 15 = 0 \implies \cos u = \tfrac{5}{6}$$

So cos(B/2) = 5/6, sin(B/2) = √11/6, giving:
- cos B = 7/18, sin B = 5√11/18
- cos(3B/2) = 4(5/6)³ − 3(5/6) = **−5/27**
- sin(3B/2) = 8√11/27

**Computing sin(2B) and sin(3B):**
- sin(2B) = 2 sin B cos B = 2·(5√11/18)·(7/18) = **35√11/162**
- cos(2B) = 2(7/18)² − 1 = −113/162
- sin(3B) = sin(2B)cos B + cos(2B)sin B = (35√11/162)(7/18) + (−113/162)(5√11/18
) = **−80√11/729**

**Final ratio:**

$$\frac{ZP}{YP} = \frac{-\sin(2B)}{\sin(3B)} = \frac{-35\sqrt{11}/162}{-80\sqrt{
11}/729} = \frac{35 \cdot 729}{162 \cdot 80} = \frac{35 \cdot 9/2}{80} = \frac{3
15}{160} = \frac{63}{32}$$

**Verification:** t = sin(3B)/(sin(3B) − sin(2B)) = (−80/729)/(−80/729 − 35/162)
 = 32/95 ∈ (0,1), confirming P lies between Y and Z with positive ratio. Numeric
al check: P_y = 486/475 = X_y ✓ (P on line OX).

The fraction 63/32 is irreducible (gcd(63,32) = 1), so a + b = 63 + 32 = **95**.
