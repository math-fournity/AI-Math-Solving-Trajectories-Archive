$$f(x) = 4x - x^2 = 4(2-y) - (2-y)^2 = 8 - 4y - 4 + 4y - y^2 = 4 - y^2$$

The new variable $y' = 2 - f(x) = 2 - (4 - y^2) = y^2 - 2$. So under the substit

$$g(y) = y^2 - 2$$

Setting $a = 2-p$, $b = 2-q$, $c = 2-r$, the system becomes:
$$b = g(a),\quad c = g(b),\quad a = g(c)$$
with $a, b, c$ distinct. Thus $\{a, b, c\}$ is a **3-cycle** of $g$, and:
$$p + q + r = (2-a)+(2-b)+(2-c) = 6 - (a+b+c)$$

**Step 2: Parametrize all real 3-cycles of $g$.**

A 3-cycle requires $g^3(a) = a$, i.e., $2\cos(8\theta) = 2\cos\theta$, giving $\
cos(8\theta) = \cos\theta$. This means $8\theta = \pm\theta + 2k\pi$:

- **Case 1:** $7\theta = 2k\pi$, so $\theta = \frac{2k\pi}{7}$.
- **Case 2:** $9\theta = 2k\pi$, so $\theta = \frac{2k\pi}{9}$.

For $|y| > 2$, $g(y) = y^2 - 2 > 2$ and the orbit escapes to infinity, so no cyc
les exist there. Thus all real 3-cycles come from these two families.
