## Proof

We determine the cardinality of $A = \bigcap_{k=1}^{\infty} A_k$, where
$$A_k = \Big\{ a \in \mathbb{N}^{\mathbb{N}} \;\Big|\; \sum_{i=100k}^{100k+99} a
_i = 200 \Big\}.$$

### Step 1: Identify the constrained and free indices

The constraint for $A_k$ involves indices in the block $B_k = \{100k, 100k+1, \l
dots, 100k+99\}$. For $k = 1, 2, 3, \ldots$, these blocks are:
$$B_1 = [100, 199],\quad B_2 = [200, 299],\quad B_3 = [300, 399],\quad \ldots$$

These blocks are pairwise disjoint and their union is $\{n \in \mathbb{N} : n \g
eq 100\}$. The indices $\{0, 1, \ldots, 99\}$ appear in no block, so they are **
unconstrained**.

### Step 2: Each block admits finitely many (≥ 2) configurations

For each block $B_k$ (100 entries), we need $\sum_{i \in B_k} a_i = 200$ with ea
ch $a_i \in \mathbb{N}$.

- If $\mathbb{N} = \{0, 1, 2, \ldots\}$: the number of solutions is $\binom{200
+ 100 - 1}{100 - 1} = \binom{299}{99}$.
- If $\mathbb{N} = \{1, 2, 3, \ldots\}$: substituting $b_i = a_i - 1 \geq 0$ wit
h $\sum b_i = 100$ gives $\binom{199}{99}$.

In either case, the number of valid configurations per block is a **finite integ
er $c \geq 2$** (indeed $\binom{299}{99} \gg 2$ and $\binom{199}{99} \gg 2$).

### Step 3: Decompose $A$ as a product

A sequence $a \in A$ is determined by:
- **Free part**: $(a_0, a_1, \ldots, a_{99}) \in \mathbb{N}^{100}$ — no constrai
nts.
- **Constrained part**: for each $k \geq 1$, the restriction $(a_i)_{i \in B_k}$
 belongs to a finite set $F_k$ with $|F_k| = c \geq 2$.

Since the blocks are disjoint, the choices are independent, giving a bijection:
$$A \;\cong\; \mathbb{N}^{100} \;\times\; \prod_{k=1}^{\infty} F_k.$$

### Step 4: Compute the cardinality

**Free part**: $|\mathbb{N}^{100}| = \aleph_0^{100} = \aleph_0$ (a finite produc
t of countable sets is countable).

**Constrained part**: $\prod_{k=1}^{\infty} F_k$ is a countable product of finit
e sets, each of size $\geq 2$.

- **Lower bound**: Since each $|F_k| \geq 2$, we can select a 2-element subset $
G_k \subseteq F_k$ for each $k$. Then $\prod_{k=1}^{\infty} G_k \cong \{0,1\}^{\
mathbb{N}}$ injects into $\prod_{k=1}^{\infty} F_k$, so $\left|\prod_{k=1}^{\inf
ty} F_k\right| \geq |\{0,1\}^{\mathbb{N}}| = 2^{\aleph_0}$.
- **Upper bound**: Each $F_k$ is finite, hence $F_k \subseteq \mathbb{N}$, so $\
prod_{k=1}^{\infty} F_k \subseteq \mathbb{N}^{\mathbb{N}}$, giving $\left|\prod_
{k=1}^{\infty} F_k\right| \leq |\mathbb{N}^{\mathbb{N}}| = 2^{\aleph_0}$.

Therefore $\left|\prod_{k=1}^{\infty} F_k\right| = 2^{\aleph_0} = \mathfrak{c}$.

### Step 5: Combine

$$|A| = \left|\mathbb{N}^{100}\right| \cdot \left|\prod_{k=1}^{\infty} F_k\right
| = \aleph_0 \cdot 2^{\aleph_0} = 2^{\aleph_0} = \mathfrak{c}.$$

### Conclusion

The cardinality of $A$ is $\boxed{2^{\aleph_0}}$ (the cardinality of the continu
um).
