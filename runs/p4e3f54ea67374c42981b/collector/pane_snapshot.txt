**Lower bound.** We exhibit $2^{\aleph_0}$ distinct elements of $A$.

For each binary sequence $b = (b_n)_{n \ge 1}$ with $b_n \in \{0,1\}$, define a
sequence $a^{(b)} = (a^{(b)}_n)_{n \ge 1}$ by
$$a^{(b)}_n = 2^n + b_n.$$

We verify that $a^{(b)} \in A$:

1. **Strictly increasing:** For every $n \ge 1$,
$$a^{(b)}_{n+1} - a^{(b)}_n = 2^{n+1} + b_{n+1} - 2^n - b_n = 2^n + (b_{n+1} - b
_n).$$
Since $b_{n+1} - b_n \ge -1$ and $2^n \ge 2$, we get $a^{(b)}_{n+1} - a^{(b)}_n
\ge 1$. ✓

2. **Density limit exists and equals 0:** Let $f(n) = \#\{j \mid a^{(b)}_j \le n
\}$. Since $a^{(b)}_j = 2^j + b_j \ge 2^j$, we have
$$f(n) \le \#\{j : 2^j \le n\} = \lfloor \log_2 n \rfloor.$$
Therefore
$$0 \le \frac{f(n)}{n} \le \frac{\lfloor \log_2 n \rfloor}{n} \xrightarrow{n \to
 \infty} 0,$$
so $\lim_{n \to \infty} \frac{f(n)}{n} = 0$ exists. ✓

b'_n$ for some $n$, giving $a^{(b)}_n = 2^n + b_n \ne 2^n + b'_n = a^{(b')}_n$,
so $a^{(b)} \ne a^{(b')}$. ✓
