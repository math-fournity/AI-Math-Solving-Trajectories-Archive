## Solution

I need to find $N$, the number of trailing zeros of $P = 1!\cdot 2!\cdot 3!\cdot
s 100!$, then compute $N \bmod 1000$.

**Trailing zeros = $\min(v_2(P), v_5(P))$.**

Since $v_p(P) = \sum_{k=1}^{100} v_p(k!)$ and $v_p(k!) = \sum_{j\ge 1}\lfloor k/
p^j\rfloor$, I swap the order of summation:

$$v_p(P) = \sum_{j\ge 1} \sum_{k=1}^{100}\left\lfloor \frac{k}{p^j}\right\rfloor
.$$

Using the identity (with $n=100$, $m=p^j$, $n=qm+r$, $0\le r<m$):
$$\sum_{k=1}^{n}\left\lfloor \frac{k}{m}\right\rfloor = m\cdot\frac{q(q-1)}{2}+q
(r+1).$$

### Computing $v_5(P)$

- **$j=1$, $m=5$:** $100 = 20\cdot 5+0$, so $q=20, r=0$.
  $$S = 5\cdot\frac{20\cdot 19}{2} + 20\cdot 1 = 950+20 = 970.$$

- **$j=2$, $m=25$:** $100 = 4\cdot 25+0$, so $q=4, r=0$.
  $$S = 25\cdot\frac{4\cdot 3}{2} + 4\cdot 1 = 150+4 = 154.$$

- **$j=3$, $m=125>100$:** $S=0$.

$$v_5(P) = 970+154 = 1124.$$

### Computing $v_2(P)$

- **$j=1$, $m=2$:** $q=50, r=0$: $S = 2\cdot\frac{50\cdot49}{2}+50 = 2450+50 = 2
500.$
- **$j=2$, $m=4$:** $q=25, r=0$: $S = 4\cdot\frac{25\cdot24}{2}+25 = 1200+25 = 1
225.$
- **$j=3$, $m=8$:** $q=12, r=4$: $S = 8\cdot\frac{12\cdot11}{2}+12\cdot5 = 528+6
0 = 588.$
- **$j=4$, $m=16$:** $q=6, r=4$: $S = 16\cdot\frac{6\cdot5}{2}+6\cdot5 = 240+30
= 270.$
- **$j=5$, $m=32$:** $q=3, r=4$: $S = 32\cdot\frac{3\cdot2}{2}+3\cdot5 = 96+15 =
 111.$
- **$j=6$, $m=64$:** $q=1, r=36$: $S = 64\cdot 0 + 1\cdot 37 = 37.$
- **$j=7$, $m=128>100$:** $S=0.$

$$v_2(P) = 2500+1225+588+270+111+37 = 4731.$$

### Conclusion

Since $v_5(P) = 1124 < 4731 = v_2(P)$, the number of trailing zeros is determine
d by the power of 5:

$$N = \min(4731, 1124) = 1124.$$

Therefore,

$$N \bmod 1000 = 1124 \bmod 1000 = \boxed{124}.$$
