## Solution

**Answer-leak check:** The problem statement contains only the problem, no solut
ions or hints. Proceeding.

**Setup.** Let $N = ab = cd = a+b+c+d-3$. Then $a+b+c+d = N+3$, with $ab=cd=N$.
For each ordered pair $(a,b)$ with $ab=N$, define $g(a)=a+N/a$. We need
$$g(a)+g(c)=N+3, \qquad a\mid N,\ c\mid N.$$

**Reduction to representatives.** Pick $a\le b$ and $c\le d$ (so $a,c\le\sqrt{N}
$); ordered quadruples are counted afterwards. Then $b=N/a,\ d=N/c$, and
$$a+c+\frac{N}{a}+\frac{N}{c}=N+3 \implies N=\frac{(a+c-3)\,ac}{ac-a-c}.$$

**Bounding.** The constraints $a\le\sqrt{N}$ and $c\le\sqrt{N}$ severely restric
t $(a,c)$.

*If $a=1$:* the denominator is $c-1-c=-1<0$; for $N>0$ need numerator $<0$, i.e.
 $c<3$. Only $c=1$ gives $N=1$ (since $c=2$ gives $N=0$).

*If $a=2$:* $N=\frac{2c(c-1)}{c-2}=2c+2+\frac{4}{c-2}$, requiring $(c-2)\mid 4$,
 so $c\in\{3,4,6\}$, giving $N\in\{12,14,15\}$. Checking $a\mid N$ and $c\mid N$
 and $c\le\sqrt{N}$: only $c=3$, $N=12$ survives ($4\nmid 14$; $2\nmid 15$).

*If $a=3$:* $N=\frac{3c^2}{2c-3}$. The condition $c\le\sqrt{N}=\sqrt{3c^2/(2c-3)
}$ forces $c\le 3$. So $c\in\{2,3\}$: $c=2\to N=12$ (same as above, swapped); $c
=3\to N=9$.

*If $a\ge 4$:* Asymptotically $N\approx a+c$, so $\sqrt{N}\approx\sqrt{a+c}$, bu
t $a\le\sqrt{N}$ requires $a^2\lesssim a+c$, i.e. $c\gtrsim a^2-a$; likewise $c\
lesssim \sqrt{a+c}$ forces $c$ small. A clean bound: from $a^2\le N$ and $c^2\le
 N$ one derives $a^2(c-1)\le c(2a+c-3)$ and its symmetric. Assuming WLOG $a\le c
$, the second gives $a\ge c^2-2c$, combined with $a\le c$ yields $c\le 3$. So no
 solutions with $a\ge 4$.

**The only values are $N\in\{1,9,12\}$.**

**Counting ordered quadruples.**

- **$N=1$:** only $(a,b)=(1,1)$, $(c,d)=(1,1)$. Sum $=4=N+3$. ✓ **1 quadruple**:
 $(1,1,1,1)$.

- **$N=9$:** only $(a,b)=(3,3)$, $(c,d)=(3,3)$. Sum $=12=N+3$. ✓ **1 quadruple**
: $(3,3,3,3)$.

- **$N=12$:** ordered pairs $(x,y)$ with $xy=12$ and their sums:
  - sum $13$: $(1,12),(12,1)$
  - sum $8$: $(2,6),(6,2)$
  - sum $7$: $(3,4),(4,3)$

  Need $(a+b)+(c+d)=15$: only $8+7$ and $7+8$.
  - $(a+b)=8$ (2 options) $\times$ $(c+d)=7$ (2 options) $=4$.
  - $(a+b)=7$ (2 options) $\times$ $(c+d)=8$ (2 options) $=4$.

  **8 quadruples**:
  $(2,6,3,4),(2,6,4,3),(6,2,3,4),(6,2,4,3),(3,4,2,6),(3,4,6,2),(4,3,2,6),(4,3,6,
2)$.

**Verification:** Each has $ab=cd=12$ and $a+b+c+d=15=12+3$. ✓

**Total:** $1+1+8 = \boxed{10}$.
