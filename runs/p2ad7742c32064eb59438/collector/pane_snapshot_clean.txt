## Proof

We compute $H_4(S^2 \times S^2; \mathbb{Z}_2)$ using the Kunneth formula.

**Setup.** Let $X = S^2$ and $Y = S^2$. We are given the homology of $S^2$ with
$\mathbb{Z}_2$ coefficients:

$$H_i(S^2; \mathbb{Z}_2) = \begin{cases} \mathbb{Z}_2 & i = 0, \\ \mathbb{Z}_2 &
 i = 2, \\ 0 & \text{otherwise.} \end{cases}$$

**Kunneth formula over a field.** The Kunneth theorem for homology states that f
or spaces $X, Y$ and a coefficient group $G$, there is a natural short exact seq
uence

$$0 \to \bigoplus_{i+j=n} H_i(X; G) \otimes H_j(Y; G) \to H_n(X \times Y; G) \to
 \bigoplus_{i+j=n-1} \operatorname{Tor}\bigl(H_i(X; G), H_j(Y; G)\bigr) \to 0.$$

When $G = F$ is a field (in particular $G = \mathbb{Z}_2$, which is a field), ev
ery module over $F$ is free (hence flat), so $\operatorname{Tor}(-, -) = 0$ iden
tically. The short exact sequence therefore splits (in fact, is an isomorphism),
 giving

$$H_n(X \times Y; F) \cong \bigoplus_{i+j=n} H_i(X; F) \otimes_F H_j(Y; F).$$

**Applying to $n = 4$, $X = Y = S^2$, $F = \mathbb{Z}_2$.** We sum over all pair
s $(i, j)$ with $i + j = 4$. A summand contributes only if both $H_i(S^2; \mathb
b{Z}_2) \neq 0$ and $H_j(S^2; \mathbb{Z}_2) \neq 0$. Since the only nonzero degr
ees are $0$ and $2$, the admissible values of $i$ and $j$ lie in $\{0, 2\}$. The
 pairs $(i, j) \in \{0, 2\}^2$ with $i + j = 4$ are:

| $(i, j)$ | $i + j$ | Contributes? |
|---|---|---|
| $(0, 0)$ | $0$ | No (wrong degree) |
| $(0, 2)$ | $2$ | No (wrong degree) |
| $(2, 0)$ | $2$ | No (wrong degree) |
| $(2, 2)$ | $4$ | **Yes** |

There is exactly one contributing pair: $(i, j) = (2, 2)$.

**Computing the single summand.**

$$H_2(S^2; \mathbb{Z}_2) \otimes_{\mathbb{Z}_2} H_2(S^2; \mathbb{Z}_2) \cong \ma
thbb{Z}_2 \otimes_{\mathbb{Z}_2} \mathbb{Z}_2 \cong \mathbb{Z}_2.$$

The last isomorphism uses the standard fact that for any field $F$, $F \otimes_F
 F \cong F$ via the multiplication map $a \otimes b \mapsto ab$.

**Conclusion.** Since the Tor term vanishes (coefficients in the field $\mathbb{
Z}_2$) and there is exactly one nonzero summand in degree $4$,

$$\boxed{H_4(S^2 \times S^2; \mathbb{Z}_2) \cong \mathbb{Z}_2.}$$
