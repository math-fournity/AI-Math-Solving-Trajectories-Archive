## Proof

We are given the system:
- $y = x^2 + 15x + 32$
- $x = y^2 + 49y + 593$

**Step 1: Complete the square to simplify.**

For the first equation:
$$y = x^2 + 15x + 32 = \left(x + \tfrac{15}{2}\right)^2 - \tfrac{225}{4} + 32 =
\left(x + \tfrac{15}{2}\right)^2 - \tfrac{97}{4}$$

For the second equation:
$$x = y^2 + 49y + 593 = \left(y + \tfrac{49}{2}\right)^2 - \tfrac{2401}{4} + 593
 = \left(y + \tfrac{49}{2}\right)^2 - \tfrac{29}{4}$$

**Step 2: Substitute to symmetrize.**

Let $u = x + \tfrac{15}{2}$ and $v = y + \tfrac{49}{2}$. Then $x = u - \tfrac{15
}{2}$ and $y = v - \tfrac{49}{2}$, so:

$$v - \tfrac{49}{2} = u^2 - \tfrac{97}{4} \implies v = u^2 + \tfrac{1}{4}$$

$$u - \tfrac{15}{2} = v^2 - \tfrac{29}{4} \implies u = v^2 + \tfrac{1}{4}$$

**Step 3: Subtract the two equations.**

$$v - u = u^2 - v^2 = (u - v)(u + v) = -(v - u)(u + v)$$

$$(v - u)\big(1 + u + v\big) = 0$$

So either $v = u$ or $u + v = -1$.

**Case 1: $v = u$.** Then $u = u^2 + \tfrac{1}{4}$, i.e. $u^2 - u + \tfrac{1}{4}
 = 0$, giving $(u - \tfrac{1}{2})^2 = 0$, so $u = \tfrac{1}{2}$ (a double root).
 Thus $v = \tfrac{1}{2}$.

Recovering $x, y$:
$$x = u - \tfrac{15}{2} = \tfrac{1}{2} - \tfrac{15}{2} = -7, \qquad y = v - \tfr
ac{49}{2} = \tfrac{1}{2} - \tfrac{49}{2} = -24$$

**Verification:** $y = (-7)^2 + 15(-7) + 32 = 49 - 105 + 32 = -24$ ✓. $x = (-24)
^2 + 49(-24) + 593 = 576 - 1176 + 593 = -7$ ✓.

**Case 2: $u + v = -1$.** Then $v = -1 - u$, and substituting into $v = u^2 + \t
frac{1}{4}$:
$$-1 - u = u^2 + \tfrac{1}{4} \implies u^2 + u + \tfrac{5}{4} = 0$$

The discriminant is $1 - 5 = -4 < 0$, so there are **no real solutions** in this
 case.

**Conclusion.** The unique real solution is $(x_0, y_0) = (-7, -24)$, and

$$x_0 + y_0 = -7 + (-24) = \boxed{-31}$$
