## General method

For ρ_t + a(x,t) ρ_x = b(x,t,ρ), characteristics satisfy dx/dt = a(x,t), and alo
ng them dρ/dt = b(x,t,ρ). The characteristic through (x₀, 0) gives x₀ = x at t =
 0, and ρ(x₀, 0) = f(x₀).

---

### (a) ρ_t + c ρ_x = e^{-3x}

Characteristics: dx/dt = c ⟹ x = x₀ + ct, so x₀ = x − ct. Along a characteristic
, x is affine in t, and

dρ/dt = e^{-3x} = e^{-3(x₀+ct)}.

Integrating from 0 to t:

$$\rho = f(x_0) + \int_0^t e^{-3(x_0+cs)}\,ds = f(x-ct) + e^{-3(x-ct)}\int_0^t e
^{-3cs}\,ds.$$

For c ≠ 0:

$$\boxed{\rho(x,t) = f(x-ct) + \frac{e^{-3(x-ct)} - e^{-3x}}{3c}.}$$

For c = 0: ρ(x,t) = f(x) + t e^{-3x}.

*Verification.* Let u = x−ct. ρ_t = −c f'(u) + e^{-3u}; ρ_x = f'(u) + (−e^{-3u}+
e^{-3x})/c, so c ρ_x = c f'(u) − e^{-3u} + e^{-3x}. Sum: ρ_t + c ρ_x = e^{-3x}.
✓

### (b) ρ_t + 3x ρ_x = 4

Characteristics: dx/dt = 3x ⟹ x = x₀ e^{3t}, so x₀ = x e^{-3t}. Along a characte
ristic dρ/dt = 4, hence

$$\boxed{\rho(x,t) = f(xe^{-3t}) + 4t.}$$

*Verification.* Let u = x e^{-3t}. ρ_t = f'(u)(−3x e^{-3t}) + 4 = −3u f'(u) + 4;
 ρ_x = f'(u) e^{-3t}. Then 3x ρ_x = 3x e^{-3t} f'(u) = 3u f'(u). Sum: 4. ✓

### (c) ρ_t + ρ_x = 5

Characteristics: dx/dt = 1 ⟹ x₀ = x − t. Along, dρ/dt = 5, so

$$\boxed{\rho(x,t) = f(x-t) + 5t.}$$

*Verification.* u = x−t: ρ_t = −f'(u)+5, ρ_x = f'(u); sum = 5. ✓

### (d) ρ_t + 5t ρ_x = 3ρ

Characteristics: dx/dt = 5t ⟹ x = x₀ + (5/2)t², so x₀ = x − (5/2)t². Along, dρ/d
t = 3ρ ⟹ ρ = ρ₀ e^{3t} = f(x₀) e^{3t}:

$$\boxed{\rho(x,t) = f\!\left(x - \tfrac{5}{2}t^2\right) e^{3t}.}$$

*Verification.* u = x − (5/2)t². ρ_t = [f'(u)(−5t) + 3 f(u)] e^{3t}; ρ_x = f'(u)
 e^{3t}; 5t ρ_x = 5t f'(u) e^{3t}. Sum: 3 f(u) e^{3t} = 3ρ. ✓

### (e) ρ_t − t² ρ_x = −ρ

Characteristics: dx/dt = −t² ⟹ x = x₀ − t³/3, so x₀ = x + t³/3. Along, dρ/dt = −
ρ ⟹ ρ = f(x₀) e^{-t}:

$$\boxed{\rho(x,t) = f\!\left(x + \tfrac{t^3}{3}\right) e^{-t}.}$$

*Verification.* u = x + t³/3. ρ_t = [f'(u)·t² − f(u)] e^{-t}; ρ_x = f'(u) e^{-t}
; −t² ρ_x = −t² f'(u) e^{-t}. Sum: −f(u) e^{-t} = −ρ. ✓

---

### (f) ρ_t + t² ρ_x = 0

Characteristics: dx/dt = t² ⟹ x = x₀ + t³/3, so x₀ = x − t³/3. Along, dρ/dt = 0,
 so ρ is constant:

$$\boxed{\rho(x,t) = f\!\left(x - \tfrac{t^3}{3}\right).}$$

*Verification.* u = x − t³/3. ρ_t = f'(u)(−t²); ρ_x = f'(u); t² ρ_x = t² f'(u).
Sum: 0. ✓

---

### (g) ρ_t + x ρ_x = t

Characteristics: dx/dt = x ⟹ x = x₀ e^t, so x₀ = x e^{-t}. Along, dρ/dt = t, hen
ce ρ = f(x₀) + t²/2:

$$\boxed{\rho(x,t) = f(xe^{-t}) + \frac{t^2}{2}.}$$

*Verification.* u = x e^{-t}. ρ_t = f'(u)(−x e^{-t}) + t = −u f'(u) + t; ρ_x = f
'(u) e^{-t}; x ρ_x = x e^{-t} f'(u) = u f'(u). Sum: t. ✓
