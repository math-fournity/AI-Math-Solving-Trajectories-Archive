## Proof

**Claim.** There exists a Lebesgue-measurable set $E\subseteq\mathbb{R}$ such th
at for every open interval $(a,b)$, both $m(E\cap(a,b))>0$ and $m(E^{c}\cap(a,b)
)>0$.

**Preliminary fact (fat Cantor sets).** In any open interval $J$ one can constru
ct a compact, nowhere-dense set $F\subseteq J$ with $m(F)>0$ (a Smith–Volterra–C
antor–type set: iteratively remove open middle subintervals whose total length i
s strictly less than $|J|$). We use this freely below.

**Construction.** Let $\{I_n\}_{n\ge 1}$ be an enumeration of all open intervals
 with rational endpoints. This family is countable, and every open interval $(a,
b)$ contains some $I_n$.

We build two sequences of sets $A_n, B_n$ by induction, maintaining:

1. $A_n, B_n$ are disjoint finite unions of fat Cantor sets (hence compact, nowh
ere dense, and disjoint);
2. $A_n\cap I_k$ and $B_n\cap I_k$ each have positive measure for every $k\le n$
.

Initialize $A_0=B_0=\varnothing$.

**Inductive step.** Suppose $A_{n-1}, B_{n-1}$ are constructed. The set $K:=A_{n
-1}\cup B_{n-1}$ is a finite union of compact nowhere-dense sets, hence is itsel
f compact and nowhere dense. Therefore
$$I_n\setminus K$$
is an open set that is dense in $I_n$ (removing a closed nowhere-dense set from
an open interval leaves a dense open set); in particular it is nonempty and open
, so it contains some open subinterval $J\subseteq I_n\setminus K$.

Split $J$ into two disjoint closed subintervals $J_A, J_B$ (for instance the lef
t and right thirds of $J$). Inside $J_A$ place a fat Cantor set $F_A$ with $m(F_
A)>0$; inside $J_B$ place a fat Cantor set $F_B$ with $m(F_B)>0$. Set
$$A_n = A_{n-1}\cup F_A,\qquad B_n = B_{n-1}\cup F_B.$$

Disjointness is preserved: $F_A\subseteq J_A$ and $F_B\subseteq J_B$ with $J_A\c
ap J_B=\varnothing$, while $J\subseteq \mathbb{R}\setminus(A_{n-1}\cup B_{n-1})$
 ensures the new pieces avoid all previous pieces. Both $A_n$ and $B_n$ remain f
inite unions of fat Cantor sets, hence compact and nowhere dense. Moreover $A_n\
cap I_n\supseteq F_A$ and $B_n\cap I_n\supseteq F_B$ both have positive measure,
 and the property for $k<n$ is inherited from $A_{n-1},B_{n-1}$. This completes
the induction.

**Definition of $E$.** Set
$$A=\bigcup_{n\ge 1}A_n,\qquad B=\bigcup_{n\ge 1}B_n,\qquad E:=A.$$
Both $A$ and $B$ are countable unions of compact sets, hence Borel (in particula
r Lebesgue-measurable). Disjointness is preserved at every stage, so $A\cap B=\v
arnothing$, which gives $B\subseteq E^{c}$.

**Verification.** Let $(a,b)$ be any open interval. Choose $I_n\subseteq(a,b)$ f
rom the rational-endpoint enumeration. By construction, $F_A\subseteq A_n\subset
eq A=E$ was placed inside $I_n\subseteq(a,b)$ with $m(F_A)>0$, so
$$m\bigl(E\cap(a,b)\bigr)\ge m(F_A)>0.$$
Likewise $F_B\subseteq B_n\subseteq B\subseteq E^{c}$ was placed inside $I_n\sub
seteq(a,b)$ with $m(F_B)>0$, so
$$m\bigl(E^{c}\cap(a,b)\bigr)\ge m(F_B)>0.$$

Both required conditions hold for every open interval $(a,b)$. Therefore such a
set $E$ exists. $\blacksquare$
