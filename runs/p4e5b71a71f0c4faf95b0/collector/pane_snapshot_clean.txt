The "only if" direction: fibration in $\mathrm{sSet}^+$ $\Longrightarrow$
underlying Joyal fibration

Let $f: (X, S) \to (Y, T)$ be a fibration in $\mathrm{sSet}^+$ between fibrant
marked simplicial sets. Then $f$ has the right lifting property (RLP) against
all marked anodyne maps.

  • Inner fibration: The marked anodyne maps of type (A) are marked versions of
  the inner horn inclusions. Forgetting markings, $f: X \to Y$ has RLP against
  all inner horn inclusions $\Lambda^n_i \to \Delta^n$ ($0 < i < n$), so $f$ is
  an inner fibration.
  • Isofibration condition: The marked anodyne maps of types (B) and (C)
  together generate the marked version of the map ${0} \to J$, where $J =
  N(\mathrm{Iso}(\bullet \leftrightarrow \bullet))$ is the nerve of the free
  isomorphism (a Kan complex, so $\mathrm{Eq}(J) = $ all edges). Specifically,
  $J$ is built from copies of $\Delta^1$ (the isomorphism and its inverse) and
  higher simplices witnessing the isomorphism; the marking map (B) marks the 1-
  simplex edges, the inner horns (A) fill the inner horns of $J$, and the outer
  horns (C) fill the remaining outer horns with the long edge marked. Thus
  $({0}, {\mathrm{id}}) \to (J, \mathrm{Eq}(J))$ is marked anodyne. Lifting
  against this, the underlying map $f: X \to Y$ has RLP against ${0} \to J$.

Since $f: X \to Y$ is an inner fibration with RLP against ${0} \to J$, it is an
isofibration, i.e., a Joyal fibration. $\checkmark$

The "if" direction fails: counterexample

Let $\mathcal{C}$ be the category with two objects $0, 1$ and a single non-
identity morphism $\alpha: 0 \to 1$. Let $X = N(\mathcal{C})$ be its nerve.

$X$ is a quasi-category (nerve of a category), hence fibrant in the Joyal model
structure.

The equivalences in $X$ are exactly the degenerate edges ${\mathrm{id}_0,
\mathrm{id}_1}$, since the homotopy category of $X$ is $\mathcal{C}$ itself, and
the only isomorphisms in $\mathcal{C}$ are the identities. In particular, $
\alpha: 0 \to 1$ is not an equivalence.

Both marked simplicial sets are fibrant:

  • $(X, \mathrm{Eq}(X)) = (X, {\mathrm{id}_0, \mathrm{id}_1})$ is fibrant in $
  \mathrm{sSet}^+$.
  • $(, \mathrm{Eq}()) = (, {\mathrm{id}_})$ is fibrant in $\mathrm{sSet}^+$.

The underlying map is a Joyal fibration: The unique map $f: X \to *$ is a Joyal
fibration, since $X$ is fibrant and the map from a fibrant object to the
terminal object is always a fibration.

The map is NOT a fibration in $\mathrm{sSet}^+$: Consider the marked anodyne map
(type B): $$g: (\Delta^1, {\text{degenerate edges}}) \longrightarrow (\Delta^1,
{\text{all edges}}).$$

Construct a lifting problem:

  • Source map $a: (\Delta^1, {\text{deg}}) \to (X, {\mathrm{id}_0, \mathrm{id}
  _1})$ sending the non-degenerate edge of $\Delta^1$ to $\alpha: 0 \to 1$. This
  is a valid map of marked simplicial sets because the degenerate edges of $
  \Delta^1$ map to $\mathrm{id}_0$ and $\mathrm{id}_1$, which are marked.
  • Target map $b: (\Delta^1, {\text{all edges}}) \to (, {\mathrm{id}_})$, the
  unique map. This is valid because all edges of $\Delta^1$ map to $\mathrm{id}
  _*$, which is marked.

The square commutes (both underlying simplicial set maps agree on $\Delta^1$). A
lift $\ell: (\Delta^1, {\text{all edges}}) \to (X, {\mathrm{id}_0, \mathrm{id}
_1})$ would require:

  • The non-degenerate edge of $\Delta^1$ (which is marked in the domain
  $(\Delta^1, {\text{all edges}})$) maps to a marked edge of $X$, i.e., to an
  element of ${\mathrm{id}_0, \mathrm{id}_1}$.
  • By commutativity of the underlying simplicial set diagram, this edge must
  map to $\alpha$.

But $\alpha \notin {\mathrm{id}_0, \mathrm{id}_1}$. No lift exists, so $f$ is
not a fibration in $\mathrm{sSet}^+$.

The correct characterization

A map $f: (X, S) \to (Y, T)$ between fibrant marked simplicial sets is a
fibration in $\mathrm{sSet}^+$ if and only if:

  1. (Isofibration) The underlying map $f: X \to Y$ is a Joyal fibration
  (isofibration), and
  2. (Reflection of equivalences) $S = f^{-1}(T)$, i.e., an edge $e$ in $X$ is
  an equivalence if and only if $f(e)$ is an equivalence in $Y$.

Condition 2 is equivalent to saying $f$ reflects equivalences (the forward
direction—preserving equivalences—is automatic for any map of quasi-categories).
The counterexample shows this reflection condition is independent of the
isofibration condition: the map $X \to $ is an isofibration but does not reflect
equivalences (since $\alpha$ maps to the equivalence $\mathrm{id}_$ but is not
itself an equivalence).

Conclusion: The answer is no. Being a Joyal fibration on underlying simplicial
sets is necessary but not sufficient for being a fibration in $\mathrm{sSet}^+$
between fibrant objects; the additional requirement of reflecting equivalences
is essential and independent.
