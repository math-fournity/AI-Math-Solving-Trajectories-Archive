# Problem

In a bustling marketplace, several artisanal craft guilds are competing for a prestigious annual contract. The selection process follows a "round-robin" format: every guild must collaborate on exactly one joint project with every other participating guild.

After each project is completed, a panel of judges awards points to the two guilds involved:
- If one guild’s contribution is judged superior, that guild earns 3 points (a "Clear Success") and the other earns 0 points (a "Failure").
- If both contributions are of equal quality, it is declared a "Balanced Effort," and each guild earns 1 point.

The Grand Overseer is interested in a specific, unusual outcome. He wants to know the smallest possible number of guilds, $n_0$, required such that it is mathematically possible for one guild (Guild A) to finish the season with the highest total point score among all participants, while simultaneously having the strictly lowest number of "Clear Successes" among all participants. 

Determine this minimum value $n_0$.
