## Proof

**Setup.** Label positions $0, 1, \ldots, 2017$ around the circle. Let $a_i$ be
the chip at position $i$. With $n = 2018$ and $h = 1009 = n/2$, the "balanced-pa
ir" condition states:

$$a_i + a_{i+1} = a_{i+h} + a_{i+h+1} \quad \text{for all } i \pmod{n}.$$

**Step 1: Deriving the structure.** Define $s_i = a_i + a_{i+1}$. The condition
gives $s_i = s_{i+h}$ for all $i$. Define $b_i = a_i - a_{i+h}$. Then:

$$b_i = a_i - a_{i+h} = (a_{i+h+1} - a_{i+1}) = -b_{i+1}$$

So $b_{i+1} = -b_i$, giving $b_i = (-1)^i c$ for some constant $c = b_0$. Consis
tency check: $b_{i+h} = (-1)^{i+h}c = (-1)^i \cdot (-1)^{1009} c = -(-1)^i c = -
b_i$, and indeed $b_{i+h} = a_{i+h} - a_{i+2h} = a_{i+h} - a_i = -b_i$. ✓ No con
tradiction since $h$ is odd.

**Step 2: Parity constraint on $c$.** Summing $a_i - a_{i+h} = (-1)^i c$ over $i
 = 0, \ldots, h-1$:

$$\sum_{i=0}^{h-1} a_i - \sum_{i=h}^{n-1} a_i = c \sum_{i=0}^{1008} (-1)^i = c \
cdot 1 = c$$

Since $\sum_{i=0}^{h-1} a_i + \sum_{i=h}^{n-1} a_i = \frac{2018 \cdot 2019}{2} =
 1009 \times 2019 = 2037171$ (odd), we get $\sum_{i=0}^{h-1} a_i = \frac{2037171
 + c}{2}$, requiring **$c$ odd**. Also $c \neq 0$ (since all chips are distinct)
.

**Step 3: Which values of $|c|$ work?** For $c > 0$: even-indexed positions get
the larger value (by $c$), odd-indexed positions get the smaller. For $c < 0$: v
ice versa. In either case, $\{1, \ldots, 2018\}$ must be partitioned into 1009 p
airs each of the form $\{x, x + |c|\}$.

This requires a perfect matching in the graph on $\{1, \ldots, 2018\}$ with edge
s $\{x, x+d\}$ where $d = |c|$. This graph is a disjoint union of paths (one per
 residue class mod $d$). A perfect matching exists iff every path has an even nu
mber of vertices, i.e., every residue class mod $d$ has an even count in $\{1, \
ldots, 2018\}$.

Writing $2018 = qd + r'$ ($0 \le r' < d$): $r'$ classes have $q+1$ elements, $d
- r'$ classes have $q$ elements. Both $q$ and $q+1$ even is impossible, so we ne
ed $r' = 0$ (i.e., $d \mid 2018$) and $q = 2018/d$ even.

Since $2018 = 2 \times 1009$ with $1009$ prime, the divisors are $\{1, 2, 1009,
2018\}$. Requiring $2018/d$ even gives $d \in \{1, 1009\}$. Both are odd ✓. So $
|c| \in \{1, 1009\}$, giving $c \in \{-1009, -1, 1, 1009\}$.

**Step 4: Unique partition for each $|c|$.**
- $|c| = 1$: The graph is a single path $1 - 2 - 3 - \cdots - 2018$. A path on $
2k$ vertices has a **unique** perfect matching: $\{1,2\}, \{3,4\}, \ldots, \{201
7, 2018\}$.
- $|c| = 1009$: The graph is 1009 disjoint edges $\{r, r+1009\}$ for $r = 1, \ld
ots, 1009$. Unique matching (each edge is forced).

**Step 5: Counting arrangements per $c$.** For each $c$, the partition into 1009
 pairs is unique. These 1009 pairs are assigned to the 1009 opposite-position pa
irs $(i, i+h)$ for $i = 0, \ldots, h-1$. Any pair can go to any slot (in both ty
pe-A and type-B slots, the even position receives the larger value when $c > 0$,
 smaller when $c < 0$ — the within-pair assignment is determined by $\operatorna
me{sgn}(c)$). Thus each $c$ gives $1009!$ arrangements.

Total arrangements (before modding out rotations): $4 \times 1009!$.

**Step 6: Quotient by rotations.** Rotation by $k$ sends $c \mapsto (-1)^k c$. N
o non-identity rotation fixes any arrangement: a rotation by $k \neq 0$ fixing a
n arrangement would require $a_{i+k} = a_i$ for all $i$, forcing periodicity wit
h period $\gcd(k, 2018) < 2018$, impossible with 2018 distinct values. (For odd
$k$, the arrangement maps to one with parameter $-c \neq c$, so it's a *differen
t* arrangement, not a fixed point.)

By Burnside's lemma, every orbit has size exactly 2018, so the number of distinc
t arrangements is:

$$\frac{4 \times 1009!}{2018} = \frac{4 \times 1009!}{2 \times 1009} = \frac{2 \
times 1009!}{1009} = 2 \times 1008!$$

**Verification with $n=6$.** For a hexagon ($h=3$): valid $|c| \in \{1,3\}$, eac
h giving $3! = 6$ arrangements per sign, total $24$, divided by orbit size $6$ g
ives $4$ distinct arrangements. Direct enumeration confirms this. ✓

## Answer

The total number of distinct arrangements is $\boxed{2 \times 1008!}$.
