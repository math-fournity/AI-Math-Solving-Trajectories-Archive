We prove the statement using the **Chevalley–Warning theorem**.

**Chevalley–Warning Theorem.** Let $f_1,\dots,f_k \in \mathbb{F}_p[t_1,\dots,t_m
]$ with $\sum_{j=1}^k \deg f_j < m$. Then the number of common zeros in $\mathbb
{F}_p^m$ is divisible by $p$.

**Setup.** Put $m = (p-1)n+1$ and introduce variables $t_1,\dots,t_m$ over $\mat
hbb{F}_p$. Write $x_i = (x_i^{(1)},\dots,x_i^{(n)}) \in \mathbb{F}_p^n$. For eac
h coordinate $j \in \{1,\dots,n\}$ define the polynomial
$$
P_j(t_1,\dots,t_m) \;=\; \sum_{i=1}^{m} x_i^{(j)}\, t_i^{\,p-1} \;\in\; \mathbb{
F}_p[t_1,\dots,t_m].
$$
Each $P_j$ is homogeneous of degree $p-1$, so
$$
\sum_{j=1}^{n} \deg P_j \;=\; n(p-1) \;=\; (p-1)n \;<\; (p-1)n+1 \;=\; m.
$$
The hypothesis of Chevalley–Warning is satisfied, hence the number
$$
N \;=\; \bigl|\{(t_1,\dots,t_m)\in\mathbb{F}_p^m : P_1=\cdots=P_n=0\}\bigr|
$$
is divisible by $p$.

**A nonzero solution exists.** The all-zero vector $\mathbf{0}=(0,\dots,0)$ is a
 common zero (every $P_j$ vanishes), so $N\ge 1$. Since $p\mid N$ and $p\ge 2$,
we have $N\ge p\ge 2$. Thus there exists a common zero $\mathbf{t}=(t_1,\dots,t_
m)\neq \mathbf{0}$.

**Extracting the subset.** By Fermat's little theorem, for $t_i\in\mathbb{F}_p$,
$$
t_i^{\,p-1} = \begin{cases} 1 & \text{if } t_i\neq 0,\\ 0 & \text{if } t_i = 0.
\end{cases}
$$
Define $I = \{\,i\in\{1,\dots,m\} : t_i \neq 0\,\}$. Since $\mathbf{t}\neq\mathb
f{0}$, the set $I$ is **non-empty**. For each coordinate $j$,
$$
0 = P_j(\mathbf{t}) = \sum_{i=1}^{m} x_i^{(j)}\,t_i^{\,p-1} = \sum_{i\in I} x_i^
{(j)}\cdot 1 = \Bigl(\sum_{i\in I} x_i\Bigr)^{(j)}.
$$
All $n$ coordinates of $\sum_{i\in I} x_i$ vanish, so
$$
\sum_{i\in I} x_i = 0 \in \mathbb{F}_p^n.
$$

Therefore a non-empty subset $I\subseteq\{1,\dots,(p-1)n+1\}$ with $\sum_{i\in I
}x_i=0$ always exists. $\blacksquare$
