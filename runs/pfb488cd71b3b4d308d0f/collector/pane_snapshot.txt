# Inverse Laplace Transform of $F(s) = \frac{e^{-1/s}}{s}$

## Setup: Key Properties

**Unit step function.** The Heaviside unit step function $u(t)$ satisfies
$$\mathcal{L}\{u(t)\} = \frac{1}{s}, \qquad \text{i.e., } \mathcal{L}^{-1}\!\lef
t\{\frac{1}{s}\right\} = u(t) = 1 \;\; (t \ge 0).$$

**Integral property.** If $g(t) = \mathcal{L}^{-1}\{G(s)\}$, then
$$\mathcal{L}^{-1}\!\left\{\frac{G(s)}{s}\right\} = \int_0^t g(\tau)\,d\tau.$$

Applying this repeatedly starting from $\mathcal{L}^{-1}\{1/s\} = u(t) = 1$:
$$\mathcal{L}^{-1}\!\left\{\frac{1}{s^2}\right\} = \int_0^t 1\,d\tau = t, \quad
\mathcal{L}^{-1}\!\left\{\frac{1}{s^3}\right\} = \int_0^t \tau\,d\tau = \frac{t^
2}{2}, \quad \dots$$
and by induction,
$$\mathcal{L}^{-1}\!\left\{\frac{1}{s^{n+1}}\right\} = \frac{t^n}{n!}, \qquad n
= 0, 1, 2, \dots$$
(where the $n=0$ case is precisely the unit step function $u(t)$).

## Expansion of $F(s)$

Expand the exponential in its Maclaurin series (valid for all $s \neq 0$):
$$e^{-1/s} = \sum_{n=0}^{\infty} \frac{(-1/s)^n}{n!} = \sum_{n=0}^{\infty} \frac
{(-1)^n}{n!\, s^n}.$$

Therefore
$$F(s) = \frac{e^{-1/s}}{s} = \sum_{n=0}^{\infty} \frac{(-1)^n}{n!\, s^{n+1}}.$$

## Term-by-Term Inversion

Since the series converges absolutely and uniformly on compact subsets of $\Re(s
) > 0$, we may invert term by term using the formula derived above:

$$f(t) = \mathcal{L}^{-1}\{F(s)\} = \sum_{n=0}^{\infty} \frac{(-1)^n}{n!}\,\math
cal{L}^{-1}\!\left\{\frac{1}{s^{n+1}}\right\} = \sum_{n=0}^{\infty} \frac{(-1)^n
}{n!}\cdot\frac{t^n}{n!} = \sum_{n=0}^{\infty} \frac{(-1)^n\, t^n}{(n!)^2}.$$

The $n=0$ term is $u(t) = 1$ (the unit step function), and each subsequent term
$t^n/n!$ is obtained from the previous one by the integral property — exactly as
 prescribed.

## Identification as a Bessel Function

Recall the Bessel function of the first kind of order zero:
$$J_0(z) = \sum_{n=0}^{\infty} \frac{(-1)^n}{(n!)^2}\left(\frac{z}{2}\right)^{\!
2n}.$$

Setting $z = 2\sqrt{t}$ so that $(z/2)^{2n} = (\sqrt{t})^{2n} = t^n$:
$$J_0(2\sqrt{t}) = \sum_{n=0}^{\infty} \frac{(-1)^n\, t^n}{(n!)^2}.$$

This is precisely the series we obtained.

## Verification

As a consistency check, compute directly:
$$\mathcal{L}\{J_0(2\sqrt{t})\} = \sum_{n=0}^{\infty} \frac{(-1)^n}{(n!)^2}\,\ma
thcal{L}\{t^n\} = \sum_{n=0}^{\infty} \frac{(-1)^n}{(n!)^2}\cdot\frac{n!}{s^{n+1

 F(s). \checkmark$$
