## Proof

**Claim.** For every infinite cardinal $\kappa$, it is possible to partition $\k
appa$ (viewed as an initial ordinal with its natural well-ordering) into countab
ly many pairwise disjoint cofinal subsets, each of cardinality $\kappa$.

**Key observation.** For any infinite cardinal $\kappa$ and any subset $A \subse
teq \kappa$ with $|A| = \kappa$, the set $A$ is automatically cofinal in $\kappa
$.

*Proof of observation.* Suppose for contradiction that $A$ is not cofinal, i.e.,
 $\sup A = \alpha < \kappa$. Then $A \subseteq \alpha + 1$, so $|A| \leq |\alpha
 + 1| = |\alpha|$. Since $\kappa$ is a cardinal (an initial ordinal), every ordi
nal $\alpha < \kappa$ satisfies $|\alpha| < \kappa$. Hence $|A| < \kappa$, contr
adicting $|A| = \kappa$. $\square$

Thus the cofinality condition is implied by the cardinality condition, and the p
roblem reduces to partitioning $\kappa$ into $\omega$-many disjoint subsets each
 of size $\kappa$.

**Construction.** Since $\kappa$ is infinite, $\kappa \cdot \aleph_0 = \max(\kap
pa, \aleph_0) = \kappa$, so there exists a bijection $f : \kappa \times \omega \
to \kappa$. For each $n \in \omega$, define
$$A_n = f[\kappa \times \{n\}] = \{f(\alpha, n) : \alpha < \kappa\}.$$

Then:
- **Disjointness:** If $n \neq m$, then $A_n \cap A_m = \emptyset$ since $f$ is
a bijection and the fibers $\kappa \times \{n\}$, $\kappa \times \{m\}$ are disj
oint.
- **Coverage:** $\bigcup_{n \in \omega} A_n = f[\kappa \times \omega] = \kappa$.
- **Cardinality:** Each $A_n$ is the image of $\kappa$ under $f(\cdot, n)$, so $
|A_n| = \kappa$.
- **Cofinality:** By the key observation, since $|A_n| = \kappa$ and $A_n \subse
teq \kappa$, each $A_n$ is cofinal in $\kappa$.

Therefore $\{A_n : n \in \omega\}$ is a partition of $\kappa$ into countably man
y pairwise disjoint cofinal subsets, each of cardinality $\kappa$.

**Conclusion.** Yes, it is possible for every infinite cardinal $\kappa$.
