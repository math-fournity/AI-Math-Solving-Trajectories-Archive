Looking at this problem, I need to determine whether the average order of all el

## Proof

**Setup.** For an odd prime p, the number of F_p-points on E(a,b,p) is given by
the character sum formula:

$$|E(a,b,p)| = p + 1 + \sum_{x \in \mathbb{F}_p} \chi(x^3 + ax + b)$$

where χ is the quadratic character on F_p (χ(0)=0, χ(y)=1 if y is a nonzero squa
re, χ(y)=−1 otherwise). This holds because the number of solutions to y² = c is
1 + χ(c).

Therefore the average equals p + 1 if and only if:

$$T := \sum_{(a,b) \in S} \sum_{x \in \mathbb{F}_p} \chi(x^3 + ax + b) = 0.$$

**Step 1: Sum over all pairs.** Define

$$T' = \sum_{(a,b) \in \mathbb{F}_p^2} \sum_{x \in \mathbb{F}_p} \chi(x^3 + ax +
 b).$$

Swap the order and sum over b first. For fixed x and a, set c = x³ + ax. Then:

$$\sum_{b \in \mathbb{F}_p} \chi(c + b) = \sum_{u \in \mathbb{F}_p} \chi(u) = 0,
$$

since the quadratic character sums to zero over F_p. Thus **T' = 0**.

**Step 2: Correction from singular pairs.** Since T = T' − C where

$$C = \sum_{(a,b):\, \Delta=0} \sum_{x \in \mathbb{F}_p} \chi(x^3 + ax + b),$$

and Δ = 4a³ + 27b², we need to show C = 0.

**Case p = 3.** Here 4a³ + 27b² ≡ a³ (mod 3), so Δ = 0 iff a = 0. The singular p
airs are (0, b) for all b ∈ F_3. Since x³ ≡ x (mod 3) for all x:

$$C = \sum_{b \in \mathbb{F}_3} \sum_{x \in \mathbb{F}_3} \chi(x + b) = \sum_{b
\in \mathbb{F}_3} 0 = 0. \quad \checkmark$$

**Case p ≥ 5.** Here 4 and 27 are both nonzero mod p. The singular pairs (4a³ +
27b² = 0) are:

- **(a, b) = (0, 0):** The sum is Σ_x χ(x³) = Σ_x χ(x) = 0, since χ(x³) = χ(x)³
= χ(x) for all x.

- **a ≠ 0:** From 4a³ = −27b², one shows (−a/3)³ = (b/2)², so −a/3 is a nonzero
square (if u³ is a square then χ(u³) = χ(u) = 1, so u is a square). Writing a =
−3t² for t ∈ F_p*, we get b² = 4t⁶, so b = ±2t³. The pairs (−3t², 2t³) and (−3t²
, −2t³) coincide as sets (via t ↔ −t), so the singular pairs with a ≠ 0 are exac
tly {(−3t², 2t³) : t ∈ F_p*}, which are p − 1 distinct pairs (injectivity: t² =
s² and t³ = s³ force t = s).

  For each such pair, the cubic factors:

  $$x^3 - 3t^2 x + 2t^3 = (x - t)^2(x + 2t).$$

  Therefore:

  $$\sum_x \chi\big((x-t)^2(x+2t)\big) = \sum_{x \neq t} \chi(x + 2t) = \left(\s
um_{u \in \mathbb{F}_p} \chi(u)\right) - \chi(3t) = -\chi(3)\chi(t).$$

  Summing over all t ∈ F_p*:

  $$\sum_{t \in \mathbb{F}_p^*} \big(-\chi(3)\chi(t)\big) = -\chi(3) \sum_{t \in
 \mathbb{F}_p^*} \chi(t) = -\chi(3) \cdot 0 = 0.$$

Combining both subcases: **C = 0 + 0 = 0** for p ≥ 5. ✓

**Step 3: Conclusion for odd p.** Since T = T' − C = 0 − 0 = 0:

$$\frac{1}{|S|} \sum_{(a,b) \in S} |E(a,b,p)| = p + 1 + \frac{T}{|S|} = p + 1.$$

**Case p = 2 (direct verification).** Here Δ = 4a³ + 27b² ≡ b² (mod 2), so S = {
(0,1), (1,1)}.

- E(0,1,2): y² = x³ + 1. Points: (0,1), (1,0), ∞ → |E| = 3 = p + 1.
- E(1,1,2): y² = x³ + x + 1. Points: (0,1), (1,1), ∞ → |E| = 3 = p + 1.

Average = (3 + 3)/2 = 3 = p + 1. ✓

**Final answer.** For every prime p:

$$\frac{1}{|S|} \sum_{(a,b) \in S} |E(a, b, p)| = p + 1.$$

The equation is **true**. The key insight is that the character sum Σ_x χ(x³ + a
x + b) averages to zero over all valid (a, b): the sum over all pairs vanishes b
y a simple orthogonality argument (summing over b first), and the correction fro
m the excluded singular pairs also vanishes — the cuspidal curve (0,0) contribut
es 0, and each nodal curve (−3t², 2t³) contributes −χ(3)χ(t), which sums to 0 ov
er t ∈ F_p*.
