## Setup

Place triangle ABC in the plane z = 0. Let H = (x, y, 0) and P = (x, y, h) with
h > 0. Set coordinates: A = (0, 0), B = (c, 0), C = (p, q) with q > 0, so Δ = ½c
q = 100.

The four heights of the tetrahedron:
- **h_P = h** (distance from P to face ABC)
- **h_A = Δh / S_PBC**, **h_B = Δh / S_PCA**, **h_C = Δh / S_PAB** (from V = ⅓·Δ
·h = ⅓·S·height)

## Condition: PH is the smallest height

The condition h ≤ h_A, h ≤ h_B, h ≤ h_C is equivalent (dividing by h > 0) to:

$$S_{PBC} \leq \Delta, \quad S_{PCA} \leq \Delta, \quad S_{PAB} \leq \Delta$$

## Computing the face areas

Using the cross product, for triangle PAB with PA = (A−P), PB = (B−P):

$$|\vec{PA} \times \vec{PB}|^2 = h^2|AB|^2 + 4\sigma_{AB}(H)^2$$

where σ_AB(H) is the signed area of triangle HAB in the plane. So:

$$S_{PAB} = \tfrac{1}{2}\sqrt{h^2 c^2 + 4\sigma_{AB}^2}$$

The condition S_PAB ≤ Δ becomes h²c² + 4σ_AB² ≤ 4Δ², and similarly for the other
 two faces.

## Existence of h > 0

For a given H, a valid h > 0 exists if and only if all three upper bounds on h²
are positive, i.e.:

$$|\sigma_{AB}(H)| < \Delta, \quad |\sigma_{BC}(H)| < \Delta, \quad |\sigma_{CA}
(H)| < \Delta$$

(For any such H, taking h sufficiently small satisfies all three inequalities, s
ince S → |σ| < Δ as h → 0.)

## Translating to strips

Since σ_AB(H) = ½·|AB|·d(H, AB) where d is the signed distance to line AB, the c
ondition |σ_AB| < Δ = ½·|AB|·h_C becomes |d(H, AB)| < h_C (the altitude from C).
 This defines a **strip** of width 2h_C centered on line AB.

Each condition defines a strip:
- **Strip AB**: between the line through C parallel to AB (inner boundary, where
 σ = Δ) and its reflection across AB (outer boundary, where σ = −Δ)
- **Strip BC** and **Strip CA**: analogously

The locus of H is the **intersection of three strips**.

## Computing the intersection area

Using the signed area identity σ_AB + σ_BC + σ_CA = Δ, I introduce normalized co
ordinates. With w = (x − py/q)/c and t = y/q, the three strip conditions become:

$$|w| < 1, \quad |t| < 1, \quad 0 < w + t < 2$$

The unit square (−1,1)×(−1,1) has area 4. The line w + t = 0 passes through corn
ers (−1,1) and (1,−1), cutting off the triangle {w+t < 0} with vertices (−1,−1),
 (−1,1), (1,−1) — a right triangle with legs 2, area 2. The constraint w + t < 2
 is automatically satisfied in the open square. So the region has **area 2** in
(w,t)-space.

The Jacobian of (w,t) → (x,y) is:

$$\frac{\partial(x,y)}{\partial(w,t)} = \begin{vmatrix} c & p \\ 0 & q \end{vmat
rix} = cq = 2\Delta = 200$$

## Geometric identification

The three inner boundaries (lines through vertices parallel to opposite sides) f
orm the **anticomplementary triangle** — the image of △ABC under homothety cente
red at the centroid with ratio −2. Each vertex of this triangle lies exactly on
the outer boundary of one strip (where σ = −Δ), and each side lies on an inner b
oundary (where σ = Δ). Since the σ-values are linear and achieve σ = −Δ only at
vertices, the entire anticomplementary triangle lies within all three strips, an
d no point outside it can satisfy all three strip conditions (any such point wou
ld have some σ > Δ).

Therefore, the locus of H is exactly the **anticomplementary triangle** of △ABC.

## Final computation

The anticomplementary triangle is a dilation of △ABC by factor 2, so its area is
 4Δ.

$$K = 4\Delta = 4 \times 100 = \boxed{400}$$
