## Proof

Let $f(t) = t^p - t - a \in F[t]$ where $\operatorname{char} F = p > 0$ and $a \
neq b^p - b$ for all $b \in F$.

**Step 1: The roots of $f$.**

Let $\alpha$ be a root of $f$ in some extension, so $\alpha^p - \alpha = a$. For
 each $c \in \mathbb{F}_p$ (the prime subfield of $F$), we have $c^p = c$, hence
$$(\alpha + c)^p - (\alpha + c) - a = \alpha^p + c^p - \alpha - c - a = (\alpha^
p - \alpha - a) + (c^p - c) = 0 + 0 = 0.$$
So $\alpha, \alpha+1, \ldots, \alpha+(p-1)$ are all roots of $f$. Since $f$ has
degree $p$, these are exactly all the roots, and they are distinct (they differ
by distinct elements of $\mathbb{F}_p$). Thus $f$ is separable, and the splittin
g field is
$$K = F(\alpha).$$

**Step 2: $f$ is irreducible over $F$.**

The hypothesis $a \neq b^p - b$ for all $b \in F$ means $f$ has no root in $F$.
By the Artin–Schreier theorem, the polynomial $t^p - t - a$ over a field of char
acteristic $p$ either splits completely over $F$ (which happens iff $a = b^p - b
$ for some $b \in F$) or is irreducible over $F$. Since $f$ has no root in $F$,
it does not split, hence $f$ is irreducible over $F$.

Therefore $[K : F] = [F(\alpha) : F] = p$, and since $K/F$ is the splitting fiel
d of a separable polynomial, $|Gal(K/F)| = [K:F] = p$.

**Step 3: The Galois group.**

Every $\sigma \in Gal(K/F)$ is determined by $\sigma(\alpha)$, which must be a r
oot of $f$, so $\sigma(\alpha) = \alpha + c_\sigma$ for some $c_\sigma \in \math
bb{F}_p$. The map
$$\varphi: Gal(K/F) \to \mathbb{F}_p, \quad \sigma \mapsto c_\sigma$$
is a group homomorphism into the additive group $(\mathbb{F}_p, +) \cong \mathbb
{Z}/p\mathbb{Z}$: if $\sigma(\alpha) = \alpha + c$ and $\tau(\alpha) = \alpha +
d$, then $(\sigma\tau)(\alpha) = \sigma(\alpha + d) = \alpha + c + d$, so $\varp
hi(\sigma\tau) = c + d = \varphi(\sigma) + \varphi(\tau)$.

The map $\varphi$ is injective (if $c_\sigma = 0$ then $\sigma = \mathrm{id}$).
Since $|Gal(K/F)| = p = |\mathbb{F}_p|$, the map $\varphi$ is an isomorphism.

**Conclusion.**

$$Gal(K/F) \cong \mathbb{Z}/p\mathbb{Z}.$$

The Galois group is cyclic of order $p$, generated by the automorphism $\sigma:
\alpha \mapsto \alpha + 1$.
