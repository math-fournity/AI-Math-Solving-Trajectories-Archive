Looking at this problem, I need to find the number of zeros of an entire functio
n $g(z)$ inside the unit square with vertices $0, 1, 1+i, i$, using the function
al equations and the argument principle.

## Proof

**Setup.** Let $S$ be the unit square in the first quadrant with vertices $0, 1,
 1+i, i$. Since $g$ is entire, it has no poles, so by the argument principle the
 number of zeros inside $S$ is:

$$N = \frac{1}{2\pi i}\oint_{\partial S} \frac{g'(z)}{g(z)}\,dz$$

The boundary $\partial S$ is traversed counterclockwise via four sides:
- $\gamma_1$ (bottom): $z = t,\; t: 0\to 1$, $\;dz = dt$
- $\gamma_2$ (right): $z = 1+it,\; t: 0\to 1$, $\;dz = i\,dt$
- $\gamma_3$ (top): $z = t+i,\; t: 1\to 0$, $\;dz = dt$
- $\gamma_4$ (left): $z = it,\; t: 1\to 0$, $\;dz = i\,dt$

**Logarithmic derivatives of the functional equations.**

From $g(z+1) = g(z)$, differentiating gives $g'(z+1) = g'(z)$, hence:
$$\frac{g'(z+1)}{g(z+1)} = \frac{g'(z)}{g(z)}. \tag{1}$$

From $g(z+i) = e^{\pi}\,e^{-2\pi i z}\,g(z)$, differentiating with respect to $z
$:
$$g'(z+i) = e^{\pi}(-2\pi i)\,e^{-2\pi i z}\,g(z) + e^{\pi}\,e^{-2\pi i z}\,g'(z
).$$

Dividing both sides by $g(z+i) = e^{\pi}\,e^{-2\pi i z}\,g(z)$:
$$\frac{g'(z+i)}{g(z+i)} = -2\pi i + \frac{g'(z)}{g(z)}. \tag{2}$$

**Evaluating the four contour integrals.**

Let $I_k = \int_{\gamma_k} \frac{g'(z)}{g(z)}\,dz$.

*Bottom side* $\gamma_1$: $z = t$,
$$I_1 = \int_0^1 \frac{g'(t)}{g(t)}\,dt.$$

*Right side* $\gamma_2$: $z = 1+it$. Using $(1)$ with $z = it$: $g(1+it) = g(it)
$ and $g'(1+it) = g'(it)$, so
$$I_2 = \int_0^1 \frac{g'(it)}{g(it)}\,i\,dt.$$

*Left side* $\gamma_4$: $z = it,\; t:1\to 0$,
$$I_4 = \int_1^0 \frac{g'(it)}{g(it)}\,i\,dt = -\int_0^1 \frac{g'(it)}{g(it)}\,i
\,dt = -I_2.$$

Therefore $I_2 + I_4 = 0$: **the vertical sides cancel.**

*Top side* $\gamma_3$: $z = t+i,\; t:1\to 0$. Using $(2)$ with $z = t$:
$$\frac{g'(t+i)}{g(t+i)} = \frac{g'(t)}{g(t)} - 2\pi i.$$

Thus
$$I_3 = \int_1^0 \frac{g'(t+i)}{g(t+i)}\,dt = -\int_0^1\left(\frac{g'(t)}{g(t)}
- 2\pi i\right)dt = -I_1 + 2\pi i\int_0^1 dt = -I_1 + 2\pi i.$$

**Combining.** The total contour integral is:
$$I_1 + I_2 + I_3 + I_4 = I_1 + I_2 + (-I_1 + 2\pi i) + (-I_2) = 2\pi i.$$

The terms $I_1$ and $I_2$ cancel completely — the individual values of the integ
rals along the bottom and right sides are irrelevant; only the functional equati
ons matter.

**Conclusion.** The number of zeros is:
$$N = \frac{1}{2\pi i}\cdot 2\pi i = 1.$$

The function $g(z)$ has exactly **1 zero** inside the unit square in the first q
uadrant.
