### Setup

Let $a_k = f(2^k)$. We have $f(0)=0$, i.e. $a_{-1}$-style base cases live at $f(
0)$.

For $x=2^k$ with $k\ge 2$: $\lfloor 2^k/2\rfloor = 2^{k-1}$ and $\lfloor 2^k/4\r
floor = 2^{k-2}$, so
$$a_k = 1 + 5a_{k-1} - 6a_{k-2}.$$

**Base cases:**
- $k=0$: $x=1$, $\lfloor 1/2\rfloor=0$, $\lfloor 1/4\rfloor=0$: $a_0 = 1 + 5f(0)
-6f(0) = 1$.
- $k=1$: $x=2$, $\lfloor 2/2\rfloor=1$, $\lfloor 2/4\rfloor=0$: $a_1 = 1 + 5f(1)
-6f(0) = 1+5 = 6$.

### Solving the recurrence

The recurrence $a_k - 5a_{k-1} + 6a_{k-2} = 1$ is nonhomogeneous. Particular sol
ution (constant): try $a_k=C$: $C-5C+6C=1 \Rightarrow 2C=1 \Rightarrow C=\tfrac1
2$.

Homogeneous characteristic: $r^2-5r+6=0 \Rightarrow (r-2)(r-3)=0$, so $r=2,3$.

General solution: $a_k = \tfrac12 + A\cdot 2^k + B\cdot 3^k$.

Using $a_0=1$: $\tfrac12 + A + B = 1 \Rightarrow A+B=\tfrac12$.
Using $a_1=6$: $\tfrac12 + 2A + 3B = 6 \Rightarrow 2A+3B=\tfrac{11}{2}$.

Solving: $A=\tfrac12-B$; $2(\tfrac12-B)+3B=\tfrac{11}{2}\Rightarrow 1+B=\tfrac{1
1}{2}\Rightarrow B=\tfrac92$; $A=-4$.

$$\boxed{a_k = \tfrac12 - 4\cdot 2^k + \tfrac92\cdot 3^k.}$$

**Verification:** $a_0=\tfrac12-4+\tfrac92=1$ ✓; $a_1=\tfrac12-8+\tfrac{27}{2}=6
$ ✓; $a_2=\tfrac12-16+\tfrac{81}{2}=25$, and directly $1+5(6)-6(1)=25$ ✓.

### Summing

$$S=\sum_{k=0}^{10} a_k = \tfrac{11}{2} - 4\sum_{k=0}^{10}2^k + \tfrac92\sum_{k=
0}^{10}3^k.$$

- $\sum_{k=0}^{10}2^k = 2^{11}-1 = 2047$.
- $\sum_{k=0}^{10}3^k = \tfrac{3^{11}-1}{2} = \tfrac{177147-1}{2} = 88573$.

$$S = \tfrac{11}{2} - 4(2047) + \tfrac92(88573) = \tfrac{11}{2} - 8188 + \tfrac{
797157}{2} = \tfrac{797168}{2} - 8188 = 398584 - 8188.$$

$$S = 390396.$$
