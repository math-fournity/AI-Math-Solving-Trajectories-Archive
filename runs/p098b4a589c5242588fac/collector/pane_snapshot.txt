## Solution

The totally unpainted cubes are the interior cubes that have no face on the surf
ace. For an $a\times b\times c$ block, the number of interior cubes is $(a-2)(b-
2)(c-2)$, provided $a,b,c\ge 2$; otherwise it is $0$. Since the probability is $
20\% = 1/5 > 0$, we must have $a,b,c\ge 3$.

Setting $x=a-2,\ y=b-2,\ z=c-2$ (all $\ge 1$), the condition is

$$\frac{xyz}{(x+2)(y+2)(z+2)}=\frac15 \quad\Longleftrightarrow\quad \left(1+\fra
c2x\right)\left(1+\frac2y\right)\left(1+\frac2z\right)=5.$$

Assume WLOG $x\le y\le z$. Then the largest factor is $1+2/x$, so $(1+2/x)^3\ge
5$, giving $x\le 2$. Also each factor $>1$, so $1+2/x\le 5$ is automatic.

**Case $x=1$:** $1+2/x=3$, so $(1+2/y)(1+2/z)=5/3$. Solving for $z$:

$$\frac2z = \frac{5/3}{1+2/y}-1 = \frac{2(y-3)}{3(y+2)} \implies z = 3+\frac{15}
{y-3}.$$

We need $y>3$ and $y-3\mid 15$, so $y-3\in\{1,3,5,15\}$, i.e. $y\in\{4,6,8,18\}$
. The constraint $z\ge y$ eliminates $y=8$ (gives $z=7<y$) and $y=18$ (gives $z=
4<y$). This leaves:
- $y=4,\ z=18$: $(x,y,z)=(1,4,18)\Rightarrow (a,b,c)=(3,6,20)$, $abc=360$.
- $y=6,\ z=8$: $(x,y,z)=(1,6,8)\Rightarrow (a,b,c)=(3,8,10)$, $abc=240$.

**Case $x=2$:** $1+2/x=2$, so $(1+2/y)(1+2/z)=5/2$. Solving:

$$\frac2z=\frac{5/2}{1+2/y}-1=\frac{3y-4}{2(y+2)} \implies z=\frac{4(y+2)}{3y-4}
.$$

Testing $y\ge 2$ with $z\ge y$:
- $y=2$: $z=8$, giving $(x,y,z)=(2,2,8)\Rightarrow (a,b,c)=(4,4,10)$, $abc=160$.
- $y=3$: $z=4$, giving $(x,y,z)=(2,3,4)\Rightarrow (a,b,c)=(4,5,6)$, $abc=120$.
- $y\ge 4$: $z=4(y+2)/(3y-4)\le 3 < y$, so no further solutions with $z\ge y$.

**Verification:** Each solution satisfies $(a-2)(b-2)(c-2)/(abc)=1/5$:
- $(3,6,20)$: $1\cdot4\cdot18/360 = 72/360 = 1/5$. ✓
- $(3,8,10)$: $1\cdot6\cdot8/240 = 48/240 = 1/5$. ✓
- $(4,4,10)$: $2\cdot2\cdot8/160 = 32/160 = 1/5$. ✓
- $(4,5,6)$: $2\cdot3\cdot4/120 = 24/120 = 1/5$. ✓

The possible values of $abc$ are $360,\ 240,\ 160,\ 120$, and their sum is

$$360+240+160+120 = \boxed{880}.$$
