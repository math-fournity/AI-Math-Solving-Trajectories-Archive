f(x+y)) = f(x) + (2x+y)g(y) where R is a commutative ring with 2 not a zero divi
sor.

## Solution

**Answer:** All solutions are $g(x) = cx$ and $f(x) = cx^2 + a$, where $c, a \in
 R$ satisfy $c^2 = c$ (i.e., $c$ is idempotent) and $a(1-c) = 0$ (equivalently $
a = ac$).

---

### Proof

Let $P(x,y)$ denote the given equation. Set $a = f(0)$, $b = g(0)$.

**Step 1: Two key substitutions.**

$P(0,y)$: $g(f(y)) = a + y\,g(y)$. &emsp; (1)

$P(x,0)$: $g(f(x)) = f(x) + 2x\,b$. &emsp; (2)

From (1) and (2): $a + x\,g(x) = f(x) + 2xb$, so
$$f(x) = a + x\,g(x) - 2xb. \tag{3}$$

**Step 2: Eliminate $f$ and $g(f(\cdot))$.**

Applying (1) with $y \to x+y$: $g(f(x+y)) = a + (x+y)\,g(x+y)$. Combining with $
P(x,y)$:
$$a + (x+y)\,g(x+y) = f(x) + (2x+y)\,g(y).$$
Substituting (3) and simplifying:
$$(x+y)\,g(x+y) = x\,g(x) + (2x+y)\,g(y) - 2xb. \tag{5}$$

**Step 3: Reduce to a homogeneous equation.**

Set $h(x) = g(x) - b$, so $h(0) = 0$. Substituting $g = h + b$ into (5), the con
stant terms involving $b$ cancel exactly:
$$(x+y)\,h(x+y) = x\,h(x) + (2x+y)\,h(y). \tag{6}$$

**Step 4: Symmetry gives a Cauchy-type relation.**

Swapping $x \leftrightarrow y$ in (6):
$$(x+y)\,h(x+y) = y\,h(y) + (2y+x)\,h(x).$$
Equating with (6) and simplifying:
$$2x\,h(y) = 2y\,h(x) \quad \text{for all } x, y.$$
Since $2$ is not a zero divisor, we deduce
$$x\,h(y) = y\,h(x) \quad \text{for all } x, y \in R. \tag{9}$$

**Step 5: Determine $h$, $g$, and $f$.**

Setting $y = 1$ in (9): $h(x) = x\,h(1)$. Let $c = h(1)$, so $h(x) = cx$ and
$$g(x) = cx + b.$$
From (3): $f(x) = a + x(cx+b) - 2xb = cx^2 - bx + a$.

**Step 6: Find constraints on $a, b, c$.**

Substitute $g(x) = cx + b$, $f(x) = cx^2 - bx + a$ into the original equation. B
oth sides depend only on $z = x+y$:

- LHS: $g(f(z)) = c(cz^2 - bz + a) + b = c^2 z^2 - bcz + ca + b$.
- RHS: $f(x) + (2x+y)\,g(y) = cx^2 - bx + a + (2x+y)(cy+b) = c(x+y)^2 + b(x+y) +
 a = cz^2 + bz + a$.

Equating for all $z$:
- $z^2$: $c^2 = c$, i.e., $c(c-1) = 0$.
- $z^1$: $-bc = b$, i.e., $b(1+c) = 0$.
- $z^0$: $ca + b = a$, i.e., $b = a(1-c)$.

From $b = a(1-c)$ and $b(1+c) = 0$: $a(1-c)(1+c) = a(1-c^2) = a(1-c) = b = 0$. S
o $b = 0$ and $a(1-c) = 0$.

**Step 7: Verification.**

With $g(x) = cx$, $f(x) = cx^2 + a$, $c^2 = c$, $a(1-c) = 0$:
$$g(f(x+y)) = c\bigl(c(x+y)^2 + a\bigr) = c^2(x+y)^2 + ca = c(x+y)^2 + a,$$
$$f(x) + (2x+y)\,g(y) = cx^2 + a + (2x+y)\,cy = c(x+y)^2 + a. \quad\checkmark$$

**Conclusion.** The solutions are exactly
$$\boxed{g(x) = cx, \quad f(x) = cx^2 + a,}$$
where $c \in R$ is any idempotent ($c^2 = c$) and $a \in R$ satisfies $a = ac$ (
equivalently $a(1-c) = 0$).

*Special cases:* When $R$ is an integral domain (e.g., $\mathbb{R}$), the only i
dempotents are $0$ and $1$, giving $f = g = 0$ (with $c=0, a=0$) or $f(x) = x^2
+ a$, $g(x) = x$ (with $c=1$, $a$ arbitrary).
