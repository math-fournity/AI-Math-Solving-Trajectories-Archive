## Key Reduction

Compute the remainder of $g$ modulo $f$:

$$g(X) - X^{n-m}f(X) = (aX+b) - X^{n-m}(aX+b) = (aX+b)(1 - X^{n-m})$$

So $f \mid g \iff f \mid (aX+b)(X^{n-m}-1)$.

**When $b \neq 0$:** Since $aX+b$ has degree 1, $aX+b \mid f$ would require $f(-
b/a) = (-b/a)^m = 0$, forcing $b=0$—contradiction. So $\gcd(f, aX+b)=1$, and we
need $f \mid X^{n-m}-1$. All roots of $f$ must be roots of unity, forcing $|b|=1
$ and $|a|=1$ (via absolute values of roots).

**When $b = 0$:** $f = X(X^{m-1}+a)$, $g = X(X^{n-1}+a)$, so need $(X^{m-1}+a) \
mid (X^{n-1}+a)$, which reduces to $(X^{m-1}+a) \mid (X^{n-m}-1)$. Again $|a|=1$
.

**When $a = 0$:** $f = X^m+b$, $g = X^n+b$. Need $X^m+b \mid X^n+b$.

## Subset 1: $a \neq 0, b \neq 0, 1 < m < n \leq 6$

Need $f \mid X^{n-m}-1$ with $f = X^m + aX + b$, $|a|=|b|=1$, so $f$ is a produc
t of cyclotomic polynomials.

- **$m=2$:** Degree-2 cyclotomic products with $a \neq 0$: $\Phi_3 = X^2+X+1$ ($
a=1,b=1$), $\Phi_6 = X^2-X+1$ ($a=-1,b=1$).
  - $\Phi_3 \mid X^k-1 \iff 3\mid k$. With $k=n-2 \leq 4$: $k=3$, $n=5$. → **$(1
,1,2,5)$** ✓
  - $\Phi_6 \mid X^k-1 \iff 6\mid k$. With $k \leq 4$: none.
- **$m=3$:** $n-m \leq 3$, $\deg f = 3$. Only $k=3$: $f \mid X^3-1 = (X-1)(X^2+X
+1)$, so $f=X^3-1$, $a=0$. ✗
- **$m \geq 4$:** $\deg f = m > n-m$. Impossible.

**Subset 1 solutions:** $\{(1,1,2,5)\}$
