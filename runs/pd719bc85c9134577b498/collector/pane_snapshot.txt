## Proof

Let $z = x + iy$ and write $f(z) = U(x,y) + iV(x,y)$ where, by hypothesis,
$$U(x,y) = u(x), \qquad V(x,y) = v(y),$$
with $u$ a function of $x$ alone and $v$ a function of $y$ alone.

Since $f$ is entire, it is holomorphic everywhere, so the Cauchy–Riemann equatio
ns hold for all $(x,y)$:
$$U_x = V_y, \qquad U_y = -V_x.$$

Computing the partial derivatives:
$$U_x = u'(x), \quad U_y = 0, \quad V_x = 0, \quad V_y = v'(y).$$

The second Cauchy–Riemann equation $U_y = -V_x$ becomes $0 = 0$, which is automa
tically satisfied.

The first equation gives
$$u'(x) = v'(y) \qquad \text{for all } x, y \in \mathbb{R}.$$

The left-hand side depends only on $x$ while the right-hand side depends only on
 $y$. Fixing $y$ and varying $x$ shows $u'(x)$ is constant; fixing $x$ and varyi
ng $y$ shows $v'(y)$ is the same constant. Hence there exists $c \in \mathbb{R}$
 such that
$$u'(x) = c, \qquad v'(y) = c.$$

Integrating,
$$u(x) = cx + a, \qquad v(y) = cy + b$$
for real constants $a, b$.

Therefore
$$f(z) = u(x) + iv(y) = (cx + a) + i(cy + b) = c(x + iy) + (a + ib) = cz + d,$$
where $c \in \mathbb{R}$ and $d = a + ib \in \mathbb{C}$.

**Verification.** Every function $f(z) = cz + d$ with $c \in \mathbb{R}$, $d \in
 \mathbb{C}$ is entire (being affine). Writing $d = a+ib$, we have $f(z) = (cx+a
) + i(cy+b)$, which is indeed of the form $u(x) + iv(y)$ with $u(x) = cx+a$ and
$v(y) = cy+b$.

**Conclusion.** The most general entire function of the form $f(z) = u(x) + iv(y
)$ is
$$\boxed{f(z) = cz + d, \qquad c \in \mathbb{R},\ d \in \mathbb{C}.}$$
