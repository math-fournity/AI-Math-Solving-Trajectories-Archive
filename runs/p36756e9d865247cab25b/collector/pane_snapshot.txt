Looking at this problem, I need to find different positive integers $A, B$ (with
 $A > B$) such that the arithmetic mean $\frac{A+B}{2}$, geometric mean $\sqrt{A
B}$, and harmonic mean $\frac{2AB}{A+B}$ are all integers, minimizing $A - B$.

## Setup

Let $d = \gcd(A, B)$, $A = da$, $B = db$ with $\gcd(a, b) = 1$. The three means
become:
- $M_1 = \frac{d(a+b)}{2}$, $\quad M_2 = d\sqrt{ab}$, $\quad M_3 = \frac{2dab}{a
+b}$

**$M_2$ integer** $\Rightarrow$ $ab$ is a perfect square. Since $\gcd(a,b)=1$, b
oth $a$ and $b$ are perfect squares: $a = s^2$, $b = t^2$ with $\gcd(s,t)=1$, $s
 > t \geq 1$.

Now $M_1 = \frac{d(s^2+t^2)}{2}$, $\;M_3 = \frac{2ds^2t^2}{s^2+t^2}$.

**Key lemma:** $\gcd(s^2+t^2,\, s^2t^2) = 1$. *Proof:* If prime $p \mid \gcd(s^2
+t^2, s^2)$, then $p \mid s$ and $p \mid t^2 = (s^2+t^2)-s^2$, so $p \mid t$, co
ntradicting $\gcd(s,t)=1$. Similarly $\gcd(s^2+t^2, t^2)=1$. ∎

Therefore $M_3$ integer requires $(s^2+t^2) \mid 2d$. Write $2d = m(s^2+t^2)$, s
o $d = \frac{m(s^2+t^2)}{2}$.

The difference is:
$$A - B = d(s^2 - t^2) = \frac{m(s^2+t^2)(s^2-t^2)}{2} = \frac{m(s^4 - t^4)}{2}$
$

**$M_1$ integer** requires $d(s^2+t^2) = \frac{m(s^2+t^2)^2}{2}$ to be even, i.e
., $m(s^2+t^2)^2 \equiv 0 \pmod{4}$.

Let $k = s^2 + t^2$.

## Case Analysis

**Case A: $k$ even** (both $s,t$ odd, since coprime). Then $k^2 \equiv 0 \pmod{4
}$, so $m \geq 1$ suffices. Minimum $m=1$:
$$A - B = \frac{s^4 - t^4}{2}$$
Smallest coprime odd pair with $s > t$: $(s,t) = (3,1)$, giving $A - B = \frac{8
1-1}{2} = 40$.

**Case B: $k$ odd** (one of $s,t$ even, the other odd). Then $k^2$ is odd, so $4
 \mid m$. Minimum $m=4$:
$$A - B = \frac{4(s^4 - t^4)}{2} = 2(s^4 - t^4)$$
Smallest coprime pair with mixed parity: $(s,t) = (2,1)$, giving $A - B = 2(16-1
) = 30$.

## Verification of the optimum $(s,t,m) = (2,1,4)$

$d = \frac{4 \cdot 5}{2} = 10$, so $A = 10 \cdot 4 = 40$, $B = 10 \cdot 1 = 10$,
 $A - B = 30$.

- $M_1 = \frac{40+10}{2} = 25$ ✓ (integer)
- $M_2 = \sqrt{400} = 20$ ✓ (integer)
- $M_3 = \frac{2 \cdot 400}{50} = 16$ ✓ (integer)

## No smaller solution exists

The algebraic analysis shows the minimum in Case A is 40 and in Case B is 30. To

## Conclusion

The minimum value of $a - b$ is $\boxed{30}$, achieved by $(A, B) = (40, 10)$.
