Let $f$ be a polynomial with $\deg f = n$.

**Degree analysis.** If $n \ge 2$, then $\deg f(2x) = n$ while $\deg(f'f'') = (n
-1)+(n-2) = 2n-3$. Equating,
$$n = 2n - 3 \implies n = 3.$$
If $n \le 1$: for $n=0$, $f\equiv c$ gives $c = 0\cdot 0 = 0$, so $f\equiv 0$; f
or $n=1$, $f(x)=ax+b$ gives $f''=0$, so $f(2x)=0$, forcing $a=b=0$. Both collaps
e to the trivial solution $f\equiv 0$, with $f(3)=0$.

**The cubic case.** Write $f(x)=ax^3+bx^2+cx+d$, $a\ne 0$. Then
$$f(2x) = 8ax^3+4bx^2+2cx+d,$$
$$f'(x)=3ax^2+2bx+c,\qquad f''(x)=6ax+2b,$$
$$f'(x)f''(x) = 18a^2x^3+18abx^2+(4b^2+6ac)x+2bc.$$

Equating coefficients with $f(2x)$:

- $x^3$: $8a = 18a^2 \Rightarrow a(18a-8)=0 \Rightarrow a = \tfrac{4}{9}$.
- $x^2$: $4b = 18ab = 8b \Rightarrow b = 0$.
- $x^1$: $2c = 4b^2+6ac = \tfrac{8}{3}c \Rightarrow c = 0$.
- $x^0$: $d = 2bc = 0$.

So $f(x) = \tfrac{4}{9}x^3$.

**Verification.** $f(2x)=\tfrac{4}{9}\cdot 8x^3=\tfrac{32}{9}x^3$; $f'(x)=\tfrac
{4}{3}x^2$, $f''(x)=\tfrac{8}{3}x$; $f'(x)f''(x)=\tfrac{4}{3}\cdot\tfrac{8}{3}x^
3=\tfrac{32}{9}x^3$. ✓

**Evaluating.** The nontrivial solution gives
$$f(3) = \tfrac{4}{9}\cdot 27 = 12.$$

(The trivial solution $f\equiv 0$ also satisfies the equation, giving $f(3)=0$;
the nontrivial cubic is the intended answer.)
