### Substitution

Let $y_i = x_i + (i-1)$ for $i = 1, 2, \ldots, 8$. Then the Stability Rating bec
omes
$$S = \sum_{i=1}^{8} y_i^2.$$

The constraints transform as follows:

- **Non-negativity:** $x_i \ge 0 \Rightarrow y_i \ge i-1$.
- **Non-decreasing:** $x_i \le x_{i+1} \Rightarrow y_i - (i-1) \le y_{i+1} - i \
Rightarrow y_i \le y_{i+1} - 1$, i.e., $y_1 < y_2 < \cdots < y_8$ (strictly incr
easing integers).
- **Total:** $\sum x_i = 32 \Rightarrow \sum y_i - \sum_{i=1}^{8}(i-1) = 32 \Rig
htarrow \sum y_i = 32 + 28 = 60$.

So we must **maximize** $\sum y_i^2$ over strictly increasing integers $y_1 < y_
2 < \cdots < y_8$ with $y_i \ge i-1$ and $\sum y_i = 60$.

### Convexity argument (optimality of concentration)

The function $f(t) = t^2$ is strictly convex. For a fixed sum, the sum of square
s $\sum y_i^2$ is **Schur-convex**: it is maximized when the vector $(y_1, \ldot
s, y_8)$ is as "spread out" (majorized by all others) as possible — i.e., when w
e push as much mass as possible into the largest component and keep all others a
t their minimums.

**Claim:** The unique maximizer is $y_1=0,\; y_2=1,\; y_3=2,\; y_4=3,\; y_5=4,\;
 y_6=5,\; y_7=6,\; y_8=39$.

**Proof of claim.** Let $(y_1, \ldots, y_8)$ be any feasible solution with $\sum
 y_i = 60$. The minimum feasible values are $y_i \ge i-1$, giving a minimum tota
l of $0+1+\cdots+7 = 28$, leaving $60 - 28 = 32$ units of "slack" to distribute.

Consider any feasible solution that is **not** of the form $(0,1,2,3,4,5,6,39)$.
 Then there exist indices $j < k$ with $y_j > j-1$ and $y_k < 39$ (i.e., not all
 slack is concentrated in $y_8$). We can perform a **transfer**: decrease $y_j$
by 1 (still feasible since $y_j > j-1 \ge y_{j-1}+1$ ensures strict increase is
maintained after decrement, as long as $y_j - 1 > y_{j-1}$; if $y_j = y_{j-1}+1$
 we cannot decrement $y_j$ — but in that case $y_j$ is at its local minimum rela
tive to $y_{j-1}$, so the slack is elsewhere).

More precisely: among all feasible solutions with $\sum y_i = 60$, take any one
where some $y_j$ with $j < 8$ exceeds its minimum $j-1$. Then $y_8 \ge y_7 + 1 \
ge \cdots$. We can decrease $y_j$ by 1 and increase $y_8$ by 1, provided $y_j -
1 > y_{j-1}$ (with $y_0 = -1$). The change in $S$ is:
$$(y_8+1)^2 + (y_j-1)^2 - y_8^2 - y_j^2 = 2y_8 + 1 - 2y_j + 1 = 2(y_8 - y_j) + 2
 > 0,$$
since $y_8 > y_j$. So $S$ strictly increases. This transfer is valid as long as
$y_j - 1 > y_{j-1}$, i.e., $y_j \ge y_{j-1} + 2$.

If $y_j = y_{j-1} + 1$ (tight), then $y_j$ cannot be decremented. But then $y_{j
-1}$ might have slack. By induction from $j=1$ downward: if $y_1 \ge 1$, we can
decrement $y_1$ and increment $y_8$. If $y_1 = 0$ (at minimum) and $y_2 = y_1+1
= 1$ (tight), and $y_3 = y_2+1 = 2$ (tight), ..., up to some $y_k$ which has sla
ck ($y_k \ge y_{k-1}+2$), we decrement $y_k$ and increment $y_8$. The only case
where **no** $y_j$ ($j < 8$) can be decremented is when $y_i = i-1$ for all $i =
 1, \ldots, 7$, which forces $y_8 = 60 - 21 = 39$.

Therefore every feasible solution other than $(0,1,2,3,4,5,6,39)$ can be improve
d, proving this is the **unique** maximizer. $\square$
