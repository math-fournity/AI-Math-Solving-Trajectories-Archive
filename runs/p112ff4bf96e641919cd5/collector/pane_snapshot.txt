## Green's Function for \(y'' + y = \delta(x-z)\), \(y(0)=y(\pi/2)=0\)

**Setup.** The Green's function \(G(x,z)\) satisfies
\[
\frac{\partial^2 G}{\partial x^2} + G = \delta(x-z), \qquad G(0,z)=0,\quad G(\tf
rac{\pi}{2},z)=0,
\]
with the standard matching conditions at \(x=z\):
- \(G\) is continuous at \(x=z\);
- \(\displaystyle \left.\frac{\partial G}{\partial x}\right|_{z^+} - \left.\frac
{\partial G}{\partial x}\right|_{z^-} = 1\) (the jump equals the coefficient of
the highest derivative, which is \(1\)).

**Solving on each subinterval.** For \(x\neq z\), the equation is homogeneous: \
(G''+G=0\), with general solution
\[
G(x,z) = A\,\sin x + B\,\cos x.
\]

*Left region* \(0\le x < z\): The boundary condition \(G(0,z)=0\) gives \(B=0\)
(since \(\cos 0=1,\ \sin 0=0\)). Hence
\[
G(x,z) = A\,\sin x, \qquad 0\le x < z.
\]

*Right region* \(z < x \le \pi/2\): The boundary condition \(G(\pi/2,z)=0\) give
s \(A\cdot 1 + B\cdot 0 = 0\), so \(A=0\). Hence
\[
G(x,z) = B\,\cos x, \qquad z < x \le \pi/2.
\]

**Matching at \(x=z\).**

*Continuity:*
\[
A\,\sin z = B\,\cos z. \tag{1}
\]

*Jump in derivative:*
\[
G'(z^+) - G'(z^-) = 1.
\]
Here \(G'(z^-) = A\cos z\) and \(G'(z^+) = -B\sin z\), so
\[
-B\,\sin z - A\,\cos z = 1. \tag{2}
\]

From (1): \(B = A\,\dfrac{\sin z}{\cos z} = A\tan z\). Substituting into (2):
\[
-A\tan z\cdot\sin z - A\cos z = 1
\;\Longrightarrow\;
-A\!\left(\frac{\sin^2 z}{\cos z} + \cos z\right) = 1
\;\Longrightarrow\;
-A\,\frac{\sin^2 z + \cos^2 z}{\cos z} = 1.
\]
Thus
\[
A = -\cos z, \qquad B = -\cos z\cdot\tan z = -\sin z.
\]

**Result.**
\[
\boxed{G(x,z) = \begin{cases}
-\cos z\,\sin x, & 0 \le x \le z,\\[4pt]
-\sin z\,\cos x, & z \le x \le \pi/2.
\end{cases}}
\]

Equivalently, using \(\min\) and \(\max\),
\[
G(x,z) = -\sin\!\bigl(\min(x,z)\bigr)\,\cos\!\bigl(\max(x,z)\bigr).
\]

**Verification.**

*Boundary conditions:* \(G(0,z) = -\cos z\cdot\sin 0 = 0\). \(G(\pi/2,z) = -\sin
 z\cdot\cos(\pi/2) = 0\). ✓

*Continuity at \(x=z\):* \(G(z^-,z) = -\cos z\sin z = -\sin z\cos z = G(z^+,z)\)
. ✓

*Jump condition:*
\[
G'(z^-) = -\cos z\cdot\cos z = -\cos^2 z, \qquad
G'(z^+) = \sin z\cdot\sin z = \sin^2 z,
\]
\[
G'(z^+) - G'(z^-) = \sin^2 z + \cos^2 z = 1. \;\checkmark
\]

*Symmetry (self-adjointness):* Since \(G(x,z)=-\sin(\min(x,z))\cos(\max(x,z))\),
 swapping \(x\leftrightarrow z\) leaves \(\min\) and \(\max\) unchanged, so \(G(
x,z)=G(z,x)\). ✓
