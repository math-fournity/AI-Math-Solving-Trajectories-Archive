## Solution

**Step 1: First integral (energy integral).**

Starting from the autonomous ODE

$$\frac{d^2 w}{dz^2} = w^3 + e\,w^2 + f\,w,$$

multiply both sides by $\frac{dw}{dz}$:

$$\frac{dw}{dz}\cdot\frac{d^2 w}{dz^2} = \frac{dw}{dz}\bigl(w^3 + e\,w^2 + f\,w\
bigr).$$

The left-hand side is $\tfrac{1}{2}\frac{d}{dz}\!\left(\frac{dw}{dz}\right)^2$ a
nd the right-hand side is $\frac{d}{dz}\!\left(\tfrac{1}{4}w^4 + \tfrac{e}{3}w^3
 + \tfrac{f}{2}w^2\right)$. Integrating with respect to $z$:

$$\frac{1}{2}\left(\frac{dw}{dz}\right)^2 = \frac{1}{4}w^4 + \frac{e}{3}w^3 + \f
rac{f}{2}w^2 + C,$$

or, setting $C_1 = 2C$,

$$\boxed{\left(\frac{dw}{dz}\right)^2 = \tfrac{1}{2}\,w^4 + \tfrac{2e}{3}\,w^3 +
 f\,w^2 + C_1\;} \;=:\; P(w). \tag{1}$$

This is the **first integral**. The constant $C_1$ is one of the two arbitrary c
onstants of the general solution.

**Step 2: Reduction to Weierstrass form.**

Equation (1) has the form $\left(\frac{dw}{dz}\right)^2 = P(w)$ where $P$ is a q
uartic. Writing

$$P(w) = a_0\,w^4 + 4a_1\,w^3 + 6a_2\,w^2 + 4a_3\,w + a_4$$

we identify $a_0 = \tfrac12,\; a_1 = \tfrac{e}{6},\; a_2 = \tfrac{f}{6},\; a_3 =
 0,\; a_4 = C_1$.

Let $w_0$ be any **simple root** of $P$ (i.e., $P(w_0)=0$, $P'(w_0)\neq 0$). Sub
stitute

$$w = w_0 + \frac{1}{u}, \qquad \frac{dw}{dz} = -\frac{1}{u^2}\frac{du}{dz}.$$

Since $P(w_0)=0$, expanding $P(w_0+1/u)$ in powers of $1/u$ and multiplying by $
u^4$ yields a **cubic** in $u$:

$$\left(\frac{du}{dz}\right)^2 = 4A\,u^3 + 6B\,u^2 + 4C\,u + D, \tag{2}$$

where

$$A = \tfrac{1}{2}\,w_0\!\left(w_0^2 + e\,w_0 + f\right), \quad B = \frac{3w_0^2
+2e\,w_0+f}{6}, \quad C = \frac{3w_0+e}{6}, \quad D = \tfrac{1}{2}.$$

(These are $A = \tfrac14 P'(w_0)$, $B = \tfrac{1}{12}P''(w_0)$, $C = \tfrac{1}{2
4}P'''(w_0)$, $D = a_0$.)

**Step 3: Weierstrass substitution.**

Remove the quadratic term in (2) by setting $u = \frac{\xi - B/2}{A}$ (equivalen
tly $\xi = Au + B/2$). Then (2) becomes the **Weierstrass equation**

$$\left(\frac{d\xi}{dz}\right)^2 = 4\xi^3 - g_2\,\xi - g_3, \tag{3}$$

whose general solution is $\xi(z) = \wp(z - z_0;\, g_2,\, g_3)$, the Weierstrass
 $\wp$-function with invariants

$$g_2 = 3B^2 - 4AC, \qquad g_3 = -B^3 + 2ABC - A^2 D.$$

**Step 4: Compute the invariants explicitly.**

A direct (and root-independent) calculation using the binary quartic invariants
$I = a_0 a_4 - 4a_1 a_3 + 3a_2^2$ and $J = a_0 a_2 a_4 - a_0 a_3^2 - a_1^2 a_4 +
 2a_1 a_2 a_3 - a_2^3$ gives $g_2 = I$ and $g_3 = J$. Substituting our coefficie
nts:

$$\boxed{g_2 = \frac{C_1}{2} + \frac{f^2}{12}, \qquad g_3 = \frac{C_1(3f - e^2)}
{36} - \frac{f^3}{216}.} \tag{4}$$

(One can verify that these do not depend on the choice of root $w_0$, as expecte
d for invariants of the quartic.)

**Step 5: Assemble the general solution.**

Tracing back through the substitutions $\xi = Au + B/2$ and $w = w_0 + 1/u$:

$$u = \frac{\xi - B/2}{A} = \frac{\wp(z-z_0;\,g_2,g_3) - B/2}{A}, \qquad w = w_0
 + \frac{A}{\wp(z-z_0;\,g_2,g_3) - B/2}.$$

Therefore the **general solution** is:

$$\boxed{\;w(z) = w_0 + \frac{A}{\wp\!\left(z - z_0;\; g_2,\; g_3\right) - \tfra
c{1}{2}B}\;} \tag{5}$$

where:
- $w_0$ is any simple root of $P(w) = \tfrac12 w^4 + \tfrac{2e}{3}w^3 + fw^2 + C
_1$,
- $A = \tfrac12\,w_0(w_0^2 + ew_0 + f)$, $\;B = \tfrac{1}{6}(3w_0^2 + 2ew_0 + f)
$,
- $g_2 = \tfrac{C_1}{2} + \tfrac{f^2}{12}$, $\;g_3 = \tfrac{C_1(3f-e^2)}{36} - \
tfrac{f^3}{216}$,
- $z_0$ and $C_1$ are the **two arbitrary constants** of integration.

**Verification.** Setting $\xi = \wp(z-z_0)$ so that $(\wp')^2 = 4\wp^3 - g_2\wp
 - g_3$, and $w = w_0 + A/(\wp - B/2)$, one computes $\left(\frac{dw}{dz}\right)
^2 = \frac{A^2(4\wp^3 - g_2\wp - g_3)}{(\wp - B/2)^4}$. Expanding $P(w_0 + A/u)$
 via Taylor series around $w_0$ (using $P(w_0)=0$, $P'(w_0)=4A$, $P''(w_0)=12B$,
 $P'''(w_0)=24C$, $P''''(w_0)=24D$) and substituting $\wp = u + B/2$ confirms te
rm-by-term that $\left(\frac{dw}{dz}\right)^2 = P(w)$, provided $g_2 = 3B^2 - 4A
C$ and $g_3 = -B^3 + 2ABC - A^2D$, which are exactly (4). $\quad\blacksquare$

**Equivalent integral form.** The solution can also be written implicitly as

$$z - z_0 = \int^{w} \frac{dt}{\sqrt{\tfrac12 t^4 + \tfrac{2e}{3}t^3 + f\,t^2 +
C_1}},$$

which is an **elliptic integral of the first kind**; its inversion is precisely
the Weierstrass $\wp$-function expression (5).
