## Setting Up the Key Recurrence

**Roots and conjugate.** The equation $t^2 - 1998t - 1 = 0$ has roots $\lambda =
 \frac{1998 + \sqrt{1998^2+4}}{2}$ and $\mu = \frac{1998 - \sqrt{1998^2+4}}{2}$.
 Key properties:
- $\lambda + \mu = 1998$, $\lambda\mu = -1$, so $\mu = -1/\lambda$ and $|\mu| <
1$.
- $\lambda - 1998 = -\mu = 1/\lambda$, i.e., $\lambda = 1998 + 1/\lambda$.

**Claim:** For all $n \geq 1$, the sequence satisfies the linear recurrence:
$$x_{n+1} = 1998\, x_n + x_{n-1} - 1.$$

**Proof of claim.** Since $x_{n+1} = \lfloor \lambda x_n \rfloor$, the recurrenc
e holds iff:
$$1998\, x_n + x_{n-1} - 1 \;\leq\; \lambda x_n \;<\; 1998\, x_n + x_{n-1}.$$

*Right inequality:* $\lambda x_n < 1998\,x_n + x_{n-1}$ iff $\frac{x_n}{\lambda}
 < x_{n-1}$ (using $\lambda - 1998 = 1/\lambda$). Since $\lambda$ is irrational
and $x_{n-1} \geq 1$, the product $\lambda x_{n-1}$ is never an integer, so $x_n
 = \lfloor \lambda x_{n-1}\rfloor < \lambda x_{n-1}$, giving $x_n/\lambda < x_{n
-1}$. ✓

*Left inequality:* $x_{n-1} - 1 \leq x_n/\lambda$ iff $x_n \geq \lambda x_{n-1}
- \lambda$. Since $x_n = \lfloor \lambda x_{n-1}\rfloor \geq \lambda x_{n-1} - 1
$ and $\lambda > 1$ gives $\lambda x_{n-1} - 1 > \lambda x_{n-1} - \lambda$, we
get $x_n > \lambda x_{n-1} - \lambda$. ✓

**Verification with initial terms:**
- $x_0 = 1$, $x_1 = \lfloor\lambda\rfloor = 1998$.
- $x_2 = 1998\cdot1998 + 1 - 1 = 1998^2$. ✓ (Check: $\lfloor 1998\lambda\rfloor
= \lfloor 1998^2 + 1998/\lambda\rfloor = 1998^2$ since $0 < 1998/\lambda < 1$.)
- $x_3 = 1998\cdot 1998^2 + 1998 - 1 = 1998^3 + 1997$. ✓

## Reducing Modulo 1998

From $x_{n+1} = 1998\,x_n + x_{n-1} - 1$, reducing mod 1998:
$$r_{n+1} \equiv r_{n-1} - 1 \pmod{1998}, \quad n \geq 1$$
where $r_n = x_n \bmod 1998$, with $r_0 = 1$, $r_1 = 0$.

This decouples into even and odd subsequences:

**Even indices** ($r_2 = r_0 - 1$, $r_4 = r_2 - 1$, …):
$$r_{2k} = r_0 - k = 1 - k \pmod{1998}$$

**Odd indices** ($r_3 = r_1 - 1$, $r_5 = r_3 - 1$, …):
$$r_{2k+1} = r_1 - k = -k \pmod{1998}$$

**Verification:**
| $n$ | $r_n$ (formula) | $r_n$ (direct) |
|-----|-----------------|----------------|
| 0 | $1$ | $1$ ✓ |
| 1 | $0$ | $0$ ✓ |
| 2 | $0$ | $0$ ✓ |
| 3 | $-1 \equiv 1997$ | $1997$ ✓ |
| 4 | $-1 \equiv 1997$ | $1997$ ✓ |
| 5 | $-2 \equiv 1996$ | $1996$ ✓ |

## Computing $x_{1998} \bmod 1998$

Since $1998 = 2 \times 999$, we use the even-index formula with $k = 999$:
$$r_{1998} = 1 - 999 = -998 \equiv 1998 - 998 = 1000 \pmod{1998}.$$

## Answer

The remainder when $x_{1998}$ is divided by $1998$ is $\boxed{1000}$.
