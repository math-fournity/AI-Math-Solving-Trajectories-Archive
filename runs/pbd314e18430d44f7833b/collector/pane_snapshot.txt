## Proof

Let $I=[0,1]$ and $I_{\mathbb{Q}}=\mathbb{Q}\cap I$. The space is
$$X = \Bigl(\bigcup_{q\in I_{\mathbb{Q}}}\{q\}\times I\Bigr)\cup\bigl(I\times\{0
\}\bigr).$$

We claim **$X$ is locally path connected exactly at the points of $I\times\{0\}$
**, i.e., at every $(x,0)$ with $x\in[0,1]$, and at no other point.

---

### Part 1: $X$ is locally path connected at every point of $I\times\{0\}$.

Let $p=(x_0,0)\in I\times\{0\}$ (x_0 can be rational or irrational). Let $U$ be
any open neighborhood of $p$ in $X$. Since $U$ is open in the subspace topology,
 there exists $\varepsilon>0$ with $X\cap B(p,\varepsilon)\subseteq U$. We show
$V:=X\cap B(p,\varepsilon)$ is path connected; since it is open in $X$ and conta
ins $p$, this establishes local path connectivity at $p$.

**$V$ is path connected.** Take any two points $a,b\in V$.

- If $a=(q_a, y_a)$ with $q_a\in I_{\mathbb{Q}}$, $y_a>0$: the vertical segment
$\{q_a\}\times[0,y_a]$ lies in $X$. For every $t\in[0,y_a]$, the distance from $
(q_a,t)$ to $p=(x_0,0)$ is $\sqrt{(q_a-x_0)^2+t^2}\le\sqrt{(q_a-x_0)^2+y_a^2}<\v
arepsilon$ (since $a\in B(p,\varepsilon)$). So the entire downward path to $(q_a
,0)$ stays in $V$. If $y_a=0$, $a$ is already on the base.
- Similarly, $b$ can be connected down to $(q_b,0)$ (or is already on the base),
 staying in $V$.
- The base portion $V\cap(I\times\{0\}) = [0,1]\cap[x_0-\varepsilon,x_0+\varepsi
lon]\times\{0\}$ is a closed interval, hence path connected. Both $(q_a,0)$ and
$(q_b,0)$ lie in this interval (their $x$-coordinates satisfy $|q_a-x_0|<\vareps
ilon$, $|q_b-x_0|<\varepsilon$), and any intermediate point $(s,0)$ on the base
path satisfies $|s-x_0|<\varepsilon$.

Concatenating: $a\to(q_a,0)\to(q_b,0)\to b$ is a path in $V$ from $a$ to $b$. He
nce $V$ is path connected. $\checkmark$

---

### Part 2: $X$ is NOT locally path connected at any point $(q,y)$ with $q\in I_
{\mathbb{Q}}$, $y\in(0,1]$.

Let $p=(q,y)$ with $y>0$. Choose $\varepsilon$ with $0<\varepsilon<y$ and set $U
:=X\cap B(p,\varepsilon)$, an open neighborhood of $p$ in $X$.

**Key observation:** Since $\varepsilon<y$, the ball $B(p,\varepsilon)$ does not
 intersect $I\times\{0\}$ (every point $(x,0)$ has distance $\sqrt{(x-q)^2+y^2}\
ge y>\varepsilon$ from $p$). Therefore
$$U = \bigcup_{\substack{q'\in I_{\mathbb{Q}}\\|q'-q|<\varepsilon}} \{q'\}\times
\bigl(I\cap(y-\varepsilon,\,y+\varepsilon)\bigr),$$
a disjoint union of vertical line segments (one per rational $q'$ near $q$), wit
h **no horizontal connections** between them.

This union is not path connected: distinct fibers $\{q_1'\}\times\cdots$ and $\{
q_2'\}\times\cdots$ are separated (any path between them would have to leave the
 vertical fibers, but the only horizontal part of $X$ is the base, which is abse
nt from $U$).

Now suppose for contradiction that there exists a path-connected open set $V$ in
 $X$ with $p\in V\subseteq U$. Since $V$ is open in $X$ and contains $p$, there
exists $\delta>0$ with $X\cap B(p,\delta)\subseteq V$. Choose $\delta<\varepsilo
n$. Since rationals are dense, there exists $q'\in I_{\mathbb{Q}}$ with $0<|q'-q
|<\delta$. Then $(q',y)\in X\cap B(p,\delta)\subseteq V$ (note $|q'-q|<\delta$ a
nd $y$ is the same, so distance is $|q'-q|<\delta$). But $(q',y)$ lies on a diff
erent fiber from $p=(q,y)$, and within $V\subseteq U$ (which has no base), there
 is no path from $(q,y)$ to $(q',y)$. This contradicts $V$ being path connected.

Hence $X$ is not locally path connected at $(q,y)$ for $y>0$. $\checkmark$

---

### Conclusion

$X$ is locally path connected at a point $p\in X$ if and only if $p\in I\times\{
0\}$, i.e., if and only if $p=(x,0)$ for some $x\in[0,1]$.
