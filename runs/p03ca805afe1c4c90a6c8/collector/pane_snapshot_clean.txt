## Solution

**Answer:** The unique function satisfying the equation is $g(x) = x$.

**Remark on the problem statement:** The equation $g(2x - g(x)) = x$ involves on
ly $g$; the bijective function $f$ plays no role in the equation as written. I s
olve the equation as stated.

---

### Proof

We seek all $g:[0,1]\to[0,1]$ such that
$$g(2x - g(x)) = x \quad \text{for all } x \in [0,1]. \tag{1}$$

Since the left side must be defined, $2x - g(x) \in [0,1]$ for every $x \in [0,1
]$.

**Step 1: Reformulation.** Write $g(x) = x + \varphi(x)$, where $\varphi(x) = g(
x) - x$. Substituting into (1):
$$g\bigl(2x - x - \varphi(x)\bigr) = g\bigl(x - \varphi(x)\bigr) = \bigl(x - \va
rphi(x)\bigr) + \varphi\bigl(x - \varphi(x)\bigr) = x,$$
so
$$\varphi\bigl(x - \varphi(x)\bigr) = \varphi(x) \quad \text{for all } x \in [0,
1]. \tag{2}$$

**Step 2: Define the iteration.** Let $T(x) = x - \varphi(x) = 2x - g(x)$. By th
e domain requirement noted above, $T(x) \in [0,1]$ whenever $x \in [0,1]$. Equat
ion (2) says $\varphi(T(x)) = \varphi(x)$, i.e., $\varphi$ is invariant under $T
$.

**Step 3: Closed form of the iterates.** I claim $T^n(x) = x - n\,\varphi(x)$ fo
r all $n \geq 0$. The case $n=0$ is trivial, and $n=1$ is the definition. Assumi
ng it holds for $n$:
$$T^{n+1}(x) = T(T^n(x)) = T^n(x) - \varphi(T^n(x)).$$
By the invariance (2) applied inductively, $\varphi(T^n(x)) = \varphi(x)$. Hence
$$T^{n+1}(x) = \bigl(x - n\,\varphi(x)\bigr) - \varphi(x) = x - (n+1)\,\varphi(x
).$$
This establishes the claim by induction.

**Step 4: Domain forces $\varphi \equiv 0$.** Since each $T^n(x)$ is obtained by
 applying $T$ to a point already in $[0,1]$, we have $T^n(x) \in [0,1]$ for ever
y $n \geq 0$. Thus
$$0 \leq x - n\,\varphi(x) \leq 1 \quad \text{for all } n \geq 0. \tag{3}$$

- If $\varphi(x) > 0$, then $x - n\,\varphi(x) \to -\infty$, violating the lower
 bound in (3) for large $n$.
- If $\varphi(x) < 0$, then $x - n\,\varphi(x) \to +\infty$, violating the upper
 bound in (3) for large $n$.

Therefore $\varphi(x) = 0$ for every $x \in [0,1]$, giving $g(x) = x$.

**Step 5: Verification.** With $g(x) = x$:
$$g(2x - g(x)) = g(2x - x) = g(x) = x,$$
and $g$ maps $[0,1]$ to $[0,1]$, with $2x - g(x) = x \in [0,1]$. All conditions
are satisfied.

---

### Conclusion

The only function $g:[0,1]\to[0,1]$ satisfying $g(2x - g(x)) = x$ is $\boxed{g(x
) = x}$.
