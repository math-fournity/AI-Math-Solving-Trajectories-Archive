## Proof

We wish to minimize
$$J(y) = \int_a^b \sqrt{1 + y'(x)^2}\, dx$$
over all $y \in C^2([a,b])$.

**Lower bound.** For every real number $t$, we have $t^2 \geq 0$, hence $1 + t^2
 \geq 1$, and since the square root is monotone,
$$\sqrt{1 + t^2} \geq 1.$$
Applying this with $t = y'(x)$ for each $x \in [a,b]$,
$$\sqrt{1 + y'(x)^2} \geq 1 \quad \text{for all } x \in [a,b].$$
Integrating over $[a,b]$,
$$J(y) = \int_a^b \sqrt{1 + y'(x)^2}\, dx \geq \int_a^b 1\, dx = b - a.$$
Thus $J(y) \geq b - a$ for every admissible $y$.

**Attainment.** Equality in $\sqrt{1+t^2} \geq 1$ holds if and only if $t^2 = 0$
, i.e., $t = 0$. Therefore equality $J(y) = b-a$ holds if and only if $y'(x) = 0
$ for all $x \in [a,b]$, i.e., $y$ is constant on $[a,b]$.

Any constant function $y(x) \equiv c$ belongs to $C^2([a,b])$ (indeed $y' \equiv
 0$ and $y'' \equiv 0$, both continuous), and for such a function
$$J(y) = \int_a^b \sqrt{1 + 0}\, dx = \int_a^b 1\, dx = b - a.$$

**Conclusion.** The lower bound $b - a$ is achieved by every constant function,
and no admissible function yields a smaller value. Hence the minimum value of th
e functional is

$$\boxed{b - a}.$$
