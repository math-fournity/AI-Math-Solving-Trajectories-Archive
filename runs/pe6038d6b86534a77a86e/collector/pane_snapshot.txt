## Solution

We determine the values of $x$ for which the series $\displaystyle\sum_{n=1}^{\i
nfty} n^{n^{1/3}}\, x^{2n}$ converges, using the **root test**.

Let $a_n = n^{n^{1/3}}\, x^{2n}$ be the general term.

### Step 1. Compute $\lim_{n\to\infty} |a_n|^{1/n}$

$$|a_n|^{1/n} = \left(n^{n^{1/3}}\right)^{1/n}\cdot |x|^{2n/n} = n^{\,n^{1/3}/n}
\cdot |x|^{2}.$$

The exponent of $n$ is

$$\frac{n^{1/3}}{n} = n^{1/3 - 1} = n^{-2/3} = \frac{1}{n^{2/3}}.$$

Hence

$$n^{\,1/n^{2/3}} = \exp\!\left(\frac{\ln n}{n^{2/3}}\right).$$

Since $\dfrac{\ln n}{n^{2/3}} \to 0$ as $n\to\infty$ (logarithm grows slower tha
n any positive power of $n$), we obtain

$$n^{\,1/n^{2/3}} \to e^{0} = 1.$$

Therefore

$$\lim_{n\to\infty} |a_n|^{1/n} = 1 \cdot |x|^{2} = |x|^{2}.$$

### Step 2. Apply the root test

- If $|x|^{2} < 1$, i.e. $|x| < 1$: the root test gives convergence (absolutely)
.
- If $|x|^{2} > 1$, i.e. $|x| > 1$: the root test gives divergence.
- If $|x|^{2} = 1$, i.e. $|x| = 1$ ($x = \pm 1$): the root test is inconclusive,
 so we check directly.

### Step 3. Boundary case $|x| = 1$

When $x = \pm 1$, $x^{2n} = 1$, so

$$a_n = n^{n^{1/3}} \to \infty \quad (n\to\infty).$$

In particular $a_n \not\to 0$, so the series **diverges** by the divergence test
.

### Conclusion

The series $\displaystyle\sum_{n=1}^{\infty} n^{n^{1/3}}\, x^{2n}$ converges if
and only if

$$\boxed{|x| < 1}, \quad \text{i.e. } x \in (-1,\, 1).$$
