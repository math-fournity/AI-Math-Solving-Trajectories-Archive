## Proof

**Reformulation.** We have a complete graph $K_n$ on $n$ vertices with edges col
ored using exactly $M$ colors, such that every triangle is either monochromatic
(1 color) or rainbow (3 colors), never using exactly 2 colors.

**Key Structural Observation.** For each color $c$, define a relation: $u \sim_c
 v$ iff edge $uv$ has color $c$. We claim this is an equivalence relation on the
 set of vertices. Reflexivity and symmetry are immediate. For transitivity: if $
uv$ and $uw$ both have color $c$, then in triangle $uvw$, two edges share color
$c$, so by the condition, the third edge $vw$ must also have color $c$. Hence $\
sim_c$ is an equivalence relation.

Therefore, each color $c$ partitions the vertex set $V$ into parts (cliques), an
d within each part, all edges have color $c$. Since each edge has exactly one co
lor, every pair of vertices lies in the same part of **exactly one** partition.
We thus have $M$ partitions $P_1, \dots, P_M$ of $[n]$ such that every pair is i
n the same part of exactly one partition.

**Notation.** For vertex $v$ and color $i$, let $s_i(v)$ be the size of the part
 containing $v$ in $P_i$, and let $d_i(v) = s_i(v) - 1$. Let $N_i(v) = \{u \neq
v : u \text{ is in the same part as } v \text{ in } P_i\}$, so $|N_i(v)| = d_i(v
)$.

Since every other vertex shares exactly one partition with $v$:
$$\sum_{i=1}^{M} d_i(v) = n - 1 \quad \text{for all } v.$$

**Key Lemma.** *For any vertex $v$ and any two distinct colors $i, j$ with $N_i(
v), N_j(v) \neq \emptyset$, we have $|N_j(v)| \leq M - 2$ (and symmetrically $|N
_i(v)| \leq M - 2$).*

*Proof.* Take any $u \in N_i(v)$. For each $w \in N_j(v)$, the edge $uw$ has som
e color $k$:
- $k \neq i$: if $k = i$, then $w \in N_i(v)$, but $w \in N_j(v)$ and $i \neq j$
, so $w$ would be in the same part as $v$ in two partitions — contradiction.
- $k \neq j$: if $k = j$, then $u \in N_j(v)$, but $u \in N_i(v)$ and $i \neq j$
 — same contradiction.

So $k \in \{1,\dots,M\} \setminus \{i,j\}$, giving $M-2$ possible colors. Now su
ppose two vertices $w, w' \in N_j(v)$ have edges $uw$ and $uw'$ both of color $k
$. Then $u, w$ are in the same part of $P_k$ and $u, w'$ are in the same part of
 $P_k$, so $w, w'$ are in the same part of $P_k$. But $w, w'$ are also in the sa
me part of $P_j$ (both in $N_j(v)$). Since $k \neq j$, the pair $\{w,w'\}$ is co
vered by two partitions — contradiction. Hence all edges from $u$ to $N_j(v)$ ha
ve **distinct** colors, so $|N_j(v)| \leq M-2$. $\square$

**Upper Bound: $N(M) \leq (M-1)^2$.**

Since exactly $M$ colors are used, at least two colors must appear on edges inci
dent to each vertex $v$ (if only one color $c$ appeared at $v$, then $v$ is in a
 single part of $P_c$ containing all vertices, making all edges color $c$ — only
 1 color used, contradicting $M \geq 2$). So at least two of the groups $N_1(v),
 \dots, N_M(v)$ are non-empty.

Let $k \geq 2$ be the number of non-empty groups at $v$. By the Key Lemma, each
non-empty group has size $\leq M-2$. Therefore:
$$n - 1 = \sum_{i=1}^{M} d_i(v) \leq k(M-2) \leq M(M-2) = M^2 - 2M.$$
Thus $n \leq M^2 - 2M + 1 = (M-1)^2$.

**Lower Bound: $N(M) \geq (M-1)^2$ when $M-1$ is a prime power.**

*Construction.* Let $q = M - 1$ be a prime power. Consider the affine plane $\te
xt{AG}(2, q)$ over $\mathbb{F}_q$, which has $q^2$ points. Lines come in $q + 1
= M$ parallel classes (directions): the $q$ slopes $0, 1, \dots, q-1$ plus the v
ertical direction $\infty$. Each parallel class consists of $q$ parallel lines,
each containing $q$ points.

Color the edge between two points by the direction (parallel class) of the uniqu
e line through them. This uses exactly $M = q + 1$ colors.

*Verification.* For any three distinct points $A, B, C$:
- **Collinear**: all three lie on one line, so all three edges have the same dir
ection → monochromatic.
- **Non-collinear**: if edges $AB$ and $AC$ had the same direction, then $B$ and
 $C$ would both lie on the line through $A$ in that direction, making $A, B, C$
collinear — contradiction. So all three directions are distinct → rainbow.

No triangle uses exactly 2 colors. All $M$ colors are used (each parallel class
has $q \geq 2$ lines with $q \geq 2$ points each). ✓

**Conclusion for $N(12)$.** Here $M = 12$, so $M - 1 = 11$, which is prime. The
upper bound gives $N(12) \leq 11^2 = 121$, and the affine plane construction ove
r $\mathbb{F}_{11}$ gives $N(12) \geq 121$.

$$\boxed{N(12) = 121}$$
