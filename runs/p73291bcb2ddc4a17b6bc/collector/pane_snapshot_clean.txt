## Proof

**Setup.** Let the radius be $r$, with $O$ at the origin and diameter $AC$ along
 the $x$-axis: $A=(-r,0)$, $C=(r,0)$, the semicircle in the upper half-plane.

Since arc $AB:BC = 1:3$, point $B$ subtends angle $\angle AOB = \pi/4$ from $A$,
 so $B$ is at angle $3\pi/4$:
$$B = \left(-\tfrac{r}{\sqrt2},\;\tfrac{r}{\sqrt2}\right).$$

$M$ is the midpoint of $OC$: $\;M = (r/2,\; 0)$.

A point $T$ on arc $BC$ has $T = (r\cos\theta,\; r\sin\theta)$ for $\theta \in [
0,\, 3\pi/4]$.

**Area via shoelace.** For quadrilateral $OBTM$ (vertices in order):
$$\text{Area} = \frac{r^2}{2}\left[\frac{\sin\theta+\cos\theta}{\sqrt2} + \frac{
\sin\theta}{2}\right] =: \frac{r^2}{2}\,f(\theta).$$

(The quadrilateral is simple for all $\theta\in[0,3\pi/4]$: edges $OB$, $BT$ (a
chord staying in $y\ge 0$), $TM$, $MO$ have no non-adjacent crossings.)

**Maximize.** Set $f'(\theta)=0$:
$$f'(\theta) = \frac{\cos\theta - \sin\theta}{\sqrt2} + \frac{\cos\theta}{2} = 0
$$
$$\Longrightarrow\quad \cos\theta\!\left(\frac{1}{\sqrt2}+\frac{1}{2}\right) = \
frac{\sin\theta}{\sqrt2} \quad\Longrightarrow\quad \tan\theta = 1 + \frac{1}{\sq
rt2}.$$

This gives $\theta \approx 59.6° \in [0,3\pi/4]$. Since $f'(0)>0$ and $f'(3\pi/4
)<0$, this critical point is the global maximum.

**Evaluate at the maximum.** Let $t = \tan\theta = 1+\tfrac{1}{\sqrt2}$. Then
$$1+t^2 = \frac{5+2\sqrt2}{2},\qquad \sin\theta = \frac{t}{\sqrt{1+t^2}},\quad \
cos\theta = \frac{1}{\sqrt{1+t^2}}.$$

$$f = \frac{t+1}{\sqrt2\sqrt{1+t^2}} + \frac{t}{2\sqrt{1+t^2}} = \frac{1}{\sqrt{
1+t^2}}\left(\frac{t+1}{\sqrt2}+\frac{t}{2}\right).$$

With $t = 1+\tfrac{\sqrt2}{2}$:
$$\frac{t+1}{\sqrt2}+\frac{t}{2} = \frac{2+\frac{\sqrt2}{2}}{\sqrt2}+\frac{1+\fr
ac{\sqrt2}{2}}{2} = \frac{2\sqrt2+1}{2}+\frac{2+\sqrt2}{4} = \frac{4\sqrt2+2+2+\
sqrt2}{4}=\frac{5\sqrt2+4}{4}.$$

So
$$f = \frac{5\sqrt2+4}{4\sqrt{(5+2\sqrt2)/2}} = \frac{(5\sqrt2+4)\sqrt2}{4\sqrt{
5+2\sqrt2}} = \frac{10+4\sqrt2}{4\sqrt{5+2\sqrt2}} = \frac{5+2\sqrt2}{2\sqrt{5+2
\sqrt2}} = \frac{\sqrt{5+2\sqrt2}}{2}.$$

Therefore
$$\text{Area}_{\max} = \frac{r^2}{2}\cdot\frac{\sqrt{5+2\sqrt2}}{2} = \boxed{\df
rac{r^2\,\sqrt{5+2\sqrt2}}{4}}.$$
