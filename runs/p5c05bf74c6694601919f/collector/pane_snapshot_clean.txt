## Proof

**Claim.** For every $s \in \bigl(\tfrac{1}{2}, \tfrac{3}{2}\bigr)$, there exist
s a constant $c = c_s > 0$ such that for all $u \in H^s(\mathbb{T})$ and all $x,
 y \in \mathbb{T}$,
$$|u(x) - u(y)| \leq c\, \|u\|_{H^s}\, |x - y|^{s - 1/2}.$$

---

### Setup

Identify $\mathbb{T} = \mathbb{R}/2\pi\mathbb{Z}$. Every $u \in H^s(\mathbb{T})$
 has a Fourier series $u(x) = \sum_{k \in \mathbb{Z}} \hat{u}(k)\, e^{ikx}$ with
$$\|u\|_{H^s}^2 \asymp \sum_{k \in \mathbb{Z}} (1+k^2)^s\, |\hat{u}(k)|^2 < \inf
ty.$$

Since $s > \tfrac{1}{2}$, the standard Sobolev embedding gives $H^s(\mathbb{T})
\hookrightarrow L^\infty(\mathbb{T}) \cap C^0(\mathbb{T})$, so pointwise evaluat
ion is meaningful.

Set $h = |x - y|$ (torus distance, so $0 \le h \le \pi$). The case $h \ge h_0 >
0$ is immediate: $|u(x)-u(y)| \le 2\|u\|_{L^\infty} \le C_s \|u\|_{H^s} \le C_s
h_0^{-(s-1/2)} \|u\|_{H^s}\, h^{s-1/2}$. Hence it suffices to handle $h \to 0$.

### Cauchy–Schwarz reduction

Since $\hat{u}(0)$ cancels in $u(x)-u(y)$:
$$u(x) - u(y) = \sum_{k \neq 0} \hat{u}(k)\bigl(e^{ikx} - e^{iky}\bigr).$$

Applying Cauchy–Schwarz with weights $(1+k^2)^s$:
$$|u(x) - u(y)|^2 \;\le\; \underbrace{\Bigl(\sum_{k \neq 0} |\hat{u}(k)|^2 (1+k^
2)^s\Bigr)}_{\le\, \|u\|_{H^s}^2}\;\cdot\; \underbrace{\Bigl(\sum_{k \neq 0} \fr
ac{|e^{ikx} - e^{iky}|^2}{(1+k^2)^s}\Bigr)}_{=:\, S(h)}.$$

It remains to show $S(h) \le C_s\, h^{2s-1}$.

### Bounding $S(h)$

Using $|e^{ikx} - e^{iky}|^2 = 4\sin^2(kh/2) \le C\min(1,\, k^2 h^2)$, we get
$$S(h) \;\le\; C \sum_{k \neq 0} \frac{\min(1,\, k^2 h^2)}{(1+k^2)^s} \;\le\; C
\sum_{k=1}^{\infty} \frac{\min(1,\, k^2 h^2)}{k^{2s}}.$$

Set $N = \lfloor 1/h \rfloor$ (for $h$ small, $N \ge 1$) and split the sum.

**Low frequencies** $\boldsymbol{1 \le k \le N}$: here $kh \le 1$, so $\min(1, k
^2 h^2) \le k^2 h^2$.
$$S_1 \;\le\; C\, h^2 \sum_{k=1}^{N} k^{2-2s}.$$
Since $s < \tfrac{3}{2}$, the exponent $2 - 2s > -1$, so the sum grows as a powe
r:
$$\sum_{k=1}^{N} k^{2-2s} \;\le\; C\, N^{3-2s} \;\le\; C\, h^{-(3-2s)}.$$
Therefore $S_1 \le C\, h^2 \cdot h^{-(3-2s)} = C\, h^{2s-1}$.

**High frequencies** $\boldsymbol{k > N}$: here $kh > 1$, so $\min(1, k^2 h^2) \
le 1$.
$$S_2 \;\le\; C \sum_{k=N+1}^{\infty} k^{-2s}.$$
Since $s > \tfrac{1}{2}$, the exponent $2s > 1$, so the tail decays as a power:
$$\sum_{k=N+1}^{\infty} k^{-2s} \;\le\; C\, N^{1-2s} \;\le\; C\, h^{2s-1}.$$
Therefore $S_2 \le C\, h^{2s-1}$.

### Conclusion

Combining both parts:
$$S(h) = S_1 + S_2 \;\le\; C_s\, h^{2s-1}.$$

Substituting back:
$$|u(x) - u(y)|^2 \;\le\; C_s\, \|u\|_{H^s}^2\, h^{2s-1},$$

and taking square roots:
$$\boxed{|u(x) - u(y)| \;\le\; c_s\, \|u\|_{H^s}\, |x - y|^{s - 1/2}}, \qquad c_
s = \sqrt{C_s}.$$

### Sharpness of the open interval

The restriction to the **open** interval $s \in \bigl(\tfrac{1}{2}, \tfrac{3}{2}
\bigr)$ is necessary:

- **At $s = \tfrac{1}{2}$:** the exponent $s - \tfrac{1}{2} = 0$ would require $
H^{1/2} \hookrightarrow L^\infty$, which fails (e.g., $u(x) = \sum_{k=2}^{\infty
} \frac{e^{ikx}}{\sqrt{k \log k}} \in H^{1/2}$ but $u \notin L^\infty$).

- **At $s = \tfrac{3}{2}$:** the exponent $s - \tfrac{1}{2} = 1$ would require $
H^{3/2} \hookrightarrow \mathrm{Lip}$ (Lipschitz). The low-frequency sum above b
ecomes $\sum_{k=1}^{N} k^{-1} \sim \log N$, giving $S_1 \sim h^2 \log(1/h)$, whi
ch exceeds $h^2 = h^{2s-1}$ by a logarithmic factor. This is not merely a failur
e of the method: $H^{3/2} \hookrightarrow C^{0,\alpha}$ holds for every $\alpha
< 1$ but **not** for $\alpha = 1$, so the Lipschitz embedding genuinely fails.

Thus the constant $c_s$ exists precisely for $s \in \bigl(\tfrac{1}{2}, \tfrac{3
}{2}\bigr)$, and the $s = 1$ case recovers Morrey's inequality as a special case
. $\blacksquare$
