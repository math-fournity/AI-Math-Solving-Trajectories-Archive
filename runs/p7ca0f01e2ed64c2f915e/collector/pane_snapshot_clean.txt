## Solution

We evaluate
$$I = \int_0^\infty \int_0^t e^{-t}\frac{\sin \tau}{\tau}\,d\tau\,dt.$$

**Step 1. Swap the order of integration.**

The region of integration is $\{(\tau,t): 0 \le \tau \le t,\; 0 \le t < \infty\}
$, which is equivalently $\{(\tau,t): 0 \le \tau < \infty,\; \tau \le t < \infty
\}$. Since $e^{-t}\frac{\sin\tau}{\tau}$ is integrable over this region (the inn
er integral converges absolutely after swapping, as we'll see), Fubini's theorem
 gives

$$I = \int_0^\infty \frac{\sin \tau}{\tau}\left(\int_\tau^\infty e^{-t}\,dt\righ
t)d\tau = \int_0^\infty \frac{\sin \tau}{\tau}\,e^{-\tau}\,d\tau.$$

**Step 2. Recognize this as a Laplace transform.**

Setting $s = 1$,
$$I = \int_0^\infty e^{-s\tau}\frac{\sin \tau}{\tau}\,d\tau\Big|_{s=1} = \mathca
l{L}\!\left\{\frac{\sin \tau}{\tau}\right\}(1).$$

**Step 3. Apply the "division by $t$" property of the Laplace transform.**

Recall that if $F(s) = \mathcal{L}\{f(t)\}(s)$, then
$$\mathcal{L}\!\left\{\frac{f(t)}{t}\right\}(s) = \int_s^\infty F(u)\,du,$$
provided the integral converges.

Here $f(\tau) = \sin\tau$, so $F(s) = \dfrac{1}{s^2+1}$. Therefore
$$\mathcal{L}\!\left\{\frac{\sin \tau}{\tau}\right\}(s) = \int_s^\infty \frac{du
}{u^2+1} = \left[\arctan u\right]_s^\infty = \frac{\pi}{2} - \arctan s.$$

**Step 4. Evaluate at $s = 1$.**

$$I = \frac{\pi}{2} - \arctan(1) = \frac{\pi}{2} - \frac{\pi}{4} = \frac{\pi}{4}
.$$

**Result:**

$$\boxed{\displaystyle \int_0^\infty \int_0^t e^{-t}\frac{\sin \tau}{\tau}\,d\ta
u\,dt = \frac{\pi}{4}}.$$
