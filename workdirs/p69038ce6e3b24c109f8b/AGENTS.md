# Problem

In the city of Gridhaven, a security firm is designing a surveillance system for an $8 \times 8$ grid of city blocks. To ensure public safety, the firm must install a specific number of specialized sensors on the street corners (the squares of the grid).

The security protocol requires a very precise density: within any possible $3 \times 3$ sub-grid of blocks, there must be exactly 3 sensors installed. The firm wants to minimize the total equipment costs by using the fewest number of sensors possible across the entire $8 \times 8$ city.

What is the smallest total number of sensors, $n$, that must be placed on the $8 \times 8$ grid to satisfy the requirement that every $3 \times 3$ area contains exactly 3 sensors?
