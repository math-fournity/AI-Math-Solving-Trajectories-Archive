## Proof

Let $s = b+c$ and $p = bc$. Then $a = 3 - s$ and

$$y = ab + ac + bc = a(b+c) + bc = (3-s)s + p,$$

so $p = s^2 - 3s + y$.

**Constraints** (from $a, b, c > 0$): $0 < s < 3$, $p > 0$, and $b, c$ real requ
ires $p \le s^2/4$ (discriminant $s^2 - 4p \ge 0$).

We minimize $p(s) = s^2 - 3s + y$ over $s \in (0,3)$ subject to $0 < p \le s^2/4
$. The parabola has vertex at $s = \tfrac{3}{2}$ with value $p\!\left(\tfrac{3}{
2}\right) = y - \tfrac{9}{4}$.

---

**Case 1: $\tfrac{9}{4} < y \le \tfrac{45}{16}$.**

At $s = \tfrac{3}{2}$: $p = y - \tfrac{9}{4} > 0$ and $p = y - \tfrac{9}{4} \le
\tfrac{45}{16} - \tfrac{36}{16} = \tfrac{9}{16} = \tfrac{s^2}{4}$. All constrain
ts hold, and since $s = \tfrac{3}{2}$ is the global minimum of the parabola,

$$\min bc = y - \tfrac{9}{4}.$$

**Case 2: $\tfrac{45}{16} < y \le 3$.**

At $s = \tfrac{3}{2}$, $p = y - \tfrac{9}{4} > \tfrac{9}{16} = \tfrac{s^2}{4}$,
violating $p \le \tfrac{s^2}{4}$. So the constraint $p \le \tfrac{s^2}{4}$ is bi
nding. Setting $p = \tfrac{s^2}{4}$ (i.e., $b = c$):

$$\tfrac{s^2}{4} = s^2 - 3s + y \;\Longrightarrow\; 3s^2 - 12s + 4y = 0 \;\Longr
ightarrow\; s = 2 \pm 2\sqrt{\tfrac{3-y}{3}}.$$

The feasible interval is $[s_1, s_2]$ with $s_1 = 2 - 2\sqrt{\tfrac{3-y}{3}}$, $
s_2 = 2 + 2\sqrt{\tfrac{3-y}{3}}$. Since $y > \tfrac{45}{16}$, we get $s_1 > \tf
rac{3}{2}$, so the vertex $s = \tfrac{3}{2}$ lies to the left of the interval; $
p(s)$ is increasing on $[s_1, s_2]$. The minimum is at $s = s_1$:

$$\min bc = p(s_1) = \tfrac{s_1^2}{4} = \left(1 - \sqrt{\tfrac{3-y}{3}}\right)^2
.$$

**Case 3: $0 < y \le \tfrac{9}{4}$.**

$p\!\left(\tfrac{3}{2}\right) = y - \tfrac{9}{4} \le 0$, so the vertex is infeas
ible. The roots of $p(s) = 0$ are $s = \tfrac{3 \pm \sqrt{9-4y}}{2}$, both in $(
0,3)$. As $s$ approaches a root from the feasible side, $p \to 0^+$ with all con
straints satisfied ($p > 0$ small, $p \le \tfrac{s^2}{4}$ holds, $a = 3 - s > 0$
). So $\inf bc = 0$, **not attained** — no minimum exists.

---

**Verification.**
- $y = 3$: Case 2 gives $(1 - 0)^2 = 1$, matching $a = b = c = 1$. ✓
- $y = \tfrac{45}{16}$: both formulas give $\tfrac{9}{16}$. ✓
- $y = \tfrac{5}{2}$ (Case 1): $\min bc = \tfrac{1}{4}$, attained at $s = \tfrac
{3}{2}$, $b, c = \tfrac{3 \pm \sqrt{5}}{4} > 0$, $a = \tfrac{3}{2}$; check $ab +
 ac + bc = \tfrac{9}{4} + \tfrac{1}{4} = \tfrac{5}{2}$. ✓

---

$$\boxed{\min bc = \begin{cases} y - \dfrac{9}{4}, & \dfrac{9}{4} < y \le \dfrac
{45}{16}, \\[8pt] \left(1 - \sqrt{\dfrac{3-y}{3}}\right)^2, & \dfrac{45}{16} < y
 \le 3. \end{cases}}$$

*(For $0 < y \le \tfrac{9}{4}$, the infimum is $0$ but is not attained, so no mi
nimum exists.)*
