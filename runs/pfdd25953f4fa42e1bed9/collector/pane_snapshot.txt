## Proof

Let $Q(z) = z^7 + 2z^4 - z$ (the fixed part) and $F(z) = az^6 + bz^3 + c$ (the f
ree part), so $P(z) = Q(z) + F(z)$.

### Step 1: Lower Bound via Cube-Root Symmetry

Let $\omega = e^{2\pi i/3}$. For any $z_0$ on the unit circle, consider the thre
e points $z_0, z_0\omega, z_0\omega^2$.

**Key observations:**

**(a)** Since $(z_0\omega^k)^3 = z_0^3 \omega^{3k} = z_0^3$ and $(z_0\omega^k)^6
 = z_0^6$, the free part is identical at all three points:
$$F(z_0\omega^k) = az_0^6 + bz_0^3 + c =: F_0 \quad \text{(independent of } k\te
xt{)}.$$

**(b)** Since $\omega^3 = 1$, we have $\omega^7 = \omega$ and $\omega^4 = \omega
$, so:
$$Q(z_0\omega^k) = (z_0\omega^k)^7 + 2(z_0\omega^k)^4 - z_0\omega^k = \omega^k(z
_0^7 + 2z_0^4 - z_0) = \omega^k Q(z_0).$$

Therefore $P(z_0\omega^k) = \omega^k Q(z_0) + F_0$ for $k = 0, 1, 2$.

**Applying the equilateral-triangle identity.** Using $\sum_{k=0}^2 \omega^k = 0
$ and $\sum_{k=0}^2 \omega^{2k} = 0$:

$$\sum_{k=0}^{2} |P(z_0\omega^k)|^2 = \sum_{k=0}^{2} |F_0 + \omega^k Q(z_0)|^2 =
 3|F_0|^2 + 3|Q(z_0)|^2 + 2\operatorname{Re}\!\left(\overline{F_0}\,Q(z_0)\sum_{
k=0}^2 \omega^k\right) = 3|F_0|^2 + 3|Q(z_0)|^2.$$

Hence:
$$\max_{k=0,1,2} |P(z_0\omega^k)|^2 \geq \frac{3(|F_0|^2 + |Q(z_0)|^2)}{3} = |F_
0|^2 + |Q(z_0)|^2 \geq |Q(z_0)|^2.$$

Since this holds for **every** $z_0$ on the unit circle and **every** choice of
$a, b, c$ (the parameter $F_0$ cancels in the inequality):

$$\max_{|z|=1} |P(z)| \geq \max_{|z_0|=1} |Q(z_0)|.$$

### Step 2: Computing $\max_{|z|=1} |Q(z)|$

Since $|z| = 1$:
$$|Q(z)| = |z^7 + 2z^4 - z| = |z|\cdot|z^6 + 2z^3 - 1| = |z^6 + 2z^3 - 1|.$$

Set $w = z^3$ (so $|w| = 1$) and $f(w) = w^2 + 2w - 1$. Then:

$$|f(w)|^2 = (w^2 + 2w - 1)(\bar{w}^2 + 2\bar{w} - 1) = (w^2 + 2w - 1)(w^{-2} +
2w^{-1} - 1).$$

Expanding:
$$= 1 + 2w - w^2 + 2w^{-1} + 4 - 2w - w^{-2} - 2w^{-1} + 1 = 6 - (w^2 + w^{-2})
= 6 - 2\cos(2\varphi),$$

where $w = e^{i\varphi}$. This is maximized when $\cos(2\varphi) = -1$ (i.e., $\
varphi = \pi/2$, $w = i$), giving:

$$|f(i)|^2 = 8 \implies \max_{|z|=1} |Q(z)| = 2\sqrt{2}.$$

Verification: $f(i) = i^2 + 2i - 1 = -2 + 2i$, $|f(i)| = \sqrt{4+4} = 2\sqrt{2}$
. ✓

### Step 3: Attainability (Upper Bound)

Setting $a = b = c = 0$ yields $P(z) = Q(z)$, and from Step 2:

$$\max_{|z|=1} |P(z)| = 2\sqrt{2}.$$

### Conclusion

For all $a, b, c \in \mathbb{C}$: $\max_{|z|=1} |P(z)| \geq 2\sqrt{2}$ (Step 1 +
 Step 2), and this bound is achieved at $a = b = c = 0$ (Step 3). Therefore:

$$\boxed{m = 2\sqrt{2}}$$
