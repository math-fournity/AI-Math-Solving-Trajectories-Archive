## Analysis

**Triangle structure.** An isosceles right triangle with hypotenuse 2 has legs o
f length $\sqrt{2}$. Since all vertices must be grid vertices (integer coordinat
es), the hypotenuse—being a segment of length 2 between grid points—must be hori
zontal or vertical (the only integer solutions to $a^2+b^2=4$ are $(\pm2,0)$ and
 $(0,\pm2)$). The two legs are diagonals of unit squares.

**Which sides cover unit segments?** The hypotenuse lies along a grid line and c
overs exactly 2 consecutive unit segments. The legs are diagonals of unit square
s—they pass through square interiors and contain no unit segments. So **each tri
angle covers exactly 2 unit segments** via its hypotenuse.

**Counting.** The $n\times n$ grid has $n(n+1)$ horizontal unit segments and $n(
n+1)$ vertical unit segments, totaling $2n(n+1)$. We need $n(n+1)$ triangles.

**Apex existence.** For a horizontal hypotenuse from $(x,y)$ to $(x+2,y)$, the a
pex is at $(x+1, y\pm1)$. For boundary rows ($y=0$ or $y=n$), one choice is alwa
ys inside the grid; for interior rows, both choices work. So the apex always exi
sts for any valid hypotenuse position. No additional constraint here.

**The key constraint: pairing.** Since horizontal unit segments can only pair wi
th collinear horizontal segments (same row), and vertical with vertical (same co
lumn), the problem reduces to: **in each row of $n$ horizontal segments, and eac
h column of $n$ vertical segments, can we partition the $n$ segments into pairs
of consecutive segments?**

This is equivalent to finding a perfect matching on the path graph $P_n$ (vertic
es = segments, edges = adjacency). A path graph $P_n$ has a perfect matching **i
f and only if $n$ is even**: vertex 1 has only one neighbor (vertex 2), forcing
edge $(1,2)$; then vertex 3 has only one remaining neighbor (vertex 4), forcing
$(3,4)$; and so on. This works when $n$ is even, giving the unique matching $\{(
1,2),(3,4),\ldots,(n-1,n)\}$. When $n$ is odd, vertex $n$ is left unmatched.

**Conclusion:** The covering is possible if and only if $n$ is even.

- **$n$ even:** Pair segments $(1,2),(3,4),\ldots,(n-1,n)$ in every row and colu
mn. Each pair forms a valid hypotenuse with an existing apex. All $2n(n+1)$ unit
 segments are covered exactly once. ✓
- **$n$ odd:** Each row has $n$ (odd) horizontal segments with no perfect matchi
ng on $P_n$, so at least one segment per row is uncovered. Impossible. ✗

**Verification for $n=2$:** The $2\times 2$ grid has 12 unit segments. Three row
s pair their 2 segments each (3 horizontal hypotenuses), three columns pair thei
r 2 segments each (3 vertical hypotenuses). All 12 segments covered, each exactl
y once. ✓

**Verification for $n=3$:** Each row has 3 horizontal segments; $P_3$ has no per
fect matching (vertex 3 is isolated after any edge choice). Impossible. ✓
