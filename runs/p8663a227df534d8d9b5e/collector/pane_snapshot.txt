## Solution

Let me define:
$$A = e^x \sin x + \cos x, \qquad B = e^x \cos x - \sin x$$

so the integral becomes $\displaystyle\int \frac{e^{2x}-e^x+1}{AB}\,dx$.

**Key observation.** Consider the logarithmic derivative of $A/B$:

$$\frac{d}{dx}\ln\left|\frac{A}{B}\right| = \frac{A'}{A} - \frac{B'}{B} = \frac{
A'B - AB'}{AB}.$$

I claim the numerator $A'B - AB'$ equals $e^{2x}-e^x+1$.

**Computing the derivatives:**
$$A' = e^x\sin x + e^x\cos x - \sin x, \qquad B' = e^x\cos x - e^x\sin x - \cos
x.$$

**Expanding $A'B$:**
$$A'B = (e^x\sin x + e^x\cos x - \sin x)(e^x\cos x - \sin x)$$
$$= e^{2x}\sin x\cos x - e^x\sin^2 x + e^{2x}\cos^2 x - e^x\sin x\cos x - e^x\si
n x\cos x + \sin^2 x$$
$$= e^{2x}\cos x(\sin x + \cos x) - e^x(\sin^2 x + 2\sin x\cos x) + \sin^2 x.$$

**Expanding $AB'$:**
$$AB' = (e^x\sin x + \cos x)(e^x\cos x - e^x\sin x - \cos x)$$
$$= e^{2x}\sin x\cos x - e^{2x}\sin^2 x - e^x\sin x\cos x + e^x\cos^2 x - e^x\si
n x\cos x - \cos^2 x$$
$$= e^{2x}\sin x(\cos x - \sin x) - e^x(2\sin x\cos x - \cos^2 x) - \cos^2 x.$$

**Taking the difference $A'B - AB'$:**

Collecting the $e^{2x}$ terms:
$$e^{2x}\big[\cos x(\sin x+\cos x) - \sin x(\cos x - \sin x)\big] = e^{2x}\big[\
sin x\cos x + \cos^2 x - \sin x\cos x + \sin^2 x\big] = e^{2x}.$$

Collecting the $e^x$ terms:
$$-e^x\big[(\sin^2 x + 2\sin x\cos x) - (2\sin x\cos x - \cos^2 x)\big] = -e^x\b
ig[\sin^2 x + \cos^2 x\big] = -e^x.$$

Collecting the constant terms:
$$\sin^2 x + \cos^2 x = 1.$$

Therefore:
$$A'B - AB' = e^{2x} - e^x + 1,$$

which is exactly the numerator of the integrand.

**Conclusion.** Since
$$\frac{e^{2x}-e^x+1}{AB} = \frac{A'B - AB'}{AB} = \frac{d}{dx}\ln\left|\frac{A}
{B}\right|,$$

we obtain
$$\int\frac{e^{2x}-e^x+1}{(e^x\sin x+\cos x)(e^x\cos x-\sin x)}\,dx = \ln\left|\
frac{e^x\sin x+\cos x}{e^x\cos x-\sin x}\right| + C.$$
