## Proof

**Upper bound via Jensen's formula.**

Since $f$ is analytic on the closed disk $|z| \leq R$ with $f(0) \neq 0$, Jensen
's formula gives:

$$\frac{1}{2\pi}\int_0^{2\pi} \log|f(Re^{i\theta})|\,d\theta = \log|f(0)| + \sum
_{k=1}^{n} \log\frac{R}{|z_k|}$$

where $z_1, \dots, z_n$ are all zeros of $f$ in $|z| < R$, counted with multipli
city.

Since $|f(z)| < M$ for all $|z| \leq R$, we have $\log|f(Re^{i\theta})| < \log M
$ for every $\theta$. By continuity of $f$, the inequality is strict pointwise,
so:

$$\log a + \sum_{k=1}^{n} \log\frac{R}{|z_k|} < \log M$$

$$\sum_{k=1}^{n} \log\frac{R}{|z_k|} < \log\frac{M}{a}$$

Among all zeros, let $N$ of them lie in $B(0, R/3)$, so $|z_k| \leq R/3$ (or $|z
_k| < R/3$). For each such zero, $\log\frac{R}{|z_k|} \geq \log 3$ (resp. $> \lo
g 3$). Any remaining zeros in $R/3 < |z_k| < R$ contribute $\log\frac{R}{|z_k|}
> 0$ to the sum. Therefore:

$$N \log 3 \leq \sum_{k=1}^{n} \log\frac{R}{|z_k|} < \log\frac{M}{a}$$

This gives the strict inequality:

$$N < \frac{\log(M/a)}{\log 3}$$

Since $N$ is a non-negative integer, we conclude:

$$N \leq \left\lceil \frac{\log(M/a)}{\log 3} \right\rceil - 1$$

(Note: $M > a$ is forced by $|f(0)| = a < M$, so $\log(M/a) > 0$ and the bound i
s non-negative.)

**Sharpness via Blaschke products.**

Set $L = \frac{\log(M/a)}{\log 3} = \log_3(M/a)$ and $N_0 = \lceil L \rceil - 1$
. We verify $N_0 < L$:
- If $L \notin \mathbb{Z}$: $N_0 = \lfloor L \rfloor < L$. ✓
- If $L = m \in \mathbb{Z}$: $N_0 = m - 1 < m = L$. ✓

Hence $3^{N_0} < 3^L = M/a$, i.e., $a \cdot 3^{N_0} < M$.

Choose $N_0$ distinct points on $|z| = R/3$, e.g., $z_k = \frac{R}{3} e^{2\pi i
k/N_0}$ for $k = 1, \dots, N_0$. Define:

$$f(z) = a \prod_{k=1}^{N_0} \frac{R^2(z - z_k)}{-z_k(R^2 - \bar{z}_k\, z)}$$

Each factor is a normalized Blaschke factor for the disk of radius $R$. We verif
y:

1. **Analyticity:** The poles of the Blaschke factors are at $z = R^2/\bar{z}_k$
, which have modulus $R^2/|z_k| = R^2/(R/3) = 3R > R$. So $f$ is analytic on $|z
| \leq R$. ✓

2. **Value at origin:** $f(0) = a \prod_{k=1}^{N_0} \frac{R^2(-z_k)}{-z_k \cdot
R^2} = a$. ✓

3. **Bound on $|z| = R$:** For each Blaschke factor, on $|z| = R$:
$$\left|\frac{R(z - z_k)}{R^2 - \bar{z}_k z}\right| = 1$$
(This follows since $|Re^{i\theta} - z_k|^2 = R^2 - 2R\operatorname{Re}(e^{i\the
ta}\bar{z}_k) + |z_k|^2 = |R - \bar{z}_k e^{i\theta}|^2$.) Therefore:
$$|f(z)| = a \prod_{k=1}^{N_0} \frac{R}{|z_k|} = a \cdot 3^{N_0} < M \quad \text
{on } |z| = R$$

4. **Bound inside:** By the maximum modulus principle, $|f(z)| \leq a \cdot 3^{N
_0} < M$ for all $|z| \leq R$. ✓

5. **Zeros:** $f$ has exactly $N_0$ zeros in $B(0, R/3)$, at $z_1, \dots, z_{N_0
}$, each with $|z_k| = R/3$. ✓

**Conclusion.** The upper bound $N \leq \lceil \log_3(M/a) \rceil - 1$ is achiev
ed by the Blaschke product construction, so the maximum possible value of $N$ is
:

$$\boxed{N_{\max} = \left\lceil \frac{\log(M/a)}{\log 3} \right\rceil - 1}$$
