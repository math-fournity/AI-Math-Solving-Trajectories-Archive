## Proof

The function $f$ is defined on $[0,1]$ by
$$f(x) = \begin{cases} 1 & x \in C \cap \mathbb{Q} \\ 2 & x \in C \cap (\mathbb{
R}\setminus\mathbb{Q}) \\ 3 & x \in [0,1]\setminus C \end{cases}$$
where $C$ is the Cantor ternary set.

**Key facts.**

1. The Cantor ternary set $C \subset [0,1]$ is closed, uncountable, and has **Le
besgue measure $m(C) = 0$**. (It is constructed by removing open middle-thirds w
hose total length is $\sum_{n=1}^{\infty} 2^{n-1}/3^n = 1$, so $m(C) = 1 - 1 = 0
$.)

2. The rationals $\mathbb{Q}$ are countable, hence $m(\mathbb{Q}) = 0$.

**Decomposing the domain.** The three pieces
$$A_1 = C \cap \mathbb{Q}, \quad A_2 = C \cap (\mathbb{R}\setminus\mathbb{Q}), \
quad A_3 = [0,1]\setminus C$$
are pairwise disjoint and partition $[0,1]$. On each piece $f$ is constant (equa
l to $1, 2, 3$ respectively), so $f$ is a simple (measurable) function and its L
ebesgue integral is
$$\int_{[0,1]} f\,dm = 1\cdot m(A_1) + 2\cdot m(A_2) + 3\cdot m(A_3).$$

**Measures of the pieces.**

- $A_1 = C \cap \mathbb{Q} \subseteq \mathbb{Q}$, and $\mathbb{Q}$ is countable,
 so $m(A_1) = 0$.
- $A_2 = C \cap (\mathbb{R}\setminus\mathbb{Q}) \subseteq C$, and $m(C) = 0$, so
 $m(A_2) = 0$.
- $A_3 = [0,1]\setminus C$, so $m(A_3) = m([0,1]) - m(C) = 1 - 0 = 1$.

**Computing the integral.**
$$\int_{[0,1]} f\,dm = 1\cdot 0 + 2\cdot 0 + 3\cdot 1 = 3.$$

The value of $f$ on the Cantor set (whether at rational or irrational points) is
 irrelevant to the Lebesgue integral, since the Cantor set is a null set. Only t
he value $3$ on the full-measure set $[0,1]\setminus C$ contributes.

$$\boxed{\displaystyle\int_{[0,1]} f\,dm = 3}$$

### PROOF COMPLETE
