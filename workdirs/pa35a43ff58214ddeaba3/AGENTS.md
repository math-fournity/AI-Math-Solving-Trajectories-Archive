# Problem

In a remote high-tech facility, an automated scanner must inspect a vertical array of solar sensors arranged in 7 rows and 2 columns. Each of the 14 sensors is independently programmed to emit either a Red or Blue light with equal probability (50/50).

A robotic inspection probe is tasked with visiting every single sensor exactly once. The probe's mission begins at one of the two sensors in the top row and must conclude at one of the two sensors in the bottom row. To move between sensors, the probe can travel horizontally, vertically, or diagonally to any immediate neighbor.

The facility manager is interested in a "perfect strobe" sequence: a path through all 14 sensors where the lights encountered strictly alternate in color (e.g., Red, Blue, Red, Blue...).

What is the probability that at least one such Hamiltonian path exists for the given color configuration? If this probability is expressed as an irreducible fraction $\frac{a}{b}$, compute the value $a + b$.
