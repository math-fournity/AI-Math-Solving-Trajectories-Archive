## Solution

**Rearranging the ODE.** The given equation is
$$f'(x) - g'(x) = g'(x)\,f(x)^2 - f'(x)\,g(x)^2.$$

Collecting $f'$ and $g'$ terms:
$$f'(x)\bigl(1 + g(x)^2\bigr) = g'(x)\bigl(1 + f(x)^2\bigr),$$
so
$$\frac{f'(x)}{1+f(x)^2} = \frac{g'(x)}{1+g(x)^2}.$$

This says $\frac{d}{dx}\arctan f(x) = \frac{d}{dx}\arctan g(x)$, hence
$$\arctan f(x) - \arctan g(x) = C$$
for some constant $C$.

**Determining $C$.** At $x=1$: $C = \arctan(1) - \arctan(1/3) = \frac{\pi}{4} -
\arctan\frac{1}{3}$.

Using the identity $\arctan\frac{1}{2} + \arctan\frac{1}{3} = \arctan\!\left(\fr
ac{1/2+1/3}{1-1/6}\right) = \arctan(1) = \frac{\pi}{4}$, we get $\arctan\frac{1}
{3} = \frac{\pi}{4} - \arctan\frac{1}{2}$, so
$$C = \arctan\frac{1}{2} =: \alpha.$$

**Setting up the minimization.** Let $v = \arctan g(x)$, so $\arctan f(x) = v +
\alpha$. Then $f = \tan(v+\alpha)$, $g = \tan v$, and
$$f - g = \tan(v+\alpha) - \tan v = \frac{\sin\alpha}{\cos(v+\alpha)\cos v}.$$

The domain: $v \in (-\pi/2,\, \pi/2)$ and $v+\alpha \in (-\pi/2,\, \pi/2)$, givi
ng $v \in (-\pi/2,\, \pi/2-\alpha)$.

**Checking the constraints $f \neq -2$, $g \neq 2$.** Note $\arctan 2 + \arctan\
frac{1}{2} = \frac{\pi}{2}$, so $\arctan 2 = \frac{\pi}{2}-\alpha$.

- $g = 2$ requires $v = \arctan 2 = \frac{\pi}{2}-\alpha$, which is the **exclud
ed endpoint** of the domain. ✓
- $f = -2$ requires $v + \alpha = -\arctan 2 = -\frac{\pi}{2}+\alpha$, i.e. $v =
 -\frac{\pi}{2}$, also an **excluded endpoint**. ✓

Both constraints are automatically satisfied, confirming consistency.

**Minimizing.** We minimize $f - g + 3 = \frac{\sin\alpha}{\cos(v+\alpha)\cos v}
 + 3$, i.e. maximize
$$\cos(v+\alpha)\cos v = \tfrac{1}{2}\bigl[\cos(2v+\alpha) + \cos\alpha\bigr].$$
This is maximized when $\cos(2v+\alpha)=1$, i.e. $v = -\alpha/2$, which lies in
$(-\pi/2,\, \pi/2-\alpha)$. The maximum is $\cos^2(\alpha/2)$, giving
$$f - g = \frac{\sin\alpha}{\cos^2(\alpha/2)} = 2\tan\frac{\alpha}{2}.$$

**Computing $\tan(\alpha/2)$** with $\tan\alpha = \frac{1}{2}$: setting $t = \ta
n(\alpha/2)$,
$$\frac{2t}{1-t^2} = \frac{1}{2} \implies t^2 + 4t - 1 = 0 \implies t = -2 + \sq
rt{5}.$$

Therefore
$$f - g + 3 = 2(\sqrt{5}-2) + 3 = 2\sqrt{5} - 1.$$

Since $\cos(v+\alpha)\cos v > 0$ throughout the domain, $f - g > 0$ always, so $
f-g+3 > 3$; the unique minimum is attained at $v = -\alpha/2$ and equals

$$\boxed{2\sqrt{5}-1}.$$
