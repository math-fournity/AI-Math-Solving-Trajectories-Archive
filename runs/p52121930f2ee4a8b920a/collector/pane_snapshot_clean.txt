Looking at this problem, I need to find positive integers $n$ with divisors $a >
 b > c \geq 1$ such that $a^2-b^2$, $b^2-c^2$, and $a^2-c^2$ also divide $n$.

## Proof

**Step 1: A working example.** Take $(a,b,c) = (4,2,1)$. Then:
- $a^2 - b^2 = 12$, $b^2 - c^2 = 3$, $a^2 - c^2 = 15$.
- The required divisibility is $\text{lcm}(4,2,1,12,3,15) = 60 \mid n$.

So $n = 60$ works, and every multiple of 60 works using this triple.

**Step 2: 60 divides every valid $n$.** I show that for any valid triple $(a,b,c
)$, the lcm $L = \text{lcm}(a,b,c,a^2{-}b^2,b^2{-}c^2,a^2{-}c^2)$ is divisible b
y $4 \cdot 3 \cdot 5 = 60$.

**Divisibility by 5.** Squares mod 5 are $\{0,1,4\}$. If $5 \mid a$ or $5 \mid b
$ or $5 \mid c$, then $5 \mid L$. Otherwise $a^2,b^2,c^2 \in \{1,4\} \pmod{5}$.
By pigeonhole, at least two of $a^2,b^2,c^2$ are congruent mod 5, so at least on
e of the three differences $a^2-b^2, b^2-c^2, a^2-c^2$ is divisible by 5. Hence
$5 \mid L$.

**Divisibility by 3.** Squares mod 3 are $\{0,1\}$. If $3 \mid a$ or $3 \mid b$
or $3 \mid c$, then $3 \mid L$. Otherwise $a^2 \equiv b^2 \equiv c^2 \equiv 1 \p
mod{3}$, so all three differences are $\equiv 0 \pmod{3}$. Hence $3 \mid L$.

**Divisibility by 4.** Squares mod 4 are $\{0,1\}$. I check all parity patterns
of $(a,b,c)$:

- **All odd:** all squares $\equiv 1$, so all differences $\equiv 0 \pmod{4}$. ✓
- **Exactly one even:** If $a$ even, $b,c$ odd: $b^2-c^2 \equiv 0 \pmod{4}$. If
$b$ even, $a,c$ odd: $a^2-c^2 \equiv 0 \pmod{4}$. If $c$ even, $a,b$ odd: $a^2-b
^2 \equiv 0 \pmod{4}$. ✓
- **Exactly two even:** If $a,b$ even, $c$ odd: $a^2-b^2 \equiv 0 \pmod{4}$. If
$a,c$ even, $b$ odd: $a^2-c^2 \equiv 0 \pmod{4}$. If $b,c$ even, $a$ odd: $b^2-c
^2 \equiv 0 \pmod{4}$. ✓
- **All even:** all squares $\equiv 0 \pmod{4}$, so all differences $\equiv 0 \p
mod{4}$. ✓

In every case, at least one of the six quantities is divisible by 4, so $4 \mid
L$.

Since $\gcd(4,3)=\gcd(4,5)=\gcd(3,5)=1$, we conclude $60 \mid L$, hence $60 \mid
 n$.

**Step 3: Conclusion.** Every valid $n$ is a multiple of 60 (Step 2), and $n=60$
 itself is valid (Step 1), so every positive multiple of 60 is valid. The five s
mallest are:

$$60,\ 120,\ 180,\ 240,\ 300.$$

Their sum is:

$$60 + 120 + 180 + 240 + 300 = \boxed{900}.$$
