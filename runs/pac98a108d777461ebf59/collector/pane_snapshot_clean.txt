## Proof

The measure $\mu$ is defined by
$$\mu(E) = \int_{E \cap B(0,1)} \sqrt{x^2+y^2+z^2}\, d\lambda_3(x,y,z).$$

This means $\mu$ is the measure with density $g(x,y,z) = \sqrt{x^2+y^2+z^2}$ wit
h respect to $\lambda_3$, restricted to the ball $B(0,1)$. Equivalently, $d\mu =
 g\cdot \mathbf{1}_{B(0,1)}\, d\lambda_3$, so $\mu$ is supported on $\overline{B
(0,1)}$.

For any $\lambda_3$-measurable function $f$ that is $\mu$-integrable, the standa
rd change-of-density formula gives
$$\int_E f\, d\mu = \int_{E \cap B(0,1)} f(x,y,z)\, g(x,y,z)\, d\lambda_3(x,y,z)
.$$

Apply this with $f(x,y,z) = xy^2 + y^2z$ and $E = B(0,2)$. Since $B(0,1) \subset
 B(0,2)$, we have $B(0,2) \cap B(0,1) = B(0,1)$. Therefore
$$\int_{B(0,2)} (xy^2+y^2z)\, d\mu = \int_{B(0,1)} (xy^2+y^2z)\,\sqrt{x^2+y^2+z^
2}\, d\lambda_3(x,y,z).$$

The right-hand side is exactly the right-hand side of the stated equality. Hence
 the equality holds.

**Note on integrability:** The function $xy^2+y^2z$ is continuous, hence bounded
 on the compact set $\overline{B(0,1)}$, and $\sqrt{x^2+y^2+z^2}$ is bounded the
re as well. Both integrals are therefore finite, so the manipulation is justifie
d.
