## Solution

**Key reformulation.** Since $a_i + \frac{1}{a_i} = \frac{a_i^2+1}{a_i}$, the eq
uation becomes:
$$\prod_{i=1}^n (a_i^2 + 1) = 2020 \cdot \prod_{i=1}^n a_i.$$

Since $2020 = 2^2 \cdot 5 \cdot 101$, for each prime $p$ we need:
$$\sum_i v_p(a_i^2+1) - \sum_i v_p(a_i) = v_p(2020). \tag{$\star$}$$

**Step 1: The prime 101 must come from $a = 10$.**

Since $v_{101}(2020) = 1$, we need a net $+1$ contribution of 101. The only way
to get $101 \mid a^2+1$ with $a < 91$ is $a = 10$ (since $10^2+1 = 101$, and the
 next solution to $a^2 \equiv -1 \pmod{101}$ is $a = 91$). For $a \geq 91$, the
factor $a + 1/a > 91$ forces the remaining product below $2020/91 \approx 22.2$,
 and a careful valuation analysis shows no valid completion exists. Thus $a = 10
$ must appear, contributing factor $101/10$, leaving a remaining product of $200
$.

**Step 2: Systematic exclusion for the remaining product 200.**

We need $\prod(a_j + 1/a_j) = 200$ with all $a_j \leq 10$ (nondecreasing). We us
e $(\star)$ with $v_p(200)$:

- **Primes $p \equiv 3 \pmod{4}$ (e.g., $p = 3, 7$):** $-1$ is not a quadratic r
esidue mod $p$, so $p \nmid a^2+1$ for any $a$ with $p \nmid a$. If $p \mid a$,
then $a^2+1 \equiv 1 \pmod{p}$, giving $v_p(a^2+1)=0$ but $v_p(a) \geq 1$, a net
 negative contribution with no way to compensate. Since $v_p(200)=0$, **no $a_j$
 can be divisible by 3 or 7**. This excludes $a \in \{3, 6, 7, 9\}$.

- **Prime $p = 13$:** $v_{13}(200)=0$. Since $5^2 \equiv -1 \pmod{13}$, both $a=
5$ ($a^2+1=26=2\cdot13$) and $a=8$ ($a^2+1=65=5\cdot13$) contribute $+1$ to the
13-valuation. To balance, we'd need $13 \mid a_j$ for some $j$, but all $a_j \le
q 10 < 13$. **Excludes $a \in \{5, 8\}$**.

- **Prime $p = 17$:** $v_{17}(200)=0$. $a=4$ gives $a^2+1=17$, contributing $+1$
. Balancing requires $17 \mid a_j$, impossible. **Excludes $a = 4$**.

- **Prime $p = 41$:** $v_{41}(200)=0$. $a=9$ gives $a^2+1=82=2\cdot41$, contribu
ting $+1$. Balancing requires $41 \mid a_j$, impossible. (Already excluded via $
p=3$.)

**Step 3: Only $a \in \{1, 2\}$ remain.** Setting $k_1$ = number of 1's, $k_2$ =
 number of 2's:

- $p = 5$: Each $a=2$ contributes $v_5(5) - v_5(2) = 1$. So $k_2 = v_5(200) = 2$
.
- $p = 2$: Each $a=1$ contributes $v_2(2) - v_2(1) = 1$; each $a=2$ contributes
$v_2(5) - v_2(2) = -1$. So $k_1 - k_2 = v_2(200) = 3$, giving $k_1 = 5$.
- All other primes: contributions are 0. ✓

**Verification:**
$$\left(1+\frac{1}{1}\right)^5 \left(2+\frac{1}{2}\right)^2 \left(10+\frac{1}{10
}\right) = 2^5 \cdot \left(\frac{5}{2}\right)^2 \cdot \frac{101}{10} = 32 \cdot
\frac{25}{4} \cdot \frac{101}{10} = 200 \cdot \frac{101}{10} = 2020. \checkmark$
$

The unique nondecreasing sequence is $(1, 1, 1, 1, 1, 2, 2, 10)$, and the sum is
:
$$a_1 + a_2 + \cdots + a_n = 5(1) + 2(2) + 10 = \boxed{19}$$
