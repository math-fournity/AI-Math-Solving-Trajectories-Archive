# Problem

In the remote Archipelago of the Five Crowns, there are five major islands, each hosting a single central hub. To facilitate trade, the ancestors built a bridge between every possible pair of islands, creating a complete network of spans.

The High Architect has announced a renovation project and needs to decommission a specific set of these bridges for structural reinforcement. However, the Department of Logistics has issued a strict mandate: even after the selected bridges are closed, it must remain physically possible for a traveler to navigate from any island to any other island using the remaining open bridges (potentially passing through intermediate islands).

Calculate the total number of distinct ways the High Architect can select a set of bridges to be closed for renovation such that the islands remain fully connected.
