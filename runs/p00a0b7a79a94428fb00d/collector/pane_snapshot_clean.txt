## Proof

We compute
$$L = \lim_{k \to \infty} \sum_{n=1}^{\infty} \frac{1}{n^2 + ik},$$
where $i = \sqrt{-1}$ and $k \to +\infty$ through the reals (in particular throu
gh positive integers).

**Setup as integration against counting measure.** Let $(\mathbb{N}, \mathcal{P}
(\mathbb{N}), \mu)$ be the natural numbers equipped with counting measure $\mu(\
{n\})=1$. Then the series is an integral:
$$\sum_{n=1}^{\infty} \frac{1}{n^2+ik} = \int_{\mathbb{N}} f_k\, d\mu, \qquad f_
k(n) := \frac{1}{n^2+ik}.$$

**Pointwise limit.** For each fixed $n \in \mathbb{N}$,
$$\left|\frac{1}{n^2+ik}\right| = \frac{1}{\sqrt{n^4+k^2}} \xrightarrow[k\to\inf
ty]{} 0,$$
so
$$f_k(n) \xrightarrow[k\to\infty]{} 0 \quad \text{for every } n.$$

**Dominating function.** For every $k>0$ and every $n\geq 1$,
$$|f_k(n)| = \frac{1}{\sqrt{n^4+k^2}} \leq \frac{1}{\sqrt{n^4}} = \frac{1}{n^2}.
$$
Set $g(n) := \dfrac{1}{n^2}$. Then $g$ is $\mu$-integrable since
$$\int_{\mathbb{N}} g\,d\mu = \sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6
} < \infty.$$

**Apply Lebesgue's Dominated Convergence Theorem.** The functions $f_k$ are meas
urable on $(\mathbb{N},\mathcal{P}(\mathbb{N}),\mu)$, $|f_k(n)|\leq g(n)$ with $
g\in L^1(\mu)$, and $f_k \to 0$ pointwise. Hence
$$\lim_{k\to\infty} \sum_{n=1}^{\infty} \frac{1}{n^2+ik} = \lim_{k\to\infty}\int
_{\mathbb{N}} f_k\,d\mu = \int_{\mathbb{N}}\lim_{k\to\infty} f_k\,d\mu = \int_{\
mathbb{N}} 0\,d\mu = 0.$$

Therefore,
$$\boxed{\displaystyle \lim_{k \to \infty} \sum_{n=1}^{\infty} \frac{1}{n^2 + ik
} = 0.}$$
