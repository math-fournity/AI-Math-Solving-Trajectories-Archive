## Proof

**Goal.** Given a locally compact Hausdorff (LCH) space $X$, with $K \subset U$,
 $K$ compact, $U$ open, construct a continuous $f: X \to \mathbb{R}$ with compac
t support such that $1_K \le f \le 1_U$.

---

### Step 1. Build an open set $V$ with $K \subset V \subset \overline{V} \subset
 U$ and $\overline{V}$ compact.

For each $x \in K$:

- By local compactness, $x$ has an open neighborhood $O_x$ with $\overline{O_x}$
 compact.
- Since $X$ is LCH, it is regular. The set $U \cap O_x$ is an open neighborhood
of $x$, so by regularity there exists an open set $W_x$ with
$$x \in W_x \subset \overline{W_x} \subset U \cap O_x.$$
Then $\overline{W_x} \subseteq \overline{O_x}$; being a closed subset of a compa
ct set in a Hausdorff space, $\overline{W_x}$ is compact, and $\overline{W_x} \s
ubset U$.

The family $\{W_x\}_{x \in K}$ is an open cover of the compact set $K$. Extract
a finite subcover $W_{x_1}, \dots, W_{x_n}$ and set
$$V := \bigcup_{i=1}^{n} W_{x_i}.$$

Then:

- $K \subset V$ and $V$ is open.
- $\overline{V} \subseteq \bigcup_{i=1}^{n} \overline{W_{x_i}} =: C$. Each $\ove
rline{W_{x_i}}$ is compact, so $C$ (a finite union of compact sets in a Hausdorf
f space) is compact. Since $\overline{V}$ is a closed subset of the compact set
$C$, it is compact.
- $\overline{V} \subset U$ (since each $\overline{W_{x_i}} \subset U$).

So we have
$$K \subset V \subset \overline{V} \subset U, \qquad \overline{V} \text{ compact
.}$$

---

### Step 2. Apply Urysohn's lemma on the compact Hausdorff space $\overline{V}$.

The space $\overline{V}$ is compact Hausdorff, hence normal. The sets

- $K$ (compact in Hausdorff $\Rightarrow$ closed in $\overline{V}$),
- $\overline{V} \setminus V$ (closed in $\overline{V}$),

are disjoint closed subsets of $\overline{V}$. By Urysohn's lemma for normal spa
ces, there exists a continuous function
$$g: \overline{V} \to [0,1]$$
with $g|_K = 1$ and $g|_{\overline{V} \setminus V} = 0$.

---

### Step 3. Extend $g$ to all of $X$ by zero.

Define $f: X \to [0,1]$ by
$$f(x) = \begin{cases} g(x), & x \in \overline{V}, \\ 0, & x \in X \setminus \ov
erline{V}. \end{cases}$$

**Continuity.** We use the pasting (gluing) lemma with the two closed sets
$$A := \overline{V} \quad (\text{compact in Hausdorff } \Rightarrow \text{ close
d}), \qquad B := X \setminus V \quad (\text{closed, since } V \text{ is open}).$
$
Their union is $A \cup B = \overline{V} \cup (X \setminus V) = X$ (because $V \s
ubseteq \overline{V}$). Their intersection is
$$A \cap B = \overline{V} \setminus V.$$
On $A$, $f = g$ is continuous. On $B$, $f = 0$ is continuous. On $A \cap B = \ov
erline{V} \setminus V$, we have $g = 0$ by construction, so $f|_A = f|_B = 0$ on
 the intersection. By the pasting lemma, $f$ is continuous on $X$.

---

### Step 4. Verify the required properties.

**Compact support.** The set where $f \neq 0$ is contained in $\overline{V}$, so
$$\operatorname{supp}(f) = \overline{\{x : f(x) \neq 0\}} \subseteq \overline{V}
,$$
which is compact. Hence $f$ has compact support. $\checkmark$

**Lower bound $1_K \le f$.** For $x \in K$: $f(x) = g(x) = 1 = 1_K(x)$. For $x \
notin K$: $1_K(x) = 0 \le f(x)$. So $1_K \le f$ on $X$. $\checkmark$

**Upper bound $f \le 1_U$.** Since $\operatorname{supp}(f) \subseteq \overline{V
} \subset U$, for every $x \notin U$ we have $f(x) = 0 = 1_U(x)$. For $x \in U$,
 $f(x) \le 1 = 1_U(x)$. So $f \le 1_U$ on $X$. $\checkmark$

**Continuity.** Established in Step 3. $\checkmark$

---

### Conclusion.

The function $f: X \to [0,1] \subset \mathbb{R}$ constructed above is continuous
, has compact support contained in $U$, equals $1$ on $K$, and satisfies $1_K \l
e f \le 1_U$ on $X$. This completes the construction. $\blacksquare$
