## Solution

We model the disc as the cycle graph $C_{12}$: 12 vertices (sectors) arranged in
 a ring, with edges between adjacent sectors (including sector 12 adjacent to se
ctor 1). We seek the number of proper vertex-colorings of $C_{12}$ using $k=6$ c
olors, i.e., the chromatic polynomial $P(C_{12},\,6)$.

### Deriving the chromatic polynomial of a cycle

Let $a_n = P(C_n, k)$ denote the number of proper $k$-colorings of the cycle $C_
n$, and let $b_n = P(P_n, k) = k(k-1)^{n-1}$ denote the number of proper $k$-col
orings of the path on $n$ vertices.

**Key recurrence.** Consider the path $1\!-\!2\!-\!\cdots\!-\!n$ (the cycle $C_n
$ with the edge $\{n,1\}$ removed). Its proper colorings number $b_n = k(k-1)^{n
-1}$. Among these, split into:

- colorings with $c(n) \neq c(1)$: these are exactly the proper colorings of $C_
n$, contributing $a_n$;
- colorings with $c(n) = c(1)$: identifying vertices $1$ and $n$ (which now shar
e a color and are non-adjacent on the path) yields a proper coloring of $C_{n-1}
$, contributing $a_{n-1}$.

Hence
$$b_n = a_n + a_{n-1} \quad\Longrightarrow\quad a_n = k(k-1)^{n-1} - a_{n-1}, \q
quad n \ge 3,$$
with the base case $a_2 = k(k-1)$ (two adjacent vertices).

**Solving the recurrence.** Unrolling:
$$a_n = k(k-1)^{n-1} - k(k-1)^{n-2} + k(k-1)^{n-3} - \cdots + (-1)^{n-2}\,k(k-1)
.$$

This is a finite geometric-type alternating sum. One verifies directly (by subst
itution back into the recurrence, or by induction) that the closed form is
$$\boxed{a_n = (k-1)^n + (-1)^n(k-1)}.$$

*Verification of the closed form:*
- $a_2 = (k-1)^2 + (k-1) = (k-1)\bigl[(k-1)+1\bigr] = k(k-1)$. ✓
- $a_3 = (k-1)^3 - (k-1) = (k-1)\bigl[(k-1)^2-1\bigr] = (k-1)(k^2-2k) = k(k-1)(k
-2)$, which is the number of proper colorings of a triangle. ✓
- Recurrence check: $(k-1)^n + (-1)^n(k-1) = k(k-1)^{n-1} - \bigl[(k-1)^{n-1} +
(-1)^{n-1}(k-1)\bigr] = (k-1)^{n-1}(k-1) + (-1)^n(k-1) = (k-1)^n + (-1)^n(k-1)$.
 ✓

### Applying to $C_{12}$ with $k = 6$

Since $n = 12$ is even,
$$P(C_{12},\,6) = (6-1)^{12} + (6-1) = 5^{12} + 5.$$

Computing:
$$5^{12} = 244\,140\,625,$$
$$5^{12} + 5 = 244\,140\,625 + 5 = 244\,140\,630.$$

### Answer

The number of distinct colorings is

$$\boxed{244\,140\,630}.$$
