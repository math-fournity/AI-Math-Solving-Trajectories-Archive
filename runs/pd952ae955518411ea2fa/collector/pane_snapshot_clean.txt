## Proof

### Setup

Consider the linear regression model $y = X\beta + \varepsilon$ where $E(\vareps
ilon)=0$, $\operatorname{Var}(\varepsilon)=\sigma^2 V$, $V$ is positive definite
 (hence nonsingular), $X$ is $n\times k$, $W$ is $r\times k$. We seek the best a
ffine unbiased estimator (BAUE) of $W\beta$.

### Step 1: Existence Condition — Estimability of Wβ

An affine estimator has the form $Ay + c$ ($A$ is $r\times n$, $c$ is $r\times 1
$). Unbiasedness requires
$$E[Ay+c] = AX\beta + c = W\beta \quad \text{for all } \beta,$$
which forces $c=0$ and $AX = W$.

The equation $AX = W$ is solvable for $A$ if and only if each row of $W$ lies in
 the row space of $X$, equivalently:
$$\operatorname{im}(W') \subseteq \operatorname{im}(X').$$

This is the **estimability condition** for $W\beta$. If it fails, no affine unbi
ased estimator exists, and hence no BAUE exists.

**Existence condition:** The BAUE of $W\beta$ exists if and only if $\operatorna
me{im}(W')\subseteq \operatorname{im}(X')$, i.e., $W\beta$ is estimable.

### Step 2: Deriving the Estimator via Constrained Optimization

Assume $W\beta$ is estimable. Among all $A$ satisfying $AX = W$, we minimize $\o
peratorname{Var}(Ay) = \sigma^2 AVA'$ in the Löwner ordering, equivalently minim
izing $\operatorname{tr}(AVA')$.

Set up the Lagrangian with multiplier matrix $\Lambda$ ($k\times r$):
$$\mathcal{L} = \operatorname{tr}(AVA') - 2\operatorname{tr}(\Lambda'(AX - W)).$
$

Differentiating with respect to $A$:
$$\frac{\partial \mathcal{L}}{\partial A} = 2AV - 2\Lambda X' = 0 \implies AV =
\Lambda X' \implies A = \Lambda X' V^{-1}.$$

Substituting into the constraint $AX = W$:
$$\Lambda X'V^{-1}X = W.$$

Let $P := X'V^{-1}X$ ($k\times k$, symmetric, $\operatorname{rank}(P)=\operatorn
ame{rank}(X)$ since $V^{-1}$ is positive definite). Then $\Lambda P = W$, giving
$$\Lambda = W P^{-},$$
where $P^{-}$ is any generalized inverse of $P$ (satisfying $P P^{-} P = P$). Th
us:
$$\boxed{\hat{W}\beta = W(X'V^{-1}X)^{-}X'V^{-1}\,y.}$$

### Step 3: Invariance to the Choice of Generalized Inverse

We show the estimator is well-defined (independent of the choice of $P^{-}$). Le
t $G$ be any generalized inverse of $P$. We prove $XGP = X$:

$$X'V^{-1}(XGP - X) = (X'V^{-1}X)GP - X'V^{-1}X = PGP - P = 0.$$

So $XGP - X \in \ker(X'V^{-1})$. Since $V^{-1}$ is nonsingular, $\ker(X'V^{-1})
= V(\ker(X'))$. Also, columns of $XGP - X$ lie in $\operatorname{im}(X)$. We cla
im $\operatorname{im}(X) \cap V(\ker(X')) = \{0\}$:

If $z \in \operatorname{im}(X) \cap V(\ker(X'))$, then $z = Xu$ for some $u$, an
d $z = Vw$ with $X'w = 0$. Then $Pu = X'V^{-1}Xu = X'V^{-1}z = X'V^{-1}Vw = X'w
= 0$. Since $V^{-1}$ is positive definite, $\ker(P) = \ker(X)$ (because $u'Pu =
(Xu)'V^{-1}(Xu) = 0 \iff Xu = 0$). So $u \in \ker(X)$, hence $z = Xu = 0$.

Therefore $XGP = X$ for any generalized inverse $G$.

Now for two generalized inverses $G_1, G_2$, let $D = G_1 - G_2$. From $XG_1P =
XG_2P = X$ we get $XDP = 0$, i.e., $XDX'V^{-1}X = 0$. By the same argument (colu
mns of $XDX'$ in $\operatorname{im}(X)$, and $X'V^{-1}(XDX') = PDX' = 0$ forces
$XDX' \in V(\ker(X')) \cap \operatorname{im}(X) = \{0\}$), we obtain $XDX' = 0$.

Since $W\beta$ is estimable, $W = B'X$ for some $B$. Then:
$$W(G_1 - G_2)X'V^{-1} = B'X \cdot D \cdot X'V^{-1} = B'(XDX')V^{-1} = 0.$$

Hence $WG_1X'V^{-1}y = WG_2X'V^{-1}y$ for all $y$ — the estimator is **invariant
** to the choice of generalized inverse.

### Step 4: Variance Matrix

Since the estimator is invariant, its variance is also invariant. Using $A = WGX
'V^{-1}$:
$$\operatorname{Var}(\hat{W}\beta) = \sigma^2 AVA' = \sigma^2 WG(X'V^{-1}X)G'W'
= \sigma^2 WGPG'W'.$$

We show $WGPG'W' = WGW'$ (so the variance simplifies). It suffices to show $XGPG
'X' = XGX'$ (then sandwiching by $B$ and $B'$ gives the result). We have:
$$XGPG'X' = (XGP)(G'X') = X \cdot G'X', \quad \text{and} \quad XGX' \text{ is th
e other term}.$$

So $XGPG'X' - XGX' = X(G' - G)X' = (XGX')' - XGX'$, the antisymmetric part of $X
GX'$. We show $XGX'$ is symmetric: $X'V^{-1}(XGX') = PGX'$. Since $PGP = P$, $PG
$ acts as identity on $\operatorname{im}(P) = \operatorname{im}(X')$, so $PGX' =
 X'$. Similarly $X'V^{-1}(XG'X') = PG'X' = X'$ (from $PG'X' = (XGP)' = X'$). Thu
s $X'V^{-1}(XGX' - XG'X') = 0$, and by $\operatorname{im}(X) \cap V(\ker(X')) =
\{0\}$, we get $XGX' = XG'X'$, i.e., $XGX'$ is symmetric.

Therefore $WGPG'W' = WGW'$, and:
$$\boxed{\operatorname{Var}(\hat{W}\beta) = \sigma^2 W(X'V^{-1}X)^{-}W',}$$
invariant to the choice of generalized inverse.

### Step 5: Optimality — Minimum Variance Among Affine Unbiased Estimators

Let $A_0 = WGX'V^{-1}$ (the BAUE) and let $A = A_0 + D$ be any other matrix sati
sfying $AX = W$. Then $DX = 0$, i.e., $\operatorname{im}(D') \subseteq \ker(X')$
, so $X'D' = 0$.

Compute:
$$\operatorname{Var}(Ay) - \operatorname{Var}(A_0 y) = \sigma^2\bigl(A_0 V D' +
DV A_0' + DVD'\bigr).$$

Now $A_0 V = WGX'V^{-1}V = WGX'$, so $A_0 V D' = WGX'D'$. Since $X'D' = 0$:
$$A_0 V D' = WG \cdot 0 = 0, \quad \text{and likewise } DVA_0' = (A_0 V D')' = 0
.$$

Therefore:
$$\operatorname{Var}(Ay) - \operatorname{Var}(A_0 y) = \sigma^2 DVD' \geq 0 \qua
d \text{(positive semidefinite)},$$
since $V$ is positive definite. This proves $A_0$ yields the **minimum variance*
* affine unbiased estimator.

### Summary

**Existence condition:** The BAUE $\hat{W}\beta$ of $W\beta$ exists if and only
if $W\beta$ is estimable, i.e., $\operatorname{im}(W') \subseteq \operatorname{i
m}(X')$ (equivalently, $W = LX$ for some matrix $L$, or the rows of $W$ lie in t

**Form:** When it exists,
$$\hat{W}\beta = W(X'V^{-1}X)^{-}X'V^{-1}y,$$
where $(X'V^{-1}X)^{-}$ is any generalized inverse of $X'V^{-1}X$. The expressio

**Variance matrix:**

Setting $W = I_k$ recovers the generalized least squares (GLS) estimator $\hat{\
