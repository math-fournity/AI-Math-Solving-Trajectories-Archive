# Problem

A specialized digital archive stores data by recording every positive integer in increasing order $(1, 2, 3, \dots)$ as a continuous stream of individual decimal digits. Each digit occupies exactly one memory cell.

The Chief Data Officer uses a function, $f(n)$, to track the complexity of the archive. For any power of ten, $10^n$, the function $f(n)$ identifies how many digits are in the specific integer that contributes the $10^n$-th digit to the stream. For instance, the $100$th digit $(10^2)$ belongs to the integer $55$; since $55$ is a two-digit number, $f(2) = 2$.

Calculate the total storage complexity score $S$, defined as the sum of the results for the first three powers and the year of the archive's founding:
$S = f(1) + f(2) + f(3) + f(1987)$.
