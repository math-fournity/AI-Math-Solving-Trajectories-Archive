## Proof

**Setup.** Consider the Snake Lemma diagram in an abelian category 𝒜:
```
  M' --a--> M --b--> M'' --> 0
  |f'       |f        |f''
  v         v         v
  0 --> N' --c--> N --d--> N''
```
producing the six-term exact sequence:
```
ker f' → ker f → ker f'' --δ--> coker f' → coker f → coker f''
```

**Step 1: The canonical connecting morphism is uniquely determined.**

The standard construction: for x ∈ ker f'', lift to m ∈ M with b(m) = x (surject
ive). Then d(f(m)) = f''(x) = 0, so f(m) ∈ ker d = im c. Since c is injective (f
rom 0 → N' → N), there is a unique n' ∈ N' with c(n') = f(m). Set δ(x) = [n'] ∈
coker f'.

Well-definedness: if m' is another lift, then m − m' ∈ ker b = im a, so m − m' =
 a(m''), giving f(m) − f(m') = c(f'(m'')), hence [n'] is unchanged in coker f'.
So **δ is uniquely determined by the diagram** — no choice enters the constructi
on.

**Step 2: Characterizing all morphisms that serve as a connecting morphism.**

A morphism δ': ker f'' → coker f' yields a six-term exact sequence if and only i
f:
- ker δ' = im(ker f → ker f'') =: A
- im δ' = ker(coker f' → coker f) =: B

Any such δ' factors as ker f'' ↠ ker f''/A → B ↪ coker f', where the middle map
is an isomorphism. The set of valid connecting morphisms is thus in bijection wi
th Iso(ker f''/A, B), a torsor under Aut(ker f''/A).

**Step 3: −δ is also a valid connecting morphism.**

Since −1 is an automorphism in any abelian category: ker(−δ) = ker δ = A and im(
−δ) = im δ = B. So −δ also produces an exact six-term sequence, and −δ ≠ δ in ge
neral.

**Step 4: Functoriality constrains the choice to natural automorphisms.**

For the assignment D ↦ δ'_D to define a functor, it must be natural: for every m
orphism of diagrams, the square
```
ker f₁'' --δ₁'--> coker f₁'
   |                  |
   v                  v
ker f₂'' --δ₂'--> coker f₂'
```
must commute. The canonical δ is natural (standard Snake Lemma). Any other natur
al δ' differs from δ by a natural automorphism of the functor D ↦ ker f''/A (equ
ivalently D ↦ B). Since this functor is built from categorical constructions (ke
rnels, cokernels, images), natural automorphisms of it arise from natural automo
rphisms of the identity functor on 𝒜.

**Step 5: The natural automorphisms of Id_𝒜 in a general abelian category are ex
actly {±1}.**

The center Z(𝒜) = Nat(Id_𝒜, Id_𝒜) is a ring receiving a canonical map ℤ → Z(𝒜) s
ending n to multiplication by n. For a general (unspecified) abelian category, t
he only natural automorphisms guaranteed to exist universally are +1 and −1 (the
 units of ℤ). These correspond to δ and −δ respectively.

**Step 6: Both choices yield valid functors.**

- **Functor F₊**: uses δ. This is the standard Snake Lemma functor. Naturality h
olds by the Snake Lemma.
- **Functor F₋**: uses −δ. The six-term sequence is exact (Step 3). Naturality h
olds: if the square commutes for δ, then composing with −1 on either side preser
ves commutativity, so the square commutes for −δ.

Both functors act identically on objects (same six terms, same five non-connecti
ng maps) and identically on morphisms (same component maps), differing only in t
he connecting morphism.

**Step 7: No other functors exist in a general abelian category.**

Any functor differing only in the connecting morphism corresponds to a natural a
utomorphism α of Id_𝒜 applied to δ, giving α ∘ δ. In a general abelian category,
 the only such α are ±1, yielding exactly the two functors F₊ and F₋.

**Conclusion.** There are exactly **2** functors from the category of diagrams w
ith exact rows to the category of six-term exact sequences, acting identically o
n objects and morphisms except for the connecting morphism: one using the canoni
cal connecting morphism δ, and one using −δ.
