## 解题过程

### 设置与符号

设 $n = 11$，$Z_1, \ldots, Z_{11}$ 为 $\mathbb{R}^d$ 中独立同分布 (i.i.d.) 的 $N
(0, I_d)$ 随机向量。定义
$$\bar Z = \tfrac{1}{11}\sum_i Z_i,\quad S_{11} = \tfrac{1}{10}\sum_i (Z_i-\bar
Z)(Z_i-\bar Z)^T,\quad Y_i = S_{11}^{-1/2}(Z_i - \bar Z).$$

我们将证明 $R(11,d) = E|Y_1-Y_2|/E|Z_1-Z_2| = \frac{256}{315}\sqrt{\frac{5}{\pi}
}$，与 $d$ 无关（对于 $d < 10$）。

### 第 1 步：分母

$Z_1 - Z_2 \sim N(0, 2I_d)$，因此 $|Z_1-Z_2|^2 = 2\chi^2_d$。使用 $E\sqrt{\chi^2
_k} = \sqrt{2}\,\Gamma\!\bigl(\tfrac{k+1}{2}\bigr)/\Gamma\!\bigl(\tfrac{k}{2}\bi
gr)$：
$$E|Z_1-Z_2| = \sqrt{2}\cdot\sqrt{2}\,\frac{\Gamma((d+1)/2)}{\Gamma(d/2)} = 2\,\
frac{\Gamma((d+1)/2)}{\Gamma(d/2)}. \tag{1}$$

### 第 2 步：将分子简化为 Wishart 计算

设 $P = I_{11} - \tfrac{1}{11}\mathbf{1}\mathbf{1}^T$ 为到与 $\mathbf{1}$ 正交的
 10 维子空间上的投影。残差矩阵 $W = PZ$ 的行为 $W_i^T = (Z_i - \bar Z)^T$，且
$$S_{11} = \tfrac{1}{10}\,W^T W = \tfrac{1}{10}\,Z^T P Z.$$
由于 $Z$ 具有 i.i.d. $N(0,1)$ 元素且 $\operatorname{rank}(P)=10$，Wishart 恒等式
给出 $10\,S_{11} = Z^T P Z \sim W_d(10, I_d)$。

关键观察：$\bar Z$ 项抵消，
$$Y_1 - Y_2 = S_{11}^{-1/2}(Z_1 - Z_2), \qquad |Y_1-Y_2|^2 = (Z_1-Z_2)^T S_{11}^
{-1}(Z_1-Z_2). \tag{2}$$

### 第 3 步：选择残差空间的标准正交基

向量 $e_1 - e_2 \in \mathbb{R}^{11}$ 位于 $\operatorname{range}(P)$ 中，且 $\|e_
1-e_2\|^2 = 2$。设 $v_1 = (e_1-e_2)/\sqrt{2}$，并将其扩展为 $\operatorname{range
}(P)$ 的标准正交基 $v_1, \ldots, v_{10}$。定义 $u_j = v_j^T Z \in \mathbb{R}^d$
；则 $u_1, \ldots, u_{10}$ 为 i.i.d. $N(0, I_d)$，且
$$Z_1 - Z_2 = (e_1-e_2)^T Z = \sqrt{2}\, v_1^T Z = \sqrt{2}\, u_1, \qquad 10\,S_
{11} = \sum_{j=1}^{10} u_j u_j^T. \tag{3}$$

代入 (2)：
$$|Y_1-Y_2|^2 = 2\, u_1^T \Bigl(\tfrac{1}{10}\sum_{j=1}^{10} u_j u_j^T\Bigr)^{-1
} u_1 = 20\, u_1^T A^{-1} u_1, \quad A := \sum_{j=1}^{10} u_j u_j^T. \tag{4}$$

### 第 4 步：分离 $u_1$（Sherman–Morrison）

设 $B = \sum_{j=2}^{10} u_j u_j^T \sim W_d(9, I_d)$，与 $u_1 \sim N(0,I_d)$ 独立
，因此 $A = B + u_1 u_1^T$。Sherman–Morrison 公式给出
$$A^{-1} = B^{-1} - \frac{B^{-1}u_1 u_1^T B^{-1}}{1 + u_1^T B^{-1} u_1}.$$
设 $t = u_1^T B^{-1} u_1$，则
$$u_1^T A^{-1} u_1 = t - \frac{t^2}{1+t} = \frac{t}{1+t}.$$
因此
$$|Y_1-Y_2|^2 = 20\,\frac{t}{1+t}, \qquad t = u_1^T B^{-1} u_1. \tag{5}$$

### 第 5 步：$t$ 的分布

标准结果（当 $d=1$ 时，$t = \chi^2_1/\chi^2_m$，这是显而易见的）：如果 $u \sim N
(0,I_d)$ 与 $B \sim W_d(m, I_d)$ 狋立，且 $m \geq d$，则
$$u^T B^{-1} u \;\stackrel{d}{=}\; \frac{\chi^2_d}{\chi^2_{m-d+1}}, \qquad \text
{独立。}$$
这里 $m = 9$，因此 $t \stackrel{d}{=} \chi^2_d / \chi^2_{10-d}$，且两者独立。设
$U \sim \chi^2_d$，$V \sim \chi^2_{10-d}$ 独立。则 $t = U/V$，且
$$\frac{t}{1+t} = \frac{U/V}{1+U/V} = \frac{U}{U+V} = \frac{U}{\chi^2_{10}}, \qu
ad \text{因为 } U+V \sim \chi^2_{10}. \tag{6}$$

因此
$$|Y_1 - Y_2|^2 = 20\,\frac{\chi^2_d}{\chi^2_{10}} = 20\, B_{d/2,\,(10-d)/2}, \t
ag{7}$$
其中 $B_{\alpha,\beta} \sim \operatorname{Beta}(\alpha,\beta)$，因为 $\frac{\chi
^2_d}{\chi^2_d + \chi^2_{10-d}} \sim \operatorname{Beta}\!\bigl(\tfrac{d}{2}, \t
frac{10-d}{2}\bigr)$。

### 第 6 步：Beta 矩

对于 $B \sim \operatorname{Beta}(\alpha, \beta)$，$E[B^{1/2}] = \frac{\Gamma(\al
pha+1/2)\,\Gamma(\alpha+\beta)}{\Gamma(\alpha)\,\Gamma(\alpha+\beta+1/2)}$。取 $
\alpha = d/2$，$\beta = (10-d)/2$，$\alpha+\beta = 5$：
$$E\!\left[\sqrt{B}\right] = \frac{\Gamma\!\bigl(\tfrac{d+1}{2}\bigr)\,\Gamma(5)
}{\Gamma\!\bigl(\tfrac{d}{2}\bigr)\,\Gamma\!\bigl(\tfrac{11}{2}\bigr)} = \frac{\
Gamma\!\bigl(\tfrac{d+1}{2}\bigr)\cdot 24}{\Gamma\!\bigl(\tfrac{d}{2}\bigr)\cdot
 \tfrac{945}{32}\sqrt{\pi}} = \frac{256}{315}\cdot\frac{\Gamma\!\bigl(\tfrac{d+1
}{2}\bigr)}{\Gamma\!\bigl(\tfrac{d}{2}\bigr)\sqrt{\pi}}, \tag{8}$$
使用 $\Gamma(5) = 24$ 和 $\Gamma(11/2) = \frac{9\cdot7\cdot5\cdot3\cdot1}{2^5}\s
qrt{\pi} = \frac{945}{32}\sqrt{\pi}$，并化简 $768/945 = 256/315$。

因此
$$E|Y_1-Y_2| = \sqrt{20}\cdot E\!\left[\sqrt{B}\right] = \sqrt{20}\cdot\frac{256
}{315}\cdot\frac{\Gamma\!\bigl(\tfrac{d+1}{2}\bigr)}{\Gamma\!\bigl(\tfrac{d}{2}\
bigr)\sqrt{\pi}}. \tag{9}$$

### 第 7 步：比率

$$R(11,d) = \frac{E|Y_1-Y_2|}{E|Z_1-Z_2|} = \frac{\sqrt{20}\cdot\frac{256}{315}\
cdot\frac{\Gamma((d+1)/2)}{\Gamma(d/2)\sqrt{\pi}}}{2\cdot\frac{\Gamma((d+1)/2)}{
\Gamma(d/2)}} = \frac{\sqrt{20}}{2\sqrt{\pi}}\cdot\frac{256}{315} = \frac{\sqrt{
5}}{\sqrt{\pi}}\cdot\frac{256}{315}.$$

$$\boxed{R(11,d) = \frac{256}{315}\sqrt{\frac{5}{\pi}}.}$$

该值与 $d$ 无关（对于 $d = 1, 2, \ldots, 9$），证实了提示中给出的值。
