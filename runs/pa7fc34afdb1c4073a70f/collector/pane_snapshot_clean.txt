## Proof

Let $X_n$ denote the number of singletons (fixed points / 1-cycles) in a uniform
ly random involution of $\{1,\ldots,n\}$. An involution decomposes uniquely into
 fixed points and transpositions.

### Step 1: Bivariate EGF

With $u$ marking fixed points:
$$F(z,u) = \exp\!\left(uz + \frac{z^2}{2}\right)$$
since an involution is a SET of 1-cycles (each $uz$) and 2-cycles (each $z^2/2$)
. Setting $u=1$: $F(z,1)=\exp(z+z^2/2)$, with $I(n)=n!\,[z^n]F(z,1)$.

### Step 2: Mean

$$\mathbb{E}[X_n] = \frac{[z^{n-1}]\exp(z+z^2/2)}{[z^n]\exp(z+z^2/2)}.$$

The function $\exp(z+z^2/2)$ is Hayman-admissible. Its saddle point $r_n>0$ sati
sfies $n = r_n g'(r_n)= r_n(1+r_n)$ where $g(z)=z+z^2/2$, giving
$$r_n = \frac{-1+\sqrt{1+4n}}{2} \sim \sqrt{n}.$$

By the saddle point method, $[z^n]\exp(g(z)) \sim \frac{\exp(g(r_n))}{r_n^n\sqrt
{2\pi b(r_n)}}$ with $b(r)=r+2r^2$. The ratio of consecutive coefficients satisf
ies $[z^{n-1}]/[z^n]\sim r_n$ (the saddle points for $n$ and $n-1$ differ by $O(
1/\sqrt{n})$, and exponential/power factors cancel to leading order). Therefore:

$$\boxed{\mathbb{E}[X_n] \sim r_n \sim \sqrt{n}, \quad \text{precisely } \tfrac{
\sqrt{1+4n}-1}{2}+O(n^{-1/4}).}$$

### Step 3: Variance

$$\mathbb{E}[X_n(X_n-1)] = \frac{[z^{n-2}]\exp(z+z^2/2)}{[z^n]\exp(z+z^2/2)} \si
m r_n^2 \sim n.$$

Hence
$$\operatorname{Var}(X_n) = \mathbb{E}[X_n(X_n-1)] + \mathbb{E}[X_n] - (\mathbb{
E}[X_n])^2 \sim n + \sqrt{n} - n = \sqrt{n}.$$

Using the MGF calculation (Step 4), more precisely $\operatorname{Var}(X_n) = \f
rac{2r_n^2}{1+2r_n}+O(n^{-1/4}) = \frac{(\sqrt{1+4n}-1)^2}{2\sqrt{1+4n}}+O(n^{-1
/4}) \sim \sqrt{n}$. The **standard deviation** is:

$$\boxed{\sigma_n \sim n^{1/4}.}$$

### Step 4: Limit Law (Gaussian)

The MGF is $M_n(t) = \frac{[z^n]\exp(e^t z + z^2/2)}{[z^n]\exp(z+z^2/2)}$. For e
ach $t$ near $0$, the numerator has saddle point $r(t)$ satisfying $r(t)(e^t+r(t
))=n$. Saddle point asymptotics give:

$$\log M_n(t) = \psi(t)-\psi(0) - \tfrac{1}{2}\log\frac{b(t)}{b(0)} + O(n^{-1/2}
),$$

where $\psi(t) = e^t r(t) + r(t)^2/2 - n\log r(t)$ and $b(t)=n+r(t)^2$.

Using the saddle point equation $r(e^t+r)=n$ (so $e^t+r=n/r$):

- $\psi'(t) = e^t r(t)$, so $\psi'(0)=r_n = \mu_n + O(n^{-1/4})$.
- $\psi''(t) = e^t(r+r') = \frac{2r^2 e^t}{e^t+2r}$, so $\psi''(0)=\frac{2r_n^2}
{1+2r_n} = \sigma_n^2 + O(n^{-1/4})$.
- For $k\ge 3$: since $r'(0) = -r_n/(1+2r_n) = O(1)$ and all higher derivatives
$r^{(j)}(0)=O(1)$ (bounded as $n\to\infty$), we get $\psi^{(k)}(0) = O(r_n) = O(
\sqrt{n})$.

The correction $-\frac{1}{2}\log(b(t)/b(0))$ has derivatives $O(1/n)$, negligibl
e.

Set $s=t/\sigma_n$. The cumulant generating function of the normalized variable:

$$K_n(s) = \log\mathbb{E}\!\left[e^{s(X_n-\mu_n)/\sigma_n}\right] = \frac{\psi''
(0)}{2\sigma_n^2}s^2 + \sum_{k\ge 3}\frac{\psi^{(k)}(0)}{k!\,\sigma_n^k}s^k + O(
n^{-1/2}).$$

Since $\psi''(0)/\sigma_n^2 \to 1$ and for each $k\ge 3$:
$$\frac{\psi^{(k)}(0)}{\sigma_n^k} = \frac{O(\sqrt{n})}{n^{k/4}} = O\!\left(n^{(
2-k)/4}\right) \to 0,$$

we obtain $K_n(s) \to s^2/2$ pointwise. By Lévy's continuity theorem:

$$\boxed{\frac{X_n - \sqrt{n}}{n^{1/4}} \xrightarrow{d} N(0,1).}$$

### Conclusion

The number of singletons $X_n$ in a random involution of size $n$ has:

| Quantity | Asymptotic |
|---|---|
| **Mean** | $\mathbb{E}[X_n] \sim \sqrt{n}$ (precisely $\frac{\sqrt{1+4n}-1}{2}

| **Standard deviation** | $\sigma_n \sim n^{1/4}$ (precisely $\sqrt{\frac{(\sqr
t{1+4n}-1)^2}{2\sqrt{1+4n}}}$) |
| **Limit law** | $\dfrac{X_n - \sqrt{n}}{n^{1/4}} \xrightarrow{d} N(0,1)$ |
