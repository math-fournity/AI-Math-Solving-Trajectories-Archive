**Answer: Yes, $u$ vanishes on $\partial\Omega$.**

**Proof.**

Since $\Omega \subset \mathbb{R}^n$ is bounded with $C^\infty$ boundary, the **t
race theorem** applies: there exists a bounded linear operator (the trace)
$$\gamma : W^{1,2}(\Omega) \to L^2(\partial\Omega)$$
such that $\gamma(v) = v|_{\partial\Omega}$ for every $v \in C^\infty(\bar\Omega
)$, where the restriction is understood pointwise with respect to the $(n-1)$-di
mensional surface measure on $\partial\Omega$.

By definition of $W^{1,2}_0(\Omega)$, there exists a sequence $\{u_k\}_{k=1}^\in
fty \subset C_c^\infty(\Omega)$ such that
$$u_k \to u \quad \text{in } W^{1,2}(\Omega).$$

Each $u_k$ is smooth and compactly supported in $\Omega$, so $\operatorname{supp
} u_k \subset \subset \Omega$ and consequently $u_k \equiv 0$ on a neighborhood
of $\partial\Omega$. In particular,
$$\gamma(u_k) = u_k|_{\partial\Omega} = 0 \quad \text{in } L^2(\partial\Omega),
\qquad \forall\, k.$$

By the boundedness (continuity) of $\gamma$,
$$\gamma(u_k) \to \gamma(u) \quad \text{in } L^2(\partial\Omega).$$
Since every $\gamma(u_k) = 0$, it follows that
$$\gamma(u) = 0 \quad \text{in } L^2(\partial\Omega),$$
i.e., $u = 0$ almost everywhere on $\partial\Omega$ (with respect to surface mea
sure).

Now we use the additional hypothesis $u \in C(\bar\Omega)$. For continuous funct
ions, the abstract trace $\gamma(u)$ coincides with the **pointwise** restrictio
n $u|_{\partial\Omega}$, which is a continuous function on the compact set $\par
tial\Omega$. A continuous function that vanishes almost everywhere (with respect
 to a measure whose support is all of $\partial\Omega$, namely surface measure o
n a smooth hypersurface) must vanish **everywhere**. Indeed, if $u(x_0) \neq 0$
at some $x_0 \in \partial\Omega$, continuity gives a neighborhood $U \subset \pa
rtial\Omega$ of $x_0$ on which $|u| > |u(x_0)|/2 > 0$, and $\sigma_{n-1}(U) > 0$
 for a smooth hypersurface, contradicting $u = 0$ a.e.

Therefore
$$u|_{\partial\Omega} \equiv 0,$$
i.e., $u$ vanishes on $\partial\Omega$. $\blacksquare$
