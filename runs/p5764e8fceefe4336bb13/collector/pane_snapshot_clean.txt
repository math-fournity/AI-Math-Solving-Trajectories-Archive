## 解答

设：
- $S$ = 每英亩初始污泥量
- $r$ = 每英亩每周渗入污泥量
- $F$ = 每台过滤装置每周处理污泥量

**情况 1**：3 台装置，2 英亩，2 周完成。

总污泥量 = 初始 + 渗入 = $2S + (2\text{ acres})(r)(2\text{ weeks}) = 2S + 4r$

总处理能力 = $3F \cdot 2 = 6F$

$$6F = 2S + 4r \quad\Longrightarrow\quad 3F = S + 2r \tag{1}$$

**情况 2**：2 台装置，2 英亩，4 周完成。

总污泥量 = $2S + (2)(r)(4) = 2S + 8r$

总处理能力 = $2F \cdot 4 = 8F$

$$8F = 2S + 8r \quad\Longrightarrow\quad 4F = S + 4r \tag{2}$$

**求解方程组**：

由 (2) − (1)：

$$F = 2r \quad\Longrightarrow\quad r = \tfrac{F}{2}$$

代入 (1)：

$$3F = S + 2\!\left(\tfrac{F}{2}\right) = S + F \quad\Longrightarrow\quad S = 2F
$$

**情况 3**：6 英亩，6 周，$n$ 台装置完成。

总污泥量 = $6S + (6)(r)(6) = 6S + 36r$

总处理能力 = $nF \cdot 6 = 6nF$

$$6nF = 6S + 36r \quad\Longrightarrow\quad nF = S + 6r$$

代入 $S = 2F$ 与 $r = \tfrac{F}{2}$：

$$nF = 2F + 6\!\left(\tfrac{F}{2}\right) = 2F + 3F = 5F$$

$$n = 5$$

**验证**：
- 情况 1：$6F = 2(2F) + 4(\tfrac{F}{2}) = 4F + 2F = 6F$ ✓
- 情况 2：$8F = 2(2F) + 8(\tfrac{F}{2}) = 4F + 4F = 8F$ ✓
- 情况 3：$6 \cdot 5 \cdot F = 30F$；$6(2F) + 36(\tfrac{F}{2}) = 12F + 18F = 30F
$ ✓

区域主管必须指派 **5 台过滤装置**，才能在恰好六周内清理完这座六英亩的水库。
