## Solution

The letters are **S, I, T**. Among these, the consonants are **S, T** (2 choices
) and the vowel is **I** (1 choice).

We count five-letter sequences over {S, I, T} that contain **no three consecutiv
e consonants**.

### Recurrence by trailing consonant run

Define states by the length of the trailing run of consonants at the end of the
word:

- $f_n(0)$: valid $n$-letter words ending in a vowel (trailing consonant run = 0
)
- $f_n(1)$: ending in exactly 1 consonant
- $f_n(2)$: ending in exactly 2 consonants

Transitions when appending one letter:

- **Append vowel (I, 1 way):** any state → state 0
- **Append consonant (S or T, 2 ways):** state 0 → state 1, state 1 → state 2, s
tate 2 → **forbidden** (would create 3 consecutive consonants)

So:
$$f_{n+1}(0) = f_n(0)+f_n(1)+f_n(2),\quad f_{n+1}(1)=2f_n(0),\quad f_{n+1}(2)=2f
_n(1)$$

with $f_0(0)=1,\; f_0(1)=f_0(2)=0$.

### Computing up to $n=5$

| $n$ | $f_n(0)$ | $f_n(1)$ | $f_n(2)$ | Total |
|-----|----------|----------|----------|-------|
| 0 | 1 | 0 | 0 | 1 |
| 1 | 1 | 2 | 0 | 3 |
| 2 | 3 | 2 | 4 | 9 |
| 3 | 9 | 6 | 4 | 19 |
| 4 | 19 | 18 | 12 | 49 |
| 5 | 49 | 38 | 36 | **123** |

### Verification by inclusion–exclusion ($n=5$)

Total unrestricted words $= 3^5 = 243$. Let $A_i$ = the event that positions $i,
i{+}1,i{+}2$ are all consonants ($i=1,2,3$).

- $|A_i| = 2^3\cdot 3^2 = 72$ for each $i$
- $|A_1\cap A_2| = 2^4\cdot 3 = 48$ (positions 1–4 consonants)
- $|A_2\cap A_3| = 3\cdot 2^4 = 48$ (positions 2–5 consonants)
- $|A_1\cap A_3| = 2^5 = 32$ (positions 1,2,3 and 3,4,5 consonants ⇒ all five co
nsonants)
- $|A_1\cap A_2\cap A_3| = 2^5 = 32$

$$|A_1\cup A_2\cup A_3| = 3\cdot 72 - (48+48+32) + 32 = 216 - 128 + 32 = 120$$

Valid words $= 243 - 120 = \mathbf{123}$, matching the recurrence. ✓

(Cross-checks: $n=3$ gives $27 - 8 = 19$ ✓; $n=4$ gives $81 - 32 = 49$ ✓.)

### Answer

$$\boxed{123}$$
