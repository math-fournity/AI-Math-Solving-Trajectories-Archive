Looking at this problem, I need to find YZ² where Y, Z are on the circumcircle Ω
, with XY, XZ tangent to the incircle ω, and X is the tangency point of the A-mi
xtilinear incircle Γ with Ω.

## Setup

**Triangle ABC**: sides a = BC = 5, b = CA = 6, c = AB = 4, semiperimeter s = 15
/2.

**Area** (Heron): Δ = √(s(s−a)(s−b)(s−c)) = √(7.5·2.5·1.5·3.5) = √(3²·5⁶·7/10⁴)
= 15√7/4.

**Circumradius**: R = abc/(4Δ) = 120/(15√7) = 8/√7, so R² = 64/7.

**Inradius**: r = Δ/s = (√7/2), so r² = 7/4.

**Angle A**: cos A = (b²+c²−a²)/(2bc) = 27/48 = 9/16. So:
- sin(A/2) = √(7/32) = √14/8
- cos(A/2) = √(25/32) = 5√2/8

## Coordinate System

Place A at the origin with the angle bisector of A along the x-axis. Then:
- B = (4cos(A/2), −4sin(A/2)) = (5√2/2, −√14/2)
- C = (6cos(A/2), 6sin(A/2)) = (15√2/4, 3√14/4)

**Circumcenter** O = (R cos θ, R sin θ). Solving |O−B|² = |O−C|² = R² yields:
- cos θ = √14/4, sin θ = √2/4
- O = (2√2, 2√14/7)

**Incenter** I = (2√2, 0) (on the bisector at distance r/sin(A/2) = 2√2 from A).

## A-Mixtilinear Incircle Γ

Center P = (d, 0) on the bisector, radius ρ = d·sin(A/2). Internal tangency with
 Ω requires |P−O| = R − ρ, which gives:

d·cos²(A/2) = 2R(cos θ − sin(A/2))

Computing: cos θ − sin(A/2) = √14/4 − √14/8 = √14/8, so:
- d = 2·(8/√7)·(√14/8)/(25/32) = 64√2/25
- ρ = d·sin(A/2) = (64√2/25)(√14/8) = **16√7/25**

Verification: |P−O|² = (14√2/25)² + (2√14/7)² = 392/625 + 8/7 = 54208/30625, and
 (R−ρ)² = (88√7/175)² = 54208/30625. ✓

## Tangency Point X

X lies on ray O→P at distance R from O: X = O + (R/(R−ρ))(P−O) = (25P − 14O)/11.

- 25P = (64√2, 0), 14O = (28√2, 4√14)
- **X = (36√2/11, −4√14/11)**

Verification: |X−O|² = (14√2/11)² + (50√14/77)² = 54208/5929 = 64/7 = R². ✓

## Tangent Lines from X to Incircle ω

Compute |XI|²:
- X − I = (14√2/11, −4√14/11)
- |XI|² = (392 + 224)/121 = **616/121**

The half-angle α between the two tangent lines from X to ω satisfies:
- sin α = r/|XI| = (√7/2)/√(616/121) = 11√7/(4√154) = √22/8
- sin²α = 22/64 = 11/32, cos²α = 42/64 = 21/32

(Tangent length² = |XI|² − r² = 616/121 − 7/4 = 1617/484 = 147/44 > 0, confirmin
g X is outside ω. ✓)

## Computing YZ²

The angle ∠YXZ = 2α (angle between the two tangent rays from X to ω, along which
 Y and Z lie).

By the **inscribed angle theorem**, ∠YXZ = 2α subtends arc YZ (not containing X)
, giving central angle 4α. Since 4α ≈ 143.6° < 180°, this is the minor arc, and:

$$YZ = 2R\sin(2\alpha)$$

$$YZ^2 = 4R^2 \sin^2(2\alpha) = 4R^2 \cdot 4\sin^2\alpha\cos^2\alpha = 16R^2 \si
n^2\alpha\cos^2\alpha$$

Substituting:
$$YZ^2 = 16 \cdot \frac{64}{7} \cdot \frac{11}{32} \cdot \frac{21}{32} = \frac{1
024}{7} \cdot \frac{231}{1024} = \frac{231}{7} = \boxed{33}$$

**Numerical check**: R ≈ 3.024, 2α ≈ 71.8°, sin(2α) ≈ 0.950, YZ ≈ 5.744, YZ² ≈ 3
2.99 ≈ 33. ✓
