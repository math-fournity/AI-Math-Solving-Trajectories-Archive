## Proof

**Definition.** A set $S \subset \mathbb{R}^k$ has *(Jordan) content zero* if fo
r every $\varepsilon > 0$ there exist finitely many closed rectangles $R_1,\dots
,R_N$ with $S \subseteq \bigcup_{i=1}^N R_i$ and $\sum_{i=1}^N \operatorname{vol
}(R_i) < \varepsilon$.

**Key facts.**
1. Any set with content zero is **bounded** (it is covered by finitely many boun
ded rectangles).
2. If $S$ has content zero, then $\overline{S}$ has content zero. *(Proof: cover
 $S$ by rectangles $R_i$ of total volume $<\varepsilon/2$; enlarge each to an op
en rectangle $R_i'$ with $\operatorname{vol}(R_i') < \operatorname{vol}(R_i)+\va
repsilon/(2N)$. Then $\bigcup R_i'$ is open, contains $S$, hence contains $\over
line{S}$, with total volume $<\varepsilon$.)*
3. By contrapositive of (2): if $\overline{S}$ does **not** have content zero, t
hen $S$ does not have content zero.

---

### Part I — Trivial answer for $\mathbb{R}^n$

For **any** function $f:\mathbb{R}^n\to\mathbb{R}$, the graph $\Gamma(f)=\{(x,f(
x)):x\in\mathbb{R}^n\}\subset\mathbb{R}^{n+1}$ is **unbounded**, since its proje
ction onto the first $n$ coordinates is all of $\mathbb{R}^n$. By Fact 1, an unb
ounded set cannot have content zero. Hence **every** function on $\mathbb{R}^n$
has a graph that does not have content zero.

This answer, while correct, is trivial. The real content of the question is whet
her the phenomenon persists even on **bounded** domains—where unboundedness cann
ot be exploited. We show it does.

---

### Part II — Non-trivial construction on a bounded domain

We construct a function $f:[0,1]\to[0,1]$ whose graph does **not** have content
zero. Extending it by zero outside $[0,1]$ yields a function on $\mathbb{R}$ (he
nce on $\mathbb{R}^n$ by ignoring extra coordinates) with the same property.

**Construction (dense graph).** Let $\{q_k\}_{k=1}^{\infty}$ be an enumeration o
f $\mathbb{Q}\cap[0,1]$. We choose values $r_k\in[0,1]$ so that the set $\{(q_k,
r_k):k\ge 1\}$ is **dense** in $[0,1]^2$.

This is possible: enumerate all open rectangles of the form $(a,b)\times(c,d)\su
bset[0,1]^2$ with rational endpoints as $B_1,B_2,\dots$. For each $j\ge 1$, pick
 an index $k_j$ (distinct from all previously chosen) with $q_{k_j}\in(a_j,b_j)$
 (possible since $\mathbb{Q}\cap(a_j,b_j)\ne\emptyset$) and set $r_{k_j}$ to any
 rational in $(c_j,d_j)$. For all remaining indices set $r_k=0$. Then $\{(q_k,r_
k)\}$ meets every basic open rectangle, hence is dense in $[0,1]^2$.

Define $f:[0,1]\to[0,1]$ by
$$
f(q_k)=r_k,\qquad f(x)=0\ \text{for }x\in[0,1]\setminus\mathbb{Q}.
$$

**The graph is dense in $[0,1]^2$.** Since $\{(q_k,r_k)\}\subseteq\Gamma(f)$ and
 $\{(q_k,r_k)\}$ is dense in $[0,1]^2$, we have $\overline{\Gamma(f)}\supseteq[0
,1]^2$. As $\Gamma(f)\subseteq[0,1]^2$, we get $\overline{\Gamma(f)}=[0,1]^2$.

**The graph does not have content zero.** The set $[0,1]^2$ has Jordan content $
1>0$, so $\overline{\Gamma(f)}=[0,1]^2$ does **not** have content zero. By Fact
3 (contrapositive), $\Gamma(f)$ does not have content zero.

---

### Part III — Extension to $\mathbb{R}^n$

Define $F:\mathbb{R}^n\to\mathbb{R}$ by $F(x_1,\dots,x_n)=f(x_1)$ where $f$ is t
he function constructed above (with $f(x)=0$ for $x\notin[0,1]$). Then
$$
\Gamma(F)\supseteq\Gamma(f)\times\{0\}^{n-1}\cap\bigl([0,1]\times\{0\}^{n-1}\tim
es\mathbb{R}\bigr),
$$
and in particular the slice of $\Gamma(F)$ over $\{(x_1,0,\dots,0):x_1\in[0,1]\}
$ contains a copy of $\Gamma(f)$. Since $\overline{\Gamma(f)}=[0,1]^2$ has posit
ive content, the closure of $\Gamma(F)$ has positive $(n+1)$-dimensional content
, so $\Gamma(F)$ does not have content zero.

---

### Conclusion

**Yes**, such a function exists. In fact:

- **Trivially**, every function $f:\mathbb{R}^n\to\mathbb{R}$ has a graph withou
t content zero, because the graph is unbounded and content-zero sets must be bou
nded.
- **Substantively**, even on a bounded domain, there exist functions whose graph
s do not have content zero: a function $f:[0,1]\to[0,1]$ with a graph dense in $
[0,1]^2$ has $\overline{\Gamma(f)}=[0,1]^2$ of content $1$, so $\Gamma(f)$ does
not have content zero. This contrasts sharply with continuous functions (whose g
raphs on compact domains always have content zero) and shows that content zero o
f the graph is **not** automatic for arbitrary functions.
