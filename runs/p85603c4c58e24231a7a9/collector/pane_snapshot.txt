## Proof

Let $\chi$ denote the Legendre symbol modulo $p$, extended by $\chi(0)=0$. Defin
e the indicator that $z \in \mathbb{Z}_p$ is a square (including $0$, since $0 =
 0^2$):

$$I(z) = \frac{1 + \chi(z) + \delta(z)}{2}, \qquad \delta(z) = \begin{cases}1 &
z=0\\0 & z\neq 0.\end{cases}$$

**Verification of $I$:** For $z\neq 0$ a nonzero square, $\chi(z)=1$, $\delta(z)
=0$, so $I=(1+1)/2=1$. For $z\neq 0$ a nonresidue, $\chi(z)=-1$, so $I=0$. For $
z=0$, $\chi(0)=0$, $\delta(0)=1$, so $I=(1+0+1)/2=1$. ✓

The desired count is
$$N = \sum_{z\in\mathbb{Z}_p} I(z)\,I(z-1).$$

Expanding:
$$N = \frac{1}{4}\sum_{z}\Big(1+\chi(z)+\delta(z)\Big)\Big(1+\chi(z-1)+\delta(z-
1)\Big).$$

We evaluate each resulting sum over $z\in\mathbb{Z}_p$:

| Sum | Value | Reason |
|-----|-------|--------|
| $\sum 1$ | $p$ | trivial |
| $\sum \chi(z)$ | $0$ | balanced character |
| $\sum \delta(z)$ | $1$ | only $z=0$ |
| $\sum \chi(z-1)$ | $0$ | balanced (shift) |
| $\sum \chi(z)\chi(z-1)$ | $-1$ | classical Jacobi sum $\sum_z \chi(z)\chi(1-z)
=-1$ |
| $\sum \delta(z)\chi(z-1)$ | $\chi(-1)$ | only $z=0$ contributes $\chi(-1)$ |
| $\sum \delta(z-1)$ | $1$ | only $z=1$ |
| $\sum \chi(z)\delta(z-1)$ | $\chi(1)=1$ | only $z=1$ |
| $\sum \delta(z)\delta(z-1)$ | $0$ | $z$ cannot be both $0$ and $1$ |

(For the Jacobi sum: $\sum_{z}\chi(z)\chi(z-1)=\sum_{z}\chi(z)\chi(-(1-z))=\chi(

1$.)

Let me recompute the Jacobi sum directly. Set $z\neq 0,1$ (boundary terms vanish

$$\sum_{z\in\mathbb{F}_p}\chi(z)\chi(1-z) = -1.$$

Now $\chi(z-1) = \chi(-(1-z)) = \chi(-1)\chi(1-z)$, so
$$\sum_z \chi(z)\chi(z-1) = \chi(-1)\sum_z\chi(z)\chi(1-z) = \chi(-1)\cdot(-1) =
 -\chi(-1).$$

Redoing the table with this correction (sum 5 = $-\chi(-1)$):

$$\text{Total} = p + 0 + 1 + 0 + (-\chi(-1)) + \chi(-1) + 1 + 1 + 0 = p + 3.$$

The $-\chi(-1)$ and $+\chi(-1)$ cancel. Therefore
$$\boxed{N = \frac{p+3}{4}}.$$

## Answer

}$ is

$$\boxed{\dfrac{p+2+\left(\dfrac{-1}{p}\right)}{4}}$$

where $\left(\dfrac{-1}{p}\right)=(-1)^{(p-1)/2}$ is the Legendre symbol of $-1$
. Equivalently,

$$N=\begin{cases}\dfrac{p+3}{4}, & p\equiv 1\pmod 4,\\[6pt]\dfrac{p+1}{4}, & p\e
quiv 3\pmod 4.\end{cases}$$
