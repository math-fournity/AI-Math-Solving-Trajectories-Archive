## Solution

Let $F$ be a finite field with $n$ elements, $n$ odd (so $\operatorname{char} F
\neq 2$, and $2, 4$ are invertible in $F$).

**Discriminant criterion.** For a monic quadratic $x^2 + bx + e$ over $F$, the d
iscriminant is $\Delta = b^2 - 4e$. Since $n$ is odd, $x^2+bx+e$ is irreducible
over $F$ if and only if $\Delta$ is a **nonzero non-square** in $F$:
- $\Delta$ a nonzero square $\Rightarrow$ two distinct roots $\Rightarrow$ reduc
ible.
- $\Delta = 0 \Rightarrow$ a repeated root $\Rightarrow$ reducible.
- $\Delta$ a nonzero non-square $\Rightarrow$ no roots in $F \Rightarrow$ irredu
cible.

**Setup.** We are given that $x^2 + bx + c$ is irreducible, so
$$\Delta_0 := b^2 - 4c \quad\text{is a nonzero non-square in } F.$$

For a general $d \in F$, the polynomial $x^2 + bx + (c+d)$ has discriminant
$$\Delta(d) = b^2 - 4(c+d) = \Delta_0 - 4d.$$

**Counting.** Since $n$ is odd, $4 \neq 0$ in $F$, so the map
$$d \longmapsto \Delta_0 - 4d$$
is a bijection $F \to F$. Thus as $d$ ranges over all $n$ elements of $F$, the v
alue $\Delta(d)$ ranges over all $n$ elements of $F$ exactly once.

We need $\Delta(d)$ to be a **nonzero non-square**. The multiplicative group $F^
\times$ is cyclic of order $n-1$; exactly half of its elements are squares and h
alf are non-squares. Hence the number of nonzero non-squares in $F$ is
$$\frac{n-1}{2}.$$

Since $d \mapsto \Delta(d)$ is a bijection, the number of $d \in F$ for which $\
Delta(d)$ is a nonzero non-square equals the number of nonzero non-squares, name
ly $\dfrac{n-1}{2}$.

**Answer.** The number of elements $d \in F$ for which $x^2 + bx + c + d$ is irr
educible is

$$\boxed{\dfrac{n-1}{2}}.$$
