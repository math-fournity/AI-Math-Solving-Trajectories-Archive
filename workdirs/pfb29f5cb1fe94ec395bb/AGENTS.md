# Problem

A specialized microchip architecture consists of a triangular processing field. This field is composed of small, unit-sized triangular cells arranged in a large equilateral triangle with a side length of 5 units. The grid lines within this large triangle define several "upward-oriented" equilateral triangles of various integer side lengths (1, 2, 3, 4, and 5). An upward-oriented triangle is one whose base is parallel to the bottom edge of the field and whose apex points toward the top of the field.

A system architect must select two distinct upward-oriented triangles from the set of all possible upward-oriented triangles contained within the grid. If every possible pair of distinct upward-oriented triangles has an equal probability of being chosen, the probability that the two selected triangles share exactly one vertex can be expressed as a fraction $m/n$ in lowest terms. Find the value of $m+n$.
