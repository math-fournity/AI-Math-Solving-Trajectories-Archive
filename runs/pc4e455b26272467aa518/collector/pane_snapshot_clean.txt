## Solution

**Claim:** Yes, $U_n^2$ is also an approximate unit for $A$.

**Proof.**

Recall that a net $(U_n)$ is an approximate unit for a $C^*$-algebra $A$ if $\|U
_n a - a\| \to 0$ and $\|a U_n - a\| \to 0$ for every $a \in A$.

**Step 1: $(U_n)$ is automatically bounded.**

For each $n$, define the left-multiplication operator $L_n : A \to A$ by $L_n(a)
 = U_n a$. This is a bounded linear operator on the Banach space $A$, and in a $
C^*$-algebra $\|L_n\| = \|U_n\|$ (the inequality $\|L_n\| \le \|U_n\|$ is immedi
ate from submultiplicativity; equality holds since $\|U_n\|^2 = \|U_n^* U_n\| =
\|L_{U_n^*}(U_n)\| \le \|L_{U_n^*}\|\|U_n\|$, and one checks $\|L_n\| = \|U_n\|$
).

Since $U_n a \to a$ for each fixed $a$, the set $\{L_n(a) : n\} = \{U_n a : n\}$
 is convergent, hence bounded, for each $a$. By the **Uniform Boundedness Princi
ple**,
$$M := \sup_n \|L_n\| = \sup_n \|U_n\| < \infty.$$

So every approximate unit for a $C^*$-algebra is norm-bounded — no boundedness h
ypothesis is needed.

**Step 2: $U_n^2 a \to a$ and $a U_n^2 \to a$.**

For any $a \in A$, write
$$U_n^2 a - a = U_n(U_n a - a) + (U_n a - a).$$

Taking norms and using $\|U_n\| \le M$:
$$\|U_n^2 a - a\| \le \|U_n\|\,\|U_n a - a\| + \|U_n a - a\| \le (M+1)\,\|U_n a
- a\| \;\longrightarrow\; 0.$$

Similarly, writing
$$a U_n^2 - a = (a U_n - a)\,U_n + (a U_n - a),$$
we get
$$\|a U_n^2 - a\| \le \|a U_n - a\|\,\|U_n\| + \|a U_n - a\| \le (M+1)\,\|a U_n
- a\| \;\longrightarrow\; 0.$$

**Step 3 (standard definition).** If one uses the common definition requiring $0
 \le U_n \le 1$ (so $M = 1$), then $U_n^2$ is positive (square of a positive ele
ment) and $\|U_n^2\| = \|U_n\|^2 \le 1$, so all defining conditions of an approx
imate unit are satisfied.

**Conclusion.** In either formulation — the convergence-only definition (where b
oundedness is automatic by the Uniform Boundedness Principle) or the standard co
ntractive-positive definition — the net $(U_n^2)$ satisfies $U_n^2 a \to a$ and
$a U_n^2 \to a$ for every $a \in A$, with the appropriate positivity/norm condit
ions. Hence **$U_n^2$ is an approximate unit for $A$**.
