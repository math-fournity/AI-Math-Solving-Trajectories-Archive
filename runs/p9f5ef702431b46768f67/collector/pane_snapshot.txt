$$L = \lim_{n\to\infty} n\,p^n \sum_{k=n}^{\infty} \frac{1}{k}\binom{k-1}{n-1}(1

**Step 1: Convert the sum to an integral.**

Let $q = 1-p$ and $r = q/p = (1-p)/p > 0$. Using the negative binomial identity
$\sum_{k=n}^{\infty}\binom{k-1}{n-1}x^{k-n} = (1-x)^{-n}$, multiply by $x^{n-1}$
 and integrate from $0$ to $q$:

$$\sum_{k=n}^{\infty}\binom{k-1}{n-1}\frac{q^k}{k} = \int_0^q \frac{x^{n-1}}{(1-
x)^n}\,dx.$$

Substituting $u = x/(1-x)$ (so $x=u/(1+u)$, $1-x=1/(1+u)$, $dx=du/(1+u)^2$), the
 integrand becomes $u^{n-1}(1+u)\cdot(1+u)^{-2}=u^{n-1}/(1+u)$, with upper limit
 $u=q/p=r$:

$$\sum_{k=n}^{\infty}\binom{k-1}{n-1}\frac{q^k}{k} = \int_0^r \frac{u^{n-1}}{1+u
}\,du.$$

Since $S_n = \sum_{k=n}^{\infty}\frac{1}{k}\binom{k-1}{n-1}q^{k-n} = q^{-n}\int_
0^r \frac{u^{n-1}}{1+u}\,du$, we get

$$n\,p^n S_n = n\left(\frac{p}{q}\right)^n\!\int_0^r \frac{u^{n-1}}{1+u}\,du = \
frac{n}{r^n}\int_0^r \frac{u^{n-1}}{1+u}\,du.$$

Substituting $u = rt$:

$$\boxed{L_n := n\,p^n S_n = n\int_0^1 \frac{t^{n-1}}{1+rt}\,dt.}$$

**Step 2: Evaluate the limit via an approximate-identity argument.**

Set $g(t) = \frac{1}{1+rt}$, which is continuous on $[0,1]$ with $g(1)=\frac{1}{
1+r}=p$.

**Claim:** For any continuous $g$ on $[0,1]$, $\;n\int_0^1 t^{n-1}g(t)\,dt \to g
(1)$.

*Proof of claim.* Write $n\int_0^1 t^{n-1}g(t)\,dt - g(1) = n\int_0^1 t^{n-1}(g(
t)-g(1))\,dt$. Given $\varepsilon>0$, pick $\delta>0$ so $|g(t)-g(1)|<\varepsilo
n$ on $[1-\delta,1]$. Split the integral at $1-\delta$:

- Near 1: $\left|n\int_{1-\delta}^1 t^{n-1}(g(t)-g(1))\,dt\right| \le \varepsilo
n\cdot n\int_{1-\delta}^1 t^{n-1}dt = \varepsilon\bigl(1-(1-\delta)^n\bigr) \le
\varepsilon.$
- Away from 1: $\left|n\int_0^{1-\delta} t^{n-1}(g(t)-g(1))\,dt\right| \le M\cdo
t(1-\delta)^n \to 0$, where $M=\sup_{[0,1]}|g-g(1)|$.

So $\limsup|L_n - g(1)|\le\varepsilon$ for every $\varepsilon>0$, proving the cl
aim. $\square$

**Step 3: Conclude.**

Applying the claim with $g(t)=\frac{1}{1+rt}$:

$$L = \lim_{n\to\infty} L_n = g(1) = \frac{1}{1+r} = \frac{1}{1+\frac{1-p}{p}} =
 \frac{1}{\frac{1}{p}} = p.$$

$$\boxed{L = p.}$$
