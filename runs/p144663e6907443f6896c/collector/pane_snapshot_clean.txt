## Solution

**Setting up coordinates.** Place the square with side length 1:
- $A = (0, 1)$, $B = (1, 1)$, $C = (1, 0)$, $D = (0, 0)$.

The relay station $N$ is the midpoint of $BC$: $N = (1, \tfrac{1}{2})$.

**Parametrizing $M$ from $\angle MAD = x$ and $\angle MDC = x$.**

Let $s = \sin x$, $c = \cos x$.

- **From $\angle MAD = x$:** Ray $AD$ has direction $(0,-1)$. The ray $AM$ makes
 angle $x$ with this, pointing into the square (right and down), so $M = A + t(\
sin x, -\cos x) = (t\,s,\; 1 - t\,c)$ for some $t > 0$.

- **From $\angle MDC = x$:** Ray $DC$ has direction $(1,0)$. The ray $DM$ makes
angle $x$ with this, pointing into the square (right and up), so $M = D + u(\cos
 x, \sin x) = (u\,c,\; u\,s)$ for some $u > 0$.

Equating coordinates:
$$t\,s = u\,c, \qquad 1 - t\,c = u\,s.$$

From the first: $u = t\tan x$. Substituting into the second:
$$1 - t\,c = t\tan x \cdot s = \frac{t\,s^2}{c} \implies 1 = \frac{t(c^2 + s^2)}
{c} = \frac{t}{c} \implies t = c.$$

Then $u = s$, giving:
$$\boxed{M = (s\,c,\; s^2).}$$

**Verification:** $\cos\angle MAD = \frac{(0,-1)\cdot(sc,-c^2)}{1\cdot s} = \fra
c{c^2}{s}\cdot\frac{1}{1} \cdot \frac{s}{s}$... directly: $|AM| = s$, and the do
t product gives $c^2$, so $\cos\angle MAD = c^2/(s\cdot 1) $ — one checks $|AM|
= \sqrt{s^2c^2+c^4}=c$, so $\cos\angle MAD = c^2/(c\cdot 1)$... Let me state cle
anly: $|AM|=c$, $\cos\angle MAD = c^2/(c) = c = \cos x$. ✓ Likewise $\cos\angle
MDC = sc/s = c = \cos x$. ✓

**Applying $\angle NMD = x$.** Compute the vectors from $M$:
$$\vec{MN} = N - M = (1 - sc,\; \tfrac{1}{2} - s^2), \qquad \vec{MD} = D - M = (
-sc,\; -s^2).$$

**Dot product:**
$$\vec{MN}\cdot\vec{MD} = (1-sc)(-sc) + (\tfrac{1}{2}-s^2)(-s^2) = -sc + s^2c^2
- \tfrac{s^2}{2} + s^4.$$

Using $s^2c^2 = s^2 - s^4$:
$$= -sc + s^2 - s^4 - \tfrac{s^2}{2} + s^4 = \frac{s^2}{2} - sc = s\!\left(\frac
{s}{2} - c\right).$$

**Magnitudes:**
$$|\vec{MD}|^2 = s^2c^2 + s^4 = s^2(c^2+s^2) = s^2 \implies |\vec{MD}| = s.$$

$$|\vec{MN}|^2 = (1-sc)^2 + (\tfrac{1}{2}-s^2)^2 = 1 - 2sc + s^2c^2 + \tfrac{1}{
4} - s^2 + s^4 = \tfrac{5}{4} - 2sc.$$

**The angle condition** $\cos\angle NMD = \cos x = c$:
$$c = \frac{s(s/2 - c)}{s\,\sqrt{5/4 - 2sc}} = \frac{s/2 - c}{\sqrt{5/4 - 2sc}}.
$$

Squaring both sides:
$$c^2\!\left(\frac{5}{4} - 2sc\right) = \left(\frac{s}{2} - c\right)^2 = \frac{s
^2}{4} - sc + c^2.$$

Expanding the left: $\frac{5c^2}{4} - 2sc^3 = \frac{s^2}{4} - sc + c^2$, which s
implifies to:
$$\frac{c^2}{4} - 2sc^3 = \frac{s^2}{4} - sc.$$

Multiplying by 4:
$$c^2 - s^2 - 8sc^3 + 4sc = 0.$$

**Simplifying using double-angle identities.** Note $c^2 - s^2 = \cos 2x$ and $4
sc(1 - 2c^2) = 4sc\cdot(-\cos 2x) = -2\sin 2x\cos 2x = -\sin 4x$:

$$\cos 2x - \sin 4x = 0 \implies \cos 2x = 2\sin 2x\cos 2x.$$

**Case 1:** $\cos 2x = 0 \Rightarrow x = 45°$. Check the sign condition: $s/2 -
c = \frac{1}{2\sqrt{2}} - \frac{1}{\sqrt{2}} < 0$, so $\vec{MN}\cdot\vec{MD} < 0
$, making $\angle NMD$ obtuse — cannot equal $45°$. **Rejected** (extraneous fro
m squaring).

**Case 2:** $\cos 2x \neq 0$, so $1 = 2\sin 2x$, giving $\sin 2x = \frac{1}{2}$,
 hence $2x = 30°$ or $150°$, i.e., $x = 15°$ or $x = 75°$.

- **$x = 15°$:** $s/2 - c \approx 0.129 - 0.966 < 0$, so the dot product is nega
tive → angle is obtuse. **Rejected.**
- **$x = 75°$:** $s/2 - c \approx 0.483 - 0.259 > 0$. ✓

**Verification of $x = 75°$.** With $s = \sin 75° = \frac{\sqrt{6}+\sqrt{2}}{4}$
, $c = \cos 75° = \frac{\sqrt{6}-\sqrt{2}}{4}$:

$$M = (sc, s^2) = \left(\tfrac{1}{4},\; \tfrac{2+\sqrt{3}}{4}\right) \approx (0.
25,\; 0.933), \quad \text{inside the square. ✓}$$

$$\vec{MN} = \left(\tfrac{3}{4},\; -\tfrac{\sqrt{3}}{4}\right), \quad \vec{MD} =
 \left(-\tfrac{1}{4},\; -\tfrac{2+\sqrt{3}}{4}\right).$$

$$\vec{MN}\cdot\vec{MD} = -\tfrac{3}{16} + \tfrac{\sqrt{3}(2+\sqrt{3})}{16} = \t
frac{-3 + 2\sqrt{3}+3}{16} = \tfrac{\sqrt{3}}{8}.$$

$$|\vec{MN}| = \tfrac{\sqrt{3}}{2}, \quad |\vec{MD}| = \tfrac{\sqrt{2+\sqrt{3}}}
{2} = \tfrac{\sqrt{6}+\sqrt{2}}{4} = s.$$

$$\cos\angle NMD = \frac{\sqrt{3}/8}{(\sqrt{3}/2)\cdot(\sqrt{6}+\sqrt{2})/4} = \
frac{\sqrt{3}/8}{\sqrt{3}(\sqrt{6}+\sqrt{2})/8} = \frac{1}{\sqrt{6}+\sqrt{2}} =
\frac{\sqrt{6}-\sqrt{2}}{4} = \cos 75°. \checkmark$$

All three angles equal $75°$, $M$ lies in the interior, and no other solution is
 valid.

$$\boxed{x = 75°}$$
