Looking at this problem, I need to find the minimum number of queries (pairs of
sets for which Mahdi learns intersection and union) to determine all 100 sets.

## Proof

**Key Observation.** For any element $x$ in the universe, define $b_i(x) = \math
bf{1}[x \in S_i]$. From the query $(S_i, S_j)$, Mahdi learns $S_i \cap S_j$ and
$S_i \cup S_j$, which reveals for each element $x$:
- If $b_i(x) = b_j(x) = 0$: $x$ is in neither the intersection nor the union.
- If $b_i(x) = b_j(x) = 1$: $x$ is in both the intersection and the union.
- If $b_i(x) \neq b_j(x)$: $x$ is in the union but not the intersection.

So each query reveals, for every element, whether $b_i = b_j$, and if equal, rev
eals the common value. Determining all sets is equivalent to determining $b_i(x)
$ for all $i$ and all $x$.

---

### Upper Bound: 100 queries suffice

**Strategy.** Mahdi queries the 99 pairs $(S_i, S_{i+1})$ for $i = 1, \ldots, 99
$ (forming a path), then queries $(S_1, S_3)$.

Fix any element $x$. From the 99 path queries, Mahdi knows for each $i$ whether
$b_i(x) = b_{i+1}(x)$ or $b_i(x) \neq b_{i+1}(x)$.

**Case 1: $(b_1, \ldots, b_{100})$ is not alternating.** Then some consecutive p
air satisfies $b_i = b_{i+1}$, and that query reveals their common value. Propag
ating along the path using the known equal/differ relationships determines all $
b_j$.

**Case 2: $(b_1, \ldots, b_{100})$ is alternating** ($b_i \neq b_{i+1}$ for all
$i$). All 99 path queries yield "differ." The extra query $(S_1, S_3)$ gives $b_
1 = b_3$ (both odd indices) and reveals their common value. Propagating along th
e path determines all $b_j$.

In both cases, all $b_j(x)$ are determined for every $x$, so all sets are determ
ined. ∎

### Lower Bound: 99 queries do not suffice

We use an **adversary argument**. Consider a universe with a single element $x$,
 so each $S_i \in \{\{x\}, \emptyset\}$, determined by a vector $v \in \{0,1\}^{
100}$.

**Adversary's strategy:** Respond "differ" ($v_i \neq v_j$, i.e., intersection $
= \emptyset$, union $= \{x\}$) to every query, as long as this is consistent.

This is consistent precisely when the **query graph** $G$ (vertices $= \{1,\ldot
s,100\}$, edges $=$ queried pairs) is **bipartite**, since $v$ must be a proper
2-coloring of $G$.

**Claim:** With at most 99 edges on 100 vertices, $G$ is always a forest (acycli
c), hence bipartite.

*Proof of claim:* A graph on $n$ vertices with at most $n-1$ edges is acyclic (s
ince any connected component with $v'$ vertices needs $\geq v'-1$ edges, and equ
ality holds iff it's a tree). With $\leq 99$ edges on 100 vertices, $G$ is a for
est. ∎

Therefore, the adversary can respond "differ" to all 99 queries. Moreover, with
exactly 99 edges on 100 vertices, $G$ is a **tree** (connected forest, since a f
orest with $k$ components has $100 - k$ edges, giving $k = 1$).

After 99 "differ" responses, Mahdi knows $v_i \neq v_j$ for all queried pairs, s
o $v$ is a 2-coloring of the tree $G$. Every tree has **exactly two** 2-coloring
s: $v$ and its complement $\bar{v}$. These yield two distinct configurations of
the sets:

- **Configuration A:** $S_i = \{x\}$ for $i$ in one bipartition class, $S_i = \e
mptyset$ for $i$ in the other.
- **Configuration B:** The flip of Configuration A.

Both produce **identical** responses for all 99 queries (every query crosses the
 bipartition, giving intersection $= \emptyset$, union $= \{x\}$). Mahdi cannot
distinguish them. ∎

---

### Conclusion

The minimum number of queries is $\boxed{100}$.
