# Solution

## Part (a): Double Fourier Transform of $u$

Define the double Fourier transform of $u$ in the variables $x, y$:

$$\hat{u}(k, l, z) = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} u(x,y,z)\, e
^{-i(kx+ly)}\, dx\, dy.$$

Under this transform, $\partial^2 u/\partial x^2 \mapsto -k^2 \hat{u}$ and $\par
tial^2 u/\partial y^2 \mapsto -l^2 \hat{u}$, while $\partial^2 u/\partial z^2 \m
apsto \partial^2 \hat{u}/\partial z^2$. Laplace's equation becomes

$$\frac{\partial^2 \hat{u}}{\partial z^2} - (k^2 + l^2)\,\hat{u} = 0.$$

Set $\rho = \sqrt{k^2 + l^2} \geq 0$. The general solution is

$$\hat{u}(k,l,z) = A(k,l)\,e^{\rho z} + B(k,l)\,e^{-\rho z}.$$

Since $u$ must remain bounded as $z \to +\infty$, we require $A(k,l) = 0$ (for $
\rho > 0$). Applying the boundary condition $\hat{u}(k,l,0) = \hat{f}(k,l)$, whe
re $\hat{f}$ is the double Fourier transform of $f$, gives $B(k,l) = \hat{f}(k,l
)$.

$$\boxed{\hat{u}(k,l,z) = \hat{f}(k,l)\,e^{-z\sqrt{k^2+l^2}}.}$$

---

## Part (b): Inversion via Polar Coordinates

The inversion formula gives

$$u(x,y,z) = \frac{1}{(2\pi)^2}\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} \h
at{f}(k,l)\,e^{-\rho z}\,e^{i(kx+ly)}\,dk\,dl.$$

Substituting $\hat{f}(k,l) = \iint f(\xi,\eta)\,e^{-i(k\xi+l\eta)}\,d\xi\,d\eta$
 and interchanging integrals:

$$u(x,y,z) = \iint f(\xi,\eta)\,G(x-\xi,\, y-\eta,\, z)\,d\xi\,d\eta,$$

where the kernel is

$$G(X,Y,z) = \frac{1}{(2\pi)^2}\iint e^{-\rho z}\,e^{i(kX+lY)}\,dk\,dl, \qquad \
rho = \sqrt{k^2+l^2}.$$

### Introducing $w$ with $u = \partial w/\partial z$

Following the hint, define $w$ via its Fourier transform:

$$\hat{w}(k,l,z) = -\frac{\hat{f}(k,l)}{\rho}\,e^{-\rho z}.$$

Then $\partial \hat{w}/\partial z = -\frac{\hat{f}}{\rho}(-\rho)e^{-\rho z} = \h
at{f}\,e^{-\rho z} = \hat{u}$, confirming $u = \partial w/\partial z$. The inver
se transform of $\hat{w}$ is

$$w(x,y,z) = -\iint f(\xi,\eta)\,H(X,Y,z)\,d\xi\,d\eta,$$

where

$$H(X,Y,z) = \frac{1}{(2\pi)^2}\iint \frac{1}{\rho}\,e^{-\rho z}\,e^{i(kX+lY)}\,
dk\,dl.$$

### Evaluating $H$ in polar coordinates

Set $k = \rho\cos\theta$, $l = \rho\sin\theta$, so $dk\,dl = \rho\,d\rho\,d\thet
a$ and the factor $1/\rho$ cancels $\rho$:

$$H = \frac{1}{(2\pi)^2}\int_0^{\infty} e^{-\rho z}\left(\int_0^{2\pi} e^{i\rho(
X\cos\theta + Y\sin\theta)}\,d\theta\right)d\rho.$$

Write $X\cos\theta + Y\sin\theta = R\cos(\theta - \varphi)$ with $R = \sqrt{X^2+
Y^2}$. The $\theta$-integral is invariant under the shift $\theta \to \theta - \
varphi$, so we need $\int_0^{2\pi} e^{i\rho R\cos\theta}\,d\theta$. However, to
use the given integral identity, we instead perform the **$\rho$-integral first*
*:

$$\int_0^{\infty} e^{-\rho z}\,e^{i\rho R\cos\alpha}\,d\rho = \frac{1}{z - iR\co
s\alpha}, \qquad \text{Re}(z) > 0.$$

Therefore

$$H = \frac{1}{(2\pi)^2}\int_0^{2\pi} \frac{d\alpha}{z - iR\cos\alpha} = \frac{1
}{(2\pi)^2}\int_0^{2\pi} \frac{z + iR\cos\alpha}{z^2 + R^2\cos^2\alpha}\,d\alpha
.$$

The imaginary part vanishes by symmetry ($\cos\alpha$ integrates to zero over a
full period), leaving

$$H = \frac{z}{(2\pi)^2}\int_0^{2\pi} \frac{d\alpha}{z^2 + R^2\cos^2\alpha}.$$

Rewrite the denominator: $z^2 + R^2\cos^2\alpha = z^2\sin^2\alpha + (z^2+R^2)\co
s^2\alpha$. This matches the form $a^2\sin^2\alpha + b^2\cos^2\alpha$ with $a =
z$ and $b = \sqrt{z^2+R^2}$. Since the integrand has period $\pi$,

$$\int_0^{2\pi} \frac{d\alpha}{z^2\sin^2\alpha + (z^2+R^2)\cos^2\alpha} = 2\int_
0^{\pi} \frac{d\alpha}{z^2\sin^2\alpha + (z^2+R^2)\cos^2\alpha} = 2\cdot\frac{2\
pi}{z\sqrt{z^2+R^2}},$$

using the given identity $\int_0^{\pi} \frac{d\theta}{a^2\sin^2\theta + b^2\cos^
2\theta} = \frac{2\pi}{ab}$. Hence

$$H = \frac{z}{(2\pi)^2}\cdot\frac{4\pi}{z\sqrt{z^2+R^2}} = \frac{1}{2\pi\sqrt{z
^2+R^2}}.$$

### Recovering $u = \partial w/\partial z$

$$w(x,y,z) = -\frac{1}{2\pi}\iint \frac{f(\xi,\eta)}{\sqrt{z^2 + (x-\xi)^2 + (y-
\eta)^2}}\,d\xi\,d\eta.$$

Differentiating under the integral with respect to $z$:

$$\frac{\partial}{\partial z}\left[\frac{1}{\sqrt{z^2+R^2}}\right] = -\frac{z}{(
z^2+R^2)^{3/2}},$$

so

$$u(x,y,z) = \frac{\partial w}{\partial z} = \frac{1}{2\pi}\iint \frac{z\,f(\xi,
\eta)}{\bigl[z^2+(x-\xi)^2+(y-\eta)^2\bigr]^{3/2}}\,d\xi\,d\eta.$$

### Verification

- **Laplace's equation:** The Poisson kernel $P_z(X,Y) = \frac{z}{2\pi}(X^2+Y^2+
z^2)^{-3/2}$ is harmonic for $z > 0$ (direct computation confirms $P_{XX}+P_{YY}
+P_{zz}=0$), so $u = f * P_z$ is harmonic.

- **Boundary condition:** $P_z$ is an approximate identity: $\iint P_z\,d\xi\,d\
eta = 1$ for all $z>0$, and $P_z \to \delta$ as $z\to 0^+$. Thus $u(x,y,z)\to f(
x,y)$ as $z\to 0^+$.

---

### Final Answer

**(a)** The double Fourier transform of $u$ is

$$\hat{u}(k,l,z) = \hat{f}(k,l)\,\exp\!\bigl(-z\sqrt{k^2+l^2}\bigr).$$

**(b)** The solution is the Poisson integral for the upper half-space:

$$\boxed{u(x,y,z) = \frac{z}{2\pi}\iint_{\mathbb{R}^2} \frac{f(\xi,\eta)}{\bigl[
z^2+(x-\xi)^2+(y-\eta)^2\bigr]^{3/2}}\,d\xi\,d\eta.}$$
