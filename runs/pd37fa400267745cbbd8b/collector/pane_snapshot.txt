Looking at this problem, I need to determine whether a Brauer class killed by an
 arbitrary field extension must be killed by some finite subextension.

**Answer: No, not in general.**

**Counterexample.** Let $k = \mathbb{R}$, let $b \in \mathrm{Br}(\mathbb{R}) \co
ng \mathbb{Z}/2\mathbb{Z}$ be the nontrivial element (represented by the Hamilto
n quaternion algebra $\mathbb{H} = (-1,-1)_{\mathbb{R}}$), and set
$$L = \mathbb{R}\!\left(t,\, \sqrt{-t^2-1}\right).$$

**Step 1: $b \otimes L = 0$.**

The class $b$ is represented by the quaternion algebra $(-1,-1)_{\mathbb{R}}$. F
or any field $F$ with $-1 \notin F^{\times 2}$, the quaternion algebra $(-1,-1)_
F$ is split if and only if $-1$ is a norm from $F(\sqrt{-1})/F$, equivalently, $
-1 = x^2 + y^2$ for some $x, y \in F$.

In $L$, set $s = \sqrt{-t^2-1}$, so $s^2 = -t^2 - 1$. Then:
$$t^2 + s^2 = t^2 + (-t^2 - 1) = -1.$$

Since $t, s \in L$, we have $-1 = t^2 + s^2$ is a sum of two squares in $L$. The
refore $(-1,-1)_L \cong M_2(L)$, i.e., $b \otimes L = 0$ in $\mathrm{Br}(L)$.

**Step 2: $L$ contains no nontrivial finite extension of $\mathbb{R}$.**

The field $L = \mathbb{R}(t, s)$ with $s^2 + t^2 + 1 = 0$ is the function field
of the conic $C: x^2 + y^2 + z^2 = 0$ in $\mathbb{P}^2_{\mathbb{R}}$. This conic
 is geometrically integral (over $\mathbb{C}$ it is a smooth conic, hence isomor
phic to $\mathbb{P}^1_{\mathbb{C}}$). For a geometrically integral variety over
a field $k$, the field $k$ is algebraically closed in the function field. Theref
ore $\mathbb{R}$ is algebraically closed in $L$, meaning $L$ contains no nontriv
ial algebraic extension of $\mathbb{R}$.

Concretely, one can verify directly that $i = \sqrt{-1} \notin L$: every element
 of $L$ has the form $a(t) + b(t)\,s$ with $a, b \in \mathbb{R}(t)$. If $i = a(t
) + b(t)\,s$, squaring and comparing (using $s^2 = -t^2-1$) forces $a(t) = 0$ an
d $b(t)^2 = 1/(t^2+1)$, which has no solution in $\mathbb{R}(t)$ since $t^2+1$ i
s not a square.

**Step 3: No finite subextension kills $b$.**

By the Artin–Schreier theorem (or the fundamental theorem of algebra), the only
finite extensions of $\mathbb{R}$ are $\mathbb{R}$ itself and $\mathbb{C} = \mat
hbb{R}(i)$. Since $\mathbb{R}$ is algebraically closed in $L$, we have $\mathbb{
C} \not\subset L$, so the only finite subextension $K/\mathbb{R}$ with $K \subse
t L$ is $K = \mathbb{R}$ itself. But $b \otimes \mathbb{R} = b \neq 0$ by assump
tion.

**Conclusion.** We have $b \otimes L = 0$, yet there is no finite-degree subexte
nsion $K/\mathbb{R}$ inside $L$ with $b \otimes K = 0$. The answer is therefore
**no** in general.

**Remark.** The answer *is* yes when $L/k$ is algebraic: if $b$ is represented b
y a degree-$n$ central simple algebra $A$ and $A \otimes_k L \cong M_n(L)$, the
isomorphism involves only finitely many elements of $L$, which (by algebraicity)
 generate a finite extension $K/k$ inside $L$ that already splits $A$. The count
erexample above exploits a transcendental extension: the function field of an an
isotropic conic splits the associated quaternion algebra without containing any
nontrivial algebraic extension of the base field.
