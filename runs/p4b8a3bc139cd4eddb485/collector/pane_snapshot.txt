# IMO 1974 Problem 5 — Solution

Let
$$S=\frac{a}{a+b+d}+\frac{b}{a+b+c}+\frac{c}{b+c+d}+\frac{d}{a+c+d},\qquad a,b,c
,d>0.$$

**Claim.** The set of possible values of $S$ is the open interval $(1,2)$.

---

## 1. The upper bound $S<2$

Since $d>0$ and $c>0$,
$$\frac{a}{a+b+d}<\frac{a}{a+b},\qquad \frac{b}{a+b+c}<\frac{b}{a+b},$$
so
$$\frac{a}{a+b+d}+\frac{b}{a+b+c}<\frac{a+b}{a+b}=1.$$
Likewise, since $b>0$ and $a>0$,
$$\frac{c}{b+c+d}<\frac{c}{c+d},\qquad \frac{d}{a+c+d}<\frac{d}{c+d},$$
so
$$\frac{c}{b+c+d}+\frac{d}{a+c+d}<\frac{c+d}{c+d}=1.$$
Adding gives $S<2$.

## 2. The lower bound $S>1$

Let $T=a+b+c+d$. Each denominator is strictly smaller than $T$:
$$a+b+d<T,\quad a+b+c<T,\quad b+c+d<T,\quad a+c+d<T,$$
since the missing variable is positive in each case. Hence each fraction is stri
ctly larger than the corresponding fraction with denominator $T$:
$$S>\frac{a+b+c+d}{T}=1.$$

Combining, $\boxed{1<S<2}$ for all positive $a,b,c,d$.

## 3. Every value in $(1,2)$ is attained

We use two one-parameter families (both continuous in the parameter $r>0$).

**Family A: $a=c=\alpha,\; b=d=\beta$.** Let $r=\alpha/\beta>0$. Then
$$S_A(r)=\frac{2\alpha}{\alpha+2\beta}+\frac{2\beta}{2\alpha+\beta}=\frac{2r}{r+
2}+\frac{2}{2r+1}.$$
- At $r=1$: $S_A=\frac{2}{3}+\frac{2}{3}=\frac{4}{3}$.
- As $r\to 0^{+}$: $S_A\to 0+2=2$.
- As $r\to\infty$: $S_A\to 2+0=2$.

The derivative
$$S_A'(r)=\frac{4}{(r+2)^2}-\frac{4}{(2r+1)^2}$$
vanishes only when $r+2=2r+1$, i.e. $r=1$, and this is the global minimum (the f
unction approaches $2$ at both ends). Thus
$$S_A\big((0,\infty)\big)=\Big[\tfrac{4}{3},\,2\Big).$$

**Family B: $a=b=\alpha,\; c=d=\beta$.** Let $r=\alpha/\beta>0$. Then
$$S_B(r)=\frac{2\alpha}{2\alpha+\beta}+\frac{2\beta}{\alpha+2\beta}=\frac{2r}{2r
+1}+\frac{2}{r+2}.$$
- At $r=1$: $S_B=\frac{2}{3}+\frac{2}{3}=\frac{4}{3}$.
- As $r\to 0^{+}$: $S_B\to 0+1=1$.
- As $r\to\infty$: $S_B\to 1+0=1$.

The derivative
$$S_B'(r)=\frac{2}{(2r+1)^2}-\frac{2}{(r+2)^2}$$
vanishes only at $r=1$, which is the global maximum (the function approaches $1$
 at both ends). Thus
$$S_B\big((0,\infty)\big)=\Big(1,\,\tfrac{4}{3}\Big].$$

**Union.** The two ranges overlap at $\frac{4}{3}$ and together cover
$$\Big(1,\tfrac{4}{3}\Big]\cup\Big[\tfrac{4}{3},2\Big)=(1,2).$$

## 4. Conclusion

For all positive reals $a,b,c,d$ we have $1<S<2$, and conversely every real numb
er in $(1,2)$ is realized by one of the two families above. Therefore the set of
 possible values is exactly

$$\boxed{(1,\,2)}.$$
