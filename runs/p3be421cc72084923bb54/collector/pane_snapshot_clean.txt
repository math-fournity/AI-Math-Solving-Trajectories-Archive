## Proof

### Part (a)

**($\Rightarrow$)** Suppose $f: X \to [0,1]$ is continuous with $f^{-1}(\{0\}) =
 A$. For each $n \ge 1$, the set $[0, 1/n)$ is open in $[0,1]$, so $f^{-1}([0,1/
n))$ is open in $X$. Since
$$A = f^{-1}(\{0\}) = \bigcap_{n=1}^{\infty} f^{-1}\bigl([0,1/n)\bigr),$$
$A$ is a countable intersection of open sets, i.e. a $G_\delta$-set. ∎

**($\Leftarrow$)** Suppose $A$ is a (closed) $G_\delta$-set, so $A = \bigcap_{n=
1}^{\infty} U_n$ with each $U_n$ open in $X$. Since $A$ is closed, for every $n$
 the sets $A$ and $X \setminus U_n$ are disjoint closed subsets of the normal sp
ace $X$. By Urysohn's lemma there exists a continuous $h_n : X \to [0,1]$ with
$$h_n(A) = \{0\}, \qquad h_n(X \setminus U_n) = \{1\}.$$

Define
$$f(x) = \sum_{n=1}^{\infty} 2^{-n} h_n(x).$$
The series is uniformly convergent (dominated by $\sum 2^{-n} = 1$), hence $f$ i
s continuous, and $0 \le f(x) \le 1$, so $f : X \to [0,1]$.

- If $x \in A$, then $h_n(x) = 0$ for every $n$, so $f(x) = 0$.
- If $x \notin A$, then since $A = \bigcap U_n$, there exists $N$ with $x \notin
 U_N$, i.e. $x \in X \setminus U_N$; thus $h_N(x) = 1$ and $f(x) \ge 2^{-N} > 0$
.

Therefore $f^{-1}(\{0\}) = A$. ∎

### Part (b)

Assume $A$ is a closed $G_\delta$-set and $B$ is closed with $A \cap B = \emptys
et$.

By part (a) there is a continuous $f : X \to [0,1]$ with $f^{-1}(\{0\}) = A$. Si
nce $A, B$ are disjoint closed sets in the normal space $X$, Urysohn's lemma giv
es a continuous $\psi : X \to [0,1]$ with
$$\psi(A) = \{0\}, \qquad \psi(B) = \{1\}.$$
In particular $A \subseteq \psi^{-1}(\{0\})$.

Define $g : X \to [0,1]$ by
$$g(x) = \max\{f(x),\, \psi(x)\}.$$
The maximum of two continuous real-valued functions is continuous, and $g$ takes
 values in $[0,1]$.

- **Zero set:** $g(x) = 0 \iff f(x) = 0 \text{ and } \psi(x) = 0 \iff x \in f^{-
1}(\{0\}) \cap \psi^{-1}(\{0\}) = A \cap \psi^{-1}(\{0\}) = A$, using $A \subset
eq \psi^{-1}(\{0\})$. Hence $g^{-1}(\{0\}) = A$.
- **Value on $B$:** For $b \in B$, $\psi(b) = 1$, so $g(b) = \max\{f(b), 1\} = 1
$.

Thus $g$ is the desired continuous function. ∎

### PROOF COMPLETE
