## 解答

**方程组分析。** 由方程 (1): $x_2 = x_1 - x_1^n = x_1(1 - x_1^{n-1})$。代入方程
(2):

$$x_3^{n+1} = x_1 x_2 - x_2^2 = x_2(x_1 - x_2) = x_2 \cdot x_1^n$$

由于 $x_1 - x_2 = x_1^n$，故 $x_3^{n+1} = x_1^n \cdot x_1(1-x_1^{n-1}) = x_1^{n+
1}(1-x_1^{n-1})$。

令 $t = x_1$，$v = 1 - t^{n-1}$，则 $x_2 = tv$，$x_3^{n+1} = t^{n+1} v$。

---

**情况一：$n$ 为偶数（$n-1$ 奇，$n+1$ 奇）。**

此时 $x_3 = t \cdot v^{1/(n+1)}$（唯一实 $(n+1)$ 次根，保号），$t$ 取任意实数。

- **$t > 0$：** $t^{n-1} > 0$，故 $v < 1$。$x_2 = tv < t = x_1$（因 $v<1$）。$x_
3 = t\,v^{1/(n+1)}$：若 $v>0$ 则 $v^{1/(n+1)}<1$，故 $x_3<t$；若 $v\le 0$ 则 $x_
3\le 0 < t$。故 $x_3 < x_1$。
- **$t < 0$：** $t^{n-1}<0$（$n-1$ 奇），故 $v > 1$。$x_2 = tv$，$t<0,\,v>1$，故
 $x_2 < t = x_1$。$x_3 = t\,v^{1/(n+1)}$，$v>1$ 故 $v^{1/(n+1)}>1$，$t<0$ 故 $x_
3 < t = x_1$。

因此对所有 $t\neq 0$，$x_1$ 严格大于 $x_2$ 和 $x_3$。等号仅在 $t=0$（三者皆零）
或 $t=2^{1/(n-1)}$（此时 $v=-1$，$x_2=x_3=-t$）时出现，这些非两两不同的解被排除
。

**结论：所有偶数 $n\ge 2$ 属于 $S$，且 $x_1$ 恒为最大。**

---

**情况二：$n$ 为奇数（$n-1$ 偶，$n+1$ 偶）。**

此时 $t^{n-1}\ge 0$，且 $x_3^{n+1}=t^{n+1}v$ 要求 $t^{n+1}v\ge 0$。因 $n+1$ 偶，
$t^{n+1}\ge 0$，故需 $v\ge 0$，即 $t^{n-1}\le 1$，即 $|t|\le 1$。且 $x_3 = \pm|t
|\,v^{1/(n+1)}$（两个符号选择）。

- **$t\in(0,1)$：** $v\in(0,1)$。$x_2=tv<t=x_1$，$|x_3|=t\,v^{1/(n+1)}<t=x_1$。
故 $x_1$ 最大。
- **$t\in(-1,0)$：** $v\in(0,1)$（因 $t^{n-1}\in(0,1)$）。$x_2=tv$，$t<0,\,v\in(
0,1)$，故 $t<x_2<0$，即 $x_2>x_1$。
  - 取 $x_3>0$：$x_3=|t|\,v^{1/(n+1)}>0>x_2>x_1$，**$x_3$ 最大**。
  - 取 $x_3<0$：$x_3=t\,v^{1/(n+1)}$，因 $v^{1/(n+1)}>v$（$0<v<1$，指数 $<1$）且
 $t<0$，故 $x_3<x_2$，**$x_2$ 最大**。

因此对奇数 $n$，存在两两不同的解使得 $x_1$ 最大（$t\in(0,1)$）、$x_3$ 最大（$t\i
n(-1,0)$，$x_3>0$）、$x_2$ 最大（$t\in(-1,0)$，$x_3<0$）。不存在单一变量恒为最大
。

**结论：所有奇数 $n\ge 3$ 不属于 $S$。**
