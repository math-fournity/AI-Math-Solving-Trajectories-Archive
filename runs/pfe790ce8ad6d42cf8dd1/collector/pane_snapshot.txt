## 解答

**The statement is TRUE.** For every homeomorphism $f: X \to X$, we have $f(C)=C
$ and $f(I)=I$.

### Proof

$X = C \sqcup I$ is the topological sum (disjoint union) of a circle $C \cong S^
1$ and an interval $I$. Both $C$ and $I$ are connected, and in the disjoint-unio
n topology each of $C$, $I$ is clopen. Hence the connected components of $X$ are
 exactly $\{C, I\}$.

**Step 1: A homeomorphism permutes connected components.**
Let $f: X \to X$ be a homeomorphism. The image $f(C)$ of a connected component i
s connected, and since $f$ is a homeomorphism it must be a maximal connected sub
set, i.e. a connected component. Thus
$$f(C) \in \{C, I\}.$$

**Step 2: $C$ and $I$ are not homeomorphic.**
We use the topological invariant of *cut points*. A point $p \in Y$ is a cut poi
nt if $Y \setminus \{p\}$ is disconnected; this property is preserved by homeomo
rphisms.

- **Circle $C = S^1$:** Removing any single point leaves an open arc, homeomorph
ic to an open interval, which is connected. So $C$ has **zero** cut points.
- **Interval $I$:** An interval (open, closed, or half-open, and non-degenerate)
 contains an interior point $p$; removing $p$ splits $I$ into two non-empty sepa
rated pieces, so $p$ is a cut point. Thus $I$ has **at least one** cut point. (I
f $I$ were degenerate — a single point — then $|C| = |\mathbb{R}| \neq 1 = |I|$,
 so again $C \not\cong I$.)

Since the number of cut points is a topological invariant and $C$ has none while
 $I$ has at least one, we conclude
$$C \not\cong I.$$

**Step 3: Conclude.**
If $f(C) = I$, then the restriction $f|_C : C \to I$ would be a homeomorphism (a
 bijective continuous map with continuous inverse, being the restriction of a ho
meomorphism to a component mapped onto a component). This contradicts Step 2. Th
erefore
$$f(C) = C.$$
Since $f$ is a bijection with $f(X) = X$, we obtain
$$f(I) = X \setminus f(C) = X \setminus C = I.$$

Hence for every homeomorphism $f: X \to X$, both $f(C) = C$ and $f(I) = I$ hold.
 $\blacksquare$
