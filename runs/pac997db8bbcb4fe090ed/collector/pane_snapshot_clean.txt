## Proof

**Claim:** If $\alpha \in \mathbb{R}$ satisfies $\cos(\pi\alpha) = \tfrac{1}{3}$
, then $\alpha$ is irrational.

**Proof by contradiction.** Suppose $\alpha$ is rational. Write $\alpha = p/q$ w
here $p, q \in \mathbb{Z}$, $q > 0$, and $\gcd(p, q) = 1$. Then

$$\cos\!\left(\frac{p\pi}{q}\right) = \frac{1}{3}.$$

**Key fact.** For any integers $p, q$ with $q \neq 0$, the number $2\cos(p\pi/q)
$ is an **algebraic integer**.

*Proof of key fact.* Set $\zeta = e^{ip\pi/q}$. Then $\zeta^{2q} = e^{i \cdot 2p
\pi} = 1$, so $\zeta$ is a $(2q)$-th root of unity, hence an algebraic integer.
Its complex conjugate $\bar{\zeta} = e^{-ip\pi/q}$ is also a root of unity and h
ence an algebraic integer. The sum of two algebraic integers is an algebraic int
eger, so

$$\zeta + \bar{\zeta} = 2\cos\!\left(\frac{p\pi}{q}\right)$$

is an algebraic integer. $\square$

Applying this to our situation: $2\cos(p\pi/q) = 2 \cdot \tfrac{1}{3} = \tfrac{2
}{3}$.

So $\tfrac{2}{3}$ is an algebraic integer. But $\tfrac{2}{3}$ is a **rational**
number, and a basic theorem of algebraic number theory states:

> *Every rational algebraic integer is an (ordinary) integer.*

*Proof of this theorem.* If $r \in \mathbb{Q}$ is an algebraic integer, then $r$
 is a root of a monic polynomial $x^n + c_{n-1}x^{n-1} + \cdots + c_0 \in \mathb
b{Z}[x]$. Write $r = a/b$ in lowest terms ($\gcd(a,b)=1$, $b>0$). Substituting a
nd multiplying through by $b^n$:

$$a^n + c_{n-1} a^{n-1} b + \cdots + c_0 b^n = 0.$$

Every term except $a^n$ is divisible by $b$, so $b \mid a^n$. Since $\gcd(a,b) =
 1$, this forces $b = 1$, i.e., $r \in \mathbb{Z}$. $\square$

Since $\tfrac{2}{3} \notin \mathbb{Z}$, it is **not** an algebraic integer. This
 contradicts the key fact, which says $\tfrac{2}{3}$ must be an algebraic intege
r.

The contradiction arose from assuming $\alpha = p/q \in \mathbb{Q}$. Therefore $
\alpha$ is irrational. $\blacksquare$
