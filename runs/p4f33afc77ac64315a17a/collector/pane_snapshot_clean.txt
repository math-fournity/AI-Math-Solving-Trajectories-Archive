**Setup.** We take $\mathbb{N} = \{1, 2, 3, \dots\}$. The functional equation is
$$f(f(n)) + f(n+1) = n + 2, \qquad n \geq 1. \tag{$\star$}$$

**Determining $f(1)$.** Setting $n = 1$: $f(f(1)) + f(2) = 3$. Since $f$ maps to
 positive integers, both terms are $\geq 1$, so $\{f(f(1)), f(2)\} = \{1, 2\}$.

Let $a = f(1)$.

- **$a = 1$:** $f(1) + f(2) = 3 \Rightarrow f(2) = 2$. ✓ (consistent so far)
- **$a = 2$:** $f(2) + f(2) = 3 \Rightarrow 2f(2) = 3$, impossible.
- **$a \geq 3$:** $f(a) + f(2) = 3$, so $\{f(a), f(2)\} = \{1,2\}$.
  - If $f(2) = 1$: from $n=2$, $f(f(2)) + f(3) = 4 \Rightarrow f(1) + f(3) = 4 \
Rightarrow f(3) = 4 - a$. Need $f(3) \geq 1$, so $a \leq 3$, giving $a = 3, f(3)
 = 1$. Then $n=3$: $f(f(3)) + f(4) = 5 \Rightarrow f(1) + f(4) = 5 \Rightarrow f
(4) = 2$. But $f(a) = f(3) = 1$ and $f(2) = 1$, so $n=1$ gives $f(3) + f(2) = 1
+ 1 = 2 \neq 3$. ✗
  - If $f(2) = 2$: from $n=2$, $f(2) + f(3) = 4 \Rightarrow f(3) = 2$. Then $n=3
$: $f(f(3)) + f(4) = 5 \Rightarrow f(2) + f(4) = 5 \Rightarrow f(4) = 3$. Then $
n=4$: $f(f(4))+f(5)=6 \Rightarrow f(3)+f(5)=6 \Rightarrow f(5)=4$. Continuing: $
n=5$: $f(4)+f(6)=7 \Rightarrow f(6)=4$; $n=6$: $f(4)+f(7)=8 \Rightarrow f(7)=5$.
 Now check: $f(a) = f(3) = 2 \neq 1$, but we needed $f(a) = 1$. ✗

Therefore **$f(1) = 1$ is the only possibility**, and $f(2) = 2$.

**Uniqueness via well-defined recursion.** Given $f(1), \dots, f(n)$, equation $
(\star)$ determines
$$f(n+1) = n + 2 - f(f(n)).$$
This is well-defined provided $f(n) \leq n$ (so $f(f(n))$ is already known). We
prove $1 \leq f(n) \leq n$ for all $n$ by induction:

- **Base:** $f(1) = 1 \leq 1$. ✓
- **Step:** Assume $f(k) \leq k$ for all $k \leq n$. Then $m := f(n) \leq n$, so
 $f(f(n)) = f(m)$ is known. Since $f(m) \geq 1$:
  - $f(n+1) = n + 2 - f(f(n)) \leq n + 1$. ✓
  - $f(n+1) = n + 2 - f(f(n)) \geq n + 2 - f(n) \geq n + 2 - n = 2 \geq 1$ ✓ (us
ing $f(f(n)) \leq f(n) \leq n$, since $f(m) \leq m$ with $m = f(n) \leq n$).

So the recursion uniquely determines $f$ with no contradictions. There is exactl
y **one** solution.
