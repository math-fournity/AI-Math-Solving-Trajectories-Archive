# Möbius Function of the Partition Lattice $\Pi_n$

## Setup

Let $\Pi_n$ denote the set of all partitions of $[n] = \{1,\ldots,n\}$, ordered
by refinement: $\sigma \leq \tau$ means every block of $\tau$ is a union of bloc
ks of $\sigma$. The minimum element is $\hat{0} = \{\{1\},\ldots,\{n\}\}$ (all s
ingletons) and the maximum is $\hat{1} = \{[n]\}$ (one block).

**Claim.** For $\sigma \leq \tau$ in $\Pi_n$, let the blocks of $\tau$ be $B_1,\
ldots,B_k$, and let $n_i$ be the number of blocks of $\sigma$ contained in $B_i$
. Then

$$\boxed{\mu(\sigma,\tau) = \prod_{i=1}^{k}\,(-1)^{n_i-1}\,(n_i-1)!}$$

In particular, $\mu(\hat{0},\hat{1}) = (-1)^{n-1}(n-1)!$.

## Proof

### Step 1: Intervals are products of partition lattices

Let $\sigma \leq \tau$ with blocks of $\tau$ being $B_1,\ldots,B_k$. A partition
 $\rho$ with $\sigma \leq \rho \leq \tau$ is determined independently on each bl
ock $B_i$: within $B_i$, we choose a partition of the $n_i$ blocks of $\sigma$ t
hat lie in $B_i$. This gives an isomorphism of posets

$$[\sigma,\tau] \cong \Pi_{n_1} \times \cdots \times \Pi_{n_k}.$$

Since the Möbius function of a product is the product of Möbius functions,

$$\mu(\sigma,\tau) = \prod_{i=1}^k \mu_{n_i}, \qquad \text{where } \mu_m := \mu(
\hat{0},\hat{1})_{\Pi_m},\;\; \mu_1 := 1.$$

Thus the entire Möbius function is determined by the values $\mu_n$.

### Step 2: Recursion via $\sum_{\rho} \mu(\hat{0},\rho) = 0$

By the defining property of the Möbius function, for $n \geq 2$:

$$\sum_{\rho \in \Pi_n} \mu(\hat{0},\rho) = 0.$$

By Step 1, if $\rho$ has blocks of sizes $m_1,\ldots,m_k$ (with $\sum m_j = n$),
 then $\mu(\hat{0},\rho) = \prod_j \mu_{m_j}$. So:

$$\sum_{\rho \in \Pi_n}\;\prod_{B \in \rho}\, \mu_{|B|} = 0 \quad \text{for } n
\geq 2, \qquad \text{and } = 1 \text{ for } n=1. \tag{$\star$}$$

### Step 3: Exponential generating function

Define $A(x) = \sum_{n \geq 1} \mu_n \,\frac{x^n}{n!}$. The exponential formula
for set partitions gives:

$$\sum_{n \geq 0}\left(\sum_{\rho \in \Pi_n}\prod_{B\in\rho}\mu_{|B|}\right)\fra
c{x^n}{n!} = \exp\!\big(A(x)\big).$$

By $(\star)$, the coefficient of $\frac{x^n}{n!}$ is $0$ for $n\geq 2$, equals $
1$ for $n=1$, and equals $1$ for $n=0$ (the empty partition). Therefore:

$$\exp(A(x)) = 1 + x.$$

Solving: $A(x) = \ln(1+x)$.

### Step 4: Extract coefficients

$$\ln(1+x) = \sum_{n \geq 1} \frac{(-1)^{n-1}}{n}\,x^n = \sum_{n \geq 1}\frac{(-
1)^{n-1}(n-1)!}{n!}\,x^n.$$

Comparing with $A(x) = \sum_{n\geq 1}\mu_n\,\frac{x^n}{n!}$:

$$\mu_n = (-1)^{n-1}(n-1)!.$$

### Step 5: General formula

Substituting back into Step 1:

$$\mu(\sigma,\tau) = \prod_{i=1}^{k}\,(-1)^{n_i-1}(n_i-1)!.$$

### Verification (small cases)

- **$n=1$:** $\mu_1 = (-1)^0\cdot 0! = 1$. ✓ (single element)
- **$n=2$:** $\mu_2 = (-1)^1\cdot 1! = -1$. ✓ (two-element chain)
- **$n=3$:** $\mu_3 = (-1)^2\cdot 2! = 2$. Check: $\Pi_3$ has $\hat{0}$, three m
iddle elements (one pair + singleton), and $\hat{1}$. Each middle element $\rho$
 has $\mu(\hat{0},\rho)=\mu_2\cdot\mu_1 = -1$. Then $\mu(\hat{0},\hat{1}) = -\bi
g(1 + 3(-1)\big) = 2$. ✓
- **$n=4$:** $\mu_4 = (-1)^3\cdot 3! = -6$. Check via $(\star)$: summing over al
l partition types of $[4]$:
  - $|4|$: $\mu_4$
  - $|3|+|1|$: $\binom{4}{3}\cdot 2\cdot 1 = 8$
  - $|2|+|2|$: $3\cdot(-1)^2 = 3$
  - $|2|+|1|+|1|$: $6\cdot(-1)\cdot 1 = -6$
  - $|1|^4$: $1$

  Total: $\mu_4 + 8 + 3 - 6 + 1 = \mu_4 + 6 = 0 \Rightarrow \mu_4 = -6$. ✓
