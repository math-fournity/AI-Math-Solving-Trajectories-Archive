## 第 1 部分：求向量场 F

我们需要 F = (M, N, 0)（因为 F = M**i** + N**j**，没有 **k** 分量），使得

∇ × F = (∂N/∂z − ∂(0)/∂y, ∂(0)/∂x − ∂M/∂z, ∂M/∂y − ∂N/∂x) = (−3xz², 0, z³).

这给出了三个方程：

1. ∂N/∂z = −3xz²
2. −∂M/∂z = 0
3. ∂M/∂y − ∂N/∂x = z³

由 (1) 得：N = −xz³ + g(x, y)。
由 (2) 得：M = h(x, y)（与 z 无关）。
将 ∂N/∂x = −z³ + ∂g/∂x 和 ∂M/∂y = ∂h/∂y 代入 (3)：

∂h/∂y − (−z³ + ∂g/∂x) = z³  ⟹  ∂h/∂y − ∂g/∂x = 0.

最简单的选择是 g = 0, h = 0，即

**F = (0, −xz³, 0).**

验证：∇ × F = (∂(−xz³)/∂z, 0, −∂(−xz³)/∂x) = (−3xz², 0, z³). ✓

## 第 2 部分：通过斯托克斯定理计算曲面积分

斯托克斯定理：

$$\iint_S (\nabla\times\mathbf{F})\cdot d\mathbf{S} = \oint_C \mathbf{F}\cdot d\
mathbf{r},$$

其中 C 是 S 的边界曲线，方向由右手定则根据向上的法线确定。

曲面 S 为 z = x² + y²，且 z ≤ 4。边界为 z = 4 且 x² + y² = 4 的圆 —— 即 z = 4 平
面上半径为 2 的圆。

**方向。** 向上的法线（正 z 分量）配合右手定则，意味着从上方观察时，边界曲线应为
逆时针方向。

**参数化 C：** r(t) = (2 cos t, 2 sin t, 4), 0 ≤ t ≤ 2π。

在 C 上：x = 2 cos t, z = 4，所以

F = (0, −xz³, 0) = (0, −2 cos t · 64, 0) = (0, −128 cos t, 0).

dr = (−2 sin t, 2 cos t, 0) dt.

F · dr = (0)(−2 sin t) + (−128 cos t)(2 cos t) + (0)(0) = −256 cos²t.

因此

$$\oint_C \mathbf{F}\cdot d\mathbf{r} = \int_0^{2\pi} -256\cos^2 t\, dt = -256\c
dot\pi = -256\pi.$$

## 结果

$$\boxed{\iint_{S}(-3xz^{2},\,0,\,z^{3})\cdot d\mathbf{S} \;=\; -256\pi}$$

一个有效的向量场为 **F = −xz³ j**（即 M = 0, N = −xz³）。
