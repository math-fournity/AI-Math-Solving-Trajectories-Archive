## Proof

**Answer: The maximum possible spectral norm is $n$.**

**Upper bound.** For any matrix $A$, the spectral norm is bounded by the Frobeni
us norm:
$$\|A\|_2 \le \|A\|_F.$$
Since every entry of $A$ is $\pm 1$, we have $a_{ij}^2 = 1$ for all $i,j$, so
$$\|A\|_F = \sqrt{\sum_{i=1}^n\sum_{j=1}^n a_{ij}^2} = \sqrt{n^2} = n.$$
Therefore $\|A\|_2 \le n$.

**Construction achieving $n$.** Note that balanced columns ($\sum_i a_{ij}=0$ fo
r each $j$) require $n$ to be even, since the sum of $n$ values each $\pm 1$ has
 the same parity as $n$ and equals $0$ only when $n$ is even. Set $n = 2m$.

Let $\mathbf{u} = (\underbrace{1,\ldots,1}_{m},\underbrace{-1,\ldots,-1}_{m})^T
\in \mathbb{R}^n$ (a balanced $\pm 1$ vector, so $\sum_i u_i = 0$), and let $\ma
thbf{v} = (1,1,\ldots,1)^T \in \mathbb{R}^n$. Define
$$A = \mathbf{u}\,\mathbf{v}^T, \qquad a_{ij} = u_i \cdot v_j = u_i.$$

*Entries are $\pm 1$:* $a_{ij} = u_i \in \{+1,-1\}$. ✓

*Balanced columns:* Column $j$ is $v_j \cdot \mathbf{u} = \mathbf{u}$, so $\sum_
i a_{ij} = v_j \sum_i u_i = 0$. ✓

*Spectral norm:* $A = \mathbf{u}\mathbf{v}^T$ is rank 1, so
$$\|A\|_2 = \|\mathbf{u}\|\,\|\mathbf{v}\| = \sqrt{n}\cdot\sqrt{n} = n.$$

Equivalently, $A^TA = \mathbf{v}\,\mathbf{u}^T\mathbf{u}\,\mathbf{v}^T = n\,\mat
hbf{v}\mathbf{v}^T$, whose largest eigenvalue is $n\|\mathbf{v}\|^2 = n^2$, givi
ng $\|A\|_2 = n$.

**Conclusion.** The upper bound $\|A\|_2 \le n$ is tight, achieved by the rank-1
 construction above. The maximum possible spectral norm is

$$\boxed{n}$$
