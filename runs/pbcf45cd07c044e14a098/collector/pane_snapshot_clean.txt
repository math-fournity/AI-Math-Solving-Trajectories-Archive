## Claim

The infinite product $\prod_{i=0}^{\infty}\mathbb{R}$ (i.e. the set of all seque
nces of real numbers, denoted $\mathbb{R}^{\mathbb{N}}$) **has the same cardinal
ity as $\mathbb{R}$**.

## Proof

We prove $|\mathbb{R}^{\mathbb{N}}| = |\mathbb{R}|$ by exhibiting injections in
both directions and invoking the Cantor–Bernstein theorem.

### Injection $\mathbb{R} \hookrightarrow \mathbb{R}^{\mathbb{N}}$

Define $\varphi:\mathbb{R}\to\mathbb{R}^{\mathbb{N}}$ by $\varphi(x) = (x,0,0,0,
\dots)$. This is clearly injective. Hence $|\mathbb{R}| \le |\mathbb{R}^{\mathbb
{N}}|$.

### Injection $\mathbb{R}^{\mathbb{N}} \hookrightarrow \mathbb{R}$

We build this in two steps.

**Step 1 — Encode reals as binary sequences.** There is an injection $\mathbb{R}
\hookrightarrow 2^{\mathbb{N}}$. For instance, compose a bijection $\mathbb{R}\t
o(0,1)$ (e.g. $x\mapsto \tfrac{1}{\pi}\arctan x + \tfrac{1}{2}$) with the map se
nding $y\in(0,1)$ to its binary expansion, choosing the *non-terminating* expans
ion whenever two expansions exist. This yields a unique binary sequence for each
 real, so we have an injection $\iota:\mathbb{R}\hookrightarrow 2^{\mathbb{N}}$.

**Step 2 — Interleave countably many binary sequences into one.** Take a sequenc
e $(x_0,x_1,x_2,\dots)\in\mathbb{R}^{\mathbb{N}}$. Apply Step 1 to each term to
get binary sequences $b_0,b_1,b_2,\dots\in 2^{\mathbb{N}}$, where $b_i = \iota(x
_i)$. The pair $(i,j)\mapsto b_i(j)$ is a function $\mathbb{N}\times\mathbb{N}\t
o\{0,1\}$. Since $\mathbb{N}\times\mathbb{N}$ is countably infinite, fix a bijec
tion $\pi:\mathbb{N}\to\mathbb{N}\times\mathbb{N}$ and define a single binary se
quence $c\in 2^{\mathbb{N}}$ by
$$c(n) = b_{\pi(n)_1}\bigl(\pi(n)_2\bigr).$$
Finally compose with any injection $2^{\mathbb{N}}\hookrightarrow\mathbb{R}$ (e.
g. interpret $c$ as the binary expansion of a number in $(0,1)$, again using the
 non-terminating convention, then map back into $\mathbb{R}$).

This composition $\psi:\mathbb{R}^{\mathbb{N}}\to\mathbb{R}$ is injective: from
$c$ we recover every bit $b_i(j)$ (via $\pi^{-1}$), hence every $b_i$, hence eve
ry $x_i$ (since $\iota$ is injective). Therefore $|\mathbb{R}^{\mathbb{N}}| \le
|\mathbb{R}|$.

### Conclusion

We have $|\mathbb{R}| \le |\mathbb{R}^{\mathbb{N}}|$ and $|\mathbb{R}^{\mathbb{N
}}| \le |\mathbb{R}|$. By the Cantor–Bernstein theorem,
$$|\mathbb{R}^{\mathbb{N}}| = |\mathbb{R}|.$$

Equivalently, via cardinal arithmetic:
$$|\mathbb{R}^{\mathbb{N}}| = (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0\cdot\aleph
_0} = 2^{\aleph_0} = |\mathbb{R}|.$$

So the infinite product $\prod_{i=0}^{\infty}\mathbb{R}$ **does** have the same
cardinality as $\mathbb{R}$.
