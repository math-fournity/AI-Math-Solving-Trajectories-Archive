Looking at this problem, I need to determine whether two non-isomorphic finite g
roups of the same order can share the same power-graph invariant $\operatorname{
Pv}$.

**Answer: Yes.**

**Proof.**

Let $p \geq 3$ be a prime. Define:
- $G = (\mathbb{Z}/p\mathbb{Z})^3$, the elementary abelian group of order $p^3$.
- $H = \bigl\langle a, b, c \mid a^p = b^p = c^p = 1,\; [a,b] = c,\; [a,c] = [b,
c] = 1 \bigr\rangle$, the Heisenberg group of order $p^3$ (upper unitriangular $
3\times 3$ matrices over $\mathbb{F}_p$).

We interpret $\operatorname{Pv}(G)$ as the **power graph** of $G$: vertices are
the elements of $G$, with $x \sim y$ iff $x \in \langle y \rangle$ or $y \in \la
ngle x \rangle$.

---

**Step 1 — $|G| = |H| = p^3$.**  Clear: $G$ is a 3-dimensional $\mathbb{F}_p$-ve
ctor space; every element of $H$ is uniquely $a^i b^j c^k$ with $0 \le i,j,k < p
$.

**Step 2 — $G \not\cong H$.**  $G$ is abelian; $H$ is not, since $[a,b] = c \neq
 1$.

**Step 3 — Both groups have exponent $p$.**  For $G$ this is immediate.  For $H$
: every element is $a^i b^j c^k$.  Since $H$ has nilpotency class 2 and $p \geq
3$, the collection formula gives
$$(a^i b^j c^k)^p = a^{ip}\, b^{jp}\, c^{kp}\, [b^j, a^i]^{\binom{p}{2}} = c^{-i
j \cdot p(p-1)/2} = 1,$$
because $p \mid \tfrac{p(p-1)}{2}$ for $p \geq 3$.  So every element has order d
ividing $p$, and $a$ has order exactly $p$.

**Step 4 — $\operatorname{Pv}(G) \cong \operatorname{Pv}(H)$.**  In both groups,
 every non-identity element has order $p$.  Therefore:

1. **Identity is universal:** the identity belongs to every cyclic subgroup, so
it is adjacent to all other $p^3 - 1$ vertices.

2. **Adjacency among non-identity elements:** for $x, y \neq 1$, both $\langle x
 \rangle$ and $\langle y \rangle$ are cyclic of prime order $p$.  Then $x \in \l
angle y \rangle \iff \langle x \rangle = \langle y \rangle$.  So $x \sim y$ iff
they generate the **same** cyclic subgroup.

3. **Clique structure:** each cyclic subgroup of order $p$ contains $p-1$ non-id
entity elements forming a clique $K_{p-1}$.  Distinct cyclic subgroups of order
$p$ intersect trivially, so there are **no edges** between different cliques.

4. **Number of cliques:** the $p^3 - 1$ non-identity elements are partitioned in
to cyclic subgroups of order $p$, each contributing $p-1$ elements.  The count i
s
$$\frac{p^3 - 1}{p - 1} = p^2 + p + 1.$$

Thus the power graph of **both** $G$ and $H$ is:
$$K_1 \;\vee\; \bigl((p^2+p+1)\;\text{copies of}\; K_{p-1}\bigr),$$
a single universal vertex joined to $p^2+p+1$ mutually non-adjacent cliques of s
ize $p-1$.

This is the same graph, so $\operatorname{Pv}(G) \cong \operatorname{Pv}(H)$.

---

**Conclusion.**  $G = (\mathbb{Z}/p\mathbb{Z})^3$ and $H = $ Heisenberg group of
 order $p^3$ (for any prime $p \geq 3$) satisfy:
- $|G| = |H| = p^3$,
- $\operatorname{Pv}(G) = \operatorname{Pv}(H)$ (isomorphic power graphs),
- $G \not\cong H$ (one abelian, one not).

Hence such groups exist. $\blacksquare$
