## Finding the Invariant Space

A weighting $w$ is an invariant iff for every valid $(i,j)$:
$$w_{i,j} + w_{i+1,j} + w_{i+1,j+1} = 0 \quad \text{and} \quad w_{i,j} + w_{i,j+
1} + w_{i+1,j+1} = 0.$$

**Subtracting (XOR):** $w_{i+1,j} = w_{i,j+1}$, so $w$ is constant on anti-diago
nals: $w_{i,j} = a_{i+j}$.

**Substituting back:** $a_k + a_{k+1} + a_{k+2} = 0$ for $k = 2, \ldots, m{+}n{-
}2$, giving the recurrence $a_{k+2} = a_k + a_{k+1}$ over $\mathbb{F}_2$, which
has **period 3**: $(a_2, a_3, a_4, a_5, \ldots) = (a, b, a{+}b, a, b, a{+}b, \ld
ots)$.

The invariant space is **2-dimensional** (parameterized by $a_2 = a$, $a_3 = b$)
, since $m,n \ge 2$ ensures $m+n \ge 4$.

## Orthogonality Condition

$$a\cdot(S_2 + S_1) + b\cdot(S_0 + S_1).$$

This vanishes for all $(a,b)$ iff $S_0 \equiv S_1 \equiv S_2 \pmod{2}$.
