## 解题思路自检

问题文本仅包含问题陈述（“√2 是否是形如 ∛n − ∛m 的数列的极限？”）。没有泄露答案、
证明草图或形式化说明。可以放心解答。

## 证明

**答案：是的。** 我们明确构造了非负整数序列 $(n_k, m_k)$，使得 $\sqrt[3]{n_k} -
\sqrt[3]{m_k} \to \sqrt{2}$。

**构造。** 对于 $k = 1, 2, 3, \dots$，令
$$m_k = k^3, \qquad n_k = \bigl\lfloor (k + \sqrt{2})^3 \bigr\rfloor.$$
两者都是非负整数。我们证明 $\sqrt[3]{n_k} - \sqrt[3]{m_k} \to \sqrt{2}$。

**展开。**
$$(k+\sqrt{2})^3 = k^3 + 3k^2\sqrt{2} + 3k\cdot 2 + 2\sqrt{2} = \underbrace{(k^3
 + 6k)}_{\in\,\mathbb{Z}} + (3k^2+2)\sqrt{2}.$$
记 $r_k = \{(3k^2+2)\sqrt{2}\} \in [0,1)$ 为小数部分。由于 $k^3+6k$ 是整数，
$$n_k = (k+\sqrt{2})^3 - r_k, \qquad 0 \le r_k < 1.$$

**误差估计。** 那么
$$\sqrt[3]{n_k} = \bigl((k+\sqrt{2})^3 - r_k\bigr)^{1/3} = (k+\sqrt{2})\left(1 -
 \frac{r_k}{(k+\sqrt{2})^3}\right)^{1/3}.$$
对于较大的 $k$，有 $r_k/(k+\sqrt{2})^3 < 1/k^3 \to 0$，因此根据 Taylor 展开 $(1-
x)^{1/3} = 1 - \tfrac{x}{3} + O(x^2)$，
$$\sqrt[3]{n_k} = (k+\sqrt{2})\left(1 - \frac{r_k}{3(k+\sqrt{2})^3} + O(k^{-6})\
right) = (k+\sqrt{2}) - \frac{r_k}{3(k+\sqrt{2})^2} + O(k^{-5}).$$

**结论。** 由于 $\sqrt[3]{m_k} = k$，
$$\sqrt[3]{n_k} - \sqrt[3]{m_k} = \sqrt{2} - \frac{r_k}{3(k+\sqrt{2})^2} + O(k^{
-5}).$$
界限 $0 \le r_k < 1$ 给出了 $\left|\frac{r_k}{3(k+\sqrt{2})^2}\right| \le \frac{
1}{3(k+\sqrt{2})^2} \to 0$，且 $O(k^{-5}) \to 0$。因此
$$\sqrt[3]{n_k} - \sqrt[3]{m_k} \;\longrightarrow\; \sqrt{2}. \qquad \blacksquar
e$$

**数值验证**（仅作合理性检查，非证明的一部分）：
- $k=1$: $n_1 = \lfloor 7+5\sqrt2\rfloor = 14$, $m_1=1$; $\sqrt[3]{14}-1 \approx
 1.410$ vs $\sqrt2 \approx 1.41421$.
- $k=2$: $n_2 = \lfloor 20+14\sqrt2\rfloor = 39$, $m_2=8$; $\sqrt[3]{39}-2 \appr
ox 1.391$ — 等等，让我重新检查：$\sqrt[3]{39}\approx 3.391$, $3.391 - 2 = 1.391$
。误差 $\approx 0.023$。
- $k=10$: $n_{10}=\lfloor 1060+302\sqrt2\rfloor = 1487$, $m_{10}=1000$; $\sqrt[3
]{1487}-10 \approx 1.418$, 误差 $\approx 0.004$.

误差呈 $O(1/k^2)$ 缩减，与界限 $\frac{1}{3(k+\sqrt2)^2}$ 一致。
