# Problem

A high-tech server room contains a row of 100 cooling fans, uniquely indexed with identification numbers from 1 to 100. Each fan is equipped with a dual-mode indicator light that can toggle between a "Standard Red" alert and a "Cautionary Yellow" warning. Initially, as the system boots up, every single fan is set to display its "Standard Red" light.

The system administrator, seeking to run a diagnostic, executes two sequential override commands:
1. First, the administrator sends a toggle signal to every fan whose identification number is an even number.
2. Second, the administrator sends a toggle signal to every fan whose identification number is a multiple of 3.

Whenever a fan receives a toggle signal, its light flips from its current color to the other (Red turns to Yellow, or Yellow turns to Red). After both commands have been fully processed by the system, how many fans are still displaying the "Standard Red" light?
