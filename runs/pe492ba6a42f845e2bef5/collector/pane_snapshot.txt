## Proof

Let $L$ be a semi-simple Lie algebra over $\mathbb{R}$ with $\dim_{\mathbb{R}} L
 = d$. Its complexification is
$$L_{\mathbb{C}} = L \otimes_{\mathbb{R}} \mathbb{C}.$$

**Step 1: Choose a real basis.** Since $\dim_{\mathbb{R}} L = d$, there exists a
n $\mathbb{R}$-basis $\{e_1, \dots, e_d\}$ of $L$.

**Step 2: The same set spans $L_{\mathbb{C}}$ over $\mathbb{C}$.** Every element
 of $L_{\mathbb{C}}$ is a finite $\mathbb{R}$-linear combination of pure tensors
 $x \otimes z$ with $x \in L$, $z \in \mathbb{C}$. Writing $x = \sum_i a_i e_i$
($a_i \in \mathbb{R}$) and $z = \alpha + i\beta$ ($\alpha,\beta \in \mathbb{R}$)
,
$$x \otimes z = \sum_i e_i \otimes (a_i z) = \sum_i (a_i z)\,(e_i \otimes 1),$$
where we use the standard identification $e_i \otimes z = z(e_i \otimes 1)$. Thu
s every element is a $\mathbb{C}$-linear combination of $\{e_1 \otimes 1, \dots,
 e_d \otimes 1\}$, so this set spans $L_{\mathbb{C}}$ over $\mathbb{C}$.

**Step 3: Linear independence over $\mathbb{C}$.** Suppose $\sum_{i=1}^d c_i (e_
i \otimes 1) = 0$ with $c_i \in \mathbb{C}$. Write $c_i = \alpha_i + i\beta_i$ w
ith $\alpha_i, \beta_i \in \mathbb{R}$. Then
$$\sum_i \alpha_i (e_i \otimes 1) + \sum_i \beta_i (e_i \otimes i) = 0.$$
Under the canonical isomorphism of real vector spaces $L \otimes_{\mathbb{R}} \m
athbb{C} \cong L \oplus L$ (sending $x \otimes (\alpha + i\beta) \mapsto (\alpha
 x, \beta x)$), this becomes
$$(\textstyle\sum_i \alpha_i e_i,\; \textstyle\sum_i \beta_i e_i) = (0,0).$$
Since $\{e_i\}$ is $\mathbb{R}$-linearly independent, $\alpha_i = 0$ and $\beta_
i = 0$ for all $i$, hence $c_i = 0$. So $\{e_1 \otimes 1, \dots, e_d \otimes 1\}
$ is $\mathbb{C}$-linearly independent.

**Step 4: Conclusion.** The $d$ elements $\{e_1 \otimes 1, \dots, e_d \otimes 1\
}$ form a $\mathbb{C}$-basis of $L_{\mathbb{C}}$. Therefore
$$\dim_{\mathbb{C}}(L_{\mathbb{C}}) = \dim_{\mathbb{C}}(L \otimes_{\mathbb{R}} \
mathbb{C}) = \dim_{\mathbb{R}} L = d.$$

Note that semi-simplicity plays no role here; the result holds for any finite-di
mensional real Lie algebra (indeed any finite-dimensional real vector space). Co
mplexification extends scalars from $\mathbb{R}$ to $\mathbb{C}$, which preserve
s the dimension count since $\mathbb{C}$ is a $2$-dimensional real vector space
but a $1$-dimensional complex vector space over itself.

$$\boxed{\dim_{\mathbb{C}} L_{\mathbb{C}} = d}$$
