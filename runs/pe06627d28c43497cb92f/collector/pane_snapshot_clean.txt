Looking at this problem, I need to determine whether there exist measurable sets
 $A$ (positive measure) and $B$ (zero measure) such that $A+B$ contains an inter
val.

**Answer: Yes.** Here is the construction and proof.

---

## Construction

Let $C \subset [0,1]$ be the standard middle-thirds Cantor set. Let $S \subset [
1,2]$ be a translated Smith–Volterra–Cantor (fat Cantor) set. Define:
- $A = C \cup S$
- $B = C$

## Verification

### $B$ has measure zero
The standard Cantor set $C$ is obtained by repeatedly removing middle thirds; th
e total removed is $\sum_{n=1}^{\infty} 2^{n-1}/3^n = 1$, so $m(C) = 0$.

### $A$ has positive measure
The Smith–Volterra–Cantor set $S$ is constructed on $[1,2]$ by: at step $n$, rem
oving $2^{n-1}$ open middle intervals each of length $1/4^n$. Total removed:
$$\sum_{n=1}^{\infty} \frac{2^{n-1}}{4^n} = \sum_{n=1}^{\infty} \frac{1}{2^{n+1}
} = \frac{1}{2}.$$
So $m(S) = 1 - 1/2 = 1/2$. Since $C \subset [0,1]$ and $S \subset [1,2]$ are dis
joint:
$$m(A) = m(C) + m(S) = 0 + \tfrac{1}{2} = \tfrac{1}{2} > 0.$$

### $A$ and $B$ are measurable
$C$ and $S$ are both closed (complements of unions of open intervals), so $A = C
 \cup S$ and $B = C$ are measurable.

### $A$ has empty interior (non-triviality)
Both $C$ and $S$ are nowhere dense. Since they lie in the disjoint intervals $[0
,1]$ and $[1,2]$, any interval $I \subset [0,2]$ must intersect the complement o
f $A$: if $I \subset [0,1]$, then $I \not\subset C$ (since $C$ has empty interio
r); if $I \subset [1,2]$, then $I \not\subset S$; if $I$ straddles $1$, it conta
ins points in $(0,1)\setminus C$, which are not in $A$. So $A$ contains no inter
val.

### $A + B$ contains an interval

Since $C \subset A$ and $B = C$, we have $A + B \supseteq C + C$. It remains to
prove:

**Claim:** $C + C = [0, 2]$.

**Proof of Claim.** The Cantor set admits the representation:
$$C = \left\{\sum_{n=1}^{\infty} \frac{2a_n}{3^n} : a_n \in \{0, 1\}\right\}.$$

For $x = \sum \frac{2a_n}{3^n}, \, y = \sum \frac{2b_n}{3^n} \in C$ (with $a_n,
b_n \in \{0,1\}$):
$$x + y = \sum_{n=1}^{\infty} \frac{2(a_n + b_n)}{3^n}, \qquad a_n + b_n \in \{0
, 1, 2\}.$$

Conversely, for any sequence $(c_n)$ with $c_n \in \{0,1,2\}$, we can find $a_n,
 b_n \in \{0,1\}$ with $a_n + b_n = c_n$ (namely $a_n = \min(c_n, 1)$, $b_n = c_
n - a_n$). Therefore:
$$C + C = \left\{\sum_{n=1}^{\infty} \frac{2c_n}{3^n} : c_n \in \{0, 1, 2\}\righ
t\} = 2\left\{\sum_{n=1}^{\infty} \frac{c_n}{3^n} : c_n \in \{0, 1, 2\}\right\}.
$$

The set $\left\{\sum \frac{c_n}{3^n} : c_n \in \{0,1,2\}\right\}$ is exactly $[0
,1]$, since every real number in $[0,1]$ has a base-$3$ expansion with digits in
 $\{0,1,2\}$ (the maximum is $\sum \frac{2}{3^n} = 1$; existence follows from th
e standard base-$3$ representation, with the convention that dyadic-rational ana
logues use the non-terminating expansion, which also has digits in $\{0,1,2\}$).

Hence $C + C = 2 \cdot [0,1] = [0,2]$. $\square$

### Conclusion

$$A + B \supseteq C + C = [0, 2],$$

so $A + B$ contains the interval $[0,2]$.

We have constructed measurable sets $A$ (with $m(A) = 1/2 > 0$ and empty interio
r) and $B$ (with $m(B) = 0$) such that $A + B$ contains an interval. Notably, $A
$ itself contains no interval, making the result non-trivial.
