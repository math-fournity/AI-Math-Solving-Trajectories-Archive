## Solution

The curve is $C: r(t) = (\cos t,\, \sin t,\, t)$ for $-\pi \le t \le \pi$.

Compute the needed pieces:
- $x = \cos t,\quad y = \sin t,\quad z = t$
- $x^2 + y^2 = \cos^2 t + \sin^2 t = 1$
- $dx = -\sin t\,dt,\quad dy = \cos t\,dt,\quad dz = dt$

Substitute into the integrand:

$$y(x^2+y^2)\,dx = \sin t \cdot 1 \cdot (-\sin t\,dt) = -\sin^2 t\,dt$$

$$-x(x^2+y^2)\,dy = -\cos t \cdot 1 \cdot (\cos t\,dt) = -\cos^2 t\,dt$$

$$xy\,dz = \cos t\,\sin t\,dt$$

Summing:

$$-\sin^2 t\,dt - \cos^2 t\,dt + \cos t\sin t\,dt = -(\sin^2 t + \cos^2 t)\,dt +
 \cos t\sin t\,dt$$

$$= -\,dt + \cos t\sin t\,dt$$

Now integrate over $[-\pi, \pi]$:

$$\int_{-\pi}^{\pi} (-1)\,dt = -2\pi$$

$$\int_{-\pi}^{\pi} \cos t\sin t\,dt = \frac{1}{2}\int_{-\pi}^{\pi}\sin 2t\,dt =
 0$$

since $\sin 2t$ is an odd function over the symmetric interval $[-\pi,\pi]$.

Therefore:

$$\int_C y(x^2+y^2)\,dx - x(x^2+y^2)\,dy + xy\,dz = -2\pi + 0 = \boxed{-2\pi}$$
