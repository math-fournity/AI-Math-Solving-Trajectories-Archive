## Proof

We work in $\mathbb{R}^2$ with the Lebesgue outer measure $m^*$, defined for $A\
subseteq\mathbb{R}^2$ by
$$m^*(A)=\inf\left\{\sum_{k=1}^{\infty}|R_k|:\; A\subseteq\bigcup_{k=1}^{\infty}
R_k,\; R_k\text{ rectangles}\right\}.$$

**Step 1. Each vertical line $\{q\}\times\mathbb{R}$ has outer measure $0$.**

Fix $q\in\mathbb{Q}$. For each $n\in\mathbb{N}$, the segment $\{q\}\times[-n,n]$
 is contained in the rectangle $[q-\varepsilon/2^{n+2},\, q+\varepsilon/2^{n+2}]
\times[-n,n]$, whose area is
$$\frac{\varepsilon}{2^{n+1}}\cdot 2n = \frac{\varepsilon n}{2^n}.$$
Hence
$$\{q\}\times\mathbb{R}=\bigcup_{n=1}^{\infty}\{q\}\times[-n,n]\subseteq\bigcup_
{n=1}^{\infty}\left[q-\frac{\varepsilon}{2^{n+2}},\,q+\frac{\varepsilon}{2^{n+2}
}\right]\times[-n,n],$$
and by countable subadditivity,
$$m^*(\{q\}\times\mathbb{R})\le\sum_{n=1}^{\infty}\frac{\varepsilon n}{2^n}=\var
epsilon\sum_{n=1}^{\infty}\frac{n}{2^n}=2\varepsilon.$$
Since $\varepsilon>0$ is arbitrary, $m^*(\{q\}\times\mathbb{R})=0$. By symmetry,
 each horizontal line $\mathbb{R}\times\{q\}$ also has outer measure $0$.

**Step 2. $\mathbb{Q}\times\mathbb{R}$ has outer measure $0$.**

Enumerate $\mathbb{Q}=\{q_1,q_2,\dots\}$. Then
$$\mathbb{Q}\times\mathbb{R}=\bigcup_{k=1}^{\infty}\{q_k\}\times\mathbb{R}.$$
By countable subadditivity and Step 1,
$$m^*(\mathbb{Q}\times\mathbb{R})\le\sum_{k=1}^{\infty}m^*(\{q_k\}\times\mathbb{
R})=\sum_{k=1}^{\infty}0=0.$$
Thus $m^*(\mathbb{Q}\times\mathbb{R})=0$. Similarly, $m^*(\mathbb{R}\times\mathb
b{Q})=0$.

**Step 3. $E=(\mathbb{Q}\times\mathbb{R})\cup(\mathbb{R}\times\mathbb{Q})$ has o
uter measure $0$.**

By countable subadditivity,
$$m^*(E)\le m^*(\mathbb{Q}\times\mathbb{R})+m^*(\mathbb{R}\times\mathbb{Q})=0+0=
0.$$

Since outer measure is non-negative, $m^*(E)=0$.

$$\boxed{m^*(E)=0}$$
