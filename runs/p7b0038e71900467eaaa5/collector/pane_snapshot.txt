## Proof

Let $a_n$ denote the $n$th positive integer that is not a perfect square. We pro
ve $a_n = n + \{\sqrt{n}\}$, where $\{m\}$ is the nearest integer to $m$.

**Key observation.** For any positive integer $N$, the number of perfect squares
 in $\{1,2,\dots,N\}$ is $\lfloor\sqrt{N}\rfloor$. Hence the number of non-perfe
ct-squares in $\{1,\dots,N\}$ is
$$f(N) = N - \lfloor\sqrt{N}\rfloor.$$

The function $f$ is non-decreasing: $f(N+1)-f(N) = 1$ when $N+1$ is not a perfec
t square, and $f(N+1)-f(N)=0$ when $N+1$ is a perfect square. Therefore $a_n$ is
 the unique non-square $N$ with $f(N)=n$.

**Setting up.** Let $k = \{\sqrt{n}\}$. We must show:
1. $n+k$ is not a perfect square, and
2. $\lfloor\sqrt{n+k}\rfloor = k$ (so that $f(n+k) = (n+k)-k = n$).

**$\{\sqrt{n}\}$ is well-defined.** If $\sqrt{n}$ were a half-integer, say $\sqr
t{n} = j+\tfrac12$, then $n = j^2+j+\tfrac14$, which is not an integer — contrad
iction. So $\sqrt{n}$ is never a half-integer, and the nearest integer is unique
.

**Range of $n$ for a given $k$.** Since $k$ is the nearest integer to $\sqrt{n}$
:
$$k - \tfrac12 < \sqrt{n} < k + \tfrac12 \implies (k-\tfrac12)^2 < n < (k+\tfrac
12)^2,$$
$$k^2 - k + \tfrac14 < n < k^2 + k + \tfrac14.$$
Since $n$ is an integer:
$$k^2 - k + 1 \le n \le k^2 + k. \tag{$\star$}$$

**Verifying (1): $n+k$ is not a perfect square.** From $(\star)$:
$$k^2 + 1 \le n + k \le k^2 + 2k.$$
The perfect squares bordering this interval are $k^2$ (below) and $(k+1)^2 = k^2
+2k+1$ (above). Neither lies in $[k^2+1,\; k^2+2k]$, so $n+k$ is not a perfect s
quare. ✓

**Verifying (2): $\lfloor\sqrt{n+k}\rfloor = k$.** From the same bounds:
$$k^2 \le k^2+1 \le n+k \le k^2+2k < k^2+2k+1 = (k+1)^2.$$
Thus $k^2 \le n+k < (k+1)^2$, giving $\lfloor\sqrt{n+k}\rfloor = k$. ✓

**Conclusion.** We have shown $f(n+k) = (n+k) - k = n$ and $n+k$ is not a perfec
t square. Since $a_n$ is the unique non-square $N$ with $f(N)=n$, we conclude
$$a_n = n + k = n + \{\sqrt{n}\}.$$

$\blacksquare$
