## Solution

**Problem.** Minimize $\int_0^1 y'^2\,dx$ subject to $y(0)=y(1)=0$ and $\int_0^1
 y^2\,dx=1$.

### Step 1 — Set up the isoperimetric variational problem

This is a constrained (isoperimetric) variational problem. Introducing a Lagrang
e multiplier $\lambda$ for the integral constraint, the augmented Lagrangian is

$$L = y'^2 + \lambda\, y^2.$$

The Euler–Lagrange equation is

$$\frac{\partial L}{\partial y} - \frac{d}{dx}\frac{\partial L}{\partial y'} = 0
 \;\\Longrightarrow\; 2\lambda y - \frac{d}{dx}(2y') = 0 \;\\Longrightarrow\; y'
' = \lambda y.$$

### Step 2 — Solve the ODE with boundary conditions

**Case $\lambda > 0$** ($\lambda=\mu^2$): $y = A\cosh(\mu x)+B\sinh(\mu x)$. The
n $y(0)=0\Rightarrow A=0$, and $y(1)=0\Rightarrow B\sinh\mu=0\Rightarrow B=0$. T
rivial — violates $\int y^2=1$.

**Case $\lambda = 0$**: $y''=0\Rightarrow y=Ax+B$; boundary conditions force $A=
B=0$. Trivial.

**Case $\lambda < 0$** (write $\lambda=-\mu^2$, $\mu>0$): $y''=-\mu^2 y$, giving

$$y = A\cos(\mu x) + B\sin(\mu x).$$

From $y(0)=0$: $A=0$. From $y(1)=0$: $B\sin\mu=0$. For a **nontrivial** solution
 we need $\sin\mu=0$, i.e.

$$\mu = n\pi,\quad n=1,2,3,\dots \qquad\Longrightarrow\qquad \lambda = -n^2\pi^2
.$$

So the extremals are $y_n(x) = B\sin(n\pi x)$.

### Step 3 — Apply the normalization constraint

$$\int_0^1 y_n^2\,dx = B^2\int_0^1\sin^2(n\pi x)\,dx = B^2\cdot\tfrac{1}{2} = 1
\;\Longrightarrow\; B^2 = 2.$$

### Step 4 — Evaluate the functional

With $y_n' = Bn\pi\cos(n\pi x)$:

$$\int_0^1 y_n'^2\,dx = B^2 n^2\pi^2\int_0^1\cos^2(n\pi x)\,dx = 2\cdot n^2\pi^2
\cdot\tfrac{1}{2} = n^2\pi^2.$$

Equivalently, multiplying $y''=\lambda y$ by $y$ and integrating by parts (bound
ary term $[yy']_0^1=0$ vanishes since $y(0)=y(1)=0$):

$$\int_0^1 y\,y''\,dx = \lambda\int_0^1 y^2\,dx \;\Longrightarrow\; -\int_0^1 y'
^2\,dx = \lambda\cdot 1 \;\Longrightarrow\; \int_0^1 y'^2\,dx = -\lambda = n^2\p
i^2.$$

### Step 5 — Select the minimum

Among the stationary values $\{n^2\pi^2 : n=1,2,3,\dots\}$, the smallest is atta
ined at $n=1$:

$$\boxed{\min \int_0^1 y'^2\,dx = \pi^2}.$$

### Step 6 — Confirm this is a true minimum (not merely stationary)

The operator $-\tfrac{d^2}{dx^2}$ on $[0,1]$ with Dirichlet boundary conditions
is self-adjoint and positive-definite, with eigenvalues $n^2\pi^2$ and eigenfunc
tions $\sin(n\pi x)$. For any admissible $y$ (i.e. $y\in H_0^1[0,1]$, $\|y\|_{L^
2}=1$), expanding in this eigenbasis $y=\sum c_n\sin(n\pi x)$ with $\sum c_n^2/2
=1$:

$$\int_0^1 y'^2\,dx = \sum_{n} n^2\pi^2\cdot\tfrac{c_n^2}{2} \;\geq\; \pi^2\sum_
n\tfrac{c_n^2}{2} = \pi^2,$$

with equality **if and only if** $c_n=0$ for all $n\geq 2$, i.e. $y(x)=\sqrt{2}\
sin(\pi x)$. This is precisely the Wirtinger (Poincaré) inequality on $[0,1]$, c
onfirming the minimum is global.

### Summary

- **Euler–Lagrange (augmented) equation:** $y'' = \lambda y$.
- **Boundary conditions** $y(0)=y(1)=0$ force $\lambda = -n^2\pi^2$, giving extr
emals $y_n = \sqrt{2}\sin(n\pi x)$.
- **Functional value** at each extremal: $n^2\pi^2$.
- **Minimum** (at $n=1$, achieved by $y(x)=\sqrt{2}\sin\pi x$):

$$\boxed{\pi^2}$$
