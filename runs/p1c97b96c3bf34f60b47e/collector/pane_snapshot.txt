We seek the supremum of $\int_0^1 f(t^a)\,dt$ over measurable $f$ with $\int_0^1
 |f(t)|\,dt \leq 1$, where $0 < a < 1$ is fixed.

### Step 1: Change of variables

Set $u = t^a$, so $t = u^{1/a}$ and $dt = \frac{1}{a}\,u^{1/a-1}\,du$. As $t: 0\
to 1$, we have $u: 0\to 1$. Thus

$$\int_0^1 f(t^a)\,dt = \int_0^1 f(u)\,w(u)\,du, \qquad w(u) := \frac{1}{a}\,u^{
1/a - 1}.$$

Since $0<a<1$, we have $1/a > 1$, so the exponent $1/a - 1 = \frac{1-a}{a} > 0$.
 Hence $w$ is continuous and **increasing** on $[0,1]$, with $w(0)=0$ and $w(1)
= \tfrac{1}{a}$. Also

$$\int_0^1 w(u)\,du = \frac{1}{a}\cdot\frac{u^{1/a}}{1/a}\Big|_0^1 = 1,$$

so $w$ is a probability density on $[0,1]$.

### Step 2: Reformulation as an $L^1$–$L^\infty$ duality problem

The problem becomes:

$$\sup\left\{\int_0^1 f(u)\,w(u)\,du \;:\; \int_0^1 |f(u)|\,du \leq 1\right\}.$$

This is the operator norm of the linear functional $T(f) = \int_0^1 f\,w\,du$ on
 $L^1([0,1])$, which equals $\|w\|_{L^\infty}$.

### Step 3: Upper bound

For any admissible $f$,

$$\left|\int_0^1 f(u)\,w(u)\,du\right| \leq \int_0^1 |f(u)|\,|w(u)|\,du \leq \|w
\|_\infty \int_0^1 |f(u)|\,du \leq \|w\|_\infty.$$

Since $w$ is increasing and continuous on $[0,1]$,

$$\|w\|_\infty = w(1) = \frac{1}{a}.$$

### Step 4: The bound is attained (as a supremum)

For $n\geq 1$, define $f_n(u) = n\cdot\mathbf{1}_{[1-1/n,\,1]}(u)$. Then $\int_0
^1 |f_n|\,du = 1$, so $f_n$ is admissible, and

$$\int_0^1 f_n(u)\,w(u)\,du = n\int_{1-1/n}^{1} w(u)\,du.$$

Since $w$ is continuous at $u=1$, by the mean value theorem for integrals this e
quals $w(\xi_n)$ for some $\xi_n \in [1-1/n, 1]$, and as $n\to\infty$, $\xi_n\to
 1$, so

$$n\int_{1-1/n}^{1} w(u)\,du \;\longrightarrow\; w(1) = \frac{1}{a}.$$

### Conclusion

The supremum is

$$\boxed{\dfrac{1}{a}}.$$
