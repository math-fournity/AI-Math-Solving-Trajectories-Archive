# Solution: Laplace's Equation in a Half-Cylinder

## (a) PDE and Boundary Conditions

**Domain:** $\Omega = \{(r,\theta,z) : 0 < r < a,\; 0 < \theta < \pi,\; 0 < z <
H\}$.

**PDE** (Laplace's equation in cylindrical coordinates):

$$\frac{1}{r}\frac{\partial}{\partial r}\!\left(r\frac{\partial T}{\partial r}\r
ight) + \frac{1}{r^2}\frac{\partial^2 T}{\partial \theta^2} + \frac{\partial^2 T
}{\partial z^2} = 0, \quad (r,\theta,z)\in\Omega.$$

**Boundary conditions:**

| Surface | Condition | Physical meaning |
|---|---|---|
| $r = a$, $0<\theta<\pi$, $0<z<H$ | $T = 0$ | Side held at $0°$C |
| $z = 0$, $0<r<a$, $0<\theta<\pi$ | $\dfrac{\partial T}{\partial z} = 0$ | Bott
om disk insulated |
| $z = H$, $0<r<a$, $0<\theta<\pi$ | $T = f(r,\theta)$ | Top half-disk: prescrib
ed temperature |
| $\theta = 0$, $0<r<a$, $0<z<H$ | $\dfrac{1}{r}\dfrac{\partial T}{\partial \the
ta} = 0$ | Flat side insulated |
| $\theta = \pi$, $0<r<a$, $0<z<H$ | $\dfrac{1}{r}\dfrac{\partial T}{\partial \t
heta} = 0$ | Flat side insulated |
| $r = 0$ | $T$ bounded | Regularity at the axis |

---

## (b) Solution by Separation of Variables

### Step 1. Separate variables

Set $T = R(r)\,\Theta(\theta)\,Z(z)$ and substitute into the PDE:

$$\frac{(rR')'}{rR} + \frac{\Theta''}{r^2\Theta} + \frac{Z''}{Z} = 0.$$

**$\theta$-equation.** With $\Theta'' + m^2\Theta = 0$ and the Neumann condition
s $\Theta'(0)=\Theta'(\pi)=0$:

$$\Theta_m(\theta) = \cos(m\theta), \qquad m = 0,1,2,\dots$$

($\Theta'(0)=0$ eliminates $\sin$; $\Theta'(\pi)=-m\sin(m\pi)=0$ is automatic fo
r integer $m$.)

**$z$-equation.** Set $Z'' = \lambda Z$ with $Z'(0)=0$ (insulated bottom). We tr
y $\lambda = \mu^2 > 0$ (the sign is forced by the $r$-equation, as shown below)
:

$$Z(\mu z) = \cosh(\mu z) \quad (\text{since } Z'(0)=0 \text{ kills the }\sinh\t
ext{ term}).$$

The case $\lambda = 0$ gives $Z = \text{const}$, but then the $r$-equation yield
s only the trivial solution (see Step 3), so there is no $\lambda=0$ eigenmode.

**$r$-equation.** Substituting $\Theta''/r^2\Theta = -m^2/r^2$ and $Z''/Z = \mu^
2$:

$$r^2 R'' + rR' + (\mu^2 r^2 - m^2)R = 0.$$

This is **Bessel's equation** of order $m$. Boundedness at $r=0$ selects $J_m$ (
rejecting $Y_m$):

$$R(r) = J_m(\mu r).$$

### Step 2. Eigenvalues from the side condition $T(a,\theta,z)=0$

$$J_m(\mu\, a) = 0 \quad\Longrightarrow\quad \mu_{m,k} = \frac{j_{m,k}}{a}, \qqu
ad k=1,2,3,\dots$$

where $j_{m,k}$ is the $k$-th positive zero of $J_m$.

**Why $\lambda > 0$ is forced.** If we had tried $\lambda = -\mu^2 < 0$, the $r$
-equation would become the *modified* Bessel equation $r^2R''+rR'-(\mu^2 r^2+m^2
)R=0$ with bounded solution $I_m(\mu r)$. But $I_m(x)>0$ for all $x>0$, so $I_m(
\mu a)=0$ has no positive root—no eigenvalues. Hence only $\lambda = +\mu^2$ wor
ks.

### Step 3. No $\lambda = 0$ mode

For $\lambda=0$: $Z=\text{const}$, and the $r$-equation is Euler's equation $r^2
R''+rR'-m^2R=0$.
- $m=0$: $R = C_1 + C_2\ln r$; boundedness $\Rightarrow C_2=0$; $R(a)=0\Rightarr
ow C_1=0$. Trivial.
- $m\geq 1$: $R = C_1 r^m + C_2 r^{-m}$; boundedness $\Rightarrow C_2=0$; $R(a)=
C_1 a^m=0\Rightarrow C_1=0$. Trivial.

### Step 4. General solution

$$\boxed{T(r,\theta,z) = \sum_{m=0}^{\infty}\sum_{k=1}^{\infty} B_{m,k}\,\frac{\
cosh\!\bigl(\frac{j_{m,k}}{a}\,z\bigr)}{\cosh\!\bigl(\frac{j_{m,k}}{a}\,H\bigr)}
\;\cos(m\theta)\;J_m\!\Bigl(\frac{j_{m,k}}{a}\,r\Bigr)}$$

### Step 5. Determine $B_{m,k}$ from $T(r,\theta,H) = f(r,\theta)$

At $z=H$ the hyperbolic ratio equals $1$, so:

$$f(r,\theta) = \sum_{m=0}^{\infty}\sum_{k=1}^{\infty} B_{m,k}\,\cos(m\theta)\,J
_m\!\Bigl(\frac{j_{m,k}}{a}\,r\Bigr).$$

This is a **Fourier–Bessel expansion**. Using the orthogonality relations:

$$\int_0^\pi \cos(m\theta)\cos(n\theta)\,d\theta = c_m\,\delta_{mn}, \qquad c_m
= \begin{cases}\pi, & m=0,\\[2pt] \pi/2, & m\geq 1,\end{cases}$$

$$\int_0^a r\,J_m\!\Bigl(\frac{j_{m,k}}{a}r\Bigr)J_m\!\Bigl(\frac{j_{m,l}}{a}r\B
igr)\,dr = \frac{a^2}{2}\bigl[J_{m+1}(j_{m,k})\bigr]^2\,\delta_{kl},$$

we multiply both sides by $\cos(n\theta)\,r\,J_n(j_{n,l}\,r/a)$ and integrate ov
er $(0,\pi)\times(0,a)$:

$$\boxed{B_{m,k} = \frac{2}{a^2\, c_m\,\bigl[J_{m+1}(j_{m,k})\bigr]^2}\int_0^\pi
\!\!\int_0^a f(r,\theta)\,\cos(m\theta)\,J_m\!\Bigl(\frac{j_{m,k}}{a}\,r\Bigr)\,
r\,dr\,d\theta}$$

or, writing $c_0=\pi$ and $c_m=\pi/2$ for $m\geq 1$ explicitly:

$$B_{0,k} = \frac{2}{\pi a^2\,[J_1(j_{0,k})]^2}\int_0^\pi\!\!\int_0^a f(r,\theta
)\,J_0\!\Bigl(\frac{j_{0,k}}{a}r\Bigr)\,r\,dr\,d\theta,$$

$$B_{m,k} = \frac{4}{\pi a^2\,[J_{m+1}(j_{m,k})]^2}\int_0^\pi\!\!\int_0^a f(r,\t
heta)\,\cos(m\theta)\,J_m\!\Bigl(\frac{j_{m,k}}{a}r\Bigr)\,r\,dr\,d\theta, \quad
 m\geq 1.$$

### Step 6. Verification of all boundary conditions

1. **$r=a$:** $J_m(j_{m,k})=0 \Rightarrow T=0$. ✓
2. **$z=0$:** $\frac{\partial}{\partial z}\cosh(\mu z)\big|_{z=0}=\mu\sinh(0)=0
\Rightarrow \partial T/\partial z=0$. ✓ (insulated)
3. **$\theta=0$:** $\frac{\partial}{\partial\theta}\cos(m\theta)\big|_{\theta=0}
=-m\sin(0)=0 \Rightarrow \partial T/\partial\theta=0$. ✓ (insulated)
4. **$\theta=\pi$:** $\frac{\partial}{\partial\theta}\cos(m\theta)\big|_{\theta=
\pi}=-m\sin(m\pi)=0 \Rightarrow \partial T/\partial\theta=0$. ✓ (insulated)
5. **$z=H$:** $\cosh(\mu H)/\cosh(\mu H)=1$, so $T=\sum B_{m,k}\cos(m\theta)J_m(
\mu r)=f(r,\theta)$. ✓
6. **$r=0$:** $J_m(0)=0$ for $m\geq 1$, $J_0(0)=1$; all terms bounded. ✓ (regula
rity)

All six boundary conditions are satisfied, and the PDE is satisfied term-by-term
 since each summand is a separated solution of Laplace's equation.
