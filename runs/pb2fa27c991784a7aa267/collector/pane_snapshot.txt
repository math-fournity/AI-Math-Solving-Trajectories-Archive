## Solution

**Answer:** $u(x) = x_1$ (the first coordinate function).

**Verification.**

Assume $N \geq 3$ (the notation $|x|^{2-N}$ is the fundamental solution of Lapla
ce's equation, which is relevant for $N\geq 3$).

**Step 1: $u$ is non-constant.** The function $u(x)=x_1$ takes different values
at different points of $B(0,1)\setminus\{0\}$ (e.g. $u((1/2,0,\dots,0))=1/2$ and
 $u((-1/2,0,\dots,0))=-1/2$), so it is non-constant.

**Step 2: $u$ is harmonic in $B(0,1)\setminus\{0\}$.** We have
$$\Delta u = \frac{\partial^2 x_1}{\partial x_1^2} + \sum_{i=2}^{N}\frac{\partia
l^2 x_1}{\partial x_i^2} = 0 + 0 = 0,$$
so $u$ is harmonic on all of $\mathbb{R}^N$, hence in particular on $B(0,1)\setm
inus\{0\}$.

**Step 3: The limit condition holds.** We must show
$$\lim_{x\to 0}\frac{u(x)}{|x|^{2-N}} = \lim_{x\to 0}\frac{x_1}{|x|^{2-N}} = \li
m_{x\to 0} x_1\,|x|^{N-2} = 0.$$

Since $|x_1| \leq |x|$, we have
$$\left|\frac{x_1}{|x|^{2-N}}\right| = |x_1|\cdot|x|^{N-2} \leq |x|\cdot|x|^{N-2
} = |x|^{N-1}.$$

For $N\geq 3$, $N-1\geq 2 > 0$, so $|x|^{N-1}\to 0$ as $x\to 0$. By the squeeze
theorem,
$$\lim_{x\to 0}\frac{u(x)}{|x|^{2-N}} = 0.$$

**Remark.** This example is consistent with the removable singularity theorem: a
ny harmonic function on a punctured domain that is $o(|x|^{2-N})$ near the punct
ure extends harmonically across the puncture. The coordinate function $x_1$ is p
recisely such an extension — it is already harmonic on the full ball, hence triv
ially $o(|x|^{2-N})$ since $|x|^{2-N}\to\infty$ while $u$ remains bounded.
