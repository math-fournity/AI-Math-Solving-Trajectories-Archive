## 证明

设 $p = 4k+1$ 为素数。我们求 $S = \sum_{i=1}^{k}\lfloor\sqrt{ip}\rfloor$。

记 $m = \frac{p-1}{2} = 2k$。

**步骤 1：$ip$ 从不是完全平方数。**

对于 $1 \le i \le k < p$，若 $ip = y^2$，则 $p \mid y^2$，故 $p \mid y$（$p$ 为
素数），从而 $p^2 \mid y^2 = ip$，即 $p \mid i$，矛盾。因此 $\lfloor\sqrt{ip}\rf
loor = \#\{y \ge 1 : y^2 < ip\}$。

**步骤 2：将 $S$ 转为格点计数并交换求和顺序。**

$$S = \sum_{i=1}^{k}\#\{y \ge 1 : y^2 \le ip\} = \#\{(i,y) : 1 \le i \le k,\; y
\ge 1,\; y^2 \le ip\}.$$

最大 $y$ 值在 $i = k$ 时取到：$\lfloor\sqrt{kp}\rfloor$。由于 $\frac{p-1}{2} \le
 \sqrt{kp} = \tfrac{1}{2}\sqrt{p(p-1)} < \frac{p+1}{2}$（前者因 $p \ge p-1$，后
者因 $p(p-1) < (p+1)^2$），故 $\lfloor\sqrt{kp}\rfloor = m$。因此：

$$S = \#\{(i,y) : 1 \le i \le k,\; 1 \le y \le m,\; y^2 \le ip\}.$$

交换求和顺序（对每个 $y$，条件为 $i \ge y^2/p$，即 $i \ge \lceil y^2/p\rceil$，
且 $\lceil y^2/p\rceil \le k$ 因 $y \le m$ 时 $y^2 \le m^2 \le kp$）：

$$S = \sum_{y=1}^{m}\bigl(k + 1 - \lceil y^2/p\rceil\bigr) = m(k+1) - \sum_{y=1}
^{m}\lceil y^2/p\rceil.$$

因 $p \nmid y^2$（$1 \le y \le m < p$），$\lceil y^2/p\rceil = \lfloor y^2/p\rfl
oor + 1$，故

$$S = m(k+1) - \sum_{y=1}^{m}\lfloor y^2/p\rfloor - m = mk - \sum_{y=1}^{m}\lflo
or y^2/p\rfloor = 2k^2 - \sum_{y=1}^{m}\lfloor y^2/p\rfloor.$$

**步骤 3：计算 $\sum_{y=1}^{m}\lfloor y^2/p\rfloor$。**

写 $y^2 = p\lfloor y^2/p\rfloor + r_y$，其中 $r_y \equiv y^2 \pmod{p}$，$1 \le r
_y \le p-1$。则

$$\sum_{y=1}^{m}\lfloor y^2/p\rfloor = \frac{1}{p}\left(\sum_{y=1}^{m}y^2 - \sum
_{y=1}^{m}r_y\right).$$

**平方和：** $\displaystyle\sum_{y=1}^{m}y^2 = \frac{m(m+1)(2m+1)}{6} = \frac{\f
rac{p-1}{2}\cdot\frac{p+1}{2}\cdot p}{6} = \frac{p(p-1)(p+1)}{24}$。

**剩余之和 $\sum r_y$：** 当 $y$ 遍历 $1, \dots, m$ 时，$r_y = y^2 \bmod p$ 恰好
遍历模 $p$ 的所有 $(p-1)/2$ 个二次剩余（每个一次，因 $y$ 与 $p-y$ 给出同一剩余而
只取一半）。

因 $p \equiv 1 \pmod{4}$，$-1$ 是模 $p$ 的二次剩余。故二次剩余集合在 $r \mapsto
p - r$ 下封闭，二次剩余两两配对为 $(r,\, p-r)$，每对和为 $p$。共有 $\frac{p-1}{4
}$ 对，因此

$$\sum_{y=1}^{m} r_y = \sum_{\text{QR}\;r} r = \frac{p(p-1)}{4}.$$

于是

$$\sum_{y=1}^{m}\lfloor y^2/p\rfloor = \frac{1}{p}\left(\frac{p(p-1)(p+1)}{24} -
 \frac{p(p-1)}{4}\right) = \frac{(p-1)(p+1)}{24} - \frac{p-1}{4} = \frac{(p-1)(p
-5)}{24}.$$

**步骤 4：合并。**

$$S = 2k^2 - \frac{(p-1)(p-5)}{24} = \frac{(p-1)^2}{8} - \frac{(p-1)(p-5)}{24} =
 \frac{(p-1)\bigl[3(p-1)-(p-5)\bigr]}{24} = \frac{(p-1)(2p+2)}{24} = \frac{(p-1)
(p+1)}{12}.$$

**验证：** $p=5$：$S = \lfloor\sqrt{5}\rfloor = 2 = 24/12$ ✓。$p=13$：$S = 3+5+6
 = 14 = 168/12$ ✓。$p=17$：$S = 4+5+7+8 = 24 = 288/12$ ✓。

$$\boxed{S = \dfrac{p^2 - 1}{12}}$$

### PROOF COMPLETE
