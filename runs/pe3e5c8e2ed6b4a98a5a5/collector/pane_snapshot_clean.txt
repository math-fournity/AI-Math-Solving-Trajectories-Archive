# Christoffel Connection for the 2-Sphere

## Setup

The metric is
$$ds^2 = d\theta^2 + \sin^2\theta\, d\phi^2.$$

Take coordinates $x^1 = \theta$, $x^2 = \phi$. The metric components and their i
nverse are

$$g_{\theta\theta} = 1, \quad g_{\phi\phi} = \sin^2\theta, \quad g_{\theta\phi}
= g_{\phi\theta} = 0,$$

$$g^{\theta\theta} = 1, \quad g^{\phi\phi} = \csc^2\theta, \quad g^{\theta\phi}
= g^{\phi\theta} = 0.$$

The only non-vanishing first derivative of any metric component is
$$\partial_\theta g_{\phi\phi} = 2\sin\theta\cos\theta.$$

## Formula

The Christoffel symbols are
$$\Gamma^{\mu}_{\nu\rho} = \tfrac{1}{2}\,g^{\mu\sigma}\bigl(\partial_\nu g_{\rho
\sigma} + \partial_\rho g_{\nu\sigma} - \partial_\sigma g_{\nu\rho}\bigr).$$

Since the metric is diagonal, for each $\mu$ only $\sigma = \mu$ contributes.

## Component-by-component computation

**$\Gamma^{\theta}_{\phi\phi}$** (set $\mu=\theta,\nu=\phi,\rho=\phi$, so $\sigm
a=\theta$):
$$\Gamma^{\theta}_{\phi\phi} = \tfrac{1}{2}\,g^{\theta\theta}\bigl(\partial_\phi
 g_{\phi\theta} + \partial_\phi g_{\phi\theta} - \partial_\theta g_{\phi\phi}\bi
gr) = \tfrac{1}{2}(1)\bigl(0 + 0 - 2\sin\theta\cos\theta\bigr) = -\sin\theta\cos
\theta.$$

**$\Gamma^{\phi}_{\theta\phi}$** (set $\mu=\phi,\nu=\theta,\rho=\phi$, so $\sigm
a=\phi$):
$$\Gamma^{\phi}_{\theta\phi} = \tfrac{1}{2}\,g^{\phi\phi}\bigl(\partial_\theta g
_{\phi\phi} + \partial_\phi g_{\theta\phi} - \partial_\phi g_{\theta\phi}\bigr)
= \tfrac{1}{2}\csc^2\theta\bigl(2\sin\theta\cos\theta + 0 - 0\bigr) = \cot\theta
.$$

**Symmetry in lower indices**: $\Gamma^{\mu}_{\nu\rho} = \Gamma^{\mu}_{\rho\nu}$
, so
$$\Gamma^{\phi}_{\phi\theta} = \Gamma^{\phi}_{\theta\phi} = \cot\theta.$$

## All other components vanish

- $\Gamma^{\theta}_{\theta\theta} = \tfrac{1}{2}g^{\theta\theta}(\partial_\theta
 g_{\theta\theta}+\partial_\theta g_{\theta\theta}-\partial_\theta g_{\theta\the
ta}) = 0$ since $g_{\theta\theta}=1$ is constant.
- $\Gamma^{\theta}_{\theta\phi} = \Gamma^{\theta}_{\phi\theta} = \tfrac{1}{2}g^{
\theta\theta}(\partial_\theta g_{\phi\theta}+\partial_\phi g_{\theta\theta}-\par
tial_\theta g_{\theta\phi}) = 0$ since $g_{\phi\theta}=0$ and $g_{\theta\theta}=
1$.
- $\Gamma^{\phi}_{\theta\theta} = \tfrac{1}{2}g^{\phi\phi}(\partial_\theta g_{\t
heta\phi}+\partial_\theta g_{\theta\phi}-\partial_\phi g_{\theta\theta}) = 0$.
- $\Gamma^{\phi}_{\phi\phi} = \tfrac{1}{2}g^{\phi\phi}(\partial_\phi g_{\phi\phi
}+\partial_\phi g_{\phi\phi}-\partial_\phi g_{\phi\phi}) = \tfrac{1}{2}g^{\phi\p
hi}\partial_\phi g_{\phi\phi} = 0$ since $g_{\phi\phi}=\sin^2\theta$ is independ
ent of $\phi$.

## Result

The non-vanishing Christoffel connection components of the 2-sphere are:

$$\boxed{\Gamma^{\theta}_{\phi\phi} = -\sin\theta\cos\theta, \qquad \Gamma^{\phi
}_{\theta\phi} = \Gamma^{\phi}_{\phi\theta} = \cot\theta.}$$

All other $\Gamma^{\mu}_{\nu\rho}$ are zero.
