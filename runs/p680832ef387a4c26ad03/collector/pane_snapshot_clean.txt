## Proof

Let $s = x + z$ and $d = z - x$. Then
$$x^2 + z^2 = \frac{(x+z)^2 + (z-x)^2}{2} = \frac{s^2 + d^2}{2} = 1,$$
so $s^2 + d^2 = 2$. The second constraint becomes
$$y^2 + 2ys = 6.$$
We want to maximize $yd$.

**Solving for $y$.** From $y^2 + 2sy - 6 = 0$:
$$y = -s \pm \sqrt{s^2 + 6}.$$
The two roots satisfy $y_1 y_2 = -6 < 0$, so they have opposite signs, and
$$|y_1| + |y_2| = |y_1 - y_2| = 2\sqrt{s^2+6}.$$

**Optimizing over $d$.** For fixed $s$ (with $|s| \le \sqrt{2}$), $d$ ranges ove
r $[-\sqrt{2-s^2},\,\sqrt{2-s^2}]$. To maximize $yd$ we choose $d = \sqrt{2-s^2}
\,\operatorname{sgn}(y)$, giving
$$\max_d\, yd = |y|\sqrt{2-s^2}.$$
Thus we maximize $\max(|y_1|,|y_2|)\sqrt{2-s^2}$ over $s$.

By the symmetry $s \mapsto -s$ (which swaps $y_1 \leftrightarrow y_2$), we may t
ake $s \ge 0$. Then $\sqrt{s^2+6} > s$, so $y_1 = \sqrt{s^2+6}-s > 0$ and $y_2 =
 -\sqrt{s^2+6}-s < 0$, with
$$\max(|y_1|,|y_2|) = \sqrt{s^2+6}+s.$$

So we maximize
$$f(s) = \bigl(\sqrt{s^2+6}+s\bigr)\sqrt{2-s^2}, \qquad s \in [0,\sqrt{2}].$$

**Calculus.** With $h(s) = \ln f(s) = \ln(\sqrt{s^2+6}+s) + \tfrac12\ln(2-s^2)$:
$$h'(s) = \frac{1}{\sqrt{s^2+6}} - \frac{s}{2-s^2}.$$
(Using $\frac{d}{ds}\ln(\sqrt{s^2+6}+s) = \frac{1}{\sqrt{s^2+6}}$.) Setting $h'(
s)=0$:
$$\frac{1}{\sqrt{s^2+6}} = \frac{s}{2-s^2} \implies 2 - s^2 = s\sqrt{s^2+6}.$$
Squaring (both sides are positive when a solution exists):
$$(2-s^2)^2 = s^2(s^2+6) \implies 4 - 4s^2 + s^4 = s^4 + 6s^2 \implies 4 = 10s^2
 \implies s^2 = \tfrac{2}{5}.$$
Check: $2 - s^2 = \tfrac{8}{5}$ and $s\sqrt{s^2+6} = \sqrt{\tfrac{2}{5}}\cdot\sq
rt{\tfrac{32}{5}} = \sqrt{\tfrac{64}{25}} = \tfrac{8}{5}$. ✓

**Value at the critical point.** With $s^2 = \tfrac{2}{5}$:
$$\sqrt{s^2+6}+s = \sqrt{\tfrac{32}{5}}+\sqrt{\tfrac{2}{5}} = \frac{4\sqrt{2}+\s
qrt{2}}{\sqrt{5}} = \frac{5\sqrt{2}}{\sqrt{5}} = \sqrt{10},$$
$$\sqrt{2-s^2} = \sqrt{\tfrac{8}{5}}.$$
Therefore
$$f^2 = 10 \cdot \tfrac{8}{5} = 16 \implies f = 4.$$

**Endpoints.** At $s=0$: $f = \sqrt{6}\cdot\sqrt{2} = \sqrt{12} < 4$. At $s=\sqr
t{2}$: $f = 0$. So the maximum is $4$.

**Attainment.** Take $s = \sqrt{2/5}$, $d = -\sqrt{8/5}$, $y = -\sqrt{10}$. Then
$$x = \frac{s-d}{2},\quad z = \frac{s+d}{2} \implies x^2+z^2 = \frac{s^2+d^2}{2}
 = 1,$$
$$y^2 + 2ys = 10 - 2\sqrt{10}\cdot\sqrt{\tfrac{2}{5}} = 10 - 2\cdot 2 = 6,$$
$$yd = (-\sqrt{10})(-\sqrt{\tfrac{8}{5}}) = \sqrt{16} = 4.$$

The maximum value of $y(z-x)$ is $\boxed{4}$.
