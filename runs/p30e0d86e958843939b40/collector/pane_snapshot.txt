## Proof

**Key tool: asymptotic expansion of erfc.** The complementary error function $\o
peratorname{erfc}(z) = 1 - \operatorname{erf}(z)$ has the asymptotic expansion
$$\operatorname{erfc}(z) = \frac{e^{-z^2}}{z\sqrt{\pi}}\left(1 + O(1/z^2)\right)
$$
valid as $|z| \to \infty$ in the sector $|\arg z| < \frac{3\pi}{4}$.

**Checking the sector.** As $b \to \infty$, $z^2 = a + ib$ has $\arg(z^2) \to \f
rac{\pi}{2}$, so $\arg(z) = \frac{1}{2}\arg(z^2) \to \frac{\pi}{4}$. Since $\fra
c{\pi}{4} < \frac{3\pi}{4}$, we are strictly inside the sector of validity for a

**Magnitude of $z$.** We have $|z|^2 = |z^2| = |a+ib| = \sqrt{a^2+b^2}$, so $|z|
 = (a^2+b^2)^{1/4} \to \infty$.

**Magnitude of $e^{-z^2}$.** Since $z^2 = a+ib$, we get $|e^{-z^2}| = e^{-\opera
torname{Re}(z^2)} = e^{-a}$, which is a **fixed constant** (independent of $b$).

**Estimating erfc.** Combining the above:
$$|\operatorname{erfc}(z)| = \frac{|e^{-z^2}|}{|z|\sqrt{\pi}}\left|1 + O(1/z^2)\
right| = \frac{e^{-a}}{(a^2+b^2)^{1/4}\,\sqrt{\pi}}\left(1 + O\!\left((a^2+b^2)^
{-1/2}\right)\right) \longrightarrow 0 \quad\text{as } b\to\infty.$$

**Behavior of erf.** Since $\operatorname{erf}(z) = 1 - \operatorname{erfc}(z)$:
$$|\operatorname{erf}(z)|^2 = |1 - \operatorname{erfc}(z)|^2 = 1 - 2\operatornam

ad\text{as } b\to\infty.$$

**The limit.** The numerator $|\operatorname{erf}(\sqrt{a+ib})|^2 \to 1$ (bounde
d), while the denominator $\sqrt{a^2+b^2} \to \infty$. Therefore:
$$\lim_{b\to\infty}\frac{|\operatorname{erf}(\sqrt{a+ib})|^2}{\sqrt{a^2+b^2}} =
\frac{1}{\infty} = \boxed{0}.$$

This holds for every fixed real $a$, since $e^{-a}$ is always a finite constant
and $|z| \to \infty$ regardless of the sign of $a$.
