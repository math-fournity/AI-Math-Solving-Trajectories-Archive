## Proof

**Step 1: Reduction to two-value configurations.**

We maximize $S = \sum_{i=1}^n x_i^2$ subject to $x_i \geq -1$ and $\sum x_i^3 =
0$. The feasible region is compact (after intersecting with $\{S \leq M\}$ for l
arge $M$), so a maximum exists.

At the maximum, the KKT conditions give multipliers $\lambda$ (equality) and $\m
u_i \geq 0$ (inequalities) with:
$$2x_i = 3\lambda x_i^2 - \mu_i, \quad \mu_i(x_i + 1) = 0.$$
If $x_i > -1$, then $\mu_i = 0$, so $x_i(2 - 3\lambda x_i) = 0$, meaning $x_i =
0$ or $x_i = \frac{2}{3\lambda}$.

Thus every variable is either $-1$, $0$, or a common value $a = \frac{2}{3\lambd
a}$. Since $\sum x_i^3 = 0$ requires positive contributions, we need $a > 0$.

Suppose $k$ variables equal $-1$, $m$ equal $0$, and $n-k-m$ equal $a > 0$. The
constraint gives $(n-k-m)a^3 = k$, so $a = \bigl(\frac{k}{n-k-m}\bigr)^{1/3}$. T
he objective is:
$$S = k + (n-k-m)\,a^2 = k + k^{2/3}(n-k-m)^{1/3}.$$
For fixed $k$, this is increasing in $n-k-m$, so it is maximized when $m = 0$. H
ence the optimal configuration has $k$ variables at $-1$ and $n-k$ at $a = \bigl
(\frac{k}{n-k}\bigr)^{1/3}$, giving:
$$\frac{S}{n} = \frac{k}{n} + \left(\frac{k}{n}\right)^{2/3}\left(1 - \frac{k}{n
}\right)^{1/3}.$$

**Step 2: Maximizing over $t = k/n$.**

Set $t = k/n \in (0,1)$ and define $f(t) = t + t^{2/3}(1-t)^{1/3}$. Substituting
 $u = t^{1/3}$, $v = (1-t)^{1/3}$ (so $u^3 + v^3 = 1$, $u,v \geq 0$), we get $f
= u^3 + u^2 v = u^2(u+v)$.

Set $r = v/u \geq 0$ (the case $u=0$ gives $f=0$). Then $u^3(1+r^3) = 1$, so $u^
3 = \frac{1}{1+r^3}$, and:
$$f = u^3(1+r) = \frac{1+r}{1+r^3} =: h(r).$$

**Step 3: Finding the maximum of $h(r)$.**

$$h'(r) = \frac{(1+r^3) - (1+r)\cdot 3r^2}{(1+r^3)^2} = \frac{1 - 3r^2 - 2r^3}{(
1+r^3)^2}.$$

Setting the numerator to zero: $2r^3 + 3r^2 - 1 = 0$, which factors as $(r+1)(2r
^2 + r - 1) = 0$. The roots are $r = -1$ (rejected) and $r = \frac{1}{2}$ (from
$2r^2+r-1=0$).

Since $h(0) = 1$, $h(r) \to 0$ as $r \to \infty$, and the unique critical point
in $(0,\infty)$ is $r = \frac{1}{2}$:
$$h\!\left(\tfrac{1}{2}\right) = \frac{1 + \frac{1}{2}}{1 + \frac{1}{8}} = \frac
{3/2}{9/8} = \frac{4}{3}.$$

Therefore $f(t) \leq \frac{4}{3}$ for all $t \in [0,1]$, with equality when $r =
 \frac{1}{2}$, i.e., $v = u/2$, i.e., $(1-t)^{1/3} = t^{1/3}/2$, giving $1 - t =
 t/8$, so $t = \frac{8}{9}$.

**Step 4: Equality is achieved.**

Take $n = 9$: eight variables equal $-1$ and one variable equals $a = \bigl(\fra
c{8}{1}\bigr)^{1/3} = 2$.

- Compression limit: all $x_i \geq -1$. ✓
- Cubic balance: $\sum x_i^3 = 8(-1)^3 + 2^3 = -8 + 8 = 0$. ✓
- Energy variance: $\sum x_i^2 = 8 \cdot 1 + 4 = 12 = \frac{4}{3} \cdot 9$. ✓

This confirms $\frac{S}{n} = \frac{4}{3}$ is attained, so no smaller constant su

**Conclusion.** The smallest constant is $c = \dfrac{4}{3}$.
