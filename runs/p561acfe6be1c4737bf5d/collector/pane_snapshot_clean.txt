**Answer: Yes, such a function exists.**

## Proof

We construct an explicit example. Enumerate the rationals in $[0,1]$ as $\{q_1,
q_2, q_3, \dots\}$ (each rational appearing exactly once). Define

$$f(x) = \sum_{\{n \,:\, q_n \le x\}} 2^{-n}, \qquad x \in [0,1].$$

This is a well-defined finite sum since $\sum_{n=1}^{\infty} 2^{-n} = 1$, so $0
\le f(x) \le 1$.

### $f$ is monotone increasing, hence of bounded variation

If $x \le y$, then $\{n : q_n \le x\} \subseteq \{n : q_n \le y\}$, so $f(x) \le
 f(y)$. Thus $f$ is increasing on $[0,1]$. Every bounded monotone function has b
ounded variation; in fact $V_0^1(f) = f(1) - f(0) \le 1$.

### $f$ is continuous at every irrational

Let $x_0 \in [0,1]$ be irrational. Since $x_0$ is not equal to any $q_n$, we hav
e $\{n : q_n \le x_0\} = \{n : q_n < x_0\}$. The left and right limits of the in
creasing function $f$ at $x_0$ are

$$f(x_0^-) = \sup_{x < x_0} f(x) = \sum_{\{n:\, q_n < x_0\}} 2^{-n}, \qquad f(x_
0^+) = \inf_{x > x_0} f(x) = \sum_{\{n:\, q_n \le x_0\}} 2^{-n}.$$

Because $x_0$ is irrational, $q_n \le x_0 \iff q_n < x_0$, so the two sums are i
dentical: $f(x_0^-) = f(x_0) = f(x_0^+)$. Hence $f$ is continuous at $x_0$.

### $f$ is discontinuous at every rational

Let $x_0 = q_k$ for some $k$. Then

$$f(x_0) = \sum_{\{n:\, q_n \le q_k\}} 2^{-n} \ge \sum_{\{n:\, q_n < q_k\}} 2^{-
n} + 2^{-k}.$$

Since the enumeration is injective, $q_n < q_k$ for all $n \ne k$ with $q_n \le
q_k$ except $n=k$ itself, so

$$f(x_0^-) = \sum_{\{n:\, q_n < q_k\}} 2^{-n} = f(q_k) - 2^{-k}.$$

Thus $f(q_k) - f(q_k^-) = 2^{-k} > 0$: there is a jump discontinuity of size $2^
{-k}$ at $q_k$. Therefore $f$ is discontinuous at every rational.

### Conclusion

The function $f$ is increasing (hence of bounded variation on $[0,1]$), continuo
us at every irrational, and discontinuous at every rational. Therefore such a fu
nction exists. $\blacksquare$
