## Solution

The surface is parametrized by $\mathbf{r}(u^1,u^2) = (u^1\cos u^2,\; u^1\sin u^
2,\; f(u^2))$, where $f'=f'(u^2)$, $f''=f''(u^2)$.

### Tangent vectors

$$\mathbf{r}_1 = \frac{\partial\mathbf{r}}{\partial u^1} = (\cos u^2,\;\sin u^2,
\;0)$$
$$\mathbf{r}_2 = \frac{\partial\mathbf{r}}{\partial u^2} = (-u^1\sin u^2,\;u^1\c
os u^2,\;f')$$

### First fundamental form $a_{\alpha\beta}$

$$a_{11}=\mathbf{r}_1\cdot\mathbf{r}_1 = \cos^2 u^2+\sin^2 u^2 = 1$$
$$a_{12}=\mathbf{r}_1\cdot\mathbf{r}_2 = -u^1\cos u^2\sin u^2+u^1\sin u^2\cos u^
2 = 0$$
$$a_{22}=\mathbf{r}_2\cdot\mathbf{r}_2 = (u^1)^2\sin^2 u^2+(u^1)^2\cos^2 u^2+(f'
)^2 = (u^1)^2+(f')^2$$

So $\boxed{a_{11}=1,\; a_{12}=0,\; a_{22}=(u^1)^2+(f')^2}$, with determinant $a
= a_{11}a_{22}-a_{12}^2 = (u^1)^2+(f')^2$.

### Unit normal

$$\mathbf{r}_1\times\mathbf{r}_2 = (f'\sin u^2,\;-f'\cos u^2,\;u^1)$$
$$|\mathbf{r}_1\times\mathbf{r}_2| = \sqrt{(f')^2+(u^1)^2}$$
$$\mathbf{n} = \frac{(f'\sin u^2,\;-f'\cos u^2,\;u^1)}{\sqrt{(f')^2+(u^1)^2}}$$

### Second derivatives

$$\mathbf{r}_{11}=(0,0,0),\quad \mathbf{r}_{12}=(-\sin u^2,\cos u^2,0),\quad \ma
thbf{r}_{22}=(-u^1\cos u^2,-u^1\sin u^2,f'')$$

### Second fundamental form $b_{\alpha\beta}=\mathbf{r}_{\alpha\beta}\cdot\mathb
f{n}$

$$b_{11}=0$$
$$b_{12}=\frac{-f'\sin^2 u^2-f'\cos^2 u^2}{\sqrt{(f')^2+(u^1)^2}} = \frac{-f'}{\
sqrt{(f')^2+(u^1)^2}}$$
$$b_{22}=\frac{-u^1 f'\cos u^2\sin u^2+u^1 f'\sin u^2\cos u^2+u^1 f''}{\sqrt{(f'
)^2+(u^1)^2}} = \frac{u^1 f''}{\sqrt{(f')^2+(u^1)^2}}$$

So $\boxed{b_{11}=0,\; b_{12}=\dfrac{-f'}{\sqrt{(f')^2+(u^1)^2}},\; b_{22}=\dfra
c{u^1 f''}{\sqrt{(f')^2+(u^1)^2}}}$.

### Gaussian curvature

$$K = \frac{b_{11}b_{22}-b_{12}^2}{a_{11}a_{22}-a_{12}^2} = \frac{0-\dfrac{(f')^
2}{(f')^2+(u^1)^2}}{(u^1)^2+(f')^2}$$

$$\boxed{K = -\frac{(f')^2}{\big((u^1)^2+(f')^2\big)^2}}$$

### Mean curvature

The inverse metric is $a^{11}=1$, $a^{12}=0$, $a^{22}=\dfrac{1}{(u^1)^2+(f')^2}$
. Then

$$H = \tfrac{1}{2}\,a^{\alpha\beta}b_{\alpha\beta} = \tfrac{1}{2}\big(a^{11}b_{1
1}+a^{22}b_{22}\big) = \tfrac{1}{2}\left(0+\frac{1}{(u^1)^2+(f')^2}\cdot\frac{u^
1 f''}{\sqrt{(f')^2+(u^1)^2}}\right)$$

$$\boxed{H = \frac{u^1 f''}{2\big((u^1)^2+(f')^2\big)^{3/2}}}$$

### Summary

- **First fundamental form:** $a_{11}=1,\; a_{12}=0,\; a_{22}=(u^1)^2+(f')^2$
- **Second fundamental form:** $b_{11}=0,\; b_{12}=-\dfrac{f'}{\sqrt{(u^1)^2+(f'
)^2}},\; b_{22}=\dfrac{u^1 f''}{\sqrt{(u^1)^2+(f')^2}}$
- **Gaussian curvature:** $K = -\dfrac{(f')^2}{\big((u^1)^2+(f')^2\big)^2}$
- **Mean curvature:** $H = \dfrac{u^1 f''}{2\big((u^1)^2+(f')^2\big)^{3/2}}$

Note: $K\le 0$ everywhere, so this conicoid is everywhere non-positively curved
(a saddle-type surface), consistent with it being a ruled surface — each $u^2=\t
ext{const}$ curve is a straight line (the generator $u^1$), and ruled surfaces h
ave $K\le 0$.
