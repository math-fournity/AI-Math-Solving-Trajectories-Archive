## Solution

**Find the point where $f(x) = 2$:**

Set $x = 0$ in the defining equation:
$$e^{0}f(0) = 2 + \int_0^0 \sqrt{t^4+1}\,dt = 2 + 0 = 2$$
So $f(0) = 2$, which means $f^{-1}(2) = 0$.

**Apply the inverse function theorem:**
$$(f^{-1})'(2) = \frac{1}{f'\!\big(f^{-1}(2)\big)} = \frac{1}{f'(0)}$$

**Compute $f'(0)$:**

Differentiate both sides of $e^{-x}f(x) = 2 + \int_0^x \sqrt{t^4+1}\,dt$ with re
spect to $x$:
$$-e^{-x}f(x) + e^{-x}f'(x) = \sqrt{x^4+1}$$

Evaluate at $x = 0$, using $f(0) = 2$:
$$-e^{0}\cdot 2 + e^{0}\cdot f'(0) = \sqrt{0+1}$$
$$-2 + f'(0) = 1$$
$$f'(0) = 3$$

**Conclusion:**
$$(f^{-1})'(2) = \frac{1}{f'(0)} = \frac{1}{3}$$
