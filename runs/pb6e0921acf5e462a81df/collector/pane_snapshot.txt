## Setup

Let $a_n = \sum_{k=0}^{n} \frac{(-1)^k 2^k}{k+1} = \sum_{k=0}^{n} \frac{(-2)^k}{
k+1}$, and define $b_n = \dfrac{a_n}{2^n}$. The target is $S = \sum_{n=0}^{\inft
y} b_n$.

**Note:** The naive double-sum interchange gives $\sum_{k=0}^{\infty}\frac{(-2)^
k}{k+1}\cdot\frac{2}{2^k} = 2\sum_{k=0}^{\infty}\frac{(-1)^k}{k+1}$, but this is
 **not justified** since $\sum\frac{2}{k+1}$ diverges (the inner partial sums $a
_n$ grow like $\frac{(-2)^{n+1}}{n+2}$, so the series is only conditionally conv
ergent). I'll use a recurrence instead, which both proves convergence and comput
es the value rigorously.

## A Useful Recurrence

Since $a_n = a_{n-1} + \frac{(-2)^n}{n+1}$, dividing by $2^n$:

$$b_n = \frac{a_{n-1}}{2^n} + \frac{(-2)^n}{(n+1)\,2^n} = \frac{1}{2}\,b_{n-1} +
 \frac{(-1)^n}{n+1}, \qquad b_0 = a_0 = 1.$$

## Convergence of $b_n \to 0$

Iterating the recurrence:
$$b_n = \frac{b_0}{2^n} + \sum_{j=1}^{n} \frac{(-1)^j}{j+1}\cdot\frac{1}{2^{\,n-
j}}.$$
The first term $\to 0$. For the sum, the weight $\frac{1}{2^{n-j}}$ is largest a
t $j=n$ (value $1$) and decays geometrically for smaller $j$, so the sum is boun
ded in magnitude by $\sum_{i=0}^{n-1}\frac{1}{2^i}\cdot\frac{1}{n+1-i}\le \frac{
C}{n}\to 0$. Thus $b_n\to 0$.

## Computing $S$

Rewrite the recurrence as $b_n - \tfrac{1}{2}b_{n-1} = \tfrac{(-1)^n}{n+1}$ and
sum from $n=1$ to $N$, with $S_N = \sum_{n=0}^{N} b_n$:

$$\sum_{n=1}^{N} b_n - \frac{1}{2}\sum_{n=1}^{N} b_{n-1} = \sum_{n=1}^{N}\frac{(
-1)^n}{n+1}.$$

$$(S_N - b_0) - \frac{1}{2}(S_N - b_N) = \sum_{n=1}^{N}\frac{(-1)^n}{n+1}.$$

$$\frac{1}{2}S_N = b_0 - \frac{1}{2}b_N + \sum_{n=1}^{N}\frac{(-1)^n}{n+1}.$$

$$S_N = 2b_0 - b_N + 2\sum_{n=1}^{N}\frac{(-1)^n}{n+1}.$$

## Taking $N \to \infty$

- $b_0 = 1$.
- $b_N \to 0$ (shown above), so $S_N$ converges — confirming the original series
 converges.
- $\sum_{n=1}^{\infty}\frac{(-1)^n}{n+1} = \sum_{m=2}^{\infty}\frac{(-1)^{m-1}}{
m} = \ln 2 - 1$, using $\ln 2 = \sum_{m=1}^{\infty}\frac{(-1)^{m-1}}{m} = 1 - \t
frac{1}{2} + \tfrac{1}{3} - \cdots$.

Therefore:
$$S = 2(1) - 0 + 2(\ln 2 - 1) = 2 + 2\ln 2 - 2 = 2\ln 2.$$
