## Proof

We solve the boundary-value problem
$$X^{(iv)}+\lambda X=0,\quad X(0)=X''(0)=X(L)=X'(L)=0.$$

We consider three cases.

---

### Case 1: $\lambda=0$

Then $X^{(iv)}=0$, so $X(x)=ax^{3}+bx^{2}+cx+d$.

- $X(0)=0\Rightarrow d=0$.
- $X''(0)=0\Rightarrow 2b=0\Rightarrow b=0$.
- $X(L)=0\Rightarrow aL^{3}+cL=0\Rightarrow c=-aL^{2}$.
- $X'(L)=0\Rightarrow 3aL^{2}+c=0\Rightarrow 3aL^{2}-aL^{2}=2aL^{2}=0\Rightarrow
 a=0\Rightarrow c=0$.

Only the trivial solution, so **$\lambda=0$ is not an eigenvalue**.

---

### Case 2: $\lambda>0$

Write $\lambda=\alpha^{4}$, $\alpha>0$. The characteristic equation $r^{4}+\alph
a^{4}=0$ has roots $r=\pm q\pm iq$ with $q=\alpha/\sqrt{2}$. The real general so
lution is
$$X=A\cosh qx\cos qx+B\cosh qx\sin qx+C\sinh qx\cos qx+D\sinh qx\sin qx.$$

Using $f_{1}=\cosh qx\cos qx$, $f_{2}=\cosh qx\sin qx$, $f_{3}=\sinh qx\cos qx$,
 $f_{4}=\sinh qx\sin qx$, one computes
$$f_{1}''=-2q^{2}f_{4},\quad f_{2}''=2q^{2}f_{3},\quad f_{3}''=-2q^{2}f_{2},\qua
d f_{4}''=2q^{2}f_{1},$$
with $f_{1}(0)=1$, $f_{2}(0)=f_{3}(0)=f_{4}(0)=0$.

- $X(0)=0\Rightarrow A=0$.
- $X''(0)=2q^{2}D=0\Rightarrow D=0$.

So $X=Bf_{2}+Cf_{3}$. The remaining conditions $X(L)=0$, $X'(L)=0$ give (writing
 $\mathrm{ch}=\cosh qL$, $\mathrm{sh}=\sinh qL$, $c=\cos qL$, $s=\sin qL$):
$$B\,\mathrm{ch}\,s+C\,\mathrm{sh}\,c=0,\qquad B(\mathrm{ch}\,c+\mathrm{sh}\,s)+
C(\mathrm{ch}\,c-\mathrm{sh}\,s)=0.$$

A nontrivial solution requires the determinant to vanish:
$$\mathrm{ch}\,s(\mathrm{ch}\,c-\mathrm{sh}\,s)-\mathrm{sh}\,c(\mathrm{ch}\,c+\m
athrm{sh}\,s)=sc(\mathrm{ch}^{2}-\mathrm{sh}^{2})-\mathrm{ch}\,\mathrm{sh}(s^{2}
+c^{2})=sc-\mathrm{ch}\,\mathrm{sh}=0,$$
i.e. $\sin qL\cos qL=\sinh qL\cosh qL$, or equivalently
$$\sin(2qL)=\sinh(2qL).$$

For $t=2qL>0$ we have $\sinh t>t>\sin t$, so $\sinh(2qL)>\sin(2qL)$ strictly. He
nce **no eigenvalue with $\lambda>0$**.

---

### Case 3: $\lambda<0$

Write $\lambda=-\alpha^{4}$, $\alpha>0$. Then $X^{(iv)}-\alpha^{4}X=0$ with char
acteristic roots $r=\pm\alpha,\pm i\alpha$, giving
$$X=A\cosh\alpha x+B\sinh\alpha x+C\cos\alpha x+D\sin\alpha x.$$

- $X(0)=0\Rightarrow A+C=0\Rightarrow C=-A$.
- $X''(0)=\alpha^{2}(A-C)=2\alpha^{2}A=0\Rightarrow A=0\Rightarrow C=0$.

So $X=B\sinh\alpha x+D\sin\alpha x$. The conditions at $x=L$:
$$B\sinh\alpha L+D\sin\alpha L=0,\qquad B\cosh\alpha L+D\cos\alpha L=0.$$

A nontrivial solution requires
$$\sinh\alpha L\cos\alpha L-\sin\alpha L\cosh\alpha L=0,$$
i.e.
$$\boxed{\tan(\alpha L)=\tanh(\alpha L).}\tag{*}$$

**Existence of roots.** For $t>0$ small, $\tan t=t+\tfrac{t^{3}}{3}+\cdots>\tanh
 t=t-\tfrac{t^{3}}{3}+\cdots$, and $\tanh t<1$ for all $t$. On each interval $(n
\pi,\,n\pi+\tfrac{\pi}{2})$, $n=1,2,3,\dots$, we have $\tan(n\pi)=0<\tanh(n\pi)$
 while $\tan t\to+\infty$ as $t\to(n\pi+\tfrac{\pi}{2})^{-}$, so by the intermed
iate value theorem there is exactly one root $t_{n}=\alpha_{n}L$ in each such in
terval. On $(0,\tfrac{\pi}{2})$ we have $\tan t>\tanh t$ throughout, so no root
there (apart from $t=0$, which is trivial). Thus there is a sequence
$$\alpha_{n}L\in\bigl(n\pi,\;n\pi+\tfrac{\pi}{2}\bigr),\qquad n=1,2,3,\dots,$$
satisfying $(*)$.

**Eigenvalues.** $\lambda_{n}=-\alpha_{n}^{4}$, $n=1,2,3,\dots$.

**Eigenfunctions.** From $B\sinh\alpha_{n}L+D\sin\alpha_{n}L=0$ we may take $D=\
sinh\alpha_{n}L$ and $B=-\sin\alpha_{n}L$, giving (up to a multiplicative consta
nt)
$$\boxed{X_{n}(x)=\sinh(\alpha_{n}L)\sin(\alpha_{n}x)-\sin(\alpha_{n}L)\sinh(\al
pha_{n}x).}$$

**Verification.**
- $X_{n}(0)=0-0=0$. ✓
- $X_{n}''(x)=\alpha_{n}^{2}\bigl[\sinh(\alpha_{n}L)\sin(\alpha_{n}x)+\sin(\alph
a_{n}L)\sinh(\alpha_{n}x)\bigr]$, so $X_{n}''(0)=0$. ✓
- $X_{n}(L)=\sinh(\alpha_{n}L)\sin(\alpha_{n}L)-\sin(\alpha_{n}L)\sinh(\alpha_{n
}L)=0$. ✓
- $X_{n}'(L)=\alpha_{n}\bigl[\sinh(\alpha_{n}L)\cos(\alpha_{n}L)-\sin(\alpha_{n}
L)\cosh(\alpha_{n}L)\bigr]=0$ by $(*)$. ✓

---

### Conclusion

All eigenvalues are negative. The complete spectrum is
$$\lambda_{n}=-\alpha_{n}^{4},\qquad n=1,2,3,\dots,$$
where $\alpha_{n}>0$ is the unique root of
$$\tan(\alpha L)=\tanh(\alpha L)$$
in the interval $\alpha L\in\bigl(n\pi,\;n\pi+\tfrac{\pi}{2}\bigr)$. The corresp
onding eigenfunctions are
$$X_{n}(x)=\sinh(\alpha_{n}L)\sin(\alpha_{n}x)-\sin(\alpha_{n}L)\sinh(\alpha_{n}
x),$$
determined up to a nonzero multiplicative constant.
