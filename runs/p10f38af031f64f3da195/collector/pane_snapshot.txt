## Proof

**Claim:** The set $\{x \in [a,b] : D^+ f(x) < c\}$ is Lebesgue measurable (in f
act, Borel measurable) for every $c \in \mathbb{R}$.

---

**Step 1: Handling the endpoint $b$.**

The expression $\frac{f(x+h)-f(x)}{h}$ requires $f$ to be defined at $x+h$ for $
h > 0$, which is not available at $x = b$. Extend $f$ to $\tilde{f}:[a,b+1]\to\m
athbb{R}$ by
$$\tilde{f}(x) = \begin{cases} f(x), & x \in [a,b],\\ f(b), & x \in (b, b+1].\en
d{cases}$$
This extension is continuous. For $x \in [a,b)$, the values $\tilde{f}(x+h)$ for
 small $h>0$ agree with $f(x+h)$, so $D^+\tilde{f}(x) = D^+f(x)$ on $[a,b)$. At
$x=b$, $D^+\tilde{f}(b)=0$. Since $\{b\}$ is a Borel set, adding or removing thi
s single point does not affect measurability. Hence it suffices to show $D^+\til
de{f}$ is Borel measurable on $[a,b]$.

**Step 2: Expressing $D^+f$ via countable operations on continuous functions.**

Define $g(x,h) = \frac{\tilde{f}(x+h)-\tilde{f}(x)}{h}$ for $x \in [a,b]$, $h \i
n (0,1]$. By definition,
$$D^+\tilde{f}(x) = \limsup_{h\to 0^+} g(x,h) = \inf_{\delta > 0}\; \sup_{0 < h
< \delta} g(x,h).$$

Since the map $\delta \mapsto \sup_{0<h<\delta} g(x,h)$ is monotone, we may rest
rict $\delta$ to the sequence $\delta = 1/n$:
$$D^+\tilde{f}(x) = \inf_{n \geq 1}\; \sup_{0 < h < 1/n} g(x,h).$$

For each fixed $x$, the function $h \mapsto g(x,h)$ is continuous on $(0,1/n)$ (
because $\tilde{f}$ is continuous). Therefore the supremum over all real $h \in
(0,1/n)$ equals the supremum over rational $h$:
$$\sup_{0 < h < 1/n} g(x,h) = \sup_{\substack{r \in \mathbb{Q}\\ 0 < r < 1/n}} g
(x,r).$$

Let $\{r_k\}_{k=1}^\infty$ be an enumeration of the positive rationals. Then
$$D^+\tilde{f}(x) = \inf_{n\geq 1}\; \sup_{\substack{k:\, 0 < r_k < 1/n}} g(x, r
_k).$$

**Step 3: Each ingredient is Borel measurable.**

For each fixed $r_k$, the function
$$x \;\mapsto\; g(x, r_k) = \frac{\tilde{f}(x+r_k)-\tilde{f}(x)}{r_k}$$
is continuous on $[a,b]$ (as a difference of continuous functions divided by a c
onstant), hence Borel measurable.

For each $n$, the function $\varphi_n(x) = \sup_{k:\, 0<r_k<1/n} g(x,r_k)$ is a
supremum of **countably many** Borel measurable functions, hence Borel measurabl
e.

Finally, $D^+\tilde{f}(x) = \inf_{n\geq 1} \varphi_n(x)$ is an infimum of **coun
tably many** Borel measurable functions, hence Borel measurable.

**Step 4: Conclusion.**

Since $D^+\tilde{f}$ is Borel measurable on $[a,b]$ and agrees with $D^+f$ on $[
a,b)$, the set
$$\{x \in [a,b] : D^+f(x) < c\}$$
differs from the Borel set $\{x \in [a,b] : D^+\tilde{f}(x) < c\}$ by at most th
e single point $\{b\}$, which is itself Borel. Therefore $\{x \in [a,b] : D^+f(x
) < c\}$ is Borel measurable, and consequently Lebesgue measurable, for every $c
 \in \mathbb{R}$.

**Answer: Yes**, the set is Lebesgue measurable (indeed Borel measurable) for al
l $c \in \mathbb{R}$.
