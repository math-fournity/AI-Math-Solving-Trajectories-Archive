# Proof

**Claim:** Yes. A continuous local martingale bounded below by a fixed constant
is necessarily a supermartingale.

**Setup.** Let $(M(t),\mathcal{F}_t)_{t\ge 0}$ be a continuous local martingale
with $M(t)\ge c$ for all $t$ and some constant $c\in\mathbb{R}$. Set
$$N(t):=M(t)-c\ge 0.$$
Then $N$ is a nonnegative continuous local martingale. We show $N$ is a supermar
tingale; since adding the constant $c$ preserves the supermartingale property, $
M=N+c$ is then a supermartingale.

**Localization.** Since $N$ is a local martingale, there exist stopping times $\
tau_n\uparrow\infty$ a.s. such that each stopped process $N^{\tau_n}$ is a (true
) martingale. In particular, for $0\le s\le t$,
$$N(s\wedge\tau_n)=\mathbb{E}\big[N(t\wedge\tau_n)\,\big|\,\mathcal{F}_s\big]. \
tag{1}$$

**Integrability of $N(t)$.** Since $N^{\tau_n}$ is a nonnegative martingale, $\m
athbb{E}[N(t\wedge\tau_n)]=\mathbb{E}[N(0)]<\infty$. Applying Fatou's lemma,
$$\mathbb{E}[N(t)]=\mathbb{E}\big[\liminf_{n\to\infty}N(t\wedge\tau_n)\big]\le\l
iminf_{n\to\infty}\mathbb{E}[N(t\wedge\tau_n)]=\mathbb{E}[N(0)]<\infty.$$
Thus $N(t)$ is integrable for every $t$ (and likewise $M(t)=N(t)+c$ is integrabl
e).

**Supermartingale inequality.** Apply the conditional version of Fatou's lemma t
o the nonnegative random variables $N(t\wedge\tau_n)$ (which converge a.s. to $N
(t)$ since $\tau_n\uparrow\infty$):
$$\mathbb{E}\big[N(t)\,\big|\,\mathcal{F}_s\big]=\mathbb{E}\big[\liminf_{n}N(t\w
edge\tau_n)\,\big|\,\mathcal{F}_s\big]\le\liminf_{n}\mathbb{E}\big[N(t\wedge\tau
_n)\,\big|\,\mathcal{F}_s\big].$$
By (1), the right-hand side equals $\liminf_{n}N(s\wedge\tau_n)=N(s)$ (using con
tinuity of $N$ and $\tau_n\uparrow\infty$). Hence
$$\mathbb{E}\big[N(t)\,\big|\,\mathcal{F}_s\big]\le N(s),\qquad 0\le s\le t.$$

**Conclusion.** $N$ is a nonnegative supermartingale, so $M(t)=N(t)+c$ is a supe
rmartingale. $\blacksquare$
