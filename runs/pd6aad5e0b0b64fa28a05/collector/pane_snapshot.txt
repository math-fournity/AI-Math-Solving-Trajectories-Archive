## Proof

**Step 1: Identify the excluded set.**

Let $B = \{(x,y)\in[0,1]^2 : x+y\in\mathbb{Q}\}$ and $C = \{(x,y)\in[0,1]^2 : xy
\in\mathbb{Q}\}$. Then $A = [0,1]^2 \setminus (B\cup C)$.

**Step 2: Show $B$ has measure zero.**

For each $q\in\mathbb{Q}$, the set $\{(x,y): x+y=q\}$ is a line in $\mathbb{R}^2
$, which has 2-dimensional Lebesgue measure zero. Since $B = \bigcup_{q\in\mathb
b{Q}} \{(x,y)\in[0,1]^2: x+y=q\}$ is a countable union of measure-zero sets, $m^
2(B)=0$.

**Step 3: Show $C$ has measure zero.**

For each $q\in\mathbb{Q}$, the set $\{(x,y): xy=q\}$ is either a hyperbola ($q\n
eq 0$) or the union of the two axes ($q=0$), each a 1-dimensional curve with 2-d
imensional Lebesgue measure zero. Since $C = \bigcup_{q\in\mathbb{Q}} \{(x,y)\in
[0,1]^2: xy=q\}$ is a countable union of measure-zero sets, $m^2(C)=0$.

**Step 4: Conclude $A$ differs from $[0,1]^2$ by a null set.**

$m^2(B\cup C) \le m^2(B)+m^2(C)=0$, so $[0,1]^2\setminus A = B\cup C$ has measur
e zero. Thus $A$ and $[0,1]^2$ differ by a set of measure zero.

**Step 5: Verify integrability and compute.**

The function $f(x,y)=y^{-1/2}\sin x$ is non-negative on $[0,1]^2$ (since $\sin x
\ge 0$ for $x\in[0,1]$ and $y^{-1/2}>0$). Since the integrand is non-negative, c
hanging the domain by a null set does not change the integral (the integral over
 a null set is zero, even for functions that are infinite there, by definition o
f the Lebesgue integral of non-negative functions). Hence

$$\int_A y^{-1/2}\sin x\,dm^2 = \int_{[0,1]^2} y^{-1/2}\sin x\,dm^2.$$

By Tonelli's theorem (non-negative integrand, product measure),

$$\int_{[0,1]^2} y^{-1/2}\sin x\,dm^2 = \left(\int_0^1 \sin x\,dx\right)\left(\i
nt_0^1 y^{-1/2}\,dy\right).$$

Both integrals are finite:
- $\int_0^1 \sin x\,dx = 1-\cos 1$,
- $\int_0^1 y^{-1/2}\,dy = \left[2y^{1/2}\right]_0^1 = 2$.

Therefore

$$\int_A y^{-1/2}\sin x\,dm^2 = 2(1-\cos 1).$$
