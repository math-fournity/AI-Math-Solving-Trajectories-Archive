## Solution

**Laplace transform in $t$.** Let $U(x,s) = \mathcal{L}\{u(x,t)\}(s) = \int_0^\i
nfty e^{-st} u(x,t)\,dt$, and $F(s) = \mathcal{L}\{f(t)\}(s)$, with $\operatorna
me{Re}(s)>0$.

Transforming the PDE $u_{tt}=c^2 u_{xx}$ and using the zero initial conditions $
u(x,0)=u_t(x,0)=0$:

$$s^2 U(x,s) = c^2\, U_{xx}(x,s) \quad\Longrightarrow\quad U_{xx} - \frac{s^2}{c
^2}\,U = 0.$$

**General solution and boundedness.** The ODE in $x$ has general solution

$$U(x,s) = A(s)\,e^{sx/c} + B(s)\,e^{-sx/c}.$$

For $\operatorname{Re}(s)>0$, the term $e^{sx/c}\to\infty$ as $x\to\infty$. The
boundedness condition $\lim_{x\to\infty}|u(x,t)|<\infty$ forces $A(s)=0$, so

$$U(x,s) = B(s)\,e^{-sx/c}.$$

**Applying the boundary condition.** From $u_x(0,t)=f(t)$ we get $U_x(0,s)=F(s)$
. Since

$$U_x(x,s) = -\frac{s}{c}\,B(s)\,e^{-sx/c},$$

evaluating at $x=0$: $-\frac{s}{c}B(s) = F(s)$, hence $B(s) = -\frac{c}{s}F(s)$.
 Therefore

$$\boxed{U(x,s) = -\frac{c}{s}\,F(s)\,e^{-sx/c}.}$$

**Inversion.** Write $U(x,s) = -\frac{c}{s}\cdot\bigl[F(s)\,e^{-sx/c}\bigr]$. By
 the second shifting theorem,

$$\mathcal{L}^{-1}\{F(s)\,e^{-sx/c}\}(t) = f\!\left(t-\tfrac{x}{c}\right) H\!\le
ft(t-\tfrac{x}{c}\right),$$

where $H$ is the Heaviside step function. Since $\mathcal{L}^{-1}\{G(s)/s\} = \i
nt_0^t g(\tau)\,d\tau$ (integration property), with $g(t)=f(t-x/c)H(t-x/c)$:

$$u(x,t) = -c\int_0^t f\!\left(\tau-\tfrac{x}{c}\right) H\!\left(\tau-\tfrac{x}{
c}\right)d\tau.$$

The step function vanishes for $\tau < x/c$, so the lower limit becomes $x/c$ (a
nd the integral is zero when $t\le x/c$). Substituting $\sigma = \tau - x/c$:

$$\boxed{\,u(x,t) = -c\,H\!\left(t-\tfrac{x}{c}\right)\int_0^{\,t-x/c} f(\sigma)
\,d\sigma.\,}$$

**Verification.**

*PDE.* For $t>x/c$ (the region where $u$ is smooth), let $\xi = t - x/c$:
- $u_t = -c\,f(\xi)$, $\ u_{tt} = -c\,f'(\xi)$;
- $u_x = -c\,f(\xi)\cdot(-1/c) = f(\xi)$, $\ u_{xx} = f'(\xi)\cdot(-1/c) = -\fra
c{1}{c}f'(\xi)$.

Hence $c^2 u_{xx} = -c\,f'(\xi) = u_{tt}$. ✓

*Boundary condition.* Differentiating in $x$:
$$u_x = \delta\!\left(t-\tfrac{x}{c}\right)\!\int_0^{t-x/c}\! f\,d\sigma \;+\; H
\!\left(t-\tfrac{x}{c}\right) f\!\left(t-\tfrac{x}{c}\right).$$
At $x=0$ the delta term is $\delta(t)\cdot 0 = 0$, leaving $u_x(0,t) = H(t)\,f(t
) = f(t)$ for $t>0$. ✓

*Initial conditions.* For $x>0$: $u(x,0) = -c\,H(-x/c)\int_0^{-x/c}\cdots = 0$ s
ince $H(-x/c)=0$; likewise $u_t(x,0)=-c\,f(-x/c)\,H(-x/c)=0$. ✓

*Boundedness.* For fixed $t$, as $x\to\infty$ we have $t-x/c\to -\infty$, so $H(
t-x/c)=0$ and $u\to 0$. ✓

All conditions are satisfied, confirming the solution.
