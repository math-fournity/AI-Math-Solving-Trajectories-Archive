**关于题目完整性的说明：** 题目文本中引用了集合 $S_n$，但并未给出其定义。在下文
中，我将在该问题的标准经典解释下进行求解——即 $S_n$ 为被超平面 $\sum x_i = a$ 从
立方体 $[0,a]^n$ 中截出的标准 $n$-单纯形 (standard $n$-simplex)：

$$S_n = \bigl\{(x_1,\dots,x_n)\in\mathbb{R}^n_{\ge 0} : x_1+x_2+\cdots+x_n \le a
\bigr\} \subseteq [0,a]^n.$$

（包含关系成立，因为每个 $x_i\ge 0$ 意味着 $x_i \le \sum_j x_j \le a$。）

---

## 证明

**第一步：计算 $\lambda(S_n)$。**

集合 $S_n = \{x\ge 0 : \sum x_i \le a\}$ 是顶点位于 $0, ae_1, \dots, ae_n$ 的标
准 $n$-单纯形，并按因子 $a$ 缩放。其体积为

$$\lambda(S_n) = \frac{a^n}{n!}.$$

*通过对 $n$ 的归纳推导：* 设 $V_n(a) = \lambda\{x\ge 0:\sum_{1}^{n} x_i \le a\}$
。通过对最后一个坐标进行切片，

$$V_n(a) = \int_{0}^{a} V_{n-1}(a - t)\,dt.$$

当 $V_1(a) = a$ 时，归纳步骤得到

$$V_n(a) = \int_0^a \frac{(a-t)^{n-1}}{(n-1)!}\,dt = \frac{a^n}{n!}.$$

因此 $\lambda(S_n) = a^n/n!$。

**第二步：计算 $\lambda([0,a]^n)$。**

$$\lambda([0,a]^n) = a^n.$$

**第三步：比值及其极限。**

$$\frac{\lambda(S_n)}{\lambda([0,a]^n)} = \frac{a^n/n!}{a^n} = \frac{1}{n!}.$$

由于 $n! \to \infty$（事实上，超指数增长：对于 $n\ge 6$，有 $n! > 2^n$），我们得
到

$$\lim_{n\to\infty}\frac{\lambda(S_n)}{\lambda([0,a]^n)} = \lim_{n\to\infty}\fra
c{1}{n!} = 0.$$

**结论。** 单纯形的体积相对于其外接立方体呈超指数级缩小：固定边长 $a$，随着维数
$n$ 的增长，单纯形占据了立方体中可忽略不计的一部分。该比值为 $1/n!$，且

$$\boxed{\displaystyle\lim_{n\to\infty}\frac{\lambda(S_n)}{\lambda([0,a]^n)} = 0
.}$$
