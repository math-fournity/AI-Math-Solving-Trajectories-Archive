## 证明

**第一步：将 f(x) 重写为单一余弦。**

利用 $\cos(a_k + x) = \cos a_k \cos x - \sin a_k \sin x$，我们得到

$$f(x) = \cos x \sum_{k=1}^{n}\frac{\cos a_k}{2^{k-1}} \;-\; \sin x \sum_{k=1}^{
n}\frac{\sin a_k}{2^{k-1}}.$$

设 $A = \sum_{k=1}^{n}\frac{\cos a_k}{2^{k-1}}$，$B = \sum_{k=1}^{n}\frac{\sin a
_k}{2^{k-1}}$，因此

$$f(x) = A\cos x - B\sin x.$$

设 $R = \sqrt{A^2+B^2}$。存在一个角 $\varphi$ 使得 $A = R\cos\varphi$ 且 $B = R\
sin\varphi$，由此可得

$$f(x) = R\cos\varphi\cos x - R\sin\varphi\sin x = R\cos(x+\varphi).$$

**第二步：证明 $R \neq 0$。**

$R = 0$ 当且仅当 $A = B = 0$，即当且仅当 $\sum_{k=1}^{n}\frac{e^{ia_k}}{2^{k-1}}
 = 0$。

将 $k=1$ 的项（系数为 $1$）与其余项分离：

$$e^{ia_1} + \sum_{k=2}^{n}\frac{e^{ia_k}}{2^{k-1}} = 0 \quad\Longrightarrow\qua
d e^{ia_1} = -\sum_{k=2}^{n}\frac{e^{ia_k}}{2^{k-1}}.$$

取模：

$$1 = |e^{ia_1}| = \left|\sum_{k=2}^{n}\frac{e^{ia_k}}{2^{k-1}}\right| \le \sum_
{k=2}^{n}\frac{1}{2^{k-1}} = \frac{1}{2}+\frac{1}{4}+\cdots+\frac{1}{2^{n-1}} =
1 - \frac{1}{2^{n-1}} < 1.$$

这产生了矛盾 $1 < 1$。因此 $R \neq 0$，即 $R > 0$。

**第三步：得出零点的结论。**

由于 $R > 0$，$f(x) = R\cos(x+\varphi)$ 的零点恰好是满足 $x + \varphi = \frac{\p
i}{2} + m\pi$（$m \in \mathbb{Z}$）的点 $x$，即

$$x = \frac{\pi}{2} - \varphi + m\pi, \qquad m \in \mathbb{Z}.$$

因此 $f$ 的任意两个零点相差 $\pi$ 的整数倍。由于 $f(x_1) = f(x_2) = 0$，我们得到

$$x_2 - x_1 = m\pi \quad\text{对于某个整数 } m.$$
