# Problem

In a specialized logistics hub, an automated sorting machine is programmed to process cargo using only four specific weight categories of heavy-duty canisters. These canisters are measured in "kilounits" (ku), and their available sizes are defined by the set $\{6n+1, 6n+3, 6n+5, 6n+7\}$, where $n$ represents a fixed positive integer determined by the facility's current operational phase.

A freight forwarder arrives at the hub with an empty transport bay. He needs to load a specific total weight of cargo, but the machine can only fulfill the request if the exact weight can be reached by combining any number of canisters from the four available sizes (with an unlimited supply of each size).

What is the maximum total weight, in kilounits, that the machine is physically unable to provide to the freight forwarder?
