## Analysis

**Setup.** Let
$$f(x) = \sqrt{\sqrt{x+a}-\sqrt{x}}, \qquad g(x) = \sqrt{\sqrt{x}-\sqrt{x-b}}.$$

The only possible issues are: (i) behavior as $x\to\infty$, and (ii) behavior ne
ar $x=b$. At $x=b$, both terms are finite ($g(b)=\sqrt{\sqrt{b}}=b^{1/4}$, $f(b)
=\sqrt{\sqrt{b+a}-\sqrt{b}}$), so there is **no singularity at the lower limit**
. Convergence depends entirely on the behavior at infinity.

**Leading asymptotics.** Using $\sqrt{x+s}-\sqrt{x} = \frac{s}{\sqrt{x+s}+\sqrt{
x}} \sim \frac{s}{2\sqrt{x}}$ as $x\to\infty$:

$$f(x) = \sqrt{\frac{a}{\sqrt{x+a}+\sqrt{x}}} \sim \sqrt{\frac{a}{2\sqrt{x}}} =
\frac{\sqrt{a}}{2^{1/2}\,x^{1/4}},$$

$$g(x) = \sqrt{\frac{b}{\sqrt{x}+\sqrt{x-b}}} \sim \frac{\sqrt{b}}{2^{1/2}\,x^{1
/4}}.$$

Therefore
$$f(x)-g(x) \sim \frac{\sqrt{a}-\sqrt{b}}{\sqrt{2}}\,x^{-1/4}.$$

**Case $a\neq b$:** The coefficient $\frac{\sqrt{a}-\sqrt{b}}{\sqrt{2}}\neq 0$,
so the integrand behaves like $C\,x^{-1/4}$ with $C\neq 0$. Since $\int^\infty x
^{-1/4}\,dx$ **diverges** ($-1/4 > -1$), the integral **diverges**.

**Case $a = b = c > 0$:** The leading term cancels. Set $A = \sqrt{x+c}+\sqrt{x}
$ and $B = \sqrt{x}+\sqrt{x-c}$, so $f = \sqrt{c/A}$, $g = \sqrt{c/B}$, and
$$f-g = \sqrt{c}\left(\frac{1}{\sqrt{A}}-\frac{1}{\sqrt{B}}\right) = \sqrt{c}\cd
ot\frac{\sqrt{B}-\sqrt{A}}{\sqrt{A}\sqrt{B}}.$$

For large $x$: $A\sim 2\sqrt{x}$, $B\sim 2\sqrt{x}$, so $\sqrt{A}\sim\sqrt{B}\si
m 2^{1/2}x^{1/4}$ and $\sqrt{A}\sqrt{B}\sim 2x^{1/2}$.

The difference:
$$A - B = \sqrt{x+c}-\sqrt{x-c} = \frac{2c}{\sqrt{x+c}+\sqrt{x-c}} \sim \frac{c}
{\sqrt{x}} = c\,x^{-1/2}.$$

By the mean-value/linearization: $\sqrt{B}-\sqrt{A} = -\frac{A-B}{\sqrt{A}+\sqrt
{B}} \sim -\frac{c\,x^{-1/2}}{2\cdot 2^{1/2}x^{1/4}} = -\frac{c}{2^{3/2}}\,x^{-3
/4}.$

Hence
$$f(x)-g(x) \sim \sqrt{c}\cdot\frac{-\frac{c}{2^{3/2}}\,x^{-3/4}}{2\,x^{1/2}} =
-\frac{c^{3/2}}{2^{5/2}}\,x^{-5/4}.$$

Since $\int^\infty x^{-5/4}\,dx$ **converges** ($5/4 > 1$), the integral **conve
rges** when $a=b$.

## Conclusion

The improper integral converges if and only if $a = b$, i.e., for exactly the pa
irs

$$\boxed{(a,b) \text{ with } a = b > 0.}$$
