## Proof

**The answer is $m = 1$.**

### Construction for $m = 1$

When $m=1$: $a = b^2$. Take $R(x,y) = y$, $P(t) = t^2$, $Q(t) = t$. Then $P(R(a,
b)) = b^2 = a$ ✓ and $Q(R(a,b)) = b$ ✓.

### Even $m$ is impossible

Let $m = 2k$ ($k \geq 1$). The curve $a^{2k} = b^2$ is equivalent to $b = \pm a^
k$, giving two branches:
$$S_+ = \{(a, a^k) : a \in \mathbb{R}\}, \quad S_- = \{(a, -a^k) : a \in \mathbb
{R}\}.$$

Define $f(a) = R(a, a^k)$ and $g(a) = R(a, -a^k)$, both polynomials in $a$.

From $P(f(a)) = a$ for all $a$: the polynomial identity $P \circ f = \mathrm{id}
$ forces $\deg(P)\cdot\deg(f) = 1$, so $f(a) = \alpha a + \beta$ with $\alpha \n
eq 0$, and $P(t) = (t-\beta)/\alpha$.

From $P(g(a)) = a$ for all $a$: similarly $g(a) = \gamma a + \delta$ with $P(t)
= (t-\delta)/\gamma$.

Equating the two expressions for $P$: $(t-\beta)/\alpha = (t-\delta)/\gamma$ for
 all $t$, which gives $\alpha = \gamma$ and $\beta = \delta$. Hence $f = g$.

But now $Q(f(a)) = a^k$ (from $S_+$) and $Q(g(a)) = Q(f(a)) = -a^k$ (from $S_-$)
, so $a^k = -a^k$ for all $a$, a contradiction. $\square$

### Odd $m \geq 3$ is impossible

For odd $m$, $a^m = b^2$ requires $a \geq 0$. The map $\varphi: \mathbb{R} \to S
$ given by $\varphi(t) = (t^2, t^m)$ is a bijection onto the curve:
- **Well-defined:** $(t^2)^m = t^{2m} = (t^m)^2$ ✓.
- **Injective:** If $t_1^2 = t_2^2$ and $t_1^m = t_2^m$, then $t_1 = \pm t_2$; i
f $t_1 = -t_2$ with $m$ odd, then $t_1^m = -t_2^m = t_2^m$ forces $t_2 = 0$, so
$t_1 = t_2$.
- **Surjective:** For $(a,b) \in S$ with $a \geq 0$, take $t = \mathrm{sgn}(b)\s
qrt{a}$; then $t^2 = a$ and $t^m = b$ (using $m$ odd).

Set $r(t) = R(t^2, t^m)$. Since $R$ is a polynomial, $r(t) \in \mathbb{R}[t^2, t
^m] \subset \mathbb{R}[t]$.

The conditions become polynomial identities:
$$P(r(t)) = t^2, \qquad Q(r(t)) = t^m.$$

**Degree argument.** From $P(r(t)) = t^2$: if $r$ is non-constant with $\deg(r)
= d$ and $P$ non-constant with $\deg(P) = e$, then $de = 2$, so $d \in \{1, 2\}$
. From $Q(r(t)) = t^m$: $d \mid m$. Since $m$ is odd, $d \mid \gcd(2, m) = 1$, s
o $d = 1$.

**But $d = 1$ is unachievable.** The ring $\mathbb{R}[t^2, t^m]$ consists of pol
ynomials whose monomials have exponents of the form $2i + mj$ for non-negative i
ntegers $i, j$. For $m \geq 3$ odd, the smallest positive such exponent is $\min
(2, m) = 2$ (since $mj \geq m \geq 3$ for $j \geq 1$, and $2i \geq 2$ for $i \ge
q 1$). The exponent $1$ is never of the form $2i + mj$, so $t \notin \mathbb{R}[
t^2, t^m]$. Therefore no degree-$1$ polynomial in $t$ lies in $\mathbb{R}[t^2, t
^m]$—the only degree-$\leq 1$ elements are constants, which cannot satisfy $P(r(
t)) = t^2$.

This contradiction shows no valid $R, P, Q$ exist for odd $m \geq 3$. $\square$

### Conclusion

The only positive integer $m$ for which such polynomials exist is $\boxed{m = 1}
$.
