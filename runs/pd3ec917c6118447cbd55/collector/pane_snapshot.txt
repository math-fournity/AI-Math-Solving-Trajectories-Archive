The given PDE is

$$\frac{\partial^2 z}{\partial x^2} - 2\frac{\partial^2 z}{\partial x\partial y}
 + \frac{\partial^2 z}{\partial y^2} = 0.$$

**Step 1. Factor the operator.** The left–hand side is a perfect square of first
-order operators:

$$\frac{\partial^2 z}{\partial x^2} - 2\frac{\partial^2 z}{\partial x\partial y}
 + \frac{\partial^2 z}{\partial y^2} = \left(\frac{\partial}{\partial x} - \frac
{\partial}{\partial y}\right)^{\!2} z.$$

Hence the equation is

$$\left(\frac{\partial}{\partial x} - \frac{\partial}{\partial y}\right)^{\!2} z
 = 0.$$

**Step 2. Change variables to characteristic coordinates.** Introduce

$$u = x + y, \qquad v = x - y.$$

By the chain rule,

$$\frac{\partial}{\partial x} = \frac{\partial u}{\partial x}\frac{\partial}{\pa
rtial u} + \frac{\partial v}{\partial x}\frac{\partial}{\partial v} = \frac{\par
tial}{\partial u} + \frac{\partial}{\partial v},$$

$$\frac{\partial}{\partial y} = \frac{\partial u}{\partial y}\frac{\partial}{\pa
rtial u} + \frac{\partial v}{\partial y}\frac{\partial}{\partial v} = \frac{\par
tial}{\partial u} - \frac{\partial}{\partial v}.$$

Therefore

$$\frac{\partial}{\partial x} - \frac{\partial}{\partial y} = 2\frac{\partial}{\
partial v},$$

and the PDE becomes

$$\left(2\frac{\partial}{\partial v}\right)^{\!2} z = 0 \quad\Longrightarrow\qua
d 4\,\frac{\partial^2 z}{\partial v^2} = 0 \quad\Longrightarrow\quad \frac{\part
ial^2 z}{\partial v^2} = 0.$$

**Step 3. Integrate twice in \(v\).** Integrating with respect to \(v\),

$$\frac{\partial z}{\partial v} = \phi(u),$$

where \(\phi\) is an arbitrary (sufficiently smooth) function of \(u\). Integrat
ing once more,

$$z = v\,\phi(u) + \psi(u),$$

where \(\psi\) is a second arbitrary (sufficiently smooth) function of \(u\).

**Step 4. Return to \((x,y)\).** Substituting \(u = x+y\) and \(v = x-y\),

$$\boxed{\,z(x,y) = (x-y)\,\phi(x+y) + \psi(x+y)\,}$$

where \(\phi\) and \(\psi\) are arbitrary twice-continuously-differentiable func
tions of a single variable.

**Verification.** Let \(u = x+y\), \(v = x-y\), and \(z = v\phi(u) + \psi(u)\).
- \(z_x = v\phi'(u) + \phi(u) + \psi'(u)\),
- \(z_y = v\phi'(u) - \phi(u) + \psi'(u)\),
- \(z_{xx} = v\phi''(u) + 2\phi'(u) + \psi''(u)\),
- \(z_{xy} = v\phi''(u)\),
- \(z_{yy} = v\phi''(u) - 2\phi'(u) + \psi''(u)\).

Then

$$z_{xx} - 2z_{xy} + z_{yy} = \bigl(v\phi'' + 2\phi' + \psi''\bigr) - 2\bigl(v\p

confirming the solution satisfies the PDE. Since the change of variables \((x,y)
