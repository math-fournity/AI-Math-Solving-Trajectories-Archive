## Solution

**Problem.** Let $f(n)$ be the number of ones in the decimal representations of
all integers from $1$ to $n$. Find $f(10^{100})$.

### Step 1: Count ones in $\{1, 2, \ldots, 10^{100}-1\}$.

Every integer from $0$ to $10^{100}-1$ can be written uniquely as a $100$-digit
string (padding with leading zeros). This gives $10^{100}$ strings ranging from
$00\ldots0$ to $99\ldots9$.

By symmetry, in any fixed position, each digit $0,1,\ldots,9$ appears exactly $1
0^{99}$ times. Hence the digit $1$ appears in each position exactly $10^{99}$ ti
mes, and across all $100$ positions:

$$\text{ones in all 100-digit strings} = 100 \cdot 10^{99} = 10^{101}.$$

The string $00\ldots0$ (representing $0$) contributes zero ones, so removing it
doesn't change the count. Leading zeros also contribute zero ones, so padding do
esn't affect the count. Therefore:

$$\text{ones in } \{1, \ldots, 10^{100}-1\} = 10^{101}.$$

### Step 2: Add the number $10^{100}$ itself.

The number $10^{100}$ is written as $1$ followed by $100$ zeros, containing exac
tly **one** digit $1$.

### Step 3: Combine.

$$f(10^{100}) = 10^{101} + 1.$$

### Verification with small cases.

- $f(10^1) = f(10)$: ones in $\{1,\ldots,9\}$ is $1$ (just the number $1$), plus
 $10$ contributes one $\to 2$. Formula: $1\cdot 10^0 + 1 = 2$. ✓
- $f(10^2) = f(100)$: ones in $\{1,\ldots,99\}$: $1$–$9$ gives $1$; $10$–$19$ gi
ves $11$; $20$–$99$ gives $8$ (ones digit only) $\to 20$. Plus $100$ gives $1$ $
\to 21$. Formula: $2\cdot 10^1 + 1 = 21$. ✓

The general formula $f(10^k) = k\cdot 10^{k-1} + 1$ holds, confirming our result
.

### Answer

$$\boxed{f(10^{100}) = 10^{101} + 1}$$
