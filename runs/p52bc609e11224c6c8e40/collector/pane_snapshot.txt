# USAMO 2001 Problem 1 — Solution

**Claim.** The smallest integer $n$ is $\boxed{23}$.

## Lower bound: $n \ge 23$

Model the configuration as 8 blocks (boxes) $B_1,\dots,B_8$, each of size 6 (the
 six distinct colors in that box), drawn from a set of $n$ colors. The condition
 "no two colors occur together in more than one box" means any two blocks inters
ect in **at most one** color:

$$|B_i\cap B_j|\le 1\quad\text{for all }i\ne j.$$

For each color $c$, let $d_c$ denote the number of boxes containing $c$. Countin
g incidences (color, box):

$$\sum_c d_c = 8\cdot 6 = 48. \tag{1}$$

Now count pairs of boxes that share a color, grouped by the shared color:

$$\sum_c \binom{d_c}{2} = \sum_{1\le i<j\le 8}|B_i\cap B_j|.$$

Since every pairwise intersection is at most 1, the right side is at most the to
tal number of box-pairs:

$$\sum_c \binom{d_c}{2}\le \binom{8}{2}=28. \tag{2}$$

By Cauchy–Schwarz, $\sum_c d_c^2 \ge \frac{(\sum_c d_c)^2}{n}=\frac{2304}{n}$, s
o

$$\sum_c\binom{d_c}{2}=\frac{\sum_c d_c^2-\sum_c d_c}{2}\ge \frac{2304/n-48}{2}=
\frac{1152}{n}-24.$$

Combining with (2):

$$\frac{1152}{n}-24\le 28\implies \frac{1152}{n}\le 52\implies n\ge \frac{1152}{
52}=\frac{288}{13}\approx 22.15.$$

Since $n$ is an integer, $\boxed{n\ge 23}$.

(For comparison, $n=22$ forces $\sum\binom{d_c}{2}\ge 30>28$, impossible.)

## Construction: $n=23$ suffices

We use 23 colors, organized as:
- two special colors $a,b$;
- nine colors $x_{ij}$ with $1\le i\le 3,\ 1\le j\le 3$;
- six colors $p_1,\dots,p_6$;
- six colors $q_1,\dots,q_6$.

Define the eight boxes:

| Box | Colors |
|-----|--------|
| $B_1$ | $a,\ x_{11},\ x_{12},\ x_{13},\ p_1,\ q_1$ |
| $B_2$ | $a,\ x_{21},\ x_{22},\ x_{23},\ p_2,\ q_2$ |
| $B_3$ | $a,\ x_{31},\ x_{32},\ x_{33},\ p_3,\ q_3$ |
| $B_4$ | $b,\ x_{11},\ x_{21},\ x_{31},\ p_4,\ q_4$ |
| $B_5$ | $b,\ x_{12},\ x_{22},\ x_{32},\ p_5,\ q_5$ |
| $B_6$ | $b,\ x_{13},\ x_{23},\ x_{33},\ p_6,\ q_6$ |
| $B_7$ | $p_1,\ p_2,\ p_3,\ p_4,\ p_5,\ p_6$ |
| $B_8$ | $q_1,\ q_2,\ q_3,\ q_4,\ q_5,\ q_6$ |

**Each box has 6 distinct colors** — clear by inspection.

**Any two colors occur together in at most one box.** We verify by tracking whic
h boxes each color lives in:
- $a$ is in $\{B_1,B_2,B_3\}$; $b$ is in $\{B_4,B_5,B_6\}$.
- $x_{ij}$ is in $\{B_i,\ B_{j+3}\}$ (exactly two boxes, one "row" box and one "
column" box).
- $p_k$ is in $\{B_k,\ B_7\}$; $q_k$ is in $\{B_k,\ B_8\}$.

Now check every type of color-pair:

1. **$(a,\cdot)$**: $a$ meets $x_{ij}$ only in $B_i$; meets $p_i,q_i$ only in $B
_i$; meets $p_j,q_j$ ($j\in\{4,5,6\}$) in no box; meets $b$ in no box. At most o
ne box each. ✓

2. **$(b,\cdot)$**: symmetric to $(a,\cdot)$. ✓

3. **$(x_{ij},x_{i'j'})$**, distinct: they share a box iff $i=i'$ (then only $B_
i$) or $j=j'$ (then only $B_{j+3}$); since $i\le 3<j'+3$ and $j\ge 4>i'+1$, at m
ost one common box. ✓

4. **$(p_i,p_j)$**, $i\ne j$: both only in $B_7$. ✓
   **$(q_i,q_j)$**, $i\ne j$: both only in $B_8$. ✓
   **$(p_i,q_j)$**: common box iff $i=j$ (then $B_i$); otherwise none. ✓

5. **$(x_{ij},p_k)$**: common box iff $k=i$ (box $B_i$) or $k=j+3$ (box $B_{j+3}
$); these are distinct indices ($i\le 3$, $j+3\ge 4$), so at most one. ✓
   **$(x_{ij},q_k)$**: identical argument. ✓

6. **$(p_i,q_i)$**: only $B_i$. **$(p_i,q_j)$, $i\ne j$**: none. ✓

Every pair of colors co-occurs in at most one box, and within each box all six c
olors are distinct. All conditions are satisfied with $n=23$ colors.

## Conclusion

The lower bound forces $n\ge 23$, and the explicit construction above achieves $
n=23$. Therefore the smallest integer $n$ for which the arrangement is possible
is

$$\boxed{23}.$$
