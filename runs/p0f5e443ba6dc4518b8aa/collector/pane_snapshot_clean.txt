## Solution

**Yes**, such a nowhere continuous function exists.

### Key observation

Let $R = f(\mathbb{R})$ be the range of $f$. Setting $y = f(x)$, the equation $f
(f(x)) = (f(x))^2$ becomes

$$f(y) = y^2 \quad \text{for every } y \in R. \tag{1}$$

So $f$ acts as the squaring map **on its own range**, and $R$ is closed under sq
uaring (since $y^2 = f(y) \in R$).

### Constructing a candidate

Take $R = \{0, 1\}$, which is closed under squaring ($0^2=0,\; 1^2=1$). Conditio
n (1) forces

$$f(0) = 0, \qquad f(1) = 1. \tag{2}$$

For $y \in \{0,1\}$ we have $y^2 = y$, so the original equation reduces to $f(f(
x)) = f(x)$, which is automatically satisfied whenever (2) holds and $f$ takes o
nly the values $0$ and $1$:

- if $f(x)=0$: $f(f(x)) = f(0) = 0 = f(x)$;
- if $f(x)=1$: $f(f(x)) = f(1) = 1 = f(x)$.

Thus **any** function $f \colon \mathbb{R} \to \{0,1\}$ satisfying $f(0)=0$ and
$f(1)=1$ solves the equation.

### Making it nowhere continuous

Start with the Dirichlet function $\mathbf{1}_{\mathbb{Q}}$ (indicator of the ra
tionals), which is nowhere continuous and satisfies $\mathbf{1}_{\mathbb{Q}}(1)=
1$. It fails only $f(0)=0$ since $\mathbf{1}_{\mathbb{Q}}(0)=1$. Define

$$f(x) = \begin{cases} 0 & x = 0, \\ \mathbf{1}_{\mathbb{Q}}(x) & x \neq 0. \end
{cases}$$

Then $f(0)=0$ and $f(1)=1$, and $f$ takes values in $\{0,1\}$, so by the argumen
t above $f(f(x)) = (f(x))^2$ for all $x$.

### Nowhere continuity

Modifying a function at a single point cannot create continuity at any other poi
nt, so $f$ is discontinuous at every $x_0 \neq 0$ (being locally equal to the Di
richlet function there). At $x_0 = 0$: $f(0)=0$, yet every neighborhood of $0$ c
ontains rationals $q \neq 0$ with $f(q)=1$ and irrationals $r$ with $f(r)=0$, so
 $f$ has no limit at $0$ and is discontinuous there too.

Hence $f$ is **nowhere continuous** and satisfies $f(f(x)) = (f(x))^2$ for all $
x \in \mathbb{R}$.
