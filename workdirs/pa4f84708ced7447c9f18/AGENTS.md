# Problem

In a specialized cyber-security facility, a technician is auditing a series of digital servers identified by their unique serial IDs, which are positive integers $n$ ranging from $1$ to $100$ inclusive. 

A server is flagged as "vulnerable" if there exists a secret encryption key $m$ (a positive integer) and two distinct firewall clearance levels represented by prime numbers $p$ and $q$ (where $1 < p < q$) that satisfy the following two security protocols:

1. The difference between the clearance levels, $q - p$, must be a factor of the encryption key $m$.
2. When the server ID $n$ is raised to the power of the encryption key $m$, the resulting value increased by $1$ (the quantity $n^m + 1$) must be perfectly divisible by both clearance levels $p$ and $q$.

Calculate the sum of all server IDs $n$ that meet these vulnerability criteria.
