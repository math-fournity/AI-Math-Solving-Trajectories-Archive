## Proof of the Erdős–Herzog–Piranian Component Lemma

**Theorem.** Let $f$ be a monic polynomial of degree $n \geq 2$ with all roots i
n the open unit disk $\{z : |z| < 1\}$. Then some connected component of $\{z :
|f(z)| < 1\}$ contains at least two roots of $f$, counted with multiplicity.

**Proof.**

**Case 1: $f$ has a repeated root.** If some root $z_0$ has multiplicity $\geq 2
$, then $|f(z_0)| = 0 < 1$, so $z_0$ lies in some component $C$ of $\{|f|<1\}$,
and $C$ contains at least 2 roots counted with multiplicity. Done.

i| < 1$.

**Step 1: Lemniscate topology.** For small $\epsilon > 0$, the sublevel set $S_\
epsilon = \{|f| < \epsilon\}$ consists of $n$ disjoint topological disks, each c
ontaining exactly one root. As $\epsilon$ increases, the topology of $S_\epsilon

where $\beta$ is a critical point ($f'(\beta) = 0$, $f(\beta) \neq 0$). At each
such level, two or more components merge (this is standard Morse theory for $|f|
^2$, which is a Morse function away from critical points).

$$|f(\beta)| \geq 1 \quad \text{for every critical point } \beta \text{ of } f.
