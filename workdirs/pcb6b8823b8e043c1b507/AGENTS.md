# Problem

A digital security firm is analyzing a collection of 10,000 unique encryption keys, each represented by a large integer. Initial scans confirm that none of these keys are divisible by the prime security constant 47. 

The firm’s goal is to select a sub-collection of these keys to form a "linear-interference-free" set. A set is considered interference-free if, for any five keys chosen from the set—denoted as $a, b, c, d,$ and $e$ (which do not have to be distinct)—the specific combined signal $a - b + c - d + e$ is never divisible by the constant 47.

Using a probabilistic approach or an analysis of residues modulo 47, what is the largest integer $k$ such that, regardless of the specific 10,000 integers provided, one can always guarantee the existence of an interference-free sub-collection containing at least $k$ keys?
