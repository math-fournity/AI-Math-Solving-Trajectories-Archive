## Proof

**Claim:** Yes. The set of limit points of $u(x)$ as $x\to\infty$ is necessarily
 nonempty.

**Setup.** Since $u\in L^\infty(\mathbb{R},\mathbb{R}^n)$, there is $M>0$ such t
hat $|u(x)|\le M$ for a.e. $x$. Pick a representative $\tilde u$ of the equivale
nce class with $|\tilde u(x)|\le M$ for **every** $x\in\mathbb{R}$ (redefine $\t
ilde u:=0$ on the exceptional null set). This is possible because modifying an $
L^\infty$ function on a null set does not change its class.

Define the set of limit points (the $\omega$-limit set) of $\tilde u(x)$ as $x\t
o\infty$:
$$\Omega \;=\; \bigcap_{R>0}\,\overline{\tilde u\bigl([R,\infty)\bigr)} \;\subse
teq\; \mathbb{R}^n.$$
Equivalently, $y\in\Omega$ iff there exists a sequence $x_k\to\infty$ with $\til
de u(x_k)\to y$.

**Compactness argument.** For each $R>0$ set $K_R:=\overline{\tilde u([R,\infty)
)}$.

- *Nonempty:* $[R,\infty)\neq\varnothing$, so $\tilde u([R,\infty))\neq\varnothi
ng$, hence $K_R\neq\varnothing$.
- *Compact:* $\tilde u([R,\infty))\subseteq\overline{B(0,M)}$, the closed ball o
f radius $M$ in $\mathbb{R}^n$, which is compact. Thus $K_R$, being a closed sub
set of a compact set, is compact.
- *Nested:* if $0<R_1<R_2$, then $[R_2,\infty)\subseteq[R_1,\infty)$, so $K_{R_2
}\subseteq K_{R_1}$.

By **Cantor's intersection theorem**, the intersection of a nested family of non
empty compact sets is nonempty. Therefore
$$\Omega=\bigcap_{R>0}K_R\neq\varnothing.$$

**Realizing a limit point.** Take $y\in\Omega$. For each $k\in\mathbb{N}$, $y\in
 K_k=\overline{\tilde u([k,\infty))}$, so there exists $x_k\ge k$ with $|\tilde
u(x_k)-y|<1/k$. Then $x_k\to\infty$ and $\tilde u(x_k)\to y$, confirming $y$ is
a genuine limit point of $u(x)$ as $x\to\infty$.

**Remark on representatives.** The argument above uses a bounded representative.
 If one prefers the representative-independent formulation, replace $\tilde u([R
,\infty))$ by the *essential range* of $u$ on $[R,\infty)$: it is closed, contai
ned in $\overline{B(0,M)}$ (hence compact), nonempty (since $[R,\infty)$ has pos
itive measure), and nested in $R$; the same Cantor-intersection argument yields
a nonempty essential $\omega$-limit set. Either interpretation gives the same co
nclusion.

**Conclusion.** Essential boundedness forces the values $u(x)$ to live in a fixe
d compact ball, and the nested nonempty compact sets $\overline{u([R,\infty))}$
cannot have empty intersection. Hence the set of limit points of $u(x)$ as $x\to
\infty$ always contains at least one point. $\blacksquare$
