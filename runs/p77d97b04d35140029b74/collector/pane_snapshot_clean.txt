## 解答

**第 1 步：对递推关系进行因式分解。**

对于 $i = 1, \dots, 1995$，递推关系为：
$$x_{i-1} + \frac{2}{x_{i-1}} = 2x_i + \frac{1}{x_i}.$$

整理得：
$$x_{i-1} - 2x_i = \frac{1}{x_i} - \frac{2}{x_{i-1}} = \frac{x_{i-1} - 2x_i}{x_i
\, x_{i-1}}.$$

因此：
$$\left(x_{i-1} - 2x_i\right)\!\left(1 - \frac{1}{x_i\, x_{i-1}}\right) = 0.$$

由于所有 $x_i > 0$，在每一步中**恰好**有以下之一成立：
- **(H)** $x_i = \dfrac{x_{i-1}}{2}$ &ensp;(“减半”)，或者
- **(R)** $x_i = \dfrac{1}{x_{i-1}}$ &ensp;(“取倒数”)。

**第 2 步：在 $t = \log_2 x$ 下进行分析。**

令 $t_i = \log_2 x_i$。这两个操作变为：
- **H**: $t \mapsto t - 1$,
- **R**: $t \mapsto -t$.

在 $t$ 中进行 1995 次此类操作后，复合函数为仿射映射 $t \mapsto \varepsilon\, t +
 c$，其中 $\varepsilon = (-1)^r$ ($r$ = R 操作的次数)。

通过追踪 $t=0$ 的变化（或者等价地，每个 H 贡献 $-1$，随后被所有后续的 R 操作取反
），常数 $c$ 为：
$$c = -\sum_{\text{H at position } j} (-1)^{\rho_j},$$
其中 $\rho_j$ = 第 $j$ 个 H 操作之后的 R 操作次数。每个 H 贡献 $+1$（若 $\rho_j$
 为奇数）或 $-1$（若 $\rho_j$ 为偶数），因此 $c = 2k - h$，其中 $k = \#\{j : \rh
o_j \text{ 为奇数}\}$ 且 $h$ 为 H 操作的总数。

**第 3 步：循环条件 $t_{1995} = t_0$。**

我们需要 $\varepsilon\, t_0 + c = t_0$。

- **若 $r$ 为偶数** ($\varepsilon = 1$)：需要 $c = 0$，即 $k = h/2$。但 $r + h =
 1995$ 为奇数，所以 $r$ 为偶数意味着 $h$ 为奇数，因此 $h/2$ 不是整数——**不可能**
。

- **若 $r$ 为奇数** ($\varepsilon = -1$)：需要 $-t_0 + c = t_0$，即 $t_0 = c/2$
，因此 $x_0 = 2^{c/2}$。

**第 4 步：最大化 $x_0 = 2^{c/2}$。**

当 $r$ 为奇数时，$h = 1995 - r$ 为偶数；令 $m = h/2$。此时 $c = 2(k - m)$，其中
$0 \le k \le h = 2m$，因此：
$$\frac{c}{2} = k - m \in \{-m, -m+1, \dots, m\}.$$

最大值为 $c/2 = m$，在 $k = h$（每个 H 都有奇数个后续 R）时取得。为了最大化 $m =
 (1995 - r)/2$，我们最小化 $r$。由于 $r$ 为奇数且 $\ge 1$，最优选择是 $r = 1$，$
h = 1994$，$m = 997$。

**第 5 步：构造。**

取 $r=1$，$h=1994$，所有 H 操作均在单个 R 操作之前：

$$\underbrace{H, H, \dots, H}_{1994},\; R.$$

此时 $x_0 = 2^{997}$，经过 1994 次减半后变为 $x_{1994} = 2^{997 - 1994} = 2^{-99
7}$，再经过一次取倒数变为 $x_{1995} = 2^{997} = x_0$。所有值均为正实数。✓

$$\boxed{2^{997}}$$
