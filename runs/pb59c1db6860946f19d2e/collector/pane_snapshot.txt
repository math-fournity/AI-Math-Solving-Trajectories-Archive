## Setup

**PCST LP relaxation** (cut/subtour formulation): with root $r$, edge variables
$x_e$, node variables $z_v$:

$$\min \sum_{e} c_e x_e + \sum_{v \neq r} \pi_v(1 - z_v)$$

s.t. $\sum_{e \in \delta(S)} x_e \geq z_v$ for all non-empty $S \subseteq V \set
minus \{r\}$, all $v \in S$; $\; 0 \le x_e, z_v \le 1$.

**Infinite penalties** force $z_v = 1$ for every $v$, reducing to the spanning-t
ree LP:

$$\min \sum_{e} x_e \quad \text{s.t.} \quad \sum_{e \in \delta(S)} x_e \geq 1 \;
\;\forall\, \emptyset \neq S \subseteq V\setminus\{r\}, \quad 0 \le x_e \le 1.$$

## Integer Optimum

A cycle on $n$ nodes has $n$ edges. A spanning tree uses exactly $n-1$ edges, ea
ch of cost 1, so:

$$\text{OPT}_{\text{IP}} = n - 1.$$

## LP Optimum

Label edges $e_1, \dots, e_n$ around the cycle, with root $r$ between $e_n$ and
$e_1$. The nodes along the path from $r$ are $v_1(=r), v_2, \dots, v_n$.

**Key observation:** Every contiguous arc $\{v_i, \dots, v_j\}$ (with $2 \le i \
le j \le n$) has boundary $\{e_{i-1}, e_j\}$, giving the constraint $x_{i-1} + x
_j \geq 1$. As $(i,j)$ ranges over all valid pairs, the indices $(i{-}1, j)$ ran
ge over **all pairs** $(a, b)$ with $1 \le a < b \le n$. Therefore:

$$x_a + x_b \geq 1 \quad \text{for every pair } 1 \le a < b \le n.$$

**Feasible solution:** Set $x_e = \tfrac{1}{2}$ for all $n$ edges. Every pairwis
e constraint holds with equality. LP value $= \frac{n}{2}$.

**Optimality:** Order variables $x_{(1)} \le x_{(2)} \le \cdots \le x_{(n)}$. Th
e pairwise constraints require $x_{(1)} + x_{(k)} \ge 1$ for all $k \ge 2$, so $
x_{(k)} \ge 1 - x_{(1)}$ for all $k \ge 2$.

- If $x_{(1)} \le \tfrac{1}{2}$: $\sum x_i \ge x_{(1)} + (n{-}1)(1 - x_{(1)}) =
(n{-}1) - (n{-}2)\,x_{(1)}$, minimized at $x_{(1)} = \tfrac{1}{2}$, giving $\sum
 x_i \ge \frac{n}{2}$.
- If $x_{(1)} > \tfrac{1}{2}$: all $x_{(k)} > \tfrac{1}{2}$, so $\sum x_i > \fra
c{n}{2}$.

Non-contiguous subsets $S$ with $k$ components have $|\delta(S)| = 2k \ge 4$ bou
ndary edges, so their constraints $\sum_{\delta(S)} x_e \ge 1$ are implied by th
e pairwise constraints and are redundant.

Therefore:

$$\text{OPT}_{\text{LP}} = \frac{n}{2}.$$

## Integrality Gap

$$\text{Integrality Gap} = \frac{\text{OPT}_{\text{IP}}}{\text{OPT}_{\text{LP}}}
 = \frac{n-1}{n/2} = \frac{2(n-1)}{n}.$$
