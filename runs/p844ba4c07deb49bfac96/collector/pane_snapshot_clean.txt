**Claim.** The generating function is
$$\sum_{n\ge 0} f(n)\frac{x^n}{n!} \;=\; \frac{1}{2-e^x}.$$

**Step 1. Faces of $\mathcal{B}_n$ biject with ordered set partitions of $\{1,\d
ots,n\}$.**

The braid arrangement $\mathcal{B}_n$ in $\mathbb{R}^n$ consists of the hyperpla
nes $H_{ij}:\ x_i=x_j$ for $1\le i<j\le n$. A point $p=(x_1,\dots,x_n)$ determin
es, for every pair $(i,j)$, the sign of $x_i-x_j$ (positive, negative, or zero).
 Two points lie in the relative interior of the same face of the arrangement if
and only if these signs agree for all pairs $(i,j)$.

This sign data is equivalent to a **weak ordering** of the coordinates $x_1,\dot
s,x_n$: define $i\sim j$ iff $x_i=x_j$, partition $\{1,\dots,n\}$ into the resul
ting equivalence classes (blocks), and order the blocks by the common value of $
x$ on each block. This produces an **ordered set partition**
$$(B_1\mid B_2\mid\cdots\mid B_k),\qquad x_i<x_j\text{ for }i\in B_a,\ j\in B_b,
\ a<b.$$

Conversely, every ordered set partition $(B_1\mid\cdots\mid B_k)$ of $\{1,\dots,
n\}$ is realized by, e.g., the point with $x_i = a$ for $i\in B_a$, which lies i
n the interior of a face. Hence faces of $\mathcal{B}_n$ are in bijection with o
rdered set partitions of an $n$-element set.

**Step 2. Count ordered set partitions.**

Choosing an ordered set partition of $\{1,\dots,n\}$ into $k$ (nonempty, ordered
) blocks amounts to: choosing a set partition into $k$ blocks ($S(n,k)$ ways, wh
ere $S(n,k)$ is a Stirling number of the second kind) and then ordering the $k$
blocks ($k!$ ways). Thus
$$f(n)=\sum_{k=0}^{n} k!\, S(n,k),$$
which is the $n$-th **ordered Bell (Fubini) number**.

**Step 3. Compute the exponential generating function.**

Using the standard EGF $\displaystyle\sum_{n\ge 0} S(n,k)\frac{x^n}{n!}=\frac{(e
^x-1)^k}{k!}$,
$$\sum_{n\ge 0} f(n)\frac{x^n}{n!}
= \sum_{n\ge 0}\sum_{k=0}^{n} k!\,S(n,k)\frac{x^n}{n!}
= \sum_{k\ge 0} k!\sum_{n\ge 0} S(n,k)\frac{x^n}{n!}
= \sum_{k\ge 0} k!\cdot\frac{(e^x-1)^k}{k!}
= \sum_{k\ge 0}(e^x-1)^k.$$
Since $e^x-1\to 0$ as $x\to 0$, this geometric series converges near $x=0$ and s
ums to
$$\frac{1}{1-(e^x-1)}=\frac{1}{2-e^x}.$$

**Step 4. Verification.** Expanding $\frac{1}{2-e^x}=\frac{1}{2}\cdot\frac{1}{1-
e^x/2}=\sum_{k\ge 0}\frac{e^{kx}}{2^{k+1}}$, the coefficient of $\frac{x^n}{n!}$
 is $\sum_{k\ge 0}\frac{k^n}{2^{k+1}}$, giving $1,1,3,13,75,541,4683,\dots$ for
$n=0,1,2,3,4,5,6$, matching the stated sequence. $\blacksquare$

$$\boxed{\displaystyle\sum_{n\ge 0} f(n)\frac{x^n}{n!}=\frac{1}{2-e^x}}$$
