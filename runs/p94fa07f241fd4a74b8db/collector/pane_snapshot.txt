## Setup

Place D (foot of altitude from A to BC) at the origin, BC along the x-axis. Sinc
e angle A is obtuse, D lies between B and C:

- A = (0, h), B = (-b, 0), C = (c, 0), with b, c, h > 0
- M = midpoint of BC = ((c−b)/2, 0)
- N = midpoint of BD = (−b/2, 0)

**Constraint 1:** AC = 2, so c² + h² = 4.

## Constraint 2: ∠BAN = ∠MAC

Using tan of the angle between vectors from A:

**tan(∠BAN)** (between AB = (−b, −h) and AN = (−b/2, −h)):
$$\tan(\angle BAN) = \frac{bh/2}{b^2/2 + h^2} = \frac{bh}{b^2 + 2h^2}$$

**tan(∠MAC)** (between AM = ((c−b)/2, −h) and AC = (c, −h)):
$$\tan(\angle MAC) = \frac{h(b+c)/2}{c(c-b)/2 + h^2} = \frac{h(b+c)}{c(c-b) + 2h
^2}$$

Setting equal and simplifying:
$$b(c^2 - 2bc - b^2) = 2ch^2 \quad \text{...(I)}$$

## Constraint 3: AB · BC = AM

$$\sqrt{b^2+h^2}\cdot(b+c) = \sqrt{\frac{(c-b)^2}{4}+h^2}$$

Squaring: $(b^2+h^2)(b+c)^2 = \frac{(c-b)^2}{4}+h^2 \quad \text{...(II)}$

## Solving the System

Let **r = b/c**. Substituting b = rc and h² = 4 − c² into (I):

$$rc \cdot c^2(1-2r-r^2) = 2c(4-c^2) \implies c^2 = \frac{8}{(r+2)(r+1)(1-r)}$$

(The denominator factors as (r+2)(r+1)(1-r), requiring 0 < r < √2−1.)

Substituting into (II) and simplifying (using c²(1−r²) = 8/(r+2), etc.):

- **LHS** = $\frac{32r(r+1)}{(r+2)^2(1-r)}$
- **RHS** = $\frac{2-6r^2-4r^3}{(r+2)(r+1)(1-r)}$

Cross-multiplying and canceling common factors (1−r) and (r+2):

$$32r(r+1)^2 = (2-6r^2-4r^3)(r+2)$$

Expanding both sides and collecting:

$$2r^4 + 23r^3 + 38r^2 + 15r - 2 = 0$$

## Factoring the Quartic

This factors as:
$$2(r+1)^2\!\left(r^2 + \tfrac{19}{2}r - 1\right) = 0$$

Since r > 0, the factor (r+1)² ≠ 0, so:
$$2r^2 + 19r - 2 = 0 \implies r = \frac{-19+\sqrt{377}}{4}$$

## Computing the Distance

The distance from B = (−b, 0) to line AM is:
$$\text{dist} = \frac{|(\vec{BA})\times(\vec{MA})|}{|AM|} = \frac{ch(r+1)/2}{AM}
$$

Using AM = AB · BC = $\sqrt{r^2c^2+h^2}\cdot c(r+1)$:

$$\text{dist} = \frac{h}{2\sqrt{r^2c^2+h^2}}$$

Earlier I computed $r^2c^2 + h^2 = \frac{4r}{r+2}$, so:

$$\text{dist} = \frac{h}{2\sqrt{4r/(r+2)}} = \frac{h\sqrt{r+2}}{4\sqrt{r}}$$

With $h^2 = \frac{4r(1-2r-r^2)}{(r+2)(r+1)(1-r)}$, substituting:

$$\text{dist} = \frac{\sqrt{1-2r-r^2}}{2\sqrt{1-r^2}}$$

## Final Simplification

From 2r² + 19r − 2 = 0: **r² = 1 − 19r/2**

Therefore:
- $1 - 2r - r^2 = 1 - 2r - 1 + \frac{19r}{2} = \frac{15r}{2}$
- $1 - r^2 = \frac{19r}{2}$

$$\text{dist} = \frac{\sqrt{15r/2}}{2\sqrt{19r/2}} = \frac{\sqrt{15}}{2\sqrt{19}
} = \frac{\sqrt{285}}{38}$$
