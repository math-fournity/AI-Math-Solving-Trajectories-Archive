## Proof

We compute the convolution $\delta' * H$ in the sense of distributions (generali
zed functions).

**Key properties used:**

1. **$\delta$ is the identity of convolution.** For any distribution $f$,
   $$\delta * f = f.$$

2. **Differentiation commutes with convolution.** For distributions $f, g$,
   $$D(f * g) = (Df) * g = f * (Dg),$$
   where $D$ denotes differentiation.

3. **Derivative of the Heaviside function.** In the distributional sense,
   $$H' = \delta.$$

**Computation:**

Using property 2 with $f = \delta$ and $g = H$:
$$\delta' * H = (D\delta) * H = D(\delta * H).$$

Using property 1, $\delta * H = H$, so:
$$\delta' * H = D(H) = H'.$$

Using property 3, $H' = \delta$, so:
$$\delta' * H = \delta.$$

**Verification via the defining integral.** Formally, the convolution is
$$(\delta' * H)(t) = \int_{-\infty}^{\infty} \delta'(\tau)\, H(t - \tau)\, d\tau
.$$

By the sifting property of $\delta'$, for any test function $\varphi$,
$$\int \delta'(\tau)\,\varphi(\tau)\,d\tau = -\varphi'(0).$$

Here $\varphi(\tau) = H(t - \tau)$, so $\varphi'(\tau) = -H'(t-\tau) = -\delta(t
-\tau)$, giving $\varphi'(0) = -\delta(t)$. Therefore
$$(\delta' * H)(t) = -\varphi'(0) = -(-\delta(t)) = \delta(t).$$

This confirms the result.

**Conclusion:**

$$\boxed{\delta' * H = \delta}$$
