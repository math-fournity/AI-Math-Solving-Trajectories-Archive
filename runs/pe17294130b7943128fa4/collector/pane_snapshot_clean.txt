## Proof

Consider the inverse system $\{A_k, f_k\}_{k \geq 0}$ where $A_k = \mathbb{Q}$ f
or all $k$ and each transition map $f_k \colon A_{k+1} \to A_k$ is multiplicatio
n by $n$.

The sequential (inverse) limit is:
$$L = \varprojlim A_k = \left\{(a_k)_{k \geq 0} \in \prod_{k=0}^{\infty} \mathbb
{Q} \;\middle|\; n \cdot a_{k+1} = a_k \text{ for all } k \geq 0 \right\}.$$

**Claim.** The projection $\pi_0 \colon L \to \mathbb{Q}$, $(a_k) \mapsto a_0$,
is an isomorphism of abelian groups.

**Injectivity.** Suppose $(a_k), (b_k) \in L$ with $a_0 = b_0$. The compatibilit
y condition gives $a_k = a_0 / n^k$ and $b_k = b_0 / n^k$ for every $k$ (by indu
ction: $a_k = n \cdot a_{k+1}$ implies $a_{k+1} = a_k / n$). Hence $a_k = b_k$ f
or all $k$, so $\pi_0$ is injective.

**Surjectivity.** Given any $q \in \mathbb{Q}$, define $a_k = q / n^k \in \mathb
b{Q}$ for each $k \geq 0$. This is well-defined because $n > 1$ (so $n \neq 0$)
and $\mathbb{Q}$ is a field, hence closed under division by nonzero integers. Th
en
$$n \cdot a_{k+1} = n \cdot \frac{q}{n^{k+1}} = \frac{q}{n^k} = a_k \quad \text{
for all } k \geq 0,$$
so $(a_k)_{k \geq 0} \in L$ and $\pi_0((a_k)) = q$. Thus $\pi_0$ is surjective.

Since $\pi_0$ is a bijective group homomorphism, it is an isomorphism. Therefore
:
$$\varprojlim \left(\cdots \xrightarrow{\times n} \mathbb{Q} \xrightarrow{\times
 n} \mathbb{Q} \xrightarrow{\times n} \mathbb{Q}\right) \cong \mathbb{Q}.$$

The essential property is that $\mathbb{Q}$ is **divisible** (in particular, $n$
-divisible for every $n > 1$), so multiplication by $n$ is surjective. This ensu
res every element $a_0 \in \mathbb{Q}$ can be "divided by $n$" indefinitely, pro
ducing a unique compatible thread through the entire inverse system.
