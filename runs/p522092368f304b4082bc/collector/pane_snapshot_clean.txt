## Solution

**Setup.** Let $u = a^3 - 3ab$ and $v = b^3$ (integers), so the expression is
$$P_n := \left(u+\tfrac12\right)^n + \left(v+\tfrac12\right)^n.$$
Set $x = u+\frac12$, $y = v+\frac12$. Then
$$s := x+y = u+v+1 = a^3+b^3-3ab+1 = (a+b+1)\big(a^2+b^2+1-ab-a-b\big),$$
an integer, and
$$p := xy = \frac{(2u+1)(2v+1)}{4} =: \frac{m}{4},$$
where $m=(2u+1)(2v+1)$ is **odd**. The power sums satisfy $P_0=2,\ P_1=s,\ P_n =
 sP_{n-1} - p\,P_{n-2}$.

**2-adic valuation analysis.** Let $w_n = v_2(P_n)$ and $\alpha = v_2(s)$ (with
$s>0$ for $(a,b)\ne(1,1)$, since $a^2+b^2+1-ab-a-b = \tfrac12((a-b)^2+(a-1)^2+(b
-1)^2)\ge 0$, equality only at $(1,1)$).

Since $m$ is odd, $v_2(p) = -2$. The recurrence gives:
- $w_0 = 1,\ w_1 = \alpha,\ w_2 = v_2(s^2 - m/2) = -1$ (since $v_2(s^2)\ge 0 > -
1 = v_2(m/2)$).

The two terms $sP_{n-1}$ and $p\,P_{n-2}$ always have **distinct** 2-adic valuat
ions (differing by $\ge 1$), so no cancellation occurs. By induction:

$$w_{2k} = -(2k-1), \qquad w_{2k+1} = \alpha - 2k \quad (k\ge 1).$$

*Even $n\ge 2$:* $w_n = -(n-1) < 0$, so $P_n$ is **never** an integer.

*Odd $n = 2k+1 \ge 3$:* $P_n$ is an integer iff $\alpha \ge 2k = n-1$, i.e. $2^{
n-1}\mid s$.

*$n=1$:* $P_1 = s$ is always an integer.

**Counting valid $n$.** The valid positive integers are $n=1$ plus those odd $n\
ge 3$ with $2^{n-1}\mid s$.

- If $s = 0$ (i.e. $a=b=1$): all odd $n$ work → infinitely many. ✗
- If $s\ne 0$: $\alpha = v_2(s)$ is finite, so only finitely many $n$ work. The
count is $1 + \lfloor \alpha/2\rfloor$.

We need count $\ge 3$: $\lfloor \alpha/2\rfloor \ge 2$, i.e. $\boxed{\alpha \ge
4}$, equivalently $16 \mid s$ (with $s\ne 0$, automatic).

**Minimizing $a+b$.** We need $16 \mid s = (a+b+1)\cdot Q$ where $Q = a^2+b^2+1-
ab-a-b$, with $(a,b)\ne(1,1)$.

Checking all $(a,b)$ with $a+b \le 5$:

| $a+b$ | pairs | $\max v_2(s)$ |
|---|---|---|
| 2 | (1,1) | $s=0$, excluded |
| 3 | (1,2),(2,1) | $s=4$, $v_2=2$ |
| 4 | (1,3),(2,2),(3,1) | $s=20$, $v_2=2$ |
| 5 | (1,4),(2,3),(3,2),(4,1) | $s=54$, $v_2=1$ |

None reach $v_2 \ge 4$.

For $a+b = 6$, take $(a,b)=(1,5)$:
- $a+b+1 = 7$, $Q = 1+25+1-5-1-5 = 16$, so $s = 7\cdot 16 = 112$, $v_2(112) = 4$
. ✓

Verification: $x = 1-15+\frac12 = -\frac{27}{2}$, $y = 125+\frac12 = \frac{251}{
2}$, $x+y = 112$.
- $n=1$: $112$ ✓
- $n=3$: $112^3 - 3\cdot(-\tfrac{6777}{4})\cdot 112 = 1404928 + 569268 = 1974196
$ ✓
- $n=5$: integer (since $\alpha=4\ge 4$) ✓
- $n=7$: $v_2 = 4-6 = -2 <0$ ✗; all even $n$ ✗.

Exactly **three** values $\{1,3,5\}$ — at least 3, finitely many. ✓

The least possible value is $\boxed{6}$.
