## Proof

**Yes**, such a sequence exists. The key point is that $\mathcal{A}$ is only an
**algebra** (closed under *finite* operations), not a $\sigma$-algebra, and $\mu
$ is only **finitely** additive. Continuity from above — the property that $A_n
\searrow \emptyset \Rightarrow \mu(A_n) \to 0$ — requires *countable* additivity
, which we do not have here.

### Construction

Let $X = \mathbb{N} = \{1, 2, 3, \dots\}$, and let $\mathcal{A}$ be the **finite
–cofinite algebra**:
$$\mathcal{A} = \{A \subseteq \mathbb{N} : A \text{ is finite, or } A^c \text{ i
s finite}\}.$$
This is an algebra: it contains $\emptyset$ (finite) and $X$ (cofinite); it is c
losed under complements (finite $\leftrightarrow$ cofinite) and under finite uni
ons/intersections (finite $\cup$ finite $=$ finite; cofinite $\cap$ cofinite $=$
 cofinite; finite $\cup$ cofinite $=$ cofinite; finite $\cap$ cofinite $=$ finit
e).

Define $\mu: \mathcal{A} \to [0,1]$ by
$$\mu(A) = \begin{cases} 0 & \text{if } A \text{ is finite}, \\ 1 & \text{if } A
 \text{ is cofinite}. \end{cases}$$

**Finite additivity.** Let $A, B \in \mathcal{A}$ be disjoint. We check all case
s:
- *Both finite:* $A \cup B$ is finite, so $\mu(A \cup B) = 0 = 0 + 0 = \mu(A)+\m
u(B)$. ✓
- *$A$ finite, $B$ cofinite (or vice versa):* Since $A \cap B = \emptyset$, we h
ave $A \subseteq B^c$, which is finite — consistent with $A$ finite. Now $A \cup
 B$ is cofinite (its complement is $B^c \setminus A$, finite), so $\mu(A \cup B)
 = 1 = 0 + 1 = \mu(A) + \mu(B)$. ✓
- *Both cofinite:* Impossible for them to be disjoint, since each contains all b
ut finitely many naturals, so their intersection is cofinite (in particular none
mpty). ✓

Also $\mu(X) = 1$ since $X$ is cofinite. Thus $\mu$ is a finitely additive proba
bility measure on $\mathcal{A}$.

### The nested sequence

Set $A_n = \{n, n+1, n+2, \dots\}$ for $n \geq 1$. Then:
- **Nested:** $A_1 \supset A_2 \supset A_3 \supset \cdots$. ✓
- **Each $A_n \in \mathcal{A}$:** $A_n^c = \{1, \dots, n-1\}$ is finite, so $A_n
$ is cofinite. ✓
- **Empty intersection:** $\bigcap_{n=1}^{\infty} A_n = \emptyset$, since no nat
ural number belongs to every tail $\{n, n+1, \dots\}$. ✓
- **Limit of measures:** Each $A_n$ is cofinite, so $\mu(A_n) = 1$ for every $n$
. Hence
$$\lim_{n \to \infty} \mu(A_n) = \lim_{n\to\infty} 1 = 1 \neq 0.$$

### Why this doesn't contradict anything

The failure is exactly where finite additivity is weaker than countable additivi
ty. If $\mu$ were *countably* additive, then $\mu(A_n) = \mu(A_1) - \mu(A_1 \set
minus A_n)$, and $A_1 \setminus A_n = \{1, \dots, n-1\}$ (finite, measure $0$),
giving $\mu(A_n) = 1$ for all $n$ — but countable additivity would force $\mu\!\
left(\bigcup_n (A_n \setminus A_{n+1})\right) = \sum_n \mu(A_n \setminus A_{n+1}
)$, and since $\bigcup_n (A_n \setminus A_{n+1}) = A_1 = \mathbb{N}$ has measure
 $1$ while each difference is a singleton with measure $0$, we'd get $1 = 0$, a
contradiction. This contradiction shows that **$\mu$ cannot be extended to a cou
ntably additive measure on the $\sigma$-algebra generated by $\mathcal{A$** — co
nfirming that our finitely additive $\mu$ is genuinely not countably additive, a
nd the phenomenon above is real.

### Conclusion

There **does exist** a nested sequence $A_1 \supset A_2 \supset \cdots$ in $\mat
hcal{A}$ with $\bigcap_n A_n = \emptyset$ yet $\lim_{n\to\infty} \mu(A_n) \neq 0
$. The finite–cofinite algebra on $\mathbb{N}$ with $\mu(\text{finite})=0$, $\mu
(\text{cofinite})=1$ provides an explicit example: the tails $A_n = \{n, n+1, \d
ots\}$ satisfy $\mu(A_n) = 1$ for all $n$ while $\bigcap_n A_n = \emptyset$.
