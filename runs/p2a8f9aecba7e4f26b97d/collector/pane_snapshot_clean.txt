## Proof

**Claim:** Yes. If $F: \mathcal{A} \to \mathcal{B}$ between additive categories
preserves binary coproducts (or binary products), then $F$ preserves the zero ob
ject.

**Proof.** In an additive category, finite products and coproducts coincide (bip
roducts), so the two hypotheses are the same condition: $F(A \oplus B) \cong F(A
) \oplus F(B)$ for all $A, B \in \mathcal{A}$. We treat the coproduct case; the
product case is identical.

Since $0$ is the unit for $\oplus$, there is a canonical isomorphism $A \oplus 0
 \cong A$ for every $A \in \mathcal{A}$. Applying $F$ and using that $F$ preserv
es binary coproducts:
$$F(A) \cong F(A \oplus 0) \cong F(A) \oplus F(0) \quad \text{for all } A \in \m
athcal{A}. \tag{$\ast$}$$

Setting $A = 0$ in $(\ast)$ gives an isomorphism
$$\varphi: F(0) \xrightarrow{\;\sim\;} F(0) \oplus F(0),$$
with inverse $\psi: F(0) \oplus F(0) \to F(0)$.

Let $\pi_i, \iota_i$ ($i=1,2$) denote the canonical projections and injections o
f the biproduct $F(0) \oplus F(0)$, satisfying $\pi_i \circ \iota_j = \delta_{ij
}\,\mathrm{id}_{F(0)}$ and $\iota_1 \pi_1 + \iota_2 \pi_2 = \mathrm{id}_{F(0)\op
lus F(0)}$. Define
$$\varphi_i := \pi_i \circ \varphi : F(0) \to F(0), \qquad \psi_i := \psi \circ
\iota_i : F(0) \to F(0).$$

From $\varphi \circ \psi = \mathrm{id}_{F(0)\oplus F(0)}$, compose on the right
with $\iota_j$ and on the left with $\pi_i$:
$$\varphi_i \circ \psi_j = \pi_i \circ \varphi \circ \psi \circ \iota_j = \pi_i
\circ \iota_j = \delta_{ij}\,\mathrm{id}_{F(0)}.$$

In particular:
- $\varphi_1 \circ \psi_1 = \mathrm{id}_{F(0)}$, so $\varphi_1$ is an isomorphis
m with inverse $\psi_1$.
- $\varphi_1 \circ \psi_2 = 0$. Since $\varphi_1$ is an isomorphism, $\psi_2 = 0
$.
- $\varphi_2 \circ \psi_2 = \mathrm{id}_{F(0)}$. Since $\psi_2 = 0$, this gives
$\mathrm{id}_{F(0)} = \varphi_2 \circ 0 = 0$.

Therefore $\mathrm{id}_{F(0)} = 0_{F(0)}$, the zero endomorphism. This means $F(
0)$ is a zero object in $\mathcal{B}$: for any $X \in \mathcal{B}$ and any $f: X
 \to F(0)$, we have $f = \mathrm{id}_{F(0)} \circ f = 0 \circ f = 0$, so $F(0)$
is terminal; dually any $g: F(0) \to X$ satisfies $g = g \circ \mathrm{id}_{F(0)
} = g \circ 0 = 0$, so $F(0)$ is initial.

Hence $F(0) \cong 0_{\mathcal{B}}$, and $F$ preserves the zero object. $\blacksq
uare$
