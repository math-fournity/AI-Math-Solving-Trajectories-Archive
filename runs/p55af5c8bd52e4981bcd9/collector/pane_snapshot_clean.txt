**Part 1: $n = [B:F]$ always suffices.**

Let $d = [B:F]$. Choose a *minimal* generating set $B = F(\alpha_1, \dots, \alph
a_r)$ (no proper subset generates $B$). Let $m_i(x) \in F[x]$ be the minimal pol

**Claim:** $d_1 + \cdots + d_r \le d$.

*Proof by induction on $r$.* For $r=1$: $d_1 = d$. For $r \ge 2$: set $B' = F(\a
lpha_1, \dots, \alpha_{r-1})$, $d' = [B':F]$. By minimality, $B' \subsetneq B$,
so $d' < d$; since $d' \mid d$ (tower law), $d' \le d/2$. By induction, $\sum_{i
=1}^{r-1} d_i \le d'$. Also, $F(\alpha_r) \subsetneq B$ (minimality) and $d_r \m
id d$, so $d_r \le d/2$. Therefore $\sum d_i \le d' + d_r \le d/2 + d/2 = d$. $\
square$

Set $D = \sum d_i \le d$. The polynomial $g(x) = m_1(x)\cdots m_r(x)$ has degree

D < d$, define $f(x) = g(x)\cdot(x-a)^{d-D}$ for any $a \in F$; this has degree
$d$ and the same splitting field as $g$ (the linear factor already splits over $
F$). If $D = d$, take $f = g$. In either case, $f \in F[x]$ has degree $d = [B:F
]$ and its splitting field $K \supseteq B$.

**Part 2: $n = [B:F]$ is best possible.**

The normal closure $K_0$ of $B/\mathbb{Q}$ is the splitting field of $p$, with $
