# Problem

In a remote high-security facility, a circular control hub is monitored by $n$ security consoles arranged in a fixed ring (where $n \ge 3$). To maintain system integrity, each console must be assigned one of three possible signal frequencies: Red, Green, or Blue.

A frequency assignment for the $n$ consoles is classified as "Stable" if and only if the following condition is met: for every physical point located within the interior of the ring of consoles, it must be possible to find a set of three specific consoles—one of each color (Red, Green, and Blue)—such that the point lies within the geometric triangle formed by those three consoles.

If two assignments differ by even a single console's frequency, they are considered distinct. Calculate the total number of unique Stable frequency assignments possible for the ring of $n$ consoles.
