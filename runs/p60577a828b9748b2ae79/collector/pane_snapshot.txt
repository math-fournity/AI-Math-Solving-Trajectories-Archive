## Solution

**Answer.** A solution exists only when $a = 0$, and in that case the solutions
are exactly the constant functions $t(x,y) \equiv c$ for $c \in \mathbb{R}$. For
 $a \neq 0$ there is no solution.

---

### Proof

The right–hand side $\dfrac{a^{2}}{x+y}$ is defined only when $x+y\neq 0$, so bo
th equations are required on the open set $\Omega=\{(x,y):x+y\neq 0\}$. We assum
e $t$ is $C^{1}$ (so that the partial derivatives in the statement exist).

**Step 1. The first equation forces $t$ to be constant on rays from the origin.*
*

The first equation is
$$x\,t_{x}(x,y)+y\,t_{y}(x,y)=0,$$
i.e. $Vt=0$ for the vector field $V=x\,\partial_{x}+y\,\partial_{y}$. The flow o
f $V$ is
$$\Phi_{s}(x,y)=(e^{s}x,\,e^{s}y),\qquad s\in\mathbb{R}.$$
Since $\frac{d}{ds}t(\Phi_{s}(x,y))=(Vt)(\Phi_{s}(x,y))=0$, the value $t(\Phi_{s
}(x,y))$ is independent of $s$. Hence
$$t(e^{s}x,e^{s}y)=t(x,y)\quad\text{for all }s,$$
so $t$ is constant on every open ray emanating from the origin.

**Step 2. Reduction on the half-plane $x>0$.**

On $H_{+}=\{x>0\}$ each ray is uniquely parametrized by $u=y/x\in\mathbb{R}$, so
 there is a differentiable function $f$ with
$$t(x,y)=f(u),\qquad u=\frac{y}{x}.$$
Differentiating,
$$t_{x}=f'(u)\cdot\Bigl(-\frac{y}{x^{2}}\Bigr)=-\frac{u\,f'(u)}{x},\qquad t_{y}=
f'(u)\cdot\frac{1}{x}=\frac{f'(u)}{x}.$$
(One checks $x\,t_{x}+y\,t_{y}=-u f'(u)+u f'(u)=0$, confirming the first equatio
n.)

Substituting into the second equation, on the region $x>0,\;x+y\neq 0$ (i.e. $u\
neq -1$):
$$t_{x}^{2}+t_{y}^{2}=\frac{f'(u)^{2}}{x^{2}}\bigl(u^{2}+1\bigr)=\frac{a^{2}}{x+
y}=\frac{a^{2}}{x(1+u)}.$$
Multiplying by $x^{2}$,
$$f'(u)^{2}\bigl(1+u^{2}\bigr)=\frac{a^{2}\,x}{1+u}.\tag{$\ast$}$$

**Step 3. Necessity of $a=0$.**

Fix any $u\neq -1$ (say $u=0$). The left–hand side of $(\ast)$ is a fixed number
 (independent of $x$), while the right–hand side $\dfrac{a^{2}x}{1+u}$ is a line
ar function of $x$. Since $(\ast)$ must hold for **all** $x>0$, the only way a c
onstant can equal a linear function of $x$ on an interval is for both to be iden
tically zero. Thus
$$\frac{a^{2}}{1+u}=0\quad\Longrightarrow\quad a=0.$$

**Step 4. Determining $t$ when $a=0$.**

With $a=0$, the second equation becomes
$$t_{x}^{2}+t_{y}^{2}=0\quad\text{on }\Omega=\{x+y\neq 0\},$$
so $t_{x}=t_{y}=0$ on $\Omega$. Hence $t$ is locally constant on $\Omega$, which
 has two connected components $\{x+y>0\}$ and $\{x+y<0\}$; thus $t$ is constant
on each component.

Since $t\in C^{1}(\mathbb{R}^{2})$, the partial derivatives $t_{x},t_{y}$ are co
ntinuous and vanish on the dense set $\Omega$; by continuity they vanish on all
of $\mathbb{R}^{2}$. Therefore $t$ is constant on $\mathbb{R}^{2}$.

**Step 5. Verification.**

Let $t(x,y)\equiv c$ be constant and $a=0$. Then $t_{x}=t_{y}=0$, and
$$x\,t_{x}+y\,t_{y}=0,\qquad t_{x}^{2}+t_{y}^{2}=0=\frac{0^{2}}{x+y}\;(x+y\neq 0
).$$
Both equations are satisfied.

---

**Conclusion.** The system is solvable if and only if $a=0$, and the solutions a
re precisely the constant functions $t(x,y)\equiv c$, $c\in\mathbb{R}$.
