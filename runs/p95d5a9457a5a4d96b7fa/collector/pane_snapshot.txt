## Proof

**Answer: Yes.** Such a smooth invertible $P(x)$ exists locally around any point
 $x_0$.

### Step 1: Reduction to the canonical case at $x_0$

By Sylvester's law of inertia, there exists a constant invertible matrix $P_0$ s
uch that
$$P_0^T Q(x_0) P_0 = J := \begin{pmatrix} Id_p & 0 & 0 \\ 0 & -Id_q & 0 \\ 0 & 0
 & 0_k \end{pmatrix}.$$
Set $\widetilde{Q}(x) = P_0^T Q(x) P_0$. This is smooth, symmetric, has constant
 signature $(p,q,k)$, and $\widetilde{Q}(x_0) = J$. It suffices to find smooth i
nvertible $S(x)$ with $S(x_0) = I$ and $S(x)^T \widetilde{Q}(x) S(x) = J$; then
$P(x) = P_0 S(x)$ is the desired matrix.

### Step 2: Block decomposition and the rank condition

Write $r = p + q$ (the constant rank of $\widetilde{Q}$). Partition $\widetilde{
Q}(x)$ into blocks:
$$\widetilde{Q}(x) = \begin{pmatrix} A(x) & B(x) \\ B(x)^T & C(x) \end{pmatrix}$
$
where $A$ is $r \times r$, $C$ is $k \times k$. At $x_0$: $A(x_0) = J_0 := \math
rm{diag}(Id_p, -Id_q)$ (invertible), $B(x_0) = 0$, $C(x_0) = 0$.

Since $A(x_0)$ is invertible, $A(x)$ is invertible in a neighborhood $U$ of $x_0
$. For a symmetric block matrix with $A$ invertible, the congruence
$$\begin{pmatrix} I & 0 \\ -B^T A^{-1} & I \end{pmatrix} \begin{pmatrix} A & B \
\ B^T & C \end{pmatrix} \begin{pmatrix} I & -A^{-1}B \\ 0 & I \end{pmatrix} = \b
egin{pmatrix} A & 0 \\ 0 & C - B^T A^{-1}B \end{pmatrix}$$
shows that $\mathrm{rank}(\widetilde{Q}) = \mathrm{rank}(A) + \mathrm{rank}(C -
B^T A^{-1} B)$. Since $\mathrm{rank}(A) = r$ (as $A$ is $r \times r$ invertible)
 and $\mathrm{rank}(\widetilde{Q}) = r$ (constant), we conclude:
$$C(x) = B(x)^T A(x)^{-1} B(x) \quad \text{for all } x \in U. \tag{$\star$}$$

### Step 3: Eliminating the off-diagonal block

Define the smooth matrix
$$R(x) = \begin{pmatrix} I_r & -A(x)^{-1} B(x) \\ 0 & I_k \end{pmatrix}, \qquad
R(x_0) = I.$$
A direct computation using $(\star)$ gives:
$$R(x)^T \widetilde{Q}(x) R(x) = \begin{pmatrix} A(x) & 0 \\ 0 & 0_k \end{pmatri
x}.$$
This is smooth since $A^{-1}$ is smooth (the inverse of a smooth invertible matr
ix is smooth).

### Step 4: Diagonalizing the non-degenerate block via smooth Gram–Schmidt

It remains to find smooth $S_0(x)$ with $S_0(x)^T A(x) S_0(x) = J_0$. The matrix
 $A(x)$ is smooth, symmetric, invertible, with $A(x_0) = J_0 = \mathrm{diag}(Id_
p, -Id_q)$, and constant signature $(p, q, 0)$ (invertibility near $x_0$ prevent
s eigenvalue sign changes).

Perform the **Gram–Schmidt process** on the standard basis $\{e_1, \ldots, e_r\}
$ with respect to the bilinear form $\langle u, v \rangle_x = u^T A(x) v$:

- Set $f_1 = e_1$. Since $\langle f_1, f_1\rangle_{x_0} = (J_0)_{11} = +1 \neq 0
$, we have $\langle f_1, f_1\rangle_x \neq 0$ near $x_0$. Define $\tilde{f}_1 =
f_1 / \sqrt{|\langle f_1, f_1\rangle_x|}$, so $\langle \tilde{f}_1, \tilde{f}_1\
rangle_x = \mathrm{sgn}(\langle f_1,f_1\rangle_{x_0}) = +1$.

- For $i = 2, \ldots, r$: set $f_i = e_i - \sum_{j < i} \frac{\langle e_i, \tild
e{f}_j\rangle_x}{\langle \tilde{f}_j, \tilde{f}_j\rangle_x} \tilde{f}_j$. Then $
\langle f_i, \tilde{f}_j\rangle_x = 0$ for $j < i$. At $x_0$, $f_i(x_0) = e_i$ a
nd $\langle f_i, f_i\rangle_{x_0} = (J_0)_{ii} = \pm 1 \neq 0$. By continuity, $
\langle f_i, f_i\rangle_x \neq 0$ near $x_0$ with the **same sign** as at $x_0$.
 Set $\tilde{f}_i = f_i / \sqrt{|\langle f_i, f_i\rangle_x|}$.

All operations involve only smooth functions and divisions/square-roots of nonva
nishing smooth functions, so $\tilde{f}_1, \ldots, \tilde{f}_r$ are **smooth** v
ector fields. They satisfy:
$$\langle \tilde{f}_i, \tilde{f}_j \rangle_x = 0 \ (i \neq j), \qquad \langle \t
ilde{f}_i, \tilde{f}_i \rangle_x = \pm 1,$$
with the signs matching those of $J_0$ (first $p$ entries $+1$, next $q$ entries
 $-1$), since signs are preserved near $x_0$.

Let $S_0(x)$ be the matrix with columns $\tilde{f}_1(x), \ldots, \tilde{f}_r(x)$
. Then:
$$S_0(x)^T A(x) S_0(x) = J_0, \qquad S_0(x_0) = I.$$

### Step 5: Composition

Define $\widetilde{S}(x) = \begin{pmatrix} S_0(x) & 0 \\ 0 & I_k \end{pmatrix}$
(smooth, invertible, $\widetilde{S}(x_0) = I$). Then:
$$\widetilde{S}(x)^T \begin{pmatrix} A(x) & 0 \\ 0 & 0_k \end{pmatrix} \widetild
e{S}(x) = \begin{pmatrix} S_0^T A S_0 & 0 \\ 0 & 0_k \end{pmatrix} = \begin{pmat
rix} J_0 & 0 \\ 0 & 0_k \end{pmatrix} = J.$$

Set $S(x) = R(x)\,\widetilde{S}(x)$. This is smooth, invertible (product of inve
rtible matrices), $S(x_0) = I$, and:
$$S(x)^T \widetilde{Q}(x) S(x) = \widetilde{S}^T R^T \widetilde{Q} R \widetilde{
S} = J.$$

Finally, $P(x) = P_0 \, S(x)$ is smooth and invertible, and:
$$\boxed{P(x)^T Q(x) P(x) = J = \begin{pmatrix} Id_p & 0 & 0 \\ 0 & -Id_q & 0 \\
 0 & 0 & 0_k \end{pmatrix}.} \qquad \blacksquare$$
