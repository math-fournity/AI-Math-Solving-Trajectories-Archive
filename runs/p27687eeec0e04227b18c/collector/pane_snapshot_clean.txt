## Solution

We consider the SDE
$$dX(t) = a(t)\,X(t)\,dt + b(t)\,X(t)\,dW(t), \qquad X(0) = x_0,$$
where $b(t) \neq 0$ a.s. and $W(t)$ is a Wiener process under measure $P$.

### Step 1. Explicit solution

This is a linear SDE (geometric Brownian motion with time-dependent coefficients
). Applying Itô's formula to $\ln X(t)$, or equivalently recognizing the integra
ting factor, the unique strong solution is:

$$\boxed{X(t) = x_0 \exp\!\left(\int_0^t \!\Big(a(s) - \tfrac{1}{2}b(s)^2\Big)\,
ds + \int_0^t b(s)\,dW(s)\right).}$$

### Step 2. Conditional expectation

For $0 \le s \le t$, we factor:
$$X(t) = X(s)\,\exp\!\left(\int_s^t \!\Big(a(u)-\tfrac{1}{2}b(u)^2\Big)\,du + \i
nt_s^t b(u)\,dW(u)\right).$$

The stochastic integral $Z := \int_s^t b(u)\,dW(u)$ is independent of $\mathcal{
F}_s$ (Brownian increments) and is Gaussian:
$$Z \sim N\!\left(0,\; \int_s^t b(u)^2\,du\right).$$

Using the moment-generating function of a Gaussian, $E[e^Z] = e^{\frac{1}{2}\mat
hrm{Var}(Z)}$:

$$E\!\left[\exp\!\left(\int_s^t b(u)\,dW(u)\right)\right] = \exp\!\left(\tfrac{1
}{2}\int_s^t b(u)^2\,du\right).$$

Since $X(s)$ is $\mathcal{F}_s$-measurable and the exponential factor is indepen
dent of $\mathcal{F}_s$:

$$E[X(t)\mid\mathcal{F}_s] = X(s)\,\exp\!\left(\int_s^t\!\big(a(u)-\tfrac{1}{2}b
(u)^2\big)\,du\right)\cdot\exp\!\left(\tfrac{1}{2}\int_s^t b(u)^2\,du\right)$$

$$= X(s)\,\exp\!\left(\int_s^t a(u)\,du\right).$$

### Step 3. Martingale condition

$X(t)$ is a $P$-martingale if and only if $E[X(t)\mid\mathcal{F}_s] = X(s)$ for
all $0\le s\le t$, i.e.,

$$\exp\!\left(\int_s^t a(u)\,du\right) = 1 \quad \text{for all } 0\le s\le t.$$

Equivalently,
$$\int_s^t a(u)\,du = 0 \quad \text{for all } 0\le s\le t.$$

By the Lebesgue differentiation theorem (or the fundamental theorem of calculus
for Lebesgue integrals), this holds if and only if

$$\boxed{a(t) = 0 \quad \text{a.e.}}$$

### Step 4. Integrability check

With $a(t)=0$ a.e., $X(t) = x_0\,\mathcal{E}\!\left(\int_0^t b(s)\,dW(s)\right)$
, the stochastic (Doléans–Dade) exponential. This is a **nonnegative local marti
ngale**, hence a supermartingale, with

$$E[X(t)] = x_0\,\exp\!\left(\int_0^t a(u)\,du\right) = x_0 < \infty,$$

so $X(t)$ is integrable for every $t$. Under the standard assumption that $b$ sa
tisfies the Novikov condition $E\!\left[\exp\!\left(\tfrac{1}{2}\int_0^T b(s)^2\
,ds\right)\right]<\infty$ (guaranteeing the stochastic exponential is a *true* m
artingale rather than merely a local one), $X(t)$ is a genuine $P$-martingale.

### Conclusion

The necessary and sufficient condition on $a(t)$ is:

$$\boxed{a(t) = 0 \text{ almost everywhere.}}$$

Under this condition (with $b(t)\neq 0$ a.s. as given, and assuming the usual in
tegrability/Novikov condition on $b$), the drift vanishes, the solution reduces
to the pure stochastic exponential $X(t)=x_0\,\mathcal{E}\!\left(\int_0^t b\,dW\
right)$, and $X(t)$ is a $P$-martingale.
