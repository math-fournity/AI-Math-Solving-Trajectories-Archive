## Solution

Let $u = (x_1, \dots, x_{n-2}) \in \mathbb{R}^{n-2}$ and $v = (x_{n-1}, x_n) \in
 \mathbb{R}^2$. The quadratic form becomes
$$Q = x_1^2 + \cdots + x_{n-2}^2 - x_{n-1}^2 - x_n^2 = |u|^2 - |v|^2,$$
so the set in question is
$$S = \{(u, v) \in \mathbb{R}^{n-2} \times \mathbb{R}^2 : |u| < |v|\}.$$

**Key observation.** The condition $|u| < |v|$ forces $|v| > 0$, hence $v \neq 0
$. Therefore
$$S = \{(u, v) : v \in \mathbb{R}^2 \setminus \{0\},\; u \in B_{|v|}(0) \subset
\mathbb{R}^{n-2}\},$$
where $B_r(0)$ is the open ball of radius $r$.

**The base $\mathbb{R}^2 \setminus \{0\}$ is path-connected.** For any two nonze
ro points $v_1, v_2 \in \mathbb{R}^2$, one can connect them by a path avoiding t
he origin (e.g., go radially out to a large circle, traverse the circle, then go
 radially in). This is where the dimension $2$ of the negative-definite part is
essential: $\mathbb{R}^k \setminus \{0\}$ is path-connected if and only if $k \g
eq 2$.

**The fiber over each $v$ is path-connected.** For fixed $v \neq 0$, the set $\{
u : |u| < |v|\}$ is the open ball $B_{|v|}(0) \subset \mathbb{R}^{n-2}$, which i
s convex and hence path-connected (note $n - 2 \geq 2 \geq 1$).

**$S$ is path-connected.** Take any two points $(u_1, v_1), (u_2, v_2) \in S$. W
e construct a path in three stages:

1. **Shrink $u_1$ to $0$:** $(u(t), v(t)) = ((1-t)\,u_1,\; v_1)$ for $t \in [0,1
]$. Then $|u(t)| = (1-t)|u_1| \leq |u_1| < |v_1| = |v(t)|$, so the path stays in
 $S$. We reach $(0, v_1)$.

2. **Move $v_1$ to $v_2$ in $\mathbb{R}^2 \setminus \{0\}$:** Let $\gamma : [0,1
] \to \mathbb{R}^2 \setminus \{0\}$ be a path with $\gamma(0) = v_1$, $\gamma(1)
 = v_2$. Set $(u(t), v(t)) = (0, \gamma(t))$. Since $|u(t)| = 0 < |\gamma(t)|$,
the path stays in $S$. We reach $(0, v_2)$.

3. **Grow $0$ to $u_2$:** $(u(t), v(t)) = (t\,u_2,\; v_2)$ for $t \in [0,1]$. Th
en $|u(t)| = t|u_2| \leq |u_2| < |v_2| = |v(t)|$, so the path stays in $S$. We r
each $(u_2, v_2)$.

Concatenating these three paths gives a continuous path in $S$ from $(u_1, v_1)$
 to $(u_2, v_2)$. Hence $S$ is path-connected.

**Conclusion.** The set $\{(x_1, \dots, x_n) \in \mathbb{R}^n : x_1^2 + \cdots +
 x_{n-2}^2 - x_{n-1}^2 - x_n^2 < 0\}$ is path-connected, so its number of connec
ted components is

$$\boxed{1}.$$
