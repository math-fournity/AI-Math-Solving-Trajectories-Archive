## Solution

We minimize the strictly convex functional $\int_0^1 (f')^2\,dx$ subject to line
ar constraints, so this is an isoperimetric problem with a unique global minimiz
er.

### Setting up the Euler–Lagrange equation

Introduce Lagrange multipliers $\mu_1, \mu_2$ for the two integral constraints.
The augmented Lagrangian is
$$L = (f')^2 + \mu_1 f + \mu_2\, x f.$$
The Euler–Lagrange equation gives
$$\frac{d}{dx}(2f') = \mu_1 + \mu_2 x \;\;\Longrightarrow\;\; f'' = a + bx,$$
where $a = \mu_1/2$, $b = \mu_2/2$. Integrating twice:
$$f'(x) = ax + \tfrac{b}{2}x^2 + c, \qquad f(x) = \tfrac{a}{2}x^2 + \tfrac{b}{6}
x^3 + cx + d.$$

### Applying the constraints

**Boundary conditions.** $f(0)=0 \Rightarrow d=0$. $f(1)=4$ gives
$$\tfrac{a}{2} + \tfrac{b}{6} + c = 4. \tag{1}$$

**Integral constraints.**
$$\int_0^1 f\,dx = \tfrac{a}{6} + \tfrac{b}{24} + \tfrac{c}{2} = 3, \tag{2}$$
$$\int_0^1 x f\,dx = \tfrac{a}{8} + \tfrac{b}{30} + \tfrac{c}{3} = 2. \tag{3}$$

From (1): $c = 4 - \tfrac{a}{2} - \tfrac{b}{6}$.

**Substituting into (2):**
$$\tfrac{a}{6} + \tfrac{b}{24} + 2 - \tfrac{a}{4} - \tfrac{b}{12} = 3 \;\Longrig
htarrow\; -\tfrac{a}{12} - \tfrac{b}{24} = 1 \;\Longrightarrow\; 2a + b = -24. \
tag{I}$$

**Substituting into (3):**
$$\tfrac{a}{8} + \tfrac{b}{30} + \tfrac{4}{3} - \tfrac{a}{6} - \tfrac{b}{18} = 2
 \;\Longrightarrow\; -\tfrac{a}{24} - \tfrac{b}{45} = \tfrac{2}{3} \;\Longrighta
rrow\; 15a + 8b = -240. \tag{II}$$

**Solving (I) and (II):** From (I), $b = -24 - 2a$. Substituting into (II):
$$15a + 8(-24-2a) = -240 \;\Longrightarrow\; -a - 192 = -240 \;\Longrightarrow\;
 a = 48,$$
$$b = -24 - 96 = -120, \qquad c = 4 - 24 + 20 = 0.$$

### The minimizer and the minimum value

$$f(x) = 24x^2 - 20x^3, \qquad f'(x) = 48x - 60x^2.$$

**Verification of constraints:**
- $f(0)=0$, $f(1)=24-20=4$. ✓
- $\int_0^1 f = 8 - 5 = 3$. ✓
- $\int_0^1 xf = 6 - 4 = 2$. ✓

**Computing the objective:**
$$(f')^2 = (48x-60x^2)^2 = 2304x^2 - 5760x^3 + 3600x^4,$$
$$\int_0^1 (f')^2\,dx = \tfrac{2304}{3} - \tfrac{5760}{4} + \tfrac{3600}{5} = 76
8 - 1440 + 720 = 48.$$

### Justification of minimality

The functional $J[f]=\int_0^1 (f')^2\,dx$ is strictly convex (quadratic in $f'$
with positive coefficient), and all four constraints are affine in $f$. The feas
ible set (an affine subspace of $H^1$) is nonempty since $f(x)=24x^2-20x^3$ lies
 in it. A strictly convex functional on a nonempty affine set has at most one cr
itical point, which (when it exists) is the unique global minimizer. We have fou
nd that critical point, so the value $48$ is the global minimum.

$$\boxed{\min \int_0^1 (f'(x))^2\,dx = 48}$$
