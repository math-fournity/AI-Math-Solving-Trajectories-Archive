# Solution

**Answer: No.** There is no (countable) increasing sequence of ordinals, each st
rictly between ω and ω₂, that is unbounded in ω₂.

## Proof

Recall that ω₂ denotes the second uncountable ordinal — the least ordinal of car
dinality ℵ₂ — and that ω₂ is a **regular cardinal**, i.e., cf(ω₂) = ω₂.

Suppose, for the sake of contradiction, that (α_n)_{n < ω} is a countable increa
sing sequence with

ω < α_n < ω₂ for every n < ω,   and   sup{α_n : n < ω} = ω₂.

Since the sequence is increasing, its supremum equals the union of the ordinals
viewed as sets:

sup{α_n : n < ω} = ⋃_{n < ω} α_n.

Each α_n is an ordinal below ω₂, so each has cardinality |α_n| ≤ ℵ₁. The supremu
m is a countable union of such sets, hence

|sup{α_n : n < ω}| ≤ ℵ₁ · ℵ₀ = ℵ₁.

Therefore sup{α_n : n < ω} is an ordinal of cardinality at most ℵ₁, which means
it is strictly less than ω₂ (the least ordinal of cardinality ℵ₂). This contradi
cts the assumption that sup{α_n : n < ω} = ω₂.

The contradiction shows that no countable increasing sequence of ordinals in the
 interval (ω, ω₂) can be cofinal (unbounded) in ω₂. ∎

**Remark.** The essential reason is the regularity of ω₂: cf(ω₂) = ω₂ > ω, so no
 sequence of length ω can be cofinal in ω₂. (If one allows sequences of arbitrar
y ordinal length, then a cofinal increasing sequence in (ω, ω₂) trivially exists
 — e.g., the natural enumeration of {α : ω < α < ω₂}, which has order type ω₂ —
but under the standard meaning of "sequence" as countably indexed, no such seque
nce exists.)
