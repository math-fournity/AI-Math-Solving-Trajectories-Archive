## Proof

The answer is **no**: $T$ need not be bounded. We give a counterexample.

Let $H = \ell^{2}(\mathbb{N})$ over $K = \mathbb{R}$ (the complex case is identi
cal), and let
$$B = \{e_{n} : n \in \mathbb{N}\}$$
be the standard orthonormal basis, where $e_{n}$ is the sequence with $1$ in pos
ition $n$ and $0$ elsewhere. Then $H = \overline{\operatorname{span}(B)}$, so $B
$ is a basis of the required kind.

**Construction of $T$.** Extend $B$ to a Hamel basis $A$ of $H$ (using Zorn's le
mma). Define $T$ on $A$ by
$$T(e_{n}) = 1 \quad\text{for every } e_{n} \in B, \qquad T(a) = 0 \quad\text{fo
r every } a \in A \setminus B,$$
and extend linearly to all of $H$. This yields a well-defined linear functional
$T : H \to K$ defined on the entire space.

**$T(B)$ is bounded.** $T(B) = \{1\}$, which is a bounded subset of $K$.

**$T$ is unbounded.** For each $N \geq 1$ set
$$x_{N} = \frac{1}{\sqrt{N}} \sum_{n=1}^{N} e_{n} \in H.$$
Then $\|x_{N}\|^{2} = \tfrac{1}{N}\cdot N = 1$, so $\|x_{N}\| = 1$, yet
$$T(x_{N}) = \frac{1}{\sqrt{N}} \sum_{n=1}^{N} T(e_{n}) = \frac{1}{\sqrt{N}}\cdo
t N = \sqrt{N} \xrightarrow[N\to\infty]{} \infty.$$
Hence $\sup_{\|x\|=1}|T(x)| = \infty$, i.e. $\|T\| = \infty$.

(Indeed, if $T$ were bounded/continuous, by Riesz representation there would exi
st $y \in \ell^{2}$ with $T(x) = \langle x, y\rangle$, forcing $y_{n} = T(e_{n})
 = 1$ for all $n$, but $(1,1,1,\dots)\notin \ell^{2}$ — a contradiction.)

Therefore a linear functional whose values on a (complete orthonormal) basis $B$
 form a bounded set need **not** be bounded.
