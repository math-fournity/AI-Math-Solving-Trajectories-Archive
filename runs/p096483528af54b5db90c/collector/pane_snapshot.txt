Looking at this problem, I need to find all pairs $(a,b)$ with $1 \le a < b \le
100$ such that $ab \mid a^k + b^k$ for some positive integer $k$.

## Setting Up the Key Reduction

Let $d = \gcd(a,b)$, and write $a = dx$, $b = dy$ with $\gcd(x,y) = 1$ and $x <
y$ (since $a < b$).

Then $ab = d^2xy$ and $a^k + b^k = d^k(x^k + y^k)$, so we need:
$$d^2xy \mid d^k(x^k + y^k) \iff \frac{d^{k-2}(x^k + y^k)}{xy} \in \mathbb{Z}$$

**Key lemma:** If $\gcd(x,y) = 1$, then $\gcd(xy, x^k + y^k) = 1$ for all $k \ge
 1$.

*Proof:* $\gcd(x, x^k + y^k) = \gcd(x, y^k) = 1$ since $\gcd(x,y)=1$. Similarly
$\gcd(y, x^k+y^k) = 1$. Since $\gcd(x,y)=1$, we conclude $\gcd(xy, x^k+y^k) = 1$
. $\square$

**Case $k = 1$:** Need $dxy \mid (x+y)$. Since $\gcd(xy, x+y) = 1$, this forces
$xy \mid 1$, so $x = y = 1$, contradicting $x < y$. No solutions.

**Case $k = 2$:** Need $xy \mid d^0(x^2+y^2) = x^2+y^2$. Since $\gcd(xy, x^2+y^2
) = 1$, need $xy \mid 1$, impossible.

**Case $k \ge 3$:** Need $xy \mid d^{k-2}(x^k + y^k)$. By the lemma, $\gcd(xy, x
^k+y^k) = 1$, so we need $xy \mid d^{k-2}$.

The existence of $k \ge 3$ with $xy \mid d^{k-2}$ is equivalent to: **every prim
e dividing $xy$ also divides $d$**, i.e., $\operatorname{rad}(xy) \mid d$.

*Necessity:* If $p \mid xy$ and $p \mid d^{k-2}$, then $p \mid d$.
*Sufficiency:* If $\operatorname{rad}(xy) \mid d$, then for $k$ large enough, $d
^{k-2}$ contains all prime powers of $xy$.

## Counting Good Pairs

The good pairs are exactly $(a,b) = (dx, dy)$ where:
- $\gcd(x,y) = 1$, $1 \le x < y$
- $\operatorname{rad}(xy) \mid d$
