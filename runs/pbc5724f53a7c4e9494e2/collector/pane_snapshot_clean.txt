**Claim.** $S$ is a closed unbounded (club) subset of $\omega_1$. Consequently $
\operatorname{otp}(S) = \omega_1$ for every such $f$, and the minimum possible o

### $S$ is unbounded in $\omega_1$.

$$\alpha_{n+1} = \sup\bigl(f[\alpha_n] \cup \{\alpha_n\}\bigr) + 1,$$
and set $\beta = \sup_{n < \omega} \alpha_n$. Since each $\alpha_n < \omega_1$ a

ha_{n+1} \le \beta$. Hence $f[\beta] \subseteq \beta$, i.e., $\beta \in S$. Sinc

### $S$ is closed.

Let $(\beta_i)_{i < \lambda}$ be an increasing sequence of elements of $S$ with
limit $\beta = \sup_i \beta_i < \omega_1$. For any $\xi < \beta$, pick $i$ with
$\xi < \beta_i$. Since $\beta_i \in S$, we have $f(\xi) < \beta_i < \beta$. Thus
 $f[\beta] \subseteq \beta$, so $\beta \in S$. Hence $S$ is closed.
