Looking at this problem, I need to find the minimum $k$ such that 100 paintings,
 each using exactly $k$ colors, satisfy: (1) any 20 paintings share a common col
or, but (2) no color appears in all 100 paintings.

## Lower Bound: $k \geq 20$

Fix any painting $P$ with color set $C$, $|C| = k$.

**Every other painting shares at least one color with $P$.** If some painting $Q
$ shares no color with $P$, then any 20 paintings containing both $P$ and $Q$ ha
ve no common color (a common color must lie in $C \cap (\text{colors of } Q) = \
emptyset$), contradicting condition (1).

**For each color $c \in C$, the set $T_c = \{$other paintings not using $c\}$ is
 non-empty.** Since $c \in P$, if $c$ were in all other 99 paintings, then $c$ w
ould be in all 100, contradicting condition (2).

**No 19 of the other 99 paintings form a transversal of $\{T_c : c \in C\}$.** S
uppose paintings $Q_1, \dots, Q_{19}$ intersect every $T_c$. Then for each $c \i
n C$, some $Q_i$ does not use $c$, so no color in $C$ is common to all of $Q_1,
\dots, Q_{19}$. The 20 paintings $\{P, Q_1, \dots, Q_{19}\}$ would then have no
common color (any common color must be in $C$), contradicting condition (1).

Therefore the transversal number $\tau(\{T_c : c \in C\}) \geq 20$. Since there
are $k$ sets and $\tau \leq k$ (select one element from each set), we conclude:

$$k \geq 20.$$

## Upper Bound: Construction with $k = 20$

Use 21 colors: $a_1, a_2, \dots, a_{20}$ and $d$.

- **80 paintings** $P_1, \dots, P_{80}$: each uses $\{a_1, a_2, \dots, a_{20}\}$
 (all 20 $a$-colors).
- **20 paintings** $Q_1, \dots, Q_{20}$: $Q_j$ uses $\{a_1, \dots, a_{20}\} \set
minus \{a_j\} \cup \{d\}$ (all $a$-colors except $a_j$, plus $d$).

Each painting uses exactly 20 colors. ✓

**Condition (1) — any 20 paintings share a color:**

- *If the 20 paintings include at least one $P_i$:* This $P_i$ uses all of $a_1,
 \dots, a_{20}$. Each $Q_j$ misses only $a_j$. Among the 20 paintings, at most 1
9 are $Q_j$'s, each missing a distinct $a$-color. So at most 19 of the 20 $a$-co
lors are missed, leaving at least one $a$-color common to all 20. ✓

- *If all 20 paintings are $Q_j$'s:* There are exactly 20 $Q_j$'s, so this is al
l of them. Every $Q_j$ uses $d$, so $d$ is common to all 20. ✓

**Condition (2) — no color in all 100 paintings:**

- $a_j$ is missed by $Q_j$ (for each $j = 1, \dots, 20$). ✓
- $d$ is used only by $Q_1, \dots, Q_{20}$, not by any $P_i$. ✓

## Conclusion

The lower bound $k \geq 20$ is forced by the transversal argument, and the const
ruction above achieves $k = 20$. Therefore, the minimum possible value is:

$$\boxed{k = 20}$$
