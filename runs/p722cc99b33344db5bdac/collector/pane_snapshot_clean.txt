## Proof

**Step 1: The excluded set has measure zero.**

Define the two excluded sets:
- $E_1 = \{(x,y) \in [0,1]^2 : x + y \in \mathbb{Q}\}$
- $E_2 = \{(x,y) \in [0,1]^2 : xy \in \mathbb{Q}\}$

For $E_1$: For each $q \in \mathbb{Q}$, the set $\{(x,y) \in [0,1]^2 : x + y = q
\}$ is a line segment (a 1-dimensional affine set), hence has 2-dimensional Lebe
sgue measure zero. Since $\mathbb{Q}$ is countable, $E_1 = \bigcup_{q \in \mathb
b{Q}} \{(x,y) : x+y=q\}$ is a countable union of measure-zero sets, so $m^2(E_1)
 = 0$.

For $E_2$: For each $q \in \mathbb{Q}$, the set $\{(x,y) \in [0,1]^2 : xy = q\}$
 is either a hyperbola arc (when $q > 0$), a union of two line segments along th
e axes (when $q = 0$, i.e., $x=0$ or $y=0$), or empty (when $q < 0$). In all cas
es it is a 1-dimensional (or lower) set, hence has 2-dimensional Lebesgue measur
e zero. Since $\mathbb{Q}$ is countable, $E_2 = \bigcup_{q \in \mathbb{Q}} \{(x,
y) : xy = q\}$ is a countable union of measure-zero sets, so $m^2(E_2) = 0$.

Therefore $m^2(E_1 \cup E_2) = 0$, and $A = [0,1]^2 \setminus (E_1 \cup E_2)$ di
ffers from $[0,1]^2$ by a set of measure zero.

**Step 2: Reduce the integral to $[0,1]^2$.**

The integrand $f(x,y) = y^{-1/2} \sin x$ is measurable and non-negative on $[0,1
]^2$ (since $\sin x \geq 0$ for $x \in [0,1] \subset [0,\pi]$, and $y^{-1/2} > 0
$ for $y \in (0,1]$). Since $A$ and $[0,1]^2$ differ only on a null set:

$$\int_A y^{-1/2} \sin x \, dm^2 = \int_{[0,1]^2} y^{-1/2} \sin x \, dm^2.$$

**Step 3: Apply Tonelli's theorem and compute.**

Since $f \geq 0$ is measurable, Tonelli's theorem gives:

$$\int_{[0,1]^2} y^{-1/2} \sin x \, dm^2 = \int_0^1 \int_0^1 y^{-1/2} \sin x \,
dx\, dy = \left(\int_0^1 \sin x \, dx\right)\left(\int_0^1 y^{-1/2}\, dy\right).
$$

The factor $\int_0^1 y^{-1/2}\, dy$ is finite since $-1/2 > -1$ (the singularity
 at $y=0$ is integrable):

$$\int_0^1 y^{-1/2}\, dy = \left[2y^{1/2}\right]_0^1 = 2.$$

And:

$$\int_0^1 \sin x\, dx = \left[-\cos x\right]_0^1 = 1 - \cos 1.$$

**Step 4: Conclusion.**

$$\int_A y^{-1/2} \sin x \, dm^2 = 2\,(1 - \cos 1).$$
