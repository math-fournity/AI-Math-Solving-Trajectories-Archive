## Proof

**Claim.** Yes. For every compact metric space $X$ and every continuous $f:X\to
X$, there exists a non-empty subset $A\subseteq X$ with $f(A)=A$.

**Construction.** Define the descending sequence of iterated images
$$X \supseteq f(X) \supseteq f^{2}(X) \supseteq \cdots \supseteq f^{n}(X) \supse
teq \cdots$$
and set
$$A \;=\; \bigcap_{n=0}^{\infty} f^{n}(X).$$

We verify three things: (i) each $f^{n}(X)$ is non-empty and compact; (ii) $A$ i
s non-empty; (iii) $f(A)=A$.

**(i) Each $f^{n}(X)$ is non-empty and compact.** $X$ is non-empty (a compact me
tric space is non-empty; if $X=\varnothing$ the claim is vacuous, so assume $X\n
eq\varnothing$). The continuous image of a compact set is compact, so by inducti
on each $f^{n}(X)$ is compact (hence closed in $X$, since $X$ is Hausdorff) and
non-empty, being the image of the non-empty set $f^{n-1}(X)$.

**(ii) $A$ is non-empty.** The family $\{f^{n}(X)\}_{n\ge 0}$ is a decreasing se
quence of non-empty closed subsets of the compact space $X$. By the finite inter
section property of compact spaces, any finite sub-intersection is non-empty (it
 equals the smallest-indexed set), so the total intersection $A$ is non-empty. B
eing an intersection of closed sets, $A$ is closed, hence compact.

**(iii) $f(A)=A$.**

*Inclusion $f(A)\subseteq A$.* Let $y\in A$. Then $y\in f^{n}(X)$ for every $n\g
e 0$. By continuity, $f(y)\in f\bigl(f^{n}(X)\bigr)=f^{n+1}(X)$ for every $n\ge
0$, so $f(y)\in\bigcap_{n\ge 0}f^{n+1}(X)=A$. Thus $f(A)\subseteq A$.

*Inclusion $A\subseteq f(A)$.* Let $x\in A$, so $x\in f^{n}(X)$ for every $n\ge
0$. In particular $x\in f^{n+1}(X)=f\bigl(f^{n}(X)\bigr)$ for every $n\ge 0$, so
 for each $n$ there exists $y_{n}\in f^{n}(X)$ with $f(y_{n})=x$.

The sequence $(y_{n})$ lies in the compact set $X$, so it has a convergent subse
quence $y_{n_{k}}\to y$ for some $y\in X$. Fix any $m\ge 0$. For all $n_{k}\ge m
$ we have $y_{n_{k}}\in f^{n_{k}}(X)\subseteq f^{m}(X)$, and $f^{m}(X)$ is close
d, so the limit $y\in f^{m}(X)$. Since $m$ was arbitrary, $y\in\bigcap_{m\ge 0}f
^{m}(X)=A$. Finally, by continuity,
$$f(y)=f\!\left(\lim_{k\to\infty}y_{n_{k}}\right)=\lim_{k\to\infty}f(y_{n_{k}})=
\lim_{k\to\infty}x=x.$$
Hence $x=f(y)\in f(A)$. This proves $A\subseteq f(A)$.

Combining both inclusions gives $f(A)=A$, with $A$ non-empty. $\blacksquare$
