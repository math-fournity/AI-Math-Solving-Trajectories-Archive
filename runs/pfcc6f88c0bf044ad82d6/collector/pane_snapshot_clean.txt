## Proof

**Key observation.** Define $u(x) = \dfrac{\sin x}{x}$ for $x > 0$, extended by
continuity at $x = 0$ with $u(0) = 1$. Compute:

$$u'(x) = \frac{x\cos x - \sin x}{x^2}.$$

Now observe that the integrand can be rewritten. Since

$$\sin x - x\cos x = -x^2\, u'(x), \qquad x^2 + \sin^2 x = x^2\bigl(1 + u(x)^2\b
igr),$$

we get

$$\frac{\sin x - x\cos x}{x^2 + \sin^2 x} = \frac{-x^2\, u'(x)}{x^2\bigl(1+u(x)^
2\bigr)} = \frac{-u'(x)}{1+u(x)^2}.$$

Recognizing the derivative of arctangent:

$$\frac{-u'(x)}{1+u(x)^2} = -\frac{d}{dx}\arctan\!\bigl(u(x)\bigr) = -\frac{d}{d
x}\arctan\!\left(\frac{\sin x}{x}\right).$$

**Verification of the derivative:**

$$\frac{d}{dx}\arctan\!\left(\frac{\sin x}{x}\right) = \frac{1}{1+\left(\frac{\s
in x}{x}\right)^2}\cdot\frac{x\cos x - \sin x}{x^2} = \frac{x\cos x - \sin x}{x^
2 + \sin^2 x}. \quad\checkmark$$

**Applying the Fundamental Theorem of Calculus.** The integrand is an exact deri
vative on $(0,\infty)$, and the antiderivative $F(x) = -\arctan\!\left(\frac{\si
n x}{x}\right)$ is bounded and has well-defined limits at both endpoints:

- **At $x \to 0^+$:** $\dfrac{\sin x}{x} \to 1$, so $F(x) \to -\arctan(1) = -\df
rac{\pi}{4}$.
- **At $x \to \infty$:** $\left|\dfrac{\sin x}{x}\right| \leq \dfrac{1}{x} \to 0
$, so $F(x) \to -\arctan(0) = 0$.

Therefore:

$$I = \lim_{R\to\infty}\Bigl[F(R) - F(0)\Bigr] = \lim_{R\to\infty}\left[-\arctan
\!\left(\frac{\sin R}{R}\right) + \arctan(1)\right] = 0 + \frac{\pi}{4} = \frac{
\pi}{4}.$$

**Convergence note.** The integral converges (conditionally for large $x$, since
 the integrand is $O(\cos x / x)$ and $\int_1^\infty \frac{\cos x}{x}\,dx$ conve
rges by Dirichlet's test; and the integrand is $O(x)$ near $x=0$, so no singular
ity there). The FTC application is justified because $F$ is continuous on $[0,\i
nfty)$, bounded, and has limits at both endpoints.

$$\boxed{I = \dfrac{\pi}{4}}$$
