Since each row has only 2 cells (which are adjacent to each other), each row can

- **State 0**: no black canister (0 blacks)
- **State 1**: black in column 1 (1 black)
- **State 2**: black in column 2 (1 black)

## Transition Structure

Between consecutive rows, vertical adjacency forbids the same column being occup

- State 0 → compatible with states {0, 1, 2}
- State 1 → compatible with states {0, 2} (column 1 blocked)
- State 2 → compatible with states {0, 1} (column 2 blocked)

By the left-right symmetry of the grid, states 1 and 2 are interchangeable, so I
 define $D_r(k) = B_r(k) = C_r(k)$ (counts for state 1 and state 2 are equal).

## Dynamic Programming Recurrence

Let $A_r(k)$ = number of ways to fill rows $1,\ldots,r$ with row $r$ in state 0
using exactly $k$ blacks. Let $D_r(k)$ = same but row $r$ in state 1 (or equival

**Base case** ($r=1$): $A_1(0)=1$, $D_1(1)=1$, all others 0.

**Recurrence:**
$$A_r(k) = A_{r-1}(k) + 2\,D_{r-1}(k)$$
$$D_r(k) = A_{r-1}(k-1) + D_{r-1}(k-1)$$

The first equation: state 0 (0 blacks added) is compatible with all three previo

s 0 and 2, and by symmetry $D$ absorbs both.
