## Proof

**Claim.** Yes. For every poset $\mathbb{P}$ and every $\mathbb{P}$-name $\dot{Q
}$, there exists a ground-model cardinal $\mu$ such that $\Vdash_{\mathbb{P}} |\
dot{Q}| \leq |\check{\mu}|$.

**Proof.**

Let $\dot{Q}$ be a $\mathbb{P}$-name. Recall that a $\mathbb{P}$-name is a set o
f ordered pairs $(\sigma, p)$ where $\sigma$ is a $\mathbb{P}$-name and $p \in \
mathbb{P}$. Define the **domain** of the name:

$$\operatorname{dom}(\dot{Q}) \;=\; \{\sigma : \exists\, p \in \mathbb{P},\; (\s
igma, p) \in \dot{Q}\}.$$

Since $\dot{Q}$ is a set in the ground model $V$, so is $\operatorname{dom}(\dot
{Q})$. Let

$$\mu \;=\; |\operatorname{dom}(\dot{Q})|^{V}$$

be the cardinality of $\operatorname{dom}(\dot{Q})$ as computed in $V$. This is
a cardinal of the ground model.

Now let $G$ be any $\mathbb{P}$-generic filter over $V$. By the recursive defini
tion of name interpretation,

$$\dot{Q}^{G} \;=\; \{\sigma^{G} : \exists\, p \in G,\; (\sigma, p) \in \dot{Q}\
}.$$

Every $\sigma$ appearing here belongs to $\operatorname{dom}(\dot{Q})$, so

$$\dot{Q}^{G} \;\subseteq\; \{\sigma^{G} : \sigma \in \operatorname{dom}(\dot{Q}
)\}.$$

The map $\sigma \mapsto \sigma^{G}$ (defined in $V[G]$) sends $\operatorname{dom
}(\dot{Q})$ onto the set on the right-hand side. Therefore

$$|\dot{Q}^{G}| \;\leq\; |\operatorname{dom}(\dot{Q})|^{V[G]}.$$

Now, in $V$ there exists an injection $f : \operatorname{dom}(\dot{Q}) \hookrigh
tarrow \mu$ (since $\mu = |\operatorname{dom}(\dot{Q})|^V$). The function $f$ is
 a set in $V$ and hence still exists in $V[G]$, where it remains an injection fr
om $\operatorname{dom}(\dot{Q})$ into $\mu$. Thus

$$|\operatorname{dom}(\dot{Q})|^{V[G]} \;\leq\; \mu.$$

Combining the two inequalities,

$$|\dot{Q}^{G}| \;\leq\; \mu \;=\; |\check{\mu}|^{V[G]}$$

holds in $V[G]$.

Since $G$ was an arbitrary $\mathbb{P}$-generic filter, we conclude

$$\Vdash_{\mathbb{P}} |\dot{Q}| \leq |\check{\mu}|.$$

The cardinal $\mu = |\operatorname{dom}(\dot{Q})|^V$ is defined entirely in the
ground model, completing the proof. $\blacksquare$
