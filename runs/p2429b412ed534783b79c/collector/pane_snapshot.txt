## Solution

The integral $\int_C \phi(t)\,dW(\phi)$ is the integral of the evaluation functi
onal $e_t : C \to \mathbb{R}$, defined by $e_t(\phi) = \phi(t)$, with respect to
 Wiener measure $W$ on the path space $C = C([0,T],\mathbb{R})$.

**Definition of Wiener measure.** Wiener measure $W$ is the probability measure
on $C$ under which the coordinate process $B_t(\phi) := \phi(t)$ is a standard B
rownian motion (Wiener process) starting at $0$. In particular, for every $t \in
 [0,T]$, the random variable $\phi(t)$ has distribution $N(0, t)$, i.e., mean $0
$ and variance $t$.

**Rewriting the integral as an expectation.** Since $W$ is a probability measure
 on $C$, integrating any measurable functional $F : C \to \mathbb{R}$ against $W
$ is precisely taking the expectation:

$$\int_C F(\phi)\,dW(\phi) = \mathbb{E}_W[F].$$

Setting $F(\phi) = \phi(t) = e_t(\phi)$, we obtain

$$\int_C \phi(t)\,dW(\phi) = \mathbb{E}_W[\phi(t)].$$

**Computing the expectation.** Under Wiener measure, $\phi(t) \sim N(0, t)$, so

$$\mathbb{E}_W[\phi(t)] = 0.$$

**Verification via finite-dimensional distributions.** More explicitly, Wiener m
easure is constructed so that for any partition $0 = t_0 < t_1 < \cdots < t_n =
t$, the increments $\phi(t_i) - \phi(t_{i-1})$ are independent with $\phi(t_i) -
 \phi(t_{i-1}) \sim N(0, t_i - t_{i-1})$. Telescoping,

$$\phi(t) = \sum_{i=1}^{n} \bigl(\phi(t_i) - \phi(t_{i-1})\bigr),$$

so by linearity of expectation and the fact that each increment has mean $0$,

$$\mathbb{E}_W[\phi(t)] = \sum_{i=1}^{n} \mathbb{E}\bigl[\phi(t_i) - \phi(t_{i-1
})\bigr] = \sum_{i=1}^{n} 0 = 0.$$

This holds for every partition, confirming $\mathbb{E}_W[\phi(t)] = 0$.

**Conclusion.**

$$\boxed{\int_C \phi(t)\,dW(\phi) = 0.}$$
