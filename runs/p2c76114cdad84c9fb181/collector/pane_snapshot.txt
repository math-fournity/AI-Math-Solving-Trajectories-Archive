## 解题过程

**答案：不成立。** 下面构造一个显式反例。

### 思路

条件 $\int_0^\infty g(ax)f(x)\,dx = a$ 对所有 $a>0$ 成立。若 $g(x)=x$，则 $\int
ax\,f(x)\,dx = a\cdot 1 = a$，自然满足。关键在于：是否存在 $g \neq x$ 也满足。

设 $g(x) = x + \phi(x)$，则需 $\int_0^\infty \phi(ax)\,f(x)\,dx = 0$ 对所有 $a>0
$。在 log-空间中，这转化为 $\phi$ 与 $f$ 的一个卷积为零，其 Fourier 变换条件为：
$\mu := xf(x)$ 所诱导分布的**特征函数在某非零点为零**。若该特征函数有零点，则可
构造非平凡的 $\phi$。

### 构造

**第 1 步：构造 $f$。**

令 $Y$ 为 $N(m_1,1)$ 与 $N(m_2,1)$ 的等权混合，其中
$$m_1 = a + \tfrac{\pi}{2},\quad m_2 = a - \tfrac{\pi}{2},\quad a = \tfrac{1}{2}
 + \ln\cosh\tfrac{\pi}{2}.$$
$Y$ 的密度 $p(y) = \frac{1}{2}\bigl[\frac{1}{\sqrt{2\pi}}e^{-(y-m_1)^2/2} + \fra
c{1}{\sqrt{2\pi}}e^{-(y-m_2)^2/2}\bigr]$ 在 $\mathbb{R}$ 上严格为正。

令 $X = e^Y$，密度记为 $\mu(x)$。定义 $f(x) = \mu(x)/x$，$x > 0$。因 $\mu$ 为对
数正态混合密度，$\mu(x)>0$ 对所有 $x>0$，故 $f$ 严格正。

**第 2 步：验证 $f$ 的条件。**

- $\int_0^\infty x\,f(x)\,dx = \int_0^\infty \mu(x)\,dx = 1$。 ✓

- $\int_0^\infty f(x)\,dx = \int_0^\infty \frac{\mu(x)}{x}\,dx = \mathbb{E}[e^{-
Y}]$。计算：
$$\mathbb{E}[e^{-Y}] = \frac{1}{2}\bigl(e^{-m_1+1/2}+e^{-m_2+1/2}\bigr) = e^{1/2
}\,e^{-a}\,\cosh\tfrac{\pi}{2} = e^{1/2}\,e^{-1/2-\ln\cosh(\pi/2)}\,\cosh\tfrac{
\pi}{2} = 1. \checkmark$$

**第 3 步：$Y$ 的特征函数在 $\xi=1$ 处为零。**

$$\varphi_Y(\xi) = e^{-\xi^2/2}\cdot\tfrac{1}{2}\bigl(e^{im_1\xi}+e^{im_2\xi}\bi
gr) = e^{-\xi^2/2}\,e^{ia\xi}\,\cos\tfrac{\pi\xi}{2}.$$

在 $\xi=1$：$\varphi_Y(1) = e^{-1/2}\,e^{ia}\,\cos\frac{\pi}{2} = 0$。 ✓

**第 4 步：定义 $g$ 并验证。**

令 $g(x) = x\bigl(1 + \tfrac{1}{2}\cos(\ln x)\bigr)$，$x>0$。

- **非负**：$g(x) \ge x(1-\tfrac12) = \tfrac{x}{2} > 0$。 ✓
- **非常数**：$g(e^{2\pi}) = e^{2\pi}\cdot\tfrac32 \ne e^{2\pi}$。 ✓
- **$g \ne x$**。 ✓

验证积分条件：
$$\int_0^\infty g(ax)\,f(x)\,dx = a\int_0^\infty x\,f(x)\,dx + \frac{a}{2}\int_0
^\infty x\,\cos(\ln a + \ln x)\,f(x)\,dx$$
$$= a + \frac{a}{2}\,\mathrm{Re}\!\left[e^{i\ln a}\int_0^\infty x^{1+i}\,f(x)\,d
x\right].$$

关键积分：
$$\int_0^\infty x^{1+i}\,f(x)\,dx = \int_0^\infty x^{i}\,\mu(x)\,dx = \mathbb{E}
[X^{i}] = \mathbb{E}[e^{iY}] = \varphi_Y(1) = 0.$$

因此
$$\int_0^\infty g(ax)\,f(x)\,dx = a \quad \text{对所有 } a>0. \checkmark$$

### 结论

我们构造了严格正的 $f$（满足 $\int f = \int xf = 1$）以及非负、非常数、$g \ne x$
 的函数 $g$，使得 $\int_0^\infty g(ax)\,f(x)\,dx = a$ 对所有 $a>0$ 成立。因此，
题设条件**不**蕴含 $g(x)=x$ 几乎处处成立。

**核心机制**：当 $\mu(x)=xf(x)$ 诱导的 $\ln X$ 分布的特征函数存在非零零点时，可
利用该零点对应的振荡模式 $x^{i\xi_0} = \cos(\xi_0\ln x)+i\sin(\xi_0\ln x)$ 构造
出与 $f$ "正交"（在 Mellin 卷积意义下）的非平凡扰动，叠加到 $g(x)=x$ 上仍满足积
分方程，且通过乘以 $x$ 保证非负性。
