## Solution

A Brownian bridge $X_t$ on $[0,1]$ from $0$ to $0$ has the following conditional
 distribution property: given $X_s = x$ for $s < t < 1$, the random variable $X_
t$ is Gaussian with

$$E[X_t \mid X_s = x] = \frac{1-t}{1-s}\,x, \qquad \operatorname{Var}(X_t \mid X
_s = x) = \frac{(t-s)(1-t)}{1-s}.$$

**Applying with $s = 3/5$, $t = 4/5$:**

- Mean: $\dfrac{1-4/5}{1-3/5}\,x = \dfrac{1/5}{2/5}\,x = \dfrac{1}{2}\,x$.
- Variance: $\dfrac{(4/5-3/5)(1-4/5)}{1-3/5} = \dfrac{(1/5)(1/5)}{2/5} = \dfrac{
1/25}{2/5} = \dfrac{1}{10}$.

Hence

$$X_{4/5} \mid X_{3/5} = x \;\sim\; \mathcal{N}\!\left(\tfrac{1}{2}x,\; \tfrac{1
}{10}\right).$$

**Forming the linear combination:**

$$X_{4/5} - \tfrac{1}{2}X_{3/5} \;\Big|\; X_{3/5} = x \;\sim\; \mathcal{N}\!\lef
t(\tfrac{1}{2}x - \tfrac{1}{2}x,\; \tfrac{1}{10}\right) = \mathcal{N}\!\left(0,\
; \tfrac{1}{10}\right).$$

The conditional distribution is centered at $0$ with variance $1/10$, and—crucia
lly—it is **independent of the value of $X_{3/5}$** (the mean of $X_{4/5}$ given
 $X_{3/5}$ is exactly $\tfrac{1}{2}X_{3/5}$, which cancels the $-\tfrac{1}{2}X_{
3/5}$ term).

**Computing the characteristic function:**

For $Z \sim \mathcal{N}(0, \sigma^2)$, the characteristic function is $E[e^{iuZ}
] = e^{-u^2\sigma^2/2}$. With $\sigma^2 = 1/10$:

$$E\!\left[e^{iu\left(X_{4/5}-\frac{1}{2}X_{3/5}\right)} \;\Big|\; X_{3/5}\right
] = e^{-u^2 \cdot (1/10)/2} = e^{-u^2/20}.$$

Since the conditional distribution does not depend on $X_{3/5}$, this is also th
e unconditional expectation.

$$\boxed{E\!\left[e^{iu\left(X_{4/5}-\frac{1}{2}X_{3/5}\right)} \;\Big|\; X_{3/5
}\right] = e^{-u^2/20}}$$
