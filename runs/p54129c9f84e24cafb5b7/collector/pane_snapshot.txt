### Preliminary: Square criterion for permutations

A permutation $\sigma$ is a square (i.e., $\sigma = \tau^2$ for some permutation
 $\tau$) if and only if **for every even positive integer $L$, the number of cyc
les of length $L$ in $\sigma$ is even.**

*Proof of criterion:* If $\tau$ has a cycle of odd length $\ell$, then $\tau^2$
restricted to it is still a single $\ell$-cycle (since $\gcd(2,\ell)=1$). If $\t
au$ has a cycle of even length $2L$, then $\tau^2$ splits it into **two** cycles
 of length $L$. Hence in any square, even-length cycles arise in pairs. Converse
ly, given $\sigma$ with even-length cycles paired, one constructs $\tau$ by: tak
ing the unique square-root of each odd cycle (possible since $2$ is invertible m
od odd lengths), and interleaving each pair of equal-length even cycles into a s
ingle cycle of double length. $\square$

### Cycle structure of $\sigma_m: k \mapsto mk \pmod n$

The set $\{1,\dots,n\}$ is a complete residue system mod $n$ (with $n \equiv 0$)
. For a unit $m$, the map $\sigma_m$ preserves $\gcd(k,n)$: if $\gcd(k,n)=d$, wr
iting $k = du$ with $u$ a unit mod $n/d$, we get $\sigma_m(k) = d(mu)$, and $mu$
 is again a unit mod $n/d$. Setting $q = n/d$, the layer $S_d = \{k : \gcd(k,n)=
d\}$ has $\varphi(q)$ elements, and the action is $u \mapsto mu$ on $(\mathbb{Z}
/q\mathbb{Z})^*$. This permutation has order $\operatorname{ord}_q(m)$, giving $
\varphi(q)/\operatorname{ord}_q(m)$ cycles each of length $\operatorname{ord}_q(
m)$.

So $\sigma_m$ is a square iff for every even $L$:
$$c_L(m) := \sum_{\substack{q \mid n \\ \operatorname{ord}_q(m) = L}} \frac{\var
phi(q)}{L} \quad \text{is even.}$$

### Necessity

**Case $n \equiv 0 \pmod{4}$:** Take $m = -1$. Then $\sigma_{-1}(k) = -k$. Fixed
 points satisfy $2k \equiv 0 \pmod n$, giving $k=0$ and $k=n/2$ — exactly $2$ fi
xed points. The remaining $n-2$ elements form $(n-2)/2$ transpositions. When $n
\equiv 0 \pmod 4$, $(n-2)/2$ is **odd**, so $\sigma_{-1}$ is not a square. ✗

**Case $n > 1$ odd:** Then $n \equiv 1 \pmod 4$ is necessary (from $m=-1$: $(n-1
)/2$ transpositions must be even). Let $p^e \| n$ with $p$ an odd prime. Since $
(\mathbb{Z}/p^e\mathbb{Z})^*$ is cyclic, choose a primitive root $g$ mod $p^e$,
and by CRT pick a unit $m$ with $m \equiv g \pmod{p^e}$ and $m \equiv 1 \pmod{n/
p^e}$.

Set $L = p - 1$ (even, since $p$ is odd). I count cycles of length $L$:
- **$q = p$:** $\operatorname{ord}_p(m) = p-1 = L$; contributes $\varphi(p)/(p-1
) = 1$ cycle.
- **$q = p^j$, $j \geq 2$:** $\operatorname{ord}_{p^j}(m) = \varphi(p^j) = p^{j-
1}(p-1) \neq L$.
- **$q = d$ with $d \mid n/p^e$:** $\operatorname{ord}_d(m) = 1 \neq L$.
- **$q = p \cdot d$ with $d \mid n/p^e$:** $\operatorname{ord}_{pd}(m) = \operat
orname{lcm}(p-1, 1) = L$; contributes $\varphi(pd)/(p-1) = \varphi(d)$ cycles.

Therefore:
$$c_L(m) = 1 + \sum_{\substack{d \mid n/p^e \\ d \geq 1}} \varphi(d) - \varphi(1
) = 1 + \frac{n}{p^e} - 1 = \frac{n}{p^e}.$$
Since $n$ is odd, $n/p^e$ is **odd**. So $c_L(m)$ is odd for even $L$ — $\sigma_
m$ is not a square. ✗

### Sufficiency: $n = 2s$ with $s$ odd (i.e., $n \equiv 2 \pmod 4$)

Every divisor of $n = 2s$ is either $d$ or $2d$ where $d \mid s$. For any unit $
m$ (so $m$ is odd), since $d$ is odd:
$$\varphi(2d) = \varphi(2)\varphi(d) = \varphi(d), \qquad \operatorname{ord}_{2d

hbb{Z}/d\mathbb{Z})^* \cong (\mathbb{Z}/d\mathbb{Z})^*$.

Hence the layers $q = d$ and $q = 2d$ produce **identical** cycle structures — s
ame lengths, same counts. Every cycle count $c_L(m)$ is therefore **doubled**, h

e for every unit $m$. ✓

**$n = 1$:** The set $\{1\}$, the only permutation is $\pi(1)=1$, and $\pi(\pi(1
