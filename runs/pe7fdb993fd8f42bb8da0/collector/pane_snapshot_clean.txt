Looking at this problem, I need to determine whether every continuous $f$ with $
f \circ g = f$ must be constant, given the conditions on $g$.

**Answer: No, $f$ is not necessarily constant.**

## Counterexample

Let $g(x) = x^2 + 1$.

**Verification of hypotheses:**
- $g$ is continuous. ✓
- $g(x) - x = x^2 - x + 1 = (x-\tfrac{1}{2})^2 + \tfrac{3}{4} \to \infty$ as $x
\to \infty$. ✓
- Fixed points satisfy $x^2 + 1 = x$, i.e., $x^2 - x + 1 = 0$, which has discrim
inant $-3 < 0$. So $g$ has **zero** fixed points — finitely many. ✓

**Construction of a non-constant $f$:**

Define the sequence $a_0 = 0,\ a_1 = 1,\ a_{n+1} = a_n^2 + 1$. Then $a_0, a_1, a
_2, \ldots = 0, 1, 2, 5, 26, 677, \ldots$ with $a_n \to \infty$, and the interva
ls $[a_n, a_{n+1}]$ cover $[0, \infty)$.

Choose any non-constant continuous $f_0: [0,1] \to \mathbb{R}$ with $f_0(0) = f_
0(1)$, for instance $f_0(x) = \sin(2\pi x)$.

Define $f: \mathbb{R} \to \mathbb{R}$ by:
- **For $x \in [0, 1]$:** $f(x) = f_0(x)$.
- **For $x \in [a_n, a_{n+1}]$ with $n \geq 1$:** $f(x) = f\!\left(\sqrt{x - 1}\
right)$. (This is well-founded because $x \in [a_n, a_{n+1}]$ implies $x - 1 \in
 [a_{n-1}^2, a_n^2]$, so $\sqrt{x-1} \in [a_{n-1}, a_n]$, where $f$ is already d
efined.)
- **For $x < 0$:** $f(x) = f(-x)$.

**$f$ is well-defined and continuous:**

On each open interval $(a_n, a_{n+1})$, $f$ is a composition of continuous funct
ions, hence continuous. At each boundary point $x = a_n$ ($n \geq 1$): since $a_
n = a_{n-1}^2 + 1$, we have $\sqrt{a_n - 1} = a_{n-1}$, so from both sides $f(x)
 \to f(a_{n-1}) = f(a_n)$. At $x = 0$: from the right $f \to f_0(0)$, from the l
eft $f(x) = f(-x) \to f_0(0)$. At $x = 1$: from the left $f \to f_0(1)$, from th
e right $f(x) = f(\sqrt{x-1}) \to f(0) = f_0(0) = f_0(1)$ (using $f_0(0)=f_0(1)$
). So $f$ is continuous on all of $\mathbb{R}$.

**$f$ is non-constant:** $f_0(x) = \sin(2\pi x)$ is non-constant on $[0,1]$, e.g
., $f(0) = 0$ while $f(1/4) = 1$.

**Verification that $f \circ g = f$:**

*Case $x \geq 0$:* $g(x) = x^2 + 1 \geq 1$, so $f(g(x)) = f(x^2+1) = f\!\left(\s
qrt{(x^2+1)-1}\right) = f(|x|) = f(x)$.

*Case $x < 0$:* $g(x) = x^2 + 1 \geq 1$, so $f(g(x)) = f(x^2+1) = f\!\left(\sqrt
{x^2}\right) = f(|x|) = f(x)$, where the last equality uses the definition $f(y)
 = f(|y|)$ for $y < 0$.

Thus $f \circ g = f$ everywhere, $f$ is continuous and non-constant, while $g$ s
atisfies all the stated hypotheses.

## Key Insight

When $g$ has **no** fixed points and $g(x) > x$ for all $x$, every forward orbit
 escapes to $+\infty$. The equation $f \circ g = f$ only forces $f$ to be consta
nt along each orbit, but different orbits can carry different values. The map $\
phi(x) = \sqrt{x-1}$ provides a continuous "backward iteration" from $[1,\infty)
$ to $[0,\infty)$ that lands in $[0,1)$ after finitely many steps, so $f$ is fre
ely determined by its (arbitrary) values on $[0,1]$, subject only to the gluing
condition $f(0) = f(1)$. This leaves room for non-constant choices.
