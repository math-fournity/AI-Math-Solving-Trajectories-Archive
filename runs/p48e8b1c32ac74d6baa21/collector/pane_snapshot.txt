Looking at this problem, I need to determine whether convergence of $\{e^{ita_n}
\}$ for some fixed $t \in \mathbb{R}$ forces $\{a_n\}$ to converge.

**Answer: No.**

## Proof

We exhibit a counterexample. The key observation is that $e^{it a_n}$ depends on
ly on $a_n$ modulo $\frac{2\pi}{|t|}$ (when $t \neq 0$), so two sequences that d
iffer by integer multiples of $\frac{2\pi}{t}$ produce identical values of $e^{i
t a_n}$.

**Counterexample (for any $t \neq 0$):** Fix any $t \neq 0$ and define
$$a_n = \frac{2\pi n}{t}, \qquad n = 1, 2, 3, \ldots$$

Then
$$e^{it a_n} = e^{it \cdot \frac{2\pi n}{t}} = e^{2\pi i n} = 1 \quad \text{for
all } n.$$

So the sequence $\{e^{it a_n}\}_{n=1}^\infty$ is constantly $1$ and thus converg
es (to $1$). However,
$$a_n = \frac{2\pi n}{t} \to +\infty \quad (\text{or } -\infty \text{ if } t < 0
),$$
so $\{a_n\}$ diverges. $\square$

**Even simpler counterexample ($t = 0$):** If $t = 0$ is permitted, then $e^{i \
cdot 0 \cdot a_n} = 1$ for every $n$ regardless of $\{a_n\}$, so any divergent s
equence (e.g., $a_n = n$) provides a counterexample.

**Remark (the "for all $t$" variant).** The situation changes dramatically if on
e requires $e^{ita_n}$ to converge for **every** $t \in \mathbb{R}$. In that cas
e, the answer becomes **Yes**: $a_n$ must converge. Sketch: if $\{a_n\}$ is unbo
unded, a subsequence $|a_{n_k}|\to\infty$ forces $e^{ita_{n_k}}$ to be non-conve
rgent for some $t$ (by Diophantine considerations), contradicting the hypothesis
. So $\{a_n\}$ is bounded. If it had two distinct accumulation points $a \neq b$
, then subsequences converging to each would require $e^{ita} = e^{itb}$ for all
 $t$, i.e., $t(a-b) \in 2\pi\mathbb{Z}$ for all $t$, which forces $a = b$. Hence
 all accumulation points coincide and $a_n$ converges. But this stronger stateme
nt is **not** what the problem asks—the problem only requires convergence for **
some** single $t$, under which the answer is negative.
