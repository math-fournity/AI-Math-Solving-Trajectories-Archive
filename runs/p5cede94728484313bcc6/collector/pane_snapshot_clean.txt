## Step 1: Criterion for the integral to vanish

A continuous function $f$ on a domain $\Omega$ satisfies $\int_\gamma f\,dz = 0$
 for every closed (partially $C^1$) curve $\gamma$ in $\Omega$ if and only if $f
$ admits a primitive (antiderivative) $F$ on $\Omega$ with $F' = f$.

Here $\Omega = \mathbb{C}\setminus\{0\}$ and $f(z) = \left(\frac{1}{z} + \frac{a
}{z^3}\right)e^z$, which is holomorphic on $\Omega$.

On $\mathbb{C}\setminus\{0\}$, a holomorphic function admits a primitive if and
only if its residue at the unique puncture $0$ is zero (equivalently, its integr
al over a small positively oriented loop around $0$ vanishes, which is $2\pi i$
times the residue). So the condition is:

$$\operatorname{Res}_{z=0}\left(\frac{1}{z}+\frac{a}{z^3}\right)e^z = 0.$$

## Step 2: Computing the residue

Expand $e^z = \sum_{n=0}^{\infty} \frac{z^n}{n!}$.

**From $\frac{1}{z}e^z$:**
$$\frac{1}{z}e^z = \sum_{n=0}^{\infty}\frac{z^{n-1}}{n!} = \frac{1}{z} + 1 + \fr
ac{z}{2} + \cdots$$
The coefficient of $z^{-1}$ is $\boxed{1}$.

**From $\frac{a}{z^3}e^z$:**
$$\frac{a}{z^3}e^z = a\sum_{n=0}^{\infty}\frac{z^{n-3}}{n!} = a\left(z^{-3} + z^
{-2} + \frac{z^{-1}}{2} + \frac{1}{6} + \cdots\right).$$
The coefficient of $z^{-1}$ is $\boxed{a/2}$ (the $n=2$ term: $a\cdot\frac{z^{-1
}}{2!} = \frac{a}{2}z^{-1}$).

**Total residue:**
$$\operatorname{Res}_{z=0} f = 1 + \frac{a}{2}.$$

Setting this to zero:
$$1 + \frac{a}{2} = 0 \implies a = -2.$$

So the unique value is $\boxed{a = -2}$.

## Step 3: Finding a primitive $F$ for $a = -2$

We need $F'(z) = \left(\frac{1}{z} - \frac{2}{z^3}\right)e^z$.

**Guess:** try a linear combination of $\frac{e^z}{z}$ and $\frac{e^z}{z^2}$. Co
mpute:

$$\frac{d}{dz}\!\left(\frac{e^z}{z}\right) = \frac{e^z}{z} - \frac{e^z}{z^2} = e
^z\!\left(\frac{1}{z} - \frac{1}{z^2}\right),$$

$$\frac{d}{dz}\!\left(\frac{e^z}{z^2}\right) = \frac{e^z}{z^2} - \frac{2e^z}{z^3
} = e^z\!\left(\frac{1}{z^2} - \frac{2}{z^3}\right).$$

Adding:
$$\frac{d}{dz}\!\left(\frac{e^z}{z} + \frac{e^z}{z^2}\right) = e^z\!\left(\frac{
1}{z} - \frac{1}{z^2} + \frac{1}{z^2} - \frac{2}{z^3}\right) = e^z\!\left(\frac{
1}{z} - \frac{2}{z^3}\right).$$

The $z^{-2}$ terms cancel, leaving exactly $f(z)$ with $a=-2$. Therefore a primi
tive is

$$\boxed{F(z) = \frac{e^z}{z} + \frac{e^z}{z^2} = \frac{e^z(z+1)}{z^2}}, \qquad
z \neq 0.$$

**Verification:**
$$F'(z) = e^z\!\left(\frac{1}{z}+\frac{1}{z^2}\right) + e^z\!\left(-\frac{1}{z^2
}-\frac{2}{z^3}\right) = e^z\!\left(\frac{1}{z} - \frac{2}{z^3}\right). \checkma
rk$$

## Conclusion

The integral vanishes for every closed partially-$C^1$ curve $\gamma$ in $\mathb
b{C}\setminus\{0\}$ if and only if $a = -2$. For this value, a primitive is

$$F(z) = \frac{e^z(z+1)}{z^2}, \quad z \neq 0.$$
