# Solution

**Answer: $k = 50$.**

## Setup and Key Lemmas

Label the 100 points $1, 2, \ldots, 100$ in circular order. Call points at odd p
ositions "odd" and points at even positions "even" (50 each). Since "no two segm
ents share a common point" prohibits both shared endpoints and crossings, we see
k a **non-crossing** perfect matching with monochromatic pairs.

**Lemma 1.** *In any non-crossing perfect matching of $2n$ points on a circle, e
ach pair consists of one odd and one even point.*

*Proof.* If point $i$ is matched to point $j$ ($i < j$), the $j - i - 1$ points
strictly between them must be perfectly matched among themselves (non-crossing),
 so $j - i - 1$ is even, hence $j - i$ is odd, meaning $i$ and $j$ have opposite
 parity. $\square$

**Lemma 2.** *A non-crossing perfect matching with all pairs monochromatic exist
s if and only if $|R_o| = |R_e|$* (the number of red odd points equals the numbe
r of red even points).

*Proof.* **Necessity:** By Lemma 1, each pair contains one odd and one even poin
t of the same color. Red odd points are paired exclusively with red even points,
 so $|R_o| = |R_e|$.

**Sufficiency** (by induction on $n$): For $n=1$, two points (one odd, one even)
; $|R_o|=|R_e|$ forces the same color, so match them. For $n > 1$: If $|R_o| = |
R_e| = 0$ or $= n$, all points share one color and any non-crossing matching wor
ks. Otherwise ($0 < |R_o| = |R_e| < n$), the coloring does not perfectly alterna
te (perfect alternation gives $|R_o| = n, |R_e| = 0$ or vice versa, contradictin
g $|R_o| = |R_e|$). Hence some **adjacent** pair of points shares the same color
. Being adjacent on the circle, they are one odd and one even. Match them and re
move both. The remaining $2n-2$ points still alternate odd/even around the circl
e, and $|R_o|$ and $|R_e|$ both decrease by 1 (if the pair was red) or are uncha
nged (if blue), preserving $|R_o'| = |R_e'|$. By induction, the remainder admits
 a non-crossing monochromatic perfect matching. $\square$

## Main Argument

We need the largest $k$ such that for **any** choice of $k$ points and **any** p
re-coloring, the remaining $100 - k$ points can be colored to achieve $|R_o| = |
R_e|$.

Let $r_o, r_e, b_o, b_e$ denote the counts of pre-colored red-odd, red-even, blu
e-odd, blue-even points, with $r_o + r_e + b_o + b_e = k$. Let $u_o = 50 - r_o -
 b_o$ and $u_e = 50 - r_e - b_e$ be the uncolored odd/even counts. We color $x$
uncolored odd points and $y$ uncolored even points red ($0 \le x \le u_o$, $0 \l
e y \le u_e$). We need:

$$r_o + x = r_e + y \iff x - y = r_e - r_o =: d.$$

This is solvable if and only if $-u_e \le d \le u_o$ (set $x = \max(d,0),\; y =
\max(-d,0)$).

### $k = 50$ always works

With $r_o + r_e + b_o + b_e = 50$, we verify both bounds:

- **Upper bound** $d \le u_o$: $\;r_e - r_o \le 50 - r_o - b_o \iff r_e + b_o \l
e 50$. Since $r_e + b_o = 50 - r_o - b_e \le 50$. ✓
- **Lower bound** $d \ge -u_e$: $\;r_e - r_o \ge -(50 - r_e - b_e) \iff r_o + b_
e \le 50$. Since $r_o + b_e = 50 - r_e - b_o \le 50$. ✓

Both hold for every pre-coloring, so we can always complete the coloring to sati
sfy $|R_o| = |R_e|$, and Lemma 2 guarantees a non-crossing monochromatic perfect
 matching.

### $k = 51$ fails

**Adversary's strategy:** Pre-color all 50 even-positioned points red and 1 odd-
positioned point blue:
$$r_e = 50,\; r_o = 0,\; b_o = 1,\; b_e = 0.$$
Then $d = r_e - r_o = 50$, but $u_o = 50 - 0 - 1 = 49$. Since $50 > 49$, no choi
ce of $x \in [0, 49]$ can achieve $x - y = 50$. So $|R_o| = |R_e|$ is impossible
, and by Lemma 2 no non-crossing monochromatic perfect matching exists.

## Conclusion

The largest $k$ is $\boxed{50}$: for any 50 pre-colored points with arbitrary co
lors, the remaining 50 can always be colored to permit a non-crossing perfect ma
tching with monochromatic pairs; but for 51 pre-colored points, an adversary can
 prevent this.
