### Example

Let $\mathscr{C}$ be the full subcategory of $\mathbf{Set}$ whose objects are al
l sets of cardinality $\leq 1$. This is a concrete category: the inclusion funct
or $U : \mathscr{C} \hookrightarrow \mathbf{Set}$ is faithful, and morphisms in
$\mathscr{C}$ are exactly the set-theoretic functions between the underlying set
s.

Set
$$X = \{1, 2\}, \qquad A = \{*\} \text{ (a singleton)}, \qquad i : X \to A, \qua
d i(1) = i(2) = *.$$

The map $i$ is constant, hence **not injective**.

### Verification of the universal property

We must show: for every object $B$ in $\mathscr{C}$ and every map $j : X \to U(B
)$, there exists a unique morphism $\phi : A \to B$ in $\mathscr{C}$ with $\phi
\circ i = j$.

The objects of $\mathscr{C}$ are $\emptyset$ and singletons $\{b\}$.

**Case $B = \emptyset$:** Since $X \neq \emptyset$, no map $j : X \to \emptyset$
 exists. The condition is vacuously satisfied.

**Case $B = \{b\}$ (singleton):** Any map $j : X \to \{b\}$ is forced to be cons
tant: $j(1) = j(2) = b$. Define $\phi : A \to B$ by $\phi(*) = b$. Then
$$(\phi \circ i)(1) = \phi(*) = b = j(1), \qquad (\phi \circ i)(2) = \phi(*) = b
 = j(2),$$
so $\phi \circ i = j$. Since $A$ and $B$ are both singletons, there is exactly o
ne function $A \to B$, namely $\phi$. Hence $\phi$ is **unique**. $\checkmark$

Therefore $A = \{*\}$ is free on $X = \{1,2\}$ in $\mathscr{C}$, with $i$ non-in
jective. $\square$

### Implications for the uniqueness of $\phi$

The uniqueness of $\phi$ is **not broken** by non-injectivity of $i$ — it remain
s part of the universal property and continues to hold. However, the example rev
eals that non-injective $i$ is only possible in a **degenerate** category, one t
hat lacks the objects needed to "detect" the collapse. The precise statement is:

> **Claim.** In any concrete category $\mathscr{C}$ that possesses an object $B$
 with $|U(B)| \geq 2$, the universal property (existence **and** uniqueness of $
\phi$) forces $i$ to be injective.

**Proof of Claim.** Suppose for contradiction that $i(x_1) = i(x_2)$ for some $x
_1 \neq x_2$ in $X$. Choose an object $B$ with $|U(B)| \geq 2$ and pick distinct
 elements $b_1 \neq b_2 \in U(B)$. Define $j : X \to U(B)$ by $j(x_1) = b_1$ and
 $j(x) = b_2$ for all $x \neq x_1$; in particular $j(x_1) \neq j(x_2)$. By the u
niversal property, there exists $\phi : A \to B$ with $\phi \circ i = j$. Then
$$j(x_1) = \phi(i(x_1)) = \phi(i(x_2)) = j(x_2),$$
contradicting $j(x_1) \neq j(x_2)$. Hence $i$ must be injective. $\square$

**Conclusion.** The uniqueness clause of the universal property, combined with t
he existence of any object whose underlying set has at least two elements, **for
ces $i$ to be injective**. A non-injective $i$ can only arise in a category wher
e every object has underlying set of size $\leq 1$ (or, more generally, where no
 object can separate the points that $i$ collapses). In such a degenerate catego
ry, uniqueness of $\phi$ holds trivially — there is at most one morphism between
 any two objects — but the "free object" $A$ carries no meaningful information a
bout $X$ beyond the collapse, since distinct elements of $X$ are identified in $
A$ and no object in the category can witness the distinction. Thus, for any non-
degenerate concrete category (e.g., $\mathbf{Set}$, $\mathbf{Grp}$, $\mathbf{Rin
g}$, $\mathbf{Mod}_R$, topological spaces, etc.), injectivity of $i$ is a **cons
equence** of the universal property, not an independent assumption.
