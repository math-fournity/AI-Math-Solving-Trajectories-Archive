## Claim: It is NOT necessarily true that $m(\partial A) = 0$.

## Proof (by counterexample)

Let $F \subset [0,1]$ be a **fat Cantor set** (e.g., the Smith–Volterra–Cantor s
et) with $m(F) = \tfrac{1}{2}$. Recall that $F$ is:
- **closed** (complement of a union of open intervals),
- **nowhere dense** (hence $\operatorname{int}(F) = \emptyset$),
- **positive Lebesgue measure** ($m(F) = 1/2$).

Set $A = \mathbb{R} \setminus F$.

**Computing $A^o$:** Since $F$ is closed, $A = \mathbb{R} \setminus F$ is open,
so $A^o = A = \mathbb{R} \setminus F$.

**Computing $\overline{A}$:** Since $F$ is nowhere dense, $\mathbb{R} \setminus
F$ is dense in $\mathbb{R}$, so $\overline{A} = \mathbb{R}$.

**Computing $\partial A$:** $\partial A = \overline{A} \setminus A^o = \mathbb{R
} \setminus (\mathbb{R} \setminus F) = F$.

**Checking the hypothesis:**
$$m(A^o) = m(\mathbb{R} \setminus F) = \infty,$$
since $\mathbb{R} \setminus F \supseteq (-\infty, 0) \cup (1,\infty)$, which alr
eady has infinite measure. Also,
$$m(\overline{A}) = m(\mathbb{R}) = \infty.$$
Thus $m(A^o) = m(\overline{A}) = \infty$. ✓

**Checking the conclusion:**
$$m(\partial A) = m(F) = \tfrac{1}{2} \neq 0.$$

So the hypothesis $m(A^o) = m(\overline{A})$ holds, yet $m(\partial A) = 1/2 > 0
$. $\square$
