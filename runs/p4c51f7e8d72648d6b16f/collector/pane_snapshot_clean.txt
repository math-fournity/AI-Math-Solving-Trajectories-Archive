**Claim.** There exists a discrete non-archimedean valued field with an infinite
 residue field.

athbb{Z}.$$

Define $v : \mathbb{K}^{\times} \to \mathbb{Z}$ by $v(f) = N$ (the smallest expo
nent with a nonzero coefficient), and set $v(0) = +\infty$. Define the absolute
value $|f| = c^{v(f)}$ for any fixed $c \in (0,1)$.

**Step 1 — $v$ is a discrete valuation.** For $f, g \in \mathbb{K}^{\times}$ wit
h leading terms $a_N t^N$, $b_M t^M$:
- $v(fg) = v(f) + v(g)$: the leading term of $fg$ is $a_N b_M t^{N+M}$ with $a_N
 b_M \neq 0$.
- $v(f+g) \geq \min(v(f), v(g))$, with equality when $v(f) \neq v(g)$: if $N < M
$, the leading term of $f+g$ is still $a_N t^N$; if $N = M$, the leading coeffic
ient is $a_N + b_N$, which may vanish, giving $v(f+g) > N$.

The value group is $v(\mathbb{K}^{\times}) = \mathbb{Z}$, which is discrete (iso
morphic to $\mathbb{Z}$). Hence $v$ is a **discrete** valuation.

**Step 2 — The absolute value is non-archimedean.** The ultrametric inequality $
|f+g| \leq \max(|f|, |g|)$ follows directly from $v(f+g) \geq \min(v(f),v(g))$ (
since $c \in (0,1)$ reverses the order). Thus $|\cdot|$ is non-archimedean.

**Step 3 — The residue field is infinite.** The valuation ring is
$$\mathcal{O} = \{f \in \mathbb{K} : v(f) \geq 0\} = \mathbb{Q}[[t]] = \left\{\s
um_{n \geq 0} a_n t^n\right\},$$
the ring of formal power series. Its unique maximal ideal is
$$\mathfrak{m} = \{f \in \mathbb{K} : v(f) \geq 1\} = t\,\mathbb{Q}[[t]].$$
The residue field is
$$\kappa = \mathcal{O}/\mathfrak{m} = \mathbb{Q}[[t]]\,/\,t\,\mathbb{Q}[[t]].$$

The quotient map sends $\sum_{n \geq 0} a_n t^n \mapsto a_0$. This is a surjecti

[[t]]$, so by the first isomorphism theorem
$$\kappa \cong \mathbb{Q}.$$

Since $\mathbb{Q}$ is infinite, the residue field $\kappa$ is **infinite**.
