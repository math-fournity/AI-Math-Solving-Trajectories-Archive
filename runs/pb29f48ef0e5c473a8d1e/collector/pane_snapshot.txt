## Solution

We compute $\displaystyle L = \lim_{n\to\infty}\left(\sqrt{2}\,\frac{\Gamma\!\le
ft(\frac{n+1}{2}\right)}{\Gamma\!\left(\frac{n}{2}\right)} - \sqrt{n}\right)$.

**Setup.** Set $x = n/2$, so $n = 2x$ and $x \to \infty$. The expression becomes
$$L = \lim_{x\to\infty}\left(\sqrt{2}\,\frac{\Gamma(x+\tfrac12)}{\Gamma(x)} - \s
qrt{2x}\right).$$

**Stirling expansion.** The log-Gamma Stirling series is
$$\ln\Gamma(z) = \left(z-\tfrac12\right)\ln z - z + \tfrac12\ln(2\pi) + \frac{1}
{12z} - \frac{1}{360z^3} + \cdots$$

Forming the difference $\ln\Gamma(x+\tfrac12) - \ln\Gamma(x)$:

$$\ln\Gamma\!\left(x+\tfrac12\right) = x\ln\!\left(x+\tfrac12\right) - \left(x+\
tfrac12\right) + \tfrac12\ln(2\pi) + \frac{1}{12(x+1/2)} - \cdots$$

$$\ln\Gamma(x) = \left(x-\tfrac12\right)\ln x - x + \tfrac12\ln(2\pi) + \frac{1}
{12x} - \cdots$$

Expanding $\ln(x+\tfrac12) = \ln x + \frac{1}{2x} - \frac{1}{8x^2} + \frac{1}{24
x^3} - \cdots$, we get
$$x\ln\!\left(x+\tfrac12\right) = x\ln x + \tfrac12 - \tfrac{1}{8x} + \tfrac{1}{
24x^2} - \cdots$$

Subtracting:
$$\ln\frac{\Gamma(x+\tfrac12)}{\Gamma(x)} = \tfrac12\ln x - \tfrac{1}{8x} + \tfr
ac{1}{24x^2} + \left[\frac{1}{12(x+1/2)} - \frac{1}{12x}\right] + \cdots$$

Since $\frac{1}{12(x+1/2)} = \frac{1}{12x}\left(1 - \frac{1}{2x} + \cdots\right)
 = \frac{1}{12x} - \frac{1}{24x^2} + \cdots$, the bracket equals $-\frac{1}{24x^
2}+\cdots$, which **cancels** the $\frac{1}{24x^2}$ term. Thus

$$\ln\frac{\Gamma(x+\tfrac12)}{\Gamma(x)} = \tfrac12\ln x - \frac{1}{8x} + O(x^{
-3}).$$

**Exponentiating:**
$$\frac{\Gamma(x+\tfrac12)}{\Gamma(x)} = \sqrt{x}\,\exp\!\left(-\frac{1}{8x}+O(x
^{-3})\right) = \sqrt{x}\left(1 - \frac{1}{8x} + O(x^{-2})\right).$$

**Forming the limit:**
$$\sqrt{2}\,\frac{\Gamma(x+\tfrac12)}{\Gamma(x)} = \sqrt{2x}\left(1 - \frac{1}{8
x} + O(x^{-2})\right) = \sqrt{2x} - \frac{\sqrt{2}}{8\sqrt{x}} + O(x^{-3/2}).$$

Therefore
$$\sqrt{2}\,\frac{\Gamma(x+\tfrac12)}{\Gamma(x)} - \sqrt{2x} = -\frac{\sqrt{2}}{
8\sqrt{x}} + O(x^{-3/2}) \;\xrightarrow{x\to\infty}\; 0.$$

**Numerical check.** For $n=100$: the correction is $-\frac{1}{4\sqrt{100}} = -0
.025$, consistent with direct evaluation. As $n\to\infty$ this vanishes.

$$\boxed{L = 0}$$
