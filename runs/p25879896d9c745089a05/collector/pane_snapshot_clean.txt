## Proof of `green_29.variant`

**Statement.** For every K ≥ 1, there exists c > 0 such that for every group G a
nd every K-approximate subgroup A (as a finset), there exists a finset S with c·
|A| ≤ |S| and S⁸ ⊆ A⁴.

### Tool: Croot–Sisask Lemma

**Lemma (Croot–Sisask, 2010).** Let G be a group, f : G → ℝ a nonzero finitely-s
upported function, p ≥ 2, and 0 < ε < 1. Then there exists a set S ⊆ G with
$$|S| \ge \left(\frac{\varepsilon}{2}\right)^{2p} \frac{\|f\|_1^2}{\|f\|_2^2}$$
such that for every s ∈ S:
$$\|f - \tau_s f\|_p \le \varepsilon \|f\|_p,$$
where $\tau_s f(x) = f(xs)$ is right-translation.

### Applying Croot–Sisask

Set $f = \mathbf{1}_A * \mathbf{1}_A$, $p = 2$, $\varepsilon = 1/16$.

**Computing the norms.** Let $r(g) = |\{(a,b) \in A^2 : ab = g\}|$, so $f(g) = r
(g)$.

- $\|f\|_1 = \sum_g r(g) = |A|^2$.
- $\|f\|_2^2 = \sum_g r(g)^2 = E(A,A)$ (the multiplicative energy).
- Since $A$ is symmetric ($A = A^{-1}$) and $e \in A$: $r(e) = |\{(a, a^{-1}) :
a \in A\}| = |A|$, so $\max_g r(g) = |A|$ (as $r(g) \le |A|$ trivially).
- Therefore $E(A,A) \le (\max_g r(g)) \cdot \sum_g r(g) = |A| \cdot |A|^2 = |A|^
3$.
- Hence $\frac{\|f\|_1^2}{\|f\|_2^2} = \frac{|A|^4}{E(A,A)} \ge \frac{|A|^4}{|A|
^3} = |A|$.

By Croot–Sisask:
$$|S| \ge \left(\frac{1}{32}\right)^4 \cdot |A| = \frac{|A|}{2^{20}}.$$

Set $c = 2^{-20}$ (independent of K, hence a fortiori a valid choice for the var
iant).

### Proving S⁸ ⊆ A⁴

For $s_1, \dots, s_8 \in S$, by the triangle inequality and the fact that $\tau$
 is an $L^p$-isometry:

$$\|f - \tau_{s_1 \cdots s_8} f\|_2 \le \sum_{i=1}^{8} \|\tau_{s_1 \cdots s_{i-1
}} f - \tau_{s_1 \cdots s_i} f\|_2 = \sum_{i=1}^{8} \|f - \tau_{s_i} f\|_2 \le 8
 \cdot \frac{1}{16} \|f\|_2 = \frac{1}{2}\|f\|_2.$$

**Support overlap.** We have $\operatorname{supp}(f) = A^2$ and $\operatorname{s
upp}(\tau_{s_1 \cdots s_8} f) = A^2 \cdot (s_1 \cdots s_8)^{-1}$.

If $A^2 \cap A^2 \cdot (s_1 \cdots s_8)^{-1} = \emptyset$, then $f$ and $\tau_{s
_1 \cdots s_8} f$ have disjoint supports, so:
$$\|f - \tau_{s_1 \cdots s_8} f\|_2^2 = \|f\|_2^2 + \|\tau_{s_1 \cdots s_8} f\|_
2^2 = 2\|f\|_2^2,$$
giving $\|f - \tau_{s_1 \cdots s_8} f\|_2 = \sqrt{2}\,\|f\|_2$.

But we showed $\|f - \tau_{s_1 \cdots s_8} f\|_2 \le \frac{1}{2}\|f\|_2 < \sqrt{
2}\,\|f\|_2$ — **contradiction**.

Therefore $A^2 \cap A^2 \cdot (s_1 \cdots s_8)^{-1} \neq \emptyset$: there exist
 $a, b, c, d \in A$ with $ab = cd \cdot (s_1 \cdots s_8)^{-1}$, i.e.,
$$s_1 \cdots s_8 = d^{-1} c^{-1} a b.$$

Since $A = A^{-1}$, we have $d^{-1}, c^{-1} \in A$, so $s_1 \cdots s_8 \in A \cd
ot A \cdot A \cdot A = A^4$.

Since this holds for all $s_1, \dots, s_8 \in S$, we conclude $S^8 \subseteq A^4
$. $\blacksquare$

## Remark on `green_29` (the open conjecture)

The main obstruction is the requirement **S ⊆ A**. The Croot–Sisask technique pr
oduces almost-periods that lie in $A^4$ (a single $s \in S$ satisfies $s \in A^4
$ by the same support-overlap argument with $k=1$), but there is no known method
 to guarantee a subset of $A$ itself with the required size and the $S^8 \subset
eq A^4$ property. This is precisely why Green's Problem 29 remains open.
