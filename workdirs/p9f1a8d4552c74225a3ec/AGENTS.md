# Problem

In the competitive world of digital logistics, a "Server-Load Batch" is defined by a capacity $n$, where $n$ is a positive integer. A load balancer distributes tasks sequentially, starting from 1 task, then 2, then 3, and so on. For any capacity $n$, we define $f(n)$ as the smallest number of sequential task-groups $m$ such that the total number of tasks (the sum $1 + 2 + \dots + m$) can be partitioned perfectly into the $n$ server slots without any remainder.

A capacity $n$ is classified as "Optimized" if the number of task-groups required to reach this perfect partition is exactly one less than the capacity itself, such that $f(n) = n - 1$.

Calculate the sum of all "Optimized" capacities $n$ that fall within the range $1 < n < 100$.
