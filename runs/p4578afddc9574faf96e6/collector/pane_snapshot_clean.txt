## 答案：**不正确。**

并非所有导出范畴之间的等价都能保持其 distinguished triangles。下面是一个反例。

---

**设定。** 设 $k$ 为一个域，$\mathcal{A} = \mathbf{fdVect}_k$ 为有限维 $k$-向量
空间范畴。由于 $k$ 是一个域，每个有界复形都分裂，并且拟同构于它的同调，因此有界
导出范畴等价于有界 $\mathbb{Z}$-分次有限维向量空间范畴：

$$D^b(\mathcal{A}) \;\cong\; \bigl\{(V^n)_{n\in\mathbb{Z}} : \dim_k V^n < \infty
,\; V^n = 0 \text{ 对于 } |n|\gg 0\bigr\}.$$

在这个等价关系下，shift 函子 $[1]$（上链约定）作用为 $(V[1])^n = V^{n+1}$。

**反等价。** 通过“翻转度数”定义一个自等价 $G$：

$$(GV)^n := V^{-n}.$$

这显然是 $D^b(\mathcal{A})$ 的一个 $k$-线性自等价（它是其自身的逆，并且保持了分
次范畴的态射）。

**$G$ 不与 shift 交换。** 对于任意分次对象 $V$，

$$(G(V[1]))^n = (V[1])^{-n} = V^{-n+1}, \qquad ((GV)[1])^n = (GV)^{n+1} = V^{-n-
1}.$$

因此 $G\circ[1] = [-1]\circ G$，特别地，$G\circ[1] \not\cong [1]\circ G$。

**$G$ 不保持 distinguished triangles。** 考虑与恒等态射相关联的标准 distinguishe
d triangle

$$k \xrightarrow{\;\mathrm{id}\;} k \longrightarrow 0 \longrightarrow k[1],$$

其中 $k$ 表示集中在度数 $0$ 的对象。应用 $G$：因为 $k$ 在度数 $0$，所以 $G(k)=k$
。对象 $k[1]$ 是集中在度数 $-1$ 的 $k$，因此

$$(G(k[1]))^n = (k[1])^{-n} = \begin{cases} k & \text{如果 } -n=-1,\text{ 即 } n
=1,\\ 0 & \text{其他},\end{cases}$$

即 $G(k[1]) = k[-1]$（集中在度数 $1$ 的 $k$）。因此 $G$ 下该三角形的像为

$$k \xrightarrow{\;\mathrm{id}\;} k \longrightarrow 0 \longrightarrow k[-1].$$

$D^b(\mathbf{fdVect}_k)$ 中的 Distinguished triangle 必须具有形式 $X\to Y\to Z\t
o X[1]$，其最后一项是 $X[1]$。这里第一项是 $X=k$，所以最后一项必须是 $k[1]$。但
实际的最后一项是 $k[-1]$，且 $k[-1]\not\cong k[1]$，因为它们在不同的度数上有支撑
（分别在度数 $1$ 和 $-1$），而在 $D^b(\mathbf{fdVect}_k)$ 中，两个对象同构当且仅
当它们具有相同的分次维数。

因此 $k \xrightarrow{\mathrm{id}} k \to 0 \to k[-1]$ **不是** distinguished tria
ngle，从而 $G$ 不保持 distinguished triangles。

---

**结论。** 自等价 $G : D^b(\mathbf{fdVect}_k) \to D^b(\mathbf{fdVect}_k)$ 是导出
范畴（作为范畴）的一个等价，但它不保持 distinguished triangles。因此，**并非所有
导出范畴之间的等价都能保持 distinguished triangles**；三角结构并不是单纯从导出范
畴的范畴结构中恢复出来的。 $\blacksquare$
