## Proof

Let $f(x) = e^{ax}\cos(bx)$ with $a, b > 0$, and let $f(x) = \sum_{n=0}^{\infty}
 c_n x^n$ be its power series.

**Step 1: Compute the coefficients.**

Since $e^{ax}\cos(bx) = \operatorname{Re}\!\bigl(e^{(a+ib)x}\bigr)$, we have

$$c_n = \frac{1}{n!}\operatorname{Re}\!\bigl((a+ib)^n\bigr).$$

Write $z = a + ib = re^{i\theta}$, where $r = \sqrt{a^2+b^2} > 0$ and $\theta =
\arctan(b/a) \in (0,\pi/2)$. Then

$$\operatorname{Re}(z^n) = r^n \cos(n\theta),$$

so, since $r^n/n! > 0$,

$$c_n = 0 \iff \cos(n\theta) = 0 \iff n\theta = \frac{\pi}{2} + k\pi \text{ for
some integer } k \geq 0.$$

Equivalently, setting $\alpha = \theta/\pi \in (0, 1/2)$:

$$c_n = 0 \iff n\alpha = k + \tfrac{1}{2} \iff 2n\alpha = 2k+1 \text{ (an odd in
teger)}.$$

**Step 2: If $\alpha$ is irrational, there are zero zero-coefficients.**

If $c_n = 0$ for some $n \geq 1$, then $2n\alpha = 2k+1 \in \mathbb{Z}$, giving
$\alpha = (2k+1)/(2n)$, which is **rational** — a contradiction. Hence every $c_
n \neq 0$.

**Step 3: If $\alpha$ is rational, write $\alpha = p/q$ in lowest terms.**

The condition $c_n = 0$ becomes $2np/q \in 2\mathbb{Z}+1$ (a positive odd intege
r). Since $\gcd(p,q)=1$:

- **$q$ odd:** $q \mid 2n \Rightarrow q \mid n$ (as $\gcd(q,2)=1$). Writing $n =
 qj$, we get $2np/q = 2jp$, which is **even**. No solution exists, so there are
**zero** zero-coefficients.

- **$q$ even, $q = 2q'$:** Then $q \mid 2n \iff q' \mid n$. Write $n = q'm$; the
n $2np/q = mp$. Since $q$ is even and $\gcd(p,q)=1$, $p$ is **odd**. We need $mp
$ odd, i.e., $m$ **odd**. Thus $c_n = 0 \iff n = q'm$ with $m$ a positive odd in
teger. There are **infinitely many** such $n$ (namely $n = q',\, 3q',\, 5q',\, \
dots$).

(For each such $n = q'm$ with $m$ odd, $n\theta = mp\pi/2$ with $mp$ a positive
odd integer, so $k = (mp-1)/2 \geq 0$ is a valid non-negative integer, confirmin
g $\cos(n\theta)=0$.)

**Conclusion.** In every case — $\alpha$ irrational, $\alpha$ rational with odd
denominator, or $\alpha$ rational with even denominator — the number of zero coe
fficients is either **0** or **infinite**. $\blacksquare$
