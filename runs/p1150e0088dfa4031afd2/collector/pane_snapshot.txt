## Solution

We interpret the integral as a **Lebesgue integral**, since $g$ is discontinuous
 at every point of $[0,1]$ (both $\mathbb{Q}$ and $\mathbb{R}\setminus\mathbb{Q}
$ are dense), so the Riemann integral does not exist.

### Step 1: Reduce to the irrational part

The set $\mathbb{Q}\cap[0,1]$ has Lebesgue measure $0$. Since $g$ differs from $
h(x) = \lfloor 1/x \rfloor$ only on this null set (where $g=1$ instead of $\lflo
or 1/x\rfloor$), the Lebesgue integral is unchanged:

$$\int_0^1 g(x)\,dx = \int_0^1 \lfloor 1/x \rfloor\, dx.$$

(At $x=0$ the value is irrelevant for the integral; we work on $(0,1]$.)

### Step 2: Decompose via level sets

For $x\in(0,1]$, we have $\lfloor 1/x \rfloor = n$ precisely when

$$n \le \frac{1}{x} < n+1 \quad\Longleftrightarrow\quad \frac{1}{n+1} < x \le \f
rac{1}{n}, \qquad n = 1, 2, 3, \dots$$

These intervals $\left(\frac{1}{n+1},\, \frac{1}{n}\right]$ are disjoint and cov
er $(0,1]$. Therefore

$$\int_0^1 \lfloor 1/x \rfloor\, dx = \sum_{n=1}^{\infty} n\left(\frac{1}{n} - \
frac{1}{n+1}\right) = \sum_{n=1}^{\infty} n\cdot\frac{1}{n(n+1)} = \sum_{n=1}^{\
infty}\frac{1}{n+1} = \sum_{k=2}^{\infty}\frac{1}{k}.$$

### Step 3: Recognize divergence

The series $\sum_{k=2}^{\infty}\frac{1}{k}$ is the tail of the harmonic series,
which **diverges** to $+\infty$.

### Verification via a lower bound

As a sanity check, for all $x\in(0,1]$,

$$\lfloor 1/x \rfloor \ge \frac{1}{x} - 1,$$

so

$$\int_0^1 \lfloor 1/x \rfloor\, dx \ge \int_0^1\!\left(\frac{1}{x}-1\right)dx =
 \int_0^1\frac{dx}{x} - 1 = +\infty.$$

This confirms the divergence independently.

### Conclusion

The integral diverges:

$$\boxed{\int_0^1 g(x)\,dx = +\infty.}$$
