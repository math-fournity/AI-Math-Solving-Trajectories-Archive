Looking at this problem, I need to find all positive integers $a, b, c$ such tha
t the fractional parts $\{\sqrt{an^2+bn+c}\}$ are dense in $[0,1]$.

**Answer:** All positive integers $(a, b, c)$ such that $a$ is **not a perfect s
quare**.

---

## Proof

### Asymptotic Expansion

For large $n$, expand $f(n) = \sqrt{an^2+bn+c}$:

$$f(n) = \sqrt{a}\,n\sqrt{1 + \tfrac{b}{an} + \tfrac{c}{an^2}} = \sqrt{a}\,n + \
frac{b}{2\sqrt{a}} + \frac{4ac - b^2}{8a\sqrt{a}\,n} + O(n^{-2}).$$

Set $\alpha = \sqrt{a}$, $\beta = \frac{b}{2\sqrt{a}}$, and $\delta_n = f(n) - (
\alpha n + \beta) = O(1/n)$.

### Part 1: $a$ not a perfect square $\Rightarrow$ condition holds

Since $a$ is a positive integer and not a perfect square, $\alpha = \sqrt{a}$ is
 irrational. By Weyl's equidistribution theorem, the sequence $\{\alpha n + \bet
a\}_{n \geq 1}$ is equidistributed (hence dense) in $[0,1]$.

We show $\{f(n)\} = \{\alpha n + \beta + \delta_n\}$ is dense in $[0,1]$.

Let $(u,v) \subset [0,1]$ with $u < v$. Set $\varepsilon = \frac{v-u}{4} > 0$. C
hoose $N$ large enough that $|\delta_n| < \varepsilon$ for all $n \geq N$.

By equidistribution of $\{\alpha n + \beta\}$, there exist infinitely many $n \g
eq N$ with
$$\{\alpha n + \beta\} \in (u + \varepsilon,\; v - \varepsilon).$$

For any such $n$, since $|\delta_n| < \varepsilon$:
- $\{\alpha n + \beta\} > u + \varepsilon > \varepsilon > |\delta_n|$, so $\{\al
pha n + \beta\} + \delta_n > 0$ (no wrap-around below 0).
- $\{\alpha n + \beta\} < v - \varepsilon < 1 - \varepsilon < 1 - |\delta_n|$, s
o $\{\alpha n + \beta\} + \delta_n < 1$ (no wrap-around above 1).

Therefore no wrapping occurs and:
$$\{f(n)\} = \{\alpha n + \beta\} + \delta_n \in (u + \varepsilon - \varepsilon,
\; v - \varepsilon + \varepsilon) = (u, v).$$

Since $(u,v)$ was arbitrary, $\{f(n)\}$ is dense in $[0,1]$.

### Part 2: $a$ a perfect square $\Rightarrow$ condition fails

Let $a = k^2$ for some positive integer $k$. Then:

$$f(n) = \sqrt{k^2 n^2 + bn + c} = kn + \frac{b}{2k} + \frac{4k^2 c - b^2}{8k^3
n} + O(n^{-2}).$$

Since $kn$ is an integer:
$$\{f(n)\} = \left\{\frac{b}{2k} + O\!\left(\frac{1}{n}\right)\right\}.$$

As $n \to \infty$, this converges to $\left\{\frac{b}{2k}\right\}$, a single fix
ed value (which is rational since $b, k$ are integers). A convergent sequence ha
s at most one limit point, so its set of values is **not dense** in $[0,1]$.

Concretely, choose any interval $(u, v)$ not containing $\{b/(2k)\}$; for large
enough $n$, no $\{f(n)\}$ falls in $(u,v)$, violating the condition.

### Conclusion

The condition holds if and only if $a$ is not a perfect square. The values of $b
$ and $c$ (any positive integers) do not affect the answer, since:
- When $a$ is non-square, the irrationality of $\sqrt{a}$ drives equidistributio
n regardless of $b, c$.
- When $a = k^2$, the fractional part always converges to the single point $\{b/
(2k)\}$ regardless of $c$.

The complete set of solutions is:
$$\boxed{(a, b, c) \in \mathbb{Z}_{>0}^3 \text{ such that } a \text{ is not a pe
rfect square.}}$$
