# Solution

**Answer: Yes.** If a bounded operator $T: X \to Y$ between Banach spaces has cl
osed image, then its adjoint $T^*: Y^* \to X^*$ has weak$^*$-closed image. This
is the forward direction of the **Closed Range Theorem**.

---

## Proof

Let $T \in \mathcal{L}(X, Y)$ with $\operatorname{Ran}(T)$ closed in $Y$. We pro
ve that $\operatorname{Ran}(T^*)$ is weak$^*$-closed in $X^*$ by establishing th
e identity

$$\operatorname{Ran}(T^*) = \ker(T)^\perp,$$

where $\ker(T)^\perp = \{x^* \in X^* : x^*(x) = 0 \text{ for all } x \in \ker(T)
\}$, and then showing the right-hand side is weak$^*$-closed.

### Step 1: Inclusion $\operatorname{Ran}(T^*) \subseteq \ker(T)^\perp$

If $x^* = T^* y^*$ for some $y^* \in Y^*$ and $x \in \ker(T)$, then
$$x^*(x) = (T^* y^*)(x) = y^*(Tx) = y^*(0) = 0.$$
Hence $x^* \in \ker(T)^\perp$.

### Step 2: Reverse inclusion $\ker(T)^\perp \subseteq \operatorname{Ran}(T^*)$

Let $x^* \in \ker(T)^\perp$. Since $x^*$ vanishes on $\ker(T)$, it descends to a
 bounded linear functional $\tilde{x}^*$ on the quotient $X / \ker(T)$ via
$$\tilde{x}^*([x]) = x^*(x),$$
with $\|\tilde{x}^*\| \leq \|x^*\|$ (well-definedness follows from $x^* \in \ker
(T)^\perp$).

Since $\operatorname{Ran}(T)$ is closed, the **induced map**
$$\tilde{T}: X / \ker(T) \longrightarrow \operatorname{Ran}(T), \qquad \tilde{T}
([x]) = Tx$$
is a bounded bijection between Banach spaces (the codomain is a closed subspace
of $Y$, hence complete). By the **Open Mapping Theorem**, $\tilde{T}$ is an isom
orphism.

Define $\phi: \operatorname{Ran}(T) \to \mathbb{F}$ by
$$\phi(y) = \tilde{x}^*\!\bigl(\tilde{T}^{-1}(y)\bigr).$$
This is a bounded linear functional on $\operatorname{Ran}(T)$. By the **Hahn–Ba
nach theorem**, $\phi$ extends to a functional $y^* \in Y^*$.

For every $x \in X$:
$$(T^* y^*)(x) = y^*(Tx) = \phi(Tx) = \tilde{x}^*([x]) = x^*(x).$$

Therefore $T^* y^* = x^*$, so $x^* \in \operatorname{Ran}(T^*)$.

### Step 3: $\ker(T)^\perp$ is weak$^*$-closed

Write
$$\ker(T)^\perp = \bigcap_{x \in \ker(T)} \ker(\delta_x), \qquad \delta_x: X^* \
to \mathbb{F},\; \delta_x(x^*) = x^*(x).$$

Each evaluation map $\delta_x$ is weak$^*$-continuous by definition of the weak$
^*$ topology, so each $\ker(\delta_x)$ is weak$^*$-closed. An arbitrary intersec
tion of weak$^*$-closed sets is weak$^*$-closed. Hence $\ker(T)^\perp$ is weak$^
*$-closed.

### Conclusion

Combining Steps 1–3:
$$\operatorname{Ran}(T^*) = \ker(T)^\perp,$$
and the right-hand side is weak$^*$-closed. Therefore $\operatorname{Ran}(T^*)$
is weak$^*$-closed in $X^*$. $\blacksquare$

---

**Remark.** The converse also holds: if $\operatorname{Ran}(T^*)$ is weak$^*$-cl
osed, then $\operatorname{Ran}(T)$ is closed. In fact, all three conditions are
equivalent (Closed Range Theorem):
1. $\operatorname{Ran}(T)$ is norm-closed in $Y$;
2. $\operatorname{Ran}(T^*)$ is norm-closed in $X^*$;
3. $\operatorname{Ran}(T^*)$ is weak$^*$-closed in $X^*$.

The equivalence of (2) and (3) is non-trivial: a generic norm-closed subspace of
 $X^*$ need not be weak$^*$-closed, but for the range of an adjoint operator the
 two notions coincide.
