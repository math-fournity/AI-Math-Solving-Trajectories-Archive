## Proof

### Upper Bound: Construction with 2n + 2 vertices

**Construction.** Take a clique $K_n$ on vertices $s_1, s_2, \ldots, s_n$. Add $
n+2$ vertices $t_1, t_2, \ldots, t_{n+2}$, each connected to all of $s_1, \ldots
, s_n$ and to no other vertex.

**Verification.**
- **Total vertices:** $n + (n+2) = 2n+2$.
- **Connected:** Every $t_i$ is adjacent to the clique $K_n$, so the graph is co
nnected.
- **Minimum degree $\geq n$:** Each $t_i$ has degree $n$ (connected to all $s_j$
). Each $s_j$ has degree $(n-1) + (n+2) = 2n+1 \geq n$. So $\delta(G) = n$. ✓
- **No Hamiltonian path:** Set $S = \{s_1, \ldots, s_n\}$, so $|S| = n$. Removin
g $S$ leaves $n+2$ isolated vertices $t_1, \ldots, t_{n+2}$, giving $c(G - S) =
n+2$ components.

  **Necessary condition for Hamiltonian path:** If $G$ has a Hamiltonian path $P
$, then removing any set $S$ from $P$ breaks it into at most $|S|+1$ subpaths, e
ach lying in a single component of $G-S$. Hence $c(G-S) \leq |S|+1$ for all $S$.

  Here $c(G-S) = n+2 > n+1 = |S|+1$, so **no Hamiltonian path exists**. ✓

### Lower Bound: 2n + 2 is necessary

**Theorem (Dirac-type for Hamiltonian paths).** If $G$ is a graph on $N$ vertice
s with minimum degree $\delta(G) \geq \frac{N-1}{2}$, then $G$ has a Hamiltonian
 path.

*Proof.* Add a universal vertex $v^*$ connected to all vertices of $G$. The resu
lting graph $G'$ has $N+1$ vertices and minimum degree $\geq \frac{N-1}{2} + 1 =
 \frac{N+1}{2}$. Since $N+1 \geq 3$ (as $n \geq 3$ implies $N \geq 4$), Dirac's
theorem guarantees $G'$ has a Hamiltonian cycle. Removing $v^*$ from this cycle
yields a Hamiltonian path in $G$. $\square$

Therefore, any connected graph with minimum degree $\geq n$ and **no** Hamiltoni
