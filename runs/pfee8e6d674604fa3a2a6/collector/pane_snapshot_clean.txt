Looking at this problem, I need to count integers $n$ with $1 \le n < 10100$ sat
isfying $\lfloor \frac{100n}{101} \rfloor = \lceil \frac{99n}{100} \rceil$.

## Proof

**Setting up the key interval.** Let $k = \lfloor \frac{100n}{101} \rfloor = \lc
eil \frac{99n}{100} \rceil$. The floor condition gives $k \le \frac{100n}{101} <
 k+1$, i.e., $\frac{101k}{100} \le n < \frac{101(k+1)}{100}$. The ceiling condit
ion gives $k-1 < \frac{99n}{100} \le k$, i.e., $\frac{100(k-1)}{99} < n \le \fra
c{100k}{99}$.

**Range of $k$.** For $1 \le n \le 10099$: $\frac{100n}{101} \in [\frac{100}{101
}, 9999.009\ldots]$ so $k \in \{0,\ldots,9999\}$; $\frac{99n}{100} \in [0.99, 99
98.01]$ so $k \ge 1$. Thus $k \in \{1, \ldots, 9999\}$.

**Simplifying the constraints.** I check whether the floor-derived bounds or cei
ling-derived bounds are binding. Compute:
$$\frac{101k}{100} - \frac{100(k-1)}{99} = \frac{10000 - k}{9900} > 0 \quad \tex
t{for } k \le 9999$$
$$\frac{101(k+1)}{100} - \frac{100k}{99} = \frac{9999 - k}{9900} > 0 \quad \text
{for } k \le 9998$$

So for $k = 1, \ldots, 9998$, the binding constraint is $n \in \left[\frac{101k}
{100},\, \frac{100k}{99}\right]$ (both inclusive). For $k = 9999$, the upper bou
nds coincide at $10100$, and the strict inequality $n < \frac{101(k+1)}{100} = 1
0100$ combines with $n \le 10099$ (from the problem) to give $n \le 10099$.

**Counting integers per $k$.** The number of integers in $\left[\frac{101k}{100}
, \frac{100k}{99}\right]$ is $\lfloor \frac{100k}{99} \rfloor - \lceil \frac{101
k}{100} \rceil + 1$ (when non-negative).

Using $\frac{100k}{99} = k + \frac{k}{99}$ and $\frac{101k}{100} = k + \frac{k}{
100}$:
$$\lfloor \tfrac{100k}{99} \rfloor = k + \lfloor \tfrac{k}{99} \rfloor, \qquad \
lceil \tfrac{101k}{100} \rceil = k + \lceil \tfrac{k}{100} \rceil = k + \lfloor
\tfrac{k-1}{100} \rfloor + 1$$

So the count for each $k$ is:
$$g(k) = \lfloor \tfrac{k}{99} \rfloor - \lfloor \tfrac{k-1}{100} \rfloor$$

Since $\frac{k}{99} - \frac{k-1}{100} = \frac{k+99}{9900} > 0$, we have $g(k) \g
e 0$ for all $k \ge 1$.

**Verification of $g(k)$ on examples.** $g(99) = 1 - 0 = 1$ (interval $[99.99, 1
00]$, integer $100$ ✓). $g(100) = 1 - 0 = 1$ (interval $[101, 101.01]$, integer
$101$ ✓). $g(9900) = 100 - 98 = 2$ (interval $[9999, 10000]$, integers $9999, 10
000$ ✓). $g(9999) = 101 - 99 = 2$ (interval $[10098.99, 10100]$, integers $10099
, 10100$ — but $10100$ is excluded).

**Computing the sum.** The total count is $\sum_{k=1}^{9998} g(k) + 1$ (the $+1$
 is for $k=9999$ where only $n=10099$ survives).

Equivalently, total $= \sum_{k=1}^{9999} g(k) - 1$ since $g(9999)=2$ but only 1
integer counts.

**First sum:** $\sum_{k=1}^{9999} \lfloor k/99 \rfloor$.
- $m=0$: $k=1,\ldots,98$ (98 terms), contribution $0$.
- $m=1,\ldots,100$: 99 terms each, contribution $99 \cdot \sum_{m=1}^{100} m = 9
9 \cdot 5050 = 499950$.
- $m=101$: $k=9999$ (1 term), contribution $101$.
- **Total:** $500051$.

**Second sum:** $\sum_{k=1}^{9999} \lfloor (k-1)/100 \rfloor = \sum_{j=0}^{9998}
 \lfloor j/100 \rfloor$.
- $m=0$: $j=0,\ldots,99$ (100 terms), contribution $0$.
- $m=1,\ldots,98$: 100 terms each, contribution $100 \cdot \sum_{m=1}^{98} m = 1
00 \cdot 4851 = 485100$.
- $m=99$: $j=9900,\ldots,9998$ (99 terms), contribution $99 \cdot 99 = 9801$.
- **Total:** $494901$.

**Final computation:**
$$\sum_{k=1}^{9999} g(k) = 500051 - 494901 = 5150$$
$$\text{Answer} = 5150 - 1 = \boxed{5149}$$
