# Solution

## Restatement

We have the complete graph $K_n$ ($n$ vertices, every pair joined by one edge).
Each edge receives one of $n-1$ colors ("topics"). A vertex is a **Universal Com
municator (UC)** if it is incident to at least one edge of every color. Since a
vertex has degree $n-1$ and there are $n-1$ colors, a UC vertex is incident to *
*exactly one** edge of each color. Let $R(n)$ be the maximum number of UC vertic
es over all colorings. We compute $\sum_{n=3}^{100} R(n)$.

## Key observation

A vertex $v$ is UC $\iff$ the $n-1$ edges incident to $v$ all carry distinct col
ors $\iff$ no two edges incident to $v$ share a color.

## Case 1: $n$ even — $R(n)=n$

When $n$ is even, $K_n$ admits a **1-factorization**: its edge set partitions in
to $n-1$ perfect matchings. Assign a distinct color to each perfect matching. Th
en every vertex is incident to exactly one edge in each matching, hence exactly
one edge of each color. So **every** vertex is UC, giving $R(n)=n$.

This is optimal since there are only $n$ vertices.

## Case 2: $n$ odd — upper bound $R(n)\le n-1$

Suppose for contradiction all $n$ vertices are UC. Then no vertex has two incide
nt edges of the same color, so the coloring is a **proper edge coloring** of $K_
n$ using only $n-1$ colors. But the chromatic index of $K_n$ for odd $n$ is $n$
(each color class is a matching of size $\le \tfrac{n-1}{2}$, so $n-1$ colors co
ver at most $(n-1)\tfrac{n-1}{2}=\tfrac{(n-1)^2}{2}<\tfrac{n(n-1)}{2}=|E(K_n)|$
edges — not enough). Contradiction. Hence $R(n)\le n-1$.

## Case 2: $n$ odd — construction achieving $n-1$

Let the vertices be $\{1,2,\dots,n\}$; we make vertices $1,\dots,n-1$ UC (note $
n-1$ is even).

1. **Edges to vertex $n$:** color every edge $\{i,n\}$ ($i=1,\dots,n-1$) with co
lor $1$.
2. **Edges among $\{1,\dots,n-1\}$:** this is $K_{n-1}$ with $n-1$ even, so it h
as a 1-factorization into $n-2$ perfect matchings. Color these with colors $2,3,
\dots,n-1$ (one color per matching).

Now each UC vertex $i\in\{1,\dots,n-1\}$ has:
- one edge $\{i,n\}$ of color $1$;
- $n-2$ edges into $\{1,\dots,n-1\}\setminus\{i\}$, one per matching, hence one
of each color $2,\dots,n-1$.

So vertex $i$ sees all $n-1$ colors exactly once: it is UC. Vertex $n$ sees only
 color $1$ (repeated $n-1\ge 2$ times), so it is not UC. This gives $n-1$ UC ver
tices, matching the upper bound.

$$\boxed{R(n)=n-1 \text{ for odd } n.}$$

## Summary

$$R(n)=\begin{cases} n & n \text{ even},\\ n-1 & n \text{ odd}.\end{cases}$$

## Computing the sum

$$\sum_{n=3}^{100} R(n)=\sum_{\substack{n=3\\n\text{ even}}}^{100} n \;+\; \sum_
{\substack{n=3\\n\text{ odd}}}^{100}(n-1).$$

Rewrite the second sum: $\sum_{\text{odd }n}(n-1)=\sum_{\text{odd }n}n-\#\{\text
{odd }n\}$. Combining,

$$\sum_{n=3}^{100}R(n)=\sum_{n=3}^{100}n \;-\; \#\{\text{odd } n\in[3,100]\}.$$

- $\displaystyle\sum_{n=3}^{100} n = \frac{100\cdot 101}{2}-1-2 = 5050-3 = 5047.
$
- Odd integers in $[3,100]$: $3,5,\dots,99$, count $= \tfrac{99-3}{2}+1 = 49.$

Therefore

$$\sum_{n=3}^{100} R(n) = 5047 - 49 = \boxed{4998}.$$
