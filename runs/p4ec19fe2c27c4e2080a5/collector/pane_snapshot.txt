## Proof

Consider the function $f:[0,1]\to\mathbb{R}$ defined by
$$f(x)=\begin{cases}1,& x\text{ algebraic},\\ 0,& x\text{ transcendental}.\end{c
ases}$$

**Key fact.** The set $\mathcal{A}$ of algebraic real numbers is countable. Inde
ed, a real number is algebraic iff it is a root of a nonzero polynomial with int
eger coefficients. The set $\mathbb{Z}[t]$ of such polynomials is countable (a c
ountable union, over degrees $n$, of $\mathbb{Z}^{n+1}$, each countable), and ea
ch polynomial of degree $n$ has at most $n$ real roots. A countable union of fin
ite sets is countable, so $\mathcal{A}$ is countable.

Hence $A:=\mathcal{A}\cap[0,1]$ is countable, and therefore has **Lebesgue measu
re zero**: enumerating $A=\{a_1,a_2,\dots\}$ and covering each $a_k$ by an inter
val of length $\varepsilon/2^k$ gives an open cover of total length $\varepsilon
$, for arbitrary $\varepsilon>0$.

**The function is measurable.** For any $c\in\mathbb{R}$, the sublevel set $\{x:
f(x)<c\}$ is one of $\varnothing$, $[0,1]\setminus A$, or $[0,1]$, all of which
are Lebesgue measurable (the middle one is the complement of a null set). So $f$
 is measurable.

**Evaluating the integral.** Since $A$ has measure zero, $f=0$ almost everywhere
 on $[0,1]$. A function that vanishes a.e. has Lebesgue integral zero:
$$\int_0^1 f(x)\,dx = \int_0^1 0\,dx = 0,$$
because changing an integrand on a null set does not change its Lebesgue integra
l.

More explicitly, $f=\mathbf{1}_A$ (the indicator of $A$), and for any measurable
 set $E$,
$$\int_0^1 \mathbf{1}_E\,dx = m(E),$$
the Lebesgue measure of $E$. With $m(A)=0$,
$$\int_0^1 f(x)\,dx = m(A) = 0.$$

$$\boxed{\displaystyle\int_0^1 f(x)\,dx = 0}$$
