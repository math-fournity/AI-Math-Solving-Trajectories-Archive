# Problem

In a remote industrial outpost, an automated shipping system processes packages weighing between 1 and 99 kilograms (inclusive). To streamline operations, the warehouse uses exactly three types of standardized weights: a 1-kg weight, an $a$-kg weight, and a $b$-kg weight, where $a$ and $b$ are integers such that $1 < a < b < 100$.

The facility manager wants to ensure that any package weight in the range $[1, 99]$ can be balanced on a scale using a combination of these three weights. To maximize efficiency, the denominations $a$ and $b$ are selected to minimize the value $N$, where $N$ represents the maximum number of individual weights required to represent any single integer total from 1 to 99.

Calculate the sum of all possible values of $b$ that could belong to a set $\{1, a, b\}$ that achieves this global minimum $N$.
