## Proof

$$u'(x) = \sec x + x\sec x\tan x = \frac{1 + x\tan x}{\cos x} = \frac{\cos x + x

$$\frac{d}{dx}\arctan\!\left(\frac{x}{\cos x}\right) = \frac{u'}{1+u^2} = \frac{
(\cos x + x\sin x)/\cos^2 x}{1 + x^2/\cos^2 x} = \frac{\cos x + x\sin x}{x^2 + \
cos^2 x}.$$

So the integrand is exactly $\dfrac{d}{dx}\arctan\!\left(\dfrac{x}{\cos x}\right

- On $(-\frac{\pi}{2}, \frac{\pi}{2})$: $\Phi(x) = \arctan\!\left(\frac{x}{\cos
x}\right)$, with $\Phi(0)=0$.
- On $(\frac{\pi}{2}, \frac{3\pi}{2})$: $\Phi(x) = \arctan\!\left(\frac{x}{\cos
x}\right) + \pi$ (to maintain continuity, since $\arctan \to -\pi/2$ from the ri

- On $(\frac{3\pi}{2}, \frac{5\pi}{2})$: $\Phi(x) = \arctan\!\left(\frac{x}{\cos

- The pattern continues, alternating $+\pi$ shifts on intervals where $\cos x <
0$.

$$\Phi(x_k) = \frac{\pi}{2} \quad \text{for all } k \geq 0.$$

**Step 4: Show $\Phi(x) \to \pi/2$ as $x \to +\infty$.**

$$\left|\Phi(x) - \frac{\pi}{2}\right| = \left|\int_{x_k}^{x} f(t)\,dt\right| \l

$$\int_{x_k}^{x_{k+1}} |f(t)|\,dt \leq \frac{2\pi}{x_k} \to 0 \quad \text{as } k

Therefore $\Phi(x) \to \dfrac{\pi}{2}$ as $x \to +\infty$.
