## Solution

**Setup.** Let the three internal angles be $\alpha, \beta, \gamma$ (in degrees)
, strictly in arithmetic progression in that order, with $\alpha + \beta + \gamm
a = 180°$. Write the common difference as $d \neq 0$, so
$$\alpha = 60° - d, \quad \beta = 60°, \quad \gamma = 60° + d,$$
with $0 < d < 60°$ (positivity of all angles; strictness gives $d \neq 0$).

**Applying the second AP condition.** The values $\sin(20\alpha), \sin(20\beta),
 \sin(20\gamma)$ form an arithmetic progression in that order, so
$$2\sin(20\beta) = \sin(20\alpha) + \sin(20\gamma).$$

Substituting $\alpha = 60°-d$, $\beta = 60°$, $\gamma = 60°+d$:
$$2\sin(1200°) = \sin(1200° - 20d°) + \sin(1200° + 20d°).$$

Using the sum-to-product identity $\sin(A-B)+\sin(A+B) = 2\sin A\cos B$:
$$2\sin(1200°) = 2\sin(1200°)\cos(20d°).$$

**Evaluating $\sin(1200°)$.** Since $1200° = 3\cdot360° + 120°$, we have $\sin(1
200°) = \sin(120°) = \tfrac{\sqrt{3}}{2} \neq 0$.

Therefore we may divide both sides by $2\sin(1200°)$:
$$\cos(20d°) = 1.$$

**Solving.** $\cos(20d°) = 1$ iff $20d° = 360° \cdot k$ for integer $k$, i.e., $
d = 18k$. The constraint $0 < d < 60°$ restricts $k$ to $\{1, 2, 3\}$, giving
$$d \in \{18°, 36°, 54°\}, \qquad \alpha = 60° - d \in \{42°, 24°, 6°\}.$$

**Verification of each candidate.** For each value, all three angles are positiv

metic progression. The sine condition is satisfied since $\cos(20d°)=1$ forces $
\sin(20\alpha)=\sin(20\beta)=\sin(20\gamma)=\sin(1200°)=\tfrac{\sqrt3}{2}$, whic
h is a (degenerate) arithmetic progression — permitted since the problem require
