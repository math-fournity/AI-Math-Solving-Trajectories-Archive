## Solution

**Setup.** Place $B$ at the origin and $C = (24, 0)$. Traverse $ABCD$ counterclo
ckwise (interior on the left).

**Locating A.** Since $\angle ABC = 150°$ and $BC$ points along angle $0°$, the
direction $B \to A$ is at angle $150°$:
$$A = 18(\cos 150°, \sin 150°) = (-9\sqrt{3},\; 9).$$

**Locating D.** At $C$, the exterior angle is $180° - 150° = 30°$. Turning left
(counterclockwise) from direction $B \to C$ (angle $0°$) by $30°$, the direction
 $C \to D$ is at angle $30°$. With $CD = d$:
$$D = (24 + \tfrac{d\sqrt{3}}{2},\; \tfrac{d}{2}).$$

**Equilateral triangle $\triangle APB$ (outside).** Edge $A \to B$ has direction
 $330°$; the outside is to the right ($240°$). Height $= 9\sqrt{3}$, midpoint of
 $AB = (-\tfrac{9\sqrt{3}}{2}, \tfrac{9}{2})$:
$$P = (-\tfrac{9\sqrt{3}}{2}, \tfrac{9}{2}) + 9\sqrt{3}(\cos 240°, \sin 240°) =
(-9\sqrt{3},\; -9).$$

**Equilateral triangle $\triangle BQC$ (outside).** Edge $B \to C$ points east;
outside is south ($270°$). Height $= 12\sqrt{3}$, midpoint $= (12, 0)$:
$$Q = (12,\; -12\sqrt{3}).$$

**Equilateral triangle $\triangle CRD$ (outside).** Edge $C \to D$ has direction
 $30°$; outside is to the right ($300°$). Height $= \tfrac{d\sqrt{3}}{2}$, midpo
int $= (24 + \tfrac{d\sqrt{3}}{4}, \tfrac{d}{4})$:
$$R = (24 + \tfrac{d\sqrt{3}}{2},\; -\tfrac{d}{2}).$$

**Computing $PQ$:**
$$PQ^2 = (12 + 9\sqrt{3})^2 + (9 - 12\sqrt{3})^2 = (144 + 216\sqrt{3} + 243) + (
81 - 216\sqrt{3} + 432) = 900,$$
$$PQ = 30.$$

**Computing $QR$:**
$$QR^2 = \left(12 + \tfrac{d\sqrt{3}}{2}\right)^2 + \left(12\sqrt{3} - \tfrac{d}
{2}\right)^2 = \left(144 + 12d\sqrt{3} + \tfrac{3d^2}{4}\right) + \left(432 - 12
d\sqrt{3} + \tfrac{d^2}{4}\right) = 576 + d^2,$$
$$QR = \sqrt{576 + d^2}.$$

**Perimeter equation.** The polygon $APQRD$ has sides $AP, PQ, QR, RD, DA$, wher
e $AP = 18$ and $RD = d$:
$$P(APQRD) = 18 + 30 + \sqrt{576 + d^2} + d + DA = 48 + \sqrt{576 + d^2} + d + D
A.$$

The quadrilateral $ABCD$ has sides $AB, BC, CD, DA$:
$$P(ABCD) = 18 + 24 + d + DA = 42 + d + DA.$$

The condition $P(APQRD) = P(ABCD) + 32$ gives:
$$48 + \sqrt{576 + d^2} + d + DA = 42 + d + DA + 32 = 74 + d + DA.$$

Canceling $d + DA$ from both sides:
$$48 + \sqrt{576 + d^2} = 74 \implies \sqrt{576 + d^2} = 26 \implies 576 + d^2 =
 676 \implies d^2 = 100.$$

Since $d = CD > 0$:

$$\boxed{CD = 10}$$
