## Key Observation: Composition + Inverse Creates Implicit Alternation

The critical insight is what happens when role composition and inverse roles int

$$\forall (R \circ S^{-}).C$$

Its semantics: for all $z$, if there exists $y$ such that $(x,y) \in R^{\mathcal
{I}}$ and $(z,y) \in S^{\mathcal{I}}$, then $z \in C^{\mathcal{I}}$.

Formally, this is:

{\mathcal{I}}\big) \Rightarrow z \in C^{\mathcal{I}} \Big]$$

This is **not** equivalent to $\forall z \forall y [\ldots]$ — the existential q

### Proof of PSPACE membership (upper bound)

We show subsumption is decidable in PSPACE using a **tableau-based decision proc
edure**.

**Subsumption to satisfiability.** $C \sqsubseteq D$ iff $C \sqcap \hat{D}$ is u
nsatisfiable, where $\hat{D}$ is the "complement" of $D$ constructed via the sta
ndard $\mathcal{AL}$ subsumption normalization (using atomic negation and the du
ality $\forall R.C / \exists R.\top$).

**Tableau rules.** The tableau algorithm expands a set of constraints:

1. **$\sqcap$-rule:** If $C_1 \sqcap C_2 \in \mathcal{L}(x)$, add $C_1, C_2$ to
$\mathcal{L}(x)$.
2. **$\forall$-rule:** If $\forall R.C \in \mathcal{L}(x)$ and $(x,y) \in R^{\ma
thcal{I}}$, add $C$ to $\mathcal{L}(y)$.
3. **Composition rule:** $\forall (R_1 \circ \cdots \circ R_k).C$ is expanded to
 $\forall R_1.(\forall R_2.(\cdots(\forall R_k.C)\cdots))$.
4. **Inverse rule:** $\forall R^{-}.C$ at $x$ generates constraints on all $R$-p
redecessors of $x$.
5. **$\exists$-rule:** $\exists R.\top \in \mathcal{L}(x)$ generates a fresh $R$
-successor $y$.
6. **Clash rule:** If $A, \neg A \in \mathcal{L}(x)$, the branch is closed.

**Key complexity properties:**

- **Polynomial depth:** The tableau depth is bounded by the maximum nesting dept
h of role restrictions in the input concept, which is $O(n)$ where $n$ is the in
put size. Role compositions of depth $k$ expand to $k$ nested restrictions, so t
he depth remains polynomial.

- **No transitive closure:** Unlike $\mathcal{ALC}_{\text{reg}}$ (which has tran
sitive closure and requires EXPTIME), $\mathcal{AL}(\circ, ^{-})$ only has bound
ed composition. The composition depth is at most the size of the concept descrip
tion, so paths in the tableau are polynomially bounded.

- **Cycle detection via blocking:** Inverse roles create cycles in the tableau (
backward edges). We use **subset blocking**: a node $x$ is blocked if there exis
ts an ancestor $y$ with $\mathcal{L}(x) \subseteq \mathcal{L}(y)$. Since labels
are subsets of the set of sub-concepts (polynomial size), blocking can be checke
d in polynomial time.

- **Depth-first exploration:** The tableau is explored depth-first with backtrac
king. At any point, only the current path (polynomial length) and the labels of
nodes on the path (polynomial size each) need to be stored. The total space is $
O(n^2)$ where $n$ is the input size.

- **Label size:** Each node's label is a subset of the sub-concepts of the input
, which has $O(n)$ elements. Composition expansion adds intermediate concepts, b
ut the total number of sub-concepts remains polynomial.

Therefore, the tableau algorithm decides satisfiability (and hence subsumption)
in **PSPACE**.
