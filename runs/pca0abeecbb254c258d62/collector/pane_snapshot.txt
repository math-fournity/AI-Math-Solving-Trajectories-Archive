## Proof

The statement is **false** in general. We provide an explicit counterexample wit
h $n = 2$.

### Counterexample

Let $\xi_1, \xi_2, \ldots$ be i.i.d. with $\mathbb{P}(\xi_t = 1) = \mathbb{P}(\x
i_t = -1) = \tfrac{1}{2}$, and define
$$D_t = (\xi_t,\, -\xi_t) \in \mathbb{R}^2, \qquad X_t = \sum_{s=1}^t D_s = (S_t
,\, -S_t),$$
where $S_t = \sum_{s=1}^t \xi_s$ is a simple symmetric random walk on $\mathbb{Z
}$.

**Verification of hypotheses:**

1. **Martingale:** $\mathbb{E}[D_t] = (\mathbb{E}[\xi_t],\, -\mathbb{E}[\xi_t])
= (0, 0) = \vec{0}$. ✓

2. **Bounded support:** $D_t \in \{(-1,1),\,(1,-1)\}$, a finite (hence bounded)
set. ✓

3. **Positive variance per coordinate:** $\operatorname{Var}(D_{t,1}) = \operato
rname{Var}(\xi_t) = 1 > 0$ and $\operatorname{Var}(D_{t,2}) = \operatorname{Var}
(-\xi_t) = 1 > 0$. ✓

### The event has probability zero

For any $k < 0$, the event in question is:
$$\exists\, t \geq 1 \text{ such that } X_{t,1} \leq k \text{ and } X_{t,2} \leq
 k.$$

Since $X_{t,1} = S_t$ and $X_{t,2} = -S_t$, this becomes:
$$\exists\, t \geq 1 \text{ such that } S_t \leq k \text{ and } -S_t \leq k,$$
i.e., $S_t \leq k$ and $S_t \geq -k$.

Since $k < 0$, we have $-k > 0 > k$, so the two conditions require simultaneousl
y $S_t \leq k < 0$ and $S_t \geq -k > 0$. **No real number satisfies both $S_t \
leq k$ and $S_t \geq -k$ when $k < 0$** (as this would require $-k \leq S_t \leq
 k$, but $-k > k$).

Therefore the event is empty:
$$\mathbb{P}\!\left[\exists\, t : X_{t,i} \leq k \text{ for all } i\right] = \ma
thbb{P}[\emptyset] = 0 \neq 1.$$

### Conclusion

The claim fails whenever the increments have a component structure that forces t
he coordinates to be perfectly negatively correlated (so that the walk is confin
ed to a subspace that does not intersect the lower orthant). In the example abov
e, the walk lives on the anti-diagonal $\{(a, -a) : a \in \mathbb{Z}\}$, which i
s disjoint from $(-\infty, k]^2$ for every $k < 0$.

Hence the answer is **no**: it is not true in general that $\mathbb{P}[\exists\,
 t : X_{t,i} \leq k \text{ for all } i] = 1$ for all $k < 0$.
