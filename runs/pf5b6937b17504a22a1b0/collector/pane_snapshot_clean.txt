Let
$$I = \int_{-\pi/2}^{\pi/2} \frac{x^{2}\cos(x)}{1+\exp(x^{2}\sin(x))}\,dx.$$

**Step 1: Symmetry reduction.**

Define $f(x) = \dfrac{x^{2}\cos(x)}{1+\exp(x^{2}\sin(x))}$. Under the substituti
on $x \to -x$:
- $x^2 \mapsto x^2$ (even),
- $\cos x \mapsto \cos x$ (even),
- $\sin x \mapsto -\sin x$ (odd),

so
$$f(-x) = \frac{x^{2}\cos(x)}{1+\exp(-x^{2}\sin(x))}.$$

Using the identity (valid for all real $u$)
$$\frac{1}{1+e^{u}} + \frac{1}{1+e^{-u}} = \frac{1}{1+e^{u}} + \frac{e^{u}}{1+e^
{u}} = 1,$$

with $u = x^{2}\sin(x)$, we get
$$f(x) + f(-x) = x^{2}\cos(x)\left[\frac{1}{1+e^{x^{2}\sin x}} + \frac{1}{1+e^{-
x^{2}\sin x}}\right] = x^{2}\cos(x).$$

Therefore
$$I = \frac{1}{2}\int_{-\pi/2}^{\pi/2}\bigl[f(x)+f(-x)\bigr]\,dx = \frac{1}{2}\i
nt_{-\pi/2}^{\pi/2} x^{2}\cos(x)\,dx.$$

**Step 2: Evaluate $\displaystyle\int_{-\pi/2}^{\pi/2} x^{2}\cos(x)\,dx$.**

Since $x^{2}\cos(x)$ is even,
$$\int_{-\pi/2}^{\pi/2} x^{2}\cos(x)\,dx = 2\int_{0}^{\pi/2} x^{2}\cos(x)\,dx.$$

Integrating by parts twice:
$$\int x^{2}\cos(x)\,dx = x^{2}\sin(x) + 2x\cos(x) - 2\sin(x) + C.$$

Evaluating from $0$ to $\pi/2$:
- At $x = \pi/2$: $\;\dfrac{\pi^{2}}{4}\cdot 1 + 2\cdot\dfrac{\pi}{2}\cdot 0 - 2
\cdot 1 = \dfrac{\pi^{2}}{4} - 2.$
- At $x = 0$: $\;0 + 0 - 0 = 0.$

Hence
$$\int_{0}^{\pi/2} x^{2}\cos(x)\,dx = \frac{\pi^{2}}{4} - 2, \qquad \int_{-\pi/2
}^{\pi/2} x^{2}\cos(x)\,dx = 2\!\left(\frac{\pi^{2}}{4} - 2\right) = \frac{\pi^{
2}}{2} - 4.$$

**Step 3: Conclude.**

$$I = \frac{1}{2}\!\left(\frac{\pi^{2}}{2} - 4\right) = \frac{\pi^{2}}{4} - 2 =
\frac{\pi^{2} - 8}{4}.$$

This matches the form $\dfrac{\pi^{a}-b}{c}$ with $a = 2$, $b = 8$, $c = 4$.

$$a + b + c = 2 + 8 + 4 = \boxed{14}.$$
