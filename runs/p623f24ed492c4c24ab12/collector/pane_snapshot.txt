**Theorem.** There exists a subset of the real numbers that does not have the Ba
ire property.

**Proof.**

Recall that a set $A \subseteq \mathbb{R}$ has the *Baire property* if there exi
sts an open set $U \subseteq \mathbb{R}$ such that the symmetric difference $A \
triangle U$ is meager (i.e., of first category). We show by a cardinality argume
nt that not every subset of $\mathbb{R}$ can have the Baire property.

**Step 1: Counting the open sets.** Every open subset of $\mathbb{R}$ is a union
 of basic open intervals with rational endpoints. Since there are only $\aleph_0
$ such basic intervals, the number of open sets is at most $2^{\aleph_0}$ (and i
n fact equal to $2^{\aleph_0}$, though the upper bound suffices).

**Step 2: Counting the meager sets.** A meager set is a countable union of nowhe
re dense sets. The total number of subsets of $\mathbb{R}$ is $2^{\aleph_0}$, so
 there are at most $2^{\aleph_0}$ nowhere dense sets. A meager set is specified
by a countable sequence of nowhere dense sets, so the number of meager sets is a
t most
$$
(2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0 \cdot \aleph_0} = 2^{\aleph_0}.
$$

**Step 3: Counting the sets with the Baire property.** If $A$ has the Baire prop
erty, then $A = U \triangle M$ for some open set $U$ and some meager set $M$ (ta
ke $M = A \triangle U$). Thus each set with the Baire property is determined by
a pair $(U, M)$ with $U$ open and $M$ meager. The number of such pairs is at mos
t
$$
2^{\aleph_0} \cdot 2^{\aleph_0} = 2^{\aleph_0}.
$$
Hence there are at most $2^{\aleph_0}$ subsets of $\mathbb{R}$ with the Baire pr
operty.

**Step 4: Comparison with all subsets.** The total number of subsets of $\mathbb
{R}$ is
$$
|\mathcal{P}(\mathbb{R})| = 2^{|\mathbb{R}|} = 2^{2^{\aleph_0}}.
$$
By Cantor's theorem, $2^{2^{\aleph_0}} > 2^{\aleph_0}$. Therefore the number of
subsets of $\mathbb{R}$ strictly exceeds the number of subsets with the Baire pr
operty, so there must exist subsets of $\mathbb{R}$ that do **not** have the Bai
re property. $\blacksquare$

**Remark.** The argument uses only ZF set theory (Cantor's theorem is provable i
n ZF). The existence of such a set is therefore unconditional in ZFC. Note, howe
ver, that this is a pure existence argument; no explicit example can be construc
ted, and indeed it is consistent with ZF + Dependent Choice + "every set of real
s has the Baire property" (the Solovay model / Shelah's result) that *every* sub
set of $\mathbb{R}$ has the Baire property. Thus the existence of a subset witho
ut the Baire property is inherently non-constructive and relies on the full Axio
m of Choice.
