## Theorem 9.14

Let $\{(X_i, d_i)\}_{i \in \omega_0}$ be a countable collection of metric spaces
. Then $\prod_{i \in \omega_0} X_i$ is metrizable.

## Proof

We construct an explicit metric on $X = \prod_{i \in \omega_0} X_i$ that induces
 the product topology.

**Step 1: Normalize each metric.** For each $i$, define
$$\bar{d}_i(x, y) = \min\{d_i(x, y), 1\}.$$
Then $\bar{d}_i$ is a metric on $X_i$ equivalent to $d_i$ (it induces the same t
opology), and $\bar{d}_i \le 1$.

*Verification that $\bar{d}_i$ is a metric:* Symmetry and the identity-of-indisc
ernibles property are immediate. For the triangle inequality, we use the fact th
at for $a, b \ge 0$,
$$\min\{a+b, 1\} \le \min\{a,1\} + \min\{b,1\}.$$
Indeed, if $a + b \le 1$ then $\min\{a+b,1\} = a+b \le \min\{a,1\}+\min\{b,1\}$;
 if $a+b > 1$ then $\min\{a+b,1\}=1 \le \min\{a,1\}+\min\{b,1\}$ (since at least
 one of $a, b$ must exceed... actually we need $1 \le \min\{a,1\}+\min\{b,1\}$;
since $a+b>1$, at least one of $a,b$ is $>0$, but more carefully: if both $a<1$
and $b<1$ then $\min\{a,1\}+\min\{b,1\}=a+b>1$; if $a\ge 1$ then $\min\{a,1\}=1$
 so the sum $\ge 1$; similarly for $b\ge 1$). Thus
$$\bar{d}_i(x,z) = \min\{d_i(x,z),1\} \le \min\{d_i(x,y)+d_i(y,z),1\} \le \min\{
d_i(x,y),1\}+\min\{d_i(y,z),1\} = \bar{d}_i(x,y)+\bar{d}_i(y,z).$$

**Step 2: Define the product metric.** For $x = (x_i)_{i \in \omega_0}$ and $y =
 (y_i)_{i \in \omega_0}$ in $X$, set
$$D(x, y) = \sum_{i=0}^{\infty} \frac{1}{2^i} \bar{d}_i(x_i, y_i).$$

This series converges since $0 \le \bar{d}_i \le 1$ gives $D(x,y) \le \sum_{i=0}
^{\infty} 2^{-i} = 2$.

**Step 3: $D$ is a metric.**
- *Non-negativity and identity:* $D(x,y) \ge 0$ as a sum of non-negative terms.
$D(x,y) = 0$ iff every term $\bar{d}_i(x_i,y_i) = 0$, iff $x_i = y_i$ for all $i
$, iff $x = y$.
- *Symmetry:* $D(x,y) = D(y,x)$ since each $\bar{d}_i$ is symmetric.
- *Triangle inequality:* For $x, y, z \in X$,
$$D(x,z) = \sum_{i=0}^{\infty} 2^{-i}\bar{d}_i(x_i,z_i) \le \sum_{i=0}^{\infty}
2^{-i}\bigl(\bar{d}_i(x_i,y_i)+\bar{d}_i(y_i,z_i)\bigr) = D(x,y)+D(y,z).$$

varepsilon}{2} \le \frac{\varepsilon}{2}\cdot 2 + \frac{\varepsilon}{2} = \frac{
3\varepsilon}{2}.$$
