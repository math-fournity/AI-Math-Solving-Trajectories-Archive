## Proof

**Claim:** Yes. The Riemann–Lebesgue Lemma implies that
$$\int_{m}^{k} f(x)\,e^{-inx}\,dx \;\longrightarrow\; 0 \quad\text{as } n\to\inf
ty$$
for every continuous real-valued function $f$ and every $m\le k$.

---

### The Riemann–Lebesgue Lemma (general form)

> If $g\in L^{1}([a,b])$ for finite real $a,b$, then
> $$\int_{a}^{b} g(x)\,e^{-i\xi x}\,dx \;\longrightarrow\; 0 \quad\text{as } |\x
i|\to\infty,\ \xi\in\mathbb{R}.$$

In particular, taking $\xi = n\in\mathbb{Z}$ with $n\to\infty$ gives the conclus
ion for integer frequencies.

---

### Verification of the hypothesis

Let $f:[m,k]\to\mathbb{R}$ be continuous with $m\le k$.

- **Case $m=k$:** The interval is a single point, so $\int_{m}^{k} f(x)e^{-inx}\
,dx = 0$ for every $n$; the limit is trivially $0$.

- **Case $m<k$:** The interval $[m,k]$ is compact. A continuous function on a co
mpact set is bounded (Extreme Value Theorem), so there exists $M$ with $|f(x)|\l
e M$ for all $x\in[m,k]$. Hence
$$\int_{m}^{k}|f(x)|\,dx \le M(k-m) < \infty,$$
so $f\in L^{1}([m,k])$.

---

### Applying the lemma

Since $f\in L^{1}([m,k])$, the Riemann–Lebesgue Lemma (with $g=f$, $a=m$, $b=k$,
 $\xi=n$) yields directly
$$\int_{m}^{k} f(x)\,e^{-inx}\,dx \;\longrightarrow\; 0 \quad\text{as } n\to\inf
ty.$$

No additional hypothesis on $f$ (such as differentiability, periodicity, or vani
shing at endpoints) is required: $L^{1}$-integrability alone suffices, and conti
nuity on a compact interval guarantees $L^{1}$-integrability.

---

### Conclusion

The Riemann–Lebesgue Lemma **does** imply the stated convergence, because every
continuous real-valued function on a closed bounded interval $[m,k]$ is bounded
and therefore belongs to $L^{1}([m,k])$, which is exactly the class of functions
 to which the lemma applies.
