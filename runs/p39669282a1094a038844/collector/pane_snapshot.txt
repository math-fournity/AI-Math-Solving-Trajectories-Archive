## Solution

**Answer:** $\sup_n f_n(x)$ is integrable on $[0,1]$ if and only if $p < 2$.

### Proof

Let $g(x) = \sup_{n \geq 1} f_n(x) = (1-x)\sup_{n\geq 1} n^p x^n$.

**Endpoints.** $g(0) = g(1) = 0$, so only $x \in (0,1)$ matters.

**Case $p \leq 0$.** Both $n^p$ (nonincreasing) and $x^n$ (strictly decreasing)
are nonincreasing in $n$, so $n^p x^n$ is nonincreasing. Hence $\sup_n n^p x^n =
 1^p \cdot x = x$, giving $g(x) = x(1-x)$, which is integrable. ✓

**Case $p > 0$.** Consider $h(n) = n^p x^n$ as a function of continuous $n > 0$.
 Then
$$\frac{d}{dn}\ln h(n) = \frac{p}{n} + \ln x, \qquad \frac{d^2}{dn^2}\ln h(n) =
-\frac{p}{n^2} < 0,$$
so $h$ is log-concave (unimodal) with a unique maximum at
$$n^* = \frac{p}{\ln(1/x)} \quad (\text{since } \ln x < 0).$$
The continuous maximum value is
$$h(n^*) = \left(\frac{p}{\ln(1/x)}\right)^p x^{p/\ln(1/x)} = \left(\frac{p}{\ln
(1/x)}\right)^p e^{-p},$$
using $x^{p/\ln(1/x)} = e^{(p/\ln(1/x))\ln x} = e^{-p}$.

Since $h$ is smooth and log-concave, the discrete supremum $\sup_{n\in\mathbb{N}
} h(n)$ is comparable to the continuous maximum within a constant factor (depend
ing only on $p$, not on $x$). Concretely, evaluating at $n_0 = \lfloor n^* \rflo
or$ or $\lceil n^* \rceil$ and using log-concavity, the ratio $\sup_{n\in\mathbb
{N}} h(n)/h(n^*)$ is bounded above and below by positive constants. Therefore
$$g(x) \asymp (1-x)\, e^{-p}\left(\frac{p}{\ln(1/x)}\right)^p \asymp (1-x)\left(
\frac{1}{\ln(1/x)}\right)^p,$$
where $\asymp$ denotes comparability up to $x$-independent constants. Hence $g$
is integrable iff
$$I_p := \int_0^1 (1-x)\left(\frac{1}{\ln(1/x)}\right)^p dx < \infty.$$

**Behavior near $x = 0$.** As $x \to 0^+$, $\ln(1/x) \to \infty$, so $(1/\ln(1/x
))^p \to 0$; the integrand is bounded by $1$ and vanishes. No singularity.

**Behavior near $x = 1$ (the only possible singularity).** Substitute $x = e^{-t
}$, $dx = -e^{-t}\,dt$, so $t = \ln(1/x) \to 0^+$ as $x \to 1^-$. Then $1 - x =
1 - e^{-t} \sim t$ and $e^{-t} \to 1$, giving
$$I_p \sim \int_0^{\varepsilon} \frac{t}{t^p}\,dt = \int_0^{\varepsilon} t^{1-p}
\,dt.$$
This integral converges if and only if $1 - p > -1$, i.e., $\boxed{p < 2}$.

**Boundary check.** At $p = 2$, the integrand behaves like $t^{-1}$ near $t = 0$
, giving a logarithmic divergence, so $p = 2$ is excluded.

### Conclusion

Combining both cases, $\sup_n f_n(x)$ is (Lebesgue) integrable on $[0,1]$ if and
 only if $p < 2$.
