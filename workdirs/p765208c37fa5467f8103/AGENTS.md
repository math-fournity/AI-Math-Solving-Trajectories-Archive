# Problem

In a specialized logistics network, an $n \times n$ grid of servers is established, where $n = 2025$. Each server is assigned a non-zero power output value. The network architecture is governed by a strict "Balance Constraint": the power output of any individual server must be exactly $k$ times smaller than the total combined power of all other servers located in the same row and the same column as that server.

Specifically, for a server at position $(i, j)$, its power value is compared to the sum of the power values of the $2n-2$ other servers residing in row $i$ and column $j$. If $k$ is the fixed ratio such that $(Sum\ of\ the\ other\ 2n-2\ servers) = k \times (Value\ of\ the\ current\ server)$ for every single server in the grid, determine all possible real values that $k$ can take.

Let $K(n)$ be defined as the sum of all such possible values of $k$ for a fixed grid size $n$. Compute the value of $K(2025)$.
