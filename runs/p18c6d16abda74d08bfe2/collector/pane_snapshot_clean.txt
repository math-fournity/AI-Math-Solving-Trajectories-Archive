## Solution

We need the smallest positive integer $x$ such that $11^{2021} \mid 5^{3x} - 3^{
4x}$.

**Rewrite.** Note $5^{3x} = (5^3)^x = 125^x$ and $3^{4x} = (3^4)^x = 81^x$. So w
e need
$$11^{2021} \mid 125^x - 81^x, \quad\text{i.e.,}\quad v_{11}(125^x - 81^x) \geq
2021.$$

**Check divisibility by 11.** Compute modulo 11:
- $125 = 11\cdot 11 + 4$, so $125 \equiv 4 \pmod{11}$.
- $81 = 7\cdot 11 + 4$, so $81 \equiv 4 \pmod{11}$.

Thus $11 \mid 125 - 81 = 44 = 4\cdot 11$, giving $v_{11}(125-81)=1$. Also $11\nm
id 125$ and $11\nmid 81$.

**Apply LTE (Lifting the Exponent).** For an odd prime $p$ with $p\mid a-b$ and
$p\nmid ab$, the LTE lemma gives
$$v_p(a^n - b^n) = v_p(a-b) + v_p(n).$$

With $a=125,\ b=81,\ p=11,\ n=x$, all conditions are satisfied ($11$ is odd, $11
\mid 125-81$, $11\nmid 125\cdot 81$). Therefore
$$v_{11}(125^x - 81^x) = v_{11}(125-81) + v_{11}(x) = 1 + v_{11}(x).$$

**Solve the inequality.** We need
$$1 + v_{11}(x) \geq 2021 \implies v_{11}(x) \geq 2020.$$

The smallest positive integer with $v_{11}(x)\geq 2020$ is $x = 11^{2020}$.

**Verification.** For $x = 11^{2020}$: $v_{11}(125^x - 81^x) = 1 + 2020 = 2021 \
geq 2021$. ✓

For any $x < 11^{2020}$: since $x = 11^{v_{11}(x)}\cdot m$ with $11\nmid m$, we
have $x \geq 11^{v_{11}(x)}$. If $v_{11}(x) \leq 2019$, then $v_{11}(125^x-81^x)
 = 1 + v_{11}(x) \leq 2020 < 2021$, so the divisibility fails. Hence no smaller
$x$ works.

**Answer:** The smallest positive integer $x$ is $\boxed{11^{2020}}$.
