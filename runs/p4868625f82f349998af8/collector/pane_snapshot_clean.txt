## Solution

We evaluate $I = \int_0^\infty \frac{\sin^4 x}{x^2}\,dx$.

**Step 1: Integration by parts.** Set $u = \sin^4 x$ and $dv = x^{-2}\,dx$, so t
hat $du = 4\sin^3 x \cos x\,dx$ and $v = -1/x$. Then

$$I = \left[-\frac{\sin^4 x}{x}\right]_0^\infty + \int_0^\infty \frac{4\sin^3 x
\cos x}{x}\,dx.$$

The boundary term vanishes: as $x\to\infty$, $|\sin^4 x / x| \le 1/x \to 0$; as
$x\to 0$, $\sin^4 x / x \sim x^3 \to 0$. Hence

$$I = \int_0^\infty \frac{4\sin^3 x \cos x}{x}\,dx.$$

**Step 2: Trigonometric simplification.** Using $2\sin x\cos x = \sin 2x$ and $2
\sin^2 x = 1-\cos 2x$,

$$4\sin^3 x\cos x = 2\sin^2 x\cdot(2\sin x\cos x) = (1-\cos 2x)\sin 2x = \sin 2x
 - \cos 2x\sin 2x.$$

Since $\cos 2x\sin 2x = \tfrac{1}{2}\sin 4x$,

$$4\sin^3 x\cos x = \sin 2x - \tfrac{1}{2}\sin 4x.$$

Therefore

$$I = \int_0^\infty \frac{\sin 2x - \tfrac{1}{2}\sin 4x}{x}\,dx = \int_0^\infty
\frac{\sin 2x}{x}\,dx - \frac{1}{2}\int_0^\infty \frac{\sin 4x}{x}\,dx.$$

**Step 3: Dirichlet integral.** The classical result $\int_0^\infty \frac{\sin(a
x)}{x}\,dx = \frac{\pi}{2}$ for $a>0$ gives

$$\int_0^\infty \frac{\sin 2x}{x}\,dx = \frac{\pi}{2}, \qquad \int_0^\infty \fra
c{\sin 4x}{x}\,dx = \frac{\pi}{2}.$$

**Step 4: Conclusion.**

$$I = \frac{\pi}{2} - \frac{1}{2}\cdot\frac{\pi}{2} = \frac{\pi}{2} - \frac{\pi}
{4} = \frac{\pi}{4}.$$

**Sanity check.** Since $0\le\sin^4 x\le\sin^2 x$, we have $I\le\int_0^\infty\fr
ac{\sin^2 x}{x^2}\,dx=\frac{\pi}{2}$, and $\frac{\pi}{4}<\frac{\pi}{2}$ is consi
stent.

$$\boxed{\int_0^\infty \frac{\sin^4 x}{x^2}\,dx = \frac{\pi}{4}}$$
