## Solution

**Formula.** Let the number have $n$ digits, with digit $d$ appearing $c_d$ time
s ($\sum c_d = n$), and digit sum $S = \sum d\cdot c_d$. The number of distinct
permutations is $\frac{n!}{\prod c_d!}$. By symmetry, each digit $d$ occupies ea
ch position exactly $\frac{c_d}{n}$ of the time, so the sum of all distinct perm
utations is

$$\text{Sum} = \frac{n!}{\prod c_d!}\cdot\frac{S}{n}\cdot R_n = \frac{(n-1)!\cdo
t S\cdot R_n}{\prod c_d!}$$

where $R_n = \underbrace{11\ldots1}_{n}$. (Check with the example: $110$ has $n=
3, S=2, \prod c_d!=2!$, giving $\frac{2\cdot2\cdot111}{2}=222$. ✓)

**Factoring the target.** $4933284 = 2^2\cdot 3\cdot 37\cdot 41\cdot 271$.

Since $R_n\mid 4933284$ and $R_n\le 4933284$, we test $n\le 7$:
- $R_1=1$: would require a single digit $=4933284$ — impossible.
- $R_2=11$: $11\nmid 4933284$.
- $R_3=111=3\cdot37$: $4933284/111=44444$, requiring $\frac{2\,S}{\prod c_d!}=44
444$, i.e. $S=22222\prod c_d!$, but $S\le 27$ — impossible.
- $R_4=1111=11\cdot101$: $1111\nmid 4933284$.
- $R_5=11111=41\cdot271$: $4933284/11111=444$, requiring $\frac{24\,S}{\prod c_d
!}=444$, i.e. $S=\frac{37\,\prod c_d!}{2}$.
- $R_6=111111=3\cdot7\cdot11\cdot13\cdot37$: has factor $7$ — not a divisor.
- $R_7=239\cdot4649$: not a divisor.

So **$n=5$** is the only possibility, with $S=\frac{37\,\prod c_d!}{2}$.

**Finding the digits.** Since $S\le 45$ (max digit sum of 5 digits), we need $\p
rod c_d!\le 2$, so $\prod c_d!=2$: exactly one digit appears twice and three dig
its appear once (4 distinct values), giving $S=37$.

Enumerating 5-element multisets (one value doubled) from $\{0,\ldots,9\}$ with s
um $37$:
- $\{4,7,8,9,9\}$, sum $37$ ✓
- $\{5,6,8,9,9\}$, sum $37$ ✓
- $\{5,7,8,8,9\}$, sum $37$ ✓
- $\{6,7,7,8,9\}$, sum $37$ ✓

(These are all: the four distinct values sum to at most $30$, forcing the double
d value $\ge 7$; a direct check yields exactly these four.)

**Smallest number.** The smallest arrangement (nonzero leading digit) of each:
- $\{4,7,8,9,9\}\to 47899$
- $\{5,6,8,9,9\}\to 56899$
- $\{5,7,8,8,9\}\to 57889$
- $\{6,7,7,8,9\}\to 67789$

The smallest is **47899**.

**Verification.** For $47899$: $n=5$, $S=4+7+8+9+9=37$, $\prod c_d!=2!$, $(n-1)!
=24$.
$$\text{Sum}=\frac{24\cdot37\cdot11111}{2}=12\cdot37\cdot11111=444\cdot11111=493
3284.\ \checkmark$$

The smallest number is $\boxed{47899}$.
