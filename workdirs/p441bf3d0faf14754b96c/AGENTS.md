# Problem

A high-security data facility uses an $n \times n$ grid of memory nodes. A configuration of active nodes is labeled "Stable" if every single row and every single column in the grid contains at least two active nodes.

A configuration is defined as "Critical" if it is Stable, but the deactivation of any single active node within the configuration immediately makes the grid unstable. For a grid of size $n$, let $m(n)$ represent the maximum possible number of active nodes that can exist in a Critical configuration.

The facility administrators are analyzing the efficiency of these configurations for grid sizes $n=5, 6, 7, 8, 9,$ and $10$. Calculate the value of the following sum:
$$m(5) + m(6) + m(7) + m(8) + m(9) + m(10)$$
