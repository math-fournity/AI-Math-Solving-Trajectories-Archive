## Solution

We count positive integers less than 1,000,000 (i.e., from 1 to 999,999) whose d
igit sum equals 49.

**Representation.** Every integer from 0 to 999,999 can be written as a 6-digit
string with leading zeros: $d_1d_2d_3d_4d_5d_6$, where $0 \le d_i \le 9$. The di
git sum is $d_1+d_2+d_3+d_4+d_5+d_6$. The integer 0 corresponds to $000000$ (dig
it sum 0), so it is automatically excluded from our count since $0 \ne 49$. Thus
 we need the number of solutions to:

$$d_1 + d_2 + d_3 + d_4 + d_5 + d_6 = 49, \quad 0 \le d_i \le 9.$$

**Inclusion–Exclusion.** Without the upper bounds, the number of non-negative so
lutions is $\binom{49+5}{5} = \binom{54}{5}$. Let $A_i$ be the set of solutions
with $d_i \ge 10$. By inclusion–exclusion:

$$N = \sum_{k=0}^{4} (-1)^k \binom{6}{k} \binom{49 - 10k + 5}{5}$$

where $k=5$ gives sum $49-50 = -1 < 0$, so it contributes 0.

Computing each term:
- $\binom{54}{5} = 3{,}162{,}510$
- $\binom{6}{1}\binom{44}{5} = 6 \times 1{,}086{,}008 = 6{,}516{,}048$
- $\binom{6}{2}\binom{34}{5} = 15 \times 278{,}256 = 4{,}173{,}840$
- $\binom{6}{3}\binom{24}{5} = 20 \times 42{,}504 = 850{,}080$
- $\binom{6}{4}\binom{14}{5} = 15 \times 2{,}002 = 30{,}030$

$$N = 3{,}162{,}510 - 6{,}516{,}048 + 4{,}173{,}840 - 850{,}080 + 30{,}030 = 252
.$$

**Verification by symmetry.** The maximum digit sum of a 6-digit string is $54$
(from $999999$). The map $d_i \mapsto 9 - d_i$ is a bijection on 6-digit strings
 sending digit sum $S$ to digit sum $54 - S$. Therefore the count for sum $49$ e
quals the count for sum $54 - 49 = 5$. For sum $5 < 10$, no upper bound is activ
e, so the count is simply $\binom{5+5}{5} = \binom{10}{5} = 252$. This confirms
the result.

$$\boxed{252}$$
