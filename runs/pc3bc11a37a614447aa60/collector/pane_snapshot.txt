## Proof

We work throughout with a fixed nonprincipal ultrafilter $\mathcal{D}$ on $\omeg
a$. We recall the key properties used: (i) $\mathcal{D}$ is closed under finite
intersections and supersets, $\omega\in\mathcal{D}$, $\emptyset\notin\mathcal{D}
$; (ii) for every $A\subseteq\omega$, exactly one of $A$, $\omega\setminus A$ li
es in $\mathcal{D}$; (iii) since $\mathcal{D}$ is nonprincipal, every cofinite s
et belongs to $\mathcal{D}$ and no finite set does.

---

### (a) Every bounded sequence has a unique D-limit

**Existence.** Let $x_n\in[a,b]$ for all $n$. For $t\in\mathbb{R}$ set $A_t=\{n:
x_n\le t\}$. Since $A_b=\omega\in\mathcal{D}$, the set $\{t:A_t\in\mathcal{D}\}$
 is nonempty and bounded below by $a$; let
$$L=\inf\{t:A_t\in\mathcal{D}\}.$$
We claim $\lim_{\mathcal{D}}x_n=L$.

Take $p<L<q$. Since $L<q$, there is $t$ with $L\le t<q$ and $A_t\in\mathcal{D}$;
 then $\{n:x_n<q\}\supseteq A_t\in\mathcal{D}$. Since $p<L=\inf\{t:A_t\in\mathca
l{D}\}$, we have $A_p\notin\mathcal{D}$, so by the ultrafilter property $\{n:x_n
>p\}=\omega\setminus A_p\in\mathcal{D}$. Hence
$$\{n:p<x_n<q\}=\{n:x_n>p\}\cap\{n:x_n<q\}\in\mathcal{D}.$$

**Uniqueness.** Suppose $r<s$ both satisfy the defining condition. Choose $q$ wi
th $r<q<s$. Applying the condition for $r$ with $p'<r<q$ gives $\{n:x_n<q\}\in\m
athcal{D}$. Applying the condition for $s$ with $q<s<q'$ gives $\{n:x_n>q\}\in\m
athcal{D}$. Their intersection is $\emptyset\in\mathcal{D}$, contradiction. $\sq
uare$

---

### (b) The D-limit of a convergent sequence coincides with its ordinary limit

If $x_n\to r$ and $p<r<q$, then $\{n:p<x_n<q\}$ is cofinite, hence in $\mathcal{
D}$ (nonprincipal ultrafilters contain every cofinite set). Thus $\lim_{\mathcal
{D}}x_n=r$. $\square$

---

### (c) $\lim_{\mathcal{D}} cx_n = c\lim_{\mathcal{D}}x_n$

Let $r=\lim_{\mathcal{D}}x_n$. If $c=0$, both sides are $0$. If $c>0$ and $p<cr<
q$, then $p/c<r<q/c$, so $\{n:p/c<x_n<q/c\}=\{n:p<cx_n<q\}\in\mathcal{D}$. If $c
<0$ and $p<cr<q$, then $q/c<r<p/c$ (inequalities reverse), so $\{n:q/c<x_n<p/c\}
=\{n:p<cx_n<q\}\in\mathcal{D}$. $\square$

---

### (d) $\lim_{\mathcal{D}}(x_n+y_n)=\lim_{\mathcal{D}}x_n+\lim_{\mathcal{D}}y_n
$

Let $a=\lim_{\mathcal{D}}x_n$, $b=\lim_{\mathcal{D}}y_n$. Given $p<a+b<q$, pick
$\delta>0$ with $2\delta<\min(a+b-p,\;q-a-b)$. Then
$$\{n:a-\delta<x_n<a+\delta\}\in\mathcal{D},\qquad \{n:b-\delta<y_n<b+\delta\}\i
n\mathcal{D}.$$
Their intersection $I\in\mathcal{D}$, and for $n\in I$,
$$a+b-2\delta < x_n+y_n < a+b+2\delta,$$
so $p<x_n+y_n<q$. Hence $\{n:p<x_n+y_n<q\}\supseteq I\in\mathcal{D}$. $\square$

---

### (e) $|\lim_{\mathcal{D}}x_n|\le\sup_n|x_n|$

Let $M=\sup_n|x_n|$ (assume the sequence is bounded, so the D-limit exists by (a
)) and let $r=\lim_{\mathcal{D}}x_n$. If $r>M$, choose $p,q$ with $M<p<r<q$; the
n $\{n:p<x_n<q\}\in\mathcal{D}$, yet $x_n\le M<p$ for all $n$, so this set is em
pty—contradiction. If $r<-M$, choose $p,q$ with $p<r<q<-M$; then $\{n:p<x_n<q\}\
in\mathcal{D}$, yet $x_n\ge -M>q$, so the set is empty—contradiction. Hence $|r|
\le M$. $\square$

---

### (f) If $x_n-y_n\to 0$, then $\lim_{\mathcal{D}}x_n=\lim_{\mathcal{D}}y_n$

Assume both sequences are bounded (so both D-limits exist). Let $a=\lim_{\mathca
l{D}}x_n$. Given $p<a<q$, set $\epsilon=\tfrac12\min(a-p,q-a)>0$. Since $x_n-y_n
\to0$, the set $C=\{n:|x_n-y_n|<\epsilon\}$ is cofinite, hence $C\in\mathcal{D}$
. Also $B=\{n:p<x_n<q\}\in\mathcal{D}$. For $n\in B\cap C\in\mathcal{D}$,
$$p<x_n<x_n+\epsilon<q\quad\text{and}\quad x_n-\epsilon<y_n<x_n+\epsilon,$$
so $p<y_n<q$. Thus $\{n:p<y_n<q\}\supseteq B\cap C\in\mathcal{D}$, giving $\lim_
{\mathcal{D}}y_n=a$. $\square$

---

### (g) Continuity: $\lim_{\mathcal{D}}f(x_n)=f(a)$

Let $\lim_{\mathcal{D}}x_n=a$ and let $f$ be continuous at $a$. Given $p<f(a)<q$
, by continuity there is $\delta>0$ such that $|x-a|<\delta\Rightarrow p<f(x)<q$
. Since $a-\delta<a<a+\delta$, the set $\{n:a-\delta<x_n<a+\delta\}\in\mathcal{D
}$, and it is contained in $\{n:p<f(x_n)<q\}$. Hence $\{n:p<f(x_n)<q\}\in\mathca
l{D}$. $\square$

---

### (h) Realizing a limit point via some nonprincipal ultrafilter

Suppose $r$ is a limit point of $\{x_n:n<\omega\}$: for every $\epsilon>0$ and e
very $N<\omega$ there exists $n>N$ with $|x_n-r|<\epsilon$. Equivalently, for ev
ery $p<r<q$ the set
$$A_{p,q}=\{n:p<x_n<q\}$$
is infinite.

Consider the family $\mathcal{F}_0=\{A_{p,q}:p,q\in\mathbb{Q},\;p<r<q\}\cup\{\te
xt{cofinite subsets of }\omega\}$. This has the **finite intersection property**
: a finite intersection of $A_{p,q}$'s is $A_{p_{\max},q_{\min}}$ with $p_{\max}
<r<q_{\min}$, which is infinite; and every $A_{p,q}$ is infinite, so it meets ev
ery cofinite set. Hence $\mathcal{F}_0$ generates a proper filter, which by the
Ultrafilter Lemma extends to an ultrafilter $\mathcal{D}$. Since $\mathcal{D}$ c
ontains all cofinite sets, it is nonprincipal. Since $\mathcal{D}\supseteq\{A_{p
,q}:p<r<q\}$, we have $\lim_{\mathcal{D}}x_n=r$. $\square$

---

### (i) Every real sequence has a (possibly infinite) D-limit

Fix a nonprincipal ultrafilter $\mathcal{D}$ and a sequence $\{x_n\}$.

**Case 1:** $\{n:x_n>p\}\in\mathcal{D}$ for every $p\in\mathbb{R}$. Then by defi
nition $\lim_{\mathcal{D}}x_n=+\infty$.

**Case 2:** $\{n:x_n<p\}\in\mathcal{D}$ for every $p\in\mathbb{R}$. Then $\lim_{
\mathcal{D}}x_n=-\infty$.

**Case 3 (neither).** There exists $p^*$ with $\{n:x_n>p^*\}\notin\mathcal{D}$,
i.e. $A_{p^*}:=\{n:x_n\le p^*\}\in\mathcal{D}$; and there exists $p_*$ with $\{n
:x_n<p_*\}\notin\mathcal{D}$, i.e. $\{n:x_n\ge p_*\}\in\mathcal{D}$. Their inter
section $B=\{n:p_*\le x_n\le p^*\}\in\mathcal{D}$, so the sequence is "bounded o
n a $\mathcal{D}$-large set."

Set $L=\inf\{t:\{n:x_n\le t\}\in\mathcal{D}\}$. This infimum is taken over a non
empty set (it contains $p^*$) that is bounded below (by $p_*$), so $L\in\mathbb{
R}$. The same argument as in part (a) — using that $\{n:x_n\le t\}\in\mathcal{D}
$ for some $t<q$ whenever $L<q$, and that $\{n:x_n\le p\}\notin\mathcal{D}$ (hen
ce $\{n:x_n>p\}\in\mathcal{D}$) whenever $p<L$ — shows that for all $p<L<q$,
$$\{n:p<x_n<q\}=\{n:x_n>p\}\cap\{n:x_n<q\}\in\mathcal{D}.$$
Hence $\lim_{\mathcal{D}}x_n=L\in\mathbb{R}$.

These three cases are exhaustive: if Case 1 fails there is some $p^*$ with $\{n:
x_n\le p^*\}\in\mathcal{D}$, and if Case 2 fails there is some $p_*$ with $\{n:x
_n\ge p_*\}\in\mathcal{D}$, putting us in Case 3. $\square$

---

All parts (a)–(i) are established.
