## Proof

Let $P \subseteq [a,b]$ be a perfect set of Lebesgue measure zero. We show $P$ i
s nowhere dense.

Recall that a set $E$ is **nowhere dense** if $\operatorname{int}(\overline{E})
= \emptyset$. Since $P$ is perfect, it is closed, so $\overline{P} = P$. Thus it
 suffices to show $\operatorname{int}(P) = \emptyset$.

Suppose for contradiction that $\operatorname{int}(P) \neq \emptyset$. Then ther
e exists a point $x \in P$ and an open interval $(c, d)$ with $c < d$ such that
$$x \in (c, d) \subseteq P.$$

The interval $(c, d)$ has Lebesgue measure $m((c,d)) = d - c > 0$. By monotonici
ty of measure, since $(c,d) \subseteq P$,
$$0 < d - c = m((c,d)) \le m(P) = 0,$$
a contradiction.

Therefore $\operatorname{int}(P) = \emptyset$. Since $P$ is closed, $\overline{P
} = P$, and so
$$\operatorname{int}(\overline{P}) = \operatorname{int}(P) = \emptyset.$$

Hence $P$ is nowhere dense. $\blacksquare$
