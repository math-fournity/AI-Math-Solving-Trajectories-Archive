### Step 1: Reduction to corner analysis (lower bound)

For any functions $f_k$, let $a_k = f_k(0)$, $b_k = f_k(1)$, $A = \sum a_k$, $c_

= 1\}$:

$$e(S) = \prod \epsilon_k - A - \sum_{k \in S} c_k = \delta_{S,[n]} - A - \sum_{
k \in S} c_k.$$

Since $\sup_{[0,1]^n} |e| \geq \max_{\text{corners}} |e|$, we need: **the best a
ffine approximation of the AND function** $g(\epsilon) = \prod \epsilon_k$ **on*
* $\{0,1\}^n$ **by** $h(\epsilon) = A + \sum c_k \epsilon_k$.

**By symmetry** (AND is permutation-invariant; averaging any optimal $h$ over al
l permutations gives a symmetric optimal $h = A + b|\epsilon|$), WLOG $c_k = b$
for all $k$. The error at level $j = |\epsilon|$ is:
- $j < n$: $e_j = -A - bj$ (target 0)
- $j = n$: $e_n = 1 - A - bn$ (target 1)

**Optimal Chebyshev solution:** Set $e_0 = E$, $e_{n-1} = -E$, $e_n = E$ (equios
cillation at 3 points for 2 parameters). Solving:
- $-A = E \Rightarrow A = -E$
- $-A - b(n-1) = -E \Rightarrow b(n-1) = 2E$
- $1 - A - bn = E \Rightarrow bn = 1 - 2E$

From the last two: $b = \frac{1-2E}{n}$ and $b = \frac{2E}{n-1}$, giving $E = \f
rac{n-1}{2n}$, $b = \frac{1}{n}$, $A = -\frac{n-1}{2n}$.

**Intermediate levels** $j = 1, \ldots, n-2$: $e_j = \frac{n-1-2j}{2n}$, linear
from $E$ to $-E$, so $|e_j| \leq E$. ✓

**Optimality proof:** Suppose some $A', b'$ achieves $\max_j |e'_j| < E$. Then $
d_j = e_j - e'_j = (A-A') + (b-b')j$ is linear in $j$, with $d_0 = E - e'_0 > 0$
, $d_{n-1} = -E - e'_{n-1} < 0$, $d_n = E - e'_n > 0$. A linear function cannot
change sign twice. **Contradiction.** ✓

Therefore $C_n \geq \frac{n-1}{2n}$.

### Step 2: Upper bound via explicit construction

Choose $f_k(x_k) = \frac{x_k}{n} - \frac{n-1}{2n^2}$, so $\sum f_k(x_k) = \frac{

$$e(x) = \prod x_k - \frac{\sum x_k}{n} + \frac{n-1}{2n}.$$

**Upper bound** $e(x) \leq \frac{n-1}{2n}$: Equivalent to $\prod x_k \leq \frac{
\sum x_k}{n}$. By AM-GM, $\prod x_k \leq \left(\frac{\sum x_k}{n}\right)^n \leq
\frac{\sum x_k}{n}$ since $\frac{\sum x_k}{n} \in [0,1]$ and $t^n \leq t$ for $t
 \in [0,1]$. ✓

**Lower bound** $e(x) \geq -\frac{n-1}{2n}$: Equivalent to $\prod x_k \geq \frac
{\sum x_k - (n-1)}{n}$.

If $\sum x_k \leq n-1$: RHS $\leq 0 \leq \prod x_k$. ✓

If $\sum x_k > n-1$: Set $y_k = 1 - x_k \in [0,1]$, so $\sum y_k < 1$. Need $n\p
rod(1-y_k) + \sum y_k \geq 1$.

**Lemma:** For $y_k \in [0,1]$, $g_n = n\prod_{k=1}^n(1-y_k) + \sum_{k=1}^n y_k
\geq 1$.

*Proof by strong induction on $n$.*

**Base** $n=1$: $g_1 = (1-y_1) + y_1 = 1$. ✓

**Inductive step:** $g_n$ attains its minimum on $[0,1]^n$ (compact). The minimu
m is interior or on the boundary.

*Interior critical point:* $\partial g_n/\partial y_k = -n\prod_{j \neq k}(1-y_j
) + 1 = 0$ gives $\prod_{j \neq k}(1-y_j) = 1/n$ for all $k$. By symmetry, all $
y_k = y$ with $(1-y)^{n-1} = 1/n$, i.e., $y = 1 - n^{-1/(n-1)}$.

$$g_n = n \cdot n^{-n/(n-1)} + n\left(1 - n^{-1/(n-1)}\right) = n^{-1/(n-1)} + n
 - n \cdot n^{-1/(n-1)} = n - (n-1)\,n^{-1/(n-1)}.$$

Since $n^{-1/(n-1)} \leq 1$, we get $g_n \geq n - (n-1) = 1$. (Strictly $> 1$ fo
r $n \geq 2$.) ✓

*Boundary $y_k = 1$ (some $k$):* $\prod(1-y_j) = 0$, so $g_n = \sum y_j \geq 1$.
 ✓

*Boundary $y_k = 0$ (some $k$, WLOG $y_n = 0$):* $g_n = n\prod_{j<n}(1-y_j) + \s
um_{j<n} y_j$. By induction, $g_{n-1} = (n-1)\prod_{j<n}(1-y_j) + \sum_{j<n} y_j
 \geq 1$. Since $g_n - g_{n-1} = \prod_{j<n}(1-y_j) \geq 0$, we get $g_n \geq g_
{n-1} \geq 1$. ✓

This completes the induction. $\square$

Therefore $|e(x)| \leq \frac{n-1}{2n}$ on $[0,1]^n$, with equality at corners (e
.g., $x = \mathbf{0}$ and $x = \mathbf{1}$). Combined with the lower bound:

$$\boxed{C_n = \frac{n-1}{2n}}$$

### Step 3: Compute the sum

$$2n \cdot C_n = 2n \cdot \frac{n-1}{2n} = n - 1.$$

$$\sum_{n=1}^{10} 2n \cdot C_n = \sum_{n=1}^{10}(n-1) = 0 + 1 + 2 + \cdots + 9 =
