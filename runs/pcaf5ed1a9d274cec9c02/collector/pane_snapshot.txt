## Proof

**Claim:** The smallest cardinal κ such that κ^{<κ} = κ is provable in ZFC witho
ut large cardinal assumptions is κ = ℵ₀.

---

### Step 1: ℵ₀^{<ℵ₀} = ℵ₀ (provable in ZFC)

By definition, κ^{<κ} = sup{κ^λ : λ < κ, λ a cardinal}.

For κ = ℵ₀, the cardinals below ℵ₀ are exactly the finite cardinals n ∈ ω. Thus:

ℵ₀^{<ℵ₀} = sup{ℵ₀^n : n < ω}

- For n = 0: ℵ₀^0 = 1.
- For every n ≥ 1: ℵ₀^n = ℵ₀, since a finite Cartesian product of countable sets
 is countable (a theorem of ZFC).

Therefore:

ℵ₀^{<ℵ₀} = sup{1, ℵ₀, ℵ₀, ℵ₀, …} = ℵ₀.

No continuum hypothesis, no large cardinal axiom, no additional assumption is in
voked. This is a pure ZFC theorem.

---

### Step 2: ℵ₀ is the smallest infinite cardinal

By definition, ℵ₀ is the smallest infinite cardinal. Since ℵ₀ satisfies the equa
tion (Step 1) and no smaller infinite cardinal exists, ℵ₀ is the smallest **infi
nite** cardinal with κ^{<κ} = κ.

---

### Step 3: ZFC cannot prove κ^{<κ} = κ for any uncountable κ

Let κ be any uncountable cardinal. Since ℵ₀ < κ, we have:

κ^{ℵ₀} ≤ κ^{<κ}.

Also, since 2 ≤ κ (as κ is uncountable), we have 2^{ℵ₀} ≤ κ^{ℵ₀}. Therefore:

2^{ℵ₀} ≤ κ^{ℵ₀} ≤ κ^{<κ}.

So if κ^{<κ} = κ, then 2^{ℵ₀} ≤ κ.

**But for any fixed uncountable κ, ZFC cannot prove 2^{ℵ₀} ≤ κ.** By Cohen's for
cing theorem (1963), the continuum 2^{ℵ₀} can be made arbitrarily large — for an
y cardinal μ with cofinality > ℵ₀, there is a forcing extension preserving ZFC i
n which 2^{ℵ₀} = μ. In particular, for any fixed uncountable κ, there exists a m
odel of ZFC in which 2^{ℵ₀} > κ. In such a model:

κ^{<κ} ≥ 2^{ℵ₀} > κ,

so κ^{<κ} ≠ κ.

This applies to **every** uncountable κ — regular or singular — since the argume
nt only uses ℵ₀ < κ and 2 ≤ κ, both of which hold for all uncountable cardinals.
 Hence ZFC alone cannot prove κ^{<κ} = κ for any uncountable κ.

---

### Step 4: Finite cardinals (completeness)

For finite cardinals n:
- 0^{<0} = sup ∅ = 0 ✓ (degenerate)
- 1^{<1} = 1^0 = 1 ✓ (degenerate)
- 2^{<2} = sup{2^0, 2^1} = sup{1, 2} = 2 ✓
- For n ≥ 3: n^{<n} = sup{n^m : m < n} = n^{n-1} > n ✗

So 0, 1, 2 satisfy the equation trivially, but these are degenerate finite cases
 with no set-theoretic content. The question, framed in the context of "models o
f ZFC without large cardinal assumptions," concerns infinite cardinals.

---

### Conclusion

- ℵ₀^{<ℵ₀} = ℵ₀ is a theorem of ZFC (Step 1).
- No uncountable κ has κ^{<κ} = κ provable in ZFC alone (Step 3), because Cohen
forcing produces models where 2^{ℵ₀} > κ, forcing κ^{<κ} > κ.
- ℵ₀ is the smallest infinite cardinal (Step 2).

**The smallest cardinal κ such that κ^{<κ} = κ in ZFC without large cardinal ass
umptions is κ = ℵ₀.**
