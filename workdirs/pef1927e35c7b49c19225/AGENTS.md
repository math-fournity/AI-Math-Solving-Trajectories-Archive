# Problem

A specialized laboratory is testing various "stability levels" for experimental chemical compounds. Each stability level is identified by a positive integer $n$. For a given $n$, the possible molecular energy states achievable by that compound form a set $S_n$, defined as all values that can be expressed in the form $x^2 + ny^2$, where $x$ and $y$ are any integers.

A stability level $n$ is classified as "pioneering" if its set $S_n$ contains at least one energy state that cannot be achieved by any stability level $k$ that is strictly smaller than $n$ (where $1 \le k < n$).

Let $A$ be the set of all such pioneering stability levels. Calculate the sum of all elements in $A$ that are less than or equal to 30.
