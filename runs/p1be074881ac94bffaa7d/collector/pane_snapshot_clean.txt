## Proof

**Step 1: $g$ is constant.**

The entire function $g$ omits every value in some open set $U \subseteq \mathbb{
C}$. Since $U$ is open and nonempty, it contains at least two distinct complex v
alues. By the **Little Picard Theorem**—which states that any entire function om
itting two or more values must be constant—$g$ is constant.

**Step 2: $h$ is constant.**

We are given $g = k \circ h$ where $k$ is one-to-one (injective). Since $g$ is c
onstant, say $g(z) = c$ for all $z \in \mathbb{C}$, we have
$$k(h(z)) = c \quad \text{for all } z \in \mathbb{C}.$$
By injectivity of $k$, there is at most one value $w$ in the domain of $k$ satis
fying $k(w) = c$. Since $k(h(z)) = c$ is attained for every $z$, it follows that
 $h(z) = w$ for all $z \in \mathbb{C}$. Thus $h$ is constant.

**Step 3: A constant entire function is bounded.**

Since $h(z) = w$ for all $z$, we have $|h(z)| = |w|$ for all $z$, so $h$ is boun
ded (by $|w|$).

**Conclusion.** The hypothesis that $g$ omits an open set is extremely strong: b
y Picard's theorem it forces $g$ to be constant, which combined with the injecti
vity of $k$ forces $h$ to be constant, and hence bounded. The additional hypothe
sis that $k$ maps the omitted open set into the unit disk is not needed for the
conclusion.
