## Solution

We compute
$$L = \lim_{n\to\infty}\int_{-n}^{n}\Bigl(\cos\frac{x}{n}\Bigr)^{n^{2}}\,dx.$$

### 1. Reduction to a pointwise limit on $\mathbb{R}$

For $|x|\le n$ we have $|x/n|\le 1<\pi/2$, hence $\cos(x/n)\in[\cos 1,1]\subset(
0,1]$, so the integrand is non‑negative and well defined. Extend it to all of $\
mathbb{R}$ by
$$f_n(x)=\Bigl(\cos\frac{x}{n}\Bigr)^{n^{2}}\mathbf 1_{[-n,n]}(x).$$
Then $\int_{-n}^{n}(\cos(x/n))^{n^{2}}dx=\int_{\mathbb R}f_n(x)\,dx$.

For each **fixed** $x\in\mathbb R$, eventually $|x|\le n$, and using $\log\cos t
=-t^{2}/2+O(t^{4})$ as $t\to0$ with $t=x/n$,
$$n^{2}\log\cos\frac{x}{n}=n^{2}\Bigl(-\frac{x^{2}}{2n^{2}}+O\Bigl(\frac{x^{4}}{
n^{4}}\Bigr)\Bigr)\xrightarrow[n\to\infty]{}-\frac{x^{2}}{2}.$$
Therefore
$$f_n(x)\xrightarrow[n\to\infty]{}e^{-x^{2}/2}\qquad\text{pointwise on }\mathbb
R.$$

### 2. An integrable dominating function (using the given inequality)

The hint gives, for $0\le r\le 1$ and $k\in\mathbb N$,
$$r^{k}\le \exp\bigl(-k(1-r)\bigr).$$
Apply it with $r=\cos(x/n)\in[0,1]$ (valid since $|x/n|\le1<\pi/2$) and $k=n^{2}
$:
$$\Bigl(\cos\frac{x}{n}\Bigr)^{n^{2}}\le \exp\Bigl(-n^{2}\bigl(1-\cos\tfrac{x}{n
}\bigr)\Bigr).$$

Use $1-\cos\theta=2\sin^{2}(\theta/2)$ and the concavity bound $\sin u\ge \frac{
2}{\pi}u$ for $u\in[0,\pi/2]$. For $|x|\le n$ we have $|x|/(2n)\le \tfrac12\le \
pi/2$, so
$$1-\cos\frac{x}{n}=2\sin^{2}\frac{x}{2n}\ge 2\Bigl(\frac{2}{\pi}\cdot\frac{|x|}
{2n}\Bigr)^{2}=\frac{2x^{2}}{\pi^{2}n^{2}}.$$
Hence
$$f_n(x)\le \exp\Bigl(-\frac{2x^{2}}{\pi^{2}}\Bigr),\qquad x\in\mathbb R.$$
The function $g(x)=\exp(-2x^{2}/\pi^{2})$ is integrable on $\mathbb R$ (Gaussian
). Thus $\{f_n\}$ is dominated by an $L^{1}$ function.

### 3. Apply dominated convergence

By the dominated convergence theorem,
$$L=\lim_{n\to\infty}\int_{\mathbb R}f_n(x)\,dx=\int_{\mathbb R}\lim_{n\to\infty
}f_n(x)\,dx=\int_{-\infty}^{\infty}e^{-x^{2}/2}\,dx.$$

The Gaussian integral evaluates to $\sqrt{2\pi}$ (e.g. via the standard squared‑
integral computation $\bigl(\int e^{-x^{2}/2}dx\bigr)^{2}=\int\int e^{-(x^{2}+y^
{2})/2}dxdy=2\pi$).

### 4. Conclusion

$$\boxed{\displaystyle\lim_{n\to\infty}\int_{-n}^{n}\Bigl(\cos\frac{x}{n}\Bigr)^
{n^{2}}dx=\sqrt{2\pi}.}$$
