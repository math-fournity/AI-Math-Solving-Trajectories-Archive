## Key Lemma

**Lemma.** For all real $a, t$: $|\cos a| + |\cos(a+t)| \le \sqrt{2} + |\cos t|$
.

*Proof.* Since $|\cos|$ has period $\pi$, assume $t \in [0,\pi]$. For fixed $t$,
 the maximum of $h(a)=|\cos a|+|\cos(a+t)|$ over $a$ is found at critical points
. In a region where both cosines share sign, $h'(a)=0$ gives $a=-t/2$ with value
 $2\cos(t/2)$; where signs differ, $h'(a)=0$ gives $a=(\pi-t)/2$ with value $2\s
in(t/2)$. Hence
$$\max_a h(a) = 2\max\!\big(\cos\tfrac{t}{2},\,\sin\tfrac{t}{2}\big).$$

- **$t \in [0,\pi/2]$:** $\max = 2\cos(t/2)$. With $c=\cos(t/2)\in[\frac{\sqrt2}
{2},1]$, we need $2c \le \sqrt2 + \cos t = \sqrt2 + 2c^2 - 1$, i.e. $2c^2-2c+\sq
rt2-1 \ge 0$. This quadratic factors with roots $c = \frac{\sqrt2}{2}$ and $c =
1-\frac{\sqrt2}{2}$, so it is $\ge 0$ for $c \ge \frac{\sqrt2}{2}$. ✓ (equality
at $t=\pi/2$).

- **$t \in [\pi/2,\pi]$:** $\max = 2\sin(t/2)$. With $s=\sin(t/2)\in[\frac{\sqrt
2}{2},1]$, we need $2s \le \sqrt2 + |\cos t| = \sqrt2 - 1 + 2s^2$, the same quad
ratic $2s^2-2s+\sqrt2-1\ge 0$, which holds for $s\ge\frac{\sqrt2}{2}$. ✓ (equali
ty at $t=\pi/2$).

The lemma follows, with equality iff $|\cos t|=0$, i.e. $t\equiv \pi/2 \pmod{\pi
}$. $\square$

## Upper Bound

$$2\big(|\cos(a_0+2jt)| + |\cos(a_0+(2j+1)t)|\big) \le 2\sqrt2 + 2|\cos t|.$$

$$2\sum_{k=0}^{2013}|\cos(a_0+kt)| \le 1007(2\sqrt2 + 2|\cos t|) = 2014\sqrt2 +

## Equality

$$|1+x|+|1-x| = |1+i|+|1-i| = \sqrt2+\sqrt2 = 2\sqrt2,$$

$$E = 1007\cdot 2\sqrt2 = 2014\sqrt2,$$
