# Problem

In a remote mountain village, three different master weavers—each represented by a unique non-zero single-digit code $(a, b, c)$—decided to collaborate on a series of experimental tapestries. One of these weavers uses the signature code 3. 

To create their patterns, they formed all six possible three-digit thread counts using their three unique codes as digits. They then organized these six thread counts into three distinct pairs. Upon comparing the tapestries in each pair, they noted the following discrepancies in thread density:
1. The difference between the thread counts in the first pair was a single-digit number.
2. The difference between the thread counts in the second pair was a two-digit number.
3. The difference between the thread counts in the third pair was a three-digit number that was exactly divisible by 5.

Identify every possible set of three digits $\{a, b, c\}$ that satisfies these observations. Let $S$ be the collection of all such valid sets. Calculate the sum of the products of the three digits within each set in $S$.
