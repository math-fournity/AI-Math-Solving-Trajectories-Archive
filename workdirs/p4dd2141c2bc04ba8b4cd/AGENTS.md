# Problem

In a remote digital archipelago, a grid-based sensor network is deployed across two separate regions: Sector Alpha, a $5 \times 5$ square grid of signal towers, and Sector Beta, a $6 \times 6$ square grid of signal towers. Each tower in these grids broadcasts a specific integer frequency.

A rectangular cluster of towers within a grid is classified as an "Isolated Domain" if there exists a threshold integer $h$ such that two conditions are met:
(i) Every tower located inside the rectangular cluster broadcasts a frequency strictly greater than $h$.
(ii) Every tower located outside the rectangular cluster that is adjacent to it (sharing a side or a corner) broadcasts a frequency less than or equal to $h$.

Let $S(m, n)$ represent the maximum possible number of distinct Isolated Domains that can exist simultaneously in an $m \times n$ grid, given an optimal assignment of frequencies to each tower.

Calculate the value of $S(5, 5) + S(6, 6)$.
