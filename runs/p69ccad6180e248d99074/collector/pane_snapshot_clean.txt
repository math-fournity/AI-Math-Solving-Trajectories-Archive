 or whether a module can satisfy it without being finitely generated.

**Answer: Yes.**

**Proof.**

Consider $\mathfrak{g} = \mathfrak{sl}_2$ with standard generators $e, f, h$ and
 simple root $\alpha$. For each integer $n \geq 0$, let $M(-n\alpha)$ denote the
 Verma module with highest weight $-n\alpha$. Define:

$$M = \bigoplus_{n=0}^{\infty} M(-n\alpha).$$

**$M$ is a weight module.** Each Verma module $M(-n\alpha)$ is a weight module,
and a direct sum of weight modules is a weight module. ✓

**The weights of $M$ lie in finitely many cones.** The weights of $M(-n\alpha)$
are $\{-n\alpha,\, -(n{+}1)\alpha,\, -(n{+}2)\alpha,\, \dots\}$. Taking the unio
n over all $n \geq 0$, the weights of $M$ are $\{-m\alpha : m \geq 0\} = \{0, -\
alpha, -2\alpha, \dots\}$, which all lie in the **single** cone $0 - \mathbb{Q}_
+$ where $\mathbb{Q}_+ = \mathbb{N}\alpha$ is the positive root cone. So the wei
ghts lie in one cone (hence finitely many). ✓

**$M$ has finite-dimensional weight spaces.** The weight space $M_{-m\alpha} = \
bigoplus_{n=0}^{m} M(-n\alpha)_{-m\alpha}$. Each $M(-n\alpha)_{-m\alpha}$ is 1-d
imensional (spanned by $f^{m-n}v_n$ where $v_n$ is the highest weight vector of
$M(-n\alpha)$, and $M(-n\alpha)_{-m\alpha} = 0$ for $n > m$). So $\dim M_{-m\alp
ha} = m+1 < \infty$. ✓

**$M$ is locally $\mathfrak{n}$-finite.** For $\mathfrak{sl}_2$, $\mathfrak{n} =
 \mathbb{C}e$. For any $v \in M_{-m\alpha}$, the element $e$ raises the weight b
y $\alpha$ each time it is applied. Since the highest weight in $M$ is $0$, we h
ave $e^k v = 0$ for all $k > m$. Thus the $\mathfrak{n}$-submodule generated by
$v$ is contained in $\bigoplus_{j=0}^{m} M_{-j\alpha}$, which is finite-dimensio
nal. ✓

**$M$ is not finitely generated.** Each element of $M$ is a finite sum, so it ha
s nonzero components in only finitely many summands $M(-n\alpha)$. Suppose $v_1,
 \dots, v_k$ generate $M$ as a $U(\mathfrak{g})$-module. Then there exists $N$ s
uch that every $v_i$ lies in $\bigoplus_{n=0}^{N} M(-n\alpha)$. Since $U(\mathfr
ak{g})$ acts componentwise on a direct sum, the submodule generated by $v_1, \do
ts, v_k$ is contained in $\bigoplus_{n=0}^{N} M(-n\alpha)$. But this is a proper
 submodule of $M$ — it does not contain the highest weight vector of $M(-(N{+}1)
\alpha)$. This is a contradiction, so $M$ is **not** finitely generated. ✓

**Conclusion.** The module $M = \bigoplus_{n \geq 0} M(-n\alpha)$ is a $\mathfra
k{g}$-module that is a weight module with finite-dimensional weight spaces, is l
ocally $\mathfrak{n}$-finite, and has all weights lying in a single cone — yet i
