Looking at this problem, I need to find the minimal size of a subset $S_n \subse

ine the asymptotic growth rate.

## Proof

**Reformulation.** The condition $(S_n + k) \cap S_n \neq \emptyset$ for every $
k \in \mathbf{Z}_n$ means: for every $k$, there exist $a, b \in S_n$ with $a + k
 \equiv b \pmod{n}$, i.e., $k \equiv b - a \pmod{n}$. Thus the condition is equi
valent to $S_n - S_n = \mathbf{Z}_n$, where $S_n - S_n = \{a - b \pmod{n} : a, b
 \in S_n\}$. So $f(n)$ is the minimal size of a **difference basis** for $\mathb
f{Z}_n$.

---

### Lower Bound

Let $|S| = m$. The difference set $S - S$ arises from $m^2$ ordered pairs $(a,b)
$. The pair $(a,a)$ always gives $0$, contributing $m$ pairs to a single value.
Each nonzero residue arises from at least one of the remaining $m^2 - m$ pairs.
Therefore:

$$|S - S| \leq 1 + (m^2 - m) = m^2 - m + 1.$$

Since $S - S = \mathbf{Z}_n$ requires $|S - S| = n$, we need $m^2 - m + 1 \geq n
$, giving:

$$f(n) \geq \frac{1 + \sqrt{4n - 3}}{2} = \sqrt{n} + O(1).$$

Hence $\ln f(n) \geq \frac{1}{2}\ln n + O(1)$, so $\frac{\ln f(n)}{\ln n} \geq \
frac{1}{2} + o(1)$.

### Upper Bound (Construction)

Let $m = \left\lceil \frac{1 + \sqrt{2n-1}}{2} \right\rceil$, so that $2m^2 - 2m
 + 1 \geq n$ and $m^2 - m \geq \frac{n-1}{2}$. For sufficiently large $n$, we al
so have $m^2 - m < n$ (since $m \approx \sqrt{n/2} < \sqrt{n}$).

Define:
$$A = \{0, 1, \ldots, m-1\}, \qquad B = \{0, m, 2m, \ldots, (m-1)m\}, \qquad S =
 A \cup B \pmod{n}.$$

**Distinctness.** Since $m \leq n$ and $(m-1)m = m^2 - m < n$, all elements of $
A$ and $B$ are distinct mod $n$. If $j \in A$ and $im \in B$ coincide mod $n$, t
hen $j = im$ as integers (both in $[0, n-1]$), forcing $m \mid j$ with $0 \leq j
 \leq m-1$, so $j = 0$. Thus $A \cap B = \{0\}$ and $|S| = 2m - 1$.

**Coverage.** Consider $B - A = \{bm - a : 0 \leq a \leq m-1,\; 0 \leq b \leq m-
1\}$ as integers. For fixed $b$, this gives the interval $\{bm - (m-1), \ldots,
bm\}$. As $b$ ranges over $0, 1, \ldots, m-1$, these intervals are:
- $b=0$: $\{-(m-1), \ldots, 0\}$
- $b=1$: $\{1, \ldots, m\}$
- $b=2$: $\{m+1, \ldots, 2m\}$
- $\vdots$
- $b=m-1$: $\{m^2-2m+1, \ldots, m^2-m\}$

These are contiguous and non-overlapping (each starts where the previous ends pl
us 1), so their union is $\{-(m-1), \ldots, m^2-m\}$, a block of $m^2$ consecuti
ve integers.

By symmetry, $A - B$ covers $\{-(m^2-m), \ldots, m-1\}$. Together:

$$S - S \supseteq \{-(m^2-m), \ldots, m^2-m\} \pmod{n},$$

which is $2(m^2 - m) + 1 = 2m^2 - 2m + 1 \geq n$ consecutive integers. Any set o
f $n$ or more consecutive integers covers every residue class mod $n$. Therefore
 $S - S = \mathbf{Z}_n$, and:

$$f(n) \leq 2m - 1 \leq 2\left\lceil \frac{1+\sqrt{2n-1}}{2}\right\rceil - 1 \le
q \sqrt{2n} + 2.$$

Hence $\ln f(n) \leq \frac{1}{2}\ln n + \frac{1}{2}\ln 2 + o(1)$, so $\frac{\ln
f(n)}{\ln n} \leq \frac{1}{2} + o(1)$.

---

### Conclusion

Combining both bounds:

$$\sqrt{n} + O(1) \;\leq\; f(n) \;\leq\; \sqrt{2n} + 2,$$

which gives $\ln f(n) = \frac{1}{2}\ln n + O(1)$, and therefore:

$$\lim_{n \to \infty} \frac{\ln f(n)}{\ln n} = \frac{1}{2}.$$
