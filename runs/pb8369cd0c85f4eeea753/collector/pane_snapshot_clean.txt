## Solution

### Setup

The unperturbed problem (ε = 0) is the standard Sturm–Liouville problem
$$\phi_0'' + \lambda \phi_0 = 0,\quad \phi_0(0)=\phi_0(L)=0,$$
with eigenvalues $\lambda_n^{(0)} = (n\pi/L)^2$ and eigenfunctions $\sin(n\pi x/
L)$.

We seek the perturbation of the **first** eigenvalue $\lambda_1^{(0)} = (\pi/L)^
2$.

### Perturbation expansion

Write
$$\phi = \phi_0 + \varepsilon \phi_1 + \cdots,\qquad \lambda_1 = \lambda_1^{(0)}
 + \varepsilon \lambda_1^{(1)} + \cdots.$$

Substituting into $\phi'' + \lambda\phi = \varepsilon\phi^3$ and collecting orde
rs:

**O(1):**
$$\phi_0'' + \lambda_1^{(0)}\phi_0 = 0,\quad \phi_0(0)=\phi_0(L)=0.$$
Solution: $\phi_0 = A\sin(\pi x/L)$, $\lambda_1^{(0)}=(\pi/L)^2$.

**O(ε):**
$$\phi_1'' + \lambda_1^{(0)}\phi_1 = -\lambda_1^{(1)}\phi_0 + \phi_0^3,\quad \ph
i_1(0)=\phi_1(L)=0.$$

### Solvability (Fredholm) condition

The operator $L = d^2/dx^2 + \lambda_1^{(0)}$ with Dirichlet BCs has a one-dimen
sional null space spanned by $\phi_0$. For a solution to exist, the RHS must be
orthogonal to $\phi_0$:

$$\int_0^L \bigl(-\lambda_1^{(1)}\phi_0 + \phi_0^3\bigr)\phi_0\,dx = 0.$$

Hence
$$\lambda_1^{(1)} = \frac{\displaystyle\int_0^L \phi_0^4\,dx}{\displaystyle\int_
0^L \phi_0^2\,dx}.$$

### Using the amplitude constraint

The problem fixes $\int_0^L \phi^2\,dx = a^2$. At leading order this is $\int_0^
L \phi_0^2\,dx = a^2$, giving
$$A^2\cdot\frac{L}{2} = a^2 \;\Longrightarrow\; A^2 = \frac{2a^2}{L}.$$

Now compute the integrals:
$$\int_0^L \phi_0^4\,dx = A^4\int_0^L \sin^4\!\Bigl(\frac{\pi x}{L}\Bigr)dx = A^
4\cdot\frac{3L}{8},$$
$$\int_0^L \phi_0^2\,dx = A^2\cdot\frac{L}{2} = a^2.$$

Therefore
$$\lambda_1^{(1)} = \frac{A^4\cdot 3L/8}{A^2\cdot L/2} = \frac{3}{4}A^2 = \frac{
3}{4}\cdot\frac{2a^2}{L} = \frac{3a^2}{2L}.$$

### Result: perturbed eigenvalue

$$\boxed{\lambda_1 = \Bigl(\frac{\pi}{L}\Bigr)^2 + \varepsilon\,\frac{3a^2}{2L}
+ O(\varepsilon^2).}$$

### Sketch of $a$ as a function of $\lambda$

Solving the leading-order relation for $a$:
$$a^2 = \frac{2L}{3\varepsilon}\Bigl(\lambda - \bigl(\tfrac{\pi}{L}\bigr)^2\Bigr
),$$
so
$$a = \sqrt{\frac{2L}{3\varepsilon}}\;\sqrt{\lambda - \bigl(\tfrac{\pi}{L}\bigr)
^2}.$$

This is a **bifurcation diagram** (pitchfork-type branch) in the $(\lambda, a)$-
plane:

- The trivial branch $a=0$ exists for all $\lambda$ (the linear eigenvalue $\lam
bda_1^{(0)}=(\pi/L)^2$).
- A **nontrivial branch** emanates from the bifurcation point $\bigl((\pi/L)^2,\
,0\bigr)$, shaped like a sideways square-root parabola.

**For $\varepsilon > 0$ (softening nonlinearity):** the branch exists for $\lamb
da > (\pi/L)^2$ — it bends to the **right** (supercritical). The eigenvalue incr
eases with amplitude.

**For $\varepsilon < 0$ (hardening nonlinearity):** the branch exists for $\lamb
da < (\pi/L)^2$ — it bends to the **left** (subcritical). The eigenvalue decreas
es with amplitude.

Sketch description:
```
        a
        |        ε > 0:  branch opens to the right
        |       /
        |      /
        |     /     ε < 0: branch opens to the left
        |    /     \
        |   /       \
        |  /         \
        | /           \
        |/             \
  ------●--------------- λ = (π/L)²
        |  bifurcation point
        |
```

The curve $a(\lambda)$ is tangent to the vertical line $\lambda = (\pi/L)^2$ at
the origin (infinite slope there, since $d\lambda/da \propto a \to 0$), and grow
s as $\sqrt{\lambda - \lambda_1^{(0)}}$ away from it — the classic **supercritic
al pitchfork** (for $\varepsilon>0$) or **subcritical pitchfork** (for $\varepsi
lon<0$) amplitude–eigenvalue relation.
