## Proof

We show that $F = \{f \in \mathbb{N}^{\mathbb{N}} : \forall n \in \mathbb{N},\ f
(2n) = n\}$ has the cardinality of the continuum.

**Step 1: Identify the free parameters.**

The constraint $f(2n) = n$ for all $n \in \mathbb{N}$ fixes the value of $f$ at
every even input:
$$f(0) = 0,\quad f(2) = 1,\quad f(4) = 2,\quad \dots,\quad f(2n) = n,\ \dots$$

The values of $f$ at odd inputs $f(1), f(3), f(5), \dots$ are unconstrained—each
 may be any element of $\mathbb{N}$.

**Step 2: Construct an explicit bijection.**

Define
$$\Phi : F \to \mathbb{N}^{\mathbb{N}}, \qquad \Phi(f) = g, \quad \text{where }
g(k) = f(2k+1).$$

That is, $\Phi$ extracts the subsequence of $f$ at odd indices.

- **$\Phi$ is injective:** If $\Phi(f_1) = \Phi(f_2)$, then $f_1(2k+1) = f_2(2k+
1)$ for all $k$, and the constraint gives $f_1(2k) = k = f_2(2k)$ for all $k$. H
ence $f_1 = f_2$ on all inputs, so $f_1 = f_2$.
- **$\Phi$ is surjective:** Given any $g \in \mathbb{N}^{\mathbb{N}}$, define $f
 \in F$ by $f(2k) = k$ and $f(2k+1) = g(k)$. This $f$ satisfies the constraint a
nd $\Phi(f) = g$.

Thus $\Phi$ is a bijection, so $|F| = |\mathbb{N}^{\mathbb{N}}|$.

**Step 3: $|\mathbb{N}^{\mathbb{N}}|$ is the cardinality of the continuum.**

It is standard that $|\mathbb{N}^{\mathbb{N}}| = \mathfrak{c}$. For completeness
:

- *Lower bound:* The map $2^{\mathbb{N}} \hookrightarrow \mathbb{N}^{\mathbb{N}}
$ (binary sequences as a subset of all sequences) gives $|2^{\mathbb{N}}| \leq |
\mathbb{N}^{\mathbb{N}}|$, so $\mathfrak{c} \leq |\mathbb{N}^{\mathbb{N}}|$.
- *Upper bound:* Each $f \in \mathbb{N}^{\mathbb{N}}$ is a countable sequence of
 natural numbers. Encoding each $f(k)$ in binary and interleaving the bits yield
s an injection $\mathbb{N}^{\mathbb{N}} \hookrightarrow 2^{\mathbb{N}}$ (using a
 self-delimiting code, e.g., unary-length prefix), so $|\mathbb{N}^{\mathbb{N}}|
 \leq |2^{\mathbb{N}}| = \mathfrak{c}$.

Therefore $|\mathbb{N}^{\mathbb{N}}| = \mathfrak{c}$, and combined with Step 2,
$$|F| = |\mathbb{N}^{\mathbb{N}}| = \mathfrak{c}.$$

$\blacksquare$
