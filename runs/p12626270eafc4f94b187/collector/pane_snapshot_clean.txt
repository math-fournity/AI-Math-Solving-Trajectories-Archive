## Proof

**Key observation.** The expression $xt + yz$ is the dot product of vectors $(x,
 y)$ and $(t, z)$. By the Cauchy–Schwarz inequality:

$$xt + yz \leq \sqrt{x^2 + y^2}\,\sqrt{z^2 + t^2} = \sqrt{4}\cdot\sqrt{9} = 2 \c
dot 3 = 6.$$

The constraint requires $xt + yz \geq 6$. Combining both inequalities:

$$6 \leq xt + yz \leq 6 \implies xt + yz = 6.$$

**Equality condition.** Equality in Cauchy–Schwarz holds if and only if the vect
ors $(x, y)$ and $(t, z)$ are positively proportional: $(t, z) = \lambda (x, y)$
 for some $\lambda > 0$.

Substituting into $z^2 + t^2 = 9$:

$$\lambda^2(x^2 + y^2) = 9 \implies \lambda^2 \cdot 4 = 9 \implies \lambda = \tf
rac{3}{2}.$$

Therefore $z = \tfrac{3}{2}\,y$ and $t = \tfrac{3}{2}\,x$.

**Maximizing the objective.** We now maximize

$$z + x = \tfrac{3}{2}\,y + x$$

subject to $x^2 + y^2 = 4$. Applying Cauchy–Schwarz again with vectors $(1, \tfr
ac{3}{2})$ and $(x, y)$:

$$x + \tfrac{3}{2}\,y \leq \sqrt{1 + \tfrac{9}{4}}\;\sqrt{x^2 + y^2} = \sqrt{\tf
rac{13}{4}} \cdot 2 = \sqrt{13}.$$

**Equality check.** Equality holds when $(x, y) \propto (1, \tfrac{3}{2})$. Sett
ing $x = \tfrac{4}{\sqrt{13}}$, $y = \tfrac{6}{\sqrt{13}}$:

- $x^2 + y^2 = \tfrac{16}{13} + \tfrac{36}{13} = \tfrac{52}{13} = 4$. ✓
- $z = \tfrac{3}{2}\cdot\tfrac{6}{\sqrt{13}} = \tfrac{9}{\sqrt{13}}$, $t = \tfra
c{3}{2}\cdot\tfrac{4}{\sqrt{13}} = \tfrac{6}{\sqrt{13}}$.
- $z^2 + t^2 = \tfrac{81}{13} + \tfrac{36}{13} = \tfrac{117}{13} = 9$. ✓
- $xt + yz = \tfrac{24}{13} + \tfrac{54}{13} = \tfrac{78}{13} = 6$. ✓
- $z + x = \tfrac{9}{\sqrt{13}} + \tfrac{4}{\sqrt{13}} = \tfrac{13}{\sqrt{13}} =
 \sqrt{13}$. ✓

All constraints are satisfied, and the bound $\sqrt{13}$ is attained.

**The maximum possible value of $z + x$ is $\sqrt{13}$.**
