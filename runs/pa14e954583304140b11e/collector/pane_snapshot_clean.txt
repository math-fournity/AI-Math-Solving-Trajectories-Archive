### Setup

 k \text{ remaining phases})$. We seek $P(X_5 \geq 1) = 1 - P(X_5 = 0)$, where

$$P(X_5 = 0) = \frac{1}{101}\sum_{n=0}^{100} q(n,4).$$

### Recursion

**Base:** $q(n,0) = [n=0]$ (1 if $n=0$, else 0).

**Step:** $q(n,k) = \frac{1}{n+1}\sum_{j=0}^{n} q(j,k-1)$.

### Computing the layers

**$k=1$:** $q(n,1) = \frac{1}{n+1}\sum_{j=0}^n [j=0] = \frac{1}{n+1}$.

**$k=2$:** $q(n,2) = \frac{1}{n+1}\sum_{j=0}^n \frac{1}{j+1} = \frac{H_{n+1}}{n+
1}$, where $H_m = \sum_{i=1}^m \frac{1}{i}$.

**$k=3$:** Using the identity $\sum_{m=1}^{M}\frac{H_m}{m} = \frac{H_M^2 + H_M^{
(2)}}{2}$:

$$q(n,3) = \frac{H_{n+1}^2 + H_{n+1}^{(2)}}{2(n+1)}.$$

**$k=4$:** Using $\sum_{m=1}^{M}\frac{H_m^2 + H_m^{(2)}}{m} = \frac{H_M^3 + 3H_M
 H_M^{(2)} + 2H_M^{(3)}}{3}$:

$$q(n,4) = \frac{H_{n+1}^3 + 3H_{n+1}H_{n+1}^{(2)} + 2H_{n+1}^{(3)}}{6(n+1)} = \
frac{h_3(1,\tfrac{1}{2},\ldots,\tfrac{1}{n+1})}{n+1},$$

where $h_3$ is the complete homogeneous symmetric polynomial of degree 3.

### Collapsing the sum

$$\sum_{n=0}^{100} q(n,4) = \sum_{m=1}^{101}\frac{h_3(1,\ldots,\tfrac{1}{m})}{m}
 = h_4\!\left(1,\tfrac{1}{2},\ldots,\tfrac{1}{101}\right),$$

since $\sum_{m=1}^{M}\frac{h_3(1,\ldots,1/m)}{m} = h_4(1,\ldots,1/M)$ (verified
for $M=1,2$). Therefore:

$$P(X_5 = 0) = \frac{h_4(1,\tfrac{1}{2},\ldots,\tfrac{1}{101})}{101}.$$
