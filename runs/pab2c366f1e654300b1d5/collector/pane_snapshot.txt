# Fredholm Property and Essential Spectrum of $A = \frac{d}{dx}$

## Setup

Let $X = C[0,1]$ with the sup-norm, and $A = \frac{d}{dx}$ with domain
$$\mathfrak{D}(A) = \{f \in C^1[0,1] \mid f(0) = f(1) = 0\}.$$

$A$ is a closed operator: if $f_n \to f$ in $C[0,1]$ and $f_n' \to g$ in $C[0,1]
$, then by the standard theorem on uniform convergence of derivatives, $f \in C^
1[0,1]$, $f' = g$, and $f(0)=\lim f_n(0)=0$, $f(1)=\lim f_n(1)=0$.

For $\alpha \in \mathbb{C}$, denote $T_\alpha := A - \alpha I$, acting as $(T_\a
lpha f)(x) = f'(x) - \alpha f(x)$ on $\mathfrak{D}(A)$.

## Step 1: The Kernel

$T_\alpha f = 0$ gives the ODE $f' - \alpha f = 0$, whose general solution is $f
(x) = Ce^{\alpha x}$. The boundary condition $f(0) = 0$ forces $C = 0$, so $f \e
quiv 0$. Thus:

$$\ker(T_\alpha) = \{0\}, \quad \text{for all } \alpha \in \mathbb{C}.$$

## Step 2: The Range

We solve $f' - \alpha f = g$ with $f(0) = f(1) = 0$ for $g \in C[0,1]$.

Multiplying by the integrating factor $e^{-\alpha x}$:

$$\bigl(e^{-\alpha x}f(x)\bigr)' = e^{-\alpha x}g(x).$$

Integrating from $0$ to $x$ and using $f(0)=0$:

$$f(x) = e^{\alpha x}\int_0^x e^{-\alpha t}\,g(t)\,dt.$$

The second boundary condition $f(1) = 0$ gives:

$$e^{\alpha}\int_0^1 e^{-\alpha t}\,g(t)\,dt = 0 \implies \int_0^1 e^{-\alpha t}
\,g(t)\,dt = 0,$$

since $e^{\alpha} \neq 0$. Therefore:

$$\operatorname{ran}(T_\alpha) = \left\{g \in C[0,1] \;\middle|\; \int_0^1 e^{-\
alpha t}\,g(t)\,dt = 0\right\} = \ker(\ell_\alpha),$$

where $\ell_\alpha : C[0,1] \to \mathbb{C}$ is the linear functional $\ell_\alph
a(g) = \int_0^1 e^{-\alpha t}\,g(t)\,dt$.

## Step 3: The Range is Closed with Codimension 1

The functional $\ell_\alpha$ is **bounded** on $C[0,1]$, since $|e^{-\alpha t}|$
 is bounded on $[0,1]$:

$$|\ell_\alpha(g)| \leq \|g\|_\infty \int_0^1 |e^{-\alpha t}|\,dt \leq \|g\|_\in
fty \cdot e^{|\operatorname{Re}(\alpha)|}.$$

It is **nonzero**: taking $g(t) = e^{-\bar{\alpha}t}$ gives $\ell_\alpha(g) = \i
nt_0^1 e^{-2\operatorname{Re}(\alpha)t}\,dt > 0$.

The kernel of a nonzero bounded linear functional on a Banach space is a **close
d** hyperplane of **codimension 1**. Hence:

- $\operatorname{ran}(T_\alpha)$ is closed for all $\alpha$.
- $\dim\operatorname{coker}(T_\alpha) = \dim\bigl(C[0,1]/\operatorname{ran}(T_\a
lpha)\bigr) = 1$ for all $\alpha$.

## Step 4: Fredholm Conclusion

For every $\alpha \in \mathbb{C}$, the operator $T_\alpha = A - \alpha$ satisfie
s all three Fredholm conditions:

1. $\dim\ker(T_\alpha) = 0 < \infty$,
2. $\operatorname{ran}(T_\alpha)$ is closed,
3. $\dim\operatorname{coker}(T_\alpha) = 1 < \infty$.

Therefore **$A - \alpha$ is Fredholm for every $\alpha \in \mathbb{C}$**, with F
redholm index

$$\operatorname{ind}(A - \alpha) = \dim\ker(T_\alpha) - \dim\operatorname{coker}
(T_\alpha) = 0 - 1 = -1.$$

## Step 5: Essential Spectrum

The essential spectrum $\sigma_{\mathrm{ess}}(A)$ is defined as the set of $\alp
ha \in \mathbb{C}$ for which $A - \alpha$ is **not** Fredholm. Since $A - \alpha
$ is Fredholm for all $\alpha \in \mathbb{C}$:

$$\boxed{\sigma_{\mathrm{ess}}(A) = \emptyset.}$$

## Remark on the Full Spectrum

Although $A - \alpha$ is always Fredholm, it is never surjective (the range alwa
ys has codimension 1), so $A - \alpha$ is never invertible. This means the full
spectrum is $\sigma(A) = \mathbb{C}$, while the essential spectrum is empty — a
situation characteristic of Fredholm operators with nonzero (here, constantly $-
1$) index.
