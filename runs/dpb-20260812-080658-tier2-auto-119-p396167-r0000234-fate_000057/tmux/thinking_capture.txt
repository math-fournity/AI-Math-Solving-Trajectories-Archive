Proof

Let $\sigma$ be a cycle of odd length $n$. Write

$$\sigma = (a_1\ a_2\ a_3\ \dots\ a_n), \qquad n \text{ odd}.$$

By definition $\sigma(a_i) = a_{i+1}$ (indices taken mod $n$, with $a_{n+1}
=a_1$). Therefore

$$\sigma^2(a_i) = \sigma(\sigma(a_i)) = \sigma(a_{i+1}) = a_{i+2},$$

so $\sigma^2$ acts on the set ${a_1, \dots, a_n}$ by the rule $a_i \mapsto
a_{i+2 \pmod n}$.

Claim: $\sigma^2$ is a single $n$-cycle. It suffices to show that the orbit of
$a_1$ under $\sigma^2$ contains all $n$ elements.

The orbit of $a_1$ is

$$a_1,\ \sigma^2(a_1)=a_3,\ \sigma^4(a_1)=a_5,\ \dots,\ \sigma^{2k}(a_1)=a_{1+2k
\pmod n},\ \dots$$

This orbit is the set ${a_{1+2k \pmod n} : k = 0, 1, 2, \dots}$. The number of
distinct elements in this orbit equals the order of $2$ in $\mathbb{Z}/
n\mathbb{Z}$, i.e. $n/\gcd(2,n)$.

Since $n$ is odd, $\gcd(2, n) = 1$. Hence the orbit has size $n/1 = n$, which is
the entire set ${a_1, \dots, a_n}$.

Therefore $\sigma^2$ consists of a single cycle of length $n$:

$$\sigma^2 = (a_1\ a_3\ a_5\ \dots\ a_n\ a_2\ a_4\ \dots\ a_{n-1}).$$

Explicitly, stepping by $2$ through the odd-indexed entries first and then the
even-indexed entries (since $n$ is odd, $a_{1+2k}$ runs through all residues mod
$n$ before returning to $a_1$), we visit every element exactly once before
returning to $a_1$.

Thus $\sigma^2$ is a cycle. $\blacksquare$
