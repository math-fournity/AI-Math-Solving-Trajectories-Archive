Looking at this problem, I need to count tilings of a 2×12 board using 1×2 domin
oes and L-shaped trominoes (2×2 minus one cell, 4 orientations).

## Setting Up the Recurrence

I process the board left to right, tracking the "frontier" — which cells beyond
the completed boundary are already filled.

**State definitions** (with column *n* being the last fully completed column):
- **a_n**: clean boundary at column *n* (complete tiling of 2×*n*)
- **b_n**: exactly one cell of column *n+1* is pre-filled (top or bottom — equal
 by mirror symmetry), with column *n+2* empty

**Key observation about dead-end states:** An L-tromino placed as "missing botto
m-left" fills (top,n+1),(top,n+2),(bottom,n+2), leaving (bottom,n+1) isolated —
all its neighbors are filled or in completed territory. No piece can cover a sin
gle isolated cell. The mirror case is identical. So these two orientations from
a clean boundary always produce dead ends and contribute zero to any complete ti
ling.

**Transitions from a_n (clean boundary, column n+1 empty):**
1. Vertical domino → **a_{n+1}** (+a_n)
2. Two horizontal dominoes → **a_{n+2}** (+a_n)
3. L-tromino missing bottom-right: fills column n+1 + (top,n+2) → **b_{n+1}** (+
a_n)
4. L-tromino missing top-right: fills column n+1 + (bottom,n+2) → **b_{n+1}** (+
a_n)

**Transitions from b_n (one cell of n+1 filled, n+2 empty):**
5. Horizontal domino filling the gap, extending into n+2 → **b_{n+1}** (+b_n)
6. L-tromino filling the gap + both cells of n+2 → **a_{n+2}** (+b_n)

By symmetry, the mirror state contributes identically, so the combined recurrenc
es are:

$$a_m = a_{m-1} + a_{m-2} + 2\,b_{m-2} \quad (m \ge 2)$$

$$b_m = a_{m-1} + b_{m-1} \quad (m \ge 1)$$

**Initial conditions:** a_0 = 1 (empty board), a_1 = 1 (one vertical domino), b_
0 = 0.

## Verification of Small Cases

**a_2 = a_1 + a_0 + 2·b_0 = 1+1+0 = 2.** Correct: two vertical or two horizontal
 dominoes. No L-tromino tiling exists (3+2≠4).

**a_3 = a_2 + a_1 + 2·b_1 = 2+1+2 = 5.** Verified: 3 domino-only tilings + 2 til
ings using two L-trominoes = 5.

**a_4 = a_3 + a_2 + 2·b_2 = 5+2+4 = 11.** Verified: 5 domino-only tilings + 6 ti
lings with 2 L-trominoes + 1 domino = 11.

Note that b_m = a_{m-1} + b_{m-1} = a_0 + a_1 + ··· + a_{m-1} (cumulative sum).
