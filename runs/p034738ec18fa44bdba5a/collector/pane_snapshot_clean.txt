Looking at this problem, I need to determine whether every bounded null set in ℝ
ⁿ can be partitioned into countably many disjoint pieces, each with measure-zero
 closure.

**Answer: No.** Here is the proof.

---

**Counterexample construction.**

Let $K = [0,1]^n$, which is a compact (hence complete) metric space. Let $\{q_k\
}_{k=1}^\infty$ be a countable dense subset of $K$ (e.g., points with rational c
oordinates). Let $\omega_n$ denote the volume of the unit ball in $\mathbb{R}^n$
. For each $m \geq 1$, set

$$r_{k,m} = \left(\frac{2^{-(k+m+1)}}{\omega_n}\right)^{1/n}, \qquad U_m = \bigc
up_{k=1}^\infty B(q_k,\, r_{k,m}).$$

Each $U_m$ is open and **dense** in $K$ (it contains the dense set $\{q_k\}$), w
ith

$$\mu(U_m) \leq \sum_{k=1}^\infty \operatorname{vol}(B(q_k, r_{k,m})) = \sum_{k=
1}^\infty 2^{-(k+m+1)} = 2^{-m-1}.$$

Define $G = \bigcap_{m=1}^\infty U_m$. Then:

- **$G$ is a $G_\delta$ set** (countable intersection of open sets).
- **$\mu(G) = 0$**, since $\mu(G) \leq \mu(U_m) \leq 2^{-m-1}$ for every $m$.
- **$G$ is bounded**: $G \subseteq U_1 \subseteq \bigcup_k B(q_k, r_{k,1})$, whi
ch is contained in a bounded neighborhood of $K$.
- **$G$ is comeager in $K$**: Each $K \setminus U_m$ is closed in $K$ with empty
 interior (since $U_m$ is dense), hence nowhere dense. So $K \setminus G = \bigc
up_m (K \setminus U_m)$ is meager in $K$.

Thus $G$ is a bounded subset of $\mathbb{R}^n$ with Lebesgue measure $0$.

---

**$G$ admits no such decomposition.**

Suppose for contradiction that $G = \bigcup_{j=1}^\infty X_j$, pairwise disjoint
, with $\mu(\overline{X_j}) = 0$ for each $j$.

Since $G$ is bounded, each $X_j \subseteq G$ is bounded, so $\overline{X_j}$ is
**compact** (closed and bounded in $\mathbb{R}^n$) with $\mu(\overline{X_j}) = 0
$. A closed set of measure $0$ has empty interior (any nonempty open ball has po
sitive measure), so each $\overline{X_j}$ is **nowhere dense** in $K$.

Set $F = \bigcup_{j=1}^\infty \overline{X_j}$. Then $F$ is a countable union of
nowhere dense sets, hence **meager** in $K$. Since $G = \bigcup X_j \subseteq \b
igcup \overline{X_j} = F$, we have $G \subseteq F$.

Now $K = G \cup (K \setminus G) \subseteq F \cup (K \setminus G)$. Both $F$ and
$K \setminus G$ are meager in $K$, so their union is meager, making $K$ meager i
n itself. This **contradicts the Baire Category Theorem**, which states that a c
omplete metric space is not meager in itself.

---

**Conclusion.** The set $G$ is a bounded null set in $\mathbb{R}^n$ that cannot
be decomposed into countably many pairwise disjoint sets whose closures each hav
e measure $0$. Therefore, such a decomposition is **not always possible**.
