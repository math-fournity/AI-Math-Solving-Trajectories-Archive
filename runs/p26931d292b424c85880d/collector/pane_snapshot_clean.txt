Yes, such a function exists. Here is the proof.

**Claim.** There exists a function $g(x,y)$, defined on a convex domain $D\subse
teq\mathbb{R}^2$, that is convex in $x$ for every fixed $y$, convex in $y$ for e
very fixed $x$, yet is not jointly convex on $D$.

**Construction.** Let $D=\mathbb{R}^2$ (which is convex) and define
$$g(x,y)=xy.$$

**Step 1: $g$ is convex in $x$ for every fixed $y$.**
For fixed $y$, the map $x\mapsto xy$ is affine (linear) in $x$. Every affine fun
ction is convex. Hence $g(\cdot,y)$ is convex for each fixed $y$.

**Step 2: $g$ is convex in $y$ for every fixed $x$.**
By the identical argument with the roles of $x$ and $y$ exchanged, the map $y\ma
psto xy$ is affine in $y$ for each fixed $x$, hence convex.

**Step 3: $g$ is not jointly convex on $D$.**
Recall that $g$ is jointly convex on $D$ iff for all $(x_1,y_1),(x_2,y_2)\in D$
and all $t\in[0,1]$,
$$g\bigl(tx_1+(1-t)x_2,\; ty_1+(1-t)y_2\bigr)\;\le\; t\,g(x_1,y_1)+(1-t)\,g(x_2,
y_2).$$

We exhibit a single violation. Take
$$(x_1,y_1)=(1,-1),\qquad (x_2,y_2)=(-1,1),\qquad t=\tfrac12.$$

Both points lie in $D=\mathbb{R}^2$. The midpoint is
$$\bigl(\tfrac12(1)+\tfrac12(-1),\;\tfrac12(-1)+\tfrac12(1)\bigr)=(0,0),$$
so the left-hand side is
$$g(0,0)=0.$$

The right-hand side is
$$\tfrac12\,g(1,-1)+\tfrac12\,g(-1,1)=\tfrac12(-1)+\tfrac12(-1)=-1.$$

The convexity inequality would require $0\le -1$, which is false. Therefore $g$
is not jointly convex.

**Remark (Hessian perspective).** The Hessian of $g$ is
$$\nabla^2 g=\begin{pmatrix}0&1\\1&0\end{pmatrix},$$
with eigenvalues $+1$ and $-1$, so it is indefinite at every point of $\mathbb{R
}^2$. A twice-differentiable function is convex only if its Hessian is positive
semidefinite everywhere; since $\nabla^2 g$ is everywhere indefinite, $g$ is joi
ntly convex on no open subset of $\mathbb{R}^2$. This is consistent with the dir
ect counterexample above.

**Conclusion.** The function $g(x,y)=xy$ on the convex domain $D=\mathbb{R}^2$ i
s separately convex in each variable (each section being affine) but is not join
tly convex. Hence such a function exists. $\blacksquare$
