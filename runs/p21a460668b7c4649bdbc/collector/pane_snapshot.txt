**Answer:** Yes, it is possible.

**Construction.** Let $C \subset [0,1]$ denote the standard middle-thirds Cantor
 set. It is well known that $C$ is uncountable and has Lebesgue measure $m(C)=0$
. Define

$$S \;=\; \bigcup_{n\in\mathbb{Z}}\,(C+n),$$

where $C+n=\{c+n:c\in C\}$ is the translate of $C$ by the integer $n$. We claim
$S$ is uncountable, unbounded, and has measure $0$.

**Proof.**

*Measure zero.* Each translate $C+n$ is a translate of a null set, hence $m(C+n)
=m(C)=0$. The collection $\{C+n\}_{n\in\mathbb{Z}}$ is countable, so by countabl
e subadditivity of Lebesgue measure,

$$m(S)\;\le\;\sum_{n\in\mathbb{Z}} m(C+n)\;=\;\sum_{n\in\mathbb{Z}} 0 \;=\; 0.$$

Since measure is nonnegative, $m(S)=0$.

*Uncountable.* Each $C+n$ is uncountable (translation is a bijection, preserving
 cardinality). A countable union of countable sets is countable; contrapositivel
y, if $S=\bigcup_{n\in\mathbb{Z}}(C+n)$ were countable, then each subset $C+n\su
bseteq S$ would be countable — contradicting that every $C+n$ is uncountable. He
nce $S$ is uncountable. (Concretely, $S$ contains the uncountable set $C+0=C$.)

*Unbounded.* For every $n\in\mathbb{N}$, the point $0+n=n$ belongs to $C+n\subse
teq S$ (since $0\in C$). Thus $S$ contains all positive integers and is therefor
e unbounded above (and similarly unbounded below, since $-n\in S$ for $n\in\math
bb{N}$).

**Conclusion.** The set $S=\bigcup_{n\in\mathbb{Z}}(C+n)$ is simultaneously unco
untable, unbounded, and of Lebesgue measure $0$. Therefore such a set can indeed
 be constructed.
