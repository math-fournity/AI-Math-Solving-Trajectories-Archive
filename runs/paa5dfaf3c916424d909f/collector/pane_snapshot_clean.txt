## 证明

设 $V$ 是 $\mathbb{F}$ 上的向量空间（$\mathbb{F} = \mathbb{R}$ 或 $\mathbb{C}$）
，且 $\dim(V) = \alpha$，其中 $\alpha$ 为无穷基数。我们确定代数对偶空间 $V^* = \
text{Hom}(V, \mathbb{F})$ 的维数。

### 步骤 1：$V^*$ 与 $\mathbb{F}^B$ 同构

设 $B$ 为 $V$ 的一个基，且 $|B| = \alpha$。每个线性泛函 $\varphi: V \to \mathbb{
F}$ 由其在 $B$ 上的值唯一确定，反之，任何函数 $f: B \to \mathbb{F}$ 都能唯一扩张
为线性泛函（通过线性扩展）。因此，作为 $\mathbb{F}$-向量空间，有 $V^* \cong \mat
hbb{F}^B$（即所有从 $B$ 到 $\mathbb{F}$ 的函数集合，赋予逐点运算）。

### 步骤 2：$|\mathbb{F}|$ 的基数

由于 $\mathbb{F} = \mathbb{R}$ 或 $\mathbb{C}$，我们有 $|\mathbb{F}| = |\mathbb{
R}| = |\mathbb{C}| = 2^{\aleph_0}$。

### 步骤 3：上界

对于任何 $\mathbb{F}$ 上的无穷维向量空间 $W$，有 $|W| = \max(|\mathbb{F}|, \dim(
W))$。应用于 $W = \mathbb{F}^B$：

$$|\mathbb{F}^B| = |\mathbb{F}|^{|B|} = |\mathbb{F}|^\alpha = (2^{\aleph_0})^\al
pha = 2^{\aleph_0 \cdot \alpha} = 2^\alpha,$$

其中我们使用了基数运算的性质：$\aleph_0 \cdot \alpha = \alpha$（因为 $\alpha$ 是
无穷的）。因此 $|\mathbb{F}^B| = 2^\alpha$，且

$$\dim(V^*) = \dim(\mathbb{F}^B) \le |\mathbb{F}^B| = 2^\alpha.$$

### 步骤 4：下界

我们证明 $\dim(\mathbb{F}^B) \ge 2^\alpha$，分两种情况讨论。

**情况 1：$\alpha > \aleph_0$。** 此时 $2^\alpha > 2^{\aleph_0} = |\mathbb{F}|$
。由 $|\mathbb{F}^B| = \max(|\mathbb{F}|, \dim(\mathbb{F}^B))$ 和 $|\mathbb{F}^B
| = 2^\alpha > |\mathbb{F}|$，我们直接得出 $\dim(\mathbb{F}^B) = 2^\alpha$。

**情况 2：$\alpha = \aleph_0$。** 此时 $|\mathbb{F}^B| = 2^{\aleph_0} = |\mathbb
{F}|$，因此基数论证仅给出 $\dim(\mathbb{F}^B) \le 2^{\aleph_0}$。我们通过显式构
造 $2^{\aleph_0}$ 个线性无关的元素来证明 $\dim(\mathbb{F}^B) \ge 2^{\aleph_0}$。

将 $B$ 等同于 $\mathbb{N}$。对每个 $a \in \mathbb{F}$，定义 $f_a \in \mathbb{F}^
{\mathbb{N}}$ 为 $f_a(n) = a^n$（$n = 0, 1, 2, \ldots$）。族 $\{f_a : a \in \mat
hbb{F}\}$ 有 $|\mathbb{F}| = 2^{\aleph_0}$ 个元素。

**线性无关性：** 设 $\sum_{i=1}^k c_i f_{a_i} = 0$，其中 $a_1, \ldots, a_k \in \
mathbb{F}$ 互不相同，$c_i \in \mathbb{F}$。这意味着对所有 $n \ge 0$，有 $\sum_{i
=1}^k c_i a_i^n = 0$。取 $n = 0, 1, \ldots, k-1$，得到 Vandermonde 方程组 $V\mat
hbf{c} = \mathbf{0}$，其中 $V = (a_i^j)_{0 \le j \le k-1,\; 1 \le i \le k}$。由
于 $a_i$ 互不相同，Vandermonde 矩阵 $V$ 可逆，故 $\mathbf{c} = \mathbf{0}$。因此
该族线性无关，给出 $\dim(\mathbb{F}^{\mathbb{N}}) \ge 2^{\aleph_0}$。

结合上界，$\dim(\mathbb{F}^{\mathbb{N}}) = 2^{\aleph_0} = 2^\alpha$。

### 步骤 5：结论

在两种情况下，均有 $\dim(V^*) = \dim(\mathbb{F}^B) = 2^\alpha$。

这实际上是 **Erdős–Kaplansky 定理** 的一个实例：对任意除环 $D$ 和无穷集 $I$，$\d
im_D(D^I) = |D|^{|I|}$。对于 $\mathbb{F} = \mathbb{R}$ 或 $\mathbb{C}$，$|\mathb
b{F}|^\alpha = (2^{\aleph_0})^\alpha = 2^\alpha$。

$$\boxed{\dim(V^*) = 2^\alpha}$$
