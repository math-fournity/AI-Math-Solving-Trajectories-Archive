## Proof

Let $M \subseteq \mathbb{C}$ denote the Mandelbrot set:
$$M = \left\{ c \in \mathbb{C} : \text{the sequence } z_0=0,\; z_{n+1}=z_n^2+c \
text{ remains bounded} \right\}.$$

We prove $|M| = 2^{\aleph_0}$.

### Upper bound: $|M| \le 2^{\aleph_0}$

Clearly $M \subseteq \mathbb{C} \cong \mathbb{R}^2$, and $|\mathbb{R}^2| = 2^{\a
leph_0}$. Hence $|M| \le 2^{\aleph_0}$.

### Lower bound: $|M| \ge 2^{\aleph_0}$

We show $M$ contains a real interval, which has the cardinality of the continuum
.

**Claim:** $M \cap \mathbb{R} = [-2, \tfrac{1}{4}]$.

*Proof of claim.* For $c \in \mathbb{R}$, the iteration $z_{n+1} = z_n^2 + c$ wi
th $z_0 = 0$ stays on the real line, so boundedness is equivalent to the orbit o
f $0$ under the real map $f_c(x) = x^2 + c$ being bounded.

- **$c > \tfrac{1}{4}$:** The fixed points of $f_c$ satisfy $x = x^2 + c$, i.e.
$x^2 - x + c = 0$, with discriminant $1 - 4c < 0$. So $f_c$ has no real fixed po
int. Since $f_c(x) - x = x^2 - x + c > 0$ for all real $x$ (the quadratic has ne
gative discriminant and positive leading coefficient), every iterate strictly in
creases: $z_{n+1} > z_n$ for all $n$. The sequence diverges to $+\infty$, so $c
\notin M$.

- **$c \in [-2, \tfrac{1}{4}]$:** The fixed points are $x_{\pm} = \frac{1 \pm \s
qrt{1-4c}}{2}$, both real. The smaller fixed point $x_- = \frac{1-\sqrt{1-4c}}{2
}$ is attracting (or neutral): the multiplier is $f_c'(x_-) = 2x_- = 1 - \sqrt{1
-4c}$, and $|1 - \sqrt{1-4c}| \le 1$ precisely when $0 \le \sqrt{1-4c} \le 2$, i
.e. $c \in [-2, \tfrac{1}{4}]$. Starting from $z_0 = 0 \in [x_-, x_+]$ (one chec
ks $0 \ge x_-$ and $0 \le x_+$ in this range), the orbit is trapped: $f_c$ maps
$[x_-, x_+]$ into itself since $f_c$ has its minimum at $x=0$ with $f_c(0)=c \ge
 x_-$ (using $c \ge -2$) and $f_c(x_{\pm})=x_{\pm}$. Thus $\{z_n\} \subseteq [x_
-, x_+]$, hence bounded. So $c \in M$.

- **$c < -2$:** Then $z_1 = c < -2$, and $z_2 = c^2 + c = c(c+1)$. For $c < -2$,
 $|c+1| > 1$ so $|z_2| = |c||c+1| > |c| = |z_1|$, and inductively $|z_{n+1}| = |
z_n^2 + c| \ge |z_n|^2 - |c|$. Once $|z_n| > |c| + 1$ (which is achieved since t
he growth is super-exponential), $|z_{n+1}| \ge |z_n|^2 - |c| > |z_n|(|z_n|-1) >
 |z_n|$, and the sequence diverges. So $c \notin M$.

Combining: $M \cap \mathbb{R} = [-2, \tfrac{1}{4}]$. $\square$

The interval $[-2, \tfrac{1}{4}]$ has cardinality $2^{\aleph_0}$. Since $[-2, \t
frac{1}{4}] \subseteq M$,
$$|M| \ge \left|[-2, \tfrac{1}{4}]\right| = 2^{\aleph_0}.$$

### Conclusion

Combining both bounds:
$$2^{\aleph_0} \le |M| \le 2^{\aleph_0},$$
so by the Cantor–Bernstein theorem,
$$\boxed{|M| = 2^{\aleph_0}}.$$

The Mandelbrot set has the cardinality of the continuum; it is **uncountable**.
