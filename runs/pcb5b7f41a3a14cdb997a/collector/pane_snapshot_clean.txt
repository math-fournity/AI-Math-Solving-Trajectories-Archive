## 解答

我们使用 Rouché 定理，分两步进行。

**第一步：将 $f$ 与 $h(z) = 10ze^{z+1} - 9$ 进行比较。**

在 $|z| = 1$ 上，记 $z = e^{i\theta}$。则
$$|z^{10}| = 1, \qquad 10ze^{z+1} = 10\,e^{\cos\theta + 1}\,e^{i(\theta + \sin\t
heta)}.$$

记 $R(\theta) = 10\,e^{\cos\theta+1} \geq 10\,e^{0} = 10$，$\phi(\theta) = \thet
a + \sin\theta$。则
$$|10ze^{z+1} - 9|^2 = R^2 - 18R\cos\phi + 81.$$

我们需要证明 $|10ze^{z+1} - 9|^2 > 1$，即 $R^2 - 18R\cos\phi + 80 > 0$。

由于 $\cos\phi \leq 1$：
$$R^2 - 18R\cos\phi + 80 \geq R^2 - 18R + 80 = (R-8)(R-10).$$

由于 $R \geq 10$，有 $(R-8)(R-10) \geq 0$。等号成立需要同时满足 $R = 10$ **且**
$\cos\phi = 1$。

- $R = 10 \Rightarrow \cos\theta = -1 \Rightarrow \theta = \pi$，此时 $\phi = \p
i + \sin\pi = \pi$，故 $\cos\phi = -1 \neq 1$。

因此两个条件不能同时成立，从而
$$R^2 - 18R\cos\phi + 80 > 0 \quad\text{对所有 }\theta\text{ 成立},$$
即 $|10ze^{z+1} - 9| > 1 = |z^{10}|$ 在 $|z| = 1$ 上严格成立。

由 Rouché 定理，$f(z) = z^{10} + (10ze^{z+1} - 9)$ 在 $|z| < 1$ 内的零点数等于 $
h(z) = 10ze^{z+1} - 9$ 在 $|z| < 1$ 内的零点数。

**第二步：计算 $h(z) = 10ze^{z+1} - 9$ 在 $|z| < 1$ 内的零点数。**

$h(z) = 0 \iff ze^{z} = \dfrac{9}{10e} =: c$。

记 $g(z) = ze^z - c$。在 $|z| = 1$ 上：
$$|ze^z| = e^{\operatorname{Re} z} \in [e^{-1},\, e^{1}], \qquad |c| = \frac{9}{
10e} = \frac{9}{10}\cdot\frac{1}{e} < \frac{1}{e} = \min_{|z|=1}|ze^z|.$$

因此 $|c| < |ze^z|$ 在 $|z| = 1$ 上成立。由 Rouché 定理，$g(z) = ze^z - c$ 与 $z
e^z$ 在 $|z| < 1$ 内有相同的零点数。

$ze^z$ 在 $|z| < 1$ 内恰有一个零点（$z = 0$ 处的单零点），故 $g(z)$ 在 $|z| < 1$
 内恰有一个零点，从而 $h(z)$ 在 $|z| < 1$ 内恰有一个零点。

**结论。** $f(z) = z^{10} + 10ze^{z+1} - 9$ 在单位圆盘 $|z| < 1$ 内的零点数为

$$\boxed{1}.$$
