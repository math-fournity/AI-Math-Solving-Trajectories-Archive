## Proof

We evaluate
$$L = \lim_{n\to\infty} \int_0^{\infty} \frac{\ln(n+x)}{n}\,e^{-x}\cos(x)\,dx.$$

**Decomposition.** Using $\ln(n+x) = \ln n + \ln\!\bigl(1+\tfrac{x}{n}\bigr)$, t
he integrand splits as
$$\frac{\ln(n+x)}{n}e^{-x}\cos x = \frac{\ln n}{n}\,e^{-x}\cos x + \frac{\ln(1+x
/n)}{n}\,e^{-x}\cos x.$$

**First term.** The factor $\frac{\ln n}{n}$ is independent of $x$, so
$$\frac{\ln n}{n}\int_0^\infty e^{-x}\cos x\,dx.$$
Computing the integral:
$$\int_0^\infty e^{-x}\cos x\,dx = \Re\!\left(\int_0^\infty e^{-(1-i)x}\,dx\righ
t) = \Re\!\left(\frac{1}{1-i}\right) = \Re\!\left(\frac{1+i}{2}\right) = \frac{1
}{2}.$$
Hence the first term equals $\dfrac{\ln n}{2n}$, which tends to $0$ as $n\to\inf
ty$.

**Second term.** We show
$$I_n := \int_0^\infty \frac{\ln(1+x/n)}{n}\,e^{-x}\cos x\,dx \;\longrightarrow\
; 0.$$
For $t\ge 0$, the inequality $\ln(1+t)\le t$ gives
$$\left|\frac{\ln(1+x/n)}{n}\right| \le \frac{x}{n^2}.$$
Therefore, since $|\cos x|\le 1$,
$$|I_n| \le \int_0^\infty \frac{x}{n^2}\,e^{-x}\,dx = \frac{1}{n^2}\int_0^\infty
 x\,e^{-x}\,dx = \frac{1}{n^2}\cdot 1 = \frac{1}{n^2}\xrightarrow[n\to\infty]{}0
.$$

**Combining.** Both terms vanish in the limit, so
$$L = \lim_{n\to\infty}\frac{\ln n}{2n} + \lim_{n\to\infty} I_n = 0 + 0 = 0.$$

$$\boxed{L = 0.}$$
