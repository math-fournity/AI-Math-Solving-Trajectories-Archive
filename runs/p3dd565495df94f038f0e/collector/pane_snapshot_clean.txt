## Proof

**Counterexample.** Consider the unbounded polyhedron
$$P = \{(x, y) \in \mathbb{R}^2 : y \le \sqrt{2}\, x\}.$$
This polyhedron is unbounded (it extends to $y \to -\infty$) and contains the ir
rational coefficient $\sqrt{2}$. Its integer point set is
$$S = \{(m, n) \in \mathbb{Z}^2 : n \le \sqrt{2}\, m\}.$$

Any perturbation of the inequality $y \le \sqrt{2}\, x$ (including perturbing al
l coefficients) takes the form $a_1 y \le a_2 x + b$ with $(a_1, a_2, b)$ close
to $(1, \sqrt{2}, 0)$ and $a_1 > 0$, which is equivalent to
$$y \le \alpha\, x + c, \quad \text{where } \alpha = a_2/a_1,\; c = b/a_1,$$
with $(\alpha, c)$ close to $(\sqrt{2}, 0)$. The perturbed integer point set is
$S' = \{(m,n) \in \mathbb{Z}^2 : n \le \alpha m + c\}$.

For $S' = S$, we require $\lfloor \alpha m + c \rfloor = \lfloor \sqrt{2}\, m \r
floor$ for all $m \in \mathbb{Z}$. I show this forces $(\alpha, c) = (\sqrt{2},
0)$.

**Case 1: $\alpha > \sqrt{2}$.** Let $\delta = \alpha - \sqrt{2} > 0$. Then $(\a
lpha m + c) - \sqrt{2}\, m = \delta m + c \to +\infty$ as $m \to +\infty$. For s
ufficiently large $m$, we have $\alpha m + c \ge \lfloor \sqrt{2}\, m \rfloor +
1$, so $\lfloor \alpha m + c \rfloor > \lfloor \sqrt{2}\, m \rfloor$. Thus $S' \
ne S$.

**Case 2: $\alpha < \sqrt{2}$.** Let $\delta = \sqrt{2} - \alpha > 0$. Then $\sq

**Case 3: $\alpha = \sqrt{2}$, $c \ne 0$.** Since $\sqrt{2}$ is irrational, by W

 in $[0, 1)$.

In both subcases, $S' \ne S$.

**Case 4: $\alpha = \sqrt{2}$, $c = 0$.** This is the original polyhedron — no p
erturbation at all.

**Conclusion.** The only way to preserve the integer point set is to not perturb
 at all. No nonzero perturbation, however small, preserves the integer points. T
he fundamental reason is that for irrational coefficients, the fractional parts
$\{\sqrt{2}\, m\}$ are dense in $[0,1)$, so the gap between the boundary and the

The answer is **No**.
