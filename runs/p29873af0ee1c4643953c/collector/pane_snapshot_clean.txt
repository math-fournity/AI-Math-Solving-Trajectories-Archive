## Solution

**Answer: No**, $A$ is not necessarily invertible (for $n \geq 2$).

We give an explicit counterexample. Take $n = 2$, with $\diamond$ the cyclic con
volution product and $\cdot$ the coordinatewise (Hadamard) product:

$$(a,b)\diamond(c,d) = (ac+bd,\; ad+bc), \qquad \text{unit } (1,0),$$

$$(a,b)\cdot(c,d) = (ac,\; bd), \qquad \text{unit } (1,1).$$

Define the linear map $A:\mathbb{C}^2 \to \mathbb{C}^2$ by

$$A(a,b) = (a+b,\; a+b).$$

**$A$ is unital.** $A(1,0) = (1,1)$, which is the unit of $(\mathbb{C}^2,+,\cdot
)$. ✓

**$A$ is multiplicative.** Computing both sides:

$$A\bigl((a,b)\diamond(c,d)\bigr) = A(ac+bd,\; ad+bc) = \bigl((a+b)(c+d),\; (a+b
)(c+d)\bigr),$$

$$A(a,b)\cdot A(c,d) = (a+b,\,a+b)\cdot(c+d,\,c+d) = \bigl((a+b)(c+d),\; (a+b)(c
+d)\bigr).$$

These agree, so $A(x\diamond y) = A(x)\cdot A(y)$. ✓

**$A$ is not invertible.** Its kernel is $\{(a,-a):a\in\mathbb{C}\}\neq\{0\}$, s
o $A$ is not injective and hence not invertible. ✓

Thus $A$ is a unital homomorphism that fails to be invertible.

---

**Why this works in general ($n\geq 2$).** Both $(\mathbb{C}^n,+,\diamond)$ (cyc
lic convolution, i.e.\ the group algebra $\mathbb{C}[\mathbb{Z}/n\mathbb{Z}]$) a
nd $(\mathbb{C}^n,+,\cdot)$ (coordinatewise) are semisimple commutative algebras
, each isomorphic to $\mathbb{C}^n$ as an algebra — the DFT gives an explicit is
omorphism $\Phi:(\mathbb{C}^n,+,\diamond)\xrightarrow{\;\sim\}(\mathbb{C}^n,+,\c
dot)$.

A unital homomorphism $\pi:(\mathbb{C}^n,+,\cdot)\to(\mathbb{C}^n,+,\cdot)$ is d
etermined by where it sends the $n$ primitive idempotents $e_1,\dots,e_n$ (the s
tandard basis vectors): their images must be pairwise-orthogonal idempotents of
$(\mathbb{C}^n,+,\cdot)$ summing to the unit $(1,\dots,1)$. Such idempotents are
 exactly $\{0,1\}$-vectors forming a partition of $\{1,\dots,n\}$ into (possibly
 empty) blocks. Choosing a partition with an empty block (equivalently, a non-su
rjective set map $\{1,\dots,n\}\to\{1,\dots,n\}$) yields a non-invertible unital
 endomorphism, e.g.

$$\pi(x_1,\dots,x_n) = (x_1,\,x_1,\,x_2,\,x_3,\,\dots,\,x_{n-1}),$$

which sends $e_n\mapsto 0$ and is therefore not injective. Composing, $A = \pi\c
irc\Phi:(\mathbb{C}^n,+,\diamond)\to(\mathbb{C}^n,+,\cdot)$ is a unital homomorp
hism that is not invertible.

The essential point: a unital homomorphism $\mathbb{C}^n\to\mathbb{C}^n$ (betwee
n product algebras) corresponds to a set map on $n$ points, and is invertible **
iff** that map is a bijection; non-bijections exist whenever $n\geq 2$.
