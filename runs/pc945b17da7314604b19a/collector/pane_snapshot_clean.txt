$$Uf = \Big(\int f\,d\mu\Big)\,\mathbf{1},$$
where $\mathbf{1}$ denotes the constant function $1$ on $E$. Since $\mu$ is a pr
obability measure, $\|\mathbf{1}\|_2^2 = \int 1\,d\mu = 1$, so $\mathbf{1}\in L^
2(\mu)$.

**Step 1: $U$ is self-adjoint and nonnegative.** For $f,g\in L^2(\mu)$,
$$\langle Uf,g\rangle = \int \Big(\int f\,d\mu\Big)\mathbf{1}\cdot g\,d\mu = \Bi
g(\int f\,d\mu\Big)\Big(\int g\,d\mu\Big) = \langle f,Ug\rangle,$$
so $U=U^*$. Moreover,
$$\langle Uf,f\rangle = \Big(\int f\,d\mu\Big)^2 \ge 0,$$
so $U\ge 0$.

**Step 2: $U$ is idempotent ($U^2=U$).** For any $f\in L^2(\mu)$,
$$U^2 f = U\Big(\big(\textstyle\int f\,d\mu\big)\mathbf{1}\Big) = \Big(\int \big

ot\mathbf{1} = Uf,$$
using $\int\mathbf{1}\,d\mu = \mu(E)=1$. Hence $U^2=U$; $U$ is an orthogonal pro
jection (onto the one-dimensional subspace of constant functions).

{s}$ satisfies $\sqrt{0}=0$ and $\sqrt{1}=1$, so by the continuous functional ca

$$U^{1/2} = \sqrt{U} = U.$$

Concretely: $(U^{1/2})^2 = U^2 = U$ and $U^{1/2}=U\ge 0$, and uniqueness of the
