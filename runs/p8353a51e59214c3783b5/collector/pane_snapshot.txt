## Proof

**Answer: Yes, $f$ is zero almost surely on $\Omega$.**

For each $i \in \mathbb{N}$, since $f_i = 0$ almost surely, there exists a measu
rable set $N_i \subseteq \Omega$ with $\mu(N_i) = 0$ such that
$$f_i(\omega) = 0 \quad \text{for all } \omega \in \Omega \setminus N_i.$$

Define the exceptional set
$$N := \bigcup_{i=1}^{\infty} N_i.$$

By countable subadditivity of the measure,
$$\mu(N) \le \sum_{i=1}^{\infty} \mu(N_i) = \sum_{i=1}^{\infty} 0 = 0,$$
so $N$ is a null set.

Now fix any $\omega \in \Omega \setminus N$. Since $\omega \notin N_i$ for every
 $i$, we have $f_i(\omega) = 0$ for every $i$. Therefore every partial sum vanis
hes:
$$\sum_{i=1}^{n} f_i(\omega) = \sum_{i=1}^{n} 0 = 0 \quad \text{for all } n.$$

Consequently the pointwise limit exists and equals zero:
$$f(\omega) = \lim_{n \to \infty} \sum_{i=1}^{n} f_i(\omega) = \lim_{n \to \inft
y} 0 = 0.$$

Thus $f(\omega) = 0$ for all $\omega \in \Omega \setminus N$, and since $\mu(N)
= 0$, we conclude
$$f = 0 \quad \text{almost surely on } \Omega.$$

**Remark.** The key ingredient is that a *countable* union of null sets is again
 null. This is precisely why the result holds for a sequence $\{f_i\}_{i=1}^{\in
fty}$ but would fail for an uncountable family: an uncountable union of null set
s need not be null (e.g., singletons in $[0,1]$ each have measure zero, yet thei
r union has measure one).
