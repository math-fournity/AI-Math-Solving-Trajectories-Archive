## Proof

**Setup.** Recall $a_n = \sum_{k=1}^n \frac{1}{k}$ (harmonic partial sums) with
$a_0=0$, so $a_n \to \infty$. The function $f_n$ is a step function supported on
 $[0, a_n)$, taking the value $2^{k-n}$ on the interval $[a_{k-1}, a_k)$ for $k
= 1, \dots, n$.

**Claim:** $f_n \to 0$ in measure.

**Pointwise behavior (motivation).** Fix $x \ge 0$. For all sufficiently large $
n$, we have $a_n > x$, so $x$ lies in a unique interval $[a_{k(x)-1}, a_{k(x)})$
 where $k(x)$ is **independent of $n$** (it is determined solely by $x$). Then $
f_n(x) = 2^{k(x)-n} \to 0$ as $n \to \infty$. So $f_n \to 0$ pointwise on $[0,\i
nfty)$.

**Convergence in measure.** We show that for every $\varepsilon > 0$,
$$m\big(\{x : f_n(x) > \varepsilon\}\big) \to 0 \quad \text{as } n \to \infty.$$

*Case 1: $\varepsilon \ge 1$.* Since $f_n(x) = 2^{k-n} \le 2^0 = 1$ for all $x$
and all $n$, the set $\{x : f_n(x) > \varepsilon\}$ is empty (for $\varepsilon \
ge 1$). The measure is $0$.

*Case 2: $0 < \varepsilon < 1$.* Set $L = \log_2(1/\varepsilon) > 0$. The condit
ion $f_n(x) > \varepsilon$ means $2^{k-n} > \varepsilon$, i.e., $k > n - L$. Sin
ce $1 \le k \le n$, the set where $f_n > \varepsilon$ is:
$$\bigcup_{k = \lfloor n - L \rfloor + 1}^{n} [a_{k-1}, a_k) = [a_{\lfloor n-L\r
floor},\; a_n).$$

Its Lebesgue measure is:
$$a_n - a_{\lfloor n-L \rfloor} = \sum_{j=\lfloor n-L\rfloor+1}^{n} \frac{1}{j}.
$$

The number of terms in this sum is $n - \lfloor n - L \rfloor \le L + 1$ (a cons
tant independent of $n$), and each term satisfies $\frac{1}{j} \le \frac{1}{\lfl
oor n-L \rfloor + 1}$. For $n$ large enough, $\lfloor n - L \rfloor \ge n/2$, so
 each term is at most $\frac{2}{n}$. Therefore:
$$m\big(\{x : f_n(x) > \varepsilon\}\big) \le \frac{2(L+1)}{n} \to 0 \quad \text
{as } n \to \infty.$$

**Conclusion.** Since $m(\{x : |f_n(x) - 0| > \varepsilon\}) \to 0$ for every $\
varepsilon > 0$, the sequence $f_n$ converges to $f \equiv 0$ in measure. $\blac
ksquare$
