## Proof

**Claim.** The maximum number of pairwise-disjoint infinite subsets of the integ
ers is countably infinite (ℵ₀).

**Upper bound.** Let {Aᵢ}ᵢ∈I be any family of pairwise-disjoint, nonempty subset
s of ℤ. Since the Aᵢ are pairwise disjoint, choosing any element aᵢ ∈ Aᵢ for eac
h i gives an injective map i ↦ aᵢ from I into ℤ (injectivity follows from disjoi
ntness: distinct indices give elements in distinct sets, hence distinct integers
). Since ℤ is countable, I must be countable. Thus no uncountable family of pair
wise-disjoint infinite subsets can exist. The number of such subsets is at most
ℵ₀.

**Lower bound (construction achieving ℵ₀).** It suffices to partition ℕ into cou
ntably many pairwise-disjoint infinite subsets; ℤ is in bijection with ℕ, so the
 same is achieved for ℤ.

For each k = 0, 1, 2, …, define

  Aₖ = { 2ᵏ · (2m + 1) : m = 0, 1, 2, … }.

Each Aₖ consists of the natural numbers whose 2-adic valuation is exactly k (i.e
., numbers divisible by 2ᵏ but not by 2ᵏ⁺¹).

- *Infinite:* Aₖ contains 2ᵏ·1, 2ᵏ·3, 2ᵏ·5, …, one element for each odd number,
so |Aₖ| = ℵ₀.
- *Pairwise disjoint:* Every positive integer n has a unique decomposition n = 2
ᵏ · q with q odd, so n belongs to exactly one Aₖ. Hence Aₖ ∩ Aⱼ = ∅ for k ≠ j.
- *Countably many:* The index set is {0, 1, 2, …}, which is countably infinite.

Thus {Aₖ : k ≥ 0} is a family of ℵ₀ pairwise-disjoint infinite subsets of ℕ. Tra
nsferring via any bijection ℤ ↔ ℕ yields ℵ₀ pairwise-disjoint infinite subsets o
f ℤ.

**Conclusion.** The upper bound is ℵ₀ and the lower bound is ℵ₀, so the maximum
number of pairwise-disjoint infinite subsets of the integers is exactly **ℵ₀ (co
untably infinite)**.
