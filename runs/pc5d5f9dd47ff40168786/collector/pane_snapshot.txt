## Proof

**Setup in barycentric coordinates.** Let A = (1,0,0), B = (0,1,0), C = (0,0,1).
 The median from a vertex connects it to the midpoint of the opposite side, and
the angle bisector from a vertex divides the opposite side in the ratio of adjac
ent sides (angle bisector theorem).

**Finding P, Q, R.** The median m_b is characterized by x = z. The angle bisecto
r w_a meets BC at a point with BD:DC = c:b, so w_a satisfies y:z = b:c.

For **P = w_a ∩ m_b**: x = z and y = bz/c. From x+y+z = 1: z + bz/c + z = 1, giv
ing z = c/(2c+b). So:
$$P = \frac{(c,\, b,\, c)}{2c+b}$$

Similarly:
$$Q = w_b \cap m_c = \frac{(a,\, a,\, c)}{2a+c}, \qquad R = w_c \cap m_a = \frac
{(a,\, b,\, b)}{a+2b}$$

**Computing δ/F.** The area ratio equals the absolute value of the determinant o
f the barycentric coordinate matrix:

$$\frac{\delta}{F} = \frac{|\det[P;Q;R]|}{1} = \frac{|3abc - a^2c - ab^2 - bc^2|
}{(2c+b)(2a+c)(a+2b)}$$

The numerator determinant expands as:
$$c(ab - cb) - b(ab - ca) + c(ab - a^2) = 3abc - a^2c - ab^2 - bc^2$$

**The numerator is non-positive.** By AM-GM:
$$a^2c + ab^2 + bc^2 \geq 3\sqrt[3]{a^2c \cdot ab^2 \cdot bc^2} = 3abc$$
with equality iff a = b = c. So N := 3abc − a²c − ab² − bc² ≤ 0, and:
$$\frac{\delta}{F} = \frac{a^2c + ab^2 + bc^2 - 3abc}{(2c+b)(2a+c)(a+2b)}$$

**Proving δ/F < 1/6.** Expanding the denominator:
$$D = (2c+b)(2a+c)(a+2b) = 4a^2c + 2ac^2 + 2a^2b + 9abc + 4bc^2 + 4ab^2 + 2b^2c$
$

A direct computation yields:
$$D - 6(a^2c + ab^2 + bc^2 - 3abc) = 27abc + 2(a-b)(b-c)(a-c)$$

We show this is always positive. Using the Ravi substitution a = y+z, b = z+x, c
 = x+y (x, y, z > 0), we get:
$$(a-b)(b-c)(a-c) = (y-x)(z-y)(z-x), \quad abc = (x+y)(y+z)(z+x)$$

- If (y−x)(z−y)(z−x) ≥ 0: the expression 27abc + 2(product) > 0 trivially.
- If (y−x)(z−y)(z−x) < 0: since |y−x| ≤ x+y, |z−y| ≤ y+z, |z−x| ≤ z+x:
$$|(y-x)(z-y)(z-x)| \leq (x+y)(y+z)(z+x) = abc$$
$$27abc + 2(y-x)(z-y)(z-x) \geq 27abc - 2abc = 25abc > 0$$

Therefore D > 6(a²c + ab² + bc² − 3abc), giving **δ/F < 1/6** for every valid tr
iangle.

**1/6 is optimal.** Consider b = c = 1, a = ε → 0⁺ (valid since ε + 1 > 1):
$$\text{Numerator} = \varepsilon^2 + \varepsilon + 1 - 3\varepsilon = (1-\vareps
ilon)^2 \to 1$$
$$\text{Denominator} = 3(2\varepsilon+1)(\varepsilon+2) \to 6$$

So δ/F → 1/6 as ε → 0⁺, meaning no constant smaller than 1/6 suffices.

**Conclusion.** The smallest positive constant λ such that δ/F < λ holds for all

$$\boxed{\lambda = \dfrac{1}{6}}$$
