## Proof

**Answer: Yes, such a function exists.**

**Construction.** Define
$$z(k) = 1 - \frac{1}{(k+1)^2}, \qquad k \geq 1.$$
Then $z(k) \in [0,1)$ for every $k$ (since $0 < \frac{1}{(k+1)^2} \leq \frac{1}{
4}$), and $z(k) \to 1$ as $k \to \infty$.

**Key theorem.** *Let $(a_n)$ be a sequence with $0 \le a_n < 1$. Then $\prod_{n
=1}^{\infty}(1-a_n) > 0$ if and only if $\sum_{n=1}^{\infty} a_n < \infty$.*

*Proof of theorem.* Set $a_n = 1 - z(n) \in (0,1]$, so the product is $\prod(1-a
_n)$. Since $a_n \to 0$, there exists $N$ such that $a_n \le 1/2$ for all $n \ge
 N$. The finite partial product $\prod_{n=1}^{N-1}(1-a_n)$ is a fixed positive c
onstant, so it suffices to analyze the tail $\prod_{n=N}^{\infty}(1-a_n)$.

For $0 \le x \le 1/2$ we have the standard bounds:
$$-x \;\le\; \log(1-x) \;\le\; -x, \qquad \text{more precisely } \;-2x \le \log(
1-x) \le -x.$$
(The upper bound $\log(1-x) \le -x$ holds for all $x \in [0,1)$; the lower bound
 $\log(1-x) \ge -2x$ holds for $x \in [0, 1/2]$ since $\log(1-x) = -\sum_{m\ge1}
 x^m/m \ge -x\sum_{m\ge0}x^m = -x/(1-x) \ge -2x$.)

Therefore, for $n \ge N$:
$$-2a_n \;\le\; \log(1-a_n) \;\le\; -a_n.$$

Summing from $N$ to $\infty$, the partial sums $\sum_{n=N}^{M}\log(1-a_n)$ are s
queezed between $-2\sum_{n=N}^{M}a_n$ and $-\sum_{n=N}^{M}a_n$. Hence $\sum \log
(1-a_n)$ converges to a finite limit if and only if $\sum a_n$ converges. Since
$$\prod_{n=N}^{M}(1-a_n) = \exp\!\Bigl(\sum_{n=N}^{M}\log(1-a_n)\Bigr),$$
the product converges to a **positive** limit exactly when the logarithmic sum c
onverges to a finite value, i.e., exactly when $\sum a_n < \infty$. $\square$

**Applying the theorem.** With our choice $z(k) = 1 - \frac{1}{(k+1)^2}$, we hav
e $a_k = \frac{1}{(k+1)^2}$ and
$$\sum_{k=1}^{\infty} a_k = \sum_{k=1}^{\infty}\frac{1}{(k+1)^2} = \sum_{j=2}^{\
infty}\frac{1}{j^2} = \frac{\pi^2}{6} - 1 < \infty.$$

By the theorem, $\prod_{k=1}^{\infty} z(k) = \prod_{k=1}^{\infty}\left(1 - \frac
{1}{(k+1)^2}\right) > 0$.

**Explicit value (optional verification).** Using the telescoping identity
$$1 - \frac{1}{(k+1)^2} = \frac{k(k+2)}{(k+1)^2} = \frac{k}{k+1}\cdot\frac{k+2}{
k+1},$$
the partial product telescopes:
$$\prod_{k=1}^{n}\left(1-\frac{1}{(k+1)^2}\right) = \prod_{k=1}^{n}\frac{k}{k+1}
\cdot\prod_{k=1}^{n}\frac{k+2}{k+1} = \frac{1}{n+1}\cdot\frac{n+2}{2} = \frac{n+
2}{2(n+1)} \xrightarrow{n\to\infty} \frac{1}{2}.$$

So the product converges to $\frac{1}{2} \neq 0$, confirming the construction di
rectly.

**Conclusion.** Such a function exists; for example $z(k) = 1 - \frac{1}{(k+1)^2
}$ yields $\prod_{k=1}^{\infty} z(k) = \frac{1}{2} > 0$.
