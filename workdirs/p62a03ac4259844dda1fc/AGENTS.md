# Problem

In a remote logistics hub, an operations manager oversees a shipping yard represented by a $3 \times 9$ grid of storage bays. Every bay contains a certain number of crates, which must be a positive integer. 

The manager follows a strict "Efficiency Protocol": any rectangular block of bays (of size $m \times n$, where $1 \le m \le 3$ and $1 \le n \le 9$) is classified as a "Optimized Zone" if the total number of crates within that block is exactly divisible by 10. 

A specific storage bay is labeled a "Critical Failure" if it is not part of any Optimized Zone within the entire grid. 

Based on these protocols, what is the maximum possible number of bays in the shipping yard that can be labeled as Critical Failures?
