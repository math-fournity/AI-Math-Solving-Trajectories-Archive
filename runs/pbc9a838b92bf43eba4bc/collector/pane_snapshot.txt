## Proof

We model the problem over the field $\mathbb{F}_2 = \mathbb{Z}/2\mathbb{Z}$. A g
lobal security state is a vector in $\mathbb{F}_2^n$ (1 = activated, 0 = deactiv
ated). Pressing the toggle at station $k$ adds (mod 2) the vector $e_{k-1}+e_k+e
_{k+1}$ (indices mod $n$). Starting from the all-zero state, the set of reachabl
e states is exactly the column space (image) of the $n\times n$ matrix $A$ whose
 $k$-th column is $e_{k-1}+e_k+e_{k+1}$.

**The number of reachable configurations is $2^{\operatorname{rank}(A)}$.**

### Structure of $A$

$A$ is a circulant matrix. Identifying $\mathbb{F}_2^n$ with the ring $R = \math
bb{F}_2[x]/(x^n-1)$ via $(a_0,\dots,a_{n-1}) \leftrightarrow a_0+a_1 x+\cdots+a_
{n-1}x^{n-1}$, left-multiplication by $A$ corresponds to multiplication by the g
enerating polynomial
$$c(x) = 1 + x + x^{n-1} \in \mathbb{F}_2[x].$$

### Nullity via gcd

A standard result for circulants: the nullity of $A$ (dimension of $\ker A$) equ
als
$$\nu = \deg\!\big(\gcd\big(c(x),\, x^n-1\big)\big).$$

*Proof of the claim.* Writing $d = \gcd(c, x^n-1)$, factor $c = d\,c'$ and $x^n-
1 = d\,m$ with $\gcd(c',m)=1$. A vector $f$ lies in $\ker A$ iff $c\,f \equiv 0
\pmod{x^n-1}$, i.e., $d\,m \mid d\,c'f$, i.e., $m \mid c'f$. Since $\gcd(c',m)=1
$, this holds iff $m \mid f$. The polynomials divisible by $m$ with degree $<n$
form an $\mathbb{F}_2$-vector space of dimension $\deg(d) = n - \deg(m)$. Hence
$\nu = \deg(d)$. $\square$

### Computing the gcd

Work in $\mathbb{F}_2[x]$, where $x^n - 1 = x^n + 1$.

**Step 1.** Divide $x^n+1$ by $c(x)=x^{n-1}+x+1$:
$$x^n + 1 = x\cdot(x^{n-1}+x+1) + (x^2+x+1),$$
since $x\cdot(x^{n-1}+x+1) = x^n+x^2+x$ and the remainder is $x^n+1 - (x^n+x^2+x
) = 1+x^2+x = x^2+x+1$ in characteristic 2.

So $\gcd(c(x),\,x^n-1) = \gcd(x^{n-1}+x+1,\; x^2+x+1)$.

**Step 2.** The polynomial $x^2+x+1$ is irreducible over $\mathbb{F}_2$ (it has
no roots: $0\mapsto 1$, $1\mapsto 1$). Thus the gcd is either $x^2+x+1$ or $1$,
and it equals $x^2+x+1$ precisely when $x^2+x+1 \mid x^{n-1}+x+1$.

Let $\omega$ be a root of $x^2+x+1$ (a primitive third root of unity, so $\omega
^3=1$ and $\omega^2+\omega+1=0$, giving $\omega+1=\omega^2$ in characteristic 2)
. The divisibility condition is
$$\omega^{n-1}+\omega+1 = 0 \iff \omega^{n-1}+\omega^2 = 0 \iff \omega^{n-1}=\om
ega^2 \iff n-1\equiv 2\pmod{3} \iff n\equiv 0\pmod{3}.$$

### Conclusion

- **If $3\mid n$:** $\gcd = x^2+x+1$, so $\nu = 2$, $\operatorname{rank}(A)=n-2$
, and the number of reachable configurations is
$$\boxed{2^{\,n-2}}.$$

- **If $3\nmid n$:** $\gcd = 1$, so $\nu = 0$, $\operatorname{rank}(A)=n$, and t
he number of reachable configurations is
$$\boxed{2^{\,n}}.$$

### Sanity checks

- $n=3$: $A$ is the $3\times 3$ all-ones matrix, rank $1$ over $\mathbb{F}_2$, g
iving $2^1=2 = 2^{3-2}$. ✓
- $n=4$ ($3\nmid 4$): answer $2^4=16$, i.e. every state is reachable. ✓ (consist
ent with full rank)
- $n=6$ ($3\mid 6$): answer $2^4=16$. ✓
