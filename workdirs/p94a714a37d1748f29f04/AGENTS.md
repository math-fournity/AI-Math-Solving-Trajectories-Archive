2. If the current ID $n$ is not a multiple of 3, the machine performs a "Quad-Decima Shift," updating the ID to $4n - 10$.

A technician observes that for certain initial packet IDs, the final value after the fifth stage is exactly 2. Find the sum of all possible positive integer values for the initial packet ID $c$ that result in this final output.
