## Proof

**Step 1: Simplify the integrand.**

Let $a = 1-z$. The base of the power is:
$$B(x,y) = 1 - \frac{(1-x)(1-y)}{(1-ax)(1-ay)} = \frac{(1-ax)(1-ay)-(1-x)(1-y)}{
(1-ax)(1-ay)}.$$

Expanding the numerator:
$$(1-ax)(1-ay) - (1-x)(1-y) = [1-ax-ay+a^2xy] - [1-x-y+xy]$$
$$= (1-a)(x+y) + (a^2-1)xy = (1-a)(x+y) - (1-a)(a+1)xy = (1-a)\bigl[(x+y)-(a+1)x
y\bigr].$$

Substituting $a = 1-z$ (so $1-a = z$, $a+1 = 2-z$):
$$\boxed{B(x,y) = \frac{z\bigl[(x+y)-(2-z)xy\bigr]}{(1-(1-z)x)(1-(1-z)y)}.}$$

**Step 2: Identify the singularities (for $z > 0$).**

*Denominator:* For $z > 0$, $a = 1-z$. If $0 < z < 1$, then $a \in (0,1)$ and $1
-ax \in [1-a, 1] = [z, 1]$. If $z \geq 1$, then $a \leq 0$ and $1-ax \geq 1$. In
 all cases, the denominator is bounded above and below by positive constants on
$[0,1]^2$. No singularity from the denominator.

*Numerator vanishing:* Set $f(x,y) = (x+y)-(2-z)xy$. We claim $f \geq 0$ on $[0,
1]^2$ with equality only at $(0,0)$.

- On the boundary $x=0$: $f = y \geq 0$ (equality only at $y=0$).
- On the boundary $y=0$: $f = x \geq 0$ (equality only at $x=0$).
- On the boundary $x=1$: $f = 1 + y - (2-z)y = 1 - (1-z)y \geq 1-(1-z) = z > 0$.
- On the boundary $y=1$: $f = x + 1 - (2-z)x = 1 - (1-z)x \geq z > 0$.

Since $f$ is bilinear (linear in each variable), its minimum on $[0,1]^2$ is att
ained at a corner. The corner values are $f(0,0)=0$, $f(1,0)=1$, $f(0,1)=1$, $f(
1,1)=z>0$. Hence $f \geq 0$ on $[0,1]^2$ with $f=0$ only at $(0,0)$. ✓

Therefore $B \geq 0$ on $[0,1]^2$ with $B = 0$ **only at the origin** $(0,0)$. T
his is the unique singularity.

**Step 3: Asymptotic behavior of $B$ near the origin.**

For $(x,y)$ near $(0,0)$, since $xy \leq \frac{(x+y)^2}{4}$:

*Upper bound:* $B = \frac{z\,f(x,y)}{(1-ax)(1-ay)} \leq \frac{z(x+y)}{(1-|a|)^2}

nd).

*Lower bound:* $f(x,y) = (x+y) - (2-z)xy \geq (x+y)\bigl[1 - (2-z)\frac{x+y}{4}\
bigr]$. For $x+y \leq \delta$ with $\delta$ small enough, the bracket $\geq \fra
c{1}{2}$. Also $(1-ax)(1-ay) \leq 1$. Hence $B \geq \frac{z}{2}(x+y) = c\,(x+y)$

Thus there exist constants $0 < c \leq C$ and $\delta > 0$ such that:
$$c\,(x+y) \leq B(x,y) \leq C\,(x+y) \quad \text{for all } (x,y) \in [0,\delta]^
2.$$

**Step 4: Reduction to a model integral.**

Since $B$ is bounded away from $0$ on $[0,1]^2 \setminus [0,\delta]^2$ (say $B \
geq \mu > 0$ there), the integrand $B^{s-2}$ is bounded on that region for any $
s > 0$. The convergence of $I(z,s)$ is therefore determined entirely by the inte
gral over $[0,\delta]^2$.

On $[0,\delta]^2$, using the comparison $c(x+y) \leq B \leq C(x+y)$:
- If $s \geq 2$: $B^{s-2} \leq C^{s-2}(x+y)^{s-2} \leq C^{s-2}\delta^{s-2}$ (bou
nded), so the integral trivially converges.
- If $0 < s < 2$: $B^{s-2} \leq c^{s-2}(x+y)^{s-2}$ (note $c^{s-2} = c^{-(2-s)}$
 is a positive constant since $s-2 < 0$ and $c \leq B$ gives $B^{s-2} \leq c^{s-
2}$... let me be careful with the direction).

For $0 < s < 2$, the exponent $s-2 < 0$, so $t \mapsto t^{s-2}$ is decreasing. F
rom $c(x+y) \leq B \leq C(x+y)$:
$$C^{s-2}(x+y)^{s-2} \leq B^{s-2} \leq c^{s-2}(x+y)^{s-2}.$$

So $B^{s-2}$ is comparable to $(x+y)^{s-2}$, and $\iint_{[0,\delta]^2} B^{s-2}\,
dx\,dy$ converges if and only if $\iint_{[0,\delta]^2} (x+y)^{s-2}\,dx\,dy$ conv
erges.

**Step 5: Evaluate the model integral.**

Use the change of variables $u = x+y$, $v = x/(x+y)$, so $x = uv$, $y = u(1-v)$,
 with Jacobian $|\partial(x,y)/\partial(u,v)| = u$. Near the origin, $u \in (0,
\delta')$ and $v \in (0,1)$:

$$\iint_{[0,\delta]^2} (x+y)^{s-2}\,dx\,dy = \int_0^{\delta'} \int_0^1 u^{s-2} \
cdot u\,dv\,du = \int_0^{\delta'} u^{s-1}\,du.$$

This integral converges if and only if $s - 1 > -1$, i.e., **$s > 0$**.

**Step 6: Conclusion.**

For any fixed $z > 0$:
- The only singularity of the integrand is at $(0,0)$.
- Near $(0,0)$, the base $B(x,y) \sim z(x+y)$.
- The resulting model integral $\int u^{s-1}\,du$ converges if and only if $s >
0$.
- For $s \leq 0$, the exponent $s-2 \leq -2$ gives $\int u^{s-1}\,du$ with $s-1
\leq -1$, which diverges.

Therefore, the double integral $I(z,s)$ **converges if and only if $s > 0$**.

Since the problem restricts to $s > 0$, the integral converges for **all** $s >
0$.
