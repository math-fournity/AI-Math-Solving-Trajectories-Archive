## Solution

The decimal digits of a uniformly random $x \in (0,1)$ form an i.i.d. sequence w
here each digit is uniformly distributed on $\{0,1,\dots,9\}$, independent of al
l others. The quantity $n(x)$ is the waiting time (measured in "digits skipped")
 before the pattern $1966$ first appears. Since the set of $x$ whose expansion n
ever contains $1966$ has measure zero, the integral $\int_0^1 n(x)\,dx$ equals $
\mathbb{E}[n(x)]$.

### Setting up the automaton

We track progress through the pattern $1,9,6,6$ using states $0,1,2,3,4$, where
state $i$ means the last $i$ digits generated match the first $i$ digits of the
pattern, and state $4$ is absorbing (pattern found). Let $E_i$ = expected number
 of additional digits to reach state $4$ from state $i$, with $E_4=0$.

**State 0** (no progress): next digit is $1$ (prob $1/10$) → state 1; otherwise
(prob $9/10$) → state 0.
$$E_0 = 1 + \tfrac{1}{10}E_1 + \tfrac{9}{10}E_0 \implies E_0 = 10 + E_1$$

**State 1** (have "$1$"): next is $9$ → state 2; next is $1$ → state 1; otherwis
e → state 0.
$$E_1 = 1 + \tfrac{1}{10}E_2 + \tfrac{1}{10}E_1 + \tfrac{8}{10}E_0$$
Substituting $E_0 = 10+E_1$: $9E_1 = 10 + E_2 + 8(10+E_1) = 90 + E_2 + 8E_1$, gi
ving $E_1 = 90 + E_2$.

**State 2** (have "$19$"): next is $6$ → state 3; next is $1$ → state 1; otherwi
se → state 0.
$$E_2 = 1 + \tfrac{1}{10}E_3 + \tfrac{1}{10}E_1 + \tfrac{8}{10}E_0$$
Substituting $E_0 = 10+E_1$ and $E_1 = 90+E_2$: $10E_2 = 90 + E_3 + 9E_1 = 90 +
E_3 + 9(90+E_2) = 900 + E_3 + 9E_2$, giving $E_2 = 900 + E_3$.

**State 3** (have "$196$"): next is $6$ → state 4 (done); next is $1$ → state 1;
 otherwise → state 0.
$$E_3 = 1 + \tfrac{1}{10}\cdot 0 + \tfrac{1}{10}E_1 + \tfrac{8}{10}E_0 = 9 + \tf
rac{9}{10}E_1$$
So $10E_3 = 90 + 9E_1$. Using $E_1 = 90 + E_2 = 90 + 900 + E_3 = 990 + E_3$:
$$10E_3 = 90 + 9(990 + E_3) = 9000 + 9E_3 \implies E_3 = 9000$$

### Back-substitution

$$E_2 = 900 + 9000 = 9900, \quad E_1 = 90 + 9900 = 9990, \quad E_0 = 10 + 9990 =
 10000$$

### Why $E_0 = 10^4$: no self-overlap

The pattern $1966$ has **no proper border** (no proper prefix that is also a suf
fix):
- Length 1: prefix "$1$" ≠ suffix "$6$"
- Length 2: prefix "$19$" ≠ suffix "$66$"
- Length 3: prefix "$196$" ≠ suffix "$966$"

By the classical pattern-matching formula, the expected number of symbols to com
plete a pattern of length $m$ over an alphabet of size $k$ is $\sum_{i \in B} k^
i$, where $B$ is the set of border lengths (including $m$). Here $B = \{4\}$, so
 $E[T] = 10^4 = 10000$, confirming our computation.

### Converting to $n(x)$

$E_0 = \mathbb{E}[T]$ counts all digits up to and including the four digits of t
he pattern. Since $n(x)$ counts only the digits *before* the pattern starts:

$$\mathbb{E}[n(x)] = \mathbb{E}[T] - 4 = 10000 - 4 = 9996$$

### Result

$$\int_0^1 n(x)\,dx = \boxed{9996}$$
