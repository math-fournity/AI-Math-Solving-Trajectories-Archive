## Proof

We show that $(J_n)$ is a Cauchy sequence.

**Setup.** Define the integrand
$$f(t) = \frac{1-\cos t}{4\,t\sqrt{t}} = \frac{1-\cos t}{4\,t^{3/2}}, \qquad t>0
.$$
Since $1-\cos t \ge 0$ for all $t$, we have $f(t)\ge 0$, and therefore $(J_n)$ i
s **monotone non-decreasing**:
$$J_{n+1} - J_n = \int_{n\pi}^{(n+1)\pi} f(t)\,dt \ge 0.$$

**Key estimate.** Using the bound $0 \le 1-\cos t \le 2$, for every $t>0$,
$$0 \le f(t) = \frac{1-\cos t}{4\,t^{3/2}} \le \frac{2}{4\,t^{3/2}} = \frac{1}{2
\,t^{3/2}}.$$

**Cauchy criterion (direct).** Let $m > n \ge 1$. By monotonicity and the estima
te above,
$$0 \le J_m - J_n = \int_{n\pi}^{m\pi} f(t)\,dt \le \int_{n\pi}^{m\pi} \frac{1}{
2\,t^{3/2}}\,dt \le \int_{n\pi}^{\infty} \frac{1}{2\,t^{3/2}}\,dt.$$
Computing the tail,
$$\int_{n\pi}^{\infty} \frac{1}{2\,t^{3/2}}\,dt = \frac{1}{2}\cdot\left[-2\,t^{-
1/2}\right]_{n\pi}^{\infty} = \frac{1}{2}\cdot\frac{2}{\sqrt{n\pi}} = \frac{1}{\
sqrt{n\pi}}.$$
Hence
$$|J_m - J_n| = J_m - J_n \le \frac{1}{\sqrt{n\pi}}.$$

**Conclusion.** Given $\varepsilon > 0$, choose $N$ such that $\frac{1}{\sqrt{N\
pi}} < \varepsilon$ (possible since $\frac{1}{\sqrt{n\pi}}\to 0$). Then for all
$m > n \ge N$,
$$|J_m - J_n| \le \frac{1}{\sqrt{n\pi}} \le \frac{1}{\sqrt{N\pi}} < \varepsilon.
$$
By symmetry in $m,n$ (using monotonicity so that $|J_m-J_n|$ is the larger minus
 the smaller), this holds for all $m,n \ge N$. Therefore $(J_n)$ satisfies the C
auchy criterion.

**Remark (convergence).** The same estimate shows the improper integral $\int_0^
{\infty} f(t)\,dt$ converges: near $t=0$, $1-\cos t = O(t^2)$ gives $f(t)=O(t^{1
/2})$, integrable on $[0,1]$; on $[1,\infty)$, $f(t)\le \frac{1}{2}t^{-3/2}$, in
tegrable. Thus $(J_n)$ is in fact convergent (hence Cauchy).
