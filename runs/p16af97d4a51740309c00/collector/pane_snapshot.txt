Looking at this problem, I need to find the maximum $c$ such that $\{n\sqrt{2}\}
 \geq \frac{c}{n}$ for all $n \in \mathbb{N}$, then determine which $n$ achieve
equality.

## Proof

**Setup.** For each $n \geq 1$, let $m = \lfloor n\sqrt{2}\rfloor$, so $\{n\sqrt
{2}\} = n\sqrt{2} - m$. Since $\sqrt{2}$ is irrational, $\{n\sqrt{2}\} > 0$ for
all $n$.

**Key identity.** We compute:
$$n\{n\sqrt{2}\} = n(n\sqrt{2} - m) = \frac{n(2n^2 - m^2)}{n\sqrt{2} + m}.$$

Since $m < n\sqrt{2}$, we have $m^2 < 2n^2$, so $2n^2 - m^2$ is a **positive int
eger**, hence $2n^2 - m^2 \geq 1$.

**Lower bound.** Using $2n^2 - m^2 \geq 1$ and $m < n\sqrt{2}$ (so $n\sqrt{2} +
m < 2n\sqrt{2}$):
$$n\{n\sqrt{2}\} = \frac{n(2n^2 - m^2)}{n\sqrt{2} + m} \geq \frac{n \cdot 1}{n\s
qrt{2} + m} > \frac{n}{2n\sqrt{2}} = \frac{1}{2\sqrt{2}} = \frac{\sqrt{2}}{4}.$$

This strict inequality holds for **every** $n \geq 1$, so $c = \frac{\sqrt{2}}{4
}$ satisfies $\{n\sqrt{2}\} \geq \frac{c}{n}$ for all $n$.

**The bound is sharp (infimum is achieved in the limit).** Consider the converge
nts of $\sqrt{2} = [1; 2, 2, 2, \ldots]$: $p_k/q_k$ with recurrences $p_{k+1} =
2p_k + p_{k-1}$, $q_{k+1} = 2q_k + q_{k-1}$, starting $(p_0,q_0)=(1,1)$, $(p_1,q
_1)=(3,2)$.

These satisfy the Pell equation $p_k^2 - 2q_k^2 = (-1)^{k+1}$.

For **even** $k$: $p_k^2 - 2q_k^2 = -1$, i.e., $2q_k^2 - p_k^2 = 1$, and $p_k/q_
k < \sqrt{2}$ so $p_k = \lfloor q_k\sqrt{2}\rfloor$. Thus:
$$q_k\{q_k\sqrt{2}\} = \frac{q_k \cdot 1}{q_k\sqrt{2} + p_k} = \frac{1}{\sqrt{2}
 + p_k/q_k}.$$

For even $k$, the sequence $p_k/q_k$ is strictly increasing toward $\sqrt{2}$ (l
ower convergents), so $\sqrt{2} + p_k/q_k$ is strictly increasing, making $q_k\{
q_k\sqrt{2}\}$ **strictly decreasing** toward:
$$\frac{1}{\sqrt{2} + \sqrt{2}} = \frac{1}{2\sqrt{2}} = \frac{\sqrt{2}}{4}.$$

The first few values: $n=1$: $\sqrt{2}-1 \approx 0.4142$; $n=5$: $\approx 0.3553
$; $n=29$: $\approx 0.3536$; approaching $\frac{\sqrt{2}}{4} \approx 0.35355$.

**No $n$ achieves equality.** Equality $n\{n\sqrt{2}\} = \frac{1}{2\sqrt{2}}$ wo
uld require simultaneously:
- $2n^2 - m^2 = 1$ (to make the numerator minimal), and
- $n\sqrt{2} + m = 2n\sqrt{2}$, i.e., $m = n\sqrt{2}$.

But $m = n\sqrt{2}$ is impossible since $\sqrt{2}$ is irrational. Therefore the
infimum $\frac{\sqrt{2}}{4}$ is **never attained**.

**Conclusion.** The maximum $c$ is:
$$\boxed{\dfrac{\sqrt{2}}{4}}$$

and there are **no** $n \in \mathbb{N}$ for which $\{n\sqrt{2}\} = \dfrac{c}{n}$
 (the inequality is strict for every $n$).
