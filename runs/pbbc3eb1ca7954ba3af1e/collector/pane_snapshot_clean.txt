## Setup

Place Earth's center at the origin, radius R. South pole at **r**₀ = (0, −R), no
rth pole at (0, R). The orbit is an ellipse with focus at the origin.

**Key observation:** The orbital plane contains the origin (focus) and the launc
h point (south pole). Since the north pole is antipodal to the south pole (at −*
*r**₀), it lies on the same line through the origin, so **the orbital plane alwa
ys contains both poles**. The orbit intersects Earth's surface along a meridian
(great circle through both poles). I work in this 2D plane with the northern hem
isphere being y > 0.

**Launch velocity:** At the south pole, the outward radial (vertical) direction
is (0, −1). Launching at angle θ from vertical:
- Radial component (outward): v cos θ
- Tangential component: v sin θ (along the meridian)

So **v** = (v sin θ, −v cos θ), giving v_r = v cos θ > 0 (outward) and v_t = v s
in θ.

## Orbital Parameters

Define the dimensionless parameter α = Rv²/μ (where μ = GM). For an ellipse (bou
nd orbit), we need 0 < α < 2 (i.e., v below escape velocity).

Specific angular momentum: h = Rv sin θ, so the semi-latus rectum is p = h²/μ =
R²v²sin²θ/μ, giving p/R = α sin²θ.

Let ψ be the polar angle from the +x axis (Earth frame) and ψ_p the periapsis di
rection. The orbit equation is r = p/(1 + e cos(ψ − ψ_p)).

**At launch** (ψ₀ = −π/2, r = R):
- From r = R: 1 + e cos(−π/2 − ψ_p) = α sin²θ, which gives **e sin ψ_p = 1 − α s
in²θ**. …(1)
- From radial velocity v_r = (μ/h)e sin(ψ − ψ_p) at ψ = −π/2: v cos θ = −(μ/h)e
cos ψ_p, giving **e cos ψ_p = −α sin θ cos θ**. …(2)

## Finding the Crash Point

The orbit crosses r = R when 1 + e cos(ψ − ψ_p) = α sin²θ, i.e., cos(ψ − ψ_p) =
(α sin²θ − 1)/e = −sin ψ_p (using (1)).

This gives cos(ψ − ψ_p) = −sin ψ_p = cos(π/2 + ψ_p), so ψ − ψ_p = ±(π/2 + ψ_p).

- ψ = −π/2 → the launch point (south pole).
- **ψ₁ = π/2 + 2ψ_p** → the crash point.

The crash is in the **northern hemisphere** iff y₁ = R sin(ψ₁) = R cos(2ψ_p) > 0
, i.e., **cos(2ψ_p) > 0**.

## Expressing the Condition

From (1) and (2), let S = e sin ψ_p = 1 − αu and C = e cos ψ_p = −α sin θ cos θ,
 where u = sin²θ.

Then cos(2ψ_p) = (C² − S²)/(C² + S²), so **cos(2ψ_p) > 0 ⟺ C² > S²**.

Computing:
$$C^2 - S^2 = \alpha^2 u(1-u) - (1-\alpha u)^2 = u(1-2u)\alpha^2 + 2u\alpha - 1
\;=:\; f(\alpha, u).$$

So the crash is in the northern hemisphere iff **f(α, u) > 0** for some α ∈ (0,
2).

## Optimizing Over α

**Case u < 1/2 (θ < 45°):** f is an upward-opening parabola in α with vertex at
α* = −1/(1−2u) < 0, so f is increasing on (0, 2). The supremum is f(2, u) = −8u²
 + 8u − 1. Setting f(2,u) = 0:

$$8u^2 - 8u + 1 = 0 \implies u = \frac{2 \pm \sqrt{2}}{4}.$$

For u < 1/2, the relevant root is u₀ = (2 − √2)/4. Since f is increasing in α an
d approaches f(2,u) as α → 2⁻ (where e → 1, a parabola, not an ellipse), f(α, u)
 > 0 for some α < 2 **iff f(2, u) > 0**, i.e., **u > u₀ = (2−√2)/4**.

At u = u₀ exactly, f(2, u₀) = 0 but f < 0 for all α < 2 (since f is strictly inc
reasing and only reaches 0 in the parabolic limit), so no elliptical orbit achie
ves f > 0.

**Case u ≥ 1/2 (θ ≥ 45°):** One verifies f(2, u) = −8u² + 8u − 1 > 0 for u ∈ (1/
2, (2+√2)/4), and for u > 3/4 the parabola's vertex lies in (0,2) with f_max = (
1−u)/(2u−1) > 0. So f > 0 is always achievable. (And tan θ ≥ 1 > √2 − 1 here, so
 this doesn't affect the infimum.)

## Computing M

The crash can be in the northern hemisphere (for some launch speed) iff:

$$\sin^2\theta > \frac{2 - \sqrt{2}}{4} = \sin^2\!\left(\frac{\pi}{8}\right).$$

This threshold is **not achieved** by any ellipse (it requires the parabolic lim
it α → 2), so the condition is strict: θ > π/8.

Therefore:

$$\tan^2\theta > \tan^2\!\left(\frac{\pi}{8}\right) = \frac{\sin^2(\pi/8)}{\cos^
2(\pi/8)} = \frac{2-\sqrt{2}}{2+\sqrt{2}} = \frac{(2-\sqrt{2})^2}{2} = 3 - 2\sqr
t{2} = (\sqrt{2}-1)^2.$$

Since 0 < θ < 90°, tan θ > 0, so:

$$\tan\theta > \sqrt{2} - 1.$$

This bound is tight (approached by near-parabolic orbits with θ → π/8⁺), so the
maximal M is:

$$\boxed{M = \sqrt{2} - 1}$$
