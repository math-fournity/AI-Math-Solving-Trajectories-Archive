# Problem

A high-tech security firm is designing a centralized command hub shaped like a regular pentagonal pyramid. The hub consists of 6 specific server nodes: one central "Apex" node located at the top, and 5 "Peripheral" nodes arranged in a perfect regular pentagon forming the base.

The nodes are connected by physical data cables along every edge of the pyramid: 5 cables connect the Apex node to each of the Peripheral nodes, and 5 cables connect the Peripheral nodes in a ring (forming the base of the pyramid).

The firm has 6 different security encryption protocols available, and each node must be assigned exactly one protocol. To prevent cross-talk interference, any two nodes directly connected by a data cable must be assigned different protocols. 

The command hub is mounted on a swivel base, meaning two protocol configurations are considered identical if one can be transformed into the other by rotating the hub around the vertical axis passing through the Apex node.

Calculate the total number of distinct ways to assign the protocols to the nodes.
