## Solution

**Answer:** All functions of the form $f(x) = c(x-1)$ for an arbitrary constant
$c \in \mathbb{R}$.

### Verification that these work

For $f(x) = c(x-1)$: $f(xy) = c(xy-1)$ and $yf(x)+f(y) = yc(x-1)+c(y-1) = c(xy-1
)$, so equality holds for all $x,y$. ✓

### Proof these are the only solutions

**Step 1: Preliminary substitutions.** Setting $x=1$: $f(y) \le yf(1)+f(y)$, so
$yf(1)\ge 0$ for all $y$, giving $f(1)=0$.

Setting $x=0$: $f(0) \le yf(0)+f(y)$, so
$$f(y) \ge f(0)(1-y) \quad \text{for all } y. \tag{1}$$

**Step 2: Reduction to a nonnegative helper.** Define $g(x) = f(x) - f(0)(1-x)$.
 By (1), $g(x)\ge 0$ for all $x$, and $g(0)=0$, $g(1)=0$. Substituting $f(x)=g(x
)+f(0)(1-x)$ into the original inequality:

$$g(xy)+f(0)(1-xy) \le y\bigl[g(x)+f(0)(1-x)\bigr]+\bigl[g(y)+f(0)(1-y)\bigr].$$

The $f(0)$-terms cancel since $y(1-x)+(1-y)=1-xy$, leaving
$$g(xy)\le yg(x)+g(y) \quad \text{for all } x,y, \qquad g\ge 0,\; g(0)=g(1)=0. \
tag{2}$$

**Step 3: $g$ is bounded.** Setting $y=-1$ in (2): $g(-x)\le -g(x)+g(-1)$, i.e.,
$$g(-x)+g(x)\le g(-1) \quad \text{for all } x. \tag{3}$$
Since $g\ge 0$, this gives $g(x)\le g(-1)$ for every $x$; thus $g$ is bounded ab
ove by $g(-1)$.

**Step 4: Forcing $g(-1)=0$.** Setting $x=-1$ in (2): $g(-y)\le yg(-1)+g(y)$. Si
nce $g(-y)\ge 0$,
$$g(y)\ge -y\,g(-1).$$
For $y<0$ (write $y=-s$, $s>0$): $g(-s)\ge s\,g(-1)$. But from Step 3, $g(-s)\le
 g(-1)$. Therefore
$$s\,g(-1)\le g(-1) \quad \text{for all } s>0.$$
Taking $s>1$: if $g(-1)>0$ we get $s\le 1$, a contradiction. Hence $g(-1)=0$.

**Step 5: Conclusion.** With $g(-1)=0$, equation (3) gives $g(-x)+g(x)\le 0$. Co
mbined with $g\ge 0$, this forces $g(x)=0$ for all $x$.

Therefore $f(x)=f(0)(1-x)$, i.e., $f(x)=c(x-1)$ with $c=-f(0)\in\mathbb{R}$.
