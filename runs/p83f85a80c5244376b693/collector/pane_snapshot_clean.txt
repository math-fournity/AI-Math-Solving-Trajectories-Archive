# 解答

**答案：** $\lambda = -\dfrac{1}{27}$.

## 证明

### 建立框架

设 $f(x) = (x-r)(x-s)(x-t)$，其中 $r,s,t \geqslant 0$ 为三个根。则 $a = -(r+s+t)
$。记 $S = r+s+t \geqslant 0$，则 $x - a = x + S$。

当 $S = 0$ 时，$r=s=t=0$，$f(x)=x^3$，$a=0$，不等式变为 $x^3 \geqslant \lambda x
^3$，即 $\lambda \leqslant 1$，对 $\lambda = -1/27$ 自动成立。以下设 $S > 0$。

对 $x \geqslant 0$，$x + S > 0$，不等式 $f(x) \geqslant \lambda(x+S)^3$ 等价于
$$\frac{(x-r)(x-s)(x-t)}{(x+S)^3} \geqslant \lambda.$$
因此 $\lambda$ 的最大值为 $\inf \dfrac{(x-r)(x-s)(x-t)}{(x+S)^3}$，其中下确界取
遍所有 $x \geqslant 0$ 和 $r,s,t \geqslant 0$。

由齐次性（比值在 $(x,r,s,t) \mapsto (kx,kr,ks,kt)$ 下不变），可归一化 $S = r+s+t
 = 1$。需证：
$$G(x,r,s,t) := (x-r)(x-s)(x-t) + \frac{(x+1)^3}{27} \geqslant 0, \quad x \geqsl
ant 0,\; r,s,t \geqslant 0,\; r+s+t=1.$$

### 证明 $G \geqslant 0$

$G$ 是连续函数，且当 $x \to \infty$ 时 $G \to \infty$（主导项 $(28/27)x^3$），故
在紧集上取到最小值。

**内部临界点不存在。** 设 $r,s,t > 0$，$x > 0$ 为临界点。由 Lagrange 乘数法（约
束 $r+s+t=1$）：
$$-(x-s)(x-t) = -(x-r)(x-t) = -(x-r)(x-s) = \mu,$$
$$\frac{\partial G}{\partial x} = (x-s)(x-t)+(x-r)(x-t)+(x-r)(x-s)+\frac{(x+1)^2
}{9} = 0.$$

由前三个等式：若 $x \neq r,s,t$，则 $r=s=t=1/3$，此时 $\partial G/\partial x = 3
(x-1/3)^2 + (x+1)^2/9 > 0$，矛盾。若 $x$ 等于某个根（设 $x=t$），则 $\mu = 0$，
从而 $(x-r)(x-s)=0$，即 $x$ 等于另一个根，此时 $\partial G/\partial x = (x+1)^2/
9 > 0$，亦矛盾。故内部无临界点。

**边界 $x = 0$：** $G(0) = -rst + 1/27$。由 AM-GM，$rst \leqslant (S/3)^3 = 1/27
$，故 $G(0) \geqslant 0$，等号当且仅当 $r=s=t=1/3$。

**边界 $r = 0$（$s,t > 0$，$s+t=1$）：** $G = x(x-s)(x-t) + (x+1)^3/27$。内部临
界点要求 $s = t = 1/2$（由 Lagrange 条件），代入 $\partial G/\partial x = 0$ 得
$28x^2 - 16x + 13/4 = 0$，判别式 $= 256 - 364 < 0$，无实解。故此面上的最小值在子
边界取到。

**子边界 $r = s = 0$，$t = 1$（及对称情形）：**
$$G = x^2(x-1) + \frac{(x+1)^3}{27} = \frac{28x^3 - 24x^2 + 3x + 1}{27}.$$
因式分解：
$$28x^3 - 24x^2 + 3x + 1 = (2x-1)^2(7x+1).$$
（验证：$(2x-1)^2(7x+1) = (4x^2-4x+1)(7x+1) = 28x^3+4x^2-28x^2-4x+7x+1 = 28x^3-2
4x^2+3x+1$。✓）

对 $x \geqslant 0$：$(2x-1)^2 \geqslant 0$ 且 $7x+1 > 0$，故 $G \geqslant 0$，等
号当且仅当 $x = 1/2$。

由对称性，$s=0$、$t=0$ 的情形给出相同结论。

**综上**，$G \geqslant 0$ 恒成立，即 $(x-r)(x-s)(x-t) \geqslant -\dfrac{(x+S)^3}
{27}$ 对所有 $x \geqslant 0$，$r,s,t \geqslant 0$ 成立。

### $\lambda = -1/27$ 的最优性

上述等号 $G = 0$ 确实可以取到（见下方等号条件），故 infimum $= -1/27$ 被达到，$\
lambda = -1/27$ 是使不等式对所有满足条件的 $f$ 和所有 $x \geqslant 0$ 成立的最大
值。

### 等号条件

归一化 $S=1$ 下，$G = 0$ 当且仅当：

**情形 1：** $r = s = t = 1/3$，$x = 0$（即三根相等，$x=0$）。

验证：$G = (x-1/3)^3 + (x+1)^3/27 = \dfrac{4x(7x^2-6x+9)}{27}$，其中 $7x^2-6x+9$
 的判别式 $= 36-252 < 0$ 恒正，故 $G = 0$ 当且仅当 $x = 0$。✓

**情形 2：** $(r,s,t)$ 为 $(1,0,0)$ 的排列，$x = 1/2$（即恰一个非零根，$x$ 为该
根的一半）。

验证：$G = (2x-1)^2(7x+1)/27 = 0$ 当且仅当 $x = 1/2$。✓

**还原到一般 $S$：**

- **等号条件 1：** $r = s = t$（三根相等，$> 0$），$x = 0$。
- **等号条件 2：** 恰一个根非零（设为 $r > 0$，$s = t = 0$），$x = r/2$。
