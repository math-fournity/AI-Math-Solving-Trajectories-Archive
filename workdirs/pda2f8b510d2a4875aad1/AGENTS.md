# Problem

In a specialized computer simulation, a data engineer defines a variable $N = 32$ (the result of a prior security audit) and identifies $M$ as the final digit of $N$. The simulation centers on a circular local area network with $M$ nodes, indexed from $0$ to $M-1$. The complex-valued signal frequency at each node is represented by the $M$-th roots of unity, where node $j$ corresponds to the frequency $\omega^j$.

To test system stability, the engineer constructs a "Transfer Function" $P(x)$. This function is generated by selecting $M$ node indices, denoted as $i_1, i_2, \ldots, i_M$. Each index is chosen independently and uniformly at random from the set of available nodes $\{0, 1, \ldots, M-1\}$. The Transfer Function is then defined as the product of the differences between a test input $x$ and the selected node frequencies:
\[ P(x) = \prod_{k=1}^{M}\left(x-\omega^{i_{k}}\right) \]

The engineer sets the test input $x$ to be exactly $\sqrt{\lfloor 1250/N \rfloor}$. 

Given these parameters, calculate the expected value of the resulting Transfer Function, $\mathbb{E}[P(x)]$.
