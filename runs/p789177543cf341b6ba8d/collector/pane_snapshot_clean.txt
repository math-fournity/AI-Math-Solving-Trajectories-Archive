## Solution

We evaluate the iterated integral
$$I = \int_0^\infty\int_0^\infty \sin(x^2+y^2)\,dx\,dy.$$

**Key identity.** Using the addition formula for sine,
$$\sin(x^2+y^2) = \sin x^2\cos y^2 + \cos x^2\sin y^2.$$

Substituting and splitting (justified below),
$$I = \int_0^\infty\int_0^\infty \sin x^2\cos y^2\,dx\,dy + \int_0^\infty\int_0^
\infty \cos x^2\sin y^2\,dx\,dy.$$

**Evaluating the first term.** For the iterated integral, fix $y$ and integrate
over $x$ first. Since $\cos y^2$ is a constant with respect to $x$,
$$\int_0^\infty \sin x^2\cos y^2\,dx = \cos y^2\int_0^\infty \sin x^2\,dx = \cos
 y^2\cdot\tfrac{1}{2}\sqrt{\tfrac{\pi}{2}}.$$
The inner improper integral converges (Fresnel), so this is well-defined. Then
$$\int_0^\infty \cos y^2\cdot\tfrac{1}{2}\sqrt{\tfrac{\pi}{2}}\,dy = \tfrac{1}{2
}\sqrt{\tfrac{\pi}{2}}\int_0^\infty \cos y^2\,dy = \tfrac{1}{2}\sqrt{\tfrac{\pi}
{2}}\cdot\tfrac{1}{2}\sqrt{\tfrac{\pi}{2}} = \tfrac{\pi}{8}.$$

**Evaluating the second term.** By the identical argument (swapping the roles of
 $\sin$ and $\cos$),
$$\int_0^\infty\int_0^\infty \cos x^2\sin y^2\,dx\,dy = \left(\int_0^\infty \cos
 x^2\,dx\right)\left(\int_0^\infty \sin y^2\,dy\right) = \tfrac{\pi}{8}.$$

**Combining.**
$$I = \frac{\pi}{8} + \frac{\pi}{8} = \frac{\pi}{4}.$$

**Remark on why polar coordinates are not directly applicable.** Converting to p
olar coordinates gives $\int_0^{\pi/2}\int_0^\infty r\sin(r^2)\,dr\,d\theta$, wh
ose inner integral $\frac{1}{2}\int_0^\infty \sin u\,du$ does not converge as a
standard improper integral. This reflects that the double integral is not absolu
tely convergent, so the change of variables is not justified. The iterated integ
ral, however, is well-defined via the product decomposition above, since each Fr
esnel integral converges.

$$\boxed{\displaystyle\iint_C \sin(x^2+y^2)\,dx\,dy = \frac{\pi}{4}}$$
