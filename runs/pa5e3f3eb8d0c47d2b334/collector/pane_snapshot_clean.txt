## Proof

We evaluate
$$I = \int_0^\infty \frac{\ln^2(1+x)}{x^{3/2}}\,dx.$$

**Step 1: Integration by parts.** Take $u=\ln^2(1+x)$ and $dv=x^{-3/2}\,dx$, so
$v=-2x^{-1/2}$ and $du=\dfrac{2\ln(1+x)}{1+x}\,dx$. Then

$$I = \Big[-2x^{-1/2}\ln^2(1+x)\Big]_0^\infty + \int_0^\infty \frac{4\ln(1+x)}{\
sqrt{x}(1+x)}\,dx.$$

The boundary term vanishes: as $x\to\infty$, $x^{-1/2}\ln^2(1+x)\to 0$; as $x\to
 0^+$, $\ln(1+x)\sim x$, so $x^{-1/2}\ln^2(1+x)\sim x^{3/2}\to 0$. Hence

$$I = 4\int_0^\infty \frac{\ln(1+x)}{\sqrt{x}(1+x)}\,dx.$$

**Step 2: Substitute $x=t^2$** ($dx=2t\,dt$, $\sqrt{x}=t$, $1+x=1+t^2$):

$$I = 4\int_0^\infty \frac{\ln(1+t^2)}{t(1+t^2)}\cdot 2t\,dt = 8\int_0^\infty \f
rac{\ln(1+t^2)}{1+t^2}\,dt.$$

**Step 3: Substitute $t=\tan\theta$** ($dt=\sec^2\theta\,d\theta$, $1+t^2=\sec^2
\theta$, $\theta\in[0,\pi/2)$):

$$I = 8\int_0^{\pi/2} \frac{\ln(\sec^2\theta)}{\sec^2\theta}\,\sec^2\theta\,d\th
eta = 8\int_0^{\pi/2}\ln(\sec^2\theta)\,d\theta = -16\int_0^{\pi/2}\ln\cos\theta
\,d\theta.$$

**Step 4: The classical integral.** Let $J=\int_0^{\pi/2}\ln\cos\theta\,d\theta$
. By $\theta\mapsto \pi/2-\theta$, also $J=\int_0^{\pi/2}\ln\sin\theta\,d\theta$
. Adding,

$$2J = \int_0^{\pi/2}\ln(\sin\theta\cos\theta)\,d\theta = \int_0^{\pi/2}\ln\!\le
ft(\tfrac12\sin 2\theta\right)d\theta = \int_0^{\pi/2}\ln\sin 2\theta\,d\theta -
 \tfrac{\pi}{2}\ln 2.$$

For the remaining integral, set $u=2\theta$:

$$\int_0^{\pi/2}\ln\sin 2\theta\,d\theta = \tfrac12\int_0^{\pi}\ln\sin u\,du = \
int_0^{\pi/2}\ln\sin u\,du = J,$$

using the symmetry $\sin u = \sin(\pi-u)$. Therefore $2J = J - \tfrac{\pi}{2}\ln
 2$, giving

$$J = -\tfrac{\pi}{2}\ln 2.$$

**Conclusion.**

$$I = -16\,J = -16\!\left(-\tfrac{\pi}{2}\ln 2\right) = 8\pi\ln 2.$$

$$\boxed{\displaystyle\int_0^\infty \frac{\ln^2(1+x)}{x^{3/2}}\,dx = 8\pi\ln 2.}
$$
