Looking at the problem, I need to find all $a > 0$ such that there exists a nonn
egative continuous $f$ on $[0,a]$ where the region under $f$ has equal perimeter
 and area.

**Setting up the perimeter and area.**

The region $R = \{(x,y): 0 \le x \le a,\, 0 \le y \le f(x)\}$ has boundary consi
sting of four pieces:
- Bottom: $(0,0) \to (a,0)$, length $a$
- Right: $(a,0) \to (a,f(a))$, length $f(a)$
- Top: graph of $f$ from $(0,f(0))$ to $(a,f(a))$, arc length $L$
- Left: $(0,f(0)) \to (0,0)$, length $f(0)$

So $P = a + f(0) + f(a) + L$ and $A = \int_0^a f(x)\,dx$. We need $P = A = k$.

**Construction for $a > 2$.**

Take $f(x) = c$ (constant). Then $L = a$, $f(0) = f(a) = c$, so:
$$P = 2a + 2c, \quad A = ac.$$
Setting $A = P$: $ac = 2a + 2c \implies c(a-2) = 2a \implies c = \frac{2a}{a-2}$
.

For $a > 2$, this gives $c > 0$, a valid nonnegative continuous function, with $
k = \frac{2a^2}{a-2}$.

**Impossibility for $0 < a \le 2$.**

If the graph of $f$ is non-rectifiable, then $L = \infty$ so $P = \infty > A$, a
nd $P \ne A$. So assume the graph is rectifiable with finite arc length $L$.

**Key inequality.** For any $x \in [0,a]$, let $L_1(x)$ be the arc length of the
 graph from $0$ to $x$, and $L_2(x)$ the arc length from $x$ to $a$, so $L_1(x)
+ L_2(x) = L$. Since arc length dominates vertical displacement:
$$f(x) - f(0) \le |f(x) - f(0)| \le L_1(x), \quad f(x) - f(a) \le |f(x) - f(a)|
\le L_2(x).$$
Thus $f(x) \le f(0) + L_1(x)$ and $f(x) \le f(a) + L_2(x)$. Since $\min(u,v) \le
 \frac{u+v}{2}$:
$$f(x) \le \tfrac{1}{2}\bigl(f(0) + f(a) + L_1(x) + L_2(x)\bigr) = \tfrac{1}{2}\
bigl(f(0) + f(a) + L\bigr).$$

Integrating over $[0,a]$:
$$A = \int_0^a f(x)\,dx \le \frac{a}{2}\bigl(f(0) + f(a) + L\bigr).$$

For $a \le 2$, $\frac{a}{2} \le 1$, so:
$$A \le f(0) + f(a) + L < a + f(0) + f(a) + L = P,$$
where the strict inequality uses $a > 0$. Therefore $A < P$ for every nonnegativ
e continuous $f$ when $0 < a \le 2$, making $A = P$ impossible.

**Conclusion.** The set of all $a > 0$ for which such a function exists is $\box
ed{a > 2}$.
