**Answer: No, $E \setminus O$ is not always a Borel set.**

**Proof.**

We construct an explicit counterexample.

**Setup.** Work in the metric space $(\mathbb{R}, |\cdot|)$ equipped with Lebesg
ue (outer) measure. Recall that a set has *measure zero* if its outer measure is
 $0$, equivalently, it is contained in a Borel set of measure zero.

**The compact set.** Let $E = [0,1]$. This is closed and bounded in $\mathbb{R}$
, hence compact. Being closed, $E$ is a Borel set.

**The Cantor set.** Let $C \subseteq [0,1]$ be the standard middle-thirds Cantor
 set. Then:
- $C$ is closed (hence compact, hence Borel),
- $C$ has Lebesgue measure $0$,
- $|C| = \mathfrak{c}$ (the cardinality of the continuum), since $C$ is in bijec
tion with $\{0,1\}^{\mathbb{N}}$.

**A non-Borel measure-zero set.** Since $|C| = \mathfrak{c}$, the power set $\ma
thcal{P}(C)$ has cardinality $2^{\mathfrak{c}}$. On the other hand, the collecti
on of Borel subsets of $\mathbb{R}$ has cardinality $\mathfrak{c}$ (generated by
 countable operations on a countable base). Therefore:

$$|\{B \cap C : B \in \text{Borel}(\mathbb{R})\}| \le \mathfrak{c} < 2^{\mathfra
k{c}} = |\mathcal{P}(C)|.$$

So there exists a subset $O \subseteq C$ that is **not** a Borel set. Since $O \
subseteq C$ and $C$ has measure zero, $O$ has outer measure zero, i.e., $O$ is a
 **measure zero set**.

**The set difference is not Borel.** Consider $E \setminus O = [0,1] \setminus O
$. Suppose for contradiction that $[0,1] \setminus O$ is Borel. Then:

$$O = [0,1] \setminus \bigl([0,1] \setminus O\bigr) = [0,1] \cap \bigl([0,1] \se
tminus O\bigr)^{c}.$$

Since $[0,1]$ is Borel and $[0,1]\setminus O$ is Borel (by assumption), their se
t-theoretic difference is Borel. This means $O$ is Borel — **contradicting** the
 choice of $O$ as a non-Borel set.

Therefore $[0,1] \setminus O$ is **not** a Borel set.

**Conclusion.** We have exhibited a compact set $E = [0,1]$ in the metric space
$\mathbb{R}$ and a measure-zero set $O \subseteq C$ (a non-Borel subset of the C
antor set) such that $E \setminus O$ is not Borel. Hence $E \setminus O$ is **no
t** always a Borel set. $\blacksquare$
