## Proof

Let $p > 2$ be prime. A "Symmetry Node" is a quadratic residue modulo $p$, **inc
luding $0$** (since $0 \equiv 0^2 \pmod p$). The set of quadratic residues (with
 $0$) has cardinality $(p+1)/2$.

We seek
$$N = \#\{n \in \{0,\dots,p-1\} : n \text{ and } n+1 \text{ are both quadratic r
esidues}\}.$$

Let $\chi$ be the Legendre symbol, extended by $\chi(0)=0$, and let $\delta(a) =
 1$ if $a\equiv 0\pmod p$, else $0$. The indicator that $a$ is a quadratic resid
ue (including $0$) is
$$I(a) = \frac{1+\chi(a)+\delta(a)}{2},$$
since for $a\not\equiv 0$ it equals $(1+\chi(a))/2$, and for $a\equiv 0$ it equa
ls $(1+0+1)/2=1$.

Then
$$N = \sum_{n=0}^{p-1} I(n)\,I(n+1) = \frac14\sum_{n=0}^{p-1}\bigl(1+\chi(n)+\de
lta(n)\bigr)\bigl(1+\chi(n+1)+\delta(n+1)\bigr).$$

Expanding and summing each term over $n=0,\dots,p-1$ (with $n+1$ taken mod $p$):

| Term | Value | Reason |
|------|-------|--------|
| $\sum 1$ | $p$ | |
| $\sum \chi(n)$ | $0$ | $\chi$ balanced |
| $\sum \delta(n)$ | $1$ | only $n=0$ |
| $\sum \chi(n+1)$ | $0$ | $\chi$ balanced |
| $\sum \chi(n)\chi(n+1)$ | $-1$ | $\sum\chi(n(n+1))=-1$ (standard: $x^2-y^2=1$
has $p-1$ solutions) |
| $\sum \delta(n)\chi(n+1)$ | $\chi(1)=1$ | only $n=0$ |
| $\sum \delta(n+1)$ | $1$ | only $n=p-1$ |
| $\sum \chi(n)\delta(n+1)$ | $\chi(-1)$ | only $n=p-1$ |
| $\sum \delta(n)\delta(n+1)$ | $0$ | never both zero |

Hence
$$N = \frac14\bigl[p + 0 + 1 + 0 - 1 + 1 + 1 + \chi(-1) + 0\bigr] = \frac14\bigl
[p + 2 + \chi(-1)\bigr].$$

Since $\chi(-1) = (-1)^{(p-1)/2}$, we obtain

$$\boxed{N = \dfrac{p + 2 + (-1)^{(p-1)/2}}{4}}.$$

**Verification.**
- $p=3$: residues $\{0,1\}$; only $n=0$ works $\Rightarrow N=1$; formula $(3+2-1
)/4=1$. ✓
- $p=5$: residues $\{0,1,4\}$; $n=0,4$ work $\Rightarrow N=2$; formula $(5+2+1)/
4=2$. ✓
- $p=7$: residues $\{0,1,2,4\}$; $n=0,1$ work $\Rightarrow N=2$; formula $(7+2-1
)/4=2$. ✓
