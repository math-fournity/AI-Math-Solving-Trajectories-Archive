## Solution

**Step 1: Trigonometric simplification.**

Use $\cos^2(x) = \frac{1+\cos(2x)}{2}$:

$$2\sin(x)\cos^2(x) = \sin(x)(1+\cos(2x)) = \sin(x) + \sin(x)\cos(2x).$$

Apply the product-to-sum formula $\sin(x)\cos(2x) = \tfrac{1}{2}[\sin(3x)+\sin(-
x)] = \tfrac{1}{2}[\sin(3x)-\sin(x)]$:

$$2\sin(x)\cos^2(x) = \sin(x) + \tfrac{1}{2}\sin(3x) - \tfrac{1}{2}\sin(x) = \tf
rac{1}{2}\sin(x) + \tfrac{1}{2}\sin(3x).$$

**Step 2: Split the integral.**

$$I = \int_0^{\infty} \frac{2\sin(x)\cos^2(x)}{x}\,e^{-x\sqrt{3}}\,dx = \frac{1}
{2}\int_0^{\infty}\frac{\sin x}{x}\,e^{-x\sqrt{3}}\,dx + \frac{1}{2}\int_0^{\inf
ty}\frac{\sin(3x)}{x}\,e^{-x\sqrt{3}}\,dx.$$

**Step 3: Apply the standard Laplace–Frullani identity.**

For $a,b>0$:
$$F(a) := \int_0^{\infty}\frac{\sin(ax)}{x}\,e^{-bx}\,dx.$$

Differentiating under the integral sign (justified by dominated convergence sinc
e $|\cos(ax)e^{-bx}|\le e^{-bx}$, integrable on $[0,\infty)$):

$$F'(a) = \int_0^{\infty}\cos(ax)\,e^{-bx}\,dx = \frac{b}{a^2+b^2}.$$

Integrating and using $F(0)=0$:

$$F(a) = \arctan\!\left(\frac{a}{b}\right).$$

**Step 4: Evaluate each piece with $b=\sqrt{3}$.**

- $a=1$: $\;F(1)=\arctan\!\left(\tfrac{1}{\sqrt{3}}\right)=\arctan\!\left(\tfrac
{\sqrt{3}}{3}\right)=\dfrac{\pi}{6}.$
- $a=3$: $\;F(3)=\arctan\!\left(\tfrac{3}{\sqrt{3}}\right)=\arctan(\sqrt{3})=\df
rac{\pi}{3}.$

**Step 5: Combine.**

$$I = \frac{1}{2}\cdot\frac{\pi}{6} + \frac{1}{2}\cdot\frac{\pi}{3} = \frac{\pi}
{12}+\frac{\pi}{6} = \frac{\pi}{12}+\frac{2\pi}{12} = \frac{3\pi}{12} = \boxed{\
dfrac{\pi}{4}}.$$
