## Solution

### Step 1: Convert to polar coordinates

Let $x = r\cos\theta$, $y = r\sin\theta$, so $x^2+y^2 = r^2$.

**Radial equation.** Using $\dot r = (x\dot x + y\dot y)/r$:

$$x\dot x + y\dot y = x(x+y-xr^2) + y(-x+y-yr^2)$$
$$= x^2 + xy - x^2 r^2 - xy + y^2 - y^2 r^2 = r^2 - r^4 = r^2(1-r^2).$$

Hence
$$\dot r = r(1-r^2).$$

**Angular equation.** Using $\dot\theta = (x\dot y - y\dot x)/r^2$:

$$x\dot y - y\dot x = x(-x+y-yr^2) - y(x+y-xr^2)$$
$$= -x^2+xy-xyr^2 - xy - y^2 + xyr^2 = -(x^2+y^2) = -r^2.$$

Hence
$$\dot\theta = -1.$$

### Step 2: Solve for $r(t)$ and $\theta(t)$

The angular equation integrates immediately:
$$\boxed{\theta(t) = \theta_0 - t.}$$

For $r$, set $u = r^2$, so $\dot u = 2r\dot r = 2r^2(1-r^2) = 2u(1-u)$, the logi
stic equation. With $u(0)=u_0=r_0^2$:

$$u(t) = \frac{u_0\, e^{2t}}{1 - u_0 + u_0\, e^{2t}} = \frac{1}{1 + (u_0^{-1}-1)
e^{-2t}}.$$

Therefore
$$\boxed{r(t) = \frac{r_0\, e^{t}}{\sqrt{\,1 + r_0^2(e^{2t}-1)\,}}.}$$

(As $t\to\infty$, $r(t)\to 1$ for any $r_0>0$, confirming the stable limit cycle
 at $r=1$.)

### Step 3: Poincaré section and return time

The section is $\Sigma = \{\theta = 0,\ r>0\}$. Since $\dot\theta = -1$ is const
ant, a trajectory starting at $\theta=0$ returns to $\theta \equiv 0 \pmod{2\pi}
$ after time
$$T = 2\pi.$$

### Step 4: Difference equation for the Poincaré sequence

Let $r_n$ denote the $n$-th intersection with $\Sigma$, with $r_0$ the initial v
alue. Setting $t = T = 2\pi$ in the radial solution gives the Poincaré map $P(r_
n) = r_{n+1}$:

$$\boxed{r_{n+1} = \frac{r_n\, e^{2\pi}}{\sqrt{\,1 + r_n^2\!\left(e^{4\pi}-1\rig
ht)\,}}, \qquad r_n > 0.}$$

**Equivalent form** (in terms of $s_n = r_n^2$, with $a = e^{4\pi}$):

$$s_{n+1} = \frac{a\, s_n}{1 + (a-1)\,s_n}, \qquad a = e^{4\pi}.$$

**Fixed point:** $s^* = \frac{a\,s^*}{1+(a-1)s^*} \Rightarrow 1+(a-1)s^* = a \Ri
ghtarrow s^* = 1$, i.e. $r^* = 1$, the limit cycle. Since $P'(1) = e^{-2\pi} < 1
$, the fixed point is stable — consistent with the attracting nature of the limi
t cycle $r=1$.
