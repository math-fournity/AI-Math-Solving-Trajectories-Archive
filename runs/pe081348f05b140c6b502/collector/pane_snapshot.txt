## Functional Derivative of $J(y) = \int_{x_0}^{x_1} \left(y^6(x) + 3y^2(x)\righ
t) dx$

### Setup

Let the integrand (Lagrangian) be
$$L(y) = y^6 + 3y^2,$$
so that $J[y] = \int_{x_0}^{x_1} L(y(x))\, dx$.

The functional derivative $\frac{\delta J}{\delta y(x)}$ is defined by the relat
ion
$$\delta J = \int_{x_0}^{x_1} \frac{\delta J}{\delta y(x)}\, \delta y(x)\, dx$$
holding to first order for every admissible variation $\delta y$.

### Computing the first variation

Perturb $y \mapsto y + \varepsilon\, \eta$, where $\eta$ is an arbitrary test fu
nction with $\eta(x_0)=\eta(x_1)=0$ (so the boundary terms vanish). Then

$$J[y + \varepsilon\eta] = \int_{x_0}^{x_1} \Big((y+\varepsilon\eta)^6 + 3(y+\va
repsilon\eta)^2\Big)\, dx.$$

Differentiating under the integral sign with respect to $\varepsilon$ and evalua
ting at $\varepsilon = 0$:

$$\left.\frac{d}{d\varepsilon}J[y+\varepsilon\eta]\right|_{\varepsilon=0} = \int
_{x_0}^{x_1} \left(6y^5(x)\,\eta(x) + 6y(x)\,\eta(x)\right) dx.$$

This uses the ordinary chain rule on $L$:
$$\frac{\partial L}{\partial y} = 6y^5 + 6y,$$
noting that $L$ depends on $y$ only (not on $y'$ or higher derivatives), so no i
ntegration-by-parts term involving $\frac{\partial L}{\partial y'}$ appears.

### Identifying the functional derivative

Factoring out the test function:

$$\delta J = \int_{x_0}^{x_1} \big(6y^5(x) + 6y(x)\big)\,\eta(x)\, dx.$$

Since this must hold for **every** admissible $\eta$, by the fundamental lemma o
f the calculus of variations the bracketed factor must equal the functional deri
vative pointwise:

$$\boxed{\frac{\delta J}{\delta y(x)} = 6y^5(x) + 6y(x) = 6y(x)\big(y^4(x) + 1\b
ig).}$$

### Verification (Euler–Lagrange consistency check)

The Euler–Lagrange equation for an extremal of $J$ is
$$\frac{\delta J}{\delta y} = \frac{\partial L}{\partial y} - \frac{d}{dx}\frac{
\partial L}{\partial y'} = 0.$$

Here $L = y^6 + 3y^2$ has no $y'$ dependence, so $\frac{\partial L}{\partial y'}
 = 0$ and the equation reduces to
$$\frac{\partial L}{\partial y} = 6y^5 + 6y = 0 \implies 6y(y^4+1)=0.$$

For real-valued $y$, $y^4+1 > 0$, so the only real extremal is $y \equiv 0$. Thi
s is consistent with the computed functional derivative and confirms its correct
ness: the integrand $y^6+3y^2 \ge 0$ is minimized at $y=0$.

### Result

$$\frac{\delta J}{\delta y(x)} = 6y^5(x) + 6y(x).$$
