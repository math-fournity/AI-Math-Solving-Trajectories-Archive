## Proof

**Key observation.** A homeomorphism f: ℝ → ℝ is a continuous bijection, hence s
trictly monotone. If f is strictly decreasing, then g(x) = f(x) − x is strictly
decreasing (as the sum of two strictly decreasing functions), so g has exactly o
ne zero — giving exactly one fixed point. Thus decreasing homeomorphisms always
yield exactly 1 fixed point. For arbitrary n, we use **strictly increasing** hom
eomorphisms, where the fixed-point set can be controlled.

**Preliminary fact.** If f: ℝ → ℝ is continuous, strictly increasing, and satisf
ies lim_{x→−∞} f(x) = −∞ and lim_{x→+∞} f(x) = +∞, then f is a bijection ℝ → ℝ,
and its inverse is continuous (standard theorem: the inverse of a continuous str
ictly monotone function on ℝ is continuous). Hence f is a homeomorphism.

---

### Case n = 0

Define **f(x) = x + 1**. This is continuous, strictly increasing, bijective (inv
erse: x ↦ x − 1), hence a homeomorphism. The equation f(x) = x gives x + 1 = x,
i.e., 1 = 0, which is impossible. So f has **0 fixed points**. ✓

---

### Case n ≥ 1

We construct f with fixed points exactly at {0, 1, 2, …, n−1}.

**Definition of f (piecewise):**

$$f(x) = \begin{cases} \dfrac{x}{2}, & x \le 0, \\[6pt] k + (x - k)^2, & x \in [
k,\, k+1], \quad k = 0, 1, \dots, n-2, \\[6pt] 2x - (n-1), & x \ge n-1. \end{cas
es}$$

**Verification that f is well-defined and continuous.** We check the junction po
ints:

- **At x = 0:** From the left, f(0) = 0/2 = 0. From the right (k=0 piece), f(0)
= 0 + (0−0)² = 0. ✓
- **At x = k for k = 1, …, n−2:** From the left (k−1 piece): f(k) = (k−1) + (k −
 (k−1))² = (k−1) + 1 = k. From the right (k piece): f(k) = k + (k − k)² = k. ✓
- **At x = n−1:** From the left (n−2 piece): f(n−1) = (n−2) + (n−1 − (n−2))² = (
n−2) + 1 = n−1. From the right: f(n−1) = 2(n−1) − (n−1) = n−1. ✓

So f is continuous on all of ℝ.

**Verification that f is strictly increasing.** On each piece:
- On (−∞, 0]: f(x) = x/2, derivative 1/2 > 0. ✓
- On [k, k+1]: f(x) = k + (x−k)². Since x − k ∈ [0, 1] and t ↦ t² is strictly in
creasing on [0, ∞), f is strictly increasing on [k, k+1]. ✓
- On [n−1, ∞): f(x) = 2x − (n−1), derivative 2 > 0. ✓

At each junction, the left value equals the right value and the function is stri
ctly increasing on each side, so f is strictly increasing on all of ℝ.

**Verification that f is surjective (hence bijective).** We have:
$$\lim_{x \to -\infty} f(x) = \lim_{x \to -\infty} \frac{x}{2} = -\infty, \qquad
 \lim_{x \to +\infty} f(x) = \lim_{x \to +\infty} (2x - (n-1)) = +\infty.$$

Since f is continuous and strictly increasing with these limits, by the Intermed
iate Value Theorem f is surjective onto ℝ. Combined with strict monotonicity (in
jectivity), f is a bijection. By the preliminary fact, **f is a homeomorphism**.

**Verification of the fixed-point set.** We solve f(x) = x on each piece:

- **On (−∞, 0):** f(x) = x/2 = x ⟹ x = 0, which is not in (−∞, 0). No fixed poin
t. At x = 0: f(0) = 0. ✓ **Fixed point.**

- **On (k, k+1) for k = 0, …, n−2:** f(x) − x = k + (x−k)² − x = (x−k)² − (x−k)
= (x−k)(x−k−1). For x ∈ (k, k+1), we have x−k ∈ (0,1), so (x−k) > 0 and (x−k−1)
< 0, giving f(x) − x < 0. Thus f(x) ≠ x; **no fixed point** in the open interval
. At the endpoints x = k and x = k+1: f(k) = k and f(k+1) = k+1. ✓ **Fixed point
s at each integer 0, 1, …, n−1.**

- **On (n−1, ∞):** f(x) − x = 2x − (n−1) − x = x − (n−1) > 0 for x > n−1. Thus f
(x) ≠ x; **no fixed point**. At x = n−1: already counted as a fixed point.

**Conclusion:** The fixed points of f are exactly {0, 1, 2, …, n−1}, which is a
set of **n distinct fixed points**. ✓

---

### Summary

| n | Homeomorphism | Fixed points |
|---|---|---|
| 0 | f(x) = x + 1 | ∅ (0 points) |
| n ≥ 1 | Piecewise f as defined above | {0, 1, …, n−1} (n points) |

For every n ∈ ℕ, we have exhibited a homeomorphism of ℝ with exactly n fixed poi
nts. $\blacksquare$
