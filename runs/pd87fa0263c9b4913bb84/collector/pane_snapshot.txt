## 解答

**答案：否。** 下面给出一个反例：去掉顶点的圆锥。

### 构造

取 $0 < a < 1$，令 $b = \sqrt{1-a^2}$，定义曲面

$$S = \{(ar\cos\theta,\; ar\sin\theta,\; br) : r > 0,\; 0 \le \theta < 2\pi\} \s
ubset \mathbb{R}^3.$$

这是一个去掉了顶点的正圆锥。参数化 $X(r,\theta) = (ar\cos\theta, ar\sin\theta, b
r)$（$r > 0$）光滑且微分单射，所以 $S$ 是 $\mathbb{R}^3$ 中的正则曲面。

### 常曲率

$S$ 是旋转曲面，母线 $f(r) = ar$，$g(r) = br$，满足 $f'^2 + g'^2 = a^2 + b^2 = 1
$（弧长参数化）。旋转曲面在此条件下的 Gauss 曲率为

$$K = -\frac{f''}{f}.$$

由于 $f(r) = ar$ 是线性的，$f'' = 0$，故 $K = 0$ 处处成立。**$S$ 具有常 Gauss 曲
率。**

### $S$ 不是齐性的

$S$ 上的诱导度量为

$$ds^2 = dr^2 + a^2 r^2\, d\theta^2, \quad r > 0,\; 0 \le \theta < 2\pi.$$

作变量替换 $u = r\cos(a\theta)$，$v = r\sin(a\theta)$，则 $ds^2 = du^2 + dv^2$（
标准欧氏度量）。在此映射下，$S$ 对应于 $(u,v)$ 平面上角度为 $2\pi a$ 的扇形 $\{(
u,v) : 0 \le \arg(u+iv) < 2\pi a\}$，其两条边界射线（$\arg = 0$ 与 $\arg = 2\pi
a$）被等同。原点 $(0,0)$ 对应于（已去掉的）顶点，不属于 $S$。

$S$ 的任何等距变换都是欧氏度量 $du^2+dv^2$ 的等距变换（即欧氏运动 $T(\mathbf{x})
 = R\mathbf{x} + \mathbf{t}$），且必须保持扇形及其边界等同结构。由于 $a \neq 1$
（故 $2\pi a \neq 2\pi$），该扇形是一个**真扇形**，具有唯一的顶点（原点）。欧氏
运动要保持此扇形不变，必须将顶点映到顶点，即 $\mathbf{t} = \mathbf{0}$。因此，**
$S$ 的每个等距变换都固定原点**，从而保持 $r = \sqrt{u^2 + v^2}$。

取 $p_1 = (a, 0, b)$（$r=1$）和 $p_2 = (2a, 0, 2b)$（$r=2$）。由于所有等距变换保
持 $r$，不存在等距变换 $f: S \to S$ 使 $f(p_1) = p_2$。**$S$ 不是齐性的。**

### 结论

去掉顶点的圆锥 $S \subset \mathbb{R}^3$ 具有常 Gauss 曲率 $K = 0$，但不是齐性的
。因此，常 Gauss 曲率**不必然**蕴含齐性。
