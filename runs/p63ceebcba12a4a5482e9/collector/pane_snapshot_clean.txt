## Proof

Let $X \sim \text{Poisson}(\lambda)$, and let the $k^{\text{th}}$ factorial mome
nt be
$$F_k = E\big[(X)_k\big] = E\big[X(X-1)(X-2)\cdots(X-k+1)\big], \qquad F_0 = 1.$
$

We use the given identity (Stein–Chen):
$$E\big[(X-\lambda)\,g(X)\big] = \lambda\,E\big[g(X+1)-g(X)\big].$$

**Setup.** Choose
$$g(X) = (X-1)(X-2)\cdots(X-k+1) = (X-1)_{k-1},$$
so that $X\cdot g(X) = X(X-1)\cdots(X-k+1) = (X)_k$. Writing $X = (X-\lambda)+\l
ambda$,

$$F_k = E\big[(X)_k\big] = E\big[(X-\lambda)\,g(X)\big] + \lambda\,E\big[g(X)\bi
g].$$

**Apply the identity** to the first term:
$$E\big[(X-\lambda)\,g(X)\big] = \lambda\,E\big[g(X+1)-g(X)\big].$$

Compute the two values of $g$:
- $g(X+1) = X(X-1)\cdots(X-k+2) = (X)_{k-1}$,
- $g(X) = (X-1)(X-2)\cdots(X-k+1) = (X-1)_{k-1}$.

Therefore
$$F_k = \lambda\,E\big[(X)_{k-1} - (X-1)_{k-1}\big] + \lambda\,E\big[(X-1)_{k-1}
\big].$$

**The shifted terms cancel:**
$$F_k = \lambda\,E\big[(X)_{k-1}\big] - \lambda\,E\big[(X-1)_{k-1}\big] + \lambd
a\,E\big[(X-1)_{k-1}\big] = \lambda\,E\big[(X)_{k-1}\big] = \lambda\,F_{k-1}.$$

**Recursion.** We obtain the simple recurrence
$$F_k = \lambda\,F_{k-1}, \qquad F_0 = E[1] = 1.$$

Unrolling:
$$F_k = \lambda\,F_{k-1} = \lambda^2 F_{k-2} = \cdots = \lambda^k F_0 = \lambda^
k.$$

**Result.** The $k^{\text{th}}$ factorial moment of a Poisson$(\lambda)$ random
variable is

$$\boxed{E\big[X(X-1)\cdots(X-k+1)\big] = \lambda^k.}$$
