## Solution

**Conformal map.** Consider the Möbius transformation

$$w = \phi(z) = i\,\frac{1-z}{1+z}, \qquad |z|<1.$$

This maps the unit disc $\{|z|<1\}$ conformally onto the upper half-plane $\{\op
eratorname{Im} w > 0\}$. To see where the boundary goes, set $z = e^{i\theta}$:

$$\frac{1-e^{i\theta}}{1+e^{i\theta}} = \frac{-2i\,e^{i\theta/2}\sin(\theta/2)}{
2\,e^{i\theta/2}\cos(\theta/2)} = -i\tan(\theta/2),$$

so $w = i\cdot(-i\tan(\theta/2)) = \tan(\theta/2) \in \mathbb{R}$. Specifically:

- $0 < \theta < \pi \Rightarrow \tan(\theta/2) > 0$: the **upper** semicircle ma
ps to $(0,+\infty)$.
- $\pi < \theta < 2\pi \Rightarrow \tan(\theta/2) < 0$: the **lower** semicircle
 maps to $(-\infty, 0)$.

**Harmonic function on the upper half-plane.** We need a harmonic function $V(w)
$ on $\{\operatorname{Im} w > 0\}$ with boundary values $+1$ on $(0,\infty)$ and
 $-1$ on $(-\infty,0)$. The function

$$V(w) = 1 - \frac{2}{\pi}\operatorname{Arg}(w), \qquad 0 < \operatorname{Arg}(w
) < \pi,$$

is harmonic (it is the imaginary part of an analytic function, up to constants)
and satisfies:
- $w \to (0,\infty)$: $\operatorname{Arg}(w) \to 0$, so $V \to 1$. ✓
- $w \to (-\infty,0)$: $\operatorname{Arg}(w) \to \pi$, so $V \to 1 - 2 = -1$. ✓

**Pull back to the disc.** Setting $U(z) = V(\phi(z))$:

$$U(z) = 1 - \frac{2}{\pi}\operatorname{Arg}\!\left(i\,\frac{1-z}{1+z}\right).$$

Since $\phi(z)$ lies in the upper half-plane for $|z|<1$, the argument satisfies
 $0 < \operatorname{Arg}(\phi(z)) < \pi$, giving a single-valued harmonic functi
on.

**Simplification.** Write the argument via the principal logarithm. Since for $|
z|<1$ the quantity $\frac{1+z}{1-z}$ has positive real part (a direct computatio
n gives $\operatorname{Re}\frac{1+z}{1-z} = \frac{1-|z|^2}{|1-z|^2} > 0$), it li
es in the right half-plane, where the **principal branch** $\operatorname{Log}$
(with $-\pi < \operatorname{Im}\operatorname{Log} < \pi$) is single-valued and a
nalytic. Using $\operatorname{Arg}(i(1-z)/(1+z)) = \frac{\pi}{2} + \operatorname
{Im}\operatorname{Log}\frac{1-z}{1+z}$ and $\operatorname{Log}\frac{1-z}{1+z} =
-\operatorname{Log}\frac{1+z}{1-z}$ (both arguments in the right half-plane):

$$\boxed{U(z) = \frac{2}{\pi}\,\operatorname{Im}\operatorname{Log}\!\left(\frac{
1+z}{1-z}\right), \qquad |z|<1,}$$

where $\operatorname{Log}$ is the **principal branch of the logarithm** (branch
cut along the negative real axis, $-\pi < \operatorname{Im}\operatorname{Log} <
\pi$). This is the correct single-valued determination: since $\frac{1+z}{1-z}$
takes values in the right half-plane for $|z|<1$, its argument lies in $(-\pi/2,
 \pi/2)$, strictly within the principal branch, so no monodromy issues arise.

**Verification.**
- *Harmonicity:* $\operatorname{Log}\frac{1+z}{1-z}$ is analytic on $|z|<1$ (com
position of analytic maps), so its imaginary part is harmonic.
- *Boundary values:* For $z = re^{i\theta}$, $r\to 1^-$:
  - $\theta \in (0,\pi)$: $\frac{1+e^{i\theta}}{1-e^{i\theta}} = \frac{2e^{i\the
ta/2}\cos(\theta/2)}{-2ie^{i\theta/2}\sin(\theta/2)} = i\cot(\theta/2)$, which i
s pure imaginary with positive imaginary part, so $\operatorname{Im}\operatornam
e{Log} = \pi/2$, giving $U \to \frac{2}{\pi}\cdot\frac{\pi}{2} = +1$. ✓
  - $\theta \in (\pi,2\pi)$: $\cot(\theta/2) < 0$, so $\frac{1+e^{i\theta}}{1-e^
{i\theta}} = i\cot(\theta/2)$ has negative imaginary part, $\operatorname{Im}\op
eratorname{Log} = -\pi/2$, giving $U \to \frac{2}{\pi}\cdot(-\frac{\pi}{2}) = -1
$. ✓
- *Symmetry:* At $z=0$, $U = \frac{2}{\pi}\operatorname{Im}\operatorname{Log}(1)
 = 0$, consistent with the average of the boundary values.
