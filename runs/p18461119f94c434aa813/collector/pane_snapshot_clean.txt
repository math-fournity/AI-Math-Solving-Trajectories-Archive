# Solution

## Setup

Since 10 is a primitive root mod 2017, $\text{ord}_{2017}(10) = 2016$. By Fermat
's little theorem, $10^{2016} \equiv 1 \pmod{2017}$, so:

$$a_n = 10^n + 10^{2016-n} \equiv 10^n + 10^{-n} \pmod{2017}$$

Let $x = 10^n$, so $a_n = x + x^{-1}$. Note $a_n = a_{2016-n}$, and for $n \in \
{1,\dots,1007\}$, the values $a_n$ are all **distinct** (since $n$ and $2016-n$
can't both be in $\{1,\dots,1007\}$), and $x \neq \pm 1$ (since $x=1$ needs $n\e
quiv 0$, $x=-1$ needs $n\equiv 1008$, both excluded). Each $a_n$ corresponds to
a unique pair $\{x, x^{-1}\}$ with $x \neq \pm 1$.

## Key identity

$$(x+x^{-1})^3 - 3(x+x^{-1}) = x^3 + x^{-3}$$

## $S_1$: $a_n \equiv 1$

$x + x^{-1} = 1 \Rightarrow x^2 - x + 1 = 0 \Rightarrow x^3 = -1, x^6 = 1$, so $
x$ has **order 6**.

$\text{ord}(10^n) = 2016/\gcd(2016,n) = 6 \Rightarrow \gcd(2016,n) = 336$, so $n
 = 336m$ with $\gcd(6,m)=1$. For $n \in \{1,\dots,1007\}$: only $m=1$, giving $n
 = 336$.

$$S_1 = \{336\}$$

## $S_2$: $a_n^2 \equiv 2$

$(x+x^{-1})^2 = 2 \Rightarrow x^2 + x^{-2} = 0 \Rightarrow x^4 = -1$, so $10^{4n
} \equiv 10^{1008}$, giving $4n \equiv 1008 \pmod{2016}$, i.e. $n \equiv 252 \pm
od{504}$.

$$S_2 = \{252, 756\}$$

## $S_3$: $a_n^3 - 3a_n \equiv 1$

$x^3 + x^{-3} = 1 \Rightarrow x^6 - x^3 + 1 = 0$. Setting $y = x^3$: $y^2 - y +
1 = 0$, so $y$ has **order 6**. Then $x^{18}=1$ and $\text{ord}(x^3)=6$ forces $
\text{ord}(x) = 18$ (checking: order 6 gives $x^3$ order 2; order 9 gives order
3; only order 18 works).

$\text{ord}(10^n) = 18 \Rightarrow \gcd(2016,n) = 112$, so $n = 112m$ with $\gcd
(18,m)=1$. For $n \le 1007$: $m \in \{1,5,7\}$.

$$S_3 = \{112, 560, 784\}$$

## $S_4$: $a_n^3 + a_n^2 - 2a_n \equiv 1$

Expanding: $a^3 + a^2 - 2a - 1 = (x^3+x^{-3}) + (x^2+x^{-2}) + (x+x^{-1}) + 1 =
0$. Multiplying by $x^3$:

$$x^6 + x^5 + x^4 + x^3 + x^2 + x + 1 = 0 \Rightarrow \frac{x^7-1}{x-1} = 0$$

So $x^7 = 1$, $x \neq 1$, meaning $x$ has **order 7**.

$\text{ord}(10^n) = 7 \Rightarrow \gcd(2016,n) = 288$, so $n = 288m$ with $\gcd(
7,m)=1$. For $n \le 1007$: $m \in \{1,2,3\}$.

$$S_4 = \{288, 576, 864\}$$

## Checking overlaps

The sets correspond to elements of orders 6, 8 (from $x^4=-1$), 18, and 7 respec
tively — all different orders, so **no overlaps**. (Direct algebraic verificatio
n confirms: e.g., $a=1$ in $S_1$ gives $a^3-3a=-2\neq 1$ for $S_3$, etc.)

## Final sum

$$|S_1 \cup S_2 \cup S_3 \cup S_4| = 1 + 2 + 3 + 3 = 9$$

$$336 + 252 + 756 + 112 + 560 + 784 + 288 + 576 + 864 = 4528$$

The master bypass code is $\boxed{4528}$.
