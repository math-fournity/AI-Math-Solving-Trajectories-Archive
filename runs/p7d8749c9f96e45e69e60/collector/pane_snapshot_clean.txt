## 解答

**答案：不，映射 $n: \omega_1 \to \omega^\omega$ 不是单射。**

### 证明

**设置。** 令 $L$ 为可数极限序数构成的集合（包含 $0$）。每个 $\alpha \in \omega_
1$ 都可以唯一地表示为 $\alpha = \beta + m$，其中 $\beta \in L$ 且 $m \in \omega$
（这是 Cantor 范式分解：去掉有限尾部后得到极限部分）。设 $\phi: \omega_1 \to L$
为序同构。

迭代过程如下：从 $\alpha_0 = \alpha$ 开始，记 $\alpha_k = \beta_k + n_k$，其中 $
\beta_k \in L$，$n_k \in \omega$，并令 $\alpha_{k+1} = \phi^{-1}(\beta_k)$。序列
 $n(\alpha) = (n_0, n_1, n_2, \ldots)$。

**关键观察：$\omega^\omega$ 是 $\phi^{-1}\!\restriction_L$ 的不动点。**

$\phi^{-1}(\lambda)$ 的值等于 $L$ 中严格小于 $\lambda$ 的元素个数，即 $L \cap \l
ambda$ 的序型。我断言 $\omega^\omega$ 的序型为 $\omega^\omega$。

小于 $\omega^\omega$ 的序数具有 Cantor 范式 $\omega^{k}a_k + \cdots + \omega^0 a
_0$（有限 $k$）。一个序数 $\alpha < \omega^\omega$ 是后继序数当且仅当其常数项 $a
_0 \geq 1$。因此，小于 $\omega^\omega$ 的非后继序数恰好是 $0$ 以及满足 $a_0 = 0$
 且 $\alpha > 0$ 的序数。

满足 $a_0 = 0$ 的序数 $\alpha$ 恰好是 $\omega$ 的倍数：$\alpha = \omega \cdot \g
amma$，其中 $\gamma \geq 1$。对于 $\gamma < \omega^\omega$，我们有 $\omega \cdot
 \gamma < \omega \cdot \omega^\omega = \omega^{1+\omega} = \omega^\omega$，且映
射 $\gamma \mapsto \omega\cdot\gamma$ 在 $[1, \omega^\omega)$ 上是严格递增的。因
此：

$$L \cap \omega^\omega \;=\; \{0\} \cup \{\omega\cdot\gamma : 1 \le \gamma < \om
ega^\omega\}.$$

集合 $\{\omega\cdot\gamma : 1 \le \gamma < \omega^\omega\}$ 的序型为 $\omega^\om
ega$（通过 $\gamma \mapsto \omega\cdot\gamma$ 与 $[1,\omega^\omega)$ 序同构，后
者序型为 $\omega^\omega$，因为 $\omega^\omega$ 是极限序数，去掉首元素不改变序型
）。前置 $\{0\}$ 得到序型 $1 + \omega^\omega = \omega^\omega$。

因此 $\phi^{-1}(\omega^\omega) = \omega^\omega$。$\checkmark$

**计算 $n(\omega^\omega)$。** 由于 $\omega^\omega$ 是极限序数，$\alpha_0 = \omeg
a^\omega = \omega^\omega + 0$，所以 $n_0 = 0$，$\beta_0 = \omega^\omega$。则 $\a
lpha_1 = \phi^{-1}(\omega^\omega) = \omega^\omega$。归纳可知，对所有 $k$，$\alph
a_k = \omega^\omega$，$n_k = 0$。因此：

$$n(\omega^\omega) = (0, 0, 0, \ldots).$$

**计算 $n(0)$。** $\alpha_0 = 0 = 0 + 0$，所以 $n_0 = 0$，$\beta_0 = 0$。则 $\al
pha_1 = \phi^{-1}(0) = 0$（因为 $0$ 是 $L$ 的最小元，$\phi(0) = 0$）。归纳可知，
对所有 $k$，$\alpha_k = 0$，$n_k = 0$。因此：

$$n(0) = (0, 0, 0, \ldots).$$

**结论。** $n(\omega^\omega) = n(0) = (0,0,0,\ldots)$，但 $\omega^\omega \neq 0$
。因此 $n$ **不是单射**。$\blacksquare$
