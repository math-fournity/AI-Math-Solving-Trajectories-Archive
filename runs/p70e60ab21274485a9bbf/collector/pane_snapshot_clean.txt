## 证明

设 $U = \mathbb{R}^2 \setminus \{(-1,0),(1,0)\}$。定义围绕每个孔洞的角度形式：

$$d\theta_1 = \frac{-y\,dx + (x+1)\,dy}{(x+1)^2 + y^2}, \qquad d\theta_2 = \frac
{-y\,dx + (x-1)\,dy}{(x-1)^2 + y^2}.$$

这两个形式在 $U$ 上都是光滑的（它们的奇点恰好位于被移除的点 $(-1,0)$ 和 $(1,0)$
）。令

$$\boxed{\;\omega \;=\; d\theta_1 - d\theta_2 \;=\; \frac{-y\,dx+(x+1)\,dy}{(x+1
)^2+y^2} \;-\; \frac{-y\,dx+(x-1)\,dy}{(x-1)^2+y^2}.\;}$$

**闭合性 (Closedness)。** 每个形式 $d\theta_i$ 在局部上都是角度函数的外微分（$d\
theta_1 = d\arctan\!\big(\tfrac{y}{x+1}\big)$，$d\theta_2 = d\arctan\!\big(\tfra
c{y}{x-1}\big)$，在适当的分支上），因此在其定义域内 $d(d\theta_i) = 0$。由于两个
形式在 $U$ 上都是光滑的，故在 $U$ 上有 $d\omega = d(d\theta_1) - d(d\theta_2) =
0$。因此 $\omega$ 是闭合的。

**对称性 (Symmetry)。** 设 $R(x,y) = (-x,y)$，因此 $R^*(dx) = -dx$ 且 $R^*(dy) =
 dy$。计算 $d\theta_1$ 的拉回 (pullback)：

$$R^*(d\theta_1) = \frac{-y(-dx)+(-x+1)\,dy}{(-x+1)^2+y^2} = \frac{y\,dx+(1-x)\,
dy}{(x-1)^2+y^2} = \frac{y\,dx-(x-1)\,dy}{(x-1)^2+y^2} = -d\theta_2.$$

类似地，$R^*(d\theta_2) = -d\theta_1$。因此

$$R^*(\omega) = R^*(d\theta_1) - R^*(d\theta_2) = -d\theta_2 - (-d\theta_1) = d\
theta_1 - d\theta_2 = \omega,$$

即 $\omega(-x,y) = \omega(x,y)$。该形式是对称的。

**非精确性 (Non-exactness)。** 第一德拉姆上同调群为 $H^1_{\mathrm{dR}}(U) \cong
\mathbb{R}^2$，其基底由 $[d\theta_1],[d\theta_2]$ 给出。事实上，设 $\gamma_1, \g
amma_2$ 为分别围绕 $(-1,0)$ 和 $(1,0)$ 的小正向圆周，则

$$\oint_{\gamma_1} d\theta_1 = 2\pi,\quad \oint_{\gamma_1} d\theta_2 = 0,\qquad
\oint_{\gamma_2} d\theta_1 = 0,\quad \oint_{\gamma_2} d\theta_2 = 2\pi.$$

因此周期矩阵为 $\bigl(\begin{smallmatrix} 2\pi & 0 \\ 0 & 2\pi \end{smallmatrix}
\bigr)$，这是可逆的，确认了 $[d\theta_1],[d\theta_2]$ 构成了 $H^1_{\mathrm{dR}}(
U)$ 的基底。对于 $\omega = d\theta_1 - d\theta_2$，

$$\oint_{\gamma_1} \omega = 2\pi,\qquad \oint_{\gamma_2} \omega = -2\pi.$$

由于 $\omega$ 在 $U$ 上的某个闭合曲线上具有非零周期，它不可能是 $U$ 上函数的外微
分（精确形式在所有闭合曲线上积分为零）。因此 $\omega$ 是非精确的。

我们构造了一个在 $U$ 上对称、闭合且非精确的 1-形式 $\omega$。
