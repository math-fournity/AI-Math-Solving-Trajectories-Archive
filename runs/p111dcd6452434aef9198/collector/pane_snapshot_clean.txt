## Proof

**Setup.** Place $A = (0,0)$ and $B = (8,0)$. Since $ABCD$ is convex with $A,B$
the southern corners, $D$ and $C$ lie above the $x$-axis. Let $\angle A = \alpha
$, so $\angle B = 120° - \alpha$.

Then:
$$D = (5\cos\alpha,\; 5\sin\alpha)$$
$$C = (8 - 5\cos(120°-\alpha),\; 5\sin(120°-\alpha))$$

**Computing $\overrightarrow{CD}$.** Using $\cos(120°-\alpha) = -\tfrac{1}{2}\co
s\alpha + \tfrac{\sqrt3}{2}\sin\alpha$ and $\sin(120°-\alpha) = \tfrac{\sqrt3}{2
}\cos\alpha + \tfrac{1}{2}\sin\alpha$:

$$\overrightarrow{CD} = C - D = \big(8 - \tfrac{5}{2}(\cos\alpha + \sqrt3\,\sin\
alpha),\;\; \tfrac{5}{2}(\sqrt3\cos\alpha - \sin\alpha)\big)$$

Setting $\theta = \alpha - 60°$, and using $\cos\alpha + \sqrt3\sin\alpha = 2\co
s\theta$ and $\sqrt3\cos\alpha - \sin\alpha = -2\sin\theta$:

$$\overrightarrow{CD} = (8 - 5\cos\theta,\; -5\sin\theta)$$

**Locating $E$.** The equilateral triangle $CDE$ is built *outside* the plot (on
 the north side of $CD$). The outer vertex is obtained by rotating $\overrightar
row{CD}$ by $+60°$ and adding to $D$:

$$E = D + R_{60°}(\overrightarrow{CD})$$

where $R_{60°}(p,q) = \big(\tfrac{p}{2} - \tfrac{\sqrt3\,q}{2},\; \tfrac{\sqrt3\
,p}{2} + \tfrac{q}{2}\big)$.

**$x$-coordinate of $E$:**
$$E_x = 5\cos\alpha + \tfrac{1}{2}(8-5\cos\theta) - \tfrac{\sqrt3}{2}(-5\sin\the
ta) = 5\cos\alpha + 4 - \tfrac{5}{2}(\cos\theta - \sqrt3\sin\theta)$$

Since $\cos\theta - \sqrt3\sin\theta = 2\cos(\theta+60°) = 2\cos\alpha$:

$$E_x = 5\cos\alpha + 4 - \tfrac{5}{2}\cdot 2\cos\alpha = 5\cos\alpha + 4 - 5\co
s\alpha = \boxed{4}$$

**$y$-coordinate of $E$:**
$$E_y = 5\sin\alpha + \tfrac{\sqrt3}{2}(8-5\cos\theta) + \tfrac{1}{2}(-5\sin\the
ta) = 5\sin\alpha + 4\sqrt3 - \tfrac{5}{2}(\sqrt3\cos\theta + \sin\theta)$$

Since $\sqrt3\cos\theta + \sin\theta = 2\sin(\theta+60°) = 2\sin\alpha$:

$$E_y = 5\sin\alpha + 4\sqrt3 - \tfrac{5}{2}\cdot 2\sin\alpha = 5\sin\alpha + 4\
sqrt3 - 5\sin\alpha = \boxed{4\sqrt3}$$

**Remarkable conclusion:** $E = (4,\, 4\sqrt3)$ is **independent of $\alpha$** —
 the position of $E$ is the same no matter how the $120°$ is split between $\ang
le A$ and $\angle B$.

**Area of $\triangle ABE$:** With $A=(0,0)$, $B=(8,0)$, $E=(4,4\sqrt3)$:

$$[\triangle ABE] = \tfrac{1}{2}\big|8\cdot 4\sqrt3 - 0\cdot 4\big| = \tfrac{1}{
2}\cdot 32\sqrt3 = 16\sqrt3$$

$$\boxed{[\triangle ABE] = 16\sqrt3}$$
