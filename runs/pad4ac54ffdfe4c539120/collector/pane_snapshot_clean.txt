## 解答

### (a) 相移 η(k)

给定本征函数为 $\psi_k(x) = e^{ikx}(-ik + \tanh x)$，本征值为 $E = k^2$。

**当 $x \to +\infty$ 时：** $\tanh x \to 1$，因此
$$\psi_k \approx (1 - ik)\,e^{ikx}.$$

**当 $x \to -\infty$ 时：** $\tanh x \to -1$，因此
$$\psi_k \approx (-1 - ik)\,e^{ikx}.$$

我们需要找到 $A$ 和 $\eta(k)$，使得：
$$A\,e^{i\eta} = 1 - ik, \qquad A\,e^{-i\eta} = -1 - ik.$$

将两式相乘得到 $A^2 = (1-ik)(-1-ik) = -(1+k^2)$，因此我们取 $A = -i\sqrt{1+k^2}$
。那么
$$e^{i\eta} = \frac{1-ik}{-i\sqrt{1+k^2}} = \frac{i(1-ik)}{\sqrt{1+k^2}} = \frac
{k+i}{\sqrt{1+k^2}}.$$

由此可得 $\cos\eta = \frac{k}{\sqrt{1+k^2}}$ 和 $\sin\eta = \frac{1}{\sqrt{1+k^2
}}$，因此

$$\boxed{\eta(k) = \arctan\!\left(\frac{1}{k}\right).}$$

**验证：** $A\,e^{-i\eta} = -i\sqrt{1+k^2}\cdot\frac{k-i}{\sqrt{1+k^2}} = -i(k-i
) = -1 - ik.$ ✓

### (b) 周期性边界条件与态密度

在 $x = +L/2$（大的正值）处：$\psi \approx A\,e^{ikL/2}\,e^{i\eta}$。
在 $x = -L/2$（大的负值）处：$\psi \approx A\,e^{-ikL/2}\,e^{-i\eta}$。

条件 $\psi(-L/2) = \psi(L/2)$ 给出：
$$e^{-ikL/2 - i\eta} = e^{ikL/2 + i\eta} \implies e^{i(kL + 2\eta)} = 1.$$

因此，允许的 $k$ 值满足量子化条件：
$$kL + 2\,\eta(k) = 2\pi n, \qquad n \in \mathbb{Z},$$
即
$$kL + 2\arctan\!\left(\frac{1}{k}\right) = 2\pi n.$$

对 $k$ 求导以获得态密度 $\rho(k) = dn/dk$：
$$L + 2\frac{d}{dk}\arctan\!\left(\frac{1}{k}\right) = 2\pi\,\frac{dn}{dk}.$$

由于 $\frac{d}{dk}\arctan(1/k) = \frac{-1/k^2}{1+1/k^2} = \frac{-1}{1+k^2}$，我
们得到：
$$L - \frac{2}{1+k^2} = 2\pi\,\rho(k),$$

$$\boxed{\rho(k) = \frac{L}{2\pi} - \frac{1}{\pi(1+k^2)}.}$$

### (c) 与自由态密度比较及积分 $\Delta N$

自由粒子（零势）情况给出 $\rho_0(k) = \frac{L}{2\pi}$，因此
$$\rho(k) - \rho_0(k) = -\frac{1}{\pi(1+k^2)}.$$

积分：
$$\Delta N = \int_{-\infty}^{\infty}\left[\rho(k) - \rho_0(k)\right]dk = -\frac{
1}{\pi}\int_{-\infty}^{\infty}\frac{dk}{1+k^2} = -\frac{1}{\pi}\cdot\pi.$$

$$\boxed{\Delta N = -1.}$$

---

### (d) 缺失的连续谱态 = 束缚态

结果 $\Delta N = -1$ 意味着与自由粒子情况相比，连续谱中恰好少了一个态。这个“缺失
”的态必定是势阱从连续谱中剥离出来并转化为束缚态的态。

为了确认这一点，我们寻找一个具有 $E < 0$ 的束缚态。令 $\psi = \operatorname{sech
} x$。那么
$$\psi'' = \operatorname{sech}x - 2\operatorname{sech}^3 x,$$
且
$$\psi'' + (E + 2\operatorname{sech}^2 x)\psi = \operatorname{sech}x - 2\operato
rname{sech}^3 x + E\operatorname{sech}x + 2\operatorname{sech}^3 x = (1+E)\opera
torname{sech}x.$$

当 $E = -1$ 时该式为零，确认 $\psi_0 = \operatorname{sech} x$ 是本征值为 $E = -1
$ 的束缚态。归一化：$\int_{-\infty}^{\infty}\operatorname{sech}^2 x\,dx = 2$，因
此归一化的束缚态为
$$\psi_0(x) = \frac{1}{\sqrt{2}}\operatorname{sech} x.$$

Pöschl–Teller 势 $V(x) = -2\operatorname{sech}^2 x$ 恰好支持这一个束缚态（透射系
数中 $k=0$ 处的极点对应于 $E = -1$ 的束缚态极点）。连续谱态密度的缺失 $\Delta N
= -1$ 正好对应于这个局域束缚态，证实了 Levinson 定理的计数：一个束缚态意味着连续
谱中少了一个态。
