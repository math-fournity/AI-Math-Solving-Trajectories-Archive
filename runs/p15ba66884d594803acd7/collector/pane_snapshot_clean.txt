## Proof

**Setup.** A degree-$d$ polynomial $p(x) = \sum_{k=0}^d c_k x^k$ has $d+1$ coeff
icients. At least $d$ of them equal 1, so at most one coefficient differs from 1
. The polynomial must have exactly $d$ real roots (counting multiplicities), mea
ning **all** roots are real.

**Key Tool — Newton's Inequalities.** If $p(x) = \sum_{k=0}^d \binom{d}{k} a_k x
^k$ has all real roots, then for $1 \le k \le d-1$:
$$a_k^2 \ge a_{k-1}\, a_{k+1}$$
where $a_k = c_k / \binom{d}{k}$. This holds for **all** real-rooted polynomials
 regardless of root signs (it is the classical Newton inequality for elementary
symmetric polynomials of real numbers).

**Critical Observation.** Suppose three consecutive coefficients $c_{k-1} = c_k
= c_{k+1} = 1$ for some $1 \le k \le d-1$. Then $a_{k-1} = 1/\binom{d}{k-1}$, $a
_k = 1/\binom{d}{k}$, $a_{k+1} = 1/\binom{d}{k+1}$, all positive. Newton's inequ
ality gives:

$$\frac{1}{\binom{d}{k}^2} \ge \frac{1}{\binom{d}{k-1}\binom{d}{k+1}} \iff \bino
m{d}{k-1}\binom{d}{k+1} \ge \binom{d}{k}^2$$

Computing the ratio:
$$\frac{\binom{d}{k-1}\binom{d}{k+1}}{\binom{d}{k}^2} = \frac{k}{d-k+1}\cdot\fra
c{d-k}{k+1} = \frac{k(d-k)}{(d-k+1)(k+1)}$$

Expanding: $k(d-k) = kd - k^2$ and $(d-k+1)(k+1) = kd - k^2 + d + 1$. So the ine
quality becomes:

$$kd - k^2 \ge kd - k^2 + d + 1 \iff 0 \ge d + 1$$

This is **impossible** for $d \ge 1$. Therefore, no three consecutive coefficien
ts can all equal 1.

**Upper Bound: $d \le 4$.** With at most one "free" coefficient at position $j$
(where $c_j \ne 1$), the indices $k$ "covered" (where at least one of $c_{k-1},
c_k, c_{k+1}$ is not 1) form the set $\{j{-}1, j, j{+}1\} \cap \{1, \ldots, d{-}
1\}$, which has **at most 3 elements**.

For all roots to be real, every $k \in \{1, \ldots, d-1\}$ must be covered. This
 requires $d - 1 \le 3$, i.e., $d \le 4$.

For $d = 5$: $\{1,2,3,4\}$ has 4 elements but we can cover at most 3 — contradic
tion. So $d \ge 5$ is impossible.

**Construction for $d = 4$.** Set $j = 2$ (the free coefficient is $c_2$), givin

This is a **palindromic** polynomial. Substituting $y = x + 1/x$:

t) + (t - 2) = y^2 + y + (t-2)$$

Setting $t = -4$: $y^2 + y - 6 = (y+3)(y-2) = 0$, giving $y = 2$ and $y = -3$.
