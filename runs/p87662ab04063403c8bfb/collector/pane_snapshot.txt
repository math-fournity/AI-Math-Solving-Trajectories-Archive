## Proof

I use the Prime Number Theorem (PNT): $\pi(x) := \#\{p \leq x : p \text{ prime}\
} \sim \frac{x}{\ln x}$, and Abel (partial) summation.

**Abel summation setup.** Let $a_n = 1$ if $n$ is prime, $0$ otherwise, so $\sum
_{n \leq t} a_n = \pi(t)$. With $f(t) = t^k$:

$$\pi_k(x) = \sum_{p \leq x} p^k = \pi(x)\, x^k - \int_2^x \pi(t)\, k\, t^{k-1}\
, dt.$$

---

**Case 1: $k > -1$ (i.e., $k+1 > 0$).**

Using $\pi(t) \sim \frac{t}{\ln t}$, the boundary term gives $\pi(x)\,x^k \sim \
frac{x^{k+1}}{\ln x}$.

For the integral, substitute $u = t^{k+1}$, so $t^k\,dt = \frac{du}{k+1}$ and $\
ln t = \frac{\ln u}{k+1}$, whence $\frac{t^k}{\ln t}\,dt = \frac{du}{\ln u}$. Th
erefore:

$$\int_2^x \frac{t^k}{\ln t}\,dt = \int_{2^{k+1}}^{x^{k+1}} \frac{du}{\ln u} = \
operatorname{li}(x^{k+1}) - \operatorname{li}(2^{k+1}) \sim \frac{x^{k+1}}{(k+1)
\ln x},$$

since $\operatorname{li}(y) \sim \frac{y}{\ln y}$. Thus:

$$\pi_k(x) \sim \frac{x^{k+1}}{\ln x} - k\cdot\frac{x^{k+1}}{(k+1)\ln x} = \frac
{x^{k+1}}{\ln x}\left(1 - \frac{k}{k+1}\right) = \frac{x^{k+1}}{(k+1)\ln x}.$$

Dividing by $x$:

$$\frac{\pi_k(x)}{x} \sim \frac{x^k}{(k+1)\ln x}.$$

- **$k > 0$:** $x^k / \ln x \to +\infty$, so $\frac{\pi_k(x)}{x} \to +\infty$. T
he limit diverges; it is not a finite real number.
- **$k = 0$:** $\frac{1}{\ln x} \to 0$, so $\frac{\pi_0(x)}{x} = \frac{\pi(x)}{x
} \to 0$.
- **$-1 < k < 0$:** $x^k \to 0$ and $\ln x \to \infty$, so $\frac{x^k}{\ln x} \t
o 0$, hence $\frac{\pi_k(x)}{x} \to 0$.

---

**Case 2: $k = -1$.**

Here $\pi_{-1}(x) = \sum_{p \leq x} \frac{1}{p}$. By Mertens' theorem (a consequ
ence of PNT), $\sum_{p \leq x} \frac{1}{p} = \ln\ln x + M + o(1)$ for a constant
 $M$. Therefore $\frac{\pi_{-1}(x)}{x} = \frac{\ln\ln x + O(1)}{x} \to 0$.

---

**Case 3: $k < -1$ (i.e., $s := -k > 1$).**

Then $\pi_k(x) = \sum_{p \leq x} \frac{1}{p^s}$ with $s > 1$. The series $\sum_p
 \frac{1}{p^s}$ converges, since $\sum_p \frac{1}{p^s} \leq \sum_{n=1}^{\infty}
\frac{1}{n^s} < \infty$ for $s > 1$. So $\pi_k(x) \to C := \sum_p p^k < \infty$,
 and $\frac{\pi_k(x)}{x} \to \frac{C}{\infty} = 0$.

---

**Conclusion.** Combining all cases:

| Range of $k$ | $\lim_{x\to\infty} \frac{\pi_k(x)}{x}$ |
|---|---|
| $k > 0$ | $+\infty$ (diverges, not a finite real number) |
| $k = 0$ | $0$ |
| $-1 < k < 0$ | $0$ |
| $k = -1$ | $0$ |
| $k < -1$ | $0$ |

For every real $k$, the limit is either $+\infty$ (not defined as a finite real
number) or $0$ (defined but zero). The fundamental obstruction is the $\frac{1}{
\ln x}$ factor inherited from the Prime Number Theorem: it prevents $\frac{x^k}{
(k+1)\ln x}$ from settling at a finite non-zero constant for any $k$.

**There is no value of $k$ for which $\lim_{x \to \infty} \frac{\pi_k(x)}{x}$ is
 defined (as a finite real number) and non-zero.**
