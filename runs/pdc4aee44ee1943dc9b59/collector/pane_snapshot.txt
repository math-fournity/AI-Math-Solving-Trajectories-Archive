**Goal.** Compute $\operatorname{Var}(W_1)$ for $W_1=\int_0^1 W^2(t)\,dt$ using
the given characteristic function
$$\phi(z)=\mathbb{E}[e^{izW_1}]=(\cos\sqrt{2iz})^{-1/2}.$$

### Step 1. Cumulant generating function

The (second) cumulant $\kappa_2$ equals the variance, so it suffices to expand
$$\log\phi(z)=-\tfrac12\log\cos u,\qquad u:=\sqrt{2iz}.$$

### Step 2. Expand $\log\cos u$ in powers of $u$

Using the standard Taylor series with Bernoulli numbers,
$$\log\cos u=-\frac{u^2}{2}-\frac{u^4}{12}-\frac{u^6}{45}-\cdots$$

Hence
$$\log\phi(z)=\frac12\Big(\frac{u^2}{2}+\frac{u^4}{12}+\cdots\Big)=\frac{u^2}{4}
+\frac{u^4}{24}+\cdots$$

### Step 3. Substitute $u^2=2iz$

- $\dfrac{u^2}{4}=\dfrac{2iz}{4}=\dfrac{iz}{2}$
- $\dfrac{u^4}{24}=\dfrac{(2iz)^2}{24}=\dfrac{-4z^2}{24}=-\dfrac{z^2}{6}$

So
$$\log\phi(z)=\frac{iz}{2}-\frac{z^2}{6}+O(z^3).$$

### Step 4. Read off cumulants

Since $\log\phi(z)=\sum_{n\ge1}\kappa_n\dfrac{(iz)^n}{n!}$:

- Coefficient of $(iz)^1/1!$: $\kappa_1=\dfrac12$, i.e. $\mathbb{E}[W_1]=\dfrac1
2$.
- Coefficient of $(iz)^2/2!=-z^2/2$: $\kappa_2\cdot\!\left(-\tfrac12\right)=-\tf
rac16$, giving $\kappa_2=\dfrac13$.

Therefore
$$\operatorname{Var}(W_1)=\kappa_2=\frac13.$$

### Step 5. Direct verification (independent of the characteristic function)

$\mathbb{E}[W_1]=\int_0^1\mathbb{E}[W^2(t)]\,dt=\int_0^1 t\,dt=\tfrac12.$ ✓

For the second moment, using the Gaussian identity $\mathbb{E}[X^2Y^2]=\mathbb{E
}[X^2]\mathbb{E}[Y^2]+2(\mathbb{E}[XY])^2$ with $X=W(s),Y=W(t)$:
$$\mathbb{E}[W^2(s)W^2(t)]=st+2\min(s,t)^2.$$
Thus
$$\mathbb{E}[W_1^2]=\int_0^1\!\!\int_0^1\big(st+2\min(s,t)^2\big)\,ds\,dt=\frac1
4+2\cdot\frac16=\frac14+\frac13=\frac{7}{12},$$
where $\displaystyle\int_0^1\!\!\int_0^1\min(s,t)^2\,ds\,dt=2\int_0^1\!\int_0^t
s^2\,ds\,dt=2\int_0^1\frac{t^3}{3}\,dt=\frac16.$

Finally
$$\operatorname{Var}(W_1)=\mathbb{E}[W_1^2]-\mathbb{E}[W_1]^2=\frac{7}{12}-\frac
14=\frac{7}{12}-\frac{3}{12}=\frac{4}{12}=\frac13.$$

Both methods agree.

---

$$\boxed{\operatorname{Var}(W_1)=\dfrac{1}{3}}$$
