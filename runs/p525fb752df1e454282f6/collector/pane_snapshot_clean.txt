## Solution

**Answer:** In general, **no** — there need not exist a state $\tau$ with $|\tau
(ab)| = \|ab\|$. However, when $a, b$ are projections with $\|ab\| = 1$, the ans
wer is **yes**.

---

### Part 1: General case — counterexample

Take $A = M_2(\mathbb{C})$. Set
$$a = \begin{pmatrix} 1 & 0 \\ 0 & \tfrac{1}{2} \end{pmatrix}, \qquad b = \tfrac
{1}{2}\begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}.$$
Both satisfy $0 \le a, b \le 1$: $a$ is diagonal with entries in $[0,1]$, and $b
 = \frac{1}{2}P$ where $P$ is the rank-one projection onto $\text{span}(1,1)^T$,
 so $b$ is a projection scaled by $\frac{1}{2}$, with eigenvalues $0$ and $\frac
{1}{2}$.

**Computing $\|ab\|$:**
$$ab = \begin{pmatrix} \tfrac{1}{2} & \tfrac{1}{2} \\[2pt] \tfrac{1}{4} & \tfrac
{1}{4} \end{pmatrix} = \begin{pmatrix} \tfrac{1}{2} \\[2pt] \tfrac{1}{4} \end{pm
atrix}\begin{pmatrix} 1 & 1 \end{pmatrix}.$$
This is rank one, so $\|ab\| = \left\|\binom{1/2}{1/4}\right\| \cdot \|(1,1)\| =
 \sqrt{\tfrac{5}{16}} \cdot \sqrt{2} = \frac{\sqrt{10}}{4}$.

**Computing $\max_\tau |\tau(ab)|$:** Every state on $M_2(\mathbb{C})$ is a conv
ex combination of vector states $\omega_v(x) = \langle xv, v\rangle$, $\|v\|=1$.
 Since $|\tau(ab)|$ is convex in $\tau$, its maximum is attained at an extreme p
oint (a vector state). For $v = (v_1, v_2)^T$:
$$\langle ab\, v, v\rangle = \frac{|v_1|^2}{2} + \frac{|v_2|^2}{4} + \frac{3\,\t
ext{Re}(\bar v_1 v_2)}{4} + \frac{i\,\text{Im}(\bar v_1 v_2)}{4}.$$
Writing $v_1 = r_1 e^{i\alpha}$, $v_2 = r_2 e^{i\beta}$, $r_1^2+r_2^2=1$, $\varp
hi = \beta - \alpha$, one checks that $|\langle ab\,v,v\rangle|^2$ is convex in
$\cos\varphi$, so its maximum is at $\cos\varphi = 1$ (i.e., $v$ can be taken **
real**). Setting $v_1 = \cos\theta$, $v_2 = \sin\theta$:
$$|\langle ab\,v,v\rangle| = \frac{(\cos\theta + \sin\theta)(2\cos\theta + \sin\
theta)}{4} = \frac{1}{4}\left(\frac{3}{2} + \frac{\cos 2\theta + 3\sin 2\theta}{
2}\right).$$
The maximum of $\cos 2\theta + 3\sin 2\theta$ is $\sqrt{1+9} = \sqrt{10}$, givin
g
$$\max_{\|v\|=1}|\langle ab\,v,v\rangle| = \frac{3 + \sqrt{10}}{8}.$$

**Comparison:** Since $3 < \sqrt{10}$ (as $9 < 10$),
$$\frac{3+\sqrt{10}}{8} < \frac{2\sqrt{10}}{8} = \frac{\sqrt{10}}{4} = \|ab\|.$$
Therefore **no state** $\tau$ on $M_2(\mathbb{C})$ satisfies $|\tau(ab)| = \|ab\
|$. $\square$

### Part 2: Projection case with $\|ab\| = 1$ — existence proof

Let $p, q \in A$ be projections with $\|pq\| = 1$. We show there exists a state
$\tau$ with $|\tau(pq)| = 1$.

Embed $A$ faithfully into $B(H)$ via the universal representation. Since $\|pq\|
 = \sup_{\|v\|=1}\|pqv\| = 1$, there exist unit vectors $v_n \in H$ with $\|pqv_
n\| \to 1$.

**Key observations.** Since $0 \le qpq \le q \le I$:
$$\|pqv_n\|^2 = \langle qpq\, v_n, v_n\rangle \le \|qv_n\|^2 \le 1.$$
As $\|pqv_n\|^2 \to 1$, we get $\|qv_n\|^2 \to 1$, hence $\|(I-q)v_n\|^2 = 1 - \
|qv_n\|^2 \to 0$.

Also $\|pqv_n\| \le \|pv_n\| \le 1$ and $\|pqv_n\| \to 1$ give $\|pv_n\| \to 1$,
 hence $\|(I-p)v_n\|^2 \to 0$.

**Convergence of vector states.** Define the vector state $\omega_n(x) = \langle
 xv_n, v_n\rangle$. Then:
$$\omega_n(pq) = \langle pq\, v_n, v_n\rangle = \langle qv_n, pv_n\rangle.$$
We estimate:
$$|\omega_n(pq) - 1| = |\langle qv_n, pv_n\rangle - \langle v_n, v_n\rangle| \le
 |\langle qv_n, (p-I)v_n\rangle| + |\langle (q-I)v_n, v_n\rangle|$$
$$\le \|qv_n\|\,\|(I-p)v_n\| + \|(I-q)v_n\|\,\|v_n\| \;\longrightarrow\; 0.$$
So $\omega_n(pq) \to 1 \in \mathbb{R}$.

**Extracting a limiting state.** The state space $S(A)$ is weak-$*$ compact (Ban
ach–Alaoglu). Thus $\{\omega_n\}$ has a weak-$*$ convergent subnet $\omega_{n_\a
lpha} \to \tau \in S(A)$. By weak-$*$ continuity of evaluation:
$$\tau(pq) = \lim_\alpha \omega_{n_\alpha}(pq) = 1.$$
Therefore $|\tau(pq)| = 1 = \|pq\|$. $\square$

---

### Summary

- **General $0 \le a, b \le 1$:** A state $\tau$ with $|\tau(ab)| = \|ab\|$ need
 **not** exist (counterexample in $M_2(\mathbb{C})$).
- **Projections with $\|ab\| = 1$:** Such a state **always** exists. The proof u
ses that $\|pq\| = 1$ forces approximating unit vectors to be "almost fixed" by
both $p$ and $q$, making the vector states $\omega_n(pq) \to 1$; compactness of
the state space then yields the desired state $\tau$ with $\tau(pq) = 1$.
