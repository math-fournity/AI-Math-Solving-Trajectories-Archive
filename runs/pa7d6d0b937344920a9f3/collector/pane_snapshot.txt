## Simplification

The expression inside the absolute value simplifies:

$$1 - \frac{1}{1+E[x]} - E\left[1 - \frac{1}{1+x}\right] = E\left[\frac{1}{1+x}\
right] - \frac{1}{1+E[x]}$$

Let $f(x) = \frac{1}{1+x}$ and $\mu = E[x]$. We seek the tightest $\epsilon_1$ s
uch that:

$$E[f(x)] - f(\mu) \leq \epsilon_1 \cdot \text{Var}(x)$$

(The absolute value is unnecessary since $f$ is convex on $[0,\infty)$, so by Je
nsen's inequality $E[f(x)] \geq f(\mu)$.)

## Upper Bound: $\epsilon_1 \leq 1$

**Taylor expansion with integral remainder.** For any $x \geq 0$ and $\mu \geq 0
$:

$$f(x) - f(\mu) - f'(\mu)(x-\mu) = \int_\mu^x (x-t)\, f''(t)\, dt$$

Computing: $f''(t) = \frac{2}{(1+t)^3}$, which is non-negative and satisfies $f'
'(t) \leq 2$ for all $t \geq 0$.

**Case $x > \mu$:** Here $t \in [\mu, x] \subset [0, \infty)$, so $f''(t) \leq 2
$ and $(x-t) \geq 0$:
$$\int_\mu^x (x-t)\, f''(t)\, dt \leq 2\int_\mu^x (x-t)\, dt = (x-\mu)^2$$

**Case $x < \mu$ (with $x \geq 0$):** Rewriting, $\int_\mu^x (x-t)f''(t)\,dt = \
int_x^\mu (t-x)f''(t)\,dt$. Here $t \in [x, \mu] \subset [0,\infty)$, so $f''(t)
 \leq 2$ and $(t-x) \geq 0$:
$$\int_x^\mu (t-x)\, f''(t)\, dt \leq 2\int_x^\mu (t-x)\, dt = (x-\mu)^2$$

In both cases: $f(x) - f(\mu) - f'(\mu)(x-\mu) \leq (x-\mu)^2$.

**Taking expectations** (noting $E[x - \mu] = 0$):

$$E[f(x)] - f(\mu) \leq E[(x-\mu)^2] = \text{Var}(x)$$

Therefore $\epsilon_1 \leq 1$.

## Tightness: $\epsilon_1 \geq 1$

Consider a two-point distribution: $X = 0$ with probability $1-p$ and $X = a$ wi
th probability $p$, where $a > 0$, $p \in (0,1)$.

- $\mu = pa$, $\quad \text{Var}(X) = pa^2(1-p)$
- $E\!\left[\frac{1}{1+X}\right] = (1-p) + \frac{p}{1+a} = \frac{1 + a(1-p)}{1+a
}$
- $f(\mu) = \frac{1}{1+pa}$

**Computing the gap:**

$$E[f(X)] - f(\mu) = \frac{1 + a(1-p)}{1+a} - \frac{1}{1+pa} = \frac{(1+a(1-p))(
1+pa) - (1+a)}{(1+a)(1+pa)}$$

Expanding the numerator:
$$(1 + a - ap)(1 + pa) = 1 + pa + a + pa^2 - ap - pa^2 p = 1 + a + pa^2(1-p)$$

So the numerator equals $pa^2(1-p)$, giving:

$$\text{Gap} = \frac{pa^2(1-p)}{(1+a)(1+pa)}$$

**The ratio:**

$$\frac{\text{Gap}}{\text{Var}(X)} = \frac{pa^2(1-p)}{(1+a)(1+pa) \cdot pa^2(1-p
)} = \frac{1}{(1+a)(1+pa)}$$

**Taking $a \to 0^+$** (with any fixed $p \in (0,1)$):

$$\frac{1}{(1+a)(1+pa)} \longrightarrow 1$$

So the ratio can be made arbitrarily close to $1$, proving $\epsilon_1 \geq 1$.

## Conclusion

Combining both directions, the tightest possible constant is:

$$\boxed{\epsilon_1 = 1}$$
