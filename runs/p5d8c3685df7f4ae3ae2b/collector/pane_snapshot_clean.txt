Looking at this problem, I need to find the minimal degree of a monic integer po
lynomial that is divisible by $n$ for all integer inputs.

## Solution

**Key idea: Binomial coefficient basis and forward differences.**

Every polynomial $p(x) \in \mathbb{Z}[x]$ can be written uniquely as $p(x) = \su
m_{k=0}^{d} a_k \binom{x}{k}$ with $a_k \in \mathbb{Z}$ (the $a_k$ are the forwa
rd differences $\Delta^k p(0)$).

**Lemma.** $p(x) \in \mathbb{Z}[x]$ satisfies $n \mid p(m)$ for all $m \in \math
bb{Z}$ if and only if $n \mid a_k$ for every $k$.

*Proof.*
- ($\Leftarrow$): If $n \mid a_k$ for all $k$, then since $\binom{m}{k} \in \mat
hbb{Z}$ for all $m \in \mathbb{Z}$, we get $p(m) = \sum a_k \binom{m}{k} \equiv
0 \pmod{n}$.
- ($\Rightarrow$): If $n \mid p(m)$ for all $m \geq 0$, then $\Delta p(m) = p(m{
+}1)-p(m) \equiv 0 \pmod{n}$ for all $m \geq 0$. By induction, $\Delta^k p(m) \e
quiv 0 \pmod{n}$ for all $m \geq 0$. Setting $m=0$: $a_k = \Delta^k p(0) \equiv
0 \pmod{n}$. $\square$

**Monic condition.** Since $\binom{x}{d} = \frac{x^d}{d!} + \text{(lower terms)}
$, the leading coefficient of $p$ is $a_d/d!$. For $p$ to be monic of degree $d$
, we need $a_d = d!$.

**Combining.** A monic degree-$d$ polynomial null mod $n$ exists iff $n \mid a_d
 = d!$ (we set $a_k = 0$ for $k < d$, which is divisible by $n$). The resulting
polynomial is $p(x) = d!\binom{x}{d} = x(x{-}1)\cdots(x{-}d{+}1)$.

Conversely, if $n \nmid d!$, then $n \nmid a_d$, so no monic degree-$d$ null pol
ynomial exists.

**Conclusion.** $f(n) = \min\{d : n \mid d!\}$, the Smarandache (Kempner) functi
on.

**Verification on small cases:**
- $f(p) = p$ for prime $p$: $p \mid d!$ first at $d = p$. ✓
- $f(6) = 3$: $3! = 6$, and $p(x) = x(x{-}1)(x{-}2)$ is always divisible by $6$.
 ✓
- $f(8) = 4$: $4! = 24$ divisible by $8$; $3! = 6$ not. ✓

**Computing $f(1000000)$.** Since $1000000 = 2^6 \cdot 5^6$, we need $v_2(d!) \g
eq 6$ and $v_5(d!) \geq 6$.

Using Legendre's formula $v_p(d!) = \sum_{i \geq 1} \lfloor d/p^i \rfloor$:

- **For $p = 5$:** $v_5(24!) = 4 + 0 = 4 < 6$; $\;v_5(25!) = 5 + 1 = 6 \geq 6$.
So we need $d \geq 25$.
- **For $p = 2$:** $v_2(8!) = 4 + 2 + 1 = 7 \geq 6$; $\;v_2(7!) = 3 + 1 = 4 < 6$
. So we need $d \geq 8$.

The binding constraint is $d \geq 25$. At $d = 25$: $v_2(25!) = 12+6+3+1 = 22 \g
eq 6$ ✓ and $v_5(25!) = 6 \geq 6$ ✓.

Therefore:

$$f(n) = \min\{d \in \mathbb{N} : n \mid d!\}, \qquad f(1000000) = \boxed{25}.$$
