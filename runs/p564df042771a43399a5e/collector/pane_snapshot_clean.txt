## Proof

**Yes, the theorem remains valid.** The proof goes through essentially unchanged
; the only ingredient that matters is that finite partial sums are continuous an
d that a uniform limit of continuous functions is continuous — neither of which
depends on the indexing set being $\mathbb{N}_0$ rather than $\mathbb{Z}$.

### Setup and definition

For a series indexed by an arbitrary set, the standard notion of convergence is
convergence of the **net of finite partial sums**. We say $\sum_{k \in \mathbb{Z
}} g_k$ *converges uniformly* to a function $f$ on $S$ if:

> For every $\varepsilon > 0$, there exists a finite set $F_0 \subset \mathbb{Z}
$ such that for every finite set $F \subset \mathbb{Z}$ with $F \supseteq F_0$,
> $$\sup_{x \in S}\left|\sum_{k \in F} g_k(x) - f(x)\right| < \varepsilon.$$

### The partial sums are continuous

For any finite set $F \subset \mathbb{Z}$, the partial sum
$$S_F := \sum_{k \in F} g_k$$
is a **finite** sum of functions, each continuous on $S$ by hypothesis. A finite
 sum of continuous functions is continuous, so $S_F$ is continuous on $S$.

### The uniform limit is continuous

We show $f$ is continuous at an arbitrary point $x_0 \in S$.

Let $\varepsilon > 0$. By uniform convergence, choose a finite set $F_0 \subset
\mathbb{Z}$ such that for every finite $F \supseteq F_0$,
$$\|S_F - f\|_{\infty,\, S} < \frac{\varepsilon}{3}.$$

Fix $F = F_0$ (which is finite, so $S_F$ is continuous at $x_0$). There exists $
\delta > 0$ such that for all $x \in S$ with $|x - x_0| < \delta$,
$$|S_F(x) - S_F(x_0)| < \frac{\varepsilon}{3}.$$

Then for all such $x$, the triangle inequality gives
$$|f(x) - f(x_0)| \leq |f(x) - S_F(x)| + |S_F(x) - S_F(x_0)| + |S_F(x_0) - f(x_0
)| < \frac{\varepsilon}{3} + \frac{\varepsilon}{3} + \frac{\varepsilon}{3} = \va
repsilon.$$

Since $x_0 \in S$ was arbitrary, $f$ is continuous on $S$.

### Remark on alternative notions of convergence

The same conclusion holds under other reasonable interpretations of "uniform con
vergence" for a two-sided series. For instance, if one defines convergence via t
he **symmetric partial sums** $T_n = \sum_{k=-n}^{n} g_k$, each $T_n$ is a finit
e sum of continuous functions and hence continuous, and uniform convergence $T_n
 \to f$ implies $f$ is continuous by the classical one-sided theorem. The argume
nt is identical in structure.

### Why the indexing set is irrelevant

The proof of the original theorem uses only two facts:
1. **Finite partial sums are continuous** — true for any indexing set, since a f
inite sum of continuous functions is continuous.
2. **A uniform limit of continuous functions is continuous** — this is a theorem
 about the mode of convergence (uniform), not about the indexing set, and it hol
ds for nets as well as sequences.

Neither fact depends on the index set being $\mathbb{N}_0$. Replacing $\mathbb{N
}_0$ with $\mathbb{Z}$ (or any other index set) changes nothing essential.

### Conclusion

The theorem is still valid: if $\sum_{k \in \mathbb{Z}} g_k$ converges uniformly
 on $S$ and each $g_k$ is continuous on $S$, then the sum represents a continuou
s function on $S$.
