## Solution

Let $P_n(z) = \sum_{k=0}^{n} \frac{z^k}{k!}$. We apply Rouché's theorem in two r
egimes.

### Case 1: $R > 2n$ — there are $n$ zeros inside $|z|=R$

Set $f(z) = \dfrac{z^n}{n!}$ and $g(z) = \sum_{k=0}^{n-1} \dfrac{z^k}{k!}$, so $
P_n = f + g$.

On $|z| = R$:
$$|f(z)| = \frac{R^n}{n!}, \qquad |g(z)| \leq \sum_{k=0}^{n-1} \frac{R^k}{k!}.$$

We show $|g(z)| < |f(z)|$. Computing the ratio:

$$\frac{|g(z)|}{|f(z)|} \leq \frac{n!}{R^n}\sum_{k=0}^{n-1}\frac{R^k}{k!} = \sum
_{m=1}^{n} \frac{n(n-1)\cdots(n-m+1)}{R^m} \leq \sum_{m=1}^{n}\left(\frac{n}{R}\
right)^m < \sum_{m=1}^{\infty}\left(\frac{n}{R}\right)^m = \frac{n}{R-n}.$$

Since $R > 2n$, we get $\dfrac{n}{R-n} < \dfrac{n}{2n - n} = 1$, so $|g(z)| < |f
(z)|$ on $|z|=R$.

By **Rouché's theorem**, $P_n = f+g$ has the same number of zeros inside $|z|=R$
 as $f(z) = z^n/n!$, namely **$n$** (all at the origin, counted with multiplicit
y).

### Case 2: $\sum_{k=1}^{n} \frac{R^k}{k!} < 1$ — there are $0$ zeros inside $|z
|=R$

Set $f(z) = 1$ and $g(z) = \sum_{k=1}^{n} \frac{z^k}{k!}$, so $P_n = f + g$.

On $|z| = R$:
$$|f(z)| = 1, \qquad |g(z)| \leq \sum_{k=1}^{n} \frac{R^k}{k!} < 1 = |f(z)|.$$

By **Rouché's theorem**, $P_n$ has the same number of zeros inside $|z|=R$ as $f
(z)=1$, namely **$0$**.

> **Sufficient condition:** Since $\sum_{k=1}^{n} \frac{R^k}{k!} \leq e^R - 1$,
the hypothesis is satisfied whenever $R < \ln 2$.

### Conclusion

$$\boxed{\text{Number of zeros of } P_n(z) \text{ inside } |z|=R \text{ is } \be
gin{cases} n & \text{if } R > 2n,\\[4pt] 0 & \text{if } \sum_{k=1}^{n} \frac{R^k
}{k!} < 1 \;\;(\text{e.g., } R < \ln 2). \end{cases}}$$

For intermediate $R$ (between these thresholds), the count lies between $0$ and
$n$ and depends on the specific locations of the zeros; Rouché's theorem with th
ese natural comparisons does not resolve the intermediate regime.
