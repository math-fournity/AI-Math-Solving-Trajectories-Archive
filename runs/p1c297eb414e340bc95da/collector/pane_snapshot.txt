## Proof

**Claim:** The unique solution is $(a, b, c) = (1, 1, 2)$.

### Verification

For $(a,b,c) = (1,1,2)$: $a^n + b^n + n = 1 + 1 + n = n+2 = n+c$, so $n+c \mid n
+c$ holds for all $n$. ✓

### Necessity

Suppose $(a,b,c)$ with $a,b,c \geq 1$ satisfies the condition. Set $M = \prod_{p
 \text{ prime},\, p < 2015} p$.

**Infinitely many useful primes exist.** We claim there are infinitely many prim
es $q > \max(a,b,c)$ such that $n := q - c$ is a positive integer with no prime
divisor $< 2015$.

For each prime $p < 2015$, we need a residue $r \pmod{M}$ avoiding $r \equiv 0 \
pmod{p}$ and $r \equiv -c \pmod{p}$. Each prime $p \geq 2$ forbids at most 2 of
$p$ residue classes, so at least one class remains per prime. By CRT, there exis
ts $r$ with $\gcd(r, M) = 1$ and $\gcd(c+r, M) = 1$. By Dirichlet's theorem, inf
initely many primes $q \equiv c+r \pmod{M}$ exist. For each such prime $q > 2015
$: $\gcd(q-c, M) = \gcd(r, M) = 1$, so $q - c$ has no prime factor $< 2015$.

**Applying the condition.** For each such prime $q$, set $n = q - c \geq 1$. Sin
ce $q > a, b$, we have $\gcd(ab, q) = 1$. The divisibility condition gives:
$$q \mid a^{q-c} + b^{q-c} + (q-c), \quad\text{i.e.,}\quad q \mid a^{q-c} + b^{q
-c} - c.$$

By Fermat's little theorem, $a^{q-1} \equiv 1 \pmod{q}$, so $a^{q-c} = a^{(q-1)-
(c-1)} \equiv a^{-(c-1)} \pmod{q}$ (valid since $c \geq 1$ and $\gcd(a,q)=1$). S
imilarly $b^{q-c} \equiv b^{-(c-1)} \pmod{q}$. Thus:
$$q \mid a^{1-c} + b^{1-c} - c \pmod{q}.$$

Multiplying by $(ab)^{c-1}$ (coprime to $q$):
$$q \mid \underbrace{a^{c-1} + b^{c-1} - c\cdot(ab)^{c-1}}_{=: N}.$$

Since $q \mid N$ for infinitely many primes $q$, the fixed integer $N$ must be z
ero:
$$a^{c-1} + b^{c-1} = c\cdot(ab)^{c-1}, \quad\text{i.e.,}\quad \frac{1}{a^{c-1}}
 + \frac{1}{b^{c-1}} = c.$$

**Solving the equation.** Since $a, b \geq 1$:

- **$c = 1$:** $\frac{1}{a^0} + \frac{1}{b^0} = 2 \neq 1$. Impossible. (Equivale
ntly, $N = 1+1-1 = 1 \neq 0$.)

- **$c = 2$:** $\frac{1}{a} + \frac{1}{b} = 2$. Since $\frac{1}{a} + \frac{1}{b}
 \leq \frac{1}{1} + \frac{1}{1} = 2$ with equality iff $a = b = 1$, we get $a =
b = 1$.

- **$c \geq 3$:** $\frac{1}{a^{c-1}} + \frac{1}{b^{c-1}} \leq 1 + 1 = 2 < c$. Im
possible.

Therefore $(a, b, c) = (1, 1, 2)$ is the only solution. $\blacksquare$
