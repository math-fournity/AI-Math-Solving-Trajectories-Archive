## Proof

We interpret the problem with $n \geq 2$ (the case $n=1$ is trivial, giving ever
y entire function). We seek all entire $f$ for which there exists a fixed intege
r $n \geq 2$ such that
$$f(z^n) = (f(z))^n \quad \text{for all } z \in \mathbb{C}.$$

**Claim.** The solutions are exactly
$$f \equiv 0 \quad\text{or}\quad f(z) = \zeta\, z^m,$$
where $m \in \mathbb{Z}_{\geq 0}$ and $\zeta$ is a root of unity.

---

### Step 1. Zeros away from the origin force $f \equiv 0$.

Suppose $f$ has a zero at some $z_0 \neq 0$. For any $z$ with $z^n = z_0$ (i.e.,
 any $n$-th root of $z_0$), the functional equation gives
$$0 = f(z_0) = f(z^n) = (f(z))^n,$$
so $f(z) = 0$ for every $n$-th root of $z_0$. Iterating, every $n^k$-th root of
$z_0$ (for all $k \geq 1$) is a zero of $f$.

- If $|z_0| \neq 1$: these roots have modulus $|z_0|^{1/n^k} \to 1$, lying in a
bounded annulus, with arguments becoming dense — so they accumulate.
- If $|z_0| = 1$: writing $z_0 = e^{i\theta}$, the $n^k$-th roots are $e^{i(\the
ta+2\pi j)/n^k}$, which become dense on the unit circle as $k \to \infty$.

In either case the zeros of the entire function $f$ have an accumulation point i
n $\mathbb{C}$, so by the identity theorem $f \equiv 0$.

**Conclusion:** A nonzero solution $f$ can vanish only at the origin.

---

### Step 2. Reduction to a multiplicative equation.

Let $f \not\equiv 0$. By Step 1, the only zero of $f$ is at $0$, so
$$f(z) = z^m g(z), \qquad m \geq 0,\quad g \text{ entire, zero-free},\quad g(0)
\neq 0.$$
Since $\mathbb{C}$ is simply connected and $g$ is zero-free, $g(z) = e^{h(z)}$ f
or some entire $h$. Substituting into the functional equation:
$$z^{mn}\, e^{h(z^n)} = f(z^n) = (f(z))^n = z^{mn}\, e^{n\,h(z)},$$
hence
$$e^{h(z^n) - n\,h(z)} = 1 \quad \text{for all } z.$$
The entire function $h(z^n) - n\,h(z)$ takes values in $2\pi i\,\mathbb{Z}$, so
it is constant:
$$h(z^n) - n\,h(z) = 2\pi i\, k, \qquad k \in \mathbb{Z} \text{ fixed}.$$

Set $H(z) = h(z) + \tfrac{2\pi i\, k}{n-1}$ (valid since $n \geq 2$). A direct s
ubstitution yields
$$H(z^n) = n\, H(z). \tag{$\ast$}$$

---

### Step 3. Solving $H(z^n) = n\,H(z)$.

Write $H(z) = \sum_{j=0}^{\infty} b_j z^j$. Then $H(z^n) = \sum_{j} b_j z^{nj}$
and $n\,H(z) = \sum_{j} n\, b_j z^j$. Comparing the coefficient of $z^r$:

- If $n \nmid r$: $0 = n\, b_r$, so $b_r = 0$.
- If $r = nj$: $b_j = n\, b_{nj}$, i.e., $b_{nj} = b_j / n$.

From $r = 0$: $b_0 = n\, b_0$, so $(n-1)b_0 = 0$, giving $b_0 = 0$.

We prove $b_r = 0$ for all $r$ by strong induction on $r$. For $r = 1, \dots, n-
1$: $n \nmid r$, so $b_r = 0$. For $r \geq n$: if $n \nmid r$ then $b_r = 0$; if
 $r = nj$ with $j < r$, then $b_r = b_j / n = 0$ by the induction hypothesis. He
nce $H \equiv 0$.

Therefore $h$ is constant: $h(z) \equiv -\tfrac{2\pi i\, k}{n-1}$, and $g(z) = e
^{h(z)}$ is a nonzero constant $A$. Thus
$$f(z) = A\, z^m, \qquad A \neq 0,\ m \geq 0.$$

---

### Step 4. Determining $A$.

Substituting $f(z) = A\, z^m$ into the functional equation:
$$A\, z^{mn} = f(z^n) = (f(z))^n = A^n\, z^{mn},$$
so $A = A^n$, i.e., $A^{n-1} = 1$. Thus $A$ is an $(n{-}1)$-th root of unity.

---

### Step 5. Existence of $n$ — collecting all solutions.

The problem requires only that **there exists** some $n \geq 2$. For $f(z) = \ze
ta\, z^m$ with $\zeta$ a root of unity of order $d$: choose $n = d + 1\ (\geq 2)
$, so $n - 1 = d$ and $\zeta^{\,n-1} = \zeta^d = 1$. The equation $f(z^n) = (f(z
))^n$ is then satisfied. Conversely, if $f(z) = A\, z^m$ works for some $n$, the
n $A^{n-1} = 1$ forces $A$ to be a root of unity.

The constant case $m = 0$ gives $f \equiv \zeta$ with $\zeta$ a root of unity, a
nd $f \equiv 0$ is the separate trivial solution (verified directly: $0 = 0$).

---

### Final Answer

The entire functions $f:\mathbb{C}\to\mathbb{C}$ satisfying $f(z^n) = (f(z))^n$
for some $n \in \mathbb{N}$, $n \geq 2$, are precisely:

$$\boxed{f \equiv 0 \quad\text{and}\quad f(z) = \zeta\, z^m \text{ with } m \in
\mathbb{Z}_{\geq 0},\ \zeta \text{ a root of unity}.}$$
