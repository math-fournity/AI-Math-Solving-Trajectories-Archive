Consider the graph H where {n, m} is an edge iff n and m are in different
"blocks" of some partition of ω into finite blocks. Say the blocks are B_k =
{2k, 2k+1}. Then {n, m} is an edge iff n and m are in different blocks. For each
n, the non-neighbors of n are just {n's partner in the same block}, which is
finite. So the neighborhood is cofinite, in U. A U-large clique: take one
element from each block, e.g., all even numbers. This is a clique (any two even
numbers are in different blocks). And if even ∈ U, this works.

But what if we use a partition into infinite blocks? Say ω = ⊔_{k ∈ ω} B_k where
each B_k is infinite. Define H: {n, m} is an edge iff n and m are in different
blocks. For each n, the non-neighbors of n are B_k \ {n} (where n ∈ B_k), which
is infinite. If B_k ∈ U for some k, then for n ∈ B_k, the non-neighbors B_k \
{n} ∈ U (since B_k ∈ U and removing one element keeps it in U for nonprincipal
U). So the neighborhood is NOT in U for n ∈ B_k.
