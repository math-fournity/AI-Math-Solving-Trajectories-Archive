**Answer: Yes, such a function exists.**

**Proof.**

Call a function *everywhere surjective* if its restriction to every nonempty ope
n interval is surjective onto $\mathbb{R}$. We construct one.

**Step 1: Reduction to rational-ended intervals.**

Every open interval $(a,b)$ contains a rational-ended subinterval $(p,q)$ with $
p,q\in\mathbb{Q}$. If $f$ is surjective on every rational-ended interval, then f
or any $(a,b)$, pick $(p,q)\subseteq(a,b)$ with $p,q\in\mathbb{Q}$; since $f|_{(
p,q)}$ is surjective and $(p,q)\subseteq(a,b)$, the restriction $f|_{(a,b)}$ is
also surjective. Hence it suffices to ensure surjectivity on rational intervals
only.

**Step 2: Setup.**

Let $\{I_n : n\in\mathbb{N}\}$ be an enumeration of all open intervals with rati
onal endpoints. Each $I_n$ has cardinality $\mathfrak{c}=|\mathbb{R}|$.

The set of all requirements is $\mathbb{N}\times\mathbb{R}$, which has cardinali
ty $\aleph_0\cdot\mathfrak{c}=\mathfrak{c}$. Let $\mathfrak{c}$ denote the initi
al ordinal of cardinality $\mathfrak{c}$, and well-order the requirements as $\{
(n_\alpha,\, y_\alpha) : \alpha < \mathfrak{c}\}$.

**Step 3: Transfinite recursion.**

We define points $x_\alpha\in\mathbb{R}$ and values $f(x_\alpha)=y_\alpha$ by re
cursion on $\alpha<\mathfrak{c}$.

At stage $\alpha$, the set of points already chosen is $\{x_\beta : \beta<\alpha
\}$, which has cardinality $|\alpha|<\mathfrak{c}$ (since $\mathfrak{c}$ is the
initial ordinal of its cardinality, every ordinal below it has strictly smaller
cardinality). The interval $I_{n_\alpha}$ has cardinality $\mathfrak{c}$, so

$$I_{n_\alpha}\setminus\{x_\beta : \beta<\alpha\}$$

is nonempty (indeed of cardinality $\mathfrak{c}$). Choose any $x_\alpha$ from t
his set and set $f(x_\alpha)=y_\alpha$.

**Step 4: Complete the definition.**

For every $x\in\mathbb{R}\setminus\{x_\alpha:\alpha<\mathfrak{c}\}$, set $f(x)=0
$ (arbitrarily). This defines $f$ on all of $\mathbb{R}$, and the definition is
consistent because the $x_\alpha$ are distinct by construction.

**Step 5: Verification.**

Fix any rational interval $I_n$ and any $y\in\mathbb{R}$. The pair $(n,y)$ appea
rs in our well-ordering, say at index $\alpha$, i.e., $(n_\alpha,y_\alpha)=(n,y)
$. By construction, $x_\alpha\in I_{n_\alpha}=I_n$ and $f(x_\alpha)=y_\alpha=y$.
 Thus $y$ lies in the image of $f|_{I_n}$.

Since $n$ and $y$ were arbitrary, $f|_{I_n}$ is surjective for every rational in
terval $I_n$. By Step 1, $f|_{(a,b)}$ is surjective for every open interval $(a,
b)$.

**Conclusion.** There exists a function $f:\mathbb{R}\to\mathbb{R}$ whose restri
ction to every open interval $(a,b)$ has image $\mathbb{R}$. $\blacksquare$

### PROOF COMPLETE
