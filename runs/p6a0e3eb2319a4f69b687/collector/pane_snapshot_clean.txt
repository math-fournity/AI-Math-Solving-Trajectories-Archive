## 证明

**设置。** 设 $a, b, c$ 为三角形的边长，满足 $a^2 + b^2 + c^2 = 2$。引入标准 Rav
i 变换：令 $x, y, z > 0$，满足
$$a = \frac{y+z}{2},\quad b = \frac{x+z}{2},\quad c = \frac{x+y}{2}.$$
则 $s = a+b+c = x+y+z$，且
$$a+b-c = z,\quad b+c-a = x,\quad c+a-b = y.$$

**用 $x, y, z$ 重写约束。** 计算：
$$a^2+b^2+c^2 = \tfrac{1}{4}\bigl[(y+z)^2+(x+z)^2+(x+y)^2\bigr] = \tfrac{1}{2}\b
igl(x^2+y^2+z^2+xy+yz+zx\bigr).$$
设 $p = x^2+y^2+z^2$ 且 $r = xy+yz+zx$。约束条件变为
$$p + r = 4. \tag{1}$$

**用 $x, y, z$ 重写 $V$。** 首先，
$$ab+bc+ca = \tfrac{1}{4}\bigl[x^2+y^2+z^2 + 3(xy+yz+zx)\bigr] = \tfrac{1}{4}(p
+ 3r).$$
利用 (1) 式，$r = 4-p$，因此
$$ab+bc+ca = \tfrac{1}{4}(p + 3(4-p)) = \tfrac{6-p}{2},$$
所以
$$3 - (ab+bc+ca) = 3 - \tfrac{6-p}{2} = \tfrac{p}{2}.$$
分子为 $(p/2)^3 = p^3/8$。分母为 $(a+b-c)^2(b+c-a)^2(c+a-b)^2 = z^2 x^2 y^2 = (x
yz)^2$。因此
$$V = \frac{p^3/8}{(xyz)^2} = \frac{p^3}{8(xyz)^2}. \tag{2}$$

**$p$ 的取值范围。** 由于 $p - r = \tfrac{1}{2}\bigl[(x-y)^2+(y-z)^2+(z-x)^2\big
r] \ge 0$，我们得到 $p \ge r = 4-p$，即 $p \ge 2$，当且仅当 $x=y=z$ 时等号成立。
又因为 $r = xy+yz+zx > 0$（因为所有变量均为正），所以 $p < 4$。因此 $p \in [2, 4
)$。

**边界行为。** 当 $p \to 4$ 时，$r \to 0$；对于 $x,y,z > 0$，这迫使至少两个变量
趋于 $0$，因此 $(xyz)^2 \to 0$，而 $p^3 \to 64$，从而得到 $V \to \infty$。因此 $
V$ 在边界附近趋于无穷大，任何最小值必定在内部取得。

**寻找内部最小值。** 最小化 $\ln V = 3\ln p - 2\ln x - 2\ln y - 2\ln z - \ln 8$
，其受 $g = p + r - 4 = 0$ 约束。拉格朗日条件 $\nabla(\ln V) = \lambda \nabla g$
 给出
$$\frac{6x}{p} - \frac{2}{x} = \lambda(2x+y+z), \tag{3}$$
对于 $x, y, z$ 呈对称形式。用 (3) 式的 $x$ 版本减去 $y$ 版本：
$$(x-y)\!\left(\frac{6}{p} + \frac{2}{xy}\right) = \lambda(x-y).$$
如果 $x \ne y$，则 $\lambda = \frac{6}{p} + \frac{2}{xy}$。同理，如果 $y \ne z$
，则 $\lambda = \frac{6}{p}+\frac{2}{yz}$，这意味着 $xy = yz$，即 $x = z$；如果
$x \ne z$，则 $\lambda = \frac{6}{p}+\frac{2}{xz} = \frac{6}{p}+\frac{2}{xy}$，
即 $z = y$ —— 这与 $y \ne z$ 矛盾。因此，在任何临界点处，要么所有三个变量相等，
要么恰好有两个相等。

**两变量相等的情况。** 设 $x = y = t$，$z = kt$，其中 $k > 0$。约束条件 (1) 变为
 $t^2(3 + 2k + k^2) = 4$，因此 $t^2 = 4/(k^2+2k+3)$。则
$$p = t^2(2+k^2) = \frac{4(2+k^2)}{k^2+2k+3}, \qquad (xyz)^2 = k^2 t^6 = \frac{6
4\,k^2}{(k^2+2k+3)^3}.$$
代入 (2) 式：
$$V(k) = \frac{p^3}{8(xyz)^2} = \frac{64(2+k^2)^3/(k^2+2k+3)^3}{512\,k^2/(k^2+2k
+3)^3} = \frac{(k^2+2)^3}{8k^2}.$$
求导：$\frac{d}{dk}\!\left[\frac{(k^2+2)^3}{k^2}\right] = \frac{2(k^2+2)^2(2k^2-
2)}{k^3}$，其唯一正根为 $k = 1$。由于 $V(k) \to \infty$ 当 $k\to 0^+$ 且 $k\to\i
nfty$ 时成立，$k=1$ 为全局最小值。此时 $x=y=z$，证实了对称临界点。

**计算最小值。** 在 $x = y = z = t$ 时，约束条件 $p + r = 3t^2 + 3t^2 = 6t^2 = 4
$ 给出 $t^2 = 2/3$。此时
$$a = b = c = t = \sqrt{\tfrac{2}{3}}, \quad a^2+b^2+c^2 = 3\cdot\tfrac{2}{3} =
2\ \checkmark,$$
$$ab+bc+ca = 3\cdot\tfrac{2}{3} = 2, \quad 3-(ab+bc+ca) = 1,$$
$$a+b-c = a = \sqrt{\tfrac{2}{3}}, \quad \text{denominator} = \left(\tfrac{2}{3}
\right)^3 = \tfrac{8}{27},$$
$$V = \frac{1^3}{8/27} = \frac{27}{8}.$$

由于 $V \to \infty$ 在边界处成立，且唯一的内部临界点产生 $V = 27/8$，这便是全局
最小值。

$$\boxed{V_{\min} = \dfrac{27}{8}}$$
