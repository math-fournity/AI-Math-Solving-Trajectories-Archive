**设定**。令 $\alpha = 1 + \sqrt{2}$ 且 $\beta = 1 - \sqrt{2}$。注意：
- $\alpha + \beta = 2$，$\alpha\beta = (1+\sqrt{2})(1-\sqrt{2}) = -1$，因此 $\al
pha, \beta$ 是 $x^2 - 2x - 1 = 0$ 的根。
- $\beta = 1 - \sqrt{2} \approx -0.414$，所以 $|\beta| = \sqrt{2}-1 < 1$。

**关键整数序列**。对于每个整数 $k \geq 0$，定义 $S_k = \alpha^k + \beta^k$。由 $
\alpha, \beta$ 满足 $x^2 = 2x+1$ 可得递推关系：
$$S_k = 2S_{k-1} + S_{k-2}, \quad S_0 = 2,\ S_1 = 2.$$
因此，对于所有 $k \geq 0$，$S_k$ 均为（偶）整数。

**计算奇数幂的分数部分**。对于 $k = 2n-1$（奇数），由于 $\beta < 0$，$\beta^{2n-
1}$ 为负数。同时 $|\beta|^{2n-1} < 1$（对于 $n \geq 1$，因为 $|\beta|<1$）。因此
：
$$\alpha^{2n-1} = S_{2n-1} - \beta^{2n-1} = \underbrace{S_{2n-1}}_{\in \mathbb{Z
}} + \underbrace{(-\beta^{2n-1})}_{\in (0,1)}.$$
由于 $S_{2n-1}$ 是整数且 $-\beta^{2n-1} \in (0,1)$，可得：
$$\{\alpha^{2n-1}\} = -\beta^{2n-1} = |\beta|^{2n-1} = (\sqrt{2}-1)^{2n-1}.$$

**对级数求和**。
$$\sum_{n=1}^{\infty}\{(1+\sqrt{2})^{2n-1}\} = \sum_{n=1}^{\infty}(\sqrt{2}-1)^{
2n-1}.$$
这是一个等比级数，其首项 $a = \sqrt{2}-1$，公比 $r = (\sqrt{2}-1)^2 = 3-2\sqrt{2
} \approx 0.172 < 1$，因此它收敛：
$$\sum_{n=1}^{\infty}(\sqrt{2}-1)^{2n-1} = \frac{\sqrt{2}-1}{1-(3-2\sqrt{2})} =
\frac{\sqrt{2}-1}{2\sqrt{2}-2} = \frac{\sqrt{2}-1}{2(\sqrt{2}-1)} = \frac{1}{2}.
$$

**验证**。对于 $n=1$：$\{1+\sqrt{2}\} = \sqrt{2}-1 \approx 0.414$ ✓。对于 $n=2$
：$(1+\sqrt{2})^3 = 7+5\sqrt{2} \approx 14.071$，分数部分 $\approx 0.071 = (\sqr
t{2}-1)^3$ ✓。部分和趋近于 $0.414 + 0.071 + 0.012 + \cdots \to 0.5$ ✓。

$$\boxed{\dfrac{1}{2}}$$
