## Construction of Orthogonal Latin Squares of Odd Order via Modular Arithmetic

### Setup

Let $n$ be an odd positive integer, $n \geq 3$. We work over the ring $\mathbb{Z
}_n = \{0, 1, \dots, n-1\}$ with arithmetic modulo $n$. We index rows and column
s by elements of $\mathbb{Z}_n$.

### Step 1 — Define a family of candidate squares

For each $a \in \mathbb{Z}_n$, define an $n \times n$ array $L_a$ by

$$L_a(i, j) = a\,i + j \pmod{n}, \qquad i, j \in \mathbb{Z}_n.$$

We will use the $n-1$ squares $L_1, L_2, \dots, L_{n-1}$ (excluding $L_0$, which
 is degenerate). In fact we will show that **any two distinct members of this fa
mily are orthogonal**, giving a complete set of $n-1$ mutually orthogonal Latin
squares (MOLS) of order $n$.

### Step 2 — Verify each $L_a$ is a Latin square (for $a$ coprime to $n$)

We need each row and each column to be a permutation of $\mathbb{Z}_n$.

**Rows.** Fix row $i$. The entries are $L_a(i,j) = ai + j$ as $j$ ranges over $\
mathbb{Z}_n$. Since $j \mapsto ai + j$ is just a translation, it is a bijection
on $\mathbb{Z}_n$. ✓

**Columns.** Fix column $j$. The entries are $L_a(i,j) = ai + j$ as $i$ ranges o
ver $\mathbb{Z}_n$. This is a bijection if and only if $i \mapsto ai$ is a bijec
tion, i.e., iff $\gcd(a, n) = 1$.

So $L_a$ is a Latin square precisely when $a$ is a unit modulo $n$. In particula
r, for $n$ **odd**, every $a \in \{1, \dots, n-1\}$ with $\gcd(a,n)=1$ gives a L
atin square. When $n$ is **prime**, all of $a=1,\dots,n-1$ work, yielding the fu
ll set of $n-1$ MOLS.

For the question as stated ("for $n$ odd"), we select any two units $a \neq b$ m
odulo $n$; such units always exist (e.g. $a=1$ and $b=2$, since $n$ odd $\Righta
rrow$ $\gcd(2,n)=1$). This already produces a pair of orthogonal Latin squares.
To produce a **complete set**, $n$ must be a prime power; for prime $n$ the cons
truction below gives all $n-1$.

### Step 3 — Prove orthogonality of $L_a$ and $L_b$ when $a \neq b$ are units

Two Latin squares $L_a, L_b$ of order $n$ are **orthogonal** if the ordered pair
s $(L_a(i,j), L_b(i,j))$ are all distinct as $(i,j)$ ranges over $\mathbb{Z}_n \
times \mathbb{Z}_n$. Equivalently, the map

$$\Phi : \mathbb{Z}_n \times \mathbb{Z}_n \to \mathbb{Z}_n \times \mathbb{Z}_n,
\quad (i,j) \mapsto (ai+j,\; bi+j)$$

is injective (hence bijective, since both sides have $n^2$ elements).

Suppose $\Phi(i,j) = \Phi(i',j')$. Then

$$ai + j = ai' + j', \qquad bi + j = bi' + j'.$$

Subtracting the second equation from the first:

$$(a - b)\,i = (a - b)\,i' \pmod{n}.$$

Since $a \neq b$ are both units and $n$ is odd, $a - b$ is a unit modulo $n$ (he
re we use that $n$ is odd: for instance with $a=1, b=2$, $a-b = -1$, a unit; mor
e generally, if $n$ is prime, any nonzero $a-b$ is a unit). Multiplying by $(a-b
)^{-1}$ gives $i = i'$. Substituting back into the first equation gives $j = j'$
. Hence $\Phi$ is injective. ✓

Therefore $L_a$ and $L_b$ are orthogonal.

### Step 4 — Why oddness of $n$ matters

The critical algebraic fact used above is:

> **For $n$ odd, there exist distinct units $a, b \in \mathbb{Z}_n$ with $a - b$
 also a unit.**

Concretely, take $a = 1$ and $b = 2$. Then:
- $\gcd(1, n) = 1$ ✓ (always),
- $\gcd(2, n) = 1$ ✓ **because $n$ is odd**,
- $a - b = -1$, and $\gcd(-1, n) = 1$ ✓ (always).

So for **every** odd $n$, the pair $(L_1, L_2)$ with

$$L_1(i,j) = i + j \pmod{n}, \qquad L_2(i,j) = 2i + j \pmod{n}$$

is a pair of orthogonal Latin squares of order $n$.

When $n$ is **even**, $\gcd(2, n) = 2 \neq 1$, so $L_2$ is not even a Latin squa
re (its columns repeat values), and this particular pair fails. (Indeed, no pair
 of orthogonal Latin squares of order $2$ or $6$ exists — Euler's 36 officers pr
oblem — so the oddness hypothesis is genuinely necessary in general.)

### Step 5 — Concrete example, $n = 3$

With $\mathbb{Z}_3 = \{0,1,2\}$:

$$L_1 = \begin{pmatrix} 0&1&2\\ 1&2&0\\ 2&0&1 \end{pmatrix}, \qquad L_2 = \begin
{pmatrix} 0&1&2\\ 2&0&1\\ 1&2&0 \end{pmatrix}.$$

The 9 ordered pairs $(L_1(i,j), L_2(i,j))$ are exactly all of $\{0,1,2\}^2$, con
firming orthogonality.

### Summary of justification

1. **Latin property**: rows are translations (always bijective); columns are dil
ations $i \mapsto ai$, bijective exactly when $\gcd(a,n)=1$.
2. **Orthogonality**: the pair map $(i,j)\mapsto(ai+j,\,bi+j)$ is injective beca
use subtracting the two component equations yields $(a-b)(i-i')=0$, and $a-b$ be
ing a unit forces $i=i'$, then $j=j'$.
3. **Odd $n$ guarantee**: choosing $a=1, b=2$ works because $n$ odd $\Rightarrow
$ $2$ is a unit and $a-b=-1$ is a unit. This is precisely where the hypothesis "
$n$ odd" enters.

For prime odd $n$, taking $a = 1, 2, \dots, n-1$ yields the maximum possible $n-
1$ mutually orthogonal Latin squares of order $n$.
