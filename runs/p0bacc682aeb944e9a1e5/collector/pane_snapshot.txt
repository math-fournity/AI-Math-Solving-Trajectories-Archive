## Proof

**Claim:** Yes, it is possible to partition $\mathbb{N}$ into two sets, neither
of which contains an infinite arithmetic progression.

We prove this by a probabilistic existence argument.

### Setup

Consider the probability space $\Omega = \{0, 1\}^{\mathbb{N}}$ equipped with th
e product $\sigma$-algebra and the product measure $\mathbb{P}$, where each coor
dinate is an independent fair coin flip (i.e., $\mathbb{P}(\omega(n) = 0) = \mat
hbb{P}(\omega(n) = 1) = \tfrac{1}{2}$ for all $n$, independently). A point $\ome
ga \in \Omega$ defines a 2-coloring of $\mathbb{N}$, and hence a partition $A =
\{n : \omega(n)=0\}$, $B = \{n : \omega(n)=1\}$.

### Each fixed AP is monochromatic with probability 0

An infinite arithmetic progression has the form $P_{a,d} = \{a, a+d, a+2d, a+3d,
 \ldots\}$ for some $a \in \mathbb{N}$, $d \geq 1$. The collection of all such A
Ps is **countable**, indexed by $(a, d) \in \mathbb{N} \times \mathbb{N}_{\geq 1
}$.

For a fixed AP $P_{a,d}$, define the event:
$$E_{a,d} = \{\omega \in \Omega : \omega \text{ is constant on } P_{a,d}\} = \bi
gcap_{k=0}^{\infty}\{\omega : \omega(a+kd) = \omega(a)\}.$$

This is a countable intersection of measurable (cylinder) sets, hence measurable
. For any $N \geq 0$:
$$\mathbb{P}(E_{a,d}) \;\leq\; \mathbb{P}\!\left(\bigcap_{k=0}^{N}\{\omega(a+kd)
=\omega(a)\}\right) = \left(\tfrac{1}{2}\right)^{N}.$$

Since this holds for all $N$ and $\left(\tfrac{1}{2}\right)^{N} \to 0$, we concl
ude:
$$\mathbb{P}(E_{a,d}) = 0 \quad \text{for every } (a,d).$$

### Union over countably many APs

The event that **some** infinite AP is monochromatic is $\bigcup_{(a,d)} E_{a,d}
$. Since the index set is countable, by countable subadditivity:
$$\mathbb{P}\!\left(\bigcup_{(a,d)} E_{a,d}\right) \;\leq\; \sum_{(a,d)} \mathbb
{P}(E_{a,d}) = \sum_{(a,d)} 0 = 0.$$

### Conclusion

Therefore:
$$\mathbb{P}\!\left(\text{no infinite AP is monochromatic}\right) = 1 - 0 = 1 >
0.$$

Since this event has positive probability (in fact probability 1), it is **nonem
pty**: there exists a coloring $\omega \in \Omega$ such that no infinite arithme
tic progression is monochromatic. The corresponding partition $A = \{n : \omega(
n) = 0\}$, $B = \{n : \omega(n) = 1\}$ has the property that neither $A$ nor $B$
 contains an infinite arithmetic progression. $\blacksquare$
