## Theorem 7 (Bodirsky, Pinsker, Tsankov) — Statement and Proof

### Statement

**Theorem 7.** Let $\Delta$ be an ordered homogeneous Ramsey structure in a fini
te relational language, with domain $D$. Let $\mathcal{C}$ be a closed function
clone (i.e., closed under composition, containing all projections, and topologic
ally closed in the function space $D^{D^n}$ for each arity $n$) such that $\oper
atorname{Aut}(\Delta) \subseteq \mathcal{C}$. Then for every function $f \in \ma
thcal{C}$ and every finite subset $F \subseteq D$, there exists a **canonical**
function $g \in \mathcal{C}$ such that $g$ agrees with $f$ on $F$ (i.e., $g|_F =
 f|_F$).

Here, a function $g: D^n \to D$ is called **canonical** (with respect to $\Delta
$) if for any two $n$-tuples $\bar{a}, \bar{b} \in D^n$ of the same type — meani
ng they lie in the same orbit under the componentwise action of $\operatorname{A
ut}(\Delta)$ — the outputs $g(\bar{a})$ and $g(\bar{b})$ are also of the same ty
pe.

### Proof

Let $f \in \mathcal{C}$ be $n$-ary, and let $F \subseteq D$ be finite. We constr
uct a canonical $g \in \mathcal{C}$ with $g|_F = f|_F$.

**Step 1: Types and the goal.** Since $\Delta$ is $\omega$-categorical (homogene
ous in a finite relational language implies $\omega$-categoricity by the Ryll-Na
rdzewski theorem), the type of an $n$-tuple $\bar{a}$ is completely determined b
y the quantifier-free type, i.e., by the induced substructure $\Delta|_{\{a_1,\d
ots,a_n\}}$. Equivalently, two tuples have the same type iff some automorphism o
f $\Delta$ maps one to the other. We write $\operatorname{tp}(\bar{a})$ for this
 type. The function $g$ is canonical iff $\operatorname{tp}(\bar{a}) = \operator
name{tp}(\bar{b}) \Rightarrow \operatorname{tp}(g(\bar{a})) = \operatorname{tp}(
g(\bar{b}))$.

**Step 2: Partial canonicity via the Ramsey property.** Fix finitely many types
$\tau_1, \dots, \tau_k$ of $n$-tuples. For each tuple $\bar{a}$ of type $\tau_i$
, the value $f(\bar{a})$ has some type $\sigma$ among the (finitely many, by $\o
mega$-categoricity) 1-types. Thus $f$ induces a coloring: each tuple of type $\t
au_i$ is colored by $\operatorname{tp}(f(\bar{a}))$. Since $\Delta$ is a **Ramse
y structure**, for any finite coloring of $n$-tuples from $D$ (organized by thei
r types), there exists an embedding $e: \Delta \hookrightarrow \Delta$ (a copy o
f $\Delta$ inside itself) such that within $e[\Delta]$, the coloring is constant
 on each type $\tau_i$. In other words, $f \circ e$ is **partially canonical** o
n the types $\tau_1, \dots, \tau_k$: for each $\tau_i$, all tuples of type $\tau
_i$ in $e[\Delta]$ receive the same color under $f \circ e$.

**Step 3: Full canonicity via compactness.** Enumerate all $n$-tuple types as $\
tau_1, \tau_2, \tau_3, \dots$ (countably many, by $\omega$-categoricity). By ite
rating Step 2 and using a standard compactness argument (or Kőnig's infinity lem
ma), we obtain a sequence of embeddings $e_1, e_2, \dots$ and a nested sequence
of copies of $\Delta$ such that for each $k$, the function $f \circ e_k$ is cano
nical on the first $k$ types. A diagonal/compactness extraction yields an embedd
ing $e^*: \Delta \to \Delta$ (more precisely, a limit in the topology of pointwi
se convergence) such that $f \circ e^*$ is canonical on **all** types simultaneo
usly, i.e., $f \circ e^*$ is a canonical function.

**Step 4: Membership in $\mathcal{C}$.** Each embedding $e_k$ is an automorphism
 of $\Delta$ composed with a self-embedding. Since $\Delta$ is homogeneous, ever
y self-embedding of a finite substructure extends to an automorphism. The self-e
mbeddings arising from the Ramsey property can be approximated by automorphisms
on larger and larger finite substructures. Since $\mathcal{C}$ contains $\operat
orname{Aut}(\Delta)$ and is closed under composition, $f \circ \alpha \in \mathc
al{C}$ for every $\alpha \in \operatorname{Aut}(\Delta)$. The canonical function
 $g = f \circ e^*$ is a limit (in the topology of pointwise convergence) of func
tions of the form $f \circ \alpha_j$ with $\alpha_j \in \operatorname{Aut}(\Delt
a)$. Since $\mathcal{C}$ is **topologically closed**, this limit $g$ belongs to
$\mathcal{C}$.

**Step 5: Agreement on $F$.** We need $g|_F = f|_F$. By homogeneity of $\Delta$,
 there exists an automorphism $\beta \in \operatorname{Aut}(\Delta)$ mapping $F$
 to a subset $F'$ of the domain that lies inside the copy $e^*[\Delta]$ in a way
 compatible with the construction. More precisely, we modify the construction: b
efore applying the Ramsey argument, we first use an automorphism to send $F$ int
o the region where the Ramsey copies will be built, and we require the Ramsey su
bstructure to contain the image of $F$. The Ramsey property guarantees we can fi
nd the monochromatic copy containing any prescribed finite set. Then the resulti
ng canonical function $g$, being $f$ composed with an embedding that fixes (the
image of) $F$, satisfies $g|_F = f|_F$ after conjugating back by $\beta$. Since
$\beta \in \operatorname{Aut}(\Delta) \subseteq \mathcal{C}$ and $\mathcal{C}$ i
s a clone, the final function remains in $\mathcal{C}$.

**Conclusion.** The function $g$ is canonical, belongs to $\mathcal{C}$, and agr
ees with $f$ on $F$. $\blacksquare$

### Significance

This theorem is the cornerstone of the Bodirsky–Pinsker–Tsankov program for stud
ying reducts of $\omega$-categorical structures. It reduces questions about arbi
trary functions in a closed clone to questions about **canonical** functions, wh
ich are determined by a finite amount of data (a type-conditioned map from input
 types to output types). This finiteness is what makes decidability results for
definability and reduct classification possible: the behavior of any function in
 the clone can be represented, up to agreement on any finite set, by a canonical
 function whose action is fully described by a finite "behavior table" on the fi
nitely many types of the relevant arity.
