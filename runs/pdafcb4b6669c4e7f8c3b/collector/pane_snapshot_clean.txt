## Solution

We evaluate
$$L = \lim_{n\to\infty}\frac{n}{\ln n}\left(\frac{\sqrt[n]{n!}}{n}-\frac{1}{e}\r
ight).$$

**Step 1: Stirling's expansion.** From Stirling's series,
$$\ln(n!) = n\ln n - n + \tfrac{1}{2}\ln(2\pi n) + \tfrac{1}{12n} + O(n^{-3}).$$

Dividing by $n$:
$$\frac{\ln(n!)}{n} = \ln n - 1 + \frac{\ln(2\pi n)}{2n} + \frac{1}{12n^{2}} + O
(n^{-4}).$$

**Step 2: Rewrite the quantity of interest.** Since $\sqrt[n]{n!}/n = \exp\!\big
(\tfrac{1}{n}\ln(n!) - \ln n\big)$, set
$$u_n = \frac{\ln(2\pi n)}{2n} + \frac{1}{12n^{2}} + O(n^{-4}) \;=\; \frac{\ln n
}{2n} + \frac{\ln(2\pi)}{2n} + O(n^{-2}).$$

Then
$$\frac{\sqrt[n]{n!}}{n} = e^{-1}\,e^{u_n}, \qquad\text{so}\qquad \frac{\sqrt[n]
{n!}}{n} - \frac{1}{e} = \frac{1}{e}\big(e^{u_n}-1\big).$$

**Step 3: Expand $e^{u_n}-1$.** Since $u_n\to 0$, we use $e^u - 1 = u + \frac{u^
2}{2} + \cdots$. The dominant part of $u_n$ is $\frac{\ln n}{2n}$, so
$$u_n^2 = \frac{(\ln n)^2}{4n^2} + O\!\left(\frac{\ln n}{n^2}\right) = O\!\left(
\frac{(\ln n)^2}{n^2}\right).$$

Therefore
$$e^{u_n} - 1 = \frac{\ln n}{2n} + \frac{\ln(2\pi)}{2n} + O\!\left(\frac{(\ln n)
^2}{n^2}\right).$$

**Step 4: Form the limit.**
$$\frac{n}{\ln n}\left(\frac{\sqrt[n]{n!}}{n}-\frac{1}{e}\right) = \frac{1}{e}\l
eft(\frac{1}{2} + \frac{\ln(2\pi)}{2\ln n} + O\!\left(\frac{\ln n}{n}\right)\rig
ht).$$

As $n\to\infty$: $\frac{\ln(2\pi)}{2\ln n}\to 0$ and $\frac{\ln n}{n}\to 0$.

Hence
$$L = \frac{1}{2e}.$$
