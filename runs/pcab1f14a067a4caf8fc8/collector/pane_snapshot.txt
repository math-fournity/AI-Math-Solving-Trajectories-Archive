## Proof

**Setup.** Let $D \subset \mathbb{C}$ be a bounded domain (open, connected, boun
ded), and let $f : D \to \mathbb{C}$ be holomorphic with infinitely many zeros i
n $D$. We investigate whether $f$ can be non-constant.

**Step 1: The zeros must have an accumulation point.**

Let $Z = \{z \in D : f(z) = 0\}$. By hypothesis, $Z$ is an infinite set. Since $
D$ is bounded, $Z$ is an infinite bounded subset of $\mathbb{C}$. By the **Bolza
no–Weierstrass theorem**, $Z$ has an accumulation point $z_0 \in \overline{D} =
D \cup \partial D$.

**Step 2: If the accumulation point lies in $D$, then $f$ is constant (identical
ly zero).**

Suppose $z_0 \in D$. Since $f$ is holomorphic on $D$ and $z_0 \in D$ is an accum
ulation point of the zero set of $f$, the **Identity Theorem** (uniqueness of an
alytic continuation) applies: if a holomorphic function on a domain vanishes on
a set with an accumulation point in that domain, then the function is identicall
y zero on the entire domain. Therefore $f \equiv 0$ on $D$, which is constant.

**Step 3: If the accumulation point lies only on $\partial D$, then $f$ can be n
on-constant.**

We exhibit an explicit counterexample. Consider the domain
$$D = \{z \in \mathbb{C} : 0 < |z| < 1\},$$
the punctured unit disk, which is open, connected, and bounded. Define
$$f(z) = \sin\!\left(\frac{1}{z}\right).$$

- **Holomorphicity:** The map $z \mapsto 1/z$ is holomorphic on $D$ (since $0 \n
otin D$), and $\sin$ is entire, so $f = \sin \circ (1/z)$ is holomorphic on $D$.

- **Infinitely many zeros:** $\sin(w) = 0$ if and only if $w = n\pi$ for $n \in
\mathbb{Z}$. Thus $f(z) = 0$ if and only if $1/z = n\pi$, i.e., $z = \frac{1}{n\
pi}$ for $n \in \mathbb{Z} \setminus \{0\}$. For $n = 1, 2, 3, \ldots$, we have
$z_n = \frac{1}{n\pi} \in \left(0, \frac{1}{\pi}\right] \subset (0,1)$, so each
$z_n \in D$. This gives infinitely many zeros in $D$.

- **Accumulation point on the boundary:** The sequence $\{z_n\}_{n=1}^{\infty} =
 \left\{\frac{1}{n\pi}\right\}$ converges to $0$, which lies on $\partial D$ (si
nce $0 \notin D$ but $0 \in \overline{D}$). Thus the accumulation point is on th
e boundary, not in $D$.

- **Non-constant:** $f$ is clearly non-constant; for instance, $f(2/\pi) = \sin(
\pi/2) = 1 \neq 0 = f(1/\pi)$.

**Step 4: The Identity Theorem does not extend to boundary accumulation points.*
*

The reason Step 3 works is that the Identity Theorem requires the accumulation p
oint to lie **inside** the domain of holomorphicity. When the accumulation point
 is on the boundary, the function need not be holomorphic (or even defined) ther
e—in our example, $z = 0$ is an essential singularity of $\sin(1/z)$—so the theo
rem's hypothesis is not satisfied, and no contradiction arises.

**Conclusion.**

A holomorphic function on a bounded domain with infinitely many zeros **can** be
 non-constant, provided the zeros accumulate only at boundary points of the doma
in (where the function need not be holomorphic). If the zeros accumulate at an i
nterior point, the Identity Theorem forces the function to be identically zero (
constant). The function $f(z) = \sin(1/z)$ on the punctured unit disk $\{0 < |z|
 < 1\}$ is an explicit non-constant holomorphic function with infinitely many ze
ros in a bounded domain.
