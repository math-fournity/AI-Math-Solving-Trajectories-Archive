## Analysis

**Identifying the construction.** The process described is precisely the **Baire
 hierarchy**:

- **Baire class 0**: continuous functions
- **Baire class 1**: pointwise limits of sequences of Baire class 0 functions
- **Baire class 2**: pointwise limits of sequences of Baire class 1 functions
- **Baire class α** (for countable ordinal α): pointwise limits of sequences of
functions from earlier classes (at limit ordinals, take unions)

Iterating this through all countable ordinals α < ω₁ yields exactly the **Borel
measurable functions** (this is the classical Baire–Lebesgue theorem: the hierar
chy is strict at every countable level and stabilizes precisely at ω₁).

ointwise convergence starting from continuous functions (on ℝ to ℝ) is $2^{\alep
h_0}$.

c \in \mathbb{R}$ are all continuous, hence already in Baire class 0. There are
$|\mathbb{R}| = 2^{\aleph_0}$ such functions. So the set has cardinality at leas
t $2^{\aleph_0}$.

**Upper bound ($\leq 2^{\aleph_0}$):** We show the set of Borel measurable funct
ions has cardinality at most $2^{\aleph_0}$.

*Step 1: The number of Borel subsets of ℝ is $2^{\aleph_0}$.*

Build the Borel hierarchy by transfinite induction over $\alpha < \omega_1$:
- Level $\Sigma^0_1$ (open sets): there are $2^{\aleph_0}$ open sets (each is a
countable union of rational-ended intervals, determined by a subset of $\mathbb{
Q}^2$, giving at most $2^{\aleph_0}$).

ha$ has $\leq 2^{\aleph_0}$ sets, the next level has $\leq (2^{\aleph_0})^{\alep
h_0} = 2^{\aleph_0}$ sets.
- At limit stages, take countable unions from earlier levels: still $\leq 2^{\al
eph_0}$.

There are $\aleph_1$ countable ordinals, so the total number of Borel sets is at
 most $\aleph_1 \cdot 2^{\aleph_0} = 2^{\aleph_0}$ (using $\aleph_1 \leq 2^{\ale
ph_0}$). Since every singleton $\{x\}$ is Borel, there are at least $2^{\aleph_0
}$ Borel sets. Thus $|\mathcal{B}(\mathbb{R})| = 2^{\aleph_0}$.

*Step 2: The number of Borel measurable functions is at most $2^{\aleph_0}$.*

A function $f: \mathbb{R} \to \mathbb{R}$ is Borel measurable if and only if $f^
{-1}((q, \infty))$ is a Borel set for every $q \in \mathbb{Q}$. The function is

hbb{Q}\}$, since this determines $f^{-1}((a,b))$ for all rational $a < b$, and h

{Q} : x \in f^{-1}((q,\infty))\}$).

Therefore the number of Borel measurable functions is at most $|\mathcal{B}(\mat
hbb{R})|^{|\mathbb{Q}|} = (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0 \cdot \aleph_0

**Conclusion:** Combining both bounds, the cardinality is exactly $2^{\aleph_0}$

and the Baire–Hausdorff–Banachiewicz theorem) establishes that:
1. The Baire hierarchy is **strict**: for every countable ordinal $\alpha$, ther

Thus "all functions constructible by iterating pointwise convergence from contin
