Yes, such a constant $c_s$ exists. Here is the proof.

---

**Claim.** For $s \in (\tfrac12, \tfrac32)$ there is a constant $c_s$ such that
for all $u \in H^s(\mathbb{T})$ and all $x,y$,
$$|u(x)-u(y)| \le c_s\, \|u\|_{H^s}\, |x-y|^{s-1/2}.$$

**Proof.** Write $h = |x-y|$ (reduced mod $2\pi$, so $h \in [0,\pi]$). Using
$$u(x)-u(y) = \sum_{k\in\mathbb Z} \hat u_k\big(e^{ikx}-e^{iky}\big)$$
and Cauchy–Schwarz,
$$|u(x)-u(y)|^2 \le \Big(\sum_k (1+k^2)^s|\hat u_k|^2\Big)\Big(\sum_k (1+k^2)^{-
s}|e^{ikx}-e^{iky}|^2\Big) = \|u\|_{H^s}^2\, S,$$
where $S := \sum_{k\in\mathbb Z}(1+k^2)^{-s}|e^{ikx}-e^{iky}|^2$. It suffices to
 prove
$$S \le C_s\, h^{2(s-1/2)}.$$

Since $|e^{ikx}-e^{iky}| = 2|\sin(kh/2)| \le \min(2,|k|h)$, we have $|e^{ikx}-e^
{iky}|^2 \le \min(4, k^2 h^2)$.

**Case $h \ge 1$.** Since $s > 1/2$, the series $\sum_k (1+k^2)^{-s}$ converges,
 so $S \le 4\sum_k (1+k^2)^{-s} =: C_s < \infty$. As $h^{2(s-1/2)} \ge 1$ (becau
se $s>1/2$), the bound $S \le C_s h^{2(s-1/2)}$ holds.

**Case $0 < h < 1$.** Set $N = \lfloor 1/h\rfloor$, so $\frac{1}{2h}\le N \le \f
rac1h$. Split $S = S_1 + S_2$ with
$$S_1 = \sum_{|k|\le N}(1+k^2)^{-s}|e^{ikx}-e^{iky}|^2,\qquad S_2 = \sum_{|k|>N}
(1+k^2)^{-s}|e^{ikx}-e^{iky}|^2.$$

*Bound on $S_1$.* For $|k|\le N$ use $|e^{ikx}-e^{iky}|^2 \le k^2 h^2$:
$$S_1 \le h^2 \sum_{|k|\le N} k^2(1+k^2)^{-s} \le h^2 \sum_{|k|\le N}(1+k^2)^{1-
s}.$$
Since $1-s \in (-\tfrac12,\tfrac12)$, we have $(1+k^2)^{1-s}\asymp k^{2-2s}$ wit
h $2-2s\in(-1,1)$. Because $s<\tfrac32$, the exponent $3-2s>0$, so
$$\sum_{k=1}^{N} k^{2-2s} \le \frac{N^{3-2s}}{3-2s} \le C\, N^{3-2s}.$$
Thus $S_1 \le C\, h^2 N^{3-2s} \le C\, h^2 \cdot h^{-(3-2s)} = C\, h^{2s-1}$.

*Bound on $S_2$.* For $|k|>N$ use $|e^{ikx}-e^{iky}|^2 \le 4$:
$$S_2 \le 4\sum_{|k|>N}(1+k^2)^{-s} \le C\sum_{k>N} k^{-2s}.$$
Since $s>\tfrac12$, i.e. $2s>1$, the tail satisfies $\sum_{k>N}k^{-2s} \le \frac
{N^{1-2s}}{2s-1} \le C\, N^{1-2s}$. Using $N\ge \frac{1}{2h}$,
$$S_2 \le C\, N^{1-2s} \le C\, h^{2s-1}.$$

Combining,
$$S = S_1 + S_2 \le C_s\, h^{2s-1} = C_s\, h^{2(s-1/2)}.$$

Therefore
$$|u(x)-u(y)| \le \sqrt{C_s}\,\|u\|_{H^s}\, h^{s-1/2} = c_s\,\|u\|_{H^s}\,|x-y|^
{s-1/2},$$
with $c_s = \sqrt{C_s}$ depending only on $s$. $\blacksquare$

---

**Remark.** The endpoint restrictions are sharp: at $s=\tfrac12$ the series $\su
m_k k^{-2s}$ diverges (no embedding into continuous functions), and at $s=\tfrac
32$ the sum $\sum_{k\le N}k^{2-2s}$ becomes $\log N$, producing a logarithmic lo
ss instead of the pure power $h^{2(s-1/2)}$. Hence the open interval $(\tfrac12,
\tfrac32)$ is exactly the range in which the stated Hölder estimate of order $s-
\tfrac12$ holds.
