## Solution

We seek a function $h(y)$ satisfying

$$y = \int_{0}^{\infty} h\!\left(\frac{y}{x}\right) dx.$$

**Substitution.** Fix $y > 0$ and set $u = \dfrac{y}{x}$, so $x = \dfrac{y}{u}$
and $dx = -\dfrac{y}{u^{2}}\,du$. The limits transform as $x \to 0^{+} \Rightarr
ow u \to +\infty$ and $x \to +\infty \Rightarrow u \to 0^{+}$. Therefore

$$\int_{0}^{\infty} h\!\left(\frac{y}{x}\right) dx = \int_{\infty}^{0} h(u)\left
(-\frac{y}{u^{2}}\right) du = y\int_{0}^{\infty} \frac{h(u)}{u^{2}}\,du.$$

**Reduced condition.** The original equation becomes

$$y = y\int_{0}^{\infty} \frac{h(u)}{u^{2}}\,du,$$

which (for $y \neq 0$) is equivalent to the single constraint

$$\int_{0}^{\infty} \frac{h(u)}{u^{2}}\,du = 1. \tag{$\ast$}$$

Thus the problem reduces to finding any function $h$ on $(0,\infty)$ whose weigh
ted integral against $u^{-2}$ equals $1$.

**Constructing a solution.** Choose any probability density $f$ on $(0,\infty)$
with $\int_{0}^{\infty} f(u)\,du = 1$, and set

$$h(u) = u^{2}\,f(u).$$

Then $\dfrac{h(u)}{u^{2}} = f(u)$, and condition $(\ast)$ is automatically satis
fied.

Taking the exponential density $f(u) = e^{-u}$ ($u > 0$), we obtain the explicit
 solution

$$\boxed{h(y) = y^{2}\,e^{-y}.}$$

**Verification.** With $h(y) = y^{2}e^{-y}$,

$$\int_{0}^{\infty} h\!\left(\frac{y}{x}\right) dx = \int_{0}^{\infty} \left(\fr
ac{y}{x}\right)^{2} e^{-y/x} dx.$$

Using the same substitution $u = y/x$:

$$= y\int_{0}^{\infty} \frac{u^{2}e^{-u}}{u^{2}}\,du = y\int_{0}^{\infty} e^{-u}
\,du = y\cdot 1 = y. \quad\checkmark$$

**Remark.** The solution is far from unique: for any density $f$ on $(0,\infty)$
, the function $h(y) = y^{2}f(y)$ satisfies the equation. For instance, $h(y) =
y^{2}\cdot\frac{1}{\pi}\cdot\frac{1}{1+y^{2}}$ (Cauchy density) also works, as d
oes $h(y) = y^{2}\cdot\frac{1}{\sqrt{2\pi}}e^{-y^{2}/2}$ (half-normal density, r
estricted to $y>0$). The simplest representative is $h(y) = y^{2}e^{-y}$.
