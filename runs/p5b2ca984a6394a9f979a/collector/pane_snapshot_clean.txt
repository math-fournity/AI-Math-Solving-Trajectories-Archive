## Proof

**Claim:** The supremum is $n$, and moreover it is attained (so it is a maximum)
.

### Upper Bound: $\lambda_{\max}(B) \leq n$

Let $B \in M_n(\mathbb{C})$ be a correlation matrix. By definition:
- $B$ is positive semidefinite, so all eigenvalues $\lambda_1, \ldots, \lambda_n
$ are non-negative.
- $B_{ii} = 1$ for all $i$, so $\operatorname{tr}(B) = \sum_{i=1}^n B_{ii} = n$.

Since the trace equals the sum of eigenvalues:
$$\sum_{i=1}^n \lambda_i = \operatorname{tr}(B) = n.$$

As all $\lambda_i \geq 0$, we have:
$$\lambda_{\max}(B) \leq \sum_{i=1}^n \lambda_i = n.$$

### Lower Bound: $\lambda_{\max}(B) = n$ is achievable

Consider the vector $v = (1, 1, \ldots, 1)^T \in \mathbb{C}^n$ and the rank-1 ma
trix:
$$B_0 = v v^* \in M_n(\mathbb{C}).$$

**$B_0$ is positive semidefinite:** For any $x \in \mathbb{C}^n$,
$$x^* B_0 x = x^* v v^* x = |v^* x|^2 \geq 0.$$

**Diagonal entries are 1:**
$$(B_0)_{ii} = v_i \overline{v_i} = |v_i|^2 = |1|^2 = 1.$$

So $B_0$ is a valid correlation matrix.

**Eigenvalues of $B_0$:** Since $B_0 = vv^*$ has rank 1, it has one nonzero eige
nvalue equal to $\operatorname{tr}(B_0) = n$ (with eigenvector $v$), and eigenva
lue $0$ with multiplicity $n-1$.

Thus $\lambda_{\max}(B_0) = n$.

### Conclusion

We have shown:
- For every correlation matrix $B$: $\lambda_{\max}(B) \leq n$.
- There exists a correlation matrix $B_0$ with $\lambda_{\max}(B_0) = n$.

Therefore, the supremum of the set of maximum eigenvalues of correlation matrice
s in $M_n(\mathbb{C})$ is:

$$\boxed{n}$$
