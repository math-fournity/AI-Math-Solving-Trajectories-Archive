## Proof

**Claim:** Yes. For any real symmetric matrices $A, B$ with $A$ positive definit
e, there always exists an invertible real matrix $V$ such that $V^{T}AV = I$ (th
e identity, i.e. a diagonal matrix with all diagonal entries equal to $1$) and $
V^{T}BV$ is diagonal.

**Construction.**

**Step 1 — Reduce $A$ to the identity.** Since $A$ is real symmetric positive de
finite, it admits a Cholesky-type factorization. Concretely, by the spectral the
orem there exists an orthogonal matrix $U$ and a diagonal matrix $\Lambda = \ope
ratorname{diag}(\lambda_1,\dots,\lambda_n)$ with all $\lambda_i > 0$ such that
$$A = U\Lambda U^{T}.$$
Set $\Lambda^{-1/2} = \operatorname{diag}(\lambda_1^{-1/2},\dots,\lambda_n^{-1/2
})$ and define
$$P := U\Lambda^{-1/2}.$$
Then $P$ is invertible and
$$P^{T}AP = \Lambda^{-1/2}U^{T}\,U\Lambda U^{T}\,U\Lambda^{-1/2} = \Lambda^{-1/2
}\Lambda\Lambda^{-1/2} = I.$$

**Step 2 — Diagonalize the transformed $B$.** Define
$$C := P^{T}BP.$$
Since $B$ is symmetric, $C^{T} = P^{T}B^{T}P = P^{T}BP = C$, so $C$ is real symm
etric. By the spectral theorem, there exists an orthogonal matrix $Q$ (so $Q^{T}
Q = QQ^{T} = I$) and a real diagonal matrix $D = \operatorname{diag}(d_1,\dots,d
_n)$ such that
$$C = QDQ^{T}.$$

**Step 3 — Combine.** Set
$$V := PQ.$$
This is invertible (product of invertible matrices). Compute each quadratic form
:

$$V^{T}AV = (PQ)^{T}A(PQ) = Q^{T}(P^{T}AP)Q = Q^{T}IQ = Q^{T}Q = I,$$

which is a diagonal matrix with every diagonal entry equal to $1$.

$$V^{T}BV = (PQ)^{T}B(PQ) = Q^{T}(P^{T}BP)Q = Q^{T}CQ = Q^{T}(QDQ^{T})Q = (Q^{T}
Q)D(Q^{T}Q) = D,$$

which is diagonal.

**Conclusion.** The matrix $V = PQ = U\Lambda^{-1/2}Q$ is a real invertible tran
sformation simultaneously making $V^{T}AV = I$ and $V^{T}BV$ diagonal. The diago
nal entries of $V^{T}BV$ are precisely the eigenvalues of $C = P^{T}BP$, i.e. th
e generalized eigenvalues of the pair $(B, A)$. Hence such a $V$ **always exists
** under the stated hypotheses ($A$ symmetric positive definite, $B$ symmetric).
 $\blacksquare$
