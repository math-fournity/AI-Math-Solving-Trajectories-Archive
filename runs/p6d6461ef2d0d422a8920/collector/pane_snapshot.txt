## 证明

拉普拉斯方程的极坐标形式为

$$\frac{1}{r}\frac{\partial}{\partial r}\left(r\frac{\partial U}{\partial r}\rig
ht) + \frac{1}{r^2}\frac{\partial^2 U}{\partial \theta^2} = 0,$$

定义在圆盘 $r \le a$ 上，边界条件为 $r=a$ 处的 $U(a,\theta) = f(\theta)$，其中

$$f(\theta) = \begin{cases} 2\theta, & 0 < \theta < \pi,\\ 0, & \pi < \theta < 2
\pi. \end{cases}$$

**调和函数的均值定理。** 一个熟知的结论是：如果 $U$ 在以原点为中心、半径为 $a$
的圆盘内调和，且在边界上连续，那么原点处的值等于边界值的平均值：

$$U(0,\theta) = \frac{1}{2\pi}\int_0^{2\pi} U(a,\phi)\,d\phi = \frac{1}{2\pi}\in
t_0^{2\pi} f(\phi)\,d\phi.$$

这可以通过圆盘的泊松积分公式最直接地看出：

$$U(r,\theta) = \frac{1}{2\pi}\int_0^{2\pi} \frac{a^2 - r^2}{a^2 - 2ar\cos(\thet
a-\phi) + r^2}\,f(\phi)\,d\phi.$$

在 $r=0$ 处，泊松核简化为 $\frac{a^2}{a^2} = 1$，因此

$$U(0,\theta) = \frac{1}{2\pi}\int_0^{2\pi} f(\phi)\,d\phi.$$

**计算积分。** 利用 $f$ 的分段定义：

$$\int_0^{2\pi} f(\phi)\,d\phi = \int_0^{\pi} 2\phi\,d\phi + \int_{\pi}^{2\pi} 0
\,d\phi = \int_0^{\pi} 2\phi\,d\phi = \bigl[\phi^2\bigr]_0^{\pi} = \pi^2.$$

因此，

$$U(0,\theta) = \frac{1}{2\pi}\cdot \pi^2 = \frac{\pi}{2}.$$

**结论。** $U(0,\theta)$ 的值与 $\theta$ 无关（正如圆盘中心的调和函数均值性质所
要求的那样），并且

$$\boxed{U(0,\theta) = \dfrac{\pi}{2}}.$$
