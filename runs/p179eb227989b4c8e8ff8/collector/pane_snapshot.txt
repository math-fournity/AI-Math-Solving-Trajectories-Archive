## Proof

Let $A$ be a Hermitian matrix. We interpret the two quantities in question.

**The left-hand side: $\| |A| \|_2$.**

Since $A$ is Hermitian, it admits a spectral decomposition $A = U \operatorname{
diag}(\lambda_1, \dots, \lambda_n) U^*$ with $U$ unitary and $\lambda_i \in \mat
hbb{R}$. The absolute value (matrix absolute value) is
$$|A| = (A^*A)^{1/2} = (A^2)^{1/2} = U \operatorname{diag}(|\lambda_1|, \dots, |
\lambda_n|) U^*,$$
so the eigenvalues of $|A|$ are $|\lambda_1|, \dots, |\lambda_n|$. The operator
2-norm (spectral norm) is the largest singular value, hence
$$\| |A| \|_2 = \max_i |\lambda_i|.$$

**The right-hand side: $\max_{\|x\|=1} |\langle Ax, x\rangle|$.**

For a unit vector $x$, write $x = Uy$ with $\|y\|=1$. Then
$$\langle Ax, x\rangle = x^* A x = y^* \operatorname{diag}(\lambda_1,\dots,\lamb
da_n) y = \sum_{i=1}^n \lambda_i |y_i|^2.$$
This is a convex combination of the real eigenvalues $\lambda_i$ (since $\sum |y
_i|^2 = 1$), so
$$\langle Ax, x\rangle \in [\min_i \lambda_i,\; \max_i \lambda_i].$$
Conversely, choosing $x$ to be the eigenvector corresponding to $\lambda_j$ give
s $\langle Ax,x\rangle = \lambda_j$. Therefore
$$\max_{\|x\|=1} |\langle Ax, x\rangle| = \max\bigl(|\min_i \lambda_i|,\; |\max_
i \lambda_i|\bigr) = \max_i |\lambda_i|.$$

**Conclusion.**

Both quantities equal $\max_i |\lambda_i|$, the spectral radius of $A$. Hence
$$\boxed{\| |A| \|_2 \;=\; \max_{\|x\|=1} |\langle Ax, x\rangle|.}$$

The equality holds because for a Hermitian matrix the numerical radius $w(A) = \
max_{\|x\|=1}|x^*Ax|$ coincides with the operator norm $\|A\|_2 = \max_i|\lambda
_i|$, and $\||A|\|_2 = \|A\|_2$ since $|A|$ shares the same set of singular valu
es $|\lambda_i|$ as $A$.
