## Solution

**Setup.** The diagonal $AC$ splits $ABCD$ into triangles $ABC$ and $ACD$, with
$B$ and $D$ on opposite sides of line $AC$.

Given $AC = BC = AD = 25$, let $AB = m$ and $CD = n$ (positive integers). Then:
- $\triangle ABC$ is isosceles with $AC = BC = 25$, base $AB = m$.
- $\triangle ACD$ is isosceles with $AC = AD = 25$, base $CD = n$.

**Triangle inequality:** $0 < m < 50$ and $0 < n < 50$, so $m, n \in \{1, 2, \ld
ots, 49\}$.

**Perimeter** $= m + n + 50$, so we maximize/minimize $m + n$.

**Convexity check.** Place $A = (0,0)$, $C = (25,0)$, $B$ above, $D$ below. Comp
uting cross products at each vertex:
- At $B$: always $-25\,y_B < 0$. ✓
- At $D$: always $25\,y_D < 0$. ✓
- At $A$: requires $x_B|y_D| + y_B x_D > 0$ (automatic when $x_D > 0$, i.e., $n
\leq 35$; for $n \geq 36$ need $\frac{m}{\sqrt{2500-m^2}} > \frac{n^2-1250}{n\sq
rt{2500-n^2}}$).
- At $C$: requires $(25-x_D)\,y_B > |y_D|(x_B-25)$ (automatic when $m \leq 35$;
for $m \geq 36$ need $\frac{m\sqrt{2500-m^2}}{n\sqrt{2500-n^2}} > \frac{m^2-1250
}{n^2}$, which simplifies to $1250/n^2 > 0$ when $m=n$).

**For $m = n = 49$:** At $A$: $49 > 1151/49 \approx 23.5$ ✓. At $C$: $1250/49^2
> 0$ ✓. **Convex.**

**For $m = n = 1$:** $x_D > 0$ and $x_B < 25$, so both conditions automatic ✓. *
*Convex.**

Thus $P_{\max}$: $m = n = 49$, perimeter $148$. $P_{\min}$: $m = n = 1$, perimet
er $52$.

**Area computation.** For $\triangle ABC$ with $AC = BC = 25$, $AB = m$:
$$\text{Area} = \frac{m\sqrt{2500 - m^2}}{4}$$

(Verified via Heron's formula: $s = (50+m)/2$, area $= \sqrt{s(s-25)^2(s-m)} = \
frac{m\sqrt{2500-m^2}}{4}$.)

By symmetry, $\triangle ACD$ with $CD = n$ has area $\frac{n\sqrt{2500-n^2}}{4}$
.

**$P_{\max}$ area** ($m = n = 49$):
$$\text{Area}_{\max} = 2 \cdot \frac{49\sqrt{2500-2401}}{4} = \frac{49\sqrt{99}}
{2} = \frac{49 \cdot 3\sqrt{11}}{2} = \frac{147\sqrt{11}}{2}$$

**$P_{\min}$ area** ($m = n = 1$):
$$\text{Area}_{\min} = 2 \cdot \frac{\sqrt{2500-1}}{4} = \frac{\sqrt{2499}}{2} =
 \frac{7\sqrt{51}}{2}$$

since $2499 = 7^2 \cdot 51$.

**Ratio:**
$$\frac{\text{Area}_{\max}}{\text{Area}_{\min}} = \frac{147\sqrt{11}/2}{7\sqrt{5
1}/2} = \frac{147\sqrt{11}}{7\sqrt{51}} = \frac{21\sqrt{11}}{\sqrt{51}} = \frac{
21\sqrt{11}\cdot\sqrt{51}}{51} = \frac{21\sqrt{561}}{51} = \frac{7\sqrt{561}}{17
}$$

**Simplification check:** $561 = 3 \cdot 11 \cdot 17$ is squarefree ✓. $\gcd(7,
17) = 1$ ✓.

So $a = 7$, $b = 561$, $c = 17$.

$$a + b + c = 7 + 561 + 17 = \boxed{585}$$
