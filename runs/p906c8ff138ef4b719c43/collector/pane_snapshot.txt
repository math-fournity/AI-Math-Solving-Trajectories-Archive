Looking at this problem, I need to determine when the conformal metric $g = (1-r
^2)^{2c}\, g_{\text{Euc}}$ on the open unit ball is geodesically complete.

## Proof

**Setup.** Let $r^2 = x^2+y^2+z^2$ and $\rho = 1-r^2 > 0$ on $B$. The metric is
$g = \rho^{2c}\, g_0$ where $g_0 = dx^2+dy^2+dz^2$ is the Euclidean metric. Sinc
e $\rho > 0$ on $B$, the conformal factor $\rho^{2c}$ is smooth and positive for
 every real $c$, so $g$ is a valid Riemannian metric on $B$ for all $c \in \math
bb{R}$.

**Key tool: Hopf–Rinow.** A connected Riemannian manifold is geodesically comple
te if and only if it is complete as a metric space, equivalently, if and only if
 every closed bounded subset is compact.

**Step 1: Distance to the boundary.** Along a radial path from the origin to rad
ius $r$, the $g$-length is
$$d_g(0, r) = \int_0^r (1-t^2)^c\, dt.$$
The distance from the origin to the boundary $\partial B$ (at $r=1$) is
$$D = \int_0^1 (1-t^2)^c\, dt.$$
Near $t = 1$, set $u = 1-t$; then $1-t^2 = (1-t)(1+t) \sim 2u$, so the integrand
 behaves like $2^c\, u^c$. The integral $\int_0 u^c\, du$ converges if and only
if $c > -1$. Therefore:

- **$c > -1$:** $D < \infty$ — the boundary is at **finite** $g$-distance.
- **$c \leq -1$:** $D = \infty$ — the boundary is at **infinite** $g$-distance.

(At the critical value $c=-1$: $\int_0^1 \frac{dt}{1-t^2} = \frac{1}{2}\ln\frac{
1+t}{1-t}\big|_0^1 = +\infty$. ✓)

The same analysis applies from any interior point $p$ at radius $r_0 < 1$: the d
istance to the boundary is $\int_{r_0}^1 (1-t^2)^c\, dt$, which is finite iff $c
 > -1$ and infinite iff $c \leq -1$.

**Step 2: $c > -1$ implies geodesically incomplete.** Since the boundary is at f
inite distance, consider the sequence $p_n = (1 - \tfrac{1}{n},\, 0,\, 0) \in B$
. The $g$-distance between consecutive points is
$$d_g(p_n, p_{n+1}) = \int_{1-1/n}^{1-1/(n+1)} (1-t^2)^c\, dt \to 0 \quad \text{
as } n \to \infty,$$
since the integrand is integrable (for $c > -1$) and the integration interval sh
rinks to a point. More generally, $(p_n)$ is $g$-Cauchy but has no limit in $B$
(it converges Euclideanly to $(1,0,0) \notin B$). Hence $(B, d_g)$ is not comple
te as a metric space, so by Hopf–Rinow, $g$ is **not** geodesically complete.

**Step 3: $c \leq -1$ implies geodesically complete.** Since every point is at i
nfinite $g$-distance from the boundary, any $g$-bounded set is contained in a Eu
clidean ball $\{r \leq R\}$ for some $R < 1$. On the compact set $\{r \leq R\}$,
 the conformal factor $\rho^{2c} = (1-r^2)^{2c}$ is continuous and strictly posi
tive, so there exist constants $0 < m \leq M$ with
$$m\, g_0 \leq g \leq M\, g_0 \quad \text{on } \{r \leq R\}.$$
Thus $g$-closed $g$-bounded sets are Euclidean closed and Euclidean bounded with
in $\{r \leq R\}$, hence compact. By Hopf–Rinow (equivalence: closed bounded set
s compact $\iff$ geodesically complete), $g$ is **geodesically complete**.

**Conclusion.** The metric $g$ is geodesically complete on $B$ if and only if $c
 \leq -1$. The critical (threshold) value is:

$$\boxed{c = -1}.$$
