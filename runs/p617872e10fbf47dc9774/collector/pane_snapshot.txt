**Notation.** Let $R_k = \frac{10^k - 1}{9}$ for $k \geq 1$, so the repunits are
 $R_1, R_2, R_3, \ldots$ Note the key identity $9R_k + 1 = 10^k$.

---

**Claim.** The solutions are exactly
$$f(x) = \frac{10^j(9x+1)^d - 1}{9},$$
where $d$ is a non-negative integer, $j$ is an integer, and $d + j \geq 1$.

---

**Verification that these work.** For any repunit $R_k$:
$$f(R_k) = \frac{10^j(9R_k + 1)^d - 1}{9} = \frac{10^j \cdot 10^{dk} - 1}{9} = \
frac{10^{dk+j} - 1}{9} = R_{dk+j}.$$
Since $d + j \geq 1$ and $k \geq 1$, we have $dk + j \geq d + j \geq 1$, so $R_{
dk+j}$ is a valid repunit. The coefficients are real (indeed rational), and the
degree is $d$ (the leading coefficient is $10^j \cdot 9^{d-1} \neq 0$ for $d \ge
q 1$; for $d = 0$ it's the constant $R_j \neq 0$ since $j \geq 1$). $\checkmark$

**Proof that these are the only solutions.**

Let $f$ be a polynomial with real coefficients such that $f(R_k)$ is a repunit f
or every $k \geq 1$. Then for each $k$, there exists a positive integer $m_k$ wi
th $f(R_k) = R_{m_k} = \frac{10^{m_k}-1}{9}$, i.e.,
$$9f(R_k) + 1 = 10^{m_k}.$$

Define $g(x) = 9f(x) + 1$, a polynomial with real coefficients. Define $h(y) = g
\!\left(\frac{y-1}{9}\right)$, also a polynomial in $y$ with real coefficients.
Since $R_k = \frac{10^k - 1}{9}$, we have $h(10^k) = g(R_k) = 10^{m_k}$ for all
$k \geq 1$.

**Case 1: $g$ is constant (degree $d = 0$).** Then $h(y) = C$ for some constant,
 and $h(10^k) = 10^{m_k} = C$ for all $k$. So $m_k$ is constant, say $m_k = j$ f
or all $k$, and $C = 10^j$. Then $f(x) = \frac{10^j - 1}{9} = R_j$, requiring $j
 \geq 1$ (i.e., $d + j \geq 1$). This matches the formula.

**Case 2: $g$ has degree $d \geq 1$.** Then $h$ has degree $d$. Write $h(y) = a_
d y^d + a_{d-1}y^{d-1} + \cdots + a_0$ with $a_d \neq 0$.

Since $h(10^k) = 10^{m_k} > 0$ for all $k$, the leading coefficient satisfies $a
_d > 0$ (for large $k$, the sign of $h(10^k)$ is determined by $a_d$).

Now:
$$10^{m_k} = a_d \cdot 10^{dk} + a_{d-1} \cdot 10^{(d-1)k} + \cdots + a_0 = a_d
\cdot 10^{dk}\left(1 + O(10^{-k})\right).$$

Taking $\log_{10}$:
$$m_k = dk + \log_{10} a_d + O(10^{-k}).$$

Since $m_k$ and $dk$ are integers, $m_k - dk$ is an integer converging to $\log_
{10} a_d$. Therefore, for all sufficiently large $k$, $m_k - dk$ equals a fixed
integer $j$, and $\log_{10} a_d = j$, i.e., $a_d = 10^j$.

Thus $h(10^k) = 10^{dk + j}$ for all $k \geq K$ (some $K$). Consider the polynom
ial
$$p(y) = h(y) - 10^j y^d.$$
This has degree at most $d - 1$ (the leading terms cancel). But $p(10^k) = 0$ fo
r all $k \geq K$, giving infinitely many roots. A nonzero polynomial of degree $
\leq d-1$ has at most $d-1$ roots, so $p \equiv 0$, meaning:
$$h(y) = 10^j y^d.$$

Therefore $h(10^k) = 10^{dk+j}$ for **all** $k \geq 1$ (not just large $k$), so
$m_k = dk + j$ for all $k \geq 1$.

Recovering $f$: since $g(x) = h(9x+1) = 10^j(9x+1)^d$,
$$f(x) = \frac{g(x) - 1}{9} = \frac{10^j(9x+1)^d - 1}{9}.$$

The condition that $m_k = dk + j \geq 1$ for all $k \geq 1$ is equivalent to $d
+ j \geq 1$ (the minimum of $dk + j$ over $k \geq 1$ is $d + j$, achieved at $k
= 1$).

---

**Conclusion.** The complete set of polynomials $f$ with real coefficients mappi
ng repunits to repunits is:
$$\boxed{f(x) = \frac{10^j\,(9x+1)^d - 1}{9}}$$
where $d$ is a non-negative integer, $j$ is an integer, and $d + j \geq 1$.

Equivalently, $9f(x) + 1 = 10^j(9x+1)^d$. Notable special cases include:
- $d = 0, j \geq 1$: constant polynomials $f(x) = R_j$ (e.g., $f \equiv 1$).
- $d = 1, j \geq 0$: linear maps $f(x) = 10^j x + R_j$ (e.g., $f(x) = x$ when $j
=0$; $f(x) = 10x + 1$ when $j=1$).
- $d = 2, j \geq -1$: quadratics like $f(x) = \frac{9x^2+2x-1}{10}$ (when $j=-1$
), which sends $R_k \mapsto R_{2k-1}$.
