### Setup

Let $N$ have digits $d_1 d_2 \cdots d_k$ (left to right). The divisibility-by-11
 test uses the alternating sum $S = d_1 - d_2 + d_3 - d_4 + \cdots = \sum_{i=1}^
k (-1)^{i-1} d_i$; $N \equiv 0 \pmod{11} \iff S \equiv 0 \pmod{11}$.

Replacing digit $d_i$ by $d_i \pm 1$ changes $S$ by $\pm(-1)^{i-1}$.

### Key constraint: every digit is 0 or 9

For each position $i$, **every** valid replacement (digit differing by 1) must y
ield a multiple of 11.

- If $0 < d_i < 9$, both $d_i-1$ and $d_i+1$ are valid, requiring:
$$S + (-1)^{i-1} \equiv 0 \pmod{11} \quad \text{and} \quad S - (-1)^{i-1} \equiv
 0 \pmod{11}.$$
Adding gives $2S \equiv 0 \pmod{11}$, so $S \equiv 0 \pmod{11}$, which then forc
es $(-1)^{i-1} \equiv 0 \pmod{11}$ — impossible. **Contradiction.**

Therefore **every digit of $N$ is either 0 or 9**. Since the leading digit canno
t be 0, $d_1 = 9$.

### Position constraints

Let $P = \sum_{i:\, d_i=9} (-1)^{i-1}$, so $S = 9P$.

- **Digit 9 at position $i$** (only replacement $9 \to 8$): $S - (-1)^{i-1} \equ
iv 0 \pmod{11}$, i.e., $9P \equiv (-1)^{i-1} \pmod{11}$.
- **Digit 0 at position $i$** (only replacement $0 \to 1$): $S + (-1)^{i-1} \equ
iv 0 \pmod{11}$, i.e., $9P \equiv -(-1)^{i-1} \pmod{11}$.

Since $9 \equiv -2 \pmod{11}$:

- 9-positions: $-2P \equiv (-1)^{i-1} \pmod{11}$.
- 0-positions: $-2P \equiv -(-1)^{i-1} \pmod{11}$, i.e., $2P \equiv (-1)^{i-1} \
pmod{11}$.

Both require $2P \equiv \pm 1 \pmod{11}$.

**Case $2P \equiv 1 \pmod{11}$** ($P \equiv 6$): 9-positions have $(-1)^{i-1}=-1
$ (even $i$), 0-positions have $(-1)^{i-1}=+1$ (odd $i$). Then position 1 (odd)
is 0 — impossible (leading digit).

**Case $2P \equiv -1 \pmod{11}$** ($P \equiv 5$): 9-positions have $(-1)^{i-1}=+
1$ (odd $i$), 0-positions have $(-1)^{i-1}=-1$ (even $i$). Position 1 (odd) is 9
. ✓

So $N$ alternates **9, 0, 9, 0, 9, 0, …** starting with 9, and the number of 9's
 satisfies $P \equiv 5 \pmod{11}$.

### Minimality

Since all 9's are at odd positions, $(-1)^{i-1}=+1$ for each, so $P$ = (number o
f 9's) = $\lceil k/2 \rceil$ for a $k$-digit number. We need $\lceil k/2 \rceil
\equiv 5 \pmod{11}$, so $\lceil k/2 \rceil \geq 5$, giving $k \geq 9$.

For $k < 9$: $\lceil k/2 \rceil \leq 4 < 5$, so no solution exists with fewer th
an 9 digits.

The unique 9-digit solution is $N = 909090909$.

### Verification

$N = 909090909$: $S = 9-0+9-0+9-0+9-0+9 = 45 \equiv 1 \pmod{11}$. **Not divisibl
e by 11.** ✓

Each replacement:
- Any **9** (odd position, sign $+1$) → 8: $S' = 45 - 1 = 44 \equiv 0 \pmod{11}$
. ✓
- Any **0** (even position, sign $-1$) → 1: $S' = 45 - 1 = 44 \equiv 0 \pmod{11}
$. ✓

All replacements yield multiples of 11. ✓
