# Solution

We determine $|M|$ where $M = \{\mu : \mathcal{B}(\mathbb{R}) \to \mathbb{R} : \
mu \text{ is a measure}\}$.

Since the codomain is $\mathbb{R}$ (not $[0,\infty]$), every $\mu \in M$ is a **
finite** positive measure: $\mu(A) \in [0,\infty)$ for all $A \in \mathcal{B}(\m
athbb{R})$ and $\mu(\mathbb{R}) < \infty$.

## Lower Bound: $|M| \geq 2^{\aleph_0}$

For each $x \in \mathbb{R}$, the Dirac measure $\delta_x : \mathcal{B}(\mathbb{R
}) \to \mathbb{R}$ defined by $\delta_x(A) = \mathbf{1}_A(x)$ is a finite measur
e with $\delta_x(\mathbb{R}) = 1$. If $x \neq y$, then $\delta_x \neq \delta_y$
(e.g., $\delta_x(\{x\}) = 1$ but $\delta_y(\{x\}) = 0$). Thus the map $x \mapsto
 \delta_x$ injects $\mathbb{R}$ into $M$, giving $|M| \geq |\mathbb{R}| = 2^{\al
eph_0}$.

## Upper Bound: $|M| \leq 2^{\aleph_0}$

**Step 1: Finite measures ↔ distribution functions.** Every finite measure $\mu$
 on $\mathcal{B}(\mathbb{R})$ has a **distribution function** $F_\mu : \mathbb{R
} \to [0,\infty)$ defined by $F_\mu(x) = \mu((-\infty, x])$. This function is:
- non-decreasing,
- right-continuous,
- satisfies $\lim_{x \to -\infty} F_\mu(x) = 0$.

Conversely, by the standard correspondence theorem (Carathéodory extension), eve
ry such function $F$ uniquely determines a finite measure $\mu$ on $\mathcal{B}(
\mathbb{R})$ via $\mu((a,b]) = F(b) - F(a)$ and extension to all Borel sets. So
the map $\mu \mapsto F_\mu$ is a **bijection** between $M$ and the set $\mathcal
{F}$ of non-decreasing, right-continuous functions $F : \mathbb{R} \to [0,\infty
)$ with $\lim_{x\to -\infty} F(x) = 0$.

**Step 2: Distribution functions are determined by values on $\mathbb{Q}$.** Let
 $F \in \mathcal{F}$. We claim $F$ is uniquely determined by $F|_\mathbb{Q}$. Fo
r any $x \in \mathbb{R}$:
$$F(x) = \inf\{F(q) : q \in \mathbb{Q},\; q > x\}.$$

*Proof of claim:* By monotonicity, $F(q) \geq F(x)$ for all $q > x$, so $\inf\{F
(q) : q \in \mathbb{Q}, q > x\} \geq F(x)$. Conversely, by right-continuity, for
 any $\varepsilon > 0$ there exists $\delta > 0$ with $F(x+t) < F(x) + \varepsil
on$ for $0 \leq t < \delta$. Choosing a rational $q$ with $x < q < x + \delta$ g
ives $F(q) < F(x) + \varepsilon$, so the infimum is $\leq F(x) + \varepsilon$. S
ince $\varepsilon$ is arbitrary, equality holds. $\square$

**Step 3: Counting.** The restriction $F|_\mathbb{Q}$ is a function from $\mathb
b{Q}$ to $[0,\infty)$. The set of all such functions has cardinality:
$$|[0,\infty)^{\mathbb{Q}}| = |[0,\infty)|^{|\mathbb{Q}|} = (2^{\aleph_0})^{\ale
ph_0} = 2^{\aleph_0 \cdot \aleph_0} = 2^{\aleph_0}.$$

Since $F$ is determined by $F|_\mathbb{Q}$, we have $|\mathcal{F}| \leq 2^{\alep
h_0}$, and hence $|M| \leq 2^{\aleph_0}$.

## Conclusion

Combining both bounds:
$$2^{\aleph_0} \leq |M| \leq 2^{\aleph_0}.$$

Therefore:
$$\boxed{|M| = 2^{\aleph_0}}.$$
