## Proof

We compute $\mathbb{E}[X_t^2]$ where $X_t = \int_0^t B_s\, dB_s$, using **Itô is
ometry**.

**Itô isometry** states that for any square-integrable adapted process $f_s$,
$$\mathbb{E}\left[\left(\int_0^t f_s\, dB_s\right)^2\right] = \int_0^t \mathbb{E
}[f_s^2]\, ds.$$

Applying this with $f_s = B_s$:
$$\mathbb{E}[X_t^2] = \mathbb{E}\left[\left(\int_0^t B_s\, dB_s\right)^2\right]
= \int_0^t \mathbb{E}[B_s^2]\, ds.$$

Since $B_s$ is standard Brownian motion, $\mathbb{E}[B_s^2] = s$. Therefore:
$$\mathbb{E}[X_t^2] = \int_0^t s\, ds = \frac{t^2}{2}.$$

**Verification via the closed form.** Using $\int_0^t B_s\, dB_s = \frac{1}{2}B_
t^2 - \frac{t}{2}$:
$$X_t^2 = \frac{1}{4}B_t^4 - \frac{t}{2}B_t^2 + \frac{t^2}{4}.$$

Taking expectations and using $\mathbb{E}[B_t^2] = t$ and $\mathbb{E}[B_t^4] = 3
t^2$ (Gaussian fourth moment):
$$\mathbb{E}[X_t^2] = \frac{1}{4}\cdot 3t^2 - \frac{t}{2}\cdot t + \frac{t^2}{4}
 = \frac{3t^2}{4} - \frac{t^2}{2} + \frac{t^2}{4} = \frac{t^2}{2}.$$

Both methods agree, confirming the result.

$$\boxed{\mathbb{E}[X_t^2] = \dfrac{t^2}{2}}$$
