## Setup

Let $n = 2^{16} = 65536$ and $p = n+1 = 65537$ (prime). The total number of sequ
ences is $\prod_{i=1}^{n} i = n!$ since $a_1=1$ is forced and $a_i$ has $i$ choi
ces.

By linearity of expectation/counting, the total number of mountains is:
$$T = \sum_{k=2}^{n-1} C_k$$
where $C_k$ = number of sequences where $a_k$ is a mountain.

## Computing $C_k$

Since the constraint on each $a_i$ depends only on $i$, the variables $a_{k-1},
a_k, a_{k+1}$ are independent of all others. So:
$$C_k = \frac{n!}{(k-1)\,k\,(k+1)} \cdot N_k$$
where $N_k$ counts valid triples $(a_{k-1}, a_k, a_{k+1})$ with $1 \le a_{k-1} \
le k-1$, $1 \le a_k \le k$, $1 \le a_{k+1} \le k+1$, and $a_k > a_{k-1}$, $a_k >
 a_{k+1}$.

**Computing $N_k$:** Fix $b = a_k$. For $b \ge 2$: the number of valid $a_{k-1}$
 is $\min(k-1, b-1)$ and valid $a_{k+1}$ is $b-1$ (since $b \le k < k+1$). For $
2 \le b \le k-1$: both give $(b-1)^2$. For $b = k$: gives $(k-1)^2$. So:
$$N_k = \sum_{b=2}^{k}(b-1)^2 = \sum_{j=1}^{k-1} j^2 = \frac{(k-1)k(2k-1)}{6}$$

## Summing over $k$

$$T = \frac{n!}{6}\sum_{k=2}^{n-1}\frac{2k-1}{k+1} = \frac{n!}{6}\sum_{k=2}^{n-1

$$= \frac{n!}{6}\left(2(n-2) - 3\sum_{j=3}^{n}\frac{1}{j}\right) = \frac{n!}{6}\

$$= \frac{n!}{6}\cdot\frac{4n+1 - 6H_n}{2} = \frac{n!\,(4n+1) - 6\,n!\,H_n}{12}$
$

Setting $S = n!\,H_n = \sum_{j=1}^{n}\frac{n!}{j}$ (an integer), and $4n+1 = 4\c

$$12\,T = n!\cdot 262145 - 6\,S$$

## Reducing modulo $p = 65537$

**Wilson's theorem:** $n! = (p-1)! \equiv -1 \pmod{p}$.

**Constant term:** $262145 = 4(p-1)+1 = 4p - 3 \equiv -3 \pmod{p}$. So $n!\cdot
262145 \equiv (-1)(-3) = 3 \pmod{p}$.

**The harmonic sum $S$:** For each $j \in \{1,\ldots,p-1\}$:
$$\frac{(p-1)!}{j} \equiv \frac{-1}{j} \equiv -j^{-1} \pmod{p}$$
So $S \equiv -\sum_{j=1}^{p-1} j^{-1} \pmod{p}$. Since $j \mapsto j^{-1}$ permut

$$\sum_{j=1}^{p-1} j^{-1} = \sum_{j=1}^{p-1} j = \frac{(p-1)p}{2} \equiv 0 \pmod
{p}$$
Thus $S \equiv 0 \pmod{p}$.
