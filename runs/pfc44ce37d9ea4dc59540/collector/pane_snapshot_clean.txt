## Solution

**Identifying the character.** Let $\chi(n) = \left(\frac{-1}{n}\right) = (-1)^{
(n-1)/2}$ for odd $n$ (the non-principal Dirichlet character mod 4), and $\chi(n
)=0$ for even $n$.

Checking the sign pattern in $A$ over odd $n$ with $3\nmid n$:
$$n=1,5,7,11,13,17,19,23,\dots \quad\Rightarrow\quad +,+,-,-,+,+,-,-,\dots$$
This matches $\chi(n)$ exactly: $\chi(1)=1,\chi(5)=1,\chi(7)=-1,\chi(11)=-1,\dot
s$ So
$$A = \sum_{\substack{n\ge1,\,n\text{ odd}\\3\nmid n}} \frac{\chi(n)}{n^2}.$$

**Analyzing $B$.** The terms are $n=3,9,15,21,27,33,\dots=3m$ with $m=1,3,5,7,\d
ots$ (odd), and signs $+,-,+,-,+,-,\dots$, which is $\chi(m)=(-1)^{(m-1)/2}$. Th
us
$$B = \sum_{\substack{m\ge1\\m\text{ odd}}}\frac{\chi(m)}{(3m)^2} = \frac{1}{9}\
sum_{\substack{m\ge1\\m\text{ odd}}}\frac{\chi(m)}{m^2} = \frac{C}{9},\quad\text
{where } C:=\sum_{\substack{m\ge1\\m\text{ odd}}}\frac{\chi(m)}{m^2}.$$

**Key identity: $\chi(3k)=-\chi(k)$ for odd $k$.** Since $k$ is odd,
$$\frac{3k-1}{2} = \frac{k-1}{2}+k \implies \chi(3k)=(-1)^{(3k-1)/2}=(-1)^{(k-1)
/2}\cdot(-1)^{k}=\chi(k)\cdot(-1)=-\chi(k).$$

**Relating $C$ and $A$.** Split $C$ by divisibility by 3:
$$C = \underbrace{\sum_{\substack{m\text{ odd}\\3\nmid m}}\frac{\chi(m)}{m^2}}_{
=A} + \sum_{\substack{k\text{ odd}}}\frac{\chi(3k)}{(3k)^2} = A + \frac{1}{9}\su
m_{k\text{ odd}}\frac{-\chi(k)}{k^2} = A - \frac{C}{9}.$$

Solving: $C + \frac{C}{9} = A \;\Rightarrow\; \frac{10}{9}C = A \;\Rightarrow\;
C = \frac{9A}{10}$.

**Computing the ratio.** Since $B = C/9 = \frac{1}{9}\cdot\frac{9A}{10} = \frac{
A}{10}$,
$$\frac{A}{B} = \frac{A}{A/10} = 10.$$

Final Answer: $\boxed{10}$
