## Construction

Let $X$ be the metric ray: vertices $v_0, v_1, v_2, \ldots$ with edges $e_n = [v
_{n-1}, v_n]$ of length $1$ for each $n \geq 1$. The path metric gives $d_X(v_i,
 v_j) = |i-j|$.

Let $Y$ be the same metric graph: vertices $u_0, u_1, u_2, \ldots$ with edges $[
u_{n-1}, u_n]$ of length $1$ for each $n \geq 1$.

Both $X$ and $Y$ have bounded geometry: every edge has length $1$ (bounded above
 and below), and every vertex has valence at most $2$.

**Definition of $f$.** Set $f(v_n) = u_0$ for all $n \geq 0$. On each edge $e_n
= [v_{n-1}, v_n]$, parametrized by arclength $t \in [0,1]$, define $f$ to traver
se the loop
$$u_0 \to u_1 \to \cdots \to u_n \to u_{n-1} \to \cdots \to u_0$$
at constant speed. This loop has total length $2n$, so the speed is $2n$.

**Cellularity and continuity.** The map sends the $0$-skeleton $X^{(0)}$ into $Y
^{(0)}$ (all vertices go to $u_0$) and each $1$-cell into $Y^{(1)} = Y$, so $f$
is cellular. At each vertex $v_n$, both adjacent edges map to loops based at $u_
0 = f(v_n)$, so $f$ is continuous.

**$f|_{X^{(0)}}$ is $L$-Lipschitz with $L = 0$.** For any vertices $v_i, v_j$:
$$d_Y(f(v_i), f(v_j)) = d_Y(u_0, u_0) = 0 \leq 0 \cdot d_X(v_i, v_j).$$

**$f$ is not $L'$-Lipschitz for any $L' < \infty$.** On edge $e_n$ (length $1$),
 the image loop has length $2n$, parametrized at constant speed $2n$. Let $x_n$
be the midpoint of $e_n$ (arclength $t = \tfrac{1}{2}$), which maps to $u_n$ (th
e midpoint of the loop at arclength $n$). Let $y_n$ be at arclength $t = \tfrac{
1}{2} + \tfrac{1}{4n}$, which maps to the point at arclength $n + \tfrac{1}{2}$
on the return path—i.e., distance $\tfrac{1}{2}$ from $u_n$. Then:
$$d_X(x_n, y_n) = \frac{1}{4n}, \qquad d_Y(f(x_n), f(y_n)) = \frac{1}{2},$$
so the ratio is
$$\frac{d_Y(f(x_n), f(y_n))}{d_X(x_n, y_n)} = 2n \xrightarrow{n \to \infty} \inf
ty.$$
For any $L' < \infty$, choosing $n > L'/2$ yields a pair violating the $L'$-Lips
chitz condition. Hence $f$ is not Lipschitz for any finite constant.

**Non-degenerate variant ($L = 1$).** Set $f(v_n) = u_n$ and map each edge $[v_{
n-1}, v_n]$ to the path $u_{n-1} \to u_{n-2} \to \cdots \to u_0 \to u_1 \to \cdo
ts \to u_n$ of length $(n-1) + n = 2n - 1$, parametrized at constant speed. Then
 $f|_{X^{(0)}}$ is the identity on the ray, hence $1$-Lipschitz, while the slope
 on $e_n$ is $2n - 1 \to \infty$, so $f$ is not Lipschitz.

**Key point.** A cellular map between graphs need only send vertices to vertices
; on each edge it is an arbitrary continuous path in the target graph. The $0$-s
keleton Lipschitz condition constrains only the images of vertices, leaving the
behavior on edge interiors (which can traverse arbitrarily long paths) completel
y unconstrained.
