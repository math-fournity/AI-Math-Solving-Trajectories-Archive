## Solution

**Setup.** Partition $A=\{1,\dots,12\}$ into residue classes modulo 3:
$$R_0=\{3,6,9,12\},\quad R_1=\{1,4,7,10\},\quad R_2=\{2,5,8,11\},$$
each of size 4. The condition "$f(i)-i$ is not a multiple of 3" is equivalent to
 $f(i)\not\equiv i\pmod 3$, i.e. **no element is sent to its own residue class**
.

**Transition matrix.** Let $n_{rs}$ = number of elements of class $R_r$ mapped i
nto class $R_s$. The $3\times 3$ matrix $N=(n_{rs})$ must satisfy:
- row sums $=4$ (each source class has 4 elements),
- column sums $=4$ (each target class receives 4 elements),
- $n_{rr}=0$ (no element stays in its own class).

Writing
$$N=\begin{pmatrix}0&a&4-a\\4-a&0&a\\a&4-a&0\end{pmatrix},$$
the column-sum constraints give $a\in\{0,1,2,3,4\}$, yielding **5 valid matrices
** (one for each value of $a$).

**Counting bijections for a fixed $N$.** For each source class $R_r$, partition
its 4 elements into groups of sizes $n_{rs}$ ($s=0,1,2$): this contributes $\dis
playstyle\frac{4!}{\prod_s n_{rs}!}$ ways. For each target class $R_s$, biject t
he 4 incoming elements to the 4 elements of $R_s$: $4!$ ways. These choices are
independent, so
$$\text{count}(N)=\prod_r\frac{4!}{\prod_s n_{rs}!}\;\cdot\;\prod_s 4!=\frac{(4!
)^6}{\prod_{r,s}n_{rs}!}.$$

Since the diagonal entries are $0$,
$$\prod_{r,s}n_{rs}! = (a!)^3\bigl((4-a)!\bigr)^3.$$

**Summing over $a$.** With $(4!)^6=24^6=191\,102\,976$:

| $a$ | $(a!)^3((4-a)!)^3$ | count |
|---|---|---|
| 0 | $1^3\cdot 24^3=13\,824$ | $13\,824$ |
| 1 | $1^3\cdot 6^3=216$ | $884\,736$ |
| 2 | $2^3\cdot 2^3=64$ | $2\,985\,984$ |
| 3 | $6^3\cdot 1^3=216$ | $884\,736$ |
| 4 | $24^3\cdot 1^3=13\,824$ | $13\,824$ |

Total:
$$13\,824+884\,736+2\,985\,984+884\,736+13\,824=4\,783\,104.$$

**Answer.** The number of one-to-one functions $f:A\to A$ with $3\nmid f(i)-i$ f
or all $i$ is

$$\boxed{4\,783\,104}.$$
