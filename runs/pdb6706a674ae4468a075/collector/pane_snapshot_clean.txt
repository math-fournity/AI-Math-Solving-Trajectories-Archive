**Answer: Yes.** There exists a convex program with zero duality gap that does n
ot satisfy Slater's condition. Below is an explicit example with a complete veri
fication.

---

### The Program

Consider the convex program

$$
\begin{aligned}
\text{minimize } & \quad f_0(x) = x \\
\text{subject to } & \quad f_1(x) = x^2 \le 0,
\end{aligned}
\qquad x \in \mathbb{R}.
$$

Both $f_0(x)=x$ (affine, hence convex) and $f_1(x)=x^2$ (convex) are convex func
tions, so this is a convex program.

---

### Step 1 — Slater's condition fails

Slater's condition (for a program with a single non-affine inequality constraint
) requires the existence of a **strictly feasible** point, i.e. some $x$ with

$$
x^2 < 0.
$$

No real number satisfies $x^2 < 0$. The feasible set is the single point $\{0\}$
, at which $f_1(0)=0$, not strictly negative. Hence **Slater's condition is not
satisfied**.

---

### Step 2 — Primal optimal value

The only feasible point is $x=0$, so the primal optimal value is

$$
p^\star = f_0(0) = 0.
$$

---

### Step 3 — Lagrange dual function

The Lagrangian is $L(x,\lambda) = x + \lambda x^2$ with $\lambda \ge 0$. The dua
l function is

$$
g(\lambda) = \inf_{x\in\mathbb{R}} \bigl(x + \lambda x^2\bigr).
$$

- **$\lambda > 0$:** $x + \lambda x^2$ is a strictly convex quadratic. Setting t
he derivative to zero gives $1 + 2\lambda x = 0$, i.e. $x^\star = -\tfrac{1}{2\l
ambda}$. Substituting,
  $$
  g(\lambda) = -\frac{1}{2\lambda} + \lambda\cdot\frac{1}{4\lambda^2} = -\frac{1
}{2\lambda} + \frac{1}{4\lambda} = -\frac{1}{4\lambda}.
  $$
- **$\lambda = 0$:** $g(0) = \inf_x x = -\infty$.

So $g(\lambda) = -\tfrac{1}{4\lambda}$ for $\lambda>0$ and $g(0)=-\infty$.

---

### Step 4 — Dual optimal value

The dual problem is $\sup_{\lambda \ge 0} g(\lambda)$. Since $g(\lambda) = -\tfr
ac{1}{4\lambda}$ for $\lambda > 0$ and this is strictly increasing toward $0$ as
 $\lambda \to \infty$,

$$
d^\star = \sup_{\lambda > 0}\left(-\frac{1}{4\lambda}\right) = 0,
$$

with the supremum approached (but not attained) as $\lambda \to \infty$.

---

### Step 5 — Zero duality gap

Comparing the primal and dual optimal values:

$$
p^\star = 0 = d^\star.
$$

The duality gap is $p^\star - d^\star = 0$.

---

### Conclusion

The program

$$
\min\ x \quad \text{s.t.}\ x^2 \le 0
$$

is a convex program that

1. **does not satisfy Slater's condition** (no strictly feasible point exists),
and
2. **has zero duality gap** ($p^\star = d^\star = 0$).

Therefore, **yes**, there exists a convex program with a zero duality gap that d
oes not satisfy Slater's condition. This confirms that Slater's condition is a *
sufficient* but not *necessary* condition for strong duality.
