## Setting Up the Maximum Spikiness Formula

Let $y_1 \le y_2 \le \cdots \le y_9$ be the order statistics. The maximum spikin
ess over all permutations is achieved by a **zigzag** (alternating) arrangement
— this follows from an exchange argument: if three consecutive elements are mono
tone, say $a \le b \le c$, their contribution is $(b-a)+(c-b) = c-a$, but rearra
nging to $b,a,c$ gives $(b-a)+(c-a) = b+c-2a \ge c-a$. So the optimal permutatio
n has no monotone triple.

For $n = 9 = 2(4)+1$ (odd), there are two zigzag types. Using the coefficient an
alysis (each interior peak gets $+2$, each interior valley gets $-2$, endpoints
get $\pm 1$), and applying the rearrangement inequality to assign values optimal
ly:

**Option A** (valleys at odd positions, 4 peaks, 5 valleys):
$$A = 2(y_6+y_7+y_8+y_9) - 2(y_1+y_2+y_3) - y_4 - y_5$$

**Option B** (peaks at odd positions, 5 peaks, 4 valleys):
$$B = 2(y_7+y_8+y_9) + y_5 + y_6 - 2(y_1+y_2+y_3+y_4)$$

The maximum spikiness is $M = \max(A, B)$.

## Computing $E[M]$

**Step 1: The average part.** Since $M = \frac{A+B}{2} + \frac{|A-B|}{2}$:

$$A + B = 3y_6 + 4y_7 + 4y_8 + 4y_9 - 4y_1 - 4y_2 - 4y_3 - 3y_4$$

Using $E[y_i] = \frac{i}{10}$ for uniform order statistics:

$$E[A+B] = \frac{1}{10}(18+28+32+36-4-8-12-12) = \frac{78}{10}$$

$$E\!\left[\frac{A+B}{2}\right] = \frac{39}{10}$$

**Step 2: The absolute value part.** Compute:
$$A - B = y_6 + y_4 - 2y_5 = (y_6 - y_5) - (y_5 - y_4) = S_5 - S_4$$

where $S_i = y_{i+1} - y_i$ are consecutive spacings. The 10 spacings $(S_0, S_1
, \ldots, S_9)$ (including $S_0 = y_1$, $S_9 = 1-y_9$) follow $\text{Dirichlet}(
1,1,\ldots,1)$ with 10 components.

I need $E[|S_5 - S_4|]$. The marginal joint density of any two components $(S_j,
 S_k)$ from $\text{Dirichlet}(1,\ldots,1)$ with $n+1$ components is:

$$f(s_j, s_k) = n(n-1)(1 - s_j - s_k)^{n-2}, \quad s_j, s_k \ge 0,\; s_j+s_k \le
 1$$

By symmetry and the substitution $u = s_k - s_j$, $v = s_j$, $w = 1-2v$:

$$E[|S_k - S_j|] = n(n-1)\int_0^1 \int_0^w u(w-u)^{n-2}\,du\,dw$$

The inner integral: $\int_0^w u(w-u)^{n-2}\,du = w^n B(2, n-1) = \frac{w^n}{n(n-
1)}$

Therefore:
$$E[|S_k - S_j|] = \int_0^1 w^n\,dw = \frac{1}{n+1}$$

For $n = 9$: $E[|S_5 - S_4|] = \frac{1}{10}$.

**Step 3: Combine.**

$$E[M] = \frac{39}{10} + \frac{1}{2}\cdot\frac{1}{10} = \frac{78}{20} + \frac{1}
{20} = \frac{79}{20}$$
