## Solution

**Setup.** Place Ω with center O at the origin, radius 10. Let A = (−10, 0) and
X = (10, 0), so AX is a diameter.

**Locating C.** Write C = (10 cos θ, 10 sin θ). Then
$$AC^2 = (10\cos\theta+10)^2 + (10\sin\theta)^2 = 200(1+\cos\theta) = 400\cos^2(
\theta/2).$$
Since AC = 16, we get cos(θ/2) = 4/5, sin(θ/2) = 3/5. Hence
$$\cos\theta = \tfrac{7}{25},\quad \sin\theta = \tfrac{24}{25},\quad C = \left(\
tfrac{14}{5}, \tfrac{48}{5}\right) = \left(\tfrac{350}{125}, \tfrac{1200}{125}\r
ight).$$

**Finding D.** We compute CX = 12. We need D = (10 cos φ, 10 sin φ) on Ω with CD
 = 12:
$$CD^2 = 200 - 56\cos\varphi - 192\sin\varphi = 144 \implies 7\cos\varphi + 24\s
in\varphi = 7.$$
Writing this as 25 cos(φ − α) = 7 with cos α = 7/25, sin α = 24/25: the solution
 φ = 0 gives X; the other is φ = 2α, giving
$$\cos 2\alpha = -\tfrac{527}{625},\quad \sin 2\alpha = \tfrac{336}{625},\quad D
 = \left(-\tfrac{1054}{125}, \tfrac{672}{125}\right).$$

**Reflections.** Midpoint of AC: M₁ = (−18/5, 24/5) = (−450/125, 600/125).
$$D' = 2M_1 - D = \left(\tfrac{154}{125}, \tfrac{528}{125}\right).$$

Midpoint of CD: M₂ = (−352/125, 936/125).
$$X' = 2M_2 - X = \left(-\tfrac{1954}{125}, \tfrac{1872}{125}\right).$$

**Area of △CD′X′.** Using C = (350/125, 1200/125):
$$D' - C = \left(-\tfrac{196}{125}, -\tfrac{672}{125}\right),\quad X' - C = \lef
t(-\tfrac{2304}{125}, \tfrac{672}{125}\right).$$
$$\det = \tfrac{(-196)(672) - (-672)(-2304)}{125^2} = \tfrac{-672(196+2304)}{156
25} = \tfrac{-1{,}680{,}000}{15625}.$$
$$\text{Area} = \tfrac{1}{2}\cdot\tfrac{1{,}680{,}000}{15625} = \tfrac{840{,}000
}{15625} = \tfrac{1344}{25}.$$

Since 1344 = 2⁶·3·7 and 25 = 5², gcd(1344, 25) = 1. Thus p = 1344, q = 25, and

$$p + q = \boxed{1369}.$$
