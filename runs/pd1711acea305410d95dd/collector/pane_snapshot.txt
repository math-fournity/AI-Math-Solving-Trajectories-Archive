**Answer: Yes.** The set of jump discontinuities of a càdlàg function is necessa
rily countable.

---

**Proof.**

Let $f:\mathbb{R}\to\mathbb{R}$ be càdlàg (right-continuous with left limits). F
or each $t$, define the jump
$$\Delta f(t) := f(t) - f(t^-),$$
where $f(t^-)=\lim_{s\uparrow t}f(s)$. A point $t$ is a jump discontinuity iff $
\Delta f(t)\neq 0$.

**Key Lemma.** *For every $\varepsilon>0$ and every compact interval $[a,b]$, th
e set $S_{\varepsilon,[a,b]}:=\{t\in[a,b]:|\Delta f(t)|>\varepsilon\}$ is finite
.*

*Proof of Lemma.* Suppose for contradiction that $S_{\varepsilon,[a,b]}$ is infi
nite. Since $[a,b]$ is compact, this set has an accumulation point $c\in[a,b]$.
By the pigeonhole principle, infinitely many points of $S_{\varepsilon,[a,b]}$ a
pproach $c$ from one side.

**Case 1: Infinitely many $t_n\in S_{\varepsilon,[a,b]}$ with $t_n\uparrow c$ (a
pproach from the left).**

Since $f$ has a left limit at $c$, we have $f(t)\to f(c^-)$ as $t\uparrow c$. Se
t $\eta=\varepsilon/4$; there exists $\delta>0$ such that for all $t\in(c-\delta
,\,c)$,
$$|f(t)-f(c^-)|<\eta.$$

Pick $t_n\in(c-\delta,\,c)\cap S_{\varepsilon,[a,b]}$. Then:
- $|f(t_n)-f(c^-)|<\varepsilon/4$.
- For $s\uparrow t_n$ with $s\in(c-\delta,\,t_n)$, we have $|f(s)-f(c^-)|<\varep
silon/4$, so taking the limit $s\uparrow t_n$ gives $|f(t_n^-)-f(c^-)|\le\vareps
ilon/4$.

Therefore
$$|\Delta f(t_n)|=|f(t_n)-f(t_n^-)|\le|f(t_n)-f(c^-)|+|f(c^-)-f(t_n^-)|<\frac{\v
arepsilon}{4}+\frac{\varepsilon}{4}=\frac{\varepsilon}{2}<\varepsilon,$$
contradicting $t_n\in S_{\varepsilon,[a,b]}$.

**Case 2: Infinitely many $t_n\in S_{\varepsilon,[a,b]}$ with $t_n\downarrow c$
(approach from the right).**

Since $f$ is right-continuous at $c$, $f(t)\to f(c)$ as $t\downarrow c$. Set $\e
ta=\varepsilon/4$; there exists $\delta>0$ such that for all $t\in[c,\,c+\delta)
$,
$$|f(t)-f(c)|<\eta.$$

Pick $t_n\in(c,\,c+\delta)\cap S_{\varepsilon,[a,b]}$. Then:
- $|f(t_n)-f(c)|<\varepsilon/4$.
- For $s\uparrow t_n$ with $s\in(c,\,t_n)\subset(c,\,c+\delta)$, we have $|f(s)-
f(c)|<\varepsilon/4$, so taking $s\uparrow t_n$ gives $|f(t_n^-)-f(c)|\le\vareps
ilon/4$.

Therefore
$$|\Delta f(t_n)|\le|f(t_n)-f(c)|+|f(c)-f(t_n^-)|<\frac{\varepsilon}{4}+\frac{\v
arepsilon}{4}=\frac{\varepsilon}{2}<\varepsilon,$$
again a contradiction.

Both cases yield contradictions, so $S_{\varepsilon,[a,b]}$ must be finite. $\sq
uare$

**Counting all jumps.** The set of all jump discontinuities is
$$J=\{t:\Delta f(t)\neq 0\}=\bigcup_{n=1}^{\infty}\left\{t:|\Delta f(t)|>\tfrac{
1}{n}\right\}=\bigcup_{n=1}^{\infty}\bigcup_{k\in\mathbb{Z}}\left\{t\in[k,k+1]:|
\Delta f(t)|>\tfrac{1}{n}\right\}.$$

By the Lemma, each set $\{t\in[k,k+1]:|\Delta f(t)|>1/n\}$ is finite. Thus $J$ i
s a countable union (over $n\in\mathbb{N}$ and $k\in\mathbb{Z}$) of finite sets,
 hence **countable**. $\blacksquare$
