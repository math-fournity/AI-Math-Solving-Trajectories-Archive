## Proof

**Setup.** Let $\{e_i\}$ be a frame on $\mathbb{R}^n$ with dual coframe $\{\thet
a^i\}$, connection 1-forms $\omega^i{}_j$, and curvature 2-forms
$$\Omega^i{}_j = d\omega^i{}_j + \omega^i{}_k \wedge \omega^k{}_j.$$
Introduce a new frame $\bar e_i = e_k\, B^k{}_i$ via an invertible matrix $B = (
B^k{}_i)$ of smooth functions, with dual coframe $\bar\theta^i = (B^{-1})^i{}_k\
, \theta^k$.

**Connection transformation.** The first structure equation $d\theta^i + \omega^
i{}_j\wedge\theta^j = 0$ is frame-independent. Substituting $\bar\theta = B^{-1}
\theta$ and requiring $d\bar\theta + \bar\omega\wedge\bar\theta = 0$ yields the
gauge transformation of the connection:
$$\boxed{\bar\omega = B^{-1}\,\omega\, B + B^{-1}\,dB},$$
where the inhomogeneous term $B^{-1}dB$ is what makes $\omega$ **not** a tensor.

**Curvature transformation.** Define $\bar\Omega = d\bar\omega + \bar\omega\wedg
e\bar\omega$. Write $\bar\omega = A + C$ with $A = B^{-1}\omega B$ and $C = B^{-
1}dB$. Using the Leibniz rule for matrix-valued forms (with the sign $(-1)^p$ wh
en a $p$-form passes through $d$), and $d(B^{-1}) = -B^{-1}\,dB\,B^{-1}$ (from $
d(B^{-1}B)=0$):

$$dA = d(B^{-1})\wedge\omega B + B^{-1}\,d\omega\, B - B^{-1}\omega\wedge dB,$$
$$dC = d(B^{-1})\wedge dB = -B^{-1}\,dB\,B^{-1}\wedge dB.$$

For the quadratic term:
$$A\wedge A = B^{-1}(\omega\wedge\omega)B,$$
$$A\wedge C = B^{-1}\omega\wedge dB \quad (\text{since }BB^{-1}=I),$$
$$C\wedge A = B^{-1}(dB\,B^{-1}\wedge\omega)B,$$
$$C\wedge C = B^{-1}(dB\,B^{-1}\wedge dB).$$

Now sum $d\bar\omega + \bar\omega\wedge\bar\omega = (dA+dC) + (A\wedge A + A\wed
ge C + C\wedge A + C\wedge C)$:

- **Curvature piece:** $B^{-1}\,d\omega\,B + B^{-1}(\omega\wedge\omega)B = B^{-1
}(d\omega + \omega\wedge\omega)B = B^{-1}\Omega\,B.$
- **$\omega\wedge dB$ pieces:** $-B^{-1}\omega\wedge dB\ (\text{from }dA) + B^{-
1}\omega\wedge dB\ (\text{from }A\wedge C) = 0.$
- **$dB\,B^{-1}\wedge\omega$ pieces:** $-B^{-1}(dB\,B^{-1}\wedge\omega)B\ (\text
{from }dA) + B^{-1}(dB\,B^{-1}\wedge\omega)B\ (\text{from }C\wedge A) = 0.$
- **$dB\,B^{-1}\wedge dB$ pieces:** $-B^{-1}(dB\,B^{-1}\wedge dB)\ (\text{from }
dC) + B^{-1}(dB\,B^{-1}\wedge dB)\ (\text{from }C\wedge C) = 0.$

All inhomogeneous terms cancel, leaving

$$\boxed{\bar\Omega = B^{-1}\,\Omega\, B}.$$

**In indices** (with $\bar e_i = e_k B^k{}_i$):
$$\bar\Omega^i{}_j = (B^{-1})^i{}_k\, \Omega^k{}_l\, B^l{}_j.$$

**Interpretation.** Unlike the connection form $\omega$, which transforms **inho
mogeneously** ($\bar\omega = B^{-1}\omega B + B^{-1}dB$), the curvature form $\O
mega$ transforms **homogeneously** — precisely as a $(1,1)$-tensor (a section of
 $\operatorname{End}(TM)$). This is the characteristic property of the curvature
: the Bianchi identity $d\Omega + \omega\wedge\Omega - \Omega\wedge\omega = 0$ (
equiv. $D\Omega = 0$) is likewise consistent with this tensorial behavior. The c
ancellation of the $dB$ terms is the geometric content of the fact that curvatur
e is the **field strength** of the connection — a genuine tensor, whereas the co
nnection itself is only a gauge potential.
