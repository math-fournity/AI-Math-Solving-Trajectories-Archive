## Proof

Suppose some prime $p \ge 3$ divides $a$. For any $n \ge 1$, $a^n \equiv 0 \pmod
{p}$, so $p \mid a^n - n^2$ forces $p \mid n$, hence $(n+1)^2 \equiv 1 \pmod{p}$
. But $a^{n+1} \equiv 0 \pmod{p}$, so $p \mid 0 - 1$, contradiction. (For $n \le
 0$: $n=0$ gives $a^0 - 0 = 1$, not divisible by $p$; $n < 0$ makes $a^n$ undefi
ned mod $p$ since $a$ is not invertible.) So no prime $p \ge 3$ divides $a$, mea
ning $a = 2^k$ for some $k \ge 0$.

**Step 2: Reduction via CRT.**

For any prime $p \ge 3$, since $p \nmid a = 2^k$, the value $a^n \bmod p$ depend
s on $n \bmod (p-1)$ (by Fermat), while $n^2 \bmod p$ depends on $n \bmod p$. Si
nce $\gcd(p, p-1) = 1$, CRT lets us choose $x := n \bmod p$ and $y := n \bmod (p
-1)$ independently.

The two conditions become:
- $a^y \equiv x^2 \pmod{p}$ ... (I)
- $a \cdot a^y \equiv (x+1)^2 \pmod{p}$ ... (II)

Combining: $a \cdot x^2 \equiv (x+1)^2 \pmod{p}$, i.e.,

$$(1-a)x^2 + 2x + 1 \equiv 0 \pmod{p}. \quad (\star)$$

Note $x \not\equiv 0$ (setting $x=0$ in $(\star)$ gives $1 \equiv 0$). Condition
 (I) then requires $x^2 \in \langle a \rangle \le (\mathbb{Z}/p\mathbb{Z})^*$.

**Step 3: $a = 4$ works.**

For $a = 4$, equation $(\star)$ becomes $-3x^2 + 2x + 1 \equiv 0 \pmod{p}$, whic
h factors as $-(3x+1)(x-1) \equiv 0 \pmod{p}$. So **$x = 1$ is always a root**,
for every prime $p \ge 3$.

Then $x^2 = 1 = 4^0 \in \langle 4 \rangle$, so (I) is satisfied with $y \equiv 0
 \pmod{\operatorname{ord}_p(4)}$. By CRT, there exists $n$ with $n \equiv 1 \pmo

ratorname{ord}_p(4)) \mid \gcd(p, p-1) = 1$). This $n$ satisfies both original c

**Case $k$ odd ($k \ge 1$):** Take $p = 3$. Then $a = 2^k \equiv (-1)^k \equiv 2

x + 2 \equiv 0 \pmod{3}$. Testing $x = 0, 1, 2$: values $2, 1, 2$ — **no root ex
ists**. Fails.

**Case $k$ even, $k \ge 4$:** Write $k = 2j$ with $j \ge 2$. Then $2^k - 1 = (2^
j - 1)(2^j + 1)$. If $2^k - 1$ were a power of $3$, both factors (which differ b

nd $3$, giving $j = 1$, i.e., $k = 2$ — contradicting $k \ge 4$. So $2^k - 1$ ha

For this prime: $2^k \equiv 1 \pmod{p}$, so $a \equiv 1 \pmod{p}$. Then $(\star)

notin \langle a \rangle$. **Fails.**

**Conclusion:** The only positive integer satisfying the condition is $\boxed{a
= 4}$.
