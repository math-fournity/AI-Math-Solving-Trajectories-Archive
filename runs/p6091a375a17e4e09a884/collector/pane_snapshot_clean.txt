## Counterexample

Work in $\mathbb{R}^3$ with the Minkowski metric $\eta = \mathrm{diag}(1,1,-1)$.
 A vector $v=(v_1,v_2,v_3)$ is **null** if $v_1^2+v_2^2-v_3^2=0$. A symmetric ma
trix $A$ is **null positive definite** if $v^TAv>0$ for all nonzero null $v$, an
d **null semi-positive definite** if $v^TAv\ge 0$ for all null $v$.

Set $t_0=1$ and define the smooth family:
$$A(t)=\mathrm{diag}(2,\;1,\;-t), \qquad t\in[0,1].$$

### Verification that $A(t)$ is null positive definite for $t\in(0,1)$

For any null vector $v$ (so $v_3^2=v_1^2+v_2^2$):
$$v^T A(t)\,v = 2v_1^2+v_2^2-t\,v_3^2 = 2v_1^2+v_2^2-t(v_1^2+v_2^2)=(2-t)v_1^2+(
1-t)v_2^2.$$

For $t\in(0,1)$: both coefficients $(2-t)>0$ and $(1-t)>0$. If $v\neq 0$ is null
, then at least one of $v_1,v_2$ is nonzero (since $v_1=v_2=0\Rightarrow v_3=0\R
ightarrow v=0$). Hence $v^TA(t)v>0$. ✓

### Verification that $A(1)$ is null semi-positive definite but not null positiv
e definite

At $t=1$:
$$v^T A(1)\,v = (2-1)v_1^2+(1-1)v_2^2 = v_1^2 \ge 0 \quad\text{for all null }v.$
$

So $A(1)$ is null semi-positive definite. It is **not** null positive definite,
since the null vector $v=(0,1,1)$ gives $v^TA(1)v=0$. ✓

### No null vector in the kernel of $A(1)$

$$A(1)=\mathrm{diag}(2,1,-1), \qquad \det A(1)=2\cdot1\cdot(-1)=-2\neq 0.$$

So $A(1)$ is invertible, and $\ker A(1)=\{0\}$. There is **no** nonzero vector $
v$ (null or otherwise) satisfying $A(1)v=0$.

## Conclusion

The smooth family $A(t)=\mathrm{diag}(2,1,-t)$ on $[0,1]$ with $t_0=1$ satisfies
 all the hypotheses:
- $A(t)$ is null positive definite for all $t\in(0,1)$,
- $A(1)$ is null semi-positive definite but not null positive definite,

yet $A(1)$ is invertible, so no null vector $v$ with $A(1)v=0$ exists. The answe
r is **no**.
