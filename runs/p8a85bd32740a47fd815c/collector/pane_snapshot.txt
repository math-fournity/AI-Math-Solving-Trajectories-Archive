## Proof

Let $A$ be the origin, with $AB$ along the $x$-axis and $AC$ along the $y$-axis.
 Set $AB = c$, $AC = b$, $BC = a = 25$.

**Determining the side lengths.** The area gives $\tfrac12 bc = 150$, so $bc = 3
00$. Since $\angle A = 90°$,
$$b^2 + c^2 = a^2 = 625.$$
Then
$$(b+c)^2 = 625 + 600 = 1225 \implies b+c = 35,$$
$$(b-c)^2 = 625 - 600 = 25 \implies c - b = 5 \quad (\text{since } AB>AC).$$
Solving: $c = AB = 20$, $b = AC = 15$.

**Coordinates.** Place $A=(0,0)$, $B=(20,0)$, $C=(0,15)$.

The incircle of a right triangle with legs on the axes has inradius
$$r = \frac{b+c-a}{2} = \frac{15+20-25}{2} = 5,$$
and incenter $I = (r,r) = (5,5)$. The tangency point on $AC$ (the line $x=0$) is
$$M = (0,\,5).$$

**Intersection of line $BM$ with $\omega$.** Parametrize line $BM$:
$$P(t) = B + t(M-B) = (20-20t,\; 5t), \qquad t\in[0,1]\text{ gives }B\to M.$$
The circle is $(x-5)^2+(y-5)^2=25$. Substituting:
$$(15-20t)^2 + (5t-5)^2 = 25,$$
$$225 - 600t + 400t^2 + 25t^2 - 50t + 25 = 25,$$
$$425t^2 - 650t + 225 = 0,$$
$$17t^2 - 26t + 9 = 0.$$
The discriminant is $676 - 612 = 64$, giving
$$t = \frac{26 \pm 8}{34} \implies t = 1 \;\text{or}\; t = \frac{9}{17}.$$
The root $t=1$ corresponds to the tangency point $M$. The root $t = \tfrac{9}{17
}$ corresponds to the second intersection $L$.

**Computing $BL$.** Since $L = P\!\left(\tfrac{9}{17}\right)$ lies on segment $B
M$ at parameter $\tfrac{9}{17}$ from $B$,
$$BL = \frac{9}{17}\,|BM|.$$
Now $|BM| = \sqrt{20^2 + 5^2} = \sqrt{425} = 5\sqrt{17}$, so
$$BL = \frac{9}{17}\cdot 5\sqrt{17} = \frac{45\sqrt{17}}{17}.$$

$$\boxed{\dfrac{45\sqrt{17}}{17}}$$
