## Proof

We wish to compute $\mathbb{E}[S_t]$ where

$$S_t = 1 + \int_0^t \exp\!\left(\sigma B_s - \frac{\sigma^2 s}{2}\right) dB_s.$
$

Set $f_s := \exp\!\left(\sigma B_s - \frac{\sigma^2 s}{2}\right)$, so that $S_t
= 1 + \int_0^t f_s\, dB_s$.

**Step 1. The integrand is the stochastic exponential.**

Recall that $M_s := \exp\!\left(\sigma B_s - \frac{\sigma^2 s}{2}\right)$ is the
 Doléans–Dade exponential of the continuous local martingale $\sigma B_s$. By It
ô's formula,

$$dM_s = \sigma M_s\, dB_s, \qquad M_0 = 1,$$

so $M_s$ is a continuous local martingale. In particular $f_s = M_s$ is adapted
and continuous, hence progressively measurable, and the Itô integral $\int_0^t f
_s\, dB_s$ is well-defined as a continuous local martingale starting at $0$.

**Step 2. Verify square-integrability (so the local martingale is a true marting
ale).**

By Itô isometry, it suffices to check $\mathbb{E}\!\int_0^t f_s^2\, ds < \infty$
. We have

$$f_s^2 = \exp\!\left(2\sigma B_s - \sigma^2 s\right).$$

Since $B_s \sim \mathcal{N}(0, s)$, the moment-generating function gives $\mathb
b{E}[e^{2\sigma B_s}] = e^{2\sigma^2 s}$. Therefore

$$\mathbb{E}[f_s^2] = e^{-\sigma^2 s}\, \mathbb{E}\!\left[e^{2\sigma B_s}\right]
 = e^{-\sigma^2 s}\, e^{2\sigma^2 s} = e^{\sigma^2 s}.$$

Integrating over $[0,t]$ (Fubini, since the integrand is non-negative):

$$\mathbb{E}\!\int_0^t f_s^2\, ds = \int_0^t e^{\sigma^2 s}\, ds = \frac{e^{\sig
ma^2 t} - 1}{\sigma^2} < \infty \qquad (\text{for every finite } t \geq 0).$$

(When $\sigma = 0$, $f_s \equiv 1$ and the same conclusion holds trivially, with
 the integral equal to $t$.)

**Step 3. Conclude the Itô integral is a true martingale with zero mean.**

Because $f_s$ is square-integrable on $[0,t]$, the Itô integral $N_t := \int_0^t
 f_s\, dB_s$ is a square-integrable martingale with

$$\mathbb{E}[N_t] = \mathbb{E}[N_0] = 0.$$

Equivalently, this follows directly from the Itô isometry: $\mathbb{E}[N_t^2] =
\mathbb{E}\!\int_0^t f_s^2\, ds < \infty$, which places $N_t$ in $L^2(\Omega)$,
and the martingale property of Itô integrals with square-integrable integrands g
ives $\mathbb{E}[N_t] = 0$.

**Step 4. Compute $\mathbb{E}[S_t]$.**

By linearity of expectation,

$$\mathbb{E}[S_t] = \mathbb{E}[1] + \mathbb{E}\!\left[\int_0^t f_s\, dB_s\right]
 = 1 + 0 = 1.$$

**Result.**

$$\boxed{\mathbb{E}[S_t] = 1 \quad \text{for all } t \geq 0.}$$

The key points are: (i) the integrand $\exp(\sigma B_s - \sigma^2 s/2)$ is the s
tochastic exponential, a (local) martingale; (ii) its square has finite expectat
ion over every finite horizon $[0,t]$, since $\mathbb{E}\!\int_0^t f_s^2 ds = (e
^{\sigma^2 t}-1)/\sigma^2 < \infty$, which upgrades the local martingale to a tr
ue square-integrable martingale; (iii) a true Itô martingale has constant expect
ation, and since the integral starts at $0$, its mean is $0$, leaving $\mathbb{E
}[S_t] = 1$.
