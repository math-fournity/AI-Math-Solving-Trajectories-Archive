## Proof

Let the triangle have sides $a, b, c$, semiperimeter $s$, and area $\Delta$. Def
ine
$$x = s-a,\quad y = s-b,\quad z = s-c,$$
so $x+y+z = s$, $a = y+z$, $b = x+z$, $c = x+y$, and by Heron's formula $\Delta^
2 = s\,x\,y\,z$.

The exradii are $r_a = \Delta/x$, $r_b = \Delta/y$, $r_c = \Delta/z$, and the in
radius is $r = \Delta/s$. Since $x+y+z = s$,
$$\frac{1}{r} = \frac{1}{r_a}+\frac{1}{r_b}+\frac{1}{r_c}.$$

Given $r_a = 10.5 = \tfrac{21}{2}$, $r_b = 12$, $r_c = 14$:
$$\frac{1}{r} = \frac{2}{21}+\frac{1}{12}+\frac{1}{14} = \frac{8}{84}+\frac{7}{8
4}+\frac{6}{84} = \frac{21}{84} = \frac{1}{4},$$
so $r = 4$, hence $s = \Delta/4$.

Now $x = \Delta/r_a = \tfrac{2\Delta}{21}$, $y = \Delta/12$, $z = \Delta/14$. Su
bstituting into $\Delta^2 = s\,x\,y\,z$:
$$\Delta^2 = \frac{\Delta}{4}\cdot\frac{2\Delta}{21}\cdot\frac{\Delta}{12}\cdot\
frac{\Delta}{14} = \frac{2\Delta^4}{4\cdot 21\cdot 12\cdot 14} = \frac{\Delta^4}
{7056}.$$
Thus $\Delta^2 = 7056$, giving $\Delta = 84$.

Therefore:
- $s = 84/4 = 21$,
- $x = 2\cdot 84/21 = 8$,
- $y = 84/12 = 7$,
- $z = 84/14 = 6$.

The sides are
$$a = y+z = 13,\quad b = x+z = 14,\quad c = x+y = 15.$$

The cubic with roots $13, 14, 15$ is
$$(x-13)(x-14)(x-15) = x^3 - 42x^2 + 587x - 2730,$$
so
$$p = 42,\quad q = 13\cdot14+14\cdot15+13\cdot15 = 587,\quad r = 13\cdot14\cdot1
5 = 2730.$$

All three coefficients are integers, as required. The stability index is
$$\sqrt{p+q+r} = \sqrt{42+587+2730} = \sqrt{3359}.$$

Since $58^2 = 3364$ and $57^2 = 3249$, we have $\sqrt{3359} \approx 57.96$, whos
e nearest integer is $\boxed{58}$.
