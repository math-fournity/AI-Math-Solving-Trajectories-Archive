Looking at this problem, I need to determine whether a continuous bijection betw
een compactly generated spaces must be a homeomorphism.

**Answer: The statement is FALSE.**

**Proof.**

I will exhibit a counterexample: a continuous bijection between two compactly ge
nerated spaces that is not a homeomorphism.

**Setup.** Let $S = \{0, 1\}$ be a two-point set. Define two topologies on $S$:

- $\tau_X = \mathcal{P}(S) = \bigl\{\varnothing, \{0\}, \{1\}, \{0,1\}\bigr\}$ —
 the discrete topology. Call this space $X$.
- $\tau_Y = \bigl\{\varnothing, \{0,1\}\bigr\}$ — the indiscrete topology. Call
this space $Y$.

Let $f : X \to Y$ be the identity map on the underlying set $S$.

**Both spaces are compactly generated.**

A topological space is *compactly generated* (a $k$-space) if it has the final t
opology with respect to the inclusions of all its compact subspaces — equivalent
ly, a subset $A$ is closed in the space iff $A \cap K$ is closed in $K$ for ever
y compact $K \subseteq$ the space.

- $X$ is a finite space, hence compact. Every compact space is compactly generat
ed: the whole space is itself a compact subset, so the condition reduces to "$A$
 is closed iff $A \cap X = A$ is closed," which is tautological. ✓
- $Y$ is likewise a finite (hence compact) space, so by the same argument $Y$ is
 compactly generated. ✓

**$f$ is a continuous bijection.**

- *Bijective:* $f$ is the identity on a set, so it is a bijection. ✓
- *Continuous:* $\tau_Y \subseteq \tau_X$ (the indiscrete topology is coarser th
an the discrete topology), so every open set in $Y$ is open in $X$, meaning the
preimage of every open set in $Y$ is open in $X$. ✓

**$f$ is not a homeomorphism.**

A homeomorphism requires $f^{-1}$ to be continuous, equivalently $f$ to be an op
en map. Consider the open set $\{0\} \in \tau_X$. Its image under $f$ is $f(\{0\
}) = \{0\}$, which is **not** open in $Y$ (since $\tau_Y = \{\varnothing, \{0,1\
}\}$). Therefore $f$ is not an open map, so $f$ is not a homeomorphism. ✓

**Conclusion.** We have exhibited a continuous bijection $f : X \to Y$ between t
wo compactly generated spaces that is not a homeomorphism. Therefore the stateme
nt is **false**.

**Remark.** The failure is unsurprising: "compactly generated" is a much weaker
condition than "compact Hausdorff." The classical theorem that a continuous bije
ction is a homeomorphism requires the domain to be compact and the codomain to b
e Hausdorff (which forces the map to be closed). Compactly generated spaces need
 be neither compact nor Hausdorff, so this rigidity is lost — as the two-point c
ounterexample above demonstrates concretely.
