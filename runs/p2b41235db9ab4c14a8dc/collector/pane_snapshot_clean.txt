## Proof

**Claim.** The only entire function $f:\mathbb{C}\to\mathbb{C}$ satisfying $f(x)
=e^x$ for all $x\in\mathbb{R}$ is $f(z)=e^z$. Hence $f(z)=e^z$ is indeed the onl
y solution.

---

### Step 1. Set up the difference

Let $f$ be an entire function with $f(x)=e^x$ for every real $x$. Define
$$g(z) := f(z) - e^z.$$
Since $f$ is entire and $e^z$ is entire, $g$ is entire. Moreover, for every $x\i
n\mathbb{R}$,
$$g(x) = f(x) - e^x = e^x - e^x = 0.$$
So $g$ vanishes on the entire real axis $\mathbb{R}\subset\mathbb{C}$.

### Step 2. Apply the Identity Theorem

The **Identity Theorem** for holomorphic functions states:

> *Let $D\subseteq\mathbb{C}$ be a connected open set, and let $g$ be holomorphi
c on $D$. If the zero set $Z(g)=\{z\in D : g(z)=0\}$ has an accumulation point i
n $D$, then $g\equiv 0$ on $D$.*

We apply this with $D=\mathbb{C}$ (connected and open) and $g$ as above. The zer
o set $Z(g)$ contains $\mathbb{R}$. Every point of $\mathbb{R}$ is an accumulati
on point of $\mathbb{R}$ (for instance, $0$ is an accumulation point, since the
sequence $x_n=1/n\to 0$ with $x_n\in\mathbb{R}\setminus\{0\}$). Since $0\in\math
bb{R}\subset\mathbb{C}=D$, the zero set has an accumulation point inside $D$.

By the Identity Theorem, $g\equiv 0$ on $\mathbb{C}$, i.e.,
$$f(z) - e^z = 0 \quad\text{for all } z\in\mathbb{C}.$$

### Step 3. Conclude

Therefore $f(z)=e^z$ for all $z\in\mathbb{C}$. Since $e^z$ itself is entire and
satisfies $e^x=e^x$ for all real $x$, it is a valid solution, and by the argumen
t above it is the **only** one.

---

### Why the identity theorem applies (key points)

1. **Entire = holomorphic on all of $\mathbb{C}$**, so $g$ is holomorphic on the
 connected open set $D=\mathbb{C}$.
2. **$\mathbb{R}$ has accumulation points in $\mathbb{C}$**: any real number, e.
g. $0$, is a limit of other real numbers, and $\mathbb{R}\subset\mathbb{C}$.
3. The identity theorem requires only *one* accumulation point of the zero set i
nside the domain — here we have infinitely many (every real point).

### Remark on why weaker hypotheses would not suffice

The identity theorem is sharp: agreement on a set *without* an accumulation poin
t (e.g. a discrete set like $\mathbb{Z}$) does **not** force equality. For examp
le, $\sin(\pi z)$ is entire and vanishes on all of $\mathbb{Z}$, yet is not iden
tically zero. The crucial feature of the hypothesis $f(x)=e^x$ on $\mathbb{R}$ i
s that $\mathbb{R}$ is a continuum with accumulation points, which is exactly wh
at the identity theorem needs.

---

**Conclusion.** $f(z)=e^z$ is the unique entire function agreeing with $e^x$ on
the real line.
