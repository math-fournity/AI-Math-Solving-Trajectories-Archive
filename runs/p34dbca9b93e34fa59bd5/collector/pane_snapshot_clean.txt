**Claim:** Yes, $\mu \geq 0$.

**Proof.**

Recall that a Radon measure $\mu$ is non-negative if and only if
$$\int_\Omega \phi \, d\mu \geq 0 \quad \text{for every } \phi \in C_0(\Omega) \
text{ with } \phi \geq 0.$$
(The forward direction is immediate. For the converse: if $\mu$ assigns negative
 mass to some Borel set, one can find a compact set $K$ with $\mu(K) < 0$; by in
ner regularity and Urysohn's lemma, a non-negative $\phi \in C_0(\Omega)$ suppor
ted near $K$ with $\phi \equiv 1$ on $K$ yields $\int \phi\,d\mu < 0$, contradic
tion.)

Now let $\phi \in C_0(\Omega)$ be any non-negative test function, $\phi \geq 0$.
 Since each $\mu_n$ is a non-negative Radon measure,
$$\int_\Omega \phi \, d\mu_n \geq 0 \quad \text{for all } n.$$
By the weak-star convergence $\mu_n \rightharpoonup^* \mu$, the sequence of real
 numbers $\int_\Omega \phi\,d\mu_n$ converges to $\int_\Omega \phi\,d\mu$. A con
vergent sequence of non-negative real numbers has a non-negative limit, so
$$\int_\Omega \phi \, d\mu \geq 0.$$
Since this holds for every non-negative $\phi \in C_0(\Omega)$, the characteriza
tion above gives $\mu \geq 0$. $\blacksquare$
