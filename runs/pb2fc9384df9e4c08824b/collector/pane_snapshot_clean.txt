Looking at this problem, I need to determine whether $\{x : \lim f_n(x) \ge c\}$
 is always $G_\delta$ when $f_n$ are continuous and converge pointwise.

**Answer: Yes.**

**Proof.**

Let $f(x) = \lim_{n\to\infty} f_n(x)$ be the pointwise limit. It suffices to sho
w that $\{x : f(x) < c\}$ is an $F_\sigma$ set, since then $\{x : f(x) \ge c\} =
 \mathbb{R} \setminus \{x : f(x) < c\}$ is $G_\delta$.

**Step 1: Rewrite $f$ using $\limsup$.**

Since $f_n \to f$ pointwise, $f(x) = \limsup_{n\to\infty} f_n(x) = \inf_{N \ge 1
}\, \sup_{n \ge N} f_n(x)$.

Define $g_N(x) = \sup_{n \ge N} f_n(x)$. Each $g_N$ is **lower semicontinuous**
(being a supremum of continuous functions), so $\{x : g_N(x) \le a\}$ is closed
for every $a \in \mathbb{R}$.

**Step 2: Decompose $\{f < c\}$.**

$$\{x : f(x) < c\} = \{x : \inf_N g_N(x) < c\} = \bigcup_{N=1}^{\infty} \{x : g_
N(x) < c\}.$$

*Justification:* $\inf_N g_N(x) < c \iff \exists N : g_N(x) < c$ (standard prope
rty of infima).

**Step 3: Each $\{g_N < c\}$ is $F_\sigma$.**

$$\{x : g_N(x) < c\} = \bigcup_{m=1}^{\infty} \{x : g_N(x) \le c - \tfrac{1}{m}\
}.$$

*Justification:* If $g_N(x) < c$, set $\varepsilon = c - g_N(x) > 0$ and pick $m
$ with $1/m < \varepsilon$; then $g_N(x) = c - \varepsilon < c - 1/m$, so $g_N(x
) \le c - 1/m$. The converse is immediate.

Since $g_N$ is lower semicontinuous, each $\{x : g_N(x) \le c - 1/m\}$ is **clos
ed**. Thus $\{x : g_N(x) < c\}$ is $F_\sigma$.

**Step 4: Conclude.**

$$\{x : f(x) < c\} = \bigcup_{N=1}^{\infty} \bigcup_{m=1}^{\infty} \{x : g_N(x)
\le c - \tfrac{1}{m}\}$$

is a countable union of closed sets, hence **$F_\sigma$**. Therefore

$$\{x : f(x) \ge c\} = \mathbb{R} \setminus \{x : f(x) < c\}$$

is the complement of an $F_\sigma$ set, which is a **$G_\delta$** set. $\blacksq
