## Answer: No.

**Counterexample.**

Let $X = \mathbb{R}$ equipped with Lebesgue measure $\mu$. Set
$$B = \mathbb{R}, \qquad A_n = \mathbb{R} \setminus [n,\, n+1].$$

**Verification of the hypothesis.** We must show that for every measurable $C \s
ubset \mathbb{R}$,
$$\mu(A_n \cap C) \longrightarrow \mu(B \cap C) = \mu(C) \quad (n \to \infty).$$

Since $A_n \cap C = C \setminus [n,n+1]$, we have
$$\mu(A_n \cap C) = \mu(C) - \mu\bigl(C \cap [n,n+1]\bigr).$$

- **If $\mu(C) < \infty$:** The intervals $[n,n+1]$ are pairwise essentially dis
joint, so the sets $C \cap [n,n+1]$ are pairwise essentially disjoint and
$$\sum_{n=0}^{\infty} \mu\bigl(C \cap [n,n+1]\bigr) \le \mu(C) < \infty.$$
A convergent series has terms tending to $0$, hence $\mu(C \cap [n,n+1]) \to 0$,
 and therefore $\mu(A_n \cap C) \to \mu(C) = \mu(B \cap C)$.

- **If $\mu(C) = \infty$:** Then $\mu(B \cap C) = \infty$. Also $\mu(A_n \cap C)
 = \infty - \mu(C \cap [n,n+1]) = \infty$ for every $n$ (subtracting a finite qu
antity from $\infty$). Hence $\mu(A_n \cap C) = \infty \to \infty = \mu(B \cap C
)$.

Thus the hypothesis holds for **all** measurable $C$.

**The symmetric difference does not tend to the empty set.** We have
$$A_n \triangle B = A_n \triangle \mathbb{R} = \mathbb{R} \setminus A_n = [n, n+
1],$$
so
$$\mu(A_n \triangle B) = \mu([n,n+1]) = 1 \quad \text{for all } n.$$

The measure of the symmetric difference is constantly $1$ and does **not** tend
to $0$; in particular $A_n \triangle B$ is never empty.

**Why the "obvious" proof fails.** One might try: take $C = B$ to get $\mu(A_n \
cap B) \to \mu(B)$, and $C = X \setminus B$ to get $\mu(A_n \setminus B) \to 0$,
 then conclude $\mu(B \setminus A_n) = \mu(B) - \mu(A_n \cap B) \to 0$. This arg
ument requires subtracting $\mu(A_n \cap B)$ from $\mu(B)$, which is only legiti
mate when $\mu(B) < \infty$. In the counterexample $\mu(B) = \mu(\mathbb{R}) = \
infty$, so the subtraction $\infty - \infty$ is undefined and the argument colla
pses — exactly the loophole the counterexample exploits.

Therefore the answer is **no**: the condition $\mu(A_n \cap C) \to \mu(B \cap C)
$ for all measurable $C$ does **not** imply $A_n \triangle B \to \varnothing$.
