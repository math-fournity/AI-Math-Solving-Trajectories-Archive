**Proof.**

Introduce the change of variables
$$p = x + y, \qquad q = x - y.$$
Then $x = \frac{p+q}{2}$, $y = \frac{p-q}{2}$, and
$$\dot p = \dot x + \dot y = (-2y + u) + (-2x + u) = -2(x+y) + 2u = -2p + 2u(t),
$$
$$\dot q = \dot x - \dot y = (-2y + u) - (-2x + u) = 2(x - y) = 2q.$$
The system decouples into two scalar equations:
$$\dot p = -2p + 2u(t), \qquad \dot q = 2q.$$

**Part 1: $x(0) \neq y(0)$.**

Here $q(0) = x(0) - y(0) \neq 0$. The equation $\dot q = 2q$ is autonomous and i
ndependent of $u(t)$, with solution
$$q(t) = q(0)\,e^{2t}.$$
Since $q(0) \neq 0$ and $e^{2t} > 0$ for every real $t$, we have $q(t) \neq 0$ f
or all $t$.

If the trajectory passed through the origin at some time $T$, then $x(T)=0$ and
$y(T)=0$, giving $q(T) = x(T)-y(T) = 0$. This contradicts $q(T) = q(0)e^{2T} \ne
q 0$. Hence the solution never passes through $(0,0)$, regardless of the choice
of $u(t)$. $\square$

**Part 2: $x(0) = y(0)$.**

Now $q(0) = 0$, so $q(t) = 0$ for all $t$; equivalently $x(t) = y(t)$ for all $t
$. Writing $x(t) = y(t) = \tfrac{1}{2}p(t)$, it suffices to drive $p(T) = 0$.

The solution of $\dot p = -2p + 2u(t)$ with $p(0) = 2x(0)$ is, by the variation-
of-constants formula,
$$p(t) = p(0)\,e^{-2t} + 2\int_0^t e^{-2(t-s)}\,u(s)\,ds.$$
Setting $t = T$ and requiring $p(T) = 0$ gives the condition
$$\int_0^T e^{-2(T-s)}\,u(s)\,ds = -\frac{p(0)}{2}\,e^{-2T}.$$

Choose $u(t)$ to be the **constant**
$$u(t) \equiv c := \frac{-\,p(0)\,e^{-2T}}{1 - e^{-2T}}.$$
(This is well-defined for every $T > 0$ since $e^{-2T} < 1$, so $1 - e^{-2T} > 0
$.) Then
$$\int_0^T e^{-2(T-s)}\,c\,ds = c\int_0^T e^{-2r}\,dr = c\cdot\frac{1 - e^{-2T}}
{2} = -\frac{p(0)}{2}\,e^{-2T},$$
which is exactly the required condition. Therefore $p(T) = 0$, hence $x(T) = y(T
) = 0$.

Since $c$ is a constant (hence continuous) and the construction works for every
$T > 0$, a suitable $u(t)$ exists for any prescribed $T > 0$. $\square$
