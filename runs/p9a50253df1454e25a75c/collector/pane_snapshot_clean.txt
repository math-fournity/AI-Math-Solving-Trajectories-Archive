## Proof

**Definition.** The multicolour Ramsey number $R(n_1, n_2, \ldots, n_c)$ is the
least integer $N$ such that every $c$-colouring of the edges of the complete gra
ph $K_N$ (with colours $\{1,2,\ldots,c\}$) contains, for some $i \in \{1,\ldots,
c\}$, a monochromatic copy of $K_{n_i}$ whose edges all receive colour $i$.

**Claim.** For every permutation $\pi$ of $\{1,2,\ldots,c\}$,
$$R(n_1, n_2, \ldots, n_c) \;=\; R\!\bigl(n_{\pi(1)}, n_{\pi(2)}, \ldots, n_{\pi
(c)}\bigr).$$

**Key tool: colour-relabelling bijection.** For a permutation $\pi$ and a $c$-ed
ge-colouring $\chi : E(K_N) \to \{1,\ldots,c\}$, define the relabelled colouring
$$(T_\pi\,\chi)(e) \;=\; \pi\bigl(\chi(e)\bigr).$$
The map $T_\pi$ is a bijection on the set of all $c$-colourings of $K_N$ (its in
verse is $T_{\pi^{-1}}$).

**Relabelling observation.** A colouring $\chi$ contains a monochromatic $K_m$ i
n colour $i$ if and only if $T_\pi\,\chi$ contains a monochromatic $K_m$ in colo
ur $\pi(i)$. This is immediate: the edge set of any $K_m$ has constant $\chi$-va
lue $i$ exactly when it has constant $T_\pi\chi$-value $\pi(i)$.

**Main argument.** Call a colouring $\chi$ *good for* $R(n_1,\ldots,n_c)$ when t
here exists $i$ with a monochromatic $K_{n_i}$ in colour $i$. Call $\chi$ *good
for* $R(n_{\pi(1)},\ldots,n_{\pi(c)})$ when there exists $j$ with a monochromati
c $K_{n_{\pi(j)}}$ in colour $j$.

I show that $T_\pi$ maps the set of colourings good for $R(n_1,\ldots,n_c)$ **bi
jectively** onto the set of colourings good for $R(n_{\pi(1)},\ldots,n_{\pi(c)})
$.

nd a vertex set $S$ with $|S|=n_i$ and all edges of $S$ having $\chi$-colour $i$
. By the observation, $T_\pi\chi$ has all edges of $S$ coloured $\pi(i)$. Settin
g $j = \pi(i)$, we have $|S| = n_i = n_{\pi^{-1}(j)}$...

Let me redo the indexing cleanly. Take $\sigma = \pi^{-1}$ and apply $T_\sigma$
instead; equivalently I prove $R(n_1,\ldots,n_c) = R(n_{\sigma(1)},\ldots,n_{\si
gma(c)})$ for an arbitrary permutation $\sigma$ by using $T_\sigma$.

Suppose $\chi$ is good for $R(n_1,\ldots,n_c)$: $\exists\, i$, $\exists\, S$ wit
h $|S|=n_i$, all edges of $S$ of $\chi$-colour $i$. Then $T_\sigma\chi$ has all
edges of $S$ of colour $\sigma(i)$. Write $j = \sigma(i)$, so $i = \sigma^{-1}(j

- ($\Leftarrow$) The inverse map $T_{\sigma^{-1}}$ reverses this exactly.

So $T_\sigma$ is a bijection between
$$\{\text{colourings good for } R(n_1,\ldots,n_c)\} \;\longleftrightarrow\; \{\t
ext{colourings good for } R(n_{\sigma^{-1}(1)},\ldots,n_{\sigma^{-1}(c)})\}.$$

Since $T_\sigma$ is in fact a bijection on **all** $c$-colourings of $K_N$, the
two "good" sets have the same size relative to the total. In particular:

> **Every** colouring of $K_N$ is good for $R(n_1,\ldots,n_c)$ $\iff$ **every**
colouring of $K_N$ is good for $R(n_{\sigma^{-1}(1)},\ldots,n_{\sigma^{-1}(c)})$
.

By the definition of Ramsey number as the least $N$ for which "every colouring i
s good" holds, this gives
$$R(n_1,\ldots,n_c) \;=\; R\!\bigl(n_{\sigma^{-1}(1)},\ldots,n_{\sigma^{-1}(c)}\

As $\sigma$ ranges over all permutations of $\{1,\ldots,c\}$, so does $\sigma^{-
1}$. Therefore, for **every** permutation $\pi$,
$$R(n_1, n_2, \ldots, n_c) \;=\; R\!\bigl(n_{\pi(1)}, n_{\pi(2)}, \ldots, n_{\pi
(c)}\bigr). \qquad\blacksquare$$

**Intuition.** The colours are merely labels; permuting the names of the colours
