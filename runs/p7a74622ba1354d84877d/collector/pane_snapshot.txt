## Solution

Let the three weights be drawn uniformly on $[0,1]^3$ and then sorted so $a \ge
b \ge c$. The joint density of the order statistics $(a,b,c)$ on the simplex $0
\le c \le b \le a \le 1$ is $3! = 6$.

We compute $P(\text{saved}) = 1 - P(4a+3b+2c < 1)$.

### Setting up the complement

$$P(4a+3b+2c < 1) = 6 \cdot \text{Vol}\{0 \le c \le b \le a,\; 4a+3b+2c < 1\}.$$

Since $4a < 1 \Rightarrow a < 1/4$, the constraint $a \le 1$ is automatic. Subst
itute $u=4a,\; v=3b,\; w=2c$, so $da\,db\,dc = \frac{1}{24}\,du\,dv\,dw$. The or
dering constraints become $4v \le 3u$ and $3w \le 2v$, and the potency condition
 becomes $u+v+w \le 1$. Thus

$$V = \frac{1}{24}\,I, \quad I = \text{Vol}\{u,v,w \ge 0,\; 4v \le 3u,\; 3w \le
2v,\; u+v+w \le 1\}.$$

### Computing $I$

Integrate over $w$ first: for fixed $u,v$ with $4v \le 3u$ and $u+v \le 1$,

$$w \in \left[0,\;\min\!\left(\tfrac{2v}{3},\; 1-u-v\right)\right].$$

The crossover is $\frac{2v}{3} \le 1-u-v \iff v \le \frac{3(1-u)}{5}$.

**Case A1:** $u \le \frac{4}{9}$ (so $\frac{3u}{4} \le \frac{3(1-u)}{5}$). Then
$v \in [0, \frac{3u}{4}]$ and $w \in [0, \frac{2v}{3}]$:
$$I_{A1} = \int_0^{4/9}\!\int_0^{3u/4} \frac{2v}{3}\,dv\,du = \int_0^{4/9}\frac{
3u^2}{16}\,du = \frac{1}{16}\cdot\frac{64}{729} = \frac{4}{729}.$$

**Case A2:** $\frac{4}{9} < u \le \frac{4}{7}$ (so $\frac{3u}{4} \le 1-u$). Spli
t $v$ at $\alpha = \frac{3(1-u)}{5}$, with $\beta = \frac{3u}{4}$:
$$\text{Inner}(u) = \int_0^{\alpha}\frac{2v}{3}\,dv + \int_{\alpha}^{\beta}(1-u-
v)\,dv = -\frac{3}{10} + \frac{27u}{20} - \frac{213u^2}{160}.$$
Antiderivative $F(u) = -\frac{3u}{10} + \frac{27u^2}{40} - \frac{71u^3}{160}$. E
valuating:
$$F(4/7) = -\frac{58}{1715}, \qquad F(4/9) = -\frac{142}{3645},$$
$$I_{A2} = F(4/7)-F(4/9) = -\frac{58}{1715}+\frac{142}{3645} = \frac{6424}{12502
35}.$$

**Case B:** $\frac{4}{7} < u \le 1$ (so $1-u < \frac{3u}{4}$, hence $v \in [0, 1
-u]$). With $\alpha = \frac{3(1-u)}{5}$, $\beta = 1-u$:
$$\text{Inner}(u) = \frac{(1-u)^2}{5}, \qquad I_B = \int_{4/7}^{1}\frac{(1-u)^2}
{5}\,du = \frac{1}{5}\cdot\frac{(3/7)^3}{3} = \frac{9}{1715}.$$

### Summing

$$I = \frac{4}{729} + \frac{6424}{1250235} + \frac{9}{1715} = \frac{6860 + 6424
+ 6561}{1250235} = \frac{19845}{1250235} = \frac{1}{63}.$$

(Using $19845 = 5\cdot 3^4\cdot 7^2$ and $1250235 = 5\cdot 3^6\cdot 7^3$.)

### Final probability

$$V = \frac{1}{24}\cdot\frac{1}{63} = \frac{1}{1512}, \qquad P(4a+3b+2c < 1) = 6
V = \frac{6}{1512} = \frac{1}{252}.$$

$$\boxed{P(\text{saved}) = 1 - \frac{1}{252} = \frac{251}{252}}.$$

### PROOF COMPLETE
