## Transfer Matrix Method

Process columns left to right. The **state** after column c tracks:
- **Partition** of column c's two vertices: **M** (merged, same component) or **
S** (split, different components)
- **Horizontal edge decisions** (h₁, h₂) to column c+1: each ∈ {0,1}
- **Validity**: no "closed" component exists (a component with no vertex in the
current column can never reconnect → doomed)

**Key observation:** If any component of the partial graph on columns 1..c has n
o vertex in column c, it is permanently isolated → the configuration is doomed.
So we only track states where every component touches the current column (at mos
t 2 components since there are 2 frontier vertices).

**8 states:** (M,00), (M,01), (M,10), (M,11), (S,00), (S,01), (S,10), (S,11).

**Closing rules** (when transitioning from column c−1 to c):
- Partition **M**: component closes if h₁=0 AND h₂=0 → doomed
- Partition **S**: a component closes if its corresponding h=0 → doomed unless h
₁=1 AND h₂=1

**New partition** (given v_c and previous state):
- v_c=1 → always M
- v_c=0 → M only if h₁=h₂=1 and previous partition was M; otherwise S
