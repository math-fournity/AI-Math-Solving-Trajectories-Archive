## 证明

递归定义为 $f_1(x) = |x-1|$ 且 $f_n(x) = f_{n-1}(|x-n|)$。展开得：

$$f_n(x) = \big|\big|\cdots\big||x-n|-(n-1)\big|-(n-2)\big|\cdots\big|-1\big|.$$

**$f_n$ 的零点。** $f_n(x) = 0$ 当且仅当 $|x-n|$ 是 $f_{n-1}$ 的非负零点。递归展
开绝对值链，零点恰好是所有 $n-1$ 个独立符号的选择形式：

$$x = n + s_{n-1}(n-1) + s_{n-2}(n-2) + \cdots + s_1 \cdot 1, \quad s_k \in \{+1
,-1\}.$$

**验证：** 对于 $n=3$：$x = 3 \pm 2 \pm 1 \in \{6,4,2,0\} = Z_3$ ✓。对于 $n=4$：
$x = 4 \pm 3 \pm 2 \pm 1 \in \{10,8,6,4,2,0,-2\} = Z_4$ ✓。

**通过子集和去重。** 设 $P \subseteq \{1,\dots,n-1\}$ 为满足 $s_k=+1$ 的 $k$ 的
集合。则：

$$x = n + 2\sum_{k\in P} k - \sum_{k=1}^{n-1} k = \frac{n(3-n)}{2} + 2\sum_{k\in
 P} k.$$

因此 $x$ 仅取决于子集和 $S = \sum_{k\in P}k$。集合 $\{1,2,\dots,n-1\}$ 可以实现
从 $0$ 到 $M = \frac{n(n-1)}{2}$ 的**所有**整数和（经典结论：包含 $\{1,\dots,m\}
$ 可以实现从 $0$ 到 $\frac{m(m+1)}{2}$ 的所有和）。因此，$f_n$ 的不同零点恰好为
：

$$x = \frac{n(3-n)}{2} + 2S, \quad S = 0, 1, 2, \dots, \frac{n(n-1)}{2},$$

共有 $M+1 = \frac{n(n-1)}{2}+1$ 个不同的零点。

**零点之和。**

$$\sum_{S=0}^{M}\!\left(\tfrac{n(3-n)}{2}+2S\right) = (M+1)\tfrac{n(3-n)}{2} + 2
\cdot\tfrac{M(M+1)}{2} = (M+1)\!\left(\tfrac{n(3-n)}{2}+M\right).$$

由于 $M = \frac{n(n-1)}{2}$，括号内可化简为 $\frac{n(3-n)+n(n-1)}{2} = \frac{2n}
{2} = n$。因此：

$$S_n = (M+1)\cdot n = \left(\frac{n(n-1)}{2}+1\right)n = \frac{n^2(n-1)}{2}+n.$
$

**对照小数值验证：** $S_1=1$✓, $S_2=4$✓, $S_3=12$✓, $S_4=28$✓。

**求最小的 $n$ 使得 $S_n > 500{,}000$：**

- $n=100$: $S_{100} = \frac{10000\cdot 99}{2}+100 = 495000+100 = 495100 < 500000
.$
- $n=101$: $S_{101} = \frac{10201\cdot 100}{2}+101 = 510050+101 = 510151 > 50000
0.$

由于 $S_n$ 关于 $n$ 严格递增，且 $S_{100} < 500000 < S_{101}$，最小的 $n$ 值为 $
\boxed{101}$。
