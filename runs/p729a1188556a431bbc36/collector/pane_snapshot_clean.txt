\to g$ plus the one-sided second-derivative bound $f_n'' < h$ (with $h \in L^1$)

**Answer: Yes.**

**Proof.**

Define $H(x) = \int_0^x (x-t)\,h(t)\,dt$. Since $h \in L^1([0,1])$, $H$ is conti
nuous on $[0,1]$ (in fact $H \in C^1$ with $H'' = h$ a.e.), hence bounded: $\|H\
|_\infty < \infty$.

Set $u_n := f_n - H$. Then $u_n'' = f_n'' - h \leq 0$ a.e. on $[0,1]$. Since $u_
n \in C^2$, this means **$u_n$ is concave** on $[0,1]$.

Since $f_n \to g$ pointwise, $u_n \to u := g - H$ pointwise on $[0,1]$. As a poi
ntwise limit of concave functions, $u$ is concave (and finite, since $g$ is fini
te by pointwise convergence of finite-valued $f_n$).

**Step 1: Uniform convergence on compact subsets of $(0,1)$.**

We claim $u_n \to u$ uniformly on $[\varepsilon, 1-\varepsilon]$ for every $\var
epsilon \in (0, 1/2)$.

Fix $\varepsilon \in (0,1/2)$. For concave $u_n$ and points $a < b < c$, the sec
ant slopes are monotone:
$$\frac{u_n(b)-u_n(a)}{b-a} \;\geq\; \frac{u_n(c)-u_n(a)}{c-a} \;\geq\; \frac{u_
n(c)-u_n(b)}{c-b}.$$

Taking $a = \varepsilon/2$, $c = 1-\varepsilon/2$, the ratio $\frac{u_n(1-\varep
silon/2)-u_n(\varepsilon/2)}{1-\varepsilon}$ converges to a finite constant $L_\
varepsilon$. For $n \geq N_0$, its absolute value is bounded by $M_\varepsilon :
= |L_\varepsilon|+1$.

For $x \in [\varepsilon, 1-\varepsilon]$, using $(a,b,c) = (\varepsilon/2, x, 1-
\varepsilon/2)$:
$$\frac{u_n(x) - u_n(\varepsilon/2)}{x - \varepsilon/2} \;\geq\; -M_\varepsilon.
$$
Using $(a,b,c) = (\varepsilon/2, \varepsilon, x)$ (for $x \geq \varepsilon$):
$$\frac{u_n(x) - u_n(\varepsilon/2)}{x-\varepsilon/2} \;\leq\; \frac{u_n(\vareps
ilon) - u_n(\varepsilon/2)}{\varepsilon/2} \;\leq\; M_\varepsilon'$$
for large $n$, where $M_\varepsilon'$ is a fixed constant (the right-hand side c
onverges). Analogous bounds hold from the right side using $(\varepsilon/2, 1-\v
arepsilon, 1-\varepsilon/2)$.

Combining both sides, there exists $\Lambda_\varepsilon$ (independent of $n$ for
 $n \geq N_0$) such that
$$|u_n(x) - u_n(y)| \;\leq\; \Lambda_\varepsilon\,|x-y|, \qquad \forall\, x,y \i
n [\varepsilon, 1-\varepsilon],\; n \geq N_0.$$

Thus $\{u_n\}_{n \geq N_0}$ is **equicontinuous** on $[\varepsilon, 1-\varepsilo
n]$. Since $u_n \to u$ pointwise, by Arzelà–Ascoli (every subsequence has a unif
ormly convergent sub-subsequence, whose limit must equal $u$ by pointwise conver
gence), $u_n \to u$ **uniformly** on $[\varepsilon, 1-\varepsilon]$.

Consequently $f_n = u_n + H \to g = u + H$ uniformly on $[\varepsilon, 1-\vareps
ilon]$, and
$$\int_\varepsilon^{1-\varepsilon} f_n \;\longrightarrow\; \int_\varepsilon^{1-\
varepsilon} g.$$

**Step 2: Uniform bound near the endpoints.**

We establish a uniform bound on $|f_n|$ over $[0, 1/4]$ and $[3/4, 1]$ for large
 $n$.

*On $[0, 1/4]$:* For $x \in [0, 1/4]$, concavity of $u_n$ gives:
- **Lower bound:** $u_n(x) \geq \min(u_n(0),\, u_n(1/4)) \geq -|u_n(0)| - |u_n(1
/4)|$.
- **Upper bound:** Using concavity at $x \leq 1/4 \leq 1/2$:
$$u_n(1/4) \;\geq\; \frac{1/4}{1/2 - x}\,u_n(x) + \frac{1/4 - x}{1/2 - x}\,u_n(1
/2),$$
so $u_n(x) \leq (2-4x)\,u_n(1/4) - (1-4x)\,u_n(1/2) \leq 2|u_n(1/4)| + |u_n(1/2)
|$.

Combining: $|u_n(x)| \leq |u_n(0)| + 3|u_n(1/4)| + |u_n(1/2)|$ for $x \in [0, 1/

For large $n$, the right-hand side is bounded by $C := (|u(0)|+1) + 3(|u(1/4)|+1
) + (|u(1/2)|+1)$, a fixed constant. Hence
$$|f_n(x)| = |u_n(x) + H(x)| \leq C + \|H\|_\infty =: K \qquad \text{for } x \in
 [0, 1/4],\; n \text{ large}.$$

*On $[3/4, 1]$:* By the same argument using points $1/2, 3/4, 1$, we get $|f_n(x
)| \leq K'$ for $x \in [3/4, 1]$, $n$ large.

Set $M := \max(K, K')$.

**Step 3: Conclusion.**

For $0 < \varepsilon \leq 1/4$ and $n$ sufficiently large:

$$\boxed{\lim_{n \to \infty} \int_0^1 f_n \;=\; \int_0^1 g.} \qquad \blacksquare
