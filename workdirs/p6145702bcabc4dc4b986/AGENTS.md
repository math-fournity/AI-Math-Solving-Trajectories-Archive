# Problem

In a circular data center, $n$ server racks are arranged in a ring. Each rack contains a non-negative integer number of processing units. A network configuration is deemed "stable" if it satisfies a specific load-balancing condition: for any selection of racks such that no two selected racks are physically adjacent in the circle, the average number of processing units across those selected racks must be a whole number.

We are interested in configurations where the racks do not all contain the same number of units. For a given number of racks $n$, let $M(n)$ represent the smallest possible value that the maximum number of units in any single rack can take, among all stable configurations that contain at least two distinct values.

Find the largest integer $n < 2023$ such that the required minimum-maximum capacity $M(n+1)$ is strictly greater than $M(n)$.
