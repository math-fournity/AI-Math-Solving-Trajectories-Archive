Looking at this problem, I need to find the volume of tetrahedron S-ABC where AB
C is equilateral, H (projection of A onto face SBC) is the orthocenter of △SBC,
the dihedral angle H-AB-C is 30°, and SA = 2√3.

## Setting Up Coordinates

Place plane SBC as the xy-plane. Since H is the orthocenter of △SBC and A projec
ts to H:

- B = (-b, 0, 0), C = (b, 0, 0), S = (p, q, 0)
- H = (p, (b²−p²)/q, 0), A = (p, (b²−p²)/q, a) (directly above H, perpendicular
to plane SBC)

Let h = b²/q, so H = (p, h, 0), A = (p, h, a).

## Equilateral Constraint Forces p = 0

|AB|² = (p+b)² + h² + a² and |AC|² = (p−b)² + h² + a². Setting |AB| = |AC| gives
 4pb = 0, so **p = 0**.

Thus: S = (0, q, 0), H = (0, h, 0) with h = b²/q, A = (0, h, a).

**Equilateral condition** |AB| = 2b: a² + h² = 3b² ... (1)

**SA = 2√3**: (h−q)² + a² = 12, i.e., (b²−q²)²/q² + a² = 12 ... (2)

## Computing the Dihedral Angle H-AB-C

This is the dihedral angle at edge AB between planes ABH and ABC.

**Plane ABC normal**: n₁ = (B−A)×(C−A) = 2b(0, −a, h)

**Plane ABH normal**: n₂ = (B−A)×(H−A) = a(h, −b, 0)

Using the direct plane-angle computation (projecting face directions perpendicul
ar to AB):

- Direction in face ABC ⊥ to AB: u₁ = (3b, −h, −a), with |u₁|² = 9b² + h² + a² =
 12b²
- Direction in face ABH ⊥ to AB: u₂ = (b(3b²−h²), h(3b²−h²), −a(b²+h²))

Computing the dot product using a² = 3b² − h²:

u₁·u₂ = (3b²−h²)² + a²(b²+h²) = 4b²(3b²−h²)

|u₂|² = (b²+h²)·4b²(3b²−h²), so |u₂| = 2b√((b²+h²)(3b²−h²))

Therefore:
$$\cos\varphi = \frac{4b^2(3b^2-h^2)}{2b\sqrt{3}\cdot 2b\sqrt{(b^2+h^2)(3b^2-h^2
)}} = \sqrt{\frac{3b^2-h^2}{3(b^2+h^2)}}$$

## Solving with φ = 30°

Setting cos 30° = √3/2:

$$\frac{3b^2-h^2}{3(b^2+h^2)} = \frac{3}{4} \implies 4(3b^2-h^2) = 9(b^2+h^2) \i
mplies 3b^2 = 13h^2$$

So **h² = 3b²/13**, and from (1): **a² = 3b² − 3b²/13 = 36b²/13**.

## Finding b from SA = 2√3

From h = b²/q: q = b²/h = b√(13/3), so q² = 13b²/3.

Substituting into (2):
$$\frac{(b^2 - 13b^2/3)^2}{13b^2/3} + \frac{36b^2}{13} = \frac{100b^2/9}{13b^2/3
} + \frac{36b^2}{13} = \frac{100b^2}{39} + \frac{108b^2}{39} = \frac{208b^2}{39}
 = 12$$

So b² = 12·39/208 = 468/208 = **9/4**, giving b = 3/2.

## Computing the Volume

Using V = (1/6)|det[B−A, C−A, S−A]|:

$$\det = \begin{vmatrix} -b & -h & -a \\ b & -h & -a \\ 0 & q-h & -a \end{vmatri
x} = -2abq$$

So V = abq/3.

With b = 3/2, a = 9/√13, q = √39/2:

$$V = \frac{1}{3}\cdot\frac{3}{2}\cdot\frac{9}{\sqrt{13}}\cdot\frac{\sqrt{39}}{2
} = \frac{1}{3}\cdot\frac{27}{4}\cdot\sqrt{3} = \frac{9\sqrt{3}}{4}$$

**Verification**: Base ABC is equilateral with side 3, area = 9√3/4. Height from
 S to plane ABC = aq/(b√3) = 3√3·(√3/1)·... confirms V = 9√3/4. ✓

## Answer

The volume of tetrahedron S-ABC is $\boxed{\dfrac{9\sqrt{3}}{4}}$.
