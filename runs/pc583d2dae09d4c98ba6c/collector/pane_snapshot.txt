## Proof

**Setup.** Place the circumcenter $O$ at the origin with circumradius $R$. Using
 the standard vector identity for the orthocenter, $H = A+B+C$ (where $A,B,C$ ar
e the position vectors of the vertices on the circumcircle).

**Making $BC$ horizontal.** Choose
$$B = R(\cos\theta,\,\sin\theta),\qquad C = R(-\cos\theta,\,\sin\theta),$$
so $BC$ is horizontal with $BC = 2R\cos\theta$, and $O=(0,0)$ lies on the perpen
dicular bisector of $BC$.

Let $A = R(\cos\varphi,\,\sin\varphi)$. Then
$$H = A+B+C = R\bigl(\cos\varphi,\;\sin\varphi + 2\sin\theta\bigr).$$

**Using $OH\parallel BC$.** Since $BC$ is horizontal, $OH$ horizontal forces the
 $y$-component of $H$ to vanish:
$$\sin\varphi + 2\sin\theta = 0 \quad\Longrightarrow\quad \sin\varphi = -2\sin\t
heta. \tag{1}$$
Then $|OH| = R|\cos\varphi|$.

**Using $BC = 4\cdot OH$:**
$$2R\cos\theta = 4R|\cos\varphi| \quad\Longrightarrow\quad \cos\theta = 2|\cos\v
arphi|. \tag{2}$$

**Solving.** From (1), $\cos^2\varphi = 1-4\sin^2\theta = 4\cos^2\theta - 3$. Sq
uaring (2): $\cos^2\theta = 4\cos^2\varphi = 4(4\cos^2\theta-3)$, giving
$$15\cos^2\theta = 12 \quad\Longrightarrow\quad \cos^2\theta = \tfrac45,\;\; \si
n^2\theta=\tfrac15.$$
Then $\cos^2\varphi = 4\cdot\tfrac45 - 3 = \tfrac15$, and $\sin\varphi = -2\sin\
theta = -\tfrac{2}{\sqrt5}$.

**Computing the angles.** Take $\cos\varphi = \tfrac1{\sqrt5}$ (the other sign g
ives the same triangle up to swapping $B\leftrightarrow C$). The points on the c
ircle are at arguments
$$\arg B = \arctan\tfrac12,\quad \arg C = \pi - \arctan\tfrac12,\quad \arg A = -
\arctan 2.$$

- **Angle $A$** = half the arc $BC$ not containing $A$:
$$A = \tfrac12\bigl(\pi - 2\arctan\tfrac12\bigr) = \tfrac12\bigl(\pi - \arctan\t
frac43\bigr).$$

- **Angle $B$** = half the arc $CA$ not containing $B$:
$$B = \tfrac12\bigl(\pi - \arctan 2 + \arctan\tfrac12\bigr) = \tfrac34\pi - \arc
tan 2.$$

- **Angle $C$** by the triangle sum:
$$C = \pi - A - B = -\tfrac\pi4 + \tfrac12\arctan\tfrac43 + \arctan 2.$$

Using $\arctan\tfrac43 = \pi - 2\arctan 2$ (since $\tan(2\arctan 2)=\tfrac{4}{1-
4}=-\tfrac43$ and $2\arctan 2$ is in the second quadrant):
$$C = -\tfrac\pi4 + \tfrac12(\pi - 2\arctan 2) + \arctan 2 = -\tfrac\pi4 + \tfra
c\pi2 = \tfrac\pi4 = 45°.$$

Numerically: $A \approx 63.43°$, $B \approx 71.57°$, $C = 45°$ — all acute, conf
irming the hypothesis.

**Verification.** $BC = 2R\cos\theta = \tfrac{4R}{\sqrt5}$, $OH = R|\cos\varphi|
 = \tfrac{R}{\sqrt5}$, so $BC = 4\cdot OH$. ✓ Also $OH$ is horizontal (parallel
to $BC$). ✓

The smallest angle of triangle $ABC$ is $\boxed{45°}$.
