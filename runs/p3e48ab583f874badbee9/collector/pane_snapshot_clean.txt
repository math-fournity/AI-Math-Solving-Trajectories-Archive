Looking at this problem, I need to analyze the Donkey's movement on a hexagonal
grid and determine the maximum number of mutually unreachable cells.

## Proof

**Coordinate System.** We model the hexagonal grid using the ring $\mathbb{Z}[\z
eta]$, where $\zeta = e^{i\pi/3}$. Each cell corresponds to an element $a + b\ze
ta$ with $a, b \in \mathbb{Z}$. The six grid directions correspond to the six un
its $\{\pm 1, \pm \zeta, \pm \zeta^2\}$, arranged cyclically so that multiplicat
ion by $\zeta$ represents a 60° counterclockwise rotation (and by $\bar{\zeta} =
 \zeta^5$ a clockwise rotation).

**The Donkey Displacement.** A Donkey move starting in direction $\zeta^i$ (for
$i = 0, 1, \ldots, 5$) produces the displacement:
$$v_i = m\,\zeta^i + n\,\zeta^{i+1} = \zeta^i(m + n\zeta).$$
Since turning 60° clockwise from direction $\zeta^i$ gives direction $\zeta^{i-1
}$ (equivalently, using the clockwise convention, the displacement is $\zeta^i(m
 + n\zeta)$ up to indexing — the set of six displacements is the same). The six
displacements are:
$$\{\zeta^i(m + n\zeta) : i = 0, 1, \ldots, 5\}.$$

**The Reachability Lattice.** From any cell $z$, the set of cells reachable via
Donkey moves is:
$$z + L, \quad \text{where } L = \mathbb{Z}\langle v_0, v_1, \ldots, v_5 \rangle
.$$
Since $\zeta$ is a unit in $\mathbb{Z}[\zeta]$ (with $\zeta \cdot \zeta^5 = 1$),
 multiplication by $\zeta$ is an automorphism of $\mathbb{Z}[\zeta]$. Therefore:
$$L = (m + n\zeta)\,\mathbb{Z}[\zeta],$$
the principal ideal generated by $\alpha = m + n\zeta$. Note also that $v_{i+3}
= \zeta^{i+3}(m+n\zeta) = -\zeta^i(m+n\zeta) = -v_i$, so $L$ is closed under neg
ation, making reachability **symmetric** within each coset.

**Coset Decomposition.** The board $\mathbb{Z}[\zeta]$ partitions into cosets of
 $L$. Two cells $z_1, z_2$ lie in the same coset if and only if $z_1 - z_2 \in L
$, i.e., $z_1 - z_2$ is a $\mathbb{Z}$-linear combination of Donkey displacement
s — equivalently, $z_1$ and $z_2$ are mutually reachable. Thus:
- **Within** a coset: every cell can reach every other cell.
- **Between** distinct cosets: no cell can reach any cell in another coset.

**Computing the Index.** The number of cosets is the index $[\mathbb{Z}[\zeta] :
 L]$. Since $L = (\alpha)$ is a principal ideal in $\mathbb{Z}[\zeta]$, and $\ma
thbb{Z}[\zeta]$ is a Euclidean domain (hence a PID), the index equals the absolu
te value of the **norm** of $\alpha$:
$$[\mathbb{Z}[\zeta] : (\alpha)] = |N(\alpha)|.$$
The norm in $\mathbb{Z}[\zeta]$ is:
$$N(a + b\zeta) = (a + b\zeta)(a + b\bar{\zeta}) = a^2 + ab(\zeta + \bar{\zeta})
 + b^2\,\zeta\bar{\zeta}.$$
Using $\zeta + \bar{\zeta} = 2\cos(\pi/3) = 1$ and $\zeta\bar{\zeta} = 1$:
$$N(a + b\zeta) = a^2 + ab + b^2.$$
Therefore:
$$N(m + n\zeta) = m^2 + mn + n^2.$$

**Maximum Independent Set.** The maximum number of mutually unreachable cells eq
uals the number of cosets, since we can select exactly one cell from each coset
(no two selected cells can reach each other, as they lie in different cosets), a
nd we cannot select more than one from any coset (as all cells within a coset ar
e mutually reachable). Hence:

$$\boxed{m^2 + mn + n^2}$$
