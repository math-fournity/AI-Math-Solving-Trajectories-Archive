\mathcal{G}$ 的内射分解。

────────────────────────────────────────────────────────────────────────────────

设定

设 $X$ 是一个概形，$\mathcal{F}, \mathcal{G}$ 是 $X$ 上的 $\mathcal{O}_X$-模层。
它们的内射分解分别为：

$$0 \to \mathcal{F} \xrightarrow{\varepsilon_\mathcal{F}} I^0_\mathcal{F}
\xrightarrow{d^0_\mathcal{F}} I^1_\mathcal{F} \xrightarrow{d^1_\mathcal{F}}
I^2_\mathcal{F} \to \cdots$$

$$0 \to \mathcal{G} \xrightarrow{\varepsilon_\mathcal{G}} I^0_\mathcal{G}
\xrightarrow{d^0_\mathcal{G}} I^1_\mathcal{G} \xrightarrow{d^1_\mathcal{G}}
I^2_\mathcal{G} \to \cdots$$

其中每个 $I^i_\mathcal{F}, I^i_\mathcal{G}$ 都是层范畴 $\mathfrak{Mod}
(\mathcal{O}_X)$ 中的内射对象。

定义逐项直和复形 $(I^_\mathcal{F} \oplus I^_\mathcal{G})$：

  • 第 $i$ 项为 $I^i_\mathcal{F} \oplus I^i_\mathcal{G}$，
  • 微分为 $d^i = d^i_\mathcal{F} \oplus d^i_\mathcal{G}$，
  • 增广映射为 $\varepsilon = \varepsilon_\mathcal{F} \oplus
  \varepsilon_\mathcal{G}: \mathcal{F} \oplus \mathcal{G} \to I^0_\mathcal{F}
  \oplus I^0_\mathcal{G}$。

需验证内射分解的两个条件：(A) 每项内射；(B) 增广复形正合。

────────────────────────────────────────────────────────────────────────────────

(A) 每项 $I^i_\mathcal{F} \oplus I^i_\mathcal{G}$ 是内射层

关键事实：在任何 Abel 范畴中，有限直和 = 有限直积，而内射对象的有限直积仍是内射
对象。

设 $I, J$ 为内射对象。对任意单射 $A \hookrightarrow B$ 和任意态射 $f: A \to I
\oplus J$，将 $f$ 投影到两个分量 $f_I: A \to I$，$f_J: A \to J$。由 $I$ 的内射
性，$f_I$ 延拓为 $\tilde{f}_I: B \to I$；由 $J$ 的内射性，$f_J$ 延拓为 $
\tilde{f}_J: B \to J$。则 $\tilde{f} = \tilde{f}_I \oplus \tilde{f}_J: B \to I
\oplus J$ 是 $f$ 的延拓。故 $I \oplus J$ 内射。

层范畴 $\mathfrak{Mod}(\mathcal{O}X)$ 是 Abel 范畴（事实上是 Grothendieck 范
畴），上述论证适用。因此每个 $I^i\mathcal{F} \oplus I^i_\mathcal{G}$ 是内射层。

│ 注：这里用的是有限直和。对无限直和，需要局部 Noether 条件才能保证内射性，但本
│ 题只涉及两个层的有限直和，无此限制。

────────────────────────────────────────────────────────────────────────────────

(B) 增广复形正合

考虑增广复形：

$$0 \to \mathcal{F} \oplus \mathcal{G} \xrightarrow{\varepsilon_\mathcal{F}
\oplus \varepsilon_\mathcal{G}} I^0_\mathcal{F} \oplus I^0_\mathcal{G}
\xrightarrow{d^0_\mathcal{F} \oplus d^0_\mathcal{G}} I^1_\mathcal{F} \oplus
I^1_\mathcal{G} \to \cdots$$

它恰是两个增广复形的逐项直和：

$$\left(0 \to \mathcal{F} \to I^_\mathcal{F}\right) \oplus \left(0 \to
\mathcal{G} \to I^_\mathcal{G}\right).$$

关键事实：在任何 Abel 范畴中，有限直和函子是正合的。

具体地，设 $A^\bullet, B^\bullet$ 为两个复形，则其直和复形 $(A \oplus
B)^\bullet$ 的上同调满足：

$$H^n\big((A \oplus B)^\bullet\big) \cong H^n(A^\bullet) \oplus H^n(B^\bullet).$
$

这是因为 $\ker(d^n_A \oplus d^n_B) = \ker(d^n_A) \oplus \ker(d^n_B)$，$
\operatorname{im}(d^{n-1}_A \oplus d^{n-1}_B) = \operatorname{im}(d^{n-1}_A)
\oplus \operatorname{im}(d^{n-1}_B)$，而商取分量进行。

现在应用此事实：

  • 在度 $0$：$H^0\big(I^_\mathcal{F} \oplus I^\mathcal{G}\big) \cong
  H^0(I^*\mathcal{F}) \oplus H^0(I^\mathcal{G}) \cong \mathcal{F} \oplus

  • 在度 $n \geq 1$：$H^n\big(I^_\mathcal{F} \oplus I^\mathcal{G}\big) \cong
  H^n(I^*\mathcal{F}) \oplus H^n(I^_\mathcal{G}) = 0 \oplus 0 = 0$，因为
  $I^\mathcal{F}, I^*\mathcal{G}$ 各自正合。

因此增广复形

$$0 \to \mathcal{F} \oplus \mathcal{G} \to I^0_\mathcal{F} \oplus

正合，即 $\varepsilon_\mathcal{F} \oplus \varepsilon_\mathcal{G}: \mathcal{F}

  2. 增广复形正合：有限直和保持正合性（上同调分量计算）。
