## Proof

A **line** in $\mathbb{CP}^n$ is a 1-dimensional projective linear subspace, i.e
. a copy of $\mathbb{CP}^1$. A subspace $\mathbb{CP}^2 \subset \mathbb{CP}^n$ is
 a 2-dimensional projective linear subspace. We determine the cardinality of $L
\cap \mathbb{CP}^2$ for a line $L \cong \mathbb{CP}^1$.

### Key theorem (dimension of intersection of linear subspaces)

Let $P_a, P_b \subset \mathbb{CP}^n$ be projective linear subspaces of (complex)
 dimensions $a$ and $b$. Then

$$\dim(P_a \cap P_b) \ge a + b - n,$$

and for subspaces in **general position** equality holds, so $\dim(P_a \cap P_b)
 = a + b - n$. In particular:

- if $a + b \ge n$, the intersection is **non-empty** (projective space has no d
isjoint linear subspaces whose dimensions sum to at least $n$);
- if $a + b = n$, the intersection is **exactly one point** (dimension $0$);
- if $a + b > n$, the intersection is a positive-dimensional linear subspace of
dimension $a+b-n$;
- if $a + b < n$, the subspaces are generically disjoint (the inequality gives a
 negative lower bound, meaning no forced intersection).

*Proof of the theorem.* Lift to the underlying $(n+1)$-dimensional complex vecto
r space $V$. A projective $a$-subspace corresponds to an $(a+1)$-dimensional lin
ear subspace $\widetilde P_a \le V$, and similarly $\widetilde P_b$ has dimensio
n $b+1$. By the dimension formula for vector subspaces,

$$\dim(\widetilde P_a \cap \widetilde P_b) \ge (a+1) + (b+1) - (n+1) = a + b - n
 + 1.$$

Projectivizing, $\dim(P_a \cap P_b) = \dim(\widetilde P_a \cap \widetilde P_b) -
 1 \ge a + b - n$, with equality in general position. When $a + b - n = 0$, the
vector-space intersection has dimension $1$, i.e. it is a single line through th
e origin, whose projectivization is a single point. $\square$

### Applying to a line and a $\mathbb{CP}^2$

Here $a = 1$ (the line $L \cong \mathbb{CP}^1$) and $b = 2$ (the subspace $\math
bb{CP}^2$), so $a + b = 3$.

- **$n = 3$:** $a + b = n$, so $L \cap \mathbb{CP}^2$ is a single point. **Answe
r: 1 point.**
- **$n = 2$:** $\mathbb{CP}^2$ is the entire ambient space, so $L \subset \mathb
b{CP}^2$ and the intersection is $L$ itself — infinitely many points. (This is t
he degenerate case $a+b > n$.)
- **$n \ge 4$:** $a + b = 3 < n$, so a generic line is disjoint from the fixed $
\mathbb{CP}^2$ (0 points). A special line that *does* meet the $\mathbb{CP}^2$ m
eets it in exactly one point (since any non-empty intersection of linear subspac
es is a linear subspace, and a line not contained in $\mathbb{CP}^2$ can meet it
 in at most one point).

### Conclusion

In the non-degenerate, transversal case — the case the problem is asking about,
where the line actually meets the $\mathbb{CP}^2$ in finitely many points — the
intersection is governed by $a + b = n$, giving a zero-dimensional intersection
consisting of exactly one point. A line cannot meet a $\mathbb{CP}^2$ in two or
more isolated points, because the intersection of two linear subspaces is itself
 linear: a linear subspace of dimension $0$ is a single point, and a linear subs
pace of dimension $\ge 1$ contains infinitely many points.

Therefore the number of points at which a line in $\mathbb{CP}^n$ intersects $\m
athbb{CP}^2$ is

$$\boxed{1}.$$
