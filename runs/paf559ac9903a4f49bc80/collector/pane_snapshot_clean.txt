## Solution

**Setting y = 0** in the functional equation:

$$f(x)f(0) = f(2x\cdot 0 + 3) + 3f(x+0) - 3f(x) + 6x$$

$$f(x)f(0) = f(3) + 3f(x) - 3f(x) + 6x = f(3) + 6x$$

**Case f(0) = 0:** Then $f(3) + 6x = 0$ for all $x$, which is impossible. So $f(
0) \neq 0$.

**Therefore f is linear:** $f(x) = \frac{6}{f(0)}x + \frac{f(3)}{f(0)}$, i.e., $
f(x) = ax + b$ for some constants $a, b$.

**Substituting $f(x) = ax + b$ into the original equation:**

LHS: $(ax+b)(ay+b) = a^2xy + abx + aby + b^2$

RHS: $a(2xy+3)+b + 3(a(x+y)+b) - 3(ax+b) + 6x$
$= 2axy + 3a + b + 3ax + 3ay + 3b - 3ax - 3b + 6x$
$= 2axy + 3ay + 6x + 3a + b$

**Equating coefficients:**

| Term | LHS | RHS | Equation |
|------|-----|-----|----------|
| $xy$ | $a^2$ | $2a$ | $a^2 = 2a \Rightarrow a(a-2)=0$ |
| $x$ | $ab$ | $6$ | $ab = 6$ |
| $y$ | $ab$ | $3a$ | $ab = 3a$ |
| const | $b^2$ | $3a+b$ | $b^2 = 3a+b$ |

From $a(a-2)=0$: $a=0$ or $a=2$.
- $a=0$: $ab=0 \neq 6$. **Rejected.**
- $a=2$: $ab=6 \Rightarrow b=3$. Check $y$: $ab=6=3a=6$ ✓. Check constant: $b^2=
9=3a+b=6+3=9$ ✓.

**So $f(x) = 2x + 3$ is the unique solution.**

**Verification:**
- LHS: $(2x+3)(2y+3) = 4xy + 6x + 6y + 9$
- RHS: $(4xy+9) + 3(2x+2y+3) - 3(2x+3) + 6x = 4xy+9+6x+6y+9-6x-9+6x = 4xy+6x+6y+
9$ ✓

**Final answer:**

$$f(8) = 2(8) + 3 = \boxed{19}$$
