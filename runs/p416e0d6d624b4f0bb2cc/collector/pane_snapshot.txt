## Solution

**Setup.** Place square $ABCD$ in the coordinate plane with $A = (0,0)$, $B = (1
,0)$, $C = (1,1)$, $D = (0,1)$.

A dilation about $A$ with scale factor $k$ sends each point $P \mapsto kP$, so:
$$B' = (k,0),\quad C' = (k,k),\quad D' = (0,k).$$

**Finding $k$.** We are given $BC' = 29$:
$$BC' = \sqrt{(k-1)^2 + k^2} = 29 \implies (k-1)^2 + k^2 = 841.$$
$$k^2 - 2k + 1 + k^2 = 841 \implies 2k^2 - 2k - 840 = 0 \implies k^2 - k - 420 =
 0.$$
$$k = \frac{1 \pm \sqrt{1 + 1680}}{2} = \frac{1 \pm 41}{2}.$$

So $k = 42$ or $k = -20$. Taking the (standard) positive dilation factor, $k = 4
2$.

**Area of $\triangle BDC'$.** With $B = (1,0)$, $D = (0,1)$, $C' = (42,42)$:
$$\text{Area} = \frac{1}{2}\big|x_B(y_D - y_{C'}) + x_D(y_{C'} - y_B) + x_{C'}(y
_B - y_D)\big|$$
$$= \frac{1}{2}\big|1\cdot(1-42) + 0\cdot(42-0) + 42\cdot(0-1)\big| = \frac{1}{2
}|-41 - 42| = \frac{83}{2} = 41.5.$$
