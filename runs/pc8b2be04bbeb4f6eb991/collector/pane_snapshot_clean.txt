## Proof

8}$. So $a^2 = a$, giving $a=1$ (since $a \neq 0$).

**Step 2 — Parity.** $P(x^2+1)$ is a polynomial in $x^2$, so it contains only ev
en powers of $x$. Hence $P(x)^2 - 1$ contains only even powers of $x$, meaning $
P(x)^2$ is an even function: $P(-x)^2 = P(x)^2$. Since $\mathbb{C}[x]$ is an int
egral domain,
$$(P(-x)-P(x))(P(-x)+P(x))=0 \implies P(-x)=P(x) \text{ or } P(-x)=-P(x).$$
Since $\deg P = 2024$ is even, $P$ must be **even**.

**Step 3 — Reduction Lemma.** *If $P$ is a degree-$2n$ solution, then there exis
ts a degree-$n$ solution $S$ with $P(x) = S(x^2+1)$. Conversely, if $S$ is a deg
ree-$n$ solution, then $P(x)=S(x^2+1)$ is a degree-$2n$ solution.*

*Proof.* Since $P$ is even, write $P(x) = R(x^2)$, $\deg R = n$. Substituting:
$$R(x^2)^2 - 1 = R\big((x^2+1)^2\big).$$
Setting $u = x^2$: $R(u)^2 - 1 = R((u+1)^2)$. Now set $t = u+1$ and $S(t) := R(t
-1)$:
$$S(t)^2 - 1 = R(t-1)^2 - 1 = R(t^2) = S(t^2+1).$$
So $S$ satisfies the same functional equation with $\deg S = n$, and $P(x) = R(x
^2) = S(x^2+1)$.

Conversely, if $S(t)^2-1 = S(t^2+1)$, set $P(x) = S(x^2+1)$. Then:
$$P(x)^2 - 1 = S(x^2+1)^2 - 1 = S\big((x^2+1)^2+1\big) = P(x^2+1). \quad\square$
$

**Step 4 — Iterating.** Applying the lemma three times:
$$2024 \;\longrightarrow\; 1012 \;\longrightarrow\; 506 \;\longrightarrow\; 253.
$$
A degree-2024 solution exists **if and only if** a degree-253 solution exists.

**Step 5 — No odd-degree solution exists.** Let $W$ be a degree-253 solution. Si
nce $253$ is odd, the parity argument forces $W$ to be **odd**, so $W(0) = 0$.

Define the orbit $a_0 = 0$, $\;a_{k+1} = a_k^2 + 1$. From the functional equatio

$$W(a_{k+1}) = W(a_k^2+1) = W(a_k)^2 - 1.$$

Computing:
- $W(a_0) = W(0) = 0$
- $W(a_1) = W(1) = 0^2 - 1 = -1$
- $W(a_2) = W(2) = (-1)^2 - 1 = 0$
- $W(a_3) = W(5) = 0^2 - 1 = -1$
- $W(a_4) = W(26) = 0$, and so on.

By induction: $W(a_k) = 0$ for even $k$, and $W(a_k) = -1$ for odd $k$.

The orbit is $a_0, a_1, a_2, \ldots = 0, 1, 2, 5, 26, 677, 458330, \ldots$, whic

Therefore $W$ vanishes at the infinitely many distinct points

But $W$ has degree $253$, so it has at most $253$ roots. **Contradiction.**

**Conclusion.** No degree-253 solution exists, so by the reduction lemma, no deg
