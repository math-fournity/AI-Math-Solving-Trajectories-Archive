## Solution

Let $s = x+y+z$, $p = xy+yz+zx$, $q = xyz$. Since $y+z = s-x$ (and cyclically),
define
$$S_k = \sum_{\text{cyc}} \frac{x^k}{s-x}.$$

**Key identity.** Since $x = s-(s-x)$,
$$\frac{x}{s-x} = \frac{s}{s-x}-1.$$

Summing: $S_1 = s\sum\frac{1}{s-x} - 3 = 9$, so $s\sum\frac{1}{s-x} = 12$.

Now $\sum\frac{1}{s-x} = \sum\frac{1}{y+z} = \frac{2s}{(y+z)(z+x)(x+y)}$, and $(
x+y)(y+z)(z+x) = sp - q$. Therefore
$$s\cdot\frac{2s}{sp-q} = 12 \implies sp - q = \frac{s^2}{6}. \tag{A}$$

**Finding $s$.** Write $x^2 = s^2 - 2s(s-x)+(s-x)^2$, so
$$\frac{x^2}{s-x} = \frac{s^2}{s-x}-2s+(s-x).$$
Summing: $S_2 = s^2\sum\frac{1}{s-x} - 6s + 2s = 12s - 4s = 8s$. Since $S_2 = 64
$,
$$s = 8.$$

**Finding $p$.** Write $x^3 = s^3-3s^2(s-x)+3s(s-x)^2-(s-x)^3$, so
$$\frac{x^3}{s-x} = \frac{s^3}{s-x}-3s^2+3s(s-x)-(s-x)^2.$$
Summing:
$$S_3 = s^3\sum\frac{1}{s-x}-9s^2+3s\cdot 2s - \sum(s-x)^2.$$
Using $s^3\sum\frac{1}{s-x}=12s^2$ and $\sum(s-x)^2 = 2s^2-2p$:
$$S_3 = 12s^2 - 9s^2 + 6s^2 - (2s^2-2p) = 7s^2+2p.$$
With $s=8$: $488 = 7\cdot 64 + 2p = 448+2p$, so $p = 20$.

**Finding $q$.** From (A): $q = sp - \frac{s^2}{6} = 8\cdot 20 - \frac{64}{6} =
160 - \frac{32}{3} = \frac{448}{3}$.

**The target expression.**
$$\frac{x}{yz}+\frac{y}{zx}+\frac{z}{xy} = \frac{x^2+y^2+z^2}{xyz} = \frac{s^2-2
p}{q} = \frac{64-40}{448/3} = \frac{24\cdot 3}{448} = \frac{72}{448} = \frac{9}{
56}.$$

**Verification.** $s=8,\,p=20,\,q=448/3$:
- $sp-q = 160-448/3 = 32/3 = s^2/6$ ✓
- $\sum 1/(s-x) = 2s/(sp-q) = 16/(32/3) = 3/2$; $S_1 = 8\cdot 3/2 - 3 = 9$ ✓
- $S_2 = 8s = 64$ ✓
- $S_3 = 7\cdot 64 + 40 = 488$ ✓

Thus $\frac{m}{n} = \frac{9}{56}$ with $\gcd(9,56)=1$, giving $m+n = 9+56 = \box
ed{65}$.

### PROOF COMPLETE
