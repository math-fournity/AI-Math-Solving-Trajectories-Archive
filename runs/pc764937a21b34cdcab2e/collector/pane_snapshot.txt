**Answer: Yes**

**Proof.**

Let $\tilde{T}: \mathcal{S}(\mathbb{R}^n) \to \mathbb{R}$ be the continuous exte

**Step 1: The extension forces $\mu$ to be a tempered measure.**

Since $\tilde{T}$ is continuous on $\mathcal{S}$, there exist $C > 0$ and $m \in

$$|\tilde{T}(\varphi)| \leq C \max_{|\alpha|,\,|\beta|\leq m}\sup_{x \in \mathbb

For $\varphi \in \mathcal{D}$ with $\varphi \geq 0$, since $\mu$ is nonnegative,

$$\int \varphi\,d\mu \leq C \max_{|\alpha|,\,|\beta|\leq m}\sup_x |x^\alpha \par

Set $M = m+1$. Let $\eta \in C_c^\infty(\mathbb{R}^n)$ with $\eta \geq 0$, $\eta

$$\varphi_R(x) = \eta(x/R)\,(1+|x|^2)^{-M}.$$

Then $\varphi_R \in \mathcal{D}$, $\varphi_R \geq 0$, and $\varphi_R \nearrow (1
+|x|^2)^{-M}$ pointwise as $R \to \infty$.

**Claim:** The seminorms $\sup_x |x^\alpha \partial^\beta \varphi_R(x)|$ for $|\

- For $|\beta| = 0$: $|x^\alpha(1+|x|^2)^{-M}| \leq (1+|x|^2)^{|\alpha|/2 - M} \

|\alpha|-2M-|\beta|)/2} \leq C$ since $|\alpha| - 2M - |\beta| \leq m - 2(m+1) -

we have $|x| \sim R$, so $|x^\alpha| \lesssim R^{|\alpha|}$, $|\partial^{\beta'}

So all seminorms are uniformly bounded by some constant $C'$. Applying $(\ast)$:
$$\int \varphi_R\,d\mu \leq C \cdot C' \quad \text{for all } R.$$

By the Monotone Convergence Theorem ($\varphi_R \nearrow (1+|x|^2)^{-M}$, $\mu \

$$\int_{\mathbb{R}^n} (1+|x|^2)^{-M}\,d\mu(x) \leq C \cdot C' < \infty.$$

Thus $\mu$ is a **tempered measure**.

$$\lim_{k \to \infty} \int \varphi_k\,d\mu = \int \varphi\,d\mu.$$
