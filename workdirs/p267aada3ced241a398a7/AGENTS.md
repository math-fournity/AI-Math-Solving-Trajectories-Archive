# Problem

In a remote digital server farm, a data-processing trial is conducted over several stages. At the start of the trial, there are exactly $2^n + 6$ data packets entering the system, where $n$ is a natural number greater than 7.

The trial consists of seven sequential processing rounds. In each round, packets are matched into pairs to compete for a "priority bit." To be paired, two packets must currently possess the exact same number of priority bits. These pairs are formed randomly; if a packet cannot find a partner because there is an odd number of packets with that specific bit count, that packet simply skips the round and retains its current bit count.

When two packets are paired, a high-speed verification occurs: one packet is awarded 1 priority bit (a "win"), and the other packet receives 0 bits (a "loss"). Every packet begins the trial with 0 priority bits.

After the completion of the seventh round, how many total data packets will have accumulated exactly 4 priority bits?
