## Proof

**Claim:** Yes, such a one-form $\gamma \in \Omega^1(M)$ always exists.

**Construction.** Every smooth manifold $M$ admits a Riemannian metric $g$. (Thi
s is standard: take a locally finite cover $\{U_\alpha\}$ by coordinate charts,
pull back the Euclidean metric on each chart, and sum $g = \sum_\alpha \rho_\alp
ha\, g_\alpha$ using a smooth partition of unity $\{\rho_\alpha\}$ subordinate t
o the cover. The result is a smooth, positive-definite $(0,2)$-tensor field.)

Since $Z$ is nowhere vanishing, $Z(p) \neq 0$ for every $p \in M$. By positive-d
efiniteness of $g$,

$$g(Z, Z)(p) = g_p\bigl(Z(p), Z(p)\bigr) > 0 \quad \text{for all } p \in M.$$

Thus the smooth function $f := g(Z,Z) \colon M \to \mathbb{R}$ is strictly posit
ive everywhere, and $1/f$ is a well-defined smooth function on $M$.

Define the one-form

$$\gamma := \frac{1}{g(Z,Z)}\, g(Z, \cdot\,).$$

Concretely, for any vector field $X$ on $M$,

$$\gamma(X) = \frac{g(Z, X)}{g(Z, Z)}.$$

This is smooth since $g$, $Z$, and $1/g(Z,Z)$ are all smooth. Evaluating on $Z$
itself:

$$\gamma(Z) = \frac{g(Z, Z)}{g(Z, Z)} = 1.$$

Therefore $\gamma \in \Omega^1(M)$ satisfies $\gamma(Z) = 1$ pointwise on all of
 $M$. $\blacksquare$

**Remark.** The nowhere-vanishing hypothesis on $Z$ is essential: it guarantees
$g(Z,Z) > 0$ so that the normalization by $g(Z,Z)$ is well-defined. The construc
tion does not require $M$ to be compact, orientable, or of any particular dimens
ion — only that $Z$ is a smooth nowhere-vanishing vector field.
