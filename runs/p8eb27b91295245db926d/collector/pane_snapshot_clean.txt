## Convergence of $\displaystyle\int_0^{+\infty} \frac{\arctan x}{x^a}\sin x\,dx
$, $a\in\mathbb{R}$

We split the integral at $x=1$:
$$\int_0^{+\infty} = \int_0^1 + \int_1^{+\infty},$$
and analyze each piece. The integral converges iff both pieces converge.

### Piece 1: Near $0$ — $\displaystyle\int_0^1 \frac{\arctan x}{x^a}\sin x\,dx$

As $x\to 0^+$, we have the standard asymptotics $\arctan x \sim x$ and $\sin x \
sim x$, so
$$\frac{\arctan x}{x^a}\sin x \sim \frac{x\cdot x}{x^a} = x^{2-a}.$$
By the limit comparison test (with limit $1$), $\int_0^1 \frac{\arctan x}{x^a}\s
in x\,dx$ converges iff $\int_0^1 x^{2-a}\,dx$ converges, which holds iff $2-a>-
1$, i.e.,
$$\boxed{a<3.}$$

### Piece 2: Near $+\infty$ — $\displaystyle\int_1^{+\infty} \frac{\arctan x}{x^
a}\sin x\,dx$

For $x>0$, use the identity $\arctan x = \tfrac{\pi}{2}-\arctan\tfrac{1}{x}$, gi
ving
$$\frac{\arctan x}{x^a}\sin x = \frac{\pi}{2}\cdot\frac{\sin x}{x^a} - \frac{\ar
ctan(1/x)}{x^a}\sin x.$$

**Second term.** Since $\arctan(1/x)\sim 1/x$ as $x\to\infty$, we have $\left|\f
rac{\arctan(1/x)}{x^a}\sin x\right|\le \frac{C}{x^{a+1}}$. The integral $\int_1^
\infty \frac{dx}{x^{a+1}}$ converges iff $a+1>1$, i.e., $a>0$. So the second ter
m converges (absolutely) for $a>0$.

**First term.** $\frac{\pi}{2}\int_1^\infty \frac{\sin x}{x^a}\,dx$. Apply **Dir
ichlet's test**: $\frac{1}{x^a}\to 0$ monotonically (for $a>0$) and $\left|\int_
1^R \sin x\,dx\right|\le 2$ is bounded. Hence $\int_1^\infty \frac{\sin x}{x^a}\
,dx$ converges for $a>0$.

**Divergence for $a\le 0$.** For $a=0$: $\int_1^\infty \sin x\,dx = \lim_{R\to\i
nfty}(\cos 1-\cos R)$, which does not exist. For $a<0$, set $b=-a>0$; integratio
n by parts gives
$$\int_1^R x^b\sin x\,dx = \bigl[-x^b\cos x\bigr]_1^R + b\int_1^R x^{b-1}\cos x\
,dx = -R^b\cos R + \cos 1 + (\text{growing term}).$$
The boundary term $-R^b\cos R$ oscillates with growing amplitude, so the limit d
oes not exist. Hence the integral diverges for $a\le 0$.

Combining, the second piece converges iff
$$\boxed{a>0.}$$

### Combining both pieces

The full integral converges iff $a<3$ **and** $a>0$, i.e.,
$$\boxed{0<a<3.}$$

### Absolute convergence (bonus)

At $0$: $\int_0^1 x^{2-a}\,dx$ is already of constant sign, so absolute converge
nce there also requires $a<3$. At $+\infty$: $\int_1^\infty \frac{|\arctan x|}{x
^a}|\sin x|\,dx \sim \frac{\pi}{2}\int_1^\infty \frac{|\sin x|}{x^a}\,dx$, which
 converges iff $a>1$. So the integral converges **absolutely** iff $1<a<3$, and
**conditionally** iff $0<a\le 1$.

### Conclusion

The improper integral $\displaystyle\int_0^{+\infty}\frac{\arctan x}{x^a}\sin x\
,dx$ **converges if and only if $0<a<3$**. Within this range it is absolutely co
nvergent for $1<a<3$ and conditionally convergent for $0<a\le 1$.
