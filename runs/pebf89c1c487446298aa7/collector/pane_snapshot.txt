## Solution

We seek positive integers $x$ such that $\lfloor x/20 \rfloor = \lfloor x/17 \rf
loor$.

**Setting up.** Let $\lfloor x/20 \rfloor = \lfloor x/17 \rfloor = n$ for some n
on-negative integer $n$. Then:
- $n \le x/20 < n+1 \implies 20n \le x \le 20n+19$
- $n \le x/17 < n+1 \implies 17n \le x \le 17n+16$

So $x$ must satisfy $\max(20n,\, 17n) \le x \le \min(20n+19,\, 17n+16)$.

**Simplifying the bounds.** For $n \ge 0$, $20n \ge 17n$, so the lower bound is
$20n$. For the upper bound, $17n+16 < 20n+19 \iff 3n > -3$, which holds for all
$n \ge 1$ (and also for $n=0$: $16 < 19$). So the upper bound is always $17n+16$
.

The interval is non-empty iff $20n \le 17n+16 \iff 3n \le 16 \iff n \le 5$.

**Counting per value of $n$.** The number of integers in $[20n,\, 17n+16]$ is $(
17n+16) - 20n + 1 = 17 - 3n$.
