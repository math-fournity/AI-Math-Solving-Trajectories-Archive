# Solution: Pendulum with Variable Length

## Setup and Constraint

Place the pivot at the origin. The bob position is $(r\sin\theta,\,-r\cos\theta)
$. "The bob moves horizontally for all time" means the vertical coordinate is co
nstant:

$$r(t)\cos\theta(t) = a, \qquad a = r(0)\cos\theta_0 = \text{const.}$$

This gives $r = a\sec\theta$, so $r$ is determined once $\theta(t)$ is known.

## Reducing the ODE under the constraint

From $r = a\sec\theta$:

$$\frac{r'}{r} = \frac{a\sec\theta\tan\theta\cdot\theta'}{a\sec\theta} = \tan\th
eta\cdot\theta', \qquad \frac{g}{r} = \frac{g\cos\theta}{a}.$$

Substituting into the original equation $\theta'' + \bigl(2\frac{r'}{r}+\frac{c}
{m}\bigr)\theta' + \frac{g}{r}\sin\theta = 0$:

$$\theta'' + 2\tan\theta\,(\theta')^2 + \frac{c}{m}\theta' + \frac{g}{a}\sin\the
ta\cos\theta = 0. \tag{1}$$

## Linearizing substitution $w = \tan\theta$

Set $w = \tan\theta$. Then:
- $\theta' = \dfrac{w'}{1+w^2}$
- $\theta'' = \dfrac{w''(1+w^2) - 2w(w')^2}{(1+w^2)^2}$
- $\sin\theta\cos\theta = \dfrac{w}{1+w^2}$

Substituting into (1) and multiplying through by $(1+w^2)^2$:

$$w''(1+w^2) - 2w(w')^2 + 2w(w')^2 + \frac{c}{m}w'(1+w^2) + \frac{g}{a}w(1+w^2)
= 0.$$

The nonlinear terms $-2w(w')^2$ and $+2w(w')^2$ **cancel exactly**, and dividing
 by $(1+w^2)$:

$$\boxed{w'' + \frac{c}{m}\,w' + \frac{g}{a}\,w = 0.} \tag{2}$$

This is a **linear** damped harmonic oscillator equation.

## Initial conditions for $w$

From $\theta(0)=\theta_0$, $\theta'(0)=0$:

$$w(0) = \tan\theta_0, \qquad w'(0) = \sec^2\theta_0\cdot\theta'(0) = 0.$$

## Solution of the linear ODE

Let $\gamma = \dfrac{c}{2m}$ and $\omega_0^2 = \dfrac{g}{a}$. The characteristic
 roots are $\lambda = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}$.

### Underdamped case ($c^2 < 4m^2 g/a$)

Define $\omega = \sqrt{\omega_0^2 - \gamma^2} = \sqrt{\dfrac{g}{a} - \dfrac{c^2}
{4m^2}}$. The solution is:

$$w(t) = \tan\theta_0\; e^{-\gamma t}\left[\cos(\omega t) + \frac{\gamma}{\omega
}\sin(\omega t)\right].$$

### Critically damped ($c^2 = 4m^2 g/a$)

$$w(t) = \tan\theta_0\,(1+\gamma t)\,e^{-\gamma t}.$$

### Overdamped ($c^2 > 4m^2 g/a$)

With $\beta = \sqrt{\gamma^2 - \omega_0^2}$:

$$w(t) = \tan\theta_0\; e^{-\gamma t}\left[\cosh(\beta t) + \frac{\gamma}{\beta}
\sinh(\beta t)\right].$$

## The exact expression for $r(t)$

Since $r = a\sec\theta$ and $\tan\theta = w$, we have $\cos\theta = 1/\sqrt{1+w^
2}$, hence:

$$\boxed{r(t) = a\,\sqrt{1 + w(t)^2}, \qquad a = r(0)\cos\theta_0,}$$

where $w(t)$ solves the linear ODE (2) with $w(0)=\tan\theta_0$, $w'(0)=0$.

**Explicitly (underdamped case):**

$$\boxed{r(t) = a\sqrt{1 + \tan^2\!\theta_0\;\cdot\; e^{-ct/m}\!\left[\cos(\omeg
a t) + \frac{c}{2m\omega}\sin(\omega t)\right]^2},}$$

$$\omega = \sqrt{\frac{g}{a} - \frac{c^2}{4m^2}}, \qquad a = r(0)\cos\theta_0.$$

## Verification

1. **Horizontal motion:** $r\cos\theta = a\sqrt{1+w^2}\cdot\frac{1}{\sqrt{1+w^2}
} = a = \text{const}.$ ✓

2. **Initial conditions:** $w(0)=\tan\theta_0 \Rightarrow \theta(0)=\theta_0$; $
w'(0)=0 \Rightarrow \theta'(0)=w'(0)\cos^2\theta_0 = 0$. ✓

3. **ODE satisfied:** The derivation shows that under $r=a\sec\theta$, the origi
nal nonlinear ODE reduces exactly to the linear equation (2), whose solution $w(
t)$ we use. The cancellation of nonlinear terms $-2w(w')^2+2w(w')^2=0$ is the ke
y mechanism. ✓

4. **Consistency at $t=0$:** $r(0) = a\sqrt{1+\tan^2\theta_0} = a\sec\theta_0 =
a/\cos\theta_0$, matching $a = r(0)\cos\theta_0$. ✓

5. **Damping-free limit ($c=0$):** $w(t)=\tan\theta_0\cos(\omega_0 t)$, $\omega_
0=\sqrt{g/a}$, giving $r(t)=a\sqrt{1+\tan^2\theta_0\cos^2(\omega_0 t)}$ — a peri
odic variation of string length, as expected for undamped horizontal motion. ✓
