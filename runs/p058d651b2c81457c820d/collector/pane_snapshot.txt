Looking at this problem, I need to analyze the iterates of a monic quadratic $Q(
x) = x^2 + bx + c$ and the sequence of minima $a_n = \min_{x \in \mathbb{R}} Q_n
(x)$.

## Setup

Write $Q(y) = (y - m)^2 + a_1$ where $m = -b/2$ is the vertex and $a_1 = c - b^2
/4$ is the minimum of $Q$.

Since $Q_n(x) \to +\infty$ as $x \to \pm\infty$ (even degree, monic), each $a_n$
 is attained. The range of $Q_n$ is $[a_n, +\infty)$, so:

$$a_{n+1} = \min_{y \in [a_n,\, +\infty)} Q(y) = \min_{y \in [a_n,\, +\infty)} \
bigl((y-m)^2 + a_1\bigr).$$

This gives the key recurrence:
- If $a_n \leq m$: the vertex $m$ lies in $[a_n, \infty)$, so $a_{n+1} = a_1$.
- If $a_n > m$: $Q$ is increasing on $[a_n, \infty)$, so $a_{n+1} = Q(a_n) = (a_
n - m)^2 + a_1$.

Also, $a_{n+1} \geq a_1$ always, so $a_n \geq a_1$ for all $n \geq 2$.

## Ruling out the constant case

**Case A: $a_1 \leq m$.** Then $a_2 = a_1$ (vertex in range), and $a_2 = a_1 \le
q m$ gives $a_3 = a_1$, etc. So $a_n = a_1$ for all $n$, contradicting the condi
tion that some $a_k \neq a_{k+1}$. **Case A is impossible.**

## The strictly increasing case

**Case B: $a_1 > m$.** Then $a_2 = (a_1 - m)^2 + a_1 > a_1$ (since $a_1 \neq m$)
. Now $a_2 > a_1 > m$, so:
$$a_3 = (a_2 - m)^2 + a_1 > (a_1 - m)^2 + a_1 = a_2,$$
since $a_2 - m > a_1 - m > 0$. By induction: if $a_n > a_{n-1} > m$, then $a_{n+
1} = (a_n-m)^2 + a_1 > (a_{n-1}-m)^2 + a_1 = a_n$.

**The sequence is strictly increasing: $a_1 < a_2 < a_3 < \cdots$**

Since the given conditions force Case B, **hypothesis (i) must be true: $X = 1$.

## Boundedness — can $a_n < 2021$ for all $n$?

The recurrence $a_{n+1} = f(a_n)$ where $f(y) = (y-m)^2 + a_1$ is strictly incre
asing (in the sequence sense). Fixed points satisfy $y = (y-m)^2 + a_1$, i.e., $
y^2 - (2m+1)y + m^2 + a_1 = 0$, with discriminant $\Delta = 1 - 4(a_1 - m)$.

**If $a_1 - m < 1/4$:** two fixed points $y_1 < y_2$ exist. Since $f(y) - y > 0$

(a_1) > a_1$ forces $a_1$ below $y_1$), the increasing sequence converges to $y_
1 < \infty$.

**Concrete example:** Take $Q(x) = x^2 + 0.1$, so $m = 0$, $a_1 = 0.1$.

- $a_1 = 0.1 > 0 = m$ ✓ (Case B)

The sequence $a_1 = 0.1,\; a_2 = 0.11,\; a_3 \approx 0.1121,\; \ldots$ converges

All conditions are satisfied and $a_n < 2021$ for every $n$. **Hypothesis (ii) i
