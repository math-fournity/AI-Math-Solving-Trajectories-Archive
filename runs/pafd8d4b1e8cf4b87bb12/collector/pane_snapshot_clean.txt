# Solution

**Problem.** Let $E_1, E_2, \ldots$ be independent with $E_n \sim \operatorname{
Unif}\{1,2,\ldots,2n\}$. Find $P\!\bigl(\{E_n : n \ge 1\} = \mathbb{E}\bigr)$, w
here $\mathbb{E} = \{2,4,6,\ldots\}$ is the set of positive even integers.

---

## Proof

Define the event
$$A = \bigl\{\{E_n : n \ge 1\} = \mathbb{E}\bigr\}, \qquad B = \bigl\{E_n \text{
 is even for every } n \ge 1\bigr\}.$$

**Claim.** $A \subseteq B$.

If $A$ holds, then every value $E_n$ belongs to the set $\{E_n : n \ge 1\} = \ma
thbb{E}$, so every $E_n$ is even. Hence $A \subseteq B$, giving $P(A) \le P(B)$.

**Computing $P(B)$.** For each $n$, since $E_n$ is uniform on $\{1,2,\ldots,2n\}
$, exactly $n$ of the $2n$ values are even, so
$$P(E_n \text{ is even}) = \frac{n}{2n} = \frac{1}{2}.$$

By independence of $\{E_n\}$,
$$P(B) = P\!\left(\bigcap_{n=1}^{\infty} \{E_n \text{ even}\}\right) = \prod_{n=
1}^{\infty} P(E_n \text{ even}) = \prod_{n=1}^{\infty} \frac{1}{2} = \lim_{N\to\
infty} 2^{-N} = 0.$$

**Conclusion.** Since $A \subseteq B$,
$$0 \le P(A) \le P(B) = 0,$$
so
$$\boxed{P\!\bigl(\{E_n : n \ge 1\} = \mathbb{E}\bigr) = 0.}$$

The probability is **0**: the requirement that *every* $E_n$ be even already has
 probability zero (an infinite product of $1/2$), and the target event is even m
ore restrictive (it additionally requires surjectivity onto $\mathbb{E}$).
