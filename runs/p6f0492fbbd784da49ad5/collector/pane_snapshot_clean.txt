Looking at this problem, I need to find ∠AOB where O is the intersection of cevi
ans BN and CM in equilateral triangle ABC, given AN = BM, BM > MA, area(ABC) = 7
, and area(BOC) = 2.

## Setting up coordinates

Place the equilateral triangle with side length s:
- A = (0, 0), B = (s, 0), C = (s/2, s√3/2)

Let M = (us, 0) on AB, so MA = us and BM = s(1−u). The condition BM > MA gives u
 < 1/2.

Since AN = BM, and N lies on AC with N = t·C (so AN = ts), we get t = 1−u. Thus:
- M = (us, 0)
- N = ((1−u)s/2, (1−u)s√3/2)

## Finding the intersection O

**Line BN:** B + λ(N−B), giving O = (s(1 − λ(1+u)/2), λ(1−u)s√3/2)

**Line CM:** C + μ(M−C), giving O = (s(1/2 + μ(u−1/2)), s√3/2·(1−μ))

Equating y-coordinates: λ(1−u) = 1−μ, so μ = 1−λ(1−u).

Substituting into x and solving:
$$\lambda = \frac{1-u}{1-u+u^2}, \qquad \mu = \frac{u}{1-u+u^2}$$

This yields:
$$O = \left(\frac{s(1-2u+3u^2)}{2(1-u+u^2)},\; \frac{(1-u)^2 s\sqrt{3}}{2(1-u+u^
2)}\right)$$

## Computing the area ratio

Using the cross product for triangle BOC:
$$\text{Area}(BOC) = \frac{s^2\sqrt{3}\,u(1-u)}{4(1-u+u^2)}$$

Since Area(ABC) = s²√3/4, the ratio is:
$$\frac{\text{Area}(BOC)}{\text{Area}(ABC)} = \frac{u(1-u)}{1-u+u^2} = \frac{2}{
7}$$

## Solving for u

$$7u(1-u) = 2(1-u+u^2)$$
$$7u - 7u^2 = 2 - 2u + 2u^2$$
$$9u^2 - 9u + 2 = 0$$
$$u = \frac{9 \pm 3}{18} \implies u = \frac{2}{3} \text{ or } u = \frac{1}{3}$$

Since u < 1/2, we select **u = 1/3**.

## Computing ∠AOB

With u = 1/3, note 1−u+u² = 7/9:
$$x_O = \frac{s(1 - 2/3 + 1/3)}{2 \cdot 7/9} = \frac{s \cdot 2/3}{14/9} = \frac{
3s}{7}$$
$$y_O = \frac{(2/3)^2 s\sqrt{3}}{2 \cdot 7/9} = \frac{(4/9)s\sqrt{3}}{14/9} = \f
rac{2s\sqrt{3}}{7}$$

So **O = (3s/7, 2s√3/7)**.

Now compute the vectors:
$$\vec{OA} = A - O = \left(-\frac{3s}{7},\; -\frac{2s\sqrt{3}}{7}\right)$$
$$\vec{OB} = B - O = \left(\frac{4s}{7},\; -\frac{2s\sqrt{3}}{7}\right)$$

The dot product:
$$\vec{OA} \cdot \vec{OB} = \left(-\frac{3s}{7}\right)\!\left(\frac{4s}{7}\right
) + \left(-\frac{2s\sqrt{3}}{7}\right)\!\left(-\frac{2s\sqrt{3}}{7}\right) = -\f
rac{12s^2}{49} + \frac{12s^2}{49} = 0$$

Since the dot product is zero, the vectors are perpendicular.
