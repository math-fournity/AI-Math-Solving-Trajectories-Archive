## Proof

**Setup.** Since $\lambda_1+\lambda_2=1$, write $f(x)=\lambda_1+\lambda_2 x = 1-
\lambda_2(1-x)$. Note $f(1)=1$ and for $x\in[0,1)$, $f(x)<1$. The integrand is n
on-negative since $f(x)\geq x$ (because $f(x)-x=\lambda_1(1-x)\geq 0$), so $f(x)
^n\geq x^n$.

**Substitution.** Set $u=n(1-x)$, i.e., $x=1-u/n$, $dx=-du/n$. When $x:0\to 1$,
$u:n\to 0$, so

$$I_n = \int_0^n \frac{\bigl(1-\tfrac{\lambda_2 u}{n}\bigr)^n - \bigl(1-\tfrac{u
}{n}\bigr)^n}{u/n}\cdot\frac{du}{n} = \int_0^n \frac{\bigl(1-\tfrac{\lambda_2 u}
{n}\bigr)^n - \bigl(1-\tfrac{u}{n}\bigr)^n}{u}\,du.$$

Define $g_n(u)=\frac{(1-\lambda_2 u/n)^n-(1-u/n)^n}{u}\cdot\mathbf{1}_{[0,n]}(u)
$.

**Pointwise limit.** For each fixed $u\geq 0$, once $n>u$ we have $(1-\lambda_2
u/n)^n\to e^{-\lambda_2 u}$ and $(1-u/n)^n\to e^{-u}$, so

$$g_n(u)\to \frac{e^{-\lambda_2 u}-e^{-u}}{u}=:g(u).$$

**Domination (to apply DCT).** We use the standard inequality $(1-t/n)^n\leq e^{
-t}$ for $t\in[0,n]$.

*Case $u\in[0,1]$:* By the Mean Value Theorem applied to $t\mapsto(1-t)^n$ on $[
\lambda_2 u/n,\, u/n]$,

$$(1-\tfrac{\lambda_2 u}{n})^n-(1-\tfrac{u}{n})^n = n(1-\xi)^{n-1}\cdot\tfrac{(1
-\lambda_2)u}{n}=\lambda_1\, u\,(1-\xi)^{n-1}\leq \lambda_1\, u$$

for some $\xi\in[\lambda_2 u/n,\,u/n]$. Hence $g_n(u)\leq\lambda_1$.

*Case $u\geq 1$:* Since the numerator is non-negative and at most $(1-\lambda_2
u/n)^n\leq e^{-\lambda_2 u}$,

$$g_n(u)\leq\frac{e^{-\lambda_2 u}}{u}\leq e^{-\lambda_2 u}.$$

(For $u>n$, $g_n(u)=0\leq e^{-\lambda_2 u}$.)

The dominating function $h(u)=\lambda_1\,\mathbf{1}_{[0,1]}(u)+e^{-\lambda_2 u}\
,\mathbf{1}_{[1,\infty)}(u)$ is integrable on $[0,\infty)$.

**Applying DCT.** By the Dominated Convergence Theorem,

$$L=\int_0^\infty \frac{e^{-\lambda_2 u}-e^{-u}}{u}\,du.$$

**Frullani's integral.** For $a,b>0$,

$$\int_0^\infty\frac{e^{-au}-e^{-bu}}{u}\,du=\ln\!\frac{b}{a},$$

proved by writing $\frac{e^{-au}-e^{-bu}}{u}=\int_a^b e^{-ut}\,dt$ and exchangin
g order (justified by Tonelli/Fubini since the integrand is non-negative when $b
>a$):

$$\int_0^\infty\int_a^b e^{-ut}\,dt\,du=\int_a^b\frac{dt}{t}=\ln\frac{b}{a}.$$

With $a=\lambda_2$ and $b=1$ (note $0<\lambda_2<1$ so $b>a$):

$$L=\ln\frac{1}{\lambda_2}=-\ln\lambda_2.$$

**Sanity checks.** As $\lambda_2\to 0^+$ ($\lambda_1\to 1$): $f(x)\to 1$, so $I_
n\to\int_0^1\frac{1-x^n}{1-x}dx=H_n\to\infty$, and $-\ln\lambda_2\to\infty$. ✓
As $\lambda_2\to 1^-$ ($\lambda_1\to 0$): $f(x)\to x$, integrand $\to 0$, and $-
\ln\lambda_2\to 0$. ✓

---

$$\boxed{\lim_{n\to\infty}\int_0^1\frac{(\lambda_1+\lambda_2 x)^n-x^n}{1-x}\,dx
= -\ln\lambda_2 = \ln\frac{1}{\lambda_2}.}$$
