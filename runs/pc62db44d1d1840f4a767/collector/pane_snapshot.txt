Looking at this problem, I need to find the expected number of cuts when startin
g with a 2-meter string, where each cut keeps the longer piece (multiplying leng
th by a factor $f \sim \text{Uniform}[1/2, 1]$), stopping when the length drops
below 0.5m.

## Setting Up the Integral Equation

Let $h(L)$ = expected number of cuts starting from length $L$. Then:

$$h(L) = \begin{cases} 0 & L < 0.5 \\ 1 + \frac{2}{L}\int_{L/2}^{L} h(u)\,du & L
 \geq 0.5 \end{cases}$$

The factor $f = \max(t, 1-t)$ where $t \sim U[0,1]$ is uniform on $[1/2, 1]$ wit
h density 2, giving the $\frac{2}{L}$ weight after substituting $u = Lf$.

## Transforming to a Delay Differential Equation

Substitute $L = \frac{1}{2}e^y$ (so $y = \ln(2L)$) and let $g(y) = h(\frac{1}{2}
e^y)$, $\phi(y) = g(y)e^y$. The integral equation becomes:

$$\phi(y) = e^y + 2\int_{y-\ln 2}^{y} \phi(v)\,dv \quad (y \geq 0), \qquad \phi(
y) = 0 \quad (y < 0)$$

Differentiating yields the **delay differential equation**:

$$\phi'(y) = e^y + 2\phi(y) - 2\phi(y - \ln 2), \quad y \geq 0$$

with $\phi(0) = 1$. We want $h(2) = g(2\ln 2) = \phi(2\ln 2)/4$.

## Solving Piecewise (delay = $\ln 2$)

**Interval $[0, \ln 2)$:** Here $\phi(y - \ln 2) = 0$, so $\phi'(y) = e^y + 2\ph
i(y)$.

Solving the linear ODE with $\phi(0) = 1$:

$$\phi(y) = 2e^{2y} - e^y$$

At $y = \ln 2$: $\phi(\ln 2) = 2\cdot 4 - 2 = 6$.

**Interval $[\ln 2, 2\ln 2)$:** Now $\phi(y - \ln 2) = 2e^{2(y-\ln 2)} - e^{y-\l
n 2} = \frac{e^{2y}}{2} - \frac{e^y}{2}$, so:

$$\phi'(y) - 2\phi(y) = 2e^y - e^{2y}$$

Using integrating factor $e^{-2y}$:

$$e^{-2y}\phi(y) = -2e^{-y} - y + C$$

$$\phi(y) = -2e^y - ye^{2y} + Ce^{2y}$$

Matching $\phi(\ln 2) = 6$: $-4 - 4\ln 2 + 4C = 6 \implies C = \frac{5}{2} + \ln
 2$.

## Evaluating at $y = 2\ln 2$

$$\phi(2\ln 2) = -2e^{2\ln 2} - (2\ln 2)e^{4\ln 2} + \left(\tfrac{5}{2} + \ln 2\
right)e^{4\ln 2}$$

$$= -2(4) - (2\ln 2)(16) + \left(\tfrac{5}{2} + \ln 2\right)(16)$$

$$= -8 - 32\ln 2 + 40 + 16\ln 2 = 32 - 16\ln 2$$

$$h(2) = \frac{\phi(2\ln 2)}{e^{2\ln 2}} = \frac{32 - 16\ln 2}{4} = 8 - 4\ln 2$$

## Verification

**Direct formula check:** For $u \in [1, 2]$, $h(u) = -2 + 5u - 2u\ln u$. The in
tegral equation requires:

$$h(2) = 1 + \int_1^2 (-2 + 5u - 2u\ln u)\,du = 1 + \big[-2u + 3u^2 - u^2\ln u\b
ig]_1^2$$

$$= 1 + (8 - 4\ln 2) - 1 = 8 - 4\ln 2 \checkmark$$

**Boundary consistency:** $h(1) = -2 + 5 - 0 = 3$ from both pieces. For $u \in [
0.5, 1]$, $h(u) = 4u - 1$, giving $h(0.5) = 1$ (exactly one cut from 0.5m, since
 $0.5f < 0.5$ a.s.). All consistent.

**Sanity check:** The minimum is 3 cuts (each cut keeps $\geq$ half, so $2 \to 1
 \to 0.5 \to <0.5$ requires at least 3). The value $8 - 4\ln 2 \approx 5.23$ is
reasonable.

## Answer

$$\boxed{8 - 4\ln 2}$$
