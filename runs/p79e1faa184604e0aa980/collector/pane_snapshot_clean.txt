## Proof

**Step 1: Identify the sequence via Chebyshev polynomials and Fibonacci numbers.
**

Let $T_k$ denote the $k$-th Chebyshev polynomial of the first kind, defined by $
T_k(\cos\theta)=\cos(k\theta)$, and let $F_k$ denote the Fibonacci sequence with
 $F_0=0, F_1=1, F_2=1, F_3=2, F_4=3, F_5=5,\ldots$

**Claim:** $x_n = T_{F_n}(a)$ for all $n \geq 0$.

*Verification of base cases:* $x_0 = 1 = T_0(a) = T_{F_0}(a)$. $x_1 = a = T_1(a)
 = T_{F_1}(a)$. $x_2 = a = T_1(a) = T_{F_2}(a)$. ✓

*Key identity:* The Chebyshev polynomials satisfy
$$T_{p+q}(a) + T_{p-q}(a) = 2\,T_p(a)\,T_q(a),$$
which follows from $2\cos(p\theta)\cos(q\theta) = \cos((p{+}q)\theta)+\cos((p{-}
q)\theta)$ and the fact that both sides are polynomials in $a$ (so the identity,
 established on $[-1,1]$, extends to all $\mathbb{R}$).

*Inductive step:* For $n \geq 2$, assume $x_k = T_{F_k}(a)$ for $k \leq n$. Set
$p = F_n$, $q = F_{n-1}$. Since $F_n \geq F_{n-1}$ for $n \geq 1$, we have $p -
q = F_n - F_{n-1} = F_{n-2} \geq 0$ and $p + q = F_{n+1}$. The identity gives:
$$T_{F_{n+1}}(a) = 2\,T_{F_n}(a)\,T_{F_{n-1}}(a) - T_{F_{n-2}}(a) = 2\,x_n\,x_{n
-1} - x_{n-2} = x_{n+1}.$$
By induction, $x_n = T_{F_n}(a)$ for all $n \geq 0$.

**Step 2: Show $x_n = 0$ implies $|a| < 1$.**

- If $|a| > 1$, write $a = \varepsilon\cosh\theta$ with $\theta > 0$ and $\varep
silon = \operatorname{sgn}(a)$. Then $T_k(a) = \varepsilon^k \cosh(k\theta)$, so
 $|x_n| = \cosh(F_n\theta) \geq 1$ for all $n$. Hence $x_n \neq 0$.
- If $a = 1$: $T_k(1) = 1$ for all $k$, so $x_n = 1 \neq 0$.
- If $a = -1$: $T_k(-1) = (-1)^k$, so $x_n = \pm 1 \neq 0$.

Therefore $x_n = 0$ for some $n$ forces $|a| < 1$. Write $a = \cos\theta$ with $
\theta \in (0,\pi)$. Then:
$$x_n = T_{F_n}(\cos\theta) = \cos(F_n\,\theta).$$

**Step 3: Use the vanishing condition to pin down $\theta$.**

Since $x_n = 0$ for some $n \geq 1$ (note $x_0 = 1 \neq 0$), we have $\cos(F_n\t
heta) = 0$, so:
$$F_n\,\theta = \frac{\pi}{2} + j\pi \quad\text{for some integer } j,$$
$$\theta = \frac{(2j+1)\pi}{2\,F_n}.$$

Since $\theta \in (0,\pi)$, such a $j$ exists (as $x_n=0$ is given).

**Step 4: Establish periodicity via the Pisano period.**

For any positive integer $m$, the Fibonacci sequence $\{F_k\}$ is periodic modul
o $m$. This is the **Pisano period**: the sequence of pairs $(F_k \bmod m,\; F_{
k+1} \bmod m)$ takes values in the finite set $\mathbb{Z}_m \times \mathbb{Z}_m$
, so by the pigeonhole principle some pair repeats. Since the recurrence $F_{k+1
} = F_k + F_{k-1}$ is reversible ($F_{k-1} = F_{k+1} - F_k$), the sequence is *p
urely* periodic from $k=0$.

Set $m = 4F_n$ and let $P = \pi(4F_n)$ be the Pisano period, so $F_{k+P} \equiv
F_k \pmod{4F_n}$ for all $k \geq 0$.

Now compute:
$$F_{k+P}\,\theta - F_k\,\theta = (F_{k+P} - F_k)\cdot\frac{(2j+1)\pi}{2F_n}.$$

Since $F_{k+P} - F_k \equiv 0 \pmod{4F_n}$, we have $F_{k+P} - F_k = 4F_n \cdot
q$ for some integer $q$, so:
$$F_{k+P}\,\theta - F_k\,\theta = 4F_n \cdot q \cdot \frac{(2j+1)\pi}{2F_n} = 2(
2j+1)\pi\, q,$$
which is an integer multiple of $2\pi$. Therefore:
$$\cos(F_{k+P}\,\theta) = \cos(F_k\,\theta) \quad\text{for all } k \geq 0,$$
i.e., $x_{k+P} = x_k$ for all $k \geq 0$.

**Conclusion:** The sequence $\{x_k\}$ is periodic with period $P = \pi(4F_n)$,
the Pisano period of the Fibonacci sequence modulo $4F_n$. $\blacksquare$
