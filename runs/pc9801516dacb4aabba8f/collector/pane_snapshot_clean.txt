## Proof

**Answer-leak check:** The problem statement contains only the problem, no solut
ions or hints. Proceeding.

**Key identity.** Note that
$$ab+bc+cd+da = b(a+c)+d(a+c) = (a+c)(b+d).$$
Set $p=a+c$, $q=b+d$, $m=ac$, $n=bd$. Then $mn=abcd=7$ and
$$a^2+c^2 = p^2-2m,\quad b^2+d^2=q^2-2n,$$
so the second constraint becomes
$$p^2+q^2-2(m+n)=20,\quad\text{i.e.}\quad p^2+q^2=20+2(m+n).$$
We must maximize $pq$ subject to $mn=7$, $m\le p^2/4$, $n\le q^2/4$ (AM–GM), and
 $m,n>0$.

**Upper bound via AM–QM.** For fixed $S:=m+n$ (with $mn=7$, so $S\ge 2\sqrt 7$),
$$pq \le \frac{p^2+q^2}{2}=10+S,$$
with equality iff $p=q$. When $p=q$, we have $p^2=q^2=10+S$, and feasibility req
uires
$$m\le \frac{p^2}{4}=\frac{10+S}{4},\qquad n\le \frac{10+S}{4}.$$
Assume $m\ge n$ (WLOG by swapping the pairs). Then $m=\frac{S+\sqrt{S^2-28}}{2}$
, $n=\frac{S-\sqrt{S^2-28}}{2}$, and the binding constraint is
$$\frac{S+\sqrt{S^2-28}}{2}\le \frac{10+S}{4} \;\Longleftrightarrow\; 2\sqrt{S^2
-28}\le 10-S.$$
This requires $S\le 10$ and, squaring,
$$4(S^2-28)\le (10-S)^2 \;\Longleftrightarrow\; 3S^2+20S-212\le 0.$$
The positive root of $3S^2+20S-212=0$ is $S=\frac{-10+4\sqrt{46}}{3}$, so
$$S\le \frac{-10+4\sqrt{46}}{3}.$$
Therefore
$$pq \le 10+S \le 10+\frac{-10+4\sqrt{46}}{3}=\frac{20+4\sqrt{46}}{3}=\frac{4(5+
\sqrt{46})}{3}.$$

**Equality is attained.** Take $p=q$ and $m=\frac{5+\sqrt{46}}{3}$, $n=\sqrt{46}
-5$ (so $mn=\frac{(\sqrt{46})^2-25}{3}=\frac{21}{3}=7$ ✓). Set $a=c=\sqrt m$ (so
 $a=c$ makes $ac=m=p^2/4$ tight) and choose $b,d>0$ with $b+d=q=p$ and $bd=n$ (p
ossible since $n\le q^2/4$). Then
$$a^2+b^2+c^2+d^2=2m+(q^2-2n)=2m+p^2-2n=2m+10+S-2n=10+S+2(m-n).$$
With $S=m+n$: $=10+m+n+2m-2n=10+3m-n$. Substituting $3m=\frac{3(5+\sqrt{46})}{3}
=5+\sqrt{46}$ and $n=\sqrt{46}-5$:
$$10+(5+\sqrt{46})-(\sqrt{46}-5)=10+5+\sqrt{46}-\sqrt{46}+5=20.\;\checkmark$$
Also $abcd=a^2\cdot bd = m\cdot n=7$ ✓, and
$$ab+bc+cd+da=(a+c)(b+d)=p\cdot q=p^2=10+S=\frac{4(5+\sqrt{46})}{3}.$$

**Conclusion.** The maximum value of $ab+bc+cd+da$ is

$$\boxed{\dfrac{4(5+\sqrt{46})}{3}}.$$
