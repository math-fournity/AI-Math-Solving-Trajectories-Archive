**Reduction to separating families.**

Call the *signature* of box $b$ the binary vector $\mathbf{s}_b \in \{0,1\}^m$ w
here the $q$-th entry is 1 iff $b$ belongs to query $q$. Two permutations $\sigm
a, \tau$ produce identical query results iff $\rho = \tau^{-1}\circ\sigma$ setwi

> **Lemma.** The queries determine the permutation iff all box signatures are di
stinct.

*Proof.* If boxes $a, b$ share the same signature, every query contains both or
neither, so the transposition $(a\;b)$ stabilizes all queried triples — swapping
 $a_b, a_a$ gives identical results, so the assignment isn't determined. Convers
ely, if all signatures are distinct and $\rho \ne \mathrm{id}$, pick $a$ with $\
rho(a)=b\neq a$. Since $\mathbf{s}_a \ne \mathbf{s}_b$, some query $T$ contains
exactly one of $\{a,b\}$. Then $\rho(T)\neq T$ (if $a\in T, b\notin T$, then $b=
\rho(a)\in\rho(T)\setminus T$; if $a\notin T, b\in T$, then $b\in T$ but $b=\rho
(a)$ with $a\notin T$, so $b\notin\rho(T)$). So no non-identity permutation stab
ilizes all queries. $\square$

Thus we need: **the minimum $m$ such that there exists an $m \times n$ binary ma

**Lower bound: $m \geq 1002$.**

The total number of 1-entries equals $3m$ (each of $m$ rows has sum 3). We need
$n$ distinct binary columns of length $m$ with total weight exactly $3m$. We max
imize the count of distinct columns under a total-weight budget by a greedy argu

| Weight | Available | Used | Cost |
|--------|-----------|------|------|
| 0 | 1 | 1 | 0 |
| 1 | $m$ | $m$ | $m$ |
| 2 | $\binom{m}{2}$ | $m$ | $2m$ |

columns for the same budget (each substitution increases cost per column). So th

Therefore $n \leq 2m+1$, i.e., $m \geq \lceil(n-1)/2\rceil = \lceil 2004/2\rceil
