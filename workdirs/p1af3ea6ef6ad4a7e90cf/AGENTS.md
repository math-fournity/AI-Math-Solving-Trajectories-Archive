# Problem

In a specialized laboratory, an engineer is assembling three identical modular server units. Each unit is a perfect cube with six connection ports (one on each face). To organize the system, the engineer must activate exactly 18 ports across the three units: 9 ports must be configured to emit a Green signal, and the remaining 9 ports must be configured to emit a Yellow signal.

The units are physically identical and can be rotated freely in three-dimensional space. Two units are considered to have the same configuration if one can be rotated to look exactly like the other. Because the units themselves are identical, the overall system setup is defined only by the collection of configurations present, regardless of the order in which the three units are placed.

How many distinct ways can the 18 ports be assigned colors across the three units to satisfy these requirements?
