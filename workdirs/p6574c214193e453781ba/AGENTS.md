# Problem

A high-security data ring consists of 10 server nodes arranged in a fixed circle. These nodes host five distinct encrypted data packets, with each packet being mirrored across exactly two nodes (forming five pairs of identical twins). Initially, the 10 nodes are assigned these mirrored packets in a completely random arrangement.

A technician can modify the configuration by performing "swaps," where the data packets of any two physically adjacent nodes are interchanged. The system is considered "stable" only when the security protocol is satisfied: no two nodes sharing the same data packet are located next to each other in the circle.

Let $E$ be the expected value of the minimum number of swaps required to transform a random initial arrangement into a stable state. If $E$ is expressed as an irreducible fraction $\frac{a}{b}$, calculate the value of $a + b$.
