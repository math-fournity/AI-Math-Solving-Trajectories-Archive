## Solution

We exhibit an explicit infinite parametric family of positive integer solutions
to $x^2 = y^3 + z^5$.

**Key idea.** Force the two terms $y^3$ and $z^5$ to be *equal*, so their sum is
 twice a perfect power, then choose the parameter to make that sum a perfect squ
are.

Since $\operatorname{lcm}(3,5)=15$, setting
$$y = t^5, \qquad z = t^3$$
gives $y^3 = t^{15} = z^5$, and therefore
$$y^3 + z^5 = 2\,t^{15}.$$
We need $2\,t^{15}$ to be a perfect square. Writing $t^{15} = t\cdot(t^7)^2$, we
 see $2\,t^{15} = 2t\cdot(t^7)^2$, which is a square exactly when $2t$ is a perf
ect square. The general positive-integer solution of "$2t$ is a square" is
$$t = 2\,n^2, \qquad n \in \mathbb{Z}_{>0}.$$

**The family.** Substituting $t = 2n^2$:

$$\boxed{\;x = 256\,n^{15},\quad y = 32\,n^{10},\quad z = 8\,n^{6}\;}\qquad(n=1,
2,3,\dots)$$

**Verification.** For every positive integer $n$:
$$y^3 = (32\,n^{10})^3 = 2^{15}\,n^{30}, \qquad z^5 = (8\,n^{6})^5 = 2^{15}\,n^{
30}.$$
Hence
$$y^3 + z^5 = 2\cdot 2^{15}\,n^{30} = 2^{16}\,n^{30} = (2^{8}\,n^{15})^2 = (256\
,n^{15})^2 = x^2. \;\checkmark$$

**Infinitely many distinct solutions.** As $n$ ranges over $1,2,3,\dots$, the va
lue $z = 8n^6$ is strictly increasing, so the triples $(x_n,y_n,z_n)$ are pairwi
se distinct. Thus we obtain infinitely many solutions.

**Sanity check ($n=1$).** $(x,y,z)=(256,32,8)$: $\;32^3 + 8^5 = 32768 + 32768 =
65536 = 256^2.$ ✓

**Sanity check ($n=2$).** $(x,y,z)=(256\cdot 2^{15},\,32\cdot 2^{10},\,8\cdot 2^
6) = (8388608,\,32768,\,512)$: $\;y^3+z^5 = 2^{15}\cdot 2^{30} + 2^{15}\cdot 2^{
30} = 2^{46} = (2^{23})^2 = (8388608)^2.$ ✓

Therefore the equation $x^2 = y^3 + z^5$ admits infinitely many positive-integer
 solutions, one for each $n\in\mathbb{Z}_{>0}$, given by
$$(x,y,z)=\bigl(256\,n^{15},\;32\,n^{10},\;8\,n^{6}\bigr).$$
