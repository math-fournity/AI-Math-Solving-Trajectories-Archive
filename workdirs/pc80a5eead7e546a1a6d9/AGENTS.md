# Problem

A data processing firm has been contracted to run a heavy-duty stress test on a quantum server using $2k$ specialized software agents, where $k$ is a positive integer. The protocol requires every possible pair of agents to perform exactly one collaborative calculation together. To prevent overheating, exactly one pair of agents is scheduled to work each day, and no agent can work on more than one calculation per day.

Each agent is initialized (loaded into memory) at the beginning of the day it participates in its very first calculation. Each agent is then terminated (cleared from memory) at the end of the day it participates in its very last scheduled calculation. For every day an agent remains in the server's memory (from the day of initialization to the day of termination, inclusive), the firm must pay a licensing fee of exactly one credit.

The firm’s engineers must design a schedule for the $\frac{2k(2k-1)}{2}$ daily calculations to minimize the total licensing fees paid for all agents over the duration of the project. Find this minimum total cost in credits.
