## Solution

**Step 1: n must be even.**

If n is odd, then 2n = τ(n)². Since 2n is even, τ(n) is even, so n is not a perf
ect square. But 2n = τ(n)² means 2n is a perfect square. Writing n = p₁^a₁ ⋯ pₖ^
aₖ (all odd primes), the left side 2n has exactly **one** factor of 2, while τ(n
)² = (a₁+1)²⋯(aₖ+1)² is a perfect square and thus has an **even** number of fact
ors of 2. Contradiction. So n is even.

**Step 2: Setting up the general equation.**

Write n = 2^a · m where m is odd, with m = p₁^{b₁} ⋯ p_{k}^{bₖ}. Then τ(n) = (a+
1)(b₁+1)⋯(bₖ+1), and the equation becomes:

$$\tau(n)^2 = 2n \implies \tau(n) = \sqrt{2n}$$

Since 2n must be a perfect square, we need a+1 even (so a odd), and all bᵢ even.
 Set a+1 = 2u, bᵢ = 2vᵢ. Then:

$$2n = (2^u \cdot p_1^{v_1} \cdots p_k^{v_k})^2, \quad \tau(n) = 2u \prod(2v_i+1
)$$

So we need: $2u \prod(2v_i+1) = 2^u \prod p_i^{v_i}$.

**Step 3: Determining u.**

The odd part of the left side is $\prod(2v_i+1)$ (all factors odd) times the odd
 part of $2u$. Since $\prod p_i^{v_i}$ is odd, the power of 2 on both sides give
s: $v_2(2u) = u$, i.e., $2u = 2^u \cdot t$ where $t$ is odd. This forces $t = u/
2^{u-1}$ to be a positive odd integer:
- u=1: t=1 ✓ (a=1)
- u=2: t=1 ✓ (a=3)
- u≥3: t < 1 ✗

So **a ∈ {1, 3}** always, and the remaining equation is:

$$\prod(2v_i+1) = \prod p_i^{v_i}$$

**Step 4: Solving the core equation.**

We need $\prod_{i=1}^{k}(2v_i+1) = \prod_{i=1}^{k} p_i^{v_i}$ where the $p_i$ ar
e distinct odd primes and $v_i \geq 1$.

**Key inequality:** For any $v \geq 2$ and odd prime $p \geq 3$: $p^v \geq 3^v >
 2v+1$ (checked: $3^2=9>5$, $3^3=27>7$, and exponential dominates). For $v=1$: $
p \geq 3 = 2(1)+1$, with equality iff $p=3$.

**If all $v_i = 1$:** The equation becomes $3^k = \prod p_i$. This requires all
$p_i = 3$, impossible for $k \geq 2$ (primes must be distinct). For $k=1$: $p_1
= 3$. ✓

**If any $v_i \geq 2$:** WLOG $v_1 \geq 2$. Then $\prod p_i^{v_i} \geq 3^{\sum v
_i}$ while $\prod(2v_i+1) \leq \prod(2v_i+1)$. Since $3^{v_i} \geq 2v_i+1$ for a
ll $v_i$ (with strict inequality when $v_i \geq 2$), we get $\prod p_i^{v_i} \ge
q 3^{\sum v_i} > \prod(2v_i+1)$ whenever any $v_i \geq 2$. So no solutions exist
 in this case.

**Conclusion:** The only possibility is $k=1$, $v_1=1$, $p_1=3$ (i.e., $m = 9$),
 or $k=0$ (i.e., $m=1$, pure power of 2).

**Step 5: Enumerating all solutions.**

- **k=0 (n = 2^a):** Need $(a+1)^2 = 2^{a+1}$. Testing: a=1 gives 4=4 ✓, a=3 giv
es 16=16 ✓. For a≥4, $2^{a+1}$ dominates $(a+1)^2$. → **n = 2, 8**

- **k=1, p=3, v=1 (n = 2^a · 9):** Need $(a+1)^2 \cdot 9 = 2^{a+1} \cdot 9$, red
ucing to $(a+1)^2 = 2^{a+1}$. Same solutions: a=1, a=3. → **n = 18, 72**

**Verification:**
- n=2: τ(2)=2, 2²=4=2·2 ✓
- n=8: τ(8)=4, 4²=16=2·8 ✓
- n=18: τ(18)=(1+1)(2+1)=6, 6²=36=2·18 ✓
- n=72: τ(72)=(3+1)(2+1)=12, 12²=144=2·72 ✓

**The sum is 2 + 8 + 18 + 72 = 100.**
