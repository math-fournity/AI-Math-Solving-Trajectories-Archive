# Work Done by the Vector Field

## Step 1: Check if the field is conservative

Let $F = (P, Q, R)$ with
$$P = \tfrac{2}{\pi}x\sin\pi y,\quad Q = x^2\cos\pi y + 2ye^{-z},\quad R = -y^2
e^{-z} + 2x.$$

Compute $\nabla \times F$:

- **x-component:** $\dfrac{\partial R}{\partial y} - \dfrac{\partial Q}{\partial
 z} = -2y e^{-z} - (-2y e^{-z}) = 0$
- **y-component:** $\dfrac{\partial P}{\partial z} - \dfrac{\partial R}{\partial
 x} = 0 - 2 = -2$
- **z-component:** $\dfrac{\partial Q}{\partial x} - \dfrac{\partial P}{\partial
 y} = 2x\cos\pi y - \tfrac{2}{\pi}x\cdot\pi\cos\pi y = 0$

So $\nabla \times F = (0, -2, 0)$. The field is **not** conservative, so we must
 compute the line integral directly (or use Stokes' theorem).

## Step 2: Decompose the field

Write $F = F_1 + F_2 + F_3$ where:

- $F_1 = \left(\tfrac{2}{\pi}x\sin\pi y,\; x^2\cos\pi y,\; 0\right) = \nabla\!\l
eft(\tfrac{x^2}{\pi}\sin\pi y\right)$ — **conservative**.
- $F_2 = \left(0,\; 2ye^{-z},\; -y^2 e^{-z}\right) = \nabla\!\left(y^2 e^{-z}\ri
ght)$ — **conservative** (verify: $\partial_y(y^2 e^{-z}) = 2y e^{-z}$ ✓, $\part
ial_z(y^2 e^{-z}) = -y^2 e^{-z}$ ✓).
- $F_3 = (0, 0, 2x)$ — the only non-conservative part, with $\nabla \times F_3 =
 (0,-2,0) = \nabla \times F$. ✓

## Step 3: The intersection curve

Setting $x^2 + y^2 = 4x$ gives $(x-2)^2 + y^2 = 4$, a circle of radius $2$ cente
red at $(2,0)$, lying in the plane $z = 4x$. This is a **closed curve** $C$.

Since $C$ is closed, the conservative parts $F_1, F_2$ contribute zero:

$$\oint_C F \cdot d\mathbf{r} = \oint_C F_3 \cdot d\mathbf{r} = \oint_C 2x\, dz.
$$

## Step 4: Evaluate via Stokes' theorem

Using the surface $S$: the portion of the plane $z = 4x$ inside $C$, with upward
 normal $\mathbf{n}\,dS = (-4, 0, 1)\,dx\,dy$:

$$\oint_C F \cdot d\mathbf{r} = \iint_S (\nabla \times F)\cdot \mathbf{n}\,dS =
\iint_D (0, -2, 0)\cdot(-4, 0, 1)\,dx\,dy = \iint_D 0\,dx\,dy = 0.$$

The curl $(0,-2,0)$ is **perpendicular** to the normal $(-4,0,1)$ of the plane $
z=4x$, so the flux vanishes.

## Step 5: Direct verification

Parametrize $C$: $x = 2+2\cos t$, $y = 2\sin t$, $z = 8+8\cos t$, $t\in[0,2\pi]$
, so $dz = -8\sin t\,dt$.

$$\oint_C 2x\,dz = \int_0^{2\pi} 2(2+2\cos t)(-8\sin t)\,dt = -16\int_0^{2\pi}(2
+2\cos t)\sin t\,dt$$
$$= -32\int_0^{2\pi}\sin t\,dt - 32\int_0^{2\pi}\cos t\,\sin t\,dt = -32\cdot 0
- 16\int_0^{2\pi}\sin 2t\,dt = 0.$$

Both methods agree.

## Result

$$\boxed{\oint_C F \cdot d\mathbf{r} = 0}$$

The work done by the vector field $F$ on the intersection curve is **$0$**.
