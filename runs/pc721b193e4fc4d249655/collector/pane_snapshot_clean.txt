**问题：** 是否存在 $g: \mathbb{N} \rightarrow \mathbb{N}$，使得集合 $\{f \mid f
: \mathbb{N} \rightarrow \mathbb{N},\ f \circ f = g\}$ 非空且有限？

**答案：** 是的。取 $g(n) = n+2$。该集合恰好有两个元素。

---

**证明。**

设 $\mathbb{N} = \{0, 1, 2, \dots\}$，并定义 $g(n) = n + 2$。

**步骤 1：$g$ 至少有一个平方根。**

函数 $f_1(n) = n + 1$ 满足 $f_1 \circ f_1(n) = n + 2 = g(n)$，因此该集合非空。

**步骤 2：$g$ 的泛函图。**

$g$ 是单射，其像为 $\{2, 3, 4, \dots\}$。元素 $0$ 和 $1$ 在 $g$ 下没有原像；其余
每个元素恰好有一个原像。因此，$g$ 的泛函图由两条不相交的射线（无限链）组成：
$$R_{\text{even}}: 0 \to 2 \to 4 \to 6 \to \cdots, \qquad R_{\text{odd}}: 1 \to
3 \to 5 \to 7 \to \cdots$$
不存在环，也不存在树。

**步骤 3：任何平方根 $f$ 必定是单射的。**

如果 $f(a) = f(b)$，那么 $g(a) = f(f(a)) = f(f(b)) = g(b)$。由于 $g$ 是单射，$a
= b$。因此 $f$ 是单射的。

**步骤 4：$f$ 的泛函图是射线的并集（无环，无树）。**

单射函数 $f: \mathbb{N} \to \mathbb{N}$ 的泛函图中，每个节点在 $f$ 下至多有一个
原像。每个连通分量要么是一个环，要么是一条射线（以唯一“起始”节点开头的无限链，该
节点不在 $f$ 的像中）。$f$ 中的环在 $f \circ f$ 中会产生环，但 $g$ 没有环，因此
$f$ 没有环。因此 $f$ 的图是射线的并集，这些射线覆盖了 $\mathbb{N}$ 的所有元素。

**步骤 5：射线计数。**

假设 $f$ 有 $k$ 条射线。在 $f \circ f$ 下，每条射线 $a \to f(a) \to f^2(a) \to f
^3(a) \to \cdots$ 会分裂为两条子射线：
$$a \to f^2(a) \to f^4(a) \to \cdots, \qquad f(a) \to f^3(a) \to f^5(a) \to \cdo
ts$$
这两条子射线是不相交的（原射线对每个元素访问一次）。因此 $f \circ f$ 恰好有 $2k$
 条射线。由于 $g$ 恰好有 $2$ 条射线，我们得到 $2k = 2$，因此 $k = 1$。

**步骤 6：确定唯一的平方根。**

$f$ 是一条覆盖 $\mathbb{N}$ 的单射线，从某个元素 $a$（$f$ 的像中唯一的缺失元素）
开始。那么 $f \circ f$ 的像中缺失 $a$ 和 $f(a)$，即 $f \circ f$ 的图中的两条射线
分别从 $a$ 和 $f(a)$ 开始。由于 $g$ 的射线从 $0$ 和 $1$ 开始，我们必须满足 $\{a,
\, f(a)\} = \{0,\, 1\}$。

- **情况 1：$a = 0,\ f(a) = 1$。** 射线是 $0, 1, f^2(0), f^3(0), \dots$。我们需
要 $f^2(n) = g(n) = n+2$。因此 $f^2(0) = 2,\ f^2(1) = 3,\ f^2(2) = 4, \dots$，这
给出了射线 $0, 1, 2, 3, 4, 5, \dots$，即 $f_1(n) = n + 1$。

- **情况 2：$a = 1,\ f(a) = 0$。** 射线是 $1, 0, f^2(1), f^3(1), \dots$。我们需
要 $f^2(1) = 3,\ f^2(0) = 2,\ f^2(3) = 5,\ f^2(2) = 4, \dots$，这给出了射线 $1,
0, 3, 2, 5, 4, 7, 6, \dots$，即：
$$f_2(2k) = 2k+3, \qquad f_2(2k+1) = 2k \quad \text{for all } k \ge 0.$$

**验证 $f_2$：** $f_2(f_2(2k)) = f_2(2k+3) = f_2(2(k+1)+1) = 2(k+1) = 2k+2 = g(2
k)$。$f_2(f_2(2k+1)) = f_2(2k) = 2k+3 = g(2k+1)$。两者检验均正确。

这两种情况是仅有的可能性，给出了恰好两个平方根 $f_1$ 和 $f_2$。

**结论。** 函数 $g(n) = n+2$ 满足 $\{f : \mathbb{N} \to \mathbb{N} \mid f \circ
f = g\} = \{f_1, f_2\}$，该集合非空且有限（基数为 $2$）。因此，这样的函数 $g$ 存
在。$\blacksquare$
