# Solution: General Coprime Integer Solutions of $x^2 + y^2 = z^3$

## Setup and Preliminary Observations

We seek all integer triples $(x, y, z)$ with $\gcd(x, y, z) = 1$ satisfying $x^2
 + y^2 = z^3$.

**Parity constraint.** Since $\gcd(x,y,z)=1$, we cannot have $2 \mid x$ and $2 \
mid y$ simultaneously (else $4 \mid x^2+y^2 = z^3$ forces $2 \mid z$, contradict
ing coprimality). If both $x, y$ are odd, then $x^2 + y^2 \equiv 2 \pmod{4}$, bu
t cubes modulo 4 are $\{0, 1, 3\}$ — contradiction. Hence **$x$ and $y$ have dif
ferent parity**, and $z = (x^2+y^2)^{1/3}$ is odd (since $x^2+y^2 \equiv 1 \pmod
 4$). Also $z > 0$ since $z^3 = x^2+y^2 \geq 0$ and $z=0$ forces $x=y=0$.

## Proof via Gaussian Integers

Work in $\mathbb{Z}[i]$, which is a UFD. Factor:
$$x^2 + y^2 = (x + iy)(x - iy) = z^3.$$

**Claim:** $\gcd(x+iy,\; x-iy)$ is a unit in $\mathbb{Z}[i]$.

Any common divisor $\delta$ divides $(x+iy)+(x-iy)=2x$ and $(x+iy)-(x-iy)=2iy$.
Since $\gcd(x,y)=1$ (which follows from $\gcd(x,y,z)=1$: if $p \mid x,y$ then $p
^2 \mid z^3$ so $p \mid z$), the only possible prime factor of $\delta$ is $1+i$
 (the prime above 2). But $(1+i) \mid (x+iy)$ iff $x \equiv y \pmod{2}$, which f
ails since $x, y$ have different parity. Hence $\delta$ is a unit. ✓

Since $x+iy$ and $x-iy$ are coprime and their product is $z^3$, each factor is a
 unit times a cube in $\mathbb{Z}[i]$:
$$x + iy = \varepsilon \cdot (a + bi)^3, \qquad \varepsilon \in \{1, -1, i, -i\}
.$$

**Every unit is itself a cube** in $\mathbb{Z}[i]$: $1 = 1^3$, $-1 = (-1)^3$, $i
 = (-i)^3$, $-i = i^3$. Therefore we can absorb $\varepsilon$ into the cube, wri
ting:
$$x + iy = (a + bi)^3$$
for some $a, b \in \mathbb{Z}$.

## Expanding the Parametrization

$$(a+bi)^3 = (a^3 - 3ab^2) + (3a^2 b - b^3)\,i.$$

Reading off real and imaginary parts:

$$\boxed{x = a(a^2 - 3b^2), \qquad y = b(3a^2 - b^2), \qquad z = a^2 + b^2.}$$

## Coprimality Conditions

We need $\gcd(x, y, z) = 1$.

**Necessary:** If $d = \gcd(a, b) > 1$, then $d^3 \mid x$, $d^3 \mid y$, $d^2 \m
id z$, so $d \mid \gcd(x,y,z)$. Hence $\gcd(a, b) = 1$ is necessary.

**Parity:** $z = a^2 + b^2$ must be odd (shown above), so $a$ and $b$ must have
**different parity**.

**Sufficient:** Suppose $\gcd(a,b) = 1$ and $a, b$ have different parity. We ver
ify $\gcd(x, y) = 1$:

- $z = a^2 + b^2$ is odd, so $2 \nmid \gcd(x,y,z)$.
- For an odd prime $p \mid x$ and $p \mid y$:
  - $p \mid a$ and $p \mid b$: impossible ($\gcd(a,b)=1$).
  - $p \mid a$ and $p \mid (3a^2 - b^2)$: then $p \mid b^2$, so $p \mid b$. ✗
  - $p \mid (a^2 - 3b^2)$ and $p \mid b$: then $p \mid a^2$, so $p \mid a$. ✗
  - $p \mid (a^2 - 3b^2)$ and $p \mid (3a^2 - b^2)$: then $p \mid \bigl[3(a^2-3b
^2) - (3a^2-b^2)\bigr] = -8b^2$, so $p \mid b$ (since $p$ odd), hence $p \mid a$
. ✗

All cases are contradictory, so $\gcd(x, y) = 1$, and since $z = a^2+b^2$ shares
 no odd prime with both $x$ and $y$ (any such prime would divide $a$ and $b$), w
e get $\gcd(x, y, z) = 1$. ✓

## Completeness

Every primitive solution arises this way: we showed any solution with $\gcd(x,y,
z)=1$ must have $x+iy = (a+bi)^3$ for some $a, b \in \mathbb{Z}$ with $\gcd(a,b)
=1$ and $a \not\equiv b \pmod{2}$. Conversely, every such $(a, b)$ produces a pr
imitive solution. The parametrization also captures all sign changes and the swa
p $(x,y) \leftrightarrow (y,x)$ via substitutions like $(a,b) \to (-a,-b)$ (nega
tes $x,y$) and $(a,b) \to (-b,-a)$ (swaps $x,y$).

## Verification

- $a=2, b=1$: $x = 2(4-3) = 2$, $y = 1(12-1) = 11$, $z = 5$. Check: $4 + 121 = 1
25 = 5^3$. ✓
- $a=1, b=0$: $x = 1$, $y = 0$, $z = 1$. Check: $1 + 0 = 1 = 1^3$. ✓
- $a=0, b=1$: $x = 0$, $y = -1$, $z = 1$. Check: $0 + 1 = 1 = 1^3$. ✓
- $a=3, b=2$: $x = 3(9-12) = -9$, $y = 2(27-4) = 46$, $z = 13$. Check: $81 + 211
6 = 2197 = 13^3$. ✓

## Conclusion

The general coprime integer solution of $x^2 + y^2 = z^3$ is:

$$x = a(a^2 - 3b^2), \quad y = b(3a^2 - b^2), \quad z = a^2 + b^2,$$

where $a, b \in \mathbb{Z}$ range over all pairs with $\gcd(a, b) = 1$ and $a \n
ot\equiv b \pmod{2}$ (one even, one odd).
