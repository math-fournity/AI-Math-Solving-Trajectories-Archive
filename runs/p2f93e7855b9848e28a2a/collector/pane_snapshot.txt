# Solution

We evaluate the Lebesgue integral $\int_{[0,1]} f\,d\mu$.

## Key fact: the Cantor set has measure zero

The Cantor set $C$ is constructed by repeatedly removing middle thirds. After $n
$ steps, the remaining set has measure $(2/3)^n \to 0$. Hence
$$\mu(C) = 0.$$

## Reducing the integral

The function $f$ is defined piecewise:
- $f(x) = \sin \pi x$ on $[0,1/2]\setminus C$,
- $f(x) = \cos \pi x$ on $(1/2,1]\setminus C$,
- $f(x) = x^2$ on $C$.

Since $\mu(C)=0$, the contribution of the third piece vanishes:
$$\int_C x^2\,d\mu = 0.$$

Moreover, removing the null set $C$ from the other two intervals does not change
 the Lebesgue integral. Therefore
$$\int_{[0,1]} f\,d\mu = \int_0^{1/2} \sin \pi x\,dx + \int_{1/2}^{1} \cos \pi x
\,dx.$$

## Computing the two integrals

**First integral:**
$$\int_0^{1/2} \sin \pi x\,dx = \left[-\frac{\cos \pi x}{\pi}\right]_0^{1/2} = -
\frac{\cos(\pi/2)}{\pi} + \frac{\cos 0}{\pi} = -\frac{0}{\pi} + \frac{1}{\pi} =
\frac{1}{\pi}.$$

**Second integral:**
$$\int_{1/2}^{1} \cos \pi x\,dx = \left[\frac{\sin \pi x}{\pi}\right]_{1/2}^{1}
= \frac{\sin \pi}{\pi} - \frac{\sin(\pi/2)}{\pi} = \frac{0}{\pi} - \frac{1}{\pi}
 = -\frac{1}{\pi}.$$

## Combining

$$\int_{[0,1]} f\,d\mu = \frac{1}{\pi} + \left(-\frac{1}{\pi}\right) = 0.$$

## Conclusion

$$\boxed{\int_{[0,1]} f\,d\mu = 0}$$

The value of the integral is $0$. The Cantor set contributes nothing (being a nu
ll set), and the two Riemann integrals over $[0,1/2]$ and $[1/2,1]$ cancel exact
ly: $\sin\pi x$ integrates to $1/\pi$ on $[0,1/2]$, while $\cos\pi x$ integrates
 to $-1/\pi$ on $[1/2,1]$.
