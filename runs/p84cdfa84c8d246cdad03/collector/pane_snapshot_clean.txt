## Solution

We solve the initial value problem

$$u_x^2\, u_t - 1 = 0, \qquad u(x,0) = x.$$

**Step 1. Rewrite and identify the Hamiltonian.** The PDE is

$$F(x,t,u,p,q) = p^2 q - 1 = 0, \qquad p := u_x,\quad q := u_t,$$

so $q = 1/p^2$ wherever $p \neq 0$.

**Step 2. Charpit's characteristic equations.** For a first-order PDE $F(x,t,u,p
,q)=0$ with no explicit dependence on $x,t,u$, the characteristic system is

$$\frac{dx}{ds} = F_p = 2pq, \qquad \frac{dt}{ds} = F_q = p^2, \qquad \frac{du}{
ds} = pF_p + qF_q, \qquad \frac{dp}{ds} = -F_x - pF_u, \qquad \frac{dq}{ds} = -F
_t - qF_u.$$

Since $F$ is independent of $x,t,u$, we have $F_x=F_t=F_u=0$, hence

$$\frac{dp}{ds} = 0, \qquad \frac{dq}{ds} = 0.$$

So **$p$ and $q$ are constant along each characteristic curve**.

**Step 3. Use the initial condition to fix $p,q$.** On the initial curve $t=0$ w
e have $u(x,0)=x$, so

$$p\big|_{t=0} = u_x(x,0) = 1.$$

The PDE constraint $p^2 q = 1$ then gives

$$q\big|_{t=0} = \frac{1}{p^2}\Big|_{t=0} = 1.$$

Since $p,q$ are constant along characteristics, **every characteristic emanating
 from the initial line carries $p=1$ and $q=1$**.

**Step 4. Integrate the remaining characteristic equations.** With $p=q=1$:

$$\frac{dt}{ds} = p^2 = 1 \;\Rightarrow\; t = s \quad (\text{taking } s=0 \text{
 at } t=0),$$

$$\frac{dx}{ds} = 2pq = 2 \;\Rightarrow\; x = x_0 + 2s = x_0 + 2t,$$

$$\frac{du}{ds} = p(2pq) + q(p^2) = 2p^2 q + p^2 q = 3p^2 q = 3 \;\Rightarrow\;
u = u_0 + 3s = x_0 + 3t,$$

where $u_0 = u(x_0,0) = x_0$.

**Step 5. Eliminate the parameter $x_0$.** From $x = x_0 + 2t$ we get $x_0 = x -
 2t$. Substituting,

$$u(x,t) = x_0 + 3t = (x - 2t) + 3t = x + t.$$

**Step 6. Verification.** For $u(x,t) = x + t$:

- $u_x = 1$, $u_t = 1$, so $u_x^2 u_t - 1 = 1\cdot 1 - 1 = 0$. ✓
- $u(x,0) = x$. ✓

The solution is unique in the classical sense near the initial line because the
initial curve is non-characteristic: the characteristic direction $(dx/ds, dt/ds
) = (2,1)$ is nowhere tangent to the initial line $t=0$ (which has direction $(1
,0)$).

## Result

$$\boxed{u(x,t) = x + t}$$
