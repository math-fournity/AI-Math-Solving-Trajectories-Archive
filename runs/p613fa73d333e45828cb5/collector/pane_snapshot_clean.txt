## Solution

Let $f(x) = x^{20} - 7x^3 + 1 = \prod_{i=1}^{20}(x - r_i)$, so $\dfrac{f'(x)}{f(
x)} = \sum_{i=1}^{20}\dfrac{1}{x - r_i}$.

**Partial fractions.** Since $\dfrac{1}{r_i^2+1} = \dfrac{1}{(r_i-i)(r_i+i)} = \
dfrac{1}{2i}\!\left(\dfrac{1}{r_i-i} - \dfrac{1}{r_i+i}\right)$, summing over $i
$:

$$\sum_{i=1}^{20}\frac{1}{r_i^2+1} = \frac{1}{2i}\!\left(\sum\frac{1}{r_i-i} - \
sum\frac{1}{r_i+i}\right) = \frac{1}{2i}\!\left(-\frac{f'(i)}{f(i)} + \frac{f'(-
i)}{f(-i)}\right) = \frac{1}{2i}\!\left(\frac{f'(-i)}{f(-i)} - \frac{f'(i)}{f(i)
}\right).$$

**Evaluate at $x = i$.** With $f'(x) = 20x^{19} - 21x^2$:
- $i^{20} = 1$, $i^3 = -i$, so $f(i) = 1 - 7(-i) + 1 = 2 + 7i$.
- $i^{19} = i^{16}\cdot i^3 = -i$, $i^2 = -1$, so $f'(i) = 20(-i) - 21(-1) = 21
- 20i$.

**Evaluate at $x = -i$.**
- $(-i)^{20} = 1$, $(-i)^3 = i$, so $f(-i) = 1 - 7i + 1 = 2 - 7i$.
- $(-i)^{19} = i$, $(-i)^2 = -1$, so $f'(-i) = 20i - 21(-1) = 21 + 20i$.

**Compute the logarithmic derivatives.**

$$\frac{f'(i)}{f(i)} = \frac{21-20i}{2+7i}\cdot\frac{2-7i}{2-7i} = \frac{(21-20i
)(2-7i)}{53} = \frac{42 - 187i + 140i^2}{53} = \frac{-98 - 187i}{53}.$$

$$\frac{f'(-i)}{f(-i)} = \frac{21+20i}{2-7i}\cdot\frac{2+7i}{2+7i} = \frac{(21+2
0i)(2+7i)}{53} = \frac{42 + 187i + 140i^2}{53} = \frac{-98 + 187i}{53}.$$

**Take the difference.**

$$\frac{f'(-i)}{f(-i)} - \frac{f'(i)}{f(i)} = \frac{(-98+187i) - (-98-187i)}{53}
 = \frac{374i}{53}.$$

**Final sum.**

$$\sum_{i=1}^{20}\frac{1}{r_i^2+1} = \frac{1}{2i}\cdot\frac{374i}{53} = \frac{37
4}{106} = \frac{187}{53}.$$

**Coprimality.** $\gcd(187, 53)$: $187 = 3\cdot 53 + 28$, $53 = 1\cdot 28 + 25$,
 $28 = 1\cdot 25 + 3$, $25 = 8\cdot 3 + 1$, so $\gcd = 1$. Thus $m = 187$, $n =
53$.

$$m + n = 187 + 53 = \boxed{240}.$$
