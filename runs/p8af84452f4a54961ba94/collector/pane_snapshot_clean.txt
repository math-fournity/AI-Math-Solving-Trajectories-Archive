Looking at this problem, I need to find all functions $f: \mathbb{Z} \to \{1, \l
dots, 1000\}$ satisfying $\gcd(f(x), f(y)) = \gcd(f(x), x-y)$ for all integers $
x, y$.

## Proof

**Step 1: Prime-by-prime decomposition.**

The gcd condition is equivalent to: for every prime $p$,
$$\min(v_p(f(x)),\, v_p(f(y))) = \min(v_p(f(x)),\, v_p(x - y)) \quad \text{for a
ll } x, y.$$

Setting $a_p(x) = v_p(f(x))$, the condition for prime $p$ is:
$$\min(a_p(x),\, a_p(y)) = \min(a_p(x),\, v_p(x - y)) \quad \text{for all } x, y
. \tag{$\star$}$$

Since gcd is determined by prime valuations, the conditions for different primes
 are independent.

**Step 2: Characterize solutions for a single prime.**

Let $m_p = \max_{x \in \mathbb{Z}} a_p(x)$ (finite since $f(x) \leq 1000$).

**Case $m_p = 0$:** Then $a_p \equiv 0$, which trivially satisfies ($\star$). On
e solution, no parameters.

**Case $m_p \geq 1$:** Pick $x_0$ with $a_p(x_0) = m_p$. From ($\star$) with thi
s $x_0$:
- If $v_p(x_0 - y) \geq m_p$: the RHS is $\min(m_p, v_p(x_0-y)) = m_p$, so $\min
(m_p, a_p(y)) = m_p$, giving $a_p(y) \geq m_p$, hence $a_p(y) = m_p$.
- If $v_p(x_0 - y) = t < m_p$: the RHS is $t$, so $\min(m_p, a_p(y)) = t$, givin
g $a_p(y) = t$.

Therefore $a_p(y) = \min(v_p(x_0 - y),\, m_p)$ for all $y$.

**Verification:** With $u = v_p(x_0 - x)$, $w = v_p(x_0 - y)$, $t = v_p(x - y)$:
- If $u \neq w$: then $t = \min(u,w)$ (ultrametric), and both sides of ($\star$)
 equal $\min(u, w, m_p)$.
- If $u = w$: then $t \geq u$, and both sides equal $\min(u, m_p)$.

So ($\star$) is satisfied. ✓

**Uniqueness of parameters:** $m_p$ is determined as the maximum. The residue $r
_p = x_0 \pmod{p^{m_p}}$ is determined because for $k < m_p$, the set $\{y : a_p
(y) = k\} = \{y : v_p(x_0 - y) = k\}$ pins down $x_0 \pmod{p^{k+1}}$ for all $k
< m_p$, hence $x_0 \pmod{p^{m_p}}$. Different residues mod $p^{m_p}$ give differ
ent functions. There are $p^{m_p}$ choices.

**Step 3: Combine across primes.**

For each prime $p$, choose $m_p \geq 0$ and (if $m_p \geq 1$) a residue $r_p \in
 \mathbb{Z}/p^{m_p}\mathbb{Z}$. Define:
$$f(x) = \prod_p p^{\min(v_p(x - r_p),\, m_p)}.$$

The maximum of $f$ is $\prod_p p^{m_p}$, achieved at any $x$ satisfying $x \equi
v r_p \pmod{p^{m_p}}$ for all $p$ (exists by CRT). The constraint $f(x) \leq 100
0$ for all $x$ is equivalent to:
$$N := \prod_p p^{m_p} \leq 1000.$$

**Step 4: Count.**

Each valid positive integer $N \leq 1000$ uniquely determines the exponents $m_p
$ (via prime factorization), and the number of residue choices is $\prod_{p : m_
p \geq 1} p^{m_p} = N$.

Therefore the total number of interesting functions is:
$$\sum_{N=1}^{1000} N = \frac{1000 \times 1001}{2} = \boxed{500500}.$$
