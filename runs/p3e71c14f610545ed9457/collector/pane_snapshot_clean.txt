Looking at this problem, I need to determine whether an open dense subset $V \su
bset \operatorname{Spec} A$ necessarily has $\dim V = \dim A$, where $A$ is a fi
nite type algebra over a domain $D$.

**Answer: No, $\dim V = \dim A$ does not hold in general.**

## Counterexample

Let $D = A = V_0$, where $V_0$ is a valuation domain of Krull dimension 2. Concr
etely, take $K = k(x,y)$ with the lexicographic valuation $v: K^* \to \mathbb{Z}
^2_{\text{lex}}$ defined by $v(x) = (1,0)$, $v(y) = (0,1)$, and let $V_0 = \{a \
in K : v(a) \geq 0\} \cup \{0\}$.

**$D = V_0$ is a domain** (it is an integral domain, being a valuation ring). **
$A = D$ is a finite type $D$-algebra** (generated by zero elements, i.e., $A = D
$).

**The spectrum of $V_0$.** The value group $\mathbb{Z}^2_{\text{lex}}$ has exact
ly three isolated subgroups: $\{0\}$, $\{0\}\times\mathbb{Z}$, and $\mathbb{Z}^2
$. These correspond to the three prime ideals of $V_0$, forming a chain:
$$(0) \subsetneq \mathfrak{p} \subsetneq \mathfrak{m},$$
so $\dim A = \dim V_0 = 2$.

**Construction of $V$.** Since $\mathfrak{p} \neq (0)$, pick any $f \in \mathfra
k{p} \setminus \{0\}$. Then:
- $f \notin (0)$ (since $f \neq 0$), so $(0) \in D(f)$.
- $f \in \mathfrak{p}$, so $\mathfrak{p} \notin D(f)$.
- $f \in \mathfrak{m}$ (since $\mathfrak{p} \subset \mathfrak{m}$), so $\mathfra
k{m} \notin D(f)$.

Therefore $D(f) = \{(0)\}$. Set $V = \{(0)\}$.

**$V$ is open:** $V = D(f)$ for $f \in \mathfrak{p}\setminus\{0\}$.

**$V$ is dense:** The closure $\overline{V}$ is the smallest closed set containi
ng $(0)$. A closed set $V(I) = \{\mathfrak{q} : I \subseteq \mathfrak{q}\}$ cont
ains $(0)$ iff $I \subseteq (0)$, i.e., $I = (0)$. Thus the only closed set cont
aining $(0)$ is $V(0) = \operatorname{Spec} A$, so $\overline{V} = \operatorname
{Spec} A$.

**Dimension comparison:** $V = \{(0)\}$ is a single point, so $\dim V = 0$. But
$\dim A = 2$. Hence:
$$\dim V = 0 \neq 2 = \dim A.$$

## Remark (Positive result under Noetherianity)

If $D$ is additionally **Noetherian**, then $A$ is Noetherian (finite type over
Noetherian), and $\dim V = \dim A$ **does hold**. The proof: $\operatorname{Spec
} A$ has finitely many irreducible components $V(\mathfrak{p}_i)$ with generic p
oints $\mathfrak{p}_i$ (the minimal primes). Since $V$ is dense, it intersects e
very irreducible component; as each $V(\mathfrak{p}_i) \cap V$ is a non-empty op
en subset of the irreducible set $V(\mathfrak{p}_i)$, it contains the generic po
int $\mathfrak{p}_i$. Thus all minimal primes lie in $V$. Since
$$\dim A = \max_i \dim(A/\mathfrak{p}_i)$$
and each $\mathfrak{p}_i \in V$, we get $\dim V \geq \dim A$, while $\dim V \leq
 \dim A$ is immediate from $V \subseteq \operatorname{Spec} A$.

The key failure in the non-Noetherian case is that $\operatorname{Spec} A$ can h
ave an irreducible component (here, all of $\operatorname{Spec} A$) whose generi
c point $(0)$ is an **open** point, allowing a dense open set of dimension 0 to
exist.
