## Solution

**Answer: Yes, $f$ can have periodic points when $n \ge 2$.** (For $n=1$ it is i
mpossible.) We give an explicit construction for $n=2$ and extend it to all $n\g
e 2$, then explain why $n=1$ is excluded.

### Construction for $n=2$

Define $f:\mathbb{R}^2\to\mathbb{R}^2$ by
$$f(x,y)=\bigl(-x,\; y+1-x^2\bigr).$$

**Smooth and injective.** $f$ is polynomial, hence smooth. If $f(x_1,y_1)=f(x_2,
y_2)$, then $-x_1=-x_2$ gives $x_1=x_2$, and $y_1+1-x_1^2=y_2+1-x_2^2$ gives $y_
1=y_2$. So $f$ is injective.

**Non-vanishing determinant.** The Jacobian is
$$f'(x,y)=\begin{pmatrix}-1&0\\-2x&1\end{pmatrix},\qquad \det f'(x,y)=-1\neq 0\q
uad\forall(x,y).$$

**No fixed points.** A fixed point satisfies $-x=x$ (so $x=0$) and $y+1-x^2=y$ (
so $1-x^2=0$). At $x=0$ this reads $1=0$, a contradiction. Hence $f$ has no fixe
d points.

**Periodic points of period 2.** Compute the second iterate:
$$f^2(x,y)=f(-x,\,y+1-x^2)=\bigl(x,\; y+1-x^2+1-(-x)^2\bigr)=(x,\;y+2-2x^2).$$
Then $f^2(x,y)=(x,y)$ iff $2-2x^2=0$, i.e. $x=\pm 1$. For every $y\in\mathbb{R}$
,
$$f(1,y)=(-1,y),\qquad f(-1,y)=(1,y),$$
so $(1,y)\leftrightarrow(-1,y)$ is a genuine 2-cycle (since $1\neq -1$). Thus $f
$ has periodic points of period $2$.

### Extension to $n\ge 2$

For $n\ge 2$ define
$$f(x_1,x_2,\dots,x_n)=\bigl(-x_1,\; x_2+1-x_1^2,\; x_3,\;\dots,\; x_n\bigr).$$
The Jacobian is lower-triangular with diagonal $(-1,1,1,\dots,1)$, so $\det f'=-
1\neq 0$. Injectivity and the absence of fixed points follow exactly as in the $
n=2$ case (a fixed point forces $x_1=0$ and then $1=0$). The same computation gi
ves $f^2(x)=(x_1,\dots,x_n)$ iff $x_1=\pm 1$, yielding 2-cycles. Hence for every
 $n\ge 2$ such an $f$ exists.

### The case $n=1$ is impossible

Let $f:\mathbb{R}\to\mathbb{R}$ be smooth, injective, with $f'(x)\neq 0$ for all
 $x$, and no fixed points. Since $f'$ is continuous and never zero on the connec
ted set $\mathbb{R}$, either $f'>0$ everywhere or $f'<0$ everywhere.

- **If $f'>0$**: $f$ is strictly increasing. For any $k\ge 1$, if $f^k(x)=x$ the
n in fact $f(x)=x$: indeed $f(x)>x\Rightarrow f^2(x)>f(x)>x\Rightarrow\cdots\Rig
htarrow f^k(x)>x$, and similarly $f(x)<x\Rightarrow f^k(x)<x$. So no periodic po
ints of period $>1$ exist.

- **If $f'<0$**: $f$ is strictly decreasing. Then $h(x)=f(x)-x$ is continuous an
d strictly decreasing. As $x\to-\infty$, $f(x)\to+\infty$ (or a finite limit $L$
, giving $h(x)\to+\infty$), so $h(x)\to+\infty$; as $x\to+\infty$, $h(x)\to-\inf
ty$. By the Intermediate Value Theorem, $h$ has a zero, i.e. $f$ has a fixed poi
nt — contradicting the hypothesis. So this case cannot occur.

Therefore for $n=1$, a fixed-point-free $f$ with $f'\neq 0$ has no periodic poin
ts.

### Conclusion

For $n\ge 2$, the answer is **yes**: the map $f(x_1,x_2,\dots,x_n)=(-x_1,\,x_2+1
-x_1^2,\,x_3,\dots,x_n)$ is smooth, injective, has $\det f'\equiv -1\neq 0$, has
 no fixed points, yet possesses 2-cycles (e.g. every point with $x_1=1$). The ke
y mechanism is that $f$ is *orientation-reversing*, so $f^2$ is orientation-pres
erving and can have fixed points without $f$ itself having any.
