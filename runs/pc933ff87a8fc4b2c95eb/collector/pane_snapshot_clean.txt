## Solution

We determine the norm of the linear functional $\phi: c_0 \to \mathbb{R}$ define
d by
$$\phi(x_n) = \sum_{n=1}^\infty (-2)^{1-n} x_n.$$

**Step 1: Identify the representing sequence.** The functional $\phi$ has the fo
rm $\phi(x) = \sum_{n=1}^\infty a_n x_n$ with coefficients
$$a_n = (-2)^{1-n}.$$

**Step 2: Check boundedness.** The dual of $c_0$ (equipped with the sup norm $\|
x\|_\infty = \sup_n |x_n|$) is isometrically isomorphic to $\ell^1$. A functiona
l of the form $\phi(x) = \sum a_n x_n$ is bounded if and only if $(a_n) \in \ell
^1$, in which case
$$\|\phi\| = \|(a_n)\|_1 = \sum_{n=1}^\infty |a_n|.$$

**Step 3: Compute the $\ell^1$ norm.** We have
$$|a_n| = |(-2)^{1-n}| = 2^{1-n}.$$

Therefore
$$\|\phi\| = \sum_{n=1}^\infty 2^{1-n} = 2^0 + 2^{-1} + 2^{-2} + \cdots = \sum_{
k=0}^\infty \frac{1}{2^k} = \frac{1}{1 - 1/2} = 2.$$

**Step 4: Verify the norm is attained (or approached).** For any $x \in c_0$ wit
h $\|x\|_\infty \le 1$,
$$|\phi(x)| = \left|\sum_{n=1}^\infty a_n x_n\right| \le \sum_{n=1}^\infty |a_n|
\,|x_n| \le \sum_{n=1}^\infty |a_n| = 2,$$
so $\|\phi\| \le 2$.

For the lower bound, define $x^{(N)}$ by $x^{(N)}_n = \operatorname{sgn}(a_n)$ f
or $n \le N$ and $x^{(N)}_n = 0$ for $n > N$. Then $x^{(N)} \in c_0$ with $\|x^{
(N)}\|_\infty = 1$, and
$$\phi(x^{(N)}) = \sum_{n=1}^N a_n \operatorname{sgn}(a_n) = \sum_{n=1}^N |a_n|
= \sum_{n=1}^N 2^{1-n} \to 2 \quad \text{as } N \to \infty.$$

Hence $\|\phi\| \ge 2$, and combined with the upper bound, $\|\phi\| = 2$.

$$\boxed{\|\phi\| = 2}$$
