Looking at this problem, I need to find the maximum number of ordered $n$-tuples
 (of distinct elements from $X$, $|X|=n+1$) such that every pair is "disjoint" —
 meaning for every pair $(a_1,\ldots,a_n)$, $(b_1,\ldots,b_n)$, there exist $i \
neq j$ with $a_i = b_j$.

**Reformulation.** Two distinct tuples are *not* disjoint (i.e., fail the condit
ion) precisely when every element they share appears in the same position. I'll
analyze when this happens:

- **Same $n$-element subset, different tuples:** They are different permutations
 of the same set, so some element occupies different positions — giving a cross-
position match. They are always disjoint. ✓

- **Different subsets** (each omits a different element, sharing $n-1$ elements)
: They are *not* disjoint iff all $n-1$ shared elements sit in identical positio
ns, i.e., the tuples **differ in exactly one position**.

So the "not-disjoint" graph $G$ has vertices = all $(n+1)!$ tuples, with edges j
oining tuples that differ in exactly one position.

**$G$ is bipartite.** For a tuple $T=(a_1,\ldots,a_n)$ omitting element $p$, for
m the full permutation $\pi_T = (a_1,\ldots,a_n,p)$ of $X$. Changing position $k
$ swaps the entries at positions $k$ and $n+1$ in $\pi_T$ — a transposition — wh
ich flips the parity. So every edge connects opposite parities. Hence $G$ is bip
artite with parts $A$ (even permutations) and $B$ (odd permutations).

**$G$ is $n$-regular.** Each tuple has exactly $n$ neighbors (one for each posit
ion we can change). Since $G$ is regular and bipartite, $|A|=|B|=(n+1)!/2$.

**$G$ has a perfect matching.** A regular bipartite graph satisfies Hall's condi
tion (each part has the same size and every subset $S$ of one part has $|N(S)| \
geq |S|$ by counting edges: $n|S| \leq n|N(S)|$). So a perfect matching exists.

**Independence number.** By König's theorem, $\alpha(G) = |V| - \nu(G)$, where $
\nu(G)$ is the maximum matching size. Since a perfect matching exists, $\nu(G) =
 |V|/2 = (n+1)!/2$, giving:

$$\alpha(G) = (n+1)! - \frac{(n+1)!}{2} = \frac{(n+1)!}{2}.$$

**Construction achieving the bound.** Take all tuples whose associated permutati
on $\pi_T$ is even (part $A$). Within $A$, no two tuples are adjacent in $G$, so
 no two are "not disjoint" — every pair is disjoint. This gives $(n+1)!/2$ pairw
ise disjoint tuples.

**Verification for $n=2$:** $|X|=3$, giving $6$ tuples forming a $6$-cycle (each
 tuple has degree $2$). The independence number of $C_6$ is $3 = 3!/2$. ✓

The maximal number of pairwise disjoint $n$-tuples is:

$$\boxed{\dfrac{(n+1)!}{2}}$$
