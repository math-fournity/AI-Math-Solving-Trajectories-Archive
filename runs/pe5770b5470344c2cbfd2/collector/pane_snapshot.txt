## Proof

We determine the asymptotic behavior of $a_n$ and then apply a comparison test.

### Step 1: $a_n \to 0$

Since $a_1 = 1 > 0$ and $\arctan(x) > 0$ for $x > 0$, by induction $a_n > 0$ for
 all $n$. For $x > 0$ we have $\arctan(x) < x$, so
$$a_{n+1} = \frac{\arctan(a_n^2)}{a_n} < \frac{a_n^2}{a_n} = a_n.$$
Thus $\{a_n\}$ is strictly decreasing and bounded below by $0$, hence converges
to some $L \ge 0$. If $L > 0$, taking limits in the recurrence gives $L = \arcta
n(L^2)/L$, i.e., $L^2 = \arctan(L^2)$, contradicting $\arctan(x) < x$ for $x > 0
$. Therefore $L = 0$.

### Step 2: Asymptotic expansion of the recurrence

Using $\arctan(x) = x - \frac{x^3}{3} + O(x^5)$ as $x \to 0$:
$$\arctan(a_n^2) = a_n^2 - \frac{a_n^6}{3} + O(a_n^{10}),$$
$$a_{n+1} = \frac{\arctan(a_n^2)}{a_n} = a_n - \frac{a_n^5}{3} + O(a_n^9). \tag{
1}$$

### Step 3: Rate of decay via $b_n = a_n^{-4}$

Set $b_n = a_n^{-4}$. From (1),
$$a_{n+1} = a_n\!\left(1 - \frac{a_n^4}{3} + O(a_n^8)\right),$$
so
$$b_{n+1} = a_{n+1}^{-4} = a_n^{-4}\!\left(1 - \frac{a_n^4}{3} + O(a_n^8)\right)
^{-4}.$$

Using $(1-u)^{-4} = 1 + 4u + O(u^2)$ for $u \to 0$ with $u = \frac{a_n^4}{3} + O
(a_n^8)$:
$$b_{n+1} = a_n^{-4}\!\left(1 + \frac{4a_n^4}{3} + O(a_n^8)\right) = b_n + \frac
{4}{3} + O(a_n^4).$$

Since $a_n \to 0$, the error term $O(a_n^4) \to 0$, hence
$$\lim_{n\to\infty}(b_{n+1} - b_n) = \frac{4}{3}.$$

By the Stolz–Cesàro theorem (or the elementary fact that if $b_{n+1}-b_n \to c$
then $b_n/n \to c$):
$$\lim_{n\to\infty} \frac{b_n}{n} = \frac{4}{3}, \qquad\text{i.e.,}\qquad \lim_{
n\to\infty} \frac{a_n^{-4}}{n} = \frac{4}{3}.$$

Therefore
$$a_n \sim \left(\frac{3}{4n}\right)^{1/4}, \qquad n\to\infty. \tag{2}$$

### Step 4: Convergence of $\sum a_n^\ell$

From (2),
$$a_n^\ell \sim \left(\frac{3}{4}\right)^{\ell/4} n^{-\ell/4}.$$

By the limit comparison test, $\sum_{n=1}^\infty a_n^\ell$ converges if and only
 if $\sum_{n=1}^\infty n^{-\ell/4}$ converges. The $p$-series $\sum n^{-p}$ conv
erges iff $p > 1$, so we need
$$\frac{\ell}{4} > 1 \iff \ell > 4.$$

At the boundary $\ell = 4$: $a_n^4 \sim \frac{3}{4n}$, so $\sum a_n^4$ diverges
(harmonic series). For $\ell < 4$, $\ell/4 \le 1$ and the series diverges as wel
l.

### Conclusion

The sum $\displaystyle\sum_{i=1}^{\infty} a_i^{\ell}$ converges if and only if $
\ell > 4$.
