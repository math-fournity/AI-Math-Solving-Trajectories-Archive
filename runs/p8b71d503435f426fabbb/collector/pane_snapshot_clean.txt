## Solution

**Step 1: Symmetry.** The integrand $f(x) = \frac{x^2}{(x^4+4)^2}$ is even, so
$$I = \frac{1}{2}\int_{-\infty}^{\infty}\frac{x^2\,dx}{(x^4+4)^2}.$$

**Step 2: Locate the poles.** The poles of $f(z)=\frac{z^2}{(z^4+4)^2}$ are the
roots of $z^4+4=0$, i.e. $z^4=-4=4e^{i\pi}$, giving
$$z_k = \sqrt{2}\,e^{i(\pi+2k\pi)/4},\quad k=0,1,2,3.$$
Explicitly:
- $a = 1+i$ (upper half-plane, UHP)
- $b = -1+i$ (UHP)
- $c = \bar a = 1-i$ (lower half-plane)
- $d = \bar b = -1-i$ (lower half-plane)

Each is a **double pole** since $z^4+4 = (z-a)(z-b)(z-c)(z-d)$.

**Step 3: Residue formula for a double pole.** Write
$$f(z) = \frac{z^2}{(z-a)^2\,D(z)},\qquad D(z)=(z-b)^2(z-c)^2(z-d)^2.$$
The residue at $a$ is
$$\operatorname{Res}_{z=a} f = \left.\frac{d}{dz}\frac{z^2}{D(z)}\right|_{z=a} =
 \frac{N'(a)D(a)-N(a)D'(a)}{D(a)^2},$$
with $N(z)=z^2$. Using $D'(a)/D(a) = \frac{2}{a-b}+\frac{2}{a-c}+\frac{2}{a-d}$,
 this becomes
$$\operatorname{Res}_{z=a} f = \frac{N'(a)-N(a)\!\left[\tfrac{2}{a-b}+\tfrac{2}{
a-c}+\tfrac{2}{a-d}\right]}{D(a)}.$$

**Step 4: Compute $\operatorname{Res}_{z=a} f$.** With $a=1+i,\; b=-1+i,\; c=1-i
,\; d=-1-i$:
- $a-b=2,\quad a-c=2i,\quad a-d=2(1+i)$.
- $\dfrac{2}{a-b}+\dfrac{2}{a-c}+\dfrac{2}{a-d} = 1 + (-i) + \dfrac{1-i}{2} = \d
frac{3}{2}(1-i)$.
- $N(a)=a^2=2i,\quad N'(a)=2a=2+2i$.
- Numerator: $(2+2i) - (2i)\cdot\tfrac{3}{2}(1-i) = (2+2i)-(3+3i) = -1-i$.
- $D(a) = (a-b)^2(a-c)^2(a-d)^2 = 4\cdot(-4)\cdot 8i = -128i$.

$$\operatorname{Res}_{z=a} f = \frac{-1-i}{-128i} = \frac{1+i}{128i} = \frac{1-i
}{128}.$$

**Step 5: Compute $\operatorname{Res}_{z=b} f$.** With $b=-1+i$:
- $b-a=-2,\quad b-c=-2+2i,\quad b-d=2i$.
- $\dfrac{2}{b-a}+\dfrac{2}{b-c}+\dfrac{2}{b-d} = -1 - \dfrac{1+i}{2} - i = -\df
rac{3}{2}(1+i)$.
- $N(b)=b^2=-2i,\quad N'(b)=2b=-2+2i$.
- Numerator: $(-2+2i) - (-2i)\!\left[-\tfrac{3}{2}(1+i)\right] = (-2+2i)-(-3+3i)
 = 1-i$.
- $D(b) = (-2)^2(-2+2i)^2(2i)^2 = 4\cdot(-8i)\cdot(-4) = 128i$.

$$\operatorname{Res}_{z=b} f = \frac{1-i}{128i} = \frac{-(1+i)}{128}.$$

**Step 6: Sum residues and apply the theorem.**
$$\sum_{\text{UHP}} \operatorname{Res} = \frac{1-i}{128} + \frac{-(1+i)}{128} =
\frac{-2i}{128} = \frac{-i}{64}.$$

Closing the contour in the upper half-plane (the arc contribution vanishes since
 $|f(z)|=O(|z|^{-6})$):
$$\int_{-\infty}^{\infty}\frac{x^2\,dx}{(x^4+4)^2} = 2\pi i\cdot\frac{-i}{64} =
\frac{2\pi}{64} = \frac{\pi}{32}.$$

**Step 7: Final result.**
$$I = \frac{1}{2}\cdot\frac{\pi}{32} = \boxed{\dfrac{\pi}{64}}.$$
