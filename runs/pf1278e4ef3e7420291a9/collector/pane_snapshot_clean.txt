**Theorem.** Every infinite set $A$ can be partitioned into two disjoint subsets
 $B$ and $C$ with $B \cup C = A$, $B \cap C = \emptyset$, and $|B| = |C| = |A|$.

**Answer: Yes** (assuming the Axiom of Choice, via the Well-Ordering Theorem).

---

### Proof

By the Well-Ordering Theorem (equivalent to the Axiom of Choice), every set can
be well-ordered. Let $A$ be an infinite set; well-order it so that $|A| = \aleph
_\alpha$ for some ordinal $\alpha$, identifying $A$ with the initial ordinal $\o
mega_\alpha$.

The proof rests on a standard lemma.

**Lemma.** For every infinite cardinal $\kappa$, $\kappa \times \kappa \sim \kap
pa$ (there is a bijection).

*Proof of Lemma.* By transfinite induction on $\alpha$ with $\kappa = \aleph_\al
pha$.

**Base case** $\alpha = 0$: $\aleph_0 \times \aleph_0 \sim \aleph_0$ by Cantor's
 pairing function (the standard enumeration of $\mathbb{N} \times \mathbb{N}$ al
ong diagonals of constant $\max$).

**Inductive step.** Assume for all $\beta < \alpha$ that $\aleph_\beta \times \a
leph_\beta \sim \aleph_\beta$. We show $\aleph_\alpha \times \aleph_\alpha \sim
\aleph_\alpha$.

Define a well-ordering $\prec$ on $\omega_\alpha \times \omega_\alpha$ by:
$$(\gamma_1, \gamma_2) \prec (\gamma_1', \gamma_2') \iff \begin{cases} \max(\gam
ma_1,\gamma_2) < \max(\gamma_1',\gamma_2'), \text{ or} \\ \max\text{'s equal and
 } \gamma_1 < \gamma_1', \text{ or} \\ \max\text{ and } \gamma_1 \text{ equal an
d } \gamma_2 < \gamma_2'. \end{cases}$$

For any $(\gamma_1, \gamma_2) \in \omega_\alpha \times \omega_\alpha$, set $\del
ta = \max(\gamma_1, \gamma_2) < \omega_\alpha$. Since $\omega_\alpha$ is an init
ial ordinal, $|\delta| < \aleph_\alpha$, so $|\delta| = \aleph_\beta$ for some $
\beta < \alpha$ (or $|\delta|$ is finite). The set of $\prec$-predecessors of $(
\gamma_1,\gamma_2)$ is contained in $(\delta+1) \times (\delta+1)$, which has ca
rdinality $\leq |\delta+1|^2$. By the induction hypothesis (or finiteness), $|\d
elta+1|^2 < \aleph_\alpha$. Thus every proper initial segment of $(\omega_\alpha
 \times \omega_\alpha, \prec)$ has cardinality $< \aleph_\alpha$.

If the order type of $\prec$ were some ordinal $\lambda > \omega_\alpha$, the el
ement at position $\omega_\alpha$ would have an initial segment of cardinality $
\aleph_\alpha$, a contradiction. Hence the order type is $\leq \omega_\alpha$, g
iving $|\omega_\alpha \times \omega_\alpha| \leq \aleph_\alpha$. Since $\omega_\
alpha \times \{0\} \subseteq \omega_\alpha \times \omega_\alpha$ gives $|\omega_
\alpha \times \omega_\alpha| \geq \aleph_\alpha$, we conclude $|\omega_\alpha \t
imes \omega_\alpha| = \aleph_\alpha$. $\square$

**Deriving the partition.** From the Lemma, $\aleph_\alpha \times \aleph_\alpha
\sim \aleph_\alpha$. Since $2 \leq \aleph_\alpha$ (as $A$ is infinite), we have
$$\aleph_\alpha \;\leq\; \aleph_\alpha \times 2 \;\leq\; \aleph_\alpha \times \a
leph_\alpha \;\sim\; \aleph_\alpha,$$
so by the Cantor–Bernstein theorem, $\aleph_\alpha \times 2 \sim \aleph_\alpha$.

Let $f : \omega_\alpha \times \{0,1\} \to \omega_\alpha$ be a bijection. Define
$$B = f\big[\omega_\alpha \times \{0\}\big], \qquad C = f\big[\omega_\alpha \tim
es \{1\}\big].$$

Then:
- $B \cap C = \emptyset$, since $f$ is a bijection and $\{0\} \cap \{1\} = \empt
yset$.
- $B \cup C = f[\omega_\alpha \times \{0,1\}] = \omega_\alpha$ (surjectivity of
$f$).
- $|B| = |\omega_\alpha \times \{0\}| = \aleph_\alpha$ and $|C| = |\omega_\alpha
 \times \{1\}| = \aleph_\alpha$.

Thus $\{B, C\}$ is the desired partition of $\omega_\alpha$. Transporting this p
artition back to $A$ via the well-ordering isomorphism $A \cong \omega_\alpha$ y
ields a partition of $A$ into two disjoint subsets, each of cardinality $|A|$. $
\blacksquare$

**Remark on the Axiom of Choice.** The use of AC is essential. Without AC, it is
 consistent with ZF that there exists an infinite **Dedekind-finite** set — an i
nfinite set not bijective with any proper subset of itself. Such a set cannot be
 split into two parts of equal cardinality: if $A = B \sqcup C$ with $|B| = |A|$
, then $B \subsetneq A$ is bijective with $A$, making $A$ Dedekind-infinite, a c
ontradiction. Hence the theorem may fail in ZF alone.
