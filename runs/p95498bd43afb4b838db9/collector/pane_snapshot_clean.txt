## Proof

We show that **no** function $f: P \to P$ (constant or not) satisfies the stated
 condition, so in particular there are no non-constant functions.

Recall $P = \mathbb{R}\setminus\{\pm 1\}$. Observe that $0 \in P$, since $0 \neq
 1$ and $0 \neq -1$.

Suppose, for contradiction, that a function $f: P \to P$ satisfies
$$f(a)f(b) + f(a)f(c) + f(b)f(c) = -1$$
for all $a,b,c \in P$ with $a+b+c = 0$.

Set $a = b = c = 0$. Then:
- $a, b, c \in P$ (since $0 \in P$),
- $a + b + c = 0 + 0 + 0 = 0$,

so the hypothesis applies, giving
$$f(0)f(0) + f(0)f(0) + f(0)f(0) = -1,$$
that is,
$$3\,f(0)^2 = -1.$$

But $f: P \to P \subseteq \mathbb{R}$, so $f(0)$ is a real number, hence $f(0)^2
 \geq 0$, which forces $3f(0)^2 \geq 0$. This contradicts $3f(0)^2 = -1 < 0$.

The contradiction shows that no function $f: P \to P$ can satisfy the given func
tional equation. Therefore the set of non-constant functions $f: P \to P$ satisf
ying the condition is **empty**.
