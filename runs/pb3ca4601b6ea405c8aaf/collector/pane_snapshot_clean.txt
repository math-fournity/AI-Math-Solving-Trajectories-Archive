## Solution

We seek all $(a, b, c, p)$ with $p$ prime, $c \ge 1$, $1 \le a, b \le 100$, sati
sfying $a^p + b^p = p^c$. The System Index is $p \cdot c$, and $S$ is the set of
 unique indices.

### Case $p = 2$: $a^2 + b^2 = 2^c$

**Parity analysis.** If both $a, b$ odd: $a^2 + b^2 \equiv 2 \pmod{4}$, forcing
$c = 1$, giving $a = b = 1$. If mixed parity: $a^2 + b^2 \equiv 1 \pmod{4}$, imp
ossible for $c \ge 2$ (and $c = 1$ gives $a^2+b^2 = 2$, both odd). If both even:
 write $a = 2a', b = 2b'$, reducing to $a'^2 + b'^2 = 2^{c-2}$.

Iterating the reduction, the only base solution is $a' = b' = 1$ with $c' = 1$.
Scaling back: $a = b = 2^k$, $c = 2k + 1$. The bound $2^k \le 100$ gives $k = 0,
 1, \ldots, 6$ (since $2^6 = 64 \le 100$, $2^7 = 128 > 100$).

**System indices:** $2c \in \{2, 6, 10, 14, 18, 22, 26\}$ (for $c \in \{1, 3, 5,
 7, 9, 11, 13\}$).

### Case $p = 3$: $a^3 + b^3 = 3^c$

If $3 \mid a$ and $3 \mid b$: write $a = 3a', b = 3b'$, reducing to $a'^3 + b'^3
 = 3^{c-3}$. If exactly one is divisible by 3: $a^3 + b^3 \equiv a + b \pmod{3}$
 (Fermat), requiring $3 \mid (a+b)$, which forces $3 \mid b$ if $3 \mid a$—contr
adiction. So either both or neither divisible by 3.

**Base case** ($3 \nmid a, 3 \nmid b$): Since $a + b \mid 3^c$, we have $a + b =
 3^s$. By the Lifting-the-Exponent (LTE) lemma, $v_3(a^3 + b^3) = v_3(a+b) + v_3
(3) = s + 1$, so $c = s + 1$ and $\frac{a^3+b^3}{a+b} = 3$, i.e., $a^2 - ab + b^
2 = 3$.

Substituting $a + b = 3^s$: $ab = 3^{2s-1} - 1$. The discriminant is $3^{2s} - 4
(3^{2s-1} - 1) = 4 - 3^{2s-1}$, which is non-negative only for $s = 1$ (giving d
iscriminant $1$). Then $a + b = 3$, $ab = 2$, so $(a, b) = (1, 2)$ or $(2, 1)$,
with $c = 2$. ✓

**Scaling:** $(a, b) = (3^k, 2 \cdot 3^k)$, $c = 2 + 3k$. The binding constraint
 is $2 \cdot 3^k \le 100$: $k = 0, 1, 2, 3$ (since $2 \cdot 3^3 = 54 \le 100$, $
2 \cdot 3^4 = 162 > 100$).

**System indices:** $3c \in \{6, 15, 24, 33\}$ (for $c \in \{2, 5, 8, 11\}$).

Verification: $27^3 + 54^3 = 19683 + 157464 = 177147 = 3^{11}$. ✓

### Case $p \ge 5$: No solutions

For odd prime $p \ge 5$, the same LTE argument applies: in the base case ($p \nm
id a, p \nmid b$), we need $\frac{a^p + b^p}{a+b} = p$ with $a + b = p^s \ge p$.

By convexity of $x^p$: $a^p + b^p \ge \frac{(a+b)^p}{2^{p-1}}$, so $\frac{a^p+b^
p}{a+b} \ge \frac{(a+b)^{p-1}}{2^{p-1}}$.

For $p = 5$, $a + b \ge 5$: $\frac{5^4}{2^4} = \frac{625}{16} \approx 39 > 5 = p
$. For larger $p$ the bound is even more overwhelming. So $\frac{a^p+b^p}{a+b} >
 p$ always, making the base case impossible. Since the base case has no solution
, scaling (both divisible by $p$) also yields nothing.

### Combining all cases

$$S = \{2, 6, 10, 14, 18, 22, 26\} \cup \{6, 15, 24, 33\} = \{2, 6, 10, 14, 15,
18, 22, 24, 26, 33\}$$

$$\sum_{s \in S} s = 2 + 6 + 10 + 14 + 15 + 18 + 22 + 24 + 26 + 33 = 170$$
