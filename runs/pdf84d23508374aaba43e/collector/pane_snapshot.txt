## Proof

Label the grid:
$$\begin{matrix} a & b & c \\ d & e & f \\ g & h & i \end{matrix}$$
The four $2\times 2$ sums are $a{+}b{+}d{+}e$, $b{+}c{+}e{+}f$, $d{+}e{+}g{+}h$,
 $e{+}f{+}h{+}i$, all equal to $S$.

**Step 1: Derive structural constraints.** Equating adjacent $2\times2$ squares:
- $a{+}b{+}d{+}e = b{+}c{+}e{+}f \Rightarrow a{+}d = c{+}f$ ... (1)
- $a{+}b{+}d{+}e = d{+}e{+}g{+}h \Rightarrow a{+}b = g{+}h$ ... (2)
- $b{+}c{+}e{+}f = e{+}f{+}h{+}i \Rightarrow b{+}c = h{+}i$ ... (3)
- $d{+}e{+}g{+}h = e{+}f{+}h{+}i \Rightarrow d{+}g = f{+}i$ ... (4)

From (1)+(3): $a{+}d{+}b{+}c = c{+}f{+}h{+}i$, i.e. $a{+}b{+}d = f{+}h{+}i$. Fro
m (2)+(4): $a{+}b{+}d{+}g = g{+}h{+}f{+}i$, giving the same relation, so the sys
tem is consistent with 3 independent equations.

**Step 2: Key identity — diagonal corner pairs have equal sum.** From the equati
ons, solving: $f=a{+}d{-}c$, $g=a{+}b{-}h$, $i=a{+}b{+}d{-}f{-}h$. Then
$$a+i = a+(a{+}b{+}d{-}f{-}h), \qquad c+g = (a{+}d{-}f)+(a{+}b{-}h).$$
Both equal $2a{+}b{+}d{-}f{-}h$. Hence
$$a+i = c+g =: P.$$

**Step 3: Express $S$ in terms of $P$ and $e$.** Summing all four $2\times2$ sum
s: the center $e$ appears 4 times, each edge ($b,d,f,h$) appears 2 times, each c
orner ($a,c,g,i$) appears once. So
$$4S = (a{+}c{+}g{+}i) + 2(b{+}d{+}f{+}h) + 4e.$$
Since $a{+}i=c{+}g=P$, the corner sum is $2P$. Also $a{+}b{+}\cdots{+}i = 45$, s
o $b{+}d{+}f{+}h = 45 - 2P - e$. Substituting:
$$4S = 2P + 2(45-2P-e) + 4e = 90 - 2P + 2e,$$
$$\boxed{S = \frac{45 - P + e}{2}}.$$
For $S$ to be an integer, $45-P+e$ must be even, i.e. $P+e$ is odd.

**Step 4: Bound $S$.** The four corners are distinct values in $\{1,\dots,9\}\se
tminus\{e\}$, split into two disjoint pairs each summing to $P$.

*Lower bound.* To minimize $S=(45-P+e)/2$, maximize $P$ and minimize $e$.
- $e=1$: corners from $\{2,\dots,9\}$, $P$ even. The largest $P$ admitting two d
isjoint equal-sum pairs is $P=14$ ($9{+}5=8{+}6$); $P=16$ only gives $9{+}7$ wit
h no second pair. So $S=(45-14+1)/2=16$.
- $e=2$: $P$ odd, max $P=15$ ($9{+}6=8{+}7$), giving $S=16$.
- $e\ge 3$: the minimum $S$ only increases. So $S\ge 16$.

*Upper bound.* To maximize $S$, minimize $P$ and maximize $e$.
- $e=9$: $P$ even, min $P=6$ ($1{+}5=2{+}4$); $P=4$ only gives $1{+}3$. So $S=(4
5-6+9)/2=24$.
- $e=8$: $P$ odd, min $P=5$ ($1{+}4=2{+}3$), giving $S=24$.
- $e\le 7$: max $S\le 23$. So $S\le 24$.

Thus $16 \le S \le 24$.

**Step 5: Every value $S\in\{16,17,\dots,24\}$ is attainable.** We exhibit a gri
d for each (verified: entries are a permutation of $1,\dots,9$ and all four $2\t
imes2$ sums equal $S$):

| $S$ | Grid ($a\,b\,c\,/\,d\,e\,f\,/\,g\,h\,i$) |
|---|---|
| 16 | $9\,4\,8\,/\,2\,1\,3\,/\,6\,7\,5$ |
| 17 | $3\,7\,4\,/\,6\,1\,5\,/\,8\,2\,9$ |
| 18 | $2\,9\,3\,/\,6\,1\,5\,/\,7\,4\,8$ |
| 19 | $1\,9\,3\,/\,7\,2\,5\,/\,6\,4\,8$ |
| 20 | $1\,8\,3\,/\,6\,5\,4\,/\,7\,2\,9$ |
| 21 | $1\,9\,2\,/\,8\,3\,7\,/\,4\,6\,5$ |
| 22 | $2\,4\,3\,/\,9\,7\,8\,/\,5\,1\,6$ |
| 23 | $1\,7\,2\,/\,9\,6\,8\,/\,3\,5\,4$ |
| 24 | $1\,6\,2\,/\,8\,9\,7\,/\,4\,3\,5$ |

Each row was checked directly: the entries form a permutation of $\{1,\dots,9\}$
 and the four $2\times2$ sums coincide.

**Conclusion.** The set of possible values of $S$ is $\{16,17,18,19,20,21,22,23,
24\}$, and their sum is
$$16+17+\cdots+24 = \frac{(16+24)\cdot 9}{2} = 180.$$
