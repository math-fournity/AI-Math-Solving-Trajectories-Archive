## Solution

The statement is **false**. I will provide an explicit counterexample.

**Setup.** Work over the ring $R = \mathbb{Z}$. Consider the short exact sequenc
e of abelian groups

$$0 \longrightarrow \mathbb{Z} \xrightarrow{\;f\;} \mathbb{Z}\oplus\mathbb{Z} \x
rightarrow{\;g\;} \mathbb{Z} \longrightarrow 0,$$

where $f(a) = (a,0)$ and $g(b_1, b_2) = b_2$.

**Verification of exactness.**
- $f$ is injective: if $f(a) = (a,0) = (0,0)$ then $a = 0$.
- $g$ is surjective: for any $c \in \mathbb{Z}$, we have $g(0, c) = c$.
- $\ker(g) = \{(b_1, b_2) : b_2 = 0\} = \mathbb{Z}\oplus 0 = \operatorname{im}(f
)$.

So the sequence is exact.

**Define the two submodules.** Let

$$P = \{(n,\, n) : n \in \mathbb{Z}\}, \qquad Q = \{(2n,\, n) : n \in \mathbb{Z}
\}.$$

Both are submodules (subgroups) of $B = \mathbb{Z}\oplus\mathbb{Z}$.

**Check condition 1: $g(P) = g(Q)$.**

$$g(P) = \{n : n \in \mathbb{Z}\} = \mathbb{Z}, \qquad g(Q) = \{n : n \in \mathb
b{Z}\} = \mathbb{Z}.$$

Hence $g(P) = g(Q) = \mathbb{Z}$. ✓

**Check condition 2: $f^{-1}(P) = f^{-1}(Q)$.**

$$f^{-1}(P) = \{a \in \mathbb{Z} : (a, 0) \in P\} = \{a : \exists\, n,\; a = n \
text{ and } 0 = n\} = \{0\}.$$

$$f^{-1}(Q) = \{a \in \mathbb{Z} : (a, 0) \in Q\} = \{a : \exists\, n,\; a = 2n
\text{ and } 0 = n\} = \{0\}.$$

Hence $f^{-1}(P) = f^{-1}(Q) = \{0\}$. ✓

**Check $P \neq Q$.**

The element $(1, 1) \in P$ (take $n = 1$). But $(1, 1) \notin Q$, since membersh
ip in $Q$ requires the first coordinate to be even ($2n = 1$ has no integer solu
tion). Therefore $P \neq Q$.

**Conclusion.** Both hypotheses $g(P) = g(Q)$ and $f^{-1}(P) = f^{-1}(Q)$ are sa
tisfied, yet $P \neq Q$. The statement is **false**.

**Remark on the underlying reason.** The two conditions pin down (i) how much of
 $\ker(g) = \operatorname{im}(f)$ each submodule captures, and (ii) the image un
der $g$. But they do not pin down the *manner* in which each submodule splits ov
er $\ker(g)$. Both $P$ and $Q$ are complements to $\ker(g)$ in $B$ (i.e., $P \ca
p \ker(g) = Q \cap \ker(g) = 0$ and $g(P) = g(Q) = \mathbb{Z}$), yet they are di
fferent complements — the sequence does not split canonically, and distinct spli
ttings yield distinct submodules with identical kernel-intersection and image da
ta.
