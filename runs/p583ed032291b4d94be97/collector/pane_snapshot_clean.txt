Looking at this problem, I need to determine whether there exists a permutation
of the natural numbers such that for every positive integer $K$, the sum of the
first $K$ terms is divisible by $K$.

## Proof

**Claim:** Such a sequence exists.

**Construction.** We build the sequence $a_1, a_2, a_3, \ldots$ inductively. At
each step we maintain the current position $K$, the partial sum $S = a_1 + \cdot
s + a_{K-1}$, and the set $U$ of unused natural numbers. Let $m = \min(U)$ denot
e the smallest unused number. We distinguish three cases.

**Case 1: $K > m$ and $m \equiv -S \pmod{K}$.** Set $a_K = m$.

**Case 2: $K > m$ and $m \not\equiv -S \pmod{K}$.** We use two steps. First, cho
ose a filler $f$ (any unused number with $f \neq m$) satisfying the simultaneous
 congruences
$$f \equiv -S \pmod{K}, \qquad f \equiv -S - m \pmod{K+1}.$$
Since $\gcd(K, K+1) = 1$, the Chinese Remainder Theorem guarantees a solution mo
dulo $K(K+1)$. The solutions form an infinite arithmetic progression, so we can
always pick an unused $f \neq m$. Set $a_K = f$ and $a_{K+1} = m$.

**Case 3: $K \le m$.** Choose any unused $f \neq m$ with $f \equiv -S \pmod{K}$
(the residue class is infinite, so such $f$ exists). Set $a_K = f$.

**Divisibility verification.**
- *Case 1:* $S + a_K = S + m \equiv S + (-S) = 0 \pmod{K}$. ✓
- *Case 2:* At step $K$: $S + f \equiv S + (-S) = 0 \pmod{K}$. At step $K+1$: $(
S + f) + m \equiv (-S - m) + S + m = 0 \pmod{K+1}$. ✓
- *Case 3:* $S + f \equiv S + (-S) = 0 \pmod{K}$. ✓

**Every number is used.** We show the smallest unused number $m$ is always event
ually placed. At the start of step $K$, we have used $K-1$ distinct numbers. The
 set $\{1, 2, \ldots, K\}$ has $K$ elements, so at least one is unused; hence $m
 \le K$.

- If $K > m$: we are in Case 1 or 2, and $m$ is placed (at step $K$ or $K+1$).
- If $K = m$: we are in Case 3, so we place a filler $f \neq m$ at step $K$. Now
 $K$ advances to $K+1 = m+1 > m$, and at the next step we enter Case 1 or 2, pla
cing $m$.

Thus $m$ is placed within at most 2 steps. After $m$ is placed, the new smallest
 unused number $m' > m$ (since $m$ is now used), and the same argument applies.
Since $m$ strictly increases and is always eventually placed, every natural numb
er appears in the sequence.

**Each number appears exactly once.** We always select unused numbers, so no num
ber is repeated. Since every number is used at least once, each appears exactly
once.

**Conclusion.** The inductively constructed sequence is a permutation of $\mathb
b{N}$ satisfying $K \mid (a_1 + a_2 + \cdots + a_K)$ for every positive integer
$K$. Therefore, such a sequence exists. $\blacksquare$
