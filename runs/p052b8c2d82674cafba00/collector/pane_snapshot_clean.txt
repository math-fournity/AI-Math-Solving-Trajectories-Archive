## Proof

**Claim:** The only natural number n is **n = 2** (with k = 3, {x, y} = {1, 2}).

### Step 1: Even k is impossible (for n ≥ 1)

If k is even, write k = 2r. Then 3^n = (x^r)² + (y^r)². Since 3 | 3^n, we need 3
 | ((x^r)² + (y^r)²). For any integer a, a² ≡ 0 or 1 (mod 3), so a sum of two sq
uares is ≡ 0 (mod 3) only if both squares are ≡ 0 (mod 3). Thus 3 | x^r and 3 |
y^r, hence 3 | x and 3 | y, contradicting gcd(x, y) = 1.

---

### Step 2: Setup for odd k ≥ 3

Since 3 | (x^k + y^k) and gcd(x, y) = 1, neither x nor y is divisible by 3 (if 3
 | x, then x^k + y^k ≡ y^k ≡ y ≢ 0 (mod 3) since k is odd and 3 ∤ y, contradicti
on).

For odd k and 3 ∤ x, 3 ∤ y: x^k ≡ x (mod 3) and y^k ≡ y (mod 3), so 3 | (x + y).

### Step 3: Case 3 ∤ k — no solution

By the **Lifting the Exponent Lemma** (p = 3 odd, 3 | x+y, 3 ∤ xy, k odd):

$$v_3(x^k + y^k) = v_3(x+y) + v_3(k) = v_3(x+y) \quad (\text{since } 3 \nmid k).
$$

Since x^k + y^k = 3^n, we get n = v_3(x+y). Also x+y | x^k+y^k = 3^n, so x+y = 3
^n and Q := (x^k+y^k)/(x+y) = 1, giving **x^k + y^k = x + y**.

- **x, y > 0:** x^k ≥ x (equality iff x=1), y^k ≥ y, so x^k+y^k ≥ x+y with equal

- **y = 0 (wlog):** x^k = x forces x = 1 (k ≥ 3), so x+y = 1 = 3^0, meaning n =
0. Not valid for n ≥ 1.
- **y < 0 < x** (since x+y > 0): write y = −z, z > 0. Then x^k − z^k = x − z, so

x^{k−2}z + ⋯ + z^{k−1} = 1. But this is a sum of k ≥ 3 positive terms (x, z ≥ 1)
, each ≥ 1, so the sum ≥ 3 > 1. **Contradiction.**

No solution when 3 ∤ k.

### Step 4: Case 3 | k — only n = 2 works

Write k = 3m (m odd, m ≥ 1). Set u = x^m, v = y^m. Then:

$$x^k + y^k = u^3 + v^3 = (u+v)(u^2 - uv + v^2) = 3^n.$$

Since gcd(x, y) = 1, we have gcd(u, v) = 1. Both factors are positive (u²−uv+v²
> 0 for (u,v) ≠ (0,0); u+v > 0 since the product is positive). So:

$$u + v = 3^a, \quad u^2 - uv + v^2 = 3^b, \quad a + b = n, \quad a \geq 1.$$

(The same argument as Step 2 gives 3 | (u+v), so a ≥ 1.)

From (u+v)² = 3^{2a} and u²−uv+v² = (u+v)² − 3uv = 3^b, we get:

$$uv = \frac{3^{2a} - 3^b}{3}.$$

For uv to be an integer, b ≥ 1. The discriminant of t² − 3^a·t + uv = 0 (roots u

$$\Delta = 3^{2a} - 4uv = \frac{4 \cdot 3^b - 3^{2a}}{3} = 3^{b-1}(4 - 3^{2a-b})
.$$

For Δ ≥ 0: 3^{2a−b} ≤ 4, so **2a − b ≤ 1**. For 3^{2a−b} to be a positive intege
r: **2a − b ≥ 0**. So 2a − b ∈ {0, 1}.

**Subcase 2a − b = 1** (b = 2a−1): Δ = 3^{2a−2} = (3^{a−1})², a perfect square.
$$\{u, v\} = \left\{\frac{3^a + 3^{a-1}}{2},\, \frac{3^a - 3^{a-1}}{2}\right\} =
 \{2 \cdot 3^{a-1},\; 3^{a-1}\}.$$
$$\gcd(u, v) = 3^{a-1} \cdot \gcd(2, 1) = 3^{a-1}.$$
For gcd = 1: **a = 1**, giving {u, v} = {2, 1}, b = 1, **n = a + b = 2**.

**Subcase 2a − b = 0** (b = 2a): Δ = 3^{2a} = (3^a)², a perfect square.
$$\{u, v\} = \{3^a, 0\}, \quad \gcd(u, v) = 3^a.$$
For gcd = 1: a = 0, but a ≥ 1. **No solution.**

So the unique solution is **n = 2, {u, v} = {1, 2}**.

Now recover x, y from u = x^m, v = y^m:
- x^m = 1 → **x = 1** (m odd, only integer with odd power = 1 is 1).

So **k = 3, {x, y} = {1, 2}, n = 2**.
