## Proof

Let $R$ be a finite ring with $1 \neq 0$, and let $S = \sum_{r \in R} r$ be the
sum of all elements. We seek all such $R$ with $S$ a unit.

### Step 1. Reduction to the $2$-torsion

The additive group $(R,+)$ is a finite abelian group. In any finite abelian grou
p $G$, elements of order $>2$ pair as $\{g,-g\}$ with $g\neq -g$ and cancel in t
he total sum. Hence

$$\sum_{g\in G} g \;=\; \sum_{\substack{g\in G\\ 2g=0}} g.$$

Applying this to $(R,+)$:

$$S = \sum_{\substack{x\in R\\ 2x=0}} x = \sum_{x\in R[2]} x, \qquad R[2]:=\{x\i
n R : 2x=0\}.$$

### Step 2. $R[2]$ is a two-sided ideal

$R[2]$ is an additive subgroup. For any $r\in R$ and $x\in R[2]$: $2(rx)=r(2x)=0
$ and $2(xr)=(2x)r=0$, so $rx,\,xr\in R[2]$. Thus $R[2]$ is a two-sided ideal, a
nd in particular $(R[2],+)$ is an elementary $2$-group, i.e. a vector space over
 $\mathbb{F}_2$. Write $|R[2]|=2^k$.

### Step 3. Computing $S$ via the elementary $2$-group

As an $\mathbb{F}_2$-vector space, $R[2]\cong (\mathbb{F}_2)^k$. The sum of all
$2^k$ elements: in each coordinate, $2^{k-1}$ entries are $1$. The coordinate-su
m is $2^{k-1}\bmod 2$, which is $0$ for $k\ge 2$ and $1$ for $k=1$. Therefore:

| $k$ | $|R[2]|$ | $S$ |
|-----|----------|-----|
| $0$ | $1$ | $0$ |
| $1$ | $2$ | $a$ (the unique nonzero element of $R[2]$) |
| $\ge 2$ | $\ge 4$ | $0$ |

For $S$ to be a unit, we need $k=1$ and the unique nonzero element $a\in R[2]$ t
o be invertible.

### Step 4. The invertibility condition forces $\operatorname{char}(R)=2$

Suppose $k=1$ and $a$ is a unit. Since $2a=0$, multiply on the right by $a^{-1}$
:

$$2\cdot 1 = 2(a\,a^{-1}) = (2a)\,a^{-1} = 0.$$

So $\operatorname{char}(R)\mid 2$. Since $R$ is non-trivial ($1\neq 0$), $\opera
torname{char}(R)=2$.

### Step 5. $\operatorname{char}(R)=2$ forces $|R|=2$

If $\operatorname{char}(R)=2$, then $2x=0$ for **every** $x\in R$, so $R[2]=R$.
But we need $|R[2]|=2$, hence $|R|=2$.

### Step 6. The unique ring of order $2$

Up to isomorphism the only ring with $1$ of order $2$ is $\mathbb{F}_2=\mathbb{Z
}/2\mathbb{Z}$. Verification:

$$S = 0 + 1 = 1,$$

and $1$ is a unit. ✓

### Step 7. Ruling out all other cases

- **Odd characteristic:** If $\operatorname{char}(R)$ is odd, then $2\cdot 1$ is
 a unit (since $\gcd(2,\operatorname{char} R)=1$), so $2x=0\Rightarrow x=0$, giv
ing $R[2]=\{0\}$, $S=0$: not a unit. ✗
- **Characteristic $2m$, $m>1$ (e.g. $\mathbb{Z}/4\mathbb{Z}$):** $R[2]=\{0,a\}$
 with $2a=0$, but $a$ is never a unit (any unit $u$ has $2u=0\Rightarrow 2=0$, c
ontradicting $\operatorname{char}>2$). ✗
- **Characteristic $2$, $|R|>2$:** Then $R[2]=R$ has $|R|\ge 4$, so $k\ge 2$ and
 $S=0$. ✗
- **Mixed/product rings (e.g. $\mathbb{Z}/6\mathbb{Z}$):** $R[2]=\{0,a\}$ but $a
$ is a zero-divisor, not a unit. ✗

All cases other than $\mathbb{F}_2$ fail.
