## Proof

**Goal.** Find the minimal integer $n$ with $H_n := \sum_{k=1}^n \frac{1}{k} \ge
 1000$.

**Step 1: Asymptotic expansion of harmonic numbers.**

By the Euler–Maclaurin formula, for every $n \ge 1$:

$$H_n = \ln n + \gamma + \frac{1}{2n} - \frac{1}{12n^2} + \frac{1}{120n^4} - \fr
ac{1}{252n^6} + \cdots$$

where $\gamma = 0.5772156649015328606\ldots$ is the Euler–Mascheroni constant. T
his is an enveloping series: truncating after any term gives an approximation wh
ose error is bounded by (and has the same sign as) the first omitted term. In pa
rticular:

$$H_n - \ln n - \gamma = \frac{1}{2n} - \frac{1}{12n^2} + \frac{1}{120n^4} - \cd
ots$$

is positive for all $n \ge 1$ (since the first term dominates), and satisfies $\
frac{1}{2n} - \frac{1}{12n^2} < H_n - \ln n - \gamma < \frac{1}{2n}$.

**Step 2: Characterize the threshold.**

Define $A := e^{1000 - \gamma}$. We seek the smallest integer $n$ with $H_n \ge
1000$.

The condition $H_n \ge 1000$ is equivalent to:

$$\ln n + \gamma + \frac{1}{2n} - \frac{1}{12n^2} + \cdots \ge 1000$$

$$\Longleftrightarrow \ln n \ge 1000 - \gamma - \frac{1}{2n} + \frac{1}{12n^2} -
 \cdots$$

$$\Longleftrightarrow n \ge A \cdot \exp\!\left(-\frac{1}{2n} + \frac{1}{12n^2}
- \cdots\right)$$

Let $\delta := \frac{1}{2n} - \frac{1}{12n^2} + \frac{1}{120n^4} - \cdots = \fra
c{1}{2n} + O(n^{-2})$. Then:

$$n \ge A \cdot e^{-\delta} = A\left(1 - \delta + \frac{\delta^2}{2} - \cdots\ri
ght) = A - A\delta + \frac{A\delta^2}{2} - \cdots$$

Since $n \approx A$ (which we will verify), $A\delta \approx A \cdot \frac{1}{2A
} = \frac{1}{2}$, and $A\delta^2 \approx A \cdot \frac{1}{4A^2} = \frac{1}{4A}$.
 More precisely:

$$n \ge A - \frac{A}{2n} + \frac{A}{12n^2} + \frac{A\delta^2}{2} + O(A/n^3)$$

Substituting $n \approx A$:

$$n \ge A - \frac{1}{2} + \frac{1}{12A} + \frac{1}{8A} + O(A^{-2}) = A - \frac{1
}{2} + \frac{5}{24A} + O(A^{-2})$$

**Step 3: The threshold $n^*$ and the answer.**

The real threshold $n^*$ (where $H_{n^*} = 1000$) satisfies:

$$n^* = A - \frac{1}{2} + \frac{5}{24A} + O(A^{-2})$$

Now $A = e^{1000-\gamma} = e^{999.4228\ldots}$. Computing the order of magnitude

$$\log_{10} A = \frac{1000 - \gamma}{\ln 10} = \frac{999.4228\ldots}{2.30259\ldo
ts} = 434.0443\ldots$$

So $A \approx 1.106 \times 10^{434}$, a number with **435 digits**.

The correction term $\frac{5}{24A} + O(A^{-2})$ is of order $10^{-435}$, which i
s **far smaller than the distance from $A - \frac{1}{2}$ to any integer** (since
 $A$ is not a half-integer — it is a specific transcendental-type real number, a
nd the probability of landing within $10^{-435}$ of a half-integer is nil).

Therefore:

$$n^* = A - \frac{1}{2} + \varepsilon, \quad \text{where } |\varepsilon| < 10^{-
434}$$

and the minimal integer $n$ with $H_n \ge 1000$ is:

$$\boxed{n = \left\lfloor e^{1000 - \gamma} + \frac{1}{2} \right\rfloor}$$

that is, the **nearest integer to $e^{1000-\gamma}$**, where $\gamma$ is the Eul
er–Mascheroni constant.

**Step 5: Leading digits of the answer.**

$$e^{1000-\gamma} = \frac{e^{1000}}{e^\gamma}$$

where $e^\gamma = 1.78107241799020\ldots$ and $e^{1000} = 10^{434.29448\ldots} \

Thus $e^{1000-\gamma} \approx 1.1063 \times 10^{434}$, so the answer is a **435-
