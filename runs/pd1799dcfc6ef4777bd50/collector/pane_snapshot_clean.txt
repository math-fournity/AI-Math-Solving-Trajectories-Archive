## Proof

The Riemann sphere $\hat{\mathbb{C}} = \mathbb{C} \cup \{\infty\}$ is homeomorph
ic to $S^2$, so $H_2(\hat{\mathbb{C}}, \mathbb{Z}) \cong \mathbb{Z}$, generated
by the fundamental class $[\hat{\mathbb{C}}]$.

For any continuous map $f: S^2 \to S^2$, the induced map $f_*$ on $H_2(S^2, \mat
hbb{Z}) \cong \mathbb{Z}$ is multiplication by the topological degree $\deg(f)$.

**Claim:** $\deg(f) = 3$ for $f(z) = z^3 + 2z + 7$ with $f(\infty) = \infty$.

**Proof of claim.** Consider the chart near $\infty$ using the coordinate $w = 1
/z$. Then $f(z) = z^3 + 2z + 7$, and in the $w$-coordinate near $w = 0$ (i.e., $
z = \infty$):

$$\frac{1}{f(z)} = \frac{1}{z^3 + 2z + 7} = \frac{w^3}{1 + 2w^2 + 7w^3}.$$

So in the local coordinate $w$ at $\infty$, the map is $w \mapsto w^3(1 + 2w^2 +
 7w^3)^{-1}$, which has a zero of order 3 at $w = 0$. The local degree at $\inft
y$ is therefore 3.

Since $f$ is holomorphic and non-constant on $\mathbb{C}$, every regular value $
y \in \mathbb{C}$ has exactly 3 preimages (counting multiplicity, since $f$ is d
egree 3 as a polynomial), each contributing $+1$ to the degree (holomorphic maps
 preserve orientation). Thus the global degree is:

$$\deg(f) = 3.$$

Therefore:

$$f_* : H_2(\hat{\mathbb{C}}, \mathbb{Z}) \to H_2(\hat{\mathbb{C}}, \mathbb{Z})$
$

is multiplication by 3, i.e.,

$$\boxed{f_*(n) = 3n \text{ for all } n \in \mathbb{Z}.}$$
