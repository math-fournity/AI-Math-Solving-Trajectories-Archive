# Problem

In a futuristic data-processing facility, engineers are trying to organize the infinite stream of all positive identification codes, $\mathbb{N}^* = \{1, 2, 3, \dots\}$, into $n$ distinct, non-empty storage servers, labeled $A_1, A_2, \dots, A_n$. Every single identification code must be assigned to exactly one server.

Each server is equipped with a specialized synthesis algorithm. This algorithm takes any three codes (not necessarily distinct) stored within that server—let's call them $a, b,$ and $c$—and processes them to generate a new value using the formula:
$$V = abc - b - c + 2$$

For the storage system to be considered "stable," every server must be self-contained: if any codes $a, b,$ and $c$ are found in server $A_i$, the resulting value $V$ generated by the algorithm must also be a code already assigned to that same server $A_i$.

Let $S$ be the set of all integers $n > 1$ for which such a stable partitioning of all positive identification codes into $n$ servers is mathematically possible.

Calculate the sum of all elements in $S$ that are less than or equal to 100.
