### Step 2: Determining P(z)

We seek a polynomial $P(z)$ satisfying $P(z) - P(z+2\pi i) = z^3$. Since the fin
ite-difference operator $P(z) \mapsto P(z) - P(z+h)$ lowers degree by one, $P$ m
ust be degree 4. Write $h = 2\pi i$ and

$$P(z) = a_4 z^4 + a_3 z^3 + a_2 z^2 + a_1 z + a_0.$$

Expanding $P(z) - P(z+h)$ and collecting powers of $z$:

$$P(z)-P(z+h) = (-4a_4 h)\,z^3 + (-6a_4 h^2 - 3a_3 h)\,z^2 + (-4a_4 h^3 - 3a_3 h
^2 - 2a_2 h)\,z + (-a_4 h^4 - a_3 h^3 - a_2 h^2 - a_1 h).$$

Setting this equal to $z^3$ gives the system:

- **$z^3$:** $-4a_4 h = 1 \;\Rightarrow\; a_4 = -\dfrac{1}{4h} = -\dfrac{1}{8\pi
 i}.$
- **$z^2$:** $-6a_4 h^2 - 3a_3 h = 0 \;\Rightarrow\; a_3 = -2a_4 h = \dfrac{1}{2
}.$
- **$z^1$:** $-4a_4 h^3 - 3a_3 h^2 - 2a_2 h = 0 \;\Rightarrow\; a_2 = -2a_4 h^2
- \tfrac{3}{2}a_3 h = \dfrac{h}{2} - \dfrac{3h}{4} = -\dfrac{h}{4} = -\dfrac{\pi
 i}{2}.$
- **$z^0$:** $-a_4 h^4 - a_3 h^3 - a_2 h^2 - a_1 h = 0 \;\Rightarrow\; a_1 = -a_
4 h^3 - a_3 h^2 - a_2 h = \dfrac{h^2}{4} - \dfrac{h^2}{2} + \dfrac{h^2}{4} = 0.$

The constant $a_0$ is free (it cancels in the difference); we set $a_0 = 0$. Thu
s

$$\boxed{P(z) = -\frac{z^4}{8\pi i} + \frac{z^3}{2} - \frac{\pi i}{2}\,z^2.}$$

**Verification.** Direct substitution confirms $P(z)-P(z+2\pi i) = z^3$ (all low
er-order coefficients vanish, as checked above).

### Step 3: Poles and Residues of $P(z)/(e^z - 1)$

The integrand $f(z) = \dfrac{P(z)}{e^z - 1}$ has simple poles at $z_k = 2k\pi i$
, $k \in \mathbb{Z}$, where $e^z - 1 = 0$. Since $(e^z-1)' = e^z$ and $e^{z_k} =
 1$, each pole is simple with

$$\operatorname{Res}\left[\frac{1}{e^z-1},\, z_k\right] = \frac{1}{e^{z_k}} = 1.
$$

Therefore

$$\operatorname{Res}\left[\frac{P(z)}{e^z-1},\, z_k\right] = P(z_k) = P(2k\pi i)
.$$

### Step 4: Evaluating $P(2k\pi i)$

Substituting $z = 2k\pi i$ (so $z^2 = -4k^2\pi^2$, $z^3 = -8k^3\pi^3 i$, $z^4 =
16k^4\pi^4$):

$$P(2k\pi i) = -\frac{16k^4\pi^4}{8\pi i} + \frac{(-8k^3\pi^3 i)}{2} - \frac{\pi
 i}{2}(-4k^2\pi^2)$$

$$= -\frac{2k^4\pi^3}{i} - 4k^3\pi^3 i + 2k^2\pi^3 i = 2k^4\pi^3 i - 4k^3\pi^3 i
 + 2k^2\pi^3 i$$

$$= 2\pi^3 i\,(k^4 - 2k^3 + k^2) = 2\pi^3 i\,k^2(k-1)^2.$$

**Key observation:** $P(z_k) = 0$ for $k = 0$ and $k = 1$, i.e., the residues at
 $z_0 = 0$ and $z_1 = 2\pi i$ both vanish.

### Step 5: The Integral via the Residue Theorem

Let $C_N$ be a contour (e.g., a large rectangle) enclosing the poles $z_0, z_1,
\ldots, z_{N-1}$. By the residue theorem:

$$\oint_{C_N} \frac{P(z)}{e^z - 1}\,dz = 2\pi i \sum_{k=0}^{N-1} P(z_k) = 2\pi i
 \sum_{k=0}^{N-1} 2\pi^3 i\, k^2(k-1)^2 = -4\pi^4 \sum_{k=0}^{N-1} k^2(k-1)^2.$$

### Step 6: Telescoping via the Key Identity (Consistency Check)

Using $P(z) - P(z+2\pi i) = z^3$ and the $2\pi i$-periodicity of $e^z - 1$:

$$\oint_{C_N} \frac{z^3}{e^z-1}\,dz = \oint_{C_N} \frac{P(z) - P(z+2\pi i)}{e^z
- 1}\,dz = \oint_{C_N}\frac{P(z)}{e^z-1}\,dz - \oint_{C_N}\frac{P(z+2\pi i)}{e^z
-1}\,dz.$$

The second integral has residues $P(z_k + 2\pi i) = P(z_{k+1})$ at the same pole
s, so:

$$\oint_{C_N} \frac{z^3}{e^z-1}\,dz = 2\pi i\!\sum_{k=0}^{N-1} P(z_k) - 2\pi i\!
\sum_{k=0}^{N-1} P(z_{k+1}) = 2\pi i\bigl[P(z_0) - P(z_N)\bigr] = -2\pi i\, P(2N
\pi i).$$

Since $P(2N\pi i) = 2\pi^3 i\, N^2(N-1)^2$:

$$\oint_{C_N} \frac{z^3}{e^z-1}\,dz = -2\pi i \cdot 2\pi^3 i\, N^2(N-1)^2 = 4\pi
^4\, N^2(N-1)^2.$$

**Cross-check** via direct residue computation: $\operatorname{Res}[z^3/(e^z-1),
\, z_k] = (2k\pi i)^3 = -8k^3\pi^3 i$, so

$$\oint_{C_N} \frac{z^3}{e^z-1}\,dz = 2\pi i \sum_{k=0}^{N-1}(-8k^3\pi^3 i) = 16
\pi^4 \sum_{k=0}^{N-1} k^3 = 16\pi^4 \cdot \frac{N^2(N-1)^2}{4} = 4\pi^4\, N^2(N
-1)^2. \;\checkmark$$

### Summary

$$P(z) = -\frac{z^4}{8\pi i} + \frac{z^3}{2} - \frac{\pi i}{2}\,z^2,$$

with residues at the poles $z_k = 2k\pi i$ given by

$$\operatorname{Res}\!\left[\frac{P(z)}{e^z-1},\, z_k\right] = P(z_k) = 2\pi^3 i
\, k^2(k-1)^2,$$

and for a contour $C_N$ enclosing the poles $z_0, \ldots, z_{N-1}$:

$$\oint_{C_N} \frac{P(z)}{e^z-1}\,dz = 2\pi i \sum_{k=0}^{N-1} P(z_k) = -4\pi^4
\sum_{k=0}^{N-1} k^2(k-1)^2.$$

The telescoping identity $P(z) - P(z+2\pi i) = z^3$ yields the companion result
$\displaystyle\oint_{C_N} \frac{z^3}{e^z-1}\,dz = 4\pi^4\, N^2(N-1)^2$, confirme
d independently by direct residue summation.
