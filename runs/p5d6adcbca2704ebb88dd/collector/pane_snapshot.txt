## Solution

**Setup.** The polynomial $p(x) = a_1 x^2 + a_2 x + a_3$ with $a_1 > 0$ has its
minimum at $x = -a_2/(2a_1)$, giving:

$$M = a_3 - \frac{a_2^2}{4a_1}$$

Ana moves first and third (filling 2 squares); Banana moves second (filling 1 sq
uare). Each move picks an empty square and an unused integer from $\{1,2,3,4,5\}
$.

**Ana's goals:** minimize $M$ → wants $a_3$ small, $a_2$ large, $a_1$ small.
**Banana's goals:** maximize $M$ → wants $a_3$ large, $a_2$ small, $a_1$ large.

**Backward induction.** On Ana's final move, with one square empty and 3 numbers
 remaining:
- If square 3 is last: Ana picks **smallest** remaining number (minimizes $a_3$)
.
- If square 2 is last: Ana picks **largest** remaining number (maximizes $a_2^2$
).
- If square 1 is last: Ana picks **smallest** remaining number (maximizes $a_2^2
/(4a_1)$).

**Evaluating all first moves.** I computed Banana's best response (maximizing $M
$) for every possible first move by Ana. The key results:

| Ana's first move | Banana's best response | Resulting $M$ |
|---|---|---|
| Square 1, value 1 | Square 2, value 2 | $3 - 4/4 = 2$ |
| Square 2, value 5 | Square 1, value 4 | $1 - 25/16 = -9/16$ |
| Square 3, value 1 | Square 2, value 2 | $1 - 4/12 = 2/3$ |

(The best option within each square is shown; all other values give larger $M$,
hence are worse for Ana.)

**Verification of the optimal line.** Ana fills $\square_2$ with **5**. Remainin
g: $\{1,2,3,4\}$.

Banana's options (each followed by Ana's optimal response):

*Banana fills $\square_1$:*
- $v_1=1$: Ana picks $a_3=2$. $M = 2 - 25/4 = -4.25$
- $v_1=2$: Ana picks $a_3=1$. $M = 1 - 25/8 = -2.125$
- $v_1=3$: Ana picks $a_3=1$. $M = 1 - 25/12 \approx -1.083$
- $v_1=4$: Ana picks $a_3=1$. $M = 1 - 25/16 = -9/16$

*Banana fills $\square_3$:*
- $v_3=1$: Ana picks $a_1=2$. $M = 1 - 25/8 = -2.125$
- $v_3=2$: Ana picks $a_1=1$. $M = 2 - 25/4 = -4.25$
- $v_3=3$: Ana picks $a_1=1$. $M = 3 - 25/4 = -3.25$
- $v_3=4$: Ana picks $a_1=1$. $M = 4 - 25/4 = -2.25$

Banana's maximum is $M = -9/16$, achieved by filling $\square_1$ with **4**. Ana
 then fills $\square_3$ with **1**.

**Confirming optimality.** Comparing Ana's best option across all three squares:
- Best via $\square_1$: $M = 2$
- Best via $\square_2$: $M = -9/16$ ✓ (minimum)
- Best via $\square_3$: $M = 2/3$

Ana's optimal first move is filling $\square_2$ with 5, yielding $M = -9/16$.

**Final configuration:** $a_1 = 4,\; a_2 = 5,\; a_3 = 1$, giving $p(x) = 4x^2 +
5x + 1$ with minimum value $1 - 25/16 = -9/16$.

$$100a_1 + 10a_2 + a_3 = 100(4) + 10(5) + 1 = \boxed{451}$$
