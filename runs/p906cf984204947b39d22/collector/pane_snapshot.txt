## Solution

We evaluate the integral
$$I = \int_0^\infty \frac{1}{(1+x^{2015})(1+x^2)}\,dx.$$

**Key substitution.** Apply the involution $x \mapsto 1/t$, i.e. $x = 1/t$, $dx
= -dt/t^2$:

$$I = \int_\infty^0 \frac{1}{\bigl(1+t^{-2015}\bigr)\bigl(1+t^{-2}\bigr)}\cdot\l
eft(-\frac{dt}{t^2}\right) = \int_0^\infty \frac{1}{\bigl(1+t^{-2015}\bigr)\bigl
(1+t^{-2}\bigr)}\cdot\frac{dt}{t^2}.$$

Rewrite the factors using $1+t^{-n} = \frac{1+t^n}{t^n}$:

$$\frac{1}{(1+t^{-2015})(1+t^{-2})}\cdot\frac{1}{t^2} = \frac{t^{2015}}{1+t^{201
5}}\cdot\frac{t^2}{1+t^2}\cdot\frac{1}{t^2} = \frac{t^{2015}}{(1+t^{2015})(1+t^2
)}.$$

Hence
$$I = \int_0^\infty \frac{t^{2015}}{(1+t^{2015})(1+t^2)}\,dt.$$

**Add the two representations.** Adding the original and the transformed form (r
enaming the dummy variable back to $x$):

$$2I = \int_0^\infty \frac{1+x^{2015}}{(1+x^{2015})(1+x^2)}\,dx = \int_0^\infty
\frac{1}{1+x^2}\,dx = \arctan x\,\Big|_0^\infty = \frac{\pi}{2}.$$

Therefore
$$I = \frac{\pi}{4}.$$

**Convergence check.** Near $x=0$ the integrand is bounded (approaches $1$); as
$x\to\infty$ it behaves like $1/x^{2017}$, which is integrable. The substitution
 $x\mapsto 1/t$ is valid on $(0,\infty)$, so the manipulation is justified.

$$\boxed{\displaystyle\int_0^\infty \frac{dx}{(1+x^{2015})(1+x^2)} = \frac{\pi}{
4}}$$
