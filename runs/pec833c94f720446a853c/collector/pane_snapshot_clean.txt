Looking at this problem, I need to determine whether the measure of the preimage
 of a shrinking box around $a$ tends to zero.

**Answer: Yes, the limit holds and equals 0.**

## Proof

**Setup and interpretation.** Since $f:\Omega\subset\mathbb{R}^n\to\mathbb{R}^n$
, the inequality $a-\epsilon\le f(x)\le a+\epsilon$ is interpreted component-wis
e, so the set in question is
$$E_\epsilon = \{x\in\Omega : a_i-\epsilon\le f_i(x)\le a_i+\epsilon,\ \forall i
\} = \{x\in\Omega:\|f(x)-a\|_\infty\le\epsilon\}.$$
Real analytic on the compact set $\Omega$ means $f$ extends to an analytic funct
ion on an open neighborhood $U\supseteq\Omega$.

**Step 1: Reduce to the fiber $\{f=a\}$.** The family $\{E_\epsilon\}_{\epsilon>
0}$ is decreasing (as $\epsilon\to 0^+$) and all sets are contained in $\Omega$,
 which is compact hence has finite Lebesgue measure. By continuity of measure fr
om above,
$$\lim_{\epsilon\to 0^+}\mu(E_\epsilon)=\mu\!\left(\bigcap_{\epsilon>0}E_\epsilo
n\right)=\mu(\{x\in\Omega:f(x)=a\}).$$

**Step 2: Show $\mu(\{x\in\Omega:f(x)=a\})=0$.** Since $f$ is non-constant, at l
east one component $f_j$ is non-constant. Since $a\in\operatorname{Im}f$, there
exists $x_0\in\Omega$ with $f(x_0)=a$. Define $g:=f_j-a_j$, which is real analyt
ic on $U$ and **not identically zero** on $U$ (if it were, $f_j$ would be consta
nt on $U$, hence constant on $\Omega$, contradicting non-constancy of $f$).

Now $\{x\in\Omega:f(x)=a\}\subseteq\{x\in U:g(x)=0\}$, so it suffices to show:

> **Lemma.** If $g:U\to\mathbb{R}$ is real analytic on an open set $U\subseteq\m
athbb{R}^n$ and $g\not\equiv 0$, then $\mu(\{x\in U:g(x)=0\})=0$.

**Proof of Lemma (by induction on $n$).** *Base case $n=1$:* A non-identically-z
ero real analytic function on an open subset of $\mathbb{R}$ has isolated zeros
(the zeros are discrete), hence countably many, so they form a measure-zero set.

*Inductive step:* Assume the result for dimension $n-1$. Write $x=(y,t)\in\mathb
b{R}^{n-1}\times\mathbb{R}$. For each $y$, let $h_y(t)=g(y,t)$. The zero set is
$Z=\{(y,t):h_y(t)=0\}$. Define
$$B=\{y\in\mathbb{R}^{n-1}: h_y\equiv 0\}=\{y:g(y,t)=0\ \text{for all }t\}.$$
Expanding $g(y,t)=\sum_{k\ge0}c_k(y)\,t^k$ where $c_k(y)=\frac{1}{k!}\frac{\part
ial^k g}{\partial t^k}(y,0)$ are real analytic in $y$, we get $B=\bigcap_{k\ge0}
\{y:c_k(y)=0\}$. Since $g\not\equiv 0$, some $c_{k_0}\not\equiv 0$. By the induc
tive hypothesis, $\mu_{n-1}(\{y:c_{k_0}(y)=0\})=0$, so $\mu_{n-1}(B)=0$.

By Fubini's theorem:
$$\mu_n(Z)=\int_{\mathbb{R}^{n-1}}\mu_1(\{t:h_y(t)=0\})\,dy.$$
For $y\notin B$, $h_y\not\equiv 0$, so by the $n=1$ case, $\mu_1(\{t:h_y(t)=0\})
=0$. For $y\in B$, the inner measure is $\mu_1(\mathbb{R})=\infty$, but $\mu_{n-
1}(B)=0$, so this contributes nothing. Hence $\mu_n(Z)=0$. $\square$

**Conclusion.** By the Lemma, $\mu(\{x\in U:g(x)=0\})=0$, so $\mu(\{x\in\Omega:f
(x)=a\})=0$, and therefore
$$\lim_{\epsilon\to 0^+}\mu\!\left(\{x\in\Omega:a-\epsilon\le f(x)\le a+\epsilon
\}\right)=0.$$

The key ingredients are: (1) continuity of measure from above for decreasing set
s of finite measure, reducing the limit to the measure of the fiber $\{f=a\}$; a
nd (2) the classical fact that the zero set of a non-identically-zero real analy
tic function has Lebesgue measure zero, which ensures the fiber has measure zero
 because non-constancy of $f$ guarantees some component $f_j-a_j$ is a non-trivi
al analytic function vanishing on the fiber.
