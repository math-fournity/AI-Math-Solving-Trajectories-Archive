## Proof

We work in the Hilbert space $H = L^2((0,1)^2)$ with inner product
$$\langle F, G\rangle = \int_0^1\!\int_0^1 F(x,y)\,G(x,y)\,dx\,dy.$$

The subspace is
$$V = \bigl\{F\in H : F(x,y)=g(x)\text{ for some }g\in L^2(0,1)\bigr\},$$
i.e. the closed subspace of functions depending only on $x$.

**Characterizing the projection.** Let $P_V f = \varphi(x)\in V$ be the orthogon
al projection of $f(x,y)=xy$. By the projection theorem, $f - P_V f \perp V$, me
aning
$$\langle xy - \varphi(x),\, h(x)\rangle = 0 \quad\text{for every } h\in V.$$

Expanding the inner product and using Fubini (all functions are in $L^2$, so thi
s is justified):
$$\int_0^1 h(x)\left[\int_0^1 \bigl(xy - \varphi(x)\bigr)\,dy\right]dx = 0 \quad
\text{for every } h\in L^2(0,1).$$

Since $h\in L^2(0,1)$ is arbitrary, the bracketed expression must vanish for a.e
. $x$:
$$\int_0^1 \bigl(xy - \varphi(x)\bigr)\,dy = 0 \quad\text{a.e. }x.$$

**Computing $\varphi$.** Evaluating the integral:
$$\int_0^1 xy\,dy - \int_0^1 \varphi(x)\,dy = x\cdot\frac{y^2}{2}\Big|_0^1 - \va
rphi(x)\cdot 1 = \frac{x}{2} - \varphi(x) = 0.$$

Hence
$$\varphi(x) = \frac{x}{2}.$$

**Verification.** Check orthogonality of the residual:
$$f - P_V f = xy - \frac{x}{2} = x\!\left(y - \frac{1}{2}\right).$$
For any $h(x)\in V$,
$$\Bigl\langle x\!\left(y-\tfrac12\right),\, h(x)\Bigr\rangle = \int_0^1 x\,h(x)
\left[\int_0^1\!\left(y-\tfrac12\right)dy\right]dx = \int_0^1 x\,h(x)\cdot 0\,dx
 = 0. \checkmark$$

So the residual is orthogonal to all of $V$, confirming $\varphi\in V$ is indeed
 the orthogonal projection.

**Interpretation.** This is the conditional expectation of $f$ over the $y$-fibe
r:
$$P_V f(x) = \int_0^1 xy\,dy = \frac{x}{2},$$
which is exactly the averaging (marginalization) over $y$ that defines projectio
n onto the sub-$\sigma$-algebra depending only on $x$.
