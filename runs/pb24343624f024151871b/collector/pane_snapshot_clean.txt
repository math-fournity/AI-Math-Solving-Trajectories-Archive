 < n$, $k = n$, or $k > n$. The algorithm must eventually terminate and output t
he value of $k$, correctly, in finite time—regardless of the adversary's choice.
 The adversary is **adaptive**: it answers each query consistently with at least
 one non-negative integer, choosing answers to thwart termination.

**Adversarial strategy.** The adversary maintains the invariant that the set $S$
 of non-negative integers consistent with all answers given so far is **infinite
**. Initially $S = \{0, 1, 2, \ldots\}$, which is infinite.

When $\mathcal{A}$ queries "compare $k$ with $n$," the adversary answers **"$k >
 n$"**.

**The invariant is preserved.** Suppose $S$ is infinite before the query. After
answering "$k > n$," the new consistent set is $S' = S \cap \{n+1, n+2, \ldots\}
$. Since $S \cap \{0, 1, \ldots, n\}$ is finite (at most $n+1$ elements) and $S$
 is infinite, we have $S' = S \setminus \{0, \ldots, n\}$, which is infinite. Th
us $S'$ remains infinite. $\checkmark$

**Key observation.** The adversary's answer "$k > n$" is **always consistent**:
$S'$ is never empty (it is infinite), so there always exists a non-negative inte
ger matching all answers given.

**The algorithm cannot terminate.** After any finite number $t$ of queries, the
consistent set $S$ is still infinite. If $\mathcal{A}$ terminates and outputs a
value $v$, the adversary can select any $k \in S \setminus \{v\}$ (non-empty sin
ce $S$ is infinite) as the "true" value—all of the adversary's answers remain co
nsistent with this $k$, yet $\mathcal{A}$'s output $v \neq k$ is **wrong**. Ther
efore $\mathcal{A}$ cannot correctly identify $k$.

**Conclusion.** No matter what strategy $\mathcal{A}$ employs, the adaptive adve
rsary can always keep infinitely many candidates consistent with its answers, pr
eventing the algorithm from pinning down $k$ in finite time. This contradicts th

Therefore, **no algorithm exists** that can identify an adversarially-chosen non
-negative integer $k$ using only comparison tests ($<, =, >$) in finite time. $\
blacksquare$
