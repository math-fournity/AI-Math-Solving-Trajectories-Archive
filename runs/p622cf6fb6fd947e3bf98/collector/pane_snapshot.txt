## Proof

Let \(W_t := -B_t\), which is again a standard Brownian motion. Define
\[
Y_t := at - B_t = at + W_t,
\]
a Brownian motion with drift \(a>0\). The stopping time becomes
\[
T = \inf\{t\ge 0 : B_t = at - b\} = \inf\{t\ge 0 : Y_t = b\} =: \tau,
\]
the first hitting time of level \(b>0\) by the drifted Brownian motion \(Y_t = a
t + W_t\).

**Step 1: \(\tau < \infty\) a.s.** Since \(W_t/t \to 0\) a.s., we have \(Y_t/t =
 a + W_t/t \to a > 0\) a.s., hence \(Y_t \to +\infty\) a.s. As \(Y_0 = 0 < b\) a
nd \(Y\) has continuous paths, it must hit \(b\) at some finite time a.s.

**Step 2: \(\mathbb{E}[\tau] \le b/a\).** For each \(n\), the stopped time \(\ta
u \wedge n\) is bounded. Applying the optional stopping theorem to the martingal
e \(W_t\) (with \(Y_t = at + W_t\), so \(W_t = Y_t - at\)):
\[
0 = \mathbb{E}[W_{\tau\wedge n}] = \mathbb{E}[Y_{\tau\wedge n}] - a\,\mathbb{E}[
\tau\wedge n].
\]
Because \(Y\) has continuous paths and hits \(b\) from below, \(Y_{\tau\wedge n}
 \le b\) (it equals \(b\) on \(\{\tau\le n\}\) and is \(<b\) on \(\{\tau>n\}\)).
 Therefore
\[
a\,\mathbb{E}[\tau\wedge n] = \mathbb{E}[Y_{\tau\wedge n}] \le b.
\]
Letting \(n\to\infty\) and using monotone convergence (\(\tau\wedge n \uparrow \
tau\)):
\[
\mathbb{E}[\tau] \le \frac{b}{a} < \infty.
\]

**Step 3: Uniform integrability of \(W_{\tau\wedge n}\).** Applying optional sto
pping to the martingale \(W_t^2 - t\) at the bounded time \(\tau\wedge n\):
\[
\mathbb{E}[W_{\tau\wedge n}^2] = \mathbb{E}[\tau\wedge n] \le \mathbb{E}[\tau] \
le \frac{b}{a}.
\]
Thus \(\{W_{\tau\wedge n}\}_{n\ge 1}\) is bounded in \(L^2\), hence uniformly in
tegrable. Since \(W_{\tau\wedge n} \to W_\tau\) a.s. (as \(\tau<\infty\) a.s.),
uniform integrability gives convergence in \(L^1\), so
\[
\mathbb{E}[W_\tau] = \lim_{n\to\infty}\mathbb{E}[W_{\tau\wedge n}] = 0.
\]

**Step 4: Compute \(\mathbb{E}[\tau]\).** At the stopping time, \(Y_\tau = b\),
hence
\[
W_\tau = Y_\tau - a\tau = b - a\tau.
\]
Taking expectations and using \(\mathbb{E}[W_\tau]=0\):
\[
0 = \mathbb{E}[W_\tau] = \mathbb{E}[b - a\tau] = b - a\,\mathbb{E}[\tau].
\]
Therefore
\[
\boxed{\mathbb{E}[T] = \mathbb{E}[\tau] = \frac{b}{a}}.
\]
