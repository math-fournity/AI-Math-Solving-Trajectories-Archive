## Solution

**Answer: Yes, every square matrix $A$ can be expressed as $A = B_1B_2 = B_2B_1$
.**

### Proof

Let $A$ be any $n \times n$ square matrix over a field $\mathbb{F}$, and let $I_
n$ denote the $n \times n$ identity matrix.

Set
$$B_1 = A, \qquad B_2 = I_n.$$

Then:
- $B_1 B_2 = A \cdot I_n = A$,
- $B_2 B_1 = I_n \cdot A = A$.

Hence $B_1 B_2 = B_2 B_1 = A$, so $A = B_1 B_2 = B_2 B_1$ as required.

Since $A$ was an arbitrary square matrix, this construction works for **every**
square matrix. The identity matrix $I_n$ commutes with every matrix, so the choi
ce $B_2 = I_n$ guarantees the commutativity condition $B_1 B_2 = B_2 B_1$ automa
tically, while the product collapses to $A$ itself.

Therefore, every square matrix $A$ admits such a representation. $\blacksquare$
