# Problem

In a futuristic industrial harbor, a logistics coordinator manages a triangular storage yard. This yard is built using a grid of $n \times n$ potential slots, but only the $n(n+1)/2$ slots located on or below the main diagonal are active. 

The harbor master secretly places exactly $n$ automated cargo pods into $n$ distinct active slots. He then provides the coordinator with two specific data logs:
1. A report stating the exact number of cargo pods located in each of the $n$ horizontal rows.
2. A confirmation that every one of the $n$ vertical columns contains exactly one cargo pod.

A configuration is defined as a "Master Layout" if the coordinator can uniquely determine the exact coordinates of all $n$ cargo pods using only these two pieces of information. 

How many different "Master Layouts" can the harbor master create for a given $n$?
