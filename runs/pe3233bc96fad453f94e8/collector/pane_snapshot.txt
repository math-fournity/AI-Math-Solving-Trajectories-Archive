## Proof

Let $C = (0,1)^d$ be the open unit cube in $\mathbb{R}^d$, which has Lebesgue me
asure $\lambda(C) = 1$.

Define the open simplex
$$\Delta = \{(x_1, \dots, x_d) \in \mathbb{R}^d : 0 < x_1 < x_2 < \cdots < x_d <
 1\}.$$

**Step 1: Decomposition of the cube.** For each permutation $\sigma \in S_d$, de
fine
$$\Delta_\sigma = \{(x_1, \dots, x_d) \in (0,1)^d : 0 < x_{\sigma(1)} < x_{\sigm
a(2)} < \cdots < x_{\sigma(d)} < 1\}.$$
Each $\Delta_\sigma$ is the set of points in the cube whose coordinates are stri
ctly ordered according to $\sigma$. The collection $\{\Delta_\sigma : \sigma \in
 S_d\}$ is pairwise disjoint, since a point with all distinct coordinates has a
unique ordering. Their union is
$$\bigcup_{\sigma \in S_d} \Delta_\sigma = (0,1)^d \setminus H,$$
where $H = \{x \in (0,1)^d : x_i = x_j \text{ for some } i \neq j\}$ is the unio
n of the diagonal hyperplanes $x_i = x_j$.

**Step 2: The exceptional set has measure zero.** Each hyperplane $\{x_i = x_j\}
$ is a $(d-1)$-dimensional affine subspace, hence has $d$-dimensional Lebesgue m
easure zero. The finite union $H$ therefore has measure zero. Thus
$$\lambda\!\left(\bigcup_{\sigma \in S_d} \Delta_\sigma\right) = \lambda((0,1)^d
) = 1.$$

**Step 3: Symmetry gives equal measure.** The symmetric group $S_d$ acts on $\ma
thbb{R}^d$ by permuting coordinates: $\sigma \cdot (x_1, \dots, x_d) = (x_{\sigm
a(1)}, \dots, x_{\sigma(d)})$. This action is linear with determinant $\pm 1$, s
o it preserves Lebesgue measure. It maps $\Delta_{\mathrm{id}} = \Delta$ bijecti
vely onto $\Delta_\sigma$ for each $\sigma$. Therefore all $d!$ simplices have t
he same measure:
$$\lambda(\Delta_\sigma) = \lambda(\Delta) \quad \text{for all } \sigma \in S_d.
$$

**Step 4: Conclusion.** Since the $\Delta_\sigma$ are pairwise disjoint, have eq
ual measure, and their union has measure $1$,
$$d! \cdot \lambda(\Delta) = 1,$$
so
$$\boxed{\lambda(\Delta) = \frac{1}{d!}}.$$
