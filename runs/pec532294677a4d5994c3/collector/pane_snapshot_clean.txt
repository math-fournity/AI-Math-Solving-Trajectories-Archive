## Proof

The product of a smooth function $c \in C^\infty(\mathbb{R})$ with a distributio
n $f \in D'(\mathbb{R})$ is defined by duality:

$$(cf)(\phi) := f(c\,\phi), \qquad \phi \in D(\mathbb{R}).$$

Here $c(x) = e^x$, which is smooth and, crucially, **nowhere vanishing** on $\ma
thbb{R}$.

**Claim.** $(cf)(\phi) = 0$ for all $\phi \in D(\mathbb{R})$ if and only if $f =
 0$ (the zero distribution).

**Proof of "if".** If $f = 0$, then $(cf)(\phi) = f(c\phi) = 0$ for every $\phi$
, trivially.

**Proof of "only if".** Suppose $(cf)(\phi) = 0$ for all $\phi \in D(\mathbb{R})
$, i.e.,

$$f(c\,\phi) = 0 \quad \text{for all } \phi \in D(\mathbb{R}). \tag{$\ast$}$$

Since $c(x) = e^x \neq 0$ everywhere, the function $c^{-1}(x) = e^{-x}$ is also
$C^\infty$. Therefore the multiplication map

$$M_c : D(\mathbb{R}) \to D(\mathbb{R}), \qquad \phi \mapsto c\,\phi$$

is a bijection: it is injective (since $c \neq 0$) and surjective because for an
y $\psi \in D(\mathbb{R})$, setting $\phi = c^{-1}\psi = e^{-x}\psi$ gives a tes
t function (product of a smooth function with a compactly supported smooth funct
ion is again compactly supported and smooth) with $M_c(\phi) = \psi$.

Now let $\psi \in D(\mathbb{R})$ be arbitrary. By surjectivity, $\psi = c\,\phi$
 for some $\phi \in D(\mathbb{R})$. Applying $(\ast)$:

$$f(\psi) = f(c\,\phi) = 0.$$

Since $\psi$ was arbitrary, $f(\psi) = 0$ for all $\psi \in D(\mathbb{R})$, whic
h is precisely the definition $f = 0$ in $D'(\mathbb{R})$. $\square$

**Conclusion.** The condition that $f \in D'(\mathbb{R})$ must satisfy so that $
cf = 0$ with $c(x) = e^x$ is:

$$\boxed{f = 0 \text{ (the zero distribution)}.}$$

The essential reason is that $e^x$ is a **unit** (nowhere-vanishing smooth funct
ion) in the algebra $C^\infty(\mathbb{R})$, so multiplication by $e^x$ is an aut
omorphism of the test-function space $D(\mathbb{R})$. Hence $e^x f = 0$ forces $
f = 0$, exactly as in ordinary algebra where a non-zero-divisor times $f$ equals
 zero implies $f = 0$.
