## Proof

**Claim:** No. In n-dimensional space, a simplex cannot be defined using more th
an n+1 points under the stated rank condition. The condition forces the number o
f points to be at most n+1.

**Setup.** Let $p_0, p_1, \dots, p_{k-1}$ be $k$ points in $\mathbb{R}^n$. Form
the difference matrix $D$ whose rows (or columns) are the vectors $p_i - p_0$ fo
r $i = 1, \dots, k-1$. Each difference is an $n$-dimensional vector, so $D$ is a
 $(k-1) \times n$ matrix (row convention). The hypothesis is:

$$\operatorname{rank}(D) = k - 1.$$

**Key bound.** The rank of any matrix is bounded by both its number of rows and
its number of columns:

$$\operatorname{rank}(D) \le \min(k-1,\; n).$$

**Deriving the constraint.** Combining the hypothesis $\operatorname{rank}(D) =
k-1$ with the rank bound:

$$k - 1 = \operatorname{rank}(D) \le n \implies k \le n + 1.$$

Therefore the hypothesis $\operatorname{rank}(D) = k-1$ is **only satisfiable wh
en $k \le n+1$**. If $k > n+1$, then $k-1 > n$, and the rank (capped at $n$) can
 never reach $k-1$. The condition is self-contradictory for more than $n+1$ poin
ts.

**Connection to the simplex.** A simplex in $\mathbb{R}^n$ is the convex hull of
 $n+1$ affinely independent points. Affine independence of $k$ points is *equiva
lent* to $\operatorname{rank}(D) = k-1$. Since this rank condition forces $k \le
 n+1$, the maximum number of affinely independent points in $\mathbb{R}^n$ is ex
actly $n+1$. Hence a simplex—requiring full affine independence—can use at most
$n+1$ points, and using more is impossible by the rank obstruction above.

**Conclusion.** It is impossible to define a simplex in $n$-dimensional space us
ing more than $n+1$ points while maintaining $\operatorname{rank}(D) = (\text{nu
mber of points}) - 1$, because the rank of the $n$-column difference matrix cann
ot exceed $n$, whereas the number of points minus one would exceed $n$. The answ
er is **no**.
