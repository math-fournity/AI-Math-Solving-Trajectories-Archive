# Problem

In a specialized data processing network, there are 8 central servers. Every single pair of distinct servers is linked by a unique one-way communication channel. A network configuration is classified as "Optimized" if there are no circular data loops (cycles) where a packet could travel through a sequence of servers and return to its starting point; otherwise, the configuration is classified as "Congested."

Engineers are analyzing the stability and flexibility of these 8-server configurations:

1. Let $k$ be the smallest integer such that there exists a specific configuration of these channels where, no matter which $k-1$ channels you choose to flip (reverse the direction of data flow), the resulting network remains "Congested."

2. Let $m$ be the smallest integer such that, regardless of how the initial one-way channels are oriented between the 8 servers, it is always possible to reach an "Optimized" state by reversing the direction of at most $m$ channels.

Find the value of $k \times m$.
