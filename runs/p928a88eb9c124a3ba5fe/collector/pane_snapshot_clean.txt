## Solving the Congruence Conditions

- **$2 \mid n^{44}+1$**: requires $n$ odd.
- **$17 \mid n^{44}+1$**: Since $n^{16}\equiv 1\pmod{17}$, we get $n^{44}\equiv
n^{12}\equiv (n^4)^3\pmod{17}$. Solving $n^{12}\equiv -1$ yields $n^4\equiv -1\p
mod{17}$. Checking: $2^4=16\equiv -1\pmod{17}$. The four solutions are $n\equiv
2, 8, 9, 15\pmod{17}$.
- **$41 \mid n^{44}+1$**: Since $n^{40}\equiv 1\pmod{41}$, we get $n^{44}\equiv
n^4\pmod{41}$. Need $n^4\equiv -1\pmod{41}$. Checking: $3^4=81\equiv 40\equiv -1
\pmod{41}$. The four solutions are $n\equiv 3, 14, 27, 38\pmod{41}$.

## Applying CRT

We need the smallest odd $n$ with $n\equiv a\pmod{17}$ ($a\in\{2,8,9,15\}$) and
$n\equiv b\pmod{41}$ ($b\in\{3,14,27,38\}$).

Since $17^{-1}\equiv 29\pmod{41}$ (as $17\times 29=493=12\times 41+1$), the CRT

## Verification

**$n=161$ is odd:** $161^{44}+1$ is even, so $2\mid 161^{44}+1$. ✓

**Divisibility by 17:** $161 = 9\times 17 + 8$, so $161\equiv 8\pmod{17}$. Then
$8^4=4096=240\times 17+16\equiv -1\pmod{17}$, so $161^{44}\equiv (8^4)^{11}\equi

**Divisibility by 41:** $161 = 3\times 41 + 38$, so $161\equiv 38\equiv -3\pmod{
41}$. Then $(-3)^4=81\equiv -1\pmod{41}$, so $161^{44}\equiv (38^4)^{11}\equiv (
-1)^{11}=-1\pmod{41}$, giving $41\mid 161^{44}+1$. ✓
