## Answer

**No.** A measurable function $F:[0,1]\to\mathbb{R}$ that is bounded almost ever
ywhere does **not** necessarily have bounded variation on $[0,1]$.

### Counterexample

Let $F = \mathbf{1}_{\mathbb{Q}\cap[0,1]}$, the Dirichlet function:

$$F(x) = \begin{cases} 1, & x \in \mathbb{Q}\cap[0,1],\\ 0, & x \notin \mathbb{Q
}\cap[0,1].\end{cases}$$

**$F$ is measurable.** $\mathbb{Q}\cap[0,1]$ is countable, hence a Borel set, so
 $\mathbf{1}_{\mathbb{Q}\cap[0,1]}$ is a measurable function.

**$F$ is bounded (everywhere, hence a.e.).** $0 \le F(x) \le 1$ for all $x\in[0,
1]$.

**$F$ is not of bounded variation.** Recall the total variation is
$$V(F) = \sup_{\mathcal{P}} \sum_{i=1}^{n} |F(x_i) - F(x_{i-1})|,$$
where the supremum is over all partitions $\mathcal{P}: 0=x_0 < x_1 < \cdots < x
_n = 1$.

For any positive integer $n$, construct a partition as follows. Since both the r
ationals and irrationals are dense in $[0,1]$, we may choose points
$$0 = x_0 < x_1 < x_2 < \cdots < x_{2n} = 1$$
such that $x_0, x_2, x_4, \ldots$ are **irrational** (so $F=0$) and $x_1, x_3, x
_5, \ldots$ are **rational** (so $F=1$). This is possible because between any tw
o distinct reals there exist both a rational and an irrational, allowing us to i
nterleave them in increasing order.

For this partition, every consecutive pair $(x_{i-1}, x_i)$ has one point ration
al and the other irrational, so
$$|F(x_i) - F(x_{i-1})| = 1 \quad \text{for each } i = 1, \ldots, 2n.$$

Hence
$$\sum_{i=1}^{2n} |F(x_i) - F(x_{i-1})| = 2n.$$

Since $n$ is arbitrary, $V(F) \ge 2n \to \infty$, so $V(F) = +\infty$. Therefore
 $F$ is not of bounded variation on $[0,1]$.

### Conclusion

Boundedness almost everywhere (even boundedness everywhere) does not imply bound
ed variation. Bounded variation requires control over the *oscillation* of the f
unction across partitions, which is a strictly stronger condition than mere boun
dedness. The counterexample above is measurable and bounded everywhere, yet has
infinite total variation.
