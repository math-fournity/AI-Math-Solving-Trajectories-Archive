## Proof

The function $f$ is entire, hence analytic on all of $\mathbb{C}$. Consider the
auxiliary entire function
$$g(z) = f(z) - z^2.$$

For every positive integer $n$, evaluating at $z = 1/\sqrt{n}$ (a real, positive
 point):
$$g\!\left(\tfrac{1}{\sqrt{n}}\right) = f\!\left(\tfrac{1}{\sqrt{n}}\right) - \l
eft(\tfrac{1}{\sqrt{n}}\right)^2 = \tfrac{1}{n} - \tfrac{1}{n} = 0.$$

Thus $g$ vanishes on the set $S = \{1/\sqrt{n} : n \in \mathbb{Z}_{>0}\}$. This
set is infinite and has an accumulation point at $0$, which lies in the domain o
f $g$ (since $g$ is entire). By the **Identity Theorem**, an analytic function v
anishing on a set with an accumulation point inside its domain must be identical
ly zero. Therefore
$$g(z) \equiv 0, \quad\text{i.e.,}\quad f(z) = z^2 \text{ for all } z \in \mathb
b{C}.$$

Evaluating at $z = -i$:
$$f(-i) = (-i)^2 = i^2 = -1.$$
