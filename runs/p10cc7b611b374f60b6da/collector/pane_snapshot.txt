## Row-by-Row Analysis

I process the grid row by row (5 rows, each a binary string of length 5). For ea
ch row $r = (r_0, r_1, r_2, r_3, r_4)$, define its **adjacent-sum pattern** $P(r

**Key observation:** The constraint between consecutive rows $r$ and $s$ require
s, for each $j$:
$$(r_j + r_{j+1}) + (s_j + s_{j+1}) = 2$$

This means the pattern of row $s$ must be the **complement** $2 - P(r)$, where c
omplement means replacing each entry $a$ with $2-a$.

## Pattern Alternation

Since each row's pattern forces the next row's pattern to be its complement, the

$$P_0,\; 2{-}P_0,\; P_0,\; 2{-}P_0,\; P_0$$

So the entire configuration is determined by the choice of $P_0$ and the specifi

## Counting Rows per Pattern

$$r_1 = a_0 - r_0,\quad r_2 = a_1 - r_1,\quad r_3 = a_2 - r_2,\quad r_4 = a_3 -
r_3$$

## Computing the Total

$$c(P_0)^3 \times c(2-P_0)^2$$

**Case 1: Self-complementary pattern** $(1,1,1,1)$ with $c = 2$:
$$2^3 \times 2^2 = 32$$

$$c(P)^3 \cdot c(Q)^2 + c(Q)^3 \cdot c(P)^2 = 1 + 1 = 2$$

With 15 such pairs: $15 \times 2 = 30$.
