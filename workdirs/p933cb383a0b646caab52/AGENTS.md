# Problem

In a remote archipelago consisting of $n$ distinct islands ($n \geq 3$), a telecommunications company is designing a network of fiber-optic cables. Each cable connects exactly two islands, and the company ensures that the entire network is connected, meaning it is possible to send a signal between any two islands in the archipelago.

The network is built with a specific structural constraint called "Cycle-Dependent Connectivity." This means that if the engineers identify any closed loop (cycle) of cables within the network and temporarily disable every single cable that forms that specific loop, the network must immediately break into at least two isolated groups of islands with no remaining path between them.

The company wants to maximize the redundancy of their infrastructure while adhering to this strict security protocol. Based on the number of islands $n$, determine the maximum possible number of fiber-optic cables that can be installed in this network.
