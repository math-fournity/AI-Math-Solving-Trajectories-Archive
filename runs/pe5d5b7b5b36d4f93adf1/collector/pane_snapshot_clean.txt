## Setup

Work mod 2 (only parity matters). Let $x_{ij} \in \{0,1\}$ be the number of puls
es at node $(i,j)$ mod 2. Define $R_a = \sum_j x_{aj} \pmod{2}$ (row pulse parit
y) and $C_b = \sum_i x_{ib} \pmod{2}$ (column pulse parity).

A pulse at $(i,j)$ affects cell $(a,b)$ iff $i=a$ or $j=b$. So the parity change
 at $(a,b)$ is:
$$g(a,b) = R_a + C_b + x_{ab} \pmod{2}$$
(the $x_{ab}$ appears 3 times = 1 mod 2). The final parity is $f(a,b) = \text{in
it}(a,b) + g(a,b)$.

## Characterizing Achievable Change Vectors $\mathcal{G}$

The map $L: x \mapsto g$ is linear over $\mathbb{F}_2$. I compute row sums of $g
$:
$$\sum_b g(a,b) = (n+1)R_a + \sum_b C_b \pmod{2}$$

**Even $n$:** $(n+1)$ is odd, so this equals $R_a + \text{colSumTotal}$, varying
 with $a$. I show $L$ is **invertible**: if $L(X)=0$, then $X(J+I)=JX$ where $J=
\mathbf{1}\mathbf{1}^T$. Since $(J+I)^2=I$ (as $J^2=0$ for even $n$), we get $X
= JX(J+I)$. Then $JX = J^2 X(J+I) = 0$, so $X(J+I)=0$, giving $X=0$. Thus $\math
cal{G} = \mathbb{F}_2^{n^2}$ — **every configuration is achievable**, so $N(n)=n
^2$.

**Odd $n$:** $(n+1)$ is even, so row sums of $g$ all equal $\text{colSumTotal}$,
 and column sums all equal $\text{rowSumTotal}$. Since $n$ is odd, these are equ
al. So $\mathcal{G}$ = matrices with all row sums equal and all column sums equa
l (to the same value $s$). Using the decomposition $\mathbb{F}_2^n = \langle\mat
hbf{1}\rangle \oplus V$ (where $V$ = even-sum subspace), the image is $V\otimes
V \oplus \langle\mathbf{1}\mathbf{1}^T\rangle$, with dimension $(n-1)^2+1$.

## Covering Radius for Odd $n$

$\mathcal{G} = \mathcal{C} \cup (\mathcal{C}+\mathbf{1})$ where $\mathcal{C}$ =
matrices with all row/column sums 0 (the cycle space of $K_{n,n}$, dimension $(n
-1)^2$).

**Coset leader weights:** Cosets of $\mathcal{C}$ are determined by row parity v
ector $r$ and column parity vector $c$ (with $\sum r_i = \sum c_j$). The minimum
-weight matrix with these parities is $\max(|R|, |C|)$ where $R=\{i:r_i=1\}$, $C
=\{j:c_j=1\}$:
- *Lower bound:* each row in $R$ needs ≥1 one, each column in $C$ needs ≥1 one.
- *Upper bound:* match elements of $R$ and $C$ in a partial permutation, then pa
ir up remaining rows/columns (adding 2 ones per pair, preserving parities).

**Distance to $\mathcal{G}$:** For matrix $P$ with parities $(r,c)$:
- Distance to $\mathcal{C}$: $\max(|R|,|C|)$
- $P+\mathbf{1}$ has parities $(r+\mathbf{1}, c+\mathbf{1})$, so $R'=\bar{R}$, $
C'=\bar{C}$: distance $\max(n-|R|, n-|C|)$

$$d(P, \mathcal{G}) = \min\!\big(\max(|R|,|C|),\; \max(n-|R|,\, n-|C|)\big)$$

**Maximizing over all valid $(|R|,|C|)$** with $|R|\equiv|C|\pmod{2}$: WLOG $|R|
\leq|C|$, so this becomes $\min(|C|,\, n-|R|)$. To get value $n$, we'd need $|C|
\geq n$ and $|R|\leq 0$, i.e., $(|R|,|C|)=(0,n)$, but $0\not\equiv n\pmod{2}$ fo
r odd $n$. The value $n-1$ is achieved at $(|R|,|C|)=(0,n-1)$ or $(1,n)$ (both s
atisfy parity). So the **covering radius is $n-1$**.

## Result

$$N(n) = \begin{cases} n^2 & \text{if } n \text{ even} \\ n^2 - (n-1) = n^2 - n
+ 1 & \text{if } n \text{ odd} \end{cases}$$

**Verification:** $N(1)=1$ ✓ (single cell always fixable). $N(3)=7$ ✓ (worst cas
e: syndrome $(1,3)$ gives distance $\min(3,2)=2$, so $9-2=7$).

## Final Answer

$$N(10) + N(11) = 100 + 111 = \boxed{211}$$
