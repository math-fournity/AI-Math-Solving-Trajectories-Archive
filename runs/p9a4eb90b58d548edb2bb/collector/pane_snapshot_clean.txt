## Proof

**Notation.** All sums are cyclic over indices mod $n$. The inequality is
$$\sum x_i x_{i+1} \geq \sum x_i^a\, x_{i+1}^b\, x_{i+2}^a.$$

### Step 1: Homogeneity forces $2a + b = 2$.

Replace every $x_i$ by $t\, x_i$ ($t > 0$). The LHS scales as $t^2$; each RHS te
rm scales as $t^{2a+b}$. For the inequality to hold for **all** $t > 0$:

- If $2a + b > 2$: let $t \to \infty$, RHS dominates → contradiction.
- If $2a + b < 2$: let $t \to 0^+$, RHS dominates → contradiction.

Hence $2a + b = 2$, i.e. $b = 2 - 2a$. Since $a, b > 0$, we get $0 < a < 1$.

The inequality becomes
$$\sum x_i x_{i+1} \;\geq\; \sum x_i^a\, x_{i+1}^{\,2-2a}\, x_{i+2}^a. \tag{$\st
ar$}$$

### Step 2: Necessity of $a = \tfrac{1}{2}$ via $n = 4$.

Take $n = 4$ and set $x_1 = x_3 = t,\; x_2 = x_4 = 1$ ($t \geq 0$).

**LHS:** $t\cdot1 + 1\cdot t + t\cdot 1 + 1\cdot t = 4t$.

**RHS:** each term $x_i^a\, x_{i+1}^{2-2a}\, x_{i+2}^a$. The four terms are:
- $t^a \cdot 1 \cdot t^a = t^{2a}$
- $1 \cdot t^{2-2a} \cdot 1 = t^{2-2a}$
- $t^a \cdot 1 \cdot t^a = t^{2a}$
- $1 \cdot t^{2-2a} \cdot 1 = t^{2-2a}$

So RHS $= 2\,t^{2a} + 2\,t^{2-2a}$, and ($\star$) requires
$$h(t) \;:=\; 2t - t^{2a} - t^{2-2a} \;\geq\; 0 \quad \text{for all } t > 0. \ta
g{$\star\star$}$$

Compute at $t = 1$:
- $h(1) = 2 - 1 - 1 = 0$.
- $h'(t) = 2 - 2a\, t^{2a-1} - (2-2a)\, t^{1-2a}$, so $h'(1) = 2 - 2a - (2-2a) =
 0$.
- $h''(t) = -2a(2a-1)\,t^{2a-2} - (2-2a)(1-2a)\,t^{-2a}$, so
$$h''(1) = -2a(2a-1) - (2-2a)(1-2a) = -2a(2a-1) + (2-2a)(2a-1) = (2a-1)\bigl[-2a
 + 2 - 2a\bigr] = (2a-1)(2-4a).$$
$$= (2a-1)\cdot 2(1-2a) = -2(2a-1)^2.$$

So $h''(1) = -2(2a-1)^2 \leq 0$, with equality **only** when $a = \tfrac{1}{2}$.

**If $a \neq \tfrac{1}{2}$:** then $h''(1) < 0$, so $t = 1$ is a **strict local
maximum** of $h$. Since $h(1) = 0$, we have $h(t) < 0$ for $t$ near (but not equ
al to) $1$, contradicting ($\star\star$).

Therefore $a = \tfrac{1}{2}$, which gives $b = 2 - 2\cdot\tfrac{1}{2} = 1$.

### Step 3: Sufficiency — $a = \tfrac{1}{2},\; b = 1$ works for all $n > 2$.

With $a = \tfrac{1}{2}, b = 1$, the RHS term is $x_i^{1/2}\, x_{i+1}\, x_{i+2}^{
1/2} = x_{i+1}\sqrt{x_i\, x_{i+2}}$.

By **AM–GM**: $\sqrt{x_i\, x_{i+2}} \leq \dfrac{x_i + x_{i+2}}{2}$ for all non-n
egative $x_i, x_{i+2}$.

Summing cyclically:
$$\sum_{i=1}^n x_{i+1}\sqrt{x_i\, x_{i+2}} \;\leq\; \frac{1}{2}\sum_{i=1}^n x_{i
+1}\bigl(x_i + x_{i+2}\bigr) = \frac{1}{2}\left(\sum_{i=1}^n x_i\, x_{i+1} + \su
m_{i=1}^n x_{i+1}\, x_{i+2}\right).$$

Both sums on the right equal $\sum x_i\, x_{i+1}$ (they are the same cyclic sum,
 just re-indexed). Hence
$$\text{RHS} \;\leq\; \frac{1}{2}\cdot 2\sum x_i\, x_{i+1} = \sum x_i\, x_{i+1}
= \text{LHS}.$$

This holds for every $n > 2$ and all non-negative $x_i$. Equality holds when $x_
i = x_{i+2}$ for all $i$ (e.g., all $x_i$ equal, or the alternating pattern $x_1
=x_3=\cdots,\; x_2=x_4=\cdots$).

### Conclusion.

The unique pair is $\boxed{a = \dfrac{1}{2},\; b = 1}$.
