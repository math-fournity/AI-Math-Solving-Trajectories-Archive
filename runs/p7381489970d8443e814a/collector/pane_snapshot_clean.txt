## Proof

**Step 1: Reformulate using $p$-adic valuations.**

For $d = \frac{a!b!c!}{10^m}$ to be a natural number with $10 \nmid d$, we need
$m = \min(v_2(a!b!c!),\, v_5(a!b!c!))$, where $v_p(N) = \sum_{k\ge1}\lfloor N/p^
k\rfloor$ is the $p$-adic valuation of $N!$.

Since $v_5(n!) < v_2(n!)$ for all $n \geq 1$ (as $5 > 2$ and Legendre's formula
gives $v_p(n!) = \frac{n - s_p(n)}{p-1}$), we have:
$$v_5(a!)+v_5(b!)+v_5(c!) < v_2(a!)+v_2(b!)+v_2(c!)$$
so $m = v_5(a!)+v_5(b!)+v_5(c!)$.

**Step 2: Apply Legendre's digit-sum formula.**

By Legendre's formula, $v_5(n!) = \frac{n - s_5(n)}{4}$, where $s_5(n)$ is the s
um of base-5 digits of $n$. Therefore:
$$m = \frac{(a+b+c) - (s_5(a)+s_5(b)+s_5(c))}{4} = \frac{2010 - S}{4}$$
where $S = s_5(a)+s_5(b)+s_5(c)$. **Minimizing $m$ is equivalent to maximizing $
S$.**

**Step 3: Express $S$ via carries in base-5 addition.**

Write $2010$ in base 5: $2010 = 3\cdot625 + 1\cdot125 + 0\cdot25 + 2\cdot5 + 0 =
 (31020)_5$, so $s_5(2010)=6$.

Let $k_i$ be the carry from position $i$ to position $i+1$ when adding $a+b+c$ i
n base 5. The digit-sum identity for addition gives:
$$S = s_5(2010) + 4(k_0+k_1+k_2+k_3) = 6 + 4T, \quad T = k_0+k_1+k_2+k_3.$$

**Step 4: Bound the carries.**

Therefore $T = k_0+k_1+k_2+k_3 \leq 8$, giving $S \leq 6 + 32 = 38$.
