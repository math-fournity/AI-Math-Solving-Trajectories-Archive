## Exploration of Small Cases

**$m=0$:** $K(n,0)=\varnothing$ for all $n$.

**$m=1$:** Since $K(\cdot,0)=\varnothing$, every intersection is empty, so $K(n,

**$m=2$:** $K(k,1)\cap K(n-k,1)=\{1,\dots,k\}\cap\{1,\dots,n-k\}=\{1,\dots,\min(

**$m=3$:** $K(k,2)\cap K(n-k,2)=\{k\}\cap\{n-k\}$, empty iff $k\neq n-k$, i.e.,
$n\neq 2k$. So $K(n,3)=\{1,\dots,n\}\setminus\{n/2\}$ (removing $n/2$ if $n$ is

**Pattern:** The stable value of $K(n,m)$ is the set of **nonzero binary submask

## Proof

**Definition.** Let $S(n)=\{k\in\{1,\dots,n\}: k\mathbin{\&} n = k\}$, the set o
f positive integers whose binary representation is a submask of $n$'s.

**Key Lemma.** *For positive integers $a,b$: $S(a)\cap S(b)=\varnothing$ if and
only if $a\mathbin{\&} b = 0$.*

*Proof.* An integer $j$ belongs to $S(a)\cap S(b)$ iff $j\mathbin{\&} a = j$ and
 $j\mathbin{\&} b = j$, i.e., every bit of $j$ is set in both $a$ and $b$. This
means $j$ is a nonzero submask of $a\mathbin{\&} b$. Such $j$ exists iff $a\math
bin{\&} b \neq 0$. $\square$

**Carry Lemma.** *For $1\le k\le n$ with $n-k\ge 0$: $k\mathbin{\&}(n-k)=0$ if a
nd only if $k$ is a submask of $n$ (i.e., $k\in S(n)\cup\{0\}$).*

*Proof.* $k+(n-k)=n$. There are no carries in this binary addition iff $k$ and $
n-k$ share no common set bits, i.e., $k\mathbin{\&}(n-k)=0$. No carries means ev
ery bit of $k$ is also a bit of $n$, i.e., $k\mathbin{\&} n = k$. $\square$

**Fixed Point.** *If $K(n,m)=S(n)$ for all $n\ge 0$, then $K(n,m+1)=S(n)$ for al
l $n$.*

*Proof.* $k\in K(n,m+1)$ iff $K(k,m)\cap K(n-k,m)=\varnothing$, i.e., $S(k)\cap
S(n-k)=\varnothing$ (for $k<n$; for $k=n$, $K(0,m)=\varnothing$ so $n\in K(n,m+1
)$ always). By the two lemmas, $S(k)\cap S(n-k)=\varnothing$ iff $k\mathbin{\&}(
n-k)=0$ iff $k\in S(n)$. Since $n\in S(n)$, we get $K(n,m+1)=S(n)$. $\square$

**Convergence Theorem.** *For all $n\ge 0$ and $m\ge n$, $K(n,m)=S(n)$.*

*Proof by strong induction on $n$.*

**Base:** $n=0$: $K(0,m)=\varnothing=S(0)$ for all $m$. $n=1$: $K(1,m)=\{1\}=S(1
)$ for $m\ge 1$.

**Inductive step:** Assume for all $n'<n$, $K(n',m')=S(n')$ whenever $m'\ge n'$.
 We prove $K(n,m)=S(n)$ for $m\ge n$.

For $m\ge n$, consider $k\in\{1,\dots,n\}$:
- **$k=n$:** $K(n,m-1)\cap K(0,m-1)=K(n,m-1)\cap\varnothing=\varnothing$, so $n\
in K(n,m)$. Also $n\in S(n)$. ✓
- **$1\le k\le n-1$:** Both $k<n$ and $n-k<n$. Since $m\ge n$, we have $m-1\ge n
-1\ge k$ and $m-1\ge n-1\ge n-k$. By the induction hypothesis, $K(k,m-1)=S(k)$ a
nd $K(n-k,m-1)=S(n-k)$. Thus:
$$k\in K(n,m) \iff S(k)\cap S(n-k)=\varnothing \iff k\mathbin{\&}(n-k)=0 \iff k\
in S(n).$$

Therefore $K(n,m)=S(n)$. $\square$

## Computing the Answer
