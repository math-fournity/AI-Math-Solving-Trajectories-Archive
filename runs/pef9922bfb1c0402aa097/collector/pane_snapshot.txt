## Solution

**Method of Characteristics for the Hamilton-Jacobi equation.**

The PDE $u_t + (u_x)^2 = 1$ is rewritten as $u_t + H(u_x) = 0$ with $H(p) = p^2
- 1$.

**Initial data.** At $t = 0$: $u(x,0) = -x^2$, so parameterizing the initial cur
ve by $s$:
$$x_0 = s,\quad t_0 = 0,\quad u_0 = -s^2,\quad p_0 = u_x(x,0) = -2s.$$

**Characteristic ODEs.** For $u_t + H(p) = 0$:
$$\dot{t} = 1,\qquad \dot{x} = H_p(p) = 2p,\qquad \dot{p} = -H_x = 0,\qquad \dot
{u} = -H(p) + p\,H_p(p).$$

Since $H$ is independent of $x$, **$p$ is constant** along each characteristic:
$p = p_0 = -2s$.

**Integrating.** With $\tau = t$:
- $t = \tau$
- $x = s + 2(-2s)\,\tau = s(1 - 4t)$
- $\dot{u} = -(p^2-1) + p\cdot 2p = p^2 + 1 = 4s^2 + 1$, so $u = -s^2 + (4s^2+1)
\,t$.

**Eliminating the parameter.** From $x = s(1-4t)$ we get $s = \dfrac{x}{1-4t}$ (
valid for $t \neq 1/4$). Substituting:

$$u = -s^2 + 4s^2 t + t = s^2(4t-1) + t = \frac{x^2(4t-1)}{(1-4t)^2} + t = \frac
{-x^2}{1-4t} + t.$$

**Solution:**
$$\boxed{u(x,t) = t - \frac{x^2}{1-4t}.}$$

**Verification.**
- Initial condition: $u(x,0) = 0 - x^2 = -x^2$. ✓
- $u_t = 1 - \dfrac{4x^2}{(1-4t)^2}$, $\;u_x = \dfrac{-2x}{1-4t}$, $\;(u_x)^2 =
\dfrac{4x^2}{(1-4t)^2}$.
- $u_t + (u_x)^2 = 1$. ✓

**Blow-up.** For any $x \neq 0$, the term $\dfrac{x^2}{1-4t} \to \infty$ as $t \
to \frac{1}{4}^-$. The characteristics $x = s(1-4t)$ all collapse to $x = 0$ at
$t = 1/4$ (a caustic/shock forms), and the classical solution becomes unbounded.

$$t^* = \dfrac{1}{4}.$$
