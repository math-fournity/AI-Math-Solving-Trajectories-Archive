## Proof

**Setup.** Define $f:[0,1]\to\{0,1\}$ by $f(x)=0$ if $x$ is computable and $f(x)
=1$ otherwise.

**Step 1 — The true value of the integral is $I=1$.**

The set $\mathcal{C}$ of computable real numbers is countable (each computable r
eal is described by a finite Turing machine, and there are countably many such m
achines). Hence $\mathcal{C}\cap[0,1]$ is countable, and every countable subset
of $\mathbb{R}$ has Lebesgue measure zero. Therefore

$$\int_0^1 f(x)\,dx = \mu\big([0,1]\setminus \mathcal{C}\big) = \mu([0,1]) - \mu
(\mathcal{C}\cap[0,1]) = 1 - 0 = 1.$$

So the mathematically correct value is $I=1$.

**Step 2 — Every numerical method running on a computer samples only computable
points.**

A numerical method (quadrature, Monte Carlo, Riemann sums, Simpson's rule, etc.)
 produces a finite or countably infinite sequence of sample points $x_1, x_2, \d
ots$ together with weights $w_1, w_2, \dots$, and outputs

$$\hat I = \sum_i w_i f(x_i) \quad\text{or}\quad \lim_{n\to\infty}\sum_{i=1}^n w
_i f(x_i).$$

The crucial observation: **every number a computer can represent, compute, or ou
tput is computable.** The machine's state is finite; every real number it genera
tes is the output of some algorithm (a Turing machine that produces the number's
 digits to arbitrary precision). Hence every $x_i$ produced by the method lies i
n $\mathcal{C}$.

**Step 3 — At every sampled point, $f=0$.**

Since each $x_i\in\mathcal{C}$, by definition $f(x_i)=0$ for every $i$. Therefor
e

$$\hat I = \sum_i w_i \cdot 0 = 0.$$

This holds for *every* numerical method, regardless of the choice of weights, me
sh refinement strategy, or pseudo-random generator:

- **Deterministic quadrature** (trapezoidal, Simpson, Gaussian): all nodes are e
xplicit algebraic/transcendental constants — computable — so $f=0$ at each node.
- **Monte Carlo with a PRNG**: every pseudo-random stream is a computable sequen
ce, so every sampled $x_i$ is computable, giving $f(x_i)=0$.
- **Adaptive / iterative refinement**: each new node is computed from previous o
nes by an algorithm, preserving computability.
- **Even a hypothetical "limit" method** that enumerates a countable dense set o
f computable points still only hits $\mathcal{C}$, where $f\equiv 0$.

**Step 4 — The discrepancy is irreducible on a classical computer.**

The function $f$ is the indicator of the non-computable reals. A Turing machine
cannot sample a non-computable real — doing so would require an algorithm produc
ing its digits, which is exactly what would make it computable, a contradiction.
 Thus the set $[0,1]\setminus\mathcal{C}$, which carries the entire mass of the
integral, is **invisible** to every algorithmic sampling procedure. The estimato
r $\hat I$ is identically $0$ regardless of how much computation is expended.

**Conclusion.** The true integral is $I=1$, yet **every numerical method execute
d on a computer will always yield $\hat I = 0$**, because any $x$ a computer can
 generate is computable, and $f$ vanishes on precisely those points. The gap bet
ween $1$ (the measure-theoretic truth) and $0$ (the algorithmically observable v
alue) is absolute and cannot be closed by any classical numerical method.
