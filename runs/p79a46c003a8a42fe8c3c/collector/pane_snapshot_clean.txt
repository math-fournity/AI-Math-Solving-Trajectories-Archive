## Proof

**Reformulation.** Since $e^{(s\log s)t} = e^{ts\log s} = s^{ts}$, the integrand
's inner expression is
$$\frac{s}{e^{(s\log s)t}} = \frac{s}{s^{ts}} = s^{1-ts}.$$
So we study $F_x(t) := \sup_{s > x}\, s^{1-ts}$ for $t \in [0,1]$.

---

**Step 1: Locate the supremum for fixed $t > 0$.**

Set $g_t(s) = s^{1-ts} = e^{(1-ts)\log s}$. Then
$$\frac{g_t'(s)}{g_t(s)} = \frac{1}{s} - t(\log s + 1).$$
The unique critical point $s^*(t) > 0$ satisfies
$$t\, s^*(t)\bigl(\log s^*(t) + 1\bigr) = 1. \tag{$\star$}$$

Since $g_t(s) \to 0$ as $s \to 0^+$ and as $s \to +\infty$ (for $t > 0$), this $
s^*(t)$ is the global maximizer of $g_t$ on $(0,\infty)$.

Define the threshold $t_0(x) = \frac{1}{x(\log x + 1)}$, so that $s^*(t_0) = x$.

- **For $0 < t < t_0$:** $s^*(t) > x$, so $F_x(t) = g_t(s^*(t))$.
- **For $t_0 \leq t \leq 1$:** $s^*(t) \leq x$, and $g_t$ is decreasing on $(x,
\infty)$, so $F_x(t) = g_t(x) = x^{1-tx}$.

---

**Step 2: Evaluate $g_t(s^*(t))$ at the critical point.**

From $(\star)$: $ts^* = \frac{1}{\log s^* + 1}$, hence $1 - ts^* = \frac{\log s^
*}{\log s^* + 1}$. Therefore
$$g_t(s^*) = s^{*\,\frac{\log s^*}{\log s^*+1}} = \exp\!\left(\frac{(\log s^*)^2
}{\log s^* + 1}\right).$$

Set $u = \log s^*$, so $t = \frac{1}{e^u(u+1)}$ and $g_t(s^*) = e^{u^2/(u+1)}$.

---

**Step 3: Show $\int_0^{t_0} g_t(s^*(t))\,dt = +\infty$.**

Substitute $t = \frac{1}{e^u(u+1)}$, giving $dt = -\frac{u+2}{e^u(u+1)^2}\,du$.
As $t: 0 \to t_0$, we have $u: +\infty \to \log x$. Thus

$$\int_0^{t_0} g_t(s^*(t))\,dt = \int_{\log x}^{\infty} \frac{u+2}{(u+1)^2}\, \e
xp\!\left(\frac{u^2}{u+1} - u\right) du.$$

Simplify the exponent:
$$\frac{u^2}{u+1} - u = \frac{u^2 - u(u+1)}{u+1} = \frac{-u}{u+1}.$$

So
$$\int_0^{t_0} g_t(s^*(t))\,dt = \int_{\log x}^{\infty} \frac{u+2}{(u+1)^2}\, e^
{-u/(u+1)}\, du. \tag{$\dagger$}$$

**Lower bound.** For $u \geq 1$:
- $\frac{u+2}{(u+1)^2} \geq \frac{1}{2(u+1)}$ (since $\frac{u+2}{u+1} \geq \frac
{1}{2}$ for $u \geq -3$).
- $e^{-u/(u+1)} \geq e^{-1}$ (since $\frac{u}{u+1} \leq 1$ for $u \geq 0$).

Therefore the integrand in $(\dagger)$ satisfies
$$\frac{u+2}{(u+1)^2}\, e^{-u/(u+1)} \;\geq\; \frac{e^{-1}}{2(u+1)}.$$

Consequently,
$$\int_0^{t_0} g_t(s^*(t))\,dt \;\geq\; \frac{e^{-1}}{2}\int_{\log x}^{\infty} \
frac{du}{u+1} \;=\; +\infty.$$

---

**Step 4: Conclusion.**

Since $F_x(t) \geq g_t(s^*(t))$ for $t \in (0, t_0)$ and the integral of the lat
ter over $(0, t_0)$ diverges, we have

$$\int_0^1 F_x(t)\,dt = \int_0^1 \sup_{s > x} \frac{s}{e^{(s\log s)t}}\,dt = +\i
nfty$$

for **every** $x > 0$. The integrand $F_x(t)$ is measurable (it is a supremum of
 continuous functions, hence lower semicontinuous), so this is a valid Lebesgue
integral equal to $+\infty$.

Therefore,
$$\lim_{x \to +\infty}\left(\int_0^1 \sup_{s > x} \frac{s}{e^{(s\log s)t}}\,dt\r
ight) = +\infty.$$
