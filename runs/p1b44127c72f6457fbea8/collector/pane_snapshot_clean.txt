## Solution

We work over a non-perfect field $k$. A convenient choice throughout is $k = \ma
thbb{F}_p(t)$, the rational function field in one variable over $\mathbb{F}_p$ (
where $p$ is a prime). Recall that $k$ is not perfect: the element $t \in k$ has
 no $p$-th root in $k$, since $t \notin k^p = \mathbb{F}_p(t^p)$.

For each part we produce an affine $k$-scheme $X = \operatorname{Spec} A$ and ve

### (a) Reduced but not geometrically reduced

Take
$$A = k[x]/(x^p - t), \qquad X = \operatorname{Spec} A.$$

**$X$ is reduced.** The polynomial $f(x) = x^p - t$ is irreducible over $k$: if
it factored, it would have a root in $k$, i.e. some $u \in k$ with $u^p = t$; bu
t $t \notin k^p$, contradiction. (Equivalently, $x^p - t$ is the minimal polynom
ial of $t^{1/p}$ over $k$, since $[k(t^{1/p}):k] = p$.) Being irreducible, $(x^p
 - t)$ is prime, so $A$ is an integral domain, hence reduced.

**$X$ is not geometrically reduced.** Over $\bar{k}$ we may pick $\alpha \in \ba
r{k}$ with $\alpha^p = t$. Then in $\bar{k}[x]$,
$$x^p - t = x^p - \alpha^p = (x - \alpha)^p,$$
so
$$A \otimes_k \bar{k} \;\cong\; \bar{k}[x]/(x-\alpha)^p.$$
This ring has nilpotents (the class of $x - \alpha$ is nonzero and nilpotent of
index $p$), so it is **not** reduced. Therefore $X_{\bar{k}}$ is not reduced, i.
e. $X$ is not geometrically reduced.

### (b) Connected but not geometrically connected

Take
$$A = k[x]/(x^p - t), \qquad X = \operatorname{Spec} A,$$
the **same** scheme as in part (a).

**$X$ is connected.** As shown above, $A$ is an integral domain, hence $X = \ope
ratorname{Spec} A$ is irreducible (in particular connected).

**$X$ is not geometrically connected.** Over $\bar{k}$, with $\alpha^p = t$,
$$A \otimes_k \bar{k} \;\cong\; \bar{k}[x]/(x-\alpha)^p.$$
This local artinian ring has a single prime ideal $(x-\alpha)$, so $\operatornam
e{Spec}$ of it is a single point — wait, that *is* connected. Let me use a clean
er separable example instead.

Take $k = \mathbb{R}$ and
$$A = \mathbb{R}[x]/(x^2 + 1), \qquad X = \operatorname{Spec} A.$$

**$X$ is connected.** The polynomial $x^2 + 1$ is irreducible over $\mathbb{R}$,
 so $A \cong \mathbb{C}$ is a field. Thus $X = \operatorname{Spec} \mathbb{C}$ i
s a single point, hence connected (even irreducible).

**$X$ is not geometrically connected.** Over $\bar{\mathbb{R}} = \mathbb{C}$,
$$x^2 + 1 = (x - i)(x + i),$$
so
$$A \otimes_{\mathbb{R}} \mathbb{C} \;\cong\; \mathbb{C}[x]/(x-i)(x+i) \;\cong\;
 \mathbb{C} \times \mathbb{C}.$$
By the Chinese remainder theorem (the ideals $(x-i)$ and $(x+i)$ are comaximal i
n $\mathbb{C}[x]$). Therefore
$$X_{\mathbb{C}} = \operatorname{Spec}(\mathbb{C} \times \mathbb{C}) = \operator
name{Spec} \mathbb{C} \;\sqcup\; \operatorname{Spec} \mathbb{C},$$
a disjoint union of **two** points, which is **disconnected**. Hence $X$ is not
geometrically connected.

$$A = k[x]/(x^p - t), \qquad X = \operatorname{Spec} A, \qquad k = \mathbb{F}_p(
t),$$
the same scheme as in part (a).

**$X$ is integral.** As established, $A$ is an integral domain, so $X$ is both r

$$A \otimes_k \bar{k} \;\cong\; \bar{k}[x]/(x - \alpha)^p,$$
