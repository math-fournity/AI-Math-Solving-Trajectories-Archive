**Proof.**

Let $q = vv^*$. Since $v v^*$ is a projection, $q$ is a projection, and $p$ is a
 projection. The hypothesis is
$$q \leq p \leq Cq,$$
i.e., $p - q \geq 0$ and $Cq - p \geq 0$ in the C\*-algebra order.

**Step 1. $q \leq p$ implies $q$ is a subprojection of $p$.**

For projections, $q \leq p$ is equivalent to $pq = q$ (equivalently, $qp = q$).
Indeed, $p - q \geq 0$ and $p - q$ is a projection since $(p-q)^2 = p - pq - qp
+ q = p - q$ when $pq = qp = q$. Conversely, if $q \leq p$ as positive elements,
 then $pqp \geq q$ (multiplying by $p$ on both sides preserves order for positiv
e elements sandwiched by the same element), and since $pqp \leq p\cdot p \cdot p
$... the standard fact is: for projections $p, q$, $q \leq p \iff pq = q$. Hence
 $pq = qp = q$.

**Step 2. Decompose $p$.**

Set $r = p - q$. Since $pq = qp = q$, we have
$$r^2 = (p-q)^2 = p - pq - qp + q = p - q - q + q = p - q = r,$$
and $r^* = r$, so $r$ is a projection. Moreover $r q = (p-q)q = q - q = 0$ and $
q r = 0$, so $r$ and $q$ are **orthogonal** projections, and
$$p = q + r.$$

**Step 3. Use the upper bound $p \leq Cq$.**

The inequality $p \leq Cq$ means $Cq - p \geq 0$. Substituting $p = q + r$ and u
sing $qr = rq = 0$:
$$Cq - p = Cq - q - r = (C-1)q - r.$$
Since $q$ and $r$ are orthogonal, this is a direct sum: $(C-1)q - r$ acts as the
 scalar $(C-1)$ on the "corner" $q\mathcal{A}q$ and as the scalar $-1$ on the co
rner $r\mathcal{A}r$.

**Step 4. Derive $r = 0$.**

Suppose for contradiction that $r \neq 0$. Since $r$ is a nonzero projection, th
ere exists a state $\varphi$ on $\mathcal{A}$ with $\varphi(r) = 1$ (e.g., any s
tate extending the pure state $r\mathcal{A}r \to \mathbb{C}$, $r x r \mapsto$ th
e scalar, via Hahn–Banach; equivalently, in the universal representation pick a
unit vector $\xi$ in the range of $r$). For such a state, $\varphi(q) = 0$ (sinc
e $q \leq 1 - r$ as $q, r$ orthogonal, so $\varphi(q) \leq \varphi(1-r) = 1 - \v
arphi(r) = 0$). Therefore
$$\varphi\bigl((C-1)q - r\bigr) = (C-1)\varphi(q) - \varphi(r) = 0 - 1 = -1 < 0.
$$
But a positive element must have non-negative value under every state. This cont
radicts $(C-1)q - r \geq 0$.

Hence $r = 0$, and therefore
$$p = q + r = q = vv^*.$$

$\blacksquare$
