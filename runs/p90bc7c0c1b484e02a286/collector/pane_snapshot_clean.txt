## 证明

设 $\omega$ 为 $x^{2016}+x^{2015}+\cdots+x+1=0$ 的根。由于

$$x^{2016}+x^{2015}+\cdots+x+1 = \frac{x^{2017}-1}{x-1},$$

任何根都满足 $\omega^{2017}=1$ 且 $\omega \neq 1$。由于 **2017 是质数**，每个满
足 $\omega^{2017}=1$ 且 $\omega\neq 1$ 的根都是 **本原 2017 次单位根**。因此 $\o
mega^0, \omega^1, \omega^2, \ldots, \omega^{2016}$ 构成了所有 2017 个单位根的完
整集合。

**目标求和：**

$$S = \sum_{k=0}^{2016}(1+\omega^k)^{2017}.$$

**步骤 1：二项式展开。**

$$(1+\omega^k)^{2017} = \sum_{j=0}^{2017}\binom{2017}{j}\omega^{kj}.$$

对所有 $k$ 求和并交换求和顺序：

$$S = \sum_{j=0}^{2017}\binom{2017}{j}\sum_{k=0}^{2016}\omega^{kj}.$$

**步骤 2：计算内层和 $T_j = \sum_{k=0}^{2016}\omega^{kj}$。**

- **如果 $2017 \mid j$**：此时 $\omega^{kj} = (\omega^{2017})^{k\cdot(j/2017)} =
 1$，因此 $T_j = 2017$。
- **如果 $2017 \nmid j$**：此时 $\omega^j \neq 1$ 是一个 2017 次单位根，因此

$$T_j = \sum_{k=0}^{2016}(\omega^j)^k = \frac{(\omega^j)^{2017}-1}{\omega^j - 1}
 = \frac{(\omega^{2017})^j - 1}{\omega^j - 1} = \frac{1-1}{\omega^j-1} = 0.$$

**步骤 3：确定哪些 $j \in \{0,1,\ldots,2017\}$ 满足 $2017 \mid j$。**

在范围 $0 \le j \le 2017$ 内，唯一满足 $2017 \mid j$ 的值是 $j=0$ 和 $j=2017$。

**步骤 4：计算 $S$。**

只有 $j=0$ 和 $j=2017$ 这两项有贡献：

$$S = \binom{2017}{0}\cdot T_0 + \binom{2017}{2017}\cdot T_{2017} = 1\cdot 2017
+ 1\cdot 2017 = 2017 + 2017 = \boxed{4034}.$$

所有其他 $j \in \{1,\ldots,2016\}$ 的项都为零，因为 $2017 \nmid j$。

**结论：**

$$\sum_{k=0}^{2016}(1+\omega^k)^{2017} = 4034.$$
