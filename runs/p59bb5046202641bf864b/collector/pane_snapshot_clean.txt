**Step 1: $f$ respects the equivalence relations.**

The hypothesis is
$$y_1 \sim_Y y_2 \iff f^{-1}(y_1) \sim_X f^{-1}(y_2). \tag{$\star$}$$

Setting $y_i = f(x_i)$, this becomes:
$$f(x_1) \sim_Y f(x_2) \iff x_1 \sim_X x_2. \tag{$\star\star$}$$

So $f$ maps $\sim_X$-equivalent points to $\sim_Y$-equivalent points, and reflec

Define $\bar{f}([x]_X) = [f(x)]_Y$.

*Well-defined:* If $[x_1]_X = [x_2]_X$, then $x_1 \sim_X x_2$, so by $(\star\sta

**Step 3: $\bar{f}$ is a bijection.**

Define $\bar{g}: Y/{\sim_Y} \to X/{\sim_X}$ by $\bar{g}([y]_Y) = [f^{-1}(y)]_X$.

*Well-defined:* If $[y_1]_Y = [y_2]_Y$, then $y_1 \sim_Y y_2$, so by $(\star)$,
$f^{-1}(y_1) \sim_X f^{-1}(y_2)$, hence $[f^{-1}(y_1)]_X = [f^{-1}(y_2)]_X$.

*Inverses:* For any $[x]_X$,
$$\bar{g}(\bar{f}([x]_X)) = \bar{g}([f(x)]_Y) = [f^{-1}(f(x))]_X = [x]_X.$$
For any $[y]_Y$,
$$\bar{f}(\bar{g}([y]_Y)) = \bar{f}([f^{-1}(y)]_X) = [f(f^{-1}(y))]_Y = [y]_Y.$$
So $\bar{f}$ is a bijection with $\bar{f}^{-1} = \bar{g}$.
