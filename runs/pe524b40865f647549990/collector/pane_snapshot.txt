Looking at this problem, I need to identify the named concept for the smallest o
rdinal not order-isomorphic ("ordinally similar") to any well-ordered subset of
any chain of an infinite poset $S$.

## Analysis

**Setting up the equivalence.** A chain of $S$ is a totally ordered subset $C \s
ubseteq S$. A subset of a chain $C$ is again totally ordered (by the induced ord
er). For such a subset to be *ordinally similar* to an ordinal $\alpha$, it must
 be **well-ordered** by the induced order and have order type $\alpha$.

Now, any well-ordered subset $W \subseteq S$ is itself totally ordered (well-ord
ered $\Rightarrow$ totally ordered), hence $W$ is a chain of $S$. Conversely, an
y well-ordered subset of a chain of $S$ is a well-ordered subset of $S$. Therefo
re:

> The ordinals ordinally similar to some subset of some chain of $S$ are exactly
 the order types of well-ordered subsets of $S$ (with the induced order from $S$
).

**Existence of a smallest non-representable ordinal.** Consider the collection
$$\mathcal{H}(S) = \{\alpha \in \mathrm{Ord} : \alpha \text{ is order-isomorphic
 to some well-ordered subset of } S\}.$$

This collection is a **set** (not a proper class). The proof follows Hartogs' cl
assical argument: if $\mathcal{H}(S)$ were a proper class, then for every ordina
l $\beta$ there would exist a well-ordered subset of $S$ of order type $\geq \be
ta$. But each such well-ordered subset is a subset of $S$, and the number of sub
sets of $S$ is $2^{|S|}$, which is a set. Since distinct ordinals give distinct
well-ordered subsets (up to the identity on elements), $\mathcal{H}(S)$ is bound
ed in the ordinals and hence is a set.

Since $\mathcal{H}(S)$ is a set of ordinals, its complement in $\mathrm{Ord}$ is
 nonempty (a set of ordinals cannot be cofinal in all of $\mathrm{Ord}$), and th
ere exists a **smallest ordinal not in** $\mathcal{H}(S)$.

**The name.** This smallest ordinal — the least ordinal not order-isomorphic to
any well-ordered subset of $S$ — is the **Hartogs number of $S$**, denoted $\ale
ph(S)$ or $h(S)$.

This generalizes the classical Hartogs number (Hartogs, 1915), which is defined
for a bare set $X$ as the smallest ordinal not injectible into $X$. When $X$ car
ries a partial order, the order-theoretic Hartogs number — the smallest ordinal
not realizable as the order type of a well-ordered subset — is the natural and s
tandard generalization, and it too bears the name **Hartogs number**.

**Illustrative cases.**
- If $S$ is countably infinite (e.g., $S = \mathbb{Q}$ with its usual order), ev
ery well-ordered subset is countable, and every countable ordinal embeds into $\
mathbb{Q}$, so $h(S) = \omega_1$ (the first uncountable ordinal).
- If $S = \mathbb{N}$ with the usual order, well-ordered subsets have order type
 $\leq \omega$, so $h(S) = \omega + 1$.
- If $S$ is an infinite antichain, the only well-ordered subsets are $\emptyset$
 and singletons, so $h(S) = 2$.

In every case the ordinal is well-defined and is called the **Hartogs number** o
f $S$.

## Answer

The smallest ordinal number that is not ordinally similar to any subset of any c
hain of an infinite partially ordered set $S$ is called the **Hartogs number of
$S$**, denoted $\aleph(S)$.
