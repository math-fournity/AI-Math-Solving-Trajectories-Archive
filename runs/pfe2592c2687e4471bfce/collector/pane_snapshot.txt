Looking at this problem, I need to show that for a connected 3-regular (cubic) g
raph, the vertex connectivity $k$ equals the edge connectivity $l$.

**Setup.** Let $G$ be a connected 3-regular graph. Define:
- $k = \kappa(G)$: minimum vertices to remove so the remainder is disconnected o
r a single vertex.
- $l = \lambda(G)$: minimum edges to remove so the graph becomes disconnected.

We use the classical inequality $\kappa(G) \leq \lambda(G) \leq \delta(G) = 3$.
Since $G$ is connected, $\kappa \geq 1$. So $1 \leq \kappa \leq \lambda \leq 3$.
 It suffices to show $\lambda \leq \kappa$ in each case.

---

**Case 1: $\kappa = 1$.** There is a cut vertex $v$. Then $G - v$ has $\geq 2$ c
omponents. Since $\deg(v)=3$, the 3 edges from $v$ distribute among the componen
ts. With 2 components the split is $(1,2)$; with 3 components it is $(1,1,1)$. I
n either case some component $C$ receives exactly 1 edge $e$ from $v$. Since $C$
 is a component of $G-v$, all paths from $C$ to the rest of $G$ pass through $v$
, and $v$ connects to $C$ only via $e$. Thus $e$ is a bridge, giving $\lambda =
1 = \kappa$.

---

**Case 2: $\kappa = 2$.** There is a vertex cut $\{u,w\}$ of size 2 and no cut v
ertex. Let $m \in \{0,1\}$ be the number of edges between $u$ and $w$ (simple gr
aph). The number of edges from $\{u,w\}$ to $G - \{u,w\}$ is $6 - 2m$.

*Subcase 2a: $m = 1$ (u, w adjacent).* There are 4 edges to the components.
- If $\geq 3$ components: by pigeonhole some component gets $\leq 1$ edge, so $\
lambda \leq 1 \leq 2 = \kappa$.
- If 2 components with split $(1,3)$ or $(3,1)$: $\lambda \leq 1 \leq \kappa$.
- If 2 components with split $(2,2)$: $\lambda \leq 2 = \kappa$.

*Subcase 2b: $m = 0$ (u, w not adjacent).* There are 6 edges to the components.
- If $\geq 3$ components: by pigeonhole some component gets $\leq 2$ edges, so $
\lambda \leq 2 = \kappa$.
- If 2 components with split $(a, 6-a)$, $a \leq 3$: if $a \leq 2$, then $\lambd
a \leq 2 = \kappa$. The critical case is split $(3,3)$.

  **The $(3,3)$ split:** Let $C_1, C_2$ be the two components. Vertex $u$ sends
$a$ edges to $C_1$ and $3-a$ to $C_2$; vertex $w$ sends $b$ to $C_1$ and $3-b$ t
o $C_2$, with $a + b = 3$.

  *Claim:* $a \notin \{0, 3\}$. If $a = 0$, then $u$ connects only to $C_2$ and
$w$ (with $b=3$) connects only to $C_1$, while $u,w$ are non-adjacent and $C_1,
C_2$ have no edges between them. Then there is no path from $C_1$ to $C_2$, cont
radicting connectivity of $G$. Similarly $a \neq 3$.

  So $a \in \{1, 2\}$.

  - **$a = 1, b = 2$:** Consider the partition $S = \{u\} \cup C_2$ and $T = \{w
\} \cup C_1$. The set $S$ is connected ($u$ has 2 edges into $C_2$, and $C_2$ is
 connected). The set $T$ is connected ($w$ has 2 edges into $C_1$, and $C_1$ is
connected). The edges crossing the cut $S \mid T$ are exactly: the 1 edge from $
u$ to $C_1$, and the 1 edge from $w$ to $C_2$ (there are no $u$–$w$ edges since
$m=0$, and no $C_1$–$C_2$ edges). Removing these 2 edges disconnects $G$, so $\l
ambda \leq 2 = \kappa$.

  - **$a = 2, b = 1$:** By symmetry (swap $C_1 \leftrightarrow C_2$), the same a
rgument with partition $\{u\} \cup C_1$ vs $\{w\} \cup C_2$ gives $\lambda \leq
2 = \kappa$.

---

**Case 3: $\kappa = 3$.** Since $\lambda \leq \delta(G) = 3 = \kappa$ and $\kapp
a \leq \lambda$, we obtain $\kappa = \lambda = 3$.

---

**Conclusion.** In every case $\lambda \leq \kappa$. Combined with the universal
 inequality $\kappa \leq \lambda$, we get $\kappa = \lambda$, i.e., $k = l$. $\b
lacksquare$
