**Key substitution.** For any number $a$ on the board, define $u = \frac{1}{a+1}
$. I claim the operation transforms $u$-values by simple addition.

Suppose Alice picks $a, b$ and writes $c = \frac{ab-1}{a+b+2}$. Set $x = a+1$, $
y = b+1$, so $a = x-1$, $b = y-1$. Then:

$$ab - 1 = (x-1)(y-1) - 1 = xy - x - y,$$
$$a + b + 2 = (x-1)+(y-1)+2 = x + y.$$

So $c = \frac{xy - x - y}{x+y}$, and therefore

$$c + 1 = \frac{xy - x - y + x + y}{x+y} = \frac{xy}{x+y}.$$

Taking reciprocals:

$$\frac{1}{c+1} = \frac{x+y}{xy} = \frac{1}{x} + \frac{1}{y} = \frac{1}{a+1} + \
frac{1}{b+1}.$$

**Invariant.** The quantity $\sum \frac{1}{a_i + 1}$ (summed over all numbers cu
rrently on the board) is conserved by the operation, since replacing $a, b$ with
 $c$ replaces $\frac{1}{a+1} + \frac{1}{b+1}$ with $\frac{1}{c+1}$, which is equ
al. Since addition is commutative and associative, **the final number is unique
regardless of the order of operations**.

**Computing the final number.** Initially the board holds $2^k - 1$ for $k = 1,
2, \ldots, 100$, so $a_k + 1 = 2^k$ and

$$\sum_{k=1}^{100} \frac{1}{a_k+1} = \sum_{k=1}^{100} \frac{1}{2^k} = 1 - \frac{
1}{2^{100}}.$$

When only one number $N$ remains, the invariant gives

$$\frac{1}{N+1} = 1 - \frac{1}{2^{100}} = \frac{2^{100}-1}{2^{100}}.$$

Hence $N + 1 = \frac{2^{100}}{2^{100}-1}$, so

$$N = \frac{2^{100}}{2^{100}-1} - 1 = \frac{1}{2^{100}-1}.$$

**Sum of all possible final numbers.** Since the final number is unique, the sum
 is just $N = \frac{1}{2^{100}-1}$. Thus $p = 1$, $q = 2^{100}-1$, which are cop
rime. Therefore

$$\log_2(p+q) = \log_2\!\bigl(1 + (2^{100}-1)\bigr) = \log_2(2^{100}) = \boxed{1
00}.$$
