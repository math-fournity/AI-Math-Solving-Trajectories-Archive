## 解答

设 $x_n = n\pi + \dfrac{\pi}{2} - \varepsilon_n$，其中 $\varepsilon_n \to 0^+$ (
$n \to \infty$)，因为 $x = \tan x$ 的根在区间 $(n\pi, n\pi+\pi/2)$ 内趋近于区间
的右端点 $n\pi+\pi/2$。

要求的极限即
$$L = \lim_{n\to\infty} n\,\varepsilon_n.$$

**化简方程。** 由 $x_n = \tan x_n$ 及 $\tan$ 的周期性，
$$\tan\!\left(n\pi + \tfrac{\pi}{2} - \varepsilon_n\right) = \tan\!\left(\tfrac{
\pi}{2} - \varepsilon_n\right) = \cot \varepsilon_n.$$
故方程化为
$$\cot \varepsilon_n = n\pi + \frac{\pi}{2} - \varepsilon_n. \tag{1}$$

**展开 $\cot$。** 对小正数 $\varepsilon_n$，
$$\cot \varepsilon_n = \frac{1}{\varepsilon_n} - \frac{\varepsilon_n}{3} + O(\va
repsilon_n^3).$$
代入 (1):
$$\frac{1}{\varepsilon_n} - \frac{\varepsilon_n}{3} + O(\varepsilon_n^3) = n\pi
+ \frac{\pi}{2} - \varepsilon_n,$$
即
$$\frac{1}{\varepsilon_n} = n\pi + \frac{\pi}{2} - \frac{2\varepsilon_n}{3} + O(
\varepsilon_n^3). \tag{2}$$

**主项分析。** 由 (2) 立即得 $\varepsilon_n \sim \dfrac{1}{n\pi + \pi/2}$，特别
地 $\varepsilon_n = O(1/n) \to 0$，与假设自洽。于是
$$n\,\varepsilon_n = \frac{n}{\,n\pi + \frac{\pi}{2} - \frac{2\varepsilon_n}{3}
+ O(\varepsilon_n^3)\,}.$$
由于 $\varepsilon_n \to 0$，分母中的修正项 $-\dfrac{2\varepsilon_n}{3} + O(\vare
psilon_n^3) \to 0$，故
$$\lim_{n\to\infty} n\,\varepsilon_n = \lim_{n\to\infty} \frac{n}{\,n\pi + \frac
{\pi}{2}\,} = \lim_{n\to\infty} \frac{1}{\,\pi + \frac{\pi}{2n}\,} = \frac{1}{\p
i}.$$

**严格性补充。** 为确认修正项不影响极限，令 $a_n = n\pi + \pi/2$。由 (2)，$\vare
psilon_n = \dfrac{1}{a_n + r_n}$，其中 $r_n = -\dfrac{2\varepsilon_n}{3} + O(\va
repsilon_n^3) = O(1/n)$。因此
$$n\,\varepsilon_n = \frac{n}{a_n + r_n} = \frac{n}{n\pi + \pi/2 + O(1/n)} = \fr
ac{1}{\pi + \pi/(2n) + O(1/n^2)} \xrightarrow{n\to\infty} \frac{1}{\pi}.$$

## 结论

$$\boxed{\lim_{n \to \infty} n \left( n\pi + \frac{\pi}{2} - x_n \right) = \frac
{1}{\pi}}$$
