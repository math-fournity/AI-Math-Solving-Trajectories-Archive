## Solution

We solve Laplace's equation ∇²u = 0 with the Neumann boundary condition ∂u/∂n|_S
 = A cos θ on a sphere of radius R, using spherical coordinates (r, θ, φ) with a
zimuthal symmetry.

**General solution** (azimuthal symmetry, l-th Legendre polynomial P_l):

$$u(r,\theta) = \sum_{l=0}^{\infty}\left(a_l\, r^l + b_l\, r^{-(l+1)}\right) P_l
(\cos\theta).$$

**Compatibility check.** The Neumann problem requires ∮_S ∂u/∂n dS = 0. Indeed,

$$\oint_S A\cos\theta\, dS = A\!\int_0^{2\pi}\!\!\int_0^{\pi}\cos\theta\, R^2\si
n\theta\, d\theta\, d\phi = 2\pi R^2 A\!\left[\tfrac{\sin^2\theta}{2}\right]_0^{
\pi}=0. \;\checkmark$$

So a solution exists, unique up to an additive constant.

---

### (a) Interior problem (r < R)

Finiteness at r = 0 forces b_l = 0 for all l, giving

$$u(r,\theta)=\sum_{l=0}^{\infty} a_l\, r^l\, P_l(\cos\theta).$$

The outward normal on S (for the interior domain) is +e_r, so ∂u/∂n = ∂u/∂r|_{r=
R}:

$$\frac{\partial u}{\partial r}\bigg|_{r=R}=\sum_{l=0}^{\infty} a_l\, l\, R^{l-1
} P_l(\cos\theta)=A\cos\theta = A\,P_1(\cos\theta).$$

Matching coefficients of P_l:

- l = 0: the term vanishes identically (l·R^{l−1} = 0), so **a_0 is arbitrary**
(the Neumann constant).
- l = 1: a_1 · 1 · R^0 = A ⟹ **a_1 = A**.
- l ≥ 2: a_l · l · R^{l−1} = 0 ⟹ a_l = 0.

Hence

$$\boxed{\,u(r,\theta)=a_0 + A\,r\cos\theta = a_0 + A\,z,\qquad r<R.\,}$$

(The solution is a uniform field A z plus an arbitrary constant.)

---

### (b) Exterior problem (r > R)

Requiring u → 0 as r → ∞ forces a_l = 0, giving

$$u(r,\theta)=\sum_{l=0}^{\infty} b_l\, r^{-(l+1)}\, P_l(\cos\theta).$$

For the exterior domain the outward normal on S points **inward**, i.e. −e_r, so
 ∂u/∂n = −∂u/∂r|_{r=R}:

$$\frac{\partial u}{\partial r}=-\sum_{l=0}^{\infty} b_l(l+1)\, r^{-(l+2)} P_l(\
cos\theta),$$

$$\frac{\partial u}{\partial n}\bigg|_{r=R}=\sum_{l=0}^{\infty} b_l(l+1)\, R^{-(
l+2)} P_l(\cos\theta)=A\,P_1(\cos\theta).$$

Matching coefficients:

- l = 0: b_0 · 1 · R^{−2} = 0 ⟹ **b_0 = 0**.
- l = 1: b_1 · 2 · R^{−3} = A ⟹ **b_1 = A R³/2**.
- l ≥ 2: b_l(l+1)R^{−(l+2)} = 0 ⟹ b_l = 0.

Hence

$$\boxed{\,u(r,\theta)=\frac{A\,R^3}{2\,r^2}\cos\theta,\qquad r>R.\,}$$

---

**Verification.**
- Interior: ∇²(Az) = A·∇²z = 0 ✓; ∂u/∂r = A cos θ ✓ at r = R.
- Exterior: u = (AR³/2) r^{−2} cos θ is harmonic for r > 0 ✓; ∂u/∂r = −AR³ r^{−3
} cos θ, so ∂u/∂n = −∂u/∂r|_{R} = A cos θ ✓.

Both solutions satisfy Laplace's equation and the prescribed normal derivative o
n S, confirming the result.
