## Reducing the System

**From condition 1:** $b \equiv -a^b \pmod{2^n}$.

**Substituting into condition 2:** $b^a \equiv (-a^b)^a = (-1)^a a^{ab} = -a^{ab

ab} \equiv -a$, giving:

$$a^{ab-1} \equiv 1 \pmod{2^n} \quad \text{(condition 3)}$$

The system is equivalent to: **condition 1** ($b \equiv -a^b \pmod{2^n}$) and **
condition 3** ($a^{ab-1} \equiv 1 \pmod{2^n}$).

## Mod 4 Analysis

For odd $a, b$: $a^b + b \equiv 0 \pmod{4}$ requires $a \not\equiv b \pmod{4}$.
So exactly one of $a, b$ is $\equiv 1 \pmod{4}$ and the other $\equiv 3 \pmod{4}

## 2-Adic Valuation of Condition 3

Define $s(a) = v_2(a-1)$ if $a \equiv 1 \pmod{4}$, and $s(a) = v_2(a+1)$ if $a \
equiv 3 \pmod{4}$. Note $s(a) \geq 2$ for all odd $a$.

**Case $a \equiv 1 \pmod{4}$:** Since $ab$ is odd, $ab-1$ is even. By the LTE le
mma (using $v_2(a+1)=1$ when $a \equiv 1 \pmod{4}$):

$$v_2(a^{ab-1} - 1) = v_2(a-1) + v_2(ab-1) = s(a) + v_2(ab-1)$$

Condition 3 requires $s(a) + v_2(ab-1) \geq n$.

**Case $a \equiv 3 \pmod{4}$:** Writing $a = -(-a)$ with $-a \equiv 1 \pmod{4}$,

$$v_2(a^{ab-1}-1) = v_2((-a)^{ab-1}-1) = v_2(a+1) + v_2(ab-1) = s(a) + v_2(ab-1)
$$

Same formula. Condition 3: $s(a) + v_2(ab-1) \geq n$.

## Uniqueness of $b$ via Hensel's Lemma

**Case $a \equiv 1 \pmod{4}$:** Define $f(b) = b + a^b$ (2-adic analytic). Then:
- $f(b) \equiv b + 1 \pmod{4}$, so $f(b) \equiv 0 \pmod{4}$ iff $b \equiv 3 \pmo
d{4}$
- $f'(b) = 1 + (\log a)\cdot a^b \equiv 1 \pmod{4}$ (since $v_2(\log a) \geq 2$)

Since $f'$ is a unit everywhere, $f$ is a 2-adic bijection — there is **exactly
one** $b \pmod{2^n}$ satisfying condition 1. Evaluating at $b_0 = -1$: $f(-1) =
-1 + a^{-1} = (1-a)/a$, so $v_2(f(-1)) = v_2(a-1) = s(a)$. The unique root satis

**Computing $v_2(ab-1)$:** Write $b = -1 + 2^{s(a)} t$. Then $ab - 1 = -(a+1) +

Condition 3 becomes: $s(a) + 1 \geq n$, i.e., **$s(a) \geq n-1$**.

**Case $a \equiv 3 \pmod{4}$:** Setting $c = -a \equiv 1 \pmod{4}$, condition 1
becomes $b = c^b \pmod{2^n}$, i.e., $g(b) = b - c^b \equiv 0$. The same Hensel a

**$s(a) \geq n-1$**.

## Enumerating Solutions

## Verification
