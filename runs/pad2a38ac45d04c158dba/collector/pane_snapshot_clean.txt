Looking at this problem, I need to find all primes $p$ whose base-$b$ representa
tion is a permutation of $\{0, 1, \ldots, b-1\}$ (exactly $b$ digits, leading ze
ros preserved), then sum them over all valid bases $b > 1$.

## Setting Up the Divisibility Framework

If $p$ has digits $d_{b-1}, \ldots, d_0$ in base $b$ forming a permutation of $\
{0,\ldots,b-1\}$, the digit sum is:
$$S = 0 + 1 + \cdots + (b-1) = \frac{b(b-1)}{2}$$

Since $b^i \equiv 1 \pmod{b-1}$, we get $p \equiv S \pmod{b-1}$.

**Case 1: $b$ even, $b \geq 4$.** Here $b/2$ is an integer, so $S = (b/2)(b-1) \
equiv 0 \pmod{b-1}$. Thus $(b-1) \mid p$ with $b-1 \geq 3$ and $p \geq b^{b-1} >
 b-1$, so $p$ is **composite**.

**Case 2: $b$ even, $b = 2$.** Then $b-1 = 1$, no divisibility constraint. Digit
s are a permutation of $\{0,1\}$, giving $p = 1$ (binary "01", not prime) or $p
= 2$ (binary "10", **prime**).

**Case 3: $b$ odd, $b \geq 3$.** Let $b-1 = 2m$ (so $b = 2m+1$). Then:
$$S = \frac{(2m+1)(2m)}{2} = m(2m+1) = 2m^2 + m \equiv m \pmod{2m}$$

So $p \equiv m \pmod{2m}$, meaning $p = m(1 + 2k)$ for some integer $k \geq 0$.

- If $m \geq 2$ (i.e., $b \geq 5$): Since $p \geq b^{b-1} = (2m+1)^{2m} \geq 5^4
 = 625 > m$, we have $k \geq 1$, so $p = m \cdot (1+2k)$ with $m \geq 2$ and $(1
+2k) \geq 3$. Thus $p$ is **composite**.
- If $m = 1$ (i.e., $b = 3$): $p = 1 \cdot (1+2k)$, so $p$ is odd — no forced co
mpositeness. This is the **only odd base that can yield primes**.

## Enumerating $b = 3$
