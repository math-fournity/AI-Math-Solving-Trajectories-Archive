### Step 1. Set up the Euler–Lagrange equation

The functional is

$$I(\phi)=\int_0^1 F(t,\phi,\phi',\phi'')\,dt,\qquad F=\frac{\phi''}{\phi}.$$

Since $F$ depends on $\phi$ and $\phi''$ (but not on $\phi'$), the Euler–Lagrang
e equation for a second-order functional is

$$\frac{\partial F}{\partial \phi}-\frac{d}{dt}\frac{\partial F}{\partial \phi'}
+\frac{d^2}{dt^2}\frac{\partial F}{\partial \phi''}=0.$$

Computing each term:

$$\frac{\partial F}{\partial \phi}=-\frac{\phi''}{\phi^2},\qquad \frac{\partial
F}{\partial \phi'}=0,\qquad \frac{\partial F}{\partial \phi''}=\frac{1}{\phi}.$$

For the last term:

$$\frac{d}{dt}\!\left(\frac{1}{\phi}\right)=-\frac{\phi'}{\phi^2},\qquad \frac{d
^2}{dt^2}\!\left(\frac{1}{\phi}\right)=-\frac{\phi''}{\phi^2}+\frac{2(\phi')^2}{
\phi^3}.$$

Substituting into the EL equation:

$$-\frac{\phi''}{\phi^2}+\left(-\frac{\phi''}{\phi^2}+\frac{2(\phi')^2}{\phi^3}\
right)=0 \;\;\Longrightarrow\;\; -\frac{2\phi''}{\phi^2}+\frac{2(\phi')^2}{\phi^
3}=0.$$

Multiplying through by $\phi^3/2$ (valid for $\phi\neq 0$):

$$\boxed{\;\phi\,\phi''=(\phi')^2\;}$$

### Step 2. Solve the ODE

Observe that

$$\frac{d}{dt}\!\left(\frac{\phi'}{\phi}\right)=\frac{\phi''\phi-(\phi')^2}{\phi
^2}=0,$$

so $\phi'/\phi = c$ (constant). Integrating:

$$\ln\phi = ct+d \;\;\Longrightarrow\;\; \phi(t)=A\,e^{ct},\qquad A=e^d.$$

### Step 3. Apply boundary conditions

$$\phi(0)=A=1,\qquad \phi(1)=e^{c}=4 \;\;\Longrightarrow\;\; c=\ln 4.$$

Hence the extremal is

$$\boxed{\;\phi(t)=e^{t\ln 4}=4^{\,t}\;}$$

### Step 4. Verification

- $\phi(0)=4^0=1$ ✓, $\phi(1)=4^1=4$ ✓.
- $\phi'(t)=(\ln 4)\,4^t$, $\phi''(t)=(\ln 4)^2\,4^t$.
- $\phi\,\phi'' = 4^t\cdot(\ln 4)^2\,4^t = (\ln 4)^2\,4^{2t} = (\phi')^2$ ✓, so
the EL equation is satisfied.
- $\phi\in C^\infty([0,1])\subset C^2$ ✓.

### Step 5. Value of the functional

$$I(\phi)=\int_0^1\frac{(\ln 4)^2\,4^t}{4^t}\,dt=\int_0^1(\ln 4)^2\,dt=(\ln 4)^2
=4(\ln 2)^2.$$

### Step 6. Minimality argument

Using the identity

$$\frac{\phi''}{\phi}=\frac{d}{dt}\!\left(\frac{\phi'}{\phi}\right)+\left(\frac{
\phi'}{\phi}\right)^2,$$

we decompose

$$I(\phi)=\left[\frac{\phi'}{\phi}\right]_0^1+\int_0^1\!\left(\frac{\phi'}{\phi}
\right)^2dt.$$

For the extremal $\phi(t)=4^t$, the ratio $\phi'/\phi=\ln 4$ is constant, so the
 boundary term vanishes: $[\ln 4]^1_0=0$, leaving $I=(\ln 4)^2$, which is precis
ely the squared $L^2$-norm of the constant $\ln 4$. By the Cauchy–Schwarz inequa
lity, for any admissible $\phi$ with $\int_0^1(\phi'/\phi)\,dt = \ln\phi(1)-\ln\
phi(0)=\ln 4$ (a fixed quantity determined by the boundary conditions),

$$\int_0^1\!\left(\frac{\phi'}{\phi}\right)^2dt \;\geq\; \left(\int_0^1\frac{\ph
i'}{\phi}\,dt\right)^{\!2} = (\ln 4)^2,$$

with equality iff $\phi'/\phi$ is constant—exactly the extremal $4^t$. When the
boundary term $\left[\phi'/\phi\right]_0^1$ vanishes (which occurs for the extre
mal and is the natural free-endpoint condition), the functional value equals $(\
ln 4)^2$, the global lower bound. Thus $\phi(t)=4^t$ achieves the minimum value

$$\boxed{I_{\min}=(\ln 4)^2=4(\ln 2)^2.}$$
