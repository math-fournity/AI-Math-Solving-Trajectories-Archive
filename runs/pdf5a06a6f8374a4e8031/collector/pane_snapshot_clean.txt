# Solution

## Analyzing the group structure

The relations are $A^4 = 1$, $B^7 = 1$, and $ABA^{-1}B = 1$, i.e., $ABA^{-1} = B
^{-1}$.

**$B$ has order exactly 7.** Since $B^7 = 1$ and $B \neq 1$, and 7 is prime, $|\
langle B \rangle| = 7$.

**$A$ has order exactly 4.** Since $A^4 = 1$ and $A^2 \neq 1$, the order of $A$
is 4 (it divides 4 and is not 1 or 2).

**Conjugation action.** The relation $ABA^{-1} = B^{-1}$ means $A$ acts on $\lan
gle B \rangle$ by inversion. By induction, $A^a B^j A^{-a} = B^{(-1)^a j}$, so:

$$B^j A^a = A^a\, B^{(-1)^a j}.$$

In particular $A^2 B A^{-2} = B^{(-1)^2} = B$, so **$A^2$ is central**.

**Normal form.** Using $B^j A^a = A^a B^{(-1)^a j}$, every word reduces to $A^a
B^b$ with $a \in \mathbb{Z}/4\mathbb{Z}$, $b \in \mathbb{Z}/7\mathbb{Z}$. These
28 normal forms are distinct (this is the semidirect product $\mathbb{Z}/7\mathb
b{Z} \rtimes \mathbb{Z}/4\mathbb{Z}$), so $|G| = 28$.

## Computing all squares

Let $C = A^a B^b$ be an arbitrary element. Then:

$$C^2 = A^a B^b A^a B^b = A^a \cdot A^a B^{(-1)^a b} \cdot B^b = A^{2a}\, B^{\,b
(1 + (-1)^a)}.$$

**Case 1: $a$ even ($a \in \{0, 2\}$).** Then $(-1)^a = 1$, so $C^2 = A^{2a} B^{
2b}$.
- $a = 0$: $C^2 = B^{2b}$. Since $\gcd(2,7) = 1$, as $b$ ranges over $\{0,\dots,
6\}$, $2b \pmod 7$ ranges over all of $\{0,\dots,6\}$. We obtain $\{1, B, B^2, B
^3, B^4, B^5, B^6\}$.
- $a = 2$: $C^2 = A^4 B^{2b} = B^{2b}$, giving the same set.

**Case 2: $a$ odd ($a \in \{1, 3\}$).** Then $(-1)^a = -1$, so $C^2 = A^{2a} B^0
 = A^{2a}$.
- $a = 1$: $C^2 = A^2$.
- $a = 3$: $C^2 = A^6 = A^2$ (since $A^4 = 1$).

## Collecting the squares

The set of squares is $\{1, B, B^2, B^3, B^4, B^5, B^6\} \cup \{A^2\}$.

These 8 elements are distinct: $A^2$ has order 2, while $B^j$ ($j \neq 0$) has o
rder 7 and $1$ has order 1, so $A^2 \notin \{B^j\}$.

## Expressing each square as $C^2$

| Square | As $C^2$ | Verification |
|--------|----------|--------------|
| $1$ | $1^2$ | trivial |
| $B$ | $(B^4)^2$ | $2 \cdot 4 = 8 \equiv 1 \pmod{7}$ |
| $B^2$ | $(B)^2$ | $2 \cdot 1 = 2$ |
| $B^3$ | $(B^5)^2$ | $2 \cdot 5 = 10 \equiv 3 \pmod{7}$ |
| $B^4$ | $(B^2)^2$ | $2 \cdot 2 = 4$ |
| $B^5$ | $(B^6)^2$ | $2 \cdot 6 = 12 \equiv 5 \pmod{7}$ |
| $B^6$ | $(B^3)^2$ | $2 \cdot 3 = 6$ |
| $A^2$ | $(A)^2$ | $2 \cdot 1 = 2$ |

## Answer

The number of elements of $G$ that can be written as $C^2$ for some $C \in G$ is
 $\boxed{8}$, namely:

$$1,\quad B,\quad B^2,\quad B^3,\quad B^4,\quad B^5,\quad B^6,\quad A^2.$$
