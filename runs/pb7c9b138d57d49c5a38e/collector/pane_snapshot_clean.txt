## Setting Up Coordinates

- B = (−b, 0), C = (b, 0) — southern wall BC = 2b on the x-axis
- A = (−a, h), D = (a, h) — northern wall AD = 2a at height h

Define the leg lengths:
- L = AC = BD = √((a+b)² + h²) (equal legs of the isosceles trapezoid)
- M = AB = √((b−a)² + h²)

## Incircle of Triangle ABC (radius 8)

**Area** = ½·BC·h = bh. **Semiperimeter** s₁ = (2b + L + M)/2.

Inradius: r₁ = bh/s₁ = 8, so s₁ = bh/8.

The incircle touches BC at P. Using tangent lengths, BP = s₁ − L, so:
**I_x = P_x = −b + s₁ − L = (M − L)/2**

Since the incircle touches BC (y = 0) with radius 8: **I_y = 8**.

## Incircle of Triangle ABD (radius 15)

**Area** = ½·AD·h = ah. **Semiperimeter** s₂ = (L + 2a + M)/2.

Inradius: r₂ = ah/s₂ = 15, so s₂ = ah/15.

The incircle touches AD at Q. Using tangent lengths, AQ = s₂ − L, so:
**J_x = Q_x = −a + s₂ − L = (M − L)/2**

Since the incircle touches AD (y = h) with radius 15: **J_y = h − 15**.

## Key Observation: I and J Are Vertically Aligned

Both incenters share the same x-coordinate: I_x = J_x = (M − L)/2. Therefore:
IJ = |I_y − J_y| = |8 − (h − 15)| = |23 − h| = 25

Since h > 0: **h = 48**.
