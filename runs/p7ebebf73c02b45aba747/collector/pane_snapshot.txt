## Proof

ositive integers satisfying: for all $i < j$,
$$a_j - a_i \geq \frac{a_i a_j}{25} \iff 25(a_j - a_i) \geq a_i a_j \iff a_j(25
- a_i) \geq 25\,a_i.$$

**Step 1: Bounding the maximum element.** If $a_i \geq 25$, then $25 - a_i \leq
0$, so $a_j(25 - a_i) \leq 0 < 25\,a_i$ for any $a_j > a_i$ — a contradiction. T
herefore every element is at most 24, and $S \subseteq \{1, 2, \ldots, 24\}$.

**Step 2: Reducing to a consecutive-pair condition.** For $y < 25$, the constrai
nt on a pair $(y, x)$ with $x > y$ becomes:
$$x \geq \frac{25y}{25 - y}.$$
Define $f(y) = \left\lceil \frac{25y}{25-y} \right\rceil$. Since $\frac{d}{dy}\f
rac{25y}{25-y} = \frac{625}{(25-y)^2} > 0$, the function $f$ is **strictly incre
asing**.

Because $f$ is increasing, for any $a_j$, the most restrictive constraint comes
from the largest element below it, namely $a_{j-1}$. Thus the full pairwise cond
ition is equivalent to the **consecutive** condition:
$$a_{i+1} \geq f(a_i) \quad \text{for all } i = 1, \ldots, n-1.$$
(If $a_{i+1} \geq f(a_i)$, then for any $j > i$, $a_j \geq a_{i+1} \geq f(a_i)$,
 so all pairs are satisfied.)

**Step 3: Greedy optimality.** Since $f$ is increasing, if $a \leq b$, then any
valid chain starting from $b$ can be replaced by a chain starting from $a$ of eq

 the chain remains valid). Therefore, to maximize chain length, we should:
- Start from the smallest element ($a_1 = 1$), and
- At each step, choose the smallest valid next element ($a_{i+1} = f(a_i)$).

This greedy strategy is optimal.
