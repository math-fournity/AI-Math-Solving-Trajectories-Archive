# Problem

In a remote sector of the galaxy, a communications officer named Lyra is broadcasting a signal to a central hub using four distinct frequencies, labeled 1, 2, 3, and 4. Each transmission attempt is generated by a computer that selects one of the four frequencies with equal probability ($1/4$ each).

Lyra must follow a strict safety protocol regarding interference: a frequency is only successfully recorded in the broadcast log if it does not "resonate" with the frequency immediately preceding it in the sequence. Resonance occurs if the sum of the new frequency and the most recently recorded frequency is exactly 5. If a generated frequency would cause resonance, it is discarded entirely, and she must try again.

The sequence begins with the first frequency generated by the computer, which is always recorded. Lyra continues this process, appending only non-resonating frequencies to her log, until the log contains at least one instance of all four frequencies.

Calculate the expected (average) number of terms in Lyra's final broadcast log.
