## Solution

**Setup.** The cell has $N=3$ particles. State $i$ ($0\le i\le 3$) means $i$ par
ticles of type A and $3-i$ of type B. On division, each particle replicates, so
the parent contains $2i$ type-A and $6-2i$ type-B particles (6 total). The daugh
ter inherits 3 particles drawn uniformly at random from these 6. States 0 and 3
are absorbing (all particles identical).

**Transition probabilities.** The number of type-A particles in the daughter is
hypergeometric: choosing 3 from 6 with $2i$ successes. With $\binom{6}{3}=20$,

$$P(i,j)=\frac{\binom{2i}{j}\binom{6-2i}{3-j}}{20}.$$

*From state 1* ($2i=2$ A, $4$ B):
$$P(1,0)=\tfrac{\binom{2}{0}\binom{4}{3}}{20}=\tfrac{4}{20}=\tfrac15,\quad P(1,1
)=\tfrac{\binom{2}{1}\binom{4}{2}}{20}=\tfrac{12}{20}=\tfrac35,\quad P(1,2)=\tfr
ac{\binom{2}{2}\binom{4}{1}}{20}=\tfrac15,\quad P(1,3)=0.$$

*From state 2* ($2i=4$ A, $2$ B), by symmetry with state 1 (swapping A↔B):
$$P(2,0)=0,\quad P(2,1)=\tfrac15,\quad P(2,2)=\tfrac35,\quad P(2,3)=\tfrac15.$$

**Absorption probabilities.** Let $a_i=P(\text{absorb at }3\mid i)$. Then $a_0=0
,\ a_3=1$, and
$$a_1=\tfrac35 a_1+\tfrac15 a_2,\qquad a_2=\tfrac15 a_1+\tfrac35 a_2+\tfrac15.$$

The first gives $2a_1=a_2$; the second gives $2a_2=a_1+1$. Substituting $a_2=2a_
1$: $4a_1=a_1+1$, so $a_1=\tfrac13$, $a_2=\tfrac23$.

Hence the absorption probabilities are:

| Starting state | Absorb at 0 (all B) | Absorb at 3 (all A) |
|---|---|---|
| 1 | $\tfrac23$ | $\tfrac13$ |
| 2 | $\tfrac13$ | $\tfrac23$ |

(From state 0: absorb at 0 w.p. 1; from state 3: absorb at 3 w.p. 1.)

**Expected times to absorption.** Let $t_i=E[\text{steps to absorption}\mid i]$,
 with $t_0=t_3=0$:
$$t_1=1+\tfrac35 t_1+\tfrac15 t_2,\qquad t_2=1+\tfrac15 t_1+\tfrac35 t_2.$$

These give $2t_1-t_2=5$ and $2t_2-t_1=5$. Adding: $t_1+t_2=10$; subtracting: $t_
1=t_2$. Therefore
$$t_1=t_2=5.$$

**Verification via the fundamental matrix.** The transient submatrix is
$$Q=\begin{pmatrix}3/5&1/5\\1/5&3/5\end{pmatrix},\qquad I-Q=\begin{pmatrix}2/5&-
1/5\\-1/5&2/5\end{pmatrix},\quad \det(I-Q)=\tfrac{3}{25}.$$
$$N=(I-Q)^{-1}=\begin{pmatrix}10/3&5/3\\5/3&10/3\end{pmatrix},\qquad N\mathbf{1}
=\begin{pmatrix}5\\5\end{pmatrix}.\ \checkmark$$
With $R=\begin{pmatrix}1/5&0\\0&1/5\end{pmatrix}$, the absorption matrix $B=NR=\
begin{pmatrix}2/3&1/3\\1/3&2/3\end{pmatrix}$, confirming the absorption probabil
ities above.

**Summary for $N=3$.**

- **Absorption probabilities:** From state 1, the cell is absorbed at state 0 wi
th probability $\frac{2}{3}$ and at state 3 with probability $\frac{1}{3}$. From
 state 2, the cell is absorbed at state 0 with probability $\frac{1}{3}$ and at
state 3 with probability $\frac{2}{3}$. (States 0 and 3 are already absorbed.)
- **Expected time to absorption:** From state 1: **5** generations. From state 2
: **5** generations. (From states 0 or 3: 0.)
