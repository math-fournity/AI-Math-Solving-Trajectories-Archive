## Solution

We compute $E\!\left[(B_t-1)^2 \int_0^t (B_s+1)^2\,dB_s\right]$.

**Step 1: Expand both factors.**

Set $X = B_t$ and $Y = \int_0^t B_s\,ds$. Then $(B_t-1)^2 = X^2 - 2X + 1$.

For the Itô integral, expand $(B_s+1)^2 = B_s^2 + 2B_s + 1$ and use:
- $\int_0^t B_s\,dB_s = \tfrac12(B_t^2 - t)$,
- $\int_0^t 1\,dB_s = B_t$,
- $\int_0^t B_s^2\,dB_s = \tfrac13 B_t^3 - \int_0^t B_s\,ds$ (from Itô on $B_t^3
$: $d(B_t^3)=3B_t^2\,dB_t+3B_t\,dt$).

So
$$\int_0^t (B_s+1)^2\,dB_s = \tfrac13 X^3 + X^2 + X - t - Y \;=:\; C.$$

**Step 2: Multiply out and take expectations.**

$$E[AC] = E\!\left[(X^2-2X+1)\left(\tfrac13 X^3+X^2+X-t-Y\right)\right].$$

Expanding and collecting by monomial:

| Term | Coefficient | $E[\cdot]$ |
|------|------------|-----------|
| $X^5$ | $\frac13$ | $0$ (odd Gaussian moment) |
| $X^4$ | $\frac13$ | $\frac13\cdot 3t^2 = t^2$ |
| $X^3$ | $-\frac23$ | $0$ |
| $X^2$ | $-(t+1)$ | $-(t+1)t = -t^2-t$ |
| $X^2Y$ | $-1$ | $-E[X^2Y]$ |
| $X$ | $2t+1$ | $0$ |
| $XY$ | $2$ | $2\,E[XY]$ |
| const | $-t$ | $-t$ |
| $Y$ | $-1$ | $-E[Y]=0$ |

**Step 3: Evaluate the cross terms.**

$E[Y] = \int_0^t E[B_s]\,ds = 0$.

$$E[XY] = E\!\left[B_t\int_0^t B_s\,ds\right] = \int_0^t E[B_t B_s]\,ds = \int_0
^t s\,ds = \frac{t^2}{2}.$$

For $E[X^2Y] = \int_0^t E[B_t^2 B_s]\,ds$: write $B_t = B_s + (B_t-B_s)$ with $B
_t-B_s\sim N(0,t-s)$ independent of $B_s$. Then
$$E[B_t^2 B_s] = E[B_s^3] + 2E[B_s^2(B_t-B_s)] + E[B_s(B_t-B_s)^2] = 0 + 0 + 0 =
 0,$$
since $E[B_s^3]=0$, $E[B_s^2]\cdot E[B_t-B_s]=0$, and $E[B_s]\cdot E[(B_t-B_s)^2
]=0$. Hence $E[X^2Y]=0$.

**Step 4: Combine.**

$$E[AC] = 0 + t^2 + 0 + (-t^2 - t) - 0 + 0 + 2\cdot\frac{t^2}{2} - t - 0 = t^2 -
 2t.$$

**Sanity check:** At $t=0$, both factors vanish, so the expectation is $0 = 0^2
- 2\cdot 0$. ✓

$$\boxed{E\!\left[(B_t-1)^2\int_0^t (B_s+1)^2\,dB_s\right] = t^2 - 2t}$$
