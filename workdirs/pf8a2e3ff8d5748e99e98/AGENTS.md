# Problem

A high-security data warehouse consists of a square grid of 100 storage vaults, organized into 10 rows and 10 columns. To minimize the risk of a chain-reaction breach, a security consultant must assign a unique security clearance level—represented by the integers from 1 to 100—to each individual vault.

The consultant is restricted by a structural integrity constraint: the sum of the clearance levels of any two "adjacent" vaults (those sharing a common wall) must not exceed a certain total security threshold, $S$.

If the consultant arranges the clearance levels across the grid to be as balanced as possible, what is the smallest possible integer value for $S$ that allows all 100 levels to be assigned while satisfying the constraint for every pair of adjacent vaults?
