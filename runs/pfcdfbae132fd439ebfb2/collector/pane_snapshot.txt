## Proof

**Setup.** The $6\times 6$ grid is tiled by 18 dominoes ($2\times 1$ or $1\times
 2$). There are 5 horizontal aisles $H_1,\dots,H_5$ (between consecutive rows) a
nd 5 vertical aisles $V_1,\dots,V_5$ (between consecutive columns). An aisle is
*clear* if no domino crosses it. We seek $n = \min_{\text{tilings}}(\text{clear
aisles})$.

**Key definitions.** Let $c_i$ = number of vertical dominoes straddling rows $i$
 and $i+1$ (so $H_i$ is crossed iff $c_i \ge 1$). Let $d_j$ = number of horizont
al dominoes straddling columns $j$ and $j+1$ (so $V_j$ is crossed iff $d_j \ge 1
$).

**Parity lemma.** Every $c_i$ and $d_j$ is even.

*Proof for $c_i$:* In row $i$, let $h_i$ = number of horizontal dominoes entirel
y within row $i$. Counting cells in row $i$:
$$2h_i + c_{i-1} + c_i = 6 \quad (\text{with } c_0 = c_6 = 0).$$
Since $6$ and $2h_i$ are both even, $c_1 = 6 - 2h_1$ is even, and inductively $c
_i = 6 - 2h_i - c_{i-1}$ is even. The argument for $d_j$ is identical (by symmet
ry on columns). $\square$

**Lower bound: at least 1 clear aisle.** Let $k$ = number of crossed horizontal
aisles, $m$ = number of crossed vertical aisles. Since each $c_i$ is even, a cro
ssed $H_i$ has $c_i \ge 2$, so $\sum c_i \ge 2k$. Similarly $\sum d_j \ge 2m$. T
he total domino count is:
$$\sum_{i=1}^{5} c_i + \sum_{j=1}^{5} d_j = 18.$$
Thus $2k + 2m \le 18$, giving $k + m \le 9$. Since there are 10 aisles total, at
 least $10 - 9 = 1$ aisle is clear. So $n \ge 1$.

**Upper bound: a tiling with exactly 1 clear aisle.** We construct a tiling achi
eving $k+m = 9$ (all aisles crossed except $V_3$), with all $c_i = 2$ and $d_1 =
 d_2 = d_4 = d_5 = 2$, $d_3 = 0$.

The 18 dominoes are:

| Row | Dominoes |
|-----|----------|
| 1 | $(1,1)\text{-}(1,2)$, $(1,4)\text{-}(1,5)$ horizontal; $(1,3)\text{-}(2,3)
$, $(1,6)\text{-}(2,6)$ vertical |
| 2 | $(2,4)\text{-}(2,5)$ horizontal; $(2,1)\text{-}(3,1)$, $(2,2)\text{-}(3,2)
$ vertical |
| 3 | $(3,5)\text{-}(3,6)$ horizontal; $(3,3)\text{-}(4,3)$, $(3,4)\text{-}(4,4)
$ vertical |
| 4 | $(4,1)\text{-}(4,2)$ horizontal; $(4,5)\text{-}(5,5)$, $(4,6)\text{-}(5,6)
$ vertical |
| 5 | $(5,2)\text{-}(5,3)$ horizontal; $(5,1)\text{-}(6,1)$, $(5,4)\text{-}(6,4)
$ vertical |
| 6 | $(6,2)\text{-}(6,3)$, $(6,5)\text{-}(6,6)$ horizontal |

**Verification:** Every cell $(r,c)$ for $1\le r,c\le 6$ is covered exactly once
 (checked row by row). The vertical domino counts: $c_1=2$ (cols 3,6), $c_2=2$ (
cols 1,2), $c_3=2$ (cols 3,4), $c_4=2$ (cols 5,6), $c_5=2$ (cols 1,4) — all hori
zontal aisles crossed. The horizontal domino counts: $d_1=2$, $d_2=2$, $d_3=0$,
$d_4=2$, $d_5=2$ — all vertical aisles crossed except $V_3$. Total dominoes: $10
 + 8 = 18$. ✓

This tiling has exactly **1 clear aisle** ($V_3$), so $n \le 1$.

**Conclusion.** Combining $n \ge 1$ and $n \le 1$:

$$\boxed{n = 1}$$
