$$K = \tfrac{1}{2}(\mathbf b + t\mathbf c),\quad L = \tfrac{1}{2}(\mathbf c + v\

**Step 1: Reduce $OP = OQ$ to a metric relation.**

$$O\cdot\mathbf b = \tfrac{1}{2}|\mathbf b|^2, \qquad O\cdot\mathbf c = \tfrac{1

Then
$$|OP|^2 = |O - t\mathbf c|^2 = |O|^2 - 2t(O\cdot\mathbf c) + t^2|\mathbf c|^2 =
 |O|^2 - t|\mathbf c|^2 + t^2|\mathbf c|^2 = |O|^2 - t(1-t)|\mathbf c|^2,$$
$$|OQ|^2 = |O - v\mathbf b|^2 = |O|^2 - v(1-v)|\mathbf b|^2.$$
So $OP = OQ \iff t(1-t)|\mathbf c|^2 = v(1-v)|\mathbf b|^2$, i.e.,
$$AP \cdot PC = AQ \cdot QB. \tag{$\star$}$$

**Step 2: Use the tangency condition.**

$$G\cdot(v\mathbf b - t\mathbf c) = M\cdot(v\mathbf b - t\mathbf c) = \tfrac{1}{

**Step 3: Determine $G\cdot\mathbf b$ and $G\cdot\mathbf c$ from $|GK|=|GM|$ and

$$K - M = \tfrac{1}{2}(\mathbf b - v\mathbf b) = \tfrac{1-v}{2}\,\mathbf b.$$
$$|K|^2 - |M|^2 = \tfrac{1}{4}\big(|\mathbf b|^2 + 2t(\mathbf b\cdot\mathbf c) +

So $2G\cdot\frac{1-v}{2}\mathbf b = \frac{1-v}{4}\big((1+v)|\mathbf b|^2 + 2t(\m
athbf b\cdot\mathbf c)\big)$, giving (since $v\ne 1$):
$$G\cdot\mathbf b = \tfrac{1}{4}\big((1+v)|\mathbf b|^2 + 2t(\mathbf b\cdot\math

By the symmetric computation from $|G-L|^2 = |G-M|^2$ (with $L - M = \frac{1-t}{

$$G\cdot\mathbf c = \tfrac{1}{4}\big((1+t)|\mathbf c|^2 + 2v(\mathbf b\cdot\math

$$v(1+v)|\mathbf b|^2 - t(1+t)|\mathbf c|^2 = 2v^2|\mathbf b|^2 - 2t^2|\mathbf c

$$v(1+v-2v)|\mathbf b|^2 = t(1+t-2t)|\mathbf c|^2,$$
$$v(1-v)|\mathbf b|^2 = t(1-t)|\mathbf c|^2.$$

This is precisely $(\star)$, i.e., $AP\cdot PC = AQ\cdot QB$.
