# Solution of $y''' - y'' + y' - y = \sec x$

## Step 1: Homogeneous Solution

The characteristic equation of $y''' - y'' + y' - y = 0$ is

$$r^3 - r^2 + r - 1 = 0 \implies (r-1)(r^2+1) = 0,$$

giving roots $r = 1,\, i,\, -i$. The homogeneous solution is

$$y_h = C_1 e^x + C_2 \cos x + C_3 \sin x.$$

## Step 2: Factor the Operator

Note that $D^3 - D^2 + D - 1 = (D-1)(D^2+1)$. Setting $w = (D-1)y = y' - y$, the
 equation becomes

$$w'' + w = \sec x.$$

## Step 3: Solve $w'' + w = \sec x$ (Variation of Parameters)

The homogeneous solutions are $\cos x, \sin x$ with Wronskian $W = \cos x \cdot
\cos x - (-\sin x)\sin x = 1$. By variation of parameters:

$$w_p = -\cos x \int \sin x \sec x\, dx + \sin x \int \cos x \sec x\, dx = -\cos
 x \int \tan x\, dx + \sin x \int 1\, dx$$

$$= \cos x \ln|\cos x| + x \sin x.$$

**Verification:** $w_p' = -\sin x \ln|\cos x| + x\cos x$, and $w_p'' = -\cos x\l
n|\cos x| + \sec x - x\sin x$, so $w_p'' + w_p = \sec x$. ✓

## Step 4: Solve $y' - y = w$ (Integrating Factor)

The general solution of $y' - y = w$ is $y = e^x \int e^{-x} w\, dx$. The homoge
neous part $A\cos x + B\sin x$ in $w$ produces, via $e^x\int e^{-x}(A\cos x + B\
sin x)\,dx$, terms that are absorbed into $C_2\cos x + C_3\sin x$ (the homogeneo
us solution of the original equation). The particular solution is:

$$y_p = e^x \int e^{-x}\bigl(\cos x\ln|\cos x| + x\sin x\bigr)\, dx.$$

### Evaluating the integrals

**Integral 1:** $\int e^{-x} x\sin x\, dx$. Using $\int e^{-x}\sin x\, dx = -\fr
ac{e^{-x}}{2}(\sin x + \cos x)$ and integration by parts ($u=x$, $dv=e^{-x}\sin
x\, dx$):

$$\int e^{-x} x\sin x\, dx = -\frac{e^{-x}}{2}\bigl[x\sin x + (x+1)\cos x\bigr].
$$

**Integral 2:** $\int e^{-x}\cos x\ln|\cos x|\, dx$. Integration by parts with $
u = \ln|\cos x|$, $dv = e^{-x}\cos x\, dx$ (so $v = \frac{e^{-x}}{2}(\sin x - \c
os x)$, $du = -\tan x\, dx$):

$$= \frac{e^{-x}(\sin x - \cos x)}{2}\ln|\cos x| + \frac{1}{2}\int e^{-x}(\sin x
 - \cos x)\tan x\, dx.$$

Expanding $(\sin x - \cos x)\tan x = \frac{\sin^2 x}{\cos x} - \sin x = \sec x -
 \cos x - \sin x$, and using $\int e^{-x}(\cos x + \sin x)\,dx = -e^{-x}\cos x$:

$$\int e^{-x}\cos x\ln|\cos x|\, dx = \frac{e^{-x}(\sin x - \cos x)}{2}\ln|\cos
x| + \frac{1}{2}\int e^{-x}\sec x\, dx + \frac{e^{-x}\cos x}{2}.$$

### Combining

$$y_p = e^x\left[\frac{e^{-x}(\sin x - \cos x)}{2}\ln|\cos x| + \frac{1}{2}\int
e^{-x}\sec x\, dx + \frac{e^{-x}\cos x}{2} - \frac{e^{-x}}{2}\bigl(x\sin x + (x+
1)\cos x\bigr)\right]$$

$$= \frac{e^x}{2}\int e^{-x}\sec x\, dx + \frac{1}{2}(\sin x - \cos x)\ln|\cos x
| - \frac{x}{2}(\cos x + \sin x).$$

(The $\cos x/2$ and $-(x+1)\cos x/2$ terms combine to $-x\cos x/2$.)

## Step 5: General Solution

$$\boxed{y = C_1 e^x + C_2 \cos x + C_3 \sin x + \frac{e^x}{2}\int e^{-x}\sec x\
, dx + \frac{1}{2}(\sin x - \cos x)\ln|\cos x| - \frac{x}{2}(\cos x + \sin x)}$$

where $\int e^{-x}\sec x\, dx$ denotes any fixed antiderivative (its constant of
 integration is absorbed into $C_1$). This integral is non-elementary, which is
expected since $\sec x$ combined with $e^{-x}$ does not admit a closed-form anti
derivative.
