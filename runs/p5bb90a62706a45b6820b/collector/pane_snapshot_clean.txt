## Setup

A regular icosahedron has 12 vertices, 30 edges, 20 equilateral triangular faces
. Each vertex has degree 5. The 12 vertices form 6 antipodal pairs. I pick verte
x $V$ and its opposite $W$.

**Structure:** 5 faces meet at $V$ (top cap), 5 faces meet at $W$ (bottom cap),
and 10 faces form a belt between them. The belt faces alternate: 5 "up-type" (sh
aring an edge with the top pentagon) and 5 "down-type" (sharing an edge with the
 bottom pentagon).

**Key constraint:** Any path from $V$ to $W$ must traverse: top face → [up-belt
→ down-belt]* → bottom face. Since belt types must alternate, the number of belt
 faces crossed is always **even** (2, 4, ...).

## Computing the 4-face path (1 top + 2 belt + 1 bottom)

I unfold a strip of 4 faces into the plane. Using edge length $a = 4$ (equilater
al triangle height $= 2\sqrt{3}$):

**Face 1** ($V A_4 A_1$, top): $A_4 = (0,0)$, $A_1 = (4,0)$, $V = (2, 2\sqrt{3})
$.

**Face 2** ($A_4 A_1 B_2$, belt, shares edge $A_4 A_1$): $B_2 = (2, -2\sqrt{3})$
 (reflected below).

**Face 3** ($A_4 B_2 B_4$, belt, shares edge $A_4 B_2$): Reflecting $A_1$ across
 edge $A_4 B_2$ gives $B_4 = (-2, -2\sqrt{3})$.
- Verify: $|B_4 - A_4| = \sqrt{4+12} = 4$ ✓, $|B_4 - B_2| = \sqrt{16} = 4$ ✓

**Face 4** ($B_2 B_4 W$, bottom, shares edge $B_2 B_4$): $W = (0, -4\sqrt{3})$ (
reflected below the horizontal edge $B_2 B_4$).
- Verify: $|W - B_2| = \sqrt{4+12} = 4$ ✓, $|W - B_4| = \sqrt{4+12} = 4$ ✓

**Straight-line distance** from $V = (2, 2\sqrt{3})$ to $W = (0, -4\sqrt{3})$:
$$d = \sqrt{(0-2)^2 + (-4\sqrt{3} - 2\sqrt{3})^2} = \sqrt{4 + 108} = \sqrt{112}
= 4\sqrt{7}$$

**Validity check** — the line $(2-2t,\; 2\sqrt{3}-6\sqrt{3}t)$ must cross each s

- Edge $B_2 B_4$ ($y = -2\sqrt{3}$, $x \in [-2,2]$): $t = 2/3$, point $(2/3, -2\
sqrt{3})$ ✓

All crossings are interior to the edges, in correct order. **The geodesic is val

## Checking the 6-face path (1 top + 4 belt + 1 bottom)

Continuing the unfolding two more faces to the left yields $W = (-4, -4\sqrt{3})
$:
$$d = \sqrt{(-4-2)^2 + (-4\sqrt{3}-2\sqrt{3})^2} = \sqrt{36 + 108} = \sqrt{144}
= 12$$

This is longer than $4\sqrt{7} \approx 10.58$.

## Ruling out other paths

- **Odd belt faces (3, 5, ...):** Impossible — belt types must alternate, requir
ing an even count.
- **5-face paths (2 top + 2 belt + 1 bottom):** The straight line passes through
 a vertex (degenerate — verified: the line from $V$ only touches shared edges at
 $V$ itself).
- **Paths with 8+ belt faces:** Even longer than the 6-face path.
- **By 5-fold symmetry:** All 4-face paths give the same distance $\sqrt{112}$;
all 6-face paths give 12.

## Sanity check

The 3D straight-line (through interior) distance between antipodal vertices is $
2R = 2\sqrt{10 + 2\sqrt{5}} \approx 7.61$, which is less than the surface path $
4\sqrt{7} \approx 10.58$ — consistent, since the surface path must be longer.

## Result

The shortest surface path is $\sqrt{112}$ meters, so $n = 112$.
