## Proof

The answer is **No**. We provide an explicit counterexample.

**Counterexample.** Let $X = [0,1]$ with the usual topology (compact), and let $
f: X \to X$ be defined by $f(x) = x/2$, which is continuous.

**Computing $Y$.** We have:
$$f(X) = [0, 1/2], \quad f^2(X) = [0, 1/4], \quad \ldots, \quad f^n(X) = [0, 2^{
-n}].$$

The sets $f^n(X) = [0, 2^{-n}]$ form a decreasing nested sequence of compact set
s, so:
$$Y = \bigcap_{n \in \mathbb{N}} f^n(X) = \bigcap_{n \in \mathbb{N}} [0, 2^{-n}]
 = \{0\}.$$

**Choosing $A$.** Set $A = \{0\}$. Then $A \subseteq Y = \{0\}$, and:
$$\overline{A} = \overline{\{0\}} = \{0\} = Y.$$

So the hypothesis $\overline{A} = Y$ is satisfied.

**Conclusion.** However:
$$\overline{A} = \{0\} \neq [0,1] = X.$$

Therefore $\overline{A} = Y$ does **not** imply $\overline{A} = X$.

**Remark.** The implication would hold only if $Y$ were dense in $X$ (i.e., $\ov
erline{Y} = X$), since $\overline{A} = Y$ gives $\overline{A} = Y \subseteq \ove
rline{Y}$, and we'd need $\overline{Y} = X$. The counterexample shows $Y$ need n
ot be dense in $X$: here $Y = \{0\}$ is a single point, far from dense in $[0,1]
$.
