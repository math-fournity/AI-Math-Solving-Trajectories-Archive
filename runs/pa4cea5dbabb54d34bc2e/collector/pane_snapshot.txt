## Part (a): Christoffel symbols of the second kind

The metric is diagonal with components
$$g_{11}=x^1,\qquad g_{22}=x^2,\qquad g_{12}=g_{21}=0,$$
so that
$$g^{11}=\frac{1}{x^1},\qquad g^{22}=\frac{1}{x^2},\qquad g^{12}=0.$$

The only non-vanishing partial derivatives of the metric components are
$$\partial_1 g_{11}=1,\qquad \partial_2 g_{22}=1.$$

Using $\Gamma^k_{ij}=\tfrac12 g^{kl}\bigl(\partial_i g_{jl}+\partial_j g_{il}-\p
artial_l g_{ij}\bigr)$:

- **$\Gamma^1_{ij}$:** Only $l=1$ contributes (since $g^{12}=0$):
$$\Gamma^1_{11}=\tfrac12 g^{11}\,\partial_1 g_{11}=\frac{1}{2x^1},\qquad \Gamma^
1_{12}=\Gamma^1_{22}=0.$$

- **$\Gamma^2_{ij}$:** Only $l=2$ contributes:
$$\Gamma^2_{22}=\tfrac12 g^{22}\,\partial_2 g_{22}=\frac{1}{2x^2},\qquad \Gamma^
2_{11}=\Gamma^2_{12}=0.$$

Hence the **only non-zero Christoffel symbols of the second kind** are
$$\boxed{\Gamma^1_{11}=\frac{1}{2x^1},\qquad \Gamma^2_{22}=\frac{1}{2x^2},}$$
with all other $\Gamma^k_{ij}=0$.

## Part (b): Verification that $x^1=t^2,\; x^2=(at^3+b)^{2/3}$ are geodesics

Since we are **not** using an arc-length (affine) parameter, the geodesic equati
ons take the non-affine form: there exists a single scalar function $\lambda(t)$
 such that for each coordinate $k$,
$$\ddot{x}^k+\Gamma^k_{ij}\,\dot{x}^i\dot{x}^j=\lambda(t)\,\dot{x}^k.\tag{$\star
$}$$

Substituting the only two non-zero Christoffel symbols, ($\star$) becomes the pa
ir
$$\ddot{x}^1+\frac{(\dot{x}^1)^2}{2x^1}=\lambda(t)\,\dot{x}^1,\qquad \ddot{x}^2+
\frac{(\dot{x}^2)^2}{2x^2}=\lambda(t)\,\dot{x}^2.\tag{I, II}$$

We verify both equations for the given curve, working on the open set where $t\n
eq 0$, $x^1>0$, $x^2>0$ (so the metric is Riemannian and the parameter is regula
r).

**First coordinate.** With $x^1=t^2$:
$$\dot{x}^1=2t,\qquad \ddot{x}^1=2.$$
The left-hand side of (I) is
$$2+\frac{(2t)^2}{2\,t^2}=2+2=4.$$
The right-hand side is $\lambda(t)\cdot 2t$, so (I) forces
$$\lambda(t)=\frac{2}{t}.\tag{$\lambda$}$$

**Second coordinate.** Set $u=at^3+b$, so $x^2=u^{2/3}$. Then
$$\dot{x}^2=\tfrac23 u^{-1/3}\cdot 3at^2=2at^2\,u^{-1/3},$$
$$\ddot{x}^2=4at\,u^{-1/3}+2at^2\!\left(-\tfrac13 u^{-4/3}\cdot 3at^2\right)=4at
\,u^{-1/3}-2a^2t^4\,u^{-4/3}.$$
Also
$$\frac{(\dot{x}^2)^2}{2x^2}=\frac{4a^2t^4\,u^{-2/3}}{2\,u^{2/3}}=2a^2t^4\,u^{-4
/3}.$$
Adding these, the left-hand side of (II) is
$$4at\,u^{-1/3}-2a^2t^4\,u^{-4/3}+2a^2t^4\,u^{-4/3}=4at\,u^{-1/3}.$$
The right-hand side of (II), using ($\lambda$), is
$$\lambda(t)\,\dot{x}^2=\frac{2}{t}\cdot 2at^2\,u^{-1/3}=4at\,u^{-1/3}.$$

**Both sides of (II) coincide**, and (I) is satisfied with the **same** $\lambda
(t)=2/t$ required by (I). Since $a$ and $b$ are arbitrary constants, the verific
ation holds for every member of the family.

Therefore every curve $x^1=t^2,\;x^2=(at^3+b)^{2/3}$ satisfies the geodesic equa
tions (in non-affine form, with common parameter function $\lambda(t)=2/t$), and
 hence **all such curves are geodesics** of the metric. $\blacksquare$
