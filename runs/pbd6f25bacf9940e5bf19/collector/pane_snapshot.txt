Looking at this problem, I need to find all possible slopes of AB in an isoscele
s trapezoid ABCD with A=(20,100), D=(21,107), integer coordinates, AB ∥ CD as th
e only parallel sides, and no horizontal/vertical sides.

## Setup

Let AB have primitive direction (p,q) with gcd(|p|,|q|)=1, p≠0, q≠0 (no horizont
al/vertical AB). Set:
- B = A + k(p,q) = (20+kp, 100+kq), k ≥ 1
- C = D + j(p,q) = (21+jp, 107+jq), j ≥ 1

Then CD = D−C = (−jp, −jq), which is parallel to AB. ✓

**Isosceles condition** |BC| = |AD| = √50:

BC = C−B = (1+(j−k)p, 7+(j−k)q). Setting d = j−k:

(1+dp)² + (7+dq)² = 50 → d²(p²+q²) + 2d(p+7q) = 0

So d = 0 (parallelogram, excluded) or **d = −2(p+7q)/(p²+q²)**.

Let t = −d = 2(p+7q)/(p²+q²). We need t to be a **nonzero integer**.

**Convexity**: All cross products of consecutive edges equal multiples of (7p−q)
, so we need **q ≠ 7p** (non-degenerate, and ensures BC ∦ AD).

**No horizontal/vertical BC**: 1−tp ≠ 0 and 7−tq ≠ 0.

## Bounding the search

|t| ≥ 1 gives p²+q² ≤ 2|p+7q| ≤ 2√50·√(p²+q²), so √(p²+q²) ≤ 10√2 ≈ 14.14, meani
ng **p²+q² ≤ 200**.
