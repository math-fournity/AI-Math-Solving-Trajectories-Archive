Looking at this problem, I need to find integer angle triples (A, B, C) with A +
 B + C = 180° where the four outer vertices of squares built externally on sides
 BC and AC are concyclic.

## Setup

Place C at the origin, A at (b, 0), B at (a cos C, a sin C), where a = BC, b = C
A. The triangle lies above the x-axis.

**Square on BC (external):** The outward perpendicular to BC is (−sin C, cos C),
 giving outer corners:
- D₁ = (a(cos C − sin C), a(sin C + cos C))
- D₂ = (−a sin C, a cos C)

**Square on AC (external):** The outward perpendicular to AC is (0, −1), giving
outer corners:
- E₁ = (b, −b)
- E₂ = (0, −b)

## Concyclicity Condition

Using the determinant test for concyclicity, I compute x² + y² for each point:
- D₁: 2a², D₂: a², E₁: 2b², E₂: b²

The 4×4 determinant is:

```
| 2a²   a(cosC−sinC)   a(sinC+cosC)   1 |
| a²    −a·sinC         a·cosC          1 |
| 2b²   b               −b              1 |
| b²    0               −b              1 |
```

**Row 1 − Row 2:** [a², a·cosC, a·sinC, 0]
**Row 3 − Row 4:** [b², b, 0, 0]

Expanding along column 4 (entries in rows 2 and 4):

Det = M₂₄ + M₄₄

Computing each 3×3 minor:

**M₂₄** = −a²b² + ab³(cos C − sin C)

**M₄₄** = a²b² − a³b(cos C − sin C)

**Det = ab(cos C − sin C)(b² − a²)**

Setting Det = 0 with a, b > 0 yields two cases:

1. **cos C = sin C** → tan C = 1 → **C = 45°**
2. **a = b** → sin A = sin B → **A = B** (since A + B < 180°, the alternative A
+ B = 180° is impossible)

## Counting Solutions

**Case 1: C = 45°, A + B = 135°.** A ranges from 1 to 134 (B = 135 − A ≥ 1). Cou
nt: **134**.

**Case 2: A = B, C = 180 − 2A.** Need C ≥ 1, so A ≤ 89; A ≥ 1. Count: **89**.

**Overlap check:** C = 45° and A = B gives 2A = 135°, so A = 67.5° — not an inte
ger. No overlap.

## Answer

**Total = 134 + 89 = 223**
