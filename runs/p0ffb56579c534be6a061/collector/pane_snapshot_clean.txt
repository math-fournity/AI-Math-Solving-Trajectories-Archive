Claim. The set of computable real numbers has Hausdorff dimension $0$. In
particular, it does not have positive Hausdorff dimension.

Step 1: The computable reals are countable.

A real number $x$ is computable if there exists a Turing machine that, on input
$n$, outputs a rational $r_n$ with $|r_n - x| \le 2^{-n}$. Since there are only
countably many Turing machines (each is a finite string over a finite alphabet),
the set of computable reals is at most countable. It is infinite (every integer,
every rational, $\pi$, $e$, $\sqrt{2}$, etc. are computable), so it is countably
infinite.

Step 2: Every countable subset of $\mathbb{R}$ has Hausdorff dimension $0$.

Let $C \subseteq \mathbb{R}$ be countable, enumerated as $C = {x_1, x_2, x_3,
\ldots}$. Fix any $s > 0$. We show the $s$-dimensional Hausdorff measure $
\mathcal{H}^s(C) = 0$.

Recall the definition: for $\delta > 0$, $$\mathcal{H}^s_\delta(C) =
\inf\left{\sum_{j} (\operatorname{diam} U_j)^s : C \subseteq \bigcup_j U_j,\
\operatorname{diam} U_j \le \delta\right},$$ and $\mathcal{H}^s(C) =
\lim_{\delta \to 0} \mathcal{H}^s_\delta(C) = \sup_{\delta > 0} \mathcal{H}
^s_\delta(C)$.

Given any $\delta > 0$, cover each $x_i$ by the closed interval $$U_i =
\left[x_i - \frac{\delta}{2^{i+1}},\ x_i + \frac{\delta}{2^{i+1}}\right],$$
which has diameter $\operatorname{diam}(U_i) = \delta \cdot 2^{-i} \le \delta$.
This is a valid $\delta$-cover of $C$. Its $s$-cost is $$\sum_{i=1}^{\infty}
(\operatorname{diam} U_i)^s = \sum_{i=1}^{\infty} \left(\frac{\delta}
{2^i}\right)^s = \delta^s \sum_{i=1}^{\infty} 2^{-is} = \delta^s \cdot
\frac{2^{-s}}{1 - 2^{-s}} = \frac{\delta^s}{2^s - 1}.$$

Therefore $$\mathcal{H}^s_\delta(C) \le \frac{\delta^s}{2^s - 1}.$$

Taking $\delta \to 0$ (with $s > 0$ fixed), $\delta^s \to 0$, so $$\mathcal{H}
^s(C) = \lim_{\delta \to 0} \mathcal{H}^s_\delta(C) = 0.$$

This holds for every $s > 0$.

Step 3: Conclude the dimension is $0$.

The Hausdorff dimension is $$\dim_H(C) = \inf{s \ge 0 : \mathcal{H}^s(C) = 0} =
\sup{s \ge 0 : \mathcal{H}^s(C) = \infty}.$$

Since $\mathcal{H}^s(C) = 0$ for every $s > 0$, the infimum is $0$, so $
\dim_H(C) = 0$.

Applying this to $C = {\text{computable reals}}$, which is countable by Step 1:

$$\boxed{\dim_H({\text{computable reals}}) = 0.}$$

dimension; its Hausdorff dimension is exactly $0$. The key reason is that
computability is a countability constraint — there are only countably many

regardless of how the set is distributed in $\mathbb{R}$. The richness of
computable analysis (computable reals are dense, form a real-closed field, etc.)
does not change the dimensional fact: dimension measures geometric mass, and a
countable set carries none.
