## Proof

**Setup and notation.** Label rows 1–5, columns 1–9. Define four classes by (row
 parity, column parity):
- Class 0 = (even, even): rows {2,4} × cols {2,4,6,8} → **8 pads**
- Class 1 = (even, odd): rows {2,4} × cols {1,3,5,7,9} → 10 pads
- Class 2 = (odd, even): rows {1,3,5} × cols {2,4,6,8} → 12 pads
- Class 3 = (odd, odd): rows {1,3,5} × cols {1,3,5,7,9} → 15 pads

**Key observation on class transitions.** A horizontal move flips column parity
(preserving row parity); a vertical move flips row parity (preserving column par
ity). Since moves alternate H, V, H, V, …, a drone starting at any class cycles
through all four classes with period 4. For instance, starting at class 0 with f
irst move H:
$$0 \xrightarrow{H} 1 \xrightarrow{V} 3 \xrightarrow{H} 2 \xrightarrow{V} 0$$
Starting with V gives $0 \to 2 \to 3 \to 1 \to 0$. In either case, **every 4 con
secutive time steps, each drone visits each class exactly once**.

**Upper bound.** At any fixed time, drones in class $X$ occupy distinct pads, so
 at most $|X|$ drones can be in class $X$. Over any 4 consecutive time steps, th
e total number of drone-visits to class $X$ equals $n$ (each drone visits once).
 Since each time step contributes at most $|X|$:
$$n \le 4|X| \quad \text{for each class } X.$$
The binding constraint is class 0 with $|X|=8$:
$$\boxed{n \le 32}.$$

**Construction achieving $n = 32$.** We exhibit a 32-cycle with alternating H, V

r minute. Since every pad is vacated and refilled simultaneously, no collisions
occur, and the alternating H/V pattern is preserved.
