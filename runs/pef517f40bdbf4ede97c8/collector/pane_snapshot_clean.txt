Looking at this problem, I need to find two distinct positive integers $a, b$ wh
ose arithmetic, geometric, and harmonic means are all integers, minimizing $|a-b
|$.

## Setup and Parametrization

Let $d = \gcd(a,b)$, so $a = dx$, $b = dy$ with $\gcd(x,y)=1$.

**Arithmetic mean:** $A = \frac{d(x+y)}{2}$, requiring $d(x+y)$ even.

**Geometric mean:** $G = d\sqrt{xy}$, requiring $xy$ to be a perfect square. Sin
ce $\gcd(x,y)=1$, both $x$ and $y$ must be perfect squares: $x = m^2$, $y = n^2$
 with $\gcd(m,n)=1$, $m \neq n$.

So $a = dm^2$, $b = dn^2$.

**Harmonic mean:** $H = \frac{2d^2m^2n^2}{d(m^2+n^2)} = \frac{2dm^2n^2}{m^2+n^2}
$.

**Key observation:** Since $\gcd(m,n)=1$, we get $\gcd(m^2+n^2, m) = \gcd(n^2,m)
=1$ and $\gcd(m^2+n^2, n)=1$, so $\gcd(m^2+n^2, m^2n^2)=1$.

Therefore $(m^2+n^2) \mid 2d$, meaning $2d = k(m^2+n^2)$ for some positive integ
er $k$.

**Arithmetic mean condition:** $A = \frac{d(m^2+n^2)}{2} = \frac{k(m^2+n^2)^2}{4
}$ must be an integer.

## Case Analysis

**Case 1: $m, n$ both odd** (same parity, coprime ⟹ both odd).

Then $m^2+n^2 \equiv 2 \pmod{4}$, so $(m^2+n^2)^2 \equiv 4 \pmod{16}$, making $\
frac{(m^2+n^2)^2}{4}$ an odd integer. Thus $A$ is integer for any $k \geq 1$, an
d $d = \frac{k(m^2+n^2)}{2}$ is integer.

$$|a-b| = \frac{k(m^2+n^2)|m^2-n^2|}{2}$$

Minimum at $k=1$, smallest coprime odd pair $m=1, n=3$:
$$|a-b| = \frac{10 \cdot 8}{2} = 40$$

**Case 2: One of $m,n$ even, the other odd** (different parity).

Then $m^2+n^2$ is odd, so $(m^2+n^2)^2$ is odd, requiring $4 \mid k$. Set $k = 4
k''$, giving $d = 2k''(m^2+n^2)$.

$$|a-b| = 2k''(m^2+n^2)|m^2-n^2|$$

Minimum at $k''=1$, smallest coprime mixed-parity pair $m=1, n=2$:
$$|a-b| = 2 \cdot 5 \cdot 3 = 30$$

## Minimality Proof

The parametrization $a = dm^2, b = dn^2$ with $\gcd(m,n)=1$ is **complete** (any
 solution must have this form). The constraint $(m^2+n^2) \mid 2d$ is **necessar
y** (derived from the harmonic mean being integer). So every solution falls into
 Case 1 or Case 2 above.

- **Case 1 minimum:** Need $(m^2+n^2)|m^2-n^2| < 80$ with both $m,n$ odd, coprim
e, distinct. The smallest such pair is $\{1,3\}$ giving exactly $80$, so $|a-b|
\geq 40$.
- **Case 2 minimum:** Need $2(m^2+n^2)|m^2-n^2| < 30$, i.e., $(m^2+n^2)|m^2-n^2|
 < 15$ with mixed parity, coprime, distinct. The smallest such pair is $\{1,2\}$
 giving exactly $15$, so $|a-b| \geq 30$.

No smaller pair exists in either case (the pairs $\{1,2\}$ and $\{1,3\}$ are the
 minimal valid pairs for each case).

## Verification

Take $a = 10$, $b = 40$ (from Case 2 with $m=1, n=2, k''=1, d=10$):

- **Arithmetic mean:** $\frac{10+40}{2} = 25$ ✓
- **Geometric mean:** $\sqrt{10 \cdot 40} = \sqrt{400} = 20$ ✓
- **Harmonic mean:** $\frac{2 \cdot 10 \cdot 40}{10+40} = \frac{800}{50} = 16$ ✓

All three means are integers, and $|a - b| = 30$.

## Answer

The minimal value of $|a - b|$ is $\boxed{30}$.
