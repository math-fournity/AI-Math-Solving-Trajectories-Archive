## Solution

**Digit-sum change when adding 2.** Write $x = 10m + u$ where $u$ is the units d
igit.

**No carry ($u \le 7$):** $x+2 = 10m + (u+2)$, so $S(x+2)-S(x) = 2$, giving $T(x
)=2$.

**Carry ($u \in \{8,9\}$):** $x+2 = 10(m+1) + (u-8)$, so
$$S(x+2)-S(x) = S(m+1) + (u-8) - S(m) - u = \bigl(S(m+1)-S(m)\bigr) - 8.$$

When adding 1 to $m$, if $m$ has $t$ trailing 9's ($t \ge 0$), those become 0's
and the preceding digit increments by 1, so $S(m+1)-S(m) = 1 - 9t$. Therefore
$$S(x+2) - S(x) = (1-9t) - 8 = -(7+9t),$$
and $T(x) = 7 + 9t$.

**Verification.** $T(199)$: $x=199$, $u=9$, $m=19$ (one trailing 9, $t=1$), so $
T = 7+9 = 16$. ✓ Also $T(8)=|S(10)-S(8)|=|1-8|=7$ ✓, $T(998)=|S(1000)-S(998)|=|1
-26|=25=7+9\cdot2$ ✓.

**The value set is** $\{2\} \cup \{7+9t : t \ge 0\} = \{2, 7, 16, 25, 34, \dots\
}$.

Every value is attainable: $T=2$ via $x=1$; $T=7+9t$ via $x = 10^{t+1}-1$ (units
 digit 9, $m = 10^t-1$ has exactly $t$ trailing 9's).

**Counting values $\le 1999$.** The value $2 \le 1999$ counts once. For the prog
ression $7, 16, \dots, 1996$:
$$7 + 9t \le 1999 \implies t \le \frac{1992}{9} = 221.33\ldots \implies t \in \{
0,1,\dots,221\},$$
giving $222$ values (last term $7+9\cdot221 = 1996 \le 1999$; next would be $200
5 > 1999$).

**Total:** $222 + 1 = \boxed{223}$.
