## Solution

**Setup.** Place the regular hexagonal floor in the $xy$-plane, centered at the
origin, with side length $s$ (so the circumradius is also $s$). The apex is $A =
 (0, 0, h)$. The six base vertices are:
$$V_k = \left(s\cos\tfrac{k\pi}{3},\; s\sin\tfrac{k\pi}{3},\; 0\right), \quad k=
0,\dots,5.$$

**Choosing the two edges.** Take edge $E_0 = V_0V_1$ and edge $E_2 = V_2V_3$. Th
ese share no vertex (not adjacent) and are not parallel ($E_0 \parallel E_3$, $E
_2 \parallel E_5$). Their midpoints are:
$$M_1 = \left(\tfrac{3s}{4},\; \tfrac{s\sqrt3}{4},\; 0\right), \qquad M_2 = \lef
t(-\tfrac{3s}{4},\; \tfrac{s\sqrt3}{4},\; 0\right).$$
The midpoint of the height is $M_3 = (0, 0, h/2)$.

**The cutting plane.** Since $M_1, M_2$ share the same $y$-coordinate, the plane
's normal is proportional to $(M_2 - M_1)\times(M_3 - M_1) = (0,\; 2h,\; s\sqrt{
3})$, giving:
$$2hy + s\sqrt{3}\,z = \frac{hs\sqrt{3}}{2}.$$

**Cross-section vertices.** Intersecting the plane with all pyramid edges:

- *Base edges* (at $z=0$, $y = s\sqrt3/4$): hits $E_0$ at $M_1$ and $E_2$ at $M_
2$.
- *Lateral edges* $AV_i$: solving $t = \frac{s\sqrt3/2 - 2y_i}{s\sqrt3 - 2y_i}$
gives:
  - $AV_0$ ($y_i=0$): $t=1/2$ → $P_0 = (s/2,\, 0,\, h/2)$
  - $AV_3$ ($y_i=0$): $t=1/2$ → $P_3 = (-s/2,\, 0,\, h/2)$
  - $AV_4$ ($y_i=-s\sqrt3/2$): $t=3/4$ → $P_4 = (-s/8,\, -s\sqrt3/8,\, 3h/4)$
  - $AV_5$ ($y_i=-s\sqrt3/2$): $t=3/4$ → $P_5 = (s/8,\, -s\sqrt3/8,\, 3h/4)$
  - $AV_1, AV_2$: the plane value is constantly $hs\sqrt3 \neq hs\sqrt3/2$, so n
o intersection.

The cross-section is the hexagon (in order): $M_1, P_0, P_5, P_4, P_3, M_2$.

**Glass pane area.** Using the 3D polygon area formula $\text{Area} = \frac{|\ma
thbf{n}\cdot\sum(\mathbf{v}_i\times\mathbf{v}_{i+1})|}{2|\mathbf{n}|}$ with $\ma
thbf{n}=(0,2h,s\sqrt3)$:

Computing $\sum \mathbf{v}_i \times \mathbf{v}_{i+1} = \left(0,\; -\tfrac{25sh}{
16},\; -\tfrac{25s^2\sqrt3}{32}\right)$, so:
$$\mathbf{n}\cdot\sum = 2h\!\left(-\tfrac{25sh}{16}\right) + s\sqrt3\!\left(-\tf
rac{25s^2\sqrt3}{32}\right) = -\tfrac{25s(4h^2+3s^2)}{32},$$
$$\text{Glass area} = \frac{25s(4h^2+3s^2)}{64\sqrt{4h^2+3s^2}} = \frac{25s\sqrt
{4h^2+3s^2}}{64}.$$

**Lateral face area.** Each lateral face is a triangle with base $s$ and slant h
eight $\ell = \sqrt{h^2 + 3s^2/4} = \tfrac{1}{2}\sqrt{4h^2+3s^2}$:
$$\text{Lateral face area} = \frac{s}{2}\cdot\frac{\sqrt{4h^2+3s^2}}{2} = \frac{
s\sqrt{4h^2+3s^2}}{4}.$$

**The ratio.**
$$\frac{\text{Glass area}}{\text{Lateral face area}} = \frac{25s\sqrt{4h^2+3s^2}
/64}{s\sqrt{4h^2+3s^2}/4} = \frac{25}{64}\cdot 4 = \frac{25}{16}.$$

Since $\gcd(25, 16) = 1$, the fraction is irreducible with $a = 25$, $b = 16$.

$$a + b = 25 + 16 = \boxed{41}$$
