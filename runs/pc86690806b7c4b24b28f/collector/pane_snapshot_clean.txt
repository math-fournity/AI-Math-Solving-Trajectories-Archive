## Proof

**Verification.** If $f(n)=n$, then $m^2+f(n) = m^2+n$ and $mf(m)+n = m^2+n$, so
 the divisibility holds trivially. ✓

**Uniqueness.** We show $f(n)=n$ is forced.

**Step 1: $f(1) = 1$.**

Set $m=1$: for all $n$,
$$1 + f(n) \mid f(1) + n. \tag{1}$$

Set $n=1$: for all $m$,
$$m^2 + f(1) \mid mf(m) + 1. \tag{2}$$

Let $a = f(1)$. Take $m = a$ in (2):
$$a^2 + a \mid a\,f(a) + 1.$$
Since $a^2 + a = a(a+1)$, in particular $a \mid a\,f(a)+1$. But $a \mid a\,f(a)$
, so $a \mid 1$, giving $a = 1$.

**Step 2: $f(n) \leq n$ for all $n$.**

With $a=1$, condition (1) becomes $1 + f(n) \mid n + 1$ for all $n$. Since $f(n)
 \geq 1$, we have $1+f(n) \geq 2$, and divisibility gives $1+f(n) \leq n+1$, hen
ce
$$f(n) \leq n. \tag{3}$$

**Step 3: $f(n) = n$ for all $n$.**

With $a=1$, condition (2) becomes $m^2 + 1 \mid mf(m) + 1$ for all $m$. Write
$$mf(m) + 1 = k_m(m^2+1)$$
for some positive integer $k_m$. Then
$$f(m) = \frac{k_m(m^2+1)-1}{m} = k_m\,m + \frac{k_m - 1}{m}.$$
For $f(m)$ to be an integer, $m \mid k_m - 1$, so $k_m = 1 + m\,t_m$ for some in
teger $t_m \geq 0$. Substituting:
$$f(m) = m + t_m(m^2 + 1).$$
Since $t_m \geq 0$ and $m^2+1 > 0$, we have $f(m) \geq m$. Combined with (3), $f
(m) \leq m$, so $t_m = 0$ and
$$f(m) = m \quad \text{for all } m.$$

**Conclusion.** The unique function satisfying the condition is $\boxed{f(n) = n
}$ for all positive integers $n$.
