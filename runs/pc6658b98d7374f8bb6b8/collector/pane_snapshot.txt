## Solution

We solve the ODE

$$y'' = y\ln y + \frac{(y')^2}{y}, \qquad y>0.$$

**Substitution.** Let $u = \ln y$, so $y = e^{u}$. Then

$$y' = e^{u}u' = y\,u', \qquad y'' = y\,(u')^{2} + y\,u'' = y\bigl((u')^{2}+u''\
bigr).$$

The right-hand side becomes

$$y\ln y + \frac{(y')^{2}}{y} = y\,u + \frac{(y\,u')^{2}}{y} = y\,u + y\,(u')^{2
} = y\bigl(u+(u')^{2}\bigr).$$

Equating both sides and dividing by $y>0$:

$$(u')^{2}+u'' = u + (u')^{2}\;\;\Longrightarrow\;\; u'' = u.$$

**Solving the reduced equation.** The equation $u''=u$ has general solution

$$u(x) = C_{1}e^{x} + C_{2}e^{-x},$$

with $C_{1},C_{2}\in\mathbb{R}$ arbitrary constants.

**Back-substitution.** Since $u=\ln y$, i.e. $y=e^{u}$,

$$\boxed{\,y(x) = \exp\!\bigl(C_{1}e^{x}+C_{2}e^{-x}\bigr)\,}.$$

**Verification.** With $u=C_{1}e^{x}+C_{2}e^{-x}$ we have $u''=u$. Then
- $y' = y\,u'$,
- $y'' = y\bigl((u')^{2}+u''\bigr)=y\bigl((u')^{2}+u\bigr)$,
- $y\ln y + \dfrac{(y')^{2}}{y}=y\,u+y\,(u')^{2}=y\bigl(u+(u')^{2}\bigr)$.

Both sides coincide, confirming the solution. Note $y=e^{u}>0$ automatically, so
 the domain restriction $y>0$ is satisfied for all $x$.
