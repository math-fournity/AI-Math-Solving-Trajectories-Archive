## Analysis

**Game setup:** State is $(a,b,c)$ with $a \ge b \ge c \ge 0$, total $S = a+b+c$
 invariant. A move selects two stacks, moving $k \ge 1$ tokens from the smaller
to the larger. The player who leaves exactly one non-empty stack wins.

**Key observations:**

1. **Sum of squares strictly increases** with every move: moving $k$ from stack
$x$ to stack $y$ ($y \ge x$) changes $\sum \text{squares}$ by $2k(y-x) + 2k^2 >
0$. Since bounded by $S^2$, the game terminates.

2. **Emptying a stack is bad when all three are positive:** If you empty one sta
ck, the opponent faces $(x, y, 0)$ with $y > 0$, and immediately moves all of $y
$ to $x$, winning. So $(x, y, 0)$ is always an **N-position** (current player wi
ns).

3. Therefore, from a 3-positive position, emptying moves always lead to N-positi
ons for the opponent — they never help. The meaningful moves are **non-emptying*
* ones.

**Claim:** $(a, b, c)$ with $a \ge b \ge c \ge 1$ is a **P-position** (first pla
yer loses) **iff $b = c$**.

**Proof by induction on $c$:**

**Base case $c = 1$:** Consider $(a, 1, 1)$. Any move picks two stacks and moves
 $\ge 1$ from the smaller. Since the two smallest stacks each have 1 token, ever
y move empties a stack (moving the only token). All such moves give the opponent
 $(x, y, 0)$, an N-position. So $(a,1,1)$ is a **P-position**.

For $(a, b, 1)$ with $b > 1$: pick stacks $a, b$ and move $k = b-1$ tokens from
$b$ to $a$. This yields $(a+b-1, 1, 1)$, a P-position. So $(a, b, 1)$ with $b >
1$ is an **N-position**.

**Inductive step:** Assume the claim holds for all $c' < c$.

**Case $b = c$, i.e., $(a, c, c)$:** Check all non-emptying moves:
- Pick $a$ and a $c$-stack: move $k$ ($1 \le k \le c-1$) from $c$ to $a$ → $(a+k
, c, c-k)$. Here $c' = c-k < c$ and $b' = c \ne c-k = c'$, so by induction this
is an **N-position**.
- Pick the two $c$-stacks: move $k$ ($1 \le k \le c-1$) from one to the other →
$(a, c+k, c-k)$. After reordering, $c' = c-k < c$. Since $a \ge c > c-k$, we hav
e $b' \ne c'$ (the middle value $\ge c > c-k$), so by induction this is an **N-p
osition**.

All non-emptying moves lead to N-positions; all emptying moves lead to $(x,y,0)$
 N-positions. Therefore $(a, c, c)$ is a **P-position**.

**Case $b > c$, i.e., $(a, b, c)$:** Pick stacks $a, b$ and move $k = b - c$ tok
ens from $b$ to $a$ (valid since $1 \le b-c \le b-1$). This yields $(a + b - c,\
; c,\; c)$, which is a P-position (just proven). So $(a, b, c)$ with $b > c$ is
an **N-position**. $\blacksquare$
