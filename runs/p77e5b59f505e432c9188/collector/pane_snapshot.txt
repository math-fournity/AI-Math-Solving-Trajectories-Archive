## Setup

Let $s \in \{0,1\}^n$ be the leader's string. The deputy reveals $S_k(s) = \{t \
in \{0,1\}^n : d(s,t) = k\}$, where $d$ is Hamming distance. The contestant must
 identify $s$ from $S_k(s)$. The minimum number of guesses needed is $\max_s |\{
s' : S_k(s') = S_k(s)\}|$.

## Determining when $S_k(s') = S_k(s)$

Suppose $S_k(s') = S_k(s)$ with $s' \neq s$. Let $j = d(s, s') > 0$.

**Notation.** Let $A = \{i : s_i \neq s'_i\}$ with $|A| = j$, and $B = \{i : s_i
 \neq t_i\}$ with $|B| = k$.

For any $t$ with $d(s, t) = k$, we need $d(s', t) = k$. Since $s'$ differs from
$s$ exactly on $A$, and $t$ differs from $s$ exactly on $B$:

$$d(s', t) = |A \triangle B| = j + k - 2|A \cap B|.$$

Setting $d(s', t) = k$ gives $|A \cap B| = j/2$ for **every** $k$-subset $B \sub
seteq [n]$.

**Range analysis.** As $B$ ranges over all $k$-subsets of $[n]$, the value $|A \
cap B|$ ranges over the interval $[\max(0,\, j+k-n),\; \min(j, k)]$. For $|A \ca
p B|$ to be constant at $j/2$, we need:

$$\max(0,\, j+k-n) = \min(j, k) = j/2. \tag{$\star$}$$

**Case 1: $j \leq k$.** Then $\min(j,k) = j$, so $j/2 = j$ forces $j = 0$, contr
adicting $j > 0$.

**Case 2: $j > k$.** Then $\min(j,k) = k$, so $j/2 = k$, giving $j = 2k$. For th
e lower bound: $\max(0, 2k + k - n) = k$. If $3k \geq n$, then $3k - n = k \Righ
tarrow n = 2k$. If $3k < n$, then $0 = k$, contradicting $k \geq 1$. So $n = 2k$
 and $j = 2k = n$, meaning $s' = \bar{s}$ (the bitwise complement of $s$).

**Converse.** When $n = 2k$ and $s' = \bar{s}$: for any $t$ with $d(s, t) = k$,
we have $d(\bar{s}, t) = n - k = k$. So $S_k(\bar{s}) = S_k(s)$. ✓

## Conclusion

- **If $n \neq 2k$:** The only string $s'$ with $S_k(s') = S_k(s)$ is $s' = s$ i
tself. The leader's string is uniquely determined, so **1 guess** suffices.

- **If $n = 2k$:** Exactly two strings produce the same set: $s$ and $\bar{s}$.
The contestant cannot distinguish them, so **2 guesses** are needed (guess both)
.

$$\boxed{\text{Minimum guesses} = \begin{cases} 1 & \text{if } n \neq 2k, \\ 2 &
 \text{if } n = 2k. \end{cases}}$$
