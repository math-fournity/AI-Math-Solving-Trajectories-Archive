## 证明

**结论：是的，$f(n) \sim \log n$ 成立。**

记 $S(n) = \sum_{i=1}^n f(i)$。由题设 $S(n) \sim n\log n$，即存在 $\epsilon(n) \
to 0$ 使得
$$S(n) = n\log n\,(1 + \epsilon(n)).$$

由于 $f$ 单调递增且恒正，$S$ 是凸序列（$f(n) = S(n)-S(n-1)$ 单调递增）。我们用 $
f$ 的单调性建立 $f(n)$ 的上下界。

---

### 下界：$f(n) \geq (1-o(1))\log n$

由 $f$ 单调递增，对所有 $1 \leq i \leq n$，$f(i) \leq f(n)$，因此
$$S(n) = \sum_{i=1}^n f(i) \leq n\,f(n),$$
故
$$f(n) \geq \frac{S(n)}{n} = \log n\,(1+\epsilon(n)) = (1+o(1))\log n. \tag{1}$$

---

### 上界：$f(n) \leq (1+o(1))\log n$

由 $f$ 单调递增，对所有 $n+1 \leq i \leq 2n$，$f(i) \geq f(n+1) \geq f(n)$，因此
$$S(2n) - S(n) = \sum_{i=n+1}^{2n} f(i) \geq n\,f(n),$$
故
$$f(n) \leq \frac{S(2n)-S(n)}{n} = 2\,\frac{S(2n)}{2n} - \frac{S(n)}{n}.$$

记 $a(n) = S(n)/n = \log n\,(1+\epsilon(n))$，则上式为 $2a(2n) - a(n)$。展开：

$$2a(2n) - a(n) = 2\log(2n)\,(1+\epsilon(2n)) - \log n\,(1+\epsilon(n)).$$

利用 $\log(2n) = \log n + \log 2$：

$$= 2(\log n + \log 2)(1+\epsilon(2n)) - \log n\,(1+\epsilon(n))$$
$$= \log n + 2\log 2 + \log n\,\bigl(2\epsilon(2n) - \epsilon(n)\bigr) + 2\log 2
\,\cdot\,\epsilon(2n).$$

由于 $\epsilon(n) \to 0$，有 $\epsilon(2n) \to 0$，因此：
- $2\log 2 \cdot \epsilon(2n) \to 0$；
- $2\epsilon(2n) - \epsilon(n) \to 0$，从而 $\log n\,(2\epsilon(2n) - \epsilon(n
)) = o(\log n)$。

因此
$$f(n) \leq 2a(2n) - a(n) = \log n + o(\log n) = (1+o(1))\log n. \tag{2}$$

---

### 综合

由 (1) 和 (2)：
$$(1-o(1))\log n \;\leq\; f(n) \;\leq\; (1+o(1))\log n,$$

故 $\dfrac{f(n)}{\log n} \to 1$，即 $f(n) \sim \log n$。$\blacksquare$
