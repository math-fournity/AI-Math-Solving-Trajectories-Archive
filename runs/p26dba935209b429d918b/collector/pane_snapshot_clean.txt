## Preliminary: the Gaussian product and the angle

Define $Z_n = \prod_{k=1}^{n}(1+ik) \in \mathbb{Z}[i]$, with $A_n = \operatornam
e{Re} Z_n$, $B_n = \operatorname{Im} Z_n$, and $x_n = B_n/A_n$.

**Key identity.** For each $k \geq 1$, writing $1+ik = \sqrt{1+k^2}\, e^{i\arcta
n k}$, we obtain
$$Z_n = \Bigl(\prod_{k=1}^n \sqrt{1+k^2}\Bigr) \exp\!\Bigl(i\sum_{k=1}^n \arctan
 k\Bigr).$$
Setting $S_n := \sum_{k=1}^n \arctan k$ and $R_n := \prod_{k=1}^n \sqrt{1+k^2} =
 \sqrt{\omega_n}$, this gives
$$A_n = R_n \cos S_n, \qquad B_n = R_n \sin S_n, \qquad \omega_n = A_n^2 + B_n^2
 = \prod_{k=1}^n (1+k^2).$$

## Theorem `x_eq_tan_sum_arctan` (textbook)

**Claim.** For $n \geq 1$, $\ x_n = \tan S_n$ (as real numbers).

**Proof.** From the key identity, whenever $A_n \neq 0$ (equivalently $\cos S_n
\neq 0$),
$$x_n = \frac{B_n}{A_n} = \frac{R_n \sin S_n}{R_n \cos S_n} = \tan S_n.$$
When $A_n = 0$, both sides are interpreted appropriately: $S_n \equiv \pi/2 \pmo
d{\pi}$, so $\tan S_n$ is a pole, and $x_n = B_n/0 = 0$ in Lean's rational divis
ion (a convention noted in the file). The identity $x_n = \tan S_n$ holds as an
identity of meromorphic functions of the angle, and agrees with the Lean convent
ion at poles. $\square$

## Theorem `x_succ` (textbook)

**Claim.** For $n \geq 1$,
$$x_{n+1} = \frac{x_n + (n+1)}{1 - (n+1)\,x_n}.$$

**Proof.** Since $S_{n+1} = S_n + \arctan(n+1)$ and $\tan(\arctan(n+1)) = n+1$,
the tangent addition formula
$$\tan(\alpha+\beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\,\tan\beta}$
$
with $\alpha = S_n$, $\beta = \arctan(n+1)$, together with `x_eq_tan_sum_arctan`
, yields
$$x_{n+1} = \tan S_{n+1} = \frac{\tan S_n + (n+1)}{1 - (n+1)\tan S_n} = \frac{x_
n + (n+1)}{1 - (n+1)\,x_n}. \quad\square$$

## Theorem `kernel_dvd_of_eq_intCast` (research, solved — proof sketch)

**Claim.** If $x_n = m \in \mathbb{Z}$ (with $A_n \neq 0$), then $K_n \mid (1+m^
2)$, and if $K_n > 1$ then $|m| \geq \sqrt{K_n - 1}$.

**Proof.** If $B_n = m\,A_n$, then $Z_n = A_n + iB_n = A_n(1+im)$, so
$$\omega_n = |Z_n|^2 = A_n^2(1+m^2).$$
Since $\omega_n = \prod_{k=1}^n(1+k^2)$, the squarefree kernel $K_n$ (product of
 primes dividing $\omega_n$ to odd power) divides $1+m^2$: every prime appearing
 to odd power in $\omega_n = A_n^2(1+m^2)$ must appear to odd power in $1+m^2$ (
since $A_n^2$ contributes only even powers). Hence $K_n \mid (1+m^2)$.

If $K_n > 1$, then $1 + m^2 \geq K_n$ (as $K_n \mid 1+m^2$ and both are positive
), giving $m^2 \geq K_n - 1$, i.e. $|m| \geq \sqrt{K_n - 1}$. $\square$

## Theorem `exists_near_half_pi` (research, solved — proof sketch)

**Claim.** If $n \in E$ (exceptional: $n \geq 5$ and $A_n = 0$ or $|x_n| > n/2+1
$), then there exists $j \in \mathbb{Z}$ with $|\operatorname{angleSum}(n) - j\p
i/2| < 2/n$.

**Proof.** Use the identity $\arctan k + \arctan(1/k) = \pi/2$ for $k \geq 1$, g
iving
$$S_n = \sum_{k=1}^n \arctan k = \frac{n\pi}{2} - \sum_{k=1}^n \arctan\frac{1}{k
} = \frac{n\pi}{2} - \operatorname{angleSum}(n).$$
So $\operatorname{angleSum}(n) = \frac{n\pi}{2} - S_n$.

**Case $A_n = 0$:** $\cos S_n = 0$, so $S_n = (2\ell+1)\pi/2$ for some $\ell \in
 \mathbb{Z}$. Then $\operatorname{angleSum}(n) = \frac{n\pi}{2} - \frac{(2\ell+1
)\pi}{2} = \frac{(n-2\ell-1)\pi}{2}$, exactly an integer multiple of $\pi/2$. Th
e bound $< 2/n$ holds trivially (distance $0$).

**Case $|x_n| > n/2 + 1$:** $|\tan S_n| > n/2+1$. Let $j_0$ be the nearest integ
er to $2S_n/\pi$, so $S_n$ is within $\pi/2$ of $j_0\pi/2$. If $j_0$ is even, sa
y $j_0 = 2q$, then $|\tan S_n| = |\tan(S_n - q\pi)|$, and $|S_n - q\pi| < \pi/2$
. For $|\theta| < \pi/2$, $|\tan\theta| \leq 1/|\cos\theta|$... More directly: $
|\tan\theta| > T$ with $|\theta| < \pi/2$ implies $|\sin\theta|/|\cos\theta| > T
$, and since $|\sin\theta| \leq |\theta|$, $|\cos\theta| < |\theta|/T \leq |\the
ta|$. Actually the clean bound: for $\theta$ near $j\pi/2$ with $j$ odd (pole),
$|\tan\theta| = |\cot(\theta - j\pi/2)|$, and $|\cot\phi| > T$ for $|\phi| < \pi
/2$ gives $|\phi| < 1/T$ (since $|\cot\phi| \geq 1/|\phi|$ for small $|\phi|$, m
ore precisely $|\tan\phi| \leq |\phi|/(1-\phi^2)$... ).

The precise quantitative bound: if $|\tan S_n| > n/2 + 1$ and $S_n$ is near an o
dd multiple $j\pi/2$ (the only way $|\tan|$ is large), set $\delta = S_n - j\pi/
2$. Then $|\tan S_n| = |\cot\delta| = |\cos\delta/\sin\delta|$. For $|\delta| <
\pi/2$, $|\sin\delta| \geq \frac{2}{\pi}|\delta|$ (Jordan's inequality) and $|\c
os\delta| \leq 1$, so $|\cot\delta| \leq \frac{\pi}{2|\delta|}$. Thus $n/2 + 1 <
 \frac{\pi}{2|\delta|}$, giving $|\delta| < \frac{\pi}{n+2} < \frac{2}{n}$ for $
n \geq 1$.

Now $\operatorname{angleSum}(n) = \frac{n\pi}{2} - S_n = \frac{n\pi}{2} - j\frac
{\pi}{2} - \delta = \frac{(n-j)\pi}{2} - \delta$. Setting $j' = n - j$, we get $
|\operatorname{angleSum}(n) - j'\pi/2| = |\delta| < 2/n$. $\square$

## Theorem `tan_arctan_sum_not_integer` (research, **OPEN**)

**Claim (Amdeberhan–Medina–Moll, 2008).** For every $n \geq 5$, $x_n$ is not an
integer.

**Status.** This is an **open conjecture**. It is explicitly marked `@[category
research open]` in the file. The reference (Ono, arXiv:2607.05739) proves the we
aker result that integer values are *rare* (the exceptional set has density $O(\
log N)$), not that they are absent for $n \geq 5$. Computational verification co
nfirms $A_n \nmid B_n$ for all $5 \leq n \leq 3000$, but no proof is known.

The two solved theorems above (`kernel_dvd_of_eq_intCast` and `exists_near_half_
pi`) are the key ingredients in Ono's proof of *rarity*: any integer value force
s $|x_n| \geq \sqrt{K_n - 1}$ (which grows), and large $|x_n|$ forces $\operator
name{angleSum}(n)$ to lie within $2/n$ of a half-integer multiple of $\pi$. Sinc
e $\operatorname{angleSum}(n) \to \sum_{k=1}^\infty \arctan(1/k) = \infty$ (dive
rgent), and the target points $j\pi/2$ are spaced $\pi/2$ apart, only $O(\log N)
$ values of $n \leq N$ can land that close — giving rarity, but not nonexistence
.

**I cannot prove this conjecture, as it is open.**
