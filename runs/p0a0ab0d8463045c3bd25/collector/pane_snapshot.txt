## Proof

Let $t = 2013$. We show that there exists a graph with chromatic number $> t$ in
 which every cycle has length $> t$.

**Construction via the probabilistic method.** Consider the Erdős–Rényi random g
raph $G \sim G(n,p)$ on $n$ vertices (with $n$ to be chosen large), where each e
dge appears independently with probability
$$p = n^{-1+1/(2t)}.$$

---

**Step 1: Bounding the number of short cycles.**

Let $X$ denote the number of cycles of length $\le t$ in $G$. The number of (lab
eled) cycles of length $i$ in $K_n$ is at most $n^i/(2i)$, so
$$\mathbb{E}[X] = \sum_{i=3}^{t} \frac{n^i}{2i}\,p^i = \sum_{i=3}^{t} \frac{(np)
^i}{2i}.$$

Since $np = n^{1/(2t)}$ and $i \le t$, we have $(np)^i \le (np)^t = n^{1/2}$, gi
ving
$$\mathbb{E}[X] \le \frac{t\, n^{1/2}}{6}.$$

By Markov's inequality,
$$\Pr\!\left[X \ge \tfrac{n}{2}\right] \le \frac{2\,\mathbb{E}[X]}{n} \le \frac{
t}{3\sqrt{n}}.$$

For $n > 16t^2/9$, this is $< 1/4$.

---

**Step 2: Bounding the independence number.**

Set $s = \lceil n/(2t)\rceil$. We bound the probability that $\alpha(G) \ge s$.
(If an independent set of size $\ge s$ exists, then one of size exactly $s$ exis
ts, so a union bound over $s$-subsets suffices.)

$$\Pr[\alpha(G) \ge s] \le \binom{n}{s}(1-p)^{\binom{s}{2}} \le \left(\frac{en}{
s}\right)^s e^{-p\,s(s-1)/2}.$$

Since $s \ge n/(2t)$, we have $en/s \le 2et$, so $(en/s)^s \le (2et)^{n/(2t)+1}$
.

For $n \ge 4t$, we have $s - 1 \ge n/(4t)$ and $s \ge n/(2t)$, hence
$$\frac{p\,s(s-1)}{2} \ge \frac{n^{-1+1/(2t)} \cdot \frac{n}{2t}\cdot\frac{n}{4t
}}{2} = \frac{n^{1+1/(2t)}}{16t^2}.$$

Therefore
$$\Pr[\alpha(G) \ge s] \le (2et)^{n/(2t)+1} \cdot \exp\!\left(-\frac{n^{1+1/(2t)
}}{16t^2}\right).$$

Taking logarithms:
$$\log \Pr[\alpha(G) \ge s] \le \left(\frac{n}{2t}+1\right)\ln(2et) - \frac{n^{1
+1/(2t)}}{16t^2}.$$

Since $1 + \frac{1}{2t} > 1$, the term $n^{1+1/(2t)}$ grows faster than $n$, so
the right-hand side $\to -\infty$ as $n \to \infty$. For $n$ sufficiently large,
 $\Pr[\alpha(G) \ge s] < 1/4$.

---

**Step 3: A good graph exists.**

By the union bound,
$$\Pr\!\left[X \ge \tfrac{n}{2}\ \text{or}\ \alpha(G) \ge s\right] < \frac{1}{4}
 + \frac{1}{4} = \frac{1}{2}.$$

Hence with positive probability, **both** $X < n/2$ and $\alpha(G) < s = \lceil
n/(2t)\rceil$ hold. In particular, such a graph $G$ exists.

---

**Step 4: Removing short cycles.**

From $G$, remove one vertex from each cycle of length $\le t$. Since $X < n/2$,
we remove fewer than $n/2$ vertices, leaving a graph $G'$ on $n' > n/2$ vertices
. By construction, $G'$ has **no cycle of length $\le t$**, so every cycle in $G
'$ has length $> t = 2013$.

**Claim:** $\chi(G') > t$.

Suppose for contradiction that $\chi(G') \le t$. Then $G'$ contains an independe
nt set of size $\ge \lceil n'/t \rceil$. Since $n' > n/2$, we have $\lceil n'/t\
rceil \ge \lceil n/(2t)\rceil = s$. But every independent set in $G'$ is also in
dependent in $G$, so $\alpha(G) \ge s$—contradicting $\alpha(G) < s$.

Therefore $\chi(G') > t = 2013$.

---

**Conclusion.** The graph $G'$ has chromatic number $> 2013$ and all of its cycl
es have length $> 2013$. Such a graph exists. $\blacksquare$
