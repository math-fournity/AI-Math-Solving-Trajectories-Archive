## Proof

**Claim:** Yes, $\lim_{\delta \to 0} f(t,\delta,\lceil \delta^{-\gamma}\rceil) =
 0$ for every $t > 0$ and every $0 < \gamma < 1$.

**Setup.** Set $\lambda = t/\delta$ and $N = \lceil \delta^{-\gamma}\rceil$. The
n

$$f(t,\delta,N) = e^{-\lambda}\sum_{k=0}^{N-1}\frac{\lambda^k}{k!} = \Pr\!\big(X
 \le N-1\big), \qquad X \sim \mathrm{Poisson}(\lambda).$$

As $\delta\to 0$, both $\lambda = t/\delta \to \infty$ and $N \to \infty$. The k
ey observation is the **relative growth rate**:

$$\frac{N}{\lambda} \;\le\; \frac{\delta^{-\gamma}+1}{t/\delta} \;=\; \frac{\del
ta^{1-\gamma}}{t} + \frac{\delta}{t} \;\longrightarrow\; 0,$$

since $1-\gamma > 0$. Thus the threshold $N-1$ is asymptotically negligible comp
ared to the mean $\lambda$, and we are asking for the probability that a Poisson
 variable with large mean lands far below its mean.

**Chernoff (lower-tail) bound.** For $X\sim\mathrm{Poisson}(\lambda)$ and any $a
 < \lambda$, optimizing the Markov inequality over $s<0$ (setting $e^s = a/\lamb
da$) gives

$$\Pr(X \le a) \;\le\; \exp\!\Big(-\lambda + a + a\ln\frac{\lambda}{a}\Big).$$

Apply this with $a = N-1$. Since $N = \lceil\delta^{-\gamma}\rceil$, we have $a
= N-1 < \delta^{-\gamma}$, and for $\delta$ small enough, $a < \lambda$ (because
 $\delta^{-\gamma} \ll t/\delta$). Define the exponent

$$E(\delta) \;=\; -\lambda + a + a\ln\frac{\lambda}{a}.$$

**Bounding the exponent.** The function $g(a) = a + a\ln(\lambda/a)$ has derivat
ive $g'(a) = \ln(\lambda/a) > 0$ for $a < \lambda$, so it is increasing in $a$.
Using $a < \delta^{-\gamma}$ as an upper bound:

$$E(\delta) \;<\; -\frac{t}{\delta} + \delta^{-\gamma}\!\left(1 + \ln\frac{t/\de
lta}{\delta^{-\gamma}}\right) = -\frac{t}{\delta} + \delta^{-\gamma}\!\Big(1 + \
ln t + (1-\gamma)\ln\tfrac{1}{\delta}\Big).$$

**The negative term dominates.** Compare the magnitudes:

$$\frac{\delta^{-\gamma}\big(1+\ln t + (1-\gamma)\ln(1/\delta)\big)}{t/\delta} \

g) \;\longrightarrow\; 0,$$

because $\delta^{1-\gamma}\to 0$ (as $1-\gamma>0$) and $\delta^{1-\gamma}\ln(1/\

$$E(\delta) \;\le\; -\frac{t}{\delta}\big(1 - o(1)\big) \;\longrightarrow\; -\in

**Conclusion.** Since $E(\delta)\to -\infty$,

$$0 \;\le\; f(t,\delta,\lceil\delta^{-\gamma}\rceil) \;=\; \Pr(X \le N-1) \;\le\
