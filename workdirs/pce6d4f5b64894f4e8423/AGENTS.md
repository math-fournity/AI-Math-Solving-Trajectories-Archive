# Problem

The hub operates under two strict safety protocols regarding how packages interact when combined or processed together:
1. **The Combined Weight Rule:** If a package from the Azure Zone and a package from the Ruby Zone are placed on a scale together, their total combined weight must always be a value that belongs in the Ruby Zone.
2. **The Scaled Interaction Rule:** If the weight of an Azure Zone package is multiplied by the weight of a Ruby Zone package, the resulting numerical value must always be a weight that belongs in the Azure Zone.

In how many distinct ways can the weights {3, 6, 9, ...} be categorized into these two zones such that a package weighing exactly 546 kg is assigned to the Azure Zone?
