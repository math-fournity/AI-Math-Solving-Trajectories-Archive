## Solution

**Setting up the equation.** Let $A + B + C = 180°$ with $A, B, C$ positive inte
gers. The equation is
$$\cos A\cos B + \sin A\sin B\sin(kC) = 1.$$

**Key identity.** Using product-to-sum formulas with $A+B = 180°-C$:
$$\cos A\cos B = \tfrac{1}{2}(\cos(A-B)-\cos C), \qquad \sin A\sin B = \tfrac{1}
{2}(\cos(A-B)+\cos C).$$

Setting $s = \sin(kC)$, the equation becomes:
$$\cos(A-B)(1+s) - \cos C\,(1-s) = 2.$$

**Bounding forces $s=1$ and $A=B$.** Since $0 < C < 180°$, we have $1+\cos C > 0
$. If $s < 1$, then $1-s>0$ and:
$$\cos(A-B)(1+s) = 2 + \cos C\,(1-s).$$
Since $\cos(A-B)\le 1$:
$$1+s \ge 2+\cos C\,(1-s) \implies s(1+\cos C)\ge 1+\cos C \implies s\ge 1,$$
contradicting $s<1$. Hence $s=\sin(kC)=1$, and the equation reduces to $2\cos(A-
B)=2$, giving $\cos(A-B)=1$, i.e., **$A=B$**.

**Determining valid triangles.** With $A=B$ and $\sin(kC)=1$:
- $\sin(kC)=1$ requires $kC = 90°+360°m$. Since $kC\le 360°$ and $k,C$ are posit
ive integers, the only possibility is $kC=90°$.
- So $C\mid 90$ and $k = 90/C$.
- $A = B = (180°-C)/2$ must be a positive integer, requiring $C$ **even**.

**Even divisors of 90:** $C\in\{2,6,10,18,30,90\}$.

| $C$ | $A=B$ | $k=90/C$ | $kC$ | Triangle |
|-----|-------|----------|------|----------|
| 2   | 89    | 45       | 90   | (89,89,2) |
| 6   | 87    | 15       | 90   | (87,87,6) |
| 10  | 85    | 9        | 90   | (85,85,10) |
| 18  | 81    | 5        | 90   | (81,81,18) |
| 30  | 75    | 3        | 90   | (75,75,30) |
| 90  | 45    | 1        | 90   | (45,45,90) |

**Verification.** For each entry, $\sin(kC)=\sin 90°=1$ and $A=B$, so
$$\cos^2 A + \sin^2 A\cdot 1 = 1. \checkmark$$

Each gives a distinct similarity class (different angle triples). No other solut
ions exist.

**The number of distinct triangles is $\boxed{6}$.**
