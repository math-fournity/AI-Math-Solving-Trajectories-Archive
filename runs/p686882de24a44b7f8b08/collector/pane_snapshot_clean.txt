## Answer

The statement is **false** in general. Here is a counterexample.

**Setup.** Take $R = \mathbb{Z}$, which is a Noetherian domain. Define
$$M = \bigoplus_{p\ \text{prime}} \mathbb{Z}/p\mathbb{Z}, \qquad N = \mathbb{Q}.
$$

**$M$ is faithful.** We have $\operatorname{Ann}_{\mathbb{Z}}(\mathbb{Z}/p\mathb
b{Z}) = p\mathbb{Z}$, so
$$\operatorname{Ann}_{\mathbb{Z}}(M) = \bigcap_{p\ \text{prime}} p\mathbb{Z} = 0
,$$
since no nonzero integer is divisible by every prime. Hence $M$ is faithful.

**$N=\mathbb{Q}$ is faithful.** If $n\in\mathbb{Z}$ satisfies $n\cdot\mathbb{Q}=
0$, then in particular $n\cdot 1 = 0$, so $n=0$. Thus $\operatorname{Ann}_{\math
bb{Z}}(\mathbb{Q})=0$.

**Compute $M\otimes_{\mathbb{Z}} N$.** Tensor products commute with direct sums,
 so
$$M\otimes_{\mathbb{Z}} N \;=\; \bigoplus_{p\ \text{prime}} \bigl(\mathbb{Z}/p\m
athbb{Z}\otimes_{\mathbb{Z}}\mathbb{Q}\bigr).$$
Using the standard isomorphism $\mathbb{Z}/p\mathbb{Z}\otimes_{\mathbb{Z}} A \co
ng A/pA$, we get
$$\mathbb{Z}/p\mathbb{Z}\otimes_{\mathbb{Z}}\mathbb{Q} \;\cong\; \mathbb{Q}/p\ma
thbb{Q}.$$
But $\mathbb{Q}$ is a divisible $\mathbb{Z}$-module, so $p\mathbb{Q}=\mathbb{Q}$
 for every prime $p$, giving $\mathbb{Q}/p\mathbb{Q}=0$. Therefore
$$M\otimes_{\mathbb{Z}} N \;=\; \bigoplus_{p\ \text{prime}} 0 \;=\; 0.$$

**Conclusion.** Since $M\otimes_{\mathbb{Z}} N = 0$, its annihilator is the whol
e ring:
$$\operatorname{Ann}_{\mathbb{Z}}(M\otimes_{\mathbb{Z}} N) = \operatorname{Ann}_
{\mathbb{Z}}(0) = \mathbb{Z} \neq 0.$$

Thus, even though $R$ is a Noetherian domain and $M$, $N$ are both faithful $R$-
modules, the annihilator $\operatorname{Ann}_R(M\otimes_R N)$ need **not** be ze
ro. The claim fails for modules that are not finitely generated. $\blacksquare$
