The hypothesis is equivalent to
$$\int_{\mathbb{R}} (F - C)\,f \leq 0 \quad\text{for all nonnegative continuous

**Claim:** $\{x : F(x) > C\}$ has measure zero.

Suppose for contradiction that $m(\{F > C\}) > 0$. Since
$$\{F > C\} = \bigcup_{n=1}^{\infty} \{F > C + \tfrac{1}{n}\},$$
there exist $\varepsilon > 0$ such that $E := \{F > C + \varepsilon\}$ has posit
ive measure.

By inner regularity of Lebesgue measure, there exists a compact set $K \subseteq
 E$ with $m(K) > 0$.

Since $K$ is compact, we can choose a bounded open set $U \supseteq K$ with $m(U
 \setminus K) < \delta$, where $\delta > 0$ will be chosen below. By Urysohn's l
emma (applied to the compact $K$ and open $U$ in $\mathbb{R}$), there exists a c
ontinuous function $f:\mathbb{R}\to[0,1]$ with
$$f = 1 \text{ on } K, \qquad \operatorname{supp}(f) \subseteq U.$$
Thus $f$ is nonnegative, continuous, and compactly supported, so it is admissibl
e in $(\star)$.

**Lower bound on $\int Ff$:** Since $\operatorname{supp}(f)\subseteq U$ and $f\g
eq 0$,
$$\int Ff = \int_K Ff + \int_{U\setminus K} Ff \geq \int_K Ff.$$
On $K\subseteq E$ we have $F > C+\varepsilon$ and $f=1$, so
$$\int_K Ff > (C+\varepsilon)\,m(K). \tag{1}$$

**Upper bound on $C\int f$:** Since $f=1$ on $K$, $f=0$ on $\mathbb{R}\setminus
U$, and $0\leq f\leq 1$,
$$C\int f = C\,m(K) + C\int_{U\setminus K} f \leq C\,m(K) + C\,m(U\setminus K) <
 C\,m(K) + C\delta. \tag{2}$$

**Deriving the contradiction:** Applying $(\star)$ and combining (1), (2):
$$(C+\varepsilon)\,m(K) < \int Ff \leq C\int f < C\,m(K) + C\delta,$$
which gives
$$\varepsilon\, m(K) < C\,\delta. \tag{3}$$

n\, m(K) < \dfrac{\varepsilon\, m(K)}{2}$, a contradiction.

$$F(x) \leq C \quad\text{almost everywhere.} \qquad\blacksquare$$
