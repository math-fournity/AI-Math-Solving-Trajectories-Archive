## Solution

We recognize the relation $x^2 + y^2 + z^2 - xyz = 4$ as a classical identity sa
tisfied by numbers of the form $t + t^{-1}$.

**Key identity.** For any nonzero $u, v$, set
$$X = u + u^{-1},\quad Y = v + v^{-1},\quad Z = uv + (uv)^{-1}.$$
A direct expansion gives
$$XYZ = u^2v^2 + u^{-2}v^{-2} + u^2 + u^{-2} + v^2 + v^{-2} + 2,$$
$$X^2 + Y^2 + Z^2 = u^2v^2 + u^{-2}v^{-2} + u^2 + u^{-2} + v^2 + v^{-2} + 6,$$
so
$$X^2 + Y^2 + Z^2 - XYZ = 4. \tag{1}$$

**Parametrizing the sequence.** This identity suggests setting $a_n = u_n + u_n^
{-1}$ with the multiplicative recurrence
$$u_{n+2} = u_{n+1}\,u_n. \tag{2}$$
Then $(a_n, a_{n+1}, a_{n+2}) = (X, Y, Z)$ in the identity (1), so the given equ
ation is automatically satisfied for every $n$.

**Solving the multiplicative recurrence.** Taking logarithms, $\log u_{n+2} = \l
og u_{n+1} + \log u_n$, which is Fibonacci. With $F_1 = F_2 = 1$, $F_{n+2} = F_{
n+1} + F_n$, the solution is
$$u_n = u_1^{F_{n-2}}\, u_2^{F_{n-1}} = u_1^{F_{n-2}+F_{n-1}}\cdot\ldots$$
More cleanly, since $F_{n-2}+F_{n-1} = F_n$:
$$u_n = u_1^{F_{n-2}}\,u_2^{F_{n-1}}.$$

**Applying initial conditions.** From $a_1 = a_2 = 3$:
$$u_1 + u_1^{-1} = 3,\qquad u_2 + u_2^{-1} = 3.$$
Both satisfy $u^2 - 3u + 1 = 0$, giving $u = \frac{3 \pm \sqrt{5}}{2}$. Choosing
 $u_1 = u_2 = u = \frac{3+\sqrt{5}}{2} > 1$ (to make the sequence increasing), w
e get
$$u_n = u^{F_{n-2}}\,u^{F_{n-1}} = u^{F_n}.$$

**General term.** Therefore
$$\boxed{\,a_n = u^{F_n} + u^{-F_n} = \left(\frac{3+\sqrt{5}}{2}\right)^{F_n} +
\left(\frac{3-\sqrt{5}}{2}\right)^{F_n}\,}$$
where $F_n$ is the Fibonacci sequence $(F_1=F_2=1,\; F_{n+2}=F_{n+1}+F_n)$.

**Verification.**
- $a_1 = u + u^{-1} = 3$ ✓, $a_2 = u + u^{-1} = 3$ ✓.

  Check $n=2$: $18^2 + 7^2 + 3^2 - 18\cdot7\cdot3 = 324+49+9-378 = 4$ ✓.
- $a_5 = u^5+u^{-5}$. Using $a_5 = a_4 a_3 - a_2 = 18\cdot7 - 3 = 123$; and $u^5
+u^{-5} = (u^2+u^{-2})(u^3+u^{-3}) - (u+u^{-1}) = 7\cdot18 - 3 = 123$ ✓.
- The sequence $3, 3, 7, 18, 123, \dots$ is (non-strictly) increasing since $u>1
$ and $F_n$ is non-decreasing. ✓

The identity (1) guarantees the recurrence holds for all $n$ by construction, an
