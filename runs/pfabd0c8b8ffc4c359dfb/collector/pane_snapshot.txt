Looking at this problem, I need to determine whether the pairwise non-constant g

stant polynomial to divide all of $I$.

**Answer: Yes.**

**Proof.**

Since $R = k[X_1, \ldots, X_n]$ is Noetherian, write $I = (f_1, \ldots, f_m)$ wi
th all $f_i \neq 0$. Let $D = \gcd(f_1, \ldots, f_m)$. Since $D \mid f_i$ for ea
ch $i$, and every element of $I$ is an $R$-linear combination $\sum r_i f_i$, we
 have $D \mid g$ for every $g \in I$. We claim $D$ is non-constant.

**The hypothesis forces $I \neq R$ and $I \neq (0)$.** Since $0 \in I$, for any
$g \in I$ we need $\gcd(0, g) = g$ to be non-constant; in particular $1 \notin I
$, so $I \neq R$. And $I = (0)$ gives $\gcd(0,0) = 0$ constant, a contradiction.

**Suppose for contradiction that $D$ is a unit.** Then no irreducible divides al
l of $f_1, \ldots, f_m$, and no $f_i$ is a unit (else $I = R$).

**Case $m = 1$:** Then $D = f_1$ is a unit, so $I = R$, already excluded.

**Case $m \geq 2$:** Let $D_1 = \gcd(f_2, \ldots, f_m)$. Since $D = \gcd(f_1, D_
1) = 1$, we have $\gcd(f_1, D_1) = 1$.

Write $f_i = D_1 \cdot g_i$ for $i = 2, \ldots, m$, and set $J' = (g_2, \ldots,
g_m)$. Then:
- $\gcd(g_2, \ldots, g_m) = 1$ (we divided out the common factor $D_1$),
- $(f_2, \ldots, f_m) = D_1 \cdot J'$.

Since $f_1$ is nonzero and non-unit, it has finitely many distinct irreducible f
actors $p_1, \ldots, p_s$.

**For each $p_j$:** since $\gcd(g_2, \ldots, g_m) = 1$, the irreducible $p_j$ do
es not divide all of $g_2, \ldots, g_m$, so $J' \not\subseteq (p_j)$.

**Applying prime avoidance:** Each $(p_j)$ is a prime ideal (as $R$ is a UFD). S
ince $J' \not\subseteq (p_j)$ for every $j$, the prime avoidance lemma gives us
$q \in J'$ with $q \notin (p_j)$ for all $j$, i.e., $\gcd(f_1, q) = 1$.

**Constructing the contradiction:** Set $g = f_1$ and $h = f_1 + D_1 q$. Both li
e in $I$:
- $g = f_1 \in I$;
- $D_1 q \in D_1 J' = (f_2, \ldots, f_m) \subseteq I$, so $h \in I$.

Since $\gcd(f_1, D_1) = 1$, in a UFD we have $\gcd(f_1, D_1 q) = \gcd(f_1, q) =
1$. Therefore:

$$\gcd(g, h) = \gcd(f_1,\; f_1 + D_1 q) = \gcd(f_1, D_1 q) = 1.$$

This is constant, **contradicting** the hypothesis that every pair of elements i
n $I$ has non-constant gcd.

**Conclusion.** The assumption that $D$ is a unit is impossible, so $D = \gcd(f_
1, \ldots, f_m)$ is a non-constant polynomial dividing every element of $I$. $\b
lacksquare$

ement of $J'$ coprime to $f_1$. (3) The identity $\gcd(a, b) = 1 \Rightarrow \gc
