## Theorem

A surjective ring homomorphism $\phi: S = F[x_1,\ldots,x_n] \to R = \prod_{i=1}^
k F_i$ exists **if and only if** each $F_i$ is a finite algebraic extension of $
F$ (with $F$ embedded in each $F_i$). In particular, the answer is **not always
yes**; it depends on this algebraicity condition.

---

## Proof

### Preliminary: Structure of quotients of $S$ isomorphic to $\prod F_i$

Since $S = F[x_1,\ldots,x_n]$ is a finitely generated $F$-algebra, any quotient
$S/I$ is also a finitely generated $F$-algebra. If $S/I \cong \prod_{i=1}^k F_i$
 where each $F_i$ is a field, then $S/I$ is a reduced Artinian ring, so $I = \ma
thfrak{m}_1 \cap \cdots \cap \mathfrak{m}_k$ for distinct maximal ideals $\mathf
rak{m}_1, \ldots, \mathfrak{m}_k$ of $S$, with $S/\mathfrak{m}_i \cong F_i$.

### ($\Rightarrow$) Necessity: Zariski's Lemma

Suppose $\phi: S \to R$ is surjective. Set $I = \ker\phi$, so $S/I \cong R = \pr
od_{i=1}^k F_i$. As above, $I = \bigcap_{i=1}^k \mathfrak{m}_i$ with $S/\mathfra
k{m}_i \cong F_i$.

By **Zariski's Lemma** (the algebraic form of the Nullstellensatz): if $A$ is a
finitely generated algebra over a field $F$ and $\mathfrak{m}$ is a maximal idea
l of $A$, then $A/\mathfrak{m}$ is a **finite algebraic extension** of $F$.

Applying this to $A = S$ and $\mathfrak{m} = \mathfrak{m}_i$: each $F_i \cong S/
\mathfrak{m}_i$ is a finite algebraic extension of $F$. $\checkmark$

### ($\Leftarrow$) Sufficiency: Construction via CRT

Suppose each $F_i$ is a finite algebraic extension of $F$. Then each $F_i$ is a
**finitely generated $F$-algebra**: if $F_i = F(\alpha_1, \ldots, \alpha_{r_i})$
 with each $\alpha_j$ algebraic over $F$, then $F_i$ is generated as an $F$-alge
bra by $\alpha_1, \ldots, \alpha_{r_i}$ (algebraic elements are integral, so $F[
\alpha_1,\ldots,\alpha_{r_i}] = F(\alpha_1,\ldots,\alpha_{r_i})$).

**Key observation:** Since $\mathbb{R} \subseteq F$ (as $F$ contains a copy of $
\mathbb{R}$, consistent with the hypothesis on the $F_i$'s), the field $F$ is **
infinite**.

**Construction (assuming $n \geq 1$):** Choose distinct elements $a_1, \ldots, a
_k \in F$ (possible since $F$ is infinite).

For each $i \in \{1,\ldots,k\}$, define a surjective $F$-algebra homomorphism
$$\phi_i : S = F[x_1, \ldots, x_n] \longrightarrow F_i$$
as follows:
- Map $x_1 \mapsto a_i$ (viewing $a_i \in F \hookrightarrow F_i$).
- Map $x_2, \ldots, x_n$ to generators of $F_i$ over $F$ (padding with $0$ if $n
-1 > r_i$, or reusing generators if $n-1 < r_i$ — but we need $n-1 \geq r_i$; se
e remark below).

This is surjective because the images of $x_2, \ldots, x_n$ generate $F_i$ as an
 $F$-algebra. Set $\mathfrak{m}_i = \ker\phi_i$; this is a maximal ideal of $S$
containing $(x_1 - a_i)$.

**Distinctness:** Since $a_i \neq a_j$ for $i \neq j$, the element $x_1 - a_i \i
n \mathfrak{m}_i$ but $x_1 - a_i \notin \mathfrak{m}_j$ (because $\phi_j(x_1 - a
_i) = a_j - a_i \neq 0$). Hence $\mathfrak{m}_i \neq \mathfrak{m}_j$ for $i \neq
 j$.

**Comaximality:** Distinct maximal ideals in a commutative ring are automaticall
y comaximal: $\mathfrak{m}_i + \mathfrak{m}_j = S$ for $i \neq j$.

**Applying the Chinese Remainder Theorem:** Since $\mathfrak{m}_1, \ldots, \math
frak{m}_k$ are pairwise comaximal,
$$S\big/\!\left(\bigcap_{i=1}^k \mathfrak{m}_i\right) \;\cong\; \prod_{i=1}^k S/
\mathfrak{m}_i \;\cong\; \prod_{i=1}^k F_i \;=\; R.$$

Composing the quotient map $S \to S/(\bigcap \mathfrak{m}_i)$ with this isomorph
ism yields a surjective ring homomorphism $\phi: S \to R$. $\checkmark$

**Remark on the number of variables:** The construction requires $n \geq 1$ (for
 the separating variable $x_1$) and $n - 1 \geq \max_i r_i$ (for generating each
 $F_i$). If $n$ is too small, we can still proceed: instead of dedicating $x_1$
solely to separation, for each $F_i$ pick a primitive element $\beta_i$ (so $F_i
 = F(\beta_i)$, possible since finite separable extensions are simple, and finit
e extensions of fields of characteristic $0$ — which holds since $\mathbb{R} \su
bseteq F$ — are separable). Then map $x_1 \mapsto \beta_i$; the kernel is the mi
nimal polynomial of $\beta_i$ over $F$. For $F_i \cong F_j$ as $F$-algebras, rep
lace $\beta_j$ by $\beta_j + c$ for generic $c \in F$ (which remains a primitive
 element for all but finitely many $c$) to ensure distinct kernels. Thus $n = 1$
 suffices.

### Conclusion

A surjective ring homomorphism $S = F[x_1,\ldots,x_n] \to R = \prod_{i=1}^k F_i$
 exists **if and only if** each $F_i$ is a finite algebraic extension of $F$.

- **Necessity** follows from Zariski's lemma: any field that is a quotient of a
finitely generated $F$-algebra by a maximal ideal must be algebraic (and finite)
 over $F$.
- **Sufficiency** follows from the Chinese Remainder Theorem: finite algebraic e
xtensions are finitely generated $F$-algebras, and the infinitude of $F$ (guaran
teed by $\mathbb{R} \subseteq F$) allows us to construct pairwise comaximal maxi
mal ideals with the prescribed residue fields.

**Counterexample showing the answer is "not always":** Take $F = \mathbb{R}$, $k
 = 1$, $F_1 = \mathbb{R}(t)$ (the field of rational functions). Then $\mathbb{R}
 \subseteq F_1$, but $F_1$ is a transcendental extension of $\mathbb{R}$, so by
Zariski's lemma, $\mathbb{R}(t)$ cannot be isomorphic to $S/\mathfrak{m}$ for an
y maximal ideal $\mathfrak{m}$ of $S = \mathbb{R}[x_1,\ldots,x_n]$. No surjectio
n exists.

**Example where it works:** Take $F = \mathbb{R}$, $F_1 = \mathbb{R}$, $F_2 = \m
athbb{C}$. Both are finite algebraic extensions of $\mathbb{R}$ (of degrees 1 an
d 2). With $S = \mathbb{R}[x]$, map $x \mapsto 0$ for $F_1 = \mathbb{R}$ (kernel
 $(x)$) and $x \mapsto i$ for $F_2 = \mathbb{C}$ (kernel $(x^2+1)$). These are c
omaximal, and CRT gives $\mathbb{R}[x]/(x(x^2+1)) \cong \mathbb{R} \times \mathb
b{C}$.
