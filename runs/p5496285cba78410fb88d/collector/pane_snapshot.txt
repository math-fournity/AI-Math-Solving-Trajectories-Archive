Proof

We work in the class of ordinals Ord. Recall the definition of ordinal
exponentiation with base α > 1:

  • α^0 = 1
  • α^{β+1} = α^β · α (successor case)
  • α^λ = sup{α^β : β < λ} for limit λ (limit case)

Lemma (Normality). For any ordinal α > 1, the function f : Ord → Ord defined by
f(β) = α^β is a normal function, i.e.:

  1. Strictly increasing: β < γ ⟹ α^β < α^γ.
  2. Continuous: for every limit ordinal λ, α^λ = sup{α^β : β < λ}.

Proof of Lemma. Continuity holds by definition. For strict monotonicity, we show
α^β < α^{β+1} for all β, which suffices (since β < γ implies α^β < α^γ by
transitivity). Indeed α^{β+1} = α^β · α > α^β · 1 = α^β because α > 1. ∎

In particular, with α = ω₁ (the first uncountable ordinal, which is > 1), the
map

$$f(\beta) = \omega_1^\beta$$

is a normal function.

Construction of the fixed point. Define a sequence (β_n)_{n < ω} by transfinite
recursion on n < ω:

  • β_0 = 0
  • β_{n+1} = f(β_n) = ω_1^{β_n}

So explicitly: $$\beta_0 = 0,\quad \beta_1 = \omega_1^0 = 1,\quad \beta_2 =
\omega_1^1 = \omega_1,\quad \beta_3 = \omega_1^{\omega_1},\quad \beta_4 =
\omega_1^{\omega_1^{\omega_1}},\ \ldots$$

Since f is strictly increasing (Lemma), the sequence is strictly increasing: $$
\beta_0 < \beta_1 < \beta_2 < \beta_3 < \cdots$$

Now set $$\beta ;=; \beta_\omega ;=; \sup{\beta_n : n < \omega}.$$

This supremum exists (the β_n form a set of ordinals) and β is a limit ordinal
(as the sup of a strictly increasing ω-sequence).

Verification that ω₁^β = β. Using continuity of f at the limit ordinal β = sup_n
β_n:

$$\omega_1^{,\beta} ;=; f!\left(\sup_{n<\omega} \beta_n\right) ;=;
\sup_{n<\omega} f(\beta_n) ;=; \sup_{n<\omega} \beta_{n+1}.$$

But $$\sup_{n<\omega} \beta_{n+1} ;=; \sup_{n<\omega} \beta_n ;=; \beta,$$

where the first equality holds because the sequence (β_{n+1})_{n<ω} = (β_1, β_2,
β_3, …) is a tail of (β_n)_{n<ω} = (β_0, β_1, β_2, …), and removing the first
term β_0 = 0 (the minimum) does not change the supremum.

Therefore $$\omega_1^{,\beta} = \beta.$$

Remark (cardinality check). One may worry whether the construction is vacuous
(e.g., whether β exists as an ordinal at all). Each β_n is a well-defined
ordinal by the recursion. The set {β_n : n < ω} is a countable set of ordinals,
so its supremum β is a well-defined ordinal. Moreover β is countable: each β_n
is countable (proved by a straightforward induction — β_0 = 0 is countable; if β
_n is countable then ω₁^{β_n} is a countable supremum of countable ordinals,
hence countable), and a countable supremum of countable ordinals is countable.
So β < ω₁, and the equation ω₁^β = β is a genuine identity of countable
ordinals. ∎
