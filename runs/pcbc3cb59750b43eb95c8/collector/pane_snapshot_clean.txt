## Proof

The partial Bell polynomial $B_{n,k}(x_1, x_2, \ldots, x_{n-k+1})$ is defined by

$$B_{n,k}(x_1, x_2, \ldots) = \sum \frac{n!}{j_1!\, j_2!\, \cdots} \left(\frac{x
_1}{1!}\right)^{j_1} \left(\frac{x_2}{2!}\right)^{j_2} \cdots$$

where the sum ranges over all sequences $(j_1, j_2, \ldots)$ of non-negative int
egers satisfying

$$j_1 + j_2 + j_3 + \cdots = k, \qquad j_1 + 2j_2 + 3j_3 + \cdots = n.$$

**Case $k = 0$.** The first condition becomes $j_1 + j_2 + j_3 + \cdots = 0$. Si
nce every $j_i$ is a non-negative integer, the only way a sum of non-negative in
tegers equals $0$ is for every term to be $0$:

$$j_1 = j_2 = j_3 = \cdots = 0.$$

Substituting into the second condition:

$$0\cdot 1 + 0\cdot 2 + 0\cdot 3 + \cdots = 0.$$

Therefore the second condition $j_1 + 2j_2 + 3j_3 + \cdots = n$ reduces to $0 =
n$.

**Consequences:**

- **If $n = 0$:** There is exactly one admissible sequence, namely the all-zero
sequence $(j_1, j_2, \ldots) = (0, 0, \ldots)$. The corresponding summand is

$$\frac{0!}{0!\, 0!\, \cdots}\left(\frac{x_1}{1!}\right)^0 \left(\frac{x_2}{2!}\
right)^0 \cdots = 1 \cdot 1 \cdot 1 \cdots = 1.$$

Hence $B_{0,0}(x_1, x_2, \ldots) = 1$.

- **If $n \geq 1$:** The only candidate sequence forced by the first condition i
s the all-zero sequence, but it yields $0 = n \geq 1$ in the second condition —
a contradiction. Thus the index set of the sum is **empty**, and

$$B_{n,0}(x_1, x_2, \ldots) = 0 \qquad (n \geq 1).$$

**Conclusion.** The second condition $j_1 + 2j_2 + 3j_3 + \cdots = n$ can be sat
isfied when $k = 0$ **only if $n = 0$**, in which case the unique solution is $j
_i = 0$ for all $i$. Consequently,

$$B_{n,0}(x_1, x_2, \ldots) = \begin{cases} 1, & n = 0, \\ 0, & n \geq 1. \end{c
ases}$$

This is consistent with the combinatorial interpretation: $B_{n,k}$ counts parti
tions of an $n$-set into $k$ blocks (weighted by the block-size statistics). Wit
h $k = 0$ blocks one can partition only the empty set ($n = 0$), giving the sing
le empty partition; for $n \geq 1$ no partition into zero blocks exists.
