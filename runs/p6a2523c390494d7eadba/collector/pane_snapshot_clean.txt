## Proof

**Step 1 — Bijection.** Finite topologies on an $n$-element set $X$ are in bijec
tion with preorders (reflexive, transitive relations) on $X$: given a topology $
\tau$, define $x \preceq y \iff$ every open set containing $x$ also contains $y$
; conversely, given a preorder, the open sets are the upward-closed sets. Under
this bijection, $T_0$ topologies correspond exactly to **partial orders** (antis
ymmetric preorders), since $T_0$ means distinct points have distinct open neighb
orhoods, i.e., $x \preceq y,\; y \preceq x \implies x = y$.

Let $P(n)$ = number of labeled partial orders on $[n]$ (= number of $T_0$ topolo
gies), and $Q(n)$ = number of labeled preorders on $[n]$ (= total number of topo
logies).

**Step 2 — Decomposition of preorders.** Every preorder $\preceq$ on $[n]$ induc
es an equivalence relation $x \sim y \iff (x \preceq y \wedge y \preceq x)$. The
 quotient $[n]/{\sim}$ carries a canonical partial order. If the quotient has $k
$ classes, the preorder is determined by (i) a partition of $[n]$ into $k$ nonem
pty blocks and (ii) a partial order on those $k$ blocks. Thus:

$$Q(n) = \sum_{k=1}^{n} S(n,k)\, P(k),$$

where $S(n,k)$ is the Stirling number of the second kind. The $T_0$ topologies c
orrespond to the $k=n$ term (the discrete partition), so the proportion of $T_0$
 topologies is:

$$\frac{P(n)}{Q(n)} = \frac{1}{1 + R(n)}, \qquad R(n) := \sum_{k=1}^{n-1} \frac{
S(n,k)\,P(k)}{P(n)}.$$

We prove $R(n) \to 0$.

**Step 3 — Kleitman–Rothschild asymptotic.** By the Kleitman–Rothschild theorem
(1975), almost all partial orders on $[n]$ have height 3 with level sizes near $
(n/4,\, n/2,\, n/4)$. Evaluating the dominant contribution:

A 3-level poset with levels $(a,b,c)$, $a+b+c=n$, is determined by choosing the
partition into levels and bipartite comparability graphs $G_{12} \subseteq L_1 \
times L_2$, $G_{23} \subseteq L_2 \times L_3$ (the $L_1$–$L_3$ comparabilities a
re then forced by transitivity). For $(a,b,c)$ near $(n/4, n/2, n/4)$, the level
 constraints (every level-2 element has neighbors in both directions, etc.) remo
ve only a $o(1)$ fraction, giving approximately $\binom{n}{a,b,c}\, 2^{b(a+c)}$
posets. Summing over all level sizes:

$$T(n) = \sum_{b=0}^{n} \binom{n}{b}\, 2^{b(n-b)} \cdot 2^{n-b} = \sum_{b=0}^{n}
 \binom{n}{b}\, 2^{(b+1)(n-b)}.$$

The exponent $g(b) = (b+1)(n-b)$ is maximized at $b^* = (n-1)/2$ with $g(b^*) =
(n+1)^2/4 = n^2/4 + n/2 + 1/4$. A Gaussian approximation around $b^*$ (using $\b
inom{n}{b} \approx 2^n / \sqrt{\pi n/2}$ and $g(b) \approx g(b^*) - (b - b^*)^2$
) gives:

$$T(n) = \Theta\!\left(\frac{2^{n^2/4 + 3n/2}}{\sqrt{n}}\right), \qquad \text{so
 } \log_2 P(n) = \frac{n^2}{4} + \frac{3n}{2} + O(\log n), \tag{$\star$}$$

since $P(n) = (1+o(1))\,T(n)$ by KR.

**Step 4 — Bounding $R(n)$.** Write $k = n - j$ with $1 \leq j \leq n-1$. From $
(\star)$:

$$\log_2 \frac{P(n-j)}{P(n)} = \frac{(n-j)^2 - n^2}{4} + \frac{3(n-j) - 3n}{2} +
 O(\log n) = -\frac{jn}{2} + \frac{j^2}{4} - \frac{3j}{2} + O(\log n). \tag{1}$$

Using the bound $S(n, n-j) \leq n^{2j}$ (each of $j$ block-merges is determined
by choosing a pair of elements):

$$\log_2 \frac{S(n,n-j)\,P(n-j)}{P(n)} \leq 2j\log_2 n - \frac{jn}{2} + \frac{j^
2}{4} + O(\log n). \tag{2}$$

We split $R(n) = \sum_{j=1}^{n-1} \frac{S(n,n-j)\,P(n-j)}{P(n)}$ into three rang
es.

**Range A: $1 \leq j \leq n/4$.** From (2), the exponent is $\leq j(2\log_2 n -
n/2 + n/16) + O(\log n) = j(2\log_2 n - 7n/16) + O(\log n)$. For large $n$, $7n/
16 \gg 2\log_2 n$, so each term is $\leq 2^{-7n/16 + O(\log n)} = 2^{-\Omega(n)}
$. Summing over $O(n)$ terms gives $o(1)$.

**Range B: $n/4 < j \leq n/2$.** From (2), the exponent is $\leq 2j\log_2 n - jn
/2 + j^2/4 + O(\log n) \leq n\log_2 n - n^2/8 + n^2/16 + O(\log n) = n\log_2 n -
 n^2/16 + O(\log n) \to -\infty$. Each term is $2^{-\Omega(n^2)}$, so the sum is
 $o(1)$.

**Range C: $j > n/2$ (i.e., $k < n/2$).** Here $S(n,k) \leq k^n \leq (n/2)^n = 2
^{n\log_2 n - n}$ and $P(k) \leq 2^{k^2/4 + 3k/2 + O(\log n)} \leq 2^{n^2/16 + 3
n/4 + O(\log n)}$, while $P(n) \geq 2^{n^2/4 + 3n/2 - O(\log n)}$. Thus:

$$\log_2 \frac{S(n,k)\,P(k)}{P(n)} \leq n\log_2 n - n + \frac{n^2}{16} + \frac{3
n}{4} - \frac{n^2}{4} - \frac{3n}{2} + O(\log n) = n\log_2 n - \frac{3n^2}{16} -
 \frac{7n}{4} + O(\log n) \to -\infty.$$

The $-3n^2/16$ dominates $n\log_2 n$, so each term is $2^{-\Omega(n^2)}$ and the
 sum over $O(n)$ terms is $o(1)$.

**Step 5 — Conclusion.** All three ranges contribute $o(1)$, so $R(n) \to 0$ as
$n \to \infty$. Therefore:

$$\frac{P(n)}{Q(n)} = \frac{1}{1 + R(n)} \longrightarrow \frac{1}{1 + 0} = 1.$$

The proportion of finite topologies of size $n$ that are $T_0$ approaches $\boxe
d{1}$ as $n \to \infty$.
