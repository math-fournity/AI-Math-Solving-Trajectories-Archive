**Proof.**

Yes. We construct an explicit sequence whose set of limit points contains every
rational number.

**Enumeration of the rationals.** Since $\mathbb{Q}$ is countable, fix an enumer
ation
$$\mathbb{Q}=\{r_1,r_2,r_3,\dots\}.$$

**Construction of the sequence.** Define a sequence $(a_n)_{n\geq 1}$ by laying
out successive "blocks," where the $k$-th block lists the first $k$ rationals:
$$(\underbrace{r_1}_{\text{block 1}}\,,\;\underbrace{r_1,r_2}_{\text{block 2}}\,
,\;\underbrace{r_1,r_2,r_3}_{\text{block 3}}\,,\;\dots\,,\;\underbrace{r_1,r_2,\
dots,r_k}_{\text{block }k}\,,\;\dots).$$
Concretely, the sequence begins
$$r_1,\; r_1,r_2,\; r_1,r_2,r_3,\; r_1,r_2,r_3,r_4,\;\dots$$

**Every rational is a limit point.** Fix any rational $r_i$. In every block $k\g
e i$, the value $r_i$ appears once. Hence $r_i$ occurs as a term of $(a_n)$ infi
nitely many times (once in each of blocks $i, i+1, i+2, \dots$). The subsequence
 formed by taking every occurrence of $r_i$ is the constant sequence
$$r_i,\, r_i,\, r_i,\, \dots,$$
which converges to $r_i$. Therefore $r_i$ is a limit point of $(a_n)$.

Since $r_i\in\mathbb{Q}$ was arbitrary, **every rational number is a limit point
** of $(a_n)$.

**Remark (the set of limit points is exactly $\mathbb{R}$, in fact).** The const
ruction above guarantees that $\mathbb{Q}\subseteq L(a_n)$, which already answer
s the question affirmatively. We note for completeness that the set of limit poi
nts is actually all of $\mathbb{R}$: given any $x\in\mathbb{R}$ and any $\vareps
ilon>0$, the interval $(x-\varepsilon,x+\varepsilon)$ contains infinitely many r
ationals, and each of them appears infinitely often in $(a_n)$, so infinitely ma
ny terms of $(a_n)$ lie in $(x-\varepsilon,x+\varepsilon)$. Thus $x$ is a limit
point. So $L(a_n)=\mathbb{R}$, which in particular contains $\mathbb{Q}$.
