### Setup

Let $v$ be the carrier's speed in the Loading Zone (units per hour). Then:

- **Loading Zone:** distance $20$, speed $v$, time $= \dfrac{20}{v}$
- **Express Zone:** distance $40$, speed $v + 20$, time $= \dfrac{40}{v+20}$

The total transit time is exactly $1$ hour:

$$\frac{20}{v} + \frac{40}{v+20} = 1$$

### Solving for $v$

Multiply through by $v(v+20)$:

$$20(v+20) + 40v = v(v+20)$$
$$20v + 400 + 40v = v^2 + 20v$$
$$60v + 400 = v^2 + 20v$$
$$v^2 - 40v - 400 = 0$$

Apply the quadratic formula:

$$v = \frac{40 \pm \sqrt{1600 + 1600}}{2} = \frac{40 \pm \sqrt{3200}}{2} = \frac
{40 \pm 40\sqrt{2}}{2} = 20 \pm 20\sqrt{2}$$

Taking the positive root (speed must be positive):

$$v = 20 + 20\sqrt{2}$$

### Time in the Express Zone

$$t_{\text{express}} = \frac{40}{v+20} = \frac{40}{(20+20\sqrt{2})+20} = \frac{4
0}{40+20\sqrt{2}} = \frac{40}{20(2+\sqrt{2})} = \frac{2}{2+\sqrt{2}}$$

Rationalize:

$$t_{\text{express}} = \frac{2}{2+\sqrt{2}} \cdot \frac{2-\sqrt{2}}{2-\sqrt{2}}
= \frac{2(2-\sqrt{2})}{4-2} = \frac{2(2-\sqrt{2})}{2} = 2 - \sqrt{2}$$

### Verification

The Loading Zone time is:

$$t_{\text{loading}} = \frac{20}{20+20\sqrt{2}} = \frac{1}{1+\sqrt{2}} = \sqrt{2
}-1$$

Total: $t_{\text{loading}} + t_{\text{express}} = (\sqrt{2}-1) + (2-\sqrt{2}) =
1$ hour. ✓

### Converting to minutes

$$t_{\text{express}} = (2-\sqrt{2}) \text{ hours} = (2-\sqrt{2})\times 60 = 120
- 60\sqrt{2} \text{ minutes}$$

With $\sqrt{2} \approx 1.41421$:

$$120 - 60(1.41421) = 120 - 84.853 = 35.147 \text{ minutes}$$

### Final Answer

Rounded to the nearest minute, the carrier spent **35 minutes** traveling throug
h the Express Zone.
