### 分析平衡条件

设 $b_i = a_i + a_{i+1}$（下标模 $2n$）。平衡条件 $a_i + a_{i+1} = a_{i+n} + a_{
i+n+1}$ 等价于 $b_i = b_{i+n}$，即序列 $(b_i)$ 以 $n$ 为周期。

定义 $d_i = a_{i+n} - a_i$（$i = 1, \ldots, n$）。由平衡条件：

$$a_i + a_{i+1} = a_{i+n} + a_{i+n+1} \implies a_{i+n} - a_i = a_{i+1} - a_{i+n+
1} \implies d_i = -d_{i+1}$$

因此 $d_{i+1} = -d_i$，即 $d_i$ 交替：$d_i = (-1)^{i-1} c$，其中 $c = d_1$。

**一致性条件：** 注意 $d_{n+1} = a_{2n+1} - a_{n+1} = a_1 - a_{n+1} = -d_1 = -c$
。但由递推关系 $d_{n+1} = (-1)^n c$。因此 $(-1)^n c = -c$，即 $((-1)^n + 1)c = 0
$。

- **$n$ 为偶数：** $(-1)^n + 1 = 2$，故 $c = 0$，所有 $d_i = 0$，即 $a_{i+n} = a
_i$。每个值出现两次，但要求 $\{1,\ldots,2n\}$ 各用一次（$n \geq 3$ 时 $n < 2n$）
，**矛盾**。故偶数 $n$ 不可行。

- **$n$ 为奇数：** $(-1)^n + 1 = 0$，条件自动满足，$c$ 可任意取值。

### 奇数 $n$ 的构造

对奇数 $n$，取 $c = 1$。则：
- 奇数下标 $i$：$a_{i+n} = a_i + 1$（$a_i$ 为较小元，配对 $\{a_i, a_i+1\}$）
- 偶数下标 $i$：$a_{i+n} = a_i - 1$（$a_i$ 为较大元，配对 $\{a_i-1, a_i\}$）

所有配对形式为 $\{x, x+1\}$，恰好将 $\{1,2\}, \{3,4\}, \ldots, \{2n-1, 2n\}$ 分
成 $n$ 对。前半圈有 $(n+1)/2$ 个奇数下标位和 $(n-1)/2$ 个偶数下标位，共 $n$ 个位
置分配 $n$ 个配对，总是可行的。

**验证 $n=3$：** 配对 $\{1,2\},\{3,4\},\{5,6\}$。令 $a = (1, 4, 5, 2, 3, 6)$：
- $a_1+a_2=5 = a_4+a_5=5$ ✓
- $a_2+a_3=9 = a_5+a_6=9$ ✓
- $a_3+a_4=7 = a_6+a_1=7$ ✓

平衡条件全部满足。

### 完整的充分性论证

对任意奇数 $n \geq 3$，取 $c=1$，将配对 $\{2k-1, 2k\}$（$k=1,\ldots,n$）分配到 $
n$ 个位置：任选 $(n+1)/2$ 个配对放在奇数下标位（取奇数元为 $a_i$），其余 $(n-1)/
2$ 个放在偶数下标位（取偶数元为 $a_i$）。这给出 $\{1,\ldots,2n\}$ 的一个排列，且
满足 $d_{i+1}=-d_i$，即平衡条件。故所有奇数 $n$ 均可行。

### 结论

$S = \{n \in \mathbb{Z} : 3 \leq n \leq 100,\ n \text{ 为奇数}\} = \{3, 5, 7, \l
dots, 99\}$。

共 $(99-3)/2 + 1 = 49$ 个元素，其和为：

$$\sum_{k=1}^{49}(2k+1) = \frac{49 \times (3 + 99)}{2} = 49 \times 51 = \boxed{2
499}$$
