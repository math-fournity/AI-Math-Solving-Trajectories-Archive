**Answer: Yes, $f$ is unique.**

**Proof.**

Let $f, g : K \hookrightarrow \mathbb{R}$ be two order-preserving field embeddin
gs. We show $f = g$.

**Step 1: Both embeddings fix $\mathbb{Q}$ pointwise.**

Since $K$ is an ordered field, it has characteristic $0$, so the prime subfield
of $K$ is isomorphic to $\mathbb{Q}$ via the unique map $n \mapsto n\cdot 1_K$,
$\frac{p}{q}\mapsto \frac{p\cdot 1_K}{q\cdot 1_K}$. Any field homomorphism sends
 $1_K\mapsto 1_{\mathbb{R}}$, hence sends $n\cdot 1_K\mapsto n$ and $\frac{p\cdo
t 1_K}{q\cdot 1_K}\mapsto \frac{p}{q}$. Thus both $f$ and $g$ restrict to the id
entity on (the copy of) $\mathbb{Q}\subseteq K$.

**Step 2: Order preservation is an equivalence.**

Since $f$ is an injective order-preserving map, for all $a,b\in K$:
$$a < b \iff f(a) < f(b).$$
The forward direction is order preservation. For the reverse: if $f(a)<f(b)$, th
en $a\neq b$ (else $f(a)=f(b)$) and $a\not> b$ (else order preservation gives $f
(a)>f(b)$), so $a<b$. The same holds for $g$.

**Step 3: $f(x)$ is determined by the rational cut of $x$.**

Fix $x\in K$. For every $q\in\mathbb{Q}\subseteq K$, using Step 2 and Step 1:
$$q < x \text{ in } K \iff f(q) < f(x) \iff q < f(x) \text{ in } \mathbb{R}.$$
Likewise $q < x \iff q < g(x)$. Therefore
$$\{\,q\in\mathbb{Q} : q < f(x)\,\} \;=\; \{\,q\in\mathbb{Q} : q < x \text{ in }
 K\,\} \;=\; \{\,q\in\mathbb{Q} : q < g(x)\,\}.$$

**Step 4: Rational cuts determine real numbers.**

$\mathbb{Q}$ is dense in $\mathbb{R}$, so every real number $r$ satisfies
$$r = \sup\{\,q\in\mathbb{Q} : q < r\,\}.$$
Applying this to $r=f(x)$ and $r=g(x)$, and using the equality of the two ration
al sets from Step 3, we obtain
$$f(x) = \sup\{\,q\in\mathbb{Q}: q < x \text{ in } K\,\} = g(x).$$

Since $x\in K$ was arbitrary, $f=g$. Hence the order-preserving embedding $K\hoo
krightarrow\mathbb{R}$ is unique. $\blacksquare$
