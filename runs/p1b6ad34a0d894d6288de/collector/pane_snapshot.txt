Looking at this problem, I need to find the condition on $p$ (in terms of $m$) s
uch that $\sum_{n=1}^\infty \frac{|g(nx)|}{n^p}$ converges a.e. for every $g \in
 L^1(\mathbb{R}^m)$ with $\int|g|>0$.

**Answer: The series converges a.e. if and only if $p \geq 1-m$.**

---

## Proof

### Sufficiency: $p \geq 1-m$ implies a.e. convergence

**Case 1: $p > 1-m$.** For any bounded measurable $A \subset \mathbb{R}^m$, by T
onelli (all terms non-negative):

$$\int_A \sum_{n=1}^\infty \frac{|g(nx)|}{n^p}\,dx = \sum_{n=1}^\infty \frac{1}{
n^{p+m}} \int_{nA} |g(u)|\,du \leq \|g\|_1 \sum_{n=1}^\infty \frac{1}{n^{p+m}} <
 \infty,$$

since $p+m > 1$. Thus the sum is finite a.e. on $A$. Taking $A = B(0,k)$ for $k=
1,2,\dots$, the series converges a.e. on $\mathbb{R}^m$.

**Case 2: $p = 1-m$.** Here $\sum n^{m-1}|g(nx)|$. We use an annulus argument. F
or $0 < a < b$, set $A = \{x \in \mathbb{R}^m : a < |x| < b\}$. By Tonelli and t
he substitution $u = nx$ (Jacobian $n^m$):

$$\int_A \sum_{n=1}^\infty n^{m-1}|g(nx)|\,dx = \sum_{n=1}^\infty \frac{1}{n}\in
t_{na < |u| < nb} |g(u)|\,du = \int_{\mathbb{R}^m} |g(u)| \underbrace{\left(\sum
_{\{n\,:\,na < |u| < nb\}} \frac{1}{n}\right)}_{S(u)}\,du.$$

**Bounding $S(u)$:** For $u \neq 0$, the condition $na < |u| < nb$ means $|u|/b
< n < |u|/a$, so:

$$S(u) = \sum_{\lceil |u|/b\rceil \leq n \leq \lfloor |u|/a\rfloor} \frac{1}{n}.
$$

- If $|u| \geq b$: $S(u) \leq \int_{|u|/b}^{|u|/a+1}\frac{dt}{t} = \log\frac{|u|
+a}{|u|}\cdot\frac{b}{a} \leq \log(b/a) + \frac{a}{b} \leq \log(b/a)+1.$
- If $|u| < b$: $S(u) \leq 1 + \log(|u|/a) \leq 1 + \log(b/a).$

In all cases, $S(u) \leq 1 + \log(b/a) + 1 = 2 + \log(b/a) := C(a,b) < \infty$.

Therefore:
$$\int_A \sum_{n=1}^\infty n^{m-1}|g(nx)|\,dx \leq C(a,b)\,\|g\|_1 < \infty.$$

So the series is finite a.e. on each annulus $\{a < |x| < b\}$. Taking $a = 1/k$
, $b = k$ for $k = 1, 2, \dots$, the union covers $\mathbb{R}^m \setminus \{0\}$
, giving a.e. convergence.

### Necessity: $p < 1-m$ implies divergence a.e. for some $g$

Since $1 - p > m$, choose $a$ with $m < a < 1-p$. Define:
$$g(x) = |x|^{-a}\,\mathbf{1}_{\{|x| \geq 1\}}.$$

**Integrability:** $g \in L^1(\mathbb{R}^m)$ since $a > m$:
$$\int_{\mathbb{R}^m} |g| = \sigma(S^{m-1})\int_1^\infty r^{m-1-a}\,dr < \infty
\quad (m-1-a < -1).$$

Clearly $\int|g| > 0$.

**Divergence:** For any $x \neq 0$, $|g(nx)| = n^{-a}|x|^{-a}\,\mathbf{1}_{\{n \
geq 1/|x|\}}$, so:
$$\sum_{n=1}^\infty \frac{|g(nx)|}{n^p} = \frac{1}{|x|^a}\sum_{n \geq \lceil 1/|
x|\rceil} \frac{1}{n^{p+a}}.$$

Since $p + a < p + (1-p) = 1$, the series $\sum n^{-(p+a)}$ diverges. Hence the
sum equals $+\infty$ for every $x \neq 0$, i.e., the series diverges a.e.

### Conclusion

The series $\sum_{n=1}^\infty \frac{|g(nx)|}{n^p}$ converges almost everywhere f
or every Lebesgue integrable $g$ with $\int|g|>0$ **if and only if $p \geq 1-m$*
*.
