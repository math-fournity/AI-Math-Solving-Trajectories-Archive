## Proof

**Key identity.** We claim that for $0 < x < 2\pi$,
$$\sum_{m=1}^{\infty} J_0(mx) = \frac{1}{x} - \frac{1}{2},$$
so the series diverges like $1/x$ as $x \to 0^+$.

**Step 1: Fourier transform of $J_0$.** Using the integral representation $J_0(t
) = \frac{1}{2\pi}\int_0^{2\pi} e^{it\cos\theta}\,d\theta$, we compute (with con
vention $\hat{f}(\omega) = \int_{-\infty}^{\infty} f(t)\,e^{-i\omega t}\,dt$):
$$\hat{J}_0(\omega) = \frac{1}{2\pi}\int_0^{2\pi}\int_{-\infty}^{\infty} e^{it(\
cos\theta - \omega)}\,dt\,d\theta = \frac{1}{2\pi}\int_0^{2\pi} 2\pi\,\delta(\co
s\theta - \omega)\,d\theta.$$
For $|\omega|<1$, the equation $\cos\theta = \omega$ has two solutions in $[0,2\
pi)$, each contributing $1/|\sin\theta| = 1/\sqrt{1-\omega^2}$, giving
$$\hat{J}_0(\omega) = \frac{2}{\sqrt{1-\omega^2}}, \quad |\omega|<1; \qquad \hat
{J}_0(\omega)=0, \quad |\omega|>1.$$
Note $\hat{J}_0 \in L^1(\mathbb{R})$ (compactly supported with integrable singul
arities at $\omega = \pm 1$), and $J_0$ is a tempered distribution.

**Step 2: Poisson summation via regularization.** Since $J_0(t) \sim \sqrt{2/(\p
i t)}\cos(t-\pi/4)$ is not in $L^1$, we regularize. Set $f_\epsilon(t) = J_0(t)\
,e^{-\epsilon t^2}$, which is in $L^1 \cap L^2$ with $\hat{f}_\epsilon \in L^1$.
 The Poisson summation formula applies to $f_\epsilon$:
$$\sum_{m=-\infty}^{\infty} J_0(mx)\,e^{-\epsilon m^2 x^2} = \frac{1}{x}\sum_{k=
-\infty}^{\infty} \hat{f}_\epsilon\!\left(\frac{2\pi k}{x}\right). \tag{$\star$}
$$

**Step 3: Take $\epsilon \to 0^+$.**

*Left side of $(\star)$:* For fixed $x \in (0, 2\pi)$, the series $\sum_{m=1}^{\
infty} J_0(mx)$ converges by Dirichlet's test (using $J_0(mx) \sim \sqrt{2/(\pi
m x)}\cos(mx - \pi/4)$, the partial sums $\sum_{m \leq N} \cos(mx - \pi/4)$ are
bounded since $x \notin 2\pi\mathbb{Z}$, and $m^{-1/2} \searrow 0$). The Gaussia
n factors $e^{-\epsilon m^2 x^2} \to 1$ monotonically, so by Abel/Dirichlet unif
ormity the left side converges to $\sum_{m=-\infty}^{\infty} J_0(mx)$.

*Right side of $(\star)$:* Since $\hat{f}_\epsilon(\omega) = (\hat{J}_0 * \hat{g
}_\epsilon)(\omega)$ where $g_\epsilon(t) = e^{-\epsilon t^2}$ is an approximate
 identity in frequency, $\hat{f}_\epsilon \to \hat{J}_0$ in $L^1$. For $0 < x <
2\pi$, the support condition $|2\pi k/x| < 1$ requires $|k| < x/(2\pi) < 1$, so
only $k=0$ contributes. Thus the right side tends to $\frac{1}{x}\cdot\frac{2}{\
sqrt{1-0}} = \frac{2}{x}$.

**Step 4: Conclude.** Passing to the limit in $(\star)$:
$$\sum_{m=-\infty}^{\infty} J_0(mx) = \frac{2}{x}, \qquad 0 < x < 2\pi.$$
Since $J_0(0)=1$ and $J_0$ is even, the left side equals $1 + 2\sum_{m=1}^{\inft
y} J_0(mx)$. Therefore:
$$\boxed{\sum_{m=1}^{\infty} J_0(mx) = \frac{1}{x} - \frac{1}{2}}, \qquad 0 < x
< 2\pi.$$

**Rate of divergence.** As $x \to 0^+$,
$$\sum_{m=1}^{\infty} J_0(mx) = \frac{1}{x} - \frac{1}{2} \sim \frac{1}{x}.$$

The series diverges at rate $\dfrac{1}{x}$, with the exact leading asymptotic $\
sum_{m=1}^{\infty} J_0(mx) \sim \frac{1}{x}$ as $x \to 0^+$.
