## Proof

**Setup.** $B$ is an infinite-dimensional Banach space, $T: B \to B$ is a contin
uous (bounded) linear operator, $T(B)=B$ (surjective), and $T(x)=0 \Rightarrow x
=0$ (injective). Thus $T$ is a continuous linear bijection of $B$ onto itself.

**Key tool — Open Mapping / Bounded Inverse Theorem.** Since $T: B \to B$ is a b
ounded linear operator that is surjective between Banach spaces, the Open Mappin
g Theorem (Banach–Schauder) applies: $T$ is an open map. Since $T$ is also injec
tive, the inverse $T^{-1}: B \to B$ exists, and by the Bounded Inverse Theorem $
T^{-1}$ is continuous, hence bounded.

---

**Statement 3 is correct.** $T^{-1}$ is a bounded linear operator. Any bounded l
inear operator between normed spaces maps bounded sets to bounded sets: if $S \s
ubseteq B$ is bounded, say $\|y\| \le M$ for all $y \in S$, then $\|T^{-1}y\| \l
e \|T^{-1}\|\,\|y\| \le \|T^{-1}\| M$, so $T^{-1}(S)$ is bounded. ✓

---

**Statement 1 is false.** Suppose $T$ mapped bounded sets to compact sets, i.e.,
 $T$ were compact. Then $T^{-1} \circ T = I_B$ would be compact (composition of
a bounded operator $T^{-1}$ with a compact operator $T$ is compact). The identit
y being compact forces the closed unit ball to be compact, which by Riesz's lemm
a forces $B$ to be finite-dimensional — contradicting the hypothesis. ✗

**Statement 2 is false.** Suppose $T^{-1}$ mapped bounded sets to compact sets,
i.e., $T^{-1}$ were compact. Then $T \circ T^{-1} = I_B$ would be compact (compo
sition of bounded $T$ with compact $T^{-1}$). Again the identity is compact, for
cing $B$ finite-dimensional — contradiction. ✗

**Statement 4 is false.** Take the compact set $K = \{0\}$. Then $T(K) = \{0\}$,
 which is a singleton. A singleton is not open in any normed space (it has empty
 interior unless the space is $\{0\}$, and an infinite-dimensional Banach space
is not $\{0\}$). Hence $T$ does not map compact sets into open sets. ✗

(Equivalently: $T$ continuous maps compact sets to compact sets; in a Hausdorff
space compact sets are closed; in a connected infinite-dimensional Banach space
the only nonempty clopen set is the whole space, which is not compact — so nonem
pty compact images are not open.)

---

**Conclusion.** Only statement **3** is correct: $T^{-1}$ maps bounded sets into
 bounded sets.
