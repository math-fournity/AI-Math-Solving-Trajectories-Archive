## Proof of `gameValueAux_le`

The lemma states that the minimax game value never exceeds `p.claimed.card + p.p
ool.card` — the total number of elements either claimed or still in the pool. Th
is holds because each move transfers exactly one element from pool to claimed (g
rowing claimed by at most 1 and shrinking pool by exactly 1), so the sum `claime
d.card + pool.card` is non-increasing after every move.

**Base case** (`fuel = 0`): `gameValueAux 0 turn p = p.claimed.card ≤ p.claimed.
card + p.pool.card`. ✓

**Inductive case** (`fuel = succ fuel`): By the induction hypothesis, for each l
egal move `x`:

- Since `x ∈ legalMoves p`, we have `x ∈ p.pool` (by `mem_legalMoves`).
- After applying the move: `(applyMove p x).claimed = insert x p.claimed` and `(
applyMove p x).pool = p.pool.erase x`.
- `(insert x p.claimed).card ≤ p.claimed.card + 1` (inserting one element grows
cardinality by at most 1).
- `(p.pool.erase x).card = p.pool.card - 1` (erasing a member decreases cardinal
ity by exactly 1, and `p.pool.card ≥ 1` since `x ∈ p.pool`).
- Therefore `(applyMove p x).claimed.card + (applyMove p x).pool.card ≤ (p.claim
ed.card + 1) + (p.pool.card - 1) = p.claimed.card + p.pool.card`.
- By IH applied to the new position: `gameValueAux fuel (!turn) (applyMove p x)
≤ (applyMove p x).claimed.card + (applyMove p x).pool.card ≤ p.claimed.card + p.
pool.card`.

Now the recursion takes max' (if `turn = true`) or min' (if `turn = false`) over
 all such values. Since **every** value in the image is `≤ p.claimed.card + p.po
ol.card`:

- **Max' case**: The maximum of values all `≤ B` is `≤ B`. ✓
- **Min' case**: The minimum of values all `≤ B` is `≤ B` (since `min' ≤` any el
ement `≤ B`). ✓

If there are no legal moves, the recursion returns `p.claimed.card ≤ p.claimed.c
ard + p.pool.card`. ✓

```lean
@[category API, AMS 5]
lemma gameValueAux_le {n : ℕ} (fuel : ℕ) (turn : Bool) (p : GamePos n) :
    gameValueAux fuel turn p ≤ p.claimed.card + p.pool.card := by
  induction fuel generalizing turn p with
  | zero =>
    simp only [gameValueAux]
    exact Nat.le_add_right _ _
  | succ fuel ih =>
    have key : ∀ x ∈ legalMoves p,
        gameValueAux fuel (!turn) (applyMove p x) ≤ p.claimed.card + p.pool.card
 := by
      intro x hx
      have hxp : x ∈ p.pool := (mem_legalMoves.mp hx).1
      have hpool_erase : (p.pool.erase x).card = p.pool.card - 1 :=
        Finset.card_erase_of_mem hxp
      have hpool_pos : 0 < p.pool.card := Finset.card_pos.mpr ⟨x, hxp⟩
      have hclaim_insert : (insert x p.claimed).card ≤ p.claimed.card + 1 := by
        by_cases hxc : x ∈ p.claimed
        · rw [Finset.card_insert_of_mem hxc]; omega
        · rw [Finset.card_insert_of_not_mem hxc]; omega
      calc gameValueAux fuel (!turn) (applyMove p x)
          ≤ (applyMove p x).claimed.card + (applyMove p x).pool.card :=
            ih (!turn) (applyMove p x)
        _ = (insert x p.claimed).card + (p.pool.erase x).card := rfl
        _ ≤ p.claimed.card + p.pool.card := by
          rw [hpool_erase]; linarith [hclaim_insert, hpool_pos]
    simp only [gameValueAux]
    split_ifs with hne ht
    · -- Prolonger turn (turn = true): max' of values all ≤ B is ≤ B
      exact Finset.max'_le (fun v hv => by
        obtain ⟨x, hx, rfl⟩ := Finset.mem_image.mp hv
        exact key x hx)
    · -- Shortener turn (turn = false): min' of values all ≤ B is ≤ B
      obtain ⟨v, hv⟩ := hne
      obtain ⟨x, hx, rfl⟩ := Finset.mem_image.mp hv
      exact Nat.le_trans (Finset.min'_le _ hv) (key x hx)
    · -- No legal moves: returns p.claimed.card
      exact Nat.le_add_right _ _
```

### Key steps explained

1. **`key` hypothesis**: For every legal move `x`, the recursive call `gameValue
Aux fuel (!turn) (applyMove p x)` is bounded by `p.claimed.card + p.pool.card`.
This follows from:
   - The IH applied to the post-move position gives a bound of `(applyMove p x).
claimed.card + (applyMove p x).pool.card`.
   - The post-move sum equals `(insert x p.claimed).card + (p.pool.erase x).card
`, which is at most `(p.claimed.card + 1) + (p.pool.card - 1) = p.claimed.card +
 p.pool.card` (using `p.pool.card ≥ 1` since `x ∈ p.pool`).

2. **Max' case** (`turn = true`): `Finset.max'_le` states that if every element
of a finset is `≤ B`, then `max' ≤ B`. Each element of `vals` is `f x` for some
`x ∈ legalMoves p`, and `key x hx` gives `f x ≤ B`.

3. **Min' case** (`turn = false`): Pick any `v ∈ vals` (exists by `hne : vals.No
nempty`). Then `Finset.min'_le _ hv` gives `min' ≤ v`, and `key` gives `v ≤ B`.
By transitivity, `min' ≤ B`.

4. **Empty case**: No legal moves means the game is saturated; the recursion ret
urns `p.claimed.card`, which is trivially `≤ p.claimed.card + p.pool.card`.
