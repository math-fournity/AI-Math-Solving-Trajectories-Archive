## Answer

**No, $Y$ is not necessarily second-countable.** The statement fails when $f$ is
 not surjective. (The problem does not assume surjectivity.)

### Counterexample

Let $X = \{\ast\}$ with the trivial topology $\tau = \{\varnothing, X\}$. Then $
X$ is second-countable: a countable base is $\mathcal{B}_X = \{X\}$.

Let $Y = \mathbb{R}$ equipped with the **discrete** topology $\sigma = \mathcal{
P}(\mathbb{R})$. The discrete topology on an uncountable set is **not** second-c
ountable: any base must contain every singleton $\{y\}$ (since $\{y\}$ is open a
nd the only open set contained in $\{y\}$ that contains $y$ is $\{y\}$ itself),
so any base has cardinality at least $|\mathbb{R}|$, which is uncountable.

Pick $y_0 = 0 \in Y$ and define $f : X \to Y$ by $f(\ast) = 0$.

- **$f$ is continuous.** For any open $V \subseteq Y$, $f^{-1}(V)$ is either $\v
arnothing$ (if $0 \notin V$) or $X$ (if $0 \in V$); both are open in $X$.
- **$f$ is open.** The open sets of $X$ are $\varnothing$ and $X$. We have $f(\v
arnothing) = \varnothing$ (open) and $f(X) = \{0\}$, which is open in $Y$ becaus
e $Y$ is discrete (every singleton is open).

Thus $f$ is continuous and open, $X$ is second-countable, yet $Y$ is **not** sec
ond-countable. $\square$

### Remark (the surjective case)

The obstruction is purely the lack of surjectivity. If one adds the hypothesis t
hat $f$ is **surjective**, then $Y$ **is** necessarily second-countable: given a
 countable base $\{B_n\}_{n\in\mathbb{N}}$ of $X$, the family $\{f(B_n)\}_{n\in\
mathbb{N}}$ is a countable collection of open sets in $Y$ (each $f(B_n)$ is open
 because $f$ is open), and it forms a base of $Y$. Indeed, for any open $V \subs
eteq Y$ and any $y \in V$, surjectivity gives $x \in X$ with $f(x) = y$; continu
ity gives $f^{-1}(V)$ open in $X$ containing $x$, so some $B_n$ satisfies $x \in
 B_n \subseteq f^{-1}(V)$, whence $y = f(x) \in f(B_n) \subseteq f(f^{-1}(V)) =
V$ (the last equality uses surjectivity). Hence $\{f(B_n)\}$ is a countable base
 of $Y$.

So the precise answer to the question as stated (without surjectivity) is **no**
.
