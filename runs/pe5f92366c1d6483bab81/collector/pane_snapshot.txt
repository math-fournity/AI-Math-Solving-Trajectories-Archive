## Proof

**Key inequality.** I claim that for all $t \in [-1, 1]$:
$$t^3 \le \tfrac{3}{4}\,t + \tfrac{1}{4},$$
with equality if and only if $t = 1$ or $t = -\tfrac{1}{2}$.

*Proof of claim.* Define $p(t) = t^3 - \tfrac{3}{4}t - \tfrac{1}{4}$. We check:
- $p(1) = 1 - \tfrac{3}{4} - \tfrac{1}{4} = 0$,
- $p(-\tfrac{1}{2}) = -\tfrac{1}{8} + \tfrac{3}{8} - \tfrac{1}{4} = 0$.

Since $p$ is a cubic with leading coefficient $1$ and the coefficient of $t^2$ i
s $0$, the sum of roots is $0$. The roots are $1, -\tfrac{1}{2}, r$ with $1 + (-
\tfrac{1}{2}) + r = 0$, giving $r = -\tfrac{1}{2}$. Thus:
$$p(t) = (t - 1)\!\left(t + \tfrac{1}{2}\right)^2.$$
For $t \in [-1, 1]$, we have $(t + \tfrac{1}{2})^2 \ge 0$ and $(t - 1) \le 0$, s
o $p(t) \le 0$. Equality holds iff $t = 1$ or $t = -\tfrac{1}{2}$. $\square$

**Upper bound.** For any admissible $f$ (continuous, $-1 \le f \le 1$, $\int_0^1
 f = 0$), applying the pointwise inequality and integrating:
$$\int_0^1 f(x)^3\,dx \le \int_0^1 \left(\tfrac{3}{4}f(x) + \tfrac{1}{4}\right)d
x = \tfrac{3}{4}\cdot 0 + \tfrac{1}{4} = \tfrac{1}{4}.$$

**The bound is sharp (supremum is achieved in the limit).** We construct a famil
y of continuous functions approaching $\tfrac{1}{4}$.

For $n \ge 6$, define:
$$f_n(x) = \begin{cases} 1 & 0 \le x \le \tfrac{1}{3} - \tfrac{1}{n}, \\[4pt] 1
- \tfrac{3n}{4}\!\left(x - \tfrac{1}{3} + \tfrac{1}{n}\right) & \tfrac{1}{3} - \
tfrac{1}{n} \le x \le \tfrac{1}{3} + \tfrac{1}{n}, \\[4pt] -\tfrac{1}{2} & \tfra
c{1}{3} + \tfrac{1}{n} \le x \le 1. \end{cases}$$

This is continuous, satisfies $-1 \le f_n \le 1$, and:

*Zero-mean check.* The constant regions contribute $(\tfrac{1}{3}-\tfrac{1}{n})\
cdot 1 + (\tfrac{2}{3}-\tfrac{1}{n})\cdot(-\tfrac{1}{2}) = \tfrac{1}{3}-\tfrac{1
}{n} - \tfrac{1}{3}+\tfrac{1}{2n} = -\tfrac{1}{2n}$. The linear transition over
length $\tfrac{2}{n}$ has average value $\tfrac{1+(-1/2)}{2} = \tfrac{1}{4}$, co

n} + \tfrac{1}{2n} = 0$. ✓

*Integral of $f_n^3$.* The constant regions contribute:
$$\left(\tfrac{1}{3}-\tfrac{1}{n}\right)\cdot 1 + \left(\tfrac{2}{3}-\tfrac{1}{n

12}+\tfrac{1}{8n} = \tfrac{1}{4} - \tfrac{7}{8n}.$$

The transition region, via the substitution $u = 1 - \tfrac{3n}{4}t$:
$$\int_0^{2/n}\!\left(1-\tfrac{3n}{4}t\right)^3 dt = \tfrac{4}{3n}\int_{-1/2}^{1

Therefore:
$$\int_0^1 f_n^3\,dx = \tfrac{1}{4} - \tfrac{7}{8n} + \tfrac{5}{16n} = \tfrac{1}
{4} - \tfrac{9}{16n} \xrightarrow{n\to\infty} \tfrac{1}{4}.$$

**Why equality is not attained.** Equality in the upper bound requires $f(x) \in

values must be constant, but then $\int_0^1 f\,dx \ne 0$. Hence $\tfrac{1}{4}$ i
