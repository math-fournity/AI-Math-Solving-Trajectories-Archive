## Proof

**Claim.** There exists an injective function $\Phi: C[0,1] \to \mathbb{R}^{\mat
hbb{N}}$.

**Construction.** Let $D = \mathbb{Q} \cap [0,1]$. This is a countable dense sub
set of $[0,1]$, so enumerate it as $D = \{q_1, q_2, q_3, \dots\}$. Define
$$\Phi(f) = \big(f(q_1),\, f(q_2),\, f(q_3),\, \dots\big) \in \mathbb{R}^{\mathb
b{N}}.$$

**Injectivity.** Suppose $f, g \in C[0,1]$ satisfy $\Phi(f) = \Phi(g)$, i.e. $f(
q_n) = g(q_n)$ for every $n$. Then $f$ and $g$ agree on all of $D = \mathbb{Q}\c
ap[0,1]$. Since $f - g$ is continuous on $[0,1]$ and vanishes on the dense set $
D$, it vanishes everywhere on $[0,1]$ (a continuous function that is zero on a d
ense set is identically zero). Hence $f = g$.

Therefore $\Phi$ is injective. $\blacksquare$

**Remark (cardinality perspective).** The same conclusion follows from a cardina
lity argument. A continuous function on $[0,1]$ is determined by its values on a
ny countable dense subset, so $|C[0,1]| \leq |\mathbb{R}^{\mathbb{N}}|$. Convers
ely, the constant functions embed $\mathbb{R}$ into $C[0,1]$, giving $|\mathbb{R
}| \leq |C[0,1]|$. Since $|\mathbb{R}^{\mathbb{N}}| = (2^{\aleph_0})^{\aleph_0}
= 2^{\aleph_0} = |\mathbb{R}|$, all three sets have cardinality $\mathfrak{c}$,
so an injection (indeed a bijection) must exist. The explicit construction above
 realizes such an injection concretely.
