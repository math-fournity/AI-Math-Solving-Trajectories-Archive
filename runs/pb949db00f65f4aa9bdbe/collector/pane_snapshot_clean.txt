## 证明

**目标：** 证明对于有限幂零群 `G` 的任意极小正规子群 `N`，`|N|` 是素数；确定 `|N
|` 的所有可能取值；并计算它们的乘积。

### 第一步：`N` 是中心的。

有限幂零群 `G` 具有每个非平凡正规子群都与中心 `Z(G)` 非平凡相交的性质。（这是幂
零群的标准特征：升中心列 `1 = Z_0 \trianglelefteq Z_1 \trianglelefteq \cdots \tr
ianglelefteq Z_c = G`，其中 `Z_{i+1}/Z_i = Z(G/Z_i)`；对于任何非平凡正规 `M \tri
anglelefteq G`，取最小的 `i` 使得 `M \cap Z_i \neq 1`，那么 `M \cap Z_i \leq Z(G
)`，因此 `M \cap Z(G) \neq 1`。）

将此应用于 `N`：`N \cap Z(G) \neq 1`。但 `N \cap Z(G)` 是 `G` 的正规子群（两个正
规子群的交集），且包含在 `N` 中。根据 `N` 的极小性，`N \cap Z(G) = N`，即 **`N \
leq Z(G)`**。

### 第二步：`N` 是初等交换 p-群。

由于 `N \leq Z(G)`，`N` 是交换群。一个交换的极小正规子群是初等交换 p-群：对于某
个素数 `p`，`N \cong (\mathbb{Z}/p)^k`。原因：`N` 是交换 p-群（它是有限交换群，
其每个 Sylow 子群在 `G` 中都是正规的，且 `N` 的极小性迫使它为单个 Sylow 子群）；
`N` 的 Frattini 子群 `\Phi(N) = N^p[N,N] = N^p` 在 `G` 中是正规的（它是 `N` 的特
征子群），且 `\Phi(N) < N`，因此根据极小性，`\Phi(N) = 1`，所以 `N` 是初等交换的
。

### 第三步：`|N| = p` 是素数。

由于 `N \leq Z(G)`，**`N` 的每个子群在 `G` 中都是正规的**（中心子群是正规的）。
如果 `|N| = p^k` 且 `k \geq 2`，那么 `N` 拥有阶为 `p` 的非平凡正规子群 `1 < H <
N`，这与 `N` 的极小性矛盾。因此 `k = 1` 且 **`|N| = p`**，是一个素数。

### 第四步：每个素数都是可实现的。

对于任意素数 `p`，取 `G = \mathbb{Z}/p`（有限循环群，因此是幂零群）。唯一的非平
凡正规子群是 `G` 本身，所以 `N = G` 是极小正规子群，且 `|N| = p`。因此，**每个素
数 `p` 都作为 `|N|` 的值出现**。

### 第五步：可能取值的集合及其乘积。

根据步骤 1–3，`|N|` 必须是素数。根据步骤 4，每个素数都会出现。因此，`|N|` 的所有
可能取值的集合恰好是**所有素数的集合**：

$$\{ |N| : G \text{ finite nilpotent},\ N \trianglelefteq G \text{ minimal norma
l} \} = \{2, 3, 5, 7, 11, 13, \ldots\}.$$

根据欧几里得定理，存在无穷多个素数，因此该集合是无限的。所有可能取值的乘积为

$$\prod_{p \text{ prime}} p,$$

它**发散到无穷大**（素数倒数之和发散，更根本的是，部分乘积严格递增且无界，因为总
是存在下一个素数）。

### 结论

对于有限幂零群的每个极小正规子群 `N`，`|N|` 是素数，且每个素数都会出现。因此，`|
N|` 的所有可能取值的集合是所有素数的集合，它们的乘积是一个无穷乘积 `∏_{p \text{
prime}} p`，它发散——**不存在有限乘积**。关键的结构性事实是：

> **有限幂零群的极小正规子群恰好具有素数阶。**
