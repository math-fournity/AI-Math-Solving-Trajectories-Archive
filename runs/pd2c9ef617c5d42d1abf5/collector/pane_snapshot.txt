## Proof

Let $\mathbb{S} = \mathcal{P}(\mathbb{N})$ denote the set of all subsets of the
natural numbers.

**Construction.** Since the rationals $\mathbb{Q}$ are countable, fix a bijectio
n $\varphi : \mathbb{N} \to \mathbb{Q}$. For each real number $a \in \mathbb{R}$
, define

$$f(a) = \{\, n \in \mathbb{N} : \varphi(n) < a \,\}.$$

This is a well-defined subset of $\mathbb{N}$, so $f(a) \in \mathbb{S}$, and $f
: \mathbb{R} \to \mathbb{S}$ is a well-defined function.

**Monotonicity.** Let $a, b \in \mathbb{R}$ with $a < b$. We show $f(a) \subset
f(b)$ (strict inclusion).

*Inclusion.* If $n \in f(a)$, then $\varphi(n) < a < b$, so $\varphi(n) < b$, he
nce $n \in f(b)$. Thus $f(a) \subseteq f(b)$.

*Strictness.* Since $\mathbb{Q}$ is dense in $\mathbb{R}$, there exists a ration
al number $q$ with $a < q < b$. Because $\varphi$ is a bijection, $q = \varphi(n
_0)$ for some $n_0 \in \mathbb{N}$. Then:

- $\varphi(n_0) = q < b$, so $n_0 \in f(b)$.
- $\varphi(n_0) = q > a$, so $\varphi(n_0) \not< a$, hence $n_0 \notin f(a)$.

Therefore $f(a) \subsetneq f(b)$.

**Conclusion.** The function $f : \mathbb{R} \to \mathbb{S}$ defined by $f(a) =
\{n \in \mathbb{N} : \varphi(n) < a\}$, where $\varphi : \mathbb{N} \to \mathbb{
Q}$ is any bijection, satisfies $f(a) \subset f(b)$ whenever $a < b$. This prove
s the existence of such a function. $\blacksquare$
