## Solution

We compute $\int_0^2 f(t)\,dt$ where $f(t) = m\bigl(\{x \in [0,\pi] : t \le 1+\c
os(3x) \le 3t\}\bigr)$.

**Setup.** Let $g(x) = 1 + \cos(3x)$ for $x \in [0,\pi]$. Since $\cos(3x) \in [-
1,1]$, we have $g(x) \in [0,2]$. The set $\{x : t \le g(x) \le 3t\}$ is non-empt
y only when $t \le 2$ and $3t \ge 0$, i.e. $t \in [0,2]$, which matches the inte
gration domain.

**Applying Tonelli's theorem.** Since $f \ge 0$, we may interchange the order of
 integration:

$$\int_0^2 f(t)\,dt = \int_0^2 \int_0^\pi \mathbf{1}_{\{t \le g(x) \le 3t\}}\,dx
\,dt = \int_0^\pi \int_0^2 \mathbf{1}_{\{t \le g(x) \le 3t\}}\,dt\,dx.$$

**Inner integral (fixed $x$).** The condition $t \le g(x) \le 3t$ is equivalent
to

$$\frac{g(x)}{3} \le t \le g(x).$$

Since $g(x) \in [0,2]$, we have $g(x)/3 \in [0, 2/3]$ and $g(x) \in [0,2]$, so t
he interval $\bigl[g(x)/3,\; g(x)\bigr] \subseteq [0,2]$. Therefore

$$\int_0^2 \mathbf{1}_{\{t \le g(x) \le 3t\}}\,dt = g(x) - \frac{g(x)}{3} = \fra
c{2}{3}\,g(x) = \frac{2}{3}\bigl(1+\cos(3x)\bigr).$$

**Outer integral.**

$$\int_0^2 f(t)\,dt = \int_0^\pi \frac{2}{3}\bigl(1+\cos(3x)\bigr)\,dx = \frac{2
}{3}\left[\int_0^\pi 1\,dx + \int_0^\pi \cos(3x)\,dx\right].$$

The first term gives $\pi$. The second:

$$\int_0^\pi \cos(3x)\,dx = \frac{\sin(3x)}{3}\bigg|_0^\pi = \frac{\sin(3\pi)-\s
in(0)}{3} = 0.$$

Hence

$$\int_0^2 f(t)\,dt = \frac{2}{3}\cdot\pi = \boxed{\dfrac{2\pi}{3}}.$$
