## 解答

**设置。** 令 $Y_i = \frac{X_{2i-1}}{X_{2i}}$（$i = 1, 2, \ldots$）。由于 $(X_{2
i-1}, X_{2i})$ 对在 $i$ 之间是独立的，且每一对内部具有相同的联合分布，因此 $Y_1,
 Y_2, \ldots$ 是独立同分布 (i.i.d.) 的。同样，$X_1^2, X_2^2, \ldots$ 也是独立同
分布的。

**关键观察：分布是对称的。** 对于每一个 $k$，都有 $P(X_i = k) = P(X_i = -k)$，因
此 $X_i$ 的分布关于 $0$ 对称。此外，其支撑集为 $\{\pm 1, \pm 2, \ldots, \pm(m+1)
\}$，其中不包含 $0$，因此 $1/X_i$ 定义明确且有界（因为 $|X_i| \geq 1$）。

**验证归一化。** $\sum_{k=1}^{m} 2 \cdot \frac{p}{2}q^{k-1} + 2\cdot\frac{q^m}{2
} = p\sum_{k=1}^m q^{k-1} + q^m = p\cdot\frac{1-q^m}{1-q} + q^m = (1-q^m)+q^m =
1.$ ✓

**计算 $E[X_1]$。** 根据对称性，$E[X_1] = 0$。

**计算 $E[Y_1] = E\!\left[\frac{X_1}{X_2}\right]$。** 由于 $X_1$ 和 $X_2$ 是独立
的：
$$E\!\left[\frac{X_1}{X_2}\right] = E[X_1]\cdot E\!\left[\frac{1}{X_2}\right] =
0 \cdot E\!\left[\frac{1}{X_2}\right] = 0.$$
（由于 $|X_2|\geq 1$，因子 $E[1/X_2]$ 是有限的，因此该乘积定义明确且等于 $0$。）

**计算 $E[X_1^2]$。** 由于 $X_1$ 不是退化的（它以正概率取非零值），因此 $E[X_1^2
] > 0$。此外，由于支撑集有界（$|X_1|\leq m+1$），因此 $E[X_1^2] < \infty$。

**应用强大数定律 (SLLN)。** 由于 $Y_i$ 是独立同分布的且 $E|Y_1| \leq E|X_1|\cdot
 E|1/X_2| < \infty$（有界支撑集），且 $X_i^2$ 是独立同分布的且 $E[X_1^2]<\infty$
，强大数定律给出：
$$\frac{1}{n}\sum_{i=1}^n Y_i \xrightarrow{\text{a.s.}} E[Y_1] = 0, \qquad \frac
{1}{n}\sum_{i=1}^n X_i^2 \xrightarrow{\text{a.s.}} E[X_1^2] > 0.$$

**得出结论。** 我们有
$$Z_n = \frac{\sum_{i=1}^n Y_i}{\sum_{i=1}^n X_i^2} = \frac{\tfrac{1}{n}\sum_{i=
1}^n Y_i}{\tfrac{1}{n}\sum_{i=1}^n X_i^2} \xrightarrow{\text{a.s.}} \frac{E[Y_1]
}{E[X_1^2]} = \frac{0}{E[X_1^2]} = 0.$$

几乎必然 (almost sure) 极限为 $\boxed{0}$。
