## Proof

**Setup and substitution.** Write $4^x \pm 4^{-x}$ in hyperbolic form. Let
$$b \;=\; \frac{a}{\ln 4} \;=\; \frac{a}{2\ln 2}.$$

**Protocol A.** Since $4^x - 4^{-x} = 2\sinh(x\ln 4)$, setting $u = x\ln 4$ give
s
$$\sinh(u) = \cos(bu). \tag{A}$$
Let $S = \{u : \sinh(u) = \cos(bu)\}$. The map $x\mapsto u=x\ln 4$ is a bijectio
n, so Protocol A having exactly $2021$ solutions means
$$|S| = 2021. \tag{1}$$

**Protocol B.** Let $v = 4^{x/2} - 4^{-x/2} = 2\sinh(x\ln 2)$. Then
$$v^2 = 4^x + 4^{-x} - 2 \;\;\Longrightarrow\;\; 4^x + 4^{-x} = v^2 + 2.$$
Protocol B's equation $4^x + 4^{-x} = 2\cos(ax) + 4$ becomes
$$v^2 + 2 = 2\cos(ax) + 4 \;\;\Longrightarrow\;\; v^2 = 2 + 2\cos(ax) = 4\cos^2\
!\left(\tfrac{ax}{2}\right).$$
Hence $v = \pm\, 2\cos\!\left(\tfrac{ax}{2}\right)$, i.e.
$$\sinh(x\ln 2) = \pm \cos\!\left(\tfrac{ax}{2}\right).$$
Now set $s = x\ln 2$ (a bijection in $x$). Since $\frac{ax}{2} = \frac{a\,s}{2\l
n 2} = bs$, Protocol B is equivalent to
$$\sinh(s) = \cos(bs) \quad\text{or}\quad \sinh(s) = -\cos(bs). \tag{B}$$

**Relating the two branches of (B) to $S$.** The first branch is exactly $S$ (sa
me equation $\sinh=\cos$ with the same $b$). For the second branch, observe
$$\sinh(s) = -\cos(bs) \;\Longleftrightarrow\; -\sinh(s) = \cos(bs) \;\Longleftr
ightarrow\; \sinh(-s) = \cos(b(-s)),$$
using that $\sinh$ is odd and $\cos$ is even. Thus $s$ satisfies the second bran
ch iff $-s\in S$; the second solution set is precisely $-S$.

Therefore the solution set of Protocol B is $S\cup(-S)$.

**Disjointness.** If $u\in S\cap(-S)$, then $u\in S$ and $-u\in S$, so
$$\sinh(u)=\cos(bu) \quad\text{and}\quad \sinh(-u)=\cos(bu).$$
But $\sinh(-u)=-\sinh(u)$, giving $\sinh(u)=\cos(bu)=-\sinh(u)$, hence $\sinh(u)
=0$ and $\cos(bu)=0$. $\sinh(u)=0\Rightarrow u=0$, yet $\cos(0)=1\neq 0$ — contr
adiction. So
$$S\cap(-S)=\emptyset. \tag{2}$$

**Counting.** Since reflection preserves cardinality, $|-S|=|S|=2021$. Using (1)
 and (2),
$$\bigl|S\cup(-S)\bigr| = |S| + |-S| - |S\cap(-S)| = 2021 + 2021 - 0 = 4042.$$

Each value of $s$ corresponds to exactly one $x$ (via $x=s/\ln 2$), so the numbe
r of distinct timestamps $x$ satisfying Protocol B is

$$\boxed{4042}.$$
