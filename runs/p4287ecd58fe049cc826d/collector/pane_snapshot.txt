## Solution

We determine all $n$ for which $A_n$ has a subgroup of index 4.

**Key tool.** If $H \leq G$ has index $k$, the action of $G$ on the left cosets
of $H$ gives a homomorphism $\phi: G \to S_k$ with $\ker\phi \leq H$.

---

### Case $n \geq 5$: no index-4 subgroup

For $n \geq 5$, $A_n$ is simple. Suppose $H \leq A_n$ with $[A_n : H] = 4$. The
coset action gives
$$\phi: A_n \to S_4, \qquad \ker\phi \leq H \subsetneq A_n.$$
Since $A_n$ is simple, $\ker\phi \in \{\{e\}, A_n\}$. But $\ker\phi \leq H \neq
A_n$ forces $\ker\phi = \{e\}$, so $A_n$ embeds into $S_4$. Then
$$|A_n| = \frac{n!}{2} \leq |S_4| = 24 \implies n! \leq 48.$$
But $5! = 120 > 48$, so $n \leq 4$, contradicting $n \geq 5$. Hence **no $n \geq
 5$ works**.

---

### Case $n \leq 3$: no index-4 subgroup

A subgroup of index 4 requires $|A_n| = 4|H| \geq 4$. But
$$|A_1| = 1,\quad |A_2| = 1,\quad |A_3| = 3,$$
all strictly less than 4. So **no $n \leq 3$ works**.

---

### Case $n = 4$: index-4 subgroup exists

Here $|A_4| = 12$, so an index-4 subgroup has order $3$. The group $A_4$ contain
s the eight $3$-cycles
$$(123),(132),(124),(142),(134),(143),(234),(243),$$
each of order $3$. Each cyclic subgroup $\langle\sigma\rangle$ of order $3$ cont
ains exactly two elements of order $3$ (plus the identity), so these eight eleme
nts form $8/2 = 4$ distinct subgroups of order $3$. Equivalently, the Sylow $3$-
subgroups of $A_4$ have order $3$, and $n_3 \equiv 1\pmod{3}$, $n_3 \mid 4$ give
s $n_3 = 4$.

Thus $A_4$ has (four) subgroups of order $3$, each of index $12/3 = 4$.

---

### Conclusion

Combining all cases, the unique value is:

$$\boxed{n = 4}.$$
