## Solution

This is a pattern-waiting-time problem for a fair coin. I'll use the standard au
tocorrelation/border formula.

**Formula.** For a binary pattern $w$ of length $n$, the expected number of flip
s until $w$ first appears is

$$E[T_w] = \sum_{k \in \mathcal{B}(w)} 2^k,$$

where $\mathcal{B}(w)$ is the set of **border lengths** of $w$: all $k$ with $1
\le k \le n$ such that the prefix of length $k$ equals the suffix of length $k$
(including $k = n$ itself).

*Quick verification:* "HH" has borders $\{1,2\}$, giving $2+4=6$ ✓. "HT" has bor
ders $\{2\}$, giving $4$ ✓. "HTH" has borders $\{1,3\}$, giving $2+8=10$ ✓.

**The pattern.** Our pattern is $w = \text{HTHT}\cdots\text{HT}$ of length $2012
$ (alternating, starting with H, ending with T since $2012$ is even). Position $
j$ (1-indexed) is H iff $j$ is odd, T iff $j$ is even.

**Finding the borders.** The prefix of length $k$ is $\text{HTHT}\cdots$ startin
g with **H**. The suffix of length $k$ starts at position $2012 - k + 1$:
- If $k$ is **even**: $2012 - k + 1$ is **odd** → starts with **H**, then altern
ates $\text{HTHT}\cdots$, matching the prefix exactly. ✓
- If $k$ is **odd**: $2012 - k + 1$ is **even** → starts with **T**, giving $\te
xt{THTH}\cdots$, which does **not** match the prefix $\text{HTHT}\cdots$. ✗

Therefore $\mathcal{B}(w) = \{2, 4, 6, \ldots, 2012\}$ (all even values up to $2
012$, including $2012$ itself).

**Computing the sum.**

$$E = \sum_{k \in \{2,4,6,\ldots,2012\}} 2^k = \sum_{j=1}^{1006} 2^{2j} = \sum_{
j=1}^{1006} 4^j = 4\cdot\frac{4^{1006}-1}{4-1} = \frac{4^{1007}-4}{3}.$$

**Sanity check with length-4 case.** For "HTHT": borders $\{2,4\}$, $E = 4 + 16
= 20$. Formula gives $\frac{4^3 - 4}{3} = \frac{60}{3} = 20$. ✓

Final Answer: $\boxed{\dfrac{4^{1007}-4}{3}}$
