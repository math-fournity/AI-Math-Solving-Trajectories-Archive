Let $S = t_1 + t_2 + \cdots + t_n$ and $R = \frac{1}{t_1} + \frac{1}{t_2} +
\cdots + \frac{1}{t_n}$. The hypothesis is $SR < n^2 + 1$.

Step 1: Reduction. Relabel so that $t_1 \le t_2 \le \cdots \le t_n$. It suffices
to prove $t_1 + t_2 > t_0$, since then for any triple $t_i \le t_j \le t_k$ we
have $t_i + t_j \ge t_1 + t_2 > t_n \ge t_k$, giving the triangle inequality.

Suppose for contradiction that $t_1 + t_2 \le t_n$.

Step 2: A useful identity. For positive reals,

$$SR = \sum_{i,j} \frac{t_i}{t_j} = n + \sum_{i < j}\left(\frac{t_i}{t_j} +
\frac{t_j}{t_i}\right) = n + \sum_{i<j}\frac{(t_i - t_j)^2 + 2,t_i t_j}{t_i t_j}
= n^2 + \sum_{i<j}\frac{(t_i - t_j)^2}{t_i t_j}.$$

So $SR - n^2 = \sum_{i<j}\frac{(t_i - t_j)^2}{t_i t_j}$.

Step 3: Lower bound from the extreme pair. Since all terms are nonnegative,

$$SR - n^2 ;\ge; \frac{(t_n - t_1)^2}{t_1, t_n} + \frac{(t_n - t_2)^2}{t_2,
t_n}.$$

Set $x = t_1,; y = t_2,; z = t_n$, with $z \ge x + y$ and $x, y > 0$. Define

$$g(z) = \frac{(z-x)^2}{xz} + \frac{(z-y)^2}{yz} = z!\left(\frac{1}{x}+\frac{1}
{y}\right) + \frac{x+y}{z} - 4.$$

$$g'(z) = \frac{1}{x}+\frac{1}{y} - \frac{x+y}{z^2}.$$

The unique critical point is $z = \sqrt{xy}$. Since $x+y \ge 2\sqrt{xy} >
\sqrt{xy}$ (for $x,y>0$), the function $g$ is increasing on $[x+y, \infty)$.

$$g(z) \ge g(x+y) = (x+y)!\left(\frac{1}{x}+\frac{1}{y}\right) + 1 - 4 =
