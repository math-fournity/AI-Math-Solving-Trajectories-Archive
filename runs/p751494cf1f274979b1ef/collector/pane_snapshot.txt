## Proof

The subspace on which all $f_1, \dots, f_n$ vanish is
$$W = \{x \in F^n : f_k(x) = 0 \text{ for all } k = 1, \dots, n\}.$$

**Reformulating the conditions.** For each $k$,
$$f_k(x) = \sum_{j=1}^n (k-j)\,x_j = k\sum_{j=1}^n x_j - \sum_{j=1}^n j\,x_j.$$

So the system $f_k(x)=0$ for all $k$ becomes
$$k\,S_1 - S_2 = 0 \quad \text{for all } k=1,\dots,n,$$
where $S_1 = \sum_j x_j$ and $S_2 = \sum_j j\,x_j$.

**Reducing to two independent conditions.** Since $n \ge 2$, taking $k=1$ and $k
=2$ gives
$$S_1 - S_2 = 0, \qquad 2S_1 - S_2 = 0.$$
Subtracting yields $S_1 = 0$, and then $S_2 = 0$. Conversely, if $S_1 = 0$ and $
S_2 = 0$, then $kS_1 - S_2 = 0$ for every $k$. Hence the full system of $n$ equa
tions is equivalent to the two equations
$$\sum_{j=1}^n x_j = 0, \qquad \sum_{j=1}^n j\,x_j = 0.$$

**Independence.** The two linear forms $g_1(x) = \sum_j x_j$ and $g_2(x) = \sum_
j j\,x_j$ are linearly independent over $F$: if $\alpha g_1 + \beta g_2 = 0$ as
a functional, then $\alpha + \beta j = 0$ for all $j=1,\dots,n$; with $n\ge 2$,
evaluating at $j=1$ and $j=2$ gives $\alpha+\beta=0$ and $\alpha+2\beta=0$, henc
e $\beta=0$ and $\alpha=0$.

**Conclusion.** The subspace $W$ is cut out by exactly $2$ independent linear eq
uations in $F^n$, so
$$\dim_F W = n - 2.$$
