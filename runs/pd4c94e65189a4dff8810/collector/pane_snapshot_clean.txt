Looking at this problem, I need to find the expected maximum total variation ove

## Setup

Let $y_1 \le y_2 \le \cdots \le y_9$ be the order statistics. For any permutatio
n $a_1, \ldots, a_9$, the total variation is $\sum_{i=1}^{8}|a_{i+1}-a_i|$. Writ
ing $\epsilon_i = \text{sign}(a_{i+1}-a_i)$, this telescopes to $\sum_{i=1}^9 c_
i\, a_i$ where:
$$c_1 = -\epsilon_1,\quad c_i = \epsilon_{i-1}-\epsilon_i \;(2\le i\le 8),\quad
c_9 = \epsilon_8,$$
with $c_i \in \{-2,0,+2\}$ for interior positions and $c_i \in \{-1,+1\}$ for en
dpoints, and $\sum c_i = 0$.

## Identifying the Optimal Sign Patterns

A coefficient of $+2$ requires a **peak** ($\epsilon_{i-1}=+1,\epsilon_i=-1$); $
-2$ requires a **valley**. To maximize $\sum c_{(i)} y_i$ (sorted coefficients m
atched with sorted values), we want as many $\pm 2$'s as possible, which means *
*fully alternating** sign patterns (maximizing sign changes).

With 8 signs, fully alternating gives two patterns:

**Pattern 1** (up-down): signs $+1,-1,+1,-1,+1,-1,+1,-1$, giving coefficients $(
-1,+2,-2,+2,-2,+2,-2,+2,-1)$. Sorted: $(-2,-2,-2,-1,-1,+2,+2,+2,+2)$.
$$V_1 = -2(y_1+y_2+y_3) - y_4 - y_5 + 2y_6 + 2(y_7+y_8+y_9)$$

**Pattern 2** (down-up): signs $-1,+1,-1,+1,-1,+1,-1,+1$, giving coefficients $(
+1,-2,+2,-2,+2,-2,+2,-2,+1)$. Sorted: $(-2,-2,-2,-2,+1,+1,+2,+2,+2)$.
$$V_2 = -2(y_1+y_2+y_3+y_4) + y_5 + y_6 + 2(y_7+y_8+y_9)$$

**Achievability:** For Pattern 1, the permutation $(y_4, y_9, y_1, y_8, y_2, y_7
, y_3, y_6, y_5)$ is up-down and realizes $V_1$. For Pattern 2, $(y_6, y_1, y_9,
 y_2, y_8, y_3, y_7, y_4, y_5)$ is down-up and realizes $V_2$. (Direct verificat
ion: each consecutive pair satisfies the required inequality.)

**Dominance:** Any non-alternating pattern has fewer $\pm 2$ coefficients (repla
ced by 0's), producing a coefficient multiset that is majorized by one of the tw
o above. Since $y_i$ are sorted, the alternating patterns dominate. Therefore:
$$M = \max(V_1, V_2).$$

## Computing $E[M]$

Let $S = 2(y_7+y_8+y_9) - 2(y_1+y_2+y_3)$ (common to both). Then:
$$V_1 = S + 2y_6 - y_4 - y_5, \qquad V_2 = S - 2y_4 + y_5 + y_6$$

$$V_1 - V_2 = y_4 + y_6 - 2y_5 = (y_6-y_5)-(y_5-y_4) = g_2 - g_1$$

where $g_1 = y_5 - y_4$ and $g_2 = y_6 - y_5$ are consecutive gaps. Also $V_1 +
V_2 = 2S + 3(y_6 - y_4)$, so:

$$M = \frac{V_1+V_2}{2} + \frac{|V_1-V_2|}{2} = S + \frac{3(y_6-y_4)}{2} + \frac
{|g_2-g_1|}{2}$$

**Term 1:** $E[S] = 2\!\left(\frac{7+8+9}{10}\right) - 2\!\left(\frac{1+2+3}{10}
\right) = \frac{48-12}{10} = \frac{18}{5}$

**Term 2:** $\frac{3}{2}E[y_6-y_4] = \frac{3}{2}\cdot\frac{2}{10} = \frac{3}{10}
$

**Term 3:** The 10 gaps $D_0, D_1, \ldots, D_9$ of uniform order statistics are
jointly $\text{Dirichlet}(1,\ldots,1)$ (10 components). Here $g_1 = D_4$, $g_2 =
 D_5$. By the Dirichlet marginal property, $(D_4, D_5, 1-D_4-D_5) \sim \text{Dir
ichlet}(1,1,8)$ with joint density $72(1-x-y)^7$ on $\{x,y\ge 0,\, x+y\le 1\}$.

Using the substitution $s = x+y,\; t = x-y$ (Jacobian $1/2$):
$$E[|D_4-D_5|] = \int_0^1\!\int_{-s}^{s} |t|\cdot 72(1-s)^7\cdot\frac{1}{2}\,dt\
,ds = 36\int_0^1 s^2(1-s)^7\,ds = 36\,B(3,8)$$
$$= 36\cdot\frac{2!\cdot 7!}{10!} = 36\cdot\frac{10080}{3628800} = 36\cdot\frac{
1}{360} = \frac{1}{10}$$

So Term 3 $= \frac{1}{2}\cdot\frac{1}{10} = \frac{1}{20}$.

## Final Computation

$$E[M] = \frac{18}{5} + \frac{3}{10} + \frac{1}{20} = \frac{72+6+1}{20} = \frac{
