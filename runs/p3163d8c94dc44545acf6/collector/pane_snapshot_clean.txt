## Solution

A real $300 \times 300$ matrix that is its own inverse satisfies $A^2 = I$, i.e.
, $A$ is an **involution**.

### Step 1: Structure of involutions

Since $A^2 = I$, the minimal polynomial of $A$ divides $x^2 - 1 = (x-1)(x+1)$, w
hich has distinct real roots. Therefore $A$ is **diagonalizable over $\mathbb{R}
$** with all eigenvalues in $\{+1, -1\}$.

Thus every such $A$ is conjugate (via some $P \in GL_{300}(\mathbb{R})$) to a di
agonal matrix
$$D_k = \operatorname{diag}(\underbrace{+1,\ldots,+1}_{k},\underbrace{-1,\ldots,
-1}_{300-k})$$
for some $k \in \{0, 1, \ldots, 300\}$.

### Step 2: Decomposition into conjugacy classes

The set of all involutions is the disjoint union of conjugacy classes
$$\mathcal{C}_k = \{P D_k P^{-1} : P \in GL_{300}(\mathbb{R})\}, \quad k = 0, 1,
 \ldots, 300.$$

Each $\mathcal{C}_k$ is a smooth manifold, being the orbit of $D_k$ under the co
njugation action of $GL_{300}(\mathbb{R})$.

### Step 3: Dimension of each class

The stabilizer of $D_k$ under conjugation is the centralizer of $D_k$, which con
sists of all block-diagonal matrices $\operatorname{diag}(B_1, B_2)$ with $B_1 \
in GL_k(\mathbb{R})$ and $B_2 \in GL_{300-k}(\mathbb{R})$. This has dimension $k
^2 + (300-k)^2$.

Since $\dim GL_{300}(\mathbb{R}) = 300^2$, the dimension of $\mathcal{C}_k$ is:
$$d_k = 300^2 - k^2 - (300-k)^2 = 2k(300-k).$$

### Step 4: Maximizing

The function $f(k) = 2k(300-k)$ is a downward parabola maximized at $k = 150$:
$$d_{150} = 2 \cdot 150 \cdot 150 = 45000.$$

### Step 5: Minimum number of real variables

The full set of involutions is a union of 301 manifolds of dimensions $d_0, d_1,
 \ldots, d_{300}$, the largest being $d_{150} = 45000$.

- **At least 45000 variables are needed**: The component $\mathcal{C}_{150}$ is
a manifold of dimension 45000, so any parametrization of the entire set must use
 at least 45000 real parameters to cover it.

- **45000 variables suffice**: We can parametrize $\mathcal{C}_{150}$ using 4500
0 real variables (via the conjugation map $GL_{300}/(GL_{150}\times GL_{150})$).
 The remaining components $\mathcal{C}_k$ for $k \neq 150$ have strictly smaller
 dimension, so they can be embedded into the same 45000-dimensional parameter sp
ace (using a discrete choice of $k$, which costs no real variables, together wit
h $d_k \leq 45000$ real parameters for that component).

Therefore the minimum number of real variables required is:

$$\boxed{45000}$$
