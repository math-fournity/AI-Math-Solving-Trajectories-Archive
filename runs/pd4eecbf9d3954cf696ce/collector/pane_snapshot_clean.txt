# Solution

**Setup.** Let $n = 2020$. Let $r_1, \dots, r_n$ be the roots of $P(x) = x^n + x
 + 2$, so $r_i^n = -r_i - 2$ and $\prod_i r_i = (-1)^n \cdot 2 = 2$. Since $Q(y)
 = \prod_{i<j}(y - r_i r_j)$ is monic, we have
$$Q(y)^2 = \prod_{i<j}(y - r_i r_j)^2 = \prod_{i \ne j}(y - r_i r_j) = \frac{F(y
)}{H(y)},$$
where $F(y) = \prod_{i,j}(y - r_i r_j)$ and $H(y) = \prod_i (y - r_i^2)$.

**The values $\alpha$.** The equation $P(\alpha) = 4$ gives $R(\alpha) := \alpha
^n + \alpha - 2 = 0$, so $\alpha^n = 2 - \alpha$. Since $n = 2020 \ge 3$, the co
efficient of $x^{n-1}$ in $R$ is $0$, hence $\sum_\alpha \alpha = 0$.

**Computing $H(\alpha^2)$.** Since $n$ is even, $P(-x) = x^n - x + 2$ has roots
$-r_i$, so
$$H(\alpha^2) = \prod_i(\alpha^2 - r_i^2) = \prod_i(\alpha - r_i)\prod_i(\alpha
+ r_i) = P(\alpha)\cdot P(-\alpha).$$
Here $P(\alpha) = 4$ and $P(-\alpha) = \alpha^n - \alpha + 2 = (2-\alpha) - \alp
ha + 2 = 4 - 2\alpha$, giving
$$H(\alpha^2) = 4(4-2\alpha) = 8(2-\alpha).$$

**Computing $F(\alpha^2)$.** For each $i$,
$$\prod_j(\alpha^2 - r_i r_j) = r_i^n\, P(\alpha^2/r_i) = \alpha^{2n} + \alpha^2
 r_i^{n-1} + 2r_i^n.$$
Using $r_i^n = -r_i - 2$ and $\alpha^{2n} = (2-\alpha)^2 = 4 - 4\alpha + \alpha^
2$:
$$= \alpha^2(1 + r_i^{n-1}) - 4\alpha - 2r_i.$$
From $r_i(r_i^{n-1}+1) = -2$ we get $r_i^{n-1}+1 = -2/r_i$, so
$$= -\frac{2\alpha^2}{r_i} - 2(2\alpha + r_i) = -\frac{2(\alpha + r_i)^2}{r_i}.$
$
Therefore
$$F(\alpha^2) = \prod_i\left(-\frac{2(\alpha+r_i)^2}{r_i}\right) = \frac{(-2)^n}
{\prod_i r_i}\left[\prod_i(\alpha+r_i)\right]^2 = \frac{2^n}{2}\cdot P(-\alpha)^
2 = 2^{n-1}(4-2\alpha)^2 = 2^{n+1}(2-\alpha)^2.$$

**Combining.** Since $2 - \alpha = \alpha^n \ne 0$ (as $R(0) = -2 \ne 0$), we ma
y divide:
$$Q(\alpha^2)^2 = \frac{F(\alpha^2)}{H(\alpha^2)} = \frac{2^{n+1}(2-\alpha)^2}{8
(2-\alpha)} = 2^{n-2}(2-\alpha).$$

**Summing over all $\alpha$.**
$$\sum_\alpha Q(\alpha^2)^2 = 2^{n-2}\sum_\alpha(2-\alpha) = 2^{n-2}\!\left(2n -
 \sum_\alpha \alpha\right) = 2^{2018}\cdot(4040 - 0) = 2^{2018}\cdot 4040.$$
Since $4040 = 2^3 \cdot 505$,
$$\sum_\alpha Q(\alpha^2)^2 = 2^{2021}\cdot 505.$$
