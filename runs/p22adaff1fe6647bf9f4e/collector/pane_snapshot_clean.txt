# Proof

**Claim:** Yes, a countable group can act properly discontinuously on a 4-regula
r tree.

**Construction.** Let $F_2 = \langle a, b \rangle$ be the free group on two gene
rators, and let $T$ be the Cayley graph of $F_2$ with respect to the generating
set $S = \{a, a^{-1}, b, b^{-1}\}$.

**Step 1: $T$ is a 4-regular tree.**

The vertex set of $T$ is $F_2$ itself, and two vertices $g, h$ are connected by
an edge iff $h = gs$ for some $s \in S$. Each vertex $g$ has exactly four neighb
ors $ga, ga^{-1}, gb, gb^{-1}$, so $T$ is 4-regular.

To see that $T$ is a tree (i.e., acyclic), suppose for contradiction there is a
reduced cycle. A closed path based at the identity corresponds to a reduced word
 $w = s_1 s_2 \cdots s_k$ (with $s_i \in S$, no $s_{i+1} = s_i^{-1}$) such that
$w = e$ in $F_2$. But a reduced word in the free group represents the identity o
nly if it is the empty word. Hence there is no nontrivial reduced cycle, and $T$
 is a tree.

**Step 2: $F_2$ is countable.**

$F_2$ is finitely generated, so its elements are finite words over the alphabet
$S$. The set of all finite words over a finite alphabet is countable.

**Step 3: $F_2$ acts on $T$ by left multiplication.**

Define the action $F_2 \curvearrowright T$ by $g \cdot h = gh$ on vertices, exte
nded to edges in the natural way. This is a graph automorphism since $h_1 \sim h
_2$ iff $h_2 = h_1 s$, which holds iff $gh_2 = (gh_1)s$, i.e., $gh_1 \sim gh_2$.

**Step 4: The action is free.**

If $g \cdot h = h$ for some vertex $h$, then $gh = h$, so $g = e$. Thus every st
abilizer is trivial.

**Step 5: The action is properly discontinuous.**

Recall that an action of a discrete group $G$ on a locally compact space $X$ is
*properly discontinuous* if for every compact $K \subseteq X$, the set $\{g \in
G : gK \cap K \neq \emptyset\}$ is finite.

The tree $T$ (viewed as a 1-dimensional CW-complex) is locally compact, and sinc
e it is locally finite, every compact subset meets only finitely many vertices.
Let $K \subseteq T$ be compact, and let $V(K) = \{v_1, \ldots, v_n\}$ be the (fi
nite) set of vertices in $K$. Then:

$$\{g \in F_2 : gK \cap K \neq \emptyset\} \subseteq \{g \in F_2 : gV(K) \cap V(
K) \neq \emptyset\} = \bigcup_{i=1}^{n}\bigcup_{j=1}^{n}\{g \in F_2 : gv_i = v_j
\}.$$

Since the action is free and transitive on vertices (left multiplication on the
group), for each pair $(v_i, v_j)$ there is exactly one $g \in F_2$ with $gv_i =
 v_j$, namely $g = v_j v_i^{-1}$. Therefore:

$$|\{g \in F_2 : gK \cap K \neq \emptyset\}| \leq n^2 < \infty.$$

Hence the action is properly discontinuous.

**Conclusion.** The free group $F_2$ is a countable group that acts freely and p
roperly discontinuously on the 4-regular tree (its Cayley graph). Therefore, a c
ountable group **can** act properly discontinuously on a 4-regular tree. $\black
square$
