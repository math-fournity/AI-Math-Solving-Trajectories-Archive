## Solution

**Setup.** For each workstation $k$ ($k=1,\dots,24$), let $b_k \in \{0,1\}$ deno
te which port is activated: $b_k=0$ means port $2k-1$ (low), $b_k=1$ means port
$2k$ (high). The configuration is a binary string $b_1b_2\cdots b_{24}$.

**Counting consecutive connections.** A consecutive connection is a pair $(m, m+
1)$ with both ports active. Two cases arise:

- **Within a workstation:** ports $2k-1$ and $2k$ — impossible, since only one i
s activated.
- **Between workstations $k$ and $k+1$:** ports $2k$ and $2k+1$. Port $2k$ is ac
tive iff $b_k=1$; port $2k+1$ is active iff $b_{k+1}=0$. Both active iff $b_k=1,
 b_{k+1}=0$ — a "10" pattern (descent).

So the number of consecutive connections equals the number of descents in $b_1\c
dots b_{24}$, and we need exactly **9 descents**.

**Run analysis.** Write the string in terms of maximal runs of identical bits. L
et $a$ = number of 1-runs, $b$ = number of 0-runs. Each descent corresponds to a
 $1\text{-run} \to 0\text{-run}$ boundary. Four cases by starting/ending bit:

| Case | Start, End | Run relation | Descents = | Solve | $(a,b)$ |
|------|-----------|-------------|-----------|-------|---------|
| 1 | 1, 1 | $a=b+1$ | $b$ | $b=9$ | $(10,9)$ |
| 2 | 1, 0 | $a=b$ | $b$ | $b=9$ | $(9,9)$ |
| 3 | 0, 1 | $a=b$ | $a-1$ | $a=10$ | $(10,10)$ |
| 4 | 0, 0 | $b=a+1$ | $a$ | $a=9$ | $(9,10)$ |

**Counting strings per case.** For a fixed starting bit, with $a$ runs of 1s and
 $b$ runs of 0s, we distribute $n_1$ ones into $a$ positive parts and $n_0 = 24-
n_1$ zeros into $b$ positive parts:

$$\sum_{n_1=a}^{24-b} \binom{n_1-1}{a-1}\binom{23-n_1}{b-1}.$$

Substituting $n_1' = n_1 - a \geq 0$, $n_0' = n_0 - b \geq 0$ with $n_1'+n_0' =
24-a-b$, this becomes the convolution

$$\sum_{i=0}^{24-a-b}\binom{i+a-1}{i}\binom{24-a-b-i+b-1}{24-a-b-i} = [x^{24-a-b
}]\frac{1}{(1-x)^{a+b}} = \binom{23}{a+b-1}.$$

**Applying to each case:**

- Case 1: $\binom{23}{18} = \binom{23}{5} = 33649$
- Case 2: $\binom{23}{17} = \binom{23}{6} = 100947$
- Case 3: $\binom{23}{19} = \binom{23}{4} = 8855$
- Case 4: $\binom{23}{18} = \binom{23}{5} = 33649$

**Total:**

$$33649 + 100947 + 8855 + 33649 = \boxed{177100}$$

### PROOF COMPLETE
