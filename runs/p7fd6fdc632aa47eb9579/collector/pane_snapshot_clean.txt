## Proof

We evaluate
$$I = \int_{\overline{D}_1(0)} \prod_{i=1}^{n} x_i \, d\lambda(x), \qquad \overl
ine{D}_1(0) = \{x \in \mathbb{R}^n : \sum_{i=1}^n x_i^2 \leq 1\}.$$

**Symmetry argument.** Consider the reflection map $\rho: \mathbb{R}^n \to \math
bb{R}^n$ defined by
$$\rho(x_1, x_2, \ldots, x_n) = (-x_1, x_2, \ldots, x_n).$$

This is a linear isometry, hence it preserves Lebesgue measure: $\lambda(\rho^{-
1}(E)) = \lambda(E)$ for every measurable $E$. Moreover, $\rho$ leaves the close
d unit ball invariant:
$$\sum_{i=1}^n (\rho(x))_i^2 = (-x_1)^2 + \sum_{i=2}^n x_i^2 = \sum_{i=1}^n x_i^
2,$$
so $\rho(\overline{D}_1(0)) = \overline{D}_1(0)$.

Under this reflection, the integrand transforms as
$$f(\rho(x)) = (-x_1)\prod_{i=2}^n x_i = -\prod_{i=1}^n x_i = -f(x).$$

By the change-of-variables formula (with $|\det \rho| = 1$),
$$I = \int_{\overline{D}_1(0)} f(x)\,d\lambda(x) = \int_{\rho(\overline{D}_1(0))
} f(x)\,d\lambda(x) = \int_{\overline{D}_1(0)} f(\rho^{-1}(y))\,d\lambda(y).$$

Since $\rho^{-1} = \rho$, we have $f(\rho^{-1}(y)) = f(\rho(y)) = -f(y)$. Theref
ore
$$I = \int_{\overline{D}_1(0)} -f(y)\,d\lambda(y) = -I.$$

Hence $2I = 0$, giving
$$I = 0.$$

**Integrability check.** The function $f(x) = \prod x_i$ is continuous on the co
mpact set $\overline{D}_1(0)$, hence bounded and Lebesgue-integrable there. The
manipulations above are therefore valid (no improper-integral issues).

$$\boxed{\displaystyle \int_{\overline{D}_1(0)} \prod_{i=1}^n x_i \, d\lambda =
0.}$$
