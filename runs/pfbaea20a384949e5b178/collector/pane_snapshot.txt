## Proof

Let $M(\theta) = \frac{1}{c}e^{j\theta}P^{-1}A + cP^{-1} = P^{-1}\!\left(\frac{1
}{c}e^{j\theta}A + cI\right)$, and set $N(\theta) := \frac{1}{c}e^{j\theta}A + c
I$, so $M(\theta) = P^{-1}N(\theta)$.

**Step 1: Compute $N(\theta)^*N(\theta)$.**

Since $A$ is Hermitian ($A^*=A$), $N(\theta)^* = \frac{1}{c}e^{-j\theta}A + cI$,
 and:

$$N(\theta)^*N(\theta) = \left(\tfrac{1}{c}e^{-j\theta}A+cI\right)\!\left(\tfrac
{1}{c}e^{j\theta}A+cI\right) = \tfrac{1}{c^2}A^2 + c^2 I + (e^{j\theta}+e^{-j\th
eta})A = \tfrac{1}{c^2}A^2 + c^2 I + 2\cos\theta\cdot A.$$

Define $G(t) := \frac{1}{c^2}A^2 + c^2 I + 2tA$ for $t\in[-1,1]$, so $N(\theta)^
*N(\theta) = G(\cos\theta)$.

**Step 2: Express $\sigma_{\min}^2$ as a generalized Rayleigh quotient.**

Since $P$ is Hermitian positive definite, $P^{-1}$ is Hermitian, and
$$M(\theta)^*M(\theta) = N(\theta)^*\,P^{-2}\,N(\theta).$$

Since $A$ is Hermitian, $N(\theta)$ is a polynomial in $A$ and hence **normal**,
 so $\|N^{-1}y\|^2 = y^*(N^*N)^{-1}y = y^*G(\cos\theta)^{-1}y$. Substituting $y
= N(\theta)x$:

$$\sigma_{\min}^2(M(\theta)) = \min_{y\neq 0}\;\frac{y^*P^{-2}y}{y^*G(\cos\theta
)^{-1}y}.$$

**Step 3: Monotonicity of $G(t)$.**

For $t_1 < t_2$:
$$G(t_2) - G(t_1) = 2(t_2-t_1)A \succ 0,$$
since $A\succ 0$. Thus $G(t_2)\succ G(t_1)\succ 0$, which implies $G(t_1)^{-1}\s
ucc G(t_2)^{-1}\succ 0$ (Loewner order reverses under inversion for PD matrices)
.

**Step 4: Each $h_y(t)$ is strictly increasing.**

For each fixed $y\neq 0$, define $h_y(t) := \frac{y^*P^{-2}y}{y^*G(t)^{-1}y}$. T
he numerator is a positive constant. The denominator $y^*G(t)^{-1}y$ is **strict
ly decreasing** in $t$ (by Step 3). Therefore $h_y(t)$ is **strictly increasing*
* in $t$, maximized at $t=1$ (i.e., $\cos\theta=1$, $\theta=0$).

**Step 5: The minimum of increasing functions is maximized at $t=1$.**

Let $y^*$ be a minimizer at $t=1$: $\sigma_{\min}^2(M(0)) = h_{y^*}(1)$. For any
 $\theta$ with $t=\cos\theta < 1$:

$$\sigma_{\min}^2(M(\theta)) = \min_{y\neq 0} h_y(t) \;\leq\; h_{y^*}(t) \;<\; h
_{y^*}(1) = \sigma_{\min}^2(M(0)).$$

- First inequality: the min over all $y$ is at most $h_{y^*}(t)$ for any specifi
c $y^*$.
- Strict inequality: $h_{y^*}$ is strictly increasing (Step 4), so $h_{y^*}(t) <
 h_{y^*}(1)$ for $t<1$.

Therefore $\sigma_{\min}(M(\theta)) < \sigma_{\min}(M(0))$ for all $\theta \in (
0,2\pi)$, and the minimum singular value is **uniquely maximized** at $\theta =
0$ (equivalently $\theta = 2\pi$).

$$\boxed{\theta = 0}$$
