## Proof

**Claim:** For every sequence $\{z_n\} \subset \mathbb{C}$, there exists an enti
re function $f$ with $f(a_n) = z_n$ for all $n$.

**Case 1: $\{a_n\}$ is finite.** A polynomial (via Lagrange interpolation) suffi
ces. Trivial.

**Case 2: $\{a_n\}$ is infinite.** Since $\{a_n\}$ is discrete with no limit poi
nt in $\mathbb{C}$, we have $|a_n| \to \infty$.

### Step 1 — Weierstrass product

By the Weierstrass factorization theorem, there exists an entire function $g$ wh
ose zero set is exactly $\{a_n\}$, with each zero simple. (Explicitly, choosing
elementary factors $E_{p_n}$ with $p_n$ large enough, $g(z) = z^m \prod_n E_{p_n
}(z/a_n)$ converges uniformly on compact sets, where $m$ accounts for a possible
 zero at the origin.)

### Step 2 — Mittag-Leffler construction

Set $r_n = \frac{z_n}{g'(a_n)}$ for each $n$. We construct a meromorphic functio
n $h$ on $\mathbb{C}$ whose only poles are simple poles at each $a_n$ with resid
ue $r_n$.

Relabel so $|a_1| \le |a_2| \le \cdots$. For each $n$ with $a_n \ne 0$, expand t
he principal part around $z=0$:

$$\frac{r_n}{z - a_n} = -\sum_{k=0}^{\infty} \frac{r_n}{a_n^{k+1}}\, z^k, \qquad
 |z| < |a_n|.$$

Choose a partial sum $Q_n(z) = -\sum_{k=0}^{m_n} \frac{r_n}{a_n^{k+1}} z^k$ (a p
olynomial) with $m_n$ large enough that

$$\left|\frac{r_n}{z - a_n} - Q_n(z)\right| < \frac{1}{2^n} \quad \text{for all
} |z| \le \frac{|a_n|}{2}.$$

This is possible by uniform convergence of the power series on compact subsets o
f $\{|z| < |a_n|\}$. (If $a_n = 0$, set $Q_n \equiv 0$; the principal part $\fra
c{r_n}{z}$ needs no correction.)

Define:

$$h(z) = \sum_{n=1}^{\infty} \left(\frac{r_n}{z - a_n} - Q_n(z)\right).$$

**Convergence:** Let $K \subset \mathbb{C}$ be compact. Since $|a_n| \to \infty$
, for all sufficiently large $n$ we have $|a_n| > 2\sup_{z \in K}|z|$, so $K \su
bset \{|z| \le |a_n|/2\}$ and $\left|\frac{r_n}{z-a_n} - Q_n(z)\right| < 2^{-n}$
 on $K$. By the Weierstrass $M$-test, the tail converges uniformly on $K$. The f
initely many remaining terms contribute only finitely many poles (at those $a_n$
 in or near $K$). Thus $h$ is meromorphic on $\mathbb{C}$ with simple poles exac
tly at $\{a_n\}$, and $\operatorname{Res}(h, a_n) = r_n$ (since $Q_n$ is a polyn
omial and does not affect the residue).

### Step 3 — Product $f = g \cdot h$

Define $f(z) = g(z)\,h(z)$. At each $a_n$:
- $g$ has a simple zero: $g(z) = g'(a_n)(z - a_n) + O((z-a_n)^2)$.
- $h$ has a simple pole with residue $r_n$: $h(z) = \frac{r_n}{z - a_n} + \text{
holomorphic near } a_n$.

So the singularity of $f$ at $a_n$ is removable, with value:

$$f(a_n) = \lim_{z \to a_n} g(z)\,h(z) = g'(a_n) \cdot r_n = g'(a_n) \cdot \frac
{z_n}{g'(a_n)} = z_n.$$

Away from $\{a_n\}$, both $g$ and $h$ are holomorphic, so $f$ is holomorphic the
re. At each $a_n$, $f$ has a removable singularity with finite value $z_n$. Ther
efore $f$ extends to an **entire** function satisfying $f(a_n) = z_n$ for all $n
 \in \mathbb{N}$. $\blacksquare$

---

**Conclusion:** For every discrete set $\{a_n\} \subset \mathbb{C}$ with no limi
t point and every sequence $\{z_n\} \subset \mathbb{C}$, there exists an entire
function $f$ with $f(a_n) = z_n$ for all $n$.
