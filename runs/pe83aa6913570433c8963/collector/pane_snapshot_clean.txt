## Solution

**Finding a closed form for $F_n(x)$.**

By the Cauchy formula for repeated integration, for $n \geq 1$:
$$F_n(x) = \frac{1}{(n-1)!}\int_0^x (x-t)^{n-1}\ln t\,dt.$$

**Evaluating at $x=1$.**

Setting $x=1$ and multiplying by $n!$:
$$n!\,F_n(1) = \frac{n!}{(n-1)!}\int_0^1(1-t)^{n-1}\ln t\,dt = n\int_0^1(1-t)^{n
-1}\ln t\,dt.$$

Substitute $u=1-t$ ($t=1-u$, $dt=-du$):
$$n!\,F_n(1) = n\int_0^1 u^{n-1}\ln(1-u)\,du.$$

**Using the series for $\ln(1-u)$.**

For $0\leq u<1$, $\displaystyle\ln(1-u)=-\sum_{k=1}^{\infty}\frac{u^k}{k}$. By d
ominated convergence (justified since $\int_0^1 u^{n-1}|\ln(1-u)|\,du<\infty$):
$$n!\,F_n(1) = -n\sum_{k=1}^{\infty}\frac{1}{k}\int_0^1 u^{n+k-1}\,du = -n\sum_{
k=1}^{\infty}\frac{1}{k(n+k)}.$$

**Partial fractions.**

Since $\displaystyle\frac{1}{k(n+k)}=\frac{1}{n}\!\left(\frac{1}{k}-\frac{1}{n+k
}\right)$:
$$n!\,F_n(1) = -\sum_{k=1}^{\infty}\left(\frac{1}{k}-\frac{1}{n+k}\right) = -\su
m_{k=1}^{n}\frac{1}{k} = -H_n,$$
where $H_n$ is the $n$-th harmonic number (the series telescopes: $\sum_{k=1}^{\
infty}\!\left(\frac{1}{k}-\frac{1}{n+k}\right)=\sum_{k=1}^{n}\frac{1}{k}$).

**Verification.** $n=1$: $F_1(x)=x\ln x - x$, so $F_1(1)=-1=-H_1$. ✓
$n=2$: $F_2(x)=\tfrac{x^2}{2}\ln x - \tfrac{3x^2}{4}$, so $2!\,F_2(1)=-\tfrac{3}
{2}=-H_2$. ✓

**Taking the limit.**

It is classical that $H_n = \ln n + \gamma + o(1)$ as $n\to\infty$, where $\gamm
a$ is the Euler–Mascheroni constant. Therefore:
$$\frac{n!\,F_n(1)}{\ln n} = \frac{-H_n}{\ln n} = \frac{-(\ln n + \gamma + o(1))
}{\ln n} \xrightarrow{n\to\infty} -1.$$

$$\boxed{\lim_{n\to\infty}\frac{n!\,F_n(1)}{\ln n}=-1}$$
