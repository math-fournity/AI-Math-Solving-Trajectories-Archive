# 证明

**定理。** von Neumann 代数 $\mathcal{M} = M_2(vN(\mathbb{F}_2))$ 在其标准表示中
允许一个分离向量。

## 预备知识

我们回顾两个标准事实：

**事实 1（标准形式与 $\sigma$-有限性）。** 设 $M$ 为 von Neumann 代数。以下条件
等价：
- $M$ 是 $\sigma$-有限的（即允许一个忠实正规状态，等价地，每个相互正交的非零投影
族都是可数的）。
- $M$ 的标准形式 $L^2(M)$ 允许一个对于 $M$ 既循环又分离的向量。

具体而言，如果 $\varphi$ 是 $M$ 上的忠实正规状态，那么 GNS 构造得出 $L^2(M,\varp
hi)$，其中向量 $\Lambda_\varphi(1)$ 对于 $M$ 是循环且分离的。该 GNS 空间是 $M$
的标准形式（在等距同构意义下唯一）。

**事实 2（循环 $\Leftrightarrow$ 分离对偶性）。** 在 von Neumann 代数 $M$ 的标准
形式中，模共轭 $J$ 满足 $M' = JMJ$。向量 $\xi$ 对于 $M$ 是分离的，当且仅当 $\xi$
 对于 $M' = JMJ$ 是循环的。在标准形式中，$M$ 允许一个分离向量，当且仅当它允许一
个循环向量，当且仅当它允许一个既循环又分离的向量。

## 自由群因子是 $\sigma$-有限的

设 $\mathbb{F}_2 = \langle a, b \rangle$ 为两个生成元上的自由群，设 $\lambda: \m
athbb{F}_2 \to \mathcal{B}(\ell^2(\mathbb{F}_2))$ 为左正则表示。群 von Neumann
代数为
$$vN(\mathbb{F}_2) = \{\lambda(g) : g \in \mathbb{F}_2\}''.$$

由 $\tau(g) = \delta_{g,e}$（单位元上的 Kronecker $\delta$）定义的规范迹 $\tau:
vN(\mathbb{F}_2) \to \mathbb{C}$ 是一个忠实正规迹状态：

- **正规性：** $\tau$ 由向量 $\delta_e \in \ell^2(\mathbb{F}_2)$ 实现，因为 $\ta
u(x) = \langle x\,\delta_e, \delta_e\rangle$，因此它是向量状态，从而是正规的。
- **忠实性：** 对于 $x = \sum_{g} c_g\,\lambda(g) \in \mathbb{C}[\mathbb{F}_2]$
（有限支撑），有 $\tau(x^*x) = \sum_g |c_g|^2$，当且仅当所有 $c_g = 0$ 时为零。
通过连续性，$\tau(x^*x) = 0 \Rightarrow x = 0$ 对于所有 $x \in vN(\mathbb{F}_2)$
 成立。
- **迹性：** $\tau(xy) = \tau(yx)$，因为 $\tau$ 在群元素上是类函数。

因此，$vN(\mathbb{F}_2)$ 是一个具有忠实正规迹状态的 $\mathrm{II}_1$ 因子，特别是
 $\sigma$-有限的。

## 矩阵放大保持 $\sigma$-有限性

设 $N = vN(\mathbb{F}_2)$。代数 $\mathcal{M} = M_2(N) \cong N \,\bar\otimes\, M_
2(\mathbb{C})$。通过
$$\tilde\tau(x) = \tfrac{1}{2}\,\tau\!\otimes\!\mathrm{tr}_2(x), \qquad x = [x_{
ij}] \in M_2(N),$$
定义 $\tilde\tau: M_2(N) \to \mathbb{C}$，其中 $\mathrm{tr}_2$ 是 $M_2(\mathbb{C
})$ 上的归一化迹，$\tau$ 是 $N$ 上的忠实正规迹。

**$\tilde\tau$ 是一个忠实正规迹状态：**

- *正规性：* $\tilde\tau$ 是两个正规状态的张量积，因此是正规的。
- *迹性：* 两个迹的张量积是迹。
- *忠实性：* 设 $x = [x_{ij}] \in M_2(N)$ 满足 $\tilde\tau(x^*x) = 0$。在 $N \ot
imes M_2(\mathbb{C})$ 的识别下，$x^*x = \sum_{k} x_{ki}^* x_{kj}$（矩阵积），且
$$\tilde\tau(x^*x) = \tfrac{1}{2}\sum_{i,j}\tau(x_{ij}^* x_{ij}) = \tfrac{1}{2}\
sum_{i,j}\tau(x_{ij}^*x_{ij}).$$
由于 $\tau$ 是忠实的且每一项 $\tau(x_{ij}^*x_{ij}) \geq 0$，其和为零迫使对于所有
 $i,j$ 有 $\tau(x_{ij}^*x_{ij})=0$，因此（由 $\tau$ 的忠实性）对于所有 $i,j$ 有
$x_{ij} = 0$，即 $x = 0$。

因此 $\mathcal{M} = M_2(N)$ 承认一个忠实正规状态 $\tilde\tau$，所以 $\mathcal{M}
$ 是 $\sigma$-有限的。

## 构造分离向量

由于 $\mathcal{M}$ 是 $\sigma$-有限的，根据事实 1，其标准形式 $L^2(\mathcal{M})$
 承认一个既循环又分离的向量。我们可以显式地构造它：

**$N$ 的标准形式。** 迹 $\tau$ 给出 GNS 空间 $L^2(N, \tau)$，其循环分离向量为 $\
Omega := \Lambda_\tau(1)$。这是 $N$ 的标准形式。

**$M_2(\mathbb{C})$ 的标准形式。** 归一化迹 $\mathrm{tr}_2$ 给出 GNS 空间 $\math
rm{HS}_2$（$2\times 2$ 矩阵的 Hilbert–Schmidt 空间），其循环分离向量为 $I_2$（单
位矩阵，视为 HS 向量）。这是 $M_2(\mathbb{C})$ 的标准形式。

**$\mathcal{M} = N \,\bar\otimes\, M_2(\mathbb{C})$ 的标准形式。** 可分 von Neum
ann 代数的张量积的标准形式是标准形式的张量积：
$$L^2(\mathcal{M}) \cong L^2(N,\tau) \otimes \mathrm{HS}_2.$$

设 $\Xi := \Omega \otimes I_2 \in L^2(N,\tau)\otimes \mathrm{HS}_2$。我们验证 $\
Xi$ 对于 $\mathcal{M}$ 是分离的（且是循环的）。

**分离性。** 假设 $T\,\Xi = 0$，其中 $T \in \mathcal{M} = N\,\bar\otimes\, M_2(\
mathbb{C})$。由于简单张量的线性组合在 $\mathcal{M}$ 中是弱 $*$-稠密的，且作用是
连续的，因此只需检查 $T = x \otimes a$（其中 $x \in N$, $a \in M_2(\mathbb{C})$
）的情况。那么
$$(x \otimes a)(\Omega \otimes I_2) = x\Omega \otimes a\,I_2 = x\Omega \otimes a
.$$
由于 $\Omega$ 对于 $N$ 是分离的，$x\Omega = 0 \Rightarrow x = 0$。由于 $I_2$ 对
于 $M_2(\mathbb{C})$ 是分离的（因为 $a\,I_2 = a = 0 \Rightarrow a = 0$），$a = 0
$。因此 $T = 0$。通过连续性和稠密性，$\Xi$ 对于 $\mathcal{M}$ 是分离的。

**循环性。** 向量 $\Xi$ 对于 $\mathcal{M}$ 是循环的，因为 $\Omega$ 对于 $N$ 是循
环的（因此 $N\Omega$ 在 $L^2(N)$ 中稠密）且 $I_2$ 对于 $M_2(\mathbb{C})$ 是循环
的（因此 $M_2(\mathbb{C})\cdot I_2 = M_2(\mathbb{C}) = \mathrm{HS}_2$）。因此 $\
mathcal{M}\,\Xi \supseteq (N\Omega)\otimes(M_2(\mathbb{C})\cdot I_2)$ 在 $L^2(N)
\otimes\mathrm{HS}_2$ 中稠密。

因此 $\Xi = \Omega \otimes I_2$ 是 $\mathcal{M} = M_2(vN(\mathbb{F}_2))$ 在其标
准表示中的一个分离（事实上也是循环）向量。

## 结论

von Neumann 代数 $\mathcal{M} = M_2(vN(\mathbb{F}_2))$ 是一个 $\mathrm{II}_1$ 因
子，它承认一个忠实正规迹状态 $\tilde\tau = \frac{1}{2}(\tau \otimes \mathrm{tr}_
2)$，因此是 $\sigma$-有限的。每一个 $\sigma$-有限 von Neumann 代数的标准形式都承
认一个既循环又分离的向量。显式地，向量 $\Xi = \Lambda_\tau(1)\otimes I_2 \in L^2
(vN(\mathbb{F}_2),\tau)\otimes\mathrm{HS}_2$ 在 $\mathcal{M}$ 的标准表示中对于 $
\mathcal{M}$ 是循环且分离的。

**$\mathcal{M} = M_2(vN(\mathbb{F}_2))$ 在其标准表示中允许一个分离向量。** $\bla
cksquare$
