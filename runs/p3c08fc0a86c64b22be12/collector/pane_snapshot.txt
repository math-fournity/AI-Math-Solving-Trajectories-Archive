## Key Identity for $T_n$

We compute $T_n = \sum_{k=1}^n S_k$ by switching the order of summation:

$$T_n = \sum_{k=1}^n \sum_{j=1}^k \frac{1}{j} = \sum_{j=1}^n \frac{1}{j}\sum_{k=
j}^n 1 = \sum_{j=1}^n \frac{n-j+1}{j} = (n+1)\sum_{j=1}^n \frac{1}{j} - \sum_{j=
1}^n 1 = (n+1)S_n - n.$$

**Verification ($n=2$):** $S_1=1,\, S_2=3/2$, so $T_2 = 5/2$. Formula: $3\cdot(3
/2)-2 = 5/2$. ✓

## Finding $a, b$

Setting $n=1988$ and using $S_{1988} = S_{1989} - \tfrac{1}{1989}$:

$$T_{1988} = 1989\,S_{1988} - 1988 = 1989\!\left(S_{1989} - \tfrac{1}{1989}\righ
t) - 1988 = 1989\,S_{1989} - 1 - 1988 = 1989\,S_{1989} - 1989.$$

So $\boxed{a = 1989,\; b = 1989}$, with $0 < a, b < 1000000$. ✓

## Key Identity for $U_n$

Using $T_k = (k+1)S_k - k$:

$$U_n = \sum_{k=1}^n \frac{T_k}{k+1} = \sum_{k=1}^n \frac{(k+1)S_k - k}{k+1} = \
sum_{k=1}^n S_k - \sum_{k=1}^n \frac{k}{k+1} = T_n - \sum_{k=1}^n\!\left(1 - \tf
rac{1}{k+1}\right).$$

$$= T_n - n + \sum_{k=1}^n \frac{1}{k+1} = T_n - n + (S_{n+1}-1).$$

Substituting $T_n = (n+1)S_n - n$:

$$U_n = (n+1)S_n - n - n + S_{n+1} - 1 = (n+1)S_n + S_{n+1} - 2n - 1.$$

Since $S_{n+1} = S_n + \tfrac{1}{n+1}$:

$$U_n = (n+2)S_n + \tfrac{1}{n+1} - 2n - 1.$$

Converting to $S_{n+1}$ via $S_n = S_{n+1} - \tfrac{1}{n+1}$:

$$U_n = (n+2)\!\left(S_{n+1}-\tfrac{1}{n+1}\right) + \tfrac{1}{n+1} - 2n - 1 = (
n+2)S_{n+1} - \tfrac{n+2}{n+1} + \tfrac{1}{n+1} - 2n - 1.$$

$$= (n+2)S_{n+1} - \tfrac{n+1}{n+1} - 2n - 1 = (n+2)S_{n+1} - (2n+2) = (n+2)S_{n
+1} - 2(n+1).$$

**Verification ($n=1$):** $U_1 = T_1/2 = 1/2$. Formula: $3\cdot S_2 - 4 = 3\cdot
(3/2)-4 = 1/2$. ✓

**Verification ($n=2$):** $T_1=1,\, T_2=5/2$, so $U_2 = 1/2 + (5/2)/3 = 1/2 + 5/
6 = 4/3$. Formula: $4\cdot S_3 - 6 = 4\cdot(11/6)-6 = 44/6-6 = 44/6-36/6 = 8/6 =
 4/3$. ✓

## Finding $c, d$

Setting $n=1988$ (so $n+1 = 1989$, $n+2 = 1990$):

$$U_{1988} = 1990\,S_{1989} - 2\cdot 1989 = 1990\,S_{1989} - 3978.$$

So $\boxed{c = 1990,\; d = 3978}$, with $0 < c, d < 1000000$. ✓
