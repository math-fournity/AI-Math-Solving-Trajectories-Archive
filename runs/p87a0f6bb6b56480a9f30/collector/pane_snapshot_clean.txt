## Setup

Let $u = \sqrt[3]{a},\; v = \sqrt[3]{b},\; w = \sqrt[3]{c}$ (real cube roots). T
hen $u^3=a, v^3=b, w^3=c$.

By Vieta's for $x^3-3x^2-7x-1=0$:
$$a+b+c=3,\quad ab+bc+ca=-7,\quad abc=1.$$

So $u^3+v^3+w^3=3$, $(uv)^3+(vw)^3+(wu)^3=-7$, and $(uvw)^3=1 \Rightarrow uvw=1$
.

Set $p=u+v+w$, $q=uv+vw+wu$, $r=uvw=1$.

## Determining $p$ and $q$

Using $u^3+v^3+w^3 = p^3-3pq+3r$:
$$3 = p^3-3pq+3 \;\Rightarrow\; p(p^2-3q)=0.$$

**Case $p=0$:** Then $u^3+v^3+w^3=3r=3$ ✓. For $X=uv,Y=vw,Z=wu$: $X+Y+Z=q$, $XY+
YZ+ZX=uvw(u+v+w)=0$, $XYZ=(uvw)^2=1$. Then
$$X^3+Y^3+Z^3 = q^3-3q\cdot 0+3\cdot 1 = q^3+3 = -7 \;\Rightarrow\; q^3=-10 \;\R
ightarrow\; q=-\sqrt[3]{10}.$$

**Verification:** $u,v,w$ are roots of $t^3-\sqrt[3]{10}\,t-1=0$. Then $a=u^3=\s
qrt[3]{10}\,u+1$, and one checks $a+b+c=3$, $ab+bc+ca=-7$, $abc=1$ all hold. ✓

(The case $p^2=3q$ leads to $p^6-27p^3+270=0$ with negative discriminant — impos
sible for real $p$. So $p=0$.)

## Computing the Expression

Let $S = \frac{1}{u-v}+\frac{1}{v-w}+\frac{1}{w-u}$. With common denominator $(u
-v)(v-w)(w-u)$, the numerator is:
$$(v-w)(w-u)+(u-v)(w-u)+(u-v)(v-w) = -(u^2+v^2+w^2-uv-vw-wu).$$

Since $u^2+v^2+w^2-uv-vw-wu = (u+v+w)^2-3(uv+vw+wu) = p^2-3q = 0-3(-\sqrt[3]{10}
) = 3\sqrt[3]{10}$,

$$S = \frac{-3\sqrt[3]{10}}{(u-v)(v-w)(w-u)}.$$

## The Discriminant

The discriminant of the monic cubic $t^3-\sqrt[3]{10}\,t-1=0$ (roots $u,v,w$) eq
uals $(u-v)^2(v-w)^2(w-u)^2$.

For $t^3+Pt+Q=0$: $\Delta = -4P^3-27Q^2$. Here $P=-\sqrt[3]{10},\; Q=-1$:
$$\Delta = -4(-\sqrt[3]{10})^3 - 27(-1)^2 = -4(-10)-27 = 40-27 = 13.$$

So $((u-v)(v-w)(w-u))^2 = 13$.

## Final Computation

$$S^2 = \frac{9\sqrt[3]{10}^{\,2}}{13} = \frac{9\sqrt[3]{100}}{13}.$$

Reading off: $p=9,\; q=100,\; r=13$.

- $\gcd(9,13)=1$ ✓
