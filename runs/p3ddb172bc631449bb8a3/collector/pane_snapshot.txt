  • 存在严格递增的共尾序列 (c_α)_{α<κ} 在 No(κ) 中。

关于"长度"的解释：在 Hahn 级数理论中（Alling, Ehrlich），级数的"长度"指其支撑集
（exponent 集）的序型。记号 ℝ((x))^{No(κ)}_{<κ^+} 中的下标 <κ^+ 正是对序型的约
束。因此：

  • "长度 < κ" = 支撑序型 < κ
  • "长度 κ" = 支撑序型 = κ
  • "有 No(κ) 中的共尾 κ-序列" = 支撑在 No(κ) 中共尾（这是对序型 = κ 的非平凡附
  加条件，因为序型 κ 的良序集本身共尾性为 κ，但未必在 No(κ) 中共尾）

反例构造

第一步：构造两个属于 S 的级数

取严格递增共尾序列 (c_α)_{α<κ}。对每个 α < κ（注意 α+1 < κ，因 κ 是极限序数），
定义：

$$a_\alpha = c_\alpha, \qquad b_\alpha = \frac{c_\alpha + c_{\alpha+1}}{2}$$

因 (c_α) 严格递增，有：

$$a_\alpha < b_\alpha < a_{\alpha+1} \quad \text{对所有 } \alpha < \kappa$$

令 A = {a_α : α < κ}，B = {b_α : α < κ}。

A 和 B 的性质：

  • 良序性：(a_α) 严格递增，故 A 良序，序型 κ。同理 B 良序，序型 κ。✓
  • 共尾性：A = {c_α} 在 No(κ) 中共尾（因 (c_α) 共尾）。B 也在 No(κ) 中共尾，因
  b_α > a_α = c_α，而 (c_α) 共尾。✓
  • 不相交：b_α = (c_α + c_{α+1})/2 严格介于 c_α 与 c_{α+1} 之间。对任意 β：若 β
  ≤ α 则 c_β ≤ c_α < b_α；若 β ≥ α+1 则 c_β ≥ c_{α+1} > b_α。故 b_α ≠ c_β 对所有
  β，即 A ∩ B = ∅。✓

定义 Hahn 级数（系数全为 1）：

$$f = \sum_{\alpha < \kappa} x^{a_\alpha}, \qquad g = \sum_{\alpha < \kappa}
x^{b_\alpha}$$

f, g ∈ S：f 和 g 的支撑序型均为 κ，且各自的支撑在 No(κ) 中共尾（存在共尾 κ-序
列）。因此无论"共尾 κ-序列"理解为在支撑中共尾还是在 No(κ) 中共尾，f 和 g 都满足
S 的第二条。✓

第二步：证明 f + g ∉ S

f + g 的支撑：因 A ∩ B = ∅，f + g 的支撑为 A ∪ B。

A ∪ B 是良序的：两个良序子集的并仍为良序集。（证明：对 A ∪ B 的任意非空子集 C，C
∩ A 和 C ∩ B 至少一个非空。若 C ∩ A 非空，取 a = min(C ∩ A)；若 C ∩ B 非空，取 b
= min(C ∩ B)。则 min(C) = min(a, b) 存在。）✓

A ∪ B 的序型为 κ · 2：由 a_α < b_α < a_{α+1}（对所有 α < κ），A ∪ B 中的元素排列
为：

$$a_0 < b_0 < a_1 < b_1 < a_2 < b_2 < \cdots < a_\alpha < b_\alpha <
a_{\alpha+1} < \cdots$$

每一对 (a_α, b_α) 贡献序型 2，共 κ 对按序排列，故序型 = κ + κ = κ · 2。

κ · 2 > κ（因 κ 是无穷基数，κ · 2 = |κ| · 2 > κ 作为序数），故：

  • κ · 2 ≮ κ：不满足"长度 < κ"。✗
  • κ · 2 ≠ κ：不满足"长度 κ"的前提条件，因此"长度 κ 且有共尾 κ-序列"条款不适
  用。✗

因此 f + g ∉ S。

第三步：验证 f + g 在外层域中

|κ · 2| = κ < κ^+，故 κ · 2 < κ^+（作为序数）。因此：

$$f + g \in \mathbb{R}((x))^{No(\kappa)}_{<\kappa^+} \subseteq \mathbb{R}
((x))^{No(\kappa)}$$

即 f + g 是外层 Hahn 域中的合法元素，只是不属于 S。

────────────────────────────────────────────────────────────────────────────────

结论

我们构造了 f, g ∈ S 使得 f + g ∉ S。因此：

  1. S 不是 ℝ((x))^{No(κ)} 的子域——它在加法下不封闭。
  2. S 不能作为 No(κ) 的完备化——完备化首先必须是域，而 S 连子域都不是。

核心原因：两个序型为 κ 的良序支撑之并可达序型 κ · 2，它落在 (κ, κ^+) 的"间隙"中
——既不 < κ 也不 = κ，从而被 S 排除。正则基数 κ^+ 处的截断 ℝ((x))^{No(κ)}_{<κ^+}
确实是域（因 κ^+ 正则，< κ^+ 的序型在自然和下封闭），但 S 在 κ 处做了更细的截
断，引入了 (κ, κ^+) 间的空洞，破坏了加法封闭性。
