## Setup: Reducing to a Real Integral

For $x \in [0,1)$, we have $x^2 - 1 < 0$, so $\sqrt{x^2-1} = i\sqrt{1-x^2}$ (pri
ncipal branch). Then

$$\frac{x-1}{\sqrt{x^2-1}} = \frac{-(1-x)}{i\sqrt{(1-x)(1+x)}} = \frac{-\sqrt{1-
x}}{i\sqrt{1+x}} = \frac{i\sqrt{1-x}}{\sqrt{1+x}},$$

which is purely imaginary with non-negative imaginary part. Using the identity $
\arctan(iy) = i\,\operatorname{arctanh}(y)$ for real $y$:

$$\arctan\!\left(\frac{i\sqrt{1-x}}{\sqrt{1+x}}\right) = i\,\operatorname{arctan
h}\!\left(\frac{\sqrt{1-x}}{\sqrt{1+x}}\right).$$

The full integrand becomes

$$\frac{i\,\operatorname{arctanh}\!\left(\frac{\sqrt{1-x}}{\sqrt{1+x}}\right)}{i
\sqrt{1-x^2}} = \frac{\operatorname{arctanh}\!\left(\frac{\sqrt{1-x}}{\sqrt{1+x}
}\right)}{\sqrt{1-x^2}},$$

which is real and non-negative. So

$$I = \int_0^1 \frac{\operatorname{arctanh}\!\left(\frac{\sqrt{1-x}}{\sqrt{1+x}}
\right)}{\sqrt{1-x^2}}\,dx.$$

## Substitution $t = \sqrt{(1-x)/(1+x)}$

Set $t = \sqrt{\frac{1-x}{1+x}}$, so $t^2 = \frac{1-x}{1+x}$ and $x = \frac{1-t^
2}{1+t^2}$. Bounds: $x=0 \Rightarrow t=1$; $x=1 \Rightarrow t=0$. Compute:

$$dx = \frac{-4t}{(1+t^2)^2}\,dt, \qquad \sqrt{1-x^2} = \frac{2t}{1+t^2}.$$

Therefore

$$I = \int_1^0 \frac{\operatorname{arctanh}(t)}{\frac{2t}{1+t^2}}\cdot\frac{-4t}
{(1+t^2)^2}\,dt = \int_0^1 \frac{2\,\operatorname{arctanh}(t)}{1+t^2}\,dt.$$

## Substitution $t = \tan\theta$

Set $t = \tan\theta$, $dt = \sec^2\theta\,d\theta$, $1+t^2 = \sec^2\theta$. Boun
ds: $t=0 \Rightarrow \theta=0$; $t=1 \Rightarrow \theta=\pi/4$. Using $\operator

$$I = \int_0^{\pi/4} \ln\!\frac{1+\tan\theta}{1-\tan\theta}\,d\theta.$$

Since $\frac{1+\tan\theta}{1-\tan\theta} = \tan\!\left(\frac{\pi}{4}+\theta\righ

$$I = \int_0^{\pi/4} \ln\tan\!\left(\frac{\pi}{4}+\theta\right)d\theta.$$

## Final Evaluation

Let $u = \frac{\pi}{4}+\theta$:

$$I = \int_{\pi/4}^{\pi/2} \ln\tan u\,du.$$

Now use two classical facts:

1. **Symmetry:** $\int_0^{\pi/2}\ln\tan u\,du = 0$ (substitute $u \mapsto \frac{
\pi}{2}-u$; the integrand changes sign).

2. **Catalan's constant:** $\int_0^{\pi/4}\ln\tan u\,du = -G$, where $G = \sum_{
n=0}^{\infty}\frac{(-1)^n}{(2n+1)^2}$ is Catalan's constant. This follows from t

2}$, whose difference gives $-G$.

Therefore:

$$I = \int_0^{\pi/2}\ln\tan u\,du - \int_0^{\pi/4}\ln\tan u\,du = 0 - (-G) = G.$
