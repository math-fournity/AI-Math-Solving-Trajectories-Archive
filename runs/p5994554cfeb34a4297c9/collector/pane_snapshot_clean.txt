## Solution

We seek a non-constant polynomial $f$ satisfying $f(g(x)) = g(f(x))$ with $g(x)
= 3x^4 - 1$.

### Degree and leading-coefficient analysis

Let $\deg f = d$ and write $f(x) = a x^d + \cdots$ ($a \neq 0$). Comparing leadi
ng terms of $f(g(x)) = g(f(x))$:

- $f(g(x))$ has leading term $a(3x^4)^d = a \cdot 3^d x^{4d}$.
- $g(f(x)) = 3(f(x))^4 - 1$ has leading term $3(a x^d)^4 = 3a^4 x^{4d}$.

Equating: $a \cdot 3^d = 3a^4$, i.e. $a^3 = 3^{d-1}$, so $a = 3^{(d-1)/3}$. For
$a$ to be rational we need $d \equiv 1 \pmod 3$; the smallest nontrivial value i
s $d = 4$, giving $a = 3$.

### Degree 2 is impossible

Try $f(x) = ax^2+bx+c$ with $a = 3^{1/3}$. Then $f(g(x)) = 9a\,x^8 + (3b-6a)x^4
+ (a-b+c)$, which contains **only** $x^8, x^4, x^0$ terms. But $g(f(x)) = 3(ax^2
+bx+c)^4-1$ has an $x^7$ coefficient $12a^3 b = 36b$, forcing $b=0$; then its $x
^6$ coefficient $12a^3 c = 36c$ forces $c=0$; then $f(x)=ax^2$ and the $x^4$ coe
fficient gives $-6a = 0$, contradiction. So no degree-2 solution exists.

### Degree 4: unique solution $f = g$

Write $f(x) = 3x^4 + px^3 + qx^2 + rx + s$. Since $g$ is even, $g(f(x)) = g(f(-x
))$, which forces $f(-x)^4 = f(x)^4$, so over $\mathbb{R}$ the polynomial $f$ is
 either even or odd. Degree $4$ rules out odd, so $f$ is even: $p = r = 0$, givi
ng $f(x) = 3x^4 + qx^2 + s$.

Now $f(g(x)) = 3(3x^4-1)^4 + q(3x^4-1)^2 + s$ is a polynomial in $x^4$ alone (on
ly powers $x^{16}, x^{12}, x^8, x^4, x^0$). Meanwhile $g(f(x)) = 3(3x^4+qx^2+s)^
4 - 1$. Setting $t = x^2$, the $x^2$-coefficient of $(3t^2+qt+s)^4$ is $4qs^3$,
so the $x^2$-term of $g(f(x))$ is $12qs^3$; vanishing requires $q=0$ or $s=0$.

- **If $s = 0$**: $f(x) = 3x^4 + qx^2$, and $g(f(x)) = 3x^8(3x^2+q)^4 - 1$. The
$x^{10}$-coefficient is $36q^3$, forcing $q=0$, giving $f(x)=3x^4$, but then $f(
g(x)) = 3(3x^4-1)^4 = 243x^{16}-324x^{12}+162x^8-36x^4+3 \neq 243x^{16}-1 = g(f(
x))$. Contradiction.

- **If $q = 0$**: $f(x) = 3x^4 + s$. Substitute $u = x^4$:
$$f(g(x)) = 3(3u-1)^4 + s = 243u^4 - 324u^3 + 162u^2 - 36u + 3 + s,$$
$$g(f(x)) = 3(3u+s)^4 - 1 = 243u^4 + 324s\,u^3 + 162s^2 u^2 + 36s^3 u + 3s^4 - 1
.$$
Matching coefficients:
  - $u^3$: $-324 = 324s \Rightarrow s = -1$.
  - $u^2$: $162 = 162s^2 = 162\;\checkmark$.
  - $u^1$: $-36 = 36s^3 = -36\;\checkmark$.
  - $u^0$: $3 + s = 3s^4 - 1 \Rightarrow 2 = 2\;\checkmark$.

All coefficients agree precisely when $s = -1$.

### Conclusion

The unique degree-4 (hence simplest non-identity) polynomial commuting with $g(x
) = 3x^4 - 1$ is

$$\boxed{f(x) = 3x^4 - 1}.$$

Verification: $f(g(x)) = 3(3x^4-1)^4 - 1 = g(3x^4-1) = g(f(x))$. $\checkmark$
