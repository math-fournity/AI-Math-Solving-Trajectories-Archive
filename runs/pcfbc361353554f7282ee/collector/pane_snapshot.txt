## Proof

Let $\mathbb{N}$ be the set of natural numbers and $\mathcal{P}\mathbb{N}$ its p
ower set. Let $I$ denote the set of injective functions $f:\mathbb{N}\to\mathcal
{P}\mathbb{N}$. We show $|I| = 2^{\aleph_0}$.

**Upper bound.** Every injective function is in particular a function, so
$$I \subseteq \mathcal{P}\mathbb{N}^{\,\mathbb{N}}.$$
Hence
$$|I| \le |\mathcal{P}\mathbb{N}|^{|\mathbb{N}|} = (2^{\aleph_0})^{\aleph_0} = 2
^{\aleph_0\cdot\aleph_0} = 2^{\aleph_0}.$$

**Lower bound.** We construct $2^{\aleph_0}$ many distinct injections. For each
subset $A\subseteq\mathbb{N}$, define $f_A:\mathbb{N}\to\mathcal{P}\mathbb{N}$ b
y
$$f_A(n) = \begin{cases}\{2n\}, & n\in A,\\ \{2n+1\}, & n\notin A.\end{cases}$$

Each $f_A$ is injective: the values $\{2n\}$ and $\{2n+1\}$ are pairwise distinc
t singletons as $n$ ranges over $\mathbb{N}$ (the integers $2n$ and $2n+1$ are a
ll distinct), so $f_A(n)\neq f_A(m)$ whenever $n\neq m$.

The map $A\mapsto f_A$ is itself injective: if $A\neq B$, pick $n$ with $n\in A\
triangle B$; then $f_A(n)\neq f_B(n)$, so $f_A\neq f_B$.

Therefore
$$|I| \ge |\mathcal{P}\mathbb{N}| = 2^{\aleph_0}.$$

**Conclusion.** Combining both bounds,
$$|I| = 2^{\aleph_0}.$$

The cardinality of the set of injective functions from $\mathbb{N}$ to $\mathcal
{P}\mathbb{N}$ is $\boxed{2^{\aleph_0}}$ (the cardinality of the continuum).
