Looking at this problem, I need to determine whether the solution to $dX_t = \si
gma(X_t)dB_t$ (with $\sigma$ globally Lipschitz with constant $K$) is a martinga
le.

**Answer: Yes, $(X_t)_{t\geq 0}$ is a martingale.**

## Proof

The SDE $dX_t = \sigma(X_t)\,dB_t$ has the mild form
$$X_t = X_0 + \int_0^t \sigma(X_s)\,dB_s.$$
Since $\sigma$ is globally Lipschitz, standard existence/uniqueness theory gives
 a unique strong solution, which is a **continuous local martingale** (the drift
 is zero). The question is whether it is a *true* martingale.

**Key criterion.** A continuous local martingale $M$ with $M_0 \in L^2$ is a tru
e martingale (in fact square-integrable) if $\mathbb{E}[\langle M\rangle_t] < \i
nfty$ for every $t \geq 0$. Here $\langle X\rangle_t = \int_0^t \sigma^2(X_s)\,d
s$, so it suffices to show $\mathbb{E}\!\left[\int_0^t \sigma^2(X_s)\,ds\right]
< \infty$ for all $t$.

**Growth bound on $\sigma$.** Since $\sigma$ is Lipschitz with constant $K$,
$$|\sigma(x)| \leq |\sigma(0)| + K|x|,$$
so by $(a+b)^2 \leq 2a^2+2b^2$,
$$\sigma^2(x) \leq 2\sigma(0)^2 + 2K^2 x^2. \tag{$\star$}$$

**Localization.** Define stopping times $\tau_n = \inf\{t \geq 0 : |X_t| \geq n\
}$. Since $X$ has continuous paths, $|X_{t\wedge\tau_n}| \leq n$, so $X^{(\tau_n
)}$ is a **bounded** local martingale, hence a true martingale. By Itô isometry
applied to the bounded integrand,
$$\mathbb{E}\!\left[X_{t\wedge\tau_n}^2\right] = X_0^2 + \mathbb{E}\!\left[\int_
0^{t\wedge\tau_n}\sigma^2(X_s)\,ds\right].$$

**Gronwall estimate.** Set $f_n(t) = \mathbb{E}[X_{t\wedge\tau_n}^2]$. Using $(\
star)$ and $\mathbb{E}[X_{s\wedge\tau_n}^2\,\mathbf{1}_{s<\tau_n}] \leq f_n(s)$:
$$f_n(t) \leq X_0^2 + 2\sigma(0)^2\,t + 2K^2\int_0^t f_n(s)\,ds.$$

By Gronwall's inequality,
$$f_n(t) \leq \bigl(X_0^2 + 2\sigma(0)^2\,t\bigr)\,e^{2K^2 t}. \tag{$\dagger$}$$

**Crucially, the bound $(\dagger)$ is independent of $n$.** By Fatou's lemma (wi
th $\tau_n \to \infty$ a.s. since $X$ does not explode under global Lipschitz co
nditions):
$$\mathbb{E}[X_t^2] \leq \liminf_{n\to\infty} f_n(t) \leq \bigl(X_0^2 + 2\sigma(
0)^2\,t\bigr)\,e^{2K^2 t} < \infty.$$

**Conclusion.** Using $(\star)$ and the finiteness of $\mathbb{E}[X_s^2]$:
$$\mathbb{E}[\langle X\rangle_t] = \mathbb{E}\!\left[\int_0^t \sigma^2(X_s)\,ds\
right] \leq \int_0^t\!\bigl(2\sigma(0)^2 + 2K^2\,\mathbb{E}[X_s^2]\bigr)\,ds < \
infty.$$

Since $\mathbb{E}[\langle X\rangle_t] < \infty$ for every $t \geq 0$, the contin
uous local martingale $X$ is a **true martingale** (and is square-integrable on
every finite time interval). $\blacksquare$
