## Proof

**Claim:** If $f \in C^2(\mathbb{R}^n)$ has a bounded second derivative (Hessian
), i.e., there exists $L \geq 0$ such that $\|\nabla^2 f(x)\|_{\mathrm{op}} \leq
 L$ for all $x \in \mathbb{R}^n$, then $\nabla f$ is globally $L$-Lipschitz. Con
sequently, **no** — a function with a bounded second derivative cannot have a gr
adient that fails to be globally Lipschitz.

**Proof.** Let $x, y \in \mathbb{R}^n$ be arbitrary. Define the vector-valued ma
p
$$h(t) := \nabla f\bigl(y + t(x - y)\bigr), \qquad t \in [0,1].$$
Since $f \in C^2$, $h$ is continuously differentiable, and by the chain rule
$$h'(t) = \nabla^2 f\bigl(y + t(x-y)\bigr)\,(x - y).$$
By the fundamental theorem of calculus for vector-valued functions,
$$\nabla f(x) - \nabla f(y) = h(1) - h(0) = \int_0^1 h'(t)\,dt = \int_0^1 \nabla
^2 f\bigl(y + t(x-y)\bigr)(x-y)\,dt.$$
Taking norms and using the triangle inequality for integrals together with the s
ubmultiplicativity of the operator norm,
$$\|\nabla f(x) - \nabla f(y)\| \leq \int_0^1 \bigl\|\nabla^2 f\bigl(y + t(x-y)\
bigr)\bigr\|_{\mathrm{op}}\,\|x - y\|\,dt \leq \int_0^1 L\,\|x-y\|\,dt = L\,\|x
- y\|.$$

Since $x$ and $y$ were arbitrary, $\nabla f$ is globally $L$-Lipschitz. $\blacks
quare$

**Remark (1D case).** When $n = 1$, this reduces to the classical fact: if $|f''
| \leq L$ everywhere, then the mean value theorem applied to $f'$ gives $|f'(x)
- f'(y)| \leq L|x - y|$ for all $x, y$, so $f'$ is globally $L$-Lipschitz.

**Remark (necessity of global boundedness).** The conclusion requires the second
 derivative to be bounded on the *entire* domain. A function whose second deriva
tive is bounded only on bounded sets (locally Lipschitz gradient) but unbounded
globally — e.g., $f(x) = \tfrac{1}{4}x^4$ with $f''(x) = 3x^2$ — has a gradient
$f'(x) = x^3$ that is *not* globally Lipschitz. This confirms that the global bo
und on the second derivative is precisely the condition that upgrades "locally L
ipschitz gradient" to "globally Lipschitz gradient."

**Conclusion.** A function with a (globally) bounded second derivative necessari
ly has a globally Lipschitz gradient. Therefore such a function **cannot** have
a gradient that is not globally Lipschitz.
