## Proof: Cardinality of the Set of Formulas in a First-Order Language

**Setup.** A first-order language $L$ consists of:

- **Logical symbols**: a countable set of variables $\{v_n : n \in \mathbb{N}\}$
, the connectives $\{\neg, \wedge, \vee, \to, \leftrightarrow\}$, the quantifier
s $\{\forall, \exists\}$, parentheses $\{(, )\}$, and (optionally) equality $\{=
\}$. This is a fixed, countable collection.
- **Non-logical symbols**: a set $S = S_c \cup S_f \cup S_r$ comprising constant
 symbols, function symbols (each with an assigned arity), and relation symbols (
each with an assigned arity). Let $\kappa = |S|$.

Let $\text{Form}(L)$ denote the set of all well-formed $L$-formulas.

**Claim.** $|\text{Form}(L)| = \max(\aleph_0, \kappa)$.

---

### Upper Bound

Every $L$-formula is a finite string over the alphabet
$$\Sigma = \{\text{variables}\} \cup \{\text{logical symbols}\} \cup S.$$

The set of variables is countable, the set of logical symbols is finite, and $|S
| = \kappa$, so
$$|\Sigma| = \max(\aleph_0, \kappa).$$

Let $\Sigma^* = \bigcup_{n=0}^{\infty} \Sigma^n$ be the set of all finite string
s over $\Sigma$. Then
$$|\Sigma^*| = \left|\bigcup_{n=0}^{\infty} \Sigma^n\right| = \sum_{n=0}^{\infty
} |\Sigma|^n.$$

- **If $|\Sigma| = \lambda$ is infinite**: $|\Sigma|^n = \lambda$ for every $n \
geq 1$, and $|\Sigma|^0 = 1$, so $|\Sigma^*| = \aleph_0 \cdot \lambda = \lambda$
.
- **If $|\Sigma|$ is finite and $\geq 2$**: $|\Sigma^*| = \aleph_0$ (there are c
ountably many finite strings over a finite alphabet).

In both cases, $|\Sigma^*| = \max(\aleph_0, |\Sigma|) = \max(\aleph_0, \kappa)$.

Since every formula is a finite string, $\text{Form}(L) \subseteq \Sigma^*$, giv
ing
$$|\text{Form}(L)| \leq \max(\aleph_0, \kappa).$$

---

### Lower Bound

We consider two cases.

**Case 1: $\kappa \geq \aleph_0$ (the non-logical symbol set is infinite).**

We exhibit an injection $S \hookrightarrow \text{Form}(L)$, showing $|\text{Form
}(L)| \geq |S| = \kappa$.

For each symbol $s \in S$, assign a distinct atomic formula:

- If $s$ is a **constant** $c$: assign the formula $c = c$.
- If $s$ is an **$n$-ary function** $f$: assign the formula $f(v_0, \dots, v_0)
= v_0$.
- If $s$ is an **$n$-ary relation** $R$: assign the formula $R(v_0, \dots, v_0)$
.

(If equality is not part of the language, constants and function symbols can ins
tead be distinguished via an atomic relation formula using a fixed relation symb
ol; the argument is adapted trivially. The standard convention includes equality
.)

Each symbol $s$ produces a syntactically distinct formula (the leading symbol of
 the formula's atomic core is $s$ itself), so this map is injective. Hence
$$|\text{Form}(L)| \geq \kappa \geq \aleph_0, \quad \text{i.e., } |\text{Form}(L
)| \geq \max(\aleph_0, \kappa) = \kappa.$$

**Case 2: $\kappa < \aleph_0$ (the non-logical symbol set is finite).**

The set of formulas is infinite. For instance, starting from the atomic formula
$\varphi_0 := (v_0 = v_0)$, define
$$\varphi_{n+1} := (\varphi_n \wedge v_0 = v_0) \quad \text{for } n \geq 0.$$

The formulas $\varphi_0, \varphi_1, \varphi_2, \dots$ are pairwise syntactically
 distinct (they have strictly increasing lengths), forming a countably infinite
subset of $\text{Form}(L)$. Hence
$$|\text{Form}(L)| \geq \aleph_0 = \max(\aleph_0, \kappa).$$

---

### Conclusion

Combining the upper and lower bounds in both cases:
$$|\text{Form}(L)| = \max(\aleph_0, \kappa).$$

**In particular:**

- If $L$ has **finitely or countably many** non-logical symbols ($\kappa \leq \a
leph_0$), then $|\text{Form}(L)| = \aleph_0$: the set of formulas is **countably
 infinite**.
- If $L$ has **uncountably many** non-logical symbols of cardinality $\kappa > \
aleph_0$, then $|\text{Form}(L)| = \kappa$: the set of formulas has the **same c
ardinality as the set of non-logical symbols**.

The key mechanism is that formulas are finite strings, so the set of all formula
s is bounded above by the set of all finite strings over the alphabet; and since
 each symbol can be embedded into a distinct atomic formula, the set of formulas
 is bounded below by the number of symbols. For infinite languages these two bou
nds coincide. $\blacksquare$
