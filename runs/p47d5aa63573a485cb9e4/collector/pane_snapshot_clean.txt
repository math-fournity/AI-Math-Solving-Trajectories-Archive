## Setup

**Substitution.** Dividing $xy+yz+zx = xyz$ by $xyz$ gives $\frac{1}{x}+\frac{1}
{y}+\frac{1}{z}=1$. Set $a=\frac{1}{x},\, b=\frac{1}{y},\, c=\frac{1}{z}$, so $a
,b,c>0$ and $a+b+c=1$.

Then:
$$p = x+y+z = \frac{ab+bc+ca}{abc} = \frac{s}{t}, \qquad q = xy+yz+zx = \frac{1}
{abc} = \frac{1}{t}$$
where $s = ab+bc+ca$ and $t = abc$.

**Range of $q$.** By AM-GM, $t = abc \leq \frac{1}{27}$, so $q = \frac{1}{t} \ge
q 27$, with equality only at $a=b=c=\frac{1}{3}$ (i.e., $x=y=z=3$). Thus $q - 27
 \geq 0$ always.

The inequality becomes $\frac{s^2}{t^2} - 81 \geq k\!\left(\frac{1}{t}-27\right)
$. Multiplying by $t^2 > 0$:
$$s^2 - 81t^2 \geq kt(1-27t).$$

Since $0 < t \leq \frac{1}{27}$, we have $t(1-27t) \geq 0$, so the largest valid
 $k$ is:
$$k_{\max} = \inf \frac{s^2 - 81t^2}{t(1-27t)}.$$

## Reduction to two equal variables (uvw method)

The inequality $s^2 - 81t^2 - kt + 27kt^2 \geq 0$ is symmetric in $a,b,c$ and is
 a polynomial in $s,t$ (with $a+b+c=1$ fixed) that is **quadratic in $t$**. By t
he **uvw method**, it suffices to verify it when two variables are equal.

Set $b = c$, $a = 1-2b$, with $0 < b < \frac{1}{2}$. Then:
$$s = 2b - 3b^2, \qquad t = b^2(1-2b).$$

## Finding the minimum

Define $R(b) = \frac{s^2-81t^2}{t(1-27t)}$. Computing:
$$R(b) = \frac{4 - 12b - 72b^2 + 324b^3 - 324b^4}{1 - 2b - 27b^2 + 108b^3 - 108b
^4}.$$

Evaluating at $b = \frac{1}{6}$ (so $a = \frac{2}{3}$):
- $s = \frac{2}{6} - \frac{3}{36} = \frac{1}{4}$, $\quad t = \frac{1}{36}\cdot\f
rac{2}{3} = \frac{1}{54}$
- Numerator: $\frac{1}{16} - \frac{81}{2916} = \frac{1}{16}-\frac{1}{36} = \frac
{5}{144}$
- Denominator: $\frac{1}{54}\cdot\frac{1}{2} = \frac{1}{108}$
- $R\!\left(\frac{1}{6}\right) = \frac{5/144}{1/108} = \frac{15}{4}$

Checking $R'\!\left(\frac{1}{6}\right) = 0$ (critical point) and boundary behavi
or ($R\to 4$ as $b\to 0$, $R\to\infty$ as $b\to\frac{1}{2}$), this is the global
 minimum on the curve.

## Proving $k = \frac{15}{4}$ works

We need $4s^2 + 81t^2 - 15t \geq 0$. On the $b=c$ curve:
$$4s^2 + 81t^2 - 15t = b^2\bigl(1 - 18b + 117b^2 - 324b^3 + 324b^4\bigr).$$

**Factoring** the quartic:
$$1 - 18b + 117b^2 - 324b^3 + 324b^4 = (6b-1)^2(3b-1)^2.$$

Therefore:
$$4s^2 + 81t^2 - 15t = b^2(6b-1)^2(3b-1)^2 \geq 0,$$

with equality at $b = \frac{1}{6}$ (giving $a=\frac{2}{3}, b=c=\frac{1}{6}$) and
 $b=\frac{1}{3}$ (the symmetric point). By the uvw method, this proves the inequ
ality for **all** $a,b,c>0$ with $a+b+c=1$.

## Verification at the extremal point

Equality holds, confirming $k = \frac{15}{4}$ is tight.
