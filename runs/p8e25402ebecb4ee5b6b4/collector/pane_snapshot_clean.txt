## Proof

**Notation.** Let $S(a,b) = \sum_{n=a}^{b} \frac{1}{n}$ and let $\operatorname{d
en}(x)$ denote the denominator of $x$ in lowest terms. Let $v_3$ denote the 3-ad
ic valuation on $\mathbb{Q}$.

**Construction.** Given $a \geq 1$, let $k \geq 0$ be the unique integer with $3
^k < a \leq 3^{k+1}$. Set $b = 2\cdot 3^{k+1} - 1$.

**$a < b$:** Since $a \leq 3^{k+1}$ and $3^{k+1} < 2\cdot 3^{k+1} - 1 \iff 1 < 3
^{k+1}$ (true for $k \geq 0$), we get $a \leq 3^{k+1} < b$. ✓

---

### Lemma 1: $v_3(S(a,b)) = -(k+1)$.

The multiples of $3^{k+1}$ in $[a,\, 2\cdot 3^{k+1}-1]$ are exactly $\{3^{k+1}\}
$: since $a \leq 3^{k+1}$ and $2\cdot 3^{k+1}-1 < 2\cdot 3^{k+1}$, the only cand
idate is $3^{k+1}$, and it lies in the range.

The term $\frac{1}{3^{k+1}}$ has $v_3 = -(k+1)$. Every other $n$ in the range sa
tisfies $v_3(n) \leq k$, so $v_3(1/n) \geq -k > -(k+1)$. Since there is a **uniq
ue** term achieving the minimum 3-adic valuation, the non-archimedean property g
ives $v_3(S(a,b)) = -(k+1)$. $\square$

---

### Lemma 2: $v_3(S(a,b+1)) \geq -k$.

We have $b+1 = 2\cdot 3^{k+1}$, so $v_3(1/(b+1)) = -(k+1)$, the same as $v_3(S(a
,b))$.

Write $S(a,b) = 3^{-(k+1)}\cdot \alpha$ with $v_3(\alpha) = 0$ (by Lemma 1). The
n:
$$S(a,b+1) = 3^{-(k+1)}\!\left(\alpha + \tfrac{1}{2}\right) = 3^{-(k+1)}\cdot \f
rac{2\alpha+1}{2}.$$

**Compute $\alpha \bmod 3$:** Since $\alpha = 3^{k+1}\cdot S(a,b) = \sum_{n=a}^{
2\cdot 3^{k+1}-1} \frac{3^{k+1}}{n}$:

- For $n = 3^{k+1}$: $\frac{3^{k+1}}{n} = 1$, contributing $v_3 = 0$ and value $
\equiv 1 \pmod{3}$.
- For $n \neq 3^{k+1}$: $v_3(n) \leq k$, so $v_3\!\left(\frac{3^{k+1}}{n}\right)
 \geq 1$; these terms are $\equiv 0 \pmod{3}$.

Therefore $\alpha \equiv 1 \pmod{3}$, whence $2\alpha + 1 \equiv 2\cdot 1 + 1 =
3 \equiv 0 \pmod{3}$, i.e., $v_3(2\alpha+1) \geq 1$.

Thus $v_3(S(a,b+1)) = -(k+1) + v_3(2\alpha+1) \geq -(k+1)+1 = -k$. $\square$

### Main argument: $\operatorname{den}(S(a,b+1)) < \operatorname{den}(S(a,b))$.

Write $S(a,b) = \frac{r_1}{s_1}$ in lowest terms. By Lemma 1, $v_3(s_1) = k+1$,
so $s_1 = 3^{k+1}\cdot m_1$ with $\gcd(m_1, 3) = 1$ and $\gcd(r_1, s_1) = 1$.

Now compute:
$$S(a,b+1) = \frac{r_1}{3^{k+1}\,m_1} + \frac{1}{2\cdot 3^{k+1}} = \frac{2r_1 +
m_1}{2\cdot 3^{k+1}\cdot m_1} = \frac{2r_1 + m_1}{2\,s_1}.$$

The denominator in lowest terms is:
$$s_2 := \operatorname{den}(S(a,b+1)) = \frac{2\,s_1}{\gcd(2r_1 + m_1,\; 2\,s_1)
}.$$

**Key claim:** $3 \mid \gcd(2r_1 + m_1,\; 2\,s_1)$.

- From Lemma 2: $v_3(2\alpha + 1) \geq 1$ where $\alpha = r_1/m_1$. Since $2\alp
ha + 1 = (2r_1 + m_1)/m_1$ and $v_3(m_1) = 0$, we get $v_3(2r_1 + m_1) \geq 1$,
i.e., $3 \mid (2r_1 + m_1)$.
- Since $s_1 = 3^{k+1}\,m_1$ with $k+1 \geq 1$, we have $3 \mid s_1$, hence $3 \
mid 2\,s_1$.

Therefore $3 \mid \gcd(2r_1 + m_1,\, 2\,s_1)$, so $\gcd(2r_1 + m_1,\, 2\,s_1) \g
eq 3$.

Consequently:
$$s_2 = \frac{2\,s_1}{\gcd(2r_1 + m_1,\, 2\,s_1)} \leq \frac{2\,s_1}{3} < s_1.$$

This gives $\operatorname{den}(S(a,b+1)) < \operatorname{den}(S(a,b))$ as requir
ed. $\square$

### Conclusion

For every $a \geq 1$, choosing $k$ with $3^k < a \leq 3^{k+1}$ and $b = 2\cdot 3
^{k+1} - 1$ yields $a < b$ and $\operatorname{den}(S(a,b+1)) < \operatorname{den

1. **Lemma 1:** $S(a,b)$ has a unique term ($1/3^{k+1}$) with minimal 3-adic val

3. The new denominator $s_2 = 2\,s_1 / g$ with $g \geq 3$ satisfies $s_2 \leq 2\

This proves the theorem. $\blacksquare$
