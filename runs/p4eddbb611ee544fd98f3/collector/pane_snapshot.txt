## Solution

**Intersection points:** Setting $x^3 - x = x$ gives $x^3 - 2x = 0$, so $x(x^2-2
)=0$, yielding $x = 0, \pm\sqrt{2}$.

**Setup — Disk method around the axis $y = x$.**

The region is bounded between the axis $y=x$ (one boundary) and the curve $y = x
^3 - x$ (the other boundary). Rotating around $y=x$, each cross-section perpendi
cular to the axis is a **disk** of radius equal to the perpendicular distance fr
om the curve to the axis.

**Perpendicular distance** from $(x,\, x^3-x)$ to the line $y=x$:
$$r = \frac{|(x^3 - x) - x|}{\sqrt{2}} = \frac{|x^3 - 2x|}{\sqrt{2}}.$$

**Arc-length parameter along the axis.** The foot of the perpendicular from $(x,
\, x^3-x)$ to $y=x$ is $\left(\frac{x^3}{2},\,\frac{x^3}{2}\right)$, so the arc-
length position along the axis is
$$\ell = \frac{x^3}{2}\cdot\sqrt{2} = \frac{x^3\sqrt{2}}{2}, \qquad d\ell = \fra
c{3x^2\sqrt{2}}{2}\,dx.$$

Since $x^3$ is strictly increasing, the projection of the curve onto the axis is
 one-to-one, so the disk method is valid (each point on the axis corresponds to
exactly one point on the curve; the left half $x\in[-\sqrt{2},0]$ and right half
 $x\in[0,\sqrt{2}]$ project to disjoint segments of the axis).

**Volume integral:**
$$V = \int_{-\sqrt{2}}^{\sqrt{2}} \pi\, r^2\, d\ell = \int_{-\sqrt{2}}^{\sqrt{2}
} \pi\cdot\frac{(x^3-2x)^2}{2}\cdot\frac{3x^2\sqrt{2}}{2}\,dx = \frac{3\pi\sqrt{
2}}{4}\int_{-\sqrt{2}}^{\sqrt{2}}(x^3-2x)^2\,x^2\,dx.$$

**Expanding the integrand:**
$$(x^3-2x)^2\,x^2 = (x^6 - 4x^4 + 4x^2)\,x^2 = x^8 - 4x^6 + 4x^4.$$

This is an even function, so:
$$\int_{-\sqrt{2}}^{\sqrt{2}}(x^8 - 4x^6 + 4x^4)\,dx = 2\int_0^{\sqrt{2}}(x^8 -
4x^6 + 4x^4)\,dx = 2\left[\frac{x^9}{9} - \frac{4x^7}{7} + \frac{4x^5}{5}\right]
_0^{\sqrt{2}}.$$

**Evaluating at $x=\sqrt{2}$** (using $(\sqrt{2})^n = 2^{n/2}$):
- $x^9 = 16\sqrt{2}$, $\;x^7 = 8\sqrt{2}$, $\;x^5 = 4\sqrt{2}$.

$$= 2\sqrt{2}\left[\frac{16}{9} - \frac{32}{7} + \frac{16}{5}\right] = 2\sqrt{2}
\cdot 16\left[\frac{1}{9} - \frac{2}{7} + \frac{1}{5}\right].$$

**Common denominator** $315$:
$$\frac{1}{9} - \frac{2}{7} + \frac{1}{5} = \frac{35 - 90 + 63}{315} = \frac{8}{
315}.$$

$$= 2\sqrt{2}\cdot 16\cdot\frac{8}{315} = \frac{256\sqrt{2}}{315}.$$

**Final volume:**
$$V = \frac{3\pi\sqrt{2}}{4}\cdot\frac{256\sqrt{2}}{315} = \frac{3\pi\cdot 256\c
dot 2}{4\cdot 315} = \frac{1536\pi}{1260} = \frac{128\pi}{105}.$$

$$\boxed{V = \dfrac{128\pi}{105}}$$
