## Proof

We work in ZFC (no Continuum Hypothesis). Recall that a set $S \subseteq \mathbb
{R}$ is a **Bernstein set** if neither $S$ nor $\mathbb{R}\setminus S$ contains
a nonempty perfect set.

### Two preliminary facts (ZFC theorems, no CH)

**Fact 1.** Every nonempty perfect subset of $\mathbb{R}$ has cardinality $\math
frak{c}$.

*Proof.* A nonempty perfect set $P$ is closed and has no isolated points. The Ca
ntor–Bendixson theorem writes every closed set as $P = C \cup D$ with $C$ perfec
t and $D$ countable; if $P$ itself is perfect and nonempty, then $P$ is uncounta
ble. Moreover, a nonempty perfect set contains a homeomorphic copy of $2^{\omega
}$ (split at every accumulation point), so $|P| \geq 2^{\aleph_0} = \mathfrak{c}
$; since $P \subseteq \mathbb{R}$, $|P| \leq \mathfrak{c}$. Hence $|P| = \mathfr
ak{c}$.

**Fact 2.** The family of nonempty perfect subsets of $\mathbb{R}$ has cardinali
ty $\mathfrak{c}$.

*Proof.* Every open subset of $\mathbb{R}$ is a countable union of open interval
s with rational endpoints, so there are at most $\mathfrak{c}^{\aleph_0} = \math
frak{c}$ open sets, hence at most $\mathfrak{c}$ closed sets, hence at most $\ma
thfrak{c}$ perfect sets. There are at least $\mathfrak{c}$ perfect sets (e.g. th
e intervals $[a,b]$, $a<b$). So the number is exactly $\mathfrak{c}$.

### Construction by transfinite recursion

By Fact 2, enumerate all nonempty perfect sets as $\{P_\alpha : \alpha < \mathfr
ak{c}\}$, using the initial ordinal $\mathfrak{c}$ (so every $\alpha < \mathfrak
{c}$ has $|\alpha| < \mathfrak{c}$). We define, by recursion on $\alpha < \mathf
rak{c}$, two points $a_\alpha, b_\alpha \in P_\alpha$ as follows.

At stage $\alpha$, let $C_\alpha = \{a_\beta, b_\beta : \beta < \alpha\}$ be the
 set of points already chosen. Since $|\alpha| < \mathfrak{c}$, we have $|C_\alp
ha| \leq 2|\alpha| < \mathfrak{c}$. By Fact 1, $|P_\alpha| = \mathfrak{c}$, so
$$|P_\alpha \setminus C_\alpha| = \mathfrak{c}.$$
In particular $P_\alpha \setminus C_\alpha$ has at least two points; pick distin
ct $a_\alpha, b_\alpha \in P_\alpha \setminus C_\alpha$.

This completes the recursion. Set
$$A = \{a_\alpha : \alpha < \mathfrak{c}\}, \qquad B = \{b_\alpha : \alpha < \ma
thfrak{c}\}, \qquad S = A.$$
By construction $A \cap B = \emptyset$ (each new pair avoids all previously chos
en points), so $B \subseteq \mathbb{R}\setminus S$.

### Verification

$S$ meets every nonempty perfect set: for any nonempty perfect $P$, we have $P =
 P_\alpha$ for some $\alpha$, and $a_\alpha \in P_\alpha \cap A = P \cap S$.

$\mathbb{R}\setminus S$ meets every nonempty perfect set: for $P = P_\alpha$, we
 have $b_\alpha \in P_\alpha \cap B \subseteq P \cap (\mathbb{R}\setminus S)$.

Now suppose, for contradiction, that $S$ contains a nonempty perfect set $P$. Th
en $P \subseteq S$, so $P \cap (\mathbb{R}\setminus S) = \emptyset$. But $\mathb
b{R}\setminus S$ meets every nonempty perfect set — contradiction.

Likewise, if $\mathbb{R}\setminus S$ contained a nonempty perfect set $P$, then
$P \cap S = \emptyset$, contradicting that $S$ meets every nonempty perfect set.

Therefore neither $S$ nor $\mathbb{R}\setminus S$ contains a nonempty perfect se
t; $S$ is a Bernstein set.

### Why CH is not used

The only set-theoretic ingredients are: (i) the Axiom of Choice, used to well-or
der the perfect sets and to make choices at each stage; (ii) the fact that $\mat
hfrak{c}$ is a cardinal, so every $\alpha < \mathfrak{c}$ has cardinality $< \ma
thfrak{c}$; (iii) Facts 1 and 2, both ZFC theorems. At no point do we need to kn
ow whether $\mathfrak{c} = \aleph_1$ or $\mathfrak{c} > \aleph_1$. The construct
ion works for whatever value $\mathfrak{c}$ happens to take. $\blacksquare$
