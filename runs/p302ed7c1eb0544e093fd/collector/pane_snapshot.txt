## Solution

We want $F'(0)$ for
$$F(x) = \frac{\Gamma\!\left(\frac{1+x}{2}\right)}{\sqrt{\pi}\;\Gamma\!\left(1+\
frac{x}{2}\right)}.$$

**Step 1: Evaluate $F(0)$.**

$$F(0) = \frac{\Gamma(1/2)}{\sqrt{\pi}\,\Gamma(1)} = \frac{\sqrt{\pi}}{\sqrt{\pi
}\cdot 1} = 1.$$

**Step 2: Logarithmic derivative.**

Let $L(x) = \log F(x)$. Then $F'(x) = F(x)\,L'(x)$, so $F'(0) = F(0)\,L'(0) = L'
(0)$.

$$L(x) = \log\Gamma\!\left(\tfrac{1+x}{2}\right) - \log\sqrt{\pi} - \log\Gamma\!
\left(1+\tfrac{x}{2}\right).$$

Differentiating (using $\frac{d}{du}\log\Gamma(u) = \psi(u)$, the digamma functi
on):

$$L'(x) = \tfrac{1}{2}\,\psi\!\left(\tfrac{1+x}{2}\right) - \tfrac{1}{2}\,\psi\!
\left(1+\tfrac{x}{2}\right).$$

**Step 3: Evaluate at $x=0$.**

$$L'(0) = \tfrac{1}{2}\bigl[\psi(1/2) - \psi(1)\bigr].$$

Using the standard digamma values:
- $\psi(1) = -\gamma$,
- $\psi(1/2) = -\gamma - 2\log 2$,

we get

$$\psi(1/2) - \psi(1) = (-\gamma - 2\log 2) - (-\gamma) = -2\log 2.$$

Therefore

$$L'(0) = \tfrac{1}{2}(-2\log 2) = -\log 2.$$

**Step 4: Conclude.**

$$F'(0) = F(0)\,L'(0) = 1\cdot(-\log 2) = -\log 2.$$

$$\boxed{F'(0) = -\log 2}$$
