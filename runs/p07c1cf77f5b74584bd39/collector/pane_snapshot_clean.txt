**Answer: Yes, it is always possible.**

## Proof

Let $\alpha, \beta$ be non-zero real numbers. We show that for every $\varepsilo
n > 0$, there exist non-zero integers $m, n$ with $|m\alpha + n\beta| < \varepsi
lon$.

Set $\gamma = \alpha/\beta$ (well-defined since $\beta \neq 0$; note $\gamma \ne
q 0$ since $\alpha \neq 0$). Then $|m\alpha + n\beta| = |\beta|\cdot|m\gamma + n
|$, so it suffices to find non-zero integers $m, n$ with $|m\gamma + n| < \varep
silon/|\beta|$.

**Case 1: $\gamma$ is rational.** Write $\gamma = p/q$ with $p, q$ non-zero inte
gers ($p \neq 0$ since $\gamma \neq 0$). Then $q\gamma - p = 0$, so taking $m =
q$, $n = -p$ (both non-zero) gives $|m\gamma + n| = 0 < \varepsilon/|\beta|$. ✓

**Case 2: $\gamma$ is irrational.** We use **Dirichlet's approximation theorem**
: *For any irrational $\gamma$ and any positive integer $N$, there exist integer
s $p, q$ with $1 \le q \le N$ and $|q\gamma - p| < 1/N$.*

*Proof of the theorem (pigeonhole):* Consider the $N+1$ fractional parts $\{0\},
 \{\gamma\}, \{2\gamma\}, \ldots, \{N\gamma\}$ in $[0,1)$. Partition $[0,1)$ int
o $N$ subintervals $[k/N, (k+1)/N)$, $k = 0,\ldots,N-1$. By pigeonhole, two of t
he $N+1$ values fall in the same subinterval: $\{i\gamma\}$ and $\{j\gamma\}$ wi
th $0 \le i < j \le N$. Set $q = j - i \in \{1,\ldots,N\}$ and $p = \lfloor j\ga
mma\rfloor - \lfloor i\gamma\rfloor \in \mathbb{Z}$. Then $|q\gamma - p| = |\{j\
gamma\} - \{i\gamma\}| < 1/N$. ✓

**Ensuring $p \neq 0$:** We need both $m = q \neq 0$ (guaranteed by $q \ge 1$) a
nd $n = -p \neq 0$. Suppose for contradiction that $p = 0$. Then $|q\gamma| < 1/
N$, so $|\gamma| < 1/(qN) \le 1/N$. Since $\gamma$ is a fixed non-zero real, cho
ose $N > 1/|\gamma|$; then $1/N < |\gamma|$, a contradiction. Hence $p \neq 0$ f
or all $N > 1/|\gamma|$.

**Completing the argument:** Given $\varepsilon > 0$, choose $N > \max\!\big(1/|
\gamma|,\; |\beta|/\varepsilon\big)$. By Dirichlet's theorem, there exist $p, q$
 with $1 \le q \le N$, $p \neq 0$, and $|q\gamma - p| < 1/N < \varepsilon/|\beta
|$. Set $m = q$, $n = -p$ (both non-zero). Then
$$|m\alpha + n\beta| = |\beta|\cdot|q\gamma - p| < |\beta|\cdot\frac{\varepsilon
}{|\beta|} = \varepsilon.$$

Since $\varepsilon > 0$ was arbitrary, $|m\alpha + n\beta|$ can be made arbitrar
ily close to zero with non-zero integers $m, n$. $\blacksquare$
