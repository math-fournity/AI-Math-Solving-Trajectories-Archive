# Solution

**Claim:** Yes, there exists a second countable metric space containing a set of
 infinite Hausdorff dimension.

**Example:** The separable Hilbert space $\ell^2$ of square-summable real sequen
ces, equipped with its standard metric
$$d(x,y) = \left(\sum_{i=1}^{\infty} |x_i - y_i|^2\right)^{1/2}.$$

Take $A = \ell^2$ itself.

---

## Proof

### Step 1: $\ell^2$ is second countable.

$\ell^2$ is a separable metric space: the set of sequences with rational entries
 that are eventually zero (i.e., $(q_1, \dots, q_n, 0, 0, \dots)$ with $q_i \in
\mathbb{Q}$) is countable and dense in $\ell^2$. Every separable metric space is
 second countable (the countable base consists of balls of rational radius cente
red at points of the countable dense set). Hence $\ell^2$ is second countable.

### Step 2: $\ell^2$ contains isometric copies of $\mathbb{R}^n$ for every $n$.

For each $n \geq 1$, define the embedding $\iota_n : \mathbb{R}^n \hookrightarro
w \ell^2$ by
$$\iota_n(x_1, \dots, x_n) = (x_1, \dots, x_n, 0, 0, \dots).$$
This is an isometry: for $x, y \in \mathbb{R}^n$,
$$d_{\ell^2}(\iota_n(x), \iota_n(y)) = \left(\sum_{i=1}^{n}|x_i - y_i|^2\right)^
{1/2} = \|x - y\|_{\mathbb{R}^n}.$$
Thus $E_n := \iota_n(\mathbb{R}^n) \subseteq \ell^2$ is an isometric copy of $\m
athbb{R}^n$.

### Step 3: Each $E_n$ has Hausdorff dimension $n$.

Hausdorff dimension is invariant under isometry (it depends only on the metric).
 Since $\dim_H(\mathbb{R}^n) = n$ (a standard fact: the $n$-dimensional Hausdorf
f measure of $\mathbb{R}^n$ is a positive constant multiple of Lebesgue measure,
 giving $\dim_H = n$), we have
$$\dim_H(E_n) = n.$$

### Step 4: $\dim_H(\ell^2) = \infty$.

Hausdorff dimension is monotone: if $S \subseteq T$, then $\dim_H(S) \leq \dim_H
(T)$. Since $E_n \subseteq \ell^2$ for every $n$,
$$\dim_H(\ell^2) \geq \dim_H(E_n) = n \quad \text{for all } n \geq 1.$$
Therefore $\dim_H(\ell^2) \geq \sup_n n = \infty$, i.e., $\dim_H(\ell^2) = \inft
y$.

### Conclusion

$\ell^2$ is a second countable metric space, and $A = \ell^2$ is a subset (indee
d the whole space) with infinite Hausdorff dimension. $\square$
