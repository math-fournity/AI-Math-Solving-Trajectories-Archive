# Stability Region of a Multistep Method

## Setup

Consider a linear multistep method $(\varrho, \sigma)$ applied to the Dahlquist
test equation

$$y' = \lambda y, \qquad \eta := h\lambda \in \mathbb{C}.$$

Substituting the exact solution form $y_n = \zeta^n$ into the method

$$\sum_{j=0}^{k} \alpha_j\, y_{n+j} = h\sum_{j=0}^{k} \beta_j\, f_{n+j},$$

and using $f_{n+j} = \lambda\, y_{n+j}$, yields the **characteristic equation**

$$\pi(\zeta, \eta) = \varrho(\zeta) - \eta\,\sigma(\zeta) = 0,$$

where

$$\varrho(\zeta) = \sum_{j=0}^{k} \alpha_j \zeta^j, \qquad \sigma(\zeta) = \sum_
{j=0}^{k} \beta_j \zeta^j.$$

The general numerical solution is a linear combination $y_n = \sum_i c_i\, \zeta
_i(\eta)^n$, where $\zeta_i(\eta)$ are the roots of $\pi(\zeta,\eta)=0$.

## Definition of the Stability Region

The **stability region** $S$ is the set of all $\eta \in \mathbb{C}$ for which t
he characteristic polynomial satisfies the **root condition**, i.e. for which ev
ery numerical solution of the test equation remains bounded as $n \to \infty$:

$$\boxed{\;S = \bigl\{\,\eta \in \mathbb{C} : \pi(\zeta,\eta) = \varrho(\zeta) -
 \eta\,\sigma(\zeta) \text{ satisfies the root condition}\,\bigr\}\;}$$

## The Root Condition (the defining conditions)

The polynomial $\pi(\zeta,\eta)$ satisfies the root condition at a given $\eta$
if and only if **both** of the following hold:

1. **(Spectral bound)** Every root $\zeta_i(\eta)$ of $\pi(\zeta,\eta)=0$ lies i
n the closed unit disk:
$$|\zeta_i(\eta)| \le 1 \quad \text{for all } i.$$

2. **(Simple on the unit circle)** Every root lying *on* the unit circle is simp
le (has algebraic multiplicity one):
$$|\zeta_i(\eta)| = 1 \;\Longrightarrow\; \zeta_i(\eta) \text{ is a simple root
of } \pi(\cdot,\eta).$$

Equivalently, writing the roots with their multiplicities $m_i$:

$$|\zeta_i(\eta)| < 1 \;\text{ when }\; m_i \ge 2, \qquad |\zeta_i(\eta)| \le 1
\;\text{ when }\; m_i = 1.$$

## Why these conditions

- A root $|\zeta_i| < 1$ gives a decaying mode $\zeta_i^n \to 0$, hence bounded
regardless of multiplicity.
- A root $|\zeta_i| = 1$ with multiplicity $m$ produces a mode growing like $n^{
m-1}\zeta_i^n$; this stays bounded **only** when $m = 1$.
- A root $|\zeta_i| > 1$ gives an exponentially growing mode, which is unbounded
.

Therefore boundedness of *all* numerical solutions of the test equation is equiv
alent to the two conditions above, which is precisely the membership test for $S
$.

## Boundary characterization (useful corollary)

The boundary $\partial S$ is contained in the **root-locus curve**

$$\partial S \subseteq \bigl\{\,\eta = \varrho(\zeta)/\sigma(\zeta) : |\zeta| =
1,\; \sigma(\zeta) \neq 0\,\bigr\},$$

since a root crosses the unit circle exactly when $\pi(\zeta,\eta)=0$ with $|\ze
ta|=1$, i.e. $\eta = \varrho(\zeta)/\sigma(\zeta)$ for $\zeta$ on the unit circl
e. (Points where $\sigma(\zeta)=0$ on $|\zeta|=1$ are handled as limiting cases.
)

## Summary

The stability region of the multistep method $(\varrho,\sigma)$ is

$$S = \bigl\{\eta \in \mathbb{C} : \text{all roots of } \varrho(\zeta)-\eta\sigm
a(\zeta) \text{ lie in } |\zeta|\le 1,\text{ and roots with }|\zeta|=1\text{ are
 simple}\bigr\}.$$
