# Periodic Solutions of the System

## Setup: polar coordinates

Let $x = r\cos\theta$, $y = r\sin\theta$, with $r^2 = x^2+y^2$ and $r>0$ (the or
igin is a singularity since the vector field contains $1/\sqrt{x^2+y^2}$).

The system is
$$\dot x = y + \tfrac{x}{r}(r^2-2), \qquad \dot y = -x + \tfrac{y}{r}(r^2-2).$$

**Radial equation.** Using $r\dot r = x\dot x + y\dot y$:
$$x\dot x + y\dot y = xy + \tfrac{x^2}{r}(r^2-2) - xy + \tfrac{y^2}{r}(r^2-2) =
\tfrac{r^2}{r}(r^2-2) = r(r^2-2).$$
Hence
$$\boxed{\dot r = r^2 - 2.}$$

**Angular equation.** Using $r^2\dot\theta = x\dot y - y\dot x$:
$$x\dot y - y\dot x = -x^2 + \tfrac{xy}{r}(r^2-2) - y^2 - \tfrac{xy}{r}(r^2-2) =
 -r^2.$$
Hence
$$\boxed{\dot\theta = -1.}$$

## Analysis of the radial ODE

The radial dynamics $\dot r = r^2 - 2$ is **autonomous and decoupled from $\thet
a$**. Its equilibria are $r = \sqrt{2}$ (taking $r>0$).

- If $r > \sqrt{2}$: $\dot r > 0$, so $r$ increases and blows up in finite time
($\int_{r_0}^{\infty}\frac{dr}{r^2-2}<\infty$). No periodic behavior.
- If $0 < r < \sqrt{2}$: $\dot r < 0$, so $r$ decreases and reaches $0$ in finit
e time ($\dot r \to -2$ as $r\to 0$). No periodic behavior.
- If $r = \sqrt{2}$: $\dot r = 0$, so $r$ is constant.

Since $\dot r$ depends only on $r$ (not on $\theta$), the only way to obtain a c
losed orbit is to have $r$ constant; any non-constant $r(t)$ is monotone and can
not return to its starting value. Thus the unique candidate is $r\equiv\sqrt{2}$
.

## The periodic orbit

At $r = \sqrt{2}$, $\dot r = 0$ and $\dot\theta = -1$, so
$$\theta(t) = \theta_0 - t, \qquad r(t) = \sqrt{2},$$
giving
$$x(t) = \sqrt{2}\cos(\theta_0 - t), \qquad y(t) = \sqrt{2}\sin(\theta_0 - t).$$

This traces the circle $x^2 + y^2 = 2$ counterclockwise (in the sense of decreas
ing $\theta$) with period $T = 2\pi$. It is a genuine periodic solution.

**Stability.** Since $\frac{d}{dr}(r^2-2)\big|_{r=\sqrt{2}} = 2\sqrt{2} > 0$, th
e equilibrium $r=\sqrt{2}$ is unstable: trajectories starting just inside spiral
 inward to the origin (reaching it in finite time), and those just outside escap
e to infinity in finite time. So the limit cycle is **unstable**.

## Conclusion

The system has exactly one periodic solution: the circular limit cycle
$$\boxed{x^2 + y^2 = 2,}$$
i.e. $x(t) = \sqrt{2}\cos(\theta_0 - t),\; y(t) = \sqrt{2}\sin(\theta_0 - t)$, w
ith period $2\pi$. It is an unstable limit cycle. No other periodic solutions ex
ist, because the decoupled radial equation $\dot r = r^2-2$ is monotone off the
equilibrium $r=\sqrt{2}$, precluding any closed orbit elsewhere.
