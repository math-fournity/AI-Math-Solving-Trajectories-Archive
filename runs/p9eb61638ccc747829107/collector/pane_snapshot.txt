## Proof

**Setup.** Let $n = 2016$, so we seek $(n-1)$-element subsets $A \subseteq X = \
{1,\dots,5\times10^6\}$ such that no non-empty subset of $A$ has sum divisible b
y $n$. The condition depends only on residues mod $n$, so we work in $\mathbb{Z}
_n$.

### Lemma (Characterization of maximal zero-sum free sequences in $\mathbb{Z}_n$
)

*A sequence $(a_1, \dots, a_{n-1})$ in $\mathbb{Z}_n$ is zero-sum free (no non-e
mpty subsequence sums to $0$) if and only if all $a_i$ equal some generator $g$
of $\mathbb{Z}_n$ (i.e., $\gcd(g,n)=1$).*

**Proof of $(\Leftarrow)$:** If all $a_i = g$ with $\gcd(g,n)=1$, any non-empty
subset of $k$ elements sums to $kg$. Since $\gcd(g,n)=1$, $kg \equiv 0 \pmod{n}$
 iff $n \mid k$. But $1 \le k \le n-1$, so $n \nmid k$. ∎

**Proof of $(\Rightarrow)$:** Suppose $(a_1,\dots,a_{n-1})$ is zero-sum free. De
fine partial sums $s_0 = 0$, $s_k = a_1 + \cdots + a_k$. If $s_i = s_j$ for $i <
 j$, then $a_{i+1}+\cdots+a_j \equiv 0$, a non-empty zero-sum subsequence — cont
radiction. So $s_0, \dots, s_{n-1}$ are $n$ distinct elements of $\mathbb{Z}_n$,
 hence $\{s_0,\dots,s_{n-1}\} = \mathbb{Z}_n$.

Now swap adjacent elements $a_k, a_{k+1}$ in the ordering. The new partial sums
are $s_0, \dots, s_{k-1}$, then $s_{k+1} - a_k$, then $s_{k+1}, \dots, s_{n-1}$.
 This new sequence is also zero-sum free (same multiset), so its partial sums mu
st again be $n$ distinct values. The new set replaces $s_k$ with $s_{k+1} - a_k$
; for all values to remain distinct, we need $s_{k+1} - a_k \notin \mathbb{Z}_n
\setminus \{s_k\}$, forcing $s_{k+1} - a_k = s_k$, i.e., $a_{k+1} = a_k$.

This holds for every $k = 1, \dots, n-2$, so $a_1 = a_2 = \cdots = a_{n-1} = g$.
 If $\gcd(g,n) = d > 1$, then $(n/d)$ copies of $g$ sum to $(n/d)g \equiv 0 \pmo
d{n}$, with $n/d \le n/2 \le n-1$ — a zero-sum subsequence, contradiction. So $d
=1$; $g$ is a generator. ∎
