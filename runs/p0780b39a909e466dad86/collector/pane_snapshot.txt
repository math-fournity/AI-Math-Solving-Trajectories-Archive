## Proof

**Setup.** The grid has $2n \times 2n = 100 \times 100$ cells, giving $(2n+1)^2
= 101^2 = 10201$ grid nodes. The set $S$ consists of all grid nodes except the f
our corners, so $|S| = 10197$.

**Key Construction.** I exhibit a single non-self-intersecting polyline that cov
ers every grid node, with both endpoints on the boundary.

Consider the **boustrophedon (snake) path**: Start at $(0,0)$, traverse row $y=0
$ left to right: $(0,0),(1,0),\ldots,(2n,0)$. Move up to $(2n,1)$, traverse row
$y=1$ right to left: $(2n,1),(2n-1,1),\ldots,(0,1)$. Move up to $(0,2)$, travers
e row $y=2$ left to right, and so on.

Since $2n+1$ is odd and $2n$ is even, the final row $y=2n$ is traversed left to
right, ending at $(2n, 2n)$.

**Verification of all constraints:**

1. **Covers all nodes:** The snake path visits every node $(x,y)$ with $x,y \in
\{0,1,\ldots,2n\}$ exactly once — it is a Hamiltonian path of the $(2n+1)\times(
2n+1)$ grid graph. Thus all $10201$ grid nodes are covered, hence all $10197$ no
des of $S$ are covered.

2. **Non-self-intersecting:** The path is a simple path in the grid graph — it n
ever revisits a node and never crosses itself, since consecutive segments share
only their common endpoint and non-consecutive segments are on different rows or
 non-overlapping portions of the same row.

3. **No two polylines share common points:** There is only one polyline, so this
 condition is vacuously satisfied.

4. **Contained in $[0,2n]^2$:** Every point on the path has coordinates in $[0,2
n]\times[0,2n]$. ✓

5. **Endpoints on the boundary:** The endpoints are $(0,0)$ and $(2n,2n)$, both
of which lie on the boundary of the square $[0,2n]^2$. ✓

**Conclusion.** This single polyline covers every node in $S$, leaving $0$ nodes
 uncovered. Since the number of uncovered nodes cannot be negative, $0$ is the m
inimum.

The minimum number of nodes in $S$ that must be left uncovered is $\boxed{0}$.
