## Proof

**Answer: Yes.**

Let $(\Omega, \mathcal{F}, \mu)$ be the probability space. Since $f_n$ does not
converge to $0$ almost everywhere, the set
$$A := \{x \in \Omega : f_n(x) \not\to 0\}$$
has positive measure. Note $A$ is measurable: since each $|f_n|$ is measurable a
nd nonnegative, $\{x : |f_n(x)| \to 0\} = \{x : \limsup_{n\to\infty}|f_n(x)| = 0
\}$, which is measurable, so $A$ is its complement.

For every $x \in A$, since $|f_n(x)| \not\to 0$ and $|f_n(x)| \geq 0$, we have
$$\limsup_{n\to\infty} |f_n(x)| > 0.$$

Define, for each integer $k \geq 1$,
$$A_k := \left\{x \in \Omega : \limsup_{n\to\infty}|f_n(x)| > \tfrac{1}{k}\right
\}.$$
Each $A_k$ is measurable (as a sublevel set of the measurable function $\limsup
|f_n|$).

**Claim:** $A = \bigcup_{k=1}^{\infty} A_k$.

- ($\supseteq$) If $x \in A_k$ for some $k$, then $\limsup |f_n(x)| > 1/k > 0$,
so $f_n(x) \not\to 0$, hence $x \in A$.
- ($\subseteq$) If $x \in A$, then $\delta := \limsup |f_n(x)| > 0$. Choose $k$
large enough that $1/k < \delta$; then $x \in A_k$.

Since $\mu(A) > 0$ and $A = \bigcup_{k=1}^\infty A_k$ is a countable union, ther
e exists some $k_0$ with $\mu(A_{k_0}) > 0$.

Set $\epsilon := \dfrac{1}{2k_0}$ and $E := A_{k_0}$. Then:
- $\mu(E) = \mu(A_{k_0}) > 0$, and
- for every $x \in E$, $\displaystyle\limsup_{n\to\infty}|f_n(x)| > \frac{1}{k_0
} = 2\epsilon$.

Thus such a set $E$ of positive measure exists. $\blacksquare$
