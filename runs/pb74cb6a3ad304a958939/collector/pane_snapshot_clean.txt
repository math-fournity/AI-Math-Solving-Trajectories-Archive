## Solution

We evaluate
$$L = \lim_{x\to 0^+}\frac{\Phi^{-1}(1-x)}{\Phi^{-1}(1-x/n)},\qquad n>0.$$

(The limit is necessarily from the right, since $\Phi^{-1}(1-x)$ is finite only
for $0<x<1$.)

**Key asymptotic.** For $t\to 0^+$, the normal tail (Mills ratio) gives
$$t = 1-\Phi(z) \sim \frac{\phi(z)}{z} = \frac{1}{\sqrt{2\pi}}\frac{e^{-z^2/2}}{
z}, \qquad z=\Phi^{-1}(1-t)\to+\infty.$$

Taking logarithms:
$$\ln t = -\frac{z^2}{2} - \ln z - \tfrac12\ln(2\pi) + o(1).$$

Hence
$$z^2 = -2\ln t - 2\ln z - \ln(2\pi) + o(1).$$

Since $\ln z = O(\ln\ln(1/t)) = o(\ln(1/t))$, we obtain
$$z^2 = -2\ln t\bigl(1 + o(1)\bigr),\qquad\text{i.e.}\qquad \Phi^{-1}(1-t) \sim
\sqrt{-2\ln t}\quad(t\to 0^+). \tag{$*$}$$

**Applying ($*$).** Set $z_1 = \Phi^{-1}(1-x)$ and $z_2 = \Phi^{-1}(1-x/n)$. As
$x\to 0^+$:
$$z_1 \sim \sqrt{-2\ln x}, \qquad z_2 \sim \sqrt{-2\ln(x/n)} = \sqrt{-2\ln x + 2
\ln n}.$$

Therefore
$$\frac{z_1}{z_2} \sim \frac{\sqrt{-2\ln x}}{\sqrt{-2\ln x + 2\ln n}} = \frac{1}
{\sqrt{1 + \dfrac{\ln n}{-\ln x}}}.$$

As $x\to 0^+$, $-\ln x\to+\infty$, so $\dfrac{\ln n}{-\ln x}\to 0$, giving
$$\frac{z_1}{z_2}\to \frac{1}{\sqrt{1+0}} = 1.$$

**Conclusion.**

$$\boxed{\lim_{x\to 0}\frac{\Phi^{-1}(1-x)}{\Phi^{-1}(1-x/n)} = 1.}$$

### PROOF COMPLETE
