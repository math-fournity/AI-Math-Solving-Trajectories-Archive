## Proof

**Definitions.** A *pointed invertible unary system* is a tuple $(A, q, f)$ wher
e $A$ is a set, $q \in A$ is a distinguished point, and $f : A \to A$ is a bijec
tion. A *morphism* $h : (A, q, f) \to (B, r, g)$ is a function $h : A \to B$ sat
isfying
$$h(q) = r \quad\text{and}\quad h \circ f = g \circ h.$$
The integers $(\mathbb{Z}, 0, s)$ with $s(n) = n+1$ form such a system since $s$
 is a bijection.

**Claim.** $(\mathbb{Z}, 0, s)$ is the initial object of this category.

**Construction of the unique morphism.** Let $(A, q, f)$ be any pointed invertib
le unary system. Since $f$ is a bijection, the iterates $f^{n}$ are defined for
every $n \in \mathbb{Z}$ (with $f^{0} = \mathrm{id}$, $f^{n+1} = f \circ f^{n}$,
 and $f^{-n} = (f^{-1})^{n}$). Define
$$h : \mathbb{Z} \to A, \qquad h(n) := f^{n}(q).$$

**$h$ is a morphism.**
- *Point preservation:* $h(0) = f^{0}(q) = q$. ✓
- *Equivariance:* For every $n \in \mathbb{Z}$,
$$h(s(n)) = h(n+1) = f^{n+1}(q) = f\bigl(f^{n}(q)\bigr) = f(h(n)),$$
so $h \circ s = f \circ h$. ✓

**Uniqueness.** Let $h' : (\mathbb{Z}, 0, s) \to (A, q, f)$ be any morphism. The
n $h'(0) = q$, and the equivariance condition gives $h'(n+1) = f(h'(n))$ for all
 $n \in \mathbb{Z}$.

- *Non-negative integers:* By induction, $h'(n) = f^{n}(q) = h(n)$ for all $n \g
eq 0$.
- *Negative integers:* From $h'(n) = f(h'(n-1))$ and bijectivity of $f$, we obta
in $h'(n-1) = f^{-1}(h'(n))$. Starting from $h'(0) = q$ and iterating, $h'(-n) =
 f^{-n}(q) = h(-n)$ for all $n \geq 0$.

Hence $h' = h$, proving uniqueness.

**Conclusion.** For every pointed invertible unary system $(A, q, f)$ there exis
ts a unique morphism $(\mathbb{Z}, 0, s) \to (A, q, f)$. Therefore $(\mathbb{Z},
 0, s)$ **is** the initial object of the category of pointed invertible unary sy
stems. $\blacksquare$
