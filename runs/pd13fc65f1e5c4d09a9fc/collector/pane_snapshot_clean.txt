## Proof

**Step 1: Degree analysis.** Let deg(P) = n > 1, deg(Q) = m. Then deg(P(Q(x))) =
 nm, deg(P(P(x))) = n², deg(P(x)) = n. Since n² > n for n > 1, the right side ha
s degree n², so nm = n², giving **m = n**: Q has the same degree as P.

**Step 2: Degree ≥ 3 is impossible.** Write P(x) = a xⁿ + b xⁿ⁻¹ + c xⁿ⁻² + ⋯ an
d Q(x) = a' xⁿ + b' xⁿ⁻¹ + c' xⁿ⁻² + ⋯. I claim the top n+1 coefficients of P(Q(
x)) (from degree n² down to n²−n) uniquely determine all n+1 coefficients of Q.

**Key lemma:** The coefficient of x^{n²−k} in P(R(x)) = a·R(x)ⁿ + ⋯ is **linear
in the (k+1)-th coefficient** r_{n−k} of R, with coefficient n·aⁿ ≠ 0 (for k < n
, only the a·Rⁿ term contributes; the term n·r_{n−k}·a^{n−1}·x^{n²−k} arises fro
m choosing r_{n−k}x^{n−k} once among n factors). This triangular structure means
 the system has a **unique solution**.

Since Q = P trivially satisfies "P(Q(x))'s top n+1 coefficients equal P(P(x))'s
top n+1 coefficients," the unique solution is **Q = P**. But then the functional
 equation gives P(P(x)) = P(P(x)) + P(x), i.e., P(x) ≡ 0, contradicting deg(P) ≥
 3. **No solutions exist for degree ≥ 3.**

**Step 3: Degree 2 solution.** Let P(x) = ax² + bx + c (a ≠ 0), Q(x) = px² + qx
+ r.

Computing P(P(x)) + P(x) and P(Q(x)) and matching coefficients:

- **x⁴:** ap² = a³ → p = ±a
- **x³:** 2apq = 2a²b → q = ±b (same sign as p/a)
- **x², x¹, x⁰:** yield three equations. Both sign cases (p = a, q = b) and (p =
 −a, q = −b) reduce to the **same constraint**:

$$\frac{1+2b}{4a} = 0 \implies \boxed{b = -\tfrac{1}{2}}$$

(The remaining coefficients determine r and c in terms of a, leaving a as a free
 parameter.)

**Step 4: Compute P(−2).** With b = −1/2:

$$P(2) = 4a + 2b + c = 4a - 1 + c = 10$$
$$P(-2) = 4a - 2b + c = 4a + 1 + c$$

Subtracting: P(−2) − P(2) = −4b = −4(−1/2) = 2, so:

$$P(-2) = 10 + 2 = \boxed{12}$$

**Step 5: Verification.** Take a = 1: P(x) = x² − x/2 + 7 (since c = 11 − 4 = 7)
, Q(x) = x² − x/2 + 15/2. Set u = P(x) = x² − x/2 + 7, so Q(x) = u + 1/2.

- P(Q(x)) = (u + 1/2)² − (u + 1/2)/2 + 7 = u² + u + 1/4 − u/2 − 1/4 + 7 = u² + u
/2 + 7
- P(P(x)) + P(x) = (u² − u/2 + 7) + u = u² + u/2 + 7 ✓

P(2) = 4 − 1 + 7 = 10 ✓, P(−2) = 4 + 1 + 7 = 12 ✓.
