uses at least two colors" is equivalent to: no monochromatic path connects two n
onadjacent vertices. This means every monochromatic connected component (in the
subgraph formed by edges of a single color) must be a **clique** in the triangul
ar grid — i.e., every pair of vertices in the component is adjacent. Since the t
riangular grid has maximum clique size 3, each monochromatic component is a sing

**Lower bound: N ≥ 3.** Consider any vertex v, which has 6 incident edges leadin
g to 6 neighbors in cyclic order. If two edges from v share a color c, say to ne
ighbors a and b, then a–v–b is a monochromatic path (color c) from a to b. For t
his to be valid, a and b must be adjacent, meaning they are **consecutive** neig

nt pair (the first and third are at 120° apart). So each color appears on **at m

per color, we need **at least 3 colors**.

**Upper bound: N = 3 suffices.** We construct a valid 3-coloring.

*Setup.* Place the triangular grid on the lattice with vertices at positions (i,
 j) for i, j ∈ ℤ, using basis vectors (1, 0) and (1/2, √3/2). The three edge typ

- Horizontal: (i,j)–(i+1,j)
- Up-right: (i,j)–(i,j+1)
- Diagonal: (i+1,j)–(i,j+1)

*Triangle decomposition.* The **up triangles** T(i,j) with vertices (i,j), (i+1,
j), (i,j+1) partition all edges: every edge belongs to exactly one up triangle.
(Each horizontal edge (i,j)–(i+1,j) belongs to T(i,j); each up-right edge (i,j)–
(i,j+1) belongs to T(i,j); each diagonal edge (i+1,j)–(i,j+1) belongs to T(i,j).
 No other up triangle shares any of these edges.)

*Coloring.* Assign each up triangle T(i,j) the color f(i,j) = (i + 2j) mod 3, an
d color all three edges of T(i,j) with f(i,j).

*Verification that triangles sharing a vertex get distinct colors.* The three up

- f(i,j) = (i + 2j) mod 3
- f(i−1,j) = (i − 1 + 2j) mod 3 = f(i,j) − 1 mod 3
- f(i,j−1) = (i + 2j − 2) mod 3 = f(i,j) − 2 mod 3

These are three distinct values modulo 3. ✓
