## Proof

Let $c$ denote the vector space (over $\mathbb{R}$, or analogously $\mathbb{C}$)
 of all convergent real sequences, and $c_0 \subset c$ the subspace of sequences
 converging to $0$.

**Define the limit functional.** Consider the map
$$L : c \to \mathbb{R}, \qquad L\big((x_n)_{n\ge1}\big) = \lim_{n\to\infty} x_n.
$$
This is well-defined since every element of $c$ converges. It is linear: for con
vergent sequences $(x_n), (y_n)$ and scalars $\alpha, \beta$,
$$L(\alpha x + \beta y) = \lim_{n\to\infty}(\alpha x_n + \beta y_n) = \alpha\lim
 x_n + \beta\lim y_n = \alpha L(x) + \beta L(y),$$
using linearity of the limit. Hence $L$ is a linear map (in fact a continuous li
near functional on $c$ with the sup-norm, though continuity is not needed for th
e dimension count).

**Identify the kernel.** By definition,
$$\ker L = \{(x_n) \in c : L((x_n)) = 0\} = \{(x_n) \in c : \lim_{n\to\infty} x_
n = 0\} = c_0.$$

**Identify the image.** $L$ is surjective: for any $\ell \in \mathbb{R}$, the co
nstant sequence $(\ell, \ell, \ell, \dots)$ lies in $c$ and has limit $\ell$. Th
us $\operatorname{im} L = \mathbb{R}$.

**Apply the first isomorphism theorem.** For a linear map, the quotient $c/\ker
L$ is isomorphic to $\operatorname{im} L$. Therefore
$$c / c_0 = c / \ker L \cong \operatorname{im} L = \mathbb{R}.$$

**Conclusion.** Since $c/c_0 \cong \mathbb{R}$ as a vector space,
$$\dim\, c/c_0 = \dim\, \mathbb{R} = 1.$$

The codimension of $c_0$ in $c$ is **1**. Geometrically, every convergent sequen
ce decomposes uniquely as its limit (a constant sequence, representing the coset
) plus a null sequence, so a single "limit direction" measures the gap between $
c$ and $c_0$.
