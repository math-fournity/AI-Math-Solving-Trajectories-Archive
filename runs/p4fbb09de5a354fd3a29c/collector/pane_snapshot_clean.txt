**Problem.** Find all $f:\mathbb{R}\to\mathbb{R}$ such that $f\!\left(x^{2}+f(y)
\right)=y+\bigl(f(x)\bigr)^{2}$ for all $x,y\in\mathbb{R}$.

**Claim.** The unique solution is $f(x)=x$.

---

### Step 1. Surjectivity

Fix any $x_0\in\mathbb{R}$. As $y$ ranges over $\mathbb{R}$, the right-hand side
 $y+f(x_0)^2$ ranges over all of $\mathbb{R}$, so $\{f(x_0^2+f(y)):y\in\mathbb{R
}\}=\mathbb{R}$. Hence $f$ is **surjective**.

### Step 2. A key involution relation; injectivity

Set $x=0$: $f(f(y))=y+f(0)^2$. Let $c:=f(0)^2$, so
$$f(f(y))=y+c \qquad\text{for all }y. \tag{1}$$
If $f(a)=f(b)$, then applying $f$ gives $a+c=b+c$, so $a=b$. Thus $f$ is **injec
tive**, hence **bijective**.

Applying $f$ to (1): $f(y+c)=f(y)+c$ for all $y$. $\tag{2}$

### Step 3. Relating $f(x^2)$ and $f(x)^2$

Since $f$ is surjective, pick $u$ with $f(u)=0$. Setting $y=u$:
$$f(x^2)=u+f(x)^2 \qquad\text{for all }x. \tag{3}$$
Since $x^2=(-x)^2$, (3) gives $f(x)^2=f(-x)^2$, so $f(-x)=\pm f(x)$. By injectiv
ity, $f(-x)=f(x)\Rightarrow x=0$; hence
$$f(-x)=-f(x)\quad(x\ne 0). \tag{4}$$
Setting $x=0$ in (3): $f(0)=u+f(0)^2=u+c$, so $u=f(0)-c$.

### Step 4. Deriving a Cauchy-type relation

Substitute $y\mapsto f(y)$ into the original equation:
$$f\!\bigl(x^2+f(f(y))\bigr)=f(y)+f(x)^2.$$
Using (1), $f(f(y))=y+c$, so $f(x^2+y+c)=f(y)+f(x)^2$. By (2) with $z=x^2+y$: $f
(x^2+y+c)=f(x^2+y)+c$. Therefore
$$f(x^2+y)=f(y)+f(x)^2-c\qquad\text{for all }x,y. \tag{5}$$
For $t\ge 0$, write $t=x^2$; by (3), $f(x)^2=f(t)-u=f(t)-(f(0)-c)$. Substituting
 into (5):
$$f(t+y)=f(y)+f(t)-f(0)\qquad(t\ge 0,\;y\in\mathbb{R}). \tag{6}$$

### Step 5. $f(0)=0$

Set $y=-t$ (with $t>0$) in (6): $f(0)=f(t)+f(-t)-f(0)$. By (4), $f(-t)=-f(t)$, s
o $f(0)=0-f(0)$, giving $\boxed{f(0)=0}$. Consequently $c=0$ and $u=0$.

Now (1) becomes $f(f(y))=y$ (involution), (3) becomes $f(x^2)=f(x)^2$, and (6) b
ecomes
$$f(t+y)=f(t)+f(y)\qquad(t\ge 0,\;y\in\mathbb{R}). \tag{7}$$

### Step 6. Full additivity

For $t<0$, we have $-t>0$. Apply (7) with $-t$ and $t+y$:
$$f(y)=f(-t)+f(t+y).$$
By (4) (now valid everywhere since $f(0)=0$), $f(-t)=-f(t)$, so $f(t+y)=f(t)+f(y
)$. Together with (7):
$$f(a+b)=f(a)+f(b)\qquad\text{for all }a,b\in\mathbb{R}. \tag{8}$$

### Step 7. Multiplicativity

Using (8) and $f(x^2)=f(x)^2$: expand $f\!\bigl((x+y)^2\bigr)$ two ways.
$$f(x+y)^2=\bigl(f(x)+f(y)\bigr)^2=f(x)^2+2f(x)f(y)+f(y)^2,$$
$$f(x^2+2xy+y^2)=f(x^2)+f(2xy)+f(y^2)=f(x)^2+2f(xy)+f(y)^2.$$
Equating: $f(x)f(y)=f(xy)$ for all $x,y$. $\tag{9}$

### Step 8. $f$ is the identity

From (9) with $x=y=1$: $f(1)^2=f(1)$, so $f(1)\in\{0,1\}$. If $f(1)=0$, then $f(
x)=f(x\cdot1)=f(x)f(1)=0$ for all $x$, contradicting bijectivity. Thus $f(1)=1$.

By additivity, $f(q)=q$ for all $q\in\mathbb{Q}$. For $r>0$, write $r=s^2$; then
 $f(r)=f(s)^2\ge 0$, and $f(r)=0\Rightarrow r=0$ by injectivity, so $f$ **preser
ves order**: $a<b\Rightarrow f(a)<f(b)$. An order-preserving additive map with $
f(1)=1$ is the identity: for any real $r$ and rationals $p<r<q$, $p=f(p)<f(r)<f(
q)=q$; squeezing gives $f(r)=r$.

$f(x)=x$: $f(x^2+f(y))=f(x^2+y)=x^2+y=y+f(x)^2$. ✓
