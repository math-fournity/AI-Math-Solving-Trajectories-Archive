# Problem

In a remote high-security server farm, a technician must monitor a $4 \times 4$ grid of 16 server nodes. To ensure security, the technician deploys $k$ digital security patches. These patches are programmed with the following rigid protocols:

i) Each patch must be applied to exactly 2 server nodes.
ii) Every single server node in the grid must be protected by at least one patch.
iii) The system must be "minimally redundant": if any single patch is deactivated, there must be at least one server node that becomes completely unprotected.

Patches are allowed to overlap, meaning a single server node can be covered by multiple patches, provided that the removal of any one patch exposes a node.

Find the maximum possible number of patches $k$ that can be active in this grid simultaneously.
