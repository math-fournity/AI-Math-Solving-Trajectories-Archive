**Claim.** Yes, there exists a bijection between the set of all infinite subsets
 of $\mathbb{N}$ and the set of all strictly increasing functions $\mathbb{N}\to
\mathbb{N}$.

**Proof.**

Let
$$A = \{S\subseteq\mathbb{N} : S \text{ is infinite}\}, \qquad B = \{f:\mathbb{N
}\to\mathbb{N} : f \text{ is strictly increasing}\}.$$

We define two maps and show they are mutual inverses.

**Map $\Phi:A\to B$.** Let $S\in A$. Since $S$ is an infinite subset of $\mathbb
{N}$, it is well-ordered by the usual order, so it can be enumerated uniquely in
 increasing order:
$$S = \{s_0 < s_1 < s_2 < \cdots\}, \qquad s_n\in S,\; s_n < s_{n+1}\;\forall n.
$$
Define $\Phi(S):\mathbb{N}\to\mathbb{N}$ by $\Phi(S)(n)=s_n$. Since $s_0<s_1<s_2
<\cdots$, the function $\Phi(S)$ is strictly increasing, hence $\Phi(S)\in B$.

**Map $\Psi:B\to A$.** Let $f\in B$. Define
$$\Psi(f) = f(\mathbb{N}) = \{f(n):n\in\mathbb{N}\}.$$
Since $f$ is strictly increasing, the values $f(0),f(1),f(2),\ldots$ are all dis
tinct, so $f(\mathbb{N})$ is an infinite subset of $\mathbb{N}$. Hence $\Psi(f)\
in A$.

**$\Psi\circ\Phi = \mathrm{id}_A$.** Let $S\in A$ with enumeration $S=\{s_0<s_1<
\cdots\}$. Then $\Phi(S)(n)=s_n$, so
$$(\Psi\circ\Phi)(S)=\Phi(S)(\mathbb{N})=\{s_n:n\in\mathbb{N}\}=S.$$

**$\Phi\circ\Psi = \mathrm{id}_B$.** Let $f\in B$ and set $T=\Psi(f)=f(\mathbb{N
})$. Enumerate $T$ increasingly as $T=\{t_0<t_1<t_2<\cdots\}$. Since $f$ is stri
ctly increasing, $f(0)<f(1)<f(2)<\cdots$ is itself an increasing enumeration of
$T$. By uniqueness of the increasing enumeration, $t_n=f(n)$ for every $n$. Ther
efore
$$(\Phi\circ\Psi)(f)(n)=t_n=f(n)\quad\forall n,$$
so $(\Phi\circ\Psi)(f)=f$.

Since $\Phi$ and $\Psi$ are mutual inverses, $\Phi:A\to B$ is a bijection. $\bla
