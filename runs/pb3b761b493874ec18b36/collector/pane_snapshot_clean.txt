## Answer

**No**, we cannot conclude that $A = B$.

### Justification

Recall the standard identity for orthogonal complements: for any subsets $A, B$
of a Hilbert space,
$$(A + B)^\perp = A^\perp \cap B^\perp.$$

The hypothesis $A^\perp \cap B^\perp = \{0\}$ is therefore equivalent to
$$(A + B)^\perp = \{0\},$$
which (using $(A+B)^\perp = \overline{A+B}^{\,\perp}$ and the fact that $M^\perp
 = \{0\}$ iff $\overline{M} = H$ for any subspace $M$) is equivalent to
$$\overline{A + B} = H.$$

So the condition says only that the **sum** $A + B$ is **dense** in $H$. This is
 a far weaker statement than $A = B$.

### Counterexample

Take $H = \mathbb{R}^2$ with the usual inner product. Let
$$A = \{(x, 0) : x \in \mathbb{R}\} = \operatorname{span}\{e_1\}, \qquad B = \{(
t, t) : t \in \mathbb{R}\} = \operatorname{span}\{e_1 + e_2\}.$$

Then
$$A^\perp = \{(0, y) : y \in \mathbb{R}\} = \operatorname{span}\{e_2\}, \qquad B
^\perp = \{(s, -s) : s \in \mathbb{R}\} = \operatorname{span}\{e_1 - e_2\}.$$

A vector in $A^\perp \cap B^\perp$ must satisfy $(0, y) = (s, -s)$, forcing $s =
 0$ and $y = 0$. Hence
$$A^\perp \cap B^\perp = \{0\}.$$

Yet $A \neq B$, since $(1, 0) \in A$ but $(1, 0) \notin B$.

### Conclusion

The condition $A^\perp \cap B^\perp = \{0\}$ is equivalent to $\overline{A + B}
= H$ (i.e., $A + B$ is dense in $H$), which does **not** imply $A = B$. The coun
terexample above in $\mathbb{R}^2$ gives two distinct closed subspaces satisfyin
g the hypothesis.
