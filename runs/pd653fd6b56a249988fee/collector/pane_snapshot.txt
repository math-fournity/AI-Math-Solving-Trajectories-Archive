## Step 1: Determine $f(\emptyset)$

Setting $B = \emptyset$: $|A \cap f(\emptyset)| = |\emptyset \cap f(A)| = 0$ for
 all $A$. Taking $A = \{i\}$ gives $i \notin f(\emptyset)$ for all $i$, so $f(\e
mptyset) = \emptyset$.

## Step 2: $f$ is determined by its values on singletons

Setting $A = \{i\}$: $|\{i\} \cap f(B)| = |B \cap f(\{i\})|$, i.e., $\mathbf{1}[
i \in f(B)] = |B \cap f(\{i\})|$.

Since the left side is 0 or 1, $|B \cap f(\{i\})| \in \{0,1\}$ for all $B$. If $
f(\{i\})$ had two elements $j_1, j_2$, taking $B = \{j_1, j_2\}$ gives $|B \cap
f(\{i\})| = 2$, contradiction. So $|f(\{i\})| \leq 1$.

Define a **partial function** $\sigma: [n] \rightharpoonup [n]$: if $f(\{i\}) =
\{j\}$, set $\sigma(i) = j$; if $f(\{i\}) = \emptyset$, $\sigma(i)$ is undefined
. Then:
$$i \in f(B) \iff \sigma(i) \in B \quad \text{(for all } B \subseteq [n]\text{)}
$$

So $f(B) = \{i \in [n] : \sigma(i) \in B\}$, and $f$ is completely determined by
 $\sigma$.

## Step 3: The symmetry condition forces $\sigma$ to be a partial involution

The general condition $|A \cap f(B)| = |B \cap f(A)|$ becomes:
$$\sum_{i \in A} \mathbf{1}[\sigma(i) \in B] = \sum_{j \in B} \mathbf{1}[\sigma(
j) \in A] \quad \text{for all } A, B.$$

Take $A = \{i\}, B = \{k\}$: $\mathbf{1}[\sigma(i) = k] = \mathbf{1}[\sigma(k) =
 i]$. This means:
- $\sigma(i) = k \iff \sigma(k) = i$ (symmetry),
- $\sigma(i)$ is defined $\iff$ $\sigma(\sigma(i))$ is defined and equals $i$.

So $\sigma$ is a **partial involution** on $[n]$: a partial function that is its
 own inverse where defined. Conversely, any partial involution satisfies the sym
metry condition (the map $i \leftrightarrow \sigma(i)$ is a bijection between $\
{i \in A : \sigma(i) \in B\}$ and $\{j \in B : \sigma(j) \in A\}$).

## Step 4: Count partial involutions

A partial involution on $[n]$ is specified by choosing a support $S \subseteq [n
]$ of size $k$, then choosing an involution on $S$. The number of involutions on
 $k$ elements is the telephone number:
$$T(k) = \sum_{m=0}^{\lfloor k/2 \rfloor} \frac{k!}{m!\, 2^m\, (k-2m)!}$$

Computing: $T(0)=1,\; T(1)=1,\; T(2)=2,\; T(3)=4,\; T(4)=10$.

Therefore $N(n) = \sum_{k=0}^{n} \binom{n}{k} T(k)$.
