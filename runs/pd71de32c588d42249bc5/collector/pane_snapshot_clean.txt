$$\left(a - \frac{x^2}{a}\right) + \left(b - \frac{x^2}{b}\right) = 0$$

$$(a + b) - x^2\!\left(\frac{1}{a} + \frac{1}{b}\right) = 0$$

$$(a+b)\left(1 - \frac{x^2}{ab}\right) = 0$$

$$x^2 = ab = \sqrt{(R^2 - x^2)(r^2 - x^2)}$$

$$x^4 = (R^2 - x^2)(r^2 - x^2) = R^2 r^2 - (R^2 + r^2)x^2 + x^4$$

$$x^2 = \frac{R^2 r^2}{R^2 + r^2}$$
