## 解答

设 $a = \arctan\frac{1}{m},\ b = \arctan\frac{1}{n},\ c = \arctan\frac{1}{p}$，
则 $a+b+c = \frac{\pi}{4}$，且 $a,b,c > 0$。

### 第一步：转化为代数方程

对 $a+b+c = \frac{\pi}{4}$ 两边取正切，利用三角和角公式：

$$\tan(a+b+c) = \frac{\tan a + \tan b + \tan c - \tan a\tan b\tan c}{1 - (\tan a
\tan b + \tan b\tan c + \tan a\tan c)} = 1.$$

令 $x=\frac1m,\ y=\frac1n,\ z=\frac1p$，交叉相乘得：

$$x+y+z+xy+yz+xz - xyz = 1.$$

两边乘以 $mnp$：

$$np + mp + mn + p + n + m - 1 = mnp,$$

即

$$mnp - mn - mp - np - m - n - p + 1 = 0. \tag{$\star$}$$

### 第二步：确定变量的范围

由于 $a,b,c>0$ 且 $a+b+c=\frac\pi4$，每个角都小于 $\frac\pi4$，故 $\frac1m,\frac
1n,\frac1p < 1$，即 $m,n,p \ge 2$（$m=1$ 会令 $a=\frac\pi4$，迫使 $b+c=0$，矛盾
）。

不妨设 $m \le n \le p$，则 $a \ge b \ge c$，$a \ge \frac{\pi}{12}$，于是

$$\frac1m = \tan a \ge \tan\frac{\pi}{12} = 2-\sqrt3 \approx 0.268,$$

故 $m \le 3$. 因此 $m \in \{2, 3\}$.

### 第三步：按 $m$ 分情况求解

**情形 1：$m = 2$.**

$b+c = \frac\pi4 - \arctan\frac12$，取正切：

$$\tan(b+c) = \frac{1 - \frac12}{1 + \frac12} = \frac13.$$

又 $\tan(b+c) = \frac{\frac1n+\frac1p}{1-\frac1{np}} = \frac{n+p}{np-1}$，故

$$\frac{n+p}{np-1} = \frac13 \implies np - 3n - 3p = 1 \implies (n-3)(p-3) = 10.
$$

在 $n \le p,\ n \ge 2$ 下，正因数对 $(n-3, p-3)$（须同为正，否则 $n,p<3$ 时乘积
至多为 $1$）为：

| $n-3$ | $p-3$ | $n$ | $p$ |
|---|---|---|---|
| $1$ | $10$ | $4$ | $13$ |
| $2$ | $5$ | $5$ | $8$ |

得解 $\{2,4,13\}$、$\{2,5,8\}$。

**情形 2：$m = 3$.**

$$\tan(b+c) = \frac{1-\frac13}{1+\frac13} = \frac12,$$

故 $\frac{n+p}{np-1} = \frac12$，即 $np - 2n - 2p = 1$，亦即

$$(n-2)(p-2) = 5.$$

在 $n \le p,\ n \ge 3$ 下，唯一正因数对 $(n-2,p-2) = (1,5)$，得 $n=3,\ p=7$.

得解 $\{3,3,7\}$。

### 第四步：验证

- $\{2,4,13\}$：$\tan(\arctan\frac12+\arctan\frac14)=\frac{6}{7}$，$\frac{6/7+1/
13}{1-6/91}=\frac{85/91}{85/91}=1$. ✓
- $\{2,5,8\}$：$\tan(\arctan\frac12+\arctan\frac15)=\frac79$，$\frac{7/9+1/8}{1-
7/72}=\frac{65/72}{65/72}=1$. ✓
- $\{3,3,7\}$：$\tan(2\arctan\frac13)=\frac34$，$\frac{3/4+1/7}{1-3/28}=\frac{25
/28}{25/28}=1$. ✓

三组解均满足原方程，且各角之和落在 $(0,\frac\pi4]$ 内，正切值 $=1$ 确实对应 $\fr
ac\pi4$。

### 结论

方程的正整数解（无序集合 $\{m,n,p\}$）共有 **3** 组：

$$\{2,4,13\},\quad \{2,5,8\},\quad \{3,3,7\}.$$

**答案为 $3$。**
