# Problem

In a futuristic data center, an administrator manages two square server arrays: one measuring $10 \times 10$ and another $11 \times 11$. Each individual server node in these $n \times n$ grids currently stores a specific integer value representing its background noise level.

The administrator can perform a "Resonance Pulse" on any specific server node. When a node is targeted, its own noise level and the noise levels of every other server located in the same row and the same column increase by exactly $1$ unit. This means for every pulse, $2n-1$ servers have their values incremented.

Let $N(n)$ represent the maximum guaranteed number of servers that can be set to an even noise level simultaneously, regardless of what the initial noise levels were, using a finite number of pulses. 

Calculate the value of $N(10) + N(11)$.
