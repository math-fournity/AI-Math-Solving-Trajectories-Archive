**Answer: Yes.** Every weak*-continuous linear functional on $X^*$ is an evaluat
ion functional $\Phi_x$ for some $x \in X$.

**Proof.**

The weak* topology on $X^*$ is the coarsest topology making every evaluation map
 $\Phi_x : X^* \to \mathbb{C}$, $\Phi_x(f) = f(x)$, continuous. We must show the
 converse: if $\Phi : X^* \to \mathbb{C}$ is linear and weak*-continuous, then $
\Phi = \Phi_x$ for some $x \in X$.

**Step 1. Extract a finite set of "control" points.**

Since $\Phi$ is weak*-continuous and linear, $\Phi$ is continuous at $0$, so the
 set
$$U := \{f \in X^* : |\Phi(f)| < 1\}$$
is a weak*-open neighborhood of $0$. By definition of the weak* topology, $U$ co
ntains a basic weak*-open neighborhood of $0$, which has the form
$$V := \{f \in X^* : |f(x_i)| < \varepsilon,\ i = 1,\dots,n\}$$
for some $x_1,\dots,x_n \in X$ and some $\varepsilon > 0$. Thus
$$V \subseteq U.$$

**Step 2. Show $\ker T \subseteq \ker \Phi$, where $T : X^* \to \mathbb{C}^n$, $
T(f) = (f(x_1),\dots,f(x_n))$.**

Suppose $f \in \ker T$, i.e. $f(x_i) = 0$ for all $i$. Then $f \in V$ (since $|f
(x_i)| = 0 < \varepsilon$), and more generally $\lambda f \in V$ for every $\lam
bda \in \mathbb{C}$, since $(\lambda f)(x_i) = 0$. Hence $\lambda f \in U$ for e
very $\lambda$, meaning $|\Phi(\lambda f)| = |\lambda|\,|\Phi(f)| < 1$ for all $
\lambda$. Letting $|\lambda| \to \infty$ forces $\Phi(f) = 0$. So $f \in \ker \P
hi$, giving
$$\ker T \subseteq \ker \Phi.$$

**Step 3. Factor $\Phi$ through $T$.**

The inclusion $\ker T \subseteq \ker \Phi$ allows us to define a map $\psi : \op
eratorname{im}(T) \to \mathbb{C}$ by
$$\psi(T(f)) := \Phi(f).$$
This is well-defined: if $T(f) = T(g)$, then $f - g \in \ker T \subseteq \ker \P
hi$, so $\Phi(f) = \Phi(g)$. Linearity of $\psi$ follows from linearity of $\Phi
$ and $T$. Extend $\psi$ (arbitrarily) to a linear functional on all of $\mathbb
{C}^n$. Every linear functional on $\mathbb{C}^n$ has the form $(z_1,\dots,z_n)
\mapsto \sum_{i=1}^n a_i z_i$ for some scalars $a_i \in \mathbb{C}$. Therefore
$$\Phi(f) = \psi(T(f)) = \sum_{i=1}^n a_i\, f(x_i) = f\!\left(\sum_{i=1}^n a_i x
_i\right).$$

**Step 4. Identify $x$.**

Set $x := \sum_{i=1}^n a_i x_i \in X$ (a finite linear combination, so it lies i
n $X$). Then for every $f \in X^*$,
$$\Phi(f) = f(x) = \Phi_x(f).$$

Hence $\Phi = \Phi_x$ with $x \in X$. $\blacksquare$

**Remark.** The argument uses only that $X$ is a vector space (closed under fini
te linear combinations) and the definition of the weak* topology via finite inte
rsections of subbasic sets. No completeness, norm, or reflexivity of $X$ is requ
ired — the result holds for any normed (or even topological vector) space $X$.
