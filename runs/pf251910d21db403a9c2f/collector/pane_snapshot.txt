## Proof

**Step 1: The process is a martingale.**

Let $p = \alpha X_n + \beta(1-X_n)$ and $q = (1-\alpha)X_n + (1-\beta)(1-X_n)$.
Note $p + q = 1$.

Given $X_n = x$, the two possible values of $X_{n+1}$ are $\frac{\alpha x}{p}$ (
with probability $p$) and $\frac{(1-\alpha)x}{q}$ (with probability $q$). Comput
ing the conditional expectation:

$$E[X_{n+1} \mid X_n = x] = p \cdot \frac{\alpha x}{p} + q \cdot \frac{(1-\alpha
)x}{q} = \alpha x + (1-\alpha)x = x.$$

So $(X_n)$ is a **martingale**.

**Step 2: The process converges almost surely.**

Since $X_n \in [0,1]$ is a bounded martingale, by the Martingale Convergence The
orem, $X_n \to X_\infty$ a.s. for some random variable $X_\infty \in [0,1]$, and
 $E[X_\infty] = E[X_0] = 0.01$.

**Step 3: The limit is in $\{0, 1\}$ (assuming $\alpha \neq \beta$).**

Define the log-odds $L_n = \log\frac{X_n}{1 - X_n}$. When $X_{n+1} = \frac{\alph
a X_n}{\alpha X_n + \beta(1-X_n)}$, we get $1 - X_{n+1} = \frac{\beta(1-X_n)}{\a
lpha X_n + \beta(1-X_n)}$, so:

$$\frac{X_{n+1}}{1-X_{n+1}} = \frac{\alpha}{\beta}\cdot\frac{X_n}{1-X_n}, \quad
\text{i.e., } L_{n+1} = L_n + \log\tfrac{\alpha}{\beta}.$$

Similarly, the other branch gives $L_{n+1} = L_n + \log\frac{1-\alpha}{1-\beta}$
.

When $\alpha \neq \beta$, both step sizes $a = \log\frac{\alpha}{\beta}$ and $b
= \log\frac{1-\alpha}{1-\beta}$ are **nonzero**, so:

$$|L_{n+1} - L_n| \geq \min(|a|, |b|) > 0 \quad \text{for all } n.$$

If $X_\infty \in (0,1)$, then $L_n \to L_\infty$ (finite), which forces $L_{n+1}
 - L_n \to 0$ — contradicting the lower bound above. Therefore $X_\infty \notin
(0,1)$, and since $X_\infty \in [0,1]$, we conclude:

$$X_\infty \in \{0, 1\} \quad \text{a.s.}$$

**Step 4: Compute the probability.**

Since $X_\infty \in \{0,1\}$ a.s. and $E[X_\infty] = E[X_0] = 0.01$:

$$P(X_\infty = 1)\cdot 1 + P(X_\infty = 0)\cdot 0 = 0.01,$$

so $P(X_\infty = 1) = 0.01$.

On the event $\{X_\infty = 1\}$, we have $X_n \to 1$, so $X_n > 0.99$ for all su
fficiently large $n$. On $\{X_\infty = 0\}$, we have $X_n \to 0$, so $X_n < 0.99
$ for all sufficiently large $n$. Therefore:

$$\lim_{n \to \infty} P(X_n > 0.99) = P(X_\infty = 1) = \boxed{0.01}.$$

**Remark on the degenerate case $\alpha = \beta$:** If $\alpha = \beta$, both up
date rules give $X_{n+1} = X_n$, so the chain is frozen at $X_0 = 0.01$ and the
probability is $0$. The answer $0.01$ holds for all $\alpha \neq \beta$ with $\a
lpha, \beta \in (0,1)$, and is the intended answer for this problem.
