Proof

Theorem. For every measurable cardinal $\kappa$, there exists a normal, $
\kappa$-complete, non-principal ultrafilter on $\kappa$.

Proof.

Let $\kappa$ be a measurable cardinal. By the definition of measurability, there
exists a non-principal $\kappa$-complete ultrafilter $U$ on $\kappa$. We shall
derive from $U$ a normal ultrafilter $D$ on $\kappa$.

Step 1. The ultrapower is well-founded

Form the ultrapower $M_0 = V^\kappa / U$. Since $U$ is $\kappa$-complete and $
\kappa > \omega$ (every measurable cardinal is uncountable), $U$ is in
particular countably complete. By Łoś's theorem together with countable
completeness, the relation $[\bar f]_U \in [\bar g]_U$ is well-founded on $M_0$.
Collapsing $M_0$ to a transitive class, we obtain a transitive model $M$ and the
canonical elementary embedding $$j : V \to M, \qquad j(x) = [\bar c_x]_U,$$
where $\bar c_x$ is the constant function with value $x$.

Step 2. $j$ is the identity below $\kappa$

For every ordinal $\alpha < \kappa$, the constant function $c_\alpha$ represents
$\alpha$ in $M$, so $j(\alpha) = \alpha$. More generally, by $\kappa$-
completeness one shows $j \upharpoonright V_\kappa = \mathrm{id}{V\kappa}$: any
element of $V_\kappa$ has rank $< \kappa$, and $\kappa$-completeness guarantees
that functions which are constant on a $U$-large set represent the corresponding
ground-model element. In particular, $j(\gamma) = \gamma$ for every $\gamma <
\kappa$.

Step 3. $j(\kappa) > \kappa$

Consider the identity function $\mathrm{id} : \kappa \to \kappa$, $\mathrm{id}
(\alpha) = \alpha$. Its equivalence class $[\mathrm{id}]_U$ is an ordinal of $M$
below $j(\kappa)$. For each $\alpha < \kappa$, the set ${\beta < \kappa : \alpha
< \beta}$ belongs to $U$: indeed $U$ is non-principal and $\kappa$-complete,
hence uniform (every member has cardinality $\kappa$), so $\kappa \setminus
(\alpha + 1) \in U$. Therefore $[\mathrm{id}]U > [c\alpha]_U = \alpha$ for every
$\alpha < \kappa$, which gives $[\mathrm{id}]_U \geq \kappa$. Since
$[\mathrm{id}]_U < j(\kappa)$, we conclude $j(\kappa) > \kappa$.

Step 4. Definition of $D$

Define $$D = { A \subseteq \kappa : \kappa \in j(A) }.$$

Step 5. $D$ is a $\kappa$-complete non-principal ultrafilter

Ultrafilter. Let $A \subseteq \kappa$. Since $j(A) \subseteq j(\kappa)$ and $
\kappa \in j(\kappa)$, either $\kappa \in j(A)$ or $\kappa \in j(\kappa)
\setminus j(A) = j(\kappa \setminus A)$. Hence $A \in D$ or $\kappa \setminus A
\in D$.

$\kappa$-completeness. Let $\langle A_\xi : \xi < \gamma \rangle$ with $\gamma <
\kappa$ and $A_\xi \in D$ for all $\xi$. Then $\kappa \in j(A_\xi)$ for every $
\xi$. Because $\gamma < \kappa$, we have $j(\gamma) = \gamma$, so by
elementarity $$j!\left(\bigcap_{\xi < \gamma} A_\xi\right) = \bigcap_{\xi <
\gamma} j(A_\xi).$$ Thus $\kappa \in \bigcap_{\xi<\gamma} j(A_\xi) =
j(\bigcap_{\xi<\gamma} A_\xi)$, giving $\bigcap_{\xi<\gamma} A_\xi \in D$.

Non-principal. For any $\alpha < \kappa$, $j({\alpha}) = {j(\alpha)} =
{\alpha}$, which does not contain $\kappa$. Hence ${\alpha} \notin D$ for every
$\alpha < \kappa$, so $D$ is non-principal.

Step 6. $D$ is normal

Let $A \in D$ and let $f : A \to \kappa$ be regressive, i.e. $f(\alpha) <
\alpha$ for all $\alpha \in A$ with $\alpha > 0$. Since $A \in D$, we have $
\kappa \in j(A)$. By elementarity, $j(f) : j(A) \to j(\kappa)$ and the statement
"$\forall \alpha \in A,(\alpha > 0 \Rightarrow f(\alpha) < \alpha)$" holds in
$M$. Applying this at $\alpha = \kappa \in j(A)$ (note $\kappa > 0$): $$j(f)
(\kappa) < \kappa.$$ Set $\beta := j(f)(\kappa) < \kappa$. Since $\beta <
\kappa$, Step 2 gives $j(\beta) = \beta$. Now compute: $$\kappa \in j({\alpha
\in A : f(\alpha) = \beta}) = {\alpha \in j(A) : j(f)(\alpha) = j(\beta)} =
{\alpha \in j(A) : j(f)(\alpha) = \beta},$$ where the last equality uses
$j(\beta) = \beta$, and the membership holds because $j(f)(\kappa) = \beta$ and
$\kappa \in j(A)$. Therefore $${\alpha \in A : f(\alpha) = \beta} \in D.$$

This is exactly normality: every regressive function on a $D$-positive set is
constant on a $D$-positive set. Equivalently, $D$ is closed under diagonal
intersections: if $\langle A_\xi : \xi < \kappa \rangle$ with each $A_\xi \in
D$, then $\triangle_{\xi<\kappa} A_\xi \in D$ (this follows from the regressive-
function characterization just proved).

Starting from any non-principal $\kappa$-complete ultrafilter $U$ on a
measurable cardinal $\kappa$, the ultrafilter $$D = {A \subseteq \kappa : \kappa
\in j(A)},$$ where $j : V \to V^\kappa / U$ is the associated elementary
embedding, is a normal, $\kappa$-complete, non-principal ultrafilter on $
\kappa$. Hence the answer to the question is yes. $\blacksquare$
