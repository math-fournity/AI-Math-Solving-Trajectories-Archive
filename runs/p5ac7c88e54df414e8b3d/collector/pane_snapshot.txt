## Solution

**Key Tool — Expected Waiting Time for a Single Pattern.**

For a pattern $w = w_1 w_2 \cdots w_L$ in an i.i.d. sequence, define a **border*
* of length $k$ as a value $k$ with $1 \le k \le L$ such that the prefix of leng
th $k$ equals the suffix of length $k$:
$$w_1 \cdots w_k = w_{L-k+1} \cdots w_L.$$
Let $\mathcal{B}$ be the set of all border lengths (note $L \in \mathcal{B}$ alw
ays). Then the expected waiting time is:

$$E[T] = \sum_{k \in \mathcal{B}} \frac{1}{\Pr(w_1 \cdots w_k)}.$$

*Verification of the formula:* For "HH" with a fair coin, borders are $\{1,2\}$,
 giving $2+4=6$ ✓. For "HT", borders are $\{2\}$, giving $4$ ✓. For "HHH", borde
rs are $\{1,2,3\}$, giving $2+4+8=14$ ✓.

**Applying to Our Pattern.**

Our pattern is $w = (\text{HMMT})^{2016}$, with length $L = 4 \times 2016 = 8064
$. Each symbol has probability $1/3$, so for any specific sequence of length $k$
:
$$\Pr(w_1 \cdots w_k) = (1/3)^k, \qquad \frac{1}{\Pr(w_1 \cdots w_k)} = 3^k.$$

**Finding All Borders of $(\text{HMMT})^{2016}$.**

First, note that the block HMMT is **primitive** — it has no nontrivial internal
 borders:
- Length 1: H ≠ T.
- Length 2: HM ≠ MT.
- Length 3: HMM ≠ MMT.

Since HMMT is primitive with period 4, the string $(\text{HMMT})^{2016}$ has fun
damental period 4.

**Borders at multiples of 4:** For $k = 4j$ with $1 \le j \le 2016$:
- Prefix of length $4j$ is $(\text{HMMT})^j$.
- Suffix of length $4j$ is the last $4j$ characters, which (since the string is
$2016$ complete copies of HMMT) is also $(\text{HMMT})^j$.

So every $k = 4j$ for $1 \le j \le 2016$ is a border. ✓

**No borders at non-multiples of 4:** For $k = 4j + r$ with $1 \le r \le 3$:
- The prefix begins with **H** (the first character of HMMT).
- The suffix of length $4j+r$ starts at position $4(2016) - (4j+r) + 1 = 4(2016-
j) - r + 1$.
  - $r=1$: starts at position $4(2016-j)$, which is the 4th character of a block
 = **T**.
  - $r=2$: starts at position $4(2016-j)-1$, which is the 3rd character = **M**.
  - $r=3$: starts at position $4(2016-j)-2$, which is the 2nd character = **M**.

In all cases, the first character of the suffix (T or M) ≠ H, so no border exist
s. ✓

**Therefore the border set is exactly $\mathcal{B} = \{4, 8, 12, \ldots, 8064\}
= \{4j : 1 \le j \le 2016\}$.**

**Computing the Expected Value.**

$$E[T] = \sum_{j=1}^{2016} 3^{4j} = \sum_{j=1}^{2016} 81^j.$$

This is a geometric series with ratio 81:

$$E[T] = 81 \cdot \frac{81^{2016} - 1}{81 - 1} = \frac{81\left(81^{2016} - 1\rig
ht)}{80}.$$

**Sanity check with small cases:**
- $(\text{HMMT})^1$: $E[T] = 81 = 3^4 = 1/(1/3)^4$ ✓ (no self-overlap, so expect
ed time = reciprocal of pattern probability).
- $(\text{HMMT})^2$: $E[T] = 81 + 81^2 = 81 + 6561 = 6642 = \frac{81(81^2-1)}{80
} = \frac{81 \cdot 6560}{80} = 6642$ ✓.

## Answer

$$\boxed{\dfrac{81\left(81^{2016}-1\right)}{80}}$$
