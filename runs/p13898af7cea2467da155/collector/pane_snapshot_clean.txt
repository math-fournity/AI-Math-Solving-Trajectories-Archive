## Proof

**Setup.** We seek the harmonic function $V(x,y)$ in the unit disk $D = \{x^2+y^
2 < 1\}$ with boundary values
$$V(e^{i\theta}) = \begin{cases} 1, & 0 < \theta < \pi/2, \\ 0, & \text{otherwis
e}. \end{cases}$$

**Step 1: Poisson integral via the Schwarz formula.**

The Poisson integral formula for the unit disk gives
$$V(r,\phi) = \frac{1}{2\pi}\int_0^{2\pi} \frac{1-r^2}{1-2r\cos(\theta-\phi)+r^2
}\,f(\theta)\,d\theta,$$
where $z = re^{i\phi} = x+iy$ and $f$ is the boundary data. Using the identity
$$\frac{1-r^2}{|e^{i\theta}-z|^2} = \operatorname{Re}\!\left(\frac{e^{i\theta}+z
}{e^{i\theta}-z}\right),$$
we write (Schwarz integral formula):
$$V(z) = \operatorname{Re}\!\left[\frac{1}{2\pi}\int_0^{\pi/2} \frac{e^{i\theta}
+z}{e^{i\theta}-z}\,d\theta\right].$$

**Step 2: Evaluate the contour integral.**

Substitute $w = e^{i\theta}$, $d\theta = dw/(iw)$, with the path from $w=1$ to $
w=i$:
$$I(z) := \frac{1}{2\pi}\int_0^{\pi/2} \frac{e^{i\theta}+z}{e^{i\theta}-z}\,d\th
eta = \frac{1}{2\pi i}\int_1^i \frac{w+z}{w(w-z)}\,dw.$$

Partial fractions: $\frac{w+z}{w(w-z)} = \frac{-1}{w} + \frac{2}{w-z}$. Hence
$$I(z) = \frac{1}{2\pi i}\Big[-\log w + 2\log(w-z)\Big]_1^i = \frac{1}{2\pi i}\l
eft[-\log i + 2\log(i-z) - 2\log(1-z)\right].$$

Since $\log i = i\pi/2$:
$$I(z) = \frac{1}{2\pi i}\left[-\frac{i\pi}{2} + 2\log\frac{i-z}{1-z}\right] = -
\frac{1}{4} + \frac{1}{\pi i}\log\frac{i-z}{1-z} = -\frac{1}{4} - \frac{i}{\pi}\
log\frac{i-z}{1-z}.$$

**Step 3: Extract the real part.**

Writing $\log\frac{i-z}{1-z} = \ln\left|\frac{i-z}{1-z}\right| + i\arg\frac{i-z}
{1-z}$, we get
$$-\frac{i}{\pi}\log\frac{i-z}{1-z} = -\frac{i}{\pi}\ln\left|\frac{i-z}{1-z}\rig
ht| + \frac{1}{\pi}\arg\frac{i-z}{1-z}.$$

Taking the real part:
$$V(z) = -\frac{1}{4} + \frac{1}{\pi}\arg\frac{i-z}{1-z}. \tag{$\star$}$$

**Step 4: Compute $\arg\frac{i-z}{1-z}$ in Cartesian coordinates.**

With $z = x+iy$:
$$\frac{i-z}{1-z} = \frac{(-x)+i(1-y)}{(1-x)-iy}\cdot\frac{(1-x)+iy}{(1-x)+iy} =
 \frac{(x^2+y^2-x-y)+i(1-x-y)}{(1-x)^2+y^2}.$$

Since $(1-x)^2+y^2 > 0$ inside the disk, denote
$$\alpha := \arg\frac{i-z}{1-z} = \operatorname{atan2}(1-x-y,\; x^2+y^2-x-y).$$

**Step 5: Relate $\alpha$ to the target expression.**

Define $\beta := \alpha - \frac{\pi}{4} = \arg\!\left(e^{-i\pi/4}\cdot\frac{i-z}
{1-z}\right)$. Since $e^{-i\pi/4} = \frac{1-i}{\sqrt{2}}$, we compute
$$\frac{(1-i)(i-z)}{1-z} = \frac{(1-i)(-x+i(1-y))}{(1-x)-iy}.$$

The numerator simplifies to $(1-x-y)+i(1+x-y)$. Rationalizing:
$$\frac{(1-i)(i-z)}{1-z} = \frac{\big[(1-x-y)+i(1+x-y)\big]\big[(1-x)+iy\big]}{(
1-x)^2+y^2}.$$

**Real part of numerator:**
$$(1-x-y)(1-x) - (1+x-y)\cdot y = (1-2x+x^2) - 2y + y^2 = x^2+y^2-2x-2y+1.$$

**Imaginary part of numerator:**
$$(1-x-y)\cdot y + (1+x-y)(1-x) = 1 - x^2 - y^2.$$

Therefore
$$\frac{(1-i)(i-z)}{1-z} = \frac{(x^2+y^2-2x-2y+1)+i(1-x^2-y^2)}{(1-x)^2+y^2}.$$

Since the denominator is positive, the argument is determined by the numerator.
Inside the disk, $1-x^2-y^2 > 0$, so the imaginary part is positive and $\beta \
in (0,\pi)$. Thus
$$\beta = \arg\!\big((x^2+y^2-2x-2y+1)+i(1-x^2-y^2)\big), \qquad \beta\in(0,\pi)
,$$
and
$$\tan\beta = \frac{1-x^2-y^2}{x^2+y^2-2x-2y+1} = \frac{1-x^2-y^2}{(x-1)^2+(y-1)
^2-1}.$$

**Step 6: Conclude.**

From $(\star)$ and $\alpha = \beta + \pi/4$:
$$V(x,y) = -\frac{1}{4} + \frac{1}{\pi}\left(\beta + \frac{\pi}{4}\right) = -\fr
ac{1}{4} + \frac{\beta}{\pi} + \frac{1}{4} = \frac{\beta}{\pi}.$$

Since $\beta \in (0,\pi)$ and $\tan\beta = \frac{1-x^2-y^2}{(x-1)^2+(y-1)^2-1}$,
 we obtain

$$\boxed{V(x,y) = \frac{1}{\pi}\arctan\!\left[\frac{1-x^2-y^2}{(x-1)^2+(y-1)^2-1
}\right], \qquad 0\le\arctan t\le\pi.}$$

**Verification at the center ($x=y=0$):** $V = \frac{1}{\pi}\arctan\frac{1}{1} =
 \frac{1}{\pi}\cdot\frac{\pi}{4} = \frac{1}{4}$, which equals the fraction of th
e boundary arc where $V=1$ (namely $\frac{\pi/2}{2\pi}=\frac{1}{4}$). ✓
