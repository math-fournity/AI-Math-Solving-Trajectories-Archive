**证明。**

我们需要计算

$$I_n = \int_0^{\infty} x^{4n+3} e^{-x} \sin x \, dx.$$

**步骤 1：复数化。** 由于 $\sin x = \operatorname{Im}(e^{ix})$，我们引入复积分

$$J_n = \int_0^{\infty} x^{4n+3} e^{-x} e^{ix}\, dx = \int_0^{\infty} x^{4n+3} e
^{(i-1)x}\, dx,$$

由此可得 $I_n = \operatorname{Im}(J_n)$。

**步骤 2：计算 $J_n$。** 令 $a = 1 - i$，因此 $e^{(i-1)x} = e^{-ax}$。由于 $\ope
ratorname{Re}(a) = 1 > 0$，标准的 Gamma 型公式适用：

$$\int_0^{\infty} x^{m}\, e^{-ax}\, dx = \frac{m!}{a^{m+1}}, \qquad \operatornam
e{Re}(a)>0,\ m\in\mathbb{Z}_{\ge 0}.$$

取 $m = 4n+3$，我们得到

$$J_n = \frac{(4n+3)!}{(1-i)^{4n+4}}.$$

**步骤 3：计算 $(1-i)^{4n+4}$。** 以极坐标形式表示 $1-i$：

$$1 - i = \sqrt{2}\, e^{-i\pi/4}.$$

因此

$$(1-i)^{4n+4} = \left(\sqrt{2}\right)^{4n+4} e^{-i(4n+4)\pi/4} = 2^{2n+2}\, e^{
-i(n+1)\pi}.$$

由于 $e^{-i(n+1)\pi} = \cos\big((n+1)\pi\big) = (-1)^{n+1}$ 是**实数**，我们得到

$$(1-i)^{4n+4} = 2^{2n+2}\,(-1)^{n+1} \in \mathbb{R}.$$

**步骤 4：得出结论。** 由于 $(1-i)^{4n+4}$ 是实数，

$$J_n = \frac{(4n+3)!}{2^{2n+2}\,(-1)^{n+1}} = \frac{(-1)^{n+1}\,(4n+3)!}{2^{2n+
2}} \in \mathbb{R}.$$

其实部为 $J_n$，虚部为 $0$。因此

$$I_n = \operatorname{Im}(J_n) = 0.$$

**验证（小值检验）。** 对于 $n=0$：$(1-i)^4 = \big((1-i)^2\big)^2 = (-2i)^2 = -4
$，所以 $J_0 = 3!/(-4) = -3/2 \in \mathbb{R}$，因此 $I_0 = 0$。对于 $n=1$：$(1-i
)^8 = (-4)^2 = 16$，所以 $J_1 = 7!/16 = 315 \in \mathbb{R}$，因此 $I_1 = 0$。两
者均与通式一致。

**核心见解：** 指数 $4n+4 = 4(n+1)$ 始终是 $4$ 的倍数，而 $(1-i)^4 = -4$ 是实数
。因此 $(1-i)^{4n+4}$ 始终是实数，这使得 $J_n$ 始终是实数，从而使其虚部——即原积
分——为 $0$。

$$\boxed{\displaystyle \int_0^{\infty} x^{4n+3} e^{-x} \sin x \, dx = 0.}$$
