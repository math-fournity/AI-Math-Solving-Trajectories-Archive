- Horizontal (±1, 0): cost 2
- Vertical (0, ±1): cost 2
- Diagonal (±1, ±1): cost 3

Any path from A to B must achieve net displacement (7, 7).

**Key observation — diagonal moves are more efficient.** A diagonal move advance
s 1 in *both* x and y for cost 3. Achieving the same with separate horizontal +
vertical moves costs 2 + 2 = 4 > 3. So we should use as many diagonal moves as p
ossible.

**Eliminating backward moves.** Any move that decreases x or y must be compensat
ed by an extra forward move, strictly increasing total cost without aiding progr

elds net displacement (+1, 0), whereas a single horizontal (+1,0) costs 2 for th

**Optimizing forward moves.** Let D = diagonal (+1,+1) moves, H = horizontal (+1

- D + H = 7 (x-displacement)
- D + V = 7 (y-displacement)
- Cost = 3D + 2H + 2V = 3D + 2(7−D) + 2(7−D) = **28 − D**

To **minimize cost**, we **maximize D**. Since H, V ≥ 0, we have D ≤ 7. Setting

$$\text{min cost} = 28 - 7 = 21$$
