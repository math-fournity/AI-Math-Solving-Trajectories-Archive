## Solution

**Setup.** A 4-digit code with alternating pattern (1st=3rd digit `a`, 2nd=4th d
igit `b`) has the form $n = \overline{abab}$. Computing:

$$n = 1000a + 100b + 10a + b = 1010a + 101b = 101(10a+b).$$

The digit product is $a\cdot b\cdot a\cdot b = a^2b^2$. The condition is $a^2b^2
 \mid n^2$.

**Key reduction.** For positive integers $d, m$: $d^2 \mid m^2 \iff d \mid m$ (c
ompare prime-exponent valuations: $2\alpha_p \le 2\beta_p \iff \alpha_p \le \bet
a_p$). So the condition becomes

$$ab \mid n = 101(10a+b).$$

**Handling $b=0$.** Then the digit product is $0$, and "$0 \mid n^2$" requires $
n^2=0$, impossible for a 4-digit number. So $b \in \{1,\dots,9\}$, and $a \in \{
1,\dots,9\}$ (leading digit).

**Using primality of 101.** Since $101$ is prime and $a,b \le 9 < 101$, we have
$\gcd(101, ab)=1$. Therefore $ab \mid 101(10a+b)$ forces

$$ab \mid (10a+b).$$

**Enumeration.** For each $a\in\{1,\dots,9\}$, $b\in\{1,\dots,9\}$, test whether
 $ab \mid (10a+b)$:

- **$a=1$:** need $b \mid (10+b)$, i.e. $b\mid 10$. With $b\le 9$: $b\in\{1,2,5\
}$ → codes **1111, 1212, 1515**.
- **$a=2$:** need $2b\mid(20+b)$. Only $b=4$: $8\mid 24$ ✓ → code **2424**.
- **$a=3$:** need $3b\mid(30+b)$. Only $b=6$: $18\mid 36$ ✓ → code **3636**.
- **$a=4$:** need $4b\mid(40+b)$; $40+b\le 49 < 4b$ is false for small $b$, and
direct check of $b=1..9$ gives no divisor. None.
- **$a=5,6,7,8,9$:** direct check of all $b=1..9$ yields no solutions (e.g. $a=5
$: $5b\mid(50+b)$ never holds since $50+b$ is not a multiple of $5b$ for any val
id $b$; similarly for the rest). None.

**Verification of the five codes:**

| Code | Digits | Product $a^2b^2$ | $n^2 / a^2b^2$ | Valid |
|------|--------|------|------|-------|
| 1111 | 1,1,1,1 | 1 | $1111^2$ | ✓ |
| 1212 | 1,2,1,2 | 4 | $1212^2/4 = 367236$ | ✓ |
| 1515 | 1,5,1,5 | 25 | $1515^2/25 = 91809$ | ✓ |
| 2424 | 2,4,2,4 | 64 | $2424^2/64 = 91809$ | ✓ |
| 3636 | 3,6,3,6 | 324 | $3636^2/324 = 40804$ | ✓ |

**Sum:**

$$1111 + 1212 + 1515 + 2424 + 3636 = 9898.$$

The total sum of all "Elite" security codes is $\boxed{9898}$.
