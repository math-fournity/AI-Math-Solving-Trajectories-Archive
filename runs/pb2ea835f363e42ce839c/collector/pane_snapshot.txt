## Solution

We solve $\cos^2 x + \cos^2(2x) + \cos^2(3x) = 1$.

**Reduction to a single cosine sum.** Using $\cos^2\theta = \tfrac{1+\cos 2\thet
a}{2}$:

$$\cos^2 x + \cos^2(2x) + \cos^2(3x) = \frac{3}{2} + \frac{\cos 2x + \cos 4x + \
cos 6x}{2}.$$

Setting this equal to $1$ gives

$$\cos 2x + \cos 4x + \cos 6x = -1.$$

Let $y = 2x$:

$$\cos y + \cos 2y + \cos 3y = -1.$$

**Factoring.** Using $\cos y + \cos 3y = 2\cos 2y\cos y$:

$$\cos 2y\,(2\cos y + 1) + \cos 2y = -1 \implies \cos 2y\,(2\cos y + 1) = -1.$$

Set $c = \cos y$, so $\cos 2y = 2c^2 - 1$:

$$(2c^2 - 1)(2c + 1) = -1.$$

Expanding: $4c^3 + 2c^2 - 2c - 1 = -1$, hence

$$4c^3 + 2c^2 - 2c = 0 \implies 2c(2c^2 + c - 1) = 0 \implies 2c(2c-1)(c+1) = 0.
$$

Thus $\cos y = \cos 2x \in \{0,\, \tfrac{1}{2},\, -1\}$.

**Solving each case.**

- **$\cos 2x = 0$:** $\;2x = \tfrac{\pi}{2} + k\pi \implies x = \tfrac{\pi}{4} +
 \tfrac{k\pi}{2},\; k\in\mathbb{Z}$.

- **$\cos 2x = \tfrac{1}{2}$:** $\;2x = \pm\tfrac{\pi}{3} + 2k\pi \implies x = \
pm\tfrac{\pi}{6} + k\pi,\; k\in\mathbb{Z}$.

- **$\cos 2x = -1$:** $\;2x = \pi + 2k\pi \implies x = \tfrac{\pi}{2} + k\pi,\;
k\in\mathbb{Z}$.

**Verification.** Since each step was reversible (we only applied identities and
 factored a polynomial whose roots we found completely), every value obtained is
 a genuine solution. We confirm directly:

- $x = \tfrac{\pi}{4}$: $\tfrac{1}{2} + 0 + \tfrac{1}{2} = 1$. ✓
- $x = \tfrac{\pi}{6}$: $\tfrac{3}{4} + \tfrac{1}{4} + 0 = 1$. ✓
- $x = \tfrac{\pi}{2}$: $0 + 1 + 0 = 1$. ✓

The three families are disjoint (their values of $\cos 2x$ differ), so the solut
ion set is their union.

**Answer.** The solutions are

$$\boxed{\,x = \frac{\pi}{4} + \frac{k\pi}{2},\quad x = \pm\frac{\pi}{6} + k\pi,
\quad x = \frac{\pi}{2} + k\pi,\qquad k\in\mathbb{Z}\,}.$$
