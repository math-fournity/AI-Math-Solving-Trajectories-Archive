## 证明

**设置。** 设 $f(x) = (x^2 - a)^2 - b = x^4 - 2ax^2 + (a^2 - b) \in \mathbb{Q}[x
]$，其中 $b > a^2$ 且 $f$ 在 $\mathbb{Q}$ 上不可约。$f$ 的根为
$$\pm u,\quad \pm v, \qquad u := \sqrt{a + \sqrt{b}},\quad v := \sqrt{a - \sqrt{
b}}.$$
由于 $b > a^2 \ge 0$，可得 $b > 0$ 且 $\sqrt{b} > |a|$，因此 $a + \sqrt{b} > 0$
（故 $u \in \mathbb{R}$），且 $a - \sqrt{b} < 0$（故 $v = i\sqrt{\sqrt{b}-a} \no
tin \mathbb{R}$）。

**步骤 1：$b$ 不是有理数的平方。** 如果对于 $k \in \mathbb{Q}$ 有 $b = k^2$，那
么 $f = (x^2 - a - k)(x^2 - a + k)$ 可以在 $\mathbb{Q}$ 上分解，这与不可约性矛盾
。因此 $L := \mathbb{Q}(\sqrt{b})$ 是 $\mathbb{Q}$ 的二次扩张。

**步骤 2：$a + \sqrt{b}$ 不是 $L$ 中的平方数。** 假设 $(c + d\sqrt{b})^2 = a + \
sqrt{b}$，其中 $c, d \in \mathbb{Q}$。比较系数可得 $c^2 + d^2 b = a$ 和 $2cd = 1
$。由 $d = 1/(2c)$ 可得 $4c^4 - 4ac^2 + b = 0$，即 $c^2 = \tfrac{a \pm \sqrt{a^2
 - b}}{2}$。由于 $a^2 - b < 0$，有 $\sqrt{a^2 - b} \notin \mathbb{Q}$，故 $c^2 \
notin \mathbb{Q}$，矛盾。由对称性可知，$a - \sqrt{b}$ 也不是 $L$ 中的平方数。

**步骤 3：分裂域的次数为 8。** 在 $L$ 上，$f = (x^2 - (a+\sqrt{b}))(x^2 - (a - \
sqrt{b}))$，且两个因子在 $L$ 上都是不可约的（步骤 2）。因此 $[\mathbb{Q}(u): \ma
thbb{Q}] = [\mathbb{Q}(u):L][L:\mathbb{Q}] = 2 \cdot 2 = 4$，这与 $f$ 的不可约性
一致。注意 $\sqrt{b} = u^2 - a \in \mathbb{Q}(u)$，所以 $\mathbb{Q}(u) = L(u) \s
ubset \mathbb{R}$。分裂域为 $K = \mathbb{Q}(u, v)$。由于 $v^2 = a - \sqrt{b} \in
 \mathbb{Q}(u)$ 且 $v \notin \mathbb{R}$，而 $\mathbb{Q}(u) \subset \mathbb{R}$
，得到 $v \notin \mathbb{Q}(u)$，因此 $[K : \mathbb{Q}(u)] = 2$，且
$$[K : \mathbb{Q}] = 8.$$

**步骤 4：识别伽罗瓦群。** $\mathbb{Q}$-自同构由其对 $\sqrt{b}, u, v$ 的作用决定
，且需满足 $u^2 = a + \sqrt{b}$, $v^2 = a - \sqrt{b}$。这 8 种可能性为：

| $\sigma(\sqrt{b})$ | $\sigma(u)$ | $\sigma(v)$ | 元素 |
|---|---|---|---|
| $\sqrt{b}$ | $u$ | $v$ | $1$ |
| $\sqrt{b}$ | $-u$ | $v$ | $\tau$ |
| $\sqrt{b}$ | $u$ | $-v$ | $\rho$ |
| $\sqrt{b}$ | $-u$ | $-v$ | $\tau\rho$ |
| $-\sqrt{b}$ | $v$ | $u$ | $s$ |
| $-\sqrt{b}$ | $-v$ | $u$ | $s\tau$ |
| $-\sqrt{b}$ | $v$ | $-u$ | $s\rho$ |
| $-\sqrt{b}$ | $-v$ | $-u$ | $s\tau\rho$ |

设 $r := s\tau$（即 $r(u) = -v$, $r(v) = u$, $r(\sqrt{b}) = -\sqrt{b}$）且 $s$
如上所定义。则：
- $r^2(u) = r(-v) = -u$, $r^2(v) = r(u) = -v$, $r^2(\sqrt{b}) = \sqrt{b}$, 所以
$r^4 = 1$ 且 $r$ 的阶为 4。
- $s^2 = 1$（$s$ 交换 $u \leftrightarrow v$ 并使 $\sqrt{b} \mapsto -\sqrt{b}$，
应用两次得到恒等）。
- $srs^{-1}(u) = sr(u) = s(-v) = -u$... 让我们计算 $srs(u)$：$s(u)=v$, $r(v)=u$,
 $s(u)=v$，所以 $srs(u) = v = r^{-1}(u)$（因为 $r^{-1}(u) = r^3(u) = v$）。经核
对 $v$ 和 $\sqrt{b}$，$srs = r^{-1}$。

因此 $G = \langle r, s \mid r^4 = s^2 = 1,\; srs = r^{-1} \rangle \cong D_4$，即
**四阶二面体群（dihedral group of order 8）**。

**一致性检查。** 该群包含 5 个阶为 2 的元素（$s, \tau, \rho, \tau\rho, s\tau\rho
$）和 2 个阶为 4 的元素（$r = s\tau$, $r^3 = s\rho$），这正是 $D_4$ 的元素结构（
排除了 $Q_8$，其有 1 个对合，以及 $\mathbb{Z}/2 \times \mathbb{Z}/4$，其为阿贝尔
群）。

## 答案

$\mathbb{Q}$ 上 $f$ 的伽罗瓦群是**四阶二面体群 $D_4$**（即对称群 $\operatorname{
Sym}(\square)$，即正方形的 8 阶对称群）：
$$\operatorname{Gal}(f/\mathbb{Q}) \cong D_4 = \langle r, s \mid r^4 = s^2 = 1,\
; srs = r^{-1} \rangle.$$
