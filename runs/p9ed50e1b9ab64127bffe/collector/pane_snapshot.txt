## Proof (Polynomial Hensel's Lemma)

**Degenerate case $f = 0$.** Then $g_1 h_1 \equiv 0 \pmod{p}$. Since $\mathbb{F}
_p[x]$ is a domain and $g_1$ is monic (nonzero), $h_1 = 0$. Take $g = g_1 \in \m
athbb{Z}_p[x]$ (monic) and $h = 0$. Then $f = gh$, $g \equiv g_1$, $h \equiv h_1
 \pmod{p}$. ✓

**Assume $f \neq 0$.** Let $N = \deg f$, $d = \deg g_1$. Since $(g_1, h_1) = 1$
in the Euclidean domain $\mathbb{F}_p[x]$, there exist $a, b \in \mathbb{F}_p[x]
$ with $a g_1 + b h_1 = 1$. Because $g_1$ is monic of degree $d$ and $g_1 h_1 \e
quiv f \pmod{p}$, we have $\deg h_1 \leq N - d$.

**Inductive construction.** We build sequences $\{g_n\}, \{h_n\} \subset \mathbb
{Z}_p[x]$ satisfying, for all $n \geq 1$:
1. $g_n$ is monic, $\deg g_n = d$;
2. $\deg h_n \leq N - d$;
3. $g_n \equiv g_1 \pmod{p}$, $h_n \equiv h_1 \pmod{p}$;
4. $f \equiv g_n h_n \pmod{p^n}$.

*Base case $n=1$:* Take $g_1, h_1$ (lifted to $\mathbb{Z}_p[x]$). Conditions (1)
–(4) hold by hypothesis.

*Inductive step:* Assume $g_n, h_n$ satisfy (1)–(4). Set $e_n := (f - g_n h_n)/p
^n \in \mathbb{Z}_p[x]$ (well-defined by (4)), and let $\bar{e}_n := e_n \bmod p
 \in \mathbb{F}_p[x]$. Since $\deg(f - g_n h_n) \leq \max(N,\, d + \deg h_n) \le
q N$, we have $\deg \bar{e}_n \leq N$.

From $a g_1 + b h_1 = 1$, multiplying by $\bar{e}_n$ gives $\bar{e}_n b\, h_1 +
\bar{e}_n a\, g_1 = \bar{e}_n$. Set $u_0 = \bar{e}_n b$, $v_0 = \bar{e}_n a$. Di
vide $u_0$ by the monic polynomial $g_1$: $u_0 = q\, g_1 + u$ with $\deg u < d$.
 Set $v = v_0 + q\, h_1$. Then
$$u\, h_1 + v\, g_1 = (u_0 - q g_1) h_1 + (v_0 + q h_1) g_1 = u_0 h_1 + v_0 g_1
= \bar{e}_n.$$
Now $\deg u < d$. Also $v g_1 = \bar{e}_n - u h_1$, where $\deg(u h_1) \leq (d-1
) + (N-d) = N-1$ and $\deg \bar{e}_n \leq N$, so $\deg(v g_1) \leq N$, giving $\
deg v \leq N - d$ (since $g_1$ is monic of degree $d$).

Lift $u, v$ to $\mathbb{Z}_p[x]$ and define
$$g_{n+1} = g_n + p^n u, \qquad h_{n+1} = h_n + p^n v.$$

*Verification of (1)–(4) for $n+1$:*
- **(1)** $\deg u < d = \deg g_n$ and $g_n$ monic ⟹ $g_{n+1}$ monic of degree $d
$. ✓
- **(2)** $\deg v \leq N-d$ and $\deg h_n \leq N-d$ ⟹ $\deg h_{n+1} \leq N-d$. ✓
- **(3)** $g_{n+1} \equiv g_n \equiv g_1$, $h_{n+1} \equiv h_n \equiv h_1 \pmod{
p}$. ✓
- **(4)** Compute:
$$f - g_{n+1} h_{n+1} = (f - g_n h_n) - p^n(u h_n + v g_n) - p^{2n} u v = p^n\bi
gl(e_n - u h_n - v g_n\bigr) - p^{2n} u v.$$
Reducing mod $p$: $e_n - u h_n - v g_n \equiv \bar{e}_n - u h_1 - v g_1 = 0 \pmo
d{p}$, so the first term is $\equiv 0 \pmod{p^{n+1}}$. Since $2n \geq n+1$ for $
n \geq 1$, the second term $p^{2n} u v \equiv 0 \pmod{p^{n+1}}$. Hence $f \equiv
 g_{n+1} h_{n+1} \pmod{p^{n+1}}$. ✓

**Convergence.** For each $n$, $g_{n+1} - g_n = p^n u$ with $\deg u < d$, and $h
_{n+1} - h_n = p^n v$ with $\deg v \leq N - d$. Thus each coefficient of $\{g_n\
}$ (and $\{h_n\}$) forms a Cauchy sequence in $\mathbb{Z}_p$ (successive differe
nces divisible by $p^n$). Since $\mathbb{Z}_p$ is complete and degrees are unifo
rmly bounded ($\deg g_n = d$, $\deg h_n \leq N - d$), the sequences converge coe
fficient-wise to limits $g, h \in \mathbb{Z}_p[x]$ with $g$ monic of degree $d$.

**Final check.** Congruences: $g \equiv g_1$, $h \equiv h_1 \pmod{p}$ (inherited
 from all $g_n, h_n$). Equality: for every $n$, $f \equiv g_n h_n \pmod{p^n}$; a
s $n \to \infty$, $g_n h_n \to gh$ coefficient-wise (bounded degrees ⟹ finite su
ms), so $f - gh \equiv 0 \pmod{p^n}$ for all $n$, whence $f = gh$ in $\mathbb{Z}
_p[x]$.

Therefore $g, h \in \mathbb{Z}_p[x]$ satisfy all the required properties: $g$ mo
nic, $f = gh$, $g \equiv g_1 \pmod{p}$, $h \equiv h_1 \pmod{p}$. $\blacksquare$
