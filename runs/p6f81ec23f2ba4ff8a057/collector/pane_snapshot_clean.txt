## Proof

**Setup.** Place $B = (0,0)$, $C = (14,0)$. From $AB = 15$, $AC = 13$:
$$x_A^2 + y_A^2 = 225,\quad (x_A-14)^2 + y_A^2 = 169 \;\Rightarrow\; 28x_A = 252
 \;\Rightarrow\; x_A = 9,\; y_A = 12.$$
So $A = (9,12)$.

**Circumcenter $O$.** The perpendicular bisector of $BC$ is $x = 7$. Set $O = (7
,k)$; from $OA = OB$:
$$49 + k^2 = 4 + (12-k)^2 \;\Rightarrow\; 24k = 99 \;\Rightarrow\; k = \tfrac{33
}{8}.$$
So $O = (7, \tfrac{33}{8})$, with circumradius $R = \tfrac{65}{8}$ (verified via
 $R = \tfrac{abc}{4\Delta}$, $\Delta = 84$).

**Line $l$.** Since $l \perp BC$ and passes through $A$: $l$ is $x = 9$.

**Circle 1 through $A, B, O$.** Equation $x^2+y^2+Dx+Ey+F=0$ with $F=0$ (through
 $B$). Solving with $A$ and $O$:
$$D = \tfrac{29}{10},\quad E = -\tfrac{837}{40}.$$
Substitute $x = 9$:
$$y^2 - \tfrac{837}{40}y + \tfrac{1071}{10} = 0.$$
One root is $y = 12$ (point $A$); the product of roots is $\tfrac{1071}{10}$, so
$$y_X = \frac{1071/10}{12} = \frac{357}{40}.$$

**Circle 2 through $A, C, O$.** Solving with $A$, $C=(14,0)$, $O$:
$$D = -\tfrac{53}{2},\quad E = -\tfrac{323}{24},\quad F = 175.$$
Substitute $x = 9$:
$$y^2 - \tfrac{323}{24}y + \tfrac{35}{2} = 0.$$
One root is $y = 12$ (point $A$); the product of roots is $\tfrac{35}{2}$, so
$$y_Y = \frac{35/2}{12} = \frac{35}{24}.$$

**Distance.**
$$XY = \left|\frac{357}{40} - \frac{35}{24}\right| = \left|\frac{1071 - 175}{120
}\right| = \frac{896}{120} = \frac{112}{15}.$$
Since $\gcd(112, 15) = 1$, this is irreducible. Therefore $a = 112$, $b = 15$, a
nd
$$a + b = \boxed{127}.$$
