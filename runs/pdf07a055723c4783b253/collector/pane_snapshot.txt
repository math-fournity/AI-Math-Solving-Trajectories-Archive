## Exploring Small Cases

Computing $K(n,m)$ for small $n$ and letting $m$ grow, the sets stabilize. Let m
e denote the stable value $S(n)$:

| $n$ | $S(n)$ | $|S(n)|$ |
|-----|--------|----------|
| 0 | $\varnothing$ | 0 |
| 1 | $\{1\}$ | 1 |
| 2 | $\{2\}$ | 1 |
| 3 | $\{1,2,3\}$ | 3 |
| 4 | $\{4\}$ | 1 |

**Key observation:** $S(n)$ equals the set of all *nonzero binary submasks* of $
n$. For example, $11 = 1011_2$, and $S(11) = \{0001, 0010, 0011, 1000, 1001, 101
0, 1011\} = \{1,2,3,8,9,10,11\}$. ✓

## The Proof

**Definition.** For $n \ge 0$, let $S(n) = \{m \ne 0 : m \mathbin{\&} n = m\}$,
the set of nonzero integers whose binary representation is a submask of $n$'s (e
very 1-bit of $m$ is also a 1-bit of $n$).

**Lemma 1 (Intersection).** $S(a) \cap S(b) = S(a \mathbin{\&} b)$. In particula
r, $S(a) \cap S(b) = \varnothing \iff a \mathbin{\&} b = 0$.

*Proof.* $m \in S(a) \cap S(b)$ iff $m \ne 0$, $m \mathbin{\&} a = m$, and $m \m
athbin{\&} b = m$, iff $m \ne 0$ and $m \mathbin{\&} (a \mathbin{\&} b) = m$, if
f $m \in S(a \mathbin{\&} b)$. $\square$

**Lemma 2 (Subtraction criterion).** For $0 \le k \le n$: $k \mathbin{\&} (n-k)
= 0 \iff k$ is a submask of $n$.

*Proof.* ($\Leftarrow$) If $k$ is a submask of $n$, then $n - k = n \oplus k$ (n
o borrows occur since every 1-bit of $k$ is a 1-bit of $n$). Then $k \mathbin{\&
} (n \oplus k) = 0$ since $k$ and $n \oplus k$ have disjoint set bits.

($\Rightarrow$) If $k \mathbin{\&} (n-k) = 0$, then $k$ and $n-k$ share no set b
its, so $n = k + (n-k) = k \mathbin{\text{OR}} (n-k)$ with no carries. Thus ever
y bit of $k$ is a bit of $n$, i.e., $k$ is a submask of $n$. $\square$

**Theorem (Stabilization).** For all $n \ge 0$ and $m \ge n$: $K(n, m) = S(n)$.

*Proof by strong induction on $n$.*

**Base:** $n = 0$: $K(0, m) = \varnothing = S(0)$ for all $m$.

**Inductive step:** Assume for all $n' < n$ and all $m' \ge n'$, $K(n', m') = S(
n')$. Let $m \ge n$.

$$K(n, m) = \{k : 1 \le k \le n,\; K(k, m{-}1) \cap K(n{-}k, m{-}1) = \varnothin
g\}.$$

- **$k = n$:** $K(n, m{-}1) \cap K(0, m{-}1) = K(n, m{-}1) \cap \varnothing = \v
arnothing$. So $n \in K(n, m)$. ($n$ is a submask of itself. ✓)

- **$1 \le k \le n{-}1$:** Both $k < n$ and $n{-}k < n$. Since $m{-}1 \ge n{-}1
\ge \max(k, n{-}k)$, the induction hypothesis gives $K(k, m{-}1) = S(k)$ and $K(
n{-}k, m{-}1) = S(n{-}k)$. By Lemma 1, $S(k) \cap S(n{-}k) = \varnothing \iff k
\mathbin{\&} (n{-}k) = 0 \iff k$ is a submask of $n$ (Lemma 2).

Therefore $K(n, m) = \{k : 1 \le k \le n,\; k \text{ is a nonzero submask of } n
\} = S(n)$. $\square$

**Corollary.** $K(2004, 2004) = S(2004)$, so $|K(2004, 2004)| = 2^{s_2(2004)} -
1$ where $s_2(n)$ counts the 1-bits of $n$ (since $S(n)$ has one element per non
empty subset of the 1-bit positions).

## Computing the Answer

$$2004 = 1024 + 512 + 256 + 128 + 64 + 16 + 4 = 2^{10} + 2^9 + 2^8 + 2^7 + 2^6 +
 2^4 + 2^2$$

In binary: $2004 = 11111010100_2$, which has **7** ones.

$$|K(2004, 2004)| = 2^7 - 1 = \boxed{127}$$
