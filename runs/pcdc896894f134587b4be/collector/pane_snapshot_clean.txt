## Solution by the Fourier Method

ns, or solution sketches. Proceeding.

### Step 1. Eigenfunction expansion

For Dirichlet boundary conditions on $(0,\pi)$, the eigenfunctions are $\{\sin(n
x)\}_{n=1}^{\infty}$ with eigenvalues $\lambda_n = n^2$. We seek

$$u(x,t) = \sum_{n=1}^{\infty} T_n(t)\,\sin(nx).$$

### Step 2. Expand the forcing term

The constant $1$ is expanded in a sine series on $(0,\pi)$:

$$1 = \sum_{n=1}^{\infty} b_n \sin(nx), \qquad b_n = \frac{2}{\pi}\int_0^{\pi}\s
in(nx)\,dx = \frac{2\bigl(1-(-1)^n\bigr)}{\pi n}.$$

Hence $b_n = \frac{4}{\pi n}$ for odd $n$, and $b_n = 0$ for even $n$.

### Step 3. ODEs for the time coefficients

Substituting into $u_{tt}+u_t = u_{xx}+1$ and matching coefficients of $\sin(nx)
$:

$$T_n'' + T_n' + n^2 T_n = b_n, \qquad T_n(0)=0,\quad T_n'(0)=0.$$

**Homogeneous solution.** The characteristic equation $r^2+r+n^2=0$ has roots

$$r = -\tfrac{1}{2} \pm i\,\omega_n, \qquad \omega_n = \tfrac{1}{2}\sqrt{4n^2-1}
 \quad (>0\text{ for }n\ge 1).$$

**Particular solution.** A constant particular solution gives $n^2 T_n^{(p)} = b
_n$, i.e. $T_n^{(p)} = b_n/n^2$.

**General solution:**

$$T_n(t) = e^{-t/2}\bigl(A_n\cos\omega_n t + B_n\sin\omega_n t\bigr) + \frac{b_n
}{n^2}.$$

### Step 4. Apply initial conditions

From $T_n(0)=0$: $\;A_n + b_n/n^2 = 0 \;\Longrightarrow\; A_n = -b_n/n^2$.

From $T_n'(0)=0$: $\;-\tfrac{1}{2}A_n + \omega_n B_n = 0 \;\Longrightarrow\; B_n
 = \dfrac{A_n}{2\omega_n} = -\dfrac{b_n}{2\,\omega_n\, n^2}$.

Therefore

$$T_n(t) = \frac{b_n}{n^2}\left[1 - e^{-t/2}\!\left(\cos\omega_n t + \frac{1}{2\
omega_n}\sin\omega_n t\right)\right].$$

### Step 5. Final solution

Substituting $b_n = \frac{2(1-(-1)^n)}{\pi n}$ and $\omega_n = \frac{\sqrt{4n^2-
1}}{2}$:

$$\boxed{\displaystyle u(x,t) = \sum_{n=1}^{\infty} \frac{2\bigl(1-(-1)^n\bigr)}
{\pi\, n^{3}}\left[1 - e^{-t/2}\!\left(\cos\!\Bigl(\tfrac{\sqrt{4n^2-1}}{2}\,t\B
igr) + \frac{1}{\sqrt{4n^2-1}}\sin\!\Bigl(\tfrac{\sqrt{4n^2-1}}{2}\,t\Bigr)\righ
t)\right]\sin(nx).}$$

Only odd harmonics survive, so equivalently with $n=2k-1$:

$$u(x,t) = \sum_{k=1}^{\infty} \frac{4}{\pi(2k-1)^{3}}\left[1 - e^{-t/2}\!\left(
\cos\omega_{2k-1}t + \frac{\sin\omega_{2k-1}t}{\sqrt{4(2k-1)^2-1}}\right)\right]
\sin\!\bigl((2k-1)x\bigr),$$

where $\omega_{2k-1} = \tfrac{1}{2}\sqrt{4(2k-1)^2-1}$.

### Verification

- **Boundary conditions:** Each $\sin(nx)$ vanishes at $x=0$ and $x=\pi$, so $u(
0,t)=u(\pi,t)=0$. ✓
- **Initial displacement:** $T_n(0)=0$ for all $n$, so $u(x,0)=0$. ✓
- **Initial velocity:** $T_n'(0)=0$ for all $n$, so $u_t(x,0)=0$. ✓
- **PDE:** Each $T_n$ satisfies $T_n''+T_n'+n^2T_n=b_n$ by construction, and the
 series reproduces $u_{xx}+1$. ✓
- **Steady state ($t\to\infty$):** The transient term decays as $e^{-t/2}$, leav
ing $u\to\sum_n \frac{b_n}{n^2}\sin(nx) = \sum_n \frac{2(1-(-1)^n)}{\pi n^3}\sin
(nx)$. One checks directly that this equals $\frac{x(\pi-x)}{2}$, which is the s
olution of $u_{ss}''=-1$ with $u_{ss}(0)=u_{ss}(\pi)=0$ — exactly the expected e
quilibrium. ✓
