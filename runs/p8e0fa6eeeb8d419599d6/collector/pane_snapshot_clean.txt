## Setting Up Coordinates

Since $ABCD$ is isosceles with $AD \parallel BC$, I place it symmetrically about

- $A = (-a, h)$, $D = (a, h)$ (top base $AD = 2a$)
- $B = (-b, 0)$, $C = (b, 0)$ (bottom base $BC = 2b$)

The equal legs are $AB = CD = \ell = \sqrt{(b-a)^2 + h^2}$, and the diagonals $A
C = BD = d = \sqrt{(a+b)^2 + h^2}$.

## Key Observation: $I$ and $J$ Share the Same $x$-Coordinate

**Incircle of $\triangle ABC$** (sides $2b, d, \ell$ opposite $A, B, C$): The ta
ngent point $P$ on $BC$ satisfies $BP = s_1 - AC$, giving
$$x_P = -b + s_1 - d = \frac{\ell - d}{2}.$$
Since $IP \perp BC$ and $PI = 8$, we get $I = \left(\frac{\ell-d}{2},\, 8\right)
$.

**Incircle of $\triangle ABD$** (sides $d, 2a, \ell$ opposite $A, B, D$): The ta
ngent point $Q$ on $AD$ satisfies $AQ = s_2 - BD$, giving
$$x_Q = -a + s_2 - d = \frac{\ell - d}{2}.$$
Since $JQ \perp AD$ and $JQ = 15$, we get $J = \left(\frac{\ell-d}{2},\, h-15\ri
ght)$.

**Both centers have the same $x$-coordinate**, so $IJ = |8 - (h-15)| = |23 - h|
= 25$, giving $h = 48$ (since $h > 0$).

## Finding $a$ and $b$

**Inradius of $\triangle ABC$:** Area $= 48b$, $s_1 = (2b + d + \ell)/2$, so $r_
1 = \frac{96b}{2b+d+\ell} = 8$ gives:
$$d + \ell = 10b. \quad (1)$$

**Inradius of $\triangle ABD$:** Area $= 48a$, $s_2 = (2a + d + \ell)/2$, so $r_
2 = \frac{96a}{2a+d+\ell} = 15$ gives:
$$d + \ell = \frac{22a}{5}. \quad (2)$$

From (1) and (2): $10b = \frac{22a}{5}$, so $a = \frac{25b}{11}$.

## Solving the System

With $a = 25b/11$ and $u = b/11$ (so $b = 11u$):
- $d = \sqrt{(36u)^2 + 48^2}$, $\ell = \sqrt{(14u)^2 + 48^2}$

$$1296u^2 + 2304 = 12100u^2 - 220u\ell + 196u^2 + 2304$$
$$220u\ell = 11000u^2 \implies \ell = 50u$$

Then $\ell^2 = 2500u^2 = 196u^2 + 2304$ gives $u^2 = 1$, so $u = 1$.

**Result:** $b = 11$, $a = 25$, $h = 48$.
