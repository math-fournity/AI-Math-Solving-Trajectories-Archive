Looking at this problem, I need to find the maximum length of a sequence on valu
es in $\{1, \ldots, n\}$ satisfying:
1. Every term's two neighbors differ: $a_{i-1} \neq a_{i+1}$ (so no run of lengt
h $\geq 3$).
2. No pattern $a_p = a_r \neq a_q = a_s$ with $p < q < r < s$ (no alternating su
bsequence $xyxy$).

**Answer: $4n - 2$.**

## Proof

### Upper Bound: $k \leq 4n - 2$

**Step 1: Runs have length at most 2.** If $a_{i-1} = a_i = a_{i+1}$, then the t
wo neighbors of $a_i$ are equal, violating condition 1. So every maximal run of
equal consecutive terms has length $\leq 2$.

**Step 2: Compress the sequence.** Replace each maximal run by a single copy of
its value, obtaining a compressed sequence $v_1, v_2, \ldots, v_m$ with $v_j \ne
q v_{j+1}$ (2-sparse) and $k \leq 2m$.

**Step 3: The compressed sequence avoids $xyxy$.** If $v_{i_1} = x, v_{i_2} = y,
 v_{i_3} = x, v_{i_4} = y$ with $i_1 < i_2 < i_3 < i_4$ and $x \neq y$, then pic
king one occurrence from each corresponding run in the original sequence gives p
ositions $p < q < r < s$ with $a_p = a_r = x \neq y = a_q = a_s$, contradicting
condition 2.

**Step 4: $m \leq 2n - 1$ (Davenport–Schinzel order 2 bound, proved by induction
).**

*Base case* $n = 1$: A 2-sparse sequence on one symbol has length $\leq 1 = 2(1)
-1$. ✓

*Inductive step:* Assume the bound for fewer than $n$ symbols. Let $v$ be the sy
mbol at position $m$ (last position), appearing at positions $j_1 < j_2 < \cdots
 < j_t = m$. The gaps $G_0 = (0, j_1)$, $G_i = (j_i, j_{i+1})$ for $1 \leq i \le
q t-1$ partition the other positions.

**Key claim:** Each symbol $w \neq v$ appears in at most one gap. If $w$ appeare
d in two gaps $G_i$ and $G_{i'}$ with $i < i'$, then $v$ at $j_i$, $w$ in $G_i$,
 $v$ at $j_{i+1}$, $w$ in $G_{i'}$ gives the pattern $v,w,v,w$ — contradiction.
(If $w$ appears before $j_1$ and in some $G_i$, then $w, v, w, v$ is formed — al
so forbidden.)

Let $n_i$ be the number of distinct symbols in gap $G_i$. Then $\sum n_i \leq n
- 1$. By 2-sparseness, each gap $G_1, \ldots, G_{t-1}$ is non-empty, so $n_i \ge
q 1$ for $i = 1, \ldots, t-1$. By induction, the subsequence in $G_i$ has length
 $\leq 2n_i - 1$.

$$m = t + \sum_{i=0}^{t-1} |G_i| \leq t + \sum_{i:\, n_i \geq 1}(2n_i - 1) \leq
t + 2(n-1) - (t-1) = 2n - 1.$$

**Step 5:** Therefore $k \leq 2m \leq 2(2n - 1) = 4n - 2$.

### Lower Bound: Construction achieving $4n - 2$

Double each term of $1, 2, 3, \ldots, n, n-1, \ldots, 2, 1$:

$$1,1,\; 2,2,\; 3,3,\; \ldots,\; n,n,\; (n{-}1),(n{-}1),\; \ldots,\; 2,2,\; 1,1$
$

This has length $2n + 2(n-1) = 4n - 2$.

**Condition 1 holds:** At every position with two neighbors, the neighbors diffe
r. Within a doubled block $\ldots, j, j, \ldots$, the first $j$ has neighbors $j
 \mp 1$ and $j$ (which differ), and the second $j$ has neighbors $j$ and $j \mp
1$ (which differ). At the peak $n, n$, neighbors are $n-1, n$ and $n, n-1$ respe
ctively — both pairs differ.

**Condition 2 holds:** The compressed sequence is $1, 2, 3, \ldots, n, n-1, \ldo
ts, 2, 1$. For any $x < y$, the occurrences appear in order $x, y, y, x$ (since
$x$ is at positions $x$ and $2n - x$, while $y$ is at positions $y$ and $2n - y$
, and $x < y < 2n - y < 2n - x$). This is the pattern $xyyx$, never $xyxy$. Sinc
e the compressed sequence avoids $xyxy$, the original doubled sequence does too.

### Conclusion

The maximum value of $k$ is $\boxed{4n - 2}$.
