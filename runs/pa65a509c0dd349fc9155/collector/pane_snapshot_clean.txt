Looking at this problem, I need to find the dihedral angle between faces OAB and
 OBC of pyramid OABCD.

## Setting Up Coordinates

Place square base ABCD in the z=0 plane, centered at origin:
- A = (a, a, 0), B = (−a, a, 0), C = (−a, −a, 0), D = (a, −a, 0)
- Apex O = (0, 0, h) above the center (guaranteeing OA = OB = OC = OD by symmetr
y)

## Finding h from ∠AOB = 45°

Vectors OA = (a, a, −h), OB = (−a, a, −h).

$$\cos(\angle AOB) = \frac{OA \cdot OB}{|OA||OB|} = \frac{-a^2 + a^2 + h^2}{2a^2
 + h^2} = \frac{h^2}{2a^2 + h^2} = \frac{\sqrt{2}}{2}$$

Solving: $2h^2 = \sqrt{2}(2a^2 + h^2)$, so $h^2(2-\sqrt{2}) = 2\sqrt{2}\,a^2$, g
iving

$$h^2 = \frac{2\sqrt{2}\,a^2}{2-\sqrt{2}} = \frac{2\sqrt{2}\,a^2(2+\sqrt{2})}{2}
 = 2a^2(1+\sqrt{2})$$

## Computing the Dihedral Angle

**Face OAB normal:** $n_1 = OA \times OB = (0,\, 2ah,\, 2a^2) \propto (0, h, a)$

**Face OBC normal:** $n_2 = OB \times OC = (-2ah,\, 0,\, 2a^2) \propto (-h, 0, a
)$

Both normals point outward (n₁ has +y component, matching face OAB on the y>0 si
de; n₂ has −x component, matching face OBC on the x<0 side).

The angle φ between outward normals satisfies $\cos\varphi = \pi - \theta$, so $
\cos\theta = -\cos\varphi$.

$$\cos\varphi = \frac{n_1 \cdot n_2}{|n_1||n_2|} = \frac{0\cdot(-h) + h\cdot 0 +
 a\cdot a}{h^2+a^2} = \frac{a^2}{h^2+a^2}$$

With $h^2 + a^2 = 2a^2(1+\sqrt{2}) + a^2 = a^2(3+2\sqrt{2})$:

$$\cos\theta = -\frac{a^2}{a^2(3+2\sqrt{2})} = -\frac{1}{3+2\sqrt{2}}$$

## Rationalizing

$$\cos\theta = -\frac{1}{3+2\sqrt{2}} \cdot \frac{3-2\sqrt{2}}{3-2\sqrt{2}} = -\
frac{3-2\sqrt{2}}{9-8} = -(3-2\sqrt{2}) = -3 + 2\sqrt{2} = -3 + \sqrt{8}$$

## Verification of Limits

- **h → 0** (∠AOB → 90°): $\cos\theta \to -a^2/a^2 = -1$, so θ → 180° (faces cop
lanar). ✓
- **h → ∞** (∠AOB → 0°): $\cos\theta \to 0$, so θ → 90° (faces become vertical p
erpendicular planes). ✓

## Result

With $\cos\theta = m + \sqrt{n} = -3 + \sqrt{8}$, we have $m = -3$ and $n = 8$.

$$m + n = -3 + 8 = 5$$

Final Answer: $\boxed{5}$
