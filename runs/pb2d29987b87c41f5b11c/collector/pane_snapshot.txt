## Proof

**Reformulation.** A partition $n = a_1 + \cdots + a_k$ with $a_1 \leq \cdots \l
eq a_k \leq a_1 + 1$ means every part equals either $q := a_1$ or $q+1$, for som
e $q \geq 1$. Writing $j$ for the number of parts equal to $q+1$ and $i = k - j$
 for the number equal to $q$, we get
$$n = i \cdot q + j \cdot (q+1) = kq + j, \qquad 0 \le j \le k,\quad q \ge 1,\qu
ad k \ge 1.$$

**Removing double-counting.** The representation with $j = k$ (all parts $= q+1$
) is identical to the representation with $q' = q+1$, $j' = 0$. To make the repr
esentation unique, require $0 \le j \le k-1$, i.e., **at least one part equals t
he minimum $q$**. Then every valid partition has a unique triple $(k, q, j)$ wit
h
$$n = kq + j,\qquad k \ge 1,\; q \ge 1,\; 0 \le j \le k-1.$$

**Counting.** Fix $k$ with $1 \le k \le n$. Set $q = \lfloor n/k \rfloor$ and $j
 = n - kq = n \bmod k$. Then:
- $q \ge 1$ since $k \le n$,
- $0 \le j \le k-1$ since $j$ is the remainder upon dividing $n$ by $k$,
- $n = kq + j$ by construction.

So each $k \in \{1, 2, \dots, n\}$ yields exactly one valid triple $(k, q, j)$,
hence one valid partition.

Conversely, any valid triple $(k, q, j)$ satisfies $n = kq + j$ with $0 \le j \l
e k-1$, which forces $q = \lfloor n/k \rfloor$ and $j = n \bmod k$ (since $kq \l
e n < kq + k = k(q+1)$). So the map $k \mapsto (k, \lfloor n/k\rfloor, n \bmod k
)$ is a **bijection** from $\{1, 2, \dots, n\}$ to the set of valid partitions.

**Verification with $n = 4$:**

| $k$ | $q = \lfloor 4/k \rfloor$ | $j = 4 \bmod k$ | Partition |
|-----|---------------------------|------------------|-----------|
| 1 | 4 | 0 | $4$ |
| 2 | 2 | 0 | $2+2$ |
| 3 | 1 | 1 | $1+1+2$ |
| 4 | 1 | 0 | $1+1+1+1$ |

This gives exactly the four partitions listed, confirming the count is $n = 4$.

**Conclusion.** The number of ways to write $n$ as such a sum is $\boxed{n}$.
