We wish to compute
$$S = \sum_{\substack{n=3 \\ n \text{ odd}}}^{\infty} \bigl(\zeta(n) - 1\bigr) =
 \sum_{k=1}^{\infty} \bigl(\zeta(2k+1) - 1\bigr).$$

**Step 1: Expand and interchange summations.**

Using $\zeta(n) - 1 = \sum_{m=2}^{\infty} \frac{1}{m^n}$,
$$S = \sum_{k=1}^{\infty} \sum_{m=2}^{\infty} \frac{1}{m^{2k+1}}.$$
Since every term is positive, Tonelli's theorem permits swapping the order:
$$S = \sum_{m=2}^{\infty} \sum_{k=1}^{\infty} \frac{1}{m^{2k+1}} = \sum_{m=2}^{\
infty} \frac{1}{m}\sum_{k=1}^{\infty} \frac{1}{m^{2k}}.$$

**Step 2: Evaluate the inner geometric series.**

For $m \geq 2$, $\frac{1}{m^2} < 1$, so
$$\sum_{k=1}^{\infty} \frac{1}{m^{2k}} = \frac{1/m^{2}}{1 - 1/m^{2}} = \frac{1}{
m^{2}-1}.$$
Hence
$$S = \sum_{m=2}^{\infty} \frac{1}{m(m^{2}-1)} = \sum_{m=2}^{\infty} \frac{1}{m(
m-1)(m+1)}.$$

**Step 3: Partial fraction decomposition.**

$$\frac{1}{m(m-1)(m+1)} = -\frac{1}{m} + \frac{1}{2(m-1)} + \frac{1}{2(m+1)},$$
which is verified by combining the right-hand side over a common denominator:
$$\frac{-2(m-1)(m+1) + m(m+1) + m(m-1)}{2m(m-1)(m+1)} = \frac{-2m^{2}+2+m^{2}+m+
m^{2}-m}{2m(m^{2}-1)} = \frac{2}{2m(m^{2}-1)}.$$

**Step 4: Telescope via partial sums.**

Let $S_N = \sum_{m=2}^{N}\left(-\frac{1}{m} + \frac{1}{2(m-1)} + \frac{1}{2(m+1)
}\right)$. Reindexing,
$$S_N = -\sum_{m=2}^{N}\frac{1}{m} + \frac{1}{2}\sum_{j=1}^{N-1}\frac{1}{j} + \f
rac{1}{2}\sum_{j=3}^{N+1}\frac{1}{j}.$$
Writing $H_n = \sum_{j=1}^{n}\frac{1}{j}$,
$$S_N = -(H_N - 1) + \tfrac{1}{2}H_{N-1} + \tfrac{1}{2}\!\left(H_{N+1} - 1 - \tf
rac{1}{2}\right) = -H_N + \tfrac{1}{2}H_{N-1} + \tfrac{1}{2}H_{N+1} + \tfrac{1}{
4}.$$
Using $H_{N-1} = H_N - \frac{1}{N}$ and $H_{N+1} = H_N + \frac{1}{N+1}$,
$$S_N = -H_N + \tfrac{1}{2}\!\left(H_N - \tfrac{1}{N}\right) + \tfrac{1}{2}\!\le
ft(H_N + \tfrac{1}{N+1}\right) + \tfrac{1}{4} = \left(-1+\tfrac{1}{2}+\tfrac{1}{
2}\right)H_N - \tfrac{1}{2N} + \tfrac{1}{2(N+1)} + \tfrac{1}{4}.$$
The harmonic terms cancel exactly, leaving
$$S_N = \frac{1}{4} - \frac{1}{2N} + \frac{1}{2(N+1)} = \frac{1}{4} - \frac{1}{2
N(N+1)}.$$

**Step 5: Take the limit.**

As $N \to \infty$, the remainder $\frac{1}{2N(N+1)} \to 0$, so
$$S = \lim_{N\to\infty} S_N = \frac{1}{4}.$$

**Conclusion.**
$$\boxed{\displaystyle\sum_{\substack{n=3 \\ n \text{ odd}}}^{\infty} \bigl(\zet
a(n) - 1\bigr) = \frac{1}{4}}.$$
