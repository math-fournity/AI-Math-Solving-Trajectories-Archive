## Solution

**Leak check:** The problem statement contains no leaked answers, solutions, or
solution sketches.

**Goal:** Find $S = 2^3 + 3^4 + 5^4 + 7^4 + \cdots + 17497^4 \pmod{240}$, where
the sum is over the fourth powers of the first $2014$ primes.

Note: $240 = 2^4 \cdot 3 \cdot 5 = 16 \cdot 15$. By CRT we compute $S \bmod 16$,
 $S \bmod 3$, and $S \bmod 5$.

---

### $S \bmod 3$

For every prime $p \neq 3$: $p \not\equiv 0 \pmod 3$, so by Fermat $p^2 \equiv 1
 \pmod 3$, hence $p^4 \equiv 1 \pmod 3$.
For $p = 3$: $3^4 \equiv 0 \pmod 3$.

Among the $2014$ primes, exactly one is $3$ (contributes $0$); the other $2013$
each contribute $1$.

$$S \equiv 2013 \equiv 0 \pmod 3.$$

### $S \bmod 5$

For every prime $p \neq 5$: by Fermat, $p^4 \equiv 1 \pmod 5$.
For $p = 5$: $5^4 \equiv 0 \pmod 5$.

Among the $2014$ primes, exactly one is $5$ (contributes $0$); the other $2013$
each contribute $1$.

$$S \equiv 2013 \equiv 3 \pmod 5.$$

### $S \bmod 16$

For every **odd** prime $p$: write $p = 2k+1$. Then
$$p^2 = 4k(k+1) + 1.$$
Since $k(k+1)$ is even, $4k(k+1) \equiv 0 \pmod 8$, so $p^2 \equiv 1 \pmod 8$. W
riting $p^2 = 8m+1$,
$$p^4 = (8m+1)^2 = 64m^2 + 16m + 1 = 16m(4m+1) + 1 \equiv 1 \pmod{16}.$$

(Verified: $3^4=81\equiv1$, $5^4=625\equiv1$, $7^4=2401\equiv1 \pmod{16}$.)

For $p = 2$: $2^4 = 16 \equiv 0 \pmod{16}$.

Among the $2014$ primes, exactly one is $2$ (contributes $0$); the other $2013$
(all odd) each contribute $1$.

$$S \equiv 2013 \equiv 13 \pmod{16}.$$

---

### Combining via CRT

We need $S$ satisfying:
- $S \equiv 0 \pmod 3$
- $S \equiv 3 \pmod 5$
- $S \equiv 13 \pmod{16}$

From $S \equiv 0 \pmod 3$ and $S \equiv 3 \pmod 5$: $S = 5k+3$ with $5k+3 \equiv
 0 \pmod 3 \Rightarrow k \equiv 0 \pmod 3$, so $k = 3j$ and $S = 15j + 3$, i.e.
$S \equiv 3 \pmod{15}$.

Now $15j + 3 \equiv 13 \pmod{16} \Rightarrow 15j \equiv 10 \pmod{16}$. Since $15
 \equiv -1 \pmod{16}$: $-j \equiv 10 \pmod{16} \Rightarrow j \equiv 6 \pmod{16}$
.

So $j = 16m + 6$ and
$$S = 15(16m+6) + 3 = 240m + 90 + 3 = 240m + 93.$$

**Verification:** $93 \bmod 3 = 0$ ✓, $93 \bmod 5 = 3$ ✓, $93 \bmod 16 = 13$ ✓.

$$\boxed{S \equiv 93 \pmod{240}}.$$
