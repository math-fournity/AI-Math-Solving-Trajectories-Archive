# Solution

We seek the remainder of $2004^{2003^{2002^{2001}}}$ upon division by $1000$.

## Setup via CRT

Since $1000 = 8 \times 125$ with $\gcd(8,125)=1$, we compute the residue modulo
$8$ and modulo $125$ separately, then recombine.

Note $2004 \equiv 4 \pmod{8}$ and $2004 \equiv 4 \pmod{125}$. Let $E = 2003^{200
2^{2001}}$. We need $4^E \bmod 8$ and $4^E \bmod 125$.

## Modulo 8

$4^1 \equiv 4 \pmod{8}$ and $4^2 = 16 \equiv 0 \pmod{8}$. Since $E \geq 2$ (inde
ed $E$ is enormous),
$$4^E \equiv 0 \pmod{8}.$$

## Modulo 125

Since $\gcd(4,125)=1$, Euler's theorem gives $4^{100}\equiv 1 \pmod{125}$ (as $\
varphi(125)=100$). So we need $E \bmod 100$.

**Computing $E \bmod 100$:** $2003 \equiv 3 \pmod{100}$, so $E \equiv 3^{2002^{2
001}} \pmod{100}$.

Use CRT with $100 = 4 \times 25$:
- **Mod 4:** $3^2 \equiv 1 \pmod 4$, and $2002^{2001}$ is even, so $3^{2002^{200
1}} \equiv 1 \pmod{4}$.
- **Mod 25:** $\varphi(25)=20$, so we need $2002^{2001} \bmod 20$. Now $2002 \eq
uiv 2 \pmod{20}$, so $2002^{2001}\equiv 2^{2001}\pmod{20}$.

  For $2^{2001}\bmod 20$: mod 4 gives $0$ (since $2001\geq 2$); mod 5 gives $2^{
2001}\equiv 2^{2001\bmod 4}=2^1=2\pmod 5$. CRT ($x\equiv 0\pmod 4,\ x\equiv 2\pm
od 5$) yields $x=12$. So $2002^{2001}\equiv 12\pmod{20}$.

  Hence $3^{2002^{2001}}\equiv 3^{12}\pmod{25}$. Compute: $3^4=81\equiv 6$, $3^8
\equiv 36\equiv 11$, $3^{12}=3^8\cdot 3^4\equiv 11\cdot 6=66\equiv 16\pmod{25}$.

Combining: $x\equiv 16\pmod{25}$ and $x\equiv 1\pmod 4$. Writing $x=25k+16$: $25
k+16\equiv k+0\equiv 1\pmod 4$, so $k\equiv 1\pmod 4$, giving $x=41$.

Thus $E \equiv 41 \pmod{100}$, and
$$4^E \equiv 4^{41} \pmod{125}.$$

**Computing $4^{41}\bmod 125$:** Using repeated squaring,
- $4^2 = 16$
- $4^4 = 256 \equiv 6 \pmod{125}$
- $4^8 \equiv 36 \pmod{125}$
- $4^{16} \equiv 36^2 = 1296 \equiv 46 \pmod{125}$
- $4^{32} \equiv 46^2 = 2116 \equiv 116 \pmod{125}$

Since $41 = 32+8+1$:
$$4^{41} \equiv 116\cdot 36\cdot 4 \pmod{125}.$$
$116\cdot 36 = 4176 \equiv 51\pmod{125}$, and $51\cdot 4 = 204 \equiv 79\pmod{12
5}$.

So $4^E \equiv 79 \pmod{125}$.

## Recombine via CRT

We need $x\bmod 1000$ with $x\equiv 0\pmod 8$ and $x\equiv 79\pmod{125}$.

Write $x = 125k + 79$. Then $125k+79\equiv 5k+7\equiv 0\pmod 8$, so $5k\equiv 1\
pmod 8$. Since $5^{-1}\equiv 5\pmod 8$, $k\equiv 5\pmod 8$. Taking $k=5$:
$$x = 125\cdot 5 + 79 = 625 + 79 = 704.$$

**Verification:** $704 = 88\cdot 8$, so $704\equiv 0\pmod 8$ ✓; $704 = 5\cdot 12
5 + 79$, so $704\equiv 79\pmod{125}$ ✓.

## Answer

The remainder when $2004^{2003^{2002^{2001}}}$ is divided by $1000$ is $\boxed{7
04}$.
