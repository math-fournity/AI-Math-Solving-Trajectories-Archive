## 证明

**第一步：确定 A 和 B。**

A(1, t) 和 B(s, 2) 关于原点中心对称，因此 B = -A，得出 (s, 2) = (-1, -t)，所以 *
*s = -1, t = -2**。因此 A = (1, -2)，B = (-1, 2)。

**第二步：将 AP · BP 表示为关于 P 的函数。**

$$\overrightarrow{AP}\cdot\overrightarrow{BP} = (x-1,\, y+2)\cdot(x+1,\, y-2) =
(x^2-1)+(y^2-4) = x^2+y^2-5.$$

因此，我们需要在 P 的轨迹上**最小化 $x^2+y^2$**。

**第三步：求轨迹（关于 $a$ 的参数方程）。**

对于固定的 $a$，该系统最多只有有限个解，因此“轨迹”是当 $a$ 变化时由 P 描出的轨迹
曲线。根据方程 1：$y = \dfrac{a^2 x}{ax+1}$。代入方程 2 并化简：

$$x\bigl[a^4+1+ax(a^2+1)\bigr]=0.$$

因此，要么 $x=0$（平凡原点解，对所有 $a$ 都成立，这是一个不属于连续轨迹的孤立点
），要么

$$x = -\frac{a^4+1}{a(a^2+1)}, \qquad y = \frac{a^4+1}{a(a^2-1)} \quad (a\neq 0,
\; a^2\neq 1).$$

**第四步：消去 $a$ 以获得隐式曲线。**

设 $u=1/x,\; v=1/y$。则

$$u = -\frac{a(a^2+1)}{a^4+1},\qquad v = \frac{a(a^2-1)}{a^4+1}.$$

计算 $u+v = \dfrac{2a^3}{a^4+1}$ 和 $v-u = -\dfrac{2a}{a^4+1}$，得到 $\dfrac{u+v
}{v-u} = -a^2$。利用 $(v-u)^2 = \dfrac{4a^2}{(a^4+1)^2}$ 并消去 $a$，得到：

$$(u^2+v^2)^2 = u^2 - v^2, \quad\text{i.e.,}\quad (x^2+y^2)^2 = x^2 y^2 (y^2 - x
^2).$$

**第五步：最小化 $r^2 = x^2 + y^2$。**

根据参数方程：

$$r^2 = x^2+y^2 = \frac{2(a^4+1)^3}{a^2(a^2+1)^2(a^2-1)^2}.$$

设 $b = a^2 > 0$ ($b\neq 1$)：

$$f(b) = \frac{2(b^2+1)^3}{b\,(b+1)^2(b-1)^2}.$$

边界情况：当 $b\to 0^+, 1, \infty$ 时，$f(b)\to\infty$，因此任何临界点都是全局最
小值。

对数微分法：$\dfrac{d}{db}\ln f = \dfrac{6b}{b^2+1} - \dfrac{1}{b} - \dfrac{2}{b
+1} - \dfrac{2}{b-1} = 0$，化简为：

$$\frac{6b}{b^2+1} = \frac{1}{b} + \frac{4b}{b^2-1}.$$

乘以 $b(b^2+1)(b^2-1)$：

$$6b^2(b^2-1) = (b^4-1) + 4b^2(b^2+1) \;\Longrightarrow\; b^4 - 10b^2 + 1 = 0.$$

因此 $b^2 = 5 \pm 2\sqrt{6} = (\sqrt{3}\pm\sqrt{2})^2$，得到 $b = \sqrt{3}+\sqrt
{2}$ 或 $b = \sqrt{3}-\sqrt{2}$（互为倒数）。由于 $f(b) = f(1/b)$，两者得出相同
的值。

**第六步：计算 $f$ 在 $b^2 = 5+2\sqrt{6}$ 处的值。**

$b^2+1 = 6+2\sqrt{6} = 2(3+\sqrt{6})$, $b^2-1 = 4+2\sqrt{6} = 2(2+\sqrt{6})$, $b
 = \sqrt{3}+\sqrt{2}$.

$$f = \frac{2(b^2+1)^3}{b\,(b^2-1)^2} = \frac{2(6+2\sqrt{6})^3}{(\sqrt{3}+\sqrt{
2})(4+2\sqrt{6})^2}.$$

计算分子：$(6+2\sqrt{6})^3 = 8(3+\sqrt{6})^3 = 8(81+33\sqrt{6}) = 648+264\sqrt{6
}$，因此分子 $= 1296+528\sqrt{6} = 24(54+22\sqrt{6})$。

分母：$(4+2\sqrt{6})^2 = 40+16\sqrt{6} = 8(5+2\sqrt{6})$，因此分母 $= 8(\sqrt{3}
+\sqrt{2})(5+2\sqrt{6}) = 8(72\sqrt{3}/... )$ —— 直接计算：

$$(\sqrt{3}+\sqrt{2})(40+16\sqrt{6}) = 40\sqrt{3}+40\sqrt{2}+16\sqrt{18}+16\sqrt
{12} = 72\sqrt{3}+88\sqrt{2} = 8(9\sqrt{3}+11\sqrt{2}).$$

所以 $f = \dfrac{24(54+22\sqrt{6})}{8(9\sqrt{3}+11\sqrt{2})} = \dfrac{3(54+22\sq
rt{6})}{9\sqrt{3}+11\sqrt{2}}$.

有理化：乘以 $\dfrac{9\sqrt{3}-11\sqrt{2}}{9\sqrt{3}-11\sqrt{2}}$，其中 $(9\sqrt
{3})^2-(11\sqrt{2})^2 = 243-242 = 1$：

$$(54+22\sqrt{6})(9\sqrt{3}-11\sqrt{2}) = 486\sqrt{3}-594\sqrt{2}+198\sqrt{18}-2
42\sqrt{12}$$
$$= 486\sqrt{3}-594\sqrt{2}+594\sqrt{2}-484\sqrt{3} = 2\sqrt{3}.$$

因此 $f = 3 \cdot 2\sqrt{3} = 6\sqrt{3}$.

**数值验证：** 在 $a^2 = \sqrt{3}+\sqrt{2} \approx 3.146$ 时，得到 $x \approx -1
.482$, $y \approx 2.863$, $x^2+y^2 \approx 10.392 = 6\sqrt{3}$. ✓

在 $a = 2$ 时：$x^2+y^2 \approx 10.918 > 10.392$. ✓

**第七步：结论。**

在轨迹上 $x^2+y^2$ 的最小值为 $6\sqrt{3}$，因此：

$$\min\,\overrightarrow{AP}\cdot\overrightarrow{BP} = 6\sqrt{3} - 5.$$
