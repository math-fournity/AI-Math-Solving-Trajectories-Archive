## Proof

Let $b_0 = 1$ and let $B_1 < B_2 < B_3 < \cdots$ be the distinct values attained
 by the sequence $(b_n)$. Since $b_n = \operatorname{lcm}(a_1,\dots,a_n) \ge a_n
$ and $a_n \to \infty$ (as $(a_n)$ is strictly increasing in positive integers),
 we have $b_n \to \infty$; hence there are infinitely many distinct values $B_k$
, and $B_k \to \infty$.

**Step 1. The distinct values grow at least geometrically.**

Let $N_k$ be the first index with $b_{N_k} = B_k$. Then $b_{N_k-1} = B_{k-1}$ an
d
$$B_k = \operatorname{lcm}(B_{k-1},\, a_{N_k}).$$
Since the lcm strictly increases at this step, $a_{N_k}\nmid B_{k-1}$, so
$$\frac{B_k}{B_{k-1}} = \frac{a_{N_k}}{\gcd(a_{N_k},B_{k-1})} \ge 2$$
(an integer strictly larger than $1$). With $B_1 \ge a_1 \ge 1$, induction gives
$$B_k \ge 2^{k-1}. \tag{1}$$

**Step 2. Bounding the multiplicity of each value.**

For every $n$ with $b_n = B_k$, we have $a_n \mid b_n = B_k$ (because $b_n$ is a
 common multiple of $a_1,\dots,a_n$). The $a_n$ are pairwise distinct (strictly
increasing), so the number of indices $n$ with $b_n = B_k$ is at most the number
 of positive divisors $d(B_k)$ of $B_k$:
$$\#\{n : b_n = B_k\} \le d(B_k). \tag{2}$$

**Step 3. Estimating the sum.**

Regrouping the sum by the value of $b_n$ and using (2),
$$\sum_{n=1}^{\infty}\frac{1}{b_n} = \sum_{k\ge 1}\sum_{\substack{n:\\ b_n=B_k}}
\frac{1}{B_k} = \sum_{k\ge 1}\frac{\#\{n:b_n=B_k\}}{B_k} \le \sum_{k\ge 1}\frac{
d(B_k)}{B_k}.$$

Using the standard divisor bound $d(m)\le 2\sqrt{m}$ (divisors pair as $(d,m/d)$
 with $d\le\sqrt m$) together with (1),
$$\frac{d(B_k)}{B_k} \le \frac{2\sqrt{B_k}}{B_k} = \frac{2}{\sqrt{B_k}} \le \fra
c{2}{\sqrt{2^{k-1}}} = 2^{1-(k-1)/2}.$$

Therefore
$$\sum_{n=1}^{\infty}\frac{1}{b_n} \le \sum_{k\ge 1} 2^{1-(k-1)/2} = 2\sum_{j\ge
 0}2^{-j/2} = \frac{2}{1-1/\sqrt{2}} < \infty.$$

The series converges. $\blacksquare$
