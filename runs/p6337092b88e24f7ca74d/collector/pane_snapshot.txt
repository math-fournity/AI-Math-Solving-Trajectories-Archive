## Proof

Let $x_1, x_2, \ldots, x_n$ be independent random variables, each uniformly dist
ributed on $[0,1]$. The given $n$-fold integral equals the expectation

$$I_n = \mathbb{E}\!\left[\cos^2\!\left(\frac{\pi}{2n}(x_1+x_2+\cdots+x_n)\right
)\right].$$

**Step 1: Reduce via the double-angle identity.** Using $\cos^2\theta = \tfrac{1
}{2}(1+\cos 2\theta)$,

$$I_n = \frac{1}{2}\left(1 + \mathbb{E}\!\left[\cos\!\left(\frac{\pi}{n}(x_1+x_2
+\cdots+x_n)\right)\right]\right).$$

Set $S_n = x_1+\cdots+x_n$ and $Y_n = S_n/n$. Then

$$I_n = \frac{1}{2}\Bigl(1 + \mathbb{E}\bigl[\cos(\pi\, Y_n)\bigr]\Bigr).$$

**Step 2: Show $Y_n \to \tfrac12$ in probability.** Since $\mathbb{E}[x_i]=\tfra
c12$ and $\operatorname{Var}(x_i)=\tfrac{1}{12}$,

$$\mathbb{E}[Y_n] = \frac{1}{n}\cdot n\cdot\frac12 = \frac12, \qquad \operatorna
me{Var}(Y_n) = \frac{1}{n^2}\cdot n\cdot\frac{1}{12} = \frac{1}{12n}.$$

By Chebyshev's inequality, for any $\varepsilon>0$,

$$\Pr\!\left(\left|Y_n - \tfrac12\right|\ge \varepsilon\right) \le \frac{\operat
orname{Var}(Y_n)}{\varepsilon^2} = \frac{1}{12n\varepsilon^2}\xrightarrow[n\to\i
nfty]{}0.$$

Hence $Y_n \to \tfrac12$ in probability, and therefore $\cos(\pi Y_n)\to\cos(\pi
/2)=0$ in probability (continuity of cosine).

**Step 3: Exchange limit and expectation.** Since $\left|\cos(\pi Y_n)\right|\le
 1$ for all $n$, the random variables $\cos(\pi Y_n)$ are uniformly bounded. By
the Bounded Convergence Theorem (equivalently, dominated convergence with domina
ting function $g\equiv 1$),

$$\lim_{n\to\infty}\mathbb{E}\bigl[\cos(\pi Y_n)\bigr] = \mathbb{E}\!\left[\lim_
{n\to\infty}\cos(\pi Y_n)\right] = \mathbb{E}[0] = 0.$$

**Step 4: Conclude.**

$$\lim_{n\to\infty} I_n = \frac{1}{2}\bigl(1 + 0\bigr) = \frac{1}{2}.$$
