## Setting Up the Polynomial

Rewriting: $t^4 + at^3 + bt^2 - 2(a+b)t + (a+b) = 0$.

By Vieta's formulas for the monic polynomial $t^4 + c_1 t^3 + c_2 t^2 + c_3 t +
c_4$:

- **Sum of roots:** $e_1 = -a = 14 \Rightarrow a = -14$
- **Product of roots:** $e_4 = a+b = 16 \Rightarrow b = 30$
- **Second elementary symmetric sum:** $e_2 = b = 30$
- **Third elementary symmetric sum:** $e_3 = 2(a+b) = 32$

So the polynomial is $t^4 - 14t^3 + 30t^2 - 32t + 16 = 0$ with $e_1=14,\ e_2=30,
\ e_3=32,\ e_4=16$.
