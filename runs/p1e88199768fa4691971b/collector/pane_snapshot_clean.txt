# Number of Conjugacy Classes in $GL(3,q)$

## Setup: parametrization by elementary divisors

Conjugacy classes in $GL(n,\mathbb{F}_q)$ are parametrized by **elementary divis
ors**: to each monic irreducible polynomial $f \in \mathbb{F}_q[x]$ with $f \neq
 x$ we assign a partition $\lambda_f$, subject to
$$\sum_{f\neq x} \deg(f)\,|\lambda_f| = n.$$
The exclusion of $f=x$ reflects that invertible matrices have no zero eigenvalue
. This is the rational canonical form classification restricted to $GL(n,q)$.

## Generating function

Let $k_n = k(GL(n,q))$. The partition-generating identity $\sum_{\lambda} t^{|\l
ambda|} = \prod_{j\ge 1}(1-t^j)^{-1}$ gives
$$\sum_{n\ge 0} k_n\, x^n = \prod_{\substack{f\text{ monic irred}\\ f\neq x}} \p
rod_{j\ge 1}\bigl(1 - x^{j\deg f}\bigr)^{-1}.$$

Let $N_d(q)$ be the number of monic irreducibles of degree $d$ over $\mathbb{F}_
q$:
$$N_d(q) = \frac{1}{d}\sum_{e\mid d}\mu(e)\,q^{d/e}.$$
For $d=1$, excluding $x$ leaves $N_1(q)-1 = q-1$ polynomials. Grouping the produ
ct by degree:
$$G(x) = \prod_{j\ge 1}(1-x^j)^{-(q-1)}\;\cdot\;\prod_{d\ge 2}\prod_{j\ge 1}(1-x
^{jd})^{-N_d(q)}.$$

## Extracting $[x^3]$

Only factors with $jd \le 3$ contribute to the coefficient of $x^3$:
- first product: $j=1,2,3$,
- $d=2$: only $j=1$ (gives $x^2$; $j=2$ gives $x^4$),
- $d=3$: only $j=1$ (gives $x^3$),
- $d\ge 4$: $x^d \ge x^4$, no contribution.

With $N_2(q) = \tfrac{q^2-q}{2}$ and $N_3(q) = \tfrac{q^3-q}{3}$,
$$G(x) \equiv (1-x)^{-(q-1)}(1-x^2)^{-(q-1+N_2)}(1-x^3)^{-(q-1+N_3)} \pmod{x^4}.
$$

Set
$$A = q-1,\quad B = q-1+N_2 = \frac{(q-1)(q+2)}{2},\quad C = q-1+N_3 = \frac{(q-
1)(q^2+q+3)}{3}.$$

Expanding:
- $(1-x)^{-A} = 1 + Ax + \tfrac{A(A+1)}{2}x^2 + \tfrac{A(A+1)(A+2)}{6}x^3 + \cdo
ts$
- $(1-x^2)^{-B} = 1 + Bx^2 + \cdots$
- $(1-x^3)^{-C} = 1 + Cx^3 + \cdots$

The coefficient of $x^3$ receives three contributions:
$$k_3 = \frac{A(A+1)(A+2)}{6} + A\,B + C.$$

## Simplification

Factor out $(q-1)$:
$$k_3 = (q-1)\left[\frac{q(q+1)}{6} + \frac{(q-1)(q+2)}{2} + \frac{q^2+q+3}{3}\r
ight].$$

Common denominator $6$:
$$\text{bracket} = \frac{q(q+1) + 3(q-1)(q+2) + 2(q^2+q+3)}{6}.$$
Computing each:
- $q(q+1) = q^2+q$,
- $3(q-1)(q+2) = 3q^2+3q-6$,
- $2(q^2+q+3) = 2q^2+2q+6$.

Sum $= (1+3+2)q^2 + (1+3+2)q + (-6+6) = 6q^2+6q = 6q(q+1)$.

Therefore
$$k_3 = (q-1)\cdot\frac{6q(q+1)}{6} = (q-1)\,q\,(q+1) = q^3 - q.$$

## Verification

- $q=2$: $k(GL(3,2)) = 8-2 = 6$. Indeed $GL(3,2)\cong PSL(2,7)$ has $6$ conjugac
y classes. ✓
- $q=3$: $k(GL(3,3)) = 27-3 = 24$, matching the known value. ✓

## Result

The number of conjugacy classes in $GL(3,q)$ is

$$\boxed{q^3 - q}.$$
