## 解答

**问题** asks whether Poisson's formula can be used to find a unique solution fo
r the Dirichlet problem of the Laplace equation in **R**^n when n > 2.

**答案：可以。** Poisson 公式可以推广到 n > 2 的情形，并且给出唯一的解。

---

### 证明

**设定。** 设 B_R = {x ∈ R^n : |x| < R} 为半径为 R 的球，f : ∂B_R → R 为连续函数
。Dirichlet 问题是：求 u ∈ C²(B_R) ∩ C(B̄_R) 使得

Δu = 0 in B_R,    u = f on ∂B_R.

**n > 2 时的 Poisson 核。** 定义 Poisson 核为

$$P_R(x, \zeta) = \frac{R^2 - |x|^2}{\omega_n\, R\, |x - \zeta|^n}, \qquad x \in
 B_R,\; \zeta \in \partial B_R,$$

其中 ω_n = 2π^{n/2}/Γ(n/2) 是单位球面 S^{n-1} 的表面积。

**验证 (n = 2 情形)。** 当 n = 2 时，ω_2 = 2π，取 x = (r cosθ, r sinθ)，ζ = (cos
φ, sinφ)，则 |x − ζ|² = 1 − 2r cos(θ−φ) + r²，于是

$$P(x,\zeta) = \frac{1 - r^2}{2\pi(1 - 2r\cos(\theta-\varphi) + r^2)},$$

这正是经典的二维 Poisson 核。因此上述公式是 n = 2 情形的自然推广。✓

**Poisson 公式。** 定义

$$u(x) = \int_{\partial B_R} P_R(x,\zeta)\, f(\zeta)\, dS(\zeta) = \frac{R^2 - |
x|^2}{\omega_n R} \int_{\partial B_R} \frac{f(\zeta)}{|x-\zeta|^n}\, dS(\zeta).$
$

**断言：** u 是 Dirichlet 问题的唯一解。

---

**第一步：调和性 (Δu = 0 in B_R)。**

对每个固定的 ζ ∈ ∂B_R，函数 x ↦ 1/|x − ζ|^n 在 B_R 内调和（因为 ζ ∉ B_R，而 |x −
 ζ|^{2−n} 是 R^n 中 n > 2 时的基本解，其 Laplacian 为零 away from ζ）。通过直接
计算可以验证

$$\Delta_x\!\left[\frac{R^2 - |x|^2}{|x-\zeta|^n}\right] = 0, \qquad x \in B_R,\
;\zeta \in \partial B_R.$$

（这是标准的逐点计算：展开 (R² − |x|²) 的二阶导数和 |x − ζ|^{−n} 的二阶导数，交
叉项恰好抵消。）由于被积函数关于 x 调和且积分在紧集上进行，可以在积分号下求导，
故 Δu = 0 in B_R。

---

**第二步：边界值 (u → f on ∂B_R)。**

Poisson 核满足三条关键性质：

1. **正性：** P_R(x, ζ) > 0 for x ∈ B_R, ζ ∈ ∂B_R（因为 R² − |x|² > 0）。
2. **归一性：** ∫_{∂B_R} P_R(x, ζ) dS(ζ) = 1（常数函数 1 调和，其 Poisson 积分等
于自身；也可通过缩放归约为单位球情形直接验证）。
3. **集中性：** 对任意 δ > 0，∫_{∂B_R \ B_δ(x₀)} P_R(x, ζ) dS(ζ) → 0 as x → x₀ ∈
 ∂B_R（因为当 x → x₀ 时，R² − |x|² → 0，而分母 |x − ζ|^n 在 ζ ∉ B_δ(x₀) 时有正下
界）。

由性质 1–3 和 f 的连续性，标准论证给出：

$$u(x) \to f(x_0) \quad \text{as } x \to x_0 \in \partial B_R.$$

具体地，对任意 ε > 0，取 δ 使 |f(ζ) − f(x₀)| < ε 当 |ζ − x₀| < δ；则

|u(x) − f(x₀)| ≤ ∫_{B_δ(x₀)} P_R · ε\, dS + ∫_{∂B_R \ B_δ(x₀)} P_R · 2M\, dS,

其中 M = sup|f|。第一项 ≤ ε（由性质 2），第二项 → 0（由性质 3），故 lim sup |u(x
) − f(x₀)| ≤ ε。由 ε 任意性，u(x) → f(x₀)。

---

**第三步：唯一性（最大值原理）。**

设 u₁, u₂ 均为解。令 w = u₁ − u₂，则 w 在 B_R 内调和、在 B̄_R 上连续、且 w = 0 on
 ∂B_R。

**最大值原理**（对所有 n ≥ 2 成立）：调和函数在紧集上的最大值和最小值在边界上达
到。因此

$$\max_{\bar{B}_R} w = \max_{\partial B_R} w = 0, \qquad \min_{\bar{B}_R} w = \m
in_{\partial B_R} w = 0.$$

故 w ≡ 0，即 u₁ = u₂。

---

### 结论

Poisson 公式可以推广到 n > 2 的情形，其核为

$$P_R(x, \zeta) = \frac{R^2 - |x|^2}{\omega_n\, R\, |x - \zeta|^n},$$

该公式给出的函数 u 在球内调和、在边界上等于给定的连续边界值 f，并且由最大值原理
（对所有维数 n ≥ 2 有效）保证唯一性。

**因此，Poisson 公式可以用于在 n > 2 时求 Laplace 方程 Dirichlet 问题的唯一解。*
