## Solution

Find all positive integers $1 < a < b < c$ with $(a-1)(b-1)(c-1) \mid abc - 1$.

**Substitution.** Let $x = a-1,\; y = b-1,\; z = c-1$, so $0 < x < y < z$ are po
sitive integers. Then $a = x+1$, $b = y+1$, $c = z+1$, and

$$abc - 1 = (x+1)(y+1)(z+1) - 1 = xyz + xy + xz + yz + x + y + z.$$

The divisibility condition $(a-1)(b-1)(c-1) \mid abc-1$ becomes $xyz \mid (xyz +
 xy + xz + yz + x + y + z)$, i.e.

$$xyz \mid (xy + xz + yz + x + y + z).$$

Set

$$q = \frac{abc-1}{(a-1)(b-1)(c-1)} = 1 + \frac{xy+xz+yz+x+y+z}{xyz} = 1 + \frac
{1}{x}+\frac{1}{y}+\frac{1}{z}+\frac{1}{xy}+\frac{1}{xz}+\frac{1}{yz}.$$

Denote $S = \frac{1}{x}+\frac{1}{y}+\frac{1}{z}+\frac{1}{xy}+\frac{1}{xz}+\frac{
1}{yz}$, so $q = 1 + S$ must be a positive integer, hence $S$ is a non-negative
integer.

**Bounding $S$.** Since $x < y < z$ with $x \geq 1$, the maximum of $S$ is attai
ned at $(x,y,z) = (1,2,3)$:

$$S \leq 1 + \tfrac{1}{2} + \tfrac{1}{3} + \tfrac{1}{2} + \tfrac{1}{3} + \tfrac{
1}{6} = \tfrac{17}{6} < 3.$$

Since all terms are positive, $S > 0$. Thus $S \in \{1, 2\}$, giving $q \in \{2,
 3\}$.
