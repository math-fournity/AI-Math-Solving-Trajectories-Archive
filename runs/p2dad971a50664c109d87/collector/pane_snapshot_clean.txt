## Proof

**Setup.** Let the square $ABCD$ have side length $s$, with $A=(0,0)$, $B=(s,0)$
, $C=(s,s)$, $D=(0,s)$.

**Case 1: M and N on opposite sides** (say M on AB, N on CD).

Let $M=(m,0)$, $N=(n,s)$. The two pieces are quadrilaterals $Q_1 = MBCN$ and $Q_
2 = MADN$, both sharing side $NM = L = \sqrt{(n-m)^2+s^2}$.

By the Pitot theorem (necessary condition for a quadrilateral to be tangential):

- $Q_1$ tangential: $MB + CN = BC + NM$, giving $s = \frac{2mn}{m+n}$ with const
raint $s \geq m+n$.
- $Q_2$ tangential: $MA + DN = AD + NM$, giving $s = \frac{2mn}{m+n}$ with const
raint $m+n \geq s$.

Both require $s = \frac{2mn}{m+n}$ but with **contradictory** inequalities ($s \
geq m+n$ and $m+n \geq s$ simultaneously forces $m+n=s$, which yields $m^2+n^2=0
$, impossible). **So opposite sides is impossible.**

**Case 2: M and N on adjacent sides** (say M on AB, N on BC).

Let $M=(m,0)$, $N=(s,n)$ with $0 < m < s$, $0 < n < s$. The segment MN divides t
he square into:
- **Triangle** $T = MBN$ (right-angled at $B$), with sides $s-m$, $n$, and $L =
\sqrt{(s-m)^2+n^2}$.
- **Pentagon** $P = MADCN$, with sides $m$, $s$, $s$, $s-n$, $L$.

Every triangle is tangential, so $T$ automatically has an incircle. The pentagon
 $P$ must be tangential.

**Pentagon's incircle.** The pentagon has four sides lying on the lines $y=0$, $
x=0$, $y=s$, $x=s$ (the square's sides). A circle tangent to all four of these l
ines must be centered at $(s/2, s/2)$ with radius $s/2$. For this to be the inci
rcle of $P$, it must also be tangent to line $MN$.

Line $MN$: $nx - (s-m)y - nm = 0$. The distance from $(s/2, s/2)$ to this line e
quals $s/2$ yields (after squaring and simplifying):

$$(s-m)\bigl[-s(s-2m) - 2nm\bigr] = 0$$

Since $s \neq m$, we get the **tangential condition**:

$$\boxed{s^2 = 2m(s-n)} \tag{$\star$}$$

This also requires $n < s/2$ (so that $s - m > 0$), which is consistent.

**Computing the inradii.** From $(\star)$: $m = \frac{s^2}{2(s-n)}$, so $s - m =
 \frac{s(s-2n)}{2(s-n)}$.

**Pentagon inradius:** $r_P = \dfrac{s}{2}$.

**Triangle inradius** (right triangle formula $r = \frac{a+b-c}{2}$):

$$r_T = \frac{(s-m) + n - L}{2}$$

Compute $(s-m)+n = \frac{s(s-2n)}{2(s-n)} + n = \frac{s^2 - 2n^2}{2(s-n)}$, and

$$L = \sqrt{(s-m)^2 + n^2} = \sqrt{\frac{s^2(s-2n)^2 + 4n^2(s-n)^2}{4(s-n)^2}} =
 \frac{s^2 - 2sn + 2n^2}{2(s-n)}$$

(using the factorization $s^2(s-2n)^2 + 4n^2(s-n)^2 = (s^2-2sn+2n^2)^2$).

Therefore:

$$r_T = \frac{1}{2}\left(\frac{s^2-2n^2}{2(s-n)} - \frac{s^2-2sn+2n^2}{2(s-n)}\r
ight) = \frac{1}{2}\cdot\frac{2sn-4n^2}{2(s-n)} = \frac{n(s-2n)}{2(s-n)}$$

**Comparing:** $r_T < r_P \iff n(s-2n) < s(s-n) \iff s^2 - 2sn + 2n^2 > 0 \iff (
s-n)^2 + n^2 > 0$, which is **always true**.

So $R = r_P = \dfrac{s}{2}$ and $r = r_T = \dfrac{n(s-2n)}{2(s-n)}$.

**The key identity.** Compute $L + r_T$:

$$L + r_T = \frac{s^2 - 2sn + 2n^2}{2(s-n)} + \frac{n(s-2n)}{2(s-n)} = \frac{s^2
 - 2sn + 2n^2 + ns - 2n^2}{2(s-n)} = \frac{s^2 - sn}{2(s-n)} = \frac{s(s-n)}{2(s
-n)} = \frac{s}{2} = R$$

Therefore:

$$L + r = R \implies \boxed{MN = R - r}$$

} = 5/3$, $r_T = (4/3+1-5/3)/2 = 1/3$, $R = 2$. Indeed $R - r = 2 - 1/3 = 5/3 =
L$. ✓ The incircle at $(2,2)$ with radius $2$ has distance $2$ to line $3x-4y-8=
0$. ✓
