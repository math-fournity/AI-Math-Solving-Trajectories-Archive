## Proof

We seek the least ordinal β > 0 satisfying α·β = β, where α > 1 is a fixed ordin
al.

**Claim:** The least such β is α^ω.

---

### Step 1: α^ω is a fixed point.

Recall α^ω = sup{α^n : n < ω}, which is a limit ordinal since (α^n)_{n<ω} is str
ictly increasing (as α > 1). For any limit ordinal λ, ordinal multiplication sat
isfies α·λ = sup{α·γ : γ < λ}. Thus

α·(α^ω) = sup{α·γ : γ < α^ω}.

**Lower bound.** For every n < ω, α^n < α^ω, so α·α^n = α^{n+1} appears among th
e terms. Hence

sup{α·γ : γ < α^ω} ≥ sup{α^{n+1} : n < ω} = α^ω.

**Upper bound.** For any γ < α^ω, there exists n < ω with γ < α^n (since α^ω = s
up{α^n : n<ω} and the sequence is increasing). By monotonicity of ordinal multip
lication in the right argument,

α·γ ≤ α·α^n = α^{n+1} < α^ω.

Taking suprema: sup{α·γ : γ < α^ω} ≤ α^ω.

Combining both bounds: **α·(α^ω) = α^ω**. ∎

---

### Step 2: No β with 0 < β < α^ω is a fixed point.

Suppose β > 0 and α·β = β. We prove by induction that β ≥ α^n for all n ≥ 1, whi
ch forces β ≥ sup{α^n : n ≥ 1} = α^ω.

**Base case (n = 1):** Since β > 0, we have β ≥ 1, so

β = α·β ≥ α·1 = α = α^1.

**Inductive step:** Assume β ≥ α^n. Using monotonicity of ordinal multiplication
 in the right argument (valid for α > 0):

β = α·β ≥ α·α^n = α^{n+1}.

By induction, β ≥ α^n for every n ≥ 1. Therefore

β ≥ sup{α^n : n ≥ 1} = α^ω.

Hence no ordinal β with 0 < β < α^ω can satisfy α·β = β. ∎

---

### Conclusion

α^ω is a fixed point of the map β ↦ α·β, and every positive fixed point is ≥ α^ω
. Therefore the least ordinal β > 0 such that α·β = β is

$$\boxed{\beta = \alpha^{\omega}.}$$
