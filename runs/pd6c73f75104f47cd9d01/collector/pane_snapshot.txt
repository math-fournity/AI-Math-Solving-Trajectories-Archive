## Proof

Let $\angle DBC = x$. Since $AB = BD$ and $\angle ABD = 36°$, triangle $ABD$ is
isosceles, giving $\angle BAD = \angle BDA = 72°$.

**Derived angles:**
- $\angle ADC = \angle BDA + \angle BDC = 72° + 12° = 84°$
- $\angle BAC = \angle BAD - \angle CAD = 72° - 30° = 42°$
- In $\triangle ACD$: $\angle ACD = 180° - 30° - 84° = 66°$
- In $\triangle BCD$: $\angle BCD = 180° - x - 12° = 168° - x$

**Trigonometric setup.** Set $AB = BD = 1$. By the law of sines:

In $\triangle ABD$: $\;AD = \dfrac{\sin 36°}{\sin 72°}$.

In $\triangle ACD$: $\;CD = AD\cdot\dfrac{\sin 30°}{\sin 66°} = \dfrac{\sin 36°\
cdot\sin 30°}{\sin 72°\cdot\sin 66°}$.

In $\triangle BCD$: $\;CD = BD\cdot\dfrac{\sin x}{\sin(168°-x)} = \dfrac{\sin x}
{\sin(12°+x)}$.

Equating the two expressions for $CD$:

$$\frac{\sin 36°\cdot\sin 30°}{\sin 72°\cdot\sin 66°} = \frac{\sin x}{\sin(12°+x
)}$$

**Claim:** $x = 6°$. We verify the identity $\sin 6°\cdot\sin 72°\cdot\sin 66° =
 \sin 18°\cdot\sin 36°\cdot\sin 30°$:

$$\text{LHS} = \sin 72°\cdot[\sin 6°\cdot\sin 66°] = \sin 72°\cdot\frac{\cos 60°
 - \cos 72°}{2} = \frac{\sin 72°\cos 60° - \sin 72°\cos 72°}{2}$$

$$= \frac{\frac{\sin 72°}{2} - \frac{\sin 144°}{2}}{2} = \frac{\sin 72° - \sin 3
6°}{4} \quad (\text{since } \sin 144°=\sin 36°)$$

$$\text{RHS} = \frac{\sin 18°\cdot\sin 36°}{2}$$

So we need $\sin 72° - \sin 36° = 2\sin 18°\cdot\sin 36°$. By sum-to-product:

$$\sin 72° - \sin 36° = 2\cos 54°\cdot\sin 18° = 2\sin 36°\cdot\sin 18° \quad \c
heckmark \quad (\text{since } \cos 54° = \sin 36°)$$

The identity holds exactly, confirming $x = 6°$.

$$\boxed{\angle DBC = 6°}$$
