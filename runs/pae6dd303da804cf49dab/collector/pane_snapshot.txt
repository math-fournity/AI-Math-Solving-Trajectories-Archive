Looking at this problem, I need to find the size of the union of 1987 sets, each

## Step 1: Determine pairwise intersection size

For any two sets $A_i, A_j$:
$$|A_i \cup A_j| = |A_i| + |A_j| - |A_i \cap A_j| = 45 + 45 - |A_i \cap A_j| = 8
9$$

So $|A_i \cap A_j| = 1$ for all $i \neq j$. **Every pair of sets shares exactly
one element.**

## Step 2: Prove all sets share a common element

**Setup.** For each element $x$ in the union, let $r_x$ = number of sets contain
ing $x$.

**Key counting identity.** Fix any set $A_i$ with 45 elements. Each of the other
 1986 sets shares exactly one element with $A_i$. An element $x \in A_i$ with re
plication number $r_x$ is shared with $r_x - 1$ other sets. Since each other set
 shares exactly one element with $A_i$:
$$\sum_{x \in A_i} (r_x - 1) = 1986 \quad \Longrightarrow \quad \sum_{x \in A_i}
 r_x = 2031$$

**Assume for contradiction** that not all sets share a common element.

**Dual linear space.** Construct a linear space where:
- **Points** = the 1987 sets
- **Lines** = for each element $x$ with $r_x \geq 2$, the collection of sets con
taining $x$

Every two points lie on exactly one line (since every two sets share exactly one
 element). Not all points are on a single line (by our assumption).

**Pigeonhole argument.** Fix any point $P$ (set $A$). Point $P$ lies on at most
45 lines (one per element of $A$ that appears in $\geq 2$ sets). The other 1986
points are distributed among these $\leq 45$ lines, with each line through $P$ c
ontaining $P$ plus some other points. Since:
$$\sum_{\text{lines } \ell \ni P} (|\ell| - 1) = 1986$$
and there are at most 45 such lines, by pigeonhole some line has size $\geq \lce
il 1986/45 \rceil + 1 = 45 + 1 = 46$.

So there exists an element $x$ appearing in at least 46 sets.

**Forcing contradiction.** Let $x$ appear in $r_x \geq 46$ sets. Any two sets co
ntaining $x$ already share $x$, so they share **only** $x$ (their intersection i
s exactly 1). Therefore no element other than $x$ appears in two different sets
containing $x$.

Now consider any set $B$ not containing $x$ (if one exists). $B$ must share exac
tly one element with each of the $r_x \geq 46$ sets containing $x$. But each ele
ment of $B$ can belong to **at most one** set containing $x$ (as shown above). S
ince $B$ has only 45 elements, it can share elements with at most 45 sets contai
ning $x$ — but it needs to share with $\geq 46$. **Contradiction.**

Therefore no set can avoid $x$; **all 1987 sets contain $x$**, contradicting our
 assumption that no common element exists.

## Step 3: Compute the union size (sunflower case)

All 1987 sets share the common element $x$. Any two sets share exactly $\{x\}$,
so the remaining 44 elements of each set are **unique** to that set (not shared
with any other set).

$$|\text{Union}| = 1 + 1987 \times 44 = 1 + 87428 = \boxed{87429}$$
