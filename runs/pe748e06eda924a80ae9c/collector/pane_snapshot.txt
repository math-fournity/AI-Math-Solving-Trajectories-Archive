## Proof

The answer is **yes**: $f^{-1}$ is $\mathcal{C}^\infty$.

Let $f(U)\subseteq\mathbb{R}^n$ (necessarily $n\ge m$ since $\mathrm{d}f(x):\mat
hbb{R}^m\to\mathbb{R}^n$ is injective). Since $\mathrm{d}f(x)$ is injective for
every $x\in U$, the rank of $f$ equals $m$ at every point of $U$; in particular
the rank is constant on $U$.

**Step 1: $f$ is an open map onto $f(U)$.** Since $f$ is a bijection and $f^{-1}
$ is continuous, for any open set $O\subseteq U$ the set $(f^{-1})^{-1}(O)=f(O)$
 is open in $f(U)$. Hence $f:U\to f(U)$ is an open map.

**Step 2: Local canonical form via the constant rank theorem.** Fix $x_0\in U$.
By the constant rank theorem (rank $m$, which is constant on $U$), there exist

- an open neighborhood $V_0\subseteq U$ of $x_0$,
- an open set $W_0\subseteq\mathbb{R}^n$ with $f(V_0)\subseteq W_0$,
- $\mathcal{C}^\infty$ diffeomorphisms $\phi:V_0\to\phi(V_0)\subseteq\mathbb{R}^
m$ and $\psi:W_0\to\psi(W_0)\subseteq\mathbb{R}^n$,

such that
$$\psi\circ f\circ\phi^{-1}(u_1,\dots,u_m)=(u_1,\dots,u_m,0,\dots,0).\qquad(\sta
r)$$

**Step 3: Adjust neighborhoods so that $f(V)=W\cap f(U)$.** Since $f$ is an open
 map (Step 1), $f(V_0)$ is open in $f(U)$, so there exists an open set $\Omega\s
ubseteq\mathbb{R}^n$ with $f(V_0)=\Omega\cap f(U)$. Set $W:=W_0\cap\Omega$ and $
V:=V_0$. Then

- $W$ is open in $\mathbb{R}^n$ and contains $f(x_0)$;
- $f(V)=f(V_0)=\Omega\cap f(U)=W_0\cap\Omega\cap f(U)=W\cap f(U)$;
- the canonical form $(\star)$ still holds on $V$, since $W\subseteq W_0$ and $\
psi|_W$ remains a diffeomorphism onto its image.

**Step 4: Construct a smooth local extension of $f^{-1}$.** Let $\pi:\mathbb{R}^
n\to\mathbb{R}^m$ be the projection onto the first $m$ coordinates, and define
$$F:W\to\mathbb{R}^m,\qquad F:=\phi^{-1}\circ\pi\circ\psi.$$
This is a composition of $\mathcal{C}^\infty$ maps, hence $\mathcal{C}^\infty$.

For any $y\in W\cap f(U)=f(V)$, write $y=f(x)$ with $x\in V$. By $(\star)$,
$$\psi(y)=\psi(f(x))=(\phi(x),0,\dots,0),$$
so $\pi(\psi(y))=\phi(x)$, and therefore
$$F(y)=\phi^{-1}(\phi(x))=x=f^{-1}(y).$$
Thus $F|_{W\cap f(U)}=f^{-1}|_{W\cap f(U)}$.

**Step 5: Conclusion.** Since $x_0\in U$ was arbitrary and $f$ is surjective ont
o $f(U)$, every point $y_0\in f(U)$ equals $f(x_0)$ for some $x_0$. Step 4 provi
des, for each such $y_0$, an open neighborhood $W\ni y_0$ in $\mathbb{R}^n$ and
a $\mathcal{C}^\infty$ map $F:W\to\mathbb{R}^m$ that agrees with $f^{-1}$ on $W\
cap f(U)$. By the definition of a smooth map on a subset of $\mathbb{R}^n$, this
 means $f^{-1}:f(U)\to\mathbb{R}^m$ is $\mathcal{C}^\infty$.

**Remark on the hypotheses.** The continuity of $f^{-1}$ is used in Step 1 to co
nclude that $f$ is an open map, which is what allows the matching $f(V)=W\cap f(
U)$ in Step 3; without it, the local smooth extension $F$ might only agree with
$f^{-1}$ on the smaller set $f(V)$ rather than on all of $W\cap f(U)$. The case
$n=m$ is the special case in which the constant rank theorem reduces to the inve
rse function theorem (the projection $\pi$ becomes the identity), giving the fam
iliar conclusion directly.

Therefore $f^{-1}$ is $\mathcal{C}^\infty$. $\blacksquare$
