# Problem

In a specialized digital archive, data packets are organized into sequential clusters. For any group of $n$ unique data packets, the total number of possible internal configurations is given by the factorial $n!$. The system's storage efficiency is measured by the "trailing zero count" of these configurations.

A technician observes a specific set of properties for a positive integer $n > 4$:
1. When $n$ packets are processed, the number of possible configurations ends with exactly $k$ zeros in its decimal representation.
2. When the batch size is doubled to $2n$ packets, the number of possible configurations for that larger set ends with exactly $3k$ zeros in its decimal representation.

Determine the sum of all such positive integers $n$ that satisfy these two efficiency conditions.
