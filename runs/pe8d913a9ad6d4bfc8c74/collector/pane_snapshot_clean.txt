## Proof

We minimize $J[f] = \int_0^1 (f''(x))^2\,dx$ over
$$\mathcal{A} = \{f \in C^2([0,1]) : f(0)=f(1)=0,\; f'(0)=a\},$$
where $f'(1)$ is **free**.

### Step 1. Euler–Poisson equation

The Lagrangian $L=(f'')^2$ depends on $f''$, so the Euler–Lagrange equation is
$$\frac{\partial L}{\partial f} - \frac{d}{dx}\frac{\partial L}{\partial f'} + \
frac{d^2}{dx^2}\frac{\partial L}{\partial f''} = 0.$$
Since $\frac{\partial L}{\partial f}=0$, $\frac{\partial L}{\partial f'}=0$, $\f
rac{\partial L}{\partial f''}=2f''$, we get
$$f^{(4)}(x) = 0.$$
Hence every extremal is a cubic: $f(x)=c_0+c_1 x+c_2 x^2+c_3 x^3$.

### Step 2. Natural boundary condition at $x=1$

For a variation $\eta$ with $\eta(0)=\eta(1)=0$, $\eta'(0)=0$ (so $\eta'(1)$ fre
e),
$$\delta J = 2\int_0^1 f''\eta''\,dx = \bigl[2f''\eta'\bigr]_0^1 - \bigl[2f'''\e
ta\bigr]_0^1 + 2\int_0^1 f^{(4)}\eta\,dx.$$
Using $\eta(0)=\eta(1)=0$, $\eta'(0)=0$, and $f^{(4)}=0$, this reduces to $2f''(
1)\,\eta'(1)$. Since $\eta'(1)$ is arbitrary, the natural boundary condition is
$$f''(1)=0.$$

### Step 3. Determine the extremal

From $f(0)=0$: $c_0=0$. From $f'(0)=a$: $c_1=a$. So $f(x)=ax+c_2 x^2+c_3 x^3$.

- $f(1)=0$: $a+c_2+c_3=0$.
- $f''(1)=0$: $f''(x)=2c_2+6c_3 x$, so $2c_2+6c_3=0$, i.e. $c_2=-3c_3$.

Substituting: $a-3c_3+c_3=0\Rightarrow c_3=\tfrac{a}{2}$, $c_2=-\tfrac{3a}{2}$.
Thus
$$\boxed{f_*(x) = a\!\left(x - \tfrac{3}{2}x^2 + \tfrac{1}{2}x^3\right).}$$

Check: $f_*(0)=0$, $f_*'(0)=a$, $f_*(1)=a(1-\tfrac32+\tfrac12)=0$, $f_*''(x)=a(-
3+3x)$, $f_*''(1)=0$. ✓

### Step 4. Verify it is the (unique) minimizer

Let $g=f_*$ and let $f\in\mathcal{A}$ be arbitrary; set $h=f-g$. Then $h(0)=h(1)
=0$, $h'(0)=0$, and
$$\int_0^1 (f'')^2\,dx = \int_0^1 (g'')^2\,dx + 2\int_0^1 g''h''\,dx + \int_0^1
(h'')^2\,dx.$$
The cross term vanishes:
$$2\int_0^1 g''h''\,dx = \bigl[2g''h'\bigr]_0^1 - \bigl[2g'''h\bigr]_0^1 + 2\int
_0^1 g^{(4)}h\,dx = 0,$$
using $g''(1)=0$, $h'(0)=0$, $h(0)=h(1)=0$, $g^{(4)}=0$. Therefore
$$\int_0^1 (f'')^2\,dx = \int_0^1 (g'')^2\,dx + \int_0^1 (h'')^2\,dx \ge \int_0^
1 (g'')^2\,dx,$$
with equality iff $h''\equiv 0$, i.e. $h$ is linear; combined with $h(0)=h(1)=h'
(0)=0$ this forces $h\equiv 0$. So the minimizer is unique.

### Step 5. Compute the minimum value

With $g''(x)=a(-3+3x)=3a(x-1)$,
$$\int_0^1 (g'')^2\,dx = 9a^2\int_0^1 (1-x)^2\,dx = 9a^2\cdot\frac{1}{3} = 3a^2.
$$

### Result

$$\boxed{\min_{f\in\mathcal{A}}\int_0^1 (f''(x))^2\,dx = 3a^2,}$$
attained uniquely at
$$\boxed{f(x) = a\!\left(x - \tfrac{3}{2}x^2 + \tfrac{1}{2}x^3\right).}$$
