# Solution

We compute $S = \sum_{n=1}^{\infty} \frac{1}{\binom{2n}{n}\, n^2}$.

## Step 1: Beta function representation

Recall the Beta function $B(a,b) = \int_0^1 t^{a-1}(1-t)^{b-1}\,dt = \frac{\Gamm
a(a)\Gamma(b)}{\Gamma(a+b)}$. For integers,

$$B(n, n+1) = \frac{(n-1)!\, n!}{(2n)!} = \frac{1}{n\,\binom{2n}{n}}.$$

Hence $\displaystyle \frac{1}{\binom{2n}{n}} = n\,B(n,n+1) = n\int_0^1 t^{n-1}(1
-t)^n\,dt$, and

$$\frac{1}{\binom{2n}{n}\,n^2} = \frac{1}{n}\int_0^1 t^{n-1}(1-t)^n\,dt.$$

## Step 2: Sum and integrate

$$S = \int_0^1 \sum_{n=1}^{\infty} \frac{t^{n-1}(1-t)^n}{n}\,dt = \int_0^1 \frac
{1}{t}\sum_{n=1}^{\infty} \frac{\bigl(t(1-t)\bigr)^n}{n}\,dt.$$

Using $-\ln(1-x) = \sum_{n=1}^{\infty} \frac{x^n}{n}$ for $|x|\le 1$ (and $t(1-t
)\le 1/4 < 1$ on $(0,1)$):

$$S = -\int_0^1 \frac{\ln\bigl(1 - t(1-t)\bigr)}{t}\,dt = -\int_0^1 \frac{\ln(1
- t + t^2)}{t}\,dt.$$

## Step 3: Factor the logarithm

Since $(1+t)(1-t+t^2) = 1+t^3$,

$$\ln(1 - t + t^2) = \ln(1+t^3) - \ln(1+t).$$

Therefore

$$S = -\int_0^1 \frac{\ln(1+t^3)}{t}\,dt + \int_0^1 \frac{\ln(1+t)}{t}\,dt.$$

## Step 4: Evaluate both integrals

**Second integral.** Expanding $\ln(1+t) = \sum_{k=1}^{\infty} \frac{(-1)^{k+1}t
^k}{k}$ and integrating termwise,

$$\int_0^1 \frac{\ln(1+t)}{t}\,dt = \sum_{k=1}^{\infty} \frac{(-1)^{k+1}}{k^2} =
 \eta(2) = \left(1 - 2^{1-2}\right)\zeta(2) = \tfrac{1}{2}\cdot\tfrac{\pi^2}{6}
= \frac{\pi^2}{12}.$$

**First integral.** Substitute $u = t^3$, so $t = u^{1/3}$, $dt = \frac{1}{3}u^{
-2/3}\,du$:

$$\int_0^1 \frac{\ln(1+t^3)}{t}\,dt = \int_0^1 \frac{\ln(1+u)}{u^{1/3}}\cdot\fra
c{1}{3}u^{-2/3}\,du = \frac{1}{3}\int_0^1 \frac{\ln(1+u)}{u}\,du = \frac{1}{3}\c
dot\frac{\pi^2}{12} = \frac{\pi^2}{36}.$$

## Step 5: Combine

$$S = -\frac{\pi^2}{36} + \frac{\pi^2}{12} = -\frac{\pi^2}{36} + \frac{3\pi^2}{3
6} = \frac{2\pi^2}{36} = \frac{\pi^2}{18}.$$

## Numerical check

Partial sums: $\frac{1}{2} + \frac{1}{24} + \frac{1}{180} + \frac{1}{1120} + \cd
ots \approx 0.5481\ldots$, and $\frac{\pi^2}{18} \approx 0.54831\ldots\;$ ✓

## Result

$$\boxed{\displaystyle \sum_{n=1}^{\infty} \frac{1}{\binom{2n}{n}\, n^2} = \frac
{\pi^2}{18}}$$
