**主张：** 是的，我们可以得出结论 $\lambda_1 = \lambda_2 = \dots = \lambda_k = 0
$。

**证明。**

设 $p_n = \lambda_1^n + \lambda_2^n + \dots + \lambda_k^n$ 为幂和，设 $e_1, e_2,
 \dots, e_k$ 为 $\lambda_1, \dots, \lambda_k$ 的初等对称多项式（以重数计算），使
得
$$\prod_{i=1}^k (x - \lambda_i) = x^k - e_1 x^{k-1} + e_2 x^{k-2} - \dots + (-1)
^k e_k.$$

已知 $p_n = 0$ 对于所有自然数 $n$ 成立，特别是对于 $n = 1, 2, \dots, k$ 成立。

**牛顿恒等式**指出，对于每个 $m \ge 1$：
$$p_m - e_1 p_{m-1} + e_2 p_{m-2} - \dots + (-1)^{m-1} e_{m-1} p_1 + (-1)^m m\,
e_m = 0.$$

我们通过对 $m$ 的归纳法证明 $e_m = 0$ 对于 $m = 1, \dots, k$ 成立。

*基础步骤 ($m=1$)：* 牛顿恒等式给出 $p_1 + (-1)^1 \cdot 1 \cdot e_1 = 0$，即 $p_
1 - e_1 = 0$。由于 $p_1 = 0$，我们得到 $e_1 = 0$。

*归纳步骤：* 假设 $e_1 = \dots = e_{m-1} = 0$。那么 $m \le k$ 的牛顿恒等式简化为
$$p_m + (-1)^m m\, e_m = 0,$$
因为所有涉及 $e_1, \dots, e_{m-1}$ 的项都消失了。由于 $p_m = 0$（已知，且 $m \le
 k$），我们得到 $(-1)^m m\, e_m = 0$，因此 $e_m = 0$。

根据归纳法，$e_1 = e_2 = \dots = e_k = 0$。因此
$$\prod_{i=1}^k (x - \lambda_i) = x^k.$$

该多项式的唯一根是 $0$（重数为 $k$）。由于每个 $\lambda_i$ 都是此多项式的根，我
们得出结论
$$\lambda_1 = \lambda_2 = \dots = \lambda_k = 0.$$

**验证一致性：** 反过来，如果所有 $\lambda_i = 0$，那么对于每个 $n \ge 1$，$p_n
= \sum 0^n = 0$，这与假设一致。（注：对于 $n \ge 1$，$0^n = 0$，因此没有歧义。）

因此，条件 $p_n = 0$ 对于所有自然数 $n$ 成立，确实迫使所有 $\lambda_i$ 为零。$\b
lacksquare$
