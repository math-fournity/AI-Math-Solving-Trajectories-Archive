**Symmetry condition:** Reading the frequency log bottom-to-top equals the origi

$$c_{a_{n+1-j}} = a_j \quad \text{for all } j = 1, \ldots, n.$$

Equivalently, $a_{n+1-j} = c_{a_j}$ for all $j$.

## Key Structural Result: Only Fixed Points Are Possible

Define $m(v) = c_v$ for each value $v$ that appears. The condition says: positio
n $j$ with value $v$ mirrors to position $n+1-j$ with value $m(v)$.

**$m$ is an involution.** If position $j$ has value $v$, then position $n+1-j$ h
as value $m(v)$. Mirroring again: position $n+1-(n+1-j) = j$ has value $m(m(v))$
. So $m(m(v)) = v$.

**Non-fixed pairs are impossible.** Suppose $m(v) = w$ with $v \neq w$. Let $S_v
 = \{j : a_j = v\}$, so $|S_v| = c_v = w$, and $S_w = \{j : a_j = w\}$, so $|S_w
| = c_w = v$. The reversal map $\sigma(j) = n+1-j$ is a bijection. The condition
 gives $\sigma(S_v) \subseteq S_w$ (every value-$v$ position maps to a value-$w$
 position), so $w = |S_v| = |\sigma(S_v)| \leq |S_w| = v$. Similarly $\sigma(S_w
) \subseteq S_v$ gives $v \leq w$. Thus $v = w$ — **contradiction**.

**Conclusion:** Every value $v$ that appears must satisfy $m(v) = v$, i.e., $c_v
 = v$. Each appearing value appears exactly as many times as its own value.

## The Sequence Is a Palindrome

Since $m(v) = v$ for all appearing values, the condition becomes $a_{n+1-j} = a_
j$ for all $j$. The sequence is a **palindrome**.

## Palindrome Constraint

A palindrome of length $n$ requires each value to appear an even number of times
, except **at most one** value appearing an odd number of times (placed in the m
iddle when $n$ is odd).

Since value $v$ appears exactly $v$ times:
- **Even values** ($v$ even): appear an even number of times ✓ — always palindro
mically compatible.
- **Odd values** ($v$ odd): appear an odd number of times — **at most one** odd
value can be included.

## Maximizing $n$

We choose $S \subseteq \{1, 2, \ldots, 10\}$ to maximize $\sum_{v \in S} v$ subj
ect to: at most one odd value in $S$.

- **Even values available:** $\{2, 4, 6, 8, 10\}$, sum $= 30$. Include all.
- **Odd values available:** $\{1, 3, 5, 7, 9\}$. Pick at most one; choose the la
rgest: $9$.

$$n = 2 + 4 + 6 + 8 + 10 + 9 = 39.$$

**Frequency check:** Each value $v \in S$ appears exactly $v$ times, so $c_v = v

## Optimality

Any valid configuration has $n = \sum_{v \in S} v$ with $S \subseteq \{1,\ldots,
10\}$ and at most one odd element. The sum of all even values is $30$; adding th

39$ is the maximum.
