Looking at this problem, I need to find all $n \in \{3, 4, \ldots, 100\}$ where
a stable configuration exists using $2n+1$ consecutive integers.

## Setup

Let the $2n+1$ consecutive integers be $\{m, m+1, \ldots, m+2n\}$. Denote statio
n codes (cyclically) as $a_1, \ldots, a_n$, repeater $i$ as $\frac{a_i + a_{i+1}
}{2}$, and server as $\frac{\sum a_i}{n}$.

**Sum constraint.** The sum of all $2n+1$ codes is $(2n+1)(m+n)$. The sum of rep
eaters equals $\sum a_i = S$, and the server equals $S/n$. So total $= 2S + S/n
= S \cdot \frac{2n+1}{n} = (2n+1)(m+n)$, giving $S = n(m+n)$, so the **server co
de is $m+n$** (the middle value).

**Shift to center at 0.** Set $b_i = a_i - (m+n)$. Then $\sum b_i = 0$, server $
= 0$, and stations + repeaters must form $\{-n, \ldots, -1, 1, \ldots, n\}$ (all
 distinct).

**Parity constraint.** Each repeater $\frac{b_i + b_{i+1}}{2}$ must be an intege
r, so all $b_i$ share the same parity.

## Case Analysis

### Case 1: $n$ odd

- **All even:** Even numbers in $\{-n,\ldots,n\}\setminus\{0\}$: only $n-1$ avai
lable, need $n$. ✗
- **All odd:** Odd numbers available: $n+1$. Need $n$ with sum $0$. Sum of all $
n+1$ odd numbers $= 0$. Removing any one $x$ gives sum $-x \neq 0$. ✗

**No solution for odd $n$.**

### Case 2: $n \equiv 2 \pmod{4}$

There are exactly $n$ even and $n$ odd values available, so stations take all of
 one parity.

- **All even stations:** Set $c_i = b_i/2 \in \{-n/2, \ldots, -1, 1, \ldots, n/2
\}$. Repeaters $= c_i + c_{i+1}$ must be all odd (to fill the odd slots), requir
ing alternating parity in the cycle. Since $n/2$ is odd, the set has $n/2 - 1$ e
ven and $n/2 + 1$ odd elements — **unequal, cannot alternate**. ✗
- **All odd stations:** Max repeater $= \frac{(n-1)+(n-3)}{2} = n-2 < n$, but $n
$ is needed as a repeater value. ✗

**No solution for $n \equiv 2 \pmod{4}$.**

### Case 3: $n \equiv 0 \pmod{4}$ — Construction

Write $n = 4k$. Use all-even stations: $b_i = 2c_i$ where $c_i$ ranges over $\{-
2k, \ldots, -1, 1, \ldots, 2k\}$. Pair each $c$ with $o = c - \operatorname{sgn}
(c)$, giving direct sums $c + o = 2c - \operatorname{sgn}(c)$.

**Cycle of $c$-values:** $-2k,\; -(2k\!-\!1),\; -2(k\!-\!1),\; -(2k\!-\!3),\; \l
dots,\; -2,\; -1,\; 2,\; 1,\; 4,\; 3,\; \ldots,\; 2k,\; (2k\!-\!1)$.

This alternates even/odd (the set has $2k$ even and $2k$ odd elements — equal ✓)
.

**Direct sums** (even + its paired odd): For $c = -2j$: $-(4j-1)$; for $c = 2j$:
 $4j-1$. Yields $\pm 3, \pm 7, \ldots, \pm(4k\!-\!1)$.

**Cross sums** (odd + next even):
- Between $-2j$ and $-2(j\!-\!1)$: $-(2j\!-\!1) - 2(j\!-\!1) = -(4j\!-\!3)$ for
$j = 2, \ldots, k$
- Between $-2$ and $2$: $-1 + 2 = 1$
- Between $2j$ and $2(j\!+\!1)$: $(2j\!-\!1) + 2(j\!+\!1) = 4j\!+\!1$ for $j = 1
, \ldots, k\!-\!1$
- Closing edge $2k \to -2k$: $(2k\!-\!1) + (-2k) = -1$

Yields $\pm 1, \pm 5, \ldots, \pm(4k\!-\!3)$.

**Together:** $\{\pm(4j\!-\!1) : j=1,\ldots,k\} \cup \{\pm(4j\!-\!3) : j=1,\ldot
s,k\} = \{\pm 1, \pm 3, \ldots, \pm(4k\!-\!1)\}$ — all $4k = n$ odd numbers from
 $-(n\!-\!1)$ to $n\!-\!1$, all distinct. ✓

**Verification for $n=4$ ($k=1$):** Cycle $-2, -1, 2, 1$. Sums: $-3, 1, 3, -1$.
Set $= \{-3,-1,1,3\}$. ✓

**Verification for $n=8$ ($k=2$):** Cycle $-4, -3, -2, -1, 2, 1, 4, 3$. Sums: $-
7, -5, -3, 1, 3, 5, 7, -1$. Set $= \{-7,-5,-3,-1,1,3,5,7\}$. ✓

**Verification for $n=12$ ($k=3$):** Cycle $-6, -5, -4, -3, -2, -1, 2, 1, 4, 3,
6, 5$. Sums: $-11, -9, -7, -5, -3, 1, 3, 5, 7, 9, 11, -1$. ✓

All station values are distinct (permutation of even numbers), all repeater valu
es are distinct (permutation of odd numbers), server $= 0$. Together they form $
\{-n, \ldots, n\}$ — exactly $2n+1$ consecutive integers. ✓

## Conclusion

A stable configuration exists **if and only if $n \equiv 0 \pmod{4}$**.

The valid $n$ in $\{3, \ldots, 100\}$ are $4, 8, 12, \ldots, 100$ — that is, $4
\cdot 1, 4 \cdot 2, \ldots, 4 \cdot 25$, giving 25 values.

$$\text{Sum} = 4(1 + 2 + \cdots + 25) = 4 \cdot \frac{25 \cdot 26}{2} = 4 \cdot
