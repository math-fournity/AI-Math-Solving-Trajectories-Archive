## Proof

**Interpretation.** A topological space X C-satisfies φ (X ⊨_C φ) if there exist
s a commutative ring R with Spec(R) ≅ X (Zariski topology) and R ⊨ φ. A sentence
 φ is C-satisfiable if some such X exists (equivalently, φ has a ring model).

**Claim.** κ = (2^{ℵ₀})⁺, the successor cardinal of the continuum.

### Upper Bound: κ ≤ (2^{ℵ₀})⁺

The language of rings L = {+, ·, 0, 1} is countable. By the **downward Löwenheim
–Skolem theorem**, every satisfiable L-sentence φ has a countable model R ⊨ φ.

For a countable ring R, every prime ideal is a subset of R, so the number of pri
me ideals is at most |P(R)| = 2^{ℵ₀}. Hence:

$$|\operatorname{Spec}(R)| \leq 2^{\aleph_0} < (2^{\aleph_0})^+.$$

Setting X = Spec(R), we have X ⊨_C φ and |X| < (2^{ℵ₀})⁺. Since φ was arbitrary,
 every C-satisfiable φ has a witness of size < (2^{ℵ₀})⁺. ∎

### Lower Bound: κ ≥ (2^{ℵ₀})⁺

We exhibit a C-satisfiable sentence φ₀ such that **every** X ⊨_C φ₀ satisfies |X
| ≥ 2^{ℵ₀}.

**The sentence.** Let φ₀ be the conjunction of:
1. **Boolean:** ∀x (x² = x)  *(R is a Boolean ring)*
2. **Atomless:** ∀x (x ≠ 0 → ∃y (yx = y ∧ y ≠ 0 ∧ y ≠ x))  *(no atom in the Bool
ean algebra order a ≤ b ⟺ ab = a)*

This is a first-order sentence in the language of rings.

**Satisfiability.** The clopen algebra of the Cantor set 2^ω is a countable, ato
mless Boolean algebra. Under Stone's correspondence, it is a countable atomless
Boolean ring R₀ ⊨ φ₀. So φ₀ is C-satisfiable, with witness X₀ = Spec(R₀) ≅ 2^ω (
the Cantor set), |X₀| = 2^{ℵ₀}.

**Every model has large spectrum.** Let R ⊨ φ₀ be any model (countable or not).
By Stone's representation theorem, X = Spec(R) is a **compact Hausdorff** space
(the Stone space of the Boolean algebra R). Since R is atomless, X has **no isol
ated points** (atoms of a Boolean algebra correspond bijectively to isolated poi
nts of its Stone space).

**Lemma (Hausdorff).** *Every compact Hausdorff space with no isolated points ha
s cardinality ≥ 2^{ℵ₀}.*

*Proof of Lemma.* Let X be compact Hausdorff with no isolated points. Since X is
 compact Hausdorff, it is normal. We build a binary tree of nonempty open sets {
U_s : s ∈ 2^{<ω}}:
- U_∅ = X.
- Given U_s (nonempty open), pick a point p ∈ U_s. Since p is not isolated, U_s
contains another point q ≠ p. By Hausdorffness, separate p and q by disjoint ope
n sets V_p, V_q. Set U_{s⌢0} = U_s ∩ V_p and U_{s⌢1} = U_s ∩ V_q, shrunk (using
normality) so that cl(U_{s⌢i}) ⊆ U_s and the closures are disjoint.

For each f ∈ 2^ω, the family {cl(U_{f↾n}) : n ∈ ω} is a decreasing sequence of n
onempty closed sets in a compact space, so ⋂_n cl(U_{f↾n}) ≠ ∅. Pick x_f in this
 intersection. If f ≠ g, let n be the first index where they differ; then x_f ∈
cl(U_{f↾n}) and x_g ∈ cl(U_{g↾n}), which are disjoint, so x_f ≠ x_g. This inject
s 2^ω into X, giving |X| ≥ 2^{ℵ₀}. ∎

Applying the lemma: |Spec(R)| ≥ 2^{ℵ₀} for every R ⊨ φ₀. Hence every witness X ⊨
_C φ₀ has |X| ≥ 2^{ℵ₀}, so no κ ≤ 2^{ℵ₀} suffices. Therefore κ ≥ (2^{ℵ₀})⁺. ∎

### Combining Both Bounds

- Upper bound: κ ≤ (2^{ℵ₀})⁺.
- Lower bound: κ ≥ (2^{ℵ₀})⁺.

**Therefore κ = (2^{ℵ₀})⁺.**

### Relation to the Löwenheim–Skolem Theorem

The result exhibits a **cardinal shift** from classical to topological model the
ory:

1. **Classical downward LS** (countable language): every satisfiable sentence ha
s a model of size ≤ ℵ₀. Applied here, it yields a **countable ring** R ⊨ φ, but
the spectrum Spec(R) can be as large as 2^{ℵ₀} — an exponential blowup from |R|
= ℵ₀ to |Spec(R)| ≤ 2^{ℵ₀}, since prime ideals are subsets of R.

2. **The lower bound is topological, not model-theoretic.** The atomless Boolean
 ring sentence φ₀ forces |Spec(R)| ≥ 2^{ℵ₀} not by first-order cardinality quant
ifiers (which are absent), but via the **Baire category theorem** and the binary
 tree construction: compactness of the Stone space plus absence of isolated poin
ts forces continuum-many points. This is a genuinely topological obstruction wit
h no classical LS analogue.

3. **The bounds match exactly.** The upper bound 2^{ℵ₀} (from LS + counting subs
ets) and the lower bound 2^{ℵ₀} (from compact Hausdorff + atomlessness) coincide
, yielding κ = (2^{ℵ₀})⁺. This mirrors the classical LS theorem's tightness (ℵ₀
bounds from both sides), but shifted one exponential higher.

4. **No compactness theorem needed for the lower bound.** Unlike classical LS lo
wer bounds (which use compactness to build models with no small cardinality), th
e topological lower bound uses the Baire category theorem — a topological compac
tness principle distinct from the model-theoretic compactness theorem, yet playi
ng an analogous role.

In summary, the passage from rings to their spectra introduces a deterministic e
xponential gap: the least bounding cardinal for topological witnesses is the **s
uccessor of the continuum**, (2^{ℵ₀})⁺, reflecting that spectra of countable rin
gs live in P(ℵ₀) while certain first-order sentences topologically force the ful
l continuum.
