Looking at this problem, I need to count the number of ways to 2-color a 2×100 g
rid so that both color classes are non-empty and edge-connected.

## Proof

**Setup.** Consider the 2×n grid of cells as a planar region: the rectangle [0,n
]×[0,2], where cell (row 1, column j) occupies [j−1,j]×[1,2] and cell (row 2, co
lumn j) occupies [j−1,j]×[0,1]. A valid coloring partitions all 2n cells into tw
o non-empty, edge-connected sets (Red and Blue).

**Step 1: The boundary is a simple path.** Since the rectangle is simply connect
ed and both regions are connected, the boundary between them is a single simple
curve along grid lines. It cannot form a closed loop (which would enclose a regi
on not touching the rectangle's boundary — impossible in a 2-cell-wide grid wher
e every cell touches the top or bottom edge). So the boundary is a simple path f
rom one point on the outer boundary to another, using only **internal grid edges
**.

**Step 2: The internal edge graph.** The internal edges of the grid (edges not o
n the outer boundary) form a graph G:
- **Spine:** horizontal edges (x,1)−(x+1,1) for x=0,…,n−1 (the line y=1).
- **Teeth:** vertical edges (x,0)−(x,1) and (x,1)−(x,2) for each x=1,…,n−1.

This is a **comb graph**: a path of n edges along y=1, with two pendant edges (u
p and down) at each interior vertex.

**Step 3: G is a tree.** G has (n+1) + 2(n−1) = 3n−1 vertices and n + 2(n−1) = 3
n−2 edges. Since (3n−1) − (3n−2) = 1, G is a tree. ✓

**Step 4: Boundary endpoints are the leaves.** The boundary path's endpoints mus
t lie on the outer boundary and be adjacent to an internal edge. These are exact
ly the **leaves** of the comb graph:
- (0,1) and (n,1) — the two ends of the spine (left and right side midpoints),
- (x,0) for x=1,…,n−1 — bottom side interior points (n−1 points),
- (x,2) for x=1,…,n−1 — top side interior points (n−1 points).

Total leaves: **2n**. The four corners (0,0), (0,2), (n,0), (n,2) are not adjace
nt to any internal edge, so they cannot be endpoints.

**Step 5: Every pair of leaves gives a valid partition.** In a tree, the unique
path between any two leaves does not pass through any other leaf (since leaves h
ave degree 1, a path entering a leaf must terminate there). Thus every pair of d
istinct leaves yields a boundary path that:
- touches the outer boundary only at its two endpoints,
- partitions the rectangle into two non-empty regions (the path uses only intern
al edges, so neither side is empty; the smallest possible region is a single cel
l).

Each such path produces exactly one partition into two connected regions, and ea
ch partition yields exactly **2 colorings** (Red/Blue or Blue/Red).

**Step 6: Counting.** The number of valid boundary paths equals the number of pa
irs of leaves:

$$\binom{2n}{2} = \frac{2n(2n-1)}{2} = n(2n-1).$$

The number of valid colorings is:

$$2 \cdot n(2n-1) = 2n(2n-1).$$

**Verification for small n:**
- **n=1:** 2×1×1 = 2. The 2×1 grid has 2 cells; the only valid colorings are (to
p Red, bottom Blue) and (top Blue, bottom Red). ✓
- **n=2:** 2×2×3 = 12. Direct enumeration of the 2×2 grid confirms 12 valid colo
rings. ✓
- **n=3:** 2×3×5 = 30. Complete enumeration of all connected subsets S with conn
ected complement yields 30 valid colorings. ✓

**Final answer for n=100:**

$$2 \times 100 \times 199 = \boxed{39800}$$
