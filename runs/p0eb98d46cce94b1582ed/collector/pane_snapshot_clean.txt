## Setup

Place the isosceles triangle with B = (0,0), C = (2a cos α, 0), A = (a cos α, a
sin α). Set a = 1 (scale at end). Let s = sin α, c = cos α. The base BC has leng
th 2c, and the apex angle is π − 2α.

An inscribed triangle has D on BC, E on AB, F on AC. We minimize max(DE, DF, EF)
.

## Key Lemma: Symmetrization

**Claim:** The optimum is achieved by a triangle symmetric about the axis of sym
metry x = c.

**Proof:** For any inscribed triangle DEF, let D'E'F' be its reflection across t
he axis (D' on BC, E' on AC, F' on AB), with all side lengths preserved. Define
the symmetrized triangle:
- D* = midpoint of D, D' (on BC, on the axis)
- E* = midpoint of E, F' (on AB)
- F* = midpoint of F, E' (on AC)

By the triangle inequality:
- D*E* = |(D−E) + (D'−F')|/2 ≤ (DE + D'F')/2 = (DE + DF)/2 ≤ L
- D*F* = |(D−F) + (D'−E')|/2 ≤ (DF + DE)/2 ≤ L
- E*F* = |(E−F) + (F'−E')|/2 ≤ (EF + EF)/2 = EF ≤ L

So the symmetric triangle D*E*F* has max side ≤ L. ∎

## Solving the Symmetric Case

With D = (c, 0) on the axis, E = (tc, ts) on AB, F = ((2−t)c, ts) on AC (symmetr
ic), set u = 1−t:

- DE = DF = √(u²c² + (1−u)²s²) =: g(u)
- EF = 2uc =: h(u)

g(u)² = u² − 2us² + s² (convex, minimized at u = s²), h(u) is linear increasing.
 Since g(0) = s > 0 = h(0) and h(1) = 2c > c = g(1), they cross at some u* ∈ (0,
1). The minimum of max(g, h) is at the crossing g(u*) = h(u*), giving an **equil
ateral** inscribed triangle.

Setting g² = h²:
u²(1 − 4c²) − 2us² + s² = 0

**L\*/a = h(u*) = 2sc(c√3 − s)/(4c² − 1)**
