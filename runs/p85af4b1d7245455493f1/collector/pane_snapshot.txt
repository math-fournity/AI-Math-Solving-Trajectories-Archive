## Proof

Let $X_1, X_2, \ldots$ be i.i.d. with $X_k \sim \text{Exp}(1)$, so $\mathbb{P}(X
_k \le x) = 1 - e^{-x}$ for $x \ge 0$. Set $\xi_n = \max_{1\le k\le n} X_k$ and
$\eta_n = \xi_n/\ln n$. We show $\eta_n \xrightarrow{p} 1$ (in fact the converge
nce is almost sure).

**Distribution of the maximum.** By independence,
$$\mathbb{P}(\xi_n \le x) = \mathbb{P}(X_1\le x,\ldots,X_n\le x) = (1-e^{-x})^n,
 \qquad x\ge 0.$$

**Upper bound: $\mathbb{P}(\eta_n > 1+\varepsilon)\to 0$.** For any $\varepsilon
>0$,
$$\mathbb{P}(\eta_n > 1+\varepsilon) = \mathbb{P}\bigl(\xi_n > (1+\varepsilon)\l
n n\bigr) = 1 - \bigl(1 - e^{-(1+\varepsilon)\ln n}\bigr)^n.$$
Since $e^{-(1+\varepsilon)\ln n} = n^{-(1+\varepsilon)}$, we have $n\cdot n^{-(1
+\varepsilon)} = n^{-\varepsilon}\to 0$. Using $(1-a_n)^n \to 1$ whenever $na_n\
to 0$,
$$\mathbb{P}(\eta_n > 1+\varepsilon) = 1 - (1 - n^{-(1+\varepsilon)})^n \to 1 -
1 = 0.$$

**Lower bound: $\mathbb{P}(\eta_n < 1-\varepsilon)\to 0$.** For any $\varepsilon
\in(0,1)$,
$$\mathbb{P}(\eta_n \le 1-\varepsilon) = \mathbb{P}\bigl(\xi_n \le (1-\varepsilo
n)\ln n\bigr) = \bigl(1 - e^{-(1-\varepsilon)\ln n}\bigr)^n = \bigl(1 - n^{-(1-\
varepsilon)}\bigr)^n.$$
Now $n\cdot n^{-(1-\varepsilon)} = n^{\varepsilon}\to\infty$, so using $\log(1-a
_n)^n = n\log(1-a_n)\sim -na_n = -n^{\varepsilon}\to -\infty$,
$$\mathbb{P}(\eta_n \le 1-\varepsilon) = (1-n^{-(1-\varepsilon)})^n \sim e^{-n^{
\varepsilon}}\to 0.$$
Hence $\mathbb{P}(\eta_n < 1-\varepsilon)\to 0$.

**Combining.** For every $\varepsilon>0$,
$$\mathbb{P}(|\eta_n - 1|>\varepsilon) = \mathbb{P}(\eta_n>1+\varepsilon) + \mat
hbb{P}(\eta_n<1-\varepsilon)\to 0.$$
Therefore $\eta_n \xrightarrow{p} 1$.

**Almost sure convergence (sketch).** The convergence is in fact a.s. Take $\var
epsilon_n = \varepsilon$ fixed and use a subsequence $n_k = \lceil k^{2/\varepsi
lon}\rceil$; then $\sum_k \mathbb{P}(\eta_{n_k}>1+\varepsilon) \le \sum_k n_k^{-
\varepsilon} <\infty$ and $\sum_k \mathbb{P}(\eta_{n_k}<1-\varepsilon)\le\sum_k
e^{-n_k^\varepsilon}<\infty$, so by Borel–Cantelli $\eta_{n_k}\to 1$ a.s. Monoto
nicity of $\xi_n$ in $n$ fills in the gaps between subsequence points, giving $\
eta_n\to 1$ a.s.

The limit is

$$\boxed{1}.$$
