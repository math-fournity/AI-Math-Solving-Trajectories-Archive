# Problem

In a futuristic automated factory, a robotic assembly line produces modular power cores. These cores are composed of a linear sequence of two types of components: **Actuators (A)** and **Batteries (B)**. The factory’s operating protocol strictly dictates which sequences are valid configurations:

1.  **Baseline Configurations:** There are no valid power cores consisting of only a single component. The only valid configurations of length 2 are **AB** and **BB**.
2.  **Recursive Assembly Rule:** For any length $n > 2$, a sequence of $n$ components is considered a valid power core if and only if it can be constructed from a shorter valid core using the "Upgrade Protocol." In this protocol, every **Actuator (A)** in the original core remains exactly where it is, while every **Battery (B)** in the original core is replaced by any valid power core (different batteries within the same core can be replaced by different valid cores).

Determine the number of distinct valid power core configurations of length $n$.
