## Solution

**Setup.** Let $B = A + A^T - 2012I_n$. Since both $A+A^T$ and $2012I_n$ are sym
metric, $B$ is a real symmetric matrix, hence diagonalizable. The condition is $
B^{2013} = E_n$, where $E_n = \mathbf{1}\mathbf{1}^T$ is the all-ones matrix (ra
nk 1).

**Step 1: Determine $B$.** Since $B$ is diagonalizable, $\operatorname{rank}(B^{
2013}) = \operatorname{rank}(B)$. As $\operatorname{rank}(E_n)=1$, we get $\oper
atorname{rank}(B)=1$. A real symmetric rank-1 matrix has the form $B = \lambda v
v^T$ for some unit vector $v$ and scalar $\lambda$. Then $B^{2013} = \lambda^{20
13}vv^T$. Setting this equal to $E_n = \mathbf{1}\mathbf{1}^T$ forces $v = \pm\m
athbf{1}/\sqrt{n}$ and $\lambda^{2013}\cdot\tfrac{1}{n} = 1$, i.e. $\lambda = n^
{1/2013}$. Therefore
$$B = n^{1/2013}\cdot\tfrac{1}{n}\,E_n = n^{-2012/2013}\,E_n.$$

**Step 2: The symmetric part of $A$.** From $A + A^T = 2012I_n + n^{-2012/2013}E

$$\frac{A+A^T}{2} = 1006\,I_n + \tfrac{1}{2}\,n^{-2012/2013}\,E_n.$$
Its eigenvalues are $1006$ (multiplicity $n-1$, eigenvectors $\perp \mathbf{1}$)
 and $1006 + \tfrac{1}{2}n^{1/2013}$ (multiplicity $1$, eigenvector $\mathbf{1}$
). Both are strictly positive, so $\frac{A+A^T}{2}$ is **positive definite**.

**Step 3: $A$ is nonsingular.** Write $A = \frac{A+A^T}{2} + K$ where $K = \frac
{A-A^T}{2}$ is skew-symmetric. For any vector $x$,
$$x^T A x = x^T\frac{A+A^T}{2}x + x^T K x = x^T\frac{A+A^T}{2}x,$$
since $x^T K x = 0$ for skew-symmetric $K$. By positive definiteness, $x^TAx > 0
$ for every $x\neq 0$.

Suppose $Ax = 0$ for some $x$. Then $x^TAx = 0$, which forces $x = 0$. Hence $\k
er(A) = \{0\}$, so $A$ is invertible and $\operatorname{rank}(A) = n$.

**Step 4: Attainability.** Taking $A = \frac{1}{2}(2012I_n + n^{-2012/2013}E_n)$
 (i.e., $K=0$) gives a symmetric positive definite matrix of rank $n$ satisfying

**Conclusion.** Every admissible $A$ has full rank, so the minimum possible valu
e is

$$\boxed{n}.$$
