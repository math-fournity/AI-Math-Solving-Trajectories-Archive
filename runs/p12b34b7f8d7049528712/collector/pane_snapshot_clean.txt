## 解答

**设置。** 设 $C_0$ 为直角顶点，$A$ 在 $(a,0)$，$B$ 在 $(0,b)$，斜边 $c = AB = \
sqrt{a^2+b^2}$。$(a,b,c)$ 为一个本原毕达哥拉斯三元组。

**递归。** $C_1$ 是从 $C_0$ 到 $\overline{AB}$ 的垂足。三角形 $C_0C_1B$ 在 $C_1$
 处为直角，斜边为 $C_0B = b$，边长分别为 $C_0C_1 = ab/c$ 和 $C_1B = b^2/c$ — 它
与原三角形相似，比例为 $b/c$。

对于 $n \geq 2$，$C_n$ 是 $\triangle C_{n-2}C_{n-1}B$ 中斜边 $C_{n-2}B$ 上的垂足
，产生一个相似的子三角形，其比例为 $b/c$。通过归纳法计算各段长度：

$$C_{n-1}C_n = a\!\left(\frac{b}{c}\right)^{\!n}, \quad n \geq 1.$$

**验证：** $C_0C_1 = ab/c$ ✓；$C_1C_2 = ab^2/c^2$ ✓（三角形 $C_0C_1B$ 中斜边 $b$
 上的高，长度为 $\frac{(ab/c)(b^2/c)}{b} = ab^2/c^2$）；每一步都以比例 $b/c$ 缩
放。

**求和。** 该条件为 $\displaystyle\sum_{n=2}^{\infty} C_{n-2}C_{n-1} = \sum_{k=1
}^{\infty} a\!\left(\frac{b}{c}\right)^{\!k} = \frac{ab/c}{1-b/c} = \frac{ab}{c-
b} = 6p = 6(a+b+c).$

**本原毕达哥拉斯参数化。** 令 $a = m^2-n^2,\ b = 2mn,\ c = m^2+n^2$，其中 $m>n\g
eq 1$，$\gcd(m,n)=1$，且 $m,n$ 奇偶性不同。

- $c - b = (m-n)^2$, $\ ab = 2mn(m-n)(m+n)$, $\ a+b+c = 2m(m+n)$.

$$\frac{2mn(m-n)(m+n)}{(m-n)^2} = 12m(m+n) \implies \frac{2n}{m-n} = 12 \implies
 m = 7,\ n = 6.$$

（$\gcd(7,6)=1$，奇偶性不同 ✓。）得到 $a=13,\ b=84,\ c=85$，两两互素 ✓。

**验证：** $\dfrac{ab}{c-b} = \dfrac{13\cdot 84}{85-84} = 1092 = 6\cdot 182 = 6p
$ ✓。

另一种赋值 $a=2mn,\ b=m^2-n^2$ 得到 $m=13,\ n=1$，两者均为奇数 — 违反了奇偶性条
件，因此没有有效的本原三元组。

$$p = 13 + 84 + 85 = \boxed{182}.$$
