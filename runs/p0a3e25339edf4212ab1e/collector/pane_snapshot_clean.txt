## Proof

**Claim:** Yes. Every open subset $A \subseteq \mathbb{C}$ can be expressed as a
 countable union $A = \bigcup_{i=1}^{\infty} U_i$ of pairwise disjoint, connecte
d, open sets.

**Proof.** We use three standard topological facts about $\mathbb{C}$ (equivalen
tly $\mathbb{R}^2$):

**Fact 1 ($\mathbb{C}$ is locally connected).** Every point $z \in \mathbb{C}$ h
as a neighborhood basis consisting of connected open sets, namely the open disks
 $D(z, r) = \{w : |w - z| < r\}$, each of which is convex and hence connected.

**Fact 2 (Connected components of an open set in a locally connected space are o
pen).** Let $A \subseteq \mathbb{C}$ be open, and let $C$ be a connected compone
nt of $A$. For any $z \in C$, since $A$ is open there exists $r > 0$ with $D(z,
r) \subseteq A$. By local connectedness we may shrink $r$ so that $D(z, r)$ is c
onnected (open disks are connected). Then $C \cup D(z, r)$ is a connected subset
 of $A$ (since $z \in C \cap D(z, r)$, the union of two connected sets with none
mpty intersection is connected). By maximality of the component $C$, we have $D(
z, r) \subseteq C$. Thus $C$ contains an open disk around each of its points, so
 $C$ is open.

**Fact 3 ($\mathbb{C}$ is second-countable, hence every family of pairwise disjo
int open sets is countable).** The collection $\{D(q, r) : q \in \mathbb{Q}+i\ma
thbb{Q},\; r \in \mathbb{Q}_{>0}\}$ is a countable base for the topology of $\ma
thbb{C}$. Now let $\{V_\alpha\}_{\alpha}$ be any family of pairwise disjoint non
empty open sets. For each $\alpha$, pick a point $z_\alpha \in V_\alpha$; since
$V_\alpha$ is open and the rational disks form a base, there exists a basic open
 set $B_\alpha = D(q_\alpha, r_\alpha)$ with $z_\alpha \in B_\alpha \subseteq V_
\alpha$. Because the $V_\alpha$ are pairwise disjoint, the $B_\alpha$ are pairwi
se distinct (if $B_\alpha = B_\beta$ then $B_\alpha \subseteq V_\alpha \cap V_\b
eta$, forcing $\alpha = \beta$). Thus the map $\alpha \mapsto B_\alpha$ is injec
tive into a countable set, so the index set is countable.

**Assembling the proof.** Let $A \subseteq \mathbb{C}$ be open. Let $\{C_\alpha\
}_{\alpha \in I}$ be the collection of connected components of $A$. By the gener
al theory of connected components:

- The components partition $A$: $A = \bigcup_{\alpha \in I} C_\alpha$, and the $
C_\alpha$ are pairwise disjoint.
- Each $C_\alpha$ is connected (by definition of component).
- By Fact 2, each $C_\alpha$ is open (since $A$ is open and $\mathbb{C}$ is loca
lly connected).
- By Fact 3, the index set $I$ is countable (the $C_\alpha$ are pairwise disjoin
t, nonempty, open subsets of the second-countable space $\mathbb{C}$).

Enumerate $I = \{1, 2, 3, \dots\}$ (or a finite subset thereof, if $A$ has finit
ely many components — the empty set corresponds to the empty union, and we may p
ad with $\emptyset$ if a countably infinite enumeration is desired). Setting $U_
i = C_i$, we obtain

$$A = \bigcup_{i=1}^{\infty} U_i,$$

where the $U_i$ are pairwise disjoint, connected, and open. $\blacksquare$

**Remark.** The argument uses only that $\mathbb{C}$ is locally connected and se
cond-countable, so the result holds for any open subset of $\mathbb{R}^n$ (indee
d any locally connected, second-countable space). The connected components are t
he *unique* maximal such decomposition: any decomposition of an open set into di
sjoint connected open sets must coincide with the decomposition into connected c
omponents, since a connected open set cannot be split across two components, and
 each component, being connected, must lie entirely within a single piece of any
 such partition.
