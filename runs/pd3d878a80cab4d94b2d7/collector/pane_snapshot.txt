## Proof (Dirichlet's Simultaneous Approximation Theorem)

**Theorem.** For any real numbers $\gamma_1, \ldots, \gamma_N$ and any integer $
Q \geq 1$, there exists a positive integer $q$ with $1 \leq q \leq Q^N$ such tha
t
$$\max_{1 \leq i \leq N} \|q\gamma_i\| \leq \frac{1}{Q}.$$

Setting $Q = \lceil 1/\epsilon \rceil$ yields $q \leq \lceil 1/\epsilon \rceil^N
$ and $\max_i \|q\gamma_i\| \leq 1/Q \leq \epsilon$. When $1/\epsilon \in \mathb
b{Z}$, this is exactly $q \leq 1/\epsilon^N$ and $\max_i \|q\gamma_i\| \leq \eps
ilon$.

**Proof.**

Fix an integer $Q \geq 1$. Partition the half-open unit cube $[0,1)^N$ into $Q^N
$ sub-cubes:
$$C_{j_1,\ldots,j_N} = \prod_{i=1}^{N} \left[\frac{j_i}{Q},\, \frac{j_i+1}{Q}\ri
ght), \quad j_i \in \{0, 1, \ldots, Q-1\}.$$

Each sub-cube has side length $1/Q$.

Now consider the $Q^N + 1$ points in $[0,1)^N$ defined by
$$P_k = \bigl(\{k\gamma_1\},\, \{k\gamma_2\},\, \ldots,\, \{k\gamma_N\}\bigr), \
quad k = 0, 1, \ldots, Q^N,$$
where $\{x\} = x - \lfloor x \rfloor$ denotes the fractional part.

Since there are $Q^N + 1$ points but only $Q^N$ sub-cubes, by the **pigeonhole p
rinciple** there exist indices $a, b$ with $0 \leq a < b \leq Q^N$ such that $P_
a$ and $P_b$ lie in the same sub-cube.

Set $q = b - a$. Then $q$ is a positive integer with $1 \leq q \leq Q^N$.

For each $i \in \{1, \ldots, N\}$, since $P_a$ and $P_b$ are in the same sub-cub
e of side $1/Q$:
$$\left|\{b\gamma_i\} - \{a\gamma_i\}\right| \leq \frac{1}{Q}.$$

Now observe:
$$\{b\gamma_i\} - \{a\gamma_i\} = (b\gamma_i - \lfloor b\gamma_i \rfloor) - (a\g
amma_i - \lfloor a\gamma_i \rfloor) = (b-a)\gamma_i - \underbrace{(\lfloor b\gam
ma_i \rfloor - \lfloor a\gamma_i \rfloor)}_{=:\, m_i \,\in\, \mathbb{Z}} = q\gam
ma_i - m_i.$$

Therefore:
$$\|q\gamma_i\| = \min_{n \in \mathbb{Z}} |q\gamma_i - n| \leq |q\gamma_i - m_i|
 = \left|\{b\gamma_i\} - \{a\gamma_i\}\right| \leq \frac{1}{Q}.$$

This holds for every $i = 1, \ldots, N$, so:
$$\max_{1 \leq i \leq N} \|q\gamma_i\| \leq \frac{1}{Q}. \qquad \blacksquare$$

## The Algorithm

The proof is **constructive** and directly yields an algorithm:

1. **Input:** reals $\gamma_1, \ldots, \gamma_N$, parameter $\epsilon > 0$.
2. Compute $Q = \lceil 1/\epsilon \rceil$.
3. For each $k = 0, 1, \ldots, Q^N$:
   - Compute the fractional parts $\{k\gamma_i\}$ for $i = 1, \ldots, N$.
   - Determine the sub-cube index $(j_1, \ldots, j_N)$ where $j_i = \lfloor Q \c
dot \{k\gamma_i\} \rfloor$.
   - Store (or hash) the pair (sub-cube index, $k$).
4. When a collision is found — two values $k = a$ and $k = b$ ($a < b$) mapping
to the same sub-cube — output $q = b - a$.

**Correctness:** By the theorem, $1 \leq q \leq Q^N \leq (1/\epsilon + 1)^N$ and
 $\max_i \|q\gamma_i\| \leq 1/Q \leq \epsilon$. When $1/\epsilon$ is a positive
integer, $Q = 1/\epsilon$ exactly, giving $q \leq 1/\epsilon^N$ and $\max_i \|q\
gamma_i\| \leq \epsilon$.

**Complexity:** The algorithm examines $Q^N + 1$ points, each requiring $O(N)$ w
ork to compute fractional parts and sub-cube indices. Using a hash table for col
lision detection, the total running time is $O(N \cdot Q^N) = O(N \cdot \lceil 1
/\epsilon \rceil^N)$, which is polynomial in $1/\epsilon$ for fixed $N$.
