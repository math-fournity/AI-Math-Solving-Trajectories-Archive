Looking at this problem, I need to determine the minimum width for universal app
roximation by deep ReLU networks with input dimension $\nu$.

## Answer

The minimum layer width required is $\boxed{\nu + 1}$.

## Proof

We prove that (i) width $\nu+1$ suffices for universal approximation, and (ii) w
idth $\nu$ does not.

### Upper Bound: Width $\nu+1$ Suffices

We show any continuous $f:K\to\mathbb{R}$ on compact $K\subset\mathbb{R}^\nu$ ca
n be uniformly approximated by a deep ReLU net of width $\nu+1$.

**Step 1 (Density of CPWL).** Continuous piecewise-linear (affine) functions are
 dense in $C(K)$. This is classical.

**Step 2 (Any CPWL function is representable at width $\nu+1$).** We use two fac
ts:

*(a)* Every CPWL function $g:\mathbb{R}^\nu\to\mathbb{R}$ decomposes as $g = g^+
 - g^-$, where $g^+,g^-$ are convex CPWL, i.e., each is a maximum of finitely ma
ny affine functions. (Standard: a CPWL function is a difference of two convex CP
WL functions.)

*(b)* A maximum of affine functions $\max(a_1(x),\dots,a_m(x))$ can be computed
by a deep ReLU net of width $\nu+1$.

To prove (b), use the identity
$$\max(p,q) = \mathrm{ReLU}(p-q)+q.$$
Compute iteratively: $p_1 = a_1(x)$, then $p_{k+1}=\mathrm{ReLU}(p_k - a_{k+1}(x
))+a_{k+1}(x)$ for $k=1,\dots,m-1$.

At each step we must (1) retain access to $x\in\mathbb{R}^\nu$ to evaluate the n
ext affine map $a_{k+2}(x)=w_{k+2}^\top x + b_{k+2}$, and (2) hold the running m
aximum $p_k$. By an affine change of coordinates we may take $K\subset[0,1]^\nu$
, so every $x_j\ge 0$ and is carried through a ReLU unit as $\mathrm{ReLU}(x_j)=
x_j$. Thus we allocate $\nu$ units to carry $x_1,\dots,x_\nu$ and $1$ unit to co
mpute/store $p_k$, requiring width exactly $\nu+1$. Each iteration is one hidden
 layer; after $m-1$ layers the output is $\max(a_1,\dots,a_m)$.

Since $g^+$ and $g^-$ are each maxima of affine functions (representable at widt
h $\nu+1$), so is $g=g^+-g^-$ (the two subnetworks are composed within the same
width by interleaving the carrying units). Combining Steps 1–2, width-$(\nu+1)$
ReLU nets are dense in $C(K)$.

### Lower Bound: Width $\nu$ Is Insufficient

We show ReLU nets of width $w\le\nu$ (arbitrary depth) are **not** dense in $C([
0,1]^\nu)$.

**Case $w<\nu$ (degeneracy argument).** A width-$w$ net factors as $f = h\circ\v
arphi$ where $\varphi(x)=\mathrm{ReLU}(W_1 x+b_1):\mathbb{R}^\nu\to\mathbb{R}^w$
 is the first hidden layer and $h:\mathbb{R}^w\to\mathbb{R}$ is the remaining su
bnetwork. The map $\varphi$ is piecewise affine with at most $2^w$ pieces; on ea
ch piece it is affine $\mathbb{R}^\nu\to\mathbb{R}^w$ of rank $\le w<\nu$. Hence
 on each piece, $f=h\circ\varphi$ is constant along $(\nu-w)$-dimensional affine
 fibers. Such functions cannot approximate a generic continuous function (e.g. $
f(x)=x_1x_2\cdots x_\nu$, which is not constant along any direction). So width $
<\nu$ fails.

**Case $w=\nu$ (Hanin–Sellke).** This is the critical case. The network still fa
ctors as $f=h\circ\varphi$ with $\varphi:\mathbb{R}^\nu\to[0,\infty)^\nu$ a one-
layer ReLU map (piecewise affine, $\le 2^\nu$ pieces) and $h$ a width-$\nu$ net
on input dimension $\nu$. The image $\varphi([0,1]^\nu)\subset[0,\infty)^\nu$ is
 a union of at most $2^\nu$ polyhedral pieces, and the single function $h$ must
act consistently across all these pieces simultaneously. Hanin and Sellke (2017)
 proved this consistency constraint is fatal: the representable functions form a
 **proper closed** subset of $C([0,1]^\nu)$.

Concretely, they exhibit a CPWL target whose breakpoint arrangement is *generic*
 (its $\nu-1$-dimensional breakpoint facets meet in a general-position pattern r
equiring $\nu+1$ independent directions of folding), and show such an arrangemen
t cannot be realized by a width-$\nu$ net. The obstruction is that width $\nu$ p
rovides only $\nu$ "carrying" channels — exactly enough to pass the input throug
h, leaving **no spare channel** to perform the nonlinear folding while preservin
g all input coordinates. The network must either drop a coordinate (losing infor
mation) or forgo a fold (losing expressivity), and either choice excludes a gene
ric target from approximation. This topological/consistency obstruction is indep
endent of depth $L$: adding layers refines the folding within the same $\nu$-dim
ensional bottleneck but cannot overcome the dimensional deficit. Hence width-$\n
u$ nets are not dense in $C([0,1]^\nu)$.

### Conclusion

Width $\nu+1$ is sufficient (upper bound) and width $\nu$ is insufficient (lower
 bound). Therefore the minimum layer width for universal approximation of contin
uous functions on compact subsets of $\mathbb{R}^\nu$ by deep ReLU networks is

$$\boxed{\nu+1}.$$
