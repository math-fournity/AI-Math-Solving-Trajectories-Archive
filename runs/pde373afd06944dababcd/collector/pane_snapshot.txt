## 解答

**设置。** 设放置在点 $A, B, C, D, E, F$ 上的数字分别为 $a, b, c, d, e, f$，其中
 $\{a,b,c,d,e,f\} = \{1,2,3,4,5,6\}$。定义 $S_{XYZ}$ 为放置在点 $X, Y, Z$ 上的三
个数字的乘积。我们希望最大化：

$$S = aef + bdf + cde + def.$$

**观察。** 点 $D, E, F$ 分别出现在 4 项中的 3 项中，而 $A, B, C$ 各出现一次。此
外，$def$ 是一个独立项。因式分解如下：

$$S = def + ef\cdot a + df\cdot b + de\cdot c.$$

**第一步：确定 $\{d,e,f\} = \{4,5,6\}$。**

对于任何将 $\{d,e,f\}$ 固定为 3 元素子集 $\{p \le q \le r\}$ 且补集为 $\{x \le y
 \le z\}$ 的选择，三个乘积为 $pq \le pr \le qr$。根据**排序不等式**（Rearrangeme
nt Inequality），$ef\cdot a + df\cdot b + de\cdot c$ 的最大值通过将最小的 $a$ 与
最小的乘积配对，最大的 $a$ 与最大的乘积配对得到：

$$\max S = pqr + x\cdot pq + y\cdot pr + z\cdot qr.$$

计算 $\{1,\dots,6\}$ 中所有 $\binom{6}{3}=20$ 个子集（此处选择关键临界点）：

| $\{p,q,r\}$ | $pqr$ | 补集 $\{x,y,z\}$ | $\max S$ |
|---|---|---|---|
| $\{3,5,6\}$ | 90 | $\{1,2,4\}$ | $90+15+36+120=261$ |
| $\{3,4,6\}$ | 72 | $\{1,2,5\}$ | $72+12+36+120=240$ |
| $\{2,5,6\}$ | 60 | $\{1,3,4\}$ | $60+10+36+120=226$ |
| $\{4,5,6\}$ | **120** | $\{1,2,3\}$ | $120+20+48+90=\mathbf{278}$ |

所有其他选择产生的值都严格小于 278（完整枚举确认最大值在 $\{4,5,6\}$ 处唯一取得
）。因此，$\{d,e,f\}=\{4,5,6\}$ 且 $\{a,b,c\}=\{1,2,3\}$。

**第二步：计算最优排列的数量。**

在 $\{d,e,f\}=\{4,5,6\}$ 的条件下，三个乘积 $\{ef, df, de\}$ 始终为 $\{20, 24, 3
0\}$（以某种顺序排列）——这是互不相同的。值 $\{a,b,c\}=\{1,2,3\}$ 也是互不相同的
。根据排序不等式，$a\cdot ef + b\cdot df + c\cdot de$ 的最大值是**唯一**实现的，
即通过将 $3$ 与最大乘积配对，$2$ 与中间乘积配对，$1$ 与最小乘积配对。

对于 $(d,e,f)$ 的 $3! = 6$ 种排列中的每一种，$\{ef, df, de\}$ 的排序是确定的，并
且存在唯一的最优分配 $(a,b,c)$。所有 6 种情况都得出 $S = 158 + 120 = 278$：

| $(d,e,f)$ | $(ef, df, de)$ | 最优 $(a,b,c)$ | $S$ |
|---|---|---|---|
| $(4,5,6)$ | $(30,24,20)$ | $(3,2,1)$ | $90+48+20+120=278$ |
| $(4,6,5)$ | $(30,20,24)$ | $(3,1,2)$ | $90+20+48+120=278$ |
| $(5,4,6)$ | $(24,30,20)$ | $(2,3,1)$ | $48+90+20+120=278$ |
| $(5,6,4)$ | $(24,20,30)$ | $(2,1,3)$ | $48+20+90+120=278$ |
| $(6,4,5)$ | $(20,30,24)$ | $(1,3,2)$ | $20+90+48+120=278$ |
| $(6,5,4)$ | $(20,24,30)$ | $(1,2,3)$ | $20+48+90+120=278$ |

**结论。** $S_{AEF}+S_{BDF}+S_{CDE}+S_{DEF}$ 的最大值为 $278$，并且恰好有 $\boxe
d{6}$ 种放置方式可以实现该最大值。
