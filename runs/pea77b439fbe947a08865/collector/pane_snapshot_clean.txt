## 解答

**建立坐标系：** 将棋盘的行和列编号为 1 到 5。Erick 从 (2,2) 出发。四个角落分别
是：(1,1)=$1，(1,5)=$5，(5,1)=$5，(5,5)=$1。

**定义 p(r,c)** = 从 (r,c) 出发，在到达其他任何角落之前先到达 (1,1) 的概率。边界
条件：p(1,1)=1，p(1,5)=0，p(5,1)=0，p(5,5)=0。对于所有非角落的方格，p(r,c) = 其
相邻方格 p 值的平均数。

**利用对称性：** 沿主对角线 (r=c) 反射保持 (1,1) 不变，因此 p(r,c) = p(c,r)。这
给出了 12 个不同的变量：

| 变量 | 方格 |
|------|--------|
| A | (1,2),(2,1) |
| B | (1,3),(3,1) |
| C | (1,4),(4,1) |
| D | (2,2) |
| E | (2,3),(3,2) |
| F | (2,4),(4,2) |
| G | (3,3) |
| H | (2,5),(5,2) |
| I | (3,4),(4,3) |
| J | (3,5),(5,3) |
| K | (4,4) |
| L | (4,5),(5,4) |

**方程组** (每个代表方格的相邻方格平均值)：

- A = (1 + B + D)/3
- B = (A + C + E)/3
- C = (B + F)/3
- D = (A + E)/2
- E = (B + G + D + F)/4
- F = (C + I + E + H)/4
- G = (E + I)/2
- H = (J + F)/3
- I = (F + K + G + J)/4
- J = (H + L + I)/3
- K = (I + L)/2
- L = (J + K)/3

**求解：** 从 D = (A+E)/2 得出 A = 2D−E。从第一个方程得出 B = 5D−3E−1。从第二个
方程得出 C = 13D−9E−3。从第三个方程得出 F = 34D−24E−8。从 E 的方程和 G=(E+I)/2
得出 G = 31E−40D+9 且 I = 61E−80D+18。从 F 的方程得出 H = 203D−149E−47。从 H 的
方程得出 J = 575D−423E−133。从 I 的方程得出 K = 660E−889D+204。从 K 的方程得出 L
 = 1259E−1698D+390。

将 L 代入最后一个方程 (3L = J + K)：
$$3540E = 4780D - 1099$$

使用 J = (H+L+I)/3：
$$3300D - 2440E = 760$$

求解：将 E = (4780D−1099)/3540 代入 165D − 122E = 38：
$$165D - \frac{122(4780D - 1099)}{3540} = 38$$

乘以 1770：$292050D - 291580D + 67039 = 67260$，得到 $470D = 221$，所以：

$$D = \frac{221}{470}$$

接着 E = 61/188，且 **F = 34D − 24E − 8 = 1/5**。

**计算期望值：** 通过对称性论证：
- P(先到达 (1,1)) = D = 221/470
- P(先到达 (5,5)) = p(4,4) = K = 61/470 (通过 180° 旋转对称性)
- P(先到达 (1,5)) = p(2,4) = F = 1/5 (通过水平翻转对称性)
- P(先到达 (5,1)) = F = 1/5 (通过主对角线对称性)

验证：221/470 + 61/470 + 2/5 = 282/470 + 188/470 = 1。 ✓

$$E = 1 \cdot \frac{282}{470} + 5 \cdot \frac{2}{5} = \frac{141}{235} + 2 = \fra
c{141 + 470}{235} = \frac{611}{235} = \frac{13}{5}$$

其中 gcd(13, 5) = 1，所以 m = 13，n = 5。
