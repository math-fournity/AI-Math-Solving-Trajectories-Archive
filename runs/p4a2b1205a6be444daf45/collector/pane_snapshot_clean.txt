## Proof

0^\infty \frac{e^{-t}-e^{-kt}}{t}\,dt$ (valid for $k\ge 1$), and interchanging t
he finite sum with the integral:

$$S_n := \sum_{k=1}^n(-1)^k\binom{n}{k}\log k = \int_0^\infty \frac{1}{t}\sum_{k
=1}^n(-1)^k\binom{n}{k}(e^{-t}-e^{-kt})\,dt.$$

Computing the two inner sums:
- $\sum_{k=1}^n(-1)^k\binom{n}{k} = (1-1)^n - 1 = -1$, so $\sum_{k=1}^n(-1)^k\bi
nom{n}{k}e^{-t} = -e^{-t}$.
- $\sum_{k=1}^n(-1)^k\binom{n}{k}e^{-kt} = (1-e^{-t})^n - 1$.

Therefore:
$$S_n = \int_0^\infty \frac{1-e^{-t}-(1-e^{-t})^n}{t}\,dt. \tag{1}$$

Note the integrand is non-negative: for $t>0$, $0<1-e^{-t}<1$, so $(1-e^{-t})^n
< 1-e^{-t}$ for $n\ge 2$.

**Step 2: Splitting at $L = \log n$.** Set $L=\log n$ and write $S_n = I_1 + I_2
$ where
$$I_1 = \int_0^L \frac{1-e^{-t}-(1-e^{-t})^n}{t}\,dt, \qquad I_2 = \int_L^\infty
 \frac{1-e^{-t}-(1-e^{-t})^n}{t}\,dt.$$

**Step 3: Asymptotics of $I_1$.** Write $I_1 = \int_0^L \frac{1-e^{-t}}{t}\,dt -
 \int_0^L \frac{(1-e^{-t})^n}{t}\,dt$.

For the first integral, using the classical identity $\int_0^L \frac{1-e^{-t}}{t
}\,dt = \gamma + \log L + E_1(L)$, where $E_1(L)=\int_L^\infty \frac{e^{-t}}{t}\
,dt = O(e^{-L}/L)$ is the exponential integral:
$$\int_0^L \frac{1-e^{-t}}{t}\,dt = \gamma + \log\log n + o(1). \tag{2}$$

For the second integral, we show it is $o(1)$. Using $1-e^{-t}\le e^{-t}$... act
ually, use $(1-e^{-t})^n \le e^{-ne^{-t}}$:
- For $t\in[0,1]$: $(1-e^{-t})^n\le t^n$, so $\int_0^1 \frac{t^n}{t}\,dt = 1/n =
 o(1)$.
- For $t\in[1, L/2]$: $ne^{-t}\ge ne^{-L/2}=\sqrt{n}$, so $(1-e^{-t})^n\le e^{-\
sqrt{n}}$, giving $\int_1^{L/2}\frac{e^{-\sqrt{n}}}{t}\,dt = o(1)$.
- For $t\in[L/2, L]$: substitute $t=L+x$, $x\in[-L/2,0]$. Then $(1-e^{-t})^n\le
e^{-e^{-x}}$, and $\frac{1}{L+x}\le\frac{2}{L}$, so the integral is $\le \frac{2
}{\log n}\int_{-\infty}^0 e^{-e^{-x}}\,dx = O(1/\log n) = o(1)$.

Therefore:
$$I_1 = \gamma + \log\log n + o(1). \tag{3}$$

**Step 4: $I_2 = o(1)$.** Substitute $t = L+x$, $x\in[0,\infty)$. As $n\to\infty
$, $(1-e^{-x}/n)^n\to e^{-e^{-x}}$ and $1-e^{-x}/n\to 1$, so the integrand conve
rges pointwise to $\frac{1-e^{-e^{-x}}}{\log n + x}$. Bounding:
$$I_2 \le \frac{1}{\log n}\int_0^\infty (1-e^{-e^{-x}})\,dx.$$

The integral converges since $1-e^{-e^{-x}}\sim e^{-x}$ as $x\to\infty$. (With t
he substitution $u=e^{-x}$, it equals $\int_0^1 \frac{1-e^{-u}}{u}\,du < \infty$
.) Hence $I_2 = O(1/\log n) = o(1)$.

**Step 5: Conclusion.** Combining (3) and Step 4:
$$S_n = \log\log n + \gamma + o(1).$$

Therefore:
$$\frac{S_n}{\log\log n} = 1 + \frac{\gamma}{\log\log n} + o\!\left(\frac{1}{\lo
g\log n}\right) \xrightarrow{n\to\infty} 1.$$

$$\boxed{\lim_{n\to\infty}\frac{1}{\log\log n}\sum_{k=1}^n(-1)^k\binom{n}{k}\log
 k = 1}$$
