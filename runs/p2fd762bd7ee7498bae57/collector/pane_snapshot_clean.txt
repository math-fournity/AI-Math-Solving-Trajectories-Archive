## Proof

We compute the product measure $(\mu \times \nu)(B)$ where
- $B = \{(x,y) \in [0,1]^2 : x + y \le 1\}$,
- $\mu$ = Lebesgue measure on $[0,1]$,
- $\nu$ = counting measure on $[0,1]$.

**Step 1: Measurability.** $B$ is a closed subset of $[0,1]^2$ (preimage of $(-\
infty, 1]$ under the continuous map $(x,y)\mapsto x+y$), hence Borel, hence belo
ngs to the product $\sigma$-algebra $\mathcal{B}([0,1])\otimes\mathcal{B}([0,1])
$.

**Step 2: Compute the $x$-section.** For each $x \in [0,1]$,
$$B_x = \{y \in [0,1] : x + y \le 1\} = [0,\, 1-x] \cap [0,1].$$
Since $x \in [0,1]$, we have $1-x \in [0,1]$, so $B_x = [0,\, 1-x]$.

**Step 3: Evaluate $\nu(B_x)$.** Counting measure counts the number of points.
- For $x \in [0,1)$: $1-x > 0$, so $B_x = [0, 1-x]$ is an uncountable interval,
hence $\nu(B_x) = \infty$.
- For $x = 1$: $B_1 = [0,0] = \{0\}$, a single point, so $\nu(B_1) = 1$.

Thus $\nu(B_x) = \infty$ for $\mu$-a.e. $x \in [0,1]$ (everywhere except the sin
gle point $x=1$, which has Lebesgue measure $0$).

**Step 4: Apply the product-measure formula.** The product measure is given by
$$(\mu \times \nu)(B) = \int_{[0,1]} \nu(B_x)\, d\mu(x) = \int_0^1 \nu(B_x)\, dx
.$$
Since $\nu(B_x) = \infty$ on $[0,1)$ (a set of full Lebesgue measure),
$$(\mu \times \nu)(B) = \int_0^1 \infty\, dx = \infty.$$

**Step 5: Cross-check via the other iterated integral.** For completeness, the $
y$-section is $B^y = [0, 1-y]$, with $\mu(B^y) = 1 - y \ge 0$. Then
$$\int_{[0,1]} \mu(B^y)\, d\nu(y) = \sum_{y \in [0,1]} (1-y).$$
This is a sum of nonneg­ative terms over an uncountable index set, with $1-y > 0
$ for uncountably many $y$ (namely all $y \in [0,1)$). A sum of nonneg­ative ter
ms over an uncountable set is $+\infty$ whenever uncountably many terms are stri
ctly positive. Hence this iterated integral also equals $\infty$, consistent wit
h the result above.

**Conclusion.** Both iterated integrals agree, and the product measure is

$$(\mu \times \nu)(B) = \infty.$$
