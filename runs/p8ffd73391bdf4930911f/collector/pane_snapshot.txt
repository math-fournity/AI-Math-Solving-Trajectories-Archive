## VC-Dimension of Parity Functions

**Claim:** The VC-dimension of $H_{N\text{-parity}}$ is $N$.

### Upper Bound: $\text{VCdim}(H_{N\text{-parity}}) \le N$

The hypothesis class contains exactly $2^N$ functions (one for each subset $I \s
ubseteq \{1,\dots,N\}$). If a set $S$ of size $d$ is shattered, then all $2^d$ b
inary labelings of $S$ must be realized by *distinct* functions in $H_{N\text{-p
arity}}$. Therefore
$$2^d \le |H_{N\text{-parity}}| = 2^N,$$
which gives $d \le N$.

### Lower Bound: $\text{VCdim}(H_{N\text{-parity}}) \ge N$

Consider the set of $N$ standard basis vectors
$$S = \{e_1, e_2, \dots, e_N\} \subseteq \{0,1\}^N,$$
where $e_i$ is the vector with a $1$ in coordinate $i$ and $0$ elsewhere.

Given any labeling $(y_1, \dots, y_N) \in \{0,1\}^N$, define
$$I = \{i \in \{1,\dots,N\} : y_i = 1\}.$$
Then for each $i$,
$$h_I(e_i) = \left(\sum_{j \in I} (e_i)_j\right) \bmod 2 = \mathbb{1}[i \in I] =
 y_i.$$
Thus every one of the $2^N$ labelings of $S$ is realized by some $h_I \in H_{N\t
ext{-parity}}$, so $S$ is shattered. Hence $\text{VCdim}(H_{N\text{-parity}}) \g
e N$.

### Conclusion

Combining both bounds,
$$\text{VCdim}(H_{N\text{-parity}}) = N.$$
