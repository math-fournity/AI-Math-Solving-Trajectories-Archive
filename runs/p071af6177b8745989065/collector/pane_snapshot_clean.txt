## Proof

Let $X$ be a random variable taking value $a_i$ with probability $p_i$, where $a
_1 < a_2 < \cdots < a_n$ and $p = (p_1, \ldots, p_n)$ lies in the probability si
mplex $\Delta_n = \{p : p_i \ge 0,\ \sum p_i = 1\}$.

**Step 1: Express $\operatorname{Var}(X)$ as a function of $p$.**

$$\operatorname{Var}(X)(p) = \mathbb{E}[X^2] - \mathbb{E}[X]^2 = \sum_{i=1}^n p_
i a_i^2 - \left(\sum_{i=1}^n p_i a_i\right)^2.$$

Define the two maps on $\Delta_n$:
- $\mu(p) = \sum_i p_i a_i$ — the mean (linear in $p$),
- $M_2(p) = \sum_i p_i a_i^2$ — the second moment (linear in $p$).

So $\operatorname{Var}(X)(p) = M_2(p) - \mu(p)^2$.

**Step 2: Show $\operatorname{Var}(X)(\cdot)$ is concave on $\Delta_n$.**

- $M_2(p)$ is linear in $p$, hence both convex and concave.
- $\mu(p)$ is linear in $p$, so $\mu(p)^2$ (composition of the convex function $
x \mapsto x^2$ with a linear map) is **convex** in $p$. Therefore $-\mu(p)^2$ is
 **concave**.
- The sum of two concave functions is concave, so

$$\operatorname{Var}(X)(p) = M_2(p) - \mu(p)^2$$

is **concave** on $\Delta_n$.

**Step 3: The superlevel set of a concave function is convex.**

Let $f$ be concave on a convex domain $C$. Consider the superlevel set $S_\alpha
 = \{p \in C : f(p) \ge \alpha\}$. Take any $p, q \in S_\alpha$ and any $t \in [
0,1]$. By concavity,

$$f(tp + (1-t)q) \ge t\,f(p) + (1-t)\,f(q) \ge t\alpha + (1-t)\alpha = \alpha.$$

Hence $tp + (1-t)q \in S_\alpha$, proving $S_\alpha$ is convex.

**Step 4: Apply to the variance region.**

The simplex $\Delta_n$ is convex. The region

$$\{p \in \Delta_n : \operatorname{Var}(X)(p) \ge \alpha\}$$

is a superlevel set of the concave function $\operatorname{Var}(X)(\cdot)$ restr
icted to the convex domain $\Delta_n$. By Step 3, it is convex.

**Conclusion.** For every positive $\alpha$, the region $\{p \in \Delta_n : \ope
ratorname{Var}(X) \ge \alpha\}$ is convex. The key reason is that variance is a
concave function of the probability distribution (the second moment is linear wh
ile the squared mean is convex, making their difference concave), and superlevel
 sets of concave functions are always convex.
