**Setup.** Let $V$ be a complex vector space with Hermitian inner product, and $
U(V)$ the group of unitary operators. The operator norm is
$$N(a) = \max_{|v|=1} |av| = \|a\|_{\mathrm{op}}.$$
The diameter is $\displaystyle D = \max_{a, b \in U(V)} \|a - b\|_{\mathrm{op}}$
.

**Step 1: Reduction to distance from the identity.**

Since $U(V)$ is a group, for any $a, b \in U(V)$, the element $c = b^{-1}a$ is a
gain unitary. Then
$$a - b = b(b^{-1}a - I) = b(c - I).$$
Left-multiplication by a unitary operator preserves the operator norm: for any o
perator $T$ and unitary $b$,
$$\|bT\|_{\mathrm{op}} = \max_{|v|=1}|bTv| = \max_{|v|=1}|Tv| = \|T\|_{\mathrm{o
p}},$$
since $b$ is an isometry. Hence
$$\|a - b\|_{\mathrm{op}} = \|c - I\|_{\mathrm{op}}, \qquad c = b^{-1}a \in U(V)
.$$
Conversely, every $c \in U(V)$ arises this way (take $b = I$, $a = c$). Therefor
e
$$D = \max_{c \in U(V)} \|c - I\|_{\mathrm{op}}.$$

**Step 2: Spectral evaluation of $\|c - I\|_{\mathrm{op}}$.**

Every unitary operator $c$ is normal, hence unitarily diagonalizable: there exis
ts a unitary $u$ with $c = u \,\mathrm{diag}(\lambda_1, \dots, \lambda_n)\, u^{-
1}$, where each eigenvalue satisfies $|\lambda_i| = 1$ (i.e., $\lambda_i = e^{i\
theta_i}$).

The operator $c - I$ is also normal (it is a normal function of $c$), so its ope
rator norm equals its spectral radius:
$$\|c - I\|_{\mathrm{op}} = \max_{1 \le i \le n} |\lambda_i - 1|.$$

For $\lambda_i = e^{i\theta_i}$ on the unit circle,
$$|\lambda_i - 1| = |e^{i\theta_i} - 1| = 2\left|\sin\frac{\theta_i}{2}\right| \
le 2,$$
with equality if and only if $\theta_i = \pi$, i.e., $\lambda_i = -1$.

Thus $\|c - I\|_{\mathrm{op}} \le 2$ for every unitary $c$.

**Step 3: Attaining the bound.**

Take $c = -I$ (which is unitary since $(-I)^* (-I) = I$). Then $c - I = -2I$, an
d
$$\|c - I\|_{\mathrm{op}} = \|{-2I}\|_{\mathrm{op}} = 2.$$
Equivalently, taking $a = -I$ and $b = I$ in the original formulation gives $\|a
 - b\|_{\mathrm{op}} = \|-2I\|_{\mathrm{op}} = 2$.

**Conclusion.** The maximum is achieved and equals $2$:

$$\boxed{\max_{a, b \in U(V)} N(a - b) = 2.}$$
