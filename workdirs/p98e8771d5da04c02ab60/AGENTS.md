# Problem

In the interconnected kingdom of Othellia, there are $n$ distinct cities. To ensure total connectivity, a high-speed maglev track has been built between every possible pair of cities, such that every city is directly linked to every other city.

The Ministry of Infrastructure has decided to decommission some of these tracks to save on maintenance costs, but they must follow a strict safety protocol: a track can only be removed if it currently forms part of a "Short Loop"—a circular route that passes through exactly four distinct cities and uses exactly four tracks. Each time a track is removed, the network configuration changes, potentially creating or destroying other Short Loops.

The decommissioning process continues one track at a time until no more Short Loops can be found anywhere in the remaining network. What is the maximum number of tracks that can be removed under these constraints?
