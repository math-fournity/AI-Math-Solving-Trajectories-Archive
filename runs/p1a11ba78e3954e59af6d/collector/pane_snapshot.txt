## Problem

Find $\displaystyle \lim_{x \to \infty} \left(\sum_{n=1}^{\infty} \left(\frac{x}
{n}\right)^{n}\right)^{\frac{1}{x}}$.

## Proof

Let $S(x) = \sum_{n=1}^{\infty}\left(\frac{x}{n}\right)^n$. We compute $L = \lim
_{x\to\infty} S(x)^{1/x}$ by determining the asymptotics of $\log S(x)$.

**Step 1: Locate the dominant term.** Write each term as $\exp(g(n))$ where
$$g(n) = n\log\!\left(\frac{x}{n}\right) = n(\log x - \log n), \qquad n > 0.$$
Treating $n$ as a continuous variable: $g'(n) = \log x - \log n - 1 = \log(x/n)
- 1$, so $g'(n)=0 \iff n = x/e$. Since $g''(n) = -1/n < 0$, the function $g$ is
strictly concave with global maximum at $n_0 = x/e$, and
$$g(n_0) = \frac{x}{e}\log e = \frac{x}{e}.$$

**Step 2: Lower bound.** Let $m = \lfloor x/e \rfloor$ (so $|m - n_0| \le 1$). B
y Taylor expansion around $n_0$ and $g''(n_0) = -e/x$,
$$g(m) \ge g(n_0) + \tfrac{1}{2}\,g''(n_0)\cdot 1^2 = \frac{x}{e} - \frac{e}{2x}
.$$
Hence
$$S(x) \ge e^{g(m)} \ge \exp\!\left(\frac{x}{e} - \frac{e}{2x}\right),$$
so $\log S(x) \ge \dfrac{x}{e} - O(1/x)$.

**Step 3: Upper bound.** We split the sum into three regions.

*Region A: $n \le 2n_0$.* For $n$ in $[n_0/2,\, 2n_0]$ (and the few terms below
$n_0/2$ are even smaller since $g$ increases up to $n_0$), Taylor's theorem with
 the bound $g''(\xi) = -1/\xi \le -1/(2n_0) = -e/(2x)$ for $\xi \in [n_0/2, 2n_0
]$ gives
$$g(n) \le \frac{x}{e} - \frac{e}{4x}(n - n_0)^2.$$
Therefore
$$\sum_{n \le 2n_0} e^{g(n)} \le e^{x/e}\sum_{n=-\infty}^{\infty} \exp\!\left(-\
frac{e}{4x}(n-n_0)^2\right) \le e^{x/e}\left(1 + \sqrt{\frac{4\pi x}{e}}\right)
\le C_1\sqrt{x}\, e^{x/e}$$
for a constant $C_1$ (the Gaussian sum is $O(\sqrt{x})$).

*Region B: $2n_0 < n \le x$.* Here $g$ is decreasing (since $n > n_0$), so $g(n)
 \le g(2n_0)$. Compute
$$g(2n_0) = \frac{2x}{e}\log\!\left(\frac{e}{2}\right) = \frac{x}{e}\cdot 2(1 -
\log 2).$$
Since $2(1-\log 2) \approx 0.614 < 1$, there is $\delta = 1 - 2(1-\log 2) = 2\lo
g 2 - 1 > 0$ with
$$g(n) \le \frac{x}{e} - \delta\,\frac{x}{e} \quad\text{for all } n > 2n_0.$$
The number of terms in this region is at most $x$, so
$$\sum_{2n_0 < n \le x} e^{g(n)} \le x\cdot e^{x/e - \delta x/e} = e^{x/e}\cdot
x\,e^{-\delta x/e} = o(e^{x/e}).$$

*Region C: $n > x$.* Here $x/n < 1$, and for $n \ge x+1$ we have $x/n \le x/(x+1
)$, hence
$$\sum_{n > x} \left(\frac{x}{n}\right)^n \le \sum_{n \ge x+1}\left(\frac{x}{x+1
}\right)^n = (x+1)\left(\frac{x}{x+1}\right)^{x+1} = O(x) = o(e^{x/e}).$$

Combining all three regions:
$$S(x) \le C_1\sqrt{x}\, e^{x/e} + o(e^{x/e}) \le C_2\sqrt{x}\, e^{x/e}$$
for large $x$, giving $\log S(x) \le \dfrac{x}{e} + O(\log x)$.

**Step 4: Conclude.** From Steps 2 and 3,
$$\frac{x}{e} - O(1/x) \;\le\; \log S(x) \;\le\; \frac{x}{e} + O(\log x),$$
so
$$\frac{1}{x}\log S(x) \;\longrightarrow\; \frac{1}{e} \qquad (x \to \infty).$$
Therefore
$$\lim_{x\to\infty} S(x)^{1/x} = \lim_{x\to\infty} \exp\!\left(\frac{\log S(x)}{
x}\right) = e^{1/e}.$$

$$\boxed{\displaystyle \lim_{x \to \infty} \left(\sum_{n=1}^{\infty} \left(\frac
{x}{n}\right)^{n}\right)^{\frac{1}{x}} = e^{1/e}}$$
