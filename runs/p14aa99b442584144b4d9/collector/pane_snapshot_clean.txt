## Setting Up the Recurrence

Let $r_i = \frac{a_{i+1}}{a_i}$. The balance law becomes:
$$r_i + \frac{1}{r_{i+1}} = k \quad \Longrightarrow \quad r_{i+1} = \frac{1}{k -
 r_i}$$

## Key Claim: $f(x, x+n)$ Depends Only on $n$

Define $F_n = f(x, x+n)$. I prove by induction that $F_n$ is **independent of th
e starting index $x$** and satisfies $F_{n+2} = kF_{n+1} - F_n$ with $F_0 = 0$,
$F_1 = 1$.

**Base cases** (verified by direct computation):
- $F_1 = f(x,x+1) = 1$
- $F_2 = f(x,x+2) = \frac{a_{x+1}}{a_{x+2}} + \frac{a_{x+1}}{a_x} = \frac{1}{r_{
x+1}} + r_x = k$ (by the balance law)
- $F_3 = k^2 - 1$ (verified by expanding and applying the balance law twice)

**Inductive step:** Using the right-end decomposition:
$$f(x, x+n+1) = \frac{f(x, x+n)}{r_{x+n}} + \frac{a_{x+n}}{a_x}$$

By hypothesis, $f(x,x+n) = F_n$ and $f(x,x+n+1) = F_{n+1}$ (both independent of
$x$). Solving:
$$\frac{a_{x+n}}{a_x} = F_{n+1} - \frac{F_n}{r_{x+n}}$$

Applying the same decomposition at $n+1$:
$$f(x, x+n+2) = \frac{F_{n+1}}{r_{x+n+1}} + \frac{a_{x+n+1}}{a_x} = \frac{F_{n+1
}}{r_{x+n+1}} + \frac{a_{x+n}}{a_x} \cdot r_{x+n}$$

Substituting:
$$f(x, x+n+2) = \frac{F_{n+1}}{r_{x+n+1}} + \left(F_{n+1} - \frac{F_n}{r_{x+n}}\
right) r_{x+n} = \frac{F_{n+1}}{r_{x+n+1}} + F_{n+1}\, r_{x+n} - F_n$$

$$= F_{n+1}\!\left(r_{x+n} + \frac{1}{r_{x+n+1}}\right) - F_n = F_{n+1} \cdot k
- F_n$$

by the balance law. This expression involves **only** $k, F_{n+1}, F_n$ — no dep
endence on $x$. So $F_{n+2} = kF_{n+1} - F_n$ for all $x$. $\square$

## Solving the Recurrence

With $k = 2\cos\theta$ (where $0 < k < 2$ gives $0 < \theta < \pi/2$), the recur
rence $F_{n+2} = 2\cos\theta\, F_{n+1} - F_n$ with $F_0=0, F_1=1$ has the closed
 form:

$$F_n = \frac{\sin(n\theta)}{\sin\theta}$$

(Verified: $F_1 = 1$, $F_2 = 2\cos\theta = k$, $F_3 = 4\cos^2\theta - 1 = k^2 -
1$.)

## Finding the Supremum

Since $f(x,y) = F_{y-x} = \frac{\sin(n\theta)}{\sin\theta}$ where $n = y - x \ge
q 1$, and $|\sin(n\theta)| \leq 1$:

$$f(x,y) \leq \frac{|\sin(n\theta)|}{\sin\theta} \leq \frac{1}{\sin\theta}$$

The smallest $c$ guaranteeing $f(x,y) \leq c$ for all pairs is therefore:

$$c = \frac{1}{\sin\theta} = \frac{1}{\sqrt{1 - k^2/4}} = \frac{2}{\sqrt{4 - k^2
}}$$

This is the least upper bound: when $\theta/\pi$ is irrational, the sequence $\{
n\theta \bmod \pi\}$ is dense in $[0,\pi]$ (by Weyl's equidistribution theorem),
 so $\sin(n\theta)$ gets arbitrarily close to $1$.

## Applying the Specific Configuration

Given $a_1 = 1, a_2 = 1, a_3 = 2$:

$$c = \frac{1}{\sin\theta} = \frac{4}{\sqrt{7}}$$
