# Problem

A specialized logistics firm operates twenty unique distribution centers located at distinct mile markers along a long, straight highway. The manager of the firm is analyzing the network's connectivity and notices a specific property regarding the "Combined Reach" of these centers. 

When the company calculates the sum of the mile markers for every possible pair of centers (including the sum of a center's location with itself), they find that there are exactly 201 unique numerical values in the resulting set of sums.

The manager now needs to determine the "Relative Spacing" of the network. This is defined as the set of all possible differences calculated by subtracting one center's mile marker from another (subtracting the smaller coordinate from the larger, or a coordinate from itself).

Based on the fact that there are exactly 201 unique pairwise sums, what is the minimum possible number of unique values that can exist in the set of pairwise differences?
