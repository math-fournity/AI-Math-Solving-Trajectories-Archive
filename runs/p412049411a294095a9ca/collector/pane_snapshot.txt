## Proof

We expand both equations and simplify.

**Equation 2** gives the key constraint. Expanding the right-hand side:
$$f(a)f(b) + f(c)f(d) = f(a)f(b) + f(a)f(d) + f(c)f(b) + f(c)f(d).$$
Canceling $f(a)f(b) + f(c)f(d)$ from both sides:
$$f(a)f(d) + f(c)f(b) = 0 \quad \text{for all } a, b, c, d. \tag{$\star$}$$

**Equation 1** gives a second constraint. Expanding the right-hand side:
$$f(a)f(b) - f(c)f(d) = f(a)f(b) - f(a)f(d) - f(c)f(b) + f(c)f(d).$$
Canceling $f(a)f(b)$ from both sides:
$$-f(c)f(d) = -f(a)f(d) - f(c)f(b) + f(c)f(d),$$
which rearranges to:
$$f(a)f(d) + f(c)f(b) = 2f(c)f(d) \quad \text{for all } a, b, c, d. \tag{$\star\
star$}$$

**Combining ($\star$) and ($\star\star$):** The left-hand sides are identical, s
o
$$0 = 2f(c)f(d) \quad \text{for all } c, d,$$
hence
$$f(c)f(d) = 0 \quad \text{for all } c, d. \tag{$\star\star\star$}$$

**Deducing $f \equiv 0$:** Set $c = d = x$ in ($\star\star\star$):
$$f(x)^2 = 0 \quad \text{for all } x,$$
so $f(x) = 0$ for all $x$.

**Verification:** For $f \equiv 0$:
- Equation 1: $0 - 0 = (0-0)(0-0) = 0$. ✓
- Equation 2: $0 + 0 = (0+0)(0+0) = 0$. ✓

**Conclusion:** Yes, such a function exists. The unique solution is $f \equiv 0$
