**Step 2: $k$ must have at least 4 digits.**

Consider $n = 1001$. We have $1001k = 1000k + k$. If $k$ has at most 3 digits, t

**Step 3: Among 4-digit numbers, only $k = 9999$ satisfies the $n = 1001$ constr

Let $k = \overline{a_3\, a_2\, a_1\, a_0}$ be a 4-digit number. In the addition
$1000k + k$:
- Positions 0, 1, 2 receive only $a_0, a_1, a_2$ (no carry possible).
- Position 3: $a_0 + a_3$, producing carry $c_4$.
- Position 4: $a_1 + c_4$, producing carry $c_5$.
- Position 5: $a_2 + c_5$, producing carry $c_6$.
- Position 6: $a_3 + c_6$, producing carry $c_7$.

The digit sum without carries is $2s(k)$, so $s(1001k) = 2s(k) - 9C$ where $C =
c_4 + c_5 + c_6 + c_7$. The condition $s(1001k) = s(k)$ requires $C = s(k)/9$.

Now I trace the carry chain:
- If $c_4 = 0$ (i.e., $a_0 + a_3 \le 9$): then $c_5 = c_6 = c_7 = 0$, so $C = 0$

0 + 9 + 9 + 9 = 36$ gives $a_0 = 9$. So $k = 9999$. ✓

Every branch except $k = 9999$ leads to a contradiction. Since $9999$ is the onl

n = 1001$ constraint.

**Step 4: $k = 9999$ satisfies the full condition.**

**Lemma (9's complement):** If $0 \le m \le 9999$, writing $m = \overline{d_3\,
d_2\, d_1\, d_0}$ in 4 digits (with leading zeros), then $9999 - m = \overline{(
9{-}d_3)\,(9{-}d_2)\,(9{-}d_1)\,(9{-}d_0)}$, so $s(9999 - m) = 36 - s(m)$.

*Proof.* Each digit $d_i \le 9$, so $9 - d_i \ge 0$; no borrowing occurs in the
subtraction. ✓

**Main verification:** For $1 \le n \le 2014$, since $n - 1 \le 2013 < 10000$:

$$nk = n \cdot 9999 = n(10000 - 1) = 10000(n-1) + (9999 - (n-1)).$$

$$s(nk) = s(n-1) + s\!\bigl(9999 - (n-1)\bigr) = s(n-1) + 36 - s(n-1) = 36 = s(9
999).$$

This holds for every $n = 1, 2, \ldots, 2014$. ✓

**Step 5: Minimality.**

- Numbers with $\le 3$ digits fail (Step 2).
- Among 4-digit numbers, only $9999$ works (Step 3).
- Numbers with $\ge 5$ digits satisfy $k \ge 10000 > 9999$.
