## 证明

**设置。** 设这三个站点构成一个顶点为 $A, B, C$、边长为 $a, b, c$、面积为 $\Delt
a$、半周长为 $s = (a+b+c)/2$ 的三角形。

- **Guardian Shield（守护盾）** 是穿过所有三个顶点的圆，即 **外接圆**，其圆心为
$O$（外心），半径为 $R$。
- **Exo-Field（外域场）** 是与其中一边相切（在其外部）并与另外两边延长线相切的圆
，即 **旁切圆**。设其为顶点 $A$ 所对的旁切圆，圆心为 $I_a$（旁心），半径为 $r_a$
。

**正交性条件。** 如果两个圆的圆心分别为 $O, I_a$，半径分别为 $R, r_a$，且在它们
的交点处半径相互垂直，则这两个圆是正交的。根据毕达哥拉斯定理，这等价于
$$OI_a^2 = R^2 + r_a^2. \tag{1}$$

**外心与旁心之间的距离。** 这是一个标准结果（欧拉型关系，与内心公式 $OI^2 = R^2
- 2Rr$ 符号相反）：
$$OI_a^2 = R^2 + 2R\,r_a. \tag{2}$$

*验证 (2)。* 对于边长为 $a$ 的等边三角形，有 $R = \tfrac{\sqrt3 a}{3}$，$r_a = \
tfrac{\sqrt3 a}{2}$，且直接计算可得 $OI_a = \tfrac{2\sqrt3 a}{3}$，因此 $OI_a^2
= \tfrac{4a^2}{3}$。同时 $R^2 + 2Rr_a = \tfrac{a^2}{3} + 2\cdot\tfrac{\sqrt3 a}{
3}\cdot\tfrac{\sqrt3 a}{2} = \tfrac{a^2}{3} + a^2 = \tfrac{4a^2}{3}$。 ✓

**求解。** 将 (2) 代入正交性条件 (1) 中：
$$R^2 + 2R\,r_a = R^2 + r_a^2.$$
消去 $R^2$ 并除以 $r_a$（因为 $r_a > 0$）：
$$2R = r_a.$$

因此，Guardian Shield 的半径与 Exo-Field 的半径之比为
$$\boxed{\dfrac{R}{r_a} = \dfrac{1}{2}}.$$
