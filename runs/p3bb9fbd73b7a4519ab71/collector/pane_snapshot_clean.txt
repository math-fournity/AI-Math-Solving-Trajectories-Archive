## Proof

Let $[m] = \{1,2,\dots,m\}$. Then $A = B_n$, the $n$-th Bell number (the number
of set partitions of $[n]$). We must show that $B$, the number of partitions of
$[n+1]$ in which no two consecutive integers lie in the same block, also equals
$B_n$.

**Inclusion–exclusion setup.** For $i = 1,\dots,n$, let $E_i$ be the set of part
itions of $[n+1]$ in which $i$ and $i+1$ belong to the same block. A partition c
ounted by $B$ is precisely one lying in none of the $E_i$, so by inclusion–exclu
sion

$$B = \sum_{S \subseteq [n]} (-1)^{|S|}\, \Bigl|\bigcap_{i\in S} E_i\Bigr|.$$

**Evaluating the intersection.** Fix $S \subseteq [n]$ and form the graph $G_S$
on vertex set $[n+1]$ with edges $\{i,i+1\}$ for each $i \in S$. Since $G_S$ is
a subgraph of the path $1\!-\!2\!-\!\cdots\!-\!(n\!+\!1)$, it is a forest on $n+
1$ vertices with $|S|$ edges, hence has exactly $(n+1)-|S|$ connected components
. These components form a partition $\mathcal C_S$ of $[n+1]$ into $r := (n+1)-|
S|$ groups.

A partition of $[n+1]$ belonging to every $E_i$ with $i \in S$ is exactly a part
ition that *coarsens* $\mathcal C_S$ (each component of $G_S$ must sit inside a
single block). Coarsening a partition of $r$ groups is equivalent to partitionin
g an $r$-element set, giving $B_r$ possibilities. Therefore

$$\Bigl|\bigcap_{i\in S} E_i\Bigr| = B_{(n+1)-|S|}.$$

Substituting and grouping by $|S|=k$,

$$B = \sum_{k=0}^{n} (-1)^k \binom{n}{k}\, B_{n+1-k}. \tag{$\ast$}$$

**An identity for Bell numbers.** We claim that for every $n \ge 0$,

$$B_n = \sum_{k=0}^{n} (-1)^k \binom{n}{k}\, B_{n+1-k}. \tag{$\dagger$}$$

We use the standard Bell recurrence (obtained by examining the block containing
$m+1$):

$$B_{m+1} = \sum_{j=0}^{m} \binom{m}{j} B_j, \qquad m \ge 0,\; B_0 = 1.$$

Apply it with $m = n-k$ to $B_{n+1-k} = \sum_{j=0}^{n-k} \binom{n-k}{j} B_j$ and
 insert into the right side of $(\dagger)$:

$$\sum_{k=0}^{n} (-1)^k \binom{n}{k} B_{n+1-k}
= \sum_{k=0}^{n} (-1)^k \binom{n}{k} \sum_{j=0}^{n-k} \binom{n-k}{j} B_j
= \sum_{j=0}^{n} B_j \sum_{k=0}^{n-j} (-1)^k \binom{n}{k}\binom{n-k}{j}.$$

Using $\binom{n}{k}\binom{n-k}{j} = \binom{n}{j}\binom{n-j}{k}$, the inner sum b
ecomes

$$\binom{n}{j} \sum_{k=0}^{n-j} (-1)^k \binom{n-j}{k} = \binom{n}{j}(1-1)^{\,n-j
}.$$

This equals $\binom{n}{j}$ when $j = n$ and $0$ otherwise. Hence the whole expre
ssion collapses to

$$B_n \cdot \binom{n}{n} \cdot 1 = B_n,$$

proving $(\dagger)$.

**Conclusion.** Comparing $(\ast)$ and $(\dagger)$,

$$B = \sum_{k=0}^{n} (-1)^k \binom{n}{k}\, B_{n+1-k} = B_n = A.$$

Therefore $A = B$, as required. $\qquad\blacksquare$
