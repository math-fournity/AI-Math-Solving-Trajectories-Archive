## Proof

**Claim:** Yes, such a probability density function exists.

**Key observations.**

1. A probability density function (PDF) is, strictly speaking, an equivalence cl
ass of non-negative measurable functions under equality almost everywhere (a.e.)
, with total integral $1$. Any representative of the class is "a PDF."

2. A countable set $S \subset \mathbb{R}$ has Lebesgue measure zero: $m(S) = 0$.

3. Modifying a measurable function on a set of measure zero does not change its
Lebesgue integral, nor does it change its equivalence class, nor its measurabili
ty (a function modified on a measurable null set remains measurable).

4. The problem writes $f: \mathbb{R} \to \mathbb{R}$ with $f(x_n) = +\infty$. Ta
ken literally this is contradictory since $+\infty \notin \mathbb{R}$. The meani
ngful interpretation—standard in measure-theoretic probability—is that $f$ is an
 **extended-valued** non-negative measurable function $f: \mathbb{R} \to [0, +\i
nfty]$, with $f \in L^1(\mathbb{R})$ (i.e., $\int f\,dm < \infty$). We proceed u
nder this standard interpretation. (If one insists on finite-valued $f: \mathbb{
R}\to\mathbb{R}$, then $f(x_n)=+\infty$ is impossible by definition and the prob
lem is vacuous.)

**Construction.**

Let $\{x_n\}_{n=1}^\infty$ be any countably infinite set with no finite accumula
tion bound, e.g., $x_n = n$. Let $\varphi(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}$
 be the standard normal density, which satisfies $\varphi \geq 0$, $\int_{\mathb
b{R}} \varphi\,dm = 1$, and has unbounded support $\operatorname{supp}(\varphi)
= \mathbb{R}$.

Define:
$$
f(x) = \begin{cases} +\infty, & x \in S := \{x_n : n \geq 1\}, \\ \varphi(x), &
x \notin S. \end{cases}
$$

**Verification.**

- **Measurability:** $f = \varphi \cdot \mathbf{1}_{\mathbb{R}\setminus S} + (+\
infty)\cdot \mathbf{1}_S$. Both $\mathbf{1}_{\mathbb{R}\setminus S}$ and $\mathb
f{1}_S$ are measurable ($S$ is Borel, being countable), and $\varphi$ is measura
ble. The pointwise operations preserve measurability for extended-valued functio
ns. Hence $f$ is measurable.

- **Integrability ($f \in L^1$):** Since $S$ has measure zero,
$$
\int_{\mathbb{R}} f\,dm = \int_{\mathbb{R}\setminus S} \varphi\,dm + \int_S (+\i
nfty)\,dm = \int_{\mathbb{R}} \varphi\,dm + 0 = 1.
$$
The integral over the null set $S$ is $0$ regardless of the (extended) values th
ere. Thus $\int f\,dm = 1 < \infty$, so $f \in L^1(\mathbb{R})$ and $f$ is a val
id PDF.

- **Countably infinite $+\infty$ points:** By construction $f(x_n) = +\infty$ fo
r every $n$, and $\{x_n\}$ is countably infinite.

- **Unbounded support:** $\operatorname{supp}(f) = \overline{\{x : f(x) > 0\}} \
supseteq \operatorname{supp}(\varphi) = \mathbb{R}$, which is unbounded. (More p
recisely, $f > 0$ on $\mathbb{R}\setminus S$ where $\varphi > 0$, which is all o
f $\mathbb{R}\setminus S$, dense in $\mathbb{R}$.)

- **Not a Dirac Comb:** The Dirac Comb $\sum_{n=1}^\infty \delta_{x_n}$ is a **s
ingular measure** (purely atomic), not absolutely continuous with respect to Leb
esgue measure, and therefore admits **no** PDF at all. Our $f$, by contrast, is
a genuine (extended-valued) function whose associated measure $\mu_f(A) = \int_A
 f\,dm$ is absolutely continuous w.r.t. Lebesgue measure—in fact $\mu_f$ is exac
tly the standard Gaussian measure, since the modification on the null set $S$ co
ntributes nothing. Thus $f$ is fundamentally different from a Dirac Comb: it is
an $L^1$ function (an a.c. density), whereas the Dirac Comb is a singular measur
e with no density representation.

**Remark (equivalence-class viewpoint).** Even more directly: a PDF is an a.e. e
quivalence class. Since $S$ is a null set, the function $f$ above belongs to the
 same equivalence class as $\varphi$. Therefore, **every** PDF with unbounded su
pport admits a representative taking the value $+\infty$ on any prescribed count
able set. The existence is thus immediate from the fact that countable sets are
null sets and PDFs are defined only up to a.e. equality.

**Conclusion.** Such a function exists. One explicit example is the standard nor
mal density modified to be $+\infty$ at the integers. The construction relies on
 the elementary fact that a countable set has Lebesgue measure zero, so altering
 a PDF on such a set preserves integrability, measurability, and total mass, whi
le introducing countably many infinite values. This is distinct from the Dirac C
omb, which is a singular measure with no density.
