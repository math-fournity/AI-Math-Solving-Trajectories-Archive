## Proof

We analyze the inequality
$$pe^t + qe^{-t} \leq \exp\!\left(\tfrac{\sigma^2}{2}t^2\right), \quad \forall\,
 t \in \mathbb{R},$$
equivalently (taking logarithms, valid since both sides are positive):
$$\log(pe^t + qe^{-t}) \leq \frac{\sigma^2}{2}\,t^2, \quad \forall\, t \in \math
bb{R}.$$

### Step 1: Taylor expansion near t = 0

Set $\mu = p - q = 2p - 1$. Expanding:
$$pe^t + qe^{-t} = (p+q) + (p-q)t + \frac{p+q}{2}t^2 + \frac{p-q}{6}t^3 + \cdots
 = 1 + \mu\, t + \frac{t^2}{2} + \frac{\mu\, t^3}{6} + \cdots$$

Writing $u = \mu\, t + \frac{t^2}{2} + O(t^3)$ and using $\log(1+u) = u - \frac{
u^2}{2} + O(u^3)$:
$$\log(pe^t + qe^{-t}) = \mu\, t + \frac{t^2}{2} - \frac{\mu^2\, t^2}{2} + O(t^3
) = \mu\, t + \frac{1 - \mu^2}{2}\,t^2 + O(t^3).$$

Note $1 - \mu^2 = 1 - (2p-1)^2 = 4pq$.

### Step 2: Case p ≠ q (i.e., p ≠ 1/2, so μ ≠ 0)

Suppose $\mu > 0$ (the case $\mu < 0$ is symmetric). For small $t > 0$:
$$\log(pe^t + qe^{-t}) = \mu\, t + \frac{4pq}{2}\,t^2 + O(t^3), \qquad \frac{\si
gma^2}{2}\,t^2 = \frac{\sigma^2}{2}\,t^2.$$

The inequality requires:
$$\mu\, t + 2pq\, t^2 + O(t^3) \leq \frac{\sigma^2}{2}\,t^2.$$

Dividing by $t > 0$:
$$\mu + 2pq\, t + O(t^2) \leq \frac{\sigma^2}{2}\,t.$$

As $t \to 0^+$, the left side $\to \mu > 0$ while the right side $\to 0$. **The
inequality fails** for all sufficiently small $t > 0$, regardless of how large $
\sigma^2$ is.

When $\mu < 0$, the same failure occurs for small $t < 0$ (where $\mu\, t > 0$).

**Conclusion for p ≠ 1/2:** No finite $\sigma^2$ satisfies the inequality for al
l $t \in \mathbb{R}$.

### Step 3: Case p = q = 1/2 (μ = 0)

Here $pe^t + qe^{-t} = \frac{e^t + e^{-t}}{2} = \cosh(t)$, and the inequality be
comes:
$$\cosh(t) \leq \exp\!\left(\tfrac{\sigma^2}{2}\,t^2\right), \quad \forall\, t \
in \mathbb{R}.$$

**Claim:** $\sigma^2 = 1$ works, i.e., $\cosh(t) \leq e^{t^2/2}$ for all $t$.

*Proof of claim.* Compare the power series (both are even functions, so it suffi
ces to compare coefficients of $t^{2n}$):
$$\cosh(t) = \sum_{n=0}^{\infty} \frac{t^{2n}}{(2n)!}, \qquad e^{t^2/2} = \sum_{
n=0}^{\infty} \frac{(t^2/2)^n}{n!} = \sum_{n=0}^{\infty} \frac{t^{2n}}{2^n\, n!}
.$$

We need $(2n)! \geq 2^n\, n!$ for all $n \geq 0$. Indeed:
$$\frac{(2n)!}{2^n\, n!} = \frac{(2n)(2n-1)(2n-2)\cdots 3\cdot 2\cdot 1}{2^n\cdo
t n!} = \frac{2^n\, n!\cdot (2n-1)(2n-3)\cdots 3\cdot 1}{2^n\, n!} = (2n-1)!! =
1\cdot 3\cdot 5\cdots(2n-1) \geq 1.$$

Since every coefficient of $e^{t^2/2}$ dominates the corresponding coefficient o
f $\cosh(t)$ and both series converge for all $t$, we have $\cosh(t) \leq e^{t^2
/2}$ for all $t \in \mathbb{R}$. $\square$

**Tightness:** From Step 1 with $\mu = 0$:
$$\frac{2\,\log\cosh(t)}{t^2} \to 1 \quad \text{as } t \to 0.$$

So any $\sigma^2 < 1$ fails for small $t$. To confirm $\sigma^2 = 1$ is the exac
t infimum, define $g(t) = \frac{2\log\cosh(t)}{t^2}$ for $t \neq 0$. We show $g$
 is strictly decreasing on $(0,\infty)$, so $\sup_{t \neq 0} g(t) = \lim_{t\to 0
} g(t) = 1$.

Compute $g'(t) = \frac{2}{t^3}\big[t\tanh(t) - 2\log\cosh(t)\big]$. Let $\varphi
(t) = t\tanh(t) - 2\log\cosh(t)$. Then $\varphi(0)=0$ and
$$\varphi'(t) = \tanh(t) + t\,\operatorname{sech}^2(t) - 2\tanh(t) = t\,\operato
rname{sech}^2(t) - \tanh(t).$$
$$\varphi''(t) = \operatorname{sech}^2(t) - 2t\,\operatorname{sech}^2(t)\tanh(t)
 - \operatorname{sech}^2(t) = -2t\,\operatorname{sech}^2(t)\tanh(t) < 0 \quad \t
ext{for } t > 0.$$

Since $\varphi'(0) = 0$ and $\varphi'' < 0$ on $(0,\infty)$, we get $\varphi'(t)
 < 0$ for $t > 0$, hence $\varphi(t) < 0$ for $t > 0$, hence $g'(t) < 0$ for $t
> 0$. So $g$ is strictly decreasing and $\sup g = 1$.

### Final Answer

A finite lower bound for $\sigma^2$ exists **if and only if $p = q = \frac{1}{2}
$**.

- **When $p = q = \frac{1}{2}$:** The optimal (smallest) lower bound is $\boxed{
\sigma^2 = 1}$, and $\cosh(t) \leq e^{t^2/2}$ holds for all $t \in \mathbb{R}$.

- **When $p \neq \frac{1}{2}$:** No finite $\sigma^2$ suffices. The linear term
$(p-q)t$ in $\log(pe^t + qe^{-t})$ near $t = 0$ causes the inequality to fail fo
r $t$ of the appropriate sign and sufficiently small magnitude, for every finite
 $\sigma^2$.
