## Solution

Let $N = 100a + 10b + c$ where $a \in \{1,\dots,9\}$ and $b,c \in \{0,\dots,9\}$
.

**Divisibility by 11.** The standard test gives $a - b + c \equiv 0 \pmod{11}$.
Since $a + c - b \in [-8, 18]$, we have $a + c - b \in \{-11, 0, 11\}$. The valu
e $-11$ is impossible (it would require $b = a+c+11 \ge 12$). Hence two cases:

- **Case 1:** $b = a + c$ (requires $a + c \le 9$).
- **Case 2:** $b = a + c - 11$ (requires $a + c \ge 11$).

The condition $N/11 = a^2 + b^2 + c^2$ is $100a + 10b + c = 11(a^2 + b^2 + c^2)$
.

### Case 1: $b = a + c$

Substituting:
$$110a + 11c = 11\bigl(a^2 + (a+c)^2 + c^2\bigr) = 11(2a^2 + 2ac + 2c^2),$$
so
$$10a + c = 2(a^2 + ac + c^2). \quad (\star)$$

Testing $a = 1, 2, 3, 4$: the resulting quadratics $2c^2 + (\text{odd})\,c + (\t
ext{const}) = 0$ have non-square or negative discriminants, yielding no integer
$c \in [0,9]$.

- $a = 5$: $(\star)$ becomes $50 + c = 2(25 + 5c + c^2) = 50 + 10c + 2c^2$, i.e.
 $c(2c + 9) = 0$, giving $c = 0$. Then $b = 5$, so $N = \mathbf{550}$. Check: $5
50/11 = 50 = 25 + 25 + 0$. ✓
- $a = 6, 7, 8, 9$: the discriminants of the resulting quadratics are all negati
ve, so no solutions.

### Case 2: $b = a + c - 11$

Substituting and simplifying:
$$10a + c - 10 = a^2 + (a+c-11)^2 + c^2,$$
which expands to
$$2a^2 + 2ac + 2c^2 - 32a - 23c + 131 = 0. \quad (\star\star)$$

Evaluating $(\star\star)$ over all $a \in [2,9]$, $c \in [0,9]$ with $a + c \ge
11$:

- $a = 8, c = 3$: $128 + 48 + 18 - 256 - 69 + 131 = 0$. ✓ Then $b = 8 + 3 - 11 =
 0$, so $N = \mathbf{803}$. Check: $803/11 = 73 = 64 + 0 + 9$. ✓
- All other pairs $(a, c)$ give strictly positive values (the smallest nonzero v
alue is $1$, at $(a,c)=(7,4)$), so there are no further solutions.

### Conclusion

The only three-digit numbers satisfying both conditions are

$$\boxed{N = 550 \quad \text{and} \quad N = 803}.$$
