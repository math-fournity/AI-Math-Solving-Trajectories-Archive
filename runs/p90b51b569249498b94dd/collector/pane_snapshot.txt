## Proof

**Claim.** For every elliptic curve $E$ defined over a number field $K$, the tor
sion subgroup $E(K)_{\text{tors}}$ of the group $E(K)$ of $K$-rational points is
 non-empty.

**Proof.**

Recall the definition. An elliptic curve $E$ over a number field $K$ is a smooth
 projective curve of genus $1$ equipped with a specified $K$-rational base point
 $O$. The set $E(K)$ of $K$-rational points forms an abelian group under the cho
rd-and-tangent group law, with the base point $O$ (the point at infinity) servin
g as the identity element.

The torsion subgroup is defined as
$$E(K)_{\text{tors}} = \{P \in E(K) : \text{there exists } n \geq 1 \text{ with
} nP = O\}.$$

Consider the identity element $O \in E(K)$. Taking $n = 1$, we have
$$1 \cdot O = O,$$
so $O$ is torsion of order $1$ by definition. Therefore
$$O \in E(K)_{\text{tors}},$$
which shows $E(K)_{\text{tors}} \neq \varnothing$.

This argument uses nothing specific to number fields; it holds for $E(K)$ over a
ny field $K$ over which $E$ is defined, since the identity element of any group
is always torsion (of order $1$). In particular, it holds for every number field
 $K$.

**Remark.** A stronger and more substantive fact is that $E(K)_{\text{tors}}$ is
 always **finite** when $K$ is a number field — this is the Mordell–Weil theorem
 (combined with the observation that the torsion subgroup of a finitely generate
d abelian group is finite). The question here, however, only asks about non-empt
iness, which is immediate from the group axioms: the identity is always a torsio
n element.
