# Problem

A specialized irrigation system is controlled by a computer model based on three distinct sensor readings, $\alpha, \beta$, and $\gamma$, which represent the three real roots of the chemical equilibrium equation $x^3 - 6x - 2 = 0$.

An engineer needs to program a secondary control module, $Q(x)$, which is defined as a quadratic function. To ensure proper synchronization, the module’s output graph $y = Q(x)$ must pass through three specific calibration coordinates related to the sensor data: $(\alpha, \beta)$, $(\beta, \gamma)$, and $(\gamma, \alpha)$. 

Depending on the order in which the sensor values $\alpha, \beta$, and $\gamma$ are assigned to the roots of the equilibrium equation, there are two distinct quadratic functions $Q$ that can satisfy these calibration points. 

Calculate the value of $Q(1)$ for both possible quadratics. What is the larger of these two values?
