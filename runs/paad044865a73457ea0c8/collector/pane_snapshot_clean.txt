## Proof

**Setup.** Let $\mathfrak c = |\mathbb R| = 2^{\aleph_0}$. Define the iterated p
ower-set (beth) hierarchy above $\mathfrak c$:
$$\beth_0(\mathfrak c)=\mathfrak c,\qquad \beth_{n+1}(\mathfrak c)=2^{\beth_n(\m
athfrak c)},\qquad \beth_\omega(\mathfrak c)=\sup_{n<\omega}\beth_n(\mathfrak c)
.$$

**Step 1 — Cardinality of each $V_n$.** We prove by induction that $|V_n|=\beth_
n(\mathfrak c)$.

- Base: $V_0=\mathbb R$, so $|V_0|=\mathfrak c=\beth_0(\mathfrak c)$.
- Step: $V_{n+1}=V_n\cup\mathcal P(V_n)$. Since $|\mathcal P(V_n)|=2^{|V_n|}>|V_
n|$ (Cantor), the union has cardinality $\max(|V_n|,2^{|V_n|})=2^{|V_n|}=\beth_{
n+1}(\mathfrak c)$.

So $|V_n|=\beth_n(\mathfrak c)$ for every finite $n$.

**Step 2 — Cardinality of $\mathbb V$.** Since $\mathbb V=\bigcup_{n<\omega}V_n$
 is a countable union,
$$|\mathbb V|\le\sum_{n<\omega}|V_n|\le\aleph_0\cdot\beth_\omega(\mathfrak c)=\b
eth_\omega(\mathfrak c).$$
Conversely $V_n\subseteq\mathbb V$ for every $n$, so $|V_n|\le|\mathbb V|$, givi
ng $|\mathbb V|\ge\sup_n\beth_n(\mathfrak c)=\beth_\omega(\mathfrak c)$. Hence
$$|\mathbb V|=\beth_\omega(\mathfrak c).$$

**Step 3 — Cardinality of $\mathcal P_{fin}(\mathbb V)$.** Let $\kappa=|\mathbb
V|=\beth_\omega(\mathfrak c)$, an infinite cardinal. The set of finite subsets d
ecomposes by size:
$$\mathcal P_{fin}(\mathbb V)=\bigcup_{k<\omega}[\mathbb V]^k.$$
For each $k\ge 1$, $|[\mathbb V]^k|=\kappa^k=\kappa$ (cardinal arithmetic for in
finite $\kappa$). Therefore
$$|\mathcal P_{fin}(\mathbb V)|\le\aleph_0\cdot\kappa=\kappa.$$
The reverse inequality $\kappa\le|\mathcal P_{fin}(\mathbb V)|$ holds via the in
jection $x\mapsto\{x\}$. Hence
$$|\mathcal P_{fin}(\mathbb V)|=\kappa=|\mathbb V|=\beth_\omega(\mathfrak c).$$

**Conclusion.**

$$\boxed{|\mathbb V|=|\mathcal P_{fin}(\mathbb V)|=\beth_\omega(\mathfrak c)=\su
p_{n<\omega}\beth_n(\mathfrak c),\quad \beth_0(\mathfrak c)=|\mathbb R|,\ \beth_
{n+1}(\mathfrak c)=2^{\beth_n(\mathfrak c)}.}$$

Both sets have the same cardinality, namely the $\omega$-th iterated power set o
f the continuum.
