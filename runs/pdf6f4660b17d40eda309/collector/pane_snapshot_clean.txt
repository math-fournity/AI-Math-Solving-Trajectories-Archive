## Solution

Let the second fence have length $x$ (meters), so the first fence has length $2x
$. The three sides of the triangular park are $75$, $x$, $2x$.

**Triangle inequality constraints.** We need $x + 2x > 75$, i.e. $x > 25$, and $
2x < 75 + x$, i.e. $x < 75$. So $x \in (25, 75)$.

**Area via two sides and included angle.** Place the two new fences meeting at a
 vertex with included angle $\theta$. Then
$$A = \tfrac{1}{2}(x)(2x)\sin\theta = x^{2}\sin\theta.$$

**Law of cosines** with the wall as the opposite side:
$$75^{2} = x^{2} + (2x)^{2} - 2\cdot x\cdot 2x\cos\theta = 5x^{2} - 4x^{2}\cos\t
heta = x^{2}(5 - 4\cos\theta),$$
so
$$x^{2} = \frac{5625}{5 - 4\cos\theta}.$$

Substituting,
$$A(\theta) = \frac{5625\sin\theta}{5 - 4\cos\theta}.$$

**Maximize.** Let $g(\theta) = \dfrac{\sin\theta}{5 - 4\cos\theta}$. Then
$$g'(\theta) = \frac{\cos\theta(5-4\cos\theta) - \sin\theta(4\sin\theta)}{(5-4\c
os\theta)^{2}} = \frac{5\cos\theta - 4(\cos^{2}\theta+\sin^{2}\theta)}{(5-4\cos\
theta)^{2}} = \frac{5\cos\theta - 4}{(5-4\cos\theta)^{2}}.$$

Setting $g'(\theta)=0$ gives $\cos\theta = \tfrac{4}{5}$, hence $\sin\theta = \t
frac{3}{5}$ (taking the positive root for maximum area). This is a maximum since
 $g$ vanishes at the endpoints $\theta=0,\pi$ and is positive in between.

**Compute the maximum:**
$$A_{\max} = \frac{5625 \cdot \tfrac{3}{5}}{5 - 4\cdot\tfrac{4}{5}} = \frac{5625
\cdot\tfrac{3}{5}}{5 - \tfrac{16}{5}} = \frac{5625\cdot\tfrac{3}{5}}{\tfrac{9}{5
}} = 5625\cdot\frac{3}{5}\cdot\frac{5}{9} = 5625\cdot\frac{1}{3} = 1875.$$

**Verification of feasibility.** At the optimum, $\cos\theta = 4/5$, so $x^{2} =
 \dfrac{5625}{5 - 16/5} = \dfrac{5625}{9/5} = 3125$, giving $x = \sqrt{3125} = 2
5\sqrt{5} \approx 55.9$ m, which lies in $(25, 75)$. The triangle is valid.

**Cross-check via Heron's formula.** With $s = \tfrac{75 + 3x}{2}$ and $x^{2}=31
25$:
$$A^{2} = \tfrac{1}{16}(75+3x)(3x-75)(75+x)(75-x) = \tfrac{1}{16}(9x^{2}-75^{2})
(75^{2}-x^{2}) = \tfrac{1}{16}(9\cdot3125 - 5625)(5625 - 3125).$$
$$= \tfrac{1}{16}(28125 - 5625)(2500) = \tfrac{1}{16}(22500)(2500) = \tfrac{5625
0000}{16} = 3515625,$$
so $A = \sqrt{3515625} = 1875$. Confirmed.

## Answer

The maximum possible area of the triangular park is $\boxed{1875}$ square meters
.
