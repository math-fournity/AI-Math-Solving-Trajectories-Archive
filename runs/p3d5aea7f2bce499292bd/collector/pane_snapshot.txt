## Proof

Let the four packet counts be $h$ (header), $s$ (sync), $p$ (parity), $d$ (data)
. We need:

- $0 \le h \le 5$
- $s \ge 0$, $s$ even
- $p \ge 0$, $p \equiv 0 \pmod{6}$
- $d \ge 0$
- $h + s + p + d = 2021$

Once $(h, s, p)$ is chosen with $h + s + p \le 2021$, the value $d = 2021 - h -
s - p$ is uniquely determined and non-negative. So we count triples $(h, s, p)$
satisfying the constraints with $h + s + p \le 2021$.

**Substitution.** Write $s = 2s'$, $p = 6p'$ with $s', p' \ge 0$ integers. The c
onstraint becomes
$$h + 2s' + 6p' \le 2021, \qquad 0 \le h \le 5.$$

For each fixed $h$, set $N = 2021 - h$. We count non-negative integer solutions
of $2s' + 6p' \le N$:
$$f(N) = \sum_{p'=0}^{\lfloor N/6 \rfloor} \left(\left\lfloor \tfrac{N - 6p'}{2}
\right\rfloor + 1\right).$$

**Closed form.** Write $N = 6q + r$ with $0 \le r \le 5$. Substituting $j = q -
p'$:
$$\left\lfloor \tfrac{6j + r}{2}\right\rfloor + 1 = 3j + \left\lfloor \tfrac{r}{
2}\right\rfloor + 1.$$
Summing over $j = 0, \dots, q$:
$$f(N) = \frac{3q(q+1)}{2} + \left(\left\lfloor \tfrac{r}{2}\right\rfloor + 1\ri
ght)(q+1).$$

1]$, and $2016 = 6 \times 336$, so $q = 336$ for every $h$, with $r = 5, 4, 3, 2
, 1, 0$ respectively.
