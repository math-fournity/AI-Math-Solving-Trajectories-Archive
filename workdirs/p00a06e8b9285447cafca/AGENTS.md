# Problem

In a massive logistics warehouse, there is a storage rack organized into 9 horizontal shelves and 2004 vertical columns, creating a $9 \times 2004$ grid of storage slots. The warehouse inventory consists of 18,036 packages. Specifically, for every integer $k$ from 1 to 2004, there are exactly 9 identical packages labeled with the value $k$.

Each of the 18,036 slots in the grid must be filled with exactly one package. To ensure structural stability, the warehouse manager has enforced a "proximity rule": for every vertical column, the difference between any two package values placed within that specific column cannot exceed 3.

Once all packages are distributed across the grid according to these rules, the manager calculates the "Top-Tier Total," which is the sum of all the values of the packages resting on the very first (top) shelf. Determine the minimum possible value of this sum.
