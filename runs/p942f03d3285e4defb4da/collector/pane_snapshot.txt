## Proof

**Setup.** There are 5 islands, and a bridge between every pair, so the network
is the complete graph $K_5$ on 5 labeled vertices, with $\binom{5}{2}=10$ edges.
 The High Architect chooses a set of bridges to **close**; the **remaining open*
* bridges must still connect all 5 islands. Thus we must count the number of spa
nning subgraphs of $K_5$ (on the fixed 5 labeled vertices) that are connected —
equivalently, the number of connected labeled graphs on 5 vertices.

**Recurrence.** Let $g_n = 2^{\binom{n}{2}}$ be the total number of (labeled) gr
aphs on $n$ vertices, and let $c_n$ be the number of **connected** labeled graph
s on $n$ vertices, with $g_0 = 1$. Fix a vertex, say vertex $1$. In any graph on
 $n$ vertices, the connected component containing vertex $1$ has some size $k$ (
$1 \le k \le n$). Choose the other $k-1$ vertices of that component in $\binom{n
-1}{k-1}$ ways; the component itself is a connected graph on those $k$ vertices
($c_k$ choices); and the remaining $n-k$ vertices carry an arbitrary graph ($g_{
n-k}$ choices). Hence

$$g_n = \sum_{k=1}^{n} \binom{n-1}{k-1}\, c_k\, g_{n-k}.$$

**Base values.** $g_0 = 1,\; g_1 = 1,\; g_2 = 2,\; g_3 = 8,\; g_4 = 64,\; g_5 =
1024$, and $c_1 = 1$.

**Compute $c_2, c_3, c_4$.**

- $n=2$: $2 = \binom{1}{0}c_1 g_1 + \binom{1}{1}c_2 g_0 = 1 + c_2 \Rightarrow c_
2 = 1$.
- $n=3$: $8 = \binom{2}{0}c_1 g_2 + \binom{2}{1}c_2 g_1 + \binom{2}{2}c_3 g_0 =
2 + 2 + c_3 \Rightarrow c_3 = 4$.
- $n=4$: $64 = \binom{3}{0}c_1 g_3 + \binom{3}{1}c_2 g_2 + \binom{3}{2}c_3 g_1 +
 \binom{3}{3}c_4 g_0 = 8 + 6 + 12 + c_4 \Rightarrow c_4 = 38$.

**Compute $c_5$.**

$$1024 = \sum_{k=1}^{5}\binom{4}{k-1}c_k\,g_{5-k}$$
$$= \binom{4}{0}c_1 g_4 + \binom{4}{1}c_2 g_3 + \binom{4}{2}c_3 g_2 + \binom{4}{
3}c_4 g_1 + \binom{4}{4}c_5 g_0$$
$$= 1\cdot 1\cdot 64 + 4\cdot 1\cdot 8 + 6\cdot 4\cdot 2 + 4\cdot 38\cdot 1 + 1\
cdot c_5\cdot 1$$
$$= 64 + 32 + 48 + 152 + c_5 = 296 + c_5.$$

Therefore

$$c_5 = 1024 - 296 = 728.$$

**Conclusion.** The number of distinct ways to select a set of bridges to close
while keeping all five islands connected equals the number of connected spanning
 subgraphs of $K_5$, which is

$$\boxed{728}.$$
