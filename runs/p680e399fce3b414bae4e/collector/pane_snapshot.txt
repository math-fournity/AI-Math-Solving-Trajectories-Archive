**Key observation.** The quantity $k \oplus \lfloor k/2\rfloor$ is precisely the
 **binary-reflected Gray code** of $k$. Indeed, writing $k$ in binary as $k = (k
_{n-1}k_{n-2}\cdots k_1 k_0)_2$, the operation $\lfloor k/2\rfloor$ is the right
 shift $k \gg 1 = (0\,k_{n-1}\cdots k_2 k_1)_2$, so bit $i$ of $k\oplus\lfloor k
/2\rfloor$ is $k_i \oplus k_{i+1}$ (with $k_n := 0$). This is exactly the Gray c
ode $G(k)$.

Let $n = 2014$. We compute
$$S = \sum_{k=0}^{2^n - 1} G(k)$$
by summing the contribution of each bit position $i \in \{0,1,\ldots,n-1\}$.

**Bit position $i = n-1$ (the most significant bit).** Here bit $n-1$ of $G(k)$
equals $k_{n-1}\oplus k_n = k_{n-1}\oplus 0 = k_{n-1}$. Among the $2^n$ values o
f $k$, exactly half have $k_{n-1}=1$, so this bit is set $2^{n-1}$ times, contri
buting $2^{n-1}\cdot 2^{n-1}$.

**Bit position $i$ with $0 \le i \le n-2$.** Bit $i$ of $G(k)$ is $k_i \oplus k_
{i+1}$. As $k$ ranges over $\{0,\ldots,2^n-1\}$, the pair $(k_i, k_{i+1})$ takes
 each of its $4$ values exactly $2^{n-2}$ times. The XOR $k_i\oplus k_{i+1}$ equ
als $1$ for exactly $2$ of the $4$ pairs, so bit $i$ is set $2\cdot 2^{n-2} = 2^
{n-1}$ times, contributing $2^{n-1}\cdot 2^i$.

**Summing over all bit positions.** Every bit position $i\in\{0,\ldots,n-1\}$ co
ntributes $2^{n-1}\cdot 2^i$, so
$$
S = \sum_{i=0}^{n-1} 2^{n-1}\cdot 2^i = 2^{n-1}\sum_{i=0}^{n-1}2^i = 2^{n-1}\big
l(2^n - 1\bigr).
$$

**Verification on small cases.**
- $n=1$: $G(0)=0,\, G(1)=1$, sum $= 1 = 2^0(2^1-1)$. ✓
- $n=2$: $G(0),G(1),G(2),G(3) = 0,1,3,2$, sum $= 6 = 2^1(2^2-1)$. ✓
- $n=3$: Gray codes $0,1,3,2,6,7,5,4$, sum $= 28 = 2^2(2^3-1)$. ✓
