## Solution

**Setup.** Index the grid by $(i,j)$ with $0 \le i,j \le 18$. Partition cells in
to four classes by parity:
$$C_{ab} = \{(i,j) : i\equiv a,\; j\equiv b \pmod 2\}, \qquad a,b\in\{0,1\}.$$
Their sizes are $|C_{00}|=10\cdot10=100$, $|C_{01}|=10\cdot9=90$, $|C_{10}|=9\cd
ot10=90$, $|C_{11}|=9\cdot9=81$.

**Upper bound.** Each move changes exactly one coordinate by $\pm1$, so each cyc
le flips exactly one bit of the pair $(i\bmod 2,\, j\bmod 2)$. The axis-alternat
ion rule forces a bot to flip the $j$-bit and $i$-bit in alternation. Thus over
any 4 consecutive cycles a bot visits all four classes exactly once:
- Type-H (starts horizontal): $(a,b)\to(a,1{-}b)\to(1{-}a,1{-}b)\to(1{-}a,b)\to(
a,b)$,
- Type-V (starts vertical): $(a,b)\to(1{-}a,b)\to(1{-}a,1{-}b)\to(a,1{-}b)\to(a,
b)$.

Let $n_{ab}(t)$ be the number of bots in $C_{ab}$ at cycle $t$. Since no two bot
s share a cell, $n_{ab}(t)\le |C_{ab}|$ for all $t$. Over any four consecutive c
ycles each of the $n$ bots lies in $C_{ab}$ exactly once, so
$$n=\sum_{k=0}^{3} n_{ab}(t+k)\le 4\,|C_{ab}|.$$
The tightest constraint comes from the smallest class $C_{11}$:
$$n \le 4\cdot 81 = 324.$$

**Construction achieving 324.** Tile the sub-grid rows $\{0,\dots,17\}$ and colu
mns $\{0,\dots,17\}$ by $9\times 9=81$ disjoint $2\times 2$ squares, with top-le
ft corners $(2p,2q)$ for $0\le p,q\le 8$. In each square place 4 bots and rotate
 them cyclically
$$(r,c)\to(r,c+1)\to(r+1,c+1)\to(r+1,c)\to(r,c).$$
The four moves around the square are H, V, H, V, so every bot alternates axes. A
ll four bots in a square move simultaneously each cycle, cyclically permuting am
ong the four cells, so each square always holds exactly 4 bots with no collision
. Bots never leave their own square, so different squares never interact. This g
ives $81\times 4 = 324$ bots in perpetual motion.

**Conclusion.** The upper bound $n\le 324$ matches the construction, so the maxi
mum is

$$\boxed{n = 324}.$$
