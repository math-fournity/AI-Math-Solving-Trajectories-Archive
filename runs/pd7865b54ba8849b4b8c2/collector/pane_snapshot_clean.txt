## Proof

**Step 1: Reduction via CRT.** By the Chinese Remainder Theorem, $\binom{2n}{n}
\bmod K$ is eventually periodic if and only if $\binom{2n}{n} \bmod p^a$ is even
tually periodic for every prime power $p^a \| K$. Moreover, if $\binom{2n}{n} \b
mod p^a$ is eventually periodic, then so is $\binom{2n}{n} \bmod p$ (by reductio
n). So it suffices to determine for which primes $p$ the sequence $\binom{2n}{n}
 \bmod p$ is eventually periodic, and then handle prime powers.

**Step 2: $K = 1$ and $K = 2$ work.**
- $K = 1$: $r_n = 0$ for all $n$, trivially periodic.
- $K = 2$: By Kummer's theorem, $v_2\!\left(\binom{2n}{n}\right)$ equals the num
ber of carries when adding $n + n$ in base $2$. At each bit position, a carry is
 generated iff $n_i = 1$, so $v_2\!\left(\binom{2n}{n}\right) = s_2(n)$ (the num
ber of $1$-bits in $n$). For $n \geq 1$, $s_2(n) \geq 1$, so $\binom{2n}{n} \equ
iv 0 \pmod{2}$. The sequence is $0, 0, 0, \ldots$, periodic from $p = 1$.

**Step 3: $K = 2^a$ with $a \geq 2$ does NOT work.**

Suppose for contradiction that $\binom{2n}{n} \bmod 2^a$ is eventually periodic
with period $T > 0$ from some $p_0$. Choose $d$ large enough that $2^d \geq p_0$
 and $2^d > T$. Set $n = 2^d$. Then:
- $v_2\!\left(\binom{2 \cdot 2^d}{2^d}\right) = s_2(2^d) = 1$, so $\binom{2^{d+1
}}{2^d} \equiv 2 \pmod{4}$, hence $\not\equiv 0 \pmod{4}$.
- $n + T = 2^d + T$ with $2^d > T$, so $s_2(2^d + T) = 1 + s_2(T) \geq 2$ (since
 $T > 0$). Thus $v_2\!\left(\binom{2(n+T)}{n+T}\right) \geq 2$, giving $\binom{2
(n+T)}{n+T} \equiv 0 \pmod{4}$.

These two values differ modulo $4$, hence modulo $2^a$ for $a \geq 2$. This cont
radicts eventual periodicity. $\square$

**Step 4: For any odd prime $p$, $\binom{2n}{n} \bmod p$ is NOT eventually perio
dic.**

By Lucas' theorem, $\binom{2n}{n} \equiv \prod_i \binom{m_i}{n_i} \pmod{p}$, whe
re $n_i$ are the base-$p$ digits of $n$ and $m_i$ are the base-$p$ digits of $2n
$. A factor $\binom{m_i}{n_i} \equiv 0 \pmod{p}$ iff $m_i < n_i$.

Analyzing the carry structure when doubling $n$ in base $p$ (with $c_0 = 0$, $2n
_i + c_i = m_i + p \cdot c_{i+1}$):
- If $c_i = 0$ and $2n_i < p$: $m_i = 2n_i \geq n_i$, no carry. ✓
- If $c_i = 0$ and $2n_i \geq p$: $m_i = 2n_i - p < n_i$ (since $n_i < p$). ✗ (z
ero factor)
- If $c_i = 1$ and $2n_i + 1 < p$: $m_i = 2n_i + 1 \geq n_i$, no carry. ✓
- If $c_i = 1$ and $2n_i + 1 \geq p$: requires $n_i = p-1$ for $m_i \geq n_i$, c
arry propagates.

Since $c_0 = 0$, the first carry (if any) arises from $c_i = 0, 2n_i \geq p$, wh
ich produces a zero factor. Therefore:

$$\binom{2n}{n} \not\equiv 0 \pmod{p} \iff \text{all base-}p\text{ digits of } n
 \text{ satisfy } n_i \leq \tfrac{p-1}{2}.$$

Now suppose $\binom{2n}{n} \bmod p$ is eventually periodic with period $T > 0$ f
rom $p_0$. Write $T = \sum t_i p^i$ in base $p$. Since $T > 0$, there exists pos
ition $j$ with $t_j \geq 1$.

**Case A: $t_j > \frac{p-1}{2}$ for some $j$.** Take $n = p^d$ for $d$ large (so
 $n \geq p_0$ and $d$ exceeds all positions of $T$'s digits). Then $n$ has digit
 $1$ at position $d$ and $0$ elsewhere; all digits $\leq \frac{p-1}{2}$ (since $
p \geq 3$). So $\binom{2n}{n} \not\equiv 0 \pmod{p}$. But $n + T$ has digit $t_j
 > \frac{p-1}{2}$ at position $j$ (no carry since $d > j$), so $\binom{2(n+T)}{n
+T} \equiv 0 \pmod{p}$. **Contradiction.**

**Case B: All digits of $T$ satisfy $t_i \leq \frac{p-1}{2}$, with some $t_j \ge
q 1$.** Take $n$ with digit $\frac{p-1}{2}$ at position $j$, digit $1$ at positi
on $d$ (for large $d$), and $0$ elsewhere. All digits of $n$ are $\leq \frac{p-1
}{2}$, so $\binom{2n}{n} \not\equiv 0 \pmod{p}$. At position $j$, $n + T$ has di
git $\frac{p-1}{2} + t_j \geq \frac{p+1}{2} > \frac{p-1}{2}$ (and $\leq p - 1 <
p$, so no carry). Thus $\binom{2(n+T)}{n+T} \equiv 0 \pmod{p}$. **Contradiction.
**

In both cases, $n$ can be made arbitrarily large (by choosing $d$ large), so the
 contradiction holds for any starting point $p_0$. $\square$

**Step 5: Conclusion.**

- If $K$ has an odd prime factor $p$, then $\binom{2n}{n} \bmod p$ is not eventu
ally periodic (Step 4), so $\binom{2n}{n} \bmod K$ is not eventually periodic.
- If $K = 2^a$ with $a \geq 2$, Step 3 shows it is not eventually periodic.
- $K = 1$ and $K = 2$ work (Step 2).

Therefore, the sequence $r_1, r_2, r_3, \ldots$ is eventually periodic if and on
ly if $K \in \{1, 2\}$.

$$\boxed{K \in \{1,\, 2\}}$$
