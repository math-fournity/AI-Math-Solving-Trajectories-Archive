# Proof

**Claim.** The set of real $n\times n$ matrices that are diagonalisable over $\m
athbb{C}$ is dense in $M_n(\mathbb{R})$.

**Key facts.**

1. A matrix $A\in M_n(\mathbb{C})$ is diagonalisable over $\mathbb{C}$ iff its c
haracteristic polynomial $\chi_A(t)=\det(tI-A)$ has $n$ distinct roots **or**, m
ore generally, iff every eigenvalue has equal algebraic and geometric multiplici
ty. In particular, **distinct eigenvalues $\Rightarrow$ diagonalisable** (eigenv
ectors for distinct eigenvalues are linearly independent).

2. The **discriminant** $\Delta$ of the characteristic polynomial is a polynomia
l in the $n^2$ entries of $A$. A matrix has repeated eigenvalues (over $\mathbb{
C}$) iff $\Delta(A)=0$.

3. $\Delta$ is **not the zero polynomial**, because there exist real matrices wi
th distinct eigenvalues, e.g. $\operatorname{diag}(1,2,\dots,n)$, for which $\De
lta\neq 0$.

**Argument.**

Let $V(\Delta)=\{A\in M_n(\mathbb{R}) : \Delta(A)=0\}$. This is the zero locus o
f a non-zero real polynomial in $n^2$ variables, hence a **proper algebraic subs
et** of $M_n(\mathbb{R})\cong\mathbb{R}^{n^2}$. A non-zero polynomial cannot van
ish on any non-empty open set (it is determined by its values on any open set, a
nd a non-zero polynomial is non-zero on a dense set), so $V(\Delta)$ has **empty
 interior**. Therefore its complement

$$U := M_n(\mathbb{R})\setminus V(\Delta)$$

is **open and dense** in $M_n(\mathbb{R})$.

For every $A\in U$, the discriminant $\Delta(A)\neq 0$, so $\chi_A$ has $n$ dist
inct roots in $\mathbb{C}$, i.e. $A$ has $n$ distinct complex eigenvalues. Disti
nct eigenvalues yield $n$ linearly independent eigenvectors over $\mathbb{C}$, s
o $A$ is diagonalisable over $\mathbb{C}$.

Thus

$$U \;\subseteq\; \{A\in M_n(\mathbb{R}) : A \text{ is diagonalisable over } \ma
thbb{C}\}.$$

Since $U$ is dense and contained in the set of complex-diagonalisable real matri
ces, that set is **dense** in $M_n(\mathbb{R})$.

**Conclusion.** Yes — the set of purely real square matrices that are complex-di
agonalisable is dense in the set of real matrices. $\blacksquare$
