# 解答

**答案：存在**（针对所有 $x \neq 0$；平凡情况 $x = 0$ 总是产生相等，因为 $|A(0)|
 = 0 = \|A\| \cdot 0$）。

我将构造一个 $l_\infty$ 上的显式连续线性泛函，它不达到其范数。

## 预备知识：Banach 极限

通过 Hahn–Banach 定理，存在一个 **Banach 极限** $L \in l_\infty^*$，使得：
- 对于所有收敛的 $x$，有 $L(x) = \lim_{n\to\infty} x_n$，
- 对于所有 $x$，有 $L(x) = L(Sx)$，其中 $S$ 是移位算子，
- 对于所有 $x \geq 0$，有 $L(x) \geq 0$，
- $\|L\| = 1$ 且 $L(\mathbf{1}) = 1$，其中 $\mathbf{1} = (1,1,1,\ldots)$。

## 构造

定义 $f \in l_1 \subset l_\infty^*$ 为
$$f(x) = \sum_{n=1}^{\infty} \frac{x_n}{2^n},$$
因此 $\|f\| = \sum \frac{1}{2^n} = 1$。令
$$A = f - L \in l_\infty^*.$$

## 范数计算

**上界：** $\|A\| \leq \|f\| + \|L\| = 1 + 1 = 2$。

**下界：** 对于 $N \geq 1$，令 $x^{(N)} = (\underbrace{1,\ldots,1}_{N},\, -1,\,
-1,\, \ldots) \in l_\infty$，因此 $\|x^{(N)}\|_\infty = 1$。那么：
$$f(x^{(N)}) = \sum_{n=1}^{N} \frac{1}{2^n} + \sum_{n=N+1}^{\infty} \frac{-1}{2^
n} = \left(1 - \frac{1}{2^N}\right) - \frac{1}{2^N} = 1 - \frac{2}{2^N} = 1 - 2^
{1-N}.$$

由于 $x^{(N)}$ 收敛于 $-1$，Banach 极限一致于普通极限：$L(x^{(N)}) = -1$。因此：
$$A(x^{(N)}) = \left(1 - 2^{1-N}\right) - (-1) = 2 - 2^{1-N}.$$

由于 $\|x^{(N)}\| = 1$，我们得到 $\|A\| \geq 2 - 2^{1-N}$（对于所有 $N$），所以
$\|A\| \geq 2$。结合上界，得出 **$\|A\| = 2$**。

## 范数未被达到

假设存在 $x \in l_\infty$ 满足 $\|x\|_\infty \leq 1$ 且 $|A(x)| = 2$。根据三角不
等式，有：
$$|A(x)| = |f(x) - L(x)| \leq |f(x)| + |L(x)| \leq 1 + 1 = 2.$$

等式要求 $|f(x)| = 1$，$|L(x)| = 1$，且 $f(x)$ 和 $L(x)$ 符号相反。

**情况 1：** $f(x) = 1$ 且 $L(x) = -1$。由于对于所有 $n$ 都有 $\frac{1}{2^n} > 0
$ 且 $\sum \frac{1}{2^n} = 1$，条件 $f(x) = \sum \frac{x_n}{2^n} = 1$（在 $|x_n|
 \leq 1$ 的条件下）**当且仅当** $x_n = 1$（对于所有 $n$）时成立，即 $x = \mathbf
{1}$。但此时 $L(x) = L(\mathbf{1}) = 1 \neq -1$。**矛盾。**

**情况 2：** $f(x) = -1$ 且 $L(x) = 1$。类似地，$f(x) = -1$ 要求 $x_n = -1$（对
于所有 $n$），即 $x = -\mathbf{1}$。但此时 $L(x) = -1 \neq 1$。**矛盾。**

因此，不存在满足 $|A(x)| = 2 = \|A\|$ 的 $x$（$\|x\| \leq 1$）。

## 结论

对于所有满足 $\|x\| \leq 1$ 的 $x$，都有 $|A(x)| < \|A\| = 2$。通过齐次性，对于
所有 $x \neq 0$：
$$|A(x)| = \|x\| \cdot \left|A\!\left(\frac{x}{\|x\|}\right)\right| < \|x\| \cdo
t \|A\|.$$

因此，对于所有 $x \neq 0$，都有 $|A(x)| \neq \|A\|\,\|x\|$（严格不等式成立）。

关于平凡情况 $x = 0$：对于任何线性泛函，都有 $|A(0)| = 0 = \|A\| \cdot 0$，因此
在 $x = 0$ 处等式总是成立。该问题的核心内容涉及非零 $x$，答案是 **是**：上述泛函
 $A(x) = \sum_{n=1}^\infty \frac{x_n}{2^n} - L(x)$ 是 $l_\infty$ 上一个不达到其
范数的连续线性泛函的显式例子。
