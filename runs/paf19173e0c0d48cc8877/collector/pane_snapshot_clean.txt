## Proof

**Answer: Yes, $B \otimes_A K$ has only finitely many prime ideals.**

**Step 1: $B \otimes_A K$ is a finite-dimensional $K$-algebra.**

Since $B$ is finitely generated as an $A$-module (via $\phi$), there exist $b_1,
 \dots, b_n \in B$ such that $B = A b_1 + \cdots + A b_n$. The $A$-module struct
ure on $K$ is given by the composition $A \to A/\mathfrak{p} \hookrightarrow K$,
 so $B \otimes_A K$ is generated as a $K$-module (i.e., as a $K$-vector space) b
y $b_1 \otimes 1, \dots, b_n \otimes 1$. Therefore
$$\dim_K(B \otimes_A K) \leq n < \infty.$$
In particular, $B \otimes_A K$ is a finite-dimensional commutative $K$-algebra (
commutativity is inherited from $A$ and $B$).

**Step 2: $B \otimes_A K$ is an Artinian ring.**

Every ideal of $B \otimes_A K$ is in particular a $K$-subspace. Since $B \otimes
_A K$ is a finite-dimensional $K$-vector space, it satisfies the descending chai
n condition on $K$-subspaces, hence on ideals. So $B \otimes_A K$ is Artinian.

**Step 3: An Artinian commutative ring has only finitely many prime ideals.**

We use two standard facts about commutative Artinian rings:

- *Every prime ideal is maximal.* If $\mathfrak{q} \subseteq B \otimes_A K$ is p
rime, then $(B \otimes_A K)/\mathfrak{q}$ is an Artinian domain. An Artinian dom
ain is a field (any nonzero element $a$ generates a descending chain $(a) \supse
teq (a^2) \supseteq \cdots$ which stabilizes, giving $a^n = a^{n+1} b$ for some
$b$; since the ring is a domain and $a \neq 0$, we get $1 = ab$, so $a$ is a uni
t). Hence $\mathfrak{q}$ is maximal.

- *There are only finitely many maximal ideals.* By the structure theorem for Ar
tinian rings, $B \otimes_A K \cong \prod_{i=1}^{m} R_i$ where each $R_i$ is an A
rtinian local ring with maximal ideal $\mathfrak{m}_i$. The maximal ideals of th
e product are exactly $\mathfrak{m}_i \times \prod_{j \neq i} R_j$ for $i = 1, \
dots, m$, so there are exactly $m < \infty$ maximal ideals.

Combining these: every prime ideal of $B \otimes_A K$ is maximal, and there are
only finitely many maximal ideals. Therefore $B \otimes_A K$ has only finitely m
any prime ideals. $\blacksquare$
