## Solution

**Coordinate setup.** Place $A=(0,0)$, $B=(2,0)$, so the semicircle $\omega$ has
 center $O=(1,0)$, radius $1$: $(x-1)^2+y^2=1$, $y\ge 0$.

**Parametrizing the two circles.** A circle tangent to $AB$ (the $x$-axis) from
above with center $(x_0, r)$ and radius $r$, internally tangent to $\omega$, sat
isfies
$$
(x_0-1)^2 + r^2 = (1-r)^2 \implies (x_0-1)^2 = 1-2r \implies r = \tfrac{1-(x_0-1
)^2}{2}.
$$

For $\omega_1$: center $(p, r_1)$, $P=(p,0)$; set $a = p-1$, so $r_1 = \frac{1-a
^2}{2}$, with $|a|<1$.
For $\omega_2$: center $(q, r_2)$, $Q=(q,0)$; set $b = q-1$, so $r_2 = \frac{1-b
^2}{2}$, with $|b|<1$.

**Tangency condition $\omega_1$–$\omega_2$ (external).**
$$
(p-q)^2 + (r_1-r_2)^2 = (r_1+r_2)^2 \implies (p-q)^2 = 4r_1 r_2 = (1-a^2)(1-b^2)
.
$$
Thus
$$
(a-b)^2 = (1-a^2)(1-b^2). \tag{$*$}
$$

**The point $C$.** $C$ is the tangency point of $\omega_1$ with $\omega$, lying
on the ray from $O$ through $(p, r_1)$ at distance $1$ from $O$. Since $1-r_1 =
\frac{1+a^2}{2}$,
$$
C = O + \frac{1}{1-r_1}\bigl((p,r_1)-O\bigr) = \left(1+\frac{2a}{1+a^2},\; \frac
{1-a^2}{1+a^2}\right).
$$

Set $a = \tan\frac{t}{2}$, $b = \tan\frac{s}{2}$. Then $\frac{2a}{1+a^2}=\sin t$
 and $\frac{1-a^2}{1+a^2}=\cos t$, so
$$
C = (1+\sin t,\;\cos t), \qquad Q = (1+\tan\tfrac{s}{2},\;0).
$$

**Computing $\tan\angle ACQ$.** With $A=(0,0)$:
$$
\vec{CA} = (-(1+\sin t),\; -\cos t), \qquad \vec{CQ} = (\tan\tfrac{s}{2}-\sin t,
\; -\cos t).
$$

Cross product (z-component):
$$
\vec{CA}\times\vec{CQ} = \cos t\,(1+\sin t) + \cos t\bigl(\tan\tfrac{s}{2}-\sin
t\bigr) = \cos t\left(1+\tan\tfrac{s}{2}\right).
$$

Dot product:
$$
\vec{CA}\cdot\vec{CQ} = -(1+\sin t)\tan\tfrac{s}{2} + (1+\sin t)\sin t + \cos^2
t = (1+\sin t)\left(1-\tan\tfrac{s}{2}\right).
$$

Both factors are positive (since $|a|,|b|<1$ gives $\cos t>0$, $1+\tan\frac{s}{2
}=1+b>0$, $1-\tan\frac{s}{2}=1-b>0$), so the angle is acute and
$$
\tan\angle ACQ = \frac{\cos t\,(1+\tan\frac{s}{2})}{(1+\sin t)(1-\tan\frac{s}{2}
)}.
$$

Using $\displaystyle\frac{\cos t}{1+\sin t} = \frac{\cos\frac{t}{2}-\sin\frac{t}
{2}}{\cos\frac{t}{2}+\sin\frac{t}{2}} = \frac{1-\tan\frac{t}{2}}{1+\tan\frac{t}{
2}} = \frac{1-a}{1+a}$, we get
$$
\tan\angle ACQ = \frac{(1-a)(1+b)}{(1+a)(1-b)}. \tag{$**$}
$$

**Using the tangency condition.** Set $X = \frac{1-a}{1+a}$, $Y = \frac{1-b}{1+b
}$, so $\tan\angle ACQ = X/Y$. Then $a = \frac{1-X}{1+X}$, $b=\frac{1-Y}{1+Y}$,
giving
$$
1-a^2 = \frac{4X}{(1+X)^2},\quad 1-b^2 = \frac{4Y}{(1+Y)^2},\quad a-b = \frac{2(
Y-X)}{(1+X)(1+Y)}.
$$

Substituting into $(*)$:
$$
\frac{4(Y-X)^2}{(1+X)^2(1+Y)^2} = \frac{16XY}{(1+X)^2(1+Y)^2} \implies (Y-X)^2 =
 4XY.
$$
$$
X^2 + Y^2 - 6XY = 0 \implies \left(\frac{X}{Y}\right)^2 - 6\left(\frac{X}{Y}\rig
ht) + 1 = 0.
$$

Let $R = X/Y = \tan\angle ACQ$. Then $R^2 - 6R + 1 = 0$, so $R = 3 \pm 2\sqrt{2}
$.

**Selecting the root.** Since $P$ is between $A$ and $Q$, we have $p < q$, hence
 $a < b$. The function $f(x)=\frac{1-x}{1+x}$ is strictly decreasing for $x>-1$,
 so $a < b$ implies $X = f(a) > f(b) = Y > 0$, giving $R = X/Y > 1$. Since $3 -
2\sqrt{2} < 1 < 3 + 2\sqrt{2}$, we conclude
$$
\boxed{\tan\angle ACQ = 3 + 2\sqrt{2}}.
$$
