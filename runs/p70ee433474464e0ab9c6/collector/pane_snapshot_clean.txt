# Proof

## Setup

Let $C \subseteq \mathbb{N}\setminus\{1,2\}$ be Cramér's random set: each $n \ge
 3$ is included independently with probability $1/\ln n$. We seek
$$P\bigl(\exists\, N\in\mathbb{N}:\ \forall\, n>N,\; 2n\in C+C\bigr).$$

Since elements of $C$ are $\ge 3$, the smallest element of $C+C$ is $6$, so only
 $n\ge 3$ can possibly satisfy $2n\in C+C$. The question is whether **almost sur
ely only finitely many** even numbers $2n$ fail to lie in $C+C$.

## Key observation: independence of representation events

Fix $n\ge 3$. The valid decompositions $2n=a+b$ with $a,b\ge 3$ correspond to $a
\in\{3,4,\dots,2n-3\}$. The unordered pairs $\{a,2n-a\}$ for $a=3,\dots,n-1$ tog
ether with the singleton $\{n\}$ **partition** the set $\{3,4,\dots,2n-3\}$:

- For $a=3,\dots,n-1$: the pair $\{a,\,2n-a\}$ (two distinct elements, since $a\
neq n$).
- For $a=n$: the singleton $\{n\}$ (requiring only $n\in C$).

Each element of $C$ is independent, and each element belongs to exactly one grou
p, so the events "both members of group $g$ lie in $C$" are **mutually independe
nt** across groups. Therefore

$$P(2n\notin C+C)=\prod_{a=3}^{n-1}\Bigl(1-\frac{1}{\ln a\;\ln(2n-a)}\Bigr)\cdot
\Bigl(1-\frac{1}{\ln n}\Bigr).$$

## Upper bound on $P(2n\notin C+C)$

Using $\ln(1-x)\le -x$ for $x\in(0,1)$:

$$\ln P(2n\notin C+C)\le -\sum_{a=3}^{n-1}\frac{1}{\ln a\;\ln(2n-a)}+\ln\Bigl(1-
\frac{1}{\ln n}\Bigr)\le -\sum_{a=3}^{n-1}\frac{1}{\ln a\;\ln(2n-a)}.$$

**Lower bound on the sum.** For $a\in[\lceil n/2\rceil,\, n-1]$ and $n$ large: $
\ln a\le \ln n$ and $\ln(2n-a)\le \ln(2n)\le 2\ln n$, so
$$\frac{1}{\ln a\;\ln(2n-a)}\ge\frac{1}{2(\ln n)^2}.$$
There are $\ge n/2-1$ such terms, hence
$$\sum_{a=3}^{n-1}\frac{1}{\ln a\;\ln(2n-a)}\ge\frac{n/2-1}{2(\ln n)^2}\ge\frac{
n}{8(\ln n)^2}\qquad(n\text{ large}).$$

Therefore
$$P(2n\notin C+C)\le\exp\!\Bigl(-\frac{n}{8(\ln n)^2}\Bigr)\qquad(n\text{ large}
).$$

## Summability and Borel–Cantelli

Since $\dfrac{n}{(\ln n)^3}\to\infty$, for all sufficiently large $n$ we have $\
dfrac{n}{8(\ln n)^2}\ge 3\ln n$, giving
$$P(2n\notin C+C)\le e^{-3\ln n}=n^{-3}.$$

Thus
$$\sum_{n\ge N_0}P(2n\notin C+C)\le\sum_{n\ge N_0}n^{-3}<\infty.$$

By the **first Borel–Cantelli lemma** (which requires no independence assumption
):
$$P\bigl(2n\notin C+C\ \text{infinitely often}\bigr)=0.$$

## Conclusion

With probability $1$, only finitely many $n$ satisfy $2n\notin C+C$. Hence there
 almost surely exists $N\in\mathbb{N}$ such that for every $n>N$, $\;2n\in C+C$.

$$\boxed{P\bigl(\exists\, N:\ \forall\, n>N,\; 2n\in C+C\bigr)=1.}$$
