## Solution

Let $M_t = 2W_t^3 + \beta t W_t$. We apply Itô's lemma to $f(t, w) = 2w^3 + \bet
a t w$.

The partial derivatives are:
- $\dfrac{\partial f}{\partial t} = \beta w$
- $\dfrac{\partial f}{\partial w} = 6w^2 + \beta t$
- $\dfrac{\partial^2 f}{\partial w^2} = 12w$

By Itô's formula:

$$dM_t = \frac{\partial f}{\partial t}\,dt + \frac{\partial f}{\partial w}\,dW_t
 + \frac{1}{2}\frac{\partial^2 f}{\partial w^2}\,dt$$

$$= \beta w\,dt + (6w^2 + \beta t)\,dW_t + 6w\,dt$$

$$= (\beta + 6)w\,dt + (6w^2 + \beta t)\,dW_t.$$

For $M_t$ to be a martingale, the drift term must vanish identically (the diffus
ion term is a martingale under standard integrability conditions, which hold her
e since $W_t$ has all moments). Thus we require

$$(\beta + 6)\,w = 0 \quad \text{for all } w \in \mathbb{R},$$

which forces

$$\beta = -6.$$

**Verification.** With $\beta = -6$, the drift vanishes and

$$dM_t = (6W_t^2 - 6t)\,dW_t,$$

so $M_t = M_0 + \int_0^t (6W_s^2 - 6s)\,dW_s$ is an Itô integral, hence a (local
) martingale. The integrand $6W_s^2 - 6s$ has finite expectation ($\mathbb{E}[W_
s^2] = s$, so $\mathbb{E}[|6W_s^2 - 6s|] < \infty$), and $\mathbb{E}\!\left[\int
_0^t (6W_s^2 - 6s)^2\,ds\right] < \infty$, confirming $M_t$ is a true martingale
.

$$\boxed{\beta = -6}$$
