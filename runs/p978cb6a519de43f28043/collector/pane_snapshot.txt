### Step 1: Compute $d = \gcd(51^{610}+1,\; 51^{671}-1)$

Since $671 = 610 + 61$, we have $51^{671} = 51^{61}\cdot 51^{610}$. Apply the Eu
clidean step:

$$\gcd(51^{610}+1,\; 51^{671}-1) = \gcd(51^{610}+1,\; (51^{671}-1) - 51^{61}(51^
{610}+1)).$$

The second argument becomes $51^{671}-1 - 51^{671} - 51^{61} = -(51^{61}+1)$, so

$$d = \gcd(51^{610}+1,\; 51^{61}+1).$$

Let $h = 51^{61}$, so $51^{610} = h^{10}$. Then $d = \gcd(h^{10}+1,\; h+1)$. Red
ucing $h^{10}+1$ modulo $h+1$ (set $h\equiv -1$):

$$h^{10}+1 \equiv (-1)^{10}+1 = 2 \pmod{h+1}.$$

Hence $d = \gcd(h+1,\, 2)$. Since $51$ is odd, $h = 51^{61}$ is odd, so $h+1$ is
 even. Therefore

$$\boxed{d = 2}.$$

### Step 2: Compute $x = \gcd(d^{671}+1,\; d^{610}-1) = \gcd(2^{671}+1,\; 2^{610

$$\gcd(2^{671}+1,\; 2^{610}-1) = \gcd(2^{671}+1 - 2^{61}(2^{610}-1),\; 2^{610}-1
).$$

The first argument simplifies to $2^{671}+1 - 2^{671} + 2^{61} = 2^{61}+1$, so

$$x = \gcd(2^{61}+1,\; 2^{610}-1).$$

Let $k = 2^{61}$, so $2^{610} = k^{10}$. Then $x = \gcd(k+1,\; k^{10}-1)$. Reduc
ing $k^{10}-1$ modulo $k+1$ (set $k\equiv -1$):

$$k^{10}-1 \equiv (-1)^{10}-1 = 0 \pmod{k+1}.$$

So $k+1 \mid k^{10}-1$, giving

$$\boxed{x = k+1 = 2^{61}+1}.$$

### Step 3: Compute $X = x \bmod 10 = (2^{61}+1)\bmod 10$

The powers of $2$ modulo $10$ cycle with period $4$: $2, 4, 8, 6, 2, 4, \ldots$
Since $61 \equiv 1 \pmod{4}$,

$$2^{61} \equiv 2^1 \equiv 2 \pmod{10}.$$

Therefore

$$X = (2 + 1) \bmod 10 = 3.$$

$$\boxed{X = 3}$$
