## Solution

$$p' = \sqrt{1 + p^2}.$$

**Separate variables.** This is a separable first-order ODE:

$$\frac{dp}{\sqrt{1+p^2}} = dx.$$

**Integrate.** The left-hand side is a standard integral:

$$\int \frac{dp}{\sqrt{1+p^2}} = \operatorname{arsinh}(p) = \ln\!\bigl(p + \sqrt
{1+p^2}\bigr).$$

Hence

$$\operatorname{arsinh}(p) = x + C_1,$$

so

$$p = \sinh(x + C_1).$$

Recalling $p = y''$, we have

$$y'' = \sinh(x + C_1).$$

**Integrate twice.**

$$y' = \int \sinh(x+C_1)\,dx = \cosh(x + C_1) + C_2.$$

$$y = \int \bigl[\cosh(x+C_1) + C_2\bigr]\,dx = \sinh(x + C_1) + C_2\, x + C_3.$

$$\sqrt{1+(y'')^2} = \sqrt{1+\sinh^2(x+C_1)} = \cosh(x+C_1) = y'''.$$ ✓
