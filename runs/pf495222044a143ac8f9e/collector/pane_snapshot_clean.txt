**Answer: No.** A set consisting solely of isolated points in a second countable
 space must be countable.

**Proof.**

Let $X$ be a second countable topological space, and let $\mathcal{B} = \{B_n :
n \in \mathbb{N}\}$ be a countable base for the topology of $X$.

Recall that a point $x \in X$ is *isolated* (in $X$) if the singleton $\{x\}$ is
 an open set.

Let $S \subseteq X$ be a set such that every point of $S$ is isolated in $X$. We
 claim $S$ is countable.

For each $x \in S$, since $\{x\}$ is open and $\mathcal{B}$ is a base, there exi
sts a basic open set $B_{n(x)} \in \mathcal{B}$ such that
$$x \in B_{n(x)} \subseteq \{x\}.$$
The containment $B_{n(x)} \subseteq \{x\}$ together with $x \in B_{n(x)}$ forces
 $B_{n(x)} = \{x\}$.

Now consider the map
$$\varphi : S \to \mathcal{B}, \qquad x \mapsto B_{n(x)} = \{x\}.$$
This map is injective: if $\varphi(x) = \varphi(y)$, then $\{x\} = \{y\}$, so $x
 = y$.

Since $\mathcal{B}$ is countable and $\varphi$ is an injection from $S$ into $\m
athcal{B}$, it follows that $S$ is countable. $\blacksquare$

**Remark.** The key point is that in a second countable space, every isolated po
int "consumes" a distinct element of the countable base (namely the basic open s
et $\{x\}$). Since the base is countable, only countably many points can be isol
ated. Hence no uncountable set of isolated points can exist.
