Looking at this problem, I need to find the maximum number of cities where: (1)
every pair of cities is connected by exactly one of bus/train/airplane, (2) no c
ity has all three types, and (3) no three cities are pairwise connected by the s
ame type.

**Answer: 5**

## Proof

Let the three transportation types be colors **R** (bus), **G** (train), **B** (
airplane). We have a complete graph $K_n$ with edges 3-colored, satisfying:

- **Condition 1:** Each vertex is incident to edges of at most 2 colors (no city
 has all three types).
- **Condition 2:** No monochromatic triangle.

### Setup: Grouping by Missing Color

By Condition 1, each vertex misses at least one color. Assign each vertex to a g
roup based on a color it misses:

- $V_R$: vertices missing R (edges use only G, B)
- $V_G$: vertices missing G (edges use only R, B)
- $V_B$: vertices missing B (edges use only R, G)

Let $|V_R|=a$, $|V_G|=b$, $|V_B|=c$, with $n = a+b+c$.

**Cross-group edges are forced.** If $u \in V_R$ and $v \in V_G$, then $u$ can u
se $\{G,B\}$ and $v$ can use $\{R,B\}$; their common color is $B$, so edge $uv$
must be **blue**. Similarly:
- $V_R$–$V_B$ edges: **green**
- $V_G$–$V_B$ edges: **red**

### Key Lemma: Forced single-color within groups

If $V_G \neq \emptyset$ and $|V_R| \geq 2$: take $u, w \in V_R$ and $v \in V_G$.
 Edges $uv$ and $wv$ are both blue (cross-group). To avoid a blue triangle, $uw$
 must be **green**. So **all edges within $V_R$ are green**.

By symmetric arguments:
- If $V_R \neq \emptyset$, $|V_G| \geq 2$: all edges within $V_G$ are **red**.
- If $V_B \neq \emptyset$, $|V_R| \geq 2$: all edges within $V_R$ are **blue**.
- If $V_R \neq \emptyset$, $|V_B| \geq 2$: all edges within $V_B$ are **red**.
- If $V_B \neq \emptyset$, $|V_G| \geq 2$: all edges within $V_G$ are **blue**.
- If $V_G \neq \emptyset$, $|V_B| \geq 2$: all edges within $V_B$ are **green**.

### Case Analysis

**Case 1: All three groups non-empty ($a,b,c \geq 1$).**
If $a \geq 2$: with $b > 0$, all edges within $V_R$ are green; with $c > 0$, all
 edges within $V_R$ are blue. Contradiction. So $a \leq 1$. By symmetry, $b \leq
 1$ and $c \leq 1$. Thus $n \leq 3$.

**Case 2: Exactly two groups non-empty.** WLOG $V_B = \emptyset$, $a, b \geq 1$.
 Cross edges ($V_R$–$V_G$) are all blue.

- If $a \geq 2$: all edges within $V_R$ are green (from the lemma), so $a \leq 2
$ (no green triangle), giving $a = 2$.
- If $b \geq 2$: all edges within $V_G$ are red, so $b \leq 2$ (no red triangle)
, giving $b = 2$.
- If $a = 1$: the single $V_R$ vertex connects to all $V_G$ vertices in blue; an
y two $V_G$ vertices with a blue edge would form a blue triangle with it, so all
 $V_G$ edges are red, forcing $b \leq 2$, giving $n \leq 3$.

The maximum in this case is $a = b = 2$, $n = 4$. (Verified: $V_R = \{r_1, r_2\}
$, $V_G = \{g_1, g_2\}$; $r_1r_2$ green, $g_1g_2$ red, all cross edges blue. Eve
ry triangle uses two colors; each vertex sees exactly 2 colors.)

**Case 3: Only one group non-empty.** WLOG $V_G = V_B = \emptyset$, all vertices
 in $V_R$. All edges use only G and B — a 2-coloring of $K_n$. Condition 1 is au
tomatically satisfied (each vertex sees at most 2 colors). Condition 2 requires
no monochromatic triangle. By Ramsey theory, $R(3,3) = 6$, so $K_5$ can be 2-col
ored without a monochromatic triangle, but $K_6$ cannot.

**Construction for $n = 5$:** Label vertices $0,1,2,3,4$. Color edge $(i,j)$ **g
reen** if $i,j$ are adjacent on the 5-cycle (difference $\equiv \pm 1 \pmod{5}$)
, and **blue** otherwise (difference $\equiv \pm 2 \pmod{5}$). The green edges f
orm a 5-cycle (no triangle); the blue edges form a complementary 5-cycle (no tri
angle). Each vertex has 2 green and 2 blue edges. ✓

### Conclusion

| Configuration | Max $n$ |
|---|---|
| Three groups | 3 |
| Two groups | 4 |
| One group | 5 |

The largest possible number of cities is $\boxed{5}$.
