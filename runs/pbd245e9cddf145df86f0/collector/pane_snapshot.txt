# The Grothendieck Group of a Commutative Group

## Setup and Definitions

The **Grothendieck group** (group completion) of a commutative monoid $(M, +, 0)
$ is an abelian group $K(M)$ together with a monoid homomorphism $i: M \to K(M)$
 satisfying the **universal property**:

> For every abelian group $G$ and every monoid homomorphism $f: M \to G$, there
exists a unique group homomorphism $\bar{f}: K(M) \to G$ with $f = \bar{f} \circ
 i$.

A standard concrete construction is:
$$K(M) = (M \times M)/{\sim}, \qquad (a,b) \sim (c,d) \iff a + d = b + c,$$
with addition $[(a,b)] + [(c,d)] = [(a+c,\, b+d)]$ and unit $[(0,0)]$, and the c
anonical map $i(a) = [(a, 0)]$.

The element $[(a,b)]$ is intended to represent the formal difference $a - b$.

## The Question

If $M$ is already a **commutative (abelian) group**, what is $K(M)$? Is it $M$ i
tself?

## Answer: Yes — $K(M) \cong M$ canonically.

**Proof.** Suppose $(M, +, 0)$ is an abelian group. We exhibit mutually inverse
homomorphisms between $K(M)$ and $M$.

**Define** $\varphi: K(M) \to M$ by
$$\varphi\bigl([(a,b)]\bigr) = a - b,$$
where $a - b := a + (-b)$ uses the existing inverse in $M$.

**Well-definedness.** If $(a,b) \sim (c,d)$, then $a + d = b + c$ in $M$. Adding
 $-b - d$ to both sides (legal since $M$ is a group):
$$a + d - b - d = b + c - b - d \implies a - b = c - d.$$
So $\varphi([(a,b)]) = \varphi([(c,d)])$. ✓

**Homomorphism.**
$$\varphi([(a,b)] + [(c,d)]) = \varphi([(a+c, b+d)]) = (a+c) - (b+d) = (a-b) + (
c-d) = \varphi([(a,b)]) + \varphi([(c,d)]). \checkmark$$

**Define** $\psi: M \to K(M)$ by $\psi(a) = i(a) = [(a, 0)]$. This is the canoni
cal map, already a monoid homomorphism (and a group homomorphism since $K(M)$ is
 a group):
$$\psi(a + c) = [(a+c, 0)] = [(a,0)] + [(c,0)] = \psi(a) + \psi(c). \checkmark$$

**The two maps are inverse.**

*$\varphi \circ \psi = \mathrm{id}_M$:*
$$\varphi(\psi(a)) = \varphi([(a,0)]) = a - 0 = a. \checkmark$$

*$\psi \circ \varphi = \mathrm{id}_{K(M)}$:*
$$\psi(\varphi([(a,b)])) = \psi(a - b) = [(a - b,\, 0)].$$
We must show $[(a-b,\, 0)] = [(a, b)]$, i.e. $(a-b, 0) \sim (a, b)$:
$$(a - b) + b \stackrel{?}{=} 0 + a \iff a = a. \checkmark$$

Hence $\varphi$ and $\psi$ are mutually inverse group isomorphisms, so
$$K(M) \cong M.$$

Moreover the isomorphism is **canonical**: $\psi = i$ is the universal map, and
$\varphi$ is the unique map guaranteed by the universal property (applied to $f
= \mathrm{id}_M: M \to M$). $\square$

## Conceptual Explanation via Universal Property

There is also a clean categorical argument. If $M$ is already an abelian group,
then the identity $\mathrm{id}_M: M \to M$ is a monoid homomorphism from $M$ int
o an abelian group. By the universal property of $K(M)$, there is a unique group
 homomorphism $\bar{i}: K(M) \to M$ with $\mathrm{id}_M = \bar{i} \circ i$:

$$M \xrightarrow{\;i\;} K(M) \xrightarrow{\;\bar{i}\;} M, \qquad \bar{i} \circ i
 = \mathrm{id}_M.$$

So $i: M \to K(M)$ is **split monic** and $\bar{i}: K(M) \to M$ is **split epic*
*. It remains to check $i \circ \bar{i} = \mathrm{id}_{K(M)}$.

Both $i \circ \bar{i}$ and $\mathrm{id}_{K(M)}$ are group homomorphisms $K(M) \t
o K(M)$ that agree on the image of $i$:
$$(i \circ \bar{i}) \circ i = i \circ (\bar{i} \circ i) = i \circ \mathrm{id}_M
= i = \mathrm{id}_{K(M)} \circ i.$$
But $K(M)$ is generated (as a group) by the image of $i$: every $[(a,b)] = [(a,0
)] - [(b,0)] = i(a) - i(b)$. Two group homomorphisms that agree on a generating
set are equal, so $i \circ \bar{i} = \mathrm{id}_{K(M)}$.

Therefore $i$ and $\bar{i}$ are inverse isomorphisms, and $K(M) \cong M$ **canon
ically**. $\square$

## Summary

| Input to Grothendieck construction | Output |
|---|---|
| Commutative monoid $M$ (not a group) | A genuinely new abelian group $K(M)$ (e
.g. $\mathbb{N} \mapsto \mathbb{Z}$) |
| Commutative (abelian) group $G$ | $K(G) \cong G$ canonically |

The Grothendieck construction "freely adjoins inverses." A group already has inv
erses, so there is nothing to adjoin: the construction is the identity (up to ca
nonical isomorphism). The canonical map $i: G \to K(G)$ is itself the isomorphis
m.
