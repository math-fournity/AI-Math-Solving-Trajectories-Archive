## Setup

Then: $A = (b\cos\gamma,\, b\sin\gamma)$, $B = (a\cos\gamma,\, -a\sin\gamma)$, a

The perpendicular bisector of $CI$ (from $(0,0)$ to $(d,0)$) is the vertical lin

**Point E** on $AC$: write $E = tA$ for $t \in [0,1]$, so $AE = (1-t)b = AI$, gi

$$(b - AI)\cos\gamma = \frac{d}{2} = \frac{r}{2\sin\gamma}. \tag{1}$$

**Point F** on $BC$: similarly, $(a - BI)\cos\gamma = \frac{r}{2\sin\gamma}. \ta

## Deriving the Key Equations

Using standard formulas $AI = r/\sin\alpha$, $BI = r/\sin\beta$, $CI = r/\sin\ga
mma$ where $\alpha = A/2$, $\beta = B/2$, and $b = 4R\sin\beta\cos\beta$, $r = 4

\beta$):

$$\cos\beta\cos\gamma = \sin\gamma\cos\gamma + \frac{\sin\alpha}{2}. \tag{I}$$

Similarly, equation (2) gives:

$$\cos\alpha\cos\gamma = \sin\gamma\cos\gamma + \frac{\sin\beta}{2}. \tag{II}$$

with the constraint $\alpha + \beta + \gamma = \pi/2$.

## Case 1: $\alpha \neq \beta$ (Non-isosceles)

Subtracting (II) from (I) and applying sum-to-product formulas:

$$2\sin\!\tfrac{\alpha+\beta}{2}\cos\gamma = \cos\!\tfrac{\alpha+\beta}{2}$$

Since $\alpha+\beta = \pi/2 - \gamma$, this gives $\tan(\pi/4 - \gamma/2) = \fra
c{1}{2\cos\gamma}$, which yields $\tan(\gamma/2) = 2-\sqrt{3}$, so $\gamma = 30°

Substituting back into (I) with $\alpha + \beta = 60°$ gives $\sqrt{3}\cos\alpha

and $\beta = 0°$. **This is degenerate** ($B = 0°$), so no valid triangle arises

## Case 2: $\alpha = \beta$ (Isosceles, $A = B$)

With $\alpha = \beta$ and $2\alpha + \gamma = \pi/2$, equation (I) becomes:

$$\cos\gamma\,(\cos\alpha - \sin\gamma) = \frac{\sin\alpha}{2}, \quad \alpha = \
frac{\pi}{4} - \frac{\gamma}{2}.$$

Setting $p = \cos(\gamma/2)$, $q = \sin(\gamma/2)$, and using $\cos\alpha = \fra
c{p+q}{\sqrt{2}}$, $\sin\alpha = \frac{p-q}{\sqrt{2}}$, $\cos\gamma = p^2-q^2$,
$\sin\gamma = 2pq$, the equation factors (after canceling $p - q \neq 0$) to:

$$(p+q)\!\left(\frac{p+q}{\sqrt{2}} - 2pq\right) = \frac{1}{2\sqrt{2}}.$$

Substituting $s = p+q$ and $pq = (s^2-1)/2$, then setting $u = s\sqrt{2}$, this
reduces to the **cubic**:

$$u^3 - u^2 - 2u + 1 = 0.$$

## Solving the Cubic

Setting $u = 2\cos\theta$, the equation becomes $2\cos 3\theta + 2\cos\theta - 2

$$2(\cos\theta + \cos 3\theta - \cos 2\theta) = 1.$$

**Testing $\theta = \pi/7$:** Using the 7th-root-of-unity identity $\cos\frac{2\

$$\cos\tfrac{\pi}{7} + \cos\tfrac{3\pi}{7} - \cos\tfrac{2\pi}{7} = \left(-\cos\t

ac{1}{2}. \checkmark$$

So $u = 2\cos(\pi/7)$ is the root in the valid range $[1, \sqrt{2}]$ (the other
roots $2\cos(3\pi/7) \approx 0.445$ and $2\cos(5\pi/7) \approx -1.247$ yield neg
