Looking at this problem, I need to determine whether a function that is locally
constant off a measure-zero set is measurable.

**Answer: Yes, $f$ is measurable on $M$ (with respect to the complete Lebesgue/H
ausdorff measure on $M$).**

## Proof

**Setup and notation.** Let $\mu$ be the (complete) measure on the surface $M$ —
 concretely, the 2-dimensional Hausdorff measure or the completed Riemannian vol
ume measure. Let $V \subset M$ with $\mu(V) = 0$, and suppose $f: M \to \mathbb{
R}$ is locally constant on $M \setminus V$ in the following sense: for every $x
\in M \setminus V$, there exists a neighborhood $U$ of $x$ in $M$ with $U \subse
t M \setminus V$ and $f$ constant on $U$.

**Step 1: $V$ is closed (hence $M \setminus V$ is open).**

By hypothesis, every $x \in M \setminus V$ possesses a neighborhood $U_x$ in $M$
 with $U_x \subset M \setminus V$. This means every point of $M \setminus V$ is
an interior point (in $M$), so $M \setminus V$ is open in $M$. Equivalently, $V$
 is closed. In particular, $V$ and $M \setminus V$ are both Borel, hence $\mu$-m
easurable.

**Step 2: $f|_{M \setminus V}$ is continuous, hence Borel measurable.**

The hypothesis says $f$ is locally constant on $M \setminus V$: each $x \in M \s
etminus V$ has a neighborhood on which $f$ is constant. A locally constant funct
ion on any topological space is continuous (the preimage of any open set is a un
ion of open neighborhoods, hence open). Thus $f|_{M \setminus V}: M \setminus V
\to \mathbb{R}$ is continuous.

Since $M \setminus V$ is open in $M$, it inherits the subspace topology, and a c
ontinuous function on it is Borel measurable. Moreover, because $M \setminus V$
is itself Borel in $M$, for any Borel set $B \subset \mathbb{R}$:
$$\bigl(f|_{M \setminus V}\bigr)^{-1}(B) \text{ is Borel in } M \setminus V, \te
xt{ hence Borel in } M.$$

**Step 3: $f|_V$ is measurable (using completeness of $\mu$).**

The restriction $f|_V: V \to \mathbb{R}$ is completely arbitrary — the hypothesi
s imposes no constraint on $f$ over $V$. However, $V$ is a null set ($\mu(V) = 0
$), and $\mu$ is complete. Therefore **every** subset of $V$ is $\mu$-measurable
 (with measure zero). Consequently, for any Borel set $B \subset \mathbb{R}$:
$$\bigl(f|_V\bigr)^{-1}(B) \subset V \implies \bigl(f|_V\bigr)^{-1}(B) \text{ is
 } \mu\text{-measurable}.$$

So $f|_V$ is measurable regardless of how $f$ behaves on $V$.

**Step 4: Gluing — $f$ is measurable on $M$.**

For any Borel set $B \subset \mathbb{R}$, we decompose:
$$f^{-1}(B) = \bigl(f|_{M \setminus V}\bigr)^{-1}(B) \;\cup\; \bigl(f|_V\bigr)^{
-1}(B).$$

- The first term is Borel in $M$ (Step 2), hence $\mu$-measurable.
- The second term is a subset of the null set $V$, hence $\mu$-measurable by com
pleteness (Step 3).

The union of two measurable sets is measurable, so $f^{-1}(B)$ is $\mu$-measurab
le for every Borel $B \subset \mathbb{R}$. This is precisely the definition of $
f$ being $\mu$-measurable.

**Conclusion.** The function $f$ is measurable on $M$. The key ingredients are:
1. Local constancy on $M \setminus V$ forces $f|_{M \setminus V}$ to be continuo
us (hence Borel measurable), and forces $V$ to be closed.
2. Completeness of the measure ensures that the arbitrary behavior of $f$ on the
 null set $V$ cannot break measurability, since every subset of a null set is me
asurable.

**Remark on completeness.** The completeness of $\mu$ is essential. If one works
 with the *uncompleted* Borel $\sigma$-algebra, the answer can be negative: one
could take $V$ to be an uncountable closed null set (e.g., a Cantor-type set emb
edded in $M$), choose a non-Borel subset $A \subset V$, and define $f = \mathbf{
1}_A$ on $V$ (and constant on $M \setminus V$). Then $f^{-1}(\{1\}) = A \cup (\t
ext{Borel set})$, which is non-Borel, so $f$ would not be Borel measurable. The
standard measure on a surface (Hausdorff measure, or completed Riemannian volume
) is complete, so under the standard convention, $f$ is measurable.
