## Proof

**Step 1: The 1-form is closed.**

Let $\omega = -f_y\,dx + f_x\,dy$. Computing the exterior derivative:

$$d\omega = d(-f_y)\wedge dx + d(f_x)\wedge dy = (f_{yy}\,dx\wedge dy) + (f_{xx}
\,dx\wedge dy) = \Delta f\,dx\wedge dy.$$

Since $\Delta f = 0$ on $\mathbb{R}^2\setminus\{p,q\}$, the form $\omega$ is **c
losed** on $\mathbb{R}^2\setminus\{p,q\}$.

**Step 2: Decomposition via the angular forms.**

The domain $\mathbb{R}^2\setminus\{p,q\}$ has $H^1 \cong \mathbb{R}^2$, generate
d by the angular forms:

$$\omega_p = \frac{-(y-p_y)\,dx + (x-p_x)\,dy}{|x-p|^2}, \qquad \omega_q = \frac
{-(y-q_y)\,dx + (x-q_x)\,dy}{|x-q|^2},$$

which satisfy $\oint_{C_p}\omega_p = 2\pi$, $\oint_{C_q}\omega_p = 0$, $\oint_{C
_p}\omega_q = 0$, $\oint_{C_q}\omega_q = 2\pi$ (each circle encloses only its ow
n center, assuming small radii so $C_p, C_q$ are disjoint).

Since $\omega$ is closed, it is cohomologous to $c_p\,\omega_p + c_q\,\omega_q$
for constants $c_p, c_q$ determined by its periods. That is:

$$\omega = c_p\,\omega_p + c_q\,\omega_q + dg$$

for some smooth function $g$ on $\mathbb{R}^2\setminus\{p,q\}$.

**Step 3: Determine the coefficients from the given data.**

Integrating around $C_p$ (small circle at $p$; $q$ lies outside):

$$A = \oint_{C_p}\omega = c_p\cdot 2\pi + c_q\cdot 0 + 0 \implies c_p = \frac{A}
{2\pi}.$$

Integrating around $C_q$ (small circle at $q$; $p$ lies outside):

$$2A = \oint_{C_q}\omega = c_p\cdot 0 + c_q\cdot 2\pi + 0 \implies c_q = \frac{A
}{\pi}.$$

**Step 4: Evaluate the integral over $C$.**

The curve $C$ is a simple closed curve enclosing **both** $p$ and $q$. By the Jo
rdan curve theorem and the orientation, $C$ winds once around each singularity,
so:

$$\oint_C \omega_p = 2\pi, \qquad \oint_C \omega_q = 2\pi.$$

The exact term vanishes: $\oint_C dg = 0$ since $g$ is single-valued on $C$ (whi
ch avoids $p$ and $q$). Therefore:

$$\oint_C \omega = c_p\cdot 2\pi + c_q\cdot 2\pi = \frac{A}{2\pi}\cdot 2\pi + \f
rac{A}{\pi}\cdot 2\pi = A + 2A = 3A.$$

## Result

$$\boxed{\int_C -f_y\,dx + f_x\,dy = 3A}$$
