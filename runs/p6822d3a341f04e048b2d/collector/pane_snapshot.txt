## Solution

We solve the quasilinear first-order PDE
$$-x\,u_x + u\,u_y = y, \qquad u(x,2x)=0$$
by the method of characteristic curves.

### Characteristic equations

Introducing a parameter $s$ along each characteristic, the PDE $a(x,y,u)u_x + b(
x,y,u)u_y = c(x,y,u)$ with $a=-x$, $b=u$, $c=y$ gives the ODE system
$$\frac{dx}{ds}=-x,\qquad \frac{dy}{ds}=u,\qquad \frac{du}{ds}=y.$$

### Parametrize the initial curve

The data is prescribed on $\Gamma:\ (x,y)=(x_0,2x_0)$ with $u=0$. We use $x_0$ a
s the parameter labeling characteristics and set $s=0$ on $\Gamma$:
$$x(0)=x_0,\quad y(0)=2x_0,\quad u(0)=0.$$

### Solve the characteristic ODEs

From $\dot x = -x$:
$$x(s)=x_0 e^{-s}.$$

From $\dot y = u$ and $\dot u = y$ we get $\ddot y = y$, whose general solution
is
$$y(s)=A e^{s}+B e^{-s},\qquad u(s)=\dot y(s)=A e^{s}-B e^{-s}.$$

Applying the initial data at $s=0$:
$$A+B=2x_0,\qquad A-B=0,$$
so $A=B=x_0$. Hence
$$y(s)=x_0(e^{s}+e^{-s})=2x_0\cosh s,\qquad u(s)=x_0(e^{s}-e^{-s})=2x_0\sinh s,\
qquad x(s)=x_0 e^{-s}.$$

### Eliminate the parameters $(x_0,s)$

From $x=x_0 e^{-s}$ we have $x_0 = x e^{s}$. Substituting:
$$y = 2x e^{s}\cosh s = x e^{s}(e^{s}+e^{-s})=x(e^{2s}+1),$$
$$u = 2x e^{s}\sinh s = x e^{s}(e^{s}-e^{-s})=x(e^{2s}-1).$$

Subtracting:
$$y - u = x(e^{2s}+1)-x(e^{2s}-1)=2x,$$
so
$$\boxed{u(x,y)=y-2x.}$$

### Verification

With $u=y-2x$: $u_x=-2$, $u_y=1$.
- PDE: $-x u_x + u\,u_y = -x(-2)+(y-2x)(1)=2x+y-2x=y$. ✓
- Boundary data: $u(x,2x)=2x-2x=0$. ✓

Both the differential equation and the initial condition are satisfied.
