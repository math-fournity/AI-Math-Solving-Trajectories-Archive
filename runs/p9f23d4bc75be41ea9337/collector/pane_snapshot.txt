## Solution

We find the Galois group of $f(x) = x^3 + x + t$ over $k = \mathbb{C}(t)$.

### Step 1: Irreducibility

View $f$ as an element of $\mathbb{C}[x][t]$: $f = t + (x^3 + x)$. This is **lin
ear (degree 1) in $t$**, hence irreducible in $\mathbb{C}[x][t] = \mathbb{C}[t][
x]$. By Gauss's Lemma, $f$ is irreducible over $\mathbb{C}(t) = k$.

### Step 2: Discriminant

For a depressed cubic $x^3 + px + q$, the discriminant is
$$\Delta = -4p^3 - 27q^2.$$
Here $p = 1$, $q = t$, so
$$\Delta = -4 - 27t^2.$$

### Step 3: Is $\Delta$ a square in $k$?

A rational function in $\mathbb{C}(t)$ is a square if and only if it has **even
valuation at every point** of $\mathbb{P}^1(\mathbb{C})$ (including the point at
 infinity).

The polynomial $-4 - 27t^2$ vanishes at $t = \pm \frac{2i}{3\sqrt{3}}$. Its deri
vative is $-54t$, which is nonzero at both roots, so each root is a **simple zer
o** (valuation $+1$, which is odd).

Since $\Delta$ has odd valuation at these points, **$\Delta$ is not a square in
$\mathbb{C}(t)$**.

### Step 4: Conclusion

For an irreducible, separable cubic over a field of characteristic $\neq 2$, the
 Galois group is:
- $A_3 \cong \mathbb{Z}/3\mathbb{Z}$ (cyclic, order 3) if the discriminant is a
square, and
- $S_3$ (symmetric group, order 6) if the discriminant is not a square.

(Here separability is automatic since $\operatorname{char} k = 0$ and $\Delta \n
eq 0$.)

Since $\Delta = -4 - 27t^2$ is **not** a square in $\mathbb{C}(t)$, the Galois g
roup is

$$\boxed{\operatorname{Gal}(f/k) \cong S_3}.$$
