## Determining the Combinatorial Structure

**Counting edges.** Each isosceles face has 2 edges of one length and 1 of the o
ther (two distinct lengths required). With 12 faces, total edge-incidences = 36,
 so E = 18.

**Euler's formula.** V − 18 + 12 = 2 gives V = 8.

**Vertex degrees.** Let v₃, v₆ be the number of degree-3 and degree-6 vertices.
Then:
- v₃ + v₆ = 8
- 3v₃ + 6v₆ = 2E = 36

Solving: v₆ = 4, v₃ = 4.

**Edge distribution.** Let e₆₆, e₆₃, e₃₃ count edges between degree-6/degree-6,
degree-6/degree-3, and degree-3/degree-3 vertex pairs:
- 2e₆₆ + e₆₃ = 24 (degree sum of degree-6 vertices)
- 2e₃₃ + e₆₃ = 12 (degree sum of degree-3 vertices)
- e₆₆ + e₆₃ + e₃₃ = 18

Subtracting the first two: e₆₆ − e₃₃ = 6. Since e₆₆ ≤ C(4,2) = 6 and e₃₃ ≥ 0, we
 get **e₆₆ = 6, e₃₃ = 0, e₆₃ = 12**.

The 4 degree-6 vertices form K₄ (complete graph); each degree-3 vertex connects
to exactly 3 of the 4 degree-6 vertices (missing one). Since e₃₃ = 0, every face
 has exactly 2 degree-6 and 1 degree-3 vertex. Counting face-edge incidences con
firms: all 12 faces are of this type (f₁ = 0, f₂ = 12).

**This is the graph of the triakis tetrahedron** — a tetrahedron with a pyramid
erected on each face.

## Setting Up Coordinates

Place the tetrahedron vertices as:
- A = (1,1,1), B = (1,−1,−1), C = (−1,1,−1), D = (−1,−1,1)

Edge length: x = |AB| = 2√2 (the 6 original tetrahedron edges, between degree-6
vertices).

By tetrahedral symmetry, the 4 apex points (degree-3 vertices) are placed at:
- a = (−t, −t, −t) opposite A, and similarly b = (−t, t, t), c = (t, −t, t), d =
 (t, t, −t)

The new edge length (degree-3 to degree-6) is:
$$y = |aB| = \sqrt{(t+1)^2 + 2(t-1)^2} = \sqrt{3t^2 - 2t + 3}$$

Each face is an isosceles triangle with base x (original edge) and equal sides y
 (new edges).

## Imposing Uniform Dihedral Angles

There are two types of dihedral angles:

**Type 1** — along an original edge (e.g., AB), shared by faces cAB and dAB. Com
puting face normals:
$$\mathbf{n}_3 = (-2t,\; 1-t,\; t-1), \quad \mathbf{n}_4 = (2t,\; 1-t,\; t-1)$$
$$\cos\theta_1 = \frac{\mathbf{n}_3 \cdot \mathbf{n}_4}{|\mathbf{n}_3||\mathbf{n
}_4|} = \frac{-2t^2 - 4t + 2}{6t^2 - 4t + 2}$$

**Type 2** — along a new edge (e.g., aB), shared by faces aBC and aBD. Computing
 face normals:
$$\mathbf{n}_1 = (1-t,\; 1-t,\; 2t), \quad \mathbf{n}_2 = (t-1,\; -2t,\; t-1)$$
$$\cos\theta_2 = \frac{(t-1)(3t+1)}{6t^2 - 4t + 2}$$

Setting cos θ₁ = cos θ₂ (equal dihedral angles):
$$-2t^2 - 4t + 2 = 3t^2 - 2t - 1$$
$$5t^2 + 2t - 3 = 0$$
$$t = \frac{-2 \pm 8}{10} \implies t = \frac{3}{5} \quad (t > 0)$$

## Verification

- **x** = 2√2

$$\frac{x}{y} = \frac{2\sqrt{2}}{6\sqrt{2}/5} = \frac{10}{6} = \frac{5}{3}$$

**Dihedral angle check:** cos θ₁ = cos θ₂ = −7/11 ✓ (both types equal).
