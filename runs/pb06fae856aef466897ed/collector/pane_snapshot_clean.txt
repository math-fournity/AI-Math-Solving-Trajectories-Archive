$$a_n^{(\ell)} = n + \lfloor n^{1/\ell} + \tfrac{1}{2} \rfloor$$

Let $r_\ell(n) = \lfloor n^{1/\ell} + \frac{1}{2} \rfloor$ (the nearest integer
to $n^{1/\ell}$). Then $a_n^{(\ell)} = n + r_\ell(n)$.

**Key observation:** $r_\ell(n) = k$ precisely when $(k - \frac{1}{2})^\ell \le
n < (k + \frac{1}{2})^\ell$, i.e., $n$ ranges over the integer interval:
$$B_k^{(\ell)} = \big[\lceil (k-\tfrac{1}{2})^\ell \rceil,\; \lceil (k+\tfrac{1}

## Identifying Skipped Values

Within each block $B_k^{(\ell)}$, the values $a_n^{(\ell)} = n + k$ form a **con
secutive** run of integers from $L_k + k$ to $U_k + k$, where $L_k = \lceil (k-\
frac{1}{2})^\ell \rceil$ and $U_k = \lceil (k+\frac{1}{2})^\ell \rceil - 1$.

**Between consecutive blocks** $k$ and $k+1$:
- Last value of block $k$: $U_k + k$
- First value of block $k+1$: $(U_k + 1) + (k+1) = U_k + k + 2$

The gap is exactly 2, so **exactly one integer is skipped**: $U_k + k + 1 = \lce
il (k+\frac{1}{2})^\ell \rceil + k$.

**Before the first block:** $a_1^{(\ell)} = 1 + 1 = 2$ for all $\ell$, so **1 is
 always skipped**.

The sequence is strictly increasing (no repeats), so an integer $m$ is in the $\
ell$-sequence **iff** $m$ is not skipped.

## Finding the Universal Tags
