## Solution

**Setup.** Label the four lines:
- L₁: y = x + 1
- L₂: y = −x + 3
- L₃: y = 2x − 1
- L₄: y = −2x + 5

**Six vertices** (pairwise intersections):

| Pair | Point |
|------|-------|
| L₁∩L₂ | A = (1, 2) |
| L₁∩L₃ | B = (2, 3) |
| L₁∩L₄ | C = (4/3, 7/3) |
| L₂∩L₃ | D = (4/3, 5/3) |
| L₂∩L₄ | E = (2, 1) |
| L₃∩L₄ | F = (3/2, 2) |

**Four triangles** (each omits one line). For each I compute the circumcenter O
and orthocenter H (using H = (sum of vertices) − 2O, from the Euler relation H =
 3G − 2O), then the perpendicular bisector of segment HO.

---

**Triangle 1** (omit L₁): vertices D, E, F.
- Circumcenter: from |O−D|²=|O−E|² and |O−D|²=|O−F|² gives O₁ = (23/12, 19/12).
- H₁ = (D+E+F) − 2O₁ = (29/6, 14/3) − (23/6, 19/6) = (1, 3/2).
- Midpoint M₁ = (35/24, 37/24); direction O₁−H₁ = (11,1), so normal (11,1).
- **PB₁: 132x + 12y = 211.**

**Triangle 2** (omit L₂): vertices B, C, F.
- O₂ = (23/12, 29/12).
- H₂ = (B+C+F) − 2O₂ = (29/6, 22/3) − (23/6, 29/6) = (1, 5/2).
- M₂ = (35/24, 59/24); direction (11,−1), normal (11,−1).
- **PB₂: 132x − 12y = 163.**

**Triangle 3** (omit L₃): vertices A, C, E.
- O₃ = (5/3, 5/3).
- H₃ = (A+C+E) − 2O₃ = (13/3, 16/3) − (10/3, 10/3) = (1, 2).
- M₃ = (4/3, 11/6); direction (2,−1), normal (2,−1).
- **PB₃: 12x − 6y = 5.**

**Triangle 4** (omit L₄): vertices A, B, D.
- O₄ = (5/3, 7/3).
- H₄ = (A+B+D) − 2O₄ = (13/3, 20/3) − (10/3, 14/3) = (1, 2).
- M₄ = (4/3, 13/6); direction (2,1), normal (2,1).
- **PB₄: 12x + 6y = 29.**

---

**Finding P.** Intersect PB₁ and PB₂:

$$132x + 12y = 211,\qquad 132x - 12y = 163.$$

Adding: 264x = 374 → **x = 187/132**.
Subtracting: 24y = 48 → **y = 2**.

So P = (187/132, 2).

**Verification** with PB₃ and PB₄:
- PB₃: 12·(187/132) − 6·2 = 17 − 12 = 5 ✓
- PB₄: 12·(187/132) + 6·2 = 17 + 12 = 29 ✓

All four perpendicular bisectors concur at P = (187/132, 2).

**Sum of coordinates:**

$$\frac{187}{132} + 2 = \frac{187 + 264}{132} = \frac{451}{132} = \frac{41}{12}.
$$
