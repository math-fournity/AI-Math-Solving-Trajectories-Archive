# Problem

A high-security data center is protected by a grid-based firewall consisting of an $8\times8$ array of nodes. To secure the system, a "Total Connectivity Map" must be generated by partitioning the entire $8\times8$ grid into $1\times2$ rectangular encryption blocks, such that every node is covered by exactly one block.

The architecture of the firewall is defined by the physical connections (edges) between adjacent nodes. There are vertical edges connecting nodes in the same column and horizontal edges connecting nodes in the same row. For every internal edge in the grid, a "Security Weight" is calculated. The Security Weight of a specific edge is defined as the total number of distinct ways the entire $8\times8$ grid can be partitioned into $1\times2$ blocks such that that specific edge forms the boundary between the two halves of one of the $1\times2$ blocks used in the partition.

A central diagnostic hub calculates the sum of the Security Weights of every single internal edge in the $8\times8$ grid. Find the last digit of this total sum.
