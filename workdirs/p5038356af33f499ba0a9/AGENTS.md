# Problem

In a remote digital archipelago, a network architect is designing decentralized server clusters. Each cluster consists of $n$ individual nodes. Within a cluster, some nodes are linked by high-speed fiber cables. The network is designed such that every node can reach any other node through some sequence of cables. The "latency" between two nodes is defined as the minimum number of cables required to send a signal between them.

The security protocol of these clusters requires that every single node must be directly cabled to at least $m$ other distinct nodes. Let $f(n, m)$ represent the maximum possible latency that could exist between any two nodes in a cluster of $n$ nodes that satisfies this $m$-connection requirement.

The architect needs to evaluate the total sum of these maximum latencies for a range of configurations where the minimum connection requirement $m$ is fixed at 3. Specifically, you must calculate the value of:

$$\sum_{n=10}^{20} f(n, 3)$$
