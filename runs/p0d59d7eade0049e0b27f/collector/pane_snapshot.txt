## Proof

**The transformation.** Let $t$ be the computable map that, given an encoding $\
langle M\rangle$ of a Turing machine, produces the encoding of the machine $M'$
obtained by swapping the labels of the two halting states: every transition into
 $q_{\text{accept}}$ is redirected into $q_{\text{reject}}$ and vice versa. Thus
 on any input $w$:
- if $M$ accepts $w$, then $t(\langle M\rangle)$ rejects $w$;
- if $M$ rejects $w$, then $t(\langle M\rangle)$ accepts $w$;
- if $M$ does not halt on $w$, then $t(\langle M\rangle)$ also does not halt on
$w$ (swapping halting states has no effect on a computation that never reaches a
 halting state).

**A fixed point.** Let $M$ be the Turing machine that, on every input, immediate
ly enters an infinite loop — concretely, a one-state machine whose only transiti
on is

$$\delta(q_0, \square) = (q_0, \square, R),$$

with $q_0$ being neither $q_{\text{accept}}$ nor $q_{\text{reject}}$. This machi
ne never halts on any input, so the language it recognizes is $\emptyset$.

**Verification.** Apply $t$ to $\langle M\rangle$. The transformation swaps $q_{
\text{accept}}\leftrightarrow q_{\text{reject}}$, but $M$ contains no transition
s into either halting state — its sole transition stays in $q_0$. Hence swapping
 the two halting states changes nothing about the transition function: $t(\langl
e M\rangle)$ describes exactly the same machine, which again loops forever on ev
ery input and recognizes $\emptyset$.

Therefore $t(\langle M\rangle)$ describes a Turing machine equivalent to $M$ (in
 fact identical to $M$), and $M$ is a fixed point of $t$.

More generally, any machine that never halts on any input is a fixed point of th
is particular $t$, since swapping two states that are never reached cannot alter
 the computed function.
