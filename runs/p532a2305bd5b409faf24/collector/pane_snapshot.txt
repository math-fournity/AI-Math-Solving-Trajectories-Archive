## Proof

We work over the complex scalar field (standard setting for spectral theory). Le
t $S: \ell^q \to \ell^q$ be defined by
$$S(x_1, x_2, x_3, x_4, \ldots) = (x_2, -x_1, x_4, -x_3, \ldots).$$

**Step 1: $S$ is a bounded operator and an isometry.**

$S$ acts in $2\times 2$ blocks, each block being the matrix $J = \begin{pmatrix}
 0 & 1 \\ -1 & 0 \end{pmatrix}$. For any $x \in \ell^q$ ($1 \le q \le \infty$),
$$\|Sx\|_q^q = |x_2|^q + |x_1|^q + |x_4|^q + |x_3|^q + \cdots = \|x\|_q^q,$$
(and similarly for $q=\infty$). Hence $S$ is an isometry, $\|S\|=1$, and $\sigma
(S) \subseteq \overline{D(0,1)} = \{\lambda : |\lambda|\le 1\}$.

**Step 2: $S^2 = -I$, which forces $\sigma(S) \subseteq \{i, -i\}$.**

Applying $S$ twice:
$$S^2(x_1, x_2, x_3, x_4, \ldots) = S(x_2, -x_1, x_4, -x_3, \ldots) = (-x_1, -x_
2, -x_3, -x_4, \ldots) = -x.$$
So $S^2 = -I$.

By the **spectral mapping theorem** for polynomials, $\sigma(S^2) = \{\lambda^2
: \lambda \in \sigma(S)\}$. Since $S^2 = -I$, we have $\sigma(S^2) = \{-1\}$. Th
erefore
$$\{\lambda^2 : \lambda \in \sigma(S)\} = \{-1\},$$
which means every $\lambda \in \sigma(S)$ satisfies $\lambda^2 = -1$, i.e., $\la
mbda \in \{i, -i\}$. Thus
$$\sigma(S) \subseteq \{i, -i\}.$$

**Step 3: Both $i$ and $-i$ are eigenvalues, so $\sigma(S) = \{i, -i\}$.**

Since $\ell^q$ (over $\mathbb{C}$) is a complex Banach space and $S$ is bounded,
 $\sigma(S) \neq \emptyset$. Combined with Step 2, at least one of $i, -i$ lies
in $\sigma(S)$. We now show **both** are eigenvalues.

**Eigenvalue $i$:** Take $x = (1, i, 0, 0, \ldots) \in \ell^q$ (for every $1 \le
 q \le \infty$). Then
$$Sx = (i, -1, 0, 0, \ldots) = i\cdot(1, i, 0, 0, \ldots) = ix.$$
So $i$ is an eigenvalue with eigenvector $x$.

**Eigenvalue $-i$:** Take $y = (1, -i, 0, 0, \ldots) \in \ell^q$. Then
$$Sy = (-i, -1, 0, 0, \ldots) = -i\cdot(1, -i, 0, 0, \ldots) = -iy.$$
(Indeed $(-i)(-i) = i^2 = -1$.) So $-i$ is an eigenvalue with eigenvector $y$.

**Conclusion.** We have shown $\sigma(S) \subseteq \{i, -i\}$ and both $i$ and $
-i$ belong to $\sigma(S)$ (as eigenvalues, hence certainly in the spectrum). The
refore, for every $1 \le q \le \infty$,
$$\boxed{\sigma(S) = \{i,\, -i\}.}$$

Both spectral values are eigenvalues (point spectrum), and there is no continuou
s or residual spectrum.
