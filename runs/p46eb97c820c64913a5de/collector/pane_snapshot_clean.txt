## Solution

Let $F_1 = (-c, 0)$, $F_2 = (c, 0)$, where $c^2 = a^2 + b^2$.

**Step 1: Find $P$ via the reflection condition.**

The line $y = -\frac{b}{a}x$, i.e. $bx + ay = 0$, is an asymptote of the hyperbo
la. Reflecting $F_1 = (-c, 0)$ about $bx + ay = 0$:

$$d = b(-c) + a(0) = -bc,\qquad a^2+b^2 = c^2.$$

$$P = \left(-c - \frac{2b(-bc)}{c^2},\; 0 - \frac{2a(-bc)}{c^2}\right) = \left(\
frac{b^2-a^2}{c},\; \frac{2ab}{c}\right).$$

**Step 2: Impose $P \in C$ to get a relation between $a$ and $b$.**

$$\frac{x_P^2}{a^2} - \frac{y_P^2}{b^2} = \frac{(b^2-a^2)^2}{a^2 c^2} - \frac{4a
^2}{c^2} = \frac{(b^2-a^2)^2 - 4a^4}{a^2 c^2} = 1.$$

So $(b^2-a^2)^2 - 4a^4 = a^2 c^2 = a^2(a^2+b^2)$, giving

$$b^4 - 3a^2 b^2 - 4a^4 = 0 \;\Longrightarrow\; (b^2 - 4a^2)(b^2 + a^2) = 0.$$

Since $b^2 + a^2 > 0$, we get $b = 2a$, hence $c^2 = 5a^2$, $c = a\sqrt{5}$.

**Step 3: Use the incircle tangent point to find $a$.**

The $x$-axis is the side $F_1F_2$ of $\triangle PF_1F_2$. The incircle is tangen

$$|F_1T| = s - |PF_2|,\qquad |F_2T| = s - |PF_1|.$$

Subtracting:

$$|F_1T| - |F_2T| = |PF_1| - |PF_2|.$$

Since $F_1 = (-c,0)$, $F_2 = (c,0)$, $T = (1,0)$:

$$|F_1T| = 1 + c,\quad |F_2T| = c - 1 \;\Longrightarrow\; |PF_1| - |PF_2| = (1+c

But $P$ is on the right branch of the hyperbola, so $|PF_1| - |PF_2| = 2a$. Ther
