## Solution

We compute the area of the portion of the helicoid $z = c\arctan(y/x)$ lying in
the first octant between the cylinders $x^2+y^2=a^2$ and $x^2+y^2=b^2$ (assume $
0 < a < b$).

### Setup

In the first octant we have $x>0,\, y>0,\, z>0$. Since $y/x>0$ there, $\arctan(y
/x)>0$, so $z>0$ is automatically satisfied. Using polar coordinates $x = r\cos\
theta,\; y = r\sin\theta$, we have $y/x = \tan\theta$, hence
$$z = c\,\arctan(\tan\theta) = c\,\theta, \qquad \theta\in(0,\pi/2).$$

The region is $a \le r \le b$, $0 \le \theta \le \pi/2$.

### Surface area element

Let $f(x,y) = c\arctan(y/x)$. Then
$$f_x = c\cdot\frac{1}{1+(y/x)^2}\cdot\!\left(-\frac{y}{x^2}\right) = -\frac{cy}
{x^2+y^2},\qquad f_y = c\cdot\frac{1}{1+(y/x)^2}\cdot\frac{1}{x} = \frac{cx}{x^2
+y^2}.$$

Therefore
$$f_x^2 + f_y^2 = \frac{c^2(y^2+x^2)}{(x^2+y^2)^2} = \frac{c^2}{x^2+y^2} = \frac
{c^2}{r^2}.$$

The area element is
$$dS = \sqrt{1+f_x^2+f_y^2}\,dx\,dy = \sqrt{1+\frac{c^2}{r^2}}\;r\,dr\,d\theta =
 \sqrt{r^2+c^2}\,dr\,d\theta.$$

### Integration

$$A = \int_0^{\pi/2}\!\int_a^b \sqrt{r^2+c^2}\,dr\,d\theta = \frac{\pi}{2}\int_a
^b \sqrt{r^2+c^2}\,dr.$$

Using the standard integral
$$\int\sqrt{r^2+c^2}\,dr = \frac{1}{2}\Bigl[r\sqrt{r^2+c^2}+c^2\ln\!\bigl(r+\sqr
t{r^2+c^2}\bigr)\Bigr],$$

we obtain
$$A = \frac{\pi}{4}\Bigl[r\sqrt{r^2+c^2}+c^2\ln\!\bigl(r+\sqrt{r^2+c^2}\bigr)\Bi
gr]_a^b.$$

### Result

$$\boxed{A = \frac{\pi}{4}\left[\,b\sqrt{b^2+c^2}-a\sqrt{a^2+c^2}+c^2\ln\!\frac{
b+\sqrt{b^2+c^2}}{a+\sqrt{a^2+c^2}}\right].}$$
