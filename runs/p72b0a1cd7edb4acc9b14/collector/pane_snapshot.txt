## Solution

We seek an analytic function $f(z)$ with $|f(z)| = e^{\rho^2 \cos(2\theta)}$, wh
ere $z = \rho e^{i\theta}$.

**Key observation.** Since $z = \rho e^{i\theta}$, we have
$$z^2 = \rho^2 e^{2i\theta} = \rho^2\cos(2\theta) + i\,\rho^2\sin(2\theta).$$
Hence
$$\operatorname{Re}(z^2) = \rho^2 \cos(2\theta).$$

The required modulus is therefore
$$|f(z)| = e^{\operatorname{Re}(z^2)}.$$

**Candidate.** Consider
$$f(z) = e^{z^2}.$$
This is entire (analytic on all of $\mathbb{C}$), being the composition of the e
ntire functions $z\mapsto z^2$ and $w\mapsto e^w$.

**Verification.** Writing $z^2 = \operatorname{Re}(z^2) + i\,\operatorname{Im}(z
^2)$,
$$f(z) = e^{z^2} = e^{\operatorname{Re}(z^2)}\cdot e^{i\,\operatorname{Im}(z^2)}
.$$
The first factor is real and positive, the second has modulus $1$, so
$$|f(z)| = e^{\operatorname{Re}(z^2)} = e^{\rho^2\cos(2\theta)},$$
exactly as required. $\square$

**General solution.** If $g(z)$ is any entire function with $\operatorname{Re}(g
(z)) = \operatorname{Re}(z^2)$ everywhere, then $g(z)-z^2$ is entire with zero r
eal part, hence (by the open mapping/Cauchy–Riemann argument) is a pure imaginar
y constant $i\alpha$, $\alpha\in\mathbb{R}$. Thus the most general analytic solu
tion is
$$f(z) = e^{z^2 + i\alpha} = e^{i\alpha}\,e^{z^2},\qquad \alpha\in\mathbb{R},$$
i.e. $e^{z^2}$ multiplied by any unimodular constant.
