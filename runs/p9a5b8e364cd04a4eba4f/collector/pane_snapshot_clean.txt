# Shortest String Containing All Length-$n$ Substrings Over an Alphabet of Size
$k$

## Answer

The length of the shortest string that contains every possible substring of leng
th $n$ over an alphabet of size $k$ is

$$\boxed{k^n + n - 1}.$$

---

## Proof

Let $\Sigma$ be an alphabet with $|\Sigma| = k$. A string $s = s_1 s_2 \cdots s_
L$ of length $L$ has substrings of length $n$ starting at positions $1, 2, \ldot
s, L - n + 1$, giving at most $L - n + 1$ distinct substrings of length $n$. The
re are exactly $k^n$ possible strings of length $n$ over $\Sigma$, so we need:

$$L - n + 1 \geq k^n \implies L \geq k^n + n - 1.$$

This establishes the **lower bound** $L \geq k^n + n - 1$.

For the **upper bound**, we construct a string of length exactly $k^n + n - 1$ t
hat contains all $k^n$ length-$n$ substrings. This is achieved by a **de Bruijn
sequence**.

### Construction via the de Bruijn graph

Define the **de Bruijn graph** $B(k, n-1)$: its vertices are all $(n-1)$-tuples
over $\Sigma$ (there are $k^{n-1}$ of them), and for each $n$-tuple $a_1 a_2 \cd
ots a_n \in \Sigma^n$ there is a directed edge from vertex $a_1 \cdots a_{n-1}$
to vertex $a_2 \cdots a_n$, labeled by $a_1 a_2 \cdots a_n$.

**Claim:** $B(k, n-1)$ is Eulerian (has a closed Eulerian tour using every edge
exactly once).

*Proof of claim.* Every vertex has out-degree $k$ (append any of $k$ symbols to
the right) and in-degree $k$ (prepend any of $k$ symbols to the left), so in-deg
ree equals out-degree at every vertex. The graph is also strongly connected: fro
m any $(n-1)$-tuple $u = u_1 \cdots u_{n-1}$ we can reach any other $v = v_1 \cd
ots v_{n-1}$ by the path that successively shifts in $v_1, v_2, \ldots, v_{n-1}$
. Hence $B(k,n-1)$ is Eulerian. $\square$

The number of edges is $k^n$ (one per $n$-tuple). An Eulerian tour traverses all
 $k^n$ edges. Reading the first symbol of each edge label along the tour produce
s a **cyclic** string of length $k^n$ in which every $n$-tuple appears exactly o
nce as a cyclic substring.

### Linearization

To convert the cyclic de Bruijn sequence of length $k^n$ into a **linear** strin
g containing all $k^n$ length-$n$ substrings, append the first $n - 1$ symbols o
f the cyclic sequence to its end. The resulting linear string has length

$$k^n + (n - 1) = k^n + n - 1.$$

Every length-$n$ substring of the cyclic sequence now appears in the linear stri
ng: the $k^n - (n-1)$ substrings that do not wrap around appear in their origina
l positions, and the $n - 1$ substrings that wrapped around the cycle are now ca
ptured by the appended $n - 1$ symbols.

### Combining the bounds

- **Lower bound:** $L \geq k^n + n - 1$ (counting argument).
- **Upper bound:** $L \leq k^n + n - 1$ (de Bruijn construction).

Therefore the minimum length is exactly

$$L = k^n + n - 1.$$
