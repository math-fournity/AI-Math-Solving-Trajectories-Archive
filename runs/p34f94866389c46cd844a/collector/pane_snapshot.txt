## Proof

We analyze the asymptotic behavior of $u_n = \int_0^1 \frac{e^{-t}}{t+1/n}\,dt$
as $n\to\infty$.

**Claim:** $v_n = \ln n$ satisfies $\lim_{n\to\infty}\frac{u_n}{v_n}=1$.

**Step 1: Split the integrand.**

Write $e^{-t} = 1 + (e^{-t}-1)$, so

$$u_n = \underbrace{\int_0^1 \frac{dt}{t+1/n}}_{I_n} + \underbrace{\int_0^1 \fra
c{e^{-t}-1}{t+1/n}\,dt}_{J_n}.$$

**Step 2: Evaluate $I_n$ exactly.**

$$I_n = \Big[\ln(t+1/n)\Big]_0^1 = \ln(1+1/n) - \ln(1/n) = \ln(1+1/n)+\ln n.$$

Since $\ln(1+1/n)\to 0$, we have $I_n = \ln n + o(1)$.

**Step 3: Show $J_n$ converges to a finite constant.**

Define $g(t) = \frac{e^{-t}-1}{t}$ for $t\in(0,1]$ and $g(0)=-1$ (by continuity,
 since $\lim_{t\to 0}\frac{e^{-t}-1}{t}=-1$). Then $g$ is continuous on $[0,1]$,
 hence bounded.

Write

$$J_n = \int_0^1 g(t)\cdot\frac{t}{t+1/n}\,dt.$$

For each $t>0$, $\frac{t}{t+1/n}\to 1$ as $n\to\infty$, and at $t=0$ the integra
nd is $0$. Moreover,

$$\left|g(t)\cdot\frac{t}{t+1/n}\right| \leq |g(t)| \leq M$$

for some constant $M$ (since $g$ is bounded on $[0,1]$). By the Dominated Conver
gence Theorem,

$$J_n \to \int_0^1 g(t)\,dt = \int_0^1 \frac{e^{-t}-1}{t}\,dt =: C,$$

where $C$ is a finite constant (in fact $C = -\int_0^1\frac{1-e^{-t}}{t}\,dt$, r
elated to the exponential integral).

**Step 4: Combine.**

$$u_n = I_n + J_n = \ln n + \ln(1+1/n) + C + o(1) = \ln n + C + o(1).$$

Therefore

$$\frac{u_n}{\ln n} = 1 + \frac{C+o(1)}{\ln n} \longrightarrow 1 \quad\text{as }
 n\to\infty,$$

since $C$ is a fixed constant and $\ln n\to\infty$.

**Conclusion.** The sequence $v_n = \ln n$ satisfies $\lim_{n\to\infty}\frac{u_n
}{v_n}=1$. $\blacksquare$
