Looking at this problem, I need to find all k ∈ {1,...,12} such that for **every

## Proof

**Setup.** Let the 12 ratings have p positives and n negatives (p + n = 12). For
 a k-subset with j negatives: product sign = (−1)^j, and the subset is **harmoni
ous** iff the sum has sign (−1)^j (positive if j even, negative if j odd). It is
 **non-harmonious** iff the sum has the opposite sign.

**Even k are not in S.** If the adversary sets all 12 values negative, every k-s
ubset has sum < 0 and product > 0 (k even) — different signs, so **no** harmonio
us subset exists. Thus k ∉ S for k = 2, 4, 6, 8, 10, 12.

**k = 1 is in S.** A single value r has sum = product = r, always same sign. ✓

**Key Lemma (Swap Argument).** Suppose the adversary wants *all* k-subsets non-h
armonious. Then:
- Every k-subset with **even** j must have **negative** sum.
- Every k-subset with **odd** j must have **positive** sum.

Consider a k-subset A with j negatives (j even) containing at least one positive
, and form B by swapping one positive in A for one negative outside A. Then B ha
s j+1 negatives (odd). Since we replaced a positive with a negative: **sum(A) >
sum(B)**. But the adversary's condition requires sum(A) < 0 (j even) and sum(B)
> 0 (j+1 odd), giving sum(A) < 0 < sum(B), **contradicting** sum(A) > sum(B).

Therefore, if there exists an **even** j in the range [L, U] where L = max(0, k−
p), U = min(k−1, n−1), the adversary's condition is impossible — a harmonious k-
subset must exist.

**Applying the lemma to odd k ∈ {3, 5, 7, 9}.** For any p, n ≥ 1 with p + n = 12
, the range [L, U] must contain an even number. The range collapses to a single
point L = U = m only when k − p = n − 1, i.e., k = p + n − 1 = 11. For k ≤ 9, th
is equation has no solution, so either the range has ≥ 2 consecutive integers (g
uaranteeing an even number) or collapses to a single even point. One can verify
directly: for each p from 1 to 11, the range always contains an even number (e.g
., k = 9, p = 1: range = {8}, even; p = 4: range = [5,7], contains 6; etc.). The
 same holds for k = 7, 5, 3 by the identical algebraic structure.

For p = 0 or n = 0 (all same sign) with odd k: every k-subset has sum and produc
t both negative (all-negative) or both positive (all-positive), so all are harmo
nious.

Therefore **k ∈ {3, 5, 7, 9} ⊂ S**. ✓

**k = 11 is not in S.** The adversary chooses n = 2, p = 10: two negatives each
−1, ten positives each 0.2. Total sum T = 10(0.2) − 2(1) = 0. There are 12 subse
ts of size 11, each missing one essence:
- **Missing a positive** (value 0.2): sum = T − 0.2 = −0.2 < 0; j = 2 negatives
(even), product > 0. Different signs → non-harmonious. ✓
- **Missing a negative** (value −1): sum = T − (−1) = 1 > 0; j = 1 negative (odd
), product < 0. Different signs → non-harmonious. ✓

All 11-subsets are non-harmonious, so k = 11 ∉ S. (This works because k = 11 = 1
2 − 1 allows the range to collapse to the single odd point m = n − 1 = 1.)

**Conclusion.** S = {1, 3, 5, 7, 9}, and the sum is:

$$1 + 3 + 5 + 7 + 9 = \boxed{25}$$
