## Solution

I'll evaluate the line integral using Stokes' theorem.

**Setup.** Let $\mathbf{F} = (P, Q, R) = (y^2,\, x,\, z)$. The curve $C$ is the
intersection of the cylinder $x^2+y^2 = x+y$ with the paraboloid $z = 2(x^2+y^2)
$.

**Compute the curl.**
$$\nabla \times \mathbf{F} = \left(\frac{\partial R}{\partial y} - \frac{\partia
l Q}{\partial z},\; \frac{\partial P}{\partial z} - \frac{\partial R}{\partial x
},\; \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) = (0-0
,\; 0-0,\; 1-2y) = (0,0,1-2y).$$

**Choose the surface.** Take $S$ to be the part of the paraboloid $z = 2(x^2+y^2
)$ lying over the disk $D = \{(x,y): x^2+y^2 \le x+y\}$. Since $C$ is positively
 oriented as viewed from $(0,0,2R)$ (i.e., from above), the right-hand rule give
s the **upward** normal. For $z = f(x,y) = 2(x^2+y^2)$, the upward normal elemen
t is
$$\mathbf{n}\,dS = (-f_x,\,-f_y,\,1)\,dx\,dy = (-4x,\,-4y,\,1)\,dx\,dy.$$

**Apply Stokes' theorem.**
$$\oint_C \mathbf{F}\cdot d\mathbf{r} = \iint_S (\nabla\times\mathbf{F})\cdot \m
athbf{n}\,dS = \iint_D (0,0,1-2y)\cdot(-4x,-4y,1)\,dx\,dy = \iint_D (1-2y)\,dx\,
dy.$$

**Evaluate over the disk.** The region $D: x^2+y^2 \le x+y$ rewrites as
$$\left(x-\tfrac12\right)^2 + \left(y-\tfrac12\right)^2 \le \tfrac12,$$
a disk centered at $(\tfrac12, \tfrac12)$ with radius $r = \tfrac{1}{\sqrt{2}}$.

Using the centroid property $\iint_D y\,dA = \bar y \cdot \text{Area}$:
$$\iint_D (1-2y)\,dA = \text{Area}(D) - 2\,\bar y\cdot\text{Area}(D) = \frac{\pi
}{2} - 2\cdot\frac12\cdot\frac{\pi}{2} = \frac{\pi}{2} - \frac{\pi}{2} = 0.$$

**Result.**

$$\boxed{\int_C y^2\,dx + x\,dy + z\,dz = 0}$$
