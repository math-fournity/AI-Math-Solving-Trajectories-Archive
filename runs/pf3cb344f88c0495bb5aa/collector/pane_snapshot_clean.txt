## Solution

We analyze each condition separately over $\mathbb{R}$, then take the minimum.

### Condition 1 (1-dimensional vector space, linear map)

$V$ is 1-dimensional over $\mathbb{R}$. Every linear map $f: V \to V$ is of the
form $f(v) = \lambda v$ for some fixed scalar $\lambda \in \mathbb{R}$.

**$n = 1$ works.** Given any non-zero $v_1 \in V$ and any $v_1^* \in V$, set $\l
ambda = v_1^*/v_1$ (well-defined since $v_1 \neq 0$). Then $f(v_1) = \lambda v_1
 = v_1^*$.

**$n = 2$ fails.** Take $v_1 = e$, $v_2 = 2e$ (distinct, non-zero) and $v_1^* =
e$, $v_2^* = 3e$ (distinct). A linear map $f(v)=\lambda v$ requires $\lambda \cd
ot 1 = 1$ and $\lambda \cdot 2 = 3$, giving $\lambda = 1$ and $\lambda = 3/2$ si
multaneously — a contradiction. No such linear map exists.

Hence **Condition 1 holds if and only if $n = 1$**.

### Condition 2 (1-dimensional affine space, affinity)

An affinity of a 1-dimensional affine space has the form $g(x) = ax + b$ with $a
 \neq 0$ (2 parameters).

**$n = 2$ works.** Given distinct $p_1, p_2$ and distinct $p_1^*, p_2^*$, solve:
$$a = \frac{p_1^* - p_2^*}{p_1 - p_2} \neq 0 \quad (\text{both pairs distinct}),
 \qquad b = p_1^* - a\,p_1.$$
This gives a valid affinity.

**$n = 3$ fails.** Take $p_1=0, p_2=1, p_3=2$ and $p_1^*=0, p_2^*=1, p_3^*=3$. F
rom the first two: $a=1, b=0$, so $g(2)=2 \neq 3$. Contradiction.

Hence **Condition 2 holds if and only if $n \leq 2$**.

### Condition 3 (1-dimensional projective space, collineation)

$P = \mathbb{RP}^1$ is the real projective line. A projective collineation is a
Möbius transformation $h(x) = \frac{ax+b}{cx+d}$ with $ad - bc \neq 0$, which ha
s 3 degrees of freedom (up to scalar).

**$n = 3$ works** (fundamental theorem of projective geometry for the line): any
 3 distinct points can be mapped to any 3 distinct points.

**$n = 4$ fails.** Take $Q_i = 0, 1, 2, 3$ and $Q_i^* = 0, 1, 2, 4$. The unique
collineation sending $0\mapsto 0, 1\mapsto 1, 2\mapsto 2$ is the identity, but t
he identity sends $3 \mapsto 3 \neq 4$.

Hence **Condition 3 holds if and only if $n \leq 3$**.

### Combining

All three conditions must hold simultaneously, so the highest $n$ is:
$$\min(1,\; 2,\; 3) = 1.$$

The binding constraint is Condition 1: a linear map on a 1-dimensional space has
 only 1 degree of freedom (a single scalar $\lambda$), so it can match at most o
ne prescribed value.

### Answer

The highest integer $n$ for which all three conditions hold is $\boxed{1}$.
