## Solution

**Setup.** Let $a = BC$, $b = CA$, $c = AB$. Place $B = (0,0)$, $C = (a,0)$, and
 $A = (d,e)$ with $e > 0$ (so $A,B,C$ are counterclockwise). Then
$$c^2 = d^2+e^2,\quad b^2 = (d-a)^2+e^2,\quad \Delta = \tfrac{1}{2}ae.$$

**Locating the apexes.** In right isosceles $\triangle BXC$ with $\angle X = 90°
$, the altitude from $X$ to hypotenuse $BC$ has length $a/2$, and $X$ lies on th
e external side of $BC$ (below the $x$-axis):
$$X = \bigl(\tfrac{a}{2},\, -\tfrac{a}{2}\bigr).$$

For $\triangle CYA$ (external to side $CA$): the outward unit normal to $\overri
ghtarrow{CA}$ is $(e,\,a-d)/b$, so
$$Y = \Bigl(\tfrac{a+d}{2}+\tfrac{e}{2},\; \tfrac{e}{2}+\tfrac{a-d}{2}\Bigr) = \
Bigl(\tfrac{a+d+e}{2},\; \tfrac{a+e-d}{2}\Bigr).$$

For $\triangle AZB$ (external to side $AB$): the outward unit normal to $\overri
ghtarrow{AB}$ is $(-e,\,d)/c$, so
$$Z = \Bigl(\tfrac{d}{2}-\tfrac{e}{2},\; \tfrac{e}{2}+\tfrac{d}{2}\Bigr) = \Bigl
(\tfrac{d-e}{2},\; \tfrac{d+e}{2}\Bigr).$$

**Computing $XY^2+YZ^2+ZX^2$.**

$$\overrightarrow{XY} = Y-X = \Bigl(\tfrac{d+e}{2},\; \tfrac{2a+e-d}{2}\Bigr),$$
$$|XY|^2 = \tfrac{1}{4}\bigl[(d+e)^2+(2a+e-d)^2\bigr] = \tfrac{1}{2}(d^2+e^2+2a^
2+2ae-2ad).$$

$$\overrightarrow{YZ} = Z-Y = \Bigl(\tfrac{-(a+2e)}{2},\; \tfrac{2d-a}{2}\Bigr),
$$
$$|YZ|^2 = \tfrac{1}{4}\bigl[(a+2e)^2+(2d-a)^2\bigr] = \tfrac{1}{2}(a^2+2d^2+2e^
2+2ae-2ad).$$

$$\overrightarrow{ZX} = X-Z = \Bigl(\tfrac{a-d+e}{2},\; \tfrac{-(a+d+e)}{2}\Bigr
),$$
$$|ZX|^2 = \tfrac{1}{4}\bigl[(a-d+e)^2+(a+d+e)^2\bigr] = \tfrac{1}{2}(a^2+d^2+e^
2+2ae).$$

Summing:
$$XY^2+YZ^2+ZX^2 = \tfrac{1}{2}\bigl[4a^2+4d^2+4e^2+6ae-4ad\bigr] = 2a^2+2d^2+2e
^2-2ad+3ae.$$

**Computing $AB^2+BC^2+CA^2$.**
$$AB^2+BC^2+CA^2 = (d^2+e^2)+a^2+\bigl((d-a)^2+e^2\bigr) = 2a^2+2d^2+2e^2-2ad.$$

**The key relation.** Let $S_1 = AB^2+BC^2+CA^2$ and $S_2 = XY^2+YZ^2+ZX^2$. The
n
$$S_2 = S_1 + 3ae = S_1 + 6\Delta,$$
since $ae = 2\Delta$ (twice the area of $\triangle ABC$).

**Optimizing the ratio.** We seek the largest $k$ with $S_1 \ge k\,S_2$ for ever
y acute triangle, i.e.
$$k = \inf_{\text{acute}} \frac{S_1}{S_2} = \inf_{\text{acute}} \frac{1}{1+6\Del
ta/S_1} = \frac{1}{1+6\sup_{\text{acute}}(\Delta/S_1)}.$$

By **Weitzenböck's inequality**, $a^2+b^2+c^2 \ge 4\sqrt{3}\,\Delta$ for every t
riangle, with equality iff the triangle is equilateral. Since $S_1 = a^2+b^2+c^2
$,
$$\frac{\Delta}{S_1} \le \frac{1}{4\sqrt{3}},$$
and the equilateral triangle (which is acute) attains equality. Hence
$$\sup_{\text{acute}} \frac{\Delta}{S_1} = \frac{1}{4\sqrt{3}},$$
and therefore
$$k = \frac{1}{1+6\cdot\frac{1}{4\sqrt{3}}} = \frac{1}{1+\frac{3}{2\sqrt{3}}} =
\frac{1}{1+\frac{\sqrt{3}}{2}} = \frac{2}{2+\sqrt{3}} = 2(2-\sqrt{3}) = 4-2\sqrt
{3}.$$

**Verification of equality.** For an equilateral triangle with side $a$: $S_1 =
3a^2$, $\Delta = \frac{\sqrt{3}}{4}a^2$, so $S_2 = 3a^2 + 6\cdot\frac{\sqrt{3}}{
4}a^2 = 3a^2\bigl(1+\frac{\sqrt{3}}{2}\bigr)$, giving $\frac{S_1}{S_2} = \frac{2
}{2+\sqrt{3}} = 4-2\sqrt{3}$. Equality holds. $\checkmark$
