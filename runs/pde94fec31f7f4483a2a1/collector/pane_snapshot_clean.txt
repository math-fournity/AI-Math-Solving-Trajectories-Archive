(x)}$ where $f(x) = |1+x|^p - 1 - px$.

## Proof

**Setup and non-negativity.** For $x \ge -1$, $|1+x|^p = (1+x)^p \ge 1 + p(1+x-1
) = 1+px$ by convexity of $t^p$ ($p>1$), so $f(x)\ge 0$. For $x<-1$, writing $u=
-1-x>0$: $f = u^p + pu + (p-1) > 0$. So $f\ge 0$ everywhere and $c_p = \inf_{x\n
e 0} f(x)/\phi_p(x)$.

We analyze four regions. Set $R(x) = f(x)/\phi_p(x)$.

---

**Region A: $x \in (0,1]$, $\phi_p = x^2$.** Here $R_1(x) = \frac{(1+x)^p - 1 -
px}{x^2}$. As $x\to 0^+$, $R_1 \to \frac{p(p-1)}{2}$. Compute $R_1'(x) = h(x)/x^
3$ where
$$h(x) = (1+x)^{p-1}[x(p-2)-2] + px + 2.$$
One checks $h(0)=h'(0)=0$ and
$$h''(x) = p(p-1)(p-2)\,x\,(1+x)^{p-3}.$$
For $p\in(1,2)$ and $x\in(0,1)$: $p-2<0$ so $h''(x)<0$. Thus $h$ is concave with
 $h(0)=h'(0)=0$, giving $h(x)<0$ on $(0,1)$. Hence $R_1'<0$, so $R_1$ is strictl
y decreasing and
$$\inf_{x\in(0,1]} R_1 = R_1(1) = 2^p - 1 - p.$$

---

**Region B: $x\in[-1,0)$, $\phi_p = x^2$.** Set $x=-y$, $y\in(0,1]$. Then $R_1(-
y)=\frac{(1-y)^p-1+py}{y^2}$. With $k(y)=(1-y)^p-1+py$ and $m(y)=yk'(y)-2k(y)$,
we get $R_1'(-y)\propto m(y)/y^3$ where
$$m(y) = -(1-y)^{p-1}[y(p-2)+2]+2-py,\quad m(0)=m'(0)=0,$$
$$m''(y) = -p(p-1)(p-2)\,y\,(1-y)^{p-3} > 0 \text{ on } (0,1).$$
So $m$ is convex with $m(0)=m'(0)=0$, hence $m(y)>0$. Thus $R_1(-y)$ is increasi
ng in $y$, so
$$\inf_{x\in[-1,0)} R_1 = R_1(-1) = p-1.$$

---

**Region C: $x>1$, $\phi_p = x^p$.** With $s=1/x\in(0,1)$:
$$R_2 = (1+s)^p - s^p - ps^{p-1}, \quad R_2'(s)=p\bigl[(1+s)^{p-1}-s^{p-2}(s+p-1
)\bigr].$$
Set $F(s)=s^{2-p}(1+s)^{p-1}$. Since $(2-p)+(p-1)=1$ and $\ln$ is strictly conca
te:
$$\ln F = (2-p)\ln s + (p-1)\ln(1+s) < \ln\bigl((2-p)s+(p-1)(1+s)\bigr) = \ln(s+
p-1).$$
So $F(s)<s+p-1$ for $s\in(0,1)$, giving $R_2'(s)<0$. Thus $R_2$ is decreasing in
 $s$ (increasing in $x$), and
$$\inf_{x>1} R_2 = R_2(1) = 2^p-1-p.$$

---

**Region D: $x<-1$, $\phi_p=|x|^p$.** Set $x=-t$, $t>1$, $u=1/t\in(0,1)$:
$$R_2^-(u)=(1-u)^p - u^p + pu^{p-1}.$$
As $u\to 0$: $R_2^-\to 1$ with $R_2^{-\,\prime}\to +\infty$; at $u=1$: $R_2^-=p-
1$ with $R_2^{-\,\prime}(1)=p(p-2)<0$. So $R_2^-$ rises from $1$ to an interior
maximum then falls to $p-1<1$. Hence
$$\inf_{x<-1} R_2 = p-1 \quad(\text{at } x=-1).$$

---

**Comparison.** The four infima are $2^p-1-p$, $p-1$, $2^p-1-p$, $p-1$. Since $\
alpha(p)=2^p-1-p$ is convex ($\alpha''=2^p(\ln 2)^2>0$) and $\beta(p)=p-1$ is af
fine, with $\alpha(1)=\beta(1)=0$ and $\alpha(2)=\beta(2)=1$, convexity gives $\
alpha(p)\le\beta(p)$ on $[1,2]$, with equality only at the endpoints.

Therefore $c_p = \min(2^p-1-p,\; p-1) = 2^p - 1 - p$.

**Verification at $p=2$:** $f(x)=(1+x)^2-1-2x=x^2=\phi_2(x)$, so $c_2=1=2^2-1-2$
. ✓

---

$$\boxed{c_p = 2^p - 1 - p}$$
