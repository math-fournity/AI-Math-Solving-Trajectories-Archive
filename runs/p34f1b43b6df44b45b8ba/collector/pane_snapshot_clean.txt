## 解答

该命题**为假**。等式 $\|\lim_n T_n\| = \lim_n \|T_n\|$ 并不总是成立。

### 反例

设 $H = \ell^2(\mathbb{N})$，其标准正交基为 $\{e_n\}_{n \geq 1}$。对于每个 $n$，
定义线性算子 $T_n : \ell^2 \to \ell^2$ 为

$$T_n(x) = x_n \, e_1, \qquad x = (x_1, x_2, \dots).$$

即，$T_n$ 取 $x$ 的第 $n$ 个坐标并将其置于第一个位置。

**每个 $T_n$ 的范数为 1。** 确实，对于任意 $x \in \ell^2$，

$$\|T_n x\|_2 = |x_n| \cdot \|e_1\|_2 = |x_n| \leq \|x\|_2,$$

因此 $\|T_n\| \leq 1$。另一方面，$T_n e_n = e_1$，因此 $\|T_n\| \geq \|T_n e_n\|
/\|e_n\| = 1$。从而

$$\|T_n\| = 1 \quad \text{对于所有 } n, \qquad \text{因此 } \lim_n \|T_n\| = 1.$
$

**序列逐点（强算子拓扑）收敛于 $0$。** 对于每个固定的 $x \in \ell^2$，我们有 $\s
um_{k} |x_k|^2 < \infty$，这迫使 $x_n \to 0$。因此

$$\|T_n x\|_2 = |x_n| \to 0 \quad \text{当 } n \to \infty,$$

即 $T_n x \to 0$ 对于每个 $x$ 成立。强算子极限为 $\lim_n T_n = 0$（零算子）。

**等式不成立：**

$$\Big\|\lim_n T_n\Big\| = \|0\| = 0, \qquad \lim_n \|T_n\| = 1.$$

因此 $\|\lim_n T_n\| = 0 \neq 1 = \lim_n \|T_n\|$。$\square$

### 为什么会失败（结构性原因）

算子范数 $T \mapsto \|T\|$ 在 $B(H)$ 上的**范数拓扑**中是连续的，但序列极限 $\li
m_n T_n$ 可能存在于较弱的拓扑中——例如强算子拓扑（SOT）或弱算子拓扑（WOT）——在这
些拓扑中，范数函数**不是**连续的。上述反例中的收敛是 SOT 收敛，而非范数收敛，且
SOT 拓扑中的范数函数是下半连续的，但不是连续的，这允许 $\liminf \|T_n\| \geq \|\
lim T_n\|$ 且等式失效。

（如果将 $\lim_n T_n$ 限制为在**算子范数**中存在，则等式确实可以通过范数的连续性
得出，因为 $|\|T_n\| - \|T\|| \leq \|T_n - T\| \to 0$。但该命题在提出时并未带有
此限制，且“对于线性算子序列总是成立”这一说法被反例所驳倒。）
