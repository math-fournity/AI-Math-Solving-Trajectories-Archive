## Proof

**Key observation:** The set $S = \{x \in [0, \pi/2] : \cos(x) \in \mathbb{Q}\}$
 has Lebesgue measure zero.

*Proof that $S$ is countable (hence measure zero):* The map $x \mapsto \cos(x)$
is injective on $[0, \pi/2]$ (strictly decreasing). For each rational $q \in \ma
thbb{Q} \cap [0,1]$, there is at most one $x \in [0,\pi/2]$ with $\cos(x) = q$.
Since $\mathbb{Q} \cap [0,1]$ is countable, $S$ is countable. Every countable su
bset of $\mathbb{R}$ has Lebesgue measure zero.

**Consequence for the integral:** The functions $f$ and $g(x) = \sin^2(x)$ diffe
r only on $S$, a set of measure zero. A Riemann-integrable (equivalently, Lebesg
ue-integrable) function's integral is unaffected by changing its values on a mea
sure-zero set. Both $f$ and $g$ are bounded on $[0,\pi/2]$ (by $1$), and $g$ is
continuous, hence integrable. Therefore:

$$\int_0^{\pi/2} f(x)\,dx = \int_0^{\pi/2} \sin^2(x)\,dx.$$

**Evaluating the integral:** Using the identity $\sin^2(x) = \frac{1 - \cos(2x)}
{2}$,

$$\int_0^{\pi/2} \sin^2(x)\,dx = \int_0^{\pi/2} \frac{1 - \cos(2x)}{2}\,dx = \le
ft[\frac{x}{2} - \frac{\sin(2x)}{4}\right]_0^{\pi/2}.$$

At $x = \pi/2$: $\frac{\pi/2}{2} - \frac{\sin(\pi)}{4} = \frac{\pi}{4} - 0 = \fr
ac{\pi}{4}$.

At $x = 0$: $\frac{0}{2} - \frac{\sin(0)}{4} = 0$.

Therefore,

$$\int_0^{\pi/2} f(x)\,dx = \frac{\pi}{4} - 0 = \frac{\pi}{4}.$$

$$\boxed{\displaystyle\int_0^{\pi/2} f(x)\,dx = \frac{\pi}{4}}$$
