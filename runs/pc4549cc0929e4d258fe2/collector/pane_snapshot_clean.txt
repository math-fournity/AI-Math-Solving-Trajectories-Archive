## Construction and Proof

**Step 1 — A Vitali set with inner measure 0 and positive outer measure.**

Let \(V\subseteq[0,1]\) be a Vitali set, i.e. a set containing exactly one repre
sentative from each equivalence class of \([0,1]\) under \(x\sim y\iff x-y\in\ma
thbb{Q}\). Two standard facts:

- **\(V\) is not Lebesgue measurable.** If it were, the countably many disjoint
rational translates \(\{V+q:q\in\mathbb{Q}\cap[-1,1]\}\) would union to a set of
 measure \(1\) (they cover \([0,1]\) and lie in \([-1,2]\)), forcing \(\sum_q m(
V+q)=m(V)\cdot\aleph_0\in\{0,\infty\}\), contradicting the value being in \([1,3
]\).

- **\(m_{*}(V)=0\).** Suppose \(F\subseteq V\) is measurable with \(m(F)>0\). By
 Steinhaus's theorem, \(F-F\) contains an open interval around \(0\), hence some
 nonzero rational \(q\). But distinct elements of \(V\) differ by an irrational,
 so \(V-V\) contains no nonzero rational — contradiction. Thus every measurable
subset of \(V\) has measure \(0\), giving \(m_{*}(V)=0\).

- **\(m^{*}(V)>0\).** If \(m^{*}(V)=0\), then \(V\) would be a null set and henc
e measurable, contradicting the first fact. Set \(c:=m^{*}(V)\in(0,1]\).

**Step 2 — The construction.**

Define
\[
R\;=\;\bigcup_{n=0}^{\infty}(V+2n),\qquad V+2n:=\{v+2n:v\in V\}.
\]
Each translate \(V+2n\subseteq[2n,\,2n+1]\), and the intervals \([2n,2n+1]\) are
 pairwise disjoint with gaps \((2n+1,\,2n+2)\) between consecutive ones.

**Step 3 — The outer measure of \(R\) is infinite.**

For sets sitting in disjoint intervals separated by gaps, outer measure is *addi
tive*: if \(A\subseteq[a,b]\) and \(B\subseteq[c,d]\) with \(b<c\), then \(m^{*}
(A\cup B)=m^{*}(A)+m^{*}(B)\) (split any covering interval crossing the gap at a
 point inside the gap; this does not increase total length, yielding independent
 covers of \(A\) and \(B\)). By induction, for every finite \(N\),
\[
m^{*}\!\Bigl(\bigcup_{n=0}^{N}(V+2n)\Bigr)=\sum_{n=0}^{N}m^{*}(V+2n)=(N+1)\,c,
\]
using translation invariance \(m^{*}(V+2n)=m^{*}(V)=c\). Since \(R\supseteq\bigc
up_{n=0}^{N}(V+2n)\),
\[
m^{*}(R)\ge (N+1)\,c\quad\text{for all }N.
\]
Letting \(N\to\infty\) and using \(c>0\), we obtain \(m^{*}(R)=\infty\).

**Step 4 — The inner measure of \(R\) is \(0\) (hence finite).**

Let \(F\subseteq R\) be any Lebesgue measurable set. Then
\[
F\cap[2n,2n+1]\subseteq V+2n,
\]
and this intersection is measurable. Since \(m_{*}(V+2n)=m_{*}(V)=0\) (translati
on invariance of inner measure), every measurable subset of \(V+2n\) has measure
 \(0\); hence
\[
m\bigl(F\cap[2n,2n+1]\bigr)=0\quad\text{for all }n.
\]
Also \(F\cap(2n+1,\,2n+2)=\varnothing\), because \(R\) has no points in the gaps
. Therefore
\[
F=\bigcup_{n=0}^{\infty}\bigl(F\cap[2n,2n+1]\bigr),
\]
and by countable additivity of Lebesgue measure,
\[
m(F)=\sum_{n=0}^{\infty}m\bigl(F\cap[2n,2n+1]\bigr)=0.
\]
Thus *every* measurable subset of \(R\) has measure \(0\), and consequently
\[
m_{*}(R)=\sup\{m(F):F\subseteq R,\;F\text{ measurable}\}=0,
\]
which is finite.

**Conclusion.** The set \(R=\bigcup_{n=0}^{\infty}(V+2n)\), where \(V\subseteq[0
,1]\) is a Vitali set, satisfies
\[
m_{*}(R)=0\quad(\text{finite}),\qquad m^{*}(R)=\infty\quad(\text{infinite}).
\]
