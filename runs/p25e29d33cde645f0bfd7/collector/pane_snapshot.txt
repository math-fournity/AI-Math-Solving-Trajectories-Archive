## Solution

**Setup.** Place $B=(0,0)$, $C=(a,0)$ on the $x$-axis, $A=(p,q)$ with $q>0$. Let
 $a=BC$, $b=CA$, $c=AB$, and $\angle A = 60°$, so $a^2 = b^2+c^2-bc$.

**Euler line intersection.** The circumcenter is $O=(a/2,\; (p^2-ap+q^2)/(2q))$,
 the centroid is $G=((a+p)/3,\; q/3)$, and the orthocenter is $H=(p,\; p(a-p)/q)
$. Parametrizing the line through $G$ and $H$ and setting $y=0$ gives the inters
ection with $BC$:

$$x_X = \frac{p(a^2 - p^2 - q^2)}{3p(a-p) - q^2}.$$

**Express in side lengths.** Using $p = c(2c-b)/(2a)$ and $q^2 = 3b^2c^2/(4a^2)$
 (from $\angle A=60°$), a direct simplification yields:

$$x_X = \frac{a(2c-b)}{3(c-b)}.$$

Since $B$ lies between $X$ and $C$, we have $x_X < 0$, which forces $\tfrac{b}{2
} < c < b$. Then:

$$XB = -x_X = \frac{a(2c-b)}{3(b-c)} = 23, \qquad XC = a - x_X = \frac{a(2b-c)}{
3(b-c)}.$$

**Introduce ratio.** Let $r = b/c \in (1,2)$. Then:

$$XB = \frac{a(2-r)}{3(r-1)} = 23 \implies a = \frac{69(r-1)}{2-r}, \qquad XC =
\frac{23(2r-1)}{2-r}.$$

**Use $XA = 49$.** Since $X=(-23,0)$: $XA^2 = (p+23)^2 + q^2 = c^2 + 46p + 529 =
 2401$, so $c^2 + 46p = 1872$. Substituting $p = c^2(2-r)/(2a)$ and using $a = 6
9(r-1)/(2-r)$:

$$c^2\!\left[1 + \frac{(2-r)^2}{3(r-1)}\right] = 1872 \implies c^2 = \frac{5616(
r-1)}{r^2-r+1}.$$

**Combine with $a^2 = c^2(r^2-r+1)$.** From $a = 69(r-1)/(2-r)$ we get $a^2 = 47
61(r-1)^2/(2-r)^2$, and from above $a^2 = 5616(r-1)$. Setting equal (with $r\neq
 1$):

$$5616 = \frac{4761(r-1)}{(2-r)^2} \implies 624(2-r)^2 = 529(r-1).$$

Let $u = r-1 \in (0,1)$, so $2-r = 1-u$:

$$624(1-u)^2 = 529u \implies 624u^2 - 1777u + 624 = 0.$$

The discriminant is $1777^2 - 4\cdot624^2 = 3157729 - 1557504 = 1600225 = 1265^2
$, giving:

$$u = \frac{1777 \pm 1265}{1248}.$$

Only $u = 512/1248 = 16/39 \in (0,1)$ is valid, so $r = 55/39$.

**Compute $XC$:**

$$XC = \frac{23(2r-1)}{2-r} = \frac{23\cdot(110/39 - 1)}{2 - 55/39} = \frac{23 \
cdot 71/39}{23/39} = 23 \cdot \frac{71}{23} = 71.$$

**Verification.** With $r=55/39$: $a^2 = 5616\cdot16/39 = 2304$, so $a=48$; $c =
 1872/49$, $b=2640/49$. One checks $a^2=b^2+c^2-bc$ ✓, all angles acute ✓, not e
quilateral ✓, $XB=23$ ✓, and $XA^2 = c^2+46p+529 = 1872+529 = 2401 = 49^2$ ✓.

$$\boxed{XC = 71}$$
