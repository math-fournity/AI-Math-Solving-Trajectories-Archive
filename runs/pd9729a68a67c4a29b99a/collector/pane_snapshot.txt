**Answer: Yes.** Such an uncountable collection exists.

## Proof

Let our countably infinite set be the set $2^{<\omega}$ of all finite binary seq
uences (i.e., finite strings over $\{0,1\}$, including the empty string). This s
et is countably infinite, since it is the countable union $\bigcup_{n=0}^{\infty
} \{0,1\}^n$, each level being finite.

For each infinite binary sequence $x = (x_0, x_1, x_2, \dots) \in 2^{\omega}$, d
efine
$$A_x = \{ x{\upharpoonright}n : n \in \mathbb{N} \},$$
the set of all finite initial segments of $x$. Here $x{\upharpoonright}n = (x_0,
 x_1, \dots, x_{n-1})$ is the prefix of $x$ of length $n$ (with $x{\upharpoonrig
ht}0$ being the empty string).

**Each $A_x$ is non-empty (in fact infinite).** Since $x$ is an infinite sequenc
e, it has initial segments of every length $n \in \mathbb{N}$, so $A_x$ contains
 infinitely many distinct finite sequences.

**The family is uncountable.** The map $x \mapsto A_x$ from $2^{\omega}$ to $\ma
thcal{P}(2^{<\omega})$ is injective: if $x \neq y$, then $x$ and $y$ differ at s
ome coordinate, so $x{\upharpoonright}n \neq y{\upharpoonright}n$ for all suffic
iently large $n$, which means $A_x \neq A_y$. Since $2^{\omega}$ is uncountable
(it has cardinality $2^{\aleph_0}$), the collection $\{A_x : x \in 2^{\omega}\}$
 is uncountable.

**Pairwise intersections are finite.** Let $x \neq y$ be two distinct infinite b
inary sequences. Let $k$ be the first coordinate at which they differ, i.e., $x_
k \neq y_k$ and $x_i = y_i$ for all $i < k$. Then for $n \leq k$, we have $x{\up
harpoonright}n = y{\upharpoonright}n$ (the prefixes agree), and for $n > k$, we
have $x{\upharpoonright}n \neq y{\upharpoonright}n$ (the prefixes differ at posi
tion $k$). Therefore
$$A_x \cap A_y = \{ x{\upharpoonright}n : n \leq k \},$$
which is a finite set of size $k+1$.

Thus $\{A_x : x \in 2^{\omega}\}$ is an uncountable collection of non-empty (ind
eed infinite) subsets of the countably infinite set $2^{<\omega}$, such that the
 intersection of any two distinct members is finite. $\blacksquare$
