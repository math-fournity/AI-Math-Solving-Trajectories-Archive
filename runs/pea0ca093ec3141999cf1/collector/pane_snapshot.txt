## Proof

Define $f(z) = iz + \sqrt{1-z^2}$ and $g(z) = iz - \sqrt{1-z^2}$, where $\sqrt{\
cdot}$ denotes the principal branch throughout.

**Key identity.** For all $z \in \mathbb{C}$ (including $z = \pm 1$, where $\sqr
t{1-z^2}=0$):

$$f(z)\cdot g(z) = (iz)^2 - (1-z^2) = -z^2 - 1 + z^2 = -1.$$

**Suppose $f(z) \le 0$ for some $z$.** Then $f(z)$ is real and non-positive, so
$f(z) = -t$ for some $t \ge 0$.

- If $t = 0$: $f(z) = 0$, but then $f(z)\cdot g(z) = 0 \ne -1$, contradiction.
- So $t > 0$, and $g(z) = -1/f(z) = 1/t > 0$ (real and positive).

**$z$ must be purely imaginary.** Since $f(z) = -t$ and $g(z) = 1/t$ are both re
al:

$$f(z) + g(z) = 2iz = -t + \frac{1}{t} \in \mathbb{R}.$$

Thus $iz$ is real, so $z = iy$ for some $y \in \mathbb{R}$.

**Evaluating at $z = iy$.** We have $z^2 = -y^2$, so $1 - z^2 = 1 + y^2 > 0$. Si
nce $1+y^2$ is a positive real number, the principal square root is the positive
 real value:

$$\sqrt{1 - z^2} = \sqrt{1 + y^2} > 0.$$

Therefore:

$$f(iy) = i(iy) + \sqrt{1+y^2} = -y + \sqrt{1+y^2}.$$

**The condition $f(iy) \le 0$ is impossible.** We need $\sqrt{1+y^2} \le y$. Sin
ce $\sqrt{1+y^2} > 0$, this requires $y > 0$. Squaring (both sides non-negative)
:

$$1 + y^2 \le y^2 \implies 1 \le 0,$$

a contradiction. (Even without squaring: $\sqrt{1+y^2} > \sqrt{y^2} = |y| \ge y$
 for all $y$, so $-y + \sqrt{1+y^2} > 0$ always.)

**Conclusion.** No $z \in \mathbb{C}$ satisfies $iz + \sqrt{1-z^2} \le 0$. The s
olution set is:

$$\boxed{\emptyset}$$
