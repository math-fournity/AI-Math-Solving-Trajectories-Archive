## Proof

-1$. The resolvent cubic is $g(x) = x^3 + 4x - 16 = (x-2)(x^2+2x+8)$, with discr

scriminant equals that of its resolvent cubic:
$$\Delta_f = 256r^3 - 27q^4 = 256(-1)^3 - 27(4)^4 = -256 - 6912 = -7168 = -32^2
\cdot 7.$$
So $\Delta_f = \Delta_g = -7168$, which is **not a square** in $\mathbb{Q}$.

**Step 2: Narrowing the candidates.** Since $f$ is irreducible, $G$ is a transit

 a square, $G \not\subseteq A_4$, which rules out $V_4 \subseteq A_4$. Thus $G \
in \{D_4, C_4\}$.

*Justification:* For $C_4 = \langle(1234)\rangle$, the subgroup $C_4 \cap A_4 =

**Step 4: Testing factorization over $\mathbb{Q}(\sqrt{-7})$.** Suppose $f$ fact

$$x^4 + 4x - 1 = (x^2 + ax + b)(x^2 - ax + c), \quad a,b,c \in \mathbb{Q}(\sqrt{

Expanding and matching coefficients:
$$c + b = a^2, \quad a(c-b) = 4, \quad bc = -1.$$
From the first two: $c = \frac{a^3+4}{2a}$, $b = \frac{a^3-4}{2a}$. Substituting

$$\frac{a^6 - 16}{4a^2} = -1 \implies a^6 + 4a^2 - 16 = 0.$$
Setting $u = a^2$, this becomes $u^3 + 4u - 16 = 0$, which is exactly the resolv
ent cubic $g(u)=0$. So $a^2$ must be a root of $g$:
$$u \in \{2, \ -1+\sqrt{-7}, \ -1-\sqrt{-7}\}.$$

We check whether any of these is a square in $\mathbb{Q}(\sqrt{-7})$:

- **$u = 2$:** $a = \sqrt{2} \notin \mathbb{Q}(\sqrt{-7})$, since $\mathbb{Q}(\s

$$p^2 - 7q^2 = -1, \quad 2pq = 1 \implies q = \tfrac{1}{2p}.$$
Substituting: $p^2 - \frac{7}{4p^2} = -1$, i.e., $4p^4 + 4p^2 - 7 = 0$. With $v

$$v = \frac{-4 \pm \sqrt{16+112}}{8} = \frac{-1 \pm 2\sqrt{2}}{2}.$$
This requires $p^2 \in \mathbb{Q}(\sqrt{2}) \setminus \mathbb{Q}$, so $p \notin
\mathbb{Q}$. No solution in $\mathbb{Q}(\sqrt{-7})$.

-7})$, so $f$ does not factor into quadratics over $\mathbb{Q}(\sqrt{-7})$. By t

$$\boxed{\operatorname{Gal}(f/\mathbb{Q}) \cong D_4.}$$
