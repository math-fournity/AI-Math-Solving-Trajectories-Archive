Looking at this problem, I need to find the largest $C$ such that any multiset o
f integers $\geq 2$ with reciprocal sum $< C$ can be partitioned into at most $n
$ groups, each with reciprocal sum $< 1$.

**Answer: $C = \dfrac{n+1}{2}$.**

---

## Proof

### Upper Bound: $C \leq \frac{n+1}{2}$

Consider $n+1$ copies of the integer $2$. The reciprocal sum is $\frac{n+1}{2}$.
 Each group can contain **at most one** copy of $2$, since $\frac{1}{2}+\frac{1}
{2}=1 \not< 1$. Thus partitioning requires at least $n+1$ groups, exceeding $n$.
 If $C > \frac{n+1}{2}$, this multiset satisfies the hypothesis but not the conc
lusion—contradiction. So $C \leq \frac{n+1}{2}$.

### Lower Bound: $C \geq \frac{n+1}{2}$

We prove by **induction on $n$** that any multiset of integers $\geq 2$ with rec
iprocal sum $< \frac{n+1}{2}$ can be partitioned into $n$ groups, each with sum
$< 1$.

**Base case** ($n=1$): If the sum $< 1$, one group suffices. ✓

**Inductive step** ($n \geq 2$): Assume the result for $n-1$. Let the multiset h
ave reciprocals $r_1 \geq r_2 \geq \cdots \geq r_m$ (each $r_i \in \{1/2, 1/3, 1
/4, \ldots\}$) with total sum $S < \frac{n+1}{2}$.

**Case 1: $S < 1$.** Place all items in one group. Done (using $1 \leq n$ groups
). ✓

**Case 2: All items equal $1/2$.** The count $k$ satisfies $\frac{k}{2} < \frac{
n+1}{2}$, so $k \leq n$. Place each item in its own group. ✓

**Case 3: $S \geq 1$ and not all items are $1/2$.** Then some item has size $\le
q 1/3$.

*Finding a good subset.* Sort items in non-increasing order and greedily add ite
ms until the running sum first exceeds $1/2$. Call the resulting subset $T$ with
 sum $s$.

Since the sum before the last item was $\leq 1/2$ and each item is $\leq 1/2$, w
e have $s \in (1/2,\, 1]$.

- **If $s < 1$:** Set $T$ as our chosen group. Then $\operatorname{sum}(T) = s \
in (1/2, 1)$.

- **If $s = 1$:** Then the sum before the last item was exactly $1/2$ and the la
st item was exactly $1/2$ (since both are $\leq 1/2$ and sum to $1$). Because it
ems are sorted non-increasingly and the last added item is $1/2$, all items in $
T$ are $1/2$. The equation $(j-1)\cdot\frac{1}{2} = \frac{1}{2}$ gives $j=2$, so
 $T = \{1/2,\, 1/2\}$.

  Since not all items are $1/2$, there exists an item $r \leq 1/3$ outside $T$.
Replace $T$ with $T' = \{1/2,\, r\}$, which has sum $\frac{1}{2}+r \leq \frac{5}
{6} \in (1/2, 1)$.

In either subcase, we obtain a subset $G$ with $\operatorname{sum}(G) \in (1/2,
1)$, so $G$ forms a valid group.

*Applying induction.* The remaining items have sum:
$$S - \operatorname{sum}(G) < \frac{n+1}{2} - \frac{1}{2} = \frac{n}{2} = \frac{
(n-1)+1}{2}.$$
By the inductive hypothesis (with parameter $n-1$), the remaining items can be p
artitioned into $n-1$ groups, each with sum $< 1$. Together with $G$, this gives
 $n$ groups. ✓

This completes the induction, establishing $C \geq \frac{n+1}{2}$.

### Conclusion

Combining both bounds:

$$\boxed{C = \frac{n+1}{2}}.$$
