Looking at this problem, I need to find sets A and B, each with k integers, such
 that A+B = {0,1,2,...,100}, then find the maximum M and minimum m of such k.

## Finding the minimum m

**Lower bound:** |A+B| ≤ |A|·|B| = k². Since |A+B| = 101, we need k² ≥ 101, so k
 ≥ 11 (since 10² = 100 < 101).

**Construction for k = 11:** Let A = {0, 1, 2, ..., 10} and B = {0, 9, 18, 27, 3
6, 45, 54, 63, 72, 81, 90}.

Both sets have 11 elements. For each b ∈ B, the set A + b = {b, b+1, ..., b+10}
is an interval of 11 consecutive integers. Since consecutive elements of B diffe
r by 9, these intervals overlap (by 2 elements) and chain together:
- b=0: {0,...,10}
- b=9: {9,...,19} → union {0,...,19}
- b=18: {18,...,28} → union {0,...,28}
- ...continuing with step 9...
- b=90: {90,...,100} → union {0,...,100}

No gaps (each interval starts 9 after the previous, within the 11-width coverage
) and no overflow (max sum = 90+10 = 100). So A+B = {0,...,100}. ✓

Thus **m = 11**.

## Finding the maximum M

**Upper bound:** Let a_min, a_max be the min/max of A, and b_min, b_max be the m
in/max of B. Since A+B = {0,...,100}:
- a_min + b_min = 0 (smallest sum)
- a_max + b_max = 100 (largest sum)

Set α = a_max − a_min, β = b_max − b_min. Then α + β = 100.

Since A is a set of integers contained in [a_min, a_max], we have |A| ≤ α + 1. S
imilarly |B| ≤ β + 1. Therefore:

k = |A| ≤ α + 1 and k = |B| ≤ β + 1

so k ≤ min(α+1, β+1). To maximize this subject to α + β = 100 with α, β ≥ 0, by
symmetry the optimum is α = β = 50, giving k ≤ 51.

**Construction for k = 51:** Let A = B = {0, 1, 2, ..., 50}. Then A+B = {0, 1, .
.., 100} (every integer from 0 to 100 is a sum of two integers in {0,...,50}, an
d no sum exceeds 100). Both sets have 51 elements. ✓

Thus **M = 51**.

## Result

$$M + m = 51 + 11 = \boxed{62}$$
