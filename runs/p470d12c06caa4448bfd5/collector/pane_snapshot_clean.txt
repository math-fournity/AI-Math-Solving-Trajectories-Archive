## Solution

We find all real quadruples $(a,b,c,d)$ satisfying
$$ab+c+d=3,\quad bc+d+a=5,\quad cd+a+b=2,\quad da+b+c=6.$$

**Step 1: Form cyclic differences.** Subtract consecutive equations:

- $(2)-(1):$ $bc-ab+a-c = 2$, i.e. $(c-a)(b-1)=2$. &ensp;(A)
- $(3)-(2):$ $cd-bc+b-d = -3$, i.e. $(d-b)(c-1)=-3$. &ensp;(B)
- $(4)-(3):$ $da-cd+c-a = 4$, i.e. $(a-c)(d-1)=4$. &ensp;(C)
- $(1)-(4):$ $ab-da+d-b = -3$, i.e. $(b-d)(a-1)=-3$. &ensp;(D)

**Step 2: $a\ne c$.** If $a=c$, then (A) gives $0=2$, contradiction. So $a\ne c$
.

**Step 3: Parameterize.** From (A), $(a-c)(b-1)=-2$; from (C), $(a-c)(d-1)=4$. D
ividing,
$$\frac{d-1}{b-1}=-2 \implies d=3-2b.$$
Set $t:=b-1$. Then $d-1=-2t$, so $d=1-2t$ and $b=1+t$.

From (B): $(d-b)(c-1)=-3$. Since $d-b=(1-2t)-(1+t)=-3t$, we get $-3t(c-1)=-3$, h
ence $t(c-1)=1$, so $c=1+\tfrac1t$ (in particular $t\ne0$).

From (D): $(b-d)(a-1)=-3$. Since $b-d=3t$, we get $3t(a-1)=-3$, hence $t(a-1)=-1
$, so $a=1-\tfrac1t$.

Consistency check with (A): $(a-c)(b-1)=\bigl((1-\tfrac1t)-(1+\tfrac1t)\bigr)t=(
-\tfrac2t)\cdot t=-2$. ✓

**Step 4: Determine $t$.** Substitute into equation (1):
$$ab+c+d = \Bigl(1-\tfrac1t\Bigr)(1+t)+\Bigl(1+\tfrac1t\Bigr)+\Bigl(1-2t\Bigr).$
$
Expanding, $\bigl(1-\tfrac1t\bigr)(1+t)=t-\tfrac1t$, so
$$ab+c+d=\Bigl(t-\tfrac1t\Bigr)+\Bigl(2+\tfrac1t-2t\Bigr)=2-t.$$
Setting $2-t=3$ gives $t=-1$.

**Step 5: Compute and verify.** With $t=-1$:
$$a=1-\tfrac1{-1}=2,\quad b=1+(-1)=0,\quad c=1+\tfrac1{-1}=0,\quad d=1-2(-1)=3.$
$

Check:
- $ab+c+d = 2\cdot0+0+3 = 3$ ✓
- $bc+d+a = 0\cdot0+3+2 = 5$ ✓
- $cd+a+b = 0\cdot3+2+0 = 2$ ✓
- $da+b+c = 3\cdot2+0+0 = 6$ ✓

**Uniqueness.** The differences (A)–(D) (three independent) together with equati
on (1) form four independent equations in four unknowns. The parameterization re
duced everything to a single linear equation $2-t=3$ in one parameter, yielding
exactly one solution.

The unique quadruple is $\boxed{(a,b,c,d)=(2,0,0,3)}$.
