## 解答

**设置。** 设 $A = (a, f(a))$ 和 $B = (b, f(b))$，其中 $a, b > 0$，$a \neq b$。
垂足为 $H_A = (a, 0)$ 和 $H_B = (b, 0)$。

**计算两个面积。**

三角形 $AOB$ 的面积（顶点为 $O=(0,0)$, $A$, $B$）：
$$S_{\triangle} = \tfrac{1}{2}\,|a\,f(b) - b\,f(a)|.$$

梯形 $ABH_BH_A$ 的面积（平行边为长度 $f(a)$ 和 $f(b)$ 的垂直线段，水平距离为 $|b
-a|$）：
$$S_{\text{trap}} = \tfrac{1}{2}\,(f(a)+f(b))\,|b-a|.$$

令 $g(x) = f(x)/x > 0$。两边约去 $\tfrac{1}{2}$ 并除以 $ab > 0$，条件变为：
$$|g(b) - g(a)| = \frac{(a\,g(a) + b\,g(b))\,|b-a|}{ab}, \qquad \text{对所有 } a
 \neq b > 0. \tag{$\star$}$$

**情况分析（$a < b$）。**

*情况 1：$g(b) \geq g(a)$。* 则 ($\star$) 化简为
$$ab\,(g(b)-g(a)) = (a\,g(a)+b\,g(b))(b-a),$$
展开并合并同类项后得到：
$$g(b)\,b\,(2a - b) = g(a)\,a\,(2b - a). \tag{C1}$$
由于 $g(a), g(b), a, b > 0$ 且 $2b - a > 0$，我们需要 $2a - b > 0$，即 **$b < 2a
$**。若 $b \geq 2a$，则左边 $\leq 0$ 而右边 $> 0$ —— 矛盾。此外，$g(b) = g(a)$
且 $b \geq 2a$ 会使得 ($\star$) 变为 $0 = (a\,g(a)+b\,g(b))(b-a) > 0$，同样矛盾
。因此：

> **当 $b \geq 2a$ 时，我们必须有 $g(b) < g(a)$。**

*情况 2：$g(b) < g(a)$。* 则 ($\star$) 化简为
$$ab\,(g(a)-g(b)) = (a\,g(a)+b\,g(b))(b-a),$$
化简后得到：
$$b^2\,g(b) = a^2\,g(a), \quad \text{即} \quad b\,f(b) = a\,f(a). \tag{C2}$$

**关键推论。** 设 $h(x) = x\,f(x)$。根据上述结论，对于 **任意** $a > 0$ 和 **任
意** $b \geq 2a$，我们有 $g(b) < g(a)$，因此适用情况 2，得到：
$$h(b) = h(a) \qquad \text{当 } b \geq 2a. \tag{$\dagger$}$$

**$h$ 是常数。** 设 $x < y$ 为 $(0,\infty)$ 中的任意两点。取 $a = x/2$，则 $2a =
 x$。由于 $y > x = 2a$ 且 $x \geq 2a$，由 ($\dagger$) 得：
$$h(y) = h(a) = h(x/2) \quad \text{且} \quad h(x) = h(a) = h(x/2).$$
因此 $h(x) = h(y)$。由于 $x < y$ 是任意的，$h$ 在 $(0,\infty)$ 上是常数：$h(x) =
 c$，其中 $c > 0$（因为 $f > 0$）。

**结论。** $x\,f(x) = c$，所以 $f(x) = \dfrac{c}{x}$，其中 $c > 0$。

**验证。** 设 $f(x) = c/x$：
- $S_{\triangle} = \tfrac{1}{2}\left|\tfrac{ac}{b} - \tfrac{bc}{a}\right| = \tfr
ac{c}{2}\cdot\tfrac{|a^2 - b^2|}{ab} = \tfrac{c(a+b)|a-b|}{2ab}$.
- $S_{\text{trap}} = \tfrac{1}{2}\left(\tfrac{c}{a}+\tfrac{c}{b}\right)|b-a| = \
tfrac{c(a+b)|a-b|}{2ab}$.

两者相等。$\checkmark$

**所有满足条件的函数为 $f(x) = \dfrac{c}{x}$，其中 $c > 0$。**
