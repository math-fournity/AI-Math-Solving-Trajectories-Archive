- $|BH| = 2R|\cos B|$, $|CH| = 2R|\cos C|$ (distances from vertices to orthocent

### Step 1: MH + NH is position-independent

Let $BM = CN = d$. Since $M$ lies on segment $BH$: $MH = |BH|-d$ (with $0 < d \l
e |BH|$). Since $N$ lies on line $CH$ beyond $H$ (H between C and N): $CN = |CH|
+HN$, so $HN = d - |CH|$ (with $d > |CH|$). Therefore:

$$MH + NH = (|BH|-d)+(d-|CH|) = |BH|-|CH| = 2R(|\cos B|-|\cos C|).$$

A valid position exists iff $|CH| < |BH|$, i.e., $|\cos C| < |\cos B|$ (so that
$d \in (|CH|,|BH|]$ is nonempty).

### Step 2: Case analysis

**Case 1: Both $B,C$ acute** ($B,C \in (0°,90°)$, $B+C=120°$). Then $|\cos B|=\c
os B$, $|\cos C|=\cos C$. Validity $|\cos C|<|\cos B|$ gives $B < C$, i.e., $B <

Set $B=60°-\theta$, $C=60°+\theta$, $\theta\in(0°,30°)$:
- $\cos B - \cos C = 2\sin 60°\sin\theta = \sqrt{3}\sin\theta$,
- $\cos B\cos C = \cos^2 60° - \sin^2\theta = \tfrac14 - \sin^2\theta$,
- $1-4\cos B\cos C = 4\sin^2\theta$.

$$\frac{MH+NH}{OH} = \frac{2R\cdot\sqrt{3}\sin\theta}{R\cdot 2\sin\theta} = \sqr
t{3}.$$

$$\frac{MH+NH}{OH} = \frac{2\cos\frac{C-B}{2}}{2\sin\frac{C-B}{2}} = \cot\frac{C

30°) = \left(\frac{1}{\sqrt{3}},\sqrt{3}\right)$.
