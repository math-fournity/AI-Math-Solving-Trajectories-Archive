# Problem

The index is calculated based on the initial nutrient dosage $x$. The formula for the total index involves the base dosage added to a cascading recursive growth factor. Specifically, the yield index is defined as:
$$f(x) = x + \sqrt{x + \sqrt{x + \sqrt{x + \sqrt{x + \ldots}}}}$$

Find the smallest positive integer $x$ such that the growth meets the viability requirement $f(x) \ge 50\sqrt{x}$.
