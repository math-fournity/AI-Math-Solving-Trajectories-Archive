## Proof

**Reformulation.** Since $x^2 + ax + 1$ is monic, by Gauss's Lemma the condition
 $(x^2+ax+1) \mid Q(x)$ in $\mathbb{Z}[x]$ is equivalent to divisibility in $\ma
thbb{Q}[x]$, which holds iff every root of $x^2+ax+1$ is a root of $Q$.

Let $\alpha, \beta$ be the roots of $x^2+ax+1=0$, so $\alpha+\beta = -a$ and $\a
lpha\beta = 1$, hence $\beta = 1/\alpha$.

---

### Case $a = 1$: Works

The roots are $\omega, \omega^2$ where $\omega = e^{2\pi i/3}$, a primitive cube
 root of unity. We need $Q(\omega) = 0$.

Grouping by residue mod 3 (each class has exactly 672 indices since $2016 = 3 \c
dot 672$):
$$Q(\omega) = S_0 + S_1 \omega + S_2 \omega^2, \quad S_j = \sum_{i \equiv j \pmo
d{3}} a_i.$$
Since $1 + \omega + \omega^2 = 0$, the condition $Q(\omega)=0$ is equivalent to
$S_0 = S_1 = S_2$.

**Construction:** Take all $a_i = 1$. Then $Q(x) = x + x^2 + \cdots + x^{2016} =
 x\cdot\frac{x^{2016}-1}{x-1}$. Since $2016 = 3 \cdot 672$:
$$x^{2016}-1 = (x^3-1)(x^{2013}+x^{2010}+\cdots+1) = (x-1)(x^2+x+1)(x^{2013}+x^{
2010}+\cdots+1),$$
so $Q(x) = x(x^2+x+1)(x^{2013}+x^{2010}+\cdots+1)$, giving $P(x) = x(x^{2013}+x^
{2010}+\cdots+x^{2014}) \in \mathbb{Z}[x]$. ✓

### Case $a = 2$: Works

Here $x^2+2x+1 = (x+1)^2$, so we need $(x+1)^2 \mid Q(x)$, i.e., $Q(-1)=0$ and $
Q'(-1)=0$.

Start with $Q_0(x) = \sum_{i=1}^{2016} x^i$ (all $a_i = 1$):
- $Q_0(-1) = \sum_{i=1}^{2016}(-1)^i = 0$ (1008 even, 1008 odd indices). ✓
- $Q_0'(-1) = \sum_{\text{odd }i} i - \sum_{\text{even }i} i = 1008^2 - 1008\cdo
t1009 = 1016064 - 1017072 = -1008 \neq 0$.

**Adjustment:** Flip $a_1, a_2, a_3, a_{506}$ from $1$ to $-1$. Setting $Q = Q_0
 - 2x - 2x^2 - 2x^3 - 2x^{506}$:

- Change in $Q(-1)$: $-2((-1)+1+(-1)+1) = 0$, so $Q(-1) = 0$. ✓
- Change in $Q'(-1)$: $-2(1\cdot1 + 2\cdot(-1) + 3\cdot1 + 506\cdot(-1)) = -2(1-
2+3-506) = 1008$, so $Q'(-1) = -1008+1008 = 0$. ✓

Since $(x+1)^2$ is monic and divides $Q$ in $\mathbb{Q}[x]$, the quotient $P = Q
/(x+1)^2 \in \mathbb{Z}[x]$. ✓

### Case $a \geq 3$: Impossible

For $a \geq 3$, the discriminant $a^2 - 4 > 0$ gives two real roots. The root wi
th larger absolute value is:
$$|\alpha| = \frac{a + \sqrt{a^2-4}}{2} \geq \frac{3+\sqrt{5}}{2} > 2.$$

(The function $f(a) = \frac{a+\sqrt{a^2-4}}{2}$ is increasing for $a > 2$.)

Since $\alpha$ is a root of $x^2+ax+1$, it must be a root of $Q$, i.e., $Q(\alph
a) = \sum_{i=1}^{2016} a_i \alpha^i = 0$. But:

$$|Q(\alpha)| \geq |\alpha|^{2016} - \sum_{i=1}^{2015} |\alpha|^i = |\alpha|^{20
16} - \frac{|\alpha|^{2016}-|\alpha|}{|\alpha|-1} = \frac{|\alpha|\bigl(|\alpha|
^{2015}(|\alpha|-2)+1\bigr)}{|\alpha|-1}.$$

Since $|\alpha| > 2$, we have $|\alpha|^{2015}(|\alpha|-2) > 0$, so the numerato
r satisfies $|\alpha|(|\alpha|^{2015}(|\alpha|-2)+1) > |\alpha| > 0$, and the de
nominator $|\alpha|-1 > 0$. Therefore $|Q(\alpha)| > 0$, contradicting $Q(\alpha
) = 0$.

Hence no solution exists for $a \geq 3$.

### Conclusion

The positive integers $a$ for which such $P$ and $Q$ exist are exactly $\boxed{a
 \in \{1, 2\}}$.
