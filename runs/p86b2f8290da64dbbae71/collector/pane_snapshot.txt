### Setup

A balanced parenthesis phrase of length 14 has 7 pairs. The total number of such
 phrases is the Catalan number $C_7 = 132$.

I model each balanced phrase as an ordered rooted forest: each matched pair `(..
.)` is a node, and `()` (a pair with empty content) is a leaf. The three reducti
on rules become tree operations:

| Rule | String | Tree meaning |
|------|--------|-------------|
| R1: `(())`→A | `(` `()` `)` | Node with one leaf child → leaf |
| R2: `(A)`→A | `(` A `)` | Node with one reduced child → leaf |
| R3: `AA`→A | A A | Two adjacent sibling leaves → one leaf |

A phrase reduces to A iff its forest reduces to a single leaf.

### Key structural lemma

**A leaf `()` can never become A on its own** — no rule matches the bare string
`()`. The only way to eliminate a leaf is via its **parent** wrapping it as `(()
)`→A (R1). This means:

- **A node with ≥ 2 children** is reducible iff **every** child is itself a redu
cible tree. (Each child must independently reduce to A so they can merge via R3;
 a leaf child cannot, and dooms the node.)
- **A node with exactly 1 child** is reducible iff the child is a leaf (R1 appli
es directly) **or** the child is a reducible tree (reduce child→A, then R2).
- **A leaf (0 children)** is **not** reducible.

Cross-boundary reductions (rules matching substrings spanning two siblings) neve
r help: balanced strings have boundary characters `)`...`(` between siblings, wh
ich no rule's left-hand side can bridge. I verified this on multiple examples (e
.g., `(()())(())`, `(())()`, `A()` — all get stuck).

### Recursion

Let $g(n)$ = number of reducible **trees** with $n$ pairs, $f(n)$ = number of re
ducible **forests** with $n$ pairs total.

**Forest → Tree:** A tree with $n$ pairs wraps a forest of $n-1$ pairs. It is re
ducible if the inner forest is reducible, **or** the inner forest is exactly `()
` (one leaf, only when $n=2$):
$$g(n) = f(n-1) + \delta_{n,2}$$

**Forest decomposition:** A forest is an ordered sequence of trees; it is reduci
ble iff all trees are reducible:
$$f(n) = \sum_{\text{compositions } n=n_1+\cdots+n_m} g(n_1)\cdots g(n_m), \qqua
d f(0)=0$$

Equivalently: $F(x) = G(x)/(1-G(x))$ and $G(x) = xF(x) + x^2$, giving the quadra
tic:
$$G(x)^2 - (1-x+x^2)\,G(x) + x^2 = 0$$
