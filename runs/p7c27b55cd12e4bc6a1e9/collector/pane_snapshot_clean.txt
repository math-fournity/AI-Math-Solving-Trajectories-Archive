## 答案：正确。该命题成立。

**证明。**

令 $S = \sum_{k=1}^{\infty} b_k^2 < \infty$。由于 $b_k = a_{k+1} - a_k$，通过裂
项求和可得 $a_k = a_1 + \sum_{j=1}^{k-1} b_j$（对于 $k \ge 2$）。定义 $c_1 = 0$
且对于 $k \ge 2$，有 $c_k = \sum_{j=1}^{k-1} b_j$，因此 $a_k = a_1 + c_k$。

利用 $(x+y)^2 \le 2x^2 + 2y^2$：

$$\frac{1}{n^2}\sum_{k=1}^n a_k^2 \;\le\; \frac{2n\,a_1^2}{n^2} + \frac{2}{n^2}\
sum_{k=1}^n c_k^2 \;=\; \frac{2a_1^2}{n} + \frac{2}{n^2}\sum_{k=1}^n c_k^2.$$

第一项趋于 $0$。接下来证明 $\frac{1}{n^2}\sum_{k=1}^n c_k^2 \to 0$。

**裂项分解。** 固定 $\varepsilon > 0$。选取 $N$ 使得 $\sum_{j=N+1}^{\infty} b_j^
2 < \varepsilon$。将 $c_k = c_k' + c_k''$ 分解，其中

$$c_k' = \sum_{j=1}^{\min(k-1,\,N)} b_j, \qquad c_k'' = \sum_{j=N+1}^{k-1} b_j \
;\;(\text{对于 } k \le N+1 \text{ 为 } 0).$$

**$c_k'$ 的界限。** 对于 $k > N$，$c_k' = B := \sum_{j=1}^{N} b_j$ 为常数。因此

$$\sum_{k=1}^n (c_k')^2 \;\le\; \underbrace{\sum_{k=1}^{N+1}(c_k')^2}_{=:\,C_N\t
ext{ (固定)}} + (n-N-1)\,B^2,$$

所以 $\frac{1}{n^2}\sum_{k=1}^n (c_k')^2 \le \frac{C_N}{n^2} + \frac{B^2}{n} \xr
ightarrow{n\to\infty} 0.$

**$c_k''$ 的界限。** 对于 $k > N+1$，根据 Cauchy–Schwarz 不等式，

$$(c_k'')^2 = \Bigl(\sum_{j=N+1}^{k-1} b_j\Bigr)^2 \le (k-1-N)\sum_{j=N+1}^{k-1}
 b_j^2 \le (k-1)\,\varepsilon.$$

因此 $\displaystyle\sum_{k=1}^n (c_k'')^2 \le \varepsilon\sum_{k=1}^n (k-1) = \v
arepsilon\cdot\frac{n(n-1)}{2} \le \frac{\varepsilon\, n^2}{2}.$

**合并结果。** 利用 $(c_k'+c_k'')^2 \le 2(c_k')^2 + 2(c_k'')^2$：

$$\frac{1}{n^2}\sum_{k=1}^n c_k^2 \;\le\; \frac{2}{n^2}\sum_{k=1}^n (c_k')^2 + \
frac{2}{n^2}\sum_{k=1}^n (c_k'')^2 \;\le\; \frac{2}{n^2}\sum_{k=1}^n (c_k')^2 +
\varepsilon.$$

取 $n \to \infty$ 时的上极限：

$$\limsup_{n\to\infty}\,\frac{1}{n^2}\sum_{k=1}^n c_k^2 \;\le\; \varepsilon.$$

由于 $\varepsilon > 0$ 是任意的，我们得出 $\frac{1}{n^2}\sum_{k=1}^n c_k^2 \to 0
$，从而有 $\frac{1}{n^2}\sum_{k=1}^n a_k^2 \to 0$。$\blacksquare$
