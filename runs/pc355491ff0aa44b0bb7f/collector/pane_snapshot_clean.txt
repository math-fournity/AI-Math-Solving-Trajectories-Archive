## Proof

We prove that the condition forces $(a_n)$ to be Cauchy; since $\mathbb{R}$ is c
omplete, this yields convergence.

**Hypothesis.** For every function $f:\mathbb{N}\to\mathbb{N}_{\ge 1}$,
$$\lim_{n\to\infty}\bigl(a_{n+f(n)}-a_n\bigr)=0.$$

**Assume for contradiction** that $(a_n)$ is **not** Cauchy. Then there exists $
\varepsilon>0$ such that for every $N$ one can find indices $m,n\ge N$ with $|a_
m-a_n|\ge\varepsilon$.

Using this, construct two sequences $(m_k),(n_k)$ inductively so that
$$m_1<n_1<m_2<n_2<\cdots,\qquad |a_{n_k}-a_{m_k}|\ge\varepsilon\ \text{for all }
k.$$
This is possible: having chosen up to $n_{k-1}$, apply the non‑Cauchy condition
with $N>n_{k-1}$ to obtain $m_k,n_k\ge N$; order them so that $m_k<n_k$. Then $|
a_{n_k}-a_{m_k}|\ge\varepsilon$, and the strict separation $n_{k-1}<m_k$ guarant
ees all the $m_k$ are distinct and $m_k\to\infty$.

Now define a positive‑integer‑valued function $f$ by
$$
f(m_k)=n_k-m_k\quad(\ge 1),\qquad f(n)=1\ \text{for }n\notin\{m_k:k\ge 1\}.
$$
This is well defined because the $m_k$ are distinct. By the hypothesis,
$$a_{n+f(n)}-a_n\to 0.$$
Yet along the subsequence $n=m_k$,
$$a_{m_k+f(m_k)}-a_{m_k}=a_{n_k}-a_{m_k},$$
and $|a_{n_k}-a_{m_k}|\ge\varepsilon$ for every $k$. Since $m_k\to\infty$, the s
ubsequence $\bigl(a_{m_k+f(m_k)}-a_{m_k}\bigr)_{k}$ cannot converge to $0$ — con
tradicting the hypothesis.

Therefore $(a_n)$ is Cauchy, and hence **convergent**. $\blacksquare$
