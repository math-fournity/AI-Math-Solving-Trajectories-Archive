**Answer: Yes.** Every continuous $f: X \to \mathbb{R}$ is constant on some inte
rval $(\alpha, \Omega)$ with $\alpha$ countable.

---

**Proof.**

Let $X = [0, \Omega)$ be the set of all countable ordinals with the order topolo
gy.

**Step 1: $X$ is countably compact, hence $f$ is bounded.**

Let $S \subseteq X$ be a countably infinite subset of distinct ordinals. Set $\b
eta = \sup S$. Since $S$ is countable and each element is a countable ordinal, $
\beta$ is a countable ordinal, so $\beta \in X$. We claim $\beta$ is a limit poi
nt of $S$. Any basic neighborhood of $\beta$ contains an interval $(c, d)$ with
$c < \beta < d$. Since $\beta = \sup S$, for any $c < \beta$ there exists $s \in
 S$ with $c < s \leq \beta$. If $s \neq \beta$, then $s \in (c,d) \cap (S \setmi
nus \{\beta\})$. If $s = \beta \in S$, then (since $S$ is infinite and $\sup S =
 \beta$) there must be elements of $S$ arbitrarily close to $\beta$ from below,
so again some $s' \in S \setminus \{\beta\}$ lies in $(c, d)$. Thus $X$ is count
ably compact.

Since $f$ is continuous, $f(X)$ is a countably compact subset of $\mathbb{R}$. I
n metric spaces, countably compact equals compact, so $f(X)$ is compact, hence *
*bounded**.

**Step 2: For every $\varepsilon > 0$, the oscillation of $f$ on some tail $[\al
pha, \Omega)$ is less than $\varepsilon$.**

Suppose for contradiction that some $\varepsilon > 0$ has the property: for ever
y countable ordinal $\alpha$, there exist $\beta, \gamma \in [\alpha, \Omega)$ w
ith $|f(\beta) - f(\gamma)| \geq \varepsilon$.

Construct sequences inductively. Set $\alpha_0 = 0$. Given $\alpha_n$, choose $\
beta_n, \gamma_n \in [\alpha_n, \Omega)$ with $|f(\beta_n) - f(\gamma_n)| \geq \
varepsilon$, and set $\alpha_{n+1} = \max(\beta_n, \gamma_n) + 1$ (a countable o
rdinal). Then $(\alpha_n)$ is strictly increasing.

Let $\alpha^* = \sup_n \alpha_n = \sup_n \{\alpha_n, \beta_n, \gamma_n\}$. This
is a countable ordinal (countable supremum of countable ordinals), so $\alpha^*
\in X$. Since $(\alpha_n)$ is strictly increasing with supremum $\alpha^*$, the
ordinal $\alpha^*$ is a **limit ordinal**.

By continuity of $f$ at $\alpha^*$, there exist $c < \alpha^* < d$ such that $|f
(x) - f(\alpha^*)| < \varepsilon/4$ for all $x \in (c, d)$.

For sufficiently large $n$, we have $\alpha_n > c$ (since $\alpha_n \to \alpha^*
 > c$). For such $n$:
- $\beta_n, \gamma_n \geq \alpha_n > c$,
- $\beta_n, \gamma_n \leq \alpha^* < d$,

so $\beta_n, \gamma_n \in (c, d)$. Then $|f(\beta_n) - f(\gamma_n)| \leq |f(\bet
a_n) - f(\alpha^*)| + |f(\alpha^*) - f(\gamma_n)| < \varepsilon/4 + \varepsilon/
4 = \varepsilon/2 < \varepsilon$, contradicting the choice of $\beta_n, \gamma_n
$. $\square$

**Step 3: $f$ is constant on a tail.**

Apply Step 2 with $\varepsilon = 1/k$ for each $k = 1, 2, 3, \ldots$, obtaining
countable ordinals $\alpha_k$ such that the oscillation of $f$ on $[\alpha_k, \O
mega)$ is less than $1/k$.

Set $\alpha = \sup_k \alpha_k$, a countable ordinal. Since $\alpha \geq \alpha_k
$ for every $k$, the interval $[\alpha, \Omega) \subseteq [\alpha_k, \Omega)$ fo
r every $k$. Therefore, for all $x, y \in [\alpha, \Omega)$ and all $k$:
$$|f(x) - f(y)| < \frac{1}{k}.$$
Letting $k \to \infty$ gives $f(x) = f(y)$ for all $x, y \in [\alpha, \Omega)$.
Thus $f$ is constant on $[\alpha, \Omega)$, and in particular on $(\alpha, \Omeg
a)$, where $\alpha$ is a countable ordinal. $\blacksquare$
