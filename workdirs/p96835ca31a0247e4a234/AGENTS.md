# Problem

In a specialized logistics network, three delivery depots are assigned ID numbers represented by natural numbers $a$, $b$, and $c$. The central hub calculates a "Network Efficiency Index" ($k$) using the formula:

$$k = \frac{ab + c^2}{a + b}$$

The system is configured such that this index $k$ results in a natural number. Furthermore, for the network to remain stable, the value of $k$ must be strictly less than both ID number $a$ and ID number $b$.

Based on these operational constraints, what is the minimum possible number of natural divisors that the sum of the depot IDs, $a+b$, can possess?
