**答案：否。** 该命题不成立。我通过一个明确的反例进行证明，其中所有三个 $a_i$ 均
为无理数，且域次数为 4（不能被 3 整除）。

**构造。** 设 $\omega_3 := \sqrt{-3}$，并取
$$a_1 = \sqrt{2},\qquad a_2 = -\sqrt{2},\qquad a_3 = 1 + \sqrt{-3}.$$

**步骤 1：所有 $a_i$ 均为无理数。** 显然 $\sqrt{2}\notin\mathbb{Q}$ 且 $-\sqrt{2
}\notin\mathbb{Q}$。对于 $a_3$：若 $1+\sqrt{-3}\in\mathbb{Q}$，则 $\sqrt{-3}\in\
mathbb{Q}$，矛盾。故所有三个数均为无理数，满足“并非所有 $a_i$ 都是有理数”的条件
。

**步骤 2：三次方之和是有理数。** 计算：
$$a_1^3 + a_2^3 = (\sqrt{2})^3 + (-\sqrt{2})^3 = 2\sqrt{2} - 2\sqrt{2} = 0.$$
对于 $a_3$，利用 $(1+\sqrt{-3})^2 = 1 + 2\sqrt{-3} - 3 = -2 + 2\sqrt{-3}$，因此
$$(1+\sqrt{-3})^3 = (1+\sqrt{-3})(-2+2\sqrt{-3}) = -2 + 2\sqrt{-3} - 2\sqrt{-3}
+ 2(-3) = -2 - 6 = -8.$$
因此
$$a_1^3 + a_2^3 + a_3^3 = 0 + (-8) = -8 \in \mathbb{Q}.$$

**步骤 3：域次数为 4，不能被 3 整除。** 我们有
$$\mathbb{Q}(a_1,a_2,a_3) = \mathbb{Q}(\sqrt{2},\, -\sqrt{2},\, 1+\sqrt{-3}) = \
mathbb{Q}(\sqrt{2},\, \sqrt{-3}).$$

现在 $\sqrt{2}$ 在 $\mathbb{Q}$ 上的次数为 2（不可约多项式 $x^2-2$）。由于 $\mat
hbb{Q}(\sqrt{2})\subset\mathbb{R}$ 而 $\sqrt{-3}\notin\mathbb{R}$，我们有 $\sqrt
{-3}\notin\mathbb{Q}(\sqrt{2})$，因此 $x^2+3$ 在 $\mathbb{Q}(\sqrt{2})$ 上仍然不
可约。从而
$$[\mathbb{Q}(\sqrt{2},\sqrt{-3}):\mathbb{Q}] = [\mathbb{Q}(\sqrt{2},\sqrt{-3}):
\mathbb{Q}(\sqrt{2})]\cdot[\mathbb{Q}(\sqrt{2}):\mathbb{Q}] = 2\cdot 2 = 4.$$

**步骤 4：结论。** 我们构造了代数数 $a_1,a_2,a_3$，它们均不为有理数，满足 $a_1^3
+a_2^3+a_3^3 = -8\in\mathbb{Q}$，但 $[\mathbb{Q}(a_1,a_2,a_3):\mathbb{Q}] = 4$，
**不能**被 3 整除。

因此该命题为**假**：$\sum a_i^3\in\mathbb{Q}$ 且并非所有 $a_i$ 为有理数，**并不
能**推导出 $[\mathbb{Q}(a_1,a_2,a_3):\mathbb{Q}]$ 能被 3 整除。
