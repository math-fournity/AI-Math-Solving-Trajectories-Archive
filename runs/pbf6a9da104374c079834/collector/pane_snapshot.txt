## Proof

**Setup.** $P = I - 2uu^T$ is a Householder reflection: it is symmetric ($P^T =
P$), orthogonal, and satisfies $P^2 = I$, so $P^{-1} = P$. Its eigenvalues are $
-1$ (eigenvector $u$) and $1$ (multiplicity $n-1$, on $u^\perp$), hence $\det(P)
 = -1$.

We prove $\det(PQ - I) = 0$, which is equivalent to $1$ being an eigenvalue of $
PQ$.

**Step 1: Reduce to a determinant involving $Q - P$.**

Since $P^{-1} = P$,
$$PQ - I = P(Q - P^{-1}) = P(Q - P),$$
so
$$\det(PQ - I) = \det(P)\det(Q - P) = -\det(Q - P). \tag{1}$$

**Step 2: Apply the matrix determinant lemma.**

Write $Q - P = (Q - I) + 2uu^T$. Set $A := Q - I$. Since $1$ is **not** an eigen
value of $Q$, $A$ is invertible. By the matrix determinant lemma,
$$\det(A + 2uu^T) = \det(A)\bigl(1 + 2\,u^T A^{-1} u\bigr).$$
Thus
$$\det(Q - P) = \det(Q - I)\Bigl(1 + 2\,u^T(Q - I)^{-1}u\Bigr). \tag{2}$$

**Step 3: A key identity for orthogonal $Q$.**

**Claim.** If $Q$ is orthogonal and $1$ is not an eigenvalue of $Q$, then
$$(Q - I)^{-1} + (Q - I)^{-T} = -I.$$

*Proof of claim.* Since $Q^{-1} = Q^T$, we have $(Q - I)^T = Q^T - I = Q^{-1} -
I$, so $(Q - I)^{-T} = (Q^{-1} - I)^{-1}$. Now
$$Q^{-1} - I = Q^{-1}(I - Q) = -Q^{-1}(Q - I),$$
hence
$$(Q^{-1} - I)^{-1} = -(Q - I)^{-1}Q.$$
Therefore
$$(Q - I)^{-1} + (Q - I)^{-T} = (Q - I)^{-1} - (Q - I)^{-1}Q = (Q - I)^{-1}(I -
Q) = -(Q - I)^{-1}(Q - I) = -I. \qquad\checkmark$$

**Step 4: Evaluate the quadratic form.**

For any real matrix $M$ and vector $u$, the skew-symmetric part of $M$ contribut
es nothing to $u^T M u$, so $u^T M u = u^T\!\left(\frac{M + M^T}{2}\right)u$. Ap
plying this with $M = (Q - I)^{-1}$ and using the claim:
$$u^T(Q - I)^{-1}u = u^T\!\left(\frac{(Q - I)^{-1} + (Q - I)^{-T}}{2}\right)u =
u^T\!\left(\frac{-I}{2}\right)u = -\frac{1}{2}\,u^T u = -\frac{1}{2},$$
since $u$ is a unit vector.

**Step 5: Conclude.**

Substituting into (2):
$$\det(Q - P) = \det(Q - I)\Bigl(1 + 2\!\left(-\tfrac{1}{2}\right)\Bigr) = \det(
Q - I)\cdot 0 = 0.$$

By (1), $\det(PQ - I) = -\det(Q - P) = 0$. Hence $PQ - I$ is singular: there exi
sts a nonzero $v \in \mathbb{R}^n$ with $PQv = v$. Therefore $1$ is an eigenvalu
e of $PQ$. $\blacksquare$
