## Solution

We consider the two Borel measures

$$\mu(A)=\sum_{n=1}^{\infty}\frac{1}{2^n}\,\lambda\big((n,2n)\cap A\big),\qquad
\nu(A)=\sum_{n=1}^{\infty}\frac{1}{3^n}\,\lambda\big((n,\tfrac32 n)\cap A\big).$
$

Both are σ-finite Borel measures, absolutely continuous with respect to Lebesgue
 measure λ. We investigate μ ≪ ν and ν ≪ μ.

### Step 1. ν ≪ μ

Observe that for every n ≥ 1,

$$(n,\tfrac32 n)\subset (n,2n),$$

since 3n/2 < 2n. Suppose μ(A) = 0. Since every summand is non-negative,

$$\frac{1}{2^n}\lambda\big((n,2n)\cap A\big)=0\quad\Longrightarrow\quad \lambda\
big((n,2n)\cap A\big)=0\quad\text{for all }n.$$

Because $(n,\tfrac32 n)\subset(n,2n)$,

$$\lambda\big((n,\tfrac32 n)\cap A\big)\le \lambda\big((n,2n)\cap A\big)=0,$$

so every summand of ν(A) vanishes, giving ν(A) = 0. Hence **ν ≪ μ**.

### Step 2. μ is not ≪ ν

Consider the set $A=(\tfrac32,2)$. For n = 1, the interval $(1,\tfrac32)$ is ope
n and does not contain 3/2, so $A\cap(1,\tfrac32)=\varnothing$. For n ≥ 2, $(n,\
tfrac32 n)\subset(n,\infty)\subset[2,\infty)$, which is disjoint from $(\tfrac32
,2)$. Therefore

$$\nu(A)=\sum_{n=1}^{\infty}\frac{1}{3^n}\lambda\big((n,\tfrac32 n)\cap(\tfrac32
,2)\big)=0.$$

On the other hand, $(\tfrac32,2)\subset(1,2)$, so

$$\mu(A)\ge \frac{1}{2^1}\lambda\big((1,2)\cap(\tfrac32,2)\big)=\frac12\cdot\fra
c12=\frac14>0.$$

Thus ν(A)=0 but μ(A)>0, so **μ is not absolutely continuous with respect to ν**.

### Step 3. The Radon–Nikodym derivative dν/dμ

Both μ and ν are absolutely continuous with respect to λ, with densities (define
d λ-a.e.)

$$f(x)=\frac{d\mu}{d\lambda}(x)=\sum_{\{n\,:\,x\in(n,2n)\}}\frac{1}{2^n},\qquad
g(x)=\frac{d\nu}{d\lambda}(x)=\sum_{\{n\,:\,x\in(n,\frac32 n)\}}\frac{1}{3^n}.$$

(The sums are over all n with x in the indicated interval; since the intervals o
verlap, these are genuine finite sums — at most finitely many n satisfy n < x <
2n, namely n ∈ (x/2, x), a bounded interval.)

Since ν ≪ μ and both ≪ λ, by the chain rule for Radon–Nikodym derivatives,

$$\frac{d\nu}{d\mu}(x)=\frac{d\nu/d\lambda}{d\mu/d\lambda}(x)=\frac{g(x)}{f(x)}\
quad\mu\text{-a.e.},$$

where the ratio is well-defined μ-a.e. because f > 0 on the support $\bigcup_n(n
,2n)$ of μ (which is exactly where μ concentrates its mass).

**Explicitly:**

$$\boxed{\frac{d\nu}{d\mu}(x)=\frac{\displaystyle\sum_{\{n\,:\,x\in(n,\frac32 n)
\}}\frac{1}{3^n}}{\displaystyle\sum_{\{n\,:\,x\in(n,2n)\}}\frac{1}{2^n}}\quad\te
xt{for }x\in\bigcup_{n=1}^{\infty}(n,2n),\ \mu\text{-a.e.}}$$

### Summary

- **ν ≪ μ**: yes, with derivative $\dfrac{d\nu}{d\mu}=\dfrac{g}{f}$ as above.
- **μ ≪ ν**: no. The measure μ charges the region $\bigcup_n(\tfrac32 n,2n)$, on
 which ν vanishes identically, so μ has a singular part with respect to ν.
