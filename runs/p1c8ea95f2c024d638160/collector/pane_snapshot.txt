## Solution

Let $E_k$ denote the expected number of additional days needed when $k$ saplings
 still remain (not yet trees). We want $E_6$. Clearly $E_0 = 0$.

**Recurrence.** On a given day, each of the $k$ remaining saplings independently
 succeeds with probability $\tfrac{1}{2}$, so the number that succeed is $\opera
torname{Binomial}(k,\tfrac12)$. Conditioning on the number $j$ of saplings that
succeed that day (probability $\binom{k}{j}/2^k$), and adding one day:

$$E_k = 1 + \sum_{j=0}^{k}\frac{\binom{k}{j}}{2^k}\,E_{k-j}.$$

The $j=0$ term contributes $\frac{1}{2^k}E_k$ (no progress), and the $j=k$ term
contributes $E_0=0$. Solving for $E_k$:

$$E_k\!\left(1-\frac{1}{2^k}\right) = 1 + \sum_{j=1}^{k-1}\frac{\binom{k}{j}}{2^
k}\,E_{k-j},$$

$$E_k = \frac{2^k + \sum_{j=1}^{k-1}\binom{k}{j}\,E_{k-j}}{2^k - 1}.$$

**Computing the values.**

- $k=1$: $\displaystyle E_1 = \frac{2}{2-1} = 2.$ (Consistent with a geometric r
.v. with $p=\tfrac12$.)

- $k=2$: $\displaystyle E_2 = \frac{4 + 2\cdot 2}{3} = \frac{8}{3}.$

- $k=3$: $\displaystyle E_3 = \frac{8 + 3\cdot\frac{8}{3} + 3\cdot 2}{7} = \frac
{8+8+6}{7} = \frac{22}{7}.$

- $k=4$: $\displaystyle E_4 = \frac{16 + 4\cdot\frac{22}{7} + 6\cdot\frac{8}{3}
+ 4\cdot 2}{15} = \frac{16 + \frac{88}{7} + 16 + 8}{15} = \frac{40 + \frac{88}{7
}}{15} = \frac{\frac{368}{7}}{15} = \frac{368}{105}.$

- $k=5$:
$$E_5 = \frac{32 + 5\cdot\frac{368}{105} + 10\cdot\frac{22}{7} + 10\cdot\frac{8}
{3} + 5\cdot 2}{31}.$$
Numerator $= 32 + \frac{368}{21} + \frac{220}{7} + \frac{80}{3} + 10 = 42 + \fra
c{368}{21} + \frac{660}{21} + \frac{560}{21} = \frac{882+368+660+560}{21} = \fra
c{2470}{21}.$
$$E_5 = \frac{2470/21}{31} = \frac{2470}{651}.$$

- $k=6$:
$$E_6 = \frac{64 + 6\cdot\frac{2470}{651} + 15\cdot\frac{368}{105} + 20\cdot\fra
c{22}{7} + 15\cdot\frac{8}{3} + 6\cdot 2}{63}.$$
Simplifying each term:
- $6\cdot\frac{2470}{651} = \frac{4940}{217},$
- $15\cdot\frac{368}{105} = \frac{368}{7},$
- $20\cdot\frac{22}{7} = \frac{440}{7},$
- $15\cdot\frac{8}{3} = 40,$
- $6\cdot 2 = 12.$

Numerator $= 64 + \frac{4940}{217} + \frac{368}{7} + \frac{440}{7} + 40 + 12 = 1
16 + \frac{4940}{217} + \frac{808}{7}.$

Converting to denominator $217$ (using $217 = 7\cdot 31$):
$$116 = \frac{25172}{217},\qquad \frac{808}{7} = \frac{25048}{217}.$$
$$\text{Numerator} = \frac{25172 + 4940 + 25048}{217} = \frac{55160}{217}.$$

Therefore
$$E_6 = \frac{55160/217}{63} = \frac{55160}{13671}.$$

**Reduction.** Factor: $13671 = 217\cdot 63 = (7\cdot 31)(9\cdot 7) = 3^2\cdot 7
^2\cdot 31$, and $55160 = 2^3\cdot 5\cdot 7\cdot 197$. The common factor is $7$:
$$E_6 = \frac{55160\div 7}{13671\div 7} = \frac{7880}{1953}.$$
Now $7880 = 2^3\cdot 5\cdot 197$ and $1953 = 3^2\cdot 7\cdot 31$ share no common
 factor, so $\gcd(7880,1953)=1$.

Thus $m = 7880$ and $n = 1953$, and
$$100m + n = 100\cdot 7880 + 1953 = 788000 + 1953 = \boxed{789953}.$$
