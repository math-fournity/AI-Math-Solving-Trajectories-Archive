## Setting up the formula for f(n)

For each k ∈ {1,...,n-1}, write k/n in lowest terms. If d = gcd(k,n), the simpli
fied fraction is (k/d)/(n/d), with numerator k/d.

Grouping by d = gcd(k,n): the values k with gcd(k,n)=d are k = d·m where 1 ≤ m ≤
 n/d−1 and gcd(m, n/d)=1. The numerator is m. Setting q = n/d (ranging over divi
sors of n with q > 1):

$$f(n) = \sum_{\substack{q \mid n \\ q > 1}} \sum_{\substack{1 \le m \le q-1 \\
\gcd(m,q)=1}} m.$$

The inner sum equals q·φ(q)/2 for q > 1. So:

$$f(n) = \tfrac{1}{2}\sum_{\substack{q \mid n \\ q>1}} q\,\varphi(q).$$

**Verification:** n=6: q∈{2,3,6}, gives (2·1+3·2+6·2)/2 = (2+6+12)/2 = 10. Direc

Define $g(n) = \sum_{q \mid n} q\,\varphi(q)$ (multiplicative, since $q\varphi(q
)$ is multiplicative). Then $f(n) = (g(n)-1)/2$.

## Parity of f(n)

f(n) is odd ⟺ (g(n)−1)/2 is odd ⟺ g(n) ≡ 3 (mod 4).

**Computing g(p^a) mod 4:**

$$g(p^a) = 1 + \sum_{j=1}^{a} p^{2j-1}(p-1).$$

- **p = 2:** Each term 2^{2j−1}·1. For j=1: 2; for j≥2: divisible by 8. So g(2^a

- **p ≡ 1 (mod 4):** (p−1) ≡ 0 (mod 4), so every term ≡ 0. Thus g(p^a) ≡ **1 (mo
d 4)** for all a.

- **p ≡ 3 (mod 4):** (p−1) ≡ 2, p^{2j−1} ≡ 3 (mod 4). Each term ≡ 6 ≡ 2 (mod 4).
 So g(p^a) ≡ 1 + 2a (mod 4), which is **3 (mod 4) iff a is odd**.

Since g is multiplicative, g(n) mod 4 is the product of contributions from each
prime power. Each contribution is either 1 or 3 (mod 4). The product is 3 (mod 4

Define the **count**:
$$\text{count}(n) = \mathbb{1}[2 \mid n] + \sum_{\substack{q \equiv 3 \pmod{4} \
\ q \text{ prime}}} \mathbb{1}[q \mid n \text{ to odd power}] \pmod{2}.$$

Then **g(n) ≡ 3 (mod 4) iff count(n) is odd**, i.e., **f(n) is odd iff count(n)
is odd**.

## Effect of multiplying by 2015

$$\text{count}(2015n) \equiv \text{count}(n) + 1 \pmod{2}.$$
