Looking at this problem, I need to find the smallest ε > 0 such that for every n
 (≥ 2), there is always a prime in the interval [n, (1+ε)n].

**Answer: ε = 2/3**

## Proof

**Step 1: ε = 2/3 is necessary.**

Take n = 3. The smallest prime greater than 3 is 5. For 5 to lie in [3, 3(1+ε)],
 we need 3(1+ε) ≥ 5, i.e., ε ≥ 2/3. So no ε < 2/3 can work universally.

**Step 2: ε = 2/3 is sufficient — reduce to consecutive prime ratios.**

For any integer n ≥ 2, let p be the largest prime ≤ n, and let q be the next pri
me after p (equivalently, the smallest prime > n, since there is no prime in (p,
 q)). Then:
- If n = p: the next prime is q, and we need q ≤ (5/3)n = (5/3)p.
- If p < n < q: the next prime is q, and q/n < q/p ≤ 5/3, so q < (5/3)n.

Thus it suffices to prove: **for every prime p ≥ 2, the next prime q satisfies q
 ≤ (5/3)p**, with equality only at p = 3.

**Step 3: Verify for small primes (p < 25).**

| p | q | q/p | ≤ 5/3? |
|---|---|-----|--------|
| 2 | 3 | 1.500 | ✓ |
| 3 | 5 | 1.667 = 5/3 | ✓ (equality) |
| 5 | 7 | 1.400 | ✓ |
| 7 | 11 | 1.571 | ✓ |
| 11 | 13 | 1.182 | ✓ |
| 13 | 17 | 1.308 | ✓ |
| 17 | 19 | 1.118 | ✓ |

| 23 | 29 | 1.261 | ✓ |

All satisfy q ≤ (5/3)p, with equality only at p = 3.

**Step 4: Verify for large primes (p ≥ 25) using Nagura's theorem.**

Nagura (1952) proved that for every real x ≥ 25, there exists a prime in the int
erval (x, 1.2x).

For any prime p ≥ 25, applying Nagura's theorem with x = p, there exists a prime
 r with p < r < 1.2p. The next prime q after p satisfies q ≤ r < 1.2p. Since 1.2
 = 6/5 < 5/3, we have:

q < (6/5)p < (5/3)p. ✓

**Step 5: Conclusion.**

Combining Steps 3 and 4, for every prime p ≥ 2, the next prime q satisfies q ≤ (
5/3)p, with equality only at p = 3. By the reduction in Step 2, for every intege
r n ≥ 2, there exists a prime in [n, (5/3)n] = [n, (1 + 2/3)n].

By Step 1, no smaller ε works (n = 3 is a witness).

Therefore, the smallest value is **ε = 2/3**.
