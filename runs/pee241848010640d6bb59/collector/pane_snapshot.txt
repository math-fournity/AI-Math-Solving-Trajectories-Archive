## Solution

**Claim.** The only analytic functions on the unit disk $\mathbb{D}$ whose real
part is itself analytic on $\mathbb{D}$ are the **real constant** functions.

---

### Proof

Let $f : \mathbb{D} \to \mathbb{C}$ be analytic, and write $f(z) = u(z) + i\,v(z
)$, where $u = \operatorname{Re} f$ and $v = \operatorname{Im} f$ are real-value
d functions on $\mathbb{D}$.

**Step 1. $u$ is real-valued.** By definition, the real part of any complex-valu
ed function is real-valued: $u(z) \in \mathbb{R}$ for every $z \in \mathbb{D}$.

**Step 2. A real-valued analytic function is constant.** Suppose $u$ is analytic
 on $\mathbb{D}$. Since $u$ is real-valued, its image $u(\mathbb{D}) \subseteq \
mathbb{R}$. The set $\mathbb{R}$ has empty interior in $\mathbb{C}$ (it is not o
pen). By the **Open Mapping Theorem**, a non-constant analytic function maps ope
n sets to open sets. Since $\mathbb{D}$ is open but $u(\mathbb{D}) \subseteq \ma
thbb{R}$ is not open in $\mathbb{C}$, $u$ cannot be non-constant. Hence $u$ is c
onstant.

*(Alternative argument without the Open Mapping Theorem:)* Since $u$ is real-val
ued and analytic, the Cauchy–Riemann equations give $u_x = 0$ and $u_y = 0$ ever
ywhere (because $u$ is real-valued, $\operatorname{Im} u = 0$, so the Cauchy–Rie
mann equations for $u$ read $u_x = (\operatorname{Im} u)_y = 0$ and $u_y = -(\op
eratorname{Im} u)_x = 0$). Thus all partial derivatives vanish and $u$ is consta
nt on the connected domain $\mathbb{D}$.

**Step 3. $f$ is constant.** Now $u \equiv c$ for some real constant $c$, so $f(
z) = c + i\,v(z)$. Since $f$ is analytic, the Cauchy–Riemann equations hold:
$$u_x = v_y, \qquad u_y = -v_x.$$
Since $u$ is constant, $u_x = u_y = 0$, giving $v_x = v_y = 0$ on $\mathbb{D}$.
As $\mathbb{D}$ is connected, $v$ is constant: $v \equiv d$ for some real consta
nt $d$. Therefore
$$f(z) = c + i\,d$$
is a constant. But we also need $u = \operatorname{Re} f = c$ to be analytic, wh
ich it is (every constant function is analytic). Moreover, $c + id$ must be such
 that $\operatorname{Re}(c+id) = c$ is analytic — this is automatic.

**Step 4. Verification.** Conversely, if $f(z) \equiv a$ for any constant $a \in
 \mathbb{C}$, then $\operatorname{Re} f \equiv \operatorname{Re} a$, which is a
(real) constant function and hence analytic. So every constant function satisfie
s the condition.

**Conclusion.** Combining Steps 2–3 (necessity) and Step 4 (sufficiency), the an
alytic functions on $\mathbb{D}$ whose real part is analytic on $\mathbb{D}$ are
 exactly the **constant functions** $f(z) \equiv a$, $a \in \mathbb{C}$.
