## Proof

**Claim.** For all $n \geq 1$, $\displaystyle f_n(x) = x(x+n)^{n-1}$.

**Base case ($n=1$).** From the recurrence with $n=0$: $f_1'(x) = 1\cdot f_0(x+1
) = 1$. Together with $f_1(0)=0$, this gives $f_1(x) = x = x(x+1)^0$. ✓

**Inductive step.** Suppose $f_n(x) = x(x+n)^{n-1}$ for some $n \geq 1$. The rec
urrence gives
$$f_{n+1}'(x) = (n+1)\,f_n(x+1) = (n+1)(x+1)(x+n+1)^{n-1}.$$
Using $f_{n+1}(0)=0$,
$$f_{n+1}(x) = (n+1)\int_0^x (t+1)(t+n+1)^{n-1}\,dt.$$
Substitute $u = t+n+1$, so $t+1 = u-n$ and $dt = du$; the limits run from $u=n+1
$ to $u=x+n+1$:
$$(n+1)\int_{n+1}^{x+n+1} (u-n)\,u^{n-1}\,du = (n+1)\int_{n+1}^{x+n+1}\!\bigl(u^
n - n\,u^{n-1}\bigr)\,du.$$
An antiderivative of $u^n - n\,u^{n-1}$ is $\dfrac{u^{n+1}}{n+1} - u^n = u^n\!\l
eft(\dfrac{u}{n+1}-1\right) = \dfrac{u^n(u-n-1)}{n+1}$. Multiplying by $(n+1)$,
the antiderivative becomes $u^n(u-n-1)$. Since $u-n-1 = t$, this equals $t\,(t+n
+1)^n$, which vanishes at $t=0$. Hence
$$f_{n+1}(x) = x\,(x+n+1)^n,$$
completing the induction. $\square$

**Applying to $f_{100}(1)$.** With $n=100$ and $x=1$:
$$f_{100}(1) = 1\cdot(1+100)^{99} = 101^{99}.$$

Since $101$ is prime, the explicit factorization of $f_{100}(1)$ into powers of
distinct primes is

$$\boxed{f_{100}(1) = 101^{99}}.$$
