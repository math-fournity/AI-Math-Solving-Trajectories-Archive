## Setup and Reformulation

For each pair $\{a_i, b_i\}$, let $m_i = \max(a_i, b_i)$. Since pairs are unorde
red, we may assume $a_i \le b_i$, so $m_i = b_i$. The pairs $(a_i, b_i)$ with $1
 \le a_i \le b_i$ are distinct lattice points.

Let $N_k = \#\{i : m_i = k\}$. Since there are exactly $k$ unordered pairs with
maximum $k$ (namely $\{1,k\}, \{2,k\}, \ldots, \{k,k\}$), we have the constraint
 $N_k \le k$. We seek to minimize
$$S = \sum_{i=1}^n m_i = \sum_k k \cdot N_k \quad \text{subject to} \quad \sum_k
 N_k = n,\; 0 \le N_k \le k.$$

## Finding the Minimum $S$

The minimum is achieved greedily: fill $N_k = k$ for $k = 1, \ldots, m-1$, then
$N_m = n - T(m-1)$, where $T(j) = j(j+1)/2$ and $m$ is determined by $T(m-1) < n
 \le T(m)$.

Setting $n = T(m-1) + r$ with $1 \le r \le m$, the minimum is:
$$f(n) = \sum_{k=1}^{m-1} k^2 + m \cdot r = \frac{(m-1)m(2m-1)}{6} + mr.$$

## Proving $f(n) \ge \frac{2\sqrt{2}}{3}\, n^{3/2}$

On each interval $(T(m-1), T(m)]$, $f(n) = mn - \frac{m(m^2-1)}{6}$ is linear in
 $n$. Define $h(n) = f(n) - \frac{2\sqrt{2}}{3}n^{3/2}$. Since $h''(n) = -\frac{
\sqrt{2}}{2}n^{-1/2} < 0$, **$h$ is concave** on each interval, so its minimum i
s at an endpoint. We check both endpoints:

**Right endpoint** $n = T(m) = m(m+1)/2$: Here $f = m(m+1)(2m+1)/6$ and
$$h(T(m)) \ge 0 \iff \frac{m(m+1)(2m+1)}{6} \ge \frac{2\sqrt{2}}{3}\left(\frac{m
(m+1)}{2}\right)^{3/2}.$$
Dividing by $m(m+1)$ and simplifying, this reduces to $\frac{2m+1}{2} \ge \sqrt{
m(m+1)}$, i.e., $(2m+1)^2 \ge 4m(m+1)$, i.e., $4m^2+4m+1 \ge 4m^2+4m$. **True**
(strict, by $1 > 0$). ✓

**Left endpoint** $n = T(m-1)+1 = (m-1)m/2 + 1$ (for $m \ge 2$): Here $f = m(2m^
2-3m+7)/6$ and we need
$$\frac{m(2m^2-3m+7)}{6} \ge \frac{2\sqrt{2}}{3}\left(\frac{m^2-m+2}{2}\right)^{
3/2} = \frac{(m^2-m+2)^{3/2}}{3}.$$
Squaring (both sides positive): $m^2(2m^2-3m+7)^2 \ge 4(m^2-m+2)^3$. Expanding b
oth sides:
- LHS $= 4m^6 - 12m^5 + 37m^4 - 42m^3 + 49m^2$
- RHS $= 4m^6 - 12m^5 + 36m^4 - 52m^3 + 72m^2 - 48m + 32$
- **LHS $-$ RHS** $= m^4 + 10m^3 - 23m^2 + 48m - 32$.

At $m=2$: $16+80-92+96-32 = 68 > 0$. The derivative $4m^3+30m^2-46m+48$ is posit
ive for $m \ge 2$ (at $m=2$ it equals $108 > 0$, and $4m^3$ dominates), so the e
xpression is increasing and positive for all $m \ge 2$. ✓

For $m=1$: $n=1$, $f(1)=1$, $h(1) = 1 - 2\sqrt{2}/3 > 0$. ✓

By concavity, $h(n) \ge 0$ throughout each interval, so **$f(n) \ge \frac{2\sqrt
{2}}{3}\,n^{3/2}$ for all $n \ge 1$**.

## Sharpness: No Larger $C$ Works

For $n = T(m) = m(m+1)/2$, the ratio is:
$$\frac{f(n)}{n^{3/2}} = \frac{\sqrt{2}}{3} \cdot \frac{2m+1}{\sqrt{m(m+1)}} \xr
ightarrow{m \to \infty} \frac{\sqrt{2}}{3} \cdot 2 = \frac{2\sqrt{2}}{3}.$$

Since $(2m+1)^2 = 4m^2+4m+1 > 4m(m+1)$, the ratio is **strictly greater** than $
2\sqrt{2}/3$ for every finite $m$, but approaches it. Therefore:
- $C = 2\sqrt{2}/3$ works (the inequality holds for all $n$), and
- any $C > 2\sqrt{2}/3$ fails for sufficiently large $m$.

## Conclusion
