## Proof

We have $S_n = \sum_{k=1}^n \xi_k$ with $\xi_k \stackrel{\text{iid}}{\sim} N(0,1
)$, so $S_n \sim N(0,n)$. Define
$$X_n = e^{aS_n - bn^2}.$$
Since $X_n > 0$ a.s., $\mathcal{L}^r$-convergence to $0$ is equivalent to
$$\mathbb{E}[X_n^r] \to 0 \quad \text{as } n\to\infty.$$

**Computing the $r$-th moment.**

$$\mathbb{E}[X_n^r] = \mathbb{E}\!\left[e^{raS_n - rbn^2}\right] = e^{-rbn^2}\,\
mathbb{E}\!\left[e^{raS_n}\right].$$

Since $S_n \sim N(0,n)$, its moment generating function gives
$$\mathbb{E}\!\left[e^{tS_n}\right] = e^{t^2 n/2}.$$

Setting $t = ra$:
$$\mathbb{E}\!\left[e^{raS_n}\right] = e^{r^2 a^2 n/2}.$$

Therefore
$$\mathbb{E}[X_n^r] = \exp\!\left(-rbn^2 + \tfrac{r^2 a^2}{2}\,n\right).$$

**Analyzing the exponent.** Let
$$\varphi(n) = -rb\,n^2 + \frac{r^2 a^2}{2}\,n.$$

- **Case $b > 0$:** The leading term $-rb\,n^2$ (quadratic, negative coefficient
) dominates the linear term $\frac{r^2 a^2}{2}n$. Hence $\varphi(n) \to -\infty$
, so $\mathbb{E}[X_n^r] \to 0$. This holds for **every** $a \in \mathbb{R}$ and
**every** $r > 0$ (in particular for all $r \geq 1$).

- **Case $b = 0$:** Then $\varphi(n) = \frac{r^2 a^2}{2}n$.
  - If $a \neq 0$: $\varphi(n) \to +\infty$, so $\mathbb{E}[X_n^r] \to +\infty$.
  - If $a = 0$: $\mathbb{E}[X_n^r] = 1$ for all $n$, which does not converge to
$0$.

  In either subcase, $\mathcal{L}^r$-convergence to $0$ fails.

- **Case $b < 0$:** Then $-rb > 0$, so $-rb\,n^2 \to +\infty$ and $\varphi(n) \t
o +\infty$, giving $\mathbb{E}[X_n^r] \to +\infty$. Convergence to $0$ fails.

**Conclusion.** The sequence $X_n = e^{aS_n - bn^2}$ converges to $0$ in $\mathc
al{L}^r$ for every $r \geq 1$ **if and only if**
$$\boxed{b > 0}$$
with $a \in \mathbb{R}$ arbitrary.
