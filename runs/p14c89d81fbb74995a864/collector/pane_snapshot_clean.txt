## Proof

We show that such a unitary $U$ exists **if and only if $n \geq 2$**, and we giv
e an explicit construction together with a complete characterization.

---

### Construction for $n \geq 2$

Let $P \in M_n(\mathbb{C})$ be the permutation matrix of the transposition $(1\;
2)$:

$$P = E_{12} + E_{21} + \sum_{i=3}^{n} E_{ii}.$$

**$P$ is unitary.** Since $P$ permutes the standard basis, $P^* = P^{-1} = P$, s
o $PP^* = I$.

**$P \notin D_n$.** The entry $P_{12} = 1 \neq 0$ is off the diagonal, so $P$ is
 not a diagonal matrix.

**$P\,D_n\,P^* = D_n$.** For any diagonal $D = \operatorname{diag}(d_1, d_2, \do
ts, d_n)$, conjugation by $P$ permutes the diagonal entries:

$$PDP^* = \operatorname{diag}(d_2, d_1, d_3, \dots, d_n),$$

which is again diagonal. Hence $P\,D_n\,P^* \subseteq D_n$. Since the map $X \ma
psto PXP^*$ is a linear bijection on $M_n(\mathbb{C})$ and $\dim D_n = n = \dim(
P\,D_n\,P^*)$, the inclusion is an equality:

$$P\,D_n\,P^* = D_n.$$

Thus $U = P$ is a unitary matrix not in $D_n$ satisfying $U\,D_n\,U^* = D_n$. $\
checkmark$

---

### Necessity of $n \geq 2$

For $n = 1$, we have $D_1 = M_1(\mathbb{C})$, so every element of $M_1(\mathbb{C
})$ is diagonal. There is no $U \in M_1(\mathbb{C})$ with $U \notin D_1$, so no
such $U$ exists.

---

### Complete characterization (all solutions)

We show that the unitary matrices $U$ with $U\,D_n\,U^* \subseteq D_n$ are **exa
ctly the monomial unitary matrices** $U = D_\lambda P_\sigma$ (diagonal unitary
times permutation matrix).

**Monomial $\Rightarrow$ preserves $D_n$.** If $U = D_\lambda P_\sigma$ with $D_
\lambda = \operatorname{diag}(\lambda_1,\dots,\lambda_n)$, $|\lambda_i|=1$, and
$P_\sigma$ a permutation matrix, then for diagonal $D$:

$$UDU^* = D_\lambda\, P_\sigma D P_\sigma^*\, D_\lambda^*.$$

Now $P_\sigma D P_\sigma^*$ is diagonal (entries permuted), and conjugating a di
agonal matrix by a diagonal unitary keeps it diagonal. So $UDU^* \in D_n$.

**Preserves $D_n$ $\Rightarrow$ monomial.** Suppose $U$ is unitary and $U\,D_n\,
U^* \subseteq D_n$. Let $E_{ii}$ be the diagonal matrix with $1$ in position $(i
,i)$ and $0$ elsewhere. Then $U E_{ii} U^*$ is a rank-$1$ orthogonal projection
(since $E_{ii}$ is), and by assumption it is diagonal. A diagonal rank-$1$ proje
ction must be some $E_{jj}$. So for each $i$ there is an index $\sigma(i)$ with

$$U E_{ii} U^* = E_{\sigma(i),\,\sigma(i)}.$$

The family $\{E_{ii}\}$ is a complete set of orthogonal projections ($E_{ii}E_{j
j}=0$ for $i\neq j$, $\sum_i E_{ii}=I$), so their images $\{E_{\sigma(i),\sigma(
i)}\}$ are also orthogonal and sum to $I$, forcing $\sigma$ to be a permutation
of $\{1,\dots,n\}$.

Writing $u_i$ for the $i$-th column of $U$, we have $U E_{ii} U^* = u_i u_i^* =
E_{\sigma(i),\sigma(i)}$. This forces $u_i = \lambda_i\, e_{\sigma(i)}$ for some
 scalar $\lambda_i$ with $|\lambda_i|=1$ (unitarity of $U$ gives the unit modulu
s). Therefore each column of $U$ is a standard basis vector times a phase, i.e.,

$$U = D_\lambda\, P_\sigma, \qquad D_\lambda = \operatorname{diag}(\lambda_1,\do
ts,\lambda_n).$$

**When is such $U$ non-diagonal?** $U = D_\lambda P_\sigma$ is diagonal if and o
nly if $\sigma = \mathrm{id}$. Hence $U \notin D_n$ requires $\sigma$ to be a **
non-identity** permutation, which exists if and only if $n \geq 2$.

---

### Conclusion

A unitary matrix $U \in M_n(\mathbb{C}) \setminus D_n$ with $U\,D_n\,U^* = D_n$
**exists if and only if $n \geq 2$**. For $n \geq 2$, any non-identity permutati
on matrix (e.g., the transposition $(1\;2)$) provides an explicit example. The f
ull solution set is the group of monomial unitary matrices $D_\lambda P_\sigma$
with $\sigma \neq \mathrm{id}$, i.e., the normalizer $N_{\mathrm{U}(n)}(D_n)$ mi
nus the diagonal subgroup $D_n$ itself.
