Looking at this problem, I need to find all two-digit numbers $ab = 10a + b$ tha

## Setting Up the Structure of Relatives

A relative $n$ of $ab$ has units digit $b$, and all remaining digits are non-zer
o and sum to $a$. Writing $n = 10m + b$, the number $m$ is any positive integer
whose digits are all non-zero and sum to $a$.

**Key observation:** Since $n \equiv m \pmod{9}$ (a number equals its digit sum
mod 9), and the digit sum of $m$ is $a$, we get $m \equiv a \pmod{9}$, so $9 \mi
d (m - a)$ for every valid $m$.

## Deriving the Divisibility Condition

We need $d = 10a + b$ to divide $10m + b$ for all valid $m$. Since $d \mid (10a+
b)$, this gives:
$$d \mid \bigl(10m + b - (10a + b)\bigr) = 10(m - a) \quad \text{for all valid }
 m.$$

Let $g = \gcd(d, 10) = \gcd(b, 10)$. Setting $D = d/g = (10a+b)/\gcd(b,10)$, the
 condition becomes:
$$D \mid (m - a) \quad \text{for all valid } m.$$

Since $9 \mid (m-a)$ always holds, **$D \mid 9$ is sufficient**. It is also **ne
cessary** when $a \geq 2$: the number $m = 10 + (a-1)$ (digits $1$ and $a-1$, bo
th non-zero, summing to $a$) gives $m - a = 9$, forcing $D \mid 9$.

## Case $a = 1$

The only $m$ with all non-zero digits summing to $1$ is $m = 1$ (any multi-digit
 number has digit sum $\geq 2$). So the only relative is $n = 10 + b = ab$ itsel
f, which trivially divides itself. **All ten numbers $10, 11, \ldots, 19$ work.*
* Their sum is $145$.
