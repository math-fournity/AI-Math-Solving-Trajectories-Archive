# Proof: Polynomial-Time Reduction from FACT to SAT

## Answer

**Yes**, it is possible to transform the RSA factoring problem (FACT) into a SAT
 problem in polynomial time, with a polynomial number of variables and clauses i
n the resulting logical formula.

## Justification

### 1. FACT is in NP

The factoring problem FACT asks: given an RSA modulus $N$ (an $n$-bit integer th
at is the product of two primes $p$ and $q$), find $p$ and $q$.

A candidate solution $(p, q)$ can be **verified in polynomial time**: simply com
pute the product $p \times q$ using standard multiplication (which runs in $O(n^
2)$ time via the schoolbook algorithm) and check whether the result equals $N$,
and additionally verify that $p$ and $q$ are prime (primality testing is in P by
 the AKS algorithm). Therefore FACT ∈ NP.

### 2. Cook–Levin Theorem: Every NP Problem Reduces to SAT in Polynomial Time

By the **Cook–Levin theorem**, SAT is NP-complete: every problem in NP can be re
duced to SAT by a polynomial-time many-one reduction. Since FACT ∈ NP, there exi
sts a polynomial-time computable function $f$ that maps any instance $N$ of FACT
 to a CNF formula $\varphi_N$ such that $\varphi_N$ is satisfiable if and only i
f $N$ has a valid factorization of the required form. The size of $\varphi_N$ (n
umber of variables and clauses) is bounded by a polynomial in the input size $n$
.

This already establishes the result. However, we can give a **direct, explicit c
onstruction** that makes the polynomial bounds concrete.

### 3. Explicit Construction via a Boolean Circuit and Tseitin Encoding

**Step 1 — Build a verification circuit.** Introduce $n$ Boolean variables repre
senting the unknown factors: $n/2$ bits for $p$ and $n/2$ bits for $q$ (with app
ropriate constraints to ensure they are nontrivial). Construct a Boolean circuit
 $C_N$ that:

- Computes the product $p \times q$ using the **schoolbook multiplication** algo
rithm. This requires $O((n/2)^2) = O(n^2)$ AND gates for the partial products an
d $O(n^2)$ full/half adders for the summation.
- Compares the resulting $n$-bit product against the known bits of $N$ using $O(
n)$ XOR/NOT gates.

The total size of this circuit is $O(n^2)$ gates — polynomial in $n$.

**Step 2 — Convert the circuit to CNF via the Tseitin transformation.** The Tsei
tin encoding introduces one fresh auxiliary variable for each gate's output and
encodes each gate's input–output relationship using a **constant number** of cla
uses (at most 4 clauses per gate for AND/OR gates, 2 for NOT/XOR). The final out
put gate is constrained to be TRUE.

- **Variables:** $n$ input variables (for $p$ and $q$) plus $O(n^2)$ auxiliary T
seitin variables $\Rightarrow$ **$O(n^2)$ variables total**.
- **Clauses:** $O(n^2)$ gates × $O(1)$ clauses per gate, plus $O(n)$ equality cl
auses $\Rightarrow$ **$O(n^2)$ clauses total**.

Both the number of variables and the number of clauses are **polynomial in $n$**
, and the entire construction runs in **polynomial time** $O(n^2)$.

### 4. Correctness

The resulting CNF formula $\varphi_N$ is satisfiable **if and only if** there ex
ist values of $p$ and $q$ such that $p \times q = N$ (with $p, q$ in the appropr
iate range). Any satisfying assignment directly yields the factors $p$ and $q$ b
y reading off the input variables; conversely, any valid factorization yields a
satisfying assignment (by extending it with the forced values of all auxiliary g
ate variables). Thus the reduction faithfully encodes FACT.

### 5. Conclusion

The factoring problem FACT can be reduced to SAT in polynomial time, producing a
 CNF formula with $O(n^2)$ variables and $O(n^2)$ clauses — both polynomial in t
he bit-length $n$. This follows either abstractly from the Cook–Levin theorem (s
ince FACT ∈ NP and SAT is NP-complete) or concretely from the explicit circuit-a
nd-Tseitin construction described above. In fact, this reduction is the foundati
on of practical **SAT-based factoring** methods that have been studied and imple
mented in the cryptography and automated reasoning communities.
