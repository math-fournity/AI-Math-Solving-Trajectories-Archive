## Proof

We seek all triples $(m, p, q)$ with $m \in \mathbb{Z}_{>0}$ and $p, q$ prime sa
tisfying
$$2^m p^2 + 1 = q^5, \quad\text{i.e.,}\quad q^5 - 1 = 2^m p^2.$$

**Factorization.** Factor
$$q^5 - 1 = (q-1)\bigl(q^4+q^3+q^2+q+1\bigr).$$
Set $A = q-1$ and $B = q^4+q^3+q^2+q+1$. Since $B = \frac{q^5-1}{q-1}$, reducing
 modulo $q-1$ (i.e. $q \equiv 1$) gives $B \equiv 1+1+1+1+1 = 5 \pmod{q-1}$, so
$$\gcd(A, B) \mid 5.$$

**Case $q = 2$.** Then $q^5 - 1 = 31$, which is prime and odd, so it cannot equa
l $2^m p^2$ with $m \ge 1$. No solution.

**Case $q$ odd.** Then $A = q-1$ is even, while $B$ (sum of five odd numbers) is
 odd. Since $q^5 - 1 = 2^m p^2$ has only the prime factors $2$ and $p$, and $B$
is odd, we must have $B = p^d$ for some $d \ge 1$, and $A = 2^m p^c$ with $c + d
 = 2$, $c \ge 0$.

- **$d = 1$:** Then $c = 1$, $A = 2^m p$, $B = p$. Hence $\gcd(A,B) = p$, which
divides $5$, so $p = 5$ and $B = 5$. But $B = q^4+q^3+q^2+q+1 = 5$ forces $q = 1
$, not prime. No solution.

- **$d = 2$:** Then $c = 0$, so $q - 1 = 2^m$ (i.e. $q = 2^m + 1$, necessarily p
rime) and
  $$p^2 = B = q^4 + q^3 + q^2 + q + 1.$$

  We determine when $B$ is a perfect square. For odd $q$, the integers $q^2 + \t
frac{q-1}{2}$ and $q^2 + \tfrac{q+1}{2}$ are consecutive. Compute:
  $$\left(q^2 + \tfrac{q-1}{2}\right)^2 = q^4 + q^3 - \tfrac{3}{4}q^2 - \tfrac{q
}{2} + \tfrac{1}{4},$$
  $$\left(q^2 + \tfrac{q+1}{2}\right)^2 = q^4 + q^3 + \tfrac{5}{4}q^2 + \tfrac{q
}{2} + \tfrac{1}{4}.$$
  Then
  $$B - \left(q^2 + \tfrac{q-1}{2}\right)^2 = \tfrac{7}{4}q^2 + \tfrac{3}{2}q +
\tfrac{3}{4} > 0,$$
  $$B - \left(q^2 + \tfrac{q+1}{2}\right)^2 = -\tfrac{(q-3)(q+1)}{4}.$$

  - For $q > 3$: $(q-3)(q+1) > 0$, so $\left(q^2+\tfrac{q-1}{2}\right)^2 < B < \
left(q^2+\tfrac{q+1}{2}\right)^2$. Since these are **consecutive** squares, $B$
is not a perfect square. No solution.
  - For $q = 3$: $B = \left(q^2+\tfrac{q+1}{2}\right)^2 = (9+2)^2 = 121 = 11^2$,
 so $p = 11$ (prime). Also $q - 1 = 2 = 2^1$, giving $m = 1$.

**Verification.** $2^1 \cdot 11^2 + 1 = 2 \cdot 121 + 1 = 243 = 3^5$. ✓

**Conclusion.** The unique triple is
$$\boxed{(m, p, q) = (1, 11, 3)}.$$
