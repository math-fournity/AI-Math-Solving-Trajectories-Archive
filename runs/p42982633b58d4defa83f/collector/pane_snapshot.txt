## Proof

Let $M$ be a smooth 3-manifold with local coordinates $(x,y,z)$, equipped with t
he standard orientation $dx\wedge dy\wedge dz$ and the Euclidean metric $g = dx\
otimes dx + dy\otimes dy + dz\otimes dz$ (so that the volume form is $\mathrm{vo
l} = dx\wedge dy\wedge dz$).

The Hodge star operator $*:\Omega^k(M)\to\Omega^{3-k}(M)$ is defined by
$$\eta\wedge *\omega = \langle\eta,\omega\rangle_g\,\mathrm{vol}$$
for all $k$-forms $\eta,\omega$, where $\langle\cdot,\cdot\rangle_g$ is the indu
ced inner product on $k$-forms.

**Computing the Hodge star on basis 2-forms.** The basis 2-forms are $\{dx\wedge
 dy,\; dy\wedge dz,\; dz\wedge dx\}$, which are orthonormal since the coordinate
 1-forms are orthonormal. Applying the definition:

- For $dx\wedge dy$: we need $(dx\wedge dy)\wedge *(dx\wedge dy) = \mathrm{vol}
= dx\wedge dy\wedge dz$, so $*(dx\wedge dy) = dz$.
- For $dy\wedge dz$: we need $(dy\wedge dz)\wedge *(dy\wedge dz) = \mathrm{vol}$
. Since $(dy\wedge dz)\wedge dx = dy\wedge dz\wedge dx = dx\wedge dy\wedge dz =
\mathrm{vol}$, we get $*(dy\wedge dz) = dx$.
- For $dz\wedge dx$: we need $(dz\wedge dx)\wedge *(dz\wedge dx) = \mathrm{vol}$
. Since $(dz\wedge dx)\wedge dy = dz\wedge dx\wedge dy = dx\wedge dy\wedge dz =
\mathrm{vol}$, we get $*(dz\wedge dx) = dy$.

**Applying to $\omega$.** By linearity of the Hodge star and the fact that $f,g,
h$ are 0-forms (functions, which commute with $*$):

$$\omega = f\,dx\wedge dy + g\,dy\wedge dz + h\,dz\wedge dx$$

$$*\omega = f\,*(dx\wedge dy) + g\,*(dy\wedge dz) + h\,*(dz\wedge dx)$$

$$*\omega = f\,dz + g\,dx + h\,dy$$

Reordering into the standard form $*\omega = \alpha\,dx + \beta\,dy + \gamma\,dz
$:

$$*\omega = g\,dx + h\,dy + f\,dz$$

**Result.** The Hodge dual of $\omega$ is the 1-form $*\omega = g\,dx + h\,dy +
f\,dz$, giving

$$\boxed{\alpha = g,\qquad \beta = h,\qquad \gamma = f.}$$

**Verification.** As a consistency check, applying $*$ again: $**\omega = *(g\,d
x + h\,dy + f\,dz)$. Using $*(dx)=dy\wedge dz$, $*(dy)=dz\wedge dx$, $*(dz)=dx\w
edge dy$ (each obtained by the same wedge-product definition), we get $**\omega
= g\,dy\wedge dz + h\,dz\wedge dx + f\,dx\wedge dy = \omega$, confirming $**=\ma
thrm{Id}$ on 2-forms in dimension 3, as expected (since $(-1)^{k(3-k)}=(-1)^{2}=
+1$).
