## 证明

设 $B_t$ 为标准布朗运动，因此 $B_t \sim N(0,t)$，且对于 $s \le t$，增量 $B_t - B
_s \sim N(0, t-s)$ 与 $\mathcal{F}_s$ 独立。

将 $B_t = B_s + (B_t - B_s)$ 代入 $M_t = e^{5B_t} e^{-bt}$ 中：

$$M_t = e^{5B_s + 5(B_t - B_s)} e^{-bt} = e^{5B_s - bs} \cdot e^{5(B_t - B_s) -
b(t-s)} = M_s \cdot e^{5(B_t - B_s) - b(t-s)}.$$

对 $\mathcal{F}_s$ 取条件期望，利用 $B_t - B_s$ 与 $\mathcal{F}_s$ 独立，可将期
望提取到外面：

$$\mathbb{E}[M_t \mid \mathcal{F}_s] = M_s \cdot \mathbb{E}\!\left[e^{5(B_t - B_
s) - b(t-s)}\right].$$

由于 $B_t - B_s \sim N(0, t-s)$，正态分布的矩母函数给出 $\mathbb{E}[e^{\lambda X
}] = e^{\lambda^2 \sigma^2/2}$，其中 $\sigma^2 = t-s$，因此：

$$\mathbb{E}\!\left[e^{5(B_t - B_s)}\right] = e^{\frac{5^2}{2}(t-s)} = e^{\frac{
25}{2}(t-s)}.$$

因此，

$$\mathbb{E}\!\left[e^{5(B_t - B_s) - b(t-s)}\right] = e^{\frac{25}{2}(t-s)} \cd
ot e^{-b(t-s)} = e^{\left(\frac{25}{2} - b\right)(t-s)}.$$

为了使 $M_t$ 成为鞅，我们需要对于所有 $s \le t$，有 $\mathbb{E}[M_t \mid \mathca
l{F}_s] = M_s$，即：

$$e^{\left(\frac{25}{2} - b\right)(t-s)} = 1 \quad \text{对所有 } t \ge s.$$

这要求指数对于所有 $t - s \ge 0$ 均消失：

$$\frac{25}{2} - b = 0 \implies b = \frac{25}{2}.$$

**验证：** 当 $b = \frac{25}{2}$ 时，$M_t = e^{5B_t - \frac{25}{2}t}$。由于 $5B_
t \sim N(0, 25t)$，我们得到 $\mathbb{E}[e^{5B_t}] = e^{25t/2}$，因此 $\mathbb{E}
[M_t] = e^{25t/2} \cdot e^{-25t/2} = 1$，这是常数（与 $M_0 = 1$ 一致），确认了鞅
性质成立。

$$\boxed{b = \dfrac{25}{2}}$$
