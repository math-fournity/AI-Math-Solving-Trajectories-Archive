Looking at this problem, I need to find the smallest integer distance AB between
 two lattice points A, B such that there exists a third noncollinear lattice poi
nt C with AC and BC also integers.

## Setup

Place A = (0,0) and B = (a, 0) where a = AB. Let C = (x, y) with integer x, y an
d y ≠ 0 (noncollinear). Set AC = c, BC = b. Then:
- x² + y² = c²
- (x − a)² + y² = b²

Subtracting: 2ax − a² = c² − b², so x = (a² + c² − b²)/(2a), and y² = c² − x².

## Case a = 1: Impossible

Here A = (0,0), B = (1,0) (the only lattice pairs at distance 1 are axis-adjacen
t). Then x = (1 + c² − b²)/2, requiring c, b of **different parity** (so c² − b²
 is odd). Set p = c − b, q = c + b; both are odd, q ≥ 1. Then x = (1 + pq)/2 and
:

$$y^2 = c^2 - x^2 = \frac{(p+q)^2 - (1+pq)^2}{4} = \frac{[-(p-1)(q-1)][(p+1)(q+1
)]}{4} = -\frac{(p^2-1)(q^2-1)}{4}.$$

Since p is odd, p² ≥ 1 so p² − 1 ≥ 0. Since q ≥ 1 is odd, q² ≥ 1 so q² − 1 ≥ 0.
Therefore y² ≤ 0, with y² = 0 only when |p| = 1 or q = 1 — both giving degenerat
e (collinear) triangles. **No valid solution exists for a = 1.**

## Case a = 2: Impossible

Lattice pairs at distance 2: A = (0,0), B = (2,0) WLOG. Then x = (4 + c² − b²)/4
, requiring c, b of the **same parity**. Set u = (c − b)/2, v = (c + b)/2 (integ
ers, v > 0), so c = u + v, b = v − u, and x = 1 + uv. Then:

$$y^2 = c^2 - x^2 = (u+v)^2 - (1+uv)^2 = u^2 + v^2 - 1 - u^2v^2 = -(u^2-1)(v^2-1
).$$

For y² > 0 we need (u²−1)(v²−1) < 0. Since v > 0:
- If v = 1: y² = 0 (degenerate).
- If v ≥ 2: v²−1 > 0, so need u²−1 < 0, i.e., u = 0. Then y² = v²−1, which is a
perfect square only if v²−1 = k², giving (v−k)(v+k) = 1, so v = 1 — contradictio
n.

**No valid solution exists for a = 2.**

## Case a = 3: Achievable

Take A = (0,0), B = (3,0), C = (0,4). Then:
- AB = 3 ✓
- AC = √(0 + 16) = 4 ✓
- BC = √(9 + 16) = 5 ✓
- Points are noncollinear (C has y = 4 ≠ 0) ✓

All three distances are integers, all coordinates are integers, and the points a
re noncollinear.

## Conclusion

Since a = 1 and a = 2 are both impossible, and a = 3 is achievable, the smallest
 possible value of AB is $\boxed{3}$.
