## Proof

**Conventions.** We use the standard separation axioms *without* a built-in T₁ r
equirement:
- **Regular:** for every closed set $F$ and every point $x \notin F$, there exis
t disjoint open sets $U, V$ with $F \subseteq U$ and $x \in V$.
- **Normal:** for every pair of disjoint closed sets $E, F$, there exist disjoin
t open sets $U, V$ with $E \subseteq U$ and $F \subseteq V$.

Under these definitions, normality does **not** automatically imply regularity,
because a singleton $\{x\}$ need not be closed (so "separate a point from a clos
ed set" is *not* a special case of "separate two closed sets"). This is exactly
the gap we exploit.

**Claim:** Yes, it is possible. We give an explicit example on a finite set.

**Construction.** Let $X = \{a, b\}$ with the topology
$$\tau = \bigl\{\varnothing,\ \{a\},\ X\bigr\}.$$
The closed sets (complements of open sets) are
$$\varnothing,\quad X\setminus\{a\}=\{b\},\quad X\setminus X=\varnothing,\quad X
\setminus\varnothing=X,$$
i.e. the closed sets are $\varnothing,\ \{b\},\ X$.

**Normality.** We must separate every pair of disjoint closed sets. The non-empt
y closed sets are $\{b\}$ and $X$, and
$$\{b\}\cap X = \{b\}\neq\varnothing.$$
So there is **no** pair of non-empty disjoint closed sets. Every disjoint pair i
nvolves $\varnothing$, which is trivially separated (take $U=\varnothing$). Henc
e $X$ is normal. ✓

**Failure of regularity.** Consider the closed set $F=\{b\}$ and the point $x=a\
notin F$. Suppose, for contradiction, that there exist disjoint open sets $U,V$
with $\{b\}\subseteq U$ and $a\in V$.

Since $b\in U$ and $U$ is open, $U$ must be an open set containing $b$. The open
 sets are $\varnothing,\{a\},X$; only $X$ contains $b$. Hence $U=X$.

But then $V\subseteq X=U$, so
$$U\cap V = V.$$
Since $a\in V$, we have $V\neq\varnothing$, giving $U\cap V\neq\varnothing$ — co
ntradicting the requirement $U\cap V=\varnothing$.

Therefore no such disjoint open sets exist, and $X$ is **not regular**. ✓

**Conclusion.** The two-point set $X=\{a,b\}$ with topology $\tau=\{\varnothing,
\{a\},X\}$ (the *Sierpiński space*) is **normal but not regular**. This is a top
ology on a finite set, so the answer is:

**Yes, it is possible to create a topology on a finite set that is normal but no
t regular.** $\blacksquare$

*Remark.* If one adopts the alternative convention where "regular" and "normal"
each include the T₁ axiom, then normality always implies regularity (in a T₁ spa
ce singletons are closed, so point–closed separation becomes a special case of c
losed–closed separation), making the answer trivially *no*. Moreover, on a finit
e set T₁ forces the discrete topology, which is both normal and regular. The non
-trivial, standard answer to this classic exercise is therefore **yes**, obtaine
d under the convention (used above) where regularity and normality are separatio
n properties standing on their own, without T₁.
