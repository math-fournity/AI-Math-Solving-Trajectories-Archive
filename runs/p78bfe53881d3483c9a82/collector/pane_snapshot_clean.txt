## Proof

Let α = ∠BAC, β = ∠ABC, γ = ∠ACB, with α + β + γ = 180°.

**Side ordering.** AB < AC < BC gives sin γ < sin β < sin α (sides = 2R·sin of o
pposite angle). This forces β < 90° (so cos β > 0) and γ < β < α.

**D is external to ω.** Since ABCD is a parallelogram, D = A + C − B (affine). P
lacing ω as the unit circle with circumcenter O at the origin:

B at angle 0, C at angle 2α, A at angle −2γ (≡ 360° − 2γ), giving
- A = (cos 2γ, −sin 2γ), B = (1,0), C = (cos 2α, sin 2α),
- D = A + C − B = (−2cos β cos(α−γ) − 1, −2cos β sin(α−γ)).

Then |D|² = 1 + 4cos²β + 4cos β cos(α−γ). Since cos β + cos(α−γ) = 2 sin α sin γ
 > 0 and cos β > 0, we get |D|² > 1, so D lies outside ω and two tangents from D
 to ω exist.

**Tangent points.** The tangent from D to ω at a point X ∈ ω satisfies (D−X)·X =
 0, i.e. D·X = 1. The two solutions E (angle e₀), F (angle f₀) on the unit circl
e are symmetric about line OD, hence

$$e_0 + f_0 = 2\theta_D, \quad \text{where } \theta_D = \arg(D).$$

**Computing ∠ABF.** Since A, B, F all lie on ω, ∠ABF is an inscribed angle subte
nding the arc AF not containing B. With A at a₀ = 360° − 2γ and F at f₀ (where 0
 < f₀ < a₀), this arc equals a₀ − f₀, so

$$\angle ABF = \tfrac{1}{2}(360° - 2\gamma - f_0).$$

**Computing ∠DCE.** From the parallelogram, CD = D − C = A − B = $\overrightarro
w{BA}$, so ray CD is parallel to ray BA. The direction of a chord joining angles
 p, q is (p+q)/2 + 90°. Thus:
- dir(BA) = 270° − γ (ray from B(0) to A(−2γ), verified: A−B = −2 sin γ(sin γ, c
os γ), direction 270° − γ),
- dir(CE) = (2α + e₀)/2 + 90° = α + e₀/2 + 90° (with E beyond C, e₀ > 2α).

Therefore

$$\angle DCE = \text{dir}(CE) - \text{dir}(CD) = (\alpha + e_0/2 + 90°) - (270°
- \gamma) = \tfrac{e_0}{2} - \beta.$$

**Imposing the condition ∠ABF = ∠DCE:**

$$\tfrac{1}{2}(360° - 2\gamma - f_0) = \tfrac{e_0}{2} - \beta$$
$$360° - 2\gamma - f_0 = e_0 - 2\beta$$
$$e_0 + f_0 = 360° - 2\gamma + 2\beta$$
$$2\theta_D = 360° - 2\gamma + 2\beta \implies \theta_D = 180° - \gamma + \beta
= \alpha + 2\beta. \quad (\ast)$$

**Deriving β.** Condition (∗) means D_x sin(α+2β) = D_y cos(α+2β):

$$(−2\cos\beta\cos(\alpha−\gamma) − 1)\sin(\alpha+2\beta) = (−2\cos\beta\sin(\al
pha−\gamma))\cos(\alpha+2\beta).$$

Rearranging:

$$−2\cos\beta\bigl[\cos(\alpha−\gamma)\sin(\alpha+2\beta) − \sin(\alpha−\gamma)\
cos(\alpha+2\beta)\bigr] = \sin(\alpha+2\beta)$$
$$−2\cos\beta\,\sin\bigl((\alpha+2\beta) − (\alpha−\gamma)\bigr) = \sin(\alpha+2
\beta)$$
$$−2\cos\beta\,\sin(2\beta + \gamma) = \sin(\alpha + 2\beta).$$

Using α + 2β = (180° − β − γ) + 2β = 180° + β − γ, so sin(α + 2β) = −sin(β − γ):

$$2\cos\beta\,\sin(2\beta + \gamma) = \sin(\beta − \gamma).$$

Expanding both sides:
- LHS = 2cos β(sin γ cos 2β + cos γ sin 2β) = 2cos β sin γ cos 2β + 4cos²β cos γ
 sin β,
- RHS = sin β cos γ − cos β sin γ.

Setting LHS − RHS = 0 and grouping:

$$\sin\gamma\bigl[2\cos\beta\cos 2\beta + \cos\beta\bigr] + \cos\gamma\sin\beta\
bigl[4\cos^2\beta − 1\bigr] = 0$$
$$\cos\beta\sin\gamma\bigl[2\cos 2\beta + 1\bigr] + \cos\gamma\sin\beta\bigl[4\c
os^2\beta − 1\bigr] = 0.$$

Since 2cos 2β + 1 = 4cos²β − 1, both terms share this factor:

$$(4\cos^2\beta − 1)\bigl[\cos\beta\sin\gamma + \cos\gamma\sin\beta\bigr] = 0$$
$$(4\cos^2\beta − 1)\sin(\beta + \gamma) = 0.$$

Since β + γ = 180° − α ∈ (0°, 180°), we have sin(β + γ) = sin α ≠ 0. Therefore

$$4\cos^2\beta − 1 = 0 \implies \cos^2\beta = \tfrac{1}{4} \implies \cos\beta =
\tfrac{1}{2} \implies \beta = 60°.$$
