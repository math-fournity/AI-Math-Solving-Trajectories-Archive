Looking at this problem, I need to find all real $a$ such that there exist reals
 $x_1,\ldots,x_n$ with $x_i(1-x_{i+1})=a$ cyclically.

**Answer.** The set of all such $a$ is:
$$a \le \tfrac{1}{4} \quad\text{or}\quad a = \frac{1}{4\cos^2\!\frac{k\pi}{n}} \
text{ for some integer } k,\; 1 \le k < \tfrac{n}{2}.$$

---

**Proof.**

**Setup.** The conditions are $x_i(1-x_{i+1})=a$ for $i=1,\dots,n$ (cyclic, $x_{
n+1}=x_1$).

**Case $a=0$.** Take $x_1=\cdots=x_n=0$. Achievable.

**Case $a\ne 0$.** Then every $x_i\ne 0$ (since $x_i(1-x_{i+1})=a\ne 0$) and eve
ry $x_i\ne 1$ (since $x_{i-1}(1-x_i)=a\ne 0$). Define the Möbius transformation
$$f(x)=1-\frac{a}{x}=\frac{x-a}{x}.$$
Then $x_{i+1}=f(x_i)$ for all $i$, and the cyclic condition gives $f^{(n)}(x_1)=
x_1$. So $x_1$ is a real fixed point of $f^{(n)}$ (and $x_1\ne 0$, so not a pole
).

The matrix representing $f$ is $M=\begin{pmatrix}1&-a\\1&0\end{pmatrix}$, with $
\det M=a$, $\operatorname{tr}M=1$. Its eigenvalues are roots of $\lambda^2-\lamb
da+a=0$:
$$\lambda_{1,2}=\tfrac{1\pm\sqrt{1-4a}}{2}.$$

The $n$-th iterate $f^{(n)}$ is represented by $M^n$. The fixed points of $f^{(n
)}$ (as a Möbius transformation) satisfy a quadratic whose discriminant is
$$\operatorname{tr}(M^n)^2-4\det(M^n)=(\lambda_1^n+\lambda_2^n)^2-4\lambda_1^n\l
ambda_2^n=(\lambda_1^n-\lambda_2^n)^2.$$

**Subcase $a\le \frac14$, $a\ne 0$: achievability.** The equation $c(1-c)=a$, i.
e.\ $c^2-c+a=0$, has real roots $c=\frac{1\pm\sqrt{1-4a}}{2}$ (since $1-4a\ge 0$
). For $a\ne 0$, we have $c\ne 0$ and $c\ne 1$ (since $0\cdot1=0\ne a$). Setting
 $x_1=\cdots=x_n=c$ gives $x_i(1-x_{i+1})=c(1-c)=a$. So every $a\in(-\infty,\fra
c14]\setminus\{0\}$ is achievable (and $a=0$ was handled above).

**Subcase $a>\frac14$: necessity.** Here $1-4a<0$, so the eigenvalues are comple
x conjugates. Write $\lambda_1=re^{i\theta}$, $\lambda_2=re^{-i\theta}$ where $r
=\sqrt{a}$ and $\theta=\arccos\frac{1}{2\sqrt{a}}\in(0,\pi/2)$ (since $\cos\thet
a=\frac{\operatorname{tr}M}{2\sqrt{\det M}}=\frac{1}{2\sqrt{a}}\in(0,1)$).

Then $\lambda_1^n-\lambda_2^n=2ir^n\sin(n\theta)$, so the discriminant is
$$(\lambda_1^n-\lambda_2^n)^2=-4a^n\sin^2(n\theta)\le 0.$$

For a real fixed point of $f^{(n)}$ to exist, the discriminant must be $\ge 0$.
Since it is $\le 0$, we need $\sin(n\theta)=0$, i.e.\ $n\theta=k\pi$ for some in
teger $k$.

Since $\theta\in(0,\pi/2)$, we get $k\pi/n\in(0,\pi/2)$, so $k$ is a positive in
teger with $k<n/2$, i.e.\ $k\in\{1,2,\dots,\lfloor\frac{n-1}{2}\rfloor\}$.

From $\cos\theta=\frac{1}{2\sqrt{a}}$ and $\theta=\frac{k\pi}{n}$:
$$a=\frac{1}{4\cos^2\frac{k\pi}{n}}.$$

Note $\cos\frac{k\pi}{n}\in(0,1)$ for such $k$, so $a>\frac14$, consistent with
our assumption. This establishes necessity: if $a>\frac14$ is achievable, then $
a=\frac{1}{4\cos^2(k\pi/n)}$ for some $k\in\{1,\dots,\lfloor\frac{n-1}{2}\rfloor
\}$.

**Subcase $a>\frac14$: achievability.** Suppose $a=\frac{1}{4\cos^2(k\pi/n)}$ fo
r some valid $k$. Then $\sin(n\theta)=0$, so $\lambda_1^n=\lambda_2^n$, meaning
$M^n$ is a scalar multiple of the identity. Therefore $f^{(n)}=\mathrm{id}$, and
 every real number (except poles of iterates of $f$) is a fixed point of $f^{(n)
}$.

We need $x_1\in\mathbb{R}$ whose orbit $x_1,f(x_1),\dots,f^{n-1}(x_1)$ avoids $0
$ (so all iterates are defined and all $x_i\ne 0$) and avoids $1$ (so all $x_i\n
e 1$). The "bad" starting values are:
- Preimages of $0$ under $f^j$ for $j=0,\dots,n-1$: at most $n$ points (each $f^
{-j}(0)$ is a single point when defined, since $f$ is a Möbius transformation).
- Since $f(x)=1$ has no solution ($1-a/x=1$ gives $a=0$, contradiction), the onl
y point mapping to $1$ is $x=1$ itself.

So the bad set is finite (at most $n+1$ points). Since $\mathbb{R}$ is infinite,
 choose $x_1$ outside this set. Then $x_i=f^{i-1}(x_1)$ are all well-defined, no
nzero, and not $1$, with $f^{(n)}(x_1)=x_1$ ensuring the cyclic condition. Each
$x_i(1-x_{i+1})=x_i\cdot\frac{a}{x_i}=a$. So $a$ is achievable.

**Verification of edge cases.**
- $n=2$: $\lfloor\frac{n-1}{2}\rfloor=0$, so no valid $k$; answer is $a\le\frac1
4$. Indeed, $x_1(1-x_2)=x_2(1-x_1)$ forces $x_1=x_2$, giving $a=x_1(1-x_1)\le\fr
ac14$. ✓
- $n=3$: $k\in\{1\}$, giving $a=\frac{1}{4\cos^2(\pi/3)}=\frac{1}{4\cdot\frac14}
=1$. One checks $x_1=2,x_2=\frac12,x_3=-1$: $2\cdot\frac12=\frac12\cdot2=(-1)(-1
)=1$. ✓

**Conclusion.** The set of all achievable $a$ is
$$a\le\frac14 \quad\text{or}\quad a=\frac{1}{4\cos^2\frac{k\pi}{n}},\quad k=1,2,
\dots,\left\lfloor\frac{n-1}{2}\right\rfloor.$$
