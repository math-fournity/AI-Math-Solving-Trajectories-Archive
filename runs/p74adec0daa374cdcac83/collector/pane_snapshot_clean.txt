## Solution

**Problem.** Determine the maximal Hausdorff dimension of the set
$$E_f := \{x \in \mathbb{R}^n : f \text{ is differentiable at } x \text{ and } |
Df(x)| = L\},$$
where $f: \mathbb{R}^n \to \mathbb{R}$ is Lipschitz continuous with strict Lipsc
hitz constant $L$, and the maximum is taken over all such $f$.

**Answer: $n$.**

### Proof

**Upper bound.** For any Lipschitz function $f: \mathbb{R}^n \to \mathbb{R}$, th
e set $E_f$ is a subset of $\mathbb{R}^n$. Since the Hausdorff dimension of any
subset of $\mathbb{R}^n$ is at most $n$, we have
$$\dim_H(E_f) \leq n$$
for every such $f$.

**The bound is achieved.** Consider the linear function
$$f(x) = L\, x_1, \quad x = (x_1, \ldots, x_n) \in \mathbb{R}^n.$$

- **Lipschitz continuity:** For any $x, y \in \mathbb{R}^n$,
$$|f(x) - f(y)| = L|x_1 - y_1| \leq L\|x - y\|,$$
so $f$ is Lipschitz with constant $L$.

- **Strict Lipschitz constant is $L$:** Taking $x = (t, 0, \ldots, 0)$ and $y =
(0, \ldots, 0)$, we get $|f(x) - f(y)|/|x - y| = L$, so the supremum $\sup_{x \n
eq y} |f(x)-f(y)|/|x-y|$ equals $L$. Hence the strict Lipschitz constant is exac
tly $L$.

- **Differentiability and $|Df| = L$ everywhere:** $f$ is smooth (linear), hence
 differentiable at every point $x \in \mathbb{R}^n$, with derivative $Df(x) = L\
, e_1$ (the constant linear map sending $v \mapsto L\, v_1$). The operator norm
is
$$|Df(x)| = \|L\, e_1^*\| = L \quad \text{for all } x \in \mathbb{R}^n.$$

Therefore $E_f = \mathbb{R}^n$, and
$$\dim_H(E_f) = \dim_H(\mathbb{R}^n) = n.$$

**Conclusion.** The upper bound $n$ is achieved by $f(x) = Lx_1$, so the maximal
 Hausdorff dimension is

$$\boxed{n}.$$
