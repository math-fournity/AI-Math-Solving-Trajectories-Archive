## Proof

Let the common value of the first equation be $k$:

$$\frac{x(y+z-x)}{\log x} = \frac{y(z+x-y)}{\log y} = \frac{z(x+y-z)}{\log z} =
k$$

Since $x, y, z > 0$ and $x, y, z \neq 1$ (for the logarithms to be defined and n
onzero), and $k \neq 0$ (as $k=0$ would force $x=y=z=0$, impossible), we can wri
te:

$$\log x = \frac{x(y+z-x)}{k}, \quad \log y = \frac{y(z+x-y)}{k}, \quad \log z =
 \frac{z(x+y-z)}{k}$$

**Key step: Show that $x^y y^x = y^z z^y = z^x x^z$.**

Compute $\log(x^y y^x) = y\log x + x\log y$:

$$y\log x + x\log y = \frac{y \cdot x(y+z-x)}{k} + \frac{x \cdot y(z+x-y)}{k} =
\frac{xy\big[(y+z-x)+(z+x-y)\big]}{k} = \frac{xy \cdot 2z}{k} = \frac{2xyz}{k}$$

Compute $\log(y^z z^y) = z\log y + y\log z$:

$$z\log y + y\log z = \frac{z \cdot y(z+x-y)}{k} + \frac{y \cdot z(x+y-z)}{k} =
\frac{yz\big[(z+x-y)+(x+y-z)\big]}{k} = \frac{yz \cdot 2x}{k} = \frac{2xyz}{k}$$

Compute $\log(z^x x^z) = x\log z + z\log x$:

$$x\log z + z\log x = \frac{x \cdot z(x+y-z)}{k} + \frac{z \cdot x(y+z-x)}{k} =
\frac{xz\big[(x+y-z)+(y+z-x)\big]}{k} = \frac{xz \cdot 2y}{k} = \frac{2xyz}{k}$$

Therefore:

$$\log(x^y y^x) = \log(y^z z^y) = \log(z^x x^z) = \frac{2xyz}{k}$$

Since $\log$ is injective:

$$x^y y^x = y^z z^y = z^x x^z =: P > 0$$

$$aP = bP = cP$$

Since $P > 0$, we divide through to obtain:

$$a = b = c$$

**Compute the answer.** Since $a = b = c$:

$$\frac{a+b}{c} = \frac{a+a}{a} = \frac{2a}{a} = 2$$

$$\boxed{a + \frac{b}{c} = 2}$$
