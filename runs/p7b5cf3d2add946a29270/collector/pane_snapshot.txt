## Solution

**Setting up the constraint.** Expand $(a^2-a+1)(b^2-b+1)=a^2b^2$:

$$a^2b^2 - a^2b + a^2 - ab^2 + ab - a + b^2 - b + 1 = a^2b^2$$

Cancelling $a^2b^2$ and regrouping with $s=a+b$, $p=ab$ (using $a^2+b^2=s^2-2p$
and $a^2b+ab^2=ps$):

$$s^2 - 2p - ps + p - s + 1 = 0 \implies s^2-s+1 = p(s+1)$$

$$\boxed{p = \frac{s^2-s+1}{s+1}}$$

**The target expression** becomes:

$$f = \frac{2ab}{a+b-1} = \frac{2p}{s-1} = \frac{2(s^2-s+1)}{(s+1)(s-1)} = \frac
{2(s^2-s+1)}{s^2-1}$$

**Range of $s$.** For $a,b$ to be positive reals, we need $s>0$, $p>0$, and $s^2
-4p\ge 0$.

- $p>0$: since $s^2-s+1>0$ always (discriminant $<0$) and $s+1>0$, this holds au
tomatically.
- Discriminant: $s^2 - \dfrac{4(s^2-s+1)}{s+1}\ge 0 \implies s^3-3s^2+4s-4\ge 0
\implies (s-2)(s^2-s+2)\ge 0$.

Since $s^2-s+2>0$ always, we need $s\ge 2$. At $s=2$: discriminant $=0$, giving
$a=b=1$ (which checks: $(1)(1)=1$). So $s\in[2,\infty)$.

**Optimizing $f(s)$.** Differentiate:

$$f'(s) = \frac{2\bigl[(2s-1)(s^2-1)-(s^2-s+1)(2s)\bigr]}{(s^2-1)^2} = \frac{2(s
^2-4s+1)}{(s^2-1)^2}$$

Setting $f'(s)=0$: $s^2-4s+1=0 \implies s=2\pm\sqrt3$. Only $s=2+\sqrt3$ lies in
 $[2,\infty)$.

Sign analysis on $[2,\infty)$: $f'(2)=\frac{2(-3)}{9}<0$ (decreasing), $f'(5)=\f
rac{2(6)}{576}>0$ (increasing). So $s=2+\sqrt3$ is the **minimum**.

**Computing $m=f(2+\sqrt3)$.** With $(2+\sqrt3)^2=7+4\sqrt3$:

$$f = \frac{2(7+4\sqrt3-2-\sqrt3+1)}{7+4\sqrt3-1} = \frac{2(6+3\sqrt3)}{6+4\sqrt
3} = \frac{6(2+\sqrt3)}{2(3+2\sqrt3)} = \frac{3(2+\sqrt3)}{3+2\sqrt3}$$

Rationalizing by multiplying by $\frac{3-2\sqrt3}{3-2\sqrt3}$ (denominator $9-12
=-3$):

$$f = \frac{3(2+\sqrt3)(3-2\sqrt3)}{-3} = -(2+\sqrt3)(3-2\sqrt3) = -(6-4\sqrt3+3
\sqrt3-6) = \sqrt3$$

So $m=\sqrt3$.

**Computing $M$.** At the boundary $s=2$: $f(2)=\frac{2(4-2+1)}{4-1}=\frac{6}{3}
=2$. As $s\to\infty$, $f(s)\to 2$ from below (e.g., $f(10)=182/99\approx1.838<2$
). Since $f$ decreases from $2$ to $\sqrt3$ then increases back toward $2$ (neve
r exceeding it), the maximum is attained at $s=2$:

$$M = 2$$

**Verification of key values:**
- $s=3$: $f=2(9-3+1)/(9-1)=14/8=1.75 > \sqrt3\approx1.732$ ✓
- $s=4$: $f=2(16-4+1)/(16-1)=26/15\approx1.733\approx\sqrt3$ ✓ (near minimum)
- $s=5$: $f=2(25-5+1)/(25-1)=42/24=1.75$ ✓ (increasing again)

**Final answer:**

$$M^2+m^2 = 2^2 + (\sqrt3)^2 = 4+3 = \boxed{7}$$
