Looking at this problem, I need to maximize $\sum_{i=1}^n x_i^2$ subject to $x_i
 \geq -1$ and $\sum_{i=1}^n x_i^3 = 0$.

## Proof

**Setup.** Split variables into negative ones $y_1,\dots,y_k \in [-1,0)$ and non
-negative ones $z_1,\dots,z_j \geq 0$ (with $k+j \leq n$; any remaining variable
s sit at $0$). The constraint becomes
$$\sum_{l=1}^j z_l^3 = \sum_{i=1}^k |y_i|^3 =: S.$$

**Bounding the negative part.** Since $|y_i|\leq 1$, we have $S=\sum|y_i|^3 \leq
 k$. By Jensen's inequality applied to the concave function $t\mapsto t^{2/3}$:
$$\sum y_i^2 = \sum (|y_i|^3)^{2/3} \leq k\left(\frac{S}{k}\right)^{2/3} = k^{1/
3}\,S^{2/3}.$$
This is increasing in $S$, so setting $S=k$ (i.e., all $|y_i|=1$, meaning $y_i=-
1$) gives
$$\sum y_i^2 \leq k, \quad \text{with equality iff all } y_i=-1.$$

**Bounding the positive part.** Again by Jensen:
$$\sum z_l^2 = \sum (z_l^3)^{2/3} \leq j\left(\frac{S}{j}\right)^{2/3} = j^{1/3}
\,S^{2/3},$$
with equality iff all $z_l$ are equal.

**Combining.** With $S=k$ (optimal for the negatives):
$$\sum x_i^2 \leq k + k^{2/3}\,j^{1/3}, \qquad k+j \leq n.$$
Since the right side is increasing in both $k$ and $j$, we set $k+j=n$.

**Optimizing over $k$.** Define $f(k) = k + k^{2/3}(n-k)^{1/3}$ for $k\in[0,n]$.
 Setting $f'(k)=0$ and substituting $t = \bigl((n-k)/k\bigr)^{1/3}$ yields
$$1 + \tfrac{2}{3}t - \tfrac{1}{3t^2} = 0 \;\;\Longrightarrow\;\; 2t^3+3t^2-1=0.
$$
Factoring: $2t^3+3t^2-1 = (t+1)^2(2t-1)=0$, so $t=\tfrac{1}{2}$ (taking the posi
tive root). This gives
$$\frac{n-k}{k} = \frac{1}{8} \;\;\Longrightarrow\;\; k=\frac{8n}{9},\quad j=\fr
ac{n}{9}.$$

The maximum value is
$$f\!\left(\tfrac{8n}{9}\right) = \frac{8n}{9} + \left(\frac{8n}{9}\right)^{2/3}
\!\left(\frac{n}{9}\right)^{1/3} = \frac{8n}{9} + \frac{4n}{9} = \frac{4n}{3}.$$

This exceeds the endpoint values $f(0)=0$ and $f(n)=n$, confirming it is a maxim
um.

**Achievability.** When $9\mid n$, take $\frac{8n}{9}$ units at $x_i=-1$ and $\f
rac{n}{9}$ units at $x_i=2$:
- Cube sum: $-\frac{8n}{9} + \frac{n}{9}\cdot 8 = 0$. ✓
- Square sum: $\frac{8n}{9}\cdot 1 + \frac{n}{9}\cdot 4 = \frac{12n}{9} = \frac{
4n}{3}$. ✓

All constraints $x_i \geq -1$ are satisfied. The upper bound from Jensen is met
with equality (all negatives equal, all positives equal), so this is optimal.

$$\boxed{\dfrac{4n}{3}}$$
