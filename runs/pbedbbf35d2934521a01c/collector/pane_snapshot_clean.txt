g \le x_i \le a_i + g$. So I need a non-decreasing sequence with lower bounds $\
ell_i = a_i - g$ and upper bounds $u_i = a_i + g$.

**Lemma (Feasibility of monotone interpolation).** There exists a non-decreasing

_i \le u_j$ for all $i \le j$.

*Necessity:* If such $(x_i)$ exists, then $\ell_i \le x_i \le x_j \le u_j$ whene
ver $i \le j$.

*Sufficiency:* Define $x_i = \max_{j \le i} \ell_j$. This is non-decreasing (the
 running max over a growing set). Clearly $x_i \ge \ell_i$. For the upper bound:
 $x_i = \ell_k$ for some $k \le i$ achieving the max. By hypothesis $\ell_k \le
u_i$ (since $k \le i$), so $x_i \le u_i$. ∎

**Applying the lemma.** With $\ell_i = a_i - g$ and $u_i = a_i + g$, the conditi
on $\ell_i \le u_j$ for $i \le j$ becomes:
$$a_i - g \le a_j + g \quad \Longleftrightarrow \quad a_i - a_j \le 2g.$$
This is precisely the given hypothesis (with $k = i$, $m = j$, $k \le m$).

$$x_i = \max_{0 \le j \le i}\, (a_j - g).$$

$$x_{i+1} = \max_{0 \le j \le i+1}(a_j - g) \ge \max_{0 \le j \le i}(a_j - g) =
x_i.$$

$$2g \ge a_k - a_i \implies a_k - g \le a_i + g \implies x_i \le a_i + g.$$
