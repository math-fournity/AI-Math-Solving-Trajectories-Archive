## Proof

**Answer-leak check:** The problem statement contains only the problem, no solut
ions or hints. Proceeding.

**Goal.** Find necessary and sufficient conditions on $\lambda \in \mathbb{R}$ s
o that $I = \langle P_1, P_2\rangle = \langle x^2-1,\ x^3+\lambda\rangle \subset
eq \mathbb{R}[x]$ is a maximal ideal.

---

**Step 1. Reduce to a principal ideal.**

Since $\mathbb{R}$ is a field, $\mathbb{R}[x]$ is a PID. Hence
$$I = \langle P_1, P_2\rangle = \langle g\rangle, \qquad g := \gcd(P_1, P_2).$$
An ideal $\langle g\rangle \subseteq \mathbb{R}[x]$ is maximal iff $g$ is irredu
cible over $\mathbb{R}$ (and $g$ is non-constant, so the ideal is proper). So we
 must determine $g$ as a function of $\lambda$.

**Step 2. Constrain $g$ using $P_1$.**

We have $g \mid P_1$ and
$$P_1(x) = x^2 - 1 = (x-1)(x+1).$$
Thus $g$ is (up to a nonzero scalar) one of
$$1,\quad x-1,\quad x+1,\quad (x-1)(x+1)=x^2-1.$$

**Step 3. Test divisibility of $P_2$ by the linear factors.**

- $x - 1 \mid P_2 \iff P_2(1) = 0 \iff 1 + \lambda = 0 \iff \lambda = -1.$
- $x + 1 \mid P_2 \iff P_2(-1) = 0 \iff -1 + \lambda = 0 \iff \lambda = 1.$

**Step 4. Determine $g$ in each case.**

- **$\lambda = 1$:** $x+1 \mid P_2$ but $x-1 \nmid P_2$ (since $P_2(1)=2\neq 0$)
. So $g = x+1$.
- **$\lambda = -1$:** $x-1 \mid P_2$ but $x+1 \nmid P_2$ (since $P_2(-1)=-2\neq
0$). So $g = x-1$.
- **$\lambda \neq \pm 1$:** Neither linear factor divides $P_2$, so $g = 1$.

The case $g = x^2-1$ would require *both* $x-1$ and $x+1$ to divide $P_2$, i.e.
$\lambda = -1$ and $\lambda = 1$ simultaneously — impossible. So $g = x^2-1$ nev
er occurs.

**Step 5. Check maximality.**

- $\lambda = 1$: $g = x+1$, irreducible (degree $1$) $\Rightarrow$ $I = \langle
x+1\rangle$ is maximal. ✓
- $\lambda = -1$: $g = x-1$, irreducible (degree $1$) $\Rightarrow$ $I = \langle
 x-1\rangle$ is maximal. ✓
- $\lambda \neq \pm 1$: $g = 1$ $\Rightarrow$ $I = \mathbb{R}[x]$, the whole rin
g, which is **not** a proper (hence not maximal) ideal. ✗

**Conclusion.**

The ideal $\langle x^2-1,\ x^3+\lambda\rangle$ is maximal in $\mathbb{R}[x]$ if
and only if
$$\boxed{\lambda = 1 \text{ or } \lambda = -1},$$
equivalently, $\lambda^2 = 1$.
