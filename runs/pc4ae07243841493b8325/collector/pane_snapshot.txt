The statement is **false** in general. I'll provide a counterexample with $r = 2
$.

## Counterexample

Let $K = \mathbb{Q}$. Let $\omega = e^{2\pi i/3}$ be a primitive cube root of un
ity, and let $\alpha = \sqrt[3]{2}$.

Set:
- $L = \mathbb{Q}(\omega)$,
- $E_1 = \mathbb{Q}(\alpha)$,
- $E_2 = \mathbb{Q}(\omega\alpha)$.

### Verification that $L \cap E_i = K$ for $i = 1, 2$

**Degrees.** The minimal polynomial of $\omega$ over $\mathbb{Q}$ is $x^2 + x +
1$, so $[L : \mathbb{Q}] = 2$. The element $\alpha$ is a root of $x^3 - 2$, whic
h is irreducible over $\mathbb{Q}$ by Eisenstein's criterion at $p = 2$, so $[E_
1 : \mathbb{Q}] = 3$. Likewise, $(\omega\alpha)^3 = \omega^3 \alpha^3 = 2$, so $
\omega\alpha$ is also a root of $x^3 - 2$; by irreducibility, $[E_2 : \mathbb{Q}
] = 3$.

**Intersection.** Let $F_i = L \cap E_i$. By the tower law, $[F_i : \mathbb{Q}]$
 divides both $[L : \mathbb{Q}] = 2$ and $[E_i : \mathbb{Q}] = 3$. Hence $[F_i :
 \mathbb{Q}] \mid \gcd(2, 3) = 1$, so $F_i = \mathbb{Q} = K$ for $i = 1, 2$.

### The composite $E = E_1 E_2$

We have $E = E_1 E_2 = \mathbb{Q}(\alpha, \omega\alpha)$. Since
$$\omega = \frac{\omega\alpha}{\alpha} \in \mathbb{Q}(\alpha, \omega\alpha),$$
it follows that $E = \mathbb{Q}(\alpha, \omega)$, which is the splitting field o
f $x^3 - 2$ over $\mathbb{Q}$.

### $L \cap E \neq K$

Since $L = \mathbb{Q}(\omega) \subseteq \mathbb{Q}(\alpha, \omega) = E$, we have
$$L \cap E = L = \mathbb{Q}(\omega) \neq \mathbb{Q} = K.$$

### Conclusion

We have exhibited field extensions $L/K$ and $E_1/K$, $E_2/K$ (with $r = 2$) sat
isfying $L \cap E_i = K$ for each $i$, yet $L \cap (E_1 E_2) = L \neq K$. Theref
ore the statement is **disproven**: the condition $L \cap E_i = K$ for all $i$ d
oes not imply $L \cap (E_1 \cdots E_r) = K$ in general.

**Remark.** The statement does hold under additional hypotheses — for instance,
if $L/K$ is Galois and the $E_i/K$ are linearly disjoint over $K$ in a suitable
sense, or if $[L:K]$ and $[E_i:K]$ are pairwise coprime for all $i$ simultaneous
ly (a stronger condition than pairwise coprimality with $L$ alone). The countere
xample exploits the fact that $E_1$ and $E_2$, while each intersecting $L$ trivi
ally, together generate $\omega$ — an element of $L$ — through their ratio.
