反例构造

取 $X = \mathbb{R}^4$，$B$ 由矩阵 $\operatorname{diag}(1, -1, 1, -1)$ 给出，即
$B(e_i, e_j) = 0$（$i \neq
j$），$B(e_1,e_1)=B(e_3,e_3)=1$，$B(e_2,e_2)=B(e_4,e_4)=-1$。$B$ 是非退化的。

设 $$M = \operatorname{span}(e_1+e_2,; e_3+e_4), \qquad N = \operatorname{span}
(e_1+e_2+e_3-e_4,; e_1+e_2-e_3+e_4).$$

验证 $M$ 全迷向： $B(e_1+e_2,, e_1+e_2) = 1 + (-1) = 0$，$B(e_3+e_4,, e_3+e_4) =
1 + (-1) = 0$，$B(e_1+e_2,, e_3+e_4) = 0$。✓

验证 $N$ 全迷向： 记 $n_1 = e_1+e_2+e_3-e_4$，$n_2 = e_1+e_2-e_3+e_4$。

  • $B(n_1, n_1) = 1 - 1 + 1 - 1 = 0$，$B(n_2, n_2) = 1 - 1 + 1 - 1 = 0$。
  • $B(n_1, n_2) = 1 - 1 - 1 + 1 = 0$。✓

验证 $M \cap N = {0}$： 设 $a(e_1+e_2) + b(e_3+e_4) = c, n_1 + d, n_2$。比较分

  • $e_1$: $a = c + d$
  • $e_3$: $b = c - d$
  • $e_4$: $b = -(c - d)$

由后两式得 $b = 0,, c = d$；代入第一式得 $a = 2c$。若 $c = 0$ 则全为零。故 $M
\cap N = {0}$。✓

$\dim M = \dim N = 2 = r$，取 $s = 1 < r$。

f_1^{(0)}) = 0$ 得 $e_2 \in M \cap (f_1^{(0)})^\perp$。

计算：

  • $M \cap (f_1^{(0)})^\perp$：$B(e_1+e_2,, f_1^{(0)}) = \tfrac{1}{2}(1 - 1 + 0

矛盾

因此 $e_2 = \alpha(e_1+e_2)$，$f_2 = \beta(e_1+e_2)$，但

$$B(e_2,, f_2) = \alpha\beta, B(e_1+e_2,; e_1+e_2) = \alpha\beta \cdot (1 - 1) =

而扩展要求 $B(e_2, f_2) = \delta_{22} = 1 \neq 0$。矛盾。
