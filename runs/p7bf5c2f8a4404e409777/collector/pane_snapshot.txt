## Setting up the congruence

We need $15^x \equiv x \pmod{1000}$. Since $1000 = 8 \times 125$ with $\gcd(8,12
5)=1$, we split into:

$$15^x \equiv x \pmod{8} \qquad\text{and}\qquad 15^x \equiv x \pmod{125}.$$

## Mod 125

Since $15 = 3 \cdot 5$, for $x \geq 3$ we have $5^x \mid 5^3 = 125$, so
$$15^x = 3^x \cdot 5^x \equiv 0 \pmod{125} \quad (x \geq 3).$$
Thus we need $x \equiv 0 \pmod{125}$, i.e. $x = 125k$ for some positive integer
$k$.

(Checking small cases: $x=0$: $15^0=1\not\equiv 0$; $x=1$: $15\not\equiv 1$; $x=
2$: $225\not\equiv 2$. No solutions with $x<3$.)

## Mod 8

Since $15 \equiv -1 \pmod{8}$, we have $15^x \equiv (-1)^x \pmod{8}$.

- **$x$ even:** $15^x \equiv 1 \pmod 8$, so $x \equiv 1 \pmod 8$.
- **$x$ odd:** $15^x \equiv 7 \pmod 8$, so $x \equiv 7 \pmod 8$.

## Combining via $x = 125k$

Since $125 \equiv 5 \pmod 8$, we get $x = 125k \equiv 5k \pmod 8$.

**Case $k$ even** ($x$ even): need $5k \equiv 1 \pmod 8$, giving $k \equiv 5 \pm
od 8$ (since $5^{-1}\equiv 5$). But $k\equiv 5\pmod 8$ is **odd**, contradicting
 $k$ even. ✗ No solutions.

**Case $k$ odd** ($x$ odd): need $5k \equiv 7 \pmod 8$, giving $k \equiv 5\cdot
7 = 35 \equiv 3 \pmod 8$. This is **odd**, consistent. ✓

So $k \equiv 3 \pmod 8$, i.e. $k = 8m + 3$ for $m \geq 0$.

## The solution set

$$x = 125(8m+3) = 1000m + 375, \qquad m = 0, 1, 2, \ldots$$

The solutions are $x = 375,\; 1375,\; 2375,\; \ldots$, i.e. exactly one solution
 per block of 1000, all satisfying $x \equiv 375 \pmod{1000}$.

## Verification of the base case $x = 375$

- **Mod 125:** $375 \geq 3 \Rightarrow 15^{375}\equiv 0\pmod{125}$, and $375 = 3
\times 125 \equiv 0\pmod{125}$. ✓
- **Mod 8:** $375$ odd $\Rightarrow 15^{375}\equiv (-1)^{375}\equiv 7\pmod 8$, a
nd $375 = 46\times 8 + 7 \equiv 7\pmod 8$. ✓

By CRT, $15^{375}\equiv 375\pmod{1000}$. ✓

## The 2018th value

The $n$-th solution is $x_n = 375 + 1000(n-1)$. For $n = 2018$:

$$x_{2018} = 375 + 1000 \times 2017 = 375 + 2{,}017{,}000 = \boxed{2{,}017{,}375
}.$$

**Final check:** $2017375 \equiv 375 \pmod{1000}$, $2017375 = 125 \times 16139 \
equiv 0\pmod{125}$, and $2017375 = 252171\times 8 + 7 \equiv 7\pmod{8}$ — all co
nditions satisfied.
