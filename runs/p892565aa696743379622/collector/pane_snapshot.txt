## Proof

We find the norm of the Volterra operator $A: L_2(0,1) \to L_2(0,1)$ defined by
$$(Ax)(t) = \int_0^t x(s)\,ds.$$

### Step 1. Reduce to the spectrum of $A^*A$

$A$ is a Hilbert–Schmidt operator with kernel $K(t,s) = \mathbf{1}_{\{s \le t\}}
$ (square-integrable on $[0,1]^2$), hence compact. Therefore $A^*A$ is compact,
self-adjoint, and positive, and by the standard identity for bounded operators o
n a Hilbert space,
$$\|A\|^2 = \|A^*A\| = \lambda_{\max}(A^*A),$$
the largest eigenvalue of $A^*A$. So it suffices to find the eigenvalues of $A^*
A$.

### Step 2. Compute $A^*$ and $A^*A$

For $x, y \in L_2(0,1)$,
$$\langle Ax, y\rangle = \int_0^1 \left(\int_0^t x(s)\,ds\right) y(t)\,dt = \int
_0^1 x(s)\left(\int_s^1 y(t)\,dt\right) ds = \langle x, A^*y\rangle,$$
so $(A^*y)(s) = \int_s^1 y(t)\,dt$. Then
$$(A^*A x)(s) = \int_s^1 (Ax)(t)\,dt = \int_s^1 \int_0^t x(u)\,du\,dt.$$

### Step 3. Convert the eigenvalue problem to an ODE

Let $A^*A x = \mu x$ with $\mu > 0$. Set $g(s) = (A^*A x)(s) = \int_s^1 \int_0^t
 x(u)\,du\,dt$. Differentiating (everything is smooth enough since $g$ is $C^2$)
:

- $g'(s) = -\int_0^s x(u)\,du = -(Ax)(s)$,
- $g''(s) = -x(s)$.

Since $g = \mu x$, we get $x = g/\mu$, hence
$$g''(s) = -\frac{g(s)}{\mu}, \qquad\text{i.e.}\qquad g''(s) + \frac{1}{\mu}\,g(
s) = 0.$$

**Boundary conditions.**
- At $s = 1$: $g(1) = \int_1^1(\cdots)\,dt = 0$, so $\mu\, x(1) = 0 \Rightarrow
x(1) = 0$.
- At $s = 0$: $g'(0) = -\int_0^0 x(u)\,du = 0$, so $\mu\, x'(0) = 0 \Rightarrow
x'(0) = 0$.

### Step 4. Solve the ODE

The general solution of $g'' + \frac{1}{\mu}g = 0$ is
$$g(s) = C\cos\!\left(\frac{s}{\sqrt{\mu}}\right) + D\sin\!\left(\frac{s}{\sqrt{
\mu}}\right).$$

The condition $g'(0) = 0$ gives $D = 0$, so $g(s) = C\cos(s/\sqrt{\mu})$, i.e. $
x(s) = \frac{C}{\mu}\cos(s/\sqrt{\mu})$.

The condition $x(1) = 0$ (equivalently $g(1) = 0$) requires
$$\cos\!\left(\frac{1}{\sqrt{\mu}}\right) = 0 \quad\Longrightarrow\quad \frac{1}
{\sqrt{\mu}} = \frac{(2k-1)\pi}{2},\quad k = 1, 2, 3, \dots$$

Thus the eigenvalues of $A^*A$ are
$$\mu_k = \frac{4}{(2k-1)^2 \pi^2}, \qquad k = 1, 2, 3, \dots$$

with eigenfunctions $x_k(s) = \cos\!\bigl(\tfrac{(2k-1)\pi}{2}\,s\bigr)$.

### Step 5. Conclude

The largest eigenvalue is $\mu_1 = \dfrac{4}{\pi^2}$, attained by $x_1(s) = \cos
\!\bigl(\tfrac{\pi s}{2}\bigr)$. Therefore
$$\|A\|^2 = \mu_1 = \frac{4}{\pi^2}, \qquad \|A\| = \frac{2}{\pi}.$$

**Verification that the bound is attained.** For $x_1(s) = \cos\!\bigl(\tfrac{\p
i s}{2}\bigr)$, which has $\|x_1\|_2^2 = \int_0^1 \cos^2\!\bigl(\tfrac{\pi s}{2}
\bigr)\,ds = \tfrac{1}{2}$, we have $A^*A x_1 = \tfrac{4}{\pi^2} x_1$, so $\|Ax_
1\|^2 = \langle A^*A x_1, x_1\rangle = \tfrac{4}{\pi^2}\|x_1\|^2$, giving $\|Ax_
1\|/\|x_1\| = 2/\pi$. The supremum is achieved.

$$\boxed{\|A\| = \dfrac{2}{\pi}}$$
