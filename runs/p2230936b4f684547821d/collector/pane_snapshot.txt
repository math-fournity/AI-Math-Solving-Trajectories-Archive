# IMO 2006 Problem 5 — Proof

Let $P(x) \in \mathbb{Z}[x]$ have degree $n > 1$, let $k \geq 1$, and set $Q(x)
= P^{(k)}(x)$ (the $k$-fold composition). Let

$$S = \{t \in \mathbb{Z} : Q(t) = t\}.$$

We prove $|S| \leq n$.

---

**Step 1. A divisibility fact.**

Since $P$ has integer coefficients, $P(x) - P(y)$ is divisible by $x - y$ in $\m
athbb{Z}[x,y]$: writing $P(x) = \sum_{i=0}^{n} a_i x^i$,

$$P(x) - P(y) = (x - y)\underbrace{\sum_{i=1}^{n} a_i \sum_{j=0}^{i-1} x^{i-1-j}
\, y^{j}}_{M(x,y)},$$

where $M \in \mathbb{Z}[x,y]$. Consequently, for any integers $a \neq b$,

$$(a - b) \mid \bigl(P(a) - P(b)\bigr), \qquad\text{hence}\qquad |P(a) - P(b)| \
geq |a - b|.$$

---

**Step 2. $P$ is injective on $S$.**

If $a, b \in S$ with $a \neq b$ but $P(a) = P(b)$, then applying $P^{(k-1)}$ to
both sides gives $P^{(k)}(a) = P^{(k)}(b)$, i.e. $a = b$, a contradiction. So $P
$ is injective on $S$.

---

**Step 3. $P$ preserves all pairwise distances on $S$.**

Take $a, b \in S$, $a \neq b$. By Step 1 applied successively (and injectivity f
rom Step 2, which guarantees each difference is nonzero):

$$|a - b| \;\leq\; |P(a) - P(b)| \;\leq\; |P^{(2)}(a) - P^{(2)}(b)| \;\leq\; \cd
ots \;\leq\; |P^{(k)}(a) - P^{(k)}(b)|.$$

But $P^{(k)}(a) = a$ and $P^{(k)}(b) = b$, so the right-hand side equals $|a - b
|$. Therefore **every** inequality is an equality:

$$|P(a) - P(b)| = |a - b| \qquad \text{for all } a, b \in S.$$

Thus $P\big|_S$ is a distance-preserving bijection of the finite set $S \subset
\mathbb{R}$.

---

**Step 4. An isometry of a finite subset of $\mathbb{R}$ is a translation or a r
eflection.**

Let $S = \{s_1 < s_2 < \cdots < s_m\}$ and let $f : S \to S$ preserve all pairwi
se distances. Since $|f(s_1) - f(s_m)| = s_m - s_1$ and both images lie in $[s_1
, s_m]$, either

- **(order-preserving)** $f(s_1) = s_1,\; f(s_m) = s_m$, or
- **(order-reversing)** $f(s_1) = s_m,\; f(s_m) = s_1$.

In the **order-preserving** case, for every $s_i$ we have $f(s_i) \in [s_1, s_m]
$ with $|f(s_i) - s_1| = s_i - s_1$, forcing $f(s_i) = s_i$. Hence $f$ is the **
identity** (a translation by $0$).

In the **order-reversing** case, $|f(s_i) - s_m| = s_i - s_1$ gives $f(s_i) = s_
1 + s_m - s_i$ (the other solution exceeds $s_m$). Hence $f(s) = c - s$ where $c
 = s_1 + s_m$, a **reflection**.

---

**Step 5. Conclusion.**

Applying Step 4 to $f = P\big|_S$:

**Case A: $P(t) = t$ for all $t \in S$.** Then every $t \in S$ is a root of $P(x
) - x$. Since $\deg P = n > 1$, we have $\deg(P(x) - x) = n$, so $|S| \leq n$.

**Case B: $P(t) = c - t$ for all $t \in S$** (for some constant $c$). Then every
 $t \in S$ is a root of $P(x) + x - c$. Since $\deg P = n > 1$, we have $\deg(P(
x) + x - c) = n$, so $|S| \leq n$.

In both cases, $|S| \leq n$. $\blacksquare$
