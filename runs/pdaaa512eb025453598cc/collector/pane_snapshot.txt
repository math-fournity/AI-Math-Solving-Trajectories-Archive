## Solution

We seek an analytic function $f(z)$ with $|f(z)| = e^{\rho^2 \cos 2\theta}$, whe
re $z = \rho e^{i\theta}$, $x = \rho\cos\theta$, $y = \rho\sin\theta$.

**Step 1: Rewrite the modulus in Cartesian form.**

Using $\rho^2\cos 2\theta = \rho^2(\cos^2\theta - \sin^2\theta) = x^2 - y^2$, th
e condition becomes

$$|f(z)| = e^{x^2 - y^2}.$$

**Step 2: Introduce the logarithm.**

Since $|f(z)| = e^{x^2-y^2} \neq 0$ everywhere, $f$ is zero-free and we may defi
ne (locally) $g(z) = \log f(z) = U(x,y) + iV(x,y)$, where

$$U(x,y) = \ln|f(z)| = x^2 - y^2, \qquad V(x,y) = \arg f(z).$$

If $f$ is analytic and zero-free, then $g = \log f$ is analytic, so $U$ and $V$
must satisfy the Cauchy–Riemann equations:

$$U_x = V_y, \qquad U_y = -V_x.$$

**Step 3: Apply the Cauchy–Riemann conditions.**

Compute the partial derivatives of $U$:

$$U_x = 2x, \qquad U_y = -2y.$$

From $U_x = V_y$:

$$V_y = 2x \implies V(x,y) = 2xy + h(x).$$

From $U_y = -V_x$:

$$V_x = -U_y = 2y.$$

But differentiating our expression for $V$ gives $V_x = 2y + h'(x)$. Hence

$$2y + h'(x) = 2y \implies h'(x) = 0 \implies h(x) = C \quad (C \in \mathbb{R}).
$$

Therefore

$$V(x,y) = 2xy + C.$$

**Step 4: Reconstruct $f(z)$.**

$$g(z) = U + iV = (x^2 - y^2) + i(2xy + C) = (x^2 - y^2 + 2ixy) + iC = (x+iy)^2
+ iC = z^2 + iC.$$

Exponentiating,

$$f(z) = e^{g(z)} = e^{z^2 + iC} = e^{iC}\, e^{z^2}.$$

**Step 5: Verification.**

$$|f(z)| = \left|e^{iC}\right|\cdot\left|e^{z^2}\right| = 1 \cdot e^{\operatorna
me{Re}(z^2)} = e^{x^2 - y^2} = e^{\rho^2 \cos 2\theta}. \checkmark$$

Since $e^{iC}$ is a constant of unit modulus, the simplest choice (taking $C = 0
$) is

$$\boxed{f(z) = e^{z^2}}.$$

More generally, $f(z) = e^{iC}e^{z^2}$ for any real constant $C$ satisfies the g
iven condition.
