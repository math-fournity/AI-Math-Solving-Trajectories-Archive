## Solution

**Setup.** Let $a_{ij}$ be the power value at position $(i,j)$, with $a_{ij} \ne
q 0$ for all $i,j$. Define row sums $R_i = \sum_{j=1}^n a_{ij}$ and column sums
$C_j = \sum_{i=1}^n a_{ij}$, and total sum $S = \sum_i R_i = \sum_j C_j$.

**Deriving the key equation.** The balance constraint states that for every $(i,
j)$:
$$\underbrace{(R_i - a_{ij})}_{\text{rest of row } i} + \underbrace{(C_j - a_{ij
})}_{\text{rest of col } j} = k \cdot a_{ij}$$
$$\Longrightarrow \quad R_i + C_j = (k+2)\,a_{ij} \quad \text{for all } i,j. \ta
g{1}$$

**Summing over $j$ (fixed $i$).** From (1): $R_i = \sum_j a_{ij} = \frac{1}{k+2}
\sum_j (R_i + C_j) = \frac{nR_i + S}{k+2}$, giving:
$$(k+2-n)\,R_i = S \quad \text{for all } i. \tag{2}$$

By symmetry (summing over $i$ for fixed $j$): $(k+2-n)\,C_j = S$ for all $j$.

**Case 1: $k + 2 - n \neq 0$.** Then every $R_i = \frac{S}{k+2-n}$ (all rows hav
e equal sum $R$) and every $C_j = \frac{S}{k+2-n}$ (all columns have equal sum $
C$). Since $S = nR = nC$, we get $R = C = S/n$. Then from (1):
$$a_{ij} = \frac{R + C}{k+2} = \frac{2S/n}{k+2},$$
which is **constant** for all $(i,j)$. Setting $a_{ij} = a \neq 0$: the constrai
nt gives $2(n-1)a = ka$, so:
$$\boxed{k = 2(n-1) = 4048.}$$

**Case 2: $k + 2 - n = 0$, i.e., $k = n - 2 = 2023$.** Then (2) forces $S = 0$.
Equation (1) becomes $a_{ij} = \frac{R_i + C_j}{n}$. The self-consistency condit
ions reduce to $\sum_i R_i = 0$ and $\sum_j C_j = 0$ (both equivalent to $S=0$).

**Existence of a valid (all-nonzero) configuration.** Set $x_i = R_i$ and $y_j =
 C_j$ with:
- $x_i = 2i - (n+1)$ for $i = 1,\dots,n$: these are **odd** integers, $\sum x_i
= 0$, and no $x_i = 0$.
- $y_j = \sqrt{2}\,(2j - (n+1))$ for $j = 1,\dots,n$: these are $\sqrt{2}$ times
 odd integers, $\sum y_j = 0$, and no $y_j = 0$.

Then $a_{ij} = \frac{x_i + y_j}{n}$. We check $x_i + y_j = 0$ would require $m +
 \sqrt{2}\,m' = 0$ where $m, m'$ are odd integers — impossible since $\sqrt{2}$
is irrational and $m, m' \neq 0$. Hence **all $a_{ij} \neq 0$**, confirming $k =
 2023$ is achievable.

**No other values.** Equation (2) admits only the two cases above (either the co
efficient vanishes or all $R_i$ are forced equal), so the complete set of possib
le $k$ values is $\{2(n-1),\; n-2\}$.

**Computing $K(2025)$.**
$$K(n) = 2(n-1) + (n-2) = 3n - 4.$$
$$K(2025) = 3 \times 2025 - 4 = 6075 - 4 = \boxed{6071}.$$
