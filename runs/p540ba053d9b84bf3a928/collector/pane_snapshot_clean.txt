## Key Counting Lemma

**Claim:** For sequences $(a_1, \ldots, a_n)$ with $1 \le a_i \le i$, the number
 with $a_n = m$ equals $(n-1)!$ for every $1 \le m \le n$.

*Proof:* By induction. Base: $n=1$, only $a_1=1$, count $=1=0!$. Inductive step:
 $f(n+1, m') = \sum_{m=1}^{n} f(n,m) = n \cdot (n-1)! = n!$, independent of $m'$
. ✓

More generally, if position $t$ has upper bound $U_t$, the count with last value
 $m$ is $\prod_{t=1}^{n-1} U_t$ (independent of $m$).

## Computing $M_k$ (sequences where $a_k$ is a mountain)

Fix $k$ with $2 \le k \le 2^{16}-1$. We need $a_k > a_{k-1}$ and $a_k > a_{k+1}$
.

- **Left part** $(a_1, \ldots, a_{k-1})$ with $a_{k-1} = j$: by the lemma, count
 $= (k-2)!$ for each $j \in \{1, \ldots, k-1\}$.
- **Right part** $(a_{k+1}, \ldots, a_{2^{16}})$ with $a_{k+1} = j'$: bounds are
 $k+1, k+2, \ldots, 2^{16}$, so count $= \prod_{s=k+2}^{2^{16}} s = \frac{(2^{16
})!}{(k+1)!}$ for each $j' \in \{1, \ldots, k+1\}$.

Setting $a_k = v$ (where $1 \le v \le k$), we need $a_{k-1} \le v-1$ and $a_{k+1
} \le v-1$. Since $v \le k$, both sums run over $\{1, \ldots, v-1\}$:

$$M_k = \sum_{v=2}^{k} \left[(v-1)(k-2)!\right]\left[(v-1)\frac{(2^{16})!}{(k+1)
!}\right] = (k-2)!\cdot\frac{(2^{16})!}{(k+1)!}\sum_{u=1}^{k-1} u^2$$

Using $\sum_{u=1}^{k-1} u^2 = \frac{(k-1)k(2k-1)}{6}$ and $(k-2)!\cdot(k-1)\cdot
 k = k!$:

$$M_k = \frac{(2^{16})!\cdot k!\cdot(2k-1)}{6\cdot(k+1)!} = \frac{(2^{16})!\,(2k
-1)}{6(k+1)}$$

**Verification ($n=4$):** $M_2 = \frac{24\cdot 3}{18}=4$, $M_3 = \frac{24\cdot 5
}{24}=5$. Direct count confirms $M_2=4$, $M_3=5$. ✓

## Summing Over All $k$

Let $M = (2^{16})!$. Then:

$$N = \frac{M}{6}\sum_{k=2}^{2^{16}-1}\frac{2k-1}{k+1} = \frac{M}{6}\sum_{k=2}^{
2^{16}-1}\left(2 - \frac{3}{k+1}\right)$$

$$= \frac{M}{6}\left(2(2^{16}-2) - 3\sum_{j=3}^{2^{16}}\frac{1}{j}\right) = \fra

}{6}\left(2^{17}+\tfrac{1}{2}-3H_{2^{16}}\right)$$

$$= \frac{M(2^{18}+1)}{12} - \frac{M\cdot H_{2^{16}}}{2}$$

## Reducing Modulo $p = 2^{16}+1 = 65537$

Since $2^{16} = p-1$, by **Wilson's theorem**: $M = (p-1)! \equiv -1 \pmod{p}$.

**Second term:** $M\cdot H_{2^{16}} = \sum_{j=1}^{p-1}\frac{M}{j} \equiv \sum_{j
=1}^{p-1}\frac{-1}{j} \equiv -\sum_{j=1}^{p-1}j \equiv -\frac{(p-1)p}{2} \equiv
0 \pmod{p}$.

**First term:** $2^{16} \equiv -1 \pmod{p}$, so $2^{18} = 4\cdot 2^{16} \equiv -
4 \pmod{p}$, giving $2^{18}+1 \equiv -3 \pmod{p}$.

$$N \equiv \frac{(-1)(-3)}{12} = \frac{3}{12} = \frac{1}{4} \pmod{p}$$

**Computing $4^{-1} \pmod{65537}$:** Since $4\cdot 16384 = 65536 \equiv -1 \pmod
