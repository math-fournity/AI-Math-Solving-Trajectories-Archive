## Solution

**Setup.** $L = \{x \in C[0,1] : x \text{ is constant}\}$, with the sup norm $\|
x\| = \max_{t\in[0,1]}|x(t)|$. The functional $f_0 \in L^*$ is $f_0(x) = x(0)$;
for a constant $x \equiv c$ this gives $f_0(x)=c$, so $\|f_0\| = 1$ (attained at
 $x\equiv 1$).

The space $L_1 = \operatorname{span}(L, t)$ consists of all affine functions $x(
t) = a + bt$, $a,b\in\mathbb{R}$.

**Claim.** The functional $f \in L_1^*$ defined by
$$\boxed{\,f(x) = x(0)\,}$$
i.e. $f(a+bt) = a$, satisfies $f|_L = f_0$ and $\|f\| = \|f_0\| = 1$.

**Proof that $f|_L = f_0$.** For $x \in L$, $x$ is constant, so $x(0) = x(t)$ fo
r all $t$, and $f(x) = x(0) = f_0(x)$. ✓

**Proof that $\|f\| = 1$.**

*Lower bound.* Take $x(t) \equiv 1 \in L_1$. Then $\|x\| = 1$ and $|f(x)| = |1|
= 1$, so $\|f\| \ge 1$.

*Upper bound.* For any $x(t) = a+bt \in L_1$,
$$|f(x)| = |a| = |a + b\cdot 0| = |x(0)| \le \max_{t\in[0,1]}|x(t)| = \|x\|,$$
since $0 \in [0,1]$. Hence $|f(x)| \le \|x\|$ for all $x\in L_1$, giving $\|f\|
\le 1$.

Combining, $\|f\| = 1 = \|f_0\|$.

**Remark (Hahn–Banach context).** This is exactly the Hahn–Banach extension of $
f_0$ from $L$ to $L_1$: $f_0$ extends to all of $C[0,1]$ as the evaluation funct
ional $\delta_0(x)=x(0)$ with norm $1$, and restricting this extension to $L_1$
yields the $f$ above. (In fact any evaluation $\delta_{t_0}$ with $t_0\in[0,1]$
also extends $f_0$ with norm $1$, since constants are unchanged; the canonical c
hoice is $t_0 = 0$.)
