## Setup

Place the unit square with opposite vertices **A** = (−√2/2, 0) and **B** = (√2/
2, 0). The circumcircle Γ has center (0,0) and radius √2/2. Since AB is a diamet
er of Γ, angle ACB = 90° for all C on Γ (excluding A, B).

Parameterize C = (√2/2 cos θ, √2/2 sin θ). Set t = θ/2 and α = t + π/4, so:
- **U** = sin α = (sin t + cos t)/√2, **V** = cos α = (cos t − sin t)/√2, with U
² + V² = 1.

## Computing C₁ and I

For the right triangle with legs a = √2 sin t, b = √2 cos t, hypotenuse c = √2:

**C₁** (incircle touch point on AB) = ((b−a)/2, 0) = (V, 0).

The incenter **I** = (a·A + b·B + c·C)/(a+b+c). After simplification using cos 2
t = UV·2 and sin 2t = 2U²−1:

**I** = (V, U − 1/√2) = (V, r), where r = U − 1/√2 is the inradius.

This confirms I is directly above C₁ (both have x-coordinate V), as expected sin
ce the radius to AB is vertical.

## Computing D (reflection of C₁ over line CI)

**C** = (sin 2α/√2, (2sin²α − 1)/√2). The direction of line CI:

C − I = (√2 sin α − 1)(V, sin α),

so line CI has **unit direction** ê = (cos α, sin α).

Using the reflection formula D = 2·foot − P, where foot = Q + ((P−Q)·ê)ê:

- P − Q = C₁ − I = (0, 1/√2 − sin α)
- (P − Q)·ê = sin α/√2 − sin²α

After expansion:

**x_D** = cos α(1 + √2 sin α − 2sin²α)

**y_D** = cos²α(2 sin α − √2)

## Verifying endpoints

- α = π/4 (C = B): x_D = (1/√2)(1 + 1 − 1) = 1/√2, y_D = (1/2)(√2 − √2) = 0 → D
= B ✓
- α = 3π/4 (C = A): x_D = (−1/√2)(1 + 1 − 1) = −1/√2, y_D = 0 → D = A ✓
- α = π/2 (C at top): x_D = 0, y_D = 0 → D = origin (midpoint of AB) ✓

## Curve structure

The upper half (α: π/4 → 3π/4) traces B → (above x-axis) → origin → (above x-axi
s) → A. By reflection symmetry over AB, the lower half traces A → (below x-axis)
 → origin → (below x-axis) → B. The curve self-intersects at the origin, forming
 **two lobes** (left and right), both traversed counterclockwise.

## Area via Green's Theorem

Computing x·(dy/dα) − y·(dx/dα) with x = cos α·f, y = cos²α·g, where f = 1 + √2
sin α − 2sin²α and g = 2 sin α − √2:

After careful differentiation and simplification (verified at α = π/3):

$$x\,y' - y\,x' = \cos^2\alpha\,(4 - 3\sqrt{2}\sin\alpha)$$

Both halves contribute equally (by the y → −y symmetry), so:

$$\mathcal{A} = \frac{1}{2}\oint (x\,dy - y\,dx) = \int_{\pi/4}^{3\pi/4} \cos^2\
alpha\,(4 - 3\sqrt{2}\sin\alpha)\,d\alpha$$

**First integral:** 4∫cos²α dα = 4[α/2 + sin 2α/4] from π/4 to 3π/4 = 4(π/4 − 1/
2) = **π − 2**

**Second integral:** 3√2 ∫cos²α sin α dα = 3√2[−cos³α/3] from π/4 to 3π/4 = 3√2
· 1/(3√2) = **1**

$$\mathcal{A} = (\pi - 2) - 1 = \pi - 3$$

## Verification

The right lobe area = ∫_{π/4}^{π/2} cos²α(4 − 3√2 sin α) dα = (π/2 − 1) − 1/2 =
(π − 3)/2, confirming total area = 2 × (π−3)/2 = π − 3. ✓
