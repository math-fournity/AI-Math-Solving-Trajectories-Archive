# Problem

In a specialized telecommunications network, there are $n$ servers (where $n \geq 4$), and every single server is initially connected to every other server by a direct fiber-optic cable. This creates a fully interconnected web where every possible pair of servers has a unique dedicated link.

An optimization protocol is introduced to reduce redundancy in the network. The protocol allows for a specific "link-decommissioning" action: if any four servers form a closed loop of exactly four cables (a square path), the network administrator can select any one cable within that specific loop and remove it. This action can be repeated as many times as possible, provided a loop of four cables can still be identified among the remaining connections.

For a fixed number of servers $n$, find the minimum possible number of fiber-optic cables that could remain in the network after the administrator has performed this operation as many times as they wish.
