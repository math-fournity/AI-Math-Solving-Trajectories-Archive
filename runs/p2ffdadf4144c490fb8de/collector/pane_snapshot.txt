### Setup

Digits are chosen uniformly from {1, …, 9} (no 0). A number is divisible by 25 i
ff its last two digits form 00, 25, 50, or 75. Since 0 is unavailable, the **onl
y** stopping endings are **25** and **75**. Thus the process stops exactly when
we append a **5** and the previous digit is **2** or **7**.

### Markov chain

After the first chip, the state is the last digit $d \in \{1,\dots,9\}$. Let $E_
d$ = expected additional chips from state $d$, and $E_S$ = expected total chips
from the blank start.

From state $d$, we place one chip (cost 1), then:
- If $d \in \{2,7\}$ and we draw $c=5$: **stop** (future cost 0).
- Otherwise: transition to state $c$.

Let $S = \sum_{c=1}^{9} E_c$.

**For $d \in \{2,7\}$** (the digit 5 leads to stopping):
$$E_d = 1 + \frac{1}{9}\sum_{c \neq 5} E_c = 1 + \frac{S - E_5}{9}$$

**For $d \notin \{2,7\}$** (drawing 5 just goes to state 5):
$$E_d = 1 + \frac{1}{9}\sum_{c=1}^{9} E_c = 1 + \frac{S}{9}$$

### Solving the system

All digits $\notin \{2,7\}$ share the same value; call it $A$. Digits $\{2,7\}$
share value $C$. There are 7 digits with value $A$ (namely {1,3,4,5,6,8,9}) and
2 with value $C$.

$$S = 7A + 2C$$

From the general equation: $A = 1 + S/9$, so $S = 9A - 9$.

From the {2,7} equation: $C = 1 + (S-A)/9$, so $S = 9C - 9 + A$.

Equating: $9A - 9 = 9C - 9 + A \Rightarrow 8A = 9C \Rightarrow C = \frac{8A}{9}$
.

Substituting into $S = 7A + 2C$:
$$S = 7A + \frac{16A}{9} = \frac{79A}{9}$$

Using $S = 9A - 9$:
$$\frac{79A}{9} = 9A - 9 \Rightarrow 79A = 81A - 81 \Rightarrow 2A = 81 \Rightar
row A = \frac{81}{2}$$

Then $C = \frac{8}{9}\cdot\frac{81}{2} = 36$, and $S = \frac{79}{9}\cdot\frac{81
}{2} = \frac{711}{2}$.

### From the start

$$E_S = 1 + \frac{1}{9}\sum_{d=1}^{9} E_d = 1 + \frac{S}{9} = 1 + \frac{711/2}{9
} = 1 + \frac{79}{2} = \frac{81}{2}$$
