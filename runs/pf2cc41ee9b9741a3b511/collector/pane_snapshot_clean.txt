## Proof

We show that $\lim_{n\to\infty}\mathbb{P}[G(n,n,p)\text{ is connected}]=0$.

**Setup.** $G(n,n,p)$ is a random bipartite graph with two parts $A$ and $B$, ea
ch of size $n$, where each of the $n^2$ possible cross-edges is present independ
ently with probability $p$. The hypothesis is $np=\ln n+w(n)$ with $w(n)\to-\inf
ty$.

**Key obstruction: isolated vertices.** A graph with any isolated vertex is disc
onnected. Let $X$ be the number of isolated vertices in $G(n,n,p)$. We show $X\t
o\infty$ in probability, which forces $\mathbb{P}[\text{connected}]\to 0$.

**First moment.** For a fixed vertex $v\in A\cup B$, its degree is $\mathrm{Bino
mial}(n,p)$, so
$$\mathbb{P}[v\text{ isolated}]=(1-p)^n\le e^{-np}=e^{-\ln n-w(n)}=\frac{e^{-w(n
)}}{n}.$$
Since $|A\cup B|=2n$,
$$\mathbb{E}[X]=2n\cdot(1-p)^n\le 2n\cdot\frac{e^{-w(n)}}{n}=2e^{-w(n)}\xrightar
row{n\to\infty}\infty,$$
because $w(n)\to-\infty$.

**Second moment (variance control).** Write $X=\sum_v \mathbf{1}_v$ where $\math
bf{1}_v$ indicates that $v$ is isolated. For two distinct vertices $u,v$:
- If $u,v$ are in the **same part** (both in $A$ or both in $B$), their isolatio
n events are independent (they depend on disjoint sets of edges), so $\mathbb{P}
[u,v\text{ both isolated}]=\mathbb{P}[u\text{ isolated}]\cdot\mathbb{P}[v\text{
isolated}]$.
- If $u\in A$, $v\in B$ are in **opposite parts**, the edge $uv$ must be absent
in both events, so
$$\mathbb{P}[u,v\text{ both isolated}]=(1-p)^{2n-1}.$$

Let $q=(1-p)^n$. Then $\mathbb{E}[X]=2nq$. For the covariance:
$$\mathrm{Var}(X)=\sum_v \mathrm{Var}(\mathbf{1}_v)+\sum_{u\ne v}\mathrm{Cov}(\m
athbf{1}_u,\mathbf{1}_v).$$

The same-part pairs contribute $0$ covariance. The opposite-part pairs: there ar
e $n^2$ such pairs, each with
$$\mathrm{Cov}(\mathbf{1}_u,\mathbf{1}_v)=(1-p)^{2n-1}-q^2=(1-p)^{2n}\left[\frac
{1}{1-p}-1\right]=\frac{p(1-p)^{2n}}{1-p}\le \frac{p\,q^2}{1-p}.$$
(Using $q=(1-p)^n$, so $(1-p)^{2n}=q^2$.)

Thus
$$\mathrm{Var}(X)\le \mathbb{E}[X]+n^2\cdot\frac{p\,q^2}{1-p}=\mathbb{E}[X]+\fra
c{np}{1-p}\cdot\frac{(\mathbb{E}[X])^2}{4n^2}\cdot n^2\cdot\frac{1}{n^2}\cdot\ld
ots$$

More cleanly: $n^2 q^2 = \frac{(2nq)^2}{4}=\frac{(\mathbb{E}[X])^2}{4}$, so
$$\mathrm{Var}(X)\le \mathbb{E}[X]+\frac{np}{4(1-p)}\cdot\frac{(\mathbb{E}[X])^2
}{n}.$$

Since $np=\ln n+w(n)=O(\ln n)$ and $p=np/n=O(\ln n/n)\to 0$, we have $1/(1-p)\to
 1$ and $\frac{np}{n}\to 0$. Therefore
$$\mathrm{Var}(X)\le \mathbb{E}[X]+o((\mathbb{E}[X])^2).$$

**Conclusion via Chebyshev.** Since $\mathbb{E}[X]\to\infty$ and $\mathrm{Var}(X
)=o((\mathbb{E}[X])^2)$, by Chebyshev's inequality:
$$\mathbb{P}[X=0]\le \mathbb{P}\!\left[|X-\mathbb{E}[X]|\ge \mathbb{E}[X]\right]
\le \frac{\mathrm{Var}(X)}{(\mathbb{E}[X])^2}\xrightarrow{n\to\infty}0.$$

Since $\{G(n,n,p)\text{ connected}\}\subseteq\{X=0\}$, we obtain
$$\mathbb{P}[G(n,n,p)\text{ is connected}]\le \mathbb{P}[X=0]\xrightarrow{n\to\i
nfty}0.$$

Hence
$$\boxed{\lim_{n\to\infty}\mathbb{P}[G(n,n,p)\text{ is connected}]=0.}$$

This is consistent with the known connectivity threshold for $G(n,n,p)$ at $np=\
ln n$: when $np=\ln n+w(n)$ with $w(n)\to-\infty$, the graph is below threshold
(a diverging number of isolated vertices almost surely exist), so connectivity p
robability vanishes.
