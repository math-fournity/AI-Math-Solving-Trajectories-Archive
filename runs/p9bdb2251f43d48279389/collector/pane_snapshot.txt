## Proof

We wish to show that $|C[0,1]| \geq |\mathbb{R}|$.

**Construction.** For each real number $c \in \mathbb{R}$, define the function
$$f_c : [0,1] \to \mathbb{R}, \qquad f_c(x) = c \quad \text{for all } x \in [0,1
].$$
This is a constant function, hence continuous. Therefore $f_c \in C[0,1]$ for ev
ery $c \in \mathbb{R}$.

**Injectivity.** Consider the map
$$\Phi : \mathbb{R} \to C[0,1], \qquad \Phi(c) = f_c.$$
We claim $\Phi$ is injective. Suppose $\Phi(c) = \Phi(d)$, i.e., $f_c = f_d$ as
functions. Then in particular $f_c(0) = f_d(0)$, which gives $c = d$. Hence $\Ph
i$ is injective.

**Conclusion.** Since there exists an injection $\Phi : \mathbb{R} \hookrightarr
ow C[0,1]$, by definition of cardinal ordering we have
$$|\mathbb{R}| \leq |C[0,1]|.$$

Therefore, the set $C[0,1]$ of all continuous functions from $[0,1]$ to $\mathbb
{R}$ has cardinality greater than or equal to that of $\mathbb{R}$.

**Remark (equality).** In fact $|C[0,1]| = |\mathbb{R}|$. A continuous function
on $[0,1]$ is uniquely determined by its values on the dense subset $\mathbb{Q}
\cap [0,1]$ (which is countable), so
$$|C[0,1]| \leq |\mathbb{R}|^{\aleph_0} = (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_
0} = |\mathbb{R}|.$$
Combined with the lower bound above, $|C[0,1]| = |\mathbb{R}|$.
