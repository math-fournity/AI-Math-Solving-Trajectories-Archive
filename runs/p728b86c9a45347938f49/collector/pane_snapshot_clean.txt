## Solution

**Setting up coordinates.** Place $B = (0,0)$ and $C = (14,0)$. From $BA = 6\sqr
t{3}$ and $CA = 22$:

$$x_A^2 + y_A^2 = 108, \quad (x_A-14)^2 + y_A^2 = 484 \implies x_A = -\tfrac{45}
{7},\; y_A = \tfrac{33\sqrt{3}}{7}.$$

So $A = \left(-\tfrac{45}{7}, \tfrac{33\sqrt{3}}{7}\right)$.

**Incenter.** With sides $a=BC=14$, $b=CA=22$, $c=AB=6\sqrt{3}$:

$$I = \frac{aA + bB + cC}{a+b+c} = \frac{(-90+84\sqrt{3},\; 66\sqrt{3})}{36+6\sq
rt{3}}.$$

Rationalizing gives $I = (-4+3\sqrt{3},\; 2\sqrt{3}-1)$.

**Points $P$ and $Q$.** Since $BP = 14 = \frac{14}{6\sqrt{3}}\cdot BA$:

$$P = \tfrac{7}{3\sqrt{3}}\cdot A = (-5\sqrt{3},\; 11).$$

Since $CQ = 14 = \frac{14}{22}\cdot CA$:

$$Q = C + \tfrac{7}{11}(A-C) = (1,\; 3\sqrt{3}).$$

**Circumcircle and tangents.** The circumcenter satisfies $O=(7,k)$ with $OB^2=O
A^2$, giving $k = 7\sqrt{3}$, so $O=(7,7\sqrt{3})$ and $R=14$.

- Tangent at $B$: perpendicular to $\overrightarrow{OB}=(-7,-7\sqrt{3})$, direct
ion $(\sqrt{3},-1)$, parametrized as $(\lambda\sqrt{3},\, -\lambda)$.
- Tangent at $C$: perpendicular to $\overrightarrow{OC}=(7,-7\sqrt{3})$, directi
on $(\sqrt{3},1)$, parametrized as $(14+\mu\sqrt{3},\, \mu)$.

**Finding $X$ (line $PI$ ∩ tangent at $B$).** Line $PI$: $P + t(I-P)$ where $I-P
 = (-4+8\sqrt{3},\; 2\sqrt{3}-12)$. Setting equal to $(\lambda\sqrt{3}, -\lambda
)$:

$$-5\sqrt{3}+t(-4+8\sqrt{3})=\lambda\sqrt{3}, \quad 11+t(2\sqrt{3}-12)=-\lambda.
$$

Solving: $t = \frac{3\sqrt{3}}{2\sqrt{3}-1} = \frac{18+3\sqrt{3}}{11}$, and $\la
mbda = -11 + t(12-2\sqrt{3}) = -11 + 18 = 7$.

$$X = (7\sqrt{3},\; -7).$$

**Finding $Y$ (line $QI$ ∩ tangent at $C$).** Line $QI$: $Q + u(I-Q)$ where $I-Q
 = (-5+3\sqrt{3},\; -1-\sqrt{3})$. Setting equal to $(14+\mu\sqrt{3},\, \mu)$:

$$1+u(-5+3\sqrt{3})=14+\mu\sqrt{3}, \quad 3\sqrt{3}+u(-1-\sqrt{3})=\mu.$$

Solving: $u(4\sqrt{3}-2)=22 \implies u = \frac{11}{2\sqrt{3}-1} = 2\sqrt{3}+1$,
and $\mu = 3\sqrt{3}-(2\sqrt{3}+1)-\sqrt{3}(2\sqrt{3}+1) = -7$.

$$Y = (14-7\sqrt{3},\; -7).$$

**Distance $XY$.** Both points have $y = -7$, so:

$$XY = \left|7\sqrt{3} - (14-7\sqrt{3})\right| = 14\sqrt{3} - 14.$$

This is $a\sqrt{b} - c$ with $a = 14$, $b = 3$, $c = 14$ (and $14 = 2\times 7$ i
s squarefree).

$$a + b + c = 14 + 3 + 14 = \boxed{31}.$$
