# Problem

In a remote digital network, a central server system is composed of several active nodes and data cables. Each cable serves as a direct point-to-point link connecting exactly two nodes. Currently, the network contains exactly 100 data cables.

The system has an automated security protocol: when a technician "reboots" a specific node $A$, every existing cable connected to node $A$ is instantly severed. However, as a redundancy measure, the system immediately generates new cables connecting node $A$ to every other node in the network that was not previously connected to $A$ just before the reboot.

A specialist aims to "isolate" the network, which is achieved when the nodes are partitioned into two separate groups such that no cable exists between any node in the first group and any node in the second group.

Find the minimum integer $N$ such that, regardless of the initial arrangement of the 100 cables, the specialist can always isolate the network using no more than $N$ reboots.
