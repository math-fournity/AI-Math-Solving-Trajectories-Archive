## Solution

**Setting up Vieta's relations.** The cubic $a_3 x^3 - x^2 + a_1 x - 7 = 0$ has
positive roots $\alpha, \beta, \gamma$, so by Vieta's:
- $\alpha + \beta + \gamma = 1/a_3$
- $\alpha\beta + \beta\gamma + \gamma\alpha = a_1/a_3$
- $\alpha\beta\gamma = 7/a_3$

In particular, $\alpha\beta\gamma = 7(\alpha+\beta+\gamma)$.

**Parameterizing the equilibrium condition.** Let the common value be $t$:
$$\frac{225\alpha^2}{\alpha^2+7} = \frac{144\beta^2}{\beta^2+7} = \frac{100\gamm
a^2}{\gamma^2+7} = t$$

Solving each: $\alpha^2 = \frac{7t}{225-t}$, $\beta^2 = \frac{7t}{144-t}$, $\gam
ma^2 = \frac{7t}{100-t}$.

**Substituting into $\alpha\beta\gamma = 7(\alpha+\beta+\gamma)$.** Setting $u=\
sqrt{225-t},\ v=\sqrt{144-t},\ w=\sqrt{100-t}$ and dividing through by $\sqrt{7t
}$:

$$\frac{t}{uvw} = \frac{1}{u}+\frac{1}{v}+\frac{1}{w} \implies t = uv+vw+wu$$

Since $t = 225 - u^2$: $u^2 + uv + vw + wu = 225$, which factors as $(u+v)(u+w)
= 225$.

**Using the differences.** Note $u^2-v^2=81$ and $u^2-w^2=125$, so $(u-v)(u+v)=8
1$ and $(u-w)(u+w)=125$.

Let $p = u+v$, $q = u+w$, with $pq = 225$. Then $u-v = 81/p$ and $u-w = 125/q$,
giving:
$$u = \tfrac{1}{2}(p + 81/p) = \tfrac{1}{2}(q + 125/q), \quad q = 225/p$$

Substituting: $p + 81/p = 225/p + 5p/9$, so $4p/9 = 144/p$, giving $p^2 = 324$,
hence $p = 18$ and $q = 25/2$.

**Computing the roots.**
- $u = (18 + 4.5)/2 = 45/4$, so $t = 225 - 2025/16 = 1575/16$
- $\alpha^2 = \frac{7 \cdot 1575/16}{2025/16} = \frac{11025}{2025} = \frac{49}{9
}$, so $\alpha = 7/3$
- $\beta^2 = \frac{11025/16}{729/16} = \frac{1225}{81}$, so $\beta = 35/9$
- $\gamma^2 = \frac{11025/16}{25/16} = 441$, so $\gamma = 21$

**Verification of equilibrium:** All three ratios equal $11025/112$. ✓

**Verification in the cubic:** Direct substitution confirms $x = 7/3,\ 35/9,\ 21
$ each give $0$. ✓

**Computing $a_1$.**
$$\alpha\beta + \beta\gamma + \gamma\alpha = \frac{245}{27} + \frac{2205}{27} +
\frac{1323}{27} = \frac{3773}{27}$$

$$\frac{1}{a_3} = \alpha+\beta+\gamma = \frac{245}{9} \implies a_3 = \frac{9}{24
5}$$

$$a_1 = a_3 \cdot \frac{3773}{27} = \frac{9}{245}\cdot\frac{3773}{27} = \frac{37
73}{735}$$

Factoring: $3773 = 7^3 \cdot 11$ and $735 = 3\cdot 5\cdot 7^2$, so $\gcd = 49$:
$$a_1 = \frac{77}{15}, \quad \gcd(77,15)=1$$

The irreducible fraction is $a/b = 77/15$, so:

$$a + b = 77 + 15 = \boxed{92}$$
