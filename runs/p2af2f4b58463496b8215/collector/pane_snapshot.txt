## Proof

The statement is **false** in general. We exhibit a counterexample with $n = 3$.

Let
$$A = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix}, \qquad
B = \begin{pmatrix} 0 & 1 & 0 \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix}.$$

**Both are singular.** $\operatorname{rank}(A) = \operatorname{rank}(B) = 1 < 3$
, so $\det A = \det B = 0$.

**The hypothesis holds.** For an arbitrary real matrix $E = (e_{ij})$,
$$EA = \begin{pmatrix} e_{11} & 0 & 0 \\ e_{21} & 0 & 0 \\ e_{31} & 0 & 0 \end{p
matrix}, \qquad EA - B = \begin{pmatrix} e_{11} & -1 & 0 \\ e_{21} & 0 & 0 \\ e_
{31} & 0 & 0 \end{pmatrix}.$$
The third column of $EA - B$ is identically zero, hence
$$\det(EA - B) = 0 \quad \text{for every real matrix } E.$$

**Neither conclusion holds.** Compute the kernels:
$$\ker(A) = \{(0, v_2, v_3) : v_2, v_3 \in \mathbb{R}\} = \operatorname{span}\{e
_2, e_3\},$$
$$\ker(B) = \{(v_1, 0, v_3) : v_1, v_3 \in \mathbb{R}\} = \operatorname{span}\{e
_1, e_3\}.$$

Using the standard factorization criterion ($X = PQ$ is solvable in $P$ iff $\ke
r(Q) \subseteq \ker(X)$):

- $A = YB$ would require $\ker(B) \subseteq \ker(A)$, i.e. $\operatorname{span}\
{e_1, e_3\} \subseteq \operatorname{span}\{e_2, e_3\}$. But $e_1 \notin \operato
rname{span}\{e_2, e_3\}$, so this fails.
- $B = ZA$ would require $\ker(A) \subseteq \ker(B)$, i.e. $\operatorname{span}\
{e_2, e_3\} \subseteq \operatorname{span}\{e_1, e_3\}$. But $e_2 \notin \operato
rname{span}\{e_1, e_3\}$, so this fails too.

Thus there exist singular matrices $A, B$ with $\det(EA - B) \equiv 0$ for all r
eal $E$, yet **neither** $A = YB$ **nor** $B = ZA$ for any matrices $Y, Z$.

**Why the implication breaks.** In a basis aligning $\operatorname{row}(A) = \op
eratorname{span}\{e_1\}$, the hypothesis forces only $\operatorname{rank}(B_2) <
 n - r$ (the "free" block $B_2$, i.e. the columns of $B$ outside $\operatorname{
row}(A)$'s complement direction, must be rank-deficient). In the example $B_2 =
\binom{1\ 0}{0\ 0}_{\!0\ 0}$ has rank $1 < 2 = n-r$, satisfying the hypothesis.
But $B_2 \neq 0$ rules out $\ker(A) \subseteq \ker(B)$ (i.e. $B = ZA$), and the
zero first column of $B$ makes $e_1 \in \ker(B) \setminus \ker(A)$, ruling out $
\ker(B) \subseteq \ker(A)$ (i.e. $A = YB$). The hypothesis constrains only a ran
k deficiency of one block of $B$, which is insufficient to force either kernel i
nclusion.

Therefore the statement is **not true in general**. $\blacksquare$
