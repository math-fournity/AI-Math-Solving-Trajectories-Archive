## Solution

**Answer: Yes, $f(z)$ must be holomorphic.**

### Proof

The key observation is that the exponential function never vanishes: $e^w \neq 0
$ for every $w \in \mathbb{C}$. Therefore $g(z) := e^{f(z)}$ is **nowhere zero**
 on $U$.

We prove $f$ is holomorphic by showing it is holomorphic in a neighborhood of ev
ery point of $U$.

**Step 1: Local holomorphic logarithm of $g$.**

Fix $z_0 \in U$. Since $g(z_0) \neq 0$ and $g$ is continuous, there is an open d
isk $D \subseteq U$ centered at $z_0$ on which $g$ is nowhere zero. A disk is si
mply connected, so the following standard result applies:

> *On a simply connected domain, every non-vanishing holomorphic function admits
 a holomorphic logarithm.*

Brief justification: define
$$h(z) = \log g(z_0) + \int_{z_0}^{z} \frac{g'(\zeta)}{g(\zeta)}\,d\zeta,$$
where the integral is along any path in $D$ from $z_0$ to $z$. Since $g'/g$ is h
olomorphic on $D$ (as $g \neq 0$) and $D$ is simply connected, Cauchy's theorem
guarantees path-independence, so $h$ is well-defined and holomorphic with $h' =
g'/g$. Then
$$\bigl(g\,e^{-h}\bigr)' = e^{-h}\bigl(g' - g\,h'\bigr) = e^{-h}\Bigl(g' - g\cdo
t\frac{g'}{g}\Bigr) = 0,$$
so $g\,e^{-h}$ is constant. Evaluating at $z_0$ gives $g(z_0)\,e^{-\log g(z_0)}
= 1$, hence $g = e^{h}$ on $D$.

**Step 2: $f$ differs from $h$ by a constant.**

On $D$ we have $e^{f(z)} = g(z) = e^{h(z)}$, so
$$e^{f(z) - h(z)} = 1 \quad\Longrightarrow\quad f(z) - h(z) \in 2\pi i\,\mathbb{
Z} \text{ for all } z \in D.$$

Since $f$ is continuous (by hypothesis) and $h$ is continuous (being holomorphic
), the function $f - h$ is continuous on $D$. A continuous function from a conne
cted set into a discrete set must be constant. Therefore there exists a fixed in
teger $k$ such that
$$f(z) - h(z) = 2\pi i\,k \quad\text{for all } z \in D.$$

**Step 3: Conclusion.**

Thus $f(z) = h(z) + 2\pi i\,k$ on $D$, which is holomorphic (holomorphic functio
n plus a constant). Since $z_0$ was arbitrary, $f$ is holomorphic in a neighborh
ood of every point of $U$, and hence $f$ is holomorphic on $U$. $\blacksquare$
