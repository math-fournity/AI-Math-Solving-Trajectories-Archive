## Solution

We need to determine for which values of $a$ we have
$$\|f\|_{M_{\infty}^{2,1/2}} = \sup_{k \geq 0}\, 2^{k/2}\,\|f\|_{L^2(R_k)} < \in
fty,$$
where $f(x) = (1+|x|^2)^{a/2}$.

**Step 1: The $k=0$ term is always finite.**

On $R_0 = B_1(0)$, we have $|x| \leq 1$, so $1 \leq 1+|x|^2 \leq 2$. Thus $(1+|x
|^2)^a$ is bounded on $B_1$ for every $a \in \mathbb{R}$ (bounded above by $\max
(1, 2^a)$ when $a \geq 0$, and by $1$ when $a < 0$). Since $B_1$ has finite meas
ure, $\|f\|_{L^2(R_0)} < \infty$ for all $a$.

**Step 2: Asymptotics for $k \geq 1$.**

For $k \geq 1$, $R_k = B_{2^k}\setminus B_{2^{k-1}}$, so $|x| \in [2^{k-1}, 2^k]
$. Using polar coordinates:
$$\|f\|_{L^2(R_k)}^2 = |S^{n-1}|\int_{2^{k-1}}^{2^k} (1+r^2)^a\, r^{n-1}\, dr.$$

On $[2^{k-1}, 2^k]$ with $k \geq 1$, we have $r \geq 1$, so $r^2 \leq 1+r^2 \leq
 2r^2$, hence $r^{2a} \leq (1+r^2)^a \leq 2^a r^{2a}$ when $a \geq 0$, and $2^a
r^{2a} \leq (1+r^2)^a \leq r^{2a}$ when $a < 0$. In all cases, $(1+r^2)^a \asymp
 r^{2a}$ with constants independent of $k$. Therefore:
$$\|f\|_{L^2(R_k)}^2 \asymp \int_{2^{k-1}}^{2^k} r^{2a+n-1}\, dr.$$

**Step 3: Evaluating the integral.**

**Case $2a + n > 0$ (i.e., $a > -n/2$):**
$$\int_{2^{k-1}}^{2^k} r^{2a+n-1}\, dr = \frac{2^{k(2a+n)} - 2^{(k-1)(2a+n)}}{2a
+n} = \frac{1 - 2^{-(2a+n)}}{2a+n}\cdot 2^{k(2a+n)} \asymp 2^{k(2a+n)}.$$

**Case $2a + n = 0$ (i.e., $a = -n/2$):**
$$\int_{2^{k-1}}^{2^k} r^{-1}\, dr = k\log 2 \asymp k.$$

**Case $2a + n < 0$ (i.e., $a < -n/2$):**
$$\int_{2^{k-1}}^{2^k} r^{2a+n-1}\, dr = \frac{2^{k(2a+n)} - 2^{(k-1)(2a+n)}}{2a
+n} = \frac{2^{2a+n}-1}{2a+n}\cdot 2^{(k-1)(2a+n)} \asymp 2^{k(2a+n)},$$
where the ratio $\frac{2^{2a+n}-1}{2a+n} > 0$ (both numerator and denominator ar
e negative).

**Step 4: The weighted sup condition.**

Combining, $\|f\|_{L^2(R_k)} \asymp 2^{k(a+n/2)}$ when $2a+n \neq 0$, and $\|f\|
_{L^2(R_k)} \asymp k^{1/2}$ when $2a+n = 0$.

- **If $a > -n/2$:** $2^{k/2}\|f\|_{L^2(R_k)} \asymp 2^{k(a + (n+1)/2)}$. Since
$a + (n+1)/2 > 1/2 > 0$, this $\to \infty$. **Diverges.**

- **If $a = -n/2$:** $2^{k/2}\|f\|_{L^2(R_k)} \asymp 2^{k/2}\, k^{1/2} \to \inft
y$. **Diverges.**

- **If $a < -n/2$:** $2^{k/2}\|f\|_{L^2(R_k)} \asymp 2^{k(a + (n+1)/2)}$.
  - If $a + (n+1)/2 > 0$, i.e., $a > -(n+1)/2$: this $\to \infty$. **Diverges.**
  - If $a + (n+1)/2 = 0$, i.e., $a = -(n+1)/2$: this $\asymp 1$. **Bounded.**
  - If $a + (n+1)/2 < 0$, i.e., $a < -(n+1)/2$: this $\to 0$. **Bounded.**

**Step 5: Verification at the boundary $a = -(n+1)/2$.**

Here $2a + n = -1 < 0$, so the formula from the case $2a+n < 0$ applies:
$$\|f\|_{L^2(R_k)}^2 \asymp 2^{k(2a+n)} = 2^{-k}, \quad \|f\|_{L^2(R_k)} \asymp
2^{-k/2}, \quad 2^{k/2}\|f\|_{L^2(R_k)} \asymp 1.$$
The sup is finite. ✓

**Conclusion.**

The function $f(x) = (1+|x|^2)^{a/2}$ belongs to $M_\infty^{2,1/2}(\mathbb{R}^n)
$ if and only if
$$\boxed{a \leq -\frac{n+1}{2}}.$$
