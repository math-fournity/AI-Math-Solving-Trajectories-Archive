## Proof

**Step 1: Reduction via identities.**

Using the standard identity
$$x^3+y^3+z^3 - 3xyz = (x+y+z)(x^2+y^2+z^2-xy-yz-zx) = \tfrac{1}{2}(x+y+z)\big((
x-y)^2+(y-z)^2+(z-x)^2\big),$$
we get
$$\frac{x^3+y^3+z^3}{3} - xyz = \frac{(x+y+z)\big((x-y)^2+(y-z)^2+(z-x)^2\big)}{
6}.$$

Define
$$R = \frac{(x^3+y^3+z^3)/3 - xyz}{|(x-y)(y-z)(z-x)|} = \frac{(x+y+z)\big((x-y)^
2+(y-z)^2+(z-x)^2\big)}{6\,|(x-y)(y-z)(z-x)|}.$$

The desired maximal α is $\alpha = \inf R$, taken over nonneg reals with distinc
t values. Note $R$ is homogeneous of degree 0, hence scale-invariant.

**Step 2: Symmetry reduction.** Since $R$ is symmetric (the absolute value remov
es sign), assume WLOG $x \ge y \ge z \ge 0$. Set $a = x-y \ge 0$, $b = y-z \ge 0
$, so $z-x = -(a+b)$. Then
$$|(x-y)(y-z)(z-x)| = ab(a+b), \quad (x-y)^2+(y-z)^2+(z-x)^2 = 2(a^2+ab+b^2).$$

Normalize $x+y+z = 3$ (by scale invariance). Then $z = (3-a-2b)/3 \ge 0$, giving
 the constraint $a, b \ge 0$, $a + 2b \le 3$, and
$$R = \frac{a^2+ab+b^2}{ab(a+b)}.$$

**Step 3: The minimum occurs at $z=0$.** For fixed ratio $r = a/b > 0$:
$$R = \frac{b^2(r^2+r+1)}{r(r+1)b^3} = \frac{r^2+r+1}{r(r+1)\,b},$$
which is strictly decreasing in $b$. The constraint $a+2b \le 3$ gives $b \le 3/
(r+2)$, with equality at $z = 0$. Hence the infimum is achieved on the boundary
$z = 0$:
$$R_{\min}(r) = \frac{(r^2+r+1)(r+2)}{3r(r+1)}.$$

**Step 4: Single-variable minimization.** Set $t = r+1 > 1$ (equivalently $t = x
/y$ with $z=0$, $x \ge y$). Then
$$f(t) = \frac{(t^2-t+1)(t+1)}{3t(t-1)} = \frac{t^3+1}{3t(t-1)}, \quad t > 1.$$

Setting $f'(t)=0$:
$$\frac{d}{dt}\left[\frac{t^3+1}{3t(t-1)}\right] = 0 \implies t^4 - 2t^3 - 2t +
1 = 0.$$

This is palindromic; dividing by $t^2$ and setting $u = t + 1/t$:
$$u^2 - 2u - 2 = 0 \implies u = 1 + \sqrt{3} \quad (\text{since } u \ge 2).$$

**Step 5: Computing the minimum value.** At the critical point, $t + 1/t = 1+\sq
rt{3}$, so
$$t^2 - t + 1 = t^2 + 1 - t = (t+1/t)\,t - t = (u-1)t = \sqrt{3}\,t.$$
Therefore $t^3 + 1 = (t+1)(t^2-t+1) = \sqrt{3}\,t(t+1)$, and
$$f = \frac{\sqrt{3}\,t(t+1)}{3t(t-1)} = \frac{t+1}{\sqrt{3}\,(t-1)}.$$

Now
$$\frac{(t+1)^2}{(t-1)^2} = \frac{t^2+2t+1}{t^2-2t+1} = \frac{(t+1/t)+2}{(t+1/t)
-2} = \frac{u+2}{u-2} = \frac{3+\sqrt{3}}{\sqrt{3}-1} = \frac{(3+\sqrt{3})(\sqrt
{3}+1)}{2} = 2\sqrt{3}+3.$$

Hence $\frac{t+1}{t-1} = \sqrt{2\sqrt{3}+3}$, and
$$f_{\min} = \frac{\sqrt{2\sqrt{3}+3}}{\sqrt{3}} = \sqrt{\frac{2\sqrt{3}+3}{3}}
= \sqrt{\frac{3+2\sqrt{3}}{3}}.$$

**Step 6: Boundary verification.** As $t \to 1^+$, $f(t) \to +\infty$; as $t \to
 +\infty$, $f(t) \sim t/3 \to +\infty$. The unique critical point in $(1,\infty)
$ is therefore the global minimum.

z=0$): LHS $= (12.115+1)/3 = 4.3717$, $|(x-y)(y)(-x)| = 2.9775$, ratio $= 1.4681
 = \sqrt{(3+2\sqrt{3})/3}$. ✓

## Conclusion

The maximal constant is
$$\boxed{\alpha = \sqrt{\dfrac{3+2\sqrt{3}}{3}}}.$$
