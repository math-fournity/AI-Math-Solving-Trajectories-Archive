# WKB Energy Eigenstates for $V(x) = -U_0/\cosh^2(\alpha x)$

## Setup

The potential $V(x) = -U_0/\cosh^2(\alpha x)$ is a symmetric well with minimum $
-U_0$ at $x=0$ and $V\to 0$ as $x\to\pm\infty$. Bound states have $-U_0 < E < 0$
. Write $E = -|E|$ with $0 < |E| < U_0$.

**Turning points.** Setting $E = V(x)$:
$$\cosh^2(\alpha x) = \frac{U_0}{|E|} \implies x_{1,2} = \mp x_0, \quad \cosh(\a
lpha x_0)=\sqrt{\frac{U_0}{|E|}}.$$

## Evaluating the WKB integral

Substitute $y = \alpha x$ ($dx = dy/\alpha$) and use the even symmetry of the in
tegrand:

$$I = \int_{-x_0}^{x_0}\sqrt{2m\!\left(E+\frac{U_0}{\cosh^2(\alpha x)}\right)}\,
dx = \frac{2\sqrt{2m}}{\alpha}\int_0^{y_0}\frac{\sqrt{U_0 - |E|\cosh^2 y}}{\cosh
 y}\,dy,$$

where $y_0 = \alpha x_0$.

**Substitution $t = \sinh y$**, so $dt = \cosh y\,dy$, $\cosh^2 y = 1+t^2$, and
$dy/\cosh y = dt/(1+t^2)$:

$$I = \frac{2\sqrt{2m}}{\alpha}\int_0^{t_0}\frac{\sqrt{(U_0-|E|)-|E|\,t^2}}{1+t^
2}\,dt, \qquad t_0 = \sqrt{\frac{U_0-|E|}{|E|}}.$$

Set $A = U_0 - |E|$, $B = |E|$ (note $A+B = U_0$), and substitute $t = \sqrt{A/B
}\,\sin\theta$:

$$\sqrt{A - Bt^2} = \sqrt{A}\cos\theta, \quad 1+t^2 = \frac{B + A\sin^2\theta}{B
}, \quad dt = \sqrt{\tfrac{A}{B}}\cos\theta\,d\theta.$$

$$I = \frac{2\sqrt{2m}}{\alpha}\,A\sqrt{B}\int_0^{\pi/2}\frac{\cos^2\theta}{B +
A\sin^2\theta}\,d\theta.$$

## The key trigonometric integral

With $u = \tan\theta$:

$$J = \int_0^{\pi/2}\frac{\cos^2\theta}{B+A\sin^2\theta}\,d\theta = \int_0^\inft
y \frac{du}{(1+u^2)\bigl(B+(A+B)u^2\bigr)}.$$

Partial fractions (using $A+B = U_0$):

$$\frac{1}{(1+u^2)(B+U_0\,u^2)} = \frac{1}{A}\!\left(\frac{U_0}{B+U_0\,u^2} - \f
rac{1}{1+u^2}\right).$$

Integrating term by term:

$$J = \frac{1}{A}\!\left(\frac{U_0}{\sqrt{B\,U_0}}\cdot\frac{\pi}{2} - \frac{\pi
}{2}\right) = \frac{\pi}{2A}\!\left(\sqrt{\frac{U_0}{B}} - 1\right) = \frac{\pi}
{2A}\cdot\frac{\sqrt{U_0}-\sqrt{|E|}}{\sqrt{|E|}}.$$

## Assembling the result

$$I = \frac{2\sqrt{2m}}{\alpha}\,A\sqrt{B}\cdot\frac{\pi}{2A}\cdot\frac{\sqrt{U_
0}-\sqrt{|E|}}{\sqrt{B}} = \frac{\sqrt{2m}\,\pi}{\alpha}\Bigl(\sqrt{U_0}-\sqrt{|
E|}\Bigr).$$

## Applying the quantization condition

Setting $I = \left(n+\tfrac{1}{2}\right)\hbar\pi$:

$$\frac{\sqrt{2m}\,\pi}{\alpha}\Bigl(\sqrt{U_0}-\sqrt{|E|}\Bigr) = \left(n+\tfra
c{1}{2}\right)\hbar\pi,$$

$$\sqrt{|E|} = \sqrt{U_0} - \frac{\alpha\hbar}{\sqrt{2m}}\left(n+\tfrac{1}{2}\ri
ght).$$

Since $E_n = -|E_n|$:

$$E_n = -\left(\sqrt{U_0} - \frac{\alpha\hbar}{\sqrt{2m}}\left(n+\tfrac{1}{2}\ri
ght)\right)^2.$$

Factoring out $\frac{\alpha^2\hbar^2}{2m}$:

$$\boxed{E_n = -\frac{\alpha^2\hbar^2}{2m}\left[\sqrt{\frac{2m\,U_0}{\alpha^2\hb
ar^2}} - \left(n+\frac{1}{2}\right)\right]^2, \qquad n \in \mathbb{Z}^+.}$$

**Validity condition:** bound states exist only when $\sqrt{|E|} > 0$, i.e.,

$$n + \frac{1}{2} < \sqrt{\frac{2m\,U_0}{\alpha^2\hbar^2}},$$

which gives the finite number of supported levels characteristic of the modified
 Pöschl–Teller potential.
