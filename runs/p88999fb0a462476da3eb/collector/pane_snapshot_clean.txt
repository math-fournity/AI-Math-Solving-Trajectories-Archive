### 定义

设 $\{\alpha_\xi\}_{\xi < \theta}$ 为序数的超限序列，由长度为 $\theta$ 的序数索
引。我们通过**对上界 $\theta$ 的超限递归**来定义**超限乘积** $\prod_{\xi < \thet
a} \alpha_\xi$：

$$P(\theta) \;=\; \prod_{\xi < \theta} \alpha_\xi$$

其中 $P$ 由以下规则确定：

1. **(空积)** $P(0) = 1$.

2. **(后继阶段)** $P(\theta + 1) = P(\theta) \cdot \alpha_\theta$, 其中 $\cdot$
表示序数乘法。

3. **(极限阶段)** $P(\lambda) = \sup_{\theta < \lambda} P(\theta)$, 对于极限序数
 $\lambda$。

**合理性**：此定义由超限递归定理验证。定义递归的类函数 $G$ 为：
- 若 $\operatorname{dom}(h) = \varnothing$，则 $G(h) = 1$；
- 若 $\operatorname{dom}(h) = \theta + 1$（后继情况），则 $G(h) = h(\theta) \cdo
t \alpha_\theta$；
- 若 $\operatorname{dom}(h) = \lambda$ 为极限序数，则 $G(h) = \sup\,\operatornam
e{ran}(h)$。

这是一个合法的类函数，因此存在唯一的类函数 $P$ 满足对所有 $\theta$ 有 $P(\theta)
 = G(P \upharpoonright \theta)$，且 $P$ 在所有序数上定义良好。

### 性质

在讨论中，我们始终假设给定了序数序列 $\{\alpha_\xi\}_{\xi<\theta}$。每条性质后均
附有简短证明或推导。

---

**性质 1（与有限乘积的一致性）。** 对于 $\theta = n < \omega$，该定义可化简为通
常的有限乘积：

$$\prod_{\xi < n} \alpha_\xi = \alpha_0 \cdot \alpha_1 \cdots \alpha_{n-1}.$$

*证明。* 对 $n$ 进行归纳：$n=0$ 得 $1$；$n \to n+1$ 得 $P(n)\cdot\alpha_n$，这与
有限情况相符。$\square$

---

**性质 2（与序数幂的关系）。** 若序列为常数，即对所有 $\xi < \theta$ 有 $\alpha_
\xi = \alpha$，则

$$\prod_{\xi < \theta} \alpha = \alpha^{\theta},$$

其中 $\alpha^\theta$ 为序数幂。

*证明。* 对 $\theta$ 进行超限归纳。基例：$\alpha^0 = 1 = P(0)$。后继情况：$P(\th
eta+1) = P(\theta)\cdot\alpha = \alpha^\theta \cdot \alpha = \alpha^{\theta+1}$
。极限情况：$P(\lambda) = \sup_{\theta<\lambda} P(\theta) = \sup_{\theta<\lambda
} \alpha^\theta = \alpha^\lambda$，其中最后一步使用了序数幂的连续性（其在指数上
是正规的）。$\square$

这表明超限乘积是序数幂的自然推广：幂是常数序列的乘积。

---

**性质 3（关于上界的连续性/正规性）。** 映射 $\theta \mapsto \prod_{\xi<\theta}\
alpha_\xi$ 在极限序数处连续：

$$\prod_{\xi < \lambda} \alpha_\xi = \sup_{\theta < \lambda}\prod_{\xi<\theta}\a
lpha_\xi \qquad (\lambda \text{ 为极限}).$$

此外，若对所有 $\xi$ 有 $\alpha_\xi \geq 2$，则该映射是**严格递增**的，因此是序
数上的**正规函数**（normal function）。

*证明。* 连续性即定义本身。对于严格单调性：在后继阶段，$P(\theta+1) = P(\theta)\
cdot\alpha_\theta \geq P(\theta)\cdot 2 = P(\theta)+P(\theta) > P(\theta)$，因为
对于任意 $\beta \geq 1$ 有 $\beta + \beta > \beta$。在极限阶段，上确界严格大于所
有前面的值，因为该序列已经是严格递增的。$\square$

---

**性质 4（关于上界的单调性）。** 若 $\theta_1 \leq \theta_2$ 且对所有 $\xi$ 有 $
\alpha_\xi \geq 1$，则

$$\prod_{\xi<\theta_1}\alpha_\xi \;\leq\; \prod_{\xi<\theta_2}\alpha_\xi.$$

*证明。* 只需证明 $P(\theta) \leq P(\theta+1)$，因为极限情况由上确界处理。但 $P(
\theta+1) = P(\theta)\cdot\alpha_\theta \geq P(\theta)\cdot 1 = P(\theta)$，利用
了 $\alpha_\theta \geq 1$ 以及序数乘法在右参数上的单调性。$\square$

---

**性质 5（关于因子的单调性）。** 若对所有 $\xi < \theta$ 有 $\alpha_\xi \leq \be
ta_\xi$，且对所有 $\xi < \theta$ 有 $\alpha_\xi \geq 1$，则

$$\prod_{\xi<\theta}\alpha_\xi \;\leq\; \prod_{\xi<\theta}\beta_\xi.$$

*证明。* 对 $\theta$ 进行超限归纳。基例显然。后继情况：$P_\alpha(\theta+1) = P_\
alpha(\theta)\cdot\alpha_\theta \leq P_\beta(\theta)\cdot\beta_\theta = P_\beta(
\theta+1)$，利用了归纳假设 $P_\alpha(\theta)\leq P_\beta(\theta)$ 以及序数乘法在
两个参数上均单调的事实（左参数：$\gamma\leq\gamma'$ 蕴含 $\gamma\cdot\delta\leq\
gamma'\cdot\delta$；右参数：$\delta\leq\delta'$ 蕴含 $\gamma\cdot\delta\leq\gamm
a\cdot\delta'$）。极限情况：取上确界保持不等式。$\square$

---

**性质 6（乘积的分裂 / 广义结合律）。** 若 $\theta = \theta_1 + \theta_2$，则

$$\prod_{\xi < \theta_1 + \theta_2} \alpha_\xi \;=\; \left(\prod_{\xi<\theta_1}\
alpha_\xi\right)\cdot\left(\prod_{\xi<\theta_2}\alpha_{\theta_1+\xi}\right).$$

*证明。* 对 $\theta_2$ 进行超限归纳。记 $\beta = \prod_{\xi<\theta_1}\alpha_\xi$
 且 $Q(\eta) = \prod_{\xi<\eta}\alpha_{\theta_1+\xi}$。我们证明 $P(\theta_1+\eta
) = \beta\cdot Q(\eta)$。

- **$\eta = 0$**：$P(\theta_1) = \beta = \beta\cdot 1 = \beta\cdot Q(0)$。$\chec
kmark$

- **$\eta = \gamma + 1$**：$P(\theta_1+\gamma+1) = P(\theta_1+\gamma)\cdot\alpha
_{\theta_1+\gamma} = \beta\cdot Q(\gamma)\cdot\alpha_{\theta_1+\gamma} = \beta\c
dot(Q(\gamma)\cdot\alpha_{\theta_1+\gamma}) = \beta\cdot Q(\gamma+1)$，利用了序
数乘法的结合律。$\checkmark$

- **$\eta = \lambda$ (极限)**：$P(\theta_1+\lambda) = \sup_{\gamma<\lambda}P(\th
eta_1+\gamma) = \sup_{\gamma<\lambda}\beta\cdot Q(\gamma) = \beta\cdot\sup_{\gam
ma<\lambda}Q(\gamma) = \beta\cdot Q(\lambda)$，利用了序数乘法在右参数上的连续性
：对于极限 $\lambda$，$\beta\cdot\sup_{\gamma<\lambda}\gamma_\eta = \sup_{\gamma
<\lambda}\beta\cdot\gamma_\eta$。$\checkmark$

关键性质在于序数乘法在右参数上是**正规的**（递增且连续），这允许上确界穿过乘法。
$\square$

**推论。** 重复应用此性质，对于序数和的任意有限分裂 $\theta = \theta_0 + \theta_
1 + \cdots + \theta_{n-1}$：

$$\prod_{\xi<\theta}\alpha_\xi = \prod_{i<n}\left(\prod_{\xi<\theta_i}\alpha_{\t
heta_0+\cdots+\theta_{i-1}+\xi}\right).$$

---

**性质 7（零因子的效应）。** 若存在 $\xi_0 < \theta$ 使得 $\alpha_{\xi_0} = 0$，
则对所有 $\theta > \xi_0$，有 $\prod_{\xi<\theta}\alpha_\xi = 0$。

*证明。* $P(\xi_0+1) = P(\xi_0)\cdot 0 = 0$。此后，对于任意 $\eta$，$P(\xi_0+1+\
eta) = 0\cdot(\cdots) = 0$，因为对于任意序数 $\gamma$ 有 $0\cdot\gamma = 0$。在
极限阶段，部分积的上确界全为 $0$，因此上确界为 $0$。$\square$

---

**性质 8（单位因子的效应）。** 若 $\alpha_{\xi_0} = 1$，则 $P(\xi_0+1) = P(\xi_0
)\cdot 1 = P(\xi_0)$，因此因子 $1$ 不改变乘积。形式上，从序列中移除值为 $1$ 的因
子不会改变乘积（需谨慎重新索引）。

---

**性质 9（非交换性）。** 序数乘法不可交换，因此因子的**顺序**至关重要。例如，对
于长度为 $2$ 的序列：

$$\prod_{\xi<2}\alpha_\xi = \alpha_0\cdot\alpha_1 \neq \alpha_1\cdot\alpha_0 = \
prod_{\xi<2}\alpha_{1-\xi} \quad\text{一般情况下}.$$

具体例子：$\{\alpha_\xi\} = (2, \omega)$ 得到 $2\cdot\omega = \omega$，而反转序
列 $(\omega, 2)$ 得到 $\omega\cdot 2 = \omega+\omega \neq \omega$。

---

**性质 10（序数乘法在右参数上的连续性——关键引理）。** 对于任意序数 $\beta$ 和极
限序数 $\lambda$：

$$\beta \cdot \sup_{\theta<\lambda}\gamma_\theta = \sup_{\theta<\lambda}(\beta\c
dot\gamma_\theta),$$

其中 $\{\gamma_\theta\}_{\theta<\lambda}$ 为非递减序数序列。这是乘积在极限阶段性
质良好的基石。它表明序数乘法在右参数上是连续的（正规的），这是定义中取上确界做法
合法性的关键。

---

**性质 12（基数界）。** 若没有因子为零，且 $\theta$ 和所有 $\alpha_\xi$ 的基数均
 $\leq \kappa$（其中 $\kappa$ 为无穷基数），则

$$\left|\prod_{\xi<\theta}\alpha_\xi\right| \;\leq\; \max\!\bigl(|\theta|,\,\sup
_{\xi<\theta}|\alpha_\xi|,\,\aleph_0\bigr).$$

对于有限 $\theta$，这可化简为 $|\alpha_0\cdots\alpha_{\theta-1}| \leq \max_i|\al
pha_i|$。对于无穷 $\theta$，乘积的基数受限于部分积的上确界的基数，而每个部分积是
 $\theta$ 个因子的有限或超限乘积，每个因子的大小 $\leq \kappa$，因此部分积的基数
 $\leq \max(|\theta|,\kappa)$，且 $\leq|\theta|$ 个部分积的上确界的基数 $\leq \m
ax(|\theta|,\kappa)$。

### 总结

序数超限序列 $\{\alpha_\xi\}_{\xi<\theta}$ 的乘积 $\prod_{\xi<\theta}\alpha_\xi$
 通过对上界 $\theta$ 的超限递归定义：空积为 $1$，后继阶段右乘新因子，极限阶段取
部分积的上确界。其主要性质为：

1. **合理性**由超限递归定理保证。
2. **连续性**：乘积函数在极限处连续（在因子 $\geq 2$ 时为正规函数）。
3. **单调性**：关于上界（当因子 $\geq 1$）和关于因子（逐点）。
4. **分裂/结合律**：$\theta = \theta_1+\theta_2$ 的乘积分裂为两个子乘积，利用了
序数乘法在右参数上的连续性。
5. **化简为幂运算**：常数序列 $\alpha$ 的乘积等于 $\alpha^\theta$，证明该乘积推
广了序数幂。
6. **零因子**使乘积归零；**单位因子**不改变乘积。
7. **非交换性**：因子顺序至关重要，反映了序数乘法的非交换性。
