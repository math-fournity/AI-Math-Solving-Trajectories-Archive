# 解答

我们证明最小的常数 $c = 4$。

## 第一部分：不等式以 $c=4$ 成立

设 $A_k = \frac{1}{k}\sum_{j=1}^k x_j$，$S_k = \sum_{j=1}^k x_j = kA_k$。注意 $x
_k = kA_k - (k-1)A_{k-1}$，其中 $A_0 = 0$。

**强化不等式归纳**：我们证明
$$\sum_{k=1}^n A_k^2 + 2nA_n^2 \leq 4\sum_{k=1}^n x_k^2. \quad (\star)$$

由于 $2nA_n^2 \geq 0$，这蕴含 $\sum_{k=1}^n A_k^2 \leq 4\sum_{k=1}^n x_k^2$。

**基础情况** ($n=1$)：$A_1 = x_1$，LHS $= x_1^2 + 2x_1^2 = 3x_1^2 \leq 4x_1^2$。
✓

**归纳步骤**：假设 $(\star)$ 对 $n-1$ 成立。则
$$\sum_{k=1}^n A_k^2 + 2nA_n^2 = \left[\sum_{k=1}^{n-1} A_k^2 + 2(n-1)A_{n-1}^2\
right] - 2(n-1)A_{n-1}^2 + (2n+1)A_n^2$$
$$\leq 4\sum_{k=1}^{n-1} x_k^2 - 2(n-1)A_{n-1}^2 + (2n+1)A_n^2.$$

只需证明：
$$-2(n-1)A_{n-1}^2 + (2n+1)A_n^2 \leq 4x_n^2 = 4(nA_n - (n-1)A_{n-1})^2.$$

整理得等价不等式：
$$Q := (4n^2-2n-1)A_n^2 - 8n(n-1)A_nA_{n-1} + 2(n-1)(2n-1)A_{n-1}^2 \geq 0.$$

这是关于 $A_n, A_{n-1}$ 的二次型，首项系数 $p = 4n^2-2n-1 > 0$（$n \geq 1$）。判
别式为：
$$\Delta = 16n^2(n-1)^2 - 2(n-1)(2n-1)(4n^2-2n-1).$$

计算关键因子：$(2n-1)(4n^2-2n-1) = 8n^3 - 8n^2 + 1$，而 $8n^2(n-1) = 8n^3 - 8n^2
$，故
$$\Delta = 2(n-1)\big[(8n^3-8n^2) - (8n^3-8n^2+1)\big] = -2(n-1) \leq 0.$$

因此 $Q \geq 0$ 对所有 $A_n, A_{n-1}$ 成立。✓ 归纳完成。

## 第二部分：常数 $4$ 是最佳的

取 $x_k = k^{-1/2}$（$k=1,\ldots,n$），则 $\sum_{k=1}^n x_k^2 = H_n$（调和数）。

由于 $t^{-1/2}$ 递减，$j^{-1/2} \geq \int_j^{j+1} t^{-1/2}\,dt$，故
$$S_k = \sum_{j=1}^k j^{-1/2} \geq \int_1^{k+1} t^{-1/2}\,dt = 2(\sqrt{k+1}-1) \
geq 2\sqrt{k}-2.$$

对任意固定 $K$ 及 $k \geq K$：
$$A_k = \frac{S_k}{k} \geq \frac{2\sqrt{k}-2}{k} = \frac{2}{\sqrt{k}}\left(1-\fr
ac{1}{\sqrt{k}}\right) \geq \frac{2}{\sqrt{k}}\left(1-\frac{1}{\sqrt{K}}\right).
$$

因此
$$\sum_{k=1}^n A_k^2 \geq 4\left(1-\frac{1}{\sqrt{K}}\right)^2 \sum_{k=K}^n \fra
c{1}{k} = 4\left(1-\frac{1}{\sqrt{K}}\right)^2 (H_n - H_{K-1}).$$

于是
$$\frac{\sum_{k=1}^n A_k^2}{\sum_{k=1}^n x_k^2} \geq 4\left(1-\frac{1}{\sqrt{K}}
\right)^2 \cdot \frac{H_n - H_{K-1}}{H_n}.$$

对任意 $\epsilon > 0$，先取 $K$ 充分大使 $4(1-1/\sqrt{K})^2 > 4 - \epsilon/2$，
再取 $n$ 充分大使 $(H_n-H_{K-1})/H_n \to 1$，则比值超过 $4 - \epsilon$。

故 $c \geq 4$。结合第一部分 $c \leq 4$，得 $c = 4$。
