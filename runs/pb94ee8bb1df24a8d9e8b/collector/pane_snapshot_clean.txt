## Proof

**Setup.** $L = \{x \in C[0,1] : x \text{ constant}\}$ with the sup norm $\|x\|
= \max_{t\in[0,1]}|x(t)|$. The functional $f_0 \in L^*$ is $f_0(x) = x(0)$. For
a constant function $x \equiv c$, we have $f_0(x) = c = x$, so $|f_0(x)| = |c| =
 \|x\|$, giving $\|f_0\| = 1$.

The space $L_1 = \operatorname{span}(L, t)$ consists of all affine functions $x(
t) = a + bt$ with $a, b \in \mathbb{R}$.

**Candidate.** Define $f \in L_1^*$ by
$$f(a + bt) = a, \qquad \text{i.e., } f(x) = x(0).$$

**Extension property.** For $x \in L$, $x$ is constant, so $x(0) = x$ (the const
ant value), hence $f(x) = x(0) = f_0(x)$. Thus $f|_L = f_0$. ✓

**Norm computation.** For $x(t) = a + bt$,
$$\|x\| = \max_{t \in [0,1]} |a + bt| = \max(|a|, |a+b|),$$
since $a+bt$ is affine and attains its extreme values at the endpoints $t=0$ (va
lue $a$) and $t=1$ (value $a+b$).

Now observe
$$f(x) = a = (1-0)\cdot a + 0 \cdot (a+b),$$
i.e., $a = x(0)$ is exactly the value at the endpoint $t=0$. Clearly
$$|f(x)| = |a| \le \max(|a|, |a+b|) = \|x\|.$$
Hence $\|f\| \le 1$.

For the lower bound, take $x(t) \equiv 1$ (i.e., $a=1, b=0$): $\|x\| = 1$ and $|
f(x)| = 1$, so $\|f\| \ge 1$.

Therefore $\|f\| = 1 = \|f_0\|$. ✓

**Answer.** The functional
$$\boxed{f(x) = x(0), \quad x \in L_1}$$
is a norm-preserving Hahn–Banach extension of $f_0$ from $L$ to $L_1$.
