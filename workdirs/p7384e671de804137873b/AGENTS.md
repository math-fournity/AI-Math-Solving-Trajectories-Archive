# Problem

A logistics manager is designing a security protocol for a high-tech warehouse that handles shipments in two specific crates, labeled Batch $a$ and Batch $b$. These batches must always contain a positive integer number of units.

The warehouse operates under a strict "Standard Load" rule, which states that the total combined units from both batches $(a+b)$ must be perfectly divisible by 36. Additionally, the manager is looking for a specific "Security Constant" $n$. This constant is defined such that whenever the product of the units in the two batches $(ab)$ is divisible by $n$, the security protocol must guarantee that each individual batch ($a$ and $b$) is itself perfectly divisible by 36.

What is the smallest positive integer value for the Security Constant $n$ that ensures this guarantee is always met, regardless of which positive integers $a$ and $b$ are chosen?
