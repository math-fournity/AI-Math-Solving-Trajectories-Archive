## Proof

Let $M$ be a smooth manifold with local coordinates $\{x^\mu\}$, and let $X = X^
\mu \partial_\mu$ and $Y = Y^\mu \partial_\mu$ be two smooth vector fields on $M
$. The commutator (Lie bracket) $[X, Y]$ is defined as the vector field acting o
n smooth functions $f \in C^\infty(M)$ by

$$[X, Y](f) = X(Y(f)) - Y(X(f)).$$

We compute each term in coordinates. First,

$$Y(f) = Y^\nu \partial_\nu f.$$

Applying $X$ to this scalar function (using the Leibniz rule, since $Y^\nu$ is a
 scalar function of the coordinates):

$$X(Y(f)) = X^\mu \partial_\mu\!\left(Y^\nu \partial_\nu f\right) = X^\mu \left(
\partial_\mu Y^\nu\right)\partial_\nu f + X^\mu Y^\nu \,\partial_\mu \partial_\n
u f.$$

Similarly, swapping the roles of $X$ and $Y$:

$$Y(X(f)) = Y^\nu \partial_\nu\!\left(X^\mu \partial_\mu f\right) = Y^\nu \left(
\partial_\nu X^\mu\right)\partial_\mu f + Y^\nu X^\mu \,\partial_\nu \partial_\m
u f.$$

Since partial derivatives commute ($\partial_\mu \partial_\nu f = \partial_\nu \
partial_\mu f$) and the second-derivative terms are identical ($X^\mu Y^\nu \par
tial_\mu\partial_\nu f = Y^\nu X^\mu \partial_\nu\partial_\mu f$), they cancel i
n the difference:

$$[X,Y](f) = X^\mu (\partial_\mu Y^\nu)\partial_\nu f - Y^\nu (\partial_\nu X^\m
u)\partial_\mu f.$$

In the second term we relabel the dummy indices $\mu \leftrightarrow \nu$ so tha
t the basis vector is consistently $\partial_\nu$:

$$Y^\nu (\partial_\nu X^\mu)\partial_\mu f \;\longrightarrow\; Y^\mu (\partial_\
mu X^\nu)\partial_\nu f.$$

Therefore

$$[X,Y](f) = \left[X^\mu \partial_\mu Y^\nu - Y^\mu \partial_\mu X^\nu\right]\pa
rtial_\nu f.$$

Since this holds for every smooth function $f$, the bracketed coefficient is pre
cisely the $\nu$-th component of the commutator. Relabeling the free index $\nu
\to \mu$:

$$\boxed{[X, Y]^\mu = X^\nu \,\partial_\nu Y^\mu - Y^\nu \,\partial_\nu X^\mu.}$
$

Equivalently, using the Einstein summation convention,

$$[X,Y]^\mu = (X^\nu \partial_\nu) Y^\mu - (Y^\nu \partial_\nu) X^\mu.$$

This confirms that the commutator $[X,Y]$ is itself a vector field whose $\mu$-t
h component is the directional derivative of $Y^\mu$ along $X$ minus the directi
onal derivative of $X^\mu$ along $Y$.

### PROOF COMPLETE
