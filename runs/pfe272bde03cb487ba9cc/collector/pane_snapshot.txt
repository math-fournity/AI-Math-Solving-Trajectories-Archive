## Solution

Define $X_t = B_t - 5t + 2$. Then $X_0 = 2 > 0$, and $X_t$ is a Brownian motion
with drift $-5$ starting at $2$. The stopping time becomes
$$T = \inf\{t \ge 0 : X_t = 0\},$$
i.e. the first hitting time of $0$ by a Brownian motion with negative drift star
ting from $2$. Since the drift is strictly negative, $T < \infty$ almost surely,
 and $T$ is integrable, so Wald's lemmas apply.

At the stopping time, by definition of $T$,
$$B_T = 5T - 2.$$

**Applying Wald's First Lemma** ($E[B_T] = 0$):
$$0 = E[B_T] = E[5T - 2] = 5\,E[T] - 2.$$
Solving,
$$E[T] = \frac{2}{5}.$$

**Verification with Wald's Second Lemma** ($E[B_T^2] = E[T]$):
Using $B_T = 5T - 2$ and $E[T] = 2/5$,
$$E[B_T^2] = E[(5T-2)^2] = 25\,E[T^2] - 20\,E[T] + 4 = 25\,E[T^2] - 8 + 4 = 25\,
E[T^2] - 4.$$
Setting this equal to $E[T] = 2/5$ gives $25\,E[T^2] = 22/5$, i.e. $E[T^2] = 22/
125$. Then
$$\operatorname{Var}(T) = E[T^2] - (E[T])^2 = \frac{22}{125} - \frac{4}{25} = \f
rac{22}{125} - \frac{20}{125} = \frac{2}{125} > 0,$$
which is consistent. Both lemmas agree, confirming the value.

$$\boxed{E[T] = \dfrac{2}{5}}$$
