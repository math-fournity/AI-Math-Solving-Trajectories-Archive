## Solution

**Claim.** $P\!\big[X^n \in C_n(t)\big] \to 1$ as $n\to\infty$ if and only if $t
 > H(X)$.

---

### Setup

Write the joint pmf of the i.i.d. sequence as
$$p(x^n) = \prod_{i=1}^{n} p(x_i), \qquad x^n = (x_1,\dots,x_n)\in\mathcal{X}^n.
$$

Taking base-2 logarithms,
$$-\frac{1}{n}\log_2 p(x^n) = \frac{1}{n}\sum_{i=1}^{n}\bigl(-\log_2 p(x_i)\bigr
).$$

Define the random variable
$$Y_n := -\frac{1}{n}\log_2 p(X^n) = \frac{1}{n}\sum_{i=1}^{n}\bigl(-\log_2 p(X_
i)\bigr).$$

Each $-\log_2 p(X_i)$ is i.i.d. with
$$\mathbb{E}\bigl[-\log_2 p(X_i)\bigr] = H(X), \qquad \operatorname{Var}\bigl[-\
log_2 p(X_i)\bigr] < \infty$$
(finiteness of the variance holds because $X$ is discrete, so $-\log_2 p(X)$ tak
es only finitely or countably many values bounded below by $0$, and its second m
oment is the entropy of $-\log p(X)$ which is finite whenever $H(X)<\infty$; in
particular for a finite-alphabet source this is immediate).

Observe the key reformulation:
$$C_n(t) = \{x^n : p(x^n) \ge 2^{-nt}\} = \{x^n : -\tfrac{1}{n}\log_2 p(x^n) \le
 t\},$$
so
$$P\!\big[X^n \in C_n(t)\big] = P\!\big[Y_n \le t\big].$$

---

### Step 1 — Convergence in probability (the AEP)

By the **Weak Law of Large Numbers** applied to the i.i.d. summands $-\log_2 p(X
_i)$,
$$Y_n \xrightarrow{\;P\;} H(X).$$

That is, for every $\varepsilon > 0$,
$$P\!\bigl[\,|Y_n - H(X)| > \varepsilon\,\bigr] \to 0.$$

---

### Step 2 — The case $t > H(X)$

Fix $t > H(X)$ and set $\varepsilon = t - H(X) > 0$. Then
$$\{Y_n \le t\} \supseteq \{|Y_n - H(X)| \le \varepsilon\},$$
because $|Y_n - H(X)| \le \varepsilon$ implies $Y_n \le H(X) + \varepsilon = t$.
 Hence
$$P\!\big[Y_n \le t\big] \ge P\!\big[|Y_n - H(X)| \le \varepsilon\big] \to 1.$$
Since probabilities are at most $1$, we conclude
$$P\!\big[X^n \in C_n(t)\big] = P\!\big[Y_n \le t\big] \to 1.$$

---

### Step 3 — The case $t < H(X)$

Fix $t < H(X)$ and set $\varepsilon = H(X) - t > 0$. Then
$$\{Y_n \le t\} \subseteq \{|Y_n - H(X)| \ge \varepsilon\},$$
because $Y_n \le t = H(X) - \varepsilon$ implies $|Y_n - H(X)| \ge \varepsilon$.
 Hence
$$P\!\big[Y_n \le t\big] \le P\!\big[|Y_n - H(X)| \ge \varepsilon\big] \to 0.$$
Therefore
$$P\!\big[X^n \in C_n(t)\big] \to 0,$$
so in particular the probability does **not** tend to $1$.

---

### Step 4 — The boundary case $t = H(X)$

At $t = H(X)$ the limit need not be $1$ in general. For example, take $X$ unifor
m on $\{0,1\}$, so $H(X)=1$ and $Y_n = \frac{1}{n}\sum_i \mathbf{1}\{X_i\text{ i
n the less likely...}\}$ — more concretely, $-\log_2 p(X_i) = 1$ always, so $Y_n
 \equiv 1 = H(X)$ deterministically, and $P[Y_n \le H(X)] = 1$ here. But for a n
on-degenerate source (e.g. $P[X=0]=p_0\neq 1/2$), $Y_n$ is a non-degenerate aver
age of a two-valued random variable, and by the CLT $Y_n$ has fluctuations of or
der $1/\sqrt{n}$ symmetrically around $H(X)$; the probability $P[Y_n \le H(X)]$
tends to $1/2$, not $1$. Thus $t = H(X)$ is **not** a value that universally gua
rantees convergence to $1$.

The question asks for the values of $t$ for which the convergence to $1$ holds (
for the given source). The robust, distribution-independent answer — and the sta
ndard AEP threshold — is the strict inequality.

---

### Conclusion

Combining Steps 2 and 3 (and noting Step 4 excludes the boundary as a general gu
arantee),

$$\boxed{\,P\!\big[X^n \in C_n(t)\big] \to 1 \quad\Longleftrightarrow\quad t > H
(X).\,}$$

The dividing value is the entropy $H(X)$: the set $C_n(t)$ of "typical" sequence
s carries asymptotically all the probability mass exactly when the rate threshol
d $t$ strictly exceeds the per-symbol entropy. This is the **Asymptotic Equipart
ition Property (AEP)**: for $t > H(X)$ the typical set $C_n(t)$ has probability
$\to 1$, while for $t < H(X)$ its probability $\to 0$.
