## Proof

**The answer is yes.** We construct such a set explicitly.

**Equivalence relation.** Define $x \sim y \iff x - y \in \mathbb{Q}$ on $\mathb
b{R}$. The equivalence class of $x$ is
$$[x] = x + \mathbb{Q} = \{x + q : q \in \mathbb{Q}\},$$
which is **countable** (indexed by $\mathbb{Q}$) and **dense** in $\mathbb{R}$ (
since $\mathbb{Q}$ is dense, every translate $x + \mathbb{Q}$ is dense).

**Cardinality of the quotient.** Let $\mathcal{Q} = \mathbb{R}/{\sim}$ be the se
t of all equivalence classes.
- *Upper bound:* $\mathcal{Q}$ is a quotient of $\mathbb{R}$, so $|\mathcal{Q}|
\le |\mathbb{R}| = \mathfrak{c}$.
- *Lower bound:* $\mathbb{R} = \bigsqcup_{E \in \mathcal{Q}} E$ with each $E$ co
untable, so $\mathfrak{c} = |\mathbb{R}| \le |\mathcal{Q}| \cdot \aleph_0$, forc
ing $|\mathcal{Q}| \ge \mathfrak{c}$.

Hence $|\mathcal{Q}| = \mathfrak{c}$.

**Partitioning the classes.** Since $|\mathcal{Q}| = \mathfrak{c}$ and $\mathfra
k{c} = \mathfrak{c} \cdot 2$, we may partition $\mathcal{Q}$ into two disjoint s
ubfamilies $\mathcal{A}$ and $\mathcal{B}$, each of cardinality $\mathfrak{c}$.
(For instance, fix any bijection $\varphi: \mathcal{Q} \to \mathbb{R}$ and set $
\mathcal{A} = \varphi^{-1}([0,\infty))$, $\mathcal{B} = \varphi^{-1}((-\infty,0)
)$.)

**Defining the set.** Set
$$A = \bigcup_{E \in \mathcal{A}} E, \qquad B = \bigcup_{E \in \mathcal{B}} E.$$
Since $\mathcal{A} \sqcup \mathcal{B} = \mathcal{Q}$ and the classes partition $
\mathbb{R}$, we have $A \sqcup B = \mathbb{R}$, i.e., $B = \mathbb{R} \setminus
A = A^{c}$.

**Both are dense.** $\mathcal{A}$ is nonempty (it has cardinality $\mathfrak{c}$
), so pick any $E_0 \in \mathcal{A}$. Then $E_0 = x_0 + \mathbb{Q}$ is dense in
$\mathbb{R}$ and $E_0 \subseteq A$, so $A$ is dense. The identical argument show
s $B$ is dense.

**Both are uncountable in every interval.** Let $(a,b)$ be any nonempty open int
erval. Every class $E = x + \mathbb{Q}$ is dense, so $E \cap (a,b) \ne \emptyset
$; in fact $E \cap (a,b)$ is countably infinite (it is a coset of $\mathbb{Q}$ r
estricted to an interval). Since the classes are pairwise disjoint,
$$A \cap (a,b) = \bigsqcup_{E \in \mathcal{A}} \bigl(E \cap (a,b)\bigr).$$
This is a disjoint union of $|\mathcal{A}| = \mathfrak{c}$ many nonempty sets, s
o
$$|A \cap (a,b)| = \mathfrak{c} \cdot \aleph_0 = \mathfrak{c},$$
which is uncountable. The same argument with $\mathcal{B}$ gives $|B \cap (a,b)|
 = \mathfrak{c}$ for every open interval $(a,b)$.

**Conclusion.** The set $A$ is dense and uncountable in every interval, and its
complement $A^{c} = B$ is also dense and uncountable in every interval. Therefor
e such a set exists. $\blacksquare$
