## Analysis by parity of x

**Case 1: x is odd.** Write x = 2k−1, k ≥ 1. Then ⌈x/2⌉ = k, so:
$$n = k + y + (2k-1)y = k + 2ky = k(2y+1)$$
Here 2y+1 is odd and ≥ 3, k ≥ 1. So **Case 1 produces exactly those n having an
odd divisor ≥ 3**, i.e., all n that are **not powers of 2** (since powers of 2 h
ave only the odd divisor 1; every non-power-of-2 has an odd prime factor ≥ 3).

**Case 2: x is even.** Write x = 2k, k ≥ 1. Then ⌈x/2⌉ = k, so:
$$n = k + y + 2ky = k + (2k+1)y$$
Set m = 2k+1 (odd, m ≥ 3), so k = (m−1)/2. Then:
$$2n + 1 = m(2y+1)$$
So **Case 2 produces n iff 2n+1 can be factored as m·q with m, q both odd and ≥
3**, which holds iff **2n+1 is composite** (and ≥ 9, i.e., n ≥ 4, which is autom
atic for composite 2n+1 ≥ 9).

## Combining the cases

n is representable iff: (n is not a power of 2) **OR** (2n+1 is composite).

Equivalently, **n is NOT representable iff n is a power of 2 AND 2n+1 is prime.*
