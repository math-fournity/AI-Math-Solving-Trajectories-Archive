## 解答

**设置。** 设 $r_1, \dots, r_{2020}$ 为 $P(x) = x^{2020}+x+2$ 的根。由 Vieta 公
式：$\prod r_i = 2$，$\sum r_i = 0$。

设 $\alpha$ 满足 $P(\alpha)=4$，即 $\alpha^{2020}+\alpha-2=0$，因此 $\alpha^{202
0}=2-\alpha$。存在 2020 个这样的 $\alpha$，且由于 $\deg \geq 3$，$\sum \alpha =
0$。

**目标。** $Q(x) = \prod_{i<j}(x - r_i r_j)$，因此 $Q(\alpha^2)^2 = \prod_{i<j}(
\alpha^2 - r_ir_j)^2 = \prod_{i\neq j}(\alpha^2 - r_i r_j)$。

由于 $\prod_{i,j}(\alpha^2 - r_i r_j) = \prod_i(\alpha^2 - r_i^2)\cdot \prod_{i\
neq j}(\alpha^2 - r_i r_j)$，我们得到：

$$Q(\alpha^2)^2 = \frac{\prod_{i,j}(\alpha^2 - r_i r_j)}{\prod_i(\alpha^2 - r_i^
2)}.$$

**分母。** $\prod_i(\alpha^2 - r_i^2) = P(\alpha)\cdot \prod_i(\alpha + r_i)$。
因为 $n=2020$ 为偶数，以 $-r_i$ 为根的多项式为 $P(-x)=x^{2020}-x+2$，所以 $\prod
_i(t+r_i)=t^{2020}-t+2$。在 $t=\alpha$ 处：$\prod_i(\alpha+r_i) = \alpha^{2020}-
\alpha+2 = (2-\alpha)-\alpha+2 = 2(2-\alpha)$。因此：

$$\prod_i(\alpha^2 - r_i^2) = 4 \cdot 2(2-\alpha) = 8(2-\alpha).$$

**分子。** $\prod_{i,j}(\alpha^2 - r_i r_j) = \prod_i \prod_j(\alpha^2 - r_i r_j
) = \prod_i r_i^{2020}\, P(\alpha^2/r_i) = 2^{2020}\prod_i P(\alpha^2/r_i)$。

使用 $r_i^{2020} = -r_i - 2$ 和 $\alpha^{4040} = (2-\alpha)^2$ 计算 $P(\alpha^2/
r_i)$：

$$P(\alpha^2/r_i) = \frac{(2-\alpha)^2}{-r_i-2} + \frac{\alpha^2}{r_i} + 2 = \fr
ac{-(2-\alpha)^2 r_i + \alpha^2(r_i+2) + 2r_i(r_i+2)}{r_i(r_i+2)}.$$

分子化简：$r_i[\alpha^2 - (2-\alpha)^2] + 2\alpha^2 + 2r_i^2 + 4r_i$。由于 $\alp
ha^2 - (2-\alpha)^2 = 4(\alpha-1)$：

$$= 4(\alpha-1)r_i + 2\alpha^2 + 2r_i^2 + 4r_i = 2r_i^2 + 4\alpha\, r_i + 2\alph
a^2 = 2(r_i+\alpha)^2.$$

所以 $P(\alpha^2/r_i) = \frac{2(r_i+\alpha)^2}{r_i(r_i+2)}$，且

$$\prod_i P(\alpha^2/r_i) = \frac{2^{2020}\left[\prod_i(r_i+\alpha)\right]^2}{\p
rod_i r_i \cdot \prod_i(r_i+2)} = \frac{2^{2020}\cdot [2(2-\alpha)]^2}{2 \cdot 2
^{2020}} = 2(2-\alpha)^2,$$

其中 $\prod_i(r_i+2) = 2^{2020}-2+2 = 2^{2020}$。

因此 $\prod_{i,j}(\alpha^2 - r_i r_j) = 2^{2020}\cdot 2(2-\alpha)^2 = 2^{2021}(2
-\alpha)^2$。

**组合。**

$$Q(\alpha^2)^2 = \frac{2^{2021}(2-\alpha)^2}{8(2-\alpha)} = 2^{2018}(2-\alpha).
$$

**求和。** 遍历所有满足 $\alpha^{2020}+\alpha-2=0$ 的 2020 个 $\alpha$ 值：

$$\sum_\alpha Q(\alpha^2)^2 = 2^{2018}\sum_\alpha(2-\alpha) = 2^{2018}\bigl(2\cd
ot 2020 - \underbrace{\sum_\alpha \alpha}_{=\,0}\bigr) = 4040\cdot 2^{2018} = \b
oxed{505\cdot 2^{2021}}.$$
