## Proof

**Setup.** Model the tanks as vertices $\{1,\ldots,1000\}$ and the chambers as e
dges of a graph $G=(V,E)$ with $|E|=m$. The total output is $S = \sum_{(i,j)\in
E} a_i a_j$. We need:
$$\max_{\substack{a_k \ge 0 \\ \sum a_k = 1}} S \le \frac{1}{2.014}.$$

**Step 1: Motzkin–Straus Theorem.** The Motzkin–Straus theorem (1965) states tha
t for any graph $G$ with clique number $\omega$:
$$\max_{\substack{a_k \ge 0 \\ \sum a_k = 1}} \sum_{(i,j)\in E} a_i a_j = \frac{
1}{2}\!\left(1 - \frac{1}{\omega}\right).$$

This maximum is achieved by the uniform distribution on a maximum clique.

**Step 2: Determine the clique bound.** We require:
$$\frac{1}{2}\!\left(1 - \frac{1}{\omega}\right) \le \frac{1}{2.014} = \frac{500
}{1007}.$$

Equivalently:
$$1 - \frac{1}{\omega} \le \frac{1000}{1007} \implies \frac{1}{\omega} \ge \frac
{7}{1007} \implies \omega \le \frac{1007}{7} = 143.857\ldots$$

Since $\omega$ is an integer, $\omega \le 143$.

**Verification of the boundary.**
- For $\omega = 143$: $\frac{1}{2}(1 - \frac{1}{143}) = \frac{71}{143}$. Compare
 with $\frac{500}{1007}$: $71 \times 1007 = 71497 < 71500 = 143 \times 500$. So
$\frac{71}{143} < \frac{500}{1007}$. ✓
- For $\omega = 144$: $\frac{1}{2}(1 - \frac{1}{144}) = \frac{143}{288}$. Compar
e with $\frac{500}{1007}$: $143 \times 1007 = 144001 > 144000 = 288 \times 500$.
 So $\frac{143}{288} > \frac{500}{1007}$. ✗

Thus $\omega \le 143$ is both necessary and sufficient.

**Step 3: Turán's Theorem.** We need the maximum number of edges in a graph on $
n=1000$ vertices with clique number at most 143 (equivalently, no $K_{144}$). By
 Turán's theorem, this is achieved by the Turán graph $T(1000, 143)$, the comple
te 143-partite graph with parts as equal as possible.

**Step 4: Compute the Turán number.** Divide 1000 into 143 parts as equally as p
ossible:
$$1000 = 142 \times 7 + 1 \times 6.$$
So 142 parts have size 7 and 1 part has size 6.

The number of edges of $T(1000,143)$ is:
$$t(1000,143) = \frac{n^2 - \sum_{i=1}^{143} n_i^2}{2} = \frac{1000^2 - \left(14
2 \times 7^2 + 1 \times 6^2\right)}{2}$$
$$= \frac{1{,}000{,}000 - (142 \times 49 + 36)}{2} = \frac{1{,}000{,}000 - (6958
 + 36)}{2} = \frac{1{,}000{,}000 - 6994}{2} = \frac{993{,}006}{2} = 496{,}503.$$

**Step 5: Achievability.** The Turán graph $T(1000,143)$ has exactly $496{,}503$
 edges and clique number $143$. By Motzkin–Straus, its maximum total output is $
\frac{71}{143} < \frac{500}{1007} = \frac{1}{2.014}$, so the safety constraint i
s satisfied.

**Step 6: Optimality.** Any graph on 1000 vertices with $496{,}504$ or more edge
s must contain a $K_{144}$ (by Turán's theorem, since $t(1000,143) = 496{,}503$
is the extremal number for $K_{144}$-free graphs). A $K_{144}$ gives clique numb
er $\omega \ge 144$, and by Motzkin–Straus the maximum total output is at least
$\frac{143}{288} > \frac{1}{2.014}$, violating the constraint.

## Answer

The maximum number of reaction chambers is:

$$\boxed{m = 496{,}503}$$
