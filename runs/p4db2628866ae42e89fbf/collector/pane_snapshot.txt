## Solution

Let $\mathbb{A}=\{1,2,3,4,5,6,7\}$, $|\mathbb{A}|=7$. We count functions $f:\mat
hbb{A}\to\mathbb{A}$ such that $f\circ f$ is constant.

**Setup.** Suppose $f(f(x))=c$ for all $x\in\mathbb{A}$. Let $S=\operatorname{Im
}(f)\subseteq\mathbb{A}$, $|S|=k$.

For every $y\in S$, since $y=f(x)$ for some $x$, we have $f(y)=f(f(x))=c$. So $f
$ is constant equal to $c$ on $S$. In particular $c=f(y)\in\operatorname{Im}(f)=
S$, so $c\in S$.

For $x\notin S$: $f(x)\in S$ (any of $k$ values). For $x\in S$: $f(x)=c$ (forced
).

The image of $f$ is $\{c\}\cup\{f(x):x\notin S\}$, and this must equal $S$. Sinc
e elements of $S\setminus\{c\}$ can only be attained by $x\notin S$, we need: th
e restriction $f|_{\mathbb{A}\setminus S}$ (a function from a $(7-k)$-element se
t to $S$) has image **containing** $S\setminus\{c\}$.

**Counting.** Fix $c$ (7 choices) and $S$ with $c\in S$, $|S|=k$ ($\binom{6}{k-1
}$ choices). The number of functions from a $(7-k)$-element set to a $k$-element
 set whose image contains a fixed $(k-1)$-element subset is, by inclusion–exclus
ion:
$$N(k)=\sum_{i=0}^{k-1}(-1)^i\binom{k-1}{i}(k-i)^{7-k}.$$

Note we need $7-k\ge k-1$, i.e. $k\le 4$; otherwise $N(k)=0$ (an $n$-element dom
ain cannot cover $k-1>n$ required values).

Computing:

- **$k=1$** ($n=6$): $N(1)=1^6=1$. Contribution: $\binom{6}{0}\cdot1=1$.
- **$k=2$** ($n=5$): $N(2)=2^5-1^5=31$. Contribution: $\binom{6}{1}\cdot31=186$.
- **$k=3$** ($n=4$): $N(3)=3^4-2\cdot2^4+1^4=81-32+1=50$. Contribution: $\binom{
6}{2}\cdot50=750$.
- **$k=4$** ($n=3$): $N(4)=4^3-3\cdot3^3+3\cdot2^3-1^3=64-81+24-1=6$. (Indeed su
rjections from 3 elements onto a fixed 3-element set $=3!=6$.) Contribution: $\b
inom{6}{3}\cdot6=120$.
- **$k=5,6,7$**: $N(k)=0$ (domain too small to cover required image). Contributi
on $0$.

Sum over $k$: $1+186+750+120=1057$.

Multiplying by the 7 choices of $c$:
$$\boxed{7\cdot 1057 = 7399}.$$
