We use the **Brunn–Minkowski inequality** in one dimension: for measurable sets
$A, B \subset \mathbb{R}$,
$$|A + B| \;\geq\; |A| + |B|,$$
where $A+B = \{a+b : a\in A,\, b\in B\}$ and $|\cdot|$ denotes Lebesgue measure
(the inequality holds for outer measure, and the sum set is measurable up to a n
ull set).

**Step 1 (Lower bound on $|S|$).** Apply Brunn–Minkowski with $A = E_1$ and $B =
 -E_2 = \{-x_2 : x_2 \in E_2\}$. Since reflection preserves measure, $|{-E_2}| =
 |E_2| = 5$, and
$$A + B \;=\; E_1 + (-E_2) \;=\; \{x_1 - x_2 : x_1 \in E_1,\, x_2 \in E_2\} \;=\
; S.$$
Therefore
$$|S| \;\geq\; |E_1| + |{-E_2}| \;=\; 3 + 5 \;=\; 8.$$

**Step 2 ($S$ contains an open interval).** Consider the convolution
$$f \;=\; \chi_{E_1} * \chi_{-E_2}, \qquad f(x) = \int_{\mathbb{R}} \chi_{E_1}(t
)\,\chi_{-E_2}(x-t)\,dt = |E_1 \cap (x + E_2)|.$$
Since $E_1, E_2$ have finite measure, $\chi_{E_1}, \chi_{-E_2} \in L^1 \cap L^2$
, so $f$ is **continuous**. Moreover
$$\int_{\mathbb{R}} f(x)\,dx = |E_1|\cdot|{-E_2}| = 3 \cdot 5 = 15 > 0,$$
and $0 \leq f(x) \leq \min(|E_1|,|E_2|) = 3$. Since $f$ is continuous with posit
ive integral, the open set $U = \{x : f(x) > 0\}$ is nonempty. For every $x \in
U$, the intersection $E_1 \cap (x + E_2)$ has positive measure, hence is nonempt
y, so $x \in S$. Thus $U \subseteq S$, and $S$ contains the nonempty open set $U

for difference sets.)

$$S \;=\; E_1 - E_2 \;=\; [0,3] - [0,5] \;=\; [-5,\,3],$$

with equality.
