## Proof

**Setup.** Let $M$ be the $n \times n$ matrix with $M_{ii} = i+1$ for $i = 1, \l
dots, n$ and $M_{ij} = 1$ for $i \neq j$. We decompose $M$ as:

$$M = D + \mathbf{1}\mathbf{1}^T$$

where $D = \operatorname{diag}(1, 2, 3, \ldots, n)$ (since $M_{ii} - 1 = i$) and
 $\mathbf{1} = (1, 1, \ldots, 1)^T \in \mathbb{R}^n$.

**Applying the Matrix Determinant Lemma.** For an invertible matrix $D$ and vect
ors $u, v$:

$$\det(D + uv^T) = \det(D)\left(1 + v^T D^{-1} u\right).$$

Here $u = v = \mathbf{1}$, so:

$$d_n = \det(D)\left(1 + \mathbf{1}^T D^{-1} \mathbf{1}\right).$$

**Computing each factor.**

- $\det(D) = 1 \cdot 2 \cdot 3 \cdots n = n!$.

- $D^{-1} = \operatorname{diag}\!\left(1, \tfrac{1}{2}, \tfrac{1}{3}, \ldots, \t
frac{1}{n}\right)$, so:

$$\mathbf{1}^T D^{-1} \mathbf{1} = \sum_{i=1}^{n} \frac{1}{i} = H_n,$$

where $H_n$ is the $n$-th harmonic number.

**Result.** Therefore:

$$d_n = n!\,(1 + H_n), \qquad \frac{d_n}{n!} = 1 + H_n = 1 + \sum_{k=1}^{n} \fra
c{1}{k}.$$

**Verification with small cases.**
- $n=1$: $d_1 = 2$, $d_1/1! = 2 = 1 + H_1 = 1 + 1$. ✓
- $n=2$: $d_2 = \det\begin{pmatrix}2&1\\1&3\end{pmatrix} = 5$, $d_2/2! = 5/2 = 1
 + H_2 = 1 + 1 + \frac{1}{2}$. ✓
- $n=3$: $d_3 = \det\begin{pmatrix}2&1&1\\1&3&1\\1&1&4\end{pmatrix} = 17$, $d_3/
3! = 17/6 = 1 + H_3 = 1 + 1 + \frac{1}{2} + \frac{1}{3}$. ✓

**Taking the limit.** Since $H_n = \sum_{k=1}^{n} \frac{1}{k}$ is the harmonic s
eries, which diverges:

$$\lim_{n \to \infty} \frac{d_n}{n!} = \lim_{n \to \infty} \left(1 + H_n\right)
= +\infty.$$

The harmonic series diverges (as $H_n \sim \ln n + \gamma \to \infty$), so the l

$$\boxed{+\infty}$$
