## Example

Take $n = 1$ and define
$$T:\mathbb{R}\to\mathbb{R},\qquad T(x) = -x.$$

$T$ is linear and invertible (its inverse is itself).

## Proof that no $S$ with $e^S = T$ exists

Suppose, for contradiction, that there exists a linear transformation $S:\mathbb
{R}\to\mathbb{R}$ with $e^S = T$.

Every linear map $\mathbb{R}\to\mathbb{R}$ is multiplication by a unique real nu
mber. So $S$ is multiplication by some $s\in\mathbb{R}$, and $T$ is multiplicati
on by $-1$.

The matrix exponential of a $1\times 1$ matrix $[s]$ is
$$e^S = e^{[s]} = [e^s].$$

Thus $e^S = T$ becomes
$$e^s = -1.$$

But the real exponential function satisfies $e^s > 0$ for every $s\in\mathbb{R}$
. This contradicts $e^s = -1 < 0$.

Hence no real linear transformation $S:\mathbb{R}\to\mathbb{R}$ satisfies $e^S =
 T$.

## Conclusion

The transformation
$$\boxed{T(x) = -x \text{ on } \mathbb{R}^1}$$
is invertible yet admits no real logarithm, i.e. there is no linear $S:\mathbb{R
}\to\mathbb{R}$ with $e^S = T$.

*(The underlying reason: a real invertible matrix has a real logarithm iff each
Jordan block size for each negative real eigenvalue occurs an even number of tim
es. The $1\times 1$ matrix $[-1]$ has a single Jordan block of size $1$ for the
negative eigenvalue $-1$ — an odd count — so no real logarithm exists.)*
