## Proof

**Claim:** The image of an $F_\sigma$ set under a homeomorphism is always an $F_
\sigma$ set, in any topological space.

**Definitions.** Let $X, Y$ be topological spaces. A set $A \subseteq X$ is an $
F_\sigma$ set if it can be written as a countable union of closed sets: $A = \bi
gcup_{n=1}^{\infty} F_n$, where each $F_n$ is closed in $X$. A homeomorphism $f:
 X \to Y$ is a bijection such that both $f$ and $f^{-1}$ are continuous.

**Key fact.** A homeomorphism maps closed sets to closed sets.

*Proof of key fact.* Since $f^{-1}$ is continuous, $f$ is an open map: for every
 open $U \subseteq X$, $f(U)$ is open in $Y$ (because $(f^{-1})^{-1}(U) = f(U)$,
 and the preimage of an open set under a continuous map is open). Now let $F \su
bseteq X$ be closed, so $X \setminus F$ is open in $X$. Since $f$ is a bijection
, $f(X \setminus F) = Y \setminus f(F)$. Since $f$ is an open map, $f(X \setminu
s F) = Y \setminus f(F)$ is open in $Y$. Therefore $f(F)$ is closed in $Y$. $\sq
uare$

**Main proof.** Let $f: X \to Y$ be a homeomorphism and let $A \subseteq X$ be a
n $F_\sigma$ set. Write
$$A = \bigcup_{n=1}^{\infty} F_n,$$
where each $F_n$ is closed in $X$. Since $f$ is a bijection, it distributes over
 arbitrary unions:
$$f(A) = f\!\left(\bigcup_{n=1}^{\infty} F_n\right) = \bigcup_{n=1}^{\infty} f(F
_n).$$
By the key fact, each $f(F_n)$ is closed in $Y$. Therefore $f(A)$ is a countable
 union of closed sets in $Y$, i.e., $f(A)$ is an $F_\sigma$ set in $Y$.

**Remark on generality.** The argument uses only: (i) $f$ is a bijection (so it
distributes over unions and complements), and (ii) $f$ maps closed sets to close
d sets (which follows from $f^{-1}$ being continuous). No separation axioms (Hau
sdorff, normal, etc.), no countability axioms (first/second countable), and no m
etric structure are required. The result holds in arbitrary topological spaces.

**Conclusion.** The image of an $F_\sigma$ set under a homeomorphism is always a
n $F_\sigma$ set. Indeed, a homeomorphism is an isomorphism of topological space
s, so it preserves the entire Borel hierarchy: it maps $F_\sigma$ sets to $F_\si
gma$ sets, $G_\delta$ sets to $G_\delta$ sets, and more generally preserves all
levels of the Borel hierarchy.
