# Green's Function for y⁽⁴⁾(x) = −f(x)

## Setup

We seek H(x, s) satisfying H⁽⁴⁾(x, s) = −δ(x − s) with boundary conditions
H(0, s) = H''(0, s) = 0,  H(π, s) = H'''(π, s) = 0.

For x ≠ s, H⁽⁴⁾ = 0, so H is a cubic polynomial on each side of s. Integrating H
⁽⁴⁾ = −δ(x−s) across x = s gives the jump condition H'''(s⁻) − H'''(s⁺) = −1, wh
ile H, H', H'' are continuous at x = s.

## General form in each region

**Region 1** (0 ≤ x ≤ s):  H = a₁ + a₂x + a₃x² + a₄x³

**Region 2** (s ≤ x ≤ π):  H = b₁ + b₂x + b₃x² + b₄x³

## Apply boundary conditions

At x = 0:  H(0,s)=0 → a₁ = 0;  H''(0,s)=0 → 2a₃ = 0 → a₃ = 0.

So Region 1: **H = a₂x + a₄x³**.

At x = π:  H(π,s)=0 → b₁ + b₂π + b₃π² + b₄π³ = 0;  H'''(π,s)=0 → 6b₄ = 0 → b₄ =
0.

So Region 2: **H = b₁ + b₂x + b₃x²**, with b₁ + b₂π + b₃π² = 0, i.e. b₁ = −b₂π −
 b₃π².

## Apply jump and continuity at x = s

**Jump:** H'''(s⁻) − H'''(s⁺) = 6a₄ − 0 = −1  →  **a₄ = −1/6**.

**H'' continuity:** 6a₄s = 2b₃  →  b₃ = 3a₄s = **−s/2**.

**H' continuity:** a₂ + 3a₄s² = b₂ + 2b₃s  →  a₂ − s²/2 = b₂ − s²  →  **a₂ = b₂
− s²/2**.

**H continuity:** a₂s + a₄s³ = b₁ + b₂s + b₃s². Substituting b₁ = −b₂π − b₃π² =
−b₂π + sπ²/2:

a₂s − s³/6 = −b₂π + sπ²/2 + b₂s − s³/2

a₂s = b₂(s − π) + sπ²/2 − s³/2 + s³/6 = b₂(s − π) + sπ²/2 − s³/3

Substituting a₂ = b₂ − s²/2:

(b₂ − s²/2)s = b₂(s − π) + sπ²/2 − s³/3

b₂s − s³/2 = b₂s − b₂π + sπ²/2 − s³/3

b₂π = sπ²/2 − s³/3 + s³/2 = sπ²/2 + s³/6

**b₂ = sπ/2 + s³/(6π)**.

Then:
- a₂ = b₂ − s²/2 = **sπ/2 + s³/(6π) − s²/2**
- b₁ = −b₂π + sπ²/2 = −(sπ/2 + s³/(6π))π + sπ²/2 = −sπ²/2 − s³/6 + sπ²/2 = **−s³
/6**
- b₃ = **−s/2**,  a₄ = **−1/6**

## The Green's function

**For 0 ≤ x ≤ s:**

H(x, s) = (sπ/2 + s³/(6π) − s²/2)x − x³/6

$$\boxed{H(x,s) = \frac{x}{6}\left[3s(\pi - s) + \frac{s^3}{\pi} - x^2\right]}$$

**For s ≤ x ≤ π:**

H(x, s) = −s³/6 + (sπ/2 + s³/(6π))x − (s/2)x²

$$\boxed{H(x,s) = \frac{\pi - x}{6}\left[3sx - \frac{s^3}{\pi}\right]}$$

## Verification

- **x = 0:** H = 0 ✓;  H'' = 6a₄·0 = 0 ✓
- **x = π:** H = (π−π)/6·[...] = 0 ✓;  H''' = 0 (b₄ = 0) ✓
- **Continuity at x = s:** Both formulas give H(s,s) = s²π/2 + s⁴/(6π) − 2s³/3 ✓
- **H' continuous at s:** Both give sπ/2 + s³/(6π) − s² ✓
- **H'' continuous at s:** Both give −s ✓
- **Jump condition:** H'''(s⁻) = 6(−1/6) = −1, H'''(s⁺) = 0, so H'''(s⁻) − H'''(
s⁺) = −1 ✓

The solution to the original BVP is then y(x) = ∫₀^π H(x, s) f(s) ds.
