Looking at this problem, I need to analyze $T_\alpha(p_n) = p_n^{\alpha} \prod_{
i=1}^n \left(1 - \frac{1}{p_i^\alpha}\right)$ for $\alpha \in (0,1)$, where $p_i
$ is the $i$-th prime.

## Proof

**Step 1: Logarithmic reformulation.**

Taking logarithms:
$$\log T_\alpha(p_n) = \alpha \log p_n + \sum_{i=1}^n \log\!\left(1 - \frac{1}{p
_i^\alpha}\right).$$

**Step 2: Expand the log terms.**

For each $i$, since $p_i \geq 2$ and $\alpha > 0$, we have $1/p_i^\alpha < 1$, s
o:
$$\log\!\left(1 - \frac{1}{p_i^\alpha}\right) = -\frac{1}{p_i^\alpha} + O\!\left
(\frac{1}{p_i^{2\alpha}}\right).$$

Thus:
$$\log T_\alpha(p_n) = \alpha \log p_n - \sum_{i=1}^n \frac{1}{p_i^\alpha} + O\!
\left(\sum_{i=1}^n \frac{1}{p_i^{2\alpha}}\right).$$

**Step 3: The error term is negligible.**

- If $2\alpha > 1$: $\sum_{i=1}^\infty 1/p_i^{2\alpha}$ converges, so the error
is $O(1)$.
- If $2\alpha = 1$: $\sum_{i=1}^n 1/p_i \sim \log\log p_n = o(\log p_n)$.
- If $2\alpha < 1$: $\sum_{i=1}^n 1/p_i^{2\alpha} \sim \frac{p_n^{1-2\alpha}}{(1
-2\alpha)\log p_n} = o\!\left(\frac{p_n^{1-\alpha}}{(1-\alpha)\log p_n}\right)$
since $1-2\alpha < 1-\alpha$.

In all cases, the error is $o\!\left(\sum_{i=1}^n 1/p_i^\alpha\right)$.

**Step 4: Asymptotic for the main sum via PNT.**

By the Prime Number Theorem, $\pi(x) \sim x/\log x$. By partial summation:
$$\sum_{p \leq x} \frac{1}{p^\alpha} = \frac{\pi(x)}{x^\alpha} + \alpha\int_2^x
\frac{\pi(t)}{t^{\alpha+1}}\,dt \sim \frac{x^{1-\alpha}}{\log x} + \alpha\cdot\f
rac{x^{1-\alpha}}{(1-\alpha)\log x} = \frac{x^{1-\alpha}}{(1-\alpha)\log x}.$$

Setting $x = p_n$:
$$\sum_{i=1}^n \frac{1}{p_i^\alpha} \sim \frac{p_n^{1-\alpha}}{(1-\alpha)\log p_
n}.$$

**Step 5: The negative term dominates.**

Combining:
$$\log T_\alpha(p_n) = \alpha\log p_n - \frac{p_n^{1-\alpha}}{(1-\alpha)\log p_n
}\bigl(1 + o(1)\bigr).$$

For any fixed $\alpha \in (0,1)$, since $p_n \to \infty$ and $1-\alpha > 0$:
$$\frac{p_n^{1-\alpha}}{(1-\alpha)\log p_n} \Big/ \alpha\log p_n = \frac{p_n^{1-
\alpha}}{\alpha(1-\alpha)(\log p_n)^2} \to \infty,$$

because $p_n^{1-\alpha}$ grows polynomially in $n$ while $(\log p_n)^2$ grows on
ly polylogarithmically. Therefore the negative term dominates:
$$\log T_\alpha(p_n) \to -\infty \quad \text{as } n \to \infty.$$

**Step 6: Conclusion.**

Since $\log T_\alpha(p_n) \to -\infty$, we have $T_\alpha(p_n) \to 0$ for **ever
y** $\alpha \in (0,1)$.

Therefore, such an $\alpha^*$ exists — indeed, every $\alpha^* \in (0,1)$ satisf
ies the condition — and the limit is:

$$\boxed{k = 0}.$$
