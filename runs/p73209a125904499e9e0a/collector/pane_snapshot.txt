Looking at this problem, I need to find the smallest $n \geq 2$ such that there
exist positive integers $a_1, \ldots, a_n$ with $\sum a_i^2 \mid (\sum a_i)^2 -
1$.

Let me denote $S = \sum a_i$, $Q = \sum a_i^2$, $P = \sum_{i<j} a_i a_j$, so $S^
2 = Q + 2P$.

## Setting up the key equation

We need $Q \mid S^2 - 1$, so $S^2 - 1 = kQ$ for some positive integer $k$. This
gives:
$$S^2 - kQ = 2P - (k-1)Q = 1.$$

**$k$ must be even.** If $k$ is odd, then $k-1$ is even, making $2P - (k-1)Q$ ev
en, contradicting $= 1$.

**$S$ must be odd.** Since $k$ is even, $kQ$ is even, so $S^2 = kQ + 1$ is odd.

## Parity obstruction

Let $r$ = number of odd $a_i$. Since each odd $a_i$ satisfies $a_i^2 \equiv 1 \p
mod{4}$ and each even $a_i$ satisfies $a_i^2 \equiv 0 \pmod{4}$:
$$Q \equiv r \pmod{4}.$$
Also $S \equiv r \pmod{2}$, so $S$ odd forces $r$ odd.

Now $Q = (S^2 - 1)/k$. For odd $S$, we have $S^2 \equiv 1 \pmod{8}$, so $v_2(S^2
 - 1) \geq 3$.

- If $v_2(k) < v_2(S^2-1)$: then $Q$ is even, forcing $r$ even — contradicting $
r$ odd.
- If $v_2(k) > v_2(S^2-1)$: then $k \nmid S^2 - 1$, no solution.
- If $v_2(k) = v_2(S^2-1) \geq 3$: then $Q$ is odd, $r$ odd, consistent. ✓

Therefore **$8 \mid k$**, which forces $k \geq 8$.

## Bounding $k$

By Cauchy–Schwarz, $S^2 \leq nQ$, so $k = (S^2-1)/Q < S^2/Q \leq n$, giving $k \
leq n-1$.

Since $k \geq 8$ and $k \leq n-1$, we need $n \geq 9$.

## Eliminating $n = 2$ directly

For $n=2$: $Q \mid 2a_1 a_2 - 1$. If $a_1 \neq a_2$, then $Q = a_1^2 + a_2^2 > 2
a_1 a_2 > 2a_1 a_2 - 1 > 0$, so no divisibility. If $a_1 = a_2 = a$, then $2a^2
\nmid 2a^2 - 1$. So $n=2$ is impossible.

## Summary of impossibility for $n \leq 8$

For each $n \in \{2, 3, \ldots, 8\}$: $k$ must be even with $k \leq n-1 \leq 7$,
 but $8 \mid k$ requires $k \geq 8$. No valid $k$ exists, so all are impossible.

## Construction for $n = 9$

Take $(a_1, \ldots, a_9) = (2, 2, 1, 1, 1, 1, 1, 1, 1)$.

- $S = 2 + 2 + 7 \cdot 1 = 11$
- $Q = 4 + 4 + 7 \cdot 1 = 15$
- $S^2 - 1 = 121 - 1 = 120 = 8 \times 15 = 8Q$

So $Q \mid S^2 - 1$. ✓

(Here $k = 8$, $S = 11 \equiv 3 \pmod{8}$, $v_2(S^2-1) = v_2(120) = 3 = v_2(8)$,
 and $Q = 15$ is odd with $r = 7$ odd terms — all conditions satisfied.)

## Conclusion

The smallest integer $n \geq 2$ is $\boxed{9}$.
