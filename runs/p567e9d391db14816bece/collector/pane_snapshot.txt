## Proof

We verify the Leibniz rule for the Poisson bracket paired with the Jordan produc
t. Let $\circ$ denote ordinary composition (matrix multiplication) of operators.

**Definitions.**
$$A * B = \tfrac{1}{2}(A\circ B + B\circ A), \qquad \{A,B\}_{\hbar} = \tfrac{i}{
\hbar}(A\circ B - B\circ A).$$

**Left-hand side.** Using $B * C = \tfrac{1}{2}(B\circ C + C\circ B)$,

$$\{A, B*C\}_{\hbar} = \tfrac{i}{\hbar}\bigl(A\circ(B*C) - (B*C)\circ A\bigr).$$

Expanding both terms:

$$A\circ(B*C) = \tfrac{1}{2}(A\circ B\circ C + A\circ C\circ B),$$
$$(B*C)\circ A = \tfrac{1}{2}(B\circ C\circ A + C\circ B\circ A).$$

Hence

$$\{A, B*C\}_{\hbar} = \tfrac{i}{2\hbar}\bigl(A\circ B\circ C + A\circ C\circ B
- B\circ C\circ A - C\circ B\circ A\bigr). \tag{1}$$

**Right-hand side.** First,

$$\{A,B\}_{\hbar} * C = \tfrac{1}{2}\bigl(\{A,B\}_{\hbar}\circ C + C\circ\{A,B\}
_{\hbar}\bigr)$$
$$= \tfrac{i}{2\hbar}\bigl((A\circ B - B\circ A)\circ C + C\circ(A\circ B - B\ci
rc A)\bigr)$$
$$= \tfrac{i}{2\hbar}\bigl(A\circ B\circ C - B\circ A\circ C + C\circ A\circ B -
 C\circ B\circ A\bigr). \tag{2}$$

Similarly,

$$\{A,C\}_{\hbar} * B = \tfrac{1}{2}\bigl(\{A,C\}_{\hbar}\circ B + B\circ\{A,C\}
_{\hbar}\bigr)$$
$$= \tfrac{i}{2\hbar}\bigl(A\circ C\circ B - C\circ A\circ B + B\circ A\circ C -
 B\circ C\circ A\bigr). \tag{3}$$

Adding (2) and (3), the cross terms cancel: $-B\circ A\circ C + B\circ A\circ C
= 0$ and $+C\circ A\circ B - C\circ A\circ B = 0$. What remains is

$$\{A,B\}_{\hbar}*C + \{A,C\}_{\hbar}*B = \tfrac{i}{2\hbar}\bigl(A\circ B\circ C
 + A\circ C\circ B - C\circ B\circ A - B\circ C\circ A\bigr). \tag{4}$$

**Conclusion.** Expressions (1) and (4) are identical term-by-term:

$$\{A, B*C\}_{\hbar} = \tfrac{i}{2\hbar}\bigl(A\circ B\circ C + A\circ C\circ B
- B\circ C\circ A - C\circ B\circ A\bigr) = \{A,B\}_{\hbar}*C + \{A,C\}_{\hbar}*
B.$$

Therefore

$$\boxed{\{A, B * C\}_{\hbar} = \{A, B\}_{\hbar} * C + \{A, C\}_{\hbar} * B.}$$
