## 解答

设等边三角形 △ABC 的边长为 $s$，面积为 $\frac{\sqrt{3}}{4}s^2 = 7$，故 $s^2 = \f
rac{28}{\sqrt{3}}$，即 $s^2\sqrt{3} = 28$。

**建立坐标系。** 令 $A = (0,0)$，$B = (s, 0)$，$C = (s/2,\, s\sqrt{3}/2)$。

**参数化 M, N。** 设 $t = BM/s$，则 $BM = ts$，$MA = (1-t)s$。条件 $BM > MA$ 给
出 $t > 1/2$。又 $AN = BM = ts$，所以

$$N = t\cdot C = \left(\tfrac{ts}{2},\, \tfrac{ts\sqrt{3}}{2}\right), \qquad M =
 B - t(B-A) = (s(1-t),\, 0).$$

**求 O = BN ∩ CM。**

直线 $BN$: $B + u(N-B)$；直线 $CM$: $C + v(M-C)$。

由 $y$ 坐标相等得 $ut = 1 - v$，即 $v = 1 - ut$。代入 $x$ 坐标方程并化简：

$$u(t - 1 - t^2) = -t \quad\Longrightarrow\quad u = \frac{t}{1 - t + t^2}.$$

于是

$$\frac{O_x}{s} = \frac{1 - 2t + \tfrac{3}{2}t^2}{1 - t + t^2}, \qquad \frac{O_y
}{s} = \frac{t^2\sqrt{3}}{2(1 - t + t^2)}.$$

**计算 △BOC 面积。**

$$[\triangle BOC] = \frac{1}{2}\bigl|\det[\,O-B,\; C-B\,]\bigr| = \frac{s^2\sqrt
{3}\,t(1-t)}{4(1 - t + t^2)}.$$

代入 $s^2\sqrt{3} = 28$ 并令其等于 2：

$$\frac{7\,t(1-t)}{1 - t + t^2} = 2 \quad\Longrightarrow\quad 9t^2 - 9t + 2 = 0
\quad\Longrightarrow\quad t = \tfrac{2}{3}\;\text{或}\;\tfrac{1}{3}.$$

由 $t > 1/2$，取 $t = \dfrac{2}{3}$。

**确定 O 的坐标。**

$$\frac{O_x}{s} = \frac{1 - \tfrac{4}{3} + \tfrac{2}{3}}{\tfrac{1}{3} + \tfrac{4
}{9}} = \frac{\tfrac{1}{3}}{\tfrac{7}{9}} = \frac{3}{7}, \qquad \frac{O_y}{s} =
\frac{\tfrac{4}{9}\sqrt{3}}{2\cdot\tfrac{7}{9}} = \frac{2\sqrt{3}}{7}.$$

故 $O = \left(\dfrac{3s}{7},\, \dfrac{2s\sqrt{3}}{7}\right)$。

**计算 ∠AOB。**

$$\vec{OA} = \left(-\tfrac{3s}{7},\, -\tfrac{2s\sqrt{3}}{7}\right), \qquad \vec{
OB} = \left(\tfrac{4s}{7},\, -\tfrac{2s\sqrt{3}}{7}\right).$$

$$\vec{OA}\cdot\vec{OB} = -\tfrac{12s^2}{49} + \tfrac{12s^2}{49} = 0.$$

点积为零，故 $\vec{OA} \perp \vec{OB}$。

$$\boxed{\angle AOB = 90°}$$
