## Proof

**Setup.** Let triangle $ABC$ have $\angle A = 60°$, with sides $a = BC$, $b = C
A$, $c = AB$. By the Law of Cosines:
$$a^2 = b^2 + c^2 - 2bc\cos 60° = b^2 + c^2 - bc. \tag{1}$$

**Locating P and Q.** By the Angle Bisector Theorem:
- $P$ on $AC$: $\displaystyle AP = \frac{bc}{a+c}$, so set $x = AP = \frac{bc}{a
+c}$.
- $Q$ on $AB$: $\displaystyle AQ = \frac{bc}{a+b}$, so set $y = AQ = \frac{bc}{a
+b}$.

Since $\angle PAQ = \angle A = 60°$, triangle $APQ$ has included angle $60°$ bet
ween sides $x$ and $y$.

**Circumradius of APQ.** Let $d = PQ$. By the Law of Cosines in $\triangle APQ$:
$$d^2 = x^2 + y^2 - xy.$$
The circumradius is $R = \dfrac{d}{2\sin 60°} = \dfrac{d}{\sqrt{3}}$.

**The two inradii.**
$$r_1 = \frac{\text{Area}(ABC)}{s} = \frac{bc\sqrt{3}/4}{(a+b+c)/2} = \frac{bc\s
qrt{3}}{2(a+b+c)}. \tag{2}$$

$$r_2 = \frac{\text{Area}(APQ)}{s_2} = \frac{xy\sqrt{3}/4}{(x+y+d)/2} = \frac{xy
\sqrt{3}}{2(x+y+d)}. \tag{3}$$

**Key claim:** $R = 2(r_1 - r_2)$, i.e., $\dfrac{d}{\sqrt{3}} = 2\!\left[\dfrac{
bc\sqrt{3}}{2(a+b+c)} - \dfrac{xy\sqrt{3}}{2(x+y+d)}\right]$.

Dividing both sides by $\sqrt{3}$:
$$\frac{d}{3} = \frac{bc}{a+b+c} - \frac{xy}{x+y+d}. \tag{4}$$

**Proof of (4).** Rearranging:
$$\frac{d}{3} + \frac{xy}{x+y+d} = \frac{bc}{a+b+c}.$$

Combining the left side over a common denominator:
$$\frac{d(x+y+d) + 3xy}{3(x+y+d)} = \frac{bc}{a+b+c}.$$

Now simplify the numerator using $d^2 = x^2+y^2-xy$:
$$d(x+y) + d^2 + 3xy = d(x+y) + (x^2+y^2-xy) + 3xy = d(x+y) + x^2+y^2+2xy = d(x+
y)+(x+y)^2 = (x+y)(d+x+y).$$

So the left side becomes:
$$\frac{(x+y)(x+y+d)}{3(x+y+d)} = \frac{x+y}{3}.$$

Thus equation (4) reduces to:
$$\frac{x+y}{3} = \frac{bc}{a+b+c}, \quad\text{i.e.,}\quad (a+b+c)(x+y) = 3bc. \
tag{5}$$

**Verifying (5).** Compute $x+y$:
$$x + y = \frac{bc}{a+c} + \frac{bc}{a+b} = \frac{bc\big[(a+b)+(a+c)\big]}{(a+b)
(a+c)} = \frac{bc(2a+b+c)}{(a+b)(a+c)}.$$

Substituting into (5) and canceling $bc$:
$$\frac{(a+b+c)(2a+b+c)}{(a+b)(a+c)} \stackrel{?}{=} 3.$$

Expanding both sides:
- **LHS:** $(a+b+c)(2a+b+c) = 2a^2 + 3ab + 3ac + b^2 + 2bc + c^2$.
- **RHS:** $3(a+b)(a+c) = 3a^2 + 3ab + 3ac + 3bc$.

**LHS − RHS** $= -a^2 + b^2 + c^2 - bc = -(b^2+c^2-bc) + (b^2+c^2-bc) \cdot \fra
c{b^2+c^2-bc}{b^2+c^2-bc}$... directly:

$$\text{LHS} - \text{RHS} = -a^2 + b^2 + c^2 - bc.$$

By the Law of Cosines identity (1), $a^2 = b^2 + c^2 - bc$, so:
$$\text{LHS} - \text{RHS} = -(b^2+c^2-bc) + (b^2+c^2-bc) = 0. \quad\checkmark$$

Therefore (5) holds, which establishes (4), and hence:

$$\boxed{R = 2(r_1 - r_2)}.$$
