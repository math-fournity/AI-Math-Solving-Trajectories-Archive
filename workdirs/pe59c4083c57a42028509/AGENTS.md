# Problem

In a remote digital archives facility, there are 5 specialized security switches, each of which can be set to one of 4 distinct positions. A cohort of 2,000 security technicians participated in a calibration exercise where each technician submitted a unique configuration by choosing exactly one position for each of the 5 switches.

The facility manager wants to ensure a specific level of diversity among the submitted configurations. She is looking for the smallest possible integer $n$ such that the following condition can be met: within any group of $n$ technicians, there must exist at least 4 technicians who are "relatively unique" compared to one another. In this context, "relatively unique" means that for any 2 technicians chosen from that specific group of 4, they must have chosen the same position for no more than 3 of the 5 switches.

Find the least possible value of $n$ for which it is possible for the 2,000 submissions to satisfy this property.
