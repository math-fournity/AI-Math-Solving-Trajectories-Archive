## Key Structural Observation

**Claim:** In any optimal configuration, every drawn diagonal is Optimized (cros
ses exactly one other).

*Proof:* Adding a non-Optimized diagonal d can only *increase* crossing counts o
f existing diagonals. If d crosses an Optimized diagonal o, then o's count goes
from 1 to ≥2, destroying its Optimized status. If d crosses nothing, it contribu
tes 0 Optimized count. So non-Optimized diagonals never help — we may assume all
 drawn diagonals are Optimized.

**Consequence:** The crossing graph on the drawn diagonals has every vertex with
 degree exactly 1, so it is a disjoint union of **crossing pairs** — pairs (d₁,
d₂) where d₁ crosses d₂, and no diagonal from one pair crosses any diagonal from
 another pair.

## Recursive Decomposition

A crossing pair (a,c)–(b,d) with a < b < c < d (cyclically) divides the polygon
into **4 arcs** with interior vertex counts s₁, s₂, s₃, s₄ where s₁+s₂+s₃+s₄ = n
−4.

**Any diagonal f from another pair must not cross (a,c) or (b,d).** A diagonal c
rosses (a,c) iff it has endpoints on opposite sides of arc (a,c); similarly for
(b,d). Combining these constraints, f must have **both endpoints in the same one
 of the 4 arcs**. Thus each arc is an independent sub-problem: a convex (sᵢ+2)-g
on.

This gives the recursion (with g(2) = g(3) = 0):

$$g(n) = \max_{\substack{s_1+s_2+s_3+s_4=n-4 \\ s_i \ge 0}} \left[2 + g(s_1+2) +
 g(s_2+2) + g(s_3+2) + g(s_4+2)\right]$$

## Solving the Recursion

**Proposed solution:** $g(n) = 2\left\lfloor\frac{n-2}{2}\right\rfloor$, i.e., g
(n) = n−2 for even n, g(n) = n−3 for odd n.

**Verification of base cases:**
- g(3) = 0 (no diagonals exist) ✓
- g(4) = 2 (both diagonals cross each other, each crosses exactly 1) ✓
- g(5) = 2, g(6) = 4, g(7) = 4, g(8) = 6 (checked by exhaustive recursion) ✓

**Inductive step:** Assume g(m) = 2⌊(m−2)/2⌋ for all m < n. Then g(sᵢ+2) = 2⌊sᵢ/
2⌋. We maximize:

$$2 + 2\sum_{i=1}^{4}\left\lfloor\frac{s_i}{2}\right\rfloor \quad\text{subject t
o}\quad \sum s_i = n-4$$

Since ⌊sᵢ/2⌋ = (sᵢ − (sᵢ mod 2))/2, we get:

$$\sum\left\lfloor\frac{s_i}{2}\right\rfloor = \frac{(n-4) - (\text{number of od

- If n−4 is **even**: we can set all sᵢ even (0 odd), giving sum = (n−4)/2. Resu

- If n−4 is **odd**: we need an odd number of odd sᵢ (≥1), giving sum = (n−5)/2.
 Result: 2 + (n−5) = n−3.

These match 2⌊(n−2)/2⌋ exactly. The maximum is achieved by concentrating all exc
