**IMO 1986, Problem 5.** Find all functions $f:[0,\infty)\to[0,\infty)$ such tha
t
$$f(xf(y))f(y)=f(x+y)\quad\text{for all }x,y\ge 0,$$
$f(2)=0$, and $f(x)\ne 0$ for $0\le x<2$.

**Answer.** The unique solution is
$$f(x)=\begin{cases}\dfrac{2}{2-x},&0\le x<2,\\[4pt]0,&x\ge 2.\end{cases}$$

---

### Proof

**Step 1: $f(0)=1$.**

Set $x=0$ in the functional equation:
$$f(0\cdot f(y))\,f(y)=f(y)\implies f(0)\,f(y)=f(y).$$
Since $f(y)\ne 0$ for $y\in[0,2)$ (in particular $y=0$), we may divide by $f(0)$
's... actually divide by $f(y)$: $f(0)=1$.

**Step 2: $f(x)=0$ for all $x\ge 2$.**

Set $y=2$ (using $f(2)=0$):
$$f(x\,f(2))\,f(2)=f(x+2)\implies f(0)\cdot 0=f(x+2)\implies f(x+2)=0$$
for every $x\ge 0$. Hence $f(t)=0$ for all $t\ge 2$. Combined with the hypothesi
s $f(x)\ne 0$ for $0\le x<2$, we have established:

> $f(t)=0$ if and only if $t\ge 2$. $\qquad(\star)$

**Step 3: Determination of $f$ on $[0,2)$.**

Fix $y\in[0,2)$, so $f(y)>0$. The functional equation reads
$$f(x\,f(y))\,f(y)=f(x+y),\qquad x\ge 0.$$

Since $f(y)>0$, the sign of the left side is determined by $f(xf(y))$:

- If $x+y<2$: then $f(x+y)>0$ by $(\star)$, so $f(xf(y))>0$, hence $xf(y)<2$ by
$(\star)$.
- If $x+y\ge 2$: then $f(x+y)=0$ by $(\star)$, so $f(xf(y))=0$, hence $xf(y)\ge
2$ by $(\star)$.

Now take $x=2-y>0$ (since $y<2$). Then $x+y=2$, so $f(x+y)=f(2)=0$, giving
$$f\bigl((2-y)\,f(y)\bigr)=0\implies (2-y)\,f(y)\ge 2. \qquad(1)$$

For any $\varepsilon>0$, set $x=2-y-\varepsilon>0$. Then $x+y=2-\varepsilon<2$,
so $f(x+y)>0$, giving
$$f\bigl((2-y-\varepsilon)\,f(y)\bigr)>0\implies (2-y-\varepsilon)\,f(y)<2. \qqu
ad(2)$$

From (1) and (2):
$$(2-y-\varepsilon)\,f(y)<2\le (2-y)\,f(y)\quad\text{for all }\varepsilon>0.$$

Letting $\varepsilon\to 0^{+}$ yields $(2-y)\,f(y)=2$, i.e.,
$$\boxed{f(y)=\frac{2}{2-y}},\qquad 0\le y<2.$$

**Step 4: Verification.**

Define $f(x)=\dfrac{2}{2-x}$ for $0\le x<2$ and $f(x)=0$ for $x\ge 2$. We verify
 all conditions.

- $f(2)=0$ and $f(x)=\dfrac{2}{2-x}>0$ for $x\in[0,2)$: clear.

- **Case $y\ge 2$:** $f(y)=0$, so $f(xf(y))f(y)=f(0)\cdot 0=0$. Also $x+y\ge 2$,
 so $f(x+y)=0$. ✓

- **Case $y<2$, $x+y\ge 2$ (i.e.\ $x\ge 2-y$):** $f(y)=\dfrac{2}{2-y}>0$ and $xf
(y)=\dfrac{2x}{2-y}\ge\dfrac{2(2-y)}{2-y}=2$, so $f(xf(y))=0$, giving LHS $=0$.
Also $f(x+y)=0$ since $x+y\ge 2$. ✓

- **Case $y<2$, $x+y<2$ (i.e.\ $x<2-y$):** Then $xf(y)=\dfrac{2x}{2-y}<2$, so
$$f(xf(y))=\frac{2}{2-\frac{2x}{2-y}}=\frac{2}{\frac{2(2-y)-2x}{2-y}}=\frac{2(2-
y)}{2(2-y-x)}=\frac{2-y}{2-y-x}.$$
Thus
$$f(xf(y))\,f(y)=\frac{2-y}{2-y-x}\cdot\frac{2}{2-y}=\frac{2}{2-y-x}=\frac{2}{2-
(x+y)}=f(x+y). \quad\checkmark$$

All conditions are satisfied, and Steps 1–3 show this is the **only** possible f
unction. $\blacksquare$
