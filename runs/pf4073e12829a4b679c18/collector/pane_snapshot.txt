## Proof

**Claim:** The pairs are exactly $(a,a)$ for all $a \in \mathbb{N}$.

### Part 1: $(a,a)$ works.

If $a = b$, then $\pi(an)/\pi(bn) = 1$ for all $n$. Taking $P = Q = 1$ (both in
$\mathbb{Z}[x]$), the identity holds. ✓

### Part 2: $a \neq b$ is impossible.

Suppose $a \neq b$ and there exist $P, Q \in \mathbb{Z}[x]$ with $\frac{\pi(an)}
{\pi(bn)} = \frac{P(n)}{Q(n)}$ for all $n \geq 1$.

**Step 1: Asymptotic limit forces $\deg P = \deg Q$.**

By the Prime Number Theorem, $\pi(m) \sim \frac{m}{\ln m}$ as $m \to \infty$. Th
us as $n \to \infty$:

$$\frac{\pi(an)}{\pi(bn)} \sim \frac{an/\ln(an)}{bn/\ln(bn)} = \frac{a}{b}\cdot\
frac{\ln(bn)}{\ln(an)} \to \frac{a}{b},$$

since $\frac{\ln(bn)}{\ln(an)} = \frac{\ln n + \ln b}{\ln n + \ln a} \to 1$.

The rational function $R(n) = P(n)/Q(n)$ must satisfy $R(n) \to \frac{a}{b}$. Th
is forces $\deg P = \deg Q =: d$ (if $\deg P > \deg Q$, $R \to \infty$; if $\deg
 P < \deg Q$, $R \to 0 \neq \frac{a}{b}$ since $a,b \geq 1$). The leading coeffi
cient ratio equals $\frac{a}{b}$.

**Step 2: Rate of convergence gives a contradiction.**

With $\deg P = \deg Q = d$, write $P(n) = p_d n^d + p_{d-1}n^{d-1} + \cdots$ and
 $Q(n) = q_d n^d + q_{d-1}n^{d-1} + \cdots$. Then:

$$R(n) = \frac{p_d}{q_d} + \frac{p_{d-1}q_d - p_d q_{d-1}}{q_d^2}\cdot\frac{1}{n
} + O\!\left(\frac{1}{n^2}\right),$$

so $R(n) - \frac{a}{b} = O\!\left(\frac{1}{n}\right)$.

**Step 3: The actual deviation is $\Theta(1/\ln n)$, not $O(1/n)$.**

Using the refinement $\pi(m) = \frac{m}{\ln m}\left(1 + O\!\left(\frac{1}{\ln m}
\right)\right)$:

$$\frac{\pi(an)}{\pi(bn)} = \frac{a}{b}\cdot\frac{\ln(bn)}{\ln(an)}\cdot\left(1
+ O\!\left(\frac{1}{\ln n}\right)\right).$$

Now compute the key factor:

$$\frac{\ln(bn)}{\ln(an)} = \frac{\ln n + \ln b}{\ln n + \ln a} = 1 + \frac{\ln
b - \ln a}{\ln n + \ln a} = 1 + \frac{\ln(b/a)}{\ln(an)}.$$

Since $a \neq b$, we have $\ln(b/a) \neq 0$, so:

$$\frac{\pi(an)}{\pi(bn)} = \frac{a}{b} + \frac{a\ln(b/a)}{b\ln n}\left(1 + o(1)
\right) + O\!\left(\frac{1}{(\ln n)^2}\right) = \frac{a}{b} + \frac{C}{\ln n}\le
ft(1 + o(1)\right),$$

where $C = \frac{a\ln(b/a)}{b} \neq 0$.

Therefore $\frac{\pi(an)}{\pi(bn)} - \frac{a}{b} = \Theta\!\left(\frac{1}{\ln n}
\right)$.

**Step 4: Contradiction.**

If $R(n) = \frac{\pi(an)}{\pi(bn)}$ for all $n$, then:

$$R(n) - \frac{a}{b} = \Theta\!\left(\frac{1}{\ln n}\right) \quad \text{(from St
ep 3)},$$

but also:

$$R(n) - \frac{a}{b} = O\!\left(\frac{1}{n}\right) \quad \text{(from Step 2)}.$$

Since $\frac{1/\ln n}{1/n} = \frac{n}{\ln n} \to \infty$, we have $\frac{1}{\ln
n} \notin O\!\left(\frac{1}{n}\right)$. This is a contradiction. $\square$
