Let
$$I = \int_0^\infty \frac{dx}{(1+x^{2015})(1+x^2)}.$$

**Step 1: The substitution $x \mapsto 1/t$.**

Set $x = 1/t$, so $dx = -dt/t^2$. As $x: 0 \to \infty$, we have $t: \infty \to 0
$. Then
$$
1 + x^{2015} = 1 + t^{-2015} = \frac{t^{2015}+1}{t^{2015}}, \qquad
1 + x^2 = 1 + t^{-2} = \frac{t^2+1}{t^2}.
$$

Therefore
$$
I = \int_\infty^0 \frac{1}{\dfrac{t^{2015}+1}{t^{2015}}\cdot\dfrac{t^2+1}{t^2}}\
cdot\left(-\frac{dt}{t^2}\right)
= \int_0^\infty \frac{t^{2015}\cdot t^2}{(t^{2015}+1)(t^2+1)}\cdot\frac{dt}{t^2}
= \int_0^\infty \frac{t^{2015}}{(1+t^{2015})(1+t^2)}\,dt.
$$

Renaming the dummy variable $t\to x$,
$$I = \int_0^\infty \frac{x^{2015}}{(1+x^{2015})(1+x^2)}\,dx. \tag{2}$$

**Step 2: Add (1) and (2).**

$$
2I = \int_0^\infty \frac{1 + x^{2015}}{(1+x^{2015})(1+x^2)}\,dx
= \int_0^\infty \frac{dx}{1+x^2}.
$$

**Step 3: Evaluate the elementary integral.**

$$
\int_0^\infty \frac{dx}{1+x^2} = \arctan x\,\Big|_0^\infty = \frac{\pi}{2} - 0 =
 \frac{\pi}{2}.
$$

Hence $2I = \dfrac{\pi}{2}$, so

$$\boxed{I = \dfrac{\pi}{4}}.$$

**Remark.** The argument uses only that the exponent $2015$ appears symmetricall
y under $x\mapsto 1/x$ (since $x^{2015}\cdot x^{-2015}=1$). The same proof shows
 $\displaystyle\int_0^\infty \frac{dx}{(1+x^a)(1+x^2)}=\frac{\pi}{4}$ for every
real $a>0$.
