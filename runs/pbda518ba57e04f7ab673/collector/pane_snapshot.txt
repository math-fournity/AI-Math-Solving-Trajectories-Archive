## Solution

The differential equation is
$$x'(t) = x(t) - e^{-t^2}, \quad\text{i.e.}\quad x'(t)-x(t) = -e^{-t^2}.$$

**General solution.** Using the integrating factor $e^{-t}$,
$$\bigl(e^{-t}x(t)\bigr)' = -e^{-t^2-t},$$
so for an arbitrary reference point $t_0$ and constant $C$,
$$e^{-t}x(t) = C - \int_{t_0}^{t} e^{-s^2-s}\,ds, \qquad x(t) = e^{t}\!\left(C -
 \int_{t_0}^{t} e^{-s^2-s}\,ds\right). \tag{1}$$

**Boundary condition at $-\infty$.** Since $-s^2-s = -(s+\tfrac12)^2 + \tfrac14$
, the integrand $e^{-s^2-s}$ is integrable over $\mathbb{R}$ (total integral $e^
{1/4}\sqrt{\pi}$). Hence $\int_{t_0}^{t}e^{-s^2-s}ds$ stays bounded as $t\to-\in
fty$, while $e^t\to 0$. Therefore
$$\lim_{t\to-\infty} x(t) = 0$$
holds for **every** value of $C$. The first boundary condition imposes no constr
aint.

**Boundary condition at $+\infty$.** As $t\to+\infty$, the integral $\int_{t_0}^
{t}e^{-s^2-s}ds$ converges to the finite value
$$J := \int_{t_0}^{\infty} e^{-s^2-s}\,ds.$$
Thus from (1),
$$x(t) = e^{t}\bigl(C - J\bigr) + e^{t}\!\left(J - \int_{t_0}^{t} e^{-s^2-s}\,ds
\right) = e^{t}(C-J) + e^{t}\!\int_{t}^{\infty} e^{-s^2-s}\,ds. \tag{2}$$

For $\lim_{t\to+\infty}x(t)$ to be **finite**, the divergent term $e^t(C-J)$ mus
t vanish, forcing
$$C = J. \tag{3}$$
With this unique choice, the only candidate solution is
$$x_*(t) = e^{t}\!\int_{t}^{\infty} e^{-s^2-s}\,ds.$$

**Evaluating the candidate's limit.** Substitute $s = t+v$:
$$x_*(t) = e^{t}\!\int_{0}^{\infty} e^{-(t+v)^2-(t+v)}\,dv = e^{-t^2}\!\int_{0}^
{\infty} e^{-2tv - v^2 - v}\,dv.$$
For large $t$, the integral is dominated by $v\approx 0$, where $e^{-v^2-v}\appr
ox 1$ and $\int_0^\infty e^{-2tv}\,dv = \frac{1}{2t}$, giving
$$x_*(t) \sim \frac{e^{-t^2}}{2t} \xrightarrow[t\to+\infty]{} 0.$$
(Equivalently, $e^{1/4}\int_{t+1/2}^{\infty}e^{-u^2}du \sim \frac{e^{1/4}e^{-(t+
1/2)^2}}{2(t+1/2)}$, and multiplying by $e^t$ yields $\frac{e^{-t^2}}{2(t+1/2)}\
to 0$.)

Hence
$$\lim_{t\to+\infty} x_*(t) = 0 \neq \frac{\sqrt{\pi}}{2}.$$

**Conclusion.** The solution family is one-parameter (parameter $C$). The condit
ion at $-\infty$ is automatic. The condition at $+\infty$ first forces the uniqu
e value $C=J$ (to avoid divergence), and with that unique value the limit equals
 $0$, not $\frac{\sqrt\pi}{2}$. No value of $C$ produces the required limit $\fr
ac{\sqrt\pi}{2}$.

Therefore the number of solutions satisfying both boundary conditions is

$$\boxed{0}.$$
