## Proof

**Claim:** Yes, $A$ must be of the stated block-diagonal form.

**Step 1: $A$ commutes with $D$.**

Since $A^2 = D$, we have
$$AD = A\cdot A^2 = A^3 = A^2 \cdot A = DA.$$
Hence $AD = DA$.

**Step 2: $A$ preserves each eigenspace of $D$.**

Let $E_i = \{v : Dv = a_i v\}$ be the eigenspace of $D$ for eigenvalue $a_i$. If
 $v \in E_i$, then
$$D(Av) = A(Dv) = A(a_i v) = a_i (Av),$$
so $Av \in E_i$. Thus each $E_i$ is $A$-invariant.

Since $D$ is diagonal, $E_i$ is the span of those standard basis vectors $e_j$ f
or which $d_j = a_i$. Because the $d_j$ are sorted in nondecreasing order, these
 indices form a contiguous block. Therefore, in the standard basis, $A$ is block
 diagonal:
$$A = \operatorname{diag}(A_1, A_2, \dots, A_m),$$
where $A_i$ is a $k_i \times k_i$ real symmetric matrix ($k_i$ = multiplicity of
 $a_i$), and $A_i^2 = a_i I_{k_i}$.

**Step 3: Analysis of each block.**

- **If $a_i > 0$:** Set $B_i = \frac{1}{\sqrt{a_i}} A_i$. Then $B_i$ is real sym
metric and
  $$B_i^2 = \frac{1}{a_i} A_i^2 = \frac{1}{a_i}\cdot a_i I_{k_i} = I_{k_i}.$$
  Hence $A_i = \sqrt{a_i}\, B_i$ with $B_i$ symmetric and $B_i^2 = I$.

- **If $a_i = 0$ (i.e., $a_1 = 0$):** Then $A_i^2 = 0$. Since $A_i$ is symmetric
,
  $$\|A_i x\|^2 = x^\top A_i^\top A_i x = x^\top A_i^2 x = 0 \quad \text{for all
 } x,$$
  so $A_i x = 0$ for all $x$, giving $A_i = 0$. This equals $\sqrt{0}\, B_i = 0$
 for any symmetric $B_i$ with $B_i^2 = I$ (e.g., $B_i = I_{k_i}$).

**Conclusion.** In every case, $A_i = \sqrt{a_i}\, B_i$ where $B_i$ is symmetric
 and $B_i^2 = I_{k_i}$, with the block size matching the multiplicity of $a_i$.
Therefore $A$ must be exactly of the form
$$A = \operatorname{diag}(\sqrt{a_1}\,B_1,\ \sqrt{a_2}\,B_2,\ \dots,\ \sqrt{a_m}
\,B_m).$$
