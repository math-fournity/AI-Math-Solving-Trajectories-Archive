Looking at this problem, I need to find all values of $n$ (with $0 < n < 2017$)
for which a right isosceles triangle with integer vertices has exactly $n$ latti
ce points on its boundary.

## Setup

Place the right-angle vertex at the origin. The two equal legs go along integer
vectors $\mathbf{u} = (a,b)$ and $\mathbf{v}$, where $\mathbf{v} \perp \mathbf{u
}$ and $|\mathbf{v}| = |\mathbf{u}|$. Rotating $(a,b)$ by 90° gives $\mathbf{v}
= (-b, a)$, which is automatically an integer vector. So the triangle has vertic
es $(0,0)$, $(a,b)$, $(-b,a)$ with $a,b$ integers, not both zero.

## Counting Boundary Lattice Points

A lattice segment from $P$ to $Q$ contains $\gcd(|\Delta x|, |\Delta y|) + 1$ la
ttice points (including endpoints). The total boundary count (each vertex counte
d once) is:

$$n = [\gcd(|a|,|b|)+1] + [\gcd(|b|,|a|)+1] + [\gcd(|a+b|,|a-b|)+1] - 3$$

$$n = 2\gcd(|a|,|b|) + \gcd(|a+b|,|a-b|)$$

Let $d = \gcd(|a|,|b|)$, and write $a = da'$, $b = db'$ with $\gcd(a',b')=1$. Th
en:

$$n = 2d + d\cdot\gcd(|a'+b'|,|a'-b'|) = d\bigl(2 + \gcd(|a'+b'|,|a'-b'|)\bigr)$
$

## Key Lemma

**Claim:** $\gcd(|a'+b'|, |a'-b'|) \in \{1, 2\}$ when $\gcd(a',b') = 1$.

*Proof:* $\gcd(a'+b',\, a'-b')$ divides $(a'+b')+(a'-b') = 2a'$ and $(a'+b')-(a'
-b') = 2b'$, so it divides $\gcd(2a', 2b') = 2\gcd(a',b') = 2$.

- If $a', b'$ have **different parity**: $a'+b'$ and $a'-b'$ are both odd, so th
e gcd (which divides 2) must be **1**.
- If $a', b'$ are **both odd**: $a'+b'$ and $a'-b'$ are both even, so the gcd is
 **2**.
- Both even is impossible since $\gcd(a',b')=1$.

## Achievable Values

Therefore $n = d(2+1) = 3d$ or $n = d(2+2) = 4d$, i.e., **$n$ is a multiple of 3
 or a multiple of 4**.

**Conversely, every such value is achieved:**
- $n = 3d$: triangle $(0,0), (d,0), (0,d)$. Each side has $d+1$ points; total $=
 3(d+1)-3 = 3d$. ✓
- $n = 4d$: triangle $(0,0), (d,d), (-d,d)$. Sides have $d+1$, $d+1$, $2d+1$ poi
nts; total $= (d+1)+(d+1)+(2d+1)-3 = 4d$. ✓

## Counting

The achievable $n$ with $0 < n < 2017$ are exactly the multiples of 3 or 4 in $\
{1, 2, \ldots, 2016\}$.

- Multiples of 3: $\lfloor 2016/3 \rfloor = 672$
- Multiples of 4: $\lfloor 2016/4 \rfloor = 504$
- Multiples of 12 (double-counted): $\lfloor 2016/12 \rfloor = 168$

By inclusion–exclusion:

$$672 + 504 - 168 = \boxed{1008}$$
