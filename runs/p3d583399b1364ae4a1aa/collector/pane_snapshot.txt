## Proof

Let $f_n(x) = \prod_{k=1}^{n}\cos(kx)$. We compute $f_n''(0)$.

**Step 1: Logarithmic differentiation.** Since $f_n(x)\neq 0$ near $x=0$ (each f
actor $\cos(kx)\to 1$),

$$\ln f_n(x) = \sum_{k=1}^{n}\ln\cos(kx).$$

Differentiating,

$$\frac{f_n'(x)}{f_n(x)} = \sum_{k=1}^{n}\frac{-k\sin(kx)}{\cos(kx)} = -\sum_{k=
1}^{n}k\tan(kx),$$

so

$$f_n'(x) = -f_n(x)\sum_{k=1}^{n}k\tan(kx). \tag{1}$$

**Step 2: Second derivative.** Differentiating (1),

$$f_n''(x) = -f_n'(x)\sum_{k=1}^{n}k\tan(kx) - f_n(x)\sum_{k=1}^{n}k^{2}\sec^{2}
(kx). \tag{2}$$

**Step 3: Evaluate at $x=0$.** We have $\cos(k\cdot 0)=1$, $\tan(k\cdot 0)=0$, $
\sec(k\cdot 0)=1$. Hence

- $f_n(0) = \prod_{k=1}^{n}1 = 1$,
- $\sum_{k=1}^{n}k\tan(k\cdot 0) = 0$, so from (1), $f_n'(0) = -1\cdot 0 = 0$,
- $\sum_{k=1}^{n}k^{2}\sec^{2}(k\cdot 0) = \sum_{k=1}^{n}k^{2}$.

Substituting into (2):

$$f_n''(0) = -0\cdot 0 - 1\cdot\sum_{k=1}^{n}k^{2} = -\sum_{k=1}^{n}k^{2} = -\fr
ac{n(n+1)(2n+1)}{6}.$$

**Step 4: Solve the inequality.** We need

$$|f_n''(0)| = \frac{n(n+1)(2n+1)}{6} > 2023,$$

i.e. $n(n+1)(2n+1) > 12138$.

- For $n=17$: $\;17\cdot 18\cdot 35 = 10710$, and $10710/6 = 1785 \le 2023$. ✗
- For $n=18$: $\;18\cdot 19\cdot 37 = 12654$, and $12654/6 = 2109 > 2023$. ✓

Since $\frac{n(n+1)(2n+1)}{6}$ is strictly increasing in $n$, the smallest $n$ s
atisfying the inequality is

$$\boxed{n = 18}.$$
