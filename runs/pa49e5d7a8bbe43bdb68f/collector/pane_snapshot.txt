Looking at this problem, I need to find all integers $n$ with $3 \le n \le 100$
for which a balanced labeling of a regular $2n$-gon exists.

## Setting Up the Key Recurrence

Define $c_i = a_{i+n} - a_i$ for $i = 1, \ldots, 2n$ (indices mod $2n$). Note th
at $c_{i+n} = a_{i+2n} - a_{i+n} = a_i - a_{i+n} = -c_i$.

The balanced condition $a_i + a_{i+1} = a_{i+n} + a_{i+n+1}$ rearranges to:
$$(a_{i+n} - a_i) + (a_{i+n+1} - a_{i+1}) = 0 \implies c_i + c_{i+1} = 0$$

So $c_{i+1} = -c_i$ for all $i$, meaning $c$ **alternates with period 2**: $c_i
= (-1)^{i-1}\alpha$ for some constant $\alpha$.

## The Parity of $n$ is Decisive

**If $n$ is even:** Since $n$ is even, $i+n$ has the same parity as $i$, so $c_{
i+n} = c_i$ (same value in the alternating sequence). But $c_{i+n} = -c_i$, forc
ing $c_i = 0$ for all $i$, i.e., $a_{i+n} = a_i$. This contradicts the labels be
ing distinct. **No balanced labeling exists.**

**If $n$ is odd:** Since $n$ is odd, $i+n$ has opposite parity to $i$, so $c_{i+
n} = -c_i$ is **automatically satisfied** by the alternating pattern. We get $c_
i = \alpha$ for odd $i$ and $c_i = -\alpha$ for even $i$, with $\alpha \ne 0$.

## Existence for Odd $n$

For odd $n$, we need to partition $\{1, 2, \ldots, 2n\}$ into $n$ pairs $\{x, x+
\alpha\}$ (a perfect matching of the "$\alpha$-step graph"), then orient them: $
\frac{n+1}{2}$ pairs as $(x, x+\alpha)$ for odd positions, $\frac{n-1}{2}$ pairs
 as $(x+\alpha, x)$ for even positions.

**When does the perfect matching exist?** The $\alpha$-step graph forms paths by
 residue class mod $\alpha$. A perfect matching requires every path to have even
 length. Writing $2n = q\alpha + r$ with $0 \le r < \alpha$:
- If $r > 0$: paths have lengths $q$ and $q+1$; both can't be even, so **impossi
ble**.
- If $r = 0$ (i.e., $\alpha \mid 2n$): all paths have length $2n/\alpha$; need t
his even, i.e., **$\alpha \mid n$**.

**Taking $\alpha = n$ always works** (since $n \mid n$): the pairs are $\{1, n+1
\}, \{2, n+2\}, \ldots, \{n, 2n\}$, each path has length $2$ (even). The orienta
tion constraint is freely satisfiable since each pair can be oriented independen
tly.

**Verification ($n=3$, $\alpha=3$):** Pairs $\{1,4\}, \{2,5\}, \{3,6\}$. Set $a
= (1, 5, 3, 4, 2, 6)$. Check: $b_1=6, b_2=8, b_3=7, b_4=6, b_5=8, b_6=7$. We hav
e $b_1=b_4$, $b_2=b_5$, $b_3=b_6$. ✓

## Computing the Answer

$$S = \{n \in \{3,4,\ldots,100\} : n \text{ is odd}\} = \{3, 5, 7, \ldots, 99\}$
$

These are $2k+1$ for $k = 1, 2, \ldots, 49$. The sum is:
$$\sum_{k=1}^{49}(2k+1) = 2\cdot\frac{49\cdot 50}{2} + 49 = 2450 + 49 = 2499$$

Equivalently, the sum of all odd numbers from $1$ to $99$ is $50^2 = 2500$, minu
s $1$ gives $2499$.

## Proof Summary

1. The balanced condition forces $c_i = a_{i+n} - a_i$ to alternate: $c_i = (-1)
^{i-1}\alpha$.
2. The identity $c_{i+n} = -c_i$ is automatic for **odd** $n$ but forces $\alpha
 = 0$ (impossible) for **even** $n$.
3. For odd $n$, choosing $\alpha = n$ yields a valid perfect matching $\{k, k+n\
}$, $k=1,\ldots,n$, with freely assignable orientations — a balanced labeling al
ways exists.
4. Therefore $S = \{3, 5, 7, \ldots, 99\}$ and $\sum_{n \in S} n = \boxed{2499}$
.
