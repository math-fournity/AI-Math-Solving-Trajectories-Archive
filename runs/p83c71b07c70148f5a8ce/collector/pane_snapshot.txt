## Solution

**Setup.** Place the equilateral triangle in coordinates. Let $A = (0,0)$, $B =
(4,0)$, $C = (2, 2\sqrt{3})$.

- $M$ = midpoint of $AB$ = $(2, 0)$.
- $D$ on $BC$ with $BD:DC = 3:1$: $D = B + \tfrac{3}{4}(C-B) = \left(\tfrac{5}{2
},\, \tfrac{3\sqrt{3}}{2}\right)$.

**Direction of $MD$.** $\vec{MD} = D - M = \left(\tfrac{1}{2},\, \tfrac{3\sqrt{3
}}{2}\right)$, i.e., direction $(1,\, 3\sqrt{3})$.

**Line through $C$ parallel to $MD$.** Parametrize as
$$P(t) = (2+t,\; \sqrt{3}(2+3t)), \qquad t \in \mathbb{R}.$$
At $t=0$ we are at $C$. Setting $y=0$ gives $t = -\tfrac{2}{3}$, $x = \tfrac{4}{
3}$, which lies on $AB$. So the segment $C \to (\tfrac{4}{3},0)$ lies inside the
 triangle; thus $T = P(t)$ for some $t \in (-\tfrac{2}{3}, 0)$.

**Using $\angle CTA = 150^\circ$.** With $T = P(t)$:
$$\vec{TC} = (-t,\,-3\sqrt{3}\,t), \qquad \vec{TA} = (-(2+t),\,-\sqrt{3}(2+3t)).
$$
$$\vec{TC}\cdot\vec{TA} = t(20+28t),\quad |\vec{TC}| = -2\sqrt{7}\,t\ (t<0),\qua
d |\vec{TA}| = 2\sqrt{4+10t+7t^2}.$$
$$\cos\angle CTA = \frac{-(5+7t)}{\sqrt{7}\,\sqrt{4+10t+7t^2}} = \cos 150^\circ
= -\frac{\sqrt{3}}{2}.$$
Squaring: $\;\dfrac{(5+7t)^2}{7(4+10t+7t^2)} = \dfrac{3}{4}$, which simplifies t
o
$$49t^2 + 70t + 16 = 0 \implies t = \frac{-70 \pm 42}{98}.$$
The root in $(-\tfrac{2}{3},0)$ is $t = -\tfrac{2}{7}$ (the other root $-\tfrac{
8}{7}$ is outside). Sign check: $5+7t = 3 > 0$ matches $\sqrt{3}/2 > 0$. ✓

So $T = \left(\tfrac{12}{7},\, \tfrac{8\sqrt{3}}{7}\right)$.

**Computing $\angle MTD$.**
$$\vec{TM} = \left(\tfrac{2}{7},\, -\tfrac{8\sqrt{3}}{7}\right), \qquad \vec{TD}
 = \left(\tfrac{11}{14},\, \tfrac{5\sqrt{3}}{14}\right).$$
$$\vec{TM}\cdot\vec{TD} = \tfrac{22}{98} - \tfrac{120}{98} = -1.$$
$$|\vec{TM}| = \sqrt{\tfrac{4+192}{49}} = 2, \qquad |\vec{TD}| = \sqrt{\tfrac{12
1+75}{196}} = 1.$$
$$\cos\angle MTD = \frac{-1}{2\cdot 1} = -\frac{1}{2} \implies \angle MTD = 120^
\circ.$$

**Answer:** $\boxed{\angle MTD = 120^\circ}$.
