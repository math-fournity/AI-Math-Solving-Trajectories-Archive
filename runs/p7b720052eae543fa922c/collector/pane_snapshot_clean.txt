## Solution

**Setting up the logarithmic form.** Define $g(x) = \ln f(x)$. The functional eq
uation $f(x)f(1-x) = e^{x^2-x}$ becomes:

$$g(x) + g(1-x) = x^2 - x.$$

Since $f'(x)/f(x) = g'(x)$, the integral is:

$$I = \int_0^1 (2x^3 - 3x^2)\, g'(x)\, dx.$$

**Decomposing $g$.** Write $g(x) = \frac{x^2-x}{2} + h(x)$, where $h(x)+h(1-x)=0
$, i.e., $h$ is antisymmetric about $x=\tfrac12$. Then:

$$g'(x) = x - \tfrac12 + h'(x),$$

so

$$I = \underbrace{\int_0^1 (2x^3-3x^2)\!\left(x-\tfrac12\right)dx}_{I_1} + \unde
rbrace{\int_0^1 (2x^3-3x^2)\,h'(x)\,dx}_{I_2}.$$

**Computing $I_1$.** Expanding:

$$(2x^3-3x^2)\!\left(x-\tfrac12\right) = 2x^4 - 4x^3 + \tfrac32 x^2.$$

$$I_1 = \frac{2}{5} - 1 + \frac{1}{2} = \frac{4-10+5}{10} = -\frac{1}{10}.$$

**Showing $I_2 = 0$.** Integrate by parts with $p(x)=2x^3-3x^2$:

$$I_2 = \big[p(x)\,h(x)\big]_0^1 - \int_0^1 p'(x)\,h(x)\,dx.$$

- **Boundary term:** Since $f(1)=1$, we get $g(1)=0$, hence $h(1)=g(1)-\frac{1-1
}{2}=0$. By antisymmetry $h(0)=-h(1)=0$. Also $p(0)=0$ and $p(1)=-1$, so $[p\,h]
_0^1 = (-1)(0) - (0)(0) = 0$.
- **Remaining integral:** $p'(x)=6x^2-6x=-6x(1-x)$. The factor $x(1-x)$ is **sym
metric** about $x=\tfrac12$, while $h(x)$ is **antisymmetric** about $x=\tfrac12
$. Their product is antisymmetric, so:

$$\int_0^1 x(1-x)\,h(x)\,dx = 0.$$

Therefore $I_2 = 0$.

**Conclusion.**

$$I = I_1 + I_2 = -\frac{1}{10} + 0 = \boxed{-\dfrac{1}{10}}.$$
