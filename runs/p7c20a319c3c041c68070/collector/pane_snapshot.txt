## Proof

We compute \(E\!\left[B(U)\,B(U+V)\,B(U+V+W)\,B(U+V+W+x)\right]\) for standard B
rownian motion \(B(t)\), given \(U+V+W > U+V > U\) and \(x>0\). These inequaliti
es give \(V>0,\; W>0\) (with \(U\ge 0\)), so the four time points are strictly o
rdered:

\[
t_1 = U \;<\; t_2 = U+V \;<\; t_3 = U+V+W \;<\; t_4 = U+V+W+x .
\]

**Tool — Isserlis' theorem (Wick / Gaussian moment formula).** For jointly Gauss
ian, jointly zero-mean random variables \(X_1,\dots,X_{2n}\),

\[
E[X_1\cdots X_{2n}] = \sum_{\text{pairings } \pi} \prod_{\{i,j\}\in\pi} E[X_i X_
j],
\]

with the sum over all perfect matchings. For four variables there are exactly th
ree pairings:

\[
E[X_1X_2X_3X_4] = E[X_1X_2]E[X_3X_4] + E[X_1X_3]E[X_2X_4] + E[X_1X_4]E[X_2X_3].
\]

Brownian motion is a centered Gaussian process, so we may apply this with \(X_i
= B(t_i)\).

**Covariance of Brownian motion.** \(E[B(s)B(t)] = \min(s,t)\). Using the orderi
ng \(t_1<t_2<t_3<t_4\):

\[
\begin{aligned}
E[B(t_1)B(t_2)] &= \min(U,\,U+V) = U,\\
E[B(t_3)B(t_4)] &= \min(U+V+W,\,U+V+W+x) = U+V+W,\\
E[B(t_1)B(t_3)] &= \min(U,\,U+V+W) = U,\\
E[B(t_2)B(t_4)] &= \min(U+V,\,U+V+W+x) = U+V,\\
E[B(t_1)B(t_4)] &= \min(U,\,U+V+W+x) = U,\\
E[B(t_2)B(t_3)] &= \min(U+V,\,U+V+W) = U+V.
\end{aligned}
\]

**Substitute into Isserlis.**

\[
\begin{aligned}
E[B(t_1)B(t_2)B(t_3)B(t_4)]
&= U\,(U+V+W) \;+\; U\,(U+V) \;+\; U\,(U+V)\\
&= U(U+V+W) + 2U(U+V)\\
&= (U^2+UV+UW) + (2U^2+2UV)\\
&= 3U^2 + 3UV + UW\\
&= U\,(3U + 3V + W).
\end{aligned}
\]

**Sanity check (special case).** Set \(V=W=x=0\) (degenerate, all four times col
lapse to \(U\)): the formula gives \(3U^2\), which equals \(E[B(U)^4]=3U^2\), th
e well-known fourth moment of a centered Gaussian with variance \(U\). Consisten
t. Also, taking \(U=0\) gives \(0\), as expected since \(B(0)=0\).

\[
\boxed{\,E\!\left[B(U)\,B(U+V)\,B(U+V+W)\,B(U+V+W+x)\right] \;=\; 3U^{2}+3UV+UW
\;=\; U(3U+3V+W)\,}
\]
