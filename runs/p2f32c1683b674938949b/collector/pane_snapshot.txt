## Solution

The 12 containers have weights 1, 2, ..., 12 tons. Their total weight is

$$1+2+\cdots+12 = \frac{12\cdot 13}{2}=78.$$

For a balanced distribution, each ship must carry exactly half, i.e. **39 tons**
, with exactly 6 containers per ship.

### Setting up the count

We need to count the number of 6-element subsets $S\subseteq\{1,2,\dots,12\}$ wi
th $\sum_{s\in S}s = 39$. Since the two ships are identical (swapping Ship A and
 Ship B is not a new distribution), and since no 6-element subset can equal its
own complement, the subsets pair up as $\{S,\,S^c\}$, each pair giving one distr
ibution. So the answer is (number of such subsets) $/\,2$.

### Counting the subsets via a bijection to partitions

Write $S=\{a_1<a_2<\cdots<a_6\}$ with $a_i\in\{1,\dots,12\}$ and $\sum a_i=39$.
Set $b_i=a_i-i$. Then

$$0\le b_1\le b_2\le\cdots\le b_6\le 6,\qquad \sum_{i=1}^6 b_i = 39-(1+2+3+4+5+6
)=18.$$

So we need the number of **partitions of 18 into at most 6 parts, each part $\le
 6$** (i.e., partitions fitting inside a $6\times 6$ box).

### Dividing by 2

Each valid subset $S$ has complement $S^c$ also summing to $78-39=39$, and $S\ne
