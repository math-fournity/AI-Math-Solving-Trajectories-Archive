## Proof

We evaluate
$$I = \int_{0}^{\infty} \frac{e^{-x}\sin x}{x}\,dx$$
using Feynman's trick (differentiation under the integral sign).

**Step 1: Introduce a parameter.** For $a > 0$, define
$$I(a) = \int_{0}^{\infty} \frac{e^{-ax}\sin x}{x}\,dx.$$
We seek $I(1)$. Note that as $a \to \infty$, the factor $e^{-ax}$ forces the int
egrand to $0$ pointwise and dominates it, so by dominated convergence
$$\lim_{a\to\infty} I(a) = 0. \tag{1}$$

**Step 2: Differentiate under the integral sign.** For $a > 0$, the derivative o
f the integrand with respect to $a$ is $-e^{-ax}\sin x$, which is dominated on $
[0,\infty)$ by $e^{-a_0 x}$ for any $a_0 \in (0,a)$ (integrable). Thus
$$I'(a) = \int_{0}^{\infty} -e^{-ax}\sin x\,dx = -\int_{0}^{\infty} e^{-ax}\sin
x\,dx. \tag{2}$$

**Step 3: Compute the inner integral.** Using $\sin x = \operatorname{Im}(e^{ix}
)$,
$$\int_{0}^{\infty} e^{-ax}\sin x\,dx = \operatorname{Im}\!\int_{0}^{\infty} e^{
-(a-i)x}\,dx = \operatorname{Im}\!\left(\frac{1}{a-i}\right) = \operatorname{Im}
\!\left(\frac{a+i}{a^{2}+1}\right) = \frac{1}{a^{2}+1}. \tag{3}$$
(Convergence holds since $\operatorname{Re}(a-i)=a>0$.)

**Step 4: Solve the ODE.** Substituting (3) into (2):
$$I'(a) = -\frac{1}{a^{2}+1}.$$
Integrating,
$$I(a) = -\arctan a + C. \tag{4}$$

**Step 5: Determine the constant.** Letting $a \to \infty$ in (4) and using (1):
$$0 = -\frac{\pi}{2} + C \implies C = \frac{\pi}{2}.$$
Hence, for all $a > 0$,
$$I(a) = \frac{\pi}{2} - \arctan a = \arctan\!\left(\frac{1}{a}\right).$$

**Step 6: Evaluate at $a=1$.**
$$I(1) = \frac{\pi}{2} - \arctan(1) = \frac{\pi}{2} - \frac{\pi}{4} = \frac{\pi}
{4}.$$

Therefore,
$$\boxed{\int_{0}^{\infty} \frac{e^{-x}\sin x}{x}\,dx = \frac{\pi}{4}.}$$
