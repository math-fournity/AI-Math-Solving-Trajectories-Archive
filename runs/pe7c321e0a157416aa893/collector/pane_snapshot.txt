# Proof

**Setup.** Let $K$ be a CM field, Galois over $\mathbb{Q}$. Denote by $F$ its to
tally real subfield ($[K:F]=2$) and by $\rho$ the CM involution (the non-trivial
 automorphism of $K/F$). The defining property of a CM field is:

> **(CM property)** For every embedding $\sigma: K \hookrightarrow \mathbb{C}$ a
nd every $u \in K$,
> $$\overline{\sigma(u)} = \sigma(\rho(u)).$$

This holds because $K/\mathbb{Q}$ Galois forces $\rho$ to be central in $\operat
orname{Gal}(K/\mathbb{Q})$, so complex conjugation on $\sigma(K)$ corresponds to
 $\rho$ under every embedding.

---

**Claim.** If $u \in K$ satisfies $|\sigma_0(u)| = 1$ for some embedding $\sigma
_0: K \hookrightarrow \mathbb{C}$, then $|\sigma(u)| = 1$ for **every** embeddin
g $\sigma$.

**Step 1: Reduce to the totally real subfield.**

Using the CM property:
$$1 = |\sigma_0(u)|^2 = \sigma_0(u)\,\overline{\sigma_0(u)} = \sigma_0(u)\,\sigm
a_0(\rho(u)) = \sigma_0\!\bigl(u\,\rho(u)\bigr).$$

Set $\alpha := u\,\rho(u)$. Since $\rho(\alpha) = \rho(u)\cdot \rho^2(u) = \rho(
u)\cdot u = \alpha$, the element $\alpha$ is fixed by $\rho$, hence $\alpha \in
F$.

So we have $\sigma_0(\alpha) = 1$ with $\alpha \in F \subset K$.

**Step 2: $\alpha = 1$.**

Since $K/\mathbb{Q}$ is Galois, the set $\{\tau(\alpha) : \tau \in \operatorname
{Gal}(K/\mathbb{Q})\}$ is exactly the set of $\mathbb{Q}$-conjugates of $\alpha$
. The equality $\sigma_0(\alpha) = 1$ shows that $1$ is a conjugate of $\alpha$,
 i.e., $1$ is a root of the minimal polynomial $m_\alpha(x) \in \mathbb{Q}[x]$.

But $m_\alpha(x)$ is irreducible over $\mathbb{Q}$ and has $1$ as a root, so $(x
-1) \mid m_\alpha(x)$. By irreducibility, $m_\alpha(x) = x - 1$, whence
$$\alpha = u\,\rho(u) = 1.$$

**Step 3: All conjugates have absolute value 1.**

For any embedding $\sigma: K \hookrightarrow \mathbb{C}$:
$$|\sigma(u)|^2 = \sigma(u)\,\overline{\sigma(u)} = \sigma(u)\,\sigma(\rho(u)) =
 \sigma\!\bigl(u\,\rho(u)\bigr) = \sigma(1) = 1.$$

Therefore $|\sigma(u)| = 1$ for every embedding $\sigma$ of $K$ into $\mathbb{C}
$, i.e., **all conjugates of $u$ have absolute value 1**. $\blacksquare$

**Answer: Yes.** The key ingredients are (1) the CM property $\overline{\sigma(u
)}=\sigma(\rho(u))$, which pushes the question down to the element $u\rho(u) \in
 F$; and (2) the irreducibility of the minimal polynomial, which forces $u\rho(u
)=1$ once a single conjugate equals $1$—this is where the Galois hypothesis ente
rs, ensuring $\sigma_0(\alpha)$ is an honest $\mathbb{Q}$-conjugate of $\alpha$.
