## Proof

**Setup.** Let $G$ be a subgroup of $\mathbb{Z}_p^*$ of order $q$, with generato
r $\gamma$. We wish to compute $a = \log_\gamma \alpha$ for a given $\alpha \in
G$. Let $F: G \to \{0, \dots, q-1\}$ be a random function, and define the iterat
ion map
$$H(x) = x \cdot \alpha \cdot \gamma^{F(x)} \pmod{p}.$$

**Tracking exponents.** We maintain the representation $x_i = \alpha^{a_i} \gamm
a^{b_i} \pmod{p}$ with known exponents $a_i, b_i \in \mathbb{Z}/q\mathbb{Z}$. St
arting from $x_0 = \alpha^{a_0}\gamma^{b_0}$ for some chosen $(a_0, b_0)$, the u
pdate $x_{i+1} = H(x_i)$ gives:
$$a_{i+1} = a_i + 1 \pmod{q}, \qquad b_{i+1} = b_i + F(x_i) \pmod{q}.$$
Thus $a_i = a_0 + i \pmod{q}$ and $b_i$ is computable from the sequence of $F$-v
alues.

**$H$ is a random function.** Since $F$ is a random function and the map $x \map
sto x \cdot \alpha \cdot \gamma^{F(x)}$ is a bijection in $F(x)$ (for each fixed
 $x$), the composition $H: G \to G$ is itself a random function on the set $G$ o
f size $q$. The sequence $x_0, x_1, x_2, \dots$ is the iteration of a random fun
ction on a set of cardinality $q$.

**Applying Exercise 8.45.** Exercise 8.45 establishes the following for a random
 function on a set of size $n$:

- **(Expected rho length.)** The expected value of $\mu + \lambda$ — where $\mu$
 is the tail length (steps before entering the cycle) and $\lambda$ is the cycle
 length — is $O(\sqrt{n})$. More precisely, $\mathbb{E}[\mu] \approx \sqrt{\pi n
/8}$ and $\mathbb{E}[\lambda] \approx \sqrt{\pi n/8}$.

- **(Tail bound.)** The probability that the rho length $\mu + \lambda$ exceeds
$t$ is at most $\exp\!\bigl(-t(t-1)/(2n)\bigr)$ for $t \le n$.

Setting $n = q$:

- $\mathbb{E}[\mu + \lambda] = O(\sqrt{q})$.
- $\Pr[\mu + \lambda > q] \le \exp(-q/2)$, which is **exponentially small in $q$
**.

**Collision detection via Floyd's algorithm.** We run Floyd's cycle-finding algo
rithm: compute $(x_i, x_{2i})$ in parallel and stop at the first $i$ with $x_i =
 x_{2i}$. This detects the cycle in $O(\mu + \lambda)$ steps. By the above, the
expected number of steps is $O(\sqrt{q})$.

**Cost per step.** Each iteration requires:
1. **Evaluate $F(x_i)$:** $O(\mathrm{len}(q))$ bit operations (hashing/indexing)
.
2. **Compute $\gamma^{F(x_i)} \bmod p$:** The exponent $F(x_i) < q$ has $\mathrm
{len}(q)$ bits. By repeated squaring, this takes $O(\mathrm{len}(q))$ modular mu
ltiplications mod $p$, each costing $O(\mathrm{len}(p)^2)$ bit operations. Total
: $O(\mathrm{len}(q)\,\mathrm{len}(p)^2)$.
3. **Compute $x_i \cdot \alpha \bmod p$:** One modular multiplication, $O(\mathr
m{len}(p)^2)$.

The dominant cost is step 2, so each step costs $O(\mathrm{len}(q)\,\mathrm{len}
(p)^2)$ bit operations.

**Expected running time.** The expected number of iterations is $O(\sqrt{q})$, a
nd each iteration costs $O(\mathrm{len}(q)\,\mathrm{len}(p)^2)$. Therefore:
$$\mathbb{E}[\text{running time}] = O\!\left(q^{1/2}\right) \cdot O\!\left(\math
rm{len}(q)\,\mathrm{len}(p)^2\right) = O\!\left(q^{1/2}\,\mathrm{len}(q)\,\mathr
m{len}(p)^2\right).$$

**Extracting the discrete logarithm.** When Floyd's algorithm finds $x_i = x_j$
with $i > j$ (specifically $j = i$ in the tortoise–hare pairing, giving $i - j =
 \lambda$), we have:
$$\alpha^{a_i}\gamma^{b_i} = \alpha^{a_j}\gamma^{b_j} \implies \alpha^{a_i - a_j
} = \gamma^{b_j - b_i} \pmod{p}.$$
Since $a_i - a_j = i - j \pmod{q}$, this gives:
$$a \cdot (i - j) \equiv b_j - b_i \pmod{q}.$$
If $\gcd(i - j, q) = 1$, we solve immediately: $a = (b_j - b_i)(i - j)^{-1} \bmo
d q$. If $\gcd(i-j, q) > 1$, we restart with an independent fresh random functio
n $F$; each restart is an independent trial.

**Failure probability.** We cap the algorithm at $c \cdot q$ steps for a constan
t $c > 0$. The algorithm fails only if:

1. **No collision found within $cq$ steps:** By Exercise 8.45, $\Pr[\mu + \lambd
a > cq] \le \exp(-c^2 q / 2)$, which is exponentially small in $q$.

2. **Collision found but $\gcd(i-j, q) > 1$ (extraction fails):** We restart wit
h a fresh independent $F$. For prime $q$, this occurs only when $i - j \equiv 0
\pmod{q}$, i.e., the cycle length $\lambda = q$, which has probability $O(1/q)$.
 Each restart is independent, so after $O(q)$ restarts (which occur with vanishi
ngly small probability and do not affect the expected running time), the residua
l failure is $\exp(-\Omega(q))$. For general $q$, the number of prime factors of
 $q$ is $O(\mathrm{len}(q))$, so the per-trial success probability is at least $
1 - O(\mathrm{len}(q)/q)$, and a constant number of independent retries suffices
 w.h.p.

Combining both sources, the overall probability of failure is $\exp(-\Omega(q))$
, **exponentially small in $q$**.

**Space efficiency.** The algorithm stores only $O(1)$ group elements and expone
nts (the tortoise and hare states), using $O(\mathrm{len}(p) + \mathrm{len}(q))$
 space, independent of $\sqrt{q}$ — unlike baby-step giant-step which requires $
O(\sqrt{q})$ space.

**Conclusion.** Assuming $F$ is a random function, the space-efficient square-ro
ot discrete logarithm algorithm has:
- **Expected running time** $O\!\left(q^{1/2}\,\mathrm{len}(q)\,\mathrm{len}(p)^
2\right)$, from $O(\sqrt{q})$ expected iterations (by Exercise 8.45) each costin
g $O(\mathrm{len}(q)\,\mathrm{len}(p)^2)$ bit operations.
- **Failure probability** $\exp(-\Omega(q))$, exponentially small in $q$, from t
he tail bound of Exercise 8.45 on the rho length of a random function on $q$ ele
ments.
