## 答案：是的。

**定理.** 对于每个 $h \ge 0$，都存在一个概率空间 $(X, \mathcal{B}, \mu)$ 和一个
保测变换 $T \colon X \to X$，其 Kolmogorov–Sinai 熵为 $h_\mu(T) = h$。

### 证明

我们使用自然对数（底数的选择无关紧要；改变底数只会对熵进行常数缩放）。

**构造（Bernoulli 移位）。** 设 $\nu = (p_1, \dots, p_n)$ 为 $\{1, \dots, n\}$
上的一个概率向量。令
$$X = \{1, \dots, n\}^{\mathbb{Z}}, \qquad \mu = \bigotimes_{k \in \mathbb{Z}} \
nu, \qquad \sigma\big((x_k)_{k \in \mathbb{Z}}\big) = (x_{k+1})_{k \in \mathbb{Z
}}.$$
乘积测度 $\mu$ 在移位 $\sigma$ 下是不变的，因此 $\sigma$ 是一个保测变换。

设 $\mathcal{P} = \{A_i : 1 \le i \le n\}$，其中 $A_i = \{x \in X : x_0 = i\}$。
这是生成 $\sigma$-代数（在零测集意义下）的**生成划分**，因为 $\bigvee_{k=-\infty
}^{\infty} \sigma^{-k}\mathcal{P}$ 生成了 $X$ 上的柱集代数，从而生成了 $\mathcal
{B}$。由 Kolmogorov–Sinai 定理，
$$h_\mu(\sigma) = h_\mu(\sigma, \mathcal{P}) = \lim_{N \to \infty} \frac{1}{N} H
\!\left(\bigvee_{k=0}^{N-1} \sigma^{-k}\mathcal{P}\right).$$

由于 $\mu$ 是乘积测度，划分 $\sigma^{-k}\mathcal{P}$ ($k = 0, \dots, N-1$) 是**
相互独立**的。因此
$$H\!\left(\bigvee_{k=0}^{N-1} \sigma^{-k}\mathcal{P}\right) = \sum_{k=0}^{N-1}
H(\sigma^{-k}\mathcal{P}) = N \cdot H(\mathcal{P}),$$
其中 $H(\mathcal{P}) = -\sum_{i=1}^{n} p_i \log p_i$（约定 $0 \log 0 = 0$）。因
此
$$h_\mu(\sigma) = H(\mathcal{P}) = -\sum_{i=1}^{n} p_i \log p_i =: H(\nu).$$

**$H$ 的值域。** 我们证明对于每个 $h \ge 0$，都存在某个 $n$ 和某个概率向量 $\nu
\in \Delta_n$ 使得 $H(\nu) = h$。

1. **连续性.** $H(\nu) = -\sum p_i \log p_i$ 在单纯形 $\Delta_n = \{(p_1,\dots,p
_n) : p_i \ge 0,\ \sum p_i = 1\}$ 上是连续的（约定 $0\log 0 = 0$）。

2. **零点.** 在 $\Delta_n$ 的顶点处，例如 $\nu = (1, 0, \dots, 0)$，有 $H(\nu) =
 -1\log 1 - 0 - \cdots = 0$。

3. **最大值.** 在重心 $\nu = (1/n, \dots, 1/n)$ 处，有 $H(\nu) = -n \cdot \tfrac
{1}{n}\log\tfrac{1}{n} = \log n$。

4. **介值性质.** $\Delta_n$ 是凸的（因此是连通的）。沿从顶点 $(1, 0, \dots, 0)$
到重心 $(1/n, \dots, 1/n)$ 的线段
$$\nu(t) = (1-t)(1,0,\dots,0) + t\!\left(\tfrac{1}{n},\dots,\tfrac{1}{n}\right),
 \qquad t \in [0,1],$$
函数 $t \mapsto H(\nu(t))$ 是连续的，$H(\nu(0)) = 0$，且 $H(\nu(1)) = \log n$。
由介值定理，$H$ 可取到 $[0, \log n]$ 中的每一个值。

5. **覆盖 $[0, \infty)$.** 给定 $h \ge 0$，选取 $n \ge 1$ 使得 $\log n \ge h$（
因为 $\log n \to \infty$，这是可能的）。由第 4 步，存在 $\nu \in \Delta_n$ 使得
$H(\nu) = h$。对应的 Bernoulli 移位 $\sigma$ 满足 $h_\mu(\sigma) = h$。

**边界情况 $h = 0$.** 选取 $n = 1$（或 $\nu = (1, 0, \dots, 0)$）；Bernoulli 移
位退化为恒等变换，其熵为 $0$。另外，有限空间上的恒等变换其熵也为 $0$。

因此，对于每个 $h \ge 0$，都存在一个保测变换，其 Kolmogorov–Sinai 熵恰好为 $h$。
$\blacksquare$
