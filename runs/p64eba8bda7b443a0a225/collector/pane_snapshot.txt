## Proof

Let $a, b, c$ be the roots of $x^3 - 2018x + 2018 = 0$. By Vieta's formulas:

$$a+b+c = 0, \quad ab+bc+ca = -2018, \quad abc = -2018.$$

**Power sums via recurrence.** Each root satisfies $x^3 = 2018x - 2018$, so the
power sums $S_n = a^n+b^n+c^n$ obey

$$S_{n+3} = 2018\,S_{n+1} - 2018\,S_n.$$

Initial values:
- $S_0 = 3$
- $S_1 = a+b+c = 0$
- $S_2 = (a+b+c)^2 - 2(ab+bc+ca) = -2(-2018) = 4036$

Computing forward:
- $S_3 = 2018(S_1 - S_0) = 2018(0-3) = -6054$
- $S_4 = 2018(S_2 - S_1) = 2018\cdot 4036$
- $S_5 = 2018(S_3 - S_2) = 2018(-6054-4036) = 2018(-10090) = -20361620$

**Average outputs $T_n = S_n/n$.**
- $T_1 = 0/1 = 0$
- $T_2 = 4036/2 = 2018$
- $T_3 = -6054/3 = -2018$
- $T_4 = 2018\cdot 4036/4 = 2018\cdot 1009 = 2034162$
- $T_5 = -20361620/5 = -4072324$

**Searching for the smallest $q$.** We need $T_{p+q} = T_p\cdot T_q$ with $0 < p
 \le q$.

*Case $q=1$:* Only $p=1$. Then $T_2 = T_1^2 = 0$, but $T_2 = 2018 \ne 0$. No sol
ution.

*Case $q=2$:* Either $p=1$ or $p=2$.
- $p=1$: $T_3 = T_1\cdot T_2 = 0$, but $T_3 = -2018 \ne 0$.
- $p=2$: $T_4 = T_2^2 = 2018^2 = 4072324$, but $T_4 = 2034162 \ne 4072324$.

No solution with $q=2$.

*Case $q=3$:* Try $p=2$ (since $p\le q$ and $p=1$ gives $T_4 = T_1\cdot T_3 = 0
\ne 2034162$).
- $p=2, q=3$: $p+q=5$, and
$$T_2\cdot T_3 = 2018 \times (-2018) = -4072324 = T_5. \quad \checkmark$$

The condition $\dfrac{S_{p+q}}{p+q} = \dfrac{S_p}{p}\cdot\dfrac{S_q}{q}$ is sati
sfied.

**Verification of $T_5 = T_2 T_3$:**
$$T_5 = \frac{S_5}{5} = \frac{-20361620}{5} = -4072324, \qquad T_2\cdot T_3 = 20
18\cdot(-2018) = -4072324. \quad \checkmark$$

**Conclusion.** The smallest integer $q$ satisfying the equilibrium condition is
 $q=3$, with $p=2$. The stability index is

$$p^2 + q^2 = 2^2 + 3^2 = 4 + 9 = \boxed{13}.$$
