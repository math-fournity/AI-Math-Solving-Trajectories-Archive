## Solution

**Step 1: Solve the recurrence (condition 3).**

Condition (3) gives $f(x+1) = 2f(x) + x - 1$.

This is a linear non-homogeneous recurrence. The homogeneous part $f(x+1)=2f(x)$
 has solution $C\cdot 2^x$. For a particular solution, try $f(x)=ax+b$:
$$a(x+1)+b = 2(ax+b)+x-1 \implies a = 2a+1,\ a+b = 2b-1$$
giving $a=-1,\ b=0$, i.e. the particular solution is $-x$.

So the general solution is
$$f(x) = -x + C\cdot 2^x,\qquad C\in\mathbb{R}.$$

**Step 2: Use condition (2) to pin down $C$.**

Substitute $f(x)=-x+C\cdot 2^x$ into
$$f(x+y)-xf(y)-yf(x)=f(x)f(y)-x-y+xy.$$

Left-hand side:
$$-(x+y)+C\cdot 2^{x+y} - x(-y+C\cdot 2^y) - y(-x+C\cdot 2^x)$$
$$= -x-y+2xy + C\cdot 2^{x+y} - xC\cdot 2^y - yC\cdot 2^x.$$

Right-hand side:
$$(-x+C\cdot 2^x)(-y+C\cdot 2^y)-x-y+xy$$
$$= xy - xC\cdot 2^y - yC\cdot 2^x + C^2\cdot 2^{x+y} - x - y + xy$$
$$= -x-y+2xy - xC\cdot 2^y - yC\cdot 2^x + C^2\cdot 2^{x+y}.$$

Equating the two sides, all terms cancel except the $2^{x+y}$ terms:
$$C\cdot 2^{x+y} = C^2\cdot 2^{x+y}\implies C=C^2\implies C\in\{0,1\}.$$

**Step 3: Use condition (1) to select $C$.**

- If $C=0$: $f(x)=-x$, so $f(1)+1 = -1+1 = 0$, which is **not** $>0$. Rejected.
- If $C=1$: $f(x)=2^x-x$, so $f(1)+1 = 2-1+1 = 2 > 0$. Accepted.

**Step 4: Compute $f(10)$.**

$$f(10) = 2^{10} - 10 = 1024 - 10 = \boxed{1014}.$$
