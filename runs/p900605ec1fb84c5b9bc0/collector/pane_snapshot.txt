odd, and $f(k) = 997$ if $k$ is even.

$$f(n) = f(f(n+5))$$

ase range, so $f(f(n+5))$ is well-defined and matches the pattern.

The base cases (Step 1) anchor the induction, so by strong induction:

$$f(n) = \begin{cases} 998 & n \text{ odd},\ n < 1000 \\ 997 & n \text{ even},\
n < 1000 \end{cases}$$

Since $84 < 1000$ and $84$ is **even**:

$$f(84) = 997$$
