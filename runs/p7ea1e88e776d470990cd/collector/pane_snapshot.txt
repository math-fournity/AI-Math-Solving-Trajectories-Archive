# Evaluation of the Integral

$$I = \int_{-\infty}^{+\infty}\int_{0}^{+\infty} x\, e^{-x^{2}e^{y}}\, \Gamma(0,
\,x^{2})\, dy\, dx$$

## Step 1: Compute the inner integral over $y$

Since $\Gamma(0, x^2)$ is independent of $y$, we factor it out:

$$\int_0^{\infty} x\, e^{-x^2 e^y}\, \Gamma(0, x^2)\, dy = x\, \Gamma(0, x^2) \i
nt_0^{\infty} e^{-x^2 e^y}\, dy.$$

**Substitution** $u = e^y$, $du = u\,dy$, so $dy = du/u$. Limits: $y=0 \Rightarr
ow u=1$; $y\to\infty \Rightarrow u\to\infty$:

$$\int_0^{\infty} e^{-x^2 e^y}\, dy = \int_1^{\infty} \frac{e^{-x^2 u}}{u}\, du.
$$

**Substitution** $t = x^2 u$, $dt = x^2\, du$, $u = t/x^2$. Limits: $u=1 \Righta
rrow t = x^2$; $u\to\infty \Rightarrow t\to\infty$:

$$\int_1^{\infty} \frac{e^{-x^2 u}}{u}\, du = \int_{x^2}^{\infty} \frac{e^{-t}}{
t}\, dt = \Gamma(0, x^2).$$

Therefore:

$$\int_0^{\infty} x\, e^{-x^2 e^y}\, \Gamma(0, x^2)\, dy = x\, \Gamma(0, x^2)^2.
$$

## Step 2: Reduce to a single integral

$$I = \int_{-\infty}^{+\infty} x\, \Gamma(0, x^2)^2\, dx.$$

## Step 3: Symmetry argument

The function $\Gamma(0, x^2)^2$ depends only on $x^2$, hence is **even** in $x$.
 The factor $x$ is **odd**. Therefore the integrand $f(x) = x\,\Gamma(0, x^2)^2$
 is an **odd function**:

$$f(-x) = -f(x).$$

## Step 4: Verify absolute convergence (so the symmetry argument is valid)

We check $\int_{-\infty}^{+\infty} |x|\, \Gamma(0, x^2)^2\, dx < \infty$.

**Near $x = 0$:** Using $\Gamma(0, z) = -\ln z - \gamma + O(z)$ as $z \to 0^+$,
we get $\Gamma(0, x^2) \sim -2\ln|x|$, so

$$|x|\, \Gamma(0, x^2)^2 \sim 4|x|\,(\ln|x|)^2 \to 0 \quad\text{as } x\to 0,$$

and $\int_0^1 x\,(\ln x)^2\, dx$ converges (standard result: $\int_0^1 x^a (\ln
x)^n dx$ converges for $a > -1$).

**As $|x| \to \infty$:** Using the asymptotic $\Gamma(0, z) \sim \frac{e^{-z}}{z
}$ as $z \to \infty$,

$$|x|\, \Gamma(0, x^2)^2 \sim |x|\cdot \frac{e^{-2x^2}}{x^4} = \frac{e^{-2x^2}}{
x^3},$$

which is integrable on $[1, \infty)$.

Hence the integral converges **absolutely**, and the integral of the odd integra
nd over the symmetric domain $(-\infty, +\infty)$ is:

$$I = 0.$$

## Result

$$\boxed{I = 0}$$
