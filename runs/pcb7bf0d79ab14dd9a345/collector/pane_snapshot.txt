### 第一步：变量代换

令 $x = t\pi$，则 $t = x/\pi$，$dt = dx/\pi$，积分限 $[0,1]\to[0,\pi]$：

$$I = \frac{1}{\pi^3}\int_0^\pi x^2 \cos(2x)\tan x\,\ln(\sin x)\,dx$$

### 第二步：化简被积函数

利用 $\cos(2x) = 2\cos^2 x - 1$：

$$\cos(2x)\tan x = (2\cos^2 x - 1)\frac{\sin x}{\cos x} = 2\sin x\cos x - \frac{
\sin x}{\cos x} = \sin(2x) - \tan x$$

因此 $I = \frac{1}{\pi^3}(J_1 - J_2)$，其中：
$$J_1 = \int_0^\pi x^2\sin(2x)\ln(\sin x)\,dx, \qquad J_2 = \int_0^\pi x^2\tan x
\,\ln(\sin x)\,dx$$

### 第三步：计算 $J_1$（利用对称性 + Fourier 级数）

**对称性**：在变换 $x\to\pi-x$ 下，$\sin(2(\pi-x))=-\sin(2x)$，$\ln(\sin(\pi-x))
=\ln(\sin x)$。设 $A=\int_0^\pi\sin(2x)\ln(\sin x)\,dx$，则 $A=-A\Rightarrow A=0
$。

对 $J_1$ 做同样的代换并相加：
$$2J_1 = \int_0^\pi[x^2-(\pi-x)^2]\sin(2x)\ln(\sin x)\,dx = \int_0^\pi(2\pi x-\p
i^2)\sin(2x)\ln(\sin x)\,dx$$

由于 $A=0$，得 $J_1 = \pi B$，其中 $B=\int_0^\pi x\sin(2x)\ln(\sin x)\,dx$。

**Fourier 级数法计算 $B$**：利用 $\ln(\sin x)=-\ln 2-\sum_{k=1}^\infty\frac{\cos
(2kx)}{k}$：

$$B = -\ln 2\int_0^\pi x\sin(2x)\,dx - \sum_{k=1}^\infty\frac{1}{k}\int_0^\pi x\
sin(2x)\cos(2kx)\,dx$$

- $\int_0^\pi x\sin(2x)\,dx = -\frac{\pi}{2}$

- 利用 $\sin(2x)\cos(2kx)=\frac{1}{2}[\sin(2(k+1)x)+\sin(2(1-k)x)]$ 和 $\int_0^\
pi x\sin(2nx)\,dx=-\frac{\pi}{2n}$（$n\neq 0$）：
  - $k=1$：$\int = -\frac{\pi}{8}$
  - $k\geq 2$：$\int = \frac{\pi}{2(k^2-1)}$

$$B = \frac{\pi\ln 2}{2}+\frac{\pi}{8}-\frac{\pi}{2}\sum_{k=2}^\infty\frac{1}{k(
k^2-1)}$$

**求和**：部分分式 $\frac{1}{k(k^2-1)}=\frac{1}{2(k-1)}-\frac{1}{k}+\frac{1}{2(k
+1)}$，裂项求和得 $\sum_{k=2}^\infty\frac{1}{k(k^2-1)}=\frac{1}{4}$。

$$B = \frac{\pi\ln 2}{2}+\frac{\pi}{8}-\frac{\pi}{8} = \frac{\pi\ln 2}{2}$$

$$\boxed{J_1 = \pi B = \frac{\pi^2\ln 2}{2}}$$

### 第四步：计算 $J_2$（分部积分 + 对称性）

**关键原函数**：验证 $\frac{d}{dx}\left[\frac{1}{4}\text{Li}_2(\cos^2 x)\right]=
\tan x\,\ln(\sin x)$（通过链式法则和 $\text{Li}_2'(z)=-\frac{\ln(1-z)}{z}$ 直接
验证）。

分部积分（$u=x^2$，$dv=\tan x\,\ln(\sin x)\,dx$）：

$$J_2 = \left[\frac{x^2}{4}\text{Li}_2(\cos^2 x)\right]_0^\pi - \frac{1}{2}\int_
0^\pi x\,\text{Li}_2(\cos^2 x)\,dx$$

边界项：$\text{Li}_2(\cos^2\pi)=\text{Li}_2(1)=\frac{\pi^2}{6}$，故 $=\frac{\pi^
4}{24}$。

由 $\text{Li}_2(\cos^2(\pi-x))=\text{Li}_2(\cos^2 x)$ 的对称性：$\int_0^\pi x\,\
text{Li}_2(\cos^2 x)\,dx=\frac{\pi}{2}K$，其中 $K=\int_0^\pi\text{Li}_2(\cos^2 x
)\,dx=2M$，$M=\int_0^{\pi/2}\text{Li}_2(\cos^2 x)\,dx$。

$$J_2 = \frac{\pi^4}{24}-\frac{\pi K}{4}$$

**计算 $M$**：利用 $\text{Li}_2(1-z)=\frac{\pi^2}{6}-\ln z\,\ln(1-z)-\text{Li}_2
(z)$，取 $z=\sin^2 x$：

$$\text{Li}_2(\cos^2 x)=\frac{\pi^2}{6}-4\ln(\sin x)\ln(\cos x)-\text{Li}_2(\sin
^2 x)$$

设 $L=\int_0^{\pi/2}\text{Li}_2(\sin^2 x)\,dx$。由 $x\to\frac{\pi}{2}-x$ 的对称
性，$L=M$。利用已知结果 $\int_0^{\pi/2}\ln(\sin x)\ln(\cos x)\,dx=\frac{\pi\ln^2
 2}{2}-\frac{\pi^3}{48}$（通过 Fourier 级数验证）：

$$M = \frac{\pi^3}{12}-4\left(\frac{\pi\ln^2 2}{2}-\frac{\pi^3}{48}\right)-L = \
frac{\pi^3}{6}-2\pi\ln^2 2-M$$

$$M = \frac{\pi^3}{12}-\pi\ln^2 2, \qquad K = 2M = \frac{\pi^3}{6}-2\pi\ln^2 2$$

$$J_2 = \frac{\pi^4}{24}-\frac{\pi}{4}\left(\frac{\pi^3}{6}-2\pi\ln^2 2\right) =
 \frac{\pi^4}{24}-\frac{\pi^4}{24}+\frac{\pi^2\ln^2 2}{2} = \frac{\pi^2\ln^2 2}{
2}$$

### 第五步：合并结果

$$I = \frac{1}{\pi^3}\left(\frac{\pi^2\ln 2}{2}-\frac{\pi^2\ln^2 2}{2}\right) =
\frac{\pi^2\ln 2(1-\ln 2)}{2\pi^3}$$

$$\boxed{I = \frac{\ln 2\,(1-\ln 2)}{2\pi}}$$
