## Proof

We seek the largest $a$ and smallest $b$ with $ax(\pi-x)\le \sin x \le bx(\pi-x)
$ for all $x\in[0,\pi]$.

**Reduction.** At $x=0$ and $x=\pi$ both sides vanish, so the constraint lives o
n $(0,\pi)$. Define
\[
f(x)=\frac{\sin x}{x(\pi-x)},\qquad x\in(0,\pi).
\]
The inequality is $a\le f(x)\le b$ for all $x\in(0,\pi)$, so $a=\inf f$ and $b=\
sup f$. Note $f(\pi-x)=f(x)$, so $f$ is symmetric about $\pi/2$.

**Endpoint limits.** $\displaystyle\lim_{x\to 0^+}f(x)=\lim_{x\to 0^+}\frac{\sin
 x}{x}\cdot\frac{1}{\pi-x}=\frac{1}{\pi}$, and by symmetry $\displaystyle\lim_{x
\to\pi^-}f(x)=\frac{1}{\pi}$.

**Value at the midpoint.** $f(\pi/2)=\dfrac{1}{(\pi/2)^2}=\dfrac{4}{\pi^2}$.

---

### Upper bound: $\sin x\le \dfrac{4}{\pi^2}x(\pi-x)$

Substitute $x=\pi t$, $t\in[0,1]$. The inequality becomes $\sin(\pi t)\le 4t(1-t
)$.

Set $s=t-\tfrac12\in[-\tfrac12,\tfrac12]$. Then $\sin(\pi t)=\cos(\pi s)$ and $4
t(1-t)=1-4s^2$, so we need
\[
\cos(\pi s)\le 1-4s^2\iff 1-\cos(\pi s)\ge 4s^2\iff 2\sin^2\!\tfrac{\pi s}{2}\ge
 4s^2\iff \frac{|\sin(\pi s/2)|}{|s|}\ge\sqrt2.
\]
For $s\ne0$ let $u=\pi|s|/2\in(0,\pi/4]$. Then $\frac{|\sin(\pi s/2)|}{|s|}=\fra
c{\sin u}{u}\cdot\frac{\pi}{2}$, and we need $\frac{\sin u}{u}\ge\frac{2\sqrt2}{
\pi}$.

**Lemma.** $\frac{\sin u}{u}$ is decreasing on $(0,\pi)$.

*Proof.* $\frac{d}{du}\frac{\sin u}{u}=\frac{u\cos u-\sin u}{u^2}$. For $u\in(0,
\pi/2)$: $u\cos u<\sin u\iff u<\tan u$, which holds since $\frac{d}{du}(\tan u-u
)=\sec^2u-1>0$ with value $0$ at $u=0$. For $u\in(\pi/2,\pi)$: $\cos u<0$ so $u\
cos u-\sin u<0$. ∎

Since $\sin u/u$ is decreasing and $u\le\pi/4$,
\[
\frac{\sin u}{u}\ge\frac{\sin(\pi/4)}{\pi/4}=\frac{\sqrt2/2}{\pi/4}=\frac{2\sqrt
2}{\pi}.
\]
Equality holds at $u=\pi/4$ (i.e. $t=1/2$, $x=\pi/2$). Thus $\sin x\le\frac{4}{\
pi^2}x(\pi-x)$, so $f(x)\le 4/\pi^2$, with equality at $x=\pi/2$.

---

### Lower bound: $\sin x\ge \dfrac{1}{\pi}x(\pi-x)$

Substitute $x=\pi t$: $\sin(\pi t)\ge\pi t(1-t)$. By symmetry ($t\leftrightarrow
 1-t$) it suffices to prove this for $t\in[0,\tfrac12]$.

**Lemma.** $\sin\theta\ge\theta-\dfrac{\theta^3}{6}$ for all $\theta\ge0$.

*Proof.* Let $g(\theta)=\sin\theta-\theta+\theta^3/6$. Then $g(0)=0$, $g'(\theta
)=\cos\theta-1+\theta^2/2$, $g''(\theta)=-\sin\theta+\theta\ge0$ (since $\theta\
ge\sin\theta$ for $\theta\ge0$). Hence $g'$ is increasing with $g'(0)=0$, so $g'
\ge0$, and $g$ is increasing with $g(0)=0$, giving $g\ge0$. ∎

Apply with $\theta=\pi t\in[0,\pi/2]$:
\[
\sin(\pi t)\ge\pi t-\frac{\pi^3 t^3}{6}.
\]
We want $\pi t-\frac{\pi^3 t^3}{6}\ge\pi t(1-t)=\pi t-\pi t^2$, i.e. $\pi t^2\ge
\frac{\pi^3 t^3}{6}$, i.e. $t\le\frac{6}{\pi^2}$. Since $\pi^2<12$ (as $\pi<2\sq
rt3$), we have $\frac{6}{\pi^2}>\frac12$, so this holds for every $t\in[0,\tfrac
12]$. By symmetry it holds on $[\tfrac12,1]$ as well.

Thus $\sin x\ge\frac{1}{\pi}x(\pi-x)$, so $f(x)\ge 1/\pi$ for $x\in(0,\pi)$.

---

### Sharpness

- **$a=1/\pi$ is largest:** $\lim_{x\to0^+}f(x)=1/\pi$, so any $a>1/\pi$ violate
s $ax(\pi-x)\le\sin x$ for $x$ near $0$.
- **$b=4/\pi^2$ is smallest:** $f(\pi/2)=4/\pi^2$ (equality), so any $b<4/\pi^2$
 violates $\sin x\le bx(\pi-x)$ at $x=\pi/2$.

$$\boxed{\,a=\dfrac{1}{\pi},\qquad b=\dfrac{4}{\pi^2}\,}$$
