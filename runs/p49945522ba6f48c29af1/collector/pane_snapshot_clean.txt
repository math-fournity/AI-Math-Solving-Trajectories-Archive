## Setting Up the Quadratic Form

- $A_{i,i+1} = A_{i+1,i} = -\frac{1}{2}$

This is a positive definite matrix (discrete Laplacian type).

## Minimizing via Lagrange Multipliers

The minimum of $\mathbf{x}^T A \mathbf{x}$ subject to $\mathbf{1}^T \mathbf{x} =

## Solving the Linear System

The system $A\mathbf{y} = \mathbf{1}$ gives:

- **Row $i$** ($2 \leq i \leq n-1$): $-y_{i-1} + 2y_i - y_{i+1} = 2$
- **Row $n$:** $-y_{n-1} + 2y_n = 2$

The homogeneous recurrence $y_{i+1} - 2y_i + y_{i-1} = 0$ has double root $r=1$,
 giving $y_i = C + Di$. A particular solution $y_i = -i^2$ satisfies $-y_{i-1}+2
y_i-y_{i+1} = 2$. So:

$$y_i = C + Di - i^2$$

**From Row 1:** $y_1 - y_2 = (C+D-1)-(C+2D-4) = -D+3 = 2 \Rightarrow D = 1$.

**From Row $n$:** $-y_{n-1}+2y_n = -(C+n-1-(n-1)^2)+2(C+n-n^2) = C - n + 2 - n^2

Therefore: $y_i = n(n+1) + i - i^2 = n(n+1) - i(i-1)$.
