## Proof

**Claim:** Such an analytic function exists.

**Construction.** Define
$$g(z) = \sum_{n=0}^{\infty} \frac{(-1)^n\, z^n}{(2n)!}.$$

**Step 1: $g$ is entire (analytic on all of $\mathbb{C}$).**

Apply the ratio test to the coefficients $a_n = \frac{(-1)^n}{(2n)!}$:
$$\left|\frac{a_{n+1}}{a_n}\right| = \frac{(2n)!}{(2n+2)!} = \frac{1}{(2n+1)(2n+
2)} \xrightarrow{n\to\infty} 0.$$
Hence $\limsup_{n\to\infty} |a_{n+1}/a_n|^{1/n} = 0$, so the radius of convergen
ce is $R = \infty$. The power series therefore defines an entire function $g:\ma
thbb{C}\to\mathbb{C}$.

**Step 2: $g(x) = \cos(\sqrt{x})$ for all $x\in\mathbb{R}^+$.**

For $x > 0$, $\sqrt{x}$ is a well-defined positive real, and the cosine series c
onverges absolutely:
$$\cos(\sqrt{x}) = \sum_{n=0}^{\infty} \frac{(-1)^n (\sqrt{x})^{2n}}{(2n)!} = \s
um_{n=0}^{\infty} \frac{(-1)^n\, x^n}{(2n)!} = g(x).$$

**Step 3: $g'(0)$ exists.**

Since $g$ is entire, it is in particular analytic at $0$, so $g'(0)$ exists. Exp
licitly, differentiating the power series term-by-term at $z=0$:
$$g'(0) = a_1 = \frac{(-1)^1}{2!} = -\frac{1}{2}.$$

**Conclusion.** The function $g(z)=\sum_{n=0}^{\infty}\frac{(-1)^n z^n}{(2n)!}$
is entire, agrees with $\cos(\sqrt{x})$ on $\mathbb{R}^+$, and satisfies $g'(0)=
-\tfrac{1}{2}$. Therefore such an analytic function exists.
