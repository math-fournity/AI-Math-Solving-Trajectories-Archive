## Proof

**Answer: Yes.** The Cantor–Lebesgue (Stieltjes) measure is a nontrivial, atomle
ss measure on ℝ that is mutually singular with the Lebesgue measure.

### Construction

Let $C \subset [0,1]$ be the middle-thirds Cantor set, obtained by repeatedly re
moving the open middle third from each remaining interval. Recall $m(C)=0$ (the
total length removed is $\sum_{n=1}^{\infty} 2^{n-1}\cdot 3^{-n}=1$).

Define a measure $\mu$ on $\mathbb{R}$ as the weak limit of the following sequen
ce of absolutely continuous measures. For each $n\ge 0$, let $C_n$ be the $n$-th
 stage approximation: a union of $2^n$ closed intervals $I_{n,k}$ ($k=1,\dots,2^
n$), each of length $3^{-n}$. Set

$$\mu_n := \sum_{k=1}^{2^n} \frac{1}{2^n}\cdot \frac{1}{|I_{n,k}|}\,\mathbf{1}_{
I_{n,k}}\,dm = 2^n\sum_{k=1}^{2^n}\frac{1}{2^n}\cdot 3^{n}\,\mathbf{1}_{I_{n,k}}
\,dm.$$

Equivalently, $\mu_n$ is the probability measure with density $3^n/2^n$ on $C_n$
 and $0$ off $C_n$. Each $\mu_n$ has total mass $1$.

The sequence $\{\mu_n\}$ is consistent in the sense that for every continuous $f
$,
$$\int f\,d\mu_n \to \int f\,d\mu$$
for a Borel probability measure $\mu$. Indeed, the distribution functions $F_n(x
)=\mu_n((-\infty,x])$ converge uniformly to the **Cantor function** (devil's sta
ircase) $F$, which is continuous, non-decreasing, with $F(0)=0$, $F(1)=1$, and c
onstant on each removed middle-third interval. The measure $\mu$ is the Lebesgue
–Stieltjes measure associated to $F$.

### Three required properties

**(1) Nontrivial.** $\mu(\mathbb{R})=F(\infty)-F(-\infty)=1-0=1\neq 0$, so $\mu$
 is nontrivial.

**(2) Mutually singular with $m$.** The Cantor function $F$ is constant on every
 connected component of $[0,1]\setminus C$ (each removed middle-third open inter
val), so $\mu$ assigns zero mass to $[0,1]\setminus C$; and $\mu$ is supported i
n $[0,1]$, so $\mu(\mathbb{R}\setminus C)=0$. Since $m(C)=0$, we have

$$\mu(\mathbb{R}\setminus C)=0 \quad\text{and}\quad m(C)=0,$$

which is exactly $\mu\perp m$.

**(3) Atomless: $\mu(\{x\})=0$ for every $x\in\mathbb{R}$.** The Cantor function
 $F$ is **continuous** on all of $\mathbb{R}$ (it is uniformly continuous, being
 continuous on the compact set $[0,1]$ and constant outside). For any point $x$,

$$\mu(\{x\}) = F(x)-F(x^-) = F(x)-F(x) = 0,$$

since continuity gives $F(x^-)=F(x)$. Hence $\mu$ has no atoms.

### Conclusion

The Cantor–Lebesgue measure $\mu$ is a nonzero Borel measure on $\mathbb{R}$, su
pported on the Lebesgue-null Cantor set (hence $\mu\perp m$), and atomless (sinc
e its distribution function is continuous, $\mu(\{x\})=0$ for all $x$). Therefor
e such a nontrivial measure exists.
