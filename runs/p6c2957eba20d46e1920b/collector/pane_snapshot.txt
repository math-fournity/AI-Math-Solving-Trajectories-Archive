**Setup (Ravi substitution).** Since $a, b, c$ are the side lengths of a triangl
e, there exist $x, y, z > 0$ such that
$$a = y+z,\quad b = z+x,\quad c = x+y.$$
Then
$$b+c-a = 2x,\quad c+a-b = 2y,\quad a+b-c = 2z.$$

**Reformulation.** The desired inequality becomes
$$2x(y+z)^2 + 2y(z+x)^2 + 2z(x+y)^2 \le 3(y+z)(z+x)(x+y).$$

**Expand both sides.**

*Left-hand side:*
$$\text{LHS} = 2x(y^2+2yz+z^2) + 2y(z^2+2zx+x^2) + 2z(x^2+2xy+y^2)$$
$$= 2(x^2y + xy^2 + x^2z + xz^2 + y^2z + yz^2) + 12xyz.$$

*Right-hand side:* First,
$$(y+z)(z+x)(x+y) = x^2y + xy^2 + x^2z + xz^2 + y^2z + yz^2 + 2xyz,$$
so
$$\text{RHS} = 3(x^2y + xy^2 + x^2z + xz^2 + y^2z + yz^2) + 6xyz.$$

**Reduce.** It suffices to show
$$\text{RHS} - \text{LHS} = (x^2y + xy^2 + x^2z + xz^2 + y^2z + yz^2) - 6xyz \ge
 0,$$
i.e.
$$x^2y + xy^2 + x^2z + xz^2 + y^2z + yz^2 \ge 6xyz.$$

**Apply AM–GM.** The six positive terms $x^2y,\, xy^2,\, x^2z,\, xz^2,\, y^2z,\,
 yz^2$ have product
$$(x^2y)(xy^2)(x^2z)(xz^2)(y^2z)(yz^2) = x^6 y^6 z^6 = (xyz)^6.$$
By the AM–GM inequality,
$$\frac{x^2y + xy^2 + x^2z + xz^2 + y^2z + yz^2}{6} \ge \big((xyz)^6\big)^{1/6}
= xyz,$$
hence
$$x^2y + xy^2 + x^2z + xz^2 + y^2z + yz^2 \ge 6xyz.$$

**Conclusion.** Therefore $\text{RHS} - \text{LHS} \ge 0$, which gives
$$a^2(b+c-a) + b^2(c+a-b) + c^2(a+b-c) \le 3abc.$$

**Equality case.** Equality in AM–GM holds iff all six terms are equal, i.e. $x
= y = z$, corresponding to $a = b = c$ (the equilateral triangle). One readily v
erifies that for $a = b = c$ both sides equal $3a^3$. $\blacksquare$
