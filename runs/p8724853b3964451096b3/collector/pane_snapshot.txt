## Proof

Let $M_t = W_t^2 - t$. We compute $E[M_t M_s]$ for $0 < s < t$.

**Method (martingale / independent increments).** Since $(W_t)$ is a Brownian mo
tion, $M_t = W_t^2 - t$ is a martingale with respect to $(\mathcal{F}_t)$. Indee
d, for $u < v$,
$$E[W_v^2 - v \mid \mathcal{F}_u] = E[(W_v - W_u + W_u)^2 \mid \mathcal{F}_u] -
v = (v - u) + W_u^2 - v = W_u^2 - u = M_u.$$

Using the tower property with $\mathcal{F}_s \subseteq \mathcal{F}_t$:
$$E[M_t M_s] = E\big[M_s \, E[M_t \mid \mathcal{F}_s]\big] = E[M_s \cdot M_s] =
E[M_s^2].$$

Now $M_s = W_s^2 - s$ with $W_s \sim \mathcal{N}(0, s)$. Hence
$$E[M_s^2] = E[W_s^4] - 2s\,E[W_s^2] + s^2 = 3s^2 - 2s\cdot s + s^2 = 2s^2,$$
using the Gaussian fourth moment $E[W_s^4] = 3s^2$ and $E[W_s^2] = s$.

**Direct verification.** Write $W_t = W_s + X$ with $X = W_t - W_s \sim \mathcal
{N}(0, t-s)$ independent of $W_s$. Then
$$W_t^2 W_s^2 = (W_s^2 + 2W_s X + X^2)W_s^2 = W_s^4 + 2W_s^3 X + W_s^2 X^2.$$
Taking expectations:
$$E[W_t^2 W_s^2] = 3s^2 + 0 + s(t-s) = 2s^2 + st.$$
Therefore
$$E[(W_t^2 - t)(W_s^2 - s)] = E[W_t^2 W_s^2] - s\,E[W_t^2] - t\,E[W_s^2] + ts =
(2s^2 + st) - st - st + st = 2s^2.$$

Both methods agree.

$$\boxed{E[(W_t^2 - t)(W_s^2 - s)] = 2s^2}$$
