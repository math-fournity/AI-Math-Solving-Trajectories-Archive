**Answer: Yes, $\prod_{j=1}^n (z - z_j^k)$ has integer coefficients for every $k
 = 1, 2, 3, \ldots$.**

---

**Proof.**

Let $P(z) = \prod_{j=1}^n (z - z_j) = z^n - e_1 z^{n-1} + e_2 z^{n-2} - \cdots +
 (-1)^n e_n$, where $e_m = e_m(z_1, \ldots, z_n)$ is the $m$-th elementary symme
tric polynomial in $z_1, \ldots, z_n$. By hypothesis, $e_1, \ldots, e_n \in \mat
hbb{Z}$.

For a fixed positive integer $k$, define
$$P_k(z) = \prod_{j=1}^n (z - z_j^k) = z^n - E_1^{(k)} z^{n-1} + E_2^{(k)} z^{n-
2} - \cdots + (-1)^n E_n^{(k)},$$
where $E_m^{(k)} = e_m(z_1^k, \ldots, z_n^k)$.

**Key observation.** For each $m$ and $k$, the expression
$$E_m^{(k)} = \sum_{1 \le i_1 < \cdots < i_m \le n} z_{i_1}^k \cdots z_{i_m}^k$$
is a **symmetric polynomial in $z_1, \ldots, z_n$ with integer coefficients**. (
Permuting the $z_j$ merely permutes the summands.)

By the **Fundamental Theorem of Symmetric Polynomials**, every symmetric polynom
ial in $z_1, \ldots, z_n$ with coefficients in a ring $R$ can be written uniquel
y as a polynomial in the elementary symmetric polynomials $e_1, \ldots, e_n$ wit
h coefficients in $R$. Taking $R = \mathbb{Z}$, there exists a polynomial $F_{m,
k} \in \mathbb{Z}[x_1, \ldots, x_n]$ such that
$$E_m^{(k)} = F_{m,k}(e_1, \ldots, e_n).$$

Since $e_1, \ldots, e_n \in \mathbb{Z}$ and $F_{m,k}$ has integer coefficients,
we conclude
$$E_m^{(k)} \in \mathbb{Z} \quad \text{for all } m = 1, \ldots, n \text{ and all
 } k \ge 1.$$

Therefore every coefficient of $P_k(z) = \prod_{j=1}^n (z - z_j^k)$ is an intege
r, for every $k = 1, 2, 3, \ldots$. $\blacksquare$

---

**Remark (alternative viewpoint via power sums).** One can also argue through Ne
wton's identities: the power sums $p_r = z_1^r + \cdots + z_n^r$ satisfy the rec
urrence $p_r = e_1 p_{r-1} - e_2 p_{r-2} + \cdots$ with integer coefficients $e_
i$ and integer initial values, so $p_r \in \mathbb{Z}$ for all $r \ge 1$. Then $
E_m^{(k)}$, being expressible via Newton's identities in terms of $p_k, p_{2k},
\ldots, p_{mk}$ (all integers), is itself an integer. This is equivalent to the
symmetric-polynomial argument above.
