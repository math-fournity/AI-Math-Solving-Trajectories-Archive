# BMO 1997 Problem 3

**Problem:** Find the number of polynomials of degree 5 with distinct coefficien
ts from {1, 2, ..., 9} divisible by x² − x + 1.

## Solution

**Root condition.** The roots of x² − x + 1 are ω = e^{iπ/3} and ω̄, where ω is a
 primitive 6th root of unity (ω³ = −1, ω² = ω − 1). Divisibility requires P(ω) =
 0. Computing powers:

| k | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| ωᵏ | 1 | ω | ω−1 | −1 | −ω | 1−ω |

Substituting into P(ω) = a₅ω⁵ + a₄ω⁴ + a₃ω³ + a₂ω² + a₁ω + a₀ and collecting coe
fficients of 1 and ω:

$$P(\omega) = \underbrace{(a_5 - a_3 - a_2 + a_0)}_{\text{real}} + \omega\underb
race{(-a_5 - a_4 + a_2 + a_1)}_{\text{imag}}$$

Both parts must vanish, giving **two equations**:

$$\textbf{(I):}\ a_5 + a_0 = a_3 + a_2 \qquad \textbf{(II):}\ a_2 + a_1 = a_5 +
a_4$$

**Parameterization.** Set u = a₂, v = a₅, d = v − u. Define p = (a₅+a₀) − u − v
and q = (a₂+a₁) − u − v. Then:

| coeff | a₂ | a₅ | a₀ | a₃ | a₄ | a₁ |
|-------|-----|-----|------|------|------|------|
| value | u | v | u+p | v+p | u+q | v+q |

The six values form a **2×3 grid**: {u, v} + {0, p, q}. Shifting by u, define R
= {0, d, p, d+p, q, d+q}. All six values u+R must be distinct elements of {1,...
,9}.

**Distinctness conditions.** The grid {0, d} + {0, p, q} has 6 distinct elements
 iff:
- d ≠ 0, p ≠ 0, q ≠ 0, p ≠ q
- p ∉ {d, −d}, q ∉ {d, −d} (no row–column collisions)
- p − q ∉ {d, −d} (no diagonal collisions)

For a set S = {0, x, y} (the two nonzero elements x, y with two orderings (x,y)
and (y,x)), one checks that **both orderings are valid iff**: d ∉ {|x|, |y|} and
 |x − y| ≠ d. Each valid set contributes 2 ordered pairs.

**Range and counting.** By the sumset property, range(R) = |d| + range({0, p, q}
). If r = range({0, p, q}), the number of valid shifts u is **9 − |d| − r** (req
uiring |d| + r ≤ 8).

By symmetry d ↔ −d, the total count is:

$$\text{Total} = 4\sum_{d=1}^{6}\sum_{r=2}^{8-d}(9 - d - r)\cdot N(d,r)$$

where N(d, r) = number of sets {0, x, y} with range r satisfying d ∉ {|x|,|y|} a
nd |x−y| ≠ d.

**Computing N(d, r).** The total sets with range r is 3(r−1). By inclusion–exclu
sion over "some element is ±d" (set A) and "|x−y| = d" (set B):

| Region | \|A\| | \|B\| | \|A∩B\| | N(d, r) |
|--------|-------|-------|---------|----------|
| r < d | 0 | 0 | 0 | 3(r−1) |
| r = d | 2(d−1) | d−1 | 0 | 0 |
| d < r < 2d | 4 | 2 | 0 | 3(r−3) |
| r = 2d | 3 | 2 | 2 | 6(d−1) |
| r > 2d | 4 | 2 | 0 | 3(r−3) |

**Tabulating the sum:**

| d | Valid r values | (9−d−r)·N(d,r) for each r | Subtotal |
|---|---------------|---------------------------|----------|
| 1 | r=4,5,6,7 | 4·3, 3·6, 2·9, 1·12 | 12+18+18+12 = **60** |
| 2 | r=4,5,6 | 3·6, 2·6, 1·9 | 18+12+9 = **39** |
| 3 | r=2,4,5 | 4·3, 2·3, 1·6 | 12+6+6 = **24** |
| 4 | r=2,3 | 3·3, 2·6 | 9+12 = **21** |
| 5 | r=2,3 | 2·3, 1·6 | 6+6 = **12** |
| 6 | r=2 | 1·3 | **3** |

(Entries with N = 0 are omitted.)

**Grand total:**

$$\text{Sum} = 60 + 39 + 24 + 21 + 12 + 3 = 159$$
$$\text{Total} = 4 \times 159 = \boxed{636}$$
