## Proof

We evaluate
$$I = \int_{-\infty}^{\infty} \frac{x^2}{x^6+1}\,dx$$
by contour integration over the closed contour $C_R$ consisting of the real segm
ent $[-R, R]$ together with the upper semicircle $\Gamma_R = \{Re^{i\theta} : 0
\le \theta \le \pi\}$, traversed counterclockwise.

**The integrand.** Let
$$f(z) = \frac{z^2}{z^6+1}.$$
The poles of $f$ are the solutions of $z^6 = -1 = e^{i\pi}$, namely
$$z_k = e^{i(2k+1)\pi/6}, \qquad k = 0,1,2,3,4,5.$$
These six roots are distinct, so every pole is simple.

**Poles in the upper half-plane.** A pole $z_k$ lies in the upper half-plane whe
n $0 < (2k+1)\pi/6 < \pi$, i.e. $0 < 2k+1 < 6$, giving $k = 0, 1, 2$:
$$z_0 = e^{i\pi/6}, \quad z_1 = e^{i\pi/2} = i, \quad z_2 = e^{i5\pi/6}.$$

**Residues.** Since each pole is simple,
$$\operatorname{Res}(f, z_k) = \frac{z_k^2}{(z^6+1)'\big|_{z=z_k}} = \frac{z_k^2
}{6z_k^5} = \frac{1}{6z_k^3}.$$
Using $z_k^6 = -1$, we compute $z_k^3$:
- $z_0^3 = e^{i\pi/2} = i$,
- $z_1^3 = e^{i3\pi/2} = -i$,
- $z_2^3 = e^{i5\pi/2} = e^{i\pi/2} = i$.

Hence
$$\operatorname{Res}(f, z_0) = \frac{1}{6i} = -\frac{i}{6}, \quad \operatorname{
Res}(f, z_1) = \frac{1}{-6i} = \frac{i}{6}, \quad \operatorname{Res}(f, z_2) = \
frac{1}{6i} = -\frac{i}{6}.$$

The sum of the residues in the upper half-plane is
$$-\frac{i}{6} + \frac{i}{6} - \frac{i}{6} = -\frac{i}{6}.$$

**Vanishing of the arc.** On $\Gamma_R$, for large $R$,
$$|f(z)| = \frac{|z|^2}{|z^6+1|} \le \frac{R^2}{R^6 - 1} \sim \frac{1}{R^4}.$$
Therefore
$$\left|\int_{\Gamma_R} f(z)\,dz\right| \le \pi R \cdot \frac{R^2}{R^6-1} = O(R^
{-3}) \to 0 \quad \text{as } R \to \infty.$$

**Applying the residue theorem.** For $R$ large enough to enclose all three uppe
r-half-plane poles,
$$\oint_{C_R} f(z)\,dz = 2\pi i \left(-\frac{i}{6}\right) = \frac{2\pi}{6} = \fr
ac{\pi}{3}.$$
Splitting the contour into the real segment and the arc,
$$\int_{-R}^{R} \frac{x^2}{x^6+1}\,dx + \int_{\Gamma_R} f(z)\,dz = \frac{\pi}{3}
.$$
Letting $R \to \infty$, the arc integral vanishes and we obtain
$$\int_{-\infty}^{\infty} \frac{x^2}{x^6+1}\,dx = \frac{\pi}{3}.$$
