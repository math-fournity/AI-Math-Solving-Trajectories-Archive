## Solution of the Infinite Euler–Bernoulli Beam Equation

**Problem.** Solve
$$u_{tt} = u_{xxxx}, \quad -\infty < x < \infty,\; t > 0,$$
with initial data $u(x,0) = f(x)$, $u_t(x,0) = g(x)$.

---

### Step 1. Fourier Transform in $x$

Define the Fourier transform and its inverse:
$$\hat{u}(k,t) = \int_{-\infty}^{\infty} u(x,t)\,e^{-ikx}\,dx, \qquad u(x,t) = \
frac{1}{2\pi}\int_{-\infty}^{\infty} \hat{u}(k,t)\,e^{ikx}\,dk,$$
and similarly $\hat{f}(k)$, $\hat{g}(k)$ for the initial data. Under the transfo
rm, $u_{xxxx} \mapsto (ik)^4 \hat{u} = k^4 \hat{u}$, so the PDE becomes an ODE i
n $t$ for each fixed $k$:

$$\hat{u}_{tt}(k,t) = k^4\,\hat{u}(k,t), \qquad \hat{u}(k,0) = \hat{f}(k),\quad
\hat{u}_t(k,0) = \hat{g}(k).$$

---

### Step 2. Solve the Transformed ODE

The characteristic equation is $r^2 = k^4$, i.e. $r = \pm k^2$.

**For $k \neq 0$:** The general solution is
$$\hat{u}(k,t) = C_1(k)\,e^{k^2 t} + C_2(k)\,e^{-k^2 t} = A(k)\cosh(k^2 t) + \fr
ac{B(k)}{k^2}\sinh(k^2 t),$$
where we switch to the $\cosh/\sinh$ basis for convenience. Applying the initial
 conditions:
$$\hat{u}(k,0) = A(k) = \hat{f}(k),$$
$$\hat{u}_t(k,0) = B(k) = \hat{g}(k).$$

Therefore:
$$\boxed{\hat{u}(k,t) = \hat{f}(k)\cosh(k^2 t) + \frac{\hat{g}(k)}{k^2}\sinh(k^2
 t), \qquad k \neq 0.}$$

**For $k = 0$:** The ODE reduces to $\hat{u}_{tt}(0,t) = 0$, giving $\hat{u}(0,t
) = \hat{f}(0) + \hat{g}(0)\,t$. This is consistent with the limit $k \to 0$ sin
ce $\cosh(k^2 t) \to 1$ and $\sinh(k^2 t)/k^2 \to t$.

---

### Step 3. Inverse Transform — The Solution

Applying the inverse Fourier transform:

$$\boxed{u(x,t) = \frac{1}{2\pi}\int_{-\infty}^{\infty}\left[\hat{f}(k)\cosh(k^2
 t) + \frac{\hat{g}(k)}{k^2}\sinh(k^2 t)\right]e^{ikx}\,dk.}$$

---

### Step 4. Verification

**Initial displacement.** At $t = 0$: $\cosh(0) = 1$, $\sinh(0) = 0$, so
$$u(x,0) = \frac{1}{2\pi}\int_{-\infty}^{\infty} \hat{f}(k)\,e^{ikx}\,dk = f(x).
 \quad\checkmark$$

**Initial velocity.** Differentiating under the integral:
$$u_t(x,t) = \frac{1}{2\pi}\int_{-\infty}^{\infty}\left[\hat{f}(k)\,k^2\sinh(k^2
 t) + \hat{g}(k)\cosh(k^2 t)\right]e^{ikx}\,dk.$$
At $t = 0$: $\sinh(0) = 0$, $\cosh(0) = 1$, so
$$u_t(x,0) = \frac{1}{2\pi}\int_{-\infty}^{\infty} \hat{g}(k)\,e^{ikx}\,dk = g(x
). \quad\checkmark$$

**PDE.** From the transformed ODE $\hat{u}_{tt} = k^4 \hat{u} = (ik)^4 \hat{u}$,
 inverting gives $u_{tt} = u_{xxxx}$. $\checkmark$

---

### Step 5. Equivalent Representation via Kernels

Using $\cosh(k^2 t) = \tfrac{1}{2}(e^{k^2 t} + e^{-k^2 t})$ and $\sinh(k^2 t)/k^
2 = \tfrac{1}{2k^2}(e^{k^2 t} - e^{-k^2 t})$, the solution splits into two parts
. The $e^{-k^2 t}$ component corresponds to convolution with the **heat kernel**
$$G(x,t) = \frac{1}{\sqrt{4\pi t}}\,e^{-x^2/(4t)}, \qquad t > 0,$$
since $\mathcal{F}^{-1}[e^{-k^2 t}] = G(x,t)$. Thus the well-defined (forward) p
art is:
$$u(x,t) \supset \frac{1}{2}(G(\cdot,t)*f)(x) + \frac{1}{2}\int_0^t (G(\cdot,s)*
g)(x)\,ds,$$
where we used $\frac{e^{-k^2 t}}{k^2} = \int_0^t e^{-k^2 s}\,ds$ (for the $g$-te
rm). The $e^{+k^2 t}$ component corresponds to the **backward heat kernel**, whi
ch is not a tempered distribution; it is well-defined only for initial data $\ha
t{f}, \hat{g}$ that decay faster than $e^{-k^2 t}$ (e.g., data in a Gevrey class
 or analytic data).

---

### Step 6. Remark on Well-Posedness

The equation $u_{tt} = u_{xxxx}$ as written is **ill-posed** (in the sense of Ha
damard) for $t > 0$: the multiplier $e^{k^2 t}$ grows super-exponentially in $k$
, so arbitrarily small high-frequency perturbations of the initial data are ampl
ified without bound. The formal solution above is valid for sufficiently regular
 (e.g., analytic) initial data.

The **standard Euler–Bernoulli beam equation** is $u_{tt} = -u_{xxxx}$ (i.e., $u
_{tt} + u_{xxxx} = 0$), which is well-posed. Its solution is obtained by replaci
ng $\cosh \to \cos$ and $\sinh \to \sin$ throughout:
$$u(x,t) = \frac{1}{2\pi}\int_{-\infty}^{\infty}\left[\hat{f}(k)\cos(k^2 t) + \f
rac{\hat{g}(k)}{k^2}\sin(k^2 t)\right]e^{ikx}\,dk,$$
which is well-defined for $f, g \in L^2(\mathbb{R})$ and involves convolution wi
th the Schrödinger (Fresnel) kernel $\mathcal{F}^{-1}[e^{ik^2 t}] = (4\pi i t)^{
-1/2} e^{ix^2/(4t)}$.

---

### Summary

The solution of $u_{tt} = u_{xxxx}$ with $u(x,0)=f(x)$, $u_t(x,0)=g(x)$ on $-\in
fty < x < \infty$ is:

$$u(x,t) = \frac{1}{2\pi}\int_{-\infty}^{\infty}\left[\hat{f}(k)\cosh(k^2 t) + \
frac{\hat{g}(k)}{k^2}\sinh(k^2 t)\right]e^{ikx}\,dk,$$

with the $k=0$ mode contributing $\hat{f}(0) + \hat{g}(0)\,t$. This is verified
to satisfy the PDE and both initial conditions. The equation is ill-posed for ge
neral data; the solution is classical for analytic initial data.
