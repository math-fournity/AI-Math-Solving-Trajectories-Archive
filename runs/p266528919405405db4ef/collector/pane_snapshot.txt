Let $a = f(0)$. We derive key constraints by substituting special values.

**Step 1: $x = y = 0$.**
$$f(f(0)) = f(0)^2 - f(0) + f(0) = a^2 \implies f(a) = a^2.$$

**Step 2: $y = 0$.**
$$f(f(x)) = f(x)\,a - f(x) + a = (a-1)f(x) + a. \tag{1}$$

**Step 3: $x = 0$.**
$$f(f(-y)) = a\,f(y) - a + f(y) = (a+1)f(y) - a.$$
Replacing $y$ by $-y$: $f(f(y)) = (a+1)f(-y) - a$. Combining with (1):
$$(a-1)f(y) + a = (a+1)f(-y) - a. \tag{2}$$

**Step 4: $y = x$ (the decisive substitution).**
$$f(f(0)) = f(x)^2 - f(x) + f(x) - x^2 = f(x)^2 - x^2.$$
Since $f(f(0)) = a^2$:
$$\boxed{f(x)^2 = x^2 + a^2 \quad \text{for all } x.} \tag{3}$$

In particular $f(1)^2 = 1 + a^2$, and the range of $f$ satisfies $|f(x)| \geq |a
|$.

**Step 5: Combine (1) and (3).** From (3) applied to $f(x)$: $f(f(x))^2 = f(x)^2
 + a^2 = x^2 + 2a^2$. Squaring (1):
$$\big((a-1)f(x)+a\big)^2 = x^2 + 2a^2.$$
Expanding and using $f(x)^2 = x^2 + a^2$:
$$(a-1)^2(x^2+a^2) + 2a(a-1)f(x) + a^2 = x^2 + 2a^2.$$
Simplifying:
$$2a(a-1)\,f(x) = a(2-a)(x^2 + a^2). \tag{4}$$

**Case $a \neq 0$:** Divide by $a$:
$$2(a-1)f(x) = (2-a)(x^2+a^2).$$

- If $a = 1$: LHS $= 0$, RHS $= x^2+1 \neq 0$. **Contradiction.**
- If $a = 2$: LHS $= 2f(x)$, RHS $= 0$, so $f \equiv 0$, but $f(0)=2$. **Contrad
iction.**
- If $a \notin\{0,1,2\}$: $f(x) = \frac{(2-a)(x^2+a^2)}{2(a-1)}$, a non-constant
 quadratic in $x^2$. Then $f(x)^2$ is degree $4$ in $x$, but (3) requires $f(x)^
2 = x^2+a^2$ (degree $2$). **Contradiction.**

**Case $a = 0$:** Then $f(0)=0$ and (3) gives $f(x)^2 = x^2$, so $f(x) \in \{x,\
,-x\}$ for each $x$. Equation (1) becomes $f(f(x)) = -f(x)$.

If $f(x_0) = x_0$ for some $x_0 \neq 0$, then $u = x_0$ is in the range of $f$,
so $f(u) = -u$, i.e., $f(x_0) = -x_0$, contradicting $f(x_0)=x_0$ unless $x_0=0$
. Hence $f(x) = -x$ for all $x \neq 0$, and $f(0)=0$.

**Verification of $f(x) = -x$:**
- LHS: $f(f(x-y)) = f(-(x-y)) = f(y-x) = -(y-x) = x-y$.
- RHS: $f(x)f(y)-f(x)+f(y)-xy = (-x)(-y)-(-x)+(-y)-xy = xy+x-y-xy = x-y$.

LHS $=$ RHS. ✓

**Conclusion:** The unique solution is $f(x) = -x$, giving $f(1) = -1$. The sum
of all possible values of $f(1)$ is $\boxed{-1}$.
