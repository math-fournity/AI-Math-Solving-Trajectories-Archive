## Key Observations

**Query structure:** A line not through any vertex of a regular $n$-gon, plus a
half-plane choice, selects a **contiguous arc** of vertices (in cyclic order). S
o each query reveals the sum of numbers on some contiguous arc of size $1$ to $n
-1$.

**Yugi's number choice:** Yugi picks the numbers. Using **super-increasing numbe
rs** (e.g., powers of 2), any subset sum uniquely identifies the subset. So each
 query reveals exactly *which* numbers lie in the queried arc — maximum possible

## Reduction to a Combinatorial Problem

With super-increasing numbers, the problem becomes: determine a permutation of $
n$ labels on a cycle using contiguous-arc-subset queries. Each query partitions
the $n$ vertices into "in arc" / "not in arc." After $q$ queries, each vertex ha
s a **binary signature** (length-$q$ vector indicating membership in each querie
d arc). Yugi can determine the placement **iff all $n$ vertices have distinct si
gnatures** (then match each number's observed signature to the unique vertex wit
h that signature).

## Lower Bound: $m(n) \ge \lceil n/2 \rceil$

Each contiguous arc has exactly **2 endpoints**, creating 2 cut points on the cy
cle. With $q$ queries, at most $2q$ cut points divide the cycle into at most $2q
$ **segments**. Vertices in the same segment share the same signature. If two ve
rtices share a signature, swapping their numbers changes no answer — Yugi cannot
 distinguish the two placements. This holds **regardless of number choice** (it'
s structural). Therefore we need $2q \ge n$, i.e., $q \ge \lceil n/2 \rceil$.

## Upper Bound: $m(n) \le \lceil n/2 \rceil$ via Construction

Set $q = \lceil n/2 \rceil$. I construct $q$ contiguous arcs giving all $n$ vert
ices distinct signatures.

**Walk construction:** Define a closed walk on the $q$-dimensional hypercube $\{
0,1\}^q$, starting at $0^q$, with flip sequence:
$$1, 2, 1, 3, 2, 4, 3, 5, 4, \ldots, (q-1), q, (q-1), q$$
This has $2q$ steps; each bit is flipped exactly twice (once $0\to1$, once $1\to
0$), so the walk closes. The "on-set" (bits currently 1) at each step traces:
$$\emptyset,\ \{1\},\ \{1,2\},\ \{2\},\ \{2,3\},\ \{3\},\ \{3,4\},\ \{4\},\ \ldo
ts,\ \{q{-}1,q\},\ \{q\}$$
These are $2q$ **distinct** sets: $\emptyset$; singletons $\{1\},\ldots,\{q\}$;
and adjacent pairs $\{1,2\},\{2,3\},\ldots,\{q{-}1,q\}$ — all distinct by size a
nd content.

**Realization as arcs:** Place the $2q$ cut points on the $n$ gaps of the cycle
in walk order. For $n$ even ($2q = n$): one cut point per gap. For $n$ odd ($2q
= n+1$): one gap receives 2 cut points (creating one empty segment). Each bit's
$0\to1$ flip marks an arc's start; its $1\to0$ flip marks its end. Since each bi
t is "on" for a contiguous range of segments, each arc is a **valid contiguous a
rc**. Consecutive flips are always different bits, so the two cut points sharing
 a gap belong to different arcs — no arc is degenerate.

The $2q$ segments have the $2q$ distinct signatures above. For $n$ even, all $n
= 2q$ segments are non-empty with distinct signatures. For $n$ odd, $n = 2q-1$ n
on-empty segments have distinct signatures (one empty segment is harmless). Sinc
e $2q \ge n$, all $n$ vertices get distinct signatures. $\checkmark$
