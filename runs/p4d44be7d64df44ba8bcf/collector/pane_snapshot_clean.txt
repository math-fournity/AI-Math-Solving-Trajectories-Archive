## Proof

We evaluate $L(x) = \lim_{m\to\infty}\lim_{n\to\infty}\sin^n(m!\,2\pi x)$.

### Step 1: The inner limit

Fix $m$ and set $\theta = m!\,2\pi x$. Since $|\sin\theta|\le 1$:

- If $|\sin\theta|<1$: $|\sin^n\theta|=|\sin\theta|^n\to 0$, so $\sin^n\theta\to
 0$.
- If $\sin\theta=1$ ($\theta\equiv\pi/2\pmod{2\pi}$): $\sin^n\theta=1$ for all $
n$, limit $=1$.
- If $\sin\theta=-1$ ($\theta\equiv 3\pi/2\pmod{2\pi}$): $\sin^n\theta=(-1)^n$ o
scillates, limit does not exist.

Translating via $\theta=2\pi\cdot m!\,x$: $\sin\theta=1\iff\{m!\,x\}=1/4$ and $\
sin\theta=-1\iff\{m!\,x\}=3/4$, where $\{\cdot\}$ denotes fractional part.

### Step 2: Rational $x$

Let $x=p/q$ in lowest terms. For every $m\ge q$, $q\mid m!$, so $m!\,x=m!\,p/q\i
n\mathbb{Z}$, giving $\{m!\,x\}=0$ and $\sin(m!\,2\pi x)=0$. Hence the inner lim
it $a_m=0$ for all $m\ge q$, and
$$\lim_{m\to\infty}a_m = 0.$$

### Step 3: Irrational $x$

Suppose $\{m!\,x\}=1/4$ for some $m$. Then $m!\,x = k+1/4$ for some $k\in\mathbb
{Z}$, so $x=(4k+1)/(4\,m!)$, which is rational — contradiction. Likewise $\{m!\,
x\}=3/4$ would force $x=(4k+3)/(4\,m!)$, also rational — contradiction.

Therefore for irrational $x$, $\{m!\,x\}\notin\{1/4,\,3/4\}$ for every $m$, so $
|\sin(m!\,2\pi x)|<1$ for every $m$, and the inner limit $a_m=0$ for every $m$.
Thus
$$\lim_{m\to\infty}a_m = 0.$$

### Conclusion

For every real $x$ — rational or irrational — the inner limit is $0$ for all suf
ficiently large $m$ (indeed for all $m$ when $x$ is irrational, and for all $m\g
e q$ when $x=p/q$). Hence

$$\boxed{\lim_{m\to\infty}\lim_{n\to\infty}\sin^n(m!\,2\pi x)=0 \quad\text{for a
ll }x\in\mathbb{R}.}$$
