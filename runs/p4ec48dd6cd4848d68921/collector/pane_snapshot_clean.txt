## Proof

We want to compute $\mathbb{E}[\sin(B_t)]$ where $B_t$ is a standard Brownian mo
tion, so $B_t \sim \mathcal{N}(0, t)$.

**Key identity.** For any real $x$, $\sin(x) = \operatorname{Im}(e^{ix})$. Hence
$$\mathbb{E}[\sin(B_t)] = \operatorname{Im}\!\left(\mathbb{E}[e^{iB_t}]\right).$
$

**Characteristic function of a Gaussian.** The characteristic function of $X \si
m \mathcal{N}(0, \sigma^2)$ is
$$\mathbb{E}[e^{iuX}] = e^{-\sigma^2 u^2 / 2}.$$
Applying this with $X = B_t$, $\sigma^2 = t$, and $u = 1$:
$$\mathbb{E}[e^{iB_t}] = e^{-t/2}.$$

**Extract the imaginary part.** Since $e^{-t/2}$ is a **real** number for every
$t \geq 0$,
$$\mathbb{E}[\sin(B_t)] = \operatorname{Im}\!\left(e^{-t/2}\right) = 0.$$

**Sanity check via symmetry.** $B_t \sim \mathcal{N}(0,t)$ is a symmetric distri
bution (its density $\frac{1}{\sqrt{2\pi t}}e^{-x^2/(2t)}$ is even in $x$). The
function $\sin$ is odd. The expectation of an odd function under a symmetric dis
tribution is zero:
$$\mathbb{E}[\sin(B_t)] = \int_{-\infty}^{\infty} \sin(x)\,\frac{1}{\sqrt{2\pi t
}}e^{-x^2/(2t)}\,dx = 0,$$
since the integrand $\sin(x)\,e^{-x^2/(2t)}$ is odd and integrable, so the integ
ral over $\mathbb{R}$ vanishes.

Both methods agree.

$$\boxed{\mathbb{E}[\sin(B_t)] = 0 \quad \text{for all } t \geq 0.}$$

### PROOF COMPLETE
