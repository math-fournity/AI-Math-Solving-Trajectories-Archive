**问题。** 确定 $F_q(t)$ 关于度赋值 $v(f/g) = \deg(f) - \deg(g)$ 的完备化。

**解答。**

**步骤 1. 相关的绝对值。**

根据 $v$，定义 $|x| = q^{\,v(x)}$，即 $|f/g| = q^{\deg f - \deg g}$（且 $|0|=0$
）。我们验证这是一个非阿基米德绝对值：

- *正定性：* 对于 $x \neq 0$，$|x| = q^{v(x)} > 0$。✓
- *乘性：* $|xy| = q^{v(xy)} = q^{v(x)+v(y)} = |x|\,|y|$，因为 $v$ 在乘法下是加
性的（度在乘法下是加性的）。✓
- *超度量不等式：* 给定 $x = f_1/g$ 和 $y = f_2/g$（通分母后），有 $x+y = (f_1+f
_2)/g$，因此
$$|x+y| = q^{\deg(f_1+f_2)-\deg g} \le q^{\max(\deg f_1,\,\deg f_2)-\deg g} = \m
ax(|x|,|y|),$$
因为 $\deg(f_1+f_2) \le \max(\deg f_1, \deg f_2)$ 且 $q>1$。✓

因此 $|\cdot|$ 是 $F_q(t)$ 上的一个非阿基米德绝对值，而完备化是关于由此产生的度
量 $d(x,y)=|x-y|$ 的拓扑完备化。

**步骤 2. 确认对应的位置。**

标准的无穷远点赋值 $v_\infty$ 定义为 $v_\infty(f/g) = \deg g - \deg f = -v(f/g)$
，其相关的绝对值为 $|x|_\infty = q^{-v_\infty(x)} = q^{v(x)} = |x|$。这两个绝对
值是一致的，因此它们诱导出**相同**的拓扑和**相同**的完备化。

赋值环 $\mathcal{O} = \{x \in F_q(t) : |x| \le 1\} = \{f/g : \deg f \le \deg g\}
$ 是 $\mathbb{P}^1_{F_q}$ 上无穷远点 $t = \infty$ 处的局部环。其极大理想为 $\mat
hfrak{m} = \{x : |x| < 1\} = \{f/g : \deg f < \deg g\}$，由 $u := 1/t$ 生成（因
为 $|u| = q^{-1} < 1$ 且 $u$ 在 $\mathfrak{m}$ 中生成赋数 $1$）。剩余域 $\mathca
l{O}/\mathfrak{m} \cong F_q$。

**步骤 3. 完备化的结构。**

设 $\widehat{F}$ 为完备化。由于 $v_\infty$ 是剩余域为 $F_q$ 的离散赋值，且一致化
参数(uniformizer)为 $u = 1/t$，完备赋值环 $\widehat{\mathcal{O}}$ 的每个元素都有
一个唯一的展开式
$$\sum_{n=0}^{\infty} a_n\, u^n, \qquad a_n \in F_q,$$
即 $\widehat{\mathcal{O}} \cong F_q[[u]] = F_q[[1/t]]$。$\widehat{F}$ 中的每个非
零元素 $x$ 都有唯一确定的赋值 $v_\infty(x) = N \in \mathbb{Z}$，因此 $x = u^{-N}
\cdot \omega$，其中 $\omega \in \widehat{\mathcal{O}}^\times$。从而
$$\widehat{F} = \bigcup_{N\in\mathbb{Z}} u^{-N}\, F_q[[u]] = F_q((u)) = F_q((1/t
)).$$

**步骤 4. 显式稠密嵌入。**

每个有理函数 $f/g \in F_q(t)$ 都可以通过在 $u=0$（即 $t=\infty$）处进行长除法展
开为关于 $u=1/t$ 的截断洛朗级数；这些截断在 $|\cdot|$ 度量下逼近 $f/g$。因此 $F_
q(t)$ 在 $F_q((1/t))$ 中稠密，且 $F_q((1/t))$ 是完备的（形式洛朗级数构成一个完备
的离散赋值域），这证实了
$$\widehat{F_q(t)} \;\cong\; F_q((1/t)).$$

形式洛朗级数域：

$$\boxed{F_q((1/t))}.$$
