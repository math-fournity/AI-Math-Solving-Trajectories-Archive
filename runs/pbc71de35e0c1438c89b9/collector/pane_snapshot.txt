## Solution

We want the last two digits of the power tower $T_n = 3^{3^{3^{\cdots}}}$ with $
n = 2015$ threes, i.e., $T_n \bmod 100$.

**Recurrence.** Define $T_1 = 3$ and $T_{k+1} = 3^{T_k}$. We seek $T_{2015} \bmo
d 100$.

Since $\gcd(3,100)=1$, we split via CRT into $\bmod 4$ and $\bmod 25$.

### Step 1: $T_n \bmod 4$

$3 \equiv -1 \pmod 4$. Every $T_k$ is an odd power of 3, hence odd. So
$$T_n = 3^{T_{n-1}} \equiv (-1)^{\text{odd}} \equiv -1 \equiv 3 \pmod 4 \quad\te
xt{for all } n\ge 1.$$

### Step 2: $T_n \bmod 20$ (needed as the exponent for mod 25)

The order of $3$ modulo $20$ is $4$ (since $3^1\equiv3,\;3^2\equiv9,\;3^3\equiv7
,\;3^4\equiv1\pmod{20}$). Thus
$$T_k \bmod 20 = 3^{T_{k-1} \bmod 4} \bmod 20.$$
Using $T_{k-1}\equiv 3\pmod 4$ for $k-1\ge 1$:
$$T_k \equiv 3^3 = 27 \equiv 7 \pmod{20} \quad\text{for all } k\ge 2.$$
(Check: $T_1\equiv3$, $T_2=27\equiv7$, $T_3=3^{27}\equiv 3^{27\bmod 4}=3^3\equiv
7\pmod{20}$.) ✓

### Step 3: $T_n \bmod 25$

$\varphi(25)=20$ and $\gcd(3,25)=1$, so $3^{20}\equiv1\pmod{25}$. Hence
$$T_n \equiv 3^{T_{n-1}\bmod 20} \pmod{25}.$$
For $n\ge 3$, $T_{n-1}\equiv 7\pmod{20}$, giving
$$T_n \equiv 3^7 = 2187 \equiv 12 \pmod{25} \quad\text{for all } n\ge 3.$$

### Step 4: Combine via CRT

We need $x$ with $x\equiv 3\pmod 4$ and $x\equiv 12\pmod{25}$.

Write $x = 12 + 25k$. Since $12\equiv 0\pmod 4$ and $25\equiv 1\pmod 4$:
$$12 + 25k \equiv k \equiv 3 \pmod 4,$$
so $k\equiv 3\pmod 4$. Taking $k=3$:
$$x = 12 + 75 = 87.$$

Verification: $87 \bmod 4 = 3$ ✓, $87 \bmod 25 = 12$ ✓.

### Sanity check on $T_3 = 3^{27}$

$3^{27}\bmod 4 = 3$ (odd exponent). $3^{27}\bmod 25 = 3^{27\bmod 20}=3^7=2187\eq
uiv 12\pmod{25}$. CRT gives $87$. Indeed $3^{27} = 7625597484987$, which ends in
 **87**. ✓

Since $2015 \ge 3$, the result applies.

### Answer

The last two digits of the power tower are $\boxed{87}$.
