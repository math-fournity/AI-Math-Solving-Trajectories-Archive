The statement is **false**. I will construct a counterexample in $\ell^2(\mathbb
{N})$ over $\mathbb{C}$.

## Counterexample

Let $\{e_n\}_{n=1}^\infty$ be the standard orthonormal basis of $\ell^2$. Define
:
$$v_n = e_{2n}, \qquad u_n = e_{2n} + 4^{-n}\, e_1, \qquad n \geq 1.$$

### Step 1: Both sequences are basic

$\{v_n\} = \{e_{2n}\}$ is an orthonormal sequence, hence a basic sequence with b
asis constant $K=1$.

For $\{u_n\}$, note $\|u_n - e_{2n}\| = \|4^{-n} e_1\| = 4^{-n}$, so
$$\sum_{n=1}^\infty \|u_n - e_{2n}\| = \sum_{n=1}^\infty 4^{-n} = \frac{1}{3} <
\frac{1}{2} = \frac{1}{2K}.$$
By the **principle of small perturbations** (Bessaga–Pełczyński), $\{u_n\}$ is a
 basic sequence equivalent to $\{e_{2n}\}$.

### Step 2: Compute the tail spaces

$$V_m = \overline{\operatorname{span}}\{e_{2n} : n \ge m\} = \Bigl\{\sum_{n \ge
m} a_n\, e_{2n} : (a_n) \in \ell^2\Bigr\}.$$

Every element of $U_m$ has the form
$$\sum_{n \ge m} a_n\, u_n = \sum_{n \ge m} a_n\, e_{2n} + \Bigl(\sum_{n \ge m}
a_n\, 4^{-n}\Bigr) e_1.$$
Define the bounded linear functional $\varphi_m : V_m \to \mathbb{C}$ by $\varph
i_m\bigl(\sum a_n e_{2n}\bigr) = \sum_{n \ge m} a_n\, 4^{-n}$ (bounded by Cauchy
–Schwarz since $(4^{-n})_{n\ge m} \in \ell^2$). Then
$$U_m = \bigl\{x + \varphi_m(x)\, e_1 : x \in V_m\bigr\}.$$

### Step 3: Compute $W_m = V_m + U_m$

An element of $W_m$ is $v + u$ with $v = \sum_{n\ge m} b_n e_{2n} \in V_m$ and $
u = \sum_{n\ge m} a_n e_{2n} + \varphi_m(a)\, e_1 \in U_m$, giving
$$v + u = \sum_{n \ge m}(a_n + b_n)\, e_{2n} + \varphi_m(a)\, e_1.$$

**Claim:** $W_m = \mathbb{C}\, e_1 + V_m$ (algebraic sum).

*Proof of claim.* The inclusion $U_m \subseteq V_m + \mathbb{C}\,e_1$ is clear s
ince $u_n = e_{2n} + 4^{-n} e_1 \in V_m + \mathbb{C}\,e_1$, so $W_m \subseteq V_
m + \mathbb{C}\,e_1$.

For the reverse inclusion, take any $\alpha \in \mathbb{C}$ and $y = \sum_{n\ge
m} c_n e_{2n} \in V_m$. We need $v \in V_m$, $u \in U_m$ with $v + u = \alpha\,
e_1 + y$. Set $a = 4^m \alpha\, e_{2m} \in V_m$ (so $\varphi_m(a) = 4^m \alpha \
cdot 4^{-m} = \alpha$) and $u = a + \alpha\, e_1 \in U_m$, then $v = y - a \in V
_m$, and $v + u = y + \alpha\, e_1$. $\checkmark$

Since $e_1 \perp V_m$ and $V_m$ is closed, $\mathbb{C}\,e_1 + V_m$ is closed, so
 this holds whether $W_m$ is the algebraic or closed sum.

### Step 4: Compute the intersection

$$\bigcap_{m=1}^\infty W_m = \bigcap_{m=1}^\infty \bigl(\mathbb{C}\, e_1 + V_m\b
igr).$$

If $x \in \bigcap W_m$, write $x = \alpha_m\, e_1 + y_m$ with $y_m \in V_m$. Sin
ce $y_m$ has no $e_1$-component, $\alpha_m$ equals the $e_1$-coordinate of $x$,
hence $\alpha_m = \alpha$ is independent of $m$. Then $x - \alpha\, e_1 = y_m \i
n V_m$ for all $m$, so
$$x - \alpha\, e_1 \in \bigcap_{m=1}^\infty V_m = \{0\},$$
where the last equality uses that $\{e_{2n}\}$ is a basic sequence. Therefore $x
 = \alpha\, e_1$ and
$$\bigcap_{m=1}^\infty W_m = \mathbb{C}\, e_1 \neq \{0\}.$$

In particular, $e_1 \in W_m$ for every $m$ (e.g., $e_1 = -4^m e_{2m} + 4^m u_m$)
, so $e_1$ lies in the intersection.

### Conclusion

The statement $\bigcap_{m=1}^\infty W_m = \{0\}$ is **false** in general. The co
unterexample above exhibits two basic sequences in $\ell^2$ for which the inters
ection equals $\mathbb{C}\, e_1$, a one-dimensional subspace.
