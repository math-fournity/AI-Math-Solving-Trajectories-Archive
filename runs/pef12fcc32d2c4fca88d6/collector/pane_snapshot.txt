## Setup

Let me define the random walk. Each flip: heads → Rosencrantz pays $1 (f decreas
es by 1), tails → Guildenstern pays $1 (f increases by 1). So $f(n) = (\text{#ta
ils} - \text{#heads})$ is a simple symmetric random walk with $f(0)=0$ and steps
 $\pm 1$.

I need $E[M]$ where $M = \max\{f(0), f(1), \ldots, f(11)\}$.

## Reflection Principle

**Claim:** For a simple symmetric random walk $S_0=0, S_1, \ldots, S_n$,
$$P(M_n \geq k) = P(S_n \geq k) + P(S_n \geq k+1).$$

**Proof of claim:** By the reflection principle, for $j < k$:
$$P(M_n \geq k,\; S_n = j) = P(S_n = 2k - j).$$
Therefore:
$$P(M_n \geq k) = \sum_{j < k} P(S_n = 2k-j) + \sum_{j \geq k} P(S_n = j).$$
The first sum (substituting $i = 2k-j$, which ranges over $k+1, k+2, \ldots$) eq
uals $P(S_n \geq k+1)$, and the second sum equals $P(S_n \geq k)$. ∎

## Computing the expectation

Since $M_n \geq 0$ always (as $f(0)=0$), and $M_n \leq n$:
$$E[M_n] = \sum_{k=1}^{n} P(M_n \geq k) = \sum_{k=1}^{n}\bigl[P(S_n \geq k) + P(
S_n \geq k+1)\bigr].$$

For $n=11$: $S_{11} = 2T - 11$ where $T \sim \text{Bin}(11, \tfrac12)$, so $S_{1
1}$ takes odd values $\{-11,-9,\ldots,9,11\}$ with $P(S_{11}=2t-11) = \binom{11}
{t}/2^{11}$.

The binomial coefficients for $t=0,\ldots,11$ are: $1, 11, 55, 165, 330, 462, 46
2, 330, 165, 55, 11, 1$ (with $2^{11}=2048$).

Computing $P(S_{11} \geq k)$ (using $T \geq \lceil(k+11)/2\rceil$):

| $k$ | threshold $T\geq$ | $\sum\binom{11}{T}$ | $P(S_{11}\geq k)$ |
|-----|-------------------|----------------------|-------------------|
| 1   | 6  | 1024 | 1024/2048 |
| 2,3 | 7  | 562  | 562/2048  |
| 4,5 | 8  | 232  | 232/2048  |
| 6,7 | 9  | 67   | 67/2048   |
| 8,9 | 10 | 12   | 12/2048   |
| 10,11 | 11 | 1  | 1/2048    |
| 12  | 12 | 0    | 0         |

(Consecutive pairs coincide because $S_{11}$ only takes odd values.)

Using the simplified form:
$$E[M_{11}] = P(S_{11}\geq 1) + 2\sum_{k=2}^{11} P(S_{11}\geq k) + P(S_{11}\geq
12).$$

$$\sum_{k=2}^{11} P(S_{11}\geq k) = \frac{562+562+232+232+67+67+12+12+1+1}{2048}

$$E[M_{11}] = \frac{1024}{2048} + 2\cdot\frac{1748}{2048} + 0 = \frac{1024 + 349
6}{2048} = \frac{4520}{2048} = \frac{565}{256}.$$

## Verification

## Answer
