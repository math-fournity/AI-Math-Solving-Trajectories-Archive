# Problem

A high-tech agricultural firm is designing a sensor network across a flat, open plain. They have installed $n$ signal towers ($n > 2$) at specific coordinates such that no three towers sit along the same straight line. 

To calibrate the network, the engineers perform a "signal sweep" for every possible pair of towers. For each pair, they establish a virtual straight-line boundary connecting them. Then, among the remaining $n-2$ towers, they identify the single tower located at the shortest perpendicular distance to that boundary. The network's precision ensures that for every specific pair, this "nearest neighbor" is always unique.

A tower is classified as a "Reference Node" if it is identified as the unique nearest neighbor for at least one pair of towers. Let $f(n)$ represent the maximum possible number of distinct towers that can be classified as Reference Nodes for a given configuration of $n$ towers.

Calculate the value of the sum:
$$\sum_{n=3}^{100} f(n)$$
