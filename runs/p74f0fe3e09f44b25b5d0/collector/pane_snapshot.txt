Looking at this problem, I need to determine whether a radical ideal in a polyno
mial ring can have the property that all its nonzero elements are non-homogeneou
s.

**Answer: Yes.**

**Proof.**

Let $k$ be a field and $R = k[x_1, x_2, \ldots, x_n]$ with the standard grading
($\deg x_i = 1$). I exhibit a radical ideal containing no nonzero homogeneous el
ement.

**The ideal.** Set $I = (x_1 + 1) \subset R$.

**Step 1: $I$ is radical (indeed, prime).**

The quotient $R/I \cong k[x_2, \ldots, x_n]$ is an integral domain, so $I$ is pr
ime, hence radical.

**Step 2: $I$ contains no nonzero homogeneous element.**

Suppose for contradiction that $f \in I$ is a nonzero homogeneous polynomial of
degree $d$. Then $f = (x_1 + 1)\,g$ for some nonzero $g \in R$. Write the homoge
neous decomposition
$$g = g_m + g_{m+1} + \cdots + g_M,$$
where each $g_j$ is homogeneous of degree $j$, $g_m \neq 0$, and $g_M \neq 0$.

Expanding $(x_1+1)g = x_1 g + g$, the homogeneous component of degree $j$ is:
$$\bigl[(x_1+1)g\bigr]_j = x_1\, g_{j-1} + g_j, \qquad (g_{-1} := 0).$$

Since $f$ is homogeneous of degree $d$, every component of degree $\neq d$ must
vanish.

- **Lowest degree ($j = m$):** The component is $x_1\, g_{m-1} + g_m = 0 + g_m =
 g_m$. For this to vanish we need $g_m = 0$, contradicting the choice of $m$—**u
nless** $m = d$, in which case this component is allowed to be nonzero. So $m =
d$ and $g_d \neq 0$.

- **Degree $j = d+1$:** $x_1\, g_d + g_{d+1} = 0$, so $g_{d+1} = -x_1\, g_d$.

- **Degree $j = d+2$:** $x_1\, g_{d+1} + g_{d+2} = 0$, so $g_{d+2} = -x_1\, g_{d
+1} = x_1^2\, g_d$.

- **By induction:** $g_{d+k} = (-x_1)^k\, g_d$ for all $k \geq 0$.

Since $g_d \neq 0$ and $x_1$ is not a zero-divisor in $R$, each $(-x_1)^k g_d \n
eq 0$. Therefore $g$ has nonzero homogeneous components of arbitrarily high degr
ee, contradicting the fact that $g$ is a polynomial (finite degree).

Hence $g = 0$, so $f = 0$—contradicting $f \neq 0$. $\square$

**Step 3: Conclusion.**

No nonzero homogeneous element belongs to $I$, yet $I$ is radical. Therefore a r
adical ideal in a polynomial ring **can** contain only non-homogeneous elements
(besides $0$, which is homogeneous by convention).

**Simplest instance.** In $k[x]$, the maximal (hence radical) ideal $(x+1)$ work
s: a nonzero homogeneous element of $k[x]$ is $c\,x^d$ ($c \neq 0$), and $(x+1)
\mid c\,x^d$ would require $(x+1)\mid x^d$, but $\gcd(x+1,\, x)=1$, so this neve
r happens.
