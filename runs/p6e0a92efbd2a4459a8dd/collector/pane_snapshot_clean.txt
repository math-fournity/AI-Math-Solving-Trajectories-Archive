## Setup

Let $n = \lfloor x \rfloor$, $\alpha = \{x\}$, $m = \lfloor x^3 \rfloor$, $\beta
 = \{x^3\}$, so $x = n+\alpha$, $x^3 = m+\beta$.

The equation is $\sqrt{nm} + \sqrt{\alpha\beta} = x^2$.

## Key Inequality (Cauchy–Schwarz)

Applying Cauchy–Schwarz to vectors $(\sqrt{n}, \sqrt{\alpha})$ and $(\sqrt{m}, \
sqrt{\beta})$:

$$\sqrt{nm} + \sqrt{\alpha\beta} \leq \sqrt{(n+\alpha)(m+\beta)} = \sqrt{x \cdot
 x^3} = x^2$$

with equality iff the vectors are proportional: $\frac{n}{m} = \frac{\alpha}{\be
ta}$, i.e., $n\beta = m\alpha$.

Since the equation requires equality, we need $n\beta = m\alpha$.

## Deriving the Structure

From $\frac{n}{\alpha} = \frac{m}{\beta} = r$: $\alpha = n/r$, $\beta = m/r$. Th
en $x = n(1+1/r)$ and $x^3 = m(1+1/r)$, giving $\frac{x^3}{x} = \frac{m}{n}$, so
 $m = nx^2$.

Since $m = \lfloor x^3 \rfloor$ must be an integer, **$nx^2 \in \mathbb{Z}$**. A
lso $\beta = x^3 - m = x^3 - nx^2 = x^2(x-n) = x^2\alpha$, and the fractional pa
rt condition requires $0 \leq x^2\alpha < 1$.

## Parametrizing Solutions

Set $k = nx^2$ (integer), so $x = \sqrt{k/n}$. We need $n \leq x < n+1$, i.e., $
n^3 \leq k < n(n+1)^2$, and $x^3 - k < 1$ (i.e., $x^2\alpha < 1$).

Write $k = n^3 + j$ with $0 \leq j \leq n(2n+1)-1$. Define $f(k) = (k/n)^{3/2} -

**$f$ is strictly increasing for $k \geq n^3$:** $f'(k) = \frac{3\sqrt{k}}{2n^{3
/2}} - 1 \geq \frac{3}{2} - 1 = \frac{1}{2} > 0$.

**$j = 0$ (integers):** $x = n$, $f = 0 < 1$. ✓ All positive integers work.

**$j = 1$:** $x = \sqrt{n^2 + 1/n}$, $f = (n^2+1/n)^{3/2} - n^3 - 1 = n^3\!\left

2} < 1 + 2t$. Let $g(t) = (1+t)^{3/2} - 1 - 2t$. Then $g(0)=0$, $g'(0) = -1/2 <
0$, $g''(t) = \frac{3}{4}(1+t)^{-1/2} > 0$ (convex). The minimum is at $t = 7/9$

0$ for all $t \in (0,1]$. ✓ **$j=1$ always works.**

**$j = 2$:** $f \approx n^3(1 + 3/n^3 + 3/(2n^6)) - n^3 - 2 = 1 + \frac{3}{2n^3}

## The 100 Smallest Values

For each $n \geq 1$, exactly two solutions: $x = n$ and $x = \sqrt{n^2 + 1/n}$,
with $n < \sqrt{n^2+1/n} < n+1$ (since $1/n < 2n+1$). Ordering:

$$x_1 = 1,\ x_2 = \sqrt{1+1},\ x_3 = 2,\ x_4 = \sqrt{4+\tfrac{1}{2}},\ x_5 = 3,\

So $x_{2k-1} = k$ and $x_{2k} = \sqrt{k^2 + 1/k}$ for $k = 1, 2, \ldots, 50$.

## Computing the Sum

$$\sum_{k=1}^{50}\frac{1}{x_{2k}^2 - x_{2k-1}^2} = \sum_{k=1}^{50}\frac{1}{\left

= \frac{50 \cdot 51}{2} = \boxed{1275}$$
