an open interval of length $10^{-4}$ (open because $x$ irrational excludes the r

$$\sum x_i \in \left(\frac{1111S}{10000},\;\frac{1111S+n}{10000}\right). \tag{$*

Conversely, every value $t$ in this open interval is attained: set $E = t - \fra
c{1111S}{10000} \in (0, n/10000)$, and choose irrationals $\epsilon_i \in (0, 10

i = d_j$. Such a choice exists because the set $\{(\epsilon_1,\ldots,\epsilon_n)

with empty interior, leaving a dense nonempty subset. Then $x_i = \frac{1111d_i}

$t$.

Since $S$ ranges over all integers $\{0, 1, \ldots, 9n\}$, the set of all repres

$$\mathcal{U}_n = \bigcup_{S=0}^{9n} \left(\frac{1111S}{10000},\;\frac{1111S+n}{

**Step 2 ($n = 1111$ is insufficient).** For $n = 1111$, the $S$-th interval is
