## Solution

**Total codes:** From 100 to 999 inclusive, there are $999 - 100 + 1 = 900$ code
s.

**Codes divisible by 3:** The smallest is $102 = 34 \times 3$ and the largest is
 $999 = 333 \times 3$, giving $333 - 34 + 1 = 300$ codes.

**Counting codes divisible by 3 with at least one digit '1':** I use complementa
ry counting — count codes divisible by 3 with **no** digit equal to 1, then subt
ract from 300.

A three-digit code $abc$ with no digit '1' has:
- $a \in \{2,3,4,5,6,7,8,9\}$ (8 choices; cannot be 0 or 1)
- $b, c \in \{0,2,3,4,5,6,7,8,9\}$ (9 choices each)

We need $a + b + c \equiv 0 \pmod{3}$.

**Residue class counts** for digits $\{0,2,3,4,5,6,7,8,9\}$ (used for $b, c$):
- Residue 0: $\{0,3,6,9\}$ → 4 digits
- Residue 1: $\{4,7\}$ → 2 digits
- Residue 2: $\{2,5,8\}$ → 3 digits

**Residue class counts** for $a \in \{2,3,4,5,6,7,8,9\}$:
- Residue 0: $\{3,6,9\}$ → 3 digits
- Residue 1: $\{4,7\}$ → 2 digits
- Residue 2: $\{2,5,8\}$ → 3 digits

**Number of $(b,c)$ pairs with $b+c \equiv s \pmod{3}$** (using $n_0=4, n_1=2, n
_2=3$):
- $s=0$: $n_0^2 + 2n_1 n_2 = 16 + 12 = 28$
- $s=1$: $2n_0 n_1 + n_2^2 = 16 + 9 = 25$
- $s=2$: $2n_0 n_2 + n_1^2 = 24 + 4 = 28$

(Check: $28+25+28 = 81 = 9^2$ ✓)

**Combining by residue of $a$** (need $b+c \equiv -a \pmod{3}$):
- $a \equiv 0$ (3 digits): need $b+c \equiv 0$ → $3 \times 28 = 84$
- $a \equiv 1$ (2 digits): need $b+c \equiv 2$ → $2 \times 28 = 56$
- $a \equiv 2$ (3 digits): need $b+c \equiv 1$ → $3 \times 25 = 75$

**Total no-'1' codes divisible by 3:** $84 + 56 + 75 = 215$.

**Codes divisible by 3 with at least one '1':** $300 - 215 = 85$.

**Probability:** $\dfrac{85}{900} = \dfrac{17}{180}$, where $\gcd(17,180)=1$ sin
ce 17 is prime and $180 = 2^2 \cdot 3^2 \cdot 5$.

Thus $m = 17$, $n = 180$, and

$$m + n = 17 + 180 = \boxed{197}$$
