Looking at this problem, I need to prove that $c(n,m) = \sum_{j=1}^m j^n$, where
 $c(n,m)$ counts functions $f:\mathcal{P}_n \to \{1,\dots,m\}$ satisfying $f(A \
cap B) = \min\{f(A), f(B)\}$.

**Proof.**

**Step 1: $f$ is order-reversing.** If $C \subseteq A$, then $C = A \cap C$, so
$f(C) = f(A \cap C) = \min(f(A), f(C))$, giving $f(C) \leq f(A)$.

**Step 2: $f$ is determined by its values on $[n]\setminus\{i\}$.** Set $g_i :=
f([n]\setminus\{i\})$ for $i=1,\dots,n$. Any $A \neq [n]$ can be written as $A =
 \bigcap_{i \notin A} ([n]\setminus\{i\})$ (non-empty intersection). By inductio
n on the min condition:

$$f(A) = \min_{i \notin A} g_i \quad \text{for all } A \neq [n].$$

In particular $f(\emptyset) = \min_{i} g_i$.

**Step 3: Constraint on $f([n])$.** Taking $A = [n]$ in the condition: $f(B) = \
min(f([n]), f(B))$ for all $B$, so $f([n]) \geq f(B)$ for all $B$. The maximum o
f $f(B)$ over $B \neq [n]$ is $\max_{A \neq [n]} \min_{i \notin A} g_i = \max_i
g_i$ (achieved by $A = [n]\setminus\{j\}$ where $g_j$ is maximal). Thus:

$$f([n]) \geq \max_i g_i, \quad f([n]) \in \{1,\dots,m\}.$$

**Step 4: Verification.** Conversely, given any $(g_1,\dots,g_n) \in \{1,\dots,m
\}^n$ and any $v \in \{1,\dots,m\}$ with $v \geq \max_i g_i$, define $f([n]) = v
$, $f(A) = \min_{i \notin A} g_i$ for $A \neq [n]$. One checks:
- If $A = [n]$: $f([n] \cap B) = f(B) = \min(v, f(B)) = f(B)$ since $v \geq \max
_i g_i \geq f(B)$. ✓
- If $A, B \neq [n]$: then $A \cap B \neq [n]$, and $f(A \cap B) = \min_{i \noti
n A \cap B} g_i = \min\!\big(\min_{i \notin A} g_i,\, \min_{i \notin B} g_i\big)
 = \min(f(A), f(B))$. ✓

So valid functions are in bijection with pairs $((g_1,\dots,g_n), v)$ where $g_i
 \in \{1,\dots,m\}$ and $v \in \{\max_i g_i, \dots, m\}$.

**Step 5: Counting.** Let $M = \max_i g_i$. The number of tuples with $\max = j$
 is $j^n - (j-1)^n$ (those in $\{1,\dots,j\}^n$ minus those in $\{1,\dots,j-1\}^
n$). For each such tuple, $v$ has $m - j + 1$ choices. Thus:

$$c(n,m) = \sum_{j=1}^{m} (m - j + 1)\big(j^n - (j-1)^n\big).$$

Since $m - j + 1 = \sum_{k=j}^{m} 1$, we swap the order of summation:

$$c(n,m) = \sum_{j=1}^{m} \sum_{k=j}^{m} \big(j^n - (j-1)^n\big) = \sum_{k=1}^{m
} \sum_{j=1}^{k} \big(j^n - (j-1)^n\big).$$

The inner sum telescopes: $\sum_{j=1}^{k}(j^n - (j-1)^n) = k^n$. Therefore:

$$c(n,m) = \sum_{k=1}^{m} k^n. \qquad \blacksquare$$
