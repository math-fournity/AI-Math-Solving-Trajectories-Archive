Looking at this problem, I need to determine whether the set $S = \{p \in (0,1)
: \exists\, i,\; x_i(p) \in \mathbb{Q}\}$ must be dense in $(0,1)$, given that $
f$ is continuous and non-constant on every open subinterval.

**Answer: Yes, $S$ must be dense in $(0,1)$.**

## Proof

We prove by contradiction. Suppose $S$ is **not** dense in $(0,1)$. Then there e
xists an open interval $J \subset (0,1)$ such that $J \cap S = \emptyset$.

(Reason: $S$ not dense means $\overline{S} \not\supset (0,1)$, so some $p_0 \in
(0,1)$ lies in the open set $(0,1)\setminus\overline{S}$, giving an open interva
l $J$ around $p_0$ with $J \cap S = \emptyset$.)

**Key Lemma.** Let $g : J \to \mathbb{R}$ be continuous. If $g(p) \notin \mathbb
{Q}$ for every $p \in J$ (i.e., $g$ takes only irrational values), then $g$ is c
onstant on $J$.

*Proof of Lemma.* Suppose $g$ is not constant on $J$. Then there exist $a, b \in
 J$ with $g(a) \neq g(b)$. Since $J$ is an interval, $[a,b] \subset J$ (or $[b,a
] \subset J$). By the Intermediate Value Theorem, $g$ attains every value betwee
n $g(a)$ and $g(b)$. In particular, $g$ attains every value in the interval $[\m
in(g(a),g(b)),\, \max(g(a),g(b))]$, which is a non-degenerate interval and there
fore contains a rational number $q$. So there exists $p$ between $a$ and $b$ wit
h $g(p) = q \in \mathbb{Q}$, contradicting the assumption that $g$ takes only ir
rational values. $\square$

**Applying the Lemma.** Since $J \cap S = \emptyset$, for every $p \in J$ and ev
ery $i \in \{1, \dots, n\}$, we have $x_i(p) \notin \mathbb{Q}$. Each coordinate
 function $x_i : J \to \mathbb{R}$ is continuous (as a component of the continuo
us map $f$) and takes only irrational values on $J$. By the Lemma, each $x_i$ is
 constant on $J$.

Therefore $f = (x_1, \dots, x_n)$ is constant on $J$. But $J$ is an open interva
l contained in $(0,1)$, and the hypothesis states that $f$ is non-constant on **
every** open interval of $(0,1)$. This is a contradiction.

**Conclusion.** Our assumption that $S$ is not dense must be false. Hence $S$ is
 dense in $(0,1)$. $\blacksquare$

**Remark.** The argument does not actually require $n > 1$; it holds for all $n
\geq 1$. For $n = 1$, the single coordinate $x_1 = f$ is non-constant on every i
nterval, so by the IVT it hits rational values on a dense set. For $n > 1$, the
hypothesis is weaker (only the vector $f$ need be non-constant, not each coordin
ate), but the lemma still forces all coordinates to be constant on any interval
avoiding $S$, yielding the same contradiction.
