## Finding the Invariant

I check the quantity $I_n = 2a_n b_n + c_n^2$:

**Even step:** $I_{n+1} = 2(a_n/2)(2b_n) + c_n^2 = 2a_n b_n + c_n^2 = I_n$. ✓

**Odd step:** $I_{n+1} = 2(a_n - b_n/2 - c_n)b_n + (b_n + c_n)^2 = 2a_n b_n - b_
n^2 - 2b_n c_n + b_n^2 + 2b_n c_n + c_n^2 = 2a_n b_n + c_n^2 = I_n$. ✓

So $I = 2a_n b_n + c_n^2 = 8k + 1$ is invariant throughout.

## Necessary Condition

If $a_n = 0$ at some point, then $c_n^2 = 8k+1$, so $8k+1$ must be a perfect squ
are. Setting $8k+1 = m^2$ with $m$ odd, we get $k = j(j+1)/2$ (triangular number

## Tracking $c_n$ and the Key Constraint

Since $b_0 = 4$ and $b$ only doubles (even steps) or stays fixed (odd steps), $b
_n$ is always a power of $2$ with $b_n \geq 4$. At each odd step, $c$ increases
by $b_n$. Since $a_n$ odd implies $b_n/2 + c_n$ is odd (as $b_n/2$ is even, $c_n
$ is odd), the result $a_{n+1} = a_n - b_n/2 - c_n$ is always **even**. So there
's at least one even step after each odd step, meaning $b$ strictly increases be
tween odd steps.

If $a_n = 0$ is reached at an odd step, then $c_n = m$ and $c_n = 1 + \sum_{i} B
_i$ where each $B_i \geq 4$ is a distinct power of $2$. Thus $m - 1 = \sum B_i \
equiv 0 \pmod{4}$, giving $m \equiv 1 \pmod{4}$.

## Sufficiency: $m \equiv 1 \pmod{4}$ Implies Termination

Write $m - 1 = 2^{f_1} + 2^{f_2} + \cdots + 2^{f_r}$ with $2 \leq f_1 < f_2 < \c
dots < f_r$ (the binary expansion, valid since $m \equiv 1 \pmod{4}$).

**Key formula:** At any odd step with state $(A, B, C)$ where $B = 2^e$, setting
 $C'' = C + B$:
$$a' = A - B/2 - C = \frac{m^2 - C''^2}{2^{e+1}} = \frac{(m - C'')(m + C'')}{2^{
e+1}}.$$

**Induction:** I prove the process follows the binary digits of $m-1$.

*Initial step:* Since $k = \frac{m-1}{4} \cdot \frac{m+1}{2}$ with $(m+1)/2$ odd
, $v_2(k) = v_2((m-1)/4) = f_1 - 2$. After $f_1 - 2$ even steps: $B_1 = 2^{f_1}$
, $C_1 = 1$, $A_1$ odd. ✓

*Inductive step $i$ ($1 \leq i \leq r$):* Assume $B_i = 2^{f_i}$, $C_i = 1 + \su
m_{j=1}^{i-1} 2^{f_j}$. Then $C'' = 1 + \sum_{j=1}^{i} 2^{f_j}$.

$$m - C'' = \sum_{j=i+1}^{r} 2^{f_j}, \qquad m + C'' = 2m - (m - C'').$$

- If $i = r$: $m - C'' = 0$, so $a' = 0$. **Termination achieved.** ✓
- If $i < r$: $v_2(m - C'') = f_{i+1}$ (smallest bit). Since $f_{i+1} \geq 3$, w
e get $m - C'' \equiv 0 \pmod{8}$, while $2m \equiv 2 \pmod{4}$, so $v_2(m + C''
) = 1$.

Thus $v_2(a') = f_{i+1} + 1 - (f_i + 1) = f_{i+1} - f_i$, giving $B_{i+1} = 2^{f
_{i+1}}$ and $C_{i+1} = C'' = 1 + \sum_{j=1}^i 2^{f_j}$. Also $A_{i+1}$ is odd (
numerator and denominator have equal 2-adic valuation). Positivity holds since $
m > C''$ for $i < r$. ✓

## Non-termination When $m \equiv 3 \pmod{4}$

If $m \equiv 3 \pmod{4}$, then $m - 1 \equiv 2 \pmod{4}$, so $m - 1$ has a 1-bit

 1 \equiv 0 \pmod{4}$, which is impossible. Once $a$ goes negative, it stays neg
ative (even steps preserve sign, odd steps decrease further), so $a = 0$ is neve
