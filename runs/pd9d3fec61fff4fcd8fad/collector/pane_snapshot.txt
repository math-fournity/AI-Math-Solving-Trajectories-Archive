## Setup

Place Earth's center $O$ at the origin in the orbital plane (2D). The South Pole
 $S$ is at $(0, -R)$. The vertical axis at $S$ is the radial direction (pointing
 outward). The launch at angle $\theta$ from vertical gives velocity components:
- Radial (outward): $v_r = v\cos\theta$
- Tangential: $v_t = v\sin\theta$

The orbit plane contains the Earth's axis (since the position $\vec{OS}$ is axia
l and the velocity has an axial component), so the 2D cross-section captures eve
rything. The Northern Hemisphere corresponds to $y > 0$.

## Orbit Equations

The orbit is $r = \frac{p}{1 + e\cos\psi}$, with focus at $O$, where $p = h^2/\m
u$, $h = Rv\sin\theta$, and $\psi$ is true anomaly from periapsis.

At $S$: $r = R$, so $1 + e\cos\psi_S = q$ where $q = p/R$. The velocity relation
s give:

$$e\sin\psi_S = q\cot\theta \quad (1), \qquad e\cos\psi_S = q - 1 \quad (2)$$

Since $v_r > 0$ (outward), $\sin\psi_S > 0$, so $\psi_S \in (0, \pi)$. Let $\bet
a = \psi_S$.

## Locating the Impact Point

The orbit intersects $r = R$ at two symmetric points: true anomalies $\beta$ and
 $-\beta$. The pod travels from $S$ (at $\beta$) through apoapsis to the second
intersection $P$ (at $-\beta$).

If $\varphi_0$ is the periapsis direction, then $S$ at polar angle $-\pi/2$ give

$$\alpha_P = \varphi_0 - \beta = -\frac{\pi}{2} - 2\beta \equiv \frac{3\pi}{2} -
 2\beta \pmod{2\pi}$$

**Northern Hemisphere condition:** $\sin\alpha_P > 0 \Rightarrow -\cos(2\beta) >
 0 \Rightarrow \cos(2\beta) < 0 \Rightarrow \beta \in \left(\frac{\pi}{4}, \frac
{3\pi}{4}\right)$.

## Eccentricity Constraint

From (1)–(2): $e^2 = q^2\cot^2\theta + (q-1)^2$. For an ellipse ($e < 1$):

$$q^2\cot^2\theta + (q-1)^2 < 1 \implies \frac{q^2}{\sin^2\theta} - 2q < 0 \impl
ies q < 2\sin^2\theta$$

So $q \in (0,\, 2\sin^2\theta)$.

## Critical Analysis: Case $\theta < \pi/4$

Here $2\sin^2\theta < 1$, so $q \in (0, 1)$, giving $\tan\beta < 0$ with $\sin\b

We need $\beta < 3\pi/4$, i.e., $\tan\beta > -1$. From $\tan\beta = \frac{q\cot\

$$\frac{q\cot\theta}{q-1} > -1 \implies q\cot\theta < 1 - q \implies q < \frac{1
}{\cot\theta + 1} = \frac{\sin\theta}{\cos\theta + \sin\theta} =: q^*$$

Since $\beta$ **decreases** as $q$ **increases**, $\beta < 3\pi/4$ requires $q >
 q^*$ (not $q < q^*$). Let me re-derive carefully:

At $q \to 0^+$: $\tan\beta \to 0^-$, so $\beta \to \pi^-$. At $q \to 1^-$: $\tan
\beta \to -\infty$, so $\beta \to \pi/2^+$. So $\beta$ decreases as $q$ increase

n\theta}{\cos\theta + \sin\theta}$.

For $\beta < 3\pi/4$ (Northern Hemisphere): we need $q > q^*$.

Combined with the ellipse constraint $q < 2\sin^2\theta$, a valid orbit exists i

$$q^* < 2\sin^2\theta \iff \frac{\sin\theta}{\cos\theta + \sin\theta} < 2\sin^2\

$$\iff \sin 2\theta > \cos 2\theta \iff \tan 2\theta > 1 \iff 2\theta > \frac{\p

**At the parabolic boundary** $q = 2\sin^2\theta$ (where $e \to 1$): $\tan\beta

## Case $\theta > \pi/4$

Here $2\sin^2\theta > 1$, so $q$ can exceed 1. For $q \in (q^*, 1)$: $\beta \in
(\pi/2, 3\pi/4)$, valid. Since $q^* < 1/2 < 1 < 2\sin^2\theta$, the range $(q^*,
 2\sin^2\theta)$ is non-empty. The pod reaches the Northern Hemisphere. ✓

## Conclusion

The set of launch angles reaching the Northern Hemisphere is $\theta \in \left(\
frac{\pi}{8}, \frac{\pi}{2}\right)$, **open** at $\pi/8$ (at $\theta = \pi/8$ on

$$M = \tan\frac{\pi}{8} = \tan 22.5° = \frac{1 - \cos 45°}{\sin 45°} = \frac{1 -

Since $\theta = \pi/8$ is not achievable (the infimum is not attained), the cond

$$\boxed{M = \sqrt{2} - 1}$$
