## General Solution of $A u_{xx} + B u_{xy} + C u_{yy} = 0$

### Setup: The Auxiliary Equation

We seek solutions of the form $u(x,y) = f(y + mx)$ for a constant $m$ and an arb
itrary twice-differentiable function $f$. Computing derivatives (with $s = y + m
x$):

$$u_x = m f'(s),\quad u_{xx} = m^2 f''(s),\quad u_{xy} = m f''(s),\quad u_{yy} =
 f''(s).$$

Substituting into the PDE:

$$\bigl(A m^2 + B m + C\bigr)\, f''(s) = 0.$$

For a nontrivial solution ($f'' \not\equiv 0$) we require the **auxiliary (chara
cteristic) equation**:

$$\boxed{A m^2 + B m + C = 0},$$

with roots

$$m_{1,2} = \frac{-B \pm \sqrt{B^2 - 4AC}}{2A} \qquad (A \neq 0).$$

The discriminant $\Delta = B^2 - 4AC$ determines three cases. By superposition (
the PDE is linear), the general solution is a linear combination of solutions bu
ilt from each root.

---

### Case 1: Hyperbolic — $\Delta = B^2 - 4AC > 0$

Two **distinct real roots** $m_1 \neq m_2$. The two independent solutions $f_1(y
 + m_1 x)$ and $f_2(y + m_2 x)$ give:

$$\boxed{u(x,y) = \varphi\!\bigl(y + m_1 x\bigr) + \psi\!\bigl(y + m_2 x\bigr),}
$$

where $\varphi, \psi$ are arbitrary $C^2$ functions.

**Verification.** With $s_i = y + m_i x$:
$$A u_{xx} + B u_{xy} + C u_{yy} = (Am_1^2 + Bm_1 + C)\,\varphi''(s_1) + (Am_2^2
 + Bm_2 + C)\,\psi''(s_2) = 0 + 0 = 0. \;\checkmark$$

---

### Case 2: Parabolic — $\Delta = B^2 - 4AC = 0$

One **repeated real root** $m = -B/(2A)$. A single family $f(y+mx)$ gives only o
ne solution; we obtain a second independent solution by the standard repeated-ro
ot ansatz $x \cdot g(y + mx)$:

$$\boxed{u(x,y) = \varphi\!\bigl(y + m x\bigr) + x\,\psi\!\bigl(y + m x\bigr), \
qquad m = -\frac{B}{2A}.}$$

**Verification.** Let $s = y + mx$, $u = \varphi(s) + x\,\psi(s)$.

$$u_{xx} = m^2 \varphi'' + 2m\,\psi' + x\,m^2 \psi'', \quad u_{xy} = m\,\varphi'
' + \psi' + x\,m\,\psi'', \quad u_{yy} = \varphi'' + x\,\psi''.$$

Collecting terms:

$$A u_{xx} + B u_{xy} + C u_{yy} = \underbrace{(Am^2 + Bm + C)}_{=0}\bigl(\varph
i'' + x\,\psi''\bigr) + \underbrace{(2Am + B)}_{=0}\,\psi' = 0. \;\checkmark$$

The second bracket vanishes because $m = -B/(2A)$ is a double root, so $2Am + B
= 0$.

---

### Case 3: Elliptic — $\Delta = B^2 - 4AC < 0$

Two **complex conjugate roots** $m_1 = \alpha + i\beta$, $m_2 = \alpha - i\beta$
, where

$$\alpha = -\frac{B}{2A}, \qquad \beta = \frac{\sqrt{4AC - B^2}}{2A}.$$

Formally, the solution has the same shape $u = F(y + m_1 x) + G(y + m_2 x)$, whe
re $F, G$ are analytic functions of their (complex) arguments. For $u$ to be **r
eal-valued**, we require $G(\bar{z}) = \overline{F(z)}$, yielding:

$$\boxed{u(x,y) = 2\,\operatorname{Re}\!\Bigl[F\!\bigl(y + (\alpha + i\beta)\,x\
bigr)\Bigr],}$$

where $F$ is an arbitrary analytic function of the complex variable $z = y + (\a
lpha + i\beta)\,x = (y + \alpha x) + i\,\beta x$.

Equivalently, introducing real variables $\xi = y + \alpha x$, $\eta = \beta x$,
 the PDE reduces to the **Laplace equation** $u_{\xi\xi} + u_{\eta\eta} = 0$, wh
ose general real solution is the real part of an analytic function of $\xi + i\e
ta$.

**Verification.** Setting $z = y + m_1 x$, $\bar{z} = y + m_2 x$:
$$A u_{xx} + B u_{xy} + C u_{yy} = (Am_1^2 + Bm_1 + C)\,F''(z) + (Am_2^2 + Bm_2
+ C)\,G''(\bar{z}) = 0. \;\checkmark$$

---

### Degenerate Cases ($A = 0$)

- **$A = 0,\, C \neq 0$:** Swap $x \leftrightarrow y$; the equation becomes $C\,
v_{xx} + B\,v_{xy} = 0$ (with $v(y,x)=u(x,y)$), and the above analysis applies w
ith $A \leftrightarrow C$.
- **$A = 0,\, C = 0,\, B \neq 0$:** The equation is $B\,u_{xy} = 0$, i.e. $u_{xy
} = 0$, giving $u = \varphi(x) + \psi(y)$.
- **$A = B = C = 0$:** The equation is $0 = 0$; $u$ is arbitrary.

---

### Summary

| Type | Condition | General Solution |
|------|-----------|-----------------|
| Hyperbolic | $B^2 - 4AC > 0$ | $u = \varphi(y + m_1 x) + \psi(y + m_2 x)$ |
| Parabolic | $B^2 - 4AC = 0$ | $u = \varphi(y + mx) + x\,\psi(y + mx)$ |
| Elliptic | $B^2 - 4AC < 0$ | $u = 2\operatorname{Re}[F(y + (\alpha+i\beta)x)]$
 |

where $m_{1,2} = \frac{-B \pm \sqrt{B^2-4AC}}{2A}$, $m = -\frac{B}{2A}$, $\alpha
 = -\frac{B}{2A}$, $\beta = \frac{\sqrt{4AC-B^2}}{2A}$, and $\varphi, \psi$ are
arbitrary $C^2$ functions, $F$ an arbitrary analytic function.
