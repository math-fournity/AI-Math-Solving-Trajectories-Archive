Looking at this problem, I need to determine whether $\{\varphi(n)/n : n \notin
\mathbb{P}\}$ is dense in $(0,1)$.

**Note on the problem statement:** The phrase "natural number not divisible by a
ny prime" is a garbled translation; taken literally only $n=1$ qualifies, giving
 the trivial set $\{1\}$. The mathematical notation $n \notin \mathbb{P}$ unambi
guously means $n$ is not prime, so $n$ ranges over $\{1\} \cup \{\text{composite
s}\}$. Since $\varphi(1)/1 = 1 \notin (0,1)$, the relevant set is $\{\varphi(n)/
n : n \text{ composite}\}$.

---

## Proof that the set is dense in $(0,1)$

**Setup.** For $n = \prod p^{a_p}$, we have $\varphi(n)/n = \prod_{p \mid n}(1 -
 1/p)$. For squarefree $n = \prod_{p \in S} p$ (product of distinct primes), $\v
arphi(n)/n = \prod_{p \in S}(1-1/p)$.

Taking logarithms with $a_p := \log\!\bigl(\tfrac{p}{p-1}\bigr) = -\log(1-1/p) >
 0$:

$$\log\!\bigl(\varphi(n)/n\bigr) = -\sum_{p \in S} a_p.$$

**Two key facts:**
1. $a_p \to 0$ as $p \to \infty$ (since $a_p \sim 1/p$).
2. $\sum_p a_p = \infty$, because $a_p \geq 1/p$ and $\sum_p 1/p = \infty$ (Eule
r).

---

**Lemma.** *Let $b_1, b_2, \ldots > 0$ with $b_i \to 0$ and $\sum b_i = \infty$.
 Then for any $L > 0$ and $\varepsilon > 0$, there exist indices $N{+}1, \ldots,
 k$ with $k \geq N{+}2$ such that $\bigl|\sum_{i=N+1}^{k} b_i - L\bigr| < \varep
silon$.*

*Proof.* Choose $N$ large enough that $b_i < \min(\varepsilon,\, L)$ for all $i
> N$. Define $S_j = \sum_{i=N+1}^{j} b_i$. Then $S_{N+1} = b_{N+1} < L$ and $S_j
 \to \infty$, so there exists $k$ with $S_{k-1} \leq L < S_k$. Since $S_{N+1} <
L$, we have $k \geq N+2$. The error is $|S_k - L| = S_k - L < S_k - S_{k-1} = b_
k < \varepsilon$. $\square$

---

**Main argument.** Given $x \in (0,1)$ and $\varepsilon > 0$:

- Set $L = -\log x > 0$.
- Choose $\delta > 0$ small enough that $x(e^{\delta}-1) < \varepsilon$ and $x(1
-e^{-\delta}) < \varepsilon$.
- Apply the Lemma to the sequence $(a_{p_i})$ (where $p_i$ is the $i$-th prime)
with parameters $L, \delta$. Obtain indices $N{+}1, \ldots, k$ with $k \geq N{+}
2$ and $\bigl|\sum_{i=N+1}^{k} a_{p_i} - L\bigr| < \delta$.

Set $n = \prod_{i=N+1}^{k} p_i$. Since $k \geq N+2$, this is a product of **at l
east two distinct primes**, so $n$ is **composite** — hence $n \notin \mathbb{P}
$.

Now:
$$\log\!\bigl(\varphi(n)/n\bigr) = -\sum_{i=N+1}^{k} a_{p_i}, \qquad \bigl|\log(
\varphi(n)/n) - \log x\bigr| = \Bigl|\sum a_{p_i} - L\Bigr| < \delta.$$

Exponentiating: $\varphi(n)/n \in \bigl(xe^{-\delta},\, xe^{\delta}\bigr)$, so $
|\varphi(n)/n - x| < \varepsilon$.

---

**Conclusion.** For every $x \in (0,1)$ and every $\varepsilon > 0$, we have pro
duced a **composite** $n \notin \mathbb{P}$ with $|\varphi(n)/n - x| < \varepsil
on$. Therefore

$$\overline{\left\{\frac{\varphi(n)}{n} : n \notin \mathbb{P}\right\}} \supseteq
 (0,1),$$

and the set **is dense in $(0,1)$**. $\blacksquare$
