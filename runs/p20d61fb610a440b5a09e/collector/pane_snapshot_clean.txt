Looking at this problem, I need to determine whether $\left\{\frac{p_{n+1}-p_n}{
n}\right\}$ is bounded, where $p_n$ is the $n$-th prime.

**Answer: The sequence is bounded.** In fact, it converges to $0$.

## Proof

Let $g_n = p_{n+1} - p_n$ denote the $n$-th prime gap. We show $g_n/n \to 0$.

**Key tool.** We use the Prime Number Theorem with the de la Vallée Poussin erro
r term: there exists a constant $c > 0$ such that

$$\pi(x) = \operatorname{Li}(x) + O\!\left(x\, e^{-c\sqrt{\log x}}\right).$$

**Claim.** For all sufficiently large $x$, the interval $\bigl[x,\; x + x\, e^{-
\frac{c}{2}\sqrt{\log x}}\bigr]$ contains a prime.

*Proof of Claim.* Set $h = x\, e^{-\frac{c}{2}\sqrt{\log x}}$. Note $h \ll x$ fo
r large $x$. The number of primes in $[x, x+h]$ is

$$\pi(x+h) - \pi(x) = \bigl(\operatorname{Li}(x+h) - \operatorname{Li}(x)\bigr)
+ E(x+h) - E(x),$$

where $|E(y)| \leq C\, y\, e^{-c\sqrt{\log y}}$ for some constant $C > 0$.

**Main term (lower bound).** Since $h \ll x$, we have $\log(x+h) \leq 2\log x$ f
or large $x$, so

$$\operatorname{Li}(x+h) - \operatorname{Li}(x) = \int_x^{x+h} \frac{dt}{\log t}
 \geq \frac{h}{\log(x+h)} \geq \frac{h}{2\log x} = \frac{x\, e^{-\frac{c}{2}\sqr
t{\log x}}}{2\log x}.$$

**Error term (upper bound).** Since $h < x$ for large $x$, we have $x + h < 2x$,
 and since $\log(x+h) \geq \log x$,

$$|E(x+h)| + |E(x)| \leq 2Cx\, e^{-c\sqrt{\log x}} + Cx\, e^{-c\sqrt{\log x}} =
3Cx\, e^{-c\sqrt{\log x}}.$$

**Dominance.** The main term dominates the error term provided

$$\frac{x\, e^{-\frac{c}{2}\sqrt{\log x}}}{2\log x} > 3Cx\, e^{-c\sqrt{\log x}},
$$

which simplifies to

$$\frac{e^{\frac{c}{2}\sqrt{\log x}}}{6C\log x} > 1 \quad\Longleftrightarrow\qua
d \frac{c}{2}\sqrt{\log x} > \log(6C) + \log\log x.$$

The left side grows as $\sqrt{\log x}$ while the right side grows as $\log\log x
$, so this inequality holds for all sufficiently large $x$. Therefore $\pi(x+h)
- \pi(x) > 0$, proving the Claim. $\square$

**Applying the claim to prime gaps.** Setting $x = p_n$ in the claim, for all su
fficiently large $n$,

$$p_{n+1} \leq p_n + p_n\, e^{-\frac{c}{2}\sqrt{\log p_n}},$$

so

$$g_n = p_{n+1} - p_n \leq p_n\, e^{-\frac{c}{2}\sqrt{\log p_n}}.$$

**Converting to a bound on $g_n/n$.** By the Prime Number Theorem, $p_n \sim n\l
og n$, hence $\log p_n \sim \log n$. Therefore

$$g_n \leq p_n\, e^{-\frac{c}{2}\sqrt{\log p_n}} \sim n\log n \cdot e^{-\frac{c}
{2}\sqrt{\log n}}.$$

Now observe that $e^{-\frac{c}{2}\sqrt{\log n}} = o(1/\log n)$, since

$$\frac{c}{2}\sqrt{\log n} - \log\log n \to +\infty.$$

Therefore

$$g_n \leq n\log n \cdot o\!\left(\frac{1}{\log n}\right) = o(n),$$

which gives

$$\frac{g_n}{n} = \frac{p_{n+1} - p_n}{n} \to 0 \quad\text{as } n \to \infty.$$

**Conclusion.** The sequence $\left\{\dfrac{p_{n+1}-p_n}{n}\right\}$ converges t
o $0$, and is therefore bounded. $\blacksquare$
