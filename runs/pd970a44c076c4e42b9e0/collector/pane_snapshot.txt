## Proof

**Part (a).** For any $x \in \mathbb{R}$, since translation is a bijection on $\
mathbb{R}$, we have $x + (\mathbb{R}\setminus E) = \mathbb{R}\setminus(x + E)$.
For any sets $A, B \subseteq \mathbb{R}$, the identity
$$(\mathbb{R}\setminus A)\,\Delta\,(\mathbb{R}\setminus B) = A\,\Delta\,B$$
holds, because $y$ belongs to exactly one of $\mathbb{R}\setminus A$, $\mathbb{R
}\setminus B$ if and only if $y$ belongs to exactly one of $A$, $B$ (complementi
ng both sets flips membership in each but preserves the XOR). Therefore
$$(\mathbb{R}\setminus E)\,\Delta\,\bigl(x + (\mathbb{R}\setminus E)\bigr) = (\m
athbb{R}\setminus E)\,\Delta\,\bigl(\mathbb{R}\setminus(x+E)\bigr) = E\,\Delta\,
(x+E).$$
By hypothesis $\lambda(E\,\Delta\,(x+E))=0$, so $\lambda\bigl((\mathbb{R}\setmin
us E)\,\Delta\,(x+(\mathbb{R}\setminus E))\bigr)=0$ for all $x$. $\quad\square$

**Part (b).** Let $f = \mathbf{1}_E$. The hypothesis $\lambda(E\,\Delta\,(x+E))=
0$ for every $x$ means
$$f(s) = f(s - x) \quad\text{for a.e. } s,\text{ for every } x \in \mathbb{R}. \
tag{$\ast$}$$

**Step 1 — Convolution is constant.** Let $\varphi \in L^1(\mathbb{R})$ have com
pact support, and set $g = f * \varphi$, i.e. $g(x) = \int_{\mathbb{R}} f(t)\,\v
arphi(x-t)\,dt$ (well-defined since $\varphi$ has compact support and $f$ is bou
nded). For any $h \in \mathbb{R}$, substituting $t = s + h$:
$$g(x+h) = \int f(s+h)\,\varphi(x-s)\,ds = \int f(s)\,\varphi(x-s)\,ds = g(x),$$
where we used $(\ast)$ with $x = -h$ to replace $f(s+h)$ by $f(s)$ a.e. Hence $g
$ is constant.

**Step 2 — Measure of $E$ in intervals of length $\alpha$.** Take $\varphi = \ma
thbf{1}_{[0,\alpha]}$ for $\alpha > 0$. Then
$$g(x) = \int_E \mathbf{1}_{[0,\alpha]}(x-t)\,dt = \lambda\bigl(E \cap [x-\alpha
,\, x]\bigr),$$
which is constant in $x$ by Step 1; denote this constant by $d(\alpha)$.

**Step 3 — $d$ is linear.** For $\alpha, \beta > 0$:
$$d(\alpha+\beta) = \lambda\bigl(E\cap[x-\alpha-\beta,\, x]\bigr) = \lambda\bigl
(E\cap[x-\alpha-\beta,\, x-\alpha]\bigr) + \lambda\bigl(E\cap[x-\alpha,\, x]\big
r).$$
The first term equals $d(\beta)$ (by constancy, evaluated at $y = x - \alpha$) a
nd the second equals $d(\alpha)$, so $d(\alpha+\beta) = d(\alpha) + d(\beta)$. S
ince $d \geq 0$ and $d$ is non-decreasing, additivity forces $d(\alpha) = \alpha
\, d(1)$. Set $c := d(1)$, so
$$\lambda\bigl(E \cap [x,\, x+\alpha]\bigr) = \alpha\, c \quad\text{for all } x
\in \mathbb{R},\; \alpha > 0. \tag{$\ast\ast$}$$

**Step 4 — $f$ is a.e. constant.** Equation $(\ast\ast)$ says $\int_x^{x+\alpha}
 f(t)\,dt = \alpha c$ for all $x$ and $\alpha > 0$. By the Lebesgue differentiat
ion theorem, for a.e. $x$:
$$f(x) = \lim_{\alpha \to 0^+} \frac{1}{\alpha}\int_x^{x+\alpha} f(t)\,dt = c.$$
Thus $f = c$ a.e. on $\mathbb{R}$.

**Step 5 — Conclusion.** Since $f = \mathbf{1}_E$ takes values in $\{0, 1\}$ a.e

- If $c = 0$: $f = 0$ a.e., so $\lambda(E) = 0$, and $\lambda(E)\cdot\lambda(\ma
thbb{R}\setminus E) = 0$.
- If $c = 1$: $f = 1$ a.e., so $\lambda(\mathbb{R}\setminus E) = 0$, and $\lambd
a(E)\cdot\lambda(\mathbb{R}\setminus E) = 0$.
