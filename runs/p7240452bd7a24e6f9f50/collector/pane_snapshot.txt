## Proof

**Claim.** The minimum possible value of $\sum_{n=1}^{100} g(n)$ is $\boxed{0}$.

**Lower bound.** Since $g(n)\ge 0$ for every $n$, we have $\sum_{n=1}^{100} g(n)
\ge 0$. So it suffices to exhibit an uncountable antichain $E$ of nonempty subse
ts of $\mathbb N$ with $g(n)=0$ for every $n\in\{1,2,\dots,100\}$.

**Construction.** Let $T=\mathbb N\setminus\{1,2,\dots,100\}=\{101,102,103,\dots
\}$, and partition $T$ into disjoint pairs
$$P_k=\{101+2k,\;102+2k\},\qquad k=0,1,2,\dots$$
For each binary sequence $\varepsilon=(\varepsilon_0,\varepsilon_1,\varepsilon_2
,\dots)\in\{0,1\}^{\mathbb N}$, define
$$F_\varepsilon=\{\,101+2k+\varepsilon_k : k=0,1,2,\dots\,\},$$
i.e. $F_\varepsilon$ contains exactly one element from each pair $P_k$ (namely $
101+2k$ if $\varepsilon_k=0$, and $102+2k$ if $\varepsilon_k=1$).

Set $E=\{F_\varepsilon:\varepsilon\in\{0,1\}^{\mathbb N}\}$.

*Nonempty.* Each $F_\varepsilon$ is infinite, hence nonempty.

*Uncountable.* The map $\varepsilon\mapsto F_\varepsilon$ is injective (distinct
 sequences differ at some coordinate $k$, producing different elements from $P_k
$), so $|E|=|\{0,1\}^{\mathbb N}|=2^{\aleph_0}$, which is uncountable.

*Antichain.* Let $\varepsilon\ne\varepsilon'$. Pick a coordinate $k$ with $\vare
psilon_k\ne\varepsilon'_k$. Then $F_\varepsilon$ contains $101+2k+\varepsilon_k$
 and $F_{\varepsilon'}$ contains $101+2k+\varepsilon'_k$; these are the two dist
inct elements of $P_k$. Since the pairs are disjoint, the element $101+2k+\varep
silon_k\in F_\varepsilon$ belongs to no other pair and hence is **not** in $F_{\
varepsilon'}$; likewise $101+2k+\varepsilon'_k\notin F_\varepsilon$. Therefore $
F_\varepsilon\not\subseteq F_{\varepsilon'}$ and $F_{\varepsilon'}\not\subseteq
F_\varepsilon$. Thus no member of $E$ is strictly contained in another.

*Avoids $\{1,\dots,100\}$.* Every $F_\varepsilon\subseteq T=\{101,102,\dots\}$,
so no $F_\varepsilon$ contains any integer $n\in\{1,\dots,100\}$. Consequently
$$g(n)=\bigl|\{F_\varepsilon\in E:n\in F_\varepsilon\}\bigr|=0\qquad\text{for al
l }n\in\{1,\dots,100\}.$$

**Conclusion.** For this $E$,
$$\sum_{n=1}^{100} g(n)=\sum_{n=1}^{100}0=0.$$
Combined with the trivial lower bound $\sum_{n=1}^{100}g(n)\ge 0$, the minimum p
ossible value is

$$\boxed{0}.$$
