Looking at this problem, I need to find positive integers $n$ where non-zero int
egers $x, y, z$ exist with $x+y+z=0$ and $\frac{1}{x}+\frac{1}{y}+\frac{1}{z}=\f
rac{1}{n}$.

## Setting Up the Equation

Since $z = -(x+y)$, substituting:

$$\frac{1}{n} = \frac{1}{x}+\frac{1}{y}-\frac{1}{x+y} = \frac{x^2+xy+y^2}{xy(x+y
)}$$

So $n = \frac{xy(x+y)}{x^2+xy+y^2}$.

## Reduction to Coprime Form

Let $d = \gcd(x,y)$, $x = da'$, $y = db'$ with $\gcd(a',b')=1$. Then:

$$n = d \cdot \frac{a'b'(a'+b')}{a'^2+a'b'+b'^2}$$

**Key coprimality fact:** I claim $\gcd(a'^2+a'b'+b'^2,\; a'b'(a'+b')) = 1$.

- $\gcd(a', a'^2+a'b'+b'^2) = \gcd(a', b'^2) = 1$ (since $\gcd(a',b')=1$), and s
imilarly for $b'$. So $\gcd(a'b', a'^2+a'b'+b'^2)=1$.
- $a'^2+a'b'+b'^2 = (a'+b')^2 - a'b'$, so $\gcd(a'^2+a'b'+b'^2, a'+b') = \gcd(a'
b', a'+b') = 1$ (since any prime dividing both $a'$ and $a'+b'$ would divide $b'
$).

Therefore $a'^2+a'b'+b'^2 \mid d$. Writing $d = k(a'^2+a'b'+b'^2)$ for positive
integer $k$:

$$n = k \cdot a'b'(a'+b')$$

## Handling Opposite Signs

When $x, y$ have opposite signs (say $x>0, y=-c<0$ with $c>x$), a parallel analy
sis with $a'=x/d, c'=c/d$ gives $n = k \cdot a'c'(c'-a')$ with $\gcd(a',c')=1, c
'>a'$.

## All Base Values Are Even

**Case 1** ($a'b'(a'+b')$): If both $a',b'$ are odd, $a'+b'$ is even. If one is
even, the product is even. Always even.

**Case 2** ($a'c'(c'-a')$): If both odd, $c'-a'$ is even. If one even, product i
s even. Always even.

Since every base value is even, **$n$ must be even**. No odd $n$ is achievable.

## All Even $n \geq 2$ Are Achievable

The smallest base value is $1 \cdot 1 \cdot 2 = 2$ (from $a'=b'=1$). With $k$ ar
bitrary, this gives $n = 2k$ for every $k \geq 1$. So every even integer $n \geq
 2$ is achievable.

## Verification of Small Cases

- **$n=2$**: $x=y=3, z=-6$. Check: $\frac{1}{3}+\frac{1}{3}-\frac{1}{6} = \frac{
3}{6} = \frac{1}{2}$. ✓
- **$n=4$**: $x=y=6, z=-12$. Check: $\frac{1}{6}+\frac{1}{6}-\frac{1}{12} = \fra
c{3}{12} = \frac{1}{4}$. ✓
- **$n=6$**: $x=y=9, z=-18$. Check: $\frac{1}{9}+\frac{1}{9}-\frac{1}{18} = \fra
c{3}{18} = \frac{1}{6}$. ✓

(Odd values $n=1,3,5$ are impossible since $n$ must be even.)

## Conclusion

The three smallest possible values of $n$ are $\boxed{2, 4, 6}$, and their sum i
s:

$$2 + 4 + 6 = 12$$
