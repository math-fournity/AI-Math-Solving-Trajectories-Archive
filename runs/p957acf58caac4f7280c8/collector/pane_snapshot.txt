## Analysis

The problem as literally stated — "Given $x, y, z \geqslant 0$, find the maximum
 value of $x^2y + y^2z + z^2x$" — has **no finite maximum**, because there is no
 constraint bounding the variables. For instance, taking $x = y = t,\ z = 0$ giv
es

$$x^2y + y^2z + z^2x = t^3 + 0 + 0 = t^3 \xrightarrow[t\to\infty]{} +\infty.$$

So the expression is unbounded above.

However, this is the well-known competition problem, and the standard formulatio
n includes the constraint $x + y + z = 1$. I will solve that version, since the
problem clearly expects a finite answer.

---

## Problem (with the standard constraint $x+y+z=1$)

Given $x, y, z \geqslant 0$ with $x + y + z = 1$, find the maximum of $f(x,y,z)
= x^2y + y^2z + z^2x$.

### Boundary analysis

On each face of the simplex one variable is $0$; by the cyclic symmetry of the b
oundary cases it suffices to check one, say $z = 0$:

$$f = x^2 y,\qquad x + y = 1,\ y = 1 - x,\ 0 \le x \le 1.$$

So $g(x) = x^2(1-x)$. Then $g'(x) = 2x(1-x) - x^2 = x(2 - 3x)$, giving the inter
ior critical point $x = \tfrac{2}{3}$ (and $x=0$, a minimum). Hence

$$g\!\left(\tfrac{2}{3}\right) = \tfrac{4}{9}\cdot\tfrac{1}{3} = \tfrac{4}{27}.$
$

By cyclic symmetry, the faces $x=0$ and $y=0$ give the same value $\tfrac{4}{27}
$ (at $(0,\tfrac{2}{3},\tfrac{1}{3})$ and $(\tfrac{1}{3},0,\tfrac{2}{3})$ respec
tively). The vertices give $f = 0$.

### Interior critical points (Lagrange multipliers)

With $g = x+y+z-1$, the stationarity conditions $\nabla f = \lambda \nabla g$ ar
e

$$2xy + z^2 = \lambda,\qquad x^2 + 2yz = \lambda,\qquad y^2 + 2zx = \lambda.$$

Equating the first two:

$$2xy + z^2 = x^2 + 2yz \;\Longrightarrow\; 2y(x-z) = (x-z)(x+z) \;\Longrightarr
ow\; (x-z)\bigl(2y - x - z\bigr) = 0.$$

**Case A: $x = z$.** Equating the second and third equations with $x = z$:

$$x^2 + 2yx = y^2 + 2x^2 \;\Longrightarrow\; (y - x)^2 = 0 \;\Longrightarrow\; y
 = x.$$

So $x = y = z = \tfrac{1}{3}$, giving $f = 3\cdot\tfrac{1}{9}\cdot\tfrac{1}{3} =
 \tfrac{1}{9}$.

**Case B: $2y = x + z$.** Together with $x + y + z = 1$ this gives $y = \tfrac{1
}{3}$, $x + z = \tfrac{2}{3}$. Substituting into the equality of the first and t
hird equations:

$$\tfrac{2x}{3} + z^2 = \tfrac{1}{9} + 2zx,\qquad x = \tfrac{2}{3} - z.$$

This reduces to $9z^2 - 6z + 1 = (3z-1)^2 = 0$, so $z = \tfrac{1}{3}$ and again
$x = y = z = \tfrac{1}{3}$.

Thus the **only** interior critical point is the symmetric one, with value $\tfr
ac{1}{9} \approx 0.111$.

### Comparison

| Region | Critical point | Value |
|---|---|---|
| Interior | $(\tfrac13,\tfrac13,\tfrac13)$ | $\tfrac{1}{9} \approx 0.111$ |
| Boundary | $(\tfrac23,\tfrac13,0)$ and cyclic | $\tfrac{4}{27} \approx 0.148$
|
| Vertices | $(1,0,0)$ etc. | $0$ |

Since $\tfrac{4}{27} > \tfrac{1}{9} > 0$, the global maximum on the simplex is a
ttained on the boundary.

### Conclusion

$$\boxed{\max_{x+y+z=1,\ x,y,z\ge 0}\bigl(x^2y + y^2z + z^2x\bigr) = \dfrac{4}{2
7}},$$

attained at $(x,y,z) = \bigl(\tfrac{2}{3},\tfrac{1}{3},0\bigr)$ and its cyclic p
ermutations $\bigl(0,\tfrac{2}{3},\tfrac{1}{3}\bigr)$, $\bigl(\tfrac{1}{3},0,\tf
rac{2}{3}\bigr)$.

*Remark.* As the problem was literally written (with no constraint on $x+y+z$),
the expression is unbounded above; the answer $\tfrac{4}{27}$ corresponds to the
 standard formulation with $x+y+z=1$.
