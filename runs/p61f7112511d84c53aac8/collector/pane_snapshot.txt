## Proof

We compute $\mathbb{E}\!\left[\left(\int_{0}^{\infty} f(t)\,dW_t\right)^{\!2}\ri
ght]$ via Itô isometry, which requires verifying that $f$ is a square-integrable
 adapted process.

**Adaptedness.** On $[2,3)$, $f(t)=W_2-W_1$ is $\mathcal{F}_2$-measurable, hence
 $\mathcal{F}_t$-measurable for every $t\ge 2$. On $[3,5)$, $f(t)=W_3-W_1$ is $\
mathcal{F}_3$-measurable, hence $\mathcal{F}_t$-measurable for every $t\ge 3$. O
utside $[2,5)$, $f(t)=0$. Thus $f$ is progressively measurable and adapted.

**Square-integrability.** $f$ is bounded in $L^2(\Omega\times[0,\infty))$ since
it takes only finitely many Gaussian-distributed values over bounded intervals,
so $\mathbb{E}\!\int_0^\infty f(t)^2\,dt<\infty$.

**Applying Itô isometry:**

$$\mathbb{E}\!\left[\left(\int_{0}^{\infty} f(t)\,dW_t\right)^{\!2}\right] = \ma
thbb{E}\!\left[\int_{0}^{\infty} f(t)^2\,dt\right] = \int_{0}^{\infty} \mathbb{E
}\!\left[f(t)^2\right] dt,$$

where the interchange of expectation and integral is justified by Fubini–Tonelli
 (integrand non-negative).

**Interval $[2,3)$:** Here $f(t)=W_2-W_1$, independent of $t$, so

$$\mathbb{E}[f(t)^2] = \mathbb{E}[(W_2-W_1)^2] = \operatorname{Var}(W_2-W_1) = 2
-1 = 1,$$

using independent increments and $\operatorname{Var}(W_s-W_r)=|s-r|$. The interv
al has length $1$, contributing

$$\int_{2}^{3} 1\,dt = 1.$$

**Interval $[3,5)$:** Here $f(t)=W_3-W_1$, independent of $t$, so

$$\mathbb{E}[f(t)^2] = \mathbb{E}[(W_3-W_1)^2] = \operatorname{Var}(W_3-W_1) = 3
-1 = 2.$$

The interval has length $2$, contributing

$$\int_{3}^{5} 2\,dt = 2\cdot 2 = 4.$$

**Outside $[2,5)$:** $f(t)=0$, contributing $0$.

**Total:**

$$\mathbb{E}\!\left[\left(\int_{0}^{\infty} f(t)\,dW_t\right)^{\!2}\right] = 1 +
 4 = \boxed{5}.$$
