## Solution

We analyze $P(x,y,z) = z(x^2 - zy^2 - 1)^2 + z = z\bigl[(x^2 - zy^2 - 1)^2 + 1\b
igr]$.

Setting $k = x^2 - zy^2 - 1$, we get $P = z(k^2 + 1)$, where $k$ ranges over all
 integers achievable as $x^2 - zy^2 - 1$ for positive integers $x, y, z$.

For each $n \in \{1,\dots,10\}$, we need $z \mid n$ and $k^2 + 1 = n/z$ for some
 valid $k$.

**$n = 1$:** $z=1, k=0$ requires $x^2 - y^2 = 1$, i.e., $(x-y)(x+y)=1$, giving $
y=0$. No solution. $\notin S$.

**$n = 2$:** $z=1, k=-1$: $x^2 - y^2 = 0 \Rightarrow x=y$. Take $(1,1,1)$: $P =
1(1-1-1)^2+1 = 2$. ✓ $\in S$.

**$n = 3$:** $z=3, k=0$: $x^2 - 3y^2 = 1$ (Pell). $(2,1,3)$: $P = 3(4-3-1)^2+3 =
 3$. ✓ $\in S$.

**$n = 4$:** $z=2, k=1$: $x^2 - 2y^2 = 2$. $(2,1,2)$: $P = 2(4-2-1)^2+2 = 4$. ✓
$\in S$.

**$n = 5$:** $z=1, k=2$: $x^2 - y^2 = 3$, $(x-y)(x+y)=3 \Rightarrow x=2,y=1$. $(
2,1,1)$: $P = 1(4-1-1)^2+1 = 5$. ✓ $\in S$.

**$n = 6$:** $z=6, k=0$: $x^2 - 6y^2 = 1$ (Pell). $(5,2,6)$: $P = 6(25-24-1)^2+6
 = 6$. ✓ $\in S$.

**$n = 7$:** $z=7, k=0$: $x^2 - 7y^2 = 1$ (Pell). $(8,3,7)$: $P = 7(64-63-1)^2+7
 = 7$. ✓ $\in S$.

**$n = 8$:** $z=4, k=-1$: $x^2 - 4y^2 = 0 \Rightarrow x=2y$. $(2,1,4)$: $P = 4(4
-4-1)^2+4 = 8$. ✓ $\in S$.

**$n = 9$:** $z \in \{1,3,9\}$: $k^2 \in \{8,2\}$ (impossible) or $k=0$ with $x^
2 - 9y^2 = 1 \Rightarrow (x-3y)(x+3y)=1 \Rightarrow y=0$. No solution. $\notin S
$.

**$n = 10$:** $z=2, k=-2$: $x^2 - 2y^2 = -1$ (Pell-type). $(1,1,2)$: $P = 2(1-2-
1)^2+2 = 10$. ✓ $\in S$.

**Summary:** $S \cap \{1,\dots,10\} = \{2, 3, 4, 5, 6, 7, 8, 10\}$.
