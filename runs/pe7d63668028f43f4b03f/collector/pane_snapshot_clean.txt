## Solution

**Substitution.** Let $x = f(t)$, so $t = f^{-1}(x)$ and $dx = f'(t)\,dt = (3t^2
 - 2t + 1)\,dt$. The integral becomes

$$I_n = \int_{t_n}^{t_{2n}} \frac{3t^2 - 2t + 1}{t^3 + t}\,dt, \qquad t_n := f^{
-1}(n).$$

**Partial fractions.** Since $t^3 + t = t(t^2+1)$,

$$\frac{3t^2-2t+1}{t(t^2+1)} = \frac{1}{t} + \frac{2t-2}{t^2+1}.$$

An antiderivative is

$$\ln t + \ln(t^2+1) - 2\arctan t = \ln\!\bigl(t(t^2+1)\bigr) - 2\arctan t.$$

Hence

$$I_n = \ln\frac{t_{2n}(t_{2n}^2+1)}{t_n(t_n^2+1)} \;-\; 2\arctan(t_{2n}) + 2\ar
ctan(t_n).$$

**Asymptotics of $t_n$.** From $t_n^3 - t_n^2 + t_n = n$ we get $t_n^3 = n + O(n
^{2/3})$, so $t_n = n^{1/3} + O(1)$, in particular $t_n \sim n^{1/3}$ and $t_n^2
 \sim n^{2/3}$.

**Logarithmic term.** Write

$$\ln\frac{t_{2n}(t_{2n}^2+1)}{t_n(t_n^2+1)} = \ln\frac{t_{2n}}{t_n} + \ln\frac{
t_{2n}^2+1}{t_n^2+1}.$$

Since $t_{2n}/t_n \to 2^{1/3}$ and $(t_{2n}^2+1)/(t_n^2+1) \to 2^{2/3}$ (the "$+
1$" is negligible compared to $t^2 \sim n^{2/3}$), this term tends to

$$\tfrac{1}{3}\ln 2 + \tfrac{2}{3}\ln 2 = \ln 2.$$

**Arctangent term.** Using $\arctan t = \frac{\pi}{2} - \frac{1}{t} + O(t^{-3})$
 as $t\to\infty$,

$$2\bigl(\arctan(t_n) - \arctan(t_{2n})\bigr) = 2\!\left(-\frac{1}{t_n} + \frac{
1}{t_{2n}} + O(t_n^{-3})\right) = O(n^{-1/3}) \to 0.$$

**Conclusion.**

$$\lim_{n\to\infty} I_n = \ln 2 + 0 = \boxed{\ln 2}.$$
