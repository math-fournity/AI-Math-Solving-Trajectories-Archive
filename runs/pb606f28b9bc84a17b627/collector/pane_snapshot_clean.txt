Looking at this problem, I need to find the smallest λ such that for any n ≥ 2 a
nd any x₁,...,xₙ ∈ [0,1], there exist ε₁,...,εₙ ∈ {0,1} with all subarray sums o
f (εₖ − xₖ) bounded by λ.

**Key reformulation.** Define partial sums S₀ = 0, Sₖ = Σᵢ₌₁ᵏ (εᵢ − xᵢ). The sub
array sum from i to j is Sⱼ − Sᵢ₋₁. So the condition becomes: **the range of {S₀
, S₁, ..., Sₙ} is at most λ.**

---

## Upper Bound: λ = 1 suffices

**Greedy algorithm.** Start with S₀ = 0. At step k, given Sₖ₋₁ ∈ [0,1]:

- If Sₖ₋₁ ≤ xₖ: set εₖ = 1, so Sₖ = Sₖ₋₁ + (1 − xₖ).
- If Sₖ₋₁ > xₖ: set εₖ = 0, so Sₖ = Sₖ₋₁ − xₖ.

**Invariant Sₖ ∈ [0,1]:**

- *Case 1* (Sₖ₋₁ ≤ xₖ): Sₖ = Sₖ₋₁ + 1 − xₖ ≤ xₖ + 1 − xₖ = 1, and Sₖ ≥ 0 since b
oth terms are ≥ 0. ✓
- *Case 2* (Sₖ₋₁ > xₖ): Sₖ = Sₖ₋₁ − xₖ > 0, and Sₖ ≤ 1 since Sₖ₋₁ ≤ 1 and xₖ ≥ 0
. ✓

By induction, all partial sums lie in [0,1], so the range is at most 1. Hence ev
ery subarray sum satisfies |Sⱼ − Sᵢ₋₁| ≤ 1.

---

## Lower Bound: λ < 1 does not suffice

For any n ≥ 2, set x₁ = ⋯ = xₙ = 1/n. Let m = Σεₖ, so Sₙ = m − 1.

- **m = 0:** Sₙ = −1, range ≥ 1.
- **m ≥ 2:** Sₙ = m − 1 ≥ 1, range ≥ 1.
- **m = 1:** Say εₚ = 1. Then:
  - For k < p: Sₖ = −k/n (decreasing from 0 to −(p−1)/n).
  - For k ≥ p: Sₖ = 1 − k/n (decreasing from 1 − p/n to 0).

  Maximum = 1 − p/n, minimum = −(p−1)/n. The range is:

  $$\left(1 - \frac{p}{n}\right) - \left(-\frac{p-1}{n}\right) = 1 - \frac{p}{n}
 + \frac{p-1}{n} = 1 - \frac{1}{n} = \frac{n-1}{n}.$$

  This holds for **every** position p, so the minimum achievable range with m =
1 is exactly (n−1)/n.

Therefore the best achievable range for this configuration is (n−1)/n. For any λ
 < 1, choose n > 1/(1−λ); then (n−1)/n = 1 − 1/n > λ, and no choice of ε achieve
s range ≤ λ.

---

## Conclusion

- λ = 1 is **achievable** (greedy upper bound).
- Every λ < 1 **fails** for sufficiently large n with all xₖ = 1/n.

The smallest real number λ is:

$$\boxed{\lambda = 1}$$
