# Problem

A high-security data vault requires a specific "multi-key" protocol for its digital safety deposit boxes to remain active. In this vault, there are $n$ distinct electronic security tokens, each programmed with a unique real-number frequency.

According to the vault’s safety protocol, where $k \geq 2$ is a fixed integer, the system is only stable if every single token in the set has a frequency exactly equal to the sum of the frequencies of $k$ other distinct tokens from that same set.

The lead architect needs to determine the minimum number of tokens, $n$ (where $n \geq k+1$), required to configure such a self-sustaining set. Find the smallest integer $n$ for which it is mathematically possible to have $n$ distinct frequencies such that each is the sum of $k$ others.
