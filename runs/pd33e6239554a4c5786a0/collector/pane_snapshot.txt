## Proof

**Setup.** Define $F(a,b,c) = a^2+b^2+c^2 - (k+1)(a+b+c) + 3k$. We need $\min_{a
bc=1,\, a,b,c>0} F \geq 0$.

Note $F(1,1,1) = 3 - 3(k+1) + 3k = 0$ for **all** $k$. So equality always holds
at $(1,1,1)$, and we need this to be a global minimum with $F \geq 0$ everywhere
.

**Step 1: Reduction to two equal variables (uvw).** Write $p = a+b+c$, $q = ab+b
c+ca$, $r = abc = 1$. Then
$$F = p^2 - 2q - (k+1)p + 3k.$$
For fixed $p$, $F$ is **linear and decreasing** in $q$ (coefficient $-2 < 0$). S
o $F$ is minimized when $q$ is maximized. By the standard uvw principle, for fix
ed $p$ and $r=1$, the extremal values of $q$ are attained when two of $a,b,c$ ar
e equal. Since $F \to +\infty$ as any variable $\to 0^+$ or $\to +\infty$, the g
lobal minimum is attained in the interior, hence at a point with two equal varia
bles.

WLOG set $a = b = t$, $c = 1/t^2$ for $t > 0$.

**Step 2: One-variable reduction.** Define
$$g(t) = 2t^2 + t^{-4} - (k+1)(2t + t^{-2}) + 3k.$$
We need $g(t) \geq 0$ for all $t > 0$. Note $g(1) = 0$ and $g'(1) = 0$ for all $
k$ (direct computation). The second derivative is $g''(1) = 18 - 6k$, so $(1,1,1
)$ is a local minimum only when $k \leq 3$.

**Step 3: Finding the critical $k$.** The largest admissible $k$ occurs when $g$
 just touches $0$ at some $t_0 \neq 1$, i.e., $g(t_0) = 0$ and $g'(t_0) = 0$ sim
ultaneously.

From $g'(t_0) = 0$: $4t_0 - 4t_0^{-5} - 2(k+1) + 2(k+1)t_0^{-3} = 0$, giving
$$k+1 = \frac{2(t_0^6 - 1)}{t_0^2(t_0^3 - 1)} = \frac{2(t_0^3+1)}{t_0^2} = 2t_0
+ \frac{2}{t_0^2}.$$

Substituting into $g(t_0) = 0$ and simplifying (multiply through by $t_0^4$) yie
lds:
$$2t_0^6 - 6t_0^5 + 3t_0^4 + 6t_0^3 - 6t_0^2 + 1 = 0.$$
This factors as
$$(t_0 - 1)^3(2t_0^3 - 3t_0 - 1) = 0.$$
Since $t_0 \neq 1$, we solve $2t_0^3 - 3t_0 - 1 = 0$, which factors as $(t_0+1)(
2t_0^2 - 2t_0 - 1) = 0$. The unique positive root $\neq 1$ is
$$t_0 = \frac{1+\sqrt{3}}{2}.$$

**Step 4: Computing $k$.** With $u = \frac{1+\sqrt{3}}{2}$:
- $2u = 1 + \sqrt{3}$
- $u^2 = \frac{2+\sqrt{3}}{2}$, so $\frac{2}{u^2} = \frac{4}{2+\sqrt{3}} = 4(2-\
sqrt{3}) = 8 - 4\sqrt{3}$

Therefore:
$$k = 2u + \frac{2}{u^2} - 1 = (1+\sqrt{3}) + (8-4\sqrt{3}) - 1 = \boxed{8 - 3\s
qrt{3}}.$$

**Step 5: Verification that $k = 8-3\sqrt{3}$ works.** Set $s = \sqrt{3}$, so $k
 = 8-3s$ and $k+1 = 9-3s$. Define $h(t) = t^4 g(t)$:
$$h(t) = 2t^6 - 2(9-3s)t^5 + 3(8-3s)t^4 - (9-3s)t^2 + 1.$$
We know $h$ has double roots at $t = 1$ and $t = u = \frac{1+s}{2}$. Factoring:
$$h(t) = 2(t-1)^2\!\left(t - \tfrac{1+s}{2}\right)^{\!2}\!\cdot\! Q(t),$$
where $Q(t) = t^2 + (4\sqrt{3}-6)t + (2-\sqrt{3})$.

The discriminant of $Q$ is:
$$(4\sqrt{3}-6)^2 - 4(2-\sqrt{3}) = 84 - 48\sqrt{3} - 8 + 4\sqrt{3} = 76 - 44\sq
rt{3}.$$
Since $76^2 = 5776 < 5808 = 44^2 \cdot 3$, we have $76 < 44\sqrt{3}$, so the dis
criminant is **negative**. With positive leading coefficient, $Q(t) > 0$ for all
 real $t$.

Therefore $h(t) = 2\underbrace{(t-1)^2}_{\geq 0}\underbrace{(t-u)^2}_{\geq 0}\un
derbrace{Q(t)}_{> 0} \geq 0$ for all $t$, and since $h(t) = t^4 g(t)$ with $t^4
> 0$, we get $g(t) \geq 0$ for all $t > 0$. Equality holds at $t = 1$ (i.e., $a=
b=c=1$) and $t = \frac{1+\sqrt{3}}{2}$.

**Step 6: $k$ cannot be larger.** At $t = u$, $\frac{\partial g}{\partial k}\big
|_{t=u} = -(2u + u^{-2}) + 3 = -(5-\sqrt{3}) + 3 = \sqrt{3} - 2 < 0$. So increas
ing $k$ beyond $8-3\sqrt{3}$ makes $g(u) < 0$, violating the inequality. Hence n
o larger $k$ works.

**Conclusion.** The largest value is $k = 8 - 3\sqrt{3}$.
