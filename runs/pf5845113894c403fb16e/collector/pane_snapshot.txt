## Solution

We evaluate $\displaystyle I = \int_{|z|=1}\frac{\log z}{z}\,dz$, where the cont
our is the unit circle traversed counterclockwise.

### Branch selection

The function $\log z$ is multi-valued with a branch point at the origin, which l
ies inside the contour. We must choose a branch. Take the branch cut along the *
*positive real axis**, with
$$\log z = \ln|z| + i\arg z, \qquad \arg z \in (0,2\pi).$$
On $|z|=1$ we have $|z|=1$, so $\log z = i\arg z$. Parametrizing $z = e^{i\theta
}$ with $\theta$ increasing from $0^+$ to $2\pi^-$ (counterclockwise, starting j
ust above the cut), we get $\log z = i\theta$, which is **continuous** along the
 entire open path.

### Direct computation

With $z = e^{i\theta}$, $dz = ie^{i\theta}\,d\theta$, and $\frac{1}{z} = e^{-i\t
heta}$:

$$I = \int_{0}^{2\pi} \frac{i\theta}{e^{i\theta}}\cdot ie^{i\theta}\,d\theta = \
int_{0}^{2\pi}(i\theta)(i)\,d\theta = -\int_{0}^{2\pi}\theta\,d\theta = -\left[\
frac{\theta^{2}}{2}\right]_{0}^{2\pi} = -\frac{(2\pi)^{2}}{2} = -2\pi^{2}.$$

### Verification via antiderivative

Observe that $\frac{d}{dz}\!\left(\frac{(\log z)^{2}}{2}\right) = \frac{\log z}{
z}$. Hence the integral equals the change in the antiderivative along the path:

- At the start ($\theta \to 0^{+}$): $\log z \to 0$, so $\frac{(\log z)^{2}}{2}
\to 0$.
- At the end ($\theta \to 2\pi^{-}$): $\log z \to 2\pi i$, so $\frac{(\log z)^{2
}}{2} \to \frac{(2\pi i)^{2}}{2} = \frac{-4\pi^{2}}{2} = -2\pi^{2}$.

Therefore
$$I = \frac{(\log z)^{2}}{2}\Bigg|_{\text{start}}^{\text{end}} = -2\pi^{2} - 0 =
 -2\pi^{2}.$$

The nonzero value arises precisely because $\log z$ is multi-valued: after one f
ull counterclockwise loop around the branch point, the logarithm does not return
 to its starting value but increases by $2\pi i$.

### Result

$$\boxed{\int_{|z|=1}\frac{\log z}{z}\,dz = -2\pi^{2}.}$$
