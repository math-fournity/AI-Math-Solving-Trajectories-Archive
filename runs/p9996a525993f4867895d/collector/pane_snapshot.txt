## Proof

**Setup.** Let $c = \cos\theta$ and $c' = \cos\theta'$. Since $\theta, \theta' \
in [0,\pi]$ are distinct and $\cos$ is injective on $[0,\pi]$, we have $c \neq c
'$. Both satisfy:
$$4t^3 - 3t = \frac{1}{v}, \quad \text{i.e., } 4vt^3 - 3vt - 1 = 0.$$

The resonance equation $w + x\cos\theta + y\cos(2\theta) = z\cos\theta'$ with $z
 \neq 0$ becomes:
$$z\,c' = 2y\,c^2 + x\,c + (w - y).$$

This requires $c' \in \mathbb{Q}(c)$, since $c'$ must be expressible as a quadra
tic polynomial in $c$ with rational coefficients (clearing denominators gives in
tegers $w,x,y,z$).

**Irreducibility for $v > 1$.** By the Rational Root Theorem, any rational root
of $4vt^3 - 3vt - 1 = 0$ has the form $\pm 1/q$ with $q \mid 4v$. Substituting $
t = 1/q$ gives $v(4 - 3q^2) = q^3$, which requires $q = 1$ and $v = 1$. Substitu
ting $t = -1/q$ gives $v(3q^2 - 4) = q^3$; a careful divisibility analysis (spli
tting by $q \bmod 4$) shows this also yields only $v = 1$. So for $v > 1$, the c
ubic is **irreducible over $\mathbb{Q}$**, with $[\mathbb{Q}(c):\mathbb{Q}] = 3$
.

**Galois group criterion.** The cubic $t^3 - \frac{3}{4}t - \frac{1}{4v} = 0$ ha
s discriminant:
$$\Delta = -4\!\left(-\tfrac{3}{4}\right)^3 - 27\!\left(-\tfrac{1}{4v}\right)^2
= \frac{27}{16} - \frac{27}{16v^2} = \frac{27(v^2-1)}{16v^2}.$$

For $v > 1$, $\Delta > 0$ (three distinct real roots). The Galois group is $A_3$
 (cyclic, order 3) iff $\Delta$ is a perfect square in $\mathbb{Q}$, and $S_3$ o
therwise.

- If $G = A_3$: the splitting field equals $\mathbb{Q}(c)$, so $c' \in \mathbb{Q
}(c)$. The relationship **exists**.
- If $G = S_3$: the splitting field has degree 6, so $c' \notin \mathbb{Q}(c)$.
The relationship **cannot exist** (it would force $c' \in \mathbb{Q}(c)$ with $z
 \neq 0$).

**Perfect square condition.** $\Delta = \frac{27(v^2-1)}{16v^2}$ is a perfect sq
uare in $\mathbb{Q}$ iff $27(v^2-1)$ is a perfect square integer. Since $27 = 3^
2 \cdot 3$, this reduces to:

$$3(v^2 - 1) = m^2 \quad \text{for some non-negative integer } m.$$

This is the Pell-type equation $m^2 - 3v^2 = -3$.

**Case $v = 1$.** The cubic factors as $4t^3 - 3t - 1 = (t-1)(2t+1)^2$, giving r
oots $1$ and $-\tfrac{1}{2}$. With $\theta = 0$, $\theta' = \frac{2\pi}{3}$: the
 equation $w + x + y = -\frac{z}{2}$ is satisfied by $w=1, x=0, y=0, z=-2$. So $
v=1$ works. (Note: $3(1^2-1) = 0 = 0^2$, so $v=1$ also satisfies the Pell equati
on.)

**Solving the Pell equation.** The fundamental solution to $u^2 - 3w^2 = 1$ is $
(u,w) = (2,1)$. Starting from $(m,v) = (0,1)$ and multiplying by $2 + \sqrt{3}$
repeatedly:

| $k$ | $(m, v)$ | $3(v^2-1) = m^2$? |
|-----|-----------|---------------------|
| 0 | $(0, 1)$ | $0 = 0^2$ ✓ |
| 1 | $(3, 2)$ | $9 = 3^2$ ✓ |
| 2 | $(12, 7)$ | $144 = 12^2$ ✓ |
| 3 | $(45, 26)$ | $2025 = 45^2$ ✓ |

**Verification for $v = 2$.** The cubic $8t^3 - 6t - 1 = 0$ has roots $\cos(\pi/
9), \cos(5\pi/9), \cos(7\pi/9)$. Direct computation yields:
$$\cos(5\pi/9) = 2\cos^2(\pi/9) - \cos(\pi/9) - 1.$$
Setting $c = \cos(\pi/9)$, $c' = \cos(5\pi/9)$: the equation $z\,c' = 2y\,c^2 +
x\,c + (w-y)$ is satisfied by $w=0, x=-1, y=1, z=1$, since $c' = 2c^2 - c - 1$.
✓

**No gaps.** For $v = 3,4,5,6$: $3(v^2-1) = 24, 45, 72, 105$ — none are perfect
squares. For $v = 8,\ldots,25$: none satisfy $3(v^2-1) = \text{square}$. The Pel

**Conclusion.** The four smallest values of $v$ allowing the resonance relations
hip are:

$$v = 1, \quad 2, \quad 7, \quad 26.$$
