## Proof

**Answer leak check:** The problem statement contains only the problem, no solut
ion or answer. Proceeding.

**Setup.** Partition $\{1,2,\ldots,2p\}$ into $p$ pairs $P_i = \{i,\, i+p\}$ for
 $i=1,\ldots,p$. Both elements of $P_i$ are congruent to $i \pmod p$ (with $P_p$
 congruent to $0$). For a $p$-element subset $A$, let $a_i = |A \cap P_i| \in \{
0,1,2\}$. Then

$$\sum_{i=1}^{p} a_i = p, \qquad \sum_{i=1}^{p} i\,a_i \equiv 0 \pmod p,$$

and the number of subsets realizing a fixed $(a_1,\ldots,a_p)$ is $\prod_{i=1}^{
p}\binom{2}{a_i}$. Thus the desired count is

$$N = \sum_{\substack{a_1,\ldots,a_p\in\{0,1,2\}\\ \sum a_i=p\\ \sum i\,a_i\equi
v 0\pmod p}} \prod_{i=1}^{p}\binom{2}{a_i}.$$

**Root-of-unity filter.** Let $\omega = e^{2\pi i/p}$. Then

$$N = \frac{1}{p}\sum_{j=0}^{p-1} \sum_{\substack{a_1,\ldots,a_p\in\{0,1,2\}\\ \
sum a_i=p}} \prod_{i=1}^{p}\binom{2}{a_i}\,\omega^{\,j\sum i a_i} = \frac{1}{p}\
sum_{j=0}^{p-1} [x^p]\,F_j(x),$$

where

$$F_j(x) = \prod_{i=1}^{p}\sum_{a=0}^{2}\binom{2}{a}\bigl(x\,\omega^{ji}\bigr)^{
a} = \prod_{i=1}^{p}\bigl(1+x\,\omega^{ji}\bigr)^2.$$

**Case $j=0$.** $F_0(x) = (1+x)^{2p}$, so $[x^p]F_0(x) = \binom{2p}{p}$.

**Case $j\neq 0$.** Since $p$ is prime, $\gcd(j,p)=1$, so as $i$ runs over $1,\l
dots,p$, the value $ji\bmod p$ runs over $0,1,\ldots,p-1$. Hence

$$F_j(x) = \prod_{i=0}^{p-1}\bigl(1+x\,\omega^{i}\bigr)^2 = \left(\prod_{i=0}^{p
-1}(1+x\,\omega^{i})\right)^{\!2}.$$

Using $\prod_{i=0}^{p-1}(z-\omega^i)=z^p-1$ with $z=-1/x$ (and $p$ odd), one obt
ains

$$\prod_{i=0}^{p-1}(1+x\,\omega^i) = 1 + x^p.$$

Therefore $F_j(x) = (1+x^p)^2 = 1+2x^p+x^{2p}$, giving $[x^p]F_j(x) = 2$ for eac
h $j=1,\ldots,p-1$.

**Combining.**

$$N = \frac{1}{p}\Bigl(\binom{2p}{p} + 2(p-1)\Bigr).$$

**Verification ($p=3$).** $\binom{6}{3}=20$, so $N = (20+4)/3 = 8$. Direct enume
ration: the only valid residue pattern is $(a_1,a_2,a_3)=(1,1,1)$ (sum of residu
es $1+2+0\equiv 0$), contributing $\binom{2}{1}^3 = 8$. ✓

The number of $p$-element subsets of $\{1,2,\ldots,2p\}$ whose element-sum is di
visible by $p$ is

$$\boxed{\dfrac{\binom{2p}{p}+2(p-1)}{p}}.$$
