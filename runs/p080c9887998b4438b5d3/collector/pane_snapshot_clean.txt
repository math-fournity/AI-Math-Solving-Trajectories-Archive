Looking at this problem, I need to find $N = \frac{\left(\frac{3p-3}{2}\right)!}
{\left[\left(\frac{p-1}{2}\right)!\right]^3} \pmod{p^2}$ for prime $p > 2$.

## Setup

Let $m = \frac{p-1}{2}$, so $p = 2m+1$ and $\frac{3p-3}{2} = 3m$. Thus
$$N = \frac{(3m)!}{(m!)^3}, \quad p = 2m+1 \text{ prime.}$$

## $p$-adic valuation

For $p \geq 5$: since $p < 3m = \frac{3(p-1)}{2} < 2p$, the factorial $(3m)!$ co
ntains exactly one multiple of $p$ (namely $p$ itself), and no multiples of $p^2
$. So $v_p((3m)!) = 1$. Meanwhile $m < p$, so $v_p((m!)^3) = 0$. Hence $v_p(N) =
 1$: we have $N \equiv 0 \pmod{p}$ but $N \not\equiv 0 \pmod{p^2}$ in general, a
nd we need $N/p \pmod{p}$.

## Extracting the factor of $p$

Split $(3m)!$ around the single multiple $p$:
$$(3m)! = p \cdot (p-1)! \cdot \prod_{k=p+1}^{3m} k.$$

Since $3m - p = \frac{p-3}{2} = m-1$, the last product is $\prod_{j=1}^{m-1}(p+j
)$. Modulo $p^2$:
$$\prod_{j=1}^{m-1}(p+j) = \prod_{j=1}^{m-1} j\cdot\prod_{j=1}^{m-1}\left(1+\tfr
ac{p}{j}\right) \equiv (m-1)!\left(1 + p\,H_{m-1}\right) \pmod{p^2},$$
where $H_{m-1} = \sum_{j=1}^{m-1} j^{-1} \pmod{p}$.

Therefore:
$$\frac{N}{p} = \frac{(p-1)!\cdot(m-1)!\cdot(1+p\,H_{m-1})}{(m!)^3}.$$

## Reducing modulo $p$

Modulo $p$, the factor $(1+p\,H_{m-1}) \equiv 1$, so:
$$\frac{N}{p} \equiv \frac{(p-1)!\cdot(m-1)!}{(m!)^3} \pmod{p}.$$

Using $m! = m\cdot(m-1)!$, we get $(m!)^3 = m^3\,((m-1)!)^3$, hence:
$$\frac{N}{p} \equiv \frac{(p-1)!}{m^3\,((m-1)!)^2} \pmod{p}.$$

Note $m^3\,((m-1)!)^2 = m\cdot m^2\,((m-1)!)^2 = m\,(m!)^2$, so:
$$\frac{N}{p} \equiv \frac{(p-1)!}{m\,(m!)^2} \pmod{p}.$$

## Wilson's theorem and the half-factorial identity

By Wilson, $(p-1)! \equiv -1 \pmod{p}$.

Split $(p-1)! = m!\cdot\prod_{k=m+1}^{p-1}k$. Writing $k = p-j$ for $j=1,\ldots,
m$:
$$\prod_{k=m+1}^{p-1}k = \prod_{j=1}^{m}(p-j) \equiv (-1)^m\,m! \pmod{p}.$$

So $(p-1)! \equiv (-1)^m\,(m!)^2 \pmod{p}$. Combined with Wilson:
$$(m!)^2 \equiv (-1)^{m+1} \pmod{p}.$$

## Final computation

Substituting:
$$\frac{N}{p} \equiv \frac{-1}{m\cdot(-1)^{m+1}} = \frac{(-1)^m}{m} \pmod{p}.$$

Since $m = \frac{p-1}{2} \equiv -\frac{1}{2} \pmod{p}$, we have $\frac{1}{m} \eq
uiv -2 \pmod{p}$, giving:
$$\frac{N}{p} \equiv -2\,(-1)^m = -2\,(-1)^{\frac{p-1}{2}} \pmod{p}.$$

By Euler's criterion, $(-1)^{\frac{p-1}{2}} = \left(\frac{-1}{p}\right)$ (the Le
gendre symbol). Therefore:

$$\boxed{N \equiv -2p\left(\frac{-1}{p}\right) \pmod{p^2}}$$

Equivalently:
- If $p \equiv 1 \pmod{4}$: $N \equiv -2p \pmod{p^2}$.
- If $p \equiv 3 \pmod{4}$: $N \equiv 2p \pmod{p^2}$.

## Verification

- **$p=5$** ($\equiv 1 \pmod 4$): $N = \frac{6!}{(2!)^3} = 90$, $90 \bmod 25 = 1
5 = -10 = -2p$. ✓
- **$p=7$** ($\equiv 3 \pmod 4$): $N = \frac{9!}{(3!)^3} = 1680$, $1680 \bmod 49
 = 14 = 2p$. ✓
- **$p=11$** ($\equiv 3 \pmod 4$): $N = \frac{15!}{(5!)^3} = 756756$, $756756 \b
mod 121 = 22 = 2p$. ✓
- **$p=13$** ($\equiv 1 \pmod 4$): $N = \frac{18!}{(6!)^3} = 17153136$, $1715313
6 \bmod 169 = 143 = -26 = -2p$. ✓
