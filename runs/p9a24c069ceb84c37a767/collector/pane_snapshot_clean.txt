**Setup and notation.** Let $I$ be the incenter of $\triangle ABC$ (equidistant
from all three sides), $D$ the foot of the altitude from $A$ to $BC$, and $X$ th
e antipode of $A$ on the circumcircle (so $AX$ is a diameter). Denote the inradi
us by $r$, circumradius by $R$, and angles $\angle A = 2\alpha$, $\angle B = 2\b
eta$, $\angle C = 2\gamma$, so $\alpha+\beta+\gamma = \tfrac{\pi}{2}$.

**Step 1: Use $IA = 3$.** The standard formula $IA = r/\sin(A/2) = r/\sin\alpha$
 gives:
$$r = 3\sin\alpha. \tag{1}$$

**Step 2: Use $IX = 4$ (with $IA=3$).** Place the circumcenter $O$ at the origin
. Then $|A|=R$ and $X = -A$. We compute:
$$|I-A|^2 = |I|^2 - 2\,I\cdot A + R^2 = 9, \qquad |I+A|^2 = |I|^2 + 2\,I\cdot A
+ R^2 = 16.$$

Adding: $2|I|^2 + 2R^2 = 25$, so $|I|^2 + R^2 = \tfrac{25}{2}$. By Euler's formu
la $|I|^2 = OI^2 = R^2 - 2Rr$:
$$2R^2 - 2Rr = \tfrac{25}{2} \quad\Longrightarrow\quad R^2 - Rr = \tfrac{25}{4}.
 \tag{2}$$

**Step 3: Use $ID = 2$.** Place $D$ at the origin, $BC$ along the $x$-axis, $A=(
0,h)$. Then $I = (x_I, r)$ and $ID^2 = x_I^2 + r^2 = 4$.

Computing the incenter's $x$-coordinate via barycentric coordinates (with $B=(-m
,0)$, $C=(n,0)$, $m+n=a$):
$$x_I = \frac{(b-c)(s-a)}{a}.$$

Using $s - a = r\cot\alpha = 3\cos\alpha$ (from (1) and $\cot\alpha = \cos\alpha
/\sin\alpha$), $a = 4R\sin\alpha\cos\alpha$, and $b - c = 4R\sin\alpha\sin(\beta
-\gamma)$, we obtain the elegant simplification:
$$x_I = 3\sin(\beta - \gamma).$$

Therefore:
$$ID^2 = 9\sin^2(\beta-\gamma) + r^2 = 4. \tag{3}$$

**Step 4: Reduce to two unknowns.** Set $u = \sin\alpha$, $v = \cos(\beta-\gamma
)$. Then:
- From (3): $\sin^2(\beta-\gamma) + \sin^2\alpha = \tfrac{4}{9}$, i.e., $1 - v^2
 + u^2 = \tfrac{4}{9}$, giving $v^2 = \tfrac{5}{9} + u^2$. **(V)**
- The product $p = \sin\beta\sin\gamma = \frac{\cos(\beta-\gamma)-\sin\alpha}{2}
 = \frac{v-u}{2}$, and from $IA=3$: $R = \frac{3}{4p}$.
- Substituting $R$ and $r=3u$ into (2): $100p^2 + 36u\,p - 9 = 0$. With $p = \fr
ac{v-u}{2}$:

$$25(v-u)^2 + 18u(v-u) - 9 = 0 \quad\Longrightarrow\quad 25v^2 - 32uv + 7u^2 - 9
 = 0. \tag{VI}$$

**Step 5: Solve.** Substituting $v^2 = \tfrac{5}{9}+u^2$ from (V) into (VI):
$$25\!\left(\tfrac{5}{9}+u^2\right) - 32uv + 7u^2 - 9 = 0 \quad\Longrightarrow\q
uad 32u^2 - 32uv + \tfrac{44}{9} = 0,$$
giving $v = u + \tfrac{11}{72u}$. Substituting back into (V):
$$\left(u + \tfrac{11}{72u}\right)^2 = \tfrac{5}{9} + u^2 \quad\Longrightarrow\q
uad \tfrac{11}{36} + \tfrac{121}{5184\,u^2} = \tfrac{5}{9},$$
$$\frac{121}{5184\,u^2} = \frac{1}{4} \quad\Longrightarrow\quad u^2 = \frac{484}
{5184} = \frac{121}{1296} \quad\Longrightarrow\quad u = \frac{11}{36}.$$

**Step 6: Compute $r$.** From (1):
$$r = 3\sin\alpha = 3\cdot\frac{11}{36} = \frac{11}{12}.$$

**Verification of all three constraints:**
- $IA = r/\sin\alpha = \frac{11/12}{11/36} = 3$. ✓
- $R = \frac{3}{4p}$, $p = \frac{v-u}{2} = \frac{29/36 - 11/36}{2} = \frac{1}{4}
$, so $R = 3$. Then $R^2 - Rr = 9 - \frac{33}{12} = \frac{25}{4}$, confirming $I
X = 4$. ✓
- $ID^2 = 9(1 - v^2) + r^2 = 9\cdot\frac{455}{1296} + \frac{121}{144} = \frac{40
95+1089}{1296} = 4$, so $ID = 2$. ✓

The triangle is valid ($\alpha \approx 17.6°$, $\beta \approx 54.4°$, $\gamma \a
pprox 18.0°$, all positive, summing to $90°$).

**Result.** The inradius is $r = \frac{11}{12}$, which is irreducible ($\gcd(11,
12)=1$). Thus $a = 11$, $b = 12$, and:

$$a + b = 11 + 12 = \boxed{23}$$
