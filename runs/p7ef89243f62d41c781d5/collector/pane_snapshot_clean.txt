## Proof

**Claim:** Yes, $X_1, X_2, \ldots, X_n$ are jointly Gaussian.

**Definition.** Random variables $Z_1, \ldots, Z_m$ are *jointly Gaussian* if ev
ery linear combination $\sum_{i=1}^m a_i Z_i$ is a (possibly degenerate, i.e., c
onstant) Gaussian random variable.

**Setup.** We are given that $Y_1, \ldots, Y_n$ are jointly Gaussian, where $Y_k
 = \sum_{i=1}^k X_i$. Observe that each $X_k$ can be recovered from the $Y$'s:
$$X_1 = Y_1, \qquad X_k = Y_k - Y_{k-1} \quad (k = 2, \ldots, n),$$
where we set $Y_0 = 0$.

**Key step.** Take any coefficients $c_1, \ldots, c_n \in \mathbb{R}$. Consider
the linear combination
$$S = \sum_{k=1}^n c_k X_k = c_1 Y_1 + \sum_{k=2}^n c_k(Y_k - Y_{k-1}).$$

Expanding and collecting terms by $Y_j$:
$$S = (c_1 - c_2)\,Y_1 + \sum_{j=2}^{n-1}(c_j - c_{j+1})\,Y_j + c_n\,Y_n.$$

This expresses $S$ as a linear combination of $Y_1, \ldots, Y_n$. Since $Y_1, \l
dots, Y_n$ are jointly Gaussian, $S$ is a Gaussian random variable.

**Conclusion.** Since every linear combination $\sum_{k=1}^n c_k X_k$ is Gaussia
n, the random variables $X_1, \ldots, X_n$ are jointly Gaussian. $\blacksquare$

**Remark.** The essential point is that $X = AY$ where $A$ is an invertible lowe
r-triangular matrix (with $1$ on the diagonal and $-1$ on the first subdiagonal)
. Joint Gaussianity is preserved under invertible linear (affine) transformation
s, so it transfers from $Y$ to $X$. The converse direction ($X$ jointly Gaussian
 $\Rightarrow$ $Y$ jointly Gaussian) holds by the same argument since $Y = A^{-1
}X$ is also a linear transformation. Thus joint Gaussianity of $(X_1,\ldots,X_n)
$ and of $(Y_1,\ldots,Y_n)$ are in fact equivalent.
