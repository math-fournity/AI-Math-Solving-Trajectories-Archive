Looking at this problem, I need to find the minimum length of a string $N$ over
$\{1,2\}$ such that every 10000-digit string with 9999 ones and one two is a sub
sequence of $N$.

## Setup

The 10000 target strings are $1^{k-1}2\,1^{10000-k}$ for $k=1,2,\ldots,10000$ (t
he single 2 is in position $k$).

Let $N$ have $T$ ones and $m$ twos. Let the twos be at positions $p_1 < p_2 < \c
dots < p_m$, and define $c_i = $ (number of ones before $p_i$). Since position $
p_i$ is a 2, the number of ones after it is $T - c_i$.

**Key observation:** The total number of ones is $T = c_i + (T-c_i)$ for every $
i$, independent of $i$.

## Necessary and Sufficient Condition

The string $1^{k-1}2\,1^{10000-k}$ is a subsequence of $N$ if and only if there
exists a 2 at some position $p_i$ with at least $k-1$ ones before it and at leas
t $10000-k$ ones after it:

$$c_i \geq k-1 \quad \text{and} \quad T - c_i \geq 10000 - k \;\;\Longleftrighta
rrow\;\; k-1 \leq c_i \leq T - 10000 + k.$$

Setting $j = k-1 \in \{0,1,\ldots,9999\}$ and $L = T - 9999$, the condition beco
mes:

> For every $j \in \{0,\ldots,9999\}$, some $c_i$ lies in $[j,\; j+L]$.

**Feasibility requires** $j \leq j + L$ for all $j$, i.e., $L \geq 0$, giving $T
 \geq 9999$.

## Lower Bound on the Number of Twos

Each value $c_i$ covers the $j$-values in $[\max(0,c_i-L),\, \min(9999, c_i)]$,
at most $L+1$ values. Since we must cover all 10000 values of $j$:

$$m \cdot (L+1) \geq 10000 \quad\Longrightarrow\quad m \geq \left\lceil \frac{10
000}{L+1}\right\rceil = \left\lceil \frac{10000}{T - 9998}\right\rceil.$$

## Optimizing the Total Length

We minimize $T + m \geq T + \left\lceil \frac{10000}{T-9998}\right\rceil$ over i
ntegers $T \geq 9999$.

Substitute $x = T - 9998 \geq 1$, so $T = x + 9998$. Minimize $g(x) = x + \lceil
 10000/x \rceil$:

| $x$ | $\lceil 10000/x\rceil$ | $g(x)$ |
|-----|------------------------|--------|
| 99  | 102 | 201 |
| **100** | **100** | **200** |
| 101 | 100 | 201 |
| 50  | 200 | 250 |

By AM-GM, $x + 10000/x \geq 200$ with equality at $x=100$. Since $10000/100 = 10
0$ is an integer, $\lceil 10000/100\rceil = 100$ and $g(100) = 200$ exactly. All
 other values give $g \geq 201$.

**Minimum total length** $= 9998 + 200 = \mathbf{10198}$.

## Construction Achieving 10198

Set $T = 10098$ ones, $m = 100$ twos, $L = 99$. Place the twos so that:

$$c_i = 99 + 100(i-1), \quad i = 1, 2, \ldots, 100,$$

i.e., $c_i \in \{99, 199, 299, \ldots, 9999\}$. This gives:

$$N = 1^{99}\;2\;(1^{100}\;2)^{99}\;1^{99}.$$

**Length check:** $99 + 1 + 99\times(100+1) + 99 = 99 + 1 + 9999 + 99 = 10198$.
✓

**Coverage check:** The value $c_i = 99 + 100(i-1)$ covers $j \in [c_i - 99,\; c
_i] = [100(i-1),\; 99 + 100(i-1)]$. For $i=1,\ldots,100$ these intervals are $[0
,99], [100,199], \ldots, [9900,9999]$, which partition $\{0,\ldots,9999\}$. Ever
y $j$ is covered. ✓

**Subsequence verification:** For target $1^{k-1}2\,1^{10000-k}$ with $j = k-1$,
 find $i$ with $j \in [100(i-1), 99+100(i-1)]$. Then $c_i = 99+100(i-1) \geq j =

 we take $k-1$ ones before the $i$-th 2, the $i$-th 2 itself, and $10000-k$ ones
