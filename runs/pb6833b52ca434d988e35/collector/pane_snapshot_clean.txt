Looking at this problem, I need to find all positive integers $n \leq 20$ such t
hat there exists a monic polynomial $P(x)$ of degree $n$ with integer coefficien
ts where $P(a)P(b) \neq P(c)$ for all integers $a, b, c$.

## Proof

**Key Tool — Modular Obstruction.** If for some prime $p$, the image of $P \bmod
 p$ (as a function $\mathbb{F}_p \to \mathbb{F}_p$) is *product-free* (no $u,v,w
$ in the image with $uv = w$), then $P(a)P(b) = P(c)$ over $\mathbb{Z}$ would re
duce to a product relation mod $p$ — a contradiction. So it suffices to find, fo
r each eligible $n$, a monic $P$ of degree $n$ whose image mod some prime is pro
duct-free.

---

### $n = 1$ fails

$P(x) = x + c$. The image on $\mathbb{Z}$ is all of $\mathbb{Z}$, so e.g. $P(0)\
cdot P(1) = c(c+1) = P(c^2+c-1+c) = P(c^2+2c-1)$... more directly, for any $u,v
\in \mathbb{Z}$, $uv = P(uv - c)$. So $n=1 \notin S$.

### $n = 2$ fails

Let $P(x) = x^2 + bx + c$ be any monic quadratic with integer coefficients. Comp
ute:
$$P(0) \cdot P(1) = c \cdot (1 + b + c) = c + bc + c^2.$$
$$P(c) = c^2 + bc + c = c + bc + c^2.$$
So $P(0) \cdot P(1) = P(c)$ for **every** monic quadratic, regardless of $b, c$.
 Since $c \in \mathbb{Z}$, this is a valid relation. Thus $n = 2 \notin S$.

### $n \geq 3$ works

**Construction.** For $n \geq 3$, define
$$P(x) = x^n - x^{n-2} + 2.$$
This is monic of degree $n$ with integer coefficients. Rewrite:
$$P(x) = 2 + x^{n-2}(x^2 - 1) = 2 + (x^3 - x)\,x^{n-3}.$$

**Mod 3 analysis.** By Fermat's little theorem, $x^3 \equiv x \pmod{3}$ for all
integers $x$, so $x^3 - x \equiv 0 \pmod{3}$. Therefore:
$$P(x) \equiv 2 \pmod{3} \quad \text{for all } x \in \mathbb{Z}.$$

The image of $P \bmod 3$ is the singleton $\{2\} \subset \mathbb{F}_3$.

**Product-free check.** The only product of elements in $\{2\}$ is $2 \cdot 2 =
4 \equiv 1 \pmod{3}$, and $1 \notin \{2\}$. So $\{2\}$ is product-free in $\math
bb{F}_3$.

**Conclusion.** If $P(a)P(b) = P(c)$ for integers $a,b,c$, reducing mod $3$ give
s $2 \cdot 2 \equiv 2 \pmod{3}$, i.e., $1 \equiv 2 \pmod{3}$, a contradiction. S
o no such $a,b,c$ exist, and $n \in S$ for all $n \geq 3$.

---

### Final Computation

$$S \cap \{1, 2, \ldots, 20\} = \{3, 4, 5, \ldots, 20\}.$$

$$\sum_{n=3}^{20} n = \frac{20 \cdot 21}{2} - 1 - 2 = 210 - 3 = \boxed{207}.$$
