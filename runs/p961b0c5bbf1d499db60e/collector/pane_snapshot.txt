**Step 1: Simplify the summand.**

Set $a = (x+1)^2$. Then
$$1 - \frac{4x}{(x+1)^2 + n^2} = \frac{(x+1)^2 + n^2 - 4x}{(x+1)^2 + n^2} = \fra
c{(x-1)^2 + n^2}{(x+1)^2 + n^2},$$
since $(x+1)^2 - 4x = x^2-2x+1 = (x-1)^2$.

Exponentiating the log-sum converts it into an infinite product:
$$e^{\sum_{n=-\infty}^{\infty}\ln\left(\frac{(x-1)^2+n^2}{(x+1)^2+n^2}\right)} =
 \prod_{n=-\infty}^{\infty}\frac{n^2+(x-1)^2}{n^2+(x+1)^2}.$$

**Step 2: Evaluate the product via the Weierstrass product for $\sinh$.**

The classical product (Euler / Weierstrass) is
$$\frac{\sinh(\pi z)}{\pi z} = \prod_{n=1}^{\infty}\left(1+\frac{z^2}{n^2}\right
),$$
so $\prod_{n=1}^{\infty}(n^2+z^2) = \Big(\prod_{n=1}^{\infty}n^2\Big)\frac{\sinh
(\pi z)}{\pi z}.$

The two-sided product is
$$\prod_{n=-\infty}^{\infty}(n^2+z^2) = z^2\prod_{n=1}^{\infty}(n^2+z^2)^2 = z^2
\Big(\prod_{n=1}^{\infty}n^2\Big)^2\frac{\sinh^2(\pi z)}{(\pi z)^2}.$$

Taking the ratio for $z = x-1$ and $w = x+1$ (both positive for $x\to\infty$), t
he divergent $\prod n^2$ factors cancel:
$$\prod_{n=-\infty}^{\infty}\frac{n^2+(x-1)^2}{n^2+(x+1)^2} = \frac{\sinh^2(\pi(
x-1))}{\sinh^2(\pi(x+1))}.$$

**Step 3: Take the limit $x\to\infty$.**

Using $\sinh t = \frac{e^t - e^{-t}}{2}$,
$$\frac{\sinh(\pi(x-1))}{\sinh(\pi(x+1))} = \frac{e^{\pi(x-1)}-e^{-\pi(x-1)}}{e^
{\pi(x+1)}-e^{-\pi(x+1)}} = e^{-2\pi}\cdot\frac{1-e^{-2\pi(x-1)}}{1-e^{-2\pi(x+1
)}}.$$

As $x\to\infty$, both $e^{-2\pi(x-1)}\to 0$ and $e^{-2\pi(x+1)}\to 0$, so the fr
action $\to 1$, giving
$$\frac{\sinh(\pi(x-1))}{\sinh(\pi(x+1))} \longrightarrow e^{-2\pi}.$$

Squaring,
$$\prod_{n=-\infty}^{\infty}\frac{n^2+(x-1)^2}{n^2+(x+1)^2} \longrightarrow e^{-
4\pi}.$$

$$\boxed{\lim_{x\to\infty} e^{\sum_{n=-\infty}^{\infty}\ln\left(1-\frac{4x}{(x+1
