## Solution

**Setup.** The integral is the Newtonian potential at $\vec{r}$ due to a "charge
 density" $\rho(\vec{r}') = y'$ distributed over the ball $r' \le R$. I expand t
he Green's function in spherical harmonics:

$$\frac{1}{|\vec{r}-\vec{r}'|} = \sum_{\ell=0}^{\infty}\sum_{m=-\ell}^{\ell} \fr
ac{4\pi}{2\ell+1}\frac{r_<^\ell}{r_>^{\ell+1}}\,Y_\ell^m(\theta,\phi)\,Y_\ell^{m
*}(\theta',\phi')$$

where $r_< = \min(r,r')$, $r_> = \max(r,r')$.

**Express $y'$ in spherical harmonics.** Using $Y_1^1 = -\sqrt{3/(8\pi)}\sin\the
ta\,e^{i\phi}$ and $Y_1^{-1} = \sqrt{3/(8\pi)}\sin\theta\,e^{-i\phi}$:

$$Y_1^1 + Y_1^{-1} = -2i\sqrt{\frac{3}{8\pi}}\sin\theta\sin\phi \implies \sin\th
eta'\sin\phi' = i\sqrt{\frac{2\pi}{3}}\bigl(Y_1^1(\theta',\phi')+Y_1^{-1}(\theta
',\phi')\bigr)$$

So $y' = r'\sin\theta'\sin\phi' = i\,r'\sqrt{\tfrac{2\pi}{3}}\bigl(Y_1^1+Y_1^{-1
}\bigr)$.

**Angular integration.** The full integral in spherical coordinates ($d^3\vec{r}
' = r'^2\,dr'\,d\Omega'$):

$$I = \int_0^R r'^3\,dr'\int d\Omega'\,\sin\theta'\sin\phi'\sum_{\ell,m}\frac{4\
pi}{2\ell+1}\frac{r_<^\ell}{r_>^{\ell+1}}Y_\ell^m(\theta,\phi)\,Y_\ell^{m*}(\the
ta',\phi')$$

By orthonormality $\int Y_\ell^{m*}Y_{\ell'}^{m'}d\Omega = \delta_{\ell\ell'}\de
lta_{mm'}$, the angular integral selects only $\ell=1$, $m=\pm1$:

$$\int d\Omega'\,\sin\theta'\sin\phi'\,Y_\ell^{m*} = i\sqrt{\frac{2\pi}{3}}\bigl
(\delta_{\ell,1}\delta_{m,1}+\delta_{\ell,1}\delta_{m,-1}\bigr)$$

Therefore:

$$I = \frac{4\pi}{3}\,i\sqrt{\frac{2\pi}{3}}\int_0^R r'^3\frac{r_<}{r_>^2}\,dr'\
;\bigl(Y_1^1(\theta,\phi)+Y_1^{-1}(\theta,\phi)\bigr)$$

**Convert back to Cartesian.** Using $Y_1^1+Y_1^{-1} = -i\sqrt{3/(2\pi)}\sin\the
ta\sin\phi = -i\sqrt{3/(2\pi)}\cdot(y/r)$:

$$I = \frac{4\pi}{3}\cdot i\sqrt{\frac{2\pi}{3}}\cdot(-i)\sqrt{\frac{3}{2\pi}}\c
dot\frac{y}{r}\int_0^R r'^3\frac{r_<}{r_>^2}\,dr' = \frac{4\pi}{3}\frac{y}{r}\in
t_0^R r'^3\frac{r_<}{r_>^2}\,dr'$$

**Radial integral — Case 1: $r \ge R$ (outside).** Here $r' \le R \le r$, so $r_
< = r'$, $r_> = r$:

$$\int_0^R r'^3\frac{r'}{r^2}\,dr' = \frac{1}{r^2}\cdot\frac{R^5}{5}$$

$$\boxed{I_{\text{out}} = \frac{4\pi R^5}{15}\,\frac{y}{r^3}}, \qquad r \ge R$$

**Radial integral — Case 2: $r \le R$ (inside).** Split at $r$:

$$\int_0^r \frac{r'^4}{r^2}\,dr' + \int_r^R \frac{r'\,r}{1}\,dr' = \frac{r^3}{5}
 + \frac{r(R^2-r^2)}{2} = \frac{r(5R^2-3r^2)}{10}$$

$$\boxed{I_{\text{in}} = \frac{2\pi y}{15}\bigl(5R^2 - 3r^2\bigr)}, \qquad r \le
 R$$

**Verification via Poisson's equation.** The potential satisfies $\nabla^2 I = -
4\pi\rho = -4\pi y$ inside the sphere. Setting $I = y\,f(r)$ with $f = \frac{2\p
i}{15}(5R^2-3r^2)$, and using that $y$ is a solid harmonic ($\nabla^2 y = 0$):

$$\nabla^2(yf) = y\,\nabla^2 f + 2\,\nabla f\cdot\nabla y$$

With $f' = -4\pi r/5$, $f'' = -4\pi/5$: $\nabla^2 f = -4\pi/5 - 8\pi/5 = -12\pi/
5$, and $2\nabla f\cdot\nabla y = 2(-4\pi r/5)(y/r) = -8\pi y/5$. Thus $\nabla^2
 I = -12\pi y/5 - 8\pi y/5 = -4\pi y$. ✓

The outside solution $\frac{4\pi R^5}{15}\frac{y}{r^3}$ is harmonic (since $y/r^
3 = y/r^{2\cdot1+1}$ is an exterior solid harmonic of degree 1). ✓

**Continuity at $r = R$:** Inside gives $\frac{2\pi y}{15}(2R^2) = \frac{4\pi R^
2 y}{15}$; outside gives $\frac{4\pi R^5 y}{15R^3} = \frac{4\pi R^2 y}{15}$. ✓ R
adial derivatives also match: both give $-4\pi R y/5$. ✓

## Final Result

$$\int_{r'\le R}\frac{y'}{|\vec{r}-\vec{r}'|}\,d^3\vec{r}' = \begin{cases} \dfra
c{2\pi\,y}{15}\bigl(5R^2 - 3r^2\bigr), & r \le R \\[8pt] \dfrac{4\pi R^5}{15}\,\
dfrac{y}{r^3}, & r \ge R \end{cases}$$

where $y = r\sin\theta\sin\phi$ is the $y$-component of the observation point $\
vec{r}$.
