## Proof

**Construction.** Let $\mathcal{U}$ be a non-principal ultrafilter on $\mathbb{N
}$ (whose existence follows from the Boolean Prime Ideal Theorem / Axiom of Choi
ce). Define

$$F = \mathbb{R}^{\mathbb{N}} / \mathcal{U},$$

the ultrapower of $\mathbb{R}$ modulo $\mathcal{U}$. Elements of $F$ are equival
ence classes $[f]$ of sequences $f = (f(1), f(2), \dots) \in \mathbb{R}^{\mathbb
{N}}$, where $[f] = [g]$ if and only if $\{i \in \mathbb{N} : f(i) = g(i)\} \in
\mathcal{U}$.

Operations and order are defined componentwise:
- $[f] + [g] = [f+g]$, where $(f+g)(i) = f(i)+g(i)$,
- $[f] \cdot [g] = [fg]$, where $(fg)(i) = f(i)\cdot g(i)$,
- $[f] < [g]$ iff $\{i : f(i) < g(i)\} \in \mathcal{U}$.

The additive identity is $[0] = [(0,0,0,\dots)]$, the multiplicative identity is
 $[1] = [(1,1,1,\dots)]$.

**Step 1: $F$ is an ordered field.**

By Łoś's Theorem (the fundamental theorem of ultrapowers): for any first-order f
ormula $\varphi(x_1,\dots,x_n)$ in the language of ordered fields and any $[f_1]
,\dots,[f_n] \in F$,

$$F \models \varphi([f_1],\dots,[f_n]) \iff \{i \in \mathbb{N} : \mathbb{R} \mod
els \varphi(f_1(i),\dots,f_n(i))\} \in \mathcal{U}.$$

Since $\mathbb{R}$ is an ordered field, it satisfies every first-order axiom of
ordered fields. These axioms are universal (equational or universal Horn) senten
ces, so by Łoś's Theorem, $F$ satisfies them as well. Hence $F$ is an ordered fi
eld. $\square$

**Step 2: $F$ is not Archimedean.**

Consider the element $\omega = [(1, 2, 3, 4, \dots)] \in F$, i.e., the class of
the sequence $f(i) = i$.

For any standard natural number $n \in \mathbb{N}$, the element $n \cdot [1] = [
(n, n, n, \dots)]$. We compare:

$$\{i \in \mathbb{N} : n < i\} = \{n+1, n+2, n+3, \dots\}.$$

Since $\mathcal{U}$ is a non-principal ultrafilter, it contains every cofinite s
ubset of $\mathbb{N}$. The set $\{n+1, n+2, \dots\}$ is cofinite, so it belongs
to $\mathcal{U}$. Therefore $n \cdot [1] < \omega$ for every $n \in \mathbb{N}$.

This means $\omega$ is an **infinite element**: no finite multiple of the identi
ty exceeds it. Equivalently, $\varepsilon = 1/\omega = [(1, \tfrac{1}{2}, \tfrac
{1}{3}, \dots)]$ is a positive infinitesimal satisfying $0 < \varepsilon < 1/n$
for all $n \in \mathbb{N}$. Hence $F$ does **not** have the Archimedean property
. $\square$

**Step 3: $F$ satisfies Cantor's Intersection Theorem.**

We must show: for any nested sequence of closed bounded intervals

$$[a_1, b_1] \supseteq [a_2, b_2] \supseteq [a_3, b_3] \supseteq \cdots$$

in $F$ (with $a_n \leq b_n$ for all $n$), the intersection $\bigcap_{n=1}^{\inft

We establish this via **countable saturation** of $F$.

> **Lemma (Countable Saturation).** *Let $\{S_n\}_{n \in \mathbb{N}}$ be a count
able family of internal subsets of $F$ with the finite intersection property (ev
ery finite subcollection has nonempty intersection). Then $\bigcap_{n=1}^{\infty
} S_n \neq \emptyset$.*

*Proof of Lemma.* Each internal set $S_n$ is defined by a first-order formula $\
varphi_n(x, \bar{c}_n)$ with parameters $\bar{c}_n = ([f_n^1], \dots, [f_n^{k_n}
]) \in F$. That is, $S_n = \{x \in F : F \models \varphi_n(x, \bar{c}_n)\}$.

By the finite intersection property, for each $N \in \mathbb{N}$ there exists $[
g_N] \in F$ with $[g_N] \in \bigcap_{n=1}^{N} S_n$. By Łoś's Theorem, the set

$$B_N = \left\{i \in \mathbb{N} : \mathbb{R} \models \exists x \bigwedge_{n=1}^{
N} \varphi_n\!\left(x,\, f_n^1(i), \dots, f_n^{k_n}(i)\right)\right\}$$

belongs to $\mathcal{U}$. Note that $B_1 \supseteq B_2 \supseteq B_3 \supseteq \
cdots$ (since satisfying more conjuncts is harder).

s follows. For each $i \in \mathbb{N}$, set

$$N(i) = \max\{N \in \mathbb{N} : i \in B_N\},$$

with $N(i) = 0$ if $i \notin B_1$.

- If $N(i) \geq 1$: since $i \in B_{N(i)}$, there exists a real number satisfyin

g(i)$ to be any such witness.
- If $N(i) = 0$: set $g(i) = 0$.

**Verification.** Fix any $n \in \mathbb{N}$. Consider

$$T_n = \left\{i \in \mathbb{N} : \mathbb{R} \models \varphi_n\!\left(g(i),\, f_
n^1(i), \dots, f_n^{k_n}(i)\right)\right\}.$$

For every $i \in B_n$, we have $N(i) \geq n$, so $g(i)$ was chosen to satisfy $\
bigwedge_{j=1}^{N(i)} \varphi_j$, which in particular includes $\varphi_n$. Thus

osed, $T_n \in \mathcal{U}$.

By Łoś's Theorem, $F \models \varphi_n([g], \bar{c}_n)$, i.e., $[g] \in S_n$. Si

so the intersection is nonempty. $\square$

*Applying the Lemma to Cantor's Intersection Theorem.* Let $[a_1, b_1] \supseteq

Each interval $[a_n, b_n] = \{x \in F : a_n \leq x \leq b_n\}$ is an **internal
set**: it is defined by the first-order formula $\varphi_n(x, a_n, b_n) := (a_n
\leq x \wedge x \leq b_n)$ with parameters $a_n, b_n \in F$.

**Finite intersection property.** For any finite subcollection $\{[a_{n_1}, b_{n
_1}], \dots, [a_{n_k}, b_{n_k}]\}$ with $n_1 < \cdots < n_k$, the intersection e

By the Countable Saturation Lemma, $\bigcap_{n=1}^{\infty} [a_n, b_n] \neq \empt

**Conclusion.** The ultrapower $F = \mathbb{R}^{\mathbb{N}}/\mathcal{U}$ is an o
rdered field (Step 1), is non-Archimedean (Step 2, since it contains the infinit

s Cantor's Intersection Theorem (Step 3, by countable saturation).

**Remark on why this is consistent.** Cantor's Intersection Theorem and the Arch
imedean property are independent in ordered fields. In Archimedean ordered field
s, the nested interval property is equivalent to Dedekind completeness (hence to
 being $\mathbb{R}$). But the Archimedean property is not first-order expressibl
e (it quantifies over the external set of standard natural numbers), so it does
not transfer through the ultrapower construction. Countable saturation, which is
 a model-theoretic property of the ultrapower over a countable index set, suppli
es the nested interval property directly — without forcing the field to be Archi
medean.
