## Solution

Let $x_n$ be the root of $e^x + x^{2n+1} = 0$. Since $2n+1$ is odd, $x_n < 0$. S
et $x_n = -t_n$ with $t_n > 0$. The equation becomes
$$e^{-t_n} = t_n^{2n+1}, \quad\text{i.e.}\quad -t_n = (2n+1)\ln t_n.$$

Let $m = 2n+1$. Then $\ln t_n = -t_n/m$, equivalently
$$\ln t_n + \frac{t_n}{m} = 0.$$

### Locating $t_n$

As $m\to\infty$, the equation forces $\ln t_n \to 0$, so $t_n \to 1$. Write $t_n
 = 1 + \epsilon$ with $\epsilon \to 0$. Expanding:
$$\epsilon - \frac{\epsilon^2}{2} + \frac{\epsilon^3}{3} - \cdots = -\frac{1+\ep
silon}{m}.$$

Seek an expansion $\epsilon = \dfrac{a}{m} + \dfrac{b}{m^2} + \dfrac{c}{m^3} + \
cdots$. Matching powers of $1/m$:

- **Order $1/m$:** $a = -1$.
- **Order $1/m^2$:** $b - \dfrac{a^2}{2} = -a \;\Rightarrow\; b - \dfrac{1}{2} =
 1 \;\Rightarrow\; b = \dfrac{3}{2}$.
- **Order $1/m^3$:** $c - ab + \dfrac{a^3}{3} = -b \;\Rightarrow\; c + \dfrac{3}
{2} - \dfrac{1}{3} = -\dfrac{3}{2} \;\Rightarrow\; c = -\dfrac{8}{3}$.

Hence
$$\epsilon = -\frac{1}{m} + \frac{3}{2m^2} - \frac{8}{3m^3} + \cdots$$

### Computing the limit

Since $x_n = -t_n = -(1+\epsilon)$, we have $x_n + 1 = -\epsilon$:
$$x_n + 1 = \frac{1}{m} - \frac{3}{2m^2} + \frac{8}{3m^3} + \cdots$$

Using $2n = m - 1$:
$$2n(x_n+1) = (m-1)\!\left(\frac{1}{m} - \frac{3}{2m^2} + \frac{8}{3m^3} + \cdot
s\right)$$
$$= 1 - \frac{1}{m} - \frac{3}{2m} + \frac{3}{2m^2} + \frac{8}{3m^2} + \cdots =
1 - \frac{5}{2m} + \frac{25}{6m^2} + \cdots$$

Therefore
$$1 - 2n(x_n+1) = \frac{5}{2m} - \frac{25}{6m^2} + \cdots$$

and
$$n\bigl(1 - 2n(x_n+1)\bigr) = \frac{5n}{2(2n+1)} - \frac{25n}{6(2n+1)^2} + \cdo
ts$$

As $n\to\infty$: the first term tends to $\dfrac{5}{4}$, and the second (and all
 higher) terms tend to $0$. Thus

$$\lim_{n\to\infty} n\bigl(1 - 2n(x_n+1)\bigr) = \dfrac{5}{4}.$$
