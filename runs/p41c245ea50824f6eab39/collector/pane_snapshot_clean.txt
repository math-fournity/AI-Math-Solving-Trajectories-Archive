# Proof

Define the **difference sequence** of a binary sequence $y = (y_1, y_2, \ldots,
y_{n+1})$ to be $x = (x_1, \ldots, x_n)$ where
$$x_i = y_i \oplus y_{i+1} \quad (1 \le i \le n),$$
i.e., $x_i = 1$ if $y_i \neq y_{i+1}$ and $x_i = 0$ if $y_i = y_{i+1}$.

**Key observation.** A four-term block $y_i, y_{i+1}, y_{i+2}, y_{i+3}$ equals $
0011$ or $1100$ if and only if the corresponding three-term block of the differe
nce sequence satisfies $x_i, x_{i+1}, x_{i+2} = 0, 1, 0$.

*Proof of observation.* Both $0011$ and $1100$ are characterized by: the first t
wo terms are equal, the middle two terms differ, and the last two terms are equa
l. This is exactly the condition $x_i = 0$ (no change), $x_{i+1} = 1$ (change),
$x_{i+2} = 0$ (no change), i.e., $x_i x_{i+1} x_{i+2} = 010$. Concretely:
- $y_i y_{i+1} y_{i+2} y_{i+3} = 0011 \iff x_i x_{i+1} x_{i+2} = 010$.
- $y_i y_{i+1} y_{i+2} y_{i+3} = 1100 \iff x_i x_{i+1} x_{i+2} = 010$.

Conversely, if $x_i x_{i+1} x_{i+2} = 010$, then $y_i = y_{i+1}$, $y_{i+1} \neq
y_{i+2}$, $y_{i+2} = y_{i+3}$, so the block is either $0011$ (if $y_i = 0$) or $
1100$ (if $y_i = 1$). $\square$

**Bijection.** The difference map $y \mapsto (x, y_1)$ is a bijection from binar
y sequences of length $n+1$ to pairs $(x, y_1)$ where $x$ is a binary sequence o
f length $n$ and $y_1 \in \{0, 1\}$. The inverse is given by $y_{i+1} = y_i \opl
us x_i$ (cumulative XOR), which reconstructs $y$ uniquely from $x$ and $y_1$.

**Validity preservation.** By the key observation:
- $y$ contains a forbidden block $0011$ or $1100$ $\iff$ $x$ contains the block
$010$.

Therefore $y$ is a valid $b$-sequence (avoids $0011$ and $1100$) if and only if
$x$ is a valid $a$-sequence (avoids $010$).

**Conclusion.** Under this bijection, the valid $b$-sequences of length $n+1$ co
rrespond exactly to pairs $(x, y_1)$ where $x$ is a valid $a$-sequence of length
 $n$ and $y_1 \in \{0,1\}$. There are $a_n$ choices for $x$ and $2$ choices for
$y_1$, giving
$$b_{n+1} = 2\,a_n$$
for all positive integers $n$. $\blacksquare$
