Looking at this problem, I need to find the probability that a randomly selected
 unit with efficiency rating exactly 66.6% belongs to a plant with serial number
 ≥ 6000.

## Setting Up the Counting

**Efficiency rating condition:** A unit producing $j$ functional components out
of $n$ total has efficiency $\frac{100j}{n}\%$, rounded to nearest tenth (round-
half-up). The value 66.6% corresponds to the interval $[66.55, 66.65)$, giving:

$$\frac{j}{n} \in [0.6655, 0.6665) = \left[\frac{1331}{2000}, \frac{1333}{2000}\
right)$$

**Count per plant:** For plant $n$, the number of qualifying units is:
$$f(n) = \left\lceil \frac{1333n}{2000} \right\rceil - \left\lceil \frac{1331n}{
2000} \right\rceil$$

(counting integers $j$ in $[1331n/2000, 1333n/2000)$).

## Decomposing the Sum

Write $n = 2000q + r$ with $0 \le r < 2000$. Then:
$$f(n) = 2q + h(r), \quad \text{where } h(r) = \left\lceil \frac{1333r}{2000} \r
ight\rceil - \left\lceil \frac{1331r}{2000} \right\rceil$$

The range $n \in [2000, 10000]$ decomposes as:
- $q = 1,2,3,4$ with $r = 0,\ldots,1999$ each (8000 values)
- $q = 5, r = 0$ (i.e., $n = 10000$, giving $f = 10$)

## Computing $H = \sum_{r=0}^{1999} h(r)$

Using the identity $\sum_{r=0}^{N-1} \left\lceil \frac{kr}{N} \right\rceil = \fr
ac{kN - k + N - \gcd(k,N)}{2}$ (derived from the floor-sum formula $\sum \lfloor
 kr/N \rfloor = \frac{(k-1)(N-1)+\gcd(k,N)-1}{2}$ plus counting non-integer term
s):

**Key GCDs:** $2000 = 2^4 \cdot 5^3$. Since $1331 = 11^3$ and $1333 = 31 \times
43$, neither shares factors with 2000, so $\gcd(1331, 2000) = \gcd(1333, 2000) =
 1$.

$$\sum_{r=0}^{1999} \left\lceil \frac{1333r}{2000} \right\rceil = \frac{1333 \cd
ot 2000 - 1333 + 2000 - 1}{2} = \frac{2666666}{2} = 1333333$$

$$\sum_{r=0}^{1999} \left\lceil \frac{1331r}{2000} \right\rceil = \frac{1331 \cd
ot 2000 - 1331 + 2000 - 1}{2} = \frac{2662668}{2} = 1331334$$

$$H = 1333333 - 1331334 = 1999$$

## Computing the Sums

**Total qualifying units ($n = 2000$ to $10000$):**
$$S_1 = \sum_{q=1}^{4}(4000q + H) + 10 = 4000 \cdot 10 + 4 \cdot 1999 + 10 = 400
00 + 7996 + 10 = 48006$$

**Qualifying units with $k \ge 6000$ ($n = 6000$ to $10000$):**
$$S_2 = \sum_{q=3}^{4}(4000q + H) + 10 = 4000 \cdot 7 + 2 \cdot 1999 + 10 = 2800
0 + 3998 + 10 = 32008$$

**Sanity check:** $\sum_{n=2000}^{10000} \frac{n}{1000} = \frac{12000 \times 800
1}{2000} = 48006 = S_1$ ✓
$\sum_{n=6000}^{10000} \frac{n}{1000} = \frac{16000 \times 4001}{2000} = 32008 =
 S_2$ ✓

(The corrections from $h(r)$ average out perfectly since $H = 1999$ balances the
 rounding effects.)

## Reducing the Fraction

$$\frac{S_2}{S_1} = \frac{32008}{48006} = \frac{16004}{24003}$$

**GCD verification** (Euclidean algorithm):
- $24003 = 1 \times 16004 + 7999$
- $16004 = 2 \times 7999 + 6$
- $7999 = 1333 \times 6 + 1$
- $6 = 6 \times 1 + 0$

$\gcd(16004, 24003) = 1$, so the fraction is already irreducible.

## Result

With $a = 16004$ and $b = 24003$:

$$a + b = \boxed{40007}$$
