## Solution

We compute
$$L = \lim_{n\to\infty}\int_{[0,1]}\left(n\sin\!\left(\frac{x}{n}\right)\right)^
n dx.$$

**Step 1: Pointwise limit.** Fix $x\in[0,1]$. Using the Taylor expansion $\sin t
 = t - t^3/6 + O(t^5)$,

$$n\sin\!\left(\frac{x}{n}\right) = x - \frac{x^3}{6n^2} + O\!\left(\frac{1}{n^4
}\right).$$

- **For $x\in[0,1)$:** Since $\sin t < t$ for $t>0$, we have $0 \le n\sin(x/n) <
 x$ for all $n$. Hence
$$0 \le \left(n\sin\!\left(\frac{x}{n}\right)\right)^n < x^n \xrightarrow{n\to\i
nfty} 0,$$
so $f_n(x)\to 0$.

- **For $x=0$:** $f_n(0)=0$ for all $n$.

- **For $x=1$:**
$$f_n(1)=\left(n\sin\!\left(\frac1n\right)\right)^n = \left(1-\frac{1}{6n^2}+O\!
\left(\frac1{n^4}\right)\right)^n.$$
Taking logarithms, $n\log\!\left(1-\frac{1}{6n^2}+O(n^{-4})\right) = n\!\left(-\
frac{1}{6n^2}+O(n^{-4})\right) = -\frac{1}{6n}+O(n^{-3})\to 0$, so $f_n(1)\to e^
0=1$.

Therefore $f_n(x)\to g(x)$ pointwise, where $g(x)=0$ for $x\in[0,1)$ and $g(1)=1
$. Since $\{1\}$ has Lebesgue measure zero, **$f_n\to 0$ a.e. on $[0,1]$**.

**Step 2: Dominating function.** For $t\ge 0$, $\sin t\le t$, so for $x\in[0,1]$
 and all $n\ge 1$:
$$0\le n\sin\!\left(\frac{x}{n}\right)\le n\cdot\frac{x}{n}=x\le 1.$$
Raising to the $n$-th power (all terms non-negative):
$$0\le f_n(x)=\left(n\sin\!\left(\frac{x}{n}\right)\right)^n \le x^n \le 1.$$

The constant function $h(x)=1$ is integrable on $[0,1]$ (with $\int_{[0,1]}1\,dx
=1<\infty$), and $|f_n(x)|\le h(x)$ for all $x\in[0,1]$ and all $n$.

**Step 3: Apply the Lebesgue Dominated Convergence Theorem.** The sequence $\{f_
n\}$ satisfies:
1. $f_n$ is measurable on $[0,1]$ for each $n$ (continuous, in fact);
2. $f_n\to 0$ a.e. on $[0,1]$;
3. $|f_n|\le 1\in L^1([0,1])$ for all $n$.

By the DCT,
$$L = \lim_{n\to\infty}\int_{[0,1]} f_n(x)\,dx = \int_{[0,1]}\lim_{n\to\infty}f_
n(x)\,dx = \int_{[0,1]} 0\,dx = 0.$$

$$\boxed{\lim_{n\to\infty}\int_{[0,1]}\left(n\sin\!\left(\frac{x}{n}\right)\righ
t)^n dx = 0.}$$
