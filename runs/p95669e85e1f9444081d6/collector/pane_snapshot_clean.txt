## Proof

**Step 1: Rewrite the general term using the given identity.**

Recall $\binom{2n}{n} = \frac{(2n)!}{n!^2}$, so

$$\frac{2^n}{(2n+1)\binom{2n}{n}} = \frac{2^n\, n!^2}{(2n+1)!}.$$

The given identity (with $k=n$) is

$$\int_0^{\pi/2}\sin^{2n+1}x\,dx = \frac{2^{2n}\,n!^2}{(2n+1)!},$$

hence

$$\frac{n!^2}{(2n+1)!} = \frac{1}{2^{2n}}\int_0^{\pi/2}\sin^{2n+1}x\,dx.$$

Therefore each term becomes

$$\frac{2^n\, n!^2}{(2n+1)!} = \frac{2^n}{2^{2n}}\int_0^{\pi/2}\sin^{2n+1}x\,dx
= \frac{1}{2^n}\int_0^{\pi/2}\sin^{2n+1}x\,dx.$$

**Step 2: Sum and interchange.**

$$S = \sum_{n=0}^{\infty}\frac{1}{2^n}\int_0^{\pi/2}\sin^{2n+1}x\,dx = \int_0^{\
pi/2}\sum_{n=0}^{\infty}\frac{\sin^{2n+1}x}{2^n}\,dx,$$

where the interchange is justified by Tonelli's theorem since every term is non-
negative.

**Step 3: Evaluate the inner geometric series.**

$$\sum_{n=0}^{\infty}\frac{\sin^{2n+1}x}{2^n} = \sin x\sum_{n=0}^{\infty}\left(\
frac{\sin^2 x}{2}\right)^n = \sin x\cdot\frac{1}{1-\frac{\sin^2 x}{2}} = \frac{2
\sin x}{2-\sin^2 x},$$

valid since $0\le \sin^2 x/2 \le 1/2 < 1$.

**Step 4: Compute the resulting integral.**

Using $\sin^2 x = 1-\cos^2 x$,

$$S = \int_0^{\pi/2}\frac{2\sin x}{1+\cos^2 x}\,dx.$$

Substitute $u=\cos x$, $du=-\sin x\,dx$, with $x:0\to\pi/2$ giving $u:1\to 0$:

$$S = \int_0^1\frac{2}{1+u^2}\,du = 2\arctan u\Big|_0^1 = 2\cdot\frac{\pi}{4} =
\frac{\pi}{2}.$$

$$\boxed{\displaystyle\sum_{n=0}^{\infty}\frac{2^n}{(2n+1)\binom{2n}{n}} = \frac
{\pi}{2}}$$
