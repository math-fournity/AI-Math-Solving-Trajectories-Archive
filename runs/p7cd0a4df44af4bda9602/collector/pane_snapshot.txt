答案：存在

证明

我们要证明：存在一个奇异基数 $\lambda$，使得对任意基数 $\kappa < \lambda$，都有
$2^\kappa < \lambda$。

满足"对任意 $\kappa < \lambda$，$2^\kappa < \lambda$"的基数 $\lambda$ 称为强极限
基数（strong limit cardinal）。因此问题等价于：是否存在奇异的强极限基数。

────────────────────────────────────────────────────────────────────────────────

构造 $\beth_\omega$

定义 Beth 数列：

  • $\beth_0 = \aleph_0$，
  • $\beth_{n+1} = 2^{\beth_n}$（对每个自然数 $n$），
  • $\beth_\omega = \sup_{n < \omega} \beth_n$。

由于 $\beth_0 = \aleph_0$，且 $\beth_{n+1} = 2^{\beth_n} > \beth_n$（由 Cantor
定理），数列 ${\beth_n}{n<\omega}$ 严格递增。因此 $\beth\omega$ 是一个极限基数。

────────────────────────────────────────────────────────────────────────────────

$\beth_\omega$ 是强极限基数

设 $\kappa < \beth_\omega$。由于 $\beth_\omega = \sup_{n<\omega} \beth_n$ 且数列
严格递增，存在某个 $n < \omega$ 使得 $\kappa < \beth_n$。于是

$$2^\kappa \leq 2^{\beth_n} = \beth_{n+1} < \beth_\omega,$$

其中最后一步是因为 $\beth_{n+1}$ 是 ${\beth_m}{m<\omega}$ 中的一项，严格小于其上
确界 $\beth\omega$。因此对任意 $\kappa < \beth_\omega$，$2^\kappa <
\beth_\omega$，即 $\beth_\omega$ 是强极限基数。

────────────────────────────────────────────────────────────────────────────────

$\beth_\omega$ 是奇异基数

数列 ${\beth_n : n < \omega}$ 是 $\beth_\omega$ 中的一个严格递增、长度为 $
\omega$ 的共尾序列，因此

$$\operatorname{cf}(\beth_\omega) \leq \omega.$$

另一方面，$\beth_\omega$ 是极限基数（非后继基数），故 $\operatorname{cf}
(\beth_\omega) \geq \omega$。综上 $\operatorname{cf}(\beth_\omega) = \omega$。

而 $\omega = \aleph_0 < \beth_\omega$（因为 $\beth_\omega \geq \beth_1 =
2^{\aleph_0} > \aleph_0$），所以

$$\operatorname{cf}(\beth_\omega) = \omega < \beth_\omega.$$

因此 $\beth_\omega$ 是奇异基数。

────────────────────────────────────────────────────────────────────────────────

结论

$\lambda = \beth_\omega$ 是一个奇异基数，且对任意 $\kappa < \lambda$ 都有
$2^\kappa < \lambda$。故这样的奇异基数存在。
