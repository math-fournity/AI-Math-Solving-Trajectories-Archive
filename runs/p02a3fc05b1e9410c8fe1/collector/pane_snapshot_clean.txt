# Prime Ideal Factorization of $p\mathcal{O}_K$ in $K = \mathbb{Q}(\theta)$, $\t
heta^3 - 4\theta + 7 = 0$

## Setup: Discriminant and the Index

The minimal polynomial is $f(X) = X^3 - 4X + 7$. Using the formula $\Delta = -4p
^3 - 27q^2$ for $X^3 + pX + q$ (here $p = -4$, $q = 7$):

$$\Delta(f) = -4(-4)^3 - 27(7)^2 = 256 - 1323 = -1067 = -11 \times 97.$$

Since $1067 = 11 \times 97$ is squarefree, the index $[\mathcal{O}_K : \mathbb{Z
}[\theta]]$ satisfies $[\mathcal{O}_K:\mathbb{Z}[\theta]]^2 \mid 1067$, forcing
$[\mathcal{O}_K:\mathbb{Z}[\theta]] = 1$. Thus $\mathcal{O}_K = \mathbb{Z}[\thet
a]$ and $\text{disc}(K) = -1067$.

**Dedekind's theorem applies directly for every prime $p$**, since no prime divi
des the index. The factorization of $p\mathcal{O}_K$ is obtained by factoring $\
bar{f}(X) = f(X) \bmod p$ in $\mathbb{F}_p[X]$: if $\bar{f} = \prod \bar{g}_i^{e
_i}$, then $p\mathcal{O}_K = \prod \mathfrak{p}_i^{e_i}$ with $\mathfrak{p}_i =
(p, g_i(\theta))$ and $N(\mathfrak{p}_i) = p^{\deg g_i}$.

---

## $p = 2$

$$\bar{f}(X) = X^3 + 1 = (X+1)(X^2+X+1) \pmod{2}.$$

$X^2+X+1$ has no roots in $\mathbb{F}_2$ (both $0$ and $1$ give value $1$), so i
t is irreducible.

$$\boxed{2\mathcal{O}_K = \mathfrak{p}_1 \cdot \mathfrak{p}_2, \quad \mathfrak{p
}_1 = (2,\,\theta+1),\; N(\mathfrak{p}_1)=2; \quad \mathfrak{p}_2 = (2,\,\theta^
2+\theta+1),\; N(\mathfrak{p}_2)=4.}$$

## $p = 3$

$$\bar{f}(X) = X^3 + 2X + 1 \pmod{3}.$$

Testing all residues: $f(0)=1$, $f(1)=1+2+1=4\equiv 1$, $f(2)=8+4+1=13\equiv 1$.
 No roots, so the cubic is irreducible over $\mathbb{F}_3$.

$$\boxed{3\mathcal{O}_K = (3) \text{ is prime (inert)}, \quad N((3)) = 27.}$$

## $p = 5$

$$\bar{f}(X) = X^3 + X + 2 \pmod{5}.$$

Testing: $f(4) = 64 + 4 + 2 = 70 \equiv 0 \pmod{5}$, so $X = 4 \equiv -1$ is a r
oot. Dividing $\bar{f}$ by $(X+1)$:

$$\bar{f}(X) = (X+1)(X^2 + 4X + 2) \pmod{5}.$$

The quadratic $X^2+4X+2$ has discriminant $16 - 8 = 8 \equiv 3 \pmod{5}$. The qu
adratic residues mod $5$ are $\{1, 4\}$; $3$ is not a residue, so the quadratic
is irreducible.

$$\boxed{5\mathcal{O}_K = \mathfrak{p}_1 \cdot \mathfrak{p}_2, \quad \mathfrak{p
}_1 = (5,\,\theta+1),\; N(\mathfrak{p}_1)=5; \quad \mathfrak{p}_2 = (5,\,\theta^
2+4\theta+2),\; N(\mathfrak{p}_2)=25.}$$

## $p = 7$

$$\bar{f}(X) = X^3 - 4X = X(X^2 - 4) = X(X-2)(X+2) \pmod{7}.$$

Three distinct linear factors.

$$\boxed{7\mathcal{O}_K = \mathfrak{p}_1 \cdot \mathfrak{p}_2 \cdot \mathfrak{p}
_3, \quad \mathfrak{p}_1=(7,\,\theta),\;\mathfrak{p}_2=(7,\,\theta-2),\;\mathfra
k{p}_3=(7,\,\theta+2), \quad N(\mathfrak{p}_i)=7.}$$

## $p = 11$ (ramified)

$$\bar{f}(X) = X^3 - 4X + 7 \pmod{11}.$$

Testing: $f(3) = 27 - 12 + 7 = 22 \equiv 0 \pmod{11}$, so $X = 3$ is a root. Div
iding by $(X - 3)$:

$$\bar{f}(X) = (X-3)(X^2 + 3X + 5) \pmod{11}.$$

The quadratic $X^2+3X+5$ has discriminant $9 - 20 = -11 \equiv 0 \pmod{11}$, so
it has a double root. Solving $2r \equiv -3 \pmod{11}$ gives $r \equiv -3 \cdot
6 \equiv 4 \pmod{11}$. Verification: $g(4) = 16+12+5 = 33 \equiv 0$, and $g'(4)
= 2\cdot4+3 = 11 \equiv 0$. So:

$$\bar{f}(X) = (X-3)(X-4)^2 \pmod{11}.$$

Since $\mathcal{O}_K = \mathbb{Z}[\theta]$ (index $1$, verified above), Dedekind
's theorem applies directly even at the ramified prime $11$:

$$\boxed{11\mathcal{O}_K = \mathfrak{p}_1 \cdot \mathfrak{p}_2^2, \quad \mathfra
k{p}_1 = (11,\,\theta-3),\; N(\mathfrak{p}_1)=11; \quad \mathfrak{p}_2 = (11,\,\
theta-4),\; N(\mathfrak{p}_2)=11.}$$

The prime $11$ is ramified: $\mathfrak{p}_2$ appears with exponent $2$. This is
consistent with $11 \mid \text{disc}(K) = -1067$.

---

## Summary

| $p$ | Factorization type | $\bar{f}(X) \bmod p$ | $p\mathcal{O}_K$ |
|-----|-------------------|----------------------|-------------------|
| $2$ | $(1)(2)$ | $(X+1)(X^2{+}X{+}1)$ | $\mathfrak{p}_1\mathfrak{p}_2$, norms
$2, 4$ |
| $3$ | $(3)$ | irreducible | $(3)$ inert, norm $27$ |
| $5$ | $(1)(2)$ | $(X{+}1)(X^2{+}4X{+}2)$ | $\mathfrak{p}_1\mathfrak{p}_2$, nor
ms $5, 25$ |
| $7$ | $(1)(1)(1)$ | $X(X{-}2)(X{+}2)$ | $\mathfrak{p}_1\mathfrak{p}_2\mathfrak
{p}_3$, norms $7,7,7$ |
| $11$ | $(1)(2)$ | $(X{-}3)(X{-}4)^2$ | $\mathfrak{p}_1\mathfrak{p}_2^2$, norms
 $11, 11$ (ramified) |

The only ramified prime among $\{2,3,5,7,11\}$ is $11$, which divides $\text{dis
c}(K) = -1067 = -11 \times 97$.
