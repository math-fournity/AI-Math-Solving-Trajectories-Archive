Looking at this problem, I need to find all bases $b \geq 9$ such that the given
 number divided by 3 is a perfect cube for all sufficiently large $n$.

## Setting Up the Formula

The number in base $b$ has $3n$ digits: $(n-1)$ ones, one 0, $(n-1)$ sevens, one
 8, and $n$ ones. Let $x = b^n$ and $S_k = \frac{b^k - 1}{b-1}$. Computing the v
alue:

$$N_n = S_n + 8b^n + 7b^{n+1}S_{n-1} + b^{2n+1}S_{n-1}$$

Substituting $S_n = \frac{x-1}{b-1}$ and $S_{n-1} = \frac{x-b}{b(b-1)}$, after a
lgebraic simplification:

$$N_n = \frac{x^3 - (b-7)x^2 + (b-7)x - 1}{b-1}$$

Setting $c = b - 7$ and $P(x) = x^3 - cx^2 + cx - 1 = (x-1)(x^2 - (c-1)x + 1)$,
we need:

$$\frac{N_n}{3} = \frac{P(b^n)}{3(b-1)} \text{ to be a perfect cube for all larg
e } n.$$

## Necessary Condition: $3(b-1)$ is a perfect cube

Since $P(b^n) \sim b^{3n}$, if $P(b^n)/(3(b-1)) = m_n^3$, then $m_n \sim b^n / (
3(b-1))^{1/3}$.

A precise expansion gives $P(b^n)^{1/3} = b^n - a + O(b^{-n})$ where $a = (b-7)/
3$, so $m_n \cdot (3(b-1))^{1/3} = b^n - a + O(b^{-n})$.

Setting $k_n = m_{n+1} - b \cdot m_n$ (an integer), we get $k_n \cdot (3(b-1))^{
1/3} = a(b-1) + O(b^{-n}) \to a(b-1)$. Since $k_n$ is an integer converging to a
 fixed value, it is eventually constant, forcing $(3(b-1))^{1/3}$ to be rational
. Thus $3(b-1) = d^3$ for some integer $d$, giving $b = 9e^3 + 1$ (with $d = 3e$
).

## Reducing to $P(b^n)$ being a perfect cube

With $3(b-1) = d^3$, the condition becomes $P(b^n) = (d \cdot m_n)^3$, so $P(b^n
)$ must be a perfect cube.

Since $P(b^n)^{1/3} = b^n - a + O(b^{-n})$ with $a = (b-7)/3 = 3e^3 - 2$ (an int
eger), for large $n$ the only possible integer cube root is $b^n - a$, requiring
:

$$P(b^n) = (b^n - a)^3 \text{ for all large } n.$$

## Comparing coefficients forces $b = 10$

We have $P(x) = x^3 - 3ax^2 + 3ax - 1$ and $(x-a)^3 = x^3 - 3ax^2 + 3a^2 x - a^3
$.

For these to be equal as polynomials (hence equal for all $x = b^n$):
- Coefficient of $x$: $3a = 3a^2 \Rightarrow a(a-1) = 0$
- Constant term: $-1 = -a^3 \Rightarrow a = 1$

So $a = 1$, giving $3e^3 - 2 = 1 \Rightarrow e = 1 \Rightarrow b = 10$.

For $e \geq 2$ (e.g., $b = 73$), $P(x) - (x-a)^3 = 3a(1-a)x + (a^3 - 1) \neq 0$,
 so $P(b^n) \neq (b^n - a)^3$, and the residual $R(b^n) = 3a(1-a)b^n + (a^3-1)$
satisfies $|R(b^n)| < 3(b^n - a)^2$ for large $n$, making it impossible for $P(b
^n)$ to equal any other perfect cube (any such cube would require $|\delta| < 1$
 where $\delta$ is a nonzero integer — contradiction).

## Verification that $b = 10$ works

With $b = 10$: $c = 3$, $P(x) = x^3 - 3x^2 + 3x - 1 = (x-1)^3$, and $3(b-1) = 27
 = 3^3$.

$$\frac{N_n}{3} = \frac{(10^n - 1)^3}{27} = \left(\frac{10^n - 1}{3}\right)^3$$

Since $10 \equiv 1 \pmod{3}$, we have $3 \mid (10^n - 1)$ for all $n \geq 1$, so
 $\frac{10^n - 1}{3}$ is a positive integer and $\frac{N_n}{3}$ is a perfect cub
e for all $n \geq 1$.

## Conclusion

The only positive integer base $b \geq 9$ satisfying the condition is:

$$\boxed{10}$$
