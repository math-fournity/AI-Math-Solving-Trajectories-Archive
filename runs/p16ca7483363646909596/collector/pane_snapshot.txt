## Solution

We need positive integers $p$ (priority crates) and $f$ (fuel units) such that:

$$\frac{p+3}{f+2} < \frac{p}{f}$$

Since all quantities are positive, cross-multiplication preserves the inequality

$$p(f+2) < (p+3)f$$
$$pf + 2p < pf + 3f$$
$$2p < 3f$$
$$\frac{p}{f} < \frac{3}{2}$$

So we need the original ratio $p/f < 3/2$.
