## Proof

We show that for every fixed $\alpha \in (0,1)$, there exists a convex function
$\Phi:\mathbb{R}_{++}\to\mathbb{R}$ making $g$ constant on $[1,2]$. In fact, an
**affine** (hence convex) function suffices.

### Construction

Set $\Phi(x) = ax + b$ where $a \in \mathbb{R}$ is arbitrary and
$$b = -\frac{a}{2-\alpha}.$$
This is well-defined since $\alpha \in (0,1)$ gives $2-\alpha \in (1,2)\neq 0$.
An affine function is convex, so $\Phi$ is a valid convex function on $\mathbb{R
}_{++}$.

### Verification

Compute each term:
$$\Phi\!\left(\tfrac{1}{t}+1\right) = a\!\left(\tfrac{1}{t}+1\right)+b = \tfrac{
a}{t}+a+b,$$
$$\Phi\!\left(\tfrac{1}{t}+\tfrac{1}{2}\right) = a\!\left(\tfrac{1}{t}+\tfrac{1}
{2}\right)+b = \tfrac{a}{t}+\tfrac{a}{2}+b.$$

Substituting into $g$:
$$g(t) = \alpha t\!\left(\tfrac{a}{t}+a+b\right) + 2(1-\alpha)\,t\!\left(\tfrac{
a}{t}+\tfrac{a}{2}+b\right)$$
$$= \alpha\bigl(a+(a+b)\,t\bigr) + 2(1-\alpha)\bigl(a+(\tfrac{a}{2}+b)\,t\bigr)$
$
$$= a\bigl[\alpha+2(1-\alpha)\bigr] + t\bigl[\alpha(a+b)+2(1-\alpha)(\tfrac{a}{2
}+b)\bigr]$$
$$= a(2-\alpha) + t\bigl[\alpha a+\alpha b+(1-\alpha)a+2(1-\alpha)b\bigr]$$
$$= a(2-\alpha) + t\bigl[a + b\bigl(\alpha+2(1-\alpha)\bigr)\bigr]$$
$$= a(2-\alpha) + t\bigl[a+b(2-\alpha)\bigr].$$

Now apply $b = -a/(2-\alpha)$:
$$a + b(2-\alpha) = a - \frac{a}{2-\alpha}\cdot(2-\alpha) = a - a = 0.$$

Therefore
$$\boxed{g(t) = a(2-\alpha) \quad \text{for all } t\in[1,2],}$$
which is constant. $\qquad\blacksquare$
