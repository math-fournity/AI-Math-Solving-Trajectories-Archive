## Proof

The answer is **No** for $n \geq 2$. We construct a counterexample.

### Construction

Define $h, g: \mathbb{R} \to \mathbb{R}$ by:
$$h(s) = \begin{cases} e^{-1/s^2} & s > 0 \\ 0 & s \leq 0 \end{cases}, \qquad g(
s) = \begin{cases} e^{-3/s^2} & s > 0 \\ 0 & s \leq 0 \end{cases}$$

Both are $C^\infty$ and flat at $s=0$ (all derivatives vanish). Define $f: \math
bb{R}^n \to \mathbb{R}$ ($n \geq 2$):
$$f(x_1, x_2, \ldots, x_n) = (x_2 - h(x_1))^2 + x_3^2 + \cdots + x_n^2 - g(x_1).
$$

Then $f \in C^\infty(\mathbb{R}^n)$ and $f(0) = 0$.

### $0$ is not a local minimum

For $s > 0$, evaluate at $(s,\, h(s),\, 0, \ldots, 0)$:
$$f(s, h(s), 0, \ldots, 0) = 0 + 0 - g(s) = -e^{-3/s^2} < 0,$$
and $(s, h(s), 0, \ldots, 0) \to 0$ as $s \to 0^+$. So $0$ is not a local minimu
m.

### $0$ is a local minimum on every algebraic curve

Let $C$ be an algebraic curve with $0 \in C$. By the local structure theorem for
 real algebraic varieties, near $0$, $C$ consists of finitely many branches, eac
h parametrized by convergent Puiseux series: $\gamma(t) = (x_1(t), \ldots, x_n(t
))$ with $\gamma(0)=0$.

**Key fact:** For any $q > 0$ and $A > 0$, $A\, s^q \gg e^{-1/s^2}$ as $s \to 0^
+$, since $e^{-1/s^2}/s^q = e^{-1/s^2 + q\ln(1/s)} \to 0$ (as $1/s^2$ dominates
$q\ln(1/s)$). Likewise $e^{-3/s^2} = o(s^q)$ for every $q > 0$.

We show $f \geq 0$ on each branch near $0$.

**Case 1: $x_1(t) \equiv 0$.** Then $h(x_1) = g(x_1) = 0$, so $f = x_2^2 + \cdot
s + x_n^2 \geq 0$. ✓

**Case 2: $x_1(t) \not\equiv 0$.** Write $x_1(t) = a\, t^p + \text{h.o.t.}$ with
 $a \neq 0$, $p > 0$ rational. Near $0$, $x_1$ has a definite sign on the branch
.

*Sub-case 2a: $x_1 \leq 0$ near $0$.* Then $h(x_1) = g(x_1) = 0$, so $f = x_2^2
+ \cdots + x_n^2 \geq 0$. ✓

*Sub-case 2b: $x_1 > 0$ near $0$.* Express each $x_i$ ($i \geq 2$) as a Puiseux
series in $x_1$: either $x_i \equiv 0$ or $x_i = c_i\, x_1^{q_i} + \text{h.o.t.}
$ with $c_i \neq 0$, $q_i > 0$.

- **All $x_i \equiv 0$ for $i \geq 2$** (branch along $x_1$-axis):
$$f = h(x_1)^2 - g(x_1) = e^{-2/x_1^2} - e^{-3/x_1^2} = e^{-2/x_1^2}\!\left(1 -
e^{-1/x_1^2}\right) > 0 \quad \text{for } x_1 > 0. \checkmark$$

- **$x_2 \not\equiv 0$:** Then $|x_2| \geq \frac{|c_2|}{2}\, x_1^{q_2}$ for smal
l $x_1 > 0$. By the key fact, $x_1^{q_2} \gg e^{-1/x_1^2} = h(x_1)$, so $|x_2 -
h(x_1)| \geq |x_2| - h(x_1) \geq \frac{|c_2|}{4}\, x_1^{q_2}$. Thus:
$$f \geq \frac{c_2^2}{16}\, x_1^{2q_2} - e^{-3/x_1^2} > 0$$
for small $x_1 > 0$, since $x_1^{2q_2} \gg e^{-3/x_1^2}$. ✓

- **$x_2 \equiv 0$ but some $x_j \not\equiv 0$ ($j \geq 3$):** Then $x_j^2 \geq
C\, x_1^{2q_j}$ for some $C, q_j > 0$, and:
$$f \geq C\, x_1^{2q_j} - e^{-3/x_1^2} > 0$$
for small $x_1 > 0$ by the key fact. ✓

In every case, $f \geq 0$ on each branch near $0$. Since $C$ has finitely many b
ranches through $0$, there exists $\epsilon > 0$ (the minimum over all branches)
 such that $f \geq 0 = f(0)$ on $C \cap B_\epsilon(0)$.

### Conclusion

The function $f$ satisfies the hypothesis — $0$ is a local minimum on every alge
braic curve — yet $0$ is **not** a local minimum of $f$. The essential mechanism
 is that the "bad set" $\{f < 0\}$ lies in an exponentially thin tube around the
 transcendental (flat) curve $x_2 = e^{-1/x_1^2}$, which no algebraic curve can
enter near $0$, because every algebraic branch has polynomial (Puiseux) asymptot
ics that dominate any flat function.

For $n = 1$ the statement is trivially true (the only algebraic curve in $\mathb
b{R}$ is $\mathbb{R}$ itself), but for every $n \geq 2$ the answer is **No**.
