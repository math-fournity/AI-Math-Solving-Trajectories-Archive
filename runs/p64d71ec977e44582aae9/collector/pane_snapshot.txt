 normal tracial state on $R$. We provide an explicit counterexample.

**Counterexample.** Let $R = M_2(\mathbb{C})$, which is a finite von Neumann alg
ebra (it is a finite factor). Let $S \subset R$ be the von Neumann subalgebra of
 diagonal matrices:
$$S = \left\{\begin{pmatrix} \alpha & 0 \\ 0 & \beta \end{pmatrix} : \alpha, \be
ta \in \mathbb{C}\right\} \cong \mathbb{C} \oplus \mathbb{C}.$$

Since $S$ is abelian, every normal state on $S$ is automatically tracial. Define
 the normal state $\tau$ on $S$ by
$$\tau\!\begin{pmatrix} \alpha & 0 \\ 0 & \beta \end{pmatrix} = \alpha.$$
This is a normal tracial state on $S$ (it is the state corresponding to the poin
t mass at the first coordinate under the identification $S \cong \mathbb{C}^2$).

Now we ask: can $\tau$ be extended to a normal tracial state $\tilde{\tau}$ on $
R = M_2(\mathbb{C})$?

Since $M_2(\mathbb{C})$ is a factor, it admits a **unique** tracial state, namel
y the normalized trace
$$\operatorname{tr}(A) = \tfrac{1}{2}\operatorname{Tr}(A).$$
(Uniqueness: any tracial state $\sigma$ on a factor satisfies $\sigma(p) = \sigm
a(q)$ for any two equivalent projections $p, q$; in $M_2(\mathbb{C})$ all rank-o
ne projections are equivalent, so $\sigma(p) = 1/2$ for every rank-one projectio
n, which forces $\sigma = \operatorname{tr}$.)

The restriction of this unique tracial state to $S$ is
$$\operatorname{tr}\!\begin{pmatrix} \alpha & 0 \\ 0 & \beta \end{pmatrix} = \tf
rac{1}{2}(\alpha + \beta).$$

For $\tau$ to extend, we would need $\alpha = \tfrac{1}{2}(\alpha + \beta)$ for
all $\alpha, \beta$, which is false (e.g., take $\alpha = 1, \beta = 0$: $1 \neq
 \tfrac{1}{2}$).

Therefore $\tau$ is a normal tracial state on $S$ that **cannot** be extended to
 any normal tracial state on $R$. $\blacksquare$

**Remark.** The obstruction is that $R = M_2(\mathbb{C})$, being a factor, has a
 unique tracial state, and this unique trace imposes the "balanced" weighting $\
lambda = 1/2$ on the two minimal central projections of $S$. Any normal tracial
state on $S \cong \mathbb{C}^2$ with an unbalanced weight $\lambda \neq 1/2$ fai
ls to extend.
