## Solution

**Step 1: Extract the Dirichlet integral from the given Fourier transform.**

We are given $f(x) = (1-2|x|)\chi_{[-1/2,\,1/2]}(x)$ with $\hat{f}(t) = \dfrac{8
\sin^2(t/4)}{t^2}$.

By the Fourier inversion formula, $f(0) = \dfrac{1}{2\pi}\displaystyle\int_{\mat
hbb{R}} \hat{f}(t)\,dt$. Since $f(0) = 1$:

$$\int_{\mathbb{R}} \frac{8\sin^2(t/4)}{t^2}\,dt = 2\pi.$$

Substituting $u = t/4$ (so $t = 4u$, $dt = 4\,du$):

$$\int_{\mathbb{R}} \frac{8\sin^2 u}{16u^2}\cdot 4\,du = 2\pi \implies 2\int_{\m
athbb{R}} \frac{\sin^2 u}{u^2}\,du = 2\pi \implies \int_0^\infty \frac{\sin^2 u}
{u^2}\,du = \frac{\pi}{2}.$$

**Integration by parts** on this ($v = \sin^2 u$, $dw = u^{-2}du$, $w = -1/u$):

$$\frac{\pi}{2} = \left[-\frac{\sin^2 u}{u}\right]_0^\infty + \int_0^\infty \fra
c{2\sin u\cos u}{u}\,du = \int_0^\infty \frac{\sin(2u)}{u}\,du.$$

With $v = 2u$, this yields the **Dirichlet integral**:

$$\int_0^\infty \frac{\sin v}{v}\,dv = \frac{\pi}{2}. \tag{$\star$}$$

---

**Step 2: Reduce the target integral via substitution.**

$$I := \int_{\mathbb{R}} \frac{\sin^4(t/2)}{t^2}\,dt.$$

Substitute $u = t/2$ ($dt = 2\,du$, $t^2 = 4u^2$):

$$I = \int_{\mathbb{R}} \frac{\sin^4 u}{4u^2}\cdot 2\,du = \frac{1}{2}\int_{\mat
hbb{R}} \frac{\sin^4 u}{u^2}\,du = \int_0^\infty \frac{\sin^4 u}{u^2}\,du.$$

---

**Step 3: Integration by parts on $\displaystyle\int_0^\infty \frac{\sin^4 u}{u^
2}\,du$.**

Set $v = \sin^4 u$, $dw = u^{-2}du$, so $w = -1/u$ and $dv = 4\sin^3 u\cos u\,du
$:

$$I = \left[-\frac{\sin^4 u}{u}\right]_0^\infty + \int_0^\infty \frac{4\sin^3 u\
cos u}{u}\,du.$$

The boundary term vanishes (at $0$: $\sin^4 u/u \to 0$; at $\infty$: $|\sin^4 u/
u| \le 1/u \to 0$), so:

$$I = 4\int_0^\infty \frac{\sin^3 u\cos u}{u}\,du.$$

---

**Step 4: Product-to-sum decomposition.**

$$\sin^3 u\cos u = \sin u\cos u\cdot\sin^2 u = \frac{1}{2}\sin(2u)\cdot\frac{1-\
cos(2u)}{2} = \frac{1}{4}\sin(2u) - \frac{1}{4}\sin(2u)\cos(2u).$$

Using $\sin(2u)\cos(2u) = \tfrac{1}{2}\sin(4u)$:

$$4\sin^3 u\cos u = \sin(2u) - \tfrac{1}{2}\sin(4u).$$

Therefore:

$$I = \int_0^\infty \frac{\sin(2u)}{u}\,du - \frac{1}{2}\int_0^\infty \frac{\sin
(4u)}{u}\,du.$$

---

**Step 5: Apply the Dirichlet integral ($\star$).**

For $a > 0$, substituting $v = au$ gives $\displaystyle\int_0^\infty \frac{\sin(
au)}{u}\,du = \int_0^\infty \frac{\sin v}{v}\,dv = \frac{\pi}{2}$.

$$I = \frac{\pi}{2} - \frac{1}{2}\cdot\frac{\pi}{2} = \frac{\pi}{2} - \frac{\pi}
{4} = \frac{\pi}{4}.$$

---

$$\boxed{\displaystyle\int_{\mathbb{R}} \frac{\sin^4(t/2)}{t^2}\,dt = \frac{\pi}
{4}}$$
