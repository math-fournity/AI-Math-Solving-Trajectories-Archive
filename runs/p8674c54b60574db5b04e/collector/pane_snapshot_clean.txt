## Proof

The statement is **false**. We construct an explicit counterexample.

**Counterexample.** Let $C \subset [0,1]$ be the middle-thirds Cantor set, and d
efine
$$f(x) = \operatorname{dist}(x, C) = \inf_{c \in C} |x - c|, \qquad x \in [0,1].
$$

**Claim 1: $f$ is Lipschitz continuous on $[0,1]$.**

For any $x, y \in [0,1]$ and any $c \in C$,
$$|x - c| \le |x - y| + |y - c|.$$
Taking the infimum over $c \in C$ on the right gives $f(x) \le |x-y| + f(y)$, so
 $f(x) - f(y) \le |x-y|$. By symmetry, $|f(x) - f(y)| \le |x - y|$. Hence $f$ is
 $1$-Lipschitz (in particular, Lipschitz continuous) on $[0,1]$.

**Claim 2: The zero set of $f$ is exactly $C$.**

Clearly $f(c) = 0$ for every $c \in C$. Conversely, if $f(x) = 0$, then there ex
ists a sequence $(c_n) \subset C$ with $|x - c_n| \to 0$; since $C$ is closed, $
x \in C$. Thus
$$Z(f) = \{x : f(x) = 0\} = C.$$

**Claim 3: $Z(f) = C$ has measure zero but is infinite (indeed uncountable).**

The Cantor set is well known to have Lebesgue measure zero (it is constructed by
 removing intervals of total length $1$). It is also uncountable, with cardinali
ty equal to that of the continuum (each point corresponds to a binary sequence v
ia the ternary expansion using only digits $0$ and $2$). In particular, $C$ cont
ains infinitely many points.

**Conclusion.** The function $f(x) = \operatorname{dist}(x, C)$ is Lipschitz con
tinuous on the interval $[0,1]$, its zero set $C$ has Lebesgue measure zero, yet
 $C$ is infinite (uncountable). Therefore the statement

> "A function that is Lipschitz continuous on an interval with a set of zeros of
 measure zero must have a finite number of zeros"

is **false**. $\blacksquare$
