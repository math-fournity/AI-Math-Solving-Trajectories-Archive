## Solution

Let $X_1, X_2, \ldots, X_n$ be i.i.d. geometric random variables counting the nu
mber of failures before the first success in independent Bernoulli trials with s
uccess probability $p = \tfrac{1}{2}$. Then each $X_i$ has

$$P(X_i = k) = (1-p)^k p = \frac{1}{2^{k+1}}, \quad k = 0,1,2,\ldots$$

with mean $\mu = \frac{1-p}{p} = 1$ and variance $\sigma^2 = \frac{1-p}{p^2} = 2
$.

Let $X = X_1 + \cdots + X_n$ be the total number of failures before the $n$-th s
uccess. The negative binomial distribution gives

$$P(X = j) = \binom{j+n-1}{j} p^n (1-p)^j = \binom{j+n-1}{j}\frac{1}{2^{n+j}}.$$

Therefore the given sum is

$$S_n = \sum_{j=0}^{n}\binom{j+n-1}{j}\frac{1}{2^{n+j}} = P(X \le n) = P\!\left(
\frac{X - n}{\sqrt{2n}} \le 0\right),$$

since $E[X] = n\mu = n$ and $\operatorname{Var}(X) = n\sigma^2 = 2n$.

By the **Central Limit Theorem**, $\dfrac{X - n}{\sqrt{2n}} \xrightarrow{d} N(0,
1)$. Hence

$$\lim_{n\to\infty} S_n = \lim_{n\to\infty} P\!\left(\frac{X-n}{\sqrt{2n}} \le 0
\right) = \Phi(0) = \frac{1}{2}.$$

$$\boxed{\displaystyle \lim_{n\to\infty}\sum_{j=0}^{n}\binom{j+n-1}{j}\frac{1}{2
^{n+j}} = \frac{1}{2}}$$
