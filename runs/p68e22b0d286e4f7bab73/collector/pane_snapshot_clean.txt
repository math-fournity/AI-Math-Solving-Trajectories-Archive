# Fourier Transform of the Sign Function

## Setup and conventions

We use the convention
$$\widehat{f}(\xi) = \mathcal{F}\{f\}(\xi) = \int_{-\infty}^{\infty} f(x)\,e^{-i
\xi x}\,dx,$$
with the inverse $f(x) = \dfrac{1}{2\pi}\int \widehat{f}(\xi)\,e^{i\xi x}\,d\xi$
. Under this convention $\mathcal{F}\{1\} = 2\pi\,\delta(\xi)$.

The sign function is
$$\operatorname{sgn}(x) = \begin{cases} +1, & x>0,\\ 0, & x=0,\\ -1, & x<0. \end
{cases}$$

It is not in $L^1$, so its Fourier transform must be understood in the **distrib
utional** sense.

## Regularization

For $\varepsilon>0$ define the regularized, integrable function
$$f_\varepsilon(x) = \operatorname{sgn}(x)\,e^{-\varepsilon|x|}.$$
As $\varepsilon\to 0^+$, $f_\varepsilon\to\operatorname{sgn}$ pointwise and in $
\mathcal{S}'$ (testing against any Schwartz function $\varphi$, dominated conver
gence gives $\langle f_\varepsilon,\varphi\rangle\to\langle\operatorname{sgn},\v
arphi\rangle$). By continuity of $\mathcal{F}:\mathcal{S}'\to\mathcal{S}'$,
$$\widehat{\operatorname{sgn}} = \lim_{\varepsilon\to 0^+} \widehat{f_\varepsilo
n}\quad\text{in }\mathcal{S}'.$$

## Computing $\widehat{f_\varepsilon}$

Splitting the integral at the origin,
$$\widehat{f_\varepsilon}(\xi) = \int_{0}^{\infty} e^{-\varepsilon x}e^{-i\xi x}
\,dx \;-\; \int_{-\infty}^{0} e^{\varepsilon x}e^{-i\xi x}\,dx.$$

For the first integral (substitute $x\ge 0$):
$$\int_{0}^{\infty} e^{-(\varepsilon+i\xi)x}\,dx = \frac{1}{\varepsilon+i\xi}.$$

For the second, writing $x=-u$ with $u\ge 0$:
$$\int_{-\infty}^{0} e^{\varepsilon x}e^{-i\xi x}\,dx = \int_{0}^{\infty} e^{-\v
arepsilon u}e^{i\xi u}\,du = \frac{1}{\varepsilon-i\xi}.$$

Therefore
$$\widehat{f_\varepsilon}(\xi) = \frac{1}{\varepsilon+i\xi} - \frac{1}{\varepsil
on-i\xi} = \frac{(\varepsilon-i\xi)-(\varepsilon+i\xi)}{(\varepsilon+i\xi)(\vare
psilon-i\xi)} = \frac{-2i\xi}{\varepsilon^{2}+\xi^{2}}.$$

## Distributional limit

We claim
$$\frac{-2i\xi}{\varepsilon^{2}+\xi^{2}} \;\xrightarrow[\varepsilon\to 0^+]{}\;
-2i\,\operatorname{pv}\!\left(\frac{1}{\xi}\right) \quad\text{in }\mathcal{S}'.$
$

It suffices to show that the kernel $K_\varepsilon(\xi):=\dfrac{\xi}{\varepsilon
^{2}+\xi^{2}}$ converges to $\operatorname{pv}(1/\xi)$ in $\mathcal{S}'$. Testin
g against $\varphi\in\mathcal{S}$:
$$\langle K_\varepsilon,\varphi\rangle = \int_{-\infty}^{\infty}\frac{\xi}{\vare
psilon^{2}+\xi^{2}}\,\varphi(\xi)\,d\xi = \int_{-\infty}^{\infty}\frac{\xi\,(\va
rphi(\xi)-\varphi(0))}{\varepsilon^{2}+\xi^{2}}\,d\xi,$$
where we used that $\dfrac{\xi}{\varepsilon^{2}+\xi^{2}}$ is odd, so its integra
l against the constant $\varphi(0)$ vanishes. Now $\varphi(\xi)-\varphi(0)=\xi\,
\psi(\xi)$ with $\psi$ smooth and bounded (since $\varphi$ is Schwartz), so the
integrand is $\dfrac{\xi^{2}\psi(\xi)}{\varepsilon^{2}+\xi^{2}}$, bounded by $|\
psi|_\infty$ and dominated by an $L^1$ function (e.g. $C/(1+\xi^{2})$ using the
Schwartz decay). By dominated convergence,
$$\langle K_\varepsilon,\varphi\rangle \to \int_{-\infty}^{\infty}\frac{\varphi(
\xi)-\varphi(0)}{\xi}\,d\xi = \operatorname{pv}\!\int_{-\infty}^{\infty}\frac{\v
arphi(\xi)}{\xi}\,d\xi = \left\langle\operatorname{pv}\!\left(\tfrac{1}{\xi}\rig
ht),\varphi\right\rangle.$$

Hence $K_\varepsilon\to\operatorname{pv}(1/\xi)$ in $\mathcal{S}'$, and multiply

## Result

Combining the steps,
$$\boxed{\;\widehat{\operatorname{sgn}}(\xi) \;=\; \frac{2}{i}\,\operatorname{pv

Equivalently, written as a distributional identity,
$$\mathcal{F}\{\operatorname{sgn}(x)\}(\xi) \;=\; \frac{2}{i}\,\operatorname{pv}
