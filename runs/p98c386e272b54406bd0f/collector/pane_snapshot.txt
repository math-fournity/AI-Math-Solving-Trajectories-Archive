## Proof

**Step 1: Express $\frac{\sin nx}{\sin x}$ as a sum of exponentials.**

Let $z = e^{ix}$. Then
$$\frac{\sin nx}{\sin x} = \frac{z^n - z^{-n}}{z - z^{-1}} = z^{-(n-1)}\cdot\fra
c{z^{2n}-1}{z^2-1} = z^{-(n-1)}\sum_{j=0}^{n-1} z^{2j} = \sum_{j=0}^{n-1} e^{i(2
j-(n-1))x}.$$

**Step 2: Square to get $\frac{\sin^2 nx}{\sin^2 x}$.**

Since $\frac{\sin nx}{\sin x}$ is real, its square equals its absolute-value squ
ared:
$$\frac{\sin^2 nx}{\sin^2 x} = \left(\sum_{j=0}^{n-1} e^{i(2j-(n-1))x}\right)\!\
left(\sum_{k=0}^{n-1} e^{-i(2k-(n-1))x}\right) = \sum_{j=0}^{n-1}\sum_{k=0}^{n-1
} e^{2i(j-k)x}.$$

**Step 3: Collect terms by difference $d = j-k$.**

For $d=0$ (i.e., $j=k$): there are $n$ pairs, contributing $n$.

For fixed $d$ with $1 \le |d| \le n-1$: the number of pairs $(j,k)$ with $j-k=d$
 and $0\le j,k\le n-1$ is $n-|d|$.

Therefore:
$$\frac{\sin^2 nx}{\sin^2 x} = n + \sum_{d=1}^{n-1}(n-d)\,e^{2idx} + \sum_{d=1}^
{n-1}(n-d)\,e^{-2idx} = n + 2\sum_{d=1}^{n-1}(n-d)\cos 2dx. \tag{$\star$}$$

**Step 4: Match to the required form.**

The target form is $a_0 + \sum_{1\le \ell < k \le n} a_{\ell,k}\cos 2(k-\ell)x$.
 Grouping by $d = k-\ell$:

$$\sum_{1\le \ell<k\le n} a_{\ell,k}\cos 2(k-\ell)x = \sum_{d=1}^{n-1}\left(\sum
_{\substack{1\le \ell<k\le n\\k-\ell=d}} a_{\ell,k}\right)\cos 2dx.$$

For a fixed $d$, the pairs $(\ell,k)$ with $k-\ell=d$ and $1\le \ell<k\le n$ are
 $(\ell,\ell+d)$ for $\ell=1,\dots,n-d$, giving $n-d$ pairs.

Comparing with $(\star)$, we need:
- $a_0 = n$,
- For each $d \in \{1,\dots,n-1\}$: $\displaystyle\sum_{\substack{1\le \ell<k\le
 n\\k-\ell=d}} a_{\ell,k} = 2(n-d)$.

Since there are exactly $n-d$ pairs with difference $d$, the symmetric (and cano
nical) solution sets every coefficient in each class equal:
$$a_{\ell,k} = \frac{2(n-d)}{n-d} = 2 \quad\text{for all } 1\le \ell < k \le n.$
$

**Step 5: Verification.**

- **$n=2$:** $\frac{\sin^2 2x}{\sin^2 x} = 4\cos^2 x = 2+2\cos 2x$. Formula give
s $a_0=2$, $a_{1,2}=2$, $\cos 2(2-1)x = \cos 2x$. ✓

- **$n=3$:** $\frac{\sin 3x}{\sin x} = 1+2\cos 2x$, so $\frac{\sin^2 3x}{\sin^2
x} = (1+2\cos 2x)^2 = 3+4\cos 2x+2\cos 4x$. Formula: $a_0=3$; pairs with $d=1$:
$(1,2),(2,3)$ each $a=2$, giving $4\cos 2x$; pair with $d=2$: $(1,3)$ with $a=2$
, giving $2\cos 4x$. Total $3+4\cos 2x+2\cos 4x$. ✓

**Conclusion.** The real numbers are:
$$\boxed{a_0 = n, \qquad a_{\ell,k} = 2 \text{ for all } 1 \le \ell < k \le n.}$
$
