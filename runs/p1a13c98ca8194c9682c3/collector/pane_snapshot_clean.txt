Looking at this problem, I need to find the probability that all consecutive gap
s between 2012 sorted uniform random variables on [0,1] are at most 1/2011.

## Setting Up the Spacings

Place 2012 uniform points in [0,1] and sort them: $x_1 \le \cdots \le x_{2012}$.
 Together with the endpoints 0 and 1, these define **2013 spacings**:
$$D_0 = x_1,\quad D_i = x_{i+1}-x_i\ (i=1,\ldots,2011),\quad D_{2012}=1-x_{2012}
.$$

These spacings are **uniform on the 2012-dimensional simplex** (Dirichlet with a
ll 2013 parameters equal to 1). We seek:
$$P = \Pr\!\Big(D_i \le \tfrac{1}{2011}\text{ for all }i=1,\ldots,2011\Big).$$

Note: the constraint is only on the **2011 internal** spacings, not $D_0$ or $D_
{2012}$.

## Inclusion-Exclusion

Let $A_i = \{D_i > 1/2011\}$ for $i=1,\ldots,2011$. By inclusion-exclusion:

$$P = \sum_{k=0}^{2011}(-1)^k\binom{2011}{k}\Pr(A_1\cap\cdots\cap A_k).$$

**Key fact:** For $n$ spacings uniform on the simplex, the probability that $k$
specific spacings each exceed $a$ (with $ka\le 1$) is $(1-ka)^{n-1}$.

Here $n=2013$, $a=1/2011$, so $n-1=2012$:

$$P = \sum_{k=0}^{2011}(-1)^k\binom{2011}{k}\left(1-\frac{k}{2011}\right)^{2012}
.$$

The $k=2011$ term vanishes ($(1-1)^{2012}=0$), so:

$$P = \frac{1}{2011^{2012}}\sum_{k=0}^{2010}(-1)^k\binom{2011}{k}(2011-k)^{2012}
.$$

## Stirling Number Identity

Substituting $j = 2011-k$:

$$P = \frac{1}{2011^{2012}}\sum_{j=1}^{2011}(-1)^{2011-j}\binom{2011}{j}j^{2012}
.$$

Using the standard identity $\sum_{j=0}^{n}(-1)^{n-j}\binom{n}{j}j^m = n!\,S(m,n
)$ (where $S(m,n)$ is the Stirling number of the second kind), with $n=2011$, $m
=2012$:

$$\sum_{j=0}^{2011}(-1)^{2011-j}\binom{2011}{j}j^{2012} = 2011!\cdot S(2012,2011
).$$

The $j=0$ term is 0, so our sum equals $2011!\cdot S(2012,2011)$.

**Computing $S(2012,2011)$:** Partitioning 2012 elements into 2011 non-empty blo
cks means exactly one block has 2 elements; the rest are singletons. Thus:
$$S(2012,2011) = \binom{2012}{2} = \frac{2012\cdot 2011}{2}.$$

## Simplifying the Probability

$$P = \frac{2011!\cdot\frac{2012\cdot 2011}{2}}{2011^{2012}} = \frac{2012\cdot 2
011!}{2\cdot 2011^{2011}} = \frac{1006\cdot 2010!}{2011^{2010}}.$$

## Coprimality

**2011 is prime** (checked: not divisible by any prime up to $\sqrt{2011}\approx
 44.8$). Since $2010!$ contains no factor of 2011, and $1006 = 2\cdot 503$ also
doesn't involve 2011:

$$\gcd(1006\cdot 2010!,\; 2011^{2010}) = 1.$$

So $m = 1006\cdot 2010!$ and $n = 2011^{2010}$ are coprime.

## Computing $(m+n)\bmod 1000$

**Numerator $m$:** Since $2010!$ contains at least three factors of 2 and three
factors of 5, $2010!\equiv 0\pmod{1000}$, so $m \equiv 0\pmod{1000}$.

**Denominator $n$:** Need $2011^{2010}\bmod 1000$, i.e., $11^{2010}\bmod 1000$.
Use CRT with $1000 = 8\times 125$:

- **Mod 8:** $11\equiv 3$, $3^2\equiv 1$, so $11^{2010}\equiv 1\pmod{8}$.
- **Mod 125:** $\varphi(125)=100$, $2010\equiv 10\pmod{100}$, so $11^{2010}\equi
v 11^{10}\pmod{125}$.
  - $11^2 = 121 \equiv -4\pmod{125}$
  - $11^4 \equiv 16\pmod{125}$
  - $11^8 \equiv 256 \equiv 6\pmod{125}$
  - $11^{10} = 11^8\cdot 11^2 \equiv 6\cdot(-4) = -24 \equiv 101\pmod{125}$

**CRT:** Find $x$ with $x\equiv 1\pmod{8}$ and $x\equiv 101\pmod{125}$.
$$x = 101 + 125k,\quad 101\equiv 5\pmod{8},\; 125\equiv 5\pmod{8}$$
$$5+5k\equiv 1\pmod{8}\implies 5k\equiv 4\pmod{8}\implies k\equiv 4\cdot 5\equiv
 4\pmod{8}$$
$$x = 101 + 125\cdot 4 = 601.$$

So $n \equiv 601\pmod{1000}$.

## Final Answer

$$m+n \equiv 0 + 601 = 601\pmod{1000}.$$

The remainder when $m+n$ is divided by 1000 is $\boxed{601}$.
