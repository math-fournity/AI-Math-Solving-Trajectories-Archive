## Proof

Let $D: \mathcal{J} \to \mathbf{Top}$ be a small diagram, and let $(L, \tau_L)$
with the cone $(\lambda_j: (L,\tau_L) \to Dj)_{j\in\mathcal{J}}$ be a limit of $
D$ in $\mathbf{Top}$. Denote by $\tau_{\text{init}}$ the initial topology on the
 underlying set $L$ with respect to the family of maps $(\lambda_j: L \to Dj)_{j
\in\mathcal{J}}$ (each $Dj$ carrying its given topology). We prove $\tau_L = \ta
u_{\text{init}}$.

**Step 1: $\tau_{\text{init}} \subseteq \tau_L$.**

Since $(\lambda_j)$ is a limit cone in $\mathbf{Top}$, each $\lambda_j: (L,\tau_
L) \to Dj$ is continuous. The initial topology $\tau_{\text{init}}$ is by defini
tion the coarsest topology on the set $L$ making every $\lambda_j$ continuous. H
ence $\tau_{\text{init}} \subseteq \tau_L$.

**Step 2: $(L, \tau_{\text{init}})$ with the same cone $(\lambda_j)$ is a limit
of $D$.**

The maps $\lambda_j: (L, \tau_{\text{init}}) \to Dj$ are continuous by construct
ion of $\tau_{\text{init}}$, so $(L,\tau_{\text{init}})$ with $(\lambda_j)$ is a
 cone over $D$. We verify the universal property. Let $(f_j: X \to Dj)_{j\in\mat
hcal{J}}$ be any cone over $D$ in $\mathbf{Top}$, so each $f_j$ is continuous an
d the family is compatible. Since $(L,\tau_L)$ is a limit, there is a unique set
 map $f: X \to L$ (the underlying set is the same) with $\lambda_j \circ f = f_j
$ for all $j$, and $f: X \to (L,\tau_L)$ is continuous. We must show $f: X \to (
L,\tau_{\text{init}})$ is continuous.

By the characteristic property of the initial topology, a map $f: X \to (L,\tau_
{\text{init}})$ is continuous if and only if $\lambda_j \circ f: X \to Dj$ is co
ntinuous for every $j$. But $\lambda_j \circ f = f_j$, and each $f_j$ is continu
ous (the cone is in $\mathbf{Top}$). Therefore $f: X \to (L,\tau_{\text{init}})$
 is continuous. Uniqueness of $f$ as a set map is inherited from the limit $(L,\
tau_L)$. Thus $(L,\tau_{\text{init}})$ with $(\lambda_j)$ satisfies the universa
l property of the limit.

**Step 3: $\tau_L = \tau_{\text{init}}$ by uniqueness of limits.**

Both $(L,\tau_L)$ and $(L,\tau_{\text{init}})$, equipped with the cone $(\lambda
_j)$, are limits of $D$. Limits are unique up to unique isomorphism commuting wi
th the cone maps: there is a unique homeomorphism $h: (L,\tau_L) \to (L,\tau_{\t
ext{init}})$ with $\lambda_j \circ h = \lambda_j$ for all $j$.

The identity map $\mathrm{id}_L: L \to L$ on the underlying set satisfies $\lamb
da_j \circ \mathrm{id}_L = \lambda_j = \lambda_j \circ \mathrm{id}_L$ for all $j
$, so it is a cone-map-preserving morphism from the cone $(L,\tau_L)$ to the con
e $(L,\tau_{\text{init}})$. By the uniqueness in the universal property (applied
 to the cone $(\lambda_j: (L,\tau_{\text{init}}) \to Dj)$ over itself), the uniq
ue mediating map $(L,\tau_{\text{init}}) \to (L,\tau_{\text{init}})$ is $\mathrm
{id}_L$, which forces $h = \mathrm{id}_L$.

Since $h = \mathrm{id}_L$ is a homeomorphism from $(L,\tau_L)$ to $(L,\tau_{\tex
t{init}})$, the identity map is continuous in both directions, which means preci
sely $\tau_L = \tau_{\text{init}}$.

**Conclusion.** The topology $\tau_L$ on the limit is exactly the initial topolo
gy on the set $L$ with respect to the limit cone maps $(\lambda_j)_{j\in\mathcal
{J}}$. $\blacksquare$
