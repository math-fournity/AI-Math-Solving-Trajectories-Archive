## 证明

设 $T$ 是 $\ell^2$ 上的线性算子，对于任意 $x = (x_1, x_2, \ldots) \in \ell^2$，
有

$$\|Tx\| = \sqrt{\sum_{i=1}^{\infty} \frac{x_i^2}{i^2}}.$$

我们通过确定 $\|T\| = \sup_{\|x\|=1} \|Tx\|$ 来计算其范数。

**上界。** 对于每个 $i \ge 1$，有 $\frac{1}{i^2} \le 1$。因此，对于任意满足 $\|x
\|^2 = \sum_{i=1}^\infty x_i^2 = 1$ 的 $x \in \ell^2$，

$$\|Tx\|^2 = \sum_{i=1}^{\infty} \frac{x_i^2}{i^2} \le \sum_{i=1}^{\infty} x_i^2
 = 1,$$

所以 $\|Tx\| \le 1$。对所有单位向量取上确界，得到 $\|T\| \le 1$。

**下界。** 设 $e_1 = (1, 0, 0, \ldots) \in \ell^2$。则 $\|e_1\| = 1$，且

$$\|Te_1\| = \sqrt{\frac{1^2}{1^2} + 0 + 0 + \cdots} = 1.$$

因此 $\|T\| = \sup_{\|x\|=1} \|Tx\| \ge \|Te_1\| = 1$。

**结论。** 结合这两个不等式，得到

$$\|T\| = 1.$$
