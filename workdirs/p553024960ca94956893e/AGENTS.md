# Problem

In a specialized security facility, an access code is generated by filling a $2 \times 2$ grid with four two-digit identification tags. These tags are selected from a master database containing all integers from $00$ to $99$.

A security protocol is deemed "Property A-Compliant" if it is impossible to construct such a $2 \times 2$ grid using only tags from a specific subset $S$ of the database. For a grid to be valid, the four two-digit tags must be placed such that the digits in the rows and columns form valid tags within the chosen subset. Specifically, if we denote the four tags in the grid as:
- Top-left to top-right (Row 1): $10a + b$
- Bottom-left to bottom-right (Row 2): $10c + d$
- Top-left to bottom-left (Column 1): $10a + c$
- Top-right to bottom-right (Column 2): $10b + d$

where $a, b, c, d$ are digits from $\{0, 1, 2, \dots, 9\}$, the protocol is breached if all four resulting two-digit numbers—$ab, cd, ac,$ and $bd$—are members of the subset $S$.

A lead cryptographer needs to determine the maximum number of unique identification tags that can be included in subset $S$ such that it remains impossible to form any such grid. 

Determine the maximum possible size of the set $S$ that satisfies Property A.
