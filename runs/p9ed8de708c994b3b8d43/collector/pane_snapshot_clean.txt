## Counterexample

Let $p$ be a prime. Set
$$F = \mathbb{F}_p(t_1, t_2, t_3, \dots), \qquad E = F\!\left(t_1^{1/p},\, t_2^{
1/p},\, t_3^{1/p},\, \dots\right),$$
where $t_1, t_2, \dots$ are algebraically independent indeterminates over $\math
bb{F}_p$.

### Claim 1: $[E:F]$ is infinite.

For each $m \ge 1$, define $E_m = F(t_1^{1/p}, \dots, t_m^{1/p})$. We show by in
duction that $[E_m : F] = p^m$.

The inductive step requires showing that $x^p - t_m$ is irreducible over $E_{m-1
}$. In characteristic $p$, $x^p - a$ is irreducible over a field $K$ iff $a \not
in K^p$. So we need $t_m \notin E_{m-1}^p$.

Any element $\beta \in E_{m-1}$ is a rational function in $t_1^{1/p}, \dots, t_{
m-1}^{1/p}$ with coefficients in $F$. Computing $\beta^p$: the Frobenius (a ring
 homomorphism in char $p$) sends each $t_i^{1/p} \mapsto t_i$ and each coefficie
nt $c \mapsto c^p \in F^p = \mathbb{F}_p(t_1^p, t_2^p, \dots)$. Therefore
$$E_{m-1}^p \;\subseteq\; \mathbb{F}_p(t_1,\, \dots,\, t_{m-1},\, t_m^p,\, t_{m+
1}^p,\, \dots).$$

Since $t_m$ is transcendental over $\mathbb{F}_p(t_1, \dots, t_{m-1}, t_m^p, t_{
m+1}^p, \dots)$ (it satisfies only $x^p - t_m^p = 0$, a degree-$p$ polynomial, o
ver this field), we have $t_m \notin E_{m-1}^p$. Hence $x^p - t_m$ is irreducibl
e over $E_{m-1}$, giving $[E_m : E_{m-1}] = p$ and $[E_m : F] = p^m$.

Since $E_m \subseteq E$ for all $m$ and $[E_m:F] = p^m \to \infty$, we conclude
$[E:F] = \infty$.

### Claim 2: Every $\alpha \in E$ satisfies $[F(\alpha):F] \le p$.

Any $\alpha \in E$ involves only finitely many generators, so $\alpha \in E_m$ f
or some $m$. Write
$$\alpha = \frac{g(t_1^{1/p}, \dots, t_m^{1/p})}{h(t_1^{1/p}, \dots, t_m^{1/p})}
, \qquad g, h \in F[x_1, \dots, x_m].$$

Applying Frobenius (using that it is a homomorphism in characteristic $p$):
$$\alpha^p = \frac{g(t_1^{1/p}, \dots)^p}{h(t_1^{1/p}, \dots)^p} = \frac{\sum c_
I^p\, t^I}{\sum d_J^p\, t^J} \;\in\; F,$$
since $c_I^p, d_J^p \in F$ and $t^I = t_1^{i_1}\cdots t_m^{i_m} \in F$.

Thus $\alpha$ is a root of $x^p - \alpha^p \in F[x]$. In characteristic $p$,
$$x^p - \alpha^p = (x - \alpha)^p,$$
so the minimal polynomial of $\alpha$ over $F$ divides $(x-\alpha)^p$, hence has
 degree $1$ or $p$. In particular,
$$[F(\alpha):F] \le p.$$

### Conclusion

Taking $n = p$, every element $\alpha \in E$ satisfies $[F(\alpha):F] \le n$, ye
t $[E:F] = \infty$. Therefore, **we cannot conclude that $[E:F]$ is finite.**

---

**Remark.** If one additionally assumes $E/F$ is separable (e.g., $\operatorname
{char}(F) = 0$), then the answer becomes **yes**: if $[E:F] > n$, one can find $
n+1$ $F$-linearly independent elements generating a finite separable subextensio
n $K/F$ with $:F] > n$; by the Primitive Element Theorem, $K = F(\gamma)$ for
some $\gamma$, giving $[F(\gamma):F] > n$, a contradiction. The counterexample a
bove exploits precisely the failure of separability (purely inseparable extensio
ns) to evade the primitive element theorem.
