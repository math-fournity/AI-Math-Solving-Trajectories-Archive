## 解答

首先，让我检查一下是否存在答案泄露。问题中写道“假设预期结果为 $R(0) = \frac{1}{2
}$”——这是作为推导目标陈述的，而非泄露的证明或解题策略。知道目标值并不能绕过实际
计算，因此这是一个合法的“验证/推导”类问题。我将对其进行求解。

---

我们要计算

$$R(0) = \frac{1}{2\pi}\int_{-\infty}^{\infty} \frac{dk}{ik+1}.$$

**第 1 步：有理化被积函数。** 将分子和分母同乘以共轭复数 $(1-ik)$：

$$\frac{1}{1+ik} = \frac{1}{1+ik}\cdot\frac{1-ik}{1-ik} = \frac{1-ik}{(1+ik)(1-i
k)} = \frac{1-ik}{1+k^{2}} = \frac{1}{1+k^{2}} - i\,\frac{k}{1+k^{2}}.$$

因此，该积分可拆分为实部和虚部两部分：

$$\int_{-\infty}^{\infty}\frac{dk}{1+ik} = \int_{-\infty}^{\infty}\frac{dk}{1+k^
{2}} \;-\; i\int_{-\infty}^{\infty}\frac{k\,dk}{1+k^{2}}.$$

**第 2 步：实部。** 这是一个标准积分：

$$\int_{-\infty}^{\infty}\frac{dk}{1+k^{2}} = \Big[\arctan k\Big]_{-\infty}^{\in
fty} = \frac{\pi}{2} - \left(-\frac{\pi}{2}\right) = \pi.$$

**第 3 步：虚部（柯西主值）。** 函数 $f(k) = \frac{k}{1+k^{2}}$ 是奇函数：$f(-k)
 = -f(k)$。在对称区间 $[-L, L]$ 上，其积分为 $0$，因此柯西主值为

$$\text{P.V.}\int_{-\infty}^{\infty}\frac{k\,dk}{1+k^{2}} = \lim_{L\to\infty}\in
t_{-L}^{L}\frac{k\,dk}{1+k^{2}} = \lim_{L\to\infty} 0 = 0.$$

**第 4 步：合并结果。** 将两部分合并：

$$\int_{-\infty}^{\infty}\frac{dk}{1+ik} = \pi - i\cdot 0 = \pi.$$

**第 5 步：得出结论。**

$$R(0) = \frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{dk}{ik+1} = \frac{1}{2\pi}\c
dot\pi = \boxed{\frac{1}{2}}.$$

---

**备注（通过围道积分验证）。** 或者，可以将被积函数 $g(k) = \frac{1}{1+ik}$ 视为
复变量 $k$ 的函数。它在 $1+ik=0$，即 $k = i$ 处有一个单极点，位于上半平面。在实
轴上闭合一个上半平面的大半圆，留数定理得出 $\oint g\,dk = 2\pi i\,\text{Res}_{k=
i} g$。由于 $\text{Res}_{k=i} \frac{1}{1+ik} = \frac{1}{i} = -i$，我们得到 $\oin
t = 2\pi i(-i) = 2\pi$。半圆弧的贡献（其中 $g \sim 1/(ik)$，长度 $\sim R$）在通
常的对称意义上不会独立消失，这与上述主值分解一致；仔细的分析重现了 $\int_{-\inft
y}^{\infty} g\,dk = \pi$，证实了 $R(0) = 1/2$。

### PROOF COMPLETE
