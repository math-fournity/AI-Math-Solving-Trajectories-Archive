## Solution

**Parametrization.** Set $t = y/x$ (so $y = tx$). Substituting into $(x+y)^5 = x
^2y^2$:

$$x^5(1+t)^5 = t^2 x^4 \implies x = \frac{t^2}{(1+t)^5}, \qquad y = tx = \frac{t
^3}{(1+t)^5}.$$

**Verification.** $x+y = \dfrac{t^2(1+t)}{(1+t)^5} = \dfrac{t^2}{(1+t)^4}$, so $
(x+y)^5 = \dfrac{t^{10}}{(1+t)^{20}} = \dfrac{t^4}{(1+t)^{10}}\cdot\dfrac{t^6}{(
1+t)^{10}} = x^2y^2$. ✓

**Identifying the loop.** The curve passes through the origin when $t=0$ and whe
n $t\to\pm\infty$. For $t\in[0,\infty)$: both $x,y\ge 0$ (first quadrant), start
ing at the origin ($t=0$) and returning to it ($t\to\infty$), thus tracing a clo
sed loop. For $t\in(-1,0)$ and $t\in(-\infty,-1)$ the branches escape to infinit
y (since $(1+t)^5\to 0$), so they are not part of the loop.

**Area via Green's theorem.** The signed area enclosed by a parametric curve is
$$A = \frac12\int_0^\infty \bigl(x\dot y - y\dot x\bigr)\,dt.$$

Compute the derivatives:
$$\dot x = \frac{(1+t)^{-6}(2t-3t^2)}{1},\qquad \dot y = (1+t)^{-6}(3t^2-2t^3).$
$

Then
$$x\dot y - y\dot x = (1+t)^{-12}\bigl[t^2(3t^2-2t^3)-t^3(2t-3t^2)\bigr] = (1+t)
^{-12}(t^4+t^5) = \frac{t^4}{(1+t)^{11}}.$$

(The orientation is counterclockwise — the curve leaves the origin along $x\appr
ox t^2$ and returns along $y\approx t^{-2}$ from above — so the sign is positive
.)

**Evaluating the integral.**
$$A = \frac12\int_0^\infty \frac{t^4}{(1+t)^{11}}\,dt = \frac12\,B(5,6) = \frac1
2\cdot\frac{\Gamma(5)\,\Gamma(6)}{\Gamma(11)} = \frac12\cdot\frac{4!\cdot 5!}{10
!}.$$

With $4!=24$, $5!=120$, $10!=3\,628\,800$:
$$\frac{4!\cdot 5!}{10!} = \frac{2880}{3\,628\,800} = \frac{1}{1260}.$$

Therefore
$$\boxed{A = \frac{1}{2}\cdot\frac{1}{1260} = \frac{1}{2520}.}$$
