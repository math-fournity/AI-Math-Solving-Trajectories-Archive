## Solution

We need to compute $E[XY] = \frac{\partial^2 M_{XY}}{\partial t_1 \partial t_2}\
Big|_{t_1=t_2=0}$.

**Define helper functions.** Let
$$A(t) = \frac{e^t}{t} - \frac{e^t-1}{t^2}, \qquad B(t) = \frac{e^t-1}{t}.$$

Then the joint MGF factors as
$$M_{XY}(t_1,t_2) = \tfrac{4}{5}\,A(t_1)\,B(t_2) + \tfrac{6}{5}\,A(t_2)\,B(t_1).
$$

**Cross partial derivative.** Since the $t_1$ and $t_2$ dependencies are separat
ed in each term,
$$\frac{\partial^2 M}{\partial t_1\,\partial t_2} = \tfrac{4}{5}\,A'(t_1)\,B'(t_
2) + \tfrac{6}{5}\,A'(t_2)\,B'(t_1).$$

Evaluating at $t_1=t_2=0$:
$$E[XY] = \tfrac{4}{5}\,A'(0)\,B'(0) + \tfrac{6}{5}\,A'(0)\,B'(0) = \left(\tfrac
{4}{5}+\tfrac{6}{5}\right)A'(0)\,B'(0) = 2\,A'(0)\,B'(0).$$

**Series expansions around $t=0$.** Using $e^t = 1 + t + \frac{t^2}{2} + \frac{t
^3}{6} + \frac{t^4}{24} + \cdots$:

$$B(t) = \frac{e^t-1}{t} = 1 + \frac{t}{2} + \frac{t^2}{6} + \frac{t^3}{24} + \c
dots$$
$$B'(t) = \frac{1}{2} + \frac{t}{3} + \frac{t^2}{8} + \cdots \implies B'(0) = \f
rac{1}{2}.$$

For $A(t)$, expand each piece:
$$\frac{e^t}{t} = \frac{1}{t} + 1 + \frac{t}{2} + \frac{t^2}{6} + \frac{t^3}{24}
 + \cdots$$
$$\frac{e^t-1}{t^2} = \frac{1}{t} + \frac{1}{2} + \frac{t}{6} + \frac{t^2}{24} +
 \cdots$$

Subtracting:
$$A(t) = \frac{1}{2} + t\!\left(\frac{1}{2}-\frac{1}{6}\right) + t^2\!\left(\fra
c{1}{6}-\frac{1}{24}\right) + \cdots = \frac{1}{2} + \frac{t}{3} + \frac{t^2}{8}
 + \cdots$$
$$A'(t) = \frac{1}{3} + \frac{t}{4} + \cdots \implies A'(0) = \frac{1}{3}.$$

**Final computation.**
$$E[XY] = 2 \cdot A'(0) \cdot B'(0) = 2 \cdot \frac{1}{3} \cdot \frac{1}{2} = \f
rac{1}{3}.$$

$$\boxed{E[XY] = \dfrac{1}{3}}$$
