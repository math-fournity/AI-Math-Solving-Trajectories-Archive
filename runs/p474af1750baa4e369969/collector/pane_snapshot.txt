## Proof

**Claim:** Yes. If $S$ is $C^*$-embedded in $X$, then every cozero set of $S$ is
 of the form $U \cap S$ for some cozero set $U$ of $X$.

**Setup.** Recall that $S \subseteq X$ is *$C^*$-embedded* if every bounded cont
inuous function $f: S \to \mathbb{R}$ extends to a continuous function $\tilde f
: X \to \mathbb{R}$. A *cozero set* of a space $Y$ is a set of the form $\operat
orname{coz}(g) = \{y \in Y : g(y) \neq 0\}$ for some continuous $g: Y \to \mathb
b{R}$.

**Key observation.** The cozero set of a function depends only on its zero set,
not on its magnitude. Thus we may replace any continuous function by a bounded o
ne with the same cozero set. Concretely, let
$$\varphi: \mathbb{R} \to (-1,1), \qquad \varphi(t) = \frac{t}{1+|t|}.$$
This is a homeomorphism (continuous, strictly increasing, with continuous invers
e $u \mapsto u/(1-|u|)$), and crucially
$$\varphi(t) = 0 \iff t = 0.$$
Hence for any continuous $f: Y \to \mathbb{R}$,
$$\operatorname{coz}(\varphi \circ f) = \operatorname{coz}(f).$$

**The argument.** Let $A$ be a cozero set of $S$, so $A = \operatorname{coz}(f)$
 for some continuous $f: S \to \mathbb{R}$ (possibly unbounded). Define
$$h = \varphi \circ f : S \to (-1,1) \subseteq \mathbb{R}.$$
Then $h$ is continuous and **bounded** ($|h| < 1$), and by the observation above
,
$$\operatorname{coz}(h) = \operatorname{coz}(f) = A.$$

Since $S$ is $C^*$-embedded and $h$ is bounded and continuous, $h$ extends to a
continuous function $H: X \to \mathbb{R}$ (which we may take bounded). Now set
$$U = \operatorname{coz}(H) = \{x \in X : H(x) \neq 0\}.$$
This is a cozero set of $X$. Moreover, since $H|_S = h$,
$$U \cap S = \{s \in S : H(s) \neq 0\} = \{s \in S : h(s) \neq 0\} = \operatorna
me{coz}(h) = A.$$

**Conclusion.** Every cozero set $A$ of $S$ admits the representation $A = U \ca
p S$ with $U$ a cozero set of $X$. The essential point is that $C^*$-embeddednes
s — which a priori only extends *bounded* functions — suffices because the bound
ed transform $\varphi(t) = t/(1+|t|)$ converts any continuous function into a bo
unded one while preserving its cozero set.
