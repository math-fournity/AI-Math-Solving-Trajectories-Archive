Looking at the problem: "Does a $C^1$ function map a set of measure zero into a
set of measure zero?"

**Answer: Yes.** A $C^1$ function $f: U \to \mathbb{R}^n$ (where $U \subseteq \m
athbb{R}^n$ is open) maps every set of Lebesgue measure zero to a set of Lebesgu
e measure zero.

**Proof.**

The key idea is that a $C^1$ function is **locally Lipschitz**, and Lipschitz fu
nctions map null sets to null sets.

---

**Step 1: $C^1$ implies locally Lipschitz.**

Let $K \subseteq U$ be compact. Since $U$ is open and $K$ is compact, there exis
ts $\delta > 0$ such that the closed $\delta$-neighborhood $K_\delta = \{x : \op
eratorname{dist}(x, K) \leq \delta\}$ is contained in $U$.

Since $Df$ is continuous and $K_\delta$ is compact, the operator norm $\|Df(x)\|
$ is bounded on $K_\delta$; call this bound $M_K < \infty$. By the Mean Value In
equality, for any $x, y \in K$ with $\|x - y\| \leq \delta$ (so that $[x, y] \su
bseteq K_\delta$):

$$\|f(x) - f(y)\| \leq M_K \|x - y\|.$$

Cover $K$ by finitely many open balls $B_1, \dots, B_N$ of radius $\delta/2$. Th
en $f$ is $L$-Lipschitz on each $B_i$ with $L = M_K$.

---

**Step 2: Lipschitz functions map null sets to null sets.**

Let $E \subseteq U$ have measure zero. Write $U = \bigcup_{k=1}^\infty K_k$ wher
e $K_k = \{x \in U : \|x\| \leq k \text{ and } \operatorname{dist}(x, \partial U
) \geq 1/k\}$ is compact. Then $E = \bigcup_k (E \cap K_k)$ and $f(E) = \bigcup_
k f(E \cap K_k)$. Since a countable union of null sets is null, it suffices to s
how $f(E \cap K_k)$ is null for each $k$.

Fix $k$ and set $A = E \cap K_k$. Cover $K_k$ by finitely many balls $B_1, \dots
, B_N$ as in Step 1, so $f$ is $L$-Lipschitz on each $B_i$. Set $A_i = A \cap B_
i$; then $f(A) = \bigcup_{i=1}^N f(A_i)$, and it suffices to show each $f(A_i)$
is null.

Fix $i$ and let $\varepsilon > 0$. Since $A_i \subseteq E$ has measure zero and
$B_i$ is open, there exist open cubes $Q_1, Q_2, \dots \subseteq B_i$ covering $
A_i$ with $\sum_j \operatorname{vol}(Q_j) < \varepsilon$.

Let $Q_j$ have side length $s_j$ and center $c_j$. For any $x \in Q_j$, we have
$\|x - c_j\| \leq \frac{s_j \sqrt{n}}{2}$, so by the Lipschitz property:

$$\|f(x) - f(c_j)\| \leq L \cdot \frac{s_j \sqrt{n}}{2}.$$

Thus $f(Q_j) \subseteq \overline{B}\!\left(f(c_j),\, \frac{L\sqrt{n}}{2}\, s_j\r
ight)$, a closed ball of radius $r_j = \frac{L\sqrt{n}}{2}\, s_j$. Its volume is
:

$$\omega_n\, r_j^n = \omega_n \left(\frac{L\sqrt{n}}{2}\right)^n s_j^n = \omega_
n \left(\frac{L\sqrt{n}}{2}\right)^n \operatorname{vol}(Q_j),$$

where $\omega_n$ is the volume of the unit ball in $\mathbb{R}^n$. Setting $C =
\omega_n \left(\frac{L\sqrt{n}}{2}\right)^n$, the outer measure satisfies:

$$m^*(f(A_i)) \leq \sum_j \operatorname{vol}\!\left(\overline{B}(f(c_j), r_j)\ri
ght) \leq C \sum_j \operatorname{vol}(Q_j) < C\,\varepsilon.$$

Since $\varepsilon > 0$ is arbitrary, $m^*(f(A_i)) = 0$, so $f(A_i)$ is measurab
le with measure zero.

---

**Step 3: Conclusion.**

Each $f(A_i)$ has measure zero, so $f(A) = \bigcup_i f(A_i)$ has measure zero, h
ence $f(E \cap K_k)$ has measure zero, and finally

$$f(E) = \bigcup_{k=1}^\infty f(E \cap K_k)$$

has measure zero, being a countable union of null sets. $\blacksquare$

---

**Remark.** The same-dimensional setting ($f: \mathbb{R}^n \to \mathbb{R}^n$) is
 essential for this positive answer. If $f: \mathbb{R}^n \to \mathbb{R}^m$ with
$m < n$, the result fails: for example, the projection $f(x, y) = x$ from $\math
bb{R}^2 \to \mathbb{R}$ maps the null set $\{0\} \times [0,1]$ to $[0,1]$, which
 has positive measure.
