### Step 2: Check Hensel lifting conditions

$f'(x) = 5x^4 + 10x + 1$.

- $f'(2) = 5\cdot16 + 20 + 1 = 101 \equiv 2 \pmod{11} \neq 0$ → **unique lift**.
- $f'(5) = 5\cdot625 + 50 + 1 = 3176 \equiv 8 \pmod{11} \neq 0$ → **unique lift*
*.

Since $f'(r) \not\equiv 0 \pmod{11}$ at each root, Hensel's lemma guarantees eac
h root lifts to exactly **one** root mod $121$.

### Step 3: Compute the lifts

**Lift of $x \equiv 2$:** Set $x = 2 + 11t$. Hensel gives
$$t \equiv -\frac{f(2)}{11}\cdot\bigl(f'(2)\bigr)^{-1} \pmod{11}.$$
- $f(2)/11 = 55/11 = 5$.
- $f'(2) \equiv 2 \pmod{11}$, and $2^{-1} \equiv 6 \pmod{11}$.
- $t \equiv -5\cdot 6 = -30 \equiv 3 \pmod{11}$.

So $x \equiv 2 + 11\cdot 3 = 35 \pmod{121}$.

**Verification:** $35^2 \equiv 15$, $35^4 \equiv 15^2 = 225 \equiv 104$, $35^5 \
equiv 104\cdot35 = 3640 \equiv 10 \pmod{121}$. Then $f(35) \equiv 10 + 5\cdot15
+ 35 + 1 = 10 + 75 + 36 = 121 \equiv 0 \pmod{121}$. ✓

**Lift of $x \equiv 5$:** Set $x = 5 + 11t$.
- $f(5)/11 = 3256/11 = 296 \equiv 10 \pmod{11}$.
- $f'(5) \equiv 8 \pmod{11}$, and $8^{-1} \equiv 7 \pmod{11}$ (since $8\cdot7=56
\equiv1$).
- $t \equiv -10\cdot 7 = -70 \equiv -70 + 77 = 7 \pmod{11}$.

So $x \equiv 5 + 11\cdot 7 = 82 \pmod{121}$.

**Verification:** $82^2 \equiv 69$, $82^4 \equiv 69^2 = 4761 \equiv 42$, $82^5 \
equiv 42\cdot82 = 3444 \equiv 56 \pmod{121}$. Then $f(82) \equiv 56 + 5\cdot69 +
 82 + 1 = 56 + 345 + 83 = 484 = 4\cdot121 \equiv 0 \pmod{121}$. ✓

There are exactly **2** roots mod 11, each lifting uniquely to a root mod 121 (s

The number of integers $0 \le x < 121$ satisfying the congruence is $\boxed{2}$.
