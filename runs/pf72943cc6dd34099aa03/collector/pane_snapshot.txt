## Solution

Let
$$g(t) = \frac{\sin t}{t^{3/2}}, \qquad f(x) = \int_0^x g(t)\,dt = \int_0^x \fra
c{\sin t}{t^{3/2}}\,dt.$$

**Step 1. Rewrite via the Laplace transform.**

The quantity of interest is
$$L_k := k^{3/2}\int_0^\infty f(x)\,e^{-kx}\,dx = k^{3/2}\,\mathcal{L}\{f\}(k).$
$

Since $f(x)=\int_0^x g(t)\,dt$ with $f(0)=0$, the standard integration-in-the-ti
me-domain property of the Laplace transform gives
$$\mathcal{L}\{f\}(k) = \frac{\mathcal{L}\{g\}(k)}{k} = \frac{G(k)}{k}, \qquad G
(k):=\int_0^\infty \frac{\sin t}{t^{3/2}}\,e^{-kt}\,dt.$$

Hence
$$L_k = k^{3/2}\cdot\frac{G(k)}{k} = k^{1/2}\,G(k) = k^{1/2}\int_0^\infty \frac{
\sin t}{t^{3/2}}\,e^{-kt}\,dt.$$

**Step 2. Isolate the leading singularity at $t=0$.**

Write $g(t) = t^{-1/2} + h(t)$, i.e.
$$h(t) := \frac{\sin t}{t^{3/2}} - \frac{1}{t^{1/2}} = \frac{\sin t - t}{t^{3/2}
}.$$

Since $\sin t - t = -\tfrac{t^3}{6} + O(t^5)$, we have $h(t) = -\tfrac{1}{6}t^{3
/2} + O(t^{7/2})$, so $h$ extends continuously to $t=0$ with $h(0)=0$. For large
 $t$, $|h(t)|\le (|\sin t|+t)/t^{3/2}\le 2t^{-1/2}$, so $h$ is bounded on every
$[\delta,\infty)$.

Then
$$L_k = k^{1/2}\int_0^\infty t^{-1/2}e^{-kt}\,dt \;+\; k^{1/2}\int_0^\infty h(t)
\,e^{-kt}\,dt =: A_k + R_k.$$

**Step 3. Evaluate $A_k$ exactly.**

With $u=kt$:
$$A_k = k^{1/2}\int_0^\infty t^{-1/2}e^{-kt}\,dt = k^{1/2}\cdot k^{-1/2}\int_0^\
infty u^{-1/2}e^{-u}\,du = \Gamma\!\left(\tfrac12\right) = \sqrt{\pi},$$
for every $k>0$.

**Step 4. Show $R_k\to 0$.**

Fix $\varepsilon>0$. Since $h$ is continuous with $h(0)=0$, choose $\delta>0$ so
 $|h(t)|<\varepsilon$ on $[0,\delta]$. Let $M=\sup_{t\ge\delta}|h(t)|<\infty$. T
hen

$$|R_k| \le k^{1/2}\!\int_0^\delta |h(t)|e^{-kt}dt + k^{1/2}\!\int_\delta^\infty
 |h(t)|e^{-kt}dt \le k^{1/2}\varepsilon\cdot\frac{1}{k} + k^{1/2}M\cdot\frac{e^{
-k\delta}}{k} = \varepsilon\,k^{-1/2} + M\,k^{-1/2}e^{-k\delta}.$$

Both terms tend to $0$ as $k\to\infty$; since $\varepsilon$ was arbitrary, $R_k\
to 0$.

**Step 5. Conclude.**

$$\lim_{k\to\infty} L_k = \lim_{k\to\infty}(A_k + R_k) = \sqrt{\pi} + 0 = \sqrt{
\pi}.$$

$$\boxed{\lim_{k \to \infty} \int_{0}^{\infty}k^{3/2}\!\left(\int_{0}^{x}\frac{\
sin t}{t\sqrt{t}}\,dt\right)e^{-kx}\,dx \;=\; \sqrt{\pi}}$$
