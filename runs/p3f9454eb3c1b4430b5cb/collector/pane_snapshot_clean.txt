## Solution

We solve
$$u_t = u_{xx} + \gamma,\quad 0<x<1,\ t>0,\qquad u(0,t)=A,\ u(1,t)=B,\ u(x,0)=0,
$$
with $\gamma,A,B>0$. (The symbol $\nu$ in the boundary conditions is read as $u$
.)

### Step 1. Steady-state (equilibrium) solution

Seek a time-independent solution $U(x)$ satisfying the PDE and the boundary cond
itions:
$$0 = U''(x) + \gamma,\qquad U(0)=A,\quad U(1)=B.$$
Integrating twice,
$$U(x) = -\tfrac{\gamma}{2}x^{2} + c_{1}x + c_{2}.$$
From $U(0)=A$: $c_{2}=A$. From $U(1)=B$: $-\tfrac{\gamma}{2}+c_{1}+A=B$, giving
$c_{1}=B-A+\tfrac{\gamma}{2}$. Hence
$$\boxed{U(x) = -\tfrac{\gamma}{2}x^{2} + \bigl(B-A+\tfrac{\gamma}{2}\bigr)x + A
.}$$
One checks $U''(x)=-\gamma$, so $U''+\gamma=0$; and $U(0)=A$, $U(1)=B$. ✓

### Step 2. Reduction to a homogeneous problem

Set $v(x,t) = u(x,t) - U(x)$. Then
$$v_t = u_t = u_{xx}+\gamma = (v_{xx}+U'')+\gamma = v_{xx}+(-\gamma)+\gamma = v_
{xx},$$
with homogeneous boundary conditions
$$v(0,t)=u(0,t)-U(0)=A-A=0,\qquad v(1,t)=u(1,t)-U(1)=B-B=0,$$
and initial data
$$v(x,0) = u(x,0)-U(x) = -U(x).$$

### Step 3. Solve the homogeneous IBVP by separation of variables

The eigenfunctions of $-\partial_{xx}$ on $(0,1)$ with Dirichlet boundary condit
ions are $\sin(n\pi x)$, $n=1,2,\dots$, with eigenvalues $n^{2}\pi^{2}$. Thus
$$v(x,t) = \sum_{n=1}^{\infty} b_{n}\,\sin(n\pi x)\,e^{-n^{2}\pi^{2}t},$$
where the coefficients are the Fourier sine coefficients of $-U$:
$$b_{n} = 2\int_{0}^{1}(-U(x))\sin(n\pi x)\,dx = -2\int_{0}^{1}U(x)\sin(n\pi x)\
,dx.$$

### Step 4. Compute $b_{n}$

Write $\alpha = n\pi$ and $U(x) = -\tfrac{\gamma}{2}x^{2} + (B-A+\tfrac{\gamma}{
2})x + A$. Using the standard integrals (with $\cos\alpha=(-1)^{n}$, $\sin\alpha
=0$):
$$\int_{0}^{1}\sin(\alpha x)\,dx = \frac{1-(-1)^{n}}{\alpha},$$
$$\int_{0}^{1}x\sin(\alpha x)\,dx = -\frac{(-1)^{n}}{\alpha},$$
$$\int_{0}^{1}x^{2}\sin(\alpha x)\,dx = -\frac{(-1)^{n}}{\alpha} - \frac{2\bigl(
1-(-1)^{n}\bigr)}{\alpha^{3}},$$
we obtain
$$\int_{0}^{1}U(x)\sin(\alpha x)\,dx
= \frac{(A-B)(-1)^{n}}{\alpha} + \bigl(1-(-1)^{n}\bigr)\!\left(\frac{\gamma}{\al
pha^{3}}+\frac{A}{\alpha}\right).$$
Therefore
$$\boxed{\,b_{n} = -2\!\left[\frac{(A-B)(-1)^{n}}{n\pi} + \bigl(1-(-1)^{n}\bigr)
\!\left(\frac{\gamma}{n^{3}\pi^{3}}+\frac{A}{n\pi}\right)\right].\,}$$

### Step 5. Assemble the solution

$$\boxed{\,u(x,t) = U(x) + \sum_{n=1}^{\infty} b_{n}\,\sin(n\pi x)\,e^{-n^{2}\pi
^{2}t},\,}$$
i.e.
$$u(x,t) = -\tfrac{\gamma}{2}x^{2} + \bigl(B-A+\tfrac{\gamma}{2}\bigr)x + A \;-\
; 2\sum_{n=1}^{\infty}\!\left[\frac{(A-B)(-1)^{n}}{n\pi} + \bigl(1-(-1)^{n}\bigr
)\!\left(\frac{\gamma}{n^{3}\pi^{3}}+\frac{A}{n\pi}\right)\right]\sin(n\pi x)\,e
^{-n^{2}\pi^{2}t}.$$

### Step 6. Verification

- **PDE.** For $t>0$ the series and all its derivatives converge uniformly (expo
nential factor $e^{-n^{2}\pi^{2}t}$), so termwise differentiation is valid. Each
 term $\sin(n\pi x)e^{-n^{2}\pi^{2}t}$ satisfies the heat equation $w_t=w_{xx}$,
 and $U''+\gamma=0$, hence $u_t=u_{xx}+\gamma$. ✓
- **Boundary conditions.** At $x=0$ and $x=1$ every $\sin(n\pi x)$ vanishes, so
$u(0,t)=U(0)=A$ and $u(1,t)=U(1)=B$. ✓
- **Initial condition.** For $0<x<1$, the Fourier sine series of the (piecewise
smooth) function $U$ converges pointwise to $U(x)$, so $u(x,0)=U(x)+\sum b_{n}\s
in(n\pi x)=U(x)-U(x)=0$. (At the endpoints the boundary values $A,B$ take over,
which is the standard compatibility behavior.) ✓
- **Long-time behavior.** As $t\to\infty$, the transient series decays to $0$ an
d $u(x,t)\to U(x)$, the physically expected steady-state temperature profile of
a rod with internal heat generation $\gamma$ and held at temperatures $A$, $B$ a
t its ends. ✓

This completes the solution.
