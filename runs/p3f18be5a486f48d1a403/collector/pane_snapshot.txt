Looking at this problem, I need to find the minimum λ such that for all n ≥ 2 an
d positive reals a_i with ∑a_i = n: ∑1/a_i − λ∏1/a_i ≤ n − λ.

**Answer: λ = e.**

## Proof

### Part 1: λ = e is sufficient

Define F(a₁,…,aₙ) = ∑1/aᵢ − e∏1/aᵢ on the open simplex Ω = {aᵢ > 0, ∑aᵢ = n}. We
 show max F = n − e.

**Step 1: The only critical point of F in Ω is aᵢ = 1 for all i.**

By Lagrange multipliers, at a critical point there exists μ with:
$$-\frac{1}{a_i^2} + e\prod_{j\neq i}\frac{1}{a_j} = \mu \quad \text{for all } i
.$$

Setting p = ∏1/aⱼ, note ∏_{j≠i} 1/aⱼ = p·aᵢ, so the condition becomes:
$$-\frac{1}{a_i^2} + ep\,a_i = \mu \quad \text{for all } i.$$

If aᵢ ≠ aⱼ for some i, j, subtracting gives:
$$ep(a_i - a_j) = \frac{1}{a_i^2} - \frac{1}{a_j^2} = -\frac{(a_i-a_j)(a_i+a_j)}
{a_i^2 a_j^2}.$$

Dividing by (aᵢ − aⱼ) ≠ 0 yields ep = −(aᵢ+aⱼ)/(aᵢ²aⱼ²) < 0, contradicting ep >
0. So all aᵢ are equal, hence aᵢ = 1. At this point F = n − e.

**Step 2: F → −∞ at the boundary of Ω.**

Suppose a₁,…,aₖ → 0 (k ≥ 1) while a_{k+1},…,aₙ stay bounded below, with T = ∑_{i
=1}^k aᵢ → 0. Fix a_{k+1},…,aₙ and let P = ∏_{j>k} 1/aⱼ > 0, C = ∑_{j>k} 1/aⱼ (b
ounded). Optimize over a₁,…,aₖ with ∑aᵢ = T. By the identical Lagrange argument
(applied to ∑1/aᵢ − eP∏1/aᵢ), the only critical point is a₁ = ⋯ = aₖ = T/k, wher
e:

$$F \leq \frac{k^2}{T} - eP\left(\frac{k}{T}\right)^k + C.$$

- **k = 1:** F ≤ (1 − eP)/T + C. By AM-GM, ∏_{j=2}^n aⱼ ≤ (n/(n−1))^{n−1}, so P
≥ ((n−1)/n)^{n−1}. Since (n/(n−1))^{n−1} = (1+1/(n−1))^{n−1} < e (the sequence (
1+1/m)^m is strictly increasing to e), we get eP ≥ e·((n−1)/n)^{n−1} > 1, so F →
 −∞.

- **k ≥ 2:** The term (k/T)^k dominates k²/T as T → 0, so F → −∞.

**Step 3: Conclusion.** Since F → −∞ at every boundary face and the unique inter
ior critical point is (1,…,1) with F = n − e, the global maximum is n − e. Thus
∑1/aᵢ − e∏1/aᵢ ≤ n − e for all n ≥ 2. ✓

### Part 2: λ < e is insufficient

For λ < e, choose n large enough that (n/(n−1))^{n−1} > λ (possible since (1+1/(
n−1))^{n−1} ↗ e). Set a₁ = ε, a₂ = ⋯ = aₙ = (n−ε)/(n−1). As ε → 0⁺:

$$\sum \frac{1}{a_i} - \lambda\prod \frac{1}{a_i} = \frac{1}{\varepsilon}\left[1
 - \lambda\left(\frac{n-1}{n-\varepsilon}\right)^{n-1}\right] + \frac{(n-1)^2}{n
-\varepsilon} \to +\infty,$$

since 1 − λ·((n−1)/n)^{n−1} = 1 − λ/(n/(n−1))^{n−1} > 0. This exceeds n − λ for
small ε, so the inequality fails.

### Result

The minimum value of λ is **e**.
