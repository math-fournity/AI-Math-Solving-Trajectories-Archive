## Proof

We take as the definition of **Kazhdan's property (T)** the following:

> A locally compact group $G$ has property (T) if every unitary representation $
(\pi, \mathcal{H})$ of $G$ that has **almost-invariant vectors** has a nonzero i
nvariant vector.

Recall that a representation $(\pi,\mathcal{H})$ has *almost-invariant vectors*
if for every compact subset $K\subseteq G$ and every $\varepsilon>0$, there exis
ts a unit vector $v\in\mathcal{H}$ such that
$$\|\pi(g)v - v\| < \varepsilon \quad\text{for all } g\in K.$$

A vector $v$ is *$(\varepsilon, K)$-invariant* if $\|\pi(g)v-v\|<\varepsilon$ fo
r all $g\in K$.

We must show: **there exist a compact set $C\subseteq G$ and $\varepsilon>0$ suc
h that every unitary representation having an $(\varepsilon,C)$-invariant vector
 has a nonzero invariant vector.**

We argue by contradiction.

---

### Assuming no Kazhdan pair exists

Suppose no such pair $(C,\varepsilon)$ exists. Then for **every** compact $K\sub
seteq G$ and every $\varepsilon>0$, there is a unitary representation $(\pi_{K,\
varepsilon},\mathcal{H}_{K,\varepsilon})$ of $G$ that

1. has an $(\varepsilon,K)$-invariant unit vector, yet
2. has **no** nonzero invariant vector.

For each pair $(K,\varepsilon)$, fix such a representation and choose a unit vec
tor $v_{K,\varepsilon}\in\mathcal{H}_{K,\varepsilon}$ that is $(\varepsilon,K)$-
invariant.

### Constructing a counterexample representation

Index the set of all pairs $(K,\varepsilon)$ with $K\subseteq G$ compact and $\v
arepsilon>0$ by a set $I$. Form the Hilbert-space direct sum
$$\mathcal{H} \;=\; \bigoplus_{(K,\varepsilon)\in I} \mathcal{H}_{K,\varepsilon}
,$$
i.e. the space of all tuples $(w_{K,\varepsilon})_{(K,\varepsilon)\in I}$ with $
w_{K,\varepsilon}\in\mathcal{H}_{K,\varepsilon}$ and $\sum \lVert w_{K,\varepsil
on}\rVert^2 <\infty$, equipped with the natural inner product. This is a Hilbert
 space for an index set of arbitrary cardinality.

Define the unitary representation
$$\pi = \bigoplus_{(K,\varepsilon)\in I} \pi_{K,\varepsilon}, \qquad \pi(g)\bigl
[(w_{K,\varepsilon})\bigr] = \bigl(\pi_{K,\varepsilon}(g)\,w_{K,\varepsilon}\big
r).$$
Each $\pi_{K,\varepsilon}$ is unitary, so $\pi$ is a well-defined unitary repres
entation of $G$ on $\mathcal{H}$.

### $\pi$ has almost-invariant vectors

Let $C\subseteq G$ be compact and let $\eta>0$. The pair $(C,\eta)$ belongs to t
he index set $I$. Embed $v_{C,\eta}$ into $\mathcal{H}$ as the tuple that is $v_
{C,\eta}$ in the $(C,\eta)$-component and $0$ elsewhere; this is a unit vector i
n $\mathcal{H}$. For every $g\in C$,
$$\|\pi(g)v_{C,\eta}-v_{C,\eta}\|_{\mathcal{H}} = \|\pi_{C,\eta}(g)v_{C,\eta}-v_
{C,\eta}\|_{\mathcal{H}_{C,\eta}} < \eta.$$
Since $C$ and $\eta$ were arbitrary, $\pi$ has almost-invariant vectors.

### $\pi$ has no nonzero invariant vector

Let $w=(w_{K,\varepsilon})\in\mathcal{H}$ be $\pi$-invariant, i.e. $\pi(g)w=w$ f
or all $g\in G$. Componentwise this gives $\pi_{K,\varepsilon}(g)\,w_{K,\varepsi
lon}=w_{K,\varepsilon}$ for all $g\in G$ and every $(K,\varepsilon)\in I$. Thus
each $w_{K,\varepsilon}$ is a $\pi_{K,\varepsilon}$-invariant vector. By constru
ction (point 2 above), $\mathcal{H}_{K,\varepsilon}$ has **no** nonzero invarian
t vector, so $w_{K,\varepsilon}=0$ for every $(K,\varepsilon)$. Hence $w=0$.

Therefore $\pi$ has almost-invariant vectors but no nonzero invariant vector.

### Contradiction

This contradicts the hypothesis that $G$ has property (T). The contradiction was
 derived from the assumption that no Kazhdan pair $(C,\varepsilon)$ exists. Cons
equently, there **must** exist a compact subset $C\subseteq G$ and some $\vareps
ilon>0$ such that every unitary representation of $G$ possessing an $(\varepsilo
n,C)$-invariant vector has a nonzero invariant vector. $\blacksquare$
