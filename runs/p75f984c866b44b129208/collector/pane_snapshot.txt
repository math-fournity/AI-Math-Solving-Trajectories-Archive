**Definition.** A number $x \in [0,1]$ is *binarily universal* if every finite b
inary string $s \in \{0,1\}^*$ appears as a contiguous block somewhere in the bi
nary expansion of $x$. Let $U \subseteq [0,1]$ denote the set of all binarily un
iversal numbers.

---

### Part 1: $U$ is a Borel set.

Write the binary expansion $x = \sum_{i=1}^{\infty} b_i(x)\,2^{-i}$ with $b_i(x)
\in\{0,1\}$, using the convention that for dyadic rationals we take the terminat
ing expansion (ending in all $0$s). This convention affects only countably many
points and is irrelevant for both Borelness and measure.

For a finite string $s = s_1\cdots s_k$ of length $k$ and an integer $n \ge 0$,
define
$$B_{s,n} = \bigl\{x \in [0,1] : b_{n+1}(x)=s_1,\; b_{n+2}(x)=s_2,\;\ldots,\; b_
{n+k}(x)=s_k\bigr\}.$$
The condition "the bits at positions $n{+}1,\ldots,n{+}k$ are prescribed" carves
 out a finite union of dyadic intervals of length $2^{-(n+k)}$, so $B_{s,n}$ is
a Borel set (a finite union of intervals).

Define
$$A_s = \bigcup_{n=0}^{\infty} B_{s,n},$$
the set of all $x$ whose binary expansion contains $s$ as a contiguous block. Th
is is a countable union of Borel sets, hence Borel.

Since $\{0,1\}^*$ is countable,
$$U = \bigcap_{s \in \{0,1\}^*} A_s$$
is a **countable intersection of Borel sets**, hence **Borel**. $\quad\blacksqua
re$

---

### Part 2: The Lebesgue measure of $U$ is $1$.

**Key fact.** Under Lebesgue measure on $[0,1]$, the binary digits $b_1, b_2, b_
3, \ldots$ are i.i.d. Bernoulli$(\tfrac12)$ random variables. (This is the stand
ard correspondence between Lebesgue measure on $[0,1]$ and the fair-coin product
 measure on $\{0,1\}^{\mathbb{N}}$; the only discrepancy is the countable set of
 dyadic rationals, which has measure $0$.)

Fix a string $s$ of length $k$. Consider the subsequence of events
$$E_j := B_{s,\,jk}, \qquad j = 0, 1, 2, \ldots$$
These events concern *disjoint* blocks of binary digits (positions $jk{+}1,\ldot
s,jk{+}k$), so the $E_j$ are **mutually independent**, and each has probability
$$\mathbb{P}(E_j) = 2^{-k} > 0.$$

Therefore
$$\sum_{j=0}^{\infty} \mathbb{P}(E_j) = \sum_{j=0}^{\infty} 2^{-k} = +\infty.$$

By the **second Borel–Cantelli lemma** (independence + divergent sum of probabil
ities),
$$\mathbb{P}\!\left(\limsup_{j\to\infty} E_j\right) = 1.$$
That is, for almost every $x \in [0,1]$, the string $s$ appears in the binary ex
pansion of $x$ at positions $jk{+}1,\ldots,jk{+}k$ for infinitely many $j$. In p
articular, $s$ appears at least once. Hence
$$m(A_s) = 1 \quad \text{for every } s \in \{0,1\}^*.$$

Now $U = \bigcap_{s} A_s$ is a countable intersection of full-measure sets:
$$m(U) = m\!\left(\bigcap_{s} A_s\right) = 1 - m\!\left(\bigcup_{s} A_s^c\right)
 \ge 1 - \sum_{s} m(A_s^c) = 1 - 0 = 1.$$

Since $U \subseteq [0,1]$, we conclude $m(U) = 1$.

---

### Conclusion

The set $U$ of binarily universal members of $[0,1]$ is a **Borel set** (specifi
cally, a countable intersection of $F_\sigma$ sets, i.e., a $G_{\delta\sigma}$-t
ype set), and its **Lebesgue (Borel) measure is $1$**.

In words: almost every real number in $[0,1]$ contains every finite binary patte
rn somewhere in its binary expansion.
