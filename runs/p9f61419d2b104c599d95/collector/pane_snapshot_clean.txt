## Solution

We solve the heat equation $u_t = D\,u_{xx}$ on $\mathbb{R}$ with $D = \tfrac{1}
{100}$ and initial data
$$u_0(x) = 100\,\mathbf{1}_{(-2,0)}(x) + 50\,\mathbf{1}_{(0,1)}(x).$$

**Heat kernel.** The fundamental solution is
$$\Phi(x,t) = \frac{1}{\sqrt{4\pi D t}}\,e^{-x^2/(4Dt)}.$$
Since $4Dt = \tfrac{t}{25}$, we have $\sqrt{4\pi Dt} = \tfrac{\sqrt{\pi t}}{5}$,
 so $\Phi(x,t) = \tfrac{5}{\sqrt{\pi t}}\,e^{-25x^2/t}$.

**Convolution formula.** The solution is $u(x,t) = \int_{-\infty}^{\infty}\Phi(x
-y,t)\,u_0(y)\,dy$. Using the standard identity (with $\sigma = \sqrt{4Dt} = \tf
rac{\sqrt{t}}{5}$):
$$\int_a^b \Phi(x-y,t)\,dy = \frac{1}{2}\Bigl[\operatorname{erf}\!\Bigl(\tfrac{5
(b-x)}{\sqrt{t}}\Bigr) - \operatorname{erf}\!\Bigl(\tfrac{5(a-x)}{\sqrt{t}}\Bigr
)\Bigr],$$
we obtain
$$u(x,t) = 100\cdot\tfrac{1}{2}\Bigl[\operatorname{erf}\!\bigl(\tfrac{-5x}{\sqrt
{t}}\bigr)-\operatorname{erf}\!\bigl(\tfrac{-5(x+2)}{\sqrt{t}}\bigr)\Bigr] + 50\
cdot\tfrac{1}{2}\Bigl[\operatorname{erf}\!\bigl(\tfrac{5(1-x)}{\sqrt{t}}\bigr)-\
operatorname{erf}\!\bigl(\tfrac{-5x}{\sqrt{t}}\bigr)\Bigr].$$

Applying $\operatorname{erf}(-z)=-\operatorname{erf}(z)$ and collecting terms:

$$\boxed{\;u(x,t) = 50\,\operatorname{erf}\!\Bigl(\tfrac{5(x+2)}{\sqrt{t}}\Bigr)
 - 25\,\operatorname{erf}\!\Bigl(\tfrac{5x}{\sqrt{t}}\Bigr) + 25\,\operatorname{
erf}\!\Bigl(\tfrac{5(1-x)}{\sqrt{t}}\Bigr),\quad t>0.\;}$$

**Verification of the initial condition** ($t\to 0^+$, using $\operatorname{erf}
(\pm\infty)=\pm 1$):

  $u\to 50(1)-25(-1)+25(1)=50+25+25=100$. ✓

- **$0<x<1$:** all three arguments $\to+\infty\Rightarrow 1$.
  $u\to 50-25+25=50$. ✓

  $u\to 50(-1)-25(-1)+25(1)=-50+25+25=0$. ✓

- **$x>1$:** $\tfrac{5(x+2)}{\sqrt t}\to+\infty\Rightarrow 1$; $\tfrac{5x}{\sqrt
 t}\to+\infty\Rightarrow 1$; $\tfrac{5(1-x)}{\sqrt t}\to-\infty\Rightarrow -1$.

,\qquad \partial_{xx}\,\operatorname{erf}(\xi) = \Bigl(\tfrac{5}{\sqrt t}\Bigr)^
