## Solution

**Finding P.** The line $y = x$ meets the parabola $y = \frac{x^2}{d}$ where $x
= \frac{x^2}{d}$, giving $x = 0$ or $x = d$. Since $P \neq$ origin, $P = (d, d)$
.

**Setting up the circle.** At $P$, the parabola has slope $y' = \frac{2x}{d}\big
|_{x=d} = 2$, so the tangent line has slope $2$ and the normal has slope $-\tfra
c{1}{2}$.

Since $C$ is tangent to the $y$-axis at $Q$, its center is at $(r, c)$ with radi
us $r$, and $Q = (0, c)$.

**Conditions:**
1. $P \in C$: $(d-r)^2 + (d-c)^2 = r^2$.
2. Radius $\overrightarrow{(r,c)\to(d,d)}$ is perpendicular to the tangent (slop
e $2$): $\frac{d-c}{d-r} = -\frac{1}{2}$, i.e. $r = 3d - 2c$.

Let $u = d - r$, $v = d - c$, so $v = -u/2$. The circle equation gives $u^2 + v^
2 = r^2$, i.e. $\tfrac{5}{4}u^2 = r^2$. Since $r = d - u$:
$$\tfrac{5}{4}u^2 = (d-u)^2 \implies u^2 + 8du - 4d^2 = 0 \implies u = d(-4 \pm
2\sqrt{5}).$$

Then $c = d - v = d + \tfrac{u}{2}$, giving:
- **Case 1:** $c = d(\sqrt{5}-1)$, so $c + d = d\sqrt{5}$.
- **Case 2:** $c = -d(\sqrt{5}+1)$, so $c + d = -d\sqrt{5}$.

Both yield the same $|c+d| = d\sqrt{5}$.

**Computing $S_1$.** The line $PQ$ (through $Q=(0,c)$ and $P=(d,d)$) has equatio
n $y = c + \frac{d-c}{d}x$. Its intersections with $y = \frac{x^2}{d}$ satisfy:
$$x^2 - (d-c)x - cd = 0 \implies x = d \text{ or } x = -c.$$

The enclosed area is:
$$S_1 = \int_{-c}^{d}\!\left(c + \tfrac{d-c}{d}x - \tfrac{x^2}{d}\right)dx = \le
ft[cx + \tfrac{d-c}{2d}x^2 - \tfrac{x^3}{3d}\right]_{-c}^{d}.$$

Evaluating:
- At $x = d$: $\;cd + \frac{(d-c)d}{2} - \frac{d^2}{3} = \frac{cd}{2} + \frac{d^
2}{6}$.
- At $x = -c$: $\;-c^2 + \frac{(d-c)c^2}{2d} + \frac{c^3}{3d} = -\frac{c^2}{2} -
 \frac{c^3}{6d}$.

Therefore:
$$S_1 = \frac{cd}{2} + \frac{c^2}{2} + \frac{d^2}{6} + \frac{c^3}{6d} = \frac{3c
d^2 + 3c^2d + c^3 + d^3}{6d} = \frac{(c+d)^3}{6d}.$$

Taking the (positive) area: $S_1 = \dfrac{|c+d|^3}{6d} = \dfrac{(d\sqrt{5})^3}{6
d} = \dfrac{5\sqrt{5}\,d^2}{6}.$

**Computing $S_2$.** The horizontal line through $P$ is $y = d$, meeting $y = \f
rac{x^2}{d}$ at $x = \pm d$:
$$S_2 = \int_{-d}^{d}\!\left(d - \tfrac{x^2}{d}\right)dx = \left[dx - \tfrac{x^3
}{3d}\right]_{-d}^{d} = \frac{2d^2}{3} - \left(-\frac{2d^2}{3}\right) = \frac{4d
^2}{3}.$$

**The ratio.**
$$\frac{S_1}{S_2} = \frac{5\sqrt{5}\,d^2/6}{4d^2/3} = \frac{5\sqrt{5}}{6}\cdot\f
rac{3}{4} = \boxed{\dfrac{5\sqrt{5}}{8}}.$$

### PROOF COMPLETE
