## Proof

**Yes, such integers exist.** We give an explicit construction with all of $a, b
, c$ nonzero.

**Setup.** Let $p_1, p_2, p_3$ be any three distinct odd primes. We seek integer
s $a, b, c$ (all nonzero) with $a^{p_1} + b^{p_2} = c^{p_3}$.

**Key idea.** Take $a, b, c$ to be powers of $2$: set $a = 2^{k_1},\; b = 2^{k_2
},\; c = 2^{k_3}$ for non-negative integers $k_1, k_2, k_3$ to be determined. Th
e equation becomes
$$2^{k_1 p_1} + 2^{k_2 p_2} = 2^{k_3 p_3}.$$

A sum of two powers of $2$ is itself a power of $2$ only when the two summands a
re equal (since $2^r + 2^r = 2^{r+1}$, and if $r < s$ then $2^r + 2^s = 2^r(1 +
2^{s-r})$ is a power of $2$ only when $s - r = 0$). So we require:
$$k_1 p_1 = k_2 p_2 =: N, \qquad k_3 p_3 = N + 1.$$

**Solving for $k_1, k_2$.** Since $p_1, p_2$ are distinct primes, $\operatorname
{lcm}(p_1, p_2) = p_1 p_2$. Thus $N$ must be a multiple of $p_1 p_2$; write $N =
 p_1 p_2 \cdot m$ for a positive integer $m$. Then
$$k_1 = p_2\, m, \qquad k_2 = p_1\, m.$$

**Solving for $k_3$ and $m$.** We need $k_3 p_3 = p_1 p_2\, m + 1$, i.e.,
$$p_3 \mid (p_1 p_2\, m + 1).$$
Since $p_3$ is a prime distinct from $p_1$ and $p_2$, the product $p_1 p_2$ is i
nvertible modulo $p_3$. Hence there exists a unique residue $m_0 \pmod{p_3}$ wit
h $p_1 p_2\, m_0 \equiv -1 \pmod{p_3}$. Choosing $m = m_0$ (or $m_0 + p_3$ to en
sure $m \geq 1$ if $m_0 = 0$, which cannot happen since $p_1 p_2 \not\equiv 0$),
 we get $k_3 = (p_1 p_2\, m + 1)/p_3$, a positive integer.

**Explicit example.** Take $p_1 = 3,\; p_2 = 5,\; p_3 = 7$. Then $p_1 p_2 = 15 \
equiv 1 \pmod{7}$, so $m \equiv -1 \equiv 6 \pmod{7}$. Choose $m = 6$:
- $N = 15 \cdot 6 = 90$,
- $k_1 = 5 \cdot 6 = 30$, $\;k_2 = 3 \cdot 6 = 18$, $\;k_3 = (90+1)/7 = 13$.

Set $a = 2^{30},\; b = 2^{18},\; c = 2^{13}$. Then:
$$a^3 + b^5 = (2^{30})^3 + (2^{18})^5 = 2^{90} + 2^{90} = 2 \cdot 2^{90} = 2^{91
},$$
$$c^7 = (2^{13})^7 = 2^{91}. \qquad \checkmark$$

**General construction.** For arbitrary distinct odd primes $p_1, p_2, p_3$:
1. Compute $m$ such that $p_1 p_2\, m \equiv -1 \pmod{p_3}$ (exists and is uniqu
e mod $p_3$ by invertibility).
2. Set $a = 2^{p_2 m},\; b = 2^{p_1 m},\; c = 2^{(p_1 p_2\, m + 1)/p_3}$.

Then $a^{p_1} + b^{p_2} = 2^{p_1 p_2 m} + 2^{p_1 p_2 m} = 2^{p_1 p_2 m + 1} = c^
{p_3}$.

**Conclusion.** For every triple of distinct odd primes $p_1, p_2, p_3$, there e
xist (nonzero) integers $a, b, c$ satisfying $a^{p_1} + b^{p_2} = c^{p_3}$.
