## Proof

**Claim:** Yes. There exists an infinite set $S$ such that $S$ is in bijection w
ith neither $\mathbb{R}$ nor $\mathbb{Z}$.

**Construction.** Let $S = \mathcal{P}(\mathbb{R})$, the power set of $\mathbb{R
}$.

**$S$ is infinite.** Since $\mathbb{R}$ is infinite, $\mathcal{P}(\mathbb{R})$ i
s infinite (it contains, for instance, all singleton sets $\{x\}$ for $x \in \ma
thbb{R}$, giving an injection $\mathbb{R} \hookrightarrow \mathcal{P}(\mathbb{R}
)$).

**No bijection between $S$ and $\mathbb{R}$.** By **Cantor's theorem** (which ho
lds in ZF, no Choice needed), for any set $X$ there is no surjection $X \to \mat
hcal{P}(X)$, hence no bijection. Applying this with $X = \mathbb{R}$:

$$|S| = |\mathcal{P}(\mathbb{R})| = 2^{|\mathbb{R}|} > |\mathbb{R}|.$$

So $S$ is strictly larger than $\mathbb{R}$; no bijection exists.

**No bijection between $S$ and $\mathbb{Z}$.** We have the chain of strict inequ
alities:

$$|\mathbb{Z}| = \aleph_0 < |\mathbb{R}| < |\mathcal{P}(\mathbb{R})| = |S|.$$

The first inequality ($\mathbb{Z}$ is countable, $\mathbb{R}$ is not) is classic
al. The second is Cantor's theorem as above. Since $|S| > |\mathbb{R}| > |\mathb
b{Z}|$, in particular $|S| \neq |\mathbb{Z}|$, so there is no bijection between
$S$ and $\mathbb{Z}$.

**Conclusion.** $S = \mathcal{P}(\mathbb{R})$ is an infinite set that is in bije
ction with neither $\mathbb{R}$ (by Cantor's theorem) nor $\mathbb{Z}$ (since it
 is uncountable and in fact strictly larger than $\mathbb{R}$). $\blacksquare$
