We seek ordered pairs of integers $(x,y)$ with $x \neq 0$, $y \neq 0$ satisfying
$$\frac{x^2}{y} - \frac{y^2}{x} = 3\!\left(2 + \frac{1}{xy}\right).$$

**Clearing denominators.** Multiplying both sides by $xy$ (valid since $xy \neq
0$):
$$x^3 - y^3 = 6xy + 3. \tag{1}$$

**Substitution.** Let $d = x - y$. Using $x^3 - y^3 = d^3 + 3xy\,d$, equation (1
) becomes
$$d^3 + 3xy\,d = 6xy + 3,$$
$$d^3 - 3 = 3xy(2 - d). \tag{2}$$

**Case $d = 2$:** Then $d^3 - 3 = 5$ but the RHS of (2) is $0$ — contradiction.
No solutions.

**Case $d \neq 2$:** From (2),
$$3xy = \frac{d^3 - 3}{2 - d} = -\frac{d^3 - 3}{d - 2}.$$
Polynomial division gives $d^3 - 3 = (d-2)(d^2 + 2d + 4) + 5$, so
$$3xy = -\!\left(d^2 + 2d + 4 + \frac{5}{d-2}\right).$$

For $xy \in \mathbb{Z}$, we need $(d-2) \mid 5$, so $d - 2 \in \{\pm 1, \pm 5\}$
, i.e. $d \in \{3, 1, 7, -3\}$.

| $d$ | $d-2$ | $5/(d-2)$ | $3xy$ | $xy$ | $x-y=d$, integer solutions? |
|-----|-------|-----------|-------|------|------------------------------|
| $3$ | $1$ | $5$ | $-(9+6+4+5)=-24$ | $-8$ | $y^2+3y+8=0$, disc. $-23<0$ — none
 |
| $1$ | $-1$ | $-5$ | $-(1+2+4-5)=-2$ | $-2/3$ | not integer — none |
| $7$ | $5$ | $1$ | $-(49+14+4+1)=-68$ | $-68/3$ | not integer — none |
| $-3$ | $-5$ | $-1$ | $-(9-6+4-1)=-6$ | $-2$ | see below |

**Only $d = -3$ survives.** Here $x - y = -3$ and $xy = -2$. Setting $x = y - 3$
:
$$(y-3)y = -2 \;\Longrightarrow\; y^2 - 3y + 2 = 0 \;\Longrightarrow\; (y-1)(y-2
) = 0.$$
- $y = 1 \Rightarrow x = -2$: check $\;\frac{4}{1} - \frac{1}{-2} = \frac{9}{2}$
, and $3(2 - \tfrac12) = \frac{9}{2}$. ✓
- $y = 2 \Rightarrow x = -1$: check $\;\frac{1}{2} - \frac{4}{-1} = \frac{9}{2}$
, and $3(2 - \tfrac12) = \frac{9}{2}$. ✓

Both pairs are valid (nonzero coordinates), and the divisibility argument shows
these are the **only** possibilities.

**The number of ordered pairs is $\boxed{2}$.**
