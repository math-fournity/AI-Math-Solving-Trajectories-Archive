## Solution

**Reformulating the condition.** In a functional graph of $f:[n]\to[n]$, every n
ode eventually reaches a cycle. The condition "$\exists b\ge1: f^b(1)=a$ and $\e
xists c\ge1: f^c(a)=1$" requires:
- $a$ is reachable from 1, and
- 1 is reachable from $a$.

If 1 is on a tail (not on a cycle) and $a$ is on the cycle it feeds, then $f^c(a
)$ stays on the cycle forever and can never return to 1 on the tail — fails. Sim
ilarly if 1 is on a cycle and $a$ is on a tail feeding it. The only way both rea
chability conditions hold is: **1 and $a$ are both on the same cycle** (includin
g the case $a=1$, meaning 1 is on a cycle).

**Counting functions where 1 is on a cycle of length $k$.** Choose the other $k-
1$ cycle nodes: $\binom{n-1}{k-1}$ ways. Arrange them cyclically with 1: $(k-1)!
$ ways. The $k$ cycle nodes' images under $f$ are then determined. The remaining
 $n-k$ nodes map freely: $n^{n-k}$ ways. The count is

$$\binom{n-1}{k-1}(k-1!\cdot n^{n-k} = \frac{(n-1)!}{(n-k)!}\cdot n^{n-k}.$$

So $P(\text{1 on cycle of length } k) = \dfrac{(n-1)!}{(n-k)!\cdot n^k}$.

**Averaging over $a$.** Since $a$ is uniform on $[n]$ and independent of $f$:

$$P = \frac{1}{n}\sum_{a=1}^{n} P(\text{1 and } a \text{ on same cycle}).$$

- For $a=1$: $P = P(\text{1 on a cycle}) = \sum_{k=1}^{n} \frac{(n-1)!}{(n-k)!\,
n^k}$.
- For $a\ne 1$: Given 1 is on a cycle of length $k$, node $a$ is on that same cy
cle with probability $\frac{k-1}{n-1}$. So

$$P(\text{1 and } a \text{ on same cycle}) = \sum_{k=1}^{n} \frac{(n-1)!}{(n-k)!
\,n^k}\cdot\frac{k-1}{n-1}.$$

Combining (the $n-1$ identical terms for $a\ne1$ cancel the $\frac{1}{n-1}$):

$$P = \frac{1}{n}\left[\sum_{k=1}^{n} \frac{(n-1)!}{(n-k)!\,n^k} + \sum_{k=1}^{n
} \frac{(n-1)!}{(n-k)!\,n^k}(k-1)\right] = \frac{1}{n}\sum_{k=1}^{n} \frac{k\,(n
-1)!}{(n-k)!\,n^k}.$$

**Evaluating the sum.** Substitute $j = n-k$:

$$S = \sum_{k=1}^{n} \frac{k\,(n-1)!}{(n-k)!\,n^k} = \frac{(n-1)!}{n^n}\sum_{j=0
}^{n-1} \frac{(n-j)\,n^j}{j!}.$$

Split the inner sum:

$$\sum_{j=0}^{n-1}\frac{(n-j)\,n^j}{j!} = n\sum_{j=0}^{n-1}\frac{n^j}{j!} - \sum
_{j=1}^{n-1}\frac{n^j}{(j-1)!} = n\sum_{j=0}^{n-1}\frac{n^j}{j!} - n\sum_{j=0}^{
n-2}\frac{n^j}{j!} = n\cdot\frac{n^{n-1}}{(n-1)!} = \frac{n^n}{(n-1)!}.$$

Therefore:

$$S = \frac{(n-1)!}{n^n}\cdot\frac{n^n}{(n-1)!} = 1,$$

and

$$\boxed{P = \frac{1}{n}\cdot 1 = \frac{1}{n}.}$$

**Verification.**
- $n=1$: Only $f(1)=1$, $a=1$; condition holds. $P=1=1/1$. ✓
- $n=2$: Enumerating all $4\times2=8$ pairs $(f,a)$, the favorable cases are exa
ctly 4, giving $P=1/2$. ✓
- $n=3$: The sum $S = \frac{1}{3}+\frac{4}{9}+\frac{2}{9}=1$, so $P=1/3$. ✓

The probability that the transit map and station $a$ satisfy the mutual connecti
on requirement is $\dfrac{1}{n}$.
