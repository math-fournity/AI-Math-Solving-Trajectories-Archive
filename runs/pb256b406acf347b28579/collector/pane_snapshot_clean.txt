## Proof

Let $\mu_1, \ldots, \mu_m$ be the distinct eigenvalues of $A$, with algebraic mu
ltiplicities $n_1, \ldots, n_m$ (so $\sum n_i = n$). Since $A$ is nonsingular, e
very $\mu_i \neq 0$.

**Key observation.** Since $A$ is similar to $A^k$ for every $k \geq 1$, the mat
rices $A$ and $A^k$ have the same eigenvalues with the same multiplicities. In p
articular they have the same trace:

$$\operatorname{tr}(A^k) = \operatorname{tr}(A), \quad \text{for all } k \geq 1.
$$

The eigenvalues of $A^k$ are $\mu_1^k, \ldots, \mu_m^k$ (with multiplicities $n_
1, \ldots, n_m$), so

$$p_k := \operatorname{tr}(A^k) = \sum_{i=1}^{m} n_i\, \mu_i^k.$$

The equality $\operatorname{tr}(A^k) = \operatorname{tr}(A)$ gives $p_k = p_1$ f
or all $k \geq 1$.

**Deriving a Vandermonde system.** Since $p_k = p_{k+1}$ for every $k \geq 1$:

$$\sum_{i=1}^{m} n_i\, \mu_i^k = \sum_{i=1}^{m} n_i\, \mu_i^{k+1}, \quad k = 1,
2, 3, \ldots$$

Rearranging:

$$\sum_{i=1}^{m} n_i(1 - \mu_i)\, \mu_i^k = 0, \quad k = 1, 2, 3, \ldots$$

Set $c_i := n_i(1 - \mu_i)$. Taking $k = 1, 2, \ldots, m$ yields the linear syst
em

$$\sum_{i=1}^{m} c_i\, \mu_i^k = 0, \quad k = 1, \ldots, m.$$

In matrix form $M\mathbf{c} = \mathbf{0}$, where $M_{ki} = \mu_i^k$. We can fact
or

$$M = \operatorname{diag}(\mu_1, \ldots, \mu_m)\cdot V,$$

where $V_{ki} = \mu_i^{k-1}$ ($k = 1, \ldots, m$; $i = 1, \ldots, m$) is the Van
dermonde matrix. Hence

$$\det(M) = \left(\prod_{i=1}^{m} \mu_i\right)\cdot \prod_{1 \le i < j \le m}(\m
u_j - \mu_i).$$

Since the $\mu_i$ are **distinct** (so $\mu_j - \mu_i \neq 0$ for $i \neq j$) an
d **nonzero** (since $A$ is nonsingular), we have $\det(M) \neq 0$.

**Conclusion.** The only solution is $c_i = 0$ for all $i$, i.e.,

$$n_i(1 - \mu_i) = 0 \quad \text{for all } i = 1, \ldots, m.$$

Since each $n_i \geq 1 > 0$, we obtain $\mu_i = 1$ for every $i$. Therefore $1$
is the only eigenvalue of $A$. $\blacksquare$
