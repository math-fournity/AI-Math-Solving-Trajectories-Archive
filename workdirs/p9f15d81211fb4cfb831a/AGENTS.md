# Problem

A specialized architectural firm is designing a high-tech security perimeter for a rectangular plaza. The outer boundary of the restricted zone is defined by the set of all coordinates $(x, y)$ that satisfy the structural constraint $(|x| + |y| - 2)^2 = 1$. This perimeter forms two concentric diamond-shaped walkways centered at the origin.

A straight laser sensor is to be installed across the plaza. The path of this laser follows the linear trajectory $y = ax + 5$, where $a$ is a real-valued calibration constant representing the slope of the beam. The laser detects a "breach" at every point where its path intersects the security perimeter.

An engineer determines that for certain specific values of the calibration constant $a$, the laser will register exactly three distinct breach points. Let $S$ be the set of all such real values of $a$ that result in exactly three intersections.

Calculate the sum of the squares of all elements contained in set $S$.
