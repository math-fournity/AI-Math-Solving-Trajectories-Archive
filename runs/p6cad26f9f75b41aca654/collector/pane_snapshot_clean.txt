Looking at this problem, I need to find $c_n = \inf_{\{f_i\}} \sup_{\mathbf{x} \
in [0,1]^n} \left|\sum f_i(x_i) - \prod x_i\right|$, which is the best uniform a
pproximation of $\prod x_i$ by separable functions.

**Answer:** $c_n = \dfrac{n-1}{2n}$.

## Proof

**Notation.** Let $g(\mathbf{x}) = \prod_{i=1}^n x_i$ and $F(\mathbf{x}) = \sum_
{i=1}^n f_i(x_i)$. Set $h = g - F$.

### Upper Bound: $c_n \leq \frac{n-1}{2n}$

Choose $f_i(x) = \frac{x}{n} - \frac{n-1}{2n^2}$ for each $i$. Then:
$$F = \sum_{i=1}^n f_i(x_i) = \frac{1}{n}\sum_{i=1}^n x_i - \frac{n-1}{2n} = \ba
r{x} - \frac{n-1}{2n},$$
where $\bar{x} = \frac{1}{n}\sum x_i$. The error is:
$$h(\mathbf{x}) = \prod_{i=1}^n x_i - \bar{x} + \frac{n-1}{2n}.$$

This function $h$ is **multilinear** (affine in each variable separately). A mul
tilinear function on $[0,1]^n$ attains its maximum and minimum at the vertices $
\{0,1\}^n$, since for fixed values of all variables except $x_i$, it is affine i
n $x_i$, so the extremum over $x_i \in [0,1]$ occurs at $x_i \in \{0,1\}$.

At a corner where exactly $k$ of the $x_i$ equal $1$ (so $|S|=k$):
- $\prod x_i = \mathbb{1}[k=n]$, and $\bar{x} = k/n$.
- For $k < n$: $h = -\frac{k}{n} + \frac{n-1}{2n} = \frac{n-1-2k}{2n}$, so $|h|
= \frac{|n-1-2k|}{2n} \leq \frac{n-1}{2n}$ (maximum at $k=0$ or $k=n-1$).
- For $k = n$: $h = 1 - 1 + \frac{n-1}{2n} = \frac{n-1}{2n}$.

Thus $\|h\|_\infty = \frac{n-1}{2n}$, giving $c_n \leq \frac{n-1}{2n}$.

### Lower Bound: $c_n \geq \frac{n-1}{2n}$

For any choice of $f_i$, set $a_i = f_i(0)$, $b_i = f_i(1)$, $\alpha = \sum a_i$
, $d_i = b_i - a_i$. At corner $S \subseteq [n]$:
$$F(S) = \alpha + \sum_{i \in S} d_i, \qquad g(S) = \mathbb{1}[S = [n]].$$

Since $\sup_{\mathbf{x}} |h| \geq \max_{\text{corners}} |h|$, we need: there exi
st $\alpha, d_1, \dots, d_n$ with
$$|\alpha + \textstyle\sum_{i\in S} d_i| \leq c \quad \forall\, S \neq [n], \qqu
ad |1 - \alpha - \textstyle\sum_i d_i| \leq c. \tag{$\ast$}$$

**Symmetry reduction.** The constraints $(\ast)$ are symmetric under permutation
s of $(d_1,\dots,d_n)$ and define a convex feasible set. If $(\alpha, d_1, \dots
, d_n)$ is feasible with bound $c$, then so is the averaged solution $(\alpha, \
bar{d}, \dots, \bar{d})$ with $\bar{d} = \frac{1}{n}\sum d_i$. Hence we may assu
me $d_1 = \cdots = d_n = d$.

With symmetric $d$, the corner with $|S|=k$ gives $F = \alpha + kd$, and the con
straints become:
$$|\alpha + kd| \leq c \quad (k = 0, 1, \dots, n-1), \qquad |1 - \alpha - nd| \l
eq c. \tag{$\ast\ast$}$$

Assume $d > 0$ (the case $d \leq 0$ is analogous or weaker). The binding constra
ints from $k=0$ and $k=n-1$ give:
$$\alpha \geq -c, \qquad \alpha + (n-1)d \leq c \implies d \leq \frac{2c}{n-1}.$
$

From $k=n$: $\alpha \geq 1 - nd - c$. Combined with $\alpha \leq c - (n-1)d$ (fr
om $k=n-1$):
$$1 - nd - c \leq c - (n-1)d \implies 1 - d \leq 2c \implies d \geq 1 - 2c.$$

For feasibility, we need $1 - 2c \leq \frac{2c}{n-1}$, i.e.:
$$(n-1)(1-2c) \leq 2c \implies (n-1) \leq 2cn \implies c \geq \frac{n-1}{2n}.$$

### Conclusion

Both bounds give $c_n = \dfrac{n-1}{2n}$.

**Verification for small $n$:** $c_1 = 0$ (trivially, $f_1(x)=x$), $c_2 = \frac{
1}{4}$ (with $h = (x_1-\frac12)(x_2-\frac12)$), $c_3 = \frac{1}{3}$. All match t
he formula.
