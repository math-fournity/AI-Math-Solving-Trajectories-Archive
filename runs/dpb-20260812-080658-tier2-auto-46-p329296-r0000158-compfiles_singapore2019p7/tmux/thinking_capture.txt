Problem. Suppose $\tan x = 5$. Find the value of $\dfrac{6 + \sin 2x}{1 + \cos
2x}$.

Solution.

Using the double-angle identities expressed in terms of $\tan x$:

$$\sin 2x = \frac{2\tan x}{1+\tan^2 x}, \qquad \cos 2x = \frac{1-\tan^2 x}{1+
\tan^2 x}.$$

Substituting $\tan x = 5$:

$$\sin 2x = \frac{2\cdot 5}{1+25} = \frac{10}{26} = \frac{5}{13},$$

$$\cos 2x = \frac{1-25}{1+25} = \frac{-24}{26} = -\frac{12}{13}.$$

Now compute the expression:

$$\frac{6 + \sin 2x}{1 + \cos 2x} = \frac{6 + \frac{5}{13}}{1 + \left(-\frac{12}
{13}\right)} = \frac{\frac{78+5}{13}}{\frac{13-12}{13}} = \frac{\frac{83}{13}}
{\frac{1}{13}} = 83.$$
