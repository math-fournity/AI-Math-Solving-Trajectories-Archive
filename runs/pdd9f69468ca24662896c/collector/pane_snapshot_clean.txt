## Solution

**Claim:** Yes, such a function exists. In fact, $f = \mathbf{1}_{[0,1]}$ is an
example, and the complete set of solutions is (up to a.e. equivalence) the indic
ator functions of measurable sets of Lebesgue measure 1.

---

### Existence

Let $f = \mathbf{1}_{[0,1]}$. Then $f: \mathbb{R} \to [0,1]$ is measurable, and
for every natural number $n \ge 1$,
$$f^n = (\mathbf{1}_{[0,1]})^n = \mathbf{1}_{[0,1]},$$
so
$$\int_{\mathbb{R}} f^n\, dL^1 = L^1([0,1]) = 1. \quad\checkmark$$

---

### Necessity (characterization of all solutions)

Suppose $f:\mathbb{R}\to[0,1]$ is measurable with $\int_{\mathbb{R}} f^n\,dL^1 =
 1$ for every $n\ge 1$.

**Step 1: The set $\{f=1\}$ has measure 1.**

Since $0 \le f \le 1$, the sequence $(f^n)_{n\ge 1}$ is non-increasing and non-n
egative. It converges pointwise to
$$\lim_{n\to\infty} f^n(x) = \mathbf{1}_{\{f=1\}}(x).$$
Since $f^1 = f$ is integrable (its integral equals 1), the Monotone Convergence
Theorem (applied to the decreasing sequence via $f - f^n \ge 0$, which increases
 to $f - \mathbf{1}_{\{f=1\}}$) gives:
$$\lim_{n\to\infty}\int_{\mathbb{R}} f^n\,dL^1 = \int_{\mathbb{R}} \mathbf{1}_{\
{f=1\}}\,dL^1 = L^1(\{f=1\}).$$
Since $\int f^n = 1$ for all $n$, the left side equals 1, so
$$L^1(\{f=1\}) = 1.$$

**Step 2: $f = 0$ a.e. on $\{f < 1\}$.**

Set $A = \{f = 1\}$, so $L^1(A) = 1$. On $A$, we have $f^n = 1$, hence $\int_A f
^n\,dL^1 = L^1(A) = 1$ for every $n$. Since $\int_{\mathbb{R}} f^n = 1$, it foll
ows that
$$\int_{\mathbb{R}\setminus A} f^n\,dL^1 = 0 \quad\text{for every } n\ge 1.$$
Taking $n=1$: $\int_{\mathbb{R}\setminus A} f\,dL^1 = 0$. Since $f \ge 0$ on $\m
athbb{R}\setminus A$, this forces $f = 0$ a.e. on $\mathbb{R}\setminus A$.

**Step 3: Conclusion.**

We have shown $f = 1$ a.e. on $A$ and $f = 0$ a.e. on $\mathbb{R}\setminus A$, i
.e., $f = \mathbf{1}_A$ a.e., where $A$ is a measurable set with $L^1(A)=1$. Con
versely, every such indicator function satisfies $\int f^n = L^1(A) = 1$ for all
 $n\ge 1$.

Therefore, the solutions are exactly $\{f = \mathbf{1}_A \text{ a.e.} : A \text{
 measurable},\, L^1(A)=1\}$, and such functions exist (e.g., $f = \mathbf{1}_{[0
,1]}$). $\blacksquare$
