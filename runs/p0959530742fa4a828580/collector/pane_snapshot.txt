## Setup and Coordinates

Place the board with coordinates $(i,j)$ where $i$ is the row (from bottom, $1 \
le i \le n$) and $j$ is the column (from left, $1 \le j \le n$). The lower-left
corner is $(1,1)$. Firing a disc at $(i,j)$:
- places a disc at $(i+1,j)$ (above) and $(i,j+1)$ (right), each only if that ce
ll exists and is unoccupied;
- if $i=n$ (top row), no cell above, so only the right placement is attempted;
- if $j=n$ (rightmost column), no cell to the right, so only the above placement
 is attempted;
- at the corner $(n,n)$, nothing is placed.

## Key Observation: Each Cell Is Fired Exactly Once

**A cell is occupied at most once.** A new disc is placed only into an *unoccupi
ed* cell, and once occupied it stays until fired (removed). So no cell ever hold
s two discs, and no cell is fired more than once.

**A cell, once occupied, is eventually fired.** The game continues as long as th
e board is non-empty (we can always fire any existing disc), and ends only when
the board is empty. Hence every disc that is ever created is eventually fired.

**Every cell $(i,j)$ with $1 \le i,j \le n$ is created.** We prove this by induc
tion on $s = i+j$.

- *Base* $s=2$: $(1,1)$ is created initially.
- *Inductive step*: Take $(i,j)$ with $i+j = s > 2$. At least one of its parents
 exists and has sum $s-1$:
  - if $i > 1$, the parent $(i-1,j)$ (which fires upward to create $(i,j)$) has
sum $s-1$;
  - if $i = 1$, then $j > 1$, and the parent $(1,j-1)$ (which fires rightward to
 create $(i,j)$) has sum $s-1$.

  By the inductive hypothesis that parent is created, hence (by the previous poi
nt) eventually fired. When it fires, cell $(i,j)$ is still unoccupied (it has ne
ver been created before, since we're proving creation now), so the disc is place
d there. Thus $(i,j)$ is created.

This induction covers every cell in the $n \times n$ grid, including boundary ce
lls: $(n,j)$ is created by $(n-1,j)$ firing upward; $(i,n)$ is created by $(i,n-
1)$ firing rightward; $(n,n)$ is created by either $(n-1,n)$ or $(n,n-1)$.

## Counting the Moves

Since every one of the $n^2$ cells is created exactly once and fired exactly onc
e, and each firing is one move:

$$M(n) = n^2.$$

## Verification on Small Cases

- $n=2$: firing order $(1,1)\to(2,1)\to(1,2)\to(2,2)$ gives $4$ moves $=2^2$. ✓
- $n=3$: tracing the process, all $9$ cells are fired, $M(3)=9=3^2$. ✓
