## Key Observations

**Geometry of queries:** For a convex polygon, any line not through a vertex div
ides vertices into two **contiguous arcs**. Conversely, any contiguous arc can b
e isolated by some line. So each query reveals the sum of some contiguous block
of vertices.

**Strategic number choice:** Yugi chooses super-increasing numbers (e.g., $a_i =
 2^{i-1}$). Then any subset sum uniquely determines the subset, so each query's
answer reveals *exactly which numbers* lie in the queried arc.

## Lower Bound: $m(n) \geq \lceil n/2 \rceil$

**For any number choice and any strategy** (adaptive or not) using $k$ queries:

Fix any permutation $\pi$. The $k$ arcs have $2k$ endpoints on the circle, creat
ing at most $2k$ regions (maximal consecutive vertex-blocks sharing the same arc
-membership). If $2k < n$, some region contains $\geq 2$ vertices. Swapping the
values of two vertices in the same region produces $\pi'$ with **identical** ans
wers to every query (both vertices are always on the same side of every line), s
o the strategy cannot distinguish $\pi$ from $\pi'$. This holds for *every* $\pi
$, so $k \geq \lceil n/2 \rceil$ is necessary.

## Upper Bound: $m(n) \leq \lceil n/2 \rceil$

Using super-increasing numbers, I construct $k = \lceil n/2 \rceil$ arcs (non-ad
aptively) that create $n$ singleton regions.

**Even $n = 2m$:** Label vertices $0, \ldots, 2m{-}1$. Use $m$ arcs: arc $i$ (fo
r $i=0,\ldots,m{-}1$) contains vertices $\{i{+}1, \ldots, i{+}m\} \pmod{n}$, wit
h endpoints in gaps $i$ and $i{+}m$. These $2m = n$ endpoints occupy all $n$ dis
tinct gaps, yielding $n$ singleton regions. Each vertex has a distinct membershi

**Odd $n = 2m{+}1$:** Use $m{+}1$ arcs. Place 2 endpoints in gap 0, one in each
other gap ($2m{+}2 = n{+}1$ endpoints total). Pair them as:
- $(e_0, e_m)$: arc containing vertices $1, \ldots, m$
- $(e_0', e_{m+1})$: arc containing the complement of $\{1,\ldots,m{+}1\}$
- $(e_i, e_{i+m+1})$ for $i=1,\ldots,m{-}1$: arc containing vertices $i{+}1,\ldo

The $n{+}1$ endpoints create $n{+}1$ segments: one empty (between $e_0, e_0'$ in
 gap 0) and $n$ non-empty singletons. Crossing each endpoint flips membership in

**Verification for small cases:**
- $n=3$: 2 arcs create patterns $(0,1),(1,0),(0,0)$ for the 3 vertices. ✓

## Computing the Sum

$$m(n) = \left\lceil \frac{n}{2} \right\rceil$$
