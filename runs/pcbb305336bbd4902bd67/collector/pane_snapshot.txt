# Solution

**Answer: Statement (a) cannot be true.**

## Proof

We analyze each statement to determine whether there exists a bounded linear ope
rator $T$ on $H$ satisfying the given conditions.

---

### Statement (a): $T(e_n) = e_1$ for all $n = 1, 2, 3, \ldots$ — **CANNOT be tr
ue**

Suppose, for contradiction, that $T$ is a bounded linear operator with $T(e_n) =
 e_1$ for every $n$.

For each positive integer $N$, define
$$x_N = \frac{1}{\sqrt{N}}\sum_{n=1}^{N} e_n.$$

Then $\|x_N\|^2 = \frac{1}{N}\sum_{n=1}^{N}\|e_n\|^2 = \frac{1}{N}\cdot N = 1$,
so $\|x_N\| = 1$.

By linearity of $T$:
$$T(x_N) = \frac{1}{\sqrt{N}}\sum_{n=1}^{N} T(e_n) = \frac{1}{\sqrt{N}}\sum_{n=1
}^{N} e_1 = \frac{N}{\sqrt{N}}\, e_1 = \sqrt{N}\, e_1.$$

Therefore $\|T(x_N)\| = \sqrt{N}\,\|e_1\| = \sqrt{N}$.

If $T$ were bounded with operator norm $\|T\| = C$, we would need
$$\sqrt{N} = \|T(x_N)\| \le C\|x_N\| = C \quad \text{for all } N.$$

But $\sqrt{N} \to \infty$ as $N \to \infty$, a contradiction. Hence **no bounded
 linear operator** can satisfy $T(e_n) = e_1$ for all $n$.

---

### Statement (b): $T(e_n) = e_{n+1}$ for all $n$ — **CAN be true**

Define $T$ on the dense span by $T\!\left(\sum a_n e_n\right) = \sum a_n e_{n+1}
$. Then
$$\|T(x)\|^2 = \sum_{n=1}^{\infty}|a_n|^2 = \|x\|^2,$$
so $T$ is an **isometry** with $\|T\| = 1$. This is the (right) unilateral shift
, a well-defined bounded linear operator.

---

### Statement (c): $T(e_1) = 0$, $T(e_n) = e_{n-1}$ for $n \ge 2$ — **CAN be tru
e**

Define $T$ on the dense span by $T\!\left(\sum a_n e_n\right) = \sum_{n=2}^{\inf
ty} a_n\, e_{n-1}$. Then
$$\|T(x)\|^2 = \sum_{n=2}^{\infty}|a_n|^2 \le \sum_{n=1}^{\infty}|a_n|^2 = \|x\|
^2,$$
so $T$ is bounded with $\|T\| \le 1$. (In fact $\|T\| = 1$ since $\|T(e_2)\| = \
|e_1\| = 1$.) This is the (left) backward shift, a well-defined bounded linear o
perator.

---

### Conclusion

Statement **(a)** cannot be true: the condition $T(e_n) = e_1$ for all $n$ force
s $T$ to be unbounded, as shown by the sequence $x_N = \frac{1}{\sqrt{N}}\sum_{n
=1}^N e_n$ of unit vectors whose images have norms $\sqrt{N} \to \infty$.

Statements (b) and (c) are each realized by bounded linear operators (the right
shift and left shift, respectively).
