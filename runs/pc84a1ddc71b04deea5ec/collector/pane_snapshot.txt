## Solution

Let
$$a_n = \frac{n^{n+1/3}}{e^n\, n!}.$$

We compute the ratio of consecutive terms:
$$\frac{a_{n+1}}{a_n} = \frac{(n+1)^{n+1+1/3}}{e^{n+1}(n+1)!}\cdot\frac{e^n\, n!
}{n^{n+1/3}} = \frac{1}{e}\cdot\frac{(n+1)^{n+1/3}}{n^{n+1/3}} = \frac{1}{e}\lef
t(1+\frac{1}{n}\right)^{n+1/3}.$$

Taking logarithms:
$$\ln\frac{a_{n+1}}{a_n} = \left(n+\tfrac{1}{3}\right)\ln\!\left(1+\tfrac{1}{n}\
right) - 1. \tag{1}$$

**Taylor expansion.** For $n\ge 2$, the series $\ln(1+x)=x-\frac{x^2}{2}+\frac{x
^3}{3}-\cdots$ is alternating with decreasing magnitudes at $x=1/n$, so the rema
inder after the cubic term is bounded by $\frac{1}{4n^4}$. Hence
$$\ln\!\left(1+\tfrac{1}{n}\right) = \frac{1}{n}-\frac{1}{2n^2}+\frac{1}{3n^3}+O
\!\left(\tfrac{1}{n^4}\right).$$

Multiplying by $\left(n+\tfrac{1}{3}\right)$:
$$\left(n+\tfrac{1}{3}\right)\ln\!\left(1+\tfrac{1}{n}\right) = \underbrace{1}_{
\text{const}} + \underbrace{\left(\tfrac{1}{3}-\tfrac{1}{2}\right)}_{-\tfrac{1}{
6}}\frac{1}{n} + \underbrace{\left(-\tfrac{1}{6}+\tfrac{1}{3}\right)}_{\tfrac{1}
{6}}\frac{1}{n^2} + O\!\left(\tfrac{1}{n^3}\right).$$

Substituting into (1):
$$\ln\frac{a_{n+1}}{a_n} = -\frac{1}{6n}+\frac{1}{6n^2}+O\!\left(\tfrac{1}{n^3}\
right) = -\frac{1}{6n}+O\!\left(\tfrac{1}{n^2}\right). \tag{2}$$

**Telescoping the logarithm.** Write
$$\ln a_n = \ln a_1 + \sum_{k=1}^{n-1}\ln\frac{a_{k+1}}{a_k}.$$

By (2), for all sufficiently large $k$ (say $k\ge k_0$),
$$\ln\frac{a_{k+1}}{a_k} = -\frac{1}{6k}+O\!\left(\tfrac{1}{k^2}\right).$$

The finitely many terms with $k<k_0$ contribute a constant $C_0$. Therefore
$$\ln a_n = C_0 - \frac{1}{6}\sum_{k=k_0}^{n-1}\frac{1}{k} + \sum_{k=k_0}^{n-1}O
\!\left(\tfrac{1}{k^2}\right). \tag{3}$$

Now we use two standard facts (neither of which is Stirling's approximation):

- **Harmonic numbers:** $\displaystyle\sum_{k=1}^{n-1}\frac{1}{k} = \ln n + O(1)
$ (e.g. by comparison with $\int_1^n \frac{dx}{x}=\ln n$).
- **Convergence:** $\displaystyle\sum_{k=1}^{\infty}\frac{1}{k^2}<\infty$, so th
e last sum in (3) is bounded by an absolute constant $S$.

Thus (3) gives
$$\ln a_n = -\frac{1}{6}\ln n + O(1).$$

Exponentiating:
$$a_n = e^{-\frac{1}{6}\ln n + O(1)} = n^{-1/6}\cdot e^{O(1)}.$$

Since $e^{O(1)}$ is bounded above by some constant $M$, we obtain
$$0 \le a_n \le M\, n^{-1/6}\xrightarrow[n\to\infty]{}0.$$

By the squeeze theorem,
$$\boxed{\lim_{n\to\infty}\frac{n^{n+1/3}}{e^n\, n!}=0.}$$

The argument uses only the Taylor expansion of $\ln(1+1/n)$ (an alternating seri
es with controlled remainder) and the elementary estimate $H_n=\ln n+O(1)$ — no
form of Stirling's approximation is invoked.
