Looking at this problem, I need to find the maximum number of points in a unit r
egular hexagon with pairwise distances ≥ √2.

**Answer: n = 3**

## Proof

**Setup.** Place the regular hexagon (side length 1) centered at the origin O. I
ts circumradius is 1, so it is inscribed in the unit circle. Every point P in th
e hexagon satisfies |OP| ≤ 1, with equality only at the 6 vertices (which lie at
 angles 0°, 60°, 120°, 180°, 240°, 300°).

**Key Lemma.** *If two points P, Q in the hexagon satisfy ∠POQ ≤ 90°, then |PQ|
< √2.*

*Proof of Lemma.* Let r_P = |OP|, r_Q = |OQ|, and α = ∠POQ. By the law of cosine
s:
$$|PQ|^2 = r_P^2 + r_Q^2 - 2\,r_P\,r_Q \cos\alpha.$$

Since both points lie in the hexagon (inscribed in the unit circle), r_P, r_Q ≤
1.

- **If α < 90°:** cos α > 0, so |PQ|² = r_P² + r_Q² − 2r_P r_Q cos α < r_P² + r_
Q² ≤ 2. Hence |PQ| < √2.

- **If α = 90°:** cos α = 0, so |PQ|² = r_P² + r_Q² ≤ 2, with equality if and on
ly if r_P = r_Q = 1 (both are vertices). But the hexagon's vertices are spaced a
t 60° intervals, so **no two vertices are at 90°**. Therefore at least one of r_
P, r_Q is strictly less than 1, giving |PQ|² < 2, i.e., |PQ| < √2.

In both cases, |PQ| < √2. □

**Upper bound: n ≤ 3.** Suppose for contradiction that 4 points P₁, P₂, P₃, P₄ c
an be placed with all pairwise distances ≥ √2.

*No point is at the center:* if some P_i = O, then |OP_j| ≤ 1 < √2 for every oth
er point, so no other point can coexist — contradicting n ≥ 4. Hence every point
 has a well-defined angle θ_i from the center.

Sort the angles: θ₁ ≤ θ₂ ≤ θ₃ ≤ θ₄. The four consecutive gaps g₁ = θ₂−θ₁, g₂ = θ
₃−θ₂, g₃ = θ₄−θ₃, g₄ = 360°−θ₄+θ₁ sum to 360°. By the pigeonhole principle, the
smallest gap satisfies g_min ≤ 360°/4 = 90°.

The two points forming this minimum gap have angular separation min(g_min, 360°−
g_min) = g_min ≤ 90° (since g_min ≤ 90° < 180°). By the Lemma, their distance is
 strictly less than √2 — contradicting the requirement that all pairwise distanc
es are ≥ √2.

Therefore, **4 points are impossible**, so n ≤ 3.

**Lower bound: n = 3 is achievable.** Take the three alternating vertices at 0°,
 120°, 240°, i.e., (1, 0), (−1/2, √3/2), (−1/2, −√3/2). Each pair is separated b
y 120° > 90°, and the distance between any two is:
$$\sqrt{1 + 1 - 2\cos 120°} = \sqrt{2 - 2(-1/2)} = \sqrt{3} \geq \sqrt{2}. \chec
kmark$$

**Conclusion.** The largest natural number n is **3**.
