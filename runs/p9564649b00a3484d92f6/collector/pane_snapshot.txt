($\Longleftarrow$) If $Z = 0$, then $X = A$ is real, and for any real invertible

($\Longrightarrow$) Suppose $Y$ is a real invertible $n \times n$ matrix and $XY

$$XY = (A + iZ)\,Y = AY + i\,(ZY).$$
Since $A$, $Z$, and $Y$ are all real, both $AY$ and $ZY$ are real matrices. Ther
efore $XY$ is real if and only if its imaginary part vanishes:
$$ZY = 0.$$
Now, because $Y$ is invertible, we can right-multiply by $Y^{-1}$ (which is also

$$Z = (ZY)\,Y^{-1} = 0 \cdot Y^{-1} = 0.$$
Thus $Z = 0$, meaning $X = A$ is real. $\square$
