$$\coprod_{\lambda \in \Lambda} M_{\lambda} = \{(\lambda, x) : \lambda \in \Lamb

$$(\lambda, x) \sim (\mu, y) \iff \exists\,\nu,\ \text{morphisms } \lambda \to \
nu,\ \mu \to \nu \text{ such that } \varphi_{\lambda\nu}(x) = \varphi_{\mu\nu}(y

**Claim.** $\sim$ is an equivalence relation.

- *Reflexivity*: $(\lambda, x) \sim (\lambda, x)$ via $\nu = \lambda$ and the id
entity map.
- *Symmetry*: immediate from the symmetric definition.
- *Transitivity*: Suppose $(\lambda, x) \sim (\mu, y)$ and $(\mu, y) \sim (\rho,

$$\varphi_{\lambda\nu_3}(x) = \varphi_{\nu_1\nu_3}(\varphi_{\lambda\nu_1}(x)) =
\varphi_{\nu_1\nu_3}(\varphi_{\mu\nu_1}(y)) = \varphi_{\mu\nu_3}(y),$$

{\nu_2\nu_3}(\varphi_{\rho\nu_2}(z)) = \varphi_{\rho\nu_3}(z).$$
Hence $\varphi_{\lambda\nu_3}(x) = \varphi_{\rho\nu_3}(z)$, giving $(\lambda, x)

Define the **direct limit as a set**:
$$\varinjlim M_{\lambda} = \coprod_{\lambda} M_{\lambda} \big/ \sim.$$

Denote the equivalence class of $(\lambda, x)$ by $[(\lambda, x)]$ or $x_{\lambd

**Case $\mathcal{C} = \mathbf{Set}$:** The construction is complete. $\varinjlim

**Case $\mathcal{C} = R\text{-}\mathbf{Mod}$:** Each $M_{\lambda}$ is an $R$-mod

$$r \cdot [(\lambda, x)] = [(\lambda, r \cdot x)],$$

map to the same element at $\nu'$ by $R$-linearity of transition maps. Similarly

x')$, witnessed at $\nu$, then $\varphi_{\lambda\nu}(rx) = r\,\varphi_{\lambda\n
u}(x) = r\,\varphi_{\lambda'\nu}(x') = \varphi_{\lambda'\nu}(rx')$.

The zero element is $[(\lambda, 0)]$ for any $\lambda$, and $-[(\lambda, x)] = [

**Case $\mathcal{C} = R\text{-}\mathbf{Alg}$:** Each $M_{\lambda}$ is an $R$-alg
