## 解答

首先进行答案泄露自查：题目文本仅包含问题陈述，没有泄露的答案、证明草图或形式化注
释。继续进行求解。

**设定。** 设 $B_t$ 为标准布朗运动，从 $B_0 = 0$ 开始，设 $T = \inf\{t \ge 0 : |
B_t| = 1\}$ 为从区间 $(-1,1)$ 中的首次退出时间。我们要求解
$$\mathbb{E}\!\left[\int_0^T B_t^2\, dt\right].$$

**通过求解 Poisson 方程。** 定义
$$u(x) = \mathbb{E}_x\!\left[\int_0^T B_t^2\, dt\right],$$
其中 $\mathbb{E}_x$ 表示 $B_0 = x$。由 Feynman–Kac / Dynkin 公式可知，$u$ 满足边
界条件为 $u(-1)=u(1)=0$ 的 Poisson 方程
$$\tfrac{1}{2}\,u''(x) = -x^2, \qquad x \in (-1,1).$$

**求解 ODE。** 积分两次：
$$u''(x) = -2x^2, \qquad u'(x) = -\frac{2}{3}x^3 + C_1, \qquad u(x) = -\frac{1}{
6}x^4 + C_1 x + C_2.$$

应用边界条件：
$$u(1) = -\tfrac{1}{6} + C_1 + C_2 = 0, \qquad u(-1) = -\tfrac{1}{6} - C_1 + C_2
 = 0.$$

两式相减得 $2C_1 = 0$，因此 $C_1 = 0$。然后由任一方程得 $C_2 = \tfrac{1}{6}$。因
此
$$u(x) = \frac{1}{6} - \frac{x^4}{6}.$$

**在起始点求值。** 由于 $B_0 = 0$，
$$\mathbb{E}\!\left[\int_0^T B_t^2\, dt\right] = u(0) = \frac{1}{6}.$$

**通过 Green 函数进行验证。** 对于在 $(-1,1)$ 上具有 Dirichlet 边界条件的布朗运
动，其 Green 函数为 $G(x,y) = 1 - |y|$（当 $x=0$ 时，对称）。因此
$$\mathbb{E}\!\left[\int_0^T B_t^2\, dt\right] = \int_{-1}^{1} G(0,y)\,y^2\,dy =
 \int_{-1}^{1}(1-|y|)\,y^2\,dy = 2\int_0^1 (1-y)\,y^2\,dy = 2\!\left[\frac{1}{3}
-\frac{1}{4}\right] = \frac{1}{6},$$
这与之前的结果一致。

$$\boxed{\mathbb{E}\!\left(\int_{0}^{T} |B_{t}|^{2}\, dt\right) = \dfrac{1}{6}}$
$

### 证明完成
