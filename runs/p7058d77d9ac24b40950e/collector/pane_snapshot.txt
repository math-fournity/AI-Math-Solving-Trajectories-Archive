Looking at this problem, I need to find the maximum of $S = \sum_{k=0}^{2N-1}(x_
k x_{k+2} + x_{k+1}x_{k+3})$ subject to $x_n + x_{n+1} + x_{n+2} \le 2c$ for a $
2N$-periodic sequence, where $c \ge 0$ and $x_n \ge 0$ (necessary for the proble
m to be well-posed, as otherwise the objective is unbounded).

**Answer: $2Nc^2$.**

## Proof

**Simplification.** By $2N$-periodicity, $\sum_{k=0}^{2N-1} x_{k+1}x_{k+3} = \su
m_{k=0}^{2N-1} x_k x_{k+2}$, so $S = 2\sum_{k=0}^{2N-1} x_k x_{k+2}$. It suffice
s to show each summand pair satisfies $x_k x_{k+2} + x_{k+1}x_{k+3} \le c^2$.

**Key Lemma.** *For every $k$, $x_k x_{k+2} + x_{k+1}x_{k+3} \le c^2$.*

*Proof.* From the constraints at positions $k$ and $k+1$:
$$x_k \le 2c - x_{k+1} - x_{k+2}, \qquad x_{k+3} \le 2c - x_{k+1} - x_{k+2}.$$

Since $x_{k+2} \ge 0$, multiplying the first inequality by $x_{k+2}$ preserves d
irection:
$$x_k\, x_{k+2} \le x_{k+2}(2c - x_{k+1} - x_{k+2}).$$

Since $x_{k+1} \ge 0$, multiplying the second inequality by $x_{k+1}$:
$$x_{k+1}\, x_{k+3} \le x_{k+1}(2c - x_{k+1} - x_{k+2}).$$

Adding both inequalities:
$$x_k x_{k+2} + x_{k+1}x_{k+3} \le (x_{k+1}+x_{k+2})\bigl(2c - x_{k+1}-x_{k+2}\b
igr).$$

Set $s = x_{k+1}+x_{k+2}$. Since $x_k \ge 0$ and $x_k + s \le 2c$, we have $0 \l
e s \le 2c$, so $2c - s \ge 0$. Then:
$$s(2c-s) = c^2 - (s-c)^2 \le c^2,$$
since $(s-c)^2 \ge 0$ in any totally ordered commutative ring. $\square$

**Upper bound.** Summing the lemma over $k = 0, 1, \ldots, 2N-1$:
$$S = \sum_{k=0}^{2N-1}\bigl(x_k x_{k+2} + x_{k+1}x_{k+3}\bigr) \le 2N\, c^2.$$

**Achievability.** Consider the $2$-periodic (hence $2N$-periodic) sequence $x =
 (c,\, 0,\, c,\, 0,\, \ldots)$:

- *Constraint check:* For even $n$: $c + 0 + c = 2c \le 2c$ ✓. For odd $n$: $0 +
 c + 0 = c \le 2c$ ✓.
- *Objective:* For even $k$: $x_k x_{k+2} + x_{k+1}x_{k+3} = c\cdot c + 0\cdot 0
 = c^2$. For odd $k$: $0\cdot 0 + c\cdot c = c^2$.

Thus $S = 2N \cdot c^2 = 2Nc^2$, achieving the upper bound. $\square$

**Equality conditions.** Equality in the lemma requires $(x_{k+1}+x_{k+2}) = c$
and either $x_{k+1}=0$ or $x_{k+3} = 2c - x_{k+1}-x_{k+2}$, and either $x_{k+2}=
0$ or $x_k = 2c-x_{k+1}-x_{k+2}$. The alternating sequence $(c,0,c,0,\ldots)$ sa
tisfies these: $x_{k+1}+x_{k+2} = c$ for all $k$, with the zero terms ensuring e
quality in the multiplication steps.
