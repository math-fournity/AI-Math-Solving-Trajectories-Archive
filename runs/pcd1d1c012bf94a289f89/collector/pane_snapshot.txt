# Solution

## Setting up the key Diophantine relation

Let $a = x + 1/y$, $b = y + 1/z$, $c = z + 1/x$ be the three positive integers.
Expanding the product:

$$(x + \tfrac{1}{y})(y + \tfrac{1}{z})(z + \tfrac{1}{x}) = xyz + (x+y+z) + \left
(\tfrac{1}{x}+\tfrac{1}{y}+\tfrac{1}{z}\right) + \tfrac{1}{xyz}.$$

When $P = xyz = 1$, this becomes $abc = 2 + \Sigma + (\tfrac{1}{x}+\tfrac{1}{y}+
\tfrac{1}{z})$. Since $\tfrac{1}{x}+\tfrac{1}{y}+\tfrac{1}{z} = xy+yz+zx$ (using
 $xyz=1$), and from the index equations $\tfrac{1}{x}+\tfrac{1}{y}+\tfrac{1}{z}
= (a+b+c)-\Sigma$, we get:

$$\boxed{abc = a + b + c + 2.}$$

## Solving $abc = a + b + c + 2$ in positive integers

WLOG $a \le b \le c$.

- **$a=1$:** $bc - b - c = 3 \Rightarrow (b-1)(c-1)=4$, giving $(b,c)=(2,5)$ and
 $(3,3)$.
- **$a=2$:** $2bc - b - c = 4 \Rightarrow (2b-1)(2c-1)=9$, giving $(b,c)=(2,2)$.
- **$a\ge 3$:** $(3b-1)(3c-1)=16$ (for $a=3$) has no factor pair with both $\ge
8$; larger $a$ is worse.

**Unordered solutions:** $\{1,2,5\}$, $\{1,3,3\}$, $\{2,2,2\}$ — yielding **10 o
rdered triples** $(a,b,c)$.

## Finding $(x,y,z)$ for each triple

Setting $u = 1/x$ and eliminating cyclically gives the quadratic $(ab{-}1)u^2 -
(abc{-}a{-}c{+}b)u + (bc{-}1) = 0$. Using $abc = a+b+c+2$, the discriminant is $
[2(b+1)]^2 - 4(b+1)^2 = 0$, so each triple yields a **unique** solution:

$$x = \frac{b+1}{bc-1},\quad y = \frac{bc-1}{c+1},\quad z = \frac{c+1}{b+1}.$$

One verifies $x+1/y=a$, $y+1/z=b$, $z+1/x=c$, and $xyz=1$ directly. All values a
re positive rationals since $bc\ge 2$.

## Enumerating all 10 configurations and their $\Sigma$

| $(a,b,c)$ | $(x,y,z)$ | $\Sigma$ |
|---|---|---|
| $(1,2,5)$ | $(1/3,\, 3/2,\, 2)$ | $23/6$ |
| $(1,5,2)$ | $(2/3,\, 3,\, 1/2)$ | $25/6$ |

| $(5,1,2)$ | $(2,\, 1/3,\, 3/2)$ | $23/6$ |
| $(5,2,1)$ | $(3,\, 1/2,\, 2/3)$ | $25/6$ |
| $(1,3,3)$ | $(1/2,\, 2,\, 1)$ | $7/2$ |
| $(3,1,3)$ | $(1,\, 1/2,\, 2)$ | $7/2$ |
| $(3,3,1)$ | $(2,\, 1,\, 1/2)$ | $7/2$ |
| $(2,2,2)$ | $(1,\, 1,\, 1)$ | $3$ |

All 10 triples $(x,y,z)$ are distinct.

## Summing all $\Sigma$

$$\sum \Sigma = \underbrace{3\cdot\frac{23}{6} + 3\cdot\frac{25}{6}}_{\{1,2,5\}}
 + \underbrace{3\cdot\frac{7}{2}}_{\{1,3,3\}} + \underbrace{3}_{\{2,2,2\}} = \fr
ac{144}{6} + \frac{21}{2} + 3 = 24 + \frac{21}{2} + 3 = \frac{75}{2}.$$

## Answer

The sum of the Total System Loads over all configurations with $P=1$ is $\boxed{
\dfrac{75}{2}}$.
