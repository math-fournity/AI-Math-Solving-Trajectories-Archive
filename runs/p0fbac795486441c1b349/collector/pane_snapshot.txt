## Solution

**Setup.** A four-digit number $\overline{abcd}$ with $1 \le a \le 9$, $0 \le b,
c,d \le 9$.

- **P class:** $a > b,\ b < c,\ c > d$ (so $b$ is a local minimum and $c$ a loca
l maximum).
- **Q class:** $a < c,\ c < d$ (a strictly increasing chain $a < c < d$).

---

### Counting $N(P)$

Fix $b, c$ with $b < c$. Then:
- $a$ satisfies $a > b$ and $a \ge 1$, i.e. $a \in \{b+1, \dots, 9\}$: gives $9
- b$ choices.
- $d$ satisfies $d < c$ and $d \ge 0$, i.e. $d \in \{0, \dots, c-1\}$: gives $c$
 choices.

$$N(P) = \sum_{\substack{0 \le b < c \le 9}} (9-b)\,c = \sum_{c=1}^{9} c \sum_{b
=0}^{c-1}(9-b) = \sum_{c=1}^{9} c\left(9c - \frac{c(c-1)}{2}\right) = \sum_{c=1}
^{9}\frac{19c^2 - c^3}{2}.$$

Using $\sum_{c=1}^{9} c^2 = 285$ and $\sum_{c=1}^{9} c^3 = 2025$:

$$N(P) = \frac{19 \cdot 285 - 2025}{2} = \frac{5415 - 2025}{2} = \frac{3390}{2}
= 1695.$$

---

### Counting $N(Q)$

The conditions $a < c < d$ with $a \ge 1$ force $c \ge 2$. The digit $b$ is unre
stricted: $10$ choices.

Fix $c, d$ with $c < d$ (and $c \ge 2$). Then $a \in \{1, \dots, c-1\}$: gives $
c - 1$ choices.

$$N(Q) = 10 \sum_{\substack{2 \le c < d \le 9}} (c-1) = 10\sum_{d=3}^{9}\sum_{c=
2}^{d-1}(c-1) = 10\sum_{d=3}^{9}\frac{(d-2)(d-1)}{2}.$$

Setting $m = d-2$ ($m = 1, \dots, 7$):

$$\sum_{m=1}^{7}\frac{m(m+1)}{2} = \frac{\sum m^2 + \sum m}{2} = \frac{140 + 28}
{2} = 84.$$

$$N(Q) = 10 \cdot 84 = 840.$$

---

### Result

$$N(P) - N(Q) = 1695 - 840 = \boxed{855}.$$

### PROOF COMPLETE
