## Solution

We claim the supremum is **1**.

**Upper bound.** Since $E$ is a subspace, $0 \in E$. Hence for every $x \neq 0$,
$$d(x,E) = \inf_{e\in E}\|x-e\| \le \|x-0\| = \|x\|,$$
so $\dfrac{d(x,E)}{\|x\|} \le 1$. Thus $\sup \le 1$.

**Lower bound (sup $\ge$ 1).** Since $E$ is a *proper* subspace, pick any $x_0 \
notin E$. Since $E$ is closed, $\delta := d(x_0, E) > 0$.

For any $\varepsilon > 0$, by definition of infimum there exists $e_\varepsilon
\in E$ with
$$\|x_0 - e_\varepsilon\| \le \delta + \varepsilon.$$
Set $y_\varepsilon := x_0 - e_\varepsilon$. Since $x_0 \notin E$ and $e_\varepsi
lon \in E$, we have $y_\varepsilon \notin E$, in particular $y_\varepsilon \neq
0$.

Now compute the distance from $y_\varepsilon$ to $E$:
$$d(y_\varepsilon, E) = \inf_{e'\in E}\|y_\varepsilon - e'\| = \inf_{e'\in E}\|x
_0 - (e_\varepsilon + e')\|.$$
As $e'$ ranges over $E$, the element $e_\varepsilon + e'$ ranges over all of $E$
 (since $E$ is a subspace). Therefore
$$d(y_\varepsilon, E) = \inf_{e''\in E}\|x_0 - e''\| = d(x_0, E) = \delta.$$

Consequently
$$\frac{d(y_\varepsilon, E)}{\|y_\varepsilon\|} = \frac{\delta}{\|y_\varepsilon\
|} \ge \frac{\delta}{\delta + \varepsilon} \xrightarrow{\varepsilon \to 0} 1.$$

So the supremum is at least $1$.

**Conclusion.** Combining both bounds,
$$\sup_{x \in X\setminus\{0\}} \frac{d(x,E)}{\|x\|} = \boxed{1}.$$

**Remark.** The value $1$ is in general only a supremum, not a maximum: achievin
g ratio $= 1$ requires a point $y$ with $\|y\| = d(y,E)$, i.e. a nearest point $
0 \in E$ to $y$, which need not exist when $E$ is merely closed (not proximinal)
. The argument above bypasses this by an $\varepsilon$-approximation that needs
only the closedness of $E$ (to ensure $\delta > 0$) and the subspace property (t
o make the distance invariant under translation by elements of $E$).
