**Answer: No.** The condition "every open set is a countable union of closed set
s" does not imply metrizability.

## Counterexample: The Sorgenfrey Line

Let $S$ denote the **Sorgenfrey line**: $\mathbb{R}$ equipped with the lower-lim
it topology, generated by the basis $\mathcal{B} = \{[a,b) : a < b,\; a,b \in \m
athbb{R}\}$.

We show that (1) every open set in $S$ is an $F_\sigma$, yet (2) $S$ is not metr
izable.

---

### Step 1: Every open set in $S$ is a countable union of closed sets

**Each basic open set $[a,b)$ is also closed.** Its complement is
$$(-\infty, a) \cup [b, +\infty) = \Big(\bigcup_{n=1}^{\infty}[a-n,\, a)\Big) \c
up \Big(\bigcup_{n=1}^{\infty}[b,\, b+n)\Big),$$
which is a union of basic open sets, hence open. So $[a,b)$ is closed.

**The Sorgenfrey line is Lindelöf.** Let $\{[a_i, b_i)\}_{i \in I}$ be an open c
over of $\mathbb{R}$. Set $E = \bigcup_{i \in I}(a_i, b_i)$; this is Euclidean-o
pen, hence Lindelöf, so countably many $(a_i, b_i)$ cover $E$. For the complemen
t: if $x \in \mathbb{R}\setminus E$, then $x$ is covered by some $[a_i, b_i)$ wi
th $a_i \le x < b_i$; since $x \notin (a_i, b_i)$ we must have $a_i = x$. Thus e
ach $x \in \mathbb{R}\setminus E$ is a left endpoint of some $[x, b_x)$, and the
 intervals $(x, b_x)$ are pairwise disjoint (if $x < y$ and $y \in (x,b_x)$ then
 $y \in E$, contradiction). A family of pairwise disjoint open intervals in $\ma
thbb{R}$ is countable, so $\mathbb{R}\setminus E$ is countable. Combining: count
ably many $[a_i,b_i)$ cover $E$, and countably many more cover $\mathbb{R}\setmi
nus E$. ∎

**Conclusion of Step 1.** Let $U \subseteq S$ be open. Then $U$ is a union of ba
sic open sets $[a,b)$. Since $S$ is Lindelöf (and hence so is the subspace $U$),
 this cover admits a countable subcover:
$$U = \bigcup_{n=1}^{\infty} [a_n, b_n).$$
Each $[a_n, b_n)$ is closed (shown above), so $U$ is a countable union of closed
 sets. ∎

---

### Step 2: $S$ is not metrizable

**$S$ is separable:** $\mathbb{Q}$ is dense, since every basic open set $[a,b)$
contains a rational.

**$S$ is not second countable.** Let $\mathcal{B}'$ be any base for $S$. For eac
h $x \in \mathbb{R}$, there exists $B_x \in \mathcal{B}'$ with $x \in B_x \subse
teq [x, x+1)$. Since $B_x \subseteq [x,x+1)$ we have $\inf B_x \ge x$, and since
 $x \in B_x$ we have $\inf B_x \le x$; thus $\inf B_x = x$. The map $x \mapsto B
_x$ is therefore injective, giving $|\mathcal{B}'| \ge |\mathbb{R}|$, which is u
ncountable.

**Metrizable + separable $\Rightarrow$ second countable** (a standard theorem: i
n a metric space, a countable dense set yields a countable base by taking balls
of rational radius). Since $S$ is separable but not second countable, it cannot
be metrizable. ∎

---

### Conclusion

The Sorgenfrey line $S$ satisfies the condition that every open set is a countab
le union of closed sets (Step 1), yet $S$ is not metrizable (Step 2). Therefore
the condition does **not** imply metrizability.
