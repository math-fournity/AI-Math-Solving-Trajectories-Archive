A system of parameters for a local ring $(S, \mathfrak{m})$ of dimension $d$ is
a sequence of $d$ elements generating an $\mathfrak{m}$-primary ideal.

Given $f_1, \ldots, f_n$ with $\text{ht}(f_1, \ldots, f_n) = n$, we have $
\dim(S/(f_1, \ldots, f_n)) = d - n$. A system of parameters for $S/(f_1, \ldots,
f_n)$ consists of $d - n$ elements whose images generate an $\mathfrak{m}/(f_1,
\ldots, f_n)$-primary ideal. Lifting these to $S$, we get $g_{n+1}, \ldots, g_d$
such that $(f_1, \ldots, f_n, g_{n+1}, \ldots, g_d)$ is $\mathfrak{m}$-primary.
So $f_1, \ldots, f_n, g_{n+1}, \ldots, g_d$ is a system of parameters for $S$.
