Looking at this problem, I need to determine whether a uniform lower bound ε exi
sts for the ratio f(a)/aᵢ across all positive vectors in M and all coordinates.

**Answer: Yes, such ε > 0 exists.**

## Proof

**Step 1: Extend f to a real-linear functional.**

Since M ⊂ ℝⁿ is torsion-free, M is a free ℤ-module. Let e₁,…,e_r be a ℤ-basis of
 M (r = rank M = dim V, where V = M ⊗ ℝ is the real span). Define F: V → ℝ by F(
Σ rᵢeᵢ) = Σ rᵢf(eᵢ) for rᵢ ∈ ℝ. This is a well-defined ℝ-linear extension of f.
Since q·𝟏 ∈ M and f(q·𝟏) = q, we get F(𝟏) = 1.

**Step 2: F is strictly positive on the entire cone C \ {0}.**

Let C = V ∩ ℝⁿ≥₀. This is a pointed polyhedral cone (intersection of the rationa
l subspace V with the positive orthant). Since V is spanned by 0-1 (integer) vec
tors, C is a **rational** polyhedral cone, so all its extreme rays are rational.

Each extreme ray contains a primitive integer vector in ℤⁿ ∩ V. Since M ⊂ ℤⁿ ∩ V
 and both are lattices in V, M has finite index in ℤⁿ ∩ V. Hence each extreme ra
y contains a nonzero point of M ∩ C. By condition 3, F > 0 on each such point, h
ence F > 0 on each extreme ray.

Any x ∈ C \ {0} is a non-negative combination of extreme rays with at least one
positive coefficient: x = Σ λⱼ rⱼ, λⱼ ≥ 0, at least one λⱼ > 0. Then F(x) = Σ λⱼ
 F(rⱼ) > 0. So **F > 0 on C \ {0}**.

**Step 3: The cross-section D = {x ∈ C : F(x) = 1} is compact and nonempty.**

D is closed. To show boundedness: if xₙ ∈ D with ‖xₙ‖ → ∞, set yₙ = xₙ/‖xₙ‖ ∈ C
with ‖yₙ‖ = 1. Passing to a subsequence, yₙ → y ∈ C with ‖y‖ = 1 (so y ≠ 0). But
 F(yₙ) = 1/‖xₙ‖ → 0, giving F(y) = 0, contradicting Step 2. So D is compact.

D is nonempty since 𝟏 ∈ C and F(𝟏) = 1, so 𝟏 ∈ D.

**Step 4: Establish the uniform bound.**

For each i = 1,…,n, define Mᵢ = max_{x ∈ D} xᵢ. This maximum exists by compactne
ss of D and continuity of x ↦ xᵢ. Since 𝟏 ∈ D and 𝟏ᵢ = 1, we have Mᵢ ≥ 1 > 0.

For any positive a ∈ M (i.e., a ∈ M ∩ C \ {0}), set d = a/F(a) ∈ D. Then:
$$a_i = F(a) \cdot d_i \leq F(a) \cdot M_i$$
so $F(a) \geq a_i / M_i$.

Set $\varepsilon = \frac{1}{2}\min_i \frac{1}{M_i} > 0$.

- **If aᵢ > 0:** $\varepsilon \cdot a_i < \frac{a_i}{M_i} \leq F(a)$, so $F(a) >
 \varepsilon\, a_i$. ✓
- **If aᵢ = 0:** $F(a) > 0 = \varepsilon \cdot 0$ by condition 3. ✓

Since f(a) = F(a) for all a ∈ M, we conclude:

$$f(a) > \varepsilon\, a_i \quad \text{for every positive } a \in M \text{ and e
very } 1 \leq i \leq n.$$
