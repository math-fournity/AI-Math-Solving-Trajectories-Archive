$$k_n \leq \sqrt{n} + \sqrt{n+a} < k_n + 1$$

Since $f(n,a) = \sqrt{n} + \sqrt{n+a}$ is continuous and strictly increasing in

The valid set is $\bigcap_{n=1}^{\infty} [\ell_n, u_n)$ where $\ell_n = k_n^2 -
2k_n\sqrt{n}$ and $u_n = (k_n+1)^2 - 2(k_n+1)\sqrt{n}$.

**Finding $L = \sup_n \ell_n$.** Note $\ell_n = k_n(k_n - 2\sqrt{n})$. This is p

4n+1$, meaning $4n+1$ is a perfect square. This occurs when $k_n = 2m+1$ (odd) a

At such $n$: $\ell_n = (2m+1)^2 - 2(2m+1)\sqrt{m(m+1)} = (2m+1)\bigl((2m+1) - 2\

Using $(2m+1)^2 - 4m(m+1) = 1$, we get $(2m+1) - 2\sqrt{m(m+1)} = \frac{1}{(2m+1

$$\ell_{m(m+1)} = \frac{2m+1}{(2m+1)+2\sqrt{m(m+1)}}$$

This is decreasing in $m$ (approaching $\frac{1}{2}$ from above), so the maximum

$$L = \frac{3}{3+2\sqrt{2}} = \frac{3(3-2\sqrt{2})}{9-8} = 9 - 6\sqrt{2}$$
