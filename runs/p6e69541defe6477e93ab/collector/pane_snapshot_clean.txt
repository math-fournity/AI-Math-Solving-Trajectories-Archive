# Curvature of the Lobachevsky Plane

## Setup

Coordinates: $x^1 = x$, $x^2 = y$, with $y > 0$.

$$g_{11} = g_{22} = \frac{1}{y^2}, \quad g_{12} = g_{21} = 0$$

Determinant and inverse:
$$g = g_{11}g_{22} - g_{12}^2 = \frac{1}{y^4}, \quad g^{11} = g^{22} = y^2, \qua
d g^{12} = 0$$

## Christoffel Symbols

Using $\Gamma^k_{ij} = \tfrac{1}{2}g^{kl}(\partial_i g_{jl} + \partial_j g_{il}
- \partial_l g_{ij})$ and the derivatives $\partial_2 g_{11} = \partial_2 g_{22}
 = -2/y^3$, $\partial_1 g_{ij} = 0$:

| Symbol | Value |
|--------|-------|
| $\Gamma^1_{12} = \Gamma^1_{21}$ | $-1/y$ |
| $\Gamma^2_{11}$ | $1/y$ |
| $\Gamma^2_{22}$ | $-1/y$ |
| all others | $0$ |

## Computing $R_{1212}$

Setting $(k,l,i,j) = (1,2,1,2)$ in the given formula:

$$R_{1212} = \tfrac{1}{2}\!\left(\tfrac{\partial^2 g_{12}}{\partial x^2\partial
x^1} + \tfrac{\partial^2 g_{21}}{\partial x^1\partial x^2} - \tfrac{\partial^2 g
_{11}}{\partial x^2\partial x^2} - \tfrac{\partial^2 g_{22}}{\partial x^1\partia
l x^1}\right) + g_{rs}\Gamma^r_{21}\Gamma^s_{12} - g_{rs}\Gamma^r_{22}\Gamma^s_{
11}$$

**Second-derivative part:**

- $\frac{\partial^2 g_{12}}{\partial x^2\partial x^1} = 0$ (since $g_{12}=0$)
- $\frac{\partial^2 g_{21}}{\partial x^1\partial x^2} = 0$
- $\frac{\partial^2 g_{11}}{(\partial x^2)^2} = \frac{\partial}{\partial y}\!\le
ft(-\frac{2}{y^3}\right) = \frac{6}{y^4}$
- $\frac{\partial^2 g_{22}}{(\partial x^1)^2} = 0$

$$\Rightarrow \quad \tfrac{1}{2}\!\left(0 + 0 - \tfrac{6}{y^4} - 0\right) = -\fr
ac{3}{y^4}$$

**Christoffel-product part:**

$$g_{rs}\Gamma^r_{21}\Gamma^s_{12} = g_{11}\,\Gamma^1_{21}\,\Gamma^1_{12} = \fra
c{1}{y^2}\cdot\!\left(-\frac{1}{y}\right)\!\cdot\!\left(-\frac{1}{y}\right) = \f
rac{1}{y^4}$$

$$g_{rs}\Gamma^r_{22}\Gamma^s_{11} = g_{22}\,\Gamma^2_{22}\,\Gamma^2_{11} = \fra
c{1}{y^2}\cdot\!\left(-\frac{1}{y}\right)\!\cdot\!\left(\frac{1}{y}\right) = -\f
rac{1}{y^4}$$

**Combining:**

$$R_{1212} = -\frac{3}{y^4} + \frac{1}{y^4} - \left(-\frac{1}{y^4}\right) = -\fr
ac{3}{y^4} + \frac{1}{y^4} + \frac{1}{y^4} = -\frac{1}{y^4}$$

## Curvature

$$K = \frac{R_{1212}}{g_{11}g_{22} - g_{12}^2} = \frac{-1/y^4}{1/y^4} = -1$$

## Result

The Gaussian curvature of the Lobachevsky plane with the metric $g_{11} = g_{22}
 = 1/y^2$, $g_{12} = 0$ is **constant** and equals

$$\boxed{K = -1}$$

at every point $(x, y)$ with $y > 0$.
