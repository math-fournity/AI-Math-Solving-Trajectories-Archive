## Proof

**Step 1: Reduce the angles.**

The angles are $\pi/9 = 20°$, $5\pi/9 = 100°$, $7\pi/9 = 140°$. Since $\sec^8$ i
s an even power, signs of cosine don't matter:
- $\cos(100°) = -\cos(80°)$, so $\sec^8(100°) = \sec^8(80°)$.
- $\cos(140°) = -\cos(40°)$, so $\sec^8(140°) = \sec^8(40°)$.

Therefore the sum equals
$$S = \sec^8(20°) + \sec^8(40°) + \sec^8(80°).$$

**Step 2: Find the cubic satisfied by the secant values.**

Let $u = \sec(20°)$, $v = \sec(40°)$, $w = \sec(80°)$. For $\theta \in \{40°, 80
°, 160°\}$, we have $3\theta \in \{120°, 240°, 480°\}$, so $\cos(3\theta) = -1/2
$. Using $\cos(3\theta) = 4\cos^3\theta - 3\cos\theta$:
$$8\cos^3\theta - 6\cos\theta + 1 = 0.$$
Substituting $r = \sec\theta = 1/\cos\theta$ and multiplying by $r^3$:
$$r^3 - 6r^2 + 8 = 0.$$

The three roots are $\sec(40°) = v$, $\sec(80°) = w$, and $\sec(160°) = -\sec(20
°) = -u$.

**Step 3: Apply Vieta's formulas.**

For $t^3 - 6t^2 + 0\cdot t + 8 = 0$ with roots $v, w, -u$:
- $v + w + (-u) = 6$, i.e., $v + w - u = 6$.
- $vw + v(-u) + w(-u) = 0$, i.e., $vw = u(v+w)$.
- $vw(-u) = -8$, i.e., $uvw = 8$.

**Step 4: Set up the power-sum recurrence.**

Since each root $r$ satisfies $r^3 = 6r^2 - 8$, we get $r^n = 6r^{n-1} - 8r^{n-3
}$ for $n \geq 3$. Define
$$p_n = v^n + w^n + (-u)^n.$$
Then $p_n = 6p_{n-1} - 8p_{n-3}$, with initial values:
- $p_0 = 3$.
- $p_1 = v + w - u = 6$.
- $p_2 = v^2 + w^2 + u^2$. Using $(v+w-u)^2 = p_2 + 2(vw - u(v+w))$ and $vw = u(
v+w)$ (so the cross term vanishes): $p_2 = 36$.

**Step 5: Compute up to $p_8$.**

| 6 | $6(6336) - 8(192) = 38016 - 1536$ | $36480$ |
| 7 | $6(36480) - 8(1104) = 218880 - 8832$ | $210048$ |
| 8 | $6(210048) - 8(6336) = 1260288 - 50688$ | $1209600$ |

**Step 6: Conclude.**

Since $(-u)^8 = u^8$, we have
$$p_8 = v^8 + w^8 + u^8 = \sec^8(40°) + \sec^8(80°) + \sec^8(20°) = S.$$

Therefore
$$\sec^8\!\left(\tfrac{\pi}{9}\right) + \sec^8\!\left(\tfrac{5\pi}{9}\right) + \
sec^8\!\left(\tfrac{7\pi}{9}\right) = \boxed{1209600}.$$
