# Spectrum of $T = S + S^*$ on $\ell^2$

## Setup

Let $S$ be the unilateral shift on $\ell^2(\mathbb{N})$, $(Se_0, Se_1, \dots) =
(0, e_0, e_1, \dots)$, i.e. $Se_n = e_{n+1}$. Its adjoint is the backward shift
$S^*e_0 = 0$, $S^*e_n = e_{n-1}$ for $n \ge 1$. Then $T = S + S^*$ is the (infin
ite) discrete Laplacian, a bounded self-adjoint operator with $\|T\| \le \|S\| +
 \|S^*\| = 2$.

Since $T$ is self-adjoint, $\sigma(T) \subseteq \mathbb{R}$, and $\sigma(T) \sub
seteq [-\|T\|,\|T\|] \subseteq [-2,2]$.

## Step 1: $\sigma(T) \supseteq [-2,2]$ (approximate point spectrum)

We show every $\lambda \in [-2,2]$ is an approximate eigenvalue. Write $\lambda
= 2\cos\theta$ for $\theta \in [0,\pi]$. Consider the unit vectors
$$x^{(N)} = \frac{1}{\sqrt{N+1}}\sum_{n=0}^{N} e^{in\theta}\, e_n, \qquad \|x^{(
N)}\|=1.$$
Compute $(S^* x^{(N)})_n = \frac{1}{\sqrt{N+1}} e^{i(n+1)\theta}$ for $0 \le n \
le N-1$ and $(S^*x^{(N)})_N = 0$; while $(Sx^{(N)})_n = \frac{1}{\sqrt{N+1}}e^{i
(n-1)\theta}$ for $1\le n\le N$ and $(Sx^{(N)})_0 = 0$. Hence for $1 \le n \le N
$:
$$(Tx^{(N)})_n = \frac{e^{i(n+1)\theta}+e^{i(n-1)\theta}}{\sqrt{N+1}} = 2\cos\th
eta\cdot \frac{e^{in\theta}}{\sqrt{N+1}} = \lambda\, x^{(N)}_n.$$
The only mismatches with $\lambda x^{(N)}$ are at the boundary indices $n=0$ and
 $n=N$. At $n=0$: $(Tx^{(N)})_0 = \frac{e^{i\theta}}{\sqrt{N+1}}$, while $\lambd
a x^{(N)}_0 = \frac{2\cos\theta}{\sqrt{N+1}} = \frac{e^{i\theta}+e^{-i\theta}}{\
sqrt{N+1}}$; difference $\frac{e^{-i\theta}}{\sqrt{N+1}}$. At $n=N$: $(Tx^{(N)})
_N = \frac{e^{i(N-1)\theta}}{\sqrt{N+1}}$, while $\lambda x^{(N)}_N = \frac{e^{i
(N+1)\theta}+e^{i(N-1)\theta}}{\sqrt{N+1}}$; difference $\frac{e^{i(N+1)\theta}}
{\sqrt{N+1}}$. Therefore
$$\|(T-\lambda I)x^{(N)}\|^2 = \frac{1}{N+1} + \frac{1}{N+1} = \frac{2}{N+1} \xr
ightarrow{N\to\infty} 0.$$
So $\lambda \in \sigma_{ap}(T) \subseteq \sigma(T)$. Since $[-2,2] = \{2\cos\the
ta : \theta\in[0,\pi]\}$, we get $[-2,2]\subseteq\sigma(T)$.

## Step 2: $\sigma(T) \subseteq [-2,2]$

$T$ is self-adjoint, so $\sigma(T)\subseteq[-\|T\|,\|T\|]$. We have $\|T\| \le \
|S\|+\|S^*\| = 1+1 = 2$. Hence $\sigma(T)\subseteq[-2,2]$.

(One can also confirm $\|T\|=2$ exactly: the approximate eigenvectors above with
 $\lambda=\pm 2$ give $\|T\|\ge 2$, so $\|T\|=2$.)

## Step 3: No residual spectrum

For a self-adjoint operator, $\sigma_r(T) = \varnothing$ (since $\ker(T-\lambda
I)^\perp = \overline{\operatorname{ran}(T-\lambda I)}$, and self-adjointness giv
es $\ker(T-\lambda I) = \ker(T^*-\lambda I) = \operatorname{ran}(T-\lambda I)^\p
erp$; if $\ker(T-\lambda I)=\{0\}$ then $\operatorname{ran}(T-\lambda I)$ is den
se). So every non-eigenvalue spectral point is in the continuous spectrum. In fa
ct $T$ has **no eigenvalues** at all: if $Tx=\lambda x$ with $x=(x_0,x_1,\dots)$
, the recurrence $x_{n+1}+x_{n-1}=\lambda x_n$ (with $x_{-1}=0$) gives $x_n = x_
0\, U_n(\lambda/2)$ (Chebyshev of 2nd kind). For $|\lambda|<2$, $|U_n(\lambda/2)
|\to\infty$ along a subsequence, so $x\notin\ell^2$ unless $x_0=0$; for $|\lambd
a|=2$, $U_n(\pm 1)=\pm(n+1)$, again not $\ell^2$; for $|\lambda|>2$, $U_n$ grows
 exponentially. Thus $\sigma_p(T)=\varnothing$ and
$$\sigma(T) = \sigma_c(T) = [-2,2].$$

## Conclusion

$$\boxed{\sigma(T) = \sigma_c(T) = [-2,\,2], \qquad \sigma_p(T)=\sigma_r(T)=\var
nothing.}$$

The spectrum is purely continuous and equals the interval $[-2,2]$.
