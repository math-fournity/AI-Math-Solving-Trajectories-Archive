# Problem

The company's primary objective is to build automated maintenance hubs. To maximize efficiency, a rule is established: for every possible pair of relay stations, a maintenance hub must be constructed at the exact geographical midpoint between those two stations.

The project manager wants to minimize infrastructure costs by choosing a layout for the 2017 relay stations that results in as much overlap as possible among the maintenance hubs. 

Assuming all stations must be placed at distinct locations on a flat, two-dimensional plain, what is the minimum possible number of distinct maintenance hub locations that must be built?
