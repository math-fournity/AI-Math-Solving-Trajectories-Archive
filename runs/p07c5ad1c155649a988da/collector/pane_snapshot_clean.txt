## Proof

We work on $\mathbb{R}$. Define
$$\langle T, \psi\rangle = \sum_{n=0}^{\infty}(n+1)\,\psi^{(n)}(n), \qquad \psi
\in C_c^\infty(\mathbb{R}).$$

### Step 1. $T$ is well-defined and linear.

Since $\psi \in C_c^\infty(\mathbb{R})$ has compact support $\operatorname{supp}
\psi \subset [-R,R]$ for some $R$, all terms with $n > R$ vanish (because $n \no
tin \operatorname{supp}\psi$). Hence the sum is **finite** for each $\psi$:
$$\langle T,\psi\rangle = \sum_{\substack{n \ge 0 \\ n \le R}}(n+1)\,\psi^{(n)}(
n).$$
Linearity is immediate.

### Step 2. $T$ is continuous, hence a distribution.

Let $K \subset \mathbb{R}$ be compact and set $N_K := \max\{n \in \mathbb{N}_0 :
 n \in K\}$ (with $N_K := -1$ if $K \cap \mathbb{N}_0 = \emptyset$, in which cas
e $T|_K \equiv 0$). For every $\psi \in C_c^\infty(\mathbb{R})$ with $\operatorn
ame{supp}\psi \subset K$:
$$|\langle T,\psi\rangle| = \left|\sum_{n=0}^{N_K}(n+1)\psi^{(n)}(n)\right| \le
\sum_{n=0}^{N_K}(n+1)\,|\psi^{(n)}(n)| \le \left(\sum_{n=0}^{N_K}(n+1)\right)\su
m_{j=0}^{N_K}\sup_{x}|\psi^{(j)}(x)|.$$
Setting $C_K := \sum_{n=0}^{N_K}(n+1)$, we obtain
$$|\langle T,\psi\rangle| \le C_K \sum_{j=0}^{N_K} \sup|\psi^{(j)}|, \qquad \for
all\, \operatorname{supp}\psi \subset K.$$
This is precisely the continuity criterion for distributions (Rudin, *Functional
 Analysis*, Def. 6.3). Therefore **$T$ is a distribution**.

### Step 3. The order of $T$ on $[0,N]$ is exactly $N$.

Recall the order of $T$ on a compact $K$ is the least $m$ such that a bound $|\l
angle T,\psi\rangle| \le C\sum_{j=0}^{m}\sup|\psi^{(j)}|$ holds for all $\psi$ s
upported in $K$.

**Lower bound (order $\ge N$ on $[0,N]$).** Fix $N \ge 1$ and suppose, for contr
adiction, that a bound with order $m < N$ holds on $[0,N]$. Pick $\phi \in C_c^\
infty(-1,1)$ with $\phi(0)=1$. For $\delta \in (0,1)$ define
$$\psi_\delta(x) := \frac{(x-N)^N}{N!}\,\phi\!\left(\frac{x-N}{\delta}\right).$$
Then $\operatorname{supp}\psi_\delta \subset [N-\delta, N+\delta] \subset [0,N]$
 (for $\delta < 1$), so $\psi_\delta^{(n)}(n)=0$ for every $n \in \{0,\dots,N-1\
}$ (the support avoids those integers). By Leibniz's rule,
$$\psi_\delta^{(N)}(x) = \sum_{k=0}^{N}\binom{N}{k}\frac{(x-N)^{k}}{k!}\,\frac{\
phi^{(k)}((x-N)/\delta)}{\delta^{k}}.$$
At $x=N$ only the $k=0$ term survives, giving $\psi_\delta^{(N)}(N) = \phi(0) =
1$. Hence
$$\langle T,\psi_\delta\rangle = (N+1)\,\psi_\delta^{(N)}(N) = N+1 \ne 0.$$

On the other hand, for $j \le m < N$, again by Leibniz and the bound $|x-N|\le \
delta$ on the support:
$$|\psi_\delta^{(j)}(x)| \le \sum_{k=0}^{j}\binom{j}{k}\frac{|x-N|^{N-(j-k)}}{(N
-(j-k))!}\frac{\|\phi^{(k)}\|_\infty}{\delta^{k}} \le \left(\sum_{k=0}^{j}\binom
{j}{k}\frac{\|\phi^{(k)}\|_\infty}{(N-(j-k))!}\right)\delta^{N-j} =: A_j\,\delta
^{N-j}.$$
Since $N - j \ge N - m \ge 1$, every $\sup|\psi_\delta^{(j)}| \to 0$ as $\delta
\to 0$ for $j \le m$. Therefore
$$C\sum_{j=0}^{m}\sup|\psi_\delta^{(j)}| \xrightarrow[\delta\to 0]{} 0,$$
contradicting $|\langle T,\psi_\delta\rangle| = N+1$. So no bound of order $m <
N$ holds on $[0,N]$; the order on $[0,N]$ is $\ge N$.

**Upper bound (order $\le N$ on $[0,N]$).** From Step 2, $|\langle T,\psi\rangle
| \le C_{[0,N]}\sum_{j=0}^{N}\sup|\psi^{(j)}|$, so the order on $[0,N]$ is $\le
N$.

Combining: **the order of $T$ on $[0,N]$ is exactly $N$.**

### Step 4. The global order of $T$ is infinite.

The (global) order of a distribution is
$$\operatorname{ord}(T) = \inf\bigl\{m \in \mathbb{N}_0 : \forall\, K,\ \exists\
, C_K \text{ s.t. } |\langle T,\psi\rangle| \le C_K\textstyle\sum_{j=0}^{m}\sup|
\psi^{(j)}| \text{ on } K\bigr\}.$$
Since the order on $[0,N]$ equals $N$ (Step 3) and $N$ is arbitrary, no finite $
m$ can serve uniformly for all compact $K$. Hence
$$\operatorname{ord}(T) = \infty.$$

### Conclusion

The functional $\langle T,\psi\rangle = \sum_{n=0}^{\infty}(n+1)\psi^{(n)}(n)$ *
*is a distribution** on $\mathbb{R}$ (it is linear and continuous on $C_c^\infty
(\mathbb{R})$), but it is a distribution of **infinite order**: on each compact
$[0,N]$ its order is exactly $N$, so no finite uniform order bounds it globally.
