**Proof.** The minimum value of $n$ is $\boxed{9}$.

**Construction for $n=9$.** Use 3 colors $A, B, C$ with classes:
$$A=\{1,6,8\},\quad B=\{2,4,9\},\quad C=\{3,5,7\}.$$
Each sums to $15 = \frac{9\cdot10}{2\cdot3}$. The coloring around $C_9$ is:
$$1(A),\; 2(B),\; 3(C),\; 4(B),\; 5(C),\; 6(A),\; 7(C),\; 8(A),\; 9(B).$$
Consecutive color pairs: $(A,B),(B,C),(C,B),(B,C),(C,A),(A,C),(C,A),(A,B),(B,A)$
 — all distinct. ✓

**No valid coloring exists for $3\le n\le 8$.**

Let $k$ be the number of colors used. We need $k\mid\frac{n(n+1)}{2}$, $2\le k\l
e 10$, and each color class is an independent set in $C_n$ with sum $S=\frac{n(n
+1)}{2k}$.

**$n=3$** (total $6$): $k\in\{2,3\}$. $k=2$: $C_3$ is not 2-colorable. $k=3$: $S
=2$; only $\{2\}$ sums to 2, so 3 non-empty parts of sum 2 are impossible.

**$n=4$** (total $10$): $k\in\{2,5\}$. $k=2$: the only proper 2-coloring of $C_4

**$n=5$** (total $15$): $k\in\{3,5\}$. $k=3$: $S=5$; the only partition is $\{5\

ns each equal to 3, impossible.

**$n=6$** (total $21$): $k\in\{3,7\}$. $k=3$: $S=7$; the only partition is $\{1,
6\},\{2,5\},\{3,4\}$, but 3,4 are adjacent in $C_6$. ($\{1,2,4\}$ is the only ot

**$n=8$** (total $36$): $k\in\{2,3,4,6\}$ (since $k\ge 9$ exceeds the element co
