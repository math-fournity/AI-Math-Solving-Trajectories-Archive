## 2. Separation of Variables

The PDE is

$$u_t = k\, u_{xx} - \beta\, u, \qquad k=\tfrac{1}{10},\;\; \beta=\tfrac{1}{4},\
qquad 0<x<1,\;t>0,$$

with $u_x(0,t)=0$, $u(1,t)=0$, $u(x,0)=f(x)$.

Set $u(x,t)=X(x)\,T(t)$. Substituting and dividing by $XT$:

$$\frac{T'}{T} = k\,\frac{X''}{X} - \beta = -(\lambda+\beta),$$

where $\lambda$ is a separation constant. This gives:

- **Temporal ODE:** $T' = -(\lambda+\beta)\,T \;\Longrightarrow\; T(t)=e^{-(\lam
bda+\beta)t}$.
- **Spatial ODE:** $k\,X'' + \lambda\, X = 0$, i.e. $X'' + \frac{\lambda}{k}X =
0$.

Let $\mu^2 = \lambda/k$. Then

$$X'' + \mu^2 X = 0, \qquad X'(0)=0,\quad X(1)=0.$$

## 3. Eigenvalues and Eigenfunctions

The general solution is $X(x)=A\cos(\mu x)+B\sin(\mu x)$.

**Boundary condition at $x=0$:** $X'(0)=-A\mu\sin 0 + B\mu\cos 0 = B\mu = 0$, so
 $B=0$.

**Boundary condition at $x=1$:** $X(1)=A\cos\mu = 0$. For a nontrivial solution
($A\neq 0$),

$$\boxed{\cos\mu = 0 \;\Longrightarrow\; \mu_n = \left(n+\tfrac{1}{2}\right)\pi
= \frac{(2n+1)\pi}{2}, \qquad n=0,1,2,\dots}$$

**Eigenvalues of the spatial operator $-d^2/dx^2$:**

$$\boxed{\mu_n^2 = \left[\frac{(2n+1)\pi}{2}\right]^2, \qquad n=0,1,2,\dots}$$

The corresponding **diffusion eigenvalues** (appearing in the temporal decay) ar
e

$$\lambda_n = k\,\mu_n^2 = \frac{1}{10}\left[\frac{(2n+1)\pi}{2}\right]^2.$$

**Unnormalized eigenfunctions:**

$$X_n(x) = \cos\!\left(\frac{(2n+1)\pi}{2}\,x\right).$$

## 4. Orthonormalization

Compute the norm:

$$\int_0^1 \cos^2(\mu_n x)\,dx = \frac{1}{2} + \frac{\sin(2\mu_n)}{4\mu_n}.$$

Since $\cos\mu_n=0$, we have $\sin(2\mu_n)=2\sin\mu_n\cos\mu_n = 0$, so

$$\int_0^1 \cos^2(\mu_n x)\,dx = \frac{1}{2}, \qquad \|X_n\| = \frac{1}{\sqrt{2}
}.$$

The family $\{\cos(\mu_n x)\}$ is orthogonal on $[0,1]$ (standard Sturm–Liouvill
e result for mixed Neumann–Dirichlet conditions). Therefore the **orthonormalize
d eigenfunctions** are:

$$\boxed{\varphi_n(x) = \sqrt{2}\,\cos\!\left(\frac{(2n+1)\pi}{2}\,x\right), \qq
uad n=0,1,2,\dots}$$

satisfying $\int_0^1 \varphi_n(x)\varphi_m(x)\,dx = \delta_{nm}$.

## 5. General Solution

$$\boxed{u(x,t) = \sum_{n=0}^{\infty} c_n\,\varphi_n(x)\,e^{-\left(k\mu_n^2+\bet
a\right)t} = \sum_{n=0}^{\infty} c_n\,\sqrt{2}\,\cos(\mu_n x)\,e^{-\left[\frac{1
}{10}\left(\frac{(2n+1)\pi}{2}\right)^2 + \frac{1}{4}\right]t}}$$

where the Fourier coefficients are

$$c_n = \int_0^1 f(x)\,\varphi_n(x)\,dx = \sqrt{2}\int_0^1 f(x)\cos(\mu_n x)\,dx
.$$

## 6. Coefficients for Each Initial Condition

Throughout, $\mu_n = \frac{(2n+1)\pi}{2}$ and $\sin\mu_n = (-1)^n$, $\cos\mu_n=0
$.

### Case 1: $f_1(x) = x$

$$\int_0^1 x\cos(\mu_n x)\,dx = \left[\frac{x\sin(\mu_n x)}{\mu_n}\right]_0^1 -
\int_0^1 \frac{\sin(\mu_n x)}{\mu_n}\,dx = \frac{\sin\mu_n}{\mu_n} + \frac{\cos\
mu_n - 1}{\mu_n^2}.$$

Using $\sin\mu_n=(-1)^n$, $\cos\mu_n=0$:

$$\int_0^1 x\cos(\mu_n x)\,dx = \frac{(-1)^n}{\mu_n} - \frac{1}{\mu_n^2}.$$

$$\boxed{c_n^{(1)} = \sqrt{2}\left[\frac{(-1)^n}{\mu_n} - \frac{1}{\mu_n^2}\righ
t] = \sqrt{2}\left[\frac{(-1)^n}{\frac{(2n+1)\pi}{2}} - \frac{1}{\left(\frac{(2n
+1)\pi}{2}\right)^2}\right]}$$

$$u_1(x,t) = \sum_{n=0}^{\infty} \sqrt{2}\left[\frac{(-1)^n}{\mu_n} - \frac{1}{\
mu_n^2}\right]\sqrt{2}\,\cos(\mu_n x)\,e^{-\left(\frac{\mu_n^2}{10}+\frac{1}{4}\
right)t}$$

$$\boxed{u_1(x,t) = 2\sum_{n=0}^{\infty}\left[\frac{(-1)^n}{\mu_n} - \frac{1}{\m
u_n^2}\right]\cos(\mu_n x)\,e^{-\left(\frac{\mu_n^2}{10}+\frac{1}{4}\right)t}}$$

### Case 2: $f_2(x) = 1$

$$\int_0^1 \cos(\mu_n x)\,dx = \frac{\sin\mu_n}{\mu_n} = \frac{(-1)^n}{\mu_n}.$$

$$\boxed{c_n^{(2)} = \frac{\sqrt{2}\,(-1)^n}{\mu_n}}$$

$$\boxed{u_2(x,t) = 2\sum_{n=0}^{\infty}\frac{(-1)^n}{\mu_n}\,\cos(\mu_n x)\,e^{
-\left(\frac{\mu_n^2}{10}+\frac{1}{4}\right)t}}$$

### Case 3: $f_3(x) = 1 - x^2$

We need $\int_0^1 (1-x^2)\cos(\mu_n x)\,dx = \int_0^1 \cos(\mu_n x)\,dx - \int_0
^1 x^2\cos(\mu_n x)\,dx$.

The first integral is $(-1)^n/\mu_n$ (from Case 2).

For the second, integrate by parts twice:

$$\int_0^1 x^2\cos(\mu x)\,dx = \frac{\sin\mu}{\mu} + \frac{2\cos\mu}{\mu^2} - \
frac{2\sin\mu}{\mu^3}.$$

With $\cos\mu_n=0$, $\sin\mu_n=(-1)^n$:

$$\int_0^1 x^2\cos(\mu_n x)\,dx = \frac{(-1)^n}{\mu_n} - \frac{2(-1)^n}{\mu_n^3}
 = (-1)^n\!\left(\frac{1}{\mu_n} - \frac{2}{\mu_n^3}\right).$$

Therefore:

$$\int_0^1 (1-x^2)\cos(\mu_n x)\,dx = \frac{(-1)^n}{\mu_n} - (-1)^n\!\left(\frac
{1}{\mu_n}-\frac{2}{\mu_n^3}\right) = \frac{2(-1)^n}{\mu_n^3}.$$

$$\boxed{c_n^{(3)} = \frac{2\sqrt{2}\,(-1)^n}{\mu_n^3}}$$

$$\boxed{u_3(x,t) = 4\sum_{n=0}^{\infty}\frac{(-1)^n}{\mu_n^3}\,\cos(\mu_n x)\,e
^{-\left(\frac{\mu_n^2}{10}+\frac{1}{4}\right)t}}$$

## 8. Verification of Boundary Conditions

**Neumann at $x=0$:** Each eigenfunction satisfies $\varphi_n'(x)=-\sqrt{2}\,\mu
_n\sin(\mu_n x)$, so $\varphi_n'(0)=0$ for every $n$. Therefore

$$u_x(0,t) = \sum_{n=0}^{\infty} c_n\,\varphi_n'(0)\,e^{-(k\mu_n^2+\beta)t} = 0
\quad \text{for all } t\geq 0.\;\checkmark$$

The left end is insulated at all times.

**Dirichlet at $x=1$:** Each eigenfunction satisfies $\varphi_n(1)=\sqrt{2}\cos(
\mu_n)=\sqrt{2}\cdot 0=0$. Therefore

$$u(1,t) = \sum_{n=0}^{\infty} c_n\,\varphi_n(1)\,e^{-(k\mu_n^2+\beta)t} = 0 \qu
ad \text{for all } t\geq 0.\;\checkmark$$

The right end is held at zero at all times.

**Initial condition:** At $t=0$, the exponential factors are all 1, and the seri
es reduces to the Fourier expansion of $f(x)$ in the orthonormal basis $\{\varph
i_n\}$, which converges to $f(x)$ on $(0,1)$ (in $L^2$ and pointwise for these s
mooth $f$). $\checkmark$
