**The answer is no.** I'll construct a counterexample.

**Key tool — Claborn's Theorem (1966):** Every abelian group is isomorphic to th
e class group of some Dedekind domain.

**Construction.** By Claborn's theorem, let $A$ be a Dedekind domain with class
group $\operatorname{Cl}(A) \cong \mathbb{Q}$ (the additive group of rationals).
 A Dedekind domain is a Noetherian domain, so $A$ satisfies the hypothesis. Sinc
e $\operatorname{Cl}(A) \neq 0$, $A$ is not a field, so $A$ possesses nonzero pr
ime ideals.

**Claim 1: $A_p$ is a UFD for every prime $p$ of $A$.**

If $p \neq (0)$, then $A_p$ is a DVR (discrete valuation ring), since $A$ is a D
edekind domain. A DVR is a PID, hence a UFD. If $p = (0)$, then $A_p = \operator
name{Frac}(A)$ is a field, hence a UFD.

**Claim 2: $A_f$ is not a UFD for any nonzero $f \in A$.**

Since $A$ is Dedekind, the localization $A_f$ is also a Dedekind domain. A Dedek
ind domain is a UFD if and only if it is a PID, equivalently, if and only if its
 class group is trivial.

Since $A$ is Noetherian, the principal ideal $(f)$ has a unique factorization in
to prime ideals:
$$(f) = \mathfrak{q}_1^{a_1} \cdots \mathfrak{q}_n^{a_n}$$
for finitely many nonzero primes $\mathfrak{q}_1, \dots, \mathfrak{q}_n$. The cl
ass group of $A_f$ is:
$$\operatorname{Cl}(A_f) = \operatorname{Cl}(A)\,/\,\langle [\mathfrak{q}_1], \d
ots, [\mathfrak{q}_n] \rangle \;\cong\; \mathbb{Q}\,/\,H,$$
where $H = \langle [\mathfrak{q}_1], \dots, [\mathfrak{q}_n] \rangle$ is a finit
ely generated subgroup of $\mathbb{Q}$.

Now, $\mathbb{Q}$ is **not** finitely generated as an abelian group: any finitel
y generated subgroup of $\mathbb{Q}$ is cyclic (hence $\cong \mathbb{Z}$), but $
\mathbb{Q}$ is divisible while $\mathbb{Z}$ is not, so $\mathbb{Q} \not\cong \ma
thbb{Z}$. Therefore $H \subsetneq \mathbb{Q}$, giving $\operatorname{Cl}(A_f) \c
ong \mathbb{Q}/H \neq 0$.

Since $\operatorname{Cl}(A_f) \neq 0$, the Dedekind domain $A_f$ is not a PID, h
ence not a UFD. $\square$

**Conclusion.** Pick any nonzero prime $p$ of $A$. By Claim 1, $A_p$ is a UFD. B
y Claim 2, for every $f \notin p$ (indeed for every nonzero $f \in A$), $A_f$ is
 **not** a UFD. Thus there is no element $f \notin p$ such that $A_f$ is a UFD,
even though $A$ is a Noetherian domain and $A_p$ is a UFD.

athbb{Q}$ is not finitely generated: localizing at any single element kills only
