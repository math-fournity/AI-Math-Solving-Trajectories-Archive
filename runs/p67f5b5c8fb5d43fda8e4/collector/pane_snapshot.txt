## Proof

**Yes**, $f(T^2(x)) = \lambda^2 f(x)$ almost everywhere.

Let $E = \{x : f(T(x)) = \lambda f(x)\}$. By hypothesis $\mu(E) = 1$, so $\mu(E^
c) = 0$.

Since $T$ is measure-preserving, for any measurable set $A$ we have $\mu(T^{-1}(
A)) = \mu(A)$. In particular,
$$\mu\bigl(T^{-1}(E^c)\bigr) = \mu(E^c) = 0,$$
so $\mu(T^{-1}(E)) = 1$.

Now consider the set $E \cap T^{-1}(E)$. Both $E$ and $T^{-1}(E)$ have full meas
ure, so
$$\mu\bigl(E \cap T^{-1}(E)\bigr) = 1.$$

For any $x \in E \cap T^{-1}(E)$:
- Since $x \in E$: $f(T(x)) = \lambda f(x)$.
- Since $T(x) \in E$: $f(T(T(x))) = \lambda f(T(x))$.

Combining,
$$f(T^2(x)) = f(T(T(x))) = \lambda f(T(x)) = \lambda \cdot \lambda f(x) = \lambd
a^2 f(x).$$

This holds on a set of full measure, hence $f(T^2(x)) = \lambda^2 f(x)$ for almo
st every $x$. $\blacksquare$
