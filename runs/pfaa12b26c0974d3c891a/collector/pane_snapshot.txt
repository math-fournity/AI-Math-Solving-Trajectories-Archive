## Proof

**Claim:** Yes. The absolute value on $K$ induced by a discrete valuation is alw
ays non-Archimedean.

Let $K$ be a field of characteristic $0$, complete with respect to a discrete va
luation
$$v: K \to \mathbb{Z} \cup \{\infty\}.$$

Recall that a discrete valuation is a surjective map satisfying, for all $x, y \
in K$:

1. $v(x) = \infty \iff x = 0$,
2. $v(xy) = v(x) + v(y)$,
3. $v(x + y) \geq \min\bigl(v(x),\, v(y)\bigr)$.

The absolute value on $K$ induced by $v$ is
$$|x|_v := c^{-v(x)}, \qquad c > 1 \text{ a fixed real constant.}$$
(The choice of $c > 1$ only changes the absolute value to an equivalent one; the
 non-Archimedean property is independent of this choice.)

We verify that $|\cdot|_v$ satisfies the **ultrametric inequality**
$$|x + y|_v \leq \max\bigl(|x|_v,\, |y|_v\bigr) \qquad \forall\, x, y \in K.$$

**Case 1: $x = 0$ or $y = 0$.** WLOG $x = 0$. Then $|x+y|_v = |y|_v = \max(0, |y
|_v) = \max(|x|_v, |y|_v)$. ✓

**Case 2: $x, y \neq 0$.** By property (3) of the discrete valuation,
$$v(x + y) \geq \min\bigl(v(x),\, v(y)\bigr).$$
Since $c > 1$, the map $t \mapsto c^{-t}$ is strictly decreasing, so applying it
 to both sides (and noting $x + y \neq 0$ since otherwise $v(x+y) = \infty$ and
the inequality is trivial) reverses the inequality:
$$|x + y|_v = c^{-v(x+y)} \leq c^{-\min(v(x),\, v(y))} = \max\!\bigl(c^{-v(x)},\
, c^{-v(y)}\bigr) = \max\bigl(|x|_v,\, |y|_v\bigr).$$

This is precisely the **non-Archimedean (ultrametric) inequality**.

**Equivalently**, the non-Archimedean property can be characterized as $|n \cdot
 1_K|_v \leq 1$ for all $n \in \mathbb{Z}$. This follows immediately: since $|1_
K|_v = c^{-v(1)} = c^{0} = 1$, repeated application of the ultrametric inequalit
y gives
$$|n \cdot 1_K|_v \leq \underbrace{\max(|1|_v, \dots, |1|_v)}_{n \text{ times}}
= 1.$$

**Remark on the hypotheses.** The non-Archimedean conclusion relies **only** on
the defining axioms of a discrete valuation (specifically axiom (3), the strong
triangle inequality for $v$). The characteristic $0$ hypothesis and the complete
ness of $K$ play no role in establishing the non-Archimedean property:

- **Completeness** is a topological property ensuring that Cauchy sequences conv
erge; it does not alter the algebraic inequality $v(x+y) \geq \min(v(x), v(y))$
that forces non-Archimedeanity.
- **Characteristic $0$** is mentioned to make the question non-vacuous in an int
eresting way: in characteristic $0$, Archimedean absolute values *can* exist (e.
g., the usual absolute value on $\mathbb{Q}$, $\mathbb{R}$, $\mathbb{C}$), so th
ere is a genuine question of whether a discrete-valuation absolute value could b
e Archimedean. In positive characteristic, *every* absolute value is automatical
ly non-Archimedean (a classical result), so the question would be trivial there.
 The point is that even in characteristic $0$—where Archimedean absolute values
are possible in general—the absolute value coming from a *discrete valuation* is
 still necessarily non-Archimedean.

**Conclusion.** The absolute value induced by any discrete valuation on any fiel
d (of any characteristic, complete or not) is always non-Archimedean. Therefore,
 for a field $K$ of characteristic $0$ complete with respect to a discrete valua
tion, the absolute value on $K$ is **always non-Archimedean**. $\blacksquare$
