## Setting Up the Model

Each integer 0–99 is written as a two-digit string, so number $n = 10a + b$ corr
esponds to the ordered pair $(a, b)$ where $a$ is the tens digit and $b$ is the
units digit. The set $S$ is thus a subset of $\{0,\dots,9\}^2$.

A 2×2 crossword grid filled with digits $a, b, c, d$:
$$\begin{pmatrix} a & b \\ c & d \end{pmatrix}$$
produces four two-digit numbers: Row 1 = $10a+b$, Row 2 = $10c+d$, Col 1 = $10a+
c$, Col 2 = $10b+d$. The set $S$ fails property $A$ if there exist digits $a,b,c
,d$ with all four of $\{10a+b,\; 10c+d,\; 10a+c,\; 10b+d\} \in S$.

## Key Reduction: Paths of Length 2

**Define a directed graph** $D$ on vertices $\{0,\dots,9\}$ where $x \to y$ is a
n edge iff $10x+y \in S$ (i.e., $(x,y) \in S$).

**Claim.** $S$ has property $A$ if and only if $D$ contains no directed path of
length 2 (i.e., no $a \to b \to d$).

*Proof of Claim.*

($\Leftarrow$) Suppose a crossword exists with digits $a,b,c,d$. Then $(a,b) \in
 S$ and $(b,d) \in S$, giving edges $a \to b$ and $b \to d$ in $D$—a path of len
gth 2. (This holds regardless of whether $b = c$ or $b \neq c$, since the four c
rossword numbers always include both $10a+b$ and $10b+d$.)

($\Rightarrow$) If $D$ has a path $a \to b \to d$, set $c = b$. The grid $\begin
{pmatrix} a & b \\ b & d \end{pmatrix}$ yields numbers $10a+b, 10b+d, 10a+b, 10b
+d$, all in $S$. So $S$ fails property $A$. $\square$

## Characterizing Property $A$

$D$ has no path of length 2 if and only if **every vertex $v$ has $\text{in-deg}
(v) = 0$ or $\text{out-deg}(v) = 0$** (otherwise an incoming edge $u \to v$ and
outgoing edge $v \to w$ form a path $u \to v \to w$).

Partition vertices into:
- $V_{\text{out}}$: vertices with out-degree $> 0$, in-degree $= 0$ (sources),
- $V_{\text{in}}$: vertices with in-degree $> 0$, out-degree $= 0$ (sinks),
- $V_{\text{iso}}$: isolated vertices (both degrees $0$).

**All edges must go from $V_{\text{out}}$ to $V_{\text{in}}$:**
- No edge can point *to* a $V_{\text{out}}$ vertex (it has in-degree $0$).
- No edge can leave a $V_{\text{in}}$ vertex (it has out-degree $0$).
- No edge involves $V_{\text{iso}}$ (both degrees $0$).

Conversely, **any** set of edges from $V_{\text{out}}$ to $V_{\text{in}}$ satisf
ies property $A$: sources only have out-edges, sinks only have in-edges, so no v
ertex is both a head and tail of an edge—no path of length 2 can form.

## Maximizing $|S|$

To maximize the number of edges (elements of $S$), we take **all** edges from $V
_{\text{out}}$ to $V_{\text{in}}$, giving $|V_{\text{out}}| \times |V_{\text{in}
}|$ edges, subject to $|V_{\text{out}}| + |V_{\text{in}}| \leq 10$.

By AM-GM, the product $|V_{\text{out}}| \times |V_{\text{in}}|$ is maximized whe
n $|V_{\text{out}}| = |V_{\text{in}}| = 5$, yielding:
$$5 \times 5 = 25.$$

## Construction Achieving 25

Take $V_{\text{out}} = \{0,1,2,3,4\}$, $V_{\text{in}} = \{5,6,7,8,9\}$, and
$$S = \{10x + y : x \in \{0,1,2,3,4\},\; y \in \{5,6,7,8,9\}\}.$$
This gives $|S| = 25$. Every edge goes from $\{0,1,2,3,4\}$ to $\{5,6,7,8,9\}$.
Any path $a \to b \to d$ requires $b \in V_{\text{out}} \cap V_{\text{in}} = \em
ptyset$, which is impossible. So property $A$ holds.

## Conclusion

The maximal number of elements in a set $S$ with property $A$ is $\boxed{25}$.
