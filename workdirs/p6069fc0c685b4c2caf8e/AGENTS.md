# Problem

In a remote deep-sea research station, a high-tech sensor array generates a daily report consisting of a data packet of 60 individual binary readings (each either a "1" or a "0"). An automated transmission system is tasked with sending this report to a surface vessel. However, due to severe bandwidth limitations caused by a storm, the system can only upload a compressed signal containing exactly 44 binary bits to the surface captain.

The surface captain receives this 44-bit signal and must use it to reconstruct the original 60-bit sensor report as accurately as possible. The captain and the automated system can agree on a coding strategy in advance to maximize the reliability of the reconstructed data.

What is the greatest integer $C$ such that there exists a predetermined strategy ensuring the captain can always identify a 60-bit word that matches the original sensor report in at least $C$ positions, regardless of which 60-bit word was generated?
