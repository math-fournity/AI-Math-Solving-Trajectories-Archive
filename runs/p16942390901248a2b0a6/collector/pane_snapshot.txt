## Solution

We evaluate $I = \int_0^{2\pi}\frac{\cos 3x}{5-4\cos x}\,dx$ using the substitut
ion $z = e^{ix}$, so $dx = \frac{dz}{iz}$, $\cos x = \frac{z+z^{-1}}{2}$, and $\
cos 3x = \frac{z^3+z^{-3}}{2}$.

**Rewriting the integrand.** The denominator becomes
$$5 - 4\cos x = 5 - \frac{2(z^2+1)}{z} = \frac{-2z^2+5z-2}{z} = \frac{-2(z-2)(z-
\tfrac{1}{2})}{z}.$$

Hence
$$I = \oint_{|z|=1} \frac{(z^6+1)}{2z^3}\cdot\frac{z}{-2(z-2)(z-\frac{1}{2})}\cd
ot\frac{dz}{iz} = \oint_{|z|=1} \frac{-(z^6+1)}{4i\,z^3(z-2)(z-\frac{1}{2})}\,dz
.$$

**Identifying poles.** Setting $g(z) = \frac{-(z^6+1)}{4i\,z^3(z-2)(z-\frac{1}{2
})}$, the poles are:
- $z = 0$ (order 3), inside $|z|=1$;
- $z = \tfrac{1}{2}$ (simple), inside $|z|=1$;
- $z = 2$ (simple), **outside** $|z|=1$.

**Residue at $z = \tfrac{1}{2}$:**
$$\operatorname{Res}\!\left(g,\tfrac{1}{2}\right) = \frac{-((\tfrac{1}{2})^6+1)}
{4i\,(\tfrac{1}{2})^3\,(\tfrac{1}{2}-2)} = \frac{-(\tfrac{65}{64})}{4i\cdot\tfra
c{1}{8}\cdot(-\tfrac{3}{2})} = \frac{-65/64}{-3i/4} = \frac{65}{48i} = -\frac{65
i}{48}.$$

**Residue at $z = 0$ (order 3):** Write $g(z) = h(z)/z^3$ with $h(z) = \frac{-(z
^6+1)}{4i\,(z-2)(z-\frac{1}{2})}$. Then $\operatorname{Res}(g,0) = \frac{h''(0)}
{2}$. Setting $\phi(z) = \frac{z^6+1}{(z-2)(z-\frac{1}{2})}$ so that $h(z) = \fr
ac{-1}{4i}\phi(z)$, we need $\phi''(0)$.

Let $\psi(z) = \frac{1}{(z-2)(z-\frac{1}{2})} = \frac{1}{z^2-\frac{5}{2}z+1}$, s
o $\phi(z) = (z^6+1)\psi(z)$. From the identity $\psi(z)(z^2-\frac{5}{2}z+1)=1$,
 differentiating twice and evaluating at $z=0$:
- $\psi(0) = 1$,
- $\psi'(0) = \frac{5}{2}$,
- $\psi''(0) - \frac{25}{2} + 2 = 0 \;\Rightarrow\; \psi''(0) = \frac{21}{2}$.

By the product rule, $\phi''(z) = 30z^4\psi + 12z^5\psi' + (z^6+1)\psi''$, so
$$\phi''(0) = 0 + 0 + 1\cdot\frac{21}{2} = \frac{21}{2}.$$

Therefore
$$\operatorname{Res}(g,0) = \frac{-1}{4i}\cdot\frac{\phi''(0)}{2} = \frac{-1}{4i
}\cdot\frac{21}{4} = \frac{-21}{16i} = \frac{21i}{16}.$$

**Applying the residue theorem:**
$$I = 2\pi i\left[\frac{21i}{16} - \frac{65i}{48}\right] = 2\pi i \cdot i\left[\
frac{63}{48} - \frac{65}{48}\right] = 2\pi(-1)\left(-\frac{2}{48}\right) = 2\pi\
cdot\frac{1}{24} = \frac{\pi}{12}.$$

**Verification via the standard formula** $\int_0^{2\pi}\frac{\cos nx}{a-b\cos x
}\,dx = \frac{2\pi}{\sqrt{a^2-b^2}}\left(\frac{a-\sqrt{a^2-b^2}}{b}\right)^n$ wi
th $a=5,\,b=4,\,n=3$:
$$\frac{2\pi}{3}\left(\frac{5-3}{4}\right)^3 = \frac{2\pi}{3}\cdot\frac{1}{8} =
\frac{\pi}{12}. \checkmark$$

$$\boxed{\displaystyle\int_0^{2\pi}\frac{\cos 3x}{5-4\cos x}\,dx = \frac{\pi}{12
}}$$
