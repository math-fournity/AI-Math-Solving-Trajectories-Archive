## Proof

We find $\|T\| = 1 + |\alpha|$.

**Setup.** Let $L: \ell^2 \to \ell^2$ be the left shift $(Lx)_n = x_{n+1}$ (i.e.
, $L = S^*$ where $S$ is the unilateral right shift, an isometry with $S^*S = I$
). Let $A = -I + \alpha L$, so $(Ax)_n = -x_n + \alpha x_{n+1}$ for all $n \ge 1
$. Let $P$ be the orthogonal projection onto $\{e_2, e_3, \dots\}$, i.e., $(Px)_
1 = 0$, $(Px)_n = x_n$ for $n \ge 2$. Then our operator is $T = PA$, since $(PAx
)_1 = 0$ and $(PAx)_n = (Ax)_n$ for $n \ge 2$.

**Upper bound.** Since $\|P\| = 1$, we have $\|T\| = \|PA\| \le \|A\|$. We show
$\|A\| \le 1 + |\alpha|$. For any $x \in \ell^2$ with $\|x\| = 1$:

$$\|Ax\|^2 = \|{-x + \alpha Lx}\|^2 = \|x\|^2 - 2\operatorname{Re}\!\big(\alpha\
langle x, Lx\rangle\big) + |\alpha|^2\|Lx\|^2.$$

Since $S$ is an isometry, $\|Lx\| = \|S^*x\| \le \|x\| = 1$, and by Cauchy–Schwa
rz, $|\langle x, Lx\rangle| \le \|x\|\|Lx\| \le 1$. Therefore:

$$\|Ax\|^2 \le 1 + 2|\alpha| \cdot 1 + |\alpha|^2 \cdot 1 = (1 + |\alpha|)^2.$$

So $\|A\| \le 1 + |\alpha|$, hence $\|T\| \le 1 + |\alpha|$.

**Lower bound.** If $\alpha = 0$, then $T = P$ and $\|T\| = 1 = 1 + |0|$. Assume
 $\alpha \neq 0$. Write $\alpha = |\alpha|e^{i\varphi}$ and set $z = -e^{-i\varp
hi}$ (so $|z| = 1$ and $\alpha z = -|\alpha|$). For each $N \ge 1$, define the u
nit vector $x^{(N)} \in \ell^2$ by:

$$x^{(N)}_n = \frac{z^n}{\sqrt{N}}, \quad n = 3, 4, \dots, N+2; \qquad x^{(N)}_n
 = 0 \text{ otherwise.}$$

Since $x^{(N)}$ is supported on $\{3, \dots, N+2\}$, we have $(Ax^{(N)})_1 = -x^
{(N)}_1 + \alpha x^{(N)}_2 = 0$, so $Tx^{(N)} = PAx^{(N)} = Ax^{(N)}$. Computing
 $(Tx^{(N)})_n = -x^{(N)}_n + \alpha x^{(N)}_{n+1}$:

- For $3 \le n \le N+1$: $(Tx^{(N)})_n = \frac{z^n}{\sqrt{N}}(-1 + \alpha z) = \
frac{z^n}{\sqrt{N}}(-1 - |\alpha|) = -(1+|\alpha|)\,x^{(N)}_n.$
- For $n = 2$: $(Tx^{(N)})_2 = \alpha\,\frac{z^3}{\sqrt{N}}$, with $|\cdot|^2 =
|\alpha|^2/N$.
- For $n = N+2$: $(Tx^{(N)})_{N+2} = -\frac{z^{N+2}}{\sqrt{N}}$, with $|\cdot|^2
 = 1/N$.

Therefore:

$$\|Tx^{(N)}\|^2 = \frac{|\alpha|^2}{N} + \frac{(N-1)(1+|\alpha|)^2}{N} + \frac{
1}{N} = \frac{|\alpha|^2 + 1}{N} + \frac{(N-1)(1+|\alpha|)^2}{N}.$$

As $N \to \infty$, $\|Tx^{(N)}\|^2 \to (1+|\alpha|)^2$. Since $\|x^{(N)}\| = 1$,
 this gives $\|T\|^2 \ge (1+|\alpha|)^2$, i.e., $\|T\| \ge 1 + |\alpha|$.

**Conclusion.** Combining both bounds:

$$\boxed{\|T\| = 1 + |\alpha|.}$$
