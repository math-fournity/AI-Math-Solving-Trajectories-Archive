证明

答案是肯定的。 每个偏序集 (poset) 都可以保序嵌入到一个完备格 (complete lattice)
中，且该嵌入能保持 $\mathfrak{A}$ 中定义的所有上确界 (suprema) 和下确界
(infima)。其构造方式是 Dedekind–MacNeille 完备化 (通过截取进行完备化)。

────────────────────────────────────────────────────────────────────────────────

构造

设 $\mathfrak{A} = (P, \leq)$ 为一个偏序集。对于子集 $A \subseteq P$，定义：

$$A^{u} = {p \in P : a \leq p \text{ 对于所有 } a \in A} \quad \text{(A 的上
界)}$$

$$A^{l} = {p \in P : p \leq a \text{ 对于所有 } a \in A} \quad \text{(A 的下
界)}$$

如果 $A = A^{ul}$，则称子集 $A$ 为 截取 (cut) (其中 $A^{ul} := (A^u)^l$)。

设 $\mathfrak{B} = \mathrm{DM}(P)$ 为所有截取的集合，按包含关系 $\subseteq$ 排
序。定义嵌入为：

$$\varphi : P \longrightarrow \mathrm{DM}(P), \qquad \varphi(p) = \downarrow!
p := {q \in P : q \leq p}.$$

────────────────────────────────────────────────────────────────────────────────

第一步：$\mathfrak{B}$ 是一个完备格

算子 $(-)^{ul}$ 是一个闭包算子：它是广泛的 ($A \subseteq A^{ul}$，因为每个 $a
\in A$ 都是 $A^u$ 中所有元素的下界)，单调的 ($A \subseteq B \Rightarrow B^u
\subseteq A^u \Rightarrow A^{ul} \subseteq B^{ul}$)，且幂等的 ($A^{ul} =
A^{ulul}$，因为 $A^{ul}$ 是一个截取)。

截取是 $(-)^{ul}$ 的闭合元素，而任何闭包算子的闭合元素族在任意交和“闭包并”下构成
一个完备格。具体来说：

  • 任意交： 截取在任意交下是闭合的。设 $C = \bigcap_i C_i$，其中每个 $C_i$ 都是
  截取。那么 $C \subseteq C^{ul}$ (广泛性)。对于反向包含：由于 $C \subseteq
  C_i$，我们有 $C_i^u \subseteq C^u$，因此 $C^{ul} = (C^u)^l \subseteq (C_i^u)^l
  = C_i^{ul} = C_i$ 对所有 $i$ 成立，因此 $C^{ul} \subseteq \bigcap_i C_i = C$。
  所以 $C$ 是一个截取。
  • 任意并 (上确界)： 截取族 ${C_i}$ 的上确界是 $(\bigcup_i C_i)^{ul}$，这总是一
  个截取。

因此 $\mathfrak{B}$ 是一个完备格，其中 $\bigwedge_i C_i = \bigcap_i C_i$ 且 $
\bigvee_i C_i = (\bigcup_i C_i)^{ul}$。

────────────────────────────────────────────────────────────────────────────────

第二步：$\varphi$ 是一个保序嵌入

对于每个 $p$，$\varphi(p) = \downarrow! p$ 是一个截取：

$$(\downarrow! p)^u = {q : r \leq q \text{ 对于所有 } r \leq p} = {q : p \leq q}
= \uparrow! p,$$

$$((\downarrow! p)^u)^l = (\uparrow! p)^l = {r : r \leq q \text{ 对于所有 } q
\geq p} = {r : r \leq p} = \downarrow! p. \checkmark$$

对于 $p, q \in P$：

$$p \leq q \iff \downarrow! p \subseteq \downarrow! q,$$

因此 $\varphi$ 既保序又反映序 —— 它是一个保序嵌入。

────────────────────────────────────────────────────────────────────────────────

第三步：$\varphi$ 保持 $\mathfrak{A}$ 中存在的所有上确界

设 $S \subseteq P$ 在 $P$ 中有上确界 $s = \bigvee S$。我们必须证明：

$$\bigvee_{a \in S} \varphi(a) = \varphi(s), \quad \text{即,} \quad (\bigcup_{a
\in S} \downarrow! a)^{ul} = \downarrow! s.$$

记 $D := \bigcup_{a \in S} \downarrow! a = {r \in P : r \leq a \text{ 对于某些 }
a \in S}$ (即 $S$ 的向下闭包)。

观察： $D^u = {p : r \leq p \text{ 对于所有 } r \in D} = {p : a \leq p \text{ 对
于所有 } a \in S} = S^u$。(如果 $p$ 在 $D$ 中所有元素的上方，它特别地在 $S$ 中所
有元素的上方；反之，如果 $p$ 在 $S$ 中所有元素的上方，它就在 $D$ 中所有元素的上
方，因为 $D$ 中的每个元素都在某个 $a \in S$ 下方。)

包含关系 $\subseteq$： 由于每个 $a \leq s$，我们有 $\downarrow! a \subseteq
\downarrow! s$，因此 $D \subseteq \downarrow! s$。根据单调性，$D^{ul} \subseteq
(\downarrow! s)^{ul} = \downarrow! s$。

包含关系 $\supseteq$： 我们证明 $s \in D^{ul}$；那么由于 $D^{ul}$ 是一个向下闭集
(它是一个截取，而所有截取都是向下闭集：如果 $r \leq q$ 且 $q \in D^{ul}$，那么对
于所有 $p \in D^u$ 都有 $q \leq p$，因此对于所有 $p \in D^u$ 都有 $r \leq p$，得
出 $r \in D^{ul}$)，我们将得到 $\downarrow! s \subseteq D^{ul}$。

现在 $s \in D^{ul} = (D^u)^l = (S^u)^l$ 当且仅当对于所有 $p \in S^u$ 都有 $s
\leq p$。这正是 $s = \bigvee S$ 的定义 (上确界是 $S$ 的所有上界中的最小元素)。因
此 $s \in D^{ul}$，从而 $\downarrow! s \subseteq D^{ul}$。

结合两个包含关系：$(\bigcup_{a \in S} \downarrow! a)^{ul} = \downarrow! s$，即 $
\bigvee_{a \in S} \varphi(a) = \varphi(\bigvee S)$。$\checkmark$

────────────────────────────────────────────────────────────────────────────────

第四步：$\varphi$ 保持 $\mathfrak{A}$ 中存在的所有下确界

设 $S \subseteq P$ 在 $P$ 中有下确界 $i = \bigwedge S$。我们必须证明：

$$\bigwedge_{a \in S} \varphi(a) = \varphi(i), \quad \text{即,} \quad \bigcap_{a
\in S} \downarrow! a = \downarrow! i.$$

(根据第一步，截取中的下确界是交集。)

计算：

$$\bigcap_{a \in S} \downarrow! a = {r \in P : r \leq a \text{ 对于所有 } a \in
S} = S^l.$$

根据下确界的定义，$i = \bigwedge S$ 是 $S$ 的所有下界中的最大元素：$i \leq a$ 对
于所有 $a \in S$ (因此 $i \in S^l$)，并且对于任何 $r$，如果对于所有 $a \in S$ 都
有 $r \leq a$，则 $r \leq i$。因此：

$$S^l = {r : r \leq i} = \downarrow! i = \varphi(i). \checkmark$$

────────────────────────────────────────────────────────────────────────────────

结论

对于任意偏序集 $\mathfrak{A}$，Dedekind–MacNeille 完备化 $\mathfrak{B} =
\mathrm{DM}(\mathfrak{A})$ 是一个完备格，且映射 $\varphi(p) = \downarrow! p$ 是
一个保序嵌入，它保持了 $\mathfrak{A}$ 中存在的所有上确界和下确界。因此，是的，这
样的嵌入必然存在。
