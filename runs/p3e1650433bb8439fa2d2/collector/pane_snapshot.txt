## Proof

**Step 1: Identify the distribution as a mixture.**

Recall that the moment generating function of a normal random variable $Y \sim N
(0, \sigma^2)$ is $M_Y(t) = e^{\sigma^2 t^2/2}$. In particular, $e^{t^2/(2n)}$ i
s the MGF of $N(0, 1/n)$.

The given MGF is
$$M_X(t) = \frac{6}{\pi^2}\sum_{n\ge 1}\frac{e^{t^2/(2n)}}{n^2}.$$

Setting $p_n = \frac{6}{\pi^2 n^2}$, we observe that $\{p_n\}$ is a probability
mass function since
$$\sum_{n=1}^{\infty} p_n = \frac{6}{\pi^2}\sum_{n=1}^{\infty}\frac{1}{n^2} = \f
rac{6}{\pi^2}\cdot\frac{\pi^2}{6} = 1.$$

Therefore $X$ admits the mixture representation: with probability $p_n = \frac{6
}{\pi^2 n^2}$, $X$ is distributed as $N(0, 1/n)$. Equivalently, let $N$ be an in
teger-valued random variable with $P(N=n) = p_n$, independent of a sequence $\{Z
_n\}$; then $X \mid N=n \sim N(0,1/n)$.

**Step 2: Compute $P(X \in \mathbb{Q})$.**

By the law of total probability,
$$P(X \in \mathbb{Q}) = \sum_{n=1}^{\infty} p_n \, P\!\left(X \in \mathbb{Q} \mi
d N = n\right).$$

For each $n$, the conditional distribution $X \mid N=n$ is $N(0, 1/n)$, which is
 a continuous (absolutely continuous) distribution. The set of rational numbers
$\mathbb{Q}$ is countable, hence has Lebesgue measure zero. Therefore
$$P\!\left(X \in \mathbb{Q} \mid N = n\right) = 0 \quad \text{for every } n \ge
1.$$

Consequently,
$$P(X \in \mathbb{Q}) = \sum_{n=1}^{\infty} p_n \cdot 0 = 0.$$

**Conclusion.** The probability that $X$ is a rational number is $\boxed{0}$.
