# Problem

In a specialized satellite network, there are $n=5$ pairs of "Twin-Link" nodes. To prevent interference, no node is allowed to establish a direct connection with its own Twin-Link partner. However, for every other possible pair of nodes in the system, a shared encrypted communication channel must exist.

To facilitate these connections, the network uses a set of $k$ distinct Hub Routers ($C_1, C_2, \dots, C_k$). Each Hub Router creates a local network (a "clique") where every node assigned to that Hub can communicate with every other node assigned to the same Hub. The network architecture is subject to two strict constraints:
1. No two nodes that are Twin-Link partners can be assigned to the same Hub Router.
2. For every pair of nodes that are NOT Twin-Link partners, there must be exactly one Hub Router to which both nodes are assigned.

Determine the minimum possible value of $k$ (the total number of Hub Routers) required to satisfy these connectivity requirements.
