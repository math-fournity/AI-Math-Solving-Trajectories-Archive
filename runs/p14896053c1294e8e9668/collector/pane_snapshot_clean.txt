# Common Divisors of $a_{1986}$ and $a_{6891}$

## Setup and Identification

The sequence $(a_n)$ is defined by $a_0 = 0$, $a_1 = 1$, and $a_{n+2} = 4a_{n+1}
 + a_n$ for $n \geq 0$. This is a **Lucas sequence of the first kind** $U_n(P, Q
)$ with parameters $P = 4$ and $Q = -1$.

The characteristic equation is $x^2 - 4x - 1 = 0$, with roots $\alpha = 2 + \sqr
t{5}$ and $\beta = 2 - \sqrt{5}$. We have $\alpha + \beta = 4 = P$, $\alpha\beta
 = -1 = Q$, and the closed form:
$$a_n = \frac{\alpha^n - \beta^n}{\alpha - \beta} = \frac{\alpha^n - \beta^n}{2\
sqrt{5}}.$$

## The Strong Divisibility Property

**Theorem.** For a Lucas sequence $U_n(P, Q)$ with $\gcd(P, Q) = 1$, the sequenc
e is a *strong divisibility sequence*:
$$\gcd(U_m, U_n) = U_{\gcd(m, n)} \quad \text{for all } m, n \geq 0.$$

**Proof sketch.** The key ingredients are:

1. **Divisibility:** If $d \mid n$, then $U_d \mid U_n$. This follows from the i
dentity $U_n = U_d \cdot \left(\sum_{j} \alpha^{n-1-jd}\beta^{jd}\right)/(2\sqrt
{5})$ combined with the fact that $U_{kn}/U_n$ is an integer (provable by induct
ion on $k$ using the addition formula $U_{m+n} = U_m U_{n+1} + Q U_{m-1} U_n$).

2. **Euclidean step:** Using the addition formula, one shows $\gcd(U_m, U_n) = \
gcd(U_n, U_{m \bmod n})$ when $n \mid$-related, mirroring the Euclidean algorith
m on the indices.

3. **Base case:** $\gcd(U_m, U_0) = \gcd(U_m, 0) = U_m = U_{\gcd(m,0)}$.

Iterating the Euclidean step yields $\gcd(U_m, U_n) = U_{\gcd(m,n)}$.

In our case $P = 4$, $Q = -1$, and $\gcd(4, -1) = 1$, so the hypothesis is satis
fied.

## Verification with Small Cases

- $a_0 = 0,\ a_1 = 1,\ a_2 = 4(1)+0 = 4,\ a_3 = 4(4)+1 = 17,\ a_4 = 4(17)+4 = 72
,\ a_5 = 4(72)+17 = 305,\ a_6 = 4(305)+72 = 1292$.
- $\gcd(a_2, a_3) = \gcd(4, 17) = 1 = a_1 = a_{\gcd(2,3)}$. ✓
- $\gcd(a_2, a_4) = \gcd(4, 72) = 4 = a_2 = a_{\gcd(2,4)}$. ✓
- $\gcd(a_3, a_6) = \gcd(17, 1292) = 17 = a_3 = a_{\gcd(3,6)}$ (since $1292 = 17
 \times 76$). ✓

## Computing $\gcd(1986, 6891)$

Applying the Euclidean algorithm:

| Step | Computation |
|------|-------------|
| $6891 = 3 \times 1986 + 933$ | |
| $1986 = 2 \times 933 + 120$ | |
| $933 = 7 \times 120 + 93$ | |
| $120 = 1 \times 93 + 27$ | |
| $93 = 3 \times 27 + 12$ | |
| $27 = 2 \times 12 + 3$ | |
| $12 = 4 \times 3 + 0$ | |

Thus $\gcd(1986, 6891) = 3$.

(Equivalently, $1986 = 2 \times 3 \times 331$ and $6891 = 3 \times 2297$, where
$331$ and $2297$ are both prime and distinct, confirming $\gcd = 3$.)

## Computing $a_3$

$$a_2 = 4a_1 + a_0 = 4(1) + 0 = 4,$$
$$a_3 = 4a_2 + a_1 = 4(4) + 1 = 17.$$

## Conclusion

By the strong divisibility property:
$$\gcd(a_{1986}, a_{6891}) = a_{\gcd(1986,\, 6891)} = a_3 = 17.$$

Since $17$ is prime, the set of all positive common divisors of $a_{1986}$ and $
a_{6891}$ is the set of all positive divisors of $17$:

$$\boxed{\{1,\ 17\}}.$$
