# Problem

In a remote industrial warehouse, a logistics manager identifies a specific inventory set, $S$, containing exactly 100 distinct identification codes chosen from the natural numbers between 1 and 10,000 inclusive.

The facility features a massive grid-storage system where every possible storage slot corresponds to a triplet of coordinates $(x, y, z)$, such that each coordinate is a code drawn from the set $S$. Consequently, there are exactly $1,000,000$ unique storage slots filled with specialized spherical containers.

Each container is labeled with a "Stability Index," calculated by a specific sensor using the formula:
$$\frac{x^{2}+y^{2}+z^{2}}{x y+y z+z x}$$
where $x, y,$ and $z$ are the identification codes of that container's specific slot.

Given that the set $S$ of 100 codes is chosen to maximize the occurrence of a specific readout, what is the maximum possible number of containers that can have a Stability Index exactly equal to 2?
