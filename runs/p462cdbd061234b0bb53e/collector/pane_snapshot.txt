## Proof

Let
$$I = \int_0^\infty \frac{dx}{(1+x^2)(1+x^{2018})}.$$

Apply the substitution $x \mapsto 1/x$. Setting $u = 1/x$, so $dx = -du/u^2$, an
d the limits reverse ($x:0\to\infty$ becomes $u:\infty\to 0$):

$$I = \int_0^\infty \frac{1}{\left(1+\frac{1}{u^2}\right)\left(1+\frac{1}{u^{201
8}}\right)}\cdot\frac{du}{u^2}.$$

Simplifying each factor:
$$1+\frac{1}{u^2} = \frac{u^2+1}{u^2}, \qquad 1+\frac{1}{u^{2018}} = \frac{u^{20
18}+1}{u^{2018}}.$$

Hence
$$I = \int_0^\infty \frac{u^2}{u^2+1}\cdot\frac{u^{2018}}{u^{2018}+1}\cdot\frac{
du}{u^2} = \int_0^\infty \frac{u^{2018}}{(1+u^2)(1+u^{2018})}\,du.$$

Renaming the dummy variable back to $x$:
$$I = \int_0^\infty \frac{x^{2018}}{(1+x^2)(1+x^{2018})}\,dx.$$

Now add the two expressions for $I$:

$$2I = \int_0^\infty \frac{1+x^{2018}}{(1+x^2)(1+x^{2018})}\,dx = \int_0^\infty
\frac{1}{1+x^2}\,dx = \arctan x\Big|_0^\infty = \frac{\pi}{2}.$$

Therefore
$$I = \frac{\pi}{4}.$$
