## Solution

The poles of $f(z)=\frac{1}{(e^z-1)^2}$ occur where $e^z-1=0$, i.e. at $z_n=2\pi
 i n$ for $n\in\mathbb{Z}$.

**Reduction to the origin.** Since $e^z$ is $2\pi i$-periodic, $f(z)$ is also $2
\pi i$-periodic. Thus every pole $z_n$ has the same local behavior as the pole a
t $z=0$; it suffices to compute the residue at $z=0$ and transfer it by periodic
ity.

**Order of the pole.** Set $w=z$. Near $w=0$,
$$e^w-1 = w + \frac{w^2}{2} + \frac{w^3}{6}+\cdots = w\!\left(1+\frac{w}{2}+\fra
c{w^2}{6}+\cdots\right).$$
Hence $(e^w-1)^2 = w^2\!\left(1+\frac{w}{2}+\cdots\right)^2$, so $f$ has a pole
of order $2$ at $w=0$.

**Laurent expansion.** Use the classical Bernoulli expansion
$$\frac{1}{e^w-1} = \frac{1}{w}-\frac{1}{2}+\frac{w}{12}-\frac{w^3}{720}+\cdots.
$$
Squaring,
$$\frac{1}{(e^w-1)^2} = \left(\frac{1}{w}-\frac{1}{2}+\frac{w}{12}-\cdots\right)
^2 = \frac{1}{w^2}-\frac{1}{w}+\left(\frac{1}{4}+\frac{1}{6}\right)+\cdots = \fr
ac{1}{w^2}-\frac{1}{w}+\frac{5}{12}+\cdots.$$

The coefficient of $1/w$ is $-1$, so
$$\operatorname{Res}_{z=0} f(z) = -1.$$

**Transfer by periodicity.** For a general pole $z_n=2\pi i n$, set $w=z-z_n$. T
hen $e^z = e^{z_n}e^w = e^w$ (since $e^{2\pi i n}=1$), so $e^z-1 = e^w-1$, and t
he identical expansion gives
$$f(z) = \frac{1}{(e^w-1)^2} = \frac{1}{w^2}-\frac{1}{w}+\frac{5}{12}+\cdots,\qq
uad w=z-z_n.$$
Therefore
$$\boxed{\operatorname{Res}_{z=2\pi i n} f(z) = -1 \quad\text{for every integer
} n.}$$
