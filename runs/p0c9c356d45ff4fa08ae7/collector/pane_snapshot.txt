## Connection to Stern's Diatomic Sequence

**Stern's diatomic sequence** is defined by:
$$s(0) = 0,\quad s(1) = 1,\quad s(2n) = s(n),\quad s(2n+1) = s(n) + s(n+1).$$

**Theorem (Calkin–Wilf):** The sequence $a_n = s(n)/s(n+1)$ for $n \geq 1$ satis
fies $a_1 = 1$ and $a_{n+1} = \frac{1}{2\lfloor a_n \rfloor - a_n + 1}$.

*Verification of base cases:* $a_1 = s(1)/s(2) = 1/1 = 1$ ✓; $a_2 = s(2)/s(3) =
1/2$ ✓; $a_3 = s(3)/s(4) = 2/1 = 2$ ✓; $a_7 = s(7)/s(8) = 3/1 = 3$ ✓; $a_{15} =
s(15)/s(16) = 4/1 = 4$ ✓.

The recurrence $a_{n+1} = \frac{1}{2\lfloor a_n\rfloor - a_n + 1}$ is the standa
rd successor function for the Calkin–Wilf tree (each node $p/q$ has left child $
p/(p+q)$ and right child $(p+q)/q$, traversed in BFS order), and $s(n)/s(n+1)$ i
s the well-known closed form for this traversal. (This can be proved by inductio
n on the tree structure: the BFS successor of a node is obtained by the "go up t
o the nearest ancestor where you came from the left, then go right, then go left
 all the way down" operation, which algebraically yields exactly $f(x) = 1/(2\lf
loor x\rfloor - x + 1)$.)

Therefore $a_{2014} = s(2014)/s(2015)$.
