The operator is

$$(Tf)(x) = \int_{-1}^{1} xy\,f(y)\,dy = x\int_{-1}^{1} y\,f(y)\,dy.$$

Set $c(f) := \int_{-1}^{1} y\,f(y)\,dy$, so $(Tf)(x) = c(f)\cdot x$.

**Step 1: Compute $\|Tf\|_1$.**

$$\|Tf\|_1 = \int_{-1}^{1}|c(f)\cdot x|\,dx = |c(f)|\int_{-1}^{1}|x|\,dx = |c(f)
|\cdot 1 = |c(f)|,$$

since $\int_{-1}^{1}|x|\,dx = 2\int_0^1 x\,dx = 1$.

**Step 2: Upper bound.**

$$|c(f)| = \left|\int_{-1}^{1} y\,f(y)\,dy\right| \le \int_{-1}^{1}|y|\,|f(y)|\,
dy \le \|f\|_{\infty}\int_{-1}^{1}|y|\,dy = \|f\|_{\infty}\cdot 1.$$

Therefore

$$\frac{\|Tf\|_1}{\|f\|_{\infty}} = \frac{|c(f)|}{\|f\|_{\infty}} \le 1,$$

giving $\|T\| \le 1$.

**Step 3: Attainment.**

Take $f(y) = \operatorname{sgn}(y)$, i.e. $f(y)=1$ for $y>0$ and $f(y)=-1$ for $
y<0$. Then $\|f\|_{\infty}=1$ and

$$c(f) = \int_{-1}^{1} y\,\operatorname{sgn}(y)\,dy = \int_{-1}^{1}|y|\,dy = 1.$
$

Hence $\|Tf\|_1 = |c(f)| = 1$ and $\|f\|_{\infty}=1$, so the ratio equals $1$.

**Conclusion.** The upper bound is achieved, so

$$\boxed{\|T\| = 1}.$$
