# Problem

In a remote digital archipelago, a network of $n$ unique server nodes, where $n$ is an odd integer greater than 10, must be arranged in a physical ring topology for a security experiment. Each node is assigned a unique identification rank from the set of natural numbers $\{1, 2, 3, \ldots, n\}$.

The security protocol requires a "Divisor Link" configuration: for any node in the ring, its identification rank must be an exact divisor of the sum of the identification ranks of its two immediate neighbors.

The network architect considers two ring arrangements to be identical if one can be transformed into the other through rotation around the circle or by flipping the entire ring (reflection).

Calculate the total number of distinct ways to arrange these $n$ nodes to satisfy the security protocol.
