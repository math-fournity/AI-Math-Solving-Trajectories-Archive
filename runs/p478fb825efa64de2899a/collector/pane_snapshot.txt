**Answer: No.** Here is a counterexample.

Let $X = [0,1]$ with its usual topology (a compact metric space), and let $A = [
0,1]$. For each $n \geq 1$, define the Borel probability measure

$$\mu_n = \frac{1}{n}\sum_{k=0}^{n-1} \delta_{k/n},$$

i.e., the uniform measure on the $n$ equally-spaced points $\{0, \tfrac{1}{n}, \
tfrac{2}{n}, \dots, \tfrac{n-1}{n}\}$.

**Verification of the hypothesis.** Set $F_n = \{k/n : k = 0, 1, \dots, n-1\}$.
This is a finite subset of $A = [0,1]$, and

$$\mu_n(F_n) = \frac{1}{n}\cdot n = 1 = \mu_n([0,1]) = \mu_n(A).$$

So the hypothesis is satisfied for every $n$.

**Weak* limit.** For any continuous function $f \in C([0,1])$,

$$\int f\,d\mu_n = \frac{1}{n}\sum_{k=0}^{n-1} f\!\left(\frac{k}{n}\right) \xrig
htarrow{n\to\infty} \int_0^1 f(x)\,dx,$$

since the left-hand side is the left Riemann sum of $f$ over $n$ equal subinterv
als, which converges to the Riemann integral for every continuous $f$. Thus $\mu
_n \to \mu$ in the weak* topology, where $\mu$ is Lebesgue measure on $[0,1]$.

**The conclusion fails.** We have $\mu(A) = \mu([0,1]) = 1$. However, Lebesgue m
easure is non-atomic: every singleton has measure $0$, so every finite set $F$ s
atisfies $\mu(F) = 0$. Therefore

$$\mu(A) = 1 \neq 0 = \mu(F)$$

for every finite $F \subseteq A$.

**Conclusion.** The property "$\mu(A)$ is concentrated on a finite subset of $A$
" is **not** preserved under weak* limits. The weak* limit of finitely-supported
 (on $A$) measures can be a non-atomic measure, for which no finite subset of $A
$ carries the full mass $\mu(A)$. Hence the answer to the question is **No**.
