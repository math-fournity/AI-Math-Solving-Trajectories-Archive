Looking at this problem, I need to find $\sum_{i \neq j}^{k} (P_iP_j)^{-2}$ for
a regular $k$-gon inscribed in the unit circle.

## Setting Up the Distance

Place the vertices at angles $\frac{2\pi m}{k}$ for $m = 0, 1, \ldots, k-1$. The
 distance between $P_i$ and $P_j$ with angular separation $\theta = \frac{2\pi(i
-j)}{k}$ is:

$$|P_iP_j| = 2\left|\sin\frac{\theta}{2}\right| = 2\left|\sin\frac{\pi(i-j)}{k}\
right|$$

so

$$(P_iP_j)^{-2} = \frac{1}{4\sin^2\!\left(\frac{\pi(i-j)}{k}\right)}.$$

## Counting Pairs by Difference

For each residue $d \in \{1, 2, \ldots, k-1\}$, there are exactly $k$ ordered pa
irs $(i,j)$ with $i - j \equiv d \pmod{k}$. Therefore:

$$S = \sum_{i \neq j} (P_iP_j)^{-2} = \frac{k}{4}\sum_{d=1}^{k-1} \csc^2\!\left(
\frac{\pi d}{k}\right).$$

## The Key Identity

**Claim:** $\displaystyle\sum_{d=1}^{k-1} \csc^2\!\left(\frac{\pi d}{k}\right) =
 \frac{k^2 - 1}{3}.$

**Proof of the identity.** Start from the product formula

$$\sin(k\theta) = 2^{k-1}\prod_{d=0}^{k-1}\sin\!\left(\theta + \frac{\pi d}{k}\r
ight).$$

Taking the logarithmic derivative:

$$k\cot(k\theta) = \sum_{d=0}^{k-1}\cot\!\left(\theta + \frac{\pi d}{k}\right).$
$

Differentiating both sides with respect to $\theta$:

$$-k^2\csc^2(k\theta) = -\sum_{d=0}^{k-1}\csc^2\!\left(\theta + \frac{\pi d}{k}\
right),$$

hence

$$\sum_{d=0}^{k-1}\csc^2\!\left(\theta + \frac{\pi d}{k}\right) = k^2\csc^2(k\th
eta).$$

Separate the $d=0$ term and let $\theta \to 0$. Using the Laurent expansion $\cs
c^2(x) = \frac{1}{x^2} + \frac{1}{3} + O(x^2)$:

$$\csc^2(\theta) + \sum_{d=1}^{k-1}\csc^2\!\left(\frac{\pi d}{k}\right) = k^2\cs
c^2(k\theta).$$

As $\theta \to 0$: the left side has $\frac{1}{\theta^2} + \frac{1}{3} + \cdots$
 from the first term, and the right side has $\frac{k^2}{k^2\theta^2} + \frac{k^
2}{3} + \cdots = \frac{1}{\theta^2} + \frac{k^2}{3} + \cdots$. The $\frac{1}{\th
eta^2}$ terms cancel, giving:

$$\sum_{d=1}^{k-1}\csc^2\!\left(\frac{\pi d}{k}\right) = \frac{k^2}{3} - \frac{1
}{3} = \frac{k^2-1}{3}. \qquad \square$$

## Final Computation

Substituting back:

$$S = \frac{k}{4}\cdot\frac{k^2-1}{3} = \frac{k(k^2-1)}{12}.$$

## Verification with Small Cases

- **$k=2$:** Two diametrically opposite points, distance $2$. Two ordered pairs,
 each contributing $1/4$. Sum $= \frac{1}{2}$. Formula: $\frac{2\cdot 3}{12} = \
frac{1}{2}$. ✓
- **$k=3$:** Equilateral triangle, side $\sqrt{3}$. Six ordered pairs, each cont
ributing $\frac{1}{3}$. Sum $= 2$. Formula: $\frac{3\cdot 8}{12} = 2$. ✓
- **$k=4$:** Square with side $\sqrt{2}$, diagonal $2$. Eight ordered pairs at d
istance $\sqrt{2}$ (contributing $\frac{1}{2}$ each) and four at distance $2$ (c
ontributing $\frac{1}{4}$ each). Sum $= 4 + 1 = 5$. Formula: $\frac{4\cdot 15}{1
2} = 5$. ✓

## Answer

$$\boxed{\displaystyle\sum_{i\neq j}^{k}(P_iP_j)^{-2} = \frac{k(k^2-1)}{12}}$$
