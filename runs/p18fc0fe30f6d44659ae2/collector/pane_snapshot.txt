# Solution

**Answer:** The number of distinct partitions is $2^{\aleph_0}$, the cardinality
 of the continuum.

## Proof

Let $\mathcal{P}$ be the set of all partitions of $\mathbb{N}$ into countably ma
ny countably infinite subsets. We show $|\mathcal{P}| = 2^{\aleph_0}$ by establi
shing matching upper and lower bounds.

### Upper Bound: $|\mathcal{P}| \leq 2^{\aleph_0}$

Every partition $\{A_0, A_1, \dots\} \in \mathcal{P}$ determines an equivalence
relation $\sim$ on $\mathbb{N}$, where $n \sim m$ iff $n$ and $m$ lie in the sam
e part $A_k$. An equivalence relation on $\mathbb{N}$ is a subset of $\mathbb{N}
 \times \mathbb{N}$. Since $|\mathbb{N} \times \mathbb{N}| = \aleph_0$, the tota
l number of equivalence relations on $\mathbb{N}$ is at most $2^{\aleph_0}$. The
refore:

$$|\mathcal{P}| \leq 2^{\aleph_0}.$$

### Lower Bound: $|\mathcal{P}| \geq 2^{\aleph_0}$

We construct an injection from a set of cardinality $2^{\aleph_0}$ into $\mathca
l{P}$.

Since $\mathbb{Q}$ is countable, fix a bijection $\mathbb{N} \cong \mathbb{Q}$;
it suffices to construct $2^{\aleph_0}$ distinct partitions of $\mathbb{Q}$ into
 countably many countably infinite sets.

**Construction.** For each irrational $\alpha \in \mathbb{R} \setminus \mathbb{Q
}$, define:

$$P_\alpha = \bigl\{\, \mathbb{Q} \cap (n + \alpha,\; n + \alpha + 1) \;:\; n \i
n \mathbb{Z} \,\bigr\}.$$

**$P_\alpha$ is a valid partition.** The open intervals $(n+\alpha,\, n+\alpha+1
)$ for $n \in \mathbb{Z}$ are pairwise disjoint and cover $\mathbb{R}$ except fo
r the boundary points $\{n + \alpha : n \in \mathbb{Z}\}$. Since $\alpha$ is irr
ational, every $n + \alpha$ is irrational, so no boundary point is rational. Hen
ce:

$$\mathbb{Q} = \bigsqcup_{n \in \mathbb{Z}} \bigl(\mathbb{Q} \cap (n+\alpha,\, n
+\alpha+1)\bigr).$$

Each part $\mathbb{Q} \cap (n+\alpha, n+\alpha+1)$ is countably infinite (by den
sity of $\mathbb{Q}$ in $\mathbb{R}$), and there are countably many parts (index
ed by $\mathbb{Z}$). Thus $P_\alpha \in \mathcal{P}$.

**Distinctness.** The partition $P_\alpha$ is completely determined by its set o
f cut points:

$$C_\alpha = \{n + \alpha : n \in \mathbb{Z}\} = \alpha + \mathbb{Z}.$$

Indeed, two rationals $q_1 < q_2$ lie in the same part of $P_\alpha$ if and only
 if the interval $(q_1, q_2)$ contains no element of $C_\alpha$. Therefore $P_\a
lpha = P_\beta$ if and only if $C_\alpha = C_\beta$, which holds if and only if
$\alpha - \beta \in \mathbb{Z}$.

It follows that the map $\alpha \mapsto P_\alpha$ descends to an injection:

$$(\mathbb{R} \setminus \mathbb{Q})\,/\,\mathbb{Z} \;\hookrightarrow\; \mathcal{
P}.$$

The domain has cardinality $2^{\aleph_0}$: $|\mathbb{R}/\mathbb{Z}| = 2^{\aleph_
0}$, and removing the countably many rational cosets preserves this cardinality.
 Hence:

$$|\mathcal{P}| \geq 2^{\aleph_0}.$$

### Conclusion

Combining both bounds:

$$|\mathcal{P}| = 2^{\aleph_0}.$$

The number of distinct ways to partition $\mathbb{N}$ into countably infinite su
bsets is $2^{\aleph_0}$, the cardinality of the continuum. $\blacksquare$
