## 解答

**平衡多项式的定义。** 如果对于每一个 $r > 0$，多项式 $p(x,y)$ 在以原点为圆心的
每个圆上的平均值都为 $0$，则称该多项式是*平衡的*：

$$\frac{1}{2\pi}\int_0^{2\pi} p(r\cos\theta,\, r\sin\theta)\,d\theta = 0 \quad \
forall\, r>0.$$

**步骤 1：化简为齐次分量。** 将任意次数 $\le 2009$ 的多项式写为 $p = \sum_{k=0}^
{2009} p_k$，其中 $p_k$ 是 $k$ 次齐次多项式。在半径为 $r$ 的圆上，$p_k(r\cos\the
ta, r\sin\theta) = r^k\, p_k(\cos\theta,\sin\theta)$，因此平均值为

$$\sum_{k=0}^{2009} r^k \underbrace{\frac{1}{2\pi}\int_0^{2\pi} p_k(\cos\theta,\
sin\theta)\,d\theta}_{:=\, A(p_k)}.$$

由于这是关于 $r$ 的多项式，且对于所有 $r>0$ 均为零，因此每一项系数 $A(p_k) = 0$
。所以 **当且仅当每一个齐次分量 $p_k$ 都是平衡的时，$p$ 才是平衡的**，且

$$\dim V = \sum_{k=0}^{2009} \dim B_k,$$

其中 $B_k$ 是 $k$ 次平衡齐次多项式的空间。

**步骤 2：$\dim B_k$。** $k$ 次齐次多项式空间的一组基为 $\{x^{k-j}y^j : 0\le j\l
e k\}$，其维数为 $k+1$。记 $M_j(\theta) = \cos^{k-j}\theta\,\sin^j\theta$。

- **$k$ 为奇数：** 在变换 $\theta\mapsto\theta+\pi$ 下，$M_j \mapsto (-1)^k M_j
= -M_j$，因此每个 $M_j$ 在 $[0,2\pi]$ 上的积分为零。每一个 $k$ 次齐次多项式都是
平衡的：$$\dim B_k = k+1.$$

- **$k$ 为偶数，$k=2m$：** 当 $j$ 为奇数时，$M_j$ 包含 $\sin\theta$ 的奇数次幂，
因此其积分为零（由关于 $\theta\mapsto -\theta$ 的对称性可知）。当 $j$ 为偶数时，
$j=2i$，平均值 $A(x^{k-2i}y^{2i}) = \frac{1}{2\pi}\int_0^{2\pi}\cos^{2(m-i)}\the
ta\sin^{2i}\theta\,d\theta = \frac{\Gamma(m-i+\tfrac12)\Gamma(i+\tfrac12)}{\pi\,
 m!} > 0$。因此，平衡条件 $A(p_k)=0$ 给出了关于 $m+1$ 个偶数 $j$ 系数的一个非平
凡线性约束，而 $m$ 个奇数 $j$ 系数是自由的。从而：$$\dim B_k = m + (m+1-1) = 2m
= k.$$

（对于 $k=0$：$m=0$，$\dim B_0 = 0$，即只有零常数是平衡的。✓）

**步骤 3：求和。**

$$\dim V = \underbrace{\sum_{\substack{k=1\\k\text{ odd}}}^{2009}(k+1)}_{\text{
奇数 } k} \;+\; \underbrace{\sum_{\substack{k=2\\k\text{ even}}}^{2008} k}_{\tex
t{偶数 } k \ge 2} \;+\; \underbrace{0}_{k=0}.$$

**奇数 $k = 2j-1$，$j=1,\dots,1005$：**
$$\sum_{j=1}^{1005}(2j-1+1) = \sum_{j=1}^{1005}2j = 2\cdot\frac{1005\cdot 1006}{
2} = 1005\cdot 1006 = 1{,}011{,}030.$$

**偶数 $k = 2j$，$j=1,\dots,1004$：**
$$\sum_{j=1}^{1004}2j = 2\cdot\frac{1004\cdot 1005}{2} = 1004\cdot 1005 = 1{,}00
9{,}020.$$

**总计：**
$$\dim V = 1{,}011{,}030 + 1{,}009{,}020 = 1005(1006+1004) = 1005\times 2010 = \
boxed{2{,}020{,}050}.$$
