## Solution

This is a finite-horizon optimal stopping problem. I solve it by backward induct
ion.

**Setup.** Each extraction yields a uniform integer in {1,2,3,4,5,6}. Up to 3 ex
tractions; the third must be accepted.

**Stage 3 (forced accept).** The expected value is
$$V_3 = \frac{1+2+3+4+5+6}{6} = \frac{21}{6} = 3.5.$$

**Stage 2.** After observing the second yield, Dr. Aris accepts it if it exceeds
 the continuation value $V_3 = 3.5$, otherwise discards and proceeds to stage 3.
 Since yields are integers, he accepts yields $\geq 4$ (i.e., 4,5,6) and discard
s 1,2,3.

$$V_2 = \frac{1}{6}(4+5+6) + \frac{1}{6}\cdot 3 \cdot V_3 = \frac{15}{6} + \frac
{3}{6}\cdot\frac{7}{2} = \frac{15}{6} + \frac{21}{12} = \frac{30}{12} + \frac{21
}{12} = \frac{51}{12} = \frac{17}{4} = 4.25.$$

**Stage 1.** After observing the first yield, he accepts if it exceeds $V_2 = 4.
25$, i.e., accepts yields $\geq 5$ (5,6) and discards 1,2,3,4.

$$V_1 = \frac{1}{6}(5+6) + \frac{1}{6}\cdot 4 \cdot V_2 = \frac{11}{6} + \frac{4
}{6}\cdot\frac{17}{4} = \frac{11}{6} + \frac{17}{6} = \frac{28}{6} = \frac{14}{3
}.$$

**Verification of optimality.** At each stage the threshold rule is optimal beca
use the continuation value is a constant independent of the observed yield, so a
ccepting iff current yield $>$ continuation value maximizes expected payoff poin
twise.

**Result.** The expected value is $\frac{14}{3}$, with $\gcd(14,3)=1$, so $m=14$
, $n=3$.

$$m + n = 14 + 3 = 17.$$
