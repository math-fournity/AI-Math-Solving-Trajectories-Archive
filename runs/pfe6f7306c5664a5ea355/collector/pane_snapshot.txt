## Solution

**Answer-leak check:** The problem statement contains only the question, no solu
tion or answer. Proceeding.

**Setup.** We have
$$\frac{3}{2008} = \frac{1}{m}+\frac{1}{n} = \frac{m+n}{mn},$$
so $3mn = 2008(m+n)$, i.e. $3mn - 2008m - 2008n = 0$.

**Simon's favorite factoring trick.** Multiply by $3$:
$$9mn - 6024m - 6024n = 0 \implies (3m-2008)(3n-2008) = 2008^2.$$

Let $d = 3m-2008$, $e = 3n-2008$, so $de = 2008^2$ with $d < e$ (since $m < n$).

**Congruence condition.** Since $d = 3m-2008 \equiv -2008 \pmod{3}$ and $2008 =
3\cdot 669 + 1 \equiv 1\pmod{3}$, we need
$$d \equiv e \equiv 2 \pmod{3}.$$

**Sign analysis.** Since $de = 2008^2 > 0$, $d,e$ have the same sign.

- *Both negative:* $d < e < 0$. Write $d' = -d, e' = -e$ with $d' > e' > 0$ and
$d'e' = 2008^2$. Then $d' > 2008$ (as $d' > e'$ and $d'e' = 2008^2$), so $m = (d
+2008)/3 = (2008-d')/3 < 0$. **No valid solutions.**

- *Both positive:* $0 < d < e$, both $\equiv 2\pmod{3}$, $de = 2008^2$. Then $m
= (d+2008)/3 > 0$ automatically. Valid.

**Counting divisors.** Factor $2008 = 2^3 \cdot 251$, so $2008^2 = 2^6 \cdot 251
^2$. Note $2 \equiv 2\pmod{3}$ and $251 \equiv 2\pmod{3}$.

A divisor $2^a \cdot 251^b$ ($0\le a\le 6$, $0\le b\le 2$) satisfies $\equiv 2\p
mod{3}$ iff $2^{a+b}\equiv 2\pmod{3}$, i.e. $a+b$ is **odd**.

Count with $a+b$ odd:
- $b=0$: $a\in\{1,3,5\}$ → $3$ choices
- $b=1$: $a\in\{0,2,4,6\}$ → $4$ choices
- $b=2$: $a\in\{1,3,5\}$ → $3$ choices

Total: $3+4+3 = 10$ divisors $\equiv 2\pmod{3}$.

**Pairing.** Since $2008^2$ is a perfect square, its square root is $2008 \equiv
 1\pmod{3}$, which is **not** among our $10$ divisors. Hence the $10$ divisors p
air perfectly into $5$ unordered pairs $(d,e)$ with $d<e$ and $de = 2008^2$, eac
h yielding a unique valid pair $(m,n) = \bigl(\frac{d+2008}{3}, \frac{e+2008}{3}
\bigr)$ with $m < n$.

**Explicit verification of the 5 pairs:**

| $d$ | $e = 2008^2/d$ | $m=(d+2008)/3$ | $n=(e+2008)/3$ |
|-----|------|------|------|
| $2$ | $2016032$ | $670$ | $672680$ |
| $8$ | $504008$ | $672$ | $168672$ |
| $32$ | $126002$ | $680$ | $42670$ |
| $251$ | $16064$ | $753$ | $6024$ |
| $1004$ | $4016$ | $1004$ | $2008$ |

Each row gives positive integers with $m < n$, and one checks (e.g. last row) $\
frac{1}{1004}+\frac{1}{2008} = \frac{2+1}{2008} = \frac{3}{2008}$. ✓

**Answer:** $\boxed{5}$.
