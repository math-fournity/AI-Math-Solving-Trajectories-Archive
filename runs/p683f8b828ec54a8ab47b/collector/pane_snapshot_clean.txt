**Claim:** $\sum_{n=1}^\infty a_n^2$ **diverges**.

### Step 1. Basic properties of $(a_n)$

We have $a_0 = \pi/2 \in (0,\pi)$ and $a_n = \sin(a_{n-1})$. Since $0 < a_0 < \p
i$, and $\sin$ maps $(0,\pi)$ into $(0,1]$, every $a_n > 0$. Also $\sin x < x$ f
or $x > 0$, so $(a_n)$ is strictly decreasing and bounded below by $0$, hence co
nverges to some $L \geq 0$ satisfying $L = \sin L$. The only solution is $L = 0$
. Thus

$$a_n \to 0, \qquad a_n \downarrow 0.$$

### Step 2. Refined asymptotics via $b_n = 1/a_n^2$

Using $\sin x = x - \tfrac{x^3}{6} + O(x^5)$ as $x \to 0$:

$$a_n = a_{n-1} - \frac{a_{n-1}^3}{6} + O(a_{n-1}^5) = a_{n-1}\!\left(1 - \frac{
a_{n-1}^2}{6} + O(a_{n-1}^4)\right).$$

Set $b_n := 1/a_n^2$. Then

$$b_n = \frac{1}{a_{n-1}^2}\left(1 - \frac{a_{n-1}^2}{6} + O(a_{n-1}^4)\right)^{
-2}.$$

Using $(1-u)^{-2} = 1 + 2u + O(u^2)$ with $u = a_{n-1}^2/6 + O(a_{n-1}^4)$:

$$b_n = b_{n-1}\left(1 + \frac{a_{n-1}^2}{3} + O(a_{n-1}^4)\right) = b_{n-1} + \
frac{1}{3} + O(a_{n-1}^2) = b_{n-1} + \frac{1}{3} + O\!\left(\frac{1}{b_{n-1}}\r
ight).$$

So for all sufficiently large $n$ there is a constant $C$ with

$$\left|b_n - b_{n-1} - \tfrac{1}{3}\right| \leq \frac{C}{b_{n-1}}. \tag{$\ast$}
$$

### Step 3. $b_n$ grows at least linearly (bootstrap)

Since $a_n \to 0$, for all large $n$ we have $b_{n-1}$ large enough that $C/b_{n
-1} \leq 1/6$. Then ($\ast$) gives $b_n - b_{n-1} \geq 1/3 - 1/6 = 1/6$. Hence f
or some $N$ and all $n \geq N$:

$$b_n \geq b_N + \frac{n-N}{6} \geq c\,n \qquad (c > 0). \tag{$\ast\ast$}$$

### Step 4. $b_n = \tfrac{n}{3} + O(\log n)$

Summing ($\ast$) from $N+1$ to $n$:

$$b_n = b_N + \frac{n-N}{3} + \sum_{k=N+1}^{n} \varepsilon_k, \qquad |\varepsilo
n_k| \leq \frac{C}{b_{k-1}}.$$

By ($\ast\ast$), $b_{k-1} \geq c(k-1)$, so

$$\sum_{k=N+1}^{n} |\varepsilon_k| \leq \sum_{k=N+1}^{n} \frac{C}{c(k-1)} = O(\l
og n).$$

Therefore

$$b_n = \frac{n}{3} + O(\log n).$$

### Step 5. Conclusion

From $b_n = n/3 + O(\log n)$ we obtain

$$\frac{b_n}{n} \to \frac{1}{3}, \qquad\text{i.e.,}\qquad n\,a_n^2 \to 3, \qquad
\text{i.e.,}\qquad a_n^2 \sim \frac{3}{n}.$$

By the limit comparison test with the divergent harmonic series $\sum \tfrac{1}{
n}$ (limit $= 3 > 0$),

$$\sum_{n=1}^{\infty} a_n^2 \;\text{diverges.}\qquad\blacksquare$$
