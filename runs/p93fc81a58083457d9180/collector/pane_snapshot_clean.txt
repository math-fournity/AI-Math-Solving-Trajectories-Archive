$$\mathcal{P}(B) = \left\{ Bx : x \in \mathbb{R}^n,\; 0 \le x_i < 1 \text{ for a

**Key observation.** Since $B$ is a basis, it is full-rank and hence invertible.

$$t \in \mathcal{P}(B) \iff \exists\, x \in [0,1)^n \text{ such that } Bx = t \i

The coordinate vector $c = B^{-1}t$ is **unique** (since $B$ is invertible), so
membership reduces to a single linear solve followed by $n$ range checks.

**Algorithm.**

1. **Solve** $Bc = t$ for $c \in \mathbb{R}^n$ using Gaussian elimination (or an

tions.
2. **Check** whether $0 \le c_i < 1$ for every $i = 1, \ldots, n$. This requires
 $O(n)$ comparisons.

Both steps run in polynomial time in $n$.

**Exactness with rational input.** In the standard computational model for latti

- $B^{-1}$ has rational entries (with denominators dividing $\det(B)$).
- $c = B^{-1}t$ has rational entries computable exactly via fraction arithmetic.
- Each comparison $0 \le c_i < 1$ is an exact comparison of rationals, decidable

No approximation or rounding is needed; the determination is exact.
