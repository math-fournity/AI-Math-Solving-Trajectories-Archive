## Proof

Let $I$ be the index set on which the ultrafilter $U$ lives, and let $M$ be an i
nfinite structure with universe also denoted $M$.

**Setup.** Since $U$ is principal, there exists an element $i_0 \in I$ such that
$$U = \{A \subseteq I : i_0 \in A\}.$$
That is, $U$ is the principal ultrafilter generated by $\{i_0\}$.

The ultrapower $M^{\langle U\rangle} = M^I / U$ is the set of equivalence classe
s of functions $f: I \to M$, where
$$f \sim g \iff \{i \in I : f(i) = g(i)\} \in U.$$

**Key observation.** Because $U$ is the principal ultrafilter at $i_0$,
$$\{i \in I : f(i) = g(i)\} \in U \iff i_0 \in \{i \in I : f(i) = g(i)\} \iff f(
i_0) = g(i_0).$$
So two functions are equivalent **if and only if** they agree at the single poin
t $i_0$.

**Constructing the bijection.** Define
$$\Phi: M^I / U \to M, \qquad \Phi([f]) = f(i_0).$$

- *Well-defined:* If $f \sim g$, then $f(i_0) = g(i_0)$, so $\Phi([f]) = \Phi([g
])$.
- *Injective:* If $\Phi([f]) = \Phi([g])$, then $f(i_0) = g(i_0)$, which means $
\{i : f(i)=g(i)\} \ni i_0$, hence this set is in $U$, so $f \sim g$ and $[f] = [
g]$.
- *Surjective:* For any $a \in M$, the constant function $c_a: I \to M$ with $c_
a(i) = a$ for all $i$ satisfies $\Phi([c_a]) = c_a(i_0) = a$.

Thus $\Phi$ is a bijection, and
$$\left|M^{\langle U\rangle}\right| = |M|.$$

**Conclusion.** When $U$ is a principal ultrafilter, the ultrapower $M^{\langle
U\rangle}$ is in bijection with — indeed isomorphic to — $M$ itself (the diagona
l embedding $a \mapsto [c_a]$ is surjective). Therefore the cardinality of $M^{\
langle U\rangle}$ equals the cardinality of $M$, which is infinite:

$$\boxed{\left|M^{\langle U\rangle}\right| = |M|}.$$
