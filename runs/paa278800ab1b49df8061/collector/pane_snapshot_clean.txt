**Direction 1: CH ⟹ such a family exists.**

**Direction 2: Such a family exists ⟹ CH.**

let $J_C = \{i \in I : A_i = C\}$. Suppose $|J_C| > \aleph_0$ for some $C \in D$

cap B = C \cap B = \emptyset$ for every $i \in J_C$, so $\{i : A_i \cap B = \emp
tyset\} \supseteq J_C$ is uncountable — contradicting the hypothesis. Therefore
$|J_C| \leq \aleph_0$ for all $C \in D$.

**Step 2: $|D| = \mathfrak{c}$.**

Since $I = \bigsqcup_{C \in D} J_C$ and $|J_C| \leq \aleph_0$:
$$\mathfrak{c} = |I| = \sum_{C \in D} |J_C| \leq |D| \cdot \aleph_0.$$
If $|D| \leq \aleph_0$, then $|D| \cdot \aleph_0 = \aleph_0 < \mathfrak{c}$, a c
ontradiction. So $|D|$ is uncountable, giving $|D| \cdot \aleph_0 = |D| \geq \ma

For any infinite $B$, the set $\{i : A_i \cap B = \emptyset\} = \bigsqcup_{C \in

For uncountable $D'$, each $C \in D'$ is countable, so $|\bigcup_{C \in D'} C| \

so $|D'| \geq \mathfrak{c}$. Since $|D'| \leq |D| = \mathfrak{c}$, we get $|D'|
