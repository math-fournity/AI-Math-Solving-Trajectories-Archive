## Proof

Let $T = T_{a,b} = \inf\{t > 0 : B_t \notin (a,b)\}$ with $a < 0 < b$ and $B_0 =
 0$.

**Step 1: Two key martingales.**

For standard Brownian motion, both $M_t = B_t$ and $N_t = B_t^2 - t$ are marting
ales with respect to the natural filtration.

**Step 2: Apply optional stopping to $B_t$.**

Since $T$ is a bounded stopping time when truncated ($T \wedge n$), the optional
 stopping theorem gives $\mathbf{E}[B_{T \wedge n}] = 0$. Letting $n \to \infty$
, using that $|B_{T \wedge n}| \leq \max(|a|,|b|)$ (bounded), dominated converge
nce yields

$$\mathbf{E}[B_T] = 0.$$

Since $B_T \in \{a, b\}$, write $p = \mathbf{P}(B_T = b)$ and $1-p = \mathbf{P}(
B_T = a)$. Then

$$pb + (1-p)a = 0 \implies p = \frac{-a}{b-a}, \qquad 1-p = \frac{b}{b-a}.$$

**Step 3: Apply optional stopping to $B_t^2 - t$.**

Again using $T \wedge n$:

$$\mathbf{E}[B_{T \wedge n}^2 - (T \wedge n)] = 0 \implies \mathbf{E}[T \wedge n
] = \mathbf{E}[B_{T \wedge n}^2].$$

The right side is bounded by $\max(a^2, b^2)$, so by monotone convergence $\math
bf{E}[T] < \infty$ and

$$\mathbf{E}[T] = \mathbf{E}[B_T^2].$$

(Justification: $\mathbf{E}[B_{T\wedge n}^2] \leq \max(a^2,b^2)$ uniformly, so $
\mathbf{E}[T\wedge n]$ is bounded; monotone convergence gives $\mathbf{E}[T] = \
lim_n \mathbf{E}[T\wedge n] = \lim_n \mathbf{E}[B_{T\wedge n}^2] = \mathbf{E}[B_
T^2]$, the last equality by dominated convergence since $B_{T\wedge n}^2 \leq \m
ax(a^2,b^2)$ and $B_{T\wedge n} \to B_T$ a.s.)

**Step 4: Compute $\mathbf{E}[B_T^2]$.**

$$\mathbf{E}[B_T^2] = p\, b^2 + (1-p)\, a^2 = \frac{-a}{b-a}\,b^2 + \frac{b}{b-a
}\,a^2 = \frac{-ab^2 + a^2 b}{b-a} = \frac{ab(a - b)}{b-a} = \frac{-ab(b-a)}{b-a
} = -ab.$$

**Conclusion.**

$$\boxed{\mathbf{E}[T_{a,b}] = -ab.}$$

Since $a < 0 < b$, we have $-ab > 0$, confirming the expectation is positive. As
 a sanity check: with $a = -b$, $\mathbf{E}[T] = b^2$, which matches the well-kn
own exit time from $(-b, b)$.
