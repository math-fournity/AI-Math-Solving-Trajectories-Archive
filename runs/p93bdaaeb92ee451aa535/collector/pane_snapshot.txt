## Proof

**Answer: Yes.** Every countable ordinal with the order topology is homeomorphic
 to a subspace of $\mathbb{R}$.

---

### Step 1: Every countable linear order order-embeds into $\mathbb{Q}$.

Let $(L, <)$ be a countable linear order, enumerated as $L = \{a_0, a_1, a_2, \d
ots\}$. We construct an order-embedding $f: L \to \mathbb{Q}$ inductively.

Suppose $f$ has been defined on $\{a_0, \dots, a_{n-1}\}$ and is order-preservin
g. To define $f(a_n)$, set:
$$L_n = \{f(a_i) : i < n,\ a_i < a_n\}, \qquad R_n = \{f(a_i) : i < n,\ a_i > a_
n\}.$$

Since $f$ is order-preserving on the already-defined elements, every member of $
L_n$ is strictly less than every member of $R_n$. Both sets are **finite**, so:
- If both are nonempty: $\max L_n < \min R_n$, and by density of $\mathbb{Q}$ we
 pick $f(a_n) \in \mathbb{Q}$ with $\max L_n < f(a_n) < \min R_n$.
- If $L_n = \emptyset$: pick $f(a_n) < \min R_n$ (possible since $\mathbb{Q}$ ha
s no left endpoint).
- If $R_n = \emptyset$: pick $f(a_n) > \max L_n$ (possible since $\mathbb{Q}$ ha
s no right endpoint).
- If both empty: pick any rational.

This produces an order-embedding $f: L \hookrightarrow \mathbb{Q} \subseteq \mat
hbb{R}$.

### Step 2: For any $A \subseteq \mathbb{R}$, the subspace topology equals the o
rder topology (restricted order).

**Order topology $\subseteq$ subspace topology:** The subbasic open sets of the
order topology on $A$ are $\{x \in A : x < a\} = A \cap (-\infty, a)$ and $\{x \
in A : x > a\} = A \cap (a, +\infty)$ for $a \in A$, both open in the subspace t
opology.

**Subspace topology $\subseteq$ order topology:** A subbasic open set of the sub
space topology is $A \cap (-\infty, r)$ for $r \in \mathbb{R}$.
- If $r \in A$: this is $\{x \in A : x < r\}$, subbasic open in the order topolo
gy. ✓
- If $r \notin A$: then $A \cap (-\infty, r) = \{x \in A : x < r\}$.
  - If $A \cap (r, +\infty) = \emptyset$, this is all of $A$ (open). ✓
  - If $r$ is a limit point of $A$ from below: $\{x \in A : x < r\} = \bigcup_{a
 \in A,\, a < r} \{x \in A : x < a\}$, a union of subbasic open sets. ✓
  - If $r$ is not a limit point from below: there is a maximum $m \in A$ with $m
 < r$ and $(m, r) \cap A = \emptyset$. Then $\{x \in A : x < r\} = \{x \in A : x
 \leq m\} = \{x \in A : x < m'\}$ where $m'$ is the least element of $A$ above $
m$ (or $= A$ if $m$ is the max of $A$), which is subbasic open. ✓

The case $A \cap (r, +\infty)$ is symmetric. Hence the two topologies coincide.

### Step 3: Order-isomorphisms are homeomorphisms of order topologies.

If $g: L \to M$ is an order-isomorphism (bijective and order-preserving), then $
g$ maps open intervals to open intervals and rays to rays, so $g$ is a homeomorp
hism when $L$ and $M$ carry their order topologies.

### Step 4: Conclusion.

Let $\alpha$ be a countable ordinal (a countable linear order). By **Step 1**, t
here exists an order-embedding $f: \alpha \hookrightarrow \mathbb{Q} \subseteq \
mathbb{R}$. Then $f$ is an order-isomorphism between $\alpha$ and $f(\alpha)$. B
y **Step 3**, $f$ is a homeomorphism between $\alpha$ (with the order topology)
and $f(\alpha)$ (with the order topology of the restricted order). By **Step 2**
, the order topology on $f(\alpha) \subseteq \mathbb{R}$ equals the subspace top
ology inherited from $\mathbb{R}$.

Therefore $f$ is a homeomorphism from $\alpha$ onto the subspace $f(\alpha)$ of
$\mathbb{R}$.
