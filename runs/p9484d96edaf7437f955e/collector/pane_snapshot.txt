## Proof

The Total Weight Index for container $a$ is $W(a) = 4a^2 + 3a + 5$. We need $6 \
mid W(a)$, i.e., $W(a) \equiv 0 \pmod 6$. Since $6 = 2 \cdot 3$, we require divi
sibility by both 2 and 3.

**Divisibility by 2.** Reduce mod 2:
$$W(a) = 4a^2 + 3a + 5 \equiv 0\cdot a^2 + 1\cdot a + 1 \equiv a + 1 \pmod 2.$$
So $W(a) \equiv 0 \pmod 2 \iff a$ is **odd**.

**Divisibility by 3.** Reduce mod 3:
$$W(a) = 4a^2 + 3a + 5 \equiv 1\cdot a^2 + 0\cdot a + 2 \equiv a^2 + 2 \pmod 3.$
$
So $W(a) \equiv 0 \pmod 3 \iff a^2 \equiv 1 \pmod 3 \iff a \not\equiv 0 \pmod 3$
 (since $a^2 \bmod 3$ is $0$ if $3\mid a$ and $1$ otherwise).

**Combining.** We need $a$ odd **and** $a \not\equiv 0 \pmod 3$. Modulo 6, the o
dd residues are $1, 3, 5$; excluding $3$ (the one divisible by 3) leaves:
$$a \equiv 1 \pmod 6 \quad\text{or}\quad a \equiv 5 \pmod 6.$$

**Counting in $\{1, 2, \ldots, 99\}$.**

- $a \equiv 1 \pmod 6$: $a = 1, 7, 13, \ldots, 97$. Count $= \dfrac{97-1}{6}+1 =
 17$.
- $a \equiv 5 \pmod 6$: $a = 5, 11, 17, \ldots, 95$. Count $= \dfrac{95-5}{6}+1
= 16$.

Total $= 17 + 16 = 33$.

**Verification by direct check of the residue classes mod 6.** For $a = 6k+1$: $
W = 4(6k+1)^2 + 3(6k+1) + 5 = 4(36k^2+12k+1) + 18k+3+5 = 144k^2+48k+4+18k+8 = 14
4k^2+66k+12 = 6(24k^2+11k+2)$. ✓ For $a = 6k+5$: $W = 4(6k+5)^2+3(6k+5)+5 = 4(36
k^2+60k+25)+18k+15+5 = 144k^2+240k+100+18k+20 = 144k^2+258k+120 = 6(24k^2+43k+20
)$. ✓ Both classes give multiples of 6, and the other four residue classes ($0,2
,3,4 \pmod 6$) fail at least one of the two conditions, confirming no over- or u
nder-counting.

The number of containers with a Total Weight Index divisible by $6$ is $\boxed{3
3}$.
