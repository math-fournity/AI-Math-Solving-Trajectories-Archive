### Method

For a two-form in $\mathbb{R}^3$ written in the standard orientation
$$\omega = P\,dy\wedge dz + Q\,dz\wedge dx + R\,dx\wedge dy,$$
the exterior derivative is the three-form
$$d\omega = \left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y}
+ \frac{\partial R}{\partial z}\right) dx\wedge dy\wedge dz.$$

### Identify $P, Q, R$

Rewrite $\beta$ in the standard basis. Since $dx\wedge dz = -dz\wedge dx$:

- Coefficient of $dy\wedge dz$: $P = -xy^2$.
- Coefficient of $dz\wedge dx$: from $-x^2 y\,dx\wedge dz = x^2 y\,dz\wedge dx$,
 so $Q = x^2 y$.
- Coefficient of $dx\wedge dy$: $R = z(y^2 - x^2)$.

### Compute the partial derivatives

$$\frac{\partial P}{\partial x} = \frac{\partial(-xy^2)}{\partial x} = -y^2,$$

$$\frac{\partial Q}{\partial y} = \frac{\partial(x^2 y)}{\partial y} = x^2,$$

$$\frac{\partial R}{\partial z} = \frac{\partial\bigl(z(y^2 - x^2)\bigr)}{\parti
al z} = y^2 - x^2.$$

### Sum

$$\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial
 R}{\partial z} = -y^2 + x^2 + (y^2 - x^2) = 0.$$

### Direct verification (term by term)

For completeness, compute $d\beta$ directly:

$$d\beta = d\bigl[z(y^2-x^2)\bigr]\wedge dx\wedge dy \;+\; d[-x^2 y]\wedge dx\we
dge dz \;+\; d[-xy^2]\wedge dy\wedge dz.$$

**First term:**
$$d[z(y^2-x^2)] = (y^2-x^2)\,dz + 2yz\,dy - 2xz\,dx.$$
Wedge with $dx\wedge dy$: only the $dz$ component survives, giving
$$(y^2-x^2)\,dz\wedge dx\wedge dy = (y^2-x^2)\,dx\wedge dy\wedge dz.$$

**Second term:**
$$d[-x^2 y] = -2xy\,dx - x^2\,dy.$$
Wedge with $dx\wedge dz$: only the $dy$ component survives,
$$-x^2\,dy\wedge dx\wedge dz = x^2\,dx\wedge dy\wedge dz.$$

**Third term:**
$$d[-xy^2] = -y^2\,dx - 2xy\,dy.$$
Wedge with $dy\wedge dz$: only the $dx$ component survives,
$$-y^2\,dx\wedge dy\wedge dz.$$

**Total:**
$$(y^2 - x^2) + x^2 + (-y^2) = 0.$$

Both methods agree.

### Conclusion

$$\boxed{\,d\beta = 0\,}$$

The two-form $\beta$ is **closed**. (In fact, since $H^2_{\mathrm{dR}}(\mathbb{R
}^3)=0$, it is also exact: $\beta = d\alpha$ for some one-form $\alpha$.)
