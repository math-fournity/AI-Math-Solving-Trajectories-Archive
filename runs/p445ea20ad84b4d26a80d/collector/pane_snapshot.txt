Looking at this problem, I need to determine whether every discrete absolute val

**Definitions.** An absolute value $|\cdot|: K \to \mathbb{R}_{\geq 0}$ is **dis
crete** if its value group $|K^\times|$ is a discrete subgroup of $\mathbb{R}_{>
0}$. It is **non-archimedean** if $|x+y| \leq \max(|x|,|y|)$ for all $x,y \in K$
.

**Key criterion.** An absolute value is non-archimedean if and only if $\{|n \cd
ot 1_K| : n \in \mathbb{N}\}$ is bounded (equivalently, $|n \cdot 1_K| \leq 1$ f
or all $n$). The forward direction is immediate from the ultrametric inequality;
 the reverse follows from the binomial expansion $|x+y|^n \leq (n+1)\max(|x|,|y|
)^n$ and taking $n$-th roots as $n \to \infty$.

**Theorem.** Every discrete absolute value on a field is non-archimedean.

**Proof.** Let $K$ be a field with a discrete absolute value $|\cdot|$.

**Case 1: $\operatorname{char}(K) = p > 0$.**

Here *every* absolute value is non-archimedean, regardless of discreteness. The
prime field is $\mathbb{F}_p$, so $n \cdot 1_K = (n \bmod p) \cdot 1_K$ for all
$n \in \mathbb{N}$. The set $\{|n \cdot 1_K| : n \in \mathbb{N}\}$ equals $\{|0|
, |1_K|, |2\cdot 1_K|, \dots, |(p{-}1)\cdot 1_K|\}$, which is finite and hence b
ounded. By the criterion above, $|\cdot|$ is non-archimedean.

**Case 2: $\operatorname{char}(K) = 0$.**

The prime field is $\mathbb{Q} \subseteq K$. Suppose for contradiction that $|\c
dot|$ is archimedean. Then there exists $n_0 \in \mathbb{N}$ with $|n_0 \cdot 1_
K| > 1$. Since $n_0 \cdot 1_K$ lies in the prime field $\mathbb{Q}$, the restric
tion of $|\cdot|$ to $\mathbb{Q}$ is an archimedean absolute value on $\mathbb{Q
}$.

By **Ostrowski's theorem**, every archimedean absolute value on $\mathbb{Q}$ has
 the form $|q| = |q|_\infty^s$ for some $s > 0$, where $|\cdot|_\infty$ is the u
sual real absolute value. Therefore:

$$|\mathbb{Q}^\times| = \{|q|_\infty^s : q \in \mathbb{Q}^\times\} = \{r^s : r \
in \mathbb{Q}_{>0}\}.$$

Since $\mathbb{Q}_{>0}$ is dense in $\mathbb{R}_{>0}$ and $x \mapsto x^s$ is a h
omeomorphism of $\mathbb{R}_{>0}$, the set $|\mathbb{Q}^\times|$ is **dense** in
 $\mathbb{R}_{>0}$.

On the other hand, $|\mathbb{Q}^\times| \subseteq |K^\times|$, and $|K^\times|$
is a discrete subgroup of $\mathbb{R}_{>0}$. Such a subgroup is either $\{1\}$ o
r $c^{\mathbb{Z}}$ for some $c \in (0,1)$. In either case it has **no accumulati
on points** in $\mathbb{R}_{>0}$: for example, if $|K^\times| = c^{\mathbb{Z}}$,
 the open interval $(c, 1)$ contains no element of $|K^\times|$.

This is a contradiction: a dense subset of $\mathbb{R}_{>0}$ must intersect ever
y non-empty open interval, yet $|\mathbb{Q}^\times| \subseteq |K^\times|$ and $|
K^\times|$ misses entire open intervals. Therefore $|\cdot|$ cannot be archimede
an, so it is non-archimedean. $\blacksquare$

mathbb{Q}^\times|$ to be dense (by Ostrowski's theorem), which is incompatible w
