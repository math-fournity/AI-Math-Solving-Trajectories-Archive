## Proof

Let $Y_t = X_t - X^\varepsilon_t$. Subtracting the two SDEs and using the identi
cal initial condition,

$$Y_t = \int_0^t \bigl[\mu(s,X_s)-\mu(s,X^\varepsilon_s)\bigr]\,ds + \int_0^t g_
s\,dW_s, \qquad g_s := \sigma(s,X_s)-\sigma_\varepsilon(s,X^\varepsilon_s).$$

**Step 1: Pathwise bound on the quadratic variation of the martingale part.**

By hypothesis, for each $\varepsilon>0$ there exists a (random) measurable set $
A_\varepsilon(\omega)\subset[0,T]$ with Lebesgue measure $|A_\varepsilon|=T-\var
epsilon$ on which $\sigma(s,X_s)=\sigma_\varepsilon(s,X^\varepsilon_s)$, i.e. $g
_s=0$. On the complement $A_\varepsilon^c$, which has measure $\varepsilon$, the
 uniform boundedness of $\sigma,\sigma_\varepsilon$ gives $|g_s|\le 2M$ (with $M
$ the common bound). Hence, *pathwise*,

$$\int_0^T g_s^2\,ds = \int_{A_\varepsilon^c} g_s^2\,ds \le 4M^2\,|A_\varepsilon
^c| = 4M^2\varepsilon. \tag{1}$$

This is a deterministic bound, valid for every $\omega$.

**Step 2: $L^2$ control of the stochastic integral via BDG.**

Let $N := \sup_{t\in[0,T]}\bigl|\int_0^t g_s\,dW_s\bigr|$. By the Burkholder–Dav
is–Gundy inequality, there exists a universal constant $C$ with

$$\mathbb{E}[N^2] \le C\,\mathbb{E}\!\left[\int_0^T g_s^2\,ds\right] \le C\cdot
4M^2\varepsilon \xrightarrow[\varepsilon\to 0]{} 0. \tag{2}$$

**Step 3: Gronwall argument.**

Let $L$ be the uniform Lipschitz constant of $\mu$. By the Lipschitz property,

$$|Y_t| \le L\int_0^t |Y_s|\,ds + \left|\int_0^t g_s\,dW_s\right| \le L\int_0^t
|Y_s|\,ds + N.$$

Set $M_t := \sup_{s\in[0,t]}|Y_s|$. Then $M_t \le L\int_0^t M_s\,ds + N$, and Gr
onwall's inequality yields

$$M_T = \sup_{t\in[0,T]}|Y_t| \le N\,e^{LT}. \tag{3}$$

**Step 4: Convergence in probability.**

From (2) and (3),

$$\mathbb{E}\!\left[\sup_{t\in[0,T]}|X_t-X^\varepsilon_t|^2\right] = \mathbb{E}[
M_T^2] \le e^{2LT}\,\mathbb{E}[N^2] \le e^{2LT}\,C\,4M^2\,\varepsilon \xrightarr
ow[\varepsilon\to 0]{} 0.$$

In particular $X^\varepsilon\to X$ in $L^2$ uniformly on $[0,T]$, which is stron
ger than convergence in probability. By Markov's inequality, for any $\delta>0$,

$$\mathbb{P}\!\left(\sup_{t\in[0,T]}|X_t-X^\varepsilon_t|>\delta\right) \le \fra
c{e^{2LT}\,C\,4M^2\,\varepsilon}{\delta^2} \xrightarrow[\varepsilon\to 0]{} 0.$$

**Conclusion.** Yes, $X^\varepsilon$ converges to $X$ uniformly in $t$ on $[0,T]
$ in probability (indeed, in $L^2$). The key mechanism is that the diffusion coe
fficients agree on a set of full measure asymptotically, so the martingale part
of the difference has quadratic variation $O(\varepsilon)$ pathwise, while the d
rift difference is controlled by the shared Lipschitz constant via Gronwall.
