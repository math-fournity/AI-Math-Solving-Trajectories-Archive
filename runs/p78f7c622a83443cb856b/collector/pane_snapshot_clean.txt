### Method of Characteristics

The PDE is
$$x\,u_x - y\,u_y = 2x^2 - 6y^2, \qquad u(1,y)=3y^2+2y-5.$$

The characteristic ODEs are
$$\frac{dx}{ds}=x,\qquad \frac{dy}{ds}=-y,\qquad \frac{du}{ds}=2x^2-6y^2.$$

**Step 1 — First integrals of the characteristic system.**

From $\dot x = x$ and $\dot y = -y$:
$$x = x_0\,e^{s},\qquad y = y_0\,e^{-s}.$$
Hence the invariant
$$c := xy = x_0 y_0$$
is constant along each characteristic curve.

**Step 2 — Integrate the equation for $u$.**

Using $x^2 = x_0^2 e^{2s}$ and $y^2 = y_0^2 e^{-2s}$,
$$\frac{du}{ds} = 2x_0^2 e^{2s} - 6y_0^2 e^{-2s}.$$
Integrating in $s$:
$$u = x_0^2 e^{2s} + 3y_0^2 e^{-2s} + F(c),$$
where $F$ is an arbitrary function of the invariant $c=xy$. Recognizing $x_0^2 e
^{2s}=x^2$ and $y_0^2 e^{-2s}=y^2$, the general solution is
$$\boxed{u(x,y) = x^2 + 3y^2 + F(xy).}$$

**Step 3 — Determine $F$ from the boundary condition.**

Setting $x=1$:
$$u(1,y) = 1 + 3y^2 + F(y) = 3y^2 + 2y - 5.$$
Therefore
$$F(y) = 2y - 6.$$
Being a function of a single variable, $F(t) = 2t - 6$, so $F(xy) = 2xy - 6$.

**Step 4 — Final solution.**
$$\boxed{u(x,y) = x^2 + 3y^2 + 2xy - 6.}$$

**Verification.**
- PDE: $u_x = 2x+2y$, $u_y = 6y+2x$. Then
$$x u_x - y u_y = x(2x+2y) - y(6y+2x) = 2x^2 + 2xy - 6y^2 - 2xy = 2x^2 - 6y^2.\
\checkmark$$
- Boundary: $u(1,y) = 1 + 3y^2 + 2y - 6 = 3y^2 + 2y - 5.\ \checkmark$

Both the PDE and the boundary condition are satisfied, so the solution is correc
t.
