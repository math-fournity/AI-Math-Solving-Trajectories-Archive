## Proof

Let $A \subseteq S = \{1, 2, \dots, 10^6\}$ with $|A| = 101$.

**Difference set.** Define the set of positive differences
$$
D^{+} = \{a' - a : a, a' \in A,\; a' > a\}.
$$
Since there are $\binom{101}{2} = 5050$ ordered pairs $(a, a')$ with $a' > a$, w
e have
$$
|D^{+}| \le 5050. \tag{1}
$$

**Disjointness criterion.** For shifts $t_i, t_j \in S$, the translates $A + t_i
$ and $A + t_j$ are disjoint iff there is no pair $x, y \in A$ with $x + t_i = y
 + t_j$, i.e. iff
$$
t_j - t_i \notin \{y - x : x, y \in A\}.
$$
If we choose $t_1 < t_2 < \dots < t_{100}$, then every difference $t_j - t_i$ (w
ith $i < j$) is positive, so the disjointness of all pairs is equivalent to
$$
t_j - t_i \notin D^{+} \qquad \text{for all } 1 \le i < j \le 100. \tag{2}
$$

**Greedy construction.** We build the sequence $t_1 < t_2 < \dots$ from $S$ iter
atively. Maintain a set of *available* elements, initially all of $S$.

- Pick the smallest available element as $t_k$.
- Delete from the available set every element of the form $t_k + d$ with $d \in
D^{+}$ (only those still in $S$ matter).

Because every $d \in D^{+}$ is positive, the deleted elements are all strictly l
arger than $t_k$, so they are all still "in the future"; in particular the eleme
nt $t_k$ itself is not re-deleted, and no already-picked element is affected.

**Why (2) holds.** When $t_j$ is picked (with $j > i$), the element $t_j$ was *n
ot* deleted at the step when $t_i$ was picked, which means $t_j \neq t_i + d$ fo
r every $d \in D^{+}$, i.e. $t_j - t_i \notin D^{+}$. Since this is true for eve
ry previously picked $t_i$, condition (2) is satisfied for all pairs.

**How many elements we can pick.** At each step we consume the picked element pl
us at most $|D^{+}|$ deleted elements, so at most $|D^{+}| + 1 \le 5051$ element
s of $S$ are consumed per step. If the greedy process stops after $m$ steps, the
n all $10^6$ elements of $S$ have been consumed, hence
$$
10^6 \le m \cdot 5051 \implies m \ge \frac{10^6}{5051} > 197.
$$
Thus $m \ge 198$. In particular we can pick at least $100$ elements $t_1 < t_2 <
 \dots < t_{100}$ from $S$ satisfying (2).

By the disjointness criterion, the $100$ sets
$$
A_j = \{x + t_j : x \in A\}, \qquad j = 1, 2, \dots, 100,
$$
are pairwise disjoint. $\blacksquare$
