**Step 1: Eigenfunction expansion.**

The homogeneous problem $u_t - a^2 u_{xx} = 0$ with $u(0,t)=u(L,t)=0$ has eigenf
unctions
$$\phi_n(x) = \sin\frac{n\pi x}{L}, \qquad \lambda_n = \left(\frac{n\pi}{L}\righ
t)^2, \qquad n=1,2,\dots$$
which form a complete orthogonal set on $(0,L)$ with $\int_0^L \sin^2\frac{n\pi
x}{L}dx = \frac{L}{2}$.

We seek
$$u(x,t) = \sum_{n=1}^{\infty} T_n(t)\,\sin\frac{n\pi x}{L}.$$

**Step 2: Expand the source term.**

Write $f(x) = J - P\delta(x-b) = \sum_{n=1}^{\infty} f_n \sin\frac{n\pi x}{L}$,
where
$$f_n = \frac{2}{L}\int_0^L \bigl[J - P\delta(x-b)\bigr]\sin\frac{n\pi x}{L}\,dx
.$$

For the constant $J$:
$$\frac{2}{L}\int_0^L J\sin\frac{n\pi x}{L}\,dx = \frac{2J}{L}\cdot\frac{L}{n\pi
}\bigl(1-\cos n\pi\bigr) = \frac{2J}{n\pi}\bigl(1-(-1)^n\bigr).$$

For the delta term, using the sifting property:
$$\frac{2}{L}\int_0^L P\delta(x-b)\sin\frac{n\pi x}{L}\,dx = \frac{2P}{L}\sin\fr
ac{n\pi b}{L}.$$

Therefore
$$f_n = \frac{2J}{n\pi}\bigl(1-(-1)^n\bigr) - \frac{2P}{L}\sin\frac{n\pi b}{L}.$
$

Note $f_n = \frac{4J}{n\pi} - \frac{2P}{L}\sin\frac{n\pi b}{L}$ for odd $n$, and
 $f_n = -\frac{2P}{L}\sin\frac{n\pi b}{L}$ for even $n$.

**Step 3: ODEs for the temporal coefficients.**

Substituting the expansion into the PDE and matching Fourier-sine coefficients:
$$T_n'(t) + a^2\lambda_n\, T_n(t) = f_n, \qquad T_n(0) = 0,$$
where $a^2\lambda_n = a^2\!\left(\frac{n\pi}{L}\right)^2$. Denote $\omega_n = \f
rac{an\pi}{L}$, so $a^2\lambda_n = \omega_n^2$.

This is a first-order linear ODE with constant forcing. With the initial conditi
on $T_n(0)=0$:
$$T_n(t) = \frac{f_n}{\omega_n^2}\bigl(1 - e^{-\omega_n^2 t}\bigr).$$

**Step 4: Assemble the solution.**

$$\boxed{\;u(x,t) = \sum_{n=1}^{\infty} \frac{1}{\omega_n^2}\left[\frac{2J}{n\pi
}\bigl(1-(-1)^n\bigr) - \frac{2P}{L}\sin\frac{n\pi b}{L}\right]\left(1 - e^{-\om
ega_n^2 t}\right)\sin\frac{n\pi x}{L}\;}$$
with $\omega_n = \dfrac{an\pi}{L}$.

**Step 5: Verification.**

*Initial condition.* At $t=0$, each factor $(1-e^{-\omega_n^2\cdot 0})=0$, so $u
(x,0)=0$. ✓

*Boundary conditions.* Each $\sin\frac{n\pi x}{L}$ vanishes at $x=0$ and $x=L$,
so $u(0,t)=u(L,t)=0$. ✓

*PDE.* Term-by-term differentiation (justified since $f_n = O(1/n)$ and the fact
or $1/\omega_n^2 = O(1/n^2)$ gives absolute and uniform convergence of the serie

$$u_t = \sum_n f_n e^{-\omega_n^2 t}\sin\frac{n\pi x}{L}, \qquad -a^2 u_{xx} = \
sum_n \omega_n^2\cdot\frac{f_n}{\omega_n^2}(1-e^{-\omega_n^2 t})\sin\frac{n\pi x
}{L} = \sum_n f_n(1-e^{-\omega_n^2 t})\sin\frac{n\pi x}{L}.$$
Adding: $u_t - a^2 u_{xx} = \sum_n f_n\sin\frac{n\pi x}{L} = J - P\delta(x-b)$.
✓

*Steady-state consistency check.* As $t\to\infty$, $u\to u_\infty(x) = \sum_n \f
