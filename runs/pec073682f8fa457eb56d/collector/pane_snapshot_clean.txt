## Setup

Let $f(n)$ = minimum worst-case total payment when $m \in \{1, \ldots, n\}$.

When Arnold guesses $k$ ($1 \le k \le n$):
- If $m \ge k$: game ends. Worst case $m = n$, cost $= 1 + (n-k)$.
- If $m < k$: pays $1 + 10 = 11$, continues with $\{1, \ldots, k-1\}$, cost $= 1
1 + f(k-1)$.

Setting $j = k-1$, the recurrence is:
$$f(n) = \min_{0 \le j \le n-1} \max\bigl(n - j,\; 11 + f(j)\bigr)$$
where $j=0$ gives cost $n$ (only the first branch applies, since no $m < 1$).

## Key Claim

Define $T_k = \frac{11k(k+1)}{2}$ for $k \ge 1$, $T_0 = 0$. Then **$f(T_k) = 11k
$** for all $k \ge 1$.

**Proof by induction.**

**Base case ($k=1$):** $T_1 = 11$. For $n \le 11$, guessing $k=1$ gives cost $n$
, and any $k \ge 2$ gives $\max(n-k+1,\; 11+f(k-1)) \ge 11$. So $f(n) = n$ for $
n \le 11$, hence $f(11) = 11$. ✓

**Inductive step.** Assume $f(T_m) = 11m$ for all $m < k$. Note $f$ is non-decre
asing (a larger set of possibilities cannot reduce worst-case cost).

*Upper bound:* Guess $k^* = T_{k-1}+1$ (so $j = T_{k-1}$).
- If $m \ge T_{k-1}+1$: worst case $m = T_k$, cost $= 1 + T_k - (T_{k-1}+1) = T_
k - T_{k-1} = 11k$.
- If $m \le T_{k-1}$: cost $= 11 + f(T_{k-1}) = 11 + 11(k-1) = 11k$.

Both cases give $11k$, so $f(T_k) \le 11k$.

*Lower bound:* For any guess with parameter $j$:
- $j = 0$: cost $= T_k \ge 11k$. ✓
- $j < T_{k-1}$: cost $\ge T_k - j > T_k - T_{k-1} = 11k$. ✓
- $j \ge T_{k-1}$: by monotonicity, $f(j) \ge f(T_{k-1}) = 11(k-1)$, so cost $\g
e 11 + f(j) \ge 11k$. ✓

In all cases cost $\ge 11k$, so $f(T_k) \ge 11k$.

Therefore $f(T_k) = 11k$. $\square$
