## Solution

**Setup.** Place $B$ at the origin and $A = (2, 0)$, so $AB = 2$ along the $x$-a
xis. Since $\angle ABC = 60°$, point $C$ lies at angle $60°$ from $BA$:

$$C = \left(\tfrac{c}{2},\; \tfrac{c\sqrt{3}}{2}\right), \quad \text{where } c =
 BC.$$

**Finding $D$ from the two right-angle constraints.**

*At $A$:* $\angle BAD = 90°$ means $AD \perp AB$, so $D$ lies on the vertical li
ne through $A$: $D = (2,\, d)$ for some $d > 0$.

*At $C$:* $\angle BCD = 90°$ means $CD \perp CB$. The direction $CB$ from $C$ is
 $(-\tfrac{1}{2}, -\tfrac{\sqrt{3}}{2})$, so the perpendicular direction is $(\t
frac{\sqrt{3}}{2}, -\tfrac{1}{2})$. Since $CD = 1$:

$$D = C + \left(\tfrac{\sqrt{3}}{2},\, -\tfrac{1}{2}\right) = \left(\tfrac{c}{2}
+\tfrac{\sqrt{3}}{2},\; \tfrac{c\sqrt{3}}{2}-\tfrac{1}{2}\right).$$

**Matching the two expressions for $D$.** Setting the $x$-coordinates equal:

$$\tfrac{c}{2} + \tfrac{\sqrt{3}}{2} = 2 \implies c = 4 - \sqrt{3}.$$

Then the $y$-coordinate gives:

$$d = \tfrac{(4-\sqrt{3})\sqrt{3}}{2} - \tfrac{1}{2} = \tfrac{4\sqrt{3}-3-1}{2}
= 2\sqrt{3} - 2.$$

So: $A=(2,0)$, $B=(0,0)$, $C=\!\left(\tfrac{4-\sqrt{3}}{2},\,\tfrac{4\sqrt{3}-3}
{2}\right)$, $D=(2,\,2\sqrt{3}-2)$.

**Finding the intersection $O$ of diagonals $AC$ and $BD$.**

Parametrize: $BD: (2t,\,(2\sqrt{3}-2)t)$ and $AC: \left(2 - \tfrac{\sqrt{3}}{2}s
,\; \tfrac{4\sqrt{3}-3}{2}s\right)$.

Equating coordinates and solving:

$$t = \frac{4-\sqrt{3}}{3}, \qquad s = \frac{4(3-\sqrt{3})}{9}.$$

$$O = \left(\frac{2(4-\sqrt{3})}{3},\; \frac{10\sqrt{3}-14}{3}\right).$$

**Computing $\sin\angle AOB$.** With $\vec{OA} = A - O$ and $\vec{OB} = B - O$:

$$\vec{OA} = \left(\frac{2\sqrt{3}-2}{3},\; \frac{14-10\sqrt{3}}{3}\right), \qua
d \vec{OB} = \left(\frac{2\sqrt{3}-8}{3},\; \frac{14-10\sqrt{3}}{3}\right).$$

**Cross product (numerator of sine):**

$$|\vec{OA}\times\vec{OB}| = \frac{(14-10\sqrt{3})}{9}\cdot\left|(2\sqrt{3}-2)-(
2\sqrt{3}-8)\right| = \frac{6(10\sqrt{3}-14)}{9} = \frac{2(10\sqrt{3}-14)}{3}.$$

**Magnitudes (denominator):**

$$|\vec{OA}|^2 = \frac{(2\sqrt{3}-2)^2+(14-10\sqrt{3})^2}{9} = \frac{512-288\sqr
t{3}}{9},$$

$$|\vec{OB}|^2 = \frac{(2\sqrt{3}-8)^2+(14-10\sqrt{3})^2}{9} = \frac{572-312\sqr
t{3}}{9}.$$

**Assembling $\sin^2\angle AOB$:**

$$\sin^2\angle AOB = \frac{4(10\sqrt{3}-14)^2/9}{(512-288\sqrt{3})(572-312\sqrt{
3})/81} = \frac{36(496-280\sqrt{3})}{562432-324480\sqrt{3}}.$$

Factoring: numerator $= 288(62-35\sqrt{3})$; denominator $= 21632(26-15\sqrt{3})
$, so

$$\sin^2\angle AOB = \frac{9(62-35\sqrt{3})}{676(26-15\sqrt{3})}.$$

**Rationalizing** using $(26-15\sqrt{3})(26+15\sqrt{3}) = 676 - 675 = 1$:

$$\sin^2\angle AOB = \frac{9(62-35\sqrt{3})(26+15\sqrt{3})}{676} = \frac{9(37+20
\sqrt{3})}{676}.$$

**Simplifying the radical:** $37 + 20\sqrt{3} = (5+2\sqrt{3})^2$ (since $25+12+2
0\sqrt{3} = 37+20\sqrt{3}$). Therefore:

$$\sin\angle AOB = \frac{3(5+2\sqrt{3})}{26} = \frac{15+6\sqrt{3}}{26}.$$

**Verification (numerical):** $\frac{15+6\sqrt{3}}{26} \approx \frac{25.392}{26}
 \approx 0.9766$, which matches the direct coordinate computation $\approx 0.976
6$. All geometric constraints ($\angle ABC=60°$, $\angle BAD=90°$, $\angle BCD=9
0°$, $AB=2$, $CD=1$) are confirmed satisfied.

$$\boxed{\sin\angle AOB = \dfrac{15+6\sqrt{3}}{26}}$$
