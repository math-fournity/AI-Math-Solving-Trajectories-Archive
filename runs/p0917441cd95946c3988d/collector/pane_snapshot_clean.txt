**Proof.**

Assume $f^3 \in \mathcal{R}(\alpha)$ on $[a,b]$, where $\alpha$ is monotonically
 increasing. Since every Riemann-Stieltjes integrable function is bounded, $f^3$
 is bounded: there exists $B > 0$ with $|f(x)^3| \leq B$ for all $x \in [a,b]$,
hence $|f(x)| \leq B^{1/3}$. Set $K = B^{1/3}$, so $|f| \leq K$.

**Key observation.** The map $\varphi(t) = t^3$ is strictly increasing and conti
nuous on $\mathbb{R}$, with continuous inverse $\varphi^{-1}(t) = t^{1/3}$. Cons
equently, for any partition subinterval $I = [x_{i-1}, x_i]$:

$$\sup_{x \in I} f(x)^3 = \left(\sup_{x \in I} f(x)\right)^3, \qquad \inf_{x \in
 I} f(x)^3 = \left(\inf_{x \in I} f(x)\right)^3.$$

Denote $M_i = \sup_{I_i} f$, $m_i = \inf_{I_i} f$. Then the oscillation of $f^3$
 on $I_i$ is:

$$M_i^3 - m_i^3 = (M_i - m_i)(M_i^2 + M_i\, m_i + m_i^2).$$

**A useful lower bound.** We claim:

$$M_i^2 + M_i\, m_i + m_i^2 \;\geq\; \tfrac{1}{2}\bigl(M_i^2 + m_i^2\bigr) \;\ge
q\; \tfrac{1}{2}\max(M_i^2,\, m_i^2).$$

Indeed, $M_i^2 + M_i m_i + m_i^2 - \frac{1}{2}(M_i^2 + m_i^2) = \frac{1}{2}(M_i
+ m_i)^2 \geq 0$, proving the first inequality; the second is immediate.

**Splitting the sum.** Let $P = \{a = x_0 < x_1 < \cdots < x_n = b\}$ be a parti
tion and $\Delta\alpha_i = \alpha(x_i) - \alpha(x_{i-1}) \geq 0$. Fix $\delta >

- $S = \{i : \max(|M_i|, |m_i|) \geq \delta\}$ (subintervals where $f$ is "not s
mall"),

so $M_i - m_i \leq 2\delta$. Thus:

$$\sum_{i \in T} (M_i - m_i)\,\Delta\alpha_i \;\leq\; 2\delta \sum_{i \in T} \De
lta\alpha_i \;\leq\; 2\delta\bigl(\alpha(b) - \alpha(a)\bigr).$$

**Estimate on $S$:** For $i \in S$, the lower bound gives $M_i^2 + M_i m_i + m_i
^2 \geq \frac{\delta^2}{2}$, so:

$$M_i - m_i \;\leq\; \frac{M_i^3 - m_i^3}{\delta^2/2} = \frac{2\,(M_i^3 - m_i^3)
}{\delta^2}.$$

Therefore:

$$\sum_{i \in S} (M_i - m_i)\,\Delta\alpha_i \;\leq\; \frac{2}{\delta^2}\sum_{i
\in S}(M_i^3 - m_i^3)\,\Delta\alpha_i \;\leq\; \frac{2}{\delta^2}\bigl(U(P, f^3,
 \alpha) - L(P, f^3, \alpha)\bigr).$$

$$U(P, f, \alpha) - L(P, f, \alpha) \;=\; \sum_{i=1}^{n}(M_i - m_i)\,\Delta\alph

 + 2\delta\bigl(\alpha(b)-\alpha(a)\bigr).$$

1. Choose $\delta > 0$ so small that $2\delta\,(\alpha(b) - \alpha(a)) < \vareps
