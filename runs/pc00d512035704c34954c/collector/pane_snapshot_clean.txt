## Theorem: $S_3$ is anti-homogeneous

**Statement:** The symmetric group $S_3 = \text{Equiv.Perm}(\text{Fin}\ 3)$ sati
sfies `HasDistinctConjClassSizes`, i.e., the map assigning to each conjugacy cla
ss its cardinality is injective.

---

### Proof

**Step 1: Reduce `conjClassCard` to finset cardinality.**

For a finite group $G$, each conjugacy class $c$ is a finite set, so `conjClassC
ard c` equals the cardinality of $c.\text{carrier}$ as a finset:

$$\text{conjClassCard}(c) = |c.\text{carrier}|.$$

This is exactly what the partial proof establishes via `Nat.card_eq_fintype_card
`. Hence `HasDistinctConjClassSizes G` is equivalent to: the map $c \mapsto |c.\
text{carrier}|$ is injective on $\text{ConjClasses}(G)$.

**Step 2: Conjugacy in $S_n$ is determined by cycle type.**

**Lemma.** In $S_n$, two permutations $\sigma, \tau$ are conjugate if and only i
f they have the same cycle type (i.e., the same multiset of cycle lengths in the
ir disjoint cycle decomposition).

*Proof of lemma.* If $\sigma = \rho \tau \rho^{-1}$, then conjugation by $\rho$
sends a cycle $(a_1\ a_2\ \cdots\ a_k)$ to $(\rho(a_1)\ \rho(a_2)\ \cdots\ \rho(
a_k))$, preserving cycle structure. Conversely, if $\sigma$ and $\tau$ have the
same cycle type, write their disjoint cycle decompositions with cycles listed in
 order of matching lengths; define $\rho$ to map the entries of $\sigma$'s cycle
s to the corresponding entries of $\tau$'s cycles. Then $\rho \sigma \rho^{-1} =
 \tau$. $\square$

**Step 3: Enumerate the conjugacy classes of $S_3$.**

$S_3$ has $3! = 6$ elements. The partitions of $3$ give the cycle types:

| Cycle type | Description | Elements | Class size |
|---|---|---|---|
| $(1,1,1)$ | identity | $\{e\}$ | $1$ |
| $(2,1)$ | transpositions | $\{(1\;2),\, (1\;3),\, (2\;3)\}$ | $\binom{3}{2} =
3$ |
| $(3)$ | 3-cycles | $\{(1\;2\;3),\, (1\;3\;2)\}$ | $\frac{3!}{3} = 2$ |

**Verification of class sizes:**
- **Identity:** The identity $e$ commutes with everything, so its conjugacy clas
s is $\{e\}$, size $1$.
- **Transpositions:** There are $\binom{3}{2} = 3$ transpositions. By the lemma,
 they form a single conjugacy class of size $3$.
- **3-cycles:** There are $\frac{3!}{3} = 2$ three-cycles. By the lemma, they fo
rm a single conjugacy class of size $2$.

**Consistency check:** $1 + 3 + 2 = 6 = |S_3|$. ✓

**Step 4: The class sizes are pairwise distinct.**

The three conjugacy class sizes are $\{1, 2, 3\}$:
- $1 \neq 2$ ✓
- $1 \neq 3$ ✓
- $2 \neq 3$ ✓

**Step 5: Injectivity.**

The map $\varphi : \text{ConjClasses}(S_3) \to \mathbb{N}$ defined by $\varphi(c
) = |c.\text{carrier}|$ takes values:
$$\varphi(\{e\}) = 1, \qquad \varphi(\{(1\;2),(1\;3),(2\;3)\}) = 3, \qquad \varp
hi(\{(1\;2\;3),(1\;3\;2)\}) = 2.$$

Since $S_3$ has exactly $3$ conjugacy classes (one per cycle type, by Step 2) an
d these map to $3$ distinct values, $\varphi$ is injective.

Therefore `HasDistinctConjClassSizes (Equiv.Perm (Fin 3))` holds. $\blacksquare$
