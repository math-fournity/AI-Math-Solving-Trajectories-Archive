# 解：具有罗宾边界条件的热传导方程

## 泄露检查

问题文本仅包含 PDE、边界条件和初始条件。未嵌入任何解决方案、草图或答案。继续。

## 第 1 步：稳态解

当 $t \to \infty$ 时，设 $u(x,t) \to v(x)$。此时 $v''(x) = 0$，因此 $v(x) = Ax +
 B$。

- $v(0) = 0 \Rightarrow B = 0$。
- $v'(1) = -h(v(1) - u_0) \Rightarrow A = -h(A - u_0) \Rightarrow A(1+h) = hu_0
\Rightarrow A = \dfrac{hu_0}{1+h}$。

因此

$$v(x) = \frac{hu_0}{1+h}\,x.$$

## 第 2 步：瞬态问题

设 $w(x,t) = u(x,t) - v(x)$。代入：

- $w_{xx} = w_t$,
- $w(0,t) = 0$,
- $w_x(1,t) = -h\,w(1,t)$ （$u_0$ 项抵消：$w_x(1,t) = u_x(1,t) - v'(1) = -h(u(1,
t)-u_0) + h(v(1)-u_0) = -h\,w(1,t)$），
- $w(x,0) = f(x) - v(x) =: g(x)$。

## 第 3 步：分离变量法

设 $w = X(x)T(t)$。则 $\dfrac{X''}{X} = \dfrac{T'}{T} = -\lambda^2$，得到

$$X'' + \lambda^2 X = 0,\qquad T' + \lambda^2 T = 0.$$

通解：$X(x) = A\cos(\lambda x) + B\sin(\lambda x)$，$T(t) = e^{-\lambda^2 t}$。

**边界条件 $x = 0$：** $X(0) = 0 \Rightarrow A = 0$，因此 $X(x) = B\sin(\lambda
x)$。

**边界条件 $x = 1$：** $X'(1) = -h\,X(1)$ 得到

$$B\lambda\cos\lambda = -hB\sin\lambda \;\Longrightarrow\; \lambda\cos\lambda +
h\sin\lambda = 0 \;\Longrightarrow\; \boxed{\tan\lambda = -\frac{\lambda}{h}}.$$

**$\lambda = 0$ 的情况：** $X = Bx$，$X'(1) = B$，$-hX(1) = -hB$，因此 $B(1+h) =
 0$；由于 $h > 0$，$B = 0$。平凡。因此 $\lambda = 0$ **不是**特征值。

**正根的存在性：** 在每个区间 $\bigl((n-\tfrac12)\pi,\; n\pi\bigr)$（$n = 1, 2,
3, \ldots$）中，$\tan\lambda$ 从 $-\infty$ 增加到 $0$，而 $-\lambda/h$ 为负且严
格递减。在左端点处 $\tan\lambda < -\lambda/h$，在右端点处 $\tan\lambda = 0 > -\l
ambda/h$。根据介值定理，每个区间中恰好存在一个根 $\lambda_n$。

因此，特征值为 $\{\lambda_n\}_{n=1}^{\infty}$，即 $\tan\lambda = -\lambda/h$ 的
正根，对应的特征函数为 $\phi_n(x) = \sin(\lambda_n x)$，时间衰减为 $e^{-\lambda_
n^2 t}$。

## 第 4 步：正交性与范数

这是 $[0,1]$ 上的正则 Sturm–Liouville 问题，因此 $\{\sin(\lambda_n x)\}$ 在 $[0,
1]$ 上权值为 $1$ 时正交。计算范数：

$$N_n := \int_0^1 \sin^2(\lambda_n x)\,dx = \frac{1}{2} - \frac{\sin(2\lambda_n)
}{4\lambda_n} = \frac{1}{2}\!\left(1 - \frac{\sin\lambda_n\cos\lambda_n}{\lambda
_n}\right).$$

利用特征值方程 $\tan\lambda_n = -\lambda_n/h$：

$$\sin\lambda_n\cos\lambda_n = \frac{\tan\lambda_n}{1+\tan^2\lambda_n} = \frac{-
\lambda_n/h}{1+\lambda_n^2/h^2} = \frac{-\lambda_n h}{h^2+\lambda_n^2},$$

因此

$$\frac{\sin\lambda_n\cos\lambda_n}{\lambda_n} = \frac{-h}{h^2+\lambda_n^2}, \qq
uad N_n = \frac{1}{2}\!\left(1 + \frac{h}{h^2+\lambda_n^2}\right) = \frac{h^2 +
\lambda_n^2 + h}{2(h^2+\lambda_n^2)}.$$

## 第 5 步：级数展开

通过正交性，

$$w(x,t) = \sum_{n=1}^{\infty} c_n\,\sin(\lambda_n x)\,e^{-\lambda_n^2 t}, \qqua
d c_n = \frac{1}{N_n}\int_0^1 g(x)\sin(\lambda_n x)\,dx,$$

其中 $g(x) = f(x) - \dfrac{hu_0}{1+h}\,x$。

## 第 6 步：完整解

$$\boxed{\;u(x,t) = \frac{hu_0}{1+h}\,x \;+\; \sum_{n=1}^{\infty} c_n\,\sin(\lam
bda_n x)\,e^{-\lambda_n^2 t}\;}$$

其中

- $\lambda_n$（$n = 1, 2, 3, \ldots$）是超越方程 $\tan\lambda = -\dfrac{\lambda}
{h}$ 的正根，每个根位于 $\bigl((n-\tfrac12)\pi,\; n\pi\bigr)$ 中；
- $c_n = \dfrac{2(h^2+\lambda_n^2)}{h^2+\lambda_n^2+h}\displaystyle\int_0^1 \!\l
eft[f(x) - \frac{hu_0}{1+h}\,x\right]\sin(\lambda_n x)\,dx$。

## 第 7 步：验证

- **PDE：** 每一项 $\sin(\lambda_n x)e^{-\lambda_n^2 t}$ 满足 $X''T = -\lambda_n
^2 XT$ 和 $XT' = -\lambda_n^2 XT$，因此 $u_{xx} = u_t$。稳态项 $v(x) = \frac{hu_
0}{1+h}x$ 满足 $v'' = 0 = v_t$。✓
- **$x = 0$：** $v(0) = 0$ 且 $\sin(\lambda_n \cdot 0) = 0$，因此 $u(0,t) = 0$。
✓
- **$x = 1$：** $v'(1) = \frac{hu_0}{1+h}$ 且 $v(1) = \frac{hu_0}{1+h}$，因此 $v
'(1) = -h\bigl(v(1) - u_0\bigr) = -h\bigl(\frac{hu_0}{1+h} - u_0\bigr) = -h\cdot
\frac{-u_0}{1+h} = \frac{hu_0}{1+h}$。✓ 每个瞬态项满足 $\lambda_n\cos\lambda_n =
 -h\sin\lambda_n$，即 $X_n'(1) = -hX_n(1)$。✓ 因此 $u_x(1,t) = -h(u(1,t) - u_0)$
。✓
- **$t = 0$：** $u(x,0) = v(x) + \sum c_n \sin(\lambda_n x) = v(x) + g(x) = f(x)
$，前提是 $g$ 在 $L^2(0,1)$ 中由特征函数展开（对于分段连续的 $f$，这是 Sturm–Lio
uville 理论的标准结果）。✓
- **当 $t \to \infty$ 时衰减：** 每个 $\lambda_n > 0$，因此 $e^{-\lambda_n^2 t}
\to 0$，且 $u \to v(x) = \frac{hu_0}{1+h}x$，这是物理上预期的稳态。✓
