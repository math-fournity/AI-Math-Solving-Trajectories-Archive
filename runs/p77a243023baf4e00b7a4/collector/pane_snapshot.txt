## Solution

**The kernel.** We consider the symmetric, degenerate (separable) kernel
$$K(x,t) = x^2\,t^2, \qquad 0 \le x,t \le 1.$$
The associated integral operator is
$$\mathcal{K}[\phi](x) = \int_0^1 x^2 t^2\,\phi(t)\,dt = x^2 \int_0^1 t^2\phi(t)
\,dt.$$

**Kellogg's iteration.** Kellogg's method generates the sequence
$$\phi_{n+1}(x) = \mathcal{K}[\phi_n](x) = \int_0^1 K(x,t)\,\phi_n(t)\,dt,$$
and the eigenvalues are obtained from the limiting ratio
$$\lambda = \lim_{n\to\infty} \frac{\langle \phi_{n+1},\phi_n\rangle}{\langle \p
hi_n,\phi_n\rangle}, \qquad \langle f,g\rangle = \int_0^1 f(x)g(x)\,dx.$$

**Carrying out the iteration.** Take any starting function $\phi_0(x)$ with $\in
t_0^1 t^2\phi_0(t)\,dt \ne 0$. Then
$$\phi_1(x) = x^2 \int_0^1 t^2\phi_0(t)\,dt = c_0\, x^2, \qquad c_0 := \int_0^1
t^2\phi_0(t)\,dt.$$
Applying the operator again:
$$\phi_2(x) = x^2 \int_0^1 t^2\, c_0\, t^2\,dt = x^2\, c_0 \int_0^1 t^4\,dt = x^
2\, c_0 \cdot \tfrac{1}{5} = \tfrac{c_0}{5}\,x^2.$$
Repeating,
$$\phi_3(x) = \tfrac{c_0}{5}\cdot\tfrac{1}{5}\,x^2 = \tfrac{c_0}{25}\,x^2, \qqua
d \phi_n(x) = \frac{c_0}{5^{n-1}}\,x^2 \quad (n\ge 1).$$

**The eigenvalue from the ratio.** For $n\ge 1$,
$$\langle \phi_{n+1},\phi_n\rangle = \int_0^1 \frac{c_0}{5^n}x^2 \cdot \frac{c_0
}{5^{n-1}}x^2\,dx = \frac{c_0^2}{5^{2n-1}}\int_0^1 x^4\,dx = \frac{c_0^2}{5^{2n-
1}}\cdot\frac{1}{5} = \frac{c_0^2}{5^{2n}},$$
$$\langle \phi_n,\phi_n\rangle = \int_0^1 \frac{c_0^2}{5^{2(n-1)}}x^4\,dx = \fra
c{c_0^2}{5^{2(n-1)}}\cdot\frac{1}{5} = \frac{c_0^2}{5^{2n-1}}.$$
Therefore
$$\frac{\langle \phi_{n+1},\phi_n\rangle}{\langle \phi_n,\phi_n\rangle} = \frac{
c_0^2/5^{2n}}{c_0^2/5^{2n-1}} = \frac{1}{5}.$$

The ratio is **constant** from the first step (a hallmark of a rank‑1 degenerate
 kernel), so Kellogg's method converges immediately:
$$\lambda = \frac{1}{5}.$$

**Why this is the smallest (nonzero) eigenvalue.** Since $K(x,t)=x^2\cdot t^2$ i
s a product of a single function of $x$ and a single function of $t$, the kernel
 has **rank 1**. The integral operator therefore has exactly **one nonzero eigen
value**. Every iterate is forced into the span of $x^2$, the unique eigenfunctio
n direction, so the single nonzero eigenvalue $\lambda = 1/5$ is simultaneously
the largest and the smallest nonzero eigenvalue. All remaining spectral values a
re $0$ (the kernel annihilates any function orthogonal to $t^2$).

**Verification via the direct eigenvalue equation.** Setting $\phi(x)=x^2$:
$$\int_0^1 x^2 t^2\cdot t^2\,dt = x^2\int_0^1 t^4\,dt = x^2\cdot\frac{1}{5} = \f
rac{1}{5}\,\phi(x). \quad\checkmark$$

**Answer.** The smallest (nonzero) eigenvalue of the kernel $K(x,t)=x^2t^2$ on $
[0,1]^2$, obtained by Kellogg's method, is

$$\boxed{\lambda = \dfrac{1}{5}}.$$
