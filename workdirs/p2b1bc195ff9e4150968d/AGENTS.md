# Problem

In a specialized data center, a security token is programmed to jump between three identical server nodes arranged in a ring configuration. At the start of the operation (Step 0), the token is located at Server Alpha. 

Every minute, the token must perform a "handover" move. During this move, the token automatically detects the two servers where it is not currently located and randomly selects one of them with equal probability (50/50) to migrate to next. The token never stays at the same server for two consecutive minutes.

After exactly 10 minutes (at the 10th move), the system administrators calculate the probability that the token has returned to its original position at Server Alpha. If this probability is expressed as a fraction $m/n$ in lowest terms (where $m$ and $n$ are relatively prime positive integers), find the value of $m + n$.
