## Proof

**Claim:** Yes, $S_M(0,1)$ is always homeomorphic to $S(0,1)$.

**Key observation.** Since $M \in \mathcal{B}(F)^+$, it admits a unique positive
 square root $M^{1/2} \in \mathcal{B}(F)^+$, and
$$\langle Mx, x\rangle = \langle M^{1/2}x, M^{1/2}x\rangle = \|M^{1/2}x\|^2 \geq
 0 \quad \text{for all } x \in F.$$
Since $M$ is injective, $M^{1/2}$ is injective as well (for if $M^{1/2}x = 0$, t
hen $Mx = M^{1/2}(M^{1/2}x) = 0$, so $x = 0$). Therefore
$$\langle Mx, x\rangle = \|M^{1/2}x\|^2 > 0 \quad \text{for all } x \neq 0. \tag
{$\ast$}$$

**Construction of the homeomorphism.** Define the **radial rescaling map**
$$\Phi : S(0,1) \longrightarrow S_M(0,1), \qquad \Phi(x) = \frac{x}{\sqrt{\langl
e Mx, x\rangle}}.$$

*Well-definedness.* For $x \in S(0,1)$ we have $x \neq 0$, so by $(\ast)$ the de
nominator $\sqrt{\langle Mx,x\rangle}$ is a positive real number. Then
$$\langle M\,\Phi(x),\, \Phi(x)\rangle = \frac{\langle Mx, x\rangle}{\langle Mx,
 x\rangle} = 1,$$
so $\Phi(x) \in S_M(0,1)$.

*Continuity.* The map $x \mapsto \langle Mx, x\rangle$ is continuous (it is a bo
unded quadratic form), positive on $S(0,1)$ by $(\ast)$, so its square root is c
ontinuous and positive on $S(0,1)$. Scalar division by a continuous positive fun
ction is continuous. Hence $\Phi$ is continuous.

**Construction of the inverse.** Define
$$\Psi : S_M(0,1) \longrightarrow S(0,1), \qquad \Psi(y) = \frac{y}{\|y\|}.$$

*Well-definedness.* For $y \in S_M(0,1)$ we have $\langle My, y\rangle = 1 > 0$,
 so by $(\ast)$, $y \neq 0$; thus $\|y\| > 0$ and $\Psi(y)$ is well-defined with
 $\|\Psi(y)\| = 1$.

*Continuity.* The norm is continuous and nonzero on $S_M(0,1)$, so $\Psi$ is con
tinuous.

**The two maps are mutual inverses.**

*($\Psi \circ \Phi = \mathrm{id}$ on $S(0,1)$):* For $x \in S(0,1)$,
$$\|\Phi(x)\|^2 = \frac{\|x\|^2}{\langle Mx, x\rangle} = \frac{1}{\langle Mx, x\
rangle},$$
so $\|\Phi(x)\| = 1/\sqrt{\langle Mx, x\rangle}$. Therefore
$$\Psi(\Phi(x)) = \frac{\Phi(x)}{\|\Phi(x)\|} = \frac{x/\sqrt{\langle Mx,x\rangl
e}}{1/\sqrt{\langle Mx,x\rangle}} = x.$$

*($\Phi \circ \Psi = \mathrm{id}$ on $S_M(0,1)$):* For $y \in S_M(0,1)$, using $
\langle My, y\rangle = 1$,
$$\langle M\,\Psi(y),\, \Psi(y)\rangle = \frac{\langle My, y\rangle}{\|y\|^2} =
\frac{1}{\|y\|^2},$$
so $\sqrt{\langle M\,\Psi(y),\, \Psi(y)\rangle} = 1/\|y\|$. Therefore
$$\Phi(\Psi(y)) = \frac{\Psi(y)}{\sqrt{\langle M\,\Psi(y),\,\Psi(y)\rangle}} = \
frac{y/\|y\|}{1/\|y\|} = y.$$

**Conclusion.** $\Phi : S(0,1) \to S_M(0,1)$ is a continuous bijection with cont
inuous inverse $\Psi$, hence a homeomorphism. The argument uses only that $M$ is
 positive and injective (which gives $(\ast)$); the infinite-dimensionality of $
F$ plays no obstruction. Therefore $S_M(0,1)$ is **always** homeomorphic to the
1-sphere $S(0,1)$.
