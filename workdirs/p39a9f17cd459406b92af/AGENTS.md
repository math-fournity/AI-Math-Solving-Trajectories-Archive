# Problem

In a circular city, there are $2n$ security stations ($n \geq 2$) positioned at the vertices of a regular $2n$-sided polygon. Exactly one security guard is stationed at each of these $2n$ locations. At the start of a drill, every guard must simultaneously move to one of the two stations immediately adjacent to their current position.

A deployment is classified as "secure" if, after all guards have moved, there is no pair of occupied stations that are diametrically opposite each other (i.e., no line segment connecting two occupied stations passes through the center of the circular city). Note that a station may end up housing zero, one, or two guards, but it is considered "occupied" as long as at least one guard is present.

Let $S$ be the set of all integers $n$ in the range $2 \leq n \leq 100$ for which there exists at least one "secure" deployment for the $2n$ guards. Calculate the sum of all elements in the set $S$.
