## Proof that the problem is underdetermined

Let $Q, A, C$ be the three certification sets, each of size 10, inside a univers
e $U$ of size 20. A 3-person task force is "triple-capable" iff it contains $\ge
 1$ member of $Q$, $\ge 1$ of $A$, and $\ge 1$ of $C$.

By inclusion–exclusion on the three "missing" events, the count is:

$$N = \binom{20}{3} - \bigl[\tbinom{|Q^c|}{3}+\tbinom{|A^c|}{3}+\tbinom{|C^c|}{3
}\bigr] + \bigl[\tbinom{|Q^c\cap A^c|}{3}+\tbinom{|Q^c\cap C^c|}{3}+\tbinom{|A^c
\cap C^c|}{3}\bigr] - \tbinom{|Q^c\cap A^c\cap C^c|}{3}.$$

Since $|Q|=|A|=|C|=10$, we have $|Q^c|=|A^c|=|C^c|=10$, so the first bracket is
$3\binom{10}{3}=360$, giving

$$N = 1140 - 360 + \bigl[\tbinom{20-|Q\cup A|}{3}+\tbinom{20-|Q\cup C|}{3}+\tbin
om{20-|A\cup C|}{3}\bigr] - \tbinom{20-|Q\cup A\cup C|}{3}.$$

The remaining terms depend on the **pairwise and triple overlaps**, which the pr
oblem does **not** specify. I show two valid configurations producing different
counts.

### Configuration 1: $Q = A = C = \{1,\dots,10\}$

All three groups coincide (10 scientists hold all three certifications; 10 hold
none). A 3-subset is triple-capable iff it contains at least one member of $\{1,
\dots,10\}$ (that member covers all three certifications).

$$N_1 = \binom{20}{3} - \binom{10}{3} = 1140 - 120 = \boxed{1020}.$$

Verification via the formula: $|Q\cup A|=|Q\cup C|=|A\cup C|=10$, $|Q\cup A\cup
C|=10$:
$$N_1 = 780 + 3\binom{10}{3} - \binom{10}{3} = 780 + 2\cdot120 = 1020.\ \checkma
rk$$

### Configuration 2: $Q=\{1,\dots,10\}$, $A=\{11,\dots,20\}$, $C=\{1,\dots,5,11,
\dots,15\}$

Here $|Q\cap A|=0$, $|Q\cap C|=5$, $|A\cap C|=5$, $|Q\cap A\cap C|=0$. The 20 sc
ientists split into four groups of 5: $Q$-only $\{6,\dots,10\}$, $A$-only $\{16,
\dots,20\}$, $Q\cap C$ $\{1,\dots,5\}$, $A\cap C$ $\{11,\dots,15\}$.

Since $Q$ and $A$ partition $U$, a triple-capable subset needs $\ge1$ from $Q=\{
1,\dots,10\}$ and $\ge1$ from $A=\{11,\dots,20\}$, plus $\ge1$ from $C=\{1,\dots
,5,11,\dots,15\}$.

- **(1 from $Q$, 2 from $A$):** If the $Q$-pick is in $\{1,\dots,5\}$ ($Q\cap C$
), $C$ is auto-satisfied: $\binom{5}{1}\binom{10}{2}=225$. If in $\{6,\dots,10\}
$ ($Q$-only), need $\ge1$ of the 2 $A$-picks in $\{11,\dots,15\}$: $5\cdot\bigl[
\binom{10}{2}-\binom{5}{2}\bigr]=5\cdot35=175$. Subtotal $400$.
- **(2 from $Q$, 1 from $A$):** Symmetric — subtotal $400$.

$$N_2 = 400 + 400 = \boxed{800}.$$

Verification via the formula: $|Q\cup A|=20$, $|Q\cup C|=15$, $|A\cup C|=15$, $|
Q\cup A\cup C|=20$:
$$N_2 = 780 + \bigl[\tbinom{0}{3}+\tbinom{5}{3}+\tbinom{5}{3}\bigr] - \tbinom{0}
{3} = 780 + (0+10+10) - 0 = 800.\ \checkmark$$

Both configurations satisfy every stated condition (20 scientists; $|Q|=|A|=|C|=

The count of triple-capable 3-person task forces **depends on the overlap struct
