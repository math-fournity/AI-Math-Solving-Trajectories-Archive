# Solution: Potential Flow Around a Sphere

## Preliminary Remark on "Viscous Liquid"

The problem asks for a **velocity potential**, which requires irrotational flow
($\nabla \times \mathbf{v} = 0$, so $\mathbf{v} = \nabla\varphi$). For incompres
sible irrotational flow, $\nabla^2\varphi = 0$. Crucially, the viscous term in t
he Navier–Stokes equation vanishes identically for irrotational flow:

$$\nu\nabla^2\mathbf{v} = \nu\bigl(\nabla(\nabla\cdot\mathbf{v}) - \nabla\times(
\nabla\times\mathbf{v})\bigr) = \nu(0 - 0) = 0$$

so the potential-flow solution satisfies the full Navier–Stokes equations (with
appropriate pressure). It satisfies the **no-penetration** boundary condition ($
v_n = U_n$ at the surface) but **not** the no-slip (tangential) condition — this
 is the standard potential-flow approximation. We solve both parts using spheric
al coordinates $(r,\theta)$ with the polar axis along the flow direction, and sp
here radius $a$.

---

## Part (b): Stationary Sphere, Uniform Flow $v_0$ at Infinity

We solve this first since part (a) follows by a Galilean transformation.

**Governing equation and boundary conditions:**

$$\nabla^2\varphi = 0, \qquad r > a$$

$$\varphi \to v_0\, r\cos\theta \quad \text{as } r\to\infty \qquad (\text{unifor
m flow } v_0\hat{z})$$

$$\frac{\partial\varphi}{\partial r}\bigg|_{r=a} = 0 \qquad (\text{no penetratio
n: sphere is stationary})$$

**General axisymmetric solution** of Laplace's equation (keeping only the $\ell=
1$ mode, which is the only one compatible with the $\cos\theta$ behavior at infi
nity):

$$\varphi = \left(A\,r + \frac{B}{r^2}\right)\cos\theta$$

**Applying the far-field condition:** $A = v_0$.

**Applying the no-penetration condition at $r = a$:**

$$\frac{\partial\varphi}{\partial r} = \left(A - \frac{2B}{r^3}\right)\cos\theta
 \bigg|_{r=a} = 0 \quad\Longrightarrow\quad A - \frac{2B}{a^3} = 0 \quad\Longrig
htarrow\quad B = \frac{v_0\,a^3}{2}$$

**Result for part (b):**

$$\boxed{\varphi = v_0\left(r + \frac{a^3}{2\,r^2}\right)\cos\theta}$$

**Velocity field:**

$$v_r = \frac{\partial\varphi}{\partial r} = v_0\left(1 - \frac{a^3}{r^3}\right)
\cos\theta$$

$$v_\theta = \frac{1}{r}\frac{\partial\varphi}{\partial\theta} = -v_0\left(1 + \
frac{a^3}{2\,r^3}\right)\sin\theta$$

**Verification at the surface** $r=a$: $v_r = 0$ ✓ (no penetration), and $v_\the
ta = -\tfrac{3}{2}v_0\sin\theta$ (tangential slip — the potential-flow solution
does not enforce no-slip).

---

## Part (a): Sphere Moving with Constant Velocity $U$ in Fluid at Rest at Infini
ty

Let the sphere move with velocity $U\hat{z}$. We use a **Galilean transformation
** to the frame comoving with the sphere. In that frame the fluid at infinity ha
s velocity $-U\hat{z}$, which is exactly part (b) with $v_0 = -U$.

**Potential in the comoving frame:**

$$\varphi' = -U\left(r + \frac{a^3}{2\,r^2}\right)\cos\theta$$

**Transform back to the lab frame** (fluid at rest at infinity) by adding the un
iform-flow potential $U\,r\cos\theta = U\,z$:

$$\varphi = \varphi' + U\,r\cos\theta = -U\left(r + \frac{a^3}{2\,r^2}\right)\co
s\theta + U\,r\cos\theta$$

**Result for part (a):**

$$\boxed{\varphi = -\frac{U\,a^3}{2\,r^2}\cos\theta}$$

This is a **dipole (doublet) potential** with dipole moment $Ua^3/2$.

**Velocity field:**

$$v_r = \frac{\partial\varphi}{\partial r} = \frac{U\,a^3}{r^3}\cos\theta$$

$$v_\theta = \frac{1}{r}\frac{\partial\varphi}{\partial\theta} = \frac{U\,a^3}{2
\,r^3}\sin\theta$$

**Verification of boundary conditions:**

- *At infinity* ($r\to\infty$): $v_r, v_\theta \to 0$ ✓ (fluid at rest).
- *At the sphere surface* ($r = a$): $v_r = U\cos\theta$, which equals the norma
l component of the sphere velocity $U\hat{z} = U\cos\theta\,\hat{r} - U\sin\thet
a\,\hat{\theta}$ ✓ (no penetration). The tangential component $v_\theta = \tfrac
{U}{2}\sin\theta \neq U\sin\theta$ (no-slip not satisfied — consistent with pote
ntial-flow approximation).

---

## Pressure on the Sphere Surface (Part a)

Using the steady Bernoulli equation in the comoving frame (where the flow is ste
ady), with $p\to p_\infty$ and $|\mathbf{v}'|\to U$ at infinity:

$$\frac{p}{\rho} + \frac{v'^2}{2} = \frac{p_\infty}{\rho} + \frac{U^2}{2}$$

At $r = a$ in the comoving frame: $v'_r = 0$, $v'_\theta = \tfrac{3U}{2}\sin\the
ta$, so $v'^2 = \tfrac{9U^2}{4}\sin^2\theta$. Thus:

$$p\big|_{r=a} = p_\infty + \frac{\rho U^2}{2}\left(1 - \frac{9}{4}\sin^2\theta\
right)$$

- **Front stagnation point** ($\theta = 0$): $p = p_\infty + \tfrac{1}{2}\rho U^
2$ (maximum).
- **Equator** ($\theta = \pi/2$): $p = p_\infty - \tfrac{5}{8}\rho U^2$ (minimum
).
- **Rear stagnation point** ($\theta = \pi$): $p = p_\infty + \tfrac{1}{2}\rho U
^2$.

The pressure is **symmetric** front-to-back, so the net drag is **zero** — this
is **d'Alembert's paradox**, the hallmark of potential flow. (A real viscous flu
id would have a thin boundary layer and a wake, producing drag; the potential-fl
ow solution captures the outer inviscid region only.)

## Summary

| | Part (a): moving sphere, fluid at rest at ∞ | Part (b): fixed sphere, flow $
v_0$ at ∞ |
|---|---|---|
| **Potential** | $\displaystyle\varphi = -\frac{Ua^3}{2r^2}\cos\theta$ (dipole)
 | $\displaystyle\varphi = v_0\!\left(r + \frac{a^3}{2r^2}\right)\cos\theta$ (un
iform flow + dipole) |
| **Relation** | Galilean transform of (b) with $v_0 = -U$, plus $+Ur\cos\theta$
 | Direct solution of Laplace's equation |

The two problems are equivalent under a Galilean transformation, as expected.
