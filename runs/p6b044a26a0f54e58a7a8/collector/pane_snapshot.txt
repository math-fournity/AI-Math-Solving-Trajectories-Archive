## Proof

Let

$$W = \{x\in[0,1] : |x - p/q| < q^{-2} \text{ for infinitely many } p,q\in\mathb
b N\}.$$

Then $E' = [0,1]\setminus W$ (up to the harmless boundary points where equality
holds), so it suffices to determine $m(W)$.

We use **Khintchine's theorem** in the following standard form:

> Let $\psi:\mathbb N\to(0,\infty)$ be non‑increasing, and let
> $$W(\psi)=\{x\in[0,1]: |x-p/q|<\psi(q)/q \text{ for infinitely many coprime pa
irs }(p,q),\ q\ge 1\}.$$
> If $\sum_{q=1}^{\infty}\psi(q)<\infty$, then $m(W(\psi))=0$.
> If $\sum_{q=1}^{\infty}\psi(q)=\infty$, then $m(W(\psi))=1$.

Take $\psi(q)=1/q$, which is non‑increasing. Then $\psi(q)/q = 1/q^{2}$, so

$$W(\psi)=\{x\in[0,1]: |x-p/q|<1/q^{2}\text{ for infinitely many coprime }(p,q)\
}.$$

The series $\sum_{q=1}^{\infty}\psi(q)=\sum_{q=1}^{\infty}1/q$ diverges (harmoni
c series). Hence by Khintchine's theorem,

$$m(W(\psi))=1.$$

The set $W$ in the problem is defined using **all** $p,q\in\mathbb N$ (not only
coprime pairs), so $W\supseteq W(\psi)$. Therefore

$$m(W)\ge m(W(\psi))=1 \quad\Longrightarrow\quad m(W)=1.$$

Consequently

$$m(E') = m([0,1]\setminus W) = 1 - m(W) = 0.$$

**Remark (stronger statement).** In fact $E'=\varnothing$. By Dirichlet's approx
imation theorem, for every irrational $x$ and every $Q\ge1$ there exist $p,q$ wi
th $1\le q\le Q$ and $|x-p/q|<1/(qQ)\le 1/q^{2}$. Since $x$ is irrational, the f
ractions obtained for arbitrarily large $Q$ are eventually distinct, giving infi
nitely many approximations with $|x-p/q|<1/q^{2}$. Every rational $x=a/b$ admits
 infinitely many exact representations $p/q=a/b$ (take $q=kb$), so it also has i
nfinitely many such approximations. Thus no point of $[0,1]$ lies in $E'$, and $
m(E')=0$ trivially.

Either way, the set $E'$ has **Lebesgue measure $0$**.
