## Setting Up the Angle Bisector Ratios

By the Angle Bisector Theorem in the respective triangles:
- $K$ on $AB$: $\frac{AK}{KB} = \frac{PA}{PB}$, so $K = \frac{b\cdot A + a\cdot
B}{a+b}$
- $L$ on $BC$: $\frac{BL}{LC} = \frac{PB}{PC}$, so $L = \frac{c\cdot B + b\cdot
C}{b+c}$
- $M$ on $CD$: $\frac{CM}{MD} = \frac{PC}{PD}$, so $M = \frac{d\cdot C + c\cdot
D}{c+d}$
- $N$ on $AD$: $\frac{AN}{ND} = \frac{PA}{PD}$, so $N = \frac{d\cdot A + a\cdot
D}{a+d}$

where $a=PA$, $b=PB$, $c=PC$, $d=PD$.

## Key Insight: $PA = PC$ and $PB = PD$

**Suppose $a = c$ and $b = d$.** Then:
$$K = \frac{bA + aB}{a+b},\quad L = \frac{aB + bC}{a+b},\quad M = \frac{bC + aD}
{a+b},\quad N = \frac{bA + aD}{a+b}$$

Computing the diagonal midpoints:
$$K + M = \frac{bA + aB + bC + aD}{a+b}, \qquad L + N = \frac{aB + bC + bA + aD}
{a+b}$$

These are **identical**, so $K + M = L + N$, confirming $KLMN$ is a parallelogra
m. ✓
