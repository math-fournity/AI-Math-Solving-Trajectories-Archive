## Proof

We use the following well-known convolution identity (a variant of Vandermonde's
 identity, provable by a combinatorial "middle element" argument):

$$\sum_{k=r}^{n-s} \binom{k}{r}\binom{n-k}{s} = \binom{n+1}{r+s+1}.$$

**Proof of the identity.** Count the number of ways to choose $r+s+1$ elements f
rom $\{0,1,\ldots,n\}$ (a set of size $n+1$), i.e. $\binom{n+1}{r+s+1}$. For any
 such choice, let $k$ be the $(r+1)$-st smallest selected element. Then:
- Exactly $r$ elements are chosen from $\{0,1,\ldots,k-1\}$, a set of size $k$:
$\binom{k}{r}$ ways.
- Exactly $s$ elements are chosen from $\{k+1,\ldots,n\}$, a set of size $n-k$:
$\binom{n-k}{s}$ ways.

The value $k$ ranges from $r$ (so that $\{0,\ldots,k-1\}$ has at least $r$ eleme
nts) up to $n-s$ (so that $\{k+1,\ldots,n\}$ has at least $s$ elements). Summing
 over all admissible $k$ partitions the count, giving the identity. $\square$

- The lower limit is $k = r = 84$. ✓
- The upper limit is $k = n - s = 8084 - 84 = 8000$. ✓
- The summand is $\binom{k}{r}\binom{n-k}{s} = \binom{k}{84}\binom{8084-k}{84}$.
