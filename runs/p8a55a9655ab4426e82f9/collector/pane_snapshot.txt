## Proof

Let $M := \sup_{n} \|f_n\| < \infty$, which is finite since $(f_n)$ is bounded.
We claim that the condition $M\epsilon < 1$ (i.e. $\epsilon < 1/M$) is sufficien
t.

**Construction of the perturbation.** Define $S: X \to X$ by
$$Sx = \sum_{n=1}^{\infty} f_n(x)\,(y_n - x_n), \qquad x \in X.$$

**$S$ is well-defined and bounded.** For every $x \in X$,
$$\sum_{n=1}^{\infty} \bigl\|f_n(x)(y_n - x_n)\bigr\| = \sum_{n=1}^{\infty} |f_n
(x)|\,\|y_n - x_n\| \le \|x\|\sum_{n=1}^{\infty}\|f_n\|\,\|y_n - x_n\| \le \|x\|
\cdot M\cdot\epsilon < \infty.$$
The series therefore converges absolutely, so $Sx$ is well-defined, and
$$\|S\| \le \sum_{n=1}^{\infty}\|f_n\|\,\|y_n - x_n\| \le M\epsilon.$$

**$S$ sends $x_n$ to $y_n - x_n$.** Using the biorthogonality $f_m(x_n) = \delta
_{mn}$,
$$Sx_n = \sum_{m=1}^{\infty} f_m(x_n)(y_m - x_m) = \sum_{m=1}^{\infty} \delta_{m
n}(y_m - x_m) = y_n - x_n.$$

**Invertibility of $T = I + S$.** Setting $T := I + S$, we obtain
$$Tx_n = x_n + Sx_n = x_n + (y_n - x_n) = y_n \qquad \text{for all } n.$$
When $M\epsilon < 1$, we have $\|S\| \le M\epsilon < 1$, so the Neumann series $
\sum_{k=0}^{\infty}(-S)^k$ converges in operator norm and gives a bounded two-si
ded inverse of $I + S$. Hence $T = I + S$ is invertible.

**Conclusion.** Whenever $\epsilon = \sum_n \|x_n - y_n\|$ is sufficiently small
 — specifically, whenever $M\epsilon < 1$ where $M = \sup_n\|f_n\|$ (more precis
ely, whenever $\sum_n \|f_n\|\,\|x_n - y_n\| < 1$) — the operator $T = I + S$ is
 an invertible operator on $X$ satisfying $Tx_n = y_n$ for all $n$. $\blacksquar
e$
