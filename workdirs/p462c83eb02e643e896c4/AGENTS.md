# Problem

In a specialized security facility, a technician named Leo is tasked with identifying a specific 2-digit access code (from 00 to 99) stored in an encrypted vault. 

The vault is equipped with a feedback sensor. Every time Leo inputs a 2-digit test code, the sensor provides a single piece of data: it reports how many digits in the test code exactly match the digits of the target code in both value and position. For example, if the target code is 42 and Leo tests 47, the sensor returns "1"; if he tests 24, it returns "0"; and if he tests 42, it returns "2".

Leo needs to develop a testing protocol that identifies the secret code with absolute certainty, regardless of what the code is. What is the minimum number of test codes Leo must input to guarantee he can determine the vault's secret code?
