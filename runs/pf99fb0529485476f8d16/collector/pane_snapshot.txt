## Proof

### Step 1: Construct a continuous singular measure with full support

Let $\{(a_n, b_n)\}_{n \geq 1}$ be an enumeration of all open intervals in $(0,1
)$ with rational endpoints (a countable basis for the topology). For each $n$, l
et $C_n \subset (a_n, b_n)$ be a Cantor set of Lebesgue measure zero (a scaled,
translated copy of the standard middle-thirds Cantor set), and let $\nu_n$ be th
e Cantor probability measure supported on $C_n$. Set $\mu_n = 2^{-n}\nu_n$ and d
efine:

$$\mu = \sum_{n=1}^{\infty} \mu_n.$$

**Properties of $\mu$:**

- **Probability measure:** $\mu([0,1]) = \sum_{n=1}^\infty 2^{-n} = 1$.
- **Non-atomic:** Each $\nu_n$ is non-atomic, so $\mu(\{x\}) = \sum_n \mu_n(\{x\
}) = 0$ for every $x$.
- **Singular w.r.t. Lebesgue measure $m$:** Each $\mu_n$ is supported on $C_n$ w
ith $m(C_n) = 0$. Since $\mu_n((C_n)^c) = 0$, we get $\mu\!\left(\left(\bigcup_n
 C_n\right)^c\right) \leq \sum_n \mu_n((C_n)^c) = 0$, so $\mu$ is concentrated o
n $\bigcup_n C_n$, which satisfies $m\!\left(\bigcup_n C_n\right) \leq \sum_n m(
C_n) = 0$. Thus $\mu \perp m$.
- **Full support:** Each $C_n \subset (a_n, b_n)$ is nonempty, and $\{(a_n,b_n)\
}$ is a basis, so $\bigcup_n C_n$ intersects every open interval and is therefor
e dense in $[0,1]$. The support of $\mu$ is $\overline{\bigcup_n C_n} = [0,1]$.

### Step 2: Define $f$

Let $g(x) = \mu([0,x])$ be the CDF of $\mu$. Since $\mu$ is non-atomic, $g$ is c
ontinuous, non-decreasing, with $g(0)=0$ and $g(1)=1$.

Fix $\varepsilon \in (0,1)$ and define:

$$f(x) = (1-\varepsilon)\,x + \varepsilon\, g(x).$$

### Step 3: Verify the conditions

**(a) $f$ is continuous, strictly increasing, $f(0)=0$, $f(1)=1$, and $f:[0,1]\t
o[0,1]$.**

- *Continuous:* Sum of continuous functions.
- *Strictly increasing:* For $x < y$,
$$f(y) - f(x) = (1-\varepsilon)(y-x) + \varepsilon\underbrace{(g(y)-g(x))}_{\geq
\, 0} \geq (1-\varepsilon)(y-x) > 0.$$
- *Boundary values:* $f(0) = 0$, $f(1) = (1-\varepsilon) + \varepsilon = 1$.
- *Range:* Continuous, strictly increasing, $f(0)=0$, $f(1)=1$ implies $f([0,1])
=[0,1]$. ✓

**(b) Condition 2: On every interval $A \subset [0,1]$, $f'$ is bad somewhere.**

Since $\mu$ is purely singular ($\mu \perp m$), by the **Lebesgue differentiatio
n theorem for measures** (see Folland, *Real Analysis*, Theorem 3.22; or Rudin,
*Real and Complex Analysis*), the upper density of $\mu$ with respect to $m$ sat
isfies:

$$\overline{D}\mu(x) := \limsup_{h \to 0^+} \frac{\mu((x, x+h])}{h} = +\infty \q
uad \text{for } \mu\text{-a.e. } x.$$

*(This is the standard result that a singular measure has infinite upper density
 at $\mu$-almost every point: the Radon–Nikodym derivative $d\mu/dm = 0$ $m$-a.e
., and the singular part has density $+\infty$ at its typical points.)*

Let $E = \{x \in [0,1] : \overline{D}\mu(x) = +\infty\}$. Then $\mu(E) = 1$ (ful
l $\mu$-measure).

At any $x \in E$, the upper right Dini derivative of $g$ is $D^+ g(x) = +\infty$
. Since $g$ is monotone:
- If $g'(x)$ exists (as an extended real), then $g'(x) = D^+g(x) = +\infty$.
- If $g'(x)$ does not exist, then $g'$ is non-existent at $x$.

In either case, $g'$ is "bad" at $x$. Since $f(x) = (1-\varepsilon)x + \varepsil
on g(x)$ and $(1-\varepsilon)x$ is everywhere differentiable:
- If $g'(x)$ doesn't exist $\Rightarrow$ $f'(x)$ doesn't exist.
- If $g'(x) = +\infty$ $\Rightarrow$ $f'(x) = +\infty$.

So $f'$ is bad at every point of $E$.

**$E$ is dense in $[0,1]$:** Suppose not. Then some open interval $(a,b) \subset
 [0,1]$ satisfies $(a,b) \cap E = \emptyset$, giving $\mu((a,b)) \leq \mu([0,1]\
setminus E) = 0$. But $(a,b) \subset \operatorname{supp}(\mu) = [0,1]$ implies $
\mu((a,b)) > 0$ (every nonempty open subset of the support has positive measure)
. Contradiction.

Since $E$ is dense, **every** interval $A \subset [0,1]$ contains a point of $E$
, where $f'$ is non-existent or $+\infty$. Condition 2 is satisfied. ✓

**(c) Condition 3: There exists a dense set $B$ where $f'$ exists, is finite, an
d positive.**

Since $g$ is monotone, $g'$ exists (possibly $+\infty$) for $m$-a.e. $x$, with $
\int_0^1 g'\,dm \leq g(1)-g(0) = 1$. The Lebesgue–Stieltjes measure $dg = d\mu$
decomposes as $dg = g'\,dm + dg_s$. Since $\mu$ is purely singular, $g'\,dm = 0$
, so:

$$g'(x) = 0 \quad \text{for } m\text{-a.e. } x.$$

Let $B = \{x \in [0,1] : g'(x) = 0\}$. Then $m(B) = 1$, so $B$ is **dense** in $
[0,1]$.

At every $x \in B$:

$$f'(x) = (1-\varepsilon) + \varepsilon \cdot g'(x) = (1-\varepsilon) + 0 = 1 -
\varepsilon > 0,$$

which is finite and positive. Condition 3 is satisfied with $B = \{x : g'(x) = 0
\}$, a set of full Lebesgue measure. ✓

### Conclusion

The function

$$\boxed{f(x) = (1-\varepsilon)\,x + \varepsilon\,\mu([0,x])}$$

where $\mu$ is a continuous (non-atomic) singular probability measure on $[0,1]$

1. $f$ is continuous, strictly increasing, $f(0)=0$, $f(1)=1$, $f:[0,1]\to[0,1]$

2. On every interval $A \subset [0,1]$, $f'$ is $+\infty$ or non-existent at som
e point (the bad set $E$ is dense). ✓
3. $f' = 1-\varepsilon > 0$ on the set $B = \{g' = 0\}$, which has full Lebesgue

Therefore, **such a function exists**. $\blacksquare$
