Looking at this problem, I need to find all positive integers $n$ such that for
every $m$ coprime to $n$, the permutation $\sigma_m : k \mapsto mk \pmod{n}$ (on
 $\{1,\ldots,n\}$, with $0 \leftrightarrow n$) has a square root in $S_n$.

**Key fact:** A permutation has a square root iff for every even cycle length, t
he number of cycles of that length is even.

**Cycle structure of $\sigma_m$:** For $k$ with $d = \gcd(k,n)$, the cycle lengt
h is $\operatorname{ord}_{n/d}(m)$, and the number of such $k$ is $\phi(n/d)$. S
o the number of cycles of length $L$ is $\sum_{d \mid n,\, \operatorname{ord}_{n
/d}(m)=L} \phi(n/d)/L$.

---

**Part 1: $n = 2q$ with $q$ odd works.**

Since $m$ is coprime to $2q$, $m$ is odd. Each divisor of $n=2q$ is either $e$ o
r $2e$ for some $e \mid q$. For each such pair:

- **$d = e$:** $n/d = 2q/e$. Since $m \equiv 1 \pmod{2}$ and $\gcd(2, q/e)=1$, b
y CRT: $\operatorname{ord}_{2q/e}(m) = \operatorname{ord}_{q/e}(m)$, and $\phi(2
q/e) = \phi(q/e)$. Contributes $\phi(q/e)/\operatorname{ord}_{q/e}(m)$ cycles of
 length $\operatorname{ord}_{q/e}(m)$.

- **$d = 2e$:** $n/d = q/e$. Contributes $\phi(q/e)/\operatorname{ord}_{q/e}(m)$
 cycles of the **same** length.

Each pair contributes **twice** the same number of cycles of each length, so eve
ry cycle count is **even**. Thus $\sigma_m$ always has a square root. ✓

This covers $n = 2, 6, 10, 14, 18, \ldots$ (all $n \equiv 2 \pmod{4}$).

---

**Part 2: $n = 1$ works.** Trivially, the only permutation of $\{1\}$ satisfies
the condition.

---

**Part 3: Odd $n > 1$ fails.**

**Case (a): $n = p^k$ (odd prime power).** Let $m$ be a primitive root mod $p^k$
. For each divisor $d = p^j$ ($0 \le j \le k-1$), $n/d = p^{k-j}$, and $\operato
rname{ord}_{p^{k-j}}(m) = \phi(p^{k-j}) = p^{k-j-1}(p-1)$, giving exactly **1**
cycle of length $p^{k-j-1}(p-1)$. Each such length is even (since $p-1$ is even)
 with count 1 (odd). No square root. ✗

**Case (b): $n = p_1^{a_1} \cdots p_r^{a_r}$, $r \ge 2$ distinct odd primes.** C
hoose $m$ that is a primitive root mod $p_1^{a_1}$ and $m \equiv 1 \pmod{n/p_1^{
a_1}}$ (possible by CRT). Then $m$ is coprime to $n$.

For any divisor $d$ of $n$ with $p_1 \nmid d$ (i.e., $d \mid n/p_1^{a_1}$): writ
ing $n/d = p_1^{a_1} \cdot s$ with $s \mid (n/p_1^{a_1})$, we get $\operatorname
{ord}_{n/d}(m) = \operatorname{lcm}(\operatorname{ord}_{p_1^{a_1}}(m), \operator
name{ord}_s(m)) = \operatorname{lcm}(p_1^{a_1-1}(p_1-1), 1) = p_1^{a_1-1}(p_1-1)
$.

The total number of cycles of length $p_1^{a_1-1}(p_1-1)$ is:
$$\sum_{d \mid n/p_1^{a_1}} \frac{\phi(n/d)}{p_1^{a_1-1}(p_1-1)} = \sum_{d \mid
n/p_1^{a_1}} \phi\!\left(\frac{n}{p_1^{a_1} d}\right) = \sum_{e \mid n/p_1^{a_1}
} \phi(e) = \frac{n}{p_1^{a_1}}.$$

Since $n$ is odd, $n/p_1^{a_1}$ is **odd**, while the cycle length $p_1^{a_1-1}(
p_1-1)$ is **even**. Odd count of even-length cycles → no square root. ✗

---

**Part 4: $n \equiv 0 \pmod{4}$ fails.**

Write $n = 2^a q$ with $a \ge 2$, $q$ odd. Take $m = n-1 \equiv -1 \pmod{n}$. Th
en $\sigma_{-1}(k) = -k$ has fixed points where $2k \equiv 0 \pmod{n}$, i.e., $k
 = 2^{a-1}q$ and $k = n$: exactly **2** fixed points. The remaining $n - 2$ elem
ents form $(n-2)/2 = 2^{a-1}q - 1$ transpositions. Since $a \ge 2$, this is **od
d**. No square root. ✗

---

**Conclusion:** $S = \{1\} \cup \{n \in \mathbb{Z}^+ : n \equiv 2 \pmod{4}\}$.

**Summation for $1 \le n \le 100$:** The values $n \equiv 2 \pmod{4}$ in $[1,100
]$ are $2, 6, 10, \ldots, 98$ — an arithmetic sequence with $k = 0, 1, \ldots, 2
4$ (25 terms):

$$\sum_{k=0}^{24}(4k+2) = 4 \cdot \frac{24 \cdot 25}{2} + 2 \cdot 25 = 1200 + 50
 = 1250.$$
