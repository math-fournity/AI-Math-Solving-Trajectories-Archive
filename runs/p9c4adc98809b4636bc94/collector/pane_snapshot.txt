## Proof

We seek all real polynomials $p(x)$ such that $p(q(x)) = q(p(x))$ for every real
 polynomial $q(x)$.

**Step 1: Use translations to pin down the form of $p$.**

Take $q(x) = x + c$ for an arbitrary real constant $c$. The commutation conditio
n gives
$$p(x + c) = p(x) + c \quad \text{for all } x, c \in \mathbb{R}.$$
Setting $x = 0$ yields $p(c) = p(0) + c$ for every $c \in \mathbb{R}$. Hence
$$p(x) = x + a, \qquad a := p(0).$$

**Step 2: Determine $a$ using a nonlinear $q$.**

Now impose the condition with $q(x) = x^2$:
$$p(q(x)) = p(x^2) = x^2 + a,$$
$$q(p(x)) = q(x + a) = (x + a)^2 = x^2 + 2ax + a^2.$$
Equality for all $x$ requires
$$x^2 + a = x^2 + 2ax + a^2 \quad \forall x,$$
i.e. $2ax + (a^2 - a) = 0$ for all $x$. Comparing coefficients:
- coefficient of $x$: $2a = 0 \Rightarrow a = 0$,
- constant term: $a^2 - a = 0$, satisfied by $a = 0$.

Thus $a = 0$, giving $p(x) = x$.

**Step 3: Verify.**

With $p(x) = x$ we have $p(q(x)) = q(x) = q(p(x))$ for every polynomial $q$. ✓

**Conclusion.** The unique real polynomial commuting with every real polynomial
under composition is the identity:

$$\boxed{p(x) = x.}$$
