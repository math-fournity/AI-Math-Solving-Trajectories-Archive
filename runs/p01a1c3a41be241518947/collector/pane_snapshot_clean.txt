## Solution

**Setup.** Place $B = (0,0)$ and $C = (1,0)$. Since $\angle ABC = 90^\circ$ and
$AB = 1$, set $A = (0,1)$.

**Locating $E$ and $D$.** We have $AE = 1$, $DE = 1$, $DC = 1$, and $\angle DEA
= 90^\circ$. The right angle at $E$ in $\triangle DEA$ means $\vec{EA} \perp \ve
c{ED}$ with $|\vec{EA}| = |\vec{ED}| = 1$, so $\triangle DEA$ is an isosceles ri
ght triangle giving $AD = \sqrt{2}$.

Write $E = A + (\cos\theta, \sin\theta) = (\cos\theta,\, 1+\sin\theta)$. The per
pendicular direction to $\vec{EA} = -(\cos\theta,\sin\theta)$ is $(\sin\theta, -
\cos\theta)$ or $(-\sin\theta, \cos\theta)$. For the convex configuration (verif
ied below), we take
$$D = E + (\sin\theta, -\cos\theta) = (\cos\theta+\sin\theta,\; 1+\sin\theta-\co
s\theta).$$

**Using $DC = 1$.** With $C = (1,0)$:
$$|D-C|^2 = (\cos\theta+\sin\theta-1)^2 + (1+\sin\theta-\cos\theta)^2 = 1.$$

Let $s = \cos\theta+\sin\theta$, $t = \sin\theta-\cos\theta$ (so $s^2+t^2=2$). T
hen:
$$(s-1)^2 + (t+1)^2 = s^2+t^2 + 2(t-s) + 2 = 4 + 2(t-s) = 1,$$
giving $t - s = -\tfrac{3}{2}$, i.e. $-2\cos\theta = -\tfrac{3}{2}$, so $\cos\th
eta = \tfrac{3}{4}$ and $\sin\theta = \tfrac{\sqrt{7}}{4}$ (positive root for co
nvexity).

**Coordinates.**
$$E = \left(\tfrac{3}{4},\, \tfrac{4+\sqrt{7}}{4}\right), \qquad D = \left(\tfra
c{3+\sqrt{7}}{4},\, \tfrac{1+\sqrt{7}}{4}\right).$$

**Verification of all constraints:**
- $AB = 1$, $BC = 1$: by construction. ✓
- $AE = |(-\tfrac{3}{4}, -\tfrac{\sqrt{7}}{4})| = \sqrt{\tfrac{9+7}{16}} = 1$. ✓
- $DE = |(\tfrac{\sqrt{7}}{4}, -\tfrac{3}{4})| = \sqrt{\tfrac{7+9}{16}} = 1$. ✓
- $DC = |(\tfrac{\sqrt{7}-1}{4}, \tfrac{1+\sqrt{7}}{4})| = \sqrt{\tfrac{(7-2\sqr
t7+1)+(1+2\sqrt7+7)}{16}} = \sqrt{\tfrac{16}{16}} = 1$. ✓
- $\angle DEA = 90°$: $\vec{EA}\cdot\vec{ED} = (-\tfrac{3}{4})(\tfrac{\sqrt7}{4}
) + (-\tfrac{\sqrt7}{4})(-\tfrac{3}{4}) = 0$. ✓
- **Convexity:** All consecutive cross products are positive (counterclockwise),
 confirming convexity. ✓

**Area via Shoelace.** Vertices $A(0,1),\, B(0,0),\, C(1,0),\, D\!\left(\tfrac{3
+\sqrt7}{4},\tfrac{1+\sqrt7}{4}\right),\, E\!\left(\tfrac{3}{4},\tfrac{4+\sqrt7}
{4}\right)$:

$$\sum x_i\,y_{i+1} - x_{i+1}\,y_i = 0 + 0 + \tfrac{1+\sqrt7}{4} + \tfrac{4+\sqr
t7}{4} + \tfrac{3}{4} = \tfrac{8+2\sqrt7}{4} = \tfrac{4+\sqrt7}{2}.$$

$$\boxed{\text{Area} = \frac{4+\sqrt{7}}{4}}.$$
