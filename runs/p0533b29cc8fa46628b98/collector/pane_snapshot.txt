## Solution

We compute $i^j$ where $i, j$ are the standard quaternion units satisfying $i^2
= j^2 = k^2 = ijk = -1$.

**Definition.** For quaternions, exponentiation with a quaternion exponent is de
fined via
$$a^b = e^{b \ln a},$$
using the principal branch of the quaternion logarithm.

**Step 1: Compute $\ln i$.**

For a quaternion $q = a + \vec{v}$ (with $\vec{v}$ the imaginary part), the prin
cipal logarithm is
$$\ln q = \ln|q| + \frac{\vec{v}}{|\vec{v}|}\arccos\!\left(\frac{a}{|q|}\right),
 \qquad q \neq -|q|.$$

For $q = i = 0 + 1\cdot i$: we have $a = 0$, $\vec{v} = i$, $|q| = 1$, $|\vec{v}
| = 1$, so
$$\ln i = \ln 1 + i\cdot\arccos(0) = 0 + i\cdot\frac{\pi}{2} = \frac{\pi}{2}\,i.
$$

**Step 2: Compute $j\ln i$.**

$$j \ln i = j\cdot\frac{\pi}{2}\,i = \frac{\pi}{2}\,(ji).$$

From the quaternion relations $ij = k$ and $ji = -k$, we get
$$j\ln i = \frac{\pi}{2}(-k) = -\frac{\pi}{2}\,k.$$

**Step 3: Compute $e^{-(\pi/2)k}$.**

The quaternion exponential of a pure imaginary $\theta\, u$ (with $u$ a unit ima
ginary quaternion) is
$$e^{\theta u} = \cos\theta + u\sin\theta.$$

Here $\theta = -\pi/2$ and $u = k$, so
$$e^{-(\pi/2)k} = \cos\!\left(-\frac{\pi}{2}\right) + k\sin\!\left(-\frac{\pi}{2
}\right) = 0 + k(-1) = -k.$$

**Conclusion.**

$$i^j = e^{j\ln i} = e^{-(\pi/2)k} = \boxed{-k}.$$
