## Solution

We analyze $f(a) = \sum_{k=2}^{\infty} e^{-a^2 k}\, k^{-3/2}$ as $a \to 0^+$.

**Step 1: Identify $f(0)$.** As $a \to 0$, $e^{-a^2 k} \to 1$, so
$$f(0) = \sum_{k=2}^{\infty} k^{-3/2} = \zeta(3/2) - 1,$$
which converges since $3/2 > 1$.

**Step 2: The deficit.** We study
$$D(a) := f(0) - f(a) = \sum_{k=2}^{\infty} (1 - e^{-a^2 k})\, k^{-3/2}.$$

**Step 3: Upper bound $D(a) = O(a)$.** Using $1 - e^{-x} \le \min(x, 1)$, set $N
 = \lfloor 1/a^2 \rfloor$ and split:

- For $2 \le k \le N$: $1 - e^{-a^2 k} \le a^2 k$, giving
$$\sum_{k=2}^{N} a^2 k \cdot k^{-3/2} = a^2 \sum_{k=2}^{N} k^{-1/2} \le a^2 \cdo
t 2\sqrt{N} \le 2a^2 \cdot a^{-1} = 2a.$$

- For $k > N$: $1 - e^{-a^2 k} \le 1$, giving
$$\sum_{k>N} k^{-3/2} \le \int_N^{\infty} x^{-3/2}\,dx = 2 N^{-1/2} \le 2a.$$

Hence $D(a) \le 4a$, so $D(a) = O(a)$.

**Step 4: Lower bound $D(a) = \Omega(a)$, establishing $\delta = 1$.** For small
 $a$ and $k \le N$, $1 - e^{-a^2 k} \ge \tfrac{1}{2} a^2 k$ (since $a^2 k \le 1$
). Thus
$$D(a) \ge \sum_{k=2}^{N} \tfrac{1}{2} a^2 k \cdot k^{-3/2} = \tfrac{a^2}{2} \su
m_{k=2}^{N} k^{-1/2} \ge \tfrac{a^2}{2} \int_1^{N} x^{-1/2}\,dx = a^2(\sqrt{N}-1
) \sim a.$$

So $D(a) = \Theta(a)$, confirming the leading order is exactly $a^1$.

**Step 5: Sharp constant via Mellin/polylogarithm expansion.** Write $t = a^2$ a
nd use $1 - e^{-tk} = \int_0^t k\, e^{-sk}\, ds$:
$$D(a) = \int_0^t \sum_{k=1}^{\infty} k^{-1/2} e^{-sk}\, ds + O(t) = \int_0^t \o
peratorname{Li}_{1/2}(e^{-s})\, ds + O(t),$$
where the $O(t)$ accounts for the $k=1$ term difference. The standard expansion
as $s \to 0^+$ is
$$\operatorname{Li}_{1/2}(e^{-s}) = \Gamma(1/2)\, s^{-1/2} + \zeta(1/2) + O(s) =
 \sqrt{\pi}\, s^{-1/2} + \zeta(1/2) + O(s).$$
Integrating from $0$ to $t$:
$$D(a) = 2\sqrt{\pi}\, t^{1/2} + \zeta(1/2)\, t + O(t^2) = 2\sqrt{\pi}\, a + \ze
ta(1/2)\, a^2 + O(a^4).$$

**Conclusion.** The leading-order deficit is
$$f(0) - f(a) \sim 2\sqrt{\pi}\, a \quad (a \to 0^+),$$
so $f(a) = f(0) - O(a^\delta)$ with

$$\boxed{\delta = 1}.$$
