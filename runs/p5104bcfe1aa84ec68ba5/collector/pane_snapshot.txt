## Proof

**Lower bound.** By the Cauchy–Schwarz inequality (or AM-HM),
$$(a+b+c)\left(\frac{1}{a}+\frac{1}{b}+\frac{1}{c}\right) \geq \frac{(a+b+c)^2}{
a+b+c} \cdot 3 = 9,$$
wait — more precisely, by Cauchy–Schwarz: $(a+b+c)\left(\frac{1}{a}+\frac{1}{b}+
\frac{1}{c}\right) \geq (1+1+1)^2 = 9$, with equality iff $a = b = c$. The equil
ateral triangle $a = b = c$ satisfies both triangle conditions, so $9$ is achiev
ed.

**Upper bound.** The expression is scale-invariant, so we may normalize. Assume
WLOG that $a \leq b \leq c$ and set $a = 1$. The triangle conditions become:

1. **Triangle inequality:** $1 + b > c$ (the binding constraint with $a \leq b \
leq c$).
2. **Reciprocal triangle inequality:** $\frac{1}{b} + \frac{1}{c} > \frac{1}{a}
= 1$, i.e., $b + c > bc$.
3. **Ordering:** $1 \leq b \leq c$.

Set $p = b + c$ and $q = bc$. Then:
$$S = (1+b+c)\left(1+\frac{1}{b}+\frac{1}{c}\right) = (1+p)\cdot\frac{q+p}{q}.$$

The constraints translate to:
- $p \geq 2$ (since $b \geq 1, c \geq b$),
- $q \geq p - 1$ (from $b \geq 1$: the smaller root of $t^2 - pt + q = 0$ is $\g
eq 1$),
- $q > \frac{p^2 - 1}{4}$ (from $c < 1 + b$, i.e., $(c-b)^2 < 1$, i.e., $p^2 - 4
q < 1$),
- $q < p$ (from $b + c > bc$, i.e., $p > q$),
- $q \leq \frac{p^2}{4}$ (discriminant non-negative, always satisfied given the
above).

**Key observation:** For fixed $p$, $S = (1+p)(q+p)/q$ is strictly decreasing in
 $q$, since
$$\frac{\partial S}{\partial q} = (1+p)\cdot\frac{q - (q+p)}{q^2} = -\frac{p(1+p
)}{q^2} < 0.$$

Thus $S$ is maximized when $q$ is minimized. The lower bound on $q$ is:
$$q_{\min} = \max\!\left(p - 1,\; \frac{p^2-1}{4}\right).$$

Comparing: $p - 1 \geq \frac{p^2-1}{4} \iff (p-1)(p-3) \leq 0 \iff 1 \leq p \leq
 3$.

**Case 1: $2 \leq p \leq 3$.** Here $q_{\min} = p - 1$ (and $\frac{p^2-1}{4} \le
q p-1$, so the strict inequality $q > \frac{p^2-1}{4}$ is satisfied). As $q \to
(p-1)^+$:
$$S \to \frac{(1+p)(2p-1)}{p-1} = 2p + 3 + \frac{2}{p-1} \triangleq f(p).$$
Then $f'(p) = 2 - \frac{2}{(p-1)^2}$, which vanishes at $p = 2$ (a minimum, $f(2
) = 9$). Since $f$ is convex ($f'' > 0$), the maximum on $[2,3]$ is at the endpo
ints: $f(2) = 9$ and $f(3) = 10$. So $S < 10$ in this range (the boundary values
 correspond to degenerate triangles and are not achieved).

**Case 2: $3 < p < 2 + \sqrt{5}$.** Here $q_{\min} = \frac{p^2-1}{4}$ (with the
strict inequality $q > \frac{p^2-1}{4}$). The upper limit $p < 2 + \sqrt{5}$ com
es from requiring $q_{\min} < p$, i.e., $\frac{p^2-1}{4} < p \iff p^2 - 4p - 1 <
 0 \iff p < 2 + \sqrt{5}$.

As $q \to \frac{p^2-1}{4}^+$:
$$S \to \frac{(1+p)\left(p + \frac{p^2-1}{4}\right)}{\frac{p^2-1}{4}} = \frac{(1
+p)\cdot\frac{p^2+4p-1}{4}}{\frac{(p-1)(p+1)}{4}} = \frac{p^2+4p-1}{p-1} = p + 5
 + \frac{4}{p-1} \triangleq g(p).$$

Then $g'(p) = 1 - \frac{4}{(p-1)^2}$. For $p > 3$, $(p-1)^2 > 4$, so $g'(p) > 0$
: $g$ is strictly increasing on $(3, 2+\sqrt{5})$.

At $p \to 3^+$: $g(3) = 3 + 5 + 2 = 10$ (consistent with Case 1).

At $p \to (2+\sqrt{5})^-$:
$$g(2+\sqrt{5}) = (2+\sqrt{5}) + 5 + \frac{4}{1+\sqrt{5}} = 7 + \sqrt{5} + \frac
{4(\sqrt{5}-1)}{(\sqrt{5}+1)(\sqrt{5}-1)} = 7 + \sqrt{5} + \frac{4(\sqrt{5}-1)}{
4} = 7 + \sqrt{5} + \sqrt{5} - 1 = 6 + 2\sqrt{5}.$$

**The supremum is not achieved.** At $p = 2 + \sqrt{5}$ and $q = \frac{p^2-1}{4}
 = p$, both triangle inequalities become equalities simultaneously ($c = 1 + b$
and $b + c = bc$), yielding a degenerate triangle. For all valid (non-degenerate
) triangles, $S < 6 + 2\sqrt{5}$.

**The supremum is approached.** Taking $a = 1$, $b \to \phi^- = \frac{1+\sqrt{5}
}{2}^-$, $c \to \phi^{2-} = \frac{3+\sqrt{5}}{2}^-$ (with $c$ slightly less than
 $1 + b$ and $\frac{1}{b}+\frac{1}{c}$ slightly greater than $1$), both triangle
 inequalities are satisfied strictly, and $S \to 6 + 2\sqrt{5}$.

**Conclusion.** The expression satisfies $9 \leq (a+b+c)\left(\frac{1}{a}+\frac{
1}{b}+\frac{1}{c}\right) < 6 + 2\sqrt{5}$ for all valid triangles, with both bou
nds being tight (the lower bound is achieved at $a = b = c$; the upper bound is
the supremum, approached as both triangles become nearly degenerate). The maximu
m value $M$ such that the inequality holds is:

$$\boxed{M = 6 + 2\sqrt{5}}.$$
