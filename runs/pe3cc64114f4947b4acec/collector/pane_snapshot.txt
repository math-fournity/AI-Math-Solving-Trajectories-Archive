Looking at this problem, I need to find all integers $a \in [0, 400]$ such that
$x^4 - 6x^2 + 4 = \sin\frac{\pi a}{200} - 2[x^2]$ has exactly six roots.

## Setting Up the Substitution

Let $y = x^2 \geq 0$, and let $n = [y]$ (integer part), $t = \{y\} = y - n \in [
0,1)$. Each positive $y$-solution gives two $x$-roots ($\pm\sqrt{y}$); $y=0$ giv
es one root ($x=0$). Since $f(0) = 4$ and $\sin(\cdot) \in [-1,1]$, $y=0$ is nev
er a solution. So **exactly 6 roots requires exactly 3 distinct positive $y$-val
ues**.

The equation becomes $f(y) = \sin\frac{\pi a}{200}$, where:
$$f(y) = y^2 - 6y + 4 + 2[y] = (n-2)^2 + t^2 + (2n-6)t, \quad t \in [0,1)$$

## Analyzing Each Interval $[n, n+1)$

For each $n$, $g_n(t) = (n-2)^2 + t^2 + (2n-6)t$ is an upward parabola with vert
ex at $t^* = 3-n$:

| $n$ | Behavior on $[0,1)$ | Range |
|-----|---------------------|-------|
| 0 | decreasing (vertex at $t=3$) | $(-1, 4]$ |
| 1 | decreasing (vertex at $t=2$) | $(-2, 1]$ |
| 2 | decreasing (vertex at $t=1$) | $(-1, 0]$ |
| 3 | increasing (vertex at $t=0$) | $[1, 2)$ |
| $\geq 4$ | increasing | $[4, \infty)$ |

Since $c = \sin\frac{\pi a}{200} \in [-1, 1]$, only $n = 0, 1, 2, 3$ can contrib
ute solutions.

## Counting Solutions for Each $c \in [-1, 1]$

**$c \in (-1, 0]$:** One solution in each of $n=0$ (range $(-1,4]$ ✓), $n=1$ (ra
nge $(-2,1]$ ✓), $n=2$ (range $(-1,0]$ ✓). $n=3$: range $[1,2)$, no. **Total: 3
solutions → 6 roots. ✓**

$t^2=0 \Rightarrow t=0$ ✓. **Total: 3 solutions → 6 roots. ✓**

**$c \in (0,1)$:** Solutions in $n=0$ ✓ and $n=1$ ✓ only ($n=2$ range caps at 0,

## Determining Valid $a$ Values

We need $\sin\frac{\pi a}{200} \in (-1, 0] \cup \{1\}$.

**$\sin\frac{\pi a}{200} = 1$:** $\frac{\pi a}{200} = \frac{\pi}{2} + 2k\pi \Rig
htarrow a = 100 + 400k$. In $[0,400]$: $a = 100$.

**$\sin\frac{\pi a}{200} \in (-1, 0]$:** This requires $\frac{\pi a}{200} \in [\
pi, 2\pi]$ (i.e., $a \in [200, 400]$) excluding $\frac{3\pi}{2}$ (i.e., $a \neq
300$), plus $a = 0$ (where $\sin 0 = 0$).

So the valid values are: $a \in \{0\} \cup \{100\} \cup \big([200, 400] \setminu
s \{300\}\big)$.

## Computing the Sum

$$S = 0 + 100 + \sum_{a=200}^{299} a + \sum_{a=301}^{400} a$$

$$\sum_{a=200}^{299} a = \frac{100 \cdot (200+299)}{2} = 24950$$

$$\sum_{a=301}^{400} a = \frac{100 \cdot (301+400)}{2} = 35050$$

$$S = 100 + 24950 + 35050 = \boxed{60100}$$
