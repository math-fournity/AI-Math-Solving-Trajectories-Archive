## Proof

Let $R_n = \mathbb{C}[x_1, \ldots, x_n]$ with $n \geq 2$, and define
$$I = \bigcap_{c \in \mathbb{C}} \langle x_1 - c \rangle \subseteq R_n.$$

We claim $I = 0$.

**Characterizing membership.** A polynomial $f \in R_n$ belongs to $\langle x_1
- c \rangle$ if and only if $f = (x_1 - c)\, g_c$ for some $g_c \in R_n$, which
holds if and only if $f$ vanishes upon substituting $x_1 = c$, i.e.,
$$f(c,\, x_2, \ldots, x_n) = 0 \quad \text{in } \mathbb{C}[x_2, \ldots, x_n].$$
Thus
$$f \in I \iff f(c, x_2, \ldots, x_n) = 0 \text{ in } \mathbb{C}[x_2,\ldots,x_n]
 \text{ for every } c \in \mathbb{C}.$$

**Writing $f$ as a polynomial in $x_1$.** View $f$ as an element of $\mathbb{C}[
x_2, \ldots, x_n][x_1]$:
$$f = \sum_{i=0}^{d} a_i(x_2, \ldots, x_n)\, x_1^i, \qquad a_i \in \mathbb{C}[x_
2, \ldots, x_n].$$

The membership condition becomes: for every $c \in \mathbb{C}$,
$$\sum_{i=0}^{d} a_i(x_2, \ldots, x_n)\, c^i = 0 \quad \text{in } \mathbb{C}[x_2
, \ldots, x_n]. \tag{$\ast$}$$

**Using that $\mathbb{C}$ is infinite.** Fix any point $(b_2, \ldots, b_n) \in \
mathbb{C}^{n-1}$. Evaluating $(\ast)$ at $(x_2,\ldots,x_n) = (b_2,\ldots,b_n)$ g
ives a univariate polynomial in $c$:
$$p(c) = \sum_{i=0}^{d} a_i(b_2, \ldots, b_n)\, c^i \in \mathbb{C}[c]$$
that vanishes for **every** $c \in \mathbb{C}$. Since $\mathbb{C}$ is an infinit
e field, a univariate polynomial vanishing identically on $\mathbb{C}$ must be t
he zero polynomial. Hence
$$a_i(b_2, \ldots, b_n) = 0 \quad \text{for all } i = 0, \ldots, d.$$

**Concluding each $a_i = 0$.** The point $(b_2, \ldots, b_n) \in \mathbb{C}^{n-1
}$ was arbitrary, so each coefficient polynomial $a_i$ vanishes on all of $\math
bb{C}^{n-1}$. By the same argument (a polynomial over an infinite field vanishin
g at every point is the zero polynomial—applied inductively, or directly since $
\mathbb{C}^{n-1}$ is Zariski-dense in itself), we conclude
$$a_i = 0 \in \mathbb{C}[x_2, \ldots, x_n] \quad \text{for every } i.$$

Therefore $f = \sum_{i=0}^d a_i\, x_1^i = 0$.

**Conclusion.** Every $f \in I$ is the zero polynomial, so $I = 0$. $\blacksquar
