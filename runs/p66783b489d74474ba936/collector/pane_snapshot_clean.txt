## Solution

We count the number of ways to write 40 as a sum of **distinct positive odd numb
ers** — equivalently, the number of partitions of 40 into distinct odd parts.

### Setup

The available parts are the odd numbers $1, 3, 5, \dots, 39$. The generating fun
ction is
$$F(x)=\prod_{k=1}^{20}(1+x^{2k-1}),$$
and we seek $[x^{40}]\,F(x)$.

### Dynamic-programming computation

Let $A_m(n)$ = number of partitions of $n$ into distinct odd parts chosen from $
\{1,3,\dots,2m-1\}$. We use the recurrence
$$A_m(n)=A_{m-1}(n)+A_{m-1}(n-(2m-1)),$$
where the first term counts partitions not using part $2m-1$, and the second cou
nts those that do. Base case: $A_0(0)=1$, $A_0(n)=0$ for $n>0$.

I build the array up to $n=40$, adding one odd part at a time. After each step $
A_m(n)=A_{m-1}(n)+A_{m-1}(n-(2m-1))$.

**Verified checkpoints** (independent hand-enumeration confirms these):
- $A(10)=2$: $\{1,9\},\{3,7\}$. ✓
- $A(15)=4$: $\{15\},\{11,3,1\},\{9,5,1\},\{7,5,3\}$. ✓
- $A(20)=7$: $\{19,1\},\{17,3\},\{15,5\},\{13,7\},\{11,9\},\{11,5,3,1\},\{9,7,3,
1\}$. ✓

These match the DP values exactly, validating the recurrence and bookkeeping.
