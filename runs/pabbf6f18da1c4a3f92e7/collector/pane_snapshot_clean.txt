## 证明

**第一步：分析递推关系与不动点。**

递推关系为 $x_{n+1} = \frac{x_n^4+3}{4}$。计算 $x_{n+1}-1$：

$$x_{n+1}-1 = \frac{x_n^4+3}{4}-1 = \frac{x_n^4-1}{4} = \frac{(x_n-1)(x_n+1)(x_n
^2+1)}{4}.$$

由于 $x_1 = 2020 > 1$，每个因子均为正，因此 $x_{n+1} > x_n \gg 1$。序列严格递增
且发散至 $+\infty$（增长极快，因为 $x_{n+1} \sim x_n^4/4$）。

**第二步：寻找望远镜分解。**

考虑差值 $\frac{1}{x_n-1}-\frac{1}{x_{n+1}-1}$。利用第一步：

$$\frac{1}{x_{n+1}-1} = \frac{4}{(x_n-1)(x_n+1)(x_n^2+1)},$$

因此

$$\frac{1}{x_n-1}-\frac{1}{x_{n+1}-1} = \frac{1}{x_n-1}\cdot\frac{(x_n+1)(x_n^2+
1)-4}{(x_n+1)(x_n^2+1)}.$$

计算分子：

$$(x_n+1)(x_n^2+1)-4 = x_n^3+x_n^2+x_n+1-4 = x_n^3+x_n^2+x_n-3 = (x_n-1)(x_n^2+2
x_n+3),$$

其中最后一个等式通过综合除法或直接展开验证：

$$(x_n-1)(x_n^2+2x_n+3) = x_n^3+2x_n^2+3x_n - x_n^2-2x_n-3 = x_n^3+x_n^2+x_n-3.\
 \checkmark$$

因此

$$\frac{1}{x_n-1}-\frac{1}{x_{n+1}-1} = \frac{x_n^2+2x_n+3}{(x_n+1)(x_n^2+1)}.$$

**第三步：部分分式分解。**

将 $\frac{x^2+2x+3}{(x+1)(x^2+1)}$ 分解：

$$\frac{x^2+2x+3}{(x+1)(x^2+1)} = \frac{A}{x+1}+\frac{Bx+C}{x^2+1}.$$

求解 $A(x^2+1)+(Bx+C)(x+1) = x^2+2x+3$ 可得 $A+B=1$，$B+C=2$，$A+C=3$，解为 $A=1
$，$B=0$，$C=2$。因此

$$\frac{x_n^2+2x_n+3}{(x_n+1)(x_n^2+1)} = \frac{1}{x_n+1}+\frac{2}{x_n^2+1}.$$

结合第二步，我们得到了关键的恒等式：

$$\boxed{\frac{1}{x_n+1}+\frac{2}{x_n^2+1} = \frac{1}{x_n-1}-\frac{1}{x_{n+1}-1}
.}$$

**第四步：对 $y_n$ 进行求和与望远镜求和。**

$$y_n = \sum_{i=1}^{n}\left(\frac{1}{x_i+1}+\frac{2}{x_i^2+1}\right) = \sum_{i=1
}^{n}\left(\frac{1}{x_i-1}-\frac{1}{x_{i+1}-1}\right) = \frac{1}{x_1-1}-\frac{1}
{x_{n+1}-1}.$$

代入 $x_1 = 2020$：

$$y_n = \frac{1}{2019}-\frac{1}{x_{n+1}-1}.$$

**第五步：取极限。**

由于 $x_n \to \infty$，我们有 $\frac{1}{x_{n+1}-1} \to 0$。因此

$$\lim_{n\to\infty} y_n = \frac{1}{2019}.$$
