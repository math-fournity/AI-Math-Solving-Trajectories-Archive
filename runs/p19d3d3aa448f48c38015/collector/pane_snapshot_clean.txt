The statement is **false**.

**Counterexample.** Define $f:\mathbb{R}\to\mathbb{R}$ by
$$f(x)=\begin{cases}1,&x=0,\\0,&x\neq 0.\end{cases}$$

**$f$ is Borel measurable.** The set $\{x:f(x)\neq 0\}=\{0\}$ is a closed (hence
 Borel) subset of $\mathbb{R}$. Equivalently, for every open $U\subseteq\mathbb{
R}$, the preimage $f^{-1}(U)$ is either $\varnothing$, $\{0\}$, or $\mathbb{R}\s
etminus\{0\}$, all of which are Borel sets. Hence $f$ is Borel measurable.

**The integral condition holds.** For every $a<b$, the function $f$ differs from
 the zero function only on the singleton $\{0\}$, which has Lebesgue measure $0$
. A function that is zero except on a set of measure zero has Lebesgue integral
$0$ over any interval. Concretely, $f$ is bounded and equals $0$ a.e. on $[a,b]$
, so
$$\int_a^b f(x)\,dx = 0.$$

**Yet $f$ is not identically zero.** We have $f(0)=1\neq 0$.

**Conclusion.** The hypothesis $\int_a^b f(x)\,dx=0$ for all $a<b$ only forces $
f=0$ *almost everywhere* (this is the standard consequence of the Lebesgue diffe
rentiation theorem / the fact that the indefinite integral has derivative $f$ a.
e.). It does **not** force $f(x)=0$ at *every* point. A Borel measurable functio
n may be nonzero on any set of Lebesgue measure zero (such as a singleton, a cou
ntable set, or even an uncountable null set like the Cantor set) while still sat
isfying the integral condition. Therefore the statement is false.
