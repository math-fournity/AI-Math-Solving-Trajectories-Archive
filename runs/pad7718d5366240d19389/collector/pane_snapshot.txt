## Solution

We minimize $\int_0^1 f(x)^2\,dx$ subject to $\int_0^1 f(x)\,dx = 0$ and $\int_0
^1 x\,f(x)\,dx = 1$.

**Step 1: Candidate via Lagrange multipliers.** Introduce multipliers $-2\lambda
_0$ and $-2\lambda_1$ for the two constraints and consider the functional
$$\Phi[f] = \int_0^1 f^2\,dx - 2\lambda_0\int_0^1 f\,dx - 2\lambda_1\int_0^1 x\,
f\,dx.$$
The Euler–Lagrange (first variation) condition gives $2f - 2\lambda_0 - 2\lambda
_1 x = 0$, hence the extremal must be affine:
$$f(x) = \lambda_0 + \lambda_1 x.$$

**Step 2: Determine the multipliers from the constraints.**
$$\int_0^1(\lambda_0+\lambda_1 x)\,dx = \lambda_0 + \tfrac{\lambda_1}{2} = 0,$$
$$\int_0^1 x(\lambda_0+\lambda_1 x)\,dx = \tfrac{\lambda_0}{2} + \tfrac{\lambda_
1}{3} = 1.$$
From the first equation $\lambda_0 = -\lambda_1/2$. Substituting:
$$-\tfrac{\lambda_1}{4} + \tfrac{\lambda_1}{3} = \tfrac{\lambda_1}{12} = 1 \impl
ies \lambda_1 = 12,\quad \lambda_0 = -6.$$
So the candidate is
$$f_*(x) = 12x - 6.$$

Verification: $\int_0^1(12x-6)\,dx = 6-6 = 0$ ✓, and $\int_0^1 x(12x-6)\,dx = \i
nt_0^1(12x^2-6x)\,dx = 4-3 = 1$ ✓.

**Step 3: This is the global minimum (orthogonality argument).** Work in the Hil
bert space $L^2[0,1]$ with inner product $\langle f,g\rangle = \int_0^1 fg\,dx$.
 Let $V = \operatorname{span}\{1, x\}$. The candidate $f_* = 12x-6 \in V$ satisf
ies both constraints.

For any admissible $f$, write $f = f_* + h$ where $h = f - f_*$. Since both $f$
and $f_*$ satisfy the two linear constraints, $h$ satisfies
$$\langle h, 1\rangle = \int_0^1 h\,dx = 0, \qquad \langle h, x\rangle = \int_0^
1 x\,h\,dx = 0.$$
Thus $h \perp V$. In particular $h \perp f_*$ (since $f_* \in V$), so by the Pyt
hagorean theorem:
$$\int_0^1 f^2\,dx = \|f\|^2 = \|f_*\|^2 + \|h\|^2 \geq \|f_*\|^2,$$
with equality if and only if $h = 0$, i.e. $f = f_*$.

**Step 4: Compute the minimum value.**
$$\int_0^1 (12x-6)^2\,dx = \int_0^1 (144x^2 - 144x + 36)\,dx = 48 - 72 + 36 = 12
.$$

Therefore the minimum value is

$$\boxed{12}.$$
