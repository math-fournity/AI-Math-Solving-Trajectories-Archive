Looking at this problem, I need to find the smallest positive integer $n$ such t
hat $\sum_{k=2}^{2015}(-1)^{k}\binom{2015}{k}(n k^{2015}-1) \equiv 1 \pmod{2017}
$, where 2017 is prime.

## Proof

**Split the sum.** Let $S = \sum_{k=2}^{2015}(-1)^{k}\binom{2015}{k}(n k^{2015}-
1) = n\,A' - B'$, where
$$A' = \sum_{k=2}^{2015}(-1)^{k}\binom{2015}{k}k^{2015}, \qquad B' = \sum_{k=2}^
{2015}(-1)^{k}\binom{2015}{k}.$$

**Compute the full binomial sums ($k=0$ to $2015$).** Using the standard identit
y (via Stirling numbers of the second kind):
$$\sum_{k=0}^{m}(-1)^{k}\binom{m}{k}k^{j} = (-1)^{m}\, m!\, S(j,m),$$
with $j = m = 2015$ and $S(2015,2015)=1$:
$$A = \sum_{k=0}^{2015}(-1)^{k}\binom{2015}{k}k^{2015} = (-1)^{2015}\cdot 2015!
= -2015!.$$
Also $B = \sum_{k=0}^{2015}(-1)^{k}\binom{2015}{k} = (1-1)^{2015} = 0$.

**Subtract the $k=0$ and $k=1$ terms.**
- $B' = B - \underbrace{1}_{k=0} - \underbrace{(-1)\binom{2015}{1}}_{k=1} = 0 -
1 + 2015 = 2014$.
- $A' = A - \underbrace{0}_{k=0} - \underbrace{(-1)\binom{2015}{1}\cdot 1}_{k=1}
 = -2015! + 2015$.

So $S = n(-2015! + 2015) - 2014 \pmod{2017}$.

**Evaluate $2015! \pmod{2017}$ via Wilson's theorem.** Since $2017$ is prime, $2
016! \equiv -1 \pmod{2017}$. As $2016! = 2016 \cdot 2015!$ and $2016 \equiv -1 \
pmod{2017}$:
$$(-1)\cdot 2015! \equiv -1 \pmod{2017} \implies 2015! \equiv 1 \pmod{2017}.$$

**Substitute.** Then $-2015! + 2015 \equiv -1 + 2015 = 2014 \equiv -3 \pmod{2017
}$, giving:
$$S \equiv -3n - 2014 \pmod{2017}.$$

**Solve the congruence.** Setting $S \equiv 1$:
$$-3n - 2014 \equiv 1 \pmod{2017} \implies -3n \equiv 2015 \equiv -2 \pmod{2017}
 \implies 3n \equiv 2 \pmod{2017}.$$

**Find $3^{-1} \pmod{2017}$.** Since $2017 = 3\cdot 672 + 1$, we get $3\cdot(-67
2)\equiv 1\pmod{2017}$, so $3^{-1}\equiv -672 \equiv 1345 \pmod{2017}$ (check: $
3\times 1345 = 4035 = 2\cdot 2017 + 1$ ✓).

Therefore:
$$n \equiv 2 \cdot 1345 = 2690 \equiv 2690 - 2017 = 673 \pmod{2017}.$$

**Verification.** $3 \times 673 = 2019 = 2017 + 2 \equiv 2 \pmod{2017}$. ✓

Since $0 < 673 < 2017$, the smallest positive integer is $\boxed{673}$.
