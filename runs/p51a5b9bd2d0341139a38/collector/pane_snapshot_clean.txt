## Solution

**Setup.** Triangle $ABC$ with $AB=5$, $BC=7$, $AC=3$. By the Law of Cosines:
$$\cos A = \frac{AB^2+AC^2-BC^2}{2\cdot AB\cdot AC} = \frac{25+9-49}{30} = -\fra
c12,$$
so $\angle A = 120°$. The angle bisector of $A$ splits it into two $60°$ angles.

**Coordinates.** Place $A=(0,0)$ with the angle bisector along the $x$-axis:
$$B = \left(\tfrac52,\;\tfrac{5\sqrt3}{2}\right),\qquad C = \left(\tfrac32,\;-\t
frac{3\sqrt3}{2}\right).$$
Check: $|BC|^2 = 1^2 + (4\sqrt3)^2 = 49$. ✓

**Point $D$.** By the angle-bisector theorem $BD:DC = 5:3$, so $BD = \tfrac{35}{
8}$. Parametrize $BC$ and set $y=0$: $t=\tfrac58$, giving $D = \left(\tfrac{15}{
8},\,0\right)$.

**Circumcircle $\omega$.** Writing $x^2+y^2+Dx+Ey=0$ (since $A$ is on it) and so
lving from $B,C$:
$$\omega:\; x^2+y^2 - 8x - \tfrac{2\sqrt3}{3}\,y = 0,\quad O=\left(4,\tfrac{\sqr
t3}{3}\right),\; R^2=\tfrac{49}{3}.$$

**Point $E$.** Setting $y=0$: $x(x-8)=0$, so $E=(8,0)$ (the second intersection)
.

**Circle $\gamma$ (diameter $DE$).** Center $\left(\tfrac{79}{16},0\right)$, rad
ius $\tfrac{49}{16}$, giving:
$$\gamma:\; x^2+y^2 - \tfrac{79}{8}x + 15 = 0.$$

**Radical axis.** $\omega - \gamma$:
$$\tfrac{15}{8}x - \tfrac{2\sqrt3}{3}y - 15 = 0 \;\;\Longrightarrow\;\; y = \tfr
ac{15\sqrt3}{16}(x-8).$$

**Point $F$.** Substituting into $\omega$ and simplifying (multiply by 256):
$$931\,x^2 - 13328\,x + 47040 = 0.$$
Since $x=8$ (point $E$) is a root, factoring gives $(x-8)(931x - 5880)=0$, so
$$x_F = \frac{5880}{931} = \frac{120}{19},\qquad y_F = \frac{15\sqrt3}{16}\!\lef
t(\frac{120}{19}-8\right) = -\frac{30\sqrt3}{19}.$$

**Computing $AF^2$:**
$$AF^2 = \left(\frac{120}{19}\right)^2 + \left(\frac{30\sqrt3}{19}\right)^2 = \f
rac{14400+2700}{361} = \frac{17100}{361} = \frac{900}{19}.$$

With $\gcd(900,19)=1$, we have $m=900$, $n=19$, and
$$m+n = \boxed{919}.$$

### PROOF COMPLETE
