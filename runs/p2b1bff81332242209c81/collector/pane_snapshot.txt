## Proof

We evaluate $I = \int_0^\infty x^n \sin(2\pi \ln x)\, e^{-\ln^2 x}\, dx$ for int
eger $n$.

**Substitution.** Let $u = \ln x$, so $x = e^u$, $dx = e^u\, du$. The limits $x:
 0 \to \infty$ become $u: -\infty \to \infty$. Then

$$I = \int_{-\infty}^{\infty} e^{nu}\, \sin(2\pi u)\, e^{-u^2}\, e^{u}\, du = \i
nt_{-\infty}^{\infty} e^{(n+1)u - u^2}\, \sin(2\pi u)\, du.$$

**Complete the square.** Since $(n+1)u - u^2 = -\bigl(u - \tfrac{n+1}{2}\bigr)^2
 + \tfrac{(n+1)^2}{4}$,

$$I = e^{(n+1)^2/4} \int_{-\infty}^{\infty} e^{-(u - \frac{n+1}{2})^2}\, \sin(2\
pi u)\, du.$$

**Shift the variable.** Let $v = u - \tfrac{n+1}{2}$, so $u = v + \tfrac{n+1}{2}
$:

$$I = e^{(n+1)^2/4} \int_{-\infty}^{\infty} e^{-v^2}\, \sin\!\Bigl(2\pi v + \pi(
n+1)\Bigr)\, dv.$$

**Expand the sine.** Using the angle-addition formula,

$$\sin\!\bigl(2\pi v + \pi(n+1)\bigr) = \sin(2\pi v)\cos\!\bigl(\pi(n+1)\bigr) +
 \cos(2\pi v)\sin\!\bigl(\pi(n+1)\bigr).$$

Hence

$$I = e^{(n+1)^2/4}\left[\cos\!\bigl(\pi(n+1)\bigr)\underbrace{\int_{-\infty}^{\
infty} e^{-v^2}\sin(2\pi v)\,dv}_{J_1} + \sin\!\bigl(\pi(n+1)\bigr)\underbrace{\
int_{-\infty}^{\infty} e^{-v^2}\cos(2\pi v)\,dv}_{J_2}\right].$$

**Evaluate $J_1$.** The function $e^{-v^2}\sin(2\pi v)$ is odd (even × odd), and
 the domain $(-\infty, \infty)$ is symmetric, so

$$J_1 = 0.$$

**Evaluate $J_2$.** This is the Fourier transform of a Gaussian at frequency $2\
pi$:

$$J_2 = \int_{-\infty}^{\infty} e^{-v^2}\cos(2\pi v)\, dv = \sqrt{\pi}\, e^{-\pi
^2}.$$

(This follows from $\int_{-\infty}^{\infty} e^{-v^2}e^{i\omega v}dv = \sqrt{\pi}
\,e^{-\omega^2/4}$ with $\omega = 2\pi$, taking the real part.)

**Combine.** Therefore

$$I = e^{(n+1)^2/4}\, \sin\!\bigl(\pi(n+1)\bigr)\, \sqrt{\pi}\, e^{-\pi^2}.$$

**Integer $n$.** For integer $n$, we have $n+1 \in \mathbb{Z}$, so $\sin(\pi(n+1
)) = 0$. Consequently every factor $\sin(\pi(n+1))$ vanishes, and

$$\boxed{I = 0.}$$

### PROOF COMPLETE
