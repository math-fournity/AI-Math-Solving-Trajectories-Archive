# Cogrowth and Amenability

## Answer

**Condition:** A finitely generated group $\Lambda$ with finite symmetric genera
ting set $S$ (i.e., $S = S^{-1}$, $e \notin S$) is amenable if and only if its c
ogrowth rate $\gamma_S$ equals $|S|$, the cardinality of the generating set. Equ
ivalently, amenability holds precisely when the cogrowth achieves its maximal po
ssible value.

**Dependence on $S$:** The condition does **not** depend on the choice of genera
ting set. The equivalence "$\Lambda$ amenable $\iff$ $\gamma_S = |S|$" holds for
 every finite symmetric generating set $S$, so the condition is satisfied for al
l $S$ or for none.

---

## Proof

### Setup and Definitions

Let $\Lambda$ be a finitely generated group and $S$ a finite symmetric generatin
g set ($S = S^{-1}$, $e \notin S$) with $|S| = n \geq 2$.

**Cogrowth.** Define $a_k$ to be the number of words of length $k$ in the alphab
et $S$ that represent the identity in $\Lambda$:
$$a_k = \left|\left\{(s_1, \ldots, s_k) \in S^k : s_1 s_2 \cdots s_k = e \text{
in } \Lambda\right\}\right|.$$
The **cogrowth rate** is:
$$\gamma_S = \limsup_{k \to \infty} a_k^{1/k}.$$
Since $a_k \leq n^k$, we have $\gamma_S \leq n$.

**Random walk.** Consider the simple random walk on the Cayley graph $\mathrm{Ca
y}(\Lambda, S)$: from vertex $g$, the walk moves to $gs$ for a uniformly chosen
$s \in S$. The return probability to the identity after $k$ steps is:
$$p_k = p^{(k)}(e, e) = \frac{a_k}{n^k}.$$

### Step 1: Spectral Radius and Cogrowth

The Markov operator $M: \ell^2(\Lambda) \to \ell^2(\Lambda)$ is:
$$Mf(g) = \frac{1}{n}\sum_{s \in S} f(gs).$$
Since $S$ is symmetric, $M$ is self-adjoint. Each right-translation operator $R_
s f(g) = f(gs)$ is unitary on $\ell^2(\Lambda)$, and $M = \frac{1}{n}\sum_{s \in
 S} R_s$ is a convex combination of unitaries, so $\|M\| \leq 1$. Define the **s
pectral radius** $\rho = \|M\|_{\ell^2 \to \ell^2}$; then $0 < \rho \leq 1$.

The spectral measure $\mu$ of $\delta_e$ with respect to $M$ satisfies $p_k = \l
angle M^k \delta_e, \delta_e\rangle = \int_{-1}^{1} t^k\, d\mu(t)$. Since $M$ is
 self-adjoint, by standard spectral theory:
$$\rho = \sup\{|t| : t \in \mathrm{supp}(\mu)\} = \limsup_{k \to \infty} p_{2k}^
{1/(2k)}.$$
(For even moments, $p_{2k} = \int t^{2k}\,d\mu(t) \geq 0$, and the $\limsup$ of
the $2k$-th root equals the supremum of $|t|$ in the support.) Since $p_{2k+1} \
leq p_{2k}^{1/2} p_{2k+2}^{1/2}$ by Cauchy–Schwarz (or submultiplicativity of re
turn probabilities), the same limit governs all $k$, giving:
$$\rho = \limsup_{k \to \infty} p_k^{1/k} = \limsup_{k \to \infty} \left(\frac{a
_k}{n^k}\right)^{1/k} = \frac{\gamma_S}{n}.$$

### Step 2: Kesten's Amenability Criterion

**Kesten's Theorem (1959).** $\Lambda$ is amenable if and only if $\rho = 1$.

*Proof of ($\Rightarrow$):* Suppose $\Lambda$ is amenable. Let $\{F_m\}$ be a Fø
lner sequence: finite sets with $|s F_m \triangle F_m|/|F_m| \to 0$ for each $s
\in S$. Set $f_m = \mathbf{1}_{F_m}/\sqrt{|F_m|} \in \ell^2(\Lambda)$, so $\|f_m
\|_2 = 1$. Then:
$$\|Mf_m - f_m\|_2^2 = \frac{1}{n^2}\sum_{s \in S} \frac{|sF_m \triangle F_m|}{|
F_m|} \to 0.$$
So $1$ is in the approximate point spectrum of $M$, hence $\rho = \|M\| \geq 1$.
 Combined with $\rho \leq 1$, we get $\rho = 1$.

*Proof of ($\Leftarrow$):* Suppose $\rho = 1$. Then for every $\varepsilon > 0$
there exists $f \in \ell^2(\Lambda)$, $\|f\|_2 = 1$, with $\|Mf\|_2 > 1 - \varep
silon$. This means:
$$\|Mf\|_2^2 = \frac{1}{n^2}\sum_{s \in S} \|R_s f\|_2^2 + \frac{2}{n^2}\sum_{s
< t} \langle R_s f, R_t f\rangle > (1-\varepsilon)^2.$$
Since each $\|R_s f\|_2 = 1$, the deficit $\|Mf\|_2^2 \leq 1$ comes entirely fro
m the cross terms. A careful estimate (using that $\|Mf\|_2^2 \leq \frac{1}{n}\s
um_s \|R_s f\|_2^2 = 1$ with equality iff all $R_s f$ are parallel) shows that $
\|R_s f - f\|_2$ must be small for all $s$. Concretely, from $\|Mf - f\|_2 < \va
repsilon' $ (which follows from $\|Mf\|_2$ close to $1$ and a polarization argum
ent), one extracts a Følner set by taking $F = \{g : |f(g)| \geq \eta\}$ for sui
table $\eta > 0$. Standard arguments (cf. Kesten 1959, or Day 1961) then yield a
 Følner sequence, proving amenability.

### Step 3: Combining Steps 1 and 2

From Step 1, $\rho = \gamma_S / n$. From Step 2, $\Lambda$ is amenable $\iff$ $\
rho = 1$. Therefore:
$$\boxed{\Lambda \text{ is amenable} \iff \frac{\gamma_S}{n} = 1 \iff \gamma_S =
 |S|.}$$

That is, $\Lambda$ is amenable if and only if its cogrowth rate equals the size
of the generating set — equivalently, the cogrowth is **maximal** (since $\gamma
_S \leq |S|$ always).

### Step 4: Independence from the Generating Set

Amenability is an intrinsic property of the group $\Lambda$, defined without ref
erence to any generating set (e.g., via the existence of a left-invariant finite
ly additive probability measure on $\Lambda$, or equivalently via the Følner con
dition on subsets of $\Lambda$).

Let $S_1, S_2$ be any two finite symmetric generating sets for $\Lambda$. By the
 theorem above:
$$\gamma_{S_1} = |S_1| \iff \Lambda \text{ is amenable} \iff \gamma_{S_2} = |S_2
|.$$

Hence the cogrowth condition $\gamma_S = |S|$ holds for **every** finite symmetr
ic generating set $S$ when $\Lambda$ is amenable, and for **no** such $S$ when $
\Lambda$ is not amenable. The condition is therefore independent of the choice o
f $S$.

**Remark.** While the numerical value of $\gamma_S$ and the value $|S|$ individu
ally depend on $S$, the *boolean condition* "$\gamma_S$ achieves its upper bound
 $|S|$" does not. This is consistent with the fact that amenability is a quasi-i
sometry invariant (and changing the generating set yields quasi-isometric Cayley
 graphs), so any condition equivalent to amenability must be invariant under suc
h changes. $\blacksquare$
