## Solution

The sum is:
$$S = \sum_{\substack{n=1\\n\text{ odd}}}^{\infty} \frac{n}{2^n} + \sum_{\substa
ck{n=2\\n\text{ even}}}^{\infty} \frac{n}{3^n}$$

**Even part.** Setting $n=2k$:
$$S_{\text{even}} = \sum_{k=1}^{\infty} \frac{2k}{3^{2k}} = 2\sum_{k=1}^{\infty}
 k\left(\tfrac{1}{9}\right)^k$$
Using $\sum_{k=1}^{\infty} kx^k = \frac{x}{(1-x)^2}$ with $x=\tfrac{1}{9}$:
$$S_{\text{even}} = 2\cdot\frac{1/9}{(8/9)^2} = 2\cdot\frac{1/9}{64/81} = 2\cdot
\frac{81}{576} = 2\cdot\frac{9}{64} = \frac{9}{32}$$

**Odd part.** Setting $n=2k-1$, and noting $2^{2k-1}=4^k/2$:
$$S_{\text{odd}} = \sum_{k=1}^{\infty} \frac{2k-1}{2^{2k-1}} = 2\sum_{k=1}^{\inf
ty}(2k-1)\left(\tfrac{1}{4}\right)^k = 2\left[2\sum_{k=1}^{\infty}k\left(\tfrac{
1}{4}\right)^k - \sum_{k=1}^{\infty}\left(\tfrac{1}{4}\right)^k\right]$$
Using the same identity with $x=\tfrac{1}{4}$:
$$\sum k\left(\tfrac{1}{4}\right)^k = \frac{1/4}{(3/4)^2} = \frac{4}{9}, \qquad
\sum\left(\tfrac{1}{4}\right)^k = \frac{1/4}{3/4} = \frac{1}{3}$$
$$S_{\text{odd}} = 2\left[2\cdot\frac{4}{9} - \frac{1}{3}\right] = 2\left[\frac{
8}{9}-\frac{3}{9}\right] = 2\cdot\frac{5}{9} = \frac{10}{9}$$

**Total.**
$$S = \frac{10}{9} + \frac{9}{32} = \frac{320}{288} + \frac{81}{288} = \frac{401
}{288}$$

**Coprimality check.** $288 = 2^5\cdot 3^2$. Testing $401$ for divisibility by p
rimes up to $\sqrt{401}\approx 20$: $401$ is odd, $4+0+1=5$ (not divisible by $3
$), not divisible by $5,7,11,13,17,19$. So $401$ is prime, hence $\gcd(401,288)=
1$.

Thus $a=401$, $b=288$, and
$$a+b = 401+288 = \boxed{689}$$
