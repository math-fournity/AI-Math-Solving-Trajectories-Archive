## Solution

**Substitution.** Let $x = \sin^2\theta$ with $\theta \in [0, \pi/2]$. Then
$$f(x) = 4\sin^2\theta\cos^2\theta = \sin^2(2\theta).$$
By induction, $f^{n}(x) = \sin^2(2^n\theta)$. Hence $f^{1992}(x)=x$ becomes
$$\sin^2(2^{1992}\theta)=\sin^2\theta.$$

**Solving the trigonometric equation.** Since $\sin^2 A = \sin^2 B \iff A = \pm
B + m\pi$ for some $m\in\mathbb{Z}$, we get two families:

- **Case 1:** $(2^{1992}-1)\theta = m\pi$, i.e. $\theta = \dfrac{k\pi}{2^{1992}-
1}$.
- **Case 2:** $(2^{1992}+1)\theta = m\pi$, i.e. $\theta = \dfrac{k\pi}{2^{1992}+
1}$.

Let $a = 2^{1992}$, $N = a-1$, $N' = a+1$ (both odd).

**Counting distinct $x$-values in Case 1.** $x = \sin^2(k\pi/N)$. Since $\sin^2(
k\pi/N)=\sin^2((N-k)\pi/N)$, the values $k=1,\dots,N-1$ pair up into $(N-1)/2$ p
airs, and $k=0$ gives $x=0$. So
$$|A| = 1 + \frac{N-1}{2} = \frac{N+1}{2} = \frac{a}{2} = 2^{1991}.$$

**Counting distinct $x$-values in Case 2.** $x = \sin^2(k\pi/N')$. Here $k=0$ an
d $k=N'$ both give $x=0$; $k=1,\dots,N'-1$ pair up into $(N'-1)/2 = a/2 = 2^{199
1}$ pairs. So
$$|B| = 1 + 2^{1991} = 2^{1991}+1.$$

**The two sets intersect only at $\{0\}$.** Suppose $\sin^2(k\pi/N)=\sin^2(\ell\
pi/N')$ with $x\neq 0$. Then
$$\frac{k}{N} = \pm\frac{\ell}{N'} + m \quad\Longrightarrow\quad k(a+1) \mp \ell
(a-1) = m(a-1)(a+1).$$
Since $\gcd(a-1,a+1)=\gcd(a-1,2)=2$, from $(a+1)\mid \ell(a-1)$ we get $(a+1)/2
\mid \ell$, so $\ell = s(a+1)/2$ with $s$ even (write $s=2t$, giving $\ell = t(a
+1)$) for $k$ to be integral. Then
$$x = \sin^2\!\Big(\frac{\ell\pi}{a+1}\Big) = \sin^2(t\pi) = 0,$$
contradicting $x\neq 0$. Hence $A\cap B = \{0\}$.

**Total.**
$$|A\cup B| = |A|+|B|-|A\cap B| = 2^{1991} + (2^{1991}+1) - 1 = 2^{1992}.$$

**Verification with $n=1$:** $f(x)=x \Rightarrow x=0,\tfrac34$ — that's $2=2^1$.
