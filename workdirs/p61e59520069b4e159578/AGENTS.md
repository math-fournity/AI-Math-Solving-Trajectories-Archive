# Problem

A high-tech research facility features a circular particle accelerator ring with 100 designated sensor stations installed along its perimeter. These stations are uniquely identified by ID numbers 1 through 100, though the IDs were assigned to the physical locations in a completely arbitrary, non-sequential order.

The facility tracks "Synchronized Triplets." A Synchronized Triplet is defined as a set of three sensors with ID numbers $i$, $j$, and $k$ (where $i < j < k$) such that if you travel clockwise around the ring starting from sensor $i$, you encounter sensor $j$ first and then sensor $k$ before returning to $i$.

Let $T(100)$ be the set containing every possible total count of Synchronized Triplets that could exist depending on how the ID numbers were distributed around the ring.

Consider the subset $S$ which contains all values $x$ within $T(100)$ such that $x$ is an odd number and falls within the range $2010 \le x \le 2020$. What is the sum of all elements in $S$?
