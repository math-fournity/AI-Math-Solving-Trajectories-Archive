## Proof

Let $K = \mathbb{Q}[i\sqrt{3}]$. Since $i\sqrt{3}$ is algebraic over $\mathbb{Q}
$ (it is a root of $x^2 + 3$), the ring $\mathbb{Q}[i\sqrt{3}]$ coincides with t
he field $\mathbb{Q}(i\sqrt{3}) = \mathbb{Q}(\sqrt{-3})$. Concretely,

$$K = \{\, a + b\,\sqrt{-3} : a, b \in \mathbb{Q}\,\},$$

with $(\sqrt{-3})^2 = -3$. We seek all **field endomorphisms** $\varphi : K \to
K$ (ring homomorphisms with $\varphi(1)=1$).

---

**Step 1. $\varphi$ fixes $\mathbb{Q}$ pointwise.**

Since $\varphi(1)=1$, by additivity $\varphi(n)=n$ for every $n\in\mathbb{Z}$, a
nd by multiplicativity $\varphi(p/q)=\varphi(p)\varphi(q)^{-1}=p/q$ for every $p
/q\in\mathbb{Q}$. Hence $\varphi|_{\mathbb{Q}} = \mathrm{id}_{\mathbb{Q}}$.

---

**Step 2. $\varphi$ is determined by $\varphi(\sqrt{-3})$.**

Every element of $K$ is $a + b\sqrt{-3}$ with $a,b\in\mathbb{Q}$, so

$$\varphi(a + b\sqrt{-3}) = \varphi(a) + \varphi(b)\,\varphi(\sqrt{-3}) = a + b\
,\varphi(\sqrt{-3}).$$

Thus $\varphi$ is completely determined by the single value $\varphi(\sqrt{-3})\
in K$.

---

**Step 3. The constraint on $\varphi(\sqrt{-3})$.**

Since $(\sqrt{-3})^2 = -3$, applying $\varphi$ gives

$$\varphi(\sqrt{-3})^2 = \varphi(-3) = -3.$$

So we must find all $x \in K$ with $x^2 = -3$. Write $x = a + b\sqrt{-3}$, $a,b\
in\mathbb{Q}$. Then

$$x^2 = (a^2 - 3b^2) + 2ab\sqrt{-3}.$$

Setting $x^2 = -3 = -3 + 0\cdot\sqrt{-3}$ and comparing coefficients (using $\{1
,\sqrt{-3}\}$ as a $\mathbb{Q}$-basis, which is linearly independent):

$$a^2 - 3b^2 = -3, \qquad 2ab = 0.$$

From $2ab = 0$: either $a=0$ or $b=0$.

- **If $b = 0$**: then $a^2 = -3$, which has no solution in $\mathbb{Q}$. No sol
utions here.
- **If $a = 0$**: then $-3b^2 = -3$, so $b^2 = 1$, giving $b = \pm 1$. Thus $x =
 \pm\sqrt{-3}$.

So the only possibilities are $\varphi(\sqrt{-3}) = \sqrt{-3}$ or $\varphi(\sqrt
{-3}) = -\sqrt{-3}$.

---

**Step 4. Both possibilities give valid endomorphisms.**

- $\varphi(\sqrt{-3}) = \sqrt{-3}$ gives $\varphi(a+b\sqrt{-3}) = a + b\sqrt{-3}
$: the **identity** endomorphism.
- $\varphi(\sqrt{-3}) = -\sqrt{-3}$ gives $\varphi(a+b\sqrt{-3}) = a - b\sqrt{-3
}$: the **complex conjugation** endomorphism $\overline{\,\cdot\,}$.

Both are well-defined field homomorphisms $K\to K$ (they preserve addition and m
ultiplication, which is verified directly: conjugation distributes over $+$ and
$\cdot$ since $\overline{\sqrt{-3}}=-\sqrt{-3}}$ and $\overline{q}=q$ for $q\in\
mathbb{Q}$). Both are in fact automorphisms (each is its own inverse).

---

**Conclusion.**

The endomorphisms of $\mathbb{Q}[i\sqrt{3}]$ are exactly the **identity map** an
d **complex conjugation**:

$$\boxed{\mathrm{id} : a+b\sqrt{-3}\mapsto a+b\sqrt{-3}, \qquad \overline{\,\cdo
t\,} : a+b\sqrt{-3}\mapsto a-b\sqrt{-3}.}$$

These form the Galois group $\mathrm{Gal}(\mathbb{Q}(\sqrt{-3})/\mathbb{Q}) \con
g \mathbb{Z}/2\mathbb{Z}$, and there are no others.
