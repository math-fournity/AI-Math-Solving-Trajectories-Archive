**Theorem.** The set $\left\{\frac{\varphi(n)}{n} : n \in \mathbb{N} \setminus \
mathbb{P}^k\right\}$ is dense in $(0,1)$, where $\mathbb{P}^k$ is the set of pri
me powers.

**Proof.**

**Step 1 (Reformulation).** For $n > 1$ with prime factorization $n = \prod p_i^
{e_i}$, Euler's formula gives
$$\frac{\varphi(n)}{n} = \prod_{p \mid n}\left(1 - \frac{1}{p}\right),$$
which depends only on the set $S(n) = \{p : p \mid n\}$ of prime divisors. Obser
ve:
- $n = 1 \iff S(n) = \emptyset$, giving $\varphi(1)/1 = 1 \notin (0,1)$.
- $n > 1$ is a prime power $\iff |S(n)| = 1$.
- $n > 1$ is **not** a prime power $\iff |S(n)| \geq 2$.

Therefore
$$\left\{\frac{\varphi(n)}{n} : n \in \mathbb{N} \setminus \mathbb{P}^k\right\}
= \left\{\prod_{p \in S}\left(1-\frac{1}{p}\right) : S \subset \mathbb{P} \text{
 finite},\; |S| \geq 2\right\}.$$

**Step 2 (A density lemma for finite subsums).**

**Lemma.** Let $(b_n)_{n \geq 1}$ be a sequence with $b_n > 0$, $b_n \to 0$, and
 $\sum b_n = \infty$. Then the set of finite subsums $\left\{\sum_{n \in F} b_n
: F \subset \mathbb{N} \text{ finite}\right\}$ is dense in $[0, \infty)$.

*Proof of Lemma.* Let $x \geq 0$ and $\varepsilon > 0$. Choose $N$ so that $b_n
< \varepsilon$ for all $n \geq N$. Build a finite set $F$ greedily: set $s = 0$;
 for $n = N, N+1, N+2, \ldots$, add $n$ to $F$ (and set $s := s + b_n$) if $s +
b_n \leq x$, otherwise skip $n$.

If we never skip, then $s = \sum_{n \geq N} b_n = \infty > x$, contradicting $s
\leq x$ (maintained by the adding condition). So at some index $n_0$ we skip, me
aning $s + b_{n_0} > x$, i.e., $s > x - b_{n_0} > x - \varepsilon$. Since we onl
y added when the result was $\leq x$, we have $s \leq x$. Thus $x - \varepsilon
< s \leq x$, giving $|s - x| < \varepsilon$. $\square$

**Step 3 (The full set of finite products is dense).** For each prime $p$, set
$$a_p = -\log\!\left(1 - \frac{1}{p}\right) = \log\frac{p}{p-1} > 0.$$

We verify the lemma's hypotheses for $(a_p)$ enumerated over primes:
- **$a_p \to 0$:** Since $a_p = \log(1 + \frac{1}{p-1}) \sim \frac{1}{p} \to 0$.
- **$\sum_p a_p = \infty$:** Using the standard inequality $\log(1+x) \geq \frac
{x}{1+x}$ for $x > 0$ (from $\log(1+x) = \int_0^x \frac{dt}{1+t} \geq \frac{x}{1
+x}$), we get
$$a_p = \log\!\left(1 + \tfrac{1}{p-1}\right) \geq \frac{1/(p-1)}{1 + 1/(p-1)} =
 \frac{1}{p}.$$
Since $\sum_p \frac{1}{p} = \infty$ (Euler's divergence of the reciprocal sum of
 primes), we conclude $\sum_p a_p = \infty$.

By the Lemma, $\left\{\sum_{p \in S} a_p : S \subset \mathbb{P} \text{ finite}\r
ight\}$ is dense in $[0,\infty)$. Exponentiating (a continuous, strictly decreas
ing map from $[0,\infty)$ onto $(0,1]$):
$$D := \left\{\prod_{p \in S}\left(1 - \frac{1}{p}\right) : S \subset \mathbb{P}
 \text{ finite}\right\} \text{ is dense in } (0, 1].$$

In particular, $D$ is dense in $(0,1)$.

- $|S| = 1$: the set $A = \left\{1 - \frac{1}{p} : p \text{ prime}\right\} = \le

We claim $D \setminus A$ is dense in $(0,1)$. Let $x \in (0,1)$ and $\varepsilon

 (x - \delta,\, x + \delta)$ is **finite**: indeed, $1 - \frac{1}{p} \in (x-\del
ta, x+\delta)$ requires $\frac{1}{p} \in (1-x-\delta,\, 1-x+\delta)$, i.e., $p \
in \left(\frac{1}{1-x-\delta},\, \frac{1}{1-x+\delta}\right)$, a bounded interva
l containing finitely many primes.

Since $D$ is dense in $(0,1)$, every non-empty open subinterval of $(0,1)$ conta
ins **infinitely many** points of $D$ (if some open interval contained only fini
tely many, a sub-interval between consecutive points would be empty of $D$, cont
radicting density). In particular, $(x - \varepsilon,\, x + \varepsilon) \cap (0
,1)$ contains infinitely many points of $D$. Removing the finitely many points o

$$(D \setminus A) \cap (x - \varepsilon,\, x + \varepsilon) \neq \emptyset.$$

Since $x \in (0,1)$ and $\varepsilon > 0$ were arbitrary, $D \setminus A$ is den
