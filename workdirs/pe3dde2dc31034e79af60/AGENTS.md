# Problem

A specialized logistics network consists of several distribution hubs. Every hub in the network is directly connected to at least $m$ other hubs via two-way transit routes, where $m \geq 3$. The network is fully integrated, meaning it is possible to travel between any two hubs through some sequence of routes.

A courier company is attempting to design a "Grand Tour" for a new delivery drone. This tour must be a path that visits every single hub in the network exactly once. However, due to the specific layout of the connections, it is mathematically impossible to find such a path that includes every hub.

Based on these constraints, find the minimum possible number of distribution hubs that must exist in this network. (Your answer should be an expression in terms of $m$).
