Looking at this problem, I need to find all positive integers $n$ for which an $
n \times n$ integer matrix exists where every row's self-dot-product is even and
 every cross dot-product is odd.

**Answer: all odd positive integers $n$.**

## Proof

**Reduction to $\mathbb{F}_2$.** Since only parity matters, let $B = A \bmod 2$
be the matrix over $\mathbb{F}_2$. The conditions become:
- $(BB^T)_{ii} = 0$ for all $i$ (diagonal entries zero),
- $(BB^T)_{ij} = 1$ for all $i \neq j$ (off-diagonal entries one),

that is, $BB^T = J + I$ over $\mathbb{F}_2$, where $J$ is the all-ones matrix. A
ny such $B$ lifts to an integer matrix (using 0 and 1 as entries) satisfying the
 original conditions, since the dot products mod 2 match.

**Key observation.** Over $\mathbb{F}_2$, $x_i^2 = x_i$, so the self-dot-product
 of a row equals its Hamming weight mod 2. Thus every row of $B$ must have **eve
n weight**, meaning all rows lie in the even-weight subspace $W = \{v \in \mathb
b{F}_2^n : \sum v_i = 0\}$, which has dimension $n - 1$.

---

### Even $n \geq 2$ is impossible

When $n$ is even, $J + I$ is invertible over $\mathbb{F}_2$. Indeed, $(J+I)v = (
\mathbf{1}^T v)\mathbf{1} + v$, and the kernel satisfies $v = (\mathbf{1}^T v)\m
athbf{1}$; if $\mathbf{1}^T v = 0$ then $v = 0$, and if $\mathbf{1}^T v = 1$ the
n $v = \mathbf{1}$, but $\mathbf{1}^T \mathbf{1} = n \equiv 0 \neq 1$, so this i
s impossible. Hence $\ker(J+I) = \{0\}$, giving rank $n$.

But all rows of $B$ lie in $W$ (dimension $n-1$), so $\operatorname{rank}(B) \le
q n-1$, hence $\operatorname{rank}(BB^T) \leq n-1 < n = \operatorname{rank}(J+I)
$. **Contradiction.** So no even $n \geq 2$ works.

---

### Odd $n$ works

**Case $n = 1$:** The matrix $[0]$ works: the single self-dot-product is $0$ (ev
en), and there are no pairs of distinct rows.

**Case $n \geq 3$, $n$ odd — explicit construction:** Define the $n \times n$ ma
trix $B$ over $\mathbb{F}_2$ by:
- **Row $i$** ($1 \leq i \leq n-1$): has 1 in positions $1$ and $i+1$, and 0 els
ewhere. (So row $i = e_1 + e_{i+1}$, weight 2.)
- **Row $n$**: has 1 in positions $2, 3, \ldots, n$ and 0 in position 1. (So row
 $n = e_2 + e_3 + \cdots + e_n$, weight $n-1$.)

**Verification of diagonal (self-dot-products) being 0:**
- Row $i$ ($i \leq n-1$): weight $2 \equiv 0 \pmod{2}$. ✓
- Row $n$: weight $n - 1 \equiv 0 \pmod{2}$ (since $n$ is odd). ✓

**Verification of off-diagonal (cross dot-products) being 1:**
- Row $i$ · Row $j$ ($i \neq j$, both $\leq n-1$): The only shared 1 is in posit
ion 1 (since $i+1 \neq j+1$), giving $1$. ✓
- Row $i$ · Row $n$ ($i \leq n-1$): Row $i$ has 1s at positions $1$ and $i+1$; r
ow $n$ has 1s at positions $2, \ldots, n$. Position 1 is not shared, but positio
n $i+1 \in \{2, \ldots, n\}$ is shared, giving exactly $1$. ✓

**Linear independence:** Rows $1, \ldots, n-1$ are clearly linearly independent
(each has a unique 1 in position $i+1$ that no earlier row has, plus the shared
position 1). Row $n = \sum_{i=1}^{n-1} \text{row}_i$ (since summing rows $1, \ld
ots, n-1$ gives 1 in position 1 appearing $n-1 \equiv 0$ times, and 1 in each po
sition $2, \ldots, n$ exactly once). So $B$ has rank $n - 1$, consistent with $\
operatorname{rank}(J+I) = n - 1$ when $n$ is odd.

Lifting $B$ to integers (entries 0 and 1) gives the desired matrix. ✓

---

### Conclusion

An $n \times n$ integer matrix with the required properties exists if and only i
f $n$ is **odd**.
