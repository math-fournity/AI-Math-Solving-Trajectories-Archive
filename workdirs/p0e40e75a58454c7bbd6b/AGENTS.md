# Problem

In a specialized data processing facility, a triangular server array is constructed with $n$ processing units in the top row (where $n > 2$). Each subsequent row contains one fewer unit than the row above it, tapering down to a single master node in the $n$-th row.

The facility manager, Petryk, initiates the system by assigning a unique priority level from $1$ to $n$ to each of the $n$ units in the top row, ensuring every integer in that range is used exactly once. The system then automatically generates priority values for the lower rows based on a specific logic gate: any unit located directly below two adjacent units with priority values $a$ and $b$ is assigned a priority value equal to the absolute difference $|a - b|$.

In terms of system optimization, Petryk needs to determine the theoretical maximum priority value that could possibly be generated in the final master node at the very bottom of the array. What is this maximum possible value?
