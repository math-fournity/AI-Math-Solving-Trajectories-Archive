## Proof that the recurrence generates the Calkin–Wilf sequence

**Claim:** $a_n$ equals the $n$-th node in the BFS traversal of the Calkin–Wilf
tree (root at position 1, left child of position $n$ at $2n$, right child at $2n
+1$).

**Proof by strong induction on $n$.**

*Base case:* $a_1 = 1 = 1/1$, the root. ✓

*Inductive step:* Assume the claim holds for all positions $\le n$. We show $a_{
n+1} = T(a_n)$ matches position $n+1$ in the tree, where $T(x) = \frac{1}{2\lflo
or x\rfloor - x + 1}$.

**Case 1: $n = 2m$ (even).** Position $n$ is the left child of position $m$; pos
ition $n+1 = 2m+1$ is the right child of position $m$. If $a_m = p/q$, then $a_n
 = p/(p+q)$ and the tree gives position $n+1 = (p+q)/q$.

Compute $T(p/(p+q))$: since $p < p+q$, we have $\lfloor p/(p+q)\rfloor = 0$, so
$$T\!\left(\frac{p}{p+q}\right) = \frac{1}{0 - \frac{p}{p+q} + 1} = \frac{1}{\fr
ac{q}{p+q}} = \frac{p+q}{q}. \checkmark$$

**Case 2: $n = 2m+1$ (odd), $n \ge 3$.** Position $n$ is the right child of posi
tion $m$; position $n+1 = 2(m+1)$ is the left child of position $m+1$. By induct
ion ($m+1 \le n$), $a_{m+1} = T(a_m)$.

Write $a_m = p/q = k + r/q$ where $k = \lfloor p/q \rfloor$, $0 \le r < q$, so $
p = kq + r$.

- $a_n = (p+q)/q = (k+1) + r/q$, so $\lfloor a_n \rfloor = k+1$.
- $a_{m+1} = T(p/q) = \frac{q}{(k+1)q - r}$, so $a_{m+1} = q/q'$ where $q' = (k+
1)q - r$.
- Left child of $a_{m+1}$ (position $n+1$): $\frac{q}{q + q'} = \frac{q}{q + (k+
1)q - r} = \frac{q}{(k+2)q - r}$.

Compute $T(a_n)$:
$$T\!\left(\frac{p+q}{q}\right) = \frac{1}{2(k+1) - \frac{(k+1)q+r}{q} + 1} = \f
rac{1}{(k+2) - \frac{r}{q}} = \frac{q}{(k+2)q - r}. \checkmark$$

Both cases confirm $a_{n+1} = T(a_n)$ matches the tree. $\blacksquare$
