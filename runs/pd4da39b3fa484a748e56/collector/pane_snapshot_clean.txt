## Proof

Let $W(t)$ be a standard Wiener process. By definition, for each fixed $t \geq 0
$,

$$W(t) \sim \mathcal{N}(0, t),$$

i.e., $W(t)$ is normally distributed with mean $0$ and variance $t$.

Define

$$U(t) = e^{t + W(t)/2}.$$

We want to compute $E(U(t)) = E\!\left(e^{t + W(t)/2}\right)$.

**Step 1: Identify the distribution of the exponent.**

Set $X = t + \dfrac{W(t)}{2}$. Since $W(t) \sim \mathcal{N}(0, t)$, the affine t
ransformation gives

$$X \sim \mathcal{N}\!\left(t,\; \frac{t}{4}\right),$$

because:
- Mean: $E[X] = t + \tfrac{1}{2}E[W(t)] = t + 0 = t$,
- Variance: $\mathrm{Var}(X) = \mathrm{Var}\!\left(\tfrac{1}{2}W(t)\right) = \tf
rac{1}{4}\mathrm{Var}(W(t)) = \tfrac{t}{4}$.

**Step 2: Apply the moment generating function of a normal random variable.**

For $X \sim \mathcal{N}(\mu, \sigma^2)$, the moment generating function evaluate
d at $1$ is

$$E\!\left(e^{X}\right) = e^{\mu + \sigma^2/2}.$$

Applying this with $\mu = t$ and $\sigma^2 = \dfrac{t}{4}$:

$$E\!\left(e^{X}\right) = e^{\,t \;+\; \frac{1}{2}\cdot\frac{t}{4}} = e^{\,t \;+
\; \frac{t}{8}} = e^{\,\frac{8t}{8} + \frac{t}{8}} = e^{\,9t/8}.$$

**Step 3: Conclusion.**

Therefore,

$$\boxed{E(U(t)) = E\!\left(e^{t + W(t)/2}\right) = e^{9t/8},}$$

which verifies the claimed identity. $\blacksquare$
