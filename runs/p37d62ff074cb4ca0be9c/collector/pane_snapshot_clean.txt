## Solution

**Goal:** Find the Laurent expansion of $f(z) = \exp\!\left(\frac{1}{1-z}\right)
$ for $1 < |z| < \infty$.

### Step 1: Reduce to a Taylor expansion via $w = 1/z$

For $|z|>1$, set $w = 1/z$ so $|w|<1$. Then

$$\frac{1}{1-z} = \frac{1}{1-1/w} = \frac{w}{w-1} = -\frac{w}{1-w}.$$

Hence $f(z) = g(w)$ where

$$g(w) = \exp\!\left(-\frac{w}{1-w}\right), \qquad |w|<1.$$

Since $g$ is analytic at $w=0$ (with $g(0)=e^0=1$), it has a Taylor expansion $g
(w)=\sum_{n=0}^{\infty} a_n w^n$ convergent for $|w|<1$. Substituting back $w=1/
z$:

$$\boxed{\exp\!\left(\frac{1}{1-z}\right) = \sum_{n=0}^{\infty} \frac{a_n}{z^n},
 \qquad |z|>1.}$$

It remains to determine the coefficients $a_n$.

### Step 2: Derive a recurrence from an ODE

Compute:

$$\frac{d}{dw}\!\left(-\frac{w}{1-w}\right) = -\frac{1}{(1-w)^2},$$

so $g$ satisfies the linear ODE

$$(1-w)^2\, g'(w) + g(w) = 0. \tag{$\star$}$$

Write $g(w) = \sum_{n=0}^{\infty} a_n w^n$, so $g'(w)=\sum_{n=0}^{\infty}(n+1)a_
{n+1}w^n$. Expanding $(\star)$:

$$\bigl(1 - 2w + w^2\bigr)g'(w) + g(w) = 0.$$

Collecting the coefficient of $w^n$:

| Term | Coefficient of $w^n$ |
|---|---|
| $g'(w)$ | $(n+1)a_{n+1}$ |
| $-2w\,g'(w)$ | $-2n\,a_n$ (valid $n\ge1$; $=0$ for $n=0$) |
| $w^2 g'(w)$ | $(n-1)a_{n-1}$ (valid $n\ge2$; $=0$ for $n=0,1$) |
| $g(w)$ | $a_n$ |

- **$n=0$:** $a_1 + a_0 = 0 \;\Rightarrow\; a_1 = -1$ (since $a_0 = g(0)=1$).
- **$n=1$:** $2a_2 - 2a_1 + a_1 = 0 \;\Rightarrow\; 2a_2 = a_1 = -1 \;\Rightarro
w\; a_2 = -\tfrac12$.
- **$n \ge 2$:** $(n+1)a_{n+1} - 2n\,a_n + (n-1)a_{n-1} + a_n = 0$, i.e.,

$$\boxed{(n+1)\,a_{n+1} = (2n-1)\,a_n - (n-1)\,a_{n-1}, \qquad n \ge 1,}$$

with $a_0 = 1,\; a_1 = -1$. (One checks the recurrence also reproduces $a_2 = -1
/2$ at $n=1$.)

The first few coefficients are:

$$a_0=1,\quad a_1=-1,\quad a_2=-\tfrac12,\quad a_3=-\tfrac16,\quad a_4=\tfrac1{2
4},\quad a_5=\tfrac{19}{120},\quad a_6=\tfrac{151}{720},\;\ldots$$

### Step 3: Closed-form expression via partitions

We can also express $a_n$ explicitly. Using the identity $-\frac{w}{1-w} = 1 - \
frac{1}{1-w}$:

$$g(w) = e^{1-1/(1-w)} = e\cdot e^{-1/(1-w)} = e\cdot e^{-\sum_{k=0}^{\infty}w^k
} = e\cdot e^{-1}\cdot e^{-\sum_{k=1}^{\infty}w^k} = \prod_{k=1}^{\infty} e^{-w^
k}.$$

Expanding each factor, $e^{-w^k} = \sum_{m_k\ge 0}\frac{(-1)^{m_k}}{m_k!}\,w^{k\
,m_k}$, and collecting the coefficient of $w^n$ (i.e., all nonneg­ative integer
sequences $(m_1,m_2,\ldots)$ with $\sum_{k\ge1} k\,m_k = n$):

$$\boxed{a_n = \sum_{\lambda\,\vdash\, n}\frac{(-1)^{\ell(\lambda)}}{\prod_{k\ge
 1} m_k(\lambda)!}\,,}$$

where the sum ranges over all integer partitions $\lambda$ of $n$, $\ell(\lambda
)=\sum_k m_k$ is the number of parts, and $m_k(\lambda)$ is the multiplicity of
part $k$.

**Verification for $n=3$:** Partitions of $3$ are $(3),\,(2{,}1),\,(1{,}1{,}1)$:
- $(3)$: $\ell=1,\; m_3=1 \;\Rightarrow\; (-1)^1/1! = -1$.
- $(2,1)$: $\ell=2,\; m_2=m_1=1 \;\Rightarrow\; (-1)^2/(1!\,1!) = 1$.
- $(1,1,1)$: $\ell=3,\; m_1=3 \;\Rightarrow\; (-1)^3/3! = -1/6$.

Total: $-1+1-1/6 = -1/6 = a_3$. ✓

### Final Answer

$$\exp\!\left(\frac{1}{1-z}\right) = \sum_{n=0}^{\infty}\frac{a_n}{z^n}, \qquad
1<|z|<\infty,$$

where $a_0=1$, $a_1=-1$, and

$$(n+1)\,a_{n+1}=(2n-1)\,a_n-(n-1)\,a_{n-1}\quad(n\ge1),$$

equivalently $a_n = \displaystyle\sum_{\lambda\vdash n}\frac{(-1)^{\ell(\lambda)
}}{\prod_{k\ge1}m_k(\lambda)!}$.

The series converges absolutely for $|z|>1$ since $g(w)$ is analytic on $|w|<1$
(the only singularity of $g$ is at $w=1$, i.e., $z=1$).
