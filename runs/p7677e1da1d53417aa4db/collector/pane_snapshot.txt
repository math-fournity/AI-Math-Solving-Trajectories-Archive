## Proof

**Upper bound.** Let $X$ be a separable Hausdorff space and let $D \subseteq X$
be a countable dense subset (which exists by separability). We show that every c
ontinuous function $f: X \to [0,1]$ is uniquely determined by its restriction $f
|_D$.

Suppose $f, g: X \to [0,1]$ are continuous and $f|_D = g|_D$. Consider the set
$$A = \{x \in X : f(x) = g(x)\}.$$
Since $[0,1]$ is Hausdorff, the diagonal $\Delta = \{(y,y) : y \in [0,1]\}$ is c
losed in $[0,1]^2$. The map $h: X \to [0,1]^2$ defined by $h(x) = (f(x), g(x))$
is continuous (as $f$ and $g$ are), so $A = h^{-1}(\Delta)$ is closed in $X$. No
w $D \subseteq A$ by assumption, and $D$ is dense, so $\overline{D} = X \subsete
q A$ (since $A$ is closed). Thus $A = X$, meaning $f = g$ on all of $X$.

Therefore the restriction map $C(X, [0,1]) \to [0,1]^D$ is injective. Since $D$
is countable, the number of functions $D \to [0,1]$ is
$$|[0,1]|^{|D|} = \mathfrak{c}^{\aleph_0} = (2^{\aleph_0})^{\aleph_0} = 2^{\alep
h_0 \cdot \aleph_0} = 2^{\aleph_0} = \mathfrak{c}.$$
Hence $|C(X, [0,1])| \leq \mathfrak{c}$.

**Lower bound (achievability).** Take $X = [0,1]$ with its usual topology, which
 is a separable Hausdorff space (it has the countable dense subset $\mathbb{Q} \
cap [0,1]$). For each $a \in [0,1]$, define $f_a: [0,1] \to [0,1]$ by $f_a(x) =
ax$. Each $f_a$ is continuous, and the map $a \mapsto f_a$ is injective since $f
_a(1) = a$ distinguishes them. Thus
$$|C([0,1], [0,1])| \geq |[0,1]| = \mathfrak{c}.$$

Combining the upper and lower bounds, the maximum number of distinct continuous
functions that can be defined from a separable Hausdorff space to $[0,1]$ is

$$\boxed{\mathfrak{c} = 2^{\aleph_0}}.$$
