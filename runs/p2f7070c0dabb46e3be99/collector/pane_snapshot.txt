## 解答

**答案：$K = 2p$。**

### 证明

我们应用标准的鸽巢原理（Pigeonhole Principle）论证，考虑所有满足 $0 \le x_i \le
q$（其中 $q = 2p$）的向量 $(x_1, \dots, x_q)$。

**计算对象（向量）的数量。** 每个坐标取 $\{0, 1, \dots, q\}$ 中的一个值，因此此
类向量的总数为
$$(q+1)^q.$$

**计算“盒子”（可能的线性组合值）的数量。** 对于每个向量，计算 $p$ 个线性组合 $L_
i = \sum_{j=1}^q a_{ij}\,x_j$，其中 $i=1,\dots,p$。对于固定的 $i$，令 $n_i^+$ 为
等于 $+1$ 的系数 $a_{ij}$ 的数量，$n_i^-$ 为等于 $-1$ 的系数数量。由于每个系数属
于 $\{-1,0,1\}$，我们有 $n_i^+ + n_i^- \le q$。

当 $x_j \in [0, q]$ 时，$L_i$ 的取值范围为：
$$-q\,n_i^- \;\le\; L_i \;\le\; q\,n_i^+.$$
因此，$L_i$ 可能取的整数值最多为
$$q\,n_i^+ + q\,n_i^- + 1 = q(n_i^+ + n_i^-) + 1 \;\le\; q^2 + 1.$$

所以，元组 $(L_1, \dots, L_p)$ 可能取值的数量最多为
$$(q^2 + 1)^p.$$

**应用鸽巢原理。** 我们需要：
$$(q+1)^q > (q^2+1)^p.$$

代入 $q = 2p$：
$$(2p+1)^{2p} > (4p^2+1)^p.$$

两边同时取 $p$ 次方根（因为两边均为正数）：
$$(2p+1)^2 > 4p^2 + 1.$$
$$4p^2 + 4p + 1 > 4p^2 + 1.$$
$$4p > 0.$$

这对于所有 $p \ge 1$ 均成立。因此，鸽巢原理保证了存在两个不同的向量 $\mathbf{x}
= (x_1,\dots,x_q)$ 和 $\mathbf{x}' = (x_1',\dots,x_q')$，且均满足 $0 \le x_i, x_
i' \le q$，使得它们产生相同的线性组合元组：
$$\sum_j a_{ij}\,x_j = \sum_j a_{ij}\,x_j' \quad \text{对于所有 } i=1,\dots,p.$$

**构造解。** 令 $y_j = x_j - x_j'$。则：
- $\sum_j a_{ij}\,y_j = 0$ 对于所有 $i$ 成立，因此 $\mathbf{y}$ 是一个解。
- $\mathbf{y} \ne \mathbf{0}$，因为这两个向量是不同的。
- $|y_j| = |x_j - x_j'| \le q - 0 = q$，因为两个 $x_j, x_j'$ 都在 $[0, q]$ 范围
内。

因此，$\mathbf{y}$ 是一个非零整数解，且满足对于所有 $j$，都有 $|y_j| \le q = 2p$
。

**最小性。** 该方法明确使用了范围 $[0, q]$，而两个此类向量之差给出的界为 $|y_j|
\le q = 2p$。这是该特定方法所能产生的界，且该界是紧的（tight），因为论证仅利用了
两个向量都位于 $[0,q]$ 内的事实。因此，该方法能保证的最小整数 $K$ 为：

$$\boxed{K = 2p}.$$
