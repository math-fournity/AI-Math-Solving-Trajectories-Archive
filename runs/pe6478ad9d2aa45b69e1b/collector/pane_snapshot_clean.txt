## Proof

**Definition.** The upper Banach density of $A \subseteq \mathbb{N}$ is
$$\overline{d_B}(A) = \lim_{N \to \infty} \sup_{a \geq 0} \frac{|A \cap [a+1,\,
a+N]|}{N}.$$
(The limit exists: $g(N) = \sup_a |A \cap [a+1,a+N]|$ is subadditive, so $g(N)/N
 \to \inf_N g(N)/N$ by Fekete's lemma.)

**Construction.** For each $k \geq 1$, set:
- $d_k = 2^{k^2}$ (common difference),
- $M_k = 2^{k^3}$ (starting point),
- $P_k = \{M_k + j\,d_k : 0 \le j \le k-1\}$ (AP of length $k$),
- $A = \bigcup_{k=1}^{\infty} P_k$.

**The blocks are disjoint.** The span of $P_k$ is $[M_k,\; M_k + (k{-}1)d_k]$. S
ince $(k{+}1)^3 = k^3 + 3k^2 + 3k + 1$, we have $M_{k+1} = 2^{(k+1)^3} \ge 2^{k^
3+4} = 16 \cdot 2^{k^3}$ for $k \ge 1$, while $M_k + (k{-}1)d_k \le 2^{k^3} + k\
cdot 2^{k^2} \le 2^{k^3}(1 + k/2^{k^2}) \le 2\cdot 2^{k^3}$. So $M_k + (k{-}1)d_
k < M_{k+1}$, confirming disjointness.

**$A$ has arbitrarily long APs.** Each $P_k$ is an AP of length $k$ in $A$, for
every $k$.

**$\overline{d_B}(A) = 0$.** We show $|A \cap I| = O(\log N)$ for every interval
 $I$ of length $N$, which gives $|A \cap I|/N \to 0$.

Let $I = [a+1, a+N]$. If $I$ meets no $P_k$, then $|A \cap I| = 0$. Otherwise, l
et $P_{k_0}, \dots, P_{k_1}$ be the blocks meeting $I$.

**Bounding $k_1$.** Since $I$ reaches $P_{k_1}$, we have $M_{k_1} \le a + N$. Al
so $a+1 \le M_{k_0} + (k_0{-}1)d_{k_0} \le 2\cdot 2^{k_0^3}$. If $k_1 > k_0$, th
en $M_{k_1} \ge M_{k_0+1} \ge 8\cdot 2^{k_0^3}$, so $N \ge 6\cdot 2^{k_0^3}$, he
nce $M_{k_1} \le a+N \le 2\cdot 2^{k_0^3} + N \le \frac{4N}{3}$. Thus $2^{k_1^3}
 \le \frac{4N}{3}$, giving $k_1 \le \bigl(\log_2 \tfrac{4N}{3}\bigr)^{1/3}$. If
$k_1 = k_0$, the bound $k_1 \le (\log_2(4N))^{1/3} + 1$ holds trivially since $M
_{k_1} \le a + N$ and $a \le M_{k_1} + (k_1{-}1)d_{k_1}$ gives $N \ge 1$, but we
 handle this case via the element count below. In all cases:
$$k_1 = O\bigl((\log N)^{1/3}\bigr).$$

**Counting elements.** Since elements of $P_k$ are spaced $d_k = 2^{k^2}$ apart:
$$|P_k \cap I| \le \min\!\Bigl(k,\; \frac{N}{d_k} + 1\Bigr).$$

Set $J = \bigl\lfloor (\log_2 N)^{1/2}\bigr\rfloor$, so $d_J \le N < d_{J+1}$.

- **For $k \le J$:** $|P_k \cap I| \le k \le J$.
- **For $k > J$:** $d_k > N$, so $|P_k \cap I| \le N/d_k + 1 \le 2$.

Therefore:
$$|A \cap I| \le \sum_{k=k_0}^{k_1} |P_k \cap I| \le \sum_{k=1}^{J} k \;+\; 2\,k
_1 \le \frac{J(J+1)}{2} + 2\bigl(\log_2(4N)\bigr)^{1/3}.$$

Since $J^2 \le \log_2 N$:
$$|A \cap I| \le \log_2 N + 2\bigl(\log_2(4N)\bigr)^{1/3} = O(\log N).$$

**Single-block case.** If $I$ meets only $P_k$: $|A \cap I| = |P_k \cap I| \le \
min(k, N/d_k+1)$. If $k \le J$, this is $\le J = O((\log N)^{1/2})$. If $k > J$,
 then $d_k > N$ so $|P_k \cap I| \le 1$. Either way $|A \cap I| = O(\log N)$.

**Conclusion.** In every case,
$$\sup_a \frac{|A \cap [a+1, a+N]|}{N} \le \frac{O(\log N)}{N} \xrightarrow{N\to
\infty} 0.$$

Hence $\overline{d_B}(A) = 0$, even though $A$ contains arithmetic progressions
of every length. $\blacksquare$
