# Problem

In a remote digital archipelago, there are $n$ server nodes arranged in a perfect circle, located at the precise coordinates of the $n$th roots of unity on a complex grid. To test the network's resilience, a security administrator executes a series of "Data Purge" cycles.

In each cycle, the administrator selects a single target coordinate $(x, y)$ anywhere on the infinite grid. Simultaneously, every active server node transmits a high-energy data beam in a direct straight line toward that specific target point. If a data beam passing toward the target happens to intersect another server node's location, that intercepted node is immediately fried and deactivated. Deactivated nodes cannot transmit beams in any subsequent cycles.

The administrator's goal is to deactivate every single one of the $n$ nodes. What is the minimum number of Data Purge cycles required to eliminate all $n$ nodes? Give your answer in terms of $n$.
