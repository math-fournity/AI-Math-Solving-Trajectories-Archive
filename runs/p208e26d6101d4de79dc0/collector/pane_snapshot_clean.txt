## Solution

**Setup.** For level $n$, $S_n = \{-6n, \ldots, -1, 1, \ldots, 6n\}$. A Linear C
orridor is an increasing 5-term arithmetic progression $a, a+d, a+2d, a+3d, a+4d
$ with $d \geq 1$, all terms in $[-6n, 6n]$, and **no term equal to 0**.

**Step 1: Total 5-term APs in $[-6n, 6n]$ (allowing 0).**

We need $a \geq -6n$ and $a+4d \leq 6n$, so $a$ ranges over $-6n \leq a \leq 6n
- 4d$, giving $12n - 4d + 1$ choices. The maximum $d$ satisfies $4d \leq 12n$, i
.e. $d \leq 3n$. Thus

$$T(n) = \sum_{d=1}^{3n}(12n - 4d + 1) = 3n(12n+1) - 4\cdot\frac{3n(3n+1)}{2} =
18n^2 - 3n.$$

**Step 2: APs that contain 0.**

The term $0$ appears at position $k \in \{0,1,2,3,4\}$, i.e. $a + kd = 0 \Righta
rrow a = -kd$. The range constraints become $-kd \geq -6n$ and $(4-k)d \leq 6n$,
 giving $d \leq \min\!\bigl(\tfrac{6n}{k}, \tfrac{6n}{4-k}\bigr)$.

| $k$ | bound on $d$ | count |
|---|---|---|
| 0 | $d \leq 6n/4 = 3n/2$ | $\lfloor 3n/2\rfloor$ |
| 1 | $d \leq 6n/3 = 2n$ | $2n$ |
| 2 | $d \leq 6n/2 = 3n$ | $3n$ |
| 3 | $d \leq 6n/1 = 6n$, but $3d\leq 6n \Rightarrow d\leq 2n$ | $2n$ |
| 4 | $d \leq 6n/4 = 3n/2$ | $\lfloor 3n/2\rfloor$ |

Since $d \geq 1$, 0 can appear at only one position, so no double-counting. The
number of APs containing 0 is

$$Z(n) = 2\left\lfloor \tfrac{3n}{2}\right\rfloor + 7n.$$

**Step 3: The formula.**

$$f(n) = T(n) - Z(n) = 18n^2 - 3n - 2\left\lfloor \tfrac{3n}{2}\right\rfloor - 7
n = 18n^2 - 10n - 2\left\lfloor \tfrac{3n}{2}\right\rfloor.$$

**Verification (n=1).** $T(1)=15$, $Z(1)=2\cdot 1 + 7 = 9$, $f(1)=6$. Direct enu
meration: $d=1$ gives 4 valid APs ($a=-6,-5,1,2$), $d=2$ gives 2 ($a=-5,-3$), $d
=3$ gives 0. Total $6$. ✓

**Step 4: Compute.**

- $n=5$: $\lfloor 15/2\rfloor = 7$. $f(5) = 18\cdot 25 - 50 - 14 = 450 - 64 = 38
6$.
- $n=6$: $\lfloor 18/2\rfloor = 9$. $f(6) = 18\cdot 36 - 60 - 18 = 648 - 78 = 57
0$.

$$f(5) + f(6) = 386 + 570 = \boxed{956}.$$
