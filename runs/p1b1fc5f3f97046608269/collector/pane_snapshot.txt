## Proof

Let $X$ be an infinite set equipped with the cocountable topology, in which the
open sets are $\emptyset$ together with all subsets $U\subseteq X$ whose complem
ent $X\setminus U$ is countable. Let $\mathcal{B}=\{X\setminus C : C\subseteq X,
\ C\text{ countable}\}$ be the given filter base, and let $\mathcal{F}$ be the f
ilter it generates.

**Step 1. Identify $\mathcal{F}$.**

A set $A$ belongs to $\mathcal{F}$ iff it contains some base element $X\setminus
 C$ with $C$ countable. The condition $X\setminus C\subseteq A$ is equivalent to
 $X\setminus A\subseteq C$, so $X\setminus A$ is countable. Hence

$$\mathcal{F}=\{A\subseteq X : X\setminus A\text{ is countable}\},$$

the family of all co-countable subsets of $X$. (This is a proper filter provided
 $X$ is uncountable; we assume this, as it is the standard setting for the cocou
ntable topology. The countable case degenerates to the discrete topology and is
noted at the end.)

**Step 2. Determine the neighborhood filter $\mathcal{N}(x)$ at a point $x\in X$
.**

A set $N$ is a neighborhood of $x$ iff there is an open set $U$ with $x\in U\sub
seteq N$. The open sets containing $x$ are exactly the co-countable sets contain
ing $x$. If $U$ is co-countable and $U\subseteq N$, then $X\setminus N\subseteq
X\setminus U$, which is countable, so $N$ is co-countable; and clearly $x\in N$.
 Conversely, if $N$ is co-countable and $x\in N$, then $N$ itself is an open set
 containing $x$ with $N\subseteq N$, so $N$ is a neighborhood. Therefore

$$\mathcal{N}(x)=\{N\subseteq X : x\in N,\ X\setminus N\text{ is countable}\},$$

the co-countable subsets of $X$ that contain $x$.

**Step 3. Check convergence.**

By definition, $x$ is a convergence point of $\mathcal{F}$ iff $\mathcal{N}(x)\s
ubseteq\mathcal{F}$, i.e., the filter $\mathcal{F}$ is finer than the neighborho
od filter at $x$.

Every member $N\in\mathcal{N}(x)$ is co-countable, and $\mathcal{F}$ consists of
 *all* co-countable subsets of $X$. Hence $\mathcal{N}(x)\subseteq\mathcal{F}$ f
or every $x\in X$.

**Step 4. No other convergence points exist.**

Convergence points must be points of $X$, and we have shown every $x\in X$ is a
convergence point. Thus the set of convergence points is exactly $X$.

**Step 5. Degenerate countable case.**

If $X$ is countably infinite, the cocountable topology coincides with the discre
te topology (every subset has countable complement). The filter base $\mathcal{B
}$ then contains $\emptyset=X\setminus X$, so it is not a proper filter base; th
e generated "filter" is the improper filter $\mathcal{P}(X)$. Under the conventi
on that the improper filter converges to every point, the conclusion is again th
at every point of $X$ is a convergence point. Under the convention that only pro
per filters converge, the setup is ill-defined for countable $X$, which is why t
he cocountable topology is standardly taken on uncountable sets.

**Conclusion.** For an (uncountable) infinite set $X$ with the cocountable topol
ogy, the filter generated by the base of all complements of countable sets conve
rges to **every point of $X$**. The set of convergence points is $X$ itself.

This reflects the fact that the cocountable topology is highly non-Hausdorff: an
y two non-empty open sets intersect (their intersection is co-countable, hence n
on-empty), so limits of filters are far from unique.
