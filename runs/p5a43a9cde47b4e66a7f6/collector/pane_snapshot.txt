## Solution

**Problem.** Evaluate
$$\lim_{n\to\infty} \int_{[0,\infty)} \frac{n\sin(x/n)}{x(1+x^2)}\,dm.$$

---

### Step 1: Pointwise limit of the integrand

Define $f_n(x) = \dfrac{n\sin(x/n)}{x(1+x^2)}$ for $x > 0$, and set $f_n(0) = 1$
 (the continuous extension, since $\lim_{x\to 0^+} \frac{n\sin(x/n)}{x} = 1$).

For each fixed $x > 0$, substitute $t = x/n \to 0$ as $n\to\infty$:
$$\frac{n\sin(x/n)}{x} = \frac{\sin t}{t} \longrightarrow 1.$$

Hence
$$f_n(x) \longrightarrow \frac{1}{1+x^2} \quad \text{for all } x \geq 0.$$

### Step 2: Dominating function

We use the classical inequality $|\sin t| \leq |t|$ for all $t \in \mathbb{R}$.
For $x > 0$:
$$|f_n(x)| = \frac{n\,|\sin(x/n)|}{x(1+x^2)} \leq \frac{n \cdot (x/n)}{x(1+x^2)}
 = \frac{1}{1+x^2}.$$

At $x = 0$: $|f_n(0)| = 1 = \frac{1}{1+0}$, so the bound holds everywhere.

Set $g(x) = \frac{1}{1+x^2}$. Then $g$ is integrable on $[0,\infty)$:
$$\int_0^\infty \frac{1}{1+x^2}\,dx = \arctan(x)\Big|_0^\infty = \frac{\pi}{2} <
 \infty.$$

### Step 3: Apply the Dominated Convergence Theorem

Since:
- $f_n \to \frac{1}{1+x^2}$ pointwise a.e. on $[0,\infty)$,
- $|f_n(x)| \leq g(x) = \frac{1}{1+x^2} \in L^1([0,\infty))$ for all $n$,

the Dominated Convergence Theorem gives:
$$\lim_{n\to\infty} \int_{[0,\infty)} f_n\,dm = \int_{[0,\infty)} \lim_{n\to\inf
ty} f_n\,dm = \int_0^\infty \frac{1}{1+x^2}\,dx = \frac{\pi}{2}.$$

### Result

$$\boxed{\dfrac{\pi}{2}}$$
