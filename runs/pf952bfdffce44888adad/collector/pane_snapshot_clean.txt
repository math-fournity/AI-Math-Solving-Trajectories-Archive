## Proof

**Claim.** The power set $\mathcal{P}(\mathbb{N})$ of the natural numbers has ca
rdinality $2^{\aleph_0}$, which is strictly greater than $\aleph_0$ (i.e., $\mat
hcal{P}(\mathbb{N})$ is uncountable).

---

### Step 1. $|\mathcal{P}(\mathbb{N})| = 2^{\aleph_0}$

For any set $S$, there is a bijection between $\mathcal{P}(S)$ and the set of fu
nctions $S \to \{0,1\}$, namely $2^S$. The map is:

$$A \subseteq S \;\longmapsto\; \chi_A : S \to \{0,1\}, \qquad \chi_A(x) = \begi
n{cases} 1 & x \in A \\ 0 & x \notin A \end{cases}$$

This is a bijection (its inverse sends a function $f$ to $f^{-1}(\{1\})$). Hence
 $|\mathcal{P}(S)| = |2^S|$. Taking $S = \mathbb{N}$:

$$|\mathcal{P}(\mathbb{N})| = |2^{\mathbb{N}}| = 2^{\aleph_0}.$$

### Step 2. $2^{\aleph_0} > \aleph_0$ (uncountability, Cantor)

We show there is no surjection $\mathbb{N} \to \mathcal{P}(\mathbb{N})$, so $|\m
athcal{P}(\mathbb{N})| > |\mathbb{N}| = \aleph_0$.

Suppose, for contradiction, that $\{A_0, A_1, A_2, \dots\}$ is any enumeration o
f subsets of $\mathbb{N}$ (i.e., any function $n \mapsto A_n$ from $\mathbb{N}$
to $\mathcal{P}(\mathbb{N})$). Define the **diagonal set**

$$D = \{n \in \mathbb{N} : n \notin A_n\}.$$

Clearly $D \subseteq \mathbb{N}$, so $D \in \mathcal{P}(\mathbb{N})$. We claim $
D \neq A_k$ for every $k \in \mathbb{N}$. Indeed, for any $k$:

- If $k \in A_k$, then by definition $k \notin D$, so $D \neq A_k$.
- If $k \notin A_k$, then by definition $k \in D$, so $D \neq A_k$.

In either case $D$ and $A_k$ differ at the element $k$. Therefore $D$ is not in
the enumeration, contradicting the assumption that the enumeration was surjectiv
e.

Hence no function $\mathbb{N} \to \mathcal{P}(\mathbb{N})$ is surjective, so $|\
mathbb{N}| < |\mathcal{P}(\mathbb{N})|$.

### Step 3. Identification with the continuum

It is a standard fact that $2^{\aleph_0} = |\mathbb{R}|$. A bijection can be exh
ibited via binary expansions: each subset $A \subseteq \mathbb{N}$ maps to $\sum
_{n \in A} 2^{-(n+1)} \in [0,1]$, and (handling the countably many dyadic-ration
al ambiguities) this gives a bijection between $\mathcal{P}(\mathbb{N})$ and $[0
,1]$, hence with $\mathbb{R}$. Thus $2^{\aleph_0} = \mathfrak{c}$, the cardinali
ty of the continuum.

---

### Conclusion

The power set of the natural numbers has cardinality

$$|\mathcal{P}(\mathbb{N})| = 2^{\aleph_0} = \mathfrak{c},$$

the cardinality of the continuum, which is strictly larger than $\aleph_0$ (the
power set of $\mathbb{N}$ is uncountable, by Cantor's diagonal argument).
