Looking at this problem, I need to find the minimum number of teams in a round-r
obin tournament where the sole winner scores less than 50% of the maximum possib
le points (which is 3(n−1)).

**Setting up the framework.** With n teams, each team plays n−1 games. I use the
 decomposition: if team i has wᵢ decisive wins, ℓᵢ decisive losses, and dᵢ draws
 (wᵢ+ℓᵢ+dᵢ = n−1), then its score is 3wᵢ + dᵢ = (n−1) + 2wᵢ − ℓᵢ. Let D = total
decisive games = Σwᵢ = Σℓᵢ. Then total points = n(n−1) + D.

**Lower bound on the winner's score W.** Total points ≥ n(n−1) (all draws). Sinc
e the winner has W and the other n−1 teams each have ≤ W−1:
$$n(n-1) \le W + (n-1)(W-1) = nW - (n-1),$$
so $W \ge \frac{n^2-1}{n}$.

**Upper bound from the <50% condition:** $W < \frac{3(n-1)}{2}$, i.e., $W \le \l
floor\frac{3n-4}{2}\rfloor$.

**Checking small n:**

| n | Lower bound on W | Upper bound on W | Feasible W |
|---|---|---|---|
| 2 | ≥ 2 | ≤ 1 | none |
| 3 | ≥ 3 | ≤ 2 | none |
| 4 | ≥ 4 | ≤ 4 | W = 4 |
| 5 | ≥ 5 | ≤ 5 | W = 5 |
| 6 | ≥ 6 | ≤ 7 | W ∈ {6, 7} |

**Key lemma: W = n is always impossible.** If W = n, then the winner needs 2w_A
− ℓ_A = n − (n−1) = 1. Every other team must have score ≤ n−1, i.e., 2wᵢ − ℓᵢ ≤
0. Summing over all teams: D = (winner's contribution) + Σ(others) = 1 + Σ(other
s). Since each of the n−1 others contributes ≤ 0, we get D ≤ 1.
- D = 0: all games drawn, everyone scores n−1 — no sole winner. ✗
- D = 1: the winner participates in the single decisive game (contributing 2 or
0 to 2w−ℓ) or doesn't (contributing 0). Neither gives contribution 1. ✗

So W = n is impossible for all n.

**n = 4:** Only W = 4 = n is available → impossible.
**n = 5:** Only W = 5 = n is available → impossible.
**n = 6:** W = 6 = n is impossible, but W = 7 = n+1 is available.

**Construction for n = 6, W = 7.** Take 6 teams. Let Team 1 beat Team 2; let eve
ry other game be a draw.

- Team 1: 1 win + 4 draws = 3 + 4 = **7** points.
- Team 2: 1 loss + 4 draws = 0 + 4 = **4** points.
- Teams 3, 4, 5, 6: 5 draws each = **5** points.

Team 1 is the **sole winner** with 7 points. The maximum possible for one partic
ipant is 3·5 = 15, and 50% of that is 7.5. Since **7 < 7.5**, the condition is s
atisfied. ✓

**Conclusion.** For n ≤ 5 no valid tournament exists (the forced winner's score
W = n is unachievable), while for n = 6 the construction above works. The minimu
m number of teams is:

$$\boxed{6}$$
