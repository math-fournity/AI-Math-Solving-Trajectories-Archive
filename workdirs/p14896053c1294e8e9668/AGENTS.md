# Problem

In a specialized cyber-security facility, an automated encryption protocol generates a sequence of security keys, $(a_n)_{n \geq 0}$, according to a specific recursive algorithm. The sequence begins with an initial baseline value $a_0 = 0$ and a primary seed value $a_1 = 1$. For every subsequent step $n \geq 0$, the next key in the sequence is generated by taking four times the value of the most recent key and adding the value of the key preceding it (mathematically, $a_{n+2} = 4a_{n+1} + a_n$).

An auditor is inspecting two specific keys generated by this system: the key at index 1986 ($a_{1986}$) and the key at index 6891 ($a_{6891}$). To assess the vulnerability of the encryption, the auditor needs to identify all positive integers that divide both $a_{1986}$ and $a_{6891}$ without leaving a remainder.

Find the common divisors of $a_{1986}$ and $a_{6891}$.
