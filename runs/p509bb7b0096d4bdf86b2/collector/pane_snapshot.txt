## Proof

Let $f(z) = az^2 + bz + c$. We are given that $f$ is a **Schur function** (bound
ed analytic by 1 on the closed unit disk).

**Step 1: Reduction to real non-negative $b, c$.**

If $f(z)$ satisfies the constraint, so does $g(z) = e^{i\phi} f(e^{i\psi} z)$ fo
r any real $\phi, \psi$. The new coefficients are $c' = e^{i\phi}c$, $b' = e^{i\
phi}e^{i\psi}b$. Choose $\phi$ so that $c' = |c| \ge 0$, then choose $\psi$ so t
hat $b' = |b| \ge 0$. Since $|b'c'| = |bc|$, we may assume WLOG that $b, c$ are
real and non-negative, and maximize $bc$.

**Step 2: The Schur transform gives the key constraint.**

By the Cauchy estimate, $|c| = |f(0)| \le 1$. If $|c| = 1$, the maximum modulus
principle forces $f$ to be constant, giving $b = 0$ and $bc = 0$. So assume $0 \
le c < 1$.

The **Schur transform** states: if $|f(z)| \le 1$ on the disk and $f(0) = c$ wit
h $|c| < 1$, then
$$g(z) = \frac{f(z) - c}{z\bigl(1 - \bar{c}\,f(z)\bigr)}$$
is also a Schur function. Computing $g(0)$:

$$f(z) - c = bz + az^2, \quad \frac{f(z)-c}{z} = b + az,$$
$$1 - \bar{c}\,f(z) = 1 - |c|^2 - \bar{c}\,bz - \bar{c}\,az^2,$$

so $g(0) = \frac{b}{1 - |c|^2}$. Since $g$ is a Schur function, $|g(0)| \le 1$,
giving:
$$|b| \le 1 - |c|^2.$$

**Step 3: Optimize.**

With $b, c \ge 0$ and $b \le 1 - c^2$, we maximize $bc \le c(1 - c^2)$ over $c \
in [0,1]$.

Let $h(c) = c - c^3$. Then $h'(c) = 1 - 3c^2 = 0$ gives $c = \frac{1}{\sqrt{3}}$
, and:
$$h\!\left(\tfrac{1}{\sqrt{3}}\right) = \frac{1}{\sqrt{3}} - \frac{1}{3\sqrt{3}}
 = \frac{2}{3\sqrt{3}} = \frac{2\sqrt{3}}{9}.$$

The second derivative $h''(c) = -6c < 0$ at $c = 1/\sqrt{3}$, confirming this is
 a maximum.

**Step 4: The bound is achieved.**

Take the **Blaschke factor** $f(z) = \frac{c + z}{1 + cz}$ with $c = \frac{1}{\s
qrt{3}}$. This satisfies $|f(z)| = 1$ on $|z| = 1$ (hence $|f(z)| \le 1$ on $|z|
 \le 1$), and expanding:

$$f(z) = (c + z)(1 + cz)^{-1} = (c+z)\sum_{n=0}^{\infty}(-cz)^n.$$

- Coefficient of $z^0$: $c = \frac{1}{\sqrt{3}}$.
- Coefficient of $z^1$: $\gamma(1 - c^2) = 1 \cdot \frac{2}{3} = \frac{2}{3}$ (w
here $\gamma = 1$).
- Coefficient of $z^2$: $-c(1-c^2) = -\frac{2}{3\sqrt{3}}$.

So $b = \frac{2}{3}$, $c = \frac{1}{\sqrt{3}}$, and $|bc| = \frac{2}{3} \cdot \f
rac{1}{\sqrt{3}} = \frac{2\sqrt{3}}{9}$.

This confirms the maximum is attained.

## Conclusion

The maximum value of $|bc|$ is $\dfrac{2\sqrt{3}}{9}$.
