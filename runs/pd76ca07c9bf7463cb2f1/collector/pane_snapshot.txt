## Solution

Let $S = \frac{X + X^T}{2}$ denote the symmetric part of $X$, and let $f(X) = \l
og\det S$. We compute the differential of $f$.

**Step 1: Differential of $\log\det$.**
For an invertible matrix $S$, the well‑known identity is
$$d(\log\det S) = \operatorname{tr}(S^{-1}\, dS).$$

**Step 2: Differential of $S$.**
Since $S = \frac{X+X^T}{2}$,
$$dS = \frac{dX + dX^T}{2}.$$

**Step 3: Substitute.**
$$df = \operatorname{tr}\!\left(S^{-1}\,\frac{dX + dX^T}{2}\right) = \frac{1}{2}
\operatorname{tr}(S^{-1}\,dX) + \frac{1}{2}\operatorname{tr}(S^{-1}\,dX^T).$$

**Step 4: Simplify the second trace.**
Using the cyclic/transpose property $\operatorname{tr}(B\,C^T) = \operatorname{t
r}(B^T\,C)$ with $B = S^{-1}$, $C = dX$:
$$\operatorname{tr}(S^{-1}\,dX^T) = \operatorname{tr}(S^{-T}\,dX).$$
Because $S$ is symmetric, $S^{-T} = S^{-1}$, so
$$\operatorname{tr}(S^{-1}\,dX^T) = \operatorname{tr}(S^{-1}\,dX).$$

**Step 5: Combine.**
$$df = \frac{1}{2}\operatorname{tr}(S^{-1}\,dX) + \frac{1}{2}\operatorname{tr}(S
^{-1}\,dX) = \operatorname{tr}(S^{-1}\,dX).$$

**Step 6: Read off the gradient.**
With the convention $df = \operatorname{tr}\!\left(\left(\frac{\partial f}{\part
ial X}\right)^{\!T} dX\right)$, we identify
$$\left(\frac{\partial f}{\partial X}\right)^{\!T} = S^{-1} \quad\Longrightarrow
\quad \frac{\partial f}{\partial X} = S^{-T} = S^{-1},$$
where the last equality uses the symmetry of $S$ (hence of $S^{-1}$).

**Result.**
$$\boxed{\frac{\partial}{\partial X}\,\log\det\!\left(\frac{X+X^T}{2}\right) = \
left(\frac{X+X^T}{2}\right)^{-1}}$$

**Sanity check.** The result is symmetric (as any gradient of a scalar w.r.t. an
 unconstrained matrix need not be, but here the function depends on $X$ only thr
ough its symmetric part, so the gradient is naturally symmetric). For scalar $X=
x$, $S=x$, $f=\log|x|$, $f' = 1/x = S^{-1}$. ✓ For diagonal $X$, $S=X$, $f=\sum_
i\log X_{ii}$, $\partial f/\partial X_{ii}=1/X_{ii}=S^{-1}_{ii}$. ✓
