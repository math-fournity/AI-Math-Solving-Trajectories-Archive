## Proof

**Claim.** The almost-everywhere equivalence relation under which the conditiona
l expectation $E(X \mid N)$ is defined (i.e. the equivalence relation giving uni
queness of $E(X\mid N)$) is the equivalence relation with respect to $N$, not $F
$.

---

### Setup

Recall the definition. For an integrable random variable $X$ on $(\Omega, F, P)$
 and a sub-$\sigma$-algebra $N \subseteq F$, the conditional expectation $E(X \m
id N)$ is an $N$-measurable random variable $Y$ satisfying

$$\int_A Y\,dP \;=\; \int_A X\,dP \qquad \text{for every } A \in N. \tag{$\star$
}$$

The phrase "defined up to a.e. equivalence" means: if $Y$ and $Y'$ both satisfy
($\star$) and are $N$-measurable, then $Y = Y'$ a.e. The question is: a.e. with
respect to which $\sigma$-algebra — $F$ or $N$?

### Uniqueness is proved inside $N$

Let $Y, Y'$ be two $N$-measurable versions of $E(X\mid N)$. Set $Z := Y - Y'$, w
hich is $N$-measurable (difference of $N$-measurable functions). By ($\star$),

$$\int_A Z\,dP = 0 \qquad \text{for every } A \in N. \tag{1}$$

Consider the sets
$$A^+ := \{Z > 0\} = \{Y > Y'\}, \qquad A^- := \{Z < 0\} = \{Y < Y'\}.$$

Since $Z$ is $N$-measurable, both $A^+$ and $A^-$ belong to $N$. Applying (1) wi
th $A = A^+$:

$$\int_{A^+} Z\,dP = 0, \quad Z > 0 \text{ on } A^+ \;\Longrightarrow\; P(A^+) =
 0.$$

Likewise $P(A^-) = 0$. Therefore

$$\{Y \neq Y'\} \;=\; A^+ \cup A^- \;\in\; N, \qquad P(\{Y \neq Y'\}) = 0. \tag{
2}$$

Equation (2) is precisely the statement that $Y = Y'$ **$N$-a.e.**: the exceptio
nal set is an $N$-measurable $P$-null set.

### Why $N$ and not $F$

The conditional expectation is canonically an element of the Banach space

$$L^1(\Omega, N, P|_N),$$

the space of $N$-measurable integrable functions modulo $N$-a.e. equivalence. Th
e quotient is taken with respect to $N$ because:

1. **Domain of the function space.** $E(X\mid N)$ is required to be $N$-measurab
le, so it lives in the function space built on $(\Omega, N, P|_N)$, whose null s
ets are the $N$-measurable $P$-null sets.

2. **The uniqueness argument uses only $N$.** The proof above only ever tests ag
ainst sets $A \in N$ (namely $A^+, A^-$), and only uses $N$-measurability of $Z$
 to conclude $A^\pm \in N$. The $\sigma$-algebra $F$ never enters.

3. **$F$-a.e. is the wrong (coarser) notion here.** An $F$-null set need not lie
 in $N$. Using $F$-a.e. equivalence would identify two $N$-measurable functions
that differ on an $F$-null set outside $N$ — but such a set is invisible to the
defining property ($\star$), which only integrates over $N$-sets. The natural, i
ntrinsic equivalence is the one generated by $N$-null sets.

### Reconciliation: the two notions coincide on $N$-measurable functions

For completeness, note that for $N$-measurable functions the two equivalence rel
ations actually agree. If $Y, Y'$ are $N$-measurable, then $\{Y \neq Y'\} \in N$
 automatically, so

$$\{Y \neq Y'\} \text{ is an } N\text{-null set} \;\iff\; \{Y \neq Y'\} \text{ i
s an } F\text{-null set},$$

because $N \subseteq F$ makes every $N$-null set an $F$-null set, and conversely
 $\{Y\neq Y'\}\in N$ forces any $F$-nullity of it to already be $N$-nullity. So
on the class of $N$-measurable functions, "$N$-a.e." and "$F$-a.e." produce the
same equivalence classes.

The point is nevertheless that the **correct/canonical** answer is **$N$**: the
conditional expectation is defined as an element of $L^1(\Omega, N, P|_N)$, and
its a.e. uniqueness is the $N$-a.e. uniqueness intrinsic to that space. The fact
 that it happens to coincide with $F$-a.e. on $N$-measurable functions is a cons
equence, not the definition.

### Conclusion

The almost-everywhere equivalence relation of $E(X \mid N)$ is with respect to *
*$N$**. The conditional expectation is unique up to $N$-a.e. equivalence, i.e. u
p to modification on an $N$-measurable $P$-null set, because it is defined as an
 element of $L^1(\Omega, N, P|_N)$ and its uniqueness is established using only
$N$-measurable test sets.
