## Proof

We consider the series $\sum_{n=3}^{\infty} \frac{1}{n\ln n\,(\ln\ln n)^p}$ (int
erpreting the index as $n$, since the summand depends on $n$).

**Step 1: Reduction via the integral test.**

For $n \ge 3$, the function $f(x) = \frac{1}{x\ln x\,(\ln\ln x)^p}$ is positive,
 continuous, and decreasing (for $x$ large enough that $\ln\ln x > 0$, i.e., $x
> e$). By the integral test, the series converges if and only if the improper in
tegral

$$\int_{3}^{\infty} \frac{dx}{x\ln x\,(\ln\ln x)^p}$$

converges.

**Step 2: Evaluate the integral.**

Substitute $u = \ln\ln x$, so $du = \frac{1}{x\ln x}\,dx$. When $x = 3$, $u = \l
n\ln 3$; as $x \to \infty$, $u \to \infty$. The integral becomes

$$\int_{\ln\ln 3}^{\infty} \frac{du}{u^p}.$$

**Step 3: Convergence of the $p$-integral.**

The integral $\int_{a}^{\infty} u^{-p}\,du$ (with $a = \ln\ln 3 > 0$) converges
if and only if $p > 1$:

- If $p > 1$: $\int_{a}^{\infty} u^{-p}\,du = \frac{a^{1-p}}{p-1} < \infty$.
- If $p = 1$: $\int_{a}^{\infty} u^{-1}\,du = \ln u\,\Big|_{a}^{\infty} = \infty
$.
- If $p < 1$: $\int_{a}^{\infty} u^{-p}\,du = \frac{u^{1-p}}{1-p}\Big|_{a}^{\inf
ty} = \infty$ (since $1 - p > 0$).

**Conclusion.**

By the integral test, the series $\sum_{n=3}^{\infty} \frac{1}{n\ln n\,(\ln\ln n
)^p}$ converges if and only if $p > 1$.

### PROOF COMPLETE
