## Answer

**No.** $X_n = O_P(a_n)$ with $a_n \to 0$ does **not** imply $X_n \xrightarrow{\
text{a.s.}} 0$.

### Reasoning

The notation $X_n = O_P(a_n)$ is a statement about the **marginal** distribution
 of each $X_n$: for every $\varepsilon > 0$ there exist $M > 0$ and $N \in \math
bb{N}$ such that
$$P\!\bigl(|X_n| > M\,a_n\bigr) < \varepsilon \quad \text{for all } n \ge N.$$
It controls the tail of each term individually but says nothing about the **join
t** distribution of the sequence $(X_n)$. Almost-sure convergence, by contrast,
is a statement about the joint behavior: $P\!\bigl(X_n \to 0\bigr) = 1$. The gap
 between marginal control and joint control is exactly the gap between convergen
ce in probability and almost-sure convergence.

Indeed, $X_n = O_P(a_n)$ with $a_n \to 0$ does imply $X_n \xrightarrow{P} 0$ (ta
ke $M$ fixed, then $M a_n \to 0$ forces $P(|X_n|>\delta)\to 0$ for every $\delta
>0$), but convergence in probability is strictly weaker than almost-sure converg
ence.

### Counterexample

Let the probability space be $([0,1],\mathcal{B},\lambda)$ (Lebesgue measure), o
r any space rich enough to support independent Bernoulli variables. Define **ind
ependent** random variables
$$X_n = \begin{cases} 1 & \text{with probability } 1/n,\\ 0 & \text{with probabi
lity } 1-1/n. \end{cases}$$
Set $a_n = 1/n$, so $a_n \to 0$.

**Claim 1: $X_n = O_P(a_n)$.** For any $\varepsilon > 0$, choose $M = 1$ and $N
> 1/\varepsilon$. For $n \ge N$ we have $a_n = 1/n \le 1 < 1$... more precisely
$a_n = 1/n \le 1/N < 1$, so $M a_n = 1/n < 1$, and since $X_n \in \{0,1\}$,
$$P\!\bigl(|X_n| > M a_n\bigr) = P(X_n = 1) = \frac{1}{n} \le \frac{1}{N} < \var
epsilon.$$
Hence $X_n = O_P(1/n)$. ✓

**Claim 2: $X_n \not\xrightarrow{\text{a.s.}} 0$.** The events $\{X_n = 1\}$ are
 independent (by construction) and
$$\sum_{n=1}^{\infty} P(X_n = 1) = \sum_{n=1}^{\infty} \frac{1}{n} = \infty.$$
By the **second Borel–Cantelli lemma**, $P(X_n = 1 \text{ infinitely often}) = 1
$. Therefore on a set of probability $1$, the sequence $X_n$ equals $1$ for infi
nitely many $n$, so $X_n$ cannot converge to $0$. Hence $X_n \not\xrightarrow{\t
ext{a.s.}} 0$. ✓

### Conclusion

$X_n = O_P(a_n)$ and $a_n \to 0$ give only convergence **in probability** to $0$
, which is strictly weaker than almost-sure convergence. The counterexample abov
e — independent Bernoulli$(1/n)$ variables with $a_n = 1/n$ — satisfies the hypo
thesis but fails the conclusion, since $X_n = 1$ infinitely often almost surely.
