## Setting Up the Framework

**State representation.** After any move, the state is a multiset of 2 or 3 pile
s. The initial state is $\{N, N, N\}$.

**Key definition.** For a positive integer $a$, define $P(a)$ = the set of Grund

r 3 non-empty parts. Since splitting $a$ produces a state $\{b_1, \ldots, b_m\}$

b_j)\bigr)$, we get:

$$P(1) = \emptyset, \qquad P(a) = \left\{\operatorname{mex}\!\Bigl(\bigcup_{j} P
(b_j)\Bigr) : (b_1,\ldots,b_m) \text{ is a 2- or 3-split of } a,\; m\in\{2,3\}\r
ight\}$$

**Grundy of the initial state.** From state $S = \{a_1, \ldots, a_k\}$, a player
 picks one pile $a_i$ and splits it (discarding others), so:
$$g(S) = \operatorname{mex}\!\Bigl(\bigcup_{i=1}^k P(a_i)\Bigr).$$
For the initial state $\{N, N, N\}$: $g = \operatorname{mex}(P(N) \cup P(N) \cup
 P(N)) = \operatorname{mex}(P(N))$.

**Bec wins** iff $g = 0$, i.e., $\operatorname{mex}(P(N)) = 0$, i.e., $0 \notin
P(N)$.

## Characterizing the Losing Pile Sizes

Let $L = \{n \geq 1 : 0 \notin P(n)\}$. I claim:

$$0 \in P(N) \iff N \text{ can be written as a sum of 2 or 3 elements of } L.$$

**Proof of claim.** A 2-split $\{b, N-b\}$ has Grundy value $\operatorname{mex}(
P(b) \cup P(N-b)) = 0$ iff $0 \notin P(b) \cup P(N-b)$, i.e., $b \in L$ and $N-b
 \in L$. Similarly, a 3-split $\{b, c, N-b-c\}$ gives Grundy value 0 iff all thr
ee parts are in $L$. Since $0 \in P(N)$ iff some split yields Grundy value 0, th
e claim follows. $\square$

Therefore: $N \in L$ iff $N$ **cannot** be expressed as a sum of 2 or 3 elements
 of $L$ (all summands $< N$, so this is well-defined inductively).

Now check each residue of $N \geq 2$:
