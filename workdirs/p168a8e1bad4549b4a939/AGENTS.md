# Problem

A high-security data facility consists of 2013 individual server nodes, indexed $1, 2, \dots, 2013$. To prevent cross-talk interference, the network engineers have established specific "Direct Links" between nodes. For any two nodes $m$ and $n$ (where $m < n$), a Direct Link exists if and only if $0 \le n - 2m \le 1$.

The security protocol requires that any two nodes must be assigned different security frequencies if they share a Direct Link or if they are both directly linked to the same common node. There are exactly four available frequencies to choose from. 

Let $N$ be the total number of ways to assign one frequency to each of the 2013 nodes such that the security protocol is satisfied. Find the remainder when $N$ is divided by 1000.
