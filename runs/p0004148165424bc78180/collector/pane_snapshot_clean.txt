## Proof

Let $\omega_1$ denote the first uncountable ordinal, and let

$$L = \{\alpha < \omega_1 : \alpha \text{ is a limit ordinal}\}$$

be the set of all countable limit ordinals. We show that every **nonempty** coun
table subset $S \subseteq L$ satisfies $\sup(S) \in L$. (The empty set has $\sup
(\emptyset)=0\notin L$, which is the only exception.)

---

**Step 1: $\sup(S)$ is countable.**

Since $S$ is countable, write $S = \{\alpha_n : n \in \mathbb{N}\}$. Each $\alph
a_n$ is a countable ordinal, i.e. $\alpha_n < \omega_1$. The supremum of countab
ly many countable ordinals is countable: indeed $\sup(S) = \bigcup_{n} \alpha_n$
 is a countable union of countable sets, hence countable. Therefore

$$\sup(S) < \omega_1.$$

**Step 2: $\sup(S)$ is not a successor ordinal.**

Suppose for contradiction that $\sup(S) = \gamma + 1$ for some ordinal $\gamma$.
 By definition of supremum, for every $\delta < \gamma+1$ there exists $s \in S$
 with $\delta < s \leq \gamma+1$. Taking $\delta = \gamma$, there is $s \in S$ w
ith $\gamma < s \leq \gamma+1$, forcing $s = \gamma+1 = \sup(S)$. But then $\gam
ma+1 \in S \subseteq L$, meaning $\gamma+1$ is a limit ordinal — contradicting t
he fact that $\gamma+1$ is a successor ordinal. Hence $\sup(S)$ is not a success
or.

**Step 3: $\sup(S)$ is a limit ordinal.**

Since $S$ is nonempty, $\sup(S) \geq \min S > 0$ (every limit ordinal is positiv
e). Combined with Step 2, $\sup(S)$ is a nonzero ordinal that is not a successor
, which is exactly the definition of a limit ordinal.

**Step 4: Conclusion.**

From Steps 1 and 3, $\sup(S)$ is a countable limit ordinal, i.e. $\sup(S) \in L$
.

---

Therefore every nonempty countable subset of the set of countable limit ordinals
 has its least upper bound within the set of countable limit ordinals. **The ans
wer is yes** (with the sole trivial exception of the empty set, whose supremum i
s $0$, which is not a limit ordinal).
