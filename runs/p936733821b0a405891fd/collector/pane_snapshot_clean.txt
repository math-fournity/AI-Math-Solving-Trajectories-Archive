证明

问题重述

在随机图模型 $G(n, K/n)$ 中，$K > 1$ 为常数。称一个顶点为"小的"，如果它所在的连
通分量大小在 $2$ 到 $Cn$ 之间，其中 $C = e^{-1000}$。问：是否存在常数 $B > 0$，
使得 $G(n, K/n)$ 中小顶点数 $\geq Bn$ 的概率当 $n \to \infty$ 时趋于 $1$。

关键事实（超临界随机图的经典结构）

当 $K > 1$ 时，$G(n, K/n)$ 处于超临界区域，具有以下经典性质（参见 Bollobás,
Random Graphs; 或 Janson–Łuczak–Ruciński）：

事实 1（巨分量）。 以高概率（w.h.p.），存在一个"巨分量"，其大小为 $\rho n +
o(n)$，其中 $\rho \in (0,1)$ 是 Poisson($K$) 分支过程的存活概率，满足 $$\rho = 1
- e^{-K\rho}.$$ 令 $u = 1 - \rho = e^{-K\rho}$ 为灭绝概率。

事实 2（非巨分量的规模）。 w.h.p.，除巨分量外的所有连通分量的大小均为 $O(\log
n)$。更精确地，第二大分量的 size 为 $\Theta(\log n)$ w.h.p.

事实 3（孤立顶点数）。 顶点 $v$ 为孤立顶点的概率为 $(1 - K/n)^{n-1} \to e^{-
K}$。由 Chebyshev 不等式（二阶矩方法），孤立顶点数为 $e^{-K} n + o(n)$ w.h.p.

事实 4（巨分量外的顶点数）。 w.h.p.，不在巨分量中的顶点数为 $(1-\rho)n + o(n) =
e^{-K\rho} n + o(n)$。

证明

第一步：非巨分量的顶点都在"小"范围内

由事实 2，非巨分量的最大 size 为 $O(\log n)$ w.h.p.。由于 $Cn = e^{-1000} n \to
\infty$ 且 $\log n / n \to 0$，存在 $N_0$ 使得对所有 $n \geq N_0$，有 $\log n
\leq Cn$。因此，w.h.p.，所有非巨分量的 size 均不超过 $Cn$。

第二步：分两种情况讨论

情况 A：$\rho > C = e^{-1000}$。

此时巨分量大小 $\rho n > Cn$（对足够大的 $n$），故巨分量不是"小的"。

小顶点 = 非巨分量中、所在分量 size $\geq 2$ 的顶点。

由事实 4，非巨分量顶点数为 $e^{-K\rho} n + o(n)$ w.h.p.

由事实 3，孤立顶点数为 $e^{-K} n + o(n)$ w.h.p.（孤立顶点当然不在巨分量中）。

因此，小顶点数 $= (e^{-K\rho} - e^{-K})n + o(n)$ w.h.p.

关键不等式：由于 $K > 1$，有 $\rho \in (0,1)$，故 $K\rho < K$，从而 $$e^{-K\rho}
> e^{-K}, \quad \text{即} \quad e^{-K\rho} - e^{-K} > 0.$$

取 $B = \frac{1}{2}(e^{-K\rho} - e^{-K}) > 0$。则 w.h.p. 小顶点数 $\geq Bn$。

情况 B：$\rho \leq C = e^{-1000}$。

此时巨分量大小 $\rho n \leq Cn$（对足够大的 $n$），故巨分量本身也是"小的"。

所有非孤立顶点都是小顶点（因为巨分量 size $\leq Cn$，非巨分量 size $O(\log n)
\leq Cn$，且它们 size $\geq 2$）。

由于 $K > 1 > 0$，有 $e^{-K} < 1$，故 $1 - e^{-K} > 0$。

取 $B = \frac{1}{2}(1 - e^{-K}) > 0$ 即可。

第三步：结论

在两种情况下，均存在常数 $B > 0$（依赖于 $K$）使得小顶点数 $\geq Bn$ 的概率当 $n
\to \infty$ 时趋于 $1$。

  • 若 $\rho \leq e^{-1000}$，取 $B = \frac{1}{2}(1 - e^{-K})$。
