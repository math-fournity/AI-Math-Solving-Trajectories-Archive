Answer

Yes, such a set exists for every $0 < \varepsilon < 1$, no matter how small.

Interpretation

Since $X \subseteq [0,1]$, the only meaningful reading of "for any open set $O$"
is: for every nonempty open set $O \subseteq [0,1]$ (in the relative topology).
(Otherwise one could take $O = (2,3)$, giving $O \cap X = \varnothing$.)
Equivalently, the condition is that $X$ has positive Lebesgue measure in every
open subinterval of $[0,1]$.

Construction

Enumerate the rationals in $[0,1]$ as ${q_1, q_2, q_3, \dots}$. For each $n \ge
1$, let $I_n$ be the open interval centered at $q_n$ with length $
\dfrac{\varepsilon}{2^{n+1}}$, and set $$U ;=; \bigcup_{n=1}^{\infty}\bigl(I_n
\cap [0,1]\bigr).$$

$U$ is open and dense in $[0,1]$. It is open by construction, and it contains
every rational in $[0,1]$, so it is dense.

Measure of $U$ is small. By subadditivity, $$\mu(U) ;\le; \sum_{n=1}
^{\infty}\frac{\varepsilon}{2^{n+1}} ;=; \frac{\varepsilon}{2} ;<; \varepsilon.$
$

$U$ meets every nonempty open set in positive measure. Let $O \subseteq [0,1]$
be any nonempty open set. Then $O$ contains some rational $q_n$, so $O \cap I_n$
is a nonempty open set, hence $$\mu(O \cap U) ;\ge; \mu(O \cap I_n) ;>; 0.$$

Filling up to exactly $\varepsilon$. Since $\mu(U) \le \varepsilon/2 <
\varepsilon$, we have $\mu([0,1]\setminus U) = 1 - \mu(U) > 1 - \varepsilon \ge
\varepsilon - \mu(U)$. Choose any measurable set $A \subseteq [0,1]\setminus U$
with $\mu(A) = \varepsilon - \mu(U)$ (possible because $[0,1]\setminus U$ has
measure at least $\varepsilon - \mu(U)$). Define $$X ;=; U \cup A.$$

Then:

  • $\mu(X) = \mu(U) + \mu(A) = \mu(U) + (\varepsilon - \mu(U)) = \varepsilon$.
  • For any nonempty open $O \subseteq [0,1]$, $$\mu(O \cap X) ;\ge; \mu(O \cap
  U) ;>; 0.$$

Conclusion

The set $X = U \cup A \subseteq [0,1]$ has Lebesgue measure exactly $
\varepsilon$ (which can be taken arbitrarily small, satisfying $0 < \varepsilon
\ll 1$), and satisfies $\mu(O \cap X) > 0$ for every nonempty open set $O
\subseteq [0,1]$. The key mechanism is that $U$ is a dense open set of tiny
measure (built by placing a shrinking interval around every rational), so it
automatically has positive-measure intersection with every open set; the
leftover measure is then filled in from the complement without disturbing this
property.
