## Solution

We solve the linear stochastic differential equation
$$dX_t = W_t X_t\,dt + dW_t, \qquad X_0 \text{ given},$$
where $W_t$ is a Brownian motion (the same one driving the noise and appearing i
n the drift).

### Step 1. Identify the structure

This is a **linear SDE** of the general form
$$dX_t = a_t\,X_t\,dt + b_t\,dW_t,$$
with random coefficients $a_t = W_t$ and $b_t = 1$. Since the drift is linear in
 $X_t$ and the diffusion coefficient is independent of $X_t$, we may use the **v
ariation-of-constants** (integrating factor) method.

### Step 2. Solve the homogeneous equation

Consider the homogeneous (random-coefficient ODE) part
$$d\Phi_t = W_t\,\Phi_t\,dt, \qquad \Phi_0 = 1.$$
This is an ordinary differential equation (the coefficient $W_t$ is random, but
there is no $dW_t$ term, so $\Phi_t$ is a process of finite variation driven by
$dt$). Its solution is
$$\Phi_t = \exp\!\Big(\int_0^t W_s\,ds\Big).$$
By direct differentiation (ordinary chain rule, since the exponent is a finite-v
ariation process),
$$d\Phi_t = W_t\,\Phi_t\,dt.$$

### Step 3. Apply variation of constants

Set $Z_t = \Phi_t^{-1} X_t$, where
$$\Phi_t^{-1} = \exp\!\Big(-\int_0^t W_s\,ds\Big).$$
Since $\Phi_t^{-1}$ is of finite variation (it satisfies $d(\Phi_t^{-1}) = -W_t\
,\Phi_t^{-1}\,dt$ with no martingale part), the quadratic covariation $[\Phi^{-1
}, X]_t$ vanishes. Applying Itô's product rule:
$$dZ_t = d(\Phi_t^{-1} X_t) = \Phi_t^{-1}\,dX_t + X_t\,d(\Phi_t^{-1}) + \underbr
ace{d[\Phi^{-1}, X]_t}_{=\,0}.$$

Substituting $dX_t = W_t X_t\,dt + dW_t$ and $d(\Phi_t^{-1}) = -W_t\,\Phi_t^{-1}
\,dt$:
$$dZ_t = \Phi_t^{-1}\big(W_t X_t\,dt + dW_t\big) + X_t\big(-W_t\,\Phi_t^{-1}\,dt
\big) = \Phi_t^{-1}\,dW_t.$$

The $dt$ terms cancel exactly, leaving a pure Itô integral:
$$dZ_t = \Phi_t^{-1}\,dW_t = \exp\!\Big(-\int_0^t W_s\,ds\Big)\,dW_t.$$

### Step 4. Integrate and recover $X_t$

Integrating from $0$ to $t$ and using $Z_0 = \Phi_0^{-1} X_0 = X_0$:
$$Z_t = X_0 + \int_0^t \exp\!\Big(-\int_0^s W_u\,du\Big)\,dW_s.$$

Multiplying back by $\Phi_t$:
$$\boxed{\,X_t = \exp\!\Big(\int_0^t W_s\,ds\Big)\left[X_0 + \int_0^t \exp\!\Big
(-\int_0^s W_u\,du\Big)\,dW_s\right].\,}$$

### Step 5. Verification

Let $\Phi_t = \exp\!\big(\int_0^t W_s\,ds\big)$ and $M_t = X_0 + \int_0^t \Phi_s
^{-1}\,dW_s$, so $X_t = \Phi_t M_t$. Then:
- $d\Phi_t = W_t\,\Phi_t\,dt$ (finite variation, no $dW$ part),
- $dM_t = \Phi_t^{-1}\,dW_t$.

By Itô's product rule (with $[\Phi, M]_t = 0$ since $\Phi$ has finite variation)
:
$$dX_t = \Phi_t\,dM_t + M_t\,d\Phi_t = \Phi_t\cdot\Phi_t^{-1}\,dW_t + M_t\cdot W
_t\,\Phi_t\,dt = dW_t + W_t\,X_t\,dt.$$

This recovers $dX_t = W_t X_t\,dt + dW_t$, and $X_0 = \Phi_0 M_0 = 1\cdot X_0 =
X_0$. The initial condition is satisfied. $\blacksquare$
