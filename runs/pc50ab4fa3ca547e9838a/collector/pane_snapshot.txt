## Solution

We solve the PDE using the method of characteristic curves.

**The PDE:** $-x\,u_x + u\,u_y = y$, with boundary condition $u(x,2x)=0$.

### Step 1: Characteristic equations

For a first-order PDE $a(x,y,u)\,u_x + b(x,y,u)\,u_y = c(x,y,u)$, the characteri
stic system is:
$$\frac{dx}{ds} = -x, \qquad \frac{dy}{ds} = u, \qquad \frac{du}{ds} = y.$$

### Step 2: Initial data

The boundary condition is prescribed on the curve $\Gamma: (x_0,\, y_0) = (x_0,\
, 2x_0)$ with $u_0 = 0$ at $s=0$.

### Step 3: Solve the characteristic ODEs

From $\frac{dx}{ds} = -x$:
$$x(s) = x_0\, e^{-s}.$$

From $\frac{dy}{ds}=u$ and $\frac{du}{ds}=y$, differentiating the first gives:
$$\frac{d^2 y}{ds^2} = \frac{du}{ds} = y \;\;\Longrightarrow\;\; y'' - y = 0.$$

The general solution is $y(s) = A\,e^{s} + B\,e^{-s}$. Applying initial conditio
ns:
- $y(0) = A + B = 2x_0$
- $y'(0) = u(0) = A - B = 0$

So $A = B = x_0$, giving:
$$y(s) = x_0\bigl(e^{s}+e^{-s}\bigr), \qquad u(s) = y'(s) = x_0\bigl(e^{s}-e^{-s
}\bigr).$$

### Step 4: Eliminate parameters $(x_0, s)$

From $x = x_0\, e^{-s}$ we get $x_0 = x\, e^{s}$. Substituting:

$$y = x\,e^{s}\bigl(e^{s}+e^{-s}\bigr) = x\bigl(e^{2s}+1\bigr),$$
$$u = x\,e^{s}\bigl(e^{s}-e^{-s}\bigr) = x\bigl(e^{2s}-1\bigr).$$

Let $t = e^{2s}$. Then:
$$y = x(t+1) \;\Longrightarrow\; t = \frac{y}{x} - 1.$$

Substituting into $u$:
$$u = x\!\left(\frac{y}{x}-1-1\right) = x\!\left(\frac{y}{x}-2\right) = y - 2x.$
$

### Step 5: Verification

- **PDE:** $u_x = -2$, $u_y = 1$, so $-x\,u_x + u\,u_y = -x(-2) + (y-2x)(1) = 2x
 + y - 2x = y.$ ✓
- **Boundary condition:** $u(x,2x) = 2x - 2x = 0.$ ✓

### Result

$$\boxed{u(x,y) = y - 2x}$$
