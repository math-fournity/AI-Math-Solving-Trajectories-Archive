## Proof

We count the number of proper colorings of a cycle $C_{12}$ (twelve workstations
 in a ring) using $6$ colors (lubricant types), where adjacent vertices must rec
eive distinct colors.

### Chromatic polynomial of a cycle

Let $P(C_n, k)$ denote the number of proper $k$-colorings of the cycle $C_n$. We
 derive the standard formula.

**Counting paths first.** Let $P_n(k)$ be the number of proper $k$-colorings of
a path on $n$ vertices. The first vertex has $k$ choices, and each subsequent ve
rtex has $k-1$ choices (anything except its predecessor's color), so
$$P_n(k) = k(k-1)^{n-1}.$$

**Relating the cycle to paths.** Take the cycle $C_n$ with vertices $v_1, v_2, \
dots, v_n$ in order. If we cut the edge $\{v_n, v_1\}$, we get a path on $n$ ver
tices, giving $P_n(k) = k(k-1)^{n-1}$ colorings. Among these, we must subtract t
hose where $v_n$ and $v_1$ happen to receive the **same** color (since those are
 not valid for the cycle).

**Counting the bad colorings (where $v_n = v_1$).** If $v_1$ and $v_n$ share a c
olor, identify them into a single vertex. The resulting graph is a cycle $C_{n-1
}$: the path $v_1 - v_2 - \cdots - v_{n-1} - v_n$ with $v_n$ glued onto $v_1$ be
comes $v_1(=v_n) - v_2 - \cdots - v_{n-1} - v_1$, which is exactly $C_{n-1}$. Th
e number of such colorings is $P(C_{n-1}, k)$.

Therefore:
$$P(C_n, k) = P_n(k) - P(C_{n-1}, k) = k(k-1)^{n-1} - P(C_{n-1}, k).$$

**Solving the recurrence.** Define $Q_n = P(C_n,k)$. Then
$$Q_n = k(k-1)^{n-1} - Q_{n-1}, \qquad Q_3 = k(k-1)(k-2).$$

We claim $Q_n = (k-1)^n + (-1)^n(k-1)$. Check the base case $n=3$:
$$(k-1)^3 + (-1)^3(k-1) = (k-1)^3 - (k-1) = (k-1)\big[(k-1)^2 - 1\big] = (k-1)(k
^2-2k) = k(k-1)(k-2). \checkmark$$

Inductive step, assuming $Q_{n-1} = (k-1)^{n-1} + (-1)^{n-1}(k-1)$:
$$Q_n = k(k-1)^{n-1} - \big[(k-1)^{n-1} + (-1)^{n-1}(k-1)\big] = (k-1)^{n-1}(k-1
) - (-1)^{n-1}(k-1).$$
$$= (k-1)^n + (-1)^n(k-1). \checkmark$$

So for all $n \ge 3$:
$$\boxed{P(C_n, k) = (k-1)^n + (-1)^n(k-1)}.$$

### Applying to our problem

Here $n = 12$ (even) and $k = 6$:
$$P(C_{12}, 6) = (6-1)^{12} + (-1)^{12}(6-1) = 5^{12} + 5.$$

Compute $5^{12}$:
$$5^{12} = (5^6)^2 = 15625^2 = 244{,}140{,}625.$$

Therefore:
$$P(C_{12}, 6) = 244{,}140{,}625 + 5 = 244{,}140{,}630.$$

### Answer

The total number of distinct ways the lubricants can be assigned to the twelve w
orkstations around the table is

$$\boxed{244{,}140{,}630}.$$
