## Solution

We solve the ODE $yy'' - (y')^2 = 2\ln y$.

**Substitution.** Set $u = \ln y$, i.e., $y = e^u$. Then

$$y' = e^u u', \qquad y'' = e^u\big((u')^2 + u''\big).$$

Substituting:

$$yy'' = e^{2u}\big((u')^2 + u''\big), \qquad (y')^2 = e^{2u}(u')^2,$$

so the equation becomes

$$e^{2u}\, u'' = 2u \quad\Longrightarrow\quad u'' = 2u\,e^{-2u}.$$

**Reduction of order.** Since $x$ does not appear explicitly, set $p = u' = du/d
x$, so $u'' = p\,dp/du$. Then

$$p\,\frac{dp}{du} = 2u\,e^{-2u}.$$

Integrating both sides with respect to $u$:

$$\frac{p^2}{2} = \int 2u\,e^{-2u}\,du.$$

**Integration by parts** for the right side (let $f = u$, $g' = 2e^{-2u}$, so $g
 = -e^{-2u}$):

$$\int 2u\,e^{-2u}\,du = -u\,e^{-2u} + \int e^{-2u}\,du = -u\,e^{-2u} - \tfrac{1
}{2}e^{-2u} + C.$$

Thus

$$p^2 = -2u\,e^{-2u} - e^{-2u} + C_1 = C_1 - e^{-2u}(2u+1),$$

where $C_1$ is an arbitrary constant.

**Back-substitution.** Since $u = \ln y$, $e^{-2u} = y^{-2}$, and $p = u' = y'/y
$:

$$\frac{(y')^2}{y^2} = C_1 - \frac{2\ln y + 1}{y^2},$$

$$\boxed{(y')^2 = C_1\, y^2 - 2\ln y - 1.}$$

The **general solution in quadrature form** is therefore:

$$\boxed{\int \frac{dy}{\sqrt{C_1\, y^2 - 2\ln y - 1}} = \pm\, x + C_2,}$$

where $C_1, C_2$ are arbitrary constants.

**Verification.** Differentiate $(y')^2 = C_1 y^2 - 2\ln y - 1$ with respect to
$x$:

$$2y'y'' = 2C_1 y\,y' - \frac{2}{y}\,y' \quad\Longrightarrow\quad y'' = C_1 y -
\frac{1}{y}.$$

Then

$$yy'' - (y')^2 = y\!\left(C_1 y - \frac{1}{y}\right) - \big(C_1 y^2 - 2\ln y -
1\big) = C_1 y^2 - 1 - C_1 y^2 + 2\ln y + 1 = 2\ln y. \checkmark$$
