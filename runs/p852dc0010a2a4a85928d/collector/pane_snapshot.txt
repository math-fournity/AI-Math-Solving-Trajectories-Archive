## 解答

**第 1 步：化简分子。**

分子 = $\sin^2 a_3 - \cos^2 a_3 + \cos^2 a_3\cos^2 a_6 - \sin^2 a_3\sin^2 a_6$

重新整理：
$$= \sin^2 a_3(1 - \sin^2 a_6) + \cos^2 a_3(\cos^2 a_6 - 1)$$
$$= \sin^2 a_3\cos^2 a_6 - \cos^2 a_3\sin^2 a_6$$

利用恒等式 $\sin^2 A\cos^2 B - \cos^2 A\sin^2 B = \sin(A+B)\sin(A-B)$：

$$\text{分子} = \sin(a_3+a_6)\sin(a_3-a_6)$$

**第 2 步：利用等差数列性质。**

- $a_3 + a_6 = (a_1+2d)+(a_1+5d) = 2a_1+7d$
- $a_4 + a_5 = (a_1+3d)+(a_1+4d) = 2a_1+7d$

所以 $a_3+a_6 = a_4+a_5$，且 $a_3 - a_6 = -3d$。

方程变为：
$$\frac{\sin(2a_1+7d)\cdot\sin(-3d)}{\sin(2a_1+7d)} = 1$$

（要求 $\sin(2a_1+7d)\neq 0$），因此：

$$\sin(-3d) = 1 \implies \sin(3d) = -1 \implies 3d = -\frac{\pi}{2}+2k\pi$$

$$d = -\frac{\pi}{6}+\frac{2k\pi}{3}$$

由于 $d\in(-1,0)$，只有 $k=0$ 成立：$d = -\frac{\pi}{6}\approx -0.5236\in(-1,0)$
。 ✓

**第 3 步：利用 $S_n$ 在 $n=9$ 处取得最大值的条件。**

$S_n = \frac{n}{2}[2a_1+(n-1)d]$ 是关于 $n$ 的开口向下的抛物线。对于等差数列求和
，当且仅当 $a_9 > 0$ 且 $a_{10} < 0$ 时，$S_n$ 在 $n=9$ 处取得**唯一**最大值（这
保证了 $S_9 > S_8$ 且 $S_9 > S_{10}$，再由凹性可知 $S_9$ 是全局唯一的最大值）。

- $a_9 = a_1 + 8d = a_1 - \frac{8\pi}{6} = a_1 - \frac{4\pi}{3} > 0 \implies a_1
 > \frac{4\pi}{3}$
- $a_{10} = a_1 + 9d = a_1 - \frac{9\pi}{6} = a_1 - \frac{3\pi}{2} < 0 \implies
a_1 < \frac{3\pi}{2}$

**第 4 步：验证 $\sin(2a_1+7d)\neq 0$。**

当 $a_1\in(\frac{4\pi}{3},\frac{3\pi}{2})$ 时：$2a_1 - \frac{7\pi}{6}\in(\frac{3
\pi}{2},\frac{11\pi}{6})$，且 $\sin$ 在此区间内不为零（零点出现在 $2\pi$，超出了
范围）。 ✓

**结论：** $a_1 \in \left(\frac{4\pi}{3},\frac{3\pi}{2}\right)$，即选项 **B**。

最终答案：$\boxed{B}$
