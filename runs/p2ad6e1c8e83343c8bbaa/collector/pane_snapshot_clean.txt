## Solution

Let $r = \tfrac{3}{2}$. The series is
$$S = \sum_{n=1}^{\infty} \frac{r^{f(n)} + r^{-f(n)}}{r^{n}},$$
where $f(n)$ is the integer nearest to $\sqrt{n}$.

### Step 1: Determine the range of $n$ for which $f(n) = k$

Since $\sqrt{n}$ is irrational for non-square $n$ and an integer for square $n$,
 it is never a half-integer, so $f(n)$ is uniquely defined. We have $f(n) = k$ i
ff
$$k - \tfrac{1}{2} < \sqrt{n} < k + \tfrac{1}{2}, \quad\text{i.e.,}\quad (k-\tfr
ac12)^2 < n < (k+\tfrac12)^2.$$
This gives $k^2 - k + \tfrac14 < n < k^2 + k + \tfrac14$, so for integer $n$:
$$f(n) = k \iff n \in \{k^2 - k + 1,\; k^2 - k + 2,\; \ldots,\; k^2 + k\},$$
a set of $2k$ consecutive integers. (For $k=0$ this set is empty, consistent wit
h $n \ge 1$.)

### Step 2: Regroup the series by blocks

$$S = \sum_{k=1}^{\infty} (r^k + r^{-k}) \sum_{n=k^2-k+1}^{k^2+k} r^{-n}.$$

The inner sum is a finite geometric series:
$$\sum_{n=a}^{b} r^{-n} = \frac{r^{-a} - r^{-(b+1)}}{1 - r^{-1}}, \quad a = k^2-
k+1,\; b = k^2+k.$$

### Step 3: Simplify each block

The $k$-th block equals
$$\frac{(r^k + r^{-k})\bigl(r^{-(k^2-k+1)} - r^{-(k^2+k+1)}\bigr)}{1 - r^{-1}}.$
$

Factor: $r^k + r^{-k} = r^{-k}(1 + r^{2k})$ and $r^{-(k^2-k+1)} - r^{-(k^2+k+1)}
 = r^{-(k^2-k+1)}(1 - r^{-2k}) = r^{-(k^2-k+1)} \cdot r^{-2k}(r^{2k}-1)$.

Their product:
$$r^{-k}(1+r^{2k}) \cdot r^{-(k^2-k+1)-2k}(r^{2k}-1) = r^{-(k^2-k+1)-3k}(r^{4k}-
1).$$

The exponent: $-(k^2-k+1) - 3k = -k^2 - 2k - 1 = -(k+1)^2$.

So the $k$-th block is
$$\frac{r^{-(k+1)^2}(r^{4k}-1)}{1-r^{-1}} = \frac{r^{4k-(k+1)^2} - r^{-(k+1)^2}}
{1-r^{-1}} = \frac{r^{-(k-1)^2} - r^{-(k+1)^2}}{1-r^{-1}},$$
since $4k - (k+1)^2 = 4k - k^2 - 2k - 1 = -(k-1)^2$.

### Step 4: Telescope

$$S = \frac{1}{1-r^{-1}} \sum_{k=1}^{\infty}\bigl(r^{-(k-1)^2} - r^{-(k+1)^2}\bi
gr).$$

The partial sum through $k = K$:
$$\sum_{k=1}^{K}\bigl(r^{-(k-1)^2} - r^{-(k+1)^2}\bigr) = \sum_{m=0}^{K-1} r^{-m
^2} - \sum_{m=2}^{K+1} r^{-m^2} = 1 + r^{-1} - r^{-K^2} - r^{-(K+1)^2}.$$

Since $r = \tfrac32 > 1$, both $r^{-K^2} \to 0$ and $r^{-(K+1)^2} \to 0$ as $K \
to \infty$. Therefore
$$S = \frac{1 + r^{-1}}{1 - r^{-1}} = \frac{1 + \tfrac{2}{3}}{1 - \tfrac{2}{3}}
= \frac{5/3}{1/3} = \boxed{5}.$$
