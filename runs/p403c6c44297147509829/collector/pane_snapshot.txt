## Key Simplification

**Lemma.** For positive integers $n < m$, we have $m - n \geq \sqrt{n} + \sqrt{m
}$ if and only if $\sqrt{m} - \sqrt{n} \geq 1$.

*Proof.* Let $u = \sqrt{n}$, $v = \sqrt{m}$ with $v > u > 0$. Then:
$$m - n = v^2 - u^2 = (v-u)(v+u), \qquad \sqrt{n} + \sqrt{m} = u + v.$$
So $m - n \geq \sqrt{n} + \sqrt{m}$ becomes $(v-u)(v+u) \geq (v+u)$, which (divi
ding by $v+u > 0$) gives $v - u \geq 1$, i.e., $\sqrt{m} - \sqrt{n} \geq 1$. $\s
quare$

## Reformulation

Call a pair $(n, m)$ **close** if $\sqrt{m} - \sqrt{n} < 1$ and **far** if $\sqr
t{m} - \sqrt{n} \geq 1$. A **bad triple** $\{a, b, c\}$ (with $a < b < c$) is on
e where all three pairs are close. Since $\sqrt{a} < \sqrt{b} < \sqrt{c}$, the c
ondition that all pairs are close is equivalent to:
$$\sqrt{c} - \sqrt{a} < 1,$$
because $\sqrt{c} - \sqrt{a} = (\sqrt{c} - \sqrt{b}) + (\sqrt{b} - \sqrt{a}) \ge
q \max(\sqrt{c}-\sqrt{b},\, \sqrt{b}-\sqrt{a})$, so if $\sqrt{c} - \sqrt{a} < 1$
 then both smaller gaps are $< 1$, and conversely if $\sqrt{c} - \sqrt{a} \geq 1
$ the triple is good.

So $A$ is valid **iff every triple in $A$ has $\sqrt{}$-range $\geq 1$**, i.e.,
for all $a < b < c$ in $A$: $\sqrt{c} - \sqrt{a} \geq 1$.

**Reduction to consecutive triples.** Sort $A = \{a_1 < a_2 < \cdots < a_k\}$ an

- ($\Leftarrow$): If $x_{i+2} - x_i \geq 1$ for all $i$, then for $i < j < \ell$

- ($\Rightarrow$): Take $j = i+1, \ell = i+2$.

Thus **$A$ is valid iff $\sqrt{a_{i+2}} - \sqrt{a_i} \geq 1$ for all $i = 1, \ld

All $\sqrt{}$-values lie in $[1, \sqrt{2018})$. Since $44^2 = 1936 < 2018 < 2025
