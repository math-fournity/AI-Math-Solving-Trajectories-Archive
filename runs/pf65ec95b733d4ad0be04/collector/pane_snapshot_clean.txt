## Setting Up the Nested Radical

Let $y = \sqrt{x + \sqrt{x + \sqrt{x + \cdots}}}$. For $x > 0$, this nested radi
cal converges (the sequence $a_1 = \sqrt{x}$, $a_{n+1} = \sqrt{x + a_n}$ is incr
easing and bounded). At the fixed point:

$$y = \sqrt{x + y} \implies y^2 = x + y \implies y^2 - y - x = 0$$

Taking the positive root: $y = \frac{1 + \sqrt{1 + 4x}}{2}$.

Therefore:
$$f(x) = x + \frac{1 + \sqrt{1 + 4x}}{2}$$

## Reformulating the Inequality

We need $f(x) \geq 50\sqrt{x}$, i.e.:

$$x + \frac{1 + \sqrt{1+4x}}{2} \geq 50\sqrt{x}$$

Let $t = \sqrt{x}$ (so $x = t^2$, $t > 0$). Multiply by 2:

$$2t^2 + 1 + \sqrt{1 + 4t^2} \geq 100t$$

$$\sqrt{1 + 4t^2} \geq 100t - 2t^2 - 1$$

**Case 1:** If $100t - 2t^2 - 1 \leq 0$ (i.e., $2t^2 - 100t + 1 \geq 0$), the in
equality holds automatically since the left side is positive. This gives $t \geq
 \frac{100 + \sqrt{9992}}{4} \approx 49.99$.

**Case 2:** If $100t - 2t^2 - 1 > 0$, both sides are positive, so squaring prese
rves the inequality:

$$1 + 4t^2 \geq (100t - 2t^2 - 1)^2 = (2t^2 - 100t + 1)^2$$

Expanding the right side:

$$(2t^2 - 100t + 1)^2 = 4t^4 - 400t^3 + 10004t^2 - 200t + 1$$

So the inequality becomes:

$$1 + 4t^2 \geq 4t^4 - 400t^3 + 10004t^2 - 200t + 1$$

$$0 \geq 4t^4 - 400t^3 + 10000t^2 - 200t = 4t(t^3 - 100t^2 + 2500t - 50)$$

Since $t > 0$, divide by $4t$:

$$t^3 - 100t^2 + 2500t - 50 \leq 0$$

**Key observation:** $t^3 - 100t^2 + 2500t = t(t^2 - 100t + 2500) = t(t - 50)^2$

$$t(t - 50)^2 \leq 50$$
