## Proof

**Claim.** The only linear transformations $T: V \to V$ whose matrix representat
ion is independent of the choice of basis are the scalar multiples of the identi
ty, $T = \lambda I$ for some $\lambda \in \mathbb{R}$.

---

### Setup

Fix any basis $\mathcal{B}$ of $V$ and let $A = [T]_{\mathcal{B}}$ be the matrix
 of $T$ in this basis. A change of basis by an invertible matrix $P$ transforms
the matrix representation to $P^{-1}AP$. The condition that the matrix represent
ation is independent of the basis is:

$$P^{-1}AP = A \quad \text{for every invertible } P \in GL_n(\mathbb{R}).$$

Equivalently, $AP = PA$ for every invertible $P$.

### Step 1: $A$ commutes with every matrix, not just invertible ones

Let $M$ be an arbitrary $n \times n$ real matrix (not necessarily invertible). W
e show $AM = MA$.

For $t \in \mathbb{R}$, consider $P_t = (t I + M)$. For all but finitely many va
lues of $t$, the matrix $P_t$ is invertible (its determinant is a nonzero polyno
mial in $t$, hence vanishes at only finitely many points). For every such $t$:

$$A(tI + M) = (tI + M)A \implies tA + AM = tA + MA \implies AM = MA.$$

Both sides are polynomials in $t$ that agree for infinitely many values of $t$,
so they agree identically. Hence $AM = MA$ for **every** matrix $M$.

### Step 2: Matrices commuting with all matrices are scalar

We show $A = \lambda I$. Let $E_{ij}$ be the matrix with $1$ in position $(i,j)$
 and $0$ elsewhere. Since $A$ commutes with every matrix, in particular $AE_{ij}
 = E_{ij}A$ for all $i, j$.

Computing both sides:
- $AE_{ij}$ has the $i$-th column of $A$ placed in column $j$, and zeros elsewhe
re; equivalently, $(AE_{ij})_{kl} = A_{ki}\,\delta_{jl}$.
- $E_{ij}A$ has the $j$-th row of $A$ placed in row $i$, and zeros elsewhere; eq
uivalently, $(E_{ij}A)_{kl} = \delta_{ik}\,A_{jl}$.

Equality for all $k, l$ gives $A_{ki}\delta_{jl} = \delta_{ik}A_{jl}$.

**Diagonal entries are equal.** Set $i = j$ and $k = l = i$: $A_{ii} = A_{ii}$ (
no info), but set $k = i$, $l = j = i$: we get $A_{ii} = A_{ii}$. To compare dia
gonal entries, take $i \neq j$ and set $k = i$, $l = j$: $A_{ii}\,\delta_{jj} =
\delta_{ii}\,A_{jj}$, i.e., $A_{ii} = A_{jj}$. So all diagonal entries are equal
; call the common value $\lambda$.

**Off-diagonal entries are zero.** Take $i \neq j$, set $k = i$, $l = j$: $A_{ii
}\cdot 1 = 1 \cdot A_{jj}$, already used. Now set $k = j$, $l = j$ with $i \neq
j$: $A_{ji}\cdot 1 = \delta_{ij}\cdot A_{jj} = 0$, so $A_{ji} = 0$. Since $i \ne
q j$ was arbitrary, all off-diagonal entries vanish.

Therefore $A = \lambda I$ for some $\lambda \in \mathbb{R}$.

### Step 3: Converse

If $T = \lambda I$, then $[T]_{\mathcal{B}} = \lambda I$ in every basis $\mathca
l{B}$, and $\lambda I$ commutes with every matrix, so $P^{-1}(\lambda I)P = \lam
bda I$ for all invertible $P$. The matrix representation is indeed basis-indepen
dent.

### Conclusion

The linear transformations $T: V \to V$ (with $\dim V = n > 1$) whose matrix rep
resentation is independent of the basis are precisely the **scalar multiples of
the identity**:

$$\boxed{T = \lambda\, I_V \quad \text{for some } \lambda \in \mathbb{R}.}$$

The hypothesis $n > 1$ is essential: for $n = 1$ every linear map is a scalar mu
ltiple of the identity, so the condition is vacuous and imposes no restriction.
