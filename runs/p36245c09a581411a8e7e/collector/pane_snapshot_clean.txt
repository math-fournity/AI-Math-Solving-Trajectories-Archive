## Proof

**Step 1: Reduction to a tree condition.**

$f(x) = cx(x-1)$ is an upward parabola with minimum $-c/4$ at $x = \tfrac{1}{2}$
. Thus $f(x) = t$ has real solutions iff $t \geq -c/4$.

Since $f(y) = 0 \iff y \in \{0,1\}$, we have $f^n(x) = 0 \iff f^{n-1}(x) \in \{0
,1\}$. The roots of $f^n$ are the roots of $f^{n-1}$ together with the solutions
 of $f^{n-1}(x) = 1$. Since $f^1$ has roots $0, 1$ (both real), by induction:

> **Condition:** All roots of $f^n$ are real for all $n$ $\iff$ all solutions of
 $f^n(x) = 1$ are real for all $n \geq 1$.

**Step 2: The preimage tree.**

Define $T_0 = \{1\}$ and $T_{k+1} = f^{-1}(T_k)$. Then $T_n$ is exactly the solu
tion set of $f^n(x) = 1$, which has $2^n$ elements. For all of these to be real,
 every value $v \in T_k$ ($k = 0, \ldots, n-1$) must satisfy $v \geq -c/4$.

For $v \geq -c/4$, the two preimages are:
$$a(v) = \frac{1 + \sqrt{1 + 4v/c}}{2}, \qquad b(v) = \frac{1 - \sqrt{1 + 4v/c}}
{2},$$
with $a(v) + b(v) = 1$, $a(v)b(v) = -v/c$. Note $a$ is increasing, $b$ is decrea
sing, and $a(v) \geq \tfrac{1}{2} \geq b(v)$.

**Step 3: Fixed point and key boundary.**

The map $a$ has a fixed point $v^* = 1 + \tfrac{1}{c}$ (solving $a(v) = v$). One
 checks $a(v) > v$ for $v < v^*$, so the iterates $a^k(1)$ increase strictly to
$v^*$. Since $b$ is decreasing and $b(v^*) = 1 - v^* = -\tfrac{1}{c}$, the value
s $b(a^k(1)) \in T_{k+1}$ decrease strictly to $-\tfrac{1}{c}$.

**Step 4: Invariant interval for $c \geq 2$.**

Consider $I = [-\tfrac{1}{c},\; v^*] = [-\tfrac{1}{c},\; 1 + \tfrac{1}{c}]$. For
 $c \geq 2$:

- **$a$ maps $I$ into $I$:** For $v \in I$, we have $1 + 4v/c \geq 1 - 4/c^2 \ge
q 0$ (since $c \geq 2$), so $a(v)$ is real. Then $a(v) \geq \tfrac{1}{2} \geq -\
tfrac{1}{c}$, and $a(v) \leq a(v^*) = v^*$.

- **$b$ maps $I$ into $I$:** $b(v) \leq \tfrac{1}{2} \leq v^*$, and $b(v) \geq b
(v^*) = -\tfrac{1}{c}$ (since $b$ is decreasing and $v \leq v^*$).

Since $1 \in I$, **every value in the tree lies in $I$**. Moreover, $v^*$ is nev
er attained in the tree (it is only a limit of $a$-iterates, and $b(v) = v^*$ is
 impossible since $b(v) \leq \tfrac{1}{2} < v^*$). Therefore $-\tfrac{1}{c} = b(
v^*)$ is also never attained, so **all tree values are strictly greater than $-\
tfrac{1}{c}$**.

For $c \geq 2$: $-\tfrac{1}{c} \geq -\tfrac{c}{4}$ (equivalent to $c^2 \geq 4$).
 Hence every tree value satisfies $v > -\tfrac{1}{c} \geq -\tfrac{c}{4}$, so all
 preimages are real at every level. ✓

**Step 5: Failure for $c < 2$.**

For $c < 2$: $c^2 < 4$ gives $-\tfrac{1}{c} < -\tfrac{c}{4}$. The values $b(a^k(
1)) \in T_{k+1}$ converge to $-\tfrac{1}{c}$ from above. Since $-\tfrac{1}{c} <
-\tfrac{c}{4}$, for sufficiently large $k$ we get $b(a^k(1)) < -\tfrac{c}{4}$. T
hen $f(x) = b(a^k(1))$ has no real solutions, so $f^{k+2}(x) = 1$ has non-real r
oots. ✗

**Conclusion.**

The condition holds for all $n$ if and only if $c \geq 2$. The smallest possible
 value is:

$$\boxed{c = 2}$$
