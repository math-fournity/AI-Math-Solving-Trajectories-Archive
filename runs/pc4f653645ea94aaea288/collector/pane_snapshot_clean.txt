**Answer: Yes, such an uncountable collection exists.**

## Proof

Let $S = 2^{<\omega}$ be the set of all finite binary strings (i.e., the full bi
nary tree). This is a countable set, since it is a countable union of finite lev
els.

For each infinite binary sequence $x \in 2^{\omega}$ (of which there are uncount
ably many, $|2^\omega| = 2^{\aleph_0}$), define
$$A_x = \{ x{\upharpoonright}n : n \in \mathbb{N},\; n \geq 1 \},$$
the set of all finite initial segments of $x$. Each $A_x$ is an infinite subset
of $S$ (it contains one string of each length).

**The family $\{A_x : x \in 2^{\omega}\}$ is almost disjoint.** Take $x \neq y \
in 2^{\omega}$. Since they differ, there is a first position $k$ at which $x(k)
\neq y(k)$. Then $x{\upharpoonright}n = y{\upharpoonright}n$ only when $n \leq k
$. Hence
$$A_x \cap A_y = \{ x{\upharpoonright}n : 1 \leq n \leq k \},$$
which is finite.

**The family is an antichain under inclusion.** Suppose $x \neq y$ and $A_x \sub
seteq A_y$. Then $A_x \cap A_y = A_x$, which is infinite. But we just showed $A_
x \cap A_y$ is finite — contradiction. So $A_x \not\subseteq A_y$ for any distin
ct $x, y$. By symmetry, neither is a subset of the other.

**The family is uncountable.** The map $x \mapsto A_x$ is injective: if $x \neq
y$, then $x{\upharpoonright}(k+1) \in A_x \setminus A_y$ (where $k$ is the first
 differing position), so $A_x \neq A_y$. Thus $|\{A_x\}| = |2^{\omega}| = 2^{\al
eph_0}$, which is uncountable.

Therefore, $\{A_x : x \in 2^{\omega}\}$ is an uncountable collection of infinite
 subsets of the countable set $S = 2^{<\omega}$, no one of which is a subset of
another. $\blacksquare$
