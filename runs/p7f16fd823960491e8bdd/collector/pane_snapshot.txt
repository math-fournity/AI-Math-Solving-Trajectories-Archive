## Solution

**Setup.** Let O be the origin, the circular base lie in the xy-plane with radiu
s r, and the vertex P = (0, 0, h).

**Determining the cone geometry.** The axial cross-section is the triangle throu
gh P and two diametrically opposite base points X = (r,0,0), Y = (−r,0,0). It is
 isosceles (PX = PY) and right-angled. The right angle must be at P (base angles
 are equal, so neither can be 90°). Thus PX·PY = 0: (r,0,−h)·(−r,0,−h) = −r² + h
² = 0, giving **h = r**.

Since A lies on the circumference, PA = √(r² + h²) = r√2 = 4, so **r = h = 2√2**
.

**Coordinates of A, B.** Place B on the x-axis: B = (x, 0, 0), x = OB. Since AB
⊥ OB with B the foot of the perpendicular from A to line OB, A projects onto the
 x-axis at B, so A = (x, y_A, 0) with x² + y_A² = r² = 8, i.e. y_A = √(8 − x²).
Thus:
- O = (0,0,0), B = (x,0,0), A = (x, √(8−x²), 0), P = (0,0,2√2), with 0 < x < 2√2
.

**Point H.** H is the foot of the perpendicular from O to line PB. Direction d =
 B − P = (x, 0, −2√2). Parameter t = (O−P)·d / |d|² = (0,0,−2√2)·(x,0,−2√2)/(x²+
8) = 8/(x²+8). So:
$$H = P + t\,d = \left(\frac{8x}{x^2+8},\ 0,\ \frac{2\sqrt{2}\,x^2}{x^2+8}\right
).$$

**Point C.** C is the midpoint of PA:
$$C = \left(\frac{x}{2},\ \frac{\sqrt{8-x^2}}{2},\ \sqrt{2}\right).$$

**Volume of tetrahedron O-HPC.** Since O is the origin:
$$V = \frac{1}{6}\bigl|\det[H, P, C]\bigr|.$$

The matrix with columns H, P, C:
$$\begin{pmatrix} \frac{8x}{x^2+8} & 0 & \frac{x}{2} \\ 0 & 0 & \frac{\sqrt{8-x^
2}}{2} \\ \frac{2\sqrt{2}\,x^2}{x^2+8} & 2\sqrt{2} & \sqrt{2} \end{pmatrix}$$

Expanding along row 2: det = (√(8−x²)/2)·M₂₃, where
$$M_{23} = \frac{8x}{x^2+8}\cdot 2\sqrt{2} - 0 = \frac{16\sqrt{2}\,x}{x^2+8}.$$

So det = 8√2 · x√(8−x²)/(x²+8), and
$$V(x) = \frac{4\sqrt{2}}{3}\cdot\frac{x\sqrt{8-x^2}}{x^2+8}.$$

**Maximizing.** Set u = x² (0 < u < 8) and maximize g(u) = u(8−u)/(u+8)². Then:
$$g'(u) = \frac{(8-2u)(u+8) - 2u(8-u)}{(u+8)^3} = \frac{-24u + 64}{(u+8)^3}.$$
Setting g'(u) = 0 gives u = 64/24 = **8/3**. Since g'(u) > 0 for u < 8/3 and g'(
u) < 0 for u > 8/3, this is the maximum.

Therefore x² = 8/3, i.e.
$$OB = x = \sqrt{\frac{8}{3}} = \frac{2\sqrt{6}}{3}.$$

(As a check, the maximum volume is V = (4√2/3)·√(1/8) = 2/3, a clean value confi
rming the computation.)

Final Answer: $\boxed{\dfrac{2\sqrt{6}}{3}}$
