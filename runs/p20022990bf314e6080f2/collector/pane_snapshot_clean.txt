## Counterexample

For $n \ge 1$, let $X_n$ be independent with
$$
X_n = \begin{cases} -a_n & \text{with probability } p_n,\\[4pt] \phantom{-}b_n &
 \text{with probability } 1-p_n, \end{cases}
$$
where $p_n = \dfrac{1}{(n+1)^2}$, $\;a_n = \dfrac{(n+1)^2}{2}$, $\;b_n = \dfrac{
(n+1)^2}{2\bigl((n+1)^2-1\bigr)}$.

**Verification of the hypotheses.**

*Mean zero.* Since $a_n p_n = \tfrac12$ and $b_n(1-p_n) = \dfrac{(n+1)^2}{2((n+1
)^2-1)}\cdot\dfrac{(n+1)^2-1}{(n+1)^2} = \tfrac12$,
$$
E[X_n] = -a_n p_n + b_n(1-p_n) = -\tfrac12 + \tfrac12 = 0.
$$

*First absolute moment.* $E|X_n| = a_n p_n + b_n(1-p_n) = \tfrac12 + \tfrac12 =
1$.

*Independence.* The $X_n$ are independent by construction.

**Key estimate.** Fix any $\varepsilon > 0$. The negative value $-a_n = -\tfrac{
(n+1)^2}{2}$ satisfies $-a_n < -\varepsilon$ for all $n$ large enough (namely $(
n+1)^2 > 2\varepsilon$). The positive value $b_n > 0 > -\varepsilon$ always. Hen
ce for all sufficiently large $n$,
$$
P(X_n < -\varepsilon) = p_n = \frac{1}{(n+1)^2}.
$$
Since $\displaystyle\sum_{n=1}^{\infty} \frac{1}{(n+1)^2} < \infty$, the **first
 Borel–Cantelli lemma** (which requires no independence) gives
$$
P\bigl(X_n < -\varepsilon \text{ infinitely often}\bigr) = 0
\qquad\text{for every } \varepsilon > 0.
$$

**Conclusion.** Recall that
$$
\liminf_{n\to\infty} X_n < 0 \;\iff\; \exists\,\varepsilon>0:\; X_n < -\varepsil
on \text{ infinitely often}.
$$
Indeed, if $\liminf X_n = L < 0$, taking $\varepsilon = -L/2$ yields $X_n < -\va
repsilon$ infinitely often; conversely, $X_n < -\varepsilon$ i.o. forces $\limin
f X_n \le -\varepsilon < 0$.

Taking a countable sequence $\varepsilon = 1/k$ and using a union bound,
$$
P\Bigl(\liminf_{n} X_n < 0\Bigr)
= P\Bigl(\bigcup_{k=1}^{\infty}\{X_n < -1/k \text{ i.o.}\}\Bigr)
\le \sum_{k=1}^{\infty} P\bigl(X_n < -1/k \text{ i.o.}\bigr) = 0.
$$

Therefore $P\bigl(\liminf_{n} X_n < 0\bigr) = 0$, which is **not** $>0$.

The constructed sequence satisfies all the hypotheses ($\{X_n\}$ independent, $E
[X_n]=0$, $E|X_n|=1$ for every $n$) yet has $P(\liminf X_n < 0) = 0$. Hence the
statement is **false**. $\blacksquare$
