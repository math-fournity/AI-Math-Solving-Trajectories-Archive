Looking at this problem, I need to find all integer-coefficient polynomials $p(x
)$ sandwiched between $f(x) = 2x^4 - 6x^2 + 1$ and $g(x) = 4 - 5x^2$ for all rea

## Setting Up the Structure

**Finding crossing points:** $f(x) = g(x)$ gives $2x^4 - x^2 - 3 = 0$, factoring
 as $(2x^2 - 3)(x^2 + 1) = 0$, so $x = \pm\sqrt{3/2}$.

- For $|x| \leq \sqrt{3/2}$: $f \leq g$ (at $x=0$: $f=1, g=4$), so $f \leq p \le
q g$.
- For $|x| \geq \sqrt{3/2}$: $f \geq g$ (at $x=2$: $f=9, g=-16$), so $g \leq p \
leq f$.

At the crossing points, $p$ is forced: $p(\pm\sqrt{3/2}) = g(\pm\sqrt{3/2}) = 4
- 5 \cdot \frac{3}{2} = -\frac{7}{2}$.

## Key Reduction

Define $q(x) = p(x) - g(x) = p(x) - 4 + 5x^2$ (integer coefficients). The condit
ion becomes: $q(x)$ lies between $0$ and $h(x) = f(x) - g(x) = (2x^2 - 3)(x^2 +
1)$ for all $x$.

Since $q(\pm\sqrt{3/2}) = 0$ and $2x^2 - 3$ is the minimal polynomial of $\sqrt{
3/2}$ over $\mathbb{Q}$ (irreducible, primitive), by Gauss's lemma: $(2x^2 - 3)
\mid q(x)$ in $\mathbb{Z}[x]$.

Write $q(x) = (2x^2 - 3)\,r(x)$ with $r(x) \in \mathbb{Z}[x]$.

**Simplifying the inequality:** Since $2x^2 - 3$ and $h(x) = (2x^2-3)(x^2+1)$ sh
are the same sign, dividing through (carefully handling sign reversals) yields i
n **both** regions:

$$0 \leq r(x) \leq x^2 + 1 \quad \text{for all } x \in \mathbb{R}.$$

## Solving the Reduced Problem

**Degree bound:** Since $r(x) \leq x^2 + 1 \to \infty$ and $r(x) \geq 0$, we nee
d $\deg r \leq 2$ (higher degree grows too fast in one direction).

**Case $\deg r = 2$:** $r(x) = ax^2 + bx + c$, $a \in \mathbb{Z}$, $a > 0$ (from
 $r \geq 0$). From $r \leq x^2+1$: $(1-a)x^2 - bx + (1-c) \geq 0$ for all $x$, r
equiring $1 - a \geq 0$, so $a = 1$. Then $bx + (1-c) \geq 0$ for all $x$ forces
 $b = 0$ and $c \leq 1$. From $r \geq 0$: $c \geq b^2/4 = 0$. So $c \in \{0, 1\}
$, giving $r = x^2$ or $r = x^2 + 1$.

**Case $\deg r \leq 1$:** $r(x) = bx + c$. From $r \geq 0$ for all $x$: $b = 0$,
 $c \geq 0$. From $r \leq x^2 + 1$: $c \leq \min(x^2+1) = 1$. So $c \in \{0, 1\}
$, giving $r = 0$ or $r = 1$.

## The Four Polynomials

Computing $p = (2x^2-3)r + 4 - 5x^2$:

| $r(x)$ | $p(x)$ |
|---------|---------|
| $0$ | $4 - 5x^2 = g(x)$ |
| $1$ | $-3x^2 + 1$ |
| $x^2$ | $2x^4 - 8x^2 + 4$ |
| $x^2+1$ | $2x^4 - 6x^2 + 1 = f(x)$ |

**Verification** at sample points (e.g., $x = 0, 1, 2, 1.2$) confirms each lies
between $f$ and $g$ everywhere. The boundary cases $r = 0$ and $r = x^2+1$ recov
er $g$ and $f$ themselves; the intermediate cases interpolate correctly.

## Answer

The number of such polynomials is $\boxed{4}$.
