**Answer: Yes.** Every infinite set can be well-ordered in a way that has no lar
gest element (in ZFC, i.e. assuming the Well-Ordering Theorem).

---

### Key lemma

**Lemma.** Every infinite initial ordinal is a limit ordinal.

*Proof.* Let $\kappa$ be an infinite initial ordinal (i.e. a cardinal). Suppose,
 for contradiction, that $\kappa$ is a successor ordinal, say $\kappa = \beta +
1$. Since $\kappa$ is infinite, $\beta$ is infinite, and for infinite ordinals $
|\beta| = |\beta+1|$. Hence $|\beta| = |\kappa|$. But $\beta < \kappa$ while $|\
beta| = |\kappa|$, contradicting the definition of $\kappa$ as the *least* ordin
al of cardinality $|\kappa|$. Therefore $\kappa$ is a limit ordinal. $\square$

### Main theorem

**Theorem.** Let $S$ be an infinite set. Then $S$ admits a well-ordering with no
 largest element.

*Proof.* By the Well-Ordering Theorem (equivalent to the Axiom of Choice), $S$ c
an be well-ordered; let $\kappa = |S|$ denote its cardinal, regarded as the init
ial ordinal of that cardinality. Since $S$ is infinite, $\kappa$ is an infinite
initial ordinal, and by the Lemma $\kappa$ is a **limit ordinal**.

Because $|\kappa| = |S| = \kappa$, there exists a bijection $f : \kappa \to S$.
Use $f$ to transport the natural well-order of $\kappa$ onto $S$:

$$x <_f y \quad\Longleftrightarrow\quad f^{-1}(x) < f^{-1}(y) \qquad (x, y \in S
).$$

This $<_f$ is a well-ordering of $S$, and its order type is exactly $\kappa$.

It remains to show this well-ordering has no largest element. Recall that a well
-ordered set has a largest element **iff** its order type is a successor ordinal
 (or $0$, for the empty set). Indeed:

- If the order type is $\alpha+1$, the element corresponding to $\alpha$ is larg
est.
- Conversely, if $m$ is a largest element, removing it leaves a well-ordered set
 of some order type $\alpha$, and the original has order type $\alpha+1$.

Since the order type of $(S, <_f)$ is $\kappa$, a limit ordinal, it is **not** a
 successor ordinal. Hence $(S, <_f)$ has no largest element. $\square$

### Concrete check (no-largest-element argument directly)

Suppose $m \in S$ were largest under $<_f$. Let $\eta = f^{-1}(m) < \kappa$. For
 every $x \in S$ we have $x \leqslant_f m$, so $f^{-1}(x) \leqslant \eta$, meani
ng every ordinal below $\kappa$ is $\leqslant \eta$. Thus $\kappa \subseteq \eta
 + 1$, i.e. $\kappa \leqslant \eta + 1$. But $\eta < \kappa$ and $\kappa$ is a l
imit ordinal, so $\eta + 1 < \kappa$ — contradiction. So no such $m$ exists.

### Remark on the role of Choice

The statement is a theorem of **ZFC**. It uses the Well-Ordering Theorem to guar
antee that $S$ is well-orderable at all. In ZF without Choice, an infinite set n
eed not be well-orderable, so the question "find a well-ordering" may have no we
ll-ordering to find. Conditional on $S$ being well-orderable, the argument above
 is constructive: take the order type to be the initial ordinal $\kappa = |S|$,
which is automatically a limit ordinal, and the induced well-ordering has no lar
gest element.
