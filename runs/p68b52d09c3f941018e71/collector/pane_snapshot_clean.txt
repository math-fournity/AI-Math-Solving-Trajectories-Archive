## Proof

Let $k$ be a field. Consider the ring

$$R = k[x_1, x_2, x_3, \dots] / (x_i x_j : i, j \ge 1),$$

i.e., the quotient of the polynomial ring in countably many variables by the ide
al generated by all pairwise products of variables. Set $X = \operatorname{Spec}
(R)$.

**Claim 1:** The underlying topological space of $X$ consists of a single point
(hence is noetherian).

In $R$, every product $x_i x_j = 0$, so each $x_i$ is nilpotent ($x_i^2 = 0$). A
s a $k$-vector space, $R$ has basis $\{1, x_1, x_2, \dots\}$. Every element is o
f the form $a + f$ with $a \in k$ and $f \in \mathfrak{m} := (x_1, x_2, \dots)$.
 Since $\mathfrak{m}^2 = 0$, an element $a + f$ with $a \neq 0$ is a unit (with
inverse $a^{-1} - a^{-2}f$). Thus $\mathfrak{m}$ is the unique maximal ideal, an
d $R$ is a local ring.

The nilradical of $R$ is $\mathfrak{m}$ (the nilpotent elements are exactly thos
e with zero constant term). Every prime ideal contains the nilradical, so every
prime ideal contains $\mathfrak{m}$. Since $\mathfrak{m}$ is maximal, it is the
**only** prime ideal. Therefore

$$\operatorname{Spec}(R) = \{\mathfrak{m}\},$$

a single point. A one-point topological space is trivially noetherian (descendin
g chains of closed subsets stabilize).

**Claim 2:** $R$ is not a noetherian ring.

The maximal ideal $\mathfrak{m} = (x_1, x_2, x_3, \dots)$ is not finitely genera
ted. Indeed, the $x_i$ are $k$-linearly independent in $R$ (they form part of a
$k$-basis), so no finite subset $\{x_{i_1}, \dots, x_{i_n}\}$ can generate all o
f $\mathfrak{m}$: any $x_j$ with $j \notin \{i_1, \dots, i_n\}$ cannot be writte
n as an $R$-linear combination of $x_{i_1}, \dots, x_{i_n}$ (such a combination
$\sum r_l x_{i_l}$ has no $x_j$-component). Hence $\mathfrak{m}$ is not finitely
 generated, so $R$ is not noetherian.

**Claim 3:** $X = \operatorname{Spec}(R)$ is not a noetherian scheme.

A scheme is noetherian if it admits a finite cover by affine open subschemes $\o
peratorname{Spec}(A_i)$ with each $A_i$ noetherian. Since $X = \operatorname{Spe
c}(R)$ is itself affine, $X$ is noetherian if and only if $R$ is noetherian. By
Claim 2, $R$ is not noetherian, so $X$ is not a noetherian scheme.

**Conclusion:** $X = \operatorname{Spec}(R)$ is a non-noetherian scheme whose un
derlying topological space is a single point (in particular, noetherian). $\squa
re$
