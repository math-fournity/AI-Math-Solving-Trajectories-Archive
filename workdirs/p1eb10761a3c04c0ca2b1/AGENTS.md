# Problem

A high-tech digital storage facility contains a sequence of 2013 individual server nodes, indexed from 0 to 2012. The facility manager is designing a specific redundant data-sharing protocol.

For any chosen node $k$ in the set $\{0, 1, 2, \dots, 2012\}$, the system generates a "Network Complexity Value" calculated by the number of possible ways to choose a subset of $k$ nodes from the total population of 2012 unique hardware slots (the value of the binomial coefficient $\binom{2012}{k}$).

The central cooling system will only activate for a specific configuration if the resulting Network Complexity Value is perfectly divisible by the total number of hardware slots, 2012.

Based on this protocol, for how many possible values of $k$ will the cooling system activate?
