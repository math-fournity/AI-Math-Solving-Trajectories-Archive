# Problem

In a massive logistics warehouse, a storage grid is organized into 9 horizontal levels and 2008 vertical stacks. The facility is tasked with storing a total of 18,072 inventory crates. These crates are labeled with identification numbers ranging from 1 to 2008, such that there are exactly 9 crates for every ID number.

The warehouse manager distributes the crates across the grid, placing exactly one crate in every slot. To ensure structural stability, the manager enforces a strict "Proximity Rule": within any single vertical stack, the difference between the ID numbers of any two crates cannot exceed 3.

The "Stack Weight" is defined as the sum of the identification numbers of the nine crates within a vertical stack. The manager aims to organize the crates to make the lightest stack in the warehouse as heavy as possible. 

What is the maximum possible value for the minimum sum found among the 2008 vertical stacks?
