## Key Observation: Edge-Minimality Characterization

**Claim:** In an edge-minimal 3-good graph, every edge has at least one endpoint
 of degree exactly 3.

*Proof:* If edge $e = (a,b)$ has both endpoints with degree $\geq 4$, removing $
e$ drops both to degree $\geq 3$, preserving 3-goodness — contradicting minimali
ty. $\square$

## Setting Up the Optimization

Partition vertices into **low** (degree exactly 3) and **high** (degree $\geq 4$
). Let $p = |A_{\text{low}}|$, $q = |B_{\text{low}}|$. No edge connects two high
 vertices.

Define edge counts:
- $e_{00}$: low-A ↔ low-B
- $e_{01}$: low-A ↔ high-B
- $e_{10}$: high-A ↔ low-B

**Degree accounting:** Each low-A vertex has degree 3, so $e_{00} + e_{01} = 3p$
. Each low-B vertex has degree 3, so $e_{00} + e_{10} = 3q$.

Total edges: $E = e_{00} + e_{01} + e_{10} = 3p + 3q - e_{00}$.

## Deriving the Upper Bound

**Feasibility constraints** (high vertices need degree $\geq 4$, connecting only
 to low vertices on the opposite side):

1. $e_{10} = 3q - e_{00} \geq 4(n-p)$ and $e_{10} \leq (n-p)q$
2. $e_{01} = 3p - e_{00} \geq 4(n-q)$ and $e_{01} \leq (n-q)p$
3. $e_{00} \geq 0$

From $e_{10} \leq (n-p)q$: $e_{00} \geq 3q - (n-p)q = q(p - n + 3)$.
From $e_{01} \leq (n-q)p$: $e_{00} \geq 3p - (n-q)p = p(q - n + 3)$.

**Case 1: $p \leq n-3$ and $q \leq n-3$.** Then $p - n + 3 \leq 0$ and $q - n +
3 \leq 0$, so $e_{00} \geq 0$ suffices. Setting $e_{00} = 0$:

$$E = 3p + 3q \leq 3(n-3) + 3(n-3) = 6n - 18$$

with feasibility requiring $3q + 4p \geq 4n$ and $3p + 4q \geq 4n$ (satisfied at
 $p = q = n-3$ when $n \geq 7$, since $7(n-3) \geq 4n \iff n \geq 7$).

**Case 2: $p \geq n-2$ (i.e., $p > n-3$).** Then $e_{00} \geq q(p-n+3) \geq q$,
so:

$$E = 3p + 3q - e_{00} \leq 3p + 2q$$

With $p = n-2$, $q \leq n-3$: $E \leq 3(n-2) + 2(n-3) = 5n - 12 < 6n - 18$ for $
n > 6$.

With $p = n-1$: $E \leq 3(n-1) + q \leq 4n - 6 < 6n - 18$ for $n > 6$.

With $p = n$: $E \leq 3n < 6n - 18$ for $n > 6$.

By symmetry, the same holds for $q > n-3$. **All cases yield $E < 6n - 18$ for $
n \geq 7$.**

## Achieving the Bound

For $n \geq 7$, set $p = q = n - 3$. Partition:
- $A_{\text{low}} = \{a_1, \ldots, a_{n-3}\}$, $A_{\text{high}} = \{a_{n-2}, a_{
n-1}, a_n\}$
- $B_{\text{low}} = \{b_1, \ldots, b_{n-3}\}$, $B_{\text{high}} = \{b_{n-2}, b_{
n-1}, b_n\}$

**Edges:** Every $a_i \in A_{\text{low}}$ connects to all of $B_{\text{high}}$ (
forming $K_{n-3,\,3}$), and every $b_j \in B_{\text{low}}$ connects to all of $A
_{\text{high}}$ (forming $K_{3,\,n-3}$). No edges between $A_{\text{low}}$ and $
B_{\text{low}}$.

**Verification:**
- Each low vertex has degree exactly 3. ✓
- Each high vertex has degree $n - 3 \geq 7 \geq 4 \geq 3$. ✓ (3-good)
- Every edge has a low endpoint (degree 3), so removing any edge drops it to deg
ree 2. ✓ (edge-minimal)
- Total edges: $3(n-3) + 3(n-3) = 6n - 18$. ✓

The geometric condition (no three points collinear) imposes no constraint on whi
ch segments can be selected — segments may cross freely. The problem is purely c
ombinatorial.

## Computing the Sum

For $n \geq 10$ (so $n \geq 7$ is satisfied): $M(n, 3) = 6n - 18$.

$$\sum_{n=10}^{20} M(n, 3) = \sum_{n=10}^{20} (6n - 18) = 6 \cdot \frac{(10+20)\
cdot 11}{2} - 18 \cdot 11 = 6 \cdot 165 - 198 = 990 - 198 = \boxed{792}$$
