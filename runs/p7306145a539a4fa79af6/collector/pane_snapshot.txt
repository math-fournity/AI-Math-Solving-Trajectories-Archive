**Answer: Yes, such a function exists.**

## Proof

We construct a function $f:\mathbb{R}\to\mathbb{R}$ whose set of continuity poin
ts $C(f)$ is a dense $G_\delta$ set of Lebesgue measure zero. This simultaneousl
y gives: (i) $f$ is continuous on a dense $G_\delta$ set, and (ii) $f$ is discon
tinuous on $\mathbb{R}\setminus C(f)$, which has full measure, so $f$ is discont
inuous almost everywhere.

### Step 1. Construct a dense $G_\delta$ null set $G$.

Enumerate $\mathbb{Q}=\{q_1,q_2,\dots\}$. For each $n\geq 1$, cover $\mathbb{Q}$
 by open intervals of total length $<1/n$:
$$U_n = \bigcup_{k=1}^{\infty}\bigl(q_k - r_{n,k},\; q_k + r_{n,k}\bigr), \qquad
 \text{with } \sum_{k} 2\,r_{n,k} < \tfrac{1}{n},\; r_{n,k}>0.$$
Each $U_n$ is open and dense (it contains $\mathbb{Q}$). Set $V_n = \bigcap_{k=1
}^{n} U_k$; then each $V_n$ is open and dense, $V_{n+1}\subseteq V_n$, and
$$G := \bigcap_{n=1}^{\infty} V_n = \bigcap_{n=1}^{\infty} U_n.$$
$G$ is a dense $G_\delta$ set (countable intersection of open dense sets in the
complete space $\mathbb{R}$). Moreover, $\lambda(G) \leq \lambda(V_n) \leq \lamb
da(U_n) < 1/n$ for every $n$, so $\lambda(G)=0$.

### Step 2. Construct $f$ with $C(f)=G$.

Let $F_n = \mathbb{R}\setminus V_n$. Then each $F_n$ is **closed and nowhere den
se** (since $V_n$ is open and dense), $F_n\subseteq F_{n+1}$, and $\bigcup_n F_n
 = \mathbb{R}\setminus G$. Define:
$$\boxed{f(x) = \sum_{n=1}^{\infty} 2^{-n}\,\chi_{F_n}(x).}$$
The series converges uniformly (bounded by $\sum 2^{-n}=1$), so $f$ is well-defi
ned and bounded.

**Claim:** $C(f)=G$.

**Continuity at $x\in G$:** Since $x\in V_n$ for all $n$ and each $V_n$ is open,
 for any $N\geq 1$ there is a neighborhood of $x$ contained in $V_1\cap\cdots\ca
p V_N$, on which $\chi_{F_n}=0$ for $n\leq N$. Thus for $y$ in this neighborhood
:
$$|f(y)-f(x)| = |f(y)| = \sum_{n>N}2^{-n}\chi_{F_n}(y) \leq 2^{-N}.$$
Since $N$ is arbitrary, $f$ is continuous at $x$.

**Discontinuity at $x\notin G$:** Let $n_0$ be the smallest index with $x\in F_{
n_0}$ (so $x\in V_n$ for $n<n_0$ and $x\in F_{n_0}$). Since $F_{n_0}$ is nowhere
 dense, $x\in\partial F_{n_0}$, so there exists a sequence $y_k\to x$ with $y_k\
in V_{n_0}$.

For $y_k\in V_{n_0}\subseteq V_n$ ($n<n_0$): $\chi_{F_n}(y_k)=0$ for $n\leq n_0$
, so
$$f(y_k)=\sum_{n>n_0}2^{-n}\chi_{F_n}(y_k)\leq 2^{-n_0}.$$

Meanwhile $f(x)=2^{-n_0}+\sum_{n>n_0}2^{-n}\chi_{F_n}(x)\geq 2^{-n_0}$.

- **If $f(x)>2^{-n_0}$:** then $|f(y_k)-f(x)|\geq f(x)-2^{-n_0}>0$ for all $k$,
so $f$ is discontinuous at $x$.

- **If $f(x)=2^{-n_0}$** (i.e., $x\in V_n$ for all $n>n_0$): For any fixed $N>n_
0$, since $x\in V_{n_0+1}\cap\cdots\cap V_N$ (open), there exists $\delta>0$ wit
h $(x-\delta,x+\delta)\subseteq V_{n_0+1}\cap\cdots\cap V_N$. For large $k$, $y_
k\in(x-\delta,x+\delta)\cap V_{n_0}$, giving $\chi_{F_n}(y_k)=0$ for $n_0<n\leq
N$, hence $f(y_k)\leq 2^{-N}$. Since $N$ is arbitrary, $f(y_k)\to 0$. But $f(x)=
2^{-n_0}>0$, so $f$ is discontinuous at $x$.

In both cases $f$ is discontinuous at $x\notin G$. Therefore $C(f)=G$. $\square$

### Step 3. Conclusion.

The function $f$ satisfies:
- $C(f)=G$ is a **dense $G_\delta$ set** — so $f$ is continuous on a dense $G_\d
elta$ set.
- $\lambda(G)=0$, so $\lambda(\mathbb{R}\setminus G)=\infty$ (full measure) — so
 $f$ is **discontinuous almost everywhere**.

Hence such a function exists. $\blacksquare$
