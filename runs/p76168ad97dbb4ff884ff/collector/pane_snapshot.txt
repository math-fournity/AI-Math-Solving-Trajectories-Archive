## 解答

我们声称 $g(x) = 6x^2 + 5x + 1$ 是所求的多项式。

### 关键恒等式

对于实系数多项式 $p(x) = \sum_{k=0}^{m} a_k x^k$，Parseval 恒等式给出：

$$\Gamma(p) = \sum_{k=0}^{m} a_k^2 = \frac{1}{2\pi}\int_0^{2\pi} \left|p(e^{i\th
eta})\right|^2\,d\theta.$$

对于实系数，$|p(e^{i\theta})|^2 = p(e^{i\theta})\,p(e^{-i\theta})$，因此对于任意
 $n \ge 1$：

$$\Gamma(p^n) = \frac{1}{2\pi}\int_0^{2\pi} \left|p(e^{i\theta})\right|^{2n}\,d\
theta.$$

因此，如果 $|g(e^{i\theta})|^2 = |F(e^{i\theta})|^2$ 在 $[0,2\pi]$ 上逐点成立，
那么对于所有 $n \ge 1$，都有 $\Gamma(g^n) = \Gamma(F^n)$。

### 因式分解与反射技巧

将 $F(x) = 3x^2+7x+2$ 写为

$$F(x) = (1+3x)(2+x).$$

那么

$$\left|F(e^{i\theta})\right|^2 = \left|1+3e^{i\theta}\right|^2\cdot\left|2+e^{i
\theta}\right|^2.$$

对于任意实数 $a$，有一个简单但关键的恒等式：

$$\left|1+ae^{i\theta}\right|^2 = 1+a^2+2a\cos\theta = a^2+1+2a\cos\theta = \lef
t|a+e^{i\theta}\right|^2.$$

将其应用于 $a=2$：$\left|1+2e^{i\theta}\right|^2 = \left|2+e^{i\theta}\right|^2$
。因此

$$\left|F(e^{i\theta})\right|^2 = \left|1+3e^{i\theta}\right|^2\cdot\left|1+2e^{
i\theta}\right|^2 = \left|(1+3x)(1+2x)\Big|_{x=e^{i\theta}}\right|^2.$$

### 定义 g 并验证两个条件

设

$$g(x) = (1+3x)(1+2x) = 6x^2+5x+1.$$

**(i) $g(0)=1$：** 直接可得 $g(0) = (1)(1) = 1$。 ✓

**(ii) $\Gamma(F^n) = \Gamma(g^n)$ 对于所有 $n \ge 1$：** 根据上述逐点等式 $\lef
t|g(e^{i\theta})\right|^2 = \left|F(e^{i\theta})\right|^2$，我们得到 $\left|g(e^
{i\theta})\right|^{2n} = \left|F(e^{i\theta})\right|^{2n}$。通过 Parseval 恒等式
进行积分：

$$\Gamma(g^n) = \frac{1}{2\pi}\int_0^{2\pi}\left|g(e^{i\theta})\right|^{2n}d\the
ta = \frac{1}{2\pi}\int_0^{2\pi}\left|F(e^{i\theta})\right|^{2n}d\theta = \Gamma
(F^n).$$

### 数值验证

- $n=1$: $\Gamma(F) = 2^2+7^2+3^2 = 62$; $\Gamma(g) = 1^2+5^2+6^2 = 62$. ✓
- $n=2$: $F^2 = 9x^4+42x^3+61x^2+28x+4$, $\Gamma(F^2)=81+1764+3721+784+16=6366$;
 $g^2 = 36x^4+60x^3+37x^2+10x+1$, $\Gamma(g^2)=1296+3600+1369+100+1=6366$. ✓

### 结论

多项式 $g(x) = 6x^2+5x+1$ 满足 $g(0)=1$，并且对于所有整数 $n \ge 1$，都有 $\Gamm
a(F(x)^n)=\Gamma(g(x)^n)$。
