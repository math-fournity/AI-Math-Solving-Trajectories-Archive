## Solution

We solve the eikonal equation $u_x^2 + u_y^2 = a^2$ with the boundary condition
$u(x, 2x) = 1$ using the **method of characteristics**.

### Setup

Let $p = u_x$, $q = u_y$, and $F(x,y,u,p,q) = p^2 + q^2 - a^2 = 0$. Since $F$ ha
s no explicit dependence on $x, y$, or $u$, the characteristic equations are:

$$\frac{dx}{ds} = F_p = 2p, \quad \frac{dy}{ds} = F_q = 2q, \quad \frac{du}{ds}
= pF_p + qF_q = 2(p^2+q^2) = 2a^2,$$
$$\frac{dp}{ds} = -F_x - pF_u = 0, \quad \frac{dq}{ds} = -F_y - qF_u = 0.$$

Since $p$ and $q$ are **constant** along each characteristic, the characteristic
s are straight lines in the $(x,y)$-plane.

### Initial data on the boundary curve

Parameterize the boundary line $y = 2x$ by $t$: $(x_0, y_0, u_0) = (t,\, 2t,\, 1
)$.

Differentiating $u(t, 2t) = 1$ with respect to $t$ gives the **strip condition**
:
$$u_x \cdot 1 + u_y \cdot 2 = 0 \quad\Longrightarrow\quad p_0 + 2q_0 = 0 \quad\L
ongrightarrow\quad p_0 = -2q_0.$$

Combining with the PDE $p_0^2 + q_0^2 = a^2$:
$$4q_0^2 + q_0^2 = a^2 \quad\Longrightarrow\quad q_0^2 = \frac{a^2}{5} \quad\Lon
grightarrow\quad q_0 = \pm\frac{a}{\sqrt{5}},\quad p_0 = \mp\frac{2a}{\sqrt{5}}.
$$

This yields **two families** of characteristics (two solutions).

### Family 1: $q_0 = \dfrac{a}{\sqrt{5}},\; p_0 = -\dfrac{2a}{\sqrt{5}}$

Along a characteristic emanating from $(t, 2t)$:
$$x = t + 2p_0\, s = t - \tfrac{4a}{\sqrt{5}}\,s, \qquad y = 2t + 2q_0\, s = 2t
+ \tfrac{2a}{\sqrt{5}}\,s, \qquad u = 1 + 2a^2 s.$$

Eliminating $t$: from the first equation $t = x + \tfrac{4a}{\sqrt{5}}\,s$; subs
tituting into the second:
$$y = 2\!\left(x + \tfrac{4a}{\sqrt{5}}\,s\right) + \tfrac{2a}{\sqrt{5}}\,s = 2x
 + \tfrac{10a}{\sqrt{5}}\,s = 2x + 2a\sqrt{5}\,s,$$
so $s = \dfrac{y - 2x}{2a\sqrt{5}}$. Therefore:
$$\boxed{u_1(x,y) = 1 + \frac{a\,(y - 2x)}{\sqrt{5}}.}$$

### Family 2: $q_0 = -\dfrac{a}{\sqrt{5}},\; p_0 = \dfrac{2a}{\sqrt{5}}$

Similarly:
$$x = t + \tfrac{4a}{\sqrt{5}}\,s, \qquad y = 2t - \tfrac{2a}{\sqrt{5}}\,s, \qqu
ad u = 1 + 2a^2 s.$$

Eliminating $t$: $t = x - \tfrac{4a}{\sqrt{5}}\,s$, and
$$y = 2\!\left(x - \tfrac{4a}{\sqrt{5}}\,s\right) - \tfrac{2a}{\sqrt{5}}\,s = 2x
 - 2a\sqrt{5}\,s,$$
so $s = \dfrac{2x - y}{2a\sqrt{5}}$. Therefore:
$$\boxed{u_2(x,y) = 1 - \frac{a\,(y - 2x)}{\sqrt{5}}.}$$

### Verification

**For $u_1$:** $u_x = -\dfrac{2a}{\sqrt{5}}$, $u_y = \dfrac{a}{\sqrt{5}}$, so $u
_x^2 + u_y^2 = \dfrac{4a^2}{5} + \dfrac{a^2}{5} = a^2$. ✓ And $u_1(x,2x) = 1 + \
dfrac{a \cdot 0}{\sqrt{5}} = 1$. ✓

**For $u_2$:** $u_x = \dfrac{2a}{\sqrt{5}}$, $u_y = -\dfrac{a}{\sqrt{5}}$, so $u
_x^2 + u_y^2 = \dfrac{4a^2}{5} + \dfrac{a^2}{5} = a^2$. ✓ And $u_2(x,2x) = 1 - \
dfrac{a \cdot 0}{\sqrt{5}} = 1$. ✓

### Conclusion

The PDE $u_x^2 + u_y^2 = a^2$ with boundary condition $u(x,2x)=1$ admits **two c
lassical solutions**:

$$u(x,y) = 1 \pm \frac{a\,(y - 2x)}{\sqrt{5}}.$$

Both are linear functions whose gradient $(u_x, u_y) = \left(\mp \frac{2a}{\sqrt
{5}},\, \pm \frac{a}{\sqrt{5}}\right)$ has constant magnitude $a$ and is orthogo
nal in the appropriate sense to the boundary line $y = 2x$, consistent with the
strip condition $p + 2q = 0$.
