## Proof

**Existence of a weak solution.** The coefficient $\sigma$ is bounded and Borel
measurable (taking values $\pm 1$). By standard weak existence results (e.g., St
roock–Varadhan), the SDE
$$dX_t = \sigma(X_t)\,dW_t, \quad X_0 = x_0$$
admits a weak solution for any deterministic initial condition $x_0$.

**Key observation via Lévy's characterization.** Let $(X, W)$ be any weak soluti
on on some filtered probability space. Set
$$M_t := X_t - x_0 = \int_0^t \sigma(X_s)\,dW_s.$$
Then:
1. **$M$ is a continuous local martingale** (it is an Itô integral with bounded
integrand).
2. **The quadratic variation is deterministic:**
$$\langle M \rangle_t = \int_0^t \sigma^2(X_s)\,ds = \int_0^t 1\,ds = t.$$

Since $M_0 = 0$, $M$ is a continuous local martingale with $\langle M \rangle_t
= t$, by **Lévy's characterization of Brownian motion**, $M = (M_t)_{t \geq 0}$
is a standard Brownian motion.

**Consequence.** Therefore
$$X_t = x_0 + M_t$$
where $M$ is a standard Brownian motion. It follows immediately that
$$X_t \sim N(x_0,\, t) \quad \text{for every } t > 0,$$
regardless of the choice of $A$.

**The normality condition is vacuous.** The conclusion $X_t \sim N(x_0, t)$ hold
s for **every** Borel set $A \subseteq \mathbb{R}$, whether or not $0 \in A$. Fo

- If $A = (0,\infty)$ (so $0 \in A$), then $X_t \sim N(x_0, t)$. ✓
- If $A = (1,\infty)$ (so $0 \notin A$), then $X_t \sim N(x_0, t)$. ✓

In both cases—and indeed for any Borel set $A$—the distribution of $X_t$ is Gaus
sian, because the diffusion coefficient always has absolute value $1$, making th

**Conclusion.** The hypothesis that $X_t$ is normally distributed for all $t > 0
