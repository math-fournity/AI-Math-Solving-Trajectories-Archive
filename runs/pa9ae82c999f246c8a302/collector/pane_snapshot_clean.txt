## Proof

We work in the quaternion algebra $\mathbb{H}$. We seek all $x \in \mathbb{H}$ s
atisfying $x^3 + 1 = 0$.

**Factorization.** Since the coefficients of $x^3 + 1$ are real (hence central i
n $\mathbb{H}$), and $x$ commutes with every real number, the polynomial identit
y
$$x^3 + 1 = (x+1)(x^2 - x + 1)$$
holds for every quaternion $x$ (the expansion uses only associativity and commut
ativity of $x$ with the real scalars $1, -1$). Hence $x^3 + 1 = 0$ iff $x + 1 =
0$ or $x^2 - x + 1 = 0$.

**First factor.** $x + 1 = 0$ gives the single root $x = -1$.

**Second factor.** Write $x = a + \vec{u}$ with $a \in \mathbb{R}$ and $\vec{u}
\in \mathbb{R}^3$ a pure imaginary quaternion. Using $\vec{u}^2 = -|\vec{u}|^2$,
$$x^2 = a^2 - |\vec{u}|^2 + 2a\vec{u}.$$
Thus
$$x^2 - x + 1 = \bigl(a^2 - |\vec{u}|^2 - a + 1\bigr) + (2a - 1)\vec{u} = 0.$$
Separating scalar and vector parts:
1. $(2a - 1)\vec{u} = \vec{0}$,
2. $a^2 - |\vec{u}|^2 - a + 1 = 0$.

*Case A:* $\vec{u} = \vec{0}$. Then $x = a \in \mathbb{R}$ and (2) becomes $a^2
- a + 1 = 0$, whose discriminant is $-3 < 0$; no real solution.

*Case B:* $2a - 1 = 0$, i.e. $a = \tfrac{1}{2}$. Then (2) gives
$$\tfrac{1}{4} - |\vec{u}|^2 - \tfrac{1}{2} + 1 = 0 \implies |\vec{u}|^2 = \tfra
c{3}{4} \implies |\vec{u}| = \tfrac{\sqrt{3}}{2}.$$
So $\vec{u}$ may be **any** vector in $\mathbb{R}^3$ of length $\sqrt{3}/2$.

**Conclusion.** The solution set is
$$\{-1\}\;\cup\;\left\{\,\tfrac{1}{2} + \vec{u} : \vec{u} \in \mathbb{R}^3,\ |\v
ec{u}| = \tfrac{\sqrt{3}}{2}\,\right\}.$$
The second set is a 2-sphere of radius $\sqrt{3}/2$ centered at $\tfrac{1}{2}$ i
n the affine subspace $\operatorname{Re}(x) = \tfrac{1}{2}$, hence is uncountabl
y infinite. Together with the isolated root $-1$, the equation has **infinitely
many** quaternion roots (indeed, uncountably many, parametrized by a 2-sphere).

The number of quaternion roots of $x^3 + 1 = 0$ is **infinite** (a 2-sphere of s
olutions together with the single real root $-1$).
