## Solution

**Setting up the constraints.** We have $z^n = 1$ and $(z+1)^n = 1$, so both $z$
 and $z+1$ lie on the unit circle:
$$|z| = 1, \qquad |z+1| = 1.$$

**Determining $z$.** From $|z|^2 = 1$: $z\bar{z} = 1$. From $|z+1|^2 = 1$:
$$(z+1)(\bar{z}+1) = 1 \implies z\bar{z} + z + \bar{z} + 1 = 1 \implies 1 + z +
\bar{z} + 1 = 1,$$
so $z + \bar{z} = -1$, giving $\operatorname{Re}(z) = -\tfrac{1}{2}$.

Combined with $|z|=1$, we get $z = -\tfrac{1}{2} \pm \tfrac{\sqrt{3}}{2}i$, i.e.
,
$$z = e^{2\pi i/3} \quad \text{or} \quad z = e^{-2\pi i/3}.$$

**Checking $z+1$.**
- If $z = e^{2\pi i/3}$, then $z+1 = \tfrac{1}{2}+\tfrac{\sqrt{3}}{2}i = e^{2\pi
 i/6}$.
- If $z = e^{-2\pi i/3}$, then $z+1 = \tfrac{1}{2}-\tfrac{\sqrt{3}}{2}i = e^{-2\
pi i/6} = e^{2\pi i\cdot 5/6}$.

**Divisibility conditions.** For $z = e^{\pm 2\pi i/3}$ to be an $n$-th root of
unity, we need $3 \mid n$. For $z+1 = e^{2\pi i \cdot k/6}$ (with $k \in \{1,5\}
$) to be an $n$-th root of unity, we need $6 \mid n$. Since $6 \mid n \Rightarro
w 3 \mid n$, the binding condition is $6 \mid n$.

We also require $5 \mid n$. Therefore $n$ must be a multiple of $\operatorname{l
cm}(6,5) = 30$.

**Computing $z^3$.** In both cases $z$ is a cube root of unity:
$$z^3 = \left(e^{\pm 2\pi i/3}\right)^3 = e^{\pm 2\pi i} = 1.$$

**Minimizing.** We have $n + z^3 = n + 1$. The smallest valid $n$ is $n = 30$, g
iving:
$$n + z^3 = 30 + 1 = \boxed{31}.$$
