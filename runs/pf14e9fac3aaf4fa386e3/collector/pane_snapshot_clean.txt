## Proof: $|x|^{-r}$ is a tempered distribution if and only if $0 < r < 1$

### Setup and Seminorm Convention

We use the Schwartz seminorm
$$\|\phi\|_{(\alpha,\beta)} = \sup_{x \in \mathbb{R}} (1+|x|)^\alpha \, |\phi^{(
\beta)}(x)|,$$
so that $|\phi^{(\beta)}(x)| \le (1+|x|)^{-\alpha}\,\|\phi\|_{(\alpha,\beta)}$ f
or all $x$.

A locally integrable function $f$ defines a tempered distribution if there exist
 $C, \alpha, \beta$ with $|T_f(\phi)| \le C\,\|\phi\|_{(\alpha,\beta)}$ for all
$\phi \in \mathcal{S}(\mathbb{R})$, where $T_f(\phi) = \int f\,\phi$.

---

### Part 1: $0 < r < 1$ implies $|x|^{-r}$ is tempered

Choose $\alpha = 1$ (any $\alpha > 1-r$ works) and $\beta = 0$. For $\phi \in \m
athcal{S}(\mathbb{R})$:

$$|T(\phi)| = \left|\int_{\mathbb{R}} |x|^{-r}\,\phi(x)\,dx\right| \le \int_{\ma
thbb{R}} |x|^{-r}\,|\phi(x)|\,dx \le \|\phi\|_{(1,0)} \underbrace{\int_{\mathbb{
R}} \frac{|x|^{-r}}{1+|x|}\,dx}_{=:C_r}.$$

**Convergence of $C_r$:** Split the integral at $|x|=1$.

- **Near the origin** ($|x| \le 1$): $\frac{|x|^{-r}}{1+|x|} \le |x|^{-r}$, and
$$\int_{|x|\le 1} |x|^{-r}\,dx = 2\int_0^1 x^{-r}\,dx = \frac{2}{1-r} < \infty \
quad \text{since } r < 1.$$

- **Near infinity** ($|x| > 1$): $\frac{|x|^{-r}}{1+|x|} \le |x|^{-(r+1)}$, and
$$\int_{|x|>1} |x|^{-(r+1)}\,dx = 2\int_1^\infty x^{-(r+1)}\,dx = \frac{2}{r} <
\infty \quad \text{since } r > 0.$$

Therefore $C_r = \int_{\mathbb{R}} \frac{|x|^{-r}}{1+|x|}\,dx < \infty$, and

$$\boxed{|T(\phi)| \le C_r\,\|\phi\|_{(1,0)} \quad \text{for all } \phi \in \mat
hcal{S}(\mathbb{R}), \quad 0 < r < 1.}$$

This shows $|x|^{-r}$ is a tempered distribution for every $r \in (0,1)$.

### Part 2: $r \ge 1$ implies $|x|^{-r}$ is NOT a tempered distribution

**Local integrability fails.** For $r \ge 1$, the function $|x|^{-r}$ is not loc
ally integrable near $x = 0$:

$$\int_{-\epsilon}^{\epsilon} |x|^{-r}\,dx = 2\int_0^\epsilon x^{-r}\,dx = \begi
n{cases} \frac{2\epsilon^{1-r}}{1-r} \to \infty & \text{if } r > 1, \\ +\infty &
 \text{if } r = 1. \end{cases}$$

**The functional is not even well-defined.** Take any non-negative $\phi \in \ma
thcal{S}(\mathbb{R})$ with $\phi(0) > 0$ (e.g., $\phi(x) = e^{-x^2}$). By contin
uity, $\phi(x) \ge \phi(0)/2 > 0$ for $|x| \le \delta$ for some $\delta > 0$. Th
en

$$\int_{\mathbb{R}} |x|^{-r}\,\phi(x)\,dx \ge \frac{\phi(0)}{2}\int_{|x|\le\delt
a} |x|^{-r}\,dx = +\infty \quad \text{for } r \ge 1.$$

So the integral diverges and $T(\phi)$ is not defined. Hence $|x|^{-r}$ does not
 define a distribution (tempered or otherwise) via integration for $r \ge 1$.

**No seminorm bound can hold.** Even if one attempted to restrict to $\phi$ with
 $\phi(0)=0$, the bound cannot hold. Consider $\phi_n(x) = e^{-n^2 x^2}\cdot n^{
-(1-r)}$ for $r > 1$ (or a suitable normalization for $r=1$). One can arrange $\
|\phi_n\|_{(\alpha,\beta)} \to 0$ for every fixed $(\alpha,\beta)$ while $\int |
x|^{-r}\phi_n\,dx$ remains bounded away from zero or diverges, contradicting any
 bound $|T(\phi)| \le C\|\phi\|_{(\alpha,\beta)}$. The essential obstruction is
the non-integrable singularity at the origin.

### Conclusion

The function $|x|^{-r}$ is a tempered distribution on $\mathbb{R}$ **if and only
 if** $0 < r < 1$.

For every $r \in (0,1)$, the bound
$$\left|\int_{\mathbb{R}} \frac{\phi(x)}{|x|^r}\,dx\right| \le C_r\,\|\phi\|_{(1
,0)}, \qquad C_r = \int_{\mathbb{R}} \frac{|x|^{-r}}{1+|x|}\,dx = \frac{2}{1-r}
+ \frac{2}{r} + \text{(finite correction)},$$
holds for all $\phi \in \mathcal{S}(\mathbb{R})$, with constants $C = C_r$ and $
\alpha = 1,\ \beta = 0$.

For $r \ge 1$, $|x|^{-r}$ fails to be locally integrable at the origin, so it do
es not define a distribution via integration, and no such constants can exist.
