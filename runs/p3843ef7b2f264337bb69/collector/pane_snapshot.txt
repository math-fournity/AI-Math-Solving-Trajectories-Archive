Looking at this problem, I need to determine whether the intersection of all tan
gent cones of a closed convex set $C \subseteq \mathbb{R}^n$ contains a non-zero
 element if and only if $C$ is unbounded.

**Answer: The statement is TRUE.**

## Proof

**Definitions.** For a closed convex set $C$ and $x \in C$:
- **Tangent cone:** $T_C(x) = \overline{\operatorname{cone}(C - x)}$
- **Normal cone:** $N_C(x) = \{n \in \mathbb{R}^n : \langle n, y - x \rangle \le
q 0,\ \forall y \in C\}$
- **Recession cone:** $\operatorname{rec}(C) = \{d \in \mathbb{R}^n : x + td \in
 C,\ \forall x \in C,\ \forall t \geq 0\}$

**Key identity (standard for convex sets):** $T_C(x) = N_C(x)^\circ$, where $S^\
circ = \{d : \langle d, s\rangle \leq 0,\ \forall s \in S\}$. This follows from
the bipolar theorem: $N_C(x) = (C-x)^\circ$, so $N_C(x)^\circ = \overline{\opera
torname{cone}(C-x)} = T_C(x)$.

---

### Step 1: $\bigcap_{x \in C} T_C(x) = \operatorname{rec}(C)$

**($\supseteq$)** If $d \in \operatorname{rec}(C)$, then for any $x \in C$ and $
t > 0$, $x + td \in C$, so $td \in C - x$, hence $d = \frac{1}{t}(td) \in \opera
torname{cone}(C-x) \subseteq T_C(x)$.

**($\subseteq$)** Let $d \in \bigcap_{x \in C} T_C(x)$. Fix $x \in C$ and $t > 0
$; we show $x + td \in C$.

Let $p = P_C(x + td)$ be the projection of $x + td$ onto $C$ (well-defined since
 $C$ is closed and convex). Set $r = x + td - p$. By the projection theorem:

(i) $r \in N_C(p)$, i.e., $\langle r, y - p \rangle \leq 0$ for all $y \in C$.

Since $d \in T_C(p) = N_C(p)^\circ$ and $r \in N_C(p)$:

(ii) $\langle d, r \rangle \leq 0$.

Since $x \in C$, applying (i) with $y = x$:

(iii) $\langle r, x - p \rangle \leq 0$.

Now decompose $r = (x - p) + td$ and compute:
$$\|r\|^2 = \langle r,\, r\rangle = \langle r,\, x - p\rangle + t\langle r,\, d\
rangle \leq 0 + t\cdot 0 = 0$$

by (iii) and (ii). Hence $r = 0$, so $x + td = p \in C$. $\quad\checkmark$

---

### Step 2: $C$ is unbounded $\iff$ $\operatorname{rec}(C) \neq \{0\}$

**($\Leftarrow$)** If $d \neq 0$ and $d \in \operatorname{rec}(C)$, then $\{x_0
+ td : t \geq 0\} \subseteq C$ for any $x_0 \in C$, so $C$ is unbounded.

**($\Rightarrow$)** Suppose $C$ is unbounded. Take $x_n \in C$ with $\|x_n\| \to
 \infty$, fix $x_0 \in C$, and set $d_n = \frac{x_n - x_0}{\|x_n - x_0\|}$. By c
ompactness of the unit sphere, pass to a subsequence with $d_n \to d$, $\|d\| =
1$.

For any fixed $t \geq 0$ and $n$ large enough ($t \leq \|x_n - x_0\|$):
$$x_0 + t\,d_n = \left(1 - \tfrac{t}{\|x_n - x_0\|}\right) x_0 + \tfrac{t}{\|x_n
 - x_0\|}\, x_n \in C$$
as a convex combination. Taking $n \to \infty$: $x_0 + td \in C$ (since $C$ is c
losed).

Now for **any** $y \in C$ and $t \geq 0$: by convexity, for $\lambda \in [0,1]$
and $s \geq 0$:
$$(1-\lambda)\,y + \lambda(x_0 + sd) \in C.$$
Set $\lambda = 1/n$, $s = nt$:
$$(1 - \tfrac{1}{n})\,y + \tfrac{1}{n}\,x_0 + td \in C.$$
Taking $n \to \infty$: $y + td \in C$ (since $C$ is closed). Thus $d \in \operat
orname{rec}(C)$ with $d \neq 0$. $\quad\checkmark$

---

### Conclusion

Combining Steps 1 and 2:
$$\bigcap_{x \in C} T_C(x) = \operatorname{rec}(C),$$
and $\operatorname{rec}(C)$ contains a non-zero element if and only if $C$ is un
bounded. Therefore, the intersection of all tangent cones at points of $C$ conta
ins a non-zero element **if and only if** $C$ is unbounded.
