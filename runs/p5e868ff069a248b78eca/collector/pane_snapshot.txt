## Proof

**Problem Interpretation.** The problem concerns the simple symmetric random wal
k: $X_1, X_2, \ldots$ are i.i.d. with $\mathbb{P}(X_i = +1) = \mathbb{P}(X_i = -
1) = \tfrac{1}{2}$, and $S_n = \sum_{i=1}^n X_i$ with $S_0 = 0$. We determine $\
mathbb{P}(S_n = 0 \text{ for infinitely many } n)$.

**Step 1: Return probabilities.** Since $S_n$ has the same parity as $n$, return
s to 0 can only occur at even times. By direct counting,

$$u_{2n} := \mathbb{P}(S_{2n} = 0) = \binom{2n}{n} 2^{-2n}.$$

By Stirling's approximation, $\binom{2n}{n} \sim \frac{4^n}{\sqrt{\pi n}}$, so

$$u_{2n} \sim \frac{1}{\sqrt{\pi n}} \quad \text{as } n \to \infty.$$

Therefore $\sum_{n=1}^{\infty} u_{2n} = \infty$ (the series diverges like $\sum
n^{-1/2}$).

**Step 2: First-return decomposition.** Define $f_{2n} = \mathbb{P}(\text{first
return to 0 occurs at time } 2n)$ and $f_{2n} = 0$ for odd indices. Set $u_0 = 1
$. By the Markov property, every return to 0 at time $2n$ is either the first re
turn (at some time $2k$) followed by a return after $2n - 2k$ more steps:

$$u_{2n} = \sum_{k=1}^{n} f_{2k}\, u_{2(n-k)}, \qquad n \geq 1.$$

**Step 3: Generating function relation.** Let $U(s) = \sum_{n=0}^{\infty} u_{2n}
 s^n$ and $F(s) = \sum_{n=1}^{\infty} f_{2n} s^n$. The convolution identity give
s:

$$U(s) = 1 + F(s)\, U(s), \quad \text{i.e., } U(s) = \frac{1}{1 - F(s)} \quad \t
ext{for } 0 \leq s < 1.$$

**Step 4: $F(1) = 1$ (certain return).** Since $u_{2n} \geq 0$ and $U(s) = \sum
u_{2n} s^n$, by monotone convergence:

$$U(1) = \sum_{n=0}^{\infty} u_{2n} = 1 + \sum_{n=1}^{\infty} u_{2n} = \infty.$$

From $U(s) = \frac{1}{1-F(s)}$, as $s \uparrow 1$ we have $U(s) \to \infty$, whi
ch forces $F(s) \to 1$. By monotone convergence, $F(1) = \sum_{n=1}^{\infty} f_{
2n} = 1$.

This means: **the walk returns to 0 at least once with probability 1.**

**Step 5: Infinitely many returns.** Let $T_1 < T_2 < \cdots$ be the successive
return times to 0 (with $T_0 = 0$). By the strong Markov property applied at eac
h return time $T_k$, the process $(S_{T_k + n} - S_{T_k})_{n \geq 0} = (S_{T_k +
 n})_{n \geq 0}$ is an independent copy of the original walk starting from 0. Th
erefore:

$$\mathbb{P}(T_{k+1} < \infty \mid T_k < \infty) = F(1) = 1.$$

By induction, $\mathbb{P}(T_k < \infty) = 1$ for every $k$. Hence:

$$\mathbb{P}(S_n = 0 \text{ for infinitely many } n) = \mathbb{P}\!\left(\bigcap
_{k=1}^{\infty} \{T_k < \infty\}\right) = \lim_{k \to \infty} \mathbb{P}(T_k < \
infty) = 1.$$

**Conclusion.** The simple symmetric random walk is recurrent: it returns to the
 origin infinitely often with probability one.

$$\boxed{\mathbb{P}[S_n = 0 \text{ for infinitely many } n] = 1}$$
