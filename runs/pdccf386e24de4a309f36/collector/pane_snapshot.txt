Looking at this problem, I need to find the minimum number of distinct complex r
oots of $\prod_{k=1}^m (f+k)$ as $f$ ranges over degree-$n$ polynomials.

**Answer:** $n(m-1) + 1$.

---

## Proof

**Setup.** Let $f$ be a polynomial of degree $n$ with complex coefficients. Defi
ne $P_f = \prod_{k=1}^m (f+k)$, a polynomial of degree $mn$. Let $d_k$ denote th
e number of distinct roots of $f+k$, so the number of distinct roots of $P_f$ is
 $D(f) = \sum_{k=1}^m d_k$ (since the root sets are disjoint — see below).

**Key observation (disjointness).** If $z$ is a common root of $f+k$ and $f+j$ w
ith $k \neq j$, then $f(z) = -k = -j$, a contradiction. So the root sets of $f+1
, \ldots, f+m$ are pairwise disjoint, confirming $D(f) = \sum_{k=1}^m d_k$.

**Lower bound.** Since $f+k$ has degree $n$, we have $d_k \leq n$, and the "exce
ss" $n - d_k = \sum_{z: (f+k)(z)=0} (\text{mult}_z - 1)$ counts multiplicity con
tributions. A root $z$ of $f+k$ has multiplicity $\geq 2$ iff $f'(z) = 0$. If $z
$ is a root of $f'$ of multiplicity $\mu(z)$, and $f(z) = -k$, then $z$ is a roo
t of $f+k$ of multiplicity $\mu(z)+1$, contributing $\mu(z)$ to the excess.

Therefore:
$$n - d_k = \sum_{\substack{z:\, f'(z)=0 \\ f(z)=-k}} \mu(z).$$

Summing over $k$:
$$\sum_{k=1}^m (n - d_k) = \sum_{k=1}^m \sum_{\substack{z:\, f'(z)=0 \\ f(z)=-k}
} \mu(z) = \sum_{\substack{z:\, f'(z)=0 \\ f(z) \in \{-1,\dots,-m\}}} \mu(z) \;\
leq\; \sum_{z:\, f'(z)=0} \mu(z) = n-1,$$

since $f'$ has degree $n-1$. The inequality holds because some critical values o
f $f$ may fall outside $\{-1,\ldots,-m\}$. Thus:

$$D(f) = \sum_{k=1}^m d_k = mn - \sum_{k=1}^m(n - d_k) \geq mn - (n-1) = n(m-1)+
1.$$

**Upper bound (construction achieving equality).** We exhibit $f$ with $D(f) = n
(m-1)+1$.

*Case $m = 1$:* Take $f(z) = z^n - 1$. Then $f+1 = z^n$ has 1 distinct root. Tot
al $= 1 = n(0)+1$. ✓

*Case $n = 1$:* $f(z) = az + b$, each $f+k = az + (b+k)$ has exactly 1 root, all
 distinct. Total $= m = 1\cdot(m-1)+1$. ✓

*Case $n \geq 2, m \geq 2$:* Use the Chebyshev polynomial $T_n$. Recall $T_n$ ha
s degree $n$, and $T_n'$ vanishes at $z_j = \cos(j\pi/n)$ for $j = 1,\ldots,n-1$
 (all simple roots of $T_n'$), with $T_n(z_j) = \cos(j\pi) = (-1)^j$.

Set $f(z) = \frac{1}{2}T_n(z) - \frac{3}{2}$. Then:
- $f'(z) = \frac{1}{2}T_n'(z)$, so the critical points are $z_1, \ldots, z_{n-1}
$ (each multiplicity 1).
- For **even** $j$: $f(z_j) = \frac{1}{2}(1) - \frac{3}{2} = -1$.
- For **odd** $j$: $f(z_j) = \frac{1}{2}(-1) - \frac{3}{2} = -2$.

So **all** critical values lie in $\{-1, -2\} \subseteq \{-1, \ldots, -m\}$ (sin
ce $m \geq 2$), achieving equality in the lower bound. Explicitly:

- $d_1 = n - \#\{j \text{ even}\}$, $\;d_2 = n - \#\{j \text{ odd}\}$, $\;d_k =
n$ for $k \geq 3$.
- $\#\{j \text{ even}\} + \#\{j \text{ odd}\} = n - 1$, so $d_1 + d_2 = 2n - (n-
1) = n+1$.
- $D(f) = (n+1) + (m-2)\cdot n = n(m-1) + 1$. ✓

**Conclusion.** The minimum number of distinct complex roots is:

$$\boxed{n(m-1) + 1}$$
