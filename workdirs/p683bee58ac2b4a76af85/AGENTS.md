# Problem

In the high-stakes world of interstellar archaeology, an expedition team has discovered a series of ancient data vaults. To unlock the central archive, a security clearance code must be generated.

The code consists of an ordered sequence of four distinct positive integers $(a, b, c, d)$. The security protocol dictates that these numbers must satisfy a specific "nested selection" hierarchy based on the planet's combinatorial logic.

Specifically, the protocol requires that if you were to take a set of $a$ unique artifacts and choose a subset of $b$ artifacts from them, the number of ways to perform that selection forms a primary value. Similarly, if you take a set of $c$ unique artifacts and choose a subset of $d$ artifacts from them, that forms a secondary value. 

The final security constraint is satisfied only if the number of ways to choose a subset of the "secondary value" size from a set of the "primary value" size is exactly 21.

How many unique ordered sequences $(a, b, c, d)$ of distinct positive integers meet this precise archaeological criteria?
