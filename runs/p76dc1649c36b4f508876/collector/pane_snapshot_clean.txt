### 问题

求自由空间格林函数 $g(x,y;\xi,\eta)$ 满足：

$$\frac{\partial^2 g}{\partial x^2} + \frac{\partial^2 g}{\partial y^2} - \frac{
\partial g}{\partial x} = -\delta(x-\xi)\delta(y-\eta), \quad -\infty < x,y,\xi,
\eta < \infty.$$

### 策略：配方代换

算子为 $L = \partial_x^2 + \partial_y^2 - \partial_x$。在 $x$ 上进行配方：

$$\partial_x^2 - \partial_x = \left(\partial_x - \tfrac{1}{2}\right)^2 - \tfrac{
1}{4}.$$

设代换

$$g(x,y;\xi,\eta) = e^{x/2}\, h(x,y;\xi,\eta).$$

则 $g_x = e^{x/2}(h_x + \tfrac{1}{2}h)$，$g_{xx} = e^{x/2}(h_{xx} + h_x + \tfrac
{1}{4}h)$，$g_{yy} = e^{x/2}h_{yy}$，因此

$$g_{xx} + g_{yy} - g_x = e^{x/2}\!\left(h_{xx} + h_{yy} - \tfrac{1}{4}h\right).
$$

PDE 变为

$$h_{xx} + h_{yy} - \tfrac{1}{4}\,h = -\,e^{-\xi/2}\,\delta(x-\xi)\,\delta(y-\et
a).$$

### 修改后的亥姆霍兹（Yukawa）格林函数

这是二维修正亥姆霍兹方程 $\nabla^2 h - \lambda^2 h = -\delta$，其中 $\lambda = \
frac{1}{2}$。其自由空间格林函数为已知的标准结果：

$$h_0(x,y;\xi,\eta) = \frac{1}{2\pi}\,K_0\!\left(\lambda\sqrt{(x-\xi)^2+(y-\eta)
^2}\right),$$

其中 $K_0$ 是零阶第二类修正贝塞尔函数。这可以通过对 $\hat{h}_0 = \frac{1}{k^2+l^
2+\lambda^2}$ 进行逆傅里叶变换并先计算 $l$ 积分来验证，得到 $\frac{1}{2\pi}K_0(\
lambda r)$，其中 $r = \sqrt{(x-\xi)^2+(y-\eta)^2}$。

对于 $\lambda = \frac{1}{2}$ 和源强度 $e^{-\xi/2}$：

$$h(x,y;\xi,\eta) = e^{-\xi/2}\,\frac{1}{2\pi}\,K_0\!\left(\frac{r}{2}\right), \
qquad r = \sqrt{(x-\xi)^2+(y-\eta)^2}.$$

### 还原为 $g$

$$\boxed{g(x,y;\xi,\eta) = \frac{1}{2\pi}\,e^{(x-\xi)/2}\,K_0\!\left(\frac{1}{2}
\sqrt{(x-\xi)^2+(y-\eta)^2}\right).}$$

### 验证

**远离源（$r>0$）：** 设 $u=x-\xi$，$v=y-\eta$，$h=\frac{1}{2\pi}K_0(r/2)$，$g=e
^{u/2}h$。由于 $h$ 满足 $h_{xx}+h_{yy}-\frac{1}{4}h=0$（对于 $r>0$），我们得到 $
g_{xx}+g_{yy}-g_x = e^{u/2}(h_{xx}+h_{yy}-\frac{1}{4}h)=0$。 ✓

**在源处：** 当 $r\to 0$ 时，$K_0(r/2)\sim -\ln(r/2)-\gamma$，因此 $\frac{1}{2\p
i}K_0(r/2)\sim -\frac{1}{2\pi}\ln r$，这是标准的二维拉普拉斯奇点，产生 $\delta(x
-\xi)\delta(y-\eta)$。指数因子 $e^{(x-\xi)/2}\to 1$ 是平滑的，且在源处不改变 $\d
elta$ 的强度。 ✓

**傅里叶变换一致性：** 对 $G(u,v)=e^{u/2}\frac{1}{2\pi}K_0(r/2)$ 进行二维傅里叶
变换得到 $\hat{G}(k,l)=\hat{f}(k+i/2,\,l) = \frac{1}{(k+i/2)^2+l^2+1/4} = \frac{
1}{k^2+l^2+ik}$，这正是对原 PDE 直接进行傅里叶变换得到的结果。 ✓
