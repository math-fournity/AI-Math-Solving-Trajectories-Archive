**Setup.** Since $\|Tu\|_2 \le C_2\|u\|_1$, the linear map $T$ is bounded. Since

le C_1^{-1}\|v\|_2$, so $T^{-1}$ is bounded. Hence $T$ is a topological isomorph

{-1}=(T^{-1})^*$.

**The positive square root.** Consider the operator $B := T^*T : H_1 \to H_1$. I
t is bounded, self-adjoint, and positive:
$$\langle Bu,u\rangle_1 = \langle Tu,Tu\rangle_2 = \|Tu\|_2^2 \ge 0.$$
Moreover $B$ is invertible: $T$ and $T^*$ are both invertible bounded operators,
 so $B=T^*T$ is invertible with bounded inverse. Being positive and invertible,
$B$ has a unique positive self-adjoint square root $A := B^{1/2} = (T^*T)^{1/2}$
, which is itself bounded, positive, and invertible (with $A^{-1} = (T^*T)^{-1/2
}$, obtained as the square root of the positive invertible operator $(T^*T)^{-1}

**Key identity.** For every $u\in H_1$, using that $A$ is self-adjoint,
$$\|Tu\|_2^2 = \langle Tu,Tu\rangle_2 = \langle T^*Tu,u\rangle_1 = \langle A^2 u
,u\rangle_1 = \langle Au,Au\rangle_1 = \|Au\|_1^2.$$
Thus
$$\|Tu\|_2 = \|Au\|_1 \qquad \forall\, u\in H_1. \tag{$\ast$}$$

**Construction of the isometry.** Define
$$U := T\,A^{-1} : H_1 \longrightarrow H_2.$$
This is well defined and bounded since both $T$ and $A^{-1}$ are. For any $u\in
H_1$, apply $(\ast)$ with $A^{-1}u$ in place of $u$:
$$\|Uu\|_2 = \|T(A^{-1}u)\|_2 = \|A(A^{-1}u)\|_1 = \|u\|_1.$$
So $U$ is an isometry.
