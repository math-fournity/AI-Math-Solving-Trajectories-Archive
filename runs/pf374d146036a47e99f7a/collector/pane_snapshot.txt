## Proof

A symmetric positive definite $10 \times 10$ matrix $A$ has $10$ positive real e
igenvalues $\lambda_1, \lambda_2, \ldots, \lambda_{10} > 0$ (counted with multip
licity), and $A$ is orthogonally diagonalizable.

The given conditions translate to:
- **Trace**: $\lambda_1 + \lambda_2 + \cdots + \lambda_{10} = 10$
- **Determinant**: $\lambda_1 \lambda_2 \cdots \lambda_{10} = 1$

**Applying the AM–GM inequality** to the positive numbers $\lambda_1, \ldots, \l
ambda_{10}$:

$$\frac{\lambda_1 + \lambda_2 + \cdots + \lambda_{10}}{10} \geq \left(\lambda_1
\lambda_2 \cdots \lambda_{10}\right)^{1/10}$$

Substituting the given values:

$$\frac{10}{10} = 1 \geq \left(1\right)^{1/10} = 1$$

So equality holds in the AM–GM inequality. **Equality in AM–GM occurs if and onl
y if all the values are equal**, hence:

$$\lambda_1 = \lambda_2 = \cdots = \lambda_{10} = 1$$

**Uniqueness of the matrix.** A real symmetric matrix is orthogonally diagonaliz
able: $A = Q D Q^T$ for some orthogonal matrix $Q$ and diagonal matrix $D = \ope
ratorname{diag}(\lambda_1, \ldots, \lambda_{10})$. Since every eigenvalue equals
 $1$, we have $D = I_{10}$, and therefore:

$$A = Q \, I_{10} \, Q^T = Q Q^T = I_{10}$$

regardless of the choice of $Q$. Thus $A = I_{10}$ is the **only** matrix satisf
ying all the conditions.

**Verification.** The identity matrix $I_{10}$ is:
- symmetric ✓
- positive definite (all eigenvalues $= 1 > 0$) ✓
- $\operatorname{tr}(I_{10}) = 10$ ✓
- $\det(I_{10}) = 1$ ✓

Therefore, there is exactly **one** such matrix.
