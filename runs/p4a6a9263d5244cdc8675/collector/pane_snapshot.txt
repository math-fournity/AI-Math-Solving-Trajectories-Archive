## Proof

**Claim:** Yes, the family $\{\phi_\varepsilon\}_{\varepsilon > 0}$ is uniformly
 bounded. In fact, it can be constructed so that $0 \le \phi_\varepsilon \le 1$
for every $\varepsilon > 0$, giving a uniform bound of $1$.

### Construction of the cutoff function

We use the standard smooth step function. Define $f: \mathbb{R} \to \mathbb{R}$
by
$$
f(t) = \begin{cases} e^{-1/t} & t > 0, \\ 0 & t \le 0. \end{cases}
$$
This is a well-known $C^\infty$ function. From it, define the normalized smooth
transition
$$
g(t) = \frac{f(t)}{f(t) + f(1 - t)}, \quad t \in \mathbb{R}.
$$
Then $g \in C^\infty(\mathbb{R})$ with the properties:
- $g(t) = 0$ for $t \le 0$,
- $g(t) = 1$ for $t \ge 1$,
- $0 \le g(t) \le 1$ for all $t \in \mathbb{R}$.

Now set $h(t) = g(1 - t)$, which reverses the transition:
- $h(t) = 1$ for $t \le 0$,
- $h(t) = 0$ for $t \ge 1$,
- $0 \le h(t) \le 1$ for all $t$.

### Definition of $\phi_\varepsilon$

For each $\varepsilon > 0$, define
$$
\phi_\varepsilon(x) = h\!\left(\frac{|x - x_0| - R}{\varepsilon}\right), \qquad
x \in \mathbb{R}^N.
$$

Since $|x - x_0|$ is continuous and $h$ is $C^\infty$, the composition is $C^\in
fty$ away from $x_0$. At $x = x_0$ the function $|x - x_0|$ is not smooth, but $
\phi_\varepsilon$ equals $1$ in a neighborhood of $x_0$ (namely $B(x_0, R)$), so
 $\phi_\varepsilon$ is identically $1$ there and hence $C^\infty$ everywhere. Th
us $\phi_\varepsilon \in C_c^\infty(\mathbb{R}^N)$.

### Verification of the required properties

**1. $\phi_\varepsilon = 1$ on $B(x_0, R)$:** If $x \in B(x_0, R)$, then $|x - x
_0| < R$, so $\frac{|x-x_0| - R}{\varepsilon} < 0$, hence $h = 1$, giving $\phi_
\varepsilon(x) = 1$.

**2. Compact support in $B(x_0, R + \varepsilon)$:** If $|x - x_0| \ge R + \vare
psilon$, then $\frac{|x-x_0|-R}{\varepsilon} \ge 1$, so $h = 0$, giving $\phi_\v
arepsilon(x) = 0$. Therefore $\operatorname{supp} \phi_\varepsilon \subseteq \ov
erline{B(x_0, R+\varepsilon)}$, which is compact. (The support is contained in t
he closed ball of radius $R + \varepsilon$, which is a compact subset; the open
ball $B(x_0, R+\varepsilon)$ contains this support except possibly the boundary
sphere where $\phi_\varepsilon = 0$, so the support lies in $B(x_0, R+\varepsilo
n)$.)

**3. Uniform boundedness:** Since $0 \le h(t) \le 1$ for all $t \in \mathbb{R}$,
 we have
$$
0 \le \phi_\varepsilon(x) \le 1 \quad \text{for all } x \in \mathbb{R}^N \text{
and all } \varepsilon > 0.
$$
Therefore
$$
\sup_{\varepsilon > 0} \|\phi_\varepsilon\|_{L^\infty(\mathbb{R}^N)} \le 1 < \in
fty.
$$

### Conclusion

The family $\{\phi_\varepsilon\}_{\varepsilon > 0}$ is **uniformly bounded** (by
 $1$). The bound is independent of $\varepsilon$, $x_0$, $R$, and $N$.
