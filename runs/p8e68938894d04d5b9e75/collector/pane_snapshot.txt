Looking at this problem, I need to find all injective functions $f: \mathbb{R} \
rightarrow \mathbb{R}$ such that for every real $x$ and positive integer $n$:
$$\left|\sum_{i=1}^n i\left(f(x+i+1)-f(f(x+i))\right)\right|<2016.$$

## Proof

**Step 1: Define $g$ and show $g \equiv 0$.**

Let $g(t) = f(t+1) - f(f(t))$ for all $t \in \mathbb{R}$. The condition becomes:
$$|S_n(x)| < 2016, \quad \text{where } S_n(x) = \sum_{i=1}^n i \cdot g(x+i),$$
for all $x \in \mathbb{R}$ and all positive integers $n$.

Observe that $S_n(x) - S_{n-1}(x) = n \cdot g(x+n)$ for $n \geq 2$ (and $S_1(x)
= g(x+1)$). By the triangle inequality:
$$|n \cdot g(x+n)| = |S_n(x) - S_{n-1}(x)| \leq |S_n(x)| + |S_{n-1}(x)| < 2016 +
 2016 = 4032.$$

For $n = 1$: $|g(x+1)| = |S_1(x)| < 2016 < 4032/1$, so the bound $|g(x+n)| < 403
2/n$ holds for all $n \geq 1$.

Now fix any $y \in \mathbb{R}$. For any positive integer $n$, set $x = y - n$ (w
hich is a valid real number). Then $x + n = y$, so:
$$|g(y)| < \frac{4032}{n}.$$

Since this holds for **every** positive integer $n$, letting $n \to \infty$ give
s $g(y) = 0$. As $y$ was arbitrary:
$$g \equiv 0, \quad \text{i.e., } f(t+1) = f(f(t)) \text{ for all } t \in \mathb
b{R}.$$

**Step 2: Use injectivity to solve the functional equation.**

We have $f(f(x)) = f(x+1)$ for all $x \in \mathbb{R}$. Since $f$ is injective, $
f(a) = f(b) \implies a = b$. Applying this with $a = f(x)$ and $b = x+1$:
$$f(x) = x + 1 \quad \text{for all } x \in \mathbb{R}.$$

**Step 3: Verification.**

For $f(x) = x+1$:
- **Injective:** $f(a) = f(b) \implies a+1 = b+1 \implies a = b$. ✓
- **Functional equation:** $f(f(x)) = f(x+1) = x+2$ and $f(x+1) = x+2$, so $f(f(
x)) = f(x+1)$. ✓
- **Original inequality:** $f(x+i+1) - f(f(x+i)) = (x+i+2) - (x+i+2) = 0$, so th
e sum is $0$, and $|0| < 2016$. ✓

**Conclusion.** The unique injective function satisfying the given condition is:
$$\boxed{f(x) = x + 1}.$$
