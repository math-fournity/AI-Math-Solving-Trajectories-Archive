## Solution

**Setup.** Let $f(x)=\sum_{i=0}^{n} a_i x^i$ with all $a_i\in\mathbb{Z}$. We are
 given
$$f(p_1^2)=-56,\qquad f(p_2^2)=56,$$
with $p_1,p_2$ prime.

**Key divisibility fact.** For any integer-coefficient polynomial $f$ and any in
tegers $u,v$,
$$u-v \mid f(u)-f(v).$$
Applying this with $u=p_1^2,\;v=p_2^2$:
$$p_1^2-p_2^2 \mid f(p_1^2)-f(p_2^2)=(-56)-56=-112.$$
So $(p_1^2-p_2^2)\mid 112$.

**Sufficiency.** The condition is also sufficient: a linear polynomial $f(x)=ax+
b$ works whenever $(p_2^2-p_1^2)\mid 112$, since $a=\dfrac{112}{p_2^2-p_1^2}$ an
d $b=-56-a\,p_1^2$ are then integers. So we only need to find all prime pairs wi
th $(p_1^2-p_2^2)\mid 112$.

**Factoring.** Let $d=p_1^2-p_2^2=(p_1-p_2)(p_1+p_2)$. Write $s=p_1+p_2\ge 4$, $
t=p_1-p_2$, with $s,t$ of the same parity and $s>|t|$.

Since $112=2^4\cdot 7$, the divisors are $\{\pm1,\pm2,\pm4,\pm7,\pm8,\pm14,\pm16
,\pm28,\pm56,\pm112\}$.

- **Odd $d$** ($\pm1,\pm7$): requires $s,t$ both odd. For $d=\pm7$: $s\cdot t=\p
m7$ with $s\ge4$ forces $s=7,t=\pm1$, giving $\{p_1,p_2\}=\{4,3\}$ — but $4$ is
not prime. For $d=\pm1$: $s=1<4$, impossible. **No solutions.**

- **Even $d$ not divisible by 4** ($\pm2,\pm14$): $s,t$ same parity means produc
t is odd (both odd) or divisible by 4 (both even) — never $2\pmod 4$. **No solut
ions.**

- **$d$ divisible by 4** ($\pm4,\pm8,\pm16,\pm28,\pm56,\pm112$): set $s=2a,\;t=2
b$, so $p_1=a+b,\;p_2=a-b$, and $4ab=d$, i.e. $ab\in\{\pm1,\pm2,\pm4,\pm7,\pm14,
\pm28\}$. We need $a+b$ and $a-b$ both prime $\ge 2$.

  Checking each positive value $ab=m\in\{1,2,4,7,14,28\}$ (negative values just
swap $p_1\leftrightarrow p_2$):

  - $ab=1$: $(a,b)=(1,1)\Rightarrow a-b=0$, not prime.
  - $ab=2$: $(2,1)\Rightarrow (3,1)$, $1$ not prime.
  - $ab=4$: $(4,1)\Rightarrow (5,3)$ ✓ — both prime. $(2,2)\Rightarrow(4,0)$, no
.
  - $ab=7$: $(7,1)\Rightarrow(8,6)$, no.
  - $ab=14$: $(14,1)\Rightarrow(15,13)$, $15$ not prime; $(7,2)\Rightarrow(9,5)$
, $9$ not prime.
  - $ab=28$: $(28,1)\Rightarrow(29,27)$, $27$ not prime; $(14,2)\Rightarrow(16,1
2)$, no; $(7,4)\Rightarrow(11,3)$ ✓ — both prime.

  Negative $ab$ gives the swapped pairs $(3,5)$ and $(3,11)$.

**All valid ordered pairs:**
$$(p_1,p_2)\in\{(5,3),\;(11,3),\;(3,5),\;(3,11)\}.$$

**Verification.**
- $(5,3)$: $f(x)=-7x+119$; $f(25)=-56$, $f(9)=56$. ✓
- $(11,3)$: $f(x)=-x+65$; $f(121)=-56$, $f(9)=56$. ✓
- $(3,5)$: $f(x)=7x-119$; $f(9)=-56$, $f(25)=56$. ✓
- $(3,11)$: $f(x)=x-65$; $f(9)=-56$, $f(121)=56$. ✓

**Sum.**
$$(5+3)+(11+3)+(3+5)+(3+11)=8+14+8+14=\boxed{44}.$$
