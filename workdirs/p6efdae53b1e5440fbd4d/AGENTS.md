# Problem

A high-security data vault uses a rotating encryption system based on a cycle of $n = 2020$ possible states, indexed from $0$ to $2019$. A state index $k$ is considered "accessible" if there exists a set of three security keys—represented by integers $x, y,$ and $z$—that satisfy two specific synchronization protocols:

1.  The Sum-of-Squares Protocol: The sum of the squares of the three keys must be a perfect multiple of the cycle length ($x^2 + y^2 + z^2 \equiv 0 \pmod{2020}$).
2.  The Product-Validation Protocol: The product of the three keys, when divided by the cycle length, must leave a remainder equal to the state index $k$ ($x y z \equiv k \pmod{2020}$).

An analyst needs to determine the total number of unique accessible state indices $k$ in the range $0 \le k \le 2019$ that can be generated by such integer keys. Find this total number.
