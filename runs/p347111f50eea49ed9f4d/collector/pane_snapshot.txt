## Proof

**Strategy.** Every square-free integer $d$ factors into "atomic" pieces (the si
gn $-1$, the prime $2$, and odd primes $p_i$). We show each atomic piece generat
es a quadratic field inside a cyclotomic field. Since $\sqrt{d}$ is a product of
 the square roots of these pieces, $\mathbb{Q}(\sqrt{d})$ lies in the compositum
 of the corresponding cyclotomic fields, and the compositum of cyclotomic fields
 is again cyclotomic.

### Key Lemma: Compositum of cyclotomic fields is cyclotomic

For any positive integers $m, n$:
$$\mathbb{Q}(\zeta_m)\cdot\mathbb{Q}(\zeta_n) \subseteq \mathbb{Q}(\zeta_{\opera
torname{lcm}(m,n)}).$$

*Proof.* Set $L = \operatorname{lcm}(m,n)$. Then $\zeta_m = \zeta_L^{L/m}$ and $
\zeta_n = \zeta_L^{L/n}$, so both $\zeta_m, \zeta_n \in \mathbb{Q}(\zeta_L)$. He
nce the compositum is contained in $\mathbb{Q}(\zeta_L)$. $\square$

By induction, any finite compositum $\mathbb{Q}(\zeta_{m_1})\cdots\mathbb{Q}(\ze
ta_{m_r}) \subseteq \mathbb{Q}(\zeta_N)$ where $N = \operatorname{lcm}(m_1,\dots
,m_r)$.

### Atomic quadratic fields are cyclotomic

We establish that each "building-block" quadratic field lies in a cyclotomic fie
ld:

**(i) $\mathbb{Q}(\sqrt{-1})$:** $\sqrt{-1} = i = \zeta_4$, so $\mathbb{Q}(\sqrt
{-1}) = \mathbb{Q}(\zeta_4)$.

**(ii) $\mathbb{Q}(\sqrt{2})$:** $\zeta_8 = e^{2\pi i/8} = \frac{\sqrt{2}}{2}(1+
i)$, so $\zeta_8 + \zeta_8^{-1} = \sqrt{2}$. Hence $\sqrt{2}\in\mathbb{Q}(\zeta_
8)$, giving $\mathbb{Q}(\sqrt{2})\subseteq\mathbb{Q}(\zeta_8)$.

**(iii) $\mathbb{Q}(\sqrt{p})$ for odd prime $p$:** This is the **given hypothes
is**: $\mathbb{Q}(\sqrt{p})\subseteq\mathbb{Q}(\zeta_p)$ or $\mathbb{Q}(\zeta_{2
p})$. In either case, $\mathbb{Q}(\sqrt{p})\subseteq\mathbb{Q}(\zeta_{2p})$ (sin
ce $\mathbb{Q}(\zeta_p)\subseteq\mathbb{Q}(\zeta_{2p})$).

**(iv) $\mathbb{Q}(\sqrt{-p})$ for odd prime $p$:** We have $\sqrt{-p} = \sqrt{p
}\cdot\sqrt{-1}$, so
$$\mathbb{Q}(\sqrt{-p}) \subseteq \mathbb{Q}(\sqrt{p})\cdot\mathbb{Q}(\sqrt{-1})
 \subseteq \mathbb{Q}(\zeta_{2p})\cdot\mathbb{Q}(\zeta_4) \subseteq \mathbb{Q}(\
zeta_{\operatorname{lcm}(2p,\,4)}).$$
Since $p$ is odd, $\operatorname{lcm}(2p, 4) = 4p$, so $\mathbb{Q}(\sqrt{-p})\su
bseteq\mathbb{Q}(\zeta_{4p})$.

**(v) $\mathbb{Q}(\sqrt{-2})$:** $\sqrt{-2} = \sqrt{2}\cdot\sqrt{-1}$, so
$$\mathbb{Q}(\sqrt{-2}) \subseteq \mathbb{Q}(\sqrt{2})\cdot\mathbb{Q}(\sqrt{-1})
 \subseteq \mathbb{Q}(\zeta_8)\cdot\mathbb{Q}(\zeta_4) \subseteq \mathbb{Q}(\zet
a_{\operatorname{lcm}(8,4)}) = \mathbb{Q}(\zeta_8).$$

### General case

Let $d$ be a square-free integer. If $d = 1$, then $\mathbb{Q}(\sqrt{d}) = \math
bb{Q} \subseteq \mathbb{Q}(\zeta_1)$, trivially. Otherwise, write:

$$d = \epsilon \cdot 2^{a} \cdot p_1 \cdot p_2 \cdots p_k$$

where $\epsilon \in \{+1, -1\}$, $a \in \{0, 1\}$, and $p_1, \dots, p_k$ are dis
tinct odd primes.

Set $d_0 = \epsilon$ (if $\epsilon = -1$), $d_1 = 2$ (if $a = 1$), and $d_{j+1}
= p_j$ for $j = 1, \dots, k$. Then $d = \prod d_i$ (over the active factors), an
d:

$$\sqrt{d} = \prod_i \sqrt{d_i} \in \mathbb{Q}\bigl(\sqrt{d_1},\, \sqrt{d_2},\,
\dots\bigr).$$

(Here the product $\prod \sqrt{d_i}$ is a square root of $\prod d_i = d$, hence
equals $\pm\sqrt{d}$; either way $\sqrt{d}$ lies in the field generated by the i
ndividual square roots.)

Each $\mathbb{Q}(\sqrt{d_i})$ is one of the atomic fields from cases (i)–(v) abo
ve, hence lies in a cyclotomic field $\mathbb{Q}(\zeta_{n_i})$:

| Factor $d_i$ | Cyclotomic containment |
|---|---|
| $-1$ | $\mathbb{Q}(\zeta_4)$ |
| $2$ | $\mathbb{Q}(\zeta_8)$ |
| $p$ (odd prime) | $\mathbb{Q}(\zeta_{2p})$ |
| $-p$ (odd prime) | $\mathbb{Q}(\zeta_{4p})$ |
| $-2$ | $\mathbb{Q}(\zeta_8)$ |

Therefore:

$$\mathbb{Q}(\sqrt{d}) \subseteq \mathbb{Q}(\sqrt{d_1})\cdot\mathbb{Q}(\sqrt{d_2
})\cdots \subseteq \mathbb{Q}(\zeta_{n_1})\cdot\mathbb{Q}(\zeta_{n_2})\cdots \su
bseteq \mathbb{Q}(\zeta_N),$$

where $N = \operatorname{lcm}(n_1, n_2, \dots)$ by the Key Lemma.

Explicitly, $N = \operatorname{lcm}\bigl(\{4 : \epsilon=-1\} \cup \{8 : a=1\} \c
up \{2p_j : j=1,\dots,k\}\bigr)$, which is a well-defined positive integer.

### Conclusion

For every square-free integer $d$, the quadratic extension $\mathbb{Q}(\sqrt{d})
$ is contained in the cyclotomic extension $\mathbb{Q}(\zeta_N)$ for some positi
ve integer $N$. $\blacksquare$
