## Proof

**Claim:** For every $k \in \mathbb{N}^*$, the limit equals $0$.

**Key idea:** The product contains $n$ factors. For $j > \sqrt{n}$ (the vast maj
ority), the arguments $\frac{x}{j^2}$ are small on $[0,n]$, so each factor is bo
unded by $\frac{x}{j^2} \ll 1$. The resulting tail product is super-exponentiall
y small, overwhelming any polynomial prefactor $n^k$.

---

**Step 1: Setting up the bound.**

Let $M = \lfloor n^{3/4} \rfloor$. For all $x \in [0,n]$ and $j > M$:
$$\frac{x}{j^2} \leq \frac{n}{M^2} \leq \frac{n}{n^{3/2}} = n^{-1/2} \to 0,$$
so for sufficiently large $n$, $\frac{x}{j^2} < 1$, and we may use $|\sin\theta|
 \leq |\theta|$ to get
$$\left|\sin\frac{x}{j^2}\right| \leq \frac{x}{j^2}.$$

For $j \leq M$, we use the trivial bound $|\sin\frac{x}{j^2}| \leq 1$.

Therefore:
$$\left|\prod_{j=1}^{n} \sin\frac{x}{j^2}\right| \leq \prod_{j=1}^{M} 1 \cdot \p
rod_{j=M+1}^{n} \frac{x}{j^2} = \frac{x^{n-M}\,(M!)^2}{(n!)^2}.$$

**Step 2: Bounding the integral.**

$$\left|\int_0^n \prod_{j=1}^{n} \sin\frac{x}{j^2}\, dx\right| \leq \frac{(M!)^2
}{(n!)^2}\int_0^n x^{n-M}\, dx = \frac{(M!)^2}{(n!)^2}\cdot\frac{n^{n-M+1}}{n-M+
1}.$$

Since $M = o(n)$, for large $n$ we have $n - M + 1 \geq n/2$, so:

$$\left|\int_0^n \prod_{j=1}^{n} \sin\frac{x}{j^2}\, dx\right| \leq \frac{2\,(M!
)^2\, n^{n-M}}{(n!)^2}.$$

**Step 3: Applying elementary Stirling-type bounds.**

We use the standard bounds:
- $n! \geq \left(\frac{n}{e}\right)^n$ (from Stirling's formula),
- $M! \leq M^M$ (trivially, since $M! = 1\cdot 2\cdots M \leq M^M$).

Substituting:

$$\frac{2\,(M!)^2\, n^{n-M}}{(n!)^2} \leq \frac{2\, M^{2M}\, n^{n-M}}{(n/e)^{2n}
} = \frac{2\, M^{2M}\, e^{2n}}{n^{n+M}}.$$

**Step 4: Logarithmic analysis with $M = n^{3/4}$.**

Taking logarithms:

$$\ln\!\left(\frac{2\, M^{2M}\, e^{2n}}{n^{n+M}}\right) = \ln 2 + 2M\ln M + 2n -
 (n+M)\ln n.$$

With $M = n^{3/4}$:

$$= \ln 2 + 2n^{3/4}\cdot\tfrac{3}{4}\ln n + 2n - \left(n + n^{3/4}\right)\ln n$
$
$$= \ln 2 + \tfrac{3}{2}\,n^{3/4}\ln n + 2n - n\ln n - n^{3/4}\ln n$$
$$= -n\ln n + 2n + \tfrac{1}{2}\,n^{3/4}\ln n + \ln 2.$$

As $n \to \infty$, the dominant term is $-n\ln n$, since $n\ln n \gg 2n$ and $n\
ln n \gg n^{3/4}\ln n$. Therefore:

$$\ln\!\left(\frac{2\, M^{2M}\, e^{2n}}{n^{n+M}}\right) \to -\infty,$$

which means $\frac{2\, M^{2M}\, e^{2n}}{n^{n+M}} \to 0$ super-exponentially.

**Step 5: Including the polynomial prefactor.**

For any fixed $k \in \mathbb{N}^*$:

$$n^k \cdot \frac{2\, M^{2M}\, e^{2n}}{n^{n+M}} \quad\text{has logarithm}\quad k
\ln n - n\ln n + 2n + \tfrac{1}{2}\,n^{3/4}\ln n + \ln 2.$$

The term $k\ln n$ is negligible compared to $-n\ln n$, so this still tends to $-
\infty$. Hence:

$$n^k \cdot \frac{2\, M^{2M}\, e^{2n}}{n^{n+M}} \to 0.$$

**Step 6: Conclusion.**

Combining Steps 2–5:

$$n^k\left|\int_0^n \prod_{j=1}^{n} \sin\frac{x}{j^2}\, dx\right| \leq n^k \cdot
 \frac{2\, M^{2M}\, e^{2n}}{n^{n+M}} \to 0.$$

Therefore:

$$\boxed{\lim_{n\to\infty} n^k \int_0^n \prod_{j=1}^{n} \sin\frac{x}{j^2}\, dx =
 0 \quad \text{for all } k \in \mathbb{N}^*.}$$

The essential reason is that the product $\prod_{j=1}^n \sin\frac{x}{j^2}$ conta
ins $n - O(n^{3/4})$ factors with arguments $\frac{x}{j^2} \leq n^{-1/2}$, each
contributing a factor $\lesssim \frac{x}{j^2}$. Their collective product is boun
ded by $\frac{x^{n-M}(M!)^2}{(n!)^2}$, which by Stirling's formula decays like $
\exp(-n\ln n + O(n))$ — super-exponentially fast, far exceeding any polynomial g
rowth $n^k$.
