## Proof

Let $y \in \mathbb{R}$ be fixed, and let $\{r_n\}_{n=1}^\infty$ be an enumeratio
n of the rationals. Define
$$f(x) = \sum_{\{n\,:\, r_n \in (x,y)\}} \frac{1}{2^n}, \qquad x < y.$$

We show $\lim_{x \to y^-} f(x) = 0$.

**Key observation.** As $x \to y^-$, the interval $(x,y)$ shrinks, so the index
set $\{n : r_n \in (x,y)\}$ is monotonically decreasing (in the sense of set inc
lusion). Hence $f(x)$ is non-increasing and bounded below by $0$, so the limit e
xists and equals $\inf_{x < y} f(x)$. It suffices to show this infimum is $0$.

**Argument.** Let $\varepsilon > 0$. Choose $N \in \mathbb{N}$ such that
$$\sum_{n = N+1}^{\infty} \frac{1}{2^n} = \frac{1}{2^N} < \varepsilon.$$

Now consider the finite set of rationals $\{r_1, r_2, \ldots, r_N\}$. Those that
 lie strictly below $y$ form a finite set
$$S = \{r_k : 1 \le k \le N,\ r_k < y\}.$$

**Case 1: $S = \emptyset$.** Then for any $x < y$, none of $r_1, \ldots, r_N$ be
long to $(x, y)$, so
$$f(x) = \sum_{\{n > N : r_n \in (x,y)\}} \frac{1}{2^n} \le \sum_{n=N+1}^{\infty
} \frac{1}{2^n} < \varepsilon.$$

**Case 2: $S \neq \emptyset$.** Let $m = \max S$, which exists since $S$ is fini
te. Choose $x$ with $m < x < y$ (possible since $m < y$). Then for every $k \in
\{1, \ldots, N\}$ with $r_k < y$, we have $r_k \le m < x$, so $r_k \notin (x, y)
$. For $k$ with $r_k \ge y$, clearly $r_k \notin (x,y)$ as well. Hence none of $
r_1, \ldots, r_N$ lie in $(x, y)$, and again
$$f(x) = \sum_{\{n > N : r_n \in (x,y)\}} \frac{1}{2^n} \le \sum_{n=N+1}^{\infty
} \frac{1}{2^n} < \varepsilon.$$

In both cases, for all $x$ sufficiently close to $y$ from below, $f(x) < \vareps
ilon$.

**Conclusion.** Since $\varepsilon > 0$ was arbitrary, $\lim_{x \to y^-} f(x) =
0$. $\blacksquare$
