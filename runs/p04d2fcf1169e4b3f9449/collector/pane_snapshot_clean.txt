## Proof

Let $G$ be a group of exponent $2^n$, so $g^{2^n}=1$ for all $g\in G$. Set $a =
x^{2^{n-1}}$ and $b = y^{2^{n-1}}$. Then
$$a^2 = x^{2^n} = 1, \qquad b^2 = y^{2^n} = 1,$$
so $a$ and $b$ are involutions: $a^{-1}=a$, $b^{-1}=b$.

Define the left-normed commutator $c_k = [a, \underbrace{b,\ldots,b}_{k}]$ for $
k\ge 1$, with $c_0 = a$.

**Claim.** For every $k\ge 1$:
- $c_k = (ab)^{2^k}$ if $k$ is odd,
- $c_k = (ba)^{2^k}$ if $k$ is even.

**Base case $k=1$:** $c_1 = [a,b] = a^{-1}b^{-1}ab = a\,b\,a\,b = (ab)^2 = (ab)^
{2^1}$. ✓

**Two useful identities** (for involutions $a,b$), both proved by induction on $
m$:
1. $(ba)^m\, b = b\,(ab)^m$,
2. $(ab)^m\, b = (ab)^{m-1}\, a$,

and their reverses $b\,(ab)^m = (ba)^m\, b$ and $a\,(ba)^m = (ab)^m\, a$.

**Inductive step (odd $k \to$ even $k+1$):** Suppose $c_k = (ab)^{2^k}$. Then
$$c_{k+1} = c_k^{-1}\, b\, c_k\, b.$$
Since $c_k^{-1} = (ba)^{2^k}$, using identity (1):
$$c_k^{-1}\, b = (ba)^{2^k}\, b = b\,(ab)^{2^k}.$$
Then
$$c_k^{-1}\, b\, c_k = b\,(ab)^{2^k}\,(ab)^{2^k} = b\,(ab)^{2^{k+1}}.$$
Finally, using identity (2) and its reverse:
$$c_{k+1} = b\,(ab)^{2^{k+1}}\, b = b\,(ab)^{2^{k+1}-1}\, a = (ba)^{2^{k+1}-1}\,
 b\, a = (ba)^{2^{k+1}-1}\,(ba) = (ba)^{2^{k+1}}.$$
Since $k+1$ is even, this matches the claim. ✓

**Inductive step (even $k \to$ odd $k+1$):** Suppose $c_k = (ba)^{2^k}$. Then $c
_k^{-1} = (ab)^{2^k}$, and using identity (2):
$$c_k^{-1}\, b = (ab)^{2^k}\, b = (ab)^{2^k-1}\, a.$$
Using $a\,(ba)^m = (ab)^m\, a$:
$$c_k^{-1}\, b\, c_k = (ab)^{2^k-1}\, a\,(ba)^{2^k} = (ab)^{2^k-1}\,(ab)^{2^k}\,
 a = (ab)^{2^{k+1}-1}\, a.$$
Then
$$c_{k+1} = (ab)^{2^{k+1}-1}\, a\, b = (ab)^{2^{k+1}-1}\,(ab) = (ab)^{2^{k+1}}.$
$
Since $k+1$ is odd, this matches the claim. ✓

**Conclusion.** In all cases, $c_k$ is a $2^k$-th power of $ab$ or $ba$. Since $
G$ has exponent $2^n$:
$$c_n = (ab)^{2^n} \text{ or } (ba)^{2^n} = 1.$$

Therefore:
$$\boxed{[x^{2^{n-1}},\, \underbrace{y^{2^{n-1}},\, \ldots,\, y^{2^{n-1}}}_{n \t
ext{ copies}}] = 1.}$$

**Sharpness.** The result is tight: $c_{n-1}$ need not be $1$. In the dihedral g
roup $D_{2^n} = \langle r, s \mid r^{2^n}=s^2=1,\; srs=r^{-1}\rangle$ (exponent
$2^n$ for $n\ge 2$), take $a = s$, $b = rs$ (both involutions). Then $ab = r^{-1
}$ has order $2^n$, so $c_{n-1} = r^{\pm 2^{n-1}} \neq 1$, while $c_n = r^{\pm 2
^n} = 1$.
