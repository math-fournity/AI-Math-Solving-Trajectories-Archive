## Solution

**Model the cube as the graph $Q_3$ (3-dimensional hypercube).** Label each vert
ex by a binary triple $(x,y,z)\in\{0,1\}^3$. Two vertices are adjacent exactly w
hen they differ in one coordinate, so each move flips exactly one of the three c
oordinates.

**One hour = 60 minutes = 6 moves.** A journey returns to the start $(0,0,0)$ if
f every coordinate is flipped an even number of times. So we need $a+b+c=6$ with
 $a,b,c$ all even, where $a,b,c$ count flips of the three coordinates.

Writing $a=2a',\, b=2b',\, c=2c'$ gives $a'+b'+c'=3$ with $a',b',c'\ge 0$. For a
 fixed $(a,b,c)$ the number of move sequences is the multinomial $\dfrac{6!}{a!\
,b!\,c!}$.

Sum over all ordered triples $(a',b',c')$ with $a'+b'+c'=3$:

| $(a',b',c')$ type | arrangements | $\frac{6!}{a!\,b!\,c!}$ | contribution |
|---|---|---|---|
| $(3,0,0)$ | 3 | $\frac{6!}{6!0!0!}=1$ | $3$ |
| $(2,1,0)$ | 6 | $\frac{6!}{4!\,2!\,0!}=15$ | $90$ |
| $(1,1,1)$ | 1 | $\frac{6!}{2!\,2!\,2!}=90$ | $90$ |

$$N = 3 + 90 + 90 = 183.$$

**Verification via eigenvalues.** The hypercube $Q_3$ has adjacency eigenvalues
$3-2k$ with multiplicity $\binom{3}{k}$, i.e. $3$ (mult. 1), $1$ (mult. 3), $-1$
 (mult. 3), $-3$ (mult. 1). The number of closed walks of length 6 from a fixed
vertex is

$$\frac{1}{8}\sum_{\lambda}\lambda^{6}\,m_\lambda = \frac{1}{8}\bigl(3^6\cdot1 +
 1^6\cdot3 + (-1)^6\cdot3 + (-3)^6\cdot1\bigr) = \frac{729+3+3+729}{8} = \frac{1
464}{8}=183.$$

Both methods agree: $N=183$.

**Sum of squares of digits of $183$:**
$$1^2 + 8^2 + 3^2 = 1 + 64 + 9 = \boxed{74}.$$
