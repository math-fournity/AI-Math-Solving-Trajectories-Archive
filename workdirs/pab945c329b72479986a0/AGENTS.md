# Problem

In the high-security archives of a digital vault, a master security gate is controlled by a sequence of 10 binary switches, $(x_1, x_2, \dots, x_{10})$, where each switch can be set to either 0 (OFF) or 1 (ON). 

To grant access, the central computer evaluates a "Security Sum" based on the following protocol: 
It starts with a base value of 1. It then adds the value of the first switch. To this, it adds the product of the first two switches, then the product of the first three, and so on, continuing until it adds the product of all ten switches. 

The gate only unlocks if the final resulting sum is an odd number (which is equivalent to the sum being congruent to $1 \pmod 2$).

How many unique configurations of the 10 binary switches will successfully unlock the gate?
