## Proof

We seek an upper bound for
$$S = \sup_{a,b \in B(0,r)} \left|\frac{e^a - e^b}{a-b}\right|,$$
where $B(0,r) = \{z \in \mathbb{C} : |z| \le r\}$ is the closed disk of radius $
r$.

**Step 1: Integral representation of the difference quotient.**

For any $a, b \in \mathbb{C}$ with $a \neq b$, the exponential function is entir
e, so we may write
$$\frac{e^a - e^b}{a - b} = \int_0^1 e^{ta + (1-t)b}\,dt.$$
This follows from the identity $e^a - e^b = \int_0^1 \frac{d}{dt}e^{ta+(1-t)b}\,
dt = (a-b)\int_0^1 e^{ta+(1-t)b}\,dt$.

**Step 2: Bound the integrand using convexity.**

For $a, b \in B(0,r)$ and $t \in [0,1]$, the point $z_t = ta + (1-t)b$ is a conv
ex combination of $a$ and $b$. Since $B(0,r)$ is convex, $z_t \in B(0,r)$, hence
 $|z_t| \le r$, which gives
$$\operatorname{Re}(z_t) \le |z_t| \le r.$$
Therefore
$$\left|e^{ta+(1-t)b}\right| = e^{\operatorname{Re}(ta+(1-t)b)} \le e^r.$$

**Step 3: Apply the triangle inequality for integrals.**

$$\left|\frac{e^a - e^b}{a-b}\right| = \left|\int_0^1 e^{ta+(1-t)b}\,dt\right| \
le \int_0^1 \left|e^{ta+(1-t)b}\right|\,dt \le \int_0^1 e^r\,dt = e^r.$$

This holds for all $a \neq b$ in $B(0,r)$, so
$$S \le e^r.$$

**Step 4: The bound is sharp.**

Taking $a = r$ and $b = r - \varepsilon$ (both real, both in $B(0,r)$ for $\vare
psilon > 0$ small), we get
$$\frac{e^r - e^{r-\varepsilon}}{\varepsilon} \to e^r \quad \text{as } \varepsil
on \to 0^+.$$
Hence the supremum is in fact $e^r$ (attained in the limit, or exactly at $a = b
 = r$ if the quotient is interpreted as the derivative $e^a$).

**Conclusion.**

$$\boxed{\sup_{a,b \in B(0,r)} \left|\frac{e^a - e^b}{a-b}\right| = e^r}$$

so $e^r$ is a (sharp) upper bound.
