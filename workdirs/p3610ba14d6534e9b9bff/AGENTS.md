# Problem

In a circular high-security server facility, there are 100 access terminals arranged evenly around a central hub. Data transmissions are conducted via "network segments," which are defined as continuous circular arcs of fiber optic cable connecting any two of these terminals.

A security engineer manages a specific set of segments called the "Encryption Suite." This suite is governed by a strict redundancy protocol: for any segment $A$ within the suite, there is at most one other segment $B$ in the suite that strictly contains $A$ (meaning $B$ covers all terminals $A$ covers, plus at least one more terminal, without $A$ and $B$ being identical).

Within this suite, a segment is classified as "Primary" if it is not contained within any other segment in the suite. A segment is classified as "Secondary" if it is contained within at least one other segment in the suite.

If there are exactly 60 Primary segments in the Encryption Suite, what is the maximum possible number of Secondary segments that can exist in the suite?
