## Proof

### Step 1: Simplify using symmetry

Since $p_{n,k} = p_{n,n-k}$, the recurrence becomes:
$$f_n = t_n + \sum_{k=1}^{n-1} \frac{1}{(n-1)} \binom{n}{k} \frac{k^{k-1}(n-k)^{
n-k-1}}{n^{n-2}} f_k.$$

### Step 2: Verify $p_{n,k}$ is a probability distribution

The number of labeled trees on $[n]$ with a directed edge splitting into compone
nts of size $k$ and $n-k$ is $\binom{n}{k} k^{k-1}(n-k)^{n-k-1}$. Summing over a
ll $k$ counts every (tree, directed edge) pair exactly once: total $= 2(n-1)n^{n
-2}$. Hence $\sum_{k=1}^{n-1} p_{n,k} = 1$. ✓

### Step 3: Introduce normalized generating functions

Define the **tree function** $T(z) = \sum_{n\geq 1} \frac{n^{n-1}}{n!} z^n$, sat
isfying $T = ze^T$ (i.e., $T = -W(-z)$, the Lambert W function), with singularit
y at $z = 1/e$ where $T=1$.

Set:
$$G(z) = \sum_{n\geq 1} \frac{n^{n-1} f_n}{n!} z^n, \qquad \Tau(z) = \sum_{n\geq
 1} \frac{n^{n-1} t_n}{n!} z^n.$$

Then $g_n := [z^n]G = \frac{n^{n-1}f_n}{n!}$ and $\tau_n := [z^n]\Tau = \frac{n^
{n-1}t_n}{n!}$, so $f_n = \frac{n!\, g_n}{n^{n-1}}$.

### Step 4: Derive the convolution identity

Expanding $\binom{n}{k} = \frac{n!}{k!(n-k)!}$, the recurrence gives:
$$f_n = t_n + \frac{n!}{(n-1)\,n^{n-2}} \sum_{k=1}^{n-1} \frac{k^{k-1} f_k}{k!}
\cdot \frac{(n-k)^{n-k-1}}{(n-k)!}.$$

The inner sum is a **convolution**: $\sum_{k=1}^{n-1} g_k \cdot c_{n-k}$ where $
c_m = \frac{m^{m-1}}{m!} = [z^m]T(z)$. Thus:
$$\sum_{k=1}^{n-1} g_k \, c_{n-k} = [z^n]\bigl(T(z)\,G(z)\bigr).$$

Substituting and using $\frac{n!}{(n-1)n^{n-2}} \cdot \frac{n^{n-1}}{n!} = \frac
{n}{n-1}$:

$$\boxed{g_n = \tau_n + \frac{n}{n-1}\,[z^n]\bigl(T\cdot G\bigr), \qquad n \geq
2.}$$

### Step 5: Convert to an ODE

Multiply by $(n-1)$ and sum over $n \geq 2$:

$$(n-1)\,g_n = (n-1)\,\tau_n + n\,s_n, \qquad s_n := [z^n](TG).$$

Using $\sum_{n\geq 2}(n-1)g_n z^n = zG' - G$, $\sum_{n\geq 2}(n-1)\tau_n z^n = z
\Tau' - \Tau$, and $\sum_{n\geq 2} n\,s_n z^n = z(TG)'$ (since $s_1=0$):

$$zG' - G = z\Tau' - \Tau + z(T'G + TG').$$

Using $T' = \frac{T}{z(1-T)}$, so $zT' = \frac{T}{1-T}$ and $1 + zT' = \frac{1}{
1-T}$:

$$z(1-T)\,G' - \frac{G}{1-T} = z\Tau' - \Tau.$$

### Step 6: Change variable to $T$ and solve

With $z = Te^{-T}$ and $\frac{dz}{dT} = \frac{z(1-T)}{T}$, we have $G' = \frac{T
\,\dot{G}}{z(1-T)}$ (dot $= d/dT$). Substituting:

$$T(1-T)\,\dot{G} - G = T\dot{\Tau} + T\Tau - \Tau.$$

This is a first-order linear ODE: $\dot{G} - \frac{1}{T(1-T)}G = \frac{T\dot{\Ta
u}+T\Tau-\Tau}{T(1-T)}$.

**Integrating factor**: $\mu = e^{-\int \frac{dT}{T(1-T)}} = e^{-\ln(T/(1-T))} =
 \frac{1-T}{T}$.

Multiplying through:
$$\frac{d}{dT}\!\left[\frac{(1-T)\,G}{T}\right] = \frac{T\dot{\Tau}+T\Tau-\Tau}{
T^2} = \underbrace{\frac{\dot{\Tau}}{T} - \frac{\Tau}{T^2}}_{\displaystyle\frac{
d}{dT}\!\left[\frac{\Tau}{T}\right]} + \frac{\Tau}{T}.$$

Integrating from $0$ to $T$ (the constant vanishes since $G(0)=\Tau(0)=0$):

$$\frac{(1-T)\,G}{T} = \frac{\Tau}{T} + \int_0^T \frac{\Tau(u)}{u}\,du.$$

### Step 7: The generating function

$$\boxed{G(T) = \frac{\displaystyle\Tau(T) + T\!\int_0^T \frac{\Tau(u)}{u}\,du}{
1 - T}}$$

where $T = T(z)$ is the tree function, $\Tau(T(z)) = \sum_{n\geq 1}\frac{n^{n-1}
t_n}{n!}z^n$, and $G(T(z)) = \sum_{n\geq 1}\frac{n^{n-1}f_n}{n!}z^n$.

Equivalently, in the $z$-variable (via $u = T(w)$, $du = \frac{u\,dw}{w(1-u)}$):

$$G(z) = \frac{\displaystyle\Tau(z) + T(z)\!\int_0^z \frac{\Tau(w)}{w\,(1-T(w))}
\,dw}{1 - T(z)}.$$

### Step 8: Asymptotic behavior

The dominant singularity is at $z = 1/e$ where $T \to 1$. Near this point, $1 -
T(z) \sim \sqrt{2(1-ez)}$.

Assuming $\Tau(1) := \sum_{n\geq 1}\frac{n^{n-1}t_n}{n!}e^{-n}$ converges and $\
int_0^1 \frac{\Tau(u)}{u}\,du$ converges, define the constant:

$$\boxed{C \;=\; \Tau(1) + \int_0^1 \frac{\Tau(u)}{u}\,du \;=\; \sum_{n=1}^{\inf
ty}\frac{n^{n-1}\,t_n}{n!}\,e^{-n} \;+\; \sum_{n=1}^{\infty}\frac{t_n\;\gamma(n,
n)}{n\cdot n!}}$$

where $\gamma(n,n) = \int_0^n v^{n-1}e^{-v}\,dv$ is the lower incomplete gamma f
unction (obtained by termwise integration with the substitution $v=nu$).

Then as $T \to 1^-$:
$$G(T) \sim \frac{C}{1-T}, \qquad\text{so}\qquad G(z) \sim \frac{C}{\sqrt{2(1-ez
)}} = \frac{C}{\sqrt{2}}\,(1-ez)^{-1/2}.$$

By the **singularity analysis transfer theorem**:
$$g_n = [z^n]\,G(z) \;\sim\; \frac{C}{\sqrt{2}} \cdot \frac{e^n}{\sqrt{\pi n}} =
 \frac{C\,e^n}{\sqrt{2\pi n}}.$$

Recovering $f_n = \frac{n!}{n^{n-1}}\,g_n$ and applying Stirling's formula $n! \
sim \sqrt{2\pi n}\,(n/e)^n$:

$$f_n \;\sim\; \frac{\sqrt{2\pi n}\,(n/e)^n}{n^{n-1}} \cdot \frac{C\,e^n}{\sqrt{
2\pi n}} \;=\; \sqrt{2\pi}\,n^{3/2}\,e^{-n} \cdot \frac{C\,e^n}{\sqrt{2\pi n}} \
;=\; C\,n.$$

$$\boxed{f_n \;\sim\; C\,n \quad\text{as } n\to\infty, \qquad C = \Tau(1) + \int
_0^1 \frac{\Tau(u)}{u}\,du.}$$

### Verification (sanity check)

For $t_n = 1$: $\Tau(T) = \sum \frac{n^{n-1}}{n!}(Te^{-T})^n = T(z) = T$, so $G
= \frac{T + T\cdot T}{1-T} = \frac{T(1+T)}{1-T}$, giving $C = \Tau(1) + \int_0^1
 1\,du = 1 + 1 = 2$, hence $f_n \sim 2n$. Direct computation: $f_1=1, f_2=3, f_3
=5, f_4=8.5$, with $f_n/n \to 2$. ✓
