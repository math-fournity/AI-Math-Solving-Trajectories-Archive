## Proof

Let $G$ be a $p$-group of order $p^4$ with $|Z(G)| = p^2$.

**Step 1: Structure of $G/Z(G)$.**

Since $|G/Z(G)| = p^4/p^2 = p^2$ and $G/Z(G)$ cannot be cyclic (a group with cyc
lic central quotient is abelian), we have $G/Z(G) \cong C_p \times C_p$. In part
icular, $G' \leq Z(G)$, so $G$ has nilpotency class $2$.

**Step 2: $G'$ is cyclic of order $p$.**

Let $\bar{x}, \bar{y}$ be an $\mathbb{F}_p$-basis of $G/Z(G)$ with lifts $x, y \
in G$. Since $G = \langle x, y\rangle \cdot Z(G)$ and $Z(G)$ is central, every c
ommutator in $G$ takes the form
$$[x^a y^b z_1,\; x^c y^d z_2] = [x^a y^b,\; x^c y^d] = [x,y]^{ad-bc},$$
using the bilinearity of the commutator in a class-$2$ group. Hence $G' = \langl
e [x,y]\rangle$ is cyclic.

Since $\bar{x}$ has order $p$ in $G/Z(G)$, we have $x^p \in Z(G)$. Using the cla
ss-$2$ identity $[x,y]^p = [x^p, y]$ and $x^p \in Z(G)$:
$$[x,y]^p = [x^p, y] = 1.$$
Therefore $|[x,y]|$ divides $p$, so $|G'| \leq p$. Since $G$ is non-abelian, $|G
'| \geq p$. Thus
$$|G'| = p.$$

**Step 3: Conjugacy class sizes.**

The $|Z(G)| = p^2$ central elements each form a singleton conjugacy class.

For any $g \in G$, the conjugacy class of $g$ is $\{h^{-1}gh : h \in G\} = \{g\c
dot [h,g] : h \in G\}$. In a class-$2$ group, the map $h \mapsto [h,g]$ is a hom
omorphism $G \to G'$, so its image $[G,g]$ is a subgroup of $G'$. The class size
 equals $|[G,g]|$, which divides $|G'| = p$.

For non-central $g$, $[G,g] \neq 1$, so $|[G,g]| = p$. Thus **every non-central
conjugacy class has size $p$**.

**Step 4: Count conjugacy classes.**

By the class equation:
$$|G| = |Z(G)| + a \cdot p,$$
where $a$ is the number of non-central conjugacy classes. Substituting:
$$p^4 = p^2 + a \cdot p \implies a = \frac{p^4 - p^2}{p} = p^3 - p.$$

The total number of conjugacy classes is:
$$k(G) = |Z(G)| + a = p^2 + (p^3 - p) = p^3 + p^2 - p.$$

**Verification via character theory.** The number of linear characters is $|G/G'
| = p^4/p = p^3$. The remaining $k(G) - p^3 = p^2 - p$ irreducible characters ar
e nonlinear, each of degree $p$ (since $|[G,g]| = p$ for non-central $g$). The s
um-of-squares check gives:
$$p^3 \cdot 1^2 + (p^2 - p)\cdot p^2 = p^3 + p^4 - p^3 = p^4 = |G|. \quad \check
mark$$

**Conclusion.** The number of conjugacy classes of $G$ is $\boxed{p^3 + p^2 - p}
$.
