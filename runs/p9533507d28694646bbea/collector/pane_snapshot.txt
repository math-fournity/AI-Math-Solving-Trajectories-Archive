## Proof

We need to evaluate:

$$\delta = \arccos\!\Big((\sin 2539^\circ+\sin 2540^\circ+\cdots+\sin 6139^\circ
)^{\cos 2520^\circ}+\cos 2521^\circ+\cos 2522^\circ+\cdots+\cos 6120^\circ\Big)$
$

### Step 1: The exponent $\cos 2520^\circ$

Since $2520 = 7\times 360$, we have $\cos 2520^\circ = \cos 0^\circ = 1$.

Therefore the power is $1$, and the base is unchanged:

$$\delta = \arccos\!\Big(\underbrace{\sin 2539^\circ+\cdots+\sin 6139^\circ}_{A}
+\underbrace{\cos 2521^\circ+\cdots+\cos 6120^\circ}_{B}\Big)$$

### Step 2: Compute $A = \sum_{k=2539}^{6139}\sin k^\circ$

Using the identity $\displaystyle\sum_{k=0}^{N-1}\sin\big((a+k)x\big)=\frac{\sin
(Nx/2)\,\sin\!\big(a+(N-1)x/2\big)}{\sin(x/2)}$ with $a=2539$, $N=3601$, $x=1^\c
irc$:

$$A=\frac{\sin(1800.5^\circ)\,\sin(4339^\circ)}{\sin(0.5^\circ)}$$

- $1800.5 = 5\times 360 + 0.5$, so $\sin(1800.5^\circ)=\sin(0.5^\circ)$.
- $4339 = 12\times 360 + 19$, so $\sin(4339^\circ)=\sin(19^\circ)$.

$$A=\frac{\sin(0.5^\circ)\,\sin(19^\circ)}{\sin(0.5^\circ)}=\sin 19^\circ$$

### Step 3: Compute $B = \sum_{k=2521}^{6120}\cos k^\circ$

Using $\displaystyle\sum_{k=0}^{N-1}\cos\big((a+k)x\big)=\frac{\sin(Nx/2)\,\cos\
!\big(a+(N-1)x/2\big)}{\sin(x/2)}$ with $a=2521$, $N=3600$, $x=1^\circ$:

$$B=\frac{\sin(1800^\circ)\,\cos(4320.5^\circ)}{\sin(0.5^\circ)}$$

- $1800 = 5\times 360$, so $\sin(1800^\circ)=\sin 0^\circ=0$.

$$B=0$$

### Step 4: Combine

$$\delta=\arccos\!\big(\sin 19^\circ + 0\big)=\arccos(\sin 19^\circ)$$

Since $\sin 19^\circ = \cos(90^\circ-19^\circ)=\cos 71^\circ$, and $71^\circ\in[
0^\circ,180^\circ]$ (the range of $\arccos$):

$$\delta=\arccos(\cos 71^\circ)=71^\circ$$

### Answer

$$\boxed{\delta = 71^\circ}$$
