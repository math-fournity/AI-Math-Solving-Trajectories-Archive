## Proof

**Claim:** $(1-\theta)^{-1} = \theta + \theta^3 + \theta^5 + \cdots + \theta^{m-
2} = \displaystyle\sum_{j=0}^{(m-3)/2} \theta^{2j+1}$, with all coefficients $a_
{2j+1}=1$ for $j=0,\ldots,\tfrac{m-3}{2}$ and all other $a_i = 0$.

**Verification.** We show $(1-\theta)\displaystyle\sum_{j=0}^{(m-3)/2}\theta^{2j
+1} = 1$ in $\mathbb{Z}[\theta]$.

**Step 1: Expand the product.**

$$(1-\theta)\sum_{j=0}^{(m-3)/2}\theta^{2j+1} = \sum_{j=0}^{(m-3)/2}\theta^{2j+1
} - \sum_{j=0}^{(m-3)/2}\theta^{2j+2}$$

$$= (\theta + \theta^3 + \cdots + \theta^{m-2}) - (\theta^2 + \theta^4 + \cdots
+ \theta^{m-1}) = \sum_{k=1}^{m-1}(-1)^{k+1}\theta^k.$$

**Step 2: Relate to a geometric sum.**

Note that $\displaystyle\sum_{k=1}^{m-1}(-1)^{k+1}\theta^k = -\sum_{k=1}^{m-1}(-
\theta)^k = 1 - \sum_{k=0}^{m-1}(-\theta)^k$.

So it suffices to show $\displaystyle\sum_{k=0}^{m-1}(-\theta)^k = 0$ in $\mathb
b{Z}[\theta]$.

**Step 3: Evaluate $(-\theta)^m$.**

Since $\theta = e^{2\pi i/(2m)}$, we have $\theta^m = e^{\pi i} = -1$. Since $m$
 is odd:

$$(-\theta)^m = (-1)^m \theta^m = (-1)(-1) = 1.$$

Also $-\theta \neq 1$ (since $\theta \neq -1$, which would require $m=1$, exclud
ed). Therefore the finite geometric series gives:

$$\sum_{k=0}^{m-1}(-\theta)^k = \frac{1 - (-\theta)^m}{1 - (-\theta)} = \frac{1
- 1}{1+\theta} = 0.$$

**Step 4: Confirm this is valid in $\mathbb{Z}[\theta]$ (i.e., $\Phi_n(x) \mid \
sum_{k=0}^{m-1}(-x)^k$).**

For odd $m$, $\displaystyle\sum_{k=0}^{m-1}(-x)^k = \frac{1+x^m}{1+x}$. Since $m
$ is odd, $x^m+1 = \prod_{d\mid m}\Phi_{2d}(x)$ (the divisors of $2m$ not dividi
ng $m$ are exactly $\{2d : d\mid m\}$). Dividing by $\Phi_2(x) = x+1$ (correspon
ding to $d=1$):

$$\frac{1+x^m}{1+x} = \prod_{\substack{d\mid m\\ d>1}} \Phi_{2d}(x).$$

Since $m>1$, taking $d=m$ shows $\Phi_{2m}(x) = \Phi_n(x)$ is a factor. Hence $\
Phi_n(\theta)=0$ implies $\displaystyle\sum_{k=0}^{m-1}(-\theta)^k = 0$.

**Step 5: Conclude.**

From Step 2 and Step 4: $\displaystyle\sum_{k=1}^{m-1}(-1)^{k+1}\theta^k = 1 - 0
 = 1$.

Combining with Step 1:

$$(1-\theta)\left(\theta + \theta^3 + \theta^5 + \cdots + \theta^{m-2}\right) =
1.$$

Therefore:

$$\boxed{(1-\theta)^{-1} = \theta + \theta^3 + \theta^5 + \cdots + \theta^{m-2}
= \sum_{j=0}^{(m-3)/2}\theta^{2j+1}}$$

The integer coefficients are $a_{2j+1} = 1$ for $j = 0, 1, \ldots, \frac{m-3}{2}
$ (i.e., $a_1 = a_3 = \cdots = a_{m-2} = 1$), and all other $a_i = 0$.
