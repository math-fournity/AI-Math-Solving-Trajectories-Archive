## 证明

设 $\angle A = \alpha$，$\angle B = 2\beta$，$\angle C = \gamma$，因此 $\alpha +
 2\beta + \gamma = \pi$。设 $AB = c$，$BC = a$。根据正弦定理，$a = 2R\sin\alpha$
，$c = 2R\sin\gamma$。

**坐标系。** 将 $B$ 置于原点，$\angle B$ 的内角平分线方向沿 $x$ 轴正方向。则：
$$A = (c\cos\beta,\, c\sin\beta), \qquad C = (a\cos\beta,\, -a\sin\beta).$$

**点 $L$ 及其平分点 $M$。** 根据角平分线定理，$AL:LC = c:a$，因此：
$$L = \frac{aA + cC}{a+c} = \left(\frac{2ac\cos\beta}{a+c},\, 0\right), \qquad M
 = \left(\frac{ac\cos\beta}{a+c},\, 0\right).$$

**点 $D$ 与射线 $BD$ 的方向。** $D$ 是不包含 $C$ 的弧 $AB$ 的中点，因此弧 $AD$
的度数为 $\gamma$。圆周角 $\angle ABD = \gamma/2$，且 $D$ 位于直线 $AB$ 上 $C$
的对侧，因此射线 $BD$ 与 $x$ 轴正方向的夹角为 $\beta + \gamma/2$。

**点 $P$。** 由于 $\angle APB = 90°$，点 $P$ 位于以 $AB$ 为直径的圆上。在射线 $B
D$ 上设 $P = t(\cos(\beta+\gamma/2),\, \sin(\beta+\gamma/2))$，代入直径为 $AB$
的圆方程可得：
$$t^2 - ct\cos(\gamma/2) = 0 \implies t = c\cos(\gamma/2).$$
（由于 $\gamma < \pi/2$，$t > BD$，确认 $P$ 在 $D$ 之外。）因此：
$$P = c\cos\tfrac{\gamma}{2}\left(\cos\!\left(\beta+\tfrac{\gamma}{2}\right),\;
\sin\!\left(\beta+\tfrac{\gamma}{2}\right)\right).$$

**点 $Q$。** 同理，射线 $BE$ 与 $x$ 轴的夹角为 $-\beta - \alpha/2$，且 $\angle C
QB = 90°$ 得到 $Q$ 在以 $BC$ 为直径的圆上，因此 $s = a\cos(\alpha/2)$：
$$Q = a\cos\tfrac{\alpha}{2}\left(\cos\!\left(\beta+\tfrac{\alpha}{2}\right),\;
-\sin\!\left(\beta+\tfrac{\alpha}{2}\right)\right).$$

**共线条件。** 点 $M = (M_x, 0)$ 在 $PQ$ 上当且仅当 $P_y(M_x - Q_x) = Q_y(M_x -
P_x)$，即：
$$\frac{P_y}{Q_y} = \frac{M_x - P_x}{M_x - Q_x}.$$

**左边。** 利用积化和差公式：
$$\cos\tfrac{\gamma}{2}\sin\!\left(\beta+\tfrac{\gamma}{2}\right) = \tfrac{1}{2}
[\sin(\beta+\gamma)+\sin\beta], \qquad \cos\tfrac{\alpha}{2}\sin\!\left(\beta+\t
frac{\alpha}{2}\right) = \tfrac{1}{2}[\sin(\beta+\alpha)+\sin\beta].$$
由于 $\beta + \gamma = \pi - \alpha - \beta$，我们得到 $\sin(\beta+\gamma) = \si
n(\alpha+\beta)$，因此这两个乘积相等。由此可得：
$$\frac{P_y}{Q_y} = -\frac{c\cos(\gamma/2)\sin(\beta+\gamma/2)}{a\cos(\alpha/2)\
sin(\beta+\alpha/2)} = -\frac{c}{a}.$$

**右边。** 利用 $\cos\frac{\gamma}{2}\cos(\beta+\frac{\gamma}{2}) = \frac{1}{2}[
\cos\beta - \cos(\alpha+\beta)]$ 和 $\cos\frac{\alpha}{2}\cos(\beta+\frac{\alpha
}{2}) = \frac{1}{2}[\cos\beta + \cos(\alpha+\beta)]$（因为 $\cos(\beta+\gamma) =
 -\cos(\alpha+\beta)$），以及 $a = 2R\sin\alpha$，$c = 2R\sin\gamma$：
$$M_x - P_x = R\sin\gamma\cdot\frac{(\sin\alpha-\sin\gamma)\cos\beta + (\sin\alp
ha+\sin\gamma)\cos(\alpha+\beta)}{\sin\alpha+\sin\gamma},$$
$$M_x - Q_x = -R\sin\alpha\cdot\frac{(\sin\alpha-\sin\gamma)\cos\beta + (\sin\al
pha+\sin\gamma)\cos(\alpha+\beta)}{\sin\alpha+\sin\gamma}.$$
括号内的表达式相同且可约去，得到：
$$\frac{M_x - P_x}{M_x - Q_x} = -\frac{\sin\gamma}{\sin\alpha} = -\frac{c}{a}.$$

**结论。** 两边均等于 $-c/a$，确认 $M$ 在直线 $PQ$ 上。$\blacksquare$
