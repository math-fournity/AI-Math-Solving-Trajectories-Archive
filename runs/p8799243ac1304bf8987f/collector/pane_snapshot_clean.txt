# Solution

**Key observation:** $22499 = 149 \times 151$. Let $a = 149$, $b = 151$, so $ab
= 22499$ and we seek $\left\lfloor \frac{a^{151}+b^{149}}{ab}\right\rfloor \bmod
 10^4$.

## Strategy

Let $N = a^{151}+b^{149}$, $q = \lfloor N/ab \rfloor$, $r = N \bmod ab$. Then $q
 = (N-r)/ab$, and $q \bmod 10^4$ is determined by $N \bmod (ab \cdot 10^4) = N \
bmod 224990000$.

Factor: $224990000 = 149 \times 151 \times 16 \times 625$ (pairwise coprime). Co
mpute $N$ modulo each factor via CRT.

## Computing $N$ modulo each factor

**Mod 149:** $a^{151}\equiv 0$, $b^{149}\equiv 2^{149}\pmod{149}$. By Fermat, $2
^{148}\equiv 1$, so $2^{149}\equiv 2$. Thus $N\equiv 2\pmod{149}$.

**Mod 151:** $a^{151}\equiv (-2)^{151}=-2^{151}\pmod{151}$, $b^{149}\equiv 0$. B
y Fermat, $2^{150}\equiv 1$, so $2^{151}\equiv 2$, giving $-2^{151}\equiv -2\equ
iv 149\pmod{151}$. Thus $N\equiv 149\pmod{151}$.

**Mod 16:** $a\equiv 5$, $b\equiv 7\pmod{16}$. Since $5^4\equiv 1$ and $151=4\cd
ot37+3$, $5^{151}\equiv 5^3\equiv 13$. Since $7^2\equiv 1$ and $149=2\cdot74+1$,
 $7^{149}\equiv 7$. Thus $N\equiv 13+7=20\equiv 4\pmod{16}$.

**Mod 625:** Repeated squaring gives:

For $149^{151}\bmod 625$: $149^2\equiv 326$, $149^4\equiv 26$, $149^8\equiv 51$,
 $149^{16}\equiv 101$, $149^{32}\equiv 201$, $149^{64}\equiv 401$, $149^{128}\eq
uiv 176$. Since $151=128+16+4+2+1$:
$$176\times101\equiv 276,\quad 276\times26\equiv 301,\quad 301\times326\equiv 1,
\quad 1\times149\equiv 149\pmod{625}.$$
So $149^{151}\equiv 149\pmod{625}$.

For $151^{149}\bmod 625$: $151^2\equiv 301$, $151^4\equiv 601$, $151^8\equiv 576
$, $151^{16}\equiv 526$, $151^{32}\equiv 426$, $151^{64}\equiv 226$, $151^{128}\
equiv 451$. Since $149=128+16+4+1$:
$$451\times526\equiv 351,\quad 351\times601\equiv 326,\quad 326\times151\equiv 4
76\pmod{625}.$$
So $151^{149}\equiv 476\pmod{625}$.

Thus $N\equiv 149+476=625\equiv 0\pmod{625}$.

## CRT reconstruction

**Combine mod 625 and mod 16:** $N=625k$, $625k\equiv 4\pmod{16}$. Since $625\eq
uiv 1\pmod{16}$, $k\equiv 4\pmod{16}$. So $N\equiv 2500\pmod{10000}$.

**Combine with mod 149:** $N=10000j+2500$, $17j+116\equiv 2\pmod{149}$, so $17j\
equiv 35\pmod{149}$. Since $17^{-1}\equiv 114\pmod{149}$ (check: $17\times114=19
38=149\times13+1$), $j\equiv 35\times114\equiv 116\pmod{149}$. So $N\equiv 11625
00\pmod{1490000}$.

**Combine with mod 151:** $N=1490000n+1162500$, $83n+102\equiv 149\pmod{151}$, s
o $83n\equiv 47\pmod{151}$. Since $83^{-1}\equiv 131\pmod{151}$ (check: $83\time
s131=10873=151\times72+1$), $n\equiv 47\times131\equiv 117\pmod{151}$.

So $N\equiv 1490000\times117+1162500=174330000+1162500=175492500\pmod{224990000}

## Final computation

**Residue:** $r = 175492500 \bmod 22499$. Since $22499\times7800=175492200$, we
get $r=300$.

**Verification of $r$:** $300\equiv 2\pmod{149}$ ✓, $300\equiv 149\pmod{151}$ ✓.

**Quotient:** $q = (175492500-300)/22499 = 175492200/22499 = 7800$.

Since $N = 224990000\cdot k + 175492500$, we have $q = 10000k + 7800$, so:

$$q \bmod 10^4 = \boxed{7800}$$
