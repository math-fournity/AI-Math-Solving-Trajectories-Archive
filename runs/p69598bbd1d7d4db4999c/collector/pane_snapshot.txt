**Answer: Yes, the statement is true.**

**Proof.** Let $X$ be a normed linear space, $C \subseteq X$ compact and convex,
 and $V$ an open set with $C \subseteq V$.

**Step 1: The distance from $C$ to $V^c$ is strictly positive.**

Since $V$ is open, $V^c$ is closed, and $C \cap V^c = \emptyset$. Consider the c
ontinuous function $f : X \to \mathbb{R}$ defined by $f(x) = \operatorname{dist}
(x, V^c) = \inf_{y \in V^c} \|x - y\|$. This function is $1$-Lipschitz (hence co
ntinuous). For each $x \in C$, since $x \in V$ and $V$ is open, there is an open
 ball around $x$ contained in $V$, so $f(x) > 0$.

Since $C$ is compact and $f$ is continuous, $f$ attains its minimum on $C$: ther
e exists $x_0 \in C$ with $f(x_0) = \min_{x \in C} f(x)$. As $f(x_0) > 0$, we co
nclude
$$\delta := \operatorname{dist}(C, V^c) = \inf_{x \in C} f(x) = f(x_0) > 0.$$

**Step 2: Construct the convex open set $U$.**

Set $\varepsilon = \delta / 2 > 0$ and define
$$U := C + B(0, \varepsilon) = \{c + b : c \in C,\; \|b\| < \varepsilon\} = \big
cup_{c \in C} B(c, \varepsilon).$$

- **$U$ is open:** It is a union of open balls $B(c, \varepsilon)$.

- **$U$ is convex:** $C$ is convex and $B(0, \varepsilon)$ is convex. The Minkow
ski sum of two convex sets is convex: if $u_1 = c_1 + b_1$ and $u_2 = c_2 + b_2$
 with $c_i \in C$, $b_i \in B(0,\varepsilon)$, and $\lambda \in [0,1]$, then
$$\lambda u_1 + (1-\lambda) u_2 = \underbrace{(\lambda c_1 + (1-\lambda) c_2)}_{
\in\, C} + \underbrace{(\lambda b_1 + (1-\lambda) b_2)}_{\in\, B(0,\varepsilon)}
 \in U.$$

- **$C \subseteq U$:** For any $c \in C$, $c = c + 0 \in U$.

- **$U \subseteq V$:** Suppose for contradiction that some $u = c + b \in U$ (wi
th $c \in C$, $\|b\| < \varepsilon$) satisfies $u \notin V$, i.e., $u \in V^c$.
Then
$$\|c - u\| = \|b\| < \varepsilon = \frac{\delta}{2} < \delta = \operatorname{di
st}(C, V^c),$$
which contradicts the definition of $\delta$ as the infimum of $\|x - y\|$ over
$x \in C$, $y \in V^c$. Hence $U \subseteq V$.

**Conclusion.** For every open set $V$ containing the compact convex set $C$, th
e set $U = C + B(0, \varepsilon)$ with $\varepsilon = \frac{1}{2}\operatorname{d
ist}(C, V^c) > 0$ is a convex open set satisfying $C \subseteq U \subseteq V$. $
\blacksquare$
