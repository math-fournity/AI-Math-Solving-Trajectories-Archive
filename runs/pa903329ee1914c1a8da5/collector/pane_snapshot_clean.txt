## Proof

We compute the torsion subgroup of $E(\mathbb{Q})$ for $E: Y^2 = X^3 + 2$ using
the Nagell–Lutz theorem.

**Setup.** The curve is $Y^2 = X^3 + aX + b$ with $a = 0$, $b = 2$, both integer
s. The discriminant is
$$\Delta = -16(4a^3 + 27b^2) = -16(0 + 27\cdot 4) = -16\cdot 108 = -1728 \neq 0,
$$
so the curve is nonsingular and Nagell–Lutz applies.

**Nagell–Lutz theorem (applicable form).** If $P = (x,y)$ is a rational torsion
point with $y \neq 0$, then $x, y \in \mathbb{Z}$ and $y^2 \mid \Delta$, i.e. $y
^2 \mid 1728$.

**Step 1: Rational 2-torsion.** A 2-torsion point satisfies $y = 0$, so $x^3 = -
2$. This has no rational solution, hence $E(\mathbb{Q})$ has no nontrivial ratio
nal 2-torsion.

**Step 2: Candidate torsion points with $y \neq 0$.** We need $x,y \in \mathbb{Z
}$ with $y^2 = x^3 + 2$ and $y^2 \mid 1728 = 2^6 \cdot 3^3$. The square divisors
 of $1728$ are $2^i 3^j$ with $i \in \{0,2,4,6\}$, $j \in \{0,2\}$, giving
$$y^2 \in \{1,\, 4,\, 16,\, 64,\, 9,\, 36,\, 144,\, 576\}, \quad |y| \in \{1,2,4
,8,3,6,12,24\}.$$
Since $x^3 = y^2 - 2 \le 576 - 2 = 574$, we have $x \le 8$; and $x^3 = y^2 - 2 \
ge 1 - 2 = -1$ gives $x \ge -1$ (since $x = -2$ would give $x^3 = -8 < -1$, impo
ssible). So we check $x \in \{-1,0,1,\dots,8\}$:

| $x$ | $x^3+2$ | perfect square? |
|-----|---------|-----------------|
| $-1$ | $1$ | yes, $y=\pm 1$ |
| $0$ | $2$ | no |
| $1$ | $3$ | no |
| $2$ | $10$ | no |
| $3$ | $29$ | no |
| $4$ | $66$ | no |
| $5$ | $127$ | no |
| $6$ | $218$ | no |
| $7$ | $345$ | no |
| $8$ | $514$ | no |

The only integral points with $y^2 \mid 1728$ are $(-1, 1)$ and $(-1, -1)$.

**Step 3: Test whether $(-1,\pm 1)$ is torsion.** Let $P = (-1, 1)$. If $P$ were
 torsion of order $> 2$, then $2P$ would also be a torsion point with $y \neq 0$
, hence by Nagell–Lutz $2P$ would have integer coordinates. Compute $2P$ using t
he doubling formula:
$$m = \frac{3x^2 + a}{2y} = \frac{3\cdot 1 + 0}{2\cdot 1} = \frac{3}{2},$$
$$x(2P) = m^2 - 2x = \frac{9}{4} - 2(-1) = \frac{9}{4} + 2 = \frac{17}{4},$$
$$y(2P) = -m(x(2P) - x) - y = -\frac{3}{2}\!\left(\frac{17}{4}+1\right) - 1 = -\
frac{3}{2}\cdot\frac{21}{4} - 1 = -\frac{63}{8} - 1 = -\frac{71}{8}.$$
Thus $2P = (17/4,\, -71/8)$, which has **non-integral** coordinates. By the cont
rapositive of Nagell–Lutz, $P$ is **not** a torsion point. Since $(-1,-1) = -P$,
 it is not torsion either.

**Step 4: Conclusion.** The only rational point satisfying the Nagell–Lutz neces
sary condition for torsion (besides the point at infinity) fails the torsion tes
t. The point at infinity $\mathcal{O}$ is always torsion (the identity). Therefo
re the torsion subgroup consists solely of the identity:

$$\operatorname{Tor} E(\mathbb{Q}) = \{\mathcal{O}\}.$$

The torsion subgroup of $E(\mathbb{Q})$ is **trivial**.
