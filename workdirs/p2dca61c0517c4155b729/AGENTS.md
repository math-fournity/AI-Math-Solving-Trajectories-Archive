# Problem

In a specialized logistics warehouse, there are $n = 6$ heavy crates labeled with unique identification numbers from 1 to 6. These crates are currently stacked in a single vertical column in a completely random order.

A robotic crane is programmed to reorganize the stack. In a single operation (one "turn"), the crane must lift the crate currently at the very top of the stack and slide it into any position within the column (top, bottom, or anywhere between existing crates). The objective is to rearrange the stack so that the crates are in perfect numerical order, with crate 1 at the top and crate 6 at the bottom.

Assuming the initial random configuration of the crates is known before the crane begins its work, let $E$ represent the expected value of the minimum number of turns required to achieve the sorted order.

Find the value of $6! \times E$.
