## Solution

**Setup.** Let $a$ be a 3-digit code, $a = 100x + 10y + z$ with $x \in \{1,\dots
,9\}$, $y,z \in \{0,\dots,9\}$. The Digit Flux is the digit sum $S(a) = x+y+z$.
We seek codes with $S(a) = S(2a)$.

**Key identity.** When doubling $a$ digit by digit, let $c_1, c_2, c_3$ be the c
arries out of the units, tens, and hundreds positions respectively. A standard r
esult gives:
$$S(2a) = 2\,S(a) - 9\,(c_1+c_2+c_3).$$
Setting $S(a)=S(2a)$ yields $S(a) = 9c$ where $c = c_1+c_2+c_3$.

**Carry structure.** Since each digit is at most 9, each carry is 0 or 1:
- $c_1 = 1 \iff z \geq 5$
- $c_2 = 1 \iff 2y + c_1 \geq 10 \iff y \geq 5$ (checking: if $c_1=0$, need $y\g
eq5$; if $c_1=1$, need $2y+1\geq10$, i.e. $y\geq5$)
- $c_3 = 1 \iff 2x + c_2 \geq 10 \iff x \geq 5$ (same reasoning)

So each carry depends only on whether the corresponding digit is $\geq 5$, indep
endently. We enumerate by $c \in \{0,1,2,3\}$.

**Case $c=0$:** All digits $\leq 4$, need $S(a)=0$, but $x\geq1$. **0 solutions.
**

**Case $c=1$:** Exactly one digit $\geq 5$, need $S(a)=9$.

*Sub-case $z\geq5,\, y\leq4,\, x\leq4$:* $z=9-x-y\in\{5,\dots,9\}$ requires $x+y
\leq4$. Counts: $x=1\to4,\; x=2\to3,\; x=3\to2,\; x=4\to1$. **Total: 10.**

*Sub-case $z\leq4,\, y\geq5,\, x\leq4$:* $z=9-x-y\in\{0,\dots,4\}$ requires $5\l
eq x+y\leq9$. Counts: $x=1\to4,\; x=2\to3,\; x=3\to2,\; x=4\to1$. **Total: 10.**

*Sub-case $z\leq4,\, y\leq4,\, x\geq5$:* $z=9-x-y\in\{0,\dots,4\}$ requires $5\l
eq x+y\leq9$. Counts: $x=5\to5,\; x=6\to4,\; x=7\to3,\; x=8\to2,\; x=9\to1$. **T
otal: 15.**

**Case $c=1$ total: 35.**

**Case $c=2$:** Exactly two digits $\geq 5$, need $S(a)=18$.

*Sub-case $z\geq5,\, y\geq5,\, x\leq4$:* $y+z=18-x$. Counts: $x=1\to2,\; x=2\to3
,\; x=3\to4,\; x=4\to5$. **Total: 14.**

*Sub-case $z\geq5,\, y\leq4,\, x\geq5$:* $x+z=18-y$. Counts: $y=0\to1,\; y=1\to2
,\; y=2\to3,\; y=3\to4,\; y=4\to5$. **Total: 15.**

*Sub-case $z\leq4,\, y\geq5,\, x\geq5$:* $x+y=18-z$. Counts: $z=0\to1,\; z=1\to2
,\; z=2\to3,\; z=3\to4,\; z=4\to5$. **Total: 15.**

**Case $c=2$ total: 44.**

**Case $c=3$:** All digits $\geq 5$, need $S(a)=27$. Only $x=y=z=9$ (i.e., $a=99
9$, $2a=1998$, $S=27$). **1 solution.**

**Verification of samples:**
- $a=108$: $S=9$, $2a=216$, $S=9$. ✓ ($c_1=1,c_2=0,c_3=0$, $c=1$, $9=9\cdot1$)
- $a=189$: $S=18$, $2a=378$, $S=18$. ✓ ($c_1=1,c_2=1,c_3=0$, $c=2$, $18=9\cdot2$
)
- $a=999$: $S=27$, $2a=1998$, $S=27$. ✓ ($c=3$, $27=9\cdot3$)

**Grand total:** $35 + 44 + 1 = \boxed{80}$.
