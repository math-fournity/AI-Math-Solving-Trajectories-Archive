## Proof

**Claim.** For every fixed natural number $n$, there are infinitely many pairs o
f primes $(p, q)$ with $p > q$ such that $n \mid (p - q)$. Equivalently, the set
 $\{n, 2n, 3n, \ldots\}$ contains infinitely many prime differences.

**Case $n = 1$.** Every positive integer is a multiple of $1$. Since there are i
nfinitely many primes, taking any two distinct primes $p > q$ gives $p - q \in \
{1, 2, 3, \ldots\} = \{1\cdot k : k \geq 1\}$. There are infinitely many such pa
irs. ✓

**Case $n \geq 2$.** We use **Dirichlet's theorem on primes in arithmetic progre
ssions**:

> *Dirichlet's Theorem.* If $\gcd(a, m) = 1$, then the arithmetic progression $a
, a+m, a+2m, \ldots$ contains infinitely many primes.

Take $a = 1$ and $m = n$. Since $\gcd(1, n) = 1$, Dirichlet's theorem guarantees
 that there are infinitely many primes $p$ with
$$p \equiv 1 \pmod{n}.$$

Let $\mathcal{P}_n = \{p \text{ prime} : p \equiv 1 \pmod{n}\}$. By Dirichlet, $
\mathcal{P}_n$ is infinite; enumerate it as $p_1 < p_2 < p_3 < \cdots$.

For every $i > j \geq 1$, both $p_i \equiv 1 \pmod{n}$ and $p_j \equiv 1 \pmod{n
}$, so
$$p_i - p_j \equiv 1 - 1 \equiv 0 \pmod{n}.$$

Since $p_i > p_j$, the difference $p_i - p_j$ is a **positive** multiple of $n$,
 i.e.,
$$p_i - p_j \in \{n, 2n, 3n, \ldots\}.$$

There are infinitely many such pairs $(p_i, p_j)$ with $i > j$ (for instance, th
e pairs $(p_{k+1}, p_k)$ for $k = 1, 2, 3, \ldots$ are all distinct and each yie
lds a positive multiple of $n$). Moreover, the differences $p_{k+1} - p_k$ need
not be distinct, but even if some coincide, the set of primes $\mathcal{P}_n$ is
 infinite, so the collection of pairs is infinite, and the set of differences ac
hieved is infinite as well: indeed, fix $p_1$ and let $p_i \to \infty$ through $
\mathcal{P}_n$; then $p_i - p_1 \to \infty$, giving infinitely many distinct mul
tiples of $n$ realized as prime differences.

**Conclusion.** In both cases, the set $\{n, 2n, 3n, \ldots\}$ contains infinite
ly many differences between prime numbers. $\blacksquare$

**Remark.** The argument only requires that *some* residue class $a \pmod{n}$ wi
th $\gcd(a,n)=1$ contain infinitely many primes — which is exactly what Dirichle
t's theorem provides. The choice $a=1$ is merely convenient; any admissible clas
s works identically.
