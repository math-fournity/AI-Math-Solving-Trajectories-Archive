## Key Reformulation

For a prime $p$, the equation $p \mid P(n)$ requires $n^2 \equiv a, b$, or $c \p
mod{p}$. This is solvable iff at least one of $a, b, c$ is a quadratic residue (
QR) mod $p$ (where $0$ counts as a QR via $n=0$).

**Primes dividing $abc$:** If $p \mid a$ (or $b$ or $c$), then $P(0) = -abc \equ
iv 0 \pmod{p}$. These primes are automatically handled.

**Primes $p \nmid abc$:** We need at least one of $a, b, c$ to be a QR mod $p$.
Writing $a = d_a \cdot s_a^2$ where $d_a$ is the squarefree part, $a$ is a QR mo
d $p$ iff $\chi_{d_a}(p) = +1$ (Legendre symbol). So the triple is **non-univers
al** iff there exists a prime $p \nmid abc$ with $\chi_{d_a}(p) = \chi_{d_b}(p)
= \chi_{d_c}(p) = -1$.

## Character Analysis

By Dirichlet's theorem, such a prime exists iff the residue class $\{r : \chi_{d
_a}(r) = \chi_{d_b}(r) = \chi_{d_c}(r) = -1\}$ is non-empty in $(\mathbb{Z}/M\ma
thbb{Z})^*$.

- If any $d_i = 1$ (perfect square), $\chi_1 \equiv +1$, so $(-1,-1,-1)$ is impo
ssible → **universal**.
- If all $d_i \neq 1$: the three quadratic characters are distinct. By character
 orthogonality:
  - **Independent** ($k=3$): all 8 sign combinations occur → $(-1,-1,-1)$ occurs
 → **non-universal**.
  - **Dependent** ($k=2$: one character equals the product of the other two, i.e
., $d_3 = d_1 \oplus d_2$ where $\oplus$ is symmetric difference of prime sets):
 only 4 combinations occur, and $(-1,-1,-1)$ is **excluded** → **universal**.
  - **Two share a squarefree part** ($d_i = d_j$): $(-1,-1,-1)$ occurs → **non-u
niversal**.
