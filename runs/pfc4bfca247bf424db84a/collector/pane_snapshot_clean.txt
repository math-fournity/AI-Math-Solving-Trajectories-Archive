## Setup

Two countries, each with type $p'$ (prob $q$) or $p''$ (prob $1-q$), $0 < p' < p
'' < 1$. Types are independent. Candidate symmetric BNE: a country attacks **iff
** its type is $p''$.

Payoff primitives (with $W > 0$, $L < 0$, $\Delta := W - L > 0$):
- Attack alone → win prob $xp$ (where $x > 1$ so $p < xp < 1$).
- Both attack → type $p$ wins prob $p$.
- Don't attack, other attacks → win prob $yp$ ($0 < y < 1$, so $0 < yp < p$).
- Neither attacks → payoff $0$.

Define $f(p) = pW + (1-p)L = L + p\Delta$, the expected payoff from a "win-with-
prob-$p$" gamble. Since $\Delta > 0$, $f$ is strictly increasing in $p$.

## Expected Payoffs Under the Candidate Strategy

Given the opponent attacks with probability $1-q$ (only when opponent is $p''$):

**If type $p$ attacks:**
$$A(p) = q\,f(xp) + (1-q)\,f(p)$$
(with prob $q$ opponent is $p'$ and doesn't attack → solo attack, win prob $xp$;
 with prob $1-q$ opponent attacks → mutual attack, win prob $p$).

**If type $p$ does not attack:**
$$N(p) = (1-q)\,f(yp)$$
(with prob $q$ opponent also doesn't attack → payoff $0$; with prob $1-q$ oppone
nt attacks → passive defense, win prob $yp$).

## Incentive Gap

$$g(p) := A(p) - N(p) = q\,f(xp) + (1-q)\,f(p) - (1-q)\,f(yp)$$

Substituting $f(t) = L + t\Delta$:

$$g(p) = q(L + xp\,\Delta) + (1-q)(L + p\,\Delta) - (1-q)(L + yp\,\Delta)$$

$$= qL + qxp\,\Delta + (1-q)p\,\Delta - (1-q)yp\,\Delta$$

$$= qL + p\,\Delta\big[qx + (1-q) - (1-q)y\big]$$

$$\boxed{g(p) = qL + p\,\Delta\big[qx + (1-q)(1-y)\big]}$$

**Monotonicity:** $g'(p) = \Delta\big[qx + (1-q)(1-y)\big]$. Since $x > 1$, $y <
 1$, $q \in (0,1)$, the bracket $K := qx + (1-q)(1-y) > 0$, so $g$ is **strictly

## Equilibrium Conditions

The candidate strategy is a BNE iff:
- **High type attacks:** $g(p'') \geq 0$
- **Low type doesn't attack:** $g(p') \leq 0$

Since $g$ is strictly increasing, these are both necessary and sufficient (no ot

Setting $g(p^*) = 0$ yields the cutoff:

$$p^* = \frac{-qL}{\Delta\,K} = \frac{q(-L)}{(W-L)\big[qx + (1-q)(1-y)\big]}$$

Since $L < 0$, $q > 0$, $\Delta > 0$, $K > 0$, we have $p^* > 0$.

$$\boxed{p' \;\leq\; \frac{q(-L)}{(W-L)\big[\,qx + (1-q)(1-y)\,\big]} \;\leq\; p
