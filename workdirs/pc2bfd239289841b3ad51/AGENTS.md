# Problem

In a specialized logistics hub, a sequence of 99 cargo terminals is numbered consecutively from $n = 2$ to $n = 100$. Each terminal $n$ is assigned a specific "Efficiency Deficit," calculated by comparing two different routing protocols.

The first protocol, the "Quadratic Route," has a processing time of $\frac{n}{n^2-1}$ hours. The second protocol, the "Linear Route," has a processing time of $\frac{1}{n}$ hours. The Efficiency Deficit for each terminal is defined as the exact difference between the Quadratic Route time and the Linear Route time.

An analyst needs to calculate the "Total System Lag," which is the sum of these Efficiency Deficits across all terminals from $n = 2$ to $n = 100$. This Total System Lag can be expressed as a fraction $\frac{s}{t}$ in lowest terms, where $s$ and $t$ are relatively prime positive integers.

Find the value of $s + t$.
