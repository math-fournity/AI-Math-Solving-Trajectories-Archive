$$\operatorname{vol}(\mathfrak{o}_v^\times, d^\times x) = 1.$$

\pi^n \mathfrak{o}_v^\times = \{x \in k_v^\times : v(x) = n\}.$$
Each shell $\pi^n \mathfrak{o}_v^\times$ is a translate (coset) of the compact s

$$\operatorname{vol}(\pi^n \mathfrak{o}_v^\times, d^\times x) = \operatorname{vo
