## Proof

We seek positive integers $a, b$ minimizing $a + b$ subject to:
- $a + 13b \equiv 0 \pmod{11}$
- $a + 11b \equiv 0 \pmod{13}$

**Reducing the congruences.** Since $13 \equiv 2 \pmod{11}$ and $11 \equiv -2 \p
mod{13}$:

- Condition 1: $a \equiv -13b \equiv -2b \equiv 9b \pmod{11}$
- Condition 2: $a \equiv -11b \equiv 2b \pmod{13}$

**Parametrizing all solutions.** Write $a = 9b + 11k$. Substituting into the sec
ond congruence:
$$9b + 11k \equiv 2b \pmod{13} \implies 7b + 11k \equiv 0 \pmod{13} \implies 7b
- 2k \equiv 0 \pmod{13}$$
$$\implies 2k \equiv 7b \pmod{13} \implies k \equiv 7 \cdot 7b \equiv 49b \equiv
 10b \pmod{13}$$

So $k = 10b + 13m$ for integer $m$, giving:
$$a = 9b + 11(10b + 13m) = 119b + 143m$$

**Minimizing $a + b = 120b + 143m$** subject to $a = 119b + 143m \geq 1$ and $b
\geq 1$.

**Reparametrizing by $s = a+b$.** Set $a = s - b$. The congruences become:
- $s - b \equiv 9b \pmod{11} \implies s \equiv 10b \equiv -b \pmod{11} \implies
b \equiv -s \pmod{11}$
- $s - b \equiv 2b \pmod{13} \implies s \equiv 3b \pmod{13} \implies b \equiv 9s
 \pmod{13}$ (since $3^{-1} \equiv 9 \pmod{13}$)

By CRT, $b \equiv 87s \pmod{143}$ (solving $b = -s + 11t$ with $t \equiv 8s \pmo
d{13}$ yields $b = 87s + 143u$).

We need an integer $u$ with $1 \leq 87s + 143u \leq s - 1$, i.e.:
$$\frac{1 - 87s}{143} \leq u \leq \frac{-86s - 1}{143}$$

The interval has length $\frac{s-2}{143}$. For $s < 28$, this interval never con
tains an integer. Checking each $s$ from $1$ to $27$: the interval $[(1-87s)/143
,\; (-86s-1)/143]$ falls strictly between two consecutive integers in every case
 (e.g., $s=27$ gives $[-16.42, -16.24]$, $s=20$ gives $[-12.16, -12.03]$, etc.),
 so no valid $b \in [1, s-1]$ exists.

**At $s = 28$:** the interval is $[-2435/143,\; -2409/143] = [-17.03,\; -16.84]$
, which contains the integer $u = -17$. Then:
$$b = 87 \cdot 28 + 143 \cdot (-17) = 2436 - 2431 = 5, \qquad a = 28 - 5 = 23$$

**Verification:**
- $a + 13b = 23 + 65 = 88 = 8 \times 11$ ✓
- $a + 11b = 23 + 55 = 78 = 6 \times 13$ ✓
- $a = 23 > 0$, $b = 5 > 0$ ✓

Since no $s < 28$ admits a solution, the minimum is:

$$\boxed{a + b = 28}$$
