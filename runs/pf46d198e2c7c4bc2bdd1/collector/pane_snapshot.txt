## Solution

Let $K = \mathbb{Q}(\sqrt{2}, \sqrt{-3})$. This is a biquadratic (Galois) extens
ion of $\mathbb{Q}$ of degree $4$, with Galois group $\mathbb{Z}/2 \times \mathb
b{Z}/2$. Its three quadratic subfields are
$$\mathbb{Q}(\sqrt{2}),\quad \mathbb{Q}(\sqrt{-3}),\quad \mathbb{Q}(\sqrt{-6}).$
$

**Step 1: Compute the discriminant $D_K$.**

For a biquadratic field, the discriminant equals the product of the (fundamental
) discriminants of its three quadratic subfields:
- $\mathbb{Q}(\sqrt{2})$: $2 \equiv 2 \pmod 4$, so $d_1 = 4\cdot 2 = 8$.
- $\mathbb{Q}(\sqrt{-3})$: $-3 \equiv 1 \pmod 4$, so $d_2 = -3$.
- $\mathbb{Q}(\sqrt{-6})$: $-6 \equiv 2 \pmod 4$, so $d_3 = 4\cdot(-6) = -24$.

Hence
$$D_K = d_1\, d_2\, d_3 = 8\cdot(-3)\cdot(-24) = 576 = 2^6\cdot 3^2.$$

**Step 2: Propose a candidate basis.**

Set $\omega = \frac{1+\sqrt{-3}}{2}$, a primitive $6$th root of unity (root of $
x^2 - x + 1$), so $\mathcal{O}_{\mathbb{Q}(\sqrt{-3})} = \mathbb{Z}[\omega]$. Al
so $\mathcal{O}_{\mathbb{Q}(\sqrt{2})} = \mathbb{Z}[\sqrt{2}]$. Consider
$$\mathcal{B} = \left\{1,\ \sqrt{2},\ \omega,\ \sqrt{2}\,\omega\right\} = \left\
{1,\ \sqrt{2},\ \tfrac{1+\sqrt{-3}}{2},\ \tfrac{\sqrt{2}+\sqrt{-6}}{2}\right\}.$
$

Each element is an algebraic integer: $1$ and $\sqrt{2}$ (root of $x^2-2$) are o
bvious; $\omega$ is a root of $x^2-x+1$; and $\sqrt{2}\,\omega$ is a product of
algebraic integers, hence an algebraic integer.

**Step 3: Compute the discriminant of $\mathcal{B}$.**

The four embeddings are $\sigma_{\epsilon,\delta}$ with $\sqrt{2}\mapsto \epsilo
n\sqrt{2}$, $\sqrt{-3}\mapsto \delta\sqrt{-3}$, $\epsilon,\delta\in\{\pm1\}$. Si
nce $\omega$ depends only on $\sqrt{-3}$:
$$\sigma_{\epsilon,+}(\omega)=\tfrac{1+\sqrt{-3}}{2},\qquad \sigma_{\epsilon,-}(
\omega)=\tfrac{1-\sqrt{-3}}{2}.$$

Computing traces (using $\omega^2 = \omega - 1$):
- $\operatorname{Tr}(1)=4$,
- $\operatorname{Tr}(\sqrt{2})=0$,
- $\operatorname{Tr}(\omega)=2\cdot\tfrac{1+\sqrt{-3}}{2}+2\cdot\tfrac{1-\sqrt{-
3}}{2}=2$,
- $\operatorname{Tr}(\sqrt{2}\,\omega)=0$,
- $\operatorname{Tr}(2)=8$,
- $\operatorname{Tr}(\omega^2)=\operatorname{Tr}(\omega-1)=2-4=-2$,
- $\operatorname{Tr}(2\omega)=2\cdot 2 = 4$,
- $\operatorname{Tr}(2\omega^2)=\operatorname{Tr}(2\omega-2)=4-8=-4$,
- all mixed traces $\operatorname{Tr}(\sqrt{2}\cdot\omega)$, $\operatorname{Tr}(
\sqrt{2}\cdot\sqrt{2}\,\omega)=\operatorname{Tr}(2\omega)$, $\operatorname{Tr}(\
omega\cdot\sqrt{2}\,\omega)=\operatorname{Tr}(\sqrt{2}\,\omega^2)=\operatorname{
Tr}(\sqrt{2}(\omega-1))=0$.

The trace matrix $(\operatorname{Tr}(e_i e_j))$ is
$$M=\begin{pmatrix}4&0&2&0\\[2pt]0&8&0&4\\[2pt]2&0&-2&0\\[2pt]0&4&0&-4\end{pmatr
ix},$$
which decouples into two $2\times 2$ blocks:
$$\det\begin{pmatrix}4&2\\2&-2\end{pmatrix}=-12,\qquad \det\begin{pmatrix}8&4\\4
&-4\end{pmatrix}=-48.$$
Thus
$$\operatorname{disc}(\mathcal{B})=\det M = (-12)(-48)=576.$$

**Step 4: Conclude.**

Since $\operatorname{disc}(\mathcal{B}) = 576 = D_K$, and every element of $\mat
hcal{B}$ is an algebraic integer, the $\mathbb{Z}$-module they span has index $1
$ in $\mathcal{O}_K$. Therefore $\mathcal{B}$ is an integral basis.

$$\boxed{\mathcal{O}_K = \mathbb{Z}\!\left[\sqrt{2},\,\tfrac{1+\sqrt{-3}}{2}\rig
ht],\quad \text{with integral basis } \left\{1,\ \sqrt{2},\ \tfrac{1+\sqrt{-3}}{
2},\ \tfrac{\sqrt{2}+\sqrt{-6}}{2}\right\}.}$$
