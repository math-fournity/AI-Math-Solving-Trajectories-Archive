# Solution

Let $\|a\| = \left(\sum_{k=1}^n a_k^2\right)^{1/2}$ and $\|x\| = \left(\sum_{k=1
}^n x_k^2\right)^{1/2}$. The inequality reads:

$$\sum_{k=1}^n r_k(x_k - a_k) \leq \|x\| - \|a\| \qquad \text{for all } x_k \geq
 0.$$

## Step 1: Determine $\sum r_k a_k$

Substitute $x = ta$ for $t \geq 0$ (i.e., $x_k = t\,a_k$). Then:

- LHS $= (t-1)\sum r_k a_k$,
- RHS $= t\|a\| - \|a\| = (t-1)\|a\|$.

So $(t-1)\sum r_k a_k \leq (t-1)\|a\|$ for all $t \geq 0$.

- For $t > 1$: $(t-1) > 0$ gives $\sum r_k a_k \leq \|a\|$.
- For $0 \leq t < 1$: $(t-1) < 0$ gives $\sum r_k a_k \geq \|a\|$.

Therefore:

$$\boxed{\sum_{k=1}^n r_k a_k = \|a\|.} \tag{1}$$

## Step 2: Bound each $r_k$ from above

Fix index $i$ and set $x_i = a_i + t$, $x_k = a_k$ for $k \neq i$, with $t > 0$.
 The inequality becomes:

$$r_i \, t \leq \sqrt{\|a\|^2 + 2a_i t + t^2} - \|a\|.$$

Dividing by $t > 0$:

$$r_i \leq \frac{\sqrt{\|a\|^2 + 2a_i t + t^2} - \|a\|}{t}.$$

Taking $t \to 0^+$ (the right-hand side is the difference quotient of $t \mapsto
 \sqrt{\|a\|^2 + 2a_i t + t^2}$ at $t=0$):

$$r_i \leq \frac{2a_i}{2\|a\|} = \frac{a_i}{\|a\|}. \tag{2}$$

## Step 3: Pin down $r_k$ exactly

Define $s_k = a_k / \|a\|$. From (2), $r_k \leq s_k$ for every $k$, and since $r
_k \geq 0$, we have $0 \leq r_k \leq s_k$. From (1):

$$\sum_{k=1}^n r_k a_k = \|a\| = \sum_{k=1}^n \frac{a_k}{\|a\|}\,a_k = \sum_{k=1
}^n s_k\, a_k.$$

Hence $\sum_{k=1}^n (s_k - r_k)\,a_k = 0$. Each summand is non-negative (since $
s_k - r_k \geq 0$ and $a_k \geq 0$), so every term must vanish:

$$(s_k - r_k)\,a_k = 0 \quad \text{for all } k.$$

- If $a_k > 0$: $r_k = s_k = a_k/\|a\|$.
- If $a_k = 0$: $s_k = 0$, so $r_k \leq 0$, and combined with $r_k \geq 0$ gives
 $r_k = 0 = a_k/\|a\|$.

In both cases:

$$\boxed{r_k = \frac{a_k}{\|a\|} = \frac{a_k}{\left(\sum_{j=1}^n a_j^2\right)^{1
/2}}.}$$

## Step 4: Verification (sufficiency)

With $r_k = a_k/\|a\|$, the LHS becomes:

$$\sum_{k=1}^n \frac{a_k}{\|a\|}(x_k - a_k) = \frac{\sum a_k x_k}{\|a\|} - \frac
{\sum a_k^2}{\|a\|} = \frac{\sum a_k x_k}{\|a\|} - \|a\|.$$

The inequality reduces to:

$$\frac{\sum a_k x_k}{\|a\|} - \|a\| \leq \|x\| - \|a\| \quad\Longleftrightarrow
\quad \sum_{k=1}^n a_k x_k \leq \|a\|\cdot\|x\|,$$

which is the **Cauchy–Schwarz inequality**, valid for all real $x_k$ (hence cert
ainly for $x_k \geq 0$). Equality holds when $x$ is a non-negative scalar multip
le of $a$, in particular at $x = a$.

## Conclusion

The unique values are:

$$r_k = \frac{a_k}{\left(\displaystyle\sum_{j=1}^{n} a_j^{2}\right)^{1/2}}, \qqu
ad k = 1, 2, \ldots, n.$$
