## Proof that $S^2$ cannot be embedded in $\mathbb{CP}^1 \times \mathbb{CP}^1$ a
s a totally real submanifold

**Setup and notation.** Let $X = \mathbb{CP}^1 \times \mathbb{CP}^1$, which has
complex dimension $2$ (real dimension $4$). Let $h_1, h_2 \in H^2(X;\mathbb{Z})$
 be the pullbacks of the hyperplane class from the first and second factors resp
ectively, so $H^2(X;\mathbb{Z}) = \mathbb{Z}h_1 \oplus \mathbb{Z}h_2$ and $H^4(X
;\mathbb{Z}) = \mathbb{Z}\,h_1 h_2$, with $h_1^2 = h_2^2 = 0$ and $\langle h_1 h
_2, [X]\rangle = 1$.

The tangent bundle splits as $TX = \pi_1^*T\mathbb{CP}^1 \oplus \pi_2^*T\mathbb{
CP}^1$, giving:
$$c(TX) = (1+2h_1)(1+2h_2) = 1 + (2h_1+2h_2) + 4h_1h_2,$$
so $c_1(TX) = 2h_1 + 2h_2$ and $c_2(TX) = 4h_1 h_2$.

---

**Step 1: The totally real condition forces $\nu \cong TM$ and $TX|_M \cong TM \
otimes \mathbb{C}$.**

Suppose $f: S^2 \to X$ is a totally real embedding. Since $\dim_\mathbb{R} S^2 =
 2 = \dim_\mathbb{C} X$, at each point $p$ we have $T_pS^2 \cap J(T_pS^2) = \{0\
}$ and $\dim T_pS^2 + \dim J(T_pS^2) = 2 + 2 = 4 = \dim T_pX$, so:
$$TX|_{S^2} = TS^2 \oplus J(TS^2).$$
The complex structure $J$ gives a real bundle isomorphism $TS^2 \xrightarrow{\si
m} J(TS^2)$, so the **normal bundle** $\nu = TX|_{S^2}/TS^2 \cong J(TS^2) \cong
TS^2$.

Moreover, the map $\phi: TS^2 \otimes_\mathbb{R} \mathbb{C} \to TX|_{S^2}$ defin
ed by $\phi(v \otimes (a+bi)) = av + bJv$ is an isomorphism of **complex** vecto
r bundles (one checks $\phi(i\cdot(v\otimes 1)) = Jv = J\cdot\phi(v\otimes 1)$).
 Therefore:
$$TX|_{S^2} \cong TS^2 \otimes \mathbb{C} \quad \text{(as complex rank-2 bundles
).}$$

---

**Step 2: The Chern class constraint gives $a + b = 0$.**

For any real vector bundle $E$, the complexification $E \otimes \mathbb{C}$ is s
elf-conjugate ($E\otimes\mathbb{C} \cong \overline{E\otimes\mathbb{C}}$), so $c_
k(E\otimes\mathbb{C}) = (-1)^k c_k(E\otimes\mathbb{C})$, forcing **odd Chern cla
sses to vanish**. In particular:
$$c_1(TS^2 \otimes \mathbb{C}) = 0.$$
By the isomorphism from Step 1:
$$f^*c_1(TX) = c_1(TX|_{S^2}) = c_1(TS^2 \otimes \mathbb{C}) = 0.$$
Writing $f_*[S^2] = a\,[\mathbb{CP}^1\times\{\mathrm{pt}\}] + b\,[\{\mathrm{pt}\
}\times\mathbb{CP}^1] \in H_2(X;\mathbb{Z})$, we have $\langle f^*h_1, [S^2]\ran
gle = a$ and $\langle f^*h_2, [S^2]\rangle = b$, so:
$$0 = f^*(2h_1 + 2h_2) = 2a + 2b \quad\Longrightarrow\quad b = -a.$$

---

**Step 3: The self-intersection from the normal bundle is $+2$.**

The self-intersection number of an embedded submanifold equals the Euler number
of its normal bundle:
$$I(S^2, S^2) = \langle e(\nu), [S^2]\rangle = \langle e(TS^2), [S^2]\rangle = \
chi(S^2) = 2,$$
using $\nu \cong TS^2$ from Step 1.

---

**Step 4: The self-intersection from the homology class is $-2a^2 \leq 0$.**

The self-intersection also equals $\langle \mathrm{PD}(f_*[S^2])^2, [X]\rangle$.
 With $b = -a$:
$$\mathrm{PD}(f_*[S^2]) = a(h_1 - h_2),$$
$$I(S^2,S^2) = a^2\langle (h_1 - h_2)^2, [X]\rangle = a^2\langle h_1^2 - 2h_1h_2
 + h_2^2, [X]\rangle = a^2(0 - 2 + 0) = -2a^2.$$

---

**Step 5: Contradiction.**

Combining Steps 3 and 4:
$$2 = -2a^2 \quad\Longrightarrow\quad a^2 = -1,$$
which has **no integer solution**. (The case $a = 0$ gives $0 = 2$, also impossi
ble.)

Therefore no totally real embedding $f: S^2 \hookrightarrow \mathbb{CP}^1 \times
 \mathbb{CP}^1$ exists. $\blacksquare$
