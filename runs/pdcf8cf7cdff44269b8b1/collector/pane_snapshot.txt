## Proof

Set up coordinates with the right angle at the origin: **B = (0, 0)**, **A = (√3
, 0)**, **C = (0, 3)**. Then AB lies on the x-axis (y = 0) and the hypotenuse AC
 has equation

$$\sqrt{3}\,x + y = 3 \quad\text{(i.e. } \sqrt{3}\,x + y - 3 = 0\text{)}.$$

The distance from B to line AC is |0 + 0 − 3|/√(3+1) = 3/2.

**First circle.** It is tangent to AB at B, so its center lies on the perpendicu
lar to AB at B, i.e. on the y-axis: center (0, r₁), radius r₁. Tangency to AC gi
ves

$$\frac{|0 + r_1 - 3|}{2} = r_1 \;\Longrightarrow\; \frac{3 - r_1}{2} = r_1 \;\L
ongrightarrow\; r_1 = 1.$$

So the first circle has center **(0, 1)** and radius **1**.

**Second circle.** It is tangent to both AB and AC, so its center lies on the an
gle bisector of ∠A. Since tan A = BC/AB = 3/√3 = √3, we have A = 60°. The intern
al bisector from A = (√3, 0) has unit direction (−√3/2, 1/2), so the center is

$$(\sqrt{3} - \tfrac{\sqrt{3}}{2}t,\;\tfrac{t}{2})$$

for some t > 0, with radius r₂ = t/2 (distance to AB). Substituting t = 2r₂, the
 center is **(√3(1 − r₂), r₂)**.

**Tangency with the first circle.** The two circles are distinct and both inside
 the triangle, so they are externally tangent:

$$\text{dist} = 1 + r_2.$$

Compute the distance between (0, 1) and (√3(1 − r₂), r₂):

$$\text{dist}^2 = 3(1-r_2)^2 + (r_2 - 1)^2 = 4(1-r_2)^2,$$

so dist = 2|1 − r₂| = 2(1 − r₂) (since r₂ < 1). Setting this equal to 1 + r₂:

$$2(1 - r_2) = 1 + r_2 \;\Longrightarrow\; 2 - 2r_2 = 1 + r_2 \;\Longrightarrow\
; 1 = 3r_2 \;\Longrightarrow\; r_2 = \tfrac{1}{3}.$$

**Verification.** Center = (2√3/3, 1/3), which satisfies √3·(2√3/3) + 1/3 = 7/3
< 3 (inside the triangle) and x, y ≥ 0. Distance to (0,1) = √(4/3 + 4/9) = √(16/
9) = 4/3 = 1 + 1/3 ✓.

The radius of the second circle is $\boxed{\dfrac{1}{3}}$.
