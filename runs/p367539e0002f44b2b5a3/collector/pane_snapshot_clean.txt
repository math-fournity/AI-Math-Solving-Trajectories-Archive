## Proof

**Step 1: Reduction via substitution.**

Let $y = x+3$, so $x^2+6x+10 = (x+3)^2+1 = y^2+1$. Since the substitution $x \ma
psto y-3$ is an automorphism of $\mathbb{Z}[x]$, we seek all $P, R \in \mathbb{Z
}[y]$ satisfying:
$$R^2 - (y^2+1)P^2 = -1. \tag{$\star$}$$

**Step 2: Algebraic setup.**

Consider the ring $A = \mathbb{Z}[y, \sqrt{y^2+1}] = \mathbb{Z}[y] \oplus \mathb
b{Z}[y]\cdot\sqrt{y^2+1}$, a free $\mathbb{Z}$-module with basis $\{y^j, \sqrt{y
^2+1}\,y^j : j \ge 0\}$. Define the **Pell conjugation** $\sigma: \sqrt{y^2+1} \
mapsto -\sqrt{y^2+1}$, $y \mapsto y$. The **Pell norm** is $N(f) = f \cdot \sigm
a(f)$. Equation $(\star)$ says $N(R + P\sqrt{y^2+1}) = -1$.

Introduce the formal variable $t$ via:
$$y = \frac{t - t^{-1}}{2}, \qquad \sqrt{y^2+1} = \frac{t + t^{-1}}{2}.$$

Set $a = \frac{t+t^{-1}}{2}$, $b = \frac{t-t^{-1}}{2} = y$. Then $a^2 - b^2 = 1$
 and $t = a+b$, $t^{-1} = a-b$. The map gives an embedding $A \hookrightarrow \m
athbb{Q}[t, t^{-1}]$ with image $\mathbb{Z}[a,b] = \mathbb{Z}[\frac{t+t^{-1}}{2}
, \frac{t-t^{-1}}{2}]$, which contains $\mathbb{Z}[t, t^{-1}]$ (since $t = a+b \
in A$) and is contained in $\mathbb{Q}[t,t^{-1}]$.

Under this embedding, the Pell conjugation $\sigma$ sends $a \mapsto -a$, $b \ma
psto b$, i.e., $t \mapsto -t^{-1}$.

**Step 3: Unit group of $A$.**

**Claim:** $A^* = \{\pm t^n : n \in \mathbb{Z}\}$.

*Proof of claim.* Any unit $u \in A^*$ is also a unit in $A \otimes \mathbb{Q} =
 \mathbb{Q}[t, t^{-1}]$, whose units are $\{c\, t^n : c \in \mathbb{Q}^*, n \in
\mathbb{Z}\}$. So $u = c\, t^n$ for some $c \in \mathbb{Q}^*$, $n \in \mathbb{Z}
$.

For $n \ge 0$: $t^n = (a+b)^n = \sum_{k=0}^n \binom{n}{k} a^k b^{n-k}$. Splittin
g into even/odd powers of $a$ and using $a^2 = b^2+1$:
- $t^n = R_n(y) + P_n(y)\cdot a$ where $R_n, P_n \in \mathbb{Z}[y]$ (integer bin
omial coefficients).

The leading coefficient of $R_n$ (when $n$ is even) or $P_n$ (when $n$ is odd) e
quals $1$. Thus $c \cdot t^n \in A$ forces $c \in \mathbb{Z}$. Similarly $u^{-1}
 = c^{-1} t^{-n} \in A$ forces $c^{-1} \in \mathbb{Z}$, so $c = \pm 1$. The case
 $n < 0$ is identical (using $t^{-n} = (a-b)^n$). $\square$

**Step 4: Elements of norm $-1$.**

The Pell norm of $t^n$ is $N(t^n) = t^n \cdot \sigma(t^n) = t^n \cdot (-t^{-1})^
n = (-1)^n$.

So $N(\pm t^n) = (-1)^n$, and the elements of norm $-1$ are exactly $\pm t^{2k+1
}$ for $k \in \mathbb{Z}$.

**Step 5: Extracting the $P$-part.**

For $n = 2k+1 \ge 1$ (i.e., $k \ge 0$), expand $t^{2k+1} = (y + a)^{2k+1}$:
$$t^{2k+1} = \underbrace{\sum_{i=0}^{k} \binom{2k+1}{2i}(y^2+1)^i\, y^{2k+1-2i}}
_{R_k(y)} + \underbrace{\left(\sum_{i=0}^{k} \binom{2k+1}{2i+1}(y^2+1)^i\, y^{2k
-2i}\right)}_{P_k(y)} \cdot a.$$

Both $R_k, P_k \in \mathbb{Z}[y]$. For $k < 0$, writing $t^{2k+1} = t^{-(2|k|-1)
} = (a - y)^{2|k|-1}$, a similar expansion shows $P_k = P_{|k|-1}$ (the $P$-part
 is unchanged; only $R$ changes sign). Thus the **distinct** $P$-values arise fr
om $k = 0, 1, 2, \ldots$.

**Step 6: Recurrence.**

Since $t^2 = (a+b)^2 = a^2 + 2ab + b^2 = (b^2+1) + 2ab + b^2 = 2b^2+1 + 2ba = (2
y^2+1) + 2y\,a$, multiplication by $t^2$ sends $(R_k, P_k) \mapsto (R_{k+1}, P_{
k+1})$ via:
$$R_{k+1} = (2y^2+1)R_k + 2y(y^2+1)P_k, \quad P_{k+1} = 2y\,R_k + (2y^2+1)P_k.$$

Eliminating $R_k$ using the backward recurrence gives:
$$\boxed{P_{k+1} = (4y^2+2)\,P_k - P_{k-1}}, \quad P_0 = 1,\; P_1 = 4y^2+1.$$

**Verification:** $P_0 = 1$: $y^2 - (y^2+1) = -1$ ✓. $P_1 = 4y^2+1$, $R_1 = 4y^3
+3y$: $R_1^2 - (y^2+1)P_1^2 = (16y^6+24y^4+9y^2) - (16y^6+24y^4+9y^2+1) = -1$ ✓.

**Step 7: Completeness.**

Any solution $(R, P) \in \mathbb{Z}[y]^2$ of $(\star)$ gives $u = R + Pa \in A$
with $N(u) = -1$. Then $u \cdot \sigma(u) = -1$, so $u \cdot (-\sigma(u)) = 1$,
meaning $u$ is a unit of $A$ with inverse $-\sigma(u) \in A$. By Step 3, $u = \p
m t^{2k+1}$ for some $k \in \mathbb{Z}$. By Step 5, $P = \pm P_{|k|}$ for some $
k \ge 0$. Conversely, every $\pm P_k$ ($k \ge 0$) gives a valid solution by cons
truction. Since $P$ and $-P$ yield the same $P^2$, the solutions are exactly $P
= \pm P_k$.

**Step 8: Translate back to $x$.**

With $y = x+3$, the complete set of integer polynomials $P$ is:

$$\boxed{P(x) = \pm P_n(x), \quad n = 0, 1, 2, \ldots}$$

where $P_0(x) = 1$, $\;P_1(x) = 4x^2 + 24x + 37$, and
$$P_{n+1}(x) = \bigl(4x^2 + 24x + 38\bigr)\,P_n(x) - P_{n-1}(x).$$

Equivalently, the explicit formula is:
$$P_n(x) = \sum_{i=0}^{n} \binom{2n+1}{2i+1}\bigl((x+3)^2+1\bigr)^i (x+3)^{2(n-i
)}.$$

The first few are: $P_0 = 1$, $P_1 = 4x^2+24x+37$, $P_2 = 16x^4+192x^3+852x^2+16
56x+1189$, $\ldots$

For each such $P_n$, the corresponding $R_n(x+3) = \sum_{i=0}^{n}\binom{2n+1}{2i
}(y^2+1)^i y^{2n+1-2i}\big|_{y=x+3}$ is an integer polynomial satisfying $(x^2+6
x+10)P_n^2 - 1 = R_n^2$.
