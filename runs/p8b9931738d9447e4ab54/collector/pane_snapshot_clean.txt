Looking at this problem, I need to determine whether among any four monic quadra
tic real polynomials, some pair is always related by composition with a linear p
olynomial (up to scalar).

**Answer: True.**

**Proof.**

Each $f_k$ is monic of degree 2, so $f_k(x) = x^2 + a_k x + b_k$ for real $a_k,
b_k$. Completing the square gives
$$f_k(x) = \left(x + \tfrac{a_k}{2}\right)^2 + s_k, \qquad s_k := b_k - \tfrac{a
_k^2}{4}.$$

**Degree constraint.** If $f_i \circ p = c\,f_j$ with $c \neq 0$, then $\deg(f_i
 \circ p) = 2\deg p = \deg(c f_j) = 2$, so $\deg p = 1$. Write $p(x) = \alpha x
+ \beta$ with $\alpha \neq 0$.

**Coefficient matching.** Expanding both sides:
$$f_i(p(x)) = \alpha^2 x^2 + \alpha(2\beta + a_i)\,x + (\beta^2 + a_i\beta + b_i
),$$
$$c\,f_j(x) = c\,x^2 + c\,a_j\,x + c\,b_j.$$

Equating coefficients:
1. $c = \alpha^2$,
2. $2\beta + a_i = \alpha\,a_j$, i.e. $\beta = \frac{\alpha\,a_j - a_i}{2}$,
3. $\beta^2 + a_i\beta + b_i = \alpha^2 b_j$.

Substituting $\beta$ from (2) into (3) and simplifying (the cross terms in $\alp
ha\,a_i a_j$ cancel):
$$\frac{\alpha^2 a_j^2}{4} - \frac{a_i^2}{4} + b_i = \alpha^2 b_j,$$
which rearranges to
$$\alpha^2\!\left(\frac{a_j^2}{4} - b_j\right) = \frac{a_i^2}{4} - b_i, \qquad\t
ext{i.e.,}\quad \alpha^2\,s_j = s_i.$$

**Solvability condition.** Since $\alpha$ is real and nonzero, $\alpha^2 > 0$. T
hus the condition $\alpha^2 s_j = s_i$ is satisfiable if and only if:
- $s_i = s_j = 0$ (any $\alpha \neq 0$ works), or
- $s_i$ and $s_j$ are both nonzero with the same sign (then $\alpha = \sqrt{s_i/
s_j}$).

In both cases, once $\alpha$ is chosen, $\beta$ and $c = \alpha^2$ are determine
d, giving a valid $p$ and $c$.

**Pigeonhole argument.** Each $s_k \in \{1,2,3,4\}$ is a real number, so it fall
s into exactly one of three sign classes: **positive**, **negative**, or **zero*
*. With four values assigned to three classes, the pigeonhole principle guarante
es that at least two of them—say $s_i$ and $s_j$ with $i \neq j$—lie in the same
 class.

- If both are zero: the condition $s_i = s_j = 0$ holds.
- If both are positive: $s_i/s_j > 0$, so $\alpha = \sqrt{s_i/s_j}$ works.
- If both are negative: $s_i/s_j > 0$, so $\alpha = \sqrt{s_i/s_j}$ works.

In every case, there exist $i \neq j$, a linear polynomial $p(x) = \alpha x + \b
eta$, and a constant $c = \alpha^2$ such that $f_i \circ p = c\,f_j$.

Therefore the statement is **true**. $\blacksquare$
