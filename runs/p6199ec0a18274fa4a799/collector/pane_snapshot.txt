### Setup: Separation of variables

We seek separated solutions $u = R(r)\Theta(\theta)T(t)$. Substituting into

$$u_{tt} = \frac{1}{r}(r u_r)_r + \frac{1}{r^2}u_{\theta\theta}$$

and dividing by $R\Theta T$ gives

$$\frac{T''}{T} = \frac{\frac{1}{r}(rR')'}{R} + \frac{1}{r^2}\frac{\Theta''}{\Th
eta} = -\lambda \quad (\text{separation constant}).$$

**Angular part.** $\Theta'' + n^2\Theta = 0$ with $2\pi$-periodicity forces $n\i
n\mathbb{Z}_{\ge 0}$, giving $\Theta \in \{\cos n\theta,\;\sin n\theta\}$ (for $
n=0$ only the constant).

**Radial part.** With $\Theta''/r^2\Theta = -n^2/r^2$,

$$r^2 R'' + rR' + (\lambda r^2 - n^2)R = 0,\qquad R(1)=0,\quad R\text{ bounded a
t }r=0.$$

This is Bessel's equation of order $n$; the bounded solution is $R(r)=J_n(\sqrt{
\lambda}\,r)$. The boundary condition $R(1)=0$ requires $J_n(\sqrt{\lambda})=0$,
 hence $\sqrt{\lambda}=\alpha_{n,m}$, the $m$-th positive zero of $J_n$. The eig
envalues are $\lambda_{n,m}=\alpha_{n,m}^2$.

**Temporal part.** $T'' + \alpha_{n,m}^2\,T = 0$, so

$$T_{n,m}(t) = A_{n,m}\cos(\alpha_{n,m}t) + B_{n,m}\sin(\alpha_{n,m}t).$$

### Initial velocity

The problem specifies only the initial displacement $u(r,\theta,0)$. For the IVP
 to be well-posed the initial velocity $u_t(r,\theta,0)$ must also be prescribed
; the standard convention (and the only one consistent with a problem that lists
 a single initial condition) is

$$u_t(r,\theta,0) = 0,$$

which forces every $B_{n,m}=0$. (Were a nonzero velocity given, the $\sin(\alpha
_{n,m}t)/\alpha_{n,m}$ terms would appear; none is supplied, so they vanish.)

### Eigenfunction expansion of the initial data

The given initial displacement is already written as a finite linear combination
 of the radial–angular eigenfunctions $\{J_n(\alpha_{n,m}r)\cos n\theta,\; J_n(\
alpha_{n,m}r)\sin n\theta\}$:

$$u(r,\theta,0) = \underbrace{J_0(\alpha_{0,1}r)}_{n=0,m=1} + 3\underbrace{J_0(\
alpha_{0,2}r)}_{n=0,m=2} - 2\underbrace{J_1(\alpha_{1,1}r)\sin\theta}_{n=1,m=1}
+ 4\underbrace{J_2(\alpha_{2,1}r)\cos 2\theta}_{n=2,m=1}.$$

Each summand is an eigenfunction corresponding to a distinct eigenvalue $\alpha_
{n,m}^2$. By the orthogonality of the Bessel eigenfunctions (Sturm–Liouville in
$r$ with weight $r$, together with orthogonality of $\{\cos n\theta,\sin n\theta
\}$), these four terms are mutually orthogonal, and the expansion is exact — no
further terms are needed.

### Time evolution

Each eigenmode evolves independently: the mode with eigenvalue $\alpha_{n,m}^2$
is multiplied by $\cos(\alpha_{n,m}t)$ (the $\sin$ coefficient being zero by the
 zero-velocity condition). Therefore

$$\boxed{\,u(r,\theta,t) = J_0(\alpha_{0,1}r)\cos(\alpha_{0,1}t) + 3\,J_0(\alpha
_{0,2}r)\cos(\alpha_{0,2}t) - 2\,J_1(\alpha_{1,1}r)\sin\theta\,\cos(\alpha_{1,1}
t) + 4\,J_2(\alpha_{2,1}r)\cos 2\theta\,\cos(\alpha_{2,1}t).\,}$$

### Verification

- **PDE:** Each term is of the form $J_n(\alpha_{n,m}r)\,\Phi_n(\theta)\,\cos(\a
lpha_{n,m}t)$. Since $J_n(\alpha_{n,m}r)\Phi_n(\theta)$ is a spatial eigenfuncti
on with eigenvalue $\alpha_{n,m}^2$, we have $\Delta_{\text{polar}}[\cdots] = -\
alpha_{n,m}^2[\cdots]$, while $\partial_{tt}[\cdots\cos(\alpha_{n,m}t)] = -\alph
a_{n,m}^2[\cdots\cos(\alpha_{n,m}t)]$. Both sides match for every term, hence fo
r the sum.
- **Periodicity:** $\cos n\theta,\sin n\theta$ are $2\pi$-periodic; $J_n$ is sin
gle-valued. ✓
- **Regularity at $r=0$:** $J_n(\alpha_{n,m}r)\sim r^n$ near $0$, so all terms a
re bounded (indeed smooth) at the origin. ✓
- **Boundary $u(1,\theta,t)=0$:** $J_n(\alpha_{n,m})=0$ by definition of $\alpha
_{n,m}$, so every term vanishes at $r=1$. ✓
- **Initial displacement:** Setting $t=0$ gives $\cos(\alpha_{n,m}\cdot 0)=1$, r
ecovering exactly the prescribed $u(r,\theta,0)$. ✓
- **Initial velocity:** $\partial_t u\big|_{t=0}\propto \sin(\alpha_{n,m}\cdot 0
)=0$ for every term, consistent with the (conventionally) zero initial velocity.
 ✓

By uniqueness of solutions to the wave equation with smooth data on this domain,
 this is the solution.
