## Proof

**Step 1: Compute the coefficients.**

Since $e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!}$, the coefficient of $x^n$ in $(
1-x+x^2)e^x$ is (with $\frac{1}{k!}:=0$ for $k<0$):

$$c_n = \frac{1}{n!} - \frac{1}{(n-1)!} + \frac{1}{(n-2)!} = \frac{1 - n + n(n-1
)}{n!} = \frac{(n-1)^2}{n!}.$$

This formula is valid for all $n \ge 0$. We have $c_0 = 1$ and $c_1 = 0$. The no
nzero coefficients are $c_0 = 1$ and $c_n$ for $n \ge 2$.

**Step 2: Reduce to a number-theoretic lemma.**

For $n \ge 2$, set $m = n-1 \ge 1$. Then $c_n = \frac{m^2}{(m+1)!}$. We must sho
w that when $\frac{m^2}{(m+1)!}$ is reduced to lowest terms, the numerator is $1
$ or a prime. Equivalently, setting

$$N(m) = \frac{m^2}{\gcd\!\big(m^2,\,(m+1)!\big)},$$

we prove:

> **Lemma.** For every positive integer $m$, $N(m)$ is either $1$ or a prime.

**Step 3: Analyze the $p$-adic valuations.**

For a prime $p \mid m$, write $m = p^a r$ with $a = v_p(m) \ge 1$ and $\gcd(r, p
) = 1$. The power of $p$ in $m^2$ is $2a$, and the power of $p$ in $(m+1)!$ is $
v_p((m+1)!)$. The power of $p$ surviving in $N(m)$ is

$$\rho_p := \max\big(0,\; 2a - v_p((m+1)!)\big).$$

Then $N(m) = \prod_{p \mid m} p^{\rho_p}$. We prove: (i) each $\rho_p \in \{0, 1
\}$, and (ii) at most one prime has $\rho_p = 1$.

**Key estimate.** Since $p \mid m$, we have $m+1 = p^a r + 1$, so

$$\left\lfloor \frac{m+1}{p} \right\rfloor = p^{a-1} r + \left\lfloor \frac{1}{p
} \right\rfloor = p^{a-1} r \quad (p \ge 2).$$

Therefore $v_p((m+1)!) \ge \lfloor (m+1)/p \rfloor = p^{a-1} r$. A **necessary**
 condition for $\rho_p > 0$ is:

$$p^{a-1} r < 2a. \tag{$\star$}$$

This severely restricts the possibilities. We check all cases.

**Case $a = 1$.** Condition $(\star)$ becomes $r < 2$, so $r = 1$ and $m = p$. T
hen $v_p((p+1)!) = 1$ (since $p < p+1 < 2p$ for $p \ge 2$, there is exactly one
multiple of $p$ in $\{1,\dots,p+1\}$, and $p^2 > p+1$). Thus $\rho_p = 2 - 1 = 1
$.

If $r \ge 2$: $v_p((m+1)!) \ge r \ge 2 = 2a$, so $\rho_p = 0$.

**Case $a = 2$.** Condition $(\star)$ becomes $pr < 4$.
- $p = 2, r = 1$: $m = 4$. Then $v_2(5!) = 3$, so $\rho_2 = 4 - 3 = 1$.
- $p = 3, r = 1$: $m = 9$. Then $v_3(10!) = \lfloor 10/3\rfloor + \lfloor 10/9\r
floor = 3+1 = 4 = 2a$, so $\rho_3 = 0$.
- $p = 2, r = 3$: $pr = 6 \ge 4$, excluded.
- All other $(p, r)$: $pr \ge 4$, excluded.

So only $m = 4$ gives $\rho_p = 1$ (with $p = 2$).

**Case $a = 3$.** Condition $(\star)$ becomes $p^2 r < 6$.
- $p = 2, r = 1$: $m = 8$. Then $v_2(9!) = 4+2+1 = 7 \ge 6 = 2a$, so $\rho_2 = 0
$.
- $p = 2, r = 3$: $p^2 r = 12 \ge 6$, excluded.
- $p \ge 3$: $p^2 \ge 9 > 6$, excluded.

No case gives $\rho_p > 0$.

**Case $a \ge 4$.** We have $p^{a-1} r \ge 2^{a-1}$. For $a = 4$: $2^{a-1} = 8 =
 2a$, so $(\star)$ fails. For $a \ge 5$: $2^{a-1} \ge 16 > 2a$, so $(\star)$ fai
ls. No case gives $\rho_p > 0$.

**Step 4: Conclude.**

The complete list of cases where some $\rho_p = 1$ is:
- $m = p$ (a prime): only prime factor is $p$, $\rho_p = 1$, all other primes do
n't divide $m$. So $N(m) = p$.
- $m = 4$: only prime factor is $2$, $\rho_2 = 1$. So $N(m) = 2$.

In every other case, all $\rho_p = 0$, so $N(m) = 1$.

In particular, at most one prime contributes (since in both exceptional cases $m
$ has a single prime factor), and the contribution is exactly $1$. Therefore $N(
m) \in \{1\} \cup \{\text{primes}\}$ for all $m \ge 1$.

**Step 5: Wrap up.**

- $c_0 = 1$: numerator is $1$. ✓
- $c_1 = 0$: excluded (nonzero coefficients only).
- $c_n = \frac{m^2}{(m+1)!}$ with $m = n-1 \ge 1$: by the Lemma, the numerator i
n lowest terms is $N(m) \in \{1\} \cup \{\text{primes}\}$. ✓

This completes the proof. $\blacksquare$
