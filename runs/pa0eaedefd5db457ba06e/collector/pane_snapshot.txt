## Solution

### Part 1: Deriving the Quadrature Rule

We seek weights $w_{-1/2}, w_0, w_{1/2}$ such that the rule
$$Q(f) = w_{-1/2}\,f(-\tfrac{1}{2}) + w_0\,f(0) + w_{1/2}\,f(\tfrac{1}{2})$$
agrees with $\int_{-1}^{1} f(x)\,dx$ on polynomials of the highest possible degr
ee.

**Symmetry.** The nodes $\{-\tfrac12, 0, \tfrac12\}$ and the interval $[-1,1]$ a
re symmetric about $0$, so the optimal rule is symmetric: $w_{-1/2} = w_{1/2} =:
 a$, $w_0 =: b$. Set $Q(f) = a\bigl[f(-\tfrac12)+f(\tfrac12)\bigr] + b\,f(0)$.

**Moment matching.**

| Degree $k$ | $\int_{-1}^1 x^k\,dx$ | $Q(x^k)$ | Equation |
|---|---|---|---|
| 0 | $2$ | $2a + b$ | $2a+b=2$ |
| 1 | $0$ | $a(-\tfrac12)+a(\tfrac12)=0$ | automatic ✓ |
| 2 | $\tfrac{2}{3}$ | $a\cdot\tfrac14 + a\cdot\tfrac14 = \tfrac{a}{2}$ | $\tfra
c{a}{2}=\tfrac23 \Rightarrow a=\tfrac43$ |
| 3 | $0$ | $a(-\tfrac18)+a(\tfrac18)=0$ | automatic ✓ |

From $a = \tfrac43$: $b = 2 - \tfrac{8}{3} = -\tfrac{2}{3}$.

**The quadrature rule is:**
$$\boxed{Q(f) = \tfrac{4}{3}\bigl[f(-\tfrac{1}{2}) + f(\tfrac{1}{2})\bigr] - \tf
rac{2}{3}\,f(0).}$$

**Degree of precision is exactly 3.** Check degree 4:
$$\int_{-1}^{1} x^4\,dx = \tfrac{2}{5}, \qquad Q(x^4) = \tfrac{4}{3}\cdot\tfrac{
1}{16}\cdot 2 - \tfrac{2}{3}\cdot 0 = \tfrac{1}{6}.$$
Since $\tfrac{2}{5} \neq \tfrac{1}{6}$, the rule fails at degree 4. Combined wit
h exactness through degree 3, **the degree of precision is 3**.

### Part 2: Error Representation via the Peano Kernel

Define the error functional $E(f) = \int_{-1}^{1} f\,dx - Q(f)$, which annihilat
es all polynomials of degree $\leq 3$. By the **Peano Kernel Theorem**, for $f \
in C^4[-1,1]$:
$$E(f) = \int_{-1}^{1} K(t)\,f^{(4)}(t)\,dt, \qquad K(t) = E_x\!\left[\frac{(x-t
)_+^3}{3!}\right] = \int_{-1}^{1}\frac{(x-t)_+^3}{6}\,dx - \sum_i w_i\,\frac{(x_
i-t)_+^3}{6}.$$

**Claim: $K(t) \geq 0$ on $[-1,1]$, with $K > 0$ in the interior.**

By the symmetry of the rule ($w_{-1/2}=w_{1/2}$, symmetric nodes), $K(t) = K(-t)
$, so it suffices to check $t \in [0,1]$.

*Case $t \in [\tfrac12, 1]$:* Here $(-\tfrac12 - t)_+ = 0$, $(0-t)_+ = 0$, $(\tf
rac12 - t)_+ = 0$, so
$$K(t) = \int_t^1 \frac{(x-t)^3}{6}\,dx = \frac{(1-t)^4}{24} \geq 0.$$

*Case $t \in [0, \tfrac12]$:* Here $(-\tfrac12-t)_+ = 0$, $(0-t)_+ = 0$, $(\tfra
c12-t)_+ = \tfrac12 - t > 0$, so
$$K(t) = \frac{(1-t)^4}{24} - \frac{4}{3}\cdot\frac{(\tfrac12-t)^3}{6} = \frac{(
1-t)^4}{24} - \frac{2(\tfrac12-t)^3}{9}.$$
Set $u = \tfrac12 - t \in [0,\tfrac12]$, so $1-t = \tfrac12 + u$:
$$K = \frac{(\tfrac12+u)^4}{24} - \frac{2u^3}{9}, \qquad \frac{dK}{du} = \frac{(
\tfrac12+u)^3}{6} - \frac{2u^2}{3}.$$
We show $\frac{dK}{du} \geq 0$: setting $v = \tfrac12 + u \in [\tfrac12, 1]$, th
e condition $(\tfrac12+u)^3 \geq 4u^2$ becomes $v^3 \geq 4(v-\tfrac12)^2$, i.e.,
$$v^3 - 4v^2 + 4v - 1 = (v-1)(v^2 - 3v + 1) \geq 0.$$
The roots of $v^2 - 3v + 1$ are $\tfrac{3\pm\sqrt5}{2} \approx 0.382$ and $2.618
$, both outside $[\tfrac12,1]$, so $v^2-3v+1 < 0$ on $[\tfrac12,1]$. Since $v -
1 \leq 0$ there, the product is $\geq 0$. Hence $\frac{dK}{du} \geq 0$, so $K$ i
s nondecreasing in $u$ (nonincreasing in $t$), giving $K(t) \geq K(\tfrac12) = \
tfrac{1}{384} > 0$ on $[0,\tfrac12]$.

By symmetry, $K(t) \geq 0$ on all of $[-1,1]$. $\square$

**Error constant.** Since $K \geq 0$ and continuous, the weighted mean value the
orem gives, for some $\xi \in (-1,1)$:
$$E(f) = f^{(4)}(\xi)\int_{-1}^{1} K(t)\,dt.$$
Evaluating with $f(x) = x^4$ (so $f^{(4)} \equiv 24$): $E(x^4) = \tfrac{2}{5} -
\tfrac{1}{6} = \tfrac{7}{30}$, hence $\int_{-1}^1 K(t)\,dt = \tfrac{7}{30 \cdot
24} = \tfrac{7}{720}$.

$$\boxed{E(f) = \int_{-1}^{1} f\,dx - Q(f) = \frac{7}{720}\,f^{(4)}(\xi), \quad
\xi \in (-1,1).}$$

### Part 3: Composite Rule — Arbitrary Subdivision

**Setup.** Subdivide $[a,b]$ into $n$ subintervals $[x_{i-1}, x_i]$, $i=1,\dots,
n$, with $x_0 = a$, $x_n = b$, and $h_i = x_i - x_{i-1} > 0$. Define $h = \max_{
1\le i \le n} h_i$.

On each subinterval $[x_{i-1}, x_i]$, apply the simple rule via the affine map $
x = x_{i-1} + \tfrac{h_i}{2}(t+1)$, $t \in [-1,1]$, $dx = \tfrac{h_i}{2}\,dt$. T
he nodes $t = -\tfrac12, 0, \tfrac12$ map to the **quarter points** $x_{i-1} + \
tfrac{h_i}{4}$, $x_{i-1}+\tfrac{h_i}{2}$, $x_{i-1}+\tfrac{3h_i}{4}$:

$$Q_i(f) = \frac{h_i}{2}\left[\frac{4}{3}\bigl(g(-\tfrac12)+g(\tfrac12)\bigr) -
\frac{2}{3}g(0)\right] = \frac{h_i}{2}\,Q(g),$$
where $g(t) = f\!\left(x_{i-1}+\tfrac{h_i}{2}(t+1)\right)$.

**Per-subinterval error.** Since $g^{(4)}(t) = \bigl(\tfrac{h_i}{2}\bigr)^4 f^{(
4)}\!\bigl(x_{i-1}+\tfrac{h_i}{2}(t+1)\bigr)$:
$$E_i(f) := \int_{x_{i-1}}^{x_i} f\,dx - Q_i(f) = \frac{h_i}{2}\,E(g) = \frac{h_
i}{2}\cdot\frac{7}{720}\,g^{(4)}(\eta_i) = \frac{7\,h_i^5}{23040}\,f^{(4)}(\xi_i
)$$
for some $\xi_i \in (x_{i-1}, x_i)$, using $K \geq 0$ and the mean value theorem
.

**Total error.** Summing over all subintervals:
$$\boxed{E_n(f) = \int_a^b f\,dx - \sum_{i=1}^n Q_i(f) = \frac{7}{23040}\sum_{i=
1}^n h_i^5\,f^{(4)}(\xi_i), \quad \xi_i \in (x_{i-1},x_i).}$$

**Convergence bound (arbitrary subdivision).** Let $M_4 = \|f^{(4)}\|_{\infty,[a
,b]}$. Then:
$$|E_n(f)| \leq \frac{7\,M_4}{23040}\sum_{i=1}^n h_i^5 \leq \frac{7\,M_4}{23040}
\,h^4\sum_{i=1}^n h_i = \frac{7\,M_4\,(b-a)}{23040}\,h^4.$$

**Theorem (Convergence).** *If $f \in C^4[a,b]$, then for any sequence of subdiv
isions with $h = \max_i h_i \to 0$:*
$$|E_n(f)| \leq \frac{7\,\|f^{(4)}\|_{\infty}\,(b-a)}{23040}\,h^4 \;\longrightar
row\; 0.$$
*The composite rule converges to $\int_a^b f\,dx$ at rate $O(h^4)$, i.e., fourth
 order in the maximum mesh size, regardless of whether the subdivision is unifor
m.*

**Uniform subdivision (special case).** If $h_i = h = \frac{b-a}{n}$ for all $i$
:
$$|E_n(f)| \leq \frac{7\,M_4\,(b-a)^5}{23040\,n^4} = \frac{7\,M_4\,(b-a)}{23040}
\,h^4.$$

**Asymptotic error form.** For a uniform mesh with $f \in C^4[a,b]$, since $K \g
eq 0$:
$$E_n(f) = \frac{7}{23040}\,h^5\sum_{i=1}^n f^{(4)}(\xi_i) = \frac{7}{23040}\,h^
4\,(b-a)\cdot\frac{1}{n}\sum_{i=1}^n f^{(4)}(\xi_i).$$
As $n\to\infty$, $\frac{1}{n}\sum f^{(4)}(\xi_i) \to \frac{1}{b-a}\int_a^b f^{(4
)}(x)\,dx = \frac{f'''(b)-f'''(a)}{b-a}$, giving the asymptotic error:
$$E_n(f) \sim \frac{7}{23040}\,h^4\bigl(f'''(b) - f'''(a)\bigr).$$

**Summary.** The simple rule $Q(f) = \tfrac{4}{3}[f(-\tfrac12)+f(\tfrac12)] - \t
frac{2}{3}f(0)$ has degree of precision 3 with error $\tfrac{7}{720}f^{(4)}(\xi)
$ on $[-1,1]$. The composite rule over an arbitrary subdivision with max mesh si
ze $h$ converges at $O(h^4)$ with the explicit bound $\frac{7\|f^{(4)}\|_\infty(
b-a)}{23040}h^4$.
