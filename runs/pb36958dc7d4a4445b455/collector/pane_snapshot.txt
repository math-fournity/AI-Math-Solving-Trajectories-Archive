Looking at this problem, I need to determine whether, for a given prime $p$ and
any integer $a$, there exist infinitely many integers $n$ such that $p \mid a^n
+ n$.

**Answer: Yes, for every prime $p$ and every integer $a$, there exist infinitely
 many positive integers $n$ such that $p \mid a^n + n$.**

---

## Proof

Fix a prime $p$ and an integer $a$. We consider two cases.

### Case 1: $p \mid a$

For any positive integer $k$, set $n = kp$. Then:
- $a^n \equiv 0 \pmod{p}$, since $p \mid a$ and $n \geq 1$.
- $n = kp \equiv 0 \pmod{p}$.

Therefore $a^n + n \equiv 0 + 0 = 0 \pmod{p}$, so $p \mid a^n + n$.

Since there are infinitely many choices of $k$, we obtain infinitely many valid
$n$. ✓

### Case 2: $p \nmid a$

Let $r = \operatorname{ord}_p(a)$ be the multiplicative order of $a$ modulo $p$.
 Since $a^{p-1} \equiv 1 \pmod{p}$ by Fermat's little theorem, we have $r \mid (
p-1)$. In particular, $\gcd(r, p) = 1$ (since $r \mid p-1$ and $p$ is prime).

We seek $n$ satisfying $a^n + n \equiv 0 \pmod{p}$, i.e., $a^n \equiv -n \pmod{p
}$.

**Key idea:** Impose $n \equiv 0 \pmod{r}$, which forces $a^n \equiv 1 \pmod{p}$
. The congruence then reduces to $1 + n \equiv 0 \pmod{p}$, i.e., $n \equiv -1 \
pmod{p}$.

Since $\gcd(r, p) = 1$, the **Chinese Remainder Theorem** guarantees that the sy
stem
$$
n \equiv 0 \pmod{r}, \qquad n \equiv -1 \pmod{p}
$$
has a solution $n_0$ modulo $rp$. All integers of the form
$$
n = n_0 + m \cdot rp, \qquad m = 0, 1, 2, \dots
$$
satisfy both congruences simultaneously. For sufficiently large $m$, these are p
ositive integers.

**Verification:** For each such $n$:
- $n \equiv 0 \pmod{r}$ implies $a^n \equiv 1 \pmod{p}$.
- $n \equiv -1 \pmod{p}$ implies $n \equiv -1 \pmod{p}$.
- Therefore $a^n + n \equiv 1 + (-1) = 0 \pmod{p}$.

Since the arithmetic progression $\{n_0 + mrp : m \geq 0\}$ is infinite, there a
re infinitely many valid $n$. ✓

---

### Concrete illustration

- **$p = 3, a = 2$:** $r = \operatorname{ord}_3(2) = 2$. CRT gives $n \equiv 2 \
pmod{6}$, so $n = 2, 8, 14, 20, \dots$ Check: $2^2 + 2 = 6 = 2 \cdot 3$ ✓; $2^8
+ 8 = 264 = 88 \cdot 3$ ✓.

- **$p = 5, a = 3$:** $r = \operatorname{ord}_5(3) = 4$. CRT gives $n \equiv 4 \
pmod{20}$, so $n = 4, 24, 44, \dots$ Check: $3^4 + 4 = 85 = 17 \cdot 5$ ✓; $3^{2
4} + 24 \equiv 1 + 24 = 25 \equiv 0 \pmod{5}$ ✓.

---

### Conclusion

In both cases ($p \mid a$ and $p \nmid a$), we exhibited an infinite arithmetic
progression of positive integers $n$ satisfying $p \mid a^n + n$. The constructi
on in Case 2 relies on the Chinese Remainder Theorem, which applies because the
order $r$ of $a$ modulo $p$ divides $p - 1$ and is therefore coprime to $p$.

**Therefore, for every prime $p$ and every integer $a$, there exist infinitely m
any integers $n$ such that $p \mid a^n + n$.** $\blacksquare$
