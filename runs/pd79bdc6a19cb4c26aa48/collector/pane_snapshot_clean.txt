## Proof

 showing they differ on an isomorphism-invariant property: being **atomic** vers

### Definitions

Recall that in a Boolean algebra $B$:
- An **atom** is a minimal nonzero element: $a \in B$, $a \neq 0$, and whenever
$0 < b \leq a$ then $b = a$.
- $B$ is **atomic** if every nonzero element dominates some atom.
- $B$ is **atomless** if it has no atoms at all.

Both properties are preserved under Boolean algebra isomorphism (an isomorphism
sends atoms to atoms, and reflects the existence of atoms below any given elemen
t). Hence an atomic algebra and an atomless algebra cannot be isomorphic.

### Example 1: $A = \mathcal{P}(\mathbb{N})$

$A$ is the power set of $\mathbb{N}$, a Boolean algebra under union, intersectio
n, and complement.

**Uncountable.** $|A| = 2^{\aleph_0} > \aleph_0$, so $A$ is uncountable.

**Atomic.** For each $n \in \mathbb{N}$, the singleton $\{n\}$ is an atom: any n
onempty subset of $\{n\}$ equals $\{n\}$. Moreover, every nonempty $S \subseteq
\mathbb{N}$ dominates the atom $\{n\}$ for any $n \in S$. Thus $A$ is atomic (in
 fact every element is the join of the atoms below it).

### Example 2: $B = \mathcal{M}/\mathcal{N}$, the Lebesgue measure algebra

Let $\mathcal{M}$ be the $\sigma$-algebra of Lebesgue-measurable subsets of $[0,
1]$, and let $\mathcal{N} \subseteq \mathcal{M}$ be the $\sigma$-ideal of null s
ets (sets of Lebesgue measure $0$). Define
$$B = \mathcal{M}/\mathcal{N} = \{[E] : E \in \mathcal{M}\},$$
where $[E] = \{E \triangle N : N \in \mathcal{N}\}$ is the equivalence class of
$E$ modulo null sets. Operations are induced by union, intersection, and complem
ent:
$$[E] \vee [F] = [E \cup F], \quad [E] \wedge [F] = [E \cap F], \quad \neg[E] =
[[0,1]\setminus E].$$
This is a well-defined Boolean algebra (the standard **measure algebra**), with
$0 = [\varnothing]$ and $1 = [[0,1]]$.

**Uncountable.** The map sending a closed nowhere-dense set to its class is not
needed; more directly: for each $t \in [0,1]$, the interval $[0,t]$ is measurabl
e, and $[0,t] \triangle [0,s]$ has measure $|t-s|$, so $[[0,t]] = [[0,s]]$ iff $
t = s$. Hence $t \mapsto [[0,t]]$ injects $[0,1]$ into $B$, giving $|B| \geq 2^{
\aleph_0}$. Conversely $|\mathcal{M}| = 2^{\aleph_0}$, so $|B| \leq 2^{\aleph_0}
$. Thus $|B| = 2^{\aleph_0}$, uncountable.

**Atomless.** Let $[E] \in B$ be nonzero, i.e. $m(E) > 0$. Split $E$ into two me
asurable subsets of positive measure: for instance, by continuity of measure the

$$0 < [E_1] < [E], \quad 0 < [E_2] < [E],$$
so $[E]$ is not minimal. Since $[E]$ was an arbitrary nonzero element, $B$ has n
o atoms: $B$ is atomless.

Both algebras have cardinality $2^{\aleph_0}$, hence are uncountable.
