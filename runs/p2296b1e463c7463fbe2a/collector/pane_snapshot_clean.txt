## Solution

**Answer: No.** There need not exist an integer $b$ with $f(b)=0$.

### Counterexample

Let $f(X) = X^2 + 1$ (monic, integer coefficients) and let $p = 5$ (an odd prime
).

**Claim.** For every positive integer $m$, there exists an integer $a$ with $a^2
 + 1 \equiv 0 \pmod{5^m}$, yet $f(b)=0$ has no integer solution.

### Proof of the claim (Hensel lifting)

We construct, by induction on $m$, integers $a_m$ with $a_m^2 + 1 \equiv 0 \pmod
{5^m}$ and $a_m \equiv 2 \pmod 5$.

**Base case** $m=1$: Take $a_1 = 2$. Then $2^2 + 1 = 5 \equiv 0 \pmod 5$. ✓

**Inductive step**: Suppose $a_m^2 + 1 \equiv 0 \pmod{5^m}$ and $a_m \equiv 2 \p
mod 5$. Write $a_m^2 + 1 = c \cdot 5^m$ for some integer $c$. Set $a_{m+1} = a_m
 + t \cdot 5^m$ with $t \in \{0,1,2,3,4\}$ to be chosen. Then

$$a_{m+1}^2 + 1 = a_m^2 + 2 a_m t \cdot 5^m + t^2 \cdot 5^{2m} + 1 = 5^m\!\bigl(
c + 2 a_m t + t^2 \cdot 5^m\bigr).$$

For divisibility by $5^{m+1}$ we need $c + 2 a_m t + t^2 \cdot 5^m \equiv 0 \pmo
d 5$. Since $m \geq 1$, the term $t^2 \cdot 5^m \equiv 0 \pmod 5$, so the condit
ion reduces to

$$c + 2 a_m\, t \equiv 0 \pmod 5.$$

Because $a_m \equiv 2 \pmod 5$, we have $2 a_m \equiv 4 \not\equiv 0 \pmod 5$, s
o $2a_m$ is invertible modulo $5$. Hence there is a **unique** $t \pmod 5$ satis
fying the congruence. Choosing that $t \in \{0,\dots,4\}$ gives $a_{m+1}^2 + 1 \
equiv 0 \pmod{5^{m+1}}$, and $a_{m+1} \equiv a_m \equiv 2 \pmod 5$. ✓

By induction, for every $m \geq 1$ there exists an integer $a_m$ with $f(a_m) \e
quiv 0 \pmod{5^m}$.

### No integer root

If $f(b) = 0$ for some integer $b$, then $b^2 + 1 = 0$, i.e. $b^2 = -1$. But $b^
2 \geq 0$ for every integer $b$, so this is impossible.

### Conclusion

The hypothesis — that $f$ has a root modulo $p^m$ for every $m$ — is equivalent
(via Hensel's lemma, when a simple root exists mod $p$) to $f$ having a root in
the ring $\mathbb{Z}_p$ of $p$-adic integers. A $p$-adic integer need not be a r
ational integer, so the existence of $p$-adic roots does **not** force the exist
ence of integer roots. The polynomial $X^2 + 1$ over $\mathbb{Z}_5$ furnishes an
 explicit counterexample.

**The answer is no.**
