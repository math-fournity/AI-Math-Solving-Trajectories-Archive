# Proof

**Claim:** Yes. If $f$ is a measurable function on a $\sigma$-finite measure spa
ce $(X, \mathcal{F}, \mu)$ such that $f\varphi \in L^1(\mu)$ for every $\varphi
\in L^2(\mu)$, then $f \in L^2(\mu)$.

---

**Step 1: The multiplication operator is bounded.**

Define $T: L^2 \to L^1$ by $T(\varphi) = f\varphi$. This is well-defined and lin
ear by hypothesis. We show $T$ is bounded using the **closed graph theorem** (ap
plicable since $L^2$ and $L^1$ are Banach spaces).

Suppose $\varphi_n \to \varphi$ in $L^2$ and $T(\varphi_n) = f\varphi_n \to \psi
$ in $L^1$. Passing to a subsequence, we may assume $\varphi_{n_k} \to \varphi$
a.e. (from $L^2$ convergence) and $f\varphi_{n_k} \to \psi$ a.e. (from $L^1$ con
vergence). But then $f\varphi_{n_k} \to f\varphi$ a.e. (since $\varphi_{n_k} \to
 \varphi$ a.e.), so $\psi = f\varphi$ a.e. The graph of $T$ is closed, hence $T$
 is bounded: there exists $C > 0$ such that

$$\|f\varphi\|_1 \le C\|\varphi\|_2 \quad \text{for all } \varphi \in L^2. \tag{
$\star$}$$

**Step 2: $f$ is finite a.e. and a local $L^2$ bound.**

If $f = \infty$ on a set $E$ with $0 < \mu(E) < \infty$, then $\varphi = \mathbf
{1}_E \in L^2$ but $f\varphi \notin L^1$, contradicting the hypothesis. So $f$ i
s finite a.e.

For any set $E$ with $\mu(E) < \infty$ and any $n \in \mathbb{N}$, set $\varphi
= \bar{f}\,\mathbf{1}_{E \cap \{|f| \le n\}}$. Then $|\varphi|^2 = |f|^2 \mathbf
{1}_{E \cap \{|f|\le n\}} \le n^2 \mu(E) < \infty$, so $\varphi \in L^2$. Applyi
ng $(\star)$:

$$\int_{E \cap \{|f| \le n\}} |f|^2\,d\mu = \|f\varphi\|_1 \le C\|\varphi\|_2 =
C\left(\int_{E \cap \{|f| \le n\}} |f|^2\,d\mu\right)^{1/2}.$$

Dividing (the case where the integral is $0$ is trivial):

$$\left(\int_{E \cap \{|f| \le n\}} |f|^2\,d\mu\right)^{1/2} \le C.$$

By monotone convergence ($n \to \infty$), using that $f$ is finite a.e.:

$$\int_E |f|^2\,d\mu \le C^2 \quad \text{for every } E \text{ with } \mu(E) < \i
nfty. \tag{$\star\star$}$$

**Step 3: Global $L^2$ bound via $\sigma$-finiteness.**

Since $(X, \mu)$ is $\sigma$-finite, write $X = \bigcup_{n=1}^\infty E_n$ with $
\mu(E_n) < \infty$ and $E_n \nearrow X$. By monotone convergence and $(\star\sta
r)$:

$$\int_X |f|^2\,d\mu = \lim_{n \to \infty} \int_{E_n} |f|^2\,d\mu \le C^2 < \inf
ty.$$

Therefore $f \in L^2(\mu)$ with $\|f\|_2 \le C$. $\blacksquare$

---

**Remark.** The $\sigma$-finiteness (or more generally, semi-finiteness) of the
measure space is essential. On a degenerate space where $L^2 = \{0\}$ (e.g., a s
ingle point with infinite measure), the hypothesis is vacuously satisfied by any
 $f$, yet $f$ need not lie in $L^2$. On any $\sigma$-finite measure space—includ
ing the standard case $L^2(\mathbb{R}^n)$—the implication holds.
