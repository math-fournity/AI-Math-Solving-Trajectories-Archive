## Solution

**Fixed points of E.** Solving $E(x)=x$: $\frac{16x+7}{4x+4}=x \Rightarrow 4x^2-
12x-7=0 \Rightarrow x=\frac{12\pm 16}{8}$, giving $x=\tfrac{7}{2}$ and $x=-\tfra
c{1}{2}$. The unique positive fixed point is $L=\tfrac{7}{2}$.

**Part 1: Finding R.**

Compute
$$E(x)-x = \frac{16x+7-x(4x+4)}{4x+4} = \frac{-4x^2+12x+7}{4x+4} = \frac{-4(x-\t
frac{7}{2})(x+\tfrac{1}{2})}{4(x+1)} = \frac{-(x-\tfrac{7}{2})(x+\tfrac{1}{2})}{
x+1}.$$

For $x>0$: $(x+\tfrac12)>0$ and $(x+1)>0$, so $\operatorname{sgn}(E(x)-x) = -\op
eratorname{sgn}(x-\tfrac72)$. Hence
$$E(x) > x \iff x < \tfrac{7}{2}, \qquad E(x) < x \iff x > \tfrac{7}{2}.$$

The derivative is $E'(x) = \frac{36}{(4x+4)^2} = \frac{9}{4(x+1)^2} > 0$, so $E$
 is strictly increasing on $(0,\infty)$.

If $0 < a_1 < \tfrac{7}{2}$: then $a_2 = E(a_1) > a_1$, and since $E$ is increas
ing, $a_2 = E(a_1) < E(\tfrac72)=\tfrac72$. By induction, $a_n < \tfrac72$ and $
a_{n+1}>a_n$ for all $n$. So the sequence is strictly increasing.

If $a_1 = \tfrac72$: $a_2 = \tfrac72 = a_1$, not strictly increasing.

If $a_1 > \tfrac72$: $a_2 < a_1$, not increasing.

Therefore the set of valid initial concentrations is $(0,\tfrac72)$, and
$$R = \sup(0,\tfrac{7}{2}) = \tfrac{7}{2}.$$

**Part 2: Finding k.**

With $a_1=3$, $b_1=4$: since $a_1 < \tfrac72 < b_1$, Batch A increases toward $\
tfrac72$ and Batch B decreases toward $\tfrac72$, so $b_n > a_n$ for all $n$ (mo
notonicity of $E$ preserves the order).

Compute the exact recurrence for the difference:
$$b_{n+1}-a_{n+1} = E(b_n)-E(a_n) = \frac{(16b_n+7)(4a_n+4)-(16a_n+7)(4b_n+4)}{(
4b_n+4)(4a_n+4)}.$$

The numerator simplifies to $36(b_n-a_n)$ and the denominator is $16(b_n+1)(a_n+
1)$, giving
$$b_{n+1}-a_{n+1} = \frac{9}{4(a_n+1)(b_n+1)}\,(b_n-a_n).$$

Define $r_n = \frac{b_{n+1}-a_{n+1}}{b_n-a_n} = \frac{9}{4(a_n+1)(b_n+1)}$. Then
$$b_n - a_n = (b_1-a_1)\prod_{i=1}^{n-1} r_i.$$

The condition $b_n-a_n \le k^{n-1}(b_1-a_1)$ for all $n\ge 1$ is equivalent to $
\prod_{i=1}^{n-1} r_i \le k^{n-1}$ for all $n\ge 2$, i.e., $k \ge \bigl(\prod_{i
=1}^{n-1} r_i\bigr)^{1/(n-1)}$ for all $n\ge 2$. The smallest such $k$ is
$$k = \sup_{n\ge 2}\Bigl(\prod_{i=1}^{n-1} r_i\Bigr)^{1/(n-1)}.$$

**The sequence $\{r_n\}$ is decreasing.** Since $a_n \nearrow \tfrac72$ and $b_n
 \searrow \tfrac72$, the product $(a_n+1)(b_n+1) = a_n b_n + a_n + b_n + 1$. At
$n=1$: $(4)(5)=20$. The limit is $(\tfrac92)(\tfrac92)=\tfrac{81}{4}=20.25$. One
 checks $(a_n+1)(b_n+1)$ is increasing (e.g., at $n=2$: $a_2=\tfrac{55}{16},\, b
_2=\tfrac{71}{20}$, product $=\tfrac{71}{16}\cdot\tfrac{91}{20}=\tfrac{6461}{320
}\approx 20.19 > 20$). Hence $r_n = \frac{9}{4(a_n+1)(b_n+1)}$ is **strictly dec
reasing**, with $r_1 = \frac{9}{4\cdot 4\cdot 5} = \frac{9}{80}$ being the large
st term.

Since $r_1 > r_2 > r_3 > \cdots$, the geometric mean $\bigl(\prod_{i=1}^{m} r_i\
bigr)^{1/m}$ is maximized at $m=1$ (adding smaller values lowers the mean). Ther
efore
$$k = r_1 = \frac{9}{80}.$$

This is tight: for $n=2$, $b_2-a_2 = r_1(b_1-a_1) = \tfrac{9}{80}(b_1-a_1) = k^1
(b_1-a_1)$, achieving equality.

**Final computation.**
$$k^{-1} = \frac{80}{9}, \qquad R + k^{-1} = \frac{7}{2} + \frac{80}{9} = \frac{
63}{18} + \frac{160}{18} = \frac{223}{18}.$$

$$\boxed{R + k^{-1} = \dfrac{223}{18}}$$
