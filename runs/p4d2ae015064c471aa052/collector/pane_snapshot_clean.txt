## 解答

**问题重述：** 找出所有满足 $n > 2$ 且 $n \le 10{,}000{,}000$ 的自然数 $n$，使得
每一个与 $n$ 互素且满足 $1 < m < n$ 的数 $m$ 都是素数。

---

### 关键观察

设 $q$ 为**不整除** $n$ 的最小素数。那么所有小于 $q$ 的素数都整除 $n$。

与 $n$ 互素的最小**合数**为 $q^2$（因为 $q$ 是不整除 $n$ 的最小素数，$q^2$ 与 $n
$ 互素，且任何与 $n$ 互素的更小合数都需要其所有素因子 $\geq q$，使得该合数 $\geq
 q^2$）。

**该条件等价于** $q^2 \geq n$，即不存在与 $n$ 互素的合数 $m$ 满足 $1 < m < n$。

由于所有小于 $q$ 的素数都整除 $n$，因此 $n$ 是 $P = \prod_{p < q} p$（即 $q$ 之
前的素数乘积）的倍数。所以我们需要：

$$P \mid n, \quad n \le q^2, \quad n > 2, \quad q \nmid n.$$

---

### 情况分析

**$q = 2$：** $P = 1$，$n \le 4$，$n$ 为奇数，$n > 2$。$\Rightarrow n = 3$。

**$q = 3$：** $P = 2$，$n \le 9$，$2\mid n$，$3\nmid n$。$\Rightarrow n \in \{4,
 8\}$。

**$q = 5$：** $P = 6$，$n \le 25$，$6\mid n$，$5\nmid n$。$\Rightarrow n \in \{6
, 12, 18, 24\}$。

**$q = 7$：** $P = 30$，$n \le 49$，$30\mid n$，$7\nmid n$。$\Rightarrow n = 30$
。

**$q = 11$：** $P = 210$，$n \le 121$。由于 $210 > 121$，无解。

**$q \ge 11$：** $P$（素数乘积）的增长速度远快于 $q^2$，因此 $P > q^2$ 始终成立
，无解。

---

### 验证

| $n$ | 与 $n$ 互素的 $m$，$1<m<n$ | 均为素数？ |
|-----|---------------------------|----------|
| 3 | $\{2\}$ | ✓ |
| 4 | $\{3\}$ | ✓ |
| 6 | $\{5\}$ | ✓ |
| 8 | $\{3,5,7\}$ | ✓ |
| 12 | $\{5,7,11\}$ | ✓ |
| 18 | $\{5,7,11,13,17\}$ | ✓ |
| 24 | $\{5,7,11,13,17,19,23\}$ | ✓ |
| 30 | $\{7,11,13,17,19,23,29\}$ | ✓ |

---

### 结论

所有满足条件的自然数 $n > 2$（且 $n \le 10{,}000{,}000$）为：

$$\boxed{n \in \{3,\, 4,\, 6,\, 8,\, 12,\, 18,\, 24,\, 30\}}.$$
