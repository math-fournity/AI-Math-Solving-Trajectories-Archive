## Setup and verification that $X = \omega_1$ is locally compact Hausdorff

The order topology on any linearly ordered set is Hausdorff. For local compactne
ss: each $\alpha < \omega_1$ has the compact neighborhood $[0, \alpha]$, since $
\omega_1$ is well-ordered (hence has the least-upper-bound property), and closed
 intervals in a linearly ordered set with the LUB property are compact in the or
der topology. The interval $(\beta, \alpha]$ (for any $\beta < \alpha$) is an op
en neighborhood of $\alpha$ contained in $[0, \alpha]$. So $X$ is locally compac
t Hausdorff.

## The argument

**Suppose for contradiction** that $N$ is a closed neighborhood of $\Delta X$ in
 $X \times X$ with $\pi_1|_N : N \to X$ proper. Then there exists an open set $U
$ with $\Delta X \subset U \subset N$.

**Step 1: Each limit ordinal forces a square inside $U$.**

For each limit ordinal $\lambda < \omega_1$, the point $(\lambda, \lambda) \in U
$. Since $U$ is open in $X \times X$, there exist basic open neighborhoods $A \n
i \lambda$ and $B \ni \lambda$ with $A \times B \subset U$. In the order topolog
y on $\omega_1$, the basic open neighborhoods of a limit ordinal $\lambda$ are o
f the form $(\beta, \lambda]$ for $\beta < \lambda$. So $A \supset (\beta_1, \la
mbda]$ and $B \supset (\beta_2, \lambda]$ for some $\beta_1, \beta_2 < \lambda$.
 Setting $\beta_\lambda = \max(\beta_1, \beta_2) < \lambda$:

$$(\beta_\lambda, \lambda] \times (\beta_\lambda, \lambda] \subset U \subset N.$
$

**Step 2: Apply Fodor's Lemma (the Pressing Down Lemma).**

The set $S$ of countable limit ordinals is a closed unbounded (club) subset of $
\omega_1$, hence stationary. The function $f: S \to \omega_1$ defined by $f(\lam
bda) = \beta_\lambda$ is **regressive**: $f(\lambda) < \lambda$ for all $\lambda
 \in S$.

By Fodor's lemma, there exists a stationary (hence **unbounded**) subset $T \sub
set S$ and a fixed $\gamma_0 < \omega_1$ such that $\beta_\lambda = \gamma_0$ fo
r all $\lambda \in T$.

**Step 3: Derive the contradiction.**

For every $\lambda \in T$ with $\lambda > \gamma_0 + 1$:

$$\gamma_0 + 1 \in (\gamma_0, \lambda], \quad \lambda \in (\gamma_0, \lambda] \i
mplies (\gamma_0 + 1, \lambda) \in (\gamma_0, \lambda] \times (\gamma_0, \lambda
] \subset N.$$

Since $T$ is unbounded in $\omega_1$, the set $\{\lambda \in T : \lambda > \gamm
a_0 + 1\}$ is unbounded. Therefore:

$$N \cap \bigl(\{\gamma_0 + 1\} \times \omega_1\bigr) \;\supset\; \bigl\{(\gamma
_0 + 1, \lambda) : \lambda \in T,\; \lambda > \gamma_0 + 1\bigr\},$$

which is **unbounded** in $\{\gamma_0 + 1\} \times \omega_1$, hence **not compac
t**.

But $\{\gamma_0 + 1\}$ is a compact subset of $X$ (a singleton). By properness o

$$(\pi_1|_N)^{-1}\bigl(\{\gamma_0 + 1\}\bigr) = N \cap \bigl(\{\gamma_0 + 1\} \t

must be compact. This contradicts the fact that it is unbounded.

## Conclusion

The contradiction shows that no closed neighborhood $N$ of $\Delta \omega_1$ can
 have $\pi_1|_N$ proper (and hence cannot have both projections proper). The key
 mechanism is:

1. Any neighborhood of the diagonal must contain "squares" $(\beta_\lambda, \lam
bda]^2$ around each limit ordinal $\lambda$.
2. The map $\lambda \mapsto \beta_\lambda$ is regressive, so Fodor's lemma force
s it to be constant ($= \gamma_0$) on an unbounded set of limit ordinals.
3. This forces $N$ to contain $\{(\gamma_0+1, \lambda)\}$ for unboundedly many $
\lambda$, making the fiber over $\gamma_0+1$ non-compact and violating propernes
s.

The answer is **No**: there exists a locally compact Hausdorff space (namely $\o
mega_1$ with the order topology) whose diagonal admits no closed neighborhood wi
th proper projections.
