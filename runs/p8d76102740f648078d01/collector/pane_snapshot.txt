# Solution

**Yes, such a function exists.**

## Setup: Finite Blaschke Products

Since $f$ is analytic in a region containing $|z|\le 1$, satisfies $|f(z)|=1$ on
 $|z|=1$, and has only finitely many zeros in the disk, $f$ must be a **finite B
laschke product** (up to a unimodular constant):

$$f(z) = e^{i\theta}\prod_{k=1}^{n}\frac{z-a_k}{1-\overline{a_k}\,z}.$$

The only zero of $f$ in $|z|\le 1$ is $z_0=\tfrac12+\tfrac{i}{2}$ with order 3,
so we must have

$$f(z)=e^{i\theta}\left(\frac{z-z_0}{1-\overline{z_0}\,z}\right)^{\!3},\qquad z_
0=\tfrac12+\tfrac{i}{2},\quad \overline{z_0}=\tfrac12-\tfrac{i}{2}.$$

## Checking the analyticity condition

The only pole of the Blaschke factor is at $z=1/\overline{z_0}$. Since $|z_0|^2=
\tfrac12$, we have $|1/\overline{z_0}|=1/|z_0|=\sqrt{2}>1$, so the pole lies str
ictly outside the closed unit disk. Hence $f$ is analytic in a neighborhood of $
|z|\le 1$. ✓

## Checking $|f(z)|=1$ on $|z|=1$

For $|z|=1$ (so $\bar z = 1/z$):

$$|z-z_0|^2=(z-z_0)(\bar z-\bar z_0)=(z-z_0)\!\left(\tfrac1z-\bar z_0\right)=1-z
\bar z_0-\tfrac{z_0}{z}+|z_0|^2,$$

$$|1-\bar z_0\,z|^2=(1-\bar z_0 z)(1-z_0\bar z)=(1-\bar z_0 z)\!\left(1-\tfrac{z
_0}{z}\right)=1-\tfrac{z_0}{z}-\bar z_0 z+|z_0|^2.$$

These are equal, so $\left|\frac{z-z_0}{1-\bar z_0 z}\right|=1$ on $|z|=1$, givi
ng $|f(z)|=|e^{i\theta}|\cdot 1^3=1$. ✓

## Computing $f'(0)$ and determining $\theta$

Let $g(z)=\frac{z-z_0}{1-\bar z_0 z}$, so $f(z)=e^{i\theta}\,g(z)^3$ and $f'(z)=
e^{i\theta}\cdot 3\,g(z)^2\cdot g'(z)$.

**Values at $z=0$:**
- $g(0)=-z_0=-\tfrac12-\tfrac{i}{2}$.
- $g'(z)=\frac{1-|z_0|^2}{(1-\bar z_0 z)^2}$, so $g'(0)=1-|z_0|^2=1-\tfrac12=\tf
rac12$.
- $g(0)^2=\left(-\tfrac12-\tfrac{i}{2}\right)^2=\left(\tfrac12+\tfrac{i}{2}\righ
t)^2=\tfrac14+\tfrac{i}{2}-\tfrac14=\tfrac{i}{2}$.

Therefore:

$$f'(0)=e^{i\theta}\cdot 3\cdot \tfrac{i}{2}\cdot\tfrac12=e^{i\theta}\cdot\frac{
3i}{4}.$$

Requiring $f'(0)=\tfrac34$ gives:

$$e^{i\theta}\cdot\frac{3i}{4}=\frac34\implies e^{i\theta}\cdot i=1\implies e^{i
\theta}=\frac1i=-i.$$

Since $|-i|=1$, this is a valid unimodular constant (corresponding to $\theta=-\
pi/2$). ✓

## The function

$$\boxed{f(z)=-i\left(\frac{z-\tfrac12-\tfrac{i}{2}}{1-\left(\tfrac12-\tfrac{i}{
2}\right)z}\right)^{\!3}}$$

satisfies all four conditions: analyticity near $|z|\le 1$, a unique zero of ord
er 3 at $\tfrac12+\tfrac{i}{2}$, unit modulus on $|z|=1$, and $f'(0)=\tfrac34$.
