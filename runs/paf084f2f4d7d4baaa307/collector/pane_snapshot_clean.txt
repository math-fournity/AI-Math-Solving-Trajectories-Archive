## Proof

**The statement is TRUE.**

Let $S_n = Z_1 + Z_2 + \cdots + Z_n$. We show $\frac{S_n}{\sqrt{n}} \to 0$ almos
t surely.

**Key observation.** Note that $P(Z_n \neq 0) = P(Z_n = n) + P(Z_n = -n) = \frac
{1}{2n^2} + \frac{1}{2n^2} = \frac{1}{n^2}$.

Since
$$\sum_{n=1}^{\infty} P(Z_n \neq 0) = \sum_{n=1}^{\infty} \frac{1}{n^2} < \infty
,$$
the **Borel–Cantelli lemma** (first part, which requires no independence assumpt
ion) gives
$$P(Z_n \neq 0 \text{ infinitely often}) = 0.$$

Therefore, with probability $1$, only finitely many of the $Z_n$ are nonzero. Th
at is, there exists a random integer $N_0 = N_0(\omega)$ such that for all $n \g
eq N_0$, $Z_n(\omega) = 0$.

**Consequence for $S_n$.** For $n \geq N_0$,
$$S_n = \sum_{k=1}^{n} Z_k = \sum_{k=1}^{N_0} Z_k + \sum_{k=N_0+1}^{n} Z_k = \su
m_{k=1}^{N_0} Z_k,$$
since every $Z_k = 0$ for $k > N_0$. Thus $S_n$ is eventually constant (a.s.); d
enote this eventual constant value by $C(\omega) = \sum_{k=1}^{N_0(\omega)} Z_k(
\omega)$, which is a finite random variable (a finite sum of finite values).

**Conclusion.** For $n \geq N_0$,
$$\frac{S_n}{\sqrt{n}} = \frac{C(\omega)}{\sqrt{n}} \to 0 \quad \text{as } n \to
 \infty,$$
since $C(\omega)$ is fixed (finite) and $\sqrt{n} \to \infty$.

Hence
$$\lim_{n \to \infty} \frac{1}{\sqrt{n}}(Z_1 + \cdots + Z_n) = 0 \quad \text{a.s
.} \qquad \blacksquare$$
