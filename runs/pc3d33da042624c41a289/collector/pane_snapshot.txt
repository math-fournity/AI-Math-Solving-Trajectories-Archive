Looking at this problem, I need to determine whether there exists a probability
measure Q on (Ω, Σ) such that the law of X under Q has density f_{X|Y}(·|y).

**Answer: Yes, such a probability measure Q exists.**

## Proof

**Step 1: f_{X|Y}(·|y) is a valid probability density.**

Fix y with f_Y(y) > 0.

- *Non-negativity:* f_{X|Y}(x|y) = f_{X,Y}(x,y)/f_Y(y) ≥ 0, since f_{X,Y} ≥ 0 an
d f_Y(y) > 0.

- *Normalization:* By definition of the marginal density,
$$\int_{\mathbb{R}} f_{X|Y}(x \mid y)\,dx = \int_{\mathbb{R}} \frac{f_{X,Y}(x,y)
}{f_Y(y)}\,dx = \frac{1}{f_Y(y)}\int_{\mathbb{R}} f_{X,Y}(x,y)\,dx = \frac{f_Y(y
)}{f_Y(y)} = 1.$$

So μ_y(S) := ∫_S f_{X|Y}(x|y) dx defines a probability measure on (ℝ, B(ℝ)).

**Step 2: Support compatibility.**

We need the support of f_{X|Y}(·|y) to be contained (up to Lebesgue-null sets) i
n the support of f_X, so that the change-of-measure construction below is valid.

*Claim:* For Lebesgue-a.e. y with f_Y(y) > 0, the set N_y := {x : f_X(x) = 0, f_
{X,Y}(x,y) > 0} has Lebesgue measure zero.

*Proof of claim:* For any x with f_X(x) = 0, we have ∫_ℝ f_{X,Y}(x,t) dt = 0, so
 f_{X,Y}(x,t) = 0 for Lebesgue-a.e. t. Consider the set A := {(x,t) : f_X(x) = 0
, f_{X,Y}(x,t) > 0}. By Fubini's theorem, the 2-dimensional Lebesgue measure of
A is zero (each x-section has t-measure zero). Applying Fubini again, for Lebesg
ue-a.e. y, the x-section {x : (x,y) ∈ A} = N_y has Lebesgue measure zero. ∎

Thus for a.e. y, f_{X|Y}(x|y) = 0 for a.e. x with f_X(x) = 0, which is exactly t
he condition needed.

**Step 3: Construction of Q via Radon–Nikodym derivative.**

Define g: Ω → [0,∞) by
$$g(\omega) = \begin{cases} \frac{f_{X|Y}(X(\omega) \mid y)}{f_X(X(\omega))} & \
text{if } f_X(X(\omega)) > 0, \\ 0 & \text{if } f_X(X(\omega)) = 0. \end{cases}$
$

Since X is Σ-measurable and f_{X|Y}(·|y), f_X are Borel functions, g is Σ-measur
able.

Define Q on (Ω, Σ) by
$$Q(A) = \int_A g\,dP, \quad A \in \Sigma.$$

**Step 4: Verification.**

*(a) Q is a probability measure:* Q is non-negative and countably additive (as a
n integral of a non-negative measurable function). We check normalization. Using
 the change-of-variables formula (the pushforward of P under X has density f_X):

$$Q(\Omega) = \int_\Omega g\,dP = \int_{\mathbb{R}} \frac{f_{X|Y}(x \mid y)}{f_X
(x)} \cdot \mathbf{1}_{\{f_X > 0\}}(x) \cdot f_X(x)\,dx = \int_{\{f_X > 0\}} f_{
X|Y}(x \mid y)\,dx.$$

By Step 2, f_{X|Y}(x|y) = 0 for a.e. x with f_X(x) = 0, so
$$\int_{\{f_X > 0\}} f_{X|Y}(x \mid y)\,dx = \int_{\mathbb{R}} f_{X|Y}(x \mid y)
\,dx = 1.$$

Hence Q(Ω) = 1. ✓

*(b) Q(X ∈ S) = ∫_S f_{X|Y}(x|y) dx for every Borel S ⊆ ℝ:*

$$Q(X \in S) = \int_\Omega \mathbf{1}_{\{X \in S\}} \cdot g\,dP = \int_{\mathbb{
R}} \mathbf{1}_S(x) \cdot \frac{f_{X|Y}(x \mid y)}{f_X(x)} \cdot \mathbf{1}_{\{f
_X > 0\}}(x) \cdot f_X(x)\,dx$$
$$= \int_{S \cap \{f_X > 0\}} f_{X|Y}(x \mid y)\,dx = \int_S f_{X|Y}(x \mid y)\,
dx,$$

where the last equality again uses that f_{X|Y}(x|y) = 0 for a.e. x ∉ {f_X > 0}
(Step 2). ✓

**Conclusion:** For every y with f_Y(y) > 0 (outside a Lebesgue-null exceptional
 set), the probability measure Q defined by the Radon–Nikodym derivative

$$\frac{dQ}{dP} = \frac{f_{X|Y}(X \mid y)}{f_X(X)}$$

satisfies Q(X ∈ S) = ∫_S f_{X|Y}(x|y) dx for all Borel S ⊆ ℝ. Therefore, such a
probability measure Q exists. $\blacksquare$
