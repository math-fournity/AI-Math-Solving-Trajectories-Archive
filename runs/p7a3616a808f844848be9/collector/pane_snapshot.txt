Looking at this problem, I need to determine whether averaging two estimators wi
th equal MSE that are a.s. distinct yields a strictly better estimator.

**Answer: Yes.** The estimator $\hat{\theta} = \tfrac{1}{2}(\hat{\theta}_1 + \ha
t{\theta}_2)$ has strictly smaller MSE than $\hat{\theta}_1$ (and $\hat{\theta}_
2$) for every $\theta$.

---

### Proof

Fix $\theta \in \mathbb{R}$. Define the errors $e_i := \hat{\theta}_i - \theta$
for $i = 1, 2$, and let
$$\sigma^2(\theta) := E_{X|\theta}(e_1^2) = E_{X|\theta}(e_2^2),$$
which is the common MSE by condition (1).

**Step 1: $\sigma^2(\theta) > 0$.**

If $\sigma^2(\theta) = 0$, then $E(e_i^2) = 0$ implies $e_i = 0$ a.s., so $\hat{
\theta}_1 = \theta = \hat{\theta}_2$ a.s., giving $P_{\theta|X}(\hat{\theta}_1 =
 \hat{\theta}_2) = 1$, contradicting condition (2). Hence $\sigma^2(\theta) > 0$
.

**Step 2: Strict inequality in Cauchy–Schwarz.**

By the Cauchy–Schwarz inequality,
$$E(e_1 e_2) \leq \sqrt{E(e_1^2)\,E(e_2^2)} = \sigma^2(\theta).$$

Equality holds if and only if $e_1 = c\, e_2$ a.s. for some constant $c$. Since
$E(e_1^2) = E(e_2^2) = \sigma^2$, equality forces $c^2 = 1$, i.e., $c = \pm 1$.

- If $c = 1$: $e_1 = e_2$ a.s., so $\hat{\theta}_1 = \hat{\theta}_2$ a.s., contr
adicting condition (2).
- If $c = -1$: $E(e_1 e_2) = E(e_1 \cdot (-e_1)) = -\sigma^2(\theta) < \sigma^2(
\theta)$ (since $\sigma^2 > 0$), so equality in the *upper* bound is not achieve
d.

In all cases consistent with condition (2), we have the **strict** inequality:
$$E(e_1 e_2) < \sigma^2(\theta).$$

**Step 3: MSE of the average.**

Set $\hat{\theta} := \tfrac{1}{2}(\hat{\theta}_1 + \hat{\theta}_2)$, with error
$e := \hat{\theta} - \theta = \tfrac{1}{2}(e_1 + e_2)$. Then:
$$E(e^2) = \frac{1}{4}E(e_1^2) + \frac{1}{4}E(e_2^2) + \frac{1}{2}E(e_1 e_2) = \
frac{\sigma^2(\theta)}{2} + \frac{E(e_1 e_2)}{2}.$$

Applying the strict inequality from Step 2:
$$E(e^2) < \frac{\sigma^2(\theta)}{2} + \frac{\sigma^2(\theta)}{2} = \sigma^2(\t
heta) = E_{X|\theta}(\hat{\theta}_1 - \theta)^2.$$

**Conclusion.**

Since $\theta$ was arbitrary, for every $\theta \in \mathbb{R}$:
$$E_{X|\theta}(\hat{\theta} - \theta)^2 < E_{X|\theta}(\hat{\theta}_1 - \theta)^
2.$$

The estimator $\hat{\theta} = \tfrac{1}{2}(\hat{\theta}_1 + \hat{\theta}_2)$ str
ictly dominates both $\hat{\theta}_1$ and $\hat{\theta}_2$ in MSE at every $\the
ta$. $\blacksquare$
