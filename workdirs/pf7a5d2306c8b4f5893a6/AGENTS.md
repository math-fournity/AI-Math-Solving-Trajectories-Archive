# Problem

A specialized logistics company uses a four-digit security code, $N = \overline{abcd}$, to authorize high-value shipments. The code is composed of four digits ($a, b, c, d$), none of which can be zero.

The company’s encryption protocol requires that the four digits satisfy a specific balance equation based on their values. To verify a code, the security system first calculates an "odd-weighted product" by taking each digit, multiplying it by 2, subtracting 1, and then finding the product of these four results.

For the code to be valid, this "odd-weighted product" must be exactly equal to one less than twice the value of the product of the four individual digits. 

Mathematically, the digits must satisfy:
$(2a - 1)(2b - 1)(2c - 1)(2d - 1) = 2(a \times b \times c \times d) - 1$

How many unique four-digit codes $N$ exist that satisfy these security requirements?
