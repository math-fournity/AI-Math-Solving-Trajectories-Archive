## Solution

Let $a = \frac{p}{q}$, $b = \frac{q}{r}$, $c = \frac{r}{p}$. Note that $abc = 1$
, so
$$\frac{1}{a}+\frac{1}{b}+\frac{1}{c} = \frac{bc+ca+ab}{abc} = ab+bc+ca.$$
Let $S = a+b+c$ and $T = ab+bc+ca = \frac{1}{a}+\frac{1}{b}+\frac{1}{c}$. We see
k $S = \frac{p}{q}+\frac{q}{r}+\frac{r}{p}$.

**First equation.** Expanding:
$$(p+q)(q+r)(r+p) = 2pqr + p^2q + pq^2 + p^2r + pr^2 + q^2r + qr^2.$$
Dividing by $pqr$:
$$\frac{(p+q)(q+r)(r+p)}{pqr} = 2 + \frac{p}{r}+\frac{q}{r}+\frac{p}{q}+\frac{r}
{q}+\frac{q}{p}+\frac{r}{p} = 2 + S + T = 24.$$
Thus $S + T = 22$.

**Second equation.** Expanding:
$$(p-2q)(q-2r)(r-2p) = -7pqr - 2p^2q + 4p^2r - 2pr^2 + 4pq^2 - 2q^2r + 4qr^2.$$
Dividing by $pqr$:
$$\frac{(p-2q)(q-2r)(r-2p)}{pqr} = -7 + 4\!\left(\frac{p}{q}+\frac{q}{r}+\frac{r
}{p}\right) - 2\!\left(\frac{q}{p}+\frac{r}{q}+\frac{p}{r}\right) = -7 + 4S - 2T
 = 10.$$
Thus $4S - 2T = 17$.

**Solving the system.** From $S + T = 22$ we get $T = 22 - S$. Substituting:
$$4S - 2(22 - S) = 17 \implies 6S - 44 = 17 \implies 6S = 61 \implies S = \frac{
61}{6}.$$

Since $\gcd(61, 6) = 1$, we have $m = 61$, $n = 6$, and
$$m + n = \boxed{67}.$$
