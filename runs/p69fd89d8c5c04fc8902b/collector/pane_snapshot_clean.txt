## Solution

**Setup.** $N = \sum_{k=10^{2003}}^{10^{2004}-1} S(k)$ ranges over all $2004$-di
git positive integers (from $1\underbrace{00\ldots0}_{2003}$ to $\underbrace{99\
ldots9}_{2004}$).

**Counting numbers.** There are $9\cdot 10^{2003}$ such numbers: the leading dig
it takes values $1,\ldots,9$, and each of the remaining $2003$ digits takes valu
es $0,\ldots,9$.

**Digit-sum contribution by position.**

*Leading digit (position $1$):* Each value $d\in\{1,\ldots,9\}$ appears exactly
$10^{2003}$ times, so the contribution is
$$\left(\sum_{d=1}^{9} d\right)\cdot 10^{2003} = 45\cdot 10^{2003}.$$

*Each of the remaining $2003$ positions:* Each digit $d\in\{0,\ldots,9\}$ appear
s $9\cdot 10^{2002}$ times (fix that position to $d$; the leading digit has $9$
choices, the other $2002$ free positions have $10^{2002}$ choices). The contribu
tion per position is
$$\left(\sum_{d=0}^{9} d\right)\cdot 9\cdot 10^{2002} = 45\cdot 9\cdot 10^{2002}
.$$
Over $2003$ such positions this gives $2003\cdot 45\cdot 9\cdot 10^{2002}$.

**Computing $N$.**
$$N = 45\cdot 10^{2003} + 2003\cdot 45\cdot 9\cdot 10^{2002} = 45\cdot 10^{2002}
\,(10 + 2003\cdot 9).$$
$$2003\cdot 9 = 18027,\qquad 10 + 18027 = 18037.$$
$$45\cdot 18037 = 18037\cdot 40 + 18037\cdot 5 = 721480 + 90185 = 811665.$$
Hence
$$N = 811665\cdot 10^{2002} = 811665\underbrace{00\ldots0}_{2002}.$$

**Final step.** Since $N$ is the digits $8,1,1,6,6,5$ followed by $2002$ zeros,
$$S(N) = 8+1+1+6+6+5 = 27.$$
