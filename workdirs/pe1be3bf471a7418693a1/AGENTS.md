# Problem

In a futuristic circular server farm, there are 100 data terminals arranged in a perfect ring, indexed sequentially from 1 to 100. A single malicious data packet, known as the "Ghost Code," is hidden within exactly one of these terminals. 

A security technician can perform a "System Scan," which constitutes one operation. In a single scan, the technician selects any four terminals and checks them simultaneously to see if the Ghost Code is present. However, the Ghost Code is dynamic: immediately after every scan, it automatically migrates from its current terminal to one of the two strictly adjacent terminals (for example, if it was in terminal 50, it moves to either 49 or 51; if it was in 100, it moves to 99 or 1).

The technician must determine a strategy to guarantee the capture of the Ghost Code, regardless of its starting position or the direction of its movements. What is the minimum number of scans required to definitely find the Ghost Code?
