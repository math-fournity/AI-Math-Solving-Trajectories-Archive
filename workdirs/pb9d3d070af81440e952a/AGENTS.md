# Problem

In a specialized logistics hub, a cargo manager is organizing a pyramid-shaped stacking plan involving a foundation of $n = 100$ shipping containers placed side-by-side in a single row. Each container in this base row is assigned a specific integer representing its weight class.

The stacking protocol follows a strict rule: a new container is placed directly on top of every adjacent pair of containers. The weight class of this upper container is determined by calculating the sum of the weight classes of the two containers supporting it. This engineering process repeats level by level, with each new row containing one fewer container than the row beneath it, until a single "apex" container completes the structure at the very top.

Across the entire assembly of $\frac{n(n+1)}{2}$ containers, the manager needs to minimize the presence of "Even-Grade" containers (those with an even weight class) by strategically choosing the initial 100 integers for the base row.

What is the minimum possible number of containers with even weight classes that can exist within the entire triangular stack?
