# Problem

A boutique clockmaker is designing a special circular decorative dial consisting of $N$ gems. Each gem position must be filled with either a Clear Diamond (representing the value 1) or a Deep Ruby (representing the value 2).

The clockmaker wants to ensure that the dial is "complete." A "code" is defined as any sequence of four gems found by looking at consecutive positions along the circle. Because the dial can be read in either direction, a code can be formed by starting at any gem and reading the next three gems moving either clockwise or counterclockwise.

The clockmaker’s goal is to arrange the $N$ gems such that every possible four-digit combination of 1s and 2s (from 1-1-1-1 to 2-2-2-2) appears at least once as a code on the dial.

What is the minimum number of gems $N$ required to construct such a circular dial?
