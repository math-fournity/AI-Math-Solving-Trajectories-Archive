# Problem

In a futuristic logistics hub, a cargo management system operates on a 20x20 grid of storage bays. A configuration of occupied bays is labeled "Active" if every one of the 20 horizontal aisles has at least one occupied bay and every one of the 20 vertical aisles has at least one occupied bay.

A configuration is labeled "Optimized" if one can select a set of exactly 20 occupied bays from it such that no two selected bays share the same horizontal or vertical aisle.

Let $\vartheta(20)$ represent the minimum number of occupied bays required to guarantee that any "Active" configuration is also "Optimized."

Furthermore, let $\varrho(20)$ represent the total number of distinct "Active" configurations containing exactly $\vartheta(20) - 1$ occupied bays that are not "Optimized."

Compute the value of $\vartheta(20) + \varrho(20)$.
