## Proof

**Setup.** The Riemann-Liouville fractional integral of order $\alpha > 0$ is

$$_0D_t^{-\alpha}f(t) = \frac{1}{\Gamma(\alpha)}\int_0^t (t-\tau)^{\alpha-1}f(\t
au)\,d\tau.$$

The Mellin transform of a function $g(t)$ is $\mathcal{M}\{g\}(s) = \int_0^\inft
y t^{s-1}g(t)\,dt$. We denote $F(s)=\mathcal{M}\{f\}(s)$.

**Computation.** We compute

$$\mathcal{M}\{_0D_t^{-\alpha}f(t)\}(s) = \int_0^\infty t^{s-1}\left[\frac{1}{\G
amma(\alpha)}\int_0^t (t-\tau)^{\alpha-1}f(\tau)\,d\tau\right]dt.$$

Swap the order of integration over the region $0\le\tau\le t<\infty$:

$$= \frac{1}{\Gamma(\alpha)}\int_0^\infty f(\tau)\left[\int_\tau^\infty t^{s-1}(
t-\tau)^{\alpha-1}\,dt\right]d\tau.$$

**Inner integral.** Substitute $t=\tau u$, $dt=\tau\,du$, $u:1\to\infty$:

$$\int_\tau^\infty t^{s-1}(t-\tau)^{\alpha-1}dt = \tau^{s+\alpha-1}\int_1^\infty
 u^{s-1}(u-1)^{\alpha-1}\,du.$$

For the remaining integral, set $u-1=w$ (so $u=1+w$, $w:0\to\infty$), then set $
x=\frac{w}{1+w}$ (so $w=\frac{x}{1-x}$, $dw=\frac{dx}{(1-x)^2}$, $1+w=\frac{1}{1
-x}$, $x:0\to 1$):

$$\int_0^\infty (1+w)^{s-1}w^{\alpha-1}\,dw = \int_0^1 x^{\alpha-1}(1-x)^{-s-\al
pha}\,dx = B\!\left(\alpha,\,1-s-\alpha\right) = \frac{\Gamma(\alpha)\,\Gamma(1-
s-\alpha)}{\Gamma(1-s)},$$

valid for $\operatorname{Re}(\alpha)>0$ and $\operatorname{Re}(1-s-\alpha)>0$.

**Assemble.** Substituting back,

$$\mathcal{M}\{_0D_t^{-\alpha}f(t)\}(s) = \frac{1}{\Gamma(\alpha)}\int_0^\infty
f(\tau)\,\tau^{s+\alpha-1}\cdot\frac{\Gamma(\alpha)\,\Gamma(1-s-\alpha)}{\Gamma(
1-s)}\,d\tau$$

$$= \frac{\Gamma(1-s-\alpha)}{\Gamma(1-s)}\int_0^\infty \tau^{(s+\alpha)-1}f(\ta
u)\,d\tau = \frac{\Gamma(1-s-\alpha)}{\Gamma(1-s)}\,F(s+\alpha).$$

**Verification ($\alpha=1$).** For ordinary integration, $_0D_t^{-1}f(t)=\int_0^
t f(\tau)d\tau$, and the formula gives $\frac{\Gamma(-s)}{\Gamma(1-s)}F(s+1)=\fr
ac{1}{-s}F(s+1)=-\frac{1}{s}F(s+1)$, using $\Gamma(1-s)=-s\,\Gamma(-s)$. This is
 exactly the classical Mellin-transform identity for an integral, obtained by in
tegration by parts with the boundary terms $t^{s-1}\!\int_0^t f$ vanishing at $t
=0$ and $t=\infty$ — precisely the hypothesis stated in the problem.

**Result.**

$$\boxed{\mathcal{M}\!\left\{_0D_t^{-\alpha}f(t)\right\}(s) \;=\; \frac{\Gamma(1
-s-\alpha)}{\Gamma(1-s)}\,F(s+\alpha),}$$

where $F(s)=\mathcal{M}\{f(t)\}(s)$, valid for $\operatorname{Re}(\alpha)>0$ and
 $\operatorname{Re}(s)<1-\operatorname{Re}(\alpha)$, with the stated boundary co
nditions ensuring convergence.
