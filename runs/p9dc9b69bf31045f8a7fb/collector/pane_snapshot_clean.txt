## Solution

**Answer.** $T_\alpha: L^2(\mathbb{R}^3) \to L^p(\mathbb{R}^3)$ is bounded if an
d only if
$$\frac{3}{2} < \alpha < 3 \quad\text{and}\quad p = \frac{6}{2\alpha - 3}.$$

---

### Necessity

**Step 1 (well-definedness forces $\alpha < 3$).** Take $f = \mathbf{1}_{B(0,1)}
 \in L^2(\mathbb{R}^3)$. Then
$$T_\alpha f(0) = \int_{B(0,1)} |y|^{-\alpha}\,dy,$$
which is finite if and only if $\alpha < 3$ (integrability of $|y|^{-\alpha}$ ne
ar the origin in $\mathbb{R}^3$). Hence for $\alpha \ge 3$ the operator is not e
ven defined on all of $L^2$, so it cannot be bounded.

For $\alpha \le 0$ the kernel $|x-y|^{-\alpha} = |x-y|^{|\alpha|}$ does not deca
y at infinity, so the convolution against a general $L^2$ function (which need n
ot be in $L^1$) diverges; the operator is not well-defined. Thus any bounded cas
e must have $0 < \alpha < 3$.

**Step 2 (scaling forces the relation $1/p = \alpha/3 - 1/2$).** For $\lambda >
0$ set $f_\lambda(x) = \lambda^{3/2} f(\lambda x)$, so $\|f_\lambda\|_{L^2} = \|
f\|_{L^2}$. A direct change of variables $y \mapsto z/\lambda$ gives
$$T_\alpha f_\lambda(x) = \lambda^{\alpha - 3/2}\,(T_\alpha f)(\lambda x).$$
Therefore
$$\|T_\alpha f_\lambda\|_{L^p} = \lambda^{\alpha - 3/2 - 3/p}\,\|T_\alpha f\|_{L
^p}.$$
If $T_\alpha: L^2 \to L^p$ is bounded, the left side is $\le C\|f\|_{L^2}$ for *
*all** $\lambda > 0$, which is possible only if the exponent of $\lambda$ vanish
es:
$$\alpha - \frac{3}{2} - \frac{3}{p} = 0 \quad\Longrightarrow\quad \frac{1}{p} =
 \frac{\alpha}{3} - \frac{1}{2}, \qquad p = \frac{6}{2\alpha - 3}.$$

**Step 3 ($p \in [1,\infty)$ forces $\alpha > 3/2$).** For $p$ to be a positive
finite number we need $2\alpha - 3 > 0$, i.e. $\alpha > 3/2$. (At $\alpha = 3/2$
 we get $p = \infty$, excluded; for $\alpha < 3/2$ the formula gives $p \le 0$,
impossible.) Combining with Step 1:
$$\frac{3}{2} < \alpha < 3, \qquad p = \frac{6}{2\alpha - 3} \in (2, \infty).$$

### Sufficiency (Hardy–Littlewood–Sobolev)

Let $\frac{3}{2} < \alpha < 3$ and set $\beta = 3 - \alpha \in (0, \tfrac{3}{2})
$. Then $|x|^{-\alpha} = |x|^{-(3-\beta)}$, so $T_\alpha f = c_{\beta}\, I_\beta
 f$ where $I_\beta$ is the Riesz potential of order $\beta$ on $\mathbb{R}^3$.

The **Hardy–Littlewood–Sobolev theorem** states: for $0 < \beta < n$, $1 < q < n
/\beta$, and $\frac{1}{p} = \frac{1}{q} - \frac{\beta}{n}$, the map $I_\beta : L
^q(\mathbb{R}^n) \to L^p(\mathbb{R}^n)$ is bounded.

Here $n = 3$, $q = 2$, $\beta = 3 - \alpha$. The condition $q < n/\beta$ reads $
2 < \frac{3}{3-\alpha}$, i.e. $3 - \alpha < \frac{3}{2}$, i.e. $\alpha > \frac{3
}{2}$ — satisfied. The relation gives
$$\frac{1}{p} = \frac{1}{2} - \frac{3-\alpha}{3} = \frac{\alpha}{3} - \frac{1}{2
} = \frac{2\alpha - 3}{6}, \qquad p = \frac{6}{2\alpha - 3}.$$
Since $\alpha \in (\frac{3}{2}, 3)$, we have $2\alpha - 3 \in (0, 3)$, so $p \in
 (2, \infty) \subset [1, \infty)$. All hypotheses of HLS are met, so $T_\alpha :
 L^2(\mathbb{R}^3) \to L^p(\mathbb{R}^3)$ is bounded.

### Conclusion

$T_\alpha : L^2(\mathbb{R}^3) \to L^p(\mathbb{R}^3)$ is bounded **if and only if
**
$$\boxed{\frac{3}{2} < \alpha < 3 \quad\text{and}\quad p = \frac{6}{2\alpha - 3}
.}$$
