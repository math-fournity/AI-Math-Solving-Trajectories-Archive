# Problem

A shipping logistics manager is tasked with decommissioning a warehouse containing 100 identical storage containers, each holding 400 specialized engine parts. To clear the facility, the manager must execute a series of shipments. In each shipment, he must select exactly two containers and remove one engine part from each.

For every shipment made, the manager receives a performance bonus equal to the absolute difference between the current number of parts remaining in the two selected containers. The decommissioning process continues until every part has been removed from all 100 containers.

What is the maximum total performance bonus the manager can earn by the time the warehouse is empty?
