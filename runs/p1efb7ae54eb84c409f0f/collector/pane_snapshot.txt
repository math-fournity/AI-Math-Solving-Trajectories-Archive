 for the hyperfactorial and Stirling for the factorial).

## Setup

The hyperfactorial is $H(n)=\prod_{k=1}^{n} k^{k}$, so $\log H(n)=\sum_{k=1}^{n}
 k\log k$. Define

$$L_n = e^{n/4}\, n^{-(n+1)/2}\left(\frac{H(n)}{n!}\right)^{1/n}, \qquad \ell_n:
=\log L_n.$$

Then

$$\ell_n = \frac{n}{4} - \frac{n+1}{2}\log n + \frac{1}{n}\log\frac{H(n)}{n!}.$$

## Two asymptotics

**Glaisher–Kinkelin** (for the hyperfactorial): there is a constant $A$ (the Gla
isher–Kinkelin constant) such that

$$\log H(n) = \left(\frac{n^{2}}{2}+\frac{n}{2}+\frac{1}{12}\right)\log n - \fra
c{n^{2}}{4} + \log A + O(1/n).$$

**Stirling** (for the factorial):

$$\log n! = n\log n - n + \frac{1}{2}\log(2\pi n) + O(1/n) = n\log n - n + \frac
{1}{2}\log n + \frac{1}{2}\log(2\pi) + O(1/n).$$

## Compute the per‑$n$ average of $\log(H(n)/n!)$

Subtracting and dividing by $n$:

$$\frac{1}{n}\log\frac{H(n)}{n!} = \frac{1}{n}\Bigl[\Bigl(\frac{n^{2}}{2}+\frac{
n}{2}+\frac{1}{12}\Bigr)\log n - \frac{n^{2}}{4} + \log A - n\log n + n - \frac{
1}{2}\log n - \frac{1}{2}\log(2\pi) + O(1/n)\Bigr].$$

Collecting terms by growth rate:

- $n^{2}$‑level: $\;\dfrac{n}{2}\log n - \dfrac{n}{4}$.
- $n^{0}$‑level (the $O(1)$ part after division): $\;\dfrac{1}{2}\log n - \log n
 + 1 = -\dfrac{1}{2}\log n + 1$.
- remainder: $O((\log n)/n)$.

Hence

$$\frac{1}{n}\log\frac{H(n)}{n!} = \frac{n}{2}\log n - \frac{n}{4} - \frac{1}{2}
\log n + 1 + O\!\left(\frac{\log n}{n}\right).$$

## Assemble $\ell_n$

$$\ell_n = \underbrace{\frac{n}{4}}_{\text{from }e^{n/4}} \;\underbrace{-\;\frac
{n}{2}\log n - \frac{1}{2}\log n}_{\text{from }n^{-(n+1)/2}}\; + \;\underbrace{\
frac{n}{2}\log n - \frac{n}{4} - \frac{1}{2}\log n + 1 + O\!\left(\frac{\log n}{
n}\right)}_{\text{from }(H(n)/n!)^{1/n}}.$$

Cancellations:

- $\frac{n}{4} - \frac{n}{4} = 0$,
- $-\frac{n}{2}\log n + \frac{n}{2}\log n = 0$,
- $-\frac{1}{2}\log n - \frac{1}{2}\log n = -\log n$.

Therefore

$$\ell_n = 1 - \log n + O\!\left(\frac{\log n}{n}\right).$$

## Take the limit

Exponentiating,

$$L_n = \exp\!\left(1 - \log n + O\!\left(\frac{\log n}{n}\right)\right) = \frac
{e}{n}\cdot \exp\!\left(O\!\left(\frac{\log n}{n}\right)\right).$$

Since $\exp(O((\log n)/n))\to 1$ and $e/n\to 0$,

$$\lim_{n\to\infty} L_n = 0.$$

In fact the sharper asymptotic is $L_n \sim \dfrac{e}{n}$.
