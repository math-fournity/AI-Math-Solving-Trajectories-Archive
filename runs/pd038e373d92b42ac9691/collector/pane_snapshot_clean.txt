## Solution

**Step 1: Find the local maximum $a_n$.**

For $f_n(x) = \frac{x^n e^{-x+n\pi}}{n!}$, differentiate:

$$f_n'(x) = \frac{e^{-x+n\pi}}{n!}\,x^{n-1}e^{-x}(n-x).$$

Setting $f_n'(x)=0$ for $x>0$ gives $x=n$. Since $f_n'(x)>0$ for $x<n$ and $f_n'
(x)<0$ for $x>n$, this is the local maximum. Thus

$$a_n = f_n(n) = \frac{n^n\, e^{-n+n\pi}}{n!}.$$

**Step 2: Form the ratio $\frac{a_{2n}}{a_n}$.**

$$\frac{a_{2n}}{a_n} = \frac{(2n)^{2n}\,e^{-2n+2n\pi}}{(2n)!}\cdot\frac{n!}{n^n\
,e^{-n+n\pi}} = \frac{4^n\, n^n\, n!\, e^{-n+n\pi}}{(2n)!}.$$

**Step 3: Take $\frac{1}{n}\ln(\cdot)$.**

$$\frac{1}{n}\ln\!\left(\frac{a_{2n}}{a_n}\right) = \ln 4 + \ln n + \frac{\ln(n!
)}{n} - 1 + \pi - \frac{\ln((2n)!)}{n}.$$

**Step 4: Apply Stirling's approximation** $\ln(m!) = m\ln m - m + \tfrac{1}{2}\
ln(2\pi m) + O(1/m)$:

$$\frac{\ln(n!)}{n} = \ln n - 1 + \frac{\ln(2\pi n)}{2n} + O(1/n^2),$$

$$\frac{\ln((2n)!)}{n} = 2\ln(2n) - 2 + \frac{\ln(4\pi n)}{2n} + O(1/n^2).$$

Substituting:

$$\ln 4 + \ln n + \left(\ln n - 1 + \frac{\ln(2\pi n)}{2n}\right) - 1 + \pi - \l
eft(2\ln(2n) - 2 + \frac{\ln(4\pi n)}{2n}\right) + O(1/n^2)$$

$$= \ln 4 + 2\ln n - 2\ln(2n) + \pi + \frac{\ln(2\pi n)-\ln(4\pi n)}{2n} + O(1/n
^2).$$

Since $2\ln(2n) = 2\ln 2 + 2\ln n$ and $\ln 4 = 2\ln 2$:

$$= \underbrace{2\ln 2 - 2\ln 2}_{0} + \underbrace{2\ln n - 2\ln n}_{0} + \pi +
\frac{\ln(1/2)}{2n} + O(1/n^2)$$

$$= \pi - \frac{\ln 2}{2n} + O(1/n^2).$$

**Step 5: Take the limit.**

$$\lim_{n\to\infty}\ln\!\left(\frac{a_{2n}}{a_n}\right)^{1/n} = \lim_{n\to\infty
}\left(\pi - \frac{\ln 2}{2n} + O(1/n^2)\right) = \pi.$$

$$\boxed{\pi}$$
