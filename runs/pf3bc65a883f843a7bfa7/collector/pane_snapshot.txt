Looking at this problem, I need to find the minimum of $\int_0^1 f(x)\,dx$ over
continuous $f:[0,1]\to\mathbb{R}$ satisfying $f(x)+f(y)\ge|x-y|$ for all $x,y\in
[0,1]$.

## Lower Bound

**Key test:** Set $y = 1-x$ for $x\in[0,\tfrac12]$. Then $|x-y|=|x-(1-x)|=|2x-1|
=1-2x$, so the constraint gives:
$$f(x)+f(1-x)\ge 1-2x, \quad \forall\, x\in[0,\tfrac12].$$

Integrate both sides over $x\in[0,\tfrac12]$:
$$\int_0^{1/2}f(x)\,dx+\int_0^{1/2}f(1-x)\,dx \;\ge\; \int_0^{1/2}(1-2x)\,dx = \
Big[x-x^2\Big]_0^{1/2}=\frac12-\frac14=\frac14.$$

For the left side, substitute $u=1-x$ in the second integral:
$$\int_0^{1/2}f(x)\,dx+\int_{1/2}^{1}f(u)\,du = \int_0^1 f(u)\,du.$$

Therefore:
$$\int_0^1 f(x)\,dx \;\ge\; \frac14.$$

## Achieving the Bound

Consider $f(x)=|x-\tfrac12|$. This is continuous on $[0,1]$.

**Feasibility:** By the triangle inequality,
$$f(x)+f(y)=\Big|x-\tfrac12\Big|+\Big|y-\tfrac12\Big|\ge\Big|(x-\tfrac12)-(y-\tf
rac12)\Big|=|x-y|,$$
so $f\in E$.

**Integral value:**
$$\int_0^1\Big|x-\tfrac12\Big|\,dx=\int_0^{1/2}\Big(\tfrac12-x\Big)dx+\int_{1/2}
^{1}\Big(x-\tfrac12\Big)dx=\frac18+\frac18=\frac14.$$

## Conclusion

The lower bound $\frac14$ is achieved by $f(x)=|x-\tfrac12|$, so the minimum val
ue is:

$$\boxed{\dfrac14}$$
