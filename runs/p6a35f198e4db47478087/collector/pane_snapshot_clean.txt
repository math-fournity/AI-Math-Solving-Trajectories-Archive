## Proof

**Notation.** There are 2021 packets, exactly one corrupted, and 7 sub-processor
s. A "bundle" is the set of packets routed through one processor on a given day.
 A processor crashes at day's end iff its bundle contains the corrupted packet.
A single packet may be placed in the bundles of *multiple* processors on the sam
e day (routing is per-processor, with no restriction that a packet visit only on
e processor).

---

### Lower bound: 1 day is impossible.

With a single day, each of the 7 processors either crashes or survives — a binar
y outcome per processor. This yields at most \(2^7 = 128\) distinct observable o
utcomes. To single out one corrupted packet among 2021, the administrator needs
at least 2021 distinguishable outcomes. Since \(128 < 2021\), one day cannot suf
fice, regardless of strategy.

---

### Upper bound: 2 days suffice.

**Encoding.** Since \(3^7 = 2187 \ge 2021\), assign each packet a **distinct** t
ernary codeword \(c_1c_2\cdots c_7\) with each \(c_i \in \{0,1,2\}\).

**Day 1.** For each processor \(i \in \{1,\dots,7\}\), place a packet into proce
ssor \(i\)'s bundle **iff** \(c_i = 1\).

*Observation.* Processor \(i\) crashes on day 1 iff the corrupted packet's code
has \(c_i = 1\). Hence, after day 1, the administrator knows **exactly which pos
itions of the corrupted packet's code equal 1**. All processors with \(c_i=1\) a
re now permanently disabled; all processors with \(c_i \in \{0,2\}\) survive.

**Day 2.** For each surviving processor \(i\), place a packet into processor \(i
\)'s bundle **iff** \(c_i = 2\). (This is well-defined: if \(c_i = 2\) then \(c_
i \ne 1\), so processor \(i\) survived day 1.)

*Observation.* Processor \(i\) crashes on day 2 iff the corrupted packet's code
has \(c_i = 2\). Hence, after day 2, the administrator knows **exactly which pos
itions equal 2**.

**Identification.** Every position is now classified:
- value \(1\) — identified by day-1 crashes,
- value \(2\) — identified by day-2 crashes,
- value \(0\) — neither (survived both days, never tested).

Thus the full 7-symbol ternary code of the corrupted packet is recovered. Since
all 2021 codewords are distinct, the corrupted packet is identified **with certa
inty**.

---

### Conclusion.

One day gives at most \(2^7 = 128 < 2021\) outcomes (impossible), while two days
 give \(3^7 = 2187 \ge 2021\) outcomes via the ternary construction above (suffi
cient). Therefore the minimum number of days required is

\[\boxed{2}.\]
