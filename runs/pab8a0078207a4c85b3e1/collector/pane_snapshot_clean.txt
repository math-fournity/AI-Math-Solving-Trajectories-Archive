# Proof: A non-empty complete metric space without isolated points is uncountabl
e

**Setup.** Let $(X, d)$ be a non-empty complete metric space in which no point i
s isolated. We prove $X$ is uncountable.

**Key lemma.** *In a metric space with no isolated points, every non-empty open
set is infinite.*

*Proof of lemma.* Let $U \neq \emptyset$ be open and suppose $U$ is finite, say
$U = \{p_1, \dots, p_k\}$. Pick $p_i \in U$; since $U$ is open, some ball $B(p_i
, \varepsilon) \subseteq U$. This ball is finite (a subset of $U$). Set $\delta
= \min\{d(p_i, p_j) : j \neq i\} > 0$, which exists because the set is finite. T
hen $B(p_i, \delta/2) = \{p_i\}$, so $p_i$ is isolated — contradiction. $\square
$

**Main proof.** Suppose for contradiction that $X$ is countable, enumerated as $
X = \{x_1, x_2, x_3, \dots\}$.

Note $|X| \geq 2$: if $X = \{p\}$, then $p$ is isolated (the open ball $B(p, 1)
= \{p\}$), contradicting the hypothesis.

We construct a nested sequence of closed balls $B_n = \overline{B}(y_n, r_n)$ wi
th:
1. $B_1 \supseteq B_2 \supseteq \cdots$ (nested),
2. $r_n \to 0$ (in fact $r_n \leq 1/n$),
3. $x_n \notin B_n$ for every $n$.

**Base case ($n=1$).** Since $|X|\geq 2$, pick $y_1 \neq x_1$. Set $r_1 = \min\!
\bigl(\tfrac{1}{2}\, d(y_1, x_1),\, \tfrac{1}{2}\bigr) > 0$. Then $x_1 \notin \o
verline{B}(y_1, r_1)$ (the closure stays at distance $\geq d(y_1,x_1) - r_1 \geq
 r_1 > 0$ from $x_1$).

**Inductive step.** Assume $B_n = \overline{B}(y_n, r_n)$ with $r_n > 0$. The in
terior $\operatorname{int}(B_n) \supseteq B(y_n, r_n)$ is a non-empty open set,
hence **infinite** by the lemma. Therefore we can choose $y_{n+1} \in \operatorn
ame{int}(B_n)$ with $y_{n+1} \neq x_{n+1}$. Since $y_{n+1}$ lies in the open int
erior of $B_n$, there exists $\varepsilon > 0$ with $B(y_{n+1}, \varepsilon) \su
bseteq \operatorname{int}(B_n)$. Now set
$$r_{n+1} = \min\!\Bigl(\tfrac{\varepsilon}{2},\; \tfrac{1}{2}\,d(y_{n+1}, x_{n+
1}),\; \tfrac{r_n}{2},\; \tfrac{1}{n+1}\Bigr) > 0.$$
Then:
- $\overline{B}(y_{n+1}, r_{n+1}) \subseteq \overline{B}(y_{n+1}, \varepsilon) \
subseteq B_n$ (nesting holds),
- $x_{n+1} \notin \overline{B}(y_{n+1}, r_{n+1})$ (exclusion holds),
- $r_{n+1} \leq 1/(n+1)$, so $r_n \to 0$.

**Applying completeness.** The sets $B_n$ are closed, nested, and $\operatorname
{diam}(B_n) \leq 2r_n \to 0$. By **Cantor's intersection theorem** (valid in any
 complete metric space), the intersection $\bigcap_{n=1}^{\infty} B_n$ contains
exactly one point; call it $y^*$.

Since each $B_n \subseteq X$, we have $y^* \in X$. But property (3) gives $x_n \
notin B_n$ for every $n$, hence $y^* \neq x_n$ for all $n$. This means $y^* \not
in \{x_1, x_2, \dots\} = X$ — contradicting $y^* \in X$.

**Conclusion.** The assumption that $X$ is countable leads to a contradiction. T
herefore $X$ is uncountable. $\blacksquare$
