**Answer: The statement is TRUE.** A totally disconnected topological group is n
ecessarily Hausdorff.

## Proof

Let $G$ be a topological group with identity $e$. We use two standard facts and
one general topological fact.

**Fact 1 (General topology).** In any topological space, the closure of a connec
ted set is connected.

**Fact 2 (Topological groups).** In a topological group, $G$ is Hausdorff if and
 only if $\{e\}$ is closed.

*Proof of Fact 2.* The map $f:G\times G\to G$, $f(x,y)=xy^{-1}$, is continuous (
since inversion and multiplication are continuous). The diagonal $\Delta=\{(x,x)
:x\in G\}$ equals $f^{-1}(\{e\})$. A space is Hausdorff iff its diagonal is clos
ed in $G\times G$. Hence $\{e\}$ closed $\Rightarrow$ $\Delta=f^{-1}(\{e\})$ clo
sed $\Rightarrow$ $G$ Hausdorff. Conversely, if $G$ is Hausdorff then $G$ is $T_
1$, so every singleton, in particular $\{e\}$, is closed. $\square$

**Fact 3 (Topological groups).** The connected component $C(e)$ of the identity
is a closed normal subgroup, and $G$ is totally disconnected iff $C(e)=\{e\}$.

This is just the definition of totally disconnected (all connected components ar
e singletons) combined with the standard fact that $C(e)$ is a (closed) normal s
ubgroup.

**Main argument.**

The singleton $\{e\}$ is connected (trivially). By Fact 1, its closure $\overlin
e{\{e\}}$ is connected. Since $\overline{\{e\}}\ni e$ and is connected, it is co
ntained in the connected component of $e$:

$$\overline{\{e\}}\subseteq C(e).$$

Now suppose $G$ is totally disconnected. By Fact 3, $C(e)=\{e\}$. Therefore

$$\overline{\{e\}}\subseteq\{e\},$$

which forces $\overline{\{e\}}=\{e\}$, i.e., $\{e\}$ is closed. By Fact 2, $G$ i
s Hausdorff. $\square$

**Remark (why the indiscrete topology is not a counterexample).** One might try
the indiscrete topology on a nontrivial group as a non-Hausdorff topological gro
up. However, the indiscrete topology is connected (the only clopen sets are $\va
rnothing$ and $G$), so its only connected component is $G$ itself, which is not
a singleton. Hence it is *not* totally disconnected, and the theorem does not ap
ply. More generally, the argument above shows that any non-Hausdorff topological
 group has $\overline{\{e\}}\neq\{e\}$, and since $\overline{\{e\}}$ is a nontri
vial connected set containing $e$, the connected component $C(e)$ is nontrivial
— so no non-Hausdorff topological group can be totally disconnected.
