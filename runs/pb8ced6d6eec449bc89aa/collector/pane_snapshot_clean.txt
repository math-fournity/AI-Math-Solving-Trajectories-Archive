## Proof

We determine the cardinality of the set of recursive subsets of $\mathbb{N}$.

**Definition.** A subset $A \subseteq \mathbb{N}$ is *recursive* (decidable) if
its characteristic function $\chi_A : \mathbb{N} \to \{0,1\}$ is a total computa
ble (recursive) function.

---

**Upper bound: at most countably many recursive subsets.**

Every recursive set $A$ is determined by its characteristic function $\chi_A$, w
hich is a total computable function. Every computable function is computed by so
me Turing machine (equivalently, by some finite program). The set of all Turing
machines is countable, since each machine has a finite description over a finite
 alphabet, and finite strings over a finite alphabet form a countable set.

The map "Turing machine $\mapsto$ function it computes" sends the countable set
of machines onto the set of (partial) computable functions. Hence the set of tot
al computable functions $\mathbb{N} \to \{0,1\}$ is at most countable. Since eac
h recursive set corresponds to exactly one such characteristic function, the set
 of recursive subsets of $\mathbb{N}$ is **at most countable**.

**Lower bound: at least countably many recursive subsets.**

For each $n \in \mathbb{N}$, the singleton $\{n\}$ is recursive: its characteris
tic function checks whether the input equals $n$, which is clearly computable. T
he map $n \mapsto \{n\}$ is injective, so there are at least countably many recu
rsive subsets of $\mathbb{N}$.

---

**Conclusion.**

The set of recursive subsets of $\mathbb{N}$ is both at most countable and at le
ast countable, hence it is **countably infinite**, with cardinality $\aleph_0$.

(Remark: this stands in contrast with the set of *all* subsets of $\mathbb{N}$,
which has cardinality $2^{\aleph_0}$, and the set of *recursively enumerable* su
bsets, which is also countable. The vast majority of subsets of $\mathbb{N}$ are
 not recursive.)
