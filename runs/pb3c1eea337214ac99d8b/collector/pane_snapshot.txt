## Proof

**Notation.** $f^2(t) := [f(t)]^2$.

### Step 1. Key substitution $x=0$

Setting $x=0$: $f(f(y)+1) = y + [f(1)]^2$. Let $c := [f(1)]^2$, so

$$f(f(y)+1) = y + c. \tag{1}$$

This shows $f$ is **surjective** (the right side ranges over all $\mathbb{R}$) a
nd **injective** (if $f(a)=f(b)$, then $f(f(a)+1)=f(f(b)+1)$ gives $a+c=b+c$, so
 $a=b$). Thus $f$ is bijective.

### Step 2. Substitution $x=-1$

Setting $x=-1$: $f(f(y)+2) - 2 = y + [f(0)]^2$, so

$$f(f(y)+2) = y + [f(0)]^2 + 2. \tag{2}$$

Since $f$ is surjective, $f(y)+1$ ranges over all reals. Setting $t = f(y)+1$ in
 (1) and (2):

$$f(t) = y + c, \quad f(t+1) = y + [f(0)]^2 + 2,$$

so $f(t+1) - f(t) = [f(0)]^2 + 2 - c =: k$ is constant. Therefore

$$f(t+1) = f(t) + k \quad \forall\, t. \tag{3}$$

### Step 3. Determining $f(f(y))$

Applying (3) with $t = f(y)$: $f(f(y)+1) = f(f(y)) + k$. Combined with (1):

$$f(f(y)) = y + c - k. \tag{4}$$

### Step 4. Substitution $y=0$

Setting $y=0$ in the original equation, with $a := f(0)$:

$$f(a + x^2 + 1) + 2x = [f(x+1)]^2. \tag{5}$$

Using (3): $f(a+x^2+1) = f(a+x^2)+k$ and $f(x+1) = f(x)+k$. So (5) becomes:

$$f(a+x^2) + k + 2x = [f(x)+k]^2. \tag{6}$$

### Step 5. Determining $k$ and $a$

From (4) with $y=0$: $f(a) = c - k$. From (6) with $x=0$: $f(a) = (a+k)^2 - k$.
Also $c = [f(1)]^2 = [f(0)+k]^2 = (a+k)^2$ (using (3) at $t=0$). These are consi
stent: $c - k = (a+k)^2 - k$. ✓

From (6) with $x=1$: $f(a+1) = [f(1)+k]^2 - k - 2 = (a+2k)^2 - k - 2$. But from
(3): $f(a+1) = f(a)+k = (a+k)^2 - k + k = (a+k)^2$. So:

$$(a+k)^2 = (a+2k)^2 - k - 2.$$

Expanding: $(a+2k)^2 - (a+k)^2 = k(2a+3k) = k+2$, giving $2ak + 3k^2 - k - 2 = 0
$. $\quad(7)$

From $c = (a+k)^2$ and $k = a^2 + 2 - c$: $k = a^2 + 2 - (a+k)^2 = 2 - 2ak - k^2
$, so $k^2 + 2ak + k - 2 = 0$, i.e., $2ak = -k^2 - k + 2$. $\quad(8)$

Substituting (8) into (7): $(-k^2 - k + 2) + 3k^2 - k - 2 = 0$, i.e., $2k^2 - 2k
 = 0$, so $k(k-1) = 0$.

If $k=0$: (8) gives $-2=0$, contradiction. So $k=1$, and (8) gives $2a = 0$, so
$a = 0$.

### Step 6. Structure of $f$

With $k=1$, $a=0$, $c=1$: (3) gives $f(t+1) = f(t)+1$, and (4) gives $f(f(y)) =
y$ (involution). Write $f(t) = t + h(t)$ where $h$ has **period 1** and $h(0)=0$
. The involution condition gives:

$$h(t) + h(t + h(t)) = 0. \tag{9}$$

### Step 7. The original equation forces $h$ to be additive

Substituting $f(t) = t + h(t)$ into the original equation and simplifying (using
 $h$ has period 1):

$$h(y) + h\big(y + h(y) + x^2\big) = 2x\,h(x) + 2h(x) + h(x)^2. \tag{10}$$

The right side depends only on $x$. Setting $u := y + h(y) = f(y)$ (which ranges
 over all $\mathbb{R}$ since $f$ is bijective), and using $h(u) = -h(y)$ from (9
):

$$h(u + x^2) - h(u) = R(x) \quad \text{for all } u \in \mathbb{R},\; x \in \math
bb{R},$$

where $R(x)$ depends only on $x$. Setting $s = x^2 \geq 0$: **$h(u+s) - h(u)$ is
 independent of $u$ for every $s \geq 0$**. Setting $u=0$ gives $h(u+s) = h(u) +
 h(s)$ for all $u$ and $s \geq 0$. For $s < 0$, writing $h(u) = h(u+s+(-s)) = h(
u+s) + h(-s)$ yields $h(u+s) = h(u) - h(-s) = h(u) + h(s)$ (one checks $h$ is od
d). Therefore:

$$h \text{ is additive: } h(p+q) = h(p) + h(q) \quad \forall\, p,q \in \mathbb{R
}. \tag{11}$$

### Step 8. Deriving $h \equiv 0$

From (6) with $k=1, a=0$: $f(x^2) = [f(x)+1]^2 - 1 - 2x$. Expanding with $f(t) =
 t + h(t)$:

$$h(x^2) = h(x)\big(2x + h(x) + 2\big). \tag{12}$$

Replace $x$ by $2x$ in (12): $h(4x^2) = h(2x)(4x + h(2x) + 2) = 2h(x)(4x + 2h(x)
 + 2)$.

By additivity (11): $h(4x^2) = 4h(x^2) = 4h(x)(2x + h(x) + 2)$ (using (12)).

Equating: $4h(x)(2x + h(x) + 2) = 2h(x)(4x + 2h(x) + 2)$.

If $h(x) \neq 0$, divide by $2h(x)$: $2(2x + h(x) + 2) = 4x + 2h(x) + 2$, i.e.,
$4x + 2h(x) + 4 = 4x + 2h(x) + 2$, giving $4 = 2$. **Contradiction.**

Therefore $h(x) = 0$ for all $x$, so $f(x) = x$.
