**Claim.** There is no strictly increasing sequence $(\alpha_k)_{k \in \mathbb{N
}}$ with $\alpha_k < \omega_1$ for all $k$ that is cofinal in $\omega_1$.

**Proof.** Suppose for contradiction that $(\alpha_k)_{k \in \mathbb{N}}$ is suc
h a sequence: $\alpha_k < \alpha_{k+1} < \omega_1$ for all $k$, and for every $\
beta < \omega_1$ there exists $k$ with $\alpha_k \geq \beta$.

Consider the set $A = \{\alpha_k : k \in \mathbb{N}\}$. This is a countable set
of countable ordinals. Let
$$\gamma = \sup A = \sup_{k \in \mathbb{N}} \alpha_k.$$

**$\gamma$ is countable.** Each $\alpha_k$ is a countable ordinal, so for each $
k$ there exists a bijection $f_k : \mathbb{N} \to \alpha_k$. Define a surjection
 $g : \mathbb{N} \times \mathbb{N} \to \gamma$ by $g(k, n) = f_k(n)$. Since ever
y element of $\gamma$ is an element of some $\alpha_k \subseteq \gamma$ (because
 $\gamma = \sup A$, every ordinal $\xi < \gamma$ satisfies $\xi < \alpha_k$ for
some $k$), $g$ is indeed surjective. Composing with a bijection $\mathbb{N} \to
\mathbb{N} \times \mathbb{N}$, we obtain a surjection $\mathbb{N} \to \gamma$, s
o $\gamma$ is countable.

Therefore $\gamma < \omega_1$.

Now consider $\gamma + 1$. Since $\gamma$ is countable, $\gamma + 1$ is also cou
ntable, so $\gamma + 1 < \omega_1$. By the cofinality assumption, there exists s
ome $k$ with $\alpha_k \geq \gamma + 1$. But $\alpha_k \in A$, so $\alpha_k \leq
 \sup A = \gamma < \gamma + 1$, a contradiction.

Therefore no such sequence exists. $\blacksquare$
