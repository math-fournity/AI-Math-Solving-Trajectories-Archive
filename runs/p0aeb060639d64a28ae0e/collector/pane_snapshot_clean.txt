## Proof

We wish to determine all real $x$ for which
$$S(x) = \sum_{n=1}^{\infty} \frac{n^{n^2}}{(n+x)^{n^2}}$$
converges.

**Reformulation.** The general term is
$$a_n = \left(\frac{n}{n+x}\right)^{n^2}.$$

We apply the **root test**, computing
$$\sqrt[n]{|a_n|} = \left|\frac{n}{n+x}\right|^n.$$

For all sufficiently large $n$ (namely $n > |x|$, so that $n+x > 0$), the absolu
te value can be dropped:
$$\sqrt[n]{|a_n|} = \left(\frac{n}{n+x}\right)^n = \left(\frac{1}{1+x/n}\right)^
n.$$

**Computing the limit.** Taking logarithms,
$$\ln\!\left(\frac{1}{1+x/n}\right)^n = -n\ln\!\left(1+\frac{x}{n}\right).$$

Using the Taylor expansion $\ln(1+t) = t - \frac{t^2}{2} + O(t^3)$ as $t \to 0$,
 with $t = x/n$:
$$-n\ln\!\left(1+\frac{x}{n}\right) = -n\!\left(\frac{x}{n} - \frac{x^2}{2n^2} +
 O\!\left(\frac{1}{n^3}\right)\right) = -x + \frac{x^2}{2n} + O\!\left(\frac{1}{
n^2}\right).$$

Therefore,
$$\lim_{n\to\infty} \sqrt[n]{|a_n|} = e^{-x}.$$

**Case 1: $x > 0$.** Then $e^{-x} < 1$. By the root test, the series converges a
bsolutely.

**Case 2: $x = 0$.** Then $a_n = \left(\frac{n}{n}\right)^{n^2} = 1$ for every $
n$, so the series is $\sum_{n=1}^\infty 1$, which diverges.

**Case 3: $x < 0$.** Then $e^{-x} = e^{|x|} > 1$. By the root test, the series d
iverges. (In particular, $|a_n| \not\to 0$, so the terms do not tend to zero.)

**Remark on negative integer $x$.** If $x = -k$ for some positive integer $k$, t
he term with $n = k$ has denominator $(n+x)^{n^2} = 0$, so the series is not eve
n defined. This is subsumed under Case 3, since the series cannot converge.

**Conclusion.** The series converges if and only if $x > 0$. The set of real val
ues of $x$ for which the series converges is

$$\boxed{(0,\,\infty)}.$$
