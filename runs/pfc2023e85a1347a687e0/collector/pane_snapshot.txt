Looking at this problem, I need to find the minimum number of students $n$ such
that there exist disjoint groups satisfying: more than $\frac{1}{3}$ go to cinem
a, more than $\frac{3}{10}$ to theatre, more than $\frac{4}{11}$ to concert.

(The disjoint interpretation is necessary — otherwise $n=1$ trivially works with
 one student attending all three.)

## Proof

Let $n$ be the number of students. Let $c, t, k$ be the numbers going to the cin
ema, theatre, and concert respectively, with $c + t + k \leq n$ (disjoint groups
). We need:
$$c > \frac{n}{3}, \quad t > \frac{3n}{10}, \quad k > \frac{4n}{11}.$$

Since $c, t, k$ are integers, the minimum values are:
$$c_{\min} = \left\lfloor \frac{n}{3} \right\rfloor + 1, \quad t_{\min} = \left\
lfloor \frac{3n}{10} \right\rfloor + 1, \quad k_{\min} = \left\lfloor \frac{4n}{
11} \right\rfloor + 1.$$

The condition $c + t + k \leq n$ requires:
$$\left\lfloor \frac{n}{3} \right\rfloor + \left\lfloor \frac{3n}{10} \right\rfl
oor + \left\lfloor \frac{4n}{11} \right\rfloor + 3 \leq n. \tag{$\star$}$$

**Key identity.** Since $\frac{1}{3} + \frac{3}{10} + \frac{4}{11} = \frac{110 +
 99 + 120}{330} = \frac{329}{330}$, we have:
$$\left\lfloor \frac{n}{3} \right\rfloor + \left\lfloor \frac{3n}{10} \right\rfl
oor + \left\lfloor \frac{4n}{11} \right\rfloor = \frac{329n}{330} - s(n),$$
where $s(n) = \left\{\frac{n}{3}\right\} + \left\{\frac{3n}{10}\right\} + \left\
{\frac{4n}{11}\right\}$ is the sum of fractional parts.

Condition ($\star$) becomes:
$$\frac{329n}{330} - s(n) + 3 \leq n \implies s(n) \geq 3 - \frac{n}{330} = \fra
c{990 - n}{330}. \tag{$\star\star$}$$

**Upper bound on $s(n)$.** Each fractional part satisfies $\{x\} \leq \frac{d-1}
{d}$ where $d$ is the denominator:
$$s(n) \leq \frac{2}{3} + \frac{9}{10} + \frac{10}{11} = \frac{220 + 297 + 300}{
330} = \frac{817}{330}.$$

Combining with ($\star\star$):
$$\frac{817}{330} \geq s(n) \geq \frac{990 - n}{330} \implies 817 \geq 990 - n \
implies n \geq 173.$$

**Achieving $n = 173$.** We need $s(173) = \frac{817}{330}$, i.e., all three fra
ctional parts simultaneously maximized. This requires:
- $n \equiv 2 \pmod{3}$ (so $\{n/3\} = 2/3$),
- $3n \equiv 9 \pmod{10}$, i.e., $n \equiv 3 \pmod{10}$ (so $\{3n/10\} = 9/10$),
- $4n \equiv 10 \pmod{11}$, i.e., $n \equiv 8 \pmod{11}$ (so $\{4n/11\} = 10/11$
).

By CRT (since $3, 10, 11$ are pairwise coprime), this system has a unique soluti
on mod $330$. Checking $n = 173$:
- $173 = 57 \cdot 3 + 2$ ✓ ($\{173/3\} = 2/3$)
- $3 \cdot 173 = 519 = 51 \cdot 10 + 9$ ✓ ($\{519/10\} = 9/10$)
- $4 \cdot 173 = 692 = 62 \cdot 11 + 10$ ✓ ($\{692/11\} = 10/11$)

So $s(173) = \frac{817}{330} = \frac{990 - 173}{330}$, and equality holds in ($\
star\star$).

**Verification for $n = 173$:**
$$c = 58,\quad t = 52,\quad k = 63.$$
- $58 > 173/3 = 57.6\overline{6}$ ✓
- $52 > 3 \cdot 173/10 = 51.9$ ✓
- $63 > 4 \cdot 173/11 = 62.9\overline{09}$ ✓
- $58 + 52 + 63 = 173 = n$ ✓ (disjoint, all students accounted for)

**Impossibility for $n < 173$:** For any $n < 173$, we have $\frac{990-n}{330} >
 \frac{817}{330} \geq s(n)$, so condition ($\star\star$) fails. Hence no valid a
ssignment exists.

## Answer

The minimum number of students in the school is $\boxed{173}$.
