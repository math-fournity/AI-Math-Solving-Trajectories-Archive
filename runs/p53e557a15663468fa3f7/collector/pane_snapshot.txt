**Proof.**

Let $R = (T - \lambda I)^{-1}$, the bounded inverse of $T - \lambda$, so by hypo
thesis
$$R = S(I - \lambda S)^{-1}.$$
Set $B := (I - \lambda S)^{-1}$, so $R = SB$.

**Case $\lambda = 0$.** Then $S(I-0)^{-1} = S$ is a bounded inverse for $T$, so
$S$ is an inverse for $T$. Done.

**Case $\lambda \neq 0$.** From $(I - \lambda S)B = I$ on $H$:
$$B - \lambda SB = I \implies B - \lambda R = I \implies B = I + \lambda R.$$
Since $R$ is bounded and everywhere defined on $H$, $B = I + \lambda R$ is a bou
nded operator on $H$. As $B = (I-\lambda S)^{-1}$, its range equals $\mathscr{D}
(S)$, so
$$\mathscr{D}(S) = \operatorname{range}(I + \lambda R). \tag{$\star$}$$

**Claim 1: $T(\mathscr{D}(T)) \subseteq \mathscr{D}(S)$, so $ST$ is defined on $
\mathscr{D}(T)$.**

For $u \in \mathscr{D}(T)$, set $v = (T-\lambda)u \in H$, so $u = Rv$. Then
$$Tu = (T-\lambda)u + \lambda u = v + \lambda Rv = (I+\lambda R)v = Bv \in \oper
atorname{range}(B) = \mathscr{D}(S).$$

**Claim 2: $ST = I$ on $\mathscr{D}(T)$.**

With $u, v$ as above ($u = Rv$, $Tu = Bv$), and using $B^{-1} = I - \lambda S$ (
so $I - B^{-1} = \lambda S$, i.e., $S = \frac{1}{\lambda}(I - B^{-1})$ on $\math
scr{D}(S)$):
$$STu = S(Bv) = \tfrac{1}{\lambda}\bigl(Bv - B^{-1}(Bv)\bigr) = \tfrac{1}{\lambd
a}(Bv - v) = \tfrac{1}{\lambda}\bigl(Tu - (T-\lambda)u\bigr) = \tfrac{1}{\lambda
}(\lambda u) = u.$$

**Claim 3: $TS = I$ on $\mathscr{D}(S)$.**

From $S = R(I - \lambda S) = R - \lambda RS$ on $\mathscr{D}(S)$, the operator $
S$ maps $\mathscr{D}(S)$ into $\mathscr{D}(T)$ (since $R$ maps into $\mathscr{D}
(T)$), so $TS$ is defined on $\mathscr{D}(S)$.

From $(T-\lambda)R = I$ on $H$ we get $TR = I + \lambda R$. For $u \in \mathscr{
D}(S)$:
$$TSu = T(Ru - \lambda RSu) = TRu - \lambda\, T(RSu) = (I+\lambda R)u - \lambda(
I+\lambda R)(Su)$$
$$= u + \lambda Ru - \lambda Su - \lambda^2 RSu = u + \lambda\underbrace{(Ru - \
lambda RSu)}_{= Su} - \lambda Su = u + \lambda Su - \lambda Su = u.$$

**Conclusion.** $TS = I$ on $\mathscr{D}(S)$ and $ST = I$ on $\mathscr{D}(T)$, s
o $S$ is an inverse for $T$. $\blacksquare$
