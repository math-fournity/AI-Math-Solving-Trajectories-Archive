## Proof

**Yes**, such constants $H > 0$ and $K$ exist.

**Key observation.** Since $A$ is continuous on $[0,\infty)$, it is in particula
r continuous at $0$. Therefore
$$\lim_{h\to 0} A(h) = A(0).$$
The hypothesis that this limit is invertible means $A(0)$ is invertible, i.e., $
\det(A(0)) \neq 0$.

**Step 1: Establishing condition (1).** The determinant is a polynomial in the e
ntries of a matrix, hence a continuous function of $h$. Since $\det(A(0)) \neq 0
$, by continuity there exists $H_1 > 0$ such that for all $h \in [0, H_1]$,
$$|\det(A(h))| \geq \tfrac{1}{2}|\det(A(0))| > 0.$$
In particular $\det(A(h)) \neq 0$ for all $h \in [0, H_1)$, giving condition (1)
 on this interval.

**Step 2: Establishing condition (2).** The interval $[0, H_1]$ is compact and $
A$ is continuous, so the scalar function $h \mapsto \|A(h)\|$ (spectral norm is
continuous) attains a maximum. Set
$$M := \max_{h \in [0, H_1]} \|A(h)\| < \infty.$$
Then $\|A(h)\| \leq M$ for all $h \in [0, H_1) \subseteq [0, H_1]$.

**Step 3: Establishing condition (3).** For $h \in [0, H_1]$, since $\det(A(h))
\neq 0$, the inverse exists and is given by
$$A(h)^{-1} = \frac{\operatorname{adj}(A(h))}{\det(A(h))},$$
where $\operatorname{adj}(A(h))$ is the adjugate, whose entries are polynomials
in the entries of $A(h)$, hence continuous in $h$. On the compact set $[0, H_1]$
:

- $h \mapsto \det(A(h))$ is continuous and satisfies $|\det(A(h))| \geq \tfrac{1
}{2}|\det(A(0))|$, so $1/|\det(A(h))| \leq 2/|\det(A(0))|$.
- $h \mapsto \|\operatorname{adj}(A(h))\|$ is continuous (adjugate entries conti
nuous, norm continuous), hence bounded: $\|\operatorname{adj}(A(h))\| \leq C$ fo
r some $C < \infty$.

Therefore
$$\|A(h)^{-1}\| \leq \frac{\|\operatorname{adj}(A(h))\|}{|\det(A(h))|} \leq \fra
c{2C}{|\det(A(0))|} =: N < \infty$$
for all $h \in [0, H_1]$, and in particular for all $h \in [0, H_1)$.

**Step 4: Combining.** Set $H := H_1$ and $K := \max(M, N)$. Then for every $h \
in [0, H)$:

1. $\det(A(h)) \neq 0$,
2. $\|A(h)\| \leq M \leq K$,
3. $\|A(h)^{-1}\| \leq N \leq K$.

Thus the desired constants exist. $\blacksquare$
