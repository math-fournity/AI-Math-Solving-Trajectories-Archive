Looking at this problem, I need to find N(n), the maximum number of triples $(a_
i, b_i, c_i)$ of non-negative integers with $a_i + b_i + c_i = n$, where all $a_
i$'s are distinct, all $b_i$'s are distinct, and all $c_i$'s are distinct.

## Upper Bound

Each coordinate takes values in $\{0, 1, \ldots, n\}$. With $N$ triples, the sum
 of $N$ distinct non-negative integers is at least $0 + 1 + \cdots + (N-1) = \fr
ac{N(N-1)}{2}$. Since $\sum(a_i + b_i + c_i) = Nn$:

$$Nn = \sum a_i + \sum b_i + \sum c_i \geq 3 \cdot \frac{N(N-1)}{2}$$

This gives $N \leq \frac{2n}{3} + 1$, so $N \leq \left\lfloor \frac{2n}{3} \righ
t\rfloor + 1$.

## Construction Achieving the Bound

I construct optimal sets for each residue of $n \bmod 3$.

**Case $n = 3k$ ($N = 2k+1$):** Set $a_i = i$, $b_i = (k+i) \bmod (2k+1)$ for $i
 = 0, \ldots, 2k$. Since $\gcd(k, 2k+1) = 1$, the $b_i$ form a permutation of $\
{0, \ldots, 2k\}$. The $c_i = 3k - i - b_i$ values are:
- For $i = 0, \ldots, k$: $c_i = 2k - 2i$ (even values $2k, 2k-2, \ldots, 0$)
- For $i = k+1, \ldots, 2k$: $c_i = 4k+1-2i$ (odd values $2k-1, 2k-3, \ldots, 1$
)

Together $\{0, 1, \ldots, 2k\}$ — all distinct. ✓

**Case $n = 3k+1$ ($N = 2k+1$):** Use the same $a_i, b_i$ as above; then $c_i =
(3k+1) - i - b_i = 1 + c_i^{(3k)}$, giving $C = \{1, 2, \ldots, 2k+1\}$, all dis
tinct. ✓

**Case $n = 3k+2$ ($N = 2k+2$):** Take the triple $(0, 0, 3k+2)$ plus the $n = 3
k$ construction shifted by 1: triples $(i'+1,\; b_{i'}+1,\; c_{i'}^{(3k)})$ for
$i' = 0, \ldots, 2k$. This gives:
- $A = \{0\} \cup \{1, \ldots, 2k+1\} = \{0, \ldots, 2k+1\}$ ✓
- $B = \{0\} \cup \{1, \ldots, 2k+1\} = \{0, \ldots, 2k+1\}$ ✓
- $C = \{3k+2\} \cup \{0, 1, \ldots, 2k\}$ ✓

All sums equal $3k+2$. ✓ (Verified for small cases: $n=2,5,8$.)

Therefore $N(n) = \left\lfloor \frac{2n}{3} \right\rfloor + 1$ for all $n \geq 2
