**Problem.** Let $p$ be prime. Find all positive integers $a, b$ such that
$$S_1 = \frac{4a+p}{b}+\frac{4b+p}{a} \quad\text{and}\quad S_2 = \frac{a^{2}}{b}
+\frac{b^{2}}{a}$$
are both integers.

## Proof

**Reduction via $\gcd$.** Let $d = \gcd(a,b)$, and write $a = dx,\ b = dy$ with
$\gcd(x,y)=1$. Then
$$S_2 = \frac{d^3(x^3+y^3)}{d^2 xy} = \frac{d(x^3+y^3)}{xy}.$$
Since $\gcd(x,y)=1$, we have $\gcd(x,\, x^3+y^3)=\gcd(x,y^3)=1$ and likewise $\g
cd(y,\,x^3+y^3)=1$, hence $\gcd(xy,\, x^3+y^3)=1$. Therefore $xy \mid d$; write
$d = kxy$ with $k \geq 1$. Thus
$$a = kx^{2}y,\qquad b = kxy^{2}.$$

**The first expression.** Substituting,
$$S_1 = \frac{4k^{2}x^{2}y^{2}(x^{2}+y^{2}) + pkxy(x+y)}{k^{2}x^{3}y^{3}} = \fra
c{4kxy(x^{2}+y^{2})+p(x+y)}{kx^{2}y^{2}}.$$
So we need
$$kx^{2}y^{2} \;\Big|\; 4kxy(x^{2}+y^{2})+p(x+y).\tag{$\ast$}$$

**Determining $x$ and $y$.** Reducing $(\ast)$ modulo $x$: the right side is $\e
quiv p\,y \pmod{x}$, so $x \mid py$. Since $\gcd(x,y)=1$, this gives $x \mid p$,
 hence $x \in \{1, p\}$. By symmetry $y \in \{1, p\}$. The pair $(x,y)=(p,p)$ is
 excluded since $\gcd(p,p)\neq 1$. So the remaining cases are $(x,y) \in \{(1,1)
,\, (p,1),\, (1,p)\}$.

---

**Case 1: $x = y = 1$.** Then $a = b = k$, and
$$S_1 = \frac{2(4k+p)}{k} = 8 + \frac{2p}{k},$$
so we need $k \mid 2p$. This gives $k \in \{1, 2, p, 2p\}$ (all divisors of $2p$
). One checks $S_2 = 2k$ is always integral. Hence
$$(a,b) = (k,k),\quad k \mid 2p.$$

---

**Case 2: $(x,y) = (p,1)$** (Case 3 $(1,p)$ is symmetric). Then $a = kp^{2},\ b
= kp$, and $(\ast)$ becomes
$$kp^{2} \;\Big|\; 4kp(p^{2}+1)+p(p+1)=p\bigl[4k(p^{2}+1)+(p+1)\bigr],$$
i.e. $kp \mid 4k(p^{2}+1)+(p+1)$.

First note $p \nmid k$: if $p \mid k$, then the expression $\equiv p+1 \equiv 1
\pmod{p}$, contradicting $p \mid$ it. So $\gcd(k,p)=1$, and by CRT the divisibil
ity $kp \mid N$ splits as:

- **mod $p$:** $4k(p^{2}+1)+(p+1) \equiv 4k+1 \pmod{p}$, so $p \mid 4k+1$.
- **mod $k$:** $4k(p^{2}+1)+(p+1) \equiv p+1 \pmod{k}$, so $k \mid p+1$.

For $p=2$: $p \mid 4k+1$ is impossible (left side is odd), so no solutions here.
 For odd $p$, the conditions are
$$p \mid 4k+1 \quad\text{and}\quad k \mid p+1,\qquad \gcd(k,p)=1\ (\text{automat
ic}).$$
This yields $(a,b) = (kp^{2}, kp)$; by symmetry $(a,b) = (kp, kp^{2})$ under the
 same conditions.

**Verification of a sample.** For $p=3$: Case 1 gives $(1,1),(2,2),(3,3),(6,6)$.
 Cases 2–3 need $3\mid 4k+1$ (i.e. $k\equiv 2\!\pmod 3$) and $k\mid 4$, giving $
k=2$, hence $(18,6)$ and $(6,18)$. Direct check: for $(18,6)$, $S_2 = 54+2=56$,
$S_1 = \tfrac{75}{6}+\tfrac{27}{18} = \tfrac{25}{2}+\tfrac{3}{2}=14$. ✓

## Answer

All positive integer solutions $(a,b)$ are exactly:

1. **$(a,b) = (d,\, d)$** where $d$ is any positive divisor of $2p$ (i.e. $d \in
 \{1, 2, p, 2p\}$);

2. **$(a,b) = (d\,p^{2},\, d\,p)$** or **$(d\,p,\, d\,p^{2})$**, where $d$ is a
positive divisor of $p+1$ satisfying $p \mid (4d+1)$ (this family is nonempty on
ly for odd primes $p$).
