# Problem

A specialized automated laboratory is testing the durability of a synthetic polymer chain. The process begins with a sample containing exactly 12 active chemical bonds. 

The laboratory operates in discrete cycles. In each cycle, the current number of active bonds, $n$, is measured. A computer then randomly selects a new number of bonds for the next cycle, $m$, from the set of all positive divisors of $n$. Each divisor has an equal probability of being selected. This new value $m$ (which could be the same as $n$) becomes the starting count for the following cycle.

The experiment continues cycle after cycle until the sample reaches a state where only 1 active bond remains. As soon as a cycle results in exactly 1 bond, the experiment terminates immediately.

Including the initial measurement of 12 bonds and the final measurement of 1 bond, what is the expected total number of measurements recorded in the laboratory's log for a single complete experiment?
