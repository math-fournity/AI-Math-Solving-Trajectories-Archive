# Asymptotic Formula for the Number of Integer Partitions

## Problem

Find the asymptotic formula for $p_n$, the number of integer partitions of $n$.

## Setup: The Generating Function

The generating function for the partition numbers is

$$F(q) = \sum_{n=0}^{\infty} p_n q^n = \prod_{k=1}^{\infty} \frac{1}{1-q^k}, \qq
uad |q|<1.$$

Writing $q = e^{-t}$ with $t > 0$ (so $|q|<1$), we have

$$F(e^{-t}) = \sum_{n=0}^{\infty} p_n e^{-nt} = \prod_{k=1}^{\infty} \frac{1}{1-
e^{-kt}}.$$

By Cauchy's coefficient formula (with $q = e^{-t}$, $dq = -e^{-t}\,dt$),

$$p_n = \frac{1}{2\pi i} \oint \frac{F(q)}{q^{n+1}}\,dq = \frac{e^{nt}}{2\pi}\in
t_{-\pi}^{\pi} F\!\left(e^{-t+i\theta}\right) e^{-in\theta}\,d\theta.$$

The strategy (Hardy–Ramanujan, 1918) is to evaluate this integral by the **saddl
e-point method**: choose $t = t_n$ to sit at the saddle point, show the integran
d is sharply peaked near $\theta = 0$, and extract the leading asymptotics.

## Step 1: Logarithmic Asymptotics of $F(e^{-t})$

Taking logarithms,

$$\log F(e^{-t}) = -\sum_{k=1}^{\infty} \log(1-e^{-kt}) = \sum_{k=1}^{\infty}\su
m_{m=1}^{\infty} \frac{e^{-kmt}}{m} = \sum_{m=1}^{\infty}\frac{1}{m}\cdot\frac{1
}{e^{mt}-1}.$$

Define $\displaystyle P(t) = \sum_{m=1}^{\infty}\frac{1}{m(e^{mt}-1)}$. We need
the behavior of $P(t)$ as $t \to 0^+$.

**Claim:** $P(t) = \frac{\pi^2}{6t} + \frac{1}{2}\log\!\left(\frac{t}{2\pi}\righ
t) + O(t)$ as $t\to 0^+$.

*Proof of claim.* Use the Mellin transform. Since $\frac{1}{e^x - 1} = \frac{1}{
2\pi i}\int_{(c)} \Gamma(s)\zeta(s)\,x^{-s}\,ds$ for $c > 1$, we get

$$P(t) = \sum_{m\ge 1}\frac{1}{m}\cdot\frac{1}{2\pi i}\int_{(c)}\Gamma(s)\zeta(s
)(mt)^{-s}\,ds = \frac{1}{2\pi i}\int_{(c)}\Gamma(s)\zeta(s)\zeta(s+1)\,t^{-s}\,
ds.$$

The integrand $\Gamma(s)\zeta(s)\zeta(s+1)$ has poles at:
- $s = 1$: from $\zeta(s)$, residue $\zeta(2)\cdot t^{-1} = \frac{\pi^2}{6t}$ (s
ince $\zeta(s) \sim \frac{1}{s-1}$ and $\zeta(s+1)$ is regular at $s=1$ with val
ue $\zeta(2)$, and $\Gamma(1)=1$). More precisely, $\zeta(s)\zeta(s+1)$ has a si
mple pole at $s=1$ with residue $\zeta(2) = \pi^2/6$.
- $s = 0$: $\Gamma(s)$ has a simple pole with residue $1$; $\zeta(0) = -1/2$; $\
zeta(s+1) = \zeta(1+s)$ has a simple pole at $s=0$ with residue $1$. So $\zeta(s
)\zeta(s+1)$ near $s=0$: $\zeta(s) = -\frac{1}{2} + \zeta'(0)s + \cdots$ where $
\zeta'(0) = -\frac{1}{2}\log(2\pi)$, and $\zeta(s+1) = \frac{1}{s} + \gamma + \c
dots$. Thus $\zeta(s)\zeta(s+1) = \frac{-1/2}{s} + (\gamma\cdot(-1/2) - \frac{1}
{2}\log(2\pi)) + \cdots$. Combined with $\Gamma(s) = \frac{1}{s} - \gamma + \cdo
ts$, the residue at $s=0$ of $\Gamma(s)\zeta(s)\zeta(s+1)$ is the constant term
of $\zeta(s)\zeta(s+1)$ at $s=0$, which is $-\frac{1}{2}\log(2\pi)$ (the $\gamma
$ terms cancel). So the contribution is $-\frac{1}{2}\log(2\pi)\cdot t^0 = -\fra
c{1}{2}\log(2\pi)$.

Wait—let me be more careful. We need $\text{Res}_{s=0}\,\Gamma(s)\zeta(s)\zeta(s
+1)t^{-s}$. Write $t^{-s} = 1 - s\log t + \cdots$. The product $\Gamma(s)\zeta(s
)\zeta(s+1)$: let $g(s) = \zeta(s)\zeta(s+1)$. Then $g(s) = \frac{a_{-1}}{s} + a
_0 + \cdots$ where $a_{-1} = \text{Res}_{s=0}\,\zeta(s)\zeta(s+1)$. Since $\zeta
(s+1) = \frac{1}{s}+\gamma+\cdots$ and $\zeta(s) = -\frac{1}{2} + \zeta'(0)s + \

Now $\Gamma(s) = \frac{1}{s} - \gamma + \cdots$, so $\Gamma(s)g(s) = \frac{a_{-1
}}{s^2} + \frac{a_0 - \gamma a_{-1}}{s} + \cdots = \frac{-1/2}{s^2} + \frac{-\fr
ac{1}{2}\gamma - \frac{1}{2}\log(2\pi) + \frac{1}{2}\gamma}{s} + \cdots = \frac{
-1/2}{s^2} - \frac{\frac{1}{2}\log(2\pi)}{s} + \cdots$.

Then $\Gamma(s)\zeta(s)\zeta(s+1)t^{-s} = \left(\frac{-1/2}{s^2} - \frac{\frac{1
}{2}\log(2\pi)}{s} + \cdots\right)(1 - s\log t + \cdots)$. The residue (coeffici
ent of $1/s$) is $\frac{1}{2}\log t - \frac{1}{2}\log(2\pi) = \frac{1}{2}\log\!\
frac{t}{2\pi}$.

So shifting the contour to the left and picking up residues at $s=1$ and $s=0$:

$$P(t) = \frac{\pi^2}{6t} + \frac{1}{2}\log\!\left(\frac{t}{2\pi}\right) + O(t),
 \qquad t\to 0^+.$$

This confirms the claim.

## Step 2: The Saddle Point

The integrand for $p_n$ involves $\exp\bigl(nt + P(t)\bigr)$ (up to the angular
part). Define

$$\Phi(t) = nt + P(t) = nt + \frac{\pi^2}{6t} + \frac{1}{2}\log\!\left(\frac{t}{
2\pi}\right) + O(t).$$

The saddle point $t = t_n$ satisfies $\Phi'(t) = 0$:

$$n - \frac{\pi^2}{6t^2} + \frac{1}{2t} + O(1) = 0 \implies \frac{\pi^2}{6t^2} =
 n + \frac{1}{2t} + \cdots.$$

To leading order, $t_n = \frac{\pi}{\sqrt{6n}}$. Refining: let $t_n = \frac{\pi}
{\sqrt{6n}}(1 + \epsilon)$ with $\epsilon = O(n^{-1/2})$. Substituting and solvi
ng to next order gives

$$t_n = \frac{\pi}{\sqrt{6n}} - \frac{1}{4n} + O(n^{-3/2}).$$

## Step 3: Evaluating $\Phi(t_n)$

Substituting $t_n = \frac{\pi}{\sqrt{6n}} + \delta$ (with $\delta = -\frac{1}{4n
} + O(n^{-3/2})$):

$$nt_n = \frac{\pi\sqrt{n}}{\sqrt{6}} + n\delta = \frac{\pi\sqrt{n}}{\sqrt{6}} -
 \frac{1}{4} + O(n^{-1/2}),$$

$$\frac{\pi^2}{6t_n} = \frac{\pi^2}{6}\cdot\frac{\sqrt{6n}}{\pi}\cdot\frac{1}{1+
\delta\sqrt{6n}/\pi} = \frac{\pi\sqrt{n}}{\sqrt{6}}\left(1 - \frac{\delta\sqrt{6
n}}{\pi} + \cdots\right) = \frac{\pi\sqrt{n}}{\sqrt{6}} - \delta n + \cdots = \f
rac{\pi\sqrt{n}}{\sqrt{6}} + \frac{1}{4} + O(n^{-1/2}).$$

So $nt_n + \frac{\pi^2}{6t_n} = \frac{2\pi\sqrt{n}}{\sqrt{6}} + O(n^{-1/2}) = \p
i\sqrt{\frac{2n}{3}} + O(n^{-1/2})$.

The $-1/4$ and $+1/4$ cancel. The logarithmic term:

$$\frac{1}{2}\log\!\left(\frac{t_n}{2\pi}\right) = \frac{1}{2}\log\!\left(\frac{
\pi}{2\pi\sqrt{6n}}\right) + O(n^{-1/2}) = \frac{1}{2}\log\!\left(\frac{1}{2\sqr
t{6n}}\right) + O(n^{-1/2}) = -\frac{1}{2}\log(2\sqrt{6n}) + O(n^{-1/2}).$$

Therefore

$$\Phi(t_n) = \pi\sqrt{\frac{2n}{3}} - \frac{1}{2}\log(2\sqrt{6n}) + O(n^{-1/2})
.$$

## Complete Proof

**Theorem (Hardy–Ramanujan, 1918).** *The number $p_n$ of integer partitions of
$n$ satisfies*

$$p_n \sim \frac{1}{4n\sqrt{3}}\exp\!\left(\pi\sqrt{\frac{2n}{3}}\right) \quad \
text{as } n\to\infty.$$

**Proof.**

**1. Generating function.** The generating function for partitions is

$$F(q) = \sum_{n\ge 0}p_n q^n = \prod_{k=1}^{\infty}\frac{1}{1-q^k}, \quad |q|<1
.$$

Setting $q = e^{2\pi i\tau}$ with $\tau = \frac{\theta+it}{2\pi}$ ($t>0$), we ha
ve $F(q) = q^{1/24}\eta(\tau)^{-1}$ where $\eta(\tau) = q^{1/24}\prod(1-q^n)$ is
 the Dedekind eta function.

**2. Modular transformation.** The key identity is $\eta(-1/\tau) = \sqrt{-i\tau
}\,\eta(\tau)$. With $\tau = \frac{\theta+it}{2\pi}$, we compute $-1/\tau = \fra
c{-2\pi\theta + 2\pi it}{\theta^2+t^2}$. Setting $\tau' = -1/\tau$, we have $\te
xt{Im}(\tau') = \frac{2\pi t}{\theta^2+t^2} \to \infty$ as $t\to 0$ (for bounded
 $\theta$), so $F(e^{2\pi i\tau'}) \to 1$. Expanding:

$$F(e^{i\theta - t}) = e^{(i\theta-t)/24}\sqrt{\frac{t-i\theta}{2\pi}}\exp\!\lef
t(\frac{\pi^2(t+i\theta)}{6(\theta^2+t^2)}\right)(1+o(1)),$$

uniformly for $|\theta| \le t^{2/3}$ as $t\to 0^+$. Outside this region, $|F(e^{
i\theta-t})|$ is exponentially smaller (the integrand is dominated by the $\thet
a\approx 0$ neighborhood).

**3. Cauchy integral and saddle point.** By Cauchy's formula,

$$p_n = \frac{e^{nt}}{2\pi}\int_{-\pi}^{\pi}F(e^{-t+i\theta})\,e^{-in\theta}\,d\
theta.$$

Define $h(\theta) = \log F(e^{-t+i\theta}) - in\theta$. From the modular expansi
on:

$$h(\theta) = -\frac{t}{24} + \frac{1}{2}\log\frac{t-i\theta}{2\pi} + \frac{\pi^
2(t+i\theta)}{6(\theta^2+t^2)} - in\theta + o(1).$$

The saddle point $t = t_n$ is determined by $h'(0) = 0$ (imaginary part, since t
he real part is even):

$$n = \frac{\pi^2}{6t_n^2} + \frac{1}{24}, \qquad\text{so}\quad t_n = \frac{\pi}
{\sqrt{6n-1/4}} = \frac{\pi}{\sqrt{6n}}\left(1 + O(n^{-1})\right).$$

**4. Evaluation at the saddle.** At $\theta = 0$:

$$h(0) = -\frac{t_n}{24} + \frac{1}{2}\log\frac{t_n}{2\pi} + \frac{\pi^2}{6t_n}.
$$

The second derivative:

$$h''(0) = -\frac{\pi^2}{3t_n^3} + \frac{1}{2t_n^2} = -\frac{\pi^2}{3t_n^3}\left
(1 + O(t_n)\right).$$

(The $-\frac{\pi^2}{3t_n^3}$ comes from $\frac{d^2}{d\theta^2}\frac{\pi^2 t}{6(\
theta^2+t^2)}\big|_0 = -\frac{\pi^2}{3t^3}$; the $+\frac{1}{2t_n^2}$ from $\frac
{d^2}{d\theta^2}\frac{1}{2}\log|t-i\theta|\big|_0$; the former dominates as $t_n
\to 0$.)

**5. Laplace's method.** Since $h(\theta)$ has a sharp maximum at $\theta=0$ wit
h $h''(0) < 0$ and $|h''(0)|\to\infty$, Laplace's method gives:

$$\int_{-\pi}^{\pi}e^{h(\theta)}\,d\theta \sim e^{h(0)}\sqrt{\frac{2\pi}{|h''(0)
|}} = e^{h(0)}\sqrt{\frac{6\pi t_n^3}{\pi^2}} = e^{h(0)}\,t_n^{3/2}\sqrt{\frac{6
}{\pi}}.$$

**6. Assembly.** Combining:

$$p_n \sim \frac{e^{nt_n}}{2\pi}\cdot e^{h(0)}\cdot t_n^{3/2}\sqrt{\frac{6}{\pi}
} = \frac{e^{nt_n}}{2\pi}\exp\!\left(-\frac{t_n}{24}+\frac{1}{2}\log\frac{t_n}{2
\pi}+\frac{\pi^2}{6t_n}\right)t_n^{3/2}\sqrt{\frac{6}{\pi}}.$$

$$= \frac{t_n^{3/2}}{2\pi}\sqrt{\frac{t_n}{2\pi}}\sqrt{\frac{6}{\pi}}\exp\!\left
(nt_n+\frac{\pi^2}{6t_n}-\frac{t_n}{24}\right) = \frac{t_n^2\sqrt{6}}{2\pi\sqrt{
2\pi}\sqrt{\pi}}\exp\!\left(nt_n+\frac{\pi^2}{6t_n}-\frac{t_n}{24}\right).$$

$$= \frac{t_n^2\sqrt{3}}{2\pi^2}\exp\!\left(nt_n+\frac{\pi^2}{6t_n}-\frac{t_n}{2
4}\right).$$

**7. Leading asymptotics.** With $t_n = \frac{\pi}{\sqrt{6n}}(1+O(n^{-1}))$:

- **Prefactor:** $\frac{\sqrt{3}\,t_n^2}{2\pi^2} = \frac{\sqrt{3}}{2\pi^2}\cdot\
frac{\pi^2}{6n}(1+O(n^{-1})) = \frac{\sqrt{3}}{12n}(1+O(n^{-1})) = \frac{1}{4n\s
qrt{3}}(1+O(n^{-1}))$.

- **Exponent:** $nt_n + \frac{\pi^2}{6t_n} = \frac{\pi\sqrt{n}}{\sqrt{6}} + \fra
c{\pi\sqrt{n}}{\sqrt{6}} + O(n^{-1/2}) = \pi\sqrt{\frac{2n}{3}} + O(n^{-1/2})$,
and $e^{O(n^{-1/2})} = 1 + O(n^{-1/2})$.

Therefore:

$$p_n \sim \frac{1}{4n\sqrt{3}}\exp\!\left(\pi\sqrt{\frac{2n}{3}}\right). \qquad
 \blacksquare$$
