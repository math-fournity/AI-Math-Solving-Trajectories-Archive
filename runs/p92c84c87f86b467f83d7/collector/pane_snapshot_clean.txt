## Proof

We work in $\mathbb{Q}_p$ (or $\mathbb{Z}_p$) equipped with the $p$-adic absolut
e value $|\cdot|_p$. The $p$-adic ball of center $x_0$ and radius $r$ is
$$B(x_0, r) = \{x : |x - x_0|_p \leq r\}.$$
The predicate $K_{x_0,r}\,\alpha$ expresses membership: $K_{x_0,r}\,\alpha$ hold
s if and only if $\alpha \in B(x_0,r)$, i.e., $|\alpha - x_0|_p \leq r$.

---

**Step 1 — The center $x_0$ lies in the class $[\alpha_0]$.**

The center is defined as $x_0 = \mu([\alpha_0])$, where $[\alpha_0]$ is the equi
valence class of $\alpha_0$ under the relation
$$\beta \sim \gamma \iff |\beta - \gamma|_p \leq \tfrac{1}{2}.$$
This class is precisely the ball $B(\alpha_0, \tfrac{1}{2})$. The map $\mu$ sele
cts a canonical representative from each class, so $x_0 \in [\alpha_0] = B(\alph
a_0, \tfrac{1}{2})$, giving
$$|x_0 - \alpha_0|_p \leq \tfrac{1}{2}. \tag{1}$$

---

**Step 2 — Every point of a $p$-adic ball is a center: $B(\alpha_0, \tfrac{1}{2}
) = B(x_0, \tfrac{1}{2})$.**

The $p$-adic absolute value satisfies the strong (non-Archimedean) triangle ineq
uality:
$$|a + b|_p \leq \max(|a|_p,\, |b|_p).$$
A fundamental consequence is that any point inside a $p$-adic ball serves as a c
enter of that ball. Concretely, using (1):

- *($\subseteq$)* If $x \in B(\alpha_0, \tfrac{1}{2})$, then
$$|x - x_0|_p = |(x - \alpha_0) + (\alpha_0 - x_0)|_p \leq \max\bigl(|x-\alpha_0
|_p,\; |\alpha_0 - x_0|_p\bigr) \leq \tfrac{1}{2},$$
so $x \in B(x_0, \tfrac{1}{2})$.

- *($\supseteq$)* If $x \in B(x_0, \tfrac{1}{2})$, then
$$|x - \alpha_0|_p = |(x - x_0) + (x_0 - \alpha_0)|_p \leq \max\bigl(|x-x_0|_p,\
; |x_0-\alpha_0|_p\bigr) \leq \tfrac{1}{2},$$
so $x \in B(\alpha_0, \tfrac{1}{2})$.

Hence $B(\alpha_0, \tfrac{1}{2}) = B(x_0, \tfrac{1}{2})$. Since $\alpha_0 \in B(
\alpha_0, \tfrac{1}{2})$ trivially, we obtain
$$\alpha_0 \in B(x_0, \tfrac{1}{2}), \quad\text{i.e.,}\quad K_{x_0,\frac{1}{2}}\
,\alpha_0 \text{ holds.} \tag{2}$$

---

**Step 3 — The biconditional in $T_1$ transfers membership from $\alpha_0$ to $\
alpha$.**

The theory
$$T_1 = \bigl\{\, K_{x_0,\frac{1}{2}}\,\alpha \iff K_{x_0,\frac{1}{2}}\,\alpha_0
 \,\bigr\}$$
asserts that $\alpha$ belongs to $B(x_0, \tfrac{1}{2})$ if and only if $\alpha_0
$ does. From (2) we know $K_{x_0,\frac{1}{2}}\,\alpha_0$ holds. Applying the for
ward direction ($\Leftarrow$) of the biconditional:
$$K_{x_0,\frac{1}{2}}\,\alpha_0 \;\Longrightarrow\; K_{x_0,\frac{1}{2}}\,\alpha.
 \tag{3}$$

---

**Step 4 — Conclusion.**

$K_{x_0,\frac{1}{2}}\,\alpha$ means precisely $|\alpha - x_0|_p \leq \tfrac{1}{2
}$, which is the defining condition for the code of $\alpha$ to belong to the $p
$-adic ball
$$B\!\left(x_0,\, \tfrac{1}{2}\right), \qquad x_0 = \mu([\alpha_0]).$$

Thus the theory $T_1$ ensures that the code of $\alpha$ lies in the $p$-adic bal
l of center $x_0 = \mu([\alpha_0])$ and radius $\frac{1}{2}$. $\blacksquare$
