## Proof

**Setup.** A sequence of $k$ steps is a function $s:\{1,\dots,k\}\to\{1,\dots,2n
\}$ (which lamp is switched at each step). Lamp $i$ ends on iff it is switched a
n odd number of times; it ends off iff switched an even number of times.

- **$N$**: number of sequences $s:\{1,\dots,k\}\to\{1,\dots,2n\}$ where each of
$1,\dots,n$ appears an odd number of times and each of $n{+}1,\dots,2n$ appears
an even number of times.
- **$M$**: number of sequences $s:\{1,\dots,k\}\to\{1,\dots,n\}$ where each of $
1,\dots,n$ appears an odd number of times.

**Parity-counting formula.** For an alphabet of size $m$ with required parities
$p_i\in\{0,1\}$ ($p_i=1$ means odd), the number of length-$k$ sequences is
$$C(m;\,p_1,\dots,p_m)=\frac{1}{2^m}\sum_{\varepsilon\in\{0,1\}^m}(-1)^{\sum_i \
varepsilon_i p_i}\bigl(m-2|\varepsilon|\bigr)^k,$$
where $|\varepsilon|=\sum_i\varepsilon_i$. This follows from the identity $\math
bf{1}[c_i\equiv p_i\pmod 2]=\tfrac12\sum_{\varepsilon_i\in\{0,1\}}(-1)^{\varepsi
lon_i(c_i+p_i)}$ and the multinomial theorem: the inner sum over $(c_1,\dots,c_m
)$ with $\sum c_i=k$ gives $\bigl(\sum_i(-1)^{\varepsilon_i}\bigr)^k=(m-2|\varep
silon|)^k$.

**Computing $M$.** Here $m=n$, all $p_i=1$, so $\sum\varepsilon_i p_i=|\varepsil
on|$:
$$M=\frac{1}{2^n}\sum_{j=0}^{n}(-1)^{j}\binom{n}{j}(n-2j)^{k}. \tag{$\star$}$$

**Computing $N$.** Here $m=2n$; split $\varepsilon=(\varepsilon',\varepsilon'')$

on'|+|\varepsilon''|$:
$$N=\frac{1}{2^{2n}}\sum_{a=0}^{n}\sum_{b=0}^{n}(-1)^{a}\binom{n}{a}\binom{n}{b}
\bigl(2n-2a-2b\bigr)^{k}=\frac{2^{k}}{2^{2n}}\sum_{a,b}(-1)^{a}\binom{n}{a}\bino
m{n}{b}(n-a-b)^{k}.$$

**Collapsing the double sum.** Set $c=a+b$ and collect terms:
$$\sum_{a=0}^{n}\sum_{b=0}^{n}(-1)^{a}\binom{n}{a}\binom{n}{b}(n-a-b)^{k}=\sum_{
c=0}^{2n}(n-c)^{k}\underbrace{\sum_{a}(-1)^{a}\binom{n}{a}\binom{n}{c-a}}_{=[x^c
]\,(1-x)^{n}(1+x)^{n}}.$$
Since $(1-x)^n(1+x)^n=(1-x^2)^n=\sum_{j=0}^{n}(-1)^{j}\binom{n}{j}x^{2j}$, the i
nner coefficient equals $(-1)^{j}\binom{n}{j}$ when $c=2j$ is even, and $0$ when
 $c$ is odd. Thus
$$\sum_{a,b}(-1)^{a}\binom{n}{a}\binom{n}{b}(n-a-b)^{k}=\sum_{j=0}^{n}(-1)^{j}\b
inom{n}{j}(n-2j)^{k}.$$
This is exactly the sum $(\star)$ appearing in $M$. Therefore
$$N=\frac{2^{k}}{2^{2n}}\cdot\bigl(2^{n}\,M\bigr)=\frac{2^{k}}{2^{n}}\,M=2^{k-n}
\,M.$$
