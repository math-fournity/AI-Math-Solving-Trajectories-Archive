## Proof

Let $r(x) = p(x) - x$, so $p(x) = x + r(x)$. Then:
$$p(p(x)) = p(x) + r(p(x)) = x + r(x) + r(p(x))$$
so $p(p(x)) - x = r(x) + r(p(x))$. The condition becomes:
$$r(x)^2 \mid r(x) + r(p(x)). \tag{$\star$}$$

**Key observation:** Every root of $r$ is a fixed point of $p$ (if $r(\alpha)=0$
 then $p(\alpha)=\alpha$), hence $r(p(\alpha)) = r(\alpha) = 0$. So $r(x) \mid r
(p(x))$ automatically, and ($\star$) is the stronger condition $r(x)^2 \mid r(x)
 + r(p(x))$.

We work over $\mathbb{C}$ (equivalent to $\mathbb{R}$ since all polynomials are
real). Let $\alpha$ be a root of $r$ with multiplicity $m$, and write $r(x) = c(
x-\alpha)^m + d(x-\alpha)^{m+1} + \cdots$ with $c \neq 0$, setting $u = x - \alp
ha$.

**Case $m \geq 2$:** Then $p(x) - \alpha = u + r(x) = u(1 + cu^{m-1} + \cdots)$,
 where the correction starts at order $m-1 \geq 1$. Computing:
$$r(p(x)) = c\,u^m\bigl(1 + mc\,u^{m-1} + \cdots\bigr) + d\,u^{m+1} + \cdots = c
\,u^m + mc^2 u^{2m-1} + d\,u^{m+1} + \cdots$$
$$r(x) + r(p(x)) = 2c\,u^m + 2d\,u^{m+1} + \cdots$$
The leading term is $2c\,u^m$ with $2c \neq 0$, so the multiplicity of $\alpha$
in $r(x)+r(p(x))$ is exactly $m < 2m$. Thus ($\star$) **fails** for $m \geq 2$.

**Case $m = 1$:** Write $r(x) = cu + du^2 + eu^3 + \cdots$. Then $p(x)-\alpha =
u + r(x) = (1+c)u + du^2 + \cdots$. Setting $s = p(x)-\alpha$:
$$r(x) + r(p(x)) = (cu + du^2 + \cdots) + (cs + ds^2 + \cdots) = c(u+s) + d(u^2+
s^2) + \cdots$$
The coefficient of $u^1$ is $c(1 + (1+c)) = c(2+c)$. For ($\star$) we need multi
plicity $\geq 2$, so $c(2+c) = 0$. Since $c \neq 0$ (simple root), we need $c =
-2$, i.e., $r'(\alpha) = -2$, equivalently $p'(\alpha) = 1 + r'(\alpha) = -1$.

**Verification that $c = -2$ suffices:** When $r'(\alpha) = -2$, we have $s = -u
 + du^2 + \cdots$, so $u + s = du^2 + \cdots$ (linear terms cancel). Then:
- $r(\alpha) + r(p(\alpha)) = 0$ (multiplicity $\geq 1$),
- $\frac{d}{dx}[r+r\circ p]\big|_\alpha = r'(\alpha) + r'(\alpha)\,p'(\alpha) =
-2 + (-2)(-1) = 0$ (multiplicity $\geq 2$),
- $\frac{d^2}{dx^2}[r+r\circ p]\big|_\alpha = 2r''(\alpha) + r'(\alpha)\,p''(\al
pha) = 2r''(\alpha) - 2r''(\alpha) = 0$ (since $p''=r''$), giving multiplicity $
\geq 3$.

So multiplicity $\geq 3 \geq 2 = 2m$. ✓

**Summary of conditions on $r$:** Every root of $r$ must be simple, and $r'(\alp
ha) = -2$ at every root $\alpha$.

**Determining all such $r$:** The condition $r'(\alpha_i) = -2$ at every root $\
alpha_i$ means $r(x) \mid r'(x) + 2$.

- If $\deg r \geq 2$: then $\deg(r'+2) = \deg r - 1 < \deg r$, so $r \mid r'+2$
forces $r'+2 \equiv 0$, giving $r(x) = -2x + C$ (degree 1), contradicting $\deg
r \geq 2$. **No solutions.**

- If $\deg r = 1$: $r(x) = ax + b$ with $a \neq 0$. The unique root is $\alpha =
 -b/a$, and $r'(\alpha) = a = -2$. So $r(x) = -2x + b$, giving $p(x) = x + r(x)
= -x + b$.

- If $\deg r = 0$: $r(x) = C$ (constant, possibly $0$). No roots, so conditions
are vacuous. Then $p(x) = x + C$, $p(p(x))-x = 2C$, $(p(x)-x)^2 = C^2$, and $q =
 2/C$ (or any $q$ if $C=0$). ✓

**Verification of both families:**

- **$p(x) = x + C$:** $p(p(x)) - x = 2C$, $(p(x)-x)^2 = C^2$, so $q = 2/C$ (cons
tant polynomial) works for $C \neq 0$; for $C = 0$, $p = \mathrm{id}$ and $q$ ar
bitrary. ✓

- **$p(x) = -x + C$:** $p(p(x)) = -(-x+C)+C = x$, so $p(p(x))-x = 0 = (p(x)-x)^2
 \cdot 0$, with $q = 0$. ✓

## Answer

The real polynomials $p$ for which such a $q$ exists are exactly:
$$\boxed{p(x) = x + c \quad \text{or} \quad p(x) = -x + c}$$
for any real constant $c$.
