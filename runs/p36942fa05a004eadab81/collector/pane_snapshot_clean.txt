## 证明

将外接圆 Γ 置于以原点 O 为中心的单位圆上。设 M₁ 为不包含 A 的弧 BC 的中点；则 M
（包含 A 的弧 BC 的中点）是 M₁ 的对径点。我们设定坐标，使得 M₁ = (1, 0) 且 M = (
−1, 0)。

由于 M₁ 是不包含 A 的弧 BC 的中点，点 B 和 C 关于 x 轴对称；记
$$B = (\cos\beta,\, \sin\beta), \qquad C = (\cos\beta,\, -\sin\beta)$$
对于某个 0 < β < π。点 A 位于经过 M = (−1, 0) 的弧 BC 上，因此记 A = (cos α, sin
 α)，其中 α ∈ (β, 2π−β)。设 a = cos α，s = sin α，c = cos β。

∠BAC 的内角平分线为直线 AM₁。由于 BC 是垂直线 x = c，点 K = AM₁ ∩ BC 满足
$$K = \Big(c,\; \frac{s(1-c)}{1-a}\Big).$$

**求 A'。** 直线 MK（其中 M = (−1, 0)）在 A' 处再次与 Γ 相交。对 P = M + λ(K − M
) 进行参数化并求解 |P|² = 1（利用 s² = 1 − a² = (1 − a)(1 + a)）可得：
$$A' = \Big(\frac{2c - a(1+c^2)}{D},\; \frac{s(1-c^2)}{D}\Big), \qquad D := 1 +
c^2 - 2ac.$$

**求 T。** 单位圆在 (x₀, y₀) 处的切线方程为 x₀x + y₀y = 1。联立 A = (a, s) 和 A'
 = (x', y') 处的切线方程可得
$$T = \Big(c,\; \frac{1-ac}{s}\Big).$$
（验证：Δ = ay' − sx' = 2s(a−c)/D，因此 T_x = (y'−s)/Δ = c 且 T_y = (a−x')/Δ = (
1−ac)/s。）

特别地，**T_x = c**，因此 **T 位于直线 BC 上**（即直线 x = c）。由于 K_x = c，直
线 TK 恰好为 BC。

**求 R。** 过 A 且垂直于 AK (= AM₁) 的直线具有方向向量 (s, 1−a)（垂直于 (1−a, −s
)）。该直线上 x 坐标为 c 的点为
$$R_0 = \Big(c,\; \frac{(1-a)(1+c)}{s}\Big),$$
由 a + u·s = c，即 u = (c−a)/s，以及 y = s + u(1−a) 得出。

我们断言 R = R₀，即 R₀ 也位于过 A' 且垂直于 A'K 的直线上。这等价于 (R₀ − A')·(K
− A') = 0。

计算所需的差值：
$$c - x' = \frac{(a-c)(1-c^2)}{D}, \qquad y_K - y' = \frac{s(1-c)^2(a-c)}{(1-a)D
}, \qquad R_{0,y} - y' = \frac{(1-a)(1+c)^2(c-a)}{s\,D}.$$

则
$$(R_0 - A')\cdot(K-A') = (c-x')^2 + (R_{0,y}-y')(y_K - y')$$
$$= \frac{(a-c)^2(1-c^2)^2}{D^2} + \frac{(1-a)(1+c)^2(c-a)}{sD}\cdot\frac{s(1-c)
^2(a-c)}{(1-a)D}$$
$$= \frac{(a-c)^2(1-c)^2(1+c)^2}{D^2} - \frac{(a-c)^2(1-c)^2(1+c)^2}{D^2} = 0.$$

因此 R₀ 位于过 A' 且垂直于 A'K 的直线上，故 R = R₀，且 R_x = c。

**结论。** 所有三点 T = (c, (1−ac)/s)、K = (c, s(1−c)/(1−a)) 和 R = (c, (1−a)(1+
c)/s) 的 x 坐标均等于 c = cos β；也就是说，这三点均位于直线 BC 上。因此 T, R, K
共线。 ∎
