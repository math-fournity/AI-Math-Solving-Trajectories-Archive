**Analysis of $S := Y_1 + 2Y_2 + 4Y_3 + 8Y_4$.**

Expanding:
$$S = \sum_{k=1}^\infty \frac{1}{16^k}\bigl(X_k^{(1)} + 2X_k^{(2)} + 4X_k^{(3)}

Define $B_k := X_k^{(1)} + 2X_k^{(2)} + 4X_k^{(3)} + 8X_k^{(4)}$. Since the four
 $X_k^{(i)}$ are independent Bernoulli(1/2), $B_k$ is a 4-bit binary number, uni
formly distributed over $\{0, 1, 2, \ldots, 15\}$, and the $B_k$ are independent
 across $k$.

Therefore $S = \sum_{k=1}^\infty B_k / 16^k$ with $B_k$ iid uniform on $\{0,\ldo
ts,15\}$. This is precisely the base-16 expansion of a random variable uniformly
 distributed on $[0,1]$. (The standard result: iid digits uniform on $\{0,\ldots
,b-1\}$ in base $b$ yield $\mathrm{Uniform}[0,1]$; the countable set of points w
ith non-unique expansions has measure zero and does not affect the distribution.
)

**Conclusion:** $S$ is absolutely continuous (indeed, uniform on $[0,1]$). ✓

**Analysis of $T := Y_1 + 4Y_3$.**

Expanding:
$$T = \sum_{k=1}^\infty \frac{1}{16^k}\bigl(X_k^{(1)} + 4\,X_k^{(3)}\bigr).$$

Define $D_k := X_k^{(1)} + 4\,X_k^{(3)}$. Since $X_k^{(1)}$ and $X_k^{(3)}$ are
independent Bernoulli(1/2), $D_k$ takes values in $\{0, 1, 4, 5\}$, each with pr

So $T = \sum_{k=1}^\infty D_k/16^k$ with $D_k$ iid uniform on $\{0,1,4,5\}$. The

**$K$ has Lebesgue measure zero.** At each level of the construction, we select
4 sub-intervals out of 16 (those starting with digits $0, 1, 4, 5$), keeping a f

- $Y_1 + 2Y_2 + 4Y_3 + 8Y_4$ **is** absolutely continuous (it is uniform on $[0,
