# Problem

In a specialized laboratory, an automated sorting system processes three types of chemical canisters: **Type A (Alkali)**, **Type B (Boron)**, and **Type C (Carbon)**. Every time the system processes a canister, it generates a heat signature measured in units based on the canisters still waiting in the queue:

- When a **Type A** canister is processed, it generates heat equal to the number of **Type C** canisters remaining in the queue.
- When a **Type B** canister is processed, it generates heat equal to **three times** the number of **Type A** canisters remaining in the queue.
- When a **Type C** canister is processed, it generates heat equal to **twice** the number of **Type B** canisters remaining in the queue.

The system must process all canisters in the queue one by one. For a given initial batch $(A, B, C)$, let $S(A, B, C)$ be the minimum possible total heat generated by the most efficient processing sequence, and let $N(A, B, C)$ be the total number of distinct processing sequences that result in that minimum heat value.

Find the sum of $S(A, B, C) + N(A, B, C)$ for each of the following three starting batches, and then calculate the grand total of these three sums:
1. $A=10, B=10, C=10$
2. $A=20, B=10, C=30$
3. $A=4, B=2, C=6$
