# Problem

A high-tech digital storage facility consists of a massive square server grid with 2013 rows and 2013 columns, creating a total of $2013^2$ data slots. Each slot is assigned a unique identification number from 1 to $2013^2$, filled sequentially row by row starting from the top-left corner (slot 1) to the bottom-right corner (slot $2013^2$).

An automated security protocol is triggered to purge specific hardware from the grid. The protocol identifies every data slot labeled with a perfect square integer—specifically the sequence $1, 4, 9, \dots, 2013^2$. For every such slot identified, the system simultaneously deletes the entire row and the entire column in which that slot is located.

After this sweep is completed and all rows and columns containing at least one perfect square have been removed, how many data slots remain in the grid?
