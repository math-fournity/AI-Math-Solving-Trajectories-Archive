## Proof

**Claim.** Let $u: \mathbb{R}_+ \to \mathbb{R}$ be positive, increasing, and con
cave, and differentiable. Then as $x \to \infty$,
$$u(x) = O(x).$$
That is, there exist constants $C, x_0 > 0$ such that $u(x) \le C\,x$ for all $x
 \ge x_0$.

---

**Step 1. Translate the hypotheses into derivative information.**

Since $u$ is differentiable:

- *Increasing* $\Longrightarrow$ $u'(x) \ge 0$ for all $x \ge 0$.
- *Concave* $\Longrightarrow$ $u'$ is non-increasing on $\mathbb{R}_+$, i.e. $x_
1 \le x_2 \Rightarrow u'(x_1) \ge u'(x_2)$.

Combining these two facts: $u'$ is a **non-negative, non-increasing** function o
n $\mathbb{R}_+$.

**Step 2. Bound the derivative from above.**

Because $u'$ is non-increasing, for every $x \ge 0$,
$$u'(x) \le u'(0).$$
(Here $u'(0)$ is a finite real number, since $u$ is differentiable on $\mathbb{R
}_+$.) Together with non-negativity,
$$0 \le u'(x) \le u'(0), \qquad \forall\, x \ge 0.$$

**Step 3. Integrate to bound $u(x)$.**

Using the fundamental theorem of calculus,
$$u(x) = u(0) + \int_0^x u'(t)\,dt.$$
Applying the pointwise bound from Step 2,
$$u(x) \le u(0) + \int_0^x u'(0)\,dt = u(0) + u'(0)\,x.$$

**Step 4. Extract the $O(\cdot)$ statement.**

Since $u$ is positive, $u(0) > 0$. Set $C := u(0) + u'(0)$ (both terms are non-n
egative, and $u'(0) \ge 0$; if $u'(0)=0$ then $u$ is constant and the bound is t
rivial). For all $x \ge 1$,
$$u(x) \le u(0) + u'(0)\,x \le \bigl(u(0) + u'(0)\bigr)\,x = C\,x.$$
(We used $u(0) \le u(0)\,x$ for $x \ge 1$.)

Therefore, by definition of big-O notation,
$$\boxed{u(x) = O(x) \quad \text{as } x \to \infty.}$$

---

**Remark on sharpness.** The bound $O(x)$ is tight: the linear function $u(x) =
x$ is itself positive, increasing, and concave (its derivative is the constant $
1$, which is non-increasing), and it is exactly $\Theta(x)$. No strictly smaller
 order (e.g. $O(\sqrt{x})$) can serve as a universal upper bound for the entire
class of positive, increasing, concave functions.
