## Proof

**Setup.** Assume $0 < c < 1$ and $t$ is an integer with $0 \le t \le n$ (so tha
t the binomial coefficients are non-trivial). Let $j = t - i$, so the sum become
s:
$$S(t) = \sum_j \binom{cn}{t-j}\binom{(1-c)n}{j}\, 2^{j}.$$

**Step 1: Generating function.** Consider the generating function $G(z) = \sum_{
t=0}^{n} S(t)\, z^t$. By exchanging the order of summation:
$$G(z) = \left(\sum_{i=0}^{cn}\binom{cn}{i}z^i\right)\left(\sum_{j=0}^{(1-c)n}\b
inom{(1-c)n}{j}(2z)^j\right) = (1+z)^{cn}(1+2z)^{(1-c)n}.$$

Setting $g(z) = (1+z)^c(1+2z)^{1-c}$, we have $G(z) = g(z)^n$, and $S(t) = [z^t]
\, g(z)^n$.

**Step 2: Total sum and the bound.** Evaluating at $z = 1$:
$$\sum_{t=0}^{n} S(t) = G(1) = 2^{cn}\cdot 3^{(1-c)n} = \left(2^c \cdot 3^{1-c}\
right)^n = 2^{\left(c + (1-c)\log_2 3\right)n}.$$

Since every term is non-negative, for **any** $t$:
$$S(t) \le \sum_{t'=0}^{n} S(t') = 2^{c' n}, \qquad c' := c + (1-c)\log_2 3.$$

**Step 3: Verifying $0 < c' < \log_2 3$.** We have $c' = \log_2 3 - c(\log_2 3 -
 1)$. Since $\log_2 3 > 1$ and $c > 0$:
$$c' = \log_2 3 - c\,(\log_2 3 - 1) < \log_2 3.$$
Since $c < 1$ and $\log_2 3 > 1$:
$$c' = c + (1-c)\log_2 3 > c + (1-c)\cdot 1 = 1 > 0.$$
So $c' \in (1,\, \log_2 3) \subset (0,\, \log_2 3)$. ✓

**Step 4: The bound is essentially tight.** Since there are only $n+1$ values of
 $t$:
$$\max_t S(t) \ge \frac{1}{n+1}\sum_{t=0}^n S(t) = \frac{2^{c'n}}{n+1}.$$
Thus $\max_t S(t)$ has the same exponential rate $c'$ (up to polynomial factors)
, so the bound cannot be improved to $2^{c''n}$ with $c'' < c'$ uniformly over $
t$.

**Step 5: Precise asymptotic via saddle-point method.** For $t = \alpha n$ with
$\alpha \in (0,1)$ bounded away from $0$ and $1$, by the saddle-point method (Fl
ajolet–Sedgewick, Ch. VIII):

$$S(\alpha n) \sim \frac{g(r)^n}{r^{\alpha n}\,\sqrt{2\pi n\,\sigma^2}},$$

where $r > 0$ is the unique positive solution to the saddle-point equation:
$$\frac{c\,r}{1+r} + \frac{2(1-c)\,r}{1+2r} = \alpha,$$

and $\sigma^2 = r\,\frac{d}{dr}\!\left[\frac{r\,g'(r)}{g(r)}\right]_{r} > 0$ is
the variance parameter. The exponential growth rate is:
$$\Lambda(\alpha) = \log_2 g(r) - \alpha\log_2 r = c\log_2(1+r) + (1-c)\log_2(1+
2r) - \alpha\log_2 r.$$

The maximum of $\Lambda(\alpha)$ over $\alpha$ is attained at $r = 1$ (i.e., $\a
lpha = \frac{c}{2}+\frac{2(1-c)}{3} = \frac{4-c}{6}$), giving $\Lambda_{\max} =
\log_2 g(1) = c + (1-c)\log_2 3 = c'$, consistent with Steps 2 and 4.

**Conclusion.** The sum satisfies $S(t) \le 2^{c'n}$ for every $t$, with
$$\boxed{c' = c + (1-c)\log_2 3 = \log_2 3 - c(\log_2 3 - 1) \in (0,\, \log_2 3)
.}$$
This bound is tight in the exponential rate: the maximum over $t$ achieves rate
exactly $c'$. The precise asymptotic for $t = \alpha n$ is given by the saddle-p
oint formula above.
