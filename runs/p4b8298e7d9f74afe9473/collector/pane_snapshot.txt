## Solution

We have 2022 applicants in a circle, numbered 1 to 2022, and we remove every 202
3rd applicant starting the count from applicant 1. We want the 49th removal.

**Setup and notation.** Let $k = 2023$ and let the circle at step $j$ have $m_j
= 2023 - j$ remaining applicants. Let $s_j$ be the starting index (0-based) at s
tep $j$, and $r_j$ the index removed:

$$r_j = (s_j + k - 1) \bmod m_j = (s_j + 2022) \bmod (2023 - j).$$

After removal, the next start is $s_{j+1} = r_j \bmod (m_j - 1)$.

**Key observation: $k = n + 1$.** Since $k - 1 = 2022 = n$, at each step the off
set $k - 1 = 2022$ relates to the circle size by $2022 = m_j + (j - 1)$.

**Claim.** For $j = 1, 2, \ldots, 49$, the $j$-th removed applicant is the trian
gular number $T_j = \frac{j(j+1)}{2}$, and the removal index is $r_j = T_{j-1} =
 \frac{(j-1)j}{2}$.

**Proof by induction.**

*Base case* ($j = 1$): $s_1 = 0$, $r_1 = (0 + 2022) \bmod 2022 = 0 = T_0$. The a
pplicant at index 0 is applicant $1 = T_1$. ✓

*Inductive step.* Assume at step $j$: $r_j = T_{j-1}$ and the removed applicant
is $T_j$, with $T_{j-1} < m_j - 1$ (so $s_{j+1} = r_j = T_{j-1}$, no wrap on the
 start).

Then:
$$r_{j+1} = (T_{j-1} + 2022) \bmod (2022 - j).$$

Since $T_{j-1} + 2022 = \frac{(j-1)j}{2} + 2022$ and $T_j = \frac{j(j+1)}{2} = \
frac{(j-1)j}{2} + j$, we get:
$$T_{j-1} + 2022 = T_j + (2022 - j) = T_j + m_{j+1}.$$

Therefore $r_{j+1} = T_j \bmod m_{j+1}$. As long as $T_j < m_{j+1} = 2022 - j$,
this gives $r_{j+1} = T_j$.

**Applicant number.** At step $j+1$, the remaining circle is $\{1, \ldots, 2022\
} \setminus \{T_1, \ldots, T_j\}$, sorted. The removed index is $T_j$ (0-based),
 i.e., the $(T_j + 1)$-th remaining applicant. Since all $j$ removed applicants
$T_1, \ldots, T_j$ satisfy $T_i \leq T_j$, among $\{1, \ldots, T_j + j + 1\}$ th
ere are exactly $T_j + 1$ remaining applicants (we removed $j$ from the first $T
_j + j + 1$ integers, all $\leq T_j$). Thus the $(T_j + 1)$-th remaining applica
nt is:

$$T_j + j + 1 = \frac{j(j+1)}{2} + (j+1) = \frac{(j+1)(j+2)}{2} = T_{j+1}. \chec
kmark$$

**Verifying the no-wrap condition for $j \leq 49$.** We need $T_j < 2022 - j$, i
.e., $\frac{j(j+1)}{2} < 2022 - j$, i.e., $j(j+3) < 4044$. For $j = 49$: $49 \ti
mes 52 = 2548 < 4044$. ✓ We also need $T_{j-1} < 2022 - j$ (start doesn't wrap),
 i.e., $\frac{j(j-1)}{2} < 2022 - j$, which gives $j(j+1) < 4044$; for $j = 49$:
 $2450 < 4044$. ✓ Finally, $T_{49} = 1225 \leq 2022$. ✓

**Conclusion.** The 49th removed applicant is:

$$T_{49} = \frac{49 \times 50}{2} = \boxed{1225}.$$
