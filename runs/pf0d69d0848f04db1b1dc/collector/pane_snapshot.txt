## Proof

**Setup.** The ℓ^p-ball of radius *r* in ℤ² is the vertex set $B = \{x \in \math
bb{Z}^2 : \|x\|_p \leq r\}$, with the induced subgraph $G = (B, E)$ where edges
connect lattice-nearest-neighbors both lying in $B$.

**Key claim: $B$ is connected as a graph.**

Take any vertex $x = (x_1, x_2) \in B$. Construct a lattice path from the origin
 $\mathbf{0}$ to $x$ by adjusting one coordinate at a time:

1. **First segment:** $\mathbf{0} \to (1,0) \to (2,0) \to \cdots \to (x_1, 0)$.
Each intermediate point $(k, 0)$ has $\|(k,0)\|_p = |k| \leq |x_1| \leq \|x\|_p
\leq r$, so all stay in $B$. ✓

2. **Second segment:** $(x_1, 0) \to (x_1, 1) \to \cdots \to (x_1, x_2)$. Each i
ntermediate point $(x_1, k)$ has $\|(x_1, k)\|_p = (|x_1|^p + |k|^p)^{1/p} \leq
(|x_1|^p + |x_2|^p)^{1/p} = \|x\|_p \leq r$, so all stay in $B$. ✓

(The argument for negative coordinates is identical, adjusting step direction.)
Therefore every vertex in $B$ is connected to the origin by a path within $B$, s
o **$G$ is connected**.

**Cluster growth analysis.** The cluster begins from some seed vertex in $B$ (e.
g., the origin). At each step, every vertex adjacent to the current cluster (in
$G$) is added. This is breadth-first search (BFS) on $G$.

Since $G$ is connected, BFS from any starting vertex in $B$ eventually reaches *
*every** vertex in $B$. Specifically, any boundary vertex $v \in \partial B$ (wh
ere $\partial B = \{x \in B : x \text{ has a neighbor in } \mathbb{Z}^2 \setminu
s B\}$) lies in $B$ and is therefore in the same connected component as the seed
.

**Probability calculation.** The probability that a boundary vertex $v$ is added
 to the cluster at any step is:

$$P(v \text{ is added}) = P(v \text{ is in the connected component of the seed i
n } G)$$

Since $G$ is connected, every vertex is in the same component as every other ver
tex. Thus:

$$\boxed{P(v \text{ is added to the cluster}) = 1}$$

This holds for every boundary vertex $v$, regardless of the choice of seed (as l
ong as the seed is in $B$), and for any $p \geq 1$ and any radius $r \geq 1$.
