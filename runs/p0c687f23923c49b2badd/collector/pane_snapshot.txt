## Solution

**Key observation:** Each circle's center is $A_k = (a_k, \tfrac{1}{4}a_k^2)$ wi
th radius $r_k = \tfrac{1}{4}a_k^2$. Since the center's height above the $x$-axi
s equals its radius, every circle $\odot A_k$ is tangent to the $x$-axis from ab
ove.

**Tangency condition between consecutive circles.** For two circles both tangent
 to the $x$-axis from above, with centers $(x_i, r_i)$, $(x_j, r_j)$ and radii $
r_i, r_j$, external tangency requires the distance between centers to equal $r_i
 + r_j$:

$$(x_i - x_j)^2 + (r_i - r_j)^2 = (r_i + r_j)^2$$

$$(x_i - x_j)^2 = 4\,r_i r_j, \qquad |x_i - x_j| = 2\sqrt{r_i r_j}.$$

Applying this to $\odot A_k$ and $\odot A_{k+1}$ with $r_k = \tfrac{1}{4}a_k^2$
and all $a_k > 0$ (since $a_1 > \cdots > a_{2018} = \tfrac{1}{2018} > 0$):

$$a_k - a_{k+1} = 2\sqrt{\tfrac{1}{4}a_k^2 \cdot \tfrac{1}{4}a_{k+1}^2} = 2\cdot
\tfrac{1}{4}a_k a_{k+1} = \tfrac{1}{2}\,a_k a_{k+1}.$$

**Reduction to an arithmetic progression.** Dividing both sides by $a_k a_{k+1}$
:

$$\frac{1}{a_{k+1}} - \frac{1}{a_k} = \frac{1}{2}.$$

Setting $b_k = \dfrac{1}{a_k}$, we obtain $b_{k+1} = b_k + \dfrac{1}{2}$, so $\{
b_k\}$ is an arithmetic progression with common difference $\tfrac{1}{2}$:

$$b_k = b_1 + (k-1)\cdot\frac{1}{2}.$$

**Solving for $a_1$.** Using $a_{2018} = \tfrac{1}{2018}$, i.e. $b_{2018} = 2018
$:

$$2018 = b_1 + 2017\cdot\frac{1}{2} = b_1 + \frac{2017}{2},$$

$$b_1 = 2018 - \frac{2017}{2} = \frac{4036 - 2017}{2} = \frac{2019}{2}.$$

Therefore

$$a_1 = \frac{1}{b_1} = \frac{2}{2019}.$$

**Verification.** From $b_1 = \tfrac{2019}{2}$: $b_{2018} = \tfrac{2019}{2} + \t
frac{2017}{2} = \tfrac{4036}{2} = 2018$, giving $a_{2018} = \tfrac{1}{2018}$. ✓
The recurrence $a_k - a_{k+1} = \tfrac{1}{2}a_k a_{k+1}$ is satisfied throughout
, confirming external tangency of every consecutive pair.

$$\boxed{a_1 = \dfrac{2}{2019}}$$
