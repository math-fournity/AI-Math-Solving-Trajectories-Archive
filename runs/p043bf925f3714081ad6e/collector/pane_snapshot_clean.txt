## Unperturbed Problem (ε = 0)

The linear eigenvalue problem is
$$\phi'' + \lambda\,\phi = 0, \quad \phi(0)=\phi(L)=0.$$
The eigenvalues and (unnormalized) eigenfunctions are
$$\lambda_n^{(0)} = \left(\frac{n\pi}{L}\right)^2, \qquad \phi_n^{(0)} = \sin\!\
left(\frac{n\pi x}{L}\right), \qquad n=1,2,\dots$$
For the first eigenvalue: $\lambda_1^{(0)} = (\pi/L)^2$.

## Amplitude Bookkeeping via the Constraint

The problem is nonlinear, so the amplitude matters. We are given
$$\int_0^L \phi^2\,dx = a^2.$$
Set $\phi = a\,u$ with the normalization $\int_0^L u^2\,dx = 1$. Substituting in
to the ODE:
$$a\,u'' + \lambda\,a\,u = \epsilon\,a^3\,u^3 \quad\Longrightarrow\quad u'' + \l
ambda\,u = \epsilon\,a^2\,u^3.$$
Define the effective small parameter $\mu := \epsilon\,a^2$. The equation become
s
$$u'' + \lambda\,u = \mu\,u^3.$$

## Perturbation Expansion

Expand
$$u = u_0 + \mu\,u_1 + \mu^2\,u_2 + \cdots, \qquad \lambda = \lambda_0 + \mu\,\l
ambda_1 + \mu^2\,\lambda_2 + \cdots$$

**Order $\mu^0$ (unperturbed):**
$$u_0'' + \lambda_0\,u_0 = 0, \quad u_0(0)=u_0(L)=0, \quad \int_0^L u_0^2\,dx =
1.$$
Solution:
$$\lambda_0 = \left(\frac{\pi}{L}\right)^2, \qquad u_0 = \sqrt{\frac{2}{L}}\,\si
n\!\left(\frac{\pi x}{L}\right).$$

**Order $\mu^1$:**
$$u_1'' + \lambda_0\,u_1 = -\lambda_1\,u_0 + u_0^3, \qquad u_1(0)=u_1(L)=0.$$
By the **Fredholm alternative** (solvability condition), the right-hand side mus
t be orthogonal to the nullspace of the adjoint (which is spanned by $u_0$ since
 the operator is self-adjoint):
$$\int_0^L u_0\bigl(-\lambda_1\,u_0 + u_0^3\bigr)\,dx = 0.$$
Using $\int_0^L u_0^2\,dx = 1$:
$$-\lambda_1 + \int_0^L u_0^4\,dx = 0 \quad\Longrightarrow\quad \lambda_1 = \int
_0^L u_0^4\,dx.$$

## Computing $\lambda_1$

$$\int_0^L u_0^4\,dx = \left(\frac{2}{L}\right)^2 \int_0^L \sin^4\!\left(\frac{\
pi x}{L}\right)dx.$$
Using $\sin^4\theta = \tfrac{1}{8}(3 - 4\cos 2\theta + \cos 4\theta)$ and the su
bstitution $t = \pi x/L$:
$$\int_0^L \sin^4\!\left(\frac{\pi x}{L}\right)dx = \frac{L}{\pi}\int_0^\pi \sin
^4 t\,dt = \frac{L}{\pi}\cdot\frac{3\pi}{8} = \frac{3L}{8}.$$
Therefore:
$$\lambda_1 = \frac{4}{L^2}\cdot\frac{3L}{8} = \frac{3}{2L}.$$

## Result: Perturbation of $\lambda_1$

$$\boxed{\lambda_1 = \left(\frac{\pi}{L}\right)^2 + \frac{3\,\epsilon\,a^2}{2L}
+ O(\epsilon^2 a^4).}$$

The first-order eigenvalue shift is
$$\delta\lambda_1 = \frac{3\,\epsilon\,a^2}{2L}.$$

## Sketch of $a$ as a Function of $\lambda$

Solving the leading-order relation $\lambda = (\pi/L)^2 + \frac{3\epsilon a^2}{2
L}$ for $a$:

$$a^2 = \frac{2L}{3\epsilon}\left(\lambda - \left(\frac{\pi}{L}\right)^2\right),
 \qquad a = \sqrt{\frac{2L}{3\epsilon}}\;\sqrt{\lambda - \left(\frac{\pi}{L}\rig
ht)^2}.$$

**Character of the curve:**

- The curve has a **vertex (turning point)** at $\bigl(\lambda_0,\, 0\bigr) = \b
igl((\pi/L)^2,\, 0\bigr)$, where $a=0$.
- For **$\epsilon > 0$** (softening-type nonlinearity): the curve exists for $\l
ambda > (\pi/L)^2$ and opens to the **right** — a square-root (parabolic) branch
 rising from the bifurcation point $(\pi/L)^2$.
- For **$\epsilon < 0$** (hardening-type nonlinearity): the curve exists for $\l
ambda < (\pi/L)^2$ and opens to the **left**.
- At the vertex, the linear eigenvalue is recovered ($a\to 0$): the nonlinear br
anch **bifurcates** from the linear eigenvalue $\lambda_1^{(0)} = (\pi/L)^2$.
- The slope $da/d\lambda \to \infty$ as $a\to 0$, i.e., the branch meets the $\l
ambda$-axis **tangentially** (vertical tangent), which is the hallmark of a **pi
tchfork-type bifurcation** from the trivial solution.
