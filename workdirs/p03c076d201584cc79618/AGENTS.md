# Problem

A high-security digital vault uses a set of unique encryption keys denoted as $P^*$, which consists of all prime numbers less than $10,000$. Each key $p \in P^*$ has an associated "activation value" defined as $p+1$.

The vault's security protocol identifies a specific category of "Master Keys." A key $p$ is considered a Master Key if it satisfies the following condition: whenever a group of other distinct keys $S = \{p_1, p_2, \dots, p_k\}$ is selected from $P^*$ (where the size of the group $k \geq 2$ and $p$ is not included in the group), there must exist at least one remaining key $q$ in the set (where $q$ is in $P^*$ but not in $S$) such that the activation value of $q$ is a mathematical divisor of the product of the activation values of all keys in $S$.

Calculate the sum of all prime numbers $p$ that qualify as Master Keys under this protocol.
