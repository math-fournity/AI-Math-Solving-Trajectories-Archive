## Proof

**Claim:** Yes, such a function exists. We exhibit $f(x) = (\ln x)^x$ for $x > e
$.

---

**Verification of condition 1: $f(x) = o(x!)$.**

Taking logarithms (Stirling's approximation $\ln(x!) \sim x \ln x$):

$$\ln f(x) = \ln\!\big((\ln x)^x\big) = x \ln \ln x.$$

Since $\ln \ln x = o(\ln x)$ as $x \to \infty$,

$$\frac{\ln f(x)}{\ln(x!)} \sim \frac{x \ln \ln x}{x \ln x} = \frac{\ln \ln x}{\
ln x} \longrightarrow 0.$$

Therefore $\ln f(x) = o(\ln(x!))$, which gives $f(x) = o(x!)$. ✓

---

**Verification of condition 2: $\displaystyle\lim_{x\to\infty} \frac{f(x)}{f'(x)
} = 0$.**

Write $f(x) = e^{h(x)}$ where $h(x) = x \ln \ln x$. Then $f'(x) = f(x)\, h'(x)$,
 so

$$\frac{f(x)}{f'(x)} = \frac{1}{h'(x)}.$$

Computing the derivative:

$$h'(x) = \ln \ln x + x \cdot \frac{1}{\ln x} \cdot \frac{1}{x} = \ln \ln x + \f
rac{1}{\ln x}.$$

As $x \to \infty$, $\ln \ln x \to \infty$ and $\frac{1}{\ln x} \to 0$, hence $h'
(x) \to \infty$. Therefore

$$\frac{f(x)}{f'(x)} = \frac{1}{\ln \ln x + 1/\ln x} \longrightarrow 0. \checkma
rk$$

---

**Conclusion.** The function $f(x) = (\ln x)^x$ satisfies both $f(x) = o(x!)$ an
d $\lim_{x\to\infty} f(x)/f'(x) = 0$, so such a function exists.
