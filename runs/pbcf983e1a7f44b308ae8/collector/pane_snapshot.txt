## Proof

**Step 1: Verify that $f$ is entire.**

The coefficients are $a_n = n^{-bn}$ for $n \geq 1$ (with $a_0 = 1$ by conventio
n). The radius of convergence is determined by

$$\frac{1}{R} = \limsup_{n\to\infty} |a_n|^{1/n} = \limsup_{n\to\infty} n^{-b} =
 0,$$

since $b > 0$. Hence $R = \infty$, so $f$ is entire.

**Step 2: State the coefficient formula for the order.**

For an entire function $f(z) = \sum_{n=0}^{\infty} a_n z^n$, the growth order (o
rder) is given by the classical formula

$$\rho = \limsup_{n\to\infty} \frac{n \log n}{\log(1/|a_n|)}.$$

*Justification.* Let $M(r) = \max_{|z|=r}|f(z)|$ and $\rho_0 = \limsup_{n\to\inf
ty} \frac{n\log n}{-\log|a_n|}$.

*Upper bound ($\rho \leq \rho_0$):* For any $\varepsilon > 0$ and all large $n$,
 $-\log|a_n| \geq \frac{n\log n}{\rho_0+\varepsilon}$, so $|a_n| \leq e^{-n\log
n/(\rho_0+\varepsilon)}$. Then $|a_n|r^n \leq \exp\!\bigl(n\log r - \frac{n\log
n}{\rho_0+\varepsilon}\bigr)$. Maximizing the exponent over continuous $n$ gives
 $n \approx r^{\rho_0+\varepsilon}/e$ with peak value $\sim C r^{\rho_0+\varepsi
lon}$. Summing, $M(r) \leq \sum |a_n|r^n \leq \exp(C' r^{\rho_0+\varepsilon})$ f
or large $r$, so $\rho \leq \rho_0+\varepsilon$. Since $\varepsilon$ is arbitrar
y, $\rho \leq \rho_0$.

*Lower bound ($\rho \geq \rho_0$):* If $\rho \leq \rho_1$, then $M(r) \leq e^{r^
{\rho_1}}$ for large $r$. By Cauchy's estimate, $|a_n| \leq M(r)/r^n \leq e^{r^{
\rho_1}}/r^n$ for all large $r$. Minimizing $r^{\rho_1} - n\log r$ over $r$ yiel
ds $r = (n/\rho_1)^{1/\rho_1}$, giving $|a_n| \leq \exp\!\bigl(-\frac{n}{\rho_1}
\log n + O(n)\bigr)$. Thus $-\log|a_n| \geq \frac{n\log n}{\rho_1} - O(n)$, and
$\frac{n\log n}{-\log|a_n|} \leq \rho_1 + o(1)$, so $\rho_0 \leq \rho_1$. Since
$\rho_1 \geq \rho$ is arbitrary, $\rho_0 \leq \rho$.

Combining both directions, $\rho = \rho_0$.

**Step 3: Compute the order.**

For our function, $a_n = n^{-bn}$, so

$$\log(1/|a_n|) = \log(n^{bn}) = bn\log n.$$

Therefore

$$\rho = \limsup_{n\to\infty} \frac{n\log n}{bn\log n} = \limsup_{n\to\infty} \f
rac{1}{b} = \frac{1}{b}.$$

The limit exists (not merely the limsup), so the growth order of $f$ is

$$\boxed{\rho = \dfrac{1}{b}}.$$
