## Proof

The answer is **No**. We construct an explicit counterexample: sequences $(a_k)$
 (not all zero) and $(b_k)$ with $1 = b_0 > b_1 > b_2 > \cdots > 0$ such that $\
sum_{i=0}^n a_i \cos(n\pi b_i) = 0$ for all $n \geq 1$.

### Construction

Set $b_0 = 1$ and $a_0 = 1$, so $S_0 = a_0 \cos(0) = 1$.

Proceed **inductively** for $n \geq 1$. Suppose $b_0, \dots, b_{n-1}$ and $a_0,
\dots, a_{n-1}$ have been defined. We choose $b_n$ and $a_n$ as follows:

**Step 1: Choose $b_n$.** The "forbidden" set is
$$F_n = \bigl\{b \in (0,\, b_{n-1}) : \cos(n\pi b) = 0\bigr\} = \left\{\frac{2k+
1}{2n} : k \in \mathbb{Z},\; 0 < \frac{2k+1}{2n} < b_{n-1}\right\}.$$
This is a **finite** set (at most $n$ elements). Since $(0, b_{n-1})$ is a nonem
pty open interval (as $b_{n-1} > 0$), we can pick any $b_n \in (0, b_{n-1}) \set
minus F_n$. This guarantees:
- $0 < b_n < b_{n-1}$ (strictly decreasing, positive),
- $\cos(n\pi b_n) \neq 0$.

**Step 2: Define $a_n$.** Set
$$a_n = -\frac{\displaystyle\sum_{i=0}^{n-1} a_i \cos(n\pi b_i)}{\cos(n\pi b_n)}
.$$
This is well-defined since $\cos(n\pi b_n) \neq 0$.

### Verification

With this choice:
$$S_n = \sum_{i=0}^{n} a_i \cos(n\pi b_i) = \sum_{i=0}^{n-1} a_i \cos(n\pi b_i)
+ a_n \cos(n\pi b_n) = \sum_{i=0}^{n-1} a_i \cos(n\pi b_i) - \sum_{i=0}^{n-1} a_
i \cos(n\pi b_i) = 0.$$

So $S_n = 0$ for every $n \geq 1$, hence $\lim_{n \to \infty} S_n = 0$.

### Concrete check (first few terms)

- $b_0 = 1,\; a_0 = 1$: $S_0 = 1$.
- $n=1$: Choose $b_1 = \tfrac{3}{4}$ (since $\cos(\tfrac{3\pi}{4}) = -\tfrac{\sq
rt{2}}{2} \neq 0$). Then $a_1 = -\frac{\cos(\pi)}{\cos(3\pi/4)} = -\frac{-1}{-\s
qrt{2}/2} = -\sqrt{2}$. Check: $S_1 = 1\cdot(-1) + (-\sqrt{2})(-\tfrac{\sqrt{2}}
{2}) = -1 + 1 = 0$. ✓
- $n=2$: Choose $b_2 = \tfrac{1}{3}$ (since $\cos(\tfrac{2\pi}{3}) = -\tfrac{1}{
2} \neq 0$, and $\tfrac{1}{3} < \tfrac{3}{4}$). Then $a_2 = -\frac{1\cdot 1 + (-
\sqrt{2})\cos(\tfrac{3\pi}{2})}{\cos(\tfrac{2\pi}{3})} = -\frac{1+0}{-1/2} = 2$.
 Check: $S_2 = 1 + 0 + 2(-\tfrac{1}{2}) = 0$. ✓
- $n=3$: Choose $b_3 = \tfrac{1}{4}$ (since $\cos(\tfrac{3\pi}{4}) = -\tfrac{\sq
rt{2}}{2} \neq 0$, and $\tfrac{1}{4} < \tfrac{1}{3}$). Then $a_3 = -\frac{-1 + (
-\sqrt{2})\tfrac{\sqrt{2}}{2} + 2(-1)}{-\sqrt{2}/2} = -\frac{-4}{-\sqrt{2}/2} =
-4\sqrt{2}$. Check: $S_3 = -1 - 1 - 2 + 4 = 0$. ✓

### Conclusion

The sequences $(a_k)$ and $(b_k)$ constructed above satisfy:
- $b_0 = 1 > b_1 = \tfrac{3}{4} > b_2 = \tfrac{1}{3} > b_3 = \tfrac{1}{4} > \cdo
ts > 0$ (strictly decreasing, all positive),
- $a_0 = 1 \neq 0$ (so not all $a_k$ are zero),
- $S_n = 0$ for all $n \geq 1$, hence $\lim_{n \to \infty} S_n = 0$.

The induction can be continued indefinitely because at each step $n$, the forbid
den set $F_n$ is finite and the interval $(0, b_{n-1})$ contains infinitely many
 points.

Therefore, the condition $\lim_{n\to\infty}\sum_{i=0}^n a_i\cos(n\pi b_i) = 0$ d
oes **not** imply that all $a_k = 0$.
