## Solution

**Setting up the angle structure.** Since $\alpha, \beta, \gamma$ are the angles
 of a triangle and form an arithmetic sequence (in that order), we have $\beta -
 \alpha = \gamma - \beta$, so $2\beta = \alpha + \gamma$. Combined with $\alpha
+ \beta + \gamma = 180°$, we get $3\beta = 180°$, hence
$$\beta = 60°, \quad \alpha = 60° - d, \quad \gamma = 60° + d$$
for some $d \geq 0$, with the positivity constraint $\alpha > 0 \Rightarrow d <
60°$ (and $\gamma < 180°$ gives $d < 120°$, which is weaker).

**Applying the second condition.** We need $\sin 20\alpha, \sin 20\beta, \sin 20
\gamma$ to form an arithmetic sequence in the same order, so the middle term is
the average:
$$\sin 20\alpha + \sin 20\gamma = 2\sin 20\beta.$$

Compute each argument (in degrees):
- $20\beta = 20 \cdot 60 = 1200°$, and $1200 = 3\cdot 360 + 120$, so $\sin 1200°
 = \sin 120° = \tfrac{\sqrt{3}}{2}$.
- $20\alpha = 20(60-d) = 1200 - 20d$.
- $20\gamma = 20(60+d) = 1200 + 20d$.

Using the sum-to-product identity:
$$\sin(1200 - 20d) + \sin(1200 + 20d) = 2\sin 1200° \cos 20d = \sqrt{3}\cos 20d.
$$

The condition becomes
$$\sqrt{3}\cos 20d = 2\sin 1200° = \sqrt{3},$$
so
$$\cos 20d = 1 \quad \Longrightarrow \quad 20d = 360k, \quad k \in \mathbb{Z}, \
quad \text{i.e. } d = 18k.$$

**Counting valid values.** The constraint $0 \leq d < 60$ gives $0 \leq 18k < 60
$, i.e. $0 \leq k < \tfrac{10}{3} \approx 3.33$. Thus $k \in \{0, 1, 2, 3\}$, yi
elding:

| $k$ | $d$ | $(\alpha,\beta,\gamma)$ |
|-----|-----|--------------------------|
| 0 | 0° | $(60°, 60°, 60°)$ |
| 1 | 18° | $(42°, 60°, 78°)$ |
| 2 | 36° | $(24°, 60°, 96°)$ |
| 3 | 54° | $(6°, 60°, 114°)$ |

Each has all angles positive and summing to $180°$, and in every case $20d \in \
{0, 360, 720, 1080\}$ is a multiple of $360°$, so $\cos 20d = 1$ and the three s
ine values are all equal to $\tfrac{\sqrt{3}}{2}$ — a (degenerate) arithmetic se
quence. The next value $k=4$ gives $d = 72° \geq 60°$, making $\alpha = -12° < 0
$, which is invalid.

**Answer: $\boxed{4}$ triples.**
