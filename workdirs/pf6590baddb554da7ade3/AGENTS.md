# Problem

A high-tech logistics facility operates a conveyor belt that processes exactly $2n$ specialized components. These components are produced in pairs; there are $n$ unique model types, and each model type consists of exactly two identical components. The conveyor belt contains all $2n$ components in a specific linear sequence.

The facility’s sorting protocol works as follows: every minute, the lead component on the belt is moved into a temporary staging bay. If the staging bay already contains the matching component of that specific model type, a robot immediately grabs the pair and moves them to permanent storage, clearing them from the staging bay.

There are $(2n)!$ possible initial sequences of components on the conveyor belt. The facility supervisor needs to identify how many of these sequences are "safe." A sequence is defined as "safe" if, at any given moment during the entire process, there are components of at most two different model types occupying the staging bay simultaneously.

Determine the total number of safe sequences in terms of $n$.
