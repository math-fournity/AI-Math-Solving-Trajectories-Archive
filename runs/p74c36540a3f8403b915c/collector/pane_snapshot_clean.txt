## Solution

**Setup.** Place the tabletop as the plane $z=0$, and the hemispherical bubble a
s the upper hemisphere $x^2+y^2+z^2=1$, $z\ge 0$, centered at the origin.

Let each marble have radius $r$. The four base marbles sit on the table, so thei
r centers are at height $z=r$. By symmetry their centers form a square; place th
em at $(\pm d,\pm d, r)$, so the square has side $2d$ and center $(0,0,r)$. The
top marble's center is directly above this center, at $(0,0,z_t)$.

**Tangency to the bubble.** Every marble is internally tangent to the bubble (sp
here of radius $1$), so each center is at distance $1-r$ from the origin.

- Base marble: $2d^2 + r^2 = (1-r)^2 \Rightarrow 2d^2 = 1-2r$. $\quad(1)$
- Top marble: $z_t = 1-r$. $\quad(2)$

**Tangency of top marble to each base marble.** The distance from $(0,0,z_t)$ to
 $(d,d,r)$ equals $2r$:
$$2d^2 + (z_t - r)^2 = 4r^2. \quad(3)$$

From (2), $z_t - r = (1-r)-r = 1-2r$. Substituting (1) and this into (3):
$$(1-2r) + (1-2r)^2 = 4r^2.$$
Expanding: $1-2r + 1 - 4r + 4r^2 = 4r^2$, giving $2 - 6r = 0$, so
$$r = \tfrac{1}{3}.$$

Then from (1): $2d^2 = 1 - \tfrac{2}{3} = \tfrac{1}{3}$, so $d^2 = \tfrac{1}{6}$
. From (2): $z_t = \tfrac{2}{3}$.

**Verification.** Distance from top center to a base center: $\sqrt{2d^2+(z_t-r)
^2} = \sqrt{\tfrac{1}{3}+\tfrac{1}{9}} = \sqrt{\tfrac{4}{9}} = \tfrac{2}{3} = 2r
$. ✓ Each center is at distance $\sqrt{2d^2+r^2}=\sqrt{\tfrac{1}{3}+\tfrac{1}{9}
}=\tfrac{2}{3}=1-r$ from the origin. ✓

**Pyramid volume.** The square base has side $2d$, so
$$\text{base area} = (2d)^2 = 4d^2 = \tfrac{2}{3}.$$
The apex $(0,0,\tfrac{2}{3})$ lies above the base plane $z=r=\tfrac{1}{3}$, so t
he height is
$$h = \tfrac{2}{3}-\tfrac{1}{3} = \tfrac{1}{3}.$$
Thus
$$V = \tfrac{1}{3}\cdot\tfrac{2}{3}\cdot\tfrac{1}{3} = \tfrac{2}{27}.$$

Since $\gcd(2,27)=1$, we have $a=2,\ b=27$, and
$$a+b = 29.$$
