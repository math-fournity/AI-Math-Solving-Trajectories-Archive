## Proof

**Example.** Let $R = \mathbb{Z}$ (the ring of integers, a commutative ring with
 unity), let $I = (2) = 2\mathbb{Z}$, and let $k = 1$.

**Claim.** $(I^{k+1} : I) = I^k$, so the containment $(I^{k+1} : I) \subseteq I^
k$ holds and is not strict (equality holds).

**Verification.**

We have $I = (2)$ and $I^2 = (2)^2 = (4) = 4\mathbb{Z}$.

Recall the definition of the colon ideal:
$$(I^2 : I) = \{r \in \mathbb{Z} : r \cdot I \subseteq I^2\} = \{r \in \mathbb{Z
} : r \cdot (2) \subseteq (4)\}.$$

The condition $r \cdot (2) \subseteq (4)$ is equivalent to $2r \in (4)$, i.e., $
4 \mid 2r$, which is equivalent to $2 \mid r$, i.e., $r \in (2) = I$.

Therefore:
$$(I^2 : I) = (2) = I = I^1 = I^k.$$

**Why the containment holds.** It is a general fact that $I^k \subseteq (I^{k+1}
 : I)$ for any ideal $I$, since $I^k \cdot I = I^{k+1} \subseteq I^{k+1}$. In ou
r example, the reverse containment $(I^{k+1} : I) \subseteq I^k$ also holds, as
shown above. Hence both containments hold, giving:
$$(I^{k+1} : I) = I^k.$$

The containment $(I^{k+1} : I) \subseteq I^k$ is therefore **not strict** — it h
olds with equality.

**Remark.** The same argument works for any $k \geq 1$ and any nonzero ideal $I
= (n)$ in $\mathbb{Z}$: $(I^{k+1} : I) = ((n^{k+1}) : (n)) = (n^k) = I^k$. The k
ey point is that $\mathbb{Z}$ is an integral domain (in fact a PID), so dividing
 by the generator $n$ is unambiguous and no "extra" elements sneak into the colo
n ideal.
