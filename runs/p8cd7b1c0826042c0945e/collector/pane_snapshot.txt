**Proof.**

Let the countable set be $S = 2^{<\omega}$, the set of all finite binary strings
. This set is countable (it is a countable union of finite sets, one per length)
.

For each infinite binary sequence $x = (x_0, x_1, x_2, \dots) \in 2^{\omega}$, d
efine
$$A_x = \{ x{\upharpoonright} n : n \in \mathbb{N},\; n \geq 1 \},$$
the set of all finite prefixes of $x$ (the strings $x_0x_1\cdots x_{n-1}$ for $n
 \geq 1$). Each $A_x$ is an infinite subset of $S$, since $x$ has a unique prefi
x of every length.

Let $\mathcal{F} = \{ A_x : x \in 2^{\omega} \}$.

**$\mathcal{F}$ is uncountable.** The map $x \mapsto A_x$ is injective: if $x \n
eq y$, let $k$ be the first coordinate where they differ. Then every prefix of l
ength $> k$ of $x$ differs from every prefix of $y$ of the same length, and in f
act $A_x \neq A_y$ (e.g. the prefix of length $k+1$ belongs to exactly one of th
em). Since $2^{\omega}$ has cardinality $2^{\aleph_0}$, $\mathcal{F}$ is uncount
able.

**Pairwise intersections are finite (almost disjointness).** Let $x \neq y$ be t
wo distinct infinite binary sequences, and let $k$ be the first coordinate at wh
ich they differ. Then $x{\upharpoonright} n = y{\upharpoonright} n$ only when $n
 \leq k$ (for $n > k$ the prefixes differ at position $k$). Hence
$$A_x \cap A_y = \{ x{\upharpoonright} n : 1 \leq n \leq k \},$$
which is a finite set (of size $k$).

**Triple intersections are finite.** For any three distinct members $A_x, A_y, A
_z \in \mathcal{F}$,
$$A_x \cap A_y \cap A_z \;\subseteq\; A_x \cap A_y,$$
and $A_x \cap A_y$ is finite by the previous paragraph. Therefore $A_x \cap A_y
\cap A_z$ is finite.

Thus $\mathcal{F}$ is an uncountable collection of infinite subsets of the count
able set $S = 2^{<\omega}$ such that the intersection of any three distinct memb
ers is finite. $\blacksquare$
