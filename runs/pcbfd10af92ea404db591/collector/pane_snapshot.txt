## Solution

We evaluate the asymptotic behavior of
$$I_n = (n+1)\int_0^1 x^n \ln(1+x)\,dx$$
as $n\to\infty$.

### Step 1: Substitution

Set $u = x^{n+1}$, so $du = (n+1)x^n\,dx$ and $x = u^{1/(n+1)}$. As $x$ ranges o
ver $[0,1]$, so does $u$. The integral becomes
$$I_n = \int_0^1 \ln\!\left(1 + u^{1/(n+1)}\right)du.$$

Let $N = n+1$. We study
$$I_n = \int_0^1 \ln\!\left(1 + u^{1/N}\right)du, \qquad N\to\infty.$$

### Step 2: The limit

For every $u\in(0,1]$, $u^{1/N} = e^{(\ln u)/N}\to e^0 = 1$ as $N\to\infty$, hen
ce the integrand converges pointwise to $\ln(1+1)=\ln 2$. Since $0\le \ln(1+u^{1
/N})\le \ln 2$ (because $u^{1/N}\le 1$), the dominated convergence theorem gives
$$\boxed{\lim_{n\to\infty} I_n = \ln 2.}$$

### Step 3: Asymptotic expansion

Write $u^{1/N} = e^s$ with $s = \frac{\ln u}{N}\le 0$. Expanding around $s=0$:
$$\ln(1+e^s) = \ln\!\left(2 + s + \tfrac{s^2}{2} + \cdots\right) = \ln 2 + \ln\!
\left(1+\tfrac{s}{2}+\tfrac{s^2}{4}+\cdots\right).$$
Using $\ln(1+w) = w - \tfrac{w^2}{2}+\cdots$ with $w = \tfrac{s}{2}+\tfrac{s^2}{
4}+\cdots$:
$$\ln(1+e^s) = \ln 2 + \frac{s}{2} + \frac{s^2}{4} - \frac{1}{2}\cdot\frac{s^2}{
4} + O(s^3) = \ln 2 + \frac{s}{2} + \frac{s^2}{8} + O(s^3).$$

Substituting $s = \frac{\ln u}{N}$:
$$\ln\!\left(1+u^{1/N}\right) = \ln 2 + \frac{\ln u}{2N} + \frac{(\ln u)^2}{8N^2
} + O\!\left(\frac{|\ln u|^3}{N^3}\right).$$

The remainder is integrable on $[0,1]$ (since $\int_0^1 |\ln u|^k\,du = k!$ is f
inite for all $k$), so we may integrate term by term:
$$I_n = \ln 2 + \frac{1}{2N}\int_0^1 \ln u\,du + \frac{1}{8N^2}\int_0^1(\ln u)^2
\,du + O(N^{-3}).$$

Using the standard values $\int_0^1 \ln u\,du = -1$ and $\int_0^1(\ln u)^2\,du =
 2$:
$$I_n = \ln 2 - \frac{1}{2N} + \frac{2}{8N^2} + O(N^{-3}) = \ln 2 - \frac{1}{2(n
+1)} + \frac{1}{4(n+1)^2} + O\!\left(\frac{1}{(n+1)^3}\right).$$

### Conclusion

$$\boxed{(n+1)\int_0^1 x^n\ln(1+x)\,dx \;=\; \ln 2 \;-\; \frac{1}{2(n+1)} \;+\;
\frac{1}{4(n+1)^2} \;+\; O\!\left(\frac{1}{(n+1)^3}\right),}$$

and in particular the limit as $n\to\infty$ is $\ln 2$.
