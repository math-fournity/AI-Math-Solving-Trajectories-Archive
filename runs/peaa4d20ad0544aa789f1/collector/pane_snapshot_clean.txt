## Solution

**Setting up the minimal polynomial.** Let $y = x^2 = \frac{3+\sqrt{53}}{2}$. Th
en $y - \frac{3}{2} = \frac{\sqrt{53}}{2}$, so squaring: $y^2 - 3y + \frac{9}{4}
 = \frac{53}{4}$, giving

$$y^2 = 3y + 11. \tag{1}$$

**Rewriting the equation in $y$.** Substituting $y = x^2$ into the given equatio
n:

$$y^{50} = 2y^{49} + 14y^{48} + 11y^{47} - y^{25} + ay^{23} + by^{22} + cy^{20}.
$$

**Key factorization.** Factor the left side minus the first three terms on the r
ight:

$$y^{50} - 2y^{49} - 14y^{48} - 11y^{47} = y^{47}(y^3 - 2y^2 - 14y - 11).$$

Using (1): $y^3 = y(3y+11) = 3y^2+11y = 3(3y+11)+11y = 20y+33$, and $y^2 = 3y+11
$, so

$$y^3 - 2y^2 - 14y - 11 = (20y+33) - 2(3y+11) - 14y - 11 = 0.$$

Therefore $y^{50} - 2y^{49} - 14y^{48} - 11y^{47} = 0$, and the equation collaps
es to:

$$y^{25} = ay^{23} + by^{22} + cy^{20}.$$

Since $y > 0$, divide by $y^{20}$:

$$y^5 = ay^3 + by^2 + c. \tag{2}$$

**Reducing powers of $y$ to linear form** using $y^2 = 3y+11$:

- $y^2 = 3y + 11$
- $y^3 = 20y + 33$
- $y^4 = y(93y+220)$... computing: $y^4 = 93y + 220$
- $y^5 = y(93y+220) = 93y^2+220y = 93(3y+11)+220y = 499y + 1023$

**Substituting into (2):**

$$499y + 1023 = a(20y+33) + b(3y+11) + c = (20a+3b)y + (33a+11b+c).$$

Equating coefficients:

$$20a + 3b = 499, \qquad 33a + 11b + c = 1023.$$

**Solving.** From the first equation: $b = \frac{499-20a}{3}$, requiring $a \equ
iv 2 \pmod{3}$ and $a \leq 24$ (for $b>0$).

From the second: $c = 1023 - 33a - 11b = \frac{121a - 2420}{3}$, requiring $a \g
eq 21$ (for $c>0$).

With $a \equiv 2\pmod{3}$ and $21 \leq a \leq 24$, the unique solution is $a = 2
3$:

$$b = \frac{499 - 460}{3} = 13, \qquad c = \frac{2783 - 2420}{3} = 121.$$
