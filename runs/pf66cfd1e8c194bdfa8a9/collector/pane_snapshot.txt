## Proof

Define a sequence of polynomials $P_n(x)$ by
$$P_0(x)=1,\quad P_1(x)=x,\quad P_n(x)=x\,P_{n-1}(x)-P_{n-2}(x)\ \ (n\ge 2).$$
Since the recurrence uses only multiplication by $x$ and subtraction, every $P_n
$ is a polynomial with integer coefficients.

**Key identity.** For every $n\ge 1$,
$$P_n(x)^2-P_{n-1}(x)\,P_{n+1}(x)=1. \tag{$\ast$}$$

We prove $(\ast)$ by induction on $n$. For $n=1$: $P_2=x^2-1$, so
$$P_1^2-P_0P_2=x^2-(x^2-1)=1.$$

For the inductive step, assume $P_{n-1}^2-P_{n-2}P_n=1$. Using $P_{n+1}=xP_n-P_{
n-1}$ and $P_n=xP_{n-1}-P_{n-2}$ (so $P_{n-2}=xP_{n-1}-P_n$),
$$P_n^2-P_{n-1}P_{n+1}=P_n^2-P_{n-1}(xP_n-P_{n-1})=P_n^2-xP_{n-1}P_n+P_{n-1}^2.$
$
The induction hypothesis gives $P_{n-1}^2-P_{n-2}P_n=1$, i.e. $P_{n-1}^2-(xP_{n-
1}-P_n)P_n=1$, which expands to
$$P_{n-1}^2-xP_{n-1}P_n+P_n^2=1.$$
This is exactly $P_n^2-P_{n-1}P_{n+1}=1$, completing the induction.

**Main induction.** We claim $Q_n(x)=P_n(x)$ for all $n\ge 0$.

- $n=0$: $Q_0=1=P_0$. $n=1$: $Q_1=x=P_1$.
- For $n\ge 2$, assuming $Q_{n-1}=P_{n-1}$ and $Q_{n-2}=P_{n-2}$,
$$Q_n=\frac{Q_{n-1}^2-1}{Q_{n-2}}=\frac{P_{n-1}^2-1}{P_{n-2}}.$$
By $(\ast)$ with index $n-1$, $P_{n-1}^2-P_{n-2}P_n=1$, so $P_{n-1}^2-1=P_{n-2}P
_n$. Since $P_{n-2}$ is a nonzero polynomial, the division is exact:
$$Q_n=\frac{P_{n-2}P_n}{P_{n-2}}=P_n.$$

Thus $Q_n(x)=P_n(x)$ for every $n\ge 0$. Since each $P_n$ is a polynomial with i
nteger coefficients, every $Q_n$ is a polynomial with integer coefficients. $\bl
acksquare$
