## Solution

Let $p$ be an odd prime and $G = \mathbb{Z}_p^* = \{1,2,\dots,p-1\}$, $|G| = p-1
$.

**Tool: the Legendre symbol as a poly-time predicate.** For $a \in G$, the Legen
dre symbol is
$$\left(\frac{a}{p}\right) \equiv a^{(p-1)/2} \pmod p,$$
taking the value $1$ when $a$ is a quadratic residue (QR) and $-1 \pmod p$ (i.e.
 $p-1$) when $a$ is a quadratic non-residue (QNR). By Euler's criterion this exa
ctly characterizes residuosity. Computing $a^{(p-1)/2} \bmod p$ via repeated squ
aring costs $O(\log p)$ modular multiplications, each $O((\log p)^2)$ bit operat
ions — polynomial in $\log p$. So we have a polynomial-time test
$$\textsf{IsQNR}(a) \;=\; \bigl[\,a^{(p-1)/2} \equiv -1 \pmod p\,\bigr].$$

**Key density fact.** The squaring map $x \mapsto x^2$ on $G$ has image of size
$(p-1)/2$ (its kernel is $\{1,-1\}$, of size $2$). Hence exactly $(p-1)/2$ eleme
nts of $G$ are QRs and exactly $(p-1)/2$ are QNRs. Therefore a uniformly random
$a \in G$ is a QNR with probability
$$\Pr[a \text{ is QNR}] = \frac{(p-1)/2}{p-1} = \frac{1}{2}.$$

### 1. Las Vegas algorithm (always correct, expected polynomial time)

```
LasVegas-QNR(p):
    repeat
        draw a uniformly from {1, ..., p-1}
        if a^((p-1)/2) ≡ -1 (mod p):
            return a
```

**Correctness.** The algorithm returns $a$ only when the Legendre symbol test ce
rtifies $a^{(p-1)/2} \equiv -1 \pmod p$, i.e. only when $a$ is genuinely a QNR.
It never returns a residue, so it is always correct.

**Expected running time.** Each iteration is one uniform draw plus one modular e
xponentiation, both polynomial in $\log p$. The success probability per iteratio
n is $1/2$. The number of iterations is geometric with success probability $1/2$
, so the expected number of iterations is
$$\mathbb{E}[\text{iterations}] = \frac{1}{1/2} = 2.$$
Each iteration costs $\operatorname{poly}(\log p)$, so the expected total time i
s $2 \cdot \operatorname{poly}(\log p) = \operatorname{poly}(\log p)$. By Markov
's inequality the running time exceeds $t \cdot \operatorname{poly}(\log p)$ wit
h probability at most $2/t$, so the algorithm is Las Vegas: always correct, expe
cted polynomial time.

### 2. Monte Carlo algorithm (always polynomial time, bounded error)

```
MonteCarlo-QNR(p, k):            # k = number of trials, controls error
    for i = 1 to k:
        draw a_i uniformly from {1, ..., p-1}
        if a_i^((p-1)/2) ≡ -1 (mod p):
            return a_i            # certified QNR, always correct
    return a_k                    # fallback: output last sample (may be a QR)
```

**Running time.** Exactly $k$ iterations, each $\operatorname{poly}(\log p)$. To
tal time $k \cdot \operatorname{poly}(\log p)$, deterministic and polynomial for
 any fixed $k$ (or $k = \operatorname{poly}(\log p)$).

**Error analysis (one-sided).** The algorithm errs only in the fallback branch,
which is reached iff **all** $k$ independent samples are QRs. Since each sample
is a QR with probability $1/2$ independently,
$$\Pr[\text{error}] = \Pr[\text{all } k \text{ samples are QR}] = \left(\frac{1}
{2}\right)^k = 2^{-k}.$$
When the algorithm does **not** err, it returns a certified QNR (the Legendre te
st passed), so the error is genuinely one-sided: a returned "QNR" is either cert
ainly a QNR (certified branch) or possibly a QR (fallback branch), and the latte
r happens with probability $2^{-k}$.

**Tuning.** Choosing $k = c$ for a constant $c$ gives constant error $2^{-c}$; c
hoosing $k = \lceil \log_2(1/\varepsilon)\rceil$ gives error at most $\varepsilo
n$ in time $O(\log(1/\varepsilon)\,\operatorname{poly}(\log p))$, polynomial for
 any inverse-polynomial $\varepsilon$. In particular $k = O(\log\log p)$ suffice
s for error $1/\operatorname{poly}(\log p)$, keeping the whole procedure polynom
ial in $\log p$.

### Comparison and summary

| | Las Vegas | Monte Carlo |
|---|---|---|
| Output correctness | always a genuine QNR | QNR except with prob. $2^{-k}$ |
| Running time | random; expected $\operatorname{poly}(\log p)$ (mean 2 trials)
| deterministic $\operatorname{poly}(\log p)$ (exactly $k$ trials) |
| Error model | none (never wrong) | one-sided, tunable to $2^{-k}$ |
| Core subroutine | Legendre symbol via $a^{(p-1)/2} \bmod p$ | same |

Both algorithms rely on the same two facts: (i) QNRs occupy exactly half of $\ma
thbb{Z}_p^*$, so random sampling hits a QNR with probability $1/2$ per trial; (i
i) the Legendre symbol is computable in polynomial time, giving a perfect member
ship test for the QNR set. The Las Vegas variant uses the test as a **filter** (
only accept certified hits, retry otherwise), yielding zero error at the cost of
 unbounded — but expected-constant — iterations. The Monte Carlo variant uses th
e test as a **verifier** but commits to a fallback answer when no hit is found w
ithin a fixed budget $k$, yielding guaranteed polynomial time at the cost of one
-sided error $2^{-k}$.
