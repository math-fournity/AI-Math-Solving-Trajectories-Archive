$$L(f) = \int_\Omega f\,d\mu \quad \text{for all } f \in C_c(\Omega).$$
Let $|\mu|$ denote the total variation measure of $\mu$.

### Step 1: Explicit formula for $a_k$

**Claim:** $a_k = \int_U g_k\,d|\mu|$.

*Upper bound.* For any admissible $f$ (i.e., $f \in C_c(\Omega)$, $|f| \leq g_k$

$$L(f) = \int f\,d\mu \leq \int |f|\,d|\mu| \leq \int_U g_k\,d|\mu|.$$
Hence $a_k \leq \int_U g_k\,d|\mu|$.

*Lower bound.* Define a signed measure $\nu_k$ by $d\nu_k = g_k\,d\mu$. Since $g
_k \geq 0$ is continuous and $\mu$ is Radon, $\nu_k$ is a signed Radon measure w
ith total variation $d|\nu_k| = g_k\,d|\mu|$.

For any $\psi \in C_c(\Omega)$ with $|\psi| \leq 1$ and $\operatorname{spt}(\psi
) \subset U$, set $f = g_k\,\psi$. Since $g_k \geq 1 > 0$ on $\Omega$:
- $f$ is continuous (product of continuous functions),
- $\operatorname{spt}(f) = \operatorname{spt}(\psi) \subset U$ (since $g_k > 0$
everywhere),
- $|f| = g_k|\psi| \leq g_k$,
- $f \in C_c(\Omega)$.

Thus $f$ is admissible for $a_k$, and
$$a_k \geq L(f) = \int g_k\,\psi\,d\mu = \int \psi\,d\nu_k.$$
Taking the supremum over such $\psi$:
$$a_k \geq \sup\!\left\{\int \psi\,d\nu_k : \psi \in C_c(\Omega),\; |\psi| \leq
1,\; \operatorname{spt}(\psi) \subset U\right\} = |\nu_k|(U) = \int_U g_k\,d|\mu

compact Hausdorff space $\Omega$), continuous functions with $|\psi| \leq 1$ and

Combining both bounds: $a_k = \int_U g_k\,d|\mu|$.

$$a_k = \int_U g_k\,d|\mu| \;\nearrow\; \int_U g\,d|\mu|.$$

Since $g_k \leq g$, every function admissible for $a_k$ is also admissible for $
a$, so $a_k \leq a$ for all $k$. Therefore:
$$\int_U g\,d|\mu| = \lim_{k\to\infty} a_k \leq a.$$

$$a = \int_U g\,d|\mu| = \lim_{k\to\infty} a_k.$$

Since $(a_k)$ is increasing (as $g_k$ is increasing) and converges to $a$, we co

$$\boxed{a_k \nearrow a \text{ as } k \to \infty.} \blacksquare$$
