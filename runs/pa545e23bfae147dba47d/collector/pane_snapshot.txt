## Solution

**Setting up coordinates.** Place $B$ at the origin, $A = (3, 0)$, and $C = (5\c
os 120°, 5\sin 120°) = \left(-\tfrac{5}{2}, \tfrac{5\sqrt{3}}{2}\right)$, so $\a
ngle ABC = 120°$, $AB = 3$, $BC = 5$.

**Using the parallel conditions to parametrize $D$ and $E$.**

- **$BC \parallel AD$:** The direction of $BC$ is $\left(-\tfrac{5}{2}, \tfrac{5
\sqrt{3}}{2}\right)$, so $D = A + s\left(-\tfrac{5}{2}, \tfrac{5\sqrt{3}}{2}\rig
ht) = \left(3 - \tfrac{5s}{2},\; \tfrac{5s\sqrt{3}}{2}\right)$ for some scalar $
s$.

- **$AC \parallel DE$:** The direction of $AC$ is $C - A = \left(-\tfrac{11}{2},
 \tfrac{5\sqrt{3}}{2}\right)$, so $E = D + u\left(-\tfrac{11}{2}, \tfrac{5\sqrt{
3}}{2}\right)$ for some scalar $u$.

- **$AB \parallel CE$:** Since $AB$ is horizontal, $CE$ must be horizontal, so $
E_y = C_y = \tfrac{5\sqrt{3}}{2}$. From the expression for $E$:
$$\frac{5s\sqrt{3}}{2} + \frac{5u\sqrt{3}}{2} = \frac{5\sqrt{3}}{2} \implies s +
 u = 1 \implies u = 1 - s.$$

Substituting back:
$$E = \left(3 - \tfrac{5s}{2} - \tfrac{11(1-s)}{2},\; \tfrac{5\sqrt{3}}{2}\right
) = \left(-\tfrac{5}{2} + 3s,\; \tfrac{5\sqrt{3}}{2}\right).$$

**Using $DE = 15$.** Since $DE = |u| \cdot |AC|$ and $|AC| = \sqrt{\tfrac{121}{4
} + \tfrac{75}{4}} = 7$:
$$|u| \cdot 7 = 15 \implies |u| = \frac{15}{7}.$$

- If $u = \tfrac{15}{7}$: then $s = -\tfrac{8}{7}$, giving $D = \left(\tfrac{41}
{7}, -\tfrac{20\sqrt{3}}{7}\right)$, which lies below the $x$-axis. Checking cro
ss products of consecutive edges shows the pentagon $ABCDE$ is **not convex** in
 this case.

- If $u = -\tfrac{15}{7}$: then $s = \tfrac{22}{7}$, giving:
$$D = \left(-\tfrac{34}{7},\; \tfrac{55\sqrt{3}}{7}\right), \qquad E = \left(\tf
rac{97}{14},\; \tfrac{5\sqrt{3}}{2}\right).$$

**Convexity check.** Computing cross products of consecutive edge vectors $AB \t
imes BC$, $BC \times CD$, $CD \times DE$, $DE \times EA$, $EA \times AB$ — all a
re negative, confirming the pentagon is convex (consistently oriented clockwise)
. ✓

**Verification of $DE = 15$:**
$$E - D = \left(\tfrac{97}{14} + \tfrac{34}{7},\; \tfrac{5\sqrt{3}}{2} - \tfrac{
55\sqrt{3}}{7}\right) = \left(\tfrac{165}{14},\; -\tfrac{75\sqrt{3}}{14}\right),
$$
$$|DE| = \tfrac{1}{14}\sqrt{165^2 + 75^2 \cdot 3} = \tfrac{1}{14}\sqrt{27225 + 1
6875} = \tfrac{\sqrt{44100}}{14} = \tfrac{210}{14} = 15. \;\checkmark$$

**Computing the areas.**

*Area of $\triangle ABC$:*
$$[\triangle ABC] = \frac{1}{2}\left|\det\begin{pmatrix} -3 & 0 \\ -\frac{11}{2}
 & \frac{5\sqrt{3}}{2}\end{pmatrix}\right| = \frac{1}{2}\cdot\frac{15\sqrt{3}}{2
} = \frac{15\sqrt{3}}{4}.$$

*Area of $\triangle EBD$:*
$$[\triangle EBD] = \frac{1}{2}\left|\det\begin{pmatrix} \frac{97}{14} & \frac{5
\sqrt{3}}{2} \\[2pt] -\frac{34}{7} & \frac{55\sqrt{3}}{7}\end{pmatrix}\right| =
\frac{1}{2}\left|\frac{97 \cdot 55\sqrt{3}}{98} + \frac{170\sqrt{3}}{14}\right|$
$
$$= \frac{1}{2}\cdot\frac{5335\sqrt{3} + 1190\sqrt{3}}{98} = \frac{1}{2}\cdot\fr
ac{6525\sqrt{3}}{98} = \frac{6525\sqrt{3}}{196}.$$

**Computing the ratio:**
$$\frac{[\triangle ABC]}{[\triangle EBD]} = \frac{\frac{15\sqrt{3}}{4}}{\frac{65
25\sqrt{3}}{196}} = \frac{15 \cdot 196}{4 \cdot 6525} = \frac{2940}{26100} = \fr
ac{49}{435}.$$

Since $\gcd(49, 435) = 1$ (as $435 = 3 \cdot 5 \cdot 29$ and $49 = 7^2$ share no
 common factors), we have $m = 49$ and $n = 435$.

$$m + n = 49 + 435 = \boxed{484}.$$
