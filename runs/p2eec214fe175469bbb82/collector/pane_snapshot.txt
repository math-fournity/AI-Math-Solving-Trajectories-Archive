## Setup

= 14400.

**Symmetry:** Swapping labels A↔B maps outcome (a,b) to (b,a), exchanging A's cr
edits and B's credits. This bijection shows P(A wins) = P(B wins). Hence

$$P(\text{A wins}) = \frac{1 - P(\text{draw})}{2}.$$

So it suffices to count draws.

## Counting draws

permutation, the draw-count is the same for every a. Thus:

$$\text{Total draws} = 120 \times D, \quad D = \#\{b : \text{draw against } a =
\text{id}\}.$$

With a = id, stage i compares i vs b_i. Define:
- exc(b) = #{i : b_i > i} = B's credits (excedances),
- fp(b) = #{i : b_i = i} = fixed points (ties),

**Draw condition:** A's credits = B's credits ⟺ exc = (5 − fp)/2. This requires
