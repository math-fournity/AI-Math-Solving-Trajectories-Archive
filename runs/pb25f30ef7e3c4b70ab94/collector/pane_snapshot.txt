## 证明

让我们展开等式右端（RHS）并对其进行简化。设 $X = A + iB$，并注意 $A - iB$ 是其“
类共轭”（因为 $A, B$ 是实矩阵，$A-iB$ 实际上就是 $\overline{X}$，尽管我们只需要
形式代数即可）。

计算两个乘积，**仔细处理非交换性**：

$$(A+iB)(A-iB) = A^2 - iAB + iBA + B^2 = A^2 + B^2 + i(BA - AB).$$

$$(A-iB)(A+iB) = A^2 + iAB - iBA + B^2 = A^2 + B^2 + i(AB - BA).$$

将它们相加：

$$(A+iB)(A-iB) + (A-iB)(A+iB) = 2A^2 + 2B^2 + i(BA-AB) + i(AB-BA).$$

交换子项为 $i(BA - AB + AB - BA) = i \cdot 0 = 0$，因此

$$(A+iB)(A-iB) + (A-iB)(A+iB) = 2(A^2 + B^2).$$

因此等式右端变为

$$\frac{2(A^2 + B^2)}{2} + C^2 = A^2 + B^2 + C^2,$$

这与等式左端（LHS）完全一致。因此，给定的等式简化为

$$A^2 + B^2 + C^2 = A^2 + B^2 + C^2,$$

这是一个**恒等式**——它对于**每一个**矩阵三元组 $(A, B, C)$ 都成立，无论是否为实
数。

### 结论

该等式是一个恒等式。它对于所有 $n \times n$ 矩阵 $A, B, C$ 都成立，特别是对于所
有**实** $n \times n$ 矩阵。因此，**是的，存在一个实数解**——事实上，每一个实矩阵
三元组 $(A, B, C)$ 都是一个解。

非交换性是唯一的潜在陷阱，但通过取两个顺序 $(A+iB)(A-iB)$ 和 $(A-iB)(A+iB)$ 的对
称平均值，交换子 $i(AB - BA)$ 项被精确抵消，这反映了标量恒等式 $(a+ib)(a-ib) = a
^2 + b^2$。因此，该等式在非交换情况下成立，与交换情况完全相同。
