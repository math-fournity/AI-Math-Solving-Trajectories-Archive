## Proof

Set $t = e^{-s}$ with $s \to 0^+$ (equivalently $t \to 1^-$, and $s = -\log t \s
im 1-t$).

### Part (a): $T(t) = \sum_{n=1}^\infty \tau(n)\, t^n$

**Reformulation as a Lambert series.** Since $\tau(n) = \sum_{d \mid n} 1$,

$$T(t) = \sum_{n=1}^\infty \sum_{d \mid n} t^n = \sum_{d=1}^\infty \sum_{k=1}^\i
nfty t^{dk} = \sum_{d=1}^\infty \frac{t^d}{1 - t^d}.$$

With $t = e^{-s}$:

$$T(e^{-s}) = \sum_{d=1}^\infty \frac{1}{e^{sd} - 1}.$$

**Extracting the leading term.** Write

$$\frac{1}{e^{sd}-1} = \frac{1}{sd}\cdot \frac{sd}{e^{sd}-1} = \frac{1}{sd}\,\ps
i(sd), \qquad \psi(u) := \frac{u}{e^u - 1}.$$

Note $\psi(u) \to 1$ as $u \to 0$ and $\psi(u) \le 1$ for all $u > 0$ (since $e^
u - 1 \ge u$), with $\psi(u) \le 2u\,e^{-u}$ for $u \ge \log 2$. Thus

$$T(e^{-s}) = \frac{1}{s}\sum_{d=1}^\infty \frac{1}{d}\,\psi(sd).$$

**Split the sum at $d = \lfloor 1/s \rfloor$.**

*Main part* ($d \le 1/s$): Here $sd \le 1$, so $\psi(sd) = 1 - sd/2 + O(s^2 d^2)
$, giving

$$\sum_{d \le 1/s} \frac{\psi(sd)}{d} = \sum_{d \le 1/s} \frac{1}{d} - \frac{s}{
2}\sum_{d \le 1/s} 1 + O\!\left(s^2 \sum_{d \le 1/s} d\right) = \log\frac{1}{s}
+ \gamma - \frac{1}{2} + O(s).$$

*Tail* ($d > 1/s$): Using $\psi(sd) \le 2sd\, e^{-sd}$ for $sd \ge 1$,

$$\sum_{d > 1/s} \frac{\psi(sd)}{d} \le 2s \sum_{d > 1/s} e^{-sd} \le \frac{2s\,
 e^{-1}}{1 - e^{-s}} = O(1).$$

Combining:

$$T(e^{-s}) = \frac{1}{s}\left(\log\frac{1}{s} + O(1)\right) = \frac{1}{s}\log\f
rac{1}{s} + O\!\left(\frac{1}{s}\right).$$

Since $s = -\log t \sim 1 - t$ as $t \to 1^-$:

$$\boxed{T(t) \sim \frac{1}{1-t}\,\log\frac{1}{1-t} \quad \text{as } t \to 1^- .
}$$

### Part (b): $S(t) = \sum_{n=1}^\infty \sigma(n)\, t^n$

**Reformulation.** Since $\sigma(n) = \sum_{d \mid n} d$,

$$S(t) = \sum_{n=1}^\infty \sum_{d \mid n} d\, t^n = \sum_{d=1}^\infty d \sum_{k
=1}^\infty t^{dk} = \sum_{d=1}^\infty \frac{d\, t^d}{1 - t^d}.$$

With $t = e^{-s}$, sum over $k$ first instead:

$$S(e^{-s}) = \sum_{d=1}^\infty \frac{d}{e^{sd}-1} = \sum_{d=1}^\infty d \sum_{k
=1}^\infty e^{-sdk} = \sum_{k=1}^\infty \sum_{d=1}^\infty d\, e^{-sdk} = \sum_{k
=1}^\infty \frac{e^{-sk}}{(1 - e^{-sk})^2},$$

using $\sum_{d=1}^\infty d\, q^d = q/(1-q)^2$ with $q = e^{-sk}$. Simplifying:

$$\frac{e^{-sk}}{(1-e^{-sk})^2} = \frac{1}{(e^{sk/2} - e^{-sk/2})^2} = \frac{1}{
4\sinh^2(sk/2)}.$$

Hence

$$S(e^{-s}) = \sum_{k=1}^\infty \frac{1}{4\sinh^2(sk/2)}.$$

**Dominated convergence.** Write

$$\frac{1}{4\sinh^2(sk/2)} = \frac{1}{s^2 k^2}\left(\frac{sk/2}{\sinh(sk/2)}\rig
ht)^2 = \frac{1}{s^2 k^2}\,\varphi(sk/2),$$

where $\varphi(u) := \bigl(u/\sinh u\bigr)^2$. Then $\varphi(u) \to 1$ as $u \to
 0$, and $\varphi(u) \le 1$ for all $u > 0$ (since $\sinh u \ge u$). Therefore

$$S(e^{-s}) = \frac{1}{s^2}\sum_{k=1}^\infty \frac{1}{k^2}\,\varphi\!\left(\frac
{sk}{2}\right).$$

Since $0 \le \varphi \le 1$ and $\sum 1/k^2 < \infty$, the **dominated convergen
ce theorem** gives

$$\sum_{k=1}^\infty \frac{1}{k^2}\,\varphi\!\left(\frac{sk}{2}\right) \xrightarr
ow{s \to 0^+} \sum_{k=1}^\infty \frac{1}{k^2} = \frac{\pi^2}{6}.$$

Thus

$$S(e^{-s}) \sim \frac{\pi^2}{6\,s^2} \quad \text{as } s \to 0^+.$$

Since $s = -\log t \sim 1 - t$:

$$\boxed{S(t) \sim \frac{\pi^2}{6\,(1-t)^2} \quad \text{as } t \to 1^- .}$$

### Summary

$$T(t) = \sum_{n=1}^\infty \tau(n)\,t^n \sim \frac{1}{1-t}\log\frac{1}{1-t}, \qq
uad S(t) = \sum_{n=1}^\infty \sigma(n)\,t^n \sim \frac{\pi^2}{6(1-t)^2}, \qquad
t \to 1^-.$$

These reflect the well-known facts that the Dirichlet series $\sum \tau(n)/n^s =
 \zeta(s)^2$ has a double pole at $s=1$ (giving the $\log$ factor in $T$), while
 $\sum \sigma(n)/n^s = \zeta(s)\zeta(s-1)$ has a double pole with residue $\zeta
(2) = \pi^2/6$ (giving the $\pi^2/6$ constant in $S$).
