## Solution

**Notation.** Let $S_n = \sum_{i=1}^{n} x_i^2$. Then $x_{n+1} = S_n$ and
$$S_{n+1} = S_n + x_{n+1}^2 = S_n + S_n^2 = S_n(S_n+1).$$
So $S_n$ evolves under $f(t) = t(t+1)$, with $S_1 = x_1^2$, and $x_{2006} = S_{2
005}$. We need $S_{2005} \equiv 0 \pmod{2006}$.

**Factorization.** $2006 = 2 \times 17 \times 59$. We use CRT.

---

### Mod 2 (automatic)

$f(t) = t(t+1) \pmod 2$: $f(0)=0$, $f(1)=1\cdot2\equiv0$. So $S_n \equiv 0 \pmod
 2$ for all $n \ge 2$. Since $2005 \ge 2$, the mod-2 condition is **automatic**
— no constraint on $x_1$.

---

### Mod 17

The fixed/absorbing structure: $f(0)=0$ (fixed point), $f(-1)=(-1)(0)=0$. So $-1
 \mapsto 0$.

**Preimages of $-1$:** solve $t(t+1) \equiv -1 \pmod{17}$, i.e., $t^2+t+1\equiv0
$. Discriminant $\Delta = -3$. Check $(-3/17)$: $-3 \equiv 14 \pmod{17}$, $14=2\
cdot7$, $(2/17)=1$ (since $17\equiv1\pmod8$), $(7/17)=-(59/7)\cdot\ldots$ — comp
uting directly, $(7/17)=-1$, so $(-3/17)=-1$. **No solution.** So $-1$ has no pr
eimage mod 17.

**Preimages of $0$:** $t\in\{0,-1\}$. Since $-1$ has no preimages, the backward
orbit of $0$ is exactly $\{0, -1\}$. No other residue ever reaches $0$.

Therefore $S_{2005}\equiv0\pmod{17}$ requires $S_1 = x_1^2 \in \{0, -1\} \pmod{1
7}$:
- $x_1^2 \equiv 0 \Rightarrow x_1 \equiv 0 \pmod{17}$.
- $x_1^2 \equiv -1 \equiv 16 \Rightarrow x_1 \equiv \pm4 \equiv 4$ or $13 \pmod{
17}$ (since $4^2=16$).

---

### Mod 59

Same structure: $f(0)=0$, $f(-1)=0$.

**Preimages of $-1$:** $t^2+t+1\equiv0\pmod{59}$, $\Delta=-3$. Check $(-3/59)$:
$-3\equiv56$, $56=2^3\cdot7$, $(2/59)=-1$ (since $59\equiv3\pmod8$), so $(2^3/59
)=(-1)^3=-1$; $(7/59)=-(59/7)=-(3/7)=-(-1)=1$. Thus $(-3/59)=-1$. **No solution.
** So $-1$ has no preimage mod 59, and the backward orbit of $0$ is exactly $\{0
,-1\}$.

Therefore $S_{2005}\equiv0\pmod{59}$ requires $S_1 = x_1^2 \in \{0,-1\}\pmod{59}
$:
- $x_1^2 \equiv 0 \Rightarrow x_1 \equiv 0 \pmod{59}$.
- $x_1^2 \equiv -1 \pmod{59}$: since $59\equiv3\pmod4$, $(-1/59)=-1$, so $-1$ is
 **not** a quadratic residue. **No solution.**

Thus **$x_1 \equiv 0 \pmod{59}$** is forced.

---

### Combining via CRT

Constraints:
- $x_1 \equiv 0 \pmod{59}$,
- $x_1 \equiv 0,\;4,$ or $13 \pmod{17}$.

Write $x_1 = 59k$. Then $59k \equiv 8k \pmod{17}$ (since $59\equiv8\pmod{17}$),
and $8^{-1}\equiv15\pmod{17}$ (since $8\cdot15=120\equiv1$).

| Condition on $x_1 \bmod 17$ | $8k \equiv$ | $k \equiv 8^{-1}\cdot$ | Smallest
$k\ge1$ | $x_1 = 59k$ |
|---|---|---|---|---|
| $0$ | $0$ | $0$ | $17$ | $1003$ |
| $4$ | $4$ | $4\cdot15=60\equiv9$ | $9$ | $531$ |
| $13$ | $13$ | $13\cdot15=195\equiv8$ | $8$ | $\mathbf{472}$ |

The smallest is $x_1 = 472$.

---

### Verification of $x_1 = 472$

- $472 = 59 \times 8$, so $x_1 \equiv 0 \pmod{59}$. Then $S_1 = x_1^2 \equiv 0 \
pmod{59}$, and $S_n \equiv 0 \pmod{59}$ for all $n$. ✓
- $472 = 17\times27 + 13$, so $x_1 \equiv 13 \equiv -4 \pmod{17}$. Then $S_1 = x
_1^2 \equiv 16 \equiv -1 \pmod{17}$, $S_2 = f(-1) = 0 \pmod{17}$, and $S_n\equiv
0\pmod{17}$ for all $n\ge2$. Since $2005\ge2$, $S_{2005}\equiv0\pmod{17}$. ✓
- $S_{2005}\equiv0\pmod2$ automatically. ✓

By CRT, $S_{2005} = x_{2006} \equiv 0 \pmod{2006}$.

### Minimality

The analysis shows the constraints $x_1\equiv0\pmod{59}$ and $x_1\equiv\{0,4,13\
}\pmod{17}$ are **necessary** (the backward orbit of $0$ under $f(t)=t(t+1)$ is
exactly $\{0,-1\}$ modulo both $17$ and $59$, since $-3$ is a non-residue modulo
 both primes). The three CRT families have minimal positive representatives $100
3$, $531$, and $472$. The smallest is $\boxed{472}$.
