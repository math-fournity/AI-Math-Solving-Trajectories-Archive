## Proof

We seek the minimum positive value of
$$f(x,y) = 25x^2 + 126xy + 162y^2$$
over all integer pairs $(x,y) \neq (0,0)$.

**The form is positive definite.** The discriminant is
$$\Delta = 126^2 - 4\cdot 25\cdot 162 = 15876 - 16200 = -324 < 0,$$
and the leading coefficient $25 > 0$, so $f(x,y) > 0$ for all $(x,y)\neq(0,0)$.

**A candidate value.** Evaluate at $(x,y)=(-3,1)$:
$$f(-3,1) = 25\cdot 9 + 126\cdot(-3) + 162\cdot 1 = 225 - 378 + 162 = 9.$$

**No smaller positive value is attainable.** Fix $n$ and ask whether $f(x,y)=n$
has an integer solution. Treating this as a quadratic in $x$:
$$25x^2 + 126y\,x + (162y^2 - n) = 0,$$
the discriminant in $x$ is
$$D_x = (126y)^2 - 4\cdot 25\cdot(162y^2 - n) = 15876y^2 - 16200y^2 + 100n = -32
4y^2 + 100n.$$
For a real (hence integer) solution we need $D_x \ge 0$, i.e.
$$y^2 \le \frac{100n}{324} = \frac{25n}{81}.$$

For $n \le 8$: $\frac{25n}{81} \le \frac{200}{81} \approx 2.47$, so $|y| \le 1$,
 giving three cases:

- **$y = 0$:** $f(x,0) = 25x^2 = n$. Since $|x|\ge 1$ gives $25x^2 \ge 25 > 8$,
no solution for $n \le 8$.

- **$y = \pm 1$:** $D_x = -324 + 100n$. For $n \le 3$, $D_x < 0$ (no real soluti
on). For $n \in \{4,5,6,7,8\}$, $D_x \in \{76, 176, 276, 376, 476\}$. Checking p
erfect squares: $8^2=64<76<81=9^2$; $13^2=169<176<196=14^2$; $16^2=256<276<289=1
7^2$; $19^2=361<376<400=20^2$; $21^2=441<476<484=22^2$. None is a perfect square
, so $x$ is irrational — no integer solution.

Therefore $f(x,y) = n$ has **no** integer solution for any $1 \le n \le 8$.

**Conclusion.** The value $9$ is attained (at $(-3,1)$ and by symmetry at $(3,-1
)$), and no positive integer below $9$ is attainable. The minimum positive value
 is

$$\boxed{9}.$$
