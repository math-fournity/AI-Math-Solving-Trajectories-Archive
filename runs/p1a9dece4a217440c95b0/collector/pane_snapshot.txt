## Solution

### Setup

The distribution $f_a(x) = \frac{H(x+a) - H(x-a)}{2a}$ is the rectangular pulse
of height $\frac{1}{2a}$ supported on $[-a, a]$. Its action on a test function $
\phi \in \mathcal{D}(\mathbb{R})$ is:

$$\langle f_a, \phi \rangle = \frac{1}{2a}\int_{-a}^{a} \phi(x)\,dx.$$

### Part 1: Computing $\frac{\partial f_a}{\partial a}$

We differentiate $\langle f_a, \phi\rangle$ with respect to $a$. Applying the pr
oduct rule to $\frac{1}{2a}\int_{-a}^{a}\phi(x)\,dx$ and the Leibniz integral ru
le $\frac{d}{da}\int_{-a}^{a}\phi(x)\,dx = \phi(a)+\phi(-a)$:

$$\left\langle \frac{\partial f_a}{\partial a},\,\phi\right\rangle = -\frac{1}{2
a^2}\int_{-a}^{a}\phi(x)\,dx \;+\; \frac{\phi(a)+\phi(-a)}{2a}.$$

**Distributional form.** Since $\frac{\partial}{\partial a}H(x+a)=\delta(x+a)$ a
nd $\frac{\partial}{\partial a}H(x-a)=-\delta(x-a)$, the product rule gives:

$$\boxed{\frac{\partial f_a}{\partial a} = \frac{\delta(x+a)+\delta(x-a)}{2a} -
\frac{H(x+a)-H(x-a)}{2a^2}.}$$

### Part 2: The limit $a \to 0$

We evaluate $\lim_{a\to 0}\left\langle \frac{\partial f_a}{\partial a},\,\phi\ri
ght\rangle$ by Taylor-expanding $\phi$ about $0$:

$$\phi(x) = \phi(0) + \phi'(0)\,x + \tfrac{\phi''(0)}{2}\,x^2 + \tfrac{\phi'''(0
)}{6}\,x^3 + \cdots$$

**First term** $\displaystyle\frac{\phi(a)+\phi(-a)}{2a}$: Adding the series at
$x=a$ and $x=-a$, all odd powers cancel:

$$\phi(a)+\phi(-a) = 2\phi(0) + \phi''(0)\,a^2 + \tfrac{\phi^{(4)}(0)}{12}\,a^4
+ \cdots$$

$$\frac{\phi(a)+\phi(-a)}{2a} = \frac{\phi(0)}{a} + \frac{\phi''(0)}{2}\,a + O(a
^3).$$

**Second term** $\displaystyle\frac{1}{2a^2}\int_{-a}^{a}\phi(x)\,dx$: Odd integ
rands vanish over the symmetric interval, so:

$$\int_{-a}^{a}\phi(x)\,dx = 2\phi(0)\,a + \frac{\phi''(0)}{3}\,a^3 + \frac{\phi
^{(4)}(0)}{60}\,a^5 + \cdots$$

$$\frac{1}{2a^2}\int_{-a}^{a}\phi(x)\,dx = \frac{\phi(0)}{a} + \frac{\phi''(0)}{
6}\,a + O(a^3).$$

**Combining**, the singular $\frac{\phi(0)}{a}$ terms cancel exactly:

$$\left\langle \frac{\partial f_a}{\partial a},\,\phi\right\rangle = \left(\frac
{1}{2}-\frac{1}{6}\right)\phi''(0)\,a + O(a^3) = \frac{\phi''(0)}{3}\,a + O(a^3)
.$$

Taking $a \to 0$:

$$\lim_{a\to 0}\left\langle \frac{\partial f_a}{\partial a},\,\phi\right\rangle
= 0 \qquad \text{for every test function } \phi.$$

### Result

$$\boxed{\lim_{a\to 0}\frac{\partial f_a}{\partial a} = 0 \quad\text{(the zero d
istribution).}}$$

**Interpretation.** As $a\to 0$, $f_a \to \delta$ (the Dirac delta). The family
$f_a$ is an even approximation to the identity, and its leading correction about
