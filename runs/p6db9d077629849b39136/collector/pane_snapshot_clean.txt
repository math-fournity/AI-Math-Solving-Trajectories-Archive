## Solution

**Setting up the angle sequence.** Since angles A, B, C, D form an increasing ar
ithmetic sequence summing to 360°, write them as:
- A = 90° − 3d, B = 90° − d, C = 90° + d, D = 90° + 3d

with 0 < d < 30° (so all angles are positive).

**Triangle ABC (right-angled at C).** Place the foot of the altitude from C to A
B at the origin H, with AB on the x-axis and C = (0, 9). Let A = (−p, 0), B = (q
, 0) with p, q > 0.

The right-angle condition ∠ACB = 90° gives the altitude-on-hypotenuse relation:
**pH · qH = CH² = 81**, i.e., pq = 81.

From the angles in triangle ABC:
- ∠BAC = 180° − 90° − (90° − d) = **d**, so tan d = 9/p → p = 9 cot d
- ∠ABC = 90° − d, so tan(90° − d) = 9/q → q = 9 tan d

Check: pq = 81 cot d · tan d = 81. ✓

The diagonal AC splits the quadrilateral's angles:
- At A: ∠DAC = (90° − 3d) − d = 90° − 4d (need d < 22.5°)
- At C: ∠ACD = (90° + d) − 90° = d

**Triangle ACD.** Angles: ∠DAC = 90° − 4d, ∠ACD = d, ∠ADC = 90° + 3d (= D). ✓

By the Law of Sines in △ACD, using AC = 9 csc d (from the right triangle):

$$\frac{CD}{\sin(90°-4d)} = \frac{AC}{\sin(90°+3d)} \implies \frac{14}{\cos 4d}
= \frac{9}{\sin d \cos 3d}$$

This gives the key equation:
$$9\cos 4d = 14\sin d\cos 3d$$

**Solving the equation.** Using product-to-sum: 14 sin d cos 3d = 7(sin 4d − sin
 2d), and cos 4d = 1 − 2sin²2d, sin 4d = 2 sin 2d cos 2d:

$$9(1 - 2\sin^2 2d) = 7\sin 2d(2\cos 2d - 1)$$

Let u = sin 2d (with 0 < u < √2/2 since 0 < 2d < 45°). Substituting v = cos 2d =
 √(1−u²) and squaring:

$$520u^4 - 252u^3 - 471u^2 + 126u + 81 = 0$$

Testing u = 3/5: 520(81/625) − 252(27/125) − 471(9/25) + 126(3/5) + 81 = 67.392
− 54.432 − 169.56 + 75.6 + 81 = **0**. ✓

Factoring: (5u − 3)(104u³ + 12u² − 87u − 27) = 0. The cubic is negative througho
ut (0, 0.707), so the only valid root is **sin 2d = 3/5**.

Verification (unsquared equation): 9 − 18(9/25) + 7(3/5) = 6.72 = 14(3/5)(4/5) =
 6.72. ✓

**Computing the area.** The area of ABCD = Area(△ABC) + Area(△ACD).

- **Area(△ABC)** = ½ · AB · CH = ½(p+q)·9 = (81/2)(cot d + tan d) = 81/(sin 2d)
= 81/(3/5) = **135**

- **Area(△ACD)** = ½ · AC · CD · sin(∠ACD) = ½ · (9/ sin d) · 14 · sin d = ½ · 9
 · 14 = **63**

(This is independent of d — a beautiful simplification.)

$$\text{Area}(ABCD) = 135 + 63 = \boxed{198}$$
