## Solution

Let the two power levels be positive integers $A, B < 1000$.

**Setting up the constraints.** Let the average (arithmetic mean) be the odd int
eger $m$. Then
$$\frac{A+B}{2} = m \implies A + B = 2m.$$

The geometric mean is the odd integer immediately preceding $m$, i.e. $m - 2$ (t
he odd integer just before an odd integer $m$ is $m-2$). Thus
$$\sqrt{AB} = m - 2 \implies AB = (m-2)^2.$$

**Solving for $A, B$.** They are roots of
$$t^2 - 2m\,t + (m-2)^2 = 0.$$

The discriminant is
$$\Delta = 4m^2 - 4(m-2)^2 = 4\bigl(m^2 - (m^2 - 4m + 4)\bigr) = 4(4m - 4) = 16(
m-1).$$

So
$$A, B = \frac{2m \pm 4\sqrt{m-1}}{2} = m \pm 2\sqrt{m-1}.$$

For $A, B$ to be integers, $m - 1$ must be a perfect square. Let $m - 1 = k^2$,
i.e. $m = k^2 + 1$. Then
$$A = k^2 + 1 + 2k = (k+1)^2, \qquad B = k^2 + 1 - 2k = (k-1)^2.$$

**Verification:** $A + B = (k+1)^2 + (k-1)^2 = 2k^2 + 2 = 2(k^2+1) = 2m$ ✓. $AB
= (k+1)^2(k-1)^2 = (k^2-1)^2$, so $\sqrt{AB} = k^2 - 1 = m - 2$ ✓.

**Parity constraint.** $m = k^2 + 1$ must be odd, so $k^2$ must be even, so $k$
must be even. Write $k = 2j$ with $j \ge 1$ (so that $B = (k-1)^2 = (2j-1)^2 > 0
$). Then
$$A = (2j+1)^2, \qquad B = (2j-1)^2.$$

**Maximizing the difference.**
$$|A - B| = (2j+1)^2 - (2j-1)^2 = 8j.$$

We need both $A, B < 1000$. The binding constraint is $A = (2j+1)^2 < 1000$:
$$2j + 1 < \sqrt{1000} \approx 31.62 \implies 2j + 1 \le 31 \implies j \le 15.$$

($j = 16$ gives $A = 33^2 = 1089 > 1000$, violating the constraint.)

**Maximum** at $j = 15$:
$$A = 31^2 = 961, \quad B = 29^2 = 841.$$

Check: $A, B < 1000$ ✓. Average $= (961 + 841)/2 = 901$ (odd ✓). Geometric mean
$= \sqrt{961 \cdot 841} = \sqrt{808801} = 899 = 901 - 2$ (odd, immediately prece
ding ✓).

**Maximum difference:**
$$|A - B| = 961 - 841 = 8 \times 15 = \boxed{120}.$$
