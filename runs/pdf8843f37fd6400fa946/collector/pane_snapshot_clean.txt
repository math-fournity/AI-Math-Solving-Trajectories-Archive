## Solution

We want
$$\mathbf{E}\!\left[B_s^2 B_t^4 - 2B_s^3 B_t^3 + B_s^4 B_t^2\right], \qquad t \g
e s.$$

**Step 1: Factor the integrand.** Write the expression in terms of $B_s$ and $B_
t$:
$$B_s^2 B_t^4 - 2B_s^3 B_t^3 + B_s^4 B_t^2 = B_s^2 B_t^2\!\left(B_t^2 - 2B_s B_t
 + B_s^2\right) = B_s^2 B_t^2 (B_t - B_s)^2.$$

So the expectation reduces to
$$\mathbf{E}\!\left[B_s^2 B_t^2 (B_t - B_s)^2\right].$$

**Step 2: Decompose into independent pieces.** Set
$$X = B_s \sim N(0,s), \qquad Y = B_t - B_s \sim N(0,\,t-s),$$
with $X$ and $Y$ independent (independent increments of Brownian motion), and $B
_t = X + Y$. Then
$$\mathbf{E}\!\left[B_s^2 B_t^2 (B_t-B_s)^2\right] = \mathbf{E}\!\left[X^2 (X+Y)
^2 Y^2\right].$$

Expand $(X+Y)^2 = X^2 + 2XY + Y^2$:
$$X^2(X+Y)^2 Y^2 = X^4 Y^2 + 2 X^3 Y^3 + X^2 Y^4.$$

**Step 3: Use independence and Gaussian moments.** Since $X \perp Y$:
- $\mathbf{E}[X^4 Y^2] = \mathbf{E}[X^4]\,\mathbf{E}[Y^2]$,
- $\mathbf{E}[X^3 Y^3] = \mathbf{E}[X^3]\,\mathbf{E}[Y^3] = 0$ (odd moments of c
entered Gaussians vanish),
- $\mathbf{E}[X^2 Y^4] = \mathbf{E}[X^2]\,\mathbf{E}[Y^4]$.

For $Z \sim N(0,\sigma^2)$: $\mathbf{E}[Z^2] = \sigma^2$, $\mathbf{E}[Z^4] = 3\s
igma^4$. Hence
$$\mathbf{E}[X^2] = s,\quad \mathbf{E}[X^4] = 3s^2,\quad \mathbf{E}[Y^2] = t-s,\
quad \mathbf{E}[Y^4] = 3(t-s)^2.$$

**Step 4: Combine.**
$$\mathbf{E} = 3s^2(t-s) + 0 + s\cdot 3(t-s)^2 = 3s(t-s)\bigl[s + (t-s)\bigr] =
3s(t-s)\cdot t.$$

**Sanity checks.**
- $t = s$: original integrand $= B_s^2 B_s^4 - 2B_s^6 + B_s^4 B_s^2 = 0$; formul
a gives $3s\cdot s\cdot 0 = 0$. ✓
- $s = 0$: $B_0 = 0$ so the expression is $0$; formula gives $0$. ✓

## Result

$$\boxed{\,\mathbf{E}\!\left[B_s^2 B_t^4 - 2B_s^3 B_t^3 + B_s^4 B_t^2\right] = 3
\,s\,t\,(t-s)\,}$$
