## Proof

Let the arithmetic progression be $s_n = a + (n-1)d$, where $a = s_1 \geq 1$ is
a positive integer and $d \geq 0$ is the common difference (a non-negative integ
er).

**Step 1: Express the three given values.**

Since $s_1 = a$, $s_2 = a+d$, $s_3 = a+2d$, we compute:

$$s_{s_1} = s_a = a + (a-1)d = a(1+d) - d.$$

$$s_{s_2} = s_{a+d} = a + (a+d-1)d = a(1+d) + d^2 - d.$$

$$s_{s_3} = s_{a+2d} = a + (a+2d-1)d = a(1+d) + 2d^2 - d.$$

Setting $A = a(1+d) - d = s_{s_1}$, the three equations become:

$$s_{s_1} = A = x+2, \qquad s_{s_2} = A + d^2 = x^2+18, \qquad s_{s_3} = A + 2d^
2 = 2x^2+18.$$

**Step 2: Determine $d$ in terms of $x$.**

Subtracting the second equation from the third:

$$d^2 = s_{s_3} - s_{s_2} = (2x^2+18) - (x^2+18) = x^2.$$

Since $d \geq 0$, we have $d = |x|$.

**Step 3: Solve for $x$.**

Substituting $A = x+2$ and $d^2 = x^2$ into the second equation $A + d^2 = x^2 +
 18$:

$$(x+2) + x^2 = x^2 + 18 \implies x + 2 = 18 \implies x = 16.$$

**Step 4: Verify.**

With $x = 16$, we get $d = 16$ and $A = 18$. From $A = a(1+d)-d = 17a - 16 = 18$
, we obtain $a = 2$. The progression is $s_n = 2 + (n-1)\cdot 16 = 16n - 14$.

- $s_1 = 2,\ s_2 = 18,\ s_3 = 34$.
- $s_{s_1} = s_2 = 18 = 16 + 2 = x+2$. ✓
- $s_{s_2} = s_{18} = 16\cdot18 - 14 = 274 = 256 + 18 = x^2+18$. ✓
- $s_{s_3} = s_{34} = 16\cdot34 - 14 = 530 = 512 + 18 = 2x^2+18$. ✓

All conditions are satisfied with positive integer terms.

$$\boxed{x = 16}$$
