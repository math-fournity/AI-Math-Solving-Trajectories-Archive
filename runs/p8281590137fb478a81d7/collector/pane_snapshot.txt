## Proof

$H = \mathbb{L}^2(0,1)$ is the Hilbert space of (equivalence classes of) square-
integrable functions on $(0,1)$, where two functions are identified if they agre
e almost everywhere (a.e.) with respect to Lebesgue measure.

The set in question is $L = \{f \in H : f(0) = 0\}$.

**Key observation.** In $\mathbb{L}^2(0,1)$, point evaluation at a single point
is not a well-defined operation on equivalence classes, because a single point h
as Lebesgue measure zero. Modifying a function at the point $\{0\}$ does not cha
nge its equivalence class.

**Claim.** $L = H$.

*Proof of claim.* Let $f \in H$ be arbitrary, and let $\hat{f}$ be any represent
ative of the equivalence class $f$. Define
$$\tilde{f}(x) = \begin{cases} \hat{f}(x), & x \in (0,1), \\ 0, & x = 0. \end{ca
ses}$$
The functions $\hat{f}$ and $\tilde{f}$ differ only on the set $\{0\}$, which ha
s Lebesgue measure zero. Hence $\tilde{f}$ is another representative of the same
 equivalence class $f$. Since $\tilde{f}(0) = 0$, the equivalence class $f$ belo
ngs to $L$. As $f$ was arbitrary, $L = H$. $\square$

Since $L = H$, the smallest closed affine subspace of $H$ containing $L$ is $H$
itself.
