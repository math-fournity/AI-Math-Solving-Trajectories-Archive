## Proof

**Theorem.** *An $n\times n$ complex matrix $C$ can be written as $C = AB - BA$
for some $n\times n$ matrices $A, B$ if and only if $\operatorname{tr}(C) = 0$.*

The "only if" direction is immediate from cyclicity of trace:
$$\operatorname{tr}(AB - BA) = \operatorname{tr}(AB) - \operatorname{tr}(BA) = 0
.$$

For the converse, we prove two lemmas.

---

**Lemma 1.** *Every traceless $n\times n$ complex matrix is similar to a matrix
with all diagonal entries equal to $0$.*

**Proof of Lemma 1**, by induction on $n$.

*Base case* $n=1$: traceless means $C = [0]$, already zero-diagonal.

*Inductive step* ($n \geq 2$): Assume the result for $n-1$. Let $C$ be traceless
.

- **If $C$ is not a scalar matrix**, there exists a vector $v$ such that $v$ and
 $Cv$ are linearly independent (otherwise every nonzero vector is an eigenvector
, forcing $C$ to be scalar). Set $v_1 = v$ and $v_2 = Cv$; extend to a basis $\{
v_1, v_2, \dots, v_n\}$. In this basis the matrix of $C$ is
$$M = \begin{pmatrix} 0 & r^{T} \\ c & D \end{pmatrix},$$
where the first column is $(0,1,0,\dots,0)^T$ (since $Cv_1 = v_2$), so the $(1,1
)$-entry is $0$, and $D$ is $(n-1)\times(n-1)$. Since $\operatorname{tr}(M)=0$ a
nd $M_{11}=0$, we get $\operatorname{tr}(D)=0$. By the induction hypothesis, the
re is an invertible $Q$ with $Q^{-1}DQ$ zero-diagonal. Setting $P' = \operatorna
me{diag}(1, Q)$ gives
$$P'^{-1} M\, P' = \begin{pmatrix} 0 & r^T Q \\ Q^{-1}c & Q^{-1}DQ \end{pmatrix}
,$$
which has zero diagonal (the $(1,1)$ entry stays $0$, and $Q^{-1}DQ$ has zero di
agonal by construction).

- **If $C = \lambda I$**, then $\operatorname{tr}(C) = n\lambda = 0$ over $\math
bb{C}$ (characteristic $0$) gives $\lambda = 0$, so $C = 0$, already zero-diagon
al.

This completes the induction. $\square$

---

**Lemma 2.** *Every zero-diagonal matrix is a commutator.*

**Proof of Lemma 2.** Let $C$ have zero diagonal. Choose $A = \operatorname{diag
}(a_1, \dots, a_n)$ with all $a_i$ distinct (e.g. $a_i = i$). Define $B$ by
$$B_{ij} = \begin{cases} \dfrac{C_{ij}}{a_i - a_j}, & i \neq j, \\[6pt] 0, & i =
 j. \end{cases}$$
Then for $i \neq j$:
$$(AB - BA)_{ij} = a_i B_{ij} - B_{ij} a_j = (a_i - a_j) B_{ij} = C_{ij},$$
and for the diagonal:
$$(AB - BA)_{ii} = a_i B_{ii} - B_{ii} a_i = 0 = C_{ii}.$$
Hence $AB - BA = C$. $\square$

---

**Combining the lemmas.** Given a traceless $C$, by Lemma 1 there exists an inve
rtible $P$ such that $C' := P^{-1}CP$ has zero diagonal. By Lemma 2, $C' = A'B'
- B'A'$ for some $A', B'$. Setting $A = PA'P^{-1}$ and $B = PB'P^{-1}$:
$$AB - BA = PA'P^{-1}PB'P^{-1} - PB'P^{-1}PA'P^{-1} = P(A'B' - B'A')P^{-1} = PC'
P^{-1} = C.$$

Therefore **yes**, for every $n\times n$ complex matrix $C$ with $\operatorname{
tr}(C) = 0$, there exist $n\times n$ matrices $A$ and $B$ such that $AB - BA = C
$. The trace-zero condition is both necessary and sufficient. $\blacksquare$
