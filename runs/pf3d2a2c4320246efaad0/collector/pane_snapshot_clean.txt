## Proof

**Setup with Ravi substitution.** Let $s=\tfrac{a+b+c}{2}$ and set
$$x=s-c,\quad y=s-a,\quad z=s-b \qquad (x,y,z>0).$$
Then $a=y+z,\; b=z+x,\; c=x+y$, and
$$a+b-c=2x,\quad b+c-a=2y,\quad c+a-b=2z.$$

**Rewrite the constraint.** Let $p=x^2+y^2+z^2$ and $q=xy+yz+zx$. Then
$$a^2+b^2+c^2=(y+z)^2+(z+x)^2+(x+y)^2=2(p+q)=2,$$
so $p+q=1$.

**Rewrite $ab+bc+ca$.** A direct expansion gives
$$ab+bc+ca=p+3q=p+3(1-p)=3-2p.$$
Hence
$$3-(ab+bc+ca)=2p.$$

**Rewrite the target expression.** The denominator is
$$(2x)^2(2y)^2(2z)^2=64\,x^2y^2z^2,$$
so the expression equals
$$E=\frac{(2p)^3}{64\,x^2y^2z^2}=\frac{p^3}{8\,x^2y^2z^2}.$$

**Apply AM–GM.** By the AM–GM inequality on $x^2,y^2,z^2$:
$$p=x^2+y^2+z^2\ge 3\sqrt[3]{x^2y^2z^2}=3(xyz)^{2/3}.$$
Raising both sides to the third power,
$$p^3\ge 27\,x^2y^2z^2 \quad\Longrightarrow\quad \frac{p^3}{x^2y^2z^2}\ge 27.$$
Therefore
$$E=\frac{1}{8}\cdot\frac{p^3}{x^2y^2z^2}\ge\frac{27}{8}.$$

**Equality.** Equality in AM–GM holds iff $x^2=y^2=z^2$, i.e. $x=y=z$ (since $x,
y,z>0$). Then $p=q=3x^2$ and $p+q=6x^2=1$, giving $x=1/\sqrt6$, so
$$a=b=c=2x=\frac{2}{\sqrt6}.$$
This is a valid equilateral triangle with $a^2+b^2+c^2=3\cdot\tfrac{4}{6}=2$. Ve
rification:
- $ab+bc+ca=2$, so $3-(ab+bc+ca)=1$;
- each factor $a+b-c=\tfrac{2}{\sqrt6}$, so the denominator is $\left(\tfrac{2}{
\sqrt6}\right)^6=\tfrac{64}{216}=\tfrac{8}{27}$;
- $E=1\big/\tfrac{8}{27}=\tfrac{27}{8}$.

**Conclusion.** The minimum possible value of the expression is

$$\boxed{\dfrac{27}{8}}.$$
