## Proof

Let the three distinct digits be $a, b, c$ (with $a \neq 0$ in the hundreds plac
e of the original code). Let $s = a + b + c$.

**Sum of all six permutations.** Among all $3! = 6$ permutations of $\{a, b, c\}
$, each digit appears in the hundreds place exactly $2$ times, in the tens place
 exactly $2$ times, and in the units place exactly $2$ times. Hence the sum of a
ll six permutations is

$$2s \cdot 100 + 2s \cdot 10 + 2s \cdot 1 = 222s.$$

**Relating to the original code.** The five *alternative* permutations sum to $2
003$, so if the original code is $N$ (one of the six permutations),

$$222s = 2003 + N, \qquad \text{i.e., } N = 222s - 2003.$$

**Bounding $s$.** Since $N$ is a 3-digit number, $100 \le N \le 999$:

$$100 \le 222s - 2003 \le 999 \implies 2103 \le 222s \le 3002 \implies 9.47 \le
s \le 13.52.$$

Thus $s \in \{10, 11, 12, 13\}$.

**Testing each candidate.** Note $2003 = 9 \cdot 222 + 5$, so $N = 222(s-9) - 5$
.

- $s = 10$: $N = 2220 - 2003 = 217$. Digits $\{2,1,7\}$, sum $= 10 = s$. ✓ Disti
nct, valid.
- $s = 11$: $N = 2442 - 2003 = 439$. Digits sum $= 4+3+9 = 16 \neq 11$. ✗
- $s = 12$: $N = 2664 - 2003 = 661$. Digits $6,6,1$ not distinct. ✗
- $s = 13$: $N = 2886 - 2003 = 883$. Digits $8,8,3$ not distinct. ✗

Only $s = 10$ yields a valid 3-digit number with three distinct digits summing t
o $s$.

**Verification.** The five other permutations of $\{1, 2, 7\}$ are $271, 127, 17
2, 712, 721$:

$$271 + 127 + 172 + 712 + 721 = 398 + 172 + 712 + 721 = 570 + 712 + 721 = 1282 +
 721 = 2003. \checkmark$$

The original 3-digit security code is $\boxed{217}$.
