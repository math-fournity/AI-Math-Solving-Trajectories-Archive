## Solution

**Interpretation.** "Seven-digit numbers consisting of the digits 1, 2, 3, 4, 5,
 6, 7" means each of the seven digits is used exactly once — i.e., the 7! = 5040
 permutations of {1,2,3,4,5,6,7}. Since every such number has exactly seven digi
ts, listing them in increasing order is the same as listing them lexicographical
ly.

**Goal.** Find the 2024th term (1-indexed), i.e., the permutation at 0-indexed p
osition 2023.

**Factorial decomposition.** Write $2023$ in the factorial-number system with pl
ace values $6!,5!,4!,3!,2!,1!,0!$:

$$
2023 = 2\cdot 720 + 4\cdot 120 + 4\cdot 24 + 1\cdot 6 + 0\cdot 2 + 1\cdot 1 + 0\
cdot 1.
$$

So the Lehmer code (digits of the factorial representation) is $(2,4,4,1,0,1,0)$
.

**Reconstructing the permutation.** Start with the ordered digit pool $D=\{1,2,3
,4,5,6,7\}$ and pick the element at the given 0-indexed position, removing it ea
ch time:

| Position | Pool (sorted) | Index | Chosen | Remaining |
|---|---|---|---|---|
| 1st digit | {1,2,3,4,5,6,7} | 2 | **3** | {1,2,4,5,6,7} |
| 2nd digit | {1,2,4,5,6,7} | 4 | **6** | {1,2,4,5,7} |
| 3rd digit | {1,2,4,5,7} | 4 | **7** | {1,2,4,5} |
| 4th digit | {1,2,4,5} | 1 | **2** | {1,4,5} |
| 5th digit | {1,4,5} | 0 | **1** | {4,5} |
| 6th digit | {4,5} | 1 | **5** | {4} |
| 7th digit | {4} | 0 | **4** | {} |

**Verification of the arithmetic.**
- $2\cdot720 = 1440$, remainder $583$.
- $4\cdot120 = 480$, remainder $103$.
- $4\cdot24 = 96$, remainder $7$.
- $1\cdot6 = 6$, remainder $1$.
- $0\cdot2 = 0$, remainder $1$.
- $1\cdot1 = 1$, remainder $0$.

Total: $1440+480+96+6+1 = 2023$. ✓

**Sanity check on ordering.** The first digit being 3 covers positions $1441$–$2
160$ (indices $1440$–$2159$), and $2024$ falls in this block. Within the block,
second digit 6 covers a sub-block of size 120 starting at relative index $480$,
i.e., absolute position $1440+480+1 = 1921$; $2024-1920 = 104$, so we need the 1
03rd (0-indexed) permutation of the remaining four digits — consistent with the
decomposition above.
