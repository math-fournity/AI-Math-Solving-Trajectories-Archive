I'll solve this integral using complex analysis with the unit circle contour.

## Step 1: Simplify the integrand

$$\sin^4 2x + \cos^4 2x = (\sin^2 2x + \cos^2 2x)^2 - 2\sin^2 2x\cos^2 2x = 1 -
\tfrac{1}{2}\sin^2 4x.$$

So
$$I = \int_0^{\pi}\frac{dx}{1 - \tfrac{1}{2}\sin^2 4x} = \int_0^{\pi}\frac{2\,dx
}{2 - \sin^2 4x}.$$

## Step 2: Reduce to a full-period integral over $[0,2\pi]$

Let $u = 4x$, $dx = du/4$:
$$I = \frac{1}{2}\int_0^{4\pi}\frac{du}{2 - \sin^2 u}.$$

Since the integrand has period $\pi$ in $u$, $\int_0^{4\pi} = 4\int_0^{\pi}$, an
d by symmetry $\int_0^{\pi} = 2\int_0^{\pi/2}$. Also
$$2 - \sin^2 u = 2\cos^2 u + \sin^2 u,$$
which is $\pi$-periodic and symmetric about $\pi/2$. Hence
$$I = 2\int_0^{\pi}\frac{du}{2\cos^2 u + \sin^2 u} = \int_0^{2\pi}\frac{du}{2\co
s^2 u + \sin^2 u}.$$

## Step 3: Apply the unit-circle substitution

Set $z = e^{iu}$, $dz = iz\,du$, $\cos u = \frac{z+z^{-1}}{2}$, $\sin u = \frac{
z-z^{-1}}{2i}$. Then
$$2\cos^2 u + \sin^2 u = \frac{2(z+z^{-1})^2 - (z-z^{-1})^2}{4} = \frac{z^2 + 6
+ z^{-2}}{4}.$$

Therefore
$$I = \oint_{|z|=1}\frac{4}{z^2+6+z^{-2}}\frac{dz}{iz} = \frac{4}{i}\oint_{|z|=1
}\frac{z\,dz}{z^4 + 6z^2 + 1}.$$

## Step 4: Locate the poles inside the unit circle

The poles are the roots of $z^4 + 6z^2 + 1 = 0$. With $t = z^2$:
$$t = \frac{-6 \pm \sqrt{32}}{2} = -3 \pm 2\sqrt{2}.$$

Both roots are negative. For $t = -3 + 2\sqrt{2}$: since $3 - 2\sqrt{2} = (\sqrt
{2}-1)^2$,
$$z = \pm\, i(\sqrt{2}-1), \qquad |z| = \sqrt{2}-1 < 1 \quad (\text{inside}).$$

For $t = -3 - 2\sqrt{2}$: since $3 + 2\sqrt{2} = (\sqrt{2}+1)^2$,
$$z = \pm\, i(\sqrt{2}+1), \qquad |z| = \sqrt{2}+1 > 1 \quad (\text{outside}).$$

So there are two simple poles inside $|z|=1$: $z_1 = i(\sqrt{2}-1)$ and $z_2 = -
i(\sqrt{2}-1)$.

## Step 5: Compute the residues

For $f(z) = \dfrac{z}{z^4+6z^2+1}$, at a simple pole $z_0$:
$$\operatorname{Res}(f, z_0) = \frac{z_0}{4z_0^3 + 12z_0} = \frac{1}{4(z_0^2 + 3
)}.$$

Both interior poles share $z_0^2 = -3 + 2\sqrt{2}$, so $z_0^2 + 3 = 2\sqrt{2}$,
giving
$$\operatorname{Res}(f, z_1) = \operatorname{Res}(f, z_2) = \frac{1}{4\cdot 2\sq
rt{2}} = \frac{1}{8\sqrt{2}}.$$

Sum of residues $= \dfrac{1}{4\sqrt{2}}$.

## Step 6: Apply the residue theorem

$$I = \frac{4}{i}\cdot 2\pi i \cdot \frac{1}{4\sqrt{2}} = \frac{8\pi}{4\sqrt{2}}
 = \frac{2\pi}{\sqrt{2}} = \sqrt{2}\,\pi.$$

## Result

$$\boxed{\int_{0}^{\pi}\frac{dx}{\sin^4 2x + \cos^4 2x} = \sqrt{2}\,\pi}$$
