## Setting Up the Complement

Let $H = \bar{G}$ be the complement graph. Minimizing $|E(G)|$ is equivalent to
maximizing $|E(H)|$.

A 4-vertex induced subgraph is **disconnected** if and only if its 4 vertices ca
n be partitioned into two non-empty parts with no edges between them. The only p
artition types are **1+3** and **2+2**.

**Condition (C1) — no 1+3 disconnection:** No vertex $v$ is non-adjacent (in $G$
) to 3 other vertices. In $H$, this means no vertex has degree $\geq 3$, i.e., $
\deg_H(v) \leq 2$ for all $v$.

**Condition (C2) — no 2+2 disconnection:** There do not exist 4 distinct vertice
s $a,b,c,d$ such that none of $ac, ad, bc, bd$ are edges of $G$. In $H$, this me
ans there do not exist 4 distinct vertices with $ac, ad, bc, bd \in E(H)$ — that
 is, $H$ contains no $K_{2,2}$ (4-cycle) as a subgraph.

## Maximizing Edges in $H$

Since $\deg_H(v) \leq 2$, the graph $H$ is a disjoint union of **paths and cycle
s**. The maximum number of edges is $\sum \deg / 2 \leq 2 \cdot 25 / 2 = 25$, wi
th equality iff every component is a cycle (no paths, since a path on $k$ vertic
es has only $k-1$ edges).

Condition (C2) forbids 4-cycles. Since $H$ has max degree 2, a $K_{2,2}$ can onl
y arise as an actual 4-cycle component — longer cycles ($k \geq 5$) and triangle
s contain no 4-cycle as a subgraph.

So we need to partition 25 vertices into cycles of allowed lengths $\{3, 5, 6, 7
, \dots\}$ (any length $\geq 3$ except 4).

**This is achievable:** $25 = 5 + 5 + 5 + 5 + 5$, i.e., five disjoint 5-cycles,
giving $|E(H)| = 25$.

## Setting Up the Complement

I work with the complement graph $\bar{G}$. A 4-set $S$ is **disconnected** in $
G$ iff there exists a partition $S = A \cup B$ (both nonempty) with no $G$-edges
 between $A$ and $B$ — equivalently, all cross-edges are present in $\bar{G}$.

## Deriving Necessary Conditions

**Case $|A|=1, |B|=3$ (or $|A|=3,|B|=1$):** A vertex $v$ plus 3 vertices all adj
acent to $v$ in $\bar{G}$. This requires $\deg_{\bar{G}}(v) \geq 3$. To prevent
this: **every vertex has $\bar{G}$-degree $\leq 2$**, i.e., $\Delta(\bar{G}) \le
q 2$.

**Case $|A|=2, |B|=2$:** Two pairs with all 4 cross-edges in $\bar{G}$ — this is
 a $K_{2,2}$ (= $C_4$) subgraph in $\bar{G}$. To prevent this: **$\bar{G}$ conta
ins no $K_{2,2}$**.

## Characterizing $\bar{G}$

With $\Delta(\bar{G}) \leq 2$, the graph $\bar{G}$ is a disjoint union of paths
and cycles. I check when such a graph contains $K_{2,2} = C_4$:
- **Paths** are $C_4$-free (acyclic). ✓
- **$C_3$** has only 3 vertices — cannot contain $C_4$. ✓
- **$C_n$ for $n \geq 5$**: any 4-edge subgraph is a path (removing one edge fro
m a cycle), not $C_4$. ✓
- **$C_4$ itself**: this IS $K_{2,2}$. ✗

So $\bar{G}$ must be a disjoint union of paths and cycles with **no $C_4$ compon
ent**.

## Sufficiency Check

If $\bar{G}$ satisfies $\Delta \leq 2$ and has no $C_4$ component, then:
- No vertex has 3 $\bar{G}$-neighbors → Case $|A|=1$ impossible. ✓
- No $K_{2,2}$ subgraph → Case $|A|=2$ impossible. ✓

So every 4-set is connected in $G$. The conditions are both necessary and suffic
ient.

## Maximizing Edges in $\bar{G}$

To minimize edges in $G$, I maximize edges in $\bar{G}$. With $\Delta \leq 2$ on
 25 vertices, the maximum is $\lfloor 25 \times 2 / 2 \rfloor = 25$ edges, achie
ved when $\bar{G}$ is **2-regular** (a union of cycles covering all vertices).

I need to partition 25 into cycle lengths $\geq 3$, each $\neq 4$:
$$25 = 5 \times 3 + 2 \times 5$$
That is, **5 triangles and 2 pentagons**, giving $5 \times 3 + 2 \times 5 = 25$
edges in $\bar{G}$.

This is valid: all components are $C_3$ or $C_5$, no $C_4$, every vertex has deg
ree 2.

## Computing the Answer

$$|E(G)| = \binom{25}{2} - |E(\bar{G})| = \frac{25 \times 24}{2} - 25 = 300 - 25
 = \boxed{275}$$

## Verification

- Every vertex has $G$-degree $22 \geq 22$, so no vertex can be isolated in any
4-set. ✓
- $\bar{G}$ has no $K_{2,2}$, so no 4-set splits as $2+2$ with no cross-edges. ✓
- Therefore every 4-vertex induced subgraph of $G$ is connected. ✓

**Optimality:** Any valid $G$ requires $\Delta(\bar{G}) \leq 2$ (else a degree-3
