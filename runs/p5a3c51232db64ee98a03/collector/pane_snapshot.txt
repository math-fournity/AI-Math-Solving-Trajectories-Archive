## Solution

**Setup.** We count ordered triples $(a_1, a_2, a_3)$ with each $a_i \in \{0,1,\
dots,n\}$ satisfying $|a_1-a_2|=|a_2-a_3|$. Let $d = |a_1-a_2|=|a_2-a_3|$.

**Case $d=0$:** $a_1=a_2=a_3$, giving $n+1$ triples.

**Case $d\geq 1$:** For fixed $d$ and $a_2=m$, each of $a_1, a_3$ is independent
ly $m-d$ (valid if $m\geq d$) or $m+d$ (valid if $m\leq n-d$). Let $c(m) = \math
bf{1}[m\geq d] + \mathbf{1}[m\leq n-d]$ be the number of valid choices for each
of $a_1, a_3$. The contribution for this $d$ is $S(d) = \sum_{m=0}^{n} c(m)^2$.

Three subcases:

- **$2d \leq n$:** $c(m)=2$ for $m\in[d, n-d]$ (count $n-2d+1$), $c(m)=1$ for $m
\in[0,d-1]\cup[n-d+1,n]$ (count $2d$). So $S(d)=4(n-2d+1)+2d = 4n-6d+4$.
- **$2d = n+1$:** $c(m)=1$ for all $m$ (the middle range is empty). $S(d)=n+1$.
- **$2d > n+1$:** $c(m)=1$ for $m\in[0,n-d]\cup[d,n]$ (count $2(n-d+1)$), $c(m)=
0$ in between. $S(d)=2(n-d+1)$.

**Computing $f(10)$:**

- $d=0$: $11$.
- $d=1,\dots,5$ (since $2d\leq 10$): $S(d)=44-6d$, giving $38+32+26+20+14 = 130$
.
- No case-2 value ($n$ even).
- $d=6,\dots,10$ (since $2d>11$): $S(d)=22-2d$, giving $10+8+6+4+2=30$.

$$f(10) = 11 + 130 + 30 = 171.$$

**Computing $f(11)$:**

- $d=0$: $12$.
- $d=1,\dots,5$ (since $2d\leq 11$): $S(d)=48-6d$, giving $42+36+30+24+18 = 150$
.
- $d=6$ (since $2d=12=n+1$): $S(6)=12$.
- $d=7,\dots,11$ (since $2d>12$): $S(d)=24-2d$, giving $10+8+6+4+2=30$.

$$f(11) = 12 + 150 + 12 + 30 = 204.$$

**Verification.** For $n=1$: $f(1) = 2 + 2 = 4$, matching direct enumeration $(0
,0,0),(0,1,0),(1,0,1),(1,1,1)$. For $n=2$: $f(2)=3+6+2=11$, matching enumeration
 ($d=0$: 3; $d=1$: 6; $d=2$: 2). The formula is confirmed.

**Final answer:**

$$f(10) + f(11) = 171 + 204 = \boxed{375}.$$
