结论：该极限不一定成立。 下面给出反例。

反例构造

取底层概率空间 $\Omega = {0, 1}$，$P(0) = P(1) = \tfrac{1}{2}$（公平硬币）。则
$P_n = \times_{i=1}^n P$ 为 ${0,1}^n$ 上的均匀测度，$P_\infty = \times_{i=1}
^\infty P$ 为无穷乘积测度。

定义事件（柱集，依赖前 $n$ 个坐标）：

$$E_n = \bigl{(x_1,\dots,x_n) \in {0,1}^n : \text{并非全部 } x_i = 0\bigr},$$

$$S_n = E_n^c = \bigl{(x_1,\dots,x_n) \in {0,1}^n : x_1 = \cdots = x_n =
0\bigr}.$$

验证条件 $P_\infty(\liminf E_n) = 1$

计算 $\bigcap_{n \geq N} E_n$：一个序列属于此交集，当且仅当对一切 $n \geq N$，前
$n$ 个坐标不全为 0。

  • 若前 $N{-}1$ 个坐标中至少有一个为 1，则对一切 $n \geq N$，前 $n$ 个坐标自然
  含有该 1，故属于交集。
  • 若前 $N{-}1$ 个坐标全为 0，则 $E_N$ 要求 $x_N = 1$；一旦 $x_N=1$，对一切 $n
  > N$ 也自动满足。

因此

$$\bigcap_{n \geq N} E_n = \bigl{\text{前 } N \text{ 个坐标中至少有一个为 }
1\bigr}.$$

于是

$$\liminf_{n\to\infty} E_n = \bigcup_{N=1}^{\infty} \bigcap_{n\geq N} E_n =
\bigcup_{N=1}^{\infty} \bigl{\text{前 } N \text{ 个坐标中至少有一个 } 1\bigr} =
\bigl{\text{序列中至少有一个 } 1\bigr}.$$

其补集为"全零序列"这一单点，$P_\infty$-测度为 $0$。故

$$P_\infty!\left(\liminf_{n\to\infty} E_n\right) = 1 - 0 = 1. \quad\checkmark$$

验证极限不成立

对每个 $n$，

$$P_n(S_n) = P_n(x_1 = \cdots = x_n = 0) = 2^{-n} > 0,$$

而 $E_n \cap S_n = E_n \cap E_n^c = \varnothing$，故

$$\frac{P_n(E_n \cap S_n)}{P_n(S_n)} = \frac{0}{2^{-n}} = 0 \quad \text{对一切 }
n.$$

因此

$$\lim_{n\to\infty} \frac{P_n(E_n \cap S_n)}{P_n(S_n)} = 0 \neq 1.$$

结论

存在满足 $P_\infty(\liminf E_n) = 1$ 的事件列 $E_n$ 以及事件列 $S_n$（且
$P_n(S_n) > 0$），使得

$$\lim_{n\to\infty} \frac{P_n(E_n \cap S_n)}{P_n(S_n)} = 0 \neq 1.$$

因此，对任意事件列 $S_n$，该极限不一定成立。 条件 $P_\infty(\liminf E_n)=1$ 虽然
保证了 $P_n(E_n)\to 1$（甚至 a.s. 最终发生），但无法控制 $E_n$ 在任意条件集
$S_n$ 上的条件概率——$S_n$ 可以专门选取为 $E_n$ 的"逃逸集"（本例中 $S_n =
E_n^c$），使条件概率趋于 0。
