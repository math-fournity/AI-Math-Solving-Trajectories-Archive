## 证明

**设置。** 我们有 100 个板条箱，编号为 1（顶部）到 100（底部），排列在队列中。每
一步：取出前 2 个，随机（概率为 1/2）销毁一个，幸存者进入队列尾部。重复此过程直
到剩下 1 个。

**关键观察：锦标赛结构。** 追踪队列：在第 1 轮中，处理 (1,2)，幸存者进入尾部。第
 2 轮处理 (3,4)，依此类推。在第一阶段的前 ⌊n/2⌋ 轮中，从队列前部配对相邻的板条箱
 (1,2), (3,4), (5,6), …，每个幸存者进入尾部。如果 n 为奇数，最后一个板条箱获得轮
空（bye）。

在第一阶段后：
- **n 为偶数 (n=2m)：** 队列变为 [s₁, s₂, …, sₘ]，其中 sᵢ 是配对 (2i−1, 2i) 的幸
存者。
- **n 为奇数 (n=2m+1)：** 队列变为 [n, s₁, s₂, …, sₘ]，其中板条箱 n 获得轮空并排
在前面。

这是一个具有特定括号结构的单败淘汰锦标赛。由于每场比赛都是 50-50 的概率，板条箱
i 获胜的概率为 (1/2)^{dᵢ}，其中 dᵢ 是板条箱 i 必须赢得的比赛数量。

**递归深度计算。** 定义 f(n, i) = 在大小为 n 的锦标赛中位置 i 的深度（比赛数量）
。

- f(1, 1) = 0。
- **n 为偶数 (n=2m)：** f(n, 2k−1) = f(n, 2k) = 1 + f(m, k)，对于 k = 1, …, m。
- **n 为奇数 (n=2m+1)：** f(n, 2m+1) = f(m+1, 1) [轮空]；f(n, 2k−1) = f(n, 2k) =
 1 + f(m+1, k+1)，对于 k = 1, …, m。

**自底向上计算 n = 100：**

| n | 深度分布 |
|---|---|
| 1 | f(1,1)=0 |
| 2 | f(2,1)=f(2,2)=1 |
| 4 | 全部 = 2 |
| 7 | 位置 1–6: d=3; 位置 7: d=2 |
| 13 | 位置 1–10: d=4; 位置 11–13: d=3 |
| 25 | 位置 1–18: d=5; 位置 19–25: d=4 |
| 50 | 位置 1–36: d=6; 位置 37–50: d=5 |
| **100** | **位置 1–72: d=7; 位置 73–100: d=6** |

**验证：** 72·(1/128) + 28·(1/64) = 72/128 + 56/128 = 128/128 = 1。✓

**期望值：**

$$E = \frac{1}{128}\sum_{i=1}^{72} i + \frac{1}{64}\sum_{i=73}^{100} i$$

$$\sum_{i=1}^{72} i = \frac{72 \cdot 73}{2} = 2628, \qquad \sum_{i=73}^{100} i =
 5050 - 2628 = 2422$$

$$E = \frac{2628}{128} + \frac{2422}{64} = \frac{2628}{128} + \frac{4844}{128} =
 \frac{7472}{128} = \frac{467}{8}$$

**可约性检查：** 467 是质数（不可被任何 ≤ ⌊√467⌋ = 21 的质数整除），gcd(467, 8)
= 1。因此 467/8 是最简分数。

$$a + b = 467 + 8 = \boxed{475}$$
