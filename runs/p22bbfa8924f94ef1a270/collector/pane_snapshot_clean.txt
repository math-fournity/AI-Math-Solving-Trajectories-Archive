## Proof

**Yes, A = B necessarily.**

Let $C = B - A$. Since $A$ and $B$ are Hermitian, $C$ is Hermitian. The hypothes
is states:

$$v^*Av = 1 \implies v^*Bv = 1,$$

which, since $v^*Bv = v^*Av + v^*Cv$, is equivalent to:

$$v^*Av = 1 \implies v^*Cv = 0. \tag{$\star$}$$

**Key step: extending from the level set to an open cone.**

By hypothesis, there exists a vector $v_0$ with $v_0^* A v_0 = 1 > 0$, so $A$ ha
s at least one positive eigenvalue. Consider any vector $w \in \mathbb{C}^n$ wit
h $w^*Aw > 0$. Define:

$$v = \frac{w}{\sqrt{w^*Aw}}.$$

Then $v^*Av = \frac{w^*Aw}{w^*Aw} = 1$, so by $(\star)$, $v^*Cv = 0$. But:

$$v^*Cv = \frac{w^*Cw}{w^*Aw} = 0,$$

and since $w^*Aw > 0$, we conclude $w^*Cw = 0$.

**The set $\{w : w^*Aw > 0\}$ is open and nonempty.** It is nonempty because it
contains $v_0$. It is open because $w \mapsto w^*Aw$ is a continuous function (a
 quadratic form) and this set is the preimage of the open interval $(0, \infty)$
.

**Vanishing on an open set forces $C = 0$.** Identify $\mathbb{C}^n \cong \mathb
b{R}^{2n}$ via $w = (x_1 + iy_1, \dots, x_n + iy_n)$. Since $C$ is Hermitian, $w
^*Cw$ is a real-valued homogeneous polynomial of degree 2 in the $2n$ real varia
bles $(x_1, y_1, \dots, x_n, y_n)$. This polynomial vanishes on the nonempty ope
n subset $\{w : w^*Aw > 0\}$ of $\mathbb{R}^{2n}$. A polynomial that vanishes on
 an open set is identically zero (by analyticity/continuity of all partial deriv
atives). Therefore $w^*Cw = 0$ for all $w \in \mathbb{C}^n$.

A Hermitian matrix whose associated quadratic form vanishes identically is the z
ero matrix: indeed, $e_i^* C e_i = C_{ii} = 0$ for each standard basis vector, a
nd $(e_i + e_j)^* C (e_i + e_j) = C_{ii} + C_{jj} + 2\operatorname{Re}(C_{ij}) =
 2\operatorname{Re}(C_{ij}) = 0$, while $(e_i + ie_j)^* C (e_i + ie_j) = C_{ii}
+ C_{jj} - 2\operatorname{Im}(C_{ij}) = -2\operatorname{Im}(C_{ij}) = 0$, giving
 $C_{ij} = 0$ for all $i, j$.

Thus $C = 0$, i.e., $\boxed{A = B}$. $\blacksquare$
