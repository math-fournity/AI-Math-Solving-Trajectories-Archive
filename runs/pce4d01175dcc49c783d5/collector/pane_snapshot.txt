Define the $1000 \times 1000$ matrix $B$ where $B_{ij}$ counts how many times th

{k=1}^m a_{i_k}a_{j_k} = \mathbf{a}^T B \mathbf{a}$. Since $\mathbf{a}^T B \math
bf{a} = \mathbf{a}^T \frac{B+B^T}{2} \mathbf{a}$, set $C = \frac{B+B^T}{2}$ (sym
metric, non-negative, half-integer entries, $\sum_{i,j} C_{ij} = m$). We need $\
max_{\mathbf{a} \in \Delta} \mathbf{a}^T C \mathbf{a} \leq L$ where $L = \frac{1
}{2.014}$ and $\Delta = \{\mathbf{a} \geq 0 : \sum a_i = 1\}$.

**Step 2: Structural constraints force a simple graph.**

- **Diagonal entries:** At vertex $\mathbf{e}_i$, $\mathbf{a}^T C \mathbf{a} = C
_{ii} \leq L < \frac{1}{2}$. Since $C_{ii} = B_{ii}$ is a non-negative integer,
$C_{ii} = 0$. No pair $(i,i)$ is used.

- **Off-diagonal entries:** At the midpoint $a_i = a_j = \frac{1}{2}$, the contr
ibution from entries $(i,j)$ and $(j,i)$ is $\frac{C_{ij}+C_{ji}}{4} \cdot 2 = \
frac{C_{ij}}{2}$ (using symmetry). So $C_{ij} \leq 2L = \frac{2}{2.014} \approx
0.9931 < 1$. Since $C_{ij}$ is a non-negative half-integer, $C_{ij} \leq \frac{1
}{2}$.

Thus $C_{ij} \in \{0, \frac{1}{2}\}$ for $i \neq j$ and $C_{ii} = 0$. This means
 each unordered pair $\{i,j\}$ is used **at most once** (as either $(i,j)$ or $(
j,i)$). The structure is exactly a **simple graph** $G$ on $\{1,\ldots,1000\}$ w
here $\{i,j\} \in E(G)$ iff the pair is used, and:
$$\mathbf{a}^T C \mathbf{a} = \sum_{\{i,j\} \in E(G)} a_i a_j, \qquad m = |E(G)|
.$$

**Step 3: Apply the Motzkin–Straus theorem.**

The Motzkin–Straus theorem (1965) states that for a graph $G$ with clique number
 $\omega$:
$$\max_{\mathbf{a} \in \Delta} \sum_{\{i,j\} \in E(G)} a_i a_j = \frac{\omega -
1}{2\omega}.$$

So the constraint becomes $\frac{\omega - 1}{2\omega} \leq \frac{1}{2.014}$.

Solving $\frac{\omega-1}{2\omega} \leq \frac{1}{2.014}$:

$$(\omega - 1) \cdot 2.014 \leq 2\omega \implies 0.014\,\omega \leq 2.014 \impli
es \omega \leq \frac{2.014}{0.014} = \frac{2014}{14} = 143.857\ldots$$

So $\omega \leq 143$.

Compute part sizes: $1000 = 143 \times 6 + 142$, so **142 parts of size 7** and
**1 part of size 6** (check: $142 \times 7 + 6 = 1000$ ✓).

The number of edges is:
$$|E(T(1000,143))| = \binom{1000}{2} - 142\binom{7}{2} - \binom{6}{2} = 499500 -
