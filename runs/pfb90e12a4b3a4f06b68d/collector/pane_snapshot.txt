## 解答

**设置。** 设 $s$ 为 Sam 的数字，$j$ 为 Joe 的数字，两者均从 $\mathbb{N}$ 上的 $
\mu$ 中独立抽取。抛硬币与 $(s,j)$ 无关。硬币正面朝上意味着 Sam 的数字被揭示；我
们观察到 $s = s_0$，其中 $s_0$ 为某个特定的非负整数。Joe 的数字 $j$ 仍然未知，且
根据独立性，其分布仍为 $\mu$。

**给定 $s = s_0$ 时的获胜概率。**

- **Sam 获胜** 当 $j < s_0$ 时：
$$P(\text{Sam wins} \mid s=s_0) = \mu(\{0,1,\ldots,s_0-1\}).$$
该集合是有限的（当 $s_0=0$ 时为空），因此根据假设 $\mu = 0$。

- **平局** 当 $j = s_0$ 时：
$$P(\text{tie} \mid s=s_0) = \mu(\{s_0\}) = 0,$$
因为单例集是有限的。

- **Joe 获胜** 当 $j > s_0$ 时：
$$P(\text{Joe wins} \mid s=s_0) = \mu(\{s_0+1, s_0+2, \ldots\}).$$
注意 $\{s_0+1, s_0+2, \ldots\} = \mathbb{N} \setminus \{0,1,\ldots,s_0\}$，且 $\
{0,1,\ldots,s_0\}$ 是有限的，因此 $\mu(\{0,\ldots,s_0\})=0$。根据**有限可加性**
：
$$\mu(\mathbb{N}) = \mu(\{0,\ldots,s_0\}) + \mu(\{s_0+1, s_0+2, \ldots\}),$$
$$1 = 0 + \mu(\{s_0+1, \ldots\}),$$
$$\mu(\{s_0+1, \ldots\}) = 1.$$

**结论。** 对于 Sam 揭示的数字 $s_0$ 的*每一个*可能值：
$$P(\text{Joe wins} \mid s=s_0) = 1, \qquad P(\text{Sam wins} \mid s=s_0) = 0.$$

因此，**Joe 更有可能获胜**——事实上，Joe 以概率 1 获胜。

**关于悖论的说明。** 根据对称性，如果 Joe 的数字被揭示，相同的论证将得出 Sam 以
概率 1 获胜的结论。这种表面上的矛盾是 $\mu$ 仅为*有限*可加（而非可数可加）这一事
实的直接结果：在 $\mathbb{N}$ 上不存在满足 $\mu(\text{finite})=0$ 的可数可加概率
测度，因为可数可加性将迫使 $\mu(\mathbb{N}) = \sum_{n} \mu(\{n\}) = 0 \neq 1$。
有限可加性允许 $\mu$ 存在，但产生了这种非直观行为——揭示任何一个玩家的数字都会使
另一个玩家确定获胜。
