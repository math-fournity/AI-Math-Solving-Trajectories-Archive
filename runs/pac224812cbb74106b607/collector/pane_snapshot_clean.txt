## Proof

**Claim.** The cardinality of the set of all real-valued functions (i.e., functi
ons $f:\mathbb{R}\to\mathbb{R}$) is $2^{\mathfrak{c}}$, where $\mathfrak{c}=|\ma
thbb{R}|=2^{\aleph_{0}}$.

---

Let $\mathcal{F}=\{f:\mathbb{R}\to\mathbb{R}\}$ denote the set of all real-value
d functions on $\mathbb{R}$. We compute $|\mathcal{F}|$.

**Upper bound.** A function $f:\mathbb{R}\to\mathbb{R}$ is determined by its val
ues on each point of $\mathbb{R}$. Equivalently, $\mathcal{F}$ is in bijection w
ith the set of all functions from a set of size $\mathfrak{c}$ to a set of size
$\mathfrak{c}$, so

$$|\mathcal{F}|=\mathfrak{c}^{\mathfrak{c}}.$$

Using $\mathfrak{c}=2^{\aleph_{0}}$ and the standard law of exponents for cardin
al arithmetic,

$$\mathfrak{c}^{\mathfrak{c}}=\left(2^{\aleph_{0}}\right)^{\mathfrak{c}}=2^{\ale
ph_{0}\cdot\mathfrak{c}}.$$

Since $\aleph_{0}\leq\mathfrak{c}$ and $\mathfrak{c}$ is infinite, $\aleph_{0}\c
dot\mathfrak{c}=\mathfrak{c}$. Therefore

$$|\mathcal{F}|=2^{\mathfrak{c}}.$$

**Lower bound (sanity check).** To confirm this is not an overcount, note that $
\mathcal{F}$ contains the set of all functions $\{0,1\}^{\mathbb{R}}$ (those tak
ing only the values $0$ and $1$), which has cardinality $2^{\mathfrak{c}}$. Henc
e $|\mathcal{F}|\geq 2^{\mathfrak{c}}$. Combined with the upper bound $|\mathcal
{F}|\leq\mathfrak{c}^{\mathfrak{c}}=2^{\mathfrak{c}}$, we obtain equality by Can
tor–Bernstein.

---

**Conclusion.** The cardinality of the set of all real-valued functions on $\mat
hbb{R}$ is exactly $2^{\mathfrak{c}}$. $\blacksquare$
