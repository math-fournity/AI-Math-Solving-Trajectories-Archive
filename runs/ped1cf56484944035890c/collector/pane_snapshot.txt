## Proof

**Interpretation of the condition.** Since $i$ is an immersion, $i'(x) \neq 0$ f
or all $x$, so $i$ is locally an embedding and the image $i(\mathbb{R})$ carries
 a natural 1-dimensional measure (the pushforward of Lebesgue measure on $\mathb
b{R}$, or equivalently the 1-dimensional Hausdorff measure on the immersed curve
). A subset $A \subseteq i(\mathbb{R})$ is null in $i(\mathbb{R})$ if and only i
f $i^{-1}(A)$ has Lebesgue measure zero in $\mathbb{R}$. Thus the condition "$i(
\mathbb{R}) \cap S$ is null in $i(\mathbb{R})$" is equivalent to:

$$\lambda_1\!\bigl(\{x \in \mathbb{R} : i(x) \in S\}\bigr) = 0.$$

**The answer is yes for every $n \geq 1$.**

**Construction via a straight line.** Fix the direction $v = e_n = (0,\dots,0,1)
$. Every point of $\mathbb{R}^n$ decomposes uniquely as $(a, t)$ with $a \in \ma
thbb{R}^{n-1}$ and $t \in \mathbb{R}$. For each $a \in \mathbb{R}^{n-1}$, define
 the "vertical fiber"

$$S_a := \{t \in \mathbb{R} : (a, t) \in S\} \subseteq \mathbb{R}.$$

**Applying Fubini's theorem.** Since $S$ is Lebesgue measurable with $\lambda_n(
S) = 0$, Fubini's theorem gives

$$0 = \lambda_n(S) = \int_{\mathbb{R}^{n-1}} \lambda_1(S_a)\, da.$$

The integrand $a \mapsto \lambda_1(S_a)$ is non-negative and measurable. A non-n
egative measurable function with zero integral vanishes almost everywhere. There
fore

$$\lambda_1(S_a) = 0 \quad \text{for almost every } a \in \mathbb{R}^{n-1}.$$

**Choosing the immersion.** Pick any $a_0 \in \mathbb{R}^{n-1}$ with $\lambda_1(
S_{a_0}) = 0$ (such an $a_0$ exists since the good set has full measure). Define

$$i: \mathbb{R} \to \mathbb{R}^n, \qquad i(t) = (a_0, t).$$

This is a smooth map with $i'(t) = e_n \neq 0$ for every $t$, so $i$ is an immer
sion. The preimage of $S$ is

$$i^{-1}(S) = \{t \in \mathbb{R} : (a_0, t) \in S\} = S_{a_0},$$

which has $\lambda_1(S_{a_0}) = 0$ by construction. Hence $i(\mathbb{R}) \cap S$
 is a null set in $i(\mathbb{R})$.

**The case $n = 1$.** Here $\mathbb{R}^{n-1} = \mathbb{R}^0 = \{0\}$, the unique
 fiber is $S_0 = S$ itself, which is null by hypothesis, and $i(t) = t$ (the ide
ntity) is an immersion with $i^{-1}(S) = S$ null. The argument above specializes
 correctly.

**Conclusion.** For every null set $S \subset \mathbb{R}^n$ and every $n \geq 1$
, there exists an immersion $i: \mathbb{R} \hookrightarrow \mathbb{R}^n$ (in fac
t, a straight line) such that $i(\mathbb{R}) \cap S$ is null in $i(\mathbb{R})$.
 The key tool is Fubini's theorem, which guarantees that almost every line in an
y fixed direction intersects a null set in a null set of parameters. $\blacksqua
re$
