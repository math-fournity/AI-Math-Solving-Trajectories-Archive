**Key Lemma.** For any $n \geq 2$ and $B \geq 1$, the image $F_n(\{1, \ldots, B\
})$ is an initial segment $\{1, \ldots, M'\}$.

*Proof.* Write $B = Qn + R$, $0 \leq R < n$. For $a = qn + r$ with $0 \leq r < n
$, $F_n(a) = q + r$. Over the complete block $a \in \{qn, \ldots, (q+1)n-1\}$, t
he values are $\{q, q+1, \ldots, q+n-1\}$. Consecutive blocks overlap (block $q$

0,\ldots,Q-1$ is $\{1, \ldots, Q+n-2\}$ (block 0 contributes $\{1,\ldots,n-1\}$
since $a \geq 1$). The partial block $q=Q$ contributes $\{Q, \ldots, Q+R\}$. If
$R \leq n-2$, this is absorbed; if $R = n-1$, it extends the image to $Q+n-1$. $
\square$

**Recurrence.** Define $f(0) = 1$ and let $f(k)$ be the largest $B$ such that so

$$f(k) = \max_{n \geq 2} \max\{B : F_n(\{1,\ldots,B\}) \subseteq \{1,\ldots,f(k-
1)\}\}.$$

**Computing the optimal $B$.** Set $M = f(k-1)$. We need $M' \leq M$.

- **Case $R = n-1$:** $M' = Q+n-1 \leq M$ gives $Q \leq M-n+1$, so $B \leq n(M-n
+1)+(n-1) = nM - n^2 + 2n - 1$.
- **Case $R \leq n-2$:** $M' = Q+n-2 \leq M$ gives $Q \leq M-n+2$, so $B \leq n(
M-n+2)+(n-2) = nM - n^2 + 3n - 2$.

For $n \geq 2$, Case 2 exceeds Case 1 by $n-1 > 0$, so the optimum is:

$$B^*(n) = -n^2 + (M+3)n - 2, \quad \text{with } n \leq M+2.$$

This concave quadratic is maximized at $n^* = (M+3)/2$.

- **$M$ even:** $n^* = (M+2)/2$ or $(M+4)/2$, giving $f(k) = \frac{M(M+6)}{4}$.
- **$M$ odd:** $n^* = (M+3)/2$, giving $f(k) = \frac{M^2+6M+1}{4}$.
