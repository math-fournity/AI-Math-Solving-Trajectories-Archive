# Problem

A high-tech automated warehouse uses a linear array of $m$ charging docks to manage its drone fleet. Two logistics protocols, Protocol A and Protocol B, operate the system in alternating cycles, starting with Protocol A.

In every cycle, Protocol A selects exactly two docks and delivers one high-capacity battery cell to each. Immediately following this, Protocol B selects exactly one dock and evacuates all battery cells currently stored in it to clear space.

Protocol A is considered successful if, at any point immediately after Protocol B completes its evacuation, there is at least one dock containing $n$ battery cells. For any given capacity $n \geq 2$, let $M(n)$ represent the minimum number of docks $m$ required for Protocol A to have a guaranteed winning strategy, regardless of which docks Protocol B chooses to evacuate.

Calculate the value of the sum: $M(2) + M(3) + M(4) + M(5) + M(6)$.
