# Solution

**Yes.** Every normed space — finite- or infinite-dimensional — is metrizable. T
he dimension plays no role.

## Proof

Let $(X, \|\cdot\|)$ be a normed space (the argument is independent of dimension
, so it applies in particular when $X$ is infinite-dimensional). Define

$$d : X \times X \to \mathbb{R}, \qquad d(x, y) = \|x - y\|.$$

We verify that $d$ is a metric on $X$.

**Non-negativity and identity of indiscernibles.** Since $\|\cdot\|$ is a norm,
$\|x - y\| \geq 0$ for all $x, y$, and $\|x - y\| = 0 \iff x - y = 0 \iff x = y$
.

**Symmetry.** Using absolute homogeneity of the norm with $\alpha = -1$ (so $|\a
lpha| = 1$):

$$d(x, y) = \|x - y\| = \|(-1)(y - x)\| = |{-1}|\,\|y - x\| = \|y - x\| = d(y, x
).$$

**Triangle inequality.** Using the triangle inequality for the norm:

$$d(x, z) = \|x - z\| = \|(x - y) + (y - z)\| \leq \|x - y\| + \|y - z\| = d(x,
y) + d(y, z).$$

Thus $d$ is a genuine metric on $X$. Moreover, the topology induced by $d$ is ex
actly the norm topology: the open balls $B_d(x, r) = \{y : d(x,y) < r\} = \{y :
\|y - x\| < r\}$ are precisely the norm-open balls, which form a base for the no
rm topology.

Therefore $(X, \|\cdot\|)$, equipped with its norm topology, is metrizable — wit
h the explicit metric $d(x,y) = \|x - y\|$.

**Remark on the role of dimension.** The construction above uses only the three
norm axioms (positive definiteness, absolute homogeneity, the triangle inequalit
y) and never refers to a Hamel basis, dimension, separability, or completeness.
Consequently the conclusion holds for *every* normed space, and the hypothesis "
infinite-dimensional" is immaterial: an infinite-dimensional normed space is met
rizable for exactly the same reason a finite-dimensional one is.

(The question one might have *expected* — whether the **weak topology** on an in
finite-dimensional normed space is metrizable — has a different answer: the weak
 topology on $X$ is metrizable if and only if $X^*$ is separable, which fails fo
r many infinite-dimensional spaces. But the question as asked concerns the norm
topology, which is always metrizable.)
