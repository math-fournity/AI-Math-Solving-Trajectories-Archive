Looking at this problem, I need to find all n in [3,20] such that every permutat
ion of birds preserves at least one triple's triangle type (acute/obtuse/right).

## Setup

Label vertices 0,…,n−1 on a regular n-gon. A triple's type depends on its arc le
ngths (a,b,c) with a+b+c=n:
- **Right**: some arc = n/2 (requires n even; triple contains an antipodal pair)
- **Obtuse**: some arc > n/2
- **Acute**: all arcs < n/2

A permutation σ fails the condition iff **every** triple changes type under σ.

## Counting Triples by Type

**Odd n** (no right triangles): Using the formula for obtuse triples (one arc d
> n/2, third vertex in the complementary short arc):

|obtuse| = n·Σ_{d=(n+1)/2}^{n−2} (n−d−1) = **n(n−1)(n−3)/8**

|acute| = C(n,3) − |obtuse| = **n(n−1)(n+1)/24**

These are equal iff n+1 = 3(n−3) iff **n = 5**.

**Even n**: |right| = n(n−2)/2, |obtuse| = n(n−4)(n−2)/8, |acute| = n(n−2)(n−4)/
24, in ratio **1 : 3 : 12** (for n ≥ 6).

## Odd Case: Only Two Types

With only acute/obtuse, a type-changing permutation must swap them entirely, req
uiring |acute| = |obtuse|. This holds **only for n=5**.

**n=5 fails**: The permutation σ(i) = 2i mod 5 maps every obtuse triple (3 conse
cutive vertices) to an acute triple:
- {0,1,2}→{0,2,4}, {1,2,3}→{2,4,1}, {2,3,4}→{4,1,3}, {3,4,0}→{1,3,0}, {4,0,1}→{3
,0,2} — all acute ✓

Since σ is a bijection, all acute triples map to obtuse too. So **5 ∉ S**.

For all other odd n ≥ 3: |acute| ≠ |obtuse|, so no swapping permutation exists.
**All odd n ≠ 5 are in S.**

## Even Case: Right Triangles Are Unavoidable

**Key argument**: For even n, antipodal pairs {i, i+n/2} exist. Suppose σ maps e
very right triple to a non-right triple. Fix any antipodal pair {a, a'}. For eve
ry c ∉ {a,a'}, the triple {σ(a),σ(a'),σ(c)} must not be right, so:
1. {σ(a),σ(a')} is **not** antipodal, and
2. For all such c: σ(c) is not antipodal to σ(a) and not antipodal to σ(a').

Let p be the antipodal partner of σ(a). Since σ is a bijection, σ(c) ranges over
 all vertices except σ(a), σ(a'). If p ∉ {σ(a),σ(a')}, then some c has σ(c)=p, m
aking {σ(a),σ(c)} antipodal — a right triple. To avoid this, we need p = σ(a'),
meaning {σ(a),σ(a')} **is** antipodal, contradicting condition 1.

**This contradiction shows no permutation can avoid preserving some right triple
's type.** So **all even n ≥ 4 are in S**. (n=4 is trivial: all 4 triples are ri
ght.)
