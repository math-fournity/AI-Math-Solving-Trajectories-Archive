## Solution

**Claim.** The function $f(x) = \sin(x^2)$ is continuous and bounded, yet $P_t f
(x) - f(x)$ does **not** converge to $0$ uniformly as $t \to 0^+$, where $P_t$ d
enotes the heat semigroup.

---

### Setup and reformulation

The given expression is the heat semigroup applied to $f$ minus $f$ itself:

$$P_t f(x) - f(x) = \int_{-\infty}^{+\infty} \frac{1}{\sqrt{2\pi t}} e^{-(y-x)^2
/(2t)} f(y)\,dy - f(x),$$

and the right-hand side is obtained by the substitution $y \mapsto x + \sqrt{t}\
,y$:

$$P_t f(x) - f(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{+\infty} e^{-y^2/2}\bi
gl(f(x+\sqrt{t}\,y) - f(x)\bigr)\,dy.$$

We must find a continuous bounded $f$ for which $\|P_t f - f\|_\infty \not\to 0$
.

---

### Key theorem: uniform convergence $\iff$ uniform continuity

**Theorem.** *Let $f:\mathbb{R}\to\mathbb{R}$ be bounded and continuous. Then $\
|P_t f - f\|_\infty \to 0$ as $t\to 0^+$ if and only if $f$ is uniformly continu
ous.*

**Proof of "$\Longleftarrow$" (uniformly continuous $\Rightarrow$ uniform conver
gence).** Let $\varepsilon > 0$. By uniform continuity, there exists $\delta > 0
$ such that $|u - v| < \delta \Rightarrow |f(u)-f(v)| < \varepsilon/2$. Since $f
$ is bounded, set $M = \|f\|_\infty$. Choose $R > 0$ so large that

$$\frac{1}{\sqrt{2\pi}}\int_{|y|>R} e^{-y^2/2}\,dy < \frac{\varepsilon}{4M}.$$

Now choose $t_0 > 0$ so that $\sqrt{t_0}\, R < \delta$. For all $0 < t < t_0$ an
d all $x \in \mathbb{R}$:

$$|P_t f(x) - f(x)| \leq \frac{1}{\sqrt{2\pi}}\int_{|y|\le R} e^{-y^2/2}\underbr
ace{|f(x+\sqrt{t}\,y)-f(x)|}_{<\,\varepsilon/2}\,dy + \frac{1}{\sqrt{2\pi}}\int_
{|y|>R} e^{-y^2/2}\underbrace{|f(x+\sqrt{t}\,y)-f(x)|}_{\le\, 2M}\,dy$$

$$< \frac{\varepsilon}{2} + 2M \cdot \frac{\varepsilon}{4M} = \varepsilon.$$

This bound is independent of $x$, so $\|P_t f - f\|_\infty < \varepsilon$ for $0
 < t < t_0$. $\checkmark$

**Proof of "$\Longrightarrow$" (uniform convergence $\Rightarrow$ uniform contin
uity).** Suppose $\|P_t f - f\|_\infty \to 0$. We first show that for each fixed
 $t > 0$, the function $P_t f$ is **Lipschitz** (hence uniformly continuous).

Indeed, $P_t f$ is differentiable (differentiation under the integral is justifi
ed since $f$ is bounded and the Gaussian kernel is smooth with integrable deriva
tives), and

$$|(P_t f)'(x)| = \left|\int_{-\infty}^{+\infty} \frac{y-x}{t}\cdot\frac{1}{\sqr
t{2\pi t}}\,e^{-(y-x)^2/(2t)}\,f(y)\,dy\right| \le M \int_{-\infty}^{+\infty} \f
rac{|y-x|}{t}\cdot\frac{1}{\sqrt{2\pi t}}\,e^{-(y-x)^2/(2t)}\,dy.$$

With $Z \sim N(0,t)$, the integral equals $\frac{1}{t}\,E[|Z|] = \frac{1}{t}\sqr
t{t}\sqrt{2/\pi} = \frac{\sqrt{2/\pi}}{\sqrt{t}}$. So

$$|(P_t f)'(x)| \le \frac{M\sqrt{2/\pi}}{\sqrt{t}} =: L_t < \infty,$$

and $P_t f$ is Lipschitz with constant $L_t$.

Now given $\varepsilon > 0$, pick $t_0 > 0$ with $\|P_{t_0}f - f\|_\infty < \var
epsilon/3$. Set $\delta = \varepsilon/(3L_{t_0})$. For $|x - x'| < \delta$:

$$|f(x) - f(x')| \le |f(x) - P_{t_0}f(x)| + |P_{t_0}f(x) - P_{t_0}f(x')| + |P_{t
_0}f(x') - f(x')| < \frac{\varepsilon}{3} + L_{t_0}\delta + \frac{\varepsilon}{3
} = \varepsilon.$$

So $f$ is uniformly continuous. $\checkmark$ $\blacksquare$

---

### The candidate: $f(x) = \sin(x^2)$

**$f$ is continuous and bounded.** Clearly $f$ is continuous and $|f(x)| \le 1$
for all $x$.

**$f$ is not uniformly continuous.** Define

$$x_n = \sqrt{2\pi n}, \qquad x_n' = \sqrt{2\pi n + \tfrac{\pi}{2}}, \qquad n =
1, 2, 3, \dots$$

Then:

$$|x_n - x_n'| = \sqrt{2\pi n} - \sqrt{2\pi n + \tfrac{\pi}{2}} = \frac{-\pi/2}{
\sqrt{2\pi n} + \sqrt{2\pi n + \pi/2}} \xrightarrow{n\to\infty} 0,$$

yet

$$f(x_n) = \sin(2\pi n) = 0, \qquad f(x_n') = \sin\!\left(2\pi n + \tfrac{\pi}{2
}\right) = 1,$$

so $|f(x_n) - f(x_n')| = 1$ for every $n$. This violates the definition of unifo
rm continuity (for $\varepsilon = 1$, no single $\delta$ works). Hence $f$ is **
not** uniformly continuous.

---

### Conclusion

By the Theorem, since $f(x) = \sin(x^2)$ is bounded and continuous but **not** u
niformly continuous, the quantity

$$\|P_t f - f\|_\infty = \sup_{x\in\mathbb{R}} \left|\frac{1}{\sqrt{2\pi}}\int_{
-\infty}^{+\infty} e^{-y^2/2}\bigl(f(x+\sqrt{t}\,y)-f(x)\bigr)\,dy\right|$$

does **not** converge to $0$ as $t \to 0^+$. $\blacksquare$
