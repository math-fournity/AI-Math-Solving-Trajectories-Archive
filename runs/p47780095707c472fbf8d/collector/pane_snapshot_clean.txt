## Proof

**Step 1: Reformulation as transitive closure.**

Since every edge goes from lower to higher index, any directed path only visits
increasing indices. For $A > B$, no path exists in either color, so the Efficien
cy condition only concerns pairs $A < B$.

For each pair $i < j$, the direct edge $i \to j$ is either Red or Blue, providin
g reachability in exactly one color. The condition requires that the *other* col
or provides no path from $i$ to $j$. This means:

- If edge $(i,j)$ is Red, then no Blue path $i \leadsto j$ exists, so Blue-reach
ability does not extend beyond Blue edges.
- If edge $(i,j)$ is Blue, then no Red path $i \leadsto j$ exists.

Equivalently, the transitive closure of the Red edge set equals the Red edge set
 itself (Red is **transitively closed**), and likewise Blue is transitively clos
ed. Indeed, if $(i,j), (j,k) \in R$ but $(i,k) \notin R$, then $(i,k) \in B$, ye
t $(i,j),(j,k) \in R$ gives a Red path $i \to j \to k$, so $k$ is Red-reachable
from $i$ while the direct edge is Blue — violating Efficiency. Conversely, if bo
th are transitively closed, reachability in each color equals the direct edges,
so each pair is reachable in exactly one color.

Thus **Efficient colorings = partitions of $\{(i,j): i<j\}$ into two transitivel
y closed sets $R$ and $B$.**

**Step 2: Bijection with permutations.**

- **Red transitive:** If $(i,j), (j,k) \in R$ with $i < j < k$, then $\sigma(i)

So every permutation yields a valid coloring.
