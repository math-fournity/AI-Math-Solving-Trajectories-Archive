### Step 1: Parity analysis — k must be even

Let $f(n) = n^2 + n + k = n(n+1) + k$. Since $n(n+1)$ is always even, $f(n) \equ
iv k \pmod{2}$.

- **If $k$ is odd:** $f(n)$ is always odd, so $v_2(f(n)) = 0$ for all $n$. For $
a = 1$ we need $v_2(f(n)) = 1$, which is impossible. So no odd $k$ is pretty.

- **If $k$ is even:** $f(n)$ is always even, so $v_2(f(n)) \geq 1$ for all $n$.
We must show every valuation $a \geq 1$ is achieved.

### Step 2: Reduction to a quadratic in m

Write $k = 2j$. Split $n$ into even and odd cases:

- **$n = 2m$:** $f(2m) = 2m(2m+1) + 2j = 2(2m^2 + m + j)$.
- **$n = 2m+1$:** $f(2m+1) = (2m+1)(2m+2) + 2j = 2(2m^2 + 3m + 1 + j)$.

Substituting $m \to -m-1$ in $2m^2 + 3m + 1 + j$ gives $2(-m-1)^2 + 3(-m-1) + 1
+ j = 2m^2 + m + j$, so both cases produce the **same set of values**. Therefore
:

$$\{v_2(f(n)) : n \in \mathbb{Z}\} = \{1 + v_2(g(m)) : m \in \mathbb{Z}\}, \quad
 g(m) = 2m^2 + m + j.$$

So $k = 2j$ is pretty $\iff$ the set $\{v_2(g(m)) : m \in \mathbb{Z}\}$ contains
 all non-negative integers.

### Step 3: All valuations are achieved (inductive argument)

**Claim:** For every integer $j$, the set $\{v_2(2m^2 + m + j) : m \in \mathbb{Z
}\}$ contains all non-negative integers.

We prove this by induction on $b$, showing $v_2 = b$ is achievable for all $b \g
eq 0$. More generally, we track polynomials of the form

$$P_r(s) = 2^r \cdot s^2 + c_r \cdot s + d_r$$

where $r \geq 1$, $c_r$ is **odd**, and $d_r$ is any integer. (The base case is
$r=1$, $c_1 = 1$, $d_1 = j$.)

**Base case ($b = 0$):** Since $c_r$ is odd and $2^r s^2 \equiv 0 \pmod{2}$, we
have $P_r(s) \equiv s + d_r \pmod{2}$. Choose $s \not\equiv d_r \pmod{2}$; then
$P_r(s)$ is odd, giving $v_2 = 0$. ✓

**Inductive step ($b \geq 1$):** We need $P_r(s)$ even, so $s \equiv d_r \pmod{2
}$.

- **If $d_r$ is even:** Set $s = 2u$. Then $P_r(2u) = 2\big(2^{r+1} u^2 + c_r \c
dot u + d_r/2\big)$. The inner polynomial $P_{r+1}(u) = 2^{r+1} u^2 + c_r \cdot
u + d_r/2$ has odd linear coefficient $c_r$. ✓

- **If $d_r$ is odd:** Set $s = 2u+1$. Then:
$$P_r(2u+1) = 2^r(2u+1)^2 + c_r(2u+1) + d_r = 2\Big(2^{r+1}u^2 + (2^{r+1}+c_r)\,
u + \big(2^{r-1} + \tfrac{c_r+d_r}{2}\big)\Big).$$
Since $c_r$ is odd and $2^{r+1}$ is even, the new linear coefficient $2^{r+1} +
c_r$ is **odd**. Since $c_r + d_r$ is even (both odd), the constant term is an i
nteger. (Note $r \geq 1$ ensures $2^{r-1}$ is an integer.) ✓

In both cases, $v_2(P_r(s)) = 1 + v_2(P_{r+1}(u))$ where $P_{r+1}$ has the same
structural form (leading coeff $2^{r+1}$, odd linear coeff). By the induction hy
pothesis, $v_2(P_{r+1}(u)) = b-1$ is achievable, so $v_2(P_r(s)) = b$ is achieva
ble. ✓

**Conclusion of induction:** All valuations $b = 0, 1, 2, \ldots$ are achieved f
or $g(m) = 2m^2 + m + j$, for any $j$.
