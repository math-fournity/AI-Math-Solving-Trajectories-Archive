## Solution

We solve the heat equation $u_t = k u_{xx}$ on $[0,L]$ with $u_x(0,t)=0$, $u_x(L
,t) = -h\,u(L,t)$, and $u(x,0)=f(x)$ by separation of variables.

### Eigenvalue Problem

Setting $u = X(x)T(t)$ gives $T' = -k\lambda T$ (so $T = e^{-k\lambda t}$) and

$$X'' + \lambda X = 0, \qquad X'(0)=0, \qquad X'(L) = -h\,X(L).$$

**Case $\lambda = 0$:** $X = A + Bx$. Then $X'(0)=B=0$, so $X=A$, and $X'(L)=0=-
hA$ forces $A=0$ since $h\neq 0$. No zero eigenvalue.

**Case $\lambda = \beta^2 > 0$:** $X = A\cos(\beta x) + B\sin(\beta x)$. From $X
'(0)=B\beta=0$ we get $B=0$, so $X = A\cos(\beta x)$. The Robin condition gives

$$-A\beta\sin(\beta L) = -hA\cos(\beta L) \implies \beta\sin(\beta L) = h\cos(\b
eta L),$$

i.e., the eigenvalue equation (valid since $\cos(\beta L)\neq 0$ at eigenvalues)
:

$$\boxed{\beta\tan(\beta L) = h.}$$

Eigenfunctions: $X_n(x) = \cos(\beta_n x)$.

**Case $\lambda = -\alpha^2 < 0$:** $X = A\cosh(\alpha x) + B\sinh(\alpha x)$. F
rom $X'(0)=B\alpha=0$ we get $B=0$, so $X=A\cosh(\alpha x)$. The Robin condition
 gives

$$A\alpha\sinh(\alpha L) = -hA\cosh(\alpha L) \implies \alpha\tanh(\alpha L) = -
h.$$

Eigenfunctions: $X(x) = \cosh(\alpha x)$, time factor $e^{k\alpha^2 t}$ (growing
).

### Orthogonality

For eigenfunctions $X_m, X_n$ with distinct eigenvalues $\lambda_m \neq \lambda_
n$:

$$(\lambda_m - \lambda_n)\int_0^L X_m X_n\,dx = \big[X_m X_n' - X_n X_m'\big]_0^
L.$$

At $x=0$: both $X_m'(0)=X_n'(0)=0$, so the boundary term vanishes. At $x=L$: $X_
m'(L)=-hX_m(L)$ and $X_n'(L)=-hX_n(L)$, so $X_m(L)(-hX_n(L)) - X_n(L)(-hX_m(L))
= 0$. Hence all eigenfunctions are mutually orthogonal in $L^2[0,L]$.

### Normalization Constants

For the $\cos(\beta_n x)$ modes, using $\sin(\beta_n L) = (h/\beta_n)\cos(\beta_
n L)$ and $\cos^2(\beta_n L) = \beta_n^2/(\beta_n^2+h^2)$:

$$N_n = \int_0^L \cos^2(\beta_n x)\,dx = \frac{L}{2} + \frac{\sin(2\beta_n L)}{4
\beta_n} = \frac{L}{2} + \frac{h}{2(\beta_n^2+h^2)}.$$

For the $\cosh(\alpha_0 x)$ mode (when it exists), using $\tanh(\alpha_0 L) = -h
/\alpha_0$ and $\cosh^2(\alpha_0 L) = \alpha_0^2/(\alpha_0^2 - h^2)$:

$$N_0 = \int_0^L \cosh^2(\alpha_0 x)\,dx = \frac{\sinh(2\alpha_0 L)}{4\alpha_0}
= \frac{-h}{2(\alpha_0^2 - h^2)}.$$

## (a) Solution for $h > 0$

**No negative eigenvalue:** The equation $\tanh(\alpha L) = -h/\alpha$ has no so
lution since $\tanh(\alpha L)>0$ while $-h/\alpha < 0$.

**Positive eigenvalues:** $\beta\tan(\beta L) = h$ with $h>0$ requires $\tan(\be
ta L)>0$, giving infinitely many roots $\beta_n$ with $\beta_n L \in \big((n{-}1
)\pi,\;(n{-}\tfrac12)\pi\big)$ for $n=1,2,3,\dots$

All eigenvalues are positive, so every mode decays exponentially — physically, h
eat escapes through the boundary at $x=L$.

$$\boxed{u(x,t) = \sum_{n=1}^{\infty} c_n \cos(\beta_n x)\, e^{-k\beta_n^2 t}}$$

where $\beta_n$ are the positive roots of $\beta\tan(\beta L) = h$, and

$$c_n = \frac{\displaystyle\int_0^L f(x)\cos(\beta_n x)\,dx}{\displaystyle\frac{
L}{2} + \frac{h}{2(\beta_n^2+h^2)}}.$$

---

## (b) Solution for $h < 0$

**One negative eigenvalue exists:** Write $g = -h > 0$. The equation $\tanh(\alp
ha L) = g/\alpha$ has exactly one positive root $\alpha_0$: as $\alpha\to 0^+$,
$\tanh(\alpha L)\to 0 < g/\alpha\to\infty$; as $\alpha\to\infty$, $\tanh(\alpha
L)\to 1 > g/\alpha\to 0$; by continuity and monotonicity of $\tanh(\alpha L) - g
/\alpha$ (increasing), there is exactly one crossing. This requires $\alpha_0 >
g = |h|$ (since $\tanh < 1$).

This gives eigenvalue $\lambda_0 = -\alpha_0^2 < 0$ with eigenfunction $\cosh(\a
lpha_0 x)$ and **growing** time factor $e^{k\alpha_0^2 t}$. Physically, $h<0$ me
ans the boundary condition $u_x(L) = |h|\,u(L)$ pumps energy into the rod, produ
cing an unstable mode.

**Positive eigenvalues:** $\beta\tan(\beta L) = h$ with $h<0$ requires $\tan(\be
ta L)<0$, giving infinitely many roots $\beta_n$ with $\beta_n L \in \big((n{-}\
tfrac12)\pi,\; n\pi\big)$ for $n=1,2,3,\dots$

$$\boxed{u(x,t) = c_0 \cosh(\alpha_0 x)\, e^{k\alpha_0^2 t} + \sum_{n=1}^{\infty
} c_n \cos(\beta_n x)\, e^{-k\beta_n^2 t}}$$

where:
- $\alpha_0 > 0$ is the unique root of $\alpha\tanh(\alpha L) = -h$ (with $-h>0$
),
- $\beta_n$ are the positive roots of $\beta\tan(\beta L) = h$,

and the coefficients (by orthogonality) are:

$$c_0 = \frac{\displaystyle\int_0^L f(x)\cosh(\alpha_0 x)\,dx}{\displaystyle\fra
c{-h}{2(\alpha_0^2 - h^2)}}, \qquad c_n = \frac{\displaystyle\int_0^L f(x)\cos(\
beta_n x)\,dx}{\displaystyle\frac{L}{2} + \frac{h}{2(\beta_n^2+h^2)}}.$$

The growing term $c_0\cosh(\alpha_0 x)e^{k\alpha_0^2 t}$ dominates as $t\to\inft
y$ (unless $c_0=0$, which occurs only for special initial data orthogonal to $\c
osh(\alpha_0 x)$), reflecting the physical instability of the system when $h<0$.
