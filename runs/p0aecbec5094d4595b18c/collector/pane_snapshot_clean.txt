## 证明

设 $g(y) = \sup\{v(y) : v \in S\}$ 为逐点上确界函数，因此 $u(x) = \limsup_{y \to
 x} g(y)$。

**第一步：$u$ 是有界的。**

由于 $S$ 是一致有界的，因此存在 $M > 0$ 使得对所有 $v \in S$ 和所有 $y \in \math
bb{R}$，都有 $|v(y)| \le M$。因此，对于所有 $y$，有 $|g(y)| \le M$，从而对于所有
 $x$，有
$$|u(x)| = \left|\limsup_{y \to x} g(y)\right| \le M.$$

**第二步：$u$ 是上半连续的，因此是 Borel 可测的。**

我们证明对于每个 $a \in \mathbb{R}$，集合 $\{x : u(x) < a\}$ 都是开集。注意到 $u
(x) = \inf_{\delta > 0}\, \sup_{0 < |y-x| < \delta} g(y)$。

设 $u(x_0) < a$。则存在 $\delta_0 > 0$ 使得 $c := \sup_{0 < |y - x_0| < \delta_0
} g(y) < a$。断言：对于所有满足 $|x - x_0| < \delta_0/2$ 的 $x$，都有 $u(x) < a$
。

- 若 $x = x_0$，则由假设 $u(x_0) < a$。
- 若 $x \neq x_0$，取 $\delta = |x - x_0| < \delta_0/2$。对于任何满足 $0 < |y -
x| < \delta$ 的 $y$，我们有 $y \neq x_0$（因为 $|y - x| < |x - x_0|$ 意味着 $|y
- x_0| \ge |x - x_0| - |y - x| > 0$），且 $|y - x_0| \le |y-x| + |x - x_0| < 2|x
 - x_0| < \delta_0$。因此 $y$ 位于环形区域 $0 < |y - x_0| < \delta_0$ 中，故 $g(
y) \le c < a$。从而 $u(x) \le \sup_{0 < |y-x| < \delta} g(y) \le c < a$。

因此 $\{x : u(x) < a\}$ 是开集，故 $u$ 是上半连续的，因此是 Borel 可测的。

**第三步：$\mu$ 是有限测度。**

$$\mu(\mathbb{R}) = \int_{\mathbb{R}} e^{-2|x|}\,dx = 2\int_0^\infty e^{-2x}\,dx
 = 2 \cdot \frac{1}{2} = 1 < \infty.$$

**结论。**

由于 $u$ 是 Borel 可测的，一致被 $M$ 界住，且 $\mu$ 是满足 $\mu(\mathbb{R}) = 1$
 的有限测度，我们有：
$$\int_{\mathbb{R}} |u|\,d\mu \le M \cdot \mu(\mathbb{R}) = M < \infty.$$

因此 $u \in L^1(\mu)$。
