## Proof

We interpret $\|A\|_p$ as the entrywise $\ell_p$ norm of $A \in \mathbb{R}^{m \t
imes n}$, so
$$f(A) = \|A\|_p^p = \sum_{i=1}^m \sum_{j=1}^n |a_{ij}|^p.$$

The gradient acts componentwise. Setting $\phi(x) = p\,|x|^{p-1}\operatorname{sg
n}(x)$, we have $(\nabla f(A))_{ij} = \phi(a_{ij})$. Since $\nabla f$ applies $\
phi$ entry-by-entry, $\nabla f$ is locally Lipschitz if and only if $\phi$ is lo
cally Lipschitz. We analyze $\phi$ by cases.

---

**Case $p = 1$:** $\phi(x) = \operatorname{sgn}(x)$, which is discontinuous at $
0$. Not locally Lipschitz.

**Case $1 < p < 2$:** For $x \neq 0$, $\phi'(x) = p(p-1)|x|^{p-2}$. Since $p - 2
 < 0$, we have $|\phi'(x)| \to \infty$ as $x \to 0$. If $\phi$ were Lipschitz on
 some neighborhood $(-\varepsilon, \varepsilon)$, then $\phi'$ would be essentia
lly bounded there (a Lipschitz function is differentiable a.e. with derivative b
ounded by the Lipschitz constant). But $|\phi'(x)| \to \infty$ as $x \to 0$ cont
radicts this. Hence $\phi$ is not locally Lipschitz.

**Case $p = 2$:** $\phi(x) = 2x$, which is linear and hence globally Lipschitz.
✓

**Case $p > 2$:** For $x \neq 0$, $\phi'(x) = p(p-1)|x|^{p-2}$. Since $p - 2 > 0
$, we have $|\phi'(x)| \to 0$ as $x \to 0$. Moreover,
$$\frac{\phi(x) - \phi(0)}{x - 0} = \frac{p\,|x|^{p-1}\operatorname{sgn}(x)}{x}
= p\,|x|^{p-2} \xrightarrow{x \to 0} 0,$$
so $\phi'(0) = 0$ and $\phi'$ is continuous on all of $\mathbb{R}$. A $C^1$ func
tion has a continuous (hence locally bounded) derivative, so $\phi$ is locally L
ipschitz. ✓

---

**Equivalence of componentwise and full local Lipschitzness.** If $\phi$ is loca
lly Lipschitz with constant $L$ on a compact set $K \subset \mathbb{R}$, then fo
r any $A, B$ with all entries in $K$:
$$\|\nabla f(A) - \nabla f(B)\|_F^2 = \sum_{i,j} |\phi(a_{ij}) - \phi(b_{ij})|^2
 \leq L^2 \sum_{i,j} |a_{ij} - b_{ij}|^2 = L^2 \|A - B\|_F^2.$$
Conversely, if $\nabla f$ is locally Lipschitz, fixing all entries of $A$ except
 one and varying that single entry shows $\phi$ must be locally Lipschitz. Hence
 the two notions coincide.

---

**Conclusion.** The gradient of $A \mapsto \|A\|_p^p$ is locally Lipschitz if an
d only if

$$\boxed{p \geq 2.}$$
