## 问题重述

求所有正整数三元组 $(a,b,c)$ 使得 $2^a + 2^b + 2^c + 3 = m^2$（某整数 $m$），并
计算 $\sum_{(a,b,c)\in S}(a+b+c)$。三个能量核心是**不同的**，因此 $(a,b,c)$ 是有
序三元组。

## 证明

**Step 1: 模 4 分析 — 至少一个为 1。**

平方数模 4 只能是 $0$ 或 $1$。若 $a,b,c \geq 2$，则 $2^a+2^b+2^c \equiv 0\pmod{4
}$，故 $m^2 \equiv 3\pmod{4}$，不可能。因此至少有一个等于 $1$。

**Step 2: 恰好两个为 1 — 不可能。**

WLOG $a=b=1, c\geq 2$。则 $2+2+2^c+3 = 2^c+7$。当 $c\geq 2$，$2^c \equiv 0\pmod{
4}$，故 $m^2 \equiv 7\equiv 3\pmod{4}$，不可能。

**Step 3: 三个全为 1 — 成立。**

$2+2+2+3 = 9 = 3^2$。✓ 得到配置 $(1,1,1)$，贡献 $a+b+c = 3$。

**Step 4: 恰好一个为 1。**

WLOG 设 $a=1$，$2 \leq b \leq c$。方程为 $2 + 2^b + 2^c + 3 = m^2$，即 $2^b + 2^
c + 5 = m^2$。

**模 8：** 若 $b, c \geq 3$，则 $2^b+2^c \equiv 0\pmod{8}$，故 $m^2 \equiv 5\pmo
d{8}$。但平方数模 8 只能是 $0,1,4$，不可能。因此 $b = 2$（因 $b \leq c$ 且 $b \g
eq 2$）。

方程变为 $4 + 2^c + 5 = m^2$，即 $m^2 = 2^c + 9$。

- **$c = 2$：** $m^2 = 13$，非平方数。
- **$c \geq 3$：** 分奇偶讨论。

**$c$ 偶数，$c = 2t$（$t \geq 2$）：** $m^2 - 2^{2t} = 9$，即 $(m - 2^t)(m + 2^t
) = 9$。因 $m > 2^t > 0$，两因子为正且 $m+2^t > m-2^t$。$9$ 的因子对 $(d, 9/d)$
中 $d < 9/d$：只有 $(1, 9)$。
  - $m - 2^t = 1,\; m + 2^t = 9$ $\Rightarrow$ $m = 5,\; 2^t = 4,\; t = 2,\; c =
 4$。✓
  - 验证：$2^1 + 2^2 + 2^4 + 3 = 2+4+16+3 = 25 = 5^2$。✓

**$c$ 奇数，$c = 2t+1$（$t \geq 1$）：** 模 3 分析。$2 \equiv -1\pmod{3}$，故 $2
^c = 2^{2t+1} \equiv (-1)^{2t+1} = -1 \equiv 2\pmod{3}$。$9 \equiv 0\pmod{3}$。
故 $m^2 \equiv 2\pmod{3}$。但平方数模 3 只能是 $0$ 或 $1$，**矛盾**。无解。

**Step 5: 汇总所有配置。**

无序形式只有两种：$\{1,1,1\}$ 和 $\{1,2,4\}$。

由于三个核心是**不同的**，$(a,b,c)$ 为有序三元组：

- $(1,1,1)$：$1$ 个，贡献 $3$。
- $(1,2,4)$ 的全排列：$(1,2,4),(1,4,2),(2,1,4),(2,4,1),(4,1,2),(4,2,1)$，共 $6$
个，每个贡献 $1+2+4=7$，合计 $42$。

**总计：**

$$\sum_{(a,b,c)\in S}(a+b+c) = 3 + 6 \times 7 = 3 + 42 = \boxed{45}$$
