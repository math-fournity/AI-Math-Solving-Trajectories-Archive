## Theorem: 1 is not a congruent number.

**Proof.** Suppose for contradiction that 1 is a congruent number. Then there ex
ist $a, b, c \in \mathbb{Q}$ with $a^2 + b^2 = c^2$ and $\tfrac{1}{2}ab = 1$.

Since $ab = 2 > 0$, we may assume $a, b, c > 0$. By the standard parametrization
 of rational right triangles (via the substitution $t = a/(b+c)$), there exist $
\lambda \in \mathbb{Q}_{>0}$ and $t \in \mathbb{Q} \cap (0,1)$ such that
$$a = 2\lambda\, t,\qquad b = \lambda(1 - t^2),\qquad c = \lambda(1 + t^2).$$
The area condition gives $\lambda^2\, t(1 - t^2) = 1$, so $t(1 - t^2) = 1/\lambd
a^2$ is a **square in $\mathbb{Q}^*$**.

Write $t = u/v$ in lowest terms with $0 < u < v$, $\gcd(u,v) = 1$. Then
$$t(1 - t^2) = \frac{u(v-u)(v+u)}{v^3} = \frac{S}{v^4}, \qquad S := uv(v-u)(v+u)
.$$
Since $v^4$ is a square, $S$ must be a **perfect square**.

### Coprimality analysis

- $\gcd(u, v) = 1$; $\gcd(u, v\pm u) = \gcd(u, v) = 1$; $\gcd(v, v \pm u) = \gcd
(v, u) = 1$.
- $\gcd(v-u,\, v+u) \mid 2\gcd(u,v) = 2$.

So the four factors are pairwise coprime except that $\gcd(v-u, v+u)$ may be $2$
.

### Case 1: $u$ and $v$ have different parities.

Then $v - u$ and $v + u$ are both odd, so all four factors are pairwise coprime.
 Since $S = u \cdot v \cdot (v{-}u) \cdot (v{+}u)$ is a square and all factors a
re positive, each is a square:
$$u = a_1^2,\quad v = b_1^2,\quad v - u = c_1^2,\quad v + u = d_1^2.$$

Adding and subtracting: $c_1^2 + d_1^2 = 2b_1^2$ and $d_1^2 - c_1^2 = 2a_1^2$, i
.e., $(d_1 - c_1)(d_1 + c_1) = 2a_1^2$.

Both $c_1, d_1$ are odd (since $v \pm u$ is odd when $u, v$ have different parit
ies), so $d_1 \pm c_1$ are even. Set $d_1 - c_1 = 2m$, $d_1 + c_1 = 2n$ ($n > m
> 0$). Then:
$$a_1^2 = 2mn, \qquad m^2 + n^2 = b_1^2 \quad\text{(Pythagorean triple)}.$$

Since $\gcd(c_1, d_1) = 1$ (as $\gcd(c_1^2, d_1^2) \mid 2$ and both odd), we get
 $\gcd(m, n) = 1$. Also $c_1 = n - m$ is odd, so $m, n$ have **different paritie
s** — a primitive Pythagorean triple. WLOG $m$ even:
$$m = 2PQ,\quad n = P^2 - Q^2,\quad b_1 = P^2 + Q^2, \qquad \gcd(P,Q)=1,\; P > Q
 > 0,\; P,Q \text{ opposite parity}.$$

From $a_1^2 = 4PQ(P^2 - Q^2)$, set $a_1 = 2a_1'$, so $a_1'^2 = PQ(P-Q)(P+Q)$. Th
e four factors $P, Q, P-Q, P+Q$ are pairwise coprime (using $\gcd(P,Q)=1$ and op
posite parity makes $P \pm Q$ odd and coprime). So each is a square:
$$P = r^2,\quad Q = s^2,\quad P - Q = \alpha^2,\quad P + Q = \beta^2, \qquad r >
 s \geq 1,\; \gcd(r,s)=1.$$

**New solution.** Set $t' = s^2/r^2 \in \mathbb{Q} \cap (0,1)$. Then:
$$t'(1 - t'^2) = \frac{s^2(r^4 - s^4)}{r^6} = \frac{s^2\, \alpha^2 \beta^2}{r^6}
 = \left(\frac{s\,\alpha\,\beta}{r^3}\right)^2.$$

This is a rational square, so $t'$ is a valid new solution. Its denominator (in
lowest terms, since $\gcd(r^2, s^2) = 1$) is $r^2$, while the original denominat
or was $v = b_1^2 = (r^4 + s^4)^2$. Since $r > s \geq 1$, we have $r^4 + s^4 > r
$, hence $v = (r^4 + s^4)^2 > r^2$. **The denominator strictly decreases.**

### Case 2: $u$ and $v$ both odd.

Then $v \pm u$ are both even. Set $v - u = 2A$, $v + u = 2B$ ($B > A > 0$). Then
 $S = 4uvAB$, so $uvAB$ must be a square.

The factors $u, v, A, B$ are pairwise coprime: $\gcd(A, B) \mid A+B = v$ and $\m
id B - A = u$, so $\gcd(A,B) \mid \gcd(u,v) = 1$; and $\gcd(u, A) = \gcd(u, (v{-
}u)/2) = 1$ since $\gcd(u, v{-}u) = 1$ and $u$ is odd (similarly for the others)
. So each is a square:
$$u = a_2^2,\quad v = b_2^2,\quad A = c_2^2,\quad B = d_2^2, \qquad a_2, b_2 \te
xt{ odd}.$$

From $b_2^2 \pm a_2^2 = 2d_2^2 / 2c_2^2$: set $b_2 - a_2 = 2e$, $b_2 + a_2 = 2f$
 ($f > e > 0$). Then:
$$e^2 + f^2 = d_2^2 \quad\text{(Pythagorean triple)},\qquad c_2^2 = 2ef.$$

$\gcd(e, f) \mid e + f = b_2$ and $\mid f - e = a_2$, so $\gcd(e, f) = 1$. Since
 $c_2^2 = 2ef$ is even, exactly one of $e, f$ is even. WLOG $e = 2g$ (even), $f$
 odd. Then $c_2 = 2h$ and $gf = h^2$ with $\gcd(g, f) = 1$, so $g = p^2$, $f = q
^2$ (with $q$ odd). Thus:
$$e = 2p^2,\quad f = q^2,\quad d_2^2 = 4p^4 + q^4.$$

Now $(d_2 - q^2)(d_2 + q^2) = 4p^4$. Since $d_2$ is odd and $q$ is odd, both fac
tors are even: set $d_2 - q^2 = 2M$, $d_2 + q^2 = 2N$, giving $MN = p^4$ with $\
gcd(M, N) = 1$ (any common divisor divides $d_2$ and $q^2$, hence $p$, contradic
ting $\gcd(p,q)=1$). So $M = r^4$, $N = s^4$ with $rs = p$, $\gcd(r,s) = 1$, and

$$q^2 = s^4 - r^4 = (s^2 - r^2)(s^2 + r^2), \qquad s > r \geq 1.$$

Since $q$ is odd, $s$ and $r$ have different parities, so $s^2 - r^2$ and $s^2 +
 r^2$ are both odd and coprime (gcd divides 2, but both odd). Thus each is a squ
are:
$$s^2 - r^2 = \alpha^2,\qquad s^2 + r^2 = \beta^2.$$

**New solution.** Set $t' = r^2/s^2 \in \mathbb{Q} \cap (0,1)$. Then:
$$t'(1 - t'^2) = \frac{r^2(s^4 - r^4)}{s^6} = \frac{r^2\, q^2}{s^6} = \left(\fra
c{r\,q}{s^3}\right)^2.$$

This is a rational square. The denominator is $s^2$, while the original was $v =
 b_2^2 = (2p^2 + q^2)^2 = (2r^2s^2 + s^4 - r^4)^2$. Since $s \geq 2$ and $r \geq
 1$, we have $2r^2s^2 + s^4 - r^4 \geq s^4 - (s{-}1)^4 > s$, so $v > s^2$. **The
 denominator strictly decreases.**

### Descent conclusion

In both cases, from a solution $t = u/v$ with denominator $v$, we construct a ne
w solution $t'$ with strictly smaller denominator $v' < v$. Iterating produces a
n infinite strictly decreasing sequence of positive integers:
$$v > v' > v'' > \cdots > 0,$$
which is impossible. Therefore, no rational $t \in (0,1)$ makes $t(1 - t^2)$ a r
ational square, so no rational right triangle of area 1 exists. $\blacksquare$
