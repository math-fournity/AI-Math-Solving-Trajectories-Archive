Find the distributional derivative of $\ln|x|$.

**Setup.** Let $f(x) = \ln|x|$, defined on $\mathbb{R}\setminus\{0\}$. As a loca
lly integrable function ($\ln|x|$ has only a logarithmic singularity at $0$, whi
ch is integrable on every compact set), $f$ defines a distribution $T_f \in \mat
hcal{D}'(\mathbb{R})$ by
$$\langle T_f, \varphi\rangle = \int_{-\infty}^{\infty} \ln|x|\,\varphi(x)\,dx,
\qquad \varphi \in C_c^\infty(\mathbb{R}).$$

Its distributional derivative $T_f'$ is the distribution defined by
$$\langle T_f', \varphi\rangle = -\langle T_f, \varphi'\rangle = -\int_{-\infty}
^{\infty} \ln|x|\,\varphi'(x)\,dx.$$

**Claim.** $T_f' = \operatorname{p.v.}\!\left(\dfrac{1}{x}\right)$, the Cauchy p
rincipal value distribution, defined by
$$\left\langle \operatorname{p.v.}\!\frac{1}{x},\,\varphi\right\rangle = \lim_{\
varepsilon\to 0^+} \int_{|x|>\varepsilon} \frac{\varphi(x)}{x}\,dx = \lim_{\vare
psilon\to 0^+}\left(\int_{-\infty}^{-\varepsilon} + \int_{\varepsilon}^{\infty}\
right)\frac{\varphi(x)}{x}\,dx.$$

**Proof of the claim.** Fix $\varphi\in C_c^\infty(\mathbb{R})$ with $\operatorn
ame{supp}\varphi\subset[-R,R]$. We must show
$$-\int_{-\infty}^{\infty}\ln|x|\,\varphi'(x)\,dx = \operatorname{p.v.}\!\int_{-
\infty}^{\infty}\frac{\varphi(x)}{x}\,dx.$$

Split the integral on the left at the singularity and integrate by parts on each
 half-line, avoiding $0$:
$$-\int_{-\infty}^{\infty}\ln|x|\,\varphi'(x)\,dx = -\lim_{\varepsilon\to 0^+}\l
eft(\int_{-R}^{-\varepsilon} + \int_{\varepsilon}^{R}\right)\ln|x|\,\varphi'(x)\
,dx.$$

On $[\varepsilon, R]$: since $\frac{d}{dx}\ln x = \frac{1}{x}$,
$$-\int_{\varepsilon}^{R}\ln x\,\varphi'(x)\,dx = -\Big[\ln x\,\varphi(x)\Big]_{
\varepsilon}^{R} + \int_{\varepsilon}^{R}\frac{\varphi(x)}{x}\,dx = \ln\varepsil
on\,\varphi(\varepsilon) + \int_{\varepsilon}^{R}\frac{\varphi(x)}{x}\,dx,$$
using $\varphi(R)=0$ (support inside $[-R,R]$).

On $[-R,-\varepsilon]$: since $\frac{d}{dx}\ln(-x)=\frac{1}{x}$,
$$-\int_{-R}^{-\varepsilon}\ln(-x)\,\varphi'(x)\,dx = -\Big[\ln(-x)\,\varphi(x)\
Big]_{-R}^{-\varepsilon} + \int_{-R}^{-\varepsilon}\frac{\varphi(x)}{x}\,dx = -\
ln\varepsilon\,\varphi(-\varepsilon) + \int_{-R}^{-\varepsilon}\frac{\varphi(x)}
{x}\,dx,$$
using $\varphi(-R)=0$.

Adding the two contributions:
$$\langle T_f',\varphi\rangle = \lim_{\varepsilon\to 0^+}\left\{\ln\varepsilon\b
ig[\varphi(\varepsilon)-\varphi(-\varepsilon)\big] + \int_{\varepsilon<|x|\le R}
\frac{\varphi(x)}{x}\,dx\right\}.$$

**The boundary term vanishes.** By Taylor expansion of the smooth $\varphi$ at $
0$,
$$\varphi(\varepsilon)-\varphi(-\varepsilon) = 2\varepsilon\,\varphi'(0) + O(\va
repsilon^3).$$
Hence
$$\ln\varepsilon\big[\varphi(\varepsilon)-\varphi(-\varepsilon)\big] = 2\varepsi
lon\ln\varepsilon\,\varphi'(0) + O(\varepsilon^3\ln\varepsilon)\xrightarrow[\var
epsilon\to 0^+]{}0,$$
since $\varepsilon\ln\varepsilon\to 0$.

Therefore
$$\langle T_f',\varphi\rangle = \lim_{\varepsilon\to 0^+}\int_{|x|>\varepsilon}\
frac{\varphi(x)}{x}\,dx = \left\langle\operatorname{p.v.}\!\frac{1}{x},\,\varphi
\right\rangle.$$

Since this holds for every test function $\varphi$, we conclude
$$\boxed{\frac{d}{dx}\big[\ln|x|\big] = \operatorname{p.v.}\!\frac{1}{x} \quad \
text{in } \mathcal{D}'(\mathbb{R}).}$$

**Remark (consistency check).** On $\mathbb{R}\setminus\{0\}$, the classical ide
ntity $\frac{d}{dx}\ln|x|=\frac{1}{x}$ holds pointwise, so the distributional de
rivative must agree with $1/x$ there. The only question is what happens at the o
rigin. The computation above shows that no delta-mass arises: the logarithmic si
ngularity is too mild to produce a point mass upon differentiation (contrast wit
h $\frac{d}{dx}|x|=2H-1$, where a kink produces a jump). The sole effect of the
singularity is that $1/x$ is not locally integrable near $0$, so it must be regu
larized as a principal value — which is precisely what the integration-by-parts
computation delivers.
