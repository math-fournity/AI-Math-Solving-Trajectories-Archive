## 解答

**答案：** $c = 2$.

### 证明

**第一步：$\phi(t)$ 在 $t=0$ 附近的展开。**

对于 $|t| \le 1$，我们有
$$\phi(t) = 1 - \sqrt{|t|(2-|t|)}.$$
将根号下的项写为 $|t|(2-|t|) = 2|t|\bigl(1 - \tfrac{|t|}{2}\bigr)$，因此
$$\sqrt{|t|(2-|t|)} = \sqrt{2|t|}\,\sqrt{1-\tfrac{|t|}{2}} = \sqrt{2}\,|t|^{1/2}
\Bigl(1 - \tfrac{|t|}{4} + O(|t|^2)\Bigr) = \sqrt{2}\,|t|^{1/2} + O(|t|^{3/2}).$
$
因此，当 $t \to 0$ 时，
$$\phi(t) = 1 - \sqrt{2}\,|t|^{1/2} + O(|t|^{3/2}), \qquad\text{即}\qquad 1-\phi
(t) \sim \sqrt{2}\,|t|^{1/2}.$$

这表明 $X_i$ 属于指数为 $\alpha = \tfrac{1}{2}$ 的对称稳定律的吸引域，其标准化常
数为 $n^{1/\alpha} = n^2$。

**第二步：取 $c=2$ 时 $S_n/n^c$ 的特征函数。**

$S_n/n^2$ 的特征函数为 $\bigl[\phi(t/n^2)\bigr]^n$。利用第一步，对于固定的 $t$
和较大的 $n$（使得 $|t|/n^2 \le 1$）：
$$\phi\!\Bigl(\frac{t}{n^2}\Bigr) = 1 - \sqrt{2}\,\Bigl|\frac{t}{n^2}\Bigr|^{1/2
} + O\!\Bigl(\Bigl|\frac{t}{n^2}\Bigr|^{3/2}\Bigr) = 1 - \frac{\sqrt{2|t|}}{n} +
 O(n^{-3}).$$

取对数（利用 $\log(1-x) = -x + O(x^2)$，其中 $x = \sqrt{2|t|}/n + O(n^{-3})$）：
$$n\log\phi\!\Bigl(\frac{t}{n^2}\Bigr) = n\Bigl(-\frac{\sqrt{2|t|}}{n} + O(n^{-3
}) + O(n^{-2})\Bigr) = -\sqrt{2|t|} + O(n^{-1}) \;\longrightarrow\; -\sqrt{2}\,|
t|^{1/2}.$$
因此
$$\bigl[\phi(t/n^2)\bigr]^n \;\longrightarrow\; \exp\!\bigl(-\sqrt{2}\,|t|^{1/2}
\bigr).$$

**第三步：极限是一个有效的特征函数。**

函数 $\psi(t) = \exp(-\sqrt{2}\,|t|^{1/2})$ 是指数 $\alpha=\tfrac12$、尺度参数 $
\lambda=\sqrt{2}$ 的对称稳定律的特征函数（这是经典的稳定律特征函数 $\exp(-\lambd
a|t|^\alpha)$，其中 $0<\alpha\le 2$）。由于 $\psi$ 在 $t=0$ 处连续，Lévy 连续性
定理意味着
$$\frac{S_n}{n^2} \;\xRightarrow{d}\; A, \qquad \text{其中 } \phi_A(t)=e^{-\sqrt
{2}\,|t|^{1/2}}.$$

**第四步：$c$ 的唯一性。**

对于一般的 $c > 0$，利用 $1-\phi(t/n^c) \sim \sqrt{2}\,|t|^{1/2}/n^{c/2}$：
$$n\log\phi(t/n^c) \sim -\sqrt{2|t|}\cdot n^{1-c/2}.$$

- 若 $c < 2$：$n^{1-c/2}\to\infty$，因此 $\bigl[\phi(t/n^c)\bigr]^n \to 0$（对于
 $t\ne 0$）——退化的，不是概率分布。
- 若 $c > 2$：$n^{1-c/2}\to 0$，因此 $\bigl[\phi(t/n^c)\bigr]^n \to 1$，意味着 $
S_n/n^c \to 0$ 依概率收敛——退化的。
- 若 $c = 2$：如上所示，得到非退化的极限 $\exp(-\sqrt{2}|t|^{1/2})$。

因此 $c = 2$ 是产生非退化极限分布的唯一正值。

### 结论

$$\boxed{c = 2}$$

常数 $c = 2$ 使得 $S_n/n^c$ 依分布收敛到随机变量 $A$，其特征函数为 $\phi_A(t) =
\exp(-\sqrt{2}\,|t|^{1/2})$，即一个指数为 $\alpha = \tfrac{1}{2}$ 的对称稳定律。
