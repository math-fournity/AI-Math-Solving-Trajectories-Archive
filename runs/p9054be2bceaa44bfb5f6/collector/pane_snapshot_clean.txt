## Proof of `erdos_427.variants.of_shiu`

$$\sum_{i=n}^{n+k-1} p_i = T(n+k) - T(n),$$

is infinite.

**Applying Shiu's theorem.** Fix $n \in \mathbb{N}$ and $d \geq 1$. Set $a = 1$,
 $q = d$, $k_{\mathrm{S}} = d$. The hypotheses are satisfied:
- $d \geq 1$, so $q \geq 1$ and $k_{\mathrm{S}} \geq 1$.
- $\gcd(1, d) = 1$.

By Shiu's theorem, the set
$$S = \{m \in \mathbb{N} : p_m, p_{m+1}, \ldots, p_{m+d-1} \equiv 1 \pmod{d}\}$$
is infinite.

 1$ (only finitely many elements of $S$ can satisfy $m \leq n$).

**Key computation.** For each $j \in \{0, 1, \ldots, d-1\}$, all primes $p_m, p_

mod{d}.$$

As $j$ ranges over $\{0, 1, \ldots, d-1\}$, the values $T(m) + j \pmod{d}$ are $
d$ consecutive residues modulo $d$, hence they are **all distinct** and cover ev

**Finding $j$.** The residue $T(n) \bmod d$ is some element of $\{0, 1, \ldots,
d-1\}$. By the covering property above, there exists $j \in \{0, 1, \ldots, d-1\

$$T(m+j) \equiv T(n) \pmod{d}.$$

**Conclusion.** Set $k = m + j - n$. Since $m \geq n+1$ and $j \geq 0$, we have

$$\sum_{i=n}^{n+k-1} p_i = T(n+k) - T(n) = T(m+j) - T(n) \equiv 0 \pmod{d}.$$

Therefore $d \mid \sum_{i=n}^{n+k-1} p_i$ with $k \geq 1$, as required. $\blacks
