## Proof

**Substitution.** Let $a = \frac{x}{x-1}$, $b = \frac{y}{y-1}$, $c = \frac{z}{z-
1}$. Then $x = \frac{a}{a-1}$ (and similarly for $y,z$), which is well-defined w
hen $a,b,c \neq 1$. Note $x \neq 1$ automatically since $\frac{a}{a-1}=1$ would
force $a=a-1$. The inequality becomes $a^2+b^2+c^2 \geq 1$.

**Reformulating the constraint.** The condition $xyz=1$ becomes
$$\frac{a}{a-1}\cdot\frac{b}{b-1}\cdot\frac{c}{c-1}=1 \implies abc = (a-1)(b-1)(
c-1).$$
Expanding the right side: $abc = abc - ab - bc - ca + a + b + c - 1$, giving
$$ab + bc + ca = a + b + c - 1. \tag{$\star$}$$

**Part (a) — the inequality.** Let $s = a+b+c$. Then
$$a^2+b^2+c^2 = s^2 - 2(ab+bc+ca) = s^2 - 2(s-1) = (s-1)^2 + 1 \geq 1.$$

**Equality condition.** Equality holds iff $s = 1$, i.e., $a+b+c=1$. Combined wi
th $(\star)$, this gives $ab+bc+ca = 0$.

**Part (b) — infinitely many rational triples.** We seek infinitely many rationa
l $(a,b,c)$ with:
$$a+b+c = 1, \quad ab+bc+ca = 0, \quad a,b,c \neq 1.$$

Fix $a$ rational. Then $b+c = 1-a$ and $bc = -a(b+c) = a^2 - a$, so $b,c$ are ro
ots of
$$t^2 - (1-a)t + a(a-1) = 0.$$
The discriminant is
$$\Delta = (1-a)^2 - 4a(a-1) = 1+2a-3a^2 = (3a+1)(1-a).$$
We need $\Delta$ to be a rational square. The conic $(3a+1)(1-a) = s^2$, i.e., $
3a^2 - 2a + s^2 = 1$, has the rational point $(a,s)=(0,1)$. Parametrize by lines
 $s = 1 + ta$ through it:
$$3a^2 - 2a + (1+ta)^2 = 1 \implies a\bigl((3+t^2)a + (2t-2)\bigr) = 0.$$
The nontrivial solution is
$$a = \frac{2(1-t)}{3+t^2}, \qquad s = \frac{3+2t-t^2}{3+t^2}.$$

Then $b = \frac{(1-a)+s}{2}$, $c = \frac{(1-a)-s}{2}$ are rational for every rat
ional $t$.

**Checking the exclusions.** We need $a,b,c \neq 1$:
- $a = 1 \iff 2(1-t) = 3+t^2 \iff (t+1)^2 = 0 \iff t = -1$.
- $b = 1 \iff s = 1+a$, which yields $t = 1$ (the known bad point $a=0, b=1$).
- $c = 1 \iff s = -(1+a)$, which forces $3 = -5$, **impossible**.

So for every rational $t \notin \{-1, 1\}$, we obtain a valid triple. Since $\ma
thbb{Q} \setminus \{-1,1\}$ is infinite, this gives **infinitely many** distinct
 rational triples $(a,b,c)$, hence infinitely many rational triples $(x,y,z) = \
left(\frac{a}{a-1}, \frac{b}{b-1}, \frac{c}{c-1}\right)$, each $\neq 1$, with $x
yz = 1$ and equality.

**Concrete example ($t=2$).** $a = -\tfrac{2}{7}$, $s = \tfrac{3}{7}$, giving $b
 = \tfrac{6}{7}$, $c = \tfrac{3}{7}$. Then $x = \tfrac{2}{9}$, $y = -6$, $z = -\
tfrac{3}{4}$. Verification: $xyz = \tfrac{2}{9}\cdot(-6)\cdot(-\tfrac{3}{4}) = 1
$, and
$$\frac{x^2}{(x-1)^2}+\frac{y^2}{(y-1)^2}+\frac{z^2}{(z-1)^2} = \frac{4}{49}+\fr
ac{36}{49}+\frac{9}{49} = 1. \quad\checkmark$$

This confirms the construction, and varying $t$ over $\mathbb{Q}\setminus\{-1,1\
}$ produces infinitely many such triples. $\blacksquare$
