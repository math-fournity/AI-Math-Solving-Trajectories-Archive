## Proof

### Setup and Key Reformulation

For $m \geq 1$, define $A(m) = \{k(m-k) : 1 \le k \le \lfloor m/2 \rfloor\}$. Si
nce $k \mapsto k(m-k)$ is strictly increasing on $[1, \lfloor m/2\rfloor]$, all
values are distinct, so $|A(m)| = \lfloor m/2 \rfloor$.

**Key identity.** For any $m$, write $k(m-k) = \frac{m^2}{4} - \left(k - \frac{m
}{2}\right)^2$. Setting $a = k - m/2$, $b = l - n/2$, the equation $k(m-k) = l(n
-l)$ becomes:

$$a^2 - b^2 = \frac{m^2 - n^2}{4}, \quad \text{i.e.,} \quad (a-b)(a+b) = \frac{m
^2-n^2}{4}.$$

Each solution $(k,l)$ bijects with a factorization of $(m^2-n^2)/4$ (or $m^2-n^2
$ after clearing denominators) into two factors of the same parity, subject to r
ange constraints on $a,b$. Different solutions yield different values of $a$ (he
nce different $k(m-k) = m^2/4 - a^2$), so **the map from intersection elements t
o factorizations is injective**.

### Part (i): The intersection can be arbitrarily large

**Claim:** For every $s \in \mathbb{N}$, there exist $m > n \geq 1$ with $|A(n)
\cap A(m)| \geq s$.

**Construction.** Let $r \geq 2$ be an integer with $2^{r-1} - 1 \geq s$ (take $
r = \lceil \log_2(s+1) \rceil + 1$). Let $p_1, \ldots, p_r$ be the first $r$ odd
 primes and set $P = p_1 p_2 \cdots p_r$ (so $P$ is odd, $P \geq 15$). Define:

$$n = P - 1, \qquad m = P + 1.$$

Then $n < m$, both are even, and $n \geq 2$. Set $M = m/2 = (P+1)/2$, $N = n/2 =
 (P-1)/2$, so $M = N+1$.

With $a = k - M$, $b = l - N$ (both integers), the equation becomes:

$$(a-b)(a+b) = M^2 - N^2 = (M-N)(M+N) = 1 \cdot (2N+1) = P.$$

Substituting $\alpha = -a = M - k \geq 0$, $\beta = -b = N - l \geq 0$, this bec
omes $(\alpha - \beta)(\alpha + \beta) = P$, i.e., setting $u = \alpha - \beta$,
 $v = \alpha + \beta$:

$$uv = P, \quad u, v > 0, \quad u \equiv v \pmod{2}, \quad u \leq v.$$

Since $P$ is odd, $u$ and $v$ must both be odd. The range constraints ($0 \leq \
alpha \leq M-1 = N$, $0 \leq \beta \leq N-1$) translate to:

$$u + v \leq 2N = P - 1, \qquad v - u \leq 2N - 2 = P - 3.$$

**Counting valid factorizations.** Since $P = p_1 \cdots p_r$ is squarefree with
 $r$ prime factors, $P$ has $\tau(P) = 2^r$ divisors, all odd. The divisors pair
 as $(d, P/d)$, so exactly $2^{r-1}$ divisors satisfy $d \leq \sqrt{P}$.

- **$d = 1$:** $u + v = 1 + P = P + 1 > P - 1$. ✗ (fails the constraint).
- **$d \geq 3$ (odd, $d \mid P$, $d \leq \sqrt{P}$):** We verify $u + v = d + P/
d \leq P - 1$ and $v - u = P/d - d \leq P - 3$.

  For $u + v$: We need $d + P/d \leq P - 1$, i.e., $d^2 + P \leq d(P-1)$, i.e.,
$P(d-1) \geq d^2 + d$. Since $d \leq \sqrt{P}$, we have $d^2 \leq P$, so $d^2 +
d \leq P + \sqrt{P}$. And $P(d-1) \geq P \cdot 2 = 2P$ (since $d \geq 3$). For $
P \geq 15$: $2P = 30 \geq 15 + \sqrt{15} \approx 18.9 \geq d^2 + d$. ✓

  For $v - u$: We need $P/d - d \leq P - 3$. Since $d \geq 3$: $P/d \leq P/3$ an
d $P/3 - 3 \leq P - 3$ iff $P/3 \leq P$, which is always true. ✓

So every odd divisor $d$ of $P$ with $3 \leq d \leq \sqrt{P}$ yields a valid ele
ment of $A(n) \cap A(m)$. The count is $2^{r-1} - 1$ (total divisors $\leq \sqrt
{P}$ is $2^{r-1}$, minus 1 for $d=1$).

**Verification with example.** For $r = 3$, $P = 3 \cdot 5 \cdot 7 = 105$: odd d
ivisors $\leq \sqrt{105} \approx 10.2$ are $\{1, 3, 5, 7\}$. Excluding 1: three
factorizations $(3,35), (5,21), (7,15)$, giving $|A(104) \cap A(106)| = 3 = 2^2
- 1$. ✓

**Conclusion.** For any $s$, choosing $r$ with $2^{r-1} - 1 \geq s$ and $P = p_1
 \cdots p_r$, $n = P-1$, $m = P+1$ gives $n < m$ and $|A(n) \cap A(m)| = 2^{r-1}
 - 1 \geq s$. $\square$

### Part (ii): Sub-polynomial upper bound

**Claim:** For every $\varepsilon > 0$, there exists $n_0$ such that for all $m,
 n$ with $n_0 < n < m$: $|A(n) \cap A(m)| < (mn)^\varepsilon$.

**Step 1: Bound the intersection by a divisor function.**

From the reformulation, each element of $A(n) \cap A(m)$ corresponds injectively
 to a factorization of $|m^2 - n^2|$ (or $(m^2-n^2)/4$ depending on parity) into
 two factors of the same parity. The number of such factorizations is at most $\
tau(|m^2 - n^2|)/2 + 1$, where $\tau$ denotes the number-of-divisors function. S
ince $|m^2 - n^2| = (m-n)(m+n) < 2m^2$ and $\tau(2m^2) \leq 2\tau(m^2)$ (multipl
ying by 2 increases the divisor count by at most a factor of 2), we get:

$$|A(n) \cap A(m)| \leq \tau(m^2) + 1.$$

**Step 2: Standard divisor function bound.**

We use the classical bound: for every $\delta > 0$, there exists $C(\delta) > 0$
 such that $\tau(N) \leq C(\delta) \cdot N^\delta$ for all $N \geq 1$.

*Proof sketch:* If $N = \prod q_i^{a_i}$, then $\tau(N)/N^\delta = \prod (a_i+1)
/q_i^{\delta a_i}$. For primes $q \geq 2^{1/\delta}$, each factor $(a+1)/q^{\del
ta a} \leq 1$ (since $q^{\delta a} \geq 2^a \geq a+1$). For the finitely many pr
imes $q < 2^{1/\delta}$, the factor $(a+1)/q^{\delta a}$ is bounded (polynomial
over exponential), say by $C_q$. Then $C(\delta) = \prod_{q < 2^{1/\delta}} C_q
< \infty$.

Applying this with $N = m^2$: $\tau(m^2) \leq C(\delta) \cdot m^{2\delta}$ for a
ny $\delta > 0$.

**Step 3: Choose parameters.**

Given $\varepsilon > 0$, set $\delta = \varepsilon/3$. Then:

$$|A(n) \cap A(m)| \leq C(\varepsilon/3) \cdot m^{2\varepsilon/3} + 1.$$

We need $C(\varepsilon/3) \cdot m^{2\varepsilon/3} + 1 < (mn)^\varepsilon$ for a
ll $n_0 < n < m$.

Since $n > n_0$ and $m > n > n_0$:
- $(mn)^\varepsilon > m^\varepsilon \cdot n_0^\varepsilon$ (using $n > n_0$).
- $m^\varepsilon = m^{2\varepsilon/3} \cdot m^{\varepsilon/3} > m^{2\varepsilon/
3} \cdot n_0^{\varepsilon/3}$ (using $m > n_0$).

So $(mn)^\varepsilon > m^{2\varepsilon/3} \cdot n_0^{\varepsilon/3} \cdot n_0^\v
arepsilon = m^{2\varepsilon/3} \cdot n_0^{4\varepsilon/3}$.

It suffices to have:
$$C(\varepsilon/3) \cdot m^{2\varepsilon/3} + 1 \leq m^{2\varepsilon/3} \cdot n_
0^{4\varepsilon/3},$$
i.e., $C(\varepsilon/3) + m^{-2\varepsilon/3} \leq n_0^{4\varepsilon/3}$.

Since $m > n_0$, we have $m^{-2\varepsilon/3} < n_0^{-2\varepsilon/3} < 1$. So i
t suffices that:

$$C(\varepsilon/3) + 1 \leq n_0^{4\varepsilon/3}.$$

Choose $n_0$ large enough that $n_0^{4\varepsilon/3} > C(\varepsilon/3) + 1$. Th
en for all $n_0 < n < m$:

$$|A(n) \cap A(m)| \leq C(\varepsilon/3) \cdot m^{2\varepsilon/3} + 1 < m^{2\var
epsilon/3} \cdot n_0^{4\varepsilon/3} \leq (mn)^\varepsilon. \quad \square$$

m)| = 2^{r-1} - 1 \geq s$. The intersection elements biject with odd divisors $d

n_0 < n < m$, using the classical sub-polynomial bound on the divisor function.
