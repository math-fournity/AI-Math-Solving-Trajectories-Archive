Looking at this problem, I need to determine whether for any countable set $S \s
ubset \mathbb{R}$, there exists a continuous function that is non-differentiable
 exactly at the points of $S$.

**Answer: Yes.** For every countable set $S \subset \mathbb{R}$, such a continuo
us function exists.

---

## Proof

**Construction.** Enumerate $S = \{s_1, s_2, s_3, \ldots\}$ (if $S$ is finite, t
he construction below simplifies to a finite sum and all convergence arguments b
ecome trivial; if $S = \emptyset$, take $f \equiv 0$). Choose positive weights

$$a_n = \frac{1}{2^n(1 + |s_n|)},$$

so that $\sum_n a_n < \infty$ and $\sum_n a_n |s_n| < \infty$. Define

$$f(x) = \sum_{n=1}^{\infty} a_n\,|x - s_n|.$$

**Step 1: $f$ is well-defined and continuous.**

For any fixed $x$, using $|x - s_n| \le |x| + |s_n|$:

$$\sum_n a_n |x - s_n| \le |x|\sum_n a_n + \sum_n a_n |s_n| < \infty,$$

so the series converges pointwise. On any compact interval $[-M, M]$, we have $|
x - s_n| \le M + |s_n|$, giving $a_n|x - s_n| \le M a_n + a_n|s_n|$, and $\sum_n
(Ma_n + a_n|s_n|) < \infty$. By the Weierstrass $M$-test, the series converges u
niformly on $[-M,M]$. Since each summand is continuous, $f$ is continuous on eve
ry compact set, hence on all of $\mathbb{R}$.

**Step 2: $f$ is differentiable at every $x_0 \notin S$.**

For $x_0 \notin S$, every $s_n \ne x_0$, so each $g_n(x) = |x - s_n|$ is differe
ntiable at $x_0$ with $g_n'(x_0) = \operatorname{sgn}(x_0 - s_n) \in \{-1, +1\}$
. The difference quotient

$$Q_n(x) = \frac{|x - s_n| - |x_0 - s_n|}{x - x_0}$$

satisfies $|Q_n(x)| \le 1$ for all $x \ne x_0$ (since $|\cdot|$ is $1$-Lipschitz
). Therefore

$$\left|a_n Q_n(x)\right| \le a_n, \qquad \sum_n a_n < \infty,$$

and by the Weierstrass $M$-test, $\sum_n a_n Q_n(x)$ converges uniformly in $x$
(for $x \ne x_0$). Since each $Q_n(x) \to g_n'(x_0)$ as $x \to x_0$, the Moore–O
sgood theorem (interchange of a pointwise limit with a uniformly convergent seri
es) gives:

$$f'(x_0) = \lim_{x \to x_0} \sum_n a_n Q_n(x) = \sum_n a_n \lim_{x \to x_0} Q_n
(x) = \sum_n a_n \operatorname{sgn}(x_0 - s_n).$$

Hence $f$ is differentiable at $x_0$.

**Step 3: $f$ is non-differentiable at every $s_k \in S$.**

Fix $s_k \in S$ and write

$$f(x) = \underbrace{a_k |x - s_k|}_{\text{corner at } s_k} + \underbrace{\sum_{
n \ne k} a_n |x - s_n|}_{=:\, h_k(x)}.$$

The set $S \setminus \{s_k\}$ is countable and $s_k \notin S \setminus \{s_k\}$,
 so by the argument of Step 2 (applied with the same weights $\{a_n\}_{n \ne k}$
, which still satisfy $\sum_{n\ne k} a_n < \infty$ and $\sum_{n \ne k} a_n|s_n|
< \infty$), the function $h_k$ is differentiable at $s_k$.

The term $a_k|x - s_k|$ has left derivative $-a_k$ and right derivative $+a_k$ a
t $x = s_k$. Since $a_k > 0$, these one-sided derivatives differ. Adding a funct
ion $h_k$ that is differentiable (hence has equal left and right derivatives) at
 $s_k$ does not resolve this mismatch:

$$f'_-(s_k) = -a_k + h_k'(s_k), \qquad f'_+(s_k) = +a_k + h_k'(s_k),$$

so $f'_-(s_k) \ne f'_+(s_k)$. Therefore $f$ is not differentiable at $s_k$.

**Conclusion.** The function $f(x) = \sum_{n=1}^{\infty} a_n |x - s_n|$ with $a_
n = \frac{1}{2^n(1+|s_n|)}$ is continuous on $\mathbb{R}$, differentiable at eve
ry point of $\mathbb{R} \setminus S$, and non-differentiable at every point of $
S$. Thus, for every countable set $S \subset \mathbb{R}$, there exists a continu
ous function whose set of non-differentiability is exactly $S$. $\blacksquare$
