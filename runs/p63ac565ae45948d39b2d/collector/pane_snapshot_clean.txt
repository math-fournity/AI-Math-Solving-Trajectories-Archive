Looking at this problem, I need to determine whether every continuous $f: \mathb
b{R}^2 \to \mathbb{R}^2$ satisfying $f(f(x)) + f(x) + x = 0$ must be additive.

**Answer: No.** I'll construct a smooth non-additive solution.

---

## Proof

Identify $\mathbb{R}^2$ with $\mathbb{C}$. Let $\omega = e^{2\pi i/3}$, so $\ome
ga^2 + \omega + 1 = 0$, $\omega^3 = 1$. The linear solution is $R(z) = \omega z$
 (rotation by $120°$), satisfying $R^2 + R + I = 0$.

### Construction

Let $\phi:[0,\infty)\to[0,1]$ be smooth with $\phi \equiv 1$ on $[0,1]$ and $\ph
i \equiv 0$ on $[2,\infty)$. For small $\epsilon > 0$, define:
$$\psi(z) = z + \epsilon\,\phi(|z|)\,|z|^2\,\bar{z}.$$

**Claim 1:** $\psi(\omega z) + \psi(\bar\omega z) + \psi(z) = 0$ for all $z$.

*Proof.* Since $|\omega z| = |\bar\omega z| = |z|$, we have $\phi(|\omega z|) =
\phi(|\bar\omega z|) = \phi(|z|)$, $|\omega z|^2 = |z|^2$, and $\overline{\omega
 z} = \bar\omega\bar z$, $\overline{\bar\omega z} = \omega\bar z$. Thus:
$$\psi(\omega z)+\psi(\bar\omega z)+\psi(z) = (\omega+\bar\omega+1)z + \epsilon\
phi(|z|)|z|^2(\bar\omega+\omega+1)\bar z = 0.\quad\checkmark$$

**Claim 2:** For $\epsilon$ sufficiently small, $\psi$ is a $C^\infty$ diffeomor
phism of $\mathbb{C}$.

*Proof.* Write $\psi = \mathrm{id} + \epsilon g$ where $g(z)=\phi(|z|)|z|^2\bar
z$ is smooth with compact support. The real Jacobian is $J_\psi = |1+\epsilon g_
z|^2 - |\epsilon g_{\bar z}|^2$. Since $g_z, g_{\bar z}$ are bounded (compact su
pport), for $\epsilon$ small enough, $J_\psi > 0$ everywhere, so $\psi$ is a loc
al diffeomorphism. Since $\psi(z)=z$ for $|z|\ge 2$, $\psi$ is proper. A proper
local diffeomorphism $\mathbb{R}^2\to\mathbb{R}^2$ is a covering map; $\mathbb{R
}^2$ is simply connected, so $\psi$ is a global diffeomorphism. $\checkmark$

### Definition of $f$

Set $f = \psi \circ R \circ \psi^{-1}$, i.e., $f(x) = \psi\!\left(\omega\,\psi^{
-1}(x)\right)$.

**Claim 3:** $f(f(x)) + f(x) + x = 0$ for all $x$.

*Proof.* Let $y = \psi^{-1}(x)$. Then $f(x) = \psi(\omega y)$ and $f(f(x)) = \ps
i(\omega\,\psi^{-1}(\psi(\omega y))) = \psi(\omega^2 y) = \psi(\bar\omega\, y)$.
 By Claim 1:
$$f(f(x)) + f(x) + x = \psi(\bar\omega\, y) + \psi(\omega\, y) + \psi(y) = 0.\qu
ad\checkmark$$

### $f$ is not additive

**Claim 4:** $f$ is not additive.

*Proof.* First, $\psi(0)=0$ so $f(0)=0$. If a continuous additive $f:\mathbb{R}^
2\to\mathbb{R}^2$ satisfies $f(0)=0$, it is $\mathbb{R}$-linear: $f(w)=Aw$ for s
ome real $2\times 2$ matrix $A$.

Compute $f$ to first order in $\epsilon$. Since $\psi^{-1}(w) = w - \epsilon g(w
) + O(\epsilon^2)$:
$$f(w) = \psi\!\big(\omega(w - \epsilon g(w) + O(\epsilon^2))\big) = \omega w -
\epsilon\,\omega\, g(w) + \epsilon\, g(\omega w) + O(\epsilon^2).$$

Now $g(w) = \phi(|w|)|w|^2\bar w$ and $g(\omega w) = \phi(|w|)|w|^2\,\bar\omega\
,\bar w$, so:
$$f(w) = \omega w + \epsilon\,\phi(|w|)|w|^2\bar w\,(-\omega + \bar\omega) + O(\
epsilon^2).$$

Since $-\omega + \bar\omega = -\omega + \omega^2 = -i\sqrt{3}$:
$$f(w) = \omega w - i\sqrt{3}\,\epsilon\,\phi(|w|)\,|w|^2\bar w + O(\epsilon^2).
$$

For $|w| \le 1$ (where $\phi\equiv 1$): $f(w) = \omega w - i\sqrt{3}\,\epsilon\,
|w|^2\bar w + O(\epsilon^2)$.

If $f$ were $\mathbb{R}$-linear, the linear part forces $f(w) = \omega w$. But $
f(w) - \omega w = -i\sqrt{3}\,\epsilon\,|w|^2\bar w + O(\epsilon^2) \neq 0$ for
small $w \neq 0$, since $|w|^2\bar w$ is a nonzero cubic function. Contradiction
. $\checkmark$

### Conclusion

The function $f = \psi \circ R \circ \psi^{-1}$ is $C^\infty$, satisfies $f(f(x)
)+f(x)+x=0$ for all $x\in\mathbb{R}^2$, and is **not** additive. The key idea is
 that the functional equation $\psi(\omega z)+\psi(\bar\omega z)+\psi(z)=0$ admi
ts non-linear solutions $\psi$ (with angular Fourier modes $n \not\equiv 0 \pmod
{3}$), and conjugating the linear rotation $R$ by such a $\psi$ that does **not*
* commute with $R$ (mode $n \equiv 2 \pmod 3$) produces a genuinely non-linear $
f$.

**The answer is no:** a continuous $f:\mathbb{R}^2\to\mathbb{R}^2$ satisfying $f
(f(x))+f(x)+x=0$ need not satisfy $f(x+y)=f(x)+f(y)$.
