## Proof

**Definitions and setup.** For $n = \prod_{i=1}^{k} p_i^{a_i}$ (with $a_i \geq 1
$), we have:
$$\Phi(n) = \prod_{i=1}^{k} p_i^{a_i - 1}(p_i - 1), \qquad \Psi(n) = \prod_{i=1}
^{k} p_i^{a_i - 1}(p_i + 1).$$

Then:
$$n + \Psi(n) = \prod_{i=1}^{k} p_i^{a_i - 1}\left(\prod_{i=1}^{k} p_i + \prod_{
i=1}^{k}(p_i + 1)\right).$$

Since $\Phi(n) = \prod p_i^{a_i-1} \cdot \prod(p_i - 1)$, the condition $\Phi(n)
 \mid (n + \Psi(n))$ reduces to:

$$\prod_{i=1}^{k}(p_i - 1) \;\Big|\; \left(\prod_{i=1}^{k} p_i + \prod_{i=1}^{k}
(p_i + 1)\right). \tag{$\star$}$$

**Key observation:** Condition $(\star)$ depends only on the *set* $P = \{p_1, \
dots, p_k\}$ of prime divisors, not on the exponents $a_i$. Thus if a set $P$ sa
tisfies $(\star)$, then every $n$ with exactly that prime set works.

Set $A = \prod_{p \in P} p$, $B = \prod_{p \in P}(p-1)$, $C = \prod_{p \in P}(p+
1)$. The condition is $B \mid (A + C)$.
