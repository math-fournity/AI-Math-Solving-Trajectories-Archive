## Solution

**The functional and transformation.** We are given
$$S[y_1, y_2] = \int \bigl[y_1'^2 + 2y_2'^2 + (2y_1 + y_2)^2\bigr]\,dx$$
and the linear change of variables
$$z_1 = y_1 + a\,y_2, \qquad z_2 = 2y_1 + y_2.$$

**Step 1: Invert the transformation.** The transformation matrix is $M = \begin{
pmatrix} 1 & a \\ 2 & 1 \end{pmatrix}$ with $\det M = 1 - 2a$. For invertibility
 we need $a \neq \tfrac{1}{2}$. Solving the linear system:

$$y_1 = \frac{z_1 - a\,z_2}{1 - 2a}, \qquad y_2 = \frac{z_2 - 2\,z_1}{1 - 2a}.$$

Differentiating:
$$y_1' = \frac{z_1' - a\,z_2'}{1 - 2a}, \qquad y_2' = \frac{z_2' - 2\,z_1'}{1 -
2a}.$$

**Step 2: Rewrite the potential term.** Since $z_2 = 2y_1 + y_2$ by definition,
the potential term is immediately
$$(2y_1 + y_2)^2 = z_2^2,$$
which depends only on $z_2$. The potential part is already decoupled.

**Step 3: Rewrite the kinetic term.** We compute
$$y_1'^2 + 2\,y_2'^2 = \frac{1}{(1-2a)^2}\Bigl[(z_1' - a\,z_2')^2 + 2\,(z_2' - 2
\,z_1')^2\Bigr].$$

Expanding both squares:
- $(z_1' - a\,z_2')^2 = z_1'^2 - 2a\,z_1'z_2' + a^2\,z_2'^2$
- $2(z_2' - 2z_1')^2 = 2z_2'^2 - 8z_1'z_2' + 8z_1'^2$

Adding:
$$y_1'^2 + 2y_2'^2 = \frac{1}{(1-2a)^2}\Bigl[9\,z_1'^2 + (a^2+2)\,z_2'^2 - (2a+8
)\,z_1'z_2'\Bigr].$$

**Step 4: Determine $a$ for decoupling.** The kinetic term is decoupled (no mixe
d $z_1'z_2'$ term) if and only if the cross-term coefficient vanishes:
$$2a + 8 = 0 \quad\Longrightarrow\quad \boxed{a = -4}.$$

**Step 5: Verify and write the decoupled functional.** With $a = -4$ we have $1
- 2a = 9$, so $(1-2a)^2 = 81$. Substituting:

$$y_1'^2 + 2y_2'^2 = \frac{1}{81}\Bigl[9\,z_1'^2 + (16+2)\,z_2'^2\Bigr] = \frac{
1}{81}\Bigl[9\,z_1'^2 + 18\,z_2'^2\Bigr] = \frac{1}{9}\,z_1'^2 + \frac{2}{9}\,z_
2'^2.$$

The full functional becomes
$$S = \int\!\left[\frac{1}{9}\,z_1'^2 + \frac{2}{9}\,z_2'^2 + z_2^2\right]dx = \
underbrace{\int \frac{1}{9}\,z_1'^2\,dx}_{S_1[z_1]} + \underbrace{\int\!\left[\f
rac{2}{9}\,z_2'^2 + z_2^2\right]dx}_{S_2[z_2]}.$$

This is a sum of two functionals: $S_1$ depends only on $z_1$ and $S_2$ depends
only on $z_2$.

**Step 6: The decoupled Euler–Lagrange equations.** Varying independently:

- **For $z_1$:** $\displaystyle \frac{d}{dx}\!\left(\frac{2}{9}\,z_1'\right) = 0
 \;\Longrightarrow\; z_1'' = 0.$

- **For $z_2$:** $\displaystyle \frac{d}{dx}\!\left(\frac{4}{9}\,z_2'\right) - 2
\,z_2 = 0 \;\Longrightarrow\; \frac{4}{9}\,z_2'' = 2\,z_2 \;\Longrightarrow\; z_
2'' = \tfrac{9}{2}\,z_2.$

These are two independent ODEs, confirming the decoupling.

**Conclusion.** The required constant is
$$\boxed{a = -4}.$$
