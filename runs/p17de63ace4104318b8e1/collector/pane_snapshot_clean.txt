# Proof

**Statement:** If $(b) \subset (c) \subset R$ with $b \neq 0$, then $(c)/(b) \si
meq R/(b:c)$, where $a \cdot c = b$.

**The statement is TRUE.**

## Setup and interpretation

Here $R$ is a commutative ring with unity, $(b) = bR$ and $(c) = cR$ are princip
al ideals, and the **colon ideal** is
$$(b : c) = \{r \in R : rc \in (b)\}.$$
The condition $a \cdot c = b$ (for some $a \in R$) simply guarantees $(b) \subse
teq (c)$, since $b = ac \in (c)$; this is consistent with the hypothesis $(b) \s
ubset (c)$.

## The isomorphism

Define the map
$$\varphi: R \longrightarrow (c)/(b), \qquad \varphi(r) = rc + (b).$$

**Well-definedness and codomain.** Since $c \in (c)$ and $(c)$ is an ideal, $rc
\in (c)$ for every $r \in R$. Since $(b) \subseteq (c)$, the quotient $(c)/(b)$
is well-defined, and $rc + (b)$ is a legitimate coset in $(c)/(b)$. So $\varphi$
 maps into the correct codomain.

**$R$-module homomorphism.** For $r_1, r_2, s \in R$:
$$\varphi(r_1 + r_2) = (r_1+r_2)c + (b) = (r_1 c + r_2 c) + (b) = \varphi(r_1) +
 \varphi(r_2),$$
$$\varphi(sr) = src + (b) = s\,(rc + (b)) = s\,\varphi(r).$$

**Surjectivity.** Every element of $(c)$ is of the form $rc$ for some $r \in R$
(because $(c)$ is the principal ideal generated by $c$). Hence every element of
$(c)/(b)$ has the form $rc + (b) = \varphi(r)$. Thus $\varphi$ is surjective.

**Kernel.**
$$\ker \varphi = \{r \in R : rc \in (b)\} = (b : c).$$

**Conclusion.** By the First Isomorphism Theorem for $R$-modules,
$$R / \ker\varphi \;\cong\; \operatorname{im}\varphi,$$
that is,
$$\boxed{R/(b:c) \;\cong\; (c)/(b)}.$$

## Remark on the hypothesis $a \cdot c = b$

The existence of $a \in R$ with $ac = b$ is equivalent to $b \in (c)$, i.e., $(b
) \subseteq (c)$. This is exactly the containment already assumed in the hypothe
sis $(b) \subset (c)$, so the condition $a \cdot c = b$ is redundant with the st
ated inclusion and does not affect the validity of the isomorphism. The result h
olds for any commutative ring $R$ whenever $(b) \subseteq (c)$ and $b \neq 0$ (t
he $b \neq 0$ condition merely excludes the trivial case $(b) = 0$).
