# 最小的 $n$ 使得 $x^2 + 7 = f_1(x)^2 + \cdots + f_n(x)^2$（$f_i \in \mathbb{Q}[x]$）

## 答案

$$\boxed{n = 5}$$

## 构造（$n = 5$ 可行）

取

$$f_1(x) = x, \quad f_2(x) = 2, \quad f_3(x) = 1, \quad f_4(x) = 1, \quad f_5(x) = 1.$$

则

$$f_1^2 + f_2^2 + f_3^2 + f_4^2 + f_5^2 = x^2 + 4 + 1 + 1 + 1 = x^2 + 7. \quad \checkmark$$

## 证明 $n \leq 4$ 不可行

### 步骤一：化简为二次型表示问题

设 $f_i(x) = a_i x + b_i$（$a_i, b_i \in \mathbb{Q}$）。首先证明每个 $f_i$ 的次数至多为 $1$。

**引理 1.** 若 $\sum_{i=1}^n f_i(x)^2 = x^2 + 7$，则 $\deg f_i \leq 1$ 对所有 $i$。

**证明.** 设 $d = \max_i \deg f_i$。若 $d \geq 2$，则 $\sum f_i^2$ 的最高次项为 $\sum_{i:\,\deg f_i = d} (\operatorname{lc}(f_i))^2 \cdot x^{2d}$。由于有理数的平方和为零当且仅当每项为零，而至少有一个 $\operatorname{lc}(f_i) \neq 0$，故该和为正数，$\deg(\sum f_i^2) = 2d \geq 4 > 2$，矛盾。因此 $d \leq 1$。$\square$

于是问题等价于：求最小的 $n$，使得存在有理数 $a_i, b_i$（$i = 1, \ldots, n$）满足

$$\sum_{i=1}^n a_i^2 = 1, \qquad \sum_{i=1}^n a_i b_i = 0, \qquad \sum_{i=1}^n b_i^2 = 7. \tag{$*$}$$

### 步骤二：利用 Witt 定理化简

将 $(*)$ 看作在二次型 $Q = \underbrace{\langle 1, 1, \ldots, 1 \rangle}_{n}$ 上的问题：需要找到两个正交向量 $\mathbf{a} = (a_1, \ldots, a_n)$ 和 $\mathbf{b} = (b_1, \ldots, b_n)$，使得 $Q(\mathbf{a}) = 1$ 且 $Q(\mathbf{b}) = 7$。

- **存在 $Q(\mathbf{a}) = 1$ 的有理向量**：对任意 $n \geq 1$，取 $\mathbf{a} = (1, 0, \ldots, 0)$ 即可。

- **正交补的等距类型**：由 **Witt 定理**，$\mathbb{Q}$ 上正定二次型 $Q = n\langle 1 \rangle$ 中任意两个 $Q$-值相同的向量可通过等距变换互换。因此 $\mathbf{a}$ 的正交补 $\mathbf{a}^\perp$ 的等距类型仅依赖于 $Q(\mathbf{a}) = 1$，不依赖于 $\mathbf{a}$ 的具体选取。

  取 $\mathbf{a} = (1, 0, \ldots, 0)$，则 $\mathbf{a}^\perp = \{(0, x_2, \ldots, x_n)\}$，$Q$ 限制其上为 $\underbrace{\langle 1, \ldots, 1 \rangle}_{n-1} = (n-1)\langle 1 \rangle$。

  由 Witt 定理，对任意满足 $Q(\mathbf{a}') = 1$ 的 $\mathbf{a}'$，其正交补均等距于 $(n-1)\langle 1 \rangle$。

**结论**：$(*)$ 有解当且仅当 $7$ 可被 $(n-1)\langle 1 \rangle$ 表示，即 **$7$ 是 $n - 1$ 个有理平方数之和**。

### 步骤三：逐项排除

现在需要确定最小的 $m$ 使得 $7$ 是 $m$ 个有理平方数之和，则 $n = m + 1$。

#### $m = 0$（$n = 1$）：不可能

$7$ 不是 $0$ 个平方数之和（空和为 $0$）。等价地，$x^2 + 7$ 不是有理多项式的完全平方（$\sqrt{7} \notin \mathbb{Q}$）。

#### $m = 1$（$n = 2$）：不可能

$7$ 不是有理数的平方，因为 $\sqrt{7}$ 是无理数。

#### $m = 2$（$n = 3$）：不可能

**定理（两平方和判据）.** 正整数 $N$ 是两个有理平方数之和当且仅当 $N$ 的素因子分解中，每个满足 $p \equiv 3 \pmod{4}$ 的素数 $p$ 出现偶数次。

**证明 $7$ 不是两个有理平方数之和.** 假设 $7 = r_1^2 + r_2^2$，$r_i \in \mathbb{Q}$。通分得 $7q^2 = p_1^2 + p_2^2$（$p_i, q \in \mathbb{Z}$，$q > 0$）。在 $7q^2$ 的素因子分解中，$7$ 的指数为 $1 + 2v_7(q)$，恒为奇数。由两平方和判据，$7q^2$ 不是两个整数平方之和，矛盾。$\square$

#### $m = 3$（$n = 4$）：不可能

**定理（Legendre 三平方和定理）.** 正整数 $N$ 是三个整数平方之和当且仅当 $N$ **不是** $4^a(8b + 7)$ 的形式（$a, b \geq 0$）。

**证明 $7$ 不是三个有理平方数之和.** 假设 $7 = r_1^2 + r_2^2 + r_3^2$，$r_i \in \mathbb{Q}$。通分得 $7q^2 = p_1^2 + p_2^2 + p_3^2$（$p_i, q \in \mathbb{Z}$，$q > 0$）。

写 $q = 2^s \cdot q'$，$q'$ 为奇数。则

$$7q^2 = 4^s \cdot 7q'^2.$$

由于 $q'$ 奇，$q'^2 \equiv 1 \pmod{8}$，故 $7q'^2 \equiv 7 \pmod{8}$，即 $7q'^2 = 8b + 7$（某非负整数 $b$）。因此

$$7q^2 = 4^s(8b + 7),$$

恰好是 Legendre 定理中禁止的形式。故 $7q^2$ 不是三个整数平方之和，矛盾。$\square$

#### $m = 4$（$n = 5$）：可行

由 **Lagrange 四平方和定理**，每个非负整数是四个整数平方之和。具体地，

$$7 = 2^2 + 1^2 + 1^2 + 1^2.$$

因此 $7$ 是四个有理（整数）平方之和。

### 步骤四：综合

| $n$ | $m = n-1$ | $7$ 是 $m$ 个有理平方和？ | 理由 |
|-----|-----------|--------------------------|------|
| $1$ | $0$ | 否 | 空和为 $0 \neq 7$ |
| $2$ | $1$ | 否 | $\sqrt{7} \notin \mathbb{Q}$ |
| $3$ | $2$ | 否 | $7 \equiv 3 \pmod{4}$，奇次出现 |
| $4$ | $3$ | 否 | $7 = 4^0(8 \cdot 0 + 7)$，Legendre 禁止 |
| $5$ | $4$ | **是** | $7 = 4 + 1 + 1 + 1$，Lagrange |

因此最小的 $n$ 为 $\boxed{5}$。

## 证毕 $\blacksquare$
