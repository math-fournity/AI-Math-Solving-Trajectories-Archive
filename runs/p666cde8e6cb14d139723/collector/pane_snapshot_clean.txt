## Proof

**Claim:** No such group exists. If $H$ has finite index in $G$, then for every
$g \in G$, the subgroup $H \cap g^{-1}Hg$ has finite index in $G$.

**Proof.**

Suppose $[G : H] = n < \infty$. Since conjugation by $g$ is an automorphism of $
G$, the conjugate $g^{-1}Hg$ is also a subgroup of finite index $n$ in $G$.

We use the following standard fact: *if $H$ and $K$ are subgroups of finite inde
x in $G$, then $H \cap K$ has finite index in $G$, with $[G : H \cap K] \le [G :
 H]\cdot[G : K]$.*

To verify this, define the map
$$\varphi : G/(H \cap K) \longrightarrow G/H \times G/K, \qquad x(H \cap K) \lon
gmapsto (xH,\, xK).$$
This map is well-defined: if $x(H\cap K) = y(H\cap K)$, then $y^{-1}x \in H\cap
K \subseteq H \cap K$, so $xH = yH$ and $xK = yK$. It is injective: if $(xH, xK)
 = (yH, yK)$, then $y^{-1}x \in H$ and $y^{-1}x \in K$, so $y^{-1}x \in H \cap K
$, giving $x(H\cap K) = y(H\cap K)$. Therefore the number of left cosets of $H \
cap K$ in $G$ is at most $|G/H|\cdot|G/K| = [G:H]\cdot[G:K]$.

Applying this with $K = g^{-1}Hg$, both of index $n$:
$$[G : H \cap g^{-1}Hg] \le [G:H]\cdot[G:g^{-1}Hg] = n \cdot n = n^2 < \infty.$$

Hence $H \cap g^{-1}Hg$ has finite index in $G$. Since $g \in G$ was arbitrary,
there is **no** group $G$ with a finite-index subgroup $H$ and an element $g$ su
ch that $H \cap g^{-1}Hg$ has infinite index in $G$. $\blacksquare$
