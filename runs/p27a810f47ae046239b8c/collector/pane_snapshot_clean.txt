## Proof

We claim that $f(x) = \frac{x(x+1)}{2} \bmod 2^n$ is a bijection on $\{0, 1, \do
ts, 2^n-1\}$, and hence produces every value in $\{0, 1, \dots, 2^n-1\}$.

Since the domain and codomain are finite sets of the same size ($2^n$), it suffi
ces to prove **injectivity**.

**Setup.** Note that $x(x+1)$ is always even, so $T(x) = \frac{x(x+1)}{2}$ is al
ways an integer. Suppose $T(a) \equiv T(b) \pmod{2^n}$ for $a, b \in \{0, \dots,
 2^n-1\}$. Then

$$\frac{a(a+1) - b(b+1)}{2} \equiv 0 \pmod{2^n},$$

which is equivalent to

$$a(a+1) - b(b+1) \equiv 0 \pmod{2^{n+1}}.$$

Factoring:

$$a(a+1) - b(b+1) = (a-b)(a+b+1).$$

So we need $(a-b)(a+b+1) \equiv 0 \pmod{2^{n+1}}$.

**Key parity observation.** Note that

$$(a - b) + (a + b + 1) = 2a + 1,$$

which is **odd**. Therefore $a - b$ and $a + b + 1$ have **opposite parities**:
exactly one is even and the other is odd. Consequently,

$$v_2\!\big((a-b)(a+b+1)\big) = v_2(a-b) + v_2(a+b+1),$$

where exactly one of the two terms on the right is $\geq 1$ and the other is $0$
.

For the product to be divisible by $2^{n+1}$, we need $v_2\!\big((a-b)(a+b+1)\bi
g) \geq n+1$. We consider two cases:

**Case 1: $a - b$ is even** (so $a + b + 1$ is odd, $v_2(a+b+1) = 0$). Then we n
eed $v_2(a-b) \geq n+1$, i.e., $a \equiv b \pmod{2^{n+1}}$. Since $a, b \in \{0,
 \dots, 2^n-1\}$, we have $|a - b| \leq 2^n - 1 < 2^{n+1}$, so this forces $a =
b$. ✓

**Case 2: $a + b + 1$ is even** (so $a - b$ is odd, $v_2(a-b) = 0$). Then we nee
d $v_2(a+b+1) \geq n+1$, i.e., $a + b + 1 \equiv 0 \pmod{2^{n+1}}$. But since $a
, b \in \{0, \dots, 2^n - 1\}$:

$$1 \leq a + b + 1 \leq 2(2^n - 1) + 1 = 2^{n+1} - 1.$$

So $a + b + 1 \in [1,\, 2^{n+1}-1]$, which contains **no** multiple of $2^{n+1}$
 (the smallest positive multiple is $2^{n+1}$ itself, which is out of range). Th
is case is **impossible**.

**Conclusion.** Only Case 1 can occur, and it forces $a = b$. Therefore $f$ is i
njective on $\{0, 1, \dots, 2^n-1\}$, hence bijective. The function $f(x) = \fra
c{x^2 + x}{2} \bmod 2^n$ **does** produce all values from $0$ to $2^n - 1$.
