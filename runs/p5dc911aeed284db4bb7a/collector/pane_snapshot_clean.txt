## Proof

**Claim:** The desired $n$ are exactly the prime powers $n = p^a$ (prime $p$, $a
 \ge 0$, where $a=0$ gives $n=1$).

### Step 1: Reduction to primes

For $n = p_1^{a_1}\cdots p_r^{a_r}$, we have $\gcd\!\left(\binom{k}{j}, n\right)
=1$ iff $p_i \nmid \binom{k}{j}$ for every $i$ and $j$. So $k$ is good for $n$ i
ff $k$ is simultaneously good for every prime $p_i \mid n$.

### Step 2: Good $k$ for a single prime $p$ (Lucas' Theorem)

Write $k = \sum k_i p^i$, $j = \sum j_i p^i$ in base $p$. By Lucas' theorem:
$$\binom{k}{j} \equiv \prod_i \binom{k_i}{j_i} \pmod{p}.$$
Since $0 \le k_i, j_i \le p-1$, we have $p \mid \binom{k_i}{j_i}$ iff $j_i > k_i
$. So $p \nmid \binom{k}{j}$ iff $j_i \le k_i$ for all $i$.

Define the *digit box* $B(k) = \{j \ge 0 : j_i \le k_i \text{ for all } i\}$. Th
en all $\binom{k}{j}$ ($0 \le j \le k$) are coprime to $p$ iff $\{0,\ldots,k\} \
subseteq B(k)$.

Since $\max B(k) = k$ and $B(k) \subseteq \{0,\ldots,k\}$, this is equivalent to
 $B(k) = \{0,\ldots,k\}$, i.e., $|B(k)| = k+1$. Now $|B(k)| = \prod_i (k_i+1)$,
so the condition is:
$$\prod_i (k_i + 1) = k + 1. \tag{$\star$}$$

### Step 3: Solving $(\star)$

**Lemma.** $(\star)$ holds iff $k+1 = b \cdot p^m$ for some $b \in \{1,\ldots,p\
}$, $m \ge 0$ (equivalently: all base-$p$ digits of $k$ are $p-1$ except possibl
y the leading digit).

*Proof by induction on the number of digits.* Set $f(k) = \prod(k_i+1)$, $g(k) =
 k+1$.

**First**, we establish $f(k) \le g(k)$ for all $k$ (simultaneous induction). Wr
ite $k = k_0 + p\,k'$. Then $f(k) = (k_0+1)f(k')$ and $g(k) = (k_0+1) + p(g(k')-
1)$. If $f(k') \le g(k')$ (inductive hypothesis), then:
$$g(k) - f(k) = p(g(k')-1) - (k_0+1)(f(k')-1) \ge \bigl(p - (k_0+1)\bigr)(g(k')-
1) \ge 0,$$
since $k_0 \le p-1$ and $g(k') \ge 1$. ✓

**Now** the equation $f(k) = g(k)$ becomes:
$$(k_0+1)(f(k')-1) = p\,(g(k')-1). \tag{$\star\star$}$$

- **$k' = 0$:** Both sides are $0$; any $k_0$ works (single digit, $k+1 = k_0+1
= b\cdot p^0$). ✓

- **$k' > 0$, $k_0 = p-1$:** $(\star\star)$ gives $f(k') = g(k')$. By induction,
 $k'+1 = b'\,p^{m'}$ with $b' \in \{1,\ldots,p\}$. Then $k+1 = p(k'+1) = b'\,p^{
m'+1}$, which has the desired form. ✓

- **$k' > 0$, $k_0 < p-1$:** Since $f(k') \le g(k')$, we get $f(k')-1 \le g(k')-
1$, so the LHS of $(\star\star)$ satisfies $(k_0+1)(f(k')-1) \le (k_0+1)(g(k')-1
) < p(g(k')-1)$ (using $k_0+1 < p$ and $g(k')-1 > 0$). This **contradicts** $(\s
tar\star)$. No solution. ✓

This completes the induction. $\square$

### Step 4: Prime powers have infinitely many good $k$

**$n = p^a$, $a \ge 1$:** Good $k$ satisfy $k+1 = b\,p^m$, $b \in \{1,\ldots,p\}
$. Taking $b=1$ gives $k = p^m - 1$ for $m = 0, 1, 2, \ldots$ — infinitely many.

**$n = 1$:** Every $k$ works trivially. Infinitely many.

### Step 5: Numbers with $\ge 2$ prime factors have only finitely many good $k$

Let $n = p_1^{a_1}\cdots p_r^{a_r}$ with $r \ge 2$, $p_1 < p_2 < \cdots < p_r$.
Write $k+1 = Q \cdot \prod_{i=1}^r p_i^{e_i}$ with $\gcd(Q,\, p_1\cdots p_r) = 1
$. The $p_i$-free part of $k+1$ is $Q \cdot \prod_{j \ne i} p_j^{e_j}$, and by t
he Lemma this must be $\le p_i$:
$$Q \cdot \prod_{j \ne i} p_j^{e_j} \le p_i \quad \text{for all } i. \tag{$\dagg
er$}$$

**From $i=1$:** $Q \cdot \prod_{j \ge 2} p_j^{e_j} \le p_1$. Since $p_j > p_1$ f
or $j \ge 2$ and $Q \ge 1$, we get $p_j^{e_j} \le p_1 < p_j$, forcing $e_j = 0$
for all $j \ge 2$. Then $Q \le p_1$.

**From $i=2$:** $Q \cdot p_1^{e_1} \le p_2$, so $p_1^{e_1} \le p_2/Q \le p_2$, g
iving $e_1 \le \lfloor \log_{p_1} p_2 \rfloor$.

Therefore $k+1 = Q \cdot p_1^{e_1}$ where $Q \in \{1,\ldots,p_1\}$ (coprime to $
n$) and $e_1 \in \{0,\ldots,\lfloor\log_{p_1} p_2\rfloor\}$. Both $Q$ and $e_1$
range over **finite** sets, so there are only finitely many valid $k+1$, hence f
initely many good $k$.

### Conclusion

There are infinitely many $k$ with all $\binom{k}{j}$ coprime to $n$ **if and on
ly if** $n$ has at most one distinct prime factor — that is, $n$ is a prime powe
r $n = p^a$ (including $n = 1 = p^0$).
