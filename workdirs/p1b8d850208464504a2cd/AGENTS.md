# Problem

In a massive urban data center, there is a square grid of $1000 \times 1000$ server towers. Each of these $1,000,000$ towers has a unique height, ensuring no two towers are exactly the same. 

A specialized cooling module is installed on a tower only if it is "thermally balanced." A tower is considered thermally balanced if, among its immediate neighbors (those located directly North, South, East, or West), there is exactly one tower taller than itself.

A network engineer wants to maximize the efficiency of the center by installing as many cooling modules as possible. Based on the height distribution of the towers, what is the maximum number of towers that can be thermally balanced?
