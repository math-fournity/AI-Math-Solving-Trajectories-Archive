## Proof

Let
$$S_n = 1 - e^{i\varphi} + e^{2i\varphi} - \cdots + (-1)^n e^{ni\varphi} = \sum_
{k=0}^{n}(-e^{i\varphi})^k,$$
a geometric sum with ratio $r = -e^{i\varphi}$.

**Case 1: $e^{i\varphi}\neq -1$ (i.e. $\varphi\not\equiv \pi \pmod{2\pi}$).**

Then $r\neq 1$, and the geometric formula gives
$$S_n = \frac{1 - (-e^{i\varphi})^{n+1}}{1+e^{i\varphi}}.$$
Since $\left|(-e^{i\varphi})^{n+1}\right| = 1$, the numerator satisfies
$$\left|1 - (-e^{i\varphi})^{n+1}\right| \le 2,$$
so
$$|S_n| \le \frac{2}{|1+e^{i\varphi}|},$$
which is a finite constant independent of $n$ (the denominator is nonzero by ass
umption). Therefore
$$\left|\frac{S_n}{\sqrt{n}}\right| \le \frac{2}{|1+e^{i\varphi}|\,\sqrt{n}} \xr
ightarrow{n\to\infty} 0.$$
Hence
$$\lim_{n\to\infty}\frac{1}{\sqrt{n}}S_n = 0.$$

**Case 2: $e^{i\varphi} = -1$ (i.e. $\varphi\equiv\pi\pmod{2\pi}$).**

Then $e^{ki\varphi} = (-1)^k$, so each summand $(-1)^k e^{ki\varphi} = (-1)^k(-1
)^k = 1$. Thus
$$S_n = \sum_{k=0}^{n} 1 = n+1,$$
and
$$\frac{S_n}{\sqrt{n}} = \frac{n+1}{\sqrt{n}} = \sqrt{n} + \frac{1}{\sqrt{n}} \x
rightarrow{n\to\infty} +\infty.$$

**Conclusion.** The limit equals $0$ for every $\varphi\not\equiv\pi\pmod{2\pi}$
, and diverges to $+\infty$ when $\varphi\equiv\pi\pmod{2\pi}$. In particular, f
or the generic (non-degenerate) value of $\varphi$, the limit is

$$\boxed{0}.$$
