## Solution

**Setup and interpretation.** The condition "$\angle ACP = \angle CQ = 90°$" is
interpreted (resolving the evident typo) as $\angle ACP = 90°$ and $\angle CQP =
 90°$: namely $CP \perp AC$ and $PQ \perp BC$, with $P \in AB$, $Q \in BC$.

**Coordinate placement.** Place $C$ at the origin and $A = (25, 0)$ along the po
sitive $x$-axis. Since $\angle ACP = 90°$ and $CP = 20$, point $P$ lies on the $
y$-axis: $P = (0, 20)$.

**Determining $\angle A$.** Since $P \in AB$, we have $\angle PAC = \angle A$. I
n right triangle $ACP$ (right at $C$):
$$AP = \sqrt{25^2 + 20^2} = 5\sqrt{41}, \qquad \tan \angle A = \frac{CP}{AC} = \
frac{4}{5}, \qquad \angle APC = 90° - \angle A.$$

**Using $\angle APC = \angle A + \angle B$.** Since $\angle A + \angle B = 180°
- \angle C$:
$$90° - \angle A = \angle A + \angle B \implies \angle B = 90° - 2\angle A, \qqu
ad \angle C = 90° + \angle A.$$

**Locating $B$.** The line $AP$ has direction $(-25, 20)$. Write $B = (25 - 25t,
\; 20t)$ for some $t > 1$ (since $P$ lies between $A$ and $B$). Set $u = t - 1 >
 0$, so $B = (-25u,\; 20(u+1))$.

The angle at $C$ satisfies $\cos \angle C = \cos(90° + \angle A) = -\sin(\arctan
\tfrac{4}{5}) = -\tfrac{4}{\sqrt{41}}$.

Computing $\cos \angle C$ from coordinates:
$$\cos \angle C = \frac{\overrightarrow{CA}\cdot\overrightarrow{CB}}{|CA|\,|CB|}
 = \frac{25 \cdot (-25u)}{25\sqrt{625u^2 + 400(u+1)^2}} = \frac{-25u}{\sqrt{625u
^2 + 400(u+1)^2}}.$$

Setting this equal to $-4/\sqrt{41}$ and squaring:
$$\frac{625u^2}{625u^2 + 400(u+1)^2} = \frac{16}{41} \implies 15625u^2 = 6400(u+
1)^2 \implies 125u = 80(u+1),$$
giving $u = \tfrac{16}{9}$, hence $t = \tfrac{25}{9}$ and
$$B = \left(-\frac{400}{9},\; \frac{500}{9}\right).$$

**Finding $Q$.** The direction of $BC$ is $(-4, 5)$. Write $Q = sB = \left(-\tfr
ac{400s}{9},\; \tfrac{500s}{9}\right)$. The condition $PQ \perp BC$ gives $(P -
Q)\cdot(-4,5) = 0$:
$$\frac{400s}{9}\cdot(-4) + \left(20 - \frac{500s}{9}\right)\cdot 5 = 0 \implies
 -\frac{4100s}{9} + 100 = 0 \implies s = \frac{9}{41}.$$

Thus $Q = \left(-\tfrac{400}{41},\; \tfrac{500}{41}\right)$.

**Computing $PQ$.**
$$P - Q = \left(\frac{400}{41},\; 20 - \frac{500}{41}\right) = \left(\frac{400}{
41},\; \frac{320}{41}\right),$$
$$PQ = \frac{1}{41}\sqrt{400^2 + 320^2} = \frac{1}{41}\sqrt{160000 + 102400} = \
frac{\sqrt{262400}}{41} = \frac{80\sqrt{41}}{41}.$$

**Verification.** $(P-Q)\cdot(-4,5) = \tfrac{-1600+1600}{41} = 0$ ✓, confirming
$PQ \perp BC$. The angle condition $\angle APC = 90° - \arctan\tfrac{4}{5} = \an
gle A + \angle B$ is satisfied ✓.

$$\boxed{PQ = \dfrac{80\sqrt{41}}{41}}$$
