Looking at this problem, I need to determine whether the condition $\inf\{C > 0
\mid \mu\{x \in K : x > C\} = 0\} = M$ implies $\operatorname{supp}(\mu) \subset
eq [0, M]$.

**Answer: Yes.**

**Proof.**

Let $S = \{C > 0 : \mu\{x \in K : x > C\} = 0\}$, so $M = \inf S$.

**Step 1: $S$ is upward closed.** If $C \in S$ and $C' > C$, then $\{x \in K : x
 > C'\} \subseteq \{x \in K : x > C\}$, so $\mu\{x \in K : x > C'\} \leq \mu\{x
\in K : x > C\} = 0$, hence $C' \in S$.

Since $M = \inf S$ and $S$ is upward closed, every $C > M$ belongs to $S$, i.e.,
 $\mu\{x \in K : x > C\} = 0$ for all $C > M$.

**Step 2: $\mu\{x \in K : x > M\} = 0$.** Observe that
$$\{x \in K : x > M\} = \bigcup_{n=1}^{\infty} \{x \in K : x > M + \tfrac{1}{n}\
}.$$
Each set $\{x \in K : x > M + \frac{1}{n}\}$ has $\mu$-measure zero (since $M +
\frac{1}{n} > M$, so $M + \frac{1}{n} \in S$ by Step 1). By countable subadditiv
ity:
$$\mu\{x \in K : x > M\} \leq \sum_{n=1}^{\infty} \mu\{x \in K : x > M + \tfrac{
1}{n}\} = 0.$$

**Step 3: $\operatorname{supp}(\mu) \subseteq [0, M]$.** The support of $\mu$ is
 the complement (in $K$) of the largest open subset of $K$ having $\mu$-measure
zero. Equivalently, $x \in \operatorname{supp}(\mu)$ iff every open neighborhood
 of $x$ (relative to $K$) has positive $\mu$-measure.

The set $(M, \infty) \cap K$ is open in $K$ and, by Step 2, has $\mu$-measure ze
ro. Therefore it is contained in the largest open set of measure zero, so:
$$\operatorname{supp}(\mu) \subseteq K \setminus \big((M, \infty) \cap K\big) =
K \cap [0, M] \subseteq [0, M].$$

Alternatively, arguing pointwise: if $x \in K$ with $x > M$, set $\varepsilon =
\frac{x - M}{2} > 0$. Then the open neighborhood $(x - \varepsilon, x + \varepsi
lon)$ is contained in $(M, \infty)$, so $\mu\big((x - \varepsilon, x + \varepsil
on) \cap K\big) \leq \mu\big((M,\infty) \cap K\big) = 0$, which means $x \notin
\operatorname{supp}(\mu)$. Hence no point of $K$ greater than $M$ lies in the su
pport.

**Note on regularity:** The argument uses only countable subadditivity (availabl
e for any measure). The regularity hypothesis is not needed for this implication
; the conclusion holds for any Borel measure on $K$.

**Conclusion:** Yes, the condition $\inf\{C > 0 : \mu\{x \in K : x > C\} = 0\} =
 M$ implies $\operatorname{supp}(\mu) \subseteq [0, M]$.
