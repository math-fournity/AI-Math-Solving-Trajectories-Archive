**Proof.**

We work in $\operatorname{Spec} A$ equipped with the Zariski topology, whose clo
sed sets are precisely the sets of the form
$$V(I) = \{\mathfrak{q} \in \operatorname{Spec} A : I \subseteq \mathfrak{q}\}$$
for an ideal $I \subseteq A$.

We claim that the closure $\overline{\{p\}}$ of the singleton $\{p\}$ equals $V(
p)$.

**Step 1: $V(p)$ is closed and contains $p$.**

Since $p$ is an ideal, $V(p)$ is by definition a closed set. Moreover $p \subset
eq p$, so $p \in V(p)$. Hence $\overline{\{p\}} \subseteq V(p)$, as the closure
is the intersection of all closed sets containing $p$.

**Step 2: Every closed set containing $p$ contains $V(p)$.**

Let $V(I)$ be any closed set with $p \in V(I)$. By definition of $V(I)$, the con
dition $p \in V(I)$ means $I \subseteq p$. Now for any $\mathfrak{q} \in V(p)$,
we have $p \subseteq \mathfrak{q}$, so $I \subseteq p \subseteq \mathfrak{q}$, g
iving $\mathfrak{q} \in V(I)$. Thus $V(p) \subseteq V(I)$.

**Step 3: Conclusion.**

Since every closed set containing $p$ contains $V(p)$, and $V(p)$ is itself clos
ed and contains $p$, the set $V(p)$ is the smallest closed set containing $p$. T
herefore
$$\overline{\{p\}} = V(p) = \{\mathfrak{q} \in \operatorname{Spec} A : p \subset
eq \mathfrak{q}\}.$$

**Remark.** This shows that a point $p \in \operatorname{Spec} A$ is a closed po
int (i.e., $\overline{\{p\}} = \{p\}$) if and only if $p$ is a maximal ideal, si
nce $V(p) = \{p\}$ requires that no prime ideal strictly contains $p$, which is
equivalent to $p$ being maximal.
