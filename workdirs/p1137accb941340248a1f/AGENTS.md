# Problem

In a specialized logistics network, there are several possible testing configurations denoted by a capacity integer $n$, which can be any integer in the set $\{2, 3, 4, 5, 6, 7, 8, 9, 10\}$.

For a configuration $n$ to be considered "robust," it must satisfy a specific stress-test condition: for any possible selection of $n$ distinct positive integer identification codes $\{a_1, a_2, \ldots, a_n\}$, there must exist at least one pair of distinct codes $a_i$ and $a_j$ such that their "Interactions Ratio" is at least $2n - 1$. 

The Interaction Ratio for any two codes $x$ and $y$ is calculated by taking the sum of the codes, $(x + y)$, and dividing it by their greatest common divisor, $\gcd(x, y)$.

Identify all values of $n$ in the given set that result in a robust configuration, and calculate the sum of these values.
