## Solution

**Region analysis.** The projection of $D$ onto the $xy$-plane is $x^2 - 2x + y^
2 \le 0$, i.e., $(x-1)^2 + y^2 \le 1$: a disk of radius $1$ centered at $(1,0)$.
 For each $(x,y)$ in this disk, $z$ ranges from $-x^2$ to $2-x-y$.

**Setting up the integral.**
$$I = \iiint_D x\,dV = \iint_{(x-1)^2+y^2\le 1} x\bigl(2-x-y-(-x^2)\bigr)\,dx\,d
y = \iint x\bigl(x^2 - x - y + 2\bigr)\,dx\,dy.$$

**Change of variables.** Let $x = 1 + r\cos\theta$, $y = r\sin\theta$, with $0 \
le r \le 1$, $0 \le \theta \le 2\pi$, Jacobian $= r$.

Compute the inner factor:
$$x^2 - x - y + 2 = (1+r\cos\theta)^2 - (1+r\cos\theta) - r\sin\theta + 2 = 2 +
r(\cos\theta - \sin\theta) + r^2\cos^2\theta.$$

So the integrand (times Jacobian) is:
$$r(1+r\cos\theta)\bigl(2 + r(\cos\theta-\sin\theta) + r^2\cos^2\theta\bigr).$$

Expanding:
$$= 2r + r^2(3\cos\theta - \sin\theta) + r^3(2\cos^2\theta - \cos\theta\sin\thet
a) + r^4\cos^3\theta.$$

**Integrating over $\theta \in [0, 2\pi]$.** Using $\int_0^{2\pi}\cos\theta\,d\t
heta = \int_0^{2\pi}\sin\theta\,d\theta = \int_0^{2\pi}\cos\theta\sin\theta\,d\t
heta = \int_0^{2\pi}\cos^3\theta\,d\theta = 0$ and $\int_0^{2\pi}\cos^2\theta\,d
\theta = \pi$:

- $\int_0^{2\pi} 2r\,d\theta = 4\pi r$
- $\int_0^{2\pi} r^2(3\cos\theta-\sin\theta)\,d\theta = 0$
- $\int_0^{2\pi} r^3(2\cos^2\theta - \cos\theta\sin\theta)\,d\theta = 2\pi r^3$
- $\int_0^{2\pi} r^4\cos^3\theta\,d\theta = 0$

This gives $\theta$-integral $= 4\pi r + 2\pi r^3$.

**Integrating over $r \in [0,1]$:**
$$I = \int_0^1 (4\pi r + 2\pi r^3)\,dr = 4\pi\cdot\frac{1}{2} + 2\pi\cdot\frac{1
}{4} = 2\pi + \frac{\pi}{2} = \boxed{\dfrac{5\pi}{2}}.$$
