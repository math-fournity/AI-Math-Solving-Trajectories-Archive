## Proof

**Yes, such functions exist.** We construct an explicit example over the interva
l $[1, \infty)$.

### Construction

Define
$$f(x) = \frac{1}{x}, \qquad g(x) = -\frac{1}{x} + \frac{1}{x^2}.$$

Then
$$f(x) + g(x) = \frac{1}{x^2},$$
which is **not** identically zero, so the trivial case is excluded.

### Verification of the three required properties

**1. $f(x) + g(x) \neq 0$:** Since $f(x)+g(x) = 1/x^2 > 0$ for all $x \in [1,\in
fty)$, the sum is not the zero function. ✓

**2. $\int_1^\infty f(x)\,dx$ diverges:**
$$\int_1^\infty \frac{1}{x}\,dx = \lim_{R\to\infty} \ln R = +\infty.$$
The integral diverges. ✓

**3. $\int_1^\infty g(x)\,dx$ diverges:**
$$\int_1^\infty g(x)\,dx = \int_1^\infty \left(-\frac{1}{x} + \frac{1}{x^2}\righ
t)dx = \lim_{R\to\infty}\left[-\ln R + 1 - \frac{1}{R}\right] = -\infty.$$
The integral diverges (to $-\infty$). ✓

**4. $\int_1^\infty (f(x)+g(x))\,dx$ converges to a finite $L$:**
$$\int_1^\infty \frac{1}{x^2}\,dx = \lim_{R\to\infty}\left[-\frac{1}{x}\Big|_1^R
\right] = \lim_{R\to\infty}\left(1 - \frac{1}{R}\right) = 1.$$
So $L = 1$, which is finite. ✓

### Justification / Intuition

The key mechanism is **cancellation of divergent parts**. The function $f$ carri
es a divergent $+1/x$ piece; $g$ carries a divergent $-1/x$ piece. These diverge
nces cancel exactly when the functions are added, leaving only the convergent $1
/x^2$ term.

This is possible because the divergence of an improper integral is a property of
 the *individual* function, while convergence of the integral of the *sum* depen
ds only on the sum. There is no contradiction: linearity of integration ($\int(f
+g) = \int f + \int g$) holds only when **both** integrals on the right converge
. When one or both diverge, the integral of the sum is determined by the sum its
elf, which may be integrable even though the summands are not.

More generally, for any divergent $h(x)$ with $\int_a^b h = \pm\infty$ and any i
ntegrable $p(x)$ with $\int_a^b p = L$, setting $f = h + p$ and $g = -h$ gives $
f+g = p$, both $\int f$ and $\int g$ diverge, yet $\int(f+g) = L$. Our example i
s the case $h(x)=1/x$, $p(x)=1/x^2$.
