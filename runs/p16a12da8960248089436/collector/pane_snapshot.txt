## 解答

**该命题是正确的。** 以下是证明。

### 证明

设 $(Z_n)$ 是一个 Galton-Watson 过程，其后代分布 $\xi$ 满足 $\mathbb{E}[\xi] = 1
$ 且 $\mathbb{P}(\xi = 1) < 1$。固定 $k > 0$ 和正整数 $N$。我们需要证明 $\mathbb
{P}(Z_n = k \text{ 对于所有 } n \geq N) = 0$。

**第一步：$(Z_n)$ 是一个非负鞅。**

由于 $\mathbb{E}[\xi] = 1$，条件期望性质给出
$$\mathbb{E}[Z_{n+1} \mid Z_n] = Z_n \cdot \mathbb{E}[\xi] = Z_n,$$
因此 $(Z_n, \mathcal{F}_n)$ 是一个非负鞅，且 $\mathbb{E}[Z_n] = \mathbb{E}[Z_0]$
 对所有 $n$ 成立。

**第二步：$(Z_n)$ 几乎必然收敛到一个有限极限 $Z_\infty \geq 0$。**

根据鞅收敛定理，每个具有有界期望的非负鞅几乎必然收敛到一个可积的有限极限。因此 $
Z_n \to Z_\infty$ a.s.，其中 $Z_\infty \in [0, \infty)$。

**第三步：极限 $Z_\infty$ 是整数且取值于 $\{0, 1, 2, \ldots\}$ 中。**

因为每个 $Z_n$ 都是整数且 $Z_n \to Z_\infty$ a.s.，所以 $Z_\infty$ 必然是整数（
整数序列只能收敛到一个整数，且最终必然是常数）。因此，存在一个（随机）$N_0$ 使得
 $Z_n = Z_\infty$ 对于所有 $n \geq N_0$ 成立。

**第四步：灭绝几乎必然发生，即 $\mathbb{P}(Z_\infty = 0) = 1$。**

设 $f(s) = \mathbb{E}[s^\xi]$ 为后代分布的概率母函数。灭绝概率 $q$ 是 $f$ 在 $[0
,1]$ 上的最小不动点。

我们首先观察到 $\mathbb{P}(\xi = 0) > 0$。事实上，如果 $\mathbb{P}(\xi = 0) = 0$
，那么 $\xi \geq 1$ a.s.，且 $\mathbb{E}[\xi] = 1$ 将迫使 $\xi = 1$ a.s.，这与 $
\mathbb{P}(\xi = 1) < 1$ 矛盾。因此 $f(0) = \mathbb{P}(\xi = 0) > 0$。

接下来，我们计算 $f'(1) = \mathbb{E}[\xi] = 1$（临界情况）。条件 $\mathbb{P}(\xi
 = 1) < 1$ 加上 $\mathbb{E}[\xi]=1$ 意味着 $\text{Var}(\xi) > 0$，因此 $f$ 在 $s
=1$ 附近是严格凸的。由于 $f$ 在 $[0,1]$ 上是严格凸的（作为 $s^k$ 的非负组合，且
至少有两个正概率的不同 $k$ 值），$f(s)$ 的图像严格位于连接 $(0, f(0))$ 和 $(1,1)
$ 的弦上方，且在 $s \in [0,1)$ 上严格位于 $s$ 上方……

更准确地说：$f$ 是严格凸的，$f(1) = 1$，$f'(1) = 1$，且 $f(0) > 0$。对于严格凸且
可导的 $f$，$f(s) > s$ 对所有 $s \in [0, 1)$ 成立（因为 $f(1) = 1$ 且 $f'(1) = 1
$，严格凸性意味着 $f(s) > f(1) + f'(1)(s-1) = s$ 对 $s < 1$ 成立）。因此 $f$ 在
$[0,1)$ 上没有不动点，这意味着 $q = 1$：灭绝几乎必然发生。

由于 $Z_n \to Z_\infty$ a.s. 且过程灭绝 a.s.（即 $\mathbb{P}(\exists n: Z_n = 0)
 = 1$），吸收态 $0$ 给出 $Z_\infty = 0$ a.s.

**第五步：结论。**

对于 $k > 0$，事件 $\{Z_n = k \text{ 对于所有 } n \geq N\}$ 包含在 $\{Z_\infty =
 k\}$ 中。根据第四步，$\mathbb{P}(Z_\infty = k) \leq \mathbb{P}(Z_\infty > 0) =
0$。因此
$$\mathbb{P}(Z_n = k \text{ 对于所有 } n \geq N) = 0.$$

这对每个 $k > 0$ 和每个正整数 $N$ 都成立，所以该命题是**正确的**。 $\blacksquare
$
