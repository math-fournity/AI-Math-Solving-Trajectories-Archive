## Proof

**Claim:** Yes, there exists an $L^1$ function on $[0,1]$ whose essential suprem
um is attained on an uncountable set.

**Construction.** Let $F \subset [0,1]$ be a *fat Cantor set* (the Smith–Volterr
a–Cantor set), obtained by the standard iterative construction that removes, at
step $n$, an open interval of length $1/2^{2n}$ from the middle of each remainin
g interval. The set $F$ has the following properties:

1. $F$ is closed (hence measurable).
2. $F$ is nowhere dense (hence has empty interior).
3. $F$ is uncountable (it is in bijection with $\{0,1\}^{\mathbb{N}}$ via the sa
me addressing scheme as the classical Cantor set).
4. $m(F) = 1 - \sum_{n=1}^{\infty} 2^{n-1}\cdot\dfrac{1}{2^{2n}} = 1 - \sum_{n=1
}^{\infty}\dfrac{1}{2^{n+1}} = 1 - \dfrac{1}{2} = \dfrac{1}{2} > 0$.

Define $f = \chi_F$, the characteristic function of $F$:
$$f(x) = \begin{cases} 1 & x \in F, \\ 0 & x \notin F. \end{cases}$$

**$f \in L^1([0,1])$.** Since $f$ is bounded and measurable,
$$\int_0^1 |f|\,dm = m(F) = \tfrac{1}{2} < \infty.$$

**The essential supremum of $|f|$ is $1$.** Since $|f| \le 1$ everywhere, $\oper
atorname{ess\,sup}|f| \le 1$. On the other hand, $\{x : |f(x)| \ge 1\} = F$ has
positive measure ($1/2$), so for every $M < 1$ the set $\{|f| > M\}$ contains $F
$ and thus has positive measure. Hence $\operatorname{ess\,sup}|f| \ge 1$. There
fore $\operatorname{ess\,sup}|f| = 1$.

**The essential supremum is attained on an uncountable set.** The set on which $
|f|$ equals its essential supremum is
$$\{x \in [0,1] : |f(x)| = 1\} = \{x : f(x) = 1\} = F,$$
which is uncountable by property (3).

**Conclusion.** The function $f = \chi_F$, where $F$ is the Smith–Volterra–Canto
r set, is an $L^1$ function on $[0,1]$ whose essential supremum ($= 1$) is attai
ned exactly on the uncountable set $F$. Hence such a function exists. $\blacksqu
are$
