Looking at this problem, I need to find the maximum number of axis-aligned squar
es with side length $n$ and integer vertices such that any two share exactly two
 points.

## Proof

**Interpretation.** A "square" here refers to its boundary (the four sides). Two
 square boundaries sharing exactly two points is the meaningful interpretation,
since the intersection of two closed convex regions (filled squares) is convex —
 and a convex set containing two distinct points contains the entire segment bet
ween them, giving infinitely many points, never exactly two.

**Setup.** Each square is determined by its lower-left corner $(a, b) \in \mathb
b{Z}^2$, with vertices $(a,b), (a{+}n,b), (a,b{+}n), (a{+}n,b{+}n)$. For two squ
ares at $(a_1, b_1)$ and $(a_2, b_2)$, let $dx = a_2 - a_1$, $dy = b_2 - b_1$.

**Characterizing exactly-two-points intersections.** Since both squares are axis
-aligned with the same side length, boundary intersection points occur only wher
e a vertical edge of one crosses a horizontal edge of the other (or at shared ve
rtices). I analyze all cases:

- **$|dx| \geq n$ or $|dy| \geq n$:** The squares are too far apart (or touch at
 a single corner when both equal $n$). Intersection is 0 or 1 points.

- **$dx = 0$ or $dy = 0$ (with the other in $(0,n)$):** The squares share a vert
ical or horizontal edge segment — infinitely many points.

- **$|dx| = n$ or $|dy| = n$ (with the other in $(0,n)$):** An edge of one coinc
ides with part of an edge of the other — infinitely many points.

- **$0 < |dx| < n$ and $0 < |dy| < n$:** The squares partially overlap. By check
ing all vertical×horizontal edge crossings, exactly two crossing points survive.
 For example, with $0 < dx < n, 0 < dy < n$, the only crossings are $(a_1{+}n,\,
 b_1{+}dy)$ (right edge of $S_1$ meets bottom edge of $S_2$) and $(a_1{+}dx,\, b
_1{+}n)$ (top edge of $S_1$ meets left edge of $S_2$). No corners coincide (sinc
e $dx, dy \notin \{0, n\}$), so exactly **2 points**. By symmetry, this holds fo
r all sign combinations.

Thus: **two squares share exactly two points if and only if $0 < |dx| < n$ and $
0 < |dy| < n$.**

**Combinatorial reduction.** We need the maximum number of points $\{(a_i, b_i)\
} \subset \mathbb{Z}^2$ such that for every pair $i \neq j$:
$$0 < |a_i - a_j| < n \quad \text{and} \quad 0 < |b_i - b_j| < n.$$

**Upper bound.** The $a$-coordinates are distinct integers (since $|a_i - a_j| >
 0$) with all pairwise differences $< n$. So $\max_i a_i - \min_i a_i \leq n - 1
$. An interval of length $n-1$ contains at most $n$ distinct integers. Hence the
re are at most $n$ squares.

**Lower bound (construction).** Take $n$ squares with lower-left corners $(i, i)
$ for $i = 0, 1, \ldots, n-1$. For any pair $i \neq j$:
$$|a_i - a_j| = |i - j| \in \{1, 2, \ldots, n-1\}, \quad |b_i - b_j| = |i - j| \
in \{1, 2, \ldots, n-1\}.$$
Both satisfy $0 < |\cdot| < n$, so every pair shares exactly two points. This gi
ves $n$ squares.

**Verification for small $n$:**
- $n=1$: Need $0 < |dx| < 1$ with integers — impossible for pairs, so max = 1 =
$n$. ✓
- $n=2$: Need $|dx| = |dy| = 1$; two squares at $(0,0)$ and $(1,1)$ work; three
would require three distinct integers with all pairwise differences $= 1$, impos
sible. Max = 2 = $n$. ✓
- $n=3$: Three squares at $(0,0), (1,1), (2,2)$; differences are 1 or 2, all $<
3$. Max = 3 = $n$. ✓

**Conclusion.** The largest possible number of squares in a friendly set is $\bo
xed{n}$.
