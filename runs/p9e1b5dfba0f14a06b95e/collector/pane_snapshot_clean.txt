### 坐标系设置

将 $D$ 置于原点，$DA$ 沿正 $x$ 轴方向。设 $\alpha = \angle ADC$，则 $A = (8, 0)$
，$C = 3(\cos\alpha, \sin\alpha)$。

**求 $\cos\alpha$：** 由圆内接四边形 $ABCD$，$\angle ABC = 180° - \alpha$。对 $A
C$ 用余弦定理：
$$AC^2 = 73 - 48\cos\alpha = 50 + 50\cos\alpha \implies \cos\alpha = \frac{23}{9
8},\quad \sin\alpha = \frac{55\sqrt{3}}{98}.$$
于是 $AC = \frac{55}{7}$，由托勒密定理 $AC \cdot BD = AB\cdot CD + BC\cdot DA =
55$，得 $BD = 7$。

**求 $B$ 的坐标：** 圆心在 $DA$ 的中垂线 $x=4$ 上，解得圆心 $(4, \sqrt{3}/3)$，
半径 $\frac{7\sqrt{3}}{3}$。由 $BD=7, AB=5$ 解得 $B = \left(\frac{11}{2}, \frac{
5\sqrt{3}}{2}\right)$（验证 $BC=5$ ✓）。

记 $u=(1,0)$，$v=(\cos\alpha,\sin\alpha)$（单位向量），则：
$$P=(8+x)\,u,\quad Q=(3+y)\,v,\quad \text{其中 } x=AP,\; y=CQ.$$

### 关键方程推导

设 $w = Q - P$，$L = |w|$。$R$ 满足 $|R-P|=y$，$|R-Q|=x$。由两式相减：
$$(R-P)\cdot w = \frac{L^2 + y^2 - x^2}{2}.$$

垂直条件 $RB \perp PQ$ 即 $(R-B)\cdot w = 0$，亦即 $(R-P)\cdot w = (B-P)\cdot w$
。代入得：
$$L^2 + y^2 - x^2 = 2(B-P)\cdot w.$$

利用恒等式 $2(B-P)\cdot(Q-P) = |B-P|^2 + |Q-P|^2 - |B-Q|^2 = |B-P|^2 + L^2 - |B-
Q|^2$，化简得：
$$y^2 - x^2 = |B-P|^2 - |B-Q|^2. \quad (\star)$$

### 计算两个距离平方

**$|B-P|^2$：** $|B|^2 = 49$（因 $BD=7$），$|P|^2=(8+x)^2$，$B\cdot P = (8+x)\cd
ot\frac{11}{2}$：
$$|B-P|^2 = 49 + (8+x)^2 - 11(8+x) = x^2 + 5x + 25.$$

**$|B-Q|^2$：** $|Q|^2=(3+y)^2$，$B\cdot v = \frac{11}{2}\cdot\frac{23}{98} + \f
rac{5\sqrt3}{2}\cdot\frac{55\sqrt3}{98} = \frac{253+825}{196} = \frac{539}{98}$
，故 $B\cdot Q = (3+y)\cdot\frac{539}{98}$：
$$|B-Q|^2 = 49 + (3+y)^2 - 2(3+y)\cdot\frac{539}{98} = y^2 - 5y + 25.$$

（验证：$6y - \frac{539y}{49} = -5y$；$58 - \frac{1617}{49} = 25$ ✓）

### 求解

代入 $(\star)$：
$$y^2 - x^2 = (x^2 + 5x + 25) - (y^2 - 5y + 25) = x^2 + 5x - y^2 + 5y,$$
$$2y^2 - 2x^2 = 5x + 5y \implies 2(y-x)(y+x) = 5(x+y).$$

因 $x, y > 0$（$P$ 在 $A$ 外侧，$Q$ 在 $C$ 外侧），$x+y \neq 0$，故：
$$2(y - x) = 5 \implies y - x = \frac{5}{2}.$$

### 结论

$$|CQ - AP| = |y - x| = \frac{5}{2} = \frac{a}{b},\quad \gcd(5,2)=1 \implies a+b
 = 5+2 = \boxed{7}.$$
