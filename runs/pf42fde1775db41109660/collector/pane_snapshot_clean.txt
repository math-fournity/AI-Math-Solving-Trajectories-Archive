Looking at this problem, I need to find the maximum number of categories (groups
 of size ≥ 2) into which {1, 2, ..., 2013} can be partitioned, such that within
each group, every subset has an integer mean.

## Characterizing the Condition

**Lemma.** A set $S$ of $m$ distinct integers has the property that every nonemp
ty subset has an integer mean if and only if:

- **$m = 1$:** Always satisfied.
- **$m = 2$:** The two elements have the same parity (so their sum is even).
- **$m \geq 3$:** All elements are congruent modulo $\text{lcm}(2, 3, \ldots, m-
1)$, and the total sum is divisible by $m$.

**Proof of Lemma.** For any $k$-element subset to have integer mean, $k$ must di
vide the subset's sum. For $k = 2$: every pair $\{a, b\}$ requires $2 \mid (a+b)
$, so all elements share the same parity. For $3 \leq k \leq m-1$: given any two
 $k$-subsets differing in one element, their sums are both divisible by $k$, so
the swapped elements are congruent mod $k$. Since $m \geq k+1$, such swaps are a
lways possible, forcing all elements congruent mod $k$. This holds for all $k =
2, \ldots, m-1$, giving congruence mod $\text{lcm}(2,\ldots,m-1)$. For $k = m$:
the total sum must be divisible by $m$. $\square$

**Key consequence:** Every group of size $\geq 2$ must consist of elements of th
e **same parity** (from the $k=2$ condition). Therefore, odd and even numbers ca
n never be mixed in a group.

## Counting and Partitioning

In $\{1, 2, \ldots, 2013\}$:
- **Odd numbers:** $1, 3, 5, \ldots, 2013$ → **1007** numbers
- **Even numbers:** $2, 4, 6, \ldots, 2012$ → **1006** numbers

Since all groups must be single-parity, we partition the odds among themselves a
nd the evens among themselves.

**Evens (1006 elements):** $1006 = 2 \times 503$, so we form **503 pairs** of ev
en numbers. Each pair has the same parity (both even), satisfying the condition.
 ✓

**Odds (1007 elements):** $1007 = 2 \times 503 + 1$. We cannot partition into pa
irs alone (one element remains). We form **502 pairs** + **1 triple** = **503 gr
oups**. The triple must consist of three odd numbers with sum divisible by 3.

**Constructing the triple:** Take $\{1, 7, 13\}$. All are odd ✓. Sum $= 21 = 3 \
times 7$ ✓. So the triple $\{1, 7, 13\}$ satisfies the condition.

**Remaining odds:** After removing $\{1, 7, 13\}$, we have 1004 odd numbers: $\{
3, 5, 9, 11, 15, 17, \ldots, 2013\}$. Pair them as $(3,5), (9,11), (15,17), \ldo
ts, (2011, 2013)$ — that's **502 pairs**, each with the same parity. ✓

## Total Count

$$1 \text{ (triple)} + 502 \text{ (odd pairs)} + 503 \text{ (even pairs)} = \box
ed{1006} \text{ categories}$$

## Upper Bound: 1007 is Impossible

Any category must contain at least 2 crates. With 1007 categories, we would need
 at least $2 \times 1007 = 2014$ crates, but we only have 2013. Therefore, 1007
categories is impossible, and **1006 is the maximum**.
