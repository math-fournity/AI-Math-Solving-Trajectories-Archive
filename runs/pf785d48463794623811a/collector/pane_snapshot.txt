# Helmholtz–Hodge Decomposition Theorem

## Statement

**Theorem (Helmholtz–Hodge Decomposition).** Let $\Omega \subset \mathbb{R}^3$ b
e a bounded open region with smooth boundary $\partial\Omega$ and outer unit nor
mal $N$. Let $X \in C^\infty(\overline{\Omega}, \mathbb{R}^3)$ be a smooth vecto
r field. Then $X$ admits the **orthogonal decomposition**

$$X = \nabla\varphi + \nabla\times A + H,$$

where:

- $\varphi \in C^\infty(\overline{\Omega})$ is a scalar potential (the **irrotat
ional** / **gradient** part, $\nabla\times(\nabla\varphi)=0$);
- $A \in C^\infty(\overline{\Omega},\mathbb{R}^3)$ is a vector potential (the **
solenoidal** / **curl** part, $\nabla\cdot(\nabla\times A)=0$);
- $H$ is a **harmonic** vector field: $\nabla\times H = 0$, $\nabla\cdot H = 0$,
 with $H\cdot N|_{\partial\Omega}=0$.

The three components are mutually $L^2$-orthogonal, and the decomposition is uni
que up to the choice of gauge (adding a constant to $\varphi$, or a gradient to
$A$).

Equivalently, defining the function spaces

$$G = \{\nabla\varphi : \varphi\in C^\infty(\overline\Omega)\},\qquad C = \{\nab
la\times A : A\in C^\infty(\overline\Omega,\mathbb R^3),\; (\nabla\times A)\cdot
 N|_{\partial\Omega}=0\},$$

$$\mathcal H = \{H\in C^\infty(\overline\Omega,\mathbb R^3) : \nabla\times H=0,\
;\nabla\cdot H=0,\; H\cdot N|_{\partial\Omega}=0\},$$

we have the **$L^2$-orthogonal direct sum**

$$L^2(\Omega,\mathbb R^3) = G \oplus C \oplus \mathcal H.$$

## Derivation / Proof

### Step 1. Reduction to a Poisson problem

We seek $\varphi$ such that the residual $Y := X - \nabla\varphi$ is divergence-
free and tangent to the boundary:

$$\nabla\cdot Y = 0,\qquad Y\cdot N\big|_{\partial\Omega}=0.$$

Since $\nabla\cdot Y = \nabla\cdot X - \Delta\varphi$, these conditions become t
he **Neumann problem**

$$\Delta\varphi = \nabla\cdot X \quad\text{in }\Omega,\qquad \frac{\partial\varp
hi}{\partial N} = X\cdot N \quad\text{on }\partial\Omega.$$

### Step 2. Solvability of the Neumann problem

By the divergence theorem,

$$\int_\Omega \nabla\cdot X\,dV = \int_{\partial\Omega} X\cdot N\,dS = \int_{\pa
rtial\Omega}\frac{\partial\varphi}{\partial N}\,dS = \int_\Omega \Delta\varphi\,
dV.$$

So the **compatibility condition** for the Neumann problem is automatically sati
sfied:

$$\int_\Omega \nabla\cdot X\,dV = \int_{\partial\Omega} X\cdot N\,dS.$$

By elliptic regularity theory for the Neumann Laplacian on a smooth bounded doma
in, there exists a solution $\varphi\in C^\infty(\overline\Omega)$, unique up to
 an additive constant. Set

$$Y := X - \nabla\varphi.$$

Then $\nabla\cdot Y = 0$ in $\Omega$ and $Y\cdot N = 0$ on $\partial\Omega$.

### Step 3. Splitting the divergence-free field into a curl plus a harmonic fiel
d

It remains to show that a smooth divergence-free field $Y$ with $Y\cdot N|_{\par
tial\Omega}=0$ decomposes as

$$Y = \nabla\times A + H,$$

where $H$ is harmonic ($\nabla\times H=0$, $\nabla\cdot H=0$, $H\cdot N|_{\parti
al\Omega}=0$).

Consider the **vector Poisson problem**: find $A$ with

$$\nabla\times(\nabla\times A) = \nabla\times Y \quad\text{in }\Omega,\qquad (\n
abla\times A)\cdot N\big|_{\partial\Omega} = 0,\qquad (\nabla\times A)\times N\b
ig|_{\partial\Omega} = Y\times N.$$

Using the identity $\nabla\times(\nabla\times A) = \nabla(\nabla\cdot A) - \Delt
a A$ and fixing the **Coulomb gauge** $\nabla\cdot A = 0$, this reduces to the c
omponent-wise Poisson problem

$$-\Delta A = \nabla\times Y \quad\text{in }\Omega,\qquad \nabla\cdot A = 0,$$

with appropriate boundary conditions. Elliptic theory (the boundary conditions a
bove are of elliptic type — they are the "magnetic" boundary conditions) guarant
ees a smooth solution $A$.

Define $Z := \nabla\times A$. Then:

- $\nabla\cdot Z = \nabla\cdot(\nabla\times A) = 0$ identically;
- $Z\cdot N|_{\partial\Omega} = 0$ by construction;
- $\nabla\times Z = \nabla\times(\nabla\times A) = \nabla\times Y$.

Set

$$H := Y - Z = Y - \nabla\times A.$$

Then:

- $\nabla\cdot H = \nabla\cdot Y - \nabla\cdot Z = 0 - 0 = 0$;
- $\nabla\times H = \nabla\times Y - \nabla\times Z = \nabla\times Y - \nabla\ti
mes Y = 0$;
- $H\cdot N|_{\partial\Omega} = Y\cdot N - Z\cdot N = 0 - 0 = 0$.

So $H$ is a **harmonic vector field** (curl-free, divergence-free, tangent to th
e boundary). Combining,

$$\boxed{X = \nabla\varphi + \nabla\times A + H.}$$

### Step 4. Orthogonality of the three components

We verify $L^2$-orthogonality using integration by parts (Green's identities).

**(a) $\nabla\varphi \perp \nabla\times A$:**

$$\int_\Omega \nabla\varphi\cdot(\nabla\times A)\,dV = \int_\Omega \nabla\cdot(\
varphi\,\nabla\times A)\,dV - \int_\Omega \varphi\,\underbrace{\nabla\cdot(\nabl
a\times A)}_{=\,0}\,dV = \int_{\partial\Omega}\varphi\,(\nabla\times A)\cdot N\,
dS = 0,$$

since $(\nabla\times A)\cdot N|_{\partial\Omega}=0$.

**(b) $\nabla\varphi \perp H$:**

$$\int_\Omega \nabla\varphi\cdot H\,dV = \int_{\partial\Omega}\varphi\,H\cdot N\
,dS - \int_\Omega\varphi\,\underbrace{\nabla\cdot H}_{=\,0}\,dV = 0,$$

since $H\cdot N|_{\partial\Omega}=0$.

**(c) $\nabla\times A \perp H$:**

$$\int_\Omega (\nabla\times A)\cdot H\,dV = \int_\Omega (\nabla\times A)\cdot\un
derbrace{(\nabla\times \Psi)}_{\text{locally, since }\nabla\times H=0 \Rightarro
w H=\nabla\times\Psi\text{ on simply-connected patches}}\,dV.$$

More directly, using the vector identity $\nabla\cdot(A\times H) = H\cdot(\nabla
\times A) - A\cdot(\nabla\times H)$ and $\nabla\times H = 0$:

$$\int_\Omega (\nabla\times A)\cdot H\,dV = \int_\Omega \nabla\cdot(A\times H)\,
dV = \int_{\partial\Omega}(A\times H)\cdot N\,dS = \int_{\partial\Omega} A\cdot(
H\times N)\,dS.$$

Since $H\cdot N=0$ on $\partial\Omega$, the tangential component $H\times N$ lie
s in the boundary, and combined with the boundary condition $(\nabla\times A)\ti
mes N = Y\times N$ (which forces $H\times N = 0$ on $\partial\Omega$), we get

$$\int_\Omega (\nabla\times A)\cdot H\,dV = 0.$$

Hence the three subspaces $G$, $C$, $\mathcal H$ are **mutually $L^2$-orthogonal
**.

### Step 5. Uniqueness

Suppose $X = \nabla\varphi_1 + \nabla\times A_1 + H_1 = \nabla\varphi_2 + \nabla
\times A_2 + H_2$. Then

$$\nabla(\varphi_1-\varphi_2) + \nabla\times(A_1-A_2) + (H_1-H_2) = 0.$$

By orthogonality, each term is $L^2$-orthogonal to the sum of the other two, so
each must vanish:

$$\nabla(\varphi_1-\varphi_2)=0,\quad \nabla\times(A_1-A_2)=0,\quad H_1=H_2.$$

Thus $\varphi_1-\varphi_2 = \text{const}$, and $\nabla\times(A_1-A_2)=0$ means $
A_1-A_2$ is a gradient (gauge freedom). This establishes uniqueness up to gauge.
 $\blacksquare$

### Summary

| Component | Property | Space |
|---|---|---|
| $\nabla\varphi$ | curl-free (irrotational) | $G$ |
| $\nabla\times A$ | divergence-free, tangent (solenoidal) | $C$ |
| $H$ | both curl- and divergence-free, tangent (harmonic) | $\mathcal H$ |

The key ingredients are: (1) the **Neumann Poisson problem** to extract the grad
ient part (its compatibility condition is automatic by the divergence theorem);
(2) the **vector Poisson problem** in Coulomb gauge to extract the curl part; (3
) the **harmonic remainder** $H$; and (4) **Green's identities** establishing $L
^2$-orthogonality, which yields uniqueness.
