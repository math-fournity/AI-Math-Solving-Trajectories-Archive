## Solution

**Factorization.** $2013 = 3 \times 671 = 3 \times 11 \times 61$. Since $2013$ i
s squarefree, its divisors are
$$1,\;3,\;11,\;33,\;61,\;183,\;671,\;2013.$$
(Note: the problem mentions "16 stations," but $2013 = 3\cdot 11\cdot 61$ has ex
actly $2^3 = 8$ divisors. The sum $\sum_{n\mid 2013}$ ranges over these 8 diviso
rs regardless.)

**A formula for $s(n)$.** Using Möbius inversion,
$$s(n)=\sum_{\substack{1\le k\le n\\\gcd(k,n)=1}}k^2=\sum_{d\mid n}\mu(d)\,d^2\s
um_{j=1}^{n/d}j^2=\sum_{d\mid n}\mu(d)\,\frac{n(n+d)(2n+d)}{6d}.$$
Expanding $\frac{(n+d)(2n+d)}{d}=\frac{2n^2}{d}+3n+d$ and using
$$\sum_{d\mid n}\frac{\mu(d)}{d}=\frac{\phi(n)}{n},\quad \sum_{d\mid n}\mu(d)=[n
=1],\quad \sum_{d\mid n}\mu(d)d=\prod_{p\mid n}(1-p),$$
we get
$$s(n)=\frac{n}{6}\Bigl(2n\,\phi(n)+3n\,[n=1]+\prod_{p\mid n}(1-p)\Bigr).$$
For **squarefree** $n>1$, $\phi(n)=\prod_{p\mid n}(p-1)$ and $\prod_{p\mid n}(1-
p)=(-1)^{\omega(n)}\phi(n)$, so
$$\frac{s(n)}{n^2}=\frac{\phi(n)}{3}+\frac{(-1)^{\omega(n)}\phi(n)}{6n}=\frac{\p
hi(n)\bigl(2n+(-1)^{\omega(n)}\bigr)}{6n},\qquad n>1,$$
and $s(1)/1^2 = 1$.

**Computing each term.** Let $\omega(n)$ = number of prime factors.

| $n$ | $\phi(n)$ | $\omega$ | $\frac{s(n)}{n^2}$ |
|-----|-----------|----------|---------------------|
| $1$ | $1$ | $0$ | $1$ |
| $3$ | $2$ | $1$ | $\frac{2(6-1)}{18}=\frac{5}{9}$ |
| $11$ | $10$ | $1$ | $\frac{10(22-1)}{66}=\frac{35}{11}$ |
| $33$ | $20$ | $2$ | $\frac{20(66+1)}{198}=\frac{670}{99}$ |
| $61$ | $60$ | $1$ | $\frac{60(122-1)}{366}=\frac{1210}{61}$ |
| $183$ | $120$ | $2$ | $\frac{120(366+1)}{1098}=\frac{7340}{183}$ |
| $671$ | $600$ | $2$ | $\frac{600(1342+1)}{4026}=\frac{134300}{671}$ |
| $2013$ | $1200$ | $3$ | $\frac{1200(4026-1)}{12078}=\frac{805000}{2013}$ |

**Summing.** The common denominator is $\mathrm{lcm}(1,9,11,99,61,183,671,2013)=
3^2\cdot 11\cdot 61=6039$. Converting:

$$S=\frac{6039+3355+19215+40870+119790+242220+1208700+2415000}{6039}=\frac{40551
89}{6039}.$$

**Floor.** Dividing,
$$6039\times 671 = 4052169,\qquad 4055189-4052169 = 3020.$$
Hence
$$S = 671 + \frac{3020}{6039}.$$
Since $6039/2 = 3019.5 < 3020 < 6039$, we have $0.5 < \frac{3020}{6039} < 1$, so
$$671.5 < S < 672.$$

Therefore the greatest integer not exceeding the total system performance value
is

$$\boxed{671}.$$
