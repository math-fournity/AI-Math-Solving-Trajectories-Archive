## Asymptotic Expansion via Laplace's Method

Let $a = \pi/2$. The integral $I_r(f) = \int_0^a x^r f(x)\,dx$ is dominated by t

**Substitution:** Set $x = a(1-s)$, then $s = u/r$:

$$I_r(f) = \frac{a^{r+1}}{r}\int_0^r (1-u/r)^r\, f(a - au/r)\,du$$

**Expansions for large $r$:**
- $(1-u/r)^r = e^{-u}\left(1 - \frac{u^2}{2r} + O(r^{-2})\right)$
- $f(a - au/r) = f(a) - \frac{au\,f'(a)}{r} + O(r^{-2})$

## Applying to Each Integral

**Sine integral** ($f = \sin$, $f(a)=\sin(\pi/2)=1$, $f'(a)=\cos(\pi/2)=0$):

$$I_r(\sin) = \frac{a^{r+1}}{r}\left(1 - \frac{1}{r} + O(r^{-2})\right)$$

**Cosine integral** ($f = \cos$, $f(a)=\cos(\pi/2)=0$, $f'(a)=-\sin(\pi/2)=-1$):

The leading term vanishes, so the next term dominates:

$$I_r(\cos) = \frac{a^{r+1}}{r}\left(\frac{0 + a\cdot 1}{r} + O(r^{-2})\right) =

## Computing the Ratio

## Determining $C$ and $L$

The full expression is:

$$\frac{r^C\, I_r(\sin)}{I_r(\cos)} = r^C\left(\frac{r}{a} - \frac{1}{a} + O(r^{

$$C + 1 = 0 \implies C = -1$$

So $L = \dfrac{2}{\pi}$ and $C = -1$.

$$\pi L - C = \pi \cdot \frac{2}{\pi} - (-1) = 2 + 1 = \boxed{3}$$
