## Proof

Let $(S_n)$ be a simple symmetric random walk on $\mathbb{Z}$ with $S_0 = 0$, so
 $S_{n+1} = S_n + X_{n+1}$ where $X_{n+1} = \pm 1$ each with probability $\tfrac
{1}{2}$, independent of $F_n$. The key moments are $E[X_{n+1}\mid F_n]=0$, $E[X_
{n+1}^2\mid F_n]=1$, $E[X_{n+1}^3\mid F_n]=0$.

**Martingale condition.** We require $E[Y_{n+1}\mid F_n]=Y_n$. Expanding:

$$Y_{n+1}=(S_n+X_{n+1})^3+\alpha_{n+1}(S_n+X_{n+1})$$
$$=S_n^3+3S_n^2X_{n+1}+3S_nX_{n+1}^2+X_{n+1}^3+\alpha_{n+1}S_n+\alpha_{n+1}X_{n+
1}.$$

Taking conditional expectation and using the moments above:

$$E[Y_{n+1}\mid F_n]=S_n^3+3S_n+\alpha_{n+1}S_n=S_n^3+(3+\alpha_{n+1})S_n.$$

For this to equal $Y_n=S_n^3+\alpha_n S_n$ for every value of $S_n$, we need

$$\alpha_n = 3+\alpha_{n+1},\qquad\text{i.e.,}\qquad \alpha_{n+1}=\alpha_n-3.$$

**Solving the recurrence.** This first-order linear recurrence gives

$$\alpha_n = \alpha_0 - 3n.$$

**Determining $\alpha_0$.** At $n=0$, $S_0=0$, so $Y_0 = 0^3+\alpha_0\cdot 0 = 0
$ regardless of $\alpha_0$. Thus $\alpha_0$ is a free parameter, and the general
 family of solutions is

$$\alpha_n = c - 3n,\qquad c\in\mathbb{R}.$$

The canonical choice $c=0$ (so that $\alpha_0=0$) yields the clean solution.

**Verification.** With $\alpha_n=-3n$, i.e. $Y_n=S_n^3-3nS_n$:

$$E[Y_{n+1}\mid F_n]=S_n^3+(3-3(n+1))S_n=S_n^3-3nS_n=Y_n.\ \checkmark$$

Integrability is immediate since $S_n$ is bounded by $n$ in absolute value, so $
|Y_n|\le n^3+3n\cdot n<\infty$. Adaptedness holds since $Y_n$ is $F_n$-measurabl
e.

## Answer

$$\boxed{\alpha_n = -3n}$$

(equivalently, the general family $\alpha_n = c-3n$ for any constant $c\in\mathb
b{R}$; the canonical choice is $c=0$.)
