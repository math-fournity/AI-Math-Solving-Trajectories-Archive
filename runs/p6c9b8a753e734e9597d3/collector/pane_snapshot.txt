## Proof

**Yes**, such a function exists. We prove this via the Baire Category Theorem.

### Setup

Let $X = C^\infty(\mathbb{R})$ with the Fréchet topology of uniform convergence
of all derivatives on compact sets, generated by seminorms $p_{m,n}(f) = \sup_{|
x|\le n}|f^{(m)}(x)|$. This is a complete metrizable topological vector space, h
ence a **Baire space**.

**Key observation.** If $f$ is analytic at some $x_0\in\mathbb{R}$, then $f$ is
analytic on an open neighborhood of $x_0$, which contains a rational. So: *not a
nalytic at any rational $\Rightarrow$ not analytic at any point.*

### Defining the bad sets

For $q\in\mathbb{Q}$, $n,N\in\mathbb{N}$, define:
$$E(q,n,N)=\bigl\{f\in X:\ |f^{(k)}(q)|\le N\,k!\,n^k\ \text{for all }k\ge0\bigr
\}.$$

**Claim 1.** *If $f$ is analytic at $q$, then $f\in E(q,n,N)$ for some $n,N$.*

If $f$ is analytic at $q$ with radius $\rho>0$, then for any $R<\rho$, Cauchy es
timates give $|f^{(k)}(q)|\le M\,k!/R^k$. Pick integer $n>1/R$ and $N\ge M$; the
n $|f^{(k)}(q)|\le M\,k!/R^k\le M\,k!\,n^k\le N\,k!\,n^k$. $\square$

So the set of functions analytic at $q$ is contained in $\bigcup_{n,N}E(q,n,N)$.

**Claim 2.** *Each $E(q,n,N)$ is closed.*

The map $f\mapsto f^{(k)}(q)$ is continuous on $X$ (since $|f^{(k)}(q)|\le p_{k,
n_0}(f)$ for $n_0>|q|$). Each condition $|f^{(k)}(q)|\le Nk!n^k$ defines a close
d set; $E(q,n,N)$ is their intersection. $\square$

**Claim 3.** *Each $E(q,n,N)$ has empty interior.*

Let $f\in E(q,n,N)$ and $U$ any neighborhood of $f$. Then $U$ contains a basic n
eighborhood
$$U_0=\{g:\ p_{m_j,\ell_j}(g-f)<\varepsilon_j,\ j=1,\dots,J\}.$$
Set $m^*=\max(m_1,\dots,m_J)$ and pick an integer $K>m^*$.

Let $\eta\in C_c^\infty(\mathbb{R})$ with $\eta(0)=1$, $\operatorname{supp}(\eta
)\subseteq[-1,1]$. For $\delta>0$ define:
$$\psi_\delta(x)=\Bigl(\frac{x-q}{\delta}\Bigr)^K\eta\!\Bigl(\frac{x-q}{\delta}\
Bigr),\qquad \operatorname{supp}(\psi_\delta)\subseteq[q-\delta,\,q+\delta].$$

**Derivatives at $q$:** By Leibniz, for $j<K$, $\psi_\delta^{(j)}(q)=0$ (each te
rm contains a factor $(x-q)^{K-\ell}$ with $K-\ell>0$). For $j=K$:
$$\psi_\delta^{(K)}(q)=\frac{K!}{\delta^K}\,\eta(0)=\frac{K!}{\delta^K}.$$

**Seminorm bounds:** On $\operatorname{supp}(\psi_\delta)$, $|x-q|\le\delta$, so
 $|\psi_\delta^{(m_j)}(x)|\le C_j\,\delta^{-m_j}$ for constants $C_j$ independen
t of $\delta$. Thus $p_{m_j,\ell_j}(\psi_\delta)\le C_j\delta^{-m_j}$ for small
$\delta$.

**Perturbation:** Set $g=f+\alpha\psi_\delta$ with $\alpha=c\,\delta^{m^*}$, whe
re $c<\min_j(\varepsilon_j/C_j)$.

*Proximity:* $p_{m_j,\ell_j}(g-f)\le c\,C_j\,\delta^{m^*-m_j}\le c\,C_j<\varepsi
lon_j$, so $g\in U_0\subseteq U$.

*Escape:* $g^{(K)}(q)=f^{(K)}(q)+c\,K!\,\delta^{m^*-K}$. Since $K>m^*$, the expo
nent $m^*-K<0$, so $\delta^{m^*-K}\to\infty$ as $\delta\to0$. Since $|f^{(K)}(q)
|\le N\,K!\,n^K$, for $\delta$ small enough:
$$|g^{(K)}(q)|\ge c\,K!\,\delta^{m^*-K}-N\,K!\,n^K>N\,K!\,n^K.$$
Hence $g\notin E(q,n,N)$, proving empty interior. $\square$

### Conclusion

For each rational $q$, the set of functions analytic at $q$ is contained in the
meager set $\bigcup_{n,N}E(q,n,N)$ (countable union of closed, nowhere-dense set
s). The set of functions analytic at *some* point of $\mathbb{R}$ is contained i
n
$$\bigcup_{q\in\mathbb{Q}}\bigcup_{n,N}E(q,n,N),$$
a countable union of meager sets, hence **meager**.

Since $X=C^\infty(\mathbb{R})$ is a Baire space, it cannot be meager in itself.
Therefore there exists $f\in C^\infty(\mathbb{R})$ belonging to no $E(q,n,N)$ fo
r any rational $q$. By Claim 1, $f$ is not analytic at any rational; by the key
observation, $f$ is **not analytic at any point** of $\mathbb{R}$.

Thus, there exists a smooth ($C^\infty$) real-valued function on $\mathbb{R}$ th
at is nowhere analytic. $\blacksquare$
