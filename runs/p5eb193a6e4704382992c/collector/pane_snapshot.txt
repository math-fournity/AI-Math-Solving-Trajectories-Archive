## Solution

I need to count paths from (0,0) to (5,5) using moves E=(1,0), N=(0,1), D=(1,1),
 where E and N can never be adjacent in the sequence (no E→N or N→E transitions)
. D can transition freely with anything.

### Dynamic Programming Setup

Define `f(a, b, last)` = number of valid sequences completing displacement (a,b)
, given the previous move was `last`:

- **After E**: next move ∈ {E, D} (N forbidden)
- **After N**: next move ∈ {N, D} (E forbidden)
- **After D or Start**: next move ∈ {E, N, D}

Recurrences (with `[P]` = 1 if P true, else 0):

```
E(a,b) = [a≥1]·E(a-1,b) + [a≥1∧b≥1]·D(a-1,b-1)
N(a,b) = [b≥1]·N(a,b-1) + [a≥1∧b≥1]·D(a-1,b-1)
D(a,b) = [a≥1]·E(a-1,b) + [b≥1]·N(a,b-1) + [a≥1∧b≥1]·D(a-1,b-1)
```

Base case: `E(0,0) = N(0,0) = D(0,0) = 1`. The answer is `D(5,5)` (Start has sam
e transitions as D).

By symmetry: `E(a,b) = N(b,a)` and `D(a,b) = D(b,a)`.
