## Proof

The problem is purely combinatorial (the "no 4 coplanar" condition is irrelevant
 to the labeling). Let $f(n)$ denote the minimum good $m$ for $n$ points.

### Lower Bound: $f(n) \geq \lceil \log_2 n \rceil$

Consider any valid labeling of $K_n$ using labels in $\{1, \ldots, M\}$, where $
M$ is the maximum label used.

**Claim 1: Edges with label $M$ form a matching.**
If edges $(i,j)$ and $(i,k)$ both have label $M$, then in triangle $\{i,j,k\}$,
two sides equal $M$, so the third must be $> M$—contradicting maximality of $M$.

**Claim 2 (Twin property):** If $(i,j)$ has label $M$, then for every other poin
t $k$: $w(i,k) = w(j,k) < M$.
In triangle $\{i,j,k\}$, edge $(i,j) = M$ is the unique maximum (by Claim 1, no
other edge in this triangle has label $M$), so it is the "larger" side, forcing
$w(i,k) = w(j,k) < M$.

**Claim 3 (Contraction):** The $M$-labeled edges pair up at most $\lfloor n/2 \r
floor$ pairs of twin points. Identifying each pair into a single vertex yields $
\lceil n/2 \rceil$ vertices. By the twin property, the induced labeling is well-
defined, uses labels in $\{1, \ldots, M-1\}$, and satisfies the triangle conditi
on. Hence:
$$f\!\left(\lceil n/2 \rceil\right) \leq M - 1 \implies M \geq 1 + f\!\left(\lce
il n/2 \rceil\right).$$

With $f(1) = 0$, $f(2) = 1$, this recurrence gives $f(n) \geq \lceil \log_2 n \r
ceil$.

### Upper Bound: $f(n) \leq \lceil \log_2 n \rceil$

**Construction (recursive):** Given $n$ points:
- **Base:** $n \leq 2$: label the single edge (if any) with $1$.
- **Step:** Pair points into $\lfloor n/2 \rfloor$ pairs (at most 1 unpaired). A
ssign label $M = 1 + f(\lceil n/2 \rceil)$ to each pair-edge. Recursively label
the $\lceil n/2 \rceil$ contracted points using labels $\{1, \ldots, M-1\}$. For
 each pair $(a,b)$ and any other point $p$, set $w(a,p) = w(b,p)$ to the corresp
onding contracted-edge label.

**Verification:**
- Triangle $\{a, b, p\}$ where $(a,b)$ is a pair: $w(a,b) = M$ (larger), $w(a,p)
 = w(b,p) < M$ (equal). ✓
- Any other triangle corresponds to a triangle in the contracted graph, valid by
 induction. ✓

This achieves $f(n) = 1 + f(\lceil n/2 \rceil) = \lceil \log_2 n \rceil$.

### Computation for $n = 2006$

$$f(2006) = 1 + f(1003) = 2 + f(502) = 3 + f(251) = 4 + f(126) = 5 + f(63)$$
$$= 6 + f(32) = 7 + f(16) = 8 + f(8) = 9 + f(4) = 10 + f(2) = 11.$$

Indeed $2^{10} = 1024 < 2006 \leq 2048 = 2^{11}$, so $\lceil \log_2 2006 \rceil
= 11$.

### Conclusion

The minimum good number is $\boxed{11}$.
