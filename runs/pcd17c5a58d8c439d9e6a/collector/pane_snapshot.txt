Proof

Setup. Let $X \in \mathbb{R}^{n\times n}$ be full rank and $A \in \mathbb{R}
^{m\times n}$ be full rank with $m \le n$. Define

$$f(A) = \det!\bigl(X - XA'(AXA')^{-1}AX\bigr).$$

Since $A$ has full row rank $m$ and $X$ is invertible, the $m\times m$ matrix
$AXA'$ is invertible, so the expression is well-defined.

Step 1: Factor out $X$. Set

$$P := XA'(AXA')^{-1}A ;\in; \mathbb{R}^{n\times n}.$$

Then $XA'(AXA')^{-1}AX = PX$, so

$$X - XA'(AXA')^{-1}AX = X - PX = (I - P),X.$$

Hence

$$f(A) = \det\bigl((I-P),X\bigr) = \det(I - P),\det(X).$$

Step 2: $P$ is idempotent (a projection). Compute:

$$P^2 = XA'(AXA')^{-1}A;\cdot;XA'(AXA')^{-1}A = XA'(AXA')^{-1}\underbrace{(AXA')
(AXA')^{-1}}_{I_m}A = XA'(AXA')^{-1}A = P.$$

So $P$ is idempotent.

Step 3: $\operatorname{rank}(P) = m$. Since $X$ is invertible,

$$\operatorname{rank}(P) = \operatorname{rank}!\bigl(A'(AXA')^{-1}A\bigr).$$

The matrix $A$ ($m\times n$) has full row rank $m$, $(AXA')^{-1}$ ($m\times m$)
is invertible, and $A'$ ($n\times m$) has full column rank $m$. The product of a
full-column-rank $n\times m$ matrix, an invertible $m\times m$ matrix, and a
full-row-rank $m\times n$ matrix has rank $m$. Therefore $\operatorname{rank}(P)
= m$.

Step 4: $\det(I - P) = 0$. An idempotent matrix has all eigenvalues in ${0,1}$,
with the number of eigenvalue-1 entries equal to $\operatorname{rank}(P) = m$.
Thus $I - P$ is also idempotent with eigenvalues in ${0,1}$, having exactly $n -
m$ eigenvalues equal to $1$ and $m$ eigenvalues equal to $0$.

Since $A$ is $m \times n$ full rank with $m \le n$ and the problem is non-
degenerate ($m \ge 1$), we have $m \ge 1$, so $I - P$ has at least one zero
eigenvalue. Therefore

$$\det(I - P) = 0.$$

Step 5: $f(A)$ is identically zero. Combining Steps 1 and 4:

$$f(A) = \det(I - P),\det(X) = 0 \cdot \det(X) = 0 \quad \text{for all valid }
A.$$

Step 6: The derivative. Since $f(A) = 0$ for every admissible $A$, $f$ is a
constant (zero) function of $A$. Therefore its derivative vanishes identically:

$$\boxed{\dfrac{\partial \det!\bigl(X - XA'(AXA')^{-1}AX\bigr)}{\partial A} ;=;
\mathbf{0}_{m\times n}.}$$
