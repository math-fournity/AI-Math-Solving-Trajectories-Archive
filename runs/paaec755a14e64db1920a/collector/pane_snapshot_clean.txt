We find all $(x, y) \in \mathbb{Z}^2$ satisfying $x^3 - y^3 = 2xy + 8$.

**Substitution.** Set $k = x - y \in \mathbb{Z}$, so $x = y + k$. Then

$$x^3 - y^3 = (y+k)^3 - y^3 = 3k y^2 + 3k^2 y + k^3,$$

$$2xy + 8 = 2(y+k)y + 8 = 2y^2 + 2ky + 8.$$

Equating and collecting terms in $y$:

$$(3k - 2)\,y^2 + (3k^2 - 2k)\,y + (k^3 - 8) = 0. \tag{$\star$}$$

This is a quadratic in $y$ (for $k \neq 2/3$, which is automatic since $k \in \m
athbb{Z}$). For integer solutions $y$ to exist, the discriminant must be a non-n
egative perfect square.

**Discriminant.**

$$\Delta(k) = (3k^2 - 2k)^2 - 4(3k-2)(k^3 - 8).$$

Expanding:

$$\Delta(k) = 9k^4 - 12k^3 + 4k^2 - 4(3k^4 - 2k^3 - 24k + 16)$$
$$= 9k^4 - 12k^3 + 4k^2 - 12k^4 + 8k^3 + 96k - 64$$
$$= -3k^4 - 4k^3 + 4k^2 + 96k - 64.$$

**Bounding $\Delta(k)$.** We analyze the sign of $\Delta(k)$ for all integer $k$
.

*Case $k \geq 3$:* We show $\Delta(k) < 0$. Note

$$\Delta(k) = -3k^4 - 4k^3 + 4k^2 + 96k - 64 < -3k^4 + 4k^2 + 96k.$$

For $k \geq 3$: $4k^2 + 96k \leq 4k^2 + 32k^2 = 36k^2$ (since $96k \leq 32k^2$ f
or $k \geq 3$). Thus $\Delta(k) < -3k^4 + 36k^2 = -3k^2(k^2 - 12) < 0$ for $k \g
eq 4$. Direct check: $\Delta(3) = -243 - 108 + 36 + 288 - 64 = -91 < 0$. So $\De
lta(k) < 0$ for all $k \geq 3$.

*Case $k \leq -1$:* Write $k = -t$, $t \geq 1$:

$$\Delta(-t) = -3t^4 + 4t^3 + 4t^2 - 96t - 64.$$

For $t \geq 1$: $4t^3 + 4t^2 \leq 4t^3 + 4t^3 = 8t^3 \leq 8t^4/1$... more direct
ly, $-3t^4 + 4t^3 + 4t^2 - 96t - 64 < -3t^4 + 8t^3 - 96t$. For $t \geq 3$: $8t^3
 \leq \frac{8}{3}t^4 < 3t^4$, so $\Delta < 0$. Direct checks: $\Delta(-1) = -155
 < 0$, $\Delta(-2) = -256 < 0$, $\Delta(-3) = -451 < 0$. So $\Delta(k) < 0$ for
all $k \leq -1$.

*Remaining cases $k \in \{0, 1, 2\}$:*

| $k$ | $\Delta(k)$ | Perfect square? |
|-----|-------------|-----------------|
| $0$ | $-64$ | No (negative) |
| $1$ | $29$ | No |
| $2$ | $64 = 8^2$ | **Yes** |

**Solving for $k = 2$.** Substituting $k = 2$ into $(\star)$:

$$4y^2 + 8y + 0 = 0 \implies 4y(y + 2) = 0 \implies y = 0 \text{ or } y = -2.$$

- $y = 0 \Rightarrow x = 2$: solution $(2, 0)$.
- $y = -2 \Rightarrow x = 0$: solution $(0, -2)$.

**Verification.**

- $(2, 0)$: $2^3 - 0^3 = 8 = 2(2)(0) + 8 = 8$. ✓
- $(0, -2)$: $0^3 - (-2)^3 = 8 = 2(0)(-2) + 8 = 8$. ✓

**Conclusion.** The discriminant $\Delta(k)$ is negative for all integers $k$ ex
cept $k \in \{1, 2\}$; for $k = 1$ it equals $29$ (not a perfect square), and fo
r $k = 2$ it equals $64$, yielding exactly two integer solutions.
