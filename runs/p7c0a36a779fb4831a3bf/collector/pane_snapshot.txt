## Proof

The answer is **No**. Pointwise convergence $T_n x \to x$ in $Y$ for every $x \i
n X$, even with uniform boundedness $\|T_n\|_{\mathcal{L}(X,Y)} \le c$, does **n
ot** imply uniform convergence on bounded sequences. We give an explicit counter
example.

---

### Counterexample

Let $X = Y = \ell^2(\mathbb{N})$ with the identity embedding $X \hookrightarrow
Y$ (which is trivially continuous). Let $T_n = P_n$ be the orthogonal projection
 onto the first $n$ coordinates:

$$P_n x = (x_1, x_2, \dots, x_n, 0, 0, \dots), \qquad x = (x_1, x_2, \dots) \in
\ell^2.$$

**Verification of the hypotheses:**

1. **Uniform boundedness.** Each $P_n$ is an orthogonal projection, so $\|P_n\|_
{\mathcal{L}(\ell^2,\ell^2)} = 1$. Take $c = 1$.

2. **Pointwise convergence.** For every $x \in \ell^2$,
$$\|x - P_n x\|_{\ell^2}^2 = \sum_{k=n+1}^{\infty} |x_k|^2 \to 0 \quad \text{as
} n \to \infty,$$
since the tail of a convergent series vanishes. Hence $P_n x \to x$ in $\ell^2$
for all $x \in \ell^2$.

**The bounded sequence.** Let $x_m = e_m$, the $m$-th standard basis vector ($1$
 in position $m$, $0$ elsewhere). Then $\{x_m\}_{m} \subset \ell^2$ with $\|x_m\
|_{\ell^2} = 1$ for all $m$, so the sequence is bounded.

**Failure of uniform convergence.** For fixed $n$ and any $m > n$:
$$P_n e_m = 0 \quad \text{(since } e_m \text{ has its only nonzero entry in posi
tion } m > n\text{)},$$
so
$$\|e_m - P_n e_m\|_{\ell^2} = \|e_m\|_{\ell^2} = 1.$$

Therefore, for every $n \in \mathbb{N}$:
$$\max_{m \in \mathbb{N}} \|x_m - T_n x_m\|_Y = \max_{m \in \mathbb{N}} \|e_m -
P_n e_m\|_{\ell^2} = 1,$$
where the maximum is attained at any $m > n$ (in particular $m = n+1$). This equ
als $1$ for all $n$, so

$$\max_{m \in \mathbb{N}} \|x_m - T_n x_m\|_Y \not\to 0 \quad \text{as } n \to \
infty.$$

---

### Why this happens (structural reason)

The uniform boundedness principle guarantees that pointwise convergence $T_n x \
to x$ combined with $\sup_n \|T_n\| \le c$ yields convergence that is **uniform
on compact subsets** of $X$: if $K \subset X$ is compact, then $\sup_{x \in K} \
|x - T_n x\|_Y \to 0$ by a standard $\varepsilon/3$-argument (approximate $K$ by
 a finite $\varepsilon$-net, use pointwise convergence on the finite net, and co
ntrol the remainder by the uniform bound $c$).

However, in an **infinite-dimensional** Hilbert space, bounded sets are **not co
mpact** (Riesz's lemma / non-compactness of the closed unit ball). The sequence
$\{e_m\}$ lies in the closed unit ball of $\ell^2$, which is not compact, and th
e elements $e_m$ are pairwise orthogonal with $\|e_m\| = 1$, so no subsequence c
onverges. The uniform convergence on bounded sets fails precisely because bounde
d sets are too "large" (non-compact) in infinite dimensions.

Thus the claimed convergence does **not** hold in general. $\blacksquare$
