Looking at this problem, I need to determine for which (n,k) with 1≤n≤10, 1≤k≤10
 the map from permutations to transmission codes is injective.

## Analysis

**The map:** For permutation p = (p₁,...,pₙ), the code is s_i = p_i + p_{i+k} (i
ndices mod n).

**Orbit structure.** The map i ↦ i+k (mod n) partitions Z_n into orbits of lengt
h m = n/gcd(n,k), with d = gcd(n,k) orbits. Within each orbit {a₀, a₁, ..., a_{m
-1}} (where a_t = a₀ + tk mod n), the code reveals consecutive cyclic sums c_t =
 p_{a_t} + p_{a_{t+1}}.

**Recovery within an orbit:**
- **m odd:** From c₀ = x₀+x₁, c₁ = x₁+x₂, ..., we get x₀ − x₂ = c₀−c₁, x₂ − x₄ =
 c₂−c₃, etc. Since m is odd, chaining all the way around expresses x₀ in terms o
f itself, yielding a **unique** solution. The linear map is injective on the ent
ire orbit.
- **m even:** The same chaining gives x₀ − x₀ = (consistency condition), leaving
 x₀ as a free parameter. The kernel on each orbit is spanned by v = (1,−1,1,−1,.
..,1,−1). The map is **not** injective.

**When m is even, collisions exist among permutations.** For any even m ≥ 2, con
struct within one orbit:
- Even-indexed positions of p: {1, 3, 5, ..., m−1} (odd values); odd-indexed pos
itions: {m, m−2, ..., 2} (even values).
- Then p' = p + v has even positions {2, 4, ..., m} and odd positions {m−1, ...,
 1} — both p and p' are permutations of {1,...,m}, they differ by the kernel vec
tor, so they produce identical codes. Filling remaining orbits with values {m+1,
...,n} (unchanged between p and p') gives full permutation collisions.

**Verification of small cases:**
- n=2, k=1: m=2 (even). (1,2)→(3,3), (2,1)→(3,3). Collision ✓
- n=4, k=4: m=1 (odd). Code = (2p₁,...,2p₄), injective ✓
- n=4, k=2: m=2 (even). (1,2,3,4) and (3,4,1,2) both give (4,6,4,6) ✓

**Conclusion:** The system is Perfectly Secure **if and only if n/gcd(n,k) is od
d**, equivalently v₂(n) ≤ v₂(k) (the 2-adic valuation of n is covered by k).
