Let $A = \{x \in \mathbb{R}^4 : \sqrt{x_2^2+x_3^2+x_4^2} \le x_1\}$, the forward
 light cone. Write $\vec{x} = (x_2,x_3,x_4)$, $\vec{t}=(t_2,t_3,t_4)$, $\rho = |
\vec{t}| = \sqrt{t_2^2+t_3^2+t_4^2}$, and $(x,t)=x_1 t_1 + \vec{x}\cdot\vec{t}$.

**Spherical coordinates.** Set $r = |\vec{x}|$, $\omega = \vec{x}/r \in S^2$, so
 $dx = dx_1\, r^2\,dr\,d\omega$ with $\int_{S^2}d\omega = 4\pi$. The constraint
$r \le x_1$ forces $x_1 \ge 0$. Then

$$K(t) = \int_0^\infty e^{-x_1 t_1}\!\int_0^{x_1} r^2\!\int_{S^2} e^{-r\,\omega\
cdot\vec{t}}\,d\omega\,dr\,dx_1.$$

**Angular integral.** By rotational symmetry align $\vec{t}$ with the north pole
, $\omega\cdot\vec{t}=\rho\cos\theta$:

$$\int_{S^2} e^{-r\rho\cos\theta}d\omega = 2\pi\int_{-1}^{1} e^{-r\rho u}\,du =
\frac{4\pi\sinh(r\rho)}{r\rho}.$$

Hence

$$K(t) = \frac{4\pi}{\rho}\int_0^\infty e^{-x_1 t_1}\int_0^{x_1} r\sinh(r\rho)\,
dr\,dx_1.$$

**Radial integral.** Using $\int r\sinh(r\rho)\,dr = \frac{r\cosh(r\rho)}{\rho}-
\frac{\sinh(r\rho)}{\rho^2}$,

$$\int_0^{x_1} r\sinh(r\rho)\,dr = \frac{x_1\cosh(x_1\rho)}{\rho} - \frac{\sinh(
x_1\rho)}{\rho^2}.$$

**Exponential integrals.** Set $\alpha = t_1-\rho$, $\beta = t_1+\rho$. Since $e
^{-x_1 t_1}\cosh(x_1\rho) = \tfrac12(e^{-\alpha x_1}+e^{-\beta x_1})$ and $e^{-x
_1 t_1}\sinh(x_1\rho)=\tfrac12(e^{-\alpha x_1}-e^{-\beta x_1})$, convergence req
uires $\alpha>0$ and $\beta>0$. As $\rho\ge 0$, $\beta\ge\alpha$, so the binding
 condition is

$$\boxed{t_1 > \rho = \sqrt{t_2^2+t_3^2+t_4^2}\quad (\text{equivalently } t_1>0,
\; t_1^2>t_2^2+t_3^2+t_4^2).}$$

If $t_1\le\rho$: when $t_1=\rho>0$ the $e^{-\alpha x_1}=1$ term makes the $x_1$-
integral diverge; when $t_1<\rho$ the exponent $-\alpha x_1$ is positive and the
 integral blows up; when $t_1\le 0$ the factor $e^{-x_1 t_1}$ does not decay. So
 $K(t)$ is finite **iff** $t_1>\sqrt{t_2^2+t_3^2+t_4^2}$.

**Evaluating.** Using $\int_0^\infty x_1 e^{-\gamma x_1}dx_1 = \gamma^{-2}$ and
$\int_0^\infty e^{-\gamma x_1}dx_1=\gamma^{-1}$:

$$\int_0^\infty e^{-x_1 t_1}x_1\cosh(x_1\rho)\,dx_1 = \tfrac12\!\left(\tfrac{1}{
\alpha^2}+\tfrac{1}{\beta^2}\right),\quad \int_0^\infty e^{-x_1 t_1}\sinh(x_1\rh
o)\,dx_1 = \tfrac12\!\left(\tfrac{1}{\alpha}-\tfrac{1}{\beta}\right).$$

Therefore

$$K(t) = \frac{4\pi}{\rho}\left[\frac{1}{\rho}\cdot\tfrac12\!\left(\tfrac{1}{\al
pha^2}+\tfrac{1}{\beta^2}\right) - \frac{1}{\rho^2}\cdot\tfrac12\!\left(\tfrac{1
}{\alpha}-\tfrac{1}{\beta}\right)\right] = \frac{2\pi}{\rho}\left[\frac{1}{\rho}
\!\left(\tfrac{1}{\alpha^2}+\tfrac{1}{\beta^2}\right) - \frac{1}{\rho^2}\!\left(
\tfrac{1}{\alpha}-\tfrac{1}{\beta}\right)\right].$$

Now $\alpha\beta = t_1^2-\rho^2$, $\beta-\alpha=2\rho$, so $\tfrac{1}{\alpha}-\t
frac{1}{\beta}=\tfrac{2\rho}{\alpha\beta}$, and $\tfrac{1}{\alpha^2}+\tfrac{1}{\
beta^2}=\tfrac{\alpha^2+\beta^2}{(\alpha\beta)^2}=\tfrac{(\alpha+\beta)^2-2\alph
a\beta}{(\alpha\beta)^2}=\tfrac{4t_1^2-2\alpha\beta}{(\alpha\beta)^2}=\tfrac{2(t
_1^2+\rho^2)}{(t_1^2-\rho^2)^2}$. Substituting:

$$K(t) = \frac{2\pi}{\rho}\cdot\frac{2}{\rho}\left[\frac{t_1^2+\rho^2}{(t_1^2-\r
ho^2)^2} - \frac{1}{t_1^2-\rho^2}\right] = \frac{4\pi}{\rho^2}\cdot\frac{t_1^2+\
rho^2-(t_1^2-\rho^2)}{(t_1^2-\rho^2)^2} = \frac{4\pi}{\rho^2}\cdot\frac{2\rho^2}
{(t_1^2-\rho^2)^2}.$$

$$\boxed{K(t) = \frac{8\pi}{\bigl(t_1^2 - t_2^2 - t_3^2 - t_4^2\bigr)^2}.}$$

**Consistency check.** For $t=(t_1,0,0,0)$ ($\rho=0$), directly $K = 4\pi\int_0^
\infty e^{-t_1 x_1}\frac{x_1^3}{3}\,dx_1 = \frac{4\pi}{3}\cdot\frac{6}{t_1^4} =
\frac{8\pi}{t_1^4}$, matching the formula $\frac{8\pi}{(t_1^2)^2}$. ✓

---

**Conclusion.** $K(t)$ is finite if and only if $t_1 > \sqrt{t_2^2+t_3^2+t_4^2}$
 (i.e. $t$ lies in the interior of the forward light cone), and in that case

$$K(t) = \frac{8\pi}{\left(t_1^2 - t_2^2 - t_3^2 - t_4^2\right)^2}.$$
