## Setting Up the Framework

**Types** form the free magma on one generator ℂ. A type is either ℂ (cost 1) or
 [T₁, T₂] (cost c₁ + c₂). So cost = number of leaves. The generating function fo
r types by cost is:

$$B(y) = y + B(y)^2 \implies B(y) = \frac{1 - \sqrt{1-4y}}{2}$$

**Modules** extracting type T: either a leaf (type T itself, complexity c(T)), o
r a linked module (M₁, M₂) where M₁ extracts [T₂, T] and M₂ extracts T₂.

## Key Structural Insight

Any module extracting T has a **left spine** structure: a chain of k ≥ 0 interna
l nodes with labels T₁, ..., Tₖ, where:
- The leftmost leaf has type [Tₖ, [...[T₁, T]...]] with cost c(T) + Σc(Tᵢ)
- Each right subtree is an independent module extracting Tᵢ

This gives:
$$F_T(x) = x^{c(T)} + x^{c(T)} \sum_{k=1}^{\infty} \left(\sum_{T' \in \mathcal{T
}} x^{c(T')} F_{T'}(x)\right)^k$$

Define $P(x) = \sum_{T} x^{c(T)} F_T(x)$. Then:

$$F_T(x) = x^{c(T)} + x^{c(T)} \cdot \frac{P(x)}{1-P(x)} = \frac{x^{c(T)}}{1 - P
(x)}$$

## Solving for P(x)

Substituting back:
$$P(x) = \sum_T \frac{x^{2c(T)}}{1-P(x)} = \frac{B(x^2)}{1-P(x)}$$

This gives $P(x)^2 - P(x) + B(x^2) = 0$, so $P(x) = \frac{1 - \sqrt{1 - 4B(x^2)}
}{2}$.

Since $\sqrt{1-4y} = 1 - 2B(y)$, we get:

$$\boxed{P(x) = B(x^2)}$$

## The Generating Function
