# Solution

## Setup

Let $f(x) = e^{\sqrt{x}} + e^{-\sqrt{x}} = 2\cosh(\sqrt{x})$, defined on $[0,\in
fty)$.

**Key observation.** Since $\cosh(t) = \sum_{k=0}^{\infty} \frac{t^{2k}}{(2k)!}$
 is entire, substituting $t = \sqrt{x}$ gives
$$f(x) = 2\sum_{k=0}^{\infty} \frac{x^k}{(2k)!},$$
a power series in $x$ with infinite radius of convergence (ratio $\frac{x}{(2k+2
)(2k+1)} \to 0$). Hence $f$ extends to an entire function, every derivative $f^{
(n)}$ is continuous at $0$, and
$$\lim_{x\searrow 0} f^{(n)}(x) = f^{(n)}(0).$$
So the problem reduces to computing $\lim_{n\to\infty} f^{(n)}(0)$.

## Recurrence from the ODE

The given ODE is $2f'(x) + 4xf''(x) = f(x)$. Differentiate $n$ times using the L
eibniz rule on the product $4x\cdot f''(x)$:
$$\frac{d^n}{dx^n}[4xf''(x)] = 4\bigl[x\,f^{(n+2)}(x) + n\,f^{(n+1)}(x)\bigr].$$
Combining with $\frac{d^n}{dx^n}[2f'(x)] = 2f^{(n+1)}(x)$ and $\frac{d^n}{dx^n}[
f(x)] = f^{(n)}(x)$:
$$(4n+2)\,f^{(n+1)}(x) + 4x\,f^{(n+2)}(x) = f^{(n)}(x).$$

Evaluating at $x = 0$ (the term $4x\,f^{(n+2)}$ vanishes):
$$f^{(n+1)}(0) = \frac{f^{(n)}(0)}{4n+2}, \qquad n = 0, 1, 2, \dots$$

## Solving the recurrence

With $f(0) = 2\cosh(0) = 2$:
$$f^{(n)}(0) = \frac{2}{\prod_{k=0}^{n-1}(4k+2)} = \frac{2}{\prod_{k=0}^{n-1}2(2
k+1)} = \frac{2}{2^n\,(2n-1)!!}.$$

**Cross-check via the power series.** From $f(x) = 2\sum_{k\geq 0}\frac{x^k}{(2k
)!}$:
$$f^{(n)}(0) = 2\cdot\frac{n!}{(2n)!} = \frac{2\,n!}{(2n)!}.$$
Verify consistency: $\frac{2\,n!}{(2n)!} = \frac{2}{(2n)!/n!} = \frac{2}{(2n)(2n
-1)\cdots(n+1)}$. Also $\frac{2}{2^n(2n-1)!!} = \frac{2}{2^n\cdot\frac{(2n)!}{2^
n\,n!}} = \frac{2\,n!}{(2n)!}$. ✓

The recurrence is also verified: $\frac{f^{(n+1)}(0)}{f^{(n)}(0)} = \frac{(n+1)!
/(2n+2)!}{n!/(2n)!} = \frac{n+1}{(2n+2)(2n+1)} = \frac{1}{2(2n+1)} = \frac{1}{4n
+2}$. ✓

## Taking the limit

By Stirling's approximation,
$$f^{(n)}(0) = \frac{2\,n!}{(2n)!} \sim \frac{2\sqrt{2\pi n}\,(n/e)^n}{\sqrt{4\p
i n}\,(2n/e)^{2n}} = \sqrt{2}\cdot\frac{e^n}{4^n\,n^n} \to 0,$$
since the denominator $4^n n^n$ dominates $e^n$ for all large $n$.

Therefore:
$$\lim_{n\to\infty}\lim_{x\searrow 0} f^{(n)}(x) = \lim_{n\to\infty} f^{(n)}(0)
= \boxed{0}.$$
