## 解决方案

**设置。** 漫游车从 (0,0) 出发，目标为 (20,20)。三种移动方式为 E=(1,0), N=(0,1),
 D=(1,1)。禁区为满足 x+y ≡ 0 (mod 3) 的点，原点 (0,0) 除外。

**关键观察。** 在任何安全点，令 s = x+y。由于 s ≡ 0 (mod 3) 是禁区，安全点满足 s
 ≡ 1 或 s ≡ 2 (mod 3)。每种移动对 s 的影响如下：
- E 或 N：s 增加 1。
- D：s 增加 2。

因此：
- **在 s ≡ 1 时**：E 或 N → s ≡ 2（安全）；D → s ≡ 0（禁区）。因此 **只允许 E 或
 N**。
- **在 s ≡ 2 时**：E 或 N → s ≡ 0（禁区）；D → s ≡ 1（安全）。因此 **只允许 D**
。

一旦漫游车离开屏蔽原点，移动模式就是**强制的交替**：在 s≡1 和 s≡2 之间振荡，永远
不会触及 s≡0。

**从原点出发。** 在 (0,0) 处，s=0（已屏蔽），这三种移动都是可能的。这给出了两种
情况：

**情况 A：第一步是 E 或 N** (s → 1 ≡ 1)。随后强制执行：E/N (s→2), D (s→4), E/N (
s→5), D (s→7), … 该序列达到的 s 值为：1, 2, 4, 5, 7, 8, …, 37, 38, 40。总步数 =
27，包含 **13 次 D 移动** 和 **14 次 E 或 N 移动**。13 次 D 移动贡献了 (13,13)，
因此 14 次 E 或 N 移动必须贡献 (7,7)：即 7 次 E 和 7 次 N。路径数量 = C(14, 7) =
 **3432**。

**情况 B：第一步是 D** (s → 2 ≡ 2)。随后强制执行：D (s→4), E/N (s→5), D (s→7), E
/N (s→8), … 该序列达到的 s 值为：2, 4, 5, 7, 8, …, 37, 38, 40。总步数 = 26，包含
 **14 次 D 移动** 和 **12 次 E 或 N 移动**。14 次 D 移动贡献了 (14,14)，因此 12
次 E 或 N 移动必须贡献 (6,6)：即 6 次 E 和 6 次 N。路径数量 = C(12, 6) = **924**
。

**验证。** 在两种情况下，目标 s=40 ≡ 1 (mod 3) 均可达到，且最后一步是 D（从 s≡2
到 s≡1）。所有中间点的 s 值均不为 ≡ 0 (mod 3)，因此没有路径进入禁区。所有移动均
为非负的，因此中间点保持在 0 ≤ x,y ≤ 20 范围内。

**DP 交叉检查。** 我通过动态规划计算了小规模的 f(x,y) 值：f(1,1)=3, f(2,2)=3, f(
3,2)=4, f(4,4)=8, f(5,5)=8 —— 在所有情况下，公式 C(a,b)+C(c,d) 均与 DP 表一致。

**计算。**
- C(14,7) = 14!/(7!·7!) = 3432
- C(12,6) = 12!/(6!·6!) = 924

**有效序列总数 = 3432 + 924 = 4356。**
