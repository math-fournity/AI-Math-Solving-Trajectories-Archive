## Proof

We determine the cardinality of the set $\mathbb{N}^{\mathbb{N}}$ of all total f
unctions $f : \mathbb{N} \to \mathbb{N}$.

**Claim.** $\left|\mathbb{N}^{\mathbb{N}}\right| = 2^{\aleph_0}$, the cardinalit
y of the continuum.

We prove this by establishing two inequalities.

---

### Upper bound: $\left|\mathbb{N}^{\mathbb{N}}\right| \le 2^{\aleph_0}$

Each function $f : \mathbb{N} \to \mathbb{N}$ is determined by its graph $\Gamma
_f = \{(n, f(n)) : n \in \mathbb{N}\} \subseteq \mathbb{N} \times \mathbb{N}$. S
ince $\mathbb{N} \times \mathbb{N}$ is countable, each graph is a subset of a co
untable set, so $\Gamma_f \in \mathcal{P}(\mathbb{N} \times \mathbb{N})$. The ma
p $f \mapsto \Gamma_f$ is injective, so

$$\left|\mathbb{N}^{\mathbb{N}}\right| \le \left|\mathcal{P}(\mathbb{N} \times \
mathbb{N})\right| = 2^{\aleph_0}.$$

---

### Lower bound: $2^{\aleph_0} \le \left|\mathbb{N}^{\mathbb{N}}\right|$

We exhibit an injection $\{0,1\}^{\mathbb{N}} \hookrightarrow \mathbb{N}^{\mathb
b{N}}$. For each binary sequence $b = (b_0, b_1, b_2, \dots) \in \{0,1\}^{\mathb
b{N}}$, define $f_b : \mathbb{N} \to \mathbb{N}$ by $f_b(n) = b_n$. Since $b_n \
in \{0,1\} \subseteq \mathbb{N}$, this is a total function $\mathbb{N} \to \math
bb{N}$, and the map $b \mapsto f_b$ is clearly injective. Therefore

$$2^{\aleph_0} = \left|\{0,1\}^{\mathbb{N}}\right| \le \left|\mathbb{N}^{\mathbb
{N}}\right|.$$

---

### Conclusion

Combining both inequalities via the Schröder–Bernstein theorem,

$$\left|\mathbb{N}^{\mathbb{N}}\right| = 2^{\aleph_0}.$$

Equivalently, using cardinal arithmetic: $\aleph_0^{\aleph_0} = 2^{\aleph_0}$, s
ince $2 \le \aleph_0 \le 2^{\aleph_0}$ gives $2^{\aleph_0} \le \aleph_0^{\aleph_
0} \le (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0 \cdot \aleph_0} = 2^{\aleph_0}$.

The set of all total functions from $\mathbb{N}$ to $\mathbb{N}$ has cardinality
 $\boxed{2^{\aleph_0}}$ (the cardinality of the continuum, $\mathfrak{c}$).

### PROOF COMPLETE
