## Solution

**No**, $A$ is not necessarily a zero-measure set. We construct an explicit coun
terexample.

### Construction

Work in dimension $k=1$. Let $C \subseteq [0,1]$ be a **fat Cantor set** (e.g. t
he Smith–Volterra–Cantor set), which has the following well-known properties:

1. $C$ is closed in $\mathbb{R}$,
2. $C$ is nowhere dense, hence $C^\circ = \emptyset$,
3. $C$ has positive Lebesgue measure (e.g. $\lambda(C) = 1/2$).

By translating and rescaling (which preserves all three properties), we may assu
me $C \subseteq [\varepsilon,\, 1-\varepsilon]$ for some $\varepsilon > 0$.

### Producing $C$ as a decreasing intersection of open sets

In any metric space, every closed set $F$ is a $G_\delta$ set, realized as a dec
reasing intersection of open neighborhoods:
$$F = \bigcap_{n=1}^{\infty} \{x : d(x, F) < r_n\}, \qquad r_n \downarrow 0.$$

Set $r_n := \min\!\bigl(\tfrac{1}{n},\, \tfrac{\varepsilon}{2}\bigr)$ and define
$$A_n := \{x \in \mathbb{R} : d(x, C) < r_n\}.$$

### Verification of the hypotheses

- **Open in $\mathbb{R}$**: Each $A_n$ is an open neighborhood of $C$, hence ope
n in the Euclidean topology of $\mathbb{R}$. ✓
- **Contained in $[0,1]$**: Since $C \subseteq [\varepsilon, 1-\varepsilon]$ and
 $r_n \le \varepsilon/2$, every $x \in A_n$ satisfies $d(x,C) < \varepsilon/2$,
so $x \in (\varepsilon/2,\, 1-\varepsilon/2) \subseteq [0,1]$. Thus $A_n \subset
eq [0,1]$. ✓
- **Strictly decreasing**: $r_{n+1} \le r_n$, and since $C$ is nowhere dense (so
 $C \neq A_n$ for any $n$), we get $A_{n+1} \subsetneq A_n$. ✓
- **Limit equals $C$**:
$$A := \lim_{n\to\infty} A_n = \bigcap_{n=1}^{\infty} A_n = \{x : d(x,C) = 0\} =
 C,$$
since $C$ is closed (the set of points at distance $0$ from a closed set is the
set itself). ✓

### The limit has empty interior but positive measure

- **Empty interior**: $A = C$ is nowhere dense, so $A^\circ = C^\circ = \emptyse
t$. ✓
- **Positive measure**: $\lambda(A) = \lambda(C) = 1/2 > 0$. ✓

### Conclusion

We have produced a decreasing sequence of open sets $A_n \subseteq [0,1]$ (open
in $\mathbb{R}$) whose limit $A$ has empty interior yet positive Lebesgue measur
e. The same construction embeds into $[0,1]^k$ for any $k \ge 1$ by taking $C \t
imes [0,1]^{k-1}$'s fat-Cantor cross-section (or simply placing the one-dimensio
nal example inside $[0,1]^k$), giving a limit with empty interior and positive $
k$-dimensional measure.

Therefore, **$A$ is not necessarily a zero-measure set.** $\blacksquare$
