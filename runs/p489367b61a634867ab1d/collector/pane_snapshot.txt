## Proof

**Step 1: Reformulation via substitution.**

The expression under the square root is $f(x)(1-f(x))$, which requires $0 \le f(
x) \le 1$. Set

$$f(x) = \frac{1 + g(x)}{2}, \qquad g(x) \in [-1, 1].$$

Then $f(x)(1-f(x)) = \frac{1-g(x)^2}{4}$, so the functional equation becomes:

$$\frac{1+g(x+1)}{2} = \frac{1}{2} + \frac{\sqrt{1-g(x)^2}}{2},$$

hence

$$g(x+1) = \sqrt{1 - g(x)^2}. \tag{$\star$}$$

Since the right side is $\ge 0$, we get $g(x) \in [0,1]$ for all $x$. Squaring:
$g(x)^2 + g(x+1)^2 = 1$.

**Step 2: Trigonometric substitution.**

Since $g(x) \in [0,1]$, write $g(x) = \sin\theta(x)$ with $\theta(x) \in [0, \pi
/2]$. Then ($\star$) gives:

$$\sin\theta(x+1) = \sqrt{1-\sin^2\theta(x)} = \cos\theta(x) = \sin\!\left(\tfra
c{\pi}{2}-\theta(x)\right).$$

Both $\theta(x+1)$ and $\frac{\pi}{2}-\theta(x)$ lie in $[0,\pi/2]$, so:

$$\theta(x+1) = \frac{\pi}{2} - \theta(x). \tag{$\star\star$}$$

This implies $\theta(x+2) = \theta(x)$, i.e., $\theta$ has period $2$. The gener
al solution is $\theta(x) = \frac{\pi}{4} + h(x)$ where $h(x+1) = -h(x)$ (anti-p
eriodic). We need $\theta(x) \in [0,\pi/2]$, i.e., $|h(x)| \le \pi/4$.

**Step 3: A concrete non-constant example.**

Choose $h(x) = \frac{\pi}{4}\cos(\pi x)$. Then:
- $h(x+1) = \frac{\pi}{4}\cos(\pi x + \pi) = -h(x)$. ✓
- $|h(x)| \le \pi/4$, so $\theta(x) \in [0, \pi/2]$. ✓
- $h$ is non-constant, so $f$ is non-constant. ✓

This gives:

$$\boxed{f(x) = \frac{1 + \sin\!\left(\frac{\pi}{4} + \frac{\pi}{4}\cos(\pi x)\r

**Step 4: Verification.**

Let $\theta = \frac{\pi}{4} + \frac{\pi}{4}\cos(\pi x) \in [0,\pi/2]$, so $f(x)
= \frac{1+\sin\theta}{2}$.

- **Square root is real:** $f(x) \in [\tfrac{1}{2}, 1] \subset [0,1]$, so $f(x)(
1-f(x)) \ge 0$. ✓

- **Functional equation:**
$$f(x)(1-f(x)) = \frac{(1+\sin\theta)(1-\sin\theta)}{4} = \frac{\cos^2\theta}{4}
.$$
Since $\theta \in [0,\pi/2]$, $\cos\theta \ge 0$, so $\sqrt{f(x)(1-f(x))} = \fra
c{\cos\theta}{2}$.

**RHS** $= \frac{1}{2} + \frac{\cos\theta}{2} = \frac{1+\cos\theta}{2}$.

For the **LHS**, note $\theta(x+1) = \frac{\pi}{4} + \frac{\pi}{4}\cos(\pi x+\pi

$$f(x+1) = \frac{1+\sin(\frac{\pi}{2}-\theta)}{2} = \frac{1+\cos\theta}{2}.$$

**LHS = RHS.** ✓
