Looking at this problem, I need to find the maximum number of rainbow vertices i
n an edge-coloring of $K_n$ with $n-1$ colors, where a vertex is rainbow if its
incident edges collectively use all $n-1$ colors.

**Key observation:** Each vertex has degree $n-1$ in $K_n$, and there are exactl
y $n-1$ colors. So a vertex is rainbow if and only if its $n-1$ incident edges a
ll have **distinct** colors (each color used exactly once).

---

**Claim:** The maximum number of rainbow vertices is $n$ if $n$ is even, and $n-
1$ if $n$ is odd.

---

### Upper Bound

If all $n$ vertices are rainbow, then for each color $c$, every vertex is incide
nt to exactly one edge of color $c$. This means each color class is a **perfect
matching** (1-factor) of $K_n$. A perfect matching requires $n$ to be even. Ther
efore:

- If $n$ is **odd**: not all $n$ vertices can be rainbow, so the upper bound is
$n-1$.
- If $n$ is **even**: the trivial upper bound is $n$.

---

### Achievability

**Case 1: $n$ even.** The complete graph $K_n$ for even $n$ admits a **1-factori
zation** — a partition of its edges into $n-1$ perfect matchings (a classical re
sult; one construction places $n-1$ vertices on a circle with one at the center,
 rotating a "direction" to generate $n-1$ matchings). Assigning a distinct color
 to each matching gives a proper edge coloring with $n-1$ colors. Every vertex t
hen has one edge of each color, so all $n$ vertices are rainbow. ✓

**Case 2: $n$ odd.** We construct a coloring with $n-1$ rainbow vertices.

1. Remove one vertex $v$, leaving $K_{n-1}$ on $n-1$ vertices (now **even**).
2. Properly edge-color $K_{n-1}$ using $n-2$ of the $n-1$ available colors (poss
ible since $n-1$ is even, so $\chi'(K_{n-1}) = n-2$). Each vertex of $K_{n-1}$ h
as degree $n-2$ and, by properness, its $n-2$ incident edges use all $n-2$ color
s (one per color).
3. Color all $n-1$ edges from $v$ to the remaining vertices with the single unus
ed $(n-1)$-th color.

**Verification:** Each vertex $u \neq v$ has $n-2$ edges using colors $1, \ldots
, n-2$ (from the $K_{n-1}$ coloring) plus one edge of color $n-1$ (to $v$), so $
u$ sees all $n-1$ colors → **rainbow**. Vertex $v$ has all edges of the same col
or → not rainbow.

This yields exactly $n-1$ rainbow vertices. ✓

---

### Why $n$ rainbow vertices is impossible for odd $n$

If all $n$ vertices were rainbow, each color class would be a perfect matching.
But each matching in $K_n$ (odd $n$) has at most $\lfloor n/2 \rfloor = (n-1)/2$
 edges, so $n-1$ colors cover at most $(n-1) \cdot \frac{n-1}{2} = \frac{(n-1)^2
}{2}$ edges. Since $K_n$ has $\frac{n(n-1)}{2}$ edges and $\frac{(n-1)^2}{2} < \
frac{n(n-1)}{2}$, this is impossible. (Equivalently, $\chi'(K_n) = n$ for odd $n
$, so a proper edge coloring with only $n-1$ colors cannot exist.)

---

### Conclusion

The maximum number of rainbow vertices is:

$$\boxed{\begin{cases} n & \text{if } n \text{ is even,} \\ n-1 & \text{if } n \
text{ is odd.} \end{cases}}$$
