## Problem

Determine for which dimensions \(n\in\mathbb N\) the Dirac delta \(\delta_{x_{0}
}\) (at a point \(x_{0}\in\Omega\)) is a bounded linear functional on \(H_{0}^{1
}(\Omega)\), i.e. \(\delta_{x_{0}}\in H^{-1}(\Omega)\).

We take the standard setting: \(\Omega\subset\mathbb R^{n}\) is a bounded open s
et and \(x_{0}\in\Omega\). (If \(x_{0}\notin\Omega\) the question is vacuous; th
e interesting case is an interior point.)

**Answer:** \(\delta_{x_{0}}\in H^{-1}(\Omega)\) **if and only if \(n=1\).**

---

## Proof

The question is exactly whether point evaluation \(\operatorname{ev}_{x_{0}}:u\m
apsto u(x_{0})\) extends to a continuous linear functional on \(H_{0}^{1}(\Omega
)\). We treat the two directions separately.

### 1. Sufficiency: \(n=1\)

In one dimension \(H_{0}^{1}(\Omega)\hookrightarrow C^{0,1/2}(\overline\Omega)\)
 continuously (Sobolev embedding with \(1-n/2=1/2>0\)). Concretely, for \(u\in H
_{0}^{1}(\Omega)\) and any \(x\in\Omega\),

\[
|u(x)|^{2}\;\le\;\|u\|_{L^{2}}\,\|u'\|_{L^{2}}\;\le\;\tfrac12\|u\|_{H^{1}}^{2},
\]

using \(u(x)=\int_{a}^{x}u'(t)\,dt\) (with \(u\) vanishing at the boundary) and
Cauchy–Schwarz. Hence

\[
|\delta_{x_{0}}(u)|=|u(x_{0})|\le 2^{-1/2}\|u\|_{H^{1}(\Omega)},
\]

so \(\delta_{x_{0}}\) is bounded on \(H_{0}^{1}(\Omega)\), i.e. \(\delta_{x_{0}}
\in H^{-1}(\Omega)\).

### 2. Necessity: \(n\ge 2\)

We show point evaluation at \(x_{0}\) is **not** continuous by exhibiting, for e
ach \(n\ge 2\), a sequence \((u_{k})\subset C_{c}^{\infty}(\Omega)\) with \(\|u_
{k}\|_{H^{1}}\) bounded (or tending to \(0\)) while \(u_{k}(x_{0})\to\infty\) (o
r stays fixed at \(1\)). Without loss \(x_{0}=0\).

#### Case \(n\ge 3\): shrinking bump.

Pick \(\varphi\in C_{c}^{\infty}(B(0,1))\) with \(\varphi(0)=1\), and set \(u_{\
varepsilon}(x)=\varphi(x/\varepsilon)\) for \(\varepsilon\downarrow 0\) (support
ed in \(B(0,\varepsilon)\subset\Omega\) for \(\varepsilon\) small). Then \(u_{\v
arepsilon}(0)=1\) and

\[
\|u_{\varepsilon}\|_{L^{2}}^{2}=\varepsilon^{n}\|\varphi\|_{L^{2}}^{2},\qquad
\|\nabla u_{\varepsilon}\|_{L^{2}}^{2}=\varepsilon^{n-2}\|\nabla\varphi\|_{L^{2}
}^{2}.
\]

Since \(n\ge 3\), both terms tend to \(0\) as \(\varepsilon\to 0\). Thus \(\|u_{
\varepsilon}\|_{H^{1}}\to 0\) while \(u_{\varepsilon}(0)=1\): evaluation cannot
be continuous. So \(\delta_{0}\notin H^{-1}(\Omega)\).

#### Case \(n=2\): logarithmic singularity.

The scaling above is critical here (\(\varepsilon^{n-2}=1\)), so a shrinking bum
p alone does not blow up. Instead use a logarithmic profile. Let \(\eta\in C_{c}
^{\infty}(B(0,1/2))\), \(\eta\equiv 1\) near \(0\), and define for \(\varepsilon
\in(0,1/4)\)

\[
u_{\varepsilon}(x)=\eta(x)\,\min\!\bigl\{\log\log(1/|x|),\,\log\log(1/\varepsilo
n)\bigr\},
\]

with the convention that the quantity in braces is set to \(\log\log(1/\varepsil
on)\) when \(|x|\le\varepsilon\). Then \(u_{\varepsilon}\in H^{1}(\Omega)\cap C(
\overline\Omega)\), \(u_{\varepsilon}(0)=\log\log(1/\varepsilon)\to\infty\), and
 \(u_{\varepsilon}\) is compactly supported in \(\Omega\), so \(u_{\varepsilon}\
in H_{0}^{1}(\Omega)\).

It remains to bound \(\|u_{\varepsilon}\|_{H^{1}}\) independently of \(\varepsil
on\). On the annulus \(\varepsilon\le|x|\le 1/2\), \(\nabla u_{\varepsilon}(x)=\
eta'(x)\,\log\log(1/|x|)+\eta(x)\,\nabla\log\log(1/|x|)\), and

\[
\bigl|\nabla\log\log(1/|x|)\bigr|=\frac{1}{|x|\,\log(1/|x|)}.
\]

Using polar coordinates (\(r=|x|\), \(dx=r\,dr\,d\theta\)),

\[
\int_{\varepsilon}^{1/2}\!\!\frac{1}{\bigl(r\log(1/r)\bigr)^{2}}\,r\,dr
=\int_{\varepsilon}^{1/2}\frac{dr}{r\,\log(1/r)^{2}}
=\int_{\log 2}^{\log(1/\varepsilon)}\frac{dt}{t^{2}}
\le\int_{\log 2}^{\infty}\frac{dt}{t^{2}}<\infty,
\]

uniformly in \(\varepsilon\). The \(\eta'\)-term is bounded since \(\log\log(1/r
)\) is bounded on \(\operatorname{supp}\eta'\subset\{|x|\ge c\}\). The \(L^{2}\)
-norm of \(u_{\varepsilon}\) is also uniformly bounded because \(\int_{0}^{1/2}(
\log\log(1/r))^{2}r\,dr<\infty\). Hence

\[
\sup_{\varepsilon}\|u_{\varepsilon}\|_{H^{1}(\Omega)}<\infty,\qquad u_{\varepsil
on}(0)=\log\log(1/\varepsilon)\to\infty.
\]

If \(\delta_{0}\) were bounded, we would have \(|u_{\varepsilon}(0)|\le C\|u_{\v
arepsilon}\|_{H^{1}}\le C'\), a contradiction. Therefore \(\delta_{0}\notin H^{-
1}(\Omega)\) for \(n=2\).

### 3. Conclusion

Combining both directions:

\[
\boxed{\;\delta_{x_{0}}\in H^{-1}(\Omega)\iff n=1.\;}
\]

Equivalently, the Dirac delta is a bounded linear functional on \(H_{0}^{1}(\Ome
ga)\) precisely in dimension one; for every \(n\ge 2\) it lies only in \(H^{-s}(
\Omega)\) with \(s>n/2\), not in \(H^{-1}(\Omega)\).
