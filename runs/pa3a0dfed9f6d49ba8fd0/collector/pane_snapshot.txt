## Probability Generating Function for the Number of Cycles

Let $C_n$ denote the number of cycles in a uniformly random permutation of $\{1,
\dots,n\}$. Its probability generating function is

$$G_n(x) = \mathbb{E}\!\left[x^{C_n}\right] = \sum_{k=0}^{n} \Pr(C_n = k)\, x^k.
$$

Since the number of permutations of $n$ elements with exactly $k$ cycles is the
**unsigned Stirling number of the first kind** $\left[{n\atop k}\right]$, and th
e total number of permutations is $n!$,

$$\Pr(C_n = k) = \frac{1}{n!}\left[{n\atop k}\right],$$

so

$$G_n(x) = \frac{1}{n!}\sum_{k=0}^{n}\left[{n\atop k}\right] x^k.$$

### Derivation via the rising factorial

The unsigned Stirling numbers of the first kind are the connection coefficients
between the monomial basis and the rising factorial basis. Concretely,

$$\sum_{k=0}^{n}\left[{n\atop k}\right] x^k \;=\; x\,(x+1)\,(x+2)\cdots(x+n-1) \
;=\; x^{\overline{n}}.$$

**Proof of this identity by induction on $n$.**
For $n=0$ both sides equal $1$. Assume it holds for $n$. The Stirling numbers sa
tisfy the recurrence

$$\left[{n+1\atop k}\right] = n\left[{n\atop k}\right] + \left[{n\atop k-1}\righ
t],$$

which reflects inserting the new element $(n+1)$ into an existing cycle ($n$ cho
ices of position) versus starting a new cycle. Multiplying the induction hypothe
sis by $(x+n)$ and collecting the coefficient of $x^k$:

$$\left(\sum_j \left[{n\atop j}\right] x^j\right)(x+n) = \sum_k\left(n\left[{n\a
top k}\right] + \left[{n\atop k-1}\right]\right) x^k = \sum_k \left[{n+1\atop k}
\right] x^k,$$

which is exactly $x^{\overline{n+1}}$. ∎

### Combinatorial proof (Foata's construction)

There is also a direct bijective argument. Write each cycle with its **smallest
element first**, and order the cycles by **decreasing smallest element**. Droppi
ng the parentheses yields a bijection between permutations of $n$ and the $n!$ w
ords on $\{1,\dots,n\}$. Under this bijection, a cycle boundary is created preci
sely when, scanning the word left to right, we encounter a **new left-to-right m
inimum**.

Now build the word by inserting $1,2,\dots,n$ in order. Inserting $i$ either ext
ends an existing block (no new record minimum) or starts a new block at the fron
t (a new record minimum). Equivalently, place $n$ "slots" (one before each exist
ing element and one at the end) and mark each slot independently: a marked slot
creates a new cycle. This gives the product form directly.

### Result

Dividing by $n!$,

$$\boxed{\,G_n(x) \;=\; \frac{x(x+1)(x+2)\cdots(x+n-1)}{n!} \;=\; \frac{x^{\over
line{n}}}{n!}\,}.$$

### Consistency checks

- **Constant term:** $G_n(0)=0$ for $n\ge 1$, since every nonempty permutation h
as at least one cycle. ✓ (the factor $x$ forces this)
- **Normalization:** $G_n(1) = \frac{1\cdot 2\cdots n}{n!}=1$. ✓
- **Mean:** $G_n'(1) = \frac{1}{n!}\,x^{\overline{n}}\sum_{j=0}^{n-1}\frac{1}{x+
j}\Big|_{x=1} = \sum_{j=0}^{n-1}\frac{1}{j+1} = H_n$, the harmonic number — the
classical expected number of cycles. ✓
- **Variance:** $G_n''(1)+G_n'(1)-G_n'(1)^2 = H_n - H_n^{(2)}$, matching the kno
wn variance. ✓

The PGF of the Stirling cycle distribution (number of cycles in a uniform random
 permutation of size $n$) is therefore

$$G_n(x) = \prod_{j=0}^{n-1}\frac{x+j}{j+1} = \frac{x^{\overline{n}}}{n!}.$$
