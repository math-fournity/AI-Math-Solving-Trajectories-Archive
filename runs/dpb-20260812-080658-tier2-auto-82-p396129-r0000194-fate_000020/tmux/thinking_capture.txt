命题：设 $F$ 是一个域，$a \in F^\times$（即 $a \neq 0$），$b \in F$。则方程 $ax
+ b = 0$ 在 $F$ 中有唯一解。

────────────────────────────────────────────────────────────────────────────────

存在性

因为 $a \in F^\times$，由域的定义，$a$ 在 $F$ 中有乘法逆元 $a^{-1} \in F$，满足
$a^{-1} a = a a^{-1} = 1$。

令 $x_0 = -a^{-1} b$。由于 $F$ 对乘法和加法封闭，且 $-a^{-1} b \in F$，故 $x_0
\in F$。代入验证：

$$a x_0 + b = a(-a^{-1} b) + b = -(a a^{-1}) b + b = -1 \cdot b + b = -b + b =
0.$$

因此 $x_0$ 是方程 $ax + b = 0$ 的解。存在性得证。

────────────────────────────────────────────────────────────────────────────────

唯一性

设 $x_1, x_2 \in F$ 都满足该方程，即

$$a x_1 + b = 0, \qquad a x_2 + b = 0.$$

两式相减：

$$a x_1 + b - (a x_2 + b) = 0 - 0 = 0,$$

即

$$a(x_1 - x_2) = 0.$$

因为 $a \in F^\times$，即 $a \neq 0$，而域中没有（非零的）零因子（或者说，域中
$a \neq 0$ 时可对 $a(x_1 - x_2) = 0$ 两边左乘 $a^{-1}$），故

$$x_1 - x_2 = a^{-1} \cdot 0 = 0,$$

即 $x_1 = x_2$。

唯一性得证。

────────────────────────────────────────────────────────────────────────────────

结论

方程 $ax + b = 0$（$a \in F^\times$, $b \in F$）在 $F$ 中存在唯一解 $x = -a^{-1}
b$。$\blacksquare$
