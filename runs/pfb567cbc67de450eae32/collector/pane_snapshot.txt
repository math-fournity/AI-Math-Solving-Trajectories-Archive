## Proof

**Substitution.** Let $x = t/k$, so $dx = dt/k$. When $x: 0 \to 1$, we have $t:
0 \to k$. Then:

$$I_k = \int_0^1 \frac{(1-x)^k \cos(k/x)}{\sqrt{x}}\,dx = \frac{1}{\sqrt{k}}\int
_0^k \frac{(1-t/k)^k}{\sqrt{t}}\cos\!\left(\frac{k^2}{t}\right)dt.$$

The key observation is that the phase $\phi(t) = k^2/t$ oscillates at frequency
$\sim k^2$, far faster than the amplitude $g(t) = (1-t/k)^k/\sqrt{t}$ varies (on
 scale $\sim 1$). This rapid oscillation drives the integral to zero.

**Splitting.** Fix any $\delta \in (0,1)$ and split $[0,k] = [0,\delta] \cup [\d
elta,k]$.

**Part 1: $t \in [0,\delta]$.** Since $(1-t/k)^k \le 1$:

$$\left|\int_0^\delta \frac{(1-t/k)^k}{\sqrt{t}}\cos(k^2/t)\,dt\right| \le \int_
0^\delta \frac{dt}{\sqrt{t}} = 2\sqrt{\delta}.$$

**Part 2: $t \in [\delta, k]$.** Here $g(t) = (1-t/k)^k/\sqrt{t}$ is smooth and
$\phi'(t) = -k^2/t^2 \neq 0$. Writing $\cos\phi = \frac{1}{\phi'}\frac{d}{dt}\si
n\phi$ and integrating by parts:

$$\int_\delta^k g(t)\cos\phi(t)\,dt = \underbrace{\left[\frac{g(t)\sin\phi(t)}{\
phi'(t)}\right]_\delta^k}_{\text{boundary}} - \int_\delta^k \left(\frac{g}{\phi'
}\right)'\sin\phi\,dt.$$

*Boundary terms.* At $t=k$: $g(k)=0$. At $t=\delta$: $\left|\frac{g(\delta)}{\ph
i'(\delta)}\right| = \frac{\delta^{3/2}(1-\delta/k)^k}{k^2} \le \frac{\delta^{3/
2}}{k^2}$.

*Integral term.* Compute:
$$\frac{g}{\phi'} = -\frac{t^{3/2}(1-t/k)^k}{k^2}, \qquad \left(\frac{g}{\phi'}\
right)' = -\frac{t^{1/2}(1-t/k)^{k-1}}{k^2}\left(\tfrac{1}{2} - \tfrac{3t}{2k}\r
ight).$$

So $\left|\left(\frac{g}{\phi'}\right)'\right| \le \frac{3\,t^{1/2}(1-t/k)^{k-1}
}{2k^2}$, and:

$$\int_\delta^k \left|\left(\frac{g}{\phi'}\right)'\right|dt \le \frac{3}{2k^2}\
int_0^k t^{1/2}(1-t/k)^{k-1}\,dt = \frac{3}{2k^2}\cdot k^{3/2}\,B\!\left(\tfrac{
3}{2},k\right).$$

Using $B(3/2,k) = \frac{\Gamma(3/2)\,\Gamma(k)}{\Gamma(k+3/2)} \sim \frac{\sqrt{
\pi}}{2}\,k^{-3/2}$, the integral is $O(k^{-2})$.

Combining Part 2: $\left|\int_\delta^k g\cos\phi\,dt\right| \le \frac{\delta^{3/
2}}{k^2} + O(k^{-2}) = O(k^{-2})$.

**Combining both parts:**

$$|I_k| \le \frac{1}{\sqrt{k}}\left(2\sqrt{\delta} + O(k^{-2})\right) = \frac{2\
sqrt{\delta}}{\sqrt{k}} + O(k^{-5/2}).$$

For any fixed $\delta > 0$, both terms vanish as $k \to \infty$. Therefore:

$$\lim_{k\to\infty} I_k = 0.$$
