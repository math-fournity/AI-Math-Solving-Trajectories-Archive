Answer

Yes. For any bounded surjective linear operator $T: X \to Y$ between Banach
spaces, there always exists a linear map $g: Y \to X$ (not necessarily bounded)
with $T \circ g = \mathrm{Id}_Y$. The proof uses only linear algebra (the axiom
of choice) and does not need the topology at all.

────────────────────────────────────────────────────────────────────────────────

Proof

The hypothesis that $X,Y$ are Banach and $T$ is bounded is actually irrelevant
to the existence of a linear right inverse; only surjectivity of $T$ as a linear
map between vector spaces matters.

Step 1: Choose a Hamel basis of $Y$.

Every vector space has a Hamel basis (Zorn's lemma). Let ${e_\alpha}_{\alpha \in
A}$ be a Hamel basis of $Y$ over $\mathbb{R}$ (or $\mathbb{C}$).

Step 2: Lift each basis vector.

Since $T$ is surjective, for every $\alpha \in A$ the set $T^{-1}(e_\alpha)
\subseteq X$ is nonempty. By the axiom of choice, select one preimage $$x_\alpha
\in X \quad \text{with} \quad T(x_\alpha) = e_\alpha.$$

Step 3: Define $g$ on the basis and extend linearly.

Define $g: Y \to X$ by setting $g(e_\alpha) = x_\alpha$ on the basis and
extending linearly: for any $y \in Y$, written uniquely as a finite sum $y =
\sum_{\alpha} c_\alpha e_\alpha$ (only finitely many $c_\alpha \neq 0$), set $
$g(y) = \sum_{\alpha} c_\alpha x_\alpha.$$

This is well-defined because the Hamel representation is a finite sum with
unique coefficients, and $g$ is linear by construction.

Step 4: Verify $T \circ g = \mathrm{Id}_Y$.

For $y = \sum_{\alpha} c_\alpha e_\alpha$, $$T(g(y)) = T!\left(\sum_{\alpha}
c_\alpha x_\alpha\right) = \sum_{\alpha} c_\alpha T(x_\alpha) = \sum_{\alpha}
c_\alpha e_\alpha = y.$$

Hence $T \circ g = \mathrm{Id}_Y$. $\square$

────────────────────────────────────────────────────────────────────────────────

Remarks

  • The map $g$ is a linear section (right inverse) of $T$. It exists for any
  surjective linear map between vector spaces, purely algebraically.
  • The Banach/bounded hypotheses become relevant only if one asks for a bounded
  right inverse. A bounded linear right inverse does not always exist; it exists
  precisely when $\ker T$ is topologically complemented in $X$ (equivalently,
  when there is a closed subspace $M \subseteq X$ with $X = \ker T \oplus M$
  topologically). For example, the quotient map $\ell^\infty \to \ell^\infty /
  c_0$ admits no bounded linear section.
  • So the answer to the question as stated (asking only for a linear map) is
  yes, always, via the axiom of choice.
