## Solution

**Setup.** Model the test as a 5×5 binary matrix $M$ where $M_{ij}=1$ if person
$i$ answers question $j$ correctly. Each entry is independently $1$ with probabi
lity $\tfrac{1}{2}$, giving $2^{25}$ equally likely outcomes.

**Condition:** every column sum $\geq 3$ (majority correct on each question).
**Event:** every row sum $= 3$ (each person gets exactly 3 correct).

We seek $p = P(\text{event} \mid \text{condition})$.

---

**Denominator.** Each column is an independent $\text{Binomial}(5,\tfrac12)$. Si
nce
$$P(\text{column sum}\geq 3)=\frac{\binom53+\binom54+\binom55}{2^5}=\frac{10+5+1
}{32}=\frac12,$$
we get $P(\text{condition}) = (1/2)^5 = 1/32$.

---

**Numerator.** If all row sums $=3$, the total number of 1's is $15$. If all col
umn sums $\geq 3$, the total is $\geq 15$. Together these force **every column s
um $= 3$** as well. So we must count 5×5 binary matrices with all row sums $= 3$
 and all column sums $= 3$.

By complementation (swap 0↔1), this equals the number of 5×5 binary matrices wit
h all row sums $= 2$ and all column sums $= 2$, i.e., the number of 2-regular bi
partite graphs on $5+5$ labeled vertices. Such a graph is a disjoint union of ev
en cycles (each length $\geq 4$) covering all 10 vertices. The only partitions o
f 10 into even parts $\geq 4$ are:

- **One 10-cycle.** The number of Hamiltonian cycles in $K_{5,5}$ is $\frac{4!\c
dot 5!}{2}=\frac{24\cdot120}{2}=1440.$

- **One 6-cycle + one 4-cycle.** Choose 3 of 5 left and 3 of 5 right vertices fo
r the 6-cycle: $\binom53^2=100$. The 6-cycle count on $3+3$ vertices is $\frac{2
!\cdot 3!}{2}=6$; the remaining $2+2$ form a unique 4-cycle. Total: $100\cdot 6\
cdot 1=600.$

Total count: $1440+600=2040$.

Thus $P(\text{event}\cap\text{condition}) = \dfrac{2040}{2^{25}}$.

---

**Combining.**
$$p=\frac{2040/2^{25}}{1/32}=\frac{2040}{2^{20}}.$$
Since $2040 = 2^3\cdot 255$ and $255=3\cdot5\cdot17$ is odd,
$$p=\frac{255}{2^{17}}.$$
So $a=255$, $b=17$, and
$$100a+b = 100\cdot 255+17 = \boxed{25517}.$$
