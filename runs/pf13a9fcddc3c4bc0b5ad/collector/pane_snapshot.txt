Looking at this problem, I need to find the smallest positive integer $n$ with $
s(n) = 20$ and $s(n+864) = 20$.

## Key Identity

When adding two numbers, the digit sums satisfy:
$$s(n + m) = s(n) + s(m) - 9c$$
where $c$ is the number of carries in the addition.

Here $s(864) = 8 + 6 + 4 = 18$, so:
$$s(n + 864) = s(n) + 18 - 9c = 20 + 18 - 9c = 38 - 9c$$

Setting $s(n+864) = 20$ gives $38 - 9c = 20$, so $c = 2$.

**I need exactly 2 carries when adding 864 to $n$, with $s(n) = 20$.**

## Carry Analysis

Write $n$ with digits $d_3\, d_2\, d_1\, d_0$ (ones = $d_0$). Adding 864 (digits
 4, 6, 8 in positions 0, 1, 2):

| Position | Sum | Carry out condition |
|----------|-----|---------------------|
| 0: $d_0 + 4$ | $c_1 = 1$ iff $d_0 \geq 6$ | |
| 1: $d_1 + 6 + c_1$ | $c_2 = 1$ iff $d_1 + 6 + c_1 \geq 10$ | |
| 2: $d_2 + 8 + c_2$ | $c_3 = 1$ iff $d_2 + 8 + c_2 \geq 10$ | |
| 3: $d_3 + c_3$ | $c_4 = 1$ iff $d_3 + c_3 \geq 10$ | |

Total carries $= c_1 + c_2 + c_3 + \cdots = 2$.

## Checking All Carry Patterns (for 3-digit $n$)

Since $s(n)=20$ requires at least 3 digits (max 2-digit sum is 18), I examine 3-
digit candidates where $(c_1, c_2, c_3)$ sums to 2:

**Case $(1,1,0)$:** $d_0 \geq 6$, $d_1 \geq 3$, $d_2 + 9 < 10 \Rightarrow d_2 =
0$. Impossible for 3-digit ($d_2 \geq 1$).

**Case $(1,0,1)$:** $d_0 \geq 6$, $d_1 \leq 2$, $d_2 + 8 \geq 10 \Rightarrow d_2
 \geq 2$. Then $d_2+d_1+d_0=20$ with $d_2 \geq 2$, $d_1 \leq 2$, $d_0 \geq 6$. S
ince $d_1 + d_0 \leq 2 + 9 = 11$, we need $d_2 \geq 9$. Only solution: $d_2=9, d
_1=2, d_0=9 \Rightarrow n = 929$.

**Case $(0,1,1)$:** $d_0 \leq 5$, $d_1 \geq 4$, $d_2 + 9 \geq 10 \Rightarrow d_2
 \geq 1$. Then $d_2+d_1+d_0=20$ with $d_1 \geq 4$, $d_0 \leq 5$. Since $d_1 + d_
0 \leq 9 + 5 = 14$, we need $d_2 \geq 6$. Setting $d_2 = 6$: $d_1 + d_0 = 14$ wi
th $d_1 \geq 4$, $d_0 \leq 5 \Rightarrow d_1 = 9, d_0 = 5 \Rightarrow n = 695$.
