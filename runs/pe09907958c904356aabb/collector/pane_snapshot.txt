Looking at this problem, I need to determine whether $\limsup_{n\to\infty}\sum_{
i=1}^n a_iX_i < \infty$ a.s. implies $\frac{1}{n}\sum_{i=1}^n a_i\mathsf{E}X_i \
to 0$.

**Answer: The statement is FALSE.** I'll construct a counterexample.

## Counterexample

Let $\{A_n\}_{n\geq 1}$ be independent events with $P(A_n) = \frac{1}{n^2}$. Set
 $a_n = 1$ for all $n$, and define:
$$X_n = n^2 \cdot \mathbf{1}_{A_n}.$$

**Verification of hypotheses:**

1. **Nonnegative:** $X_n \geq 0$. ✓

2. **Bounded:** $X_n \leq n^2$ a.s., so each $X_n$ is bounded (the bound may dep
end on $n$). ✓

3. **Positive constants:** $a_n = 1 > 0$. ✓

4. **$\limsup S_n < \infty$ a.s.:** Since $\sum_{n=1}^{\infty} P(A_n) = \sum_{n=
1}^{\infty} \frac{1}{n^2} < \infty$, the **Borel–Cantelli lemma** (first part, n
o independence needed) gives $P(A_n \text{ i.o.}) = 0$. Thus, almost surely, onl
y finitely many $A_n$ occur. Therefore:
$$S_\infty = \sum_{n=1}^{\infty} a_n X_n = \sum_{n=1}^{\infty} n^2 \mathbf{1}_{A
_n}$$
is a sum of only finitely many nonzero terms (each finite), hence $S_\infty < \i
nfty$ a.s. Since $S_n = \sum_{i=1}^n a_i X_i$ is non-decreasing (all terms nonne
g), $\limsup_{n\to\infty} S_n = S_\infty < \infty$ a.s. ✓

**Checking the conclusion:**

$$\mathsf{E}X_n = n^2 \cdot P(A_n) = n^2 \cdot \frac{1}{n^2} = 1.$$

Therefore:
$$\frac{1}{n}\sum_{i=1}^n a_i \mathsf{E}X_i = \frac{1}{n}\sum_{i=1}^n 1 = 1 \qua
d \text{for all } n.$$

So $\frac{1}{n}\sum_{i=1}^n a_i \mathsf{E}X_i \to 1 \neq 0$.

## Why the intuition fails

One might hope that $S_n \to S_\infty < \infty$ a.s. forces $\mathsf{E}[S_n]/n \
to 0$. When $\mathsf{E}[S_\infty] < \infty$, this is indeed true (since $\mathsf
{E}[S_n] \leq \mathsf{E}[S_\infty] < \infty$ implies $\mathsf{E}[S_n]/n \to 0$).
 However, $S_\infty < \infty$ a.s. does **not** imply $\mathsf{E}[S_\infty] < \i
nfty$. In the counterexample, $\mathsf{E}[S_\infty] = \sum_{n=1}^\infty \mathsf{
E}X_n = \sum_{n=1}^\infty 1 = \infty$, even though $S_\infty < \infty$ a.s. The
heavy tail of $S_\infty$ (large values on very rare events) allows $\mathsf{E}[S
_n]$ to grow linearly while $S_n$ converges a.s.
