## Solution

We compute $\mathbb{P}\{T_2 < T_{-1} < T_3\}$ for standard Brownian motion $X_t$
 starting at $X_0 = 0$.

**Decomposition via the Strong Markov Property.**

The event $\{T_2 < T_{-1} < T_3\}$ requires:
1. Brownian motion hits $2$ before $-1$.
2. Thereafter (starting from $2$), it hits $-1$ before $3$.

By the strong Markov property, $X_{T_2 + t} - X_{T_2}$ is a standard Brownian mo
tion independent of $\mathcal{F}_{T_2}$. Since $X_{T_2} = 2$, the post-$T_2$ pro
cess is a Brownian motion starting at $2$. Thus the two events are independent:

$$\mathbb{P}(T_2 < T_{-1} < T_3) = \mathbb{P}(T_2 < T_{-1}) \cdot \mathbb{P}_{2}
(T_{-1} < T_3).$$

**Hitting probability formula.** For Brownian motion starting at $x \in (a,b)$,
the process $X_{t \wedge T_{a,b}}$ is a bounded martingale, so by optional stopp
ing:

$$x = a\,\mathbb{P}(T_a < T_b) + b\,\mathbb{P}(T_b < T_a), \qquad \mathbb{P}(T_a
<T_b)+\mathbb{P}(T_b<T_a)=1.$$

Solving gives $\mathbb{P}_x(T_a < T_b) = \dfrac{b - x}{b - a}$.

**Step 1.** Starting at $x=0$, with $a=-1$, $b=2$:

$$\mathbb{P}(T_{-1} < T_2) = \frac{2 - 0}{2-(-1)} = \frac{2}{3}, \qquad \mathbb{
P}(T_2 < T_{-1}) = 1 - \frac{2}{3} = \frac{1}{3}.$$

**Step 2.** Starting at $x=2$, with $a=-1$, $b=3$:

$$\mathbb{P}_{2}(T_{-1} < T_3) = \frac{3 - 2}{3 - (-1)} = \frac{1}{4}.$$

**Combining:**

$$\mathbb{P}\{T_2 < T_{-1} < T_3\} = \frac{1}{3} \cdot \frac{1}{4} = \boxed{\dfr
ac{1}{12}}.$$
