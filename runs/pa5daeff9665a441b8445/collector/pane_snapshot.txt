## 证明

我们使用 Cantor 空间 $C = \{0,1\}^{\mathbb{N}}$ 的 clopen（既开又闭）子集构成的
Boolean algebra $\mathcal{B}$（配备乘积拓扑）。这是一个经典的 atomless Boolean a
lgebra。

**断言 1：$\mathcal{B}$ 是 atomless 的。**

设 $U \in \mathcal{B}$ 为非空。由于 $U$ 在乘积拓扑中是开集，它仅依赖于有限个坐标
：存在 $N$ 使得 $U$ 中的成员资格由前 $N$ 个坐标决定。因此 $U$ 是形如 $N_\sigma =
 \{x \in C : x|_N = \sigma\}$ 的柱集（cylinder sets）的有限并集，其中 $\sigma \i
n \{0,1\}^N$。

由于 $U$ 不依赖于坐标 $N+1$，集合 $U_0 = U \cap \{x : x_{N+1} = 0\}$ 和 $U_1 = U
 \cap \{x : x_{N+1} = 1\}$ 均非空（任何将前 $N$ 个坐标赋值后落入 $U$ 的方式，都
可以通过扩展 $x_{N+1}$ 的任意值来实现）。两者均为 clopen，$U_0 \cup U_1 = U$，且
 $U_0, U_1 \subsetneq U$。因此 $U$ 不是原子（atom）。由于 $U$ 是任意的，$\mathca
l{B}$ 是 atomless 的。

**构造。**

对于每个 $n \geq 1$，定义 $a_n = \{x \in C : x_n = 1\}$。这是 clopen 的（它是固
定第 $n$ 个坐标为 1 的柱集的并集），因此 $a_n \in \mathcal{B}$。

**断言 2：序列 $(a_n)_{n \geq 1}$ 生成了 $\mathcal{B}$。**

每个 clopen 集 $U \in \mathcal{B}$ 仅依赖于有限个坐标 $i_1, \ldots, i_k$，因此它
是形如 $\{x : x_{i_1} = \epsilon_1, \ldots, x_{i_k} = \epsilon_k\}$ 的柱集的有限
并集。每个这样的柱集是 $\bigcap_{j=1}^k a_{i_j}^{\epsilon_j}$，其中 $a^1 = a$ 且
 $a^0 = \neg\, a$。因此 $U$ 是 $a_{i_1}, \ldots, a_{i_k}$ 的有限 Boolean 组合，
属于由 $\{a_n\}$ 生成的子代数。

**断言 3：该序列元素的任何非平凡有限 Boolean 组合都不等于零。**

设 $f : \{0,1\}^k \to \{0,1\}$ 为一个不恒等于零的 Boolean 函数，并设 $i_1, \ldot
s, i_k$ 为不同的正整数。组合 $f(a_{i_1}, \ldots, a_{i_k})$ 是集合：
$$\bigcup_{\substack{(\epsilon_1, \ldots, \epsilon_k) \in \{0,1\}^k \\ f(\epsilo
n_1, \ldots, \epsilon_k) = 1}} \{x \in C : x_{i_1} = \epsilon_1, \ldots, x_{i_k}
 = \epsilon_k\}.$$

由于 $f$ 不恒为零，存在 $(\epsilon_1^*, \ldots, \epsilon_k^*)$ 使得 $f(\epsilon_
1^*, \ldots, \epsilon_k^*) = 1$。相应的柱集非空：我们通过将坐标 $i_1, \ldots, i_
k$ 设置为 $\epsilon_1^*, \ldots, \epsilon_k^*$ 并将所有其他坐标设置为 $0$ 来构造
 $C$ 的一个元素。因此该并集非空，所以 $f(a_{i_1}, \ldots, a_{i_k}) \neq \emptyse
t = 0$。

**备注。** Boolean 代数 $\mathcal{B}$ 同构于可数生成元的自由 Boolean 代数。其生
成元根据构造是独立的（自由 = 在生成元上没有任何关系），且可数生成元的自由代数是
atomless 的，因为任何依赖于 $x_1, \ldots, x_N$ 的非零元素 $b$ 都可以被 $b \wedge
 x_{N+1}$ 和 $b \wedge \neg x_{N+1}$ 分裂——两者都是严格小于 $b$ 的，且它们的并集
为 $b$，所以至少有一个是非零的。这提供了相同构造的抽象视角。

**结论。** 在 Cantor 空间 clopen 子集的 atomless Boolean 代数 $\mathcal{B}$ 中的
序列 $(a_n)_{n \geq 1}$（其中 $a_n = \{x \in \{0,1\}^{\mathbb{N}} : x_n = 1\}$）
生成了 $\mathcal{B}$，并且其元素的任何非平凡有限 Boolean 组合都不等于零。$\black
square$
