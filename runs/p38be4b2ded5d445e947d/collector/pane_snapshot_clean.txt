# The Halting Problem

**Claim:** There does **not** exist a Turing Machine that can decide, for every
pair (Turing Machine $M$, input $w$), whether $M$ halts on $w$.

## Proof (by contradiction / diagonalization)

Suppose, for contradiction, that such a decider exists. That is, suppose there i
s a Turing Machine $H$ with the following behavior:

- **Input:** an encoding $\langle M, w\rangle$ of a Turing machine $M$ and an in
put string $w$.
- **Output:**
  - $H$ halts and **accepts** if $M$ halts on input $w$.
  - $H$ halts and **rejects** if $M$ does **not** halt on input $w$.

The key property of $H$ is that it **always halts** — it is a *decider*, not jus
t a recognizer.

### Constructing the diagonal machine $D$

From $H$ we construct a new Turing machine $D$ that takes a single argument — th
e encoding $\langle M\rangle$ of a Turing machine $M$ — and behaves as follows:

> On input $\langle M\rangle$:
> 1. Simulate $H$ on $\langle M, \langle M\rangle\rangle$ — that is, ask $H$ whe
ther $M$ halts when fed **its own description** as input.
> 2. If $H$ **accepts** (meaning "$M$ halts on $\langle M\rangle$"), then $D$ **
loops forever**.
> 3. If $H$ **rejects** (meaning "$M$ does not halt on $\langle M\rangle$"), the
n $D$ **halts**.

Since $H$ is assumed to always halt, step 1 always terminates, so $D$ is a well-
defined Turing machine whose only non-halting behavior is the deliberate infinit
e loop in step 2.

### The contradiction

Now feed $D$ its own description: run $D$ on input $\langle D\rangle$.

By the definition of $D$, what happens is:

1. $D$ simulates $H$ on $\langle D, \langle D\rangle\rangle$ — asking whether $D
$ halts on $\langle D\rangle$.
2. **Case A:** Suppose $D$ **halts** on $\langle D\rangle$. Then $H$ (being corr
ect) accepts $\langle D, \langle D\rangle\rangle$. By construction of $D$, when
$H$ accepts, $D$ **loops forever**. So $D$ does **not** halt on $\langle D\rangl
e$. **Contradiction.**
3. **Case B:** Suppose $D$ does **not** halt on $\langle D\rangle$. Then $H$ (be
ing correct) rejects $\langle D, \langle D\rangle\rangle$. By construction of $D
$, when $H$ rejects, $D$ **halts**. So $D$ **does** halt on $\langle D\rangle$.
**Contradiction.**

In both cases we reach a contradiction: $D$ halts on $\langle D\rangle$ if and o
nly if $D$ does not halt on $\langle D\rangle$.

### Conclusion

The contradiction arises from the sole assumption that $H$ exists. Therefore no
such Turing Machine $H$ can exist. The halting problem is **undecidable**.

$\blacksquare$
