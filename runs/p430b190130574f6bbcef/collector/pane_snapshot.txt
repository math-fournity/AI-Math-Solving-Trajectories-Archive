## Proof

Let $N = 3^{100} + 1$ and $\theta_k = \dfrac{2\pi \cdot 3^k}{N}$.

**Key identity.** For any $\theta$,
$$1 + 2\cos\theta = \frac{\sin(3\theta/2)}{\sin(\theta/2)}.$$
*Proof of identity:* $\dfrac{\sin(3x)}{\sin x} = 3 - 4\sin^2 x = 1 + 2\cos(2x)$,
 so setting $\theta = 2x$ gives $1 + 2\cos\theta = \dfrac{\sin(3\theta/2)}{\sin(
\theta/2)}$.

**Apply to each factor.** With $\theta_k = \dfrac{2\pi \cdot 3^k}{N}$:
$$1 + 2\cos\theta_k = \frac{\sin\!\left(\frac{3}{2}\cdot\frac{2\pi\cdot 3^k}{N}\
right)}{\sin\!\left(\frac{1}{2}\cdot\frac{2\pi\cdot 3^k}{N}\right)} = \frac{\sin
\!\left(\frac{\pi\cdot 3^{k+1}}{N}\right)}{\sin\!\left(\frac{\pi\cdot 3^k}{N}\ri
ght)}.$$

**Telescoping product.**
$$\prod_{k=1}^{100}\left(1+2\cos\theta_k\right) = \prod_{k=1}^{100}\frac{\sin\!\
left(\frac{\pi\cdot 3^{k+1}}{N}\right)}{\sin\!\left(\frac{\pi\cdot 3^k}{N}\right
)} = \frac{\sin\!\left(\frac{\pi\cdot 3^{101}}{N}\right)}{\sin\!\left(\frac{\pi\
cdot 3}{N}\right)}.$$

**Evaluate the numerator.** Since $N = 3^{100}+1$,
$$\frac{3^{101}}{N} = \frac{3\cdot 3^{100}}{3^{100}+1} = 3\!\left(1 - \frac{1}{3
^{100}+1}\right) = 3 - \frac{3}{N}.$$

Therefore
$$\sin\!\left(\frac{\pi\cdot 3^{101}}{N}\right) = \sin\!\left(3\pi - \frac{3\pi}
{N}\right).$$

Using $\sin(3\pi - x) = \sin 3\pi\cos x - \cos 3\pi\sin x = 0 - (-1)\sin x = \si
n x$:
$$\sin\!\left(3\pi - \frac{3\pi}{N}\right) = \sin\!\left(\frac{3\pi}{N}\right).$
$

**Conclusion.** The numerator equals $\sin\!\left(\dfrac{3\pi}{N}\right)$, which
 is exactly the denominator:
$$\prod_{k=1}^{100}\left(1+2\cos\left(\frac{2\pi \cdot 3^k}{3^{100}+1}\right)\ri
ght) = \frac{\sin(3\pi/N)}{\sin(3\pi/N)} = \boxed{1}.$$
