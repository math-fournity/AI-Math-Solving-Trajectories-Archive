**Answer: Yes, such a function exists.**

**Construction.** Let $a_n = \tfrac12 + 2^{-(n+1)}$ for $n = 1,2,3,\dots$, so $\
{a_n\} \subset (\tfrac12, \tfrac34]$, the $a_n$ are distinct, and $a_n \to \tfra
c12$. Define $f:[0,1]\to\mathbb{R}$ by
$$
f(x) \;=\; \sum_{n=1}^{\infty} 2^{-n}\,\mathbf{1}_{[a_n,\,1]}(x)
\;=\; \sum_{\{n\,:\,a_n \le x\}} 2^{-n}.
$$
The series is bounded by $\sum 2^{-n}=1$, so $f$ is well defined. Since each sum
mand is nondecreasing, $f$ is **monotone increasing**; consequently the one-side
d limits $f(c^-)=\sup_{x<c}f(x)$ and $f(c^+)=\inf_{x>c}f(x)$ exist at every $c\i
n[0,1]$.

**Locating the discontinuities.** For any $c$,
$$
f(c^+) = \sum_{\{n:\,a_n\le c\}}2^{-n}, \qquad
f(c^-) = \sum_{\{n:\,a_n<c\}}2^{-n},
$$
because as $x\downarrow c$ the index set $\{n:a_n\le x\}$ decreases to $\{n:a_n\
le c\}$, and as $x\uparrow c$ it increases to $\{n:a_n<c\}$. Also $f(c)=\sum_{\{
n:a_n\le c\}}2^{-n}=f(c^+)$, so $f$ is right-continuous everywhere. The jump at
$c$ is
$$
f(c^+)-f(c^-)=\sum_{\{n:\,a_n=c\}}2^{-n}.
$$
Since the $a_n$ are distinct, this equals $2^{-k}>0$ when $c=a_k$, and equals $0
$ when $c\notin\{a_n\}$. Hence:

- $f$ is continuous at every $c\notin\{a_n\}$ (in particular at the accumulation
 point $c=\tfrac12$, since $\tfrac12\notin\{a_n\}$: both one-sided limits equal
$f(\tfrac12)=\sum_{\{n:a_n\le 1/2\}}2^{-n}=0$).
- At each $a_k$, both one-sided limits exist and differ by $2^{-k}$, so $a_k$ is
 a **jump discontinuity**.

Thus **every** discontinuity of $f$ is a jump discontinuity.

**Why $f$ is not piecewise continuous.** The discontinuity set is exactly $\{a_n
:n\ge1\}$, an infinite set contained in $(\tfrac12,\tfrac34]\subset[0,1]$ and ac
cumulating at $\tfrac12$. The finite subinterval $[0,1]$ (indeed any neighborhoo
d of $\tfrac12$) contains infinitely many discontinuities. By the given definiti
on, a piecewise-continuous function must have only finitely many discontinuities
 in every finite subinterval. Therefore $f$ is **not** piecewise continuous.

**Conclusion.** The function $f$ has only jump discontinuities, yet it has infin
itely many of them accumulating inside $[0,1]$, so it is not piecewise continuou
s. Hence such a function does exist. $\blacksquare$
