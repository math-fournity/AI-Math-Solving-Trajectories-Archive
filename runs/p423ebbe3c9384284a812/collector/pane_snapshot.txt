## 解答

**答案：** 当且仅当 $n = 2k - 1$（即 $n$ 为奇数且 $k = \frac{n+1}{2}$）时，所要
求的选取是可能的。

### 必要性

选择 $n$ 个方格，且任意两个方格不在同一行或同一列，对应于 $\{1, \dots, n\}$ 的一
个排列 $\sigma$，即选取方格 $(i, \sigma(i))$，其中 $i = 1, \dots, n$。$(i, \sigm
a(i))$ 处的值为 $i + \sigma(i) - k$。

我们需要多重集 $\{i + \sigma(i) - k : i = 1, \dots, n\}$ 等于 $\{1, 2, \dots, n\
}$，等价地，$\{i + \sigma(i)\}$ 等于 $\{k+1, k+2, \dots, k+n\}$。

对两边求和：
$$\sum_{i=1}^{n} \bigl(i + \sigma(i)\bigr) = \sum_{i=1}^{n} i + \sum_{i=1}^{n} \
sigma(i) = 2 \cdot \frac{n(n+1)}{2} = n(n+1),$$
因为 $\sigma$ 是一个排列。而
$$\sum_{j=1}^{n}(k + j) = nk + \frac{n(n+1)}{2}.$$
令两者相等得到 $n(n+1) = nk + \frac{n(n+1)}{2}$，即 $\frac{n(n+1)}{2} = nk$。由
于 $n > 0$，我们得到 $n + 1 = 2k$，即
$$n = 2k - 1.$$

### 充分性

现在假设 $n = 2k - 1$。我们构造一个排列 $\sigma$，使得 $\{i + \sigma(i)\} = \{k+
1, k+2, \dots, 3k-1\}$（注意 $k + n = k + 2k - 1 = 3k - 1$）。

定义 $\sigma$ 为循环移位 $\sigma(i) = \bigl((i + k - 2) \bmod n\bigr) + 1$，即 $
\sigma(i) = i + (k-1)$（当 $i + k - 1 \le n$ 时），否则 $\sigma(i) = i + (k-1) -
 n$。这是一个有效的排列（移位 $k-1$）。

**求和计算。** 令 $c = k - 1$。

- **当 $i = 1, \dots, n - c = k$ 时**（即 $i + c \le n$）：$\sigma(i) = i + c$，
所以 $i + \sigma(i) = 2i + c$。当 $i$ 从 $1$ 变到 $k$ 时，这给出了值 $k+1, \, k+
3, \, \dots, \, 3k-1$（$k$ 个值，每隔一个取一个）。

- **当 $i = k+1, \dots, n = 2k-1$ 时**（即 $i + c > n$）：$\sigma(i) = i + c - n
$，所以 $i + \sigma(i) = 2i + c - n = 2i - k$。当 $i$ 从 $k+1$ 变到 $2k-1$ 时，
这给出了值 $k+2, \, k+4, \, \dots, \, 3k-2$（$k-1$ 个值，每隔一个取一个）。

这两个集合分别是 $\{k+1, k+3, \dots, 3k-1\}$ 和 $\{k+2, k+4, \dots, 3k-2\}$，它
们的并集恰好是 $\{k+1, k+2, \dots, 3k-1\}$ —— 所有 $n = 2k-1$ 个连续整数，每个恰
好出现一次。

因此 $\{i + \sigma(i) - k\} = \{1, 2, \dots, n\}$，这正是所要求的。

**小例子验证 ($n=5, k=3$)：** $\sigma = (3,4,5,1,2)$。求和 $i + \sigma(i) = (4,6
,8,5,7) = \{4,5,6,7,8\} = \{k+1,\dots,3k-1\}$。数值 $= (1,3,5,2,4) = \{1,2,3,4,5
\}$。 ✓

### 结论

所要求的选取是可能的，当且仅当 $n$ 和 $k$ 满足 $n = 2k - 1$。
