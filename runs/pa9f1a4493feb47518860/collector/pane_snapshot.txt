## 证明

**观察。** 题目中的序列恰好由那些在**三进制表示中每位数字仅为 0 或 1** 的正整数
组成（没有数字 2）。事实上，“3 的幂或不同 3 的幂之和”正是三进制中仅使用数字 0 和
 1 的整数集合，且每个这样的数都有唯一的此类表示。该序列按递增顺序列出了这些数。

**关键映射。** 我声明，将正整数 $n$ 映射为“以 $n$ 的二进制表示作为三进制数读取”
所得的数，给出了序列项与 $\mathbb{Z}_{>0}$ 之间的保序双射。

设 $f(n)$ 为将 $n$ 的二进制表示作为三进制数读取所得的整数。例如：
- $n=1$: 二进制 $1$ → $f(1)=1$ ✓
- $n=2$: 二进制 $10$ → $f(2)=3$ ✓
- $n=3$: 二进制 $11$ → $f(3)=4$ ✓
- $n=4$: 二进制 $100$ → $f(4)=9$ ✓
- $n=5$: 二进制 $101$ → $f(5)=10$ ✓
- $n=6$: 二进制 $110$ → $f(6)=12$ ✓
- $n=7$: 二进制 $111$ → $f(7)=13$ ✓

这些与给定的序列 $1,3,4,9,10,12,13,\ldots$ 相匹配。

**双射性。** 每个三进制表示仅使用数字 $\{0,1\}$ 的正整数对应于唯一的二进制字符串
（相同的数字），因此对应于唯一的正整数 $n$。因此 $f$ 是从 $\mathbb{Z}_{>0}$ 到序
列项集合的双射。

**保序性。** 设 $n < m$。设 $n$ 的二进制表示为 $b$，$m$ 的二进制表示为 $c$。按字
典顺序比较 $b$ 和 $c$（左侧补零至相同长度）：因为 $n < m$，$c$ 在字典顺序上严格
大于 $b$。由于 $\{0,1\}$ 上的字典顺序与将这些字符串作为三进制数读取所得到的数值
顺序一致，我们得到 $f(n) < f(m)$。因此 $f$ 是严格递增的，所以序列的第 $k$ 项恰好
是 $f(k)$。

**计算 $f(2014)$。** 将 2014 转换为二进制：
$$2014 = 1024+512+256+128+64+16+8+4+2 = 2^{10}+2^9+2^8+2^7+2^6+2^4+2^3+2^2+2^1.$
$

因此 $2014$ 的二进制表示为 $\boxed{11111011110}$（位 $10,9,8,7,6,4,3,2,1$ 为 1；
位 $5$ 和 $0$ 为 0）。

验证：$1024+512+256+128+64 = 1984$，且 $16+8+4+2 = 30$，总计 $1984+30 = 2014$。
✓

现在将 $11111011110$ 作为三进制数读取：
$$f(2014) = 3^{10}+3^9+3^8+3^7+3^6+3^4+3^3+3^2+3^1.$$

使用 $3^1=3,\;3^2=9,\;3^3=27,\;3^4=81,\;3^5=243,\;3^6=729,\;3^7=2187,\;3^8=6561,
\;3^9=19683,\;3^{10}=59049$：

$$\begin{aligned}
f(2014) &= 59049+19683+6561+2187+729+81+27+9+3\\
&= 78732+6561+2187+729+81+27+9+3\\
&= 85293+2187+729+81+27+9+3\\
&= 87480+729+81+27+9+3\\
&= 88209+81+27+9+3\\
&= 88290+27+9+3\\
&= 88317+9+3\\
&= 88326+3\\
&= 88329.
\end{aligned}$$

**答案：** 该序列的第 2014 项为 $\boxed{88329}$。
