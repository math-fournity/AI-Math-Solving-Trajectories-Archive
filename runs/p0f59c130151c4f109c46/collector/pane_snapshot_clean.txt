## Proof

Let $\mathbb{I} = (0,1)\setminus\mathbb{Q}$ denote the set of all irrational num
bers in the open interval $(0,1)$, and let $\mathbb{R}$ denote the set of all re
al numbers. We show that $\mathbb{I}$ and $\mathbb{R}$ are **equivalent** (i.e.,
 there exists a bijection between them), so they have the same cardinality.

**Step 1: $|\mathbb{R}| = |\mathbb{I}|$ would follow from $|\mathbb{I}| = \mathf
rak{c}$, where $\mathfrak{c} = |\mathbb{R}|$.**

We use two standard facts:
- The interval $(0,1)$ has cardinality $\mathfrak{c}$ (e.g., via the bijection $
x \mapsto \tan(\pi(x-\tfrac12))$ from $(0,1)$ to $\mathbb{R}$).
- The set $\mathbb{Q}\cap(0,1)$ of rationals in $(0,1)$ is **countable** (since
$\mathbb{Q}$ is countable).

es a set of cardinality $\mathfrak{c}$.**

cardinality $\mathfrak{c}$ and we remove only countably many points, we claim $|
\mathbb{I}| = \mathfrak{c}$.

A standard clean proof: Since $\mathbb{Q}\cap(0,1)$ is countable, enumerate it a

- $h(r_n) = r_{2n}$ for each chosen irrational $r_n$,

**Step 3: Compose to get a bijection $\mathbb{I}\to\mathbb{R}$.**

Since $|\mathbb{I}| = \mathfrak{c} = |\mathbb{R}|$, there exists a bijection bet
