# Solution of the Damped Wave Equation

## Problem

Solve $u_{tt}(t,x) + 2u_t(t,x) = u_{xx}(t,x)$ with $u(0,x)=x^2$, $u_t(0,x)=1$, u
sing Laplace transform and Taylor series expansion.

---

## Step 1: Apply the Laplace Transform in $t$

Let $U(s,x) = \mathcal{L}\{u(t,x)\}(s) = \int_0^\infty u(t,x)\,e^{-st}\,dt$.

Using the standard Laplace transform identities:

$$\mathcal{L}\{u_{tt}\} = s^2 U - s\,u(0,x) - u_t(0,x) = s^2 U - s x^2 - 1$$

$$\mathcal{L}\{u_t\} = s\,U - u(0,x) = s\,U - x^2$$

$$\mathcal{L}\{u_{xx}\} = U_{xx}$$

Substituting into the PDE $u_{tt} + 2u_t = u_{xx}$:

$$(s^2 U - s x^2 - 1) + 2(s U - x^2) = U_{xx}$$

Rearranging:

$$U_{xx} - (s^2 + 2s)\,U = -(s+2)\,x^2 - 1$$

---

## Step 2: Solve the ODE in $x$

Set $\lambda^2 = s^2 + 2s = s(s+2)$. The ODE becomes:

$$U_{xx} - \lambda^2 U = -(s+2)\,x^2 - 1$$

**Particular solution.** Since the right-hand side is a polynomial in $x$, we tr
y a polynomial ansatz $U_p = ax^2 + bx + c$:

$$U_{p,xx} = 2a$$

Substituting:

$$2a - \lambda^2(ax^2 + bx + c) = -(s+2)\,x^2 - 1$$

Matching coefficients:

| Power | Equation | Result |
|-------|----------|--------|
| $x^2$ | $-\lambda^2 a = -(s+2)$ | $a = \dfrac{s+2}{\lambda^2} = \dfrac{s+2}{s(
s+2)} = \dfrac{1}{s}$ |
| $x^1$ | $-\lambda^2 b = 0$ | $b = 0$ |
| $x^0$ | $2a - \lambda^2 c = -1$ | $c = \dfrac{2a+1}{\lambda^2} = \dfrac{\frac{
2}{s}+1}{s(s+2)} = \dfrac{s+2}{s^2(s+2)} = \dfrac{1}{s^2}$ |

So the particular solution is:

$$U_p = \frac{x^2}{s} + \frac{1}{s^2}$$

**Homogeneous solution.** The general solution is $U = U_p + A e^{\lambda x} + B
 e^{-\lambda x}$. Since the initial data $u(0,x) = x^2$ is a polynomial in $x$,
and the PDE preserves polynomial structure (differentiation in $x$ maps polynomi
als to polynomials), the solution $u(t,x)$ must remain a polynomial in $x$ for a
ll $t$. This forces $A = B = 0$, since the exponential terms would introduce non
-polynomial (and unbounded) behavior in $x$.

Therefore:

$$\boxed{U(s,x) = \frac{x^2}{s} + \frac{1}{s^2}}$$

---

## Step 3: Invert the Laplace Transform

Using standard inverse Laplace transforms:

$$\mathcal{L}^{-1}\left\{\frac{1}{s}\right\} = 1, \qquad \mathcal{L}^{-1}\left\{
\frac{1}{s^2}\right\} = t$$

Since $x$ is treated as a parameter:

$$u(t,x) = x^2 \cdot \mathcal{L}^{-1}\left\{\frac{1}{s}\right\} + \mathcal{L}^{-
1}\left\{\frac{1}{s^2}\right\} = x^2 \cdot 1 + t$$

$$\boxed{u(t,x) = x^2 + t}$$

---

## Step 4: Verification via Taylor Series Expansion

Expand $u(t,x)$ as a Taylor series in $t$ around $t = 0$:

$$u(t,x) = \sum_{n=0}^{\infty} \frac{u^{(n)}(0,x)}{n!}\,t^n$$

where $u^{(n)}$ denotes the $n$-th partial derivative with respect to $t$.

**Compute the derivatives at $t=0$ using the PDE $u_{tt} = u_{xx} - 2u_t$:**

- $n=0$: $\;u(0,x) = x^2$
- $n=1$: $\;u_t(0,x) = 1$
- $n=2$: $\;u_{tt}(0,x) = u_{xx}(0,x) - 2u_t(0,x) = 2 - 2(1) = 0$
- $n=3$: $\;u_{ttt} = \partial_t(u_{tt}) = \partial_t(u_{xx} - 2u_t) = u_{xxt} -
 2u_{tt}$

  $\;u_{xxt}(0,x) = \partial_{xx}(u_t(0,x)) = \partial_{xx}(1) = 0$, and $u_{tt}
(0,x)=0$, so $u_{ttt}(0,x) = 0$.

- $n \geq 2$ (induction): Suppose $u^{(n)}(0,x) = 0$ for all $2 \leq n \leq k$.
Then:

  $$u^{(k+1)} = \partial_t\,u^{(k)} = \partial_t\!\left(\partial_x^{2}\,u^{(k-2)
} - 2\,u^{(k-1)}\right) = \partial_x^{2}\,u^{(k-1)} - 2\,u^{(k)}$$

  By the induction hypothesis, $u^{(k-1)}(0,x) = 0$ and $u^{(k)}(0,x) = 0$, so $
u^{(k+1)}(0,x) = 0$.

By induction, **all derivatives of order $n \geq 2$ vanish at $t = 0$**.

Therefore the Taylor series terminates:

$$u(t,x) = \frac{x^2}{0!} + \frac{1}{1!}\,t + 0 + 0 + \cdots = x^2 + t$$

This confirms the result obtained from the Laplace transform.

---

## Step 5: Direct Verification

Check the PDE and initial conditions for $u(t,x) = x^2 + t$:

| Condition | Computation | Result |
|-----------|-------------|--------|
| $u_{tt} + 2u_t = u_{xx}$ | $0 + 2(1) = 2$ and $u_{xx} = 2$ | $2 = 2$ ✓ |
| $u(0,x) = x^2$ | $0^2 + x^2 = x^2$... wait, $u(0,x) = x^2 + 0 = x^2$ | ✓ |
| $u_t(0,x) = 1$ | $\partial_t(x^2 + t) = 1$ | ✓ |

All conditions are satisfied.

---

## Conclusion

The solution to the damped wave equation $u_{tt} + 2u_t = u_{xx}$ with initial c
onditions $u(0,x) = x^2$ and $u_t(0,x) = 1$ is:

$$\boxed{u(t,x) = x^2 + t}$$

The Laplace transform reduces the PDE to an ODE in $x$ whose polynomial particul
ar solution (with zero homogeneous part, justified by the polynomial nature of t
he data) inverts directly to $x^2 + t$. The Taylor series expansion in $t$ confi
rms this: all time-derivatives of order $\geq 2$ vanish at $t=0$ (proved by indu
ction using the PDE), so the series truncates to exactly two terms.
