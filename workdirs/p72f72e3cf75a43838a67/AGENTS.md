# Problem

A high-security data vault is protected by a network of $n$ unique biometric scanners, where $n$ is an integer between 4 and 20, inclusive. To test the system's redundancy, a security team generates a collection of $n$ distinct access keys. Each access key is programmed to grant entry only if a specific combination of exactly 3 different scanners is activated.

The vault's "overlap protocol" is considered active if, for any possible collection of $n$ such keys, there must exist at least two keys in that collection that share exactly one scanner in common.

Let $S$ be the set of all possible values of $n$ in the range $4 \le n \le 20$ for which this overlap protocol is guaranteed to be active. Calculate the sum of all integer values contained in $S$.
