Looking at this problem, I need to find the circumradius of the face triangle $\
mathcal{T}$ of an isosceles tetrahedron (disphenoid) with surface area 24, volum
e 4, and one edge of each face equal to 3.

## Setup

An isosceles tetrahedron has all four faces congruent. Let the face $\mathcal{T}
$ have sides $a, b, c$ with opposite edges of the tetrahedron paired as $(a,a),
(b,b), (c,c)$. Set $c = 3$, so $z = c^2 = 9$, $x = a^2$, $y = b^2$.

**Area constraint:** Each face has area $24/4 = 6$. Using the formula $\text{Are
a}^2 = \frac{1}{16}[2(xy + 9x + 9y) - (x^2 + y^2 + 81)]$:

$$576 = 2xy + 18x + 18y - x^2 - y^2 - 81$$

Let $u = x+y$, $v = x-y$. Then:

$$v^2 = 18u - 657 \quad \cdots (1)$$

(requiring $u \geq 36.5$)

**Volume constraint:** The disphenoid volume formula is $V = \frac{\sqrt{(x+y-z)
(x-y+z)(-x+y+z)}}{6\sqrt{2}}$. With $V=4$:

$$(u-9)(v+9)(9-v) = 1152 \quad \Longrightarrow \quad (u-9)(81 - v^2) = 1152 \qua
d \cdots (2)$$

## Solving the System

Substituting (1) into (2):

$$(u-9)\big(81 - (18u - 657)\big) = 1152$$
$$(u-9)(738 - 18u) = 1152$$
$$18(u-9)(41-u) = 1152$$
$$(u-9)(41-u) = 64$$
$$u^2 - 50u + 433 = 0$$
$$u = 25 \pm 8\sqrt{3}$$

Only $u = 25 + 8\sqrt{3} \approx 38.86$ satisfies $u \geq 36.5$. (The other root
 $\approx 11.14$ gives $v^2 < 0$.)

## Computing the Circumradius

The circumradius is $R = \frac{abc}{4 \cdot \text{Area}} = \frac{abc}{24} = \fra
c{3ab}{24} = \frac{ab}{8}$.

Compute $xy = \frac{u^2 - v^2}{4} = \frac{u^2 - 18u + 657}{4}$:

$$u^2 = (25+8\sqrt{3})^2 = 817 + 400\sqrt{3}, \quad 18u = 450 + 144\sqrt{3}$$
$$u^2 - 18u + 657 = 1024 + 256\sqrt{3}$$
$$xy = 256 + 64\sqrt{3} = 64(4 + \sqrt{3})$$

Therefore:
$$ab = \sqrt{xy} = 8\sqrt{4+\sqrt{3}}$$
$$R = \frac{ab}{8} = \sqrt{4+\sqrt{3}}$$

## Verification

**Volume check:** $(u-9)(81-v^2) = (16+8\sqrt{3})\cdot 144(2-\sqrt{3}) = 8(2+\sq
rt{3})\cdot 144(2-\sqrt{3}) = 1152 \cdot 1 = 1152$ ✓

**Acute check:** $v^2 = 144\sqrt{3}-207 \approx 42.4$, so $|v| \approx 6.51 < 9$
. Thus $x+9 > y$, $y+9 > x$, and $x+y > 9$ — all angles acute ✓

**Scalene check:** $c=3$, $a \approx 4.76$, $b \approx 4.02$ — all distinct ✓

**Uniqueness:** The system yields a single valid $u$, and $xy$ (hence $R$) is de
termined by $u$ alone. The "maximum" is this unique value.

## Answer

$$\boxed{R = \sqrt{4+\sqrt{3}}}$$
