## Solution

We evaluate $I = \int_0^{2\pi} \frac{d\theta}{5 - 3\sin\theta}$ using Cauchy's i
ntegral formula.

**Substitution.** Set $z = e^{i\theta}$, so $d\theta = \frac{dz}{iz}$ and $\sin\
theta = \frac{z - z^{-1}}{2i} = \frac{z^2 - 1}{2iz}$. Then

$$5 - 3\sin\theta = 5 - \frac{3(z^2-1)}{2iz} = \frac{10iz - 3z^2 + 3}{2iz} = \fr
ac{-3z^2 + 10iz + 3}{2iz}.$$

Hence

$$I = \oint_{|z|=1} \frac{2iz}{-3z^2 + 10iz + 3}\cdot\frac{dz}{iz} = \oint_{|z|=
1} \frac{2\,dz}{-3z^2 + 10iz + 3}.$$

**Factoring the denominator.** Solving $-3z^2 + 10iz + 3 = 0$, equivalently $3z^
2 - 10iz - 3 = 0$:

$$z = \frac{10i \pm \sqrt{(10i)^2 - 4\cdot 3\cdot(-3)}}{6} = \frac{10i \pm \sqrt
{-64}}{6} = \frac{10i \pm 8i}{6}.$$

So the roots are $z_1 = 3i$ and $z_2 = \tfrac{i}{3}$, giving

$$-3z^2 + 10iz + 3 = -3(z - 3i)\!\left(z - \tfrac{i}{3}\right).$$

**Locating the poles.** We have $|3i| = 3 > 1$ (outside the unit circle) and $\l
eft|\tfrac{i}{3}\right| = \tfrac{1}{3} < 1$ (inside). Thus only $z = \tfrac{i}{3
}$ lies inside the contour $|z| = 1$.

**Applying Cauchy's integral formula.** Write

$$I = \oint_{|z|=1} \frac{-2/3}{(z - 3i)\!\left(z - \tfrac{i}{3}\right)}\,dz.$$

Let $f(z) = \dfrac{-2/3}{z - 3i}$, which is analytic on and inside $|z| = 1$ (it
s pole at $3i$ is exterior). By Cauchy's integral formula,

$$I = 2\pi i\cdot f\!\left(\tfrac{i}{3}\right) = 2\pi i\cdot\frac{-2/3}{\tfrac{i
}{3} - 3i} = 2\pi i\cdot\frac{-2/3}{i\!\left(\tfrac{1}{3} - 3\right)} = 2\pi i\c
dot\frac{-2/3}{-\tfrac{8i}{3}}.$$

Simplifying,

$$I = 2\pi i\cdot\frac{-2/3}{-8i/3} = 2\pi i\cdot\frac{2}{8i} = 2\pi i\cdot\frac
{1}{4i} = \frac{2\pi i}{4i} = \frac{\pi}{2}.$$

**Conclusion.**

$$\boxed{\int_0^{2\pi}\frac{d\theta}{5 - 3\sin\theta} = \frac{\pi}{2}}.$$
