## Proof

,1,1)$ is excluded). Note:
$$x - t = x(1-yz) \geq 0, \quad y - t = y(1-xz) \geq 0, \quad z - t = z(1-xy) \g
eq 0,$$
since $yz, xz, xy \leq 1$. Also $x - t \leq 1 - t$ (since $x \leq 1$), and simil
arly for $y, z$. So all three factors in the numerator are non-negative and at m

**Step 1: Upper bound via AM-GM.** Since $x - t, y - t, z - t \geq 0$, by AM-GM:
$$(x-t)(y-t)(z-t) \leq \left(\frac{(x-t)+(y-t)+(z-t)}{3}\right)^3 = \left(\frac{
x+y+z-3t}{3}\right)^3.$$

**Step 2: Key inequality $x + y + z - xyz \leq 2$.** We prove that for all $x, y
, z \in [0,1]$:
$$x + y + z - xyz \leq 2.$$

Since $(1-x)(1-y) \geq 0$, we get $x + y \leq 1 + xy$. Therefore:
$$x + y + z \leq 1 + xy + z.$$
We need $1 + xy + z \leq 2 + xyz$, i.e., $xy + z \leq 1 + xyz$, i.e., $xy(1 - z)
 \leq 1 - z$. When $z < 1$, this reduces to $xy \leq 1$, which holds since $x, y
 \in [0,1]$. When $z = 1$, the original inequality becomes $x + y + 1 - xy \leq
2$, i.e., $1 - (1-x)(1-y) \leq 1$, which holds since $(1-x)(1-y) \geq 0$. ✓

**Step 3: Combining.** From Step 2: $x + y + z - 3t = (x + y + z - t) - 2t \leq
2 - 2t = 2(1 - t)$.

Substituting into Step 1:
$$(x-t)(y-t)(z-t) \leq \left(\frac{2(1-t)}{3}\right)^3 = \frac{8}{27}(1-t)^3.$$

Dividing by $(1-t)^3 > 0$:
$$f(x,y,z) = \frac{(x-t)(y-t)(z-t)}{(1-t)^3} \leq \frac{8}{27}.$$

**Step 4: The bound is attained in the limit.** Set $x = y = z = s$ with $s \in
[0,1)$. Then $t = s^3$ and:
$$f(s,s,s) = \frac{(s - s^3)^3}{(1 - s^3)^3} = \frac{s^3(1-s^2)^3}{(1-s^3)^3} =
\frac{s^3(1-s)^3(1+s)^3}{(1-s)^3(1+s+s^2)^3} = \left(\frac{s(1+s)}{1+s+s^2}\righ
t)^3.$$

Let $g(s) = \frac{s(1+s)}{1+s+s^2}$. Then:
$$g'(s) = \frac{(1+2s)(1+s+s^2) - s(1+s)(1+2s)}{(1+s+s^2)^2} = \frac{(1+2s)\cdot
 1}{(1+s+s^2)^2} > 0,$$
so $g$ is increasing on $[0,1)$. As $s \to 1^-$:
$$g(s) \to \frac{1 \cdot 2}{1+1+1} = \frac{2}{3}, \qquad f(s,s,s) \to \left(\fra
c{2}{3}\right)^3 = \frac{8}{27}.$$

**Step 5: Equality is not achieved.** Equality in AM-GM requires $x = y = z$. Eq
uality in $x + y + z - xyz \leq 2$ with $x = y = z$ requires $3s - s^3 = 2$, i.e

here in the domain, but $f \to 8/27$ along the diagonal.

**Conclusion.** The supremum of $f$ is:
