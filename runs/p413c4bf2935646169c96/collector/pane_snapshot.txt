## Solution

**Claim.** The minimum value of $M(a-b)$ over all $a, b \in U(V)$ is $\boxed{0}$
.

**Proof.**

First, $M$ is well-defined and non-negative: for any endomorphism $T$ and any un
it vector $v$, $|Tv| \ge 0$, so
$$M(T) = \min_{|v|=1}|Tv| \ge 0.$$

In particular, for every pair $a, b \in U(V)$, we have $M(a-b) \ge 0$.

To see that the value $0$ is attained, take $a = b$ (any unitary operator, for i
nstance $a = b = I$). Then $a - b = 0$, and
$$M(a-b) = M(0) = \min_{|v|=1}|0\cdot v| = \min_{|v|=1} 0 = 0.$$

Combining the lower bound $M(a-b) \ge 0$ with the attained value $M(a-b) = 0$ (a
t $a = b$), we conclude
$$\min_{a,b \in U(V)} M(a-b) = 0.$$

**Remark on the structure (for completeness).** Writing $a - b = b(b^{-1}a - I)$
 and using that left-multiplication by the unitary $b$ preserves all singular va
lues, we get $M(a-b) = M(u - I)$ where $u = b^{-1}a \in U(V)$. The singular valu
es of $u - I$ are $|\lambda_i - 1|$, where $\lambda_1, \dots, \lambda_n$ are the
 eigenvalues of $u$ (each on the unit circle). Hence
$$M(a-b) = \min_i |\lambda_i - 1|,$$
which ranges in $[0, 2]$: it equals $0$ whenever $u$ has an eigenvalue $1$ (in p
articular when $a = b$), and equals $2$ when $u = -I$ (i.e. $a = -b$). Thus the
minimum is $0$ and the maximum is $2$.
