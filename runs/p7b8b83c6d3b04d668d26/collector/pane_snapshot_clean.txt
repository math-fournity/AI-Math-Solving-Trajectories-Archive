## Solution

**Parametrize the curve.** The curve $C$ is the intersection of the cylinder $x^
2+y^2=a^2$ and the plane $\tfrac{x}{a}+\tfrac{z}{b}=1$.

On the cylinder, set
$$x = a\cos t,\quad y = a\sin t,\quad t\in[0,2\pi].$$
From the plane equation, $z = b\!\left(1-\tfrac{x}{a}\right) = b(1-\cos t)$.

The differentials are:
$$dx = -a\sin t\,dt,\quad dy = a\cos t\,dt,\quad dz = b\sin t\,dt.$$

**Compute each term of the integrand.**

$$y - z = a\sin t - b(1-\cos t) = a\sin t - b + b\cos t,$$
$$(y-z)\,dx = (a\sin t - b + b\cos t)(-a\sin t) = -a^2\sin^2 t + ab\sin t - ab\s
in t\cos t.$$

$$z - x = b(1-\cos t) - a\cos t = b - (a+b)\cos t,$$
$$(z-x)\,dy = \bigl(b-(a+b)\cos t\bigr)(a\cos t) = ab\cos t - a(a+b)\cos^2 t.$$

$$x - y = a\cos t - a\sin t = a(\cos t - \sin t),$$
$$(x-y)\,dz = a(\cos t - \sin t)(b\sin t) = ab\cos t\sin t - ab\sin^2 t.$$

**Sum the three contributions.** The cross terms $-ab\sin t\cos t$ and $+ab\cos
t\sin t$ cancel, giving

$$-a^2\sin^2 t + ab\sin t - a(a+b)\cos^2 t - ab\sin^2 t.$$

Group the quadratic terms:

$$-\bigl(a^2+ab\bigr)\sin^2 t - a(a+b)\cos^2 t + ab\sin t = -a(a+b)\bigl(\sin^2
t + \cos^2 t\bigr) + ab\sin t.$$

Using $\sin^2 t + \cos^2 t = 1$:

$$-a(a+b) + ab\sin t.$$

**Integrate over $[0,2\pi]$:**

$$\int_0^{2\pi}\!\bigl[-a(a+b) + ab\sin t\bigr]\,dt = -a(a+b)\cdot 2\pi + ab\cdo
t 0 = -2\pi a(a+b).$$

**Result.**

$$\boxed{\int_C (y-z)\,dx + (z-x)\,dy + (x-y)\,dz = -2\pi a(a+b).}$$
