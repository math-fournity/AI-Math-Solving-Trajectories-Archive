Looking at this problem, I need to determine which values of n ∈ {1,...,100} all
ow reaching a uniform distribution.

## Setup

Label children 0–5 around the circle. Child i is opposite child i+3 (mod 6). A m
ove at child i (requires ≥4 sweets): child i loses 4, and children i−1, i+1, i+3
 each gain 1. Total sweets decrease by 1 per move (one eaten).

The move vector at position i is: −4 at i, +1 at i−1, i+1, i+3 (mod 6).

## Fourier Analysis (Necessity)

Represent the move kernel as g = [−4, 1, 0, 1, 0, 1] (indices 0–5). Its discrete
 Fourier transform ĝ(ω^k) for ω = e^{2πi/6}:

| k | ĝ(k) |
|---|------|
| 0 | −1 |
| 1,5 | −4 |
| 2,4 | −4 |
| 3 | −7 |

If child i fires m_i times (nonneg integers), the final state in Fourier mode k
is:
$$\hat{f}(k) = n + \hat{g}(k)\cdot\hat{M}(k)$$
where $\hat{M}(k) = \sum_i m_i \,\omega^{-ik}$.

For the final state to be constant $(k,k,k,k,k,k)$, we need $\hat{f}(k)=0$ for $
k=1,2,3,4,5$:

- **k=1,2,4,5:** $\hat{M}(k) = n/4$ (must be real)
- **k=3:** $\hat{M}(3) = n/7$ (automatically real)

**Reality conditions** on $\hat{M}(1)$ and $\hat{M}(2)$:

- $\text{Im}(\hat{M}(1))=0 \Rightarrow m_1+m_2 = m_4+m_5$
- $\text{Im}(\hat{M}(2))=0 \Rightarrow m_1+m_4 = m_2+m_5$

These give $m_2=m_4$ and $m_1=m_5$. Setting $a=m_1=m_5$, $b=m_2=m_4$:

- **Re($\hat{M}(1)$):** $m_0 - m_3 + a - b = n/4$
- **Re($\hat{M}(2)$):** $m_0 + m_3 - a - b = n/4$
- **$\hat{M}(3)$:** $m_0 - m_3 - 2a + 2b = n/7$

Adding the first two: $m_0 = b + n/4$. Subtracting: $m_3 = a$.

Substituting into the third: $3(b-a) + n/4 = n/7$, giving:
$$a - b = \frac{n}{28}$$

Since $a, b$ are nonneg integers, **28 must divide n**. This is necessary.

## Sufficiency by Construction

For $n = 28t$ ($t \geq 1$), set $b=0$: $m_0 = 7t$, $m_1 = m_5 = t$, $m_2 = m_4 =
 0$, $m_3 = t$, final value $k = 3t$.

**Explicit sequence:**
1. **Fire child 0 exactly $7t$ times.** Each fire gives +1 to children 1, 3, 5.
Result: $(0,\; 7t,\; 0,\; 7t,\; 0,\; 7t)$. (Child 0 goes from $28t$ to $0$; vali
d since $28t \geq 4$ throughout.)

2. **Fire child 1 exactly $t$ times.** Each gives +1 to children 0, 2, 4. Child
1 goes from $7t$ to $3t$; valid since $7t - 4j \geq 4$ for $j \leq t-1$ (as $3t+
4 \geq 4$). Result: $(t,\; 3t,\; t,\; 7t,\; t,\; 7t)$.

3. **Fire child 3 exactly $t$ times.** Each gives +1 to children 2, 4, 0. Result
: $(2t,\; 3t,\; 2t,\; 3t,\; 2t,\; 7t)$.

4. **Fire child 5 exactly $t$ times.** Each gives +1 to children 4, 0, 2. Result
: $(3t,\; 3t,\; 3t,\; 3t,\; 3t,\; 3t)$. ✓

All firing constraints are satisfied (children 1, 3, 5 each start with $7t \geq
7 \geq 4$ and only lose sweets during their own firing turns; no other child giv
es them sweets).

## Verification

|---|---|-------------|-------------|-----------------|

## Conclusion

The necessary condition $28 \mid n$ is also sufficient. Within $\{1, \ldots, 100
\}$, the multiples of 28 are $28, 56, 84$ (since $28 \times 4 = 112 > 100$).

$$S = \{28, 56, 84\}, \qquad \sum_{n \in S} n = 28 + 56 + 84 = \boxed{168}$$
