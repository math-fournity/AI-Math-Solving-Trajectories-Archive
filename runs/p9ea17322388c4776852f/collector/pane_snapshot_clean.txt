## Proof

**Claim:** For every fixed integer $C$, the equation $2^n - 3^m = C$ has only fi
nitely many solutions in non-negative integers $(m, n)$ with $(m, n) \neq (2, 2)
$.

---

### Case 1: $C = 0$

The equation becomes $2^n = 3^m$. Since $2$ and $3$ are distinct primes, the onl
y solution in non-negative integers is $m = n = 0$ (giving $1 = 1$). So there is
 exactly one solution — certainly finite.

---

### Case 2: $C \neq 0$

We show that $m$ and $n$ are bounded by an effectively computable constant depen
ding on $C$, using **Baker's theorem on linear forms in logarithms**.

**Step 1: Reduction to a linear form in logarithms.**

Suppose $(m, n)$ is a solution with $m, n \geq 1$ and $3^m > 2|C|$. From $2^n -
3^m = C$:

$$\frac{2^n}{3^m} = 1 + \frac{C}{3^m}.$$

Taking logarithms:

$$\Lambda := n \log 2 - m \log 3 = \log\!\left(1 + \frac{C}{3^m}\right).$$

Since $|C/3^m| < 1/2$ and $|\log(1+x)| \leq 2|x|$ for $|x| \leq 1/2$:

$$|\Lambda| \leq \frac{2|C|}{3^m}. \tag{1}$$

**Step 2: Comparability of $m$ and $n$.**

From $3^m < 2^n \leq 3^m + |C| < 2 \cdot 3^m$ (using $3^m > |C|$), we get:

$$m \frac{\log 3}{\log 2} < n \leq m \frac{\log 3}{\log 2} + \frac{\log 2}{\log
2} = m\frac{\log 3}{\log 2} + 1.$$

So $n = \Theta(m)$; in particular $\max(n, m) \leq c_0 \, m$ for an absolute con
stant $c_0 = \lceil \log 3 / \log 2 \rceil + 1 = 3$.

**Step 3: Baker's lower bound.**

Since $2$ and $3$ are multiplicatively independent (distinct primes), $\log 2$ a
nd $\log 3$ are linearly independent over $\mathbb{Q}$. **Baker's theorem** (196
6) on linear forms in logarithms of algebraic numbers gives:

> There exist effectively computable constants $K > 0$ and $D \geq 1$ (depending
 only on $\alpha_1 = 2$, $\alpha_2 = 3$) such that for all positive integers $b_
1, b_2$:
> $$|b_1 \log 2 - b_2 \log 3| > \frac{K}{\max(b_1, b_2)^D}.$$

Applying this with $b_1 = n$, $b_2 = m$:

$$|\Lambda| > \frac{K}{\max(n, m)^D} \geq \frac{K}{(c_0 \, m)^D}. \tag{2}$$

**Step 4: Combining (1) and (2) to bound $m$.**

From (1) and (2):

$$\frac{K}{c_0^D \, m^D} < \frac{2|C|}{3^m},$$

which gives:

$$3^m < \frac{2|C| \, c_0^D}{K} \cdot m^D. \tag{3}$$

The left side grows **exponentially** in $m$; the right side grows **polynomiall
y** in $m$. Therefore (3) can hold only for $m \leq M$, where $M$ is an effectiv
ely computable constant depending on $C$, $K$, $D$, and $c_0$.

Since $n = \Theta(m)$, we also have $n \leq N$ for some effectively computable b
ound $N$.

**Step 5: Handling small $m$ or $n$.**

- If $m = 0$: $2^n - 1 = C \Rightarrow 2^n = C + 1$, at most one solution.
- If $n = 0$: $1 - 3^m = C \Rightarrow 3^m = 1 - C$, at most one solution.
- If $m = 0, n = 0$: gives $C = 0$, already handled.

These contribute at most finitely many additional solutions.

**Step 6: The exclusion $(m, n) \neq (2, 2)$.**

The pair $(2, 2)$ corresponds to $C = 2^2 - 3^2 = -5$. Removing a single solutio
n from a finite set leaves it finite. This condition does not affect the finiten
ess conclusion for any value of $C$.

---

### Conclusion

For every fixed integer $C$:

- If $C = 0$: at most one solution.
- If $C \neq 0$: Baker's theorem forces $m \leq M(C)$ and $n \leq N(C)$, giving
finitely many solutions.

The exclusion of $(m, n) = (2, 2)$ removes at most one solution and does not cha
nge finiteness.

**Therefore, the equation $2^n - 3^m = C$ has only finitely many solutions for a
ny fixed integer $C$, even without the restriction $(m, n) \neq (2, 2)$.** $\bla
cksquare$
