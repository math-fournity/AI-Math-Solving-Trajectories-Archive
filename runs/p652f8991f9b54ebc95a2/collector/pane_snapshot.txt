## Solution

**Find all functions $f: \mathbb{R} \rightarrow \mathbb{R}$ satisfying**
$$(x-y) f(x+y)-(x+y) f(x-y)=4 x y\left(x^{2}-y^{2}\right).$$

### Step 1: Change of variables

Set $u = x+y$ and $v = x-y$, so $x = \tfrac{u+v}{2}$ and $y = \tfrac{u-v}{2}$. S
ince the map $(x,y)\mapsto (u,v)$ is a bijection of $\mathbb{R}^2$, the equation
 holds for all $x,y$ iff it holds for all $u,v$. We compute:
$$xy = \frac{(u+v)(u-v)}{4} = \frac{u^2-v^2}{4}, \qquad x^2-y^2 = (x+y)(x-y)=uv.
$$
Hence
$$4xy(x^2-y^2) = 4\cdot\frac{u^2-v^2}{4}\cdot uv = uv(u^2-v^2).$$
The functional equation becomes
$$v\,f(u) - u\,f(v) = uv(u^2-v^2). \tag{$\ast$}$$

### Step 2: Determine $f$ on $\mathbb{R}\setminus\{0\}$

For $u,v\neq 0$, divide $(\ast)$ by $uv$:
$$\frac{f(u)}{u} - \frac{f(v)}{v} = u^2 - v^2,$$
i.e.
$$\frac{f(u)}{u}-u^2 = \frac{f(v)}{v}-v^2.$$
Thus the quantity $\frac{f(t)}{t}-t^2$ is constant on $\mathbb{R}\setminus\{0\}$
; call it $c\in\mathbb{R}$. Then
$$f(t) = t^3 + ct, \qquad t\neq 0. \tag{$\dagger$}$$

### Step 3: Determine $f(0)$

Set $x+y=0$ (i.e. $y=-x$) in the original equation:
$$(2x)\,f(0) - 0\cdot f(2x) = 4x(-x)(x^2-x^2)=0.$$
So $2x\,f(0)=0$ for every $x$, giving $f(0)=0$. This is consistent with $(\dagge
r)$, which also yields $f(0)=0$.

### Step 4: Verification

For $f(t)=t^3+ct$ (with arbitrary $c\in\mathbb{R}$):
$$v f(u)-u f(v) = v(u^3+cu)-u(v^3+cv)=vu^3+cuv-uv^3-cuv=uv(u^2-v^2),$$
which equals the right-hand side of $(\ast)$. Hence every such $f$ satisfies the
 original equation.

### Conclusion

All solutions are
$$\boxed{f(x) = x^3 + cx, \quad c\in\mathbb{R}.}$$
