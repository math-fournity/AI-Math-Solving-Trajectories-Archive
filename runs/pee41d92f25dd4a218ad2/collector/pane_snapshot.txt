## Setting Up the Case Analysis

The system is:
1. |x| + y = a
2. 2|y| − x = b

I split into four cases based on the signs of x and y.

**Case 2 (x ≥ 0, y < 0):** x + y = a, −2y − x = b → y = −(a+b), x = 2a+b. Valid
when b > −a and b ≥ −2a, i.e., b > −a (since a > 0).

**Case 3 (x < 0, y ≥ 0):** −x + y = a, 2y − x = b → y = b−a, x = b−2a. Valid whe
