The problem asks: Identify a function from the real numbers to the real numbers
that cannot be expressed as the pointwise limit of a sequence of measurable
functions.

This is a classic problem in measure theory / real analysis. The pointwise limit
of a sequence of measurable functions is measurable. So any non-measurable
function would work.

The key theorem: If $f_n$ are measurable functions and $f_n \to f$ pointwise,
then $f$ is measurable. This is because the pointwise limit of measurable
functions is measurable.

So we need a non-measurable function. The classic example is the indicator
function of a non-measurable set (like a Vitali set).

Solution

Claim. Let $V \subset \mathbb{R}$ be a Vitali set (a set of representatives of
the equivalence classes of $\mathbb{R}$ under $x \sim y \iff x - y \in
\mathbb{Q}$), and let $f = \mathbf{1}_V : \mathbb{R} \to \mathbb{R}$ be its
indicator function. Then $f$ cannot be expressed as the pointwise limit of any
sequence of Lebesgue-measurable functions.

────────────────────────────────────────────────────────────────────────────────

Step 1. A standard theorem

│ Theorem. If $(f_n)_{n \ge 1}$ is a sequence of (Lebesgue-)measurable functions
│ $\mathbb{R} \to \mathbb{R}$ and $f_n \to f$ pointwise, then $f$ is measurable.

Proof (recalled for completeness). For every real $a$, $$ {x : f(x) > a} =
\bigcup_{k=1}^{\infty};\bigcap_{N=1}^{\infty};\bigcup_{n \ge N}{x : f_n(x) \ge a
+ \tfrac{1}{k}}. $$ Each set ${x : f_n(x) \ge a + 1/k}$ is measurable (since
$f_n$ is measurable), and the countable Boolean operations preserve
measurability. Hence ${x : f(x) > a}$ is measurable for every $a$, which is
exactly the measurability of $f$. $\square$

So: every pointwise limit of measurable functions is measurable. By
contrapositive, every non-measurable function is a valid answer.

────────────────────────────────────────────────────────────────────────────────

Step 2. A non-measurable function exists: the indicator of a Vitali set

Define the equivalence relation on $\mathbb{R}$: $$x \sim y \iff x - y \in
\mathbb{Q}.$$ Using the axiom of choice, pick exactly one representative from
each equivalence class; call the resulting set $V$ (a Vitali set).

$V$ is not Lebesgue-measurable. The standard argument: the countably many
rational translates ${V + q}_{q \in \mathbb{Q}}$ are pairwise disjoint and cover
$\mathbb{R}$. If $V$ were measurable with measure $m(V)$:

  • Pairwise disjointness and countable additivity give $m!\left(\bigcup_{q \in
  \mathbb{Q}}(V+q)\right) = \sum_{q \in \mathbb{Q}} m(V)$.
  • The union is contained in $[r, r+1]$ for a suitable bounded interval when
  restricted to a fundamental domain, and contains such an interval, forcing $0
  < \sum_{q} m(V) < \infty$.
  • But $\sum_{q \in \mathbb{Q}} m(V)$ is a sum of identical terms: it is $0$ if
  $m(V)=0$, or $+\infty$ if $m(V) > 0$. Neither lies strictly between $0$ and $
  \infty$ — contradiction.

Hence $V$ is not Lebesgue-measurable.

────────────────────────────────────────────────────────────────────────────────

Step 3. The indicator $f = \mathbf{1}_V$ is non-measurable, hence not a
pointwise limit of measurable functions

Define $f : \mathbb{R} \to \mathbb{R}$ by $$f(x) = \mathbf{1}_V(x) =
\begin{cases} 1 & x \in V, \ 0 & x \notin V. \end{cases}$$

If $f$ were measurable, then the preimage $$f^{-1}({1}) = V$$ would be a
measurable set (since ${1}$ is a Borel set and measurable functions pull Borel
sets back to measurable sets). This contradicts Step 2, which says $V$ is not
measurable.

Therefore $f = \mathbf{1}_V$ is not measurable.

By the theorem in Step 1, a non-measurable function cannot be the pointwise
limit of any sequence of measurable functions. Consequently:

$$\boxed{,f = \mathbf{1}_V \text{, where } V \text{ is a Vitali set, is a
function } \mathbb{R}\to\mathbb{R} \text{ that is not the pointwise limit of any
sequence of measurable functions.},}$$
