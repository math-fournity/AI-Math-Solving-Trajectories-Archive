I'll evaluate the integral $\int_0^\infty \frac{dx}{1+x^6}$ using the residue th
eorem.

## Setup

Consider the contour integral
$$I = \oint_C \frac{dz}{1+z^6}$$
where $C$ is the standard semicircular contour in the upper half-plane: the segm
ent $[-R, R]$ on the real axis, plus the semicircular arc $\Gamma_R: z = Re^{i\t
heta}$, $0 \le \theta \le \pi$, traversed counterclockwise.

The integrand $f(z) = \frac{1}{1+z^6}$ has poles where $1+z^6 = 0$, i.e., $z^6 =
 -1 = e^{i\pi}$, giving
$$z_k = e^{i(\pi + 2k\pi)/6} = e^{i(2k+1)\pi/6}, \quad k = 0,1,2,3,4,5.$$

The six roots are:
- $z_0 = e^{i\pi/6}$
- $z_1 = e^{i\pi/2} = i$
- $z_2 = e^{i5\pi/6}$
- $z_3 = e^{i7\pi/6}$ (lower half-plane)
- $z_4 = e^{i3\pi/2} = -i$ (lower half-plane)
- $z_5 = e^{i11\pi/6}$ (lower half-plane)

The poles in the **upper half-plane** are $z_0 = e^{i\pi/6}$, $z_1 = i$, $z_2 =
e^{i5\pi/6}$.

## Residue computation

Since $1+z^6 = \prod_k(z-z_k)$, each pole is simple. For a simple pole $z_k$ of
$\frac{1}{1+z^6}$:
$$\operatorname{Res}(f, z_k) = \frac{1}{6z_k^5}.$$

Using $z_k^6 = -1$, so $z_k^5 = -1/z_k$, hence
$$\operatorname{Res}(f, z_k) = \frac{1}{6 \cdot (-1/z_k)} = -\frac{z_k}{6}.$$

**Sum of residues in the upper half-plane:**
$$\sum_{\text{UHP}} \operatorname{Res}(f, z_k) = -\frac{1}{6}(z_0 + z_1 + z_2) =
 -\frac{1}{6}\left(e^{i\pi/6} + i + e^{i5\pi/6}\right).$$

Compute the sum:
$$e^{i\pi/6} + e^{i5\pi/6} = \left(\tfrac{\sqrt3}{2} + \tfrac{i}{2}\right) + \le
ft(-\tfrac{\sqrt3}{2} + \tfrac{i}{2}\right) = i.$$

So
$$z_0 + z_1 + z_2 = i + i = 2i.$$

Therefore
$$\sum_{\text{UHP}} \operatorname{Res}(f, z_k) = -\frac{1}{6}\cdot 2i = -\frac{i
}{3}.$$

## Applying the residue theorem

By the residue theorem:
$$\oint_C f(z)\,dz = 2\pi i \cdot \left(-\frac{i}{3}\right) = 2\pi i \cdot \frac
{-i}{3} = \frac{2\pi}{3}.$$

## The arc integral vanishes

On $\Gamma_R$, $|f(z)| = \frac{1}{|1+z^6|} \le \frac{1}{R^6 - 1}$ for $R > 1$, s
o
$$\left|\int_{\Gamma_R} f(z)\,dz\right| \le \frac{\pi R}{R^6 - 1} \to 0 \quad \t
ext{as } R \to \infty.$$

## Taking the limit

As $R \to \infty$:
$$\int_{-\infty}^{\infty} \frac{dx}{1+x^6} = \frac{2\pi}{3}.$$

Since $\frac{1}{1+x^6}$ is an even function:
$$\int_0^{\infty} \frac{dx}{1+x^6} = \frac{1}{2}\cdot\frac{2\pi}{3} = \frac{\pi}
{3}.$$

## Verification

General formula: $\int_0^\infty \frac{dx}{1+x^n} = \frac{\pi/n}{\sin(\pi/n)}$ fo
r $n > 1$. With $n = 6$:
$$\frac{\pi/6}{\sin(\pi/6)} = \frac{\pi/6}{1/2} = \frac{\pi}{3}. \checkmark$$

## Result

$$\boxed{\int_0^{\infty} \frac{dx}{1+x^6} = \frac{\pi}{3}}$$
