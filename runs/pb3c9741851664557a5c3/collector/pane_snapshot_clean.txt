## Proof

**Step 1: Partial fraction decomposition.**

Since $f(x) = a_0\prod_{\nu=1}^n (x - x_\nu)$ with distinct roots, $f'(x_\nu) =
a_0\prod_{\mu\ne\nu}(x_\nu - x_\mu)$. The partial fraction decomposition of $1/f
(x)$ is:

$$\frac{1}{f(x)} = \sum_{\nu=1}^{n} \frac{1}{f'(x_\nu)(x - x_\nu)}.$$

Both sides are rational functions with the same simple poles and the same residu
es $1/f'(x_\nu)$ at each pole; their difference is a polynomial vanishing at inf
inity, hence identically zero.

**Step 2: $\alpha_k$ as a Laurent coefficient.**

For any $k \geq 0$, divide $x^k$ by $f(x)$: $x^k = f(x)Q(x) + R(x)$, $\deg R < n
$ (with $Q=0$ if $k<n$). Then

$$\frac{x^k}{f(x)} = Q(x) + \frac{R(x)}{f(x)} = Q(x) + \sum_{\nu=1}^{n}\frac{R(x
_\nu)}{f'(x_\nu)(x-x_\nu)}.$$

Since $f(x_\nu)=0$, we have $R(x_\nu) = x_\nu^k - f(x_\nu)Q(x_\nu) = x_\nu^k$, s
o

$$\frac{x^k}{f(x)} = Q(x) + \sum_{\nu=1}^{n}\frac{x_\nu^k}{f'(x_\nu)(x - x_\nu)}
.$$

Expanding each partial fraction at $x=\infty$: $\frac{A_\nu}{x-x_\nu} = \frac{A_
\nu}{x}\sum_{m=0}^{\infty}(x_\nu/x)^m$, the coefficient of $x^{-1}$ is $\sum_\nu
 A_\nu = \alpha_k$. Since $Q(x)$ is a polynomial (no negative powers), **$\alpha
_k$ equals the coefficient of $x^{-1}$ in the Laurent expansion of $x^k/f(x)$ at
 $x = \infty$**.

**Step 3: Computing the Laurent coefficient.**

Write $f(x) = a_0 x^n\bigl(1 + \tfrac{a_1}{a_0}u + \cdots + \tfrac{a_n}{a_0}u^n\
bigr)$ with $u = 1/x$. Set

$$g(u) = 1 + \tfrac{a_1}{a_0}u + \cdots + \tfrac{a_n}{a_0}u^n, \qquad h(u) = \fr
ac{1}{g(u)} = \sum_{j=0}^{\infty} c_j\, u^j.$$

Then $\frac{x^k}{f(x)} = \frac{1}{a_0}\,u^{n-k}\,h(u) = \frac{1}{a_0}\sum_{j=0}^
{\infty} c_j\, x^{k-n-j}$. The coefficient of $x^{-1}$ requires $k-n-j=-1$, i.e.
, $j = k-n+1$. Therefore

$$\boxed{\alpha_k = \frac{c_{k-n+1}}{a_0}}, \qquad c_j := 0 \text{ for } j<0.$$

From $g(u)\,h(u)=1$, the coefficients satisfy $c_0 = 1$ and for $j \geq 1$:

$$c_j = -\sum_{i=1}^{\min(j,n)} \frac{a_i}{a_0}\, c_{j-i}. \tag{$\star$}$$

**Step 4: The cases $0 \leq k \leq n-2$ and $k = n-1$.**

- **$0 \leq k \leq n-2$:** Then $j = k-n+1 \leq -1 < 0$, so $c_j = 0$, giving $\
alpha_k = 0$.
- **$k = n-1$:** Then $j = 0$, so $c_0 = 1$, giving $\alpha_{n-1} = 1/a_0 = a_0^
{-1}$.

**Step 5: Independence of $a_n$ for $k = n, n+1, \ldots, 2n-2$.**

Here $j = k - n + 1$ ranges over $1, 2, \ldots, n-1$. In the recursion $(\star)$
, the term with $i = n$ (which carries $a_n$) requires $j - n \geq 0$, i.e., $j
\geq n$. But $j \leq n-1$, so **the coefficient $a_n$ never appears** in the com
putation of $c_1, c_2, \ldots, c_{n-1}$. Explicitly, for $1 \leq j \leq n-1$:

$$c_j = -\sum_{i=1}^{j} \frac{a_i}{a_0}\, c_{j-i},$$

which depends only on $a_0, a_1, \ldots, a_{n-1}$. Hence $\alpha_k = c_{k-n+1}/a
_0$ is **independent of $a_n$** for $k = n, \ldots, 2n-2$.

**Step 6: Linearity in $a_n$ for $k = 2n-1$.**

Here $j = n$. The recursion gives:

$$c_n = -\sum_{i=1}^{n} \frac{a_i}{a_0}\, c_{n-i} = -\frac{a_1}{a_0}c_{n-1} - \c
dots - \frac{a_{n-1}}{a_0}c_1 - \frac{a_n}{a_0}\,c_0.$$

By Step 5, each $c_1, \ldots, c_{n-1}$ is independent of $a_n$, and $c_0 = 1$. T
he only term involving $a_n$ is $-\frac{a_n}{a_0}\cdot 1 = -\frac{a_n}{a_0}$. Th
erefore

$$c_n = \bigl(\text{expression independent of } a_n\bigr) - \frac{a_n}{a_0},$$

and

$$\alpha_{2n-1} = \frac{c_n}{a_0} = \frac{(\text{independent of } a_n)}{a_0} - \
frac{a_n}{a_0^2}.$$

Thus $\alpha_{2n-1}$ is **linear in $a_n$ with coefficient $-a_0^{-2}$**. $\blac
ksquare$
