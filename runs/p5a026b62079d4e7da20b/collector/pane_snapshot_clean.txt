## Proof

Since $Z_1, \ldots, Z_n$ are jointly Gaussian, any linear combinations of them a
re also jointly Gaussian. For jointly Gaussian random variables, **independence
is equivalent to zero covariance**. Thus $M$ is independent of $Z_i - M$ if and
only if
$$\operatorname{Cov}(M,\, Z_i - M) = 0 \quad \text{for all } i = 1, \ldots, n.$$

**Computing the covariance.** We have
$$\operatorname{Cov}(M, Z_i - M) = \operatorname{Cov}(M, Z_i) - \operatorname{Va
r}(M).$$

Now
$$\operatorname{Cov}(M, Z_i) = \operatorname{Cov}\!\left(\sum_{j=1}^n c_j Z_j,\,
 Z_i\right) = c_i \operatorname{Var}(Z_i) = c_i,$$
using independence of the $Z_j$. Also
$$\operatorname{Var}(M) = \operatorname{Var}\!\left(\sum_{j=1}^n c_j Z_j\right)
= \sum_{j=1}^n c_j^2.$$

**The system of equations.** The independence condition becomes
$$c_i - \sum_{j=1}^n c_j^2 = 0 \quad \text{for every } i = 1, \ldots, n.$$

Let $S = \sum_{j=1}^n c_j^2$. Then the equations say $c_i = S$ for every $i$. He
nce **all the $c_i$ are equal**: write $c_1 = c_2 = \cdots = c_n = c$.

**Solving for $c$.** Substituting,
$$S = \sum_{j=1}^n c^2 = nc^2, \qquad c = S = nc^2.$$
So $c(nc - 1) = 0$. Since the constants are not all zero, $c \neq 0$, giving
$$c = \frac{1}{n}.$$

**Verification.** With $c_i = 1/n$ for all $i$, we get $M = \frac{1}{n}\sum_{j=1
}^n Z_j = \bar{Z}$, the sample mean. Then
$$\operatorname{Cov}(\bar{Z}, Z_i) = \frac{1}{n}, \qquad \operatorname{Var}(\bar
{Z}) = \frac{1}{n},$$
so $\operatorname{Cov}(\bar{Z}, Z_i - \bar{Z}) = \frac{1}{n} - \frac{1}{n} = 0$
for every $i$. By joint Gaussianity, $\bar{Z}$ is independent of each $Z_i - \ba
r{Z}$.

**Conclusion.** The unique (up to a common nonzero scalar multiple, but normaliz
ed so the $c_i$ sum to $1$) solution is
$$\boxed{c_1 = c_2 = \cdots = c_n = \frac{1}{n}},$$
i.e., $M = \frac{1}{n}(Z_1 + \cdots + Z_n)$ is the sample mean.
