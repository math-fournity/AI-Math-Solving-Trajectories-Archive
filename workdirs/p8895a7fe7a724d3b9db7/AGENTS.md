# Problem

In the remote Archipelago of Alternia, there are exactly 2019 distinct islands. The Ministry of Transport is drafting a new regulation for a network of one-way ferry routes between these islands. 

The regulation focuses on the "In-Out Balance" of each island. For any given island, the Ministry calculates the absolute difference between the number of outgoing ferry routes originating from that island and the number of incoming ferry routes terminating at that island.

The Ministry wants to establish a universal threshold, an integer $k$, that guarantees total connectivity. Specifically, they want to ensure that no matter how the one-way ferry routes are distributed among the 2019 islands, if every single island maintains an In-Out Balance of $k$ or less, it must be possible for a traveler to start at any island and reach any other island in the archipelago by following the available routes.

Determine the maximum possible integer value of $k$ that guarantees this universal connectivity.
