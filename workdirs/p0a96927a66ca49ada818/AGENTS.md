# Problem

A specialized artificial intelligence, "Unit-1," manages a sequence of digital vaults. For every positive integer level $n$ in the system, there is a vault containing a specific number of encrypted data packets, denoted as $a_n$. 

The AI is governed by two strict security protocols:
1. **The Expansion Protocol:** For every level $n$, the number of packets in the next vault ($a_{n+1}$) must be at least equal to the number of packets in the current vault ($a_n$), but it cannot exceed the current vault's count by more than 5.
2. **The Verification Protocol:** To ensure data integrity, the total number of packets in vault $n$ must be exactly divisible by the level number $n$ for every $n \ge 1$.

Based on these protocols, what are the possible values for the number of packets stored in the very first vault ($a_1$)?
