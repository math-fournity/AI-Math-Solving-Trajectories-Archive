## Proof

**Setup.** Let $S_n = \mu\!\left(\{x \in [0,\tfrac{\pi}{2}] : \sin(4nx) \geq \si
n x\}\right)$, where $\mu$ is Lebesgue measure.

**Step 1: Decompose into periods.**

The function $\sin(4nx)$ has period $T = \frac{\pi}{2n}$. The interval $[0, \fra
c{\pi}{2}]$ contains exactly $n$ periods $I_k = [kT, (k+1)T]$, $k = 0, 1, \ldots
, n-1$.

**Step 2: Substitution within each period.**

On $I_k$, write $x = kT + u$, $u \in [0, T]$. Then $4nx = 2k\pi + 4nu$, so $\sin
(4nx) = \sin(4nu)$. Substituting $v = 4nu$ (so $u = v/(4n)$, $dv = 4n\,du$, $v \
in [0, 2\pi]$):

$$s_k := \mu(\{u \in [0,T] : \sin(4nu) \geq \sin(kT+u)\}) = \frac{1}{4n}\int_0^{
2\pi} \mathbf{1}\!\left[\sin v \geq \sin\!\left(kT + \tfrac{v}{4n}\right)\right]
 dv.$$

**Step 3: Freeze the threshold.**

Set $c_k = \sin(kT) = \sin\!\left(\frac{k\pi}{2n}\right) \in [0,1)$. Since $\lef
t|\frac{v}{4n}\right| \leq \frac{\pi}{4n}$:

$$\sin\!\left(kT + \tfrac{v}{4n}\right) = c_k + \frac{v}{4n}\cos(kT) + O(1/n^2)
= c_k + \epsilon_k(v),$$

where $|\epsilon_k(v)| \leq C/n$ uniformly. Define $f(c) = \mu(\{v \in [0,2\pi]
: \sin v \geq c\}) = \pi - 2\arcsin(c)$ for $c \in [0,1]$.

**Step 4: Bound the error.**

The per-period error satisfies:

$$\left|s_k - \frac{f(c_k)}{4n}\right| \leq \frac{1}{4n}\,\mu\!\left(\{v : |\sin
 v - c_k| \leq C/n\}\right).$$

By the mean value theorem applied to $f$, this is $O\!\left(\frac{1}{n^2 \cos(k\
pi/(2n))}\right)$ (using $f'(c) = -2/\sqrt{1-c^2}$ and $1-c_k^2 = \cos^2(k\pi/(2
n))$).

Summing over $k$: for $k \leq n/2$, $\cos(k\pi/(2n)) \geq 1/\sqrt{2}$, contribut
ing $O(1/n)$. For $k > n/2$, writing $j = n-1-k$, we have $\cos(k\pi/(2n)) \appr
ox (j+1)\pi/(2n)$, giving $\sum_{j \geq 1} O\!\left(\frac{1}{n \cdot j}\right) =
 O(\log n / n)$.

**Total error:** $O(\log n / n) \to 0$.

**Step 5: Compute the limit.**

$$S_n = \frac{1}{4n}\sum_{k=0}^{n-1} f(c_k) + o(1) = \frac{1}{4n}\sum_{k=0}^{n-1
}\left(\pi - 2\arcsin\!\left(\sin\!\tfrac{k\pi}{2n}\right)\right) + o(1).$$

Since $\frac{k\pi}{2n} \in [0, \frac{\pi}{2})$ for $k = 0, \ldots, n-1$, we have
 $\arcsin(\sin\frac{k\pi}{2n}) = \frac{k\pi}{2n}$, so:

$$S_n = \frac{1}{4n}\sum_{k=0}^{n-1}\left(\pi - \frac{k\pi}{n}\right) + o(1) = \
frac{\pi}{4}\cdot\frac{1}{n}\sum_{k=0}^{n-1}\left(1 - \frac{k}{n}\right) + o(1).
$$

This is a Riemann sum:

$$\frac{\pi}{4}\cdot\frac{1}{n}\sum_{k=0}^{n-1}\left(1-\frac{k}{n}\right) \;\lon
grightarrow\; \frac{\pi}{4}\int_0^1 (1-t)\,dt = \frac{\pi}{4}\cdot\frac{1}{2} =
\frac{\pi}{8}.$$

**Verification of the Riemann sum:** $\frac{1}{n}\sum_{k=0}^{n-1}(1-k/n) = 1 - \
frac{n-1}{2n} \to \frac{1}{2}$. ✓

**Intuition check:** The fraction of each period satisfying the inequality is $\
frac{\pi - 2x}{2\pi}$, ranging from $1/2$ at $x=0$ to $0$ at $x=\pi/2$, with ave
rage $1/4$. Total measure $\approx \frac{1}{4}\cdot\frac{\pi}{2} = \frac{\pi}{8}
$. ✓

$$\boxed{\lim_{n\to\infty} S_n = \dfrac{\pi}{8}}$$
