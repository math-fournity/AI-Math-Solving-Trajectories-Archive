## Solution

We evaluate
$$I = \frac{1}{2\pi i}\int_{\gamma} \frac{dz}{z^4(e^{2z}-1)}, \qquad \gamma:\; |
z|=\tfrac{1}{2}\;\text{(once, counterclockwise)}.$$

### Step 1: Locate singularities inside $\gamma$

The integrand $f(z)=\dfrac{1}{z^4(e^{2z}-1)}$ has singularities where $z^4(e^{2z
}-1)=0$:
- $z=0$ (from $z^4$, and also $e^{2z}-1=0$ here), and
- $z = \dfrac{k\pi i}{2}$ for $k\in\mathbb{Z}\setminus\{0\}$ (zeros of $e^{2z}-1
$).

The nearest nonzero zeros satisfy $|z|=\pi/2\approx 1.571 > 1/2$, so **the only
singularity inside $\gamma$ is $z=0$**. By the Residue Theorem,
$$I = \operatorname{Res}_{z=0} f(z).$$

### Step 2: Reduce to a power-series inversion

Since $e^{2z}-1 = 2z\,g(z)$ with
$$g(z) = \frac{e^{2z}-1}{2z} = 1 + z + \frac{2}{3}z^2 + \frac{1}{3}z^3 + \frac{2
}{15}z^4 + \cdots,$$
we have
$$f(z) = \frac{1}{2z^5\, g(z)}.$$

Writing $h(z)=1/g(z)=a_0+a_1 z+a_2 z^2+a_3 z^3+a_4 z^4+\cdots$, the residue (coe
fficient of $z^{-1}$) is
$$\operatorname{Res}_{z=0} f(z) = \frac{1}{2}\,a_4.$$

### Step 3: Compute $h(z)=1/g(z)$ via $g(z)h(z)=1$

Equating coefficients of $g(z)h(z)$ to $1$:

| $z^n$ | Equation | Result |
|---|---|---|
| $z^0$ | $a_0 = 1$ | $a_0=1$ |
| $z^1$ | $a_1 + a_0 = 0$ | $a_1=-1$ |
| $z^2$ | $a_2 + a_1 + \tfrac{2}{3}a_0 = 0$ | $a_2 = \tfrac{1}{3}$ |
| $z^3$ | $a_3 + a_2 + \tfrac{2}{3}a_1 + \tfrac{1}{3}a_0 = 0$ | $a_3 = 0$ |
| $z^4$ | $a_4 + a_3 + \tfrac{2}{3}a_2 + \tfrac{1}{3}a_1 + \tfrac{2}{15}a_0 = 0$
 | $a_4 = -\tfrac{1}{45}$ |

For the $z^4$ coefficient:
$$a_4 + 0 + \frac{2}{9} - \frac{1}{3} + \frac{2}{15} = a_4 - \frac{1}{9} + \frac
{2}{15} = a_4 - \frac{5}{45} + \frac{6}{45} = a_4 + \frac{1}{45} = 0,$$
hence $a_4 = -\dfrac{1}{45}$.

### Step 4: Conclude

$$\operatorname{Res}_{z=0} f(z) = \frac{1}{2}\left(-\frac{1}{45}\right) = -\frac
{1}{90}.$$

Therefore
$$\boxed{\frac{1}{2\pi i}\int_{\gamma} \frac{dz}{z^4(e^{2z}-1)} = -\frac{1}{90}}
.$$
