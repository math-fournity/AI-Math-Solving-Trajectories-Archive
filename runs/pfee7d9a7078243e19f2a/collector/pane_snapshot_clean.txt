Looking at this problem, I need to determine whether a non-constant integer poly
nomial $W(x)$ can have $\{g(W(x)) \mid x \in \mathbb{N}^*\}$ be finite.

**Answer: No.**

## Proof

The key tool is **Schur's Theorem** (1912), which I prove below for self-contain
edness.

### Schur's Theorem (for positive integers)

**Claim:** If $f \in \mathbb{Z}[x]$ is non-constant, then infinitely many primes
 divide the set $\{f(n) : n \in \mathbb{N}^*\}$.

**Proof of Schur's Theorem.** Suppose for contradiction that only finitely many
primes $p_1, \dots, p_s$ divide values $f(n)$ for $n \in \mathbb{N}^*$.

Since $f$ is non-constant, it has finitely many integer roots, so we may pick $n
_0 \in \mathbb{N}^*$ with $f(n_0) \neq 0$. Set $A = |f(n_0)|$ and $P = p_1 p_2 \
cdots p_s$, and $M = AP$.

Consider the polynomial $h(t) = f(n_0 + Mt)$ for $t \in \mathbb{N}^*$. Since $n_
0 + Mt \in \mathbb{N}^*$, every prime factor of $h(t)$ lies in $\{p_1, \dots, p_
s\}$ by our assumption.

Now, $f(n_0 + Mt) - f(n_0)$ is divisible by $Mt$ (as a polynomial identity: $f(a
+b) - f(a)$ is divisible by $b$ in $\mathbb{Z}[a,b]$), hence divisible by $M$. S
o:
$$h(t) \equiv f(n_0) \pmod{M}.$$

Writing $f(n_0) = \varepsilon A$ where $\varepsilon \in \{-1, +1\}$, we get $h(t
) = \varepsilon A + AP \cdot r(t) = A\bigl(\varepsilon + P \cdot r(t)\bigr)$ for
 some integer $r(t)$.

Since $A \mid h(t)$ and all prime factors of both $A$ and $h(t)$ lie in $\{p_1,
\dots, p_s\}$, all prime factors of $h(t)/A = \varepsilon + P\,r(t)$ also lie in
 $\{p_1, \dots, p_s\}$.

But $P$ is divisible by every $p_i$, so:
$$\frac{h(t)}{A} = \varepsilon + P\,r(t) \equiv \varepsilon \pmod{p_i} \quad \te
xt{for each } i.$$

Since $\varepsilon = \pm 1$ and each $p_i \geq 2$, no $p_i$ divides $h(t)/A$. Th
erefore $h(t)/A$ has **no** prime factors, so $|h(t)/A| = 1$, giving $h(t) = \pm
 A = f(n_0)$ for all $t \in \mathbb{N}^*$.

But $h(t) = f(n_0 + Mt)$ is a non-constant polynomial in $t$ (since $f$ is non-c
onstant and $M \neq 0$), so it cannot be constant on $\mathbb{N}^*$. **Contradic
tion.** $\square$

### Main Proof

Suppose for contradiction that a non-constant $W(x) \in \mathbb{Z}[x]$ exists wi
th $\{g(W(x)) : x \in \mathbb{N}^*\}$ finite, say equal to $\{1, q_1, \dots, q_m
\}$ where $q_1, \dots, q_m$ are primes.

By definition of $g$:
- If $g(W(x)) = 1$, then $W(x) \in \{-1, 0, 1\}$.
- If $g(W(x)) = q_i$ (a prime), then $q_i$ is the **largest** prime factor of $W
(x)$, so every prime factor of $W(x)$ lies in $\{q_1, \dots, q_m\}$.

In either case, **every prime factor of $W(x)$ belongs to the finite set $S = \{
q_1, \dots, q_m\}$** (for $W(x) \in \{-1,0,1\}$ there are no prime factors at al
l).

Therefore, only finitely many primes (namely those in $S$) divide the set $\{W(x
) : x \in \mathbb{N}^*\}$.

This directly **contradicts Schur's Theorem**, which guarantees that infinitely
many primes divide $\{W(x) : x \in \mathbb{N}^*\}$ for any non-constant $W \in \
mathbb{Z}[x]$.

### Conclusion

No non-constant polynomial $W(x) \in \mathbb{Z}[x]$ can make $\{g(W(x)) : x \in
\mathbb{N}^*\}$ finite. The set of largest prime factors of the values of any no
n-constant integer polynomial is always infinite.
