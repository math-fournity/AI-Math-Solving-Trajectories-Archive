**Answer: Yes, τ = τ'.**

## Proof

**Step 1 (Reduction to a single γ).** Taking g = I in the hypothesis gives j(τ)
= j(τ'). The modular j-function induces a bijection SL₂(ℤ)\ℍ → 𝔸¹, so j(z) = j(w
) iff z and w lie in the same SL₂(ℤ)-orbit. Hence there exists γ ∈ SL₂(ℤ) with

τ' = γτ.

We must show γ acts trivially on τ.

**Step 2 (Conjugation condition).** For arbitrary g ∈ GL₂⁺(ℚ), the hypothesis j(
gτ) = j(gτ') = j(gγτ) gives, again using injectivity of j on SL₂(ℤ)-orbits, an e
lement h_g ∈ SL₂(ℤ) with

gγτ = h_g · gτ,   i.e.   (gγg⁻¹)(gτ) = h_g(gτ).

Thus h_g⁻¹(gγg⁻¹) fixes gτ. The stabilizer of any point of ℍ in SL₂(ℤ) is a subg
roup of SL₂(ℤ) (it is {±I} for a generic point, and slightly larger at the ellip
tic points i and e^{2πi/3}). In every case h_g⁻¹(gγg⁻¹) ∈ SL₂(ℤ), and since h_g
∈ SL₂(ℤ), we conclude

gγg⁻¹ ∈ SL₂(ℤ)   for every g ∈ GL₂⁺(ℚ).        (∗)

**Step 3 (The intersection of all rational conjugates of SL₂(ℤ) is {±I}).** Writ
e γ = ( a b ; c d ) with a,b,c,d ∈ ℤ, ad − bc = 1.

Apply (∗) with g = diag(n, 1) for n = 1, 2, 3, … ∈ GL₂⁺(ℚ):

gγg⁻¹ = ( a  nb ; c/n  d ).

For this to lie in SL₂(ℤ) its entries must be integers, so c/n ∈ ℤ for every pos
itive integer n. The only integer divisible by every positive integer is 0, henc
e **c = 0**.

With c = 0 we have ad = 1, a,d ∈ ℤ, so (a,d) = (1,1) or (−1,−1). Now apply (∗) w
ith g = diag(1, n):

gγg⁻¹ = ( a  b/n ; 0  d ),

so b/n ∈ ℤ for every n, forcing **b = 0**. Therefore γ = diag(a, a) with a = ±1,
 i.e.

γ ∈ { I, −I }.

**Step 4 (Conclusion).** Both I and −I act trivially on ℍ (−I sends z to (−z)/(−
1) = z). Hence

τ' = γτ = τ.

Therefore τ = τ'. ∎
