## Solution

Let $S_n = X_1 + \cdots + X_n$. We have $X_k \in \{-1,+1\}$ with
$$\mathbb{P}(X_k = +1) = \tfrac{1}{2}(1+k^{-1/2}), \qquad \mathbb{P}(X_k = -1) =
 \tfrac{1}{2}(1-k^{-1/2}).$$

**Step 1: Mean and variance.**
$$\mu_k := \mathbb{E}[X_k] = \tfrac{1}{2}(1+k^{-1/2}) - \tfrac{1}{2}(1-k^{-1/2})
 = k^{-1/2},$$
$$\operatorname{Var}(X_k) = \mathbb{E}[X_k^2] - \mu_k^2 = 1 - k^{-1}.$$

Hence
$$M_n := \mathbb{E}[S_n] = \sum_{k=1}^{n} k^{-1/2}, \qquad V_n := \operatorname{
Var}(S_n) = \sum_{k=1}^{n}(1-k^{-1}).$$

**Step 2: Asymptotics of $M_n$ and $V_n$.** By comparison with the integral $\in
t_1^n x^{-1/2}\,dx = 2\sqrt{n}-2$,
$$M_n = 2\sqrt{n} + O(1).$$
Also $V_n = n - H_n$ where $H_n = \sum_{k=1}^n k^{-1} = \ln n + O(1)$, so
$$V_n = n - \ln n + O(1), \qquad \sqrt{V_n} = \sqrt{n}\left(1 + O\!\left(\tfrac{
\ln n}{n}\right)\right).$$

Therefore
$$\frac{M_n}{\sqrt{V_n}} = \frac{2\sqrt{n}+O(1)}{\sqrt{n}\,(1+o(1))} \longrighta
rrow 2.$$

**Step 3: Lindeberg CLT applies.** The variables $X_1, X_2, \ldots$ are independ
ent (not identically distributed). Set $Y_{n,k} = (X_k - \mu_k)/\sqrt{V_n}$. Sin
ce $X_k \in \{-1,+1\}$ and $\mu_k = k^{-1/2}$,
$$|X_k - \mu_k| \le 1 + k^{-1/2} \le 2 \quad \text{for all } k.$$

For any $\varepsilon > 0$, once $n$ is large enough that $\varepsilon\sqrt{V_n}
> 2$, the event $\{|X_k - \mu_k| > \varepsilon\sqrt{V_n}\}$ is empty for every $
k \le n$. Consequently
$$\frac{1}{V_n}\sum_{k=1}^{n}\mathbb{E}\!\left[(X_k-\mu_k)^2\,\mathbf{1}_{\{|X_k
-\mu_k|>\varepsilon\sqrt{V_n}\}}\right] = 0$$
for all sufficiently large $n$, so Lindeberg's condition holds trivially. By the
 **Lindeberg central limit theorem**,
$$\frac{S_n - M_n}{\sqrt{V_n}} \xrightarrow{d} \mathcal{N}(0,1).$$

**Step 4: Evaluate the limit.** Since $M_n/\sqrt{V_n} \to 2$,
$$\mathbb{P}(S_n \le 0) = \mathbb{P}\!\left(\frac{S_n - M_n}{\sqrt{V_n}} \le -\f
rac{M_n}{\sqrt{V_n}}\right) \longrightarrow \Phi(-2),$$
where $\Phi$ is the standard normal CDF. (The convergence at the moving boundary
 $-M_n/\sqrt{V_n}\to -2$ follows from continuity of $\Phi$ and convergence in di
stribution, since $-2$ is a continuity point.)

**Conclusion.**
$$\boxed{\lim_{n\to\infty}\mathbb{P}(X_1+\cdots+X_n \le 0) = \Phi(-2) = \frac{1}
{\sqrt{2\pi}}\int_{-\infty}^{-2} e^{-t^2/2}\,dt \approx 0.0228.}$$
