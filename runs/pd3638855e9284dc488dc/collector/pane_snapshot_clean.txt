## Solution

Let $f(x) = \dfrac{\sin x}{x}$ (with $f(0)=1$ by continuity). Then

$$f'(x) = \frac{x\cos x - \sin x}{x^2}, \qquad\text{so}\qquad \sin x - x\cos x =
 -x^2 f'(x).$$

The denominator factors as

$$x^2 + \sin^2 x = x^2\!\left(1 + \frac{\sin^2 x}{x^2}\right) = x^2\bigl(1 + f(x
)^2\bigr).$$

Therefore the integrand simplifies:

$$\frac{\sin x - x\cos x}{x^2 + \sin^2 x} = \frac{-x^2 f'(x)}{x^2\bigl(1+f(x)^2\
bigr)} = \frac{-f'(x)}{1+f(x)^2}.$$

Since $\dfrac{d}{dx}\arctan\bigl(f(x)\bigr) = \dfrac{f'(x)}{1+f(x)^2}$, an antid
erivative is $-\arctan\bigl(f(x)\bigr)$.

**Convergence check.** Near $x=0$: $\sin x - x\cos x = \tfrac{x^3}{3}+O(x^5)$ an
d $x^2+\sin^2 x = 2x^2+O(x^4)$, so the integrand is $O(x)\to 0$ — no singularity
. As $x\to\infty$, $f(x)\to 0$, so $\arctan(f(x))\to 0$; the antiderivative has
finite limits at both endpoints, hence the improper integral converges.

**Evaluation.**

$$\int_{0}^{\infty} \frac{\sin x - x\cos x}{x^2 + \sin^2 x}\,dx = \Bigl[-\arctan
\bigl(f(x)\bigr)\Bigr]_{0}^{\infty} = -\arctan\!\left(\lim_{x\to\infty}\frac{\si
n x}{x}\right) + \arctan\!\left(\lim_{x\to 0^+}\frac{\sin x}{x}\right).$$

Using $\displaystyle\lim_{x\to\infty}\frac{\sin x}{x}=0$ and $\displaystyle\lim_
{x\to 0}\frac{\sin x}{x}=1$:

$$= -\arctan(0) + \arctan(1) = 0 + \frac{\pi}{4} = \boxed{\dfrac{\pi}{4}}.$$

### PROOF COMPLETE
