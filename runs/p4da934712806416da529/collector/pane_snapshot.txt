# Solution of the Cylindrical Heat Equation with Robin Boundary Condition

## Problem Setup

We solve:
$$\frac{\partial u}{\partial t} = a^2\left(\frac{\partial^2 u}{\partial r^2} + \
frac{1}{r}\frac{\partial u}{\partial r}\right), \quad 0 < r < r_0,\ t > 0$$

$$\frac{\partial u}{\partial r}\bigg|_{r=r_0} = h\,[U_1 - u(r_0,t)], \quad t > 0
$$

$$u(r,0) = U_0, \quad 0 < r < r_0$$

with the implicit regularity condition that $u$ is bounded at $r = 0$.

## Step 1: Decomposition into Steady State + Transient

Set $u(r,t) = v(r) + w(r,t)$, where $v$ is the steady-state solution.

**Steady state:** $v'' + \frac{1}{r}v' = 0$, i.e., $(rv')' = 0$, giving $v' = C_
1/r$. Boundedness at $r=0$ forces $C_1 = 0$, so $v = \text{const} = C_2$. The bo
undary condition $v'(r_0) = h[U_1 - v(r_0)]$ gives $0 = h(U_1 - C_2)$, hence:

$$v(r) = U_1$$

**Transient part** $w = u - U_1$ satisfies:
$$\frac{\partial w}{\partial t} = a^2\left(w'' + \frac{1}{r}w'\right), \quad w'(
r_0) = -h\,w(r_0), \quad w(r,0) = U_0 - U_1$$

## Step 2: Separation of Variables

Let $w(r,t) = R(r)\,T(t)$. Then:
$$\frac{T'}{a^2 T} = \frac{R'' + \frac{1}{r}R'}{R} = -\lambda^2$$

**Time equation:** $T(t) = e^{-a^2\lambda^2 t}$ (decaying solutions).

**Radial equation:** $R'' + \frac{1}{r}R' + \lambda^2 R = 0$, which is **Bessel'
s equation of order zero**. The bounded solution at $r=0$ is $R(r) = J_0(\lambda
 r)$ (discarding $Y_0$).

**Boundary condition:** $R'(r_0) = -h\,R(r_0)$, i.e., $-\lambda J_1(\lambda r_0)
 = -h\,J_0(\lambda r_0)$, giving the **eigenvalue equation**:

$$\boxed{\lambda\, J_1(\lambda r_0) + h\, J_0(\lambda r_0) = 0}$$

Setting $\mu_n = \lambda_n r_0$ and $\mathrm{Bi} = h\,r_0$ (Biot number), the ei
genvalues $\mu_n$ ($n = 1, 2, 3, \ldots$) are the **positive roots** of:

$$\mu\, J_1(\mu) + \mathrm{Bi}\, J_0(\mu) = 0$$

## Step 3: Orthogonality and Eigenfunction Expansion

The eigenfunctions $J_0(\lambda_n r)$ are orthogonal on $[0, r_0]$ with weight $
r$:

$$\int_0^{r_0} J_0(\lambda_m r)\,J_0(\lambda_n r)\,r\,dr = 0 \quad (m \neq n)$$

The normalization integral is:

$$\int_0^{r_0} J_0^2(\lambda_n r)\,r\,dr = \frac{r_0^2}{2}\left[J_0^2(\mu_n) + J
_1^2(\mu_n)\right]$$

## Step 4: Determining the Coefficients

The transient solution is:

$$w(r,t) = \sum_{n=1}^{\infty} A_n\, J_0(\lambda_n r)\, e^{-a^2 \lambda_n^2 t}$$

From the initial condition $w(r,0) = U_0 - U_1$:

$$A_n = (U_0 - U_1)\,\frac{\displaystyle\int_0^{r_0} J_0(\lambda_n r)\,r\,dr}{\d
isplaystyle\int_0^{r_0} J_0^2(\lambda_n r)\,r\,dr}$$

**Numerator:** $\displaystyle\int_0^{r_0} J_0(\lambda_n r)\,r\,dr = \frac{r_0\,
J_1(\mu_n)}{\lambda_n} = \frac{r_0^2\, J_1(\mu_n)}{\mu_n}$

**Denominator:** $\dfrac{r_0^2}{2}\left[J_0^2(\mu_n) + J_1^2(\mu_n)\right]$

Therefore:

$$A_n = (U_0 - U_1)\,\frac{2\,J_1(\mu_n)}{\mu_n\left[J_0^2(\mu_n) + J_1^2(\mu_n)
\right]}$$

## Step 5: Simplification Using the Eigenvalue Equation

From $\mu_n J_1(\mu_n) = -\mathrm{Bi}\, J_0(\mu_n)$, we get $J_1(\mu_n) = -\dfra
c{\mathrm{Bi}\, J_0(\mu_n)}{\mu_n}$.

Substituting:

$$J_0^2(\mu_n) + J_1^2(\mu_n) = J_0^2(\mu_n)\left(1 + \frac{\mathrm{Bi}^2}{\mu_n
^2}\right) = \frac{J_0^2(\mu_n)\,(\mu_n^2 + \mathrm{Bi}^2)}{\mu_n^2}$$

Hence:

$$A_n = (U_0 - U_1)\cdot\frac{2\left(-\frac{\mathrm{Bi}\,J_0(\mu_n)}{\mu_n}\righ
t)}{\mu_n\cdot\frac{J_0^2(\mu_n)(\mu_n^2+\mathrm{Bi}^2)}{\mu_n^2}} = (U_0 - U_1)
\cdot\frac{-2\,\mathrm{Bi}}{J_0(\mu_n)\,(\mu_n^2 + \mathrm{Bi}^2)}$$

$$\boxed{A_n = \frac{-2\,(U_0 - U_1)\,h\,r_0}{J_0(\mu_n)\,(\mu_n^2 + h^2 r_0^2)}
}$$

## Step 6: Verification of the Initial Condition

At $t = 0$, the series becomes:

$$U_0 - U_1 = \sum_{n=1}^{\infty} A_n\, J_0(\mu_n r/r_0) = -2(U_0-U_1)\,\mathrm{
Bi}\sum_{n=1}^{\infty}\frac{J_0(\mu_n r/r_0)}{J_0(\mu_n)(\mu_n^2+\mathrm{Bi}^2)}
$$

This is precisely the Fourier–Bessel expansion of the constant $1$ in the eigenf
unctions $J_0(\mu_n r/r_0)$ with the Robin boundary condition, which we derived
in Step 4. The expansion coefficients $c_n = -2\,\mathrm{Bi}/[J_0(\mu_n)(\mu_n^2
+\mathrm{Bi}^2)]$ satisfy $\sum c_n J_0(\mu_n r/r_0) = 1$ on $[0, r_0]$, confirm
ing the initial condition is satisfied. ✓

## Final Solution

$$\boxed{u(r,t) = U_1 - 2\,(U_0 - U_1)\,h\,r_0 \sum_{n=1}^{\infty} \frac{J_0\!\l
eft(\mu_n\, r/r_0\right)}{J_0(\mu_n)\,\left(\mu_n^2 + h^2 r_0^2\right)}\,\exp\!\
left(-\frac{a^2\,\mu_n^2\, t}{r_0^2}\right)}$$

where $\mu_n$ ($n = 1, 2, 3, \ldots$) are the **positive roots** of the transcen
dental equation:

$$\mu\, J_1(\mu) + h\, r_0\, J_0(\mu) = 0$$

**Interpretation:**
- $U_1$ is the steady-state (equilibrium) temperature, reached as $t \to \infty$
 (all exponential terms vanish).
- $U_0 - U_1$ measures the initial departure from equilibrium.
- The Biot number $\mathrm{Bi} = hr_0$ governs the boundary coupling: $\mathrm{B
i} \to \infty$ recovers the Dirichlet condition $u(r_0) = U_1$ (eigenvalue equat
ion reduces to $J_0(\mu) = 0$); $\mathrm{Bi} \to 0$ recovers the insulated (Neum
ann) condition (eigenvalue equation reduces to $J_1(\mu) = 0$, with $\mu = 0$ gi
ving the constant mode).
- Each mode decays with characteristic time $\tau_n = r_0^2/(a^2 \mu_n^2)$.
