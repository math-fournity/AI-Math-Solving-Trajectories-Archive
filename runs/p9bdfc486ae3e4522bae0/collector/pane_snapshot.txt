## Answer

**No.** A compact set of positive Lebesgue measure need not contain any nonempty
 open set.

### Counterexample: The Smith–Volterra–Cantor (SVC) set

Construct a set $A \subset [0,1] \subset \mathbb{R}$ as follows. Start with $C_0
 = [0,1]$. At step $k \geq 1$, remove from the middle of each connected componen
t of $C_{k-1}$ an open interval of length $2^{-2k}$ (so at step 1 remove length
$1/4$, at step 2 remove length $1/16$ from each of the 2 remaining intervals, et
c.). Let
$$A = \bigcap_{k=0}^{\infty} C_k.$$

**$A$ is compact.** Each $C_k$ is a finite union of closed intervals, hence clos
ed; $A$ is a decreasing intersection of compact sets in $[0,1]$, so $A$ is compa
ct.

**$A$ has positive measure.** The total length removed is
$$\sum_{k=1}^{\infty} 2^{k-1}\cdot 2^{-2k} = \sum_{k=1}^{\infty} 2^{-k-1} = \fra
c{1}{2}.$$
Hence $m(A) = 1 - \tfrac{1}{2} = \tfrac{1}{2} > 0$.

**$A$ contains no nonempty open set.** At every stage each remaining component i
s a closed interval, and we always remove a nontrivial open subinterval from its
 middle. The endpoints of every removed interval belong to $A$, yet every point
of $A$ is a limit of removed intervals: each point of $A$ lies in a nested seque
nce of components whose lengths shrink to $0$, and each component has a gap remo
ved from its interior at the next step. Consequently $A$ is **nowhere dense**: i
ts interior is empty.

If there were a nonempty open set $B \subset A$, then $B$ would contain some ope
n interval $(a,b) \subset A$, contradicting $\operatorname{int}(A) = \emptyset$.

### Conclusion

The SVC set $A \subset \mathbb{R}$ is compact, has Lebesgue measure $\tfrac{1}{2
} > 0$, yet contains no nonempty open subset. Embedding this example into $\math
bb{R}^n$ (e.g. $A \times \{0\}^{n-1}$ has measure $0$ in $\mathbb{R}^n$, so inst
ead take $A \times [0,1]^{n-1}$, which is compact with measure $\tfrac{1}{2} > 0
$ and whose interior is $A^\circ \times (0,1)^{n-1} = \emptyset$) gives a counte
rexample in $\mathbb{R}^n$ for every $n \geq 1$.

Therefore, **no**, such an open set $B$ need not exist.
