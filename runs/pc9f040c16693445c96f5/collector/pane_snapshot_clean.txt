$$\alpha + \beta + \gamma + \delta + \varepsilon = \pi$$

**Chord conditions:**
- AB = 2R sin α = 14, so sin α = 7/R
- BE = 2R sin(β+γ+δ) = 10, so sin(β+γ+δ) = 5/R
- BC = CD = DE implies sin β = sin γ = sin δ

**Proving β = γ = δ:** Since β, γ, δ ∈ (0, π) and β+γ+δ < π (as α+ε > 0), the eq
uation sin β = sin γ forces either β = γ or β+γ = π. The latter contradicts β+γ+
δ < π, so β = γ = δ =: θ.

## Area Conditions

Using the signed area formula for cyclic polygons, Area = (1/2)R² Σ sin(2φᵢ):

**Area(ABCDE)** = (1/2)R²[sin(2α) + 3sin(2θ) + sin(2ε)]

**Area(ACD)**: The arcs A→C, C→D, D→A have half-angles (α+θ), θ, (θ+ε):
$$\text{Area}(ACD) = \tfrac{1}{2}R^2[\sin 2(\alpha+\theta) + \sin 2\theta + \sin
 2(\theta+\varepsilon)]$$

The condition Area(ABCDE) = 3·Area(ACD) gives:
$$\sin 2\alpha + 3\sin 2\theta + \sin 2\varepsilon = 3[\sin 2(\alpha+\theta) + \
sin 2\theta + \sin 2(\theta+\varepsilon)]$$

Simplifying (the 3sin 2θ terms cancel):
$$\sin 2\alpha + \sin 2\varepsilon = 3\sin 2(\alpha+\theta) + 3\sin 2(\theta+\va
repsilon)$$

## Substituting ε = π − α − 3θ

Using ε = π − α − 3θ:
- sin 2ε = −sin(2α + 6θ)
- sin 2(θ+ε) = −sin(2α + 4θ)

The equation becomes:
$$\sin 2\alpha - \sin(2\alpha+6\theta) = 3\sin(2\alpha+2\theta) - 3\sin(2\alpha+
4\theta)$$

Applying sum-to-product identities:
- **Left side:** −2cos(2α+3θ)sin(3θ)
- **Right side:** −6cos(2α+3θ)sin(θ)

This yields:
$$-2\cos(2\alpha+3\theta)\sin 3\theta = -6\cos(2\alpha+3\theta)\sin\theta$$

If cos(2α+3θ) ≠ 0, then sin 3θ = 3sin θ, which gives sin θ = 0 (degenerate). So
we must have:

$$\cos(2\alpha + 3\theta) = 0 \implies 2\alpha + 3\theta = \frac{\pi}{2} \text{
or } \frac{3\pi}{2}$$
