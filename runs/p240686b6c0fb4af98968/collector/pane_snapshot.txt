## Proof

Let $c_i \in \{0,1\}$ denote node $i$'s status, where $c_i = 0$ means Secure and
 $c_i = 1$ means Compromised (indices mod 2000). Each node $i$ reports: *"among
nodes $i{+}1, i{+}2, i{+}3$, at least two are Compromised,"* i.e. $c_{i+1}+c_{i+
2}+c_{i+3} \ge 2$.

Since Secure nodes tell the truth and Compromised nodes lie:

$$c_i = 0 \iff c_{i+1}+c_{i+2}+c_{i+3} \ge 2, \qquad c_i = 1 \iff c_{i+1}+c_{i+2
}+c_{i+3} \le 1.$$

**Determining the recurrence.** Fix $(c_i, c_{i+1}, c_{i+2})$ and let $a = c_{i+
1}+c_{i+2} \in \{0,1,2\}$.

- If $c_i = 0$: need $c_{i+3} \ge 2-a$. When $a=0$ this forces $c_{i+3}\ge 2$, *
*impossible**; when $a=1$, $c_{i+3}=1$; when $a=2$, $c_{i+3}$ free.
- If $c_i = 1$: need $c_{i+3} \le 1-a$. When $a=2$ this forces $c_{i+3}\le -1$,
**impossible**; when $a=1$, $c_{i+3}=0$; when $a=0$, $c_{i+3}$ free.

The impossible cases are exactly $(c_i,c_{i+1},c_{i+2}) = (0,0,0)$ and $(1,1,1)$
: **no three consecutive nodes share the same status.** The remaining six states
 form a deterministic shift register (state $(c_i,c_{i+1},c_{i+2})$ maps to $(c_
{i+1},c_{i+2},c_{i+3})$):

$$\begin{aligned}
001 &\to 011 \to 110 \to 100 \to 001 \quad &\text{(cycle of length 4)}\\
010 &\to 101 \to 010 \quad &\text{(cycle of length 2)}
\end{aligned}$$

Each state has a unique successor, so the entire circular sequence follows one o
f these two cycles.

**Cycle 1 (period 4):** the $c$-sequence is $0,0,1,1,0,0,1,1,\dots$ (pattern $00
11$). Each period has two Secure ($0$) and two Compromised ($1$). Since $4 \mid
2000$, this closes up: $2000/4 = 500$ periods, giving $500 \times 2 = 1000$ Secu
re nodes.

**Cycle 2 (period 2):** the $c$-sequence is $0,1,0,1,\dots$ (pattern $01$). Each
 period has one Secure and one Compromised. Since $2 \mid 2000$, this closes up:
 $1000$ periods, giving $1000$ Secure nodes.

**Verification of Cycle 1** ($c = 0011\overline{0011}$): Node $i$ with $c_i=0$ s
ees next-three summing to $2$ (true ✓); node with $c_i=1$ sees next-three summin
g to $1$ (statement "$\ge 2$" is false, so the Compromised node lies ✓). **Verif
ication of Cycle 2** ($c=01\overline{01}$): $c_i=0$ sees sum $2$ (true ✓); $c_i=
1$ sees sum $1$ (false, lies ✓).

Both valid configurations yield exactly **1000** Secure nodes, so the answer is
determined regardless of which configuration occurs.

### The total number of secure nodes in the network is $\boxed{1000}$.
