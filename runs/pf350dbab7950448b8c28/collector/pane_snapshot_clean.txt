1. $b_k \to 0$: This is automatic since $b_k = a_k - a_{k-1}$ and $a_{n+1} - a_n

2. $\sum_{k=1}^\infty b_k = \infty$: By telescoping, $\sum_{k=1}^n b_k = a_n$, s

Thus the real question is: **must an unbounded positive sequence with $a_{n+1}-a

**Counterexample.** Construct the sequence in blocks. In block $k$ (for $k = 2,

ps, reaching value $1 + k(k-1)\cdot\frac{1}{k} = 1 + (k-1) = k$.
- **Down phase:** Start at value $k$, decrease by $1/k$ each step for $k(k-1)$ s

Concatenate blocks $k=2, 3, 4, \ldots$. At each block boundary the value is $1$,
 so transitions are seamless (difference $0$).

**Verification of properties:**

- **Positive:** Every value lies in $[1, k]$ during block $k$, so $a_n \geq 1 >
0$ for all $n$.
- **Unbounded:** The sequence reaches value $k$ in block $k$, so $\sup_n a_n = \
infty$.
