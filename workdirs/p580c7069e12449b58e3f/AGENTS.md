# Problem

In a specialized circular data network consisting of $n$ server nodes arranged in a ring, a cybersecurity team and a maintenance team are competing to configure the connections (edges) between them. The network size $n$ can be any integer such that $3 \leq n \leq 20$.

The configuration follows strict protocols:
- The **Cybersecurity Team** (acting first) must choose any unconfigured connection that shares either **0 or 2** endpoints with connections already configured.
- The **Maintenance Team** (acting second) must choose any unconfigured connection that shares **exactly 1** endpoint with connections already configured.

The teams take turns selecting one connection at a time. The first team unable to make a valid move according to their specific protocol loses the round.

Let $S$ be the set of all possible network sizes $n$ in the range $3 \leq n \leq 20$ where the **Maintenance Team** has a guaranteed strategy to win, regardless of the Cybersecurity Team's choices. 

Calculate the sum of all integers in the set $S$.
