Looking at this problem, I need to find all natural numbers $n$ such that some $
m$ (with ≥2 distinct non-zero digits) is a multiple of $n$, and every digit rear
rangement of $m$ is also a multiple of $n$.

## Proof

**Step 1: $5 \nmid n$.**
If $5 \mid n$, every rearrangement must end in 0 or 5. Since 0 is excluded, ever
y digit must be 5 (any digit can be placed last). But digits must be distinct, g
iving only one digit — contradicting $L \geq 2$.

**Step 2: Swap reduction.**
Write $n = 2^a \cdot q$ with $q$ odd, $\gcd(q,10)=1$. Swapping digits $x,y$ at p
ositions $i > j$ changes the number by $(x-y)(10^i - 10^j)$. Since both rearrang
ements are multiples of $n$:
$$n \mid (x-y)(10^i - 10^j) \quad \text{for all digits } x,y \in D,\; \text{posi
tions } i \neq j.$$
Conversely, if this holds for all swaps, all rearrangements are congruent mod $n
$; so if one is divisible by $n$, all are.

**Step 3: The $2^a$ part.**
Since $10^i - 10^j = 10^j(10^{i-j}-1)$ and $10^{i-j}-1$ is odd, $v_2(10^i-10^j)
= j$ (smaller position). The tightest case $j=0$ gives $2^a \mid (x-y)$ for all
digits, so all digits are congruent mod $2^a$. The common residue mod $2^a$ must
 also be 0.

- **$a=0$:** No constraint. Digits from $\{1,\ldots,9\}$.
- **$a=1$:** All digits same parity. If all odd, rearrangements are odd (not div
 by 2). So digits from $\{2,4,6,8\}$.
- **$a=2$:** All digits $\equiv 0 \pmod{4}$ (common residue 0 mod 4 requires thi
s). Only $\{4,8\}$, so $L=2$.
- **$a \geq 3$:** All digits $\equiv 0 \pmod{8}$: only digit 8, $L=1$. (For $a=3
$, digits $\{1,9\}$ give common residue 3 mod 8 $\neq 0$.) Impossible.

**Step 4: The $q$ part.**
Write $q = 3^c \cdot r$, $\gcd(r,3)=1$. Since $9 \mid 10^k - 1$ for all $k \geq
1$, the swap condition reduces to $q \mid 9 \cdot g_D$ where $g_D = \gcd\{x-y :
x,y \in D\}$. This gives $r \mid g_D$ and $c \leq 2 + v_3(g_D)$.

For the common residue: since $10 \equiv 1 \pmod{9}$, the residue mod $3^c$ (for
 $c \leq 2$) equals the digit sum $s \pmod{3^c}$, requiring $3^c \mid s$. For $c
=3$: direct computation shows the common residue mod 27 equals $s \pmod{27}$, an
d no valid digit set achieves $27 \mid s$ (e.g., $\{1,4,7\}$: $s=12$; $\{3,6,9\}
$: $s=18$; $\{2,5,8\}$: $s=15$ — none divisible by 27).

For the $r$ part: all digits $\equiv r_0 \pmod{r}$, and the common residue mod $
r$ is $r_0 \cdot \frac{10^L-1}{9} \pmod{r}$, requiring $r \mid r_0(10^L - 1)$.

**Step 5: Enumeration.**

*Case $a=0$:* $g_D \leq 8$. Since $r \mid g_D$, $r$ odd, $\gcd(r,3)=1$: $r \in \
{1,5,7\}$.
- $r=5$: Digits $\{1,6\},\{2,7\},\{3,8\},\{4,9\}$, $L=2$. Need $5 \mid r_0 \cdot
 99$; since $99 \equiv 4 \pmod{5}$, need $5 \mid 4r_0$ with $r_0 \in \{1,2,3,4\}
$: impossible.
- $r=7$: Digits $\{1,8\},\{2,9\}$, $L=2$. $99 \equiv 1 \pmod{7}$, need $7 \mid r
_0$ with $r_0 \in \{1,2\}$: impossible.
- $r=1$: $q = 3^c$, $c \leq 2$. Need $3^c \mid s$. Gives $n \in \{1, 3, 9\}$.

*Case $a=1$:* Digits from $\{2,4,6,8\}$, $g_D \leq 6$. Only $r=1$ (odd divisors
of $\{2,4,6\}$ coprime to 3: just 1). So $q=3^c$, $c \leq 2$. Gives $n \in \{2,
6, 18\}$.

*Case $a=2$:* Digits $\{4,8\}$, $L=2$, $g_D=4$. $r=1$, $c \leq 2$. Need $n \mid
\gcd(48,84)=12$ and $4 \mid n$. Gives $n \in \{4, 12\}$.

**Step 6: Verification.**
- $n=1$: $m=12$ ✓
- $n=2$: $m=24$; 24, 42 both even ✓
- $n=3$: $m=12$; 12, 21 both div by 3 ✓
- $n=4$: $m=48$; 48, 84 both div by 4 ✓
- $n=6$: $m=24$; 24, 42 both div by 6 ✓
- $n=9$: $m=18$; 18, 81 both div by 9 ✓
- $n=12$: $m=48$; 48, 84 both div by 12 ✓
- $n=18$: $m=468$ (digits 4,6,8, sum 18); all rearrangements even with digit sum
 18, hence div by 18 ✓

**Conclusion:** $S = \{1, 2, 3, 4, 6, 9, 12, 18\}$.

$$\sum_{n \in S} n = 1 + 2 + 3 + 4 + 6 + 9 + 12 + 18 = \boxed{55}$$
