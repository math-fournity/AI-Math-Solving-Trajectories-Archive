Proof

We partition ${1, 2, \ldots, 100}$ into three non-empty, distinguishable boxes
$A, B, C$. The condition requires that the three pairwise sum sets $$S_{AB} =
A+B,\quad S_{AC} = A+C,\quad S_{BC} = B+C$$ are pairwise disjoint. We count all
ordered triples $(A, B, C)$ satisfying this.

Step 1: A counting bound forces equality

Every cross-box sum $x + y$ (with $x, y$ in different boxes, so $x \neq y$) lies
in ${3, 4, \ldots, 199}$, which has $197$ elements. Since $S_{AB}, S_{AC},
S_{BC}$ are pairwise disjoint subsets of this set: $$|S_{AB}| + |S_{AC}| + |
S_{BC}| \leq 197.$$

For finite sets of integers, the classical sumset lower bound gives $|X + Y|
\geq |X| + |Y| - 1$ (the elements $x_1 + y_1 < x_2 + y_1 < \cdots < x_m + y_1 <
x_m + y_2 < \cdots < x_m + y_n$ are all distinct). Therefore: $$|S_{AB}| + |
S_{AC}| + |S_{BC}| \geq (|A|+|B|-1)+(|A|+|C|-1)+(|B|+|C|-1) = 2(|A|+|B|+|C|)-3 =
197.$$

Both bounds equal $197$, so equality holds throughout:

  1. $|A+B| = |A|+|B|-1$, $\ |A+C| = |A|+|C|-1$, $\ |B+C| = |B|+|C|-1$.
  2. $S_{AB} \cup S_{AC} \cup S_{BC} = {3, 4, \ldots, 199}$ (the sum sets
  partition this interval).

Step 2: Characterizing equality — arithmetic progressions

A classical result on integer sumsets states: $|X + Y| = |X| + |Y| - 1$ if and
only if $X$ and $Y$ are arithmetic progressions with the same common difference.

Proof of this fact: If $X = {x_1 < \cdots < x_m}$ and $Y = {y_1 < \cdots <
y_n}$, the $m + n - 1$ sums $x_1+y_1, x_2+y_1, \ldots, x_m+y_1, x_m+y_2, \ldots,
x_m+y_n$ are strictly increasing, giving the lower bound. Equality means every
sum $x_i + y_j$ appears among these $m+n-1$ values. In particular, $x_i + y_j =
x_{i+j-1} + y_1$ for $i+j \leq m+1$ (and symmetrically), which forces $x_{i+1} -
x_i = y_{j+1} - y_j = d$ for all valid indices, so both are APs with common
difference $d$. $\square$
