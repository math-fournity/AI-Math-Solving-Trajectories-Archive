# Proof

**Answer: Yes.** If $N$ is a type III factor, then $\mathbb{M}_n(N) \cong \mathb
b{M}_n(\mathbb{C})\,\bar{\otimes}\, N$ is also a type III factor.

---

## Step 1: $\mathbb{M}_n(N)$ is a factor

The center of $\mathbb{M}_n(N)$ is $\mathbb{M}_n(Z(N))$, where $Z(N)$ is the cen
ter of $N$. Since $N$ is a factor, $Z(N) = \mathbb{C}\cdot 1_N$. Therefore

$$Z(\mathbb{M}_n(N)) = \mathbb{M}_n(\mathbb{C}\cdot 1_N) = \mathbb{C}\cdot I_n,$
$

so $\mathbb{M}_n(N)$ is a factor.

## Step 2: Setup and the key projection

Identify $\mathbb{M}_n(N) = \mathbb{M}_n(\mathbb{C})\,\bar{\otimes}\, N$. Let $e
_i = e_{ii}\otimes 1_N$ for $i=1,\dots,n$, where $\{e_{ij}\}$ are the standard m
atrix units. The $e_i$ are mutually orthogonal projections summing to $1$, and t
hey are all Murray–von Neumann equivalent via the partial isometries $e_{ij}\oti
mes 1_N$.

Set $e = e_1 = e_{11}\otimes 1_N$. The corner

$$e\,\mathbb{M}_n(N)\,e = (e_{11}\,\mathbb{M}_n(\mathbb{C})\,e_{11})\,\bar{\otim
es}\, N \cong \mathbb{C}\,\bar{\otimes}\, N \cong N$$

via the map $e_{11}\otimes x \mapsto x$. This isomorphism preserves Murray–von N
eumann equivalence of projections.

## Step 3: $e$ is infinite

Under the isomorphism $e\,\mathbb{M}_n(N)\,e \cong N$, the projection $e$ corres
ponds to $1_N$. Since $N$ is type III, every nonzero projection in $N$ is infini
te; in particular $1_N$ is infinite in $N$. Therefore $e$ is infinite in $\mathb
b{M}_n(N)$.

## Step 4: Every nonzero projection in $\mathbb{M}_n(N)$ is infinite

Recall that a factor is type III if and only if every nonzero projection is infi
nite. We now show this holds for $\mathbb{M}_n(N)$.

Let $p\in\mathbb{M}_n(N)$ be a nonzero projection. Since $\mathbb{M}_n(N)$ is a
factor, the Murray–von Neumann comparison theorem applies: either $p\precsim e$
or $e\precsim p$.

**Case 1: $e \precsim p$.** There exists $p'\leq p$ with $p'\sim e$. Since $e$ i
s infinite, $p'$ is infinite (infiniteness is invariant under equivalence). If $
p$ were finite, every subprojection of $p$ would be finite (finiteness is heredi
tary downward: if $q\leq p$ and $q$ is infinite with $q'\sim q$, $q'<q$, then $(
p-q)+q' < p$ and $(p-q)+q'\sim p$, contradicting finiteness of $p$). This contra
dicts $p'$ being infinite. So $p$ is infinite.

**Case 2: $p \precsim e$.** There exists $p'\leq e$ with $p'\sim p$. Since $p\ne
q 0$, we have $p'\neq 0$. Now $p'$ is a nonzero projection in the corner $e\,\ma
thbb{M}_n(N)\,e\cong N$, corresponding to a nonzero projection $q\in N$. Since $
N$ is type III, $q$ is infinite in $N$: there exists $q' < q$ in $N$ with $q'\si
m q$. Under the isomorphism, this yields $p'' < p'$ in $\mathbb{M}_n(N)$ with $p
''\sim p'\sim p$.

Let $v$ be a partial isometry with $v^*v = p$ and $vv^* = p'$. Define $\tilde{p}
 = v^* p'' v$. Since $p''\leq p' = vv^*$, the element $\tilde{p}$ is a projectio
n satisfying $\tilde{p}\leq v^*p'v = v^*vv^*v = p$.

The partial isometry $v^*p''$ satisfies $(v^*p'')^*(v^*p'') = p''vv^*p'' = p''p'
p'' = p''$ and $(v^*p'')(v^*p'')^* = v^*p''p''v = v^*p''v = \tilde{p}$, so $\til
de{p}\sim p''\sim p$.

It remains to show $\tilde{p} < p$ (proper). Suppose $\tilde{p} = p$. Then $v\ti
lde{p}v^* = vpv^* = p'vv^* = p'$. But also $v\tilde{p}v^* = vv^*p''vv^* = p'p''p
' = p''$ (since $p''\leq p'$). This gives $p'' = p'$, contradicting $p'' < p'$.

Therefore $\tilde{p} < p$ with $\tilde{p}\sim p$, proving $p$ is infinite.

## Conclusion

In both cases, the arbitrary nonzero projection $p$ is infinite. Therefore every
 nonzero projection in $\mathbb{M}_n(N)$ is infinite, which is precisely the cha
racterization of a type III factor. Combined with Step 1, $\mathbb{M}_n(N)$ is a
 type III factor. $\blacksquare$
