# Solution by the Fourier Method

## Problem (correcting obvious typos ν→u)

$$u_{tt} = u_{xx} + \sin t, \quad (x,t)\in(0,\pi)\times\mathbb{R}_+$$
$$u(0,t)=u(\pi,t)=0,\quad u(x,0)=\sin x,\quad u_t(x,0)=x(x-\pi).$$

## Step 1. Eigenfunction expansion

The eigenfunctions of $-\partial_{xx}$ on $(0,\pi)$ with homogeneous Dirichlet c
onditions are $\{\sin(nx)\}_{n=1}^{\infty}$ with eigenvalues $n^{2}$. Set

$$u(x,t)=\sum_{n=1}^{\infty}T_n(t)\sin(nx).$$

Expand the forcing $\sin t$ (constant in $x$) in a sine series:

$$f_n(t)=\frac{2}{\pi}\sin t\int_0^{\pi}\sin(nx)\,dx=\frac{2(1-(-1)^n)}{n\pi}\si
n t
=\begin{cases}\dfrac{4}{n\pi}\sin t,& n\text{ odd},\\[4pt]0,& n\text{ even}.\end
{cases}$$

Each $T_n$ satisfies the forced oscillator ODE

$$T_n''+n^2 T_n=f_n(t).$$

## Step 2. Initial data in sine coefficients

From $u(x,0)=\sin x$: $\;T_1(0)=1$, $\;T_n(0)=0\;(n\neq 1)$.

From $u_t(x,0)=x^2-\pi x$:

$$T_n'(0)=\frac{2}{\pi}\int_0^{\pi}(x^2-\pi x)\sin(nx)\,dx.$$

Compute (integration by parts twice):

$$\int_0^{\pi}x^2\sin(nx)\,dx=-\frac{\pi^2(-1)^n}{n}+\frac{2\bigl((-1)^n-1\bigr)
}{n^3},\qquad
\int_0^{\pi}\pi x\,\sin(nx)\,dx=-\frac{\pi^2(-1)^n}{n}.$$

Subtracting:

$$\int_0^{\pi}(x^2-\pi x)\sin(nx)\,dx=\frac{2\bigl((-1)^n-1\bigr)}{n^3},$$

so

$$T_n'(0)=\frac{4\bigl((-1)^n-1\bigr)}{\pi n^3}
=\begin{cases}-\dfrac{8}{\pi n^3},& n\text{ odd},\\[4pt]0,& n\text{ even}.\end{c
ases}$$

## Step 3. Solve the ODEs

**Even $n$:** $f_n=0$, $T_n(0)=T_n'(0)=0$, hence $T_n(t)\equiv 0$.

**Odd $n\ge 3$:** $T_n''+n^2 T_n=\dfrac{4}{n\pi}\sin t$, with $T_n(0)=0$, $T_n'(
0)=-\dfrac{8}{\pi n^3}$. Since $1\neq n$, a particular solution is $C\sin t$ wit
h $C(n^2-1)=\dfrac{4}{n\pi}$, i.e. $C=\dfrac{4}{n\pi(n^2-1)}$. Thus

$$T_n(t)=A\cos(nt)+B\sin(nt)+\frac{4}{n\pi(n^2-1)}\sin t.$$

From $T_n(0)=0$: $A=0$. From $T_n'(0)=Bn+\dfrac{4}{n\pi(n^2-1)}=-\dfrac{8}{\pi n
^3}$:

$$Bn=-\frac{8}{\pi n^3}-\frac{4}{n\pi(n^2-1)}=\frac{-8(n^2-1)-4n^2}{\pi n^3(n^2-
1)}=\frac{-12n^2+8}{\pi n^3(n^2-1)},$$

$$B=\frac{-12n^2+8}{\pi n^4(n^2-1)}.$$

**$n=1$ (resonance):** $T_1''+T_1=\dfrac{4}{\pi}\sin t$, with $T_1(0)=1$, $T_1'(
0)=-\dfrac{8}{\pi}$. Since $\sin t$ is a homogeneous solution, use the ansatz $C
t\cos t$:

$$(Ct\cos t)''+Ct\cos t=-2C\sin t=\frac{4}{\pi}\sin t\;\Longrightarrow\;C=-\frac
{2}{\pi}.$$

So $T_1(t)=A\cos t+B\sin t-\dfrac{2t}{\pi}\cos t$. From $T_1(0)=1$: $A=1$. From
$T_1'(0)=B-\dfrac{2}{\pi}=-\dfrac{8}{\pi}$: $B=-\dfrac{6}{\pi}$. Hence

$$T_1(t)=\cos t-\frac{6}{\pi}\sin t-\frac{2t}{\pi}\cos t.$$

## Step 4. The solution

$$\boxed{\,u(x,t)=\Bigl(\cos t-\frac{6}{\pi}\sin t-\frac{2t}{\pi}\cos t\Bigr)\si
n x+\sum_{\substack{n\ge 3\\ n\text{ odd}}}\left[\frac{4\,\sin t}{n\pi(n^2-1)}+\
frac{(-12n^2+8)\,\sin(nt)}{\pi n^4(n^2-1)}\right]\sin(nx).\,}$$

## Verification

- **BCs:** Each $\sin(nx)$ vanishes at $x=0,\pi$. ✓
- **$u(x,0)$:** $T_1(0)=1$; for odd $n\ge3$, $T_n(0)=0+0=0$; even $n$ vanish. So
 $u(x,0)=\sin x$. ✓
- **$u_t(x,0)$:** $T_1'(0)=-\frac{6}{\pi}-\frac{2}{\pi}=-\frac{8}{\pi}$; for odd
 $n\ge3$,
$$T_n'(0)=\frac{-12n^2+8}{\pi n^3(n^2-1)}+\frac{4}{\pi n(n^2-1)}=\frac{-12n^2+8+
4n^2}{\pi n^3(n^2-1)}=\frac{-8(n^2-1)}{\pi n^3(n^2-1)}=-\frac{8}{\pi n^3}.$$
Summing over odd $n$:
$$u_t(x,0)=\sum_{\substack{n\ge1\\n\text{ odd}}}\frac{-8}{\pi n^3}\sin(nx)=\frac
{2}{\pi}\sum_{\text{odd }n}\frac{2((-1)^n-1)}{n^3}\sin(nx)=\frac{2}{\pi}\int_0^\
pi(x^2-\pi x)\,d_x\bigl[\text{sine series}\bigr]=x^2-\pi x.\;\checkmark$$
- **PDE:** Each $T_n''+n^2T_n=f_n(t)$, so $u_{tt}-u_{xx}=\sum f_n(t)\sin(nx)=\si
n t$. ✓

The secular (linearly growing) term $-\frac{2t}{\pi}\cos t\,\sin x$ arises from
resonance of the time-harmonic forcing $\sin t$ with the fundamental mode $n=1$.
