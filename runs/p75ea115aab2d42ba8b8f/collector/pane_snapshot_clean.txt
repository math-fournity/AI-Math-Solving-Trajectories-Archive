## Solution

**Key Observation: Digit sum changes when incrementing by 1.**

When going from $n$ to $n+1$, if $n$ has $k$ trailing 9's, the digit sum changes
 by $1 - 9k$ (the trailing 9's become 0's, losing $9k$, and the next digit gains
 1). For two consecutive numbers to **both** have digit sum $\equiv 0 \pmod{5}$,
 we need:
$$1 - 9k \equiv 0 \pmod{5} \implies 4k \equiv 1 \pmod{5} \implies k \equiv 4 \pm
od{5}$$

**Checking feasibility in $[1, 1000]$:** The maximum number of trailing 9's for
any number $\leq 999$ is $k=3$ (the number 999). The possible values are $k \in
\{0, 1, 2, 3\}$, and the corresponding changes mod 5 are:

| $k$ | Change $1-9k$ | mod 5 |
|-----|---------------|-------|
| 0   | $+1$          | 1     |
| 1   | $-8$          | 2     |
| 2   | $-17$         | 3     |
| 3   | $-26$         | 4     |

None are $\equiv 0 \pmod{5}$. The transition $999 \to 1000$ gives digit sums $27
 \to 1$ (change $-26 \equiv 4$). Since $k=4$ would require a number ending in $9
999 > 1000$, **no two consecutive numbers in $[1,1000]$ can both have digit sum
divisible by 5**.

Therefore the maximum run length is $n = 1$, and we must count all numbers in $[
1, 1000]$ with digit sum $\equiv 0 \pmod{5}$.

**Counting by digit length:**

**1-digit (1–9):** Digit sum equals the number itself. Divisible by 5: only $\{5
\}$. Count $= 1$.

**2-digit (10–99):** Digits $d_1 \in \{1,\dots,9\}$, $d_0 \in \{0,\dots,9\}$. Ne
ed $d_1 + d_0 \equiv 0 \pmod{5}$. For each $d_1$, exactly 2 values of $d_0 \in \
{0,\dots,9\}$ satisfy $d_0 \equiv -d_1 \pmod{5}$ (since 10 = 2×5). Count $= 9 \t
imes 2 = 18$.

**3-digit (100–999):** Digits $d_2 \in \{1,\dots,9\}$, $d_1, d_0 \in \{0,\dots,9
\}$. Need $d_2 + d_1 + d_0 \equiv 0 \pmod{5}$. For each $(d_2, d_1)$, exactly 2
values of $d_0$ work. Count $= 9 \times 10 \times 2 = 180$.

**1000:** Digit sum $= 1$, not divisible by 5. Count $= 0$.

**Total:** $1 + 18 + 180 = 199$.

**Verification of a few cases:**
- $5 \to 5$ ✓; $6 \to 6$ ✗ (consecutive pair broken)
- $19 \to 10$ ✓; $20 \to 2$ ✗
- $140 \to 5$ ✓; $141 \to 6$ ✗
- $999 \to 27 \equiv 2$ ✗; $1000 \to 1$ ✗

All confirm no two consecutive accessible lockers exist.

## Answer

The maximum sequence length is $n = 1$, and the number of such maximum-length se
quences is $\boxed{199}$.
