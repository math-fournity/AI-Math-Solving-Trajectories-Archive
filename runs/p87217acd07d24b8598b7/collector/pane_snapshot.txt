$$\left(k - \frac{1}{k}\right)\left(m - \frac{1}{m}\right)\left(n - \frac{1}{n}\

## Proof

Since both sides are symmetric in $k, m, n$, we may assume WLOG that $a < b < c$
 are three distinct positive integers. Set $u = b - a \ge 1$ and $v = c - b \ge
1$, so $b = a + u$ and $c = a + u + v$.

**Step 1: Reformulation.** Since $x - 1/x = (x^2 - 1)/x$, the left side equals $
\frac{(a^2-1)(b^2-1)(c^2-1)}{abc}$. Multiplying both sides by $abc > 0$, we need
:

$$(a^2-1)(b^2-1)(c^2-1) \le abc(abc - a - b - c).$$

**Step 2: Expansion.** Expanding both sides and canceling $a^2b^2c^2$, this is e
quivalent to:

$$a^2b^2 + a^2c^2 + b^2c^2 - abc(a+b+c) \ge a^2 + b^2 + c^2 - 1.$$

**Step 3: Key identity.** Setting $x = ab,\, y = bc,\, z = ca$, the left side be
comes:

$$x^2 + y^2 + z^2 - (xy + yz + zx) = \tfrac{1}{2}\bigl((x-y)^2 + (y-z)^2 + (z-x)
^2\bigr) = \tfrac{1}{2}\bigl(b^2(a-c)^2 + c^2(b-a)^2 + a^2(c-b)^2\bigr).$$

So we need to prove:

$$b^2(a-c)^2 + c^2(b-a)^2 + a^2(c-b)^2 \ge 2(a^2 + b^2 + c^2 - 1). \tag{$\star$}
$$

**Step 4: Substitution.** With $b = a+u$, $c = a+u+v$, and $s = u+v$, the left s
ide of $(\star)$ is:

$$(a+u)^2 s^2 + (a+s)^2 u^2 + a^2 v^2.$$

Expanding:

$$= a^2(s^2 + u^2 + v^2) + 2a(s^2 u + u^2 s) + 2u^2 s^2.$$

Since $s^2 + u^2 + v^2 = 2(u^2 + uv + v^2)$ and $s^2 u + u^2 s = su(s+u) = u(u+v
)(2u+v)$, this equals:

$$2a^2(u^2+uv+v^2) + 2au(u+v)(2u+v) + 2u^2(u+v)^2.$$

The right side of $(\star)$ is $2\bigl(3a^2 + 2a(2u+v) + 2u^2+2uv+v^2 - 1\bigr)$
.

**Step 5: Forming the difference.** The difference (LHS $-$ RHS) of $(\star)$, d
ivided by $2$, is:

$$a^2\underbrace{(u^2+uv+v^2-3)}_{A} \;+\; a\underbrace{(2u+v)(u^2+uv-2)}_{B} \;
+\; \underbrace{u^2(u+v)^2 - 2u^2 - 2uv - v^2 + 1}_{C}.$$

**Step 6: The constant term factors.** We simplify $C$:

$$C = u^2(u+v)^2 - u^2 - (u+v)^2 + 1 = (u^2-1)\bigl((u+v)^2 - 1\bigr) = (u-1)(u+
1)(u+v-1)(u+v+1).$$

**Step 7: Non-negativity of all three coefficients.** For $u \ge 1,\, v \ge 1$:

- **$A = u^2 + uv + v^2 - 3 \ge 0$:** The function $u^2+uv+v^2$ is increasing in
 both variables for $u,v > 0$, so its minimum on $u,v \ge 1$ is at $u=v=1$, givi
ng $3$. Equality iff $u=v=1$.

- **$B = (2u+v)(u^2+uv-2) \ge 0$:** Since $2u+v > 0$ and $u^2+uv \ge 1+1 = 2$ (w
ith equality iff $u=v=1$), we have $B \ge 0$.

- **$C = (u-1)(u+1)(u+v-1)(u+v+1) \ge 0$:** Each factor is non-negative: $u-1 \g
e 0$, $u+1 > 0$, $u+v-1 \ge 1 > 0$, $u+v+1 > 0$. Equality iff $u = 1$.

**Step 8: Conclusion.** Since $a \ge 1$ is a positive integer and $A, B, C \ge 0
$, we have:

$$a^2 A + aB + C \ge 0.$$

This establishes $(\star)$, and hence the original inequality. $\blacksquare$

**Equality cases.** Equality holds iff $A = B = C = 0$, which requires $u = v =
1$ (i.e., $a, b, c$ are three consecutive integers). One verifies directly that
for $(a, a+1, a+2)$ both sides equal $a(a+1)^2(a+2)(a^2+2a-3) = a(a-1)(a+1)^2(a+
2)(a+3)$, confirming equality for all consecutive triples, including $(1,2,3)$,
$(2,3,4)$, $(3,4,5)$, etc.
