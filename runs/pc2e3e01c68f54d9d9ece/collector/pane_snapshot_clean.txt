## Solution

Let
$$F(x) = \int f(x)\,dx, \qquad G(x) = \int \frac{1}{f(x)}\,dx.$$
The given equation is $F(x)\,G(x) = -1$ for all $x$ (the right-hand side is the
constant $-1$). In particular $F$ is never zero and $G = -1/F$.

Differentiating $F\,G = -1$ gives
$$F'\,G + F\,G' = 0 \;\;\Longrightarrow\;\; f\cdot G + F\cdot \frac{1}{f} = 0.$$
Substituting $G = -1/F$:
$$-\frac{f}{F} + \frac{F}{f} = 0 \;\;\Longrightarrow\;\; \frac{F}{f} = \frac{f}{
F} \;\;\Longrightarrow\;\; F^{2} = f^{2}.$$

Hence at every point $f = F$ or $f = -F$. Assuming $f$ is continuous and never z
ero (so $F$ is continuous and never zero), on each connected interval of the dom
ain the sign is constant, giving two cases.

**Case 1: $f = F$.** Then $F' = F$, so $F(x) = C e^{x}$ for a constant $C\neq 0$
, and $f(x) = C e^{x}$. Verify:
$$\int f\,dx = C e^{x} + c_1,\qquad \int \frac{1}{f}\,dx = -\frac{1}{C}e^{-x} +
c_2.$$
Their product is
$$-1 + Cc_2\,e^{x} - \frac{c_1}{C}\,e^{-x} + c_1 c_2.$$
For this to equal $-1$ identically we need $c_1 = 0$ and $c_2 = 0$, giving the p
roduct $-1$. ✓

**Case 2: $f = -F$.** Then $F' = -F$, so $F(x) = C e^{-x}$ and $f(x) = -C e^{-x}
 = C' e^{-x}$ (renaming $C' = -C \neq 0$). Verify:
$$\int f\,dx = C' \cdot(-e^{-x}) + c_1 = -C'e^{-x} + c_1,\qquad \int \frac{1}{f}
\,dx = \frac{1}{C'}e^{x} + c_2.$$
Their product is
$$-1 + \frac{c_1}{C'}e^{x} - C'c_2\,e^{-x} + c_1 c_2,$$
which equals $-1$ identically only when $c_1 = c_2 = 0$. ✓

In both families the integration constants must be zero, and the multiplicative
constant must be nonzero (so that $1/f$ is defined).

**Answer.** All solutions are
$$\boxed{f(x) = C\,e^{x} \quad\text{or}\quad f(x) = C\,e^{-x}},\qquad C\in\mathb
b{R}\setminus\{0\}.$$
