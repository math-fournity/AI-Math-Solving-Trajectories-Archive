## Proof

**Key observation.** The condition "no rectangle has zeros at all four corners"
is equivalent to: any two distinct rows share **at most one** column in which bo
th have a zero. (If rows $r_1, r_2$ both have zeros in columns $c_1, c_2$, then
the four corners $(r_i, c_j)$ are all zero — a forbidden rectangle.)

So we need a set system on $n = k^2 - k + 1$ elements with $n$ blocks, each bloc
k of size $k$, each element in $k$ blocks, and any two blocks intersecting in at
 most one element. This is precisely the incidence structure of a **finite proje
ctive plane of order $p$**, since:
$$n = p^2 + p + 1 = (p+1)^2 - (p+1) + 1 = k^2 - k + 1, \qquad k = p+1.$$

### Construction via $PG(2, p)$

Work over the field $\mathbb{F}_p$.

**Points:** The 1-dimensional subspaces of $\mathbb{F}_p^3$, i.e., equivalence c
lasses $[x:y:z]$ of nonzero vectors under $(x,y,z) \sim \lambda(x,y,z)$ for $\la
mbda \in \mathbb{F}_p^*$. The number of points is
$$\frac{p^3 - 1}{p - 1} = p^2 + p + 1 = k^2 - k + 1.$$

**Lines:** The 2-dimensional subspaces of $\mathbb{F}_p^3$, each given by an equ
ation $ax + by + cz = 0$ with $(a,b,c) \neq (0,0,0)$, up to scalar multiplicatio
n. Written as $[a:b:c]$. The number of lines is also $p^2 + p + 1$.

**Incidence:** Point $[x:y:z]$ lies on line $[a:b:c]$ if and only if $ax + by +
cz \equiv 0 \pmod{p}$.

**Distribution rule.** Index the rows of the table by the $p^2+p+1$ lines and th
e columns by the $p^2+p+1$ points. Place **0** in cell $(L, P)$ if point $P$ lie
s on line $L$; place **1** otherwise.

### Verification of the three required properties

**1. Each row has exactly $k = p+1$ zeros.**

A line $L: ax+by+cz=0$ is the kernel of a nonzero linear functional $\mathbb{F}_
p^3 \to \mathbb{F}_p$, which has rank 1. Its kernel is a 2-dimensional subspace
containing $p^2 - 1$ nonzero vectors, yielding
$$\frac{p^2 - 1}{p - 1} = p + 1 = k$$
projective points on $L$. So each row has exactly $k$ zeros. ✓

**2. Each column has exactly $k = p+1$ zeros.**

Fix a point $P = [x_0:y_0:z_0]$. The lines through $P$ correspond to nonzero $(a
,b,c)$ satisfying $ax_0 + by_0 + cz_0 = 0$. This is the kernel of the nonzero li
near functional $(a,b,c) \mapsto ax_0 + by_0 + cz_0$ on $\mathbb{F}_p^3$, hence
a 2-dimensional subspace, giving
$$\frac{p^2 - 1}{p - 1} = p + 1 = k$$
lines through $P$. So each column has exactly $k$ zeros. ✓

**3. No rectangle has zeros at all four corners.**

Two distinct lines $L_1 = [a_1:b_1:c_1]$ and $L_2 = [a_2:b_2:c_2]$ correspond to
 two linearly independent linear functionals (independence follows from distinct
ness, since proportional functionals define the same line). Their common zero se
t is the intersection of two distinct 2-dimensional subspaces in $\mathbb{F}_p^3
$, which is a 1-dimensional subspace — yielding **exactly one** projective point
.

Therefore any two distinct rows share **exactly one** column with a zero. A rect
angle with zeros at all four corners would require two rows sharing at least **t
wo** zero-columns, which is impossible. ✓

### Conclusion

For every prime $p$, setting $k = p+1$ and using the incidence matrix of the pro
jective plane $PG(2,p)$ over $\mathbb{F}_p$ — placing 0 where point lies on line
, 1 otherwise — produces a $(k^2-k+1) \times (k^2-k+1)$ table in which:
- every row and every column contains exactly $k = p+1$ zeros, and
- no axis-parallel rectangle has zeros at all four corners (since any two lines
of $PG(2,p)$ meet in exactly one point).

This gives the required distribution for each prime $p$. $\blacksquare$
