# Problem

In a specialized logistics warehouse, an automated storage system consists of various rectangular zones. Each zone is defined by a grid of $m$ rows and $n$ columns of docking slots. A technician is tasked with installing high-security sensors at $k$ of these slots.

To prevent interference between sensors, the technician must follow a strict safety protocol: no three sensors can be placed in a configuration that forms a right-angled triangle whose sides are parallel to the rows and columns of the grid. 

Let $k(m, n)$ represent the maximum number of sensors that can be installed in an $m \times n$ grid while adhering to this safety protocol. 

The warehouse manager needs to evaluate the total capacity of different grid configurations. Calculate the total sum of these maximum capacities for all possible grid sizes where $m$ and $n$ each range from 1 to 10:
$$\sum_{m=1}^{10} \sum_{n=1}^{10} k(m, n)$$
