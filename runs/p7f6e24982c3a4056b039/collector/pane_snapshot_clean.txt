## Proof

Model the situation as a graph $G$ on 9 vertices (the men), with an edge joining
 two men who are acquainted. The condition "among every three, two are mutually
acquainted" means $G$ has **no independent set of size 3**, i.e. $\alpha(G) \le
2$. We prove $G$ contains a clique $K_4$ (four mutually acquainted men).

Consider the complement graph $H = \overline{G}$, where an edge means two men ar
e **not** acquainted. Then:

- $G$ has no independent set of size 3 $\iff$ $H$ has no triangle ($K_3$), i.e.
$H$ is **triangle-free**.
- $G$ has a $K_4$ $\iff$ $H$ has an **independent set of size 4**.

So it suffices to prove:

> **Claim.** Every triangle-free graph $H$ on 9 vertices has an independent set
of size 4.

*Proof of Claim.* Suppose for contradiction that $\alpha(H) \le 3$.

Since $H$ is triangle-free, for every vertex $v$ the neighborhood $N(v)$ is an i
ndependent set: if two neighbors of $v$ were adjacent, together with $v$ they wo
uld form a triangle. Since $\alpha(H) \le 3$, this forces
$$\deg(v) = |N(v)| \le 3 \quad \text{for every vertex } v.$$

Now fix any vertex $v$ and let $R = V(H) \setminus (\{v\} \cup N(v))$ be the set
 of vertices that are neither $v$ itself nor adjacent to $v$. Then
$$|R| = 9 - 1 - \deg(v) \ge 9 - 1 - 3 = 5.$$

The induced subgraph $H[R]$ is triangle-free (being a subgraph of a triangle-fre
e graph). If $|R| \ge 6$, then by $R(3,3)=6$, the triangle-free graph $H[R]$ on
at least 6 vertices contains an independent set $\{a,b,c\}$ of size 3. Since $a,
b,c \in R$, none of them is adjacent to $v$, and they are mutually non-adjacent;
 hence $\{v,a,b,c\}$ is an independent set of size 4 in $H$—contradicting $\alph
a(H) \le 3$.

Therefore $|R| \le 5$. Combined with $|R| \ge 5$, we get $|R| = 5$, and conseque
ntly $\deg(v) = 3$.

Since $v$ was arbitrary, **every** vertex has degree exactly 3. But then the sum
 of all degrees is $9 \times 3 = 27$, which is odd—impossible by the handshake l
emma (the sum of degrees in any graph is even).

This contradiction establishes $\alpha(H) \ge 4$, so $G$ contains a $K_4$; i.e.,
 some four of the nine men are mutually acquainted. $\blacksquare$

*(For completeness, $R(3,3)=6$: in any 6-vertex graph, a vertex $v$ has at least
 3 neighbors or at least 3 non-neighbors. In the first case, either two neighbor
s are adjacent (a triangle with $v$) or three neighbors are mutually non-adjacen
t (an independent set of size 3). In the second case, either two non-neighbors a
re non-adjacent (an independent set of size 3 with $v$) or three non-neighbors a
re mutually adjacent (a triangle). Thus every 6-vertex graph has a triangle or a
n independent set of size 3.)*
