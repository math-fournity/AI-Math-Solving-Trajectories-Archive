## Proof

**Answer-leak check:** The problem statement contains no solutions, answer value
s, or proof sketches. Proceeding.

Let $F(x) = x^n - a$. We seek ordered pairs $(P_1, P_2) \in \mathbb{Z}[x]^2$ wit
h
$$P_1^2 + P_2^2 = F^2,$$
excluding the trivial pairs $(\pm F, 0)$ and $(0, \pm F)$.

**Key identity.** Working in the UFD $R = \mathbb{Z}[i][x]$ (since $\mathbb{Z}[i
]$ is a PID, $R$ is a UFD), we have
$$P_1^2 + P_2^2 = (P_1 + iP_2)(P_1 - iP_2).$$
Since $P_1, P_2$ have integer (hence real) coefficients, complex conjugation fix
es them, so $\overline{P_1 + iP_2} = P_1 - iP_2$. Also $\bar{a} = a$, hence $\ba
r{F} = F$.

**Using irreducibility.** By hypothesis $F$ is irreducible in $R$; in a UFD irre
ducible elements are prime, so $F$ is prime. Write
$$P_1 + iP_2 = F^{k}\cdot H, \qquad \gcd(H, F) = 1, \quad k \ge 0,$$
for some $H \in R$ (up to a unit absorbed into $H$). Applying conjugation (and $
\bar F = F$):
$$P_1 - iP_2 = F^{k}\cdot \bar H.$$
Multiplying:
$$F^2 = (P_1+iP_2)(P_1-iP_2) = F^{2k}\, H\bar H.$$
Hence
$$H\bar H = F^{\,2-2k}.$$

**$H$ is coprime to $F$.** If $F \mid H$, that contradicts $\gcd(H,F)=1$. If $F
\mid \bar H$, conjugating gives $F \mid H$, same contradiction. Therefore $F \nm
id H\bar H$, forcing the exponent $2 - 2k = 0$, i.e. $k = 1$. Then
$$H\bar H = 1.$$

**$H$ must be a unit.** If $\deg H \ge 1$, then $\deg(H\bar H) = 2\deg H \ge 2 >
 0$, contradicting $H\bar H = 1$. So $H$ is a constant $c \in \mathbb{Z}[i]$, an
d $c\bar c = |c|^2 = 1$, giving $c \in \{1, -1, i, -i\}$.

**Enumerating.** With $k=1$ and $H = c \in \{\pm1, \pm i\}$:
$$P_1 + iP_2 = c\,F.$$

- $c = 1$: $(P_1, P_2) = (F, 0)$.
- $c = -1$: $(P_1, P_2) = (-F, 0)$.
- $c = i$: $P_1 + iP_2 = iF \Rightarrow (P_1, P_2) = (0, F)$.
- $c = -i$: $(P_1, P_2) = (0, -F)$.

These are exactly the four trivial pairs. No other value of $k$ or $H$ is possib
le, so **every** solution is trivial.

**Conclusion.** The number of ordered pairs $(P_1, P_2)$ satisfying $P_1^2 + P_2
^2 = (x^n - a)^2$ with $P_1, P_2 \in \mathbb{Z}[x]$, excluding the trivial pairs
, is

$$\boxed{0}.$$
