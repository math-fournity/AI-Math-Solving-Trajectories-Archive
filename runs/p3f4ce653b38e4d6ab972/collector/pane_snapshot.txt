## Part 1: Computing f(4)

We count permutations of {0, 1, 2, 3, 4} with no "succession" — no position wher
e value *i* is immediately followed by value *i+1*. The forbidden successions ar
e: 0→1, 1→2, 2→3, 3→4 (four events total).

**Inclusion-Exclusion.** Let $A_i$ be the set of permutations where succession $
i \to i{+}1$ occurs. We want $5! - |A_0 \cup A_1 \cup A_2 \cup A_3|$.

For any subset $S \subseteq \{0,1,2,3\}$ of successions required simultaneously:
 each succession glues two adjacent values into a block. Even when successions c
hain (e.g., {0→1, 1→2} forms block (0,1,2)), the total number of free objects is
 $5 - |S|$, giving $(5-|S|)!$ permutations. This holds for every subset of size
$|S|$, regardless of chaining.

By inclusion-exclusion:

$$f(4) = \sum_{k=0}^{4} (-1)^k \binom{4}{k}(5-k)!$$

Computing each term:

| k | Sign | $\binom{4}{k}$ | $(5-k)!$ | Term |
|---|------|----------------|-----------|------|
| 0 | + | 1 | 120 | +120 |
| 1 | − | 4 | 24 | −96 |
| 2 | + | 6 | 6 | +36 |
| 3 | − | 4 | 2 | −8 |
| 4 | + | 1 | 1 | +1 |

$$f(4) = 120 - 96 + 36 - 8 + 1 = \boxed{53}$$

## Part 2: Computing g(3)

We have 3 files {1, 2, 3} and ordered pairs $(B, C)$ of permutations such that:
for every $x$, if $B(x) \neq x$ then $C(x) = x$. Equivalently, **the support of
$C$ (elements moved by $C$) must be contained in the fixed-point set of $B$**.

The 6 permutations of {1,2,3} and their fixed points:

| B | Moved set M(B) | Fixed points Fix(B) | Valid C (must fix all of M(B)) | Co
unt |
|---|----------------|---------------------|-------------------------------|----
---|
| id | ∅ | {1,2,3} | any of 6 permutations | 6 |
| (12) | {1,2} | {3} | C must fix 1,2 → only id | 1 |
| (13) | {1,3} | {2} | C must fix 1,3 → only id | 1 |
| (23) | {2,3} | {1} | C must fix 2,3 → only id | 1 |
| (123) | {1,2,3} | ∅ | C must fix all → only id | 1 |
| (132) | {1,2,3} | ∅ | C must fix all → only id | 1 |

**Reasoning for each case:** When $B = \text{id}$, no element is moved by $B$, s
o $C$ is unconstrained — all 6 permutations qualify. For every non-identity $B$,
 at least two elements are moved, so $C$ must fix at least two elements. A permu
tation of {1,2,3} that fixes two elements necessarily fixes the third (a single
element cannot be permuted alone), forcing $C = \text{id}$.

$$g(3) = 6 + 1 + 1 + 1 + 1 + 1 = \boxed{11}$$
