# Solution

## Setting Up the Transfer Matrix

We tile a $3 \times 2021$ grid with cell $(1,1)$ removed using dominoes. We use
the transfer matrix method, processing columns left to right. The **state** is a
 subset $S \subseteq \{1,2,3\}$ recording which rows of the current column are a
lready occupied by horizontal dominoes from the previous column.

For a **normal** column, the transfer matrix $M$ (rows = incoming state $S$, col
umns = outgoing state $T$) is built by tiling the free cells (complement of $S$)
 with vertical dominoes (adjacent pairs) and horizontal dominoes (which set bits
 in $T$). Computing all 8 rows:

| $S$ | Free cells | Possible $T$ (with multiplicity) |
|-----|-----------|----------------------------------|
| 0 (000) | {1,2,3} | T=1, T=4, T=7 |
| 1 (001) | {2,3} | T=0, T=6 |
| 2 (010) | {1,3} | T=5 |
| 3 (011) | {3} | T=4 |
| 4 (100) | {1,2} | T=0, T=3 |
| 5 (101) | {2} | T=2 |
| 6 (110) | {1} | T=1 |
| 7 (111) | {} | T=0 |

## Handling the Removed Cell

**Column 1** has cell $(1,1)$ removed, so only rows 2,3 are available. With inco
ming state $S=0$, the free cells are $\{2,3\}$ — identical to a normal column wi
th incoming state $S=1$. Thus after column 1, the state vector is row 1 of $M$,
namely $v_1 = e_0 + e_6$ (states 0 and 6, each with 1 way).

Columns 2 through 2021 are normal, so:
$$v_{2021} = (e_0 + e_6)\, M^{2020}, \qquad m = v_{2021}[0] = (M^{2020})[0,0] +
(M^{2020})[6,0].$$

## Reducing to a Single Matrix Entry

Define $f(n) = (M^n)[1,0]$, the number of tilings of a $3\times n$ board with ce
ll $(1,1)$ removed (state 1 at the left = row 1 pre-occupied). Then:
$$f(2021) = (M^{2021})[1,0] = \sum_k M[1,k]\,(M^{2020})[k,0] = M[1,0]\cdot b_{20
20} + M[1,6]\cdot c_{2020} = b_{2020}+c_{2020}=m.$$

So $m = f(2021)$.

## Establishing the Recurrence

By computing $w_n = e_1 \cdot M^n$ step by step:

| $n$ | $f(n) = w_n[0]$ |
|-----|------|
| 0 | 0 |
| 1 | 1 |
| 2 | 0 |
| 3 | 4 |
| 4 | 0 |
| 5 | 15 |
| 6 | 0 |
| 7 | 56 |

For **odd** $n = 2k+1$, setting $g(k) = f(2k+1)$: we get $g(0)=1,\; g(1)=4,\; g(
2)=15,\; g(3)=56$, satisfying:
$$g(k) = 4\,g(k-1) - g(k-2).$$

This is the **Lucas sequence** $g(k) = U_{k+1}(4,1)$ where $U_0=0,\; U_1=1,\; U_
n = 4U_{n-1}-U_{n-2}$.

Since $2021 = 2\cdot 1010 + 1$, we have $k=1010$, so:
$$m = f(2021) = g(1010) = U_{1011}.$$

## Computing $U_{1011} \pmod{19}$

The characteristic equation is $t^2 - 4t + 1 = 0$ with roots $\alpha = 2+\sqrt{3
}$, $\beta = 2-\sqrt{3}$, and $\alpha\beta = 1$.

**Is 3 a quadratic residue mod 19?** By Euler's criterion: $3^9 \equiv 18 \equiv
 -1 \pmod{19}$, so 3 is **not** a QR mod 19. The roots lie in $\mathrm{GF}(19^2)
$.

Let $\omega^2 = 3$ in $\mathrm{GF}(19^2)$. Then $\alpha = 2+\omega$, $\beta = 2-
\omega = \alpha^{-1}$.

**Finding the order of $\alpha$:** Since $N(\alpha) = \alpha\cdot\alpha^{19} = \
alpha\beta = 1$, the order of $\alpha$ divides $|\ker N| = (19^2-1)/(19-1) = 20$
. Computing directly:
$$\alpha^2 = 7+4\omega, \qquad \alpha^4 = (7+4\omega)^2 = 97 + 56\omega \equiv 2
 + 18\omega = 2-\omega = \beta = \alpha^{-1} \pmod{19}.$$

Therefore $\alpha^5 = \alpha\cdot\alpha^4 = \alpha\cdot\alpha^{-1} = 1$, so $\op
eratorname{ord}(\alpha) = 5$.

Since $U_n = \frac{\alpha^n - \alpha^{-n}}{\alpha - \alpha^{-1}}$ and $\alpha^n$
 has period 5, **$U_n \pmod{19}$ has period 5**:

| $n \bmod 5$ | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| $U_n \bmod 19$ | 0 | 1 | 4 | 15 | 18 |

(Verified directly: $U_0{=}0,\; U_1{=}1,\; U_2{=}4,\; U_3{=}15,\; U_4{=}56{\equi
v}18,\; U_5{=}4(18){-}15{=}57{\equiv}0,\; U_6{\equiv}1,\ldots$)

## Final Computation

$$1011 \equiv 1 \pmod{5} \implies U_{1011} \equiv U_1 = 1 \pmod{19}.$$

**Verification with small cases:** A $3\times 1$ board minus $(1,1)$ leaves cell
s $(2,1),(3,1)$: exactly 1 vertical domino, so $f(1)=1$. ✓ A $3\times 3$ board m
inus $(1,1)$: either a vertical domino in column 1 leaving a $3\times 2$ board (
3 tilings), or horizontal dominoes in rows 2,3 of column 1 forcing a unique comp
letion (1 tiling) — total 4 = $f(3)$. ✓

## Answer

$$\boxed{m \equiv 1 \pmod{19}}$$
