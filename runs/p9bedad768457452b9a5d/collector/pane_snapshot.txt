## Solution to the Polar Laplace Equation with $u(a,\theta)=0$

### Problem Setup

The Laplace equation in polar coordinates $(r,\theta)$ is:

$$\nabla^2 u = \frac{\partial^2 u}{\partial r^2} + \frac{1}{r}\frac{\partial u}{
\partial r} + \frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2} = 0$$

with the boundary condition $u(a,\theta) = 0$ for all $\theta$.

### Separation of Variables

We seek solutions of the form $u(r,\theta) = R(r)\Theta(\theta)$. Substituting a
nd dividing by $R\Theta$:

$$\frac{r^2 R'' + rR'}{R} + \frac{\Theta''}{\Theta} = 0$$

Setting each part equal to a separation constant $-\lambda$:

**Angular equation:** $\Theta'' + \lambda\,\Theta = 0$, with periodicity $\Theta
(\theta+2\pi)=\Theta(\theta)$.

This forces $\lambda = n^2$ for $n = 0, 1, 2, \ldots$, giving:
- $n=0$: $\Theta_0 = \text{const}$
- $n \geq 1$: $\Theta_n = \cos(n\theta)$ or $\sin(n\theta)$

**Radial equation (Euler–Cauchy):** $r^2 R'' + rR' - n^2 R = 0$.

Trying $R = r^k$ yields $k^2 - n^2 = 0$, so $k = \pm n$.

- $n = 0$: $R_0(r) = A_0 + B_0 \ln r$
- $n \geq 1$: $R_n(r) = A_n r^n + B_n r^{-n}$

### General Solution

Superposing all modes:

$$u(r,\theta) = A_0 + B_0 \ln r + \sum_{n=1}^{\infty}\Big[\big(A_n r^n + B_n r^{
-n}\big)\cos(n\theta) + \big(C_n r^n + D_n r^{-n}\big)\sin(n\theta)\Big]$$

### Applying the Boundary Condition $u(a,\theta)=0$

Setting $r = a$ and requiring the result to vanish for **all** $\theta$, each Fo
urier mode must independently vanish:

**Constant mode ($n=0$):**
$$A_0 + B_0 \ln a = 0 \implies B_0 = -\frac{A_0}{\ln a}$$

So the $n=0$ contribution becomes:
$$A_0 + B_0\ln r = A_0 - \frac{A_0}{\ln a}\ln r = A_0\frac{\ln a - \ln r}{\ln a}
 = A_0\,\frac{\ln(a/r)}{\ln a}$$

**Cosine modes ($n\geq 1$):**
$$A_n\, a^n + B_n\, a^{-n} = 0 \implies B_n = -A_n\, a^{2n}$$

So each cosine radial factor becomes:
$$A_n r^n + B_n r^{-n} = A_n\big(r^n - a^{2n}\,r^{-n}\big) = A_n\,r^{-n}\big(r^{
2n} - a^{2n}\big)$$

**Sine modes ($n\geq 1$):**
$$C_n\, a^n + D_n\, a^{-n} = 0 \implies D_n = -C_n\, a^{2n}$$

So each sine radial factor becomes:
$$C_n r^n + D_n r^{-n} = C_n\big(r^n - a^{2n}\,r^{-n}\big) = C_n\,r^{-n}\big(r^{
2n} - a^{2n}\big)$$

### Final General Solution

Substituting back, the most general harmonic function in the plane (polar coordi
nates) satisfying $u(a,\theta)=0$ is:

$$\boxed{u(r,\theta) = A_0\,\frac{\ln(a/r)}{\ln a} + \sum_{n=1}^{\infty}\big(r^n
 - a^{2n}\,r^{-n}\big)\Big[A_n\cos(n\theta) + C_n\sin(n\theta)\Big]}$$

where $A_0, A_n, C_n$ ($n\geq 1$) are arbitrary constants determined by any addi
tional boundary/regularity conditions.

### Verification

**Check 1 — Each term is harmonic.** The functions $\ln r$, $r^n\cos(n\theta)$,
$r^{-n}\cos(n\theta)$, $r^n\sin(n\theta)$, $r^{-n}\sin(n\theta)$ are all classic
al solutions of the polar Laplace equation (obtained via separation of variables
), and linearity preserves harmonicity.

**Check 2 — Boundary condition.** At $r = a$:
- Constant mode: $A_0\,\dfrac{\ln(a/a)}{\ln a} = A_0\cdot 0 = 0$. ✓
- Each $n\geq 1$ mode: $\big(a^n - a^{2n}\,a^{-n}\big) = a^n - a^n = 0$. ✓

Hence $u(a,\theta) = 0$ for every $\theta$, as required.

**Check 3 — Completeness.** The separated solutions $\{1,\ln r,\, r^{\pm n}\cos
n\theta,\, r^{\pm n}\sin n\theta\}$ form a complete basis for harmonic functions
 on an annular domain (standard Fourier–Laplace expansion). The boundary conditi
on $u(a,\theta)=0$ imposes exactly one linear constraint per mode, reducing each
 pair $(A_n,B_n)$ and $(C_n,D_n)$ to a single free parameter, and fixing $B_0$ i
n terms of $A_0$. No further constraints are imposed, so the family above is the
 **full** general solution.
