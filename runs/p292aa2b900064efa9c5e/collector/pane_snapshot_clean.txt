# Proof

**Claim:** Every Lindelöf subspace of the ordinal space $\omega_1$ is countable.

We prove the contrapositive: every uncountable subspace of $\omega_1$ is **not**
 Lindelöf.

---

**Setup.** Let $\omega_1 = [0, \omega_1)$ denote the set of all countable ordina
ls equipped with the order topology. Recall two standard facts:

- (F1) Every countable ordinal has only countably many predecessors; equivalentl
y, for every $\alpha < \omega_1$, the initial segment $[0, \alpha] = \alpha + 1$
 is countable.
- (F2) The supremum of countably many countable ordinals is again a countable or
dinal, hence is $< \omega_1$.

**Step 1: An uncountable subspace is cofinal in $\omega_1$.**

Let $S \subseteq \omega_1$ be uncountable. Suppose, for contradiction, that $\su
p S = \alpha < \omega_1$. Then $S \subseteq [0, \alpha] = \alpha + 1$, which is
countable by (F1). This forces $S$ to be countable — a contradiction. Hence
$$\sup S = \omega_1.$$

**Step 2: Construct an open cover with no countable subcover.**

For each $\alpha < \omega_1$, set $U_\alpha = [0, \alpha) = \{\gamma \in \omega_
1 : \gamma < \alpha\}$. In the order topology on $\omega_1$, each $U_\alpha$ is
open (it is a basic open neighborhood of the minimum element $0$, and more gener
ally an open ray). Therefore $\{U_\alpha \cap S : \alpha < \omega_1\}$ is a fami
ly of open sets in the subspace $S$.

This family covers $S$: for any $\beta \in S$, we have $\beta < \omega_1$, so $\
beta \in [0, \beta+1) = U_{\beta+1}$, hence $\beta \in U_{\beta+1} \cap S$.

**Step 3: No countable subcover exists.**

Consider any countable subfamily $\{U_{\alpha_n} \cap S : n \in \mathbb{N}\}$. I
ts union is
$$\bigcup_{n \in \mathbb{N}} U_{\alpha_n} \cap S = [0, \beta) \cap S, \qquad \te
xt{where } \beta = \sup_{n} \alpha_n.$$
By (F2), $\beta < \omega_1$. Since $\sup S = \omega_1 > \beta$, there exists $\g
amma \in S$ with $\gamma \geq \beta$, i.e., $\gamma \notin [0, \beta)$. Thus $\g
amma$ is not covered by the subfamily.

Since this holds for **every** countable subfamily, the open cover $\{U_\alpha \
cap S : \alpha < \omega_1\}$ admits no countable subcover. Therefore $S$ is not
Lindelöf.

---

**Conclusion.** We have shown that every uncountable subspace of $\omega_1$ fail
s to be Lindelöf. By contraposition, every Lindelöf subspace of $\omega_1$ is co
untable. $\blacksquare$
