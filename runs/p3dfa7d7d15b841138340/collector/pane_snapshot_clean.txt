## Proof

Let $A \in \mathrm{GL}_2(\mathbb{Q})$ have finite order, so $A^n = I$ for some $
n \geq 1$. Then the minimal polynomial $m_A(x)$ divides $x^n - 1$, hence is a pr
oduct of distinct cyclotomic polynomials (since $x^n-1$ is separable over $\math
bb{Q}$). In particular, $A$ is **semisimple** (diagonalizable over $\overline{\m
athbb{Q}}$), and every eigenvalue of $A$ is a root of unity.

The characteristic polynomial $\chi_A(x)$ is a monic degree-2 polynomial over $\
mathbb{Q}$ whose roots are roots of unity. We enumerate all possibilities.

### Case 1: Both eigenvalues are rational roots of unity

The only rational roots of unity are $\pm 1$, giving three characteristic polyno
mials:

**(a) $\chi_A(x) = (x-1)^2$.** Since $A$ is semisimple, the minimal polynomial i
s squarefree, so $m_A(x) \mid (x-1)$, forcing $m_A(x) = x-1$ and $A = I$. (A non
trivial Jordan block with eigenvalue $1$ would give $A = I + N$ with $N^2 = 0$,
$N \neq 0$, and $A^n = I + nN \neq I$ for $n \geq 1$—not finite order.) **One co
njugacy class: $\{I\}$, order 1.**

**(b) $\chi_A(x) = (x+1)^2$.** Similarly, semisimplicity forces $m_A(x) = x+1$,
so $A = -I$. (A nontrivial Jordan block gives $A = -I + N$, $A^n = (-1)^n I + n(
-1)^{n-1}N \neq \pm I$.) **One conjugacy class: $\{-I\}$, order 2.**

**(c) $\chi_A(x) = (x-1)(x+1) = x^2 - 1$.** The eigenvalues $1, -1$ are distinct
, so $m_A(x) = x^2 - 1 = \chi_A(x)$. There is a single rational canonical form (
companion matrix of $x^2-1$), and $A$ is conjugate to $\mathrm{diag}(1, -1)$. **
One conjugacy class, order 2.**

### Case 2: Eigenvalues are non-rational roots of unity (conjugate pair)

The characteristic polynomial must be an irreducible degree-2 factor of some $x^
n - 1$, i.e., a cyclotomic polynomial $\Phi_n(x)$ with $\varphi(n) = 2$. Solving
 $\varphi(n) = 2$ gives $n \in \{3, 4, 6\}$:

**(d) $\chi_A(x) = \Phi_3(x) = x^2 + x + 1$.** Irreducible over $\mathbb{Q}$, so
 $m_A = \chi_A$. Single rational canonical form (companion matrix). Eigenvalues
are primitive 3rd roots of unity. **One conjugacy class, order 3.**

**(e) $\chi_A(x) = \Phi_4(x) = x^2 + 1$.** Irreducible, $m_A = \chi_A$. Eigenval
ues $\pm i$. **One conjugacy class, order 4.**

**(f) $\chi_A(x) = \Phi_6(x) = x^2 - x + 1$.** Irreducible, $m_A = \chi_A$. Eige
nvalues are primitive 6th roots of unity. **One conjugacy class, order 6.**

### No other cases

If one eigenvalue is rational and the other is not, the characteristic polynomia
l would not have rational coefficients—impossible. If both eigenvalues are non-r
ational but not conjugate over $\mathbb{Q}$, the characteristic polynomial would
 not be rational—impossible. The only irreducible degree-2 cyclotomic polynomial
s are $\Phi_3, \Phi_4, \Phi_6$ (from $\varphi(n)=2$), so the list is exhaustive.

### Verification of finite order

For each class above, the matrix satisfies its minimal polynomial which divides
some $x^n - 1$:
- $I$: order 1; $-I$: $(-I)^2 = I$, order 2; $\mathrm{diag}(1,-1)$: order 2;
- Companion of $\Phi_3$: $A^3 = I$ (since $\Phi_3 \mid x^3 - 1$), order 3;
- Companion of $\Phi_4$: $A^4 = I$ (since $\Phi_4 \mid x^4 - 1$), order 4;
- Companion of $\Phi_6$: $A^6 = I$ (since $\Phi_6 \mid x^6 - 1$), order 6.

### Conclusion

The distinct conjugacy classes of matrices of finite order in $\mathrm{GL}_2(\ma
thbb{Q})$ are represented by the rational canonical forms with characteristic/mi
nimal polynomials:

| Representative | Characteristic polynomial | Order |
|---|---|---|
| $I$ | $(x-1)^2$ | 1 |
| $-I$ | $(x+1)^2$ | 2 |
| $\mathrm{diag}(1,-1)$ | $x^2 - 1$ | 2 |
| $\mathrm{comp}(\Phi_3)$ | $x^2 + x + 1$ | 3 |
| $\mathrm{comp}(\Phi_4)$ | $x^2 + 1$ | 4 |
| $\mathrm{comp}(\Phi_6)$ | $x^2 - x + 1$ | 6 |

There are **6** distinct conjugacy classes.
