# Comparing Cardinalities of $A = \{f:[0,1]\to\mathbb{N}\}$ and $B = \mathbb{R}$

Let $\mathfrak{c} = |\mathbb{R}| = 2^{\aleph_0}$, and note $|[0,1]| = \mathfrak{
c}$ and $|\mathbb{N}| = \aleph_0$.

## Step 1: Compute $|A|$

$A$ is the set of all functions $[0,1]\to\mathbb{N}$, so by definition of cardin
al exponentiation,
$$|A| = \aleph_0^{\,\mathfrak{c}} = \aleph_0^{\,2^{\aleph_0}}.$$

## Step 2: Two-sided bounds

**Lower bound.** Since $\aleph_0 \geq 2$,
$$\aleph_0^{\,2^{\aleph_0}} \geq 2^{\,2^{\aleph_0}} = 2^{\mathfrak{c}}.$$

**Upper bound.** Since $\aleph_0 \leq 2^{\aleph_0} = \mathfrak{c}$,
$$\aleph_0^{\,\mathfrak{c}} \leq \mathfrak{c}^{\,\mathfrak{c}} = (2^{\aleph_0})^
{\,\mathfrak{c}} = 2^{\aleph_0 \cdot \mathfrak{c}}.$$
Because $\aleph_0 \cdot \mathfrak{c} = \mathfrak{c}$ (infinite cardinal arithmet
ic: $\mathfrak{c}$ is infinite and $\aleph_0 \leq \mathfrak{c}$),
$$\aleph_0^{\,\mathfrak{c}} \leq 2^{\mathfrak{c}}.$$

Combining both bounds:
$$|A| = \aleph_0^{\,\mathfrak{c}} = 2^{\mathfrak{c}}.$$

## Step 3: Compare with $|B|$

We have $|B| = |\mathbb{R}| = \mathfrak{c}$, and $|A| = 2^{\mathfrak{c}}$.

By **Cantor's theorem**, for every cardinal $\kappa$, $2^{\kappa} > \kappa$. App
lying this with $\kappa = \mathfrak{c}$:
$$|A| = 2^{\mathfrak{c}} > \mathfrak{c} = |B|.$$

## Conclusion

The set $A$ of all functions $[0,1]\to\mathbb{N}$ has strictly larger cardinalit
y than $\mathbb{R}$:
$$\boxed{|A| = 2^{\mathfrak{c}} > \mathfrak{c} = |B|}.$$

Equivalently, $|A| = 2^{|\mathbb{R}|}$, so $A$ has the same cardinality as the p
ower set $\mathcal{P}(\mathbb{R})$, which is strictly larger than $\mathbb{R}$ i
tself.
