## Solution

**Analyzing the triangle condition.**

For two distinct numbers $x < y$ in $A$, the sides of any triangle must each be
$x$ or $y$. The possible non-equilateral isosceles triangles are:

1. **$(x, x, y)$**: valid iff the triangle inequality $x + x > y$ holds, i.e., $
y < 2x$.
2. **$(y, y, x)$**: valid iff $y + y > x$, i.e., $2y > x$. Since $x < y$, we hav
e $x < y < 2y$, so this is **always valid**.

The equilateral triangles $(x,x,x)$ and $(y,y,y)$ are excluded by hypothesis.

**Uniqueness requirement.** The problem requires *exactly one* such triangle. Si
nce $(y,y,x)$ is always valid when $x < y$, we need $(x,x,y)$ to be **invalid**,
 i.e.:

$$y \geq 2x \quad \text{for every pair } x < y \text{ in } A.$$

**Maximizing $|A|$.** Sort $A = \{a_1 < a_2 < \cdots < a_k\}$. The condition bec
omes $a_{i+1} \geq 2a_i$ for all $i$, which by induction gives:

$$a_k \geq 2^{k-1} a_1 \geq 2^{k-1} \cdot 1 = 2^{k-1}.$$

Since $a_k \leq 2015$, we need $2^{k-1} \leq 2015$. Computing:

$$2^{10} = 1024 \leq 2015, \qquad 2^{11} = 2048 > 2015.$$

So $k - 1 \leq 10$, giving $k \leq 11$.

**Construction achieving $k = 11$.** Take $A = \{1, 2, 4, 8, 16, 32, 64, 128, 25
6, 512, 1024\}$.

- Every element satisfies $a_i = 2^{i-1} \leq 1024 \leq 2015$. ✓
- For any pair $a_i < a_j$ (with $j > i$): $a_j / a_i = 2^{j-i} \geq 2$, so $a_j
 \geq 2a_i$. ✓

Thus every pair $\{a_i, a_j\}$ with $i < j$ yields exactly one valid non-equilat
eral isosceles triangle, namely $(a_j, a_j, a_i)$.

**Conclusion.** The largest possible size of $A$ is $\boxed{11}$.
