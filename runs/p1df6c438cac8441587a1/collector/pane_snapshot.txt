## Proof

We want to determine when $X_n^{(\alpha)} \to 0$ almost surely. Since $X_n^{(\al
pha)} \in \{0,1\}$, convergence to $0$ a.s. is equivalent to
$$P\bigl(X_n^{(\alpha)} = 1 \text{ infinitely often}\bigr) = 0.$$

Let $A_n = \{X_n^{(\alpha)} = 1\}$, so $P(A_n) = n^{-2\alpha}$. The events $\{A_
n\}$ are independent (the $X_n^{(\alpha)}$ are independent).

**Borel–Cantelli (converse part).** For independent events, $P(A_n \text{ i.o.})
 \in \{0,1\}$, and
$$P(A_n \text{ i.o.}) = 0 \iff \sum_{n=1}^{\infty} P(A_n) < \infty.$$

Now
$$\sum_{n=1}^{\infty} P(A_n) = \sum_{n=1}^{\infty} \frac{1}{n^{2\alpha}},$$
which is a $p$-series converging if and only if $2\alpha > 1$, i.e. $\alpha > \t
frac{1}{2}$.

Therefore
$$S = \Bigl\{\alpha > 0 : X_n^{(\alpha)} \to 0 \text{ a.s.}\Bigr\} = \Bigl(\tfra
c{1}{2},\, \infty\Bigr).$$

Hence
$$\inf S = \frac{1}{2}.$$
