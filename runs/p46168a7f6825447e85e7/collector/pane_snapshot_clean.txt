Proof: Existence of a Subset of ℝ Without the Baire Property

Answer: Yes, such a subset exists. We construct a Bernstein set and prove it
lacks the Baire property. The construction uses the Axiom of Choice (which is
necessary: it is consistent with ZF + DC that every set of reals has the Baire
property).

────────────────────────────────────────────────────────────────────────────────

Step 1: Construction of a Bernstein Set

A set $B \subseteq \mathbb{R}$ is a Bernstein set if both $B$ and $B^c$
intersect every uncountable closed subset of $\mathbb{R}$ (equivalently, every
perfect set).

Enumeration. The collection of perfect subsets of $\mathbb{R}$ has cardinality $
\mathfrak{c}$ (the continuum): there are at most $\mathfrak{c}$ closed sets
(each determined by a countable union of open intervals with real endpoints),
and at least $\mathfrak{c}$ perfect sets (the closed intervals $[a,b]$, $a <
b$). Enumerate all perfect sets as ${P_\alpha : \alpha < \mathfrak{c}}$.

Transfinite recursion. For each $\alpha < \mathfrak{c}$, choose two distinct
points $$x_\alpha,, y_\alpha \in P_\alpha \setminus {x_\beta,, y_\beta : \beta <
\alpha}.$$ This is possible because $|P_\alpha| = \mathfrak{c}$ (every perfect
set in $\mathbb{R}$ has cardinality $\mathfrak{c}$) while $|{x_\beta, y_\beta :
\beta < \alpha}| \leq 2|\alpha| < \mathfrak{c}$.

Set $B = {x_\alpha : \alpha < \mathfrak{c}}$. Then:

  • $B \cap P_\alpha \ni x_\alpha \neq \emptyset$ for every $\alpha$ — $B$ meets
  every perfect set.
  • $B^c \cap P_\alpha \ni y_\alpha \neq \emptyset$ for every $\alpha$ — $B^c$
  meets every perfect set.

────────────────────────────────────────────────────────────────────────────────

Step 2: A Bernstein Set Lacks the Baire Property

Suppose for contradiction that $B$ has the Baire property. Then there exists an
open set $U \subseteq \mathbb{R}$ such that $B \bigtriangleup U$ is meager. We
consider two cases.

Case 1: $U = \emptyset$ (i.e., $B$ is meager)

Since $B$ is meager, $B$ is contained in an $F_\sigma$ meager set $M =
\bigcup_{n=1}^{\infty} F_n$, where each $F_n$ is closed and nowhere dense. Then
$$\mathbb{R} \setminus M = \bigcap_{n=1}^{\infty} (\mathbb{R} \setminus F_n)$$
is a dense $G_\delta$ set (each $\mathbb{R} \setminus F_n$ is dense open, since
$F_n$ is nowhere dense). Being a dense $G_\delta$ in the perfect Polish space $
\mathbb{R}$, the set $\mathbb{R} \setminus M$ is uncountable and Borel. By the
perfect set property of Borel sets, $\mathbb{R} \setminus M$ contains a perfect
set $P$.

But $B \subseteq M$, so $B \cap P \subseteq B \cap (\mathbb{R} \setminus M) =
\emptyset$, i.e., $B \cap P = \emptyset$. This contradicts the Bernstein
property ($B$ must meet every perfect set). $\Rightarrow!\Leftarrow$

Case 2: $U \neq \emptyset$ (i.e., $B$ is non-meager)

$U$ contains a nonempty open interval, so $U$ is non-meager (by the Baire
Category Theorem, no nonempty open set in $\mathbb{R}$ is meager). Since $B
\bigtriangleup U$ is meager, $B$ is non-meager as well (otherwise $U = B
\bigtriangleup (B \bigtriangleup U)$ would be a symmetric difference of two
meager sets, hence meager — contradiction).

Now, $U \setminus B \subseteq B \bigtriangleup U$ is meager. So $U \setminus B$
is contained in some $F_\sigma$ meager set $M = \bigcup_n F_n$ (each $F_n$
closed nowhere dense). Define $$G = U \setminus M = U \cap \bigcap_{n=1}
^{\infty}(\mathbb{R} \setminus F_n).$$ Each $U \cap (\mathbb{R} \setminus F_n)$
is dense open in $U$ (since $F_n$ is nowhere dense, $\mathbb{R} \setminus F_n$
is dense, so its intersection with the open set $U$ is dense in $U$). Therefore
$G$ is a dense $G_\delta$ in $U$, and: $$G \subseteq U \setminus (U \setminus B)
= U \cap B \subseteq B.$$

Since $U$ is a nonempty open subset of $\mathbb{R}$, it is a perfect Polish
space (with the subspace topology). The dense $G_\delta$ set $G$ is uncountable
and Borel (as a $G_\delta$ in $\mathbb{R}$). By the perfect set property of
Borel sets, $G$ contains a perfect set $P$.

Then $P \subseteq G \subseteq B$, so $B^c \cap P = \emptyset$. But $P$ is a
perfect subset of $\mathbb{R}$, and $B^c$ must meet every perfect set (Bernstein
property). Contradiction. $\Rightarrow!\Leftarrow$

────────────────────────────────────────────────────────────────────────────────

Conclusion

Both cases yield contradictions. Therefore our assumption was false: $B$ does
not have the Baire property. Since $B \subseteq \mathbb{R}$, there exists a
subset of $\mathbb{R}$ without the Baire property. $\blacksquare$

Remark. The Axiom of Choice is essential here. In Solovay's model (ZF + DC +
"every set of reals is Lebesgue measurable"), every set of reals has the Baire
property, so the existence of such sets is independent of ZF + DC.
