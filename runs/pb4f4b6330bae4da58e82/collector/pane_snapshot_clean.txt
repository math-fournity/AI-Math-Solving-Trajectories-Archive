## Upper Bound: Total Variation $\leq 2n - 8$

Let $U = \sum_{i: h_{i+1} > h_i} (h_{i+1} - h_i)$ be the total increase and $D =
 \sum_{i: h_{i+1} < h_i} |h_{i+1} - h_i|$ the total decrease. Then:
$$\text{Total variation} = U + D, \qquad U - D = h_{n-2} - h_1 = 3 - h_1.$$
So $D = U + h_1 - 3$ and **total variation $= 2U + h_1 - 3$**.

**Bounding $U$ via interior point budget.** Each increase step where $h_{i+1} -
h_i = d > 0$ corresponds to removing a hull vertex whose ear contains $p = d + 1
$ points that get promoted from interior to hull (since the increase equals $p -
 1$). By Lemma 2, hull vertices never become interior, so the total number of pr
omotions over the entire process is at most the initial number of interior point
s:
$$\sum_{\text{increasing steps}} (d_i + 1) = U + \gamma \leq n - h_1,$$
where $\gamma$ is the number of increasing steps. If $U > 0$, then $\gamma \geq
1$, giving:
$$U \leq n - h_1 - 1.$$

Therefore:
$$\text{Total variation} = 2U + h_1 - 3 \leq 2(n - h_1 - 1) + h_1 - 3 = 2n - h_1
 - 5 \leq 2n - 8,$$
since $h_1 \geq 3$. (When $U = 0$, total variation $= h_1 - 3 \leq n - 3 < 2n -
8$ for $n > 5$.)
