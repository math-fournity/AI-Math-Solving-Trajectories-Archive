## Solution

**Key observation:** The operation $k \oplus \lfloor k/2 \rfloor$ is precisely t
he **binary-reflected Gray code** of $k$, denoted $G(k)$.

**Proof that $G$ is a bijection on $\{0, 1, \ldots, 2^n-1\}$:**

For any $n$-bit number $k$, the map $G(k) = k \oplus \lfloor k/2 \rfloor$ is inv
ertible. Given $g = G(k)$, we recover $k$ bit by bit from the most significant b
it downward: the top bit of $k$ equals the top bit of $g$, and each subsequent b
it $k_i = g_i \oplus k_{i+1}$ (where bits are indexed from MSB). This is well-de
fined and produces a unique $k \in \{0,\ldots,2^n-1\}$ for every $g \in \{0,\ldo
ts,2^n-1\}$. Hence $G$ is a bijection (in fact a permutation) of $\{0,1,\ldots,2
^n-1\}$.

**Verification with small case ($n=2$):**
- $G(0) = 0 \oplus 0 = 0$
- $G(1) = 1 \oplus 0 = 1$
- $G(2) = 10_2 \oplus 01_2 = 11_2 = 3$
- $G(3) = 11_2 \oplus 01_2 = 10_2 = 2$

The values $\{0,1,3,2\}$ are a permutation of $\{0,1,2,3\}$, and the sum is $6 =
 \frac{3\cdot 4}{2}$. ✓

**Computing the sum:**

Since $G$ permutes $\{0, 1, \ldots, 2^{2014}-1\}$ (taking $n = 2014$), the set o

}-1\}$. Therefore:
