## Proof

We compute $S=\sum_{i=1}^{1000} g(i)$, where $g(i)=3^{f(i)}$ and $f(i)$ counts t
he digits of $i$ that are $\ge 5$.

**Key observation.** For a $k$-digit number with digits $d_1 d_2 \ldots d_k$, we
 have
$$g = 3^{f} = \prod_{j=1}^{k} 3^{\mathbf{1}[d_j \ge 5]}.$$
This multiplicative form lets us factor the sum over each digit position.

Define $A = \sum_{d=0}^{9} 3^{\mathbf{1}[d\ge 5]} = 5\cdot 3^0 + 5\cdot 3^1 = 5+
15 = 20$ (digits $0,1,2,3,4$ contribute $1$; digits $5,6,7,8,9$ contribute $3$).

Define $B = \sum_{d=1}^{9} 3^{\mathbf{1}[d\ge 5]} = 4\cdot 1 + 5\cdot 3 = 4+15 =
 19$ (the leading digit cannot be $0$).

**One-digit numbers ($1$ to $9$).** The single digit ranges over $1,\ldots,9$, s
o the sum is $B = 19$.

**Two-digit numbers ($10$ to $99$).** The tens digit ranges over $1,\ldots,9$ an
d the units digit over $0,\ldots,9$, independently:
$$\sum_{a=1}^{9}\sum_{b=0}^{9} 3^{\mathbf{1}[a\ge5]+\mathbf{1}[b\ge5]} = B\cdot
A = 19\cdot 20 = 380.$$

**Three-digit numbers ($100$ to $999$).** Hundreds digit $1,\ldots,9$; tens and
units each $0,\ldots,9$:
$$B\cdot A\cdot A = 19\cdot 20\cdot 20 = 7600.$$

**The number $1000$.** Its digits are $1,0,0,0$; none is $\ge 5$, so $f(1000)=0$
 and $g(1000)=3^0=1$.

**Total.**
$$S = 19 + 380 + 7600 + 1 = 8000.$$

Therefore,

$$\boxed{\sum_{i=1}^{1000} g(i) = 8000}.$$
