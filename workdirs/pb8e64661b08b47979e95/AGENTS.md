# Problem

In the year 2047, a specialized cyber-security firm is auditing a database containing "secure-coded" identification numbers. These IDs are defined as positive integers $n$ that satisfy three specific security protocols:

1. **The Factor Protocol:** Each identification number $n$ must possess exactly $1974$ unique divisors (factors). It is known that $1974$ can be decomposed into the product $2 \cdot 3 \cdot 7 \cdot 47$.
2. **The Frequency Protocol:** To maintain high-frequency compatibility, no prime factor of $n$ can be greater than $40$.
3. **The Parity and Terminal Protocol:** For encryption purposes, the ID number $n$ must end in one of the following terminal digits: $1, 3, 7,$ or $9$.

How many distinct positive integers $n$ meet all three of these security criteria?
