# Solution

## Setup and Angle Chasing

Let me set up coordinates with $B = (0,0)$, $C = (2,0)$, so $M = (1,0)$ (midpoin
t of $BC$). Let $A = (a, h)$, $D = (d, h)$ with $AD \parallel BC$ (both horizont
al). Let $P = (p, h)$ on $AD$.

**Key elements:**
- Line $PM$ extended meets line $DC$ at $Q$ (beyond $C$).
- The fiber-optic cable from $P$ is perpendicular to $AD$, i.e., the vertical li
ne $x = p$, meeting line $BQ$ at $K$.
- In $\triangle KQD$: $\angle KQD = 64°$, $\angle KDQ = 38°$, so $\angle QKD = 7
8°$.

## Establishing $\alpha = \angle KBC$

Since $K$ lies on segment $BQ$ (between $B$ and $Q$), the ray $QK$ points toward
 $B$, so $\angle BQD = \angle KQD = 64°$.

Since $Q$ lies on line $DC$ beyond $C$, the rays $QC$ and $QD$ point in the **sa
me direction** from $Q$. Thus $\angle BQC = \angle BQD = 64°$.

In $\triangle BQC$, with $\angle QBC = \alpha$ and $\angle BCQ = 180° - \angle B
CD$ (since $CQ$ is opposite to $CD$):

$$64° + \alpha + (180° - \angle BCD) = 180° \implies \alpha = \angle BCD - 64°$$

Since $AD \parallel BC$, the trapezoid gives $\angle ADC + \angle BCD = 180°$, s
o $\angle ADC = 180° - \angle BCD = 116° - \alpha$.

## Using the Perpendicular and Midpoint Constraints

**Angle of $DK$:** Since $\angle KDQ = 38°$ and $\angle ADC = 116° - \alpha$, th
e angle between $DA$ (horizontal) and $DK$ at $D$ is:

$$\angle ADK = \angle ADC - \angle KDC = (116° - \alpha) - 38° = 78° - \alpha$$

**Slope constraint from the perpendicular:** The line $BQ$ makes angle $\alpha$
below horizontal, so $K = (p,\, -p\tan\alpha)$. Since $PK$ is vertical and $P =
(p, h)$, we have $K$ directly below $P$.

**Collinearity of $P, M, Q$ and $Q$ on line $DC$:** Working through the coordina
te algebra (with $M = (1,0)$ the midpoint of $BC = 2$), the collinearity of $P =
 (p,h)$, $M = (1,0)$, and $Q$ on line $DC$ yields:

$$\tan\alpha = \frac{h}{d - 2p} \quad \Longrightarrow \quad h = (d - 2p)\tan\alp
ha$$

**Angle of $DK$ in coordinates:** The direction from $D = (d, h)$ to $K = (p, -p
\tan\alpha)$ gives:

$$\frac{p\tan\alpha + h}{d - p} = \tan(78° - \alpha)$$

## The Key Cancellation

Substituting $h = (d - 2p)\tan\alpha$:

$$\frac{p\tan\alpha + (d-2p)\tan\alpha}{d - p} = \tan(78° - \alpha)$$

$$\frac{\tan\alpha \cdot (d - p)}{d - p} = \tan(78° - \alpha)$$

$$\tan\alpha = \tan(78° - \alpha)$$

The factor $(d-p)$ **cancels completely** — this is the crucial role of the midp
oint constraint (the coefficient $2$ in $2p$ arises from $M$ being the midpoint
of $BC$).

## Solving

Since both $\alpha$ and $78° - \alpha$ lie in $(0°, 90°)$ where tangent is injec
tive:

$$\alpha = 78° - \alpha \implies 2\alpha = 78° \implies \alpha = 39°$$

## Verification

- $\alpha = 39°$, $\angle BCD = 103°$, $\angle ADC = 77°$
- $\angle ADK = 78° - 39° = 39°$, $\angle KDC = 77° - 39° = 38°$ ✓
- In $\triangle BKD$: $\angle BKD = 102°$, $\angle KBD = 39° + \angle DBC$, $\an
gle BDK = \angle BDC - 38°$
- Check: $102° + 39° + \angle DBC + \angle BDC - 38° = 103° + (\angle DBC + \ang
le BDC) = 103° + 77° = 180°$ ✓

## Answer

$$\boxed{\angle KBC = 39°}$$
