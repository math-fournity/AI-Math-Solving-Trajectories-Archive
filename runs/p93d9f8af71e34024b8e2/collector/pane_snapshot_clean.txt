## Proof

Let α = ∠A, β = ∠B, γ = ∠C, so β > α (since AC > BC) and α + β + γ = π. Set
φ = α + β = π − γ,   ψ = β − α,   so 0 < ψ < φ < π.

**Coordinate setup.** Place M (midpoint of AB) at the origin with AB on the x‑ax
is: A = (−1, 0), B = (1, 0). We compute first on the unit circumcircle and then
rescale.

On the unit circumcircle put S (midpoint of arc ACB) at angle π/2, so S = (0, 1)
. Since S is the midpoint of arc ACB and C lies on this arc, A, B are symmetric
about the vertical axis; write
A = e^{i(π/2+φ)},   B = e^{i(π/2−φ)},   C = e^{i(π/2−ψ)}
(C lies on arc SB because β > α). Then M = (A+B)/2 = i cos φ and B − A = 2 sin φ
 (real), so AB is horizontal of length 2 sin φ. Rescaling by 1/sin φ and transla
ting by −i cos φ sends A ↦ (−1,0), B ↦ (1,0).

**Incenter.** The side lengths (chords) are a = |BC| = 2 sin((φ−ψ)/2), b = |CA|
= 2 sin((φ+ψ)/2), c = |AB| = 2 sin φ. The incenter is I = (aA + bB + cC)/(a+b+c)
. Grouping real and imaginary parts (product‑to‑sum) gives, on the unit circle,
I = i(2 cos(φ/2) e^{−iψ/2} − 1).
After rescaling this becomes
I = ( sin(ψ/2)/sin(φ/2),  (cos(ψ/2) − cos(φ/2))/sin(φ/2) ).   (1)

**Circumcircle and S.** The center is (0, −cot φ) and the radius is csc φ, hence
x² + y² + 2y cot φ = 1,   (2)
and S = (0, tan(φ/2)).

**Finding T and D.** Put P = cos(φ/2), Q = cos(ψ/2), s = sin(φ/2), Δ = 1 − 2PQ +
 P². Parametrize line SI by (x, y) = S + t(I − S). Substituting in (2) and using
 t = 0 (point S) as one root, the other root is
t_T = (1 − PQ)/Δ.   (3)
(Here one uses s + cot φ = csc φ and I_y − S_y = −2(1−PQ)/sin φ, together with I
_x² + (I_y−S_y)² = Δ/(s²P²).)

Since D = 2T − I, from (1) and (3):
D_x = I_x(2t_T − 1) = I_x·(1 − P²)/Δ = I_x·s²/Δ = s·sin(ψ/2)/Δ,
D_y = 2S_y − I_y + 2t_T(I_y − S_y) = s(P − Q)/Δ,   (4)
where the second line follows from the identity (2 − P² − PQ)Δ − 2(1 − PQ)² = s²
P(P − Q).

**Finding E.** By definition E is the intersection of line IM (the line through
the origin and I, i.e. the points λI) with the horizontal line y = D_y (through
D, parallel to AB). Thus E = λI with λ = D_y/I_y. From (1), I_y = (Q − P)/s = −(
P − Q)/s, so by (4)
λ = D_y/I_y = [s(P − Q)/Δ] / [−(P − Q)/s] = −s²/Δ.
Hence
E_x = λ I_x = −s²/Δ · sin(ψ/2)/s = −s·sin(ψ/2)/Δ = −D_x,   and   E_y = D_y.   (5
)

**Conclusion.** Equation (5) says E = (−D_x, D_y), i.e. E is the reflection of D
 across the y‑axis — the perpendicular bisector of AB. This reflection swaps A =
 (−1, 0) and B = (1, 0) and sends D to E, so it carries segment BD to segment AE
 while preserving length. Therefore
AE = BD.   ▯
