**Clarifying the condition:** "None of the numbers has a sum of digits not divis
ible by 5" — as a competition problem, this asks for the longest run of consecut
ive integers where **no number has digit sum divisible by 5** (i.e., every digit
 sum is *not* divisible by 5). Under the literal double-negation reading (all di
git sums divisible by 5), no two consecutive integers in [1,1000] can satisfy th
is (requires ≥4 trailing 9s, impossible below 9999), making the problem trivial.
 The competition-intended reading is: **no term has digit sum ≡ 0 (mod 5)**.

## Proof

**Digit sum behavior under increment.** Let $s(n)$ denote the digit sum of $n$.
If $n$ ends in exactly $k$ nines, then $s(n+1) = s(n) + 1 - 9k$, so modulo 5:
$$s(n+1) \equiv s(n) + 1 - 4k \pmod{5}.$$
The "extra shift" beyond the normal $+1$ is $-4k \bmod 5$, i.e., $0, 1, 2, 3$ fo
r $k = 0, 1, 2, 3$.

**Within a decade.** Consider a decade $XY0$–$XY9$ (hundreds digit $X$, tens dig
it $Y$). The starting phase is $a = (X+Y) \bmod 5$. The ten digit sums mod 5 are
:
$$a,\; a{+}1,\; a{+}2,\; a{+}3,\; a{+}4,\; a,\; a{+}1,\; a{+}2,\; a{+}3,\; a{+}4
 \pmod{5}.$$
The residue $0$ appears at positions $p$ and $p+5$ where $p = (-a) \bmod 5$. So
within each decade, $0$ appears exactly twice, with gap $5$ between them.

**Between decades.** The carry at $XY9 \to X(Y{+}1)0$ shifts the phase by $+2$ i
nstead of $+1$. The gap between the second $0$ of decade $Y$ and the first $0$ o
f decade $Y+1$ is:
$$5 + p_{Y+1} - p_Y \pmod{\text{actual}}, \quad \text{where } p_Y = (-X{-}Y) \bm
od 5.$$
- If $p_Y = 0$ (i.e., $X+Y \equiv 0 \pmod{5}$): $p_{Y+1} = 4$, gap $= 9$.
- If $p_Y \geq 1$: $p_{Y+1} = p_Y - 1$, gap $= 4$.

A gap of $9$ means **$8$ consecutive integers** with no digit sum $\equiv 0 \pmo
d 5$. A gap of $4$ means only $3$.

**Between centuries.** The double carry at $X99 \to (X{+}1)00$ shifts the phase
by $+3$. Computing the inter-century gap:
- Gap $= 8$ (run of $7$) when $X \equiv 0$ or $1 \pmod{5}$.
- Gap $= 3$ (run of $2$) otherwise.

Since $7 < 8$, **century boundaries never produce runs longer than $8$**.

**Triple carry at 999.** The last $0$ before $999$ is at $997$ ($s(997)=25\equiv
 0$). After it: $s(998)=26\equiv 1$, $s(999)=27\equiv 2$, $s(1000)=1\equiv 1$. T
he run is only $3$ numbers (cut off at $1000$). No improvement.

**Boundary at 1.** The first $0$ is at $5$ ($s(5)=5\equiv 0$). The run $1$–$4$ h
as length $4 < 8$.

**Maximum run length is $8$**, arising only from the between-decade gap of $9$.

**Counting runs of length 8.** Each such run spans positions $10Y+6$ through $10
Y+13$ within century $X$, i.e., numbers $100X + 10Y + 6$ to $100X + 10Y + 13$, r
equiring:
$$X + Y \equiv 0 \pmod{5}, \quad 0 \leq X \leq 9, \quad 0 \leq Y \leq 8.$$

For each $X$, the valid $Y$ values in $\{0,\ldots,8\}$ with $Y \equiv -X \pmod{5

| $X \bmod 5$ | $(-X) \bmod 5$ | Valid $Y$ values | Count |
|---|---|---|---|
| $0$ | $0$ | $\{0, 5\}$ | $2$ |
| $1$ | $4$ | $\{4\}$ ($9>8$ excluded) | $1$ |
| $2$ | $3$ | $\{3, 8\}$ | $2$ |
| $3$ | $2$ | $\{2, 7\}$ | $2$ |
| $4$ | $1$ | $\{1, 6\}$ | $2$ |

Over $X = 0, 1, \ldots, 9$ (each residue class appears twice):

$$\text{Total} = \underbrace{2+2}_{X\equiv 0} + \underbrace{1+1}_{X\equiv 1} + \
underbrace{2+2}_{X\equiv 2} + \underbrace{2+2}_{X\equiv 3} + \underbrace{2+2}_{X
\equiv 4} = 4 + 2 + 4 + 4 + 4 = \boxed{18}.$$
