# 解答

我们将 $n \times n$ 棋盘建模为网格图 $G_n$，其顶点为 $\{(i,j): 1 \le i,j \le n\}
$，边连接共享一条边的方块。一个“顽皮”子集恰好是一个**反馈顶点集 (FVS)**：即一个
顶点集合，移除后剩余图为无环图（森林）。

## 下界：$C \geq \frac{1}{3}$ 是必要的

$G_n$ 有 $n^2$ 个顶点，$m = 2n(n-1)$ 条边，且是连通的。设 $X$ 是一个大小为 $\tau
$ 的顽皮子集。移除 $X$ 后，剩余部分是一个有 $n^2 - \tau$ 个顶点的森林，最多有 $n
^2 - \tau - 1$ 条边。每个顶点的度数最多为 4，因此移除 $\tau$ 个顶点最多移除 $4\t
au$ 条边：

$$2n(n-1) - 4\tau \le n^2 - \tau - 1 \implies (n-1)^2 \le 3\tau \implies \tau \g
e \frac{(n-1)^2}{3}.$$

对于任意 $C < \frac{1}{3}$，选择足够大的 $n$，使得 $\frac{(n-1)^2}{3} > Cn^2$（
因为 $\frac{(n-1)^2}{n^2} \to 1 > 3C$）。此时不存在大小 $\le Cn^2$ 的顽皮子集，
因此 $C < \frac{1}{3}$ 是不成立的。

## 上界：$C = \frac{1}{3}$ 是充分的

对于 $r \in \{0,1,2\}$，令 $X_r = \{(i,j) : 1 \le i,j \le n,\ i+j \equiv r \pmod
{3}\}$。

**断言 1：$G_n - X_r$ 是一个森林。**

剩余顶点满足 $i+j \equiv r+1$ 或 $r+2 \pmod{3}$。

- 满足 $i+j \equiv r+1$ 的顶点，其剩余邻居仅在“递增”方向：$(i+1,j)$ 和 $(i,j+1)$
（均为 $r+2$），因为“递减”邻居 $(i-1,j)$ 和 $(i,j-1)$（为 $r$）已被移除。
- 满足 $i+j \equiv r+2$ 的顶点，其剩余邻居仅在“递减”方向：$(i-1,j)$ 和 $(i,j-1)$
（均为 $r+1$）。

因此 $G_n - X_r$ 中的每个顶点度数最多为 2，所以它是由路径和环组成的并集。我们证
明不存在环。

在任意环中，顶点在 $r+1$ 和 $r+2$ 残差之间交替。考虑 $\phi(i,j) = i+j$。从 $r+1$
 顶点出发的边使 $\phi$ 增加 1；从 $r+2$ 顶点出发的边使 $\phi$ 减少 1。两步非回溯
移动从残差 $r+1$ 的顶点 $(i,j)$ 到达 $(i+1, j-1)$ 或 $(i-1, j+1)$，两者都保持了
$\phi$。因此，环中所有的 $r+1$ 顶点共享相同的 $\phi$ 值，位于同一条反对角线上。
两步移动使 $i$ 改变 $\pm 1$，形成了一维行走。非回溯的一维行走是单调的，无法回到
起点——这与环的存在相矛盾。

**断言 2：对于每个 $n$，存在某个 $r$ 使得 $|X_r| \le \frac{n^2}{3}$。**

记 $n = 3q + s$，$s \in \{0,1,2\}$。计算 $|X_r|$：

- **$n = 3q$**：对于所有 $r$，$|X_r| = 3q^2 = \frac{n^2}{3}$。 ✓
- **$n = 3q+1$**：$|X_0| = |X_2| = 3q^2 + 2q \le 3q^2 + 2q + \frac{1}{3} = \frac
{n^2}{3}$。 ✓
- **$n = 3q+2$**：$|X_1| = |X_2| = 3q^2 + 4q + 1 \le 3q^2 + 4q + \frac{4}{3} = \
frac{n^2}{3}$。 ✓

因此，对于每个 $n \ge 2$，我们选择一个合适的 $r$，得到一个大小 $\le \frac{n^2}{3
}$ 的顽皮子集。

## 结论

下界要求 $C \ge \frac{1}{3}$；构造表明 $C = \frac{1}{3}$ 对所有 $n \ge 2$ 都成立
。由于任何 $C \ge \frac{1}{3}$ 都平凡成立，所有有效的 $C$ 的集合为：

$$\boxed{\left[\tfrac{1}{3},\, \infty\right)}$$
