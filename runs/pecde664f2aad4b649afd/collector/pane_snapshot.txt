## 解答

**对问题的解释：** 原文表述“$(X^2+1)^{6n+2}+X^4+1$ 整除 $X^2+X+1$”在 $n \geq 0$
时会导致度数矛盾（被除数的度数为 $12n+4 \geq 4 > 2$）。唯一有意义的解释——也是该
问题作为竞赛题的标准解读——是求所有自然数 $n$，使得 $X^2+X+1$ 整除 $(X^2+1)^{6n+2
}+X^4+1$。我们将在此解释下进行求解。

**答案：所有自然数 $n$。**

---

**证明。**

设 $\omega = e^{2\pi i/3}$ 为本原单位立方根，因此 $\omega^3 = 1$ 且 $1 + \omega
+ \omega^2 = 0$。

多项式 $X^2+X+1$ 的根为 $\omega$ 和 $\omega^2$。由于 $f(X) = (X^2+1)^{6n+2}+X^4+
1$ 具有整系数（因此为实系数），我们有 $f(\omega) = 0 \iff f(\overline{\omega}) =
 f(\omega^2) = 0$。因此：

$$X^2+X+1 \mid f(X) \iff f(\omega) = 0.$$

在 $X = \omega$ 处计算 $f$：

$$f(\omega) = (\omega^2+1)^{6n+2} + \omega^4 + 1.$$

**化简每一项。** 由 $1+\omega+\omega^2 = 0$，我们得到 $\omega^2 + 1 = -\omega$。
由 $\omega^3 = 1$，我们得到 $\omega^4 = \omega \cdot \omega^3 = \omega$。代入：

$$f(\omega) = (-\omega)^{6n+2} + \omega + 1.$$

由于 $6n+2$ 始终为偶数，$(-1)^{6n+2} = 1$，因此：

$$(-\omega)^{6n+2} = (-1)^{6n+2}\,\omega^{6n+2} = \omega^{6n+2}.$$

利用 $\omega^3 = 1$ 进行化简：

$$\omega^{6n+2} = (\omega^3)^{2n}\cdot \omega^2 = 1^{2n}\cdot \omega^2 = \omega^
2.$$

因此：

$$f(\omega) = \omega^2 + \omega + 1 = 0,$$

其中最后一步使用了定义关系 $1 + \omega + \omega^2 = 0$。

**结论。** 对于**每一个**自然数 $n$，都有 $f(\omega) = 0$，从而 $f(\omega^2) = 0
$，因此

$$X^2+X+1 \mid (X^2+1)^{6n+2}+X^4+1 \quad \text{对所有 } n \in \mathbb{N} \text{
 成立}.$$

**数值验证。**
- $n=0$: $f = (X^2+1)^2+X^4+1 = 2(X^4+X^2+1) = 2(X^2+X+1)(X^2-X+1)$. ✓
- $n=1$: $f(\omega) = (-\omega)^8+\omega+1 = \omega^8+\omega+1 = \omega^2+\omega
+1 = 0$. ✓

所有自然数 $n$ 均满足该条件。$\blacksquare$
