# Problem

The encryption follows a strict protocol where:
1. Each unique letter in the three words represents a distinct decimal digit (0 through 9).
2. The leading letters of each code (**M**, **W**, and **G**) cannot represent the digit zero.
3. The sum of the numerical values of the four-digit packets must exactly equal the numerical value of the five-digit security key: $\text{MATH} + \text{WITH} = \text{GIRLS}$.

Based on these encryption protocols, compute the smallest possible numerical value for the security key **GIRLS**.
