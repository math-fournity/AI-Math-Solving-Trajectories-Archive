Looking at this problem, I need to determine whether there exists a sequence $(a
_n)$ such that $P_j(x) = \sum_{n=0}^j a_n x^n$ has no root of multiplicity great
er than 1 for any natural number $j$.

**Answer: Yes, such a sequence exists.**

**Proof.**

We construct the sequence $(a_n)$ inductively over $\mathbb{R}$ (or any infinite
 field of characteristic $0$).

**Base case.** Set $a_0 = 1$. Then $P_0(x) = 1$ has no roots, hence no repeated
roots.

**Inductive step.** Suppose $a_0, a_1, \dots, a_{j-1}$ have been chosen (with $a
_0 \neq 0$) so that $P_0, P_1, \dots, P_{j-1}$ each have no repeated roots. We s
how that only finitely many values of $a_j$ are "bad" (i.e., cause $P_j$ to acqu
ire a repeated root), so a good choice always exists.

Recall $P_j(x) = P_{j-1}(x) + a_j x^j$. A number $\alpha$ is a repeated root of
$P_j$ if and only if:
$$P_{j-1}(\alpha) + a_j \alpha^j = 0 \quad \text{and} \quad P_{j-1}'(\alpha) + j
\, a_j\, \alpha^{j-1} = 0.$$

**Case $\alpha = 0$:** Then $P_j(0) = a_0 = 0$ is required, but $a_0 = 1 \neq 0$
, so $\alpha = 0$ is never a repeated root.

**Case $\alpha \neq 0$:** From the first equation, $a_j = -P_{j-1}(\alpha)/\alph
a^j$. Substituting into the second:
$$P_{j-1}'(\alpha) - j\,\frac{P_{j-1}(\alpha)}{\alpha} = 0 \iff \alpha\, P_{j-1}
'(\alpha) - j\, P_{j-1}(\alpha) = 0.$$

Define the polynomial
$$Q_j(x) = x\, P_{j-1}'(x) - j\, P_{j-1}(x).$$

Computing its coefficients: since $P_{j-1}(x) = \sum_{n=0}^{j-1} a_n x^n$, we ge
t
$$Q_j(x) = \sum_{n=1}^{j-1} n\, a_n\, x^n - j \sum_{n=0}^{j-1} a_n\, x^n = -j\,
a_0 + \sum_{n=1}^{j-1}(n - j)\, a_n\, x^n.$$

This has degree at most $j - 1$. The constant term is $Q_j(0) = -j\, a_0 = -j \n
eq 0$ (since $a_0 = 1$ and $j \geq 1$), so:

1. $Q_j$ is **not** the zero polynomial (its constant term is nonzero).
2. $0$ is **not** a root of $Q_j$.

Therefore $Q_j$ has at most $j - 1$ distinct nonzero roots, say $\alpha_1, \dots
, \alpha_m$ with $m \leq j-1$. For each such root $\alpha_i$, the corresponding
bad value of $a_j$ is $-P_{j-1}(\alpha_i)/\alpha_i^j$.

The set of bad values $\left\{ -P_{j-1}(\alpha_i)/\alpha_i^j : i = 1, \dots, m \
right\}$ is **finite** (at most $j - 1$ elements). Since $\mathbb{R}$ is infinit
e, we can choose $a_j$ outside this finite set, ensuring $P_j$ has no repeated r
oots.

**Conclusion.** By induction, we can choose $a_0, a_1, a_2, \dots$ so that every
 $P_j$ has no root of multiplicity greater than $1$. $\blacksquare$
