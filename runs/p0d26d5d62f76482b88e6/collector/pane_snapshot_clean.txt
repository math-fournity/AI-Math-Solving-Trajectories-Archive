## Setting Up the Framework

**Key Reformulation.** A $3 \times n$ continuous arithmetic table has 3 rows (ea
ch a permutation of $\{1, \dots, n\}$) and $n$ columns, where each column's 3 en
tries form a 3-term arithmetic progression with $d > 0$ (hence distinct terms).

Since each row is a permutation, each value $v \in \{1,\dots,n\}$ appears exactl
y 3 times (once per row), in 3 distinct columns. Each column has 3 distinct valu
es forming an AP. So we need:

> **A collection of $n$ triples (3-term APs from $\{1,\dots,n\}$, with repetitio
n allowed) such that each value appears in exactly 3 triples.**

This is a 3-regular 3-uniform hypergraph with AP edges (automatically $n$ edges
since $3n/3 = n$).

**Row assignment is always possible.** Given such a collection, form the biparti
te graph (values vs. columns) where $v \sim c$ if $v$ appears in column $c$. Thi
s graph is 3-regular and bipartite. By **König's edge-coloring theorem**, it adm
its a proper 3-edge-coloring. Assigning color $i$ to edge $(v,c)$ places value $
v$ in row $i$ of column $c$. Each value gets 3 distinct colors (appears once per
 row), each column gets 3 distinct colors (one value per row). So each row is a
permutation. ✓

Thus the problem reduces entirely to the **existence of the AP triple collection
**.
