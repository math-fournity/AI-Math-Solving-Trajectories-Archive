# Problem

In the digital archives of the Galactic Library, a security sequence is generated based on the "permutation-sum" of a specific access code. To generate this sequence, technicians take an initial positive integer (written in standard base-10) and identify every unique number that can be formed by rearranging its digits. These resulting numbers are then added together to produce a final security total.

For instance, if the initial code were 110, the unique permutations would be 110, 101, and 011 (treated as 11), yielding a security total of $110 + 101 + 11 = 222$.

A high-clearance vault has been locked with a security total of 4,933,284. To unlock the vault, you must identify the original code used to generate this sum. If multiple codes could produce this total, the security protocol requires the smallest possible starting number.

What is the smallest positive integer whose unique digit permutations sum to 4,933,284?
