# Solution

## Setup

Let $\omega$ be a primitive $2013$th root of unity, where $2013 = 3 \cdot 11 \cd
ot 61$ (squarefree). Define $S(a) = 1 + \omega + \cdots + \omega^a = \frac{1 - \
omega^{a+1}}{1 - \omega}$.

**Key observation:** Since $2013$ has three distinct prime factors, $\Phi_{2013}
(1) = 1$, so $N(1-\omega) = 1$, meaning $1 - \omega$ is a **unit** in $\mathbb{Z
}[\omega]$. Thus $v_P(S(a)) = v_P(1 - \omega^{a+1})$ for every prime ideal $P$.

## When is $S(a) = 0$?

$S(a) = 0 \iff \omega^{a+1} = 1 \iff 2013 \mid (a+1)$. Since $a+1 \in \{2, \ldot
s, 2014\}$, this gives $a = 2012$ only. For $a = 2012$, $S(a)S(b)/3 = 0$ is triv
ially an algebraic integer for all $b$.

## Prime factorization of $3$ in $\mathbb{Z}[\omega]$

Since $3 \mid 2013$ and $2013 = 3 \cdot 671$ with $\gcd(3, 671) = 1$:

- In $\mathbb{Q}(\zeta_{671})$, the prime $3$ splits into $\varphi(671)/\text{or
d}_{671}(3)$ primes. Computing: $\text{ord}_{11}(3) = 5$, $\text{ord}_{61}(3) =
10$ (since $3^5 \equiv -1 \pmod{61}$), so $\text{ord}_{671}(3) = \text{lcm}(5,10
) = 10$. This gives $600/10 = 60$ primes, each with residue degree $10$.

- In $\mathbb{Q}(\zeta_{2013})/\mathbb{Q}(\zeta_{671})$ (degree $2$, totally ram
ified at primes above $3$): each of the $60$ primes ramifies with index $e = 2$.

So $(3) = \prod_{i=1}^{60} P_i^2$ in $\mathbb{Z}[\omega]$, giving $v_{P_i}(3) =
2$ for each of the $60$ primes above $3$.

For primes above $11$ or $61$: $v_P(3) = 0$ (since $\gcd(3, 11) = \gcd(3, 61) =
1$), so the divisibility condition is automatic there. **Only primes above $3$ m
atter.**

## Computing $v_{P_i}(S(a))$ for primes $P_i$ above $3$

In the residue field $\mathbb{Z}[\omega]/P_i$ (characteristic $3$, size $3^{10}$
): since $3 \mid 2013$, we get $\omega^{671} \equiv 1 \pmod{P_i}$ (as $x^3 - 1 =
 (x-1)^3$ in char $3$). The order of $\omega \bmod P_i$ is exactly $671$ (verifi
ed: $671 \mid 3^{10} - 1 = 59048 = 671 \times 88$, and $\text{ord}_{671}(3) = 10
$ matches the residue degree).

Therefore $v_{P_i}(1 - \omega^{a+1}) > 0 \iff \omega^{a+1} \equiv 1 \pmod{P_i} \
iff 671 \mid (a+1)$.

The multiples of $671$ in $\{2, \ldots, 2014\}$ are $671, 1342, 2013$, giving $a
 \in \{670, 1341, 2012\}$.

- $a = 2012$: $S(a) = 0$ (already handled).
- $a = 670$: $\omega^{a+1} = \omega^{671} = \zeta_3$, so $1 - \omega^{a+1} = 1 -
 \zeta_3$.
- $a = 1341$: $\omega^{a+1} = \omega^{1342} = \zeta_3^2$, so $1 - \omega^{a+1} =
 1 - \zeta_3^2$.

**Valuation computation:** In $\mathbb{Q}(\zeta_3)$, $(1-\zeta_3)$ is the unique
 prime above $3$ with ramification index $2$ over $\mathbb{Q}$. In $\mathbb{Q}(\
zeta_{2013})$, each $P_i$ has ramification index $2$ over $\mathbb{Q}$, so the r
amification index of $P_i$ over $(1-\zeta_3)$ is $2/2 = 1$. Since all $60$ prime
s lie above the unique prime $(1-\zeta_3)$ of $\mathbb{Q}(\zeta_3)$:

$$(1 - \zeta_3) = \prod_{i=1}^{60} P_i \quad \text{in } \mathbb{Z}[\zeta_{2013}]
$$

confirming $v_{P_i}(S(a)) = 1$ for all $60$ primes when $a \in \{670, 1341\}$.

**Norm check:** $N(S(670)) = \Phi_3(1)^{1200/\varphi(3)} = 3^{600}$, and $\prod_
{i} N(P_i)^{v_{P_i}} = \prod_{i=1}^{60} 3^{10 \cdot 1} = 3^{600}$. ✓

For all other $a \neq 2012$ (i.e., $671 \nmid (a+1)$): $v_{P_i}(S(a)) = 0$ for a
ll $P_i \mid 3$.

## Counting valid pairs

We need $v_{P_i}(S(a)) + v_{P_i}(S(b)) \geq 2$ for all $60$ primes $P_i$ above $
3$. Since all $P_i$ share the same valuations, this reduces to a single conditio
n:

| Case | Condition | Count |
|------|-----------|-------|
| $a = 2012$ | $S(a) = 0$, always OK | $2013$ pairs |
| $b = 2012$ | $S(b) = 0$, always OK | $2013$ pairs |
| (overlap) | $(2012, 2012)$ | subtract $1$ |
| $a \in \{670, 1341\}$, $b \in \{670, 1341\}$ | $v_P + v_P = 1 + 1 = 2 \geq 2$
✓ | $2 \times 2 = 4$ pairs |

All other pairs give $v_P(S(a)) + v_P(S(b)) \in \{0, 1\} < 2$, failing the condi
tion.

**Total:** $(2013 + 2013 - 1) + 4 = 4025 + 4 = \boxed{4029}$.
