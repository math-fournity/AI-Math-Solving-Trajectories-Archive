## Green's Function for the General Third-Order Linear ODE

### Setup

Let $L = D^3 + a_2 D^2 + a_1 D + a_0$ with characteristic polynomial
$$P(z) = z^3 + a_2 z^2 + a_1 z + a_0 = (z - r_1)(z - r_2)(z - r_3),$$
where $r_1, r_2, r_3$ are the (distinct) roots. The Green's function satisfies
$$L\,G(x,x') = \delta(x - x'),$$
with initial conditions $G(0,x') = G_x(0,x') = G_{xx}(0,x') = 0$.

### Step 1: Solution for $x \neq x'$

For $x \neq x'$, the equation is homogeneous: $LG = 0$. The general solution is
$$G(x,x') = \sum_{i=1}^{3} c_i\, e^{r_i x}.$$

Since all three initial conditions at $x = 0$ are zero, the solution in the regi
on $x < x'$ (which includes $x = 0$ for any $x' > 0$) with zero initial data is
identically:
$$G(x,x') = 0, \qquad x < x'.$$

For $x > x'$, we write
$$G(x,x') = \sum_{i=1}^{3} A_i(x')\, e^{r_i x}.$$

### Step 2: Matching Conditions at $x = x'$

Integrating $LG = \delta(x - x')$ across an infinitesimal interval around $x = x
'$, only the highest-derivative term survives:
$$G''(x'^+,x') - G''(x'^-,x') = 1.$$
The lower-order terms integrate to zero as the interval shrinks (since $G$, $G'$
 remain bounded). Continuity of $G$ and $G'$ gives:
$$G(x'^+,x') = G(x'^-,x') = 0, \qquad G'(x'^+,x') = G'(x'^-,x') = 0.$$

Setting $B_i = A_i\, e^{r_i x'}$, the three conditions at $x = x'^+$ become:
$$\sum_{i=1}^{3} B_i = 0, \qquad \sum_{i=1}^{3} B_i\, r_i = 0, \qquad \sum_{i=1}
^{3} B_i\, r_i^2 = 1.$$

### Step 3: Solving the Vandermonde System

This is a Vandermonde system. The key identity (proved below) is:
$$\sum_{i=1}^{n} \frac{r_i^k}{P'(r_i)} = \begin{cases} 0 & k = 0, 1, \ldots, n-2
, \\ 1 & k = n-1, \end{cases}$$
where $P'(r_i) = \prod_{j \neq i}(r_i - r_j)$.

For $n = 3$, this gives exactly:
$$\sum_{i=1}^{3} \frac{1}{P'(r_i)} = 0, \quad \sum_{i=1}^{3} \frac{r_i}{P'(r_i)}
 = 0, \quad \sum_{i=1}^{3} \frac{r_i^2}{P'(r_i)} = 1.$$

Comparing with our system, the unique solution is:
$$B_i = \frac{1}{P'(r_i)} = \frac{1}{(r_i - r_j)(r_i - r_k)},$$
where $\{j,k\} = \{1,2,3\}\setminus\{i\}$.

**Proof of the identity:** From the partial fraction decomposition of $z^k / P(z
)$:
$$\frac{z^k}{P(z)} = \sum_{i=1}^{n} \frac{r_i^k}{P'(r_i)} \cdot \frac{1}{z - r_i
}.$$
For $k \leq n-2$, the rational function $z^k/P(z)$ has degree $\leq -2$ at infin
ity, so its Laurent expansion has no $1/z$ term; the sum of residues $\sum_i r_i
^k/P'(r_i)$ (which equals the $1/z$ coefficient) is $0$. For $k = n-1$, we have
$z^{n-1}/P(z) = 1/z + O(1/z^2)$, so the $1/z$ coefficient is $1$.

### Step 4: Assembling the Green's Function

Since $A_i = B_i\, e^{-r_i x'}$, the solution for $x > x'$ is:
$$G(x,x') = \sum_{i=1}^{3} \frac{e^{r_i(x - x')}}{P'(r_i)}.$$

Combining both regions using the Heaviside step function $\Theta$:

$$\boxed{G(x,x') = \Theta(x - x') \sum_{i=1}^{3} \frac{e^{r_i(x - x')}}{(r_i - r
_j)(r_i - r_k)}}$$

where for each $i$, $\{j,k\}$ is the complementary pair of indices, and equivale
ntly $P'(r_i) = (r_i - r_j)(r_i - r_k) = 3r_i^2 + 2a_2 r_i + a_1$.

### Verification

1. **Homogeneous equation for $x \neq x'$:** Each $e^{r_i x}$ is annihilated by
$L$ since $P(r_i) = 0$. ✓

2. **Jump condition:** $G''(x'^+) - G''(x'^-) = \sum_i r_i^2 / P'(r_i) - 0 = 1$.
 ✓

3. **Continuity of $G$ and $G'$:** $G(x'^+) = \sum_i 1/P'(r_i) = 0$ and $G'(x'^+
) = \sum_i r_i/P'(r_i) = 0$. ✓

4. **Boundary conditions at $x = 0$:** For any $x' > 0$, the point $x = 0$ lies
in the region $x < x'$ where $G \equiv 0$, so $G(0,x') = G'(0,x') = G''(0,x') =
0$. ✓
