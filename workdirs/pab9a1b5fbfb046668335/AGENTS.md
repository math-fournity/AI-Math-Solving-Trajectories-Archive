# Problem

In the futuristic city of Numeria, a master architect is designing high-capacity data storage modules. He is testing a specific efficiency coefficient, $P$, which is determined by the configuration of a primary server bank. This bank is defined by a central tuning integer, $n$, where $n$ is a natural number chosen from the range $1 \le n \le 120$.

The efficiency coefficient of a server bank is calculated by the following formula:
$P = (n^2-4)(n^2-1)(n^2+3)$

A server bank is considered "ultra-stable" only if its efficiency coefficient $P$ is perfectly divisible by the city’s power grid constant, which is exactly $2880$.

The architect needs to find every possible value of $n$ within the given range that results in an ultra-stable server bank. Calculate the sum of all such natural numbers $n$.
