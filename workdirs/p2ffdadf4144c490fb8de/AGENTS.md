# Problem

In a specialized laboratory, a robotic arm is tasked with programming a digital security code. The display starts completely blank. Each second, the robot randomly selects a single-digit chip from a bin containing nine distinct chips, labeled 1 through 9. Each chip has an equal 1/9 probability of being chosen. The robot installs the chosen chip at the end of the current sequence on the display, effectively forming a multi-digit integer that grows with every addition.

The robot is programmed to cease operation immediately once the integer displayed on the screen is a multiple of 25. Let $E$ represent the expected total number of chips installed by the robot when the process stops. Given that $E$ can be expressed as a fraction $m/n$ in simplest form (where $m$ and $n$ are relatively prime positive integers), calculate the value of $100m + n$.
