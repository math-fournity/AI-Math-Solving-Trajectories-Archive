# Solution

We use the generalized d'Alembert formula. For the inhomogeneous wave equation
$$u_{tt} - c^2 u_{xx} = f(x,t), \qquad u(x,0)=g(x),\quad u_t(x,0)=h(x),$$
the solution on $-\infty < x < \infty$ is
$$u(x,t) = \underbrace{\frac{g(x+ct)+g(x-ct)}{2} + \frac{1}{2c}\int_{x-ct}^{x+ct
} h(s)\,ds}_{\text{homogeneous part}} \;+\; \underbrace{\frac{1}{2c}\int_0^t\!\i
nt_{x-c(t-\tau)}^{x+c(t-\tau)} f(s,\tau)\,ds\,d\tau}_{\text{Duhamel forcing}}.$$

---

## Part (a)

**Data:** $f=1$, $g(x)=\sin bx$, $h(x)=0$.

**Homogeneous part.** Since $h=0$,
$$u_h = \tfrac{1}{2}\bigl[\sin b(x+ct)+\sin b(x-ct)\bigr].$$
Using $\sin A+\sin B = 2\sin\tfrac{A+B}{2}\cos\tfrac{A-B}{2}$,
$$u_h = \sin(bx)\cos(bct).$$

**Forcing part.**
$$u_p = \frac{1}{2c}\int_0^t\!\int_{x-c(t-\tau)}^{x+c(t-\tau)} 1\,ds\,d\tau = \f
rac{1}{2c}\int_0^t 2c(t-\tau)\,d\tau = \int_0^t (t-\tau)\,d\tau = \frac{t^2}{2}.
$$

**Solution:**
$$\boxed{\,u(x,t) = \sin(bx)\cos(bct) + \tfrac{t^2}{2}\,}$$

**Verification.**
- $u_{tt} = -b^2c^2\sin(bx)\cos(bct)+1$, $\;u_{xx}=-b^2\sin(bx)\cos(bct)$, so $u
_{tt}-c^2u_{xx}=1$. ✓
- $u(x,0)=\sin(bx)$, $\;u_t(x,0)=-bc\sin(bx)\sin 0 + 0 = 0$. ✓

---

## Part (b)

**Data:** $f(x,t)=4x+t$, $g(x)=0$, $h(x)=\cosh bx$.

**Homogeneous part.** Since $g=0$,
$$u_h = \frac{1}{2c}\int_{x-ct}^{x+ct}\cosh(bs)\,ds = \frac{1}{2bc}\bigl[\sinh b
(x+ct)-\sinh b(x-ct)\bigr].$$
Using $\sinh A-\sinh B = 2\cosh\tfrac{A+B}{2}\sinh\tfrac{A-B}{2}$,
$$u_h = \frac{1}{2bc}\cdot 2\cosh(bx)\sinh(bct) = \frac{1}{bc}\cosh(bx)\sinh(bct
).$$

**Forcing part.**
$$u_p = \frac{1}{2c}\int_0^t\!\int_{x-c(t-\tau)}^{x+c(t-\tau)}(4s+\tau)\,ds\,d\t
au.$$

Inner integral (with $a=x-c(t-\tau)$, $b_0=x+c(t-\tau)$, so $b_0-a=2c(t-\tau)$,
$b_0+a=2x$):
$$\int_a^{b_0}(4s+\tau)\,ds = \bigl[2s^2+\tau s\bigr]_a^{b_0} = 2(b_0^2-a^2)+\ta
u(b_0-a) = 2\cdot 4xc(t-\tau)+\tau\cdot 2c(t-\tau) = 2c(t-\tau)(4x+\tau).$$

Therefore
$$u_p = \frac{1}{2c}\int_0^t 2c(t-\tau)(4x+\tau)\,d\tau = \int_0^t (t-\tau)(4x+\
tau)\,d\tau.$$
Expanding and integrating:
$$\int_0^t\bigl[4xt+\tau(t-4x)-\tau^2\bigr]d\tau = 4xt^2+\tfrac{t^2}{2}(t-4x)-\t
frac{t^3}{3} = 2xt^2+\tfrac{t^3}{6}.$$

**Solution:**
$$\boxed{\,u(x,t) = \frac{1}{bc}\cosh(bx)\sinh(bct) + 2xt^2 + \frac{t^3}{6}\,}$$

**Verification.**
- $u_t = \cosh(bx)\cosh(bct)+4xt+\tfrac{t^2}{2}$,
- $u_{tt} = bc\cosh(bx)\sinh(bct)+4x+t$,
- $u_x = \tfrac{1}{c}\sinh(bx)\sinh(bct)+2t^2$,
- $u_{xx} = \tfrac{b}{c}\cosh(bx)\sinh(bct)$, so $c^2u_{xx}=bc\cosh(bx)\sinh(bct
)$,
- $u_{tt}-c^2u_{xx} = 4x+t$. ✓
- $u(x,0)=0$, $\;u_t(x,0)=\cosh(bx)$. ✓

Both solutions satisfy their respective PDEs and initial conditions.
