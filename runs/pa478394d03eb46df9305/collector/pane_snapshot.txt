## Proof

**Claim:** $d(n) = \sum_{q=1}^{\lceil n/2\rceil} R_q(n)$ equals $\tau(n)$, the n
umber of divisors of $n$.

**Setup.** Let $r(n) = v_2(2n)$, the 2-adic valuation of $2n$. Write $n = 2^a \c
dot m$ where $a \geq 0$ and $m$ is odd. Then $v_2(n) = a$, so
$$r(n) = v_2(2n) = v_2(n) + 1 = a + 1.$$

**Evaluating $R_q(n)$.** The term $R_q(n)$ is nonzero only when the odd number $
(2q-1)$ divides $n$. Since $2q-1$ is odd, $(2q-1) \mid n$ iff $(2q-1) \mid m$. W
hen this holds,
$$R_q(n) = r\!\left(\frac{n}{2q-1}\right) = v_2\!\left(\frac{n}{2q-1}\right) + 1
.$$
Since $2q-1$ is odd, dividing by it does not change the 2-adic valuation: $v_2\!
\left(\frac{n}{2q-1}\right) = v_2(n) = a$. Therefore
$$R_q(n) = a + 1 \quad \text{for every odd divisor } (2q-1) \text{ of } n, \qqua
d R_q(n) = 0 \text{ otherwise.}$$

**Summing.** Each odd divisor of $n$ (equivalently, each divisor of $m$) contrib
utes exactly $a+1$ to the sum:
$$d(n) = (a+1) \cdot \tau(m),$$
where $\tau(m)$ is the number of divisors of $m$.

**Range check.** We must confirm every odd divisor of $n$ appears as some $2q-1$
 with $1 \leq q \leq \lceil n/2 \rceil$, i.e., $2q-1 \in \{1, 3, \dots, 2\lceil
n/2\rceil - 1\}$.

- If $n$ is odd: $2\lceil n/2\rceil - 1 = n$, so the range covers all odd intege
rs up to $n$, including every odd divisor of $n$ (all $\leq n$). ✓
- If $n$ is even: $2\lceil n/2\rceil - 1 = n - 1$. Every odd divisor of $n$ divi
des $m \leq n/2 \leq n-1$ (for $n \geq 2$), so all are in range. ✓
- $n = 1$: range is $\{1\}$, odd divisor $1$ is covered. ✓

**Conclusion.** The number of divisors of $n = 2^a \cdot m$ is
$$\tau(n) = (a+1)\,\tau(m),$$
since each divisor of $n$ is $2^i \cdot d'$ with $0 \leq i \leq a$ and $d' \mid
m$. This is exactly $d(n)$. $\blacksquare$
