## Solution

**Setting up the congruence condition.** The fractional part $\{3^k/10^4\} = (3^
k \bmod 10000)/10000$, so the condition $\{3^l/10^4\} = \{3^m/10^4\} = \{3^n/10^
4\}$ is equivalent to
$$3^l \equiv 3^m \equiv 3^n \pmod{10000}.$$
Since $\gcd(3, 10000) = 1$, this reduces to $3^{l-n} \equiv 1 \pmod{10000}$ and
$3^{m-n} \equiv 1 \pmod{10000}$, i.e., both $l - n$ and $m - n$ are multiples of
 $\operatorname{ord}_{10000}(3)$.

**Computing $\operatorname{ord}_{10000}(3)$.** Factor $10000 = 16 \times 625$.

- **Mod 16:** $3^1=3,\; 3^2=9,\; 3^4 = 81 \equiv 1 \pmod{16}$, so $\operatorname
{ord}_{16}(3) = 4$.

- **Mod 625** ($\varphi(625)=500$): Compute by repeated squaring:
  - $3^{10} = 59049 \equiv 299 \pmod{625}$
  - $3^{20} \equiv 299^2 = 89401 \equiv 26 \pmod{625}$
  - $3^{40} \equiv 26^2 = 676 \equiv 51 \pmod{625}$
  - $3^{50} \equiv 51 \times 299 = 15249 \equiv 249 \pmod{625}$
  - $3^{100} \equiv 249^2 = 62001 \equiv 126 \pmod{625}$
  - $3^{200} \equiv 126^2 = 15876 \equiv 251 \pmod{625}$
  - $3^{250} \equiv 251 \times 249 = 62499 \equiv 624 \equiv -1 \pmod{625}$

  Since $3^{250} \equiv -1 \pmod{625}$, we get $3^{500} \equiv 1 \pmod{625}$, an
d the order is exactly $500$.

Therefore $\operatorname{ord}_{10000}(3) = \operatorname{lcm}(4, 500) = 500$.

**Parametrizing the sides.** Write $l - n = 500c$ and $m - n = 500d$ with intege
rs $c > d \geq 1$. Then
$$l = n + 500c,\quad m = n + 500d,\quad \text{perimeter} = 3n + 500(c + d).$$

**Triangle inequality.** The binding constraint is $m + n > l$:
$$n + 500d + n > n + 500c \implies n > 500(c - d).$$

**Minimizing the perimeter.** To minimize $3n + 500(c+d)$:
- Minimize $c + d$: the smallest value with $c > d \geq 1$ is $c = 2, d = 1$, gi
ving $c + d = 3$ and $c - d = 1$.
- Then $n > 500$, so $n \geq 501$.
- Minimum perimeter $= 3(501) + 500(3) = 1503 + 1500 = 3003$.

Any other choice ($d \geq 2$, or $c - d \geq 2$) increases $c + d$ or the lower
bound on $n$, yielding a larger perimeter.

**Verification.** With $(l, m, n) = (1501, 1001, 501)$:
- $3^{501} \equiv 3^{500}\cdot 3 \equiv 3$, $\;3^{1001} \equiv 3^{1000}\cdot 3 \
equiv 3$, $\;3^{1501} \equiv 3^{1500}\cdot 3 \equiv 3 \pmod{10000}$. ✓
- Triangle inequality: $1001 + 501 = 1502 > 1501$. ✓
- Perimeter $= 1501 + 1001 + 501 = 3003$.

The minimum perimeter is $\boxed{3003}$.
