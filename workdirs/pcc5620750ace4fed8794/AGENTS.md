# Problem

In a remote digital archipelago, a surveyor is mapping out rectangular regions of land partitioned into $a \times b$ identical square plots, where $a$ and $b$ are positive integers. In each region, every plot either contains a hidden seismic sensor or is a "safe zone." Each safe zone is assigned a "detection value" equal to the total number of seismic sensors located in its immediate vicinity (this includes all plots that share at least one edge or a corner with the safe zone).

A government agency is interested in specific types of "uniform regions." These are regions where exactly 2019 plots are safe zones, and every single one of those 2019 safe zones displays the exact same detection value, $k$.

Let $S$ be the set of all possible integers $k \in \{0, 1, 2, 3, 4, 5, 6, 7, 8\}$ for which there exists at least one pair of dimensions $(a, b)$ and at least one configuration of seismic sensors that satisfies the agency's uniform region criteria.

Calculate the sum of all elements contained in the set $S$.
