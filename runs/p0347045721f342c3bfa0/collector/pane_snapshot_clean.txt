## Solution

Let
$$A = \int_0^{\pi/2} (x\cos x + 1)\,e^{\sin x}\,dx, \qquad B = \int_0^{\pi/2} (x
\sin x - 1)\,e^{\cos x}\,dx.$$

**Computing A.** Observe that
$$\frac{d}{dx}\!\left[x\,e^{\sin x}\right] = e^{\sin x} + x\cos x\,e^{\sin x} =
(x\cos x + 1)\,e^{\sin x}.$$
Hence the integrand of $A$ is an exact derivative, so
$$A = \Big[x\,e^{\sin x}\Big]_0^{\pi/2} = \frac{\pi}{2}\,e^{\sin(\pi/2)} - 0 = \
frac{\pi}{2}\,e.$$

**Computing B.** Observe that
$$\frac{d}{dx}\!\left[x\,e^{\cos x}\right] = e^{\cos x} + x(-\sin x)\,e^{\cos x}
 = (1 - x\sin x)\,e^{\cos x} = -(x\sin x - 1)\,e^{\cos x}.$$
Thus the integrand of $B$ is $-\frac{d}{dx}[x\,e^{\cos x}]$, so
$$B = -\Big[x\,e^{\cos x}\Big]_0^{\pi/2} = -\left(\frac{\pi}{2}\,e^{\cos(\pi/2)}
 - 0\right) = -\frac{\pi}{2}\,e^{0} = -\frac{\pi}{2}.$$

**The ratio.**
$$\frac{A}{B} = \frac{\frac{\pi}{2}\,e}{-\frac{\pi}{2}} = -e,$$
and therefore
$$\left|\frac{A}{B}\right| = e.$$
