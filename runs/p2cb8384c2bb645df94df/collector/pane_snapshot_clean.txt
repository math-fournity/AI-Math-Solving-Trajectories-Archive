# Proof: The Base of the Logarithm is $e$

## Setup

The inequality
$$\omega(n) < \frac{\log n}{\log \log n} + 1.4573\,\frac{\log n}{(\log \log n)^2
}$$
is **Robin's bound** (1983) on $\omega(n)$, the number of distinct prime divisor
s of $n$. We determine the base by analyzing the asymptotic expansion of $\omega
(n)$ at its extremal values and matching the constant $1.4573$.

## Step 1: Extremal Case — Primorials

The maximum of $\omega(n)$ among integers of a given size is attained by **primo
rials** $n = p_k\# = \prod_{i=1}^{k} p_i$, for which $\omega(n) = k$ and
$$\log n = \sum_{i=1}^{k} \log p_i = \vartheta(p_k),$$
where $\vartheta$ is the first Chebyshev function.

## Step 2: Asymptotic Expansion (Natural Logarithm)

Using the Prime Number Theorem, $p_k = k(\log k + \log\log k - 1 + \frac{\log\lo
g k - 2}{\log k} + \cdots)$ and $\vartheta(p_k) = p_k + O(p_k\, e^{-c\sqrt{\log
p_k}})$, so with **natural logarithm** $\ln$:

$$\ln n = k\!\left(\ln k + \ln\ln k - 1 + \frac{\ln\ln k - 2}{\ln k} + \cdots\ri
ght).$$

Set $L = \ln n$, $\ell = \ln\ln n$. We invert to express $k$ in terms of $L, \el
l$. Writing $k = \frac{L}{\ell}\!\left(1 + \frac{a}{\ell} + \cdots\right)$ and s
ubstituting:

- $\ln k = \ell - \ln\ell + \frac{a}{\ell} + O(1/\ell^2)$,
- $\ln\ln k = \ln\ell - \frac{\ln\ell}{\ell} + O(1/\ell^2)$,

so $\ln k + \ln\ln k - 1 = \ell - 1 + \frac{a - \ln\ell}{\ell} + \cdots$, and $\
frac{\ln\ln k - 2}{\ln k} = \frac{\ln\ell - 2}{\ell} + \cdots$, giving

$$\ln n = k\!\left(\ell - 1 + \frac{a - 2}{\ell} + \cdots\right).$$

Solving: $k = \frac{L}{\ell - 1 + (a-2)/\ell + \cdots} = \frac{L}{\ell}\!\left(1
 + \frac{1}{\ell} + \cdots\right) = \frac{L}{\ell} + \frac{L}{\ell^2} + \cdots$.

Matching with $k = \frac{L}{\ell} + \frac{a\,L}{\ell^2} + \cdots$ yields **$a =
1$**. Thus:

$$\boxed{\omega(n) = \frac{\ln n}{\ln\ln n} + \frac{\ln n}{(\ln\ln n)^2} + O\!\l
eft(\frac{\ln n}{(\ln\ln n)^3}\right)}$$

The **asymptotic** second-order coefficient (natural log) is exactly **1**. Robi
n's constant $1.4573 > 1$ is the sharp **uniform** upper bound valid for all $n
\geq 3$, consistent with this asymptotic.

## Step 3: Base Dependence Rules Out All $b \neq e$

For a general base $b$, $\log_b n = \frac{\ln n}{\ln b}$ and $\log_b\log_b n = \
frac{\ln\ln n - \ln\ln b}{\ln b}$, so

$$\frac{\log_b n}{\log_b\log_b n} = \frac{\ln n}{\ln\ln n - \ln\ln b} = \frac{\l
n n}{\ln\ln n} + \frac{(\ln\ln b)\,\ln n}{(\ln\ln n)^2} + \cdots$$

The asymptotic second-order coefficient becomes $\ln\ln b$ (instead of $1$). For
 the inequality to hold with a **uniform** constant $C = 1.4573$ that exceeds th
e asymptotic coefficient by the margin Robin established, we need the asymptotic
 coefficient to be $1$:

$$\ln\ln b = 1 \implies \ln b = e \implies b = e^{e}.$$

Wait — this would suggest base $e^e$. But this conflates two different expansion
s. The correct interpretation: Robin's constant $1.4573$ was **derived and state
d** with natural logarithm. The expansion in Step 2 uses $\ln$ throughout and yi
elds asymptotic coefficient $1$; the uniform bound $1.4573$ is calibrated to thi
s. Changing the base rescales **both** the asymptotic coefficient **and** the un
iform constant by the same factor $\ln b$ in a coupled way, so the specific valu
e $1.4573$ is tied to the natural logarithm.

Concretely: if Robin's result in natural log is $\omega(n) < \frac{\ln n}{\ln\ln
 n} + 1.4573\frac{\ln n}{(\ln\ln n)^2}$, rewriting in base $b$ gives $\omega(n)
< \frac{\log_b n}{\log_b\log_b n + \log_b\ln b} + \cdots$, which does **not** re
tain the clean form $\frac{\log_b n}{\log_b\log_b n} + 1.4573\frac{\log_b n}{(\l
og_b\log_b n)^2}$. The form of the inequality as stated — with the **same** cons
tant $1.4573$ and the **same** structure — is preserved only under the natural l
ogarithm.

## Conclusion

The asymptotic expansion of $\omega(n)$ at primorials gives second-order coeffic
ient $1$ **exactly when the logarithm is natural** ($\ln$, base $e$), and Robin'
s uniform constant $1.4573$ is the sharp bound calibrated to this expansion. The
 inequality as written, with constant $1.4573$, is Robin's theorem stated in ter
ms of the **natural logarithm**.

$$\boxed{\text{The base of the logarithm is } e.}$$
