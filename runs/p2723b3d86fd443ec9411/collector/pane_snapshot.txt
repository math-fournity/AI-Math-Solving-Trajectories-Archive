## Proof

Let $T \colon \mathbb{R}^n \to \mathbb{R}^n$ be a continuous linear map and let
$E \subseteq \mathbb{R}^n$ be Lebesgue measurable. We show $T(E)$ is Lebesgue me
asurable by splitting into two cases according to whether $T$ is invertible.

### Case 1: $T$ is singular ($\det T = 0$)

If $T$ is singular, then $\ker T \neq \{0\}$, so $\operatorname{rank} T = k$ for
 some $k < n$. The image

$$T(\mathbb{R}^n) \subseteq \mathbb{R}^n$$

is a $k$-dimensional linear subspace with $k < n$. Any proper subspace of $\math
bb{R}^n$ has $n$-dimensional Lebesgue measure zero (it is contained in a hyperpl
ane, which has measure zero, and more generally any $k$-dimensional subspace wit
h $k<n$ is a countable union of translates of a coordinate $k$-plane, each of me
asure zero — equivalently, it has zero $n$-dimensional volume).

Since $E \subseteq \mathbb{R}^n$, we have

$$T(E) \subseteq T(\mathbb{R}^n),$$

and $T(\mathbb{R}^n)$ is a null set. **Lebesgue measure is complete**: every sub
set of a null set is Lebesgue measurable. Therefore $T(E)$ is Lebesgue measurabl
e (with measure $0$).

### Case 2: $T$ is invertible ($\det T \neq 0$)

When $T$ is invertible, it is a linear bijection of $\mathbb{R}^n$, hence a home
omorphism (all linear maps on finite-dimensional spaces are continuous, and so i
s $T^{-1}$). Moreover $T$ is **Lipschitz**: for some constant $L = \|T\|_{\text{
op}}$,

$$|T(x) - T(y)| \leq L\,|x - y| \quad \forall x, y \in \mathbb{R}^n.$$

We use two standard facts:

1. **Lipschitz maps send null sets to null sets.** If $N$ has measure zero and $
\varepsilon > 0$, cover $N$ by cubes $\{Q_j\}$ with $\sum_j |Q_j| < \varepsilon
/ L^n$. Then $T(N) \subseteq \bigcup_j T(Q_j)$, and each $T(Q_j)$ is contained i
n a cube of side at most $L$ times that of $Q_j$, so $\sum_j |T(Q_j)| \leq L^n \
sum_j |Q_j| < \varepsilon$. Hence $T(N)$ is null.

2. **Homeomorphisms preserve the Borel $\sigma$-algebra.** A homeomorphism maps
open sets to open sets, hence maps Borel sets to Borel sets.

Now write the measurable set $E$ in its standard decomposition. Since $E$ is Leb
esgue measurable, there exists a Borel set $B$ and a null set $N$ with

$$E = B \cup N, \qquad B \text{ Borel}, \quad N \text{ null}$$

(for instance, take $B$ to be a $G_\delta$ set with $E \subseteq B$ and $m(B \se
tminus E) = 0$, and set $N = E \setminus B$; then $E = B \cup (E \setminus B)$ w
here $E \setminus B \subseteq B \setminus E$ is null).

Applying $T$:

$$T(E) = T(B) \cup T(N).$$

- $T(B)$ is Borel, by fact 2 (since $T$ is a homeomorphism).
- $T(N)$ is null, by fact 1 (since $T$ is Lipschitz).

Thus $T(E)$ is the union of a Borel set and a null set, hence Lebesgue measurabl
e. $\qquad\blacksquare$

### Conclusion

In both cases — $T$ singular or $T$ invertible — the image $T(E)$ of a Lebesgue
measurable set $E$ under a continuous linear map $T \colon \mathbb{R}^n \to \mat
hbb{R}^n$ is Lebesgue measurable. The key ingredients are:

- **Singular case**: the image lies in a proper subspace (measure zero), and com
pleteness of Lebesgue measure makes every subset measurable.
- **Invertible case**: $T$ is a bi-Lipschitz homeomorphism, so it preserves both
 the Borel structure (homeomorphism) and null sets (Lipschitz), and measurabilit
y is exactly the combination of these two properties.
