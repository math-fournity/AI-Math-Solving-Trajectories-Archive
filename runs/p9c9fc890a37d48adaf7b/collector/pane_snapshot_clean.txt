## Proof

Let $\angle B = \beta$, so $\angle A = 2\beta$ and $\angle C = \pi - 3\beta$. Th
e condition $\angle C > 90°$ gives $\beta < 30°$, i.e., $\cos\beta > \cos 30° =
\tfrac{\sqrt{3}}{2}$.

**Parametrization.** By the law of sines, $a : b : c = \sin 2\beta : \sin\beta :
 \sin 3\beta$. Using
$$\frac{a}{b} = \frac{\sin 2\beta}{\sin\beta} = 2\cos\beta, \qquad \frac{c}{b} =
 \frac{\sin 3\beta}{\sin\beta} = 4\cos^2\beta - 1,$$
set $x = \cos\beta = \tfrac{a}{2b}$, so $a = 2bx$ and $c = b(4x^2-1) = \tfrac{a^
2-b^2}{b}$.

For $a, b, c$ to be positive integers we need:
- $a > b$ (so $c > 0$), i.e. $x > \tfrac{1}{2}$;
- $b \mid a^2$ (so $c = \tfrac{a^2-b^2}{b} \in \mathbb{Z}$);
- $a < 2b$ (so $\cos\beta < 1$, i.e. $\beta > 0$);
- $a^2 > 3b^2$ (so $\cos\beta > \tfrac{\sqrt3}{2}$, i.e. $\angle C > 90°$).

**Reduction to coprime form.** Write $a = gA,\ b = gB$ with $\gcd(A,B)=1$. The d
ivisibility $b \mid a^2$ becomes $B \mid g$. Setting $g = Bk$ ($k \in \mathbb{Z}
_{>0}$):
$$a = ABk,\qquad b = B^2 k,\qquad c = k(A^2 - B^2),$$
with $\gcd(A,B)=1$ and $A > B$. The remaining constraints become:
$$\sqrt{3}\,B < A < 2B \qquad\text{(equivalently } 3B^2 < A^2 < 4B^2\text{)}.$$

The perimeter is
$$P = a+b+c = k\bigl(AB + B^2 + A^2 - B^2\bigr) = kA(A+B).$$

**Minimization.** Take $k=1$ (any $k \geq 2$ only scales $P$ up). We seek the sm
allest $A(A+B)$ over coprime pairs $(A,B)$ with $\sqrt{3}\,B < A < 2B$.

| $B$ | Interval $(\sqrt3\,B,\ 2B)$ | Integer $A$ in interval, $\gcd(A,B)=1$ | $
A(A+B)$ |
|-----|------------------------------|------------------------------------------
|----------|
| 1 | $(1.732,\ 2)$ | none | — |
| 2 | $(3.464,\ 4)$ | none | — |
| 3 | $(5.196,\ 6)$ | none | — |
| 4 | $(6.928,\ 8)$ | $A=7$, $\gcd(7,4)=1$ ✓ | $7\cdot 11 = 77$ |
| 5 | $(8.660,\ 10)$ | $A=9$, $\gcd(9,5)=1$ | $9\cdot 14 = 126$ |
| $\geq 6$ | — | — | $> 77$ |

For $B\geq 5$ the minimal $A$ already gives $A(A+B) \geq 126 > 77$, and values o
nly grow. Hence the global minimum is attained at $(A,B,k) = (7,4,1)$.

**Verification.** This gives
$$a = 7\cdot 4 = 28,\quad b = 4^2 = 16,\quad c = 7^2 - 4^2 = 33.$$
- Triangle inequality: $28+16=44>33$, $28+33=61>16$, $16+33=49>28$ ✓.
- $\cos\beta = \tfrac{a}{2b} = \tfrac{28}{32} = \tfrac{7}{8} = 0.875 > \tfrac{\s
qrt3}{2}\approx 0.8660$ ✓, so $\angle C = 180°-3\beta > 90°$.
- $\cos\beta < 1$ ✓, so $\beta > 0$ and all angles are positive.
- $\angle A = 2\beta$, $\angle B = \beta$, $\angle A = 2\angle B$ ✓.
- $a^2 = 784 > 768 = 3b^2$ ✓ (equivalent to $\angle C > 90°$).

The perimeter is
$$P = 28 + 16 + 33 = \boxed{77}.$$
