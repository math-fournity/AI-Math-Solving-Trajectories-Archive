## 解答

**第一步：确定 A 的结构。**

集合 $A$ 包含 2024 个互不相同的非零复数，且在除法（$z_m/z_k \in A$）和乘法（$z_m
 z_k \in A$）下封闭。取 $z_k = z_m$ 可得 $1 \in A$。因此 $A$ 是 $\mathbb{C}^*$
的有限子群。$\mathbb{C}^*$ 的任何有限子群都是循环群，且由单位根构成。由于 $|A| =
 2024$，$A$ 恰好是 2024 次单位根群：

$$A = \{e^{2\pi i a/2024} : a = 0, 1, \dots, 2023\}.$$

**第二步：重写条件。**

令 $z_x = e^{2\pi i a/2024}$，$z_y = e^{2\pi i b/2024}$，其中 $a, b \in \{0, \do
ts, 2023\}$。条件为：

$$\operatorname{Re}(z_x + z_y) + \operatorname{Im}(z_x + z_y) > 0.$$

这等价于：

$$\left(\cos\tfrac{2\pi a}{2024} + \sin\tfrac{2\pi a}{2024}\right) + \left(\cos\
tfrac{2\pi b}{2024} + \sin\tfrac{2\pi b}{2024}\right) > 0.$$

定义 $g(a) = \sqrt{2}\sin\!\left(\tfrac{2\pi a}{2024} + \tfrac{\pi}{4}\right)$。
我们需要 $g(a) + g(b) > 0$。

**第三步：关键对称性。**

由于 $2024/2 = 1012$：

$$g(a + 1012) = \sqrt{2}\sin\!\left(\tfrac{2\pi a}{2024} + \pi + \tfrac{\pi}{4}\
right) = -g(a).$$

对 $(a, b) \mapsto (a+1012,\; b+1012) \pmod{2024}$ 的对合映射将和为正的配对与和
为负的配对进行了互换。设 $P$ = 和为正的配对数，$N$ = 和为负的配对数，$Z$ = 和为
零的配对数。则 $P = N$ 且 $P + N + Z = 2024^2$，因此：

$$|B| = P = \frac{2024^2 - Z}{2}.$$

**第四步：计算 $Z$。**

$g(a) + g(b) = 0 \iff g(b) = -g(a) = g(a + 1012 \bmod 2024)$。令 $c = a + 1012 \
bmod 2024$；当 $a$ 遍历 $\{0,\dots,2023\}$ 时，$c$ 也遍历该集合。因此：

$$Z = \sum_{c=0}^{2023} n(c), \quad \text{其中 } n(c) = \#\{b : g(b) = g(c)\}.$$

方程 $\sin\alpha = \sin\beta$（其中 $\alpha = \tfrac{2\pi b}{2024}+\tfrac{\pi}{4
}$，$\beta = \tfrac{2\pi c}{2024}+\tfrac{\pi}{4}$）有两个解族：

- **情况 1：** $\alpha = \beta + 2k\pi \Rightarrow b = c$（始终恰好有一个解在范
围内）。
- **情况 2：** $\alpha = \pi - \beta + 2k\pi \Rightarrow b = 506 - c + 2024k$（
恰好有一个解在范围内，即 $b = (506 - c) \bmod 2024$）。

当 $b = c$ 时，这两个解重合，即 $(506 - c) \equiv c \pmod{2024}$，亦即 $2c \equi
v 506 \pmod{2024}$，即 $c \equiv 253 \pmod{1012}$。因此 $c \in \{253, 1265\}$。

- 对于 $c \in \{253, 1265\}$：$n(c) = 1$（2 个值）。
- 对于所有其他 $c$：$n(c) = 2$（2022 个值）。

$$Z = 2 \times 1 + 2022 \times 2 = 2 + 4044 = 4046.$$

**第五步：最终计算。**

$$|B| = \frac{2024^2 - 4046}{2} = \frac{4096576 - 4046}{2} = \frac{4092530}{2} =
 2046265.$$

计算所有 64 个配对得到 $P = 25$。 ✓
