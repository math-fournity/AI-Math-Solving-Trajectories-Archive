**Answer:** N = 1 or 3 | N.

## Proof

**Definition.** f(n) = √n if n is a perfect square, f(n) = n + 3 otherwise.

**Key observation (squares mod 3).** A perfect square is congruent to 0 or 1 (mo
d 3). Moreover, if a square is ≡ 0 (mod 3), it is ≡ 0 (mod 9).

### Part 1: N ≡ 2 (mod 3) does NOT work.

If N ≡ 2 (mod 3), then N is not a perfect square (squares are 0 or 1 mod 3), so
f(N) = N + 3 ≡ 2 (mod 3). By induction, f^k(N) = N + 3k ≡ 2 (mod 3) for all k ≥
0. Since no number ≡ 2 (mod 3) is a perfect square, f^k(N) = N + 3k → ∞. The orb
it is not eventually periodic. ∎

### Part 2: N ≡ 0 (mod 3) works.

**The orbit stays in {multiples of 3}.** If v ≡ 0 (mod 3) and v is not a square,
 f(v) = v + 3 ≡ 0 (mod 3). If v ≡ 0 (mod 3) and v is a square, then v ≡ 0 (mod 9
), so v = 9m² and f(v) = 3m ≡ 0 (mod 3).

**From any v ≡ 0 (mod 3), non-square, we eventually hit a square.** We need v +
3k = 9m² for some k ≥ 0. Setting k = 3m² − v/3 (an integer since 3 | v), this is
 non-negative for m ≥ ⌈√(v/9)⌉, which exists.

**The value eventually decreases to the cycle {3, 6, 9}.** From v ≡ 0 (mod 3), n
on-square, let 9m² be the smallest square ≡ 0 (mod 9) with 9m² ≥ v. Since among
any three consecutive integers one is divisible by 3, we have 3m ≤ ⌈√v⌉ + 2 ≤ √v
 + 3. For v ≥ 36, this gives 3m < v. If v ≡ 0 (mod 3) is a square v = 9m² ≥ 36,
then f(v) = 3m = √v < v. So for v ≥ 36, the orbit value strictly decreases.

For v < 36 with v ≡ 0 (mod 3), direct verification shows all reach {3, 6, 9}:
- 3 → 6 → 9 → 3 (cycle of period 3).
- Every value in {12, 15, 18, 21, 24, 27, 30, 33} reaches 36 = 6² → 6 → 9 → 3, e
ntering the cycle.

Thus every N ≡ 0 (mod 3) eventually enters the cycle {3, 6, 9}, so {n : f^n(N) =
 3} is infinite. ∎

### Part 3: N = 1 works.

1 = 1² is a perfect square, so f(1) = 1. The orbit is 1, 1, 1, …, so {n : f^n(1)
 = 1} = ℕ is infinite. ∎

### Part 4: N ≡ 1 (mod 3), N > 1, does NOT work.

**The orbit visits only ≡ 1 and ≡ 2 (mod 3) values.** From v ≡ 1 (mod 3), non-sq
uare: f(v) = v + 3 ≡ 1 (mod 3). From v ≡ 1 (mod 3), square v = m²: since v ≡ 1 (
mod 3), m ≢ 0 (mod 3), so m ≡ 1 or 2 (mod 3), and f(v) = m.

Once the orbit reaches a value ≡ 2 (mod 3), it stays there and diverges to ∞ (by
 Part 1). So it suffices to show the orbit must eventually reach ≡ 2 (mod 3).

**Define a "phase" starting from v ≡ 1 (mod 3), v > 1:**
- If v is a square, v = m²: the phase yields m. If m ≡ 2 (mod 3), the orbit dive
rges. If m ≡ 1 (mod 3), the next phase starts at m.
- If v is not a square: the orbit goes v, v+3, v+6, … until reaching the smalles
t square s² ≡ 1 (mod 3) with s² ≥ v. The phase yields s. If s ≡ 2 (mod 3), the o
rbit diverges. If s ≡ 1 (mod 3), the next phase starts at s.

**The phase value strictly decreases.**
- If v = m² is a square with m ≡ 1 (mod 3), m > 1 (since v > 1), so m < m² = v.
- If v is not a square: among any three consecutive integers, at least two are n
ot divisible by 3, so among ⌈√v⌉, ⌈√v⌉+1, ⌈√v⌉+2, at least one squares to a valu
e ≡ 1 (mod 3). Thus s² ≤ (⌈√v⌉ + 2)² ≤ (√v + 3)², giving s ≤ √v + 3. For v ≥ 7 (
the smallest ≡ 1 mod 3 value greater than 4), we have √v + 3 < v (since v − √v −
 3 > 0 for v ≥ 7: at v = 7, 7 − 2.6… − 3 > 0). So s < v.

**The value 1 is unreachable.** Going up by 3 from any v > 1 never produces 1. T
aking √ of a square > 1 gives a value > 1. So the phase value is always ≥ 4 (the
 smallest integer ≡ 1 mod 3 that is > 1).

**Conclusion.** The phase value is a positive integer ≡ 1 (mod 3), at least 4, a
nd strictly decreasing at each phase. It cannot decrease indefinitely, so after
finitely many phases, the phase must yield a value ≡ 2 (mod 3) instead of ≡ 1 (m
od 3). At that point, the orbit diverges to ∞ and is not eventually periodic. ∎

### Summary

Combining all parts:
- **N ≡ 0 (mod 3):** orbit enters cycle {3, 6, 9} → works.
- **N = 1:** fixed point → works.
- **N ≡ 2 (mod 3):** orbit diverges → does not work.
- **N ≡ 1 (mod 3), N > 1:** orbit eventually reaches ≡ 2 (mod 3) and diverges →
does not work.

**The set of all N ∈ ℕ such that {n : f^n(N) = a} is infinite for some a ∈ ℕ is
exactly {1} ∪ {N ∈ ℕ : 3 | N}.**
