## Solution

We evaluate
$$I = \int_0^{\infty} \frac{x^7(1-x^{12})}{(1+x)^{28}}\,dx = \int_0^{\infty} \fr
ac{x^7}{(1+x)^{28}}\,dx - \int_0^{\infty} \frac{x^{19}}{(1+x)^{28}}\,dx.$$

**Convergence.** Near $x=0$, the integrand behaves like $x^7$ (first term) and $
x^{19}$ (second term), both integrable. Near $x=\infty$, the terms behave like $
x^{7-28}=x^{-21}$ and $x^{19-28}=x^{-9}$, both integrable. So $I$ converges abso
lutely.

**Symmetry argument.** Apply the substitution $x = 1/t$, so $dx = -t^{-2}\,dt$ a
nd the limits reverse ($x:0\to\infty$ becomes $t:\infty\to 0$):

$$I = \int_0^{\infty} \frac{t^{-7}\bigl(1-t^{-12}\bigr)}{(1+1/t)^{28}}\cdot\frac
{1}{t^2}\,dt = \int_0^{\infty} \frac{t^{-7}\bigl(1-t^{-12}\bigr)\cdot t^{28}}{(1
+t)^{28}}\cdot t^{-2}\,dt.$$

Combining powers of $t$: the exponent is $-7+28-2 = 19$, so

$$I = \int_0^{\infty} \frac{t^{19}\bigl(1-t^{-12}\bigr)}{(1+t)^{28}}\,dt = \int_
0^{\infty} \frac{t^{19}-t^{7}}{(1+t)^{28}}\,dt = -\int_0^{\infty}\frac{t^{7}-t^{
19}}{(1+t)^{28}}\,dt = -I.$$

Since $I = -I$, we conclude $I = 0$.

**Verification via the Beta function.** Using $\displaystyle\int_0^{\infty}\frac
{x^{a-1}}{(1+x)^{a+b}}\,dx = B(a,b) = \frac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}$:

- First term: $a-1=7 \Rightarrow a=8$, $a+b=28 \Rightarrow b=20$, giving $B(8,20
)$.
- Second term: $a-1=19 \Rightarrow a=20$, $a+b=28 \Rightarrow b=8$, giving $B(20
,8)$.

Since the Beta function is symmetric, $B(8,20)=B(20,8)$, so

$$I = B(8,20) - B(20,8) = 0.$$

Both methods agree.

$$\boxed{\displaystyle\int_0^{\infty} \frac{x^7(1-x^{12})}{(1+x)^{28}}\,dx = 0}$
$
