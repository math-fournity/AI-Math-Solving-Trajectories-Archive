## Solution

**Setup.** Let wise man $i$ start with $i$ coins ($i = 1, \dots, n$). Total coin
s initially: $S_0 = \frac{n(n+1)}{2}$. Each minute, exactly $n-1$ men receive 1
coin (one is "skipped"), so after $t$ minutes the total is
$$S_t = \frac{n(n+1)}{2} + t(n-1).$$

If all $n$ men have equal coins after $t$ minutes, each has $C = S_t / n$, requi
ring $n \mid S_t$.

**Divisibility.** Modulo $n$: $S_t \equiv \frac{n(n+1)}{2} + t(n-1) \pmod n$. Fo
r even $n$, $\frac{n(n+1)}{2} \equiv \frac{n}{2} \pmod n$ and $t(n-1) \equiv -t
\pmod n$, so
$$S_t \equiv \tfrac{n}{2} - t \pmod n.$$
Thus $t \equiv \frac{n}{2} \pmod n$, i.e. $t = \frac{n}{2} + nk$ for some intege
r $k \ge 0$.

**Determining the skips.** Let $s_i$ = number of minutes wise man $i$ is skipped
. Then $\sum s_i = t$ and his final count is $i + (t - s_i)$. Equality forces
$$s_i = i + t - C = i + t - \frac{S_t}{n} = i - \frac{n+1}{2} + \frac{t}{n}.$$
With $t = \frac{n}{2} + nk$ (so $\frac{t}{n} = \frac{1}{2} + k$) and $n$ even:
$$s_i = i - \frac{n}{2} + k.$$

**Non-negativity constraint.** Since $s_i \ge 0$ for all $i$, the binding case i
s $i = 1$:
$$s_1 = 1 - \tfrac{n}{2} + k \ge 0 \quad\Longrightarrow\quad k \ge \tfrac{n}{2}
- 1.$$

**Realizability.** Any non-negative integers $s_1, \dots, s_n$ with $\sum s_i =
t$ are realizable: simply assign each of the $t$ minutes to one of the $n$ men a
s the "skipped" one, with man $i$ skipped $s_i$ times. No further constraint exi
sts. At the minimal $k$, the $s_i$ form the consecutive values $0, 1, 2, \dots,
n-1$, which sum to $\frac{n(n-1)}{2} = \frac{n}{2} + n(\frac{n}{2}-1) = t$. ✓

**Minimum $t$.** Taking $k = \frac{n}{2} - 1$:
$$f(n) = \frac{n}{2} + n\!\left(\frac{n}{2} - 1\right) = \frac{n}{2} + \frac{n^2
}{2} - n = \frac{n^2 - n}{2} = \frac{n(n-1)}{2}.$$

**Verification for $n = 10$:** $f(10) = \frac{10 \cdot 9}{2} = 45$. Here $t = 45
$, $k = 4$, $s_i = i - 1$ giving $s = (0,1,\dots,9)$, sum $= 45 = t$. Final coin
s: $C = \frac{55 + 45 \cdot 9}{10} = \frac{460}{10} = 46$, and man $i$ has $i +
45 - (i-1) = 46$. ✓

**Verification for $n = 20$:** $f(20) = \frac{20 \cdot 19}{2} = 190$. Here $t =
190$, $k = 9$, $s_i = i - 1$ giving $s = (0,1,\dots,19)$, sum $= 190 = t$. Final
 coins: $C = \frac{210 + 190 \cdot 19}{20} = \frac{3820}{20} = 191$, and man $i$
 has $i + 190 - (i-1) = 191$. ✓

**Answer:**
$$f(10) + f(20) = 45 + 190 = \boxed{235}.$$
