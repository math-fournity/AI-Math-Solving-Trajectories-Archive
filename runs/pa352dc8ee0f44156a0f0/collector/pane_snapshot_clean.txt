### Setup

Define the elementary symmetric polynomials:
- $E_1(x,y,z) = x+y+z$
- $E_2(x,y,z) = xy+yz+zx$
- $E_3(x,y,z) = xyz$

The transformation is $f(a,b,c) = (E_1, E_2, E_3) = (s, p, q)$, where
$$s = a+b+c,\quad p = ab+bc+ca,\quad q = abc.$$

The condition $f(f(a,b,c)) = (a,b,c)$ becomes the system:
$$\begin{cases} s = a+b+c & (1)\\ p = ab+bc+ca & (2)\\ q = abc & (3)\\ a = s+p+q
 & (4)\\ b = sp+pq+qs & (5)\\ c = spq & (6) \end{cases}$$

### Key constraint from (3) and (6)

From (6): $c = spq$. From (3): $q = abc$. Substituting,
$$c = sp \cdot (abc) = (spab)\cdot c.$$

**Case A: $c \neq 0$.** Then $spab = 1$, so each of $s, p, a, b$ is an integer e
qual to $\pm 1$.

Enumerate $(a,b) \in \{\pm1\}^2$, using $s = a+b+c$ and $p = ab + c(a+b)$:

The only solution with $c\neq 0$ is $(a,b,c) = (-1,-1,1)$. Direct check: $s=-1,
p=-1, q=1$; $f(-1,-1,1)=(-1,-1,1)$, so this is a **fixed point** (trivially a 2-
cycle).

**Case B: $c = 0$.** Then $q = 0$, $s = a+b$, $p = ab$.
- (4): $a = s+p+q = a+b+ab$, so $b(1+a)=0$, giving $b=0$ or $a=-1$.
- (5): $b = sp = (a+b)(ab) = ab(a+b)$.

If $b = 0$: (5) holds trivially. This yields **fixed points** $(a, 0, 0)$ for an
y integer $a$ (since $f(a,0,0) = (a,0,0)$).

If $a = -1$: (5) gives $b = (-1)b(-1+b) = b - b^2$, so $b^2 = 0$, i.e. $b = 0$ —
 already covered.

### No genuine period-2 points exist

Every solution is a fixed point of $f$:
$$S = \{(a, 0, 0) : a \in \mathbb{Z}\} \cup \{(-1, -1, 1)\}.$$

### Counting $S_{100}$

Require $|a|, |b|, |c| \le 100$:

- **Family $(a, 0, 0)$:** $|a| \le 100$ gives $a \in \{-100, -99, \dots, 100}$,
i.e. **201** nodes.
- **Node $(-1, -1, 1)$:** $|-1|, |-1|, |1| \le 100$ ✓. This is **1** node, disti
nct from the family above (since $b = -1 \neq 0$).

Total:
$$|S_{100}| = 201 + 1 = \boxed{202}.$$
