## Problem Analysis

We have $M = \{(x, x^2) : x \in \mathbb{R}\}$, the standard parabola. We need to
 find $\varepsilon > 0$ such that the normal exponential map $F(p,w) = p + w$ is
 a diffeomorphism from $NM \cap (\mathbb{R}^2 \times B_\varepsilon(0))$ onto $M_
\varepsilon$.

## Step 1: Parametrize the Normal Bundle

Parametrize $M$ by $\gamma(x) = (x, x^2)$. The tangent vector is $\gamma'(x) = (
1, 2x)$ with $|\gamma'(x)| = \sqrt{1+4x^2} =: s$. The unit normal at $\gamma(x)$
 is:
$$n(x) = \frac{(-2x, 1)}{\sqrt{1+4x^2}} = \frac{(-2x, 1)}{s}.$$

Every element of $NM$ has the form $(\gamma(x),\, t\, n(x))$ for some $x, t \in
\mathbb{R}$. Since $|t\, n(x)| = |t|$, the constraint $(p,w) \in \mathbb{R}^2 \t
imes B_\varepsilon(0)$ becomes $|t| < \varepsilon$. So the domain of $F$ is $\{(
x,t) \in \mathbb{R}^2 : |t| < \varepsilon\}$, and:
$$F(x,t) = \left(x - \frac{2xt}{s},\; x^2 + \frac{t}{s}\right), \quad s = \sqrt{
1+4x^2}.$$

## Step 2: Compute the Jacobian

Computing partial derivatives:
$$\frac{\partial F_1}{\partial x} = 1 - \frac{2t}{s} + \frac{8x^2 t}{s^3}, \quad
 \frac{\partial F_1}{\partial t} = -\frac{2x}{s},$$
$$\frac{\partial F_2}{\partial x} = 2x - \frac{4xt}{s^3}, \quad \frac{\partial F
_2}{\partial t} = \frac{1}{s}.$$

The Jacobian determinant is:
$$J = \left(1 - \frac{2t}{s} + \frac{8x^2 t}{s^3}\right)\frac{1}{s} - \left(-\fr
ac{2x}{s}\right)\left(2x - \frac{4xt}{s^3}\right)$$
$$= \frac{1}{s} - \frac{2t}{s^2} + \frac{8x^2 t}{s^4} + \frac{4x^2}{s} - \frac{8
x^2 t}{s^4} = \frac{1+4x^2}{s} - \frac{2t}{s^2} = s - \frac{2t}{s^2} = \frac{s^3
 - 2t}{s^2}.$$

Since $s^2 = 1 + 4x^2 \geq 1 > 0$, we have $J = 0$ if and only if $t = \frac{s^3
}{2} = \frac{(1+4x^2)^{3/2}}{2}$.

The minimum of $(1+4x^2)^{3/2}/2$ over $x \in \mathbb{R}$ is $\frac{1}{2}$, achi
eved at $x = 0$. Therefore:
- For $\varepsilon \leq \frac{1}{2}$: since $|t| < \varepsilon \leq \frac{1}{2}
\leq \frac{(1+4x^2)^{3/2}}{2}$, we have $J > 0$ everywhere, so $F$ is a **local
diffeomorphism**.
- For $\varepsilon > \frac{1}{2}$: the point $(x,t) = (0, \frac{1}{2})$ lies in
the domain and $J = 0$ there, so $F$ is not a local diffeomorphism.

*Proof of claim.* We show that $t_1 < \frac{1}{2}$ and $t_2 < \frac{1}{2}$ (and

**Case 1: $x_1, x_2$ have the same sign.** Then $x_1(x_1+x_2) \geq 0$ and $x_2(x
