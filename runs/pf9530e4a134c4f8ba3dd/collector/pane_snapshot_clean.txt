# Solution

## Identifying the polynomials

The recurrence $P_0=1,\; P_1=x,\; P_{n+1}=2xP_n-P_{n-1}$ defines the **Chebyshev
 polynomials of the first kind**: $P_n(x)=T_n(x)$, where $T_n(\cos\theta)=\cos(n
\theta)$.

## Computing $P_n'(i/2)$

Using $T_n'(x)=n\,U_{n-1}(x)$ and $U_{n-1}(x)=\dfrac{\sin(n\arccos x)}{\sin(\arc
cos x)}$:

At $x=i/2$: $\sin(\arccos(i/2))=\sqrt{1-(i/2)^2}=\sqrt{5/4}=\sqrt{5}/2$.

Setting $\theta=\arccos(i/2)$, we solve $\cos\theta=i/2$ with $\theta=a+bi$:
- $\cos a\cosh b=0 \Rightarrow a=\pi/2$
- $-\sin a\sinh b=1/2 \Rightarrow \sinh b=-1/2 \Rightarrow b=-\operatorname{arcs
inh}(1/2)=-\ln\varphi$

where $\varphi=\frac{1+\sqrt5}{2}$ (golden ratio). So $\theta=\frac{\pi}{2}-i\ln
\varphi$.

Then:
$$\sin(n\theta)=\sin\!\left(\tfrac{n\pi}{2}\right)\cosh(n\ln\varphi)-i\cos\!\lef
t(\tfrac{n\pi}{2}\right)\sinh(n\ln\varphi)$$

**For $n=2017$** ($2017\equiv1\pmod 4$): $\sin(2017\pi/2)=1$, $\cos(2017\pi/2)=0
$, so
$$\sin(2017\theta)=\cosh(2017\ln\varphi)=\frac{\varphi^{2017}+\varphi^{-2017}}{2
}$$

**For $n=17$** ($17\equiv1\pmod 4$): similarly $\sin(17\theta)=\frac{\varphi^{17
}+\varphi^{-17}}{2}$.

Therefore:
$$P_n'(i/2)=\frac{2n\sin(n\theta)}{\sqrt5}\implies S=\frac{2017(\varphi^{2017}+\
varphi^{-2017})}{\sqrt5},\quad T=\frac{17(\varphi^{17}+\varphi^{-17})}{\sqrt5}$$

## Connecting to Fibonacci numbers

For **odd** $n$: $\varphi^{-n}=-\psi^n$ (where $\psi=-\varphi^{-1}$), so $\varph
i^n+\varphi^{-n}=\varphi^n-\psi^n=F_n\sqrt5$. Thus:

$$\frac{S}{T}=\frac{2017\cdot F_{2017}}{17\cdot F_{17}}=\frac{2017\cdot F_{2017}
}{27149}$$

since $F_{17}=1597$ and $17\times1597=27149$.

## Computing $2017\cdot F_{2017}\pmod{27149}$

**Mod 17:** The Pisano period $\pi(17)=36$ (verified: $F_{18}\equiv0$, $F_{17}\e
quiv-1$, so period $=36$). Since $2017\equiv1\pmod{36}$, we get $F_{2017}\equiv
F_1=1\pmod{17}$. With $2017\equiv11\pmod{17}$:
$$2017\cdot F_{2017}\equiv 11\pmod{17}$$

**Mod 1597:** Write $2017=17\times118+11$. Using $F_{a+b}=F_aF_{b+1}+F_{a-1}F_b$
:
$$F_{2017}=F_{17\cdot118+11}=F_{17\cdot118}\cdot F_{12}+F_{17\cdot118-1}\cdot F_
{11}\equiv F_{2005}\cdot89\pmod{1597}$$

since $F_{17}\mid F_{17\cdot118}$. Define $a_k=F_{17k-1}\pmod{1597}$. Then:
$$a_{k+1}=F_{17k+16}=F_{17k}\cdot F_{17}+F_{17k-1}\cdot F_{16}\equiv a_k\cdot987
\pmod{1597}$$

with $a_0=F_{-1}=1$, so $a_k=987^k\pmod{1597}$.

By **Cassini's identity**: $F_{18}F_{16}-F_{17}^2=(-1)^{17}=-1$, and $F_{18}\equ
iv F_{16}=987\pmod{1597}$, giving $987^2\equiv-1\pmod{1597}$.

Therefore $F_{2005}=a_{118}=987^{118}=(987^2)^{59}\equiv(-1)^{59}=-1\pmod{1597}$
, and:
$$F_{2017}\equiv(-1)\cdot89=-89\equiv1508\pmod{1597}$$

With $2017\equiv420\pmod{1597}$: $2017\cdot F_{2017}\equiv420\cdot(-89)=-37380\e
quiv948\pmod{1597}$.

## CRT reconstruction

We need $r$ with $r\equiv11\pmod{17}$ and $r\equiv948\pmod{1597}$.

Set $r=948+1597k$. Since $948\equiv13\pmod{17}$ and $1597\equiv-1\pmod{17}$:
$$13-k\equiv11\pmod{17}\implies k\equiv2\pmod{17}$$

$$r=948+1597\times2=4142$$

**Verification:** $4142\mod17=11$ ✓, $4142\mod1597=948$ ✓.

## Reducing the fraction

$\gcd(4142,27149)$: Since $4142=2\times2071$ and $27149=17\times1597$, checking
$2071\mod17=14\neq0$ and $4142\mod1597=948\neq0$, we get $\gcd=1$.

The fractional part is $\frac{4142}{27149}$ with $m=4142$, $n=27149$ coprime.

$$\boxed{m=4142}$$
