## Proof

**Yes, such a function exists.** We construct one using transfinite recursion (r
equiring the Axiom of Choice, equivalently the well-orderability of $\mathbb{R}$
).

### Setup

Let $\mathfrak{c} = |\mathbb{R}|$, and let $\omega_{\mathfrak{c}}$ denote the in
itial ordinal of cardinality $\mathfrak{c}$ (the least ordinal of size $\mathfra
k{c}$). Using the well-ordering principle, fix a bijection
$$
\bigl\{(I_\alpha, y_\alpha) : \alpha < \omega_{\mathfrak{c}}\bigr\} \;=\; \bigl\
{(I, y) : I \subseteq \mathbb{R} \text{ is an open interval},\; y \in \mathbb{R}
\bigr\}.
$$
This is legitimate because the set of open intervals has cardinality $\mathfrak{
c}$ (each is determined by its two endpoints), so the set of pairs $(I,y)$ has c
ardinality $\mathfrak{c}\cdot\mathfrak{c}=\mathfrak{c}$.

### Construction

We define a partial function by transfinite recursion over $\alpha < \omega_{\ma
thfrak{c}}$. Suppose $f$ has been defined on a set $S_\alpha = \{x_\beta : \beta
 < \alpha\}$ with $|S_\alpha| \le |\alpha| < \mathfrak{c}$.

**Claim:** $I_\alpha \setminus S_\alpha \neq \emptyset$.

*Proof of claim.* The interval $I_\alpha$ has cardinality $\mathfrak{c}$, while
$|S_\alpha| \le |\alpha| < \mathfrak{c}$. Removing fewer than $\mathfrak{c}$ poi
nts from a set of size $\mathfrak{c}$ leaves a set of size $\mathfrak{c}$, hence
 in particular a nonempty set. $\square$

Choose $x_\alpha \in I_\alpha \setminus S_\alpha$ and set $f(x_\alpha) = y_\alph
a$.

After the recursion completes, $f$ is defined on $S = \{x_\alpha : \alpha < \ome
ga_{\mathfrak{c}}\}$. Extend $f$ to all of $\mathbb{R}$ by setting $f(x) = 0$ fo
r $x \notin S$.

### Verification

Let $(a,b)$ be any open interval with $a < b$, and let $y \in \mathbb{R}$ be arb
itrary. The pair $((a,b), y)$ appears in our enumeration, say $(I_{\alpha_0}, y_
{\alpha_0}) = ((a,b), y)$ for some $\alpha_0 < \omega_{\mathfrak{c}}$.

At stage $\alpha_0$, we selected $x_{\alpha_0} \in I_{\alpha_0} = (a,b)$ and set
 $f(x_{\alpha_0}) = y_{\alpha_0} = y$. Therefore
$$
x_{\alpha_0} \in (a,b) \quad\text{and}\quad f(x_{\alpha_0}) = y,
$$
so $y \in f\bigl((a,b)\bigr)$. Since $y$ was arbitrary,
$$
f\bigl((a,b)\bigr) = \mathbb{R}.
$$
Since $(a,b)$ was arbitrary, this holds for **every** open interval.

### Conclusion

The function $f: \mathbb{R} \to \mathbb{R}$ constructed above satisfies $f\bigl(
(a,b)\bigr) = \mathbb{R}$ for every open interval $(a,b)$ with $a < b$. Hence su
ch a function exists. $\blacksquare$
