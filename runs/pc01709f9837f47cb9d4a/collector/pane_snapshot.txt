## Solution

We evaluate $I = \frac{1}{2\pi i}\int_C |1+z+z^2|^2\,dz$, where $C$ is the unit
circle $|z|=1$ traversed anticlockwise.

**Key substitution.** On the unit circle, $|z|=1$, so $\bar{z} = z^{-1}$. Theref
ore, for any polynomial $P(z)$, we have $\overline{P(z)} = \bar{P}(\bar{z}) = \b
ar{P}(z^{-1})$, where $\bar{P}$ denotes the polynomial with conjugated coefficie
nts. Since $1+z+z^2$ has real coefficients:

$$|1+z+z^2|^2 = (1+z+z^2)\,\overline{(1+z+z^2)} = (1+z+z^2)\left(1+z^{-1}+z^{-2}
\right).$$

**Expand the product:**

$$
(1+z+z^2)(1+z^{-1}+z^{-2})
= 1 + z^{-1} + z^{-2} + z + 1 + z^{-1} + z^2 + z + 1.
$$

Collecting like powers of $z$:

$$|1+z+z^2|^2 = z^2 + 2z + 3 + 2z^{-1} + z^{-2}.$$

**Apply the residue theorem.** We have

$$I = \frac{1}{2\pi i}\oint_C \left(z^2 + 2z + 3 + 2z^{-1} + z^{-2}\right)dz.$$

Recall that for integer $n$,

$$\frac{1}{2\pi i}\oint_C z^n\,dz = \begin{cases} 1 & n = -1,\\ 0 & n \neq -1.\e
nd{cases}$$

This follows directly from Cauchy's integral formula (or equivalently, the resid
ue theorem, where only the $z^{-1}$ term has a residue at $z=0$).

Applying this term-by-term:

- $\frac{1}{2\pi i}\oint z^2\,dz = 0$,
- $\frac{1}{2\pi i}\oint 2z\,dz = 0$,
- $\frac{1}{2\pi i}\oint 3\,dz = 0$,
- $\frac{1}{2\pi i}\oint 2z^{-1}\,dz = 2\cdot 1 = 2$,
- $\frac{1}{2\pi i}\oint z^{-2}\,dz = 0$.

**Result.** Only the $z^{-1}$ term contributes, with coefficient $2$. Therefore

$$\boxed{I = 2}.$$
