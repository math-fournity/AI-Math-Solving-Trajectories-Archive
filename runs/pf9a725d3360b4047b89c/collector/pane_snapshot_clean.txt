## Proof

**Setup and key identity.** Let $s = xyz$ and $u = xy + yz + zx$. Expanding:

$$(xy+1)(yz+1)(zx+1) = (xyz)^2 + xyz(x+y+z) + (xy+yz+zx) + 1 = s^2 + s(x+y+z) +
u + 1.$$

From Constraint 1: $s + (x+y+z) = 6$, so $x+y+z = 6-s$. Substituting:

$$s^2 + s(6-s) + u + 1 = 6s + u + 1. \tag{$\star$}$$

**Expressing everything in terms of $z$.** From Constraint 1, $x + y = 6 - s - z
$ and $xy = s/z$. From Constraint 2:

$$s + 2xy + z(x+y) + z = 10 \implies s + \frac{2s}{z} + z(6-s-z) + z = 10.$$

Solving for $s$:

$$s\!\left(1 + \frac{2}{z} - z\right) = 10 - 7z + z^2 \implies s \cdot \frac{z+2
-z^2}{z} = z^2 - 7z + 10.$$

Factoring: $z+2-z^2 = -(z-2)(z+1)$ and $z^2-7z+10 = (z-2)(z-5)$, so for $z \neq
2$:

$$s = \frac{z(5-z)}{z+1}. \tag{1}$$

(The case $z=2$ is a removable singularity; direct substitution gives $x=y=1, z=
2, s=2$, consistent with (1).)

**Computing $x+y$ and $xy$:**

$$x + y = 6 - s - z = \frac{6}{z+1}, \qquad xy = \frac{s}{z} = \frac{5-z}{z+1}.
\tag{2}$$

**Computing $u = xy + yz + zx$:** Since $yz + zx = z(x+y) = \frac{6z}{z+1}$,

$$u = \frac{5-z}{z+1} + \frac{6z}{z+1} = \frac{5+5z}{z+1} = 5. \tag{3}$$

This is the crucial simplification: **$u = 5$ for all valid $z$.**

**Reducing to a single-variable problem.** From $(\star)$ and (1), (3):

$$\text{Objective} = 6s + 6 = 6\!\left(\frac{z(5-z)}{z+1} + 1\right) = 6 \cdot \
frac{-z^2 + 6z + 1}{z+1} =: 6\,f(z).$$

**Domain.** We need $s > 0 \Rightarrow z < 5$ (with $z > 0$), and $xy > 0 \Right
arrow z < 5$. The discriminant for $x,y$ is:

$$(x+y)^2 - 4xy = \frac{36}{(z+1)^2} - \frac{4(5-z)}{z+1} = \frac{4(z-2)^2}{(z+1
)^2} \geq 0,$$

so real solutions always exist. The domain is $z \in (0, 5)$.

**Optimizing $f(z) = \frac{-z^2+6z+1}{z+1}$.**

$$f'(z) = \frac{(-2z+6)(z+1)-(-z^2+6z+1)}{(z+1)^2} = \frac{-z^2-2z+5}{(z+1)^2}.$
$

Setting $f'(z)=0$: $z^2 + 2z - 5 = 0$, giving $z = -1 \pm \sqrt{6}$. Only $z = \
sqrt{6}-1 \approx 1.449$ lies in $(0,5)$.

Since the numerator $-z^2-2z+5$ is a downward parabola (positive between its roo
ts), $f' > 0$ for $z < \sqrt{6}-1$ and $f' < 0$ for $z > \sqrt{6}-1$. Thus $z =
\sqrt{6}-1$ is the **global maximum** (boundary values: $f \to 1$ as $z \to 0^+$
 or $z \to 5^-$, both less than the critical value).

**Evaluating at the maximum.** With $z = \sqrt{6}-1$, so $z+1 = \sqrt{6}$ and $z
^2 = 7 - 2\sqrt{6}$:

$$-z^2 + 6z + 1 = -(7-2\sqrt{6}) + 6(\sqrt{6}-1) + 1 = -12 + 8\sqrt{6}.$$

$$f(z) = \frac{-12+8\sqrt{6}}{\sqrt{6}} = 8 - 2\sqrt{6}.$$

**Maximum value:**

$$6\,f(z) = 6(8 - 2\sqrt{6}) = \boxed{48 - 12\sqrt{6}}.$$

**Verification.** At $z = \sqrt{6}-1$: $s = \frac{(\sqrt{6}-1)(6-\sqrt{6})}{\sqr
t{6}} = \frac{7\sqrt{6}-12}{\sqrt{6}} = 7 - 2\sqrt{6} \approx 2.101$; $xy = \fra
c{6-\sqrt{6}}{\sqrt{6}} = \sqrt{6}-1 \approx 1.449$; $x+y = \frac{6}{\sqrt{6}} =
 \sqrt{6} \approx 2.449$. Constraint 1: $s + (x+y) + z = (7-2\sqrt{6}) + \sqrt{6
} + (\sqrt{6}-1) = 6$. ✓ Constraint 2: $s + 2xy + z(x+y) + z = (7-2\sqrt{6}) + 2
(\sqrt{6}-1) + (\sqrt{6}-1)\sqrt{6} + (\sqrt{6}-1) = 7-2\sqrt{6}+2\sqrt{6}-2+6-\
sqrt{6}+\sqrt{6}-1 = 10$. ✓ The objective $\approx 18.606$, exceeding the symmet
ric point value of $18$ (at $z=2$). ✓
