## Solution

We need to evaluate
$$I = \int_0^\infty \int_0^\infty \frac{e^{-(x_1+x_2)/2}}{x_1+x_2}\,dx_1\,dx_2$$
and find $C = 1/I$.

**Change of variables.** Set $s = x_1 + x_2$ and $t = x_1$ (so $x_2 = s - t$). F
or fixed $s \ge 0$, the variable $t$ ranges over $[0, s]$, and the Jacobian is $
1$. Therefore
$$\iint_{x_1,x_2 \ge 0} g(x_1+x_2)\,dx_1\,dx_2 = \int_0^\infty \left(\int_0^s g(
s)\,dt\right)ds = \int_0^\infty s\, g(s)\,ds.$$

**Apply with** $g(s) = \dfrac{e^{-s/2}}{s}$:
$$I = \int_0^\infty s \cdot \frac{e^{-s/2}}{s}\,ds = \int_0^\infty e^{-s/2}\,ds
= \left[-2e^{-s/2}\right]_0^\infty = 0 - (-2) = 2.$$

**Therefore**
$$C = \frac{1}{I} = \frac{1}{2}.$$
