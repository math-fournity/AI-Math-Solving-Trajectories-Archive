## Proof

We wish to find the number of trailing zeros of
$$S = \sum_{n=10}^{99} (n^2)! = 100! + 121! + 144! + \cdots + 9801!.$$

The number of trailing zeros equals $v_{10}(S) = \min(v_2(S), v_5(S))$, where $v
_p$ denotes the $p$-adic valuation.

**Step 1: Compute $v_5$ of each term.**

Using Legendre's formula $v_5(m!) = \sum_{k\ge 1}\lfloor m/5^k\rfloor$:

- $v_5(100!) = 20 + 4 + 0 = 24$ (term $n=10$, since $10^2=100$).
- $v_5(121!) = 24 + 4 + 0 = 24$ (term $n=11$, since $11^2=121$).
- $v_5(144!) = 28 + 5 + 1 = 34$ (term $n=12$, since $12^2=144$).

For $n \ge 12$, we have $n^2 \ge 144$, so $v_5((n^2)!) \ge v_5(144!) = 34$.

Thus the only two terms with the minimal $5$-adic valuation $24$ are $100!$ and
$121!$; every other term has $v_5 \ge 34$.

**Step 2: Combine the two leading terms.**

$$100! + 121! = 100!\bigl(1 + P\bigr), \quad \text{where } P = \frac{121!}{100!}
 = 101\cdot 102\cdots 121.$$

The product $P$ runs over 21 consecutive integers $101,\dots,121$, which include
 the multiples of $5$: $105, 110, 115, 120$. Hence $5 \mid P$, so
$$1 + P \equiv 1 \pmod{5}, \qquad v_5(1+P) = 0.$$

Therefore
$$v_5(100! + 121!) = v_5(100!) + v_5(1+P) = 24 + 0 = 24.$$

**Step 3: Combine with the remaining terms.**

Write $S = (100! + 121!) + R$, where $R = \sum_{n=12}^{99}(n^2)!$ satisfies $v_5
(R) \ge 34$.

Since $v_5(100!+121!) = 24 < 34 \le v_5(R)$, the valuations are unequal, so
$$v_5(S) = \min(24, 34) = 24.$$

**Step 4: Compute $v_2(S)$.**

$$v_2(100!) = 50 + 25 + 12 + 6 + 3 + 1 = 97.$$

Every term $(n^2)!$ with $n\ge 10$ has $v_2 \ge v_2(100!) = 97$, so $v_2(S) \ge
97 \gg 24$.

**Step 5: Conclusion.**

$$v_{10}(S) = \min(v_2(S), v_5(S)) = \min(97, 24) = 24.$$

The number of zeros at the end of the integer is $\boxed{24}$.
