## Proof

**Small cases.**

- **$n=1$:** $n!=1$, range $0\le a<1$ gives $a=0$, and $1\mid 0^1+1=1$. Unique.
✓
- **$n=2$:** $n!=2$, $a\in\{0,1\}$. $a=0$: $0^2+1=1$, $2\nmid 1$. $a=1$: $1+1=2$
, $2\mid 2$. Unique. ✓

**Even $n\ge 4$ fail.** For $n\ge 4$, $4\mid n!$, so we need $a^n\equiv -1\pmod{
4}$. If $a$ is even, $a^n\equiv 0\pmod 4$, so $a^n+1\equiv 1$. If $a$ is odd, $a
^2\equiv 1\pmod 4$ and $n$ even gives $a^n=(a^2)^{n/2}\equiv 1\pmod 4$, so $a^n+
1\equiv 2\pmod 4$. Neither is $0\pmod 4$, so **no solution exists**. ✗

**Odd $n\ge 3$: setting up via CRT.** Write $n!=\prod_{p\le n}p^{k_p}$ where $k_
p=v_p(n!)$. By CRT, the number of solutions to $a^n\equiv -1\pmod{n!}$ with $0\l
e a<n!$ equals the product over primes $p\le n$ of $N_p$, where $N_p$ is the num
ber of solutions mod $p^{k_p}$.

**The 2-part ($p=2$) always gives $N_2=1$ for odd $n$.**
- If $k_2=1$ (i.e., $n=3$): need $a^n\equiv 1\pmod 2$, so $a$ odd: 1 solution.
- If $k_2\ge 2$: mod $4$, need $a^n\equiv 3\pmod 4$. Since $n$ odd and $a$ odd,
$a\equiv 3\pmod 4$ is the unique solution (as $3^n\equiv 3\pmod 4$, $1^n\equiv 1
\pmod 4$).
- If $k_2\ge 3$: $(\mathbb{Z}/2^{k_2}\mathbb{Z})^*\cong\{\pm1\}\times\langle 5\r
angle$ with $|\langle 5\rangle|=2^{k_2-2}$. Write $a=(-1)^\varepsilon\cdot 5^j$.
 Then $a^n=(-1)^{n\varepsilon}\cdot 5^{nj}=(-1)^\varepsilon\cdot 5^{nj}$ (since
$n$ odd). Setting $a^n=-1=(-1)^1\cdot 5^0$ forces $\varepsilon=1$ and $nj\equiv
0\pmod{2^{k_2-2}}$. Since $\gcd(n,2^{k_2-2})=1$ ($n$ odd), this gives $j\equiv 0
$, a unique solution. ✓

**Odd prime parts.** For an odd prime $p$ with $p^{k_p}\Vert n!$, the group $(\m
athbb{Z}/p^{k_p}\mathbb{Z})^*$ is cyclic of order $\varphi(p^{k_p})=p^{k_p-1}(p-
1)$. Let $g$ be a generator; then $-1=g^{\varphi/2}$. Writing $a=g^j$, the equat
ion $a^n\equiv -1$ becomes $nj\equiv \varphi/2\pmod{\varphi}$, which has exactly
 $\gcd(n,\varphi(p^{k_p}))$ solutions (when solutions exist, i.e., when $\gcd(n,
\varphi)\mid \varphi/2$).

For the total count to equal $1$, since $N_2=1$, we need **$N_p=1$ for every odd
 prime $p\le n$**, i.e., $\gcd(n,\varphi(p^{k_p}))=1$ for all odd primes $p\le n
$.

**Case: $n$ is an odd prime.** Let $n=q$ (prime). For each odd prime $p\le q$:
- **$p=q$:** $k_q=v_q(q!)=1$, so $\varphi(q)=q-1$, and $\gcd(q,q-1)=1$. ✓
- **$p<q$:** Since $q$ is prime, $p\nmid q$, so $\gcd(q,p^{k_p-1})=1$. Also $\gc
d(q,p-1)=1$ since $p-1<q$ and $q$ is prime (a prime cannot divide a smaller posi
tive integer). Thus $\gcd(q,p^{k_p-1}(p-1))=1$. ✓

So $n$ an odd prime gives a unique solution. ✓

**Case: $n$ is odd and composite.** Then $n$ has an odd prime factor $p$ with $p
\mid n$ and $n\ge 2p$ (since $n$ is composite, $n\ge p\cdot 3$ or $n=p^2\ge 3p$;
 in any case $n\ge 2p$). Then $k_p=v_p(n!)\ge\lfloor n/p\rfloor\ge 2$, so $p\mid
 p^{k_p-1}$ and $p\mid n$, giving $\gcd(n,p^{k_p-1}(p-1))\ge p\ge 3$.

The number of solutions mod $p^{k_p}$ is either $0$ (if $\gcd(n,\varphi)\nmid\va
rphi/2$) or $\ge 3$. In the first subcase, the total count is $0$; in the second
, it's $\ge 3$. **Neither equals $1$.** ✗

**Conclusion.** The values of $n$ for which a unique $a$ exists are:

$$\boxed{n\in\{1,\,2\}\cup\{p:\ p \text{ is an odd prime}\}}.$$
