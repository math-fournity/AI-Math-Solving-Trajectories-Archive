Computing E[ε₁]:

$$\mathbb{E}[\varepsilon_1] = (-1)(1-C_\beta) + C_\beta \beta \int_0^\infty t^\b

Substituting u = t^β (so dt = (1/β)u^{1/β−1} du):

$$\int_0^\infty t^\beta e^{-t^\beta}\,dt = \frac{1}{\beta}\int_0^\infty u^{1/\be

So:

$$\mathbb{E}[\varepsilon_1] = -(1-C_\beta) + C_\beta\,\Gamma\!\left(1+\tfrac{1}{

Setting this equal to −1/2:

$$-1 + C_\beta + C_\beta\,\Gamma\!\left(1+\tfrac{1}{\beta}\right) = -\tfrac{1}{2
}$$

$$C_\beta = \frac{1}{2\left(1 + \Gamma\!\left(1+\frac{1}{\beta}\right)\right)}$$

Since Γ(1+1/β) > 0 for all β > 0, we get C_β ∈ (0, 1/2) ⊂ (0,1). ✓ The constrain

**Step 2: Apply the definition of heavy-tailed.**

A distribution is **heavy-tailed** if its moment generating function is infinite
 for every s > 0, i.e., E[e^{sε₁}] = ∞ for all s > 0. Equivalently, the right ta
il is not exponentially bounded: −ln P(ε₁ > t) = o(t) as t → ∞.

For our distribution:

$$-\ln \bar{F}(t) = -\ln C_\beta + t^\beta, \quad t \geq 0$$

The condition −ln F̄(t) = o(t) as t → ∞ requires:

$$\lim_{t\to\infty} \frac{t^\beta}{t} = \lim_{t\to\infty} t^{\beta-1} = 0$$

This holds **if and only if β < 1**.

**Step 3: Verify via the moment generating function directly.**

$$M(s) = \mathbb{E}[e^{s\varepsilon_1}] = (1-C_\beta)e^{-s} + C_\beta\beta\int_0
^\infty t^{\beta-1} e^{st - t^\beta}\,dt$$

The convergence of the integral depends on the exponent st − t^β as t → ∞:

- **β < 1, s > 0:** t^β = o(t), so st − t^β → +∞. The integrand grows without bo
und, the integral diverges, and M(s) = ∞ for all s > 0. **Heavy-tailed.** ✓

- **β = 1, s > 0:** st − t = t(s−1). The integral converges for s < 1 and diverg
es for s ≥ 1. So M(s) < ∞ for s ∈ (0,1). **Not heavy-tailed.**

- **β > 1, s > 0:** t^β dominates st, so st − t^β → −∞. The integral converges f
or all s > 0, giving M(s) < ∞. **Light-tailed (superexponential).**

## Conclusion

The random walk is heavy-tailed if and only if the tail e^{−t^β} decays subexpon
entially, which occurs precisely when the Weibull-type shape parameter satisfies
 β < 1.

$$\boxed{0 < \beta < 1}$$
