Let $n=2015$ and $\omega=e^{2\pi i/n}$, a primitive $n$-th root of unity. The ex
pression is
$$P=\prod_{a=1}^{n}\prod_{b=1}^{n}(1+\omega^{ab}).$$

**Inner product.** Fix $a$ and set $d=\gcd(a,n)$. Then $\omega^a$ is a primitive
 $(n/d)$-th root of unity, and as $b$ ranges over $1,\dots,n$, the value $(\omeg
a^a)^b$ runs through every $(n/d)$-th root of unity exactly $d$ times. Hence
$$\prod_{b=1}^{n}(1+\omega^{ab})=\Bigl(\prod_{\zeta^{\,n/d}=1}(1+\zeta)\Bigr)^{d
}.$$

For any $m$, $\prod_{\zeta^m=1}(x-\zeta)=x^m-1$; setting $x=-1$ gives $\prod_{\z
eta^m=1}(1+\zeta)=(-1)^m\bigl((-1)^m-1\bigr)$, which equals $2$ if $m$ is odd an
d $0$ if $m$ is even.

Now $n=2015=5\cdot 13\cdot 31$ is odd, so every divisor $d\mid n$ is odd and $n/
d$ is odd. Thus $n/d$ is always odd, and
$$\prod_{b=1}^{n}(1+\omega^{ab})=2^{d}=2^{\gcd(a,n)}.$$

**Outer product.** Therefore
$$P=\prod_{a=1}^{n}2^{\gcd(a,n)}=2^{\,\sum_{a=1}^{n}\gcd(a,n)},\qquad \log_2 P=\
sum_{a=1}^{n}\gcd(a,n).$$

**Evaluating the gcd sum.** Using $\#\{a:1\le a\le n,\ \gcd(a,n)=d\}=\varphi(n/d
)$,
$$\sum_{a=1}^{n}\gcd(a,n)=\sum_{d\mid n}d\,\varphi(n/d).$$
This is the Dirichlet convolution $\mathrm{id}*\varphi$, which is multiplicative

$$f(p)=p^0\varphi(p)+p^1\varphi(1)=(p-1)+p=2p-1.$$
