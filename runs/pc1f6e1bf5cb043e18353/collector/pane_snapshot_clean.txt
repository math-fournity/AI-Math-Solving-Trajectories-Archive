Looking at this problem, I need to find all integer-coefficient polynomials p(x)
 satisfying min(T₁(x), T₂(x)) ≤ p(x) ≤ max(T₁(x), T₂(x)) for all real x, where T
₁(x) = 2x⁴ − 6x² + 1 and T₂(x) = 4 − 5x².

## Setting Up the Sandwich Structure

**Finding crossing points:** T₁(x) − T₂(x) = 2x⁴ − x² − 3 = (2x² − 3)(x² + 1). T
his vanishes at x = ±√(3/2) = ±α.

**Determining upper/lower envelopes:** Checking x = 0: T₁(0) = 1 < 4 = T₂(0). So
:
- For |x| ≤ α: L = T₁, U = T₂ (T₁ is lower)
- For |x| ≥ α: L = T₂, U = T₁ (T₂ is lower)

**Critical boundary condition:** At x = ±α, T₁ = T₂ = −7/2, so p(±α) = −7/2.

## Degree Analysis

As x → ∞: T₁ ~ 2x⁴ → +∞, T₂ ~ −5x² → −∞. The sandwich requires T₂ ≤ p ≤ T₁, forc
ing deg(p) ≤ 4. Degree 3 is impossible (cubic → −∞ faster than T₂ in one directi
on). Degree 4 requires leading coefficient a₄ ∈ {1, 2} (positive, ≤ 2); degree ≤
 2 has a₄ = 0.

## Exploiting Symmetry — Even/Odd Decomposition

Since T₁, T₂ are even, write p = E + O (even + odd parts). Both p(x) and p(−x) =
 E − O must lie in [L(x), U(x)]. This forces:
- **E(x) ∈ [L(x), U(x)] for all x** (the even part must itself be in the sandwic
h)
- **|O(x)| ≤ min(U(x) − E(x), E(x) − L(x)) for all x** (the odd part has limited
 room)

### Boundary condition on E

Writing E(x) = a₄x⁴ + a₂x² + a₀ and evaluating at α (using α² = 3/2):
4a₀ + 6a₂ + 9a₄ = −14.

**a₄ = 1:** 4a₀ + 6a₂ = −23 — even = odd, **no solution**.

**a₄ = 0:** 2a₀ + 3a₂ = −7, requiring a₂ odd.

**a₄ = 2:** 2a₀ + 3a₂ = −16, requiring a₂ even.

## Finding Valid Even Polynomials

Substituting t = x², the sandwich becomes conditions on q(t) = a₄t² + a₂t + a₀.
Both q − T₁ and q − T₂ vanish at t = 3/2, so (t − 3/2) divides each. Factoring a
nd enforcing sign conditions on each region:

**a₄ = 0 case:** q(t) = a₂t + a₀, with q − T₁ = −2(t − 3/2)(t − r_f) where r_f =
 (a₂+3)/2, and q − T₂ = (a₂+5)(t − 3/2).

Sign analysis yields: a₂ ≤ −3 (from f) and a₂ ≥ −5 (from g), with a₂ odd.
- **a₂ = −5:** p = −5x² + 4 = T₂ ✓
- **a₂ = −3:** p = −3x² + 1 ✓ (verified: p − T₁ = −x²(2x²−3), T₂ − p = 3 − 2x²,
both have correct signs in each region)

**a₄ = 2 case:** q − T₁ = (a₂+6)(t − 3/2), q − T₂ = 2(t − 3/2)(t − r_g) where r_
g = −(a₂+8)/2.

Sign analysis yields: a₂ ≤ −6 and a₂ ≥ −8, with a₂ even.
- **a₂ = −6:** p = 2x⁴ − 6x² + 1 = T₁ ✓
- **a₂ = −8:** p = 2x⁴ − 8x² + 4 ✓ (verified: p − T₁ = 3 − 2x², T₂ − p = −x²(2x²
−3), correct signs)

## Ruling Out Nonzero Odd Parts

The odd part has the form O(x) = k·x(2x² − 3) for integer k (from the constraint
 2a₁ + 3a₃ = 0, giving a₁ = −3k, a₃ = 2k). Note O(±α) = 0 automatically.

For each even polynomial, I check whether |O(x)| ≤ m(x) := min(U−E, E−L) allows
k ≠ 0:

- **E = T₁ or E = T₂:** m(x) = 0 everywhere (E coincides with a bound), forcing
k = 0.
- **E = −3x² + 1:** E(0) = 1 = T₁(0) = L(0), so E − L = 0 at t = 0. For small t
> 0: m ≈ 3t while |O| ≈ 3|k|√t. The condition |k| ≤ √t as t → 0⁺ forces k = 0.
- **E = 2x⁴ − 8x² + 4:** E(0) = 4 = T₂(0) = U(0), so U − E = 0 at t = 0. Same √t
-vs-t argument forces k = 0. Additionally, for large t: m ~ 2t while |O| ~ 2|k|t
^{3/2}, and t^{3/2} ≫ t forces k = 0.

**No polynomial with a nonzero odd part satisfies the sandwich condition.**

## Conclusion

The four valid polynomials are:

| Polynomial | Notes |
|---|---|
| 4 − 5x² | = T₂ |
| −3x² + 1 | "inner" polynomial |
| 2x⁴ − 6x² + 1 | = T₁ |
| 2x⁴ − 8x² + 4 | "inner" polynomial |

Note that p₃ + p₄ = T₁ + T₂, confirming they are reflections across the midpoint
 (T₁+T₂)/2.

The number of integer-coefficient polynomials satisfying the safety requirement
is **4**.
