## Analysis

**General construction for even k = 2m, n = 2^m:**

Index grid positions by (i, j) where i, j ∈ GF(2)^m (binary vectors). Define the
 key assignment as a linear map:

$$\text{key}(i, j) = M_1 \cdot i + M_2 \cdot j \pmod{2}$$

where M₁, M₂ are k × m binary matrices. This is a bijection iff [M₁ | M₂] (a k ×
 k matrix) is invertible over GF(2).

**Key idea:** Let J = (1,1,…,1) ∈ GF(2)^k. Partition {1,…,k} into R = {1,…,m} an
d S = {m+1,…,k}. Define:
- r_t = e_t (standard basis vector, t = 1,…,m), so p_t = J + e_t (weight k−1 ✓)
- s_t = e_{m+t}, so q_t = J + e_{m+t} (weight k−1 ✓)

Set the columns of M₁ as: a₁ = p₁ = J + e₁, and a_t = p_t + p_{t−1} = e_t + e_{t
−1} for t ≥ 2.
Set the columns of M₂ as: m₁ = q₁ = J + e_{m+1}, and m_t = q_t + q_{t−1} = e_{m+
t} + e_{m+t−1} for t ≥ 2.
