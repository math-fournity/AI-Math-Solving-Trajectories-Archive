## Example 12 — Circulation of $\vec{F} = \rho\sin\varphi\,\vec{e}_\rho + \rho z
\,\vec{e}_\varphi + \rho^3\,\vec{e}_z$ along $L:\ \rho=\sin\varphi,\ z=0,\ 0\le\
varphi\le\pi$

### Step 1. Identify the curve

On $L$: $\rho=\sin\varphi$, $z=0$. In Cartesian,
$$x=\rho\cos\varphi=\sin\varphi\cos\varphi=\tfrac12\sin 2\varphi,\qquad y=\rho\s
in\varphi=\sin^2\varphi.$$
Since $\rho^2=\rho\sin\varphi=y$, i.e. $x^2+y^2=y$, equivalently
$$x^2+\bigl(y-\tfrac12\bigr)^2=\tfrac14,$$
the curve is the circle of radius $\tfrac12$ centered at $(0,\tfrac12)$ in the p
lane $z=0$. At $\varphi=0$: $\rho=0$ (origin); at $\varphi=\pi$: $\rho=0$ (origi
n). Hence **$L$ is a closed curve**.

As $\varphi$ increases from $0$ to $\pi$, $x$ runs $0\to+\tfrac12\to0\to-\tfrac1
2\to0$ while $y$ runs $0\to1\to0$: the traversal is **counterclockwise** viewed
from $+z$, so the compatible normal is $+\vec{e}_z$.

---

### Step 2. Direct computation

The line element in cylindrical coordinates is
$$d\vec r = d\rho\,\vec e_\rho + \rho\,d\varphi\,\vec e_\varphi + dz\,\vec e_z.$
$
On $L$: $d\rho=\cos\varphi\,d\varphi$, $dz=0$, so
$$d\vec r = \cos\varphi\,d\varphi\,\vec e_\rho + \sin\varphi\,d\varphi\,\vec e_\
varphi.$$

The field restricted to $L$ ($\rho=\sin\varphi$, $z=0$):
$$\vec F\big|_L = \sin\varphi\cdot\sin\varphi\,\vec e_\rho + \sin\varphi\cdot 0\
,\vec e_\varphi + \sin^3\varphi\,\vec e_z = \sin^2\varphi\,\vec e_\rho + \sin^3\
varphi\,\vec e_z.$$

Therefore
$$\vec F\cdot d\vec r = \sin^2\varphi\cos\varphi\,d\varphi + 0 + 0 = \sin^2\varp
hi\cos\varphi\,d\varphi.$$

The circulation:
$$\oint_L \vec F\cdot d\vec r = \int_0^\pi \sin^2\varphi\cos\varphi\,d\varphi =
\left[\frac{\sin^3\varphi}{3}\right]_0^\pi = 0-0 = \boxed{0}.$$

### Step 3. Via Stokes' theorem

Stokes' theorem: $\displaystyle\oint_L \vec F\cdot d\vec r = \iint_S (\nabla\tim
es\vec F)\cdot d\vec S$, where $S$ is the disk $x^2+(y-\tfrac12)^2\le\tfrac14$ i
n the plane $z=0$, i.e. in cylindrical coordinates $0\le\rho\le\sin\varphi$, $0\
le\varphi\le\pi$, $z=0$, with normal $\vec e_z$.

**Curl in cylindrical coordinates** (with $F_\rho=\rho\sin\varphi$, $F_\varphi=\
rho z$, $F_z=\rho^3$):
$$(\nabla\times\vec F)_\rho = \frac1\rho\!\left[\frac{\partial F_z}{\partial\var
phi}-\frac{\partial(\rho F_\varphi)}{\partial z}\right] = \frac1\rho\!\left[0-\f
rac{\partial(\rho^2 z)}{\partial z}\right] = \frac1\rho(0-\rho^2)=-\rho,$$
$$(\nabla\times\vec F)_\varphi = \frac{\partial F_\rho}{\partial z}-\frac{\parti
al F_z}{\partial\rho} = 0-3\rho^2 = -3\rho^2,$$
$$(\nabla\times\vec F)_z = \frac1\rho\!\left[\frac{\partial(\rho F_\varphi)}{\pa
rtial\rho}-\frac{\partial F_\rho}{\partial\varphi}\right] = \frac1\rho\!\left[\f
rac{\partial(\rho^2 z)}{\partial\rho}-\rho\cos\varphi\right] = \frac1\rho(2\rho
z-\rho\cos\varphi) = 2z-\cos\varphi.$$

On $S$ we have $z=0$, so only the $z$-component contributes:
$$(\nabla\times\vec F)\cdot\vec e_z\big|_{z=0} = -\cos\varphi.$$

The surface element on the $z=0$ plane is $d\vec S = \vec e_z\,\rho\,d\rho\,d\va
rphi$. Hence
$$\iint_S (\nabla\times\vec F)\cdot d\vec S = \int_0^\pi\!\int_0^{\sin\varphi}(-
\cos\varphi)\,\rho\,d\rho\,d\varphi = \int_0^\pi (-\cos\varphi)\left[\frac{\rho^
2}{2}\right]_0^{\sin\varphi}d\varphi$$
$$= -\frac12\int_0^\pi \sin^2\varphi\cos\varphi\,d\varphi = -\frac12\left[\frac{
\sin^3\varphi}{3}\right]_0^\pi = 0.$$

---

### Step 4. Conclusion

Both methods agree:

$$\oint_L \vec F\cdot d\vec r = 0 \qquad\text{(direct)},\qquad \iint_S(\nabla\ti
mes\vec F)\cdot d\vec S = 0 \qquad\text{(Stokes)}.$$

The circulation of the vector field along $L$ is **$0$**.
