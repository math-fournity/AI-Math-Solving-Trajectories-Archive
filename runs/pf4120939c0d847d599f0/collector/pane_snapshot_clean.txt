## Solution

We solve the first-order nonlinear PDE

$$z_x \, z_y = 1 \qquad \text{where } z = z(x,y).$$

Let $p = z_x$, $q = z_y$. The PDE is $F(x,y,z,p,q) = pq - 1 = 0$.

### Charpit's equations

Since $F$ depends only on $p,q$:

$$F_p = q,\quad F_q = p,\quad F_x = F_y = F_z = 0.$$

The Charpit (Lagrange) system is

$$\frac{dx}{q} = \frac{dy}{p} = \frac{dz}{pF_p + qF_q} = \frac{dp}{-F_x - pF_z}
= \frac{dq}{-F_y - qF_z}.$$

Substituting:

$$\frac{dx}{q} = \frac{dy}{p} = \frac{dz}{2pq} = \frac{dp}{0} = \frac{dq}{0}.$$

Since $pq = 1$, the third ratio is $\frac{dz}{2}$.

### First integrals

From $\dfrac{dp}{0} = \dfrac{dq}{0}$: both $p$ and $q$ are constant along charac
teristics. Set

$$p = a \quad (\text{constant}), \qquad q = \frac{1}{a} \quad (\text{since } pq=
1).$$

Now $\dfrac{dx}{1/a} = \dfrac{dy}{a} = \dfrac{dz}{2}$, i.e. $a\,dx = \frac{1}{a}
\,dy$ and $dz = \frac{2}{q}\,dx = 2a\,dx$.

From $dz = p\,dx + q\,dy = a\,dx + \frac{1}{a}\,dy$, integrating directly:

$$\boxed{z = a\,x + \frac{y}{a} + b}$$

where $a \neq 0$ and $b$ are arbitrary constants. **Verification:** $z_x = a$, $
z_y = 1/a$, so $z_x z_y = 1$. ✓

This is the **complete integral** (two arbitrary constants).

### General integral

Set $b = \phi(a)$ for an arbitrary function $\phi$, and eliminate $a$ between

$$z = a\,x + \frac{y}{a} + \phi(a), \qquad \frac{\partial}{\partial a}\!\left[a\
,x + \frac{y}{a} + \phi(a)\right] = 0 \;\;\Longrightarrow\;\; x - \frac{y}{a^{2}
} + \phi'(a) = 0.$$

This gives the **general integral** (containing one arbitrary function $\phi$):

$$\boxed{z = a\,x + \frac{y}{a} + \phi(a), \qquad x - \frac{y}{a^{2}} + \phi'(a)
 = 0 \;\; (a \text{ eliminated}).}$$

### Singular integral

The envelope of the one-parameter family $z = a\,x + \dfrac{y}{a}$ (taking $\phi
 \equiv 0$) is obtained from

$$\frac{\partial z}{\partial a} = x - \frac{y}{a^{2}} = 0 \;\;\Longrightarrow\;\
; a^{2} = \frac{y}{x}, \quad a = \sqrt{\frac{y}{x}}.$$

Substituting back:

$$z = \sqrt{\frac{y}{x}}\cdot x + \frac{y}{\sqrt{y/x}} = \sqrt{xy} + \sqrt{xy} =
 2\sqrt{xy}.$$

**Verification:** $z_x = \sqrt{y/x}$, $z_y = \sqrt{x/y}$, so $z_x\,z_y = 1$. ✓

The **singular integral** is

$$\boxed{z = 2\sqrt{xy}.}$$

### Summary

| Type | Solution |
|------|----------|
| Complete integral | $z = a\,x + \dfrac{y}{a} + b$ |
| General integral | $z = a\,x + \dfrac{y}{a} + \phi(a)$, with $x - \dfrac{y}{a^
{2}} + \phi'(a) = 0$ ($a$ eliminated) |
| Singular integral | $z = 2\sqrt{xy}$ |
