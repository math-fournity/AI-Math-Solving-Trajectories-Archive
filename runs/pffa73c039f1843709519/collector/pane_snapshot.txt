## Proof

**Claim:** Not every Borel set is a countable union of intervals.

**Proof.** Consider the **Cantor set** $C \subset [0,1]$, constructed as the int
ersection $C = \bigcap_{n=0}^{\infty} C_n$, where $C_0 = [0,1]$ and $C_{n+1}$ is
 obtained from $C_n$ by removing the open middle third of each constituent inter
val.

**Step 1: $C$ is Borel.**
Each $C_n$ is a finite union of closed intervals, hence closed. The Cantor set $
C = \bigcap_{n=0}^{\infty} C_n$ is a countable intersection of closed sets, henc
e Borel (in fact, closed).

**Step 2: $C$ has Lebesgue measure zero.**
At stage $n$, the set $C_n$ consists of $2^n$ intervals, each of length $3^{-n}$
. Thus
$$m(C_n) = 2^n \cdot 3^{-n} = \left(\tfrac{2}{3}\right)^n \xrightarrow{n\to\inft
y} 0.$$
Since $C \subseteq C_n$ for every $n$, we have $m(C) \leq m(C_n)$ for every $n$,
 so $m(C) = 0$.

**Step 3: $C$ is uncountable.**
Every $x \in C$ admits a ternary expansion $x = \sum_{k=1}^{\infty} a_k 3^{-k}$
with each $a_k \in \{0, 2\}$ (the digits $1$ correspond to the removed middle th
irds). The map $C \to \{0,1\}^{\mathbb{N}}$ sending $x$ to the sequence $(a_k/2)
$ is a surjection onto $\{0,1\}^{\mathbb{N}}$, which has cardinality $2^{\aleph_
0}$. Hence $C$ is uncountable.

**Step 4: $C$ is not a countable union of intervals.**
Suppose for contradiction that $C = \bigcup_{n=1}^{\infty} I_n$, where each $I_n
$ is an interval (of any type: open, closed, half-open, degenerate, or empty). S
ince $I_n \subseteq C$ and $m(C) = 0$, every $I_n$ has Lebesgue measure zero. An
 interval in $\mathbb{R}$ with measure zero is either empty or a single point. T
herefore each $I_n$ contains at most one point, so
$$C = \bigcup_{n=1}^{\infty} I_n$$
is a countable union of singletons (and empty sets), hence countable. This contr
adicts Step 3, which says $C$ is uncountable.

**Conclusion.** The Cantor set $C$ is a Borel set that cannot be expressed as a
countable union of intervals. Therefore, **not every Borel set is a countable un
ion of intervals**. $\blacksquare$
