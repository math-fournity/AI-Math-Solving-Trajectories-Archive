## Solution

We compute $\int_{-\infty}^{\infty} |f(\xi)|^2\,d\xi$ where $f(\xi)=\int_0^1 \sq
rt{x}\sin(\xi x)\,dx$, using Plancherel's theorem.

**Fourier transform convention.** Let $\widehat{g}(\omega)=\int_{-\infty}^{\inft
y} g(\xi)\,e^{-i\omega\xi}\,d\xi$. Plancherel's formula gives
$$\int_{-\infty}^{\infty}|g(\xi)|^2\,d\xi=\frac{1}{2\pi}\int_{-\infty}^{\infty}|
\widehat{g}(\omega)|^2\,d\omega.$$

**Step 1: Express $f$ via a complex exponential.** Define
$$h(\xi)=\int_0^1 \sqrt{x}\,e^{i\xi x}\,dx.$$
Since $\sqrt{x}$ is real, $\overline{h(\xi)}=\int_0^1\sqrt{x}\,e^{-i\xi x}\,dx=h
(-\xi)$. Using $\sin(\xi x)=\frac{e^{i\xi x}-e^{-i\xi x}}{2i}$,
$$f(\xi)=\frac{h(\xi)-h(-\xi)}{2i}.$$

**Step 2: Compute $\widehat{h}(\omega)$.** Exchanging the order of integration (
formally justified by distribution theory):
$$\widehat{h}(\omega)=\int_{-\infty}^{\infty}\!\left(\int_0^1\sqrt{x}\,e^{i\xi x
}\,dx\right)e^{-i\omega\xi}\,d\xi=\int_0^1\sqrt{x}\!\left(\int_{-\infty}^{\infty
}e^{i\xi(x-\omega)}\,d\xi\right)dx.$$
Using $\int_{-\infty}^{\infty}e^{i\xi t}\,d\xi=2\pi\,\delta(t)$,
$$\widehat{h}(\omega)=2\pi\int_0^1\sqrt{x}\,\delta(x-\omega)\,dx=2\pi\sqrt{\omeg
a}\,\mathbf{1}_{[0,1]}(\omega).$$

**Step 3: Compute $\widehat{f}(\omega)$.**
$$\widehat{f}(\omega)=\frac{1}{2i}\bigl[\widehat{h}(\omega)-\widehat{h}(-\omega)
\bigr].$$
Now $\widehat{h}(-\omega)=2\pi\sqrt{-\omega}\,\mathbf{1}_{[0,1]}(-\omega)=2\pi\s
qrt{|\omega|}\,\mathbf{1}_{[-1,0]}(\omega)$, so

- For $\omega\in[0,1]$: $\widehat{f}(\omega)=\frac{2\pi\sqrt{\omega}}{2i}=-i\pi\
sqrt{\omega}$.
- For $\omega\in[-1,0]$: $\widehat{f}(\omega)=\frac{-2\pi\sqrt{|\omega|}}{2i}=i\
pi\sqrt{|\omega|}$.
- Otherwise: $\widehat{f}(\omega)=0$.

In all cases $|\widehat{f}(\omega)|^2=\pi^2|\omega|\cdot\mathbf{1}_{[-1,1]}(\ome
ga)$.

**Step 4: Apply Plancherel.**
$$\int_{-\infty}^{\infty}|f(\xi)|^2\,d\xi=\frac{1}{2\pi}\int_{-1}^{1}\pi^2|\omeg
a|\,d\omega=\frac{\pi}{2}\cdot 2\int_0^1\omega\,d\omega=\frac{\pi}{2}\cdot 2\cdo
t\frac{1}{2}=\boxed{\dfrac{\pi}{2}}.$$
