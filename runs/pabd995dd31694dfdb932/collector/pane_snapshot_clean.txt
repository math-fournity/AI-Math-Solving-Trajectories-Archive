## Solution

We evaluate $\displaystyle I = \int_{-\infty}^{\infty}\bigl(\cos^{2}x - 3\sec x\
bigr)\,\delta^{\prime\prime}(x)\,dx$ using the definition of the distributional
derivative.

### Distributional derivative definition

For the Dirac delta distribution, the distributional derivatives act on a test f
unction $\varphi$ by

$$\langle \delta', \varphi\rangle = -\varphi'(0), \qquad \langle \delta'', \varp
hi\rangle = \varphi''(0),$$

i.e., $\displaystyle\int_{-\infty}^{\infty}\varphi(x)\,\delta''(x)\,dx = \varphi
''(0)$, provided $\varphi$ is $C^{2}$ in a neighborhood of $0$.

### Smoothness check at $x=0$

Set $f(x) = \cos^{2}x - 3\sec x$. The only singularities of $f$ occur where $\co
s x = 0$, i.e. $x = \frac{\pi}{2}+k\pi$. At $x=0$, $\cos 0 = 1\neq 0$, so $f$ is
 $C^{\infty}$ near $0$. The formula applies.

### Compute $f''(0)$

First derivative:
$$f'(x) = -2\sin x\cos x - 3\sec x\tan x = -\sin 2x - 3\sec x\tan x.$$

Second derivative:
$$f''(x) = -2\cos 2x - 3\,\frac{d}{dx}(\sec x\tan x).$$

Using $\frac{d}{dx}(\sec x\tan x) = \sec x\tan^{2}x + \sec^{3}x$:

$$f''(x) = -2\cos 2x - 3\bigl(\sec x\tan^{2}x + \sec^{3}x\bigr).$$

Evaluate at $x=0$ using $\cos 0 = 1$, $\sec 0 = 1$, $\tan 0 = 0$:

$$f''(0) = -2\cdot 1 - 3\bigl(1\cdot 0 + 1\bigr) = -2 - 3 = -5.$$

### Result

$$\int_{-\infty}^{\infty}\bigl(\cos^{2}x - 3\sec x\bigr)\,\delta^{\prime\prime}(
x)\,dx = f''(0) = \boxed{-5}.$$
