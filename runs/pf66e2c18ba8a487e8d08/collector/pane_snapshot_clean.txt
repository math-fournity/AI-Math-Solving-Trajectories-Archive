## Proof

**Claim.** There exists an uncountable set $S$ of subsets of $\mathbb{N}$ such t
hat for any two distinct $A, B \in S$, either $A \subsetneq B$ or $B \subsetneq
A$.

**Construction.**

Since $\mathbb{Q}$ is countable, fix a bijection $f \colon \mathbb{N} \to \mathb
b{Q}$. For each real number $r \in \mathbb{R}$, define

$$A_r \;=\; \{\, n \in \mathbb{N} : f(n) < r \,\}.$$

Set $S = \{\, A_r : r \in \mathbb{R}\,\}$.

**$S$ is uncountable.** Suppose $A_r = A_s$ for $r, s \in \mathbb{R}$. If $r \ne
q s$, say $r < s$. By density of $\mathbb{Q}$ in $\mathbb{R}$, there exists $q \
in \mathbb{Q}$ with $r < q < s$. Let $n = f^{-1}(q)$. Then $f(n) = q > r$ so $n
\notin A_r$, but $f(n) = q < s$ so $n \in A_s$. This contradicts $A_r = A_s$. He
nce $r = s$, so the map $r \mapsto A_r$ is injective. Since $\mathbb{R}$ is unco
untable, $S$ is uncountable.

**$S$ is totally ordered by strict inclusion.** Let $A_r, A_s \in S$ with $r \ne
q s$. Without loss assume $r < s$.

- *$A_r \subseteq A_s$:* If $n \in A_r$ then $f(n) < r < s$, so $n \in A_s$.
- *$A_r \neq A_s$ (proper):* By density of $\mathbb{Q}$, pick $q \in \mathbb{Q}$
 with $r < q < s$, and let $n = f^{-1}(q)$. Then $n \notin A_r$ (since $q > r$)
but $n \in A_s$ (since $q < s$). So $A_r \subsetneq A_s$.

Therefore for any two distinct elements of $S$, one is a proper subset of the ot
her.

**Conclusion.** The set $S = \{A_r : r \in \mathbb{R}\}$ is an uncountable chain
 of subsets of $\mathbb{N}$ under inclusion. $\blacksquare$
