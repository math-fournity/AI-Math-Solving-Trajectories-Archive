## Proof

**The curve and its identity.** Consider $C \subset \mathbb{P}^2_K$ given by
$$F(X,Y,Z) = X^3 + Y^3 - AZ^3 = 0, \qquad A \in K^\times.$$
The point $O = (1:-1:0)$ lies on $C$ since $1 + (-1)^3 - 0 = 0$.

**Nonsingularity.** The partials are $F_X = 3X^2$, $F_Y = 3Y^2$, $F_Z = -3AZ^2$.
 They vanish simultaneously only at $(0:0:0)$, which is not a point of $\mathbb{
P}^2$. Hence $C$ is nonsingular (a smooth plane cubic), so it is an elliptic cur
ve with identity $O$.

**$O$ is a flex.** The tangent at $O$ is $F_X(O)X + F_Y(O)Y + F_Z(O)Z = 3X + 3Y
= 0$, i.e. $X + Y = 0$. Substituting $X = -Y$ into $F = 0$ gives $-AZ^3 = 0$, he
nce $Z = 0$ (as $A \neq 0$), so the tangent meets $C$ only at $O$, with contact
order $3$. Thus $O$ is a flex — as required for the identity of an elliptic curv
e in Weierstrass form.

**Birational transformation to Weierstrass form.** Work in the affine chart $Z =
 1$: $x^3 + y^3 = A$. Set
$$s = x + y, \qquad d = x - y, \qquad \text{so } x = \tfrac{s+d}{2},\; y = \tfra
c{s-d}{2}.$$
Using $x^3 + y^3 = (x+y)(x^2 - xy + y^2)$ and
$$x^2 - xy + y^2 = \tfrac{1}{4}(s^2 + 3d^2),$$
the equation becomes
$$s \cdot \tfrac{s^2 + 3d^2}{4} = A \;\;\Longrightarrow\;\; s^3 + 3s\,d^2 = 4A.
\tag{1}$$

Now define new coordinates
$$U = \frac{12A}{s}, \qquad V = \frac{36A\,d}{s},$$
so that $s = \frac{12A}{U}$ and $d = \frac{V}{3U}$. Substituting into (1):
$$\left(\frac{12A}{U}\right)^3 + 3\cdot\frac{12A}{U}\cdot\left(\frac{V}{3U}\righ
t)^2 = 4A$$
$$\frac{1728\,A^3}{U^3} + \frac{4A\,V^2}{U^3} = 4A.$$
Multiplying by $U^3$ and dividing by $4A \neq 0$:
$$V^2 = U^3 - 432\,A^2. \tag{2}$$

This is a (short) Weierstrass equation. The map $(x,y) \mapsto (U,V)$ is defined
 off the line $s = x+y = 0$ (the tangent at $O$), and its inverse $s = 12A/U$, $
d = V/(3U)$ is defined off $U = 0$; the point $O$ corresponds to the point at in
finity on (2). Thus $C$ is isomorphic (on nonsingular models) to the Weierstrass
 curve (2), so they share the same $j$-invariant.

**Computing the $j$-invariant.** Equation (2) is $V^2 = U^3 + aU + b$ with
$$a = 0, \qquad b = -432\,A^2.$$
The discriminant is
$$\Delta = -16(4a^3 + 27b^2) = -16 \cdot 27 \cdot (432)^2 A^4 \neq 0 \quad (\tex
t{since } A \neq 0),$$
confirming nonsingularity. The $j$-invariant is
$$j = 1728\,\frac{4a^3}{4a^3 + 27b^2} = 1728 \cdot \frac{0}{0 + 27(432)^2 A^4} =
 0.$$

Therefore the $j$-invariant of the elliptic curve $X^3 + Y^3 = AZ^3$ is $0$. $\b
lacksquare$
