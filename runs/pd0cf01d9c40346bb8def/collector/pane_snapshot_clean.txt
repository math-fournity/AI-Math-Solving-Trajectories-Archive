## Proof

We are given
$$D(s) = \sum_{n=1}^{\infty} \frac{e^{i\theta/n}}{n^s}, \qquad \zeta(s) = \sum_{
n=1}^{\infty} \frac{1}{n^s},$$
and seek $\lim_{s\to 1} D(s)/\zeta(s)$.

**Key observation.** Write
$$D(s) = \zeta(s) + \sum_{n=1}^{\infty} \frac{e^{i\theta/n}-1}{n^s} =: \zeta(s)
+ R(s).$$

We claim $R(s)$ converges (indeed, is analytic) at $s=1$.

**Convergence of $R(s)$ at $s=1$.** For each $n$,
$$e^{i\theta/n} - 1 = \frac{i\theta}{n} + O\!\left(\frac{1}{n^2}\right).$$
Hence
$$\left|e^{i\theta/n}-1\right| \le \frac{C}{n}$$
for some constant $C$ and all $n\ge 1$. Therefore
$$\sum_{n=1}^{\infty} \frac{|e^{i\theta/n}-1|}{n} \le C\sum_{n=1}^{\infty}\frac{
1}{n^2} < \infty.$$
So $R(1)=\sum_{n}(e^{i\theta/n}-1)/n$ converges absolutely. In fact, by comparis
on with $\sum 1/n^{1+\varepsilon}$, the series $R(s)$ converges absolutely for $
\Re(s)>0$, hence defines a continuous (indeed analytic) function in a neighborho
od of $s=1$.

**Computing the limit.** The Riemann zeta function has a simple pole at $s=1$:
$$\zeta(s) = \frac{1}{s-1} + \gamma + O(s-1) \quad (s\to 1).$$
Since $R(s)$ is continuous at $s=1$ with finite value $R(1)$,
$$D(s) = \zeta(s) + R(s) = \frac{1}{s-1} + \bigl(\gamma + R(1)\bigr) + O(s-1).$$
Thus
$$\frac{D(s)}{\zeta(s)} = \frac{\zeta(s)+R(s)}{\zeta(s)} = 1 + \frac{R(s)}{\zeta
(s)}.$$
As $s\to 1$, $R(s)\to R(1)<\infty$ while $\zeta(s)\to\infty$, so
$$\frac{R(s)}{\zeta(s)}\to 0.$$

Therefore
$$\boxed{\lim_{s\to 1}\frac{D(s)}{\zeta(s)} = 1}.$$
