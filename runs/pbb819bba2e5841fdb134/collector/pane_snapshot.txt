# Evaluation of the Nested Radical

## Problem

$$A = \sqrt{1 + 2\sqrt{1 + 3\sqrt{1 + 4\sqrt{1 + 5\sqrt{1 + \cdots}}}}}$$

## Answer

$$\boxed{A = 3}$$

## Proof

### Step 1: Algebraic Identity

For every integer $n \geq 1$:

$$\sqrt{1 + (n+1)(n+3)} = \sqrt{n^2 + 4n + 4} = n+2 \tag{1}$$

since $1 + (n+1)(n+3) = 1 + n^2 + 4n + 3 = (n+2)^2$.

### Step 2: Formal (Self-Consistent) Solution

Define $x_k = k+2$ for $k = 1, 2, 3, \ldots$ Then:

$$\sqrt{1 + (k+1)\,x_{k+1}} = \sqrt{1 + (k+1)(k+3)} \stackrel{(1)}{=} k+2 = x_k.
$$

So the sequence $\{x_k\}$ satisfies the exact recurrence $x_k = \sqrt{1+(k+1)\,x
_{k+1}}$ that defines the nested radical. The outermost value is $x_1 = 3$. It r
emains to show the infinite radical **converges** to this formal solution.

### Step 3: Finite Truncation and Convergence

Define the $N$-level truncation (terminal value $0$):

$$r_N = 0, \qquad r_k = \sqrt{1 + (k+1)\,r_{k+1}}, \quad k = N{-}1, \ldots, 1, \
qquad A_N = r_1.$$

**Normalization.** Set $s_k = r_k/(k+2)$ and $u_k = s_k - 1$ (so $u_k = 0$ is th
e exact solution). The recurrence becomes

$$s_k^2 = 1 + \alpha_k\,(s_{k+1}-1), \qquad \alpha_k := \frac{(k+1)(k+3)}{(k+2)^
2} = 1 - \frac{1}{(k+2)^2}, \tag{2}$$

equivalently $u_k(2+u_k) = \alpha_k\, u_{k+1}$, i.e.,

$$u_k = \frac{\alpha_k\, u_{k+1}}{2 + u_k}. \tag{3}$$

The terminal condition is $s_N = 0$, i.e., $u_N = -1$.

**Phase 1 — Recovery from $u \approx -1$.** When $s_{k+1}$ is small (near $0$),
Eq. (2) gives $s_k^2 \approx 1 - \alpha_k = 1/(k+2)^2$, so $s_k \approx 1/(k+2)$
. Iterating backward from the terminal, the exponent of $1/(k+2)$ **halves** at
each step:

$$s_{N-1} \sim (N{+}2)^{-1},\quad s_{N-2} \sim (N{+}2)^{-1/2},\quad s_{N-3} \sim
 (N{+}2)^{-1/4},\quad \ldots,\quad s_{N-m} \sim (N{+}2)^{-1/2^{m-1}}.$$

Choosing $m = \lceil \log_2 \ln(N{+}2)\rceil + 2 = O(\log\log N)$ levels, we obt
ain $s_{N-m} \geq \tfrac{1}{2}$, hence $u_{N-m} \geq -\tfrac{1}{2}$, with $|u_{N
-m}|$ bounded by an absolute constant.

**Phase 2 — Exponential contraction.** Once $u_k \geq -\tfrac{1}{2}$ (so $2 + u_
k \geq \tfrac{3}{2}$), Eq. (3) yields

$$|u_k| = \frac{\alpha_k\,|u_{k+1}|}{2+u_k} \leq \frac{2}{3}\,|u_{k+1}|. \tag{4}
$$

Applying (4) over the remaining $N - m = N - O(\log\log N)$ levels:

$$|u_1| \leq \left(\frac{2}{3}\right)^{N - O(\log\log N)}\cdot |u_{N-m}| \;\long
rightarrow\; 0 \quad \text{as } N \to \infty.$$

Therefore $A_N = r_1 = 3(1 + u_1) \to 3$.

### Step 4: Numerical Verification

With $N = 10$, $t = 0$: computing backward gives $A_{10} \approx 2.981$, already
 within $0.6\%$ of $3$. Larger $N$ converges rapidly, consistent with the super-
exponential decay established above.

### Conclusion

The nested radical converges, and its value is

$$A = \sqrt{1 + 2\sqrt{1 + 3\sqrt{1 + 4\sqrt{1 + 5\sqrt{1 + \cdots}}}}} = 3.$$
