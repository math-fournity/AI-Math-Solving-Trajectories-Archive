# Newton Step for the Barrier Function

## Setup

The function is
$$f(x) = -\sum_{i=1}^{n}\log(x_i+1) - \sum_{i=1}^{n}\log(1-x_i) - \sum_{i=1}^{m}
\log(b_i - a_i^T x).$$

Define the slack variables $s_i = b_i - a_i^T x$ for $i=1,\dots,m$, and let $A \
in \mathbb{R}^{m\times n}$ with rows $a_i^T$.

## Gradient and Hessian

**Gradient.** Differentiating term by term:
$$g_j = \frac{\partial f}{\partial x_j} = -\frac{1}{x_j+1} + \frac{1}{1-x_j} + \
sum_{i=1}^{m}\frac{a_{ij}}{s_i}.$$

In vector form: $g = -(\mathbf{1}+x)^{-1} + (\mathbf{1}-x)^{-1} + A^T s^{-1}$, w
here all inverses are componentwise.

**Hessian.** The box-constraint terms contribute a diagonal matrix; the linear i
nequality terms contribute $A^T D_s A$:
$$H = \nabla^2 f(x) = D + A^T D_s A,$$
where
$$D = \operatorname{diag}\!\left(\frac{1}{(1+x_j)^2} + \frac{1}{(1-x_j)^2}\right
)_{j=1}^{n}, \qquad D_s = \operatorname{diag}\!\left(\frac{1}{s_i^2}\right)_{i=1
}^{m}.$$

Both $D$ and $D_s$ are positive diagonal, so $H \succ 0$ on the domain.

## Newton Step

The Newton step is $\Delta x_{\text{nt}} = -H^{-1}g$, i.e., we solve
$$(D + A^T D_s A)\,\Delta x = -g. \tag{$\star$}$$

The cost depends on which dimension is larger. We distinguish two cases.

---

## Case 1: $m \geq n$ — Solve the $n\times n$ system directly

When $m \geq n$, the Hessian $H$ is $n\times n$ and $n$ is the smaller dimension
. We form $H$ and solve directly.

**Algorithm:**
1. Compute $D$ and $D_s$: $O(n + m)$.
2. Scale the rows of $A$ by $D_s$ to get $D_s A$: $O(mn)$.
3. Form $A^T(D_s A)$ (an $n\times n$ matrix): $O(mn^2)$.
4. Add the diagonal: $H = D + A^T D_s A$: $O(n)$.
5. Cholesky factorize $H = LL^T$: $O(n^3)$.
6. Solve $H\,\Delta x = -g$ by forward/back substitution: $O(n^2)$.

**Total cost:** $O(mn^2 + n^3) = O(mn^2)$ (since $m \geq n$).

---

## Case 2: $m \leq n$ — Reduce to an $m\times m$ system via the Schur complement

When $m \leq n$, forming the $n\times n$ Hessian and factorizing it costs $O(n^3
)$, which is wasteful. Instead we exploit the structure $H = D + A^T D_s A$ to r
educe to an $m\times m$ system.

Introduce the auxiliary variable $y = D_s A\,\Delta x \in \mathbb{R}^m$, so that
 $A\,\Delta x = D_s^{-1} y$ (note $D_s^{-1} = \operatorname{diag}(s_i^2)$). The
system ($\star$) splits into:

$$D\,\Delta x + A^T y = -g, \qquad A\,\Delta x = D_s^{-1} y.$$

From the first equation: $\Delta x = -D^{-1}(g + A^T y)$ (cheap since $D$ is dia
gonal).

Substituting into the second:
$$-A\,D^{-1}(g + A^T y) = D_s^{-1} y,$$
$$\bigl(A\,D^{-1}A^T + D_s^{-1}\bigr)\,y = -A\,D^{-1}\,g. \tag{$\star\star$}$$

This is an $m\times m$ positive-definite system (the Schur complement of $D$ in
$H$). Let $S = A\,D^{-1}A^T + D_s^{-1}$.

**Algorithm:**
1. Compute $D^{-1}$ and $D_s^{-1} = \operatorname{diag}(s^2)$: $O(n+m)$.
2. Form $A\,D^{-1}A^T$ (an $m\times m$ matrix): $O(m^2 n)$.
3. Form $S = A\,D^{-1}A^T + D_s^{-1}$: $O(m)$.
4. Compute $A\,D^{-1}g$: $O(mn)$.
5. Cholesky factorize $S = LL^T$: $O(m^3)$.
6. Solve $S\,y = -A\,D^{-1}g$: $O(m^2)$.
7. Recover $\Delta x = -D^{-1}(g + A^T y)$: $O(mn)$.

**Total cost:** $O(m^2 n + m^3) = O(m^2 n)$ (since $m \leq n$).

---

## Summary

| Case | Method | System size | Cost |
|------|--------|-------------|------|
| $m \geq n$ | Form $H = D + A^T D_s A$ directly, Cholesky, solve | $n \times n$
 | $O(mn^2)$ |
| $m \leq n$ | Schur complement: solve $m\times m$ system $(AD^{-1}A^T + D_s^{-1
})\,y = -AD^{-1}g$, then back-substitute | $m \times m$ | $O(m^2 n)$ |

In both cases the diagonal structure of $D$ and $D_s$ is exploited. The guiding
principle is: **always solve the linear system in the smaller dimension.** When
$m \geq n$ the Hessian is the smaller ($n\times n$) system, so we form and facto
rize it directly. When $m \leq n$, the Schur complement reduces the problem to t
he smaller ($m\times m$) system, avoiding the expensive $O(n^3)$ factorization.
