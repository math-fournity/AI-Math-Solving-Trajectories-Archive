# Problem

A specialized satellite network consists of 2013 communication beacons deployed into a single circular orbit. The deployment follows a rigorous logistical protocol:

The process begins by launching Beacon 1 into a fixed position. To place each subsequent beacon, a deployment drone travels at a constant altitude in a counterclockwise direction along the orbital path. The rule for deployment is as follows: every time the drone passes a beacon that has already been successfully installed, it must immediately release the next beacon into the empty orbital gap it just entered.

The drone continues this orbiting and dropping process until all 2013 beacons are positioned. Each beacon is assigned a permanent ID number $k$ corresponding to the order in which it was deployed (from $k=1$ to $k=2013$).

Once the final beacon, ID 2013, is locked into its position, technicians identify the ID numbers of the two beacons located immediately adjacent to it in the orbit. If these two ID numbers are $x$ and $y$, calculate the value of $x + y$.
