## Model

Label the circles $1, 2, \ldots, n$. Each coin lies on exactly two circles (an i
ntersection point of those two circles), so each coin corresponds to an unordere
d pair $\{i,j\}$. Each pair of circles gives exactly 2 intersection points, so t
here are $2\binom{n}{2} = n(n-1)$ coins total.

**Game rule restated:** If a player takes a coin on circles $\{i,j\}$, the next
player must take a coin on circles $\{k,l\}$ with $\{k,l\} \cap \{i,j\} = \empty
set$ — that is, the two edges must be **vertex-disjoint** in $K_n$.

## Key Observation

Since $n(n-1)$ is always even, if all coins are taken, player Y (moving second)
makes the last move and X loses. So **Y wins if the game always completes**, and
 Y also wins if X ever gets stuck. Y loses only if Y gets stuck.

## Y's Pairing Strategy for $n \geq 4$

I show Y can pair all coins into pairs on vertex-disjoint edges, guaranteeing Y
always has a legal response.

**Construction of the pairing:**

- **Even $n \geq 4$:** $K_n$ admits a 1-factorization into $n-1$ perfect matchin
gs $M_1, \ldots, M_{n-1}$. Each $M_s$ has $n/2 \geq 2$ pairwise vertex-disjoint
edges. Within each $M_s$, arrange the $n$ coins (2 per edge) cyclically and pair
 each coin with the coin from the next edge in the cycle. Every pair lies on two
 distinct, vertex-disjoint edges.

- **Odd $n \geq 5$:** $K_n$ decomposes into $n$ near-perfect matchings $M_1, \ld
ots, M_n$ (the round-robin tournament schedule), each with $(n-1)/2 \geq 2$ pair
wise vertex-disjoint edges. Apply the same cyclic pairing within each $M_s$.

In both cases, all $n(n-1)$ coins are paired, and each pair consists of coins on
 vertex-disjoint edges. (The construction requires $\geq 2$ edges per matching,
which holds exactly when $n \geq 4$.)

**The strategy:** Y fixes this pairing before the game. Whenever X takes coin $c
$ (on edge $e$), Y takes its paired coin $c'$ (on edge $e'$, vertex-disjoint fro
m $e$). This is always legal. Coin $c'$ is always available: since the pairing i
s a partition, $c'$ is paired only with $c$, and X took $c$ (not $c'$).

After Y takes $c'$ on edge $e'$, X must find a coin on an edge disjoint from $e'
$. If X cannot, X loses. If X can, X takes some coin $d$, and Y responds with $d
$'s pair. The game continues until all coins are exhausted (Y wins, since $n(n-1
)$ is even) or X gets stuck (Y wins).

Since Y **always** has a valid response, Y never gets stuck. The game is finite,
 so it must end with X unable to move. **Y wins for all $n \geq 4$.**

## X Wins for $n = 2$ and $n = 3$

- **$n = 2$:** The only edge is $\{1,2\}$ with 2 coins. X takes one. Y must take
 a coin on an edge disjoint from $\{1,2\}$, but no such edge exists. Y is stuck
immediately. X wins.

- **$n = 3$:** The edges are $\{1,2\}, \{1,3\}, \{2,3\}$. In $K_3$, every two ed
ges share a vertex, so no two edges are vertex-disjoint. X takes any coin; Y has
 no valid response. Y is stuck. X wins.
