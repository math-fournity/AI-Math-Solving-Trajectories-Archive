Looking at this problem, I need to find $\limsup_{n\to\infty} \frac{E_n}{n}$, wh
ere $E_n$ is the expected maximum cycle length (period length) of a uniformly ra
ndom function $f:[n]\to[n]$.

## Proof

**Interpretation.** For a function $f:[n]\to[n]$, the functional graph decompose
s into components, each containing a directed cycle with trees feeding into it.
The "period length" of an element $x\in[n]$ is the length of the cycle that the
orbit $x, f(x), f^2(x), \ldots$ eventually enters. The "maximum period length" o
f $f$ is $\max_{x\in[n]} \text{period}(x)$, which equals the **maximum cycle len
gth** in the functional graph of $f$.

**Key bound.** The maximum cycle length is at most the total number of cyclic po
ints (points lying on cycles). So:
$$E_n \leq E[C_n]$$
where $C_n$ is the number of cyclic points of a uniformly random function $f:[n]
\to[n]$.

**Computing $E[C_n]$.** A point $x\in[n]$ lies on a cycle of length exactly $k$
with probability:
$$P(x \text{ on a } k\text{-cycle}) = \frac{(n-1)!}{(n-k)!\, n^k}, \quad 1 \leq
k \leq n.$$
(This is the probability that $f(x), f^2(x), \ldots, f^{k-1}(x)$ are all distinc
t and different from $x$, and $f^k(x)=x$.) By linearity of expectation:
$$E[C_n] = \sum_{x=1}^{n} P(x \text{ is cyclic}) = n \sum_{k=1}^{n} \frac{(n-1)!
}{(n-k)!\, n^k} = \sum_{k=1}^{n} \frac{n!}{(n-k)!\, n^k}.$$

**Estimating the sum.** Write $a_k = \frac{n!}{(n-k)!\, n^k} = \prod_{j=0}^{k-1}
\left(1 - \frac{j}{n}\right)$. Using $1-t \leq e^{-t}$:
$$a_k \leq \prod_{j=0}^{k-1} e^{-j/n} = e^{-k(k-1)/(2n)}.$$

For $k \geq 2$, we have $k(k-1) \geq k^2/2$, so $a_k \leq e^{-k^2/(4n)}$. Theref
ore:
$$E[C_n] \leq 1 + \sum_{k=2}^{n} e^{-k^2/(4n)} \leq 1 + \sum_{k=1}^{\infty} e^{-
k^2/(4n)} \leq 1 + \int_0^{\infty} e^{-x^2/(4n)}\,dx = 1 + \sqrt{\pi n}.$$

Thus $E[C_n] = O(\sqrt{n})$.

**Conclusion.** Since $E_n \leq E[C_n] = O(\sqrt{n})$:
$$\frac{E_n}{n} \leq \frac{C\sqrt{n}}{n} = \frac{C}{\sqrt{n}} \to 0 \quad \text{
as } n\to\infty.$$

Since $E_n \geq 0$, we have $\frac{E_n}{n} \geq 0$, so by the squeeze theorem:
$$\lim_{n\to\infty} \frac{E_n}{n} = 0,$$
and in particular:
$$\limsup_{n\to\infty} \frac{E_n}{n} = 0.$$
