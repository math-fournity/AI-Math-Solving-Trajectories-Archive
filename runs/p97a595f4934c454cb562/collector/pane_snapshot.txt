\pi i \mathbb{Z}$ is discrete, $f_1$ is constant. ✗

**Impossibility for $n = 2$.** Suppose $e^{f_1} + e^{f_2} = 1$ with $f_1, f_2$ e
ntire. Set $g = e^{f_1}$. Then:
- $g$ is entire and **never zero** (it is an exponential).
- $1 - g = e^{f_2}$ is also **never zero**, so $g$ never takes the value $1$.

Thus $g$ is an entire function omitting both $0$ and $1$. By **Picard's little t
heorem**, an entire function omitting two distinct values is constant. So $g$ is
 constant, forcing $f_1$ and $f_2$ both constant. ✗
