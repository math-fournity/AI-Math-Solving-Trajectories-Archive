## Solution

We evaluate
$$S = \sum_{n=0}^{\infty} \arctan\!\left(\frac{1}{n^2+n+1}\right).$$

**Key observation.** Note that $n^2+n+1 = n(n+1)+1$. We use the subtraction iden
tity for arctangent:
$$\arctan a - \arctan b = \arctan\!\left(\frac{a-b}{1+ab}\right), \qquad ab>-1.$
$

Set $a = \tfrac{1}{n}$ and $b = \tfrac{1}{n+1}$ (valid for $n \geq 1$). Then $ab
 = \tfrac{1}{n(n+1)} > -1$, and
$$\frac{a-b}{1+ab} = \frac{\frac{1}{n}-\frac{1}{n+1}}{1+\frac{1}{n(n+1)}} = \fra
c{\frac{1}{n(n+1)}}{\frac{n(n+1)+1}{n(n+1)}} = \frac{1}{n(n+1)+1} = \frac{1}{n^2
+n+1}.$$

Since $a>b>0$, the difference $\arctan a - \arctan b \in (0,\pi/2)$, so there is
 no branch ambiguity. Thus, for every $n \geq 1$,
$$\arctan\!\left(\frac{1}{n^2+n+1}\right) = \arctan\!\frac{1}{n} - \arctan\!\fra
c{1}{n+1}.$$

**The $n=0$ term.** This must be handled separately since $a=\tfrac{1}{0}$ is un
defined:
$$\arctan\!\left(\frac{1}{0^2+0+1}\right) = \arctan 1 = \frac{\pi}{4}.$$

**Telescoping.** For $N \geq 1$,
$$\sum_{n=1}^{N} \arctan\!\left(\frac{1}{n^2+n+1}\right) = \sum_{n=1}^{N}\left(\
arctan\frac{1}{n} - \arctan\frac{1}{n+1}\right) = \arctan 1 - \arctan\frac{1}{N+
1}.$$

Taking $N \to \infty$, since $\arctan\tfrac{1}{N+1} \to 0$,
$$\sum_{n=1}^{\infty} \arctan\!\left(\frac{1}{n^2+n+1}\right) = \arctan 1 = \fra
c{\pi}{4}.$$

**Combining.**
$$S = \underbrace{\arctan 1}_{n=0} + \sum_{n=1}^{\infty} \arctan\!\left(\frac{1}
{n^2+n+1}\right) = \frac{\pi}{4} + \frac{\pi}{4} = \boxed{\frac{\pi}{2}}.$$
