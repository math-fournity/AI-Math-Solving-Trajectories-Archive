## Structural Analysis

Label bins and parcels $1, \ldots, n$, where parcel $i$ is assigned to bin $i$.

**Claim (Cycle Structure):** The resulting placement permutation is either the i
dentity, or a single cycle containing element 1, with all other elements fixed.

*Proof.* If parcel 1 → bin 1, every subsequent parcel $i \geq 2$ finds bin $i$ e
mpty and is placed correctly — the identity.

If parcel 1 → bin $c_1 \neq 1$: bin $c_1$ is occupied, bin 1 is empty. Any parce
l $j$ (with $j \neq c_1, j \neq 1$) processed before parcel $c_1$ finds bin $j$
empty (only bin $c_1$ and correctly-filled bins are occupied), so it is placed c
orrectly. When parcel $c_1$ is processed, bin $c_1$ is occupied, so it is sent t
o a uniformly random empty bin. The empty bins at that moment are exactly **bin
1** and the bins of all not-yet-processed parcels (which all have index $> c_1$)
. If parcel $c_1$ → bin 1, the cycle $(1, c_1)$ closes and all remaining parcels
 go correctly. If parcel $c_1$ → bin $c_2$ with $c_2 > c_1$, the chain extends.
By induction the chain is $1 \to c_1 \to c_2 \to \cdots$ with $c_1 < c_2 < \cdot
s$, closing when some displaced parcel lands in bin 1. Every parcel not on the c
hain is placed correctly. ∎

So the number of misplaced parcels equals the cycle length $L$ when $L \geq 2$,
and $0$ when $L = 1$ (identity). Thus

$$E[\text{wrong}] = E[L] - P(L=1) = E[L] - \tfrac{1}{n}.$$

## Recursion

Define $g(m)$ = expected number of *additional* elements added to the cycle when
 a displaced parcel (already counted) is about to choose among $m$ empty bins, o
ne of which is bin 1 (the "closing" bin). Label the empty bins by position $1, 2
, \ldots, m$, where position 1 = bin 1. The displaced parcel picks uniformly:

- Position 1 (prob $1/m$): cycle closes, contributes $0$.
- Position $k \geq 2$ (prob $1/m$): displaces a new parcel (contributes $1$), th
en continues with $m - k + 1$ empty bins.

Setting $j = m - k + 1$ (so $j$ runs from $1$ to $m-1$):

$$g(m) = \frac{1}{m}\sum_{j=1}^{m-1}\bigl(1 + g(j)\bigr) = \frac{m-1}{m} + \frac
{1}{m}\sum_{j=1}^{m-1} g(j), \qquad g(1) = 0.$$

**Relating $E[L]$ to $g$:** Parcel 1 chooses among $n$ bins. If bin 1 (prob $1/n
$): $L = 1$. If position $k \geq 2$ (prob $1/n$): $L = 2 + g(n-k+1)$. Hence

$$E[L] = \frac{1}{n} + \frac{1}{n}\sum_{k=2}^{n}\bigl(2 + g(n-k+1)\bigr) = \frac
{2n-1}{n} + \frac{1}{n}\sum_{j=1}^{n-1} g(j) = 1 + g(n),$$

since $g(n) = \frac{n-1}{n} + \frac{1}{n}\sum_{j=1}^{n-1} g(j)$, giving $E[L] =
1 + g(n)$.

## Solving the Recursion

From $m\,g(m) = (m-1) + \sum_{j=1}^{m-1} g(j)$ and $(m-1)\,g(m-1) = (m-2) + \sum
_{j=1}^{m-2} g(j)$, subtracting:

$$m\,g(m) - (m-1)\,g(m-1) = 1 + g(m-1),$$

$$m\,g(m) = m\,g(m-1) + 1 \implies g(m) = g(m-1) + \frac{1}{m}.$$

With $g(1) = 0$:

$$g(m) = \sum_{i=2}^{m} \frac{1}{i} = H_m - 1.$$

## Final Computation

$$E[\text{wrong}] = E[L] - \frac{1}{n} = 1 + g(n) - \frac{1}{n} = 1 + H_n - 1 -
\frac{1}{n} = H_n - \frac{1}{n} = H_{n-1}.$$

**Verification on small cases:**
- $n = 1$: $H_0 = 0$. ✓ (sole parcel must go to sole bin)
- $n = 2$: $H_1 = 1$. ✓ (parcel 1 wrong with prob $1/2$, forcing both wrong: $\f
rac{1}{2}\cdot 2 = 1$)
- $n = 3$: $H_2 = \frac{3}{2}$. ✓ (direct enumeration gives $\frac{3}{2}$)

## Result

The expected number of parcels stored in wrong bins is

$$\boxed{H_{n-1} \;=\; \sum_{k=1}^{n-1} \frac{1}{k}}$$

the $(n-1)$-th harmonic number.
