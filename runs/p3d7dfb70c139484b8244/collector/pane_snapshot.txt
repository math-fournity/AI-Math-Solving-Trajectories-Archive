## Solution

**Compute $I$:**

$$I = \int_0^\infty x^{1/2} e^{-x^3}\,dx.$$

Substitute $u = x^3$, so $x = u^{1/3}$, $dx = \tfrac{1}{3}u^{-2/3}\,du$, and $x^
{1/2} = u^{1/6}$. Then

$$I = \int_0^\infty u^{1/6} e^{-u}\cdot \tfrac{1}{3}u^{-2/3}\,du = \frac{1}{3}\i
nt_0^\infty u^{-1/2}e^{-u}\,du = \frac{1}{3}\Gamma\!\left(\tfrac{1}{2}\right) =
\frac{\sqrt{\pi}}{3}.$$

**Compute $J$:**

$$J = \int_0^1 x^{-2/3}(1-x)^{-1/3}\,dx.$$

This is the Beta integral $B(a,b)=\int_0^1 t^{a-1}(1-t)^{b-1}\,dt$ with $a-1=-\t
frac{2}{3}$ (so $a=\tfrac{1}{3}$) and $b-1=-\tfrac{1}{3}$ (so $b=\tfrac{2}{3}$):

$$J = B\!\left(\tfrac{1}{3},\tfrac{2}{3}\right) = \frac{\Gamma(\tfrac{1}{3})\,\G
amma(\tfrac{2}{3})}{\Gamma(1)} = \Gamma\!\left(\tfrac{1}{3}\right)\Gamma\!\left(
\tfrac{2}{3}\right).$$

By the reflection formula $\Gamma(z)\Gamma(1-z)=\dfrac{\pi}{\sin(\pi z)}$ with $
z=\tfrac{1}{3}$:

$$\Gamma\!\left(\tfrac{1}{3}\right)\Gamma\!\left(\tfrac{2}{3}\right) = \frac{\pi
}{\sin(\pi/3)} = \frac{\pi}{\sqrt{3}/2} = \frac{2\pi}{\sqrt{3}}.$$

Hence $J = \dfrac{2\pi}{\sqrt{3}}$.

**Compute the ratio:**

$$\frac{J}{I} = \frac{\,2\pi/\sqrt{3}\,}{\,\sqrt{\pi}/3\,} = \frac{2\pi}{\sqrt{3
}}\cdot\frac{3}{\sqrt{\pi}} = \frac{6\pi}{\sqrt{3}\,\sqrt{\pi}} = \frac{6\pi}{\s
qrt{3\pi}} = \frac{6\sqrt{\pi}\cdot\sqrt{\pi}}{\sqrt{3}\,\sqrt{\pi}} = \frac{6\s
qrt{\pi}}{\sqrt{3}} = 2\sqrt{3}\,\sqrt{\pi} = 2\sqrt{3\pi}.$$

$$\boxed{\dfrac{J}{I} = 2\sqrt{3\pi}\,.}$$
