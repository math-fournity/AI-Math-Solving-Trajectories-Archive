Looking at this problem, I need to find the largest value guaranteed: no matter
how 5 subsets of size 500 are chosen from {1,...,1000}, there must exist three w
ith at least that many common elements. Equivalently, I minimize over all config
urations the maximum triple intersection.

## Proof

**Setup.** For each element $x \in \{1,\dots,1000\}$, let $d(x)$ be the number o
f sets $A_i$ containing $x$. Then:
$$\sum_{x} d(x) = \sum_{i=1}^{5} |A_i| = 5 \cdot 500 = 2500,$$
so the average degree is $2500/1000 = 2.5$.

**Lower bound via counting.** Consider the sum over all $\binom{5}{3}=10$ triple
s:
$$S = \sum_{\{i,j,k\}} |A_i \cap A_j \cap A_k| = \sum_{x} \binom{d(x)}{3}.$$

The function $f(d) = \binom{d}{3}$ is convex (its second differences $0,1,2,3,4,
\dots$ are non-negative). By convexity, with 1000 non-negative integers $d(x)$ s
umming to 2500, the sum $\sum f(d(x))$ is minimized when the $d(x)$ are as equal
 as possible, i.e., 500 values equal to 2 and 500 values equal to 3. This gives:
$$S \ge 500\binom{2}{3} + 500\binom{3}{3} = 0 + 500 = 500.$$

Since there are 10 triples, by averaging, some triple has intersection at least
$S/10 \ge 50$.

**Construction achieving 50.** Consider the 10 two-element subsets and 10 three-
element subsets of $\{1,2,3,4,5\}$. Assign 50 distinct elements to each two-elem
ent pattern and 50 distinct elements to each three-element pattern (using all $1
0\cdot 50 + 10\cdot 50 = 1000$ elements). Define $A_i$ as the set of all element
s whose pattern contains $i$.

- **Size check:** $A_i$ contains elements from the $\binom{4}{1}=4$ pair-pattern
s through $i$ ($4\cdot 50=200$) plus the $\binom{4}{2}=6$ triple-patterns throug
h $i$ ($6\cdot 50=300$), giving $|A_i|=500$. ✓

- **Triple intersection:** For any triple $\{i,j,k\}$, the elements in all three
 sets are exactly those assigned to the single pattern $\{i,j,k\}$ (no pair-patt
ern contains all three indices), giving $|A_i\cap A_j\cap A_k| = 50$. ✓

Every triple intersection equals exactly 50, so the maximum triple intersection
is 50.

**Conclusion.** The lower bound shows every configuration has some triple with i
ntersection $\ge 50$, and the construction shows 50 is achievable. Therefore the
 answer is $\boxed{50}$.
