## Solution

**Setup.** Given $a_0 = \frac{2M+1}{2} = M + \tfrac{1}{2}$, so $\lfloor a_0 \rfl
oor = M$ and
$$a_1 = a_0 \cdot M = M^2 + \tfrac{M}{2}.$$

**Key observation.** If $a_k = n + \tfrac{1}{2}$ for some integer $n$, then $\lf
loor a_k \rfloor = n$ and
$$a_{k+1} = \left(n + \tfrac{1}{2}\right)n = n^2 + \tfrac{n}{2}.$$
- If $n$ is **even**, then $n^2 + n/2$ is an integer → **stable**.
- If $n$ is **odd**, write $n/2 = (n-1)/2 + 1/2$, so $a_{k+1} = \bigl(n^2 + (n-1
)/2\bigr) + \tfrac{1}{2}$, which is again of the form $n_{k+1} + \tfrac{1}{2}$ w
ith $n_{k+1} = n^2 + (n-1)/2$.

So the sequence of integer parts follows the map $f(n) = n^2 + (n-1)/2$ as long
as $n$ stays odd, and stability is reached as soon as some $n_k$ is even.

**2-adic analysis.** For odd $n > 1$, let $t = v_2(n-1) \ge 1$ (the 2-adic valua
tion of $n-1$). Write $n = 1 + 2^t q$ with $q$ odd. Then:
$$f(n) - 1 = n^2 + \frac{n-1}{2} - 1 = (n-1)\!\left(n + \frac{1}{2}\right) - 1 +
 1 = \cdots$$

More directly:
$$f(n) - 1 = n^2 - 1 + \frac{n-1}{2} = (n-1)\!\left(n+1+\tfrac{1}{2}\right) = (n
-1)\cdot\frac{2n+3}{2}.$$

Since $n$ is odd, $2n+3$ is odd, so $v_2(2n+3) = 0$, and $\frac{2n+3}{2}$ has $v
_2 = -1$. Therefore:
$$v_2(f(n)-1) = v_2(n-1) + v_2\!\left(\tfrac{2n+3}{2}\right) = t - 1.$$

**This is the crucial result:** each application of $f$ reduces $v_2(n-1)$ by ex
actly 1.

**Consequence.** Starting from $n_0 = M$ (odd, $M > 1$), we have $v_2(M - 1) = t
 < \infty$. After $t$ steps, $v_2(n_t - 1) = 0$, meaning $n_t - 1$ is odd, i.e.,
 $n_t$ is **even** → the concentration becomes an integer → **stable**.

**The exceptional case $M = 1$:** Here $n_0 = 1$, $v_2(0) = \infty$, and $f(1) =
 1^2 + 0 = 1$. The sequence is fixed at $n_k = 1$ forever, giving $a_k = 3/2$ fo
r all $k$ — never an integer. So $M = 1$ is **not stable**.

**Verification of examples:**
- $M=2$: $a_0=5/2$, $a_1 = 5/2 \cdot 2 = 5$ ✓ (integer)
- $M=3$: $a_0=7/2$, $a_1=21/2$, $\lfloor\cdot\rfloor=10$, $a_2=21/2\cdot10=105$
✓
- $M=5$: $v_2(4)=2$; $n_1=27$ ($v_2(26)=1$), $n_2=742$ (even) ✓
- $M=9$: $v_2(8)=3$; levels $3\to2\to1\to0$ (even) ✓

**Conclusion.** $M$ is stable if and only if $M \neq 1$. Therefore:
$$S \cap [1,100] = \{2, 3, 4, \ldots, 100\},$$
$$\sum_{M \in S,\, 1\le M\le 100} M = \sum_{M=2}^{100} M = \frac{100\cdot101}{2}
 - 1 = 5050 - 1 = \boxed{5049}.$$

### PROOF COMPLETE
