# Leading Asymptotic Behavior of Ai(x) as x → +∞

## 1. Integral Representation

The Airy function admits the contour-integral representation

$$Ai(x) = \frac{1}{2\pi i}\int_C \exp\!\Bigl(\tfrac{t^3}{3}-xt\Bigr)\,dt,$$

where $C$ runs from $e^{-i\pi/3}\infty$ to $e^{i\pi/3}\infty$.

## 2. Scaling Out the Large Parameter

Set $t = \sqrt{x}\,u$, $dt = \sqrt{x}\,du$. Then

$$\tfrac{t^3}{3}-xt = x^{3/2}\Bigl(\tfrac{u^3}{3}-u\Bigr),$$

so with the **large parameter** $\lambda := x^{3/2}\to\infty$ and phase $\phi(u)
=u^3/3-u$,

$$Ai(x)=\frac{\sqrt{x}}{2\pi i}\int_{C'} e^{\lambda\phi(u)}\,du.$$

## 3. Locating the Saddle Points

$$\phi'(u)=u^2-1=0 \;\Longrightarrow\; u=\pm 1.$$

Values at the saddles:
- $\phi(1)=\tfrac13-1=-\tfrac23$,
- $\phi(-1)=-\tfrac13+1=+\tfrac23$.

Since $Ai(x)\to 0$ exponentially as $x\to+\infty$, only the saddle $u_0=1$ (with
 $\operatorname{Re}\phi<0$) contributes. The second derivative is

$$\phi''(u)=2u,\qquad \phi''(1)=2.$$

## 4. Steepest-Descent Direction

Write $u=1+s$. Then

$$\phi(1+s)=-\tfrac23+s^2+\tfrac{s^3}{3}.$$

For steepest descent we need $\operatorname{Re}(\lambda s^2)<0$ with $\operatorn
ame{Im}(\lambda s^2)=0$. Since $\lambda>0$ is real, this requires $s^2\in\mathbb
 R_{<0}$, i.e. $s=iy$, $y\in\mathbb R$, giving $ds=i\,dy$ and $\lambda s^2=-\lam
bda y^2$.

**Consistency with the contour.** The steepest-descent path through $u_0=1$ is $
\operatorname{Im}\phi=\operatorname{Im}\phi(1)=0$. Writing $u=a+ib$,

$$\operatorname{Im}\phi = b\Bigl(a^2-\tfrac{b^2}{3}-1\Bigr)=0 \;\Longrightarrow\
; a^2-\tfrac{b^2}{3}=1.$$

As $b\to+\infty$: $u\sim \tfrac{2b}{\sqrt3}e^{i\pi/3}$; as $b\to-\infty$: $u\sim
 \tfrac{2|b|}{\sqrt3}e^{-i\pi/3}$. Thus the steepest-descent path runs from $e^{
-i\pi/3}\infty$ to $e^{i\pi/3}\infty$ — exactly the original contour $C'$. Hence
 $C'$ deforms onto this path with no additional saddle contributions.

## 5. Gaussian Evaluation

On the steepest-descent path,

$$\int_{C'} e^{\lambda\phi(u)}\,du \sim e^{-2\lambda/3}\int e^{\lambda s^2}\,ds
= e^{-2\lambda/3}\,i\int_{-\infty}^{\infty}e^{-\lambda y^2}\,dy = e^{-2\lambda/3
}\,i\sqrt{\frac{\pi}{\lambda}}.$$

## 6. Assembling the Result

$$Ai(x)\sim \frac{\sqrt{x}}{2\pi i}\,e^{-2\lambda/3}\,i\sqrt{\frac{\pi}{\lambda}
} = \frac{\sqrt{x}}{2\pi}\sqrt{\frac{\pi}{\lambda}}\,e^{-2\lambda/3}.$$

Substituting $\lambda=x^{3/2}$:

$$Ai(x)\sim \frac{1}{2\pi}\sqrt{\pi}\,\frac{\sqrt{x}}{x^{3/4}}\,e^{-\frac{2}{3}x
^{3/2}} = \frac{1}{2\sqrt{\pi}}\,x^{1/2-3/4}\,e^{-\frac{2}{3}x^{3/2}}.$$

Therefore

$$\boxed{\,Ai(x)\sim \frac{1}{2\sqrt{\pi}\,x^{1/4}}\,\exp\!\Bigl(-\tfrac{2}{3}x^
{3/2}\Bigr),\qquad x\to+\infty.\,}$$
