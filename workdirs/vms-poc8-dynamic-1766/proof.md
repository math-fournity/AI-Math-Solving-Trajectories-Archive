# 求解 $1 + 2^x + 2^{2x+1} = y^2$ 的所有整数对 $(x, y)$

## 结论

所有满足方程的整数对为：

$$\boxed{(x, y) \in \{(0, 2),\; (0, -2),\; (4, 23),\; (4, -23)\}}$$

---

## 证明

### 第一步：$x \geq 0$

若 $x < 0$，则 $2^x$ 不是整数，左端 $1 + 2^x + 2^{2x+1}$ 不是整数，不可能等于整数 $y^2$。故 $x \geq 0$。

### 第二步：小情形直接验证

- $x = 0$：$1 + 1 + 2 = 4 = 2^2$，故 $y = \pm 2$。✓
- $x = 1$：$1 + 2 + 8 = 11$，不是完全平方数。
- $x = 2$：$1 + 4 + 32 = 37$，不是完全平方数。

### 第三步：$x \geq 3$ 时 $y$ 为奇数

对 $x \geq 1$，$2^x$ 与 $2^{2x+1}$ 均为偶数，故 $y^2 = 1 + \text{偶} + \text{偶}$ 为奇数，从而 $y$ 为奇数。

### 第四步：因式分解与 2-adic 赋值分析

对 $x \geq 3$，$y$ 为奇数，将方程改写为：

$$y^2 - 1 = 2^x + 2^{2x+1} = 2^x\!\left(1 + 2^{x+1}\right)$$

即

$$(y - 1)(y + 1) = 2^x\!\left(1 + 2^{x+1}\right). \tag{$\star$}$$

由于 $y$ 为奇数，$y - 1$ 与 $y + 1$ 均为偶数，且 $\gcd(y-1,\, y+1) \mid 2$（因它们的差为 $2$），故 $\gcd(y-1,\, y+1) = 2$。

令

$$y - 1 = 2a, \qquad y + 1 = 2b,$$

则 $b = a + 1$，$\gcd(a, b) = 1$（连续整数），且方程 $(\star)$ 变为

$$4ab = 2^x\!\left(1 + 2^{x+1}\right) \implies ab = 2^{x-2}\!\left(1 + 2^{x+1}\right). \tag{$\star\star$}$$

注意 $1 + 2^{x+1}$ 为**奇数**。由于 $\gcd(a, b) = 1$，$2$ 的全部幂次 $2^{x-2}$ 只能分配给 $a, b$ 中的一个。记 $w = 2^{x-2}$（$w \geq 2$），分两种情形。

---

### 情形 B：$b = wv,\; a = u$（$u, v$ 为奇数）

此时 $uv = 1 + 2^{x+1} = 1 + 8w$，且由 $b = a + 1$ 得 $wv = u + 1$，即 $u = wv - 1$。代入：

$$v(wv - 1) = 1 + 8w \implies wv^2 - v = 1 + 8w \implies w(v^2 - 8) = v + 1.$$

因此

$$w = \frac{v + 1}{v^2 - 8}. \tag{1}$$

**约束 $w \geq 2$ 给出 $v$ 的上界。** 由 $w \geq 2$：

$$v + 1 \geq 2(v^2 - 8) \implies 2v^2 - v - 17 \leq 0 \implies v \leq \frac{1 + \sqrt{137}}{4} \approx 3.18.$$

又 $v$ 为正奇数且 $v^2 - 8 > 0$（否则 $w \leq 0$），故 $v \geq 3$。因此 **$v = 3$** 是唯一可能。

代入 (1)：$w = \dfrac{4}{9 - 8} = 4$，故 $x - 2 = 2$，$x = 4$。

此时 $u = 4 \cdot 3 - 1 = 11$，$y = 2b - 1 = 2wv - 1 = 23$。

验证：$1 + 2^4 + 2^9 = 1 + 16 + 512 = 529 = 23^2$。✓

---

### 情形 A：$a = wu,\; b = v$（$u, v$ 为奇数）

此时 $uv = 1 + 8w$，且 $v = wu + 1$。代入：

$$u(wu + 1) = 1 + 8w \implies wu^2 + u = 1 + 8w \implies w(u^2 - 8) = 1 - u.$$

因此

$$w = \frac{1 - u}{u^2 - 8}. \tag{2}$$

**要求 $w \geq 2$（正整数）。** 分析 $w > 0$ 的条件：分子 $1 - u$ 与分母 $u^2 - 8$ 同号。

- **$u \geq 3$（奇数）**：$1 - u < 0$，$u^2 - 8 > 0$，异号，$w < 0$。不行。
- **$u = 1$**：$w = 0$。不行。
- **$u = -1$**：$w = 2 / (-7) < 0$。不行。
- **$u \leq -3$（奇数）**：$1 - u > 0$，$u^2 - 8 > 0$，同号，$w > 0$。✓

对 $u \leq -3$，令 $n = |u| \geq 3$（奇数），则

$$w = \frac{n + 1}{n^2 - 8}.$$

要求 $w \geq 2$：

$$n + 1 \geq 2(n^2 - 8) \implies 2n^2 - n - 17 \leq 0 \implies n \leq \frac{1 + \sqrt{137}}{4} \approx 3.18.$$

故 $n \leq 3$，即 $n = 3$，$u = -3$ 是唯一可能。

代入 (2)：$w = \dfrac{4}{9 - 8} = 4$，故 $x = 4$。

此时 $y = 2a + 1 = 2wu + 1 = 2 \cdot 4 \cdot (-3) + 1 = -23$。

验证：$(-23)^2 = 529 = 1 + 16 + 512$。✓

---

### 第五步：汇总

| $x$ | $y$ | 验证 |
|-----|-----|------|
| $0$ | $\pm 2$ | $1 + 1 + 2 = 4 = (\pm 2)^2$ ✓ |
| $4$ | $\pm 23$ | $1 + 16 + 512 = 529 = (\pm 23)^2$ ✓ |

- $x = 1, 2$：直接计算无解。
- $x \geq 3$：通过 2-adic 赋值分析，情形 B 唯一给出 $(x, y) = (4, 23)$，情形 A 唯一给出 $(x, y) = (4, -23)$。

因此，方程 $1 + 2^x + 2^{2x+1} = y^2$ 的全部整数解为

$$(x, y) \in \{(0, 2),\; (0, -2),\; (4, 23),\; (4, -23)\}.$$

**证毕.** $\blacksquare$
