## Proof

We solve the Fredholm integral equation of the second kind
$$u(x) + \int_0^{2\pi} \cos(x+t)\,u(t)\,dt = (\pi+1)\cos x.$$

**Step 1: Decompose the kernel.** Using the addition formula
$$\cos(x+t) = \cos x\cos t - \sin x\sin t,$$
the integral becomes
$$\int_0^{2\pi}\cos(x+t)\,u(t)\,dt = \cos x\int_0^{2\pi}\cos t\,u(t)\,dt - \sin
x\int_0^{2\pi}\sin t\,u(t)\,dt.$$

Introduce the constants
$$A = \int_0^{2\pi}\cos t\,u(t)\,dt, \qquad B = \int_0^{2\pi}\sin t\,u(t)\,dt.$$

The equation then reduces to
$$u(x) + A\cos x - B\sin x = (\pi+1)\cos x,$$
hence
$$u(x) = (\pi+1-A)\cos x + B\sin x. \tag{$\ast$}$$

**Step 2: Determine $A$.** Multiplying $(\ast)$ by $\cos t$ and integrating over
 $[0,2\pi]$:
$$A = \int_0^{2\pi}\cos t\,u(t)\,dt = (\pi+1-A)\int_0^{2\pi}\cos^2 t\,dt + B\int
_0^{2\pi}\cos t\,\sin t\,dt.$$

Using $\int_0^{2\pi}\cos^2 t\,dt = \pi$ and $\int_0^{2\pi}\cos t\sin t\,dt = 0$:
$$A = \pi(\pi+1-A).$$

Solving: $A = \pi^2+\pi-\pi A$, so $A(1+\pi)=\pi(1+\pi)$, giving
$$A = \pi.$$

**Step 3: Determine $B$.** Multiplying $(\ast)$ by $\sin t$ and integrating over
 $[0,2\pi]$:
$$B = \int_0^{2\pi}\sin t\,u(t)\,dt = (\pi+1-A)\int_0^{2\pi}\sin t\cos t\,dt + B
\int_0^{2\pi}\sin^2 t\,dt.$$

Using $\int_0^{2\pi}\sin t\cos t\,dt = 0$ and $\int_0^{2\pi}\sin^2 t\,dt = \pi$:
$$B = B\pi.$$

Since $\pi \neq 1$, we get $B(1-\pi)=0$, hence
$$B = 0.$$

**Step 4: Conclusion.** Substituting $A=\pi$ and $B=0$ into $(\ast)$:
$$u(x) = (\pi+1-\pi)\cos x + 0\cdot\sin x = \cos x.$$

**Verification.** With $u(x)=\cos x$:
$$\int_0^{2\pi}\cos(x+t)\cos t\,dt = \cos x\int_0^{2\pi}\cos^2 t\,dt - \sin x\in
t_0^{2\pi}\sin t\cos t\,dt = \pi\cos x - 0 = \pi\cos x.$$

Therefore
$$u(x) + \int_0^{2\pi}\cos(x+t)\,u(t)\,dt = \cos x + \pi\cos x = (\pi+1)\cos x,$
$
which matches the right-hand side. ✓

The exact solution is
$$\boxed{u(x) = \cos x.}$$
