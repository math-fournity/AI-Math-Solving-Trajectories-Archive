# Problem

In a specialized laboratory, three security sensors monitor a vault. To maintain protocol, the vault is considered "Secure" only if exactly one sensor is active (reporting a signal) and the other two are inactive. At the start of a security drill, the system is in this "Secure" state: Sensor A is active, while Sensor B and Sensor C are inactive.

A diagnostic computer is programmed to perform a stress test consisting of exactly four automated interventions. For each intervention, the computer randomly selects one of the three sensors (each with a 1/3 probability) and flips its current state—if the sensor was active, it becomes inactive; if it was inactive, it becomes active.

Let the probability that the vault remains in a "Secure" state (exactly one sensor active and two inactive) after all four interventions have been completed be represented by the fraction $m/n$, where $m$ and $n$ are relatively prime positive integers.

Find the value of $m + n$.
