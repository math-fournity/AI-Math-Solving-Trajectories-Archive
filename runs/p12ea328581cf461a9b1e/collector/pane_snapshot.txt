cd(a_1, \ldots, a_n) = 1$).

**Answer: The statement is TRUE.**

## Proof

### Extension Lemma

**Lemma.** Let $(a_1, \ldots, a_{n-1}, a_n)$ be a primitive Pythagorean $n$-tupl
e with $a_n$ odd and $a_n \geq 3$. Set $b = \frac{a_n^2 - 1}{2}$ and $c = \frac{
a_n^2 + 1}{2}$. Then $(a_1, \ldots, a_{n-1}, b, c)$ is a primitive Pythagorean $
(n{+}1)$-tuple with $c$ odd.

**Proof of Lemma.** Since $a_n$ is odd, $b$ and $c$ are integers, and:
$$a_n^2 + b^2 = a_n^2 + \frac{(a_n^2-1)^2}{4} = \frac{4a_n^2 + a_n^4 - 2a_n^2 +
1}{4} = \frac{(a_n^2+1)^2}{4} = c^2.$$

So $(a_n, b, c)$ is a Pythagorean triple. It is primitive: $\gcd(a_n, b) = \gcd\
!\left(a_n, \frac{(a_n-1)(a_n+1)}{2}\right) = 1$, since $\gcd(a_n, a_n \pm 1) =
1$ and $a_n$ is odd (so the factor of $2$ is coprime to $a_n$). Also $\gcd(b,c)
= 1$ since $c - b = 1$.

Now $(a_1, \ldots, a_{n-1}, b, c)$ is a Pythagorean $(n{+}1)$-tuple:
$$a_1^2 + \cdots + a_{n-1}^2 + b^2 = a_n^2 + b^2 = c^2.$$

**Primitivity:** Let $d = \gcd(a_1, \ldots, a_{n-1}, b, c)$. Since $d \mid a_i$
for $i = 1, \ldots, n{-}1$ and $a_1^2 + \cdots + a_{n-1}^2 = a_n^2$, we get $d^2
 \mid a_n^2$, hence $d \mid a_n$. Therefore $d \mid \gcd(a_1, \ldots, a_{n-1}, a
_n) = 1$, so $d = 1$.

**$c$ is odd:** Since $a_n$ is odd, $a_n^2 \equiv 1 \pmod{4}$, so $a_n^2 + 1 \eq
uiv 2 \pmod{4}$, giving $c = \frac{a_n^2+1}{2} \equiv 1 \pmod{2}$. $\square$

### Base case: $n = 3$

The family $\big(2t+1,\; 2t(t+1),\; 2t(t+1)+1\big)$ for $t = 1, 2, 3, \ldots$ gi
ves infinitely many primitive Pythagorean triples, each with odd hypotenuse $2t(
t+1)+1 \geq 5$. (This is the standard odd parametrization: $\gcd(2t+1, 2t(t+1))
= 1$ and the triple is primitive.)

### Inductive step: $n \geq 4$

For each $t \geq 1$, start with the primitive triple $\big(2t+1,\; 2t(t+1),\; 2t
(t+1)+1\big)$, which has odd hypotenuse $\geq 5$. Apply the Extension Lemma $n -
 3$ times. At each step:
- Primitivity is preserved (by the Lemma).
- The new hypotenuse $c = \frac{h^2+1}{2}$ is odd and $\geq \frac{5^2+1}{2} = 13
 > 3$, so the next application is valid.

The result is a primitive Pythagorean $n$-tuple whose **first element is $2t+1$*
* (the extension only appends elements and replaces the hypotenuse; it never mod
ifies $a_1, \ldots, a_{n-1}$). Since different values of $t$ yield different fir
st elements, the resulting $n$-tuples are all distinct.

### Conclusion

For every $n \geq 3$, the construction above produces infinitely many distinct p
rimitive Pythagorean $n$-tuples (one for each $t = 1, 2, 3, \ldots$). Therefore
the statement is **true**.
