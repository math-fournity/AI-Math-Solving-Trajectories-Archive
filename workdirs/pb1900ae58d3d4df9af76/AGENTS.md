# Problem

A sequence of $n$ empty research modules is arranged in a straight line on a space station. Two engineers, Archer and Breen, are tasked with installing specialized life-support systems. Archer always installs a "Liquid-Oxygen" system, while Breen always installs a "Carbon-Scrubber" system. 

They take turns, starting with Archer, selecting any one empty module to install their respective system. However, safety protocols strictly dictate that no two adjacent modules can ever contain the same type of system. 

The process continues until either all $n$ modules are filled—resulting in a neutral mission completion—or a player is unable to make a valid move according to the safety protocol, in which case that player is declared the loser and the other player wins.

Let $S$ be the set of all positive integers $n \le 15$ for which Breen has a guaranteed strategy to win, no matter how Archer chooses his modules. Find the sum of all the elements in the set $S$.
