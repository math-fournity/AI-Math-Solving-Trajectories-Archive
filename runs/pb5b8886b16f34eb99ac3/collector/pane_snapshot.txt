## 解答

**定义** $T(m, n)$ 为所有满足 $0 \le a_1 \le m$ 且 $0 \le a_i \le a_{i-1}$ 的序
列 $(a_1, \dots, a_n)$ 的乘积之和。我们需要求 $T(2, 2011) \bmod 1000$。

**递推关系**：按 $a_1$ 的取值分类，

$$T(m, n) = \sum_{a_1=0}^{m} a_1 \cdot T(a_1,\, n-1), \qquad T(m,1) = \sum_{a=0}
^{m} a = \frac{m(m+1)}{2}.$$

**计算各值**：

- $T(0, n) = 0$（$a_1=0$ 使乘积为 $0$）。
- $T(1, 1) = 1$；$T(1, n) = 0\cdot T(0,n-1) + 1\cdot T(1,n-1) = T(1,n-1)$，故 $T
(1,n)=1$ 对所有 $n$。
- $T(2, 1) = 0+1+2 = 3$；

$$T(2, n) = 0\cdot T(0,n-1) + 1\cdot T(1,n-1) + 2\cdot T(2,n-1) = 1 + 2\,T(2,n-1
).$$

**解递推** $T(2,n) = 1 + 2\,T(2,n-1)$，$T(2,1)=3$：

通解 $T(2,n) = c\cdot 2^{n-1} - 1$。代入 $n=1$：$c - 1 = 3 \Rightarrow c = 4$。
因此

$$T(2, n) = 4\cdot 2^{n-1} - 1 = 2^{n+1} - 1.$$

**所以** $N = T(2, 2011) = 2^{2012} - 1$。

**求 $2^{2012} \bmod 1000$**，用 CRT 分解 $1000 = 8 \times 125$：

- $\bmod\ 8$：因 $2012 \ge 3$，$2^{2012} \equiv 0 \pmod{8}$。
- $\bmod\ 125$：$\varphi(125)=100$，故 $2^{100}\equiv 1\pmod{125}$。$2012 = 20\t
imes100 + 12$，所以 $2^{2012}\equiv 2^{12} = 4096 \equiv 96 \pmod{125}$。

由 CRT 求 $x$：$x\equiv 0\pmod{8}$，$x\equiv 96\pmod{125}$。令 $x=125k+96$，则 $
125k+96\equiv 5k\equiv 0\pmod{8}$，故 $k\equiv 0\pmod{8}$，取 $k=0$ 得 $x=96$。
验证：$96\bmod 8=0$ ✓，$96\bmod 125=96$ ✓。

因此 $2^{2012}\equiv 96\pmod{1000}$，从而

$$N = 2^{2012}-1 \equiv 96 - 1 = 95 \pmod{1000}.$$

**答案**：$N \bmod 1000 = \boxed{95}$。
