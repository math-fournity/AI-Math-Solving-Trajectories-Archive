## Solution

**Claim.** The most efficient algorithm is **back-substitution (for upper-triang
ular $A$) / forward-substitution (for lower-triangular $A$) applied directly to
the triangular matrix $M = xI - A$**, computing the triangular inverse $N = M^{-
1}$ entry-by-entry via a short recurrence ordered by increasing distance from th
e diagonal. This exploits triangularity to (i) make the determinant free, (ii) h
alve the number of nonzero entries, and (iii) replace each entry's formula by a
bounded sum, yielding $\tfrac{n^{3}}{6}+O(n^{2})$ rational-function operations —
 roughly half the cost of general polynomial-matrix inversion and strictly bette
r than Faddeev–Leverrier ($O(n^{4})$ scalar ops, no triangularity gain).

Below is the proof for the upper-triangular case; the lower-triangular case is i
dentical by transposition.

---

### 1. Structure inherited from triangularity

Let $A \in \mathbb{F}^{n\times n}$ be upper triangular with diagonal $a_{11},\do
ts,a_{nn}$. Then $M := xI - A$ is upper triangular with

$$M_{ij} = \begin{cases} x - a_{ii}, & i = j,\\ -a_{ij}, & i < j,\\ 0, & i > j.
\end{cases}$$

Two facts follow immediately:

**(F1)** $\det M = \prod_{i=1}^{n}(x - a_{ii})$ — the characteristic polynomial
is obtained for free, no $O(n^{4})$ Faddeev–Leverrier sweep needed.

**(F2)** The inverse of an upper-triangular matrix is upper triangular, so $N =
M^{-1}$ has $N_{ij} = 0$ for $i > j$. Only $\tfrac{n(n+1)}{2}$ entries (not $n^{
2}$) must be computed.

---

### 2. The recurrence (back-substitution)

From $MN = I$, for $i \le j$:

$$\sum_{k=i}^{j} M_{ik}\,N_{kj} = \delta_{ij}.$$

Separating the $k=i$ term ($M_{ii} = x - a_{ii}$) from the rest ($M_{ik} = -a_{i
k}$ for $k>i$):

$$(x - a_{ii})\,N_{ij} - \sum_{k=i+1}^{j} a_{ik}\,N_{kj} = \delta_{ij},$$

hence

$$\boxed{\;N_{ij} = \frac{1}{x - a_{ii}}\!\left(\delta_{ij} + \sum_{k=i+1}^{j} a
_{ik}\,N_{kj}\right).\;}$$

Unpacked:

- **Diagonal** ($i = j$): $\;N_{ii} = \dfrac{1}{x - a_{ii}}$.
- **Off-diagonal** ($i < j$): $\;N_{ij} = \dfrac{1}{x - a_{ii}}\displaystyle\sum
_{k=i+1}^{j} a_{ik}\,N_{kj}$.

Crucially, $N_{ij}$ depends only on entries $N_{kj}$ with $k > i$, i.e. with **s
trictly smaller distance $j - k < j - i$ from the diagonal**. Therefore the entr
ies can be computed in order of increasing $j - i$ (diagonal first, then first s
uperdiagonal, then second, …), and every required operand is already known when
needed. This is exactly back-substitution, generalized to polynomial/rational en
tries.

---

### 3. Correctness

**Theorem.** The recurrence above produces $N = (xI - A)^{-1}$.

*Proof.* Existence and uniqueness of the inverse are guaranteed because $\det M
= \prod_i (x-a_{ii}) \neq 0$ as a rational function, so $M$ is invertible over $
\mathbb{F}(x)$. Since the inverse of an upper-triangular matrix is upper triangu
lar, $N$ is supported on $i \le j$. The relation $\sum_{k=i}^{j} M_{ik}N_{kj} =
\delta_{ij}$ is necessary and sufficient for $MN = I$ on the upper-triangular su
pport, and the recurrence solves this relation for $N_{ij}$ in terms of already-
computed entries (smaller $j - k$). Processing by increasing $j - i$ ensures a v
alid topological order, so the computed $N$ satisfies $MN = I$, i.e. $N = M^{-1}
$. $\square$

---

### 4. Shape of each entry (degree bound)

**Proposition.** For $i \le j$,

$$N_{ij} = \frac{p_{ij}(x)}{\prod_{m=i}^{j}(x - a_{mm})}, \qquad \deg p_{ij} \le
 \max(0,\, j - i - 1), \quad p_{ii} = 1.$$

*Proof by induction on $d = j - i$.*
Base $d = 0$: $N_{ii} = 1/(x - a_{ii})$, so $p_{ii} = 1$, denominator $(x - a_{i
i})$. ✓
Step $d \ge 1$: $N_{ij} = \frac{1}{x-a_{ii}}\sum_{k=i+1}^{j} a_{ik}\,N_{kj}$. By
 induction $N_{kj} = p_{kj}/\prod_{m=k}^{j}(x-a_{mm})$ with $\deg p_{kj} \le j -
 k - 1$. Bringing the sum to the common denominator $\prod_{m=i+1}^{j}(x-a_{mm})
$ multiplies the $k$-th numerator by $\prod_{m=i+1}^{k-1}(x-a_{mm})$ (degree $k
- i - 1$), giving a numerator of degree $\le (j - k - 1) + (k - i - 1) = j - i -
 2 \le j - i - 1$. Dividing by $(x - a_{ii})$ extends the denominator to $\prod_
{m=i}^{j}(x-a_{mm})$ without changing the numerator. ✓

So every entry is a **proper rational function** with a small numerator (degree
$\le d - 1$ for distance $d$), keeping polynomial arithmetic cheap throughout.

### 5. Complexity analysis

Count rational-function operations (multiply-by-scalar, add, divide-by-linear):

- For each pair $(i,j)$ with $i < j$ at distance $d = j - i$: the sum $\sum_{k=i
+1}^{j} a_{ik}N_{kj}$ uses $d$ scalar multiplications and $d - 1$ additions, plu
s one division by $(x - a_{ii})$.
- Number of pairs at distance $d$: $n - d$.
- Total scalar multiplications: $\displaystyle\sum_{d=1}^{n-1}(n-d)\,d = \frac{n
^{3}}{6} + O(n^{2}).$
- Total additions: $\displaystyle\sum_{d=1}^{n-1}(n-d)(d-1) = \frac{n^{3}}{6} +
O(n^{2}).$
- Total divisions by a linear factor: $\tfrac{n(n-1)}{2} + n = O(n^{2})$ (neglig
ible).

Each rational-function operation touches polynomials of degree $O(n)$ (the denom
inator has degree $\le n$), so with naive polynomial arithmetic the **bit cost i
s $O(n^{4})$**; with FFT-based polynomial arithmetic it drops to $O(n^{3}\log n)
$.

### 7. Pseudocode (upper-triangular $A$)

```
for i = 1 .. n:  N[i][i] = 1 / (x - a[i][i])
for d = 1 .. n-1:                      # distance from diagonal
    for i = 1 .. n-d:
        j = i + d
        s = 0
        for k = i+1 .. j:  s += a[i][k] * N[k][j]
        N[i][j] = s / (x - a[i][i])
return N
```

(Lower-triangular $A$: mirror the indices, i.e. forward-substitution with $N_{ij
} = \frac{1}{x-a_{jj}}\sum_{k=i}^{j-1} N_{ik}\,a_{kj}$ for $i < j$.)
