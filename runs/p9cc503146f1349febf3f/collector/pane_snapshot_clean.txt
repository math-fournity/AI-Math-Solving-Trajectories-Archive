Looking at this problem, I need to find the asymptotic behavior of the smallest
strictly positive value of $\int_{-1}^{1} x^n f(x)\,dx$ over all degree-$n$ inte
ger-coefficient polynomials $f$.

**Setting up the integral.** Let $f(x) = \sum_{k=0}^n a_k x^k$ with $a_k \in \ma
thbb{Z}$. Then
$$E = \int_{-1}^1 x^n f(x)\,dx = \sum_{k=0}^n a_k \int_{-1}^1 x^{n+k}\,dx.$$
Since $\int_{-1}^1 x^m\,dx = 0$ for $m$ odd and $= \frac{2}{m+1}$ for $m$ even,
only terms where $n+k$ is even survive. So $k$ must have the same parity as $n$.

**Case $n = 2m$ (even):** $k = 2j$ for $j = 0, \ldots, m$, giving
$$E = \sum_{j=0}^{m} a_{2j} \cdot \frac{2}{2m+2j+1}.$$

**Case $n = 2m+1$ (odd):** $k = 2j+1$ for $j = 0, \ldots, m$, giving
$$E = \sum_{j=0}^{m} a_{2j+1} \cdot \frac{2}{2m+2j+3}.$$

In both cases, $E = \sum_{j} a_j \cdot \frac{2}{d_j}$ where $d_0, d_1, \ldots, d
_m$ are $m+1$ consecutive odd integers ranging approximately from $n$ to $2n$.

**Lattice of achievable values.** The set of achievable $E$ values is $\left\{\s
um_j a_j \cdot \frac{2}{d_j} : a_j \in \mathbb{Z}\right\}$. Let $L = \operatorna
me{lcm}(d_0, \ldots, d_m)$ and $b_j = L/d_j$. Then
$$E = \frac{2}{L} \sum_j a_j b_j, \quad a_j \in \mathbb{Z}.$$
The set $\{\sum_j a_j b_j : a_j \in \mathbb{Z}\} = \gcd(b_0, \ldots, b_m) \cdot
\mathbb{Z}$.

**Key lemma:** If $L = \operatorname{lcm}(d_0, \ldots, d_m)$, then $\gcd(L/d_0,
\ldots, L/d_m) = 1$.

*Proof:* If prime $p$ divides all $L/d_j$, then $v_p(L) > v_p(d_j)$ for all $j$,
 so $v_p(L) > \max_j v_p(d_j) = v_p(L)$, contradiction. $\square$

Therefore the achievable values form $\frac{2}{L}\mathbb{Z}$, and the smallest s
trictly positive value is
$$\alpha_n = \frac{2}{L_n}, \quad \text{where } L_n = \operatorname{lcm}(d_0, \l
dots, d_m).$$

**Asymptotics of $L_n$.** The $d_j$ are consecutive odd integers with $A \approx
 n$ (smallest) and $B \approx 2n$ (largest). Specifically:
- $n = 2m$: $d_j = 2m+2j+1$, so $A = n+1$, $B = 2n+1$.
- $n = 2m+1$: $d_j = 2m+2j+3$, so $A = n+2$, $B = 2n+1$.

We compute $\log L_n = \sum_{p \text{ odd prime}} \max_{\substack{k \text{ odd}
\\ k \in [A,B]}} v_p(k) \cdot \log p$.

For an odd prime power $p^e \leq B$, an odd multiple of $p^e$ exists in $[A, B]$
 if and only if:
- $p^e \leq (B-A)/2 \approx n/2$: guaranteed by spacing (odd multiples are $2p^e
$ apart, interval length $\approx n \geq 2p^e$).
- $n/2 < p^e \leq B/3 \approx 2n/3$: the multiple $3p^e \in [3n/2, 2n] \subseteq
 [A, B]$ works.
- $A \leq p^e \leq B$: $p^e$ itself is in $[A, B]$.
- $B/3 < p^e < A$ (the **gap**, approximately $(2n/3, n)$): $p^e < A$ and $3p^e
> B$, and $5p^e > B$ as well, so **no** odd multiple exists in $[A, B]$.

When $p^{e_p}$ (the largest power of $p$ that is $\leq B$) falls in the gap, the
 max $v_p$ drops from $e_p$ to $e_p - 1$ (since $p^{e_p - 1} < B/(3p) \cdot 3 =
B/p \leq B/3 < n/2$, which has an odd multiple in $[A,B]$). The loss is exactly
$\log p$ per such prime.

**Computing the loss.** The total loss is:
$$\sum_{\substack{p \text{ odd prime} \\ p^{e_p} \in (B/3,\, A)}} \log p.$$

- **Primes** $p \in (B/3, A) \approx (2n/3, n)$: these have $e_p = 1$, contribut
ing $\theta(A) - \theta(B/3) \sim n - \frac{2n}{3} = \frac{n}{3}$ by the Prime N
umber Theorem.
- **Higher prime powers** ($e \geq 2$) in the gap: at most $O(\sqrt{n})$ such po
wers, each contributing $O(\log n)$, total $O(\sqrt{n}\log n) = o(n)$.

**Full value.** The sum over all odd prime powers $\leq B$ is $\psi(B) - O(\log
n) \sim 2n$, where $\psi$ is the Chebyshev function and $\psi(B) \sim B \sim 2n$
.

**Combining:**
$$\log L_n = 2n - \frac{n}{3} + o(n) = \frac{5n}{3} + o(n).$$

Therefore:
$$\frac{\log \alpha_n}{n} = \frac{\log 2 - \log L_n}{n} = \frac{\log 2 - \frac{5
n}{3} + o(n)}{n} \longrightarrow -\frac{5}{3}.$$
