## 证明

**目标。** 设 $B$ 为不可数集，$A \subseteq B$ 为可数集。我们构造一个双射 $f: B \
to B \setminus A$。

**准备工作。** 首先，观察到 $B \setminus A$ 是不可数的：如果它是可数的，那么 $B
= A \cup (B\setminus A)$ 将是两个可数集的并集，因而是可数的——这与 $B$ 不可数相矛
盾。因此 $B \setminus A$ 是不可数的，特别是它是无限的，所以我们可以在 $B \setmin
us A$ 中选择一个可数无限子集 $C = \{c_1, c_2, c_3, \dots\}$，其中所有的 $c_i$ 都
是互不相同的。注意 $A$、$C$ 和 $B \setminus (A \cup C)$ 两两不相交，且 $B = A \c
up C \cup \bigl(B \setminus (A \cup C)\bigr)$，同时 $B \setminus A = C \cup \big
l(B \setminus (A \cup C)\bigr)$。

我们根据 $A$ 是有限还是可数无限来分别处理。

---

**情况 1：$A$ 是有限的**，比如 $A = \{a_1, a_2, \dots, a_n\}$。

定义 $f: B \to B \setminus A$ 为：
$$
f(x) = \begin{cases}
c_i & \text{if } x = a_i \text{ for some } 1 \le i \le n, \\
c_{n+i} & \text{if } x = c_i \text{ for some } i \ge 1, \\
x & \text{if } x \in B \setminus (A \cup C).
\end{cases}
$$

*值域。* $f$ 的值域是
$$
\{c_1, \dots, c_n\} \;\cup\; \{c_{n+1}, c_{n+2}, \dots\} \;\cup\; \bigl(B \setmi
nus (A \cup C)\bigr) = C \cup \bigl(B \setminus (A \cup C)\bigr) = B \setminus A
.
$$

*单射性。* $f$ 的三个部分分别将 $A$、$C$ 和 $B \setminus (A \cup C)$ 映射到两两
不相交的集合 $\{c_1,\dots,c_n\}$、$\{c_{n+1}, c_{n+2}, \dots\}$ 和 $B \setminus
(A \cup C)$ 中。在每个部分内，$f$ 显然是单射的（$a_i \mapsto c_i$ 且 $c_i \mapst
o c_{n+i}$ 都是具有不同下标的单射）。因此 $f$ 是单射的。

因此 $f$ 是从 $B$ 到 $B \setminus A$ 的双射。

---

**情况 2：$A$ 是可数无限的**，比如 $A = \{a_1, a_2, a_3, \dots\}$。

定义 $f: B \to B \setminus A$ 为：
$$
f(x) = \begin{cases}
c_{2i} & \text{if } x = a_i \text{ for some } i \ge 1, \\
c_{2i-1} & \text{if } x = c_i \text{ for some } i \ge 1, \\
x & \text{if } x \in B \setminus (A \cup C).
\end{cases}
$$

*值域。* $f$ 的值域是
$$
\{c_2, c_4, c_6, \dots\} \;\cup\; \{c_1, c_3, c_5, \dots\} \;\cup\; \bigl(B \set
minus (A \cup C)\bigr) = C \cup \bigl(B \setminus (A \cup C)\bigr) = B \setminus
 A.
$$

*单射性。* 三个部分分别将 $A$、$C$ 和 $B \setminus (A \cup C)$ 映射到两两不相交
的集合 $\{c_2, c_4, \dots\}$、$\{c_1, c_3, \dots\}$ 和 $B \setminus (A \cup C)$
中。在每个部分内，$f$ 是单射的（$a_i \mapsto c_{2i}$ 和 $c_i \mapsto c_{2i-1}$
都是具有不同下标的单射）。因此 $f$ 是单射的。

因此 $f$ 是从 $B$ 到 $B \setminus A$ 的双射。

---

**总结。** 在两种情况下（$A$ 有限或可数无限），我们都构造了一个显式的双射 $f: B
\to B \setminus A$。核心思想是：在 $B \setminus A$ 内部选择一个可数无限“缓冲区”
$C$，将可数集 $A$ 吸收到 $C$ 中（通过将 $A$ 映射到 $C$ 的一半，将 $C$ 重新路由到
另一半），并保持 $B \setminus (A \cup C)$ 中的所有内容不变。这是一种希尔伯特旅馆
式的构造，适应于不可数背景。$\blacksquare$
