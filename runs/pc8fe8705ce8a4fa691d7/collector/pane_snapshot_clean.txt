## Proof

We use the **Schwarz–Pick lemma**: if $f: U \to U$ is holomorphic, then for ever
y $z \in U$,

$$\frac{|f'(z)|}{1 - |f(z)|^2} \le \frac{1}{1 - |z|^2}.$$

Applying this at $z = 1/2$, and using $f(1/2) = 1/3$:

$$|f'(1/2)| \le \frac{1 - |f(1/2)|^2}{1 - |1/2|^2} = \frac{1 - (1/3)^2}{1 - (1/2
)^2} = \frac{1 - 1/9}{1 - 1/4} = \frac{8/9}{3/4} = \frac{8}{9} \cdot \frac{4}{3}
 = \frac{32}{27}.$$

So $|f'(1/2)| \le \dfrac{32}{27}$.

**Equality is attained.** Let $\varphi_a(z) = \dfrac{z - a}{1 - \overline{a}\,z}
$ be the disk automorphism sending $a \mapsto 0$. Consider

$$f(z) = \varphi_{1/3}^{-1}\!\left(e^{i\theta}\,\varphi_{1/2}(z)\right),$$

where $\varphi_{1/3}^{-1}(w) = \dfrac{w + 1/3}{1 + w/3}$ is the inverse automorp
hism (sending $0 \mapsto 1/3$). This $f$ is a disk automorphism (a composition o
f automorphisms), hence maps $U \to U$ holomorphically, and

$$f(1/2) = \varphi_{1/3}^{-1}\!\left(e^{i\theta} \cdot 0\right) = \varphi_{1/3}^
{-1}(0) = 1/3.$$

Since $f$ is an automorphism, equality holds in Schwarz–Pick, giving $|f'(1/2)|
= \dfrac{32}{27}$.

Therefore the maximum value is

$$\boxed{\dfrac{32}{27}}.$$
