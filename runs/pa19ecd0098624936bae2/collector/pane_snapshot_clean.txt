Looking at this problem, I need to find all integers $x$ such that $x^2 + 2010x$
 is a perfect square.

## Setup

Let $y$ be an integer with $y^2 = x^2 + 2010x$. Completing the square:

$$y^2 = (x+1005)^2 - 1005^2$$

So $(x+1005)^2 - y^2 = 1005^2$. Setting $a = x+1005$ and $b = y$:

$$(a-b)(a+b) = 1005^2$$

## Factoring

$1005 = 3 \cdot 5 \cdot 67$, so $1005^2 = 3^2 \cdot 5^2 \cdot 67^2$.

The number of positive divisors of $1005^2$ is $(2+1)(2+1)(2+1) = 27$.

Since $1005^2$ is odd, every divisor is odd, so for any factorization $de = 1005
^2$, the factors $d$ and $e$ have the same parity (both odd). Thus $a = (d+e)/2$
 and $b = (e-d)/2$ are always integers — **every** divisor yields a valid soluti
on.

## Counting distinct $x$ values

Each ordered pair $(d, e)$ with $de = 1005^2$ gives $a = (d+e)/2$, hence $x = a
- 1005$.

Two divisors $d_1 \neq d_2$ yield the same $a$ iff $(d_1 + N/d_1) = (d_2 + N/d_2
)$, which factors as $(d_1 - d_2)(1 - N/(d_1 d_2)) = 0$. So either $d_1 = d_2$ o
r $d_1 d_2 = N$, i.e., $d_2 = N/d_1$. Thus divisors $d$ and $N/d$ give the **sam
e** $a$.

**Positive divisors:** The 27 positive divisors form unordered pairs $\{d, N/d\}
$. Since $N = 1005^2$ is a perfect square, the divisor $d = 1005$ is self-paired
. The remaining 26 divisors form 13 pairs. So there are $13 + 1 = 14$ distinct p
ositive values of $a$.

**Negative divisors:** For each positive pair $\{d, e\}$, the negative pair $\{-
d, -e\}$ gives $a = -(d+e)/2 < 0$. This yields 14 distinct negative values of $a
$.

**No overlap:** Positive and negative $a$-values coincide only if $a = 0$, i.e.,
 $x = -1005$. But then $x^2 + 2010x = 1005^2 - 2010 \cdot 1005 = -1005^2 < 0$, w
hich is not a perfect square. So $a = 0$ never occurs, and the positive and nega
tive cases are disjoint.
