## Proof

We interpret "sequences of positive integers" as infinite sequences $(a_1, a_2,
a_3, \dots)$ with each $a_i \in \mathbb{N}_{>0}$, i.e., functions $f \colon \mat
hbb{N}_{>0} \to \mathbb{N}_{>0}$. A sequence "contains all positive integers" me
ans $f$ is **surjective**: every positive integer $n$ appears as some $f(i)$.

Let $S$ be the set of surjective functions $\mathbb{N}_{>0} \to \mathbb{N}_{>0}$
. We show $|S| = 2^{\aleph_0}$.

**Upper bound.** The set of *all* functions $\mathbb{N}_{>0} \to \mathbb{N}_{>0}
$ has cardinality
$$\aleph_0^{\aleph_0}.$$
Since $2 \leq \aleph_0 \leq 2^{\aleph_0}$,
$$2^{\aleph_0} \leq \aleph_0^{\aleph_0} \leq (2^{\aleph_0})^{\aleph_0} = 2^{\ale
ph_0 \cdot \aleph_0} = 2^{\aleph_0},$$
so $\aleph_0^{\aleph_0} = 2^{\aleph_0}$. Since $S$ is a subset of all such funct
ions, $|S| \leq 2^{\aleph_0}$.

**Lower bound.** We inject $\{0,1\}^{\mathbb{N}}$ (which has cardinality $2^{\al
eph_0}$) into $S$. For each binary sequence $b = (b_1, b_2, \dots) \in \{0,1\}^{
\mathbb{N}}$, define $f_b \colon \mathbb{N}_{>0} \to \mathbb{N}_{>0}$ by
$$f_b(2n-1) = n, \qquad f_b(2n) = b_n + 1 \quad (n \geq 1).$$

- **Surjectivity:** For every $n \in \mathbb{N}_{>0}$, we have $f_b(2n-1) = n$,
so every positive integer is attained. Hence $f_b \in S$.
- **Injectivity of $b \mapsto f_b$:** If $b \neq b'$, then $b_n \neq b'_n$ for s
ome $n$, so $f_b(2n) = b_n+1 \neq b'_n+1 = f_{b'}(2n)$, giving $f_b \neq f_{b'}$
.

Thus $|S| \geq 2^{\aleph_0}$.

**Conclusion.** Combining both bounds,
$$|S| = 2^{\aleph_0}.$$

The number of sequences of positive integers that contain all positive integers
is **$2^{\aleph_0}$** — the cardinality of the continuum (uncountably many).
