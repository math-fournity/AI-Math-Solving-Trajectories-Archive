# Problem

In a specialized digital archive, every possible unique security permutation of the digits 1 through 9 is recorded. A permutation is considered valid if it uses each digit from 1 to 9 exactly once. To create a master reference string $S$, an engineer lists every valid permutation in ascending numerical order and concatenates them into one continuous sequence. The sequence begins as $123456789123456798\dots$ and continues until all $9!$ permutations are exhausted.

A security scanner is designed to read "windows" of $k$ consecutive digits from this master string. For the scanner to function without ambiguity, the value of $k$ must be large enough to ensure that every possible window of length $k$ captured from $S$ is unique. 

What is the smallest integer $k$ such that no two identical subsequences of length $k$ exist within the master string $S$?
