## Solution

The problem is the inhomogeneous heat equation in a disk with homogeneous Dirich
let boundary data and zero initial data. Since the boundary, initial data, and s
ource $f(r,t)$ depend only on the radial coordinate, the solution is radially sy
mmetric, so we work with the radial Laplacian
$$\nabla^2 u = u_{rr} + \frac{1}{r}u_r.$$

### 1. Eigenfunction expansion (Fourier–Bessel)

The homogeneous problem $\nabla^2 \phi + \lambda^2 \phi = 0$ with $\phi(a)=0$ an
d regularity at $r=0$ has eigenfunctions
$$\phi_n(r) = J_0(\lambda_n r), \qquad J_0(\lambda_n a)=0,$$
i.e. $\lambda_n = \alpha_n/a$ where $\alpha_n$ is the $n$-th positive zero of $J
_0$. These eigenfunctions are orthogonal with weight $r$:
$$\int_0^a r\, J_0(\lambda_n r) J_0(\lambda_m r)\,dr = \frac{a^2}{2}\bigl[J_1(\a
lpha_n)\bigr]^2 \delta_{nm}.$$

Expand
$$u(r,t) = \sum_{n=1}^{\infty} T_n(t)\, J_0(\lambda_n r), \qquad f(r,t) = \sum_{
n=1}^{\infty} f_n(t)\, J_0(\lambda_n r),$$
with
$$f_n(t) = \frac{2}{a^2 [J_1(\alpha_n)]^2}\int_0^a r'\, f(r',t)\, J_0(\lambda_n
r')\,dr'.$$

### 2. Time coefficients

Substituting into the PDE and using $\nabla^2 J_0(\lambda_n r) = -\lambda_n^2 J_
0(\lambda_n r)$ gives, for each $n$,
$$T_n'(t) + k\lambda_n^2 T_n(t) = f_n(t), \qquad T_n(0)=0.$$

This first-order ODE has the solution (Duhamel / integrating factor)
$$T_n(t) = \int_0^t e^{-k\lambda_n^2(t-\tau)}\, f_n(\tau)\,d\tau.$$

### 3. Final answer

$$\boxed{\;u(r,t) = \frac{2}{a^2}\sum_{n=1}^{\infty} \frac{J_0(\alpha_n r/a)}{[J
_1(\alpha_n)]^2} \int_0^t e^{-k\alpha_n^2(t-\tau)/a^2}\!\left[\int_0^a r'\, f(r'
,\tau)\, J_0(\alpha_n r'/a)\,dr'\right] d\tau.\;}$$

### 4. Verification

- **Boundary:** at $r=a$, $J_0(\alpha_n)=0$ for every $n$, so $u(a,t)=0$. ✓
- **Initial data:** at $t=0$ the outer integral collapses to $0$, so $u(r,0)=0$.
 ✓
- **PDE:** termwise differentiation is justified by the uniform convergence furn
ished by the exponential factor $e^{-k\alpha_n^2 t/a^2}$ for $t>0$; each mode sa
tisfies $T_n' = -k\lambda_n^2 T_n + f_n$, and summing reconstructs $\partial_t u
 = k\nabla^2 u + f$. ✓
- **Regularity at $r=0$:** $J_0$ is bounded and smooth at the origin, so $u$ is
regular. ✓
