# Problem

In a high-security data center, a square mainframe server rack is organized into an $n \times n$ grid of processing nodes. Currently, 101 of these nodes are designated as "Master Nodes" and are glowing blue.

The facility manager needs to partition the entire $n \times n$ grid into several smaller rectangular server clusters. The partitions must follow the grid lines between the nodes, and the layout must adhere to one strict security protocol: every individual rectangular cluster must contain exactly one Master Node.

After surveying the grid, the lead engineer determines that there is only one unique way to divide the $n \times n$ rack into these rectangular clusters such that the protocol is satisfied.

What is the smallest possible value of $n$ for which such a unique partition of the $n \times n$ grid exists for these 101 Master Nodes?
