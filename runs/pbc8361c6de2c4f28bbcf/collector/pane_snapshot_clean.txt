## Proof

The answer is **No** in general. We provide an explicit counterexample.

**Setup.** Let $A = M_2(\mathbb{C})$, the C*-algebra of $2\times 2$ complex matr
ices. The pure state space $PS(A)$ is naturally identified with $\mathbb{C}P^1$:
 every pure state on $M_2(\mathbb{C})$ is a vector state $\omega_\xi(a) = \langl
e a\xi, \xi\rangle$ for a unit vector $\xi \in \mathbb{C}^2$, and $\omega_\xi =
\omega_\eta$ if and only if $\xi$ and $\eta$ differ by a unimodular scalar. The
weak-* topology on $PS(A)$ coincides with the standard topology on $\mathbb{C}P^
1 \cong S^2$.

Let $\xi = e_1 = (1,0)^T$ and $\phi = \omega_{e_1}$. Choose $E$ to be a small op
en ball around $[e_1]$ in $\mathbb{C}P^1$ (in the round metric on $S^2$) of radi
us $r < \pi/2$. Then $PS(A)\setminus E$ is a closed disk of positive radius, hen
ce contains more than one point.

**Suppose for contradiction** that there exists $a \in M_2(\mathbb{C})$ with $0
\leq a \leq 1$, $\phi(a) = 1$, and $\psi(a) = 0$ for all $\psi \in PS(A)\setminu
s E$.

**Step 1: $a\,e_1 = e_1$.** Since $0 \leq a \leq 1$, the element $1-a$ is positi
ve. We have
$$\langle (1-a)e_1, e_1\rangle = 1 - \langle ae_1, e_1\rangle = 1 - \phi(a) = 0.
$$
Since $1-a \geq 0$, positivity gives $\|(1-a)^{1/2}e_1\|^2 = \langle(1-a)e_1,e_1
\rangle = 0$, so $(1-a)^{1/2}e_1 = 0$, hence $(1-a)e_1 = 0$, i.e., $ae_1 = e_1$.
 In particular, $a \neq 0$.

**Step 2: $a$ annihilates every $[\eta] \in PS(A)\setminus E$.** For any unit ve
ctor $\eta$ with $[\eta] \in PS(A)\setminus E$, we have $\omega_\eta(a) = \langl
e a\eta,\eta\rangle = 0$. Since $a \geq 0$, this gives $\|a^{1/2}\eta\|^2 = 0$,
so $a^{1/2}\eta = 0$, hence $a\eta = 0$.

**Step 3: The zero set of $\hat{a}$ on $\mathbb{C}P^1$ is too small.** Define $Z
(a) = \{[\eta] \in \mathbb{C}P^1 : a\eta = 0\} = \mathbb{P}(\ker a)$, the projec
tivization of the kernel of $a$. Since $a$ is a $2\times 2$ matrix:

- If $\ker a = \{0\}$ (i.e., $a$ is invertible), then $Z(a) = \emptyset$.
- If $\dim\ker a = 1$, then $Z(a)$ is a **single point** of $\mathbb{C}P^1$.
- If $\dim\ker a = 2$ (i.e., $a = 0$), then $Z(a) = \mathbb{C}P^1$.

By Step 1, $a \neq 0$, so $Z(a) \neq \mathbb{C}P^1$. Thus $Z(a)$ is either empty
 or a single point.

**Step 4: Contradiction.** By Step 2, $PS(A)\setminus E \subseteq Z(a)$. But $PS
(A)\setminus E$ is a closed disk containing more than one point, while $Z(a)$ is
 either empty or a single point. This is impossible.

**Conclusion.** For $A = M_2(\mathbb{C})$, the open set $E$ (a small ball around
 $[e_1]$), and $\phi = \omega_{e_1}$, no positive element $a \leq 1$ satisfies b
oth $\phi(a) = 1$ and $\psi(a) = 0$ for all $\psi \in PS(A)\setminus E$. The ans
wer to the question is **No**.

The essential obstruction is that the zero locus of a positive element on the pu
re state space is the projectivization of its kernel—a projective subspace—where
as the complement of a general open set in $PS(A)$ need not be contained in any
proper projective subspace.
