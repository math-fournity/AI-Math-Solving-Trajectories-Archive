Looking at the problem, I need to determine whether an infinite σ-algebra exists
 where every nonempty member has a nonempty proper measurable subset (i.e., an a
tomless σ-algebra).

The key obstacle is that singletons, when measurable, are always atoms. So I nee
d a σ-algebra where singletons are *not* measurable, yet the σ-algebra remains r
ich (infinite) and every nonempty measurable set can still be split.

**Answer: Yes.**

Let $I$ be an uncountable set (e.g., $I = \mathbb{R}$), let $X = \{0,1\}^I$, and
 let $\mathcal{F}$ be the product $\sigma$-algebra on $X$ (generated by the coor
dinate projections $x \mapsto x_i$ for $i \in I$). We show $\mathcal{F}$ is an i
nfinite, atomless $\sigma$-algebra.

---

**$\mathcal{F}$ is infinite.** For each $i \in I$, the cylinder set $A_i = \{x \
in X : x_i = 0\}$ is measurable. Since $I$ is uncountable, these are uncountably
 many distinct measurable sets.

---

**Key structural fact.** A set $A \subseteq X$ belongs to $\mathcal{F}$ if and o
nly if $A$ depends on only countably many coordinates: there exists a countable
$J \subseteq I$ and a Borel set $B \subseteq \{0,1\}^J$ such that $A = \pi_J^{-1
}(B)$, where $\pi_J : X \to \{0,1\}^J$ is the projection.

*Proof of fact.* Each generator $\{x : x_i = 0\}$ depends on one coordinate. Com
plements and countable unions/intersections of sets depending on countably many
coordinate sets still depend on countably many coordinates (a countable union of
 countable sets is countable). So every set in $\mathcal{F}$ depends on countabl
y many coordinates. Conversely, for countable $J$, the product $\sigma$-algebra
on $\{0,1\}^J$ is generated by the coordinate projections for $j \in J$, and $\p
i_J^{-1}$ of any such generator is a cylinder set in $X$, hence in $\mathcal{F}$
; so $\pi_J^{-1}(B) \in \mathcal{F}$ for every Borel $B \subseteq \{0,1\}^J$. $\
square$

---

**$\mathcal{F}$ is atomless.** Let $A \in \mathcal{F}$ be nonempty. Write $A = \
pi_J^{-1}(B)$ with $J \subseteq I$ countable and $B \subseteq \{0,1\}^J$ nonempt
y Borel.

*Case 1: $B$ contains at least two points.* Pick $b \in B$. Since $J$ is countab
le, $\{0,1\}^J$ is a standard Borel space, so $\{b\}$ is Borel. Then $\pi_J^{-1}
(\{b\})$ is a nonempty, proper (since $B \neq \{b\}$), measurable subset of $A$.

*Case 2: $B = \{b\}$ is a singleton.* Then $A = \{x \in X : x|_J = b\}$. Since $
I$ is uncountable and $J$ is countable, choose $i \in I \setminus J$. Set
$$A_0 = A \cap \{x \in X : x_i = 0\} = \{x \in X : x|_J = b,\; x_i = 0\}.$$
- **Nonempty:** we can construct $x$ with $x|_J = b$ and $x_i = 0$ (remaining co
ordinates arbitrary).
- **Proper subset of $A$:** the set $A_1 = A \cap \{x : x_i = 1\}$ is also nonem
pty.
- **Measurable:** $A_0$ depends on the countable coordinate set $J \cup \{i\}$,
so $A_0 \in \mathcal{F}$.

In both cases, $A$ has a nonempty proper measurable subset. $\square$

---

**Why uncountability of $I$ is essential.** If $I$ were countable, every singlet
on $\{x\} = \bigcap_{i \in I} \{y : y_i = x_i\}$ would be a countable intersecti
on of measurable sets, hence measurable—and a measurable singleton is automatica
lly an atom (its only proper subset is $\emptyset$). The uncountability of $I$ e
nsures that singletons depend on uncountably many coordinates and thus are *not*
 measurable, while always leaving a free coordinate $i \notin J$ to split any se
t depending on a countable $J$.

---

Therefore, the product $\sigma$-algebra on $\{0,1\}^I$ for uncountable $I$ is an
 infinite $\sigma$-algebra in which every nonempty member has a nonempty proper
measurable subset.
