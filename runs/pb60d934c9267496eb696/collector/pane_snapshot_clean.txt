## Solution

We need integer pairs $(a,b)$ satisfying all three inequalities:
1. $a^2 + b^2 < 16$
2. $a^2 + b^2 < 8a \;\Leftrightarrow\; (a-4)^2 + b^2 < 16$
3. $a^2 + b^2 < 8b \;\Leftrightarrow\; a^2 + (b-4)^2 < 16$

**Geometric interpretation:** The point $(a,b)$ must lie strictly inside three c
ircles of radius $4$: centered at the origin $O=(0,0)$, at $A=(4,0)$, and at $B=
(0,4)$.

**Bounding the candidates.** From inequality (1), $a^2<16$ and $b^2<16$, so $a,b
\in\{-3,-2,-1,0,1,2,3\}$.

From inequality (2), $(a-4)^2<16$, so $|a-4|<4$, giving $a\in\{1,2,3,4,5,6,7\}$.
 Intersecting with the above: $a\in\{1,2,3\}$.

From inequality (3), by symmetry, $b\in\{1,2,3\}$.

This leaves $9$ candidates. Checking each against all three inequalities:

| $(a,b)$ | $a^2+b^2$ | $(a-4)^2+b^2$ | $a^2+(b-4)^2$ | All $<16$? |
|---------|-----------|----------------|----------------|------------|
| $(1,1)$ | $2$ | $10$ | $10$ | ✓ |
| $(1,2)$ | $5$ | $13$ | $5$ | ✓ |
| $(1,3)$ | $10$ | $18$ | $2$ | ✗ |
| $(2,1)$ | $5$ | $5$ | $13$ | ✓ |
| $(2,2)$ | $8$ | $8$ | $8$ | ✓ |
| $(2,3)$ | $13$ | $13$ | $5$ | ✓ |
| $(3,1)$ | $10$ | $2$ | $18$ | ✗ |
| $(3,2)$ | $13$ | $5$ | $13$ | ✓ |
| $(3,3)$ | $18$ | $10$ | $10$ | ✗ |

The valid pairs are:
$$(1,1),\;(1,2),\;(2,1),\;(2,2),\;(2,3),\;(3,2)$$

That is **6** ordered pairs.
