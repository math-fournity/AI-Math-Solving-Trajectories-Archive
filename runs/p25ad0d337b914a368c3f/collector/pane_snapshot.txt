**Claim:** $F_n(x) = \dfrac{x^n}{n!}\bigl(\ln x - H_n\bigr)$, where $H_n = \sum_
{k=1}^{n}\frac{1}{k}$ is the $n$-th harmonic number.

**Base case ($n=0$):** $F_0(x) = \ln x = \dfrac{x^0}{0!}(\ln x - H_0)$, with $H_
0 = 0$. ✓

**Inductive step:** Assume $F_n(x) = \dfrac{x^n}{n!}(\ln x - H_n)$. Then
$$F_{n+1}(x) = \int_0^x F_n(t)\,dt = \frac{1}{n!}\int_0^x t^n(\ln t - H_n)\,dt.$
$

Using integration by parts (valid since $\lim_{t\to 0^+} t^{n+1}\ln t = 0$ for $
n \ge 0$),
$$\int_0^x t^n \ln t\,dt = \frac{x^{n+1}}{n+1}\ln x - \frac{x^{n+1}}{(n+1)^2}, \
qquad \int_0^x t^n\,dt = \frac{x^{n+1}}{n+1}.$$

Substituting,
$$F_{n+1}(x) = \frac{1}{n!}\left[\frac{x^{n+1}}{n+1}\ln x - \frac{x^{n+1}}{(n+1)
^2} - H_n\frac{x^{n+1}}{n+1}\right] = \frac{x^{n+1}}{(n+1)!}\left[\ln x - \left(
H_n + \frac{1}{n+1}\right)\right].$$

Since $H_{n+1} = H_n + \frac{1}{n+1}$, this gives $F_{n+1}(x) = \dfrac{x^{n+1}}{
(n+1)!}(\ln x - H_{n+1})$. ✓

**Evaluating at $x=1$:** Since $\ln 1 = 0$,
$$F_n(1) = \frac{1}{n!}(0 - H_n) = -\frac{H_n}{n!}, \qquad \text{so} \qquad n!\,
F_n(1) = -H_n.$$

**The limit:**
$$\lim_{n\to\infty}\frac{n!\,F_n(1)}{\ln n} = \lim_{n\to\infty}\frac{-H_n}{\ln n
}.$$

By the classical asymptotic expansion $H_n = \ln n + \gamma + o(1)$ (where $\gam
ma$ is the Euler–Mascheroni constant), we have
$$\frac{H_n}{\ln n} = 1 + \frac{\gamma + o(1)}{\ln n} \longrightarrow 1.$$

Therefore,
$$\boxed{\lim_{n \to \infty} \frac{n!\, F_n(1)}{\ln n} = -1}.$$
