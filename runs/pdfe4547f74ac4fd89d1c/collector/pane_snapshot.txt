## Proof

Let $x_1, x_2, \ldots$ be i.i.d. $\operatorname{Uniform}(0,1)$ random variables.
 Set $S_n = x_1 + \cdots + x_n$ and $\bar{X}_n = S_n/n$. The integral equals $E[
n/S_n] = E[1/\bar{X}_n]$.

**Step 1: Almost sure limit.** By the strong law of large numbers, $\bar{X}_n \t
o E[x_1] = 1/2$ a.s., so $1/\bar{X}_n \to 2$ a.s.

**Step 2: Lower bound via Fatou.** Since $1/\bar{X}_n \geq 0$, Fatou's lemma giv
es
$$\liminf_{n\to\infty} E[1/\bar{X}_n] \geq E\!\left[\liminf_{n\to\infty} 1/\bar{
X}_n\right] = 2.$$

**Step 3: Upper bound.** Write $Y_i = 1 - x_i$ (i.i.d. $\operatorname{Uniform}(0
,1)$), so $\bar{X}_n = 1 - \bar{Y}_n$ and $1/\bar{X}_n = 1/(1-\bar{Y}_n)$. Using
 the tail-integral formula $E[Z] = \int_0^\infty P(Z>t)\,dt$:

$$E\!\left[\frac{1}{1-\bar{Y}_n}\right] = \int_0^\infty P\!\left(\bar{Y}_n > 1 -
 \tfrac{1}{t}\right) dt.$$

We bound the integrand on four regions:

- **$t \in [0,2]$:** $P(\bar{Y}_n > 1-1/t) \leq 1$, contributing $\leq 2$.

- **$t \in [2,4]$:** By Hoeffding's inequality ($Y_i \in [0,1]$, $E[Y_i]=1/2$):
$$P\!\left(\bar{Y}_n > 1-\tfrac{1}{t}\right) = P\!\left(\bar{Y}_n - \tfrac{1}{2}
 > \tfrac{1}{2}-\tfrac{1}{t}\right) \leq \exp\!\left(-2n\!\left(\tfrac{1}{2}-\tf
rac{1}{t}\right)^{\!2}\right).$$
Substituting $u = 1/2 - 1/t$ (so $dt = du/(1/2-u)^2 \leq 16\,du$ for $u \in [0,1
/4]$):
$$\int_2^4 \exp\!\left(-2n\!\left(\tfrac{1}{2}-\tfrac{1}{t}\right)^{\!2}\right)
dt \leq 16\int_0^{1/4} e^{-2nu^2}\,du \leq 16\cdot\tfrac{1}{2}\sqrt{\tfrac{\pi}{
2n}} = \frac{4\sqrt{2\pi}}{\sqrt{n}} \to 0.$$

- **$t \in [4,n]$:** Here $1/2 - 1/t \geq 1/4$, so the Hoeffding bound gives $\l
eq e^{-n/8}$, and
$$\int_4^n e^{-n/8}\,dt \leq n\,e^{-n/8} \to 0.$$

- **$t \in [n,\infty)$:** Here $n/t \leq 1$, so using the Irwin–Hall CDF $P(S_n
< s) = s^n/n!$ for $s \leq 1$, and Stirling's bound $n! \geq (n/e)^n$:
$$P\!\left(\bar{Y}_n > 1-\tfrac{1}{t}\right) = P(S_n < n/t) \leq \left(\frac{e}{
t}\right)^{\!n},$$
$$\int_n^\infty \left(\frac{e}{t}\right)^{\!n} dt = \frac{n\,(e/n)^n}{n-1} \to 0
.$$

Combining all regions:
$$E\!\left[\frac{1}{1-\bar{Y}_n}\right] \leq 2 + \frac{4\sqrt{2\pi}}{\sqrt{n}} +
 n\,e^{-n/8} + \frac{n(e/n)^n}{n-1} \xrightarrow{n\to\infty} 2.$$

**Step 4: Conclusion.** Steps 2 and 3 give
$$2 \leq \liminf_{n\to\infty} E\!\left[\frac{n}{S_n}\right] \leq \limsup_{n\to\i
nfty} E\!\left[\frac{n}{S_n}\right] \leq 2.$$

Therefore
$$\lim_{n \to \infty} \int_{(0,1)^n} \frac{n}{x_1 + \cdots + x_n} \, dx_1 \cdots
 dx_n = \boxed{2}.$$
