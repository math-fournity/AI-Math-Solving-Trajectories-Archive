## Solution

We seek a nontrivial polynomial $p$ with $p(2x) = p'(x)p''(x) \neq 0$.

**Degree analysis.** Let $\deg p = n$. Then $\deg p(2x) = n$, while $\deg p' = n
-1$ and $\deg p'' = n-2$, so $\deg(p'p'') = 2n-3$. Equality of polynomials force
s equal degrees:
$$n = 2n - 3 \implies n = 3.$$

So $p$ is cubic. Write $p(x) = ax^3 + bx^2 + cx + d$ with $a \neq 0$.

**Compute both sides.**
$$p(2x) = 8ax^3 + 4bx^2 + 2cx + d,$$
$$p'(x) = 3ax^2 + 2bx + c, \qquad p''(x) = 6ax + 2b,$$
$$p'(x)p''(x) = (3ax^2+2bx+c)(6ax+2b) = 18a^2x^3 + 18abx^2 + (4b^2+6ac)x + 2bc.$
$

**Match coefficients.**

- $x^3$: $8a = 18a^2$. Since $a\neq 0$, $a = \tfrac{8}{18} = \tfrac{4}{9}$.
- $x^2$: $4b = 18ab = 18\cdot\tfrac{4}{9}\cdot b = 8b$, so $4b = 8b$, giving $b
= 0$.
- $x^1$: $2c = 4b^2 + 6ac = 0 + 6\cdot\tfrac{4}{9}\cdot c = \tfrac{8}{3}c$, so $
2c = \tfrac{8}{3}c$, giving $c = 0$.
- $x^0$: $d = 2bc = 0$.

Thus $p(x) = \tfrac{4}{9}x^3$.

**Verification.**
$$p(2x) = \tfrac{4}{9}\cdot 8x^3 = \tfrac{32}{9}x^3,$$
$$p'(x) = \tfrac{4}{3}x^2, \quad p''(x) = \tfrac{8}{3}x, \quad p'(x)p''(x) = \tf
rac{4}{3}\cdot\tfrac{8}{3}\,x^3 = \tfrac{32}{9}x^3.$$

Both sides agree, and $p'(x)p''(x) = \tfrac{32}{9}x^3$ is not the zero polynomia
l. Also $p$ itself is nontrivial (degree 3, $a = 4/9 \neq 0$).

$$\boxed{p(x) = \dfrac{4}{9}\,x^3}$$
