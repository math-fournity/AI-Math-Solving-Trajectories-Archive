## Proof

**Reformulation via prefix sums.** Assign $X = +1$, $O = -1$. Define prefix sums
 $p_0 = 0$ and $p_k = \sum_{i=1}^k s_i$ for a string $s_1 \cdots s_n$. For any s
ubstring $s_{i+1} \cdots s_j$, we have $\Delta = p_j - p_i$. The condition $-2 \
leq \Delta(T) \leq 2$ for all substrings is equivalent to:

$$\max_{0 \leq i \leq n} p_i - \min_{0 \leq i \leq n} p_i \leq 2.$$

So a string is balanced iff the range of its prefix sums is at most $2$. Each ba
lanced string corresponds to a walk of length $n$ on $\mathbb{Z}$ starting at $0
$, with steps $\pm 1$, whose visited values all lie in some interval of length $
\leq 2$.

**Reduction to three intervals.** Since $p_0 = 0$, the interval must contain $0$
. An interval of length $2$ containing $0$ is one of $\{0,1,2\}$, $\{-1,0,1\}$,
or $\{-2,-1,0\}$. Let:
- $A$ = walks staying in $\{0,1,2\}$, count $a_n$,
- $B$ = walks staying in $\{-1,0,1\}$, count $b_n$,
- $C$ = walks staying in $\{-2,-1,0\}$, count $c_n = a_n$ (by the symmetry $v \m
apsto -v$).

By inclusion-exclusion:
$$f(n) = |A \cup B \cup C| = 2a_n + b_n - |A \cap B| - |A \cap C| - |B \cap C| +
 |A \cap B \cap C|.$$

The pairwise intersections are walks on $\{0,1\}$, $\{0\}$, $\{-1,0\}$ respectiv
ely. A walk on $\{0,1\}$ starting at $0$ is forced to alternate $0,1,0,1,\ldots$
, giving exactly $1$ walk for every $n$; similarly for $\{-1,0\}$. A walk on $\{
0\}$ exists only for $n=0$. Thus for $n \geq 1$:

$$f(n) = 2a_n + b_n - 1 - 0 - 1 + 0 = 2a_n + b_n - 2.$$

(For $n=0$: $f(0) = 1$, which the formula also gives: $2\cdot 1 + 1 - 2 = 1$.)

**Computing $a_n$ (walks on $\{0,1,2\}$ starting at $0$).** Let $p_n, q_n, r_n$
be the counts ending at $0, 1, 2$. By symmetry $p_n = r_n$ for $n \geq 1$. The r
ecurrences are $p_{n+1} = q_n$, $q_{n+1} = p_n + r_n = 2p_n$, $r_{n+1} = q_n$, w
ith $p_0=1, q_0=0, r_0=0$.

From $p_{n+2} = q_{n+1} = 2p_n$ with $p_1 = 0$, $p_2 = 1$: we get $p_{2k+1} = 0$
 and $p_{2k} = 2^{k-1}$ for $k \geq 1$. Then $q_n = p_{n+1}$ gives $q_{2k} = 0$,
 $q_{2k+1} = 2^k$.

$$a_n = 2p_n + q_n = \begin{cases} 2^k & n = 2k \\ 2^k & n = 2k+1 \end{cases} =
2^{\lfloor n/2 \rfloor}.$$

**Computing $b_n$ (walks on $\{-1,0,1\}$ starting at $0$).** Let $u_n, v_n, w_n$
 be counts ending at $-1, 0, 1$. By symmetry $u_n = w_n$. Recurrences: $u_{n+1}
= v_n$, $v_{n+1} = 2u_n$, with $u_0=0, v_0=1$.

From $v_{n+2} = 2v_n$ with $v_0=1, v_1=0$: $v_{2k} = 2^k$, $v_{2k+1} = 0$. Then
$u_n = v_{n-1}$ gives $u_{2k}=0$, $u_{2k+1} = 2^k$.

$$b_n = 2u_n + v_n = \begin{cases} 2^k & n = 2k \\ 2^{k+1} & n = 2k+1 \end{cases
} = 2^{\lceil n/2 \rceil}.$$

**Combining.** For all $n \geq 0$:

$$f(n) = 2 \cdot 2^{\lfloor n/2 \rfloor} + 2^{\lceil n/2 \rceil} - 2 = 2^{\lfloo
r n/2 \rfloor + 1} + 2^{\lceil n/2 \rceil} - 2.$$

Equivalently, writing $n = 2k$ or $n = 2k+1$:

$$f(n) = \begin{cases} 3 \cdot 2^k - 2 & \text{if } n = 2k, \\ 2^{k+2} - 2 & \te
xt{if } n = 2k+1. \end{cases}$$

**Verification for small $n$:**
- $n=1$: $f(1) = 4 - 2 = 2$. Strings $X, O$; both balanced. ✓
- $n=2$: $f(2) = 6 - 2 = 4$. All four strings $XX, XO, OX, OO$ balanced. ✓
- $n=3$: $f(3) = 8 - 2 = 6$. Only $XXX$ ($\Delta=3$) and $OOO$ ($\Delta=-3$) fai
l. ✓
- $n=4$: $f(4) = 12 - 2 = 10$. The $6$ strings containing $XXX$ or $OOO$ fail; $
16-6=10$. ✓
- $n=5$: $f(5) = 16 - 2 = 14$. Verified by exhaustive enumeration over all $32$
strings. ✓

The number of balanced strings of length $n$ is $\boxed{2^{\lfloor n/2 \rfloor +
 1} + 2^{\lceil n/2 \rceil} - 2}$.
