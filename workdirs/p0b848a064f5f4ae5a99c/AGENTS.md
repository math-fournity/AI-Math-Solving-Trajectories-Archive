# Problem

In a specialized digital manufacturing facility, a lead engineer is programming an automated assembly line that produces customized alloy plates. The efficiency of the production sequence is dictated by the structure of a "Control Function," modeled as $x^n + x + 1$, where $n$ is a positive integer representing the batch size, and $n \leq 100$.

The facility's protocol requires that the manufacturing process be "Redundant." A process is defined as Redundant if its Control Function can be mathematically factored into a product of at least two separate sub-functions, each of which must have a positive integer degree and strictly integer coefficients. 

If the batch size $n$ results in a Redundant process, that batch size is considered "Stable."

Your task is to identify every Stable batch size $n$ in the range $1 \leq n \leq 100$ and calculate the total sum of all these specific integers.
