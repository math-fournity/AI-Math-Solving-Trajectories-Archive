## Proof

Let $z = x + iy$ with $x, y \in \mathbb{Q}$ and $|z| = 1$. Then $x^2 + y^2 = 1$,
 so we may write $z = e^{i\theta}$ where $\cos\theta = x$ and $\sin\theta = y$,
both rational.

**Key identity.** Since $|z|=1$, we have $\bar z = z^{-1}$. For any integer $n$:

$$|z^{2n}-1|^2 = (z^{2n}-1)\overline{(z^{2n}-1)} = (z^{2n}-1)(\bar z^{2n}-1) = (
z^{2n}-1)(z^{-2n}-1).$$

Expanding:

$$|z^{2n}-1|^2 = z^{2n}\cdot z^{-2n} - z^{2n} - z^{-2n} + 1 = 2 - (z^{2n}+z^{-2n
}).$$

Since $z = e^{i\theta}$, we have $z^{2n}+z^{-2n} = e^{2in\theta}+e^{-2in\theta}
= 2\cos(2n\theta)$. Therefore:

$$|z^{2n}-1|^2 = 2 - 2\cos(2n\theta) = 4\sin^2(n\theta),$$

using the double-angle identity $1-\cos(2n\theta)=2\sin^2(n\theta)$. Hence:

$$|z^{2n}-1| = 2|\sin(n\theta)|.$$

**Rationality of $\sin(n\theta)$.** We show $\sin(n\theta)\in\mathbb{Q}$ for eve
ry integer $n$.

Recall the Chebyshev polynomial of the second kind $U_{m}(t)$, defined by the id
entity

$$\sin((m+1)\theta) = \sin\theta\cdot U_m(\cos\theta),$$

where $U_m(t)$ is a polynomial with **integer coefficients** (this follows from
the recurrence $U_0=1$, $U_1=2t$, $U_{m+1}=2t\,U_m - U_{m-1}$).

For $n \geq 1$, setting $m = n-1$:

$$\sin(n\theta) = \sin\theta\cdot U_{n-1}(\cos\theta) = y\cdot U_{n-1}(x).$$

Since $U_{n-1}$ has integer coefficients and $x\in\mathbb{Q}$, we get $U_{n-1}(x
)\in\mathbb{Q}$, and since $y\in\mathbb{Q}$, we conclude $\sin(n\theta)\in\mathb
b{Q}$.

For $n=0$: $\sin(0)=0\in\mathbb{Q}$.

For $n<0$: $\sin(n\theta) = -\sin((-n)\theta)$, and $-n>0$ reduces to the case a
bove, so $\sin(n\theta)\in\mathbb{Q}$.

**Conclusion.** For every integer $n$, $\sin(n\theta)$ is rational, so

$$|z^{2n}-1| = 2|\sin(n\theta)| \in \mathbb{Q}. \qquad\blacksquare$$
