Looking at this problem, I need to find a constant $c$ such that $\lambda_n(AA^T
) \ge c\|A\|_F^2$ for all non-singular matrices $A$.

## Analysis

Let $A$ be an $n \times n$ non-singular matrix. Since $A$ is non-singular, $AA^T
$ is symmetric positive definite, with eigenvalues
$$\sigma_1^2 \ge \sigma_2^2 \ge \cdots \ge \sigma_n^2 > 0,$$
where $\sigma_1 \ge \cdots \ge \sigma_n > 0$ are the singular values of $A$. The
 Frobenius norm satisfies
$$\|A\|_F^2 = \operatorname{tr}(AA^T) = \sum_{i=1}^n \sigma_i^2.$$

The inequality $\lambda_n(AA^T) \ge c\,\|A\|_F^2$ is equivalent to
$$\sigma_n^2 \ge c\sum_{i=1}^n \sigma_i^2, \qquad\text{i.e.,}\qquad c \le \frac{
\sigma_n^2}{\sum_{i=1}^n \sigma_i^2}.$$

The best (largest) universal constant is therefore
$$c^* = \inf_{A\ \text{non-singular}} \frac{\sigma_n(A)^2}{\|A\|_F^2}.$$

## The infimum is $0$ (for $n \ge 2$)

Consider the family of non-singular matrices
$$A_\varepsilon = \operatorname{diag}(\varepsilon,\, 1,\, 1,\, \dots,\, 1), \qqu
ad \varepsilon \in (0,1).$$

- $A_\varepsilon$ is non-singular (diagonal with all positive entries).
- Singular values: $\sigma_1 = 1, \dots, \sigma_{n-1} = 1, \sigma_n = \varepsilo
n$.
- $\lambda_n(A_\varepsilon A_\varepsilon^T) = \varepsilon^2$.
- $\|A_\varepsilon\|_F^2 = \varepsilon^2 + (n-1)$.

The ratio is
$$\frac{\lambda_n(A_\varepsilon A_\varepsilon^T)}{\|A_\varepsilon\|_F^2} = \frac
{\varepsilon^2}{\varepsilon^2 + (n-1)} \xrightarrow{\varepsilon \to 0^+} 0.$$

Therefore, for any $c > 0$, choosing $\varepsilon$ small enough gives
$$\varepsilon^2 < c\bigl(\varepsilon^2 + (n-1)\bigr),$$
which violates the inequality. Hence **no positive constant** $c$ can satisfy $\
lambda_n(AA^T) \ge c\,\|A\|_F^2$ for all non-singular $A$.

## The only valid constant is $c = 0$

Since $AA^T$ is positive definite for non-singular $A$, we have $\lambda_n(AA^T)
 > 0 \ge 0 \cdot \|A\|_F^2$, so $c = 0$ trivially satisfies the inequality. Comb
ined with the argument above showing no $c > 0$ works, we conclude:

## Proof

**Claim.** The largest constant $c$ such that $\lambda_n(AA^T) \ge c\,\|A\|_F^2$
 holds for every non-singular $n\times n$ matrix $A$ (with $n \ge 2$) is $c = 0$
.

**Upper bound ($c^* \le 0$):** For $\varepsilon \in (0,1)$, set $A_\varepsilon =
 \operatorname{diag}(\varepsilon, 1, \dots, 1)$. This matrix is non-singular, wi
th
$$\frac{\lambda_n(A_\varepsilon A_\varepsilon^T)}{\|A_\varepsilon\|_F^2} = \frac
{\varepsilon^2}{\varepsilon^2 + n - 1} \to 0 \quad\text{as } \varepsilon \to 0^+
.$$
Thus $\inf_A \frac{\lambda_n(AA^T)}{\|A\|_F^2} = 0$, so any valid $c$ must satis
fy $c \le 0$.

**Lower bound ($c = 0$ works):** For any non-singular $A$, the matrix $AA^T$ is
positive definite, so every eigenvalue is strictly positive: $\lambda_n(AA^T) >
0 = 0 \cdot \|A\|_F^2$.

**Conclusion:** $c = 0$ is the unique largest constant satisfying the inequality
 for all non-singular matrices $A$ (when $n \ge 2$). No positive lower bound of
the form $c\,\|A\|_F^2$ exists for the smallest eigenvalue of $AA^T$ over the cl
ass of all non-singular matrices, because the condition number $\sigma_1/\sigma_
n$ can be made arbitrarily large while keeping $A$ non-singular.

$$\boxed{c = 0}$$
