## Proof

We wish to determine which of
$$f(n) = 3^{2^n}, \qquad g(n) = n!\cdot n^3$$
is asymptotically greater as $n\to\infty$.

Since both functions are positive for all $n\ge 1$, it suffices to compare their
 logarithms. We use the natural logarithm throughout.

**Logarithm of $f$.**
$$\ln f(n) = \ln\!\left(3^{2^n}\right) = 2^n \ln 3.$$

**Logarithm of $g$.** By Stirling's approximation,
$$\ln(n!) = n\ln n - n + O(\ln n),$$
so
$$\ln g(n) = \ln(n!) + 3\ln n = n\ln n - n + O(\ln n).$$

**Comparison.** We must compare
$$\ln f(n) = (\ln 3)\cdot 2^n \qquad\text{against}\qquad \ln g(n) = n\ln n - n +
 O(\ln n).$$

Consider the ratio
$$\frac{\ln g(n)}{\ln f(n)} = \frac{n\ln n - n + O(\ln n)}{(\ln 3)\cdot 2^n}.$$

The numerator $n\ln n - n + O(\ln n)$ grows like $n\ln n$, which is polynomial-t
imes-logarithmic in $n$. The denominator $(\ln 3)\cdot 2^n$ grows **exponentiall
y** in $n$. Since exponential growth dominates any polynomial (and in particular
 dominates $n\ln n$), we have
$$\lim_{n\to\infty}\frac{n\ln n}{2^n} = 0.$$

Therefore
$$\lim_{n\to\infty}\frac{\ln g(n)}{\ln f(n)} = 0.$$

**From logarithms back to the functions.** Since $\ln g(n) = o(\ln f(n))$, for a
ny fixed constant $c>0$ and all sufficiently large $n$ we have $\ln g(n) < c\,\l
n f(n)$, i.e. $g(n) < f(n)^c$. In particular, taking $c=1$ gives $g(n) < f(n)$ f
or all large $n$.

More sharply, consider the ratio of the functions themselves:
$$\frac{g(n)}{f(n)} = \exp\!\bigl(\ln g(n) - \ln f(n)\bigr) = \exp\!\bigl(-(\ln
3)\cdot 2^n + n\ln n - n + O(\ln n)\bigr).$$

The exponent tends to $-\infty$ because $2^n$ dominates $n\ln n$, so
$$\lim_{n\to\infty}\frac{g(n)}{f(n)} = 0.$$

Equivalently,
$$\lim_{n\to\infty}\frac{f(n)}{g(n)} = +\infty.$$

## Conclusion

$$\boxed{f(n) = 3^{2^n} \text{ is asymptotically greater than } g(n) = n!\cdot n
^3.}$$

The decisive reason is that $\ln f(n) = (\ln 3)\,2^n$ grows **exponentially**, w
hereas $\ln g(n) = n\ln n - n + O(\ln n)$ (by Stirling) grows only as $n\ln n$.
Exponential growth of $2^n$ overwhelms the polynomial-logarithmic growth of $n\l
n n$, so $f(n)/g(n)\to\infty$.
