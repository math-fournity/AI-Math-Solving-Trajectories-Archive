## Proof

**Setup and round decomposition.** Encode each lamp as a bit (1 = ON, 0 = OFF),
with indices mod $n$. At step $j$ the update is
$$L_{j} \;\longleftarrow\; L_{j} \oplus L_{j-1},$$
which is linear over $\mathbb{F}_2$. Group the steps into rounds of $n$ consecut
ive steps. Let $v^{r}=(v^{r}_{0},\dots,v^{r}_{n-1})$ be the state after $r$ comp
lete rounds ($rn$ steps), with $v^{-1}=(1,1,\dots,1)$ the initial state. Within
round $r+1$ the lamps are updated sequentially $0,1,\dots,n-1$, so
$$\text{new}_{0}=v^{r}_{0}\oplus v^{r}_{n-1},\qquad \text{new}_{i}=v^{r}_{i}\opl
us \text{new}_{i-1}\ \ (1\le i\le n-1),$$
and $v^{r+1}=(\text{new}_{0},\dots,\text{new}_{n-1})$. After $i$ steps *into* ro
und $r+1$ the state is
$$(\text{new}_{0},\dots,\text{new}_{i-1},\,v^{r}_{i},\dots,v^{r}_{n-1}). \tag{$\
star$}$$
Each step map is invertible, so the orbit of the all‑ones state is purely period
ic; $M(n)$ is the first positive time this orbit returns to all‑ones.

---

**Computation of $M(8)$.** Applying the recurrence above to $v^{-1}=11111111$ gi
ves the round‑end states

| $r$ | $v^{r}$ |
|---|---|
| $-1$ | `11111111` |
| $0$ | `01010101` |
| $1$ | `10011001` |
| $2$ | `00010001` |
| $3$ | `11100001` |
| $4$ | `01000001` |
| $5$ | `10000001` |
| $6$ | `00000001` |
| $7$ | `11111110` |

None of $v^{0},\dots,v^{7}$ is all‑ones, so no return occurs at a round boundary
 through round 7.

For a mid‑round return during round $r+1$, by ($\star$) we need a suffix $v^{r}_
{i},\dots,v^{r}_{n-1}$ equal to all $1$'s **and** $\text{new}_{0},\dots,\text{ne
w}_{i-1}$ all equal to $1$. Inspecting the table, the only round whose starting
state has an all‑ones suffix is round $7$, starting from $v^{6}=\texttt{00000001
}$ (suffix of length $1$, namely $v^{6}_{7}=1$). In round $7$:
$$\text{new}_{0}=0\oplus1=1,\ \text{new}_{1}=0\oplus1=1,\ \dots,\ \text{new}_{6}
=0\oplus1=1,$$
so after $i=7$ steps the state is $(\underbrace{1,1,1,1,1,1,1}_{\text{new}},\,v^
{6}_{7}=1)=11111111$. No earlier round admits a mid‑round all‑ones state (each $
v^{r}$ for $r\le 5$ has $v^{r}_{7}=1$ but the prefix $\text{new}_{0},\dots$ hits
 a $0$ before reaching length $7$; round $0$ has $\text{new}_{0}=0$). Hence
$$M(8)=7\cdot 8+7=63.$$

---

**Computation of $M(9)$.** Starting from $v^{-1}=111111111$ the round‑end states
 are

| $r$ | $v^{r}$ |
|---|---|
| $-1$ | `111111111` |
| $0$ | `010101010` |
| $1$ | `011001100` |
| $2$ | `010001000` |
| $3$ | `011110000` |
| $4$ | `010100000` |
| $5$ | `011000000` |
| $6$ | `010000000` |
| $7$ | `011111111` |

None of $v^{0},\dots,v^{7}$ is all‑ones. For a mid‑round return during round $r+
1$ we again need an all‑ones suffix of $v^{r}$. For $r=0,\dots,6$ the last bit $
v^{r}_{8}=0$, so no suffix of positive length is all‑ones (and the full‑round ca
se $i=9$ is exactly the round‑end state, already excluded). For round $0$ (start
ing from all‑ones) $\text{new}_{0}=1\oplus1=0$, blocking every $i\ge1$. The deci
sive round is round $8$, starting from $v^{7}=\texttt{011111111}$, which has an
all‑ones suffix of length $8$ (positions $1,\dots,8$). Taking $i=1$:
$$\text{new}_{0}=v^{7}_{0}\oplus v^{7}_{8}=0\oplus1=1,$$
and the unprocessed tail is $v^{7}_{1},\dots,v^{7}_{8}=11111111$, so the state a
fter one step is $111111111$. Thus
$$M(9)=8\cdot 9+1=73.$$

---

**Conclusion.**
$$M(8)+M(9)=63+73=\boxed{136}.$$
