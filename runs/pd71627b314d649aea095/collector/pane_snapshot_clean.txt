Claim: Yes, such a subset $\mathfrak{F}$ exists. In fact, every subset $
\mathfrak{F} \subseteq \omega^\omega$ with $|\mathfrak{F}| = \aleph_1$ satisfies
the required property.

────────────────────────────────────────────────────────────────────────────────

Step 1: An $\aleph_1$-sized subset of $\omega^\omega$ exists.

The set $\omega^\omega$ has cardinality $|\omega|^{|\omega|} =
\aleph_0^{\aleph_0} = 2^{\aleph_0}$. By Cantor's theorem, $2^{\aleph_0} >
\aleph_0$. Since $\aleph_1$ is the least uncountable cardinal, we have $\aleph_1
\leq 2^{\aleph_0}$. Hence we may choose any subset $\mathfrak{F} \subseteq
\omega^\omega$ with $|\mathfrak{F}| = \aleph_1$.

────────────────────────────────────────────────────────────────────────────────

Step 2: Any $\mathfrak{G} \subseteq \mathfrak{F}$ with $|\mathfrak{G}| <
\aleph_1$ is at most countable.

In ZFC, the cardinals strictly below $\aleph_1$ are exactly the finite cardinals
and $\aleph_0$. Therefore $|\mathfrak{G}| < \aleph_1$ implies $|\mathfrak{G}|
\leq \aleph_0$.

────────────────────────────────────────────────────────────────────────────────

Step 3: The set of finite compositions from $\mathfrak{G}$ has cardinality at
most $\aleph_0$.

Define the set of finite compositions: $$\mathrm{Comp}(\mathfrak{G}) = {g_1
\circ g_2 \circ \cdots \circ g_n : n \geq 1,; g_1, \dots, g_n \in \mathfrak{G}}.
$$

(If one also admits the empty composition — the identity — this adds at most one
element and does not affect the cardinality argument.)

We bound the cardinality: $$|\mathrm{Comp}(\mathfrak{G})| \leq \left|
\bigcup_{n=1}^{\infty} \mathfrak{G}^n\right| \leq \sum_{n=1}^{\infty} |
\mathfrak{G}|^n.$$

  • If $|\mathfrak{G}|$ is finite, each $|\mathfrak{G}|^n$ is finite, so the sum
  is $\leq \aleph_0 \cdot \aleph_0 = \aleph_0$.
  • If $|\mathfrak{G}| = \aleph_0$, each $|\mathfrak{G}|^n = \aleph_0$, so the
  sum is $\aleph_0 \cdot \aleph_0 = \aleph_0$.

In either case, $|\mathrm{Comp}(\mathfrak{G})| \leq \aleph_0$.
