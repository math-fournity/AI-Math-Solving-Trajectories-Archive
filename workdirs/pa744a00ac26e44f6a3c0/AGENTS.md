# Problem

A high-security data vault requires a specific configuration of encryption keys to function. To set up the vault, a security engineer must select two distinct groups of unique integer-coded keys, Group $A$ and Group $B$.

The engineer must adhere to the following protocols:
i) Group $A$ must contain exactly $n$ keys (where $n \geq 5$), and every key assigned to Group $A$ must also be included in Group $B$, which contains a total of $m$ keys.
ii) The vault’s "Sum-Stability" rule states: For any two different keys $x$ and $y$ present in Group $B$, their numerical sum $x+y$ is also a key in Group $B$ if and only if both $x$ and $y$ were originally chosen from Group $A$.

If the engineer follows these protocols strictly, what is the minimum possible number of keys, $m$, that must be included in Group $B$?
