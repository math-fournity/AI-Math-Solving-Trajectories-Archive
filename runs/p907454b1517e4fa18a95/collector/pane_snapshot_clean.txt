# Solution

**Claim:** There are infinitely many numbers appearing in both sequences.

## Closed forms

**Sequence $b_n$.** The characteristic equation is $x^2 - 6x + 1 = 0$ with roots
 $3 \pm 2\sqrt{2}$. Writing $b_n = \alpha(3+2\sqrt{2})^n + \beta(3-2\sqrt{2})^n$
 and using $b_0=2,\, b_1=14$:

$$\alpha+\beta = 2, \qquad 3(\alpha+\beta)+2\sqrt{2}(\alpha-\beta)=14,$$

giving $\alpha = 1+\sqrt{2}$, $\beta = 1-\sqrt{2}$. Since $3+2\sqrt{2}=(1+\sqrt{
2})^2$, we obtain

$$b_n = (1+\sqrt{2})^{2n+1}+(1-\sqrt{2})^{2n+1}.$$

**Sequence $a_n$.** The characteristic equation is $x^2-14x-1=0$ with roots $7\p
m 5\sqrt{2}$. Writing $a_n = \alpha(7+5\sqrt{2})^n+\beta(7-5\sqrt{2})^n$ and usi
ng $a_0=2,\,a_1=14$:

$$\alpha+\beta=2,\qquad 7(\alpha+\beta)+5\sqrt{2}(\alpha-\beta)=14,$$

giving $\alpha=\beta=1$. Since $7+5\sqrt{2}=(1+\sqrt{2})^3$ (as $(1+\sqrt{2})^3
= 1+3\sqrt{2}+6+2\sqrt{2}=7+5\sqrt{2}$), we obtain

$$a_n = (1+\sqrt{2})^{3n}+(1-\sqrt{2})^{3n}.$$

## The Pell–Lucas function

Define $P_k = (1+\sqrt{2})^k+(1-\sqrt{2})^k$ for $k\ge 0$. Then:

$$a_n = P_{3n}, \qquad b_n = P_{2n+1}.$$

**Monotonicity.** We have $P_0=P_1=2$, and for $k\ge 1$ the sequence $P_k$ is st
rictly increasing: since $|1-\sqrt{2}|<1$, the term $(1-\sqrt{2})^k$ is bounded
with $|(1-\sqrt{2})^k|<1$, while $(1+\sqrt{2})^k$ grows without bound, so $P_k$
is dominated by $(1+\sqrt{2})^k$ and increases strictly for $k\ge 1$.

## Infinitely many common terms

A value appears in both sequences iff it equals $P_{3n}$ for some $n\ge 0$ **and
** $P_{2m+1}$ for some $m\ge 0$. By strict monotonicity (for indices $\ge 1$), t
his requires the indices to coincide:

$$3n = 2m+1, \qquad n,m\ge 0.$$

This holds for every $k = 3n = 2m+1$ with $k$ simultaneously a multiple of $3$ a
nd odd, i.e., $k \equiv 3 \pmod{6}$. Setting $k = 6j+3$ for $j = 0,1,2,\dots$:

- $n = 2j+1 \ge 1$, so $P_{6j+3} = a_{2j+1}$,
- $m = 3j+1 \ge 1$, so $P_{6j+3} = b_{3j+1}$.

Thus $a_{2j+1} = b_{3j+1} = P_{6j+3}$ for every $j\ge 0$.

**Verification ($j=0$):** $P_3 = (1+\sqrt{2})^3+(1-\sqrt{2})^3 = 14$, and indeed
 $a_1 = b_1 = 14$.

**Verification ($j=1$):** $P_9$. We compute $a_3 = 14\cdot 198+14 = 2786$ and $b
_4 = 6\cdot 478 - 82 = 2786$, confirming $a_3 = b_4 = P_9 = 2786$.

Since $P_k$ is strictly increasing for $k\ge 1$, the values $P_3, P_9, P_{15}, P
_{21}, \dots$ are all distinct, yielding **infinitely many** common terms.

## Conclusion

There are infinitely many numbers appearing in both sequences; specifically, $P_
{6j+3} = a_{2j+1} = b_{3j+1}$ for every $j\ge 0$.
