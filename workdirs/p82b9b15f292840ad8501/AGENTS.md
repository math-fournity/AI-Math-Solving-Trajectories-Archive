# Problem

A specialized computer server is programmed to process batches of data. The server defines a batch size $k$ as "efficient" if the product of the first $k$ prime numbers is exactly divisible by the integer $k$. 

For instance, a batch size of $k=2$ is efficient because the product of the first two primes ($2 \times 3 = 6$) is divisible by 2.

A software engineer is monitoring the performance of the server and notices that efficient batch sizes sometimes occur in sequences of consecutive integers (e.g., $k, k+1, k+2, \dots$). What is the maximum possible number of consecutive efficient batch sizes?
