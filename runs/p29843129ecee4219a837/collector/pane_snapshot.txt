**Answer: No.** Not every Borel set is $G_{\delta,\sigma}$. Below is a proof via
 the standard universal-set diagonal argument, showing the Borel hierarchy is st
rict at level 3.

---

**Setup.** Work in the Baire space $\mathcal{N}=\omega^{\omega}$ (homeomorphic t
o the irrationals; the result transfers to $\mathbb{R}$ and any uncountable Poli
sh space). Recall the Borel hierarchy:

- $\Sigma^0_1 = $ open ($G$), $\;\Pi^0_1 = $ closed ($F$),
- $\Sigma^0_2 = F_\sigma$, $\;\Pi^0_2 = G_\delta$,
- $\Sigma^0_3 = G_{\delta,\sigma}$ (countable unions of $G_\delta$ sets), $\;\Pi
^0_3 = F_{\sigma,\delta}$,

and $\Pi^0_3 \subseteq \text{Borel}$. We will exhibit a Borel set that is $\Pi^0
_3$ but **not** $\Sigma^0_3$.

---

**Step 1: A universal open set.** Enumerate all finite sequences of naturals as
$\{s_n\}_{n\in\omega}$; the sets $N_{s_n}=\{y\in\mathcal{N}: s_n\subset y\}$ for
m a countable base. Define
$$V=\{(x,y)\in\mathcal{N}\times\mathcal{N}:\exists n,\; x(n)>0 \text{ and } y\in
 N_{s_n}\}=\bigcup_n \{x:x(n)>0\}\times N_{s_n}.$$
This is **open**, and for every open $O=\bigcup_{n\in A}N_{s_n}\subseteq\mathcal
{N}$, taking $x_A$ with $x_A(n)=\mathbf{1}_{n\in A}$ gives $V_{x_A}=O$. So $V$ i
s *universal* for open sets.

**Step 2: A universal $G_\delta$ set.** Fix a pairing bijection $\pi:\omega\time
s\omega\to\omega$ and write $x^{[k]}(n)=x(\pi(k,n))$, so $x$ encodes a sequence
$(x^{[0]},x^{[1]},\dots)$. Define
$$W=\{(x,y):\forall k,\;(x^{[k]},y)\in V\}=\bigcap_k \underbrace{\{(x,y):(x^{[k]
},y)\in V\}}_{\text{open}}.$$
So $W$ is $G_\delta$. For any $G_\delta$ set $G=\bigcap_k O_k$ (each $O_k$ open)
, pick $x_k$ with $V_{x_k}=O_k$ and let $x$ encode $(x_0,x_1,\dots)$; then $W_x=
\bigcap_k O_k=G$. So $W$ is *universal* for $G_\delta$ sets.

**Step 3: A universal $G_{\delta,\sigma}$ set.** Use a tripling bijection $\pi_3
:\omega^3\to\omega$ and write $x^{[j,k]}(n)=x(\pi_3(j,k,n))$. Define
$$U=\{(x,y):\exists j,\;\forall k,\;(x^{[j,k]},y)\in V\}=\bigcup_j\bigcap_k \und
erbrace{\{(x,y):(x^{[j,k]},y)\in V\}}_{\text{open}}.$$
So $U$ is $G_{\delta,\sigma}=\Sigma^0_3$. For any $G_{\delta,\sigma}$ set $S=\bi
gcup_j G_j$ with $G_j=\bigcap_k O_{j,k}$ (each $O_{j,k}$ open), choose $x_{j,k}$
 with $V_{x_{j,k}}=O_{j,k}$ and encode everything into one $x$; then $U_x=S$. So
 $U$ is *universal* for $G_{\delta,\sigma}$ sets: **every** $G_{\delta,\sigma}\s
ubseteq\mathcal{N}$ set is some section $U_x$.

---

**Step 4: The diagonal set.** Define
$$D=\{x\in\mathcal{N}:x\notin U_x\}=\{x:(x,x)\notin U\},\qquad U_x:=\{y:(x,y)\in
 U\}.$$

- **$D$ is Borel (indeed $\Pi^0_3$).** The diagonal map $\Delta:\mathcal{N}\to\m
athcal{N}\times\mathcal{N}$, $\Delta(x)=(x,x)$, is continuous. Since $U$ is $\Si
gma^0_3$, its complement $U^c$ is $\Pi^0_3=F_{\sigma,\delta}$, and preimages of
$\Pi^0_3$ sets under continuous maps are $\Pi^0_3$. Thus $D=\Delta^{-1}(U^c)$ is
 $F_{\sigma,\delta}=\Pi^0_3$, hence Borel.

- **$D$ is not $G_{\delta,\sigma}$.** Suppose for contradiction that $D\in\Sigma
^0_3=G_{\delta,\sigma}$. By universality (Step 3), there exists $x_0\in\mathcal{
N}$ with $U_{x_0}=D$. Then:
$$x_0\in D \iff x_0\in U_{x_0} \iff (x_0,x_0)\in U \iff x_0\notin D,$$
a contradiction. (The first $\iff$ uses $U_{x_0}=D$; the second is the definitio
n of $U_{x_0}$; the third is the definition of $D$.) $\Rightarrow\!\Leftarrow$

---

**Conclusion.** $D$ is a Borel set (in fact $F_{\sigma,\delta}$) that is **not**
 $G_{\delta,\sigma}$. Therefore not every Borel set is $G_{\delta,\sigma}$; the
inclusion $\Sigma^0_3\subsetneq\text{Borel}$ is strict. $\blacksquare$
