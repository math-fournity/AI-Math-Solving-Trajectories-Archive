## Solution

**Setup.** Let $P(x) = x^{2560} + 2x^{2559} + 3x^{2558} + \dotsb + 2561 = \sum_{
k=0}^{2560}(k+1)\,x^{2560-k}$, with roots $x_1,\dots,x_{2560}$.

**Key identity.** Since $x^2+1 = (x-i)(x+i)$,

$$\prod_{j=1}^{2560}(x_j^2+1) = \prod_{j=1}^{2560}(x_j - i)\cdot\prod_{j=1}^{256
0}(x_j + i) = \prod_{j=1}^{2560}(x_j-i)\cdot\prod_{j=1}^{2560}(x_j-(-i)).$$

Since $P$ is monic of even degree $n=2560$, $\prod_{j=1}^{n}(x_j - a) = (-1)^n P
(a) = P(a)$. Therefore

$$\prod_{j=1}^{2560}(x_j^2+1) = P(i)\cdot P(-i).$$

**Evaluating $P(i)$.** Re-index with $j = 2560-k$ (so $k+1 = 2561-j$):

$$P(i) = \sum_{j=0}^{2560}(2561-j)\,i^{\,j}.$$

Since $2560 = 4\cdot 640$, the powers $i^j$ complete 640 full cycles. Grouping b
y $j \bmod 4$, let $S_r = \sum_{j\equiv r\,(4)}(2561-j)$:

- $r=0$: $j=0,4,\dots,2560$ (641 terms), values $2561,2557,\dots,1$: $S_0 = 641\
cdot\tfrac{2561+1}{2} = 641\cdot 1281 = 821121$.
- $r=1$: $j=1,5,\dots,2557$ (640 terms), values $2560,2556,\dots,4$: $S_1 = 640\
cdot\tfrac{2560+4}{2} = 640\cdot 1282 = 820480$.
- $r=2$: $j=2,6,\dots,2558$ (640 terms), values $2559,2555,\dots,3$: $S_2 = 640\
cdot\tfrac{2559+3}{2} = 640\cdot 1281 = 819840$.
- $r=3$: $j=3,7,\dots,2559$ (640 terms), values $2558,2554,\dots,2$: $S_3 = 640\
cdot\tfrac{2558+2}{2} = 640\cdot 1280 = 819200$.

(Check: $S_0+S_1+S_2+S_3 = 3280641 = \sum_{m=1}^{2561}m = \tfrac{2561\cdot 2562}
{2}$. ✓)

Using $i^0=1,\, i^1=i,\, i^2=-1,\, i^3=-i$:

$$P(i) = (S_0 - S_2) + i(S_1 - S_3) = (821121-819840) + i(820480-819200) = 1281
+ 1280i.$$

Since $P$ has real coefficients, $P(-i) = \overline{P(i)} = 1281 - 1280i$.

**Final computation.**

$$P(i)\cdot P(-i) = 1281^2 + 1280^2 = 1640961 + 1638400 = 3279361.$$
