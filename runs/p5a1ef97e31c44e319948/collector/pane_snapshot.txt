## Answer

The maximal dimension is $\rho(n)$, the **Radon–Hurwitz number**, defined as fol
lows. Write
$$n = 2^{4a+b}\cdot m, \qquad m \text{ odd},\quad 0 \le b \le 3,$$
so that $s = v_2(n) = 4a+b$ with $a \ge 0$ and $0 \le b \le 3$. Then
$$\boxed{\rho(n) = 8a + 2^b}.$$

## Proof

The proof has two parts: an **upper bound** $d \le \rho(n)$ (using Adams' theore
m on vector fields on spheres) and a **lower bound** $d \ge \rho(n)$ (using the
Hurwitz–Radon–Eckmann construction of Clifford systems).

### Part 1: Upper bound — $d \le \rho(n)$

Let $F$ be a $d$-dimensional subspace of $M_n(\mathbb{R})$ whose only non-invert
ible element is $O$. Choose a basis $A_1, A_2, \ldots, A_d$ of $F$ with $A_1 = I
_n$ (replace $A_1$ by any invertible element of $F$ and conjugate the basis; the
 property is preserved since $A_1^{-1}F$ is again such a subspace containing $I$
). Set $B_i = A_i$ for $i = 2, \ldots, d$.

**Key property.** Every nonzero real linear combination $\alpha_0 I + \sum_{i=2}
^d \alpha_i B_i$ is invertible.

**Construction of vector fields on $S^{n-1}$.** For each $i \in \{2, \ldots, d\}
$, define a vector field $V_i$ on $S^{n-1}$ by
$$V_i(x) = B_i\, x - \langle B_i\, x,\, x\rangle\, x, \qquad x \in S^{n-1}.$$
This is the orthogonal projection of $B_i x$ onto the tangent space $T_x S^{n-1}
 = \{v : \langle v, x\rangle = 0\}$, so $V_i$ is a tangent vector field.

**Claim.** $V_2, \ldots, V_d$ are $(d-1)$ linearly independent vector fields on
$S^{n-1}$.

*Proof of claim.* Fix $x \in S^{n-1}$ and suppose $\sum_{i=2}^d c_i V_i(x) = 0$.
 Then
$$\sum_{i=2}^d c_i B_i\, x = \left(\sum_{i=2}^d c_i \langle B_i x, x\rangle\righ
t) x.$$
Set $\lambda = \sum_{i=2}^d c_i \langle B_i x, x\rangle$. Then
$$\left(\sum_{i=2}^d c_i B_i - \lambda I\right) x = 0.$$
If not all $c_i$ are zero, then $\sum_{i=2}^d c_i B_i - \lambda I \neq 0$ (since
 $\{I, B_2, \ldots, B_d\}$ are linearly independent, $I$ is not in the span of $
B_2, \ldots, B_d$). This nonzero element of $F$ is therefore invertible, contrad
icting that it kills $x \neq 0$. Hence all $c_i = 0$, proving linear independenc
e. $\square$

**Applying Adams' theorem.** By the theorem of Adams (1962), the maximum number
of everywhere-linearly-independent tangent vector fields on $S^{n-1}$ is $\rho(n
) - 1$. Therefore
$$d - 1 \le \rho(n) - 1 \implies d \le \rho(n).$$

### Part 2: Lower bound — $d \ge \rho(n)$

We construct a $\rho(n)$-dimensional subspace of $M_n(\mathbb{R})$ in which ever
y nonzero element is invertible.

**Hurwitz–Radon–Eckmann theorem (Clifford system).** Write $n = 2^{4a+b}\cdot m$
 with $m$ odd and $0 \le b \le 3$, so $\rho(n) = 8a + 2^b$. Set $r = \rho(n) - 1
$. Then there exist $r$ matrices $E_1, \ldots, E_r \in M_n(\mathbb{R})$ satisfyi
ng:
1. $E_i^\top = -E_i$ (skew-symmetric),
2. $E_i^2 = -I_n$,
3. $E_i E_j + E_j E_i = 0$ for $i \neq j$ (anticommuting).

This is the existence of an orthogonal representation of the Clifford algebra $\
mathrm{Cl}_r$ on $\mathbb{R}^n$, which exists precisely when $r \le \rho(n)-1$.
(This is the Hurwitz–Radon theorem in the formulation due to Eckmann; the bound
$r \le \rho(n)-1$ is sharp.)

**The subspace.** Define
$$F = \mathrm{span}\{I_n,\, E_1,\, \ldots,\, E_r\} \subseteq M_n(\mathbb{R}).$$
This has dimension $r + 1 = \rho(n)$ (the matrices are linearly independent sinc
e $I_n$ is symmetric while each $E_i$ is skew-symmetric, and the $E_i$ are linea
rly independent by the anticommutation relations).

**Every nonzero element is invertible.** Take any nonzero $A = c_0 I_n + \sum_{i
=1}^r c_i E_i \in F$. Compute $A^\top A$:
$$A^\top = c_0 I_n - \sum_{i=1}^r c_i E_i \quad (\text{since } E_i^\top = -E_i),
$$
$$A^\top A = \left(c_0 I - \sum c_i E_i\right)\left(c_0 I + \sum c_i E_i\right)
= c_0^2 I - \left(\sum c_i E_i\right)^2.$$
Using the anticommutation and $E_i^2 = -I$:
$$\left(\sum_{i=1}^r c_i E_i\right)^2 = \sum_i c_i^2 E_i^2 + \sum_{i < j} c_i c_
j(E_i E_j + E_j E_i) = -\left(\sum_i c_i^2\right) I.$$
Therefore
$$A^\top A = \left(c_0^2 + \sum_{i=1}^r c_i^2\right) I_n.$$
Since $(c_0, c_1, \ldots, c_r) \neq 0$, we have $c_0^2 + \sum c_i^2 > 0$, so $A^
\top A$ is a positive scalar multiple of $I_n$, hence invertible. Therefore $A$
is invertible.

Thus $F$ is a $\rho(n)$-dimensional subspace whose only non-invertible element i
s $O$.

### Conclusion

Combining both parts:
$$\rho(n) \le \dim F \le \rho(n),$$
so the maximal dimension is exactly $\rho(n)$.

Explicitly, writing $n = 2^{4a+b}\cdot m$ with $m$ odd and $0 \le b \le 3$:

$$\boxed{\dim_{\max} F = \rho(n) = 8a + 2^b.}$$

**Examples.** $n$ odd $\Rightarrow \rho(n)=1$; $n=2 \Rightarrow \rho=2$ (complex
 numbers); $n=4 \Rightarrow \rho=4$ (quaternions); $n=8 \Rightarrow \rho=8$ (oct
onions); $n=16 \Rightarrow \rho=9$.
