## Solution

**Claim:** The closed linear span of $\{x_k : k \geq 1\}$ is dense in $\ell_3$.

**Setup.** Write elements of $\ell_3$ as $a = (a_0, a_1, a_2, \dots)$ with $\|a\
|_3^3 = \sum_{n=0}^\infty |a_n|^3 < \infty$. The vector $x_k$ has $n$-th coordin
ate $(x_k)_n = 3^{-nk}$, so
$$x_k = (1,\, 3^{-k},\, 3^{-2k},\, 3^{-3k},\, \dots).$$
For $k\ge 1$ we have $x_k \in \ell_3$ since $\sum_{n\ge 0} 3^{-3nk} = \frac{1}{1
-3^{-3k}} < \infty$.

**Strategy.** By the Hahn–Banach theorem, the closed linear span $\overline{\ope
ratorname{span}}\{x_k\}$ equals $\ell_3$ if and only if the only continuous line
ar functional on $\ell_3$ that annihilates every $x_k$ is the zero functional.

**Dual space.** The dual of $\ell_3$ is $\ell_{3/2}$ (where $3/2$ is the conjuga
te exponent of $3$). Every continuous linear functional on $\ell_3$ is of the fo
rm
$$\Lambda_y(a) = \sum_{n=0}^\infty y_n\, a_n, \qquad y = (y_0,y_1,y_2,\dots) \in
 \ell_{3/2}.$$

**Annihilation condition.** The functional $\Lambda_y$ vanishes on every $x_k$ i
ff
$$\sum_{n=0}^\infty y_n\, 3^{-nk} = 0 \quad\text{for all } k = 1,2,3,\dots \tag{
$\ast$}$$

**Analytic function.** Define $f(z) = \sum_{n=0}^\infty y_n\, z^n$. Since $y \in
 \ell_{3/2}$, by Hölder's inequality, for any $|z|<1$:
$$\sum_{n=0}^\infty |y_n|\,|z|^n \le \|y\|_{3/2}\left(\sum_{n=0}^\infty |z|^{3n}
\right)^{1/3} = \|y\|_{3/2}\left(\frac{1}{1-|z|^3}\right)^{1/3} < \infty.$$
Hence $f$ converges absolutely on the open unit disk $\mathbb{D} = \{z : |z|<1\}
$ and is analytic there. Condition $(\ast)$ says
$$f(3^{-k}) = 0 \quad\text{for all } k = 1,2,3,\dots$$

**Applying the identity theorem.** The points $\{3^{-k}\}_{k\ge 1}$ all lie in $
\mathbb{D}$ and accumulate at $0 \in \mathbb{D}$. Since $f$ is analytic on the c
onnected open set $\mathbb{D}$ and its zero set has a limit point inside $\mathb
b{D}$, the identity theorem for analytic functions forces
$$f \equiv 0 \quad\text{on } \mathbb{D}.$$

**Conclusion.** All Taylor coefficients of the identically zero function vanish,
 so $y_n = 0$ for every $n \ge 0$, i.e., $y = 0$ in $\ell_{3/2}$. Thus the only
continuous linear functional annihilating all $x_k$ is the zero functional. By H
ahn–Banach,
$$\overline{\operatorname{span}}\{x_k : k \ge 1\} = \ell_3.$$

The space generated by the sequence $\{x_k\}$ **is dense** in $\ell_3$.
