# Cardinality of $\mathbb{R}^\infty$

The notation $\mathbb{R}^\infty$ is used in two standard senses. I show that **i
n both cases** the cardinality equals $\beth_1 = 2^{\aleph_0}$.

Recall $\beth_0 = \aleph_0$ and $\beth_1 = 2^{\beth_0} = 2^{\aleph_0} = |\mathbb
{R}|$.

---

## Interpretation A: $\mathbb{R}^\infty = \bigoplus_{n=1}^{\infty}\mathbb{R}$ (e
ventually-zero sequences)

This is the direct limit of the inclusions $\mathbb{R}^1 \hookrightarrow \mathbb
{R}^2 \hookrightarrow \mathbb{R}^3 \hookrightarrow \cdots$, i.e.

$$\mathbb{R}^\infty = \bigcup_{n=1}^{\infty} \mathbb{R}^n = \{(x_1,x_2,\dots) :
x_k = 0 \text{ for all but finitely many } k\}.$$

**Lower bound.** $\mathbb{R}^1 \subseteq \mathbb{R}^\infty$, so $|\mathbb{R}^\in
fty| \geq |\mathbb{R}| = \beth_1$.

**Upper bound.** $\mathbb{R}^\infty = \bigcup_{n=1}^{\infty}\mathbb{R}^n$ is a c
ountable union. For each $n \geq 1$, $|\mathbb{R}^n| = |\mathbb{R}| = \beth_1$ (
a finite product of sets of size $\beth_1$ has size $\beth_1$). Hence

$$\left|\mathbb{R}^\infty\right| \leq \sum_{n=1}^{\infty} \beth_1 = \beth_1 \cdo
t \aleph_0 = \beth_1,$$

since $\beth_1$ is an uncountable cardinal and $\beth_1 \cdot \aleph_0 = \max(\b
eth_1,\aleph_0) = \beth_1$.

Combining: $|\mathbb{R}^\infty| = \beth_1$. ✓

## Interpretation B: $\mathbb{R}^\infty = \mathbb{R}^{\mathbb{N}} = \prod_{n=1}^
{\infty}\mathbb{R}$ (all sequences)

$$\left|\mathbb{R}^{\mathbb{N}}\right| = |\mathbb{R}|^{\aleph_0} = (2^{\aleph_0}
)^{\aleph_0}.$$

Using the law of exponents for cardinal arithmetic, $(2^{\aleph_0})^{\aleph_0} =

able × countable = countable, e.g. via the Cantor pairing function),

$$(2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0} = \beth_1.$$

So $|\mathbb{R}^{\mathbb{N}}| = \beth_1$. ✓

## Conclusion

Under either standard interpretation of $\mathbb{R}^\infty$ — the countable **di

$$|\mathbb{R}^\infty| = 2^{\aleph_0} = \beth_1.$$

**Yes, the cardinality of $\mathbb{R}^\infty$ is the same as $\beth_1$.**
