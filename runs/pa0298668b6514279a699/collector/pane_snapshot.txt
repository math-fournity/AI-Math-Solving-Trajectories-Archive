**证明。**

设圆 ω 上弧 AB、BC、CD、DA（按 A、B、C、D 的顺序）的大小分别为 2a、2b、2c、2d，
因此 a + b + c + d = π。

**第一步：由切线条件得出的角度。**

由于 (ADQ) 的外接圆在 A 点与直线 AC 相切，根据切线-弦角定理：
∠ADQ = ∠CAB = b, ∠AQD = ∠CAD = c。

由于 (BCP) 的外接圆在 B 点与直线 BD 相切：
∠BCP = ∠DBA = d, ∠BPC = ∠DBC = c。

**第二步：长度 AQ 和 BP。**

在 △ADQ 中，其中 ∠QAD = π − (b+c)，根据正弦定理：AQ = AD sin b / sin c。

在 △BCP 中，其中 ∠CBP = π − (d+c)，根据正弦定理：BP = BC sin d / sin c。

**第三步：三角形 ANQ 和 BMP 中的角度。**

设 ∠ANQ = φ, ∠AQN = ψ，因此 φ + ψ = b + c。由于 N 是 AD 的中点，AN = AD/2。根据
△ANQ 中的正弦定理：

sin ψ / sin φ = AN/AQ = (AD/2)/(AD sin b/sin c) = sin c/(2 sin b)。

所以 2 sin b sin ψ = sin c sin(b + c − ψ)。 ……(★)

类似地，设 ∠BPM = ν, ∠BMP = μ，且 μ + ν = d + c, BM = BC/2。根据正弦定理：

sin ν / sin μ = sin c/(2 sin d)，所以 2 sin d sin ν = sin c sin(d + c − ν)。 ……(
★★)

**第四步：关键化简。**

根据 (★)：2 sin b sin ψ = sin c[sin(b+c) cos ψ − cos(b+c) sin ψ]，得到 sin ψ[2 s
in b + sin c cos(b+c)] = sin c sin(b+c) cos ψ。现在：

sin(c − ψ) = sin c cos ψ − cos c sin ψ = [sin ψ(2 sin b + sin c cos(b+c))/sin(b+
c)] − cos c sin ψ
= (sin ψ/sin(b+c))[2 sin b + sin c cos(b+c) − cos c sin(b+c)]
= (sin ψ/sin(b+c))[2 sin b + sin(−b)] = sin ψ sin b / sin(b+c)。

因此 **sin(c − ψ)/sin ψ = sin b/sin(b+c)**。

根据 (★★) 通过相同的计算（将 b 替换为 d）：**sin ν/sin(c − ν) = sin(d+c)/sin d**
。

**第五步：比率 CX/XD 和 CY/YD。**

设 X = ℓ_A ∩ CD，Y = ℓ_B ∩ CD，其中 ℓ_A 是 (ANQ) 在 A 处的切线，ℓ_B 是 (BMP) 在
B 处的切线。

根据切线-弦角定理，ℓ_A 与 AD 的夹角为 ψ，与 AB 的夹角为 φ。由于 Q 在 AD 中包含 C
 的一侧，ℓ_A 位于 AD 的 C 侧，因此 ∠XAD = ψ 且 ∠CAX = c − ψ（带符号角度）。

在三角形 ACD 中，通过正弦定理（利用 sin∠AXC = sin∠AXD）：
CX/XD = (AC sin∠CAX)/(AD sin∠XAD) = (AC sin(c − ψ))/(AD sin ψ)。

由于 AC = 2R sin(a+b) 且 AD = 2R sin d：
**CX/XD = (sin(a+b)/sin d)·(sin b/sin(b+c))**。

类似地，ℓ_B 与 BC 的夹角为 ν，与 AB 的夹角为 μ，位于 BC 的 D 侧，因此 ∠CBY = ν
且 ∠YBD = c − ν。由于 BC = 2R sin b 且 BD = 2R sin(a+d)：
**CY/YD = (sin b/sin(a+d))·(sin(d+c)/sin d)**。

**第六步：等式。**

我们需要 sin(a+b)sin b/[sin d sin(b+c)] = sin b sin(d+c)/[sin(a+d) sin d]，即：

sin(a+b)/sin(b+c) = sin(d+c)/sin(a+d)。

由于 a+b+c+d = π：a+d = π−(b+c) 所以 sin(a+d) = sin(b+c)；且 d+c = π−(a+b) 所以
sin(d+c) = sin(a+b)。代入后得到恒等式 sin(a+b)/sin(b+c) = sin(a+b)/sin(b+c)。✓

因此 CX/XD = CY/YD，这意味着 X = Y。(ANQ) 在 A 处的切线、(BMP) 在 B 处的切线以及
直线 CD 都经过同一个点。
