## Proof

Let $S = \{A \in M_n(\mathbb{C}) : A^k = I \text{ for some } k \geq 1\}$.

### Step 1: Characterize $S$

**Claim:** $S$ is exactly the set of diagonalizable matrices whose eigenvalues a
re all roots of unity.

*Proof.* If $A^k = I$, the minimal polynomial of $A$ divides $x^k - 1$, which ha
s $k$ distinct roots over $\mathbb{C}$. Therefore the minimal polynomial has no
repeated roots, so $A$ is diagonalizable, and every eigenvalue is a $k$-th root
of unity.

Conversely, if $A$ is diagonalizable with eigenvalues $\lambda_1, \dots, \lambda
_n$, each a root of unity of order $d_i$, then setting $k = \operatorname{lcm}(d
_1, \dots, d_n)$ gives $A^k = I$. $\square$

### Step 2: The eigenvalue multiset is constant on connected components

**Claim:** If $A(t)$, $t \in [0,1]$, is a continuous path in $S$, then the multi
set of eigenvalues of $A(t)$ is constant.

*Proof.* The characteristic polynomial $p_t(x) = \det(xI - A(t))$ has coefficien
ts that are continuous functions of $t$ (since they are polynomials in the entri
es of $A(t)$).

Each coefficient of $p_t$ is (up to sign) an elementary symmetric polynomial $e_
j(\lambda_1(t), \dots, \lambda_n(t))$ in the eigenvalues. Since each $\lambda_i(
t) \in \mu$ (the set of all roots of unity) and $\mu$ is countable, the set of p
ossible values of each $e_j$ is the image of the countable set $\mu^n$ under $e_
j$, hence countable.

Each coefficient of $p_t$ is therefore a continuous function $[0,1] \to \mathbb{
C}$ taking values in a countable subset of $\mathbb{C}$. Since any countable sub
set of $\mathbb{C}$ is totally disconnected (any connected subset of $\mathbb{C}
$ with more than one point is uncountable), each coefficient is constant. Theref
ore $p_t$ is constant, so the eigenvalue multiset is constant. $\square$

### Step 3: Each conjugacy class is connected

Fix a multiset $\Lambda = \{\lambda_1, \dots, \lambda_n\}$ of roots of unity and
 let $D = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$. The set of matrices
 in $S$ with eigenvalue multiset $\Lambda$ is the conjugacy class:
$$\mathcal{C}_\Lambda = \{PDP^{-1} : P \in GL_n(\mathbb{C})\}.$$

**Claim:** $\mathcal{C}_\Lambda$ is connected.

*Proof.* The map $\phi: GL_n(\mathbb{C}) \to M_n(\mathbb{C})$ given by $\phi(P)
= PDP^{-1}$ is continuous, and $\mathcal{C}_\Lambda = \phi(GL_n(\mathbb{C}))$ is
 the continuous image of $GL_n(\mathbb{C})$.

It remains to show $GL_n(\mathbb{C})$ is connected. Indeed, $GL_n(\mathbb{C})$ i
s path-connected: for any $A \in GL_n(\mathbb{C})$, since $\mathbb{C}^*$ admits
a logarithm and $A$ has a Jordan form, $A$ has a matrix logarithm $B$ (i.e., $A
= e^B$). Then $t \mapsto e^{tB}$ for $t \in [0,1]$ is a continuous path from $I$
 to $A$ in $GL_n(\mathbb{C})$.

Therefore $\mathcal{C}_\Lambda$ is connected. $\square$

### Step 4: Connected components = conjugacy classes

- By Step 2, every connected subset of $S$ has a constant eigenvalue multiset, s
o it lies within a single conjugacy class $\mathcal{C}_\Lambda$.
- By Step 3, each $\mathcal{C}_\Lambda$ is connected.
- Distinct multisets $\Lambda \neq \Lambda'$ give disjoint conjugacy classes (ma
trices with different eigenvalue multisets cannot be conjugate).

Therefore each $\mathcal{C}_\Lambda$ is a maximal connected subset of $S$, i.e.,
 a connected component.

### Conclusion

The connected components of $S$ are in bijection with **multisets of size $n$ of
 roots of unity**. Explicitly, for each multiset $\Lambda = \{\lambda_1, \dots,
\lambda_n\}$ where each $\lambda_i$ is a root of unity, the corresponding connec
ted component is the conjugacy class

$$\mathcal{C}_\Lambda = \{P \operatorname{diag}(\lambda_1, \dots, \lambda_n) P^{
-1} : P \in GL_n(\mathbb{C})\},$$

consisting of all diagonalizable $n \times n$ complex matrices with exactly that
 multiset of eigenvalues. Two matrices in $S$ lie in the same connected componen
t if and only if they have the same eigenvalues with the same multiplicities.
