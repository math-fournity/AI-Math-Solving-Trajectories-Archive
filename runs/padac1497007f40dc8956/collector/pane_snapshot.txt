## 设置

设 $U = \bigcap_{i=1}^5 W_i$，$\dim U = 1$。取商空间 $\bar V = V/U$，并令 $\bar
W_i = W_i/U$。则：

- $\dim \bar W_i = 3$（对于每个 $i$），
- $\bigcap_{i=1}^5 \bar W_i = 0$，
- $\dim\!\left(\sum_{i=1}^5 \bar W_i\right) = 14$，
- $\dim(W_i \cap W_j) = 1 + \dim(\bar W_i \cap \bar W_j)$。

令 $a_{ij} = \dim(\bar W_i \cap \bar W_j)$，$\bar S = \sum_{i<j} a_{ij}$。则 $S
= \sum_{i<j}\dim(W_i\cap W_j) = 10 + \bar S$。我需要求出 $\bar S$ 的所有可能值。

## 关键恒等式

对于子空间的任意排序 $(i_1, \dots, i_5)$，令 $V_k = \bar W_{i_1} + \cdots + \bar
 W_{i_k}$，$t_k = \dim(\bar W_{i_k} \cap V_{k-1})$（其中 $V_0 = 0$）。则：

$$\dim V_5 = \sum_{k=1}^{5}(\dim \bar W_{i_k} - t_k) = 15 - \sum_{k=2}^{5} t_k.$
$

由于 $\dim V_5 = 14$，我们得到 $\sum_{k=2}^{5} t_k = 1$，**与排序无关**（该计算
仅使用了 $\dim V_5 = 14$ 和 $\dim V_1 = 3$，两者均与排序无关）。由于每个 $t_k \g
e 0$，最多有一个 $t_k$ 等于 $1$，其余均为 $0$。

## 约束条件 1：$a_{ij} \le 1$

在以 $i, j$ 开头的排序中：$t_2 = a_{ij}$，因此 $a_{ij} \le 1$。

## 约束条件 2：如果 $a_{ij}=1$，则该对是孤立的

在排序 $(i, j, k, \ldots)$ 中：$t_2 + t_3 \le 1$，其中 $t_2 = a_{ij}$，且 $t_3 =
 \dim(\bar W_k \cap (\bar W_i + \bar W_j)) \ge \max(a_{ik}, a_{jk})$。因此，如果
 $a_{ij} = 1$，则 $\max(a_{ik}, a_{jk}) = 0$，即对于所有 $k \notin \{i,j\}$，有
$a_{ik} = a_{jk} = 0$。

## 约束条件 3：最多有一对满足 $a_{ij} = 1$

假设 $a_{12} = 1$ 且 $a_{34} = 1$（不相交对）。在排序 $(1,2,3,4,5)$ 中：$t_2 = a
_{12} = 1$，因此 $t_4 = 0$。但 $t_4 = \dim(\bar W_4 \cap (\bar W_1+\bar W_2+\bar
 W_3)) \ge a_{34} = 1$。矛盾。

共享对（$a_{12}=1, a_{13}=1$）已被约束 2 排除。因此，**最多只有一对**满足 $a_{ij
}=1$。

## 结论：$\bar S \in \{0, 1\}$

- **情况 A**：某一对满足 $a_{ij}=1$。根据约束 2 和 3，所有其他 $a$ 均为 $0$，因
此 $\bar S = 1$。
- **情况 B**：所有 $a_{ij} = 0$，因此 $\bar S = 0$。

## 两种情况均可实现

**$\bar S = 1$**：在 $F^{14}$ 中，令 $\bar W_1 = \langle e_1,e_2,e_3\rangle$，$\
bar W_2 = \langle e_1,e_4,e_5\rangle$，$\bar W_3 = \langle e_6,e_7,e_8\rangle$，
$\bar W_4 = \langle e_9,e_{10},e_{11}\rangle$，$\bar W_5 = \langle e_{12},e_{13}
,e_{14}\rangle$。则 $a_{12}=1$，其余所有 $a_{ij}=0$，$\bigcap \bar W_i = 0$，$\d
im(\sum \bar W_i) = 5+3+3+3 = 14$。✓

**$\bar S = 0$**：在 $F^{14}$ 中，令 $\bar W_1 = \langle e_1,e_2,e_3\rangle$，$\
bar W_2 = \langle e_4,e_5,e_6\rangle$，$\bar W_3 = \langle e_7,e_8,e_9\rangle$，
$\bar W_4 = \langle e_{10},e_{11},e_{12}\rangle$，$\bar W_5 = \langle e_{13},\,
e_{14},\, e_1+e_4+e_7+e_{10}\rangle$。

- 所有成对交集均为 $0$：例如，$\bar W_5 \cap \bar W_1 = 0$，因为 $a e_{13} + b e
_{14} + c(e_1+e_4+e_7+e_{10}) \in \bar W_1$ 迫使 $a=b=0$ 且 $c e_4 + c e_7 + c e

- $\bar W_5 \cap (\bar W_1+\cdots+\bar W_4) = \langle e_1+e_4+e_7+e_{10}\rangle$

- $\bigcap_{i=1}^{4} \bar W_i = 0$（直和），因此 $\bigcap_{i=1}^{5} \bar W_i = 0
$。✓

两个构造均适用于任意域 $F$（仅使用显式基向量）。
