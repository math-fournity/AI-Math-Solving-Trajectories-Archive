## Solution

**Step 1: Compute $a_n$ via substitution.**

$$a_n = \int_{0}^{\pi/2}(1-\sin t)^n \sin(2t)\,dt.$$

Let $u = 1 - \sin t$, so $du = -\cos t\,dt$. Using $\sin(2t) = 2\sin t\cos t = 2
(1-u)\cos t$, we get
$$\sin(2t)\,dt = 2(1-u)\cos t\,dt = -2(1-u)\,du.$$
The limits: $t=0 \Rightarrow u=1$; $t=\pi/2 \Rightarrow u=0$. Therefore
$$a_n = \int_{1}^{0} u^n\bigl(-2(1-u)\bigr)\,du = 2\int_{0}^{1} u^n(1-u)\,du = 2
\left[\frac{1}{n+1}-\frac{1}{n+2}\right] = \frac{2}{(n+1)(n+2)}.$$

**Step 2: Form the general term of the series.**

$$\frac{a_n}{n} = \frac{2}{n(n+1)(n+2)}.$$

**Step 3: Partial fraction decomposition.**

$$\frac{2}{n(n+1)(n+2)} = \frac{A}{n}+\frac{B}{n+1}+\frac{C}{n+2}.$$
Solving $2 = A(n+1)(n+2)+Bn(n+2)+Cn(n+1)$:
- $n=0$: $2=2A \Rightarrow A=1$,
- $n=-1$: $2=-B \Rightarrow B=-2$,
- $n=-2$: $2=2C \Rightarrow C=1$.

Hence
$$\frac{2}{n(n+1)(n+2)} = \frac{1}{n}-\frac{2}{n+1}+\frac{1}{n+2}.$$

**Step 4: Telescoping.**

Set $b_n = \frac{1}{n}-\frac{1}{n+1}$. Then
$$\frac{1}{n}-\frac{2}{n+1}+\frac{1}{n+2} = \left(\frac{1}{n}-\frac{1}{n+1}\righ
t)-\left(\frac{1}{n+1}-\frac{1}{n+2}\right) = b_n - b_{n+1}.$$

So the partial sum telescopes:
$$S_N = \sum_{n=1}^{N}(b_n - b_{n+1}) = b_1 - b_{N+1} = \left(1-\frac{1}{2}\righ
t) - \left(\frac{1}{N+1}-\frac{1}{N+2}\right) = \frac{1}{2} - \frac{1}{(N+1)(N+2
)}.$$

**Step 5: Take the limit.**

$$\lim_{N\to\infty} S_N = \frac{1}{2} - 0 = \frac{1}{2}.$$

$$\boxed{\lim_{N\to\infty}\sum_{n=1}^{N}\frac{a_n}{n} = \frac{1}{2}}.$$
