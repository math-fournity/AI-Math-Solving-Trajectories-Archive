## Proof

We evaluate $\sum_{b=1}^r |S(r,b,\psi)|^2$ where $S(r,b,\psi) = \sum_{y=1}^r \ps
i(y)\, e(by/r)$, using the standard additive character $e(x) = e^{2\pi i x}$, an
d $\psi$ is a Dirichlet character modulo $r$.

**Step 1: Expand the square.** Since $\overline{e(by/r)} = e(-by/r)$,

$$|S(r,b,\psi)|^2 = \left(\sum_{y=1}^r \psi(y)\,e(by/r)\right)\left(\sum_{z=1}^r
 \overline{\psi(z)}\,e(-bz/r)\right).$$

Summing over $b$ and exchanging the order of summation:

$$\sum_{b=1}^r |S(r,b,\psi)|^2 = \sum_{y=1}^r\sum_{z=1}^r \psi(y)\overline{\psi(
z)} \underbrace{\sum_{b=1}^r e\!\left(\frac{b(y-z)}{r}\right)}_{(*)}.$$

**Step 2: Evaluate the inner sum $(*)$.** This is a geometric sum. Setting $k =
y - z$,

$$\sum_{b=1}^r e(bk/r) = \begin{cases} r & \text{if } k \equiv 0 \pmod{r},\\[4pt
] 0 & \text{if } k \not\equiv 0 \pmod{r}. \end{cases}$$

(The sum is $r \cdot \frac{1 - e(k)}{1 - e(k/r)} = 0$ when $r \nmid k$, since $e
(k) = 1$ but $e(k/r) \neq 1$; and equals $r$ when $r \mid k$.)

Since $y, z \in \{1, \dots, r\}$, the condition $y - z \equiv 0 \pmod{r}$ forces
 $y = z$. Therefore

$$\sum_{b=1}^r |S(r,b,\psi)|^2 = r \sum_{y=1}^r \psi(y)\overline{\psi(y)} = r\su
m_{y=1}^r |\psi(y)|^2.$$

**Step 3: Use the properties of Dirichlet characters.** A Dirichlet character $\
psi$ modulo $r$ satisfies:
- $\psi(y) = 0$ if and only if $\gcd(y, r) \neq 1$,
- $|\psi(y)| = 1$ if $\gcd(y, r) = 1$.

Hence $|\psi(y)|^2 = 1$ when $\gcd(y,r)=1$ and $|\psi(y)|^2 = 0$ otherwise. The
number of integers $y \in \{1, \ldots, r\}$ coprime to $r$ is $\phi(r)$ (Euler's
 totient function). Therefore

$$\sum_{y=1}^r |\psi(y)|^2 = \phi(r).$$

**Conclusion.** Combining Steps 2 and 3,

$$\boxed{\sum_{b=1}^r |S(r,b,\psi)|^2 = r\,\phi(r).}$$

Note this holds for **every** Dirichlet character $\psi$ modulo $r$ (including t
he principal character), since the orthogonality of the additive characters $e(b
\,\cdot/r)$ collapsed the dependence on $\psi$ to the single quantity $\sum_y |\
psi(y)|^2 = \phi(r)$, which is the same for all characters modulo $r$.
