We minimize the functional $J[y] = \int_0^1 y'^2\,dx$ subject to the boundary co
nditions $y(0)=y(1)=0$ and the isoperimetric constraint $\int_0^1 y^2\,dx = 1$.

### Step 1. Augmented functional and Euler–Lagrange equation

Introduce a Lagrange multiplier $\lambda$ and form the augmented integrand
$$F(x,y,y') = y'^2 - \lambda\, y^2.$$
The Euler–Lagrange equation is
$$\frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\partial F}{\partial y'} = 0
\;\Longrightarrow\; -2\lambda y - \frac{d}{dx}(2y') = 0,$$
which simplifies to the necessary ODE
$$\boxed{y'' + \lambda\, y = 0.}$$

### Step 2. Apply the boundary conditions

The general solution is $y(x) = A\cos(\sqrt{\lambda}\,x) + B\sin(\sqrt{\lambda}\
,x)$.

- $y(0)=0 \Rightarrow A = 0$, so $y(x) = B\sin(\sqrt{\lambda}\,x)$.
- $y(1)=0 \Rightarrow B\sin(\sqrt{\lambda}) = 0$.

For a nontrivial solution ($B\neq 0$) we need $\sin(\sqrt{\lambda})=0$, hence
$$\sqrt{\lambda} = n\pi,\qquad n = 1,2,3,\dots \quad\Longrightarrow\quad \lambda
_n = n^2\pi^2.$$

### Step 3. Determine $B$ from the constraint $\int_0^1 y^2\,dx = 1$

With $y(x) = B\sin(n\pi x)$:
$$\int_0^1 B^2\sin^2(n\pi x)\,dx = B^2\cdot\frac{1}{2} = 1
\;\Longrightarrow\; B^2 = 2,\quad B = \sqrt{2}.$$

So the extremals are $y_n(x) = \sqrt{2}\,\sin(n\pi x)$.

### Step 4. Evaluate the functional on each extremal

Compute $y_n' = \sqrt{2}\,n\pi\cos(n\pi x)$, so
$$\int_0^1 y_n'^2\,dx = 2n^2\pi^2\int_0^1\cos^2(n\pi x)\,dx = 2n^2\pi^2\cdot\fra
c{1}{2} = n^2\pi^2.$$

Equivalently, multiply the ODE $y''+\lambda y=0$ by $y$ and integrate by parts u
sing $y(0)=y(1)=0$:
$$\int_0^1 y'^2\,dx = \lambda\int_0^1 y^2\,dx = \lambda\cdot 1 = \lambda = n^2\p
i^2,$$
confirming the same result.

### Step 5. Minimum value

Among the admissible extremals, the functional takes the values $\pi^2, 4\pi^2,
9\pi^2, \dots$ corresponding to $n=1,2,3,\dots$. The smallest is attained at $n=
1$, with the minimizer
$$y(x) = \sqrt{2}\,\sin(\pi x).$$

This is indeed a minimum (not merely a stationary point): by the Wirtinger inequ
ality, for any $y$ with $y(0)=y(1)=0$,
$$\int_0^1 y^2\,dx \le \frac{1}{\pi^2}\int_0^1 y'^2\,dx,$$
so $\int_0^1 y'^2\,dx \ge \pi^2\int_0^1 y^2\,dx = \pi^2$, with equality exactly
at $y\propto\sin(\pi x)$.

### Conclusion

The minimum value of the functional is

$$\boxed{\pi^2}.$$
