Looking at this problem, I need to find the area of isosceles triangle ABC where
 BC = 12, AB = AC, and there is exactly one point P with PA:PB:PC = 3:4:5.

## Setting Up Coordinates

Place B = (-6, 0), C = (6, 0), A = (0, h) with h > 0. The area of △ABC = ½ · 12
· h = 6h.

A Type-Z point P = (x, y) satisfies PA = 3k, PB = 4k, PC = 5k for some k > 0, gi
ving two Apollonius circle equations:

**Circle I** (from PB²/PA² = 16/9): 7x² − 108x + 7y² − 32hy + 16h² − 324 = 0

**Circle II** (from PC²/PA² = 25/9): 16x² + 108x + 16y² − 50hy + 25h² − 324 = 0

Two circles intersect in 0, 1, or 2 points. Exactly one Type-Z location means **
the circles are tangent**.

## Finding Centers and Radii

**Circle I**: Center C₁ = (54/7, 16h/7), radius r₁ = 12√(36+h²)/7

**Circle II**: Center C₂ = (−27/8, 25h/16), radius r₂ = 15√(36+h²)/16

Both radii are proportional to √(36+h²) — a key simplification.

**Distance between centers:**
$$d = \frac{\sqrt{1242^2 + 81^2 h^2}}{112}$$

## Applying Tangency

**Case 1 (external): d = r₁ + r₂**
$$\sqrt{1242^2 + 81^2 h^2} = 297\sqrt{36+h^2}$$
$$1542564 + 6561h^2 = 88209(36+h^2) = 3175524 + 88209h^2$$
$$-1632960 = 81648h^2 \implies h^2 < 0$$

No valid solution.

**Case 2 (internal): d = r₁ − r₂** (since 12/7 > 15/16)

$$1542564 + 6561h^2 = 7569(36+h^2) = 272484 + 7569h^2$$

## Verification

- r₁ = 12·36/7 = 432/7, r₂ = 15·36/16 = 135/4
