# Solution

We solve the boundary value problem
$$u_{tt}+2u_t=c^2 u_{xx}-u,\qquad 0<x<L,\ t>0,$$
$$u(0,t)=0,\qquad u(L,t)=0.$$

No initial conditions are prescribed, so we seek **all** functions satisfying th
e PDE together with the two Dirichlet boundary conditions.

## Step 1. Separation of variables

Set $u(x,t)=X(x)\,T(t)$. Substituting and dividing by $XT$:
$$\frac{T''}{T}+2\frac{T'}{T}=c^{2}\frac{X''}{X}-1.$$
The left side depends only on $t$, the right only on $x$, so both equal a common
 constant. The boundary conditions $u(0,t)=u(L,t)=0$ force $X(0)=X(L)=0$, which
selects the standard eigenvalue problem
$$X''+\lambda X=0,\qquad X(0)=X(L)=0.$$

## Step 2. Spatial eigenvalues and eigenfunctions

The nontrivial solutions are
$$\lambda_n=\Big(\frac{n\pi}{L}\Big)^{2},\qquad X_n(x)=\sin\!\Big(\frac{n\pi x}{
L}\Big),\qquad n=1,2,3,\dots$$

## Step 3. Temporal equation

For each $n$, the separation constant gives
$$\frac{T''}{T}+2\frac{T'}{T}=-c^{2}\lambda_n-1,$$
i.e.
$$T''+2T'+\omega_n^{2}\,T=0,\qquad \omega_n^{2}:=c^{2}\Big(\frac{n\pi}{L}\Big)^{
2}+1.$$

The characteristic equation is $r^{2}+2r+\omega_n^{2}=0$, with roots
$$r=-1\pm\sqrt{1-\omega_n^{2}}=-1\pm\sqrt{1-\Big(c^{2}\big(\tfrac{n\pi}{L}\big)^
{2}+1\Big)}=-1\pm i\,\frac{cn\pi}{L}.$$

Hence
$$T_n(t)=e^{-t}\Big[A_n\cos\!\Big(\frac{cn\pi t}{L}\Big)+B_n\sin\!\Big(\frac{cn\
pi t}{L}\Big)\Big],$$
with $A_n,B_n$ arbitrary constants.

## Step 4. General solution

Superposing all separated solutions (the eigenfunctions $\{\sin(n\pi x/L)\}$ for
m a complete orthogonal system on $[0,L]$, so every solution of the linear homog
eneous problem with these BCs is a convergent series of them):

$$\boxed{\;u(x,t)=\sum_{n=1}^{\infty}e^{-t}\Big[A_n\cos\!\Big(\frac{cn\pi t}{L}\
Big)+B_n\sin\!\Big(\frac{cn\pi t}{L}\Big)\Big]\sin\!\Big(\frac{n\pi x}{L}\Big)\;
}$$

where $A_n,B_n\in\mathbb{R}$ are arbitrary constants (determined only if initial
 data $u(x,0),\,u_t(x,0)$ are additionally specified).

## Verification

For each term $u_n=e^{-t}\big[A_n\cos(\tfrac{cn\pi t}{L})+B_n\sin(\tfrac{cn\pi t
}{L})\big]\sin(\tfrac{n\pi x}{L})$:

- **BCs:** $\sin(0)=\sin(n\pi)=0$, so $u_n(0,t)=u_n(L,t)=0$. ✓
- **PDE:** $X_n''=-\lambda_n X_n$, so $c^2 u_{xx}-u=(c^2(-\lambda_n)-1)u_n=-\ome
ga_n^2 u_n$. Also $T_n''+2T_n'=-\omega_n^2 T_n$ by construction of $T_n$. Thus $
u_{tt}+2u_t=-\omega_n^2 u_n=c^2 u_{xx}-u$. ✓

By linearity, any convergent superposition also satisfies the PDE and BCs. Conve
rsely, completeness of the sine basis on $[0,L]$ guarantees that every sufficien
tly regular solution admits a Fourier-sine expansion in $x$ whose time coefficie
nts must each satisfy the ODE above, so the displayed family is exhaustive.
