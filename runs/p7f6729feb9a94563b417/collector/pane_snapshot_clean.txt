## Solution

**Problem restatement:** Find all n-digit primes (n ≥ 3) such that deleting any
k digits (1 ≤ k ≤ n−2) always leaves a prime. Sum all such passkeys.

### Key constraints from 2-digit subsequences

Deleting k digits leaves a subsequence of length n−k ≥ 2. So **every subsequence
 of length ≥ 2 must be prime**, including every 2-digit subsequence. For any two
 positions i < j, the 2-digit number d_i d_j must be prime.

**Digit 0 is impossible:** If 0 appears at position i < n, then (d_j, 0) = 10·d_
j is composite for any j < i. If 0 is last, (d_i, 0) is composite. So all digits
 ∈ {1,…,9}.

**Only digit 1 can repeat:** (a,a) must be prime for a to repeat; only 11 is pri
me among {11,22,…,99}. Every other digit appears at most once.

**Coexistence with 1:** A digit a coexisting with 1 needs (1,a) and/or (a,1) val
id. Checking: digits 2, 5, 8 fail both directions with 1 (12,21,15,51,18,81 all
composite). Digits 4, 6 only allow (a,1) [41,61 prime] but not (1,a) [14,16 comp
osite], forcing them before all 1's. Digit 9 only allows (1,9) [19 prime] but no
t (9,1) [91=7·13], forcing it after all 1's. Digits 3, 7 allow both directions.

**Among {3,7,9}:** (3,7)=37 and (7,3)=73 both prime; (7,9)=79 and (9,7)=97 both
prime; but (3,9)=39 and (9,3)=93 are both composite — **3 and 9 cannot coexist**
.

### Case A: No digit 1

Digits from {2,…,9}, all distinct. The "source" digits {2,4,5,6,8} have no incom
ing edges among themselves and are pairwise incompatible (e.g., 24, 42 both comp
osite), so at most one can appear (first). Checking each with compatible {3,7,9}
-subsets: the only length-3 candidates are 437 (=19·23) and 473 (=11·43), both c
omposite. **Case A yields nothing.**

### Case B: Digit 1 present

Non-1 digits ⊆ {3,7} or {7,9} (since 3,9 conflict). **At most two 1's total** (t
hree 1's give subsequence 111 = 3·37, composite).

**B1 — digits from {1,3,7}** (all pairs valid, any order works):
- Two 1's + one 3 (n=3): 113, 131, 311 — all prime, all 2-digit subsequences (11
,13,31) prime. ✓
- Two 1's + one 7: 117=9·13, 171=9·19, 711=3·237 — all composite. ✗
- One 1 + one 3 + one 7 (n=3): 137, 173, 317 prime ✓; 371=7·53, 713=23·31, 731=1
7·43 composite ✗.
- Two 1's + 3 + 7 (n=4): contains {1,1,7} subsequence (117/171/711, all composit
e). ✗

**B2 — digits from {1,7,9}** (9 must follow all 1's):
- Two 1's + one 9: 119 = 7·17. ✗
- One 1 + one 7 + one 9 (n=3): 179, 197, 719 prime ✓; (7,9,1),(9,7,1),(9,1,7) in
valid by ordering.
- Two 1's + 7 + 9 (n=4): contains {1,1,7} subsequence. ✗
