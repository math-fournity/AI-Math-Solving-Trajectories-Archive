## 下界：χ(G) ≥ ℵ₀

固定任意函数 f₀ ∈ V。考虑函数族 {f_v : v ∈ ℕ, v ≠ f₀(0)}，其中 f_v 定义为：当 n
≠ 0 时 f_v(n) = f₀(n)，且 f_v(0) = v。

对于任意两个不同的 v, w，函数 f_v 和 f_w 仅在输入 0 处不同（因为 f_v(0) = v ≠ w
= f_w(0)，且对于所有 n ≥ 1 有 f_v(n) = f_w(n)）。因此 f_v 和 f_w 是相邻的。这构
成了一个大小为 |ℕ \ {f₀(0)}| = ℵ₀ 的团。

由于任何着色都必须为团中的每个顶点分配不同的颜色，因此 **χ(G) ≥ ℵ₀**。

## 上界：χ(G) ≤ ℵ₀

**连通分量。** 如果两个函数 f, g 仅在有限多个输入上不同，则它们之间存在路径（逐
个修改不同的坐标）。因此，G 的连通分量正是以下关系的等价类：“在有限多个点上不同”
。每个分量都是可数的：从代表元 f₀ 出发，在 k 步内可达的函数与 f₀ 最多在 k 个坐标
上不同，且此类函数有 ℵ₀^k · ℵ₀^k = ℵ₀ 个；对所有有限的 k 取并集，得到一个可数集
。不同分量之间不存在边。

**单分量的着色。** 设 C 为一个连通分量，代表元为 f₀ ∈ C。对于每个 g ∈ C，令 D(g)
 = {n ∈ ℕ : g(n) ≠ f₀(n)}（这是一个有限集），并定义：

$$c(g) = \sum_{n \in D(g)} \bigl(g(n) - f_0(n)\bigr) \in \mathbb{Z}.$$

该求和是有限的，因为 D(g) 是有限的，因此 c(g) 是一个定义明确的整数。

**正确性。** 假设 g 和 h 在恰好一个坐标 n 上不同。那么对于所有 m ≠ n，g(m) = h(m
)，这意味着 m ∈ D(g) 当且仅当 m ∈ D(h)。有三种情况：

- **n ∈ D(g) ∩ D(h)：** 则 D(g) = D(h)，且 c(g) − c(h) = (g(n) − f₀(n)) − (h(n)
− f₀(n)) = g(n) − h(n) ≠ 0。
- **n ∈ D(g) \ D(h)：** 则 h(n) = f₀(n) 且 D(g) = D(h) ∪ {n}，因此 c(g) − c(h) =
 (g(n) − f₀(n)) ≠ 0，因为 n ∈ D(g)。
- **n ∈ D(h) \ D(g)：** 同理，c(g) − c(h) = −(h(n) − f₀(n)) ≠ 0。

在所有情况下，c(g) ≠ c(h)，因此这是一个真着色（proper coloring）。

**组合各分量。** 着色 c 将 C 映射到 ℤ，且 |ℤ| = ℵ₀。由于不同分量之间不存在边，我
们可以在每个分量中独立使用相同的 ℵ₀-颜色调色板（通过与 ℕ 的双射来识别）。这产生
了一个使用 ℵ₀ 种颜色的全图 G 的真着色。

因此 **χ(G) ≤ ℵ₀**。

## 结论

结合这两个界：

$$\boxed{\chi(G) = \aleph_0}$$

色数**是** ℵ₀。
