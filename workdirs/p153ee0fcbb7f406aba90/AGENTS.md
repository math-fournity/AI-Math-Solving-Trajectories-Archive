# Problem

A competitive logistics hub manages 100 shipping containers, each assigned a unique identification weight ranging from 1 to 100 units. These containers are arranged in a single, fixed linear queue $(x_1, x_2, \dots, x_{100})$ based on the order of their arrival.

A safety inspector evaluates the queue by examining every possible triplet of adjacent containers. For each set of three neighbors $\{x_i, x_{i+1}, x_{i+2}\}$, the inspector identifies the container with the median weight among them and marks its weight for a security audit.

Let $S$ be the set containing all unique weights that were marked for audit at least once during this process.

Given that the containers can be arranged in any of the $100!$ possible arrival sequences, determine the minimum possible value for the sum of all distinct weights contained in $S$.
