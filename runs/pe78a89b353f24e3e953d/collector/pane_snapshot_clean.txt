## Setup

Let $a = x^2,\, b = y^2,\, c = z^2$, so $a, b, c \ge 0$ and $a + b + c = 1$. We
maximize
$$P = (a-b)(b-c)(c-a).$$

**Symmetry observation:** Swapping any two of $a, b, c$ negates $P$. Therefore $
\max P = \max |P|$ (achieved at the permutation giving positive sign). So $M = \
max |(a-b)(b-c)(c-a)|$.

## Reduction to gaps

Let $s = a - b,\; t = b - c$. Then $c - a = -(s+t)$, so
$$P = -\,s\,t\,(s+t), \qquad |P| = |s\,t\,(s+t)|.$$
Solving $a+b+c=1$ with $a = b+s,\; c = b-t$:
$$a = \tfrac{1+2s+t}{3},\quad b = \tfrac{1-s+t}{3},\quad c = \tfrac{1-s-2t}{3}.$
$
Non-negativity gives the feasible polygon bounded by $a=0,\, b=0,\, c=0$.

## No interior critical point

Set $f = s\,t\,(s+t)$. Then
$$\frac{\partial f}{\partial s} = t(2s+t), \qquad \frac{\partial f}{\partial t}
= s(s+2t).$$
Both vanish simultaneously only when $s = t = 0$ (giving $f = 0$) or on the triv
ial axes $s=0$/$t=0$. So **no nonzero interior critical point exists**, and the
maximum of $|P|$ lies on the boundary.

## Boundary analysis

By symmetry it suffices to check one face, say $c = 0$. Then $a + b = 1$ with $a
, b \ge 0$, and
$$|P| = |(a-b)\cdot b \cdot (-a)| = |ab(a-b)|.$$
Substitute $a = \frac{1+d}{2},\; b = \frac{1-d}{2}$ with $d \in [0,1]$:
$$|P| = \frac{d(1-d^2)}{4}.$$
Differentiate: $g'(d) = \frac{1-3d^2}{4} = 0 \Longrightarrow d = \frac{1}{\sqrt{
3}}$.
$$g\!\left(\tfrac{1}{\sqrt{3}}\right) = \frac{1}{\sqrt{3}}\cdot\frac{1 - \tfrac{
1}{3}}{4} = \frac{1}{\sqrt{3}}\cdot\frac{1}{6} = \frac{1}{6\sqrt{3}}.$$

The other two faces ($a = 0$ and $b = 0$) give the identical value by the same c
omputation. Hence
$$M = \frac{1}{6\sqrt{3}}.$$

## Verification

At the maximizer (e.g. $c = 0,\; a = \frac{1+1/\sqrt{3}}{2},\; b = \frac{1-1/\sq
rt{3}}{2}$):
- $ab = \frac{1 - 1/3}{4} = \frac{1}{6}$, $\;a - b = \frac{1}{\sqrt{3}}$,
- $|P| = \frac{1}{6}\cdot\frac{1}{\sqrt{3}} = \frac{1}{6\sqrt{3}} \approx 0.0962
$.

A sample interior point $a=0.6, b=0.1, c=0.3$ gives $|P| = 0.03 < 0.0962$, consi
stent with the boundary being the global max.

## Final computation

$$M^2 = \frac{1}{(6\sqrt{3})^2} = \frac{1}{108}, \qquad \boxed{\frac{1}{M^2} = 1
08}.$$
