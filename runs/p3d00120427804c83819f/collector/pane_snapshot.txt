## (a) General Solution of Hermite's Differential Equation

Hermite's differential equation is

$$y'' - 2xy' + 2ny = 0 \qquad (n = 0, 1, 2, \dots) \tag{1}$$

A particular solution is the **Hermite polynomial** $H_n(x)$. Following the hint
, set

$$y = v\,H_n(x). \tag{2}$$

Differentiating:

$$y' = v'H_n + vH_n', \qquad y'' = v''H_n + 2v'H_n' + vH_n''. \tag{3}$$

Substituting (2)–(3) into (1):

$$v''H_n + 2v'H_n' + vH_n'' - 2x(v'H_n + vH_n') + 2nvH_n = 0.$$

Collecting the $v$–terms:

$$v\bigl(H_n'' - 2xH_n' + 2nH_n\bigr) + v''H_n + v'\bigl(2H_n' - 2xH_n\bigr) = 0
.$$

Since $H_n$ itself satisfies (1), the bracketed term vanishes, leaving

$$v''H_n + v'(2H_n' - 2xH_n) = 0. \tag{4}$$

Let $w = v'$. Then (4) becomes the first-order equation

$$w'H_n + w(2H_n' - 2xH_n) = 0,$$

$$\frac{w'}{w} = 2x - 2\frac{H_n'}{H_n}.$$

Integrating:

$$\ln|w| = x^2 - 2\ln|H_n| + \text{const},$$

$$w = v' = C\,\frac{e^{x^2}}{H_n^2(x)}.$$

Integrating once more:

$$v = C_1 + C_2\int \frac{e^{x^2}}{H_n^2(x)}\,dx.$$

Substituting back into $y = vH_n(x)$:

$$\boxed{\,y = C_1\,H_n(x) + C_2\,H_n(x)\!\int \frac{e^{x^2}}{H_n^2(x)}\,dx\,} \
tag{5}$$

This is the **general solution** of Hermite's equation: $C_1 H_n(x)$ is the poly
nomial (Hermite) solution, and the second term is the linearly independent non-p
olynomial solution obtained by reduction of order.

## (b) Cases $n=1$ and $n=2$

### Case $n = 1$: $H_1(x) = 2x$

From (5):

$$y = C_1(2x) + C_2(2x)\int \frac{e^{x^2}}{(2x)^2}\,dx = C_1(2x) + \frac{C_2}{2}
\,x\int \frac{e^{x^2}}{x^2}\,dx.$$

Evaluate the integral by parts with $u = e^{x^2}$, $dv = x^{-2}dx$ (so $du = 2xe
^{x^2}dx$, $v = -1/x$):

$$\int \frac{e^{x^2}}{x^2}\,dx = -\frac{e^{x^2}}{x} + 2\int e^{x^2}\,dx.$$

Hence

$$y = C_1(2x) + \frac{C_2}{2}\,x\!\left[-\frac{e^{x^2}}{x} + 2\int e^{x^2}\,dx\r
ight] = C_1(2x) + C_2\!\left[x\int e^{x^2}\,dx - \frac{1}{2}e^{x^2}\right].$$

Using $\displaystyle\int e^{x^2}\,dx = \frac{\sqrt{\pi}}{2}\operatorname{erfi}(x
)$:

$$\boxed{\,y = C_1(2x) + C_2\!\left[\frac{\sqrt{\pi}}{2}\,x\,\operatorname{erfi}
(x) - \frac{1}{2}e^{x^2}\right]\,} \tag{6}$$

### Case $n = 2$: $H_2(x) = 4x^2 - 2$

From (5):

$$y = C_1(4x^2 - 2) + C_2(4x^2 - 2)\int \frac{e^{x^2}}{(4x^2 - 2)^2}\,dx.$$

The integral can be reduced by parts. Setting $u = e^{x^2}$, $dv = (4x^2-2)^{-2}
dx$, with $v = -x/[2(4x^2-2)]$ (verified by differentiating), gives

$$\int \frac{e^{x^2}}{(4x^2-2)^2}\,dx = -\frac{x\,e^{x^2}}{2(4x^2-2)} + \int \fr
ac{e^{x^2}}{4x^2-2}\,dx.$$

The remaining integral $\displaystyle\int \frac{e^{x^2}}{4x^2-2}\,dx$ is non-ele
mentary (expressible via $\operatorname{erfi}$ and elementary terms). The genera
l solution is therefore

$$\boxed{\,y = C_1(4x^2 - 2) + C_2(4x^2 - 2)\!\int \frac{e^{x^2}}{(4x^2 - 2)^2}\
,dx\,} \tag{7}$$

or, after the partial reduction,

$$y = C_1(4x^2 - 2) + C_2\!\left[-\frac{x\,e^{x^2}}{2} + (4x^2 - 2)\!\int \frac{
e^{x^2}}{4x^2 - 2}\,dx\right].$$

In both (6) and (7), $C_1$ and $C_2$ are arbitrary constants, the first term is
the Hermite polynomial solution and the second is the linearly independent non-p
olynomial solution.
