# Solution

## Setup

Place $B = (-\tfrac{15}{2}, 0)$, $C = (\tfrac{15}{2}, 0)$, so the midpoint $P =
(0,0)$. From $AB = 13$, $AC = 14$:

$$\left(x+\tfrac{15}{2}\right)^2 + y^2 = 169,\quad \left(x-\tfrac{15}{2}\right)^
2 + y^2 = 196.$$

Subtracting: $-30x = 27$, so $x = -\tfrac{9}{10}$. Then $y^2 = 169 - \tfrac{1089
}{25} = \tfrac{3136}{25}$, giving $y = \tfrac{56}{5}$. Thus

$$A = \left(-\tfrac{9}{10},\, \tfrac{56}{5}\right).$$

The area is $\tfrac{1}{2}\cdot 15\cdot \tfrac{56}{5} = 84$, and $s = 21$, $r = 4
$, circumradius $= \tfrac{13\cdot14\cdot15}{4\cdot84} = \tfrac{65}{8}$.

## Excenters

With $a = BC = 15$, $b = CA = 14$, $c = AB = 13$:

$$I_B = \frac{aA - bB + cC}{a - b + c} = \frac{15A - 14B + 13C}{14}.$$

Computing: $15A = (-\tfrac{27}{2}, 168)$, $-14B = (105, 0)$, $13C = (\tfrac{195}
{2}, 0)$. Sum $= (189, 168)$, so

$$I_B = \left(\tfrac{27}{2},\, 12\right).$$

$$I_C = \frac{aA + bB - cC}{a + b - c} = \frac{15A + 14B - 13C}{16}.$$

Sum $= (-216, 168)$, so

$$I_C = \left(-\tfrac{27}{2},\, \tfrac{21}{2}\right).$$

**Verification:** $r_b = \tfrac{84}{s-b} = \tfrac{84}{7} = 12 = $ ($y$-coord of
$I_B$); $r_c = \tfrac{84}{s-c} = \tfrac{84}{8} = \tfrac{21}{2} = $ ($y$-coord of
 $I_C$). ✓

## Circumradius of $\triangle PI_BI_C$

**Side lengths:**

$$PI_B = \sqrt{\tfrac{729}{4} + 144} = \sqrt{\tfrac{1305}{4}} = \tfrac{3\sqrt{14
5}}{2},$$

$$PI_C = \sqrt{\tfrac{729}{4} + \tfrac{441}{4}} = \sqrt{\tfrac{1170}{4}} = \tfra
c{3\sqrt{130}}{2},$$

$$I_BI_C = \sqrt{729 + \tfrac{9}{4}} = \sqrt{\tfrac{2925}{4}} = \tfrac{15\sqrt{1
3}}{2}.$$

**Area:**

$$[\triangle PI_BI_C] = \tfrac{1}{2}\left|\tfrac{27}{2}\cdot\tfrac{21}{2} - \lef
t(-\tfrac{27}{2}\right)\cdot 12\right| = \tfrac{1}{2}\left(\tfrac{567}{4} + \tfr
ac{648}{4}\right) = \tfrac{1215}{8}.$$

**Circumradius:**

$$R = \frac{PI_B \cdot PI_C \cdot I_BI_C}{4[\triangle PI_BI_C]} = \frac{\tfrac{3
\sqrt{145}}{2}\cdot\tfrac{3\sqrt{130}}{2}\cdot\tfrac{15\sqrt{13}}{2}}{4\cdot\tfr
ac{1215}{8}} = \frac{\tfrac{135\sqrt{145\cdot130\cdot13}}{8}}{\tfrac{1215}{2}}.$
$

Now $145\cdot 130\cdot 13 = (5\cdot29)(2\cdot5\cdot13)(13) = 2\cdot 25\cdot 169\
cdot 29 = 245050$, and $\sqrt{245050} = \sqrt{50\cdot 4901} = 5\sqrt{2}\cdot 13\
sqrt{29} = 65\sqrt{58}$.

$$R = \frac{135\cdot 65\sqrt{58}/8}{1215/2} = \frac{135\cdot 65\sqrt{58}}{8}\cdo
t\frac{2}{1215} = \frac{65\sqrt{58}}{36}.$$

**Cross-check via $R = \tfrac{I_BI_C}{2\sin P}$:** With $\vec{PI_B}=(\tfrac{27}{
2},12)$, $\vec{PI_C}=(-\tfrac{27}{2},\tfrac{21}{2})$:

$$\cos P = \frac{-\tfrac{729}{4}+126}{\tfrac{3\sqrt{145}}{2}\cdot\tfrac{3\sqrt{1
30}}{2}} = \frac{-225/4}{9\sqrt{18850}/4} = \frac{-25}{\sqrt{18850}} = \frac{-5}
{\sqrt{754}},$$

$$\sin P = \sqrt{1-\tfrac{25}{754}} = \frac{27}{\sqrt{754}},\qquad R = \frac{15\
sqrt{13}/2}{2\cdot 27/\sqrt{754}} = \frac{15\sqrt{13}\cdot\sqrt{754}}{108} = \fr
ac{15\cdot 13\sqrt{58}}{108} = \frac{65\sqrt{58}}{36}.\ \checkmark$$

## Result

$$R^2 = \frac{65^2\cdot 58}{36^2} = \frac{4225\cdot 58}{1296} = \frac{245050}{12
96} = \frac{122525}{648}.$$

Since $122525 = 5^2\cdot 13^2\cdot 29$ and $648 = 2^3\cdot 3^4$ share no common
factor, this is fully reduced.

$$\boxed{R^2 = \dfrac{122525}{648}}$$
