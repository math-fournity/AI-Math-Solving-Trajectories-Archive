## Proof

We work on the probability space $((0,1), \mathcal{G}, \lambda)$ where $\lambda$
 is Lebesgue measure restricted to $(0,1)$, and $\mathcal{G}$ consists of all co
untable subsets of $(0,1)$ together with all co-countable subsets of $(0,1)$.

**Step 1. Characterize $\mathcal{G}$-measurable functions.**

Recall that $\mathcal{G} = \{A \subseteq (0,1) : A \text{ is countable}\} \cup \
{A \subseteq (0,1) : A^c \text{ is countable}\}$. This is a $\sigma$-algebra: it
 is closed under complements by construction, and under countable unions since a
 countable union of countable sets is countable, while the complement of a count
able union of co-countable sets is a countable intersection of countable sets, h
ence countable.

Under $\lambda$, every countable set has measure $0$, and every co-countable sub
set of $(0,1)$ has measure $1$ (since its complement is countable, hence null).

Let $f$ be $\mathcal{G}$-measurable. For every $t \in \mathbb{R}$, the set $\{f
> t\} \in \mathcal{G}$, so it is either countable (measure $0$) or co-countable
(measure $1$). Define $c = \sup\{t : \lambda(\{f > t\}) = 1\}$. Then $\{f > c +
\varepsilon\}$ has measure $0$ for all $\varepsilon > 0$ and $\{f > c - \varepsi
lon\}$ has measure $1$ for all $\varepsilon > 0$. Hence $f = c$ $\lambda$-a.e. C
onversely, every a.e.-constant function is $\mathcal{G}$-measurable. Therefore:

$$f \text{ is } \mathcal{G}\text{-measurable} \iff f \text{ is constant } \lambd
a\text{-a.e.}$$

**Step 2. Compute $\mathbb{E}[X]$.**

$$\mathbb{E}[X] = \int_0^1 \cos(\pi\omega)\,d\omega = \left[\frac{\sin(\pi\omega
)}{\pi}\right]_0^1 = \frac{\sin\pi - \sin 0}{\pi} = 0.$$

**Step 3. Verify the candidate $\mathbb{E}(X\mid\mathcal{G}) = 0$.**

The constant function $0$ is $\mathcal{G}$-measurable. We check the defining pro
perty: for every $A \in \mathcal{G}$,
$$\int_A \mathbb{E}(X\mid\mathcal{G})\,d\lambda = \int_A X\,d\lambda.$$

- If $A$ is countable, then $\lambda(A) = 0$, so $\int_A 0\,d\lambda = 0 = \int_
A X\,d\lambda$. ✓
- If $A$ is co-countable, then $A^c$ is countable with $\lambda(A^c)=0$, so
$$\int_A X\,d\lambda = \int_{(0,1)} X\,d\lambda - \int_{A^c} X\,d\lambda = \math
bb{E}[X] - 0 = 0 = \int_A 0\,d\lambda. \quad ✓$$

Both cases confirm the identity. Since $\mathcal{G}$-measurable functions are de
termined only up to $\lambda$-a.e. equality, and the only a.e.-constant value co
nsistent with the above is $0$, we conclude:

$$\boxed{\mathbb{E}(X\mid\mathcal{G}) = 0 \quad \lambda\text{-a.e.}}$$

**Remark.** Intuitively, $\mathcal{G}$ is the trivial $\sigma$-algebra modulo $\
lambda$-null sets (every set in $\mathcal{G}$ has measure $0$ or $1$), so condit
ioning on $\mathcal{G}$ collapses $X$ to its overall mean $\mathbb{E}[X] = 0$.
