## Proof

Define $g(z) = e^{z^3}$, which is entire and never vanishes. Consider the quotie
nt
$$h(z) = \frac{f(z)}{g(z)} = f(z)\,e^{-z^3}.$$
Since $g$ is entire and zero-free, $h$ is entire. The hypothesis $|f(z)| \geq \t
frac{1}{3}|e^{z^3}|$ becomes
$$|h(z)| \geq \frac{1}{3} \quad \text{for all } z \in \mathbb{C}.$$

In particular $h$ never vanishes, so $k(z) := 1/h(z)$ is entire, and
$$|k(z)| \leq 3 \quad \text{for all } z \in \mathbb{C}.$$

By Liouville's theorem, $k$ is constant. Hence $h$ is constant. Evaluating at th
e origin:
$$h(0) = \frac{f(0)}{g(0)} = \frac{1}{1} = 1,$$
so $h(z) \equiv 1$, which gives
$$f(z) = e^{z^3} \quad \text{for all } z. \qquad \blacksquare$$

## Can this be shown using the Cauchy integral formula?

**Yes.** Liouville's theorem is itself a direct corollary of the Cauchy integral
 formula, so the entire argument above rests on it. Concretely, one may replace
the invocation of Liouville's theorem by the following Cauchy-integral argument
applied to the bounded entire function $k = 1/h$:

Fix $a \in \mathbb{C}$ and $R > 0$. The Cauchy integral formula for the derivati
ve gives
$$k'(a) = \frac{1}{2\pi i}\oint_{|w-a|=R} \frac{k(w)}{(w-a)^2}\,dw.$$
Parametrizing $w = a + Re^{i\theta}$ and using $|k(w)| \leq 3$:
$$|k'(a)| \leq \frac{1}{2\pi}\cdot \frac{3}{R^2}\cdot 2\pi R = \frac{3}{R}.$$
Letting $R \to \infty$ yields $k'(a) = 0$. Since $a$ was arbitrary, $k' \equiv 0
$, so $k$ is constant. The same estimate with $(w-a)^{n+1}$ in the denominator s
hows $k^{(n)}(a) = 0$ for all $n \geq 1$, giving the conclusion directly from th
e Cauchy integral formula without naming Liouville's theorem.

Thus the result **can** be shown using the Cauchy integral formula — indeed Liou
ville's theorem is nothing but the Cauchy estimates derived from it.
