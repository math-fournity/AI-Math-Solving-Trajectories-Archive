## Proof

We claim that every number of the form $a = 4m^{4}$, where $m \geq 2$ is a natur
al number, has the required property. Since there are infinitely many such $m$,
this yields infinitely many distinct values of $a$.

Fix $m \geq 2$ and set $a = 4m^{4}$. For any natural number $n$, we apply the **
Sophie Germain identity**:

$$z = n^{4} + 4m^{4} = n^{4} + 4\cdot m^{4}\cdot 1 = (n^{2} - 2mn + 2m^{2})(n^{2
} + 2mn + 2m^{2}).$$

This factorization is verified by direct expansion:

$$(n^{2} - 2mn + 2m^{2})(n^{2} + 2mn + 2m^{2}) = (n^{2}+2m^{2})^{2} - (2mn)^{2}
= n^{4} + 4m^{2}n^{2} + 4m^{4} - 4m^{2}n^{2} = n^{4} + 4m^{4}.$$

It remains to show that **both factors exceed $1$**, so that $z$ is genuinely co
mposite.

**First factor.** Complete the square:

$$n^{2} - 2mn + 2m^{2} = (n - m)^{2} + m^{2} \geq m^{2} \geq 4 > 1,$$

since $m \geq 2$.

**Second factor.** Similarly,

$$n^{2} + 2mn + 2m^{2} = (n + m)^{2} + m^{2} \geq (1 + m)^{2} + m^{2} \geq 9 + 4
 = 13 > 1,$$

for $n \geq 1$ and $m \geq 2$.

(If $0$ is counted among the natural numbers, then for $n = 0$ we have $z = a =
4m^{4}$, which is divisible by $4$ and hence composite as well; and the first fa
ctor at $n=0$ equals $2m^{2} \geq 8 > 1$, the second also $2m^{2} > 1$.)

Thus for **every** natural number $n$, the number $z = n^{4} + a = n^{4} + 4m^{4
}$ factors as a product of two integers each strictly greater than $1$, and is t
herefore **not prime**.

Since the values $a = 4m^{4}$ for $m = 2, 3, 4, \dots$ are all distinct (the fun
ction $m \mapsto 4m^{4}$ is strictly increasing) and each has the required prope
rty, there are **infinitely many** such natural numbers $a$. $\blacksquare$
