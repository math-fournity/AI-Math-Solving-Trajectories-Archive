## Solution

We seek an entire function $f(z)$ with $f(0)=1$ and $\operatorname{Re}(f(z)) = x
^2 - y^2 + e^{-x}\cos y$, where $z = x + iy$.

**Recognizing the pieces.** Recall two standard facts:
- $\operatorname{Re}(z^2) = x^2 - y^2$, since $z^2 = (x+iy)^2 = (x^2-y^2) + 2ixy
$.
- $\operatorname{Re}(e^{-z}) = e^{-x}\cos y$, since $e^{-z} = e^{-x-iy} = e^{-x}
(\cos y - i\sin y)$.

**Constructing a candidate.** Define
$$g(z) = z^2 + e^{-z}.$$
This is entire (sum of entire functions), and
$$\operatorname{Re}(g(z)) = \operatorname{Re}(z^2) + \operatorname{Re}(e^{-z}) =
 (x^2 - y^2) + e^{-x}\cos y,$$
which matches the required real part exactly.

**Uniqueness up to an imaginary constant.** Suppose $f$ is any entire function w
ith $\operatorname{Re}(f(z)) = \operatorname{Re}(g(z))$ for all $z$. Then $h(z)
:= f(z) - g(z)$ is entire and $\operatorname{Re}(h(z)) = 0$ everywhere. By the o
pen mapping theorem (or the Cauchy–Riemann equations), an entire function whose
image lies in the line $\{w : \operatorname{Re}(w)=0\}$ must be constant; hence
$h(z) = iC$ for some real constant $C$. Thus
$$f(z) = z^2 + e^{-z} + iC.$$

**Applying the initial condition.** Using $f(0) = 1$:
$$f(0) = 0^2 + e^{0} + iC = 1 + iC = 1 \implies C = 0.$$

**Conclusion.** The unique entire function satisfying both conditions is

$$\boxed{f(z) = z^2 + e^{-z}}.$$

**Verification.**
- $f(0) = 0 + 1 = 1$. ✓
- $\operatorname{Re}(f(z)) = (x^2 - y^2) + e^{-x}\cos y$. ✓
- $f$ is entire as a sum of entire functions. ✓
