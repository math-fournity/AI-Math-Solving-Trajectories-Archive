## Proof

**Setup.** Let $f = u + iv$ with $u = \operatorname{Re} f$, $v = \operatorname{I
m} f$. By the Cauchy–Riemann equations, $|f'(z)|^2 = u_x^2 + v_x^2 = u_x^2 + u_y
^2 = |\nabla u|^2$.

**Step 1: Reduction to a functional equation.**

If $f$ is constant, the condition is trivially satisfied. Assume $f$ is non-cons
tant. If $f'(z_0) = 0$ for some $z_0$, then $|f'(z_0)|^2 = 0$, so $|f'|^2 = 0$ o
n the entire level curve $\{u = u(z_0)\}$. Since $f'$ is analytic and vanishes o
n a curve (which has accumulation points), $f' \equiv 0$, contradicting non-cons
tancy. Thus **$f'$ never vanishes**, and $\nabla u = f' \neq 0$ everywhere.

Since $\nabla u \neq 0$ everywhere, the level curves of $u$ form a global foliat
ion. The condition "$|f'|$ is constant on each level curve of $u$" means $|f'(z)
|^2 = h(u(z))$ for some real-analytic function $h$.

**Step 2: The key functional equation.**

Define $\bar{f}(w) := \overline{f(\bar{w})}$, which is entire. Then $\overline{f
(z)} = \bar{f}(\bar{z})$ and $\overline{f'(z)} = \bar{f}'(\bar{z})$. The relatio
n $|f'|^2 = h(u)$ becomes:

$$f'(\zeta)\,\bar{f}'(\eta) = h\!\left(\frac{f(\zeta) + \bar{f}(\eta)}{2}\right)
 \qquad \text{for all } \zeta, \eta \in \mathbb{C}, \tag{1}$$

treating $\zeta$ and $\eta$ as independent variables (set $\zeta = z$, $\eta = \
bar{z}$ to recover the original).

**Step 3: Differentiating to find the form of $h$.**

Differentiate (1) with respect to $\zeta$:

$$f''(\zeta)\,\bar{f}'(\eta) = \tfrac{1}{2}\,h'\!\left(\tfrac{f(\zeta)+\bar{f}(\
eta)}{2}\right) f'(\zeta).$$

Since $f' \neq 0$, divide by $f'(\zeta)$:

$$\frac{f''(\zeta)}{f'(\zeta)} = \frac{h'(u)}{2\,\bar{f}'(\eta)}, \qquad u = \fr
ac{f(\zeta)+\bar{f}(\eta)}{2}. \tag{2}$$

The left side depends only on $\zeta$. Differentiate the right side with respect
 to $\eta$ and set to zero:

$$\frac{h''(u)\,\bar{f}'(\eta)^2 - 2\,h'(u)\,\bar{f}''(\eta)}{4\,\bar{f}'(\eta)^
2} = 0,$$

yielding:

$$\frac{\bar{f}''(\eta)}{\bar{f}'(\eta)^2} = \frac{h''(u)}{2\,h'(u)}. \tag{3}$$

The left side depends only on $\eta$; the right side depends on $u$, which varie
s with $\zeta$ (since $f$ is non-constant). Therefore the right side must be **c
onstant**:

$$\frac{h''(u)}{2\,h'(u)} = \frac{c}{2} \quad \Longrightarrow \quad h'' = c\,h'$
$

for some constant $c \in \mathbb{R}$. This gives $h'(u) = A\,e^{cu}$, so:

- **If $c = 0$:** $h(u) = Au + B$. From (3), $\bar{f}''(\eta) = 0$, hence $f'' \
equiv 0$, giving $f(z) = az + b$.
- **If $c \neq 0$:** $h(u) = \frac{A}{c}e^{cu} + B$. From (3), $\frac{f''(z)}{f'
(z)^2} = \frac{c}{2}$. Integrating: $-\frac{1}{f'(z)} = \frac{c}{2}z + d$, so $f
'(z) = \frac{-2/c}{z + 2d/c}$. This has a **simple pole** at $z = -2d/c \in \mat
hbb{C}$, so $f'$ is not entire. Since $c \neq 0$ makes the numerator $-2/c \neq
0$, the pole cannot be removed. **No entire solution exists in this case.**

**Step 4: Verification.**

For $f(z) = az + b$: $f'(z) = a$, so $|f'(z)| = |a|$ is constant everywhere, hen
ce constant on every curve. ✓

**Conclusion.** The analytic functions $f: \mathbb{C} \to \mathbb{C}$ satisfying
 the condition are precisely the **affine linear functions**:

$$\boxed{f(z) = az + b, \quad a, b \in \mathbb{C}.}$$
