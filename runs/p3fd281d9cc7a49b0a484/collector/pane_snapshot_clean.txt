**Answer: No.** There exists a set $E \subseteq \mathbb{R}$ with $m^*(E) > 0$ th
at contains **no** Borel subset of positive Lebesgue measure. A Vitali set provi
des the counterexample.

### Proof

**Construction of $E$.** Define the equivalence relation on $\mathbb{R}$: $x \si
m y \iff x - y \in \mathbb{Q}$. By the Axiom of Choice, select exactly one repre
sentative from each equivalence class that meets $[0,1]$. Let $V \subseteq [0,1]
$ be the resulting set of representatives (a Vitali set). Set $E := V$.

**Claim 1: $m^*(V) > 0$.**

The translates $\{V + q : q \in \mathbb{Q} \cap [-1, 1]\}$ are pairwise disjoint
: if $(V+q_1) \cap (V+q_2) \neq \emptyset$ with $q_1 \neq q_2$, then $v_1 + q_1
= v_2 + q_2$ for some $v_1, v_2 \in V$, giving $v_1 - v_2 = q_2 - q_1 \in \mathb
b{Q} \setminus \{0\}$, contradicting that $V$ contains at most one element per e
quivalence class.

Moreover, $[0,1] \subseteq \bigcup_{q \in \mathbb{Q} \cap [-1,1]} (V + q)$: ever
y $x \in [0,1]$ belongs to some equivalence class, whose representative $v \in V
$ satisfies $x - v \in \mathbb{Q}$ and $|x - v| \leq 1$, so $x \in V + (x - v)$.

Suppose for contradiction that $m^*(V) = 0$. Then $m^*(V + q) = 0$ for every $q$
 (outer measure is translation-invariant). By countable subadditivity,
$$m^*\!\Big(\bigcup_{q \in \mathbb{Q}\cap[-1,1]}(V+q)\Big) \leq \sum_{q} m^*(V+q
) = 0.$$
But this union contains $[0,1]$, so $0 \geq m^*([0,1]) = 1$, a contradiction. He
nce $m^*(V) > 0$.

**Claim 2: $V$ contains no Borel subset of positive measure.**

We use **Steinhaus's theorem**: if $A \subseteq \mathbb{R}$ is Lebesgue measurab
le with $m(A) > 0$, then $A - A$ contains an open neighborhood of $0$.

*Brief justification:* By the Lebesgue density theorem, $A$ has a point of densi
ty $x$. For small $\epsilon > 0$, $m\big(A \cap (x-\epsilon, x+\epsilon)\big) >
\tfrac{3}{2}\epsilon$. For any $|h| < \epsilon/2$, the sets $A \cap (x-\epsilon,
x+\epsilon)$ and $\big(A \cap (x-\epsilon,x+\epsilon)\big) + h$ both lie in $(x
- \tfrac{3\epsilon}{2}, x + \tfrac{3\epsilon}{2})$ and each has measure $> \tfra
c{3}{2}\epsilon > \tfrac{1}{2}\cdot 3\epsilon$, so they intersect. Thus $h = a'
- a$ for some $a, a' \in A$, giving $h \in A - A$.

Now suppose, for contradiction, that $B \subseteq V$ is Borel (hence measurable)
 with $m(B) > 0$. By Steinhaus's theorem, $B - B$ contains $(-\delta, \delta)$ f
or some $\delta > 0$. This interval contains a nonzero rational $r \in \mathbb{Q
} \setminus \{0\}$. Since $B - B \subseteq V - V$, we have $r \in V - V$, so $r
= v_1 - v_2$ for some $v_1, v_2 \in V$. But $r \in \mathbb{Q} \setminus \{0\}$ m
eans $v_1 \sim v_2$ with $v_1 \neq v_2$, contradicting the definition of $V$ (on
e representative per class).

Therefore no Borel subset $B \subseteq V$ can have $m(B) > 0$.

**Conclusion.** Taking $E = V$, we have $E \subseteq \mathbb{R}$ with $m^*(E) >
0$, yet every Borel subset $B \subseteq E$ satisfies $m(B) = 0$. So the answer t
o the question is **no** — such a Borel set need not exist.
