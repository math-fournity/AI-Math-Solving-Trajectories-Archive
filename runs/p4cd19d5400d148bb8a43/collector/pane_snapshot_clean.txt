# Proof

**Setup.** Let $O$ be the origin. By rotation, assume the half-plane is the uppe
r half-plane $\{(x,y) : y \geq 0\}$ with boundary the $x$-axis. The $n$ unit vec
tors then make angles $\alpha_1, \alpha_2, \ldots, \alpha_n \in [0, \pi]$ with t
he positive $x$-axis, where $n = 2m+1$ is odd. Let $S = \sum_{k=1}^n \mathbf{u}_
k$ where $\mathbf{u}_k = (\cos \alpha_k, \sin \alpha_k)$. We must show $|S| \geq
 1$.

**Sorting and pairing.** Relabel so that $\alpha_1 \leq \alpha_2 \leq \cdots \le
q \alpha_{2m+1}$. The *middle* vector is $\mathbf{u}_{m+1}$ at angle $\alpha_{m+
1}$. Form $m$ pairs from the remaining $2m$ vectors:
$$(\alpha_1,\, \alpha_{2m+1}),\quad (\alpha_2,\, \alpha_{2m}),\quad \ldots,\quad
 (\alpha_m,\, \alpha_{m+2}).$$

**Key inequality for each pair.** For the $j$-th pair $(\alpha_j,\, \alpha_{2m+2
-j})$ with $1 \leq j \leq m$, set
$$a_j = \alpha_{m+1} - \alpha_j \geq 0, \qquad b_j = \alpha_{2m+2-j} - \alpha_{m
+1} \geq 0,$$
where the inequalities hold because $j \leq m < m+1 < 2m+2-j$. Since both angles
 lie in $[0,\pi]$:
$$a_j + b_j = \alpha_{2m+2-j} - \alpha_j \leq \pi.$$

Using the sum-to-product identity:
$$\cos(\alpha_j - \alpha_{m+1}) + \cos(\alpha_{2m+2-j} - \alpha_{m+1}) = \cos a_
j + \cos b_j = 2\cos\!\tfrac{a_j+b_j}{2}\;\cos\!\tfrac{a_j-b_j}{2}.$$

Since $0 \leq a_j + b_j \leq \pi$, we have $\frac{a_j+b_j}{2} \in [0, \frac{\pi}
{2}]$, so $\cos\frac{a_j+b_j}{2} \geq 0$. Since $|a_j - b_j| \leq a_j + b_j \leq
 \pi$, we have $\frac{|a_j-b_j|}{2} \in [0, \frac{\pi}{2}]$, so $\cos\frac{a_j-b
_j}{2} \geq 0$. Therefore:
$$\cos(\alpha_j - \alpha_{m+1}) + \cos(\alpha_{2m+2-j} - \alpha_{m+1}) \geq 0 \q
quad \text{for each } j = 1, \ldots, m.$$

**Projection onto the middle vector.** Project $S$ onto the unit direction $\mat
hbf{u}_{m+1}$:
$$S \cdot \mathbf{u}_{m+1} = \sum_{k=1}^{n} \cos(\alpha_k - \alpha_{m+1}) = \und
erbrace{\cos 0}_{=\,1} + \sum_{j=1}^{m}\Big[\cos(\alpha_j - \alpha_{m+1}) + \cos
(\alpha_{2m+2-j} - \alpha_{m+1})\Big].$$

By the key inequality, every bracketed term is $\geq 0$, so:
$$S \cdot \mathbf{u}_{m+1} \geq 1.$$

**Conclusion.** Since $\mathbf{u}_{m+1}$ is a unit vector, $S \cdot \mathbf{u}_{
m+1} \leq |S|$. Combining with the inequality above:
$$|S| \geq S \cdot \mathbf{u}_{m+1} \geq 1.$$

This completes the proof. $\blacksquare$
