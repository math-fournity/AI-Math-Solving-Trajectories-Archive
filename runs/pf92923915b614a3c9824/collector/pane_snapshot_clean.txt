Looking at this problem, I need to count non-constant, non-decreasing functions
$f:\{1,\dots,n\}\to\{1,\dots,n\}$ satisfying $f(k)=f(f(k+1))$ for $k=1,\dots,n-1
$.

## Structural Analysis

Let $a_k = f(k)$. Since $f$ is non-decreasing, $a_1 \le a_2 \le \cdots \le a_n$.
 Let the distinct image values be $v_1 < v_2 < \cdots < v_r$, with block $j$ bei
ng the set of positions where $f$ takes value $v_j$.

**Deriving the constraints.** For each $k \in \{1,\dots,n-1\}$:

- **Within a block** ($f(k)=f(k+1)=v_j$): the condition gives $v_j = f(v_j)$, so
 $v_j$ is a fixed point.
- **At a transition** ($f(k)=v_{j-1},\; f(k+1)=v_j$): the condition gives $v_{j-
1} = f(v_j)$.

**Key deduction.** For every $j \ge 2$, the transition into block $j$ forces $f(
v_j) = v_{j-1} \ne v_j$. But if block $j$ had size $\ge 2$, the within-block con
dition would force $f(v_j)=v_j$ — a contradiction. Therefore **every block $j\ge
 2$ has size exactly 1**. Only block 1 may have size $\ge 2$.

**Block structure.** With $r$ distinct values, block 1 occupies positions $\{1,\
dots,n-r+1\}$ and block $j$ ($j\ge2$) occupies position $n-r+j$. So $s_1 = n-r+1
$.

**Locating the image values.** The constraint $f(v_j)=v_{j-1}$ means position $v
_j$ lies in block $j-1$:
- For $j\ge 3$: block $j-1$ is the single position $n-r+j-1$, so $v_j = n-r+j-1$
.
- For $j=2$: $v_2$ must lie in block 1, so $v_2 \in \{1,\dots,n-r+1\}$.

**Consistency checks.** Since $v_1 < v_2 \le n-r+1 < n-r+2 = v_3$, the ordering
is automatic. The case $r=n$ forces $s_1=1$ and $v_2\le 1$ with $v_1<v_2$, impos
sible — so $r \le n-1$, meaning $s_1\ge 2$ always. The fixed-point condition $f(
v_1)=v_1$ then requires $v_1$ in block 1, which holds since $v_1 < v_2 \le n-r+1
$.

**Counting.** For fixed $r$ ($2\le r\le n-1$), the free parameters are $(v_1,v_2
)$ with $1\le v_1 < v_2 \le n-r+1$, giving $\binom{n-r+1}{2}$ choices. Setting $
m=n-r+1$ (ranging from $2$ to $n-1$):

$$N(n) = \sum_{m=2}^{n-1}\binom{m}{2} = \sum_{m=2}^{n-1}\frac{m(m-1)}{2} = \frac
{1}{2}\cdot\frac{(n-1)n(n-2)}{3} = \frac{(n-1)n(n-2)}{6} = \binom{n}{3}.$$

## Verification

- **$n=3$:** $N(3)=\binom{3}{3}=1$. Only $f=(1,1,2)$: check $f(1)=f(f(2))=f(1)=1
$ ✓, $f(2)=f(f(3))=f(2)=1$ ✓.
- **$n=4$:** $N(4)=\binom{4}{3}=4$. The four functions $(1,1,1,2),(1,1,1,3),(2,2
,2,3),(1,1,2,3)$ all satisfy the recursive condition (verified directly).

## Final Computation

$$\sum_{n=3}^{10} N(n) = \sum_{n=3}^{10}\binom{n}{3} = \binom{11}{4} = \frac{11\
cdot10\cdot9\cdot8}{24} = 330,$$

where the hockey-stick identity $\sum_{i=r}^{N}\binom{i}{r}=\binom{N+1}{r+1}$ wa
s applied with $r=3$, $N=10$.

$$\boxed{330}$$
