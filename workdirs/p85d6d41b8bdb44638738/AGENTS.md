# Problem

A specialized automated logistics system manages a sequence of storage containers labeled $a_1, a_2, a_3, \dots$, where each container holds a specific integer number of units. The inventory levels are governed by a strict operational protocol: for every container index $n$ (where $n$ is a positive integer), the quantity in the next container, $a_{n+1}$, is restricted by the current container's quantity, $a_n$, according to the equilibrium formula:
$$(n-1) a_{n+1}=(n+1) a_{n}-2(n-1)$$

A recent audit of the facility revealed that the stock level in container $a_{2000}$ is exactly divisible by 2008. 

Based on this inventory protocol, find the smallest positive integer $n$ (where $n \geq 2$) such that the number of units in container $a_n$ is guaranteed to be a multiple of 2008.
