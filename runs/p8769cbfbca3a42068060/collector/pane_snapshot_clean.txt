# Principal Curvatures of the Helicoid and Catenoid

## Setup

For a parametrized surface $\sigma(u,v)$, the principal curvatures are the eigen
values of the shape operator, equivalently the roots $k$ of
$$\det\begin{pmatrix} L - kE & M - kF \\ M - kF & N - kG \end{pmatrix} = 0,$$
where $E,F,G$ are the coefficients of the first fundamental form and $L,M,N$ tho
se of the second fundamental form $L = \sigma_{uu}\cdot \hat n$, $M = \sigma_{uv
}\cdot \hat n$, $N = \sigma_{vv}\cdot \hat n$, with $\hat n = \frac{\sigma_u \ti
mes \sigma_v}{|\sigma_u \times \sigma_v|}$.

---

## Helicoid: $\sigma(u,v) = (\cos v\sinh u,\; \sin v\sinh u,\; v)$

**First partials:**
$$\sigma_u = (\cos v\cosh u,\; \sin v\cosh u,\; 0),\qquad \sigma_v = (-\sin v\si
nh u,\; \cos v\sinh u,\; 1).$$

**First fundamental form:**
$$E = \cos^2 v\cosh^2 u + \sin^2 v\cosh^2 u = \cosh^2 u,$$
$$F = -\cos v\sin v\cosh u\sinh u + \sin v\cos v\cosh u\sinh u = 0,$$
$$G = \sin^2 v\sinh^2 u + \cos^2 v\sinh^2 u + 1 = \sinh^2 u + 1 = \cosh^2 u.$$

So $E = G = \cosh^2 u,\; F = 0$, and $EG - F^2 = \cosh^4 u$.

**Unit normal.**
$$\sigma_u\times\sigma_v = (\sin v\cosh u,\; -\cos v\cosh u,\; \cosh u\sinh u),$
$
$$|\sigma_u\times\sigma_v|^2 = \cosh^2 u + \cosh^2 u\sinh^2 u = \cosh^2 u(1+\sin
h^2 u) = \cosh^4 u,$$
$$\hat n = \frac{1}{\cosh u}(\sin v,\; -\cos v,\; \sinh u) = \bigl(\sin v\,\math
rm{sech}\,u,\; -\cos v\,\mathrm{sech}\,u,\; \tanh u\bigr).$$

**Second partials:**
$$\sigma_{uu} = (\cos v\sinh u,\; \sin v\sinh u,\; 0),\quad \sigma_{uv} = (-\sin
 v\cosh u,\; \cos v\cosh u,\; 0),\quad \sigma_{vv} = (-\cos v\sinh u,\; -\sin v\
sinh u,\; 0).$$

**Second fundamental form:**
$$L = \sigma_{uu}\cdot\hat n = \frac{\sinh u}{\cosh u}(\cos v\sin v - \sin v\cos
 v) = 0,$$
$$M = \sigma_{uv}\cdot\hat n = \frac{\cosh u}{\cosh u}(-\sin^2 v - \cos^2 v) = -
1,$$
$$N = \sigma_{vv}\cdot\hat n = \frac{\sinh u}{\cosh u}(-\cos v\sin v + \sin v\co
s v) = 0.$$

**Principal curvatures.** The characteristic equation is
$$(L-kE)(N-kG) - (M-kF)^2 = (0 - k\cosh^2 u)(0 - k\cosh^2 u) - (-1)^2 = k^2\cosh
^4 u - 1 = 0,$$
$$k^2 = \frac{1}{\cosh^4 u} = \mathrm{sech}^4 u \quad\Longrightarrow\quad k = \p
m\,\mathrm{sech}^2 u.$$

$$\boxed{\kappa_1^{\text{hel}} = \frac{1}{\cosh^2 u},\qquad \kappa_2^{\text{hel}
} = -\frac{1}{\cosh^2 u}.}$$

## Catenoid: $\sigma(u,v) = (\cosh u\cos v,\; \cosh u\sin v,\; u)$

**First partials:**
$$\sigma_u = (\sinh u\cos v,\; \sinh u\sin v,\; 1),\qquad \sigma_v = (-\cosh u\s
in v,\; \cosh u\cos v,\; 0).$$

**First fundamental form:**
$$E = \sinh^2 u(\cos^2 v + \sin^2 v) + 1 = \sinh^2 u + 1 = \cosh^2 u,$$
$$F = -\sinh u\cos v\cosh u\sin v + \sinh u\sin v\cosh u\cos v = 0,$$
$$G = \cosh^2 u(\sin^2 v + \cos^2 v) = \cosh^2 u.$$

Again $E = G = \cosh^2 u,\; F = 0$ — the **same** first fundamental form as the
helicoid (confirming the classical isometry between the two).

**Unit normal.**
$$\sigma_u\times\sigma_v = (-\cosh u\cos v,\; -\cosh u\sin v,\; \sinh u\cosh u),
$$
$$|\sigma_u\times\sigma_v|^2 = \cosh^2 u + \sinh^2 u\cosh^2 u = \cosh^4 u,$$
$$\hat n = \frac{1}{\cosh u}(-\cos v,\; -\sin v,\; \sinh u) = \bigl(-\cos v\,\ma
thrm{sech}\,u,\; -\sin v\,\mathrm{sech}\,u,\; \tanh u\bigr).$$

**Second partials:**
$$\sigma_{uu} = (\cosh u\cos v,\; \cosh u\sin v,\; 0),\quad \sigma_{uv} = (-\sin
h u\sin v,\; \sinh u\cos v,\; 0),\quad \sigma_{vv} = (-\cosh u\cos v,\; -\cosh u
\sin v,\; 0).$$

**Second fundamental form:**
$$L = \sigma_{uu}\cdot\hat n = \frac{\cosh u}{\cosh u}(-\cos^2 v - \sin^2 v) = -
1,$$
$$M = \sigma_{uv}\cdot\hat n = \frac{\sinh u}{\cosh u}(\sin v\cos v - \cos v\sin
 v) = 0,$$
$$N = \sigma_{vv}\cdot\hat n = \frac{\cosh u}{\cosh u}(\cos^2 v + \sin^2 v) = 1.
$$

**Principal curvatures.** The characteristic equation is
$$(L-kE)(N-kG) - (M-kF)^2 = (-1 - k\cosh^2 u)(1 - k\cosh^2 u) - 0 = -(1 - k^2\co
sh^4 u) = 0,$$
$$k^2\cosh^4 u = 1 \quad\Longrightarrow\quad k = \pm\,\mathrm{sech}^2 u.$$

$$\boxed{\kappa_1^{\text{cat}} = \frac{1}{\cosh^2 u},\qquad \kappa_2^{\text{cat}
} = -\frac{1}{\cosh^2 u}.}$$

## Summary and Consistency Check

Both surfaces share the first fundamental form $ds^2 = \cosh^2 u\,(du^2 + dv^2)$
, so they are locally isometric — the classical helicoid–catenoid correspondence
 (conjugate minimal surfaces).

For both:
- **Principal curvatures:** $\displaystyle \kappa_1 = \frac{1}{\cosh^2 u} = \mat
hrm{sech}^2 u,\quad \kappa_2 = -\frac{1}{\cosh^2 u} = -\mathrm{sech}^2 u.$
- **Mean curvature:** $H = \tfrac12(\kappa_1 + \kappa_2) = 0$ — both are **minim
al surfaces**. ✓
- **Gaussian curvature:** $K = \kappa_1\kappa_2 = -\mathrm{sech}^4 u = -\dfrac{1
}{\cosh^4 u} < 0$ — both are negatively curved, as expected for minimal surfaces
 that are not planes. ✓

The two surfaces differ only in the *sign pattern* of the second fundamental for
m coefficients: the helicoid has $(L,M,N) = (0,-1,0)$ while the catenoid has $(L
,M,N) = (-1,0,1)$. This swap of the off-diagonal entry $M$ with the diagonal ent
ries $L,N$ (up to sign) is precisely the "conjugation" that exchanges the two su
rfaces while preserving the principal curvatures in magnitude.
