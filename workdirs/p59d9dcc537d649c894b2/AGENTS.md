# Problem

In the coastal logistics hub of Port Veridian, there is a secure vault containing a shipment of 13 unique shipping containers, each assigned a specific identifying integer. A local logistics coordinator is tasked with forming various "shipping manifests" (subsets) from these 13 containers. 

For any given manifest, the coordinator calculates the "Total Weight Index" by summing the integers of the containers included in that manifest. Following port regulations, a manifest is classified as "Balanced" if its Total Weight Index is exactly divisible by 5. Note that a "Null Manifest"—a manifest containing no containers—is officially recorded as having a Total Weight Index of 0, which is divisible by 5.

Given that the integers assigned to the 13 containers can be any set of 13 distinct integers, determine the minimum possible number of "Balanced" manifests the coordinator can identify.
