# Problem

In a specialized digital archive, a master security key is generated based on a specific prime number $p$. The archive contains a total of $2^p p$ encrypted data blocks.

To ensure redundant protection, a security protocol creates specific "sub-keys" by calculating the number of unique ways to select distinct groups of blocks from the total collection. The protocol only generates sub-keys for odd-sized groups, starting from a group of $1$ block and increasing by increments of two ($1, 3, 5, \dots$). This process continues until it reaches the largest odd integer that is strictly less than half of the total number of blocks (specifically, the last group size is $2^{p-1}p - 1$).

Each sub-key is numerically equal to the number of combinations possible for its respective group size. A final master override code is defined as the largest integer that divides every single one of these generated sub-key values.

Determine the value of this master override code in terms of $p$.
