## Proof

We work in $\ell^1 = \ell^1(\mathbb{N}_0)$ with $\|x\|_1 = \sum_{n=0}^\infty |x_
n|$. The operator is
$$(Ax)_n = \sum_{k=0}^\infty \frac{a^k}{k!}\, x_{n+k}, \qquad a > 0.$$

**Reindexing as a matrix operator.** Setting $j = n+k$ (so $k = j-n$), we rewrit
e
$$(Ax)_n = \sum_{j=n}^{\infty} \frac{a^{j-n}}{(j-n)!}\, x_j.$$
Thus $A$ is the matrix operator $(Ax)_n = \sum_{j=0}^\infty a_{nj}\, x_j$ with e
ntries
$$a_{nj} = \begin{cases} \dfrac{a^{j-n}}{(j-n)!}, & j \geq n, \\[6pt] 0, & j < n
. \end{cases}$$

**Upper bound.** For any $x \in \ell^1$,
$$\|Ax\|_1 = \sum_{n=0}^\infty \left|\sum_{j=0}^\infty a_{nj}\, x_j\right| \leq
\sum_{n=0}^\infty \sum_{j=0}^\infty |a_{nj}|\,|x_j| = \sum_{j=0}^\infty |x_j| \u
nderbrace{\sum_{n=0}^\infty |a_{nj}|}_{=:\, c_j} \leq \left(\sup_j c_j\right) \|
x\|_1.$$
Hence $\|A\| \leq \sup_j c_j$.

**Computing the column sums.** For fixed $j$, since $a_{nj} \neq 0$ only when $n
 \leq j$:
$$c_j = \sum_{n=0}^\infty |a_{nj}| = \sum_{n=0}^{j} \frac{a^{j-n}}{(j-n)!} = \su
m_{m=0}^{j} \frac{a^m}{m!},$$
where we substituted $m = j-n$. The sequence $(c_j)$ is non-decreasing (each $c_
{j+1} = c_j + \frac{a^{j+1}}{(j+1)!} > c_j$) and converges to
$$\lim_{j\to\infty} c_j = \sum_{m=0}^\infty \frac{a^m}{m!} = e^a.$$
Therefore
$$\sup_j c_j = e^a,$$
giving $\|A\| \leq e^a$.

**Lower bound (attaining the supremum).** For each $j$, take $x = e_j$ (the $j$-
th standard basis vector), so $\|e_j\|_1 = 1$. Then
$$(Ae_j)_n = a_{nj}, \qquad \|Ae_j\|_1 = \sum_{n=0}^\infty |a_{nj}| = c_j = \sum
_{m=0}^{j} \frac{a^m}{m!}.$$
Thus $\|A\| \geq c_j$ for every $j$, and taking the supremum,
$$\|A\| \geq \sup_j c_j = e^a.$$

**Conclusion.** Combining both bounds,
$$\boxed{\|A\| = e^a.}$$
