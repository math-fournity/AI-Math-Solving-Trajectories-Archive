Looking at this problem, I need to find the maximum of $\sum_{i=1}^{10} \cos(3x_
i)$ subject to $\sum_{i=1}^{10} \cos(x_i) = 0$.

## Proof

**Step 1: Reformulation.** Let $c_i = \cos(x_i) \in [-1, 1]$, so $\sum c_i = 0$.
 Using the triple angle identity $\cos(3x) = 4\cos^3 x - 3\cos x$, we get:

$$\sum_{i=1}^{10} \cos(3x_i) = \sum(4c_i^3 - 3c_i) = 4\sum c_i^3 - 3\underbrace{
\sum c_i}_{=0} = 4\sum_{i=1}^{10} c_i^3.$$

So we need to **maximize** $\sum c_i^3$ subject to $c_i \in [-1,1]$ and $\sum c_
i = 0$.

**Step 2: KKT analysis.** The feasible set is compact, so a maximum exists. The
Lagrangian for maximizing $\sum c_i^3$ subject to $\sum c_i = 0$ and $-1 \le c_i
 \le 1$ gives the stationarity condition:

$$3c_i^2 = \lambda + \mu_i - \nu_i,$$

where $\mu_i \ge 0$ with $\mu_i(c_i - 1)=0$ and $\nu_i \ge 0$ with $\nu_i(-c_i-1
)=0$.

- **If $c_i = 1$:** $\mu_i = 3 - \lambda \ge 0 \Rightarrow \lambda \le 3$.
- **If $c_i = -1$:** $\nu_i = \lambda - 3 \ge 0 \Rightarrow \lambda \ge 3$.
- **Interior ($-1 < c_i < 1$):** $c_i = \pm\sqrt{\lambda/3} =: \pm r$ with $r \i
n (0,1)$, requiring $0 < \lambda < 3$.

**Case $\lambda = 3$:** All $c_i \in \{-1, +1\}$, forcing 5 at $+1$ and 5 at $-1
$, giving $\sum c_i^3 = 0$.

**Case $\lambda \ge 3$ with $c_i = -1$:** Forces $\lambda = 3$, same as above.

**Case $0 < \lambda < 3$:** Values at $+1$ are allowed, values at $-1$ are not.
Interior values are $\pm r$. So each $c_i \in \{1, +r, -r\}$ for some $r \in (0,
1)$.

Let $a$ variables equal $1$, $b$ equal $+r$, $d$ equal $-r$, with $a+b+d=10$ and
 $a + (b-d)r = 0$, so $a = (d-b)r$.

The objective becomes:
$$\sum c_i^3 = a + (b-d)r^3 = (d-b)r + (b-d)r^3 = (d-b)\,r(1-r^2).$$

Since $a = (d-b)r \ge 0$, we need $d \ge b$. Setting $m = d - b \ge 0$ and $a =
mr$ (must be a non-negative integer), plus $b = \frac{10 - mr - m}{2} \ge 0$ (so
 $m(1+r) \le 10$), the objective is $m \cdot r(1-r^2)$.

**Step 3: Optimizing.** For fixed $r$, the objective increases with $m$, so we t
ake $m$ maximal: $m(1+r) = 10$, giving objective $= \frac{10}{1+r} \cdot r(1-r^2
) = 10r(1-r)$. This is maximized at $r = 1/2$ with value $5/2$, but requires $a
= mr = 10r/(1+r) = 10/3$, which is **not an integer**.

With the integer constraint, setting $b = 0$ (which is optimal since using $+r$
values only reduces $m$), we have $a$ variables at $+1$ and $10-a$ at $-r$ where
 $r = a/(10-a)$, requiring $a \le 5$. The objective becomes:

$$f(a) = a - \frac{a^3}{(10-a)^2}.$$

Computing for each integer $a \in \{1, 2, 3, 4, 5\}$:

| $a$ | $r = a/(10-a)$ | $\sum c_i^3 = a - a^3/(10-a)^2$ |
|---|---|---|
| 1 | $1/9$ | $1 - 1/81 = 80/81 \approx 0.988$ |
| 2 | $1/4$ | $2 - 8/64 = 15/8 = 1.875$ |
| 3 | $3/7$ | $3 - 27/49 = 120/49 \approx 2.449$ |
| 4 | $2/3$ | $4 - 64/36 = 20/9 \approx 2.222$ |
| 5 | $1$ | $5 - 5 = 0$ |

I also verified that configurations with $b > 0$ (some variables at $+r$) yield
strictly smaller values—for example, $(s,m) = (3,5)$ gives only $48/25 = 1.92$.

**The maximum is $\sum c_i^3 = 120/49$, achieved at $a = 3$.**

**Step 4: Verification.** Take $c_1 = c_2 = c_3 = 1$ (i.e., $x_i = 0$) and $c_4
= \cdots = c_{10} = -3/7$.

- $\sum c_i = 3 \cdot 1 + 7 \cdot (-3/7) = 3 - 3 = 0$. ✓
- For $c_i = 1$: $\cos(3x_i) = 4(1)^3 - 3(1) = 1$.
- For $c_i = -3/7$: $\cos(3x_i) = 4(-3/7)^3 - 3(-3/7) = -108/343 + 9/7 = -108/34
3 + 441/343 = 333/343$.
- $\sum \cos(3x_i) = 3 \cdot 1 + 7 \cdot \frac{333}{343} = 3 + \frac{2331}{343}
= 3 + \frac{333}{49} = \frac{147 + 333}{49} = \frac{480}{49}$.

**Conclusion.** The greatest possible value is:

$$\boxed{\dfrac{480}{49}}$$
