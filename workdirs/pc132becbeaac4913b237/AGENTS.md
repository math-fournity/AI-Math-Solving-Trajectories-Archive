# Problem

In a remote research outpost, a computer terminal manages a high-security lock. The terminal contains a digital pool of seven unique data keys labeled with the integers 1, 2, 3, 4, 5, 6, and 7. 

Two engineers, Alex and Blake, take turns attempting to bypass the lock. Alex always takes the first turn. During a turn, an engineer randomly selects one key from the pool, records its value, and immediately returns the key to the pool so it can be selected again in any future turn. 

The security system tracks the cumulative sum of all values recorded since the start of the game. If the total sum becomes a multiple of 3 at the end of a turn, the system unlocks, and the engineer who just performed that turn is declared the winner.

The probability that Alex wins the game can be expressed as an irreducible fraction $p/q$. Calculate the value of $p - q$.
