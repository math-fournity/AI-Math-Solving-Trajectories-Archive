Looking at this problem, I need to find the maximum size of a collection **G** o
f 5-element subsets of a 100-element set **S**, where any two distinct subsets i
n **G** have a *different* intersection of size 4 — meaning every pair intersect
s in exactly 4 elements, and all these 4-element intersections are distinct.

## Proof

**Upper Bound: |G| ≤ 6.**

Take any two distinct sets $A, B \in G$. By hypothesis, $|A \cap B| = 4$, so $|A
 \cup B| = 5 + 5 - 4 = 6$. Let $A \cup B = \{1,2,3,4,5,6\}$, with $A = \{1,2,3,4
,5\}$, $B = \{1,2,3,4,6\}$, and $A \cap B = \{1,2,3,4\}$.

Now consider any third set $C \in G \setminus \{A, B\}$. We must have $|C \cap A
| = 4$ and $|C \cap B| = 4$, with $C \cap A \neq A \cap B$ and $C \cap B \neq A
\cap B$ (all intersections distinct).

Since $|C \cap A| = 4$, the set $C$ shares exactly 4 elements with $A = \{1,2,3,
4,5\}$, so $C$ misses exactly one element of $A$.

- **If $C$ misses element 5** (the element in $A \setminus B$): then $C \supsete
q \{1,2,3,4\}$, so $C \cap A = \{1,2,3,4\} = A \cap B$. This violates the distin
ctness condition. ✗

- **If $C$ misses element $i \in \{1,2,3,4\}$** (an element in $A \cap B$): then
 $C = (\{1,2,3,4,5\} \setminus \{i\}) \cup \{x\}$ for some $x \notin A \setminus
 \{i\}$, i.e., $x = i$ (giving $C = A$, excluded) or $x \notin A = \{1,2,3,4,5\}
$.

  Now compute $|C \cap B|$. We have $B = \{1,2,3,4,6\}$ and $C = (\{1,2,3,4\} \s
etminus \{i\}) \cup \{5, x\}$, so:
$$C \cap B = (\{1,2,3,4\} \setminus \{i\}) \cup (\{5,x\} \cap \{1,2,3,4,6\}) = (
\{1,2,3,4\} \setminus \{i\}) \cup \{x \cap \{6\}\},$$
  since $5 \notin B$. Thus $|C \cap B| = 3 + [x = 6]$. For $|C \cap B| = 4$, we
need $x = 6$.

  Therefore $C = \{1,2,3,4,5,6\} \setminus \{i\}$, which is a **5-subset of $A \
cup B$**. ✓

This shows every member of $G$ must be a 5-subset of the 6-element set $A \cup B
$. Since there are exactly $\binom{6}{5} = 6$ such subsets, $|G| \leq 6$.

**Lower Bound: |G| = 6 is achievable.**

Choose any 6-element subset $T \subseteq S$ (possible since $|S| = 100 \geq 6$).
 Let $G = \{T \setminus \{t\} : t \in T\}$, the collection of all six 5-element
subsets of $T$.

For any two distinct members $T \setminus \{t_1\}$ and $T \setminus \{t_2\}$ (wi
th $t_1 \neq t_2$):
$$(T \setminus \{t_1\}) \cap (T \setminus \{t_2\}) = T \setminus \{t_1, t_2\},$$
which has size $4$. Different unordered pairs $\{t_1, t_2\}$ yield different 4-e
lement sets $T \setminus \{t_1, t_2\}$. Since there are $\binom{6}{2} = 15$ pair
s, all 15 intersections are distinct 4-element subsets.

Thus $G$ satisfies the condition with $|G| = 6$.

**Conclusion.** The upper bound and lower bound match, so the maximum size of $G
$ is:

$$\boxed{6}$$
