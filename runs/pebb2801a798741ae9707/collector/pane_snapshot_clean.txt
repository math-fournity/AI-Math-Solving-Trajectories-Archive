The answer is **no**: $e^A e^B = e^{A+B}$ does not imply $AB = BA$. I provide an

## Counterexample

Define
$$A = 2\pi i \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \qquad B = 2\pi i \be
gin{pmatrix} 1 & 1 \\ 0 & 0 \end{pmatrix}.$$

Set $P_1 = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ and $P_2 = \begin{pmatr
ix} 1 & 1 \\ 0 & 0 \end{pmatrix}$, so $A = 2\pi i\, P_1$ and $B = 2\pi i\, P_2$.

**Both $P_1$ and $P_2$ are idempotent** ($P_1^2 = P_1$, $P_2^2 = P_2$), so for a
ny idempotent $P$:
$$e^{2\pi i\, P} = I + (e^{2\pi i} - 1)P = I + 0 \cdot P = I.$$

Therefore $e^A = I$ and $e^B = I$, giving $e^A e^B = I$.

**Now compute $e^{A+B}$.** We have $A + B = 2\pi i\, Q$ where $Q = P_1 + P_2 = \
begin{pmatrix} 2 & 1 \\ 0 & 0 \end{pmatrix}$. Note:
$$Q^2 = \begin{pmatrix} 2 & 1 \\ 0 & 0 \end{pmatrix}^2 = \begin{pmatrix} 4 & 2 \
\ 0 & 0 \end{pmatrix} = 2Q,$$
so by induction $Q^n = 2^{n-1} Q$ for all $n \geq 1$. Then:
$$e^{2\pi i\, Q} = I + \sum_{n=1}^{\infty} \frac{(2\pi i)^n}{n!}\, 2^{n-1} Q = I
 + \frac{Q}{2}\sum_{n=1}^{\infty} \frac{(4\pi i)^n}{n!} = I + \frac{Q}{2}\bigl(e
^{4\pi i} - 1\bigr) = I + 0 = I.$$

Hence $e^{A+B} = I = e^A e^B$. ✓

**But $A$ and $B$ do not commute:**
$$AB = (2\pi i)^2\, P_1 P_2 = -4\pi^2 \begin{pmatrix} 1 & 1 \\ 0 & 0 \end{pmatri
x}, \qquad BA = (2\pi i)^2\, P_2 P_1 = -4\pi^2 \begin{pmatrix} 1 & 0 \\ 0 & 0 \e
nd{pmatrix}.$$

Since $P_1 P_2 = \begin{pmatrix} 1 & 1 \\ 0 & 0 \end{pmatrix} \neq \begin{pmatri
x} 1 & 0 \\ 0 & 0 \end{pmatrix} = P_2 P_1$, we have $AB \neq BA$.

## Conclusion

The implication $e^A e^B = e^{A+B} \Longrightarrow AB = BA$ is **false**. The co
nverse of the standard theorem ("$AB = BA \Rightarrow e^A e^B = e^{A+B}$") does
not hold, because the matrix exponential is not injective: distinct matrices (ev
en non-commuting ones) can share the same exponential, allowing the equality $e^
A e^B = e^{A+B}$ to hold without commutativity.
