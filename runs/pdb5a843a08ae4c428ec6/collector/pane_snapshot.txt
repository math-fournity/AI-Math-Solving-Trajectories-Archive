## Solution

We evaluate $I = \int_{-\infty}^{+\infty} \exp\!\big(-(x+i)^2\big)\,dx$.

**Substitution.** Let $u = x+i$, so $du = dx$. As $x$ runs along $\mathbb{R}$, $
u$ runs along the horizontal line $\operatorname{Im} u = 1$. Hence

$$I = \int_{-\infty+i}^{+\infty+i} e^{-u^2}\,du.$$

So $I$ is the integral of the entire function $e^{-z^2}$ along the shifted line
$\operatorname{Im} z = 1$. We compare it with the standard Gaussian integral $\i
nt_{-\infty}^{+\infty} e^{-x^2}dx = \sqrt{\pi}$ using a closed contour.

**Contour.** For $R>0$, let $\Gamma_R$ be the positively oriented rectangle with
 vertices
$$-R,\quad R,\quad R+i,\quad -R+i.$$
Since $e^{-z^2}$ is entire, Cauchy's theorem gives $\oint_{\Gamma_R} e^{-z^2}\,d
z = 0$.

Decomposing the contour into four sides:

1. **Bottom** ($-R\to R$, real axis):
$$\int_{-R}^{R} e^{-x^2}\,dx \;\xrightarrow[R\to\infty]{}\; \sqrt{\pi}.$$

2. **Right** ($R\to R+i$): parametrize $z = R+iy$, $0\le y\le 1$, $dz = i\,dy$:
$$\left|\int_0^1 e^{-(R+iy)^2}\,i\,dy\right| \le \int_0^1 \big|e^{-(R+iy)^2}\big
|\,dy = \int_0^1 e^{-R^2+y^2}\,dy \le e^{-R^2+1}\xrightarrow[R\to\infty]{}0.$$

3. **Top** ($R+i\to -R+i$, traversed right-to-left): parametrize $z = x+i$, $x$
from $R$ to $-R$:
$$\int_{R}^{-R} e^{-(x+i)^2}\,dx = -\int_{-R}^{R} e^{-(x+i)^2}\,dx \;\xrightarro
w[R\to\infty]{}\; -I.$$

4. **Left** ($-R+i\to -R$): parametrize $z = -R+iy$, $y$ from $1$ to $0$:
$$\left|\int_1^0 e^{-(-R+iy)^2}\,i\,dy\right| \le \int_0^1 e^{-R^2+y^2}\,dy \le
e^{-R^2+1}\xrightarrow[R\to\infty]{}0.$$

**Taking the limit.** Summing the four contributions and using $\oint = 0$:

$$\int_{-R}^{R} e^{-x^2}\,dx \;-\; \int_{-R}^{R} e^{-(x+i)^2}\,dx \;+\; (\text{r
ight side}) \;+\; (\text{left side}) \;=\; 0.$$

Letting $R\to\infty$, the vertical sides vanish, giving

$$\sqrt{\pi} - I = 0.$$

**Result.**

$$\boxed{\int_{-\infty}^{+\infty} \exp\!\big(-(x+i)^2\big)\,dx \;=\; \sqrt{\pi}.
}$$

The key point is that $e^{-z^2}$ is entire, so its integral is path-independent
up to the vanishing contributions of the vertical segments; the horizontal shift
 by $i$ in the imaginary direction does not change the value of the Gaussian int
egral.
