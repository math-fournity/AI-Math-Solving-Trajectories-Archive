## Proof

We prove by contradiction. Suppose $A = \{a_0 < a_1 < \cdots < a_{4n+1}\} \subse
teq \{0, 1, \ldots, 5^n\}$ and for all $i < j < k$,
$$a_k + 2a_i \leq 3a_j, \quad\text{i.e.,}\quad a_k - a_j \leq 2(a_j - a_i).$$

**Define gaps and tail sums.** Let $d_i = a_{i+1} - a_i \geq 1$ for $i = 0, 1, \
ldots, 4n$ (since the $a_i$ are distinct integers). Define the tail sum:
$$S_i = d_i + d_{i+1} + \cdots + d_{4n} = a_{4n+1} - a_i, \quad i = 0, 1, \ldots
, 4n,$$
with $S_{4n+1} = 0$. Note that $S_0 = a_{4n+1} - a_0 \leq 5^n$.

**Key inequality.** Apply the assumed condition to the triple $(a_i,\, a_{i+1},\
, a_{4n+1})$ for each $i = 0, 1, \ldots, 4n-1$ (these are valid triples since $i
 < i+1 < 4n+1$):
$$a_{4n+1} + 2a_i \leq 3a_{i+1}.$$
Rearranging:
$$a_{4n+1} - a_{i+1} \leq 2(a_{i+1} - a_i) = 2d_i.$$
The left side is $S_{i+1}$ and $d_i = S_i - S_{i+1}$, so:
$$S_{i+1} \leq 2(S_i - S_{i+1}) \implies 3S_{i+1} \leq 2S_i \implies S_{i+1} \le
q \tfrac{2}{3}\,S_i.$$

**Iterating.** Since $d_{4n} \geq 1$, we have $S_{4n} \geq 1$. Applying the ineq
uality $S_{i+1} \leq \frac{2}{3}S_i$ repeatedly for $i = 4n-1, 4n-2, \ldots, 0$:
$$S_{4n} \geq 1,\quad S_{4n-1} \geq \tfrac{3}{2}S_{4n} \geq \tfrac{3}{2},\quad S
_{4n-2} \geq \tfrac{3}{2}S_{4n-1} \geq \left(\tfrac{3}{2}\right)^2, \quad \ldots
$$
$$S_0 \geq \left(\tfrac{3}{2}\right)^{4n} = \left(\tfrac{81}{16}\right)^n.$$

**Contradiction.** We have:
$$\left(\frac{81}{16}\right)^n \leq S_0 \leq 5^n.$$
This requires $\frac{81}{16} \leq 5$, i.e., $81 \leq 80$, which is **false**. (T
he key numerical fact is $3^4 = 81 > 80 = 16 \cdot 5$, equivalently $\left(\frac
{3}{2}\right)^4 = \frac{81}{16} > 5$.)

This contradiction shows our assumption was false. Therefore, there exist $a, b,
 c \in A$ with $a < b < c$ and $c + 2a > 3b$. $\blacksquare$
