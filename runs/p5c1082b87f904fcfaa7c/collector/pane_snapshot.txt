$k_n$ for $n=3$ to $20$.

## Analysis of the Structure

Let $\mathcal{F}$ be a family of triples (3-element subsets) of $Z$ with pairwis
e intersection exactly 1. I identify two structural types.

**Type 1 (Star/Pencil):** All triples share a common element $p$. Then each trip
le is $\{p, x_i, y_i\}$, and any two such triples share only $p$, so the pairs $
\{x_i, y_i\}$ must be pairwise disjoint. This gives at most $\lfloor (n-1)/2 \rf
loor$ triples.

**Type 2 (Non-star):** Not all triples share a common element. I prove this yiel
ds at most 7 triples (the Fano plane).

### Non-star Case Analysis

Since $\mathcal{F}$ is non-star, there exist $T_1 = \{a,b,c\}$ and $T_2 = \{a,d,
e\}$ sharing $a$, and some $T_3$ not containing $a$. Then $T_3$ shares exactly o
ne element with $T_1$ (say $b$) and one with $T_2$ (say $d$), so $T_3 = \{b, d,
f\}$ where $f \notin \{a,c,e\}$ (and $f \notin \{b,d\}$), requiring a 6th elemen
t.

**Every other triple $T$ must be one of four types**, determined by which elemen
t it shares with $T_1$:

- **Shares $a$:** $T = \{a, f, w\}$, $w \notin \{b,c,d,e\}$ (Type 1, needs 7th e
lement $w$)
- **Shares $b$:** $T = \{b, e, w\}$, $w \notin \{a,c,d,f\}$ (Type 2, needs 7th e
lement $w$)
- **Shares $c$, contains $d$:** $T = \{c, d, w\}$, $w \notin \{a,b,e,f\}$ (Type
3, needs 7th element $w$)
- **Shares $c$, contains $f$:** $T = \{c, e, f\}$ (Type 4, uses only the 6 exist
ing elements)

**At most one triple per type:** Two Type-1 triples $\{a,f,w_1\}, \{a,f,w_2\}$ s
hare $\{a,f\}$ = 2 elements — forbidden. Similarly for Types 2, 3.

**Cross-type constraints:** Types 1 and 2 ($\{a,f,w_1\}$ and $\{b,e,w_2\}$) shar
e nothing unless $w_1 = w_2$. Since they must share exactly 1, we need $w_1 = w_
2$. The same applies to all pairs among Types 1–3. So if all three are present,
they share a common $w$, yielding the **Fano plane**:

$$\{a,b,c\},\; \{a,d,e\},\; \{b,d,f\},\; \{c,e,f\},\; \{a,f,w\},\; \{b,e,w\},\;
\{c,d,w\}$$

— 7 triples on 7 points, every pair meeting in exactly 1 point.

**No 8th triple is possible:** In the Fano plane, every pair of points lies on e
xactly one line. Any new triple $\{x,y,z\}$ using Fano points has each pair on s
ome Fano line, so it shares 2 elements with that line — forbidden. If it uses a
new point $g$: $\{x,y,g\}$ must share exactly 1 with each Fano line, but $x,y$ l
ie on a Fano line $L$, so it shares 2 with $L$ — forbidden.

### Summary of Non-star Maximum

- **$n \leq 5$:** Non-star impossible (needs 6 elements).
- **$n = 6$:** Non-star max = 4 ($T_1, T_2, T_3$, Type 4). Types 1–3 need a 7th
element.
- **$n \geq 7$:** Non-star max = 7 (Fano plane, cannot be extended).
