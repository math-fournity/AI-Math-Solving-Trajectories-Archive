## Complete Proof of `z_even`

**Theorem:** For all n ∈ ℕ, z(2(n+1)) = 0. That is, the Cayley table of the cycl
ic group ℤ_N for N = 2(n+1) has no transversals.

**Proof:**

Let N = 2(n+1). Then N is a positive even integer with N ≥ 2.

Recall that a transversal of the Cayley table of ℤ_N is a permutation σ of {0, 1
, …, N−1} such that the map i ↦ i + σ(i) (mod N) is also a permutation.

**Suppose for contradiction** that a transversal σ exists. Then:
- σ is a bijection on Fin N (it is a permutation).
- The map f : i ↦ i + σ(i) is a bijection on Fin N (by the definition of transve
rsal — the cell labels i + σ(i) are all distinct, hence a permutation since Fin
N is finite).

Work in the ring ℤ_N. Define S = Σ_{i ∈ Fin N} (i : ℤ_N).

**Step 1: Establish S + S = S.**

Since f is a bijection, reindexing the sum:
$$\sum_{i=0}^{N-1} f(i) = \sum_{i=0}^{N-1} i = S$$
That is, $\sum_{i=0}^{N-1} (i + \sigma(i)) = S$.

Since σ is a bijection, reindexing again:
$$\sum_{i=0}^{N-1} \sigma(i) = \sum_{i=0}^{N-1} i = S$$

Now compute:
$$S = \sum_{i=0}^{N-1}(i + \sigma(i)) = \sum_{i=0}^{N-1} i + \sum_{i=0}^{N-1} \s
igma(i) = S + S$$

where the second equality uses linearity of summation (distributing the sum over
 addition).

**Step 2: Deduce S = 0.**

From S + S = S, subtract S from both sides (ℤ_N is an additive group):
$$S = 0 \text{ in } \mathbb{Z}_N$$

**Step 3: Compute S explicitly.**

$$S = \sum_{i=0}^{N-1} i = \frac{N(N-1)}{2}$$

Set m = n + 1, so N = 2m. Then:
$$S = \frac{2m(2m-1)}{2} = m(2m-1) = 2m^2 - m$$

Reduce modulo N = 2m:
$$S = 2m^2 - m \equiv -m \equiv m \pmod{2m}$$

since $2m^2 = m \cdot 2m \equiv 0 \pmod{2m}$.

**Step 4: Derive the contradiction.**

We have shown S = m = n + 1 in ℤ_N. Since n ≥ 0:
- m = n + 1 ≥ 1 > 0
- m = n + 1 < 2(n+1) = N

Therefore 0 < m < N, which means m ≢ 0 (mod N), i.e., **S ≠ 0 in ℤ_N**.

This contradicts S = 0 from Step 2. ∎

### Key ideas of the proof:

1. **Reindexing via bijections:** Both σ and f(i) = i + σ(i) are bijections, so
summing over their outputs equals summing over all elements.

2. **The parity obstruction:** The equation S + S = S forces S = 0, but the actu
al sum S = N(N−1)/2 ≡ N/2 (mod N) is nonzero when N is even — because N/2 is a g
enuine residue between 0 and N.

3. **Why odd N works:** For odd N, N(N−1)/2 = ((N−1)/2)·N ≡ 0 (mod N), so the ob
struction vanishes — consistent with the conjecture that odd-order Latin squares
 always have transversals.
