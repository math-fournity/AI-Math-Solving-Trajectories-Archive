## Solution

Let the state be the number of switches that are **on** (out of 3). We start at
state **1** (one on, two off).

**Transition rule.** If the current state is $k$ (so $k$ switches on, $3-k$ off)
, clicking a uniformly random switch:
- picks an **on** switch with probability $\frac{k}{3}$, moving to state $k-1$;
- picks an **off** switch with probability $\frac{3-k}{3}$, moving to state $k+1
$.

Explicitly:
- State 0: $\to 1$ with probability $1$.
- State 1: $\to 0$ with $\frac{1}{3}$, $\to 2$ with $\frac{2}{3}$.
- State 2: $\to 1$ with $\frac{2}{3}$, $\to 3$ with $\frac{1}{3}$.
- State 3: $\to 2$ with probability $1$.

**Step-by-step computation.** Let $P_i^{(t)}$ be the probability of being in sta
te $i$ after $t$ clicks.

**Start ($t=0$):** $P_1^{(0)}=1$.

**After 1 click:**
$$P_0^{(1)}=\tfrac{1}{3},\quad P_2^{(1)}=\tfrac{2}{3}.$$

**After 2 clicks:**
- From state 0 ($\frac{1}{3}$): $\to 1$, contributing $\frac{1}{3}$.
- From state 2 ($\frac{2}{3}$): $\to 1$ with $\frac{2}{3}$, contributing $\frac{
4}{9}$; $\to 3$ with $\frac{1}{3}$, contributing $\frac{2}{9}$.

$$P_1^{(2)}=\tfrac{1}{3}+\tfrac{4}{9}=\tfrac{7}{9},\quad P_3^{(2)}=\tfrac{2}{9}.
$$

**After 3 clicks:**
- From state 1 ($\frac{7}{9}$): $\to 0$ with $\frac{1}{3}$, contributing $\frac{
7}{27}$; $\to 2$ with $\frac{2}{3}$, contributing $\frac{14}{27}$.
- From state 3 ($\frac{2}{9}$): $\to 2$, contributing $\frac{2}{9}=\frac{6}{27}$
.

$$P_0^{(3)}=\tfrac{7}{27},\quad P_2^{(3)}=\tfrac{14}{27}+\tfrac{6}{27}=\tfrac{20
}{27}.$$

**After 4 clicks:**
- From state 0 ($\frac{7}{27}$): $\to 1$, contributing $\frac{7}{27}=\frac{21}{8
1}$.
- From state 2 ($\frac{20}{27}$): $\to 1$ with $\frac{2}{3}$, contributing $\fra
c{20}{27}\cdot\frac{2}{3}=\frac{40}{81}$; $\to 3$ with $\frac{1}{3}$, contributi
ng $\frac{20}{81}$.

$$P_1^{(4)}=\frac{21}{81}+\frac{40}{81}=\frac{61}{81}.$$

**Reduction.** Since $61$ is prime and $81=3^4$, we have $\gcd(61,81)=1$, so $\f
rac{m}{n}=\frac{61}{81}$ with $m=61$, $n=81$.

$$m+n=61+81=142.$$
