**Answer: Yes.** If $B \times A \cong A$ for every object $A$ in $\mathbf{C}$, t
hen $B$ is a terminal object.

---

### Proof

Assume throughout that $\mathbf{C}$ has binary products (the hypothesis itself f
orces $B\times A$ to exist for every $A$, and in particular $B\times B$ exists).

**Step 1 — A cardinality constraint on $\operatorname{Hom}(X,B)$.**

Specialize the hypothesis to $A = B$. We obtain an isomorphism
$$\psi : B \times B \xrightarrow{\;\sim\;} B.$$

For an arbitrary object $X$, postcomposition with the isomorphism $\psi$ yields
a bijection of sets
$$\operatorname{Hom}(X,\, B\times B) \;\xrightarrow{\;\sim\;}\; \operatorname{Ho
m}(X,\, B), \qquad u \mapsto \psi\circ u.$$

By the universal property of the categorical product, there is a natural bijecti
on
$$\operatorname{Hom}(X,\, B\times B) \;\cong\; \operatorname{Hom}(X,B)\times \op
eratorname{Hom}(X,B).$$

Composing these two bijections gives, for every $X$,
$$\operatorname{Hom}(X,B)\times\operatorname{Hom}(X,B) \;\cong\; \operatorname{H
om}(X,B).$$

Hence $\lvert\operatorname{Hom}(X,B)\rvert^{2}=\lvert\operatorname{Hom}(X,B)\rve
rt$, so
$$\lvert\operatorname{Hom}(X,B)\rvert \in \{0,\,1\} \quad\text{for every }X.$$

**Step 2 — Ruling out $0$: existence of a map $A\to B$.**

Let $A$ be any object. By hypothesis there is an isomorphism $\varphi_{A}:B\time
s A\xrightarrow{\sim} A$. Denote by $\pi_{1}:B\times A\to B$ the first product p
rojection. Then
$$\pi_{1}\circ\varphi_{A}^{-1}\;:\;A\longrightarrow B$$
is a well-defined morphism $A\to B$. Therefore $\operatorname{Hom}(A,B)\neq\varn
othing$ for every $A$.

Combining with Step 1,
$$\lvert\operatorname{Hom}(A,B)\rvert = 1 \quad\text{for every object }A.$$

**Step 3 — Conclusion.**

A terminal object is exactly an object $T$ such that $\lvert\operatorname{Hom}(A
,T)\rvert=1$ for every $A$. We have shown $\lvert\operatorname{Hom}(A,B)\rvert=1
$ for every $A$. Therefore $B$ is a terminal object of $\mathbf{C}$.

---

**Remark.** The argument uses the hypothesis in two essential ways: the instance
 $A=B$ (giving $B\times B\cong B$, which forces *at most one* map into $B$ from
any object), and the general instance $B\times A\cong A$ (giving *at least one*
map $A\to B$ via $\pi_{1}\circ\varphi_{A}^{-1}$). Together they pin down exactly
 one map $A\to B$ for every $A$, which is precisely the definition of $B$ being
terminal. Note that no pre-existing terminal object is assumed; $B$ is *shown* t
o be one.
