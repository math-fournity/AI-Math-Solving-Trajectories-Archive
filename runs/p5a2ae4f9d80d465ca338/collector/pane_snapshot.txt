## Proof

**Yes**, such a bijection exists.

### Setup

Take $\mathbb{N} = \{1, 2, 3, 4, \ldots\}$. The natural numbers partition into t
hree classes:
- **Primes** $P = \{2, 3, 5, 7, 11, \ldots\}$ — countably infinite.
- **Composites** $C = \{4, 6, 8, 9, 10, \ldots\}$ — countably infinite.
- **The number 1** — neither prime nor composite (a single element).

The integers partition as $\mathbb{Z} = \mathbb{Z}_{<0} \cup \mathbb{Z}_{\geq 0}
$, where $\mathbb{Z}_{<0} = \{-1, -2, -3, \ldots\}$ and $\mathbb{Z}_{\geq 0} = \
{0, 1, 2, 3, \ldots\}$, both countably infinite.

### Construction

Enumerate the primes in increasing order: $p_1 = 2,\ p_2 = 3,\ p_3 = 5,\ p_4 = 7
, \ldots$

Enumerate the composites in increasing order: $c_1 = 4,\ c_2 = 6,\ c_3 = 8,\ c_4
 = 9, \ldots$

Define $g: \mathbb{N} \to \mathbb{Z}$ by:
$$g(1) = 0, \qquad g(p_k) = k, \qquad g(c_k) = -k, \quad \text{for } k = 1, 2, 3
, \ldots$$

### Verification

**Primes map to nonnegatives:** $g(p_k) = k \in \{1, 2, 3, \ldots\} \subseteq \m
athbb{Z}_{\geq 0}$. ✓

**Composites map to negatives:** $g(c_k) = -k \in \{-1, -2, -3, \ldots\} = \math
bb{Z}_{<0}$. ✓

**Surjectivity:** The image is
$$g[\mathbb{N}] = \{0\} \cup \{1, 2, 3, \ldots\} \cup \{-1, -2, -3, \ldots\} = \
mathbb{Z}_{\geq 0} \cup \mathbb{Z}_{<0} = \mathbb{Z}.$$
Every integer is hit. ✓

**Injectivity:** The three pieces of the domain map to three disjoint pieces of
the codomain:
- $\{1\} \mapsto \{0\}$
- $P \mapsto \{1, 2, 3, \ldots\}$
- $C \mapsto \{-1, -2, -3, \ldots\}$

Within each piece, $g$ is injective (distinct indices give distinct values), and
 the three image sets are pairwise disjoint. So $g$ is injective. ✓

Since $g$ is both injective and surjective, it is a **bijection** satisfying all
 required conditions.

### Why this works

The key observations are:

1. **Cardinality match:** Primes and composites are each countably infinite, mat
ching $\mathbb{Z}_{\geq 0}$ and $\mathbb{Z}_{<0}$ respectively.

2. **The leftover element fits:** The single element 1 (neither prime nor compos
ite) is placed at $0 \in \mathbb{Z}_{\geq 0}$. This "uses up" one nonnegative in
teger, leaving $\{1, 2, 3, \ldots\}$ for the primes — still countably infinite,
so a bijection from primes to this set exists.

3. **No conflict:** Composites exhaust all of $\mathbb{Z}_{<0}$, primes exhaust
$\mathbb{Z}_{>0}$, and 1 fills the remaining slot at $0$. The partition is clean
.

**Remark on convention:** If $\mathbb{N}$ is taken to include $0$ (so both $0$ a
nd $1$ are neither prime nor composite), the same approach works: set $g(0) = 0$
, $g(1) = 1$, map primes to $\{2, 3, 4, \ldots\}$, and composites to $\{-1, -2,
-3, \ldots\}$. Removing finitely many elements from a countably infinite set pre
serves countability, so the construction adapts trivially.
