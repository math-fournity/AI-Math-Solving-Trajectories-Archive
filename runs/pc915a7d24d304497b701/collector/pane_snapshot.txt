## Setup

Let $k = p/q$ in lowest terms ($\gcd(p,q)=1$, $0 < p < q$). Model G's rate after
 $t$ missions with $s$ successes is $s/t$. The rate equals $p/q$ exactly when $t
$ is a multiple of $q$.

## When Can a "Jump" Occur?

The rate increases only on successes. A **jump** over $k$ in a single step (from
 $s/t$ to $(s+1)/(t+1)$) requires:
$$\frac{s}{t} < \frac{p}{q} < \frac{s+1}{t+1}$$

This gives $sq < pt$ and $(s+1)q > p(t+1)$, i.e., $sq > pt + p - q$. Setting $d
= pt - sq$, the condition becomes:
$$0 < d < q - p$$

## Key Theorem

**The property holds if and only if $q - p = 1$, i.e., $k = (q-1)/q$.**

**Sufficiency ($q-p=1$):** A jump requires an integer $d$ with $0 < d < 1$, whic
h is impossible. Since the rate can only cross $k$ via a single-step increase (s
uccesses increase the rate one at a time; failures only decrease it), the first
time the rate exceeds $k$, the previous step was $\leq k$. If it was $=k$, we're
 done. If it was $<k$, that's a jump — impossible. So the rate must hit $k$ exac
tly. ✓

**Necessity ($q-p \geq 2$):** Choose $d=1$ (valid since $0 < 1 < q-p$). Since $\
gcd(p,q)=1$, solve $pt_0 - qs_0 = 1$ with $1 \leq t_0 \leq q-1$. Then $s_0 = (pt
_0-1)/q \geq 0$ and $s_0 \leq t_0$.

- Start at $(0,1)$: rate $0 < p/q$. ✓
- Build up to $(s_0, t_0)$ using $s_0$ successes and $t_0-1-s_0$ failures in any
 order. Since every intermediate $t' \leq t_0 < q$, no $t'$ is a multiple of $q$
, so the rate **never** equals $p/q$. ✓
- Add one success: rate becomes $(s_0+1)/(t_0+1) > p/q$ (guaranteed by $d < q-p$
). If $t_0+1 = q$, then $s_0+1 = (p(q-1)+q-1)/q \neq p$ (since $q-p \geq 2$), so
 the rate still isn't $p/q$. ✓

This gives a complete path from below $k$ to above $k$ never hitting $k$, so the
 property **fails**. ✓

## Collecting All Valid $k$

The valid values are $k = (q-1)/q$ for $q = 2, 3, \ldots, 2015$ (since $(q-1)/q$
 is already in lowest terms, it requires $n = q \leq 2015$; values with $q > 201
5$ cannot be expressed as $a/n$ with $n \leq 2015$).

The endpoints $k=0$ and $k=1$ are excluded: for $k=0$ no initial rate $<0$ exist

## Computing the Product

$$\prod_{q=2}^{2015} \frac{q-1}{q} = \frac{1}{2} \cdot \frac{2}{3} \cdot \frac{3
}{4} \cdots \frac{2014}{2015} = \frac{1}{2015}$$

This is a telescoping product: all intermediate factors cancel, leaving $\frac{1
}{2015}$.
