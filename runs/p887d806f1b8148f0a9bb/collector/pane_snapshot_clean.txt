Looking at this problem, I need to find positive integers n ≤ 10000 that are sim
ultaneously 7-safe, 11-safe, and 13-safe.

## Setting Up the Residue Conditions

A positive integer n is **p-safe** if |n − kp| > 2 for every integer k. The dist
ance from n to the nearest multiple of p is min(r, p−r) where r = n mod p ∈ {0,1
,…,p−1}. So n is p-safe iff:

$$2 < r < p - 2, \quad \text{i.e., } r \in \{3, 4, \ldots, p-3\}$$

This gives the allowed residue sets:
- **7-safe:** r mod 7 ∈ {3, 4} → **2 values**
- **11-safe:** r mod 11 ∈ {3,4,5,6,7,8} → **6 values**
- **13-safe:** r mod 13 ∈ {3,4,5,6,7,8,9,10} → **8 values**

**Verification with the example:** For p=10, allowed residues are {3,4,5,6,7}, g
iving numbers {3,4,5,6,7,13,14,15,16,17,23,…} ✓

## Counting via the Chinese Remainder Theorem

Since 7, 11, 13 are pairwise coprime, the period is 7 × 11 × 13 = **1001**. By C
RT, each valid combination of residues corresponds to exactly one value modulo 1
001.

**Valid numbers per complete period:** 2 × 6 × 8 = **96**.

## Decomposing [1, 10000]

$$10000 = 9 \times 1001 + 991$$

- **Complete periods:** n = 1 to 9009 (9 periods) → 9 × 96 = **864**
- **Partial period:** n = 9010 to 10000 (991 numbers)

Since 9010 = 9×1001 + 1, the partial period covers residues m = 1, 2, …, 991 (mo
d 1001). The full period {0,1,…,1000} has 96 valid values, so I subtract the val
id values among the **excluded** residues {0, 992, 993, …, 1000}:

| m | m mod 7 | Valid? |
|---|---------|--------|
| 0 | 0 | ✗ |
| 992 | 5 | ✗ |
| 993 | 6 | ✗ |
| 994 | 0 | ✗ |
| 995 | 1 | ✗ |
| 996 | 2 | ✗ |
| 997 | 3 | check mod 11 = 7 ✓, mod 13 = 9 ✓ → **Valid** |
| 998 | 4 | check mod 11 = 8 ✓, mod 13 = 10 ✓ → **Valid** |
| 999 | 5 | ✗ |
| 1000 | 6 | ✗ |

Only **2** valid values are excluded (m = 997 and m = 998).

**Partial period count:** 96 − 2 = **94**

## Final Answer

$$864 + 94 = \boxed{958}$$
