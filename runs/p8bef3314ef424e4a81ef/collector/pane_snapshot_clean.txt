## 证明

设 $a = BC$，$m = AB$，$n = AC$。设 $\angle A = 2\alpha$，$\angle B = \beta$，$\
angle C = \gamma$，因此 $2\alpha + \beta + \gamma = \pi$。

**步骤 1：$AD$ 是角平分线。**

因为 $EF \parallel BC$，三角形 $\triangle AEF$ 和 $\triangle ABC$ 相似，得出 $\f
rac{AF}{AB} = \frac{AE}{AC}$，即 $\frac{m - FB}{m} = \frac{n - CE}{n}$。因为 $FB
 = BD$ 且 $CE = DC$，这得出 $\frac{BD}{m} = \frac{DC}{n}$，因此 $\frac{BD}{DC} =
 \frac{m}{n} = \frac{AB}{AC}$。根据角平分线定理，$AD$ 平分 $\angle A$，所以 $\an
gle BAD = \angle CAD = \alpha$。

**步骤 2：三角形 $\triangle DEF$ 中的角。**

因为 $FB = BD$，三角形 $\triangle BDF$ 是等腰三角形，且 $\angle BFD = \angle BDF
 = \frac{\pi - \beta}{2}$。因为 $EF \parallel BC$，$\angle AFE = \beta$，所以 $\
angle BFA = \pi - \beta$，且
$$\angle DFE = \angle BFA - \angle BFD = \frac{\pi - \beta}{2}.$$

类似地，$CE = DC$ 得出 $\angle CED = \angle CDE = \frac{\pi - \gamma}{2}$，且 $\
angle FED = \frac{\pi - \gamma}{2}$。

因此
$$\angle EDF = \pi - \tfrac{\pi-\beta}{2} - \tfrac{\pi-\gamma}{2} = \tfrac{\beta
+\gamma}{2} = \tfrac{\pi}{2} - \alpha.$$

**步骤 3：坐标系。**

设 $B = (0,0)$，$C = (a,0)$，$A = (u,v)$，且 $v > 0$。设 $\lambda = \frac{a}{m+n
}$。根据步骤 1：
$$D = (m\lambda,\, 0),\quad F = (\lambda u,\, \lambda v),\quad E = \bigl(a(1-\la
mbda)+\lambda u,\; \lambda v\bigr).$$

利用余弦定理 $a^2 = (m-n)^2 + 4mn\sin^2\alpha$，可以推导出：
$$u = \frac{m(m - n\cos 2\alpha)}{a}, \qquad v = \frac{2mn\sin\alpha\cos\alpha}{
a}.$$

**步骤 4：$F$ 处的切线方向。**

根据切线-弦角定理，$F$ 处的切线与弦 $FE$ 之间的夹角等于 $\angle FDE = \frac{\pi}
{2}-\alpha$。因为 $D$ 位于 $EF$ 下方（$D$ 在 $y=0$ 处，$EF$ 在 $y=\lambda v > 0$
 处），切线位于 $FE$ 上方。因为 $FE$ 指向 $+x$ 方向（沿 $BC$），所以 $F$ 处的切
线方向为 $(\sin\alpha,\, \cos\alpha)$。

**步骤 5：计算 $P$。**

$F$ 处的切线：$(x,y) = (\lambda u + t\sin\alpha,\; \lambda v + t\cos\alpha)$。直
线 $AD$：$(u + s(m\lambda - u),\; v(1-s))$。

通过 $y$ 轴坐标相等并代入 $x$ 轴坐标，设 $\tau = \tan\alpha$：
$$s = \frac{(1-\lambda)(v\tau - u)}{m\lambda - u + v\tau}, \qquad P_y = v(1-s) =
 \frac{v\lambda(m + v\tau - u)}{m\lambda - u + v\tau}.$$

利用 $v\tau = \frac{2mn\sin^2\alpha}{a}$ 以及 $u, v$ 的表达式：
- $m + v\tau - u = \frac{m(a + n - m)}{a}$,
- $m\lambda - u + v\tau = \frac{2mn(n - m\cos 2\alpha)}{a(m+n)}$.

因此：
$$P_y = \frac{m\sin\alpha\cos\alpha\,(a + n - m)}{n - m\cos 2\alpha}.$$

**步骤 6：计算 $Q$。**

$EF$ 的垂直平分线是垂直线 $x = \frac{a(1-\lambda) + 2\lambda u}{2}$。与直线 $AC$
 相交：
$$Q_y = \frac{v\bigl(a(1+\lambda) - 2\lambda u\bigr)}{2(a - u)}.$$

计算各部分：
- $a(1+\lambda) - 2\lambda u = a + n - m$ （利用 $a(m{+}n{+}a) - 2m(m{-}n\cos 2\
alpha) = (m{+}n)(a{+}n{-}m)$，这可由 $a^2 = m^2 + n^2 - 2mn\cos 2\alpha$ 得出）
，
- $a - u = \frac{n(n - m\cos 2\alpha)}{a}$.

因此：
$$Q_y = \frac{v\cdot a(a+n-m)}{2n(n - m\cos 2\alpha)} = \frac{m\sin\alpha\cos\al
pha\,(a + n - m)}{n - m\cos 2\alpha}.$$

**步骤 7：结论。**

$$P_y = Q_y = \frac{m\sin\alpha\cos\alpha\,(a + n - m)}{n - m\cos 2\alpha}.$$

因为 $P$ 和 $Q$ 具有相同的 $y$ 坐标，直线 $PQ$ 是水平的，即 $PQ \parallel BC$。
$\blacksquare$
