## Proof

**Setup and reduction.** Let the grid be $G=[m]\times[n]$. A set $C\subseteq G$
of "off" screens is *closed* if no $2\times2$ subgrid contains exactly 3 cells o
f $C$ (equivalently, the closure of $C$ under the rule is $C$ itself). Starting
from an initial set $S$, the process monotonically grows $S$ until it reaches th
e smallest closed set $\overline S\supseteq S$. Full shutdown happens iff $\over
line S=G$.

So $k=\max\{|S|:\overline S\neq G\}$. Since we may take $S=C$ for any closed $C$
, this equals $\max\{|C|:C\subsetneq G,\ C\text{ closed}\}$. Writing $T=G\setmin
us C$ (the screens that stay on), the condition "no $2\times2$ has exactly 3 in
$C$" becomes

$$\text{no }2\times2\text{ subgrid has exactly 1 cell in }T. \tag{$\star$}$$

Thus $k=mn-\mu$, where $\mu$ is the minimum size of a **nonempty** set $T\subset
eq G$ satisfying $(\star)$.

---

**Lemma 1 (boundary propagation).** If the topmost row containing a cell of $T$
is $r>1$, then every cell of row $r$ lies in $T$ (so $|T|\ge n$). The analogous
statement holds for the bottommost, leftmost, and rightmost rows/columns.

*Proof.* Pick $(r,c)\in T$ with row $r-1$ empty. The block on rows $r-1,r$ and c
olumns $c-1,c$ (when $c>1$) has its only possible $T$-cells in row $r$: it contr
ibutes $A_{r,c-1}+A_{r,c}=A_{r,c-1}+1$. By $(\star)$ this is not $1$, so $A_{r,c
-1}=1$, i.e. $(r,c-1)\in T$. Similarly the block on columns $c,c+1$ (when $c<n$)
 forces $(r,c+1)\in T$. Propagating left and right fills the entire row $r$. $\s
quare$

---

**Lemma 2 (empty row forces constant neighbors).** If row $i$ is entirely free o
f $T$, then each of rows $i-1$ and $i+1$ (when it exists) is constant — all $0$
or all $1$.

*Proof.* For the pair of rows $(i,i+1)$, the column sums are $s_j=A_{i,j}+A_{i+1
,j}=A_{i+1,j}\in\{0,1\}$. Condition $(\star)$ gives $s_j+s_{j+1}\ne1$, i.e. $A_{
i+1,j}+A_{i+1,j+1}\ne1$; since both terms are in $\{0,1\}$, they must be equal.
Hence row $i+1$ is constant. The argument for row $i-1$ is identical. $\square$

---

**Theorem.** $\mu=\min(m,n)$.

*Lower bound.* Let $T\ne\emptyset$ satisfy $(\star)$.

- If $T$ does **not** touch the top boundary (topmost $T$-row $>1$), Lemma 1 giv
es $|T|\ge n\ge\min(m,n)$. Likewise, not touching the bottom gives $|T|\ge n\ge\
min(m,n)$.
- So suppose $T$ touches **both** the top (row $1$) and the bottom (row $m$); bo
th rows are nonempty. We prove by induction that either every row is nonempty (g
iving $|T|\ge m\ge\min(m,n)$) or some row is entirely $1$ (giving $|T|\ge n\ge\m
in(m,n)$).

  Base: row $1$ is nonempty. Assume rows $1,\dots,i$ are all nonempty for some $
i<m$. Consider row $i+1$:
  - If $i+1=m$, it is nonempty (touches bottom); all rows are nonempty, so $|T|\
ge m$.
  - If $i+1<m$ and row $i+1$ is nonempty, extend the induction.
  - If $i+1<m$ and row $i+1$ is empty, Lemma 2 makes rows $i$ and $i+2$ constant
. Row $i$ is nonempty and constant, hence entirely $1$, so $|T|\ge n$.

  In every outcome $|T|\ge\min(m,n)$.

*Upper bound (construction).* If $m\le n$, take $T$ to be a full column: $|T|=m=
\min(m,n)$. Any $2\times2$ block either avoids that column (contributes $0$) or
meets it in exactly $2$ cells — never $1$ — so $(\star)$ holds. If $n\le m$, use
 a full row instead. Hence $\mu\le\min(m,n)$.

Combining both bounds, $\mu=\min(m,n)$. $\square$

---

**Conclusion.** Therefore
$$k = mn-\mu = mn-\min(m,n).$$
For $m=15,\ n=20$:
$$k = 15\cdot 20 - \min(15,20)=300-15=\boxed{285}.$$

(Explicitly: turn off all screens except those in a single column — $285$ screen
s. No $2\times2$ block then has exactly $3$ off screens, so nothing further trig
gers, and the remaining $15$ screens stay on forever. By the theorem, no set of
$286$ or more initially-off screens can avoid full shutdown.)
