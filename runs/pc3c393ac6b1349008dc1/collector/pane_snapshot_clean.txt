## Solution

We count the number of ways to write 2000 as a sum of three positive integers wh
ere order does **not** matter, i.e., the number of partitions of 2000 into exact
ly 3 positive parts.

### Setting up the count

We count solutions to
$$a + b + c = 2000, \qquad 1 \le a \le b \le c.$$

Substitute $a = x+1,\; b = a + y = x+1+y,\; c = b + z = x+1+y+z$ with $x, y, z \
ge 0$. Then
$$a+b+c = 3(x+1) + 2y + z = 2000,$$
so
$$3x + 2y + z = 1997, \qquad x,y,z \ge 0.$$

### Counting non‑negative solutions

For each fixed $x$ with $0 \le x \le \lfloor 1997/3\rfloor = 665$, we need $2y +
 z = 1997 - 3x$, giving $\lfloor(1997-3x)/2\rfloor + 1$ solutions $(y,z)$.

Let $m = 1997 - 3x$. Since 1997 is odd, $m$ is **odd when $x$ is even** and **ev
en when $x$ is odd**.

- **$x$ even** (333 values: $x = 0,2,\dots,664$): count $= \dfrac{m+1}{2} = \dfr
ac{1998-3x}{2}$.
- **$x$ odd** (333 values: $x = 1,3,\dots,665$): count $= \dfrac{m}{2}+1 = \dfra
c{1999-3x}{2}$.

### Evaluating the sums

**Even $x$** ($x = 0,2,\dots,664$, sum of $x$'s $= 2(0+1+\cdots+332) = 332\cdot3
33 = 110556$):
$$\frac{1}{2}\sum (1998-3x) = \frac{1}{2}\bigl(333\cdot1998 - 3\cdot110556\bigr)
 = \frac{1}{2}(665334 - 331668) = 166833.$$

**Odd $x$** ($x = 1,3,\dots,665$, sum of $x$'s $= 1+3+\cdots+665 = 333^2 = 11088
9$):
$$\frac{1}{2}\sum (1999-3x) = \frac{1}{2}\bigl(333\cdot1999 - 3\cdot110889\bigr)
 = \frac{1}{2}(665667 - 332667) = 166500.$$

### Final result

$$166833 + 166500 = \boxed{333333}.$$

This agrees with the classical formula $p(n,3) = \left\lfloor\dfrac{n^2+3}{12}\r
ight\rfloor$, since $\left\lfloor\dfrac{2000^2+3}{12}\right\rfloor = \left\lfloo
r\dfrac{4000003}{12}\right\rfloor = 333333$.
