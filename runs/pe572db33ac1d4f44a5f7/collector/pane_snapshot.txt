## Solution

**Setting up coordinates.** Place $B = (0,0)$, $C = (14,0)$. From $AB = 13$, $AC
 = 15$:
$$x^2 + y^2 = 169, \quad (x-14)^2 + y^2 = 225 \implies x = 5,\; y = 12.$$
So $A = (5, 12)$.

**Contact triangle.** With $s = 21$: $BD = BF = 6$, $CD = CE = 8$, $AE = AF = 7$
. Thus:
$$D = (6, 0), \quad E = C + \tfrac{8}{15}(A-C) = \left(\tfrac{46}{5}, \tfrac{32}
{5}\right), \quad F = A + \tfrac{7}{13}(B-A) = \left(\tfrac{30}{13}, \tfrac{72}{
13}\right).$$

**Circumcircle of $ABC$:** $x^2 + y^2 - 14x - \tfrac{33}{4}y = 0$, center $(7, \
tfrac{33}{8})$, radius $\tfrac{65}{8}$.

**Circumcircle of $AEF$:** Solving $x^2+y^2+Dx+Ey+F=0$ through $A, E, F$ yields:
$$x^2 + y^2 - 11x - 16y + 78 = 0.$$

**Finding $X$.** The radical axis (common chord $AX$) is obtained by subtracting
 the two circle equations:
$$-3x + \tfrac{31}{4}y - 78 = 0 \implies 12x - 31y + 312 = 0.$$

Parametrize from $A = (5,12)$ along direction $(31, 12)$: $(x,y) = (5+31t,\; 12+
12t)$. Substituting into the circumcircle of $ABC$:
$$1105t^2 + 65t = 0 \implies t\left(17t + 1\right) = 0.$$
The root $t = 0$ gives $A$; the root $t = -\tfrac{1}{17}$ gives:
$$X = \left(\frac{54}{17},\; \frac{192}{17}\right).$$

**Midpoint $M$ of arc $BC$ not containing $A$.** This lies on the perpendicular
bisector $x = 7$, on the far side from $A$:
$$M = \left(7,\; \tfrac{33}{8} - \tfrac{65}{8}\right) = (7, -4).$$

**Collinearity check.** The line through $M(7,-4)$ and $D(6,0)$ has direction $(
-1, 4)$. At parameter $s = \tfrac{65}{17}$: $(7 - \tfrac{65}{17}, -4 + \tfrac{26
0}{17}) = (\tfrac{54}{17}, \tfrac{192}{17}) = X$. ✓ So $X, M, D$ are collinear,
confirming the configuration.

**Computing the ratio.**
$$AM = \sqrt{(7-5)^2 + (-4-12)^2} = \sqrt{4 + 256} = \sqrt{260} = 2\sqrt{65}.$$
$$AX = \frac{1}{17}\sqrt{31^2 + 12^2} = \frac{\sqrt{961+144}}{17} = \frac{\sqrt{
1105}}{17} = \frac{\sqrt{65 \cdot 17}}{17} = \frac{\sqrt{65}}{\sqrt{17}}.$$
$$\frac{AM}{AX} = \frac{2\sqrt{65}}{\sqrt{65}/\sqrt{17}} = 2\sqrt{17}.$$

### $\dfrac{AM}{AX} = 2\sqrt{17}$

### PROOF COMPLETE
