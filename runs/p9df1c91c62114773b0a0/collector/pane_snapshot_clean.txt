## Solution

Let me model this as a Markov chain where the state is the current streak length
 of identical outcomes.

**States:** Let $E_k$ = expected number of additional cycles needed when the cur
rent streak of identical outcomes has length $k$ (for $k = 0, 1, 2$). When the s
treak reaches length 3, the test terminates (expected additional = 0).

**Transition structure:** From a streak of length $k < 3$, the next cycle either
:
- matches the current outcome (probability $1/2$), extending the streak to $k+1$
, or
- differs (probability $1/2$), resetting the streak to length 1 (the new outcome
 starts a fresh streak of 1).

**Equations:**

Starting state (no prior outcome):
$$E_0 = 1 + E_1$$
(One cycle is performed, producing some outcome and establishing a streak of len
gth 1.)

From streak length 1:
$$E_1 = 1 + \tfrac{1}{2}E_2 + \tfrac{1}{2}E_1$$

From streak length 2:
$$E_2 = 1 + \tfrac{1}{2}\cdot 0 + \tfrac{1}{2}E_1 = 1 + \tfrac{1}{2}E_1$$

**Solving:**

From the $E_1$ equation:
$$E_1 - \tfrac{1}{2}E_1 = 1 + \tfrac{1}{2}E_2 \implies \tfrac{1}{2}E_1 = 1 + \tf
rac{1}{2}E_2 \implies E_1 = 2 + E_2$$

Substituting $E_2 = 1 + \tfrac{1}{2}E_1$:
$$E_1 = 2 + 1 + \tfrac{1}{2}E_1 \implies \tfrac{1}{2}E_1 = 3 \implies E_1 = 6$$

Then:
$$E_2 = 1 + \tfrac{1}{2}(6) = 4$$
$$E_0 = 1 + 6 = 7$$

cles is 3 (e.g., PPP or FFF), with probability $2 \cdot (1/2)^3 = 1/4$. The expe
cted value of 7 is consistent with the geometric-like tail of longer sequences.
One can also confirm by computing $\sum_{n\geq 3} n \cdot P(\text{terminate exac

**Answer:** The expected value of the total number of cycles performed until the
