Yes, it follows that $\{P_n(x)\}$ converges uniformly to $1$.

**Proof.** Let $f_n(x) = \ln(P_n(x))$. By hypothesis $f_n \to 0$ uniformly, so
$$M_n := \sup_x |f_n(x)| \to 0 \quad \text{as } n\to\infty.$$
(Here $P_n(x)>0$ is implicit, since $\ln(P_n(x))$ is defined.)

Since $M_n \to 0$, there exists $N$ such that for all $n \ge N$, $M_n \le 1$, i.
e. $|f_n(x)| \le 1$ for all $x$.

For $|t| \le 1$, by the Mean Value Theorem applied to $e^t$,
$$|e^t - 1| = e^{c}|t| \quad \text{for some } c \text{ between } 0 \text{ and }
t.$$
Since $|c| \le |t| \le 1$, we have $e^c \le e$, hence
$$|e^t - 1| \le e\,|t|, \qquad |t|\le 1.$$

Now for $n \ge N$ and all $x$,
$$|P_n(x) - 1| = |e^{f_n(x)} - 1| \le e\,|f_n(x)| \le e\, M_n.$$
Therefore
$$\sup_x |P_n(x) - 1| \le e\, M_n \to 0 \quad \text{as } n\to\infty.$$

Thus $P_n \to 1$ uniformly. $\blacksquare$

The key point is that the exponential function is Lipschitz on every bounded int
erval (equivalently, uniformly continuous on bounded sets), so uniform convergen
ce of $f_n$ to $0$ is preserved under composition with $\exp$.
