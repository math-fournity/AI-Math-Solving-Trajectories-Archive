## Proof

**Setup.** We have $x = \log_\gamma \alpha$ with $0 \le x < \hat{x}$. Define $Q
:= Q_p(y) = \prod_{q_i \le y} q_i^{e_i}$. Since $Q \mid (p-1)$, we decompose:

$$x = a \cdot Q + b, \qquad 0 \le b < Q,\quad 0 \le a < \lceil \hat{x}/Q \rceil.
$$

The algorithm finds $b$ first (Step 1), then $a$ (Step 2), and outputs $x = b +
aQ$.

---

**Step 1: Compute $b = x \bmod Q$ via Pohlig–Hellman.**

Since $Q = \prod_{q_i \le y} q_i^{e_i}$ with the $q_i^{e_i}$ pairwise coprime, i
t suffices to find $b \bmod q_i^{e_i}$ for each $q_i \le y$, then apply CRT.

Fix a prime power $q_i^{e_i}$ with $q_i \le y$. Set $m_i = (p-1)/q_i^{e_i}$. Com
pute:
$$\alpha_i = \alpha^{m_i}, \qquad \gamma_i = \gamma^{m_i}.$$
Then $\gamma_i$ has order $q_i^{e_i}$, and $\alpha_i = \gamma_i^{x \bmod q_i^{e_
i}}$. Since $q_i^{e_i} \mid Q$, we have $x \bmod q_i^{e_i} = b \bmod q_i^{e_i}$,
 so $\alpha_i = \gamma_i^{d}$ where $d = b \bmod q_i^{e_i}$.

We find $d$ digit-by-digit in base $q_i$. Write $d = d_0 + d_1 q_i + \cdots + d_
{e_i-1} q_i^{e_i-1}$ with $0 \le d_j < q_i$. Set $g = \gamma_i^{q_i^{e_i-1}}$, w
hich has order $q_i$.

- **Digit $d_0$:** Compute $\alpha_i^{q_i^{e_i-1}} = g^{d_0}$. Find $d_0$ by BSG
S in the subgroup $\langle g \rangle$ of order $q_i$, costing $O(q_i^{1/2})$ gro
up operations.
- **Digit $d_j$** ($j = 1, \ldots, e_i - 1$): Update $\alpha_i \leftarrow \alpha
_i \cdot \gamma_i^{-d_{j-1} q_i^{j-1}}$, then raise to $q_i^{e_i-1-j}$ and solve
 $\alpha_i^{q_i^{e_i-1-j}} = g^{d_j}$ by BSGS, costing $O(q_i^{1/2})$.

Total cost for this prime power: $O(e_i \cdot q_i^{1/2})$ group operations.

**Cost of Step 1.** The total across all $q_i \le y$ is:
$$\sum_{q_i \le y} O(e_i \cdot q_i^{1/2}) \text{ group ops.}$$

We bound this sum. Let $r' $ be the number of distinct prime factors of $p-1$ th
at are $\le y$. Since the product of $r'$ distinct primes (each $\ge 2$) divides
 $p-1$, we have $2^{r'} \le p-1$, so $r' \le \log_2 p$. For each such prime, $e_
i \le \log_{q_i}(p-1) \le \log_2 p$ and $q_i^{1/2} \le y^{1/2}$. Therefore:

$$\sum_{q_i \le y} e_i \cdot q_i^{1/2} \le r' \cdot \log_2(p) \cdot y^{1/2} \le
(\log_2 p)^2 \cdot y^{1/2} = y^{1/2} \cdot \operatorname{len}(p)^{O(1)}.$$

The CRT combination costs $O(r' \cdot \operatorname{len}(p)^2)$, which is neglig
ible. Each group operation (exponentiation, multiplication) costs $\operatorname
{len}(p)^{O(1)}$. Thus Step 1 runs in time $y^{1/2} \cdot \operatorname{len}(p)^
{O(1)}$.

---

**Step 2: Compute $a$ via Baby-step Giant-step.**

Set $\beta = \gamma^Q$ (order $(p-1)/Q$) and $\alpha' = \alpha \cdot \gamma^{-b}
 = \beta^a$. We know $0 \le a < \lceil \hat{x}/Q \rceil$. Let $M = \lceil (\hat{
x}/Q)^{1/2} \rceil$ and write $a = iM + j$ with $0 \le j < M$, $0 \le i \le M$.

- **Baby steps:** Compute and hash $\beta^j$ for $j = 0, 1, \ldots, M-1$. Cost:
$O(M)$ group ops.
- **Giant steps:** Compute $\alpha' \cdot (\beta^{-M})^i$ for $i = 0, 1, \ldots,
 M$ and look up in the hash table. A match gives $a = iM + j$. Cost: $O(M)$ grou
p ops.

Total: $O(M) = O((\hat{x}/Q)^{1/2})$ group operations, i.e., time $(\hat{x}/Q_p(
y))^{1/2} \cdot \operatorname{len}(p)^{O(1)}$.

---

**Step 3: Output.** Return $x = b + a \cdot Q_p(y)$.

**Correctness.** Step 1 correctly finds $b = x \bmod Q_p(y)$ by Pohlig–Hellman (
each $b \bmod q_i^{e_i}$ is found correctly, and CRT recovers $b \bmod Q_p(y)$).
 Step 2 correctly finds $a$ since $\alpha' = \beta^a$ and BSGS exhaustively cove
rs all $a < \lceil \hat{x}/Q \rceil$. Since $x = aQ + b$ with $0 \le x < \hat{x}
$, the decomposition is unique, so $x = b + aQ$ is the correct discrete logarith
m.

**Total time.**

$$\underbrace{y^{1/2} \cdot \operatorname{len}(p)^{O(1)}}_{\text{Step 1}} + \und
erbrace{\left(\frac{\hat{x}}{Q_p(y)}\right)^{1/2} \cdot \operatorname{len}(p)^{O
(1)}}_{\text{Step 2}} = \left(y^{1/2} + \left(\frac{\hat{x}}{Q_p(y)}\right)^{1/2
}\right) \cdot \operatorname{len}(p)^{O(1)}.$$
