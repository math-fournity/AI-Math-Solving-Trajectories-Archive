## Proof

**Yes**, such a model exists. The **Ordered Mostowski Model** (also called the M
ostowski linearly ordered model) provides the construction.

### Setup of the Ordered Mostowski Model

We work in ZFA + AC (Zermelo-Fraenkel set theory with Atoms plus the Axiom of Ch
oice) as the ground theory. Let $A$ be a countably infinite set of atoms. Fix a
linear order $<$ on $A$ isomorphic to $(\mathbb{Q}, <)$, the rational numbers wi
th their usual order.

Define the permutation model as follows:

- **Group:** $G = \operatorname{Aut}(A, <)$, the group of all order automorphism
s of $(A, <)$.
- **Normal filter:** Generated by the stabilizers of finite subsets of $A$. That
 is, for each finite $E \subseteq A$, the subgroup $\operatorname{fix}(E) = \{\p
i \in G : \pi(a) = a \text{ for all } a \in E\}$ is in the filter, and the filte
r is the smallest normal filter containing all such subgroups.
- **Model:** $\mathcal{M}$ is the class of **hereditarily symmetric** sets. A se
t $x$ is *symmetric* if there exists a finite $E \subseteq A$ (called a *support
* of $x$) such that every $\pi \in \operatorname{fix}(E)$ fixes $x$, i.e., $\pi(
x) = x$. A set is *hereditarily symmetric* if it is symmetric and every element
of its transitive closure is symmetric.

### Claim 1: $A$ can be linearly ordered in $\mathcal{M}$.

The order $<$ on $A$ is fixed by every element of $G = \operatorname{Aut}(A, <)$
 by the very definition of $G$. Therefore $<$ has **empty support** — every orde
r automorphism preserves $<$. Hence $<$ is symmetric. Its elements are ordered p
airs of atoms, each of which is symmetric (atoms have empty support). Therefore
$<$ is hereditarily symmetric, so $< \in \mathcal{M}$.

Since $<$ is a linear order on $A$ (as $(A, <) \cong (\mathbb{Q}, <)$), the set
$A$ **can be linearly ordered** in $\mathcal{M}$.

### Claim 2: $A$ cannot be well-ordered in $\mathcal{M}$.

Suppose for contradiction that there exists a well-order $\preceq$ of $A$ with $
\preceq \in \mathcal{M}$. Then $\preceq$ is symmetric, so it has a finite suppor
t $E \subseteq A$. This means: for every $\pi \in \operatorname{fix}(E)$, $\pi(\
preceq) = \preceq$, i.e., for all $a, b \in A$,
$$a \preceq b \iff \pi(a) \preceq \pi(b).$$

Since $A$ is infinite and $E$ is finite, $A \setminus E$ is infinite. Pick two d
istinct atoms $a, b \in A \setminus E$.

**Constructing the automorphism:** The structure $(A \setminus E, <\,)$ is a cou
ntable dense linear order without endpoints (removing finitely many points from
$\mathbb{Q}$ preserves density and the lack of endpoints, and $A \setminus E$ re
mains countably infinite). By Cantor's back-and-forth theorem, $(A \setminus E,
<)$ is isomorphic to $(\mathbb{Q}, <)$. Moreover, $(\mathbb{Q}, <)$ is **homogen
eous**: for any two points $p, q$, there exists an order automorphism of $(\math
bb{Q}, <)$ mapping $p$ to $q$. This homogeneity transfers to $(A \setminus E, <)
$ via the isomorphism.

Concretely, using the back-and-forth method: start with the finite partial isomo
rphism $\{a \mapsto b\}$ on $(A \setminus E, <)$. At each stage, extend to cover
 the next uncovered element on the "forth" side (mapping it to an element with t
he same order relationship to previously mapped elements) and the next uncovered
 element on the "back" side. Since $(A \setminus E, <)$ is a countable DLO witho
ut endpoints, this process never gets stuck and produces a full order automorphi
sm $\sigma$ of $(A \setminus E, <)$ with $\sigma(a) = b$.

Extend $\sigma$ to an automorphism $\pi$ of $(A, <)$ by setting $\pi|_E = \opera
torname{id}_E$ and $\pi|_{A \setminus E} = \sigma$. Then:
- $\pi \in G = \operatorname{Aut}(A, <)$ (it preserves $<$ on all of $A$),
- $\pi \in \operatorname{fix}(E)$ (it fixes $E$ pointwise),
- $\pi(a) = b$ with $a \neq b$.

**Deriving the contradiction:** Since $\pi \in \operatorname{fix}(E)$ and $E$ su
pports $\preceq$:
$$a \preceq b \iff \pi(a) \preceq \pi(b) \iff b \preceq a.$$

But $a \neq b$ and $\preceq$ is a **linear** order, so exactly one of $a \preceq
 b$ or $b \preceq a$ holds (with $a \neq b$). The equivalence $a \preceq b \iff
b \preceq a$ forces both or neither, contradicting linearity (and antisymmetry).

Therefore, **no well-order of $A$ exists in $\mathcal{M}$**.

### Conclusion

In the Ordered Mostowski Model $\mathcal{M}$:
1. $A$ **can be linearly ordered** — the order $< \cong (\mathbb{Q}, <)$ is in $
\mathcal{M}$ (Claim 1).
2. $A$ **cannot be well-ordered** — any putative well-order would require finite
 support, but order automorphisms fixing any finite set can move any atom to any
 other, yielding a contradiction (Claim 2).

Thus, **yes**, it is possible to construct a model in Fraenkel-Mostowski set the
ory where the set of atoms can be linearly ordered but not well-ordered. The Ord
ered Mostowski Model is an explicit witness.
