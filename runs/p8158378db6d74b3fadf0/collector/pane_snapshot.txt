## Proof

We want to compute $\mathbb{E}[\sin(\alpha W(t))]$, where $W(t)$ is a standard B
rownian motion.

**Key fact.** For a standard Brownian motion, $W(t) \sim \mathcal{N}(0, t)$. Hen
ce $\alpha W(t) \sim \mathcal{N}(0, \alpha^2 t)$, a Gaussian random variable wit
h mean $0$.

**Symmetry argument.** The distribution of $\alpha W(t)$ is symmetric about $0$
(it is a centered Gaussian). Therefore $\alpha W(t)$ and $-\alpha W(t)$ have the
 same distribution. Since $\sin$ is an odd function,

$$\sin(\alpha W(t)) \stackrel{d}{=} \sin(-\alpha W(t)) = -\sin(\alpha W(t)).$$

If a random variable $X$ satisfies $X \stackrel{d}{=} -X$ and $\mathbb{E}[|X|] <
 \infty$, then $\mathbb{E}[X] = 0$. The integrability holds because $|\sin(\alph
a W(t))| \le 1$ is bounded. Thus

$$\mathbb{E}[\sin(\alpha W(t))] = 0.$$

**Verification via the characteristic function (optional consistency check).** S
ince $\alpha W(t) \sim \mathcal{N}(0, \alpha^2 t)$,

$$\mathbb{E}\!\left[e^{i\alpha W(t)}\right] = e^{-\alpha^2 t/2}.$$

Taking imaginary parts of both sides:

$$\mathbb{E}[\sin(\alpha W(t))] = \operatorname{Im}\!\left(e^{-\alpha^2 t/2}\rig
ht) = 0,$$

since $e^{-\alpha^2 t/2}$ is purely real. This confirms the result.

**Remark on the martingale condition.** The given condition that $N(t) = e^{\bet
a t}\cos(\alpha W(t))$ is a martingale is consistent with $\mathbb{E}[\cos(\alph
a W(t))] = e^{-\alpha^2 t/2}$ (the real part of the characteristic function), wh
ich fixes the value of $\beta$. Note that this condition concerns only the *cosi
ne* (real, even) part; the *sine* (imaginary, odd) part vanishes identically in
expectation by symmetry, independently of the value of $\beta$. Thus the marting
ale hypothesis, while providing context, is not actually needed to determine the
 answer.

### Answer

$$\boxed{\mathbb{E}[\sin(\alpha W(t))] = 0}$$
