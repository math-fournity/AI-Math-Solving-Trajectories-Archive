## Proof

Let $z_n = \tfrac{1}{2} + i\gamma_n$ (or more generally, $\beta_n + i\gamma_n$ w
ith $0 < \beta_n < 1$) denote the non-trivial zeros of the Riemann zeta function
 $\zeta(s)$ with positive imaginary part, ordered so that
$$0 < \gamma_1 \le \gamma_2 \le \gamma_3 \le \cdots.$$

We use the **Riemann–von Mangoldt counting formula**, which states that the numb
er $N(T)$ of non-trivial zeros (counted with multiplicity) with $0 < \Im(\rho) \
le T$ satisfies
$$N(T) = \frac{T}{2\pi}\log\!\left(\frac{T}{2\pi}\right) - \frac{T}{2\pi} + O(\l
og T), \qquad T \to \infty.$$

In particular, $N(T) \to \infty$ as $T \to \infty$, which guarantees infinitely
many non-trivial zeros with arbitrarily large imaginary part, so the sequence $\
{\gamma_n\}$ is well-defined and infinite.

**Claim:** $\displaystyle\lim_{n\to\infty} \gamma_n = +\infty.$

**Proof of claim.** Suppose for contradiction that $\{\gamma_n\}$ is bounded, i.
e., there exists $M > 0$ such that $\gamma_n \le M$ for all $n$. Then every non-
trivial zero with positive imaginary part satisfies $0 < \Im(\rho) \le M$, so $N
(M) = \infty$. But $N(M)$ is a finite number (it counts zeros in a bounded regio
n, and $\zeta(s)$ has only finitely many zeros in any bounded region since it is
 meromorphic with a single pole at $s=1$). This is a contradiction.

Therefore $\{\gamma_n\}$ is unbounded. Since the sequence is non-decreasing by c
onstruction, an unbounded non-decreasing sequence diverges to $+\infty$:
$$\lim_{n \to \infty} \gamma_n = \lim_{n \to \infty} \Im(z_n) = +\infty.$$

**Conclusion.** The limit of $\Im(z_n)$ as $n \to \infty$ is $\boxed{+\infty}$.
