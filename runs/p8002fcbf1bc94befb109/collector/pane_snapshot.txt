## 证明

设 $A_n = \bigcap_{i=1}^{\lfloor \log_2 n \rfloor} H_{n+i}$，即第 $n+1, n+2, \ld
ots, n+\lfloor \log_2 n\rfloor$ 次抛硬币全部为正面的随机事件。我们将证明

$$\mathbb{P}(A_n \text{ 无穷次发生 (i.o.)}) = 1.$$

**第一步：计算 $\mathbb{P}(A_n)$ 并证明 $\sum_n \mathbb{P}(A_n) = \infty$。**

由于抛硬币是独立且公平的，$\mathbb{P}(A_n) = 2^{-\lfloor \log_2 n \rfloor}$。按
$k = \lfloor \log_2 n \rfloor$ 进行分组：对于每个 $k \ge 0$，恰好有 $2^k$ 个 $n$
 的值（即 $n = 2^k, \ldots, 2^{k+1}-1$）满足 $\lfloor \log_2 n \rfloor = k$，每
个值的概率为 $2^{-k}$。因此

$$\sum_{n=1}^{\infty} \mathbb{P}(A_n) = \sum_{k=0}^{\infty} 2^k \cdot 2^{-k} = \
sum_{k=0}^{\infty} 1 = \infty.$$

**第二步：这些事件并非独立的——提取一个具有不相交区间的子序列。**

$A_n$ 的区间为 $[n+1,\; n+\lfloor\log_2 n\rfloor]$。对于不同的 $n$，这些区间可能
会重叠，因此 $A_n$ 不是独立的，我们不能直接应用 Borel–Cantelli 第二引理。相反，
我们构建一个子序列 $\{n_k\}$，使其区间两两不相交。

递归设置 $n_1 = 2$ 且 $n_{k+1} = n_k + \lceil \log_2 n_k\rceil + 1$。那么 $A_{n_
k}$ 的区间结束于

$$n_k + \lfloor \log_2 n_k\rfloor \le n_k + \lceil \log_2 n_k\rceil < n_k + \lce
il \log_2 n_k\rceil + 1 = n_{k+1},$$

且 $A_{n_{k+1}}$ 的区间开始于 $n_{k+1}+1$。因此，连续的（从而所有）区间都是不相
交的。由于硬币抛掷是独立的，事件 $\{A_{n_k}\}_{k\ge 1}$ **是独立的**。

**第三步：证明 $\sum_k \mathbb{P}(A_{n_k}) = \infty$。**

由于 $2^{\lfloor \log_2 n_k\rfloor} \le n_k$，我们有 $\mathbb{P}(A_{n_k}) = 2^{-
\lfloor \log_2 n_k\rfloor} \ge 1/n_k$，因此只需证明 $\sum_k 1/n_k = \infty$ 即可
。

由递归关系得，$n_{k+1} - n_k = \lceil \log_2 n_k\rceil + 1 \le \log_2 n_k + 2$，
因此

$$n_k \le 2 + \sum_{j=1}^{k-1}(\log_2 n_j + 2) \le 2k + (k-1)\log_2 n_k.$$

对于 $x = 4k\log_2 k$ 且 $k$ 足够大的情况，函数 $g(x) = x - k\log_2 x$ 满足 $g(4
k\log_2 k) = 3k\log_2 k - k\log_2\log_2 k - 2k > 2k$，而不等式 $n_k - k\log_2 n_
k \le 2k$ 意味着 $n_k < 4k\log_2 k$（对于所有足够大的 $k$）。因此 $n_k = O(k\log
 k)$，且

$$\sum_{k=K}^{\infty} \frac{1}{n_k} \ge \sum_{k=K}^{\infty} \frac{1}{4k\log_2 k}
 = \frac{\ln 2}{4}\sum_{k=K}^{\infty}\frac{1}{k\ln k} = \infty.$$

因此 $\sum_k \mathbb{P}(A_{n_k}) \ge \sum_k 1/n_k = \infty$。

**第四步：应用 Borel–Cantelli 第二引理并得出结论。**

事件 $\{A_{n_k}\}$ 是独立的，且 $\sum_k \mathbb{P}(A_{n_k}) = \infty$。根据 Bore
l–Cantelli 第二引理：

$$\mathbb{P}(A_{n_k} \text{ 无穷次发生 (i.o.)}) = 1.$$

由于 $\{A_{n_k} \text{ 无穷次发生 (i.o.)}\} \subseteq \{A_n \text{ 无穷次发生 (i
.o.)}\}$（无限多个子序列索引意味着无限多个总索引），我们得到

$$\mathbb{P}(A_n \text{ 无穷次发生 (i.o.)}) \ge 1.$$

因此

$$\boxed{\mathbb{P}\!\left(\bigcap_{i=1}^{\lfloor \log_2 n\rfloor} H_{n+i} \text
{ 无穷次发生 (i.o.)}\right) = 1.}$$
