## Proof

**Yes**, such a convex open set $U$ always exists.

**Setup.** Let $X$ be a normed linear space, $C \subseteq X$ compact and convex,
 and $V \subseteq X$ open with $C \subseteq V$.

**Step 1: The distance from $C$ to $X \setminus V$ is positive.**

Since $V$ is open, $X \setminus V$ is closed. Since $C \subseteq V$, we have $C
\cap (X \setminus V) = \emptyset$. Define

$$d := \operatorname{dist}(C,\, X \setminus V) = \inf\{\,\|x - y\| : x \in C,\;
y \in X \setminus V\,\}.$$

The function $x \mapsto \operatorname{dist}(x, X\setminus V)$ is continuous (in
fact 1-Lipschitz), and $C$ is compact, so it attains its minimum at some $x_0 \i
n C$. Since $x_0 \in V$ and $V$ is open, $\operatorname{dist}(x_0, X\setminus V)
 > 0$. Hence

$$d = \operatorname{dist}(x_0, X \setminus V) > 0.$$

**Step 2: Construct $U$ as a Minkowski sum.**

Let $B(0, r) = \{z \in X : \|z\| < r\}$ denote the open ball of radius $r$ cente
red at the origin, and set

$$U := C + B\!\left(0, \tfrac{d}{2}\right) = \{\,x + z : x \in C,\; \|z\| < \tfr
ac{d}{2}\,\} = \bigcup_{x \in C} B\!\left(x, \tfrac{d}{2}\right).$$

**Step 3: Verify the three required properties.**

*$U$ is open.* It is a union of open balls $B(x, d/2)$, hence open.

*$C \subseteq U$.* For any $x \in C$, we have $x = x + 0 \in U$ since $\|0\| = 0
 < d/2$.

*$U \subseteq V$.* Take any $w \in U$. Then $w = x + z$ for some $x \in C$ with
$\|z\| < d/2$, so $\|w - x\| = \|z\| < d/2 < d$. Thus $\operatorname{dist}(w, C)
 \le \|w - x\| < d$. If $w \notin V$, then $w \in X \setminus V$ and $\operatorn
ame{dist}(w, C) \ge d$, a contradiction. Hence $w \in V$.

*$U$ is convex.* Both $C$ and $B(0, d/2)$ are convex. The Minkowski sum of two c
onvex sets is convex: if $w_1 = x_1 + z_1$ and $w_2 = x_2 + z_2$ with $x_i \in C
$, $z_i \in B(0, d/2)$, and $\lambda \in [0,1]$, then

$$\lambda w_1 + (1-\lambda)w_2 = \underbrace{(\lambda x_1 + (1-\lambda)x_2)}_{\i
n\, C} + \underbrace{(\lambda z_1 + (1-\lambda) z_2)}_{\in\, B(0,d/2)},$$

since $\|\lambda z_1 + (1-\lambda)z_2\| \le \lambda\|z_1\| + (1-\lambda)\|z_2\|
< d/2$. Hence $\lambda w_1 + (1-\lambda)w_2 \in U$.

**Conclusion.** $U = C + B(0, d/2)$ is a convex open set satisfying $C \subseteq
 U \subseteq V$. Therefore, for every open set $V$ containing a compact convex s
et $C$ in a normed linear space, there exists a convex open set $U$ with $C \sub
seteq U \subseteq V$.
