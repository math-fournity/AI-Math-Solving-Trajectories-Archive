## Half-Derivative of $\ln x$

We use the **Riemann–Liouville fractional derivative** of order $\alpha \in (0,1
)$:

$$D^{\alpha} f(x) = \frac{1}{\Gamma(1-\alpha)}\frac{d}{dx}\int_0^x (x-t)^{-\alph
a} f(t)\,dt.$$

For $\alpha = \tfrac12$ and $f(t)=\ln t$, this gives

$$\frac{d^{1/2}}{dx^{1/2}}\ln x = \frac{1}{\Gamma(1/2)}\frac{d}{dx}\int_0^x (x-t
)^{-1/2}\ln t\,dt = \frac{1}{\sqrt\pi}\frac{d}{dx}\,I(x),$$

where $I(x)=\displaystyle\int_0^x (x-t)^{-1/2}\ln t\,dt$.

### Evaluating $I(x)$

Substitute $u = x-t$ (so $t = x-u$, $dt=-du$):

$$I(x) = \int_0^x u^{-1/2}\ln(x-u)\,du.$$

Now set $u = xv$, $du = x\,dv$:

$$I(x) = \int_0^1 (xv)^{-1/2}\ln\!\big(x(1-v)\big)\,x\,dv = x^{1/2}\int_0^1 v^{-
1/2}\big[\ln x + \ln(1-v)\big]\,dv.$$

Split the integral:

$$I(x) = x^{1/2}\!\left[\ln x\!\int_0^1 v^{-1/2}\,dv + \int_0^1 v^{-1/2}\ln(1-v)
\,dv\right].$$

**First piece:** $\displaystyle\int_0^1 v^{-1/2}\,dv = 2$.

**Second piece:** Use the Beta-function identity $\displaystyle\int_0^1 v^{a-1}(
1-v)^{b-1}\,dv = B(a,b)=\frac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}$. Differentiating
 with respect to $b$:

$$\int_0^1 v^{a-1}(1-v)^{b-1}\ln(1-v)\,dv = B(a,b)\big[\psi(b)-\psi(a+b)\big].$$

At $a=\tfrac12,\, b=1$:

$$B\!\left(\tfrac12,1\right) = \frac{\Gamma(1/2)\Gamma(1)}{\Gamma(3/2)} = \frac{
\sqrt\pi\cdot 1}{\sqrt\pi/2}=2,$$

$$\psi(1)=-\gamma,\qquad \psi\!\left(\tfrac32\right)=\psi\!\left(\tfrac12\right)
+2 = -\gamma - 2\ln 2 + 2.$$

Hence

$$\int_0^1 v^{-1/2}\ln(1-v)\,dv = 2\big[(-\gamma)-(-\gamma-2\ln 2+2)\big] = 2(2\
ln 2 - 2) = 4\ln 2 - 4.$$

Therefore

$$I(x) = x^{1/2}\big[2\ln x + 4\ln 2 - 4\big].$$

### Differentiating

$$\frac{d}{dx}I(x) = \frac{d}{dx}\Big[x^{1/2}\big(2\ln x + 4\ln 2 - 4\big)\Big]$
$

$$= \tfrac12 x^{-1/2}\big(2\ln x + 4\ln 2 - 4\big) + x^{1/2}\cdot\frac{2}{x}$$

$$= x^{-1/2}\big(\ln x + 2\ln 2 - 2\big) + 2x^{-1/2}$$

$$= x^{-1/2}\big(\ln x + 2\ln 2\big) = x^{-1/2}\ln(4x).$$

### Final result

$$\boxed{\frac{d^{1/2}}{dx^{1/2}}\ln x = \frac{\ln(4x)}{\sqrt{\pi x}}}$$
