## Proof

**Setup.** Let α = ∠BAC, so ∠ABC = 90° − α. Set a = BC, b = AC, c = AB (hypotenu
se), with a = c sin α, b = c cos α. Let s = (a+b+c)/2 be the semi-perimeter.

**Tangent lengths.** The excircle opposite C touches side AB at N. The tangent l
engths from A and B to this excircle are:
- AN = s − b = (a − b + c)/2
- BN = s − a = (b − a + c)/2

(These follow from the standard excircle tangent length formulas: tangent from C
 to the C-excircle equals s, so CA + AN = s gives AN = s − b, and CB + BN = s gi
ves BN = s − a.)

**Coordinates.** Place C at the origin, A = (b, 0), B = (0, a). Since N lies on
AB with AN = (a − b + c)/2:

$$N = A + \frac{AN}{c}(B - A)$$

$$N_x = \frac{b(c - a + b)}{2c}, \qquad N_y = \frac{a(a - b + c)}{2c}$$

**Angle condition.** The angle ∠BNC is the angle between vectors **NB** = B − N
and **NC** = C − N. Computing:

- **Cross product** (z-component): **NB** × **NC** = a · N_x
- **Dot product**: **NB** · **NC** = |NC|² − a · N_y

Since ∠BNC = 45°, we have tan(45°) = 1, so:

$$a \cdot N_x = |NC|^2 - a \cdot N_y$$

$$a(N_x + N_y) = N_x^2 + N_y^2 \tag{1}$$

**Substitution.** Set c = 1 (WLOG), so a = sin α, b = cos α. Denote s₀ = sin α,
k = cos α. Then:

$$N_x = \frac{k(1 - s_0 + k)}{2}, \qquad N_y = \frac{s_0(s_0 - k + 1)}{2}$$

**Left side of (1):** a(N_x + N_y) = s₀ · [k(1 − s₀ + k) + s₀(s₀ − k + 1)] / 2

The bracket simplifies: k − ks₀ + k² + s₀² − ks₀ + s₀ = (k + s₀) + (k² + s₀²) −
2ks₀ = (k + s₀) + 1 − 2ks₀.

So LHS = s₀(k + s₀ + 1 − 2ks₀)/2.

**Right side of (1):** N_x² + N_y² = [k²(1 + k − s₀)² + s₀²(1 + s₀ − k)²] / 4.

Expanding using k² + s₀² = 1:
- (1 + k − s₀)² = 2(1 + k − s₀ − ks₀)
- (1 + s₀ − k)² = 2(1 + s₀ − k − ks₀)

So RHS = [k² · 2(1 + k − s₀ − ks₀) + s₀² · 2(1 + s₀ − k − ks₀)] / 4

= [2(k² + s₀²) + 2(k³ + s₀³) − 2ks₀(k² + s₀²) − 2ks₀(k² + s₀²)] / 4...

Let me consolidate. After expanding and collecting terms using k² + s₀² = 1, k³
+ s₀³ = (k + s₀)(1 − ks₀), and k²s₀ + ks₀² = ks₀(k + s₀):

$$\text{RHS} = \frac{2\big[1 + (k+s_0)(1 - 2ks_0) - ks_0\big]}{4} = \frac{1 + (k
+s_0)(1-2ks_0) - ks_0}{2}$$

**Equating LHS = RHS** and multiplying by 2:

$$s_0(k + s_0 + 1 - 2ks_0) = 1 + (k+s_0)(1 - 2ks_0) - ks_0$$

Expanding both sides:
- LHS = ks₀ + s₀² + s₀ − 2ks₀²
- RHS = 1 + k + s₀ − 2ks₀(k + s₀) − ks₀ = 1 + k + s₀ − 2k²s₀ − 2ks₀² − ks₀

Setting LHS − RHS = 0:

$$ks_0 + s_0^2 + s_0 - 2ks_0^2 - 1 - k - s_0 + 2k^2 s_0 + 2ks_0^2 + ks_0 = 0$$

$$s_0^2 - 1 - k + 2k^2 s_0 + 2ks_0 = 0$$

Substituting s₀² = 1 − k²:

$$1 - k^2 - 1 - k + 2ks_0(k + 1) = 0$$

$$-k^2 - k + 2ks_0(k+1) = 0$$

$$-k(k+1) + 2ks_0(k+1) = 0$$

$$k(k+1)(2s_0 - 1) = 0$$

**Solving.** Since the triangle is non-degenerate: k = cos α ≠ 0 (else ∠ABC = 0°

$$2\sin\alpha - 1 = 0 \implies \sin\alpha = \frac{1}{2} \implies \alpha = 30°$$
