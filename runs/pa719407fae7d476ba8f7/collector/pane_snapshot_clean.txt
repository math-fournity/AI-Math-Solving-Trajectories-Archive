## 证明

**设置。** 考虑乘积 $\prod_{n=1}^{1996}(1+n\,x^{3^n})$。展开时，每一项对应一个子
集 $S\subseteq\{1,\dots,1996\}$，得到 $\left(\prod_{n\in S}n\right)x^{\sum_{n\in
 S}3^n}$。

**关键观察 1：指数互不相同。** 由于每个指数 $\sum_{n\in S}3^n$ 都是 3 的不同次幂
之和，且 $3$ 进制表示是唯一的（数字仅为 $0$ 或 $1$），因此不同的子集会产生不同的
指数。因此 $m = 2^{1996}-1$，且每个 $a_j$ 都是单一子集 $S_j$ 的元素乘积。

**关键观察 2：按 $\sum 3^n$ 排序等于按 $\sum 2^n$ 排序。** 给定两个子集 $S,T$，
设 $n^*$ 为 $S\triangle T$ 中的最大元素。无论以 3 为底还是以 2 为底，较低位置的
总和都严格小于最高位数字（因为 $\sum_{i=1}^{n^*-1}3^i = \frac{3^{n^*}-1}{2}<3^{n
^*}$ 且 $\sum_{i=1}^{n^*-1}2^i = 2^{n^*}-2<2^{n^*}$）。因此，在两种底数下，比较
结果均由 $n^*$ 决定，这意味着排序顺序是相同的。

**识别第 $j$ 个子集。** 非空子集上 $\sum_{n\in S}2^n$ 的值恰好是 $2, 4, 6, 8, \d
ots, 2^{1997}-2$ —— 即从 $2$ 到 $2^{1997}-2$ 的所有偶数正整数。第 $j$ 小的值是 $
2j$。现在 $n\in S_j$ 当且仅当 $2j$ 的第 $n$ 位是 $1$，这等同于 $j$ 的第 $(n-1)$
位是 $1$。因此：

$$S_j = \{i+1 : \text{$j$ 的第 $i$ 位是 } 1\}, \qquad a_j = \prod_{\substack{i:\
, \text{第 }i\text{ 位} \\ \text{of } j \text{ 是 } 1}} (i+1).$$

**计算 $j=1996$。** 将 $1996$ 转换为二进制：
$$1996 = 1024+512+256+128+64+8+4 = 2^{10}+2^9+2^8+2^7+2^6+2^3+2^2.$$
因此 $1996 = (11111001100)_2$，其置位位于位置 $2,3,6,7,8,9,10$。因此：

$$S_{1996} = \{3,\,4,\,7,\,8,\,9,\,10,\,11\}.$$

**计算系数：**
$$a_{1996} = 3\cdot4\cdot7\cdot8\cdot9\cdot10\cdot11 = 12\cdot7\cdot8\cdot9\cdot
10\cdot11 = 84\cdot8\cdot9\cdot10\cdot11 = 672\cdot9\cdot10\cdot11 = 6048\cdot10
\cdot11 = 60480\cdot11 = 665280.$$
