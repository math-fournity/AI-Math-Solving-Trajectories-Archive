## Solution

**Setup.** Place $A$ at the origin. Let $\vec{AB}=\mathbf{b}$, $\vec{AC}=\mathbf
{c}$, with $|\mathbf{b}|=17$, $|\mathbf{c}|=23$. Set $p=\mathbf{b}\cdot\mathbf{c
}$, so
$$BC^2 = |\mathbf{b}-\mathbf{c}|^2 = 289+529-2p = 818-2p.$$
The centroid is $G=\tfrac{1}{3}(\mathbf{b}+\mathbf{c})$.

**Circumcircle equation.** Since the circle passes through the origin, a point $
\mathbf{x}$ lies on it iff $|\mathbf{x}|^2=\mathbf{x}\cdot\mathbf{d}$ for some f
ixed $\mathbf{d}$ with $\mathbf{b}\cdot\mathbf{d}=289$, $\mathbf{c}\cdot\mathbf{
d}=529$.

**Finding $B_1$.** Since $BB_1\parallel AC$, write $B_1=\mathbf{b}+t\,\mathbf{c}
$. Substituting into the circle equation:
$$|\mathbf{b}+t\mathbf{c}|^2=(\mathbf{b}+t\mathbf{c})\cdot\mathbf{d}$$
$$289+2tp+529t^2=289+529t \implies t(2p+529t-529)=0.$$
The nonzero solution is $t=\frac{529-2p}{529}$, giving $B_1=\mathbf{b}+\frac{529
-2p}{529}\,\mathbf{c}$.

**Finding $C_1$.** Since $CC_1\parallel AB$, write $C_1=\mathbf{c}+s\,\mathbf{b}
$. Similarly:
$$529+2sp+289s^2=529+289s \implies s(2p+289s-289)=0,$$
so $s=\frac{289-2p}{289}$, giving $C_1=\mathbf{c}+\frac{289-2p}{289}\,\mathbf{b}
$.

**Collinearity condition.** $G\in B_1C_1$ means $G=(1-\lambda)B_1+\lambda C_1$ f
or some $\lambda$.

Comparing $\mathbf{b}$-coefficients:
$$\tfrac{1}{3}=(1-\lambda)+\lambda\cdot\tfrac{289-2p}{289}=1-\tfrac{2p\lambda}{2
89} \implies \lambda=\tfrac{289}{3p}.$$

Comparing $\mathbf{c}$-coefficients:
$$\tfrac{1}{3}=(1-\lambda)\cdot\tfrac{529-2p}{529}+\lambda.$$

Substituting $\lambda=\tfrac{289}{3p}$ and multiplying through by $3p\cdot 529$:
$$529p=(3p-289)(529-2p)+289\cdot 529.$$
Expanding: $(3p-289)(529-2p)=2165p-6p^2-289\cdot 529$, so
$$529p=2165p-6p^2-289\cdot 529+289\cdot 529=2165p-6p^2.$$
$$6p^2-1636p=0 \implies p(6p-1636)=0.$$

**Rejecting $p=0$.** If $p=0$, then $t=1$ and $s=1$, so $B_1=\mathbf{b}+\mathbf{
c}=C_1$; the "line" $B_1C_1$ degenerates to a point $\neq G$, so this case is in
valid.

Therefore $p=\frac{1636}{6}=\frac{818}{3}$, and
$$BC^2=818-2\cdot\tfrac{818}{3}=818-\tfrac{1636}{3}=\tfrac{818}{3}.$$

**Verification.** $\gcd(818,3)=1$ since $818=2\cdot 409$ and $409$ is prime. The
 triangle with sides $17,23,\sqrt{818/3}\approx 16.5$ satisfies the triangle ine
quality.

With $m=818$, $n=3$:
$$100m+n=81800+3=\boxed{81803}.$$
