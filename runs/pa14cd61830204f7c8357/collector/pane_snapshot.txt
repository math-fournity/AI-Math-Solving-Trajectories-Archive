## Proof

We are given a finite group $G$ of odd order $n$, an element $g$ lying in a real
 conjugacy class $C$ (so $C = C^{-1}$), and an element $h \in G$ satisfying
$$h^{-1} g h = g^{-1}.$$

### Step 1: $h^{-2} g h^{2} = g$, hence $h^{2} \in C_{G}(g)$

Conjugate both sides of $h^{-1} g h = g^{-1}$ by $h$. The left-hand side becomes
$$h^{-1}(h^{-1} g h)h = h^{-2} g h^{2}.$$
The right-hand side becomes
$$h^{-1} g^{-1} h = (h^{-1} g h)^{-1} = (g^{-1})^{-1} = g,$$
where we used that conjugation respects inversion: $(h^{-1}gh)^{-1} = h^{-1}g^{-
1}h$.

Equating both sides:
$$h^{-2} g h^{2} = g.$$

By definition, $C_{G}(g) = \{x \in G : x^{-1} g x = g\}$, the centralizer of $g$
 in $G$. The equation $h^{-2} g h^{2} = g$ says precisely that $h^{2}$ commutes
with $g$, i.e.
$$h^{2} \in C_{G}(g).$$

### Step 2: $|h|$ is odd, so $h \in C_{G}(g)$

Since $|G| = n$ is odd, by Lagrange's theorem the order of every element divides
 $n$, hence every element of $G$ has odd order. In particular $|h|$ is odd.

Let $m = |h|$. Since $\gcd(2, m) = 1$, the integer $2$ is invertible modulo $m$:
 there exists an integer $k$ with
$$2k \equiv 1 \pmod{m}.$$

Therefore
$$h = h^{1} = h^{2k \bmod m} = (h^{2})^{k}.$$

Now $C_{G}(g)$ is a subgroup of $G$ (it is closed under products and inverses, a
nd contains the identity). Since $h^{2} \in C_{G}(g)$ and $C_{G}(g)$ is a subgro
up, every power of $h^{2}$ also lies in $C_{G}(g)$:
$$(h^{2})^{k} \in C_{G}(g).$$

But $(h^{2})^{k} = h$, so
$$h \in C_{G}(g).$$

### Step 3: Conclude $h$ centralizes $g$

Since $h \in C_{G}(g)$, by definition $h$ commutes with $g$:
$$h^{-1} g h = g.$$

Combined with the original hypothesis $h^{-1} g h = g^{-1}$, this gives $g = g^{
-1}$, i.e. $g^{2} = e$. But $|g|$ divides $|G| = n$, which is odd, so $|g|$ is o
dd. The only element of odd order satisfying $g^{2} = e$ is $g = e$. Thus in fac
t $g = e$.

**Remark.** The conclusion $h \in C_{G}(g)$ together with $h^{-1}gh = g^{-1}$ fo
rces $g = g^{-1}$, hence $g = e$ (since $|g|$ is odd). This is consistent with t
he well-known fact that in a group of odd order, the only real conjugacy class i
s the trivial class $\{e\}$: a non-identity element cannot be conjugate to its o
wn inverse, because the conjugating element would have to both invert and centra
lize $g$, which is impossible for non-identity $g$ of odd order.

### Summary

- Conjugating $h^{-1}gh = g^{-1}$ by $h$ once more yields $h^{-2}gh^{2} = g$, so
 $h^{2} \in C_{G}(g)$.
- Since $|h|$ is odd, $2$ is invertible mod $|h|$, so $h = (h^{2})^{k}$ for some
 $k$. As $C_{G}(g)$ is a subgroup containing $h^{2}$, it contains $(h^{2})^{k} =
 h$. Hence $h \in C_{G}(g)$.
