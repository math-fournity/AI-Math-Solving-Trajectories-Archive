## Solution

We compute the Cauchy principal value of
$$I = \text{P.V.}\int_{-\infty}^{\infty} \frac{x}{(x^{2}+4)(x-1)}\,dx.$$

The integrand has a simple pole at $x=1$ on the real axis, so the principal valu
e is required.

### Step 1: Partial Fraction Decomposition

Write
$$\frac{x}{(x^{2}+4)(x-1)} = \frac{Ax+B}{x^{2}+4} + \frac{C}{x-1}.$$

Clearing denominators: $x = (Ax+B)(x-1) + C(x^{2}+4)$. Expanding and matching co
efficients:

| Power | Equation |
|-------|----------|
| $x^{2}$ | $A + C = 0$ |
| $x^{1}$ | $-A + B = 1$ |
| $x^{0}$ | $-B + 4C = 0$ |

Solving: $C = -A$, $B = 4C = -4A$, and $-A - 4A = 1 \Rightarrow A = -\tfrac{1}{5
}$. Hence $C = \tfrac{1}{5}$, $B = \tfrac{4}{5}$, giving

$$\frac{x}{(x^{2}+4)(x-1)} = \frac{1}{5}\cdot\frac{-x+4}{x^{2}+4} + \frac{1}{5}\
cdot\frac{1}{x-1}.$$

### Step 2: Antiderivative

$$F(x) = -\frac{1}{10}\ln(x^{2}+4) + \frac{2}{5}\arctan\!\frac{x}{2} + \frac{1}{
5}\ln|x-1|.$$

### Step 3: Principal Value Computation

$$\text{P.V.} = \lim_{R\to\infty}\lim_{\epsilon\to 0^{+}}\Big[F(R) - F(1+\epsilo
n) + F(1-\epsilon) - F(-R)\Big].$$

**Near the pole ($\epsilon \to 0^{+}$):** The only singular term is $\tfrac{1}{5
}\ln|x-1|$, which gives $\tfrac{1}{5}\ln\epsilon - \tfrac{1}{5}\ln\epsilon = 0$.
 The remaining terms ($\ln(x^{2}+4)$ and $\arctan(x/2)$) are continuous at $x=1$
, so $F(1-\epsilon)-F(1+\epsilon) \to 0$.

**At infinity ($R\to\infty$):**
$$F(R)-F(-R) = \frac{2}{5}\arctan\!\tfrac{R}{2} - \frac{2}{5}\arctan\!\tfrac{-R}
{2} + \frac{1}{5}\ln\frac{R-1}{R+1} = \frac{4}{5}\arctan\!\tfrac{R}{2} + \frac{1
}{5}\ln\frac{R-1}{R+1}.$$

As $R\to\infty$: $\arctan(R/2)\to \pi/2$ and $\ln\frac{R-1}{R+1}\to 0$. Therefor
e

$$\text{P.V.} = \frac{4}{5}\cdot\frac{\pi}{2} + 0 = \boxed{\dfrac{2\pi}{5}}.$$
