# Solution

**Claim:** The unique solution is $f(x) = x$.

## Step 1: Injectivity

Suppose $f(a) = f(b)$. For any $x$:
$$f(x^2 + f(a)) = a + f(x)^2, \quad f(x^2 + f(b)) = b + f(x)^2.$$
The left sides are equal, so $a = b$. Thus $f$ is **injective**.

## Step 2: Surjectivity and the key relation

Set $x = 0$: $f(f(y)) = y + f(0)^2$. Let $a = f(0)$, $c = a^2$. Then
$$f(f(y)) = y + a^2. \tag{1}$$
The map $f \circ f$ is surjective (onto $\mathbb{R}$), so $f$ is **surjective**.
 Hence $f$ is bijective, and from (1): $f^{-1}(t) = f(t) - a^2$.

## Step 3: Reduction to a Cauchy equation

Since $f$ is surjective, substitute $t = f(y)$ (so $y = f^{-1}(t) = f(t) - a^2$)
 into the original equation:
$$f(x^2 + t) = f(t) - a^2 + f(x)^2, \quad \forall\, x, t \in \mathbb{R}. \tag{2}
$$
The quantity $f(x^2 + t) - f(t) = f(x)^2 - a^2$ depends only on $x^2$. Setting $
t = 0$: $f(h) - a = f(x)^2 - a^2$ for $h = x^2 \geq 0$, confirming the RHS depen
ds only on $h$.

Define $F(x) = f(x) - a$. Then (2) gives, for all $t \in \mathbb{R}$ and $h \geq
 0$:
$$F(t + h) = F(t) + F(h). \tag{3}$$
Setting $t = b$, $h = -b > 0$ (for $b < 0$) in (3): $F(0) = F(b) + F(-b)$, so $F
(-b) = -F(b)$; **$F$ is odd**. Then for $h < 0$: $F(t+h) = F(t) - F(-h) = F(t) +
 F(h)$. So (3) extends to **all** $t, h \in \mathbb{R}$: $F$ is **additive** (Ca
uchy).

## Step 4: Multiplicativity of $F$

From (2) with $F$: $F(x^2) = F(x)^2 + 2aF(x)$. Compute $F((x+y)^2)$ two ways:
- Via additivity: $F(x^2 + 2xy + y^2) = F(x)^2 + 2aF(x) + 2F(xy) + F(y)^2 + 2aF(
y)$.
- Directly: $(F(x)+F(y))^2 + 2a(F(x)+F(y)) = F(x)^2 + 2F(x)F(y) + F(y)^2 + 2aF(x
) + 2aF(y)$.

Comparing: $F(xy) = F(x)F(y)$. So $F$ is a **field automorphism** of $\mathbb{R}
$.

## Step 5: $F$ is the identity

Any field automorphism $\sigma$ of $\mathbb{R}$ satisfies $\sigma(x^2) = \sigma(
x)^2 \geq 0$, so $\sigma$ preserves order. Since $\sigma$ fixes $\mathbb{Q}$, fo
r any $r \in \mathbb{R}$ and rationals $p < r < q$: $p = \sigma(p) \leq \sigma(r
) \leq \sigma(q) = q$. This forces $\sigma(r) = r$. So **$F = \mathrm{id}$**, i.
e., $f(x) = x + a$.

## Step 6: Determine $a$

With $f(x) = x + a$, the original equation gives:
$$(x^2 + y + a) + a = y + (x + a)^2 \implies x^2 + y + 2a = y + x^2 + 2ax + a^2.
$$
So $2a = 2ax + a^2$ for all $x$, forcing $a = 0$.

## Verification

$f(x) = x$: $f(x^2 + f(y)) = x^2 + y = y + x^2 = y + f(x)^2$. ✓

## Conclusion

The unique function satisfying the equation is $\boxed{f(x) = x}$.
