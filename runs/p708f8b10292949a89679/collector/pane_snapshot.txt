## Solution

We seek the extremal of

$$J(u) = u(0) + \tfrac{1}{2}u(0)^2 + \int_0^1 [u'(t)]^2\,dt, \qquad u(1)=2,\quad
 u(0)\ \text{free}.$$

This is a variational problem with a **boundary cost** $g(x)=x+\tfrac12 x^2$ at
the free left endpoint $t=0$ and a fixed right endpoint $t=1$.

### Euler–Lagrange equation

The integrand is $L(t,u,u')=(u')^2$, which is independent of $u$. The Euler–Lagr
ange equation is

$$\frac{\partial L}{\partial u} - \frac{d}{dt}\!\left(\frac{\partial L}{\partial
 u'}\right) = 0 \;\Longrightarrow\; \frac{d}{dt}(2u')=0 \;\Longrightarrow\; u''=
0.$$

Hence the extremal is affine: $u(t)=at+b$.

### Transversality condition at the free endpoint

Take a variation $u_\varepsilon = u+\varepsilon\eta$ with $\eta(1)=0$ (right end
point fixed) and $\eta(0)$ arbitrary. Computing the first variation:

$$\left.\frac{dJ}{d\varepsilon}\right|_{\varepsilon=0} = g'(u(0))\,\eta(0) + \in
t_0^1 2u'\eta'\,dt.$$

Integrating by parts:

$$\int_0^1 2u'\eta'\,dt = \bigl[2u'\eta\bigr]_0^1 - \int_0^1 2u''\eta\,dt = -\,2
u'(0)\,\eta(0) - \int_0^1 2u''\eta\,dt,$$

since $\eta(1)=0$. Therefore

$$\delta J = \bigl[g'(u(0)) - 2u'(0)\bigr]\eta(0) - \int_0^1 2u''\eta\,dt.$$

For $\delta J=0$ for all admissible $\eta$:

1. **EL equation:** $u''=0$ (already obtained).
2. **Transversality at $t=0$:** $g'(u(0)) = 2u'(0)$.

Since $g'(x)=1+x$, the transversality condition reads

$$1 + u(0) = 2u'(0).$$

### Solving the system

With $u(t)=at+b$: $u(0)=b$, $u'(0)=a$, $u(1)=a+b=2$.

$$\begin{cases} 1 + b = 2a, \\ a + b = 2. \end{cases}$$

From the first equation $b=2a-1$. Substituting into the second: $a+2a-1=2$, so $
3a=3$, giving $a=1$ and $b=1$.

### Verification

The extremal is $u(t)=t+1$, with $u(0)=1$, $u(1)=2$, $u'(t)=1$.

- Transversality: $1+u(0)=1+1=2=2\cdot 1=2u'(0)$. ✓
- Boundary condition: $u(1)=1+1=2$. ✓
- Functional value: $J=1+\tfrac12(1)^2+\int_0^1 1\,dt = 1+\tfrac12+1 = \tfrac52$
.

The second variation is $\delta^2 J = \int_0^1 2(\eta')^2\,dt \geq 0$ with equal
ity only when $\eta'\equiv 0$, which (combined with $\eta(1)=0$) forces $\eta\eq
uiv 0$. Hence the extremal is a **strict minimizer**.

### Result

$$\boxed{u(t) = t + 1}$$
