## Solution

We want to compute $\lim_{x \to 0} \Im\!\left((-1)^x \Gamma(x)\right)$.

**Branch choice.** We interpret $(-1)^x = e^{x \log(-1)}$ using the principal br
anch of the complex logarithm, so $\log(-1) = i\pi$, giving
$$(-1)^x = e^{i\pi x}.$$

**Laurent expansion of $\Gamma(x)$ near $x=0$.** The Gamma function has a simple
 pole at the origin:
$$\Gamma(x) = \frac{1}{x} - \gamma + O(x),$$
where $\gamma$ is the Euler–Mascheroni constant.

**Expansion of $e^{i\pi x}$:**
$$e^{i\pi x} = 1 + i\pi x - \frac{\pi^2 x^2}{2} + O(x^3).$$

**Product.** Multiplying:
$$(-1)^x \Gamma(x) = e^{i\pi x}\left(\frac{1}{x} - \gamma + O(x)\right)$$
$$= \left(1 + i\pi x - \frac{\pi^2 x^2}{2} + \cdots\right)\!\left(\frac{1}{x} -
\gamma + O(x)\right).$$

Distributing term by term:
$$= \underbrace{\frac{1}{x}}_{\text{from }1\cdot\frac1x} + \underbrace{i\pi}_{\t
ext{from }i\pi x \cdot \frac1x} - \underbrace{\gamma}_{\text{from }1\cdot(-\gamm
a)} + \underbrace{\left(-\frac{\pi^2}{2} - i\pi\gamma\right)x}_{\text{higher ord
er}} + O(x).$$

So:
$$(-1)^x \Gamma(x) = \frac{1}{x} + i\pi - \gamma + O(x).$$

**Extracting the imaginary part.** The real part is $\frac{1}{x} - \gamma + O(x)
$ (which diverges as $x\to 0$), while the imaginary part is:
$$\Im\!\left((-1)^x \Gamma(x)\right) = \pi + O(x).$$

The $O(x)$ correction vanishes as $x \to 0$, so:
$$\lim_{x \to 0} \Im\!\left((-1)^x \Gamma(x)\right) = \pi.$$
