## Solution

Let $a, b, c$ be the roots of $x^3 - 2018x + 2018 = 0$. By Vieta's formulas:
$$a+b+c = 0, \quad ab+bc+ca = -2018, \quad abc = -2018.$$

**Power sums and recurrence.** Define $S_n = a^n + b^n + c^n$. Since each root s
atisfies $x^3 = 2018x - 2018$, we get the recurrence:
$$S_{n+3} = 2018\,S_{n+1} - 2018\,S_n.$$

The initial values are:
- $S_0 = 3$
- $S_1 = a+b+c = 0$
- $S_2 = (a+b+c)^2 - 2(ab+bc+ca) = 0 - 2(-2018) = 4036$

Computing further:
- $S_3 = 2018\,S_1 - 2018\,S_0 = 0 - 6054 = -6054$  (also equals $3abc = 3(-2018
) = -6054$ ✓)
- $S_4 = 2018\,S_2 - 2018\,S_1 = 2018 \cdot 4036$
- $S_5 = 2018\,S_3 - 2018\,S_2 = 2018(-6054 - 4036) = 2018(-10090)$

**Define $T_n = S_n / n$.** The equation becomes $T_{p+q} = T_p \cdot T_q$.

Computing $T_n$ for small $n$:
- $T_1 = 0/1 = 0$
- $T_2 = 4036/2 = 2018$
- $T_3 = -6054/3 = -2018$
- $T_4 = (2018 \cdot 4036)/4 = 2018 \cdot 1009$
- $T_5 = 2018(-10090)/5 = 2018 \cdot (-2018) = -2018^2$

**Searching for the smallest $q$.**

**$q = 1$:** Need $p = 1$ (since $0 < p \leq q$). Then $T_2 = T_1 \cdot T_1 = 0$
, but $T_2 = 2018 \neq 0$. ✗

**$q = 2$:** Need $p \in \{1, 2\}$.
- $p = 1$: $T_3 = T_1 \cdot T_2 = 0$, but $T_3 = -2018 \neq 0$. ✗
- $p = 2$: $T_4 = T_2 \cdot T_2 = 2018^2 = 2018 \cdot 2018$, but $T_4 = 2018 \cd
ot 1009 \neq 2018 \cdot 2018$. ✗

**$q = 3$:** Need $p \in \{1, 2, 3\}$.
- $p = 1$: $T_4 = T_1 \cdot T_3 = 0$, but $T_4 = 2018 \cdot 1009 \neq 0$. ✗
- $p = 2$: $T_5 = T_2 \cdot T_3 = 2018 \cdot (-2018) = -2018^2$, and $T_5 = -201
8^2$. ✓

**Verification:** $T_2 \cdot T_3 = (2018)(-2018) = -2018^2 = T_5$. ✓

So the smallest $q$ is $q = 3$, achieved with $p = 2$ (satisfying $0 < p \leq q$
).

$$p^2 + q^2 = 2^2 + 3^2 = 4 + 9 = \boxed{13}$$
