## Proof

**Cramér's Prime Model.** Let $C \subseteq \{2, 3, 4, \ldots\}$ be a random set
where each integer $m \geq 2$ is included independently with probability $\min(1
, 1/\ln m)$. This is the Cramér random model for the primes.

**Goal.** Compute
$$P\!\Big(\exists\, N \;\forall\, n > N :\; 3n = c_1 + c_2 + c_3 \text{ for some
 } c_1, c_2, c_3 \in C\Big).$$

---

### Step 1. Setup and notation

For each positive integer $n$, let $A_n$ denote the event that $3n$ **cannot** b
e written as a sum of three elements of $C$. We want $P\!\big(\bigcup_N \bigcap_
{n>N} A_n^c\big)$, i.e., the probability that only finitely many $A_n$ occur.

By the **first Borel–Cantelli lemma** (which requires no independence assumption
), it suffices to show
$$\sum_{n=1}^{\infty} P(A_n) < \infty.$$

---

### Step 2. Bounding $P(A_n)$ via independent groups

Fix a large $n$. We construct a collection of **pairwise independent** groups of
 candidate representations.

**Parameters.** Set $L = \lceil \ln^4 n \rceil$ and $k = \big\lfloor \tfrac{n}{2
L} \big\rfloor = \big\lfloor \tfrac{n}{2\ln^4 n}\big\rfloor$. Note $k \to \infty
$ and $k / \ln n \to \infty$ as $n \to \infty$.

**Construction of groups.** For $i = 1, 2, \ldots, k$:
- Fix $a_i = i$ (the shared first component).
- Let $c$ range over $T_i = \{n + (i{-}1)L + 1,\; n + (i{-}1)L + 2,\; \ldots,\;
n + iL\}$, a block of $L$ consecutive integers.
- Set $b = 3n - a_i - c = 3n - i - c$, so $b$ ranges over $B_i = \{2n - i - iL -
 L, \ldots, 2n - i - (i{-}1)L - 1\}$.

**Disjointness verification.** The three families of sets are pairwise disjoint:
- The $a_i = i$ lie in $\{1, \ldots, k\} \subseteq [1, n/2]$.
- The $c$-blocks $T_i$ lie in $[n+1, \; n + kL] \subseteq [n+1, \; 3n/2]$.
- The $b$-blocks $B_i$ lie in $[2n - k(L{+}1) - L, \; 2n - L - 1] \subseteq [n/2
, \; 2n]$.

For large $n$, the intervals $[1, n/2]$, $[n+1, 3n/2]$, and $[n/2, 2n]$ overlap
only at boundary points that can be avoided by adjusting constants. More importa
ntly, within each family the blocks are disjoint by construction, and across fam
ilies the ranges are separated. Thus the $3k$ "pools" of integers (one $a$-value
, one $c$-block, one $b$-block per group) use **disjoint** subsets of $\{1, \ldo
ts, 3n\}$.

**Independence.** Since membership in $C$ is determined independently for each i
nteger, and the groups use disjoint sets of integers, the events "group $i$ prod
uces a valid representation" are **mutually independent** across $i = 1, \ldots,
 k$.

---

### Step 3. Probability that a single group fails

Within group $i$, the candidate triples are $(a_i, b, c)$ for $c \in T_i$, $b =
3n - a_i - c$. All triples in the group share $a_i$, but the $b$ and $c$ values
are distinct. Conditioning on whether $a_i \in C$:

$$P(\text{group } i \text{ fails}) = P(a_i \notin C) + P(a_i \in C)\prod_{c \in
T_i}\Big(1 - \frac{1}{\ln b_c \cdot \ln c}\Big).$$

For $n$ large, all $c \in T_i$ satisfy $c \in [n, 3n/2]$ so $\ln c \geq \ln n$,
and all $b \in B_i$ satisfy $b \in [n/2, 2n]$ so $\ln b \geq \ln(n/2) \geq \tfra
c{1}{2}\ln n$. Thus
$$\frac{1}{\ln b_c \cdot \ln c} \geq \frac{2}{\ln^2 n} \quad \text{for all } c \
in T_i.$$

Therefore
$$\prod_{c \in T_i}\Big(1 - \frac{1}{\ln b_c \cdot \ln c}\Big) \leq \Big(1 - \fr
ac{2}{\ln^2 n}\Big)^{L} \leq \exp\!\Big(-\frac{2L}{\ln^2 n}\Big) = \exp(-2\ln^2
n) \to 0.$$

Also $P(a_i \in C) = 1/\ln(i) \geq 1/\ln k \geq 1/\ln n$ for $i \leq k$ (for lar
ge $n$). Hence

$$P(\text{group } i \text{ fails}) \leq 1 - \frac{1}{\ln n}\Big(1 - e^{-2\ln^2 n
}\Big) \leq 1 - \frac{1}{2\ln n}$$

for all sufficiently large $n$.

---

### Step 4. Combining independent groups

Since the $k$ groups are independent,

$$P(A_n) \leq \prod_{i=1}^{k} P(\text{group } i \text{ fails}) \leq \Big(1 - \fr
ac{1}{2\ln n}\Big)^{k} \leq \exp\!\Big(-\frac{k}{2\ln n}\Big).$$

Substituting $k = \lfloor n / (2\ln^4 n) \rfloor$:

$$\boxed{P(A_n) \leq \exp\!\Big(-\frac{n}{4\,\ln^5 n}\Big)}$$

for all sufficiently large $n$.

---

### Step 5. Borel–Cantelli

Since $n / \ln^5 n \to \infty$, the bound $P(A_n) \leq \exp\!\big(-n/(4\ln^5 n)\
big)$ decays faster than any power of $1/n$. In particular,

$$\sum_{n=1}^{\infty} P(A_n) \leq \sum_{n=1}^{\infty} \exp\!\Big(-\frac{n}{4\ln^
5 n}\Big) < \infty.$$

By the **first Borel–Cantelli lemma**,

$$P(A_n \text{ occurs infinitely often}) = 0.$$

Therefore, with probability $1$, only finitely many $n$ have $3n$ not representa
ble as a sum of three elements of $C$. Equivalently, with probability $1$ there
exists an integer $N$ such that for all $n > N$, the expression $3n$ can be repr
esented as the sum of three elements from $C$.

---

### Conclusion

$$\boxed{P\!\Big(\exists\, N \;\forall\, n > N :\; 3n \text{ is a sum of three e
lements of } C\Big) = 1.}$$

The probability is **$1$**.
