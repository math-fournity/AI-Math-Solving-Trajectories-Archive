## Proof

**Claim.** Yes. If $\psi_n \rightharpoonup \psi$ weakly in $H$, then for each fi
xed $k$,
$$\lim_{n\to\infty}\langle \psi_n - \psi,\, \phi_k\rangle_H = 0.$$

**Justification.**

Recall the definition of weak convergence in a Hilbert space. A sequence $\{\psi
_n\}$ converges weakly to $\psi$ (written $\psi_n \rightharpoonup \psi$) if and
only if

$$\langle \psi_n,\, v\rangle_H \;\longrightarrow\; \langle \psi,\, v\rangle_H \q
uad \text{for every } v \in H.$$

(Equivalently, $f(\psi_n)\to f(\psi)$ for every continuous linear functional $f\
in H^*$; by the Riesz representation theorem every such $f$ is of the form $f(\c
dot)=\langle\,\cdot\,,v\rangle_H$ for a unique $v\in H$, so the two formulations
 coincide.)

Now fix any index $k$. Since $\{\phi_k\}$ is an orthonormal sequence in $H$, in
particular $\phi_k \in H$. Applying the definition of weak convergence with $v =
 \phi_k$ gives

$$\langle \psi_n,\, \phi_k\rangle_H \;\longrightarrow\; \langle \psi,\, \phi_k\r
angle_H \quad\text{as } n\to\infty.$$

By linearity of the inner product in the first argument,

$$\langle \psi_n - \psi,\, \phi_k\rangle_H = \langle \psi_n,\, \phi_k\rangle_H -
 \langle \psi,\, \phi_k\rangle_H \;\longrightarrow\; 0 \quad\text{as } n\to\inft
y.$$

Since $k$ was arbitrary, this holds for every $k$.

**Remark.** This is in fact an immediate, definitional consequence of weak conve
rgence — each $\phi_k$ is a legitimate test vector in $H$. The converse (that co
nvergence against every $\phi_k$ implies weak convergence) would generally fail,
 since $\{\phi_k\}$ need not span $H$; but the forward direction asked here requ
ires only the definition.
