# Problem

Lisa and Bart are playing a game with $n$ lights evenly spaced around a circular table. Some lights are on and some are off. Lisa wins if she can turn all lights on. On each turn, Lisa chooses a set of positions to flip, but before the flipping occurs, Bart can rotate the table to any position he chooses. Then the lights in the positions Lisa chose are flipped.
Let $L(n)$ be the maximum number of turns Lisa needs to guarantee a win regardless of the initial configuration, or $L(n) = \infty$ if Bart can prevent her from winning.
Find $L(8) + L(7)$. If $L(n) = \infty$, use the value $0$.
