## Solution

**Setup and notation.** Let $V$ be a Lie algebra and $X$ a common eigenvector of
 all $M \in V$, so $MX = \alpha(M)X$ for a linear functional $\alpha: V \to \mat
hbb{F}$. Define the iterated functionals
$$\alpha_0(B) := \alpha(B), \qquad \alpha_{k+1}(B) := \alpha_k([B, A]),$$
so that $\alpha_k(B) = \alpha\!\big(\operatorname{ad}_A^k(B)\big)$ with $\operat
orname{ad}_A(B) = [B,A] = BA - AB$. The sequence is $X_0 = X$, $X_{k+1} = AX_k$,
 i.e. $X_k = A^k X$.

**Key identity.** For any $B \in V$, using $BA = AB + [B,A]$:
$$BX_k = B(A^k X) = (BA^k)X.$$
Moving $B$ past each factor of $A$ one at a time and collecting terms by how man
y commutators are taken (a binomial count of paths), one obtains the general for
mula

$$\boxed{BX_k = \sum_{j=0}^{k} \binom{k}{j}\,\alpha_j(B)\,X_{k-j}.}$$

**Proof by induction on $k$.** Base $k=0$: $BX_0 = \alpha_0(B)X_0$. ✓

Inductive step: $BX_{k+1} = B(AX_k) = (BA)X_k = (AB + [B,A])X_k = A(BX_k) + [B,A
]X_k$.

By the induction hypothesis applied to $B$ and to $[B,A]$:
$$A(BX_k) = \sum_{j=0}^{k}\binom{k}{j}\alpha_j(B)\,X_{k+1-j},$$
$$[B,A]X_k = \sum_{j=0}^{k}\binom{k}{j}\alpha_j([B,A])\,X_{k-j} = \sum_{j=0}^{k}
\binom{k}{j}\alpha_{j+1}(B)\,X_{k-j}.$$
Re-indexing the second sum with $j' = j+1$ and combining via Pascal's identity $
\binom{k}{j}+\binom{k}{j-1}=\binom{k+1}{j}$ gives
$$BX_{k+1} = \sum_{j=0}^{k+1}\binom{k+1}{j}\alpha_j(B)\,X_{k+1-j}. \qquad \check
mark$$

**Applying to $MX_3$.** Setting $B = M$, $k = 3$:
$$MX_3 = \binom{3}{0}\alpha_0(M)\,X_3 + \binom{3}{1}\alpha_1(M)\,X_2 + \binom{3}
{2}\alpha_2(M)\,X_1 + \binom{3}{3}\alpha_3(M)\,X_0.$$

The coefficient of $X_2$ is $\binom{3}{1}\alpha_1(M) = 3 \cdot \alpha_1(M)$.

Given $\alpha_1(M) = 3$:

$$\text{coefficient of } X_2 = 3 \times 3 = \boxed{9}.$$
