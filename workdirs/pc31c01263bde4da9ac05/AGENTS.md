# Problem

In a cutting-edge laboratory, a team of micro-engineers is constructing a power grid on a high-precision circuit board. The board is designed as a perfect grid layout of 8 rows and 8 columns of square processors. 

The engineers have installed conductive filaments along every single boundary line of the 64 processors. This includes all the perimeter edges of the entire $8\times8$ layout as well as all internal lines where two processors meet. Each boundary segment between two adjacent intersection points contains exactly one filament.

A safety inspector realizes that if any set of filaments forms a closed rectangle of any size (from a $1\times1$ up to an $8\times8$), it will cause a catastrophic feedback loop. To prevent this, the engineers must remove a certain number of filaments from the grid.

What is the minimum number of conductive filaments that must be removed so that no closed rectangular circuits remain in the network?
