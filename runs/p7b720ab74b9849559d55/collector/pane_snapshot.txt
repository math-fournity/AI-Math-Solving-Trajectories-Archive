## Setting Up the Counting

A player on team $n$ who made $m$ shots has percentage $100m/n$. This rounds to
66.6% when:
$$66.55 \leq \frac{100m}{n} < 66.65 \quad\Longleftrightarrow\quad \frac{1331}{20
00} \leq \frac{m}{n} < \frac{1333}{2000}$$

(The example "32.45% → 32.5%" confirms round-half-up, so 66.65→66.7 is excluded,
 while 66.55→66.6 is included.)

For team $n$, the count of such players is:
$$c(n) = \left\lceil \frac{1333n}{2000} \right\rceil - \left\lceil \frac{1331n}{
2000} \right\rceil$$

(integers $m$ in $[1331n/2000,\; 1333n/2000)$).

## Decomposing by Period

$$c(n) = 2q + g(r), \quad \text{where } g(r) = \left\lceil \frac{1333r}{2000}\ri
ght\rceil - \left\lceil \frac{1331r}{2000}\right\rceil$$

The range $n \in [2000, 10000]$ gives:
- $q=1$: $r=0,\ldots,1999$ (2000 values)
- $q=2$: $r=0,\ldots,1999$ (2000 values)
- $q=3$: $r=0,\ldots,1999$ (2000 values)
- $q=4$: $r=0,\ldots,1999$ (2000 values)
- $q=5$: $r=0$ (1 value, $n=10000$)

## Computing $G = \sum_{r=0}^{1999} g(r)$

Since $\gcd(1331,2000)=1$ and $\gcd(1333,2000)=1$, for $r=1,\ldots,1999$ the res
idues $kr \bmod 2000$ permute $\{1,\ldots,1999\}$. Using the standard floor-sum
identity:

$$\sum_{r=1}^{1999}\left\lfloor \frac{kr}{2000}\right\rfloor = \frac{(k-1)\cdot
1999}{2}$$

Since $2000 \nmid kr$ for $1 \le r \le 1999$:
$$A_k := \sum_{r=0}^{1999}\left\lceil \frac{kr}{2000}\right\rceil = \frac{(k-1)\
cdot 1999}{2} + 1999 = \frac{1999(k+1)}{2}$$

Therefore:
$$G = A_{1333} - A_{1331} = \frac{1999 \cdot 1334 - 1999 \cdot 1332}{2} = \frac{
1999 \cdot 2}{2} = 1999$$

**Key observation:** $G = 1999 = \sum_{r=0}^{1999} r/1000$, so the rounding erro
rs average out perfectly over each complete period.

## Computing the Sums

$$S_1 = \sum_{q=1}^{4}\bigl(2000\cdot 2q + G\bigr) + 10 = 4000(1{+}2{+}3{+}4) +

$S_2 = \sum_{n=6000}^{10000} n/1000 = \frac{(6000+10000)\cdot 4001}{2\cdot 1000}

## Reducing the Fraction

$$\frac{S_2}{S_1} = \frac{32008}{48006} = \frac{16004}{24003}$$
