## Proof

Let $S = \mathbb{N}^{\mathbb{N}}$ denote the set of all infinite sequences of na
tural numbers, and let $B = \{0,1\}^{\mathbb{N}}$ denote the set of all infinite
 binary sequences, which has cardinality $2^{\aleph_0}$. We are given a surjecti
on $F: S \to B$. We show that the Cantor–Bernstein–Schroeder (CBS) theorem impli
es $|S| = 2^{\aleph_0}$.

**CBS theorem (recap).** If there exist injections $f: A \to B$ and $g: B \to A$
, then $|A| = |B|$.

We establish injections in both directions between $S$ and $B$.

---

**Direction 1: Injection $B \hookrightarrow S$ (i.e., $2^{\aleph_0} \leq |S|$).*
*

Since $\{0,1\} \subseteq \mathbb{N}$, every binary sequence is automatically a s
equence of natural numbers. The inclusion map
$$\iota: B \to S, \qquad (b_1, b_2, \ldots) \mapsto (b_1, b_2, \ldots)$$
is injective. (This direction does not even require the given surjection $F$; al
ternatively, using the axiom of choice, the surjection $F: S \to B$ yields a rig
ht-inverse $g: B \to S$ with $F \circ g = \mathrm{id}_B$, which is injective — b
ut the trivial inclusion above suffices without any choice.)

---

**Direction 2: Injection $S \hookrightarrow B$ (i.e., $|S| \leq 2^{\aleph_0}$).*
*

We construct an explicit injection $h: S \to B$. For a sequence $\mathbf{a} = (a
_1, a_2, a_3, \ldots) \in \mathbb{N}^{\mathbb{N}}$, encode each entry $a_i$ as a
 block of $a_i$ ones followed by a single zero:
$$h(\mathbf{a}) = \underbrace{1\cdots1}_{a_1}\,0\,\underbrace{1\cdots1}_{a_2}\,0
\,\underbrace{1\cdots1}_{a_3}\,0\,\cdots$$
This produces an infinite binary sequence (since infinitely many blocks are conc
atenated, each nonempty as it contains at least its terminating zero).

**$h$ is injective:** Given $h(\mathbf{a})$, we recover $\mathbf{a}$ uniquely by
 scanning left to right: count the number of consecutive $1$'s before each $0$;
the $i$-th such count is $a_i$. The delimiters (the $0$'s) partition the binary
sequence into blocks unambiguously, so distinct sequences $\mathbf{a} \neq \math
bf{a}'$ yield distinct binary sequences $h(\mathbf{a}) \neq h(\mathbf{a}')$.

Thus $h: S \hookrightarrow B$ is an injection, giving $|S| \leq 2^{\aleph_0}$.

---

**Applying CBS.**

We have constructed:
- An injection $\iota: B \to S$, so $2^{\aleph_0} \leq |S|$.
- An injection $h: S \to B$, so $|S| \leq 2^{\aleph_0}$.

By the Cantor–Bernstein–Schroeder theorem, $|S| = |B| = 2^{\aleph_0}$.

---

**Remark on the role of $F$.** The given surjection $F: S \to B$ confirms $|B| \
leq |S|$ (a surjection from $A$ onto $B$ implies $|B| \leq |A|$, using the axiom
 of choice to select a preimage for each element of $B$). However, this directio
n is already supplied by the trivial inclusion $\iota: B \hookrightarrow S$, so
$F$ is not strictly necessary. The essential ingredient for CBS is the *reverse*
 injection $h: S \hookrightarrow B$, which we constructed explicitly. With both
injections in hand, CBS yields the equality $|\mathbb{N}^{\mathbb{N}}| = 2^{\ale
ph_0}$.
