## Proof

**Setup.** Place $K=8$ boxes labeled $0, 1, \dots, 7$ around a circle. Place 2 i
dentical balls into these boxes (a ball placement is a multiset $\{a, b\}$ with
$a, b \in \mathbb{Z}_8$). The cyclic group $C_8 = \{r^k : k = 0, \dots, 7\}$ act
s by rotation: $r^k$ sends box $i$ to box $i+k \pmod{8}$, so $\{a,b\} \mapsto \{
a+k, b+k\} \pmod{8}$.

Two arrangements that differ by a rotation are identified. The number of distinc
t circular arrangements equals the number of orbits under $C_8$, computed by **B
urnside's lemma**:

$$\text{# orbits} = \frac{1}{|C_8|}\sum_{k=0}^{7} |\operatorname{Fix}(r^k)|$$

**Total arrangements (without symmetry):** Multisets of size 2 from 8 elements:
$\binom{8+2-1}{2} = \binom{9}{2} = 36$.

**Computing $|\operatorname{Fix}(r^k)|$ for each $k$:**

An arrangement $\{a, b\}$ is fixed by $r^k$ if $\{a+k,\, b+k\} = \{a, b\} \pmod{
8}$.

- **Case $a = b$ (both balls in same box):** Requires $a + k \equiv a \pmod{8}$,
 i.e., $k \equiv 0$. So only $k=0$ fixes these.

- **Case $a \neq b$:** The equality $\{a+k, b+k\} = \{a, b\}$ requires either:
  - (i) $a+k \equiv a$ and $b+k \equiv b$, giving $k \equiv 0$, **or**
  - (ii) $a+k \equiv b$ and $b+k \equiv a$, giving $k \equiv b-a$ and $k \equiv
a-b$, hence $2k \equiv 0 \pmod{8}$.

  So for $k \neq 0$, fixed arrangements exist only when $2k \equiv 0 \pmod{8}$,
i.e., $k = 4$ (the only nonzero solution in $\{1,\dots,7\}$).

**Summary of fixed-point counts:**

| $k$ | $|\operatorname{Fix}(r^k)|$ | Reason |
|-----|---------------------------|--------|
| 0 | 36 | All arrangements |
| 1, 2, 3, 5, 6, 7 | 0 | $2k \not\equiv 0 \pmod{8}$; no fixed arrangement with $
a \neq b$, and $a=b$ needs $k=0$ |
| 4 | 4 | Arrangements $\{a, a+4\}$ for $a = 0,1,2,3$ (note $\{a,a+4\} = \{a+4,
a\}$, so $a=4,5,6,7$ give duplicates) |

**Applying Burnside:**

$$\text{# orbits} = \frac{1}{8}\left(36 + 4 + 0 \times 6\right) = \frac{40}{8} =
 \boxed{5}$$

**Direct verification by enumerating the 5 orbits:**

Each orbit is characterized by the circular distance $d = \min(|b-a|, 8-|b-a|) \
in \{0, 1, 2, 3, 4\}$:

1. **$d=0$** (same box): $\{0,0\}, \{1,1\}, \dots, \{7,7\}$ — orbit of size 8.
2. **$d=1$** (adjacent): $\{0,1\}, \{1,2\}, \dots, \{7,0\}$ — orbit of size 8.
3. **$d=2$**: $\{0,2\}, \{1,3\}, \dots, \{7,1\}$ — orbit of size 8.
4. **$d=3$**: $\{0,3\}, \{1,4\}, \dots, \{7,2\}$ — orbit of size 8.
5. **$d=4$** (diametrically opposite): $\{0,4\}, \{1,5\}, \{2,6\}, \{3,7\}$ — or
bit of size 4 (stabilized by $r^4$).

Total elements: $8 + 8 + 8 + 8 + 4 = 36 = \binom{9}{2}$, confirming all arrangem
ents are accounted for with no overlaps.

The number of ways to place 2 balls into 8 boxes arranged in a circle, invariant
 under circular permutations, is **5**.
