## Proof

**Setup.** Let $w = z^{1/n}$, so that $z = w^n$. Then the given fractional power
 series becomes an ordinary polynomial in $w$:

$$u(z) = P(w) = c_0 + c_1 w + c_2 w^2 + \cdots + c_k w^k, \qquad w = z^{1/n}.$$

Our goal is to construct $f(z, W) = a_0(z) + a_1(z)W + \cdots + a_n(z)W^n$, with
 each $a_i(z)$ a polynomial in $z$ (integer powers only), such that $f(z, u) = 0
$.

---

**Construction.** Let $\zeta$ be a primitive $n$-th root of unity (over $\mathbb
{C}$; if the $c_i$ are real, the resulting $a_i(z)$ are still real since complex
 conjugate pairs combine). Define

$$\boxed{\;f(z, W) \;=\; \prod_{j=0}^{n-1}\bigl(W - P(\zeta^{\,j} w)\bigr), \qqu
ad w = z^{1/n}.\;}$$

This is a monic polynomial of degree $n$ in $W$, so it has the form $f(z,W) = W^
n + a_{n-1}(z)W^{n-1} + \cdots + a_0(z)$ (absorbing the leading coefficient into
 notation; equivalently $a_n(z)=1$).

---

**$f(z,u)=0$.** Substituting $W = u = P(w)$, the factor with $j=0$ is $(P(w) - P
(\zeta^0 w)) = (P(w)-P(w)) = 0$. Hence the whole product vanishes:

$$f(z, u) = \prod_{j=0}^{n-1}\bigl(P(w) - P(\zeta^{\,j}w)\bigr) = 0. \qquad\chec
kmark$$

---

**Each $a_i(z)$ is a polynomial in $z$ with integer powers.** The coefficient of
 $W^{n-m}$ in $f$ is $(-1)^m e_m$, where $e_m$ is the $m$-th elementary symmetri
c polynomial in the $n$ values

$$P(w),\; P(\zeta w),\; P(\zeta^2 w),\;\ldots,\; P(\zeta^{n-1} w).$$

Consider the substitution $w \mapsto \zeta w$. This cyclically permutes the set
$\{\zeta^j w\}_{j=0}^{n-1}$, hence permutes the set $\{P(\zeta^j w)\}_{j=0}^{n-1
}$. Since $e_m$ is symmetric in these values, it is **invariant** under $w \maps
to \zeta w$:

$$e_m(\zeta w) = e_m(w).$$

Now $e_m(w)$ is a polynomial in $w$ (with coefficients that are polynomials in t
he $c_i$). Write $e_m(w) = \sum_{\ell} b_\ell\, w^\ell$. The invariance $e_m(\ze
ta w) = e_m(w)$ gives $\sum_\ell b_\ell \zeta^\ell w^\ell = \sum_\ell b_\ell w^\
ell$, so $b_\ell(\zeta^\ell - 1) = 0$ for every $\ell$. Since $\zeta$ is a primi
tive $n$-th root of unity, $\zeta^\ell = 1 \iff n \mid \ell$. Therefore $b_\ell
= 0$ unless $n \mid \ell$, and

$$e_m(w) = \sum_{r} b_{nr}\, w^{nr} = \sum_r b_{nr}\, z^{r}.$$

Thus each $e_m$, and consequently each coefficient $a_i(z) = (-1)^{n-i} e_{n-i}(
z)$, is a polynomial in $z = w^n$ with **integer powers** of $z$. $\qquad\checkm
ark$

---

**Summary of the method.**

1. Rewrite $u(z) = P(w)$ with $w = z^{1/n}$, where $P$ is an ordinary polynomial
.
2. Pick a primitive $n$-th root of unity $\zeta$.
3. Form $f(z, W) = \prod_{j=0}^{n-1}\bigl(W - P(\zeta^{\,j} z^{1/n})\bigr)$.
4. Expand in $W$; the coefficient of each $W^{n-m}$ is $(-1)^m e_m\bigl(P(w), P(
\zeta w),\ldots\bigr)$, which is invariant under $w\mapsto\zeta w$ and therefore
 a polynomial in $z = w^n$ with integer powers.
5. The result $f(z, W) = a_0(z) + a_1(z)W + \cdots + a_n(z) W^n$ (with $a_n = 1$
) satisfies $f(z, u) = 0$ because the $j=0$ factor vanishes identically.

This is exactly the **norm construction** (the field-theoretic norm $N_{\mathbb{
C}(w)/\mathbb{C}(w^n)}(W - P(w))$): the minimal/annihilating polynomial of $P(w)
$ over $\mathbb{C}(z)$, which is a polynomial of degree $\le n$ in $W$ with coef
ficients in $\mathbb{C}[z]$.
