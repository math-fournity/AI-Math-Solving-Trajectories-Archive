## Solution

**Characterization of primitive pairs.** For $(a,b) \neq (0,0)$, write $z = a+bi
$. Then $z^\ell$ is real for some positive integer $\ell$ iff $z^\ell = \overlin
e{z^\ell} = \overline{z}^{\,\ell}$, i.e.
$$\left(\frac{z}{\overline{z}}\right)^{\!\ell} = 1.$$
Thus $z/\overline{z}$ must be a root of unity. Since $z/\overline{z} = (a+bi)/(a
-bi) \in \mathbb{Q}(i)$, and the only roots of unity in $\mathbb{Q}(i)$ are $\{1
,-1,i,-i\}$ (the units of $\mathbb{Z}[i]$), we get four cases:

- $z/\overline{z}=1 \Rightarrow b=0$,
- $z/\overline{z}=-1 \Rightarrow a=0$,
- $z/\overline{z}=i \Rightarrow a+bi = i(a-bi) = b+ia \Rightarrow a=b$,
- $z/\overline{z}=-i \Rightarrow a+bi = -b-ia \Rightarrow a=-b$.

The origin $(0,0)$ is trivially primitive ($0^\ell=0$), and it lies on all four
lines. Hence

$$(a,b)\text{ primitive} \iff b=0 \text{ or } a=0 \text{ or } a=b \text{ or } a=
-b.$$

**Counting.** In the square $0\le a,b\le n$, the line $a=-b$ contributes only $(
0,0)$. The three lines $a=0$, $b=0$, $a=b$ each contain $n+1$ points, and their
pairwise (and triple) intersections all equal $\{(0,0)\}$. By inclusion–exclusio
n the number of primitive pairs is
$$3(n+1)-3\cdot 1+1 = 3n+1.$$

**Threshold.** We need
$$\frac{3n+1}{(n+1)^2} < \frac{1}{100}
\iff 100(3n+1) < (n+1)^2
\iff n^2 - 298n - 99 > 0.$$

The positive root of $n^2-298n-99=0$ is $\frac{298+\sqrt{298^2+396}}{2}=\frac{29
8+\sqrt{89200}}{2}$. Since $298^2=88804<89200<89401=299^2$, we have $\sqrt{89200
}\in(298,299)$, so the root lies in $\bigl(298,\tfrac{298+299}{2}\bigr)=(298,298
.5)$. Thus the inequality holds for $n\ge 299$.

Check the boundary:
- $n=298$: $100(3\cdot298+1)=100\cdot895=89500 > 89401=(299)^2$, so the fraction
 exceeds $1\%$.
- $n=299$: $100(3\cdot299+1)=100\cdot898=89800 < 90000=(300)^2$, so the fraction
 is below $1\%$.

Therefore the smallest positive integer $n$ is $\boxed{299}$.
