**Answer: No.** For every $n > 1$, there exists a non-affine map $A: \mathbb{R}^
n \to \mathbb{R}^n$ that maps lines onto lines.

---

## Construction

We construct a function $g: \mathbb{R}^n \to \mathbb{R}$ such that for **every**
 line $\ell \subset \mathbb{R}^n$, the restriction $g|_\ell : \ell \to \mathbb{R
}$ is surjective. Then we set
$$A(x_1, \dots, x_n) = (g(x), 0, \dots, 0).$$

### Constructing $g$ by transfinite induction

The set of all lines in $\mathbb{R}^n$ has cardinality $\mathfrak{c} = |\mathbb{
R}|$ (each line is determined by a point and a direction up to scaling). Conside
r the family of requirements indexed by pairs $(\ell, t)$ where $\ell$ is a line
 and $t \in \mathbb{R}$: we require that **some** point of $\ell$ is mapped to $
t$ by $g$. This family has cardinality $\mathfrak{c} \cdot \mathfrak{c} = \mathf
rak{c}$.

Well-order these requirements as $\{(\ell_\alpha, t_\alpha) : \alpha < \mathfrak
{c}\}$. By transfinite induction:

- **At step $\alpha$:** Fewer than $\mathfrak{c}$ points have been assigned valu
es. Since $\ell_\alpha$ has $\mathfrak{c}$ points, there exists an unassigned po
int $p_\alpha \in \ell_\alpha$. Set $g(p_\alpha) = t_\alpha$.

- **After all steps:** Assign $g(p) = 0$ for any remaining unassigned points.

### Verification that $g|_\ell$ is surjective for every line $\ell$

For any line $\ell$ and any $t \in \mathbb{R}$, the requirement $(\ell, t)$ appe
ars as some $(\ell_\alpha, t_\alpha)$ in the enumeration. By construction, $g(p_
\alpha) = t_\alpha = t$ with $p_\alpha \in \ell$. Hence $g|_\ell$ is surjective.
 $\checkmark$

### $A$ maps every line onto a line

Let $\ell = \{p + sv : s \in \mathbb{R}\}$ be any line. Then
$$A(\ell) = \{(g(p+sv),\, 0, \dots, 0) : s \in \mathbb{R}\}.$$
Since $g|_\ell$ is surjective, $g(p+sv)$ ranges over all of $\mathbb{R}$, so
$$A(\ell) = \{(t, 0, \dots, 0) : t \in \mathbb{R}\},$$
which is the $x_1$-axis — a line. $\checkmark$

### $A$ is not affine

We show $A$ is **not injective**, which rules out affinity as follows. An affine
 map has the form $A(x) = Mx + b$ for a matrix $M$ and vector $b$. If $M$ is sin
gular, there exists $v \neq 0$ with $Mv = 0$, and the line $\{p + tv : t \in \ma
thbb{R}\}$ maps to the single point $\{Mp + b\}$ — not a line. So any affine map
 sending lines onto lines must have invertible $M$, hence be injective.

**$A$ is not injective:** Take any point $p \in \mathbb{R}^n$ and two distinct l
ines $\ell_1, \ell_2$ through $p$ (these exist since $n \geq 2$). Since $g|_{\el
l_1}$ and $g|_{\ell_2}$ are both surjective onto $\mathbb{R}$, and $\ell_1 \cap
\ell_2 = \{p\}$, we have:
$$g(\ell_1 \setminus \{p\}) = \mathbb{R} \setminus \{g(p)\} = g(\ell_2 \setminus
 \{p\}).$$
So there exist $q_1 \in \ell_1 \setminus \{p\}$ and $q_2 \in \ell_2 \setminus \{
p\}$ with $g(q_1) = g(q_2)$. Since $\ell_1 \cap \ell_2 = \{p\}$ and $q_1, q_2 \n
eq p$, we have $q_1 \neq q_2$, yet $A(q_1) = A(q_2)$. Thus $A$ is not injective.
 $\checkmark$

Since $A$ is not injective, it cannot be an affine transformation (as any affine
 transformation mapping lines onto lines must be injective). Therefore $A$ is a
non-affine map that sends lines onto lines.

## Conclusion

For every integer $n > 1$, there exists a map $A: \mathbb{R}^n \to \mathbb{R}^n$
 that maps lines onto lines but is **not** an affine transformation. The conditi
on "maps lines onto lines" does **not** imply affinity, because it does not forc
e injectivity — a map can collapse all of $\mathbb{R}^n$ onto a single line whil
e still sending every line surjectively onto that line.

**Remark.** If one additionally requires $A$ to be injective, then the answer be
comes **yes**: an injective collineation of $\mathbb{R}^n$ ($n \geq 2$) is affin
e by the fundamental theorem of affine geometry (since $\mathbb{R}$ has no nontr
ivial field automorphisms, every semiaffine collineation is affine). The key poi
nt is that without injectivity, the theorem fails.
