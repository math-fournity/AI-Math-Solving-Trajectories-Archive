# 解答

## 问题

求所有正整数 $n$，使得集合 $S = \{1, 2, \ldots, n\}$ 可以染成红色和蓝色，满足：$S \times S \times S$ 中恰好有 2007 个有序三元组 $(x, y, z)$，使得 (i) $x, y, z$ 同色，且 (ii) $x + y + z$ 被 $n$ 整除。

## 答案

$$\boxed{n \in \{69, \, 84\}}$$

---

## 证明

### 第一步：建立计数公式

将 $S = \{1, 2, \ldots, n\}$ 等同于 $\mathbb{Z}/n\mathbb{Z}$（其中 $n \equiv 0$）。设红色元素集合为 $R$，蓝色元素集合为 $B$，记 $|R| = r$，$|B| = b$，则 $r + b = n$。

定义 $f: \mathbb{Z}/n\mathbb{Z} \to \{0, 1\}$ 为红色的指示函数，$g = 1 - f$ 为蓝色的指示函数。

同色三元组的数量为

$$N = \sum_{\substack{x+y+z \equiv 0 \pmod{n}}} \bigl[f(x)f(y)f(z) + g(x)g(y)g(z)\bigr].$$

### 第二步：Fourier 分析

定义离散 Fourier 变换 $\hat{h}(k) = \sum_{x \in \mathbb{Z}/n\mathbb{Z}} h(x)\,\omega^{kx}$，其中 $\omega = e^{2\pi i/n}$。

利用指示函数 $\mathbf{1}_{x+y+z \equiv 0} = \frac{1}{n}\sum_{k=0}^{n-1} \omega^{k(x+y+z)}$，得

$$N_R = \sum_{x+y+z \equiv 0} f(x)f(y)f(z) = \frac{1}{n}\sum_{k=0}^{n-1} \hat{f}(k)^3,$$

$$N_B = \sum_{x+y+z \equiv 0} g(x)g(y)g(z) = \frac{1}{n}\sum_{k=0}^{n-1} \hat{g}(k)^3.$$

### 第三步：关键消元

计算 $\hat{g}(k)$：

- 当 $k = 0$ 时：$\hat{g}(0) = \sum_x g(x) = b$，$\hat{f}(0) = r$。
- 当 $k \neq 0$ 时：$\hat{g}(k) = \sum_x (1 - f(x))\,\omega^{kx} = \sum_x \omega^{kx} - \hat{f}(k) = 0 - \hat{f}(k) = -\hat{f}(k)$。

（此处用到 $\{1, \ldots, n\}$ 是 $\mathbb{Z}/n\mathbb{Z}$ 的完全剩余系，故 $k \neq 0$ 时 $\sum_x \omega^{kx} = 0$。）

因此

$$N_B = \frac{1}{n}\left[b^3 + \sum_{k=1}^{n-1} \bigl(-\hat{f}(k)\bigr)^3\right] = \frac{1}{n}\left[b^3 - \sum_{k=1}^{n-1} \hat{f}(k)^3\right],$$

$$N_R = \frac{1}{n}\left[r^3 + \sum_{k=1}^{n-1} \hat{f}(k)^3\right].$$

两式相加，**非零频率的 Fourier 系数完全抵消**：

$$\boxed{N = N_R + N_B = \frac{r^3 + b^3}{n}.}$$

**这个结果与具体的着色方式无关**——任何具有 $r$ 个红色、$b$ 个蓝色的着色都给出相同的 $N$。

### 第四步：化简方程

利用 $r^3 + b^3 = (r+b)(r^2 - rb + b^2) = n(r^2 - rb + b^2)$，得

$$N = r^2 - rb + b^2.$$

又 $r^2 - rb + b^2 = (r+b)^2 - 3rb = n^2 - 3rb$，故

$$N = n^2 - 3rb = 2007 \quad \Longrightarrow \quad rb = \frac{n^2 - 2007}{3}.$$

### 第五步：推导必要条件

1. **$rb \geq 0$**：需 $n^2 \geq 2007$，即 $n \geq 45$（因 $44^2 = 1936 < 2007$，$45^2 = 2025 > 2007$）。

2. **$rb$ 为整数**：需 $3 \mid (n^2 - 2007)$。因 $2007 = 3 \times 669$，即 $3 \mid n^2$，故 $3 \mid n$。

3. **$r, b$ 为实数**（从而才可能为整数）：$r, b$ 是方程 $t^2 - nt + rb = 0$ 的根，判别式

$$\Delta = n^2 - 4 \cdot \frac{n^2 - 2007}{3} = \frac{8028 - n^2}{3} \geq 0,$$

故 $n^2 \leq 8028$，即 $n \leq 89$（因 $89^2 = 7921$，$90^2 = 8100 > 8028$）。

### 第六步：求解 Diophantine 方程

设 $n = 3m$（$m$ 为正整数），则

$$\Delta = \frac{8028 - 9m^2}{3} = 2676 - 3m^2.$$

需 $2676 - 3m^2$ 为完全平方数。设 $2676 - 3m^2 = s^2$（$s \geq 0$），即

$$s^2 + 3m^2 = 2676.$$

由条件 $45 \leq n \leq 89$ 得 $15 \leq m \leq 29$。

逐一检查 $m = 15, 16, \ldots, 29$，计算 $2676 - 3m^2$ 是否为完全平方数：

| $m$ | $n=3m$ | $2676-3m^2$ | $\lfloor\sqrt{\cdot}\rfloor$ | 完全平方？ |
|-----|--------|-------------|------------------------------|-----------|
| 15  | 45     | 2001        | 44                           | 否        |
| 16  | 48     | 1908        | 43                           | 否        |
| 17  | 51     | 1809        | 42                           | 否        |
| 18  | 54     | 1704        | 41                           | 否        |
| 19  | 57     | 1593        | 39                           | 否        |
| 20  | 60     | 1476        | 38                           | 否        |
| 21  | 63     | 1353        | 36                           | 否        |
| 22  | 66     | 1224        | 34                           | 否        |
| **23**  | **69**     | **1089**     | **33**                           | **是** ($33^2=1089$)        |
| 24  | 72     | 948         | 30                           | 否        |
| 25  | 75     | 801         | 28                           | 否        |
| 26  | 78     | 648         | 25                           | 否        |
| 27  | 81     | 489         | 22                           | 否        |
| **28**  | **84**     | **324**      | **18**                           | **是** ($18^2=324$)        |
| 29  | 87     | 153         | 12                           | 否        |

仅有两个解：

- **$m = 23$，$n = 69$**：$s = 33$，$r = \frac{69+33}{2} = 51$，$b = 18$。
  - 验证：$51^2 - 51 \times 18 + 18^2 = 2601 - 918 + 324 = 2007$。✓

- **$m = 28$，$n = 84$**：$s = 18$，$r = \frac{84+18}{2} = 51$，$b = 33$。
  - 验证：$51^2 - 51 \times 33 + 33^2 = 2601 - 1683 + 1089 = 2007$。✓

（$r$ 与 $b$ 互换给出等价的着色，不产生新的 $n$。）

### 第七步：验证充分性

对于 $n = 69$：任取 $S$ 中 51 个元素染红、18 个染蓝。由第三步的公式，同色三元组数恰好为 $\frac{51^3 + 18^3}{69} = \frac{132651 + 5832}{69} = \frac{138483}{69} = 2007$。

对于 $n = 84$：任取 $S$ 中 51 个元素染红、33 个染蓝。同色三元组数为 $\frac{51^3 + 33^3}{84} = \frac{132651 + 35937}{84} = \frac{168588}{84} = 2007$。

两种情况下着色均存在（只需任意选取相应数量的元素着色即可），且计数与着色方式无关。

### 第八步：排除其他可能

- $n$ 不是 3 的倍数时，$rb = \frac{n^2-2007}{3}$ 不是整数，无解。
- $n < 45$ 时 $rb < 0$，无解。
- $n > 89$ 时判别式 $\Delta < 0$，无实数解。
- 在 $45 \leq n \leq 89$ 且 $3 \mid n$ 的 15 个候选值中，逐一检验后仅 $n = 69$ 和 $n = 84$ 使判别式为完全平方数。

## 结论

满足条件的正整数 $n$ 为

$$\boxed{n = 69 \quad \text{和} \quad n = 84.}$$

**QED**
