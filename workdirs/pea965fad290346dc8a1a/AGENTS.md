# Problem

In the city of Arithmos, the Central Bank issues 11-digit identification codes for high-security vaults. These codes are formed using digits $0$ through $9$, and the first digit must always be non-zero. 

Two codes are considered "compositionally identical" if they contain the exact same set of eleven digits, regardless of the order (provided the first digit of both is non-zero).

A vault code $K$ is designated as "Standard" if it satisfies the following security protocols:
1. It is divisible by 2.
2. It is divisible by 3.
3. It is divisible by 5.

A vault code $K$ is designated as "Elite-Compatible" if there exists at least one code $K'$ that is compositionally identical to $K$, and $K'$ satisfies a different set of protocols: $K'$ must be divisible by 7, 11, 13, 17, 101, and 9901.

How many 11-digit vault codes $K$ exist that are both "Standard" and "Elite-Compatible"?
