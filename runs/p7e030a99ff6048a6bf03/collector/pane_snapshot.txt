We show that $J$ is continuous and $\|J\| = 1$.

### Step 1: $l^1(\mathbb{N}) \subseteq l^2(\mathbb{N})$ with $\|\xi\|_2 \le \|\x
i\|_1$

Let $\xi \in l^1(\mathbb{N})$, so $\|\xi\|_1 = \sum_{n=1}^\infty |\xi(n)| < \inf
ty$. In particular $|\xi(n)| \to 0$, so for all sufficiently large $n$, $|\xi(n)
| \le 1$, hence $|\xi(n)|^2 \le |\xi(n)|$. More directly, since $|\xi(n)| \le \|
\xi\|_1$ for every $n$,

$$|\xi(n)|^2 \le \|\xi\|_1 \cdot |\xi(n)|.$$

Summing over $n$:

$$\sum_{n=1}^\infty |\xi(n)|^2 \le \|\xi\|_1 \sum_{n=1}^\infty |\xi(n)| = \|\xi\
|_1^2.$$

Therefore $\|\xi\|_2 = \bigl(\sum |\xi(n)|^2\bigr)^{1/2} \le \|\xi\|_1 < \infty$
, so $\xi \in l^2(\mathbb{N})$. This confirms $J$ is well-defined as a map $l^1
\to l^2$.

### Step 2: $J$ is bounded (continuous) with $\|J\| \le 1$

The inequality $\|\xi\|_2 \le \|\xi\|_1$ established above means

$$\|J(\xi)\|_2 = \|\xi\|_2 \le \|\xi\|_1 \quad \text{for all } \xi \in l^1(\math
bb{N}).$$

Hence $J$ is a bounded linear operator with operator norm

$$\|J\| = \sup_{\|\xi\|_1 = 1} \|J(\xi)\|_2 \le 1.$$

### Step 3: $\|J\| \ge 1$ (norm is attained)

Consider the standard basis vector $e_1 = (1, 0, 0, \ldots) \in l^1(\mathbb{N})$
. Then

$$\|e_1\|_1 = 1, \qquad \|J(e_1)\|_2 = \|e_1\|_2 = 1.$$

Therefore

$$\|J\| = \sup_{\|\xi\|_1=1}\|\xi\|_2 \ge \|J(e_1)\|_2 = 1.$$

### Conclusion

Combining Steps 2 and 3:

$$\boxed{\|J\| = 1}.$$

The map $J: l^1(\mathbb{N}) \to l^2(\mathbb{N})$, $J(\xi)=\xi$, is continuous (b
ounded), and its operator norm is $1$. The norm is attained at any standard basi
s vector $e_k$.
