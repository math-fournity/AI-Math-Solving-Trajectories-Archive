## Proof

**Key Observation: $M_n$ is a circulant matrix.**

Index rows and columns by $0, 1, \ldots, 2n$. Define $c_k$ for $k = 1, \ldots, 2
n$ by $c_k = 1$ if $1 \le k \le n$ and $c_k = -1$ if $n+1 \le k \le 2n$. Then fo
r $i > j$, $M_n[i,j] = c_{i-j}$, and for $i < j$, $M_n[i,j] = -c_{j-i}$.

**Claim:** $c_{2n+1-k} = -c_k$ for all $k = 1, \ldots, 2n$.

*Proof of claim:* If $1 \le k \le n$, then $n+1 \le 2n+1-k \le 2n$, so $c_{2n+1-
k} = -1 = -c_k$. If $n+1 \le k \le 2n$, then $1 \le 2n+1-k \le n$, so $c_{2n+1-k
} = 1 = -c_k$. ✓

Now set $a_0 = 0$ and $a_k = -c_k$ for $k = 1, \ldots, 2n$. Consider the circula
nt matrix $C$ with first row $(a_0, a_1, \ldots, a_{2n})$, i.e., $C[i,j] = a_{(j
-i) \bmod (2n+1)}$.

- **Case $i > j$:** $C[i,j] = a_{(j-i)\bmod(2n+1)} = a_{2n+1-(i-j)} = -c_{2n+1-(
i-j)} = -(-(c_{i-j})) = c_{i-j} = M_n[i,j]$. ✓
- **Case $i < j$:** $C[i,j] = a_{j-i} = -c_{j-i} = M_n[i,j]$. ✓
- **Case $i = j$:** Both are $0$. ✓

Therefore $M_n = C$ is a circulant matrix.

**Eigenvalue computation.** The eigenvalues of a circulant matrix of size $m = 2
n+1$ with first row $(a_0, \ldots, a_{m-1})$ are
$$\lambda_j = \sum_{k=0}^{m-1} a_k \, \omega^{jk}, \quad j = 0, 1, \ldots, m-1,$
$
where $\omega = e^{2\pi i/m}$. Substituting:
$$\lambda_j = -\sum_{k=1}^{n} \omega^{jk} + \sum_{k=n+1}^{2n} \omega^{jk}.$$

For $j = 0$: $\lambda_0 = -n + n = 0$.

For $j \neq 0$: Using $\sum_{k=0}^{2n} \omega^{jk} = 0$, we split:
$$0 = 1 + \sum_{k=1}^{n} \omega^{jk} + \sum_{k=n+1}^{2n} \omega^{jk}.$$
Setting $S_j = \sum_{k=1}^{n} \omega^{jk}$ and noting $\sum_{k=n+1}^{2n} \omega^
{jk} = \omega^{jn} S_j$, we get $1 + S_j(1 + \omega^{jn}) = 0$, so $S_j = \frac{
-1}{1+\omega^{jn}}$. Therefore:
$$\lambda_j = -S_j + \omega^{jn} S_j = S_j(\omega^{jn} - 1) = \frac{-1}{1+\omega
^{jn}} \cdot (\omega^{jn}-1) = \frac{1 - \omega^{jn}}{1 + \omega^{jn}}.$$

**Counting zero eigenvalues.** For $j = 1, \ldots, 2n$:

- **Numerator zero:** $1 - \omega^{jn} = 0 \iff \omega^{jn} = 1 \iff (2n+1) \mid
 jn$. Since $\gcd(n, 2n+1) = \gcd(n, 1) = 1$, this requires $(2n+1) \mid j$, whi
ch is impossible for $1 \le j \le 2n$.

- **Denominator zero:** $1 + \omega^{jn} = 0 \iff \omega^{jn} = -1 \iff \omega^{
2jn} = 1 \iff (2n+1) \mid 2jn$. Since $\gcd(2n, 2n+1) = 1$ and $\gcd(n, 2n+1) =
1$, this again requires $(2n+1) \mid j$, impossible for $1 \le j \le 2n$.

Therefore $\lambda_j \neq 0$ for all $j = 1, \ldots, 2n$.

**Conclusion.** Exactly one eigenvalue ($\lambda_0 = 0$) is zero, and the remain
ing $2n$ eigenvalues are nonzero. The rank of $M_n$ equals the number of nonzero
 eigenvalues:

$$\operatorname{rank}(M_n) = 2n.$$

**Verification with $M_1$:** Here $n=1$, $m=3$, $\omega = e^{2\pi i/3}$. We get
$\lambda_0 = 0$ and $\lambda_1 = \frac{1-\omega}{1+\omega} = -i\sqrt{3} \neq 0$,
 $\lambda_2 = \overline{\lambda_1} = i\sqrt{3} \neq 0$. Rank $= 2 = 2(1)$. ✓
