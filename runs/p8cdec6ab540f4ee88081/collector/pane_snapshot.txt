Solution

Problem Restatement

Define two sequences using Knuth's up-arrow notation:

  • Graham sequence: $G_1 = 3 \uparrow^4 3$, $;G_{k+1} = 3 \uparrow^{G_k} 3$, up
  to $G_{64}$.
  • H-sequence: $H_1 = 4 \uparrow^4 4$, $;H_{k+1} = 4 \uparrow^{H_k} 4$.

Find the smallest index $n$ such that $H_n > G_n$.

Key Property of Up-Arrow Notation

For integers $a \geq 2$, $b \geq 2$, $k \geq 1$, the expression $a \uparrow^k b$
is strictly increasing in each of its three arguments $a$, $b$, and $k$.

Proof sketch: The recursion is $a \uparrow^1 b = a^b$ (clearly increasing in $a$
and $b$), and $a \uparrow^k b = a \uparrow^{k-1}(a \uparrow^k (b-1))$ with $a
\uparrow^k 1 = a$. By induction on $(k, b)$ in lexicographic order, strict
monotonicity in all three arguments follows directly from the recursive
structure: increasing $a$ increases every sub-computation; increasing $b$ adds
more iterations of the outer function; increasing $k$ replaces each $
\uparrow^{k-1}$ with a strictly larger $\uparrow^k$-based tower.

Base Case: $n = 1$

$$H_1 = 4 \uparrow^4 4, \qquad G_1 = 3 \uparrow^4 3.$$

Both use the same number of arrows ($k = 4$). Applying monotonicity:

$$4 \uparrow^4 4 ;>; 3 \uparrow^4 4 ;>; 3 \uparrow^4 3,$$

where the first inequality uses the larger base ($4 > 3$) and the second uses
the larger right argument ($4 > 3$). Therefore:

$$H_1 > G_1. \qquad \checkmark$$

Inductive Step

Claim: $H_n > G_n$ for all $n \geq 1$.

Induction hypothesis: Suppose $H_n > G_n$ for some $n \geq 1$.

Then: $$H_{n+1} = 4 \uparrow^{H_n} 4, \qquad G_{n+1} = 3 \uparrow^{G_n} 3.$$

We compare the three arguments of the up-arrow operator:

┌───────────┬───────────┬───────────┬──────────────────────┐
│ Argument  │ $H_{n+1}$ │ $G_{n+1}$ │ Relation             │
├───────────┼───────────┼───────────┼──────────────────────┤
│ Base      │ $4$       │ $3$       │ $4 > 3$              │
├───────────┼───────────┼───────────┼──────────────────────┤
│ Arrows    │ $H_n$     │ $G_n$     │ $H_n > G_n$ (by IH)  │
├───────────┼───────────┼───────────┼──────────────────────┤
│ Right arg │ $4$       │ $3$       │ $4 > 3$              │
└───────────┴───────────┴───────────┴──────────────────────┘

By strict monotonicity in all three arguments simultaneously:

$$H_{n+1} = 4 \uparrow^{H_n} 4 ;>; 3 \uparrow^{G_n} 3 = G_{n+1}.$$

Conclusion

  • Base case: $H_1 > G_1$ (both base and right argument are larger, same number
  of arrows).
  • Inductive step: If $H_n > G_n$, then $H_{n+1} > G_{n+1}$ (all three up-arrow
  arguments are simultaneously larger).

By induction, $H_n > G_n$ for every $n \geq 1$. The sequence $H_n$ is greater
than $G_n$ starting from the very first index.

$$\boxed{n = 1}$$
