## Answer

**No**, the statement is not true in general. Here is a counterexample.

---

**Counterexample.** Define

$$A = \{0\} \cup [1,2], \qquad B = \{0\} \cup [1,2].$$

Both $A$ and $B$ are closed subsets of $\mathbb{R}$ (a finite union of closed se
ts), and both have positive Lebesgue measure: $\lambda(A) = \lambda([1,2]) = 1$
and $\lambda(B) = 1$.

Set $I = A \times B$ and let $E = \{(0,0)\}$, which is a single point and hence
has two-dimensional Lebesgue measure zero.

**Claim.** $(0,0) \in I$ but $(0,0) \notin \overline{I \setminus E}$, so $\overl
ine{I \setminus E} \neq I$.

*Proof of claim.* Clearly $(0,0) \in A \times B = I$.

Now take any $\varepsilon$ with $0 < \varepsilon < 1$. Consider the open square
$U = (-\varepsilon, \varepsilon) \times (-\varepsilon, \varepsilon)$, which is a
n open neighborhood of $(0,0)$. Since $\varepsilon < 1$,

$$(-\varepsilon, \varepsilon) \cap A = \{0\}, \qquad (-\varepsilon, \varepsilon)
 \cap B = \{0\}.$$

Therefore

$$U \cap I = \bigl((-\varepsilon,\varepsilon)\cap A\bigr) \times \bigl((-\vareps
ilon,\varepsilon)\cap B\bigr) = \{0\}\times\{0\} = \{(0,0)\}.$$

Removing $E = \{(0,0)\}$ gives

$$U \cap (I \setminus E) = \{(0,0)\} \setminus \{(0,0)\} = \emptyset.$$

Since every open neighborhood of $(0,0)$ (every such neighborhood contains some
$U$ of the above form) has empty intersection with $I \setminus E$, the point $(
0,0)$ is not in the closure of $I \setminus E$:

$$(0,0) \notin \overline{I \setminus E}.$$

Yet $(0,0) \in I$, so $\overline{I \setminus E} \neq I$. $\square$

---

**Remark on why the statement fails.** The inclusion $\overline{I\setminus E}\su
bseteq I$ always holds (since $I$ is closed and $I\setminus E\subseteq I$). The
reverse inclusion $I\subseteq\overline{I\setminus E}$ requires that every point
of $I$ be a limit point of $I\setminus E$. A point $p=(a,b)\in I$ is guaranteed
to be such a limit point only when $I$ has *positive local measure* at $p$—i.e.,
 every neighborhood of $p$ meets $I$ in a set of positive two-dimensional measur
e—for then that positive-measure piece cannot be swallowed by the null set $E$.
But a closed set of positive measure need not have positive local measure at eve
ry point: it can have isolated points (as $\{0\}$ in the example above), and at
an isolated point $I$ is locally a single point of measure zero, which a null se
t $E$ can entirely remove.
