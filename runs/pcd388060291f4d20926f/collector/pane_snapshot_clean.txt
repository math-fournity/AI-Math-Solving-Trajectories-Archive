## 证明

设 $a < b < c < d$ 为正整数，其中每三个不同的数都能构成一个钝角三角形。

**建立充分条件。** 对于满足 $x < y < z$ 的任意三元组 $(x,y,z)$，构成钝角三角形需
要：
- 三角形不等式：$x + y > z$
- 钝角条件：$z^2 > x^2 + y^2$

这四个三元组分别为 $(a,b,c), (a,b,d), (a,c,d), (b,c,d)$。

**三角形不等式。** 最严格的是 $a + b > d$，因为 $a+b \le a+c \le b+c$ 且 $d \ge
c$。此条件蕴含了所有其他条件（$a+b > d > c$; $a+c > a+b > d$; $b+c > a+c > d$）
。

**钝角条件。** 我们需要 $c^2 > a^2+b^2$（对于 $(a,b,c)$）和 $d^2 > b^2+c^2$（对
于 $(b,c,d)$）。后者蕴含了 $d^2 > a^2+c^2$（因为 $a < b$）和 $d^2 > a^2+b^2$（因
为 $c > b$）。前者结合 $d > c$ 蕴含了 $d^2 > a^2+b^2$。因此，必要和充分条件为：
1. $a + b > d$
2. $c^2 > a^2 + b^2$
3. $d^2 > b^2 + c^2$

**下界：$d \ge 14$。** 我们证明 $d \le 13$ 是不可能的。

由 (1) 得：$a + b \ge d + 1$。因为 $a < b$，我们得到 $2b > a+b \ge d+1$，所以 $b
 \ge \lceil (d+2)/2 \rceil$。

对于 $d = 13$：$a + b \ge 14$ 且 $a < b$，所以 $b \ge 8$。由 (3) 得：$b^2 + c^2
\le 168$，且 $c \ge b+1$。

- **$b = 8$：** $c^2 \le 104$，所以 $c \le 10$。由 (2) 得：$a^2 + 64 < c^2 \le 1
00$，所以 $a^2 < 36$，$a \le 5$。但 $a + b \ge 14$ 要求 $a \ge 6$。矛盾。
- **$b = 9$：** $c^2 \le 87$，所以 $c \le 9$，但 $c > b = 9$。矛盾。
- **$b \ge 10$：** $c \ge 11$，所以 $b^2 + c^2 \ge 100 + 121 = 221 > 168$。矛盾
。

因此 $d = 13$ 是不可能的，即得 $d \ge 14$。

**可达性：$d = 14$。** 取 $(a, b, c, d) = (7, 8, 11, 14)$：
- $a + b = 15 > 14 = d$ ✓
- $c^2 = 121 > 49 + 64 = 113 = a^2 + b^2$ ✓
- $d^2 = 196 > 64 + 121 = 185 = b^2 + c^2$ ✓

所有四个三元组均构成钝角三角形：
- $(7, 8, 11)$：$121 > 113$ ✓
- $(7, 8, 14)$：$196 > 113$ ✓
- $(7, 11, 14)$：$196 > 170$ ✓
- $(8, 11, 14)$：$196 > 185$ ✓

因此，$d$ 的最小值为 $\boxed{14}$。
