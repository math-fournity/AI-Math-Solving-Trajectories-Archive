## Solution

**Step 1: Set up the conformal map.**

Let $z = x + iy$ denote points in the upper half-plane $\mathbb{H} = \{z : \oper
atorname{Im} z > 0\}$. Consider the conformal map
$$w = z^{1/2},$$
using the principal branch (with $0 < \arg z < \pi$ in $\mathbb{H}$). This maps
$\mathbb{H}$ conformally onto the first quadrant $Q = \{w : \operatorname{Re} w
> 0,\; \operatorname{Im} w > 0\}$, since $\arg w = \tfrac{1}{2}\arg z \in (0, \p
i/2)$.

Under this map:
- The positive real axis $\{x > 0, y = 0\}$ (where $\arg z = 0$) maps to the pos
itive real axis $\{w = s > 0\}$ in the $w$-plane, with $s = x^{1/2}$.
- The negative real axis $\{x < 0, y = 0\}$ (where $\arg z = \pi$) maps to the p
ositive imaginary axis $\{w = it,\; t > 0\}$ in the $w$-plane, with $t = |x|^{1/
2}$.

**Step 2: Transform the boundary value problem.**

Define $U(w) = u(z)$ where $w = z^{1/2}$ (equivalently $z = w^2$). Since $z \map
sto z^{1/2}$ is conformal, $U$ is harmonic in $Q$ whenever $u$ is harmonic in $\
mathbb{H}$, and vice versa.

On the real axis of the $w$-plane ($w = s > 0$): here $z = s^2 > 0$, so the give
n boundary condition yields
$$U(s, 0) = u(s^2, 0) = (s^2)^{1/2} = s, \qquad s > 0.$$

On the imaginary axis of the $w$-plane ($w = it,\; t > 0$): here $z = (it)^2 = -
t^2 < 0$, and
$$U(0, t) = u(-t^2, 0), \qquad t > 0,$$
which is the quantity we need to determine.

**Step 3: Solve the Dirichlet problem in the first quadrant.**

We need a harmonic function $U$ on $Q$ with $U(s,0) = s$ for $s > 0$. The functi
on
$$U(w) = \operatorname{Re}(w)$$
is harmonic (being the real part of the analytic function $w$) and satisfies $U(
s, 0) = s$ on the positive real axis. By the uniqueness of the solution to the D
irichlet problem on the quadrant (with bounded, continuous boundary data), this
is the solution.

Evaluating on the imaginary axis:
$$U(0, t) = \operatorname{Re}(it) = 0, \qquad t > 0.$$

**Step 4: Recover $u$ and the boundary values for $x < 0$.**

Since $U(0, t) = 0$ for all $t > 0$, and $U(0,t) = u(-t^2, 0)$, we obtain
$$u(x, 0) = 0 \qquad \text{for all } x < 0.$$

The solution itself is $u(x,y) = \operatorname{Re}(z^{1/2})$. Writing $z = re^{i
\theta}$ with $r = \sqrt{x^2+y^2}$ and $\theta = \arg z \in (0,\pi)$:
$$u(x,y) = r^{1/2}\cos\!\left(\tfrac{\theta}{2}\right) = \sqrt{\frac{\sqrt{x^2+y
^2}+x}{2}}.$$

**Verification.** On $y = 0$, $x > 0$: $r = x$, $\theta = 0$, so $u = \sqrt{x}\c
os 0 = x^{1/2}$. ✓
On $y = 0$, $x < 0$: $r = |x|$, $\theta = \pi$, so $u = |x|^{1/2}\cos(\pi/2) = 0
$. ✓
Harmonicity holds since $u = \operatorname{Re}(z^{1/2})$ and $z^{1/2}$ is analyt
ic on $\mathbb{H}$.

**Conclusion.**

The solution is
$$\boxed{u(x,y) = \operatorname{Re}\!\left((x+iy)^{1/2}\right) = \sqrt{\frac{\sq
rt{x^2+y^2}+x}{2}}},$$
and the boundary values on the negative real axis are
$$\boxed{u(x,0) = 0 \quad \text{for } -\infty < x < 0.}$$
