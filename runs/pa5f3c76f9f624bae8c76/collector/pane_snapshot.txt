## Solution

**Setting up the equations.** We need positive integers $a, b, c$ such that:
- **Geometric progression:** $b^2 = ac$ (constant ratio $b/a = c/b$).
- **Arithmetic progression after adding 1 to the middle:** $a, b+1, c$ form an A
P, so $a + c = 2(b+1) = 2b+2$.

**Solving the system.** From $a + c = 2b+2$ and $b^2 = ac$, the values $a, c$ ar
e roots of:
$$t^2 - (2b+2)t + b^2 = 0$$

The discriminant is:
$$(2b+2)^2 - 4b^2 = 8b+4 = 4(2b+1)$$

For $a, c$ to be positive integers, $2b+1$ must be a **perfect square**. Set $2b
+1 = s^2$ with $s$ a positive odd integer ($s \geq 3$). Then:
$$b = \frac{s^2-1}{2}, \quad a = \frac{(s-1)^2}{2}, \quad c = \frac{(s+1)^2}{2}$
$

Since $s$ is odd, $(s\pm1)^2$ is divisible by 4, so $a, c$ are integers. Writing
 $s = 2k+1$ for $k = 1, 2, 3, \ldots$:
$$a = 2k^2, \quad b = 2k(k+1), \quad c = 2(k+1)^2$$

**Verification.**
- GP: $b^2 = 4k^2(k+1)^2 = [2k^2]\cdot[2(k+1)^2] = ac$. ✓
- AP: $a + c = 2k^2 + 2(k+1)^2 = 4k^2+4k+2 = 2(2k^2+2k+1) = 2(b+1)$. ✓

**The first three sets (ordered by increasing $a$):**

| $k$ | $a$ | $b$ | $c$ | GP ratio | AP check |
|-----|-----|-----|-----|----------|----------|
| 1 | 2 | 4 | 8 | 2 | $2, 5, 8$ (diff 3) ✓ |
| 2 | 8 | 12 | 18 | $3/2$ | $8, 13, 18$ (diff 5) ✓ |
| 3 | 18 | 24 | 32 | $4/3$ | $18, 25, 32$ (diff 7) ✓ |

Since $a_n = 2n^2$:
$$a_1 + a_2 + a_3 = 2 + 8 + 18 = \boxed{28}$$
