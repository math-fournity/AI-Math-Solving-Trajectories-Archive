## Proof

**Key technique (padding).** Given n integers a₁,...,aₙ with sum = product = n,
let b₁,...,b_r be those with |bᵢ| ≥ 2, let p = # of 1's, q = # of (−1)'s. Then:
- p + q + r = n
- p − q + Σbᵢ = n, giving **Σbᵢ = 2q + r**
- (−1)^q · ∏bᵢ = n

So q = (Σbᵢ − r)/2 must be a **non-negative integer**, requiring Σbᵢ − r even (e
quivalently, the number of even bᵢ is even), and the sign condition (−1)^q·∏bᵢ =
 n must hold, with q + r ≤ n.
