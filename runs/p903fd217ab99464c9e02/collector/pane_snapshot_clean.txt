# Cardinality of the Set of All Partitions of ℕ

**Answer:** The set of all partitions of ℕ has cardinality $2^{\aleph_0}$ (the c
ardinality of the continuum).

---

## Proof

Let $\Pi$ denote the set of all partitions of $\mathbb{N}$. We establish $|\Pi|
= 2^{\aleph_0}$ by proving both inequalities.

### Upper bound: $|\Pi| \leq 2^{\aleph_0}$

Every partition $\mathcal{P}$ of $\mathbb{N}$ can be encoded by a function $f_{\
mathcal{P}} : \mathbb{N} \to \mathbb{N}$ that assigns to each $n \in \mathbb{N}$
 the index (a natural number) of the block containing $n$. Concretely, enumerate
 the blocks of $\mathcal{P}$ as $B_0, B_1, B_2, \dots$ (possible since $\mathcal
{P}$ is countable, being a collection of disjoint nonempty subsets of $\mathbb{N
}$, each with a least element providing an injection $\mathcal{P} \hookrightarro
w \mathbb{N}$), and set $f_{\mathcal{P}}(n) = k$ where $n \in B_k$.

The map $\mathcal{P} \mapsto f_{\mathcal{P}}$ is injective: two partitions with
the same encoding function have the same blocks (the block of $n$ is $\{m : f(m)
 = f(n)\}$). Hence

$$|\Pi| \leq |\mathbb{N}^{\mathbb{N}}| = \aleph_0^{\aleph_0}.$$

Now $\aleph_0^{\aleph_0} = 2^{\aleph_0}$, since:
- $2^{\aleph_0} \leq \aleph_0^{\aleph_0}$ (as $2 \leq \aleph_0$), and
- $\aleph_0^{\aleph_0} \leq (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0 \cdot \aleph
_0} = 2^{\aleph_0}$.

Therefore $|\Pi| \leq 2^{\aleph_0}$.

### Lower bound: $|\Pi| \geq 2^{\aleph_0}$

We construct an injection $2^{\mathbb{N}} \hookrightarrow \Pi$. Partition $\math
bb{N}$ into the disjoint pairs $P_n = \{2n,\, 2n+1\}$ for $n = 0, 1, 2, \dots$;
these pairs cover all of $\mathbb{N}$.

For each subset $A \subseteq \mathbb{N}$, define a partition $\mathcal{P}_A$ of
$\mathbb{N}$ by modifying each pair according to membership in $A$:

$$\mathcal{P}_A = \big\{\, \{2n,\, 2n+1\} : n \notin A \,\big\} \;\cup\; \big\{\
, \{2n\},\, \{2n+1\} : n \in A \,\big\}.$$

In words: pairs indexed by elements of $A$ are split into singletons; pairs inde
xed by elements outside $A$ are kept intact. This is a valid partition of $\math
bb{N}$ for every $A$.

The map $A \mapsto \mathcal{P}_A$ is injective: given $\mathcal{P}_A$, we recove
r $A$ as

$$A = \{\, n \in \mathbb{N} : \{2n\} \in \mathcal{P}_A \,\}.$$

Thus distinct subsets $A$ yield distinct partitions, giving $|\Pi| \geq |2^{\mat
hbb{N}}| = 2^{\aleph_0}$.

### Conclusion

Combining both inequalities,

$$|\Pi| = 2^{\aleph_0}.$$

The set of all partitions of $\mathbb{N}$ has the cardinality of the continuum.
$\blacksquare$
