## Green's Function for the 2D Wave Equation

### Setup and reduction by translation invariance

Define shifted variables
$$t' = t - \tau, \qquad x' = x - \xi, \qquad y' = y - \eta, \qquad r = \sqrt{x'^
2 + y'^2}.$$
By translation invariance of the PDE and the boundary conditions, write
$$G(x,y,t\,|\,\xi,\eta,\tau) = g(x',y',t'),$$
where $g$ satisfies
$$g_{t't'} - c^2\,(g_{x'x'} + g_{y'y'}) = \delta(t')\,\delta(x')\,\delta(y'), \q
quad g = 0 \;\text{for}\; t' < 0, \qquad g \to 0 \;\text{as}\; r \to \infty.$$

### Spatial Fourier transform

Define $\tilde{g}(\mathbf{k},t') = \iint g(\mathbf{r},t')\,e^{-i\mathbf{k}\cdot\
mathbf{r}}\,d^2\mathbf{r}$, with $\mathbf{k}=(k_x,k_y)$ and $|\mathbf{k}|=\rho$.
 The PDE transforms to
$$\tilde{g}_{t't'} + c^2\rho^2\,\tilde{g} = \delta(t').$$

For $t'<0$, causality gives $\tilde{g}=0$. Integrating across $t'=0$ yields the
jump condition $\tilde{g}_{t'}\big|_{0^-}^{0^+}=1$, while $\tilde{g}$ itself is
continuous: $\tilde{g}(\mathbf{k},0^+)=0$. For $t'>0$ the ODE is homogeneous, so
$$\boxed{\tilde{g}(\mathbf{k},t') = \frac{\sin(c\rho\, t')}{c\,\rho}\,H(t'), \qq
uad \rho = |\mathbf{k}|.}$$

### Inverse Fourier transform

$$g(\mathbf{r},t') = \frac{H(t')}{(2\pi)^2}\iint_{\mathbb{R}^2} \frac{\sin(c\rho
\,t')}{c\,\rho}\,e^{i\mathbf{k}\cdot\mathbf{r}}\,d^2\mathbf{k}.$$

Switch to polar coordinates $(\rho,\theta)$ for $\mathbf{k}$ and align the angul
ar origin with $\mathbf{r}$ (using $r=|\mathbf{r}|$):
$$g(\mathbf{r},t') = \frac{H(t')}{(2\pi)^2}\int_0^\infty\!\int_0^{2\pi} \frac{\s
in(c\rho\,t')}{c\,\rho}\,e^{i\rho r\cos\theta}\,\rho\,d\theta\,d\rho
= \frac{H(t')}{2\pi c}\int_0^\infty \sin(c\rho\,t')\,J_0(\rho r)\,d\rho,$$
where we used $\frac{1}{2\pi}\int_0^{2\pi}e^{i\rho r\cos\theta}\,d\theta = J_0(\
rho r)$.

### Evaluating the Weber–Schafheitlin integral

We evaluate $I(a,r) = \int_0^\infty J_0(\rho r)\,\sin(a\rho)\,d\rho$ with $a = c
\,t' > 0$. From the Laplace transform of $J_0$,
$$\int_0^\infty J_0(\rho r)\,e^{-s\rho}\,d\rho = \frac{1}{\sqrt{s^2+r^2}}, \qqua
d \operatorname{Re}(s)>0.$$
Set $s = \varepsilon - ia$ with $\varepsilon\to 0^+$ (the causal prescription):
$$\int_0^\infty J_0(\rho r)\,e^{ia\rho}\,d\rho = \lim_{\varepsilon\to 0^+}\frac{
1}{\sqrt{(\varepsilon-ia)^2 + r^2}} = \lim_{\varepsilon\to 0^+}\frac{1}{\sqrt{(r
^2-a^2) - 2ia\varepsilon + \varepsilon^2}}.$$

**Case $r > a$:** $r^2 - a^2 > 0$; the small imaginary part is negligible. The s
quare root is real and positive, so the integral is real: $I(a,r) = 0$.

**Case $0 \le r < a$:** Writing $b = a^2 - r^2 > 0$, the argument is $z = -b - 2
ia\varepsilon$, lying in the third quadrant with $\arg z \to -\pi^+$. On the pri
ncipal branch, $\sqrt{z} \to \sqrt{b}\,e^{-i\pi/2} = -i\sqrt{b}$, hence
$$\frac{1}{\sqrt{z}} \to \frac{1}{-i\sqrt{b}} = \frac{i}{\sqrt{b}} = \frac{i}{\s
qrt{a^2 - r^2}}.$$
Taking the imaginary part: $I(a,r) = \dfrac{1}{\sqrt{a^2 - r^2}}$.

Combining (with a nonintegrable singularity at $r=a$, the wavefront):
$$\int_0^\infty J_0(\rho r)\,\sin(a\rho)\,d\rho = \frac{H(a - r)}{\sqrt{a^2 - r^
2}}, \qquad a > 0.$$

### Assembling the Green's function

Substituting $a = c\,t'$:
$$g(\mathbf{r},t') = \frac{H(t')\,H(c\,t' - r)}{2\pi c\,\sqrt{c^2 t'^2 - r^2}}.$
$

Returning to the original variables $(r = \sqrt{(x-\xi)^2+(y-\eta)^2},\; t' = t-
\tau)$:

$$\boxed{\;G(x,y,t\,|\,\xi,\eta,\tau) = \frac{H(t-\tau)\;H\!\Big(c(t-\tau) - \sq
rt{(x-\xi)^2+(y-\eta)^2}\Big)}{2\pi c\,\sqrt{\,c^2(t-\tau)^2 - (x-\xi)^2 - (y-\e
ta)^2\,}}\;}$$

### Verification

1. **Causality ($G=0$ for $t<\tau$):** The factor $H(t-\tau)$ vanishes. ✓

2. **Decay ($G\to 0$ as $x,y\to\pm\infty$):** For fixed $t>\tau$, once $r > c(t-
\tau)$ the factor $H(c(t-\tau)-r)=0$, so $G=0$ identically outside the light con
e. ✓

3. **Jump/source condition:** In Fourier space, $\tilde{g}(\mathbf{k},0^+)=0$ an
d $\tilde{g}_{t'}(\mathbf{k},0^+)=\cos(0)=1$, so $\tilde{g}_{t'}\big|_{0^-}^{0^+
} = 1 - 0 = 1$, reproducing the $\delta(t')$ impulse. The spatial $\delta(\mathb
f{r})$ is recovered because $\tilde{g}(\mathbf{k},t')\to \frac{\sin(c\rho t')}{c
\rho}\to t'$ as $\rho\to 0$ and the inverse transform of the constant $1$ in $\m
athbf{k}$-space gives $\delta(\mathbf{r})$ at $t'=0^+$. ✓

4. **PDE for $t'>\tau$, $r\neq$ wavefront:** Inside the cone ($r < ct'$), $G \pr
opto (c^2t'^2 - r^2)^{-1/2}$, which is the known free-space solution of the homo
geneous 2D wave equation (verifiable by direct substitution in polar coordinates
). ✓

5. **Support structure (Huygens principle in 2D):** Unlike the 3D case (where th
e Green's function lives only *on* the cone $r=ct'$), the 2D Green's function ha
s support throughout the *interior* of the cone $r < ct'$ — a hallmark of even-d
imensional wave propagation, consistent with Hadamard's method of descent from 3
D. ✓
