## Solution

We seek a non-zero function $f$ satisfying the delay differential equation

$$f'(x) = f(x-1).$$

**Ansatz.** Try $f(x) = e^{\lambda x}$ for some constant $\lambda$. Then

$$f'(x) = \lambda e^{\lambda x}, \qquad f(x-1) = e^{\lambda(x-1)} = e^{-\lambda}
e^{\lambda x}.$$

Substituting into the equation gives

$$\lambda e^{\lambda x} = e^{-\lambda} e^{\lambda x}.$$

Since $f$ is non-zero, $e^{\lambda x}\neq 0$, so we may divide through:

$$\lambda = e^{-\lambda}, \qquad\text{i.e.,}\qquad \lambda e^{\lambda} = 1.$$

**Existence of a real solution $\lambda$.** The equation $\lambda e^{\lambda}=1$
 is the defining equation for the **Lambert $W$ function**: $\lambda = W(1)$. Th
e function $g(\lambda)=\lambda e^{\lambda}$ is continuous, $g(0)=0$, and $g(1)=e
>1$, so by the intermediate value theorem there is a real root $\lambda_0\in(0,1
)$. (Numerically $\lambda_0 = W(1)\approx 0.5671$, the so-called Omega constant.
) Hence a real $\lambda_0$ satisfying $\lambda_0 = e^{-\lambda_0}$ exists.

**Verification.** Set $f(x) = e^{\lambda_0 x}$ with $\lambda_0 = W(1)$. Then

$$f'(x) = \lambda_0 e^{\lambda_0 x}, \qquad f(x-1) = e^{-\lambda_0}e^{\lambda_0
x} = \lambda_0 e^{\lambda_0 x},$$

where the last equality uses $\lambda_0 = e^{-\lambda_0}$. Thus $f'(x) = f(x-1)$
 for all $x\in\mathbb{R}$, and $f$ is clearly non-zero.

**Conclusion.** A non-zero function satisfying $\dfrac{d}{dx}f(x)=f(x-1)$ is

$$\boxed{f(x) = e^{W(1)\,x}},$$

where $W$ denotes the Lambert $W$ function (the unique real solution of $W(1)\,e
^{W(1)}=1$).
