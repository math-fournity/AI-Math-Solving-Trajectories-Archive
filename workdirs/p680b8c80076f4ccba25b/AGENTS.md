# Problem

A massive high-tech server farm is arranged in a rigid $100 \times 100$ grid of processing units. Each unit is currently processing a specific workload represented by a positive integer. 

The facility manager is looking for "optimal clusters," which are defined as any rectangular block of units where the total combined workload is exactly divisible by 17. The manager wants to run a diagnostic protocol on these clusters. 

The rules of the protocol are strict: you can select any number of these optimal clusters to run the diagnostic, provided that no two selected clusters overlap (meaning each individual processing unit can be included in, at most, one diagnostic group). 

Regardless of how the specific workload integers are distributed across the grid, there is a guaranteed minimum number of units, $d$, that can always be covered by a collection of non-overlapping optimal clusters. Find the maximum possible value of $d$.
