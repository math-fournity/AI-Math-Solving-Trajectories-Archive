## Proof

By the definition of the Radon–Nikodym derivative: a measure $\mathbb{P}_1$ is a
bsolutely continuous with respect to $\mathbb{P}_0$ (written $\mathbb{P}_1 \ll \
mathbb{P}_0$) if there exists a $\mathbb{P}_0$-measurable function $f : \Omega \
to [0,\infty)$ such that for every measurable set $A \subseteq \Omega$,

$$\mathbb{P}_1(A) = \int_A f \, d\mathbb{P}_0.$$

When such an $f$ exists, it is unique up to $\mathbb{P}_0$-null sets, and we wri
te

$$\frac{d\mathbb{P}_1}{d\mathbb{P}_0} = f.$$

**Given condition.** For every interval $[a,b] \subseteq \Omega = [0,1]$,

$$\mathbb{P}_1([a,b]) = \int_a^b (2\omega + 3)\, d\mathbb{P}_0(\omega).$$

**Identification.** Comparing the given formula with the defining relation of th
e Radon–Nikodym derivative, the integrand playing the role of $f$ is

$$f(\omega) = 2\omega + 3.$$

**Validity check.** The function $f(\omega) = 2\omega + 3$ is non-negative on $\
Omega = [0,1]$ (its minimum is $f(0) = 3 > 0$), continuous, hence $\mathbb{P}_0$
-measurable for any Borel measure $\mathbb{P}_0$ on $[0,1]$. Therefore it is a l
egitimate candidate for the density.

Since the relation $\mathbb{P}_1([a,b]) = \int_{[a,b]} f\,d\mathbb{P}_0$ holds o
n the class of closed intervals $[a,b] \subseteq [0,1]$, and this class is a $\p
i$-system generating the Borel $\sigma$-algebra $\mathcal{B}([0,1])$, the unique
ness theorem for measures (Dynkin's $\pi$-$\lambda$ theorem) extends the equalit
y to all Borel sets $A$:

$$\mathbb{P}_1(A) = \int_A (2\omega + 3)\, d\mathbb{P}_0(\omega), \qquad \forall
 A \in \mathcal{B}([0,1]).$$

This is precisely the defining relation of the Radon–Nikodym derivative. By uniq
ueness (up to $\mathbb{P}_0$-null sets), we conclude

$$\boxed{\dfrac{d\mathbb{P}_1}{d\mathbb{P}_0}(\omega) = 2\omega + 3.}$$
