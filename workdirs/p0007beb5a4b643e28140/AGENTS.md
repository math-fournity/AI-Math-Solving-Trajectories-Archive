# Problem

A specialized microchip architecture consists of two long, parallel bus lines, each containing a sequence of data nodes extending infinitely in one direction. The chip begins at a primary input node located at the start of the first bus line.

Between every two adjacent nodes (either horizontally along a bus line or vertically between the two lines), a quantum logic gate is positioned. Due to manufacturing fluctuations, each gate has exactly a $50\%$ chance of being "conductive" and a $50\%$ chance of being "resistive," determined independently for every gate. 

A data signal originates at the primary input node and can propagate to any node in the architecture, provided there is a continuous path of conductive gates leading to it.

Calculate the expected total number of nodes (including the starting node) that the signal can reach. If your answer is an irreducible fraction $\frac{a}{b}$, find the value of $a + b$.
