# Solution to $e^z = z$

## Step 1: Real solutions

For real $x$, consider $f(x) = e^x - x$. Then $f'(x) = e^x - 1$, which vanishes
only at $x = 0$. Since $f''(x) = e^x > 0$, this is a global minimum, with $f(0)
= e^0 - 0 = 1 > 0$. Hence $e^x - x \geq 1 > 0$ for all $x \in \mathbb{R}$, so

$$\boxed{\text{There are no real solutions.}}$$

## Step 2: Reduction to the Lambert $W$ function

Rewrite $e^z = z$ by multiplying both sides by $e^{-z}$:

$$z\, e^{-z} = 1.$$

Multiplying by $-1$:

$$(-z)\, e^{-z} = -1.$$

The **Lambert $W$ function** is defined as the multi-valued inverse of the map $
w \mapsto w e^w$. That is, $w = W(u)$ means $w e^w = u$. Applying this with $w =
 -z$ and $u = -1$:

$$-z = W_k(-1) \quad\Longrightarrow\quad z = -W_k(-1), \qquad k \in \mathbb{Z}.$
$

**Verification.** If $z = -W_k(-1)$, then $-z = W_k(-1)$, so by definition $(-z)
e^{-z} = -1$, i.e., $z e^{-z} = 1$, i.e., $e^z = z$. ✓

## Step 3: All solutions are captured

Conversely, every solution of $e^z = z$ satisfies $(-z)e^{-z} = -1$, so $-z$ is
**some** value of $W(-1)$, i.e., $-z = W_k(-1)$ for some branch $k$. Hence every
 solution has the form $z = -W_k(-1)$.

## Step 4: The branches are all complex and distinct

The real branches $W_0$ and $W_{-1}$ of the Lambert $W$ function are defined onl
y on $[-1/e, \infty)$ and $[-1/e, 0)$ respectively. Since

$$-1 < -\frac{1}{e} \approx -0.3679,$$

the argument $-1$ lies **outside** the real domain of every real-valued branch.
Therefore **every** $W_k(-1)$ is genuinely complex, confirming again that no rea
l solution exists.

For the complex branches $k \in \mathbb{Z}$: the values $W_k(-1)$ are pairwise d
istinct (the only branch-point collisions occur at $u = -1/e$, and $-1 \neq -1/e
$). Moreover, for $|k| \to \infty$ the asymptotic formula

$$W_k(u) \sim \log u + 2\pi i k - \log(\log u + 2\pi i k) \quad (|k|\to\infty)$$

shows that $|W_k(-1)| \to \infty$, so infinitely many distinct values arise. Hen
ce there are **infinitely many** distinct complex solutions, one for each intege
r branch $k$.

## Step 5: Explicit form via $z = x + iy$

For concreteness, writing $z = x + iy$ and separating $e^x(\cos y + i\sin y) = x
 + iy$ gives the coupled system

$$e^x \cos y = x, \qquad e^x \sin y = y,$$

which is equivalent to

$$x = y\cot y, \qquad x = \ln\!\left(\frac{y}{\sin y}\right),$$

i.e., the single transcendental equation

$$y\cot y = \ln\!\left(\frac{y}{\sin y}\right), \qquad y \neq n\pi.$$

Each solution $y$ of this equation (paired with $x = y\cot y$) corresponds to ex
actly one branch $W_k(-1)$, and vice versa. This confirms the solution set is di
screte and infinite.

## Conclusion

The equation $e^z = z$ has:

- **No real solutions** (since $e^x - x \geq 1 > 0$ for all real $x$).
- **Infinitely many complex solutions**, given exactly by

$$\boxed{\,z = -W_k(-1), \qquad k \in \mathbb{Z}\,}$$

where $W_k$ denotes the $k$-th branch of the Lambert $W$ function. Each branch y
ields a distinct complex number, and these exhaust all solutions.
