Looking at this problem, I need to find all integer-coefficient polynomials $P(x
)$ with $|coefficients| < 2017^3$, where $P(2018)=0$ and $P(a+b)=P(a)+P(b)$ when
ever $ab=1$.

## Analyzing the Functional Equation

Setting $b = 1/a$ (for $a \neq 0$), the condition becomes $P(a + 1/a) = P(a) + P
(1/a)$ for all $a \neq 0$.

Let $P(x) = \sum_{k=0}^n c_k x^k$. Then:
- **LHS:** $P(a+1/a) = \sum_k c_k (a+1/a)^k = \sum_k c_k \sum_{j=0}^k \binom{k}{
j} a^{k-2j}$
- **RHS:** $P(a)+P(1/a) = \sum_k c_k(a^k + a^{-k})$

Computing LHS $-$ RHS for each $k$:
- $k=0$: $1 - 2 = -1$, contributing $-c_0$
- $k=1$: $(a+1/a) - (a+1/a) = 0$
- $k \geq 2$: $\sum_{j=1}^{k-1} \binom{k}{j} a^{k-2j}$

So the condition is: $-c_0 + \sum_{k=2}^n c_k \sum_{j=1}^{k-1} \binom{k}{j} a^{k
-2j} = 0$ for all $a \neq 0$.

## Determining the Solution Space

The highest power $a^{n-2}$ (from $k=n, j=1$) has coefficient $n \cdot c_n$. For
 $n \geq 3$, this power appears only from $k=n$, forcing $c_n = 0$. By induction
 downward through each power $a^m$ ($m \geq 1$), each introduces exactly one new
 coefficient $c_{m+2}$ with nonzero multiplier $\binom{m+2}{1} = m+2$, forcing $
c_k = 0$ for all $k \geq 3$.

The constant term ($a^0$) receives contributions from $-c_0$ and $2c_2$ (from $k
=2, j=1$), giving $-c_0 + 2c_2 = 0$, so $c_0 = 2c_2$.

**General solution:** $P(x) = c_2(x^2 + 2) + c_1 x$ for integers $c_1, c_2$.

**Verification:** For $P(x) = x^2+2$: $P(a+1/a) = a^2+1/a^2+4 = (a^2+2)+(1/a^2+2
) = P(a)+P(1/a)$. ✓

## Applying $P(2018) = 0$

$$c_2(2018^2+2) + 2018c_1 = 0 \implies 4072326\,c_2 + 2018\,c_1 = 0$$

Since $2036163 = 1009 \times 2018 + 1$, we have $\gcd(2036163, 1009) = 1$, so th

$$c_2 = 1009k, \quad c_1 = -2036163k, \quad c_0 = 2018k \quad \text{for integer
