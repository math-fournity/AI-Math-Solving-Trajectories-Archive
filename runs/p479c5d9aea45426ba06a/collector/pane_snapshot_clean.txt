## Proof

We determine the cardinality of
$$H = \{f : \mathbb{N} \to \mathbb{N} \mid f \text{ is an involution}\},$$
where an involution satisfies $f \circ f = \mathrm{id}_\mathbb{N}$.

### Structure of an involution

Since $f \circ f = \mathrm{id}$, every $n \in \mathbb{N}$ satisfies $f(f(n)) = n
$. There are two cases for each $n$:

- **Fixed point:** $f(n) = n$.
- **2-cycle (transposition):** $f(n) = m \neq n$, which forces $f(m) = n$.

No cycle of length $\geq 3$ can occur, since $f(f(n)) = n$ rules out $f^k(n) = n
$ only for $k = 2$ (and $k=1$). Hence every involution is a product of disjoint
transpositions together with fixed points. In particular, every involution is a
bijection (permutation) of $\mathbb{N}$.

### Upper bound: $|H| \leq 2^{\aleph_0}$

Every involution is, in particular, a function $\mathbb{N} \to \mathbb{N}$. Ther
efore
$$H \subseteq \mathbb{N}^\mathbb{N}.$$
The set of all functions $\mathbb{N} \to \mathbb{N}$ has cardinality
$$|\mathbb{N}^\mathbb{N}| = \aleph_0^{\aleph_0} = 2^{\aleph_0},$$
since $2^{\aleph_0} \leq \aleph_0^{\aleph_0} \leq (2^{\aleph_0})^{\aleph_0} = 2^
{\aleph_0 \cdot \aleph_0} = 2^{\aleph_0}$. Hence
$$|H| \leq 2^{\aleph_0}.$$

### Lower bound: $|H| \geq 2^{\aleph_0}$

Partition $\mathbb{N}$ into countably many disjoint pairs:
$$\mathbb{N} = \{0,1\} \;\cup\; \{2,3\} \;\cup\; \{4,5\} \;\cup\; \cdots = \bigc
up_{k=0}^{\infty} \{2k,\, 2k+1\}.$$

For each subset $S \subseteq \mathbb{N}$, define an involution $f_S$ by:
- If $k \in S$: swap the pair, i.e., $f_S(2k) = 2k+1$ and $f_S(2k+1) = 2k$.
- If $k \notin S$: fix the pair, i.e., $f_S(2k) = 2k$ and $f_S(2k+1) = 2k+1$.

Each $f_S$ is an involution: applying it twice returns every element to itself,
since each pair is either swapped (and swapping twice is identity) or fixed. The
 map $S \mapsto f_S$ is injective, because $S$ can be recovered from $f_S$ via $
k \in S \iff f_S(2k) = 2k+1$.

Since there are $2^{\aleph_0}$ subsets $S \subseteq \mathbb{N}$, we obtain
$$|H| \geq 2^{\aleph_0}.$$

### Conclusion

Combining both bounds:
$$2^{\aleph_0} \leq |H| \leq 2^{\aleph_0},$$
so by the Cantor–Bernstein–Schröder theorem (or simply by squeeze),
$$\boxed{|H| = 2^{\aleph_0}}.$$

The cardinality of the set of involutions on $\mathbb{N}$ equals the cardinality
 of the continuum.
