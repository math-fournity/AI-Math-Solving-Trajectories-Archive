### Step 1: Key substitution $y = 1$

Setting $y = 1$ in the functional equation:
$$f(f(x) - x) + xf(1) + f(x) = f(x) + f(x)f(1)$$

Simplifying:
$$f(f(x) - x) = f(1)\bigl(f(x) - x\bigr)$$

Let $a = f(1)$ and $h(x) = f(x) - x$. Then:
$$f(h(x)) = a \cdot h(x) \quad \text{for all } x > 0. \tag{$\star$}$$

### Step 2: General substitution using $(\star)$

In the original equation, $f(f(xy)-xy) = a \cdot h(xy) = a(f(xy)-xy)$, so:
$$a(f(xy)-xy) + xf(y) + yf(x) = f(xy) + f(x)f(y)$$

Rearranging:
$$(a-1)f(xy) = \bigl(f(x)-x\bigr)\bigl(f(y)-y\bigr) + (a-1)xy = h(x)h(y) + (a-1)
xy$$

**Case $a = 1$:** Setting $y = x$ gives $0 = h(x)^2$, so $h(x) = 0$ and $f(x) =
x$. (This is $f(x)=cx$ with $c=1$.)

**Case $a \neq 1$:** We get $h(xy) = \frac{h(x)h(y)}{a-1}$. Define $k(x) = \frac
{h(x)}{a-1}$; then:
$$k(xy) = k(x)k(y)$$
Since $f$ is continuous, $k$ is continuous and multiplicative on $\mathbb{R}^+$,
 so $k(x) = x^r$ for some $r \in \mathbb{R}$. Thus:
$$f(x) = x + (a-1)x^r$$

### Step 3: Constraining $r$ via $(\star)$

Substituting $f(x) = x + (a-1)x^r$ into $f(h(x)) = a\cdot h(x)$, where $h(x) = (
a-1)x^r$:

$$f\bigl((a-1)x^r\bigr) = (a-1)x^r + (a-1)\bigl((a-1)x^r\bigr)^r = (a-1)x^r + (a
-1)^{r+1}x^{r^2}$$

This must equal $a(a-1)x^r$, so:
$$(a-1)^{r+1}x^{r^2} = (a-1)^2 x^r \quad \text{for all } x > 0$$

This requires:
- **Power condition:** $r^2 = r$, so $r \in \{0, 1\}$.
- **Coefficient condition:** $(a-1)^{r+1} = (a-1)^2$, so $r+1 = 2$, i.e., $r = 1
$ — **unless** $a-1 \in \{0,1\}$ (base cases where the power equation degenerate
s).

**Subcase $r = 1$:** Coefficient condition holds for all $a$. Then $f(x) = x + (
a-1)x = ax$ for any $a > 0$. ✓

**Subcase $r = 0$:** Power condition satisfied. Coefficient condition: $(a-1)^1
= (a-1)^2$, so $a-1 \in \{0,1\}$. Since $a \neq 1$, we get $a = 2$, giving $f(x)
 = x + 1$. ✓
