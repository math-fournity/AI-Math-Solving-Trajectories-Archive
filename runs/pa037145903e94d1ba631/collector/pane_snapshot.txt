Looking at this problem, I need to find AC + CB for a right triangle with two in
scribed squares of areas 441 and 440.

## Solution

Let me set up the right triangle with the right angle at C. Let AC = a, CB = b,
so AC + CB = a + b = p, and the hypotenuse AB = c = √(a² + b²). Let q = ab.

**Two types of inscribed squares:**

1. **Corner square** (one vertex at C, two sides on the legs): side = ab/(a+b) =
 q/p

2. **Hypotenuse square** (one side on AB): Using the altitude h = ab/c from C to
 AB, the small triangle cut off by the square is similar to ABC with ratio (h−s)
/h, giving side s = ch/(h+c) = abc/(ab + c²) = qc/(p² − q)

**Assigning the squares:** Testing both assignments, the consistent one is:
- S₁ (area 441, side 21) = corner square → q/p = 21, so q = 21p
- S₂ (area 440, side 2√110) = hypotenuse square → qc/(p² − q) = 2√110

**Substituting q = 21p:**

c = √(p² − 2q) = √(p² − 42p)

The hypotenuse square equation becomes:

$$2\sqrt{110}\,(p - 21) = 21\sqrt{p^2 - 42p}$$

**Squaring both sides:**

$$440(p - 21)^2 = 441(p^2 - 42p)$$

$$440(p^2 - 42p + 441) = 441p^2 - 18522p$$

$$440p^2 - 18480p + 194040 = 441p^2 - 18522p$$

$$p^2 - 42p - 194040 = 0$$

**Quadratic formula:**

$$p = \frac{42 \pm \sqrt{1764 + 776160}}{2} = \frac{42 \pm \sqrt{777924}}{2} = \
frac{42 \pm 882}{2}$$

Taking the positive root: p = (42 + 882)/2 = **462**

**Verification:** With p = 462, q = 9702, c² = 462² − 2·9702 = 194040.
- Corner square: q/p = 9702/462 = 21 ✓ (area = 441 ✓)
- Hypotenuse square: s² = 441·194040/441² = 194040/441 = 440 ✓

$$AC + CB = \boxed{462}$$
