The problem is a standard ring theory proof. No answer leak. Let me write the
proof directly.

Proof

Let $R$ be a ring with unity $1$, and let $a \in R$ be nilpotent. By definition,
there exists a positive integer $n$ such that $a^n = 0$.

Step 1: $a + 1$ is invertible

We construct an explicit inverse. Consider the element

$$b = 1 - a + a^2 - a^3 + \cdots + (-1)^{n-1} a^{n-1} = \sum_{k=0}^{n-1} (-a)^k.
$$

We compute $(1+a),b$:

$$(1+a),b = (1+a)\sum_{k=0}^{n-1}(-a)^k = \sum_{k=0}^{n-1}(-a)^k + a\sum_{k=0}
^{n-1}(-a)^k = \sum_{k=0}^{n-1}(-a)^k + \sum_{k=0}^{n-1}(-1)^k a^{k+1}.$$

Reindexing the second sum (set $j = k+1$):

$$= \sum_{k=0}^{n-1}(-a)^k + \sum_{j=1}^{n}(-1)^{j-1} a^{j} = \sum_{k=0}^{n-1}(-
a)^k - \sum_{j=1}^{n}(-a)^{j}.$$

The first sum is $(-a)^0 + (-a)^1 + \cdots + (-a)^{n-1}$, and the second is $(-
a)^1 + \cdots + (-a)^{n}$. All intermediate terms cancel (telescoping), leaving

$$(1+a),b = (-a)^0 - (-a)^n = 1 - (-1)^n a^n = 1 - (-1)^n \cdot 0 = 1.$$

The same computation with $b$ on the left gives $b,(1+a) = 1$ (the argument is
identical since $1$ commutes with every element, and the telescoping works the
same way). Hence $b$ is a two-sided inverse of $1+a$, so $a+1$ is invertible.

Step 2: $a - 1$ is invertible

We use the same idea. Note that $a - 1 = -(1 - a)$, and $-1$ is a unit (with
inverse $-1$), so it suffices to show $1 - a$ is invertible.

Consider

$$c = 1 + a + a^2 + \cdots + a^{n-1} = \sum_{k=0}^{n-1} a^k.$$

Then

$$(1-a),c = (1-a)\sum_{k=0}^{n-1}a^k = \sum_{k=0}^{n-1}a^k - \sum_{k=0}^{n-1}
a^{k+1} = \sum_{k=0}^{n-1}a^k - \sum_{j=1}^{n}a^{j}.$$

This telescopes to

$$(1-a),c = a^0 - a^n = 1 - 0 = 1.$$

Likewise $c,(1-a) = 1$ by the same telescoping argument. Thus $c$ is a two-sided
inverse of $1-a$, so $1 - a$ is invertible.

Since $a - 1 = -(1-a)$ and $-1$ is a unit, $a - 1 = (-1)(1-a)$ is a product of
two units, hence a unit. Explicitly, its inverse is $-c$:

$$(a-1)(-c) = (-(1-a))(-c) = (1-a)c = 1, \qquad (-c)(a-1) = (-c)(-(1-a)) = c(1-
a) = 1.$$

Conclusion

Both $a+1$ and $a-1$ are invertible in $R$, with explicit inverses

$$\boxed{(a+1)^{-1} = \sum_{k=0}^{n-1}(-a)^k, \qquad (a-1)^{-1} = -\sum_{k=0}
^{n-1} a^k.}$$
