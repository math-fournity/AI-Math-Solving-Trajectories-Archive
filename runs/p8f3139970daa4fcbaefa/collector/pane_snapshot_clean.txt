## Solution

**Setup.** Let $f(z) = z^3 e^{z^2}$. The contour $\Gamma$ is the unit circle $|z
|=1$ parametrized by $z = e^{i\theta}$ with $0 \le \theta \le 4\pi$, i.e., **tra
versed twice** in the positive (counterclockwise) direction.

**Argument principle.** For a meromorphic function $f$ and a positively oriented
 simple closed contour $\gamma$ (traversed once) on which $f$ has no zeros or po
les,

$$\frac{1}{2\pi i}\oint_\gamma \frac{f'(z)}{f(z)}\,dz = N - P,$$

where $N$ is the number of zeros and $P$ the number of poles of $f$ inside $\gam
ma$, counted with multiplicity.

**Zeros of $f$.** Since $e^{z^2}$ is entire and never vanishes, the zeros of $f$
 come only from $z^3 = 0$, giving $z = 0$ with multiplicity $3$. The point $z=0$
 lies inside $|z|=1$.

**Poles of $f$.** $f$ is entire, so $P = 0$.

**Single traversal.** For one counterclockwise traversal of $|z|=1$:
$$\frac{1}{2\pi i}\oint \frac{f'(z)}{f(z)}\,dz = N - P = 3 - 0 = 3.$$

**Double traversal.** Since $\Gamma$ winds around the circle twice ($\theta$ run
s from $0$ to $4\pi$), the integral is doubled:

$$\frac{1}{2\pi i}\oint_\Gamma \frac{f'(z)}{f(z)}\,dz = 2 \cdot 3 = 6.$$

**Verification via direct computation.** We have $f'(z) = 3z^2 e^{z^2} + z^3 \cd
ot 2z\, e^{z^2} = e^{z^2}(3z^2 + 2z^4)$, so

$$\frac{f'(z)}{f(z)} = \frac{e^{z^2}(3z^2 + 2z^4)}{z^3 e^{z^2}} = \frac{3z^2 + 2
z^4}{z^3} = \frac{3}{z} + 2z.$$

Hence

$$\frac{1}{2\pi i}\oint_\Gamma \frac{f'(z)}{f(z)}\,dz = \frac{1}{2\pi i}\oint_\G
amma \left(\frac{3}{z} + 2z\right)dz.$$

For the double traversal of $|z|=1$:
- $\displaystyle\frac{1}{2\pi i}\oint_\Gamma \frac{3}{z}\,dz = 3 \cdot 2 = 6$ (w
inding number $2$ times the residue $3$),
- $\displaystyle\frac{1}{2\pi i}\oint_\Gamma 2z\,dz = 0$ (entire integrand).

Therefore

$$\frac{1}{2\pi i}\oint_\Gamma \frac{f'(z)}{f(z)}\,dz = 6.$$

### PROOF COMPLETE
