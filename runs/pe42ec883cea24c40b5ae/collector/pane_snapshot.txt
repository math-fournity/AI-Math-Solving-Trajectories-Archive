## Solution

**Chamber 1:** $x^2 + ax + 20 = 0$ with all roots negative integers.

Let the roots be $-m, -n$ where $m, n$ are positive integers. By Vieta's:
- $m \cdot n = 20$
- $a = m + n$

Factor pairs of 20 (positive integers): $(1,20), (2,10), (4,5)$.

So possible values of $a$: $21, 12, 9$. **Minimum $a = 9$** (from $m=4, n=5$).

**Chamber 2:** $x^2 + 17x + b = 0$ with all roots negative integers.

Let the roots be $-p, -q$ where $p, q$ are positive integers. By Vieta's:
- $p + q = 17$
- $b = pq$

Positive integer pairs summing to 17: $(1,16), (2,15), (3,14), (4,13), (5,12), (
6,11), (7,10), (8,9)$.

Corresponding $b = pq$: $16, 30, 42, 52, 60, 66, 70, 72$.

**Minimum $b = 16$** (from $p=1, q=16$).

**Combined sum:** The two chambers are independent, so we minimize each separate
ly:

$$a + b = 9 + 16 = 25$$

**Verification:**
- Chamber 1: $x^2 + 9x + 20 = (x+4)(x+5) = 0 \Rightarrow x = -4, -5$ ✓ both nega
tive integers
- Chamber 2: $x^2 + 17x + 16 = (x+1)(x+16) = 0 \Rightarrow x = -1, -16$ ✓ both n
egative integers

The smallest possible value of $a + b$ is $\boxed{25}$.
