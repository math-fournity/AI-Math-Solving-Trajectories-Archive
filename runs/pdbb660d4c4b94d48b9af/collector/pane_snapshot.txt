## Solution

**Setup: Transfer Matrix Method**

We process the grid column by column (left to right). Each column has 4 cells. T
he state is a bitmask indicating which cells in the current column are already o
ccupied by horizontal dominoes extending from the previous column. The reachable
 states are:

| State | Binary | Description |
|-------|--------|-------------|
| A | 0000 | No cells pre-filled |
| B | 0011 | Rows 0,1 pre-filled |
| C | 1100 | Rows 2,3 pre-filled |
| D | 1001 | Rows 0,3 pre-filled |
| E | 0110 | Rows 1,2 pre-filled |
| F | 1111 | All cells pre-filled |

**Transfer rules** (from each state, fill remaining cells using vertical dominoe
s in the current column and horizontal dominoes extending right):

- **A→A**: Two vertical dominoes (rows 0-1, 2-3). **A→B**: Vertical 2-3, horizon
tal 0,1. **A→C**: Vertical 0-1, horizontal 2,3. **A→D**: Vertical 1-2, horizonta
l 0,3. **A→F**: All horizontal.
- **B→A**: Vertical 2-3. **B→C**: Horizontal 2,3.
- **C→A**: Vertical 0-1. **C→B**: Horizontal 0,1.
- **D→A**: Vertical 1-2. **D→E**: Horizontal 1,2.
- **E→D**: Horizontal 0,3.
- **F→A**: Empty pass-through.

**Deriving the recurrence**

Let $a_n, b_n, c_n, d_n, e_n, f_n$ be the number of ways to reach each state aft
er $n$ columns, starting from state A. Then:

$$a_{n+1} = a_n + b_n + c_n + d_n + f_n, \quad b_{n+1} = a_n + c_n, \quad c_{n+1
} = a_n + b_n$$
$$d_{n+1} = a_n + e_n, \quad e_{n+1} = d_n, \quad f_{n+1} = a_n$$

with $a_0=1$, all others $= 0$.

**Key eliminations:**
- From $b_{n+1} = a_n + c_n$ and $c_{n+1} = a_n + b_n$: since $b_0 = c_0 = 0$, b
y symmetry $b_n = c_n$ for all $n$, and $b_n = b_{n-1} + a_{n-1}$.
- $f_n = a_{n-1}$ (from $f_{n+1} = a_n$).
- $e_n = d_{n-1}$ (from $e_{n+1} = d_n$), and $d_n = a_{n-1} + d_{n-2}$.

Define $g_n = 2b_n + d_n$, so $a_{n+1} = a_n + a_{n-1} + g_n$.

Computing $g_n - g_{n-2}$:
$$g_n - g_{n-2} = 2(b_n - b_{n-2}) + (d_n - d_{n-2}) = 2(a_{n-1} + a_{n-2}) + a_
{n-1} = 3a_{n-1} + 2a_{n-2}$$

Substituting $g_n = a_{n+1} - a_n - a_{n-1}$:
$$a_{n+1} - a_n - a_{n-1} - a_{n-1} + a_{n-2} + a_{n-3} = 3a_{n-1} + 2a_{n-2}$$

$$\boxed{a_n = a_{n-1} + 5a_{n-2} + a_{n-3} - a_{n-4}}$$
