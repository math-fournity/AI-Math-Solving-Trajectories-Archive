## Solution

**Answer: Yes, the integral can converge to zero.**

### Counterexample

Let $X = [0, \infty)$ with Lebesgue measure $m$, and define
$$f(x) = e^{-x}, \quad x \in [0,\infty).$$
Then $f(x) > 0$ everywhere on $X$ (hence positive almost everywhere), and $f$ is
 integrable since $\int_0^\infty e^{-x}\,dx = 1 < \infty$.

Set $c = \tfrac{1}{2}$ and define
$$A_n = [n,\, n+1], \quad n = 1, 2, 3, \dots$$

Each $A_n \subseteq X$ is measurable with
$$m(A_n) = 1 > \tfrac{1}{2} = c \quad \text{for all } n,$$
so the uniform lower bound $m(A_n) > c > 0$ is satisfied.

Now compute the integral of $f$ over $A_n$:
$$\int_{A_n} f(x)\,dx = \int_n^{n+1} e^{-x}\,dx = \left[-e^{-x}\right]_n^{n+1} =
 e^{-n} - e^{-(n+1)} = e^{-n}(1 - e^{-1}).$$

Since $0 < 1 - e^{-1} < 1$ is a fixed constant and $e^{-n} \to 0$ as $n \to \inf
ty$,
$$\int_{A_n} f(x)\,dx = e^{-n}(1-e^{-1}) \;\longrightarrow\; 0 \quad \text{as }
n \to \infty.$$

### Why this works (and when it would fail)

The key mechanism is that $f$, while positive everywhere, **concentrates its mas
s on a region of finite measure** (here near the origin). The sets $A_n$ each ca
rry fixed measure $1$, but they slide off toward $+\infty$ where $f$ is exponent
ially small. The integral over each $A_n$ captures only a vanishingly small port
ion of $f$'s total mass.

**Remark (finite-measure case).** If $X$ had *finite* measure, the answer would
be **no**. Indeed, writing $B_k = \{x \in X : f(x) \ge 1/k\}$, the a.e.-positivi
ty of $f$ gives $m(X \setminus B_k) \to m(\{f=0\}) = 0$ (by continuity from abov
e, valid since $m(X)<\infty$). For each fixed $k$,
$$\int_{A_n} f \ge \int_{A_n \cap B_k} f \ge \tfrac{1}{k}\, m(A_n \cap B_k),$$
so $m(A_n \cap B_k) \le k\int_{A_n} f \to 0$. Then
$$m(A_n) = m(A_n \cap B_k) + m(A_n \setminus B_k) \le m(A_n \cap B_k) + m(X \set
minus B_k).$$
Taking $\limsup_{n\to\infty}$: $\limsup m(A_n) \le m(X\setminus B_k)$ for every
$k$. Letting $k\to\infty$ yields $\limsup m(A_n) \le 0$, contradicting $m(A_n) >
 c > 0$. The finite-measure hypothesis is essential: it is precisely the failure
 of $m(X\setminus B_k)\to 0$ (these sets have infinite measure in the counterexa
mple) that allows the integral to escape to zero.
