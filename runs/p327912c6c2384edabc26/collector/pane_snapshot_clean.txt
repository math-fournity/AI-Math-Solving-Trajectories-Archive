## Solution

**Setup.** The grid has 16×16 = 256 dots, with 240 horizontal + 240 vertical = *
*480 total line segments**. Each segment is red (both endpoints red), blue (both
 endpoints blue), or yellow (endpoints differ). Let R, B, Y denote these counts.
 Given Y = 196:

$$R + B + Y = 480 \implies R + B = 284.$$

**Key identity.** Sum the grid-degrees of all red dots. A red–red edge contribut
es 2 to this sum (both endpoints), a yellow edge contributes 1 (one red endpoint
), a blue edge contributes 0:

$$\sum_{\text{red dots}} \deg = 2R + Y.$$

**Computing the left side.** In the grid: corners have degree 2, boundary non-co
rners degree 3, interior dots degree 4. There are 4 corners, 56 boundary non-cor
ners, 196 interior dots.

Given 133 red dots total, 32 on the boundary (including the 2 red corners):
- Red corners: 2 → degree contribution 2·2 = 4
- Red boundary non-corners: 30 → 30·3 = 90
- Red interior: 133 − 32 = 101 → 101·4 = 404

$$\sum_{\text{red dots}} \deg = 4 + 90 + 404 = 498.$$

**Solving.**

$$2R + 196 = 498 \implies 2R = 302 \implies R = 151.$$

$$B = 284 - 151 = 133.$$

**Verification via blue dots.** Blue dots = 256 − 133 = 123. Blue corners = 2, b
lue boundary non-corners = 26, blue interior = 95. Sum of blue degrees = 2·2 + 2
6·3 + 95·4 = 4 + 78 + 380 = 462. Check: 2B + Y = 2·133 + 196 = 462. ✓

The number of blue line segments is **133**.
