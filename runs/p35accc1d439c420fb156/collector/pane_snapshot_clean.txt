## Counterexample

**Setup.** Let $Y_1, Y_2, \ldots$ be i.i.d. $N(0,1)$ random variables on a commo
n probability space. Define the triangular array by $X_{n,i} := Y_i$ for $i = 1,
 \ldots, n$. Within each row, the variables are independent. Set
$$f_n(x_1, \ldots, x_n) = \frac{1}{n}\sum_{i=1}^n x_i, \qquad \mu_n = f_n(X_{n,1
}, \ldots, X_{n,n}) = \frac{1}{n}\sum_{i=1}^n Y_i.$$
By the Strong Law of Large Numbers, $\mu_n \to \mathbb{E}[Y_1] = 0$ almost surel
y, so $c = 0$.

**The two distributions.** We have:
$$\bar{X}_{n,i} = Y_i - \mu_n = Y_i - \frac{1}{n}\sum_{j=1}^n Y_j, \qquad \tilde
{X}_{n,i} = Y_i - c = Y_i.$$

**Key observation.** For every realization,
$$\sum_{i=1}^n \bar{X}_{n,i} = \sum_{i=1}^n Y_i - n \cdot \frac{1}{n}\sum_{j=1}^
n Y_j = 0.$$
Therefore $\bar{X}_n$ is supported on the hyperplane
$$H_n := \left\{x \in \mathbb{R}^n : \sum_{i=1}^n x_i = 0\right\},$$
i.e., $P(\bar{X}_n \in H_n) = 1$.

On the other hand, $\tilde{X}_n = (Y_1, \ldots, Y_n) \sim N(0, I_n)$, which has
a density with respect to $n$-dimensional Lebesgue measure. Since $H_n$ is an $(
n-1)$-dimensional subspace, it has Lebesgue measure zero, so
$$P(\tilde{X}_n \in H_n) = 0.$$

**TV distance computation.** Using the set $A = H_n$ as a witness:
$$d_{TV}\!\big(P(\bar{X}_n \in \cdot),\, P(\tilde{X}_n \in \cdot)\big) \geq \big
|P(\bar{X}_n \in H_n) - P(\tilde{X}_n \in H_n)\big| = |1 - 0| = 1.$$

Since total variation distance is always at most 1, we conclude:
$$d_{TV}\!\big(P(\bar{X}_n \in \cdot),\, P(\tilde{X}_n \in \cdot)\big) = 1 \quad
 \text{for every } n \geq 1.$$

**Conclusion.** The total variation distance does not converge to zero. In this
counterexample it remains identically equal to 1. The underlying reason is that
$\mu_n = f_n(X_{n,1}, \ldots, X_{n,n})$ is a function of the entire row, so cent
ering by $\mu_n$ introduces a deterministic constraint (here $\sum_i \bar{X}_{n,
i} = 0$) that makes the support of $\bar{X}_n$ singular with respect to the dist
ribution of $\tilde{X}_n$. The almost-sure convergence $\mu_n \to c$ only ensure
s the *shift* $(\mu_n - c)\mathbf{1}_n \to 0$ pointwise, but it does not remove
the structural dependence that centering by a data-dependent quantity introduces
. $\blacksquare$
