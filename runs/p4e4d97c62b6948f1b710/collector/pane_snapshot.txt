## Proof

Let $g(z) = z^4 + z^3 + z^2 + z + 1$. Observe that
$$(z-1)\,g(z) = z^5 - 1,$$
so the zeros of $g$ are precisely the primitive $5$th roots of unity:
$$\omega_k = e^{2\pi i k/5}, \qquad k = 1, 2, 3, 4.$$
None of these is real (the only real $5$th root of unity is $1$, and $g(1)=5\neq
 0$; also $g(-1)=1\neq 0$).

**Step 1. The spectrum is contained in the zero set of $g$.**

By the spectral mapping theorem, for any bounded operator $S$,
$$\sigma(g(S)) = g(\sigma(S)).$$
Since $g(S)=0$, we have $\sigma(g(S)) = \{0\}$, hence
$$g(\sigma(S)) = \{0\},$$
so every $\lambda \in \sigma(S)$ satisfies $g(\lambda)=0$. Therefore
$$\sigma(S) \subseteq \{\omega_1,\omega_2,\omega_3,\omega_4\}.$$

**Step 2. Self-adjointness forces the spectrum to be real.**

Since $S$ is self-adjoint, $\sigma(S) \subseteq \mathbb{R}$.

**Step 3. Combine.**

From Steps 1 and 2,
$$\sigma(S) \subseteq \mathbb{R} \cap \{\omega_1,\omega_2,\omega_3,\omega_4\} =
\varnothing,$$
since every $\omega_k$ is non-real. Hence
$$\sigma(S) = \varnothing.$$

**Step 4. Consistency.** A bounded operator on a *nonzero* complex Hilbert space
 has nonempty spectrum. The only way $\sigma(S)=\varnothing$ is therefore $H=\{0
\}$, the zero Hilbert space, on which $S=0$ trivially satisfies $g(S)=0$ and has
 empty spectrum. This is consistent with all the hypotheses.

$$\boxed{\sigma(S) = \varnothing}$$
