**Proof.**

We show that if \(A \subseteq \mathbb{R}\) is Lebesgue-measurable and locally \(
\varepsilon\)-dense, then \(\mu(A) > 0\).

Suppose, for contradiction, that \(\mu(A) = 0\).

Since \(A\) is Lebesgue-measurable with \(\mu(A) = 0\), every Lebesgue-measurabl
e subset of \(A\) also has measure zero (by monotonicity of measure: if \(B \sub
seteq A\) and \(B\) is measurable, then \(\mu(B) \le \mu(A) = 0\)).

For any \(x < y\), the set \(A \cap [x,y]\) is Lebesgue-measurable (intersection
 of two measurable sets) and satisfies \(A \cap [x,y] \subseteq A\). Hence
\[
\mu(A \cap [x,y]) = 0
\]
for every choice of \(x < y\).

Consequently, for every \(x < y\),
\[
\frac{\mu(A \cap [x,y])}{y - x} = \frac{0}{y - x} = 0.
\]

Now take \(\varepsilon = \tfrac{1}{2}\). By the locally \(\varepsilon\)-dense pr
operty of \(A\), there must exist \(x < y\) such that
\[
\frac{\mu(A \cap [x,y])}{y - x} \ge 1 - \varepsilon = 1 - \tfrac{1}{2} = \tfrac{
1}{2}.
\]
But we have just shown that the left-hand side equals \(0\) for **all** \(x < y\
), so we would need \(0 \ge \tfrac{1}{2}\), which is false. This is a contradict
ion.

Therefore our assumption \(\mu(A) = 0\) is impossible, and we conclude
\[
\mu(A) > 0.
\]

In fact, the argument shows something slightly stronger: the locally \(\varepsil
on\)-dense condition fails for **any** set of measure zero, since a measure-zero
 set has zero intersection with every interval. Hence local \(\varepsilon\)-dens
ity necessarily forces \(A\) to have positive Lebesgue measure.
