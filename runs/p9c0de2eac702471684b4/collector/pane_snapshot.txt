## Proof

**Setup and notation.** Let α = ∠BAC = 60°, β = ∠ABC, γ = ∠BCA, so β + γ = 120°.
 Denote the angles at P: ∠BPC = x, ∠CPA = y, ∠APB = z, with x + y + z = 360°.

**Step 1: Determine the angles at P.**

The condition gives x − α = y − β = z − γ = k. Summing:
$$x + y + z = (\alpha + \beta + \gamma) + 3k = 180° + 3k = 360°$$
So k = 60°, yielding:
$$\angle BPC = 120°,\quad \angle CPA = \beta + 60°,\quad \angle APB = \gamma + 6
0°$$

**Step 2: Define the pedal triangle.**

Let D, E, F be the feet of perpendiculars from P to BC, CA, AB respectively. The
 pedal triangle is DEF.

**Step 3: Compute the side EF.**

Since PE ⊥ CA and PF ⊥ AB, quadrilateral AEPF is cyclic with diameter AP. The ch
ord EF subtends angle ∠EAF = α = 60° at the circumference, so by the inscribed a
ngle theorem:
$$EF = AP \cdot \sin\alpha = 12 \cdot \sin 60° = 6\sqrt{3}$$

**Step 4: Show the pedal triangle is equilateral.**

Set ∠PAB = α₁, ∠PAC = α₂ (so α₁ + α₂ = 60°); ∠PBA = β₁, ∠PBC = β₂ (so β₁ + β₂ =
β); ∠PCA = γ₁, ∠PCB = γ₂ (so γ₁ + γ₂ = γ).

From the three triangles at P:
- Triangle APB: α₁ + β₁ = 180° − (γ + 60°) = 120° − γ
- Triangle APC: α₂ + γ₁ = 180° − (β + 60°) = 120° − β
- Triangle BPC: β₂ + γ₂ = 180° − 120° = 60°

**Angle at D:** Using cyclic quadrilaterals BFPD (diameter BP) and CEPD (diamete
r CP):
$$\angle FDP = \angle FBP = \beta_1, \qquad \angle PDE = \angle PCE = \gamma_1$$
$$\angle FDE = \beta_1 + \gamma_1 = (120° - \gamma - \alpha_1) + (120° - \beta -
 \alpha_2) = 240° - \beta - \gamma - 60° = 240° - 120° - 60° = 60°$$

**Angle at E:** Using cyclic quadrilaterals AEPF (diameter AP) and CEPD (diamete
r CP):
$$\angle FEP = \angle FAP = \alpha_1, \qquad \angle PED = \angle PCD = \gamma_2$
$
$$\angle DEF = \alpha_1 + \gamma_2 = \alpha_1 + (60° - \beta_2) = \alpha_1 + 60°
 - (\beta - \beta_1) = 60° + \alpha_1 + \beta_1 - \beta = 60° + (120° - \gamma)
- \beta = 180° - \beta - \gamma = 60°$$

**Angle at F:** By the angle sum (180°), ∠EFD = 60°.

All three angles equal 60°, so **DEF is equilateral**.

**Step 5: Compute the area.**

Since DEF is equilateral with side EF = 6√3:
$$\text{Area} = \frac{\sqrt{3}}{4} \cdot (6\sqrt{3})^2 = \frac{\sqrt{3}}{4} \cdo

The area of the triangular region formed by the three relay stations is $\boxed{
27\sqrt{3}}$ square kilometers.
