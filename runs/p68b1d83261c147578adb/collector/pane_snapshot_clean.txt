## Proof

**Key Lemma (Symmetry Trick).** Let $f:(-a,a)\to\mathbb{R}$ be an odd function (
$f(-x)=-f(x)$) and $g:(-a,a)\to\mathbb{R}$ be an even function ($g(-x)=g(x)$), w
ith both integrable. Then:
$$\int_{-a}^{a} \frac{g(x)}{e^{f(x)}+1}\,dx = \frac{1}{2}\int_{-a}^{a} g(x)\,dx.
$$

*Proof of Lemma.* Denote the integral as $J$. Substituting $x\mapsto -x$:
$$J = \int_{-a}^{a} \frac{g(-x)}{e^{f(-x)}+1}\,dx = \int_{-a}^{a} \frac{g(x)}{e^
{-f(x)}+1}\,dx,$$
using $g$ even and $f$ odd. Adding the two expressions:
$$2J = \int_{-a}^{a} g(x)\left(\frac{1}{e^{f(x)}+1}+\frac{1}{e^{-f(x)}+1}\right)
dx.$$
Since $\frac{1}{e^u+1}+\frac{1}{e^{-u}+1} = \frac{1}{e^u+1}+\frac{e^u}{e^u+1}=1$
 for all $u$, we get $2J=\int_{-a}^a g(x)\,dx$. $\square$

**Verification of the hints.** Each hint integral has the form $\int_{-\pi/2}^{\
pi/2}\frac{\cos x}{e^{f(x)}+1}\,dx$ with $g(x)=\cos x$ (even) and:
- $I_2$: $f(x)=x$, which is odd. ✓
- $I_3$: $f(x)=\sin x$, which is odd. ✓
- $I_4$: $f(x)=1/\sin^3 x$; since $\sin(-x)=-\sin x$, we get $f(-x)=1/(-\sin x)^
3=-1/\sin^3 x=-f(x)$, odd. ✓

By the Lemma, each equals $\frac{1}{2}\int_{-\pi/2}^{\pi/2}\cos x\,dx = \frac{1}
{2}[\sin x]_{-\pi/2}^{\pi/2}=\frac{1}{2}(1-(-1))=1$.

**Main integral.** Write $\gamma^{H_x - H_{-x}} = e^{(H_x - H_{-x})\ln\gamma}$,
so the integrand is $\frac{\cos x}{e^{f(x)}+1}$ where:
$$f(x) = (H_x - H_{-x})\ln\gamma.$$

**$f$ is odd.** The harmonic number for real arguments is $H_x = \psi(x+1)+\gamm
a_{\text{EM}}$ (digamma function). Setting $g_0(x) = H_x - H_{-x}$:
$$g_0(-x) = H_{-x} - H_{-(-x)} = H_{-x} - H_x = -g_0(x).$$
So $g_0$ is odd, and $f(x)=g_0(x)\cdot\ln\gamma$ is odd (constant times odd func
tion).

**$g(x)=\cos x$ is even.** Clear.

**Convergence.** On $(-\pi/2,\pi/2)$, $\cos x>0$ and $\gamma^{H_x-H_{-x}}>0$, so
 the denominator exceeds $1$ and the integrand satisfies $0 < \frac{\cos x}{\gam
ma^{H_x-H_{-x}}+1} < \cos x \le 1$. The integral converges absolutely. (Near $x=
\pm1$ where $H$ has logarithmic singularities, the integrand remains bounded: as
 $x\to1^-$, $H_{-x}\to-\infty$ so $\gamma^{H_x-H_{-x}}\to 0$ and the integrand $
\to\cos 1$; as $x\to -1^+$, $H_x\to-\infty$ so $\gamma^{H_x-H_{-x}}\to+\infty$ a
nd the integrand $\to 0$.)

**Applying the Lemma** with $a=\pi/2$, $f(x)=(H_x-H_{-x})\ln\gamma$, $g(x)=\cos
x$:
$$I = \frac{1}{2}\int_{-\pi/2}^{\pi/2}\cos x\,dx = \frac{1}{2}\Big[\sin x\Big]_{
-\pi/2}^{\pi/2} = \frac{1}{2}\big(1-(-1)\big) = \boxed{1}.$$

**Remark.** The result $I=1$ is independent of the value of $\gamma$ (as long as
 $\gamma>0$): the oddness of $H_x-H_{-x}$ is the only structural property needed
, and it holds for any base of the exponent.
