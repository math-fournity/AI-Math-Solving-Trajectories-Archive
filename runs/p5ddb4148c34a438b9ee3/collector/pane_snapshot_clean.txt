**Claim:** The only differentiable function satisfying the equation is $f(x) = 0
$ for all $x \in \mathbb{R}$.

**Proof.**

**Step 1: Initial values.** Set $y = 0$ (note $x \cdot 0 = 0 \neq 1$):
$$f(x) + f(0) = f\!\left(\frac{x+0}{1-0}\right) = f(x),$$
so $f(0) = 0$.

Set $y = -x$ (valid whenever $x^2 \neq 1$, i.e., $x \neq \pm 1$):
$$f(x) + f(-x) = f\!\left(\frac{x - x}{1 + x^2}\right) = f(0) = 0,$$
so $f(-x) = -f(x)$ for $x \neq \pm 1$. By continuity (differentiability implies
continuity) this extends to $x = \pm 1$ as well: $f$ is **odd**.

**Step 2: Differentiate.** Since $f$ is differentiable, differentiate both sides
 of
$$f(x) + f(y) = f\!\left(\frac{x+y}{1-xy}\right)$$
with respect to $y$. Let $g(x,y) = \frac{x+y}{1-xy}$. Then
$$\frac{\partial g}{\partial y} = \frac{(1-xy) - (x+y)(-x)}{(1-xy)^2} = \frac{1
- xy + x^2 + xy}{(1-xy)^2} = \frac{1+x^2}{(1-xy)^2}.$$
By the chain rule:
$$f'(y) = f'(g(x,y)) \cdot \frac{1+x^2}{(1-xy)^2}.$$

**Step 3: Evaluate at $y = 0$.** Setting $y = 0$ gives $g(x,0) = x$ and $(1-xy)^
2 = 1$:
$$f'(0) = f'(x) \cdot (1 + x^2).$$
Let $c = f'(0)$. Then for all $x \in \mathbb{R}$:
$$f'(x) = \frac{c}{1+x^2}.$$

**Step 4: Integrate.** Integrating:
$$f(x) = c \arctan(x) + d$$
for some constant $d$. Since $f(0) = 0$ and $\arctan(0) = 0$, we get $d = 0$. Th
us
$$f(x) = c \arctan(x).$$

**Step 5: Use the full domain to force $c = 0$.** The functional equation must h
old for **all** $x, y$ with $xy \neq 1$, including the case $xy > 1$.

Take $x = 2$, $y = 3$ (so $xy = 6 > 1 \neq 1$). Then $\frac{x+y}{1-xy} = \frac{5
}{-5} = -1$. The equation requires:
$$f(2) + f(3) = f(-1).$$
Substituting $f(x) = c\arctan(x)$:
$$c\bigl(\arctan(2) + \arctan(3)\bigr) = c\arctan(-1).$$

Now $\arctan(2) + \arctan(3) = \pi + \arctan\!\left(\frac{5}{-5}\right) = \pi +
\arctan(-1) = \pi - \frac{\pi}{4} = \frac{3\pi}{4}$, and $\arctan(-1) = -\frac{\
pi}{4}$. So:
$$c \cdot \frac{3\pi}{4} = c \cdot \left(-\frac{\pi}{4}\right),$$
$$c \cdot \pi = 0,$$
hence $c = 0$.

**Step 6: Verification.** With $c = 0$, we have $f(x) = 0$ for all $x$. Checking
: $0 + 0 = 0$ for all valid $x, y$. ✓

**Conclusion.** The unique differentiable function satisfying the given equation
 is:

$$\boxed{f(x) = 0 \text{ for all } x \in \mathbb{R}.}$$
