## Solution

The function $g$ is defined on $[0, 1/2] \cup C$ (where $C$ is the Cantor set in
 $[0,1]$) by:
- $g(x) = \cos 2\pi x$ on $[0, 1/4] \setminus C$
- $g(x) = \sin 2\pi x$ on $(1/4, 1/2] \setminus C$
- $g(x) = x^3$ on $C$

**Key fact.** The Cantor set $C$ has Lebesgue measure $m(C) = 0$. Since $g$ diff
ers from the piecewise-continuous function
$$h(x) = \begin{cases} \cos 2\pi x, & x \in [0,1/4] \\ \sin 2\pi x, & x \in (1/4
, 1/2] \end{cases}$$
only on the set $C$ (a null set), and $g$ is measurable (each piece is a Borel f
unction restricted to a measurable set), the Lebesgue integral of $g$ equals the
 Lebesgue integral of $h$ over $[0, 1/2]$. The contribution from $x^3$ on $C$ is
 zero because integration over a null set is zero.

**Computation.**

$$\int_0^{1/2} g\,dm = \int_0^{1/4} \cos 2\pi x\,dx + \int_{1/4}^{1/2} \sin 2\pi
 x\,dx.$$

First integral:
$$\int_0^{1/4} \cos 2\pi x\,dx = \left[\frac{\sin 2\pi x}{2\pi}\right]_0^{1/4} =
 \frac{\sin(\pi/2)}{2\pi} - 0 = \frac{1}{2\pi}.$$

Second integral:
$$\int_{1/4}^{1/2} \sin 2\pi x\,dx = \left[-\frac{\cos 2\pi x}{2\pi}\right]_{1/4
}^{1/2} = -\frac{\cos \pi}{2\pi} + \frac{\cos(\pi/2)}{2\pi} = -\frac{(-1)}{2\pi}
 + 0 = \frac{1}{2\pi}.$$

**Result.**

$$\int g\,dm = \frac{1}{2\pi} + \frac{1}{2\pi} = \boxed{\dfrac{1}{\pi}}.$$

### PROOF COMPLETE
