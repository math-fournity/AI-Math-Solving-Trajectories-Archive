## Analysis

Let $f(x) = \sqrt{\sqrt{x+a}-\sqrt{x}} - \sqrt{\sqrt{x}-\sqrt{x-b}}$, integrated
 over $[b, \infty)$.

**Regularity at the lower limit.** At $x=b$: $\sqrt{x-b}=0$, so the second term
equals $\sqrt[4]{b}$ (finite); the first term $\sqrt{\sqrt{a+b}-\sqrt{b}}$ is al
so finite. The integrand is continuous on $[b,\infty)$, so only behavior at $+\i
nfty$ matters.

**Asymptotics at infinity.** Set $t = x^{-1/2} \to 0^+$. Then
$$\sqrt{x+a}-\sqrt{x} = \tfrac{at}{2} - \tfrac{a^{2}t^{3}}{8} + \tfrac{a^{3}t^{5
}}{16} - \cdots,$$
$$\sqrt{x}-\sqrt{x-b} = \tfrac{bt}{2} + \tfrac{b^{2}t^{3}}{8} + \tfrac{b^{3}t^{5
}}{16} + \cdots.$$

Hence $\sqrt{\sqrt{x+a}-\sqrt{x}} = \sqrt{at/2}\,(1 - \tfrac{at^{2}}{8} + \cdots
)$ and $\sqrt{\sqrt{x}-\sqrt{x-b}} = \sqrt{bt/2}\,(1 + \tfrac{bt^{2}}{8} + \cdot
s)$, giving
$$f(x) = \tfrac{1}{\sqrt{2}}(\sqrt{a}-\sqrt{b})\,x^{-1/4} + O(x^{-3/4}).$$

**Case $a \neq b$.** The leading coefficient $C = \tfrac{1}{\sqrt{2}}(\sqrt{a}-\
sqrt{b}) \neq 0$ has fixed sign for large $x$, and $\int^{\infty} x^{-1/4}\,dx$
diverges (exponent $1/4 < 1$). So the improper integral diverges.

**Case $a = b$.** The $x^{-1/4}$ term cancels. With $a=b$, writing $A = \sqrt{x+
a}-\sqrt{x}$, $B = \sqrt{x}-\sqrt{x-a}$:
$$A = \tfrac{at}{2}\bigl(1 - \tfrac{at^{2}}{4} + \tfrac{a^{2}t^{4}}{8} - \cdots\
bigr),\quad B = \tfrac{at}{2}\bigl(1 + \tfrac{at^{2}}{4} + \tfrac{a^{2}t^{4}}{8}
 + \cdots\bigr).$$

Using $(1+u)^{1/2} = 1 + u/2 - u^{2}/8 + \cdots$:
$$\sqrt{A} = \sqrt{\tfrac{at}{2}}\Bigl(1 - \tfrac{at^{2}}{8} + \tfrac{7a^{2}t^{4
}}{128} + \cdots\Bigr),\quad \sqrt{B} = \sqrt{\tfrac{at}{2}}\Bigl(1 + \tfrac{at^
{2}}{8} + \tfrac{7a^{2}t^{4}}{128} + \cdots\Bigr).$$

Subtracting:
$$f(x) = \sqrt{\tfrac{at}{2}}\Bigl(-\tfrac{at^{2}}{4} + O(t^{6})\Bigr) = -\tfrac
{a}{4}\sqrt{\tfrac{a}{2}}\,t^{5/2} + O(t^{13/2}) = -\tfrac{a}{4}\sqrt{\tfrac{a}{
2}}\,x^{-5/4} + O(x^{-13/4}).$$

Since $5/4 > 1$, $\int^{\infty} x^{-5/4}\,dx$ converges, and the remainder is do
minated by an integrable term. Therefore the improper integral converges.

## Conclusion

The improper integral converges if and only if $a = b$. The set of pairs is
$$\boxed{\{(a,b)\in\mathbb{R}_{>0}^{2} : a = b\}}.$$
