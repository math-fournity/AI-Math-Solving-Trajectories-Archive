## 解答

**建立 3-adic 赋值。** 设 $m = n - 3k$。该表达式为

$$\frac{n!}{(n-3k)!\,k!\,3^{k+1}} = \frac{(n)_{3k}}{k!\,3^{k+1}}.$$

对于任意素数 $p \neq 3$：

$$v_p = v_p\!\left(\binom{n}{3k}\right) + v_p((3k)!) - v_p(k!) \geq 0,$$

因为 $\binom{n}{3k}$ 和 $(3k)!/k!$ 都是整数。因此，只有 $p = 3$ 会产生非整数。

**计算 $v_3$。** 利用 Legendre 公式 $v_3(N!) = \frac{N - s_3(N)}{2}$，其中 $s_3$
 为三进制各位数字之和：

$$v_3 = \frac{n - s_3(n)}{2} - \frac{m - s_3(m)}{2} - \frac{k - s_3(k)}{2} - (k+
1) = \frac{s_3(m) + s_3(k) - s_3(n) - 2}{2}.$$

由于 $s_3(3k) = s_3(k)$ 且 $n = m + 3k$，标准的 carry 公式给出：

$$s_3(m) + s_3(3k) - s_3(m+3k) = 2c,$$

其中 $c$ 是在以 3 为底数将 $m$ 和 $3k$ 相加时的进位次数。因此：

$$v_3 = \frac{2c - 2}{2} = c - 1.$$

**非整数条件。** 当且仅当 $v_3 < 0$，即 $c = 0$（无进位）时，该表达式不是整数。

**计算无进位的 $k$ 的数量。** 将 $n$ 写成三进制形式 $n = (d_L \cdots d_1 d_0)_3$
。无进位条件 $m + 3k = n$ 意味着：

- $d_0(m) = d_0(n)$（因为 $3k$ 的个位数字为 $0$），
- 对于每个 $i \geq 1$：$d_i(m) + d_{i-1}(k) = d_i(n)$，因此 $d_{i-1}(k) \in \{0,
 1, \ldots, d_i(n)\}$。

因此 $k$ 的数字为 $d_j(k) \in \{0, \ldots, d_{j+1}(n)\}$，其中 $j = 0, \ldots, L
-1$。包含 $k=0$ 在内的选择总数为：

$$\prod_{i=1}^{L}(d_i(n)+1).$$

排除 $k=0$（因为 $k \geq 1$），使得表达式**不是**整数的 $k \geq 1$ 的数量为：

$$f(n) = \prod_{i=1}^{L}(d_i(n)+1) - 1.$$

**验证小规模情况。**

- $n=3=(10)_3$：$f = (1+1)-1 = 1$。检查 $k=1$：$\frac{3!}{0!\cdot1!\cdot9} = \fr
ac{6}{9}=\frac{2}{3}$。 ✓
- $n=6=(20)_3$：$f = (2+1)-1 = 2$。$k=1$：$\frac{6!}{3!\cdot1!\cdot9}=\frac{720}
{54}=\frac{40}{3}$；$k=2$：$\frac{6!}{0!\cdot2!\cdot27}=\frac{720}{54}=\frac{40}
{3}$。 ✓
- $n=9=(100)_3$：$f = (0+1)(1+1)-1 = 1$。$k=3$：$\frac{9!}{0!\cdot6\cdot81}=\fra
c{362880}{486}=\frac{4480}{6}$，不是整数。 ✓

**求解 $f(n) = 216$。** 我们需要：

$$\prod_{i=1}^{L}(d_i(n)+1) = 217.$$

每个因子 $(d_i(n)+1) \in \{1, 2, 3\}$，因此该乘积必须为 $2^a \cdot 3^b$。但：

$$217 = 7 \times 31,$$

且 $7$ 和 $31$ 都是大于 $3$ 的素数。因此 $217$ **不能**表示为 $2^a \cdot 3^b$ 的
形式。

**结论。** 不存在满足 $f(n) = 216$ 的正整数 $n < 3^8$。
