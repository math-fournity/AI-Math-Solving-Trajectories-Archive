## Proof

The matrix $M$ is defined by $M_{ij} = 1$ if $i+j$ is even, and $M_{ij} = 0$ if
$i+j$ is odd (using 1-based indexing).

**Key observation:** Rows 1 and 3 are identical. Both equal $(1, 0, 1, 0, 1, 0,
\ldots)$.

More generally, every odd-indexed row equals $(1, 0, 1, 0, \ldots)$ and every ev
en-indexed row equals $(0, 1, 0, 1, \ldots)$. Thus $M$ has at most **rank 2** —
all rows are linear combinations of just two distinct row vectors.

**Finite truncations.** Let $D_n$ be the $n \times n$ leading principal submatri
x.

- $n = 1$: $D_1 = [1]$, $\det(D_1) = 1$.
- $n = 2$: $D_2 = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$, $\det(D_2) = 1$
.
- $n \geq 3$: Rows 1 and 3 of $D_n$ are both $(1, 0, 1, 0, \ldots, *)$, i.e., id
entical. A matrix with two identical rows has determinant **0**.

**Infinite determinant.** The determinant of the infinite matrix $M$ is defined
as the limit $\lim_{n \to \infty} \det(D_n)$ (the standard definition for infini
te determinants via principal minors). Since $\det(D_n) = 0$ for all $n \geq 3$,
 we have:

$$\det(M) = \lim_{n \to \infty} \det(D_n) = \lim_{n \to \infty} 0 = 0.$$

**Alternative argument (rank):** The matrix $M$ has rank exactly 2, since:
- Row 1 $= (1,0,1,0,\ldots)$ and Row 2 $= (0,1,0,1,\ldots)$ are linearly indepen
dent.
- Every other row is a copy of one of these two.

An infinite matrix of finite rank $r < \infty$ is singular (its row space is fin
ite-dimensional while the matrix is infinite-dimensional), so $\det(M) = 0$.

$$\boxed{\det(M) = 0}$$
