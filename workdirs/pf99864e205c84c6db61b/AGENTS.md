# Problem

A high-security data vault contains 100 encrypted digital files, each representing a unique set of access codes. A cybersecurity analyst is tasked with identifying the exact contents of every single file. 

The vault’s interface is restricted: the analyst cannot view a file directly. Instead, in a single query, he must select exactly two distinct files. The system then generates two reports for that pair: 
1. A list of all access codes that appear in both selected files (the intersection).
2. A list of all unique access codes that appear in at least one of the two selected files (the union).

The analyst must determine the contents of all 100 files individually. What is the minimum number of queries required to guarantee that he can identify the specific contents of every file?
