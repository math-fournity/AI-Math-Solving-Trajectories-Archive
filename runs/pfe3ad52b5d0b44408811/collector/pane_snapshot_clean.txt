## Proof

**Answer: Yes**, $(C[0,1], \|\cdot\|_1)$ is a countable union of nowhere dense s
ets.

**Construction.** For each $n \in \mathbb{N}$, define
$$F_n = \bigl\{f \in C[0,1] : |f(x)| \le n \text{ for all } x \in [0,1]\bigr\}.$
$
We show that (1) $\bigcup_{n=1}^{\infty} F_n = C[0,1]$, (2) each $F_n$ is closed
 in $(C[0,1], \|\cdot\|_1)$, and (3) each $F_n$ has empty interior. Together the
se establish that $C[0,1]$ is a countable union of nowhere dense sets.

**(1) The union covers $C[0,1]$.** Every $f \in C[0,1]$ is bounded on the compac
t set $[0,1]$, so $\sup_{x \in [0,1]} |f(x)| = M < \infty$. Choosing any $n \ge
M$, we have $f \in F_n$. $\checkmark$

**(2) Each $F_n$ is closed in the $L^1$ norm.** Let $(f_k) \subset F_n$ with $f_
k \to f$ in $\|\cdot\|_1$, where $f \in C[0,1]$. Convergence in $L^1$ implies co
nvergence in measure, so there exists a subsequence $f_{k_j} \to f$ almost every
where. Since $|f_{k_j}(x)| \le n$ for all $x$, we obtain $|f(x)| \le n$ for almo
st every $x$. Because $f$ is continuous, if $|f(x_0)| > n$ for some $x_0$, then
by continuity $|f| > n$ on a neighborhood of $x_0$ of positive measure — contrad
icting $|f| \le n$ a.e. Hence $|f(x)| \le n$ for all $x$, so $f \in F_n$. $\chec
kmark$

**(3) Each $F_n$ has empty interior.** Suppose for contradiction that $F_n$ cont
ains an open $L^1$-ball: there exist $f_0 \in F_n$ and $r > 0$ such that $B_{L^1
}(f_0, r) \subset F_n$.

Construct a continuous "spike" function $h_\varepsilon \in C[0,1]$ with $h_\vare
psilon(1/2) = 1$ and $\|h_\varepsilon\|_1 = \varepsilon/2$ (a triangular spike o
f height 1 and base width $\varepsilon$ centered at $x = 1/2$).

Set $g = f_0 + (2n+1)\, h_\varepsilon$. Then:
- $g(1/2) = f_0(1/2) + (2n+1) \ge -n + (2n+1) = n+1 > n$, so $g \notin F_n$.
- $\|g - f_0\|_1 = (2n+1)\|h_\varepsilon\|_1 = (2n+1)\,\varepsilon/2$.

Choosing $\varepsilon < \frac{2r}{2n+1}$ gives $\|g - f_0\|_1 < r$, so $g \in B_
{L^1}(f_0, r) \subset F_n$.

This contradicts $g \notin F_n$. Hence $F_n$ has empty interior. $\checkmark$

**Conclusion.** Since each $F_n$ is closed with empty interior, each $F_n$ is no
where dense. We have
$$C[0,1] = \bigcup_{n=1}^{\infty} F_n,$$
a countable union of nowhere dense sets. $\blacksquare$
