## Proof

Let $\zeta = \zeta_n$ be a primitive $n$-th root of unity with $n > 2$, and set
$\alpha = \zeta + \zeta^{-1}$.

**Step 1: The degree is at most 2.**

Since $\zeta + \zeta^{-1} = \alpha$, multiplying by $\zeta$ gives $\zeta^2 - \al
pha\zeta + 1 = 0$. Thus $\zeta$ is a root of the polynomial
$$f(x) = x^2 - \alpha x + 1 \in \mathbb{Q}(\alpha)[x],$$
so $[\mathbb{Q}(\zeta) : \mathbb{Q}(\alpha)] \leq 2$.

**Step 2: Galois-theoretic upper bound on $[\mathbb{Q}(\alpha):\mathbb{Q}]$.**

The extension $\mathbb{Q}(\zeta)/\mathbb{Q}$ is Galois with Galois group $G = \o
peratorname{Gal}(\mathbb{Q}(\zeta)/\mathbb{Q}) \cong (\mathbb{Z}/n\mathbb{Z})^\t
imes$, where $a \in (\mathbb{Z}/n\mathbb{Z})^\times$ acts by $\sigma_a(\zeta) =
\zeta^a$. We have $|G| = \varphi(n)$.

Since $n > 2$, we have $-1 \not\equiv 1 \pmod{n}$, so the element $-1 \in (\math
bb{Z}/n\mathbb{Z})^\times$ is nontrivial. The subgroup $H = \{1, -1\} \subset G$
 has order $2$.

The automorphism $\sigma_{-1}$ is complex conjugation: $\sigma_{-1}(\zeta) = \ze
ta^{-1} = \overline{\zeta}$. The element $\alpha = \zeta + \zeta^{-1} = \zeta +
\overline{\zeta} = 2\cos(2\pi/n)$ is real, hence fixed by $\sigma_{-1}$ (and tri
vially by $\sigma_1$). Therefore $\alpha$ lies in the fixed field $K = \mathbb{Q
}(\zeta)^H$, so
$$\mathbb{Q}(\alpha) \subseteq K.$$
By the fundamental theorem of Galois theory,
$$ : \mathbb{Q}] = [G : H] = \frac{\varphi(n)}{2},$$
so $[\mathbb{Q}(\alpha) : \mathbb{Q}] \leq \varphi(n)/2$.

**Step 3: Combining the bounds.**

From the tower $\mathbb{Q} \subseteq \mathbb{Q}(\alpha) \subseteq \mathbb{Q}(\ze
ta)$,
$$[\mathbb{Q}(\zeta) : \mathbb{Q}] = [\mathbb{Q}(\zeta) : \mathbb{Q}(\alpha)] \c
dot [\mathbb{Q}(\alpha) : \mathbb{Q}],$$
that is, $\varphi(n) = [\mathbb{Q}(\zeta) : \mathbb{Q}(\alpha)] \cdot [\mathbb{Q
}(\alpha) : \mathbb{Q}]$.

From Step 1, $[\mathbb{Q}(\zeta) : \mathbb{Q}(\alpha)] \leq 2$, so
$$[\mathbb{Q}(\alpha) : \mathbb{Q}] = \frac{\varphi(n)}{[\mathbb{Q}(\zeta) : \ma
thbb{Q}(\alpha)]} \geq \frac{\varphi(n)}{2}.$$

From Step 2, $[\mathbb{Q}(\alpha) : \mathbb{Q}] \leq \varphi(n)/2$.

Combining these two inequalities:
$$[\mathbb{Q}(\alpha) : \mathbb{Q}] = \frac{\varphi(n)}{2}, \qquad [\mathbb{Q}(\
zeta) : \mathbb{Q}(\alpha)] = 2. \qquad \blacksquare$$
