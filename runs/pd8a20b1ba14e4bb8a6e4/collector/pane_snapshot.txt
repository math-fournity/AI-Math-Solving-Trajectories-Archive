### 级数 1：$S_1 = \sum_{k=2}^{\infty} \{\zeta(2k-1)\}$

对于奇数 $s \geq 3$，我们有 $\zeta(s) = 1 + 2^{-s} + 3^{-s} + \cdots$。由于 $s \
geq 3$，可得 $2^{-s} + 3^{-s} + \cdots < \sum_{j=2}^{\infty} j^{-3} < 1$，因此 $
\lfloor \zeta(s) \rfloor = 1$，从而 $\{\zeta(s)\} = \zeta(s) - 1$。

因此：

$$S_1 = \sum_{k=2}^{\infty} (\zeta(2k-1) - 1) = \sum_{k=2}^{\infty} \sum_{j=2}^{
\infty} j^{-(2k-1)} = \sum_{j=2}^{\infty} \sum_{k=2}^{\infty} j^{-(2k-1)}$$

（通过绝对收敛交换求和顺序。）对于固定的 $j \geq 2$：

$$\sum_{k=2}^{\infty} j^{-(2k-1)} = j^{-3} + j^{-5} + \cdots = \frac{j^{-3}}{1 -
 j^{-2}} = \frac{1}{j^3 - j} = \frac{1}{j(j-1)(j+1)}$$

部分分式分解：

$$\frac{1}{j(j-1)(j+1)} = \frac{1/2}{j-1} - \frac{1}{j} + \frac{1/2}{j+1}$$

该求和式呈裂项相消形式。截取至 $N$ 项：

$$\sum_{j=2}^{N} \left[\frac{1}{2(j-1)} - \frac{1}{j} + \frac{1}{2(j+1)}\right]
= \frac{1}{4} - \frac{1}{2N} + \frac{1}{2(N+1)}$$

当 $N \to \infty$ 时，余项消失，得到：

$$\boxed{S_1 = \frac{1}{4}}$$

### 级数 2：$S_2 = \sum_{n=1}^{\infty} \frac{2^{\langle n \rangle} + 2^{-\langle
 n \rangle}}{2^n}$

**确定 $\langle n \rangle$。** 当 $(m - \tfrac{1}{2})^2 < n < (m + \tfrac{1}{2})
^2$ 时，有 $\langle n \rangle = m$，即 $m^2 - m + \frac{1}{4} < n < m^2 + m + \f
rac{1}{4}$。由于 $n$ 为整数，这意味着对于 $m \geq 1$，有 $n \in \{m^2 - m + 1, \
ldots, m^2 + m\}$（共 $2m$ 个值）。（半整数情况 $n = m^2 + m + \frac{1}{4}$ 永远
不是整数，因此不存在歧义。）

**按 $m$ 分组：**

$$S_2 = \sum_{m=1}^{\infty} (2^m + 2^{-m}) \sum_{n=m^2-m+1}^{m^2+m} 2^{-n}$$

内层求和（等比数列，$a = m^2-m+1$，$b = m^2+m$，共 $2m$ 项）：

$$\sum_{n=a}^{b} 2^{-n} = 2^{-a+1}(1 - 2^{-2m}) = 2^{m - m^2}(1 - 2^{-2m}) = 2^{
m-m^2} - 2^{-m^2-m}$$

乘以 $(2^m + 2^{-m})$：

$$(2^m + 2^{-m})(2^{m-m^2} - 2^{-m^2-m}) = 2^{2m-m^2} - 2^{-m^2} + 2^{-m^2} - 2^
{-m^2-2m} = 2^{2m-m^2} - 2^{-m^2-2m}$$

注意 $2m - m^2 = 1 - (m-1)^2$ 且 $m^2 + 2m = (m+1)^2 - 1$，因此：

$$2^{2m-m^2} - 2^{-m^2-2m} = 2^{1-(m-1)^2} - 2^{1-(m+1)^2}$$

令 $a_m = 2^{1-m^2}$。每一项均为 $a_{m-1} - a_{m+1}$，因此求和裂项相消：

$$S_2 = \sum_{m=1}^{M} (a_{m-1} - a_{m+1}) = a_0 + a_1 - a_M - a_{M+1}$$

当 $M \to \infty$ 时，$a_M = 2^{1-M^2} \to 0$，因此：

$$\boxed{S_2 = a_0 + a_1 = 2^{1} + 2^{0} = 2 + 1 = 3}$$

### 比较

$$S_1 = \frac{1}{4} = 0.25, \qquad S_2 = 3$$

**第二个级数收敛到更大的值**，因为 $3 > \frac{1}{4}$。
