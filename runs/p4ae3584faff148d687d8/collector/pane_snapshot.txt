Looking at this problem, I need to determine whether $\mathfrak{a}^m = \mathfrak
{b}^n$ forces $m = n$, given that $\mathfrak{a}, \mathfrak{b}$ are coprime ideal
s with $\mathfrak{a}\mathfrak{b}$ principal.

**Answer: No.** The equality $\mathfrak{a}^m = \mathfrak{b}^n$ does **not** impl
y $m = n$.

---

## Proof

### Setup in the class group

Since $\mathfrak{a}\mathfrak{b}$ is principal, in the ideal class group $\operat
orname{Cl}(K)$ we have:
$$[\mathfrak{a}]\,[\mathfrak{b}] = [\mathfrak{a}\mathfrak{b}] = 1 \implies [\mat
hfrak{b}] = [\mathfrak{a}]^{-1}.$$

The equality $\mathfrak{a}^m = \mathfrak{b}^n$ (in the class group) becomes:
$$[\mathfrak{a}]^m = [\mathfrak{b}]^n = [\mathfrak{a}]^{-n} \implies [\mathfrak{
a}]^{m+n} = 1.$$

If $[\mathfrak{a}]$ has order $d$ in $\operatorname{Cl}(K)$, this requires only
$d \mid (m+n)$, which does **not** force $m = n$.

### Concrete counterexample

Let $K = \mathbb{Q}(\sqrt{-23})$, which has class number $h_K = 3$, so $\operato
rname{Cl}(K) \cong \mathbb{Z}/3\mathbb{Z}$.

The ring of integers is $\mathcal{O}_K = \mathbb{Z}[\omega]$ where $\omega = \fr
ac{1+\sqrt{-23}}{2}$, with minimal polynomial $x^2 - x + 6$.

**Splitting of 2.** Reducing $x^2 - x + 6 \pmod{2}$ gives $x(x-1)$, so $2$ split
s:
$$(2) = \mathfrak{p}\,\mathfrak{q}, \quad \mathfrak{p} = (2,\,\omega), \quad \ma
thfrak{q} = (2,\,\omega - 1).$$

**Coprimality.** $\mathfrak{p} + \mathfrak{q} \supseteq \{\omega,\, \omega-1\}$,
 so $\omega - (\omega-1) = 1 \in \mathfrak{p}+\mathfrak{q}$, hence $\mathfrak{p}
+\mathfrak{q} = \mathcal{O}_K$. ✓

**Product is principal.** $\mathfrak{p}\mathfrak{q} = (2)$ is principal. ✓

**$[\mathfrak{p}]$ has order 3.** The Minkowski bound is $\frac{2}{\pi}\sqrt{23}
 \approx 3.05$, so every class is represented by an ideal of norm $\leq 3$. The
norm form is $N(a+b\omega) = a^2 + ab + 6b^2$.

- **$[\mathfrak{p}] \neq 1$:** No element of norm 2 exists ($a^2+ab+6b^2=2$ has
no integer solutions: $b=0 \Rightarrow a^2=2$; $|b|\geq 1 \Rightarrow a^2 \pm a
+ 6 = 2$, discriminant $< 0$). So $\mathfrak{p}$ is not principal.

- **$[\mathfrak{p}]^2 \neq 1$:** The only elements of norm 4 are $\pm 2$ (from $
b=0, a=\pm 2$), giving $(\pm 2) = (2) = \mathfrak{p}\mathfrak{q} \neq \mathfrak{
p}^2$. So $\mathfrak{p}^2$ is not principal.

Since $[\mathfrak{p}] \neq 1$, $[\mathfrak{p}]^2 \neq 1$, and $[\mathfrak{p}]^3
= 1$ (class group has order 3), $[\mathfrak{p}]$ has order exactly 3. ✓

(Explicitly, $\mathfrak{q}^3 = (1+\omega)$ since $1+\omega \in \mathfrak{q}$ and
 $N(1+\omega) = 1+1+6 = 8 = 2^3$.)

### The counterexample

Set $\mathfrak{a} = \mathfrak{p}$, $\mathfrak{b} = \mathfrak{q}$. Then:
- $\mathfrak{a}, \mathfrak{b}$ are coprime ✓
- $\mathfrak{a}\mathfrak{b} = (2)$ is principal ✓
- $[\mathfrak{b}] = [\mathfrak{q}] = [\mathfrak{p}]^{-1} = [\mathfrak{p}]^{2} =
[\mathfrak{a}]^{2}$

Therefore:
$$[\mathfrak{a}]^{2} = [\mathfrak{b}]^{1},$$
which gives $\mathfrak{a}^2 = \mathfrak{b}^1$ in the class group, but $m = 2 \ne
q 1 = n$.

### General observation

For any $[\mathfrak{a}]$ of order $d \geq 2$ with $[\mathfrak{b}] = [\mathfrak{a
}]^{-1}$, the equation $[\mathfrak{a}]^{m+n}=1$ only requires $d \mid (m+n)$. Ta
king $m=1, n=d-1$ (with $m \neq n$ whenever $d \geq 3$) always yields a countere
xample. Even for $d=2$, taking $m=2, n=4$ works since $2+4=6$ is divisible by 2.
