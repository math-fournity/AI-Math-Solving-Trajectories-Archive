Looking at this problem, I need to find $xy + yz + zx$ given three equations.

## Setup: Substitution

Let $u = -x+y+z$, $v = x-y+z$, $w = x+y-z$. Then:
- $x = \frac{v+w}{2}$, $y = \frac{u+w}{2}$, $z = \frac{u+v}{2}$
- $y - z = \frac{w-v}{2}$, $z - x = \frac{u-w}{2}$, $x - y = \frac{v-u}{2}$

The equations become:
1. $u^2 - \frac{1}{3} = (w-v)^2 \implies u^2 - (w-v)^2 = \frac{1}{3}$
2. $v^2 - \frac{1}{4} = (u-w)^2 \implies v^2 - (u-w)^2 = \frac{1}{4}$
3. $w^2 - \frac{1}{5} = (v-u)^2 \implies w^2 - (v-u)^2 = \frac{1}{5}$

## Factoring

Define $\alpha = u+v-w$, $\beta = u-v+w$, $\gamma = -u+v+w$. Then:

1. $(u+v-w)(u-v+w) = \alpha\beta = \frac{1}{3}$
2. $(v+w-u)(u+v-w) = \gamma\alpha = \frac{1}{4}$
3. $(u+w-v)(v+w-u) = \beta\gamma = \frac{1}{5}$

## Solving the system

c{4}{3}$ and $\frac{\alpha\beta}{\beta\gamma} = \frac{\alpha}{\gamma} = \frac{5}
{3}$.

So $\alpha = \frac{5}{3}\gamma$, $\beta = \frac{4}{3}\gamma$. From $\beta\gamma
= \frac{1}{5}$:

$$\frac{4}{3}\gamma^2 = \frac{1}{5} \implies \gamma^2 = \frac{3}{20}$$
