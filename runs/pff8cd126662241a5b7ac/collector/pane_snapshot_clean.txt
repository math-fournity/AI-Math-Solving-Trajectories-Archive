## Setup and Key Observation

Recall the definitions:
- $f_i = \bar{p}_i^{-1} \circ \pi_i : G_i \to G/H$, where $\pi_i: G_i \twoheadri
ghtarrow G_i/K_i$.
- $\bar{p}_i(gH) = p_i(g)K_i$, so $\bar{p}_i^{-1}(p_i(g)K_i) = gH$.
- $L = \{(x_1,x_2)\in G_1\times G_2 \mid f_1(x_1)=f_2(x_2)\}$.

**Claim:** The isomorphism is $p$ itself, with codomain restricted to $L$:
$$\boxed{p: G \xrightarrow{\;\sim\;} L,\qquad g\longmapsto \bigl(p_1(g),\,p_2(g)
\bigr).}$$

## Proof

### Step 1: $\operatorname{im}(p)\subseteq L$

For any $g\in G$:
$$f_1(p_1(g)) = \bar{p}_1^{-1}(\pi_1(p_1(g))) = \bar{p}_1^{-1}(p_1(g)K_1) = gH,$
$
$$f_2(p_2(g)) = \bar{p}_2^{-1}(\pi_2(p_2(g))) = \bar{p}_2^{-1}(p_2(g)K_2) = gH.$
$

Hence $f_1(p_1(g))=f_2(p_2(g))=gH$, so $p(g)=(p_1(g),p_2(g))\in L$. Therefore $\
operatorname{im}(p)\subseteq L$.

### Step 2: $L\subseteq \operatorname{im}(p)$

Let $(x_1,x_2)\in L$, so $f_1(x_1)=f_2(x_2)$. Denote this common value in $G/H$
by $gH$ for some $g\in G$.

From $f_1(x_1)=gH$:
$$\bar{p}_1^{-1}(x_1 K_1)=gH \implies x_1 K_1 = \bar{p}_1(gH)=p_1(g)K_1.$$

Since $K_1=p_1(H_2)$, we have $x_1\in p_1(g)\,p_1(H_2)$, so there exists $h_2\in
 H_2$ with
$$x_1 = p_1(g)\,p_1(h_2)=p_1(g\,h_2).$$

Similarly, from $f_2(x_2)=gH$:
$$x_2 K_2 = p_2(g)K_2 = p_2(g)\,p_2(H_1),$$
so there exists $h_1\in H_1$ with
$$x_2 = p_2(g)\,p_2(h_1)=p_2(g\,h_1).$$

Now set $g' = g\,h_2\,h_1 \in G$. Using $h_1\in H_1=\ker p_1$ and $h_2\in H_2=\k
er p_2$:

$$p_1(g') = p_1(g)\,p_1(h_2)\,\underbrace{p_1(h_1)}_{=1} = p_1(g\,h_2) = x_1,$$
$$p_2(g') = p_2(g)\,\underbrace{p_2(h_2)}_{=1}\,p_2(h_1) = p_2(g\,h_1) = x_2.$$

Therefore $p(g')=(x_1,x_2)$, proving $L\subseteq\operatorname{im}(p)$.

### Step 3: Conclusion

From Steps 1 and 2, $\operatorname{im}(p)=L$. The map $p:G\to G_1\times G_2$ is
injective by hypothesis, so $p:G\to L$ is a bijective group homomorphism, hence
an isomorphism:

$$p: G \xrightarrow{\;\sim\;} L = \{(x_1,x_2)\in G_1\times G_2 \mid f_1(x_1)=f_2
(x_2)\},\qquad g\mapsto (p_1(g),\,p_2(g)).$$

This is the **fiber-product (Goursat) isomorphism**: $G$ is identified with the
subdirect product $L\subseteq G_1\times G_2$ cut out by the compatibility condit
ion $f_1(x_1)=f_2(x_2)$, i.e., $G \cong G_1\times_{G/H} G_2$.
