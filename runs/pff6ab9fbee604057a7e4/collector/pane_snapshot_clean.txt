Looking at this problem, I need to find the largest $n$ such that there exists a
n $n$-element subset $S$ of $\{1, 2, \ldots, 2019\}$ where for every $2 \le k \l
e n$, exactly $n-1$ elements of $S$ are divisible by $k$.

## Proof

**Setup.** For each $k \in \{2, \ldots, n\}$, exactly one element of $S$ is **no
t** divisible by $k$; call this the *exception* for $k$. Define $f : \{2, \ldots
, n\} \to S$ mapping each $k$ to its exception.

**Upper bound via LCM.** The domain of $f$ has $n-1$ elements, so the image of $
f$ has at most $n-1$ elements. Since $|S| = n$, at least one element $a \in S$ i
s **not** in the image of $f$, meaning $a$ is not the exception for any $k$, so
$k \mid a$ for all $2 \le k \le n$. Therefore $\operatorname{lcm}(2, 3, \ldots,
n) \mid a$, which requires $\operatorname{lcm}(2, \ldots, n) \le 2019$.

Computing: $\operatorname{lcm}(2, \ldots, 8) = 840 \le 2019$, but $\operatorname
{lcm}(2, \ldots, 9) = 2520 > 2019$. So $n \le 8$.

**Ruling out $n = 8$.** The $k$-values are $\{2,3,4,5,6,7,8\}$. The exception se
ts $T_i$ partition this set. For each $T_i$ and each $k \in T_i$, we need $k \nm
id \operatorname{lcm}(\{2,\ldots,8\} \setminus T_i)$ (otherwise every multiple o
f that LCM is divisible by $k$, making a non-divisible element impossible).

- If $2 \in T_i$: the even elements of $\{2,\ldots,8\}$ are $\{2,4,6,8\}$. For $
2 \nmid \operatorname{lcm}(\{2,\ldots,8\}\setminus T_i)$, all even elements must
 be in $T_i$, so $\{2,4,6,8\} \subseteq T_i$.
- Since $6 \in T_i$ and $6$ is divisible by $3$: for $3$'s exception to work, we
 need $3 \in T_i$ as well (otherwise $6 \in \{2,\ldots,8\}\setminus T_j$ for $k=
3$'s exception set $T_j$, forcing $3 \mid \operatorname{lcm}$). So $T_i \supsete
q \{2,3,4,6,8\}$ — **five** $k$-values in one set.

This leaves at most $\{5, 7\}$ for other exception sets, giving at most $3$ exce
ption elements total. The remaining $8 - 3 = 5$ elements must be universal (divi
sible by $\operatorname{lcm}(2,\ldots,8) = 840$). But $\lfloor 2019/840 \rfloor
= 2$ (only $840$ and $1680$), so we cannot have $5$ universal elements. **$n = 8
$ is impossible.**

**Construction for $n = 7$.** Take $S = \{35, 60, 84, 420, 840, 1260, 1680\}$.

The exception sets are:

- Universal elements: $420, 840, 1260, 1680$ (all multiples of $\operatorname{lc
m}(2,\ldots,7) = 420$). ✓

**Verification** (exactly $6$ divisible, $1$ not, for each $k$):

| $k$ | Not divisible | Divisible (6 elements) |
|-----|--------------|----------------------|
