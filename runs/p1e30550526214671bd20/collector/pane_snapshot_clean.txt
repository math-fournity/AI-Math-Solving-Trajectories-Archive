## Proof

**Setup.** Let $H$ denote the real vector space of Hermitian matrices in $M_n(\m
athbb{C})$, so $\dim_{\mathbb{R}} H = n^2$. The map $g_B : H \to H$, $A \mapsto
BAB^*$, is well-defined since $A = A^*$ implies $(BAB^*)^* = BA^*B^* = BAB^*$.

**Step 1: A complex-linear extension.** Define $T_B : M_n(\mathbb{C}) \to M_n(\m
athbb{C})$ by $T_B(A) = BAB^*$. This is complex-linear. Using the vectorization
identity $\operatorname{vec}(XAY) = (Y^T \otimes X)\operatorname{vec}(A)$, we ge
t
$$\operatorname{vec}(BAB^*) = \bigl((B^*)^T \otimes B\bigr)\operatorname{vec}(A)
 = (\bar{B} \otimes B)\operatorname{vec}(A).$$
So $T_B$ is represented (in the standard basis) by the $n^2 \times n^2$ matrix $
\bar{B} \otimes B$. By the Kronecker product determinant formula $\det(A \otimes
 C) = \det(A)^{\dim C}\det(C)^{\dim A}$, with both factors $n \times n$:
$$\det\nolimits_{\mathbb{C}} T_B = \det(\bar{B} \otimes B) = \det(\bar{B})^{n}\,
\det(B)^{n} = \overline{\det B}^{\,n}\,(\det B)^{n} = |\det B|^{2n}.$$

**Step 2: Real determinant of $T_B$.** Viewing the complex-linear map $T_B$ as a
 real-linear map on the underlying $2n^2$-dimensional real space, $\det_{\mathbb
{R}} T_B = |\det_{\mathbb{C}} T_B|^2 = |\det B|^{4n}$.

**Step 3: Decomposition $M_n(\mathbb{C}) = H \oplus iH$.** Every matrix $M$ deco
mposes uniquely as
$$M = \underbrace{\tfrac{M+M^*}{2}}_{\in\, H} + \underbrace{\tfrac{M-M^*}{2}}_{\
in\, iH}.$$
The map $T_B$ preserves both summands: if $A \in H$ then $T_B(A) = g_B(A) \in H$
; if $A = iC \in iH$ with $C \in H$, then
$$T_B(iC) = B(iC)B^* = i\,(BCB^*) = i\,g_B(C).$$
Under the real-linear identification $iH \xrightarrow{\;\sim\;} H$, $\;iC \mapst
o C$, the restriction $T_B|_{iH}$ is exactly $g_B$. Therefore, as a real-linear
map,
$$T_B = g_B \oplus g_B \quad\text{on } H \oplus iH,$$
and consequently
$$\det\nolimits_{\mathbb{R}} T_B = \det(g_B)\cdot\det(g_B) = \det(g_B)^2.$$

**Step 4: Conclude.** Combining Steps 2 and 3:
$$\det(g_B)^2 = |\det B|^{4n} \quad\Longrightarrow\quad \det(g_B) = \pm\,|\det B
|^{2n}.$$

The function $B \mapsto \det(g_B)$ is a polynomial in the entries of $B$ and $\b
ar{B}$, hence continuous. On the open set $GL_n(\mathbb{C}) = \{B : \det B \neq
0\}$ — which is connected — the sign is constant. At $B = I_n$ we have $g_{I_n}
= \operatorname{id}_H$, so $\det(g_{I_n}) = 1 = |1|^{2n} > 0$, fixing the sign a
s $+1$. By continuity this extends to all of $M_n(\mathbb{C})$.

$$\boxed{\det g_B = |\det B|^{2n}.}$$
