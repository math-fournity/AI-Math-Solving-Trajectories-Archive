## Solution

A number is divisible by $25$ iff its last two digits form $00, 25, 50,$ or $75$
. Since Bob only uses digits $1$–$9$ (no $0$), the only stopping endings are **2
5** and **75**. Thus Bob stops when the last digit is $5$ and the second-to-last
 digit is $2$ or $7$.

**States** (by last digit written):
- $S$: start (no digits yet)
- $5$: last digit is $5$
- $2$: last digit is $2$
- $7$: last digit is $7$
- $O$: last digit is in $\{1,3,4,6,8,9\}$
- $A$: absorbing (just formed $25$ or $75$)

By symmetry, states $2$ and $7$ have identical transition structure. Let $e_2 =
e_7 = e$, and let $e_5, e_O$ be the expected additional digits from states $5, O
$ respectively.

**From state $2$** (write one digit, each with prob $1/9$):
- digit $5$ → stop; digit $2$ → state $2$; digit $7$ → state $7$; six others → s
tate $O$.

$$e = 1 + \tfrac{1}{9}(0 + e + e) + \tfrac{6}{9}e_O \implies 7e = 9 + 6e_O \quad
 (1)$$

**From state $5$**: digit $5$→state $5$; digit $2$→state $2$; digit $7$→state $7
$; six others→state $O$.

$$e_5 = 1 + \tfrac{1}{9}e_5 + \tfrac{2}{9}e + \tfrac{6}{9}e_O \implies 8e_5 = 9
+ 2e + 6e_O \quad (2)$$

**From state $O$**: digit $5$→state $5$; digit $2$→state $2$; digit $7$→state $7
$; six others→state $O$.

$$e_O = 1 + \tfrac{1}{9}e_5 + \tfrac{2}{9}e + \tfrac{6}{9}e_O \implies 3e_O = 9
+ e_5 + 2e \quad (3)$$

**From start $S$**: the first digit is uniformly $1$–$9$, with the same state di
stribution as from $O$, so $e_S = e_O$.

**Solving:** From (1), $e_O = \frac{7e-9}{6}$. From (3), $e_5 = 3e_O - 9 - 2e$.
Substituting into (2):

$$8(3e_O - 9 - 2e) = 9 + 2e + 6e_O \implies 18e_O = 81 + 18e \implies e_O = \tfr
ac{9}{2} + e$$

Setting this equal to (1)'s expression:

$$\tfrac{9}{2} + e = \tfrac{7e - 9}{6} \implies 27 + 6e = 7e - 9 \implies e = 36
$$

Then $e_O = \frac{9}{2} + 36 = \frac{81}{2}$, and $e_5 = 3\cdot\frac{81}{2} - 9
- 72 = \frac{81}{2}$ (consistent).

**Verification:** $8\cdot\frac{81}{2} = 324$ and $9 + 72 + 6\cdot\frac{81}{2} =
9+72+243 = 324$. ✓

Therefore $E = e_S = e_O = \dfrac{81}{2}$, with $\gcd(81,2)=1$, so $m=81,\; n=2$
.

$$100m + n = 100(81) + 2 = \boxed{8102}$$
