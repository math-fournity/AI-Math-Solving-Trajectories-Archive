## Solution

**Setting up coordinates.** Place $B$ at the origin with $\angle ABC = 120°$. Le
t $A = (3, 0)$ (so $AB = 3$ along the $x$-axis) and
$$C = 5(\cos 120°, \sin 120°) = \left(-\tfrac{5}{2},\, \tfrac{5\sqrt{3}}{2}\righ
t).$$

**Applying the parallelism constraints.**

*Constraint 1:* $AB \parallel CE$. Since $AB$ is horizontal, $CE$ is horizontal,
 so $E_y = \tfrac{5\sqrt{3}}{2}$.

*Constraint 2:* $BC \parallel AD$. The direction of $BC$ is $(-\tfrac{5}{2}, \tf
rac{5\sqrt{3}}{2}) \propto (-1, \sqrt{3})$, so
$$D = A + t(-1, \sqrt{3}) = (3 - t,\; t\sqrt{3})$$
for some $t > 0$.

*Constraint 3:* $AC \parallel DE$. The direction of $AC$ is $C - A = (-\tfrac{11
}{2}, \tfrac{5\sqrt{3}}{2}) \propto (-11, 5\sqrt{3})$. So
$$E - D = s(-11,\, 5\sqrt{3})$$
for some scalar $s$. The length condition $DE = 15$ gives
$$|s|\sqrt{121 + 75} = |s|\cdot 14 = 15 \implies |s| = \tfrac{15}{14}.$$

**Determining the sign via convexity.** From $E_y = \tfrac{5\sqrt{3}}{2}$:
$$t\sqrt{3} + 5\sqrt{3}\,s = \tfrac{5\sqrt{3}}{2} \implies t = \tfrac{5}{2} - 5s
.$$

- If $s = +\tfrac{15}{14}$: $t = \tfrac{5}{2} - \tfrac{75}{14} = -\tfrac{20}{7}
< 0$ (invalid, places $D$ incorrectly).
- If $s = -\tfrac{15}{14}$: $t = \tfrac{5}{2} + \tfrac{75}{14} = \tfrac{55}{7} >
 0$. ✓

This yields
$$D = \left(3 - \tfrac{55}{7},\, \tfrac{55\sqrt{3}}{7}\right) = \left(-\tfrac{34
}{7},\, \tfrac{55\sqrt{3}}{7}\right), \qquad E = \left(\tfrac{97}{14},\, \tfrac{
5\sqrt{3}}{2}\right).$$

A cross-product check around $A \to B \to C \to D \to E$ gives all-negative (con
sistently clockwise) signed turns, confirming convexity.

**Verification of $DE = 15$:**
$$E - D = \left(\tfrac{165}{14},\, -\tfrac{75\sqrt{3}}{14}\right), \quad |E-D| =
 \tfrac{1}{14}\sqrt{165^2 + 3\cdot 75^2} = \tfrac{1}{14}\sqrt{44100} = \tfrac{21
0}{14} = 15.\ \checkmark$$

**Computing the areas.**

$$[\triangle ABC] = \tfrac{1}{2}\left|\det\!\begin{pmatrix} 3 & 0 \\ -\tfrac{5}{
2} & \tfrac{5\sqrt{3}}{2}\end{pmatrix}\right| = \tfrac{1}{2}\cdot\tfrac{15\sqrt{
3}}{2} = \tfrac{15\sqrt{3}}{4}.$$

$$[\triangle EBD] = \tfrac{1}{2}\left|\det\!\begin{pmatrix} \tfrac{97}{14} & \tf
rac{5\sqrt{3}}{2} \\[2pt] -\tfrac{34}{7} & \tfrac{55\sqrt{3}}{7}\end{pmatrix}\ri

}\right| = \tfrac{1}{2}\cdot\tfrac{6525\sqrt{3}}{98} = \tfrac{6525\sqrt{3}}{196}
.$$

**The ratio:**
$$\frac{[\triangle ABC]}{[\triangle EBD]} = \frac{\tfrac{15\sqrt{3}}{4}}{\tfrac{
6525\sqrt{3}}{196}} = \frac{15}{4}\cdot\frac{196}{6525} = \frac{2940}{26100} = \
frac{49}{435}.$$

Since $49 = 7^2$ and $435 = 3\cdot 5\cdot 29$ are coprime, we have $m = 49$, $n
= 435$.

$$m + n = 49 + 435 = \boxed{484}.$$
