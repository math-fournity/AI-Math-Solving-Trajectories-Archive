The statement is **false**. Here is a counterexample in $\mathbb{R}^2$.

**Construction.** Let
$$U = \{x \in \mathbb{R}^2 : 0 < |x| < 1\} \quad\text{(punctured open disk)},\qq
uad V = \{x \in \mathbb{R}^2 : 1 < |x| < 2\} \quad\text{(open annulus)}.$$
Both are bounded open subsets of $\mathbb{R}^2$. Define $h: U \to V$ by
$$h(x) = (1 + |x|)\,\frac{x}{|x|}.$$
In polar coordinates this sends radius $r \in (0,1)$ to $1+r \in (1,2)$, keeping
 the angle. It is continuous and bijective, with continuous inverse $h^{-1}(y) =
 (|y|-1)\,\frac{y}{|y|}$. Hence $h$ is a homeomorphism $U \to V$.

**The closures.** Since $0$ is a limit point of $U$,
$$\overline{U} = \{x : |x| \le 1\} = D^2 \quad\text{(closed unit disk)},\qquad \
overline{V} = \{x : 1 \le |x| \le 2\} = A \quad\text{(closed annulus)}.$$

**No extension can exist.** Suppose, for contradiction, that a homeomorphism $H:
 \overline{U} \to \overline{V}$ with $H|_U = h$ existed. Then $H$ would be a hom
eomorphism $D^2 \to A$. But:

- $D^2$ is contractible, so $\pi_1(D^2) = 0$.
- $A = \{1 \le |x| \le 2\}$ deformation retracts onto the circle $\{|x|=1\} \con
g S^1$ via $F_t(x) = (1-t)x + t\,\frac{x}{|x|}$, so $\pi_1(A) \cong \pi_1(S^1) \
cong \mathbb{Z}$.

Homeomorphic spaces have isomorphic fundamental groups, yet $\pi_1(D^2) = 0 \not
\cong \mathbb{Z} = \pi_1(A)$. This is a contradiction.

**Why the extension is forced to fail.** (Intuition.) As $|x| \to 0$ in $U$, the
 homeomorphism $h$ sends $|h(x)| = 1+|x| \to 1$, so any continuous extension wou
ld have to map the puncture $0$ onto the inner boundary circle $\{|x|=1\}$. Thus
 an extension would identify the closed disk with the closed annulus, which is t
opologically impossible — the "missing point" in $U$ becomes a whole missing cir
cle's worth of boundary in $V$, and a single point cannot be mapped homeomorphic
ally onto a circle.

Therefore a homeomorphism between bounded open sets need **not** extend to a hom
eomorphism of their closures. The statement is false.
