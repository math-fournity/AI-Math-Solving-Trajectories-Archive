## Proof

We determine the set
$$S = \left\{ f\in C([0,1],\mathbb{R}) : \int_0^1 t^n f(t)\,dt = 0 \text{ for al
l } n=1,2,3,\dots \right\}.$$

**Step 1: Reduce to a moment problem on all of $\{0,1,2,\dots\}$.**

Define $g(t) = t\,f(t)$. Since $f$ is continuous on $[0,1]$, so is $g$. For ever
y $n = 1,2,3,\dots$,
$$\int_0^1 t^n f(t)\,dt = \int_0^1 t^{n-1}\cdot t\,f(t)\,dt = \int_0^1 t^{n-1} g
(t)\,dt = 0.$$
Setting $k = n-1$, this says
$$\int_0^1 t^k g(t)\,dt = 0 \qquad \text{for all } k = 0,1,2,\dots \tag{$\ast$}$
$

So $g$ is a continuous function on $[0,1]$ whose moments against every monomial
$t^k$ ($k\ge 0$) vanish.

**Step 2: Use the Weierstrass approximation theorem.**

By the Weierstrass approximation theorem, polynomials are dense in $C([0,1])$ wi
th the uniform norm. From $(\ast)$, by linearity of the integral,
$$\int_0^1 p(t)\,g(t)\,dt = 0 \qquad \text{for every polynomial } p. \tag{$\ast\
ast$}$$

**Step 3: Conclude $g \equiv 0$.**

Let $M = \sup_{t\in[0,1]}|g(t)|$. Given $\varepsilon > 0$, choose a polynomial $
p$ with $\sup_{[0,1]}|g - p| < \varepsilon$ (possible by Weierstrass). Then
$$\int_0^1 g(t)^2\,dt = \int_0^1 g(t)\bigl(g(t)-p(t)\bigr)\,dt + \int_0^1 g(t)\,
p(t)\,dt.$$
The second integral vanishes by $(\ast\ast)$. For the first,
$$\left|\int_0^1 g(t)\bigl(g(t)-p(t)\bigr)\,dt\right| \le \int_0^1 |g(t)|\cdot|g
(t)-p(t)|\,dt \le M\cdot\varepsilon.$$
Since $\varepsilon > 0$ is arbitrary, $\int_0^1 g(t)^2\,dt = 0$. As $g^2$ is con
tinuous and non-negative, this forces $g(t) = 0$ for all $t \in [0,1]$.

**Step 4: Recover $f$.**

$g(t) = t\,f(t) = 0$ for all $t \in [0,1]$. For every $t \in (0,1]$, $t \ne 0$,
so $f(t) = 0$. By continuity of $f$ at $0$,
$$f(0) = \lim_{t\to 0^+} f(t) = \lim_{t\to 0^+} 0 = 0.$$
Hence $f \equiv 0$ on $[0,1]$.

**Step 5: Verify the zero function belongs to $S$.**

The identically zero function is continuous and clearly satisfies $\int_0^1 t^n
\cdot 0\,dt = 0$ for all $n\ge 1$.

**Conclusion.** The set $S$ consists of exactly one element, the zero function.
The answer is **(b) contains a single element**.
