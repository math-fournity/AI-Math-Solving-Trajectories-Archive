## Solution

We evaluate $I = \int_0^{\infty}\frac{\arctan^2(x)}{x^2}\,dx$.

### Step 1: Integration by parts

Let $u = \arctan^2(x)$ and $dv = \frac{dx}{x^2}$, so $du = \frac{2\arctan(x)}{1+
x^2}\,dx$ and $v = -\frac{1}{x}$.

$$I = \left[-\frac{\arctan^2(x)}{x}\right]_0^{\infty} + 2\int_0^{\infty}\frac{\a
rctan(x)}{x(1+x^2)}\,dx.$$

**Boundary terms vanish:** As $x\to\infty$, $\arctan(x)\to\pi/2$ so $\frac{\arct
an^2(x)}{x}\to 0$. As $x\to 0^+$, $\arctan(x)\sim x$ so $\frac{\arctan^2(x)}{x}\
sim x\to 0$.

Thus
$$I = 2J, \qquad J = \int_0^{\infty}\frac{\arctan(x)}{x(1+x^2)}\,dx.$$

### Step 2: Substitution $x = \tan\theta$

With $x=\tan\theta$, $dx = \sec^2\theta\,d\theta$, $1+x^2=\sec^2\theta$, and lim
its $0\to\pi/2$:

$$J = \int_0^{\pi/2}\frac{\theta}{\tan\theta\cdot\sec^2\theta}\,\sec^2\theta\,d\
theta = \int_0^{\pi/2}\theta\cot\theta\,d\theta.$$

### Step 3: Integration by parts on $J$

Let $u = \theta$, $dv = \cot\theta\,d\theta$, so $v = \ln\sin\theta$.

$$J = \bigl[\theta\ln\sin\theta\bigr]_0^{\pi/2} - \int_0^{\pi/2}\ln\sin\theta\,d
\theta.$$

**Boundary terms vanish:** At $\theta=\pi/2$: $\frac{\pi}{2}\ln 1 = 0$. At $\the
ta\to 0^+$: $\theta\ln\sin\theta\sim\theta\ln\theta\to 0$.

### Step 4: Classical integral

Using the well-known result $\int_0^{\pi/2}\ln\sin\theta\,d\theta = -\frac{\pi}{
2}\ln 2$ (obtained via the symmetry $\int_0^{\pi/2}\ln\sin\theta\,d\theta = \int
_0^{\pi/2}\ln\cos\theta\,d\theta$ and the identity $2I = \int_0^{\pi/2}\ln\!\big
l(\tfrac{1}{2}\sin 2\theta\bigr)\,d\theta$):

$$J = 0 - \left(-\frac{\pi}{2}\ln 2\right) = \frac{\pi}{2}\ln 2.$$

### Step 5: Final result

$$I = 2J = 2\cdot\frac{\pi}{2}\ln 2 = \pi\ln 2.$$

$$\boxed{\int_0^{\infty}\frac{\arctan^2(x)}{x^2}\,dx = \pi\ln 2.}$$
