**Answer: No.**

**Counterexample.**

Let $X = \ell^1(\mathbb{N})$, so $X^* = \ell^\infty(\mathbb{N})$: every bounded
sequence $a = (a_n)$ defines a functional $\phi_a(x) = \sum_{n=1}^\infty a_n\, x
_n$ with $\|\phi_a\| = \|a\|_\infty$.

Let $D = c_{00}(\mathbb{N})$, the subspace of finitely supported sequences. This
 is dense in $\ell^1$.

For each $N \in \mathbb{N}$, define $a^{(N)} \in \ell^\infty$ by
$$a^{(N)}_n = \begin{cases} 0 & n \leq N, \\ N & n > N. \end{cases}$$
Note $\|a^{(N)}\|_\infty = N$, so the norms are unbounded. Let $\phi_N = \phi_{a
^{(N)}} \in X^*$ and let $\phi = 0$ (the zero functional).

**Convergence on $D$:** Take any $d \in c_{00}$, supported on $\{1,\dots,M\}$. F
or $N \geq M$, every $n \leq M \leq N$ has $a^{(N)}_n = 0$, so
$$\phi_N(d) = \sum_{n=1}^{M} a^{(N)}_n\, d_n = 0 = \phi(d).$$
Hence $\lim_{N\to\infty} \phi_N(d) = \phi(d)$ for every $d \in D$. ✓

**Failure on $X$:** Take $x = (1/n^2)_{n\geq 1} \in \ell^1$ (since $\sum 1/n^2 =
 \pi^2/6 < \infty$). Then
$$\phi_N(x) = \sum_{n=N+1}^{\infty} N \cdot \frac{1}{n^2} = N\sum_{n=N+1}^{\inft
y}\frac{1}{n^2}.$$
By integral comparison, $\frac{1}{N+1} \leq \sum_{n=N+1}^{\infty}\frac{1}{n^2} \
leq \frac{1}{N}$, so
$$\frac{N}{N+1} \leq \phi_N(x) \leq 1.$$
By the squeeze theorem, $\lim_{N\to\infty} \phi_N(x) = 1 \neq 0 = \phi(x)$.

Thus pointwise convergence on the dense subspace $D$ does **not** extend to all
of $X$. $\blacksquare$
