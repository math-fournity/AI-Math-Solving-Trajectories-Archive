**Problem.** Determine all even natural numbers $n$ such that $\{1,2,\ldots,n^2\

## Proof

Let $N = n^2$. The set $\{1,2,\ldots,N\}$ has total sum $S = \frac{N(N+1)}{2}$.
Since $n$ is even, $N$ is even, and we set $|A| = |B| = k = N/2$.

From $S_A/S_B = 39/64$ and $S_A + S_B = S$:
$$S_A = \frac{39}{103}\,S = \frac{39\,N(N+1)}{206}, \qquad S_B = \frac{64}{103}\
,S = \frac{64\,N(N+1)}{206}.$$

### Necessity: $103 \mid n$

Both $S_A$ and $S_B$ must be integers, so $103 \mid S = \frac{N(N+1)}{2}$. Since
 $103$ is an odd prime, this requires $103 \mid N(N+1)$, i.e., $103 \mid N$ or $
103 \mid (N+1)$.

- If $103 \mid (N+1)$, then $N \equiv -1 \pmod{103}$, i.e., $n^2 \equiv -1 \pmod
{103}$. But $103 \equiv 3 \pmod{4}$, so $-1$ is **not** a quadratic residue modu
lo $103$ (by Euler's criterion: $(-1)^{51} = -1$). Contradiction.

Therefore $103 \mid N = n^2$, and since $103$ is prime, $103 \mid n$.

Combined with $n$ even: $\boxed{206 \mid n}$ (since $\gcd(2,103)=1$).

### Sufficiency: every multiple of $206$ works

Assume $206 \mid n$. Then $n$ is even (so $k = N/2$ is an integer) and $103 \mid
 n$, so $103^2 \mid N$, ensuring $S_A$ and $S_B$ are integers (verified: $\frac{
N(N+1)}{2}$ is divisible by $103$ since $103 \mid N$ and $103$ is odd).

We need to select exactly $k = N/2$ elements from $\{1,\ldots,N\}$ summing to $S
_A$. We use:

> **Classical Lemma.** *The set of sums of $k$-element subsets of $\{1,2,\ldots,
N\}$ is the full integer interval*
> $$\left[\frac{k(k+1)}{2},\;\frac{k(2N-k+1)}{2}\right].$$

*Proof of Lemma (by induction on $N$).* For $N=1$: $k=0$ gives sum $0$, $k=1$ gi
ves sum $1$; both are single-point intervals. ✓

Assume the result for $N-1$. A $k$-element subset of $\{1,\ldots,N\}$ either:
- **Excludes $N$**: a $k$-element subset of $\{1,\ldots,N-1\}$, with sums in $\l
eft[\frac{k(k+1)}{2},\,\frac{k(2N-k-1)}{2}\right]$ (by induction).
- **Includes $N$**: $\{N\} \cup$ a $(k{-}1)$-element subset of $\{1,\ldots,N{-}1
\}$, with sums in $\left[N + \frac{(k-1)k}{2},\,N + \frac{(k-1)(2N-k)}{2}\right]
$ (by induction).

These two intervals overlap (or are adjacent) when:
$$\frac{k(2N-k-1)}{2} \geq N + \frac{(k-1)k}{2} - 1,$$
which simplifies to $(k-1)(N-k) \geq k-1$, i.e., $N \geq k+1$ (for $k \geq 2$).
This holds whenever $k \leq N-1$. For $k=1$ the intervals $[1, N-1]$ and $[N, N]
$ are adjacent. For $k=N$ there is a single subset. Hence the union is the full
interval $\left[\frac{k(k+1)}{2},\,\frac{k(2N-k+1)}{2}\right]$. $\square$

**Applying the Lemma.** With $k = N/2$, the achievable range is:
$$\left[\frac{N(N+2)}{8},\;\frac{N(3N+2)}{8}\right].$$

We verify $S_A = \frac{39N(N+1)}{206}$ lies in this interval (for $N \geq 1$):

- **Lower bound:** $\frac{39(N+1)}{206} \geq \frac{N+2}{8} \iff 312(N+1) \geq 20
6(N+2) \iff 106N \geq 100$. ✓ for $N \geq 1$.
- **Upper bound:** $\frac{39(N+1)}{206} \leq \frac{3N+2}{8} \iff 312(N+1) \leq 2
06(3N+2) \iff 312 \leq 306N + 412$. ✓ for $N \geq 1$.

Since $N = n^2 \geq 206^2 \geq 1$, both conditions hold, so $S_A$ is an achievab
le $k$-element subset sum. The complementary $k$ elements automatically sum to $
S_B = S - S_A$, giving the desired partition with $S_A/S_B = 39/64$.

### Conclusion
