# Problem

In a remote digital archives facility, a master encryption key is generated based on a specific security protocol involving a prime-numbered server ID, denoted as $p$.

The facility's automated maintenance script runs at various intervals defined by a positive integer $n$. A security audit is triggered only if the server ID $p$ is a perfect divisor of a specific data checksum calculated during the script's run. The checksum formula is defined as the sum of two power functions: $n^{n+1}$ and $(n+1)^n$.

To ensure the system is perpetually testable, the protocol requires that there must be an infinite number of different maintenance intervals $n$ that trigger this audit for a given server.

Determine all possible prime server IDs $p$ for which the security audit will be triggered infinitely many times.
