Looking at this problem, I need to determine whether neural networks with arbitr

\mathbb{R})$.

**Answer: Yes**, provided the fixed width is at least some threshold depending o
n the input dimension and activation function. I prove this constructively for $
\sigma = \mathrm{ReLU}$ with width $W=3$, then discuss extensions.

## Proof (ReLU, width 3)

**Key tools:**
1. Continuous piecewise-linear (PL) functions are dense in $C([0,1];\mathbb{R})$
.
2. Any continuous PL function on $[0,1]$ can be **exactly represented** by a wid
th-3 ReLU network of sufficient depth.

### Step 1: Representing any PL function with non-negative coefficients

Let $f$ be continuous PL on $[0,1]$ with breakpoints $0<t_1<\cdots<t_L<1$. Then:
$$f(x)=\alpha x+\beta+\sum_{i=1}^L c_i\,\mathrm{ReLU}(x-t_i).$$

Some $c_i$ may be negative. Using the identity $-\mathrm{ReLU}(z)=\mathrm{ReLU}(
-z)-z$, each negative term $-|c_i|\mathrm{ReLU}(x-t_i)$ becomes $|c_i|\mathrm{Re
LU}(t_i-x)+|c_i|t_i-|c_i|x$, absorbing the linear part into $\alpha,\beta$. Afte
r this conversion and adding a large constant $M>0$:

$$f(x)+M = \underbrace{(\alpha' x+\beta'')}_ {\geq\,0\text{ on }[0,1]} + \sum_{i
=1}^L d_i\,\mathrm{ReLU}\!\bigl(s_i(x-t_i)\bigr),$$

where **all $d_i>0$**, $s_i\in\{+1,-1\}$, and $M$ is chosen large enough that $\
alpha'x+\beta''\geq 0$ on $[0,1]$. Since every $d_i>0$ and $\mathrm{ReLU}\geq 0$
, every partial sum $S_k(x)=\alpha'x+\beta''+\sum_{i=1}^k d_i\,\mathrm{ReLU}(s_i
(x-t_i))$ satisfies $S_k(x)\geq 0$ on $[0,1]$.

### Step 2: Width-3 network construction

Use three neurons per layer carrying $(S_k,\; x,\; r_k)$: the running sum, the i
nput (carried), and a temporary register.

**Initialization (Layer 1):**
- $S_0 = \mathrm{ReLU}(\alpha' x+\beta'') = \alpha'x+\beta''$ (since $\geq 0$ on
 $[0,1]$) ✓
- $x = \mathrm{ReLU}(x) = x$ (since $x\in[0,1]$) ✓
- $r = \mathrm{ReLU}(0)=0$ ✓

**For each $i=1,\dots,L$, use two layers:**

*Layer $2i$ (compute the ReLU term):*
- $S \mapsto \mathrm{ReLU}(1\cdot S+0)=S$ (carry, since $S\geq 0$)
- $x\mapsto \mathrm{ReLU}(x)=x$ (carry)
- $r_i = \mathrm{ReLU}(s_i\cdot x - s_i t_i)=\mathrm{ReLU}(s_i(x-t_i))$ ✓

*Layer $2i{+}1$ (add term to running sum):*
- $S \mapsto \mathrm{ReLU}(S + d_i\cdot r_i) = S+d_i r_i$ — valid because $S\geq
 0$ and $d_i r_i\geq 0$, so the argument is $\geq 0$ and $\mathrm{ReLU}$ is the
identity ✓
- $x\mapsto \mathrm{ReLU}(x)=x$ (carry)
- $r\mapsto \mathrm{ReLU}(0)=0$ (reset)

**Output layer (linear readout):**
$$f(x) = 1\cdot S_L + 0\cdot x + 0\cdot r - M = S_L(x)-M.$$

Total depth: $2L+2$ layers, **width 3 throughout**. This exactly represents $f$.
 $\square$

### Step 3: Conclusion for ReLU

Since every continuous PL function on $[0,1]$ is representable by a width-3 ReLU
 network of sufficient depth, and PL functions are dense in $C([0,1];\mathbb{R})
$, the class of width-3 ReLU networks with arbitrary depth is **dense in $C([0,1
];\mathbb{R})$** — i.e., it achieves universal approximation.

## Extension to general activation functions

The result extends well beyond ReLU:

**Sigmoidal $\sigma$** (e.g., sigmoid, tanh): For large $M$, $\sigma(Mt)$ approx
imates the Heaviside step $H(t)$. Using approximate step functions, one can impl
ement a binary addition circuit with a fixed-width subnetwork (each gate approxi
mated by a small $\sigma$-network). The same "running sum" construction then app
lies: each term $c_i\,\sigma(a_i x+b_i)$ is computed in a register and added to
the running sum via the addition subnetwork. The width $W$ is fixed (determined
by the adder circuit complexity, not by $N$), and depth scales as $O(N)$.

**General non-polynomial continuous $\sigma$**: By Leshno, Lin, Pinkus & Schocke
n (1993), the span $\{c\,\sigma(ax+b):a,b,c\in\mathbb{R}\}$ is dense in $C([0,1]
)$ **if and only if** $\sigma$ is not a polynomial. Combined with the depth-base
d simulation argument (any shallow wide network can be approximated by a deep na
rrow network via the running-sum/addition-subnetwork technique), fixed-width arb
itrary-depth networks remain universal approximators.

**Necessity of non-trivial width**: Width $W=1$ is **insufficient** — a width-1
network computes only $\sigma(w_L\sigma(\cdots\sigma(w_1 x+b_1)\cdots)+b_L)$, a
1-parameter family, which is not dense. Some minimum width (depending on input d
imension and $\sigma$) is required.

---

## Summary

**Yes.** Neural networks with arbitrary depth and fixed (sufficiently large) lay
er width can achieve universal approximation of $C([0,1];\mathbb{R})$, for any c
ontinuous non-polynomial activation function $\sigma$. The proof hinges on the *
*running-sum construction**: a deep narrow network simulates a shallow wide netw
ork by building up the sum $\sum_{i=1}^N c_i\,\sigma(a_i x+b_i)$ one term at a t
ime across layers, using a fixed number of neurons to carry the running sum, the
 input, and a temporary register. Depth compensates for width: $O(N)$ layers rep
lace the $O(N)$ width of the shallow network.
