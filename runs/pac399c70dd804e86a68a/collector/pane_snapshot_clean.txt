## Proof

Let $h_a(x) = {}_2F_1(a, b; c; x)$ be the Gauss hypergeometric function with fix
ed $b, c > 0$ and varying parameter $a$. We consider the regime $a + b > c$ (so
$h_a$ is singular at $x = 1$), which is the relevant regime for large $a$.

### Step 1: Derive the Riccati equation for $g(x) = x(1-x)h_a'(x)/h_a(x)$

The hypergeometric ODE is:
$$x(1-x)h'' + [c - (a+b+1)x]\,h' - ab\,h = 0.$$

Dividing by $h$ and writing $h'/h = g/(x(1-x))$, we compute $h''/h = \frac{g'}{x
(1-x)} - \frac{g(1-2x)}{x^2(1-x)^2} + \frac{g^2}{x^2(1-x)^2}$. Substituting and
simplifying:

$$\boxed{g' + \frac{g^2 + \bigl(c - 1 - (a+b-1)x\bigr)\,g}{x(1-x)} = ab.}$$

### Step 2: Limit of $f(x)$ as $x \to 1^-$

By the standard connection formula, when $a + b > c$ (i.e., $c - a - b < 0$), th
e dominant term near $x = 1$ is:

$$h_a(x) \sim K\,(1-x)^{c-a-b}, \quad K = \frac{\Gamma(c)\,\Gamma(a+b-c)}{\Gamma
(a)\,\Gamma(b)} > 0.$$

Therefore:
$$\frac{h_a'(x)}{h_a(x)} \sim \frac{(c-a-b)(1-x)^{c-a-b-1}\cdot(-1)}{(1-x)^{c-a-
b}} = \frac{a+b-c}{1-x},$$

and
$$f(x) = x(1-x)\,\frac{h_a'(x)}{h_a(x)} \;\longrightarrow\; x\,(a+b-c) \;\xright
arrow{x\to 1}\; a+b-c.$$

### Step 3: $g(x) < a + b - c$ for all $x \in (0,1)$

Set $\varphi = a + b - c > 0$. At any point where $g = \varphi$, the Riccati equ
ation gives:

$$g'\Big|_{g=\varphi} = ab - \frac{\varphi^2 + (c-1-(a+b-1)x)\,\varphi}{x(1-x)}.
$$

**Key identity:**
$$\varphi^2 + (c-1-(a+b-1)x)\,\varphi = \varphi\bigl[\varphi + c - 1 - (a+b-1)x\
bigr] = \varphi\bigl[(a+b-1) - (a+b-1)x\bigr] = \varphi\,(a+b-1)(1-x).$$

Therefore:
$$g'\Big|_{g=\varphi} = ab - \frac{\varphi\,(a+b-1)}{x}.$$

For $a$ sufficiently large, $\varphi\,(a+b-1) = (a+b-c)(a+b-1) \sim a^2 > ab \si
m ab$, so the threshold $x^* = \frac{\varphi(a+b-1)}{ab} \sim \frac{a}{b} \to \i
nfty > 1$. Hence for all $x \in (0,1)$:

$$g'\Big|_{g=\varphi} = ab - \frac{\varphi(a+b-1)}{x} < ab - \varphi(a+b-1) < 0.
$$

**Comparison argument:** Since $g(0) = 0 \cdot 1 \cdot \frac{ab/c}{1} = 0 < \var
phi$, suppose for contradiction that $g(x_0) \geq \varphi$ for some $x_0 \in (0,
1)$. By continuity, there exists $x_1 \in (0, x_0]$ with $g(x_1) = \varphi$ and
$g(x) < \varphi$ for $x \in (0, x_1)$. Then $g$ crosses $\varphi$ from below at
$x_1$, so $g'(x_1) \geq 0$. But we just showed $g'(x_1) < 0$—contradiction. $\sq
uare$

### Step 4: Conclusion

From Steps 2 and 3:
- $g(x) < a + b - c$ for all $x \in (0,1)$,
- $\lim_{x \to 1^-} g(x) = a + b - c$.

Therefore:
$$\sup_{x \in [0,1]} f(x) = a + b - c.$$

Since $a + b - c$ is an **affine (linear) function of $a$** (with $b, c$ fixed),
 the maximum value of $f$ grows **linearly** with respect to the parameter $a$.
$\blacksquare$
