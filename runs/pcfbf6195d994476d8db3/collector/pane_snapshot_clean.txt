Looking at this problem, I need to find the minimax value: the engineer chooses
$p \in [0,1]$ to maximize the success probability, while the tester chooses inte
ger $h > 1$ to minimize it.

## Setting Up the Recurrence

Let $g(h)$ = probability of success starting from weight $h$. The process remove
s 2 (prob $1-p$) or 3 (prob $p$) each step, stopping when cumulative removal $\g
eq h$.

**Boundary conditions:** $g(0) = 1$, $g(1) = 0$ (both moves overshoot), and $g(\
text{negative}) = 0$.

**Recurrence** (for $h \geq 2$): $g(h) = (1-p)\,g(h-2) + p\,g(h-3)$.

**Initial values:**
- $g(2) = 1-p$
- $g(3) = p$
- $g(4) = (1-p)^2$
- $g(5) = 2p(1-p)$
- $g(6) = (1-p)^3 + p^2$

## Asymptotic Analysis

The characteristic equation $x^3 = (1-p)x + p$ factors as $(x-1)(x^2+x+p) = 0$.
The root $x=1$ gives a constant limiting value. Using the generating function $G
(z) = 1/(1-(1-p)z^2 - pz^3)$ and factoring out $(1-z)$, the limiting value is:

$$A(p) = \lim_{h\to\infty} g(h) = \frac{1}{2+p}$$

(valid for $0 < p < 1$, where subdominant roots have modulus $< 1$).

## Finding the Optimal $p$

**Key observations at the extremes:**
- $p \to 0$: $g(h) \to 1$ for even $h$, $0$ for odd $h$. Tester picks odd $h$, e
ngineer gets $\approx 0$.
- $p \to 1$: $g(h) \to 1$ for $h \equiv 0 \pmod{3}$, $0$ otherwise. Tester picks
 $h \not\equiv 0$, engineer gets $\approx 0$.

The engineer must balance the worst-case $h$ values. The critical constraint: $g
(3) = p$ is increasing in $p$, while $g(4) = (1-p)^2$ is decreasing. Setting the
m equal:

$$p = (1-p)^2 \implies p^2 - 3p + 1 = 0 \implies p = \frac{3-\sqrt{5}}{2}$$

Let $\alpha = \frac{\sqrt{5}-1}{2}$ (so $\alpha^2 + \alpha = 1$), giving $p = \a
lpha^2 = \frac{3-\sqrt{5}}{2}$.

## Verifying This is Optimal

**At $p = \alpha^2$ (where $1-p = \alpha$):**

| $h$ | $g(h)$ | Value |
|-----|--------|-------|
| 2 | $\alpha$ | $\approx 0.618$ |
| 3 | $\alpha^2$ | $\approx 0.382$ |
| 4 | $\alpha^2$ | $\approx 0.382$ |
| 5 | $2\alpha^3$ | $\approx 0.472$ |
| 6 | $\alpha^2$ | $\approx 0.382$ |
| 7 | $3\alpha^4$ | $\approx 0.438$ |

Note $g(6) = \alpha^3 + \alpha^4 = \alpha^2(\alpha + \alpha^2) = \alpha^2 \cdot
1 = \alpha^2$. So $g(3) = g(4) = g(6) = \alpha^2$.

**Proof that $g(h) \geq \alpha^2$ for all $h \geq 2$:**

Define $u(h) = g(h) - \alpha^2$. Since $\alpha^2$ is a fixed point of the recurr
ence ($\alpha \cdot \alpha^2 + \alpha^2 \cdot \alpha^2 = \alpha^3 + \alpha^4 = \
alpha^2$), $u$ satisfies the same recurrence: $u(h) = \alpha\, u(h-2) + \alpha^2
\, u(h-3)$ for $h \geq 4$.

**Base cases:** $u(2) = \alpha - \alpha^2 = \alpha^3 > 0$; $u(3) = 0$; $u(4) = 0
$; $u(5) = \alpha^5 > 0$; $u(6) = 0$; $u(7) = \alpha^6 > 0$.

**Induction for $h \geq 8$:** Since $u(h-2) \geq 0$ and $u(h-3) \geq 0$ (by indu
ction), and at least one is strictly positive (the only zeros for $h \geq 2$ are
 at $h = 3, 4, 6$; for $h \geq 8$, $h-3 \geq 5$ and $h-2 \geq 6$, with $u(5) > 0
$ covering the $h-2=6$ case), we get $u(h) > 0$.

Therefore $g(h) \geq \alpha^2$ for all $h \geq 2$, with equality at $h = 3, 4, 6
$.

## Confirming Global Optimality

- **If $p < \alpha^2$:** $g(3) = p < \alpha^2$, so $\min_h g(h) < \alpha^2$.
- **If $p > \alpha^2$:** $g(4) = (1-p)^2 < \alpha^2$, so $\min_h g(h) < \alpha^2
$.

Thus $p = \alpha^2 = \frac{3-\sqrt{5}}{2}$ is the **unique global maximizer**, a
nd the game value is $\alpha^2$.
