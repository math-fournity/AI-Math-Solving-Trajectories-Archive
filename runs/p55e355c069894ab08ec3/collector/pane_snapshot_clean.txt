**Polynomial division (Remainder Theorem):** For any polynomial $f(x)$ of degree
 $n$ and any integer $r$, there exists a unique polynomial $q(x)$ of degree $n-1
$ such that
$$f(x) = (x-r)q(x) + f(r).$$
Rearranging:
$$(x-r)q(x) = f(x) - f(r) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + (a_0 - f(r
)).$$

So setting $g(x) = q(x)$ and $b_0 = a_0 - f(r)$, we have $(x-r)g(x) = a_nx^n + \
cdots + a_1x + b_0$ with $g$ of degree $n-1$.

The condition $a_0 \equiv b_0 \pmod{p}$ becomes:
$$a_0 \equiv a_0 - f(r) \pmod{p} \iff f(r) \equiv 0 \pmod{p}.$$

So the conclusion is **equivalent** to $f(r) \equiv 0 \pmod{p}$.

But the hypothesis only gives $f(r) \equiv 0 \pmod{n}$, which does **not** imply
