## Setup

$Y$ is the part of the upper hemisphere $z = \sqrt{1-x^2-y^2}$ lying above the p
lanar region
$$D = \{y \le x,\ x \le 0,\ 0 \le x^2+y^2 \le 1\}.$$

For the upper hemisphere, $z_x = -x/\sqrt{1-x^2-y^2}$, $z_y = -y/\sqrt{1-x^2-y^2
}$, so
$$dS = \sqrt{1+z_x^2+z_y^2}\,dx\,dy = \frac{1}{\sqrt{1-x^2-y^2}}\,dx\,dy.$$

Therefore
$$\int_Y xyz\,dS = \int_D xy\sqrt{1-x^2-y^2}\cdot\frac{dx\,dy}{\sqrt{1-x^2-y^2}}
 = \int_D xy\,dx\,dy.$$

## Polar coordinates

Set $x = r\cos\theta$, $y = r\sin\theta$, $dx\,dy = r\,dr\,d\theta$.

**Finding the $\theta$-range.** The constraint $y \le x$ gives $\sin\theta \le \
cos\theta$, i.e. $\sqrt{2}\sin(\theta-\pi/4)\le 0$, so $\theta \in [5\pi/4,\,9\p
i/4]$ (mod $2\pi$), i.e. $\theta\in[5\pi/4,2\pi]\cup[0,\pi/4]$. The constraint $
x\le 0$ gives $\cos\theta\le 0$, i.e. $\theta\in[\pi/2,3\pi/2]$. Intersecting:
$$[5\pi/4,2\pi]\cup[0,\pi/4]\;\cap\;[\pi/2,3\pi/2] = [5\pi/4,\,3\pi/2].$$

With $0\le r\le 1$, the integral becomes
$$\int_{5\pi/4}^{3\pi/2}\!\!\int_0^1 (r\cos\theta)(r\sin\theta)\,r\,dr\,d\theta
= \left(\int_0^1 r^3\,dr\right)\!\left(\int_{5\pi/4}^{3\pi/2}\cos\theta\sin\thet
a\,d\theta\right).$$

## Evaluation

Radial part:
$$\int_0^1 r^3\,dr = \frac{1}{4}.$$

Angular part, using $\cos\theta\sin\theta = \tfrac12\sin 2\theta$:
$$\int_{5\pi/4}^{3\pi/2}\cos\theta\sin\theta\,d\theta = \frac12\int_{5\pi/4}^{3\
pi/2}\sin 2\theta\,d\theta = -\frac14\Big[\cos 2\theta\Big]_{5\pi/4}^{3\pi/2}.$$
$$\cos\!\Big(2\cdot\tfrac{3\pi}{2}\Big)=\cos 3\pi = -1,\qquad \cos\!\Big(2\cdot\

$$= -\frac14(-1-0)=\frac14.$$

## Result

$$\int_Y xyz\,dS = \frac14\cdot\frac14 = \boxed{\frac{1}{16}}.$$
