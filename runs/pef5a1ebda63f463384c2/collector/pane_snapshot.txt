## Proof

Let $H = L^2([0,1])$ and let $M: H \to H$ be the operator $(Mf)(x) = x^2 f(x)$.

**Step 1: $M$ is a bounded multiplication operator.**

Since $x^2 \in [0,1]$ for $x \in [0,1]$, we have $|x^2 f(x)| \leq |f(x)|$, so $\
|Mf\|_2 \leq \|f\|_2$. Thus $M$ is bounded with $\|M\| \leq 1$ (in fact $\|M\| =
 1$, since the essential supremum of $x^2$ on $[0,1]$ is $1$).

**Step 2: $I + M$ is a multiplication operator.**

$(I+M)f = f + x^2 f = (1+x^2)f$. So $I+M$ is the multiplication operator by the
function $g(x) = 1 + x^2$.

**Step 3: Invertibility.**

A multiplication operator $T_g$ on $L^2([0,1])$ is invertible (with bounded inve
rse) if and only if $g$ is essentially bounded away from zero, i.e., $|g(x)| \ge
q c > 0$ a.e. for some constant $c$.

Here $g(x) = 1 + x^2 \geq 1$ for all $x \in [0,1]$. Hence $I + M$ is invertible,
 and its inverse is the multiplication operator by $\frac{1}{1+x^2}$:
$$((I+M)^{-1}f)(x) = \frac{f(x)}{1+x^2}.$$

**Step 4: Norm of the inverse.**

The norm of a multiplication operator $T_h$ on $L^2$ equals $\|h\|_\infty$ (the
essential supremum of $|h|$). Therefore
$$\|(I+M)^{-1}\| = \left\|\frac{1}{1+x^2}\right\|_{L^\infty([0,1])}.$$

The function $x \mapsto \frac{1}{1+x^2}$ is continuous and strictly decreasing o
n $[0,1]$, so it attains its maximum at $x = 0$:
$$\sup_{x \in [0,1]} \frac{1}{1+x^2} = \frac{1}{1+0} = 1.$$

Since the function is continuous, the essential supremum equals the supremum, so
$$\|(I+M)^{-1}\| = 1.$$

**Conclusion.** The operator $I + M$ is invertible, with inverse $((I+M)^{-1}f)(
x) = \frac{f(x)}{1+x^2}$, and
$$\boxed{\|(I+M)^{-1}\| = 1}.$$
