## Solution

We are asked whether the Diophantine equation $a^n + b^n = c^n$ has integer solu
tions when $n$ is a negative integer. The answer is **yes**.

### Reduction to a reciprocal equation

Let $n = -k$ where $k$ is a positive integer. The equation becomes
$$a^{-k} + b^{-k} = c^{-k}, \qquad \text{i.e.,} \qquad \frac{1}{a^k} + \frac{1}{
b^k} = \frac{1}{c^k}.$$
This requires $a, b, c$ to be **nonzero** integers (otherwise the expression is
undefined).

### Explicit solution for $n = -1$ (i.e., $k = 1$)

For $k = 1$ the equation is
$$\frac{1}{a} + \frac{1}{b} = \frac{1}{c}.$$
Clearing denominators gives $c(a+b) = ab$, equivalently
$$ab - ac - bc = 0 \iff (a-c)(b-c) = c^2.$$

Take $c = 1$. Then we need $(a-1)(b-1) = 1$. The integer factorizations of $1$ g
ive $a - 1 = 1,\; b - 1 = 1$, hence $a = 2,\; b = 2$.

**Verification:**
$$2^{-1} + 2^{-1} = \tfrac{1}{2} + \tfrac{1}{2} = 1 = 1^{-1} = c^{-1}. \quad\che
ckmark$$

So $(a, b, c, n) = (2, 2, 1, -1)$ is an integer solution.

### A family of solutions for general negative $n$

In fact, solutions exist for **every** negative integer $n$. We use the identity
$$\underbrace{\frac{1}{m} + \dots + \frac{1}{m}}_{m \text{ terms}} = 1$$
adapted to two terms. Set $a = b = 2c$ (with $c$ any nonzero integer) and $n = -
1$; then $\frac{1}{2c} + \frac{1}{2c} = \frac{1}{c}$, giving infinitely many sol
utions $(a,b,c) = (2c, 2c, c)$ for $n = -1$.

For higher $|n|$, the equation $\frac{1}{a^k}+\frac{1}{b^k}=\frac{1}{c^k}$ is mo
re restrictive (it is the Fermat-type equation in reciprocal form), but the case
 $n = -1$ already suffices to answer the question affirmatively.

### Conclusion

Integer solutions to $a^n + b^n = c^n$ **do exist** for negative integer values
of $n$. A concrete example is
$$\boxed{(a, b, c, n) = (2, 2, 1, -1): \quad 2^{-1} + 2^{-1} = 1^{-1}.}$$
