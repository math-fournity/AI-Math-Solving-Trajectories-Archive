## Solution

The operator is
$$(Ax)(t) = \int_{-1}^{1} t^2 s\, x(s)\,ds = t^2 \int_{-1}^{1} s\,x(s)\,ds.$$

**Step 1: Recognize the structure.** Set $\varphi(s)=s$ and $\psi(t)=t^2$, both
in $L_2[-1,1]$. Then
$$(Ax)(t) = \langle x,\varphi\rangle\,\psi(t),$$
i.e. $A = \psi\otimes\varphi$ is a **rank-one** operator. In particular $A$ is c
ompact (finite rank), and $\operatorname{Ran} A \subseteq \operatorname{span}\{\
psi\}$.

**Step 2: Nonzero eigenvalues.** Suppose $Ax=\lambda x$ with $\lambda\neq 0$. Th
en $x = \frac{1}{\lambda}Ax = \frac{\langle x,\varphi\rangle}{\lambda}\psi$, so
$x\in\operatorname{span}\{\psi\}$; write $x=c\,\psi$. Substituting back:
$$A(c\psi) = c\,\langle\psi,\varphi\rangle\,\psi = \lambda\,c\,\psi.$$
For $c\neq 0$ this forces $\lambda = \langle\psi,\varphi\rangle$. But
$$\langle\psi,\varphi\rangle = \int_{-1}^{1} t^2\cdot t\,dt = \int_{-1}^{1} t^3\
,dt = 0$$
since $t^3$ is odd. Hence the would-be nonzero eigenvalue is $0$, a contradictio
n. Therefore **$A$ has no nonzero eigenvalues**.

**Step 3: Zero is an eigenvalue.** $\ker A = \{x : \langle x,\varphi\rangle = 0\
}$, i.e. all $x$ with $\int_{-1}^{1} s\,x(s)\,ds=0$. This is a closed hyperplane
 of codimension $1$, so $\ker A$ is infinite-dimensional. Thus $0$ is an eigenva
lue of infinite multiplicity.

**Step 4: The full spectrum.** For a compact operator on an infinite-dimensional
 Banach space, the spectrum is
$$\sigma(A) = \{0\}\cup\{\text{nonzero eigenvalues}\}.$$
Since there are no nonzero eigenvalues (Step 2) and $0\in\sigma(A)$ necessarily
(the space is infinite-dimensional, so $A$ cannot be invertible), we obtain
$$\sigma(A)=\{0\}.$$

**Conclusion.** The spectrum of $A$ consists of the single point $0$:
$$\boxed{\sigma(A)=\{0\}}.$$
Moreover, $0$ is an eigenvalue of infinite multiplicity (with eigenspace $\ker A
 = \{x\in L_2[-1,1] : \int_{-1}^{1} s\,x(s)\,ds = 0\}$), and there are no other
spectral values. The resolvent set is $\rho(A)=\mathbb{C}\setminus\{0\}$, with $
(A-\lambda I)^{-1} = -\frac{1}{\lambda}I - \frac{1}{\lambda^2}\,\psi\otimes\varp
hi$ for $\lambda\neq 0$ (readily verified: $(A-\lambda I)\bigl(-\frac{1}{\lambda
