**Lower Bound (8 weighings).**

*Claim:* Any of the 201 coins can be the 101st smallest, so we must distinguish
201 possible answers.

dots < s_k < g_1 < \cdots < g_{101-k} < s_{k+1} < \cdots < s_{100} < g_{102-k} <

Since all 201 outcomes are achievable, and each weighing yields a binary result,
 $k$ weighings distinguish at most $2^k$ outcomes. We need $2^k \ge 201$. Since
$2^7 = 128 < 201 \le 256 = 2^8$, we require **$k \ge 8$**.

**Upper Bound (8 weighings suffice).**

Define sentinel values $s_0 = g_0 = -\infty$ and $s_{101} = g_{102} = +\infty$.

*Key observation:* If exactly $i$ silver coins are among the 101 smallest, then
$j = 101 - i$ gold coins are among the 101 smallest, and the 101st smallest is $

$$s_i \le g_{j+1} = g_{102-i} \quad \text{and} \quad g_j \le s_{i+1}.$$

*Monotonicity:* As $i$ increases, $s_i$ increases and $g_{102-i}$ decreases, so

*Correctness of $i^*$:* By definition, $s_{i^*} \le g_{102-i^*} = g_{j^*+1}$. By

coins are $\{s_1, \ldots, s_{i^*}\} \cup \{g_1, \ldots, g_{j^*}\}$, and the 101s
