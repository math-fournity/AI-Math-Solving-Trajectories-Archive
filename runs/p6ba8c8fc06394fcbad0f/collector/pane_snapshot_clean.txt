## Proof

Let $X$ be a $C^*$-algebra and let $a, b \in X$ be **positive** elements satisfy
ing $a^*a = b^*b$.

**Key observation.** Since $a$ and $b$ are positive, $a = a^*$ and $b = b^*$, an
d their spectra lie in $[0, \infty)$. The hypothesis $a^*a = b^*b$ therefore rea
ds
$$a^2 = b^2.$$

**Claim.** For positive elements, $a^2 = b^2$ forces $a = b$.

*Proof of claim.* For any positive element $x \in X$, we have
$$x = (x^2)^{1/2}.$$
Indeed, $x$ is positive with $\sigma(x) \subseteq [0,\infty)$. By continuous fun
ctional calculus, $x^2 = g(x)$ where $g(t) = t^2$, and $\sigma(x^2) = \{t^2 : t
\in \sigma(x)\} \subseteq [0,\infty)$. Taking the square root (the function $h(s
) = \sqrt{s}$ on $\sigma(x^2)$) gives
$$(x^2)^{1/2} = h(x^2) = (h \circ g)(x),$$
where $(h \circ g)(t) = \sqrt{t^2} = |t| = t$ for all $t \in \sigma(x) \subseteq
 [0,\infty)$. Hence $(h \circ g)(x) = x$, i.e. $(x^2)^{1/2} = x$. $\square$

Applying the claim:
$$a = (a^2)^{1/2} = (b^2)^{1/2} = b.$$

Therefore $a = b$.

**Existence of the unitary.** Assuming $X$ is unital (which is implicit in the p
roblem's reference to a "unitary element $u$ in $X$," since unitaries require a
unit), take
$$u = \mathbf{1},$$
the unit of $X$. Then $u^*u = uu^* = \mathbf{1}$, so $u$ is unitary, and
$$ub = \mathbf{1}\cdot b = b = a.$$

Thus such a unitary **always exists**; in fact the positivity hypothesis forces
$a = b$, so the identity unitary suffices.

**Remark on the non-unital case.** If $X$ is not unital, the notion of a unitary
 element of $X$ is not defined (there is no identity element to satisfy $u^*u =
uu^* = \mathbf{1}$). In that setting the question is moot; passing to the unitiz
ation $\widetilde{X}$, the same argument gives $u = \mathbf{1}$.

**Conclusion.** Yes. For positive $a, b$ with $a^*a = b^*b$, we have $a = b$, an
d $u = \mathbf{1}$ is a unitary satisfying $a = ub$.
