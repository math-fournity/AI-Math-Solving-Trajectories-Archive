# Problem

A network security firm is designing a series of $n \times n$ square server grids, where $n$ is a positive integer. Each cell in the grid can host at most one security probe. A grid configuration is classified as "Optimally Encrypted" if it satisfies the following three conditions:
1. Every cell along both the main diagonal and the anti-diagonal of the grid contains a security probe.
2. Every individual row in the grid contains an odd total number of security probes.
3. Every individual column in the grid contains an odd total number of security probes.

Let $S$ be the set of all possible grid dimensions $n$ for which there exists an "Optimally Encrypted" configuration containing exactly $\lceil n^2/2 \rceil$ security probes in total.

Find the sum of all elements in the set $S$ that are less than or equal to 20.
