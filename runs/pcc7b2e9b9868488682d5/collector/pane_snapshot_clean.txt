## Solution

**Domain.** We need $3-x \ge 0$ and $x+1 \ge 0$, so $-1 \le x \le 3$.

**Reduction.** Set $a = \sqrt{3-x}$, $b = \sqrt{x+1}$. Then
$$a^2 + b^2 = (3-x)+(x+1) = 4, \qquad ab = \sqrt{(3-x)(x+1)} = \sqrt{4-(x-1)^2}.
$$
The inequality $a - b > \tfrac12$ forces $a > b$, i.e. $3-x > x+1$, i.e. $x < 1$
.

**Squaring.** On $x < 1$ we have $a - b > 0$, and $\tfrac12 > 0$, so squaring pr
eserves the inequality:
$$a - b > \tfrac12 \iff (a-b)^2 > \tfrac14 \iff a^2 - 2ab + b^2 > \tfrac14 \iff
4 - 2ab > \tfrac14,$$
that is,
$$ab < \frac{15}{8}.$$
Substituting $ab = \sqrt{4-(x-1)^2}$ (which is nonnegative on the domain):
$$\sqrt{4-(x-1)^2} < \frac{15}{8} \iff 4-(x-1)^2 < \frac{225}{64} \iff (x-1)^2 >
 \frac{31}{64}.$$

**Solving.** $|x-1| > \frac{\sqrt{31}}{8}$. Since we already require $x < 1$, we
 take the left branch:
$$x < 1 - \frac{\sqrt{31}}{8}.$$
Combining with the domain $x \ge -1$:
$$-1 \le x < 1 - \frac{\sqrt{31}}{8}.$$

**Endpoint check.** At $x = 1 - \frac{\sqrt{31}}{8}$: $(x-1)^2 = \frac{31}{64}$,
 so $ab = \sqrt{4-\frac{31}{64}} = \sqrt{\frac{225}{64}} = \frac{15}{8}$, giving
 $(a-b)^2 = 4 - 2\cdot\frac{15}{8} = \frac14$, hence $a-b = \frac12$ (positive s
ince $a>b$). Equality holds, so this endpoint is correctly excluded. At $x = -1$
: $a=2$, $b=0$, $a-b = 2 > \tfrac12$. ✓

**Answer.** The set of all real $x$ satisfying the inequality is
$$\boxed{-1 \le x < 1 - \dfrac{\sqrt{31}}{8}}.$$
