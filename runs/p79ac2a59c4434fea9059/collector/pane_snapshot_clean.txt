## Proof

Assume \(A \neq 0\) (the zero operator trivially satisfies the hypothesis but ad
mits no scalar \(\lambda\) with \(\lambda A\) unitary, so the statement is meani
ngful only for nonzero \(A\); equivalently the problem implicitly excludes this
degenerate case). We work over \(\mathbb{F} = \mathbb{R}\) or \(\mathbb{C}\), wi
th inner product \(\langle\cdot,\cdot\rangle\), and assume \(V\) is finite-dimen
sional so that injectivity of a linear operator implies surjectivity.

**Claim 1.** If \(\|u\| = \|v\|\), then \(\|Au\| = \|Av\|\).

*Proof.* We have
\[
\langle u+v,\, u-v\rangle = \|u\|^{2} - \|v\|^{2} = 0,
\]
so \(u+v \perp u-v\). By the hypothesis, \(A(u+v) \perp A(u-v)\), i.e.
\[
\langle Au+Av,\, Au-Av\rangle = \|Au\|^{2} - \|Av\|^{2} = 0.
\]
Hence \(\|Au\| = \|Av\|\). \(\square\)

**Claim 2.** There exists a constant \(c > 0\) such that \(\|Au\| = c\,\|u\|\) f
or all \(u \in V\).

*Proof.* By Claim 1, \(\|Au\|\) depends only on \(\|u\|\); write \(\|Au\| = g(\|
u\|)\) for some \(g:[0,\infty)\to[0,\infty)\). By linearity of \(A\),
\[
g(|t|\,\|u\|) = \|A(tu)\| = |t|\,\|Au\| = |t|\,g(\|u\|).
\]
Pick \(u_{0}\) with \(\|u_{0}\| = 1\). Since \(A \neq 0\), we may choose \(u_{0}
\) with \(Au_{0}\neq 0\) (otherwise \(A\) vanishes on the unit sphere and hence
everywhere). Set \(c := g(1) = \|Au_{0}\| > 0\). Then \(g(r) = cr\) for all \(r
\ge 0\), giving \(\|Au\| = c\,\|u\|\). \(\square\)

**Claim 3.** \(\langle Au, Av\rangle = c^{2}\langle u, v\rangle\) for all \(u, v
 \in V\).

*Proof.* Use the polarization identity. In the real case,
\[
\langle u,v\rangle = \tfrac{1}{4}\bigl(\|u+v\|^{2} - \|u-v\|^{2}\bigr).
\]
Applying \(A\) and using Claim 2,
\[
\langle Au,Av\rangle = \tfrac{1}{4}\bigl(\|A(u+v)\|^{2} - \|A(u-v)\|^{2}\bigr) =
 \tfrac{c^{2}}{4}\bigl(\|u+v\|^{2} - \|u-v\|^{2}\bigr) = c^{2}\langle u,v\rangle
.
\]
In the complex case the identity
\[
\langle u,v\rangle = \tfrac{1}{4}\bigl(\|u+v\|^{2} - \|u-v\|^{2} + i\|u+iv\|^{2}
 - i\|u-iv\|^{2}\bigr)
\]
yields the same conclusion by the identical substitution. \(\square\)

**Conclusion.** Set \(\lambda = 1/c\). Then for all \(u, v\),
\[
\langle \lambda A u,\, \lambda A v\rangle = \lambda^{2}\langle Au, Av\rangle = \
frac{1}{c^{2}}\cdot c^{2}\langle u,v\rangle = \langle u, v\rangle.
\]
Thus \(\lambda A\) preserves the inner product, so \((\lambda A)^{*}(\lambda A)
= I\); hence \(\lambda A\) is injective. Since \(V\) is finite-dimensional, inje
ctivity implies surjectivity, so \((\lambda A)(\lambda A)^{*} = I\) as well. The
refore \(\lambda A\) is unitary. \(\blacksquare\)
