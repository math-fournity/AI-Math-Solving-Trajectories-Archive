## Setting Up the Cyclic Map

The three equations are:
- z² + 5x = 10z
- y² + 5z = 10y
- x² + 5y = 10x

Define **g(t) = (10t − t²)/5 = −t²/5 + 2t**. Then each equation says the "predec
essor" equals g of the current variable:
- x = g(z) (from eq. 1: 5x = 10z − z²)
- z = g(y) (from eq. 2: 5z = 10y − y²)
- y = g(x) (from eq. 3: 5y = 10x − x²)

Chaining: x = g(z), y = g(x) = g²(z), and z = g(y) = g³(z).

**The system is equivalent to g³(z) = z.**
