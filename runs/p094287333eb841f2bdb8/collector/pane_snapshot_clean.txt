## Proof

### Step 1: Determine $f(2)$ and $f(3)$

Set $p = 2, q = 3$. Then $f(2)^{f(3)} - f(3)^{f(2)} = 2^3 - 3^2 = -1$, i.e.,

$$f(3)^{f(2)} - f(2)^{f(3)} = 1.$$

Let $a = f(2), b = f(3)$ (both primes). We solve $b^a - a^b = 1$.

**Case $a = b$:** gives $0 \neq 1$.

**Case $a = 2$:** $b^2 - 2^b = 1$. Check $b = 3$: $9 - 8 = 1$ ✓. For $b = 2$: $0
 \neq 1$. For $b \geq 5$: $2^b > b^2$ (true at $b=5$: $32 > 25$, and preserved b
y induction since $2b^2 > (b+1)^2$ for $b \geq 3$), so $b^2 - 2^b < 0$.

**Case $b = 2$:** $2^a - a^2 = 1$. Check $a = 3$: $8 - 9 = -1 \neq 1$. For $a \g
eq 5$: $2^a - a^2$ is strictly increasing (derivative $2^a \ln 2 - 2a > 0$ for $
a \geq 5$) with value $7$ at $a=5$, so never $1$.

**Case $a, b \geq 3$, $a \neq b$:** The function $h(x) = x^{1/x}$ is strictly de
creasing for $x \geq 3$ (since $h'(x) = x^{1/x}\cdot\frac{1-\ln x}{x^2} < 0$ for
 $x > e$). If $a < b$: $a^{1/a} > b^{1/b}$, so $a^b > b^a$, giving $b^a - a^b <
0 \neq 1$. If $a > b \geq 3$: $b^a > a^b > 0$, and the smallest value occurs at
$(b,a) = (3,5)$: $3^5 - 5^3 = 118 > 1$; all other cases give larger values. So n
ever $1$.

**Conclusion:** The unique solution is $(a, b) = (2, 3)$, hence $\boxed{f(2) = 2
, \; f(3) = 3}$.

### Step 2: Determine $f(q)$ for all primes $q \geq 5$

Set $p = 2$ and let $q$ be any prime. Using $f(2) = 2$:

$$2^{f(q)} - f(q)^2 = 2^q - q^2.$$

Define $g(x) = 2^x - x^2$. We need $g(f(q)) = g(q)$ for all primes $q$.

**$g$ is strictly increasing on $[5, \infty)$:** We have $g'(x) = 2^x \ln 2 - 2x
$ and $g''(x) = 2^x(\ln 2)^2 - 2$. At $x = 5$: $g'(5) = 32\ln 2 - 10 \approx 12.
2 > 0$ and $g''(5) = 32(\ln 2)^2 - 2 \approx 13.4 > 0$. Since $g''(x) > 0$ for $
x \geq 5$, $g'$ is increasing, so $g'(x) > 0$ for all $x \geq 5$. Thus $g$ is st
rictly increasing on $[5, \infty)$.

**Values at small primes:** $g(2) = 0$, $g(3) = -1$, $g(5) = 7$.

Now fix a prime $q \geq 5$. Then $g(q) \geq g(5) = 7 > 0$.

- If $f(q) = 2$: $g(f(q)) = 0 \neq g(q) \geq 7$. ✗
- If $f(q) = 3$: $g(f(q)) = -1 \neq g(q) \geq 7$. ✗
- If $f(q) \geq 5$: Since both $f(q)$ and $q$ lie in $[5, \infty)$ where $g$ is
strictly increasing, $g(f(q)) = g(q)$ implies $f(q) = q$. ✓

Therefore $f(q) = q$ for every prime $q \geq 5$.

### Step 3: Conclusion

Combining all steps:

$$f(2) = 2, \quad f(3) = 3, \quad f(q) = q \text{ for all primes } q \geq 5.$$

Hence $f(p) = p$ for all primes $p$, i.e., **$f$ is the identity function**.

**Verification:** For $f = \mathrm{id}$, LHS $= p^q - q^p =$ RHS for all primes
$p, q$. ✓

The unique solution is $f(p) = p$ for all $p \in \mathbb{P}$.
