# Proof: The Axiom of Regularity Can Fail

We show that the axiom of regularity is **independent** of the remaining axioms
of ZF (denoted ZF⁻). Specifically, we establish:

1. **Regularity can fail**: If ZF is consistent, then ZF⁻ + ¬Regularity is consi
stent.
2. **Regularity can hold**: If ZF⁻ is consistent, then ZF is consistent.

Together these prove that regularity is independent of ZF⁻, and in particular, *
*regularity can fail**.

---

## Part 1: Regularity Can Fail — Con(ZF) → Con(ZF⁻ + ¬Regularity)

We use the **Rieger–Bernays permutation method**.

Let (M, ∈) be a model of ZF. Define a class permutation π of M by:

- π(∅) = {∅},  π({∅}) = ∅,  and π(x) = x for all other x.

This is a definable class of M (given by an explicit first-order formula), and i
s a bijection of M. Define a new binary relation E on M by:

> **x E y  iff  x ∈ π(y).**

**Claim:** (M, E) ⊨ ZF⁻ + ¬Regularity.

### Regularity fails

Observe: ∅ E ∅ because ∅ ∈ π(∅) = {∅}. ✓

The E-singleton of ∅ is the set c such that z E c iff z = ∅, i.e., π(c) = {∅}, i
.e., c = π⁻¹({∅}) = ∅. So the E-singleton of ∅ is ∅ itself, and its sole E-eleme
nt is ∅, with ∅ E ∅. Thus ∅ has no E-minimal element. **Regularity fails.** ✓

### ZF⁻ holds in (M, E)

We verify each axiom:

- **Extensionality:** If x, y have the same E-elements, then ∀z (z ∈ π(x) ↔ z ∈
π(y)), so π(x) = π(y), hence x = y. ✓

- **Empty set:** ∅_E = π⁻¹(∅) = {∅} has no E-elements since π({∅}) = ∅. ✓

- **Pairing:** The E-pair of a, b is π⁻¹({a, b}), which exists in M by Pairing i
n (M, ∈). ✓

- **Union:** The E-union of a is ⋃π[π(a)]. Since π is a definable class function
 of M, π[π(a)] = {π(u) : u ∈ π(a)} is a set in M by Replacement, and its union e
xists by Union. ✓

- **Power Set:** The E-power set of a is π⁻¹[P(π(a))]. Since P(π(a)) exists by P
ower Set in M, and π⁻¹ is definable, π⁻¹[P(π(a))] exists by Replacement. ✓

- **Infinity:** The set π⁻¹(ω) is E-inductive: it contains ∅_E = π⁻¹(∅) and is c
losed under the E-successor operation (which corresponds via π to the ordinary s
uccessor). ✓

- **Replacement:** Any E-definable class function F is also ∈-definable in M (si
nce E is ∈-definable via the formula x ∈ π(y)). For any E-set a, F[a] is a set i
n M by Replacement in (M, ∈), hence an E-set. ✓

Thus (M, E) ⊨ ZF⁻ + ¬Regularity, establishing **Con(ZF) → Con(ZF⁻ + ¬Regularity)
**. ∎

---

## Part 2: Regularity Is Consistent with ZF⁻ — Con(ZF⁻) → Con(ZF)

Within ZF⁻, define the **von Neumann hierarchy**:

- V₀ = ∅,  V_{α+1} = P(V_α),  V_λ = ⋃_{α<λ} V_α for limit λ.

Let **WF = ⋃_α V_α** (the class of well-founded sets). This construction uses on
ly Power Set and Replacement, both available in ZF⁻, so ZF⁻ proves V_α exists fo
r every ordinal α.

**ZF⁻ proves that WF satisfies every axiom of ZF:**

- **Extensionality:** WF is transitive, so extensionality holds. ✓
- **Empty set, Pairing, Union, Power Set, Infinity:** These hold by the closure
properties of the hierarchy: if a, b ∈ V_α then {a,b} ∈ V_{α+1}; if a ∈ V_α then
 ⋃a ∈ V_α and P(a) ∈ V_{α+1}; ω ∈ V_{ω+1}. ✓
- **Replacement:** If F is a definable function and a ∈ WF, then F[a] is a set o
f well-founded sets, each lying in some V_α; by Replacement in ZF⁻, F[a] is a se
t, and its elements are bounded in rank, so F[a] ∈ WF. ✓
- **Regularity:** Every non-empty set a ∈ V_α has elements of rank < α. Choose b
 ∈ a of **minimal rank**. For any c ∈ b, we have ρ(c) < ρ(b). If c ∈ a as well,
then ρ(c) ≥ ρ(b) (since b has minimal rank in a)—contradiction. So b ∩ a = ∅. **
Regularity holds in WF.** ✓

Since ZF⁻ proves σ^WF (the relativization to WF) for every axiom σ of ZF, any pr
oof of contradiction from ZF would, upon relativization to WF, yield a proof of
contradiction from ZF⁻. Hence **Con(ZF⁻) → Con(ZF)**. ∎

---

## Conclusion

Assuming ZF is consistent:

| Theory | Consistent? | Source |
|---|---|---|
| ZF (with Regularity) | Yes | Part 2 (or trivially, ZF ⊨ ZF) |
| ZF⁻ + ¬Regularity | Yes | Part 1 (Rieger–Bernays) |

The axiom of regularity is **independent** of the other axioms of ZF. In particu
lar, **the axiom of regularity can fail**: there exists a consistent set theory
(ZF⁻ + ¬Regularity) in which it does not hold, as demonstrated by the Rieger–Ber
nays permutation construction producing a model with self-membered sets (∅ E ∅).
