## Vandermonde Structure

The Vandermonde $V(y_0, \ldots, y_{n-1}) = \sum_{\sigma \in S_n} \operatorname{s
gn}(\sigma) \prod_{j=0}^{n-1} y_j^{\sigma(j)}$, so every monomial term has expon
ents that are a **permutation of $(0, 1, \ldots, n-1)$**.

- **Row Vandermonde** (3 variables): each term has exponents = permutation of $(
0, 1, 2)$. Each variable gets degree in $\{0, 1, 2\}$.
- **Column Vandermonde** (4 variables): each term has exponents = permutation of
 $(0, 1, 2, 3)$. Each variable gets degree in $\{0, 1, 2, 3\}$, and **one variab
le per column necessarily receives degree 3**.

## The Impossibility

For the monomial $x_1^2 x_2^2 \cdots x_{12}^2$, each variable $x_{r,c}$ must hav

$$\underbrace{a_{r,c}}_{\text{from row Vandermonde}} + \underbrace{b_{r,c}}_{\te
xt{from column Vandermonde}} = 2$$

Since $a_{r,c} \in \{0, 1, 2\}$ (row constraint) and $b_{r,c} \in \{0, 1, 2, 3\}
$ (column constraint), we need $b_{r,c} = 2 - a_{r,c} \geq 0$, so $a_{r,c} \leq
2$ (always satisfied).

permutation of $(0,1,2,3)$. So **one variable in each column must have $b_{r,c}
= 3$**, requiring $a_{r,c} = 2 - 3 = -1$.

Since the row Vandermonde can only assign degrees $\geq 0$, this is **impossible
