**Setup.** Let $\phi = 2\pi/n$ with $n > 2$ integer, and let $i,j \in \{1,\dots,
n\}$. Observe that for $i=j$,
$$a_{ii} = 1 + \cos(2i\phi) = 1 + \cos((i+i)\phi).$$
Hence if we define $B$ by $B_{ij} = \cos((i+j)\phi)$ for **all** $i,j$, then
$$A = B + I_n.$$

**Rank-2 decomposition of $B$.** Using $\cos(\alpha+\beta)=\cos\alpha\cos\beta -
 \sin\alpha\sin\beta$,
$$B_{ij} = \cos(i\phi)\cos(j\phi) - \sin(i\phi)\sin(j\phi),$$
so, setting $c = (\cos\phi, \cos 2\phi, \dots, \cos n\phi)^T$ and $s = (\sin\phi
, \sin 2\phi, \dots, \sin n\phi)^T$,
$$B = cc^T - ss^T.$$
Thus $B$ has rank $\le 2$, and
$$A = I_n + cc^T - ss^T = I_n + UV^T,$$
where $U = [\,c \mid -s\,]$ and $V = [\,c \mid s\,]$ are $n\times 2$ matrices.

**Determinant lemma.** By the generalized matrix determinant lemma,
$$\det(I_n + UV^T) = \det(I_2 + V^T U).$$
We compute the $2\times 2$ matrix $V^T U$:
$$V^T U = \begin{pmatrix} c^Tc & -c^Ts \\ s^Tc & -s^Ts \end{pmatrix}.$$

**Evaluating the inner products.** Since $\phi = 2\pi/n$ and $n>2$, the roots of
 unity sum gives
$$\sum_{k=1}^{n} e^{i\,2k\phi} = \sum_{k=1}^{n} e^{i\,4\pi k/n} = 0,$$
because $e^{i4\pi/n}\neq 1$ (as $n>2$) and $e^{i4\pi}=1$. Taking real and imagin
ary parts:
$$\sum_{k=1}^{n}\cos(2k\phi) = 0, \qquad \sum_{k=1}^{n}\sin(2k\phi) = 0.$$
Therefore
$$c^Tc = \sum_{k=1}^{n}\cos^2(k\phi) = \frac{n}{2} + \frac{1}{2}\sum_{k=1}^{n}\c
os(2k\phi) = \frac{n}{2},$$
$$s^Ts = \sum_{k=1}^{n}\sin^2(k\phi) = \frac{n}{2} - \frac{1}{2}\sum_{k=1}^{n}\c
os(2k\phi) = \frac{n}{2},$$
$$c^Ts = \sum_{k=1}^{n}\cos(k\phi)\sin(k\phi) = \frac{1}{2}\sum_{k=1}^{n}\sin(2k
\phi) = 0.$$

So
$$I_2 + V^T U = \begin{pmatrix} 1 + n/2 & 0 \\ 0 & 1 - n/2 \end{pmatrix},$$
and
$$\det(A) = \det(I_2 + V^T U) = \left(1+\frac{n}{2}\right)\left(1-\frac{n}{2}\ri
ght) = 1 - \frac{n^2}{4} = \frac{4-n^2}{4}.$$
