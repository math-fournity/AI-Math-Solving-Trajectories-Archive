## Proof

**Answer: Yes, $a = 0$.**

Since $\{x_n : n \geq 1\}$ is finite, the sequence $(x_n)$ takes only finitely m
any distinct values. Let $V$ denote the set of values taken by $x_n$ **infinitel
y often**:

$$V = \{y \in X : x_n = y \text{ for infinitely many } n\}.$$

The set $V$ is nonempty (an infinite sequence taking finitely many values must t
ake at least one value infinitely often) and finite.

**Key observation.** For each fixed $m$, the scalar sequence $\big(\langle f_m,
x_n\rangle\big)_{n}$ takes values in the finite set $\{\langle f_m, y\rangle : y
 \in V\} \cup \{\text{finitely many transient values}\}$. Its set of subsequenti
al limits is exactly

$$\{\langle f_m, y\rangle : y \in V\}.$$

Since condition (1) states that $\lim_n \langle f_m, x_n\rangle$ exists, all sub
sequential limits must coincide. Therefore, for each $m$, the functional $f_m$ i
s **constant on $V$**:

$$\langle f_m, y\rangle = \langle f_m, y'\rangle \quad \text{for all } y, y' \in
 V.$$

Consequently,

$$a_m = \lim_n \langle f_m, x_n\rangle = \langle f_m, y\rangle \quad \text{for a
ny } y \in V.$$

**Applying the weak*-null condition.** Pick any $y_0 \in V$ (which is a fixed el
ement of $X$). Since $(f_m)$ is weak*-null, by definition

$$\langle f_m, y_0\rangle \xrightarrow{m \to \infty} 0.$$

But $a_m = \langle f_m, y_0\rangle$ for every $m$, so

$$a = \lim_{m \to \infty} a_m = \lim_{m \to \infty} \langle f_m, y_0\rangle = 0.
 \qquad \blacksquare$$
