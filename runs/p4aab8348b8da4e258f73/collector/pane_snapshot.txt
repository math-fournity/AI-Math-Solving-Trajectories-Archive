## Solution

We solve the initial-boundary value problem by eigenfunction expansion (Fourier
sine series).

### Step 1. Eigenfunction basis

The homogeneous problem $u_t - 2u_{xx} = 0$ with $u(0,t)=u(1,t)=0$ has eigenfunc
tions $\{\sin(n\pi x)\}_{n=1}^{\infty}$ on $(0,1)$, with eigenvalues $\lambda_n
= (n\pi)^2$. We expand

$$u(x,t) = \sum_{n=1}^{\infty} T_n(t)\,\sin(n\pi x).$$

### Step 2. Expand the source term

Write $x - 1 = \sum_{n=1}^{\infty} f_n \sin(n\pi x)$, where

$$f_n = 2\int_0^1 (x-1)\sin(n\pi x)\,dx.$$

Compute:

$$\int_0^1 \sin(n\pi x)\,dx = \frac{1-(-1)^n}{n\pi}, \qquad \int_0^1 x\sin(n\pi
x)\,dx = \frac{(-1)^{n+1}}{n\pi}.$$

Hence

$$\int_0^1 (x-1)\sin(n\pi x)\,dx = \frac{(-1)^{n+1}}{n\pi} - \frac{1-(-1)^n}{n\p
i} = \frac{(-1)^{n+1}-1+(-1)^n}{n\pi} = \frac{-1}{n\pi},$$

so

$$f_n = \frac{-2}{n\pi}.$$

### Step 3. ODE for the time coefficients

Substituting into $u_t - 2u_{xx} = x-1$ and using $u_{xx} = -\sum (n\pi)^2 T_n(t
)\sin(n\pi x)$:

$$T_n'(t) + 2n^2\pi^2\, T_n(t) = f_n = \frac{-2}{n\pi}, \qquad T_n(0) = 0.$$

This first-order linear ODE has solution

$$T_n(t) = \frac{f_n}{2n^2\pi^2}\bigl(1 - e^{-2n^2\pi^2 t}\bigr) = \frac{-2/(n\p
i)}{2n^2\pi^2}\bigl(1 - e^{-2n^2\pi^2 t}\bigr) = \frac{-1}{n^3\pi^3}\bigl(1 - e^
{-2n^2\pi^2 t}\bigr).$$

### Step 4. The solution

$$\boxed{\displaystyle u(x,t) = -\sum_{n=1}^{\infty} \frac{1 - e^{-2n^2\pi^2 t}}
{n^3\pi^3}\,\sin(n\pi x) = \sum_{n=1}^{\infty} \frac{e^{-2n^2\pi^2 t}-1}{n^3\pi^
3}\,\sin(n\pi x).}$$

### Step 5. Verification

**PDE.** Each term satisfies $u_t - 2u_{xx} = f_n\sin(n\pi x)$; summing gives $x
-1$. ✓

**Boundary conditions.** $\sin(n\pi\cdot 0) = \sin(n\pi\cdot 1) = 0$ for all $n$
, so $u(0,t)=u(1,t)=0$. ✓

**Initial condition.** At $t=0$, every factor $(1 - e^{0}) = 0$, so $u(x,0)=0$.
✓

**Steady-state check.** As $t\to\infty$, $u \to -\sum \frac{\sin(n\pi x)}{n^3\pi
^3}$. Using the classical identity (valid for $x\in[0,2]$)

$$\sum_{n=1}^{\infty}\frac{\sin(n\pi x)}{n^3} = \frac{\pi^3}{12}\,x(x-1)(x-2),$$

the steady state is $\frac{-x(x-1)(x-2)}{12}$. Solving the steady-state ODE $-2u
_{xx}=x-1$, $u(0)=u(1)=0$ gives $u(x)=\frac{x^2}{4}-\frac{x^3}{12}-\frac{x}{6} =
 \frac{-x(x-1)(x-2)}{12}$, which agrees. ✓
