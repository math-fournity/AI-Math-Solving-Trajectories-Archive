# Problem

In a specialized server network consisting of $n$ server nodes (where $n \geqslant 3$), the nodes are interconnected by dedicated fiber-optic cables. Each cable directly links exactly two nodes, and no two nodes are connected by more than one cable. While these cables may physically cross paths in the facility, they never intersect or splice together; they only join at the server nodes themselves.

The network is currently configured such that it is possible to send data from any one node to any other node through the sequence of cables. However, the system is designed with a specific vulnerability: if the network engineers identify any "closed-loop" sequence of cables (a path that starts and ends at the same node without repeating any cables) and deactivate every cable involved in that specific loop for maintenance, the remaining network will inevitably become disconnected, making it impossible to reach at least one node from another.

Based on these structural constraints, what is the maximum possible number of fiber-optic cables that can exist in this network?
