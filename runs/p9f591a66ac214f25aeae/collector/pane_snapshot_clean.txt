## Solution

**Coordinate setup.** Since $F_1F_2$ is parallel to both directrices $\ell_1, \e
ll_2$, I place all directrices as horizontal lines. Set $F_1 = (0,0)$ and $F_2 =
 (1,0)$ so that $F_1F_2 = 1$. Let $\ell_1: y = c_1$ and $\ell_2: y = c_2$ with $
c_1 \neq c_2$.

**Parabola equations.** A point $(x,y)$ on a parabola satisfies: distance to foc
us = distance to directrix.

*Path 1* (focus $F_1=(0,0)$, directrix $y=c_1$):
$$x^2 + y^2 = (y-c_1)^2 \implies x^2 = -2c_1 y + c_1^2 \implies y = \frac{c_1^2
- x^2}{2c_1}$$

*Path 2* (focus $F_2=(1,0)$, directrix $y=c_2$):
$$(x-1)^2 + y^2 = (y-c_2)^2 \implies y = \frac{c_2^2 - (x-1)^2}{2c_2}$$

**Applying the focus-on-path conditions.**

$F_1 = (0,0)$ lies on Path 2:
$$0 = \frac{c_2^2 - 1}{2c_2} \implies c_2^2 = 1 \implies c_2 = \pm 1$$

$F_2 = (1,0)$ lies on Path 1:
$$0 = \frac{c_1^2 - 1}{2c_1} \implies c_1^2 = 1 \implies c_1 = \pm 1$$

Since the directrices are distinct ($c_1 \neq c_2$), we must have $\{c_1, c_2\}
= \{1, -1\}$. By symmetry (reflection across $y=0$) both choices give the same $
AB^2$. Take **$c_1 = 1,\ c_2 = -1$**.

**The two parabolas:**
$$\text{Path 1: } y = \frac{1 - x^2}{2}, \qquad \text{Path 2: } y = \frac{(x-1)^
2 - 1}{2} = \frac{x^2 - 2x}{2}$$

**Finding intersection points.** Setting them equal:
$$1 - x^2 = x^2 - 2x \implies 2x^2 - 2x - 1 = 0 \implies x = \frac{1 \pm \sqrt{3
}}{2}$$

So $x_A = \frac{1+\sqrt{3}}{2}$, $x_B = \frac{1-\sqrt{3}}{2}$.

**Computing $y$-coordinates** using $y = \frac{1-x^2}{2}$:

$$x_A^2 = \frac{4+2\sqrt{3}}{4} = \frac{2+\sqrt{3}}{2} \implies y_A = \frac{1 -
\frac{2+\sqrt{3}}{2}}{2} = -\frac{\sqrt{3}}{4}$$

$$x_B^2 = \frac{4-2\sqrt{3}}{4} = \frac{2-\sqrt{3}}{2} \implies y_B = \frac{1 -
\frac{2-\sqrt{3}}{2}}{2} = \frac{\sqrt{3}}{4}$$

**Computing $AB^2$:**

$$x_A - x_B = \sqrt{3}, \qquad y_A - y_B = -\frac{\sqrt{3}}{2}$$

$$AB^2 = (\sqrt{3})^2 + \left(-\frac{\sqrt{3}}{2}\right)^2 = 3 + \frac{3}{4} = \
frac{15}{4}$$

**Verification of all conditions:**
- $F_1F_2 = 1$ ✓
- $F_1F_2$ (the $x$-axis) is parallel to $\ell_1: y=1$ and $\ell_2: y=-1$ ✓
- $F_1=(0,0)$ on Path 2: $\frac{0-0}{2}=0$ ✓
- $F_2=(1,0)$ on Path 1: $\frac{1-1}{2}=0$ ✓
- $\ell_1 \neq \ell_2$ ✓
- Two distinct intersection points ✓

**Final answer.** $AB^2 = \frac{15}{4}$ with $\gcd(15,4)=1$, so $m=15$, $n=4$.

$$100m + n = 100(15) + 4 = \boxed{1504}$$
