## (a) Labeled plot of f(t) vs t

\(f(t)=\sum_{n=-\infty}^{\infty}\delta(t-nT_o)\) is a periodic train of Dirac de
lta impulses ("Dirac comb"). It consists of unit-area spikes located at every in
teger multiple of \(T_o\):

```
f(t)
  ↑
 1|  ↑      ↑      ↑      ↑      ↑
  |  |      |      |      |      |
  |  |      |      |      |      |
--+--+--+---+--+---+--+---+--+---+--+--+--> t
  -2To -To  0    To    2To   3To
            ↑           ↑
        (each spike = δ, area = 1)
```

- x-axis: \(t\), with ticks at \(t=nT_o,\; n\in\mathbb Z\).
- y-axis: \(f(t)\). Each arrow represents a delta of unit area; the function is

## (b) Fundamental frequency and Fourier coefficients

**Fundamental frequency.** Since \(f(t+T_o)=f(t)\), the period is \(T_o\), so

\[
\omega_0 = \frac{2\pi}{T_o}.
\]

**Coefficients.** Using the standard trigonometric Fourier series over one perio
d (take the symmetric interval \([-T_o/2,\,T_o/2]\), which contains exactly one
delta, at \(t=0\)):

\[
a_0 = \frac{2}{T_o}\int_{-T_o/2}^{T_o/2} f(t)\,dt
     = \frac{2}{T_o}\int_{-T_o/2}^{T_o/2}\delta(t)\,dt
     = \frac{2}{T_o}.
\]

\[
a_n = \frac{2}{T_o}\int_{-T_o/2}^{T_o/2} f(t)\cos(n\omega_0 t)\,dt
    = \frac{2}{T_o}\int_{-T_o/2}^{T_o/2}\delta(t)\cos(n\omega_0 t)\,dt
    = \frac{2}{T_o}\cos(0)
    = \frac{2}{T_o},\qquad n\ge 1.
\]

\[
b_n = \frac{2}{T_o}\int_{-T_o/2}^{T_o/2}\delta(t)\sin(n\omega_0 t)\,dt
    = \frac{2}{T_o}\sin(0)
    = 0,\qquad n\ge 1.
\]

Hence

\[
\boxed{\omega_0=\frac{2\pi}{T_o},\qquad a_0=\frac{2}{T_o},\qquad a_n=\frac{2}{T_
o}\;\;(n\ge 1),\qquad b_n=0.}
\]

Equivalently, since \(\omega_0=2\pi/T_o\),

\[
\sum_{n=-\infty}^{\infty}\delta(t-nT_o)=\frac{1}{T_o}+\frac{2}{T_o}\sum_{n=1}^{\
infty}\cos(n\omega_0 t)
=\frac{1}{T_o}\sum_{n=-\infty}^{\infty}e^{in\omega_0 t},
\]

which is the Poisson summation form of the Dirac comb.

## (c) What is unusual about the coefficients

For any piecewise-smooth (or piecewise-continuous) periodic function, the Fourie
r coefficients decay to zero as \(n\to\infty\) — typically at least as fast as \
(1/n\), and faster for smoother functions. This decay is precisely what guarante
es convergence of the Fourier series (pointwise, or in \(L^2\)).

Here, however,

\[
a_n = \frac{2}{T_o}\quad\text{for every }n\ge 0,
\]

i.e. **all the cosine coefficients are equal and constant; they do not decay at
all** (and \(b_n=0\) identically). The partial sums

\[
S_N(t)=\frac{1}{T_o}+\frac{2}{T_o}\sum_{n=1}^{N}\cos(n\omega_0 t)
=\frac{\sin\!\big((N+\tfrac12)\omega_0 t\big)}{T_o\,\sin(\tfrac12\omega_0 t)}
\]

do not converge pointwise to an ordinary function as \(N\to\infty\); they oscill
ate without settling (the Dirichlet kernel grows in peak height). This is the si
gnature of the extreme discontinuity of the delta function: \(\delta(t)\) is not
 a function at all but a distribution (generalized function). Consequently its F
ourier series does **not** converge in the ordinary sense — it converges only in
 the **distributional** sense, where the partial sums tend to a periodic train o
f delta functions. The failure of the coefficients to decay is the direct Fourie
r-analytic manifestation of the fact that the δ-function is "more singular" than
 any piecewise-continuous function, lying outside the class for which the standa
rd convergence theorems of this chapter apply.
