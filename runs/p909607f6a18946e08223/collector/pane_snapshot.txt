## Proof

Let the grid be $16\times 16$, so there are $256$ nodes total. Let $R=133$ be th
e number of Ruby servers and $S=256-133=123$ the number of Sapphire servers.

### Counting all edges (cables)

Horizontal edges: $16\text{ rows}\times 15=240$. Vertical edges: $15\times 16=24
0$. Total edges:
$$E_{\text{total}}=240+240=480.$$

Each edge is Red, Blue, or Yellow, so
$$\text{Red}+\text{Blue}+\text{Yellow}=480.$$
With $\text{Yellow}=196$:
$$\text{Red}+\text{Blue}=284. \tag{1}$$

### Degrees by position

A node's degree (number of adjacent nodes) depends on its position:
- Corner: degree $2$ (4 corners),
- Edge (non-corner boundary): degree $3$,
- Interior: degree $4$.

Boundary nodes: $4\cdot 16-4=60$; corners $=4$; edge non-corner $=56$; interior
$=256-60=196$.

### Ruby distribution

- Ruby corners: $2$ (given),
- Ruby boundary non-corner: $32-2=30$,
- Ruby interior: $133-32=101$.

Sum of degrees over all Ruby nodes:
$$D_R = 2\cdot 2 + 3\cdot 30 + 4\cdot 101 = 4+90+404 = 498.$$

Each Red edge contributes $2$ to this sum (both endpoints Ruby), and each Yellow
 edge contributes $1$ (one endpoint Ruby). Hence
$$D_R = 2\,\text{Red} + \text{Yellow}.$$
$$498 = 2\,\text{Red}+196 \implies 2\,\text{Red}=302 \implies \text{Red}=151.$$

### Solving for Blue

From (1):
$$\text{Blue}=284-151=133.$$

### Verification via Sapphire side

Sapphire distribution:
- Sapphire corners: $4-2=2$,
- Sapphire boundary non-corner: $(60-32)-2=26$,
- Sapphire interior: $123-28=95$.

Sum of degrees over Sapphire nodes:
$$D_S=2\cdot 2+3\cdot 26+4\cdot 95=4+78+380=462.$$
$$D_S=2\,\text{Blue}+\text{Yellow}\implies 462=2\,\text{Blue}+196\implies 2\,\te
xt{Blue}=266\implies \text{Blue}=133.$$

Both independent counts agree.

$$\boxed{\text{Blue cables}=133}$$
