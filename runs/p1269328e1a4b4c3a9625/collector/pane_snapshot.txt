## 证明

设原始抛物线上的点为 $(t, t^2)$。绕原点顺时针旋转角 $\theta$（$\theta$ 为锐角）
后，该点变为：

$$X = t\cos\theta + t^2\sin\theta, \qquad Y = -t\sin\theta + t^2\cos\theta.$$

**与 $x$-轴的交点 ($Y = 0$).**

$$-t\sin\theta + t^2\cos\theta = 0 \;\Longrightarrow\; t(\,-\sin\theta + t\cos\t
heta\,) = 0,$$

因此 $t = 0$ 或 $t = \tan\theta$。两个不同的交点为：

- $t = 0$: $(X, Y) = (0, 0)$.
- $t = \tan\theta$: $X = \tan\theta\cos\theta + \tan^2\theta\sin\theta = \sin\th
eta + \dfrac{\sin^3\theta}{\cos^2\theta} = \sin\theta\cdot\dfrac{\cos^2\theta +
\sin^2\theta}{\cos^2\theta} = \dfrac{\sin\theta}{\cos^2\theta}$.

它们之间的距离为 $\dfrac{\sin\theta}{\cos^2\theta}$，已知其等于 $1$：

$$\frac{\sin\theta}{\cos^2\theta} = 1 \;\Longrightarrow\; \sin\theta = \cos^2\th
eta = 1 - \sin^2\theta.$$

设 $s = \sin\theta$。则 $s^2 + s - 1 = 0$，所以（取正根，因为 $\theta$ 为锐角）

$$s = \sin\theta = \frac{\sqrt 5 - 1}{2} = \frac{1}{\varphi}, \qquad \cos^2\thet
a = \sin\theta = \frac{\sqrt 5 - 1}{2},$$

其中 $\varphi = \dfrac{1+\sqrt 5}{2}$ 为黄金比例。

**与 $y$-轴的交点 ($X = 0$).**

$$t\cos\theta + t^2\sin\theta = 0 \;\Longrightarrow\; t(\,\cos\theta + t\sin\the
ta\,) = 0,$$

因此 $t = 0$ 或 $t = -\cot\theta$。两个不同的交点为：

- $t = 0$: $(X, Y) = (0, 0)$.
- $t = -\cot\theta$: $Y = -(-\cot\theta)\sin\theta + \cot^2\theta\cos\theta = \c
os\theta + \dfrac{\cos^3\theta}{\sin^2\theta} = \cos\theta\cdot\dfrac{\sin^2\the
ta + \cos^2\theta}{\sin^2\theta} = \dfrac{\cos\theta}{\sin^2\theta}$.

因此两个 $y$-轴交点之间的距离为

$$D = \frac{\cos\theta}{\sin^2\theta}.$$

利用关系 $\sin\theta = \cos^2\theta$，我们得到 $\sin^2\theta = \cos^4\theta$，因
此

$$D = \frac{\cos\theta}{\cos^4\theta} = \frac{1}{\cos^3\theta}.$$

由于 $\cos^2\theta = \sin\theta = 1/\varphi$，我们有 $\cos\theta = \varphi^{-1/2
}$，所以

$$D = \frac{1}{\varphi^{-3/2}} = \varphi^{3/2}.$$

最后，利用 $\varphi^2 = \varphi + 1$，

$$\varphi^3 = \varphi\cdot\varphi^2 = \varphi(\varphi+1) = \varphi^2 + \varphi =
 (\varphi+1)+\varphi = 2\varphi + 1 = (1+\sqrt 5) + 1 = 2 + \sqrt 5.$$

因此

$$D = \varphi^{3/2} = \sqrt{\varphi^3} = \sqrt{2 + \sqrt 5}.$$

**数值验证.** $\sin\theta \approx 0.618$, $\cos\theta \approx 0.786$。检查: $\si
n\theta/\cos^2\theta \approx 0.618/0.618 = 1$ ✓。$y$-轴距离: $\cos\theta/\sin^2\
theta \approx 0.786/0.382 \approx 2.058$，且 $\sqrt{2+\sqrt 5} \approx \sqrt{4.2
36} \approx 2.058$ ✓。

## 答案

两个垂直交点之间的距离为

$$\boxed{\sqrt{2+\sqrt 5}\,.}$$
