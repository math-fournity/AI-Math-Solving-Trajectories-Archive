# Problem

In a specialized logistics network, a master fleet is divided into several regional divisions. Each regional division is further partitioned into local squadrons, each local squadron is split into delivery units, and each delivery unit is composed of individual courier teams. 

The number of courier teams in each delivery unit, the number of delivery units in each local squadron, and the number of local squadrons in each regional division is represented by the same integer, which is greater than 1. 

A "Lead Coordinator" is appointed for every organizational level above the team level: there is one coordinator for every delivery unit, one for every local squadron, one for every regional division, and one for the master fleet itself. If there are exactly 161 Lead Coordinators in the entire network, how many regional divisions are there in this master fleet?
