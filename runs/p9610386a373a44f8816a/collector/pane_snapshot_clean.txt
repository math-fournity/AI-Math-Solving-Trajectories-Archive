set \cup \emptyset) = \tau(\emptyset) + \tau(\emptyset)$, so $\tau(\emptyset) =
0$.

efine:
$$\tau^+(A) = \sup\{\tau(B) : B \in \mathcal{A},\; B \subseteq A\}, \qquad \tau^
-(A) = \sup\{-\tau(B) : B \in \mathcal{A},\; B \subseteq A\}.$$

Since $\tau$ is bounded (condition 1), there exists $M > 0$ with $|\tau(B)| \leq
 M$ for all $B \in \mathcal{A}$, so both $\tau^+(A)$ and $\tau^-(A)$ lie in $[0,
 M]$ and are finite. Since $\emptyset \subseteq A$ and $\tau(\emptyset) = 0$, bo
th are $\geq 0$.

**Step 3: $\tau^+$ is finitely additive.** Let $A, B \in \mathcal{A}$ be disjoin
t. For any $C \in \mathcal{A}$ with $C \subseteq A \cup B$, set $C_A = C \cap A$
 and $C_B = C \cap B$. Then $C = C_A \cup C_B$ is a disjoint union with both par
ts in $\mathcal{A}$, so by additivity:
$$\tau(C) = \tau(C_A) + \tau(C_B) \leq \tau^+(A) + \tau^+(B).$$
Taking the supremum over all such $C$ gives $\tau^+(A \cup B) \leq \tau^+(A) + \
tau^+(B)$.

Conversely, for any $B_1 \subseteq A$ and $B_2 \subseteq B$ with $B_1, B_2 \in \
mathcal{A}$, the set $B_1 \cup B_2 \subseteq A \cup B$ is a disjoint union, so $
\tau(B_1 \cup B_2) = \tau(B_1) + \tau(B_2) \leq \tau^+(A \cup B)$. Taking the su
premum first over $B_1$ and then over $B_2$:
$$\tau^+(A) + \tau^+(B) \leq \tau^+(A \cup B).$$

Therefore $\tau^+(A \cup B) = \tau^+(A) + \tau^+(B)$. The identical argument (ap
plied to $-\tau$, which is also bounded and finitely additive) shows $\tau^-$ is
 finitely additive.

athcal{A}$ with $B \subseteq A$, we have the disjoint decomposition $A = B \cup

$$\tau(B) = \tau(A) - \tau(A \setminus B).$$
Therefore:
$$\tau^+(A) = \sup_{B \subseteq A} \tau(B) = \sup_{B \subseteq A} \bigl(\tau(A)
- \tau(A \setminus B)\bigr) = \tau(A) + \sup_{B \subseteq A}\bigl(-\tau(A \setmi

$$\tau^+(A) = \tau(A) + \sup_{C \subseteq A}\bigl(-\tau(C)\bigr) = \tau(A) + \ta

This gives $\tau(A) = \tau^+(A) - \tau^-(A)$ for every $A \in \mathcal{A}$.
