## Proof

We seek a regular (analytic) function $f(z)$, $z = x+iy$, with real part
$$u(x,y) = y\cos(y)\sinh(x) + x\sin(y)\cosh(x).$$

**Key observation.** Recall two identities involving $\sinh$ and $\sin$:
$$\sinh(z) = \sinh(x)\cos(y) + i\cosh(x)\sin(y), \qquad \sin(iz) = i\sinh(z).$$

**Ansatz.** Consider
$$f(z) = -iz\,\sinh(z).$$
This is entire (product of entire functions), hence regular. We compute its real
 part.

Since $-iz = -i(x+iy) = y - ix$ and $\sinh(z) = \sinh(x)\cos(y) + i\cosh(x)\sin(
y)$,

$$f(z) = (y - ix)\bigl(\sinh(x)\cos(y) + i\cosh(x)\sin(y)\bigr).$$

Expanding:
$$f(z) = y\sinh(x)\cos(y) + iy\cosh(x)\sin(y) - ix\sinh(x)\cos(y) - i^{2}x\cosh(
x)\sin(y).$$

Using $i^{2}=-1$ and collecting real and imaginary parts:
$$f(z) = \underbrace{\bigl[y\sinh(x)\cos(y) + x\cosh(x)\sin(y)\bigr]}_{\text{rea
l part}} + i\underbrace{\bigl[y\cosh(x)\sin(y) - x\sinh(x)\cos(y)\bigr]}_{\text{
imaginary part}}.$$

Therefore
$$\operatorname{Re} f(z) = y\cos(y)\sinh(x) + x\sin(y)\cosh(x) = u(x,y). \quad\c
heckmark$$

**Verification via Cauchy–Riemann.** With
$$v(x,y) = y\cosh(x)\sin(y) - x\sinh(x)\cos(y),$$
we compute:
$$u_x = y\cos(y)\cosh(x) + \sin(y)\cosh(x) + x\sin(y)\sinh(x),$$
$$v_y = \cosh(x)\sin(y) + y\cosh(x)\cos(y) + x\sinh(x)\sin(y),$$
so $u_x = v_y$. Also
$$u_y = \cos(y)\sinh(x) - y\sin(y)\sinh(x) + x\cos(y)\cosh(x),$$
$$-v_x = \sinh(x)\cos(y) - y\sinh(x)\sin(y) + x\cosh(x)\cos(y),$$
so $u_y = -v_x$. The Cauchy–Riemann equations are satisfied, confirming regulari
ty.

$$\boxed{f(z) = -iz\,\sinh(z)}$$
(equivalently, $f(z) = -z\sin(iz)$, since $\sin(iz)=i\sinh(z)$). The harmonic co
