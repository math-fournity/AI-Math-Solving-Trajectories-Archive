# Problem

A specialized telecommunications network consists of $53$ server nodes. Every pair of nodes is either linked by a single direct two-way fiber-optic cable or has no direct physical connection. In total, there are exactly $312$ cables installed across the network. The system is designed such that any server can communicate with any other server through some sequence of cables. 

To prevent hardware overheating, each server node is physically limited to a maximum of $12$ ports, meaning no node is connected to more than $12$ direct cables. Technical latency is measured by the "hop count," which is the number of cables in the shortest path between two nodes. Let $D$ represent the network's maximum hop count—the greatest possible shortest distance between any two servers in the system.

Under these constraints ($N=53$ nodes, $M=312$ cables, and a maximum capacity of $K=12$ cables per node), what is the maximum possible value of $D$?
