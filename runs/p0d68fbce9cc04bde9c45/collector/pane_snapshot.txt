Looking at this problem, I need to determine whether a continuous function can b
e inserted strictly between an USC function $u$ and an LSC function $l$ on a com
pact metric space, given $u < l$ pointwise.

**Answer: Yes, such a continuous function $f$ exists.**

**Proof.**

Since $X$ is a compact metric space, it is paracompact and Hausdorff, so continu
ous partitions of unity subordinate to any open cover exist.

**Construction.** For each $x \in X$, since $u(x) < l(x)$, choose real numbers $
a_x, b_x$ with
$$u(x) < a_x < b_x < l(x).$$

Since $u$ is upper semi-continuous, the set $U_x := \{y \in X : u(y) < a_x\}$ is
 open and contains $x$.

Since $l$ is lower semi-continuous, the set $V_x := \{y \in X : l(y) > b_x\}$ is
 open and contains $x$.

Set $W_x := U_x \cap V_x$; this is an open neighborhood of $x$. The family $\{W_
x\}_{x \in X}$ is an open cover of $X$. By compactness, extract a finite subcove
r $\{W_{x_1}, \dots, W_{x_n}\}$.

Let $\{\varphi_1, \dots, \varphi_n\}$ be a continuous partition of unity subordi
nate to $\{W_{x_i}\}_{i=1}^n$, so:
- each $\varphi_i : X \to [0,1]$ is continuous,
- $\operatorname{supp}(\varphi_i) \subseteq W_{x_i}$,
- $\sum_{i=1}^n \varphi_i(x) = 1$ for all $x \in X$.

Define
$$f(x) := \sum_{i=1}^n \varphi_i(x)\, c_i, \qquad \text{where } c_i := \frac{a_{
x_i} + b_{x_i}}{2}.$$

**$f$ is continuous.** It is a finite sum of continuous functions.

**$f$ maps into $[0,1]$.** Since $u, l : X \to [0,1]$ and $u(x_i) < a_{x_i} < b_
{x_i} < l(x_i)$, we have $0 \le u(x_i) < a_{x_i} < c_i < b_{x_i} < l(x_i) \le 1$
, so each $c_i \in (0,1)$. As $f(x)$ is a convex combination of the $c_i$, we ge
t $f(x) \in (0,1) \subseteq [0,1]$.

**Strict inequalities $u(x) < f(x) < l(x)$.** Fix $x \in X$. For every $i$ with
$\varphi_i(x) > 0$, we have $x \in \operatorname{supp}(\varphi_i) \subseteq W_{x
_i} \subseteq U_{x_i}$, so $u(x) < a_{x_i} < c_i$. Likewise $x \in W_{x_i} \subs
eteq V_{x_i}$, so $l(x) > b_{x_i} > c_i$. Thus every $c_i$ contributing to the s
um satisfies
$$u(x) < c_i < l(x).$$

Since $f(x) = \sum_i \varphi_i(x) c_i$ is a convex combination (weights $\varphi
_i(x) \ge 0$, summing to $1$) of values all lying strictly in the interval $(u(x
),\, l(x))$, we conclude
$$u(x) < f(x) < l(x).$$

This holds for every $x \in X$, completing the proof. $\blacksquare$
