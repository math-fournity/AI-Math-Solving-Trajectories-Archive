$$2x_3 > x_1+x_2 \iff 3x_3 > x_1+x_2+x_3 \iff 3t_3 > 0 \iff t_3 > 0$$

**Step 3: Parametrize and compute $q$.**

Set $t_3 = \mu > 0$. From $t_1+t_2 = -\mu$ and $t_2 - t_1 = \lambda$:
$$t_1 = \frac{-\mu-\lambda}{2}, \quad t_2 = \frac{-\mu+\lambda}{2}$$

Since $q = -t_1 t_2 t_3$:
$$t_1 t_2 = \frac{(-\mu-\lambda)(-\mu+\lambda)}{4} = \frac{\mu^2 - \lambda^2}{4}
$$
$$q = -\frac{(\mu^2-\lambda^2)}{4}\cdot\mu = \frac{\mu(\lambda^2 - \mu^2)}{4}$$

**Step 4: Maximize.**

$$\frac{27q}{\lambda^3} = \frac{27\mu(\lambda^2-\mu^2)}{4\lambda^3} = \frac{27}{

$$h'(u) = 1 - 3u^2 = 0 \implies u = \frac{1}{\sqrt{3}}$$
$$h''(u) = -6u < 0 \text{ for } u > 0 \quad (\text{maximum})$$

$$h\!\left(\frac{1}{\sqrt{3}}\right) = \frac{1}{\sqrt{3}}\left(1 - \frac{1}{3}\r

$$\frac{27}{4}\cdot\frac{2}{3\sqrt{3}} = \frac{9}{2\sqrt{3}} = \frac{3\sqrt{3}}{
