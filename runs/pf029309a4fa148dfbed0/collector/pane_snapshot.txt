## Solution

We compute $\mathbb{E}\!\left[\left(\dfrac{1}{T}\int_0^T W_t\,dt\right)^2\right]
$ for standard Brownian motion $W_t$.

### Setup

Let $\displaystyle X := \frac{1}{T}\int_0^T W_t\,dt$. We want $\mathbb{E}[X^2]$.

Since $W_t$ is a Gaussian process, $X$ is Gaussian (a linear functional of a Gau
ssian process). In particular $\mathbb{E}[X]=0$ because $\mathbb{E}[W_t]=0$ for
all $t$, so

$$\mathbb{E}[X^2] = \operatorname{Var}(X) = \frac{1}{T^2}\,\mathbb{E}\!\left[\le
ft(\int_0^T W_t\,dt\right)^2\right].$$

### Expanding the square via Fubini

By Fubini's theorem (justified since $\int_0^T\!\!\int_0^T \mathbb{E}[|W_s W_t|]
\,ds\,dt < \infty$):

$$\mathbb{E}\!\left[\left(\int_0^T W_t\,dt\right)^2\right] = \int_0^T\!\!\int_0^
T \mathbb{E}[W_s W_t]\,ds\,dt.$$

For standard Brownian motion, the covariance is $\mathbb{E}[W_s W_t] = \min(s,t)
$.

### Evaluating the double integral

By symmetry in $s,t$:

$$\int_0^T\!\!\int_0^T \min(s,t)\,ds\,dt = 2\int_0^T\!\!\int_0^t \min(s,t)\,ds\,
dt.$$

On the region $\{0 \le s \le t \le T\}$ we have $\min(s,t)=s$, so

$$2\int_0^T\!\!\int_0^t s\,ds\,dt = 2\int_0^T \frac{t^2}{2}\,dt = \int_0^T t^2\,
dt = \frac{T^3}{3}.$$

### Final computation

Therefore

$$\mathbb{E}[X^2] = \frac{1}{T^2}\cdot\frac{T^3}{3} = \frac{T}{3}.$$

---

### Result

$$\boxed{\mathbb{E}\!\left[\left(\dfrac{1}{T}\int_0^T W_t\,dt\right)^2\right] =
\dfrac{T}{3}}$$
