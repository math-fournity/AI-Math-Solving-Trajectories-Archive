## Reformulation

Setting $u=a+x$, $v=a+y$, $w=a+x+y$, the condition becomes: there exist $1\le u\
le v < w\le n$ with $w\le u+v$ that are monochromatic. (Verification: $a=u+v-w\g
e 0$ iff $w\le u+v$; $x=w-v\ge 1$ iff $w\ge v+1$ ✓; $y=w-u\ge 1$ ✓; $x\le y$ iff
 $u\le v$ ✓.)

## Pair constraints suffice

**Case $u=v$ (i.e., $x=y$):** The triple becomes $\{u, u, w\}$ with $w\le 2u$ —
a **pair constraint**: if $a<b\le 2a$, then $a,b$ must have different colors.

**Case $u<v$:** If a color class $S$ satisfies the pair constraint ($b>2a$ for a
ll $a<b$ in $S$), then for $u<v<w$ in $S$: $w>2v=v+v\ge u+v$, so $w>u+v$ and the
 triple constraint is automatically satisfied.

**Conclusion:** The problem reduces to finding the chromatic number of the graph
 $G_n$ on $\{1,\ldots,n\}$ where $a\sim b$ iff $a<b\le 2a$.

## Computing $\chi(G_n)$

**Lower bound (clique):** The set $\{\lceil n/2\rceil, \ldots, n\}$ is a clique.
 For any $a<b$ in this set, $a\ge\lceil n/2\rceil$, so $2a\ge 2\lceil n/2\rceil\
ge n\ge b$. Size: $n-\lceil n/2\rceil+1=\lfloor n/2\rfloor+1$.

**Upper bound (coloring):** Color $m$ with $c(m)=(m-1)\bmod k$ where $k=\lfloor
n/2\rfloor+1$. For any edge $a<b\le 2a$ with $a,b\in\{1,\ldots,n\}$, let $d=b-a$
. Then:
- $d\ge 1$ and $d\le a$ (from $b\le 2a$) and $a+d\le n$ (from $b\le n$), giving
$d\le\lfloor n/2\rfloor$.
- Since $k=\lfloor n/2\rfloor+1>d\ge 1$, we have $d\not\equiv 0\pmod{k}$, so $c(
a)\neq c(b)$. ✓

**Therefore $\chi(G_n)=\lfloor n/2\rfloor+1$.**

## Finding $h(r)$

$$h(r)=\min\{n:\chi(G_n)>r\}=\min\{n:\lfloor n/2\rfloor+1>r\}=\min\{n:\lfloor n/
2\rfloor\ge r\}=2r.$$

**Verification:** $h(2)=4$: $\chi(G_3)=2\le 2$ (coloring $1,3$ same; $2$ differe
nt works), $\chi(G_4)=3>2$ (clique $\{2,3,4\}$). ✓
