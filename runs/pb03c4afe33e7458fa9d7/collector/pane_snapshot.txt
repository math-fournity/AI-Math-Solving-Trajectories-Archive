## Solution

We seek a non-zero function $f$ satisfying the delay-differential equation

$$f'(x) = f(x-1).$$

**Ansatz.** Try an exponential solution $f(x) = e^{\lambda x}$ for some constant
 $\lambda \in \mathbb{C}$ (allowing complex $\lambda$; a real solution will emer
ge).

**Substitution.** Computing both sides:

$$f'(x) = \lambda e^{\lambda x}, \qquad f(x-1) = e^{\lambda(x-1)} = e^{-\lambda}
e^{\lambda x}.$$

The equation $f'(x)=f(x-1)$ becomes

$$\lambda e^{\lambda x} = e^{-\lambda}e^{\lambda x}.$$

Since $e^{\lambda x}\neq 0$, we may divide through, obtaining the **characterist
ic equation**

$$\lambda = e^{-\lambda} \quad\Longleftrightarrow\quad \lambda e^{\lambda} = 1.$
$

**Solving the characteristic equation.** The equation $\lambda e^{\lambda}=1$ is
 solved by the Lambert $W$ function (defined by $W(z)e^{W(z)}=z$):

$$\lambda = W(1).$$

The principal branch $W_0(1)$ is a **positive real number** (the "Omega constant
" $\Omega \approx 0.56714329$), because the function $g(\lambda)=\lambda e^{\lam
bda}$ is continuous, strictly increasing on $[0,\infty)$, with $g(0)=0<1$ and $g
(1)=e>1$, so there is a unique real root $\lambda\in(0,1)$.

**Verification.** Set $\lambda = W(1)$, so $\lambda e^{\lambda}=1$, equivalently
 $\lambda = e^{-\lambda}$. Define

$$\boxed{f(x) = e^{\,W(1)\,x} = e^{\,\Omega\, x}.}$$

Then

$$f'(x) = \Omega\, e^{\Omega x} = e^{-\Omega}\, e^{\Omega x} = e^{\Omega(x-1)} =
 f(x-1). \quad\checkmark$$

This $f$ is non-zero everywhere (it is a positive exponential), defined for all
$x\in\mathbb{R}$, and satisfies the required identity identically.
