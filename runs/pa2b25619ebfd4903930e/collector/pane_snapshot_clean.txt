## Problem

Find the asymptotic distribution of $p_n(k) = \left\{\begin{array}{l}n \\ k\end{
array}\right\}/S_n$ (Stirling partition numbers normalized by the Bell number),
and its mean and variance.

---

## Proof

### Setup

Let $K_n$ be the number of blocks in a uniformly random set partition of $[n]=\{
1,\dots,n\}$. Then

$$\mathbb{P}(K_n = k) = \frac{\left\{\begin{array}{l}n\\k\end{array}\right\}}{S_
n}, \qquad k=1,\dots,n,$$

where $S_n = \sum_k \left\{\begin{array}{l}n\\k\end{array}\right\}$ is the $n$-t
h Bell number. We study the asymptotic law of $K_n$ as $n\to\infty$.

### Bivariate generating function

The bivariate exponential generating function is

$$F(z,u) = \exp\!\bigl(u(e^z - 1)\bigr) = \sum_{n\ge 0}\sum_{k\ge 0}\left\{\begi
n{array}{l}n\\k\end{array}\right\}\frac{z^n}{n!}\,u^k.$$

The probability generating function of $K_n$ is

$$\mathbb{E}[u^{K_n}] = \frac{[z^n]\,F(z,u)}{[z^n]\,F(z,1)}.$$

### Saddle-point analysis

For fixed $u>0$, the saddle point $r_u$ of $[z^n]\exp(u(e^z-1))$ satisfies

$$r_u\, u\, e^{r_u} = n, \qquad\text{i.e.,}\quad r_u = W(n/u),$$

where $W$ is the Lambert $W$-function. Denote $r := r_1 = W(n)$, so $re^r = n$ a
nd $e^r = n/r$.

By the saddle-point method,

$$[z^n]\,F(z,u) \sim \frac{\exp\!\bigl(u(e^{r_u}-1)\bigr)}{r_u^n\,\sqrt{2\pi\, n
(1+r_u)}},$$

since the variance factor is $b(r_u) = r_u\cdot\frac{d}{dr_u}\bigl(r_u\,u\,e^{r_
u}\bigr)=n(1+r_u)$.

Setting $u = e^s$ (moment generating function) and taking logarithms:

$$h(s) := \log\mathbb{E}[e^{sK_n}] = \phi(s) - \phi(0) + \tfrac{1}{2}\log\frac{1
+r}{1+r_{e^s}} + O(1/n),$$

where, using $e^{r_u} = n/(u\,r_u)$,

$$\phi(s) = \frac{n}{r_{e^s}} - e^s - n\log r_{e^s}.$$

### Expansion in $s$

From $r_{e^s}\,e^{r_{e^s}} = ne^{-s}$ and $re^r=n$, taking logs gives $\log(r_{e
^s}/r) + (r_{e^s}-r) = -s$. Writing $\delta = r_{e^s}-r$ and expanding:

$$\delta = \frac{-rs}{r+1} + \frac{rs^2}{2(r+1)^3} + O(s^3).$$

Substituting into each term of $h(s)$ and collecting:

**Coefficient of $s$ (the mean):**

$$\mu_n = \frac{n}{r(r+1)} + \frac{n}{r+1} - 1 + \frac{r}{2(r+1)^2} = \frac{n}{r
} - 1 + \frac{r}{2(1+r)^2}.$$

Since $n/r = e^r$, this gives $\boxed{\mathbb{E}_n] = e^r - 1 + \frac{r}{2(1+r
)^2} + \cdots \sim \frac{n}{\log n}}$, where $r=W(n)\sim\log n - \log\log n$.

**Coefficient of $s^2/2$ (the variance):**

$$\sigma_n^2 = n\!\left(\frac{r}{(r+1)^3} - \frac{1}{r(r+1)^3}\right) + O(1) = \
frac{n(r-1)}{r(r+1)^2} + O(1).$$

For large $r$, $\frac{r-1}{r(r+1)^2}\sim\frac{1}{r^2}$, giving $\boxed{\mathrm{V
ar}(K_n) \sim \frac{n}{(\log n)^2}}$.

### Asymptotic normality (Harper's theorem)

The cumulant generating function has the form

$$h(s) = \mu_n\, s + \frac{1}{2}\sigma_n^2\, s^2 + O\!\left(\frac{n}{r^3}\right)
,$$

where the remainder is $o(\sigma_n^2)$ since $\sigma_n^2 \sim n/r^2$ and $n/r^3
= o(n/r^2)$. By the quasi-powers theorem (or direct characteristic-function argu
ment), the standardized variable converges:

$$\frac{K_n - \mu_n}{\sigma_n} \;\xrightarrow{d}\; \mathcal{N}(0,1).$$

This is **Harper's theorem** (1967): the distribution $p_n(k) = \left\{\begin{ar
ray}{l}n\\k\end{array}\right\}/S_n$ is **asymptotically Gaussian**.

### Summary

The Stirling partition numbers normalized by the Bell number converge to a **nor
mal (Gaussian) distribution**. Specifically, with $r = W(n)$ (the Lambert $W$-fu
nction evaluated at $n$):

| Quantity | Leading asymptotics | Refined form |
|---|---|---|
| **Distribution** | $\mathcal{N}(0,1)$ after standardization | Harper (1967) |
| **Mean** $\mu_n$ | $\dfrac{n}{\log n}$ | $e^r - 1 + \dfrac{r}{2(1+r)^2} + \cdo
ts$ |
| **Variance** $\sigma_n^2$ | $\dfrac{n}{(\log n)^2}$ | $\dfrac{n(r-1)}{r(1+r)^2
} + O(1)$ |

Equivalently,

$$\frac{K_n - n/\log n}{\sqrt{n}/\log n} \;\xrightarrow{d}\; \mathcal{N}(0,1).$$
