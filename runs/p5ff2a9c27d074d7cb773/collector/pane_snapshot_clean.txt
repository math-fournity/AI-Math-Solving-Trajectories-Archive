## Proof

**Setup.** With $R=1$ (since $y \in \partial B_1(0)$ means $|y|=1$), the Poisson
 kernel is
$$P(x,y) = \frac{1}{\omega_n}\,\frac{1-|x|^2}{|x-y|^n}, \qquad |x|<1,\; |y|=1.$$

We prove that $\displaystyle\int_{\partial B_1(0)} P(x,y)\,dA_y = 1$ by deriving
 the Poisson kernel from the Green's function and applying Green's representatio
n formula to the constant function.

---

### Step 1. Green's Function for $B_R(0)$

The fundamental solution of Laplace's equation in $\mathbb{R}^n$ ($n\ge 3$) is
$$\Phi(z) = \frac{1}{(n-2)\,\omega_n}\,|z|^{2-n}.$$
(For $n=2$, $\Phi(z)=\frac{1}{2\pi}\log|z|$; the argument is analogous.)

For $x\in B_R(0)\setminus\{0\}$, define the **Kelvin inversion** $x^* = \frac{R^
2}{|x|^2}\,x$, which lies outside $\overline{B_R}$. The Green's function for $B_
R(0)$ is
$$G(x,y) = \Phi(y-x) - \Phi\!\Big(\tfrac{|x|}{R}(y - x^*)\Big), \qquad y\in \ove
rline{B_R}.$$

**Boundary vanishing.** For $y\in\partial B_R$ (so $|y|=R$):
$$\frac{|x|}{R}|y-x^*| = \frac{|x|}{R}\sqrt{|y|^2 - 2y\cdot x^* + |x^*|^2} = \sq
rt{\frac{|x|^2 R^2}{R^2} - 2x\cdot y + R^2} = |x-y|.$$
Hence $G(x,y)=0$ on $\partial B_R$. ✓

---

### Step 2. The Poisson Kernel is the Normal Derivative of $G$

The Poisson kernel is $P(x,y) = \frac{\partial G}{\partial n_y}(x,y)$ for $y\in\
partial B_R$, where $n_y = y/R$ is the outward unit normal.

**First term.** Since $\frac{\partial}{\partial n_y}|x-y| = \frac{R^2 - x\cdot y
}{R\,|x-y|}$,
$$\frac{\partial}{\partial n_y}\Phi(y-x) = \frac{1}{(n-2)\omega_n}(2-n)|x-y|^{1-
n}\cdot\frac{R^2-x\cdot y}{R\,|x-y|} = \frac{-(R^2-x\cdot y)}{\omega_n\, R\,|x-y
|^n}.$$

**Second term.** Set $\rho = \frac{|x|}{R}|y-x^*|$. On $\partial B_R$, $\rho=|x-
y|$. Computing $\frac{\partial \rho}{\partial n_y}$: since $\rho^2 = \frac{|x|^2
|y|^2}{R^2}-2x\cdot y + R^2$,
$$\frac{\partial \rho^2}{\partial n_y} = \frac{2(|x|^2 - x\cdot y)}{R}, \qquad\t
ext{so}\qquad \frac{\partial \rho}{\partial n_y} = \frac{|x|^2-x\cdot y}{R\,|x-y
|}.$$
Thus
$$\frac{\partial}{\partial n_y}\Phi(\rho) = \frac{1}{(n-2)\omega_n}(2-n)|x-y|^{1
-n}\cdot\frac{|x|^2-x\cdot y}{R\,|x-y|} = \frac{-(|x|^2-x\cdot y)}{\omega_n\, R\
,|x-y|^n}.$$

**Combining:**
$$P(x,y) = \frac{\partial G}{\partial n_y} = \frac{-1}{\omega_n R\,|x-y|^n}\Big[
(R^2-x\cdot y)-(|x|^2-x\cdot y)\Big] = \frac{1}{\omega_n R}\cdot\frac{R^2-|x|^2}
{|x-y|^n}.$$

This matches the given kernel. ✓

---

### Step 3. Green's Representation Formula

For any $u$ harmonic in $B_R$ and $C^1$ on $\overline{B_R}$, Green's second iden
tity gives
$$u(x) = \int_{\partial B_R}\Big[u(y)\,\frac{\partial G}{\partial n_y}(x,y) - G(
x,y)\,\frac{\partial u}{\partial n_y}(y)\Big]\,dA_y.$$

Since $G(x,y)=0$ for $y\in\partial B_R$, the second term vanishes:
$$u(x) = \int_{\partial B_R} P(x,y)\,u(y)\,dA_y. \tag{$\star$}$$

---

### Step 4. Apply to $u\equiv 1$

The constant function $u\equiv 1$ is harmonic ($\Delta u = 0$). Substituting int
o $(\star)$:
$$1 = u(x) = \int_{\partial B_R} P(x,y)\cdot 1\,dA_y = \int_{\partial B_R} P(x,y
)\,dA_y.$$

Setting $R=1$ (since the integral is over $\partial B_1(0)$):

$$\boxed{\int_{\partial B_1(0)} P(x,y)\,dA_y = 1.}$$

This holds for every $x$ with $|x|<1$ and for every dimension $n\ge 2$.
