# Problem

A high-tech server farm is constructing a massive modular data core by stacking 27 identical server units into a $3 \times 3 \times 3$ cubic arrangement. Each unit is a cube with an edge length of $a$, and the finished assembly forms a larger cube with an edge length of $3a$. 

Each individual server unit must be manufactured as either a "Type-B" (High-Security) unit or a "Type-W" (Standard) unit. The configuration of the exterior of the large data core must satisfy a specific security protocol: on each of the six outer square faces of the $3 \times 3 \times 3$ assembly, every row and every column of server faces must contain exactly one Type-B unit and exactly two Type-W units.

Let $m$ represent the minimum possible number of Type-B server units required to satisfy this protocol across all six faces. Let $M$ represent the maximum possible number of Type-B server units that can be used while still strictly adhering to the same protocol.

Calculate the value of the product $m \cdot M$.
