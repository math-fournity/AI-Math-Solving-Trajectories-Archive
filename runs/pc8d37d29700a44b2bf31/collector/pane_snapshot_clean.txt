## Proof

We claim the limit is **0** for every Borel set $B\subset\mathbb{R}^2$ with $\la
mbda_2(B)<\infty$.

**Step 1: Change of variables.** Consider the map $\Phi:(x,y)\mapsto (x,u)=(x,xy
)$, defined on $\{x\neq 0\}$. Its Jacobian is
$$\det\frac{\partial(x,u)}{\partial(x,y)}=\det\begin{pmatrix}1&0\\ y&x\end{pmatr
ix}=x,$$
so $dx\,dy = \frac{dx\,du}{|x|}$. The set $\{x=0\}$ has $\lambda_2$-measure zero
, hence contributes nothing. Setting $f=\mathbf{1}_B$,
$$\int_B \sin(nxy)\,d\lambda_2 = \int_{\mathbb{R}^2} f(x,y)\sin(nxy)\,dx\,dy = \
int_{\mathbb{R}^2} f\!\left(x,\tfrac{u}{x}\right)\sin(nu)\,\frac{dx\,du}{|x|}.$$

**Step 2: Define the marginal.** Let
$$h(u):=\int_{\mathbb{R}}\frac{f(x,u/x)}{|x|}\,dx=\int_{\mathbb{R}}\frac{\mathbf
{1}_B(x,u/x)}{|x|}\,dx.$$

**Step 3: $h\in L^1(\mathbb{R})$.** By Tonelli (the integrand below is non-negat
ive),
$$\int_{\mathbb{R}} h(u)\,du = \int_{\mathbb{R}}\int_{\mathbb{R}}\frac{\mathbf{1
}_B(x,u/x)}{|x|}\,dx\,du = \int_{\mathbb{R}}\frac{1}{|x|}\left(\int_{\mathbb{R}}
\mathbf{1}_B(x,u/x)\,du\right)dx.$$
Substituting $y=u/x$ (so $du=|x|\,dy$) in the inner integral,
$$\int_{\mathbb{R}}\mathbf{1}_B(x,u/x)\,du = \int_{\mathbb{R}}\mathbf{1}_B(x,y)\
,|x|\,dy = |x|\int_{\mathbb{R}}\mathbf{1}_B(x,y)\,dy.$$
Therefore
$$\int_{\mathbb{R}} h(u)\,du = \int_{\mathbb{R}}\frac{1}{|x|}\cdot|x|\int_{\math
bb{R}}\mathbf{1}_B(x,y)\,dy\,dx = \int_{\mathbb{R}^2}\mathbf{1}_B\,d\lambda_2 =
\lambda_2(B)<\infty.$$
So $h\in L^1(\mathbb{R})$.

**Step 4: Justify Fubini and apply Riemann–Lebesgue.** Since
$$\int_{\mathbb{R}^2}\frac{\mathbf{1}_B(x,u/x)}{|x|}\,dx\,du = \lambda_2(B)<\inf
ty,$$
the function $\frac{f(x,u/x)}{|x|}\sin(nu)$ is absolutely integrable, so Fubini
gives
$$\int_B \sin(nxy)\,d\lambda_2 = \int_{\mathbb{R}}\sin(nu)\,h(u)\,du.$$
Since $h\in L^1(\mathbb{R})$, the **Riemann–Lebesgue lemma** yields
$$\lim_{n\to\infty}\int_{\mathbb{R}}\sin(nu)\,h(u)\,du = 0.$$

Hence
$$\boxed{\lim_{n\to\infty}\int_B \sin(nxy)\,d\lambda_2 = 0}$$
for every Borel set $B\subset\mathbb{R}^2$ of finite Lebesgue measure.
