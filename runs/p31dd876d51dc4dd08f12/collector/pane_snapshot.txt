## Proof

**Setup.** We have $g \in L^1(\Omega, \mu)$ and $f$ defined by
$$f(x) = \begin{cases} \frac{\overline{g(x)}}{|g(x)|}, & g(x) \neq 0 \\ 0, & g(x
) = 0 \end{cases}$$

Note that $f$ is well-defined and measurable: on $\{g \neq 0\}$, $|f(x)| = \left
|\frac{\overline{g(x)}}{|g(x)|}\right| = \frac{|g(x)|}{|g(x)|} = 1$, and on $\{g
 = 0\}$, $|f(x)| = 0$. So in general $|f(x)| \in \{0, 1\}$ pointwise.

**The hypothesis** $|f(x)| = 1$ for all $x$ means that $g(x) \neq 0$ for all $x$
 (a.e.), i.e., $\mu(\{x : g(x) = 0\}) = 0$. Under this hypothesis, $|f(x)| = 1$
a.e.

**Claim 1: $f \in L^\infty$.** Since $|f(x)| \leq 1$ for all $x$ (by constructio
n, $|f| \in \{0,1\}$), we have for any $\alpha > 1$:
$$\mu(\{x : |f(x)| > \alpha\}) = 0,$$
since $|f(x)| \leq 1 < \alpha$. Therefore $\{\alpha > 0 : \mu(\{|f| > \alpha\})
= 0\}$ is nonempty (it contains $(1, \infty)$), so
$$\|f\|_\infty = \inf\{\alpha > 0 : \mu(\{|f| > \alpha\}) = 0\} \leq 1 < \infty.
$$
Hence $f \in L^\infty$. (This part holds even without the hypothesis $|f|=1$.)

**Claim 2: $\|f\|_\infty = 1$.** Under the hypothesis $|f(x)| = 1$ for all $x$ a
.e.:

- **Lower bound:** For any $0 < \alpha < 1$, the set $\{x : |f(x)| > \alpha\}$ c
ontains $\{x : g(x) \neq 0\}$, which has full measure (since $\mu(\{g = 0\}) = 0
$ by hypothesis). Assuming $\mu(\Omega) > 0$, this set has positive measure, so
$\mu(\{|f| > \alpha\}) > 0$. Therefore no $\alpha < 1$ belongs to the set $\{\al
pha > 0 : \mu(\{|f| > \alpha\}) = 0\}$, giving $\|f\|_\infty \geq 1$.

- **Upper bound:** For any $\alpha \geq 1$, since $|f(x)| = 1 \leq \alpha$ a.e.,
 we have $\{x : |f(x)| > \alpha\} \subseteq \{x : |f(x)| \neq 1\}$, which has me
asure zero. So $\mu(\{|f| > \alpha\}) = 0$, giving $\|f\|_\infty \leq 1$.

Combining: $\|f\|_\infty = 1$.

**Remark on the degenerate case.** If $\mu(\Omega) = 0$, then $\mu(\{|f| > \alph
a\}) = 0$ for every $\alpha > 0$, giving $\|f\|_\infty = 0$. In this trivial cas
e the conclusion $\|f\|_\infty = 1$ fails, but $L^\infty$ itself is the trivial
vector space $\{0\}$, so the question is vacuous. For any non-degenerate measure
 space ($\mu(\Omega) > 0$), the conclusion holds.

**Conclusion.** Yes. For any non-degenerate measure space, the condition $|f(x)|
 = 1$ for all $x$ (a.e.) guarantees both that $f \in L^\infty$ and that $\|f\|_\
infty = 1$.
