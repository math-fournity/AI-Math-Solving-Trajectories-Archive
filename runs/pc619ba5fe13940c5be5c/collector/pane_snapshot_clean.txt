## Solution

We evaluate
$$L = \lim_{n\to+\infty} \frac{e^{(n+1)^2}}{(n+1)\int_{n}^{n+1}e^{x^2}\,dx}.$$

**Step 1: Substitution to isolate the dominant exponential.**

Let $x = n + t$ with $t \in [0,1]$, so $x^2 = n^2 + 2nt + t^2$. Then
$$\int_{n}^{n+1} e^{x^2}\,dx = e^{n^2}\int_0^1 e^{2nt+t^2}\,dt.$$

Since $(n+1)^2 = n^2 + 2n + 1$, the expression becomes
$$L = \lim_{n\to\infty} \frac{e^{2n+1}}{(n+1)\int_0^1 e^{2nt+t^2}\,dt}.$$

**Step 2: Locate the dominant contribution via $u = 1-t$.**

The integrand $e^{2nt+t^2}$ is maximized at $t=1$. Set $u = 1-t$:
$$2nt + t^2 = 2n(1-u) + (1-u)^2 = (2n+1) - (2n+2)u + u^2.$$

Hence
$$\int_0^1 e^{2nt+t^2}\,dt = e^{2n+1}\int_0^1 e^{-(2n+2)u+u^2}\,du,$$

and therefore
$$L = \lim_{n\to\infty} \frac{1}{(n+1)\int_0^1 e^{-(2n+2)u+u^2}\,du}.$$

**Step 3: Rescale and apply dominated convergence.**

Set $v = (2n+2)u$, so $u = \frac{v}{2n+2}$, $du = \frac{dv}{2n+2}$:
$$(n+1)\int_0^1 e^{-(2n+2)u+u^2}\,du = \frac{n+1}{2n+2}\int_0^{2n+2} e^{-v+\frac
{v^2}{(2n+2)^2}}\,dv = \frac{1}{2}\int_0^{2n+2} e^{-v+\frac{v^2}{(2n+2)^2}}\,dv.
$$

Writing the integral over $[0,\infty)$ with an indicator:
$$\frac{1}{2}\int_0^{\infty} e^{-v+\frac{v^2}{(2n+2)^2}}\,\mathbf{1}_{[0,\,2n+2]
}(v)\,dv.$$

For $v \le 2n+2$ we have $\frac{v^2}{(2n+2)^2} \le 1$, so the integrand is domin
ated by $e\cdot e^{-v}$, which is integrable on $[0,\infty)$. Pointwise, the int
egrand converges to $e^{-v}$. By the **Dominated Convergence Theorem**,
$$\lim_{n\to\infty}\int_0^{2n+2} e^{-v+\frac{v^2}{(2n+2)^2}}\,dv = \int_0^{\inft
y} e^{-v}\,dv = 1.$$

**Step 4: Conclude.**

$$(n+1)\int_0^1 e^{-(2n+2)u+u^2}\,du \;\longrightarrow\; \frac{1}{2}\cdot 1 = \f
rac{1}{2},$$

and therefore
$$L = \frac{1}{1/2} = \boxed{2}.$$
