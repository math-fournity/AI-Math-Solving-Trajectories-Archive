# Problem

A high-tech server farm is organized into a rigid square grid of $n$ rows and $n$ columns, creating exactly $n^2$ possible slots for processor nodes. Each slot is identified by its coordinates $(x, y)$, where $x$ and $y$ are integers ranging from $1$ to $n$.

A network architect needs to install a specific set of active nodes within these slots. However, due to a unique electromagnetic interference pattern, the configuration must be "interference-free." A configuration is defined as interference-free if it is impossible to find four active nodes that serve as the four corners of a parallelogram, provided those four nodes are not all located on the same straight line.

What is the maximum number of active processor nodes the architect can install in the grid such that the set of nodes remains interference-free?
