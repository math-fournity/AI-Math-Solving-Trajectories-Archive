Looking at this problem, I need to find a polynomial $p(x)$ with $p(p(x)) = xp(x
) + x^2$.

**Degree analysis.** Let $\deg p = n$.

- If $n \geq 2$: $\deg(p(p(x))) = n^2$, while $\deg(xp(x)+x^2) = n+1$. So $n^2 =
 n+1$, i.e. $n^2-n-1=0$, which has no integer solution. No polynomial of degree
$\geq 2$ works.
- If $n = 0$ (constant $p(x)=c$): $p(p(x))=c$ but $xp(x)+x^2 = cx+x^2$ is noncon
stant. Impossible.

So $n=1$ is the only option.

**Solving for $p(x) = ax+b$.** Then:
$$p(p(x)) = a(ax+b)+b = a^2 x + ab+b.$$
$$xp(x)+x^2 = x(ax+b)+x^2 = (a+1)x^2 + bx.$$

Equating coefficients:

- $x^2$: $0 = a+1 \Rightarrow a = -1$.
- $x^1$: $a^2 = b \Rightarrow 1 = b$.
- $x^0$: $ab+b = 0 \Rightarrow (-1)(1)+1 = 0$ ✓.

**Verification.** With $p(x) = 1-x$:
$$p(p(x)) = p(1-x) = 1-(1-x) = x.$$
$$xp(x)+x^2 = x(1-x)+x^2 = x - x^2 + x^2 = x. \quad\checkmark$$

**Conclusion.** The unique polynomial solution is:

$$\boxed{p(x) = 1 - x}.$$
