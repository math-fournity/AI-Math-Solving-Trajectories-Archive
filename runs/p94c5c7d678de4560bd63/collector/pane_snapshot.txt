**Key observation:** $\Omega((a+k)(b+k)) = \Omega(a+k) + \Omega(b+k)$, so the pa
rity condition becomes $\Omega(a+k) \equiv \Omega(b+k) \pmod{2}$ for all $k = 0,
 1, \ldots, N-1$.

This reduces to finding two identical length-$N$ blocks in the parity sequence o

**Proof.**

Define $\lambda(n) = \Omega(n) \bmod 2$ for $n \geq 1$. The condition $\Omega((a
+k)(b+k))$ even for all $k < N$ is equivalent to
$$\lambda(a+k) = \lambda(b+k) \quad \text{for all } k = 0, 1, \ldots, N-1.$$

For each $n \geq 1$, consider the **block** of length $N$:
$$B_n = \big(\lambda(n),\, \lambda(n+1),\, \ldots,\, \lambda(n+N-1)\big) \in \{0
,1\}^N.$$

There are exactly $2^N$ possible values for such a block. Now consider the $2^N
+ 1$ blocks
$$B_1,\; B_2,\; \ldots,\; B_{2^N+1}.$$

By the **Pigeonhole Principle**, two of these blocks must be identical: there ex
ist $a, b$ with $1 \leq a < b \leq 2^N + 1$ such that $B_a = B_b$.

Since $a \neq b$ (they are distinct positive integers) and $B_a = B_b$ means $\l
ambda(a+k) = \lambda(b+k)$ for every $k = 0, 1, \ldots, N-1$, we conclude:
$$\Omega(a+k) \equiv \Omega(b+k) \pmod{2} \quad \text{for all } k < N.$$

Therefore
$$\Omega\big((a+k)(b+k)\big) = \Omega(a+k) + \Omega(b+k) \equiv 0 \pmod{2} \quad
 \text{for all } k < N,$$

which is even, as required. $\blacksquare$
