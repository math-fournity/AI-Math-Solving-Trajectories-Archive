**Key construction relations.** For the isosceles right triangle AB₁C with right

- A = B₁ + s₁·i·(C − B₁), where s₁ = ±1

**Determining the signs.** Testing all four sign combinations against the constr

$$B + C = 2i\,u, \quad \text{where } u = 6$$

## Solving for B and C

## Computing A

With s₁ = −1: A = (1+i)·B₁ − i·C. For **B = (2√10, 3), C = (−2√10, 9)**:

$$A = (1+i)(-6) - i(-2\sqrt{10} + 9i) = 3 + (2\sqrt{10} - 6)i$$

So **A = (3, 2√10 − 6)**.

## Computing the Area

$$\vec{B-A} = (2\sqrt{10}-3,\; 9-2\sqrt{10}), \quad \vec{C-A} = (-2\sqrt{10}-3,\

$$\text{Area} = \frac{1}{2}\left|\det\begin{pmatrix} 2\sqrt{10}-3 & 9-2\sqrt{10}

$$= \frac{1}{2}\left|(2\sqrt{10}-3)(15-2\sqrt{10}) - (9-2\sqrt{10})(-2\sqrt{10}-
