## Proof

**Setup.** Let $\alpha = \sqrt{b(c-1)}$ (a known constant once $b, c$ are fixed)
, and let $t = \sqrt{a - c}$, so $a = t^2 + c$. The equation becomes:

$$\sqrt{(t^2 + c)(101b+1)} = 1 + \alpha + 10\sqrt{b}\, t$$

**Squaring both sides** (both sides are non-negative when a solution exists):

$$(t^2 + c)(101b+1) = (1 + \alpha + 10\sqrt{b}\, t)^2$$

Expanding the right side using $\alpha^2 = b(c-1)$:

$$(101b+1)\,t^2 + c(101b+1) = 1 + \alpha^2 + 100b\,t^2 + 2\alpha + 20\sqrt{b}\,t
 + 20\alpha\sqrt{b}\,t$$

**Collecting terms** into a quadratic in $t$:

$$(101b + 1 - 100b)\,t^2 - 20\sqrt{b}\,(1+\alpha)\,t + c(101b+1) - (1+\alpha)^2
= 0$$

$$(b+1)\,t^2 - 20\sqrt{b}\,(1+\alpha)\,t + \big[c(101b+1) - (1+\alpha)^2\big] =
0$$

**Computing the discriminant.** Using $\alpha^2 = b(c-1) = bc - b$, so $(1+\alph
a)^2 = 1 + 2\alpha + bc - b$:

$$c(101b+1) - (1+\alpha)^2 = 101bc + c - 1 - 2\alpha - bc + b = 100bc + b + c -
1 - 2\alpha$$

The discriminant is:

$$\Delta = 400b(1+\alpha)^2 - 4(b+1)(100bc + b + c - 1 - 2\alpha)$$

Substituting $u = c - 1$ (so $\alpha = \sqrt{bu}$) and expanding:

$$\Delta = 4(101b+1)\big(2\sqrt{bu} - b - u\big)$$

$$= -4(101b+1)\big(\sqrt{b} - \sqrt{u}\big)^2$$

$$= -4(101b+1)\big(\sqrt{b} - \sqrt{c-1}\big)^2$$

**Key observation.** Since $101b + 1 > 0$ for $b > 0$, we have:

$$\Delta = -4(101b+1)\left(\sqrt{b} - \sqrt{c-1}\right)^2 \leq 0$$

with equality **if and only if** $\sqrt{c-1} = \sqrt{b}$, i.e., $c = b + 1$.

**Conclusion on existence.** A real solution for $a$ exists if and only if $c =
b + 1$. In that case $\Delta = 0$, giving a **unique** solution (double root):

$$t = \frac{20\sqrt{b}\,(1+\alpha)}{2(b+1)}$$

With $c = b+1$, we get $\alpha = \sqrt{b \cdot b} = b$, so:

$$t = \frac{20\sqrt{b}\,(1+b)}{2(b+1)} = 10\sqrt{b}$$

Therefore:

$$a = t^2 + c = 100b + (b+1) = \boxed{101b + 1}$$

**Verification.** With $a = 101b+1$ and $c = b+1$:
- $\sqrt{a(101b+1)} = \sqrt{(101b+1)^2} = 101b+1$
- $\sqrt{b(c-1)} = \sqrt{b \cdot b} = b$
- $10\sqrt{b(a-c)} = 10\sqrt{b \cdot 100b} = 100b$

Check: $(101b+1) - 1 = b + 100b \implies 101b = 101b$. ✓

The primary core efficiency is $a = 101b + 1$.
