**Claim.** The limit equals $L$.

**Proof.**

Since $a_n \to L \neq 0$, the sequence $(a_n)$ is bounded: there exists $M>0$ wi
th $|a_n|\le M$ for all $n$. Hence $\sum_{n\ge 0} a_n x^n$ converges absolutely
for every $|x|<1$, so the expression is well-defined for $x\in(0,1)$.

Write $a_n = L + b_n$, where $b_n := a_n - L \to 0$ as $n\to\infty$. Then for $0
<x<1$,

$$
\sum_{n\ge 0} a_n x^n = L\sum_{n\ge 0} x^n + \sum_{n\ge 0} b_n x^n = \frac{L}{1-
x} + \sum_{n\ge 0} b_n x^n.
$$

Multiplying by $(1-x)$,

$$
(1-x)\sum_{n\ge 0} a_n x^n = L + (1-x)\sum_{n\ge 0} b_n x^n.
$$

It remains to show the **key lemma**: if $b_n\to 0$, then $(1-x)\sum_{n\ge 0} b_
n x^n \to 0$ as $x\to 1^-$.

*Proof of lemma.* Let $\varepsilon>0$. Since $b_n\to 0$, choose $N$ so that $|b_
n|<\varepsilon/2$ for all $n\ge N$. Split

$$
(1-x)\sum_{n\ge 0} b_n x^n = \underbrace{(1-x)\sum_{n=0}^{N-1} b_n x^n}_{\text{(
I)}} + \underbrace{(1-x)\sum_{n\ge N} b_n x^n}_{\text{(II)}}.
$$

For (I): it is a finite sum, so
$$
|\text{(I)}| \le (1-x)\sum_{n=0}^{N-1}|b_n|x^n \le (1-x)\sum_{n=0}^{N-1}|b_n| \x
rightarrow{x\to 1^-} 0.
$$
Thus there exists $\delta_1>0$ such that $|\text{(I)}|<\varepsilon/2$ whenever $
1-\delta_1 < x < 1$.

For (II): using $|b_n|<\varepsilon/2$ for $n\ge N$,
$$
|\text{(II)}| \le (1-x)\sum_{n\ge N}\tfrac{\varepsilon}{2} x^n = \tfrac{\varepsi
lon}{2}(1-x)\cdot \frac{x^N}{1-x} = \tfrac{\varepsilon}{2}x^N < \tfrac{\varepsil
on}{2}.
$$

Combining, for $1-\delta_1 < x < 1$,
$$
\left|(1-x)\sum_{n\ge 0} b_n x^n\right| \le |\text{(I)}| + |\text{(II)}| < \frac
{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.
$$

Since $\varepsilon>0$ was arbitrary, the lemma follows. $\square$

Applying the lemma with $b_n = a_n - L$,

$$
\lim_{x\to 1^-}(1-x)\sum_{n\ge 0} a_n x^n = L + \lim_{x\to 1^-}(1-x)\sum_{n\ge 0
} b_n x^n = L + 0 = L.
$$

Therefore,

$$
\boxed{\lim_{x\to 1^-}(1-x)\sum_{n\ge 0} a_n x^n = L.}
$$
