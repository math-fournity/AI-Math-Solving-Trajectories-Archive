## Solution: SONET Cross-Connect Modular Capacity Routing

### 1. Problem Classification

The formulation is an **integer multi-commodity minimum-cost flow problem with m
odular link capacities**. The decision variables $x_{kp}$ assign integer flow to
 paths. The parameters $c_{\ell n}$ (number of modules of type $n$ on link $\ell
$) and $M_n$ (modular capacity of type $n$) are fixed, so each link $\ell$ has a
 fixed total capacity $C_\ell = \sum_{n=1}^{4} M_n c_{\ell n}$.

The constraint matrix has a **block-angular structure**: the demand constraints
$\sum_p x_{kp} = h_k$ are independent across demands $k$, while the capacity con
straints $\sum_k \sum_p \delta_{k\ell p} x_{kp} \leq C_\ell$ couple all demands
through shared links.

### 2. Lagrangian Relaxation of Capacity Constraints

Relax the $L$ capacity constraints with multipliers $\lambda_\ell \geq 0$:

$$
L(\mathbf{x}, \boldsymbol{\lambda}) = \sum_{k=1}^{K}\sum_{p=1}^{P_k} \xi_{kp}\,
x_{kp} + \sum_{\ell=1}^{L} \lambda_\ell \left(\sum_{k=1}^{K}\sum_{p=1}^{P_k} \de
lta_{k\ell p}\, x_{kp} - C_\ell\right)
$$

where $C_\ell = \sum_{n=1}^{4} M_n c_{\ell n}$. Rearranging by collecting terms
in $x_{kp}$:

$$
L(\mathbf{x}, \boldsymbol{\lambda}) = \sum_{k=1}^{K}\sum_{p=1}^{P_k} \underbrace
{\left(\xi_{kp} + \sum_{\ell=1}^{L} \lambda_\ell\, \delta_{k\ell p}\right)}_{\ti
lde{\xi}_{kp}(\boldsymbol{\lambda})}\; x_{kp} \;-\; \sum_{\ell=1}^{L} \lambda_\e
ll\, C_\ell
$$

The modified path cost $\tilde{\xi}_{kp} = \xi_{kp} + \sum_\ell \lambda_\ell \de
lta_{k\ell p}$ is the original path cost plus the **congestion price** $\sum_\el
l \lambda_\ell \delta_{k\ell p}$, which charges each path for the capacity it co
nsumes on each link at price $\lambda_\ell$.

### 3. Decomposition into Independent Shortest-Path Subproblems

For fixed $\boldsymbol{\lambda} \geq \mathbf{0}$, the inner minimization $\min_{
\mathbf{x}} L(\mathbf{x}, \boldsymbol{\lambda})$ subject only to $\sum_p x_{kp}
= h_k$, $x_{kp} \geq 0$, integer, **separates by demand** $k$:

$$
\min_{\{x_{kp}\}} \sum_{p=1}^{P_k} \tilde{\xi}_{kp}\, x_{kp} \quad \text{s.t.} \
quad \sum_{p=1}^{P_k} x_{kp} = h_k,\quad x_{kp} \geq 0,\;\text{integer}
$$

**Lemma.** *The optimal solution assigns all $h_k$ units to a single path of min
imum modified cost.*

*Proof.* This is a continuous (integer) knapsack with a single equality constrai
nt and non-negativity. Let $p_k^* = \arg\min_{p} \tilde{\xi}_{kp}$. For any feas
ible $\{x_{kp}\}$:

$$
\sum_p \tilde{\xi}_{kp}\, x_{kp} \geq \tilde{\xi}_{kp_k^*} \sum_p x_{kp} = \tild
e{\xi}_{kp_k^*}\, h_k
$$

with equality when $x_{kp_k^*} = h_k$ and $x_{kp} = 0$ for $p \neq p_k^*$. Since
 $h_k$ is integer, this solution is integer. $\square$

### 4. Lagrangian Dual Function

Substituting the optimal subproblem solutions:

$$
\phi(\boldsymbol{\lambda}) = \sum_{k=1}^{K} h_k \min_{p \in \{1,\ldots,P_k\}} \t
ilde{\xi}_{kp}(\boldsymbol{\lambda}) \;-\; \sum_{\ell=1}^{L} \lambda_\ell\, C_\e

$$

The **Lagrangian dual** is:

$$
\boxed{\max_{\boldsymbol{\lambda} \geq \mathbf{0}} \;\phi(\boldsymbol{\lambda})
= \max_{\boldsymbol{\lambda} \geq \mathbf{0}} \left[\sum_{k=1}^{K} h_k \min_{p}\
left(\xi_{kp} + \sum_{\ell=1}^{L} \lambda_\ell\, \delta_{k\ell p}\right) - \sum_
{\ell=1}^{L} \lambda_\ell \sum_{n=1}^{4} M_n\, c_{\ell n}\right]}
$$

**Theorem (Weak Duality).** *For all $\boldsymbol{\lambda} \geq \mathbf{0}$, $\p
hi(\boldsymbol{\lambda}) \leq F^*$, where $F^*$ is the optimal primal value.*

*Proof.* For any primal-feasible $\bar{\mathbf{x}}$ and any $\boldsymbol{\lambda
} \geq \mathbf{0}$:

$$
L(\bar{\mathbf{x}}, \boldsymbol{\lambda}) = \sum_k \sum_p \xi_{kp} \bar{x}_{kp}
+ \sum_\ell \lambda_\ell \underbrace{\left(\sum_k \sum_p \delta_{k\ell p} \bar{x
}_{kp} - C_\ell\right)}_{\leq\, 0} \leq \sum_k \sum_p \xi_{kp} \bar{x}_{kp}
$$

Taking the minimum over all $\mathbf{x}$ (which includes all primal-feasible $\b
ar{\mathbf{x}}$): $\phi(\boldsymbol{\lambda}) = \min_{\mathbf{x}} L(\mathbf{x},
\boldsymbol{\lambda}) \leq L(\bar{\mathbf{x}}, \boldsymbol{\lambda}) \leq F^*$.
$\square$

### 5. Subgradient of the Dual Function

**Theorem.** *A subgradient of $\phi$ at $\boldsymbol{\lambda}$ is the vector $\
mathbf{g} \in \mathbb{R}^L$ with components:*

$$
g_\ell = \sum_{k=1}^{K} \sum_{p=1}^{P_k} \delta_{k\ell p}\, x_{kp}^*(\boldsymbol
{\lambda}) - C_\ell
$$

*where $x_{kp}^*$ is the optimal relaxed solution (all $h_k$ on the shortest mod
ified-cost path for demand $k$).*

*Proof.* $\phi(\boldsymbol{\lambda})$ is the pointwise minimum of affine functio
ns of $\boldsymbol{\lambda}$ (one per path selection), hence concave. By Danskin
's theorem, for any minimizing path selection, the corresponding gradient of the
 affine piece is a subgradient. The partial derivative of $\phi$ with respect to
 $\lambda_\ell$ for a fixed path selection is exactly $g_\ell$. $\square$

**Physical interpretation:** $g_\ell$ is the **capacity slack** on link $\ell$ —
 the total flow assigned to link $\ell$ minus its capacity. If $g_\ell > 0$, lin
k $\ell$ is overloaded and $\lambda_\ell$ should increase; if $g_\ell < 0$, link
 $\ell$ is underutilized and $\lambda_\ell$ should decrease.

### 6. Subgradient Optimization Algorithm

Initialize $\lambda_\ell^{(0)} = 0$ for all $\ell$. At iteration $t$:

1. **Solve subproblems:** For each demand $k$, compute modified costs $\tilde{\x
i}_{kp}^{(t)} = \xi_{kp} + \sum_\ell \lambda_\ell^{(t)} \delta_{k\ell p}$ and as
sign $x_{kp_k^*}^{(t)} = h_k$ to the shortest path $p_k^*$.

2. **Compute subgradient:** $g_\ell^{(t)} = \sum_k \sum_p \delta_{k\ell p}\, x_{
kp}^{(t)} - C_\ell$.

3. **Update multipliers:** $\lambda_\ell^{(t+1)} = \max\!\left(0,\; \lambda_\ell
^{(t)} + \alpha_t\, g_\ell^{(t)}\right)$, where $\alpha_t > 0$ is a step size sa
tisfying $\alpha_t \to 0$ and $\sum_t \alpha_t = \infty$ (e.g., $\alpha_t = \fra
c{a}{t}$ for constant $a > 0$).

**Theorem (Convergence).** *With the step-size conditions above, the sequence $\
phi(\boldsymbol{\lambda}^{(t)})$ converges to the optimal dual value $\phi^* = \
max_{\boldsymbol{\lambda} \geq 0} \phi(\boldsymbol{\lambda})$.*

*Proof.* This is the standard subgradient method for concave maximization over a
 closed convex set ($\boldsymbol{\lambda} \geq \mathbf{0}$). The dual function $
\phi$ is concave (as a pointwise minimum of affine functions). The Polyak/Shor c
onvergence theorem for subgradient methods with diminishing step sizes guarantee
s convergence to the optimum. $\square$

### 7. Duality Gap and Integrality

**Theorem.** *There is in general a duality gap: $\phi^* \leq F^*$, with strict
inequality possible.*

*Proof.* The LP relaxation (dropping integrality) has zero LP duality gap by str
ong duality, so $\phi^* = F_{\text{LP}}^* \leq F^*$, where $F_{\text{LP}}^*$ is
the LP relaxation optimum. The gap $F^* - \phi^* = F^* - F_{\text{LP}}^*$ is the
 integrality gap, which is non-zero in general for multi-commodity flow. $\squar
e$

However, the Lagrangian relaxation with **integer subproblem solutions** (all-or
-nothing assignment to shortest paths) often yields a tighter bound than the LP
relaxation, because the subproblem integrality is preserved.

### 8. Primal Feasible Solution Recovery

The Lagrangian solution $\mathbf{x}^*(\boldsymbol{\lambda}^*)$ may violate capac
ity constraints (some $g_\ell > 0$). A feasible primal solution is recovered as
follows:

**Procedure (Rerouting heuristic):**
1. Identify the set of overloaded links: $\mathcal{O} = \{\ell : g_\ell > 0\}$.
2. For each demand $k$ routed through any $\ell \in \mathcal{O}$, compute altern
ative paths that avoid $\mathcal{O}$.
3. Reroute flow greedily: move $\Delta$ units from the current path to the cheap
est alternative path that has residual capacity, reducing overload.
4. If no rerouting fully resolves overload, apply branch-and-bound on the remain
ing violated constraints, using $\phi^*$ as a lower bound and the best heuristic
 solution as an upper bound.

**Theorem (Optimality Certificate).** *If a primal-feasible solution $\hat{\math
bf{x}}$ is found with $F(\hat{\mathbf{x}}) = \phi^*$, then $\hat{\mathbf{x}}$ is
 optimal.*

*Proof.* By weak duality, $\phi^* \leq F^*$. If $F(\hat{\mathbf{x}}) = \phi^*$ a
nd $\hat{\mathbf{x}}$ is feasible, then $F^* \leq F(\hat{\mathbf{x}}) = \phi^* \
leq F^*$, so $F^* = \phi^* = F(\hat{\mathbf{x}})$. $\square$

The optimal total cost $F^*$ is obtained by the following procedure:
