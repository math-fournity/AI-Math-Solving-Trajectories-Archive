## Solution

We want $f^{(2021)}(0)$ where $f(x) = \dfrac{1+x}{1+x+x^2}$.

**Key simplification.** Multiply numerator and denominator by $(1-x)$:

$$f(x) = \frac{(1+x)(1-x)}{(1+x+x^2)(1-x)} = \frac{1-x^2}{1-x^3}.$$

**Power series expansion.** For $|x|<1$,

$$\frac{1}{1-x^3} = \sum_{k=0}^{\infty} x^{3k}.$$

Therefore

$$f(x) = (1-x^2)\sum_{k=0}^{\infty} x^{3k} = \sum_{k=0}^{\infty} x^{3k} - \sum_{
k=0}^{\infty} x^{3k+2}.$$

**Extracting the coefficient of $x^n$.** The coefficient $[x^n]\,f(x)$ is:
- $1$ if $n \equiv 0 \pmod{3}$,
- $0$ if $n \equiv 1 \pmod{3}$,
- $-1$ if $n \equiv 2 \pmod{3}$.

**Apply to $n = 2021$.** Since $2021 = 673 \times 3 + 2$, we have $2021 \equiv 2
 \pmod{3}$, so

$$[x^{2021}]\,f(x) = -1.$$

**Convert to derivative.** Since $f(x) = \sum_{n} \frac{f^{(n)}(0)}{n!} x^n$, th
e coefficient of $x^n$ equals $\frac{f^{(n)}(0)}{n!}$. Thus

$$\frac{f^{(2021)}(0)}{2021!} = -1 \implies f^{(2021)}(0) = -2021!.$$
