# Problem

A high-security data vault contains 2023 unique biometric encryption keys and $2023 \times 1011$ secure storage containers. Each container is designed to unlock if and only if a specific, unique pair of these biometric keys is simultaneously active in the system. The technician, Alex, has inherited the vault but the records identifying which container is linked to which pair of keys have been lost.

Initially, all 2023 biometric keys are deactivated. Alex must map every container to its corresponding key pair. Every minute, Alex can toggle the status of exactly one biometric key (either activating a deactivated key or deactivating an active one). Immediately after the toggle, the vault’s central computer displays the current status (locked or unlocked) of every container.

What is the minimum number of minutes Alex requires to definitively identify the specific pair of keys associated with every single container?
