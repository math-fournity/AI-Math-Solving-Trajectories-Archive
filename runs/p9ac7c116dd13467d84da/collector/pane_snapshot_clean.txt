## Solution

We seek the **radical** of the bilinear form $f(A,B) = n\,\mathrm{Trace}(AB) - \
mathrm{Trace}(A)\,\mathrm{Trace}(B)$, i.e. all $A \in M_n(\mathbb{C})$ with $f(A
,B)=0$ for every $B$.

### Step 1: Reformulate the condition

Let $a = \mathrm{Trace}(A)$. The condition $f(A,B)=0$ for all $B$ becomes

$$n\,\mathrm{Trace}(AB) = a\,\mathrm{Trace}(B) \quad \text{for all } B \in M_n(\
mathbb{C}),$$

which is equivalent to

$$\mathrm{Trace}\bigl((nA - aI_n)\,B\bigr) = 0 \quad \text{for all } B \in M_n(\
mathbb{C}).$$

### Step 2: Use non-degeneracy of the trace form

The standard trace pairing $(X,Y) \mapsto \mathrm{Trace}(XY)$ is **non-degenerat
e** on $M_n(\mathbb{C})$. Indeed, using the basis $\{E_{ij}\}$, $\mathrm{Trace}(
E_{ij}E_{kl}) = \delta_{jk}\delta_{il}$, which is a perfect pairing. Therefore

$$\mathrm{Trace}(XB) = 0 \;\text{ for all } B \;\Longrightarrow\; X = 0.$$

Applying this with $X = nA - aI_n$, we obtain

$$nA - aI_n = 0 \quad\Longrightarrow\quad A = \frac{a}{n}\,I_n.$$

### Step 3: Verify consistency and compute dimension

If $A = \frac{a}{n}I_n$, then $\mathrm{Trace}(A) = \frac{a}{n}\cdot n = a$, whic
h is consistent with the definition $a = \mathrm{Trace}(A)$. Checking the origin
al form:

$$f\!\left(\tfrac{a}{n}I_n,\, B\right) = n\,\mathrm{Trace}\!\left(\tfrac{a}{n}I_
n B\right) - a\,\mathrm{Trace}(B) = a\,\mathrm{Trace}(B) - a\,\mathrm{Trace}(B)
= 0. \;\checkmark$$

So $U^\perp = \{c\,I_n : c \in \mathbb{C}\}$, the line of scalar matrices, spann
ed by $I_n$.

### Conclusion

$$\boxed{\dim(U^\perp) = 1}$$
