## 证明

设对于 $x>0$，有 $g(x) = x\,f(x)$。由于 $f \in C(0,+\infty)$，因此 $g \in C(0,+\
infty)$。

**由条件 (1) 得：** $x\,f(x^2) = f(x)$。两边同乘 $x$：

$$x^2\,f(x^2) = x\,f(x) \implies g(x^2) = g(x).$$

因此对于所有 $x>0$，有 $g(x) = g(x^2)$。通过迭代，$g(x) = g(x^{1/2})$（将 $x$ 替
换为 $\sqrt{x}$），进而有

$$g(x) = g\!\left(x^{1/2^n}\right) \quad \text{对于所有 } n \ge 1.$$

由于 $x>0$，当 $n\to\infty$ 时 $x^{1/2^n} \to 1$。由 $g$ 的连续性，

$$g(x) = \lim_{n\to\infty} g\!\left(x^{1/2^n}\right) = g(1).$$

因此 $g$ 在 $(0,+\infty)$ 上是常数：$g(x) = g(1) = f(1)$。令 $c = f(1)$，我们得
到

$$f(x) = \frac{c}{x}, \qquad c \in \mathbb{R}.$$

**验证条件 (1)：** $x\,f(x^2) = x\cdot\frac{c}{x^2} = \frac{c}{x} = f(x)$. ✓

**验证条件 (2)：**

$$\int_x^{x^2} f(t)\,dt = \int_x^{x^2} \frac{c}{t}\,dt = c\ln\!\left(\frac{x^2}{
x}\right) = c\ln x,$$

$$\int_1^x f(t)\,dt = \int_1^x \frac{c}{t}\,dt = c\ln x.$$

两边相等。✓

**唯一性：** 条件 (1) 加上连续性已经迫使 $g(x)=g(1)$ 为常数，即 $f(x)=c/x$。条件
 (2) 并未进一步限制 $c$（它对所有 $c$ 都成立）。因此解集已穷尽。

$$\boxed{f(x) = \dfrac{c}{x}, \quad c \text{ 为任意实常数}}$$
