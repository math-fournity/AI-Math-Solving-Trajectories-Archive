## Proof

**Setup.** Let $R$ be a rectangle with side lengths $a$ and $b$. We work in $\ma
thbb{R}^{N+k}$ where $N = k^{k+1}$. Let $v_0, \dots, v_N$ be the $N+1$ vertices
of a regular simplex in $\mathbb{R}^N$ with side length $a$, and let $w_0, \dots
, w_k$ be the $k+1$ vertices of a regular simplex in $\mathbb{R}^k$ with side le
ngth $b$. Consider the $(N+1)(k+1)$ points $(v_i, w_j) \in \mathbb{R}^{N+k}$, wh
ere $0 \le i \le N$ and $0 \le j \le k$. Each point is assigned one of $k$ color
s. We prove that some four of these points form a monochromatic rectangle congru
ent to $R$.

**Step 1 (Pigeonhole on rows).** For each fixed $i \in \{0, \dots, N\}$, the $k+
1$ points $(v_i, w_0), \dots, (v_i, w_k)$ each receive one of $k$ colors. The co
mplete coloring of this row is described by a function $\{0, \dots, k\} \to \{1,
 \dots, k\}$, i.e., an element of $\{1, \dots, k\}^{k+1}$. There are exactly $k^
{k+1} = N$ such functions.

Since there are $N+1$ rows (one for each $i = 0, \dots, N$) but only $N$ distinc
t coloring patterns, by the **pigeonhole principle** there exist indices $0 \le
i_1 < i_2 \le N$ such that rows $i_1$ and $i_2$ have identical colorings. Concre
tely, for every $j \in \{0, \dots, k\}$:
$$\text{color}(v_{i_1}, w_j) = \text{color}(v_{i_2}, w_j). \quad (\star)$$

**Step 2 (Pigeonhole within a row).** Now focus on row $i_1$. The $k+1$ points $
(v_{i_1}, w_0), \dots, (v_{i_1}, w_k)$ are each colored with one of $k$ colors.
Since $k+1 > k$, by the **pigeonhole principle** there exist indices $0 \le j_1
< j_2 \le k$ such that:
$$\text{color}(v_{i_1}, w_{j_1}) = \text{color}(v_{i_1}, w_{j_2}) = c$$
for some color $c$.

**Step 3 (Monochromatic rectangle).** By property $(\star)$ from Step 1, the mat
ching columns in row $i_2$ carry the same colors as in row $i_1$. Therefore:
$$\text{color}(v_{i_2}, w_{j_1}) = \text{color}(v_{i_1}, w_{j_1}) = c,$$
$$\text{color}(v_{i_2}, w_{j_2}) = \text{color}(v_{i_1}, w_{j_2}) = c.$$

All four points $(v_{i_1}, w_{j_1}),\; (v_{i_1}, w_{j_2}),\; (v_{i_2}, w_{j_1}),
\; (v_{i_2}, w_{j_2})$ are colored $c$.

**Step 4 (Geometric verification).** We verify these four points form a rectangl
e congruent to $R$. Denote:
- $P_{11} = (v_{i_1}, w_{j_1})$, $P_{12} = (v_{i_1}, w_{j_2})$,
- $P_{21} = (v_{i_2}, w_{j_1})$, $P_{22} = (v_{i_2}, w_{j_2})$.

Since the $v$-coordinates live in $\mathbb{R}^N$ and the $w$-coordinates live in
 $\mathbb{R}^k$, these subspaces are orthogonal in $\mathbb{R}^{N+k}$. Computing
 squared distances:

- $|P_{11} - P_{12}|^2 = |v_{i_1} - v_{i_1}|^2 + |w_{j_1} - w_{j_2}|^2 = 0 + b^2
 = b^2$, so $|P_{11}P_{12}| = b$.

- $|P_{11} - P_{21}|^2 = |v_{i_1} - v_{i_2}|^2 + |w_{j_1} - w_{j_1}|^2 = a^2 + 0
 = a^2$, so $|P_{11}P_{21}| = a$.

- $|P_{12} - P_{22}|^2 = |v_{i_1} - v_{i_2}|^2 + |w_{j_2} - w_{j_2}|^2 = a^2$, s
o $|P_{12}P_{22}| = a$.

- $|P_{21} - P_{22}|^2 = |v_{i_2} - v_{i_2}|^2 + |w_{j_1} - w_{j_2}|^2 = b^2$, s
o $|P_{21}P_{22}| = b$.

- $|P_{11} - P_{22}|^2 = |v_{i_1} - v_{i_2}|^2 + |w_{j_1} - w_{j_2}|^2 = a^2 + b
^2$ (diagonal).

The four points have side lengths $a$ and $b$ with right angles (the $v$-directi
on and $w$-direction edges are orthogonal), and diagonal $\sqrt{a^2+b^2}$. This
is a rectangle congruent to $R$.

**Conclusion.** For any $k$-coloring of the points $\{(v_i, w_j)\}$, the pigeonh
ole principle (applied first across $N+1$ rows with $N = k^{k+1}$ patterns, then
 within a single row of $k+1$ points with $k$ colors) guarantees a monochromatic
 set of four points forming a rectangle with sides $a, b$, congruent to $R$. $\b
lacksquare$
