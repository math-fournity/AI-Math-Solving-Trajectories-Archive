# Spectrum of the Multiplication Operator $M_b$ on $L_2(\mathbb{R}^n)$

## Setup

Define $b(x) = e^{|x|^2}$ where $|x|^2 = x_1^2 + \cdots + x_n^2$. The multiplica
tion operator $M_b$ acts on $L_2(\mathbb{R}^n)$ by
$$(M_b f)(x) = e^{|x|^2} f(x),$$
with domain
$$D(M_b) = \bigl\{ f \in L_2(\mathbb{R}^n) : e^{|x|^2} f \in L_2(\mathbb{R}^n) \
bigr\}.$$

Since $b$ is unbounded ($b(x)\to\infty$ as $|x|\to\infty$), $M_b$ is an **unboun
ded** (densely defined) operator. Its domain is dense: $C_c^\infty(\mathbb{R}^n)
\subset D(M_b)$, and $C_c^\infty$ is dense in $L_2$.

## Key Tool: Spectrum = Essential Range

For a multiplication operator $M_b$ (bounded or unbounded, densely defined) on $
L_2(\mathbb{R}^n, \mu)$ with $\mu$ the Lebesgue measure, the **spectrum equals t
he essential range** of $b$:
$$\sigma(M_b) = \operatorname{ess\,ran}(b).$$

Recall the essential range is
$$\operatorname{ess\,ran}(b) = \bigl\{ \lambda\in\mathbb{C} : \forall\,\varepsil
on>0,\; \mu\bigl(\{x : |b(x)-\lambda|<\varepsilon\}\bigr) > 0 \bigr\}.$$

**Proof of this fact (sketch).** $\lambda\notin\operatorname{ess\,ran}(b)$ iff t
here exists $\varepsilon>0$ with $\mu(\{x:|b(x)-\lambda|<\varepsilon\})=0$, i.e.
, $|b(x)-\lambda|\ge\varepsilon$ a.e. Then $(M_b - \lambda I)^{-1} = M_{1/(b-\la
mbda)}$ is a bounded multiplication operator (with $\|M_{1/(b-\lambda)}\|\le 1/\
varepsilon$), so $\lambda\in\rho(M_b)$. Conversely, if $\lambda\in\operatorname{
ess\,ran}(b)$, then for every $\varepsilon>0$ the set where $|b-\lambda|<\vareps
ilon$ has positive measure, so $1/(b-\lambda)$ is not essentially bounded; hence
 $M_{1/(b-\lambda)}$ is not a bounded operator on $L_2$, and $\lambda\notin\rho(
M_b)$. ∎

## Computing the Essential Range of $b(x)=e^{|x|^2}$

**Step 1: $b$ is continuous.** The map $x\mapsto |x|^2$ is continuous, and $t\ma
psto e^t$ is continuous, so $b$ is continuous on $\mathbb{R}^n$.

**Step 2: Essential range of a continuous function = closure of its range.** For
 a continuous function on $\mathbb{R}^n$ (where every nonempty open set has posi
tive Lebesgue measure), the essential range coincides with $\overline{b(\mathbb{
R}^n)}$.

- *Inclusion $\overline{b(\mathbb{R}^n)}\subseteq\operatorname{ess\,ran}(b)$:* T
ake $\lambda\in\overline{b(\mathbb{R}^n)}$. There exist $x_k$ with $b(x_k)\to\la
mbda$. For any $\varepsilon>0$, pick $x_k$ with $|b(x_k)-\lambda|<\varepsilon/2$
. By continuity, there is an open neighborhood $U$ of $x_k$ with $|b(x)-\lambda|
<\varepsilon$ for all $x\in U$. Since $U$ is open and nonempty, $\mu(U)>0$. Henc
e $\lambda\in\operatorname{ess\,ran}(b)$.
- *Inclusion $\operatorname{ess\,ran}(b)\subseteq\overline{b(\mathbb{R}^n)}$:* I
f $\lambda\notin\overline{b(\mathbb{R}^n)}$, then $\operatorname{dist}(\lambda,
b(\mathbb{R}^n))=\delta>0$, so $|b(x)-\lambda|\ge\delta$ for all $x$, giving $\m
u(\{x:|b(x)-\lambda|<\delta/2\})=0$. Thus $\lambda\notin\operatorname{ess\,ran}(
b)$.

**Step 3: Compute the range of $b$.** As $x$ ranges over $\mathbb{R}^n$, $|x|^2$
 ranges over $[0,\infty)$ (achieved at $x=0$ the value $0$, and tending to $\inf
ty$). Therefore
$$b(\mathbb{R}^n) = e^{[0,\infty)} = [1,\infty).$$
This set is **already closed** in $\mathbb{R}$.

## Conclusion

Combining the steps:
$$\sigma(M_b) = \operatorname{ess\,ran}(b) = \overline{b(\mathbb{R}^n)} = \overl
ine{[1,\infty)} = [1,\infty).$$

The spectrum of the multiplication operator $M_b$ on $L_2(\mathbb{R}^n)$ is
$$\boxed{\sigma(M_b) = [1, \infty)}.$$

**Remark on the nature of the spectrum.** Every $\lambda\in[1,\infty)$ lies in t
he **continuous spectrum**: $M_b - \lambda I$ is injective (since $b(x)-\lambda\
neq 0$ a.e. — the zero set $\{x:e^{|x|^2}=\lambda\}=\{x:|x|^2=\ln\lambda\}$ is a
 sphere of measure zero) and has dense range, but its inverse $M_{1/(b-\lambda)}
$ is unbounded, so the range is not all of $L_2$. There is no point spectrum (no
 $L_2$ eigenfunctions) and no residual spectrum.
