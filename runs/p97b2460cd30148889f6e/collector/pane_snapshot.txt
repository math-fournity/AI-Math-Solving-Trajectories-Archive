Looking at this problem, I need to find all odd n in [3,100] where some arrangem
ent of 1,...,n at the vertices of a regular n-gon is "good" w.r.t. every axis of
 symmetry simultaneously.

## Setting Up the Structure

For odd n, each of the n axes of symmetry passes through exactly one vertex and
the midpoint of the opposite edge. Axis k passes through vertex k, and the refle
ction about axis k maps vertex i to vertex 2k−i (mod n). The off-axis pairs for
axis k are {k+j, k−j} for j = 1,...,(n−1)/2.

An arrangement is **good** w.r.t. axis k if all (n−1)/2 comparisons v[k+j] vs v[
k−j] go the same direction.

## The Construction

**Choose a "peak" vertex p.** Assign values so they strictly decrease with circu
lar distance from p:

- Vertex p gets value n.
- Distance class d (vertices p+d and p−d, for d = 1,...,(n−1)/2) gets values n−2
d+1 and n−2d, with the **larger** value (n−2d+1) assigned to **p+d** and the sma
ller (n−2d) to **p−d**.

This gives the arrangement: v[p] = n, v[p+d] = n−2d+1, v[p−d] = n−2d.

## Verification

**Axis p (the peak's own axis):** The pairs are {p+d, p−d} for d = 1,...,(n−1)/2
. We have v[p+d] = n−2d+1 > n−2d = v[p−d] for every d. All comparisons go the sa
me way. ✓

**Axis k ≠ p:** Vertex p is not on axis k, so p lies strictly on one side. WLOG
p = k+m for some 1 ≤ m ≤ (n−1)/2. For each pair {k+j, k−j}:
- k+j is on p's side; k−j is on the opposite side.
- Circular distance from k+j to p is |j−m| (since |j−m| ≤ (n−3)/2 < n/2).
- Circular distance from k−j to p is min(j+m, n−j−m).

**Key inequality:** I claim |j−m| < min(j+m, n−j−m) for all valid j, m.

- |j−m| < j+m: Since j, m ≥ 1, we have j+m ≥ 2 > |j−m| (with equality impossible
 since both are positive). ✓
- |j−m| < n−j−m: If j ≥ m, this becomes j−m < n−j−m ⟺ 2j < n, which holds since
j ≤ (n−1)/2 < n/2. If j < m, this becomes m−j < n−j−m ⟺ 2m < n, which holds sinc
e m ≤ (n−1)/2 < n/2. ✓

Therefore k+j is **strictly closer** to p than k−j, so k+j belongs to a strictly
 smaller distance class and thus has a strictly larger value. The side containin
g p always wins, so all comparisons go the same direction. ✓

## Conclusion

The construction works for **every** odd n ≥ 3. Therefore:

$$S = \{3, 5, 7, 9, \ldots, 99\}$$

This is an arithmetic sequence with first term 3, last term 99, common differenc
e 2, and 49 terms:

$$\sum_{n \in S} n = \frac{49 \cdot (3 + 99)}{2} = 49 \cdot 51 = \boxed{2499}$$
