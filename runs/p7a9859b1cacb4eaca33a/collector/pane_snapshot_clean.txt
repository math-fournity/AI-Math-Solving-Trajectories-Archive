## Proof

**Notation.** Let $X, Y$ be topological spaces. Let $\mathcal{C}(X,Y)$ denote th
e set of continuous maps $X \to Y$, equipped (when relevant) with the compact-op
en topology. We write $|Z|$ for the cardinality of a set $Z$.

### Theorem (Main)

*Let $Y$ be a nonempty topological space. The following are equivalent:*

1. *Every continuous map $f : X \to Y$ is constant.*
2. *For any (hence every) point $x_0 \in X$, the evaluation map*
$$\operatorname{ev}_{x_0} : \mathcal{C}(X,Y) \longrightarrow Y, \qquad f \longma
psto f(x_0)$$
*is a bijection.*
3. *The same evaluation map is a homeomorphism when $\mathcal{C}(X,Y)$ carries t
he compact-open topology.*

**Proof.**

**(1) $\Rightarrow$ (2).** If every continuous $f : X \to Y$ is constant, then $
f \equiv c_y$ for a unique $y = f(x_0)$. Thus $\operatorname{ev}_{x_0}$ maps $c_
y \mapsto y$, which is clearly a bijection: surjective because every constant ma
p $c_y$ is continuous (the preimage of any open $U \subseteq Y$ is either $\empt
yset$ or $X$), and injective because two constant maps agreeing at $x_0$ agree e
verywhere.

**(2) $\Rightarrow$ (1).** If $\operatorname{ev}_{x_0}$ is a bijection, then in
particular it is injective: $f(x_0) = g(x_0) \Rightarrow f = g$ for all continuo
us $f, g$. Taking $g = c_{f(x_0)}$ (the constant map at $f(x_0)$, which is conti
nuous), we get $f(x_0) = c_{f(x_0)}(x_0)$, so $f = c_{f(x_0)}$. Hence every cont
inuous map is constant.

**(1) $\Leftrightarrow$ (3).** It remains to show that when every continuous map
 is constant, $\operatorname{ev}_{x_0}$ is a homeomorphism for the compact-open
topology. The subbasic open sets of $\mathcal{C}(X,Y)$ are
$$, U] = \{ f \in \mathcal{C}(X,Y) : f(K) \subseteq U \}, \qquad K \subseteq X
 \text{ compact},\; U \subseteq Y \text{ open}.$$
Under the identification $f = c_y$ (constant map at $y$), we have $c_y(K) = \{y\
} \subseteq U \iff y \in U$. Therefore
$$, U] = \{ c_y : y \in U \} \;\longleftrightarrow\; U \subseteq Y.$$
So every subbasic open set of $\mathcal{C}(X,Y)$ corresponds exactly to an open
set $U$ of $Y$, and conversely every open $U \subseteq Y$ arises as $[X, U]$ (no
te $X$ is compact in itself when we take $K = X$; if $X$ is not compact, take an
y compact $K \neq \emptyset$, e.g. a single point $\{x_0\}$, and $[\{x_0\}, U]$
gives the same set $\{c_y : y \in U\}$). Hence the compact-open topology on $\ma
thcal{C}(X,Y)$ is exactly the topology of $Y$ transported through $\operatorname
{ev}_{x_0}$, making $\operatorname{ev}_{x_0}$ a homeomorphism. $\blacksquare$

### Corollary (Characterization for all $Y$)

*$\mathcal{C}(X, Y) \cong Y$ (naturally, for every topological space $Y$ with $|
Y| \geq 2$) if and only if $X$ is a single point.*

**Proof.**

*($\Leftarrow$)* If $X = \{*\}$, every map $\{*\} \to Y$ is constant (trivially)
, so by the Theorem, $\mathcal{C}(\{*\}, Y) \cong Y$ for every $Y$.

*($\Rightarrow$)* Suppose $|X| \geq 2$. Take $Y = X$ equipped with the **discret
e** topology. Then every function $X \to Y$ is continuous, so
$$|\mathcal{C}(X, Y)| = |Y|^{|X|} = |X|^{|X|}.$$
By Cantor's theorem, for any set $S$ with $|S| \geq 2$ we have $|S|^{|S|} \geq 2
^{|S|} > |S|$. Hence
$$|\mathcal{C}(X, Y)| = |X|^{|X|} > |X| = |Y|,$$
so no bijection $\mathcal{C}(X, Y) \cong Y$ can exist. Therefore $|X| \geq 2$ is
 impossible, and $X$ must be a single point. $\blacksquare$

### Sufficient conditions for "every continuous map $X \to Y$ is constant"

The Theorem reduces the problem to finding when all continuous maps $X \to Y$ ar
e constant. The following are standard sufficient conditions:

**(a) $X$ is a single point.** Trivial; works for every $Y$. This is the only co
ndition that works *uniformly for all* $Y$, by the Corollary.

**(b) $X$ is connected and $Y$ is totally disconnected.** The image $f(X)$ of a
continuous map from a connected space is connected. In a totally disconnected sp
ace, every connected subset is a single point. Hence $f(X) = \{y\}$ for some $y$
, i.e., $f$ is constant.

**(c) More generally: $X$ is connected and $Y$ has no connected subset with more
 than one point** (equivalently, $Y$ is hereditarily disconnected in the sense t
hat connected components are points). Same argument as (b).

**(d) $X$ is connected and $Y$ is $T_1$ with the discrete topology** (special ca
se of (b)).

### Summary

$$\boxed{\mathcal{C}(X, Y) \cong Y \text{ (naturally, via evaluation) } \iff \te
xt{ every continuous map } X \to Y \text{ is constant.}}$$

The **uniform** condition (holding for *all* $Y$) is:

$$\boxed{X = \{*\} \text{ (a single point)}.}$$

In both cases the bijection is a **homeomorphism** for the compact-open topology
, since the compact-open topology on constant maps reproduces the topology of $Y
$ exactly.
