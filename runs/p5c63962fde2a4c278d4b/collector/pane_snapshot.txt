## Proof

an automorphism of $\overline{\mathbb{Q}}$.**

ce $\sigma(\alpha) \in \overline{\mathbb{Q}}$. Thus $\sigma(\overline{\mathbb{Q}

The image $\sigma(\overline{\mathbb{Q}})$ is algebraically closed (isomorphic to

{\mathbb{Q}}$ is algebraic over $\mathbb{Q}$, hence algebraic over $\sigma(\over
line{\mathbb{Q}}) \supseteq \mathbb{Q}$. But $\sigma(\overline{\mathbb{Q}})$ is
algebraically closed, so any element algebraic over it lies in it. Therefore $\o
verline{\mathbb{Q}} \subseteq \sigma(\overline{\mathbb{Q}})$, giving $\sigma(\ov
erline{\mathbb{Q}}) = \overline{\mathbb{Q}}$. So $\sigma$ is an automorphism of
$\overline{\mathbb{Q}}$ over $\mathbb{Q}$.

The set of $\mathbb{Q}$-morphisms $\overline{\mathbb{Q}} \to \mathbb{C}$ equals
$\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$.

**Step 2: Upper bound — $|\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})|
\leq 2^{\aleph_0}$.**

$\overline{\mathbb{Q}}$ is countable (countably many polynomials over $\mathbb{Q
}$, each with finitely many roots). The set of all functions $\overline{\mathbb{
Q}} \to \overline{\mathbb{Q}}$ has cardinality $\aleph_0^{\aleph_0} = 2^{\aleph_
0}$. Since $\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$ is a subset, $
|\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})| \leq 2^{\aleph_0}$.

**Step 3: Lower bound — $|\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})|
\geq 2^{\aleph_0}$.**

Consider $K = \mathbb{Q}(\sqrt{p} : p \text{ prime}) \subseteq \overline{\mathbb
{Q}}$. For distinct primes $p_1, \ldots, p_n$, the classes of $p_1, \ldots, p_n$

hbb{Q}^*)^2$ (a standard result in algebraic number theory). Hence $[\mathbb{Q}(
\sqrt{p_1}, \ldots, \sqrt{p_n}) : \mathbb{Q}] = 2^n$ and $\operatorname{Gal}(\ma
thbb{Q}(\sqrt{p_1}, \ldots, \sqrt{p_n})/\mathbb{Q}) \cong (\mathbb{Z}/2\mathbb{Z
})^n$.

The extension $K/\mathbb{Q}$ is Galois with $\operatorname{Gal}(K/\mathbb{Q}) =
\varprojlim_{S} (\mathbb{Z}/2\mathbb{Z})^S$ (over finite sets $S$ of primes, wit
h projection maps). This inverse limit is $\prod_{p \text{ prime}} \mathbb{Z}/2\
mathbb{Z}$, since a compatible family is determined by independently choosing $\
sqrt{p} \mapsto \pm\sqrt{p}$ for each prime $p$.

Since there are $\aleph_0$ primes, $|\operatorname{Gal}(K/\mathbb{Q})| = 2^{\ale
ph_0}$.

**Step 4: Extending automorphisms.**

Every $\sigma \in \operatorname{Gal}(K/\mathbb{Q})$ extends to $\tilde{\sigma} \
in \operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$. This follows by Zorn's
 lemma: the set of extensions of $\sigma$ to intermediate fields $K \subseteq L
\subseteq \overline{\mathbb{Q}}$, ordered by extension, has a maximal element; s
ince $\overline{\mathbb{Q}}$ is algebraically closed, any partial extension to a
 proper subfield can be further extended to include any additional algebraic ele
ment, so the maximal element is defined on all of $\overline{\mathbb{Q}}$.

Thus the restriction map $\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q}) \
to \operatorname{Gal}(K/\mathbb{Q})$ is surjective, giving $|\operatorname{Gal}(
\overline{\mathbb{Q}}/\mathbb{Q})| \geq |\operatorname{Gal}(K/\mathbb{Q})| = 2^{
\aleph_0}$.

**Conclusion:**

$$|\operatorname{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})| = 2^{\aleph_0}.$$

The cardinality of the set of $\mathbb{Q}$-morphisms from $\overline{\mathbb{Q}}
$ to $\mathbb{C}$ is $\boxed{2^{\aleph_0}}$ (the cardinality of the continuum).
