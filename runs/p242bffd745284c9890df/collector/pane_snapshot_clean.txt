## Proof

The Cosine Integral is defined as
$$\mathrm{Ci}(x) = -\int_x^{\infty}\frac{\cos t}{t}\,dt.$$

**Key identity.** Using $\mathrm{Ci}(x) = \gamma + \ln x + \displaystyle\int_0^x
 \frac{\cos t - 1}{t}\,dt$, where $\gamma$ is the Euler–Mascheroni constant. Thi
s follows from splitting
$$-\int_x^\infty \frac{\cos t}{t}\,dt = -\int_x^1 \frac{\cos t}{t}\,dt - \int_1^
\infty \frac{\cos t}{t}\,dt$$
and rewriting $-\int_x^1 \frac{\cos t}{t}\,dt = -\int_x^1 \frac{1}{t}\,dt - \int
_x^1 \frac{\cos t - 1}{t}\,dt = \ln x + \int_0^1\frac{\cos t - 1}{t}\,dt - \int_
0^x \frac{\cos t-1}{t}\,dt$, with the constant $\gamma = -\int_1^\infty \frac{\c
os t}{t}\,dt + \int_0^1 \frac{\cos t - 1}{t}\,dt$.

**Series expansion.** Since $\cos t - 1 = \sum_{n=1}^{\infty}\frac{(-1)^n t^{2n}
}{(2n)!}$, dividing by $t$ and integrating termwise (valid near $0$ by uniform c
onvergence on bounded intervals):
$$\int_0^x \frac{\cos t - 1}{t}\,dt = \sum_{n=1}^{\infty}\frac{(-1)^n x^{2n}}{2n
\,(2n)!}.$$
Hence
$$\mathrm{Ci}(x) = \gamma + \ln x + \sum_{n=1}^{\infty}\frac{(-1)^n x^{2n}}{2n\,
(2n)!}.$$

**Apply to the limit.** For $x \to 0^+$ (the natural domain of $\mathrm{Ci}$),
$$\mathrm{Ci}(x) - \mathrm{Ci}(3x) = \bigl(\gamma + \ln x\bigr) - \bigl(\gamma +
 \ln(3x)\bigr) + \sum_{n=1}^{\infty}\frac{(-1)^n\bigl(x^{2n} - (3x)^{2n}\bigr)}{
2n\,(2n)!}.$$

The logarithmic part:
$$\ln x - \ln(3x) = \ln x - \ln 3 - \ln x = -\ln 3.$$

The series part: each term $\frac{(-1)^n(x^{2n} - (3x)^{2n})}{2n(2n)!}$ is $O(x^
{2n})$, so the entire sum is $O(x^2) \to 0$ as $x \to 0$.

Therefore
$$\lim_{x\to 0}\bigl(\mathrm{Ci}(x) - \mathrm{Ci}(3x)\bigr) = -\ln 3 + 0 = \boxe
d{-\ln 3}.$$
