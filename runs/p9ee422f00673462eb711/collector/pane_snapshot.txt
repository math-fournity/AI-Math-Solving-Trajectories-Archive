## Proof

Let $\Omega = \omega_1$ be the first uncountable ordinal with the order topology
. For each limit ordinal $\lambda < \omega_1$, let $U_\lambda$ be an open neighb
orhood of $\lambda$. Set
$$C := [0, \omega_1) \setminus \bigcup\{U_\lambda : \lambda < \omega_1 \text{ is
 limit}\}.$$
We prove that **$C$ is finite** (cardinality $< \aleph_0$).

### Step 1: $C$ is countable (Fodor's Lemma)

For each limit ordinal $\lambda < \omega_1$, since $U_\lambda$ is an open neighb
orhood of $\lambda$ in the order topology and $\lambda$ is a limit, there exists
 $\beta_\lambda < \lambda$ such that
$$(\beta_\lambda, \lambda] \subseteq U_\lambda.$$
(The basic open neighborhoods of a limit ordinal $\lambda$ are of the form $(\be
ta, \lambda+1) = (\beta, \lambda]$.)

The set $S$ of limit ordinals below $\omega_1$ is **stationary** (indeed, club)
in $\omega_1$. Define $f: S \to \omega_1$ by $f(\lambda) = \beta_\lambda$. This
is **regressive**: $f(\lambda) = \beta_\lambda < \lambda$ for all $\lambda \in S
$.

By **Fodor's Pressing-Down Lemma**, there exists a stationary (hence unbounded)
subset $T \subseteq S$ and a fixed ordinal $\beta < \omega_1$ such that $f(\lamb
da) = \beta$ for all $\lambda \in T$.

Since $T$ is unbounded in $\omega_1$:
$$\bigcup_{\lambda \in T} U_\lambda \supseteq \bigcup_{\lambda \in T} (\beta, \l
ambda] = (\beta, \omega_1).$$
Therefore $C \subseteq [0, \beta]$. Since $\beta < \omega_1$ is a countable ordi
nal, $[0, \beta]$ is countable, so **$C$ is countable**.

### Step 2: $C$ is finite

Suppose for contradiction that $C$ is infinite. Since $C$ is countable, $\delta_
0 := \sup C < \omega_1$.

**Claim:** If $C_n \subseteq C$ is infinite with $\delta_n := \sup C_n$, then $\
delta_n$ is a **successor** ordinal and $\delta_n \in C_n$.

*Proof of claim:* If $\delta_n$ were a **limit** ordinal, then $C_n$ is cofinal
in $\delta_n$. Since $U_{\delta_n} \supseteq (\gamma, \delta_n]$ for some $\gamm
a < \delta_n$, and $C_n$ is cofinal in $\delta_n$, there exists $c \in C_n$ with

bda$. But $c \in C_n \subseteq C$ means $c \notin \bigcup U_\lambda$ — **contrad
iction**. So $\delta_n$ is a successor, say $\delta_n = \delta_n' + 1$. Since $\
sup C_n = \delta_n$ and $C_n \subseteq [0, \delta_n]$, we must have $\delta_n \i
n C_n$ (otherwise $C_n \subseteq [0, \delta_n']$ and $\sup C_n \leq \delta_n' <
\delta_n$). $\square$

Now construct a sequence iteratively. Set $C_0 = C$, $\delta_0 = \sup C_0$. By t
he claim, $\delta_0$ is a successor and $\delta_0 \in C_0$. Set $C_1 = C_0 \setm

again: $\delta_1$ is a successor, $\delta_1 \in C_1$. Set $C_2 = C_1 \setminus \
{\delta_1\}$, and so on.

This produces an **infinite strictly decreasing sequence** of ordinals:
$$\delta_0 > \delta_1 > \delta_2 > \cdots$$
This contradicts the **well-foundedness** of the ordinal ordering (there is no i
nfinite strictly descending sequence of ordinals). Therefore, $C$ must be **fini
