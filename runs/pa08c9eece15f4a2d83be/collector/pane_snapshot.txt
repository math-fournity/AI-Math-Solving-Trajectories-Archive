## Solution

**Setup.** Write the surface as $z = f(x,y)$, and let $P = (x_0, y_0, z_0)$ be a
 point on $S$. Denote $p = f_x(x_0,y_0)$, $q = f_y(x_0,y_0)$. The tangent plane
at $P$ is

$$p\,x + q\,y - z = p\,x_0 + q\,y_0 - z_0.$$

Let $D = p\,x_0 + q\,y_0 - z_0$. The three axis intercepts are

$$A = \frac{D}{p},\qquad B = \frac{D}{q},\qquad C = -D,$$

giving the three points $(A,0,0)$, $(0,B,0)$, $(0,0,C)$.

**Orthocenter of an intercept triangle.** For a triangle with vertices $(a,0,0)$
, $(0,b,0)$, $(0,0,c)$, the orthocenter $H=(h_x,h_y,h_z)$ satisfies the altitude
 conditions:

$$(H-(a,0,0))\cdot(0,b,-c)=0 \;\Longrightarrow\; b\,h_y = c\,h_z,$$
$$(H-(0,b,0))\cdot(a,0,-c)=0 \;\Longrightarrow\; a\,h_x = c\,h_z,$$
$$(H-(0,0,c))\cdot(a,-b,0)=0 \;\Longrightarrow\; a\,h_x = b\,h_y.$$

Hence $a\,h_x = b\,h_y = c\,h_z =: t$, so $h_x = t/a$, $h_y = t/b$, $h_z = t/c$.
 Since $H$ lies in the plane $x/a+y/b+z/c=1$:

$$\frac{t}{a^2}+\frac{t}{b^2}+\frac{t}{c^2}=1 \;\Longrightarrow\; t = \frac{1}{1
/a^2+1/b^2+1/c^2}.$$

**Imposing the condition $H = P$.** Setting $h_x=x_0$, $h_y=y_0$, $h_z=z_0$ give
s $a = t/x_0$, $b = t/y_0$, $c = t/z_0$, and

$$t = \frac{1}{x_0^2/t^2 + y_0^2/t^2 + z_0^2/t^2} = \frac{t^2}{x_0^2+y_0^2+z_0^2
}.$$

So $t = x_0^2+y_0^2+z_0^2$ (nonzero on $S$), and

$$a = \frac{x_0^2+y_0^2+z_0^2}{x_0},\quad b = \frac{x_0^2+y_0^2+z_0^2}{y_0},\qua
d c = \frac{x_0^2+y_0^2+z_0^2}{z_0}.$$

**Deriving the PDE.** With $a=D/p$, $b=D/q$, $c=-D$ and $\Sigma := x_0^2+y_0^2+z
_0^2$:

$$\frac{D}{p} = \frac{\Sigma}{x_0},\quad \frac{D}{q} = \frac{\Sigma}{y_0},\quad
-D = \frac{\Sigma}{z_0}.$$

From the third, $D = -\Sigma/z_0$. Substituting into the first two:

$$p = -\frac{x_0}{z_0},\qquad q = -\frac{y_0}{z_0}.$$

Dropping subscripts, the surface satisfies the PDE system

$$\frac{\partial z}{\partial x} = -\frac{x}{z},\qquad \frac{\partial z}{\partial
 y} = -\frac{y}{z}.$$

**Solving the PDE.** From $z\,z_x = -x$: $\tfrac{1}{2}z^2 = -\tfrac{1}{2}x^2 + g
(y)$, i.e. $x^2+z^2 = 2g(y)$. From $z\,z_y = -y$: $y^2+z^2 = 2h(x)$. Subtracting
: $x^2 - y^2 = 2g(y) - 2h(x)$, i.e. $x^2 + 2h(x) = y^2 + 2g(y) = 2k$ (constant).
 Hence $g(y) = k - y^2/2$ and

$$z^2 = 2g(y) - x^2 = 2k - y^2 - x^2 \;\Longrightarrow\; x^2 + y^2 + z^2 = 2k.$$

The surface is a sphere centered at the origin.

**Applying the point $(1,1,1)$.** Substituting: $1+1+1 = 2k \Rightarrow 2k = 3$.

**Verification.** For the sphere $x^2+y^2+z^2 = R^2$ with $R^2=3$, the tangent p
lane at $P=(x_0,y_0,z_0)$ is $x_0 x + y_0 y + z_0 z = R^2$, with intercepts $a=R
^2/x_0$, $b=R^2/y_0$, $c=R^2/z_0$. Then

$$t = \frac{1}{x_0^2/R^4 + y_0^2/R^4 + z_0^2/R^4} = \frac{R^4}{R^2} = R^2,$$

and $H = (t/a, t/b, t/c) = (x_0, y_0, z_0) = P$. ✓ The condition holds at every
point.

$$\boxed{x^2 + y^2 + z^2 = 3}$$
