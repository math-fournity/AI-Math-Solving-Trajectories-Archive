## Step 1: Characterize $n$-well numbers

**Claim:** $a$ is $n$-well if and only if $a \in S_n := \{\lfloor n/k \rfloor :
1 \leq k \leq n\}$.

**Proof:** Let $q = \lfloor n/a \rfloor$. The condition $\lfloor n/q \rfloor = a
$ means $a$ is in the image of $k \mapsto \lfloor n/k \rfloor$ (with $k = q$), s
o $a \in S_n$. Conversely, if $a = \lfloor n/k \rfloor$ for some $k$, then $n/(a
+1) < k \leq n/a$. Setting $q = \lfloor n/a \rfloor$, we have $k \leq q$ (since
$k \leq n/a$ and $k$ is integer) and $q \geq k > n/(a+1)$, so $n/(a+1) < q \leq
n/a$, giving $\lfloor n/q \rfloor = a$. ∎

So $f(n) = |S_n|$ = number of distinct values of $\lfloor n/k \rfloor$ for $1 \l
eq k \leq n$.

## Step 2: Formula for $f(n)$

Let $m = \lfloor\sqrt{n}\rfloor$, so $m^2 \leq n \leq m^2+2m$.

- **Values $\{1, \ldots, m\}$ all appear in $S_n$:** For $v \leq m$, the interva
l $(n/(v+1),\, n/v]$ has length $n/(v(v+1)) \geq m^2/((m-1)m) > 1$, so it contai
ns an integer. Also $m$ appears since $q = \lfloor n/m \rfloor > n/(m+1)$ (verif
ied: $q - n/(m+1) \geq 1/(m(m+1)) > 0$).

- **Values $\lfloor n/k \rfloor$ for $k=1,\ldots,m$ are $m$ distinct values, all
 $\geq m$:** For $k < k+1 \leq m$, we have $n/k - n/(k+1) = n/(k(k+1)) > 1$, so
$\lfloor n/k \rfloor > \lfloor n/(k+1) \rfloor$.

**Case 1:** $m^2 \leq n < m^2+m$. Then $\lfloor n/m \rfloor = m$, so the smalles
t of the $m$ large values equals $m$. Values $> m$: $m-1$. Values $\leq m$: $m$.
 Total: $f(n) = 2m-1$.

**Case 2:** $m^2+m \leq n \leq m^2+2m$. Then $\lfloor n/m \rfloor \geq m+1$, so
all $m$ large values exceed $m$. Values $> m$: $m$. Values $\leq m$: $m$. Total:
 $f(n) = 2m$.

## Step 3: Compute the sum

For each $m \geq 1$, the range $n \in [m^2,\, m^2+2m]$ splits as:
- $[m^2,\, m^2+m-1]$: $m$ values with $f = 2m-1$
- $[m^2+m,\, m^2+2m]$: $m+1$ values with $f = 2m$

Contribution per $m$:
$$S_m = m(2m-1) + (m+1)(2m) = 2m^2 - m + 2m^2 + 2m = 4m^2 + m$$

Since $99^2 = 9801$ and $100^2 = 10000$, the ranges for $m = 1, \ldots, 99$ cove

$$\sum_{n=1}^{9999} f(n) = \sum_{m=1}^{99}(4m^2 + m) = 4\sum_{m=1}^{99}m^2 + \su
m_{m=1}^{99}m$$

$$\sum_{m=1}^{99} m = \frac{99 \cdot 100}{2} = 4{,}950$$
