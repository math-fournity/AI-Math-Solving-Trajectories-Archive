## Proof: All harmonic functions on $\mathbb{R}^n$ depending only on $\rho$

**Setup.** Let $u$ be harmonic on $\mathbb{R}^n$ and depend only on $\rho = |x|$
, so $u(x) = f(\rho)$ for some function $f$. We seek all such $f$.

**Step 1: Compute the Laplacian of a radial function.**

For a radial function $u(x) = f(\rho)$, $\rho = |x|$, we compute $\Delta u = \su
m_{i=1}^n \frac{\partial^2 u}{\partial x_i^2}$.

Since $\frac{\partial \rho}{\partial x_i} = \frac{x_i}{\rho}$, we have
$$\frac{\partial u}{\partial x_i} = f'(\rho)\frac{x_i}{\rho},$$
$$\frac{\partial^2 u}{\partial x_i^2} = f''(\rho)\frac{x_i^2}{\rho^2} + f'(\rho)
\left(\frac{1}{\rho} - \frac{x_i^2}{\rho^3}\right).$$

Summing over $i = 1, \dots, n$ and using $\sum x_i^2 = \rho^2$:
$$\Delta u = f''(\rho)\frac{\rho^2}{\rho^2} + f'(\rho)\left(\frac{n}{\rho} - \fr
ac{\rho^2}{\rho^3}\right) = f''(\rho) + \frac{n-1}{\rho}f'(\rho).$$

**Step 2: Solve the ODE $\Delta u = 0$.**

The harmonicity condition becomes the ODE (for $\rho > 0$):
$$f''(\rho) + \frac{n-1}{\rho}f'(\rho) = 0.$$

Set $g(\rho) = f'(\rho)$. Then $g' + \frac{n-1}{\rho}g = 0$, i.e., $\frac{g'}{g}
 = -\frac{n-1}{\rho}$. Integrating:
$$g(\rho) = C\,\rho^{-(n-1)},$$
for a constant $C$. Hence $f'(\rho) = C\,\rho^{-(n-1)}$, and integrating again:

- **Case $n = 1$:** $f'(\rho) = C$, so $f(\rho) = C\rho + D$, i.e., $u(x) = C|x|
 + D$.
- **Case $n = 2$:** $f'(\rho) = C/\rho$, so $f(\rho) = C\ln\rho + D$.
- **Case $n \geq 3$:** $f'(\rho) = C\,\rho^{-(n-1)}$, so $f(\rho) = \frac{C}{2-n
}\,\rho^{2-n} + D$. Relabeling the constant, $f(\rho) = A\,\rho^{2-n} + B$.

These are the general radial functions that are harmonic on $\mathbb{R}^n \setmi
nus \{0\}$.

**Step 3: Enforce harmonicity on all of $\mathbb{R}^n$ (including the origin).**

A harmonic function on $\mathbb{R}^n$ must be $C^2$ (in fact $C^\infty$) everywh
ere, including at the origin. We check which of the above solutions remain smoot
h at $\rho = 0$:

- **$n = 1$:** $u(x) = C|x| + D$. The function $|x|$ is not differentiable at $x
 = 0$. For $u$ to be $C^2$ at the origin, we need $C = 0$, giving $u = D$ (const
ant).
- **$n = 2$:** $u(x) = C\ln|x| + D$. As $\rho \to 0$, $\ln\rho \to -\infty$, so
$u$ is unbounded and not even defined at the origin. We need $C = 0$, giving $u
= D$ (constant).
- **$n \geq 3$:** $u(x) = A\,\rho^{2-n} + B$. As $\rho \to 0$, $\rho^{2-n} \to \
infty$ (since $2-n < 0$), so $u$ blows up at the origin. We need $A = 0$, giving
 $u = B$ (constant).

**Conclusion.** In every dimension, the requirement that $u$ be harmonic (hence
$C^2$) on all of $\mathbb{R}^n$, including the origin, forces the singular coeff
icient to vanish. The only harmonic functions on $\mathbb{R}^n$ depending solely
 on $\rho = |x|$ are the **constant functions**:
$$\boxed{u(x) = \text{constant}.}$$

*Remark.* If the domain were $\mathbb{R}^n \setminus \{0\}$ instead of all of $\
mathbb{R}^n$, the full family of radial harmonic functions would be $u = A + B\,
\rho^{2-n}$ for $n \geq 3$, $u = A + B\ln\rho$ for $n = 2$, and $u = A + B\rho$
for $n = 1$ (the latter being $A + B|x|$, harmonic on $\mathbb{R}\setminus\{0\}$
). The singularity at the origin is precisely what excludes these non-constant s
olutions when the domain is all of $\mathbb{R}^n$.
