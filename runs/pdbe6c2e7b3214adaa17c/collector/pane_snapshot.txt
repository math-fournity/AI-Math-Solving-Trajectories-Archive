## Solution

The statement is **false**. I will exhibit an explicit counterexample (in fact,
an infinite family of them).

### Counterexample: $p = 3,\ m = 1$

Here $p = 3 \geq 3$ is prime, and $m = 1$ divides $p - 1 = 2$. We have $\frac{p-
1}{m} = 2$, so the sum is

$$S = \sum_{t=0}^{1}\sum_{s=0}^{1}\binom{t}{s}.$$

Computing each term (using the standard convention $\binom{a}{b}=0$ for $b>a$):

| $t$ | $s$ | $\binom{t}{s}$ |
|-----|-----|----------------|
| 0 | 0 | $\binom{0}{0}=1$ |
| 0 | 1 | $\binom{0}{1}=0$ |
| 1 | 0 | $\binom{1}{0}=1$ |
| 1 | 1 | $\binom{1}{1}=1$ |

$$S = 1 + 0 + 1 + 1 = 3 = p.$$

Since $p = 3$ divides $S = 3$, the claimed statement fails.

### An infinite family of counterexamples: $m = 1$, any prime $p \geq 3$

In fact the failure is not isolated. Setting $m = 1$ (which always divides $p-1$
), we get $\frac{p-1}{m} = p-1$, and

$$S = \sum_{t=0}^{p-2}\sum_{s=0}^{p-2}\binom{t}{s}.$$

For each fixed $t \leq p-2$, every term $\binom{t}{s}$ with $s > t$ vanishes, so
 the inner sum is the full binomial sum:

$$\sum_{s=0}^{p-2}\binom{t}{s} = \sum_{s=0}^{t}\binom{t}{s} = 2^{t}.$$

Therefore

$$S = \sum_{t=0}^{p-2}2^{t} = 2^{p-1} - 1.$$

By **Fermat's little theorem**, since $\gcd(2,p)=1$ for any odd prime $p$,

$$2^{p-1} \equiv 1 \pmod{p},$$

so

$$S = 2^{p-1} - 1 \equiv 0 \pmod{p}.$$

Thus $p \mid S$ for **every** odd prime $p$ when $m=1$. This yields counterexamp
les for all primes $p \geq 3$:

- $p=3$: $S = 2^{2}-1 = 3$, and $3 \mid 3$. ✓
- $p=5$: $S = 2^{4}-1 = 15$, and $5 \mid 15$. ✓
- $p=7$: $S = 2^{6}-1 = 63$, and $7 \mid 63$. ✓

and so on for every odd prime.

### Conclusion

The assertion that "$p$ does not divide the sum" is **not true**. The choice $m
= 1$ (which is always a valid divisor of $p-1$) reduces the double sum to $2^{p-
1}-1$, which is divisible by $p$ by Fermat's little theorem. The single countere
xample $p=3,\ m=1$ already disproves the universal claim.
