**Step 2. Reciprocal recursion.** Set $y_n = 1/x_n$. Then
$$
y_n = \frac{1}{x_{n-1}(1-x_{n-1})} = \frac{y_{n-1}^2}{y_{n-1}-1}.
$$
Polynomial division gives $\dfrac{y_{n-1}^2}{y_{n-1}-1} = y_{n-1}+1+\dfrac{1}{y_
{n-1}-1}$, hence
$$
y_n = y_{n-1}+1+\frac{1}{y_{n-1}-1}. \tag{1}
$$
Since $x_{n-1}<1$, we have $y_{n-1}>1$, so the last term is positive and $y_n>y_
{n-1}+1$. In particular $y_n\to+\infty$ and $y_n\ge n + (y_1-1)$, so $y_n\to\inf
ty$ at least linearly.

**Step 3. Leading order: $y_n\sim n$.** From (1), $y_n-y_{n-1}=1+\frac{1}{y_{n-1
}-1}\to 1$, so by Stolz–Cesàro (or summation), $y_n/n\to 1$. Thus $x_n\sim 1/n$.

**Step 4. Next order via $z_n:=y_n-n$.** Subtracting $n-(n-1)=1$ from (1):
$$
z_n = z_{n-1} + \frac{1}{y_{n-1}-1} = z_{n-1} + \frac{1}{n-2+z_{n-1}}, \qquad n\

$$
z_n = \ln n + O(1), \qquad\text{i.e.}\qquad y_n = n + \ln n + O(1). \tag{3}

**Step 5. Extract the limit.** From (3),
$$
x_n = \frac{1}{n+\ln n+O(1)} = \frac{1}{n}\cdot\frac{1}{1+\frac{\ln n+O(1)}{n}}.

$$
n^2 x_n = n - \ln n + O(1).
$$
Hence
$$
n^2 x_n - n = -\ln n + O(1),
$$
and finally
$$
\frac{n^2 x_n - n}{\ln n} = \frac{-\ln n + O(1)}{\ln n} \xrightarrow[n\to\infty]

$$
