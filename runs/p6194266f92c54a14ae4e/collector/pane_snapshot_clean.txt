Looking at this problem, I need to find the maximum number of ordered triples $(
x,y,z) \in S^3$ with $\frac{x^2+y^2+z^2}{xy+yz+zx} = 2$, over all choices of $S
\subseteq \{1,\ldots,10000\}$ with $|S|=100$.

## Setting Up the Equation

The condition $\frac{x^2+y^2+z^2}{xy+yz+zx}=2$ gives:
$$x^2 + y^2 + z^2 = 2xy + 2yz + 2zx$$

Treating this as a quadratic in $x$:
$$x^2 - 2(y+z)x + (y-z)^2 = 0$$

By the quadratic formula:
$$x = (y+z) \pm 2\sqrt{yz}$$

So $x = (\sqrt{y}+\sqrt{z})^2$ or $x = (\sqrt{y}-\sqrt{z})^2$.

**For $x$ to be a positive integer, $yz$ must be a perfect square.** Since $y,z$
 are integers, $\sqrt{yz}$ is either an integer or irrational — so $yz$ being a
perfect square is necessary.

## Group Structure by Squarefree Part

Write each $n \in S$ as $n = a \cdot k^2$ where $a$ is squarefree (the "squarefr
ee part"). Two numbers $y = a\,m^2$ and $z = a\,n^2$ have the same squarefree pa
rt $a$ if and only if $yz = a^2 m^2 n^2$ is a perfect square.

When $y = a\,m^2$ and $z = a\,n^2$ (same group), the solutions are:
- $x = a(m+n)^2$ — same group
- $x = a(m-n)^2$ — same group (valid only if $m \neq n$, since $m=n$ gives $x=0$
)

**All three elements $x, y, z$ must belong to the same squarefree group.** Cross
-group pairs yield irrational $x$, contributing nothing.

## Optimal Strategy: Concentrate in One Group

The count of valid ordered triples is the sum over groups of within-group contri
butions. By convexity, concentrating all 100 elements in a single group maximize
s the total.

The group with squarefree part $a$ contains $\lfloor 100/\sqrt{a}\,\rfloor$ elem
ents up to 10000. To fit 100 elements:
$$\left\lfloor \frac{100}{\sqrt{a}} \right\rfloor \geq 100 \implies \sqrt{a} \le
q 1 \implies a = 1$$

**Only the perfect squares group ($a=1$) has $\geq 100$ elements**, namely $\{1,
 4, 9, \ldots, 10000\}$ — exactly 100 elements. This is the unique optimal choic
e: $S = \{k^2 : 1 \leq k \leq 100\}$.

## Counting the Triples

Set $K = \{1, 2, \ldots, 100\}$ (the multipliers). For each ordered pair $(m, n)
 \in K^2$, the valid values of $j$ (where $x = j^2$) are:

| Condition | Valid $x$ values | Count |
|-----------|-----------------|-------|
| $m+n \leq 100$, $m \neq n$ | $(m+n)^2$ and $(m-n)^2$ | 2 |
| $m+n \leq 100$, $m = n$ | $(2m)^2$ only | 1 |
| $m+n > 100$, $m \neq n$ | $(m-n)^2$ only | 1 |
| $m+n > 100$, $m = n$ | none | 0 |

**Counting pairs:**
- $m = n$, $2m \leq 100$ (i.e., $m \leq 50$): **50 pairs**
- $m = n$, $2m > 100$ (i.e., $m > 50$): **50 pairs**
- $m \neq n$, $m+n \leq 100$: total $m+n\leq 100$ pairs $= \sum_{m=1}^{99}(100-m
) = 4950$, minus 50 diagonal $= \mathbf{4900}$
- $m \neq n$, $m+n > 100$: $9900 - 4900 = \mathbf{5000}$

**Total ordered triples:**
$$4900 \times 2 + 50 \times 1 + 5000 \times 1 + 50 \times 0 = 9800 + 50 + 5000 =
 \boxed{14850}$$

## Verification with Small Case

For $S = \{1, 4, 9\}$ ($n=3$), the formula $\frac{3n(n-1)}{2} = 9$. Direct enume
ration of all 9 ordered pairs $(m,n) \in \{1,2,3\}^2$ confirms exactly 9 valid t
riples, matching the formula.

## Conclusion

The maximum possible number of containers with Stability Index exactly 2 is $\bo
xed{14850}$, achieved uniquely by $S = \{1, 4, 9, 16, \ldots, 10000\}$ (the firs
t 100 perfect squares).
