# Solution

## Problem

Find the sum of all $n \in \{1,2,\ldots,10\}$ such that $n \notin S$, where $S$
is the set of positive integers $n$ for which there exist $k \geq 2$ and positiv
e rationals $a_1,\ldots,a_k$ with $a_1+\cdots+a_k = a_1\cdots a_k = n$.

## Key Tool: AM-GM Bound

For positive reals with sum $n$ and $k$ terms, the product is at most $\left(\fr
ac{n}{k}\right)^k$. So if $\left(\frac{n}{k}\right)^k < n$, no solution exists f
or that $k$.

## Checking each $n$

**$n=1$:** $k=2$: $a+b=1, ab=1 \Rightarrow$ discriminant $1-4<0$. For $k\geq 3$:
 $(1/k)^k < 1$. **Not in $S$.**

**$n=2$:** $k=2$: discriminant $4-8<0$. For $k\geq 3$: $(2/k)^k \leq (2/3)^3 = 8
/27 < 2$. **Not in $S$.**

**$n=3$:** $k=2$: discriminant $9-12<0$. For $k\geq 3$: $(3/3)^3 = 1 < 3$. **Not
 in $S$.**

**$n=4$:** $k=2$: $a+b=4, ab=4 \Rightarrow a=b=2$. ✓ **In $S$.**

**$n=5$:** $k=2$: discriminant $25-20=5$, not a perfect square (roots irrational
). For $k=3$: $(5/3)^3 = 125/27 \approx 4.63 < 5$. For $k\geq 4$: even smaller.
**Not in $S$.**

**$n=6$:** $k=3$, set $a=1$: $b+c=5, bc=6 \Rightarrow$ discriminant $25-24=1$, s
o $b=3, c=2$. Check: $1+2+3=6$, $1\cdot2\cdot3=6$. ✓ **In $S$.**

**$n=7$:** $k=3$, set $a=\tfrac{7}{6}$: $b+c=\tfrac{35}{6}, bc=6 \Rightarrow$ di
scriminant $\tfrac{1225}{36}-24 = \tfrac{361}{36}$, so $b=\tfrac{9}{2}, c=\tfrac
{4}{3}$. Check: $\tfrac{7}{6}+\tfrac{9}{2}+\tfrac{4}{3} = \tfrac{7+27+8}{6}=7$,
$\tfrac{7}{6}\cdot\tfrac{9}{2}\cdot\tfrac{4}{3}=\tfrac{252}{36}=7$. ✓ **In $S$.*
*

**$n=8$:** $k=4$, set $a=b=1$: $c+d=6, cd=8 \Rightarrow$ discriminant $36-32=4$,
 so $c=4, d=2$. Check: $1+1+2+4=8$, $1\cdot1\cdot2\cdot4=8$. ✓ **In $S$.**

**$n=9$:** $k=3$, set $a=\tfrac{1}{2}$: $b+c=\tfrac{17}{2}, bc=18 \Rightarrow$ d
iscriminant $\tfrac{289}{4}-72=\tfrac{1}{4}$, so $b=\tfrac{9}{2}, c=4$. Check: $
\tfrac{1}{2}+\tfrac{9}{2}+4=9$, $\tfrac{1}{2}\cdot\tfrac{9}{2}\cdot4=9$. ✓ **In
$S$.**

**$n=10$:** $k=5$, set $a=b=c=1$: $d+e=7, de=10 \Rightarrow$ discriminant $49-40
=9$, so $d=5, e=2$. Check: $1+1+1+2+5=10$, $1\cdot1\cdot1\cdot2\cdot5=10$. ✓ **I
n $S$.**

## Answer

The values not in $S$ are $\{1, 2, 3, 5\}$.

$$1 + 2 + 3 + 5 = \boxed{11}$$
