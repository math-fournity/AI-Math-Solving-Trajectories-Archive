## Solution

We evaluate
$$I = \int_0^\infty \frac{x^{1/2}}{x^2+4}\,dx$$
using a keyhole contour $\mathcal{C}$ encircling the branch cut along the positi
ve real axis, with the branch of $z^{1/2}$ defined by $0 < \arg z < 2\pi$ (so th
e cut is on $[0,\infty)$).

Consider
$$f(z) = \frac{z^{1/2}}{z^2+4}.$$

**Poles.** The denominator vanishes at $z = \pm 2i$. Both lie inside the keyhole
 contour. With our branch choice:
- $z = 2i = 2e^{i\pi/2}$, so $z^{1/2} = \sqrt{2}\,e^{i\pi/4} = 1+i$.
- $z = -2i = 2e^{i3\pi/2}$, so $z^{1/2} = \sqrt{2}\,e^{i3\pi/4} = -1+i$.

**Residues.** Since $z^2+4 = (z-2i)(z+2i)$, the residue at each simple pole $z_0
$ is $\dfrac{z_0^{1/2}}{2z_0}$:

$$\operatorname{Res}_{z=2i} f = \frac{1+i}{2\cdot 2i} = \frac{1+i}{4i} = \frac{(
1+i)(-i)}{4} = \frac{1-i}{4},$$

$$\operatorname{Res}_{z=-2i} f = \frac{-1+i}{2\cdot(-2i)} = \frac{-1+i}{-4i} = \
frac{(-1+i)(i)}{4} = \frac{-1-i}{4}.$$

Sum:
$$\sum \operatorname{Res} = \frac{1-i}{4} + \frac{-1-i}{4} = \frac{-2i}{4} = -\f
rac{i}{2}.$$

**Residue theorem.** The large and small circular arcs vanish (the integrand dec
ays as $|z|^{-3/2}$ on the large arc and as $|z|^{1/2}\cdot|z|^{-2}\cdot|dz|\sim
|z|^{-1/2}$ with shrinking radius on the small arc). Hence the entire contour in
tegral comes from the two straight pieces along the cut:

- **Upper edge** ($\arg z = 0$, $x:0\to\infty$): $z^{1/2}=\sqrt{x}$, contributio
n $= \displaystyle\int_0^\infty \frac{\sqrt{x}}{x^2+4}\,dx = I$.
- **Lower edge** ($\arg z = 2\pi$, $x:\infty\to 0$): $z^{1/2}=\sqrt{x}\,e^{i\pi}
=-\sqrt{x}$, $dz=dx$, contribution $= \displaystyle\int_\infty^0 \frac{-\sqrt{x}
}{x^2+4}\,dx = \int_0^\infty \frac{\sqrt{x}}{x^2+4}\,dx = I$.

Therefore
$$\oint_{\mathcal{C}} f(z)\,dz = I + I = 2I.$$

By the residue theorem,
$$2I = 2\pi i \sum \operatorname{Res} = 2\pi i\left(-\frac{i}{2}\right) = \pi.$$

**Verification (independent check).** Substituting $x=2t$, $dx=2\,dt$:
$$I = \int_0^\infty \frac{\sqrt{2t}}{4t^2+4}\,2\,dt = \frac{\sqrt{2}}{2}\int_0^\
infty \frac{t^{1/2}}{t^2+1}\,dt.$$
Using the standard Mellin result $\displaystyle\int_0^\infty \frac{t^{a-1}}{1+t^
b}\,dt = \frac{\pi}{b\sin(a\pi/b)}$ with $a=\tfrac32, b=2$:
$$\int_0^\infty \frac{t^{1/2}}{t^2+1}\,dt = \frac{\pi}{2\sin(3\pi/4)} = \frac{\p
i}{2\cdot\frac{\sqrt{2}}{2}} = \frac{\pi}{\sqrt{2}}.$$
Thus $I = \dfrac{\sqrt{2}}{2}\cdot\dfrac{\pi}{\sqrt{2}} = \dfrac{\pi}{2}$, confi
rming the contour result.

## Result

$$\boxed{\int_0^\infty \frac{x^{1/2}}{x^2+4}\,dx = \frac{\pi}{2}}$$
