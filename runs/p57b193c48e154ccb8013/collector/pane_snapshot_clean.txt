## Proof

Let Σ be a finite alphabet with |Σ| ≥ 1. A *language* is any subset of Σ*.

**Step 1. The set of all languages is uncountable.**

Σ* is countably infinite (its strings can be enumerated by length and then lexic
ographically). The set of all languages is the power set 𝒫(Σ*). By Cantor's theo
rem, |𝒫(Σ*)| > |Σ*| = ℵ₀, so the set of all languages is uncountable. (Concretel
y, |𝒫(Σ*)| = 2^ℵ₀, the cardinality of the continuum.)

**Step 2. The set of recursively enumerable (RE) languages is countable.**

Every RE language is recognized by some Turing machine. A Turing machine has a f
inite description: a finite set of states, a finite tape alphabet, and a finite
transition function, all encodable as a finite string over a fixed finite alphab
et. Hence the set of all Turing-machine descriptions is a subset of {0,1}* (afte
r some fixed encoding), which is countable. Therefore the set of Turing machines
 is countable, and since every RE language is recognized by at least one Turing
machine, the set of RE languages is at most countable. It is infinite (e.g., {aⁿ
 : n ≥ 0}, {aⁿbⁿ : n ≥ 0}, … give infinitely many distinct RE languages), so the
 set of RE languages is countably infinite.

**Step 3. The set of non-RE languages is uncountable.**

Let 𝓛 = 𝒫(Σ*) be the set of all languages, let 𝓡 be the set of RE languages, and
 let 𝓝 = 𝓛 \ 𝓡 be the set of non-RE languages. We have

- |𝓛| = 2^ℵ₀ (uncountable),
- |𝓡| = ℵ₀ (countable),
- 𝓡 ⊆ 𝓛, and 𝓝 = 𝓛 \ 𝓡.

Suppose for contradiction that 𝓝 were countable. Then 𝓛 = 𝓡 ∪ 𝓝 would be a union
 of two countable sets, hence countable — contradicting Step 1, which says 𝓛 is
uncountable. Therefore 𝓝 cannot be countable.

Equivalently, removing a countable set (𝓡) from an uncountable set (𝓛) leaves an
 uncountable set: if |𝓛 \ 𝓡| ≤ ℵ₀, then |𝓛| ≤ |𝓡| + |𝓝| ≤ ℵ₀ + ℵ₀ = ℵ₀, again co
ntradicting |𝓛| = 2^ℵ₀ > ℵ₀.

**Conclusion.** The set of all non-recursively enumerable languages is **uncount
able**. In fact its cardinality equals that of the continuum, 2^ℵ₀, since it is
obtained by removing only countably many languages from the uncountable family o
f all languages.
