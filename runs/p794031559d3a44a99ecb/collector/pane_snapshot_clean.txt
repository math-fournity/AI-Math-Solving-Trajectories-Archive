## Proof

**Setup and Interpretation.**

Let $X$ be an uncountable set with $|X| = \kappa$, and let $B$ denote the set of
 all bounded real-valued functions on $\mathbb{R}$:
$$B = \{f : \mathbb{R} \to \mathbb{R} : \exists\, M > 0 \text{ s.t. } \forall x
\in \mathbb{R},\; |f(x)| \leq M\}.$$

We denote $c = |\mathbb{R}| = 2^{\aleph_0}$.

**Step 1: Compute $|B|$.**

Write $B = \bigcup_{n=1}^{\infty} B_n$ where $B_n = \{f : \mathbb{R} \to [-n, n]
\}$.

Each $B_n$ is the set of all functions from $\mathbb{R}$ to $[-n,n]$, so:
$$|B_n| = |[-n,n]|^{|\mathbb{R}|} = c^c = \left(2^{\aleph_0}\right)^{2^{\aleph_0
}} = 2^{\aleph_0 \cdot 2^{\aleph_0}} = 2^{2^{\aleph_0}} = 2^c.$$

(Here $\aleph_0 \cdot 2^{\aleph_0} = 2^{\aleph_0}$ since $\aleph_0 \leq 2^{\alep
h_0}$.)

Therefore:
$$|B| = \left|\bigcup_{n=1}^{\infty} B_n\right| \leq \aleph_0 \cdot 2^c = 2^c, \
quad \text{and} \quad |B| \geq |B_1| = 2^c.$$

By the squeeze principle: $\boxed{|B| = 2^c}$.

**Step 2: Lemma — Number of injections between infinite sets.**

**Lemma.** *For infinite cardinals $2 \leq \kappa \leq \mu$, the number of injec
tive functions from a set of cardinality $\kappa$ to a set of cardinality $\mu$
is $\mu^\kappa$.*

*Proof of Lemma.* Let $X$ have $|X| = \kappa$ and $Y$ have $|Y| = \mu$. Well-ord
er $X = \{x_\alpha : \alpha < \kappa\}$.

**Upper bound.** Every injection is a function, so the number of injections $\le
q \mu^\kappa$ (the total number of functions $X \to Y$).

**Lower bound.** An injection $f : X \to Y$ is constructed by choosing, for each
 $\alpha < \kappa$, a value $f(x_\alpha) \in Y \setminus \{f(x_\beta) : \beta <
\alpha\}$. At step $\alpha$, the set of already-used values has cardinality $|\a
lpha| < \kappa \leq \mu$. Since $\mu$ is infinite and $|\alpha| < \mu$:
$$\left|Y \setminus \{f(x_\beta) : \beta < \alpha\}\right| = \mu - |\alpha| = \m
u.$$

So the number of available choices at each step is $\mu$, giving:
$$\text{number of injections} = \prod_{\alpha < \kappa} \mu = \mu^\kappa. \qquad
 \square$$

**Step 3: Apply to the problem.**

We want $|\mathrm{Inj}(X, B)|$ where $|X| = \kappa$ (uncountable) and $|B| = 2^c
$.

**Case 1: $\kappa > 2^c$.** No injection from a larger set to a smaller set exis
ts, so $|\mathrm{Inj}(X, B)| = 0$.

**Case 2: $\kappa \leq 2^c$.** By the Lemma:
$$|\mathrm{Inj}(X, B)| = |B|^{|X|} = (2^c)^\kappa = 2^{c \cdot \kappa}.$$

Since $\kappa$ is uncountable, $\kappa \geq \aleph_1 > \aleph_0$, and $c = 2^{\a
leph_0} \geq \aleph_1$, so $c \cdot \kappa = \max(c, \kappa)$.

- **If $\kappa \leq c$** (e.g., $X = \mathbb{R}$, $\kappa = c$): $c \cdot \kappa
 = c$, so $|\mathrm{Inj}(X, B)| = 2^c = 2^{2^{\aleph_0}}$.
- **If $c < \kappa \leq 2^c$**: $c \cdot \kappa = \kappa$, so $|\mathrm{Inj}(X,
B)| = 2^\kappa$.

---

**Step 4: The canonical case $X = \mathbb{R}$.**

For the most natural choice $X = \mathbb{R}$ (the canonical uncountable set, $|X
| = c$):

$$|\mathrm{Inj}(\mathbb{R}, B)| = (2^c)^c = 2^{c \cdot c} = 2^c = 2^{2^{\aleph_0
}}.$$

This equals the cardinality of the power set of $\mathbb{R}$, i.e., $|\mathcal{P
}(\mathbb{R})|$.

**Conclusion.**

For an uncountable set $X$ with $|X| = \kappa$ and $B$ the set of bounded real-v

$$|\mathrm{Inj}(X, B)| = \begin{cases} 2^{c \cdot \kappa} & \text{if } \kappa \l

$$\boxed{|\mathrm{Inj}(\mathbb{R}, B)| = 2^{2^{\aleph_0}}}$$
