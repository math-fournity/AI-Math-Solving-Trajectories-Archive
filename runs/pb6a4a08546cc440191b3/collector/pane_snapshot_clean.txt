## Solution

We solve the non-homogeneous heat equation with non-homogeneous boundary conditi
ons by reducing to homogeneous BCs, then using an eigenfunction (sine series) ex
pansion.

### Step 1: Homogenize the boundary conditions

Set
$$u(x,t) = v(x) + w(x,t), \qquad v(x) = 1 - \frac{x}{\pi}.$$

Then $v(0)=1$, $v(\pi)=0$, and $v''(x)=0$. Substituting:

$$\frac{\partial w}{\partial t} = \frac{\partial^2 w}{\partial x^2} + \sin 5x\,
e^{-2t},$$

with **homogeneous** boundary conditions $w(0,t)=0$, $w(\pi,t)=0$, and initial c
ondition

$$w(x,0) = u(x,0) - v(x) = -\Bigl(1-\frac{x}{\pi}\Bigr) = \frac{x}{\pi}-1.$$

### Step 2: Sine-series expansion of the initial data

Expand $w(x,t)=\sum_{n=1}^{\infty} b_n(t)\sin nx$. The coefficients of the initi
al profile are

$$b_n(0)=\frac{2}{\pi}\int_0^{\pi}\Bigl(\frac{x}{\pi}-1\Bigr)\sin nx\,dx.$$

Compute the two pieces:

$$\int_0^\pi \sin nx\,dx = \frac{1-(-1)^n}{n}, \qquad \int_0^\pi x\sin nx\,dx =
\frac{-\pi(-1)^n}{n}.$$

Hence

$$\int_0^\pi\Bigl(\frac{x}{\pi}-1\Bigr)\sin nx\,dx = \frac{1}{\pi}\cdot\frac{-\p
i(-1)^n}{n} - \frac{1-(-1)^n}{n} = \frac{-(-1)^n-1+(-1)^n}{n} = -\frac{1}{n},$$

so

$$\boxed{b_n(0) = -\frac{2}{n\pi}}.$$

### Step 3: ODEs for the time-dependent coefficients

Substituting the expansion into the PDE and matching the $\sin 5x$ source agains
t the eigenfunction $\sin 5x$:

- **For $n\neq 5$:** $b_n'(t) = -n^2 b_n(t)$, giving
$$b_n(t) = -\frac{2}{n\pi}\,e^{-n^2 t}.$$

- **For $n=5$:** $b_5'(t) = -25\,b_5(t) + e^{-2t}$, i.e. $b_5'+25b_5 = e^{-2t}$.

Solve via integrating factor $e^{25t}$:

$$\frac{d}{dt}\bigl[e^{25t}b_5(t)\bigr] = e^{23t} \implies e^{25t}b_5(t) = \frac
{1}{23}e^{23t}+C.$$

Applying $b_5(0) = -\frac{2}{5\pi}$:

$$-\frac{2}{5\pi} = \frac{1}{23}+C \implies C = -\frac{2}{5\pi}-\frac{1}{23}.$$

Thus

$$b_5(t) = \frac{1}{23}e^{-2t} + \Bigl(-\frac{2}{5\pi}-\frac{1}{23}\Bigr)e^{-25t
} = -\frac{2}{5\pi}e^{-25t} + \frac{1}{23}\bigl(e^{-2t}-e^{-25t}\bigr).$$

### Step 4: Verification

**Boundary conditions.** $u(0,t)=1-0+\sum b_n(t)\cdot 0 = 1$ ✓; $u(\pi,t)=1-1+\s
um b_n(t)\sin n\pi = 0$ ✓.

**Initial condition.** $u(x,0)=1-\frac{x}{\pi}+\sum_{n=1}^\infty\bigl(-\frac{2}{
n\pi}\bigr)\sin nx$. The sine series of $\frac{x}{\pi}-1$ on $(0,\pi)$ has coeff
icients $-\frac{2}{n\pi}$ (computed above), so the sum equals $\frac{x}{\pi}-1$
and $u(x,0)=0$ ✓.

**PDE.** For $n\neq 5$: $b_n'=-n^2 b_n$ ✓. For $n=5$:

$$b_5'+25b_5 = \Bigl[\tfrac{10}{\pi}e^{-25t}+\tfrac{1}{23}(-2e^{-2t}+25e^{-25t})
\Bigr] + \Bigl[-\tfrac{10}{\pi}e^{-25t}+\tfrac{25}{23}(e^{-2t}-e^{-25t})\Bigr] =
 \tfrac{-2+25}{23}e^{-2t} = e^{-2t}\;\checkmark.$$

### Final Answer

$$\boxed{u(x,t) = 1 - \frac{x}{\pi} + \sum_{n=1}^{\infty} b_n(t)\,\sin nx,}$$

where

$$b_n(t) = \begin{cases} -\dfrac{2}{n\pi}\,e^{-n^2 t}, & n\neq 5,\\[6pt] -\dfrac
{2}{5\pi}\,e^{-25t} + \dfrac{1}{23}\bigl(e^{-2t}-e^{-25t}\bigr), & n=5. \end{cas
es}$$
