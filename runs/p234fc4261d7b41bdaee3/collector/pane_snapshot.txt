## Proof

Let $G$ be a finite abelian group of order $n$. Since $G$ is abelian, every irre
ducible character is linear (degree 1), so the number of irreducible characters
equals $|G| = n$. The character table is therefore an $n \times n$ matrix.

**Setup.** Index the irreducible characters as $\chi_1, \dots, \chi_n$ and the g
roup elements as $g_1, \dots, g_n$. Let $X$ be the character table matrix, with
entries
$$X_{ij} = \chi_i(g_j), \qquad 1 \le i, j \le n.$$

**Orthogonality.** The standard column orthogonality relation for characters sta
tes that for any two group elements $g_j, g_k$,
$$\sum_{i=1}^{n} \chi_i(g_j)\,\overline{\chi_i(g_k)} = n\,\delta_{jk}.$$

In matrix terms, this sum is the $(j,k)$-entry of $X^T \overline{X}$ (where $\ov
erline{X}$ denotes entrywise complex conjugation). Indeed,
$$(X^T \overline{X})_{jk} = \sum_{i=1}^{n} (X^T)_{ji}(\overline{X})_{ik} = \sum_
{i=1}^{n} X_{ij}\,\overline{X_{ik}} = \sum_{i=1}^{n} \chi_i(g_j)\,\overline{\chi
_i(g_k)} = n\,\delta_{jk}.$$

Hence
$$X^T \overline{X} = n\,I_n.$$

**Taking determinants.** Applying the determinant to both sides:
$$\det(X^T \overline{X}) = \det(n\,I_n) = n^n.$$

Using $\det(X^T) = \det(X)$ and $\det(\overline{X}) = \overline{\det(X)}$ (since
 conjugation commutes with the determinant, being a polynomial in the entries):
$$\det(X)\,\overline{\det(X)} = n^n.$$

The left-hand side is $|\det(X)|^2$. Therefore
$$|\det(X)|^2 = n^n,$$

and taking the positive square root (noting $n > 0$):
$$|\det(X)| = n^{n/2}.$$

**Consistency check (cyclic case).** When $G = \mathbb{Z}/n\mathbb{Z}$ is cyclic
 with generator $\sigma$ and $\xi = e^{2\pi i/n}$, the character table is $X_{jk
} = \xi^{(j-1)(k-1)}$, which is a Vandermonde matrix in $1, \xi, \xi^2, \dots, \
xi^{n-1}$. The classical Vandermonde determinant gives
$$\det(X) = \prod_{0 \le a < b \le n-1}(\xi^b - \xi^a).$$

Each factor satisfies $|\xi^b - \xi^a| = |e^{2\pi i b/n} - e^{2\pi i a/n}| = 2\l
eft|\sin\!\tfrac{\pi(b-a)}{n}\right|$. Grouping the $\binom{n}{2}$ factors by th
e value $d = b - a \in \{1, \dots, n-1\}$ (each $d$ occurring $n - d$ times):
$$|\det(X)| = \prod_{d=1}^{n-1}\left(2\sin\!\tfrac{\pi d}{n}\right)^{n-d}.$$

Using the identity $\prod_{d=1}^{n-1} 2\sin\!\tfrac{\pi d}{n} = n$ together with
 the symmetry $\sin\!\tfrac{\pi d}{n} = \sin\!\tfrac{\pi(n-d)}{n}$, one verifies
 $|\det(X)|^2 = n^n$, confirming $|\det(X)| = n^{n/2}$. This matches the general
 result above.

**Conclusion.** For any finite abelian group $G$ of order $n$, the modulus of th
e determinant of its character table is

$$\boxed{|\det(X)| = n^{n/2}}.$$
