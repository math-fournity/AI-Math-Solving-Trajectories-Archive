## Proof

**Step 1: Partial fraction decomposition.**

Since $p(0), p(1), p(-1) \neq 0$, the rational function $\frac{p(x)}{x(x-1)(x+1)
}$ has simple poles at $x = 0, 1, -1$. Writing
$$\frac{p(x)}{x^3 - x} = q(x) + \frac{A}{x} + \frac{B}{x-1} + \frac{C}{x+1},$$
where $q(x)$ is the polynomial quotient. Since $\deg p \leq 1991$ and $\deg(x^3
- x) = 3$, we have $\deg q \leq 1988 < 1992$, so the 1992nd derivative of $q$ va
nishes.

The residues are:
$$A = \frac{p(0)}{(0-1)(0+1)} = -p(0), \quad B = \frac{p(1)}{1 \cdot 2} = \frac{
p(1)}{2}, \quad C = \frac{p(-1)}{(-1)(-2)} = \frac{p(-1)}{2}.$$

**Step 2: Compute the 1992nd derivative.**

Using $\frac{d^n}{dx^n}\left[\frac{1}{x-a}\right] = \frac{(-1)^n\, n!}{(x-a)^{n+
1}}$ with $n = 1992$ (even):

$$\frac{d^{1992}}{dx^{1992}}\frac{p(x)}{x^3-x} = 1992!\left[\frac{-p(0)}{x^{1993
}} + \frac{p(1)/2}{(x-1)^{1993}} + \frac{p(-1)/2}{(x+1)^{1993}}\right].$$

**Step 3: Common denominator.**

Setting $a = p(0),\, b = p(1),\, c = p(-1)$ (all nonzero), the common denominato
r is $g(x) = (x^3 - x)^{1993}$ (degree $5979$), and the numerator is:

$$f(x) = 1992!\left[-a(x^2-1)^{1993} + \tfrac{b}{2}(x^2+x)^{1993} + \tfrac{c}{2}
(x^2-x)^{1993}\right].$$

**Step 4: The fraction is already reduced.**

Evaluating $f$ at the roots of $g$:
- $f(0) = 1992! \cdot a \neq 0$,
- $f(1) = 1992! \cdot b \cdot 2^{1992} \neq 0$,
- $f(-1) = 1992! \cdot c \cdot 2^{1992} \neq 0$.

Since $g$ has roots only at $0, 1, -1$, we conclude $\gcd(f, g) = 1$. So $\deg f
$ is the degree of the numerator above.

**Step 5: Determine the degree.**

Each term has degree $\leq 3986$. Write $H(x) = f(x)/1992!$ and substitute $x =
1/y$:

$$H(x) = x^{3986}\,\phi(y), \quad y = 1/x, \quad \phi(y) = -a(1-y^2)^{1993} + \t
frac{b}{2}(1+y)^{1993} + \tfrac{c}{2}(1-y)^{1993}.$$

Then $\deg H = 3986 - k$, where $k$ is the order of vanishing of $\phi$ at $y =
0$. We maximize $k$ over $a, b, c \neq 0$.

Expanding $\phi(y) = \sum c_n y^n$:

- **Odd coefficients** ($n = 2m+1$): $[y^{2m+1}]\phi = \frac{1}{2}\binom{1993}{2
m+1}(b - c)$.
- **Even coefficients** ($n = 2m$): $[y^{2m}]\phi = -a(-1)^m\binom{1993}{m} + \f
rac{b+c}{2}\binom{1993}{2m}$.

**Killing $[y^0]$** ($m=0$): $-a + \frac{b+c}{2} = 0 \Longrightarrow b + c = 2a$

**Killing $[y^1]$** ($m=0$, odd): $\frac{1993}{2}(b - c) = 0 \Longrightarrow b =

Together: $b = c = a$ (with $a \neq 0$). Then all odd coefficients vanish, and t

$$[y^{2m}]\phi = a\left[(-1)^{m+1}\binom{1993}{m} + \binom{1993}{2m}\right].$$

For $m = 0$: $a[-1 + 1] = 0$ ✓.
For $m = 1$: $a\left[1993 + \binom{1993}{2}\right] = a\left[1993 + 1993 \cdot 99
6\right] = a \cdot 1993 \cdot 997 \neq 0$.

So $[y^2]\phi \neq 0$, giving $k = 2$.

**Step 6: $k = 2$ is optimal.**

For $k \geq 3$, we would need $[y^2]\phi = 0$ in addition. Under $b + c = 2a$:

$$[y^2]\phi = a \cdot 1993 + a\cdot\binom{1993}{2} = a \cdot 1993 \cdot 997.$$

1] \neq 0$, so $k = 1$; if $b + c \neq 2a$, then $k = 0$).

Therefore $k_{\max} = 2$, and:

$$\deg f = 3986 - 2 = \boxed{3984}.$$
