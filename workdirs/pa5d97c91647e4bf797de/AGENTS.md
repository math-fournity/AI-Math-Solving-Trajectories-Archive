# Problem

In the high-security digital vault of a global bank, the security system is built upon a central circular mainframe. Within this mainframe, a specific finite set of data-bridges has been established. Each bridge connects two distinct access points on the perimeter of the circular system.

A "Data-Loop" is defined as any closed path formed by at least three distinct data-bridges from the established set. Two loops are considered identical if they utilize the exact same set of bridges, regardless of the order in which they are traversed.

During a system audit, engineers discovered a specific "Master Loop," denoted as $\mathcal{M}$, which consists of exactly 2022 distinct data-bridges. This Master Loop has a unique structural property: every single Data-Loop that can possibly be formed within the system must share at least one data-bridge with $\mathcal{M}$.

Based on this architecture, determine the maximum possible total number of Data-Loops that can exist within the mainframe.
