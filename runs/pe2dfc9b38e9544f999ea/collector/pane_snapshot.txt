# Solution

**Claim:** Yes. The orthogonal Procrustes problem for complex matrices can be so
lved by exactly the same SVD-based method used in the real case, with the transp
ose $T$ replaced by the conjugate transpose $*$ and "orthogonal" replaced by "un
itary."

---

## Problem Setup

Given $A, B \in \mathbb{C}^{m \times n}$, find $Q \in \mathbb{C}^{n \times n}$ w
ith $Q^*Q = I$ (unitary) minimizing
$$\|A - BQ\|_F^2.$$

## Reduction to a Trace Maximization

Expand using the complex Frobenius norm $\|X\|_F^2 = \operatorname{tr}(X^*X)$:
$$\|A - BQ\|_F^2 = \operatorname{tr}\!\big((A-BQ)^*(A-BQ)\big) = \operatorname{t
r}(A^*A) - \operatorname{tr}(Q^*B^*A) - \operatorname{tr}(A^*BQ) + \operatorname
{tr}(Q^*B^*BQ).$$

Since $Q^*Q = I$, the last term is $\operatorname{tr}(B^*B) = \|B\|_F^2$, indepe
ndent of $Q$. Also $\operatorname{tr}(A^*BQ) = \overline{\operatorname{tr}(Q^*B^
*A)}$, so the two middle terms combine to $-2\,\operatorname{Re}\operatorname{tr
}(Q^*B^*A)$. Setting $M := B^*A$:
$$\|A - BQ\|_F^2 = \|A\|_F^2 + \|B\|_F^2 - 2\,\operatorname{Re}\operatorname{tr}
(Q^*M).$$

Thus minimizing the norm is equivalent to **maximizing** $\operatorname{Re}\oper
atorname{tr}(Q^*M)$ over unitary $Q$.

## SVD-Based Solution (Same as Real Case)

Take the (complex) SVD $M = U\Sigma V^*$, with $U, V$ unitary and $\Sigma = \ope
ratorname{diag}(\sigma_1,\dots,\sigma_n)$, $\sigma_i \ge 0$. Define $Z := V^*Q^*
U$, which is unitary whenever $Q$ is. Then
$$\operatorname{tr}(Q^*M) = \operatorname{tr}(Q^*U\Sigma V^*) = \operatorname{tr
}(V^*Q^*U\Sigma) = \operatorname{tr}(Z\Sigma) = \sum_{i=1}^n z_{ii}\,\sigma_i.$$

Since $Z$ is unitary, every diagonal entry satisfies $|z_{ii}| \le 1$ (each row
of a unitary matrix has unit norm). Therefore
$$\operatorname{Re}\operatorname{tr}(Q^*M) = \sum_{i=1}^n \operatorname{Re}(z_{i
i})\,\sigma_i \le \sum_{i=1}^n |z_{ii}|\,\sigma_i \le \sum_{i=1}^n \sigma_i.$$

**Equality** holds iff $\operatorname{Re}(z_{ii}) = 1$ and $|z_{ii}|=1$ for ever
y $i$ with $\sigma_i > 0$, i.e. $z_{ii}=1$. Taking $Z = I$ (hence $Q = UV^*$) ac
hieves this, giving
$$\max_{Q^*Q=I}\operatorname{Re}\operatorname{tr}(Q^*M) = \sum_{i=1}^n \sigma_i
= \operatorname{tr}(\Sigma).$$

## The Optimal $Q$

$$\boxed{Q = UV^*}, \qquad \text{where } B^*A = U\Sigma V^* \text{ is the SVD.}$
$

This is unitary since $U$ and $V$ are unitary: $(UV^*)(UV^*)^* = UV^*VU^* = I$.

## Comparison with the Real Case

| Step | Real | Complex |
|---|---|---|
| Constraint | $Q^TQ = I$ (orthogonal) | $Q^*Q = I$ (unitary) |
| Cross matrix | $M = B^TA$ | $M = B^*A$ |
| SVD | $M = U\Sigma V^T$ | $M = U\Sigma V^*$ |
| Objective to maximize | $\operatorname{tr}(Q^TM)$ | $\operatorname{Re}\operato
rname{tr}(Q^*M)$ |
| Optimal $Q$ | $UV^T$ | $UV^*$ |
| Max value | $\sum\sigma_i$ | $\sum\sigma_i$ |

Every step is identical in structure: form $M = B^*A$, take its SVD, set $Q = UV
^*$. The only differences are the notational substitutions $T \mapsto *$ and the
 appearance of $\operatorname{Re}(\cdot)$ (which is automatic in the real case s
ince the trace is already real). The key inequality $|z_{ii}|\le 1$ for unitary
$Z$ — the crux of the argument — holds in exactly the same way as $|z_{ii}|\le 1
$ for orthogonal $Z$ in the real case.

## Conclusion

The orthogonal Procrustes problem **can** be solved for complex matrices using t
he same solution method as for real matrices. The SVD-based approach transfers v
erbatim: compute $M = B^*A$, take its SVD $M = U\Sigma V^*$, and the minimizer i
s $Q = UV^*$. The proof of optimality goes through unchanged because the unitary
 constraint satisfies the same diagonal-bound property ($|z_{ii}|\le 1$) that th
e orthogonal constraint does in the real case.
