## Proof

We work in finite dimensions. Let $H_1, H_2$ have dimensions $n, m$ respectively
. Since $S_1(H) = B(H)$ in finite dimensions, $\varphi$ is a bijection. We prove
 $\|\varphi^{-1}\| = \min\{m,n\}$ by establishing both inequalities. WLOG assume
 $n \leq m$.

### Upper Bound: $\|\varphi^{-1}\| \leq n$

We must show $\pi(T) \leq n\,\|T\|_1$ for all $T \in S_1(H_1 \otimes_2 H_2)$, wh
ere $\pi$ denotes the projective tensor norm.

Take the singular value decomposition $T = \sum_\alpha s_\alpha\,|u_\alpha\rangl
e\langle v_\alpha|$, where $s_\alpha \geq 0$, $\sum_\alpha s_\alpha = \|T\|_1$,
and $\{u_\alpha\}, \{v_\alpha\}$ are orthonormal systems in $H_1 \otimes_2 H_2$.

Each unit vector $u_\alpha$ has a Schmidt decomposition $u_\alpha = \sum_{i=1}^{
r_\alpha} \sqrt{\lambda_{\alpha,i}}\, e_{\alpha,i} \otimes f_{\alpha,i}$ with $r
_\alpha \leq \min\{n,m\} = n$ and $\sum_i \lambda_{\alpha,i} = 1$. Similarly, $v
_\alpha = \sum_{j=1}^{r'_\alpha} \sqrt{\mu_{\alpha,j}}\, e'_{\alpha,j} \otimes f
'_{\alpha,j}$ with $r'_\alpha \leq n$.

Then:
$$|u_\alpha\rangle\langle v_\alpha| = \sum_{i,j} \sqrt{\lambda_{\alpha,i}\,\mu_{
\alpha,j}}\;|e_{\alpha,i}\rangle\langle e'_{\alpha,j}| \otimes |f_{\alpha,i}\ran
gle\langle f'_{\alpha,j}|.$$

Since each $|e_{\alpha,i}\rangle\langle e'_{\alpha,j}|$ and $|f_{\alpha,i}\rangl
e\langle f'_{\alpha,j}|$ is rank-1 with trace norm 1:
$$\pi(|u_\alpha\rangle\langle v_\alpha|) \leq \sum_{i,j} \sqrt{\lambda_{\alpha,i
}\,\mu_{\alpha,j}} = \Bigl(\sum_i \sqrt{\lambda_{\alpha,i}}\Bigr)\Bigl(\sum_j \s
qrt{\mu_{\alpha,j}}\Bigr).$$

By Cauchy–Schwarz: $\sum_i \sqrt{\lambda_{\alpha,i}} \leq \sqrt{r_\alpha}\,\sqrt
{\sum_i \lambda_{\alpha,i}} = \sqrt{r_\alpha} \leq \sqrt{n}$, and likewise $\sum
_j \sqrt{\mu_{\alpha,j}} \leq \sqrt{n}$. Therefore:
$$\pi(|u_\alpha\rangle\langle v_\alpha|) \leq n.$$

Summing over $\alpha$:
$$\pi(T) \leq \sum_\alpha s_\alpha\,\pi(|u_\alpha\rangle\langle v_\alpha|) \leq
n\sum_\alpha s_\alpha = n\,\|T\|_1. \quad\checkmark$$

### Lower Bound: $\|\varphi^{-1}\| \geq n$

We exhibit $T$ with $\pi(T)/\|T\|_1 = n$. Let $\{e_i\}_{i=1}^n$ be an ONB of $H_
1$ and $\{f_j\}_{j=1}^m$ an ONB of $H_2$. Define the maximally entangled unit ve
ctor:
$$|\Omega\rangle = \frac{1}{\sqrt{n}}\sum_{i=1}^n e_i \otimes f_i \in H_1 \otime
s_2 H_2,$$
and set $T = |\Omega\rangle\langle\Omega|$. Since $T$ is a rank-1 projection, $\
|T\|_1 = 1$.

**Showing $\pi(T) \leq n$:** Using the Schmidt decomposition of $|\Omega\rangle$
 (Schmidt coefficients $\lambda_i = 1/n$ for $i=1,\dots,n$):
$$T = \frac{1}{n}\sum_{i,j=1}^n |e_i\rangle\langle e_j| \otimes |f_i\rangle\lang
le f_j|,$$
so $\pi(T) \leq \frac{1}{n}\sum_{i,j} 1 \cdot 1 = n$.

**Showing $\pi(T) \geq n$ via duality:** The dual of $S_1(H_1)\hat{\otimes}_\pi
S_1(H_2)$ is $B(S_1(H_1),\, B(H_2))$ (bounded linear maps $S_1(H_1) \to B(H_2) =
 S_1(H_2)^*$). Define the linear map $\tilde\beta: S_1(H_1) \to B(H_2)$ by:
$$\tilde\beta(A) = U\, A^T\, U^*,$$
where $U: H_1 \to H_2$ is the isometry $Ue_i = f_i$ ($i \leq n$), and $A^T$ is t
he transpose of $A$ in the $\{e_i\}$ basis. The corresponding bilinear form is:
$$\beta(A, B) = \operatorname{tr}(\tilde\beta(A)\, B) = \sum_{i,j=1}^n \langle e
_i, A\, e_j\rangle\,\langle f_i, B\, f_j\rangle.$$

**Norm of $\tilde\beta$:** Since $U$ is an isometry and transpose preserves sing
ular values, $\|\tilde\beta(A)\|_\infty = \|A^T\|_\infty = \|A\|_\infty \leq \|A
\|_1$. Hence $\|\tilde\beta\| = \sup_{\|A\|_1 \leq 1} \|\tilde\beta(A)\|_\infty
= 1$ (equality achieved at any rank-1 $A$). Thus $\|\beta\| = 1$.

**Evaluating on $T$:** Since $\beta(|e_i\rangle\langle e_j|,\, |f_k\rangle\langl
e f_l|) = \delta_{ik}\,\delta_{jl}$, we get $\beta(|e_i\rangle\langle e_j|,\, |f
_i\rangle\langle f_j|) = 1$ for all $i,j$. Therefore:
$$\langle \beta, T\rangle = \frac{1}{n}\sum_{i,j=1}^n \beta(|e_i\rangle\langle e
_j|,\, |f_i\rangle\langle f_j|) = \frac{1}{n}\cdot n^2 = n.$$

Since $\|\beta\| = 1$, we conclude $\pi(T) \geq |\langle \beta, T\rangle| = n$.

Combining: $\pi(T) = n$ and $\|T\|_1 = 1$, so $\|\varphi^{-1}\| \geq n$.

### Conclusion

$$\|\varphi^{-1}\| = n = \min\{m, n\} \quad\text{(when } n \leq m\text{)}.$$

By symmetry (exchanging the roles of $H_1$ and $H_2$ when $m \leq n$), the gener
al result holds:

$$\boxed{\|\varphi^{-1}\| = \min\{m,\, n\}.}$$

The answer is **yes**.
