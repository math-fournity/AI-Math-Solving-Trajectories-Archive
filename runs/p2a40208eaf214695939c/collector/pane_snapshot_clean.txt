Looking at this problem, I need to find $\angle DEC$ in a rhombus $ABCD$ with $\
angle ABC = 40°$, where $M$ is the midpoint of $BC$, and $E$ lies on line $DM$ w
ith $AE \perp DM$.

**Setting up coordinates.** Place $B = (0,0)$, $C = (1,0)$ (side length 1). Sinc
e $\angle ABC = 40°$, we get $A = (\cos 40°, \sin 40°)$ and $D = (1 + \cos 40°,
\sin 40°)$. The midpoint is $M = (1/2, 0)$.

Let $c = \cos 40°$, $s = \sin 40°$.

**Finding E.** Since $AE \perp DM$ and $E$ is the intersection point on line $DM
$, $E$ is the foot of perpendicular from $A$ to line $DM$.

Direction of $DM$: $M - D = (-1/2 - c,\; -s)$.

Writing $E = D + t(M-D)$ and imposing $(E - A) \cdot (M - D) = 0$:

$$t = \frac{1/2 + c}{(1/2+c)^2 + s^2} = \frac{1/2 + c}{5/4 + c}$$

since $(1/2+c)^2 + s^2 = 1/4 + c + c^2 + s^2 = 5/4 + c$.

**Computing E explicitly:**

$$E = \left(\frac{4+5c}{5+4c},\;\frac{3s}{5+4c}\right)$$

**Computing the vectors from E:**

$$\vec{ED} = D - E = \left(\frac{(1+2c)^2}{5+4c},\;\frac{2s(1+2c)}{5+4c}\right)$
$

$$\vec{EC} = C - E = \left(\frac{1-c}{5+4c},\;\frac{-3s}{5+4c}\right)$$

**Dot product:**

$$\vec{ED}\cdot\vec{EC} = \frac{(1+2c)^2(1-c) - 6s^2(1+2c)}{(5+4c)^2} = \frac{(1
+2c)\big[(1+2c)(1-c)-6s^2\big]}{(5+4c)^2}$$

Expanding: $(1+2c)(1-c) - 6s^2 = 1+c-2c^2 - 6(1-c^2) = 4c^2+c-5 = (4c+5)(c-1)$.

So $\vec{ED}\cdot\vec{EC} = \frac{(1+2c)(c-1)}{5+4c}$.

**Magnitudes:**

$$|\vec{ED}|^2 = \frac{(1+2c)^2\big[(1+2c)^2+4s^2\big]}{(5+4c)^2} = \frac{(1+2c)
^2(5+4c)}{(5+4c)^2} = \frac{(1+2c)^2}{5+4c}$$

$$|\vec{EC}|^2 = \frac{(1-c)^2+9s^2}{(5+4c)^2} = \frac{10-2c-8c^2}{(5+4c)^2} = \
frac{2(5+4c)(1-c)}{(5+4c)^2} = \frac{2(1-c)}{5+4c}$$

**Computing the cosine:**

$$\cos\angle DEC = \frac{(1+2c)(c-1)/(5+4c)}{\dfrac{1+2c}{\sqrt{5+4c}}\cdot\sqrt
{\dfrac{2(1-c)}{5+4c}}} = \frac{c-1}{\sqrt{2(1-c)}} = \frac{-(1-c)}{\sqrt{2(1-c)
}} = -\sqrt{\frac{1-c}{2}}$$

**Applying the half-angle identity** $\frac{1-\cos\theta}{2} = \sin^2(\theta/2)$
:

$$\cos\angle DEC = -\sqrt{\frac{1-\cos 40°}{2}} = -\sin 20° = -\cos 70° = \cos 1
10°$$

Therefore:

$$\angle DEC = \boxed{110°}$$

### PROOF COMPLETE
