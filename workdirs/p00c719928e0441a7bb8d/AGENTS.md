# Problem

In a futuristic city, an architect is designing an $8 \times 8$ grid of high-tech server modules. Each module is a rectangle that covers exactly two grid cells, representing a single "data unit." 

These units can be installed in one of two orientations: "Horizontal Units," which span two cells within the same row, or "Vertical Units," which span two cells within the same column. The architect must fill the entire grid with these units so that every one of the 64 cells is covered by exactly one unit.

The city’s cooling system is installed along the internal edges where a Horizontal Unit and a Vertical Unit are adjacent to one another. An edge segment (of length 1) contributes to the "Thermal Boundary" only if it serves as a common border between a unit placed horizontally and a unit placed vertically. Edges between two horizontal units, edges between two vertical units, and the outer perimeter of the $8 \times 8$ board do not count toward the cooling capacity.

What is the maximum possible total length of this Thermal Boundary?
