# Problem

In a vast digital landscape represented as an infinite grid of processing nodes, a "Replicator" protocol is initialized. To begin the process, a specific number of nodes, $N$, are manually activated (marked). 

The protocol operates under a strict "Activation Rule": An inactive node $A$ will automatically activate if and only if there are at least $k$ already active nodes located within its "Communication Range." The Communication Range of node $A$ is defined as the set of all nodes sharing the same horizontal row or the same vertical column as $A$.

For a given positive integer $k$, we define $f(k)$ as the minimum number of initial nodes $N$ required such that, through a sequence of automatic activations, every single node in the infinite grid eventually becomes active.

Calculate the value of the following sum:
$$\sum_{k=1}^{20} f(k)$$
