## Solution

**Alpha's daily rates:**
- Day 1: 160/300 = 8/15 ≈ 0.5333
- Day 2: 140/200 = 7/10 = 0.7

**Setup.** Let Beta attempt $a$ points on day 1 and $c = 500 - a$ on day 2, with
 $a \neq 300$ (given), $a, c$ positive integers. Let Beta score $b_1$ on day 1 a
nd $b_2$ on day 2, both positive integers, with
$$b_1/a < 8/15, \qquad b_2/c < 7/10.$$

We maximize $b_1 + b_2$ (then divide by 500).

**Maximizing each day's score.** Since $b_1$ is a positive integer with $b_1 < 8
a/15$:
$$b_1^{\max} = \left\lceil \tfrac{8a}{15}\right\rceil - 1.$$

For day 2, $b_2 < 7c/10 = 7(500-a)/10 = 350 - 7a/10$, so
$$b_2^{\max} = \left\lceil 350 - \tfrac{7a}{10}\right\rceil - 1 = 350 - \left\lf
loor \tfrac{7a}{10}\right\rfloor - 1 = 349 - \left\lfloor \tfrac{7a}{10}\right\r
floor,$$
using $\lceil 350 - x\rceil = 350 - \lfloor x\rfloor$ (since 350 is an integer).

**Total to maximize:**
$$T(a) = b_1^{\max} + b_2^{\max} = \left\lceil \tfrac{8a}{15}\right\rceil - 1 +
349 - \left\lfloor \tfrac{7a}{10}\right\rfloor = 348 + \underbrace{\left(\left\l
ceil \tfrac{8a}{15}\right\rceil - \left\lfloor \tfrac{7a}{10}\right\rfloor\right
)}_{h(a)}.$$

**Upper bound on $h(a)$.** Using $\lceil x\rceil \le x + \tfrac{14}{15}$ (fracti
onal slack) and $\lfloor y\rfloor \ge y - \tfrac{9}{10}$:
$$h(a) \le \tfrac{8a}{15} + \tfrac{14}{15} - \tfrac{7a}{10} + \tfrac{9}{10} = -\
tfrac{a}{6} + \tfrac{11}{6}.$$

For $a \ge 1$: $h(a) \le \tfrac{11}{6} - \tfrac{1}{6} = \tfrac{10}{6} < 2$. Sinc
e $h(a)$ is an integer, $h(a) \le 1$ for all valid $a$. Hence $T(a) \le 349$.

**Achieving $T = 349$.** Take $a = 2$, $c = 498$:
- $b_1 < 16/15 \approx 1.067 \Rightarrow b_1 = 1$. Rate: $1/2 = 0.5 < 8/15$. ✓ (
positive integer)
- $b_2 < 7\cdot 498/10 = 348.6 \Rightarrow b_2 = 348$. Rate: $348/498 \approx 0.
6988 < 0.7$. ✓ (positive integer)
- $a = 2 \neq 300$. ✓
- Total: $1 + 348 = 349$.

(Also $a = 4$: $b_1 = 2$, $b_2 = 347$, total $349$, also valid.)

**Verification of all constraints:**
- Beta attempted $2 + 498 = 500$ points total. ✓
- Positive integer score each day ($1$ and $348$). ✓
- Each daily rate strictly less than Alpha's ($1/2 < 8/15$ and $348/498 < 7/10$)
. ✓
- Did not attempt 300 on day 1. ✓

**Reducing the fraction.** $349/500$: since $349$ is prime (no prime divisor $\l
e \sqrt{349} \approx 18.7$) and $349 \nmid 500$, we have $\gcd(349, 500) = 1$.

Thus $m/n = 349/500$ and
$$m + n = 349 + 500 = \boxed{849}.$$
