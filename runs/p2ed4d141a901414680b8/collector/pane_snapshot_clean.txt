## Proof

Let $\mathcal{F} = \{f \text{ holomorphic on } \mathbb{D} : \Re f(z) > 0 \text{
for all } z \in \mathbb{D},\ f(0)=1\}$ be the **Carathéodory class** (with stric
t positivity).

**Step 1: Herglotz representation.** By the Herglotz representation theorem, eve
ry $f \in \mathcal{F}$ (a fortiori satisfying $\Re f \geq 0$) admits the integra
l representation
$$f(z) = \int_{0}^{2\pi} \frac{1+e^{-it}z}{1-e^{-it}z}\,d\mu(t),$$
where $\mu$ is a probability measure on $[0,2\pi]$ (the condition $f(0)=1$ force
s $\mu$ to be a probability measure, since the integrand equals $1$ at $z=0$).

**Step 2: Bound on $f'(0)$.** Differentiating under the integral sign,
$$f'(z) = \int_{0}^{2\pi} \frac{2e^{-it}}{(1-e^{-it}z)^2}\,d\mu(t),$$
so evaluating at $z=0$,
$$f'(0) = 2\int_{0}^{2\pi} e^{-it}\,d\mu(t).$$
Taking moduli and using $|e^{-it}|=1$,
$$|f'(0)| \leq 2\int_{0}^{2\pi}|e^{-it}|\,d\mu(t) = 2\,\mu([0,2\pi]) = 2.$$
Hence $\alpha \leq 2$.

**Step 3: The bound is attained.** Consider
$$f_0(z) = \frac{1+z}{1-z}.$$
This corresponds to $\mu = \delta_0$ (a point mass at $t=0$) in the Herglotz rep
resentation. We verify:
- $f_0(0) = 1$.
- $\Re f_0(z) = \Re\frac{1+z}{1-z} = \frac{1-|z|^2}{|1-z|^2} > 0$ for all $|z|<1
$.
- $f_0'(z) = \frac{2}{(1-z)^2}$, so $f_0'(0) = 2$.

Thus $|f_0'(0)| = 2$, giving $\alpha \geq 2$.

Combining Steps 2 and 3, $\alpha = 2$.

**Step 4: All extremizers.** Equality $|f'(0)|=2$ in Step 2 requires equality in
 $|\int e^{-it}\,d\mu| \leq \int|e^{-it}|\,d\mu$, which holds iff $e^{-it}$ is c
onstant $\mu$-a.e., i.e., $\mu$ is a point mass $\delta_{t_0}$ for some $t_0 \in
 [0,2\pi)$. The corresponding extremal functions are
$$f_{t_0}(z) = \frac{1+e^{-it_0}z}{1-e^{-it_0}z},$$
each satisfying $\Re f_{t_0}(z) = \frac{1-|z|^2}{|1-e^{-it_0}z|^2} > 0$ on $\mat
hbb{D}$ and $f_{t_0}'(0) = 2e^{-it_0}$, so $|f_{t_0}'(0)| = 2$.

**Conclusion.** The supremum is
$$\boxed{\alpha = 2},$$
and it **is attained**, for instance by $f(z) = \frac{1+z}{1-z}$ (and more gener
ally by $f_{t_0}(z)=\frac{1+e^{-it_0}z}{1-e^{-it_0}z}$).
