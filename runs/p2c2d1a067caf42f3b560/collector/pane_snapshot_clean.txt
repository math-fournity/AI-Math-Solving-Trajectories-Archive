The Monadic Fragment of Inclusive First-Order Logic is Decidable

Definitions

Inclusive first-order logic is first-order logic whose semantics permits the
empty domain (in addition to all non-empty domains). This is the standard
meaning of "inclusive" in this context: the class of models is inclusive of the
empty structure.

The monadic fragment consists of first-order formulas using only unary predicate
symbols (no function symbols; equality and constants may be present). This is
the classical monadic class of Löwenheim and Behmann.

Key Facts

Fact 1 (Löwenheim–Behmann). The monadic fragment of standard (exclusive) first-
order logic is decidable.

Sketch: A monadic sentence with $k$ unary predicate symbols partitions any
domain into at most $2^k$ "1-types" (maximal consistent sets of atomic/unnegated
atomic formulas). Elements realizing the same 1-type are indistinguishable by
any monadic formula (without equality; with equality one keeps at most one
representative per type, or a bounded number). Hence any satisfiable monadic
sentence has a model of size at most $2^k$ (adjustable for equality and
constants). Satisfiability is thus decidable by exhaustive search over finitely
many bounded-size structures.

Fact 2. The truth value of any first-order sentence in the empty structure is
computable.

In the empty domain $\emptyset$:

  • $\forall x, \varphi$ is true (vacuous quantification),
  • $\exists x, \varphi$ is false (vacuous quantification),
  • Boolean connectives compose as usual.

So by structural recursion on the sentence, we can effectively compute its truth
value in $\emptyset$. (If the language contains constants, the empty structure
is not available — see the remark below.)

Proof

Let $\varphi$ be a monadic sentence. We give a decision procedure for both
satisfiability and validity in inclusive FOL.

Satisfiability

$\varphi$ is satisfiable in inclusive FOL iff there exists a model — possibly $
\emptyset$ — satisfying $\varphi$. This splits into two cases:

$$\varphi \text{ sat. in inclusive FOL} \iff \bigl(\emptyset \vDash
\varphi\bigr) ;\vee; \bigl(\varphi \text{ sat. in standard FOL}\bigr).$$

  • Left disjunct: Compute $\emptyset \vDash \varphi$ by the recursion of Fact
  2. This is decidable.
  • Right disjunct: Decidable by Fact 1 (the Löwenheim–Behmann result for the
  monadic class).

The disjunction of two decidable predicates is decidable. $\checkmark$

Validity

$\varphi$ is valid in inclusive FOL iff $\varphi$ holds in every model,
including $\emptyset$:

$$\varphi \text{ valid in inclusive FOL} \iff \bigl(\emptyset \vDash
\varphi\bigr) ;\wedge; \bigl(\varphi \text{ valid in standard FOL}\bigr).$$

  • Left conjunct: Decidable by Fact 2.
  • Right conjunct: Validity in standard FOL = unsatisfiability of $\neg\varphi$
  in standard FOL, decidable by Fact 1 (since the monadic fragment is closed
  under negation).

The conjunction of two decidable predicates is decidable. $\checkmark$

Remark on constants

If the language contains constants, the empty structure is not a legitimate
model (constants require denotations). In that case inclusive FOL coincides with
standard FOL for that language, and decidability follows directly from Fact 1.
If the language has no constants (or if the semantics treats constants as non-
denoting in the empty domain), the argument above applies verbatim. Either way,
decidability holds.

Remark on free variables

If one considers open formulas, satisfiability is defined via existential
closure and validity via universal closure. The existentially closed sentence is
false in $\emptyset$ (leading existentials), so satisfiability reduces to the
standard case. The universally closed sentence is true in $\emptyset$ (leading
universals), so validity requires checking both $\emptyset$ and non-empty models
— both decidable as shown. No difficulty arises.

Conclusion

The difference between inclusive and standard first-order logic is exactly one
additional model: the empty structure. Checking any sentence against a single,
concrete, finite model is trivially decidable. Since the monadic fragment of
standard first-order logic is decidable (Löwenheim–Behmann), and since adding a
single decidable model-check to a decidable theory preserves decidability, the
monadic fragment of inclusive first-order logic is decidable.

More generally, this argument shows that for any fragment $\mathcal{F}$ of
first-order logic: if satisfiability (resp. validity) of $\mathcal{F}$-sentences
is decidable in standard FOL, then it is also decidable in inclusive FOL — the
empty domain contributes only one additional decidable case.
