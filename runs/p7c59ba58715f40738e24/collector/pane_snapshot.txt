## Solution

**Setup.** The numbers $1$ through $255$ are precisely the positive integers who
se binary representations have length $1$ through $8$ (no leading zeros). I coun
t the total number of $1$-runs over all binary strings of each length $k$, then
sum over $k=1,\dots,8$.

**Counting $1$-runs via run-starts.** A $1$-run begins at position $i$ if bit $i
 = 1$ and either $i=1$ (the leading bit) or bit $i-1 = 0$. Thus
$$B(n) = [\text{bit }1 = 1] + \sum_{i=2}^{k}[\text{bit }i = 1 \text{ and bit }{i
-1}=0].$$

**Strings of length $k$ (leading bit fixed to $1$).** There are $2^{k-1}$ such s
trings.

- *First-bit contribution:* every string has bit $1 = 1$, contributing $2^{k-1}$
 total.
- *Transition contribution at position $i$, $2 \le i \le k$:* we need bit $i = 1
$ and bit $i-1 = 0$.
  - For $i = 2$: this requires bit $1 = 0$, impossible since bit $1 = 1$. Contri
bution $0$.
  - For $i \ge 3$: fix bit $i = 1$, bit $i-1 = 0$; the remaining $k-3$ free posi
tions each take $0$ or $1$, giving $2^{k-3}$ strings. There are $k-2$ such posit
ions ($i = 3,\dots,k$).

So for $k \ge 3$:
$$T(k) = 2^{k-1} + (k-2)\cdot 2^{k-3}.$$
For $k=1$: $T(1)=1$ (only "$1$"). For $k=2$: $T(2)=2$ (strings "$10$","$11$", ea
ch with $B=1$), matching $2^1 + 0$.

**Verification on small cases.**
- $k=3$: strings $100,101,110,111$ have $B$-values $1,2,1,1$, sum $5$. Formula:
$4 + 1\cdot1 = 5$. ✓
- $k=4$: $B$-values $1,2,2,2,1,2,1,1$, sum $12$. Formula: $8 + 2\cdot2 = 12$. ✓
- $k=5$: summing all $16$ strings gives $28$. Formula: $16 + 3\cdot4 = 28$. ✓

**Computing the total.**

| $k$ | $T(k) = 2^{k-1}+(k-2)2^{k-3}$ | Value |
|-----|-------------------------------|-------|
| 1 | — | 1 |
| 2 | — | 2 |
| 3 | $4 + 1\cdot 1$ | 5 |
| 4 | $8 + 2\cdot 2$ | 12 |
| 5 | $16 + 3\cdot 4$ | 28 |
| 6 | $32 + 4\cdot 8$ | 64 |
| 7 | $64 + 5\cdot 16$ | 144 |
| 8 | $128 + 6\cdot 32$ | 320 |

$$B(1)+B(2)+\cdots+B(255) = 1+2+5+12+28+64+144+320 = \boxed{576}.$$
