Let $S = x+y+z$, $p = xy+yz+zx$, $q = xyz$, and $P_k = x^k+y^k+z^k$. Define
$$a_k = \frac{x^k}{y+z}+\frac{y^k}{z+x}+\frac{z^k}{x+y} = \sum_i \frac{x_i^k}{S-
x_i},$$
so $a_1=9,\ a_2=64,\ a_3=488$. Also let $T = \sum_i \frac{1}{S-x_i}$.

**Partial-fraction recursion.** Since $x^k = (x-S)\bigl(x^{k-1}+Sx^{k-2}+\cdots+
S^{k-1}\bigr)+S^k$,
$$\frac{x^k}{S-x} = -\sum_{j=0}^{k-1} S^{k-1-j}x^j + \frac{S^k}{S-x}.$$
Summing over $x,y,z$ (with $P_0=3$):
$$a_k = -\sum_{j=0}^{k-1} S^{k-1-j}P_j + S^k T.$$

**$k=1$:** $a_1 = -P_0 + ST = -3 + ST = 9$, so $ST = 12$.

**$k=2$:** $a_2 = -(SP_0 + P_1) + S^2T = -(3S+S)+S^2T = -4S+S^2T$. Using $S^2T =
 12S$: $a_2 = 8S = 64$, hence
$$S = 8,\qquad T = \tfrac{12}{8} = \tfrac{3}{2}.$$

**$k=3$:** $a_3 = -(S^2P_0+SP_1+P_2)+S^3T = -(4S^2+P_2)+S^3T$. With $S^3T = S^2\
cdot ST = 64\cdot 12 = 768$ and $P_2 = S^2-2p = 64-2p$:
$$488 = -(256+64-2p)+768 = 448+2p \implies p = 20.$$

**Finding $q$.** Now
$$T = \frac{1}{y+z}+\frac{1}{z+x}+\frac{1}{x+y} = \frac{(z+x)(x+y)+(y+z)(x+y)+(y
+z)(z+x)}{(y+z)(z+x)(x+y)}.$$
Numerator $= (x^2+y^2+z^2)+3(xy+yz+zx) = (S^2-2p)+3p = S^2+p = 64+20 = 84$.
Denominator $= (S-x)(S-y)(S-z) = S^3-S^3+Sp-q = Sp-q = 160-q$.
So $T = \dfrac{84}{160-q} = \dfrac{3}{2}$, giving $168 = 480-3q$, hence
$$q = 104.$$

**Target quantity.**
$$\frac{x}{yz}+\frac{y}{zx}+\frac{z}{xy} = \frac{x^2+y^2+z^2}{xyz} = \frac{P_2}{
q} = \frac{S^2-2p}{q} = \frac{64-40}{104} = \frac{24}{104} = \frac{3}{13}.$$

Thus $m=3,\ n=13$, with $\gcd(3,13)=1$, and
$$\boxed{m+n = 16}.$$
