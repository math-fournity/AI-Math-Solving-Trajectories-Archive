# Problem

In a specialized logistics warehouse, every package is assigned a unique three-digit identification code ranging from 100 to 999. To optimize the sorting process, the warehouse manager has defined a "Digital Sync" rule between a package’s full code and its internal contents.

A package is considered "Synced" if the numeric value of its contents represents a suffix of its identification code. Specifically, the value of the contents must be obtainable by erasing zero, one, or two digits from the leftmost side of the three-digit identification code. For example, if a package code is 329, it is Synced if its content value is 329, 29, or 9.

The manager has further stipulated a strict "Product Rule" for the contents: the value of the contents inside any package must be exactly equal to the product of the three individual digits that make up the package's identification code.

Based on these specific rules, how many distinct three-digit identification codes are "Synced"?
