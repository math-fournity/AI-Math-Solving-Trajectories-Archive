## Solution

We evaluate
$$I = \int_{-\infty}^{\infty} \frac{\sin^2(\pi R x)}{R(\pi x)^2}\,dx, \qquad R>0
.$$

**Step 1: Substitution.** Let $t = \pi R x$, so $x = t/(\pi R)$ and $dx = dt/(\p
i R)$. Then
- $\sin(\pi R x) = \sin t$,
- $\pi x = \pi\cdot \frac{t}{\pi R} = \frac{t}{R}$, hence $(\pi x)^2 = \frac{t^2
}{R^2}$.

The denominator becomes $R\cdot \frac{t^2}{R^2} = \frac{t^2}{R}$, so the integra
nd is
$$\frac{\sin^2 t}{t^2/R} = \frac{R\sin^2 t}{t^2}.$$

Therefore
$$I = \int_{-\infty}^{\infty}\frac{R\sin^2 t}{t^2}\cdot\frac{dt}{\pi R} = \frac{
1}{\pi}\int_{-\infty}^{\infty}\frac{\sin^2 t}{t^2}\,dt.$$

**Step 2: The classical integral.** We compute $J = \int_{-\infty}^{\infty}\frac
{\sin^2 t}{t^2}\,dt$.

Using the identity $\sin^2 t = \frac{1-\cos(2t)}{2}$,
$$J = \int_{-\infty}^{\infty}\frac{1-\cos(2t)}{2t^2}\,dt.$$

Substitute $u = 2t$, $dt = du/2$, $t^2 = u^2/4$:
$$J = \int_{-\infty}^{\infty}\frac{1-\cos u}{2\cdot u^2/4}\cdot\frac{du}{2} = \i
nt_{-\infty}^{\infty}\frac{1-\cos u}{u^2}\,du.$$

**Step 3: Integration by parts.** Set $f = 1-\cos u$ and $g' = 1/u^2$, so $f' =
\sin u$ and $g = -1/u$. Then
$$\int_{-\infty}^{\infty}\frac{1-\cos u}{u^2}\,du = \left[-\frac{1-\cos u}{u}\ri
ght]_{-\infty}^{\infty} + \int_{-\infty}^{\infty}\frac{\sin u}{u}\,du.$$

The boundary term vanishes since $|1-\cos u|\le 2$ is bounded while $1/u\to 0$ a
s $|u|\to\infty$. Hence
$$J = \int_{-\infty}^{\infty}\frac{\sin u}{u}\,du = \pi,$$

where the Dirichlet integral $\int_{-\infty}^{\infty}\frac{\sin u}{u}\,du = \pi$
 is standard (obtained, e.g., by contour integration or by differentiating $\int
_0^\infty e^{-su}\frac{\sin u}{u}\,du = \arctan(1/s)$ and taking $s\to 0^+$).

**Step 4: Conclusion.**
$$I = \frac{1}{\pi}\,J = \frac{1}{\pi}\cdot\pi = 1.$$

$$\boxed{\displaystyle\int_{-\infty}^{\infty} \frac{\sin^2(\pi R x)}{R(\pi x)^2}
\,dx = 1 \quad \text{for all } R>0.}$$
