## Proof

**Step 1: Simplify the exponents.**

Compute $\binom{n-i}{2}-\binom{n}{2}$:
$$\binom{n-i}{2}-\binom{n}{2} = \frac{(n-i)(n-i-1)-n(n-1)}{2} = \frac{-2ni+i^2+i
}{2} = \frac{i(i+1-2n)}{2}.$$

Also $\binom{i}{2}=\frac{i(i-1)}{2}$. So each summand is
$$T(i)=\binom{n}{i}\,3^{\frac{i(i+1-2n)}{2}}\,2^{\frac{i(i-1)}{2}}.$$

**Step 2: Combine the exponential factors.**

Taking logarithms of the $3^{\cdot}2^{\cdot}$ part:
$$\frac{i(i+1-2n)}{2}\ln 3+\frac{i(i-1)}{2}\ln 2=\frac{i}{2}\bigl[i\ln 6+\ln\tfr
ac{3}{2}-2n\ln 3\bigr].$$

**Step 3: Key inequality.** For every $1\le i\le n-1$ (so $i\le n$):

$$i\ln 6 \le n\ln 6,$$

hence
$$i\ln 6-2n\ln 3 \le n\ln 6-2n\ln 3 = n\ln\tfrac{2}{3}=-n\ln\tfrac{3}{2}.$$

Therefore
$$\frac{i}{2}\bigl[i\ln 6+\ln\tfrac{3}{2}-2n\ln 3\bigr]\le\frac{i}{2}\bigl[-n\ln
\tfrac{3}{2}+\ln\tfrac{3}{2}\bigr]=-\frac{i(n-1)}{2}\ln\frac{3}{2}.$$

Exponentiating:
$$3^{\frac{i(i+1-2n)}{2}}\,2^{\frac{i(i-1)}{2}}\le\left(\frac{3}{2}\right)^{-i(n
-1)/2}.$$

**Step 4: Bound the sum.** Using $\binom{n}{i}\le\frac{n^i}{i!}$:

$$S_n\le\sum_{i=1}^{n-1}\frac{n^i}{i!}\left(\frac{3}{2}\right)^{-i(n-1)/2}=\sum_
{i=1}^{n-1}\frac{1}{i!}\left(\frac{n}{(3/2)^{(n-1)/2}}\right)^i.$$

Set $r_n=\dfrac{n}{(3/2)^{(n-1)/2}}$. Then

$$S_n\le\sum_{i=1}^{n-1}\frac{r_n^i}{i!}\le\sum_{i=1}^{\infty}\frac{r_n^i}{i!}=e
^{r_n}-1.$$

**Step 5: Show $r_n\to 0$.** We have $r_n = n\cdot(2/3)^{(n-1)/2}$. Since $(2/3)
^{(n-1)/2}$ decays exponentially while $n$ grows polynomially, $r_n\to 0$ as $n\
to\infty$.

Consequently $e^{r_n}-1\to 0$, and since $S_n\ge 0$, by the squeeze theorem:

$$\boxed{S_n\to 0\quad\text{as }n\to\infty.}$$

More precisely, $S_n=O\!\left(n\cdot(2/3)^{(n-1)/2}\right)$, so the sum decays t
o **zero** exponentially fast.
