## Solution

We solve $(x^2+1)y'' + xy' - y = 0$.

**Step 1: Find a simple solution by inspection.**

Try $y = x$. Then $y' = 1$, $y'' = 0$, and
$$(x^2+1)\cdot 0 + x\cdot 1 - x = 0. \checkmark$$
So $y_1 = x$ is a solution.

**Step 2: Reduction of order.** Set $y = x\,v(x)$. Then
$$y' = v + xv', \qquad y'' = 2v' + xv''.$$

Substituting:
$$(x^2+1)(2v' + xv'') + x(v + xv') - xv = 0.$$

The $v$ terms cancel ($xv - xv = 0$), leaving
$$x(x^2+1)v'' + \bigl(2(x^2+1) + x^2\bigr)v' = 0,$$
$$x(x^2+1)v'' + (3x^2+2)v' = 0.$$

Let $w = v'$:
$$x(x^2+1)\,w' + (3x^2+2)\,w = 0,$$
$$\frac{dw}{w} = -\frac{3x^2+2}{x(x^2+1)}\,dx.$$

**Step 3: Partial fractions.**
$$\frac{3x^2+2}{x(x^2+1)} = \frac{2}{x} + \frac{x}{x^2+1},$$
since $3x^2+2 = 2(x^2+1) + x^2$.

Integrating:
$$\ln|w| = -2\ln|x| - \tfrac{1}{2}\ln(x^2+1),$$
$$w = \frac{C}{x^2\sqrt{x^2+1}}.$$

**Step 4: Integrate to recover $v$.**
$$v = C\int \frac{dx}{x^2\sqrt{x^2+1}}.$$

Use $x = \tan\theta$, $dx = \sec^2\theta\,d\theta$, $\sqrt{x^2+1}=\sec\theta$:
$$\int \frac{\sec^2\theta}{\tan^2\theta\,\sec\theta}\,d\theta = \int \frac{\cos\
theta}{\sin^2\theta}\,d\theta = -\csc\theta = -\frac{\sqrt{x^2+1}}{x}.$$

Hence
$$v = -C\,\frac{\sqrt{x^2+1}}{x} + D,$$
$$y = xv = -C\sqrt{x^2+1} + Dx.$$

**Step 5: Verification of $y_2 = \sqrt{x^2+1}$.**
$$y_2' = \frac{x}{\sqrt{x^2+1}}, \qquad y_2'' = \frac{1}{(x^2+1)^{3/2}}.$$
$$(x^2+1)\cdot\frac{1}{(x^2+1)^{3/2}} + x\cdot\frac{x}{\sqrt{x^2+1}} - \sqrt{x^2
+1} = \frac{1+x^2}{\sqrt{x^2+1}} - \sqrt{x^2+1} = 0. \checkmark$$

**General solution:**
$$\boxed{y = c_1\, x + c_2\,\sqrt{x^2+1}}$$

where $c_1, c_2$ are arbitrary constants.
