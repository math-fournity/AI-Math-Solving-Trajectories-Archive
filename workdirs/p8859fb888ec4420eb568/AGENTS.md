# Problem

In a specialized logistics center, a technician is tasked with certifying the exact weight of cargo crates. Each crate is guaranteed to have a mass that is a whole number of kilograms, ranging from 1 kg up to a maximum capacity of $n$ kg.

To perform these certifications, the technician uses a traditional mechanical balance scale with two weighing pans. The center provides the technician with a set of exactly four precision weights. These four weights can be placed on either of the two pans (the same pan as the cargo crate or the opposite pan), but the weights cannot be altered or divided in any way.

The technician must be able to determine the exact integer mass of any crate within the range of 1 to $n$ kg by achieving a perfect equilibrium on the scale, using any combination of the four weights and the crate across the two pans.

What is the largest possible value of the integer $n$ such that every integer mass from 1 to $n$ can be uniquely identified using only these four weights?
