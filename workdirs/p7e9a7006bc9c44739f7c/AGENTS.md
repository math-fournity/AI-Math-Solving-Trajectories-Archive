# Problem

In a bustling logistical hub, there are 12 distinct docking bays, numbered sequentially from 1 to 12. There are also 12 unique cargo ships, also numbered 1 through 12. Each ship must be assigned to exactly one docking bay, and each bay can accommodate exactly one ship, creating a complete one-to-one assignment.

The port authority has implemented a strict safety protocol regarding the "assignment offset." To prevent signal interference between ship transponders and bay sensors, the difference between a ship's identification number ($i$) and the number of the bay to which it is assigned ($f(i)$) must never be a multiple of 3. That is, for every ship $i \in \{1, 2, 3, \dots, 12\}$, the value $|f(i) - i|$ (or simply $f(i) - i$) cannot be divisible by 3.

In how many different ways can the port authority assign all 12 ships to the 12 docking bays while satisfying this safety protocol?
