## Analysis of Moves

From position $n$, the legal moves leave a remainder $n-k$ where:
- **Even $k$**: $2 \leq k \leq \lfloor n/2 \rfloor$, so the remainder is in $[\l
ceil n/2 \rceil,\, n-2]$ with the **same parity** as $n$.
- **Odd $k$**: $\lceil n/2 \rceil \leq k \leq n$, so the remainder is in $[0,\,
\lfloor n/2 \rfloor]$ with **opposite parity** to $n$.

The P-positions are $0, 2, 6, 14, \ldots = \{2^m - 2 : m \geq 1\}$.

## Proof that P-positions are exactly $\{p_m = 2^m - 2 : m \geq 1\}$

**Part 1: From $p_m$, every move leads to an N-position.**

Let $n = p_m = 2^m - 2$ (even).

- **Even moves** leave an even number in $[\lceil n/2\rceil, n-2] = [2^{m-1}-1,\
, 2^m-4]$. The P-positions in this range: $p_{m-1} = 2^{m-1}-2 < 2^{m-1}-1$ (bel
ow range) and $p_m = 2^m-2 > 2^m-4$ (above range). No P-position is reachable. ✓

- **Odd moves** leave an odd number in $[0, \lfloor n/2\rfloor] = [0, 2^{m-1}-2]
$. All P-positions are even, so no P-position is reachable. ✓

**Part 2: From any N-position $n$, there exists a move to a P-position.**

Let $n \in (p_m, p_{m+1})$ for some $m \geq 1$, i.e., $2^m - 1 \leq n \leq 2^{m+
1}-3$.

**Case A: $n$ even** (so $2^m \leq n \leq 2^{m+1}-4$).
Set $k = n - p_m = n - (2^m - 2)$. Then $k$ is even, $k \geq 2$, and $k \leq n/2
$ iff $n \leq 2p_m = 2^{m+1}-4$, which holds. This is a valid even move reaching
 $p_m$. ✓

**Case B: $n$ odd** (so $2^m - 1 \leq n \leq 2^{m+1}-3$).
We use an odd move to reach a P-position $p_j \leq n/2$.

- If $n \geq 2^{m+1}-4$ (i.e., $n = 2^{m+1}-3$): take $j = m$. Then $p_m = 2^m -
 2 \leq (2^{m+1}-3)/2 = 2^m - 3/2$. ✓ Set $k = n - p_m = 2^m - 1$ (odd), $k \geq
 n/2$ ✓, $k \leq n$ ✓.

- If $n < 2^{m+1}-4$ (i.e., $n \leq 2^{m+1}-5$): take $j = m-1$ (for $m \geq 2$)
. Then $p_{m-1} = 2^{m-1}-2 \leq n/2$ iff $n \geq 2^m - 4$, which holds since $n
 \geq 2^m - 1$. Set $k = n - p_{m-1}$ (odd), $k \geq n/2$ ✓, $k \leq n$ ✓.

  For $m = 1$: $n = 1$, take $k = 1$ (odd, $1/2 \leq 1 \leq 1$), reaching $p_1 =
 0$. ✓

By the standard theory of impartial games, Parts 1 and 2 together establish that
 the P-positions are exactly $\{2^m - 2 : m \geq 1\}$.
