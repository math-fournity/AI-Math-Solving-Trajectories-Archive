- $|OC_1| = 10$, $\quad |OC_2| = 9$.

The line $y=0$ is tangent to each $\omega_i$, so $C_i$ is at distance $r_i$ from

**Case 1 (same side):** $C_1 = (a, 2)$, $C_2 = (b, 3)$. Then $T_1 = (a,0)$, $T_2

$$X_1 = O + \tfrac{12}{10}(C_1 - O) = \left(\tfrac{6a-h}{5},\; \tfrac{12-k}{5}\r

Computing the chord lengths $X_iT_i$ (with $T_i$ the foot of perpendicular from

$$X_1T_1^2 = \frac{(a-h)^2 + (12-k)^2}{25}, \qquad X_2T_2^2 = \frac{(b-h)^2 + (1
2-k)^2}{9}.$$

Using $(a-h)^2 = 100 - (2-k)^2$ and $(b-h)^2 = 81 - (3-k)^2$:

$$X_1T_1^2 = \frac{240 - 20k}{25} = \frac{4(12-k)}{5}, \qquad X_2T_2^2 = \frac{2

## Case 2 (opposite sides)

$$(b-h)^2 + (12+k)^2 = 216 + 18k = 18(12+k),$$

## Applying the condition $2\,X_1T_1 = X_2T_2$

$$\frac{16(12-k)}{5} = 2(12+k)$$

$$16(12-k) = 10(12+k)$$

$$192 - 16k = 120 + 10k$$

$$72 = 26k \implies k = \frac{36}{13}.$$

## Computing $AB$

$$AB = 2 \cdot \frac{48\sqrt{10}}{13} = \frac{96\sqrt{10}}{13}.$$
