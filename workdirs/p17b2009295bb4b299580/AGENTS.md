# Problem

In a specialized logistics network, a distribution center offers shipping crates of specific capacities. The set of available crate sizes is defined by the formula $S = \{10^n + 1000 : n = 0, 1, 2, \dots\}$. Specifically, the available sizes are crates that can hold $1001, 1010, 1100, 2000, 11000, 101000, \dots$ units. 

An inventory manager needs to fulfill orders by filling them exactly using any combination of these crates. The manager can use as many crates of each size as needed (for example, they could use five crates of size 1001 or a mix of sizes). 

What is the largest total integer quantity of units that cannot be shipped using a combination of these specific crate sizes?
