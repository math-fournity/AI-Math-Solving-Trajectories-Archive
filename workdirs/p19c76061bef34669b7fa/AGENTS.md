# Problem

A high-tech manufacturing plant utilizes 14 independent automated sensors to monitor a critical production line. Each sensor generates a precision calibration value, represented by a random number chosen uniformly and independently from the continuous range of 0.000 to 1.000.

The facility’s data processor organizes these 14 values into seven distinct pairs. For each pair $k = 1, 2, \ldots, 7$, a "stability zone" $I_k$ is defined as the continuous range of values starting at the smaller number of the pair $(a_{2k-1}, a_{2k})$ and ending at the larger number.

The system is considered "synchronized" if there exists at least one specific numerical value that is contained within every single one of the seven stability zones simultaneously.

If the probability that the system is synchronized is expressed as an irreducible fraction $\frac{a}{b}$, calculate the value of $a + b$.
