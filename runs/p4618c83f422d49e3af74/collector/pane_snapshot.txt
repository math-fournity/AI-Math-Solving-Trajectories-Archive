## Proof

**Notation and definitions.** For a map $h: A \to (B, \mathcal{W})$, the *induce
d* (initial) uniform structure on $A$ is the coarsest uniform structure making $
h$ uniformly continuous. It has as a base the sets
$$h_2^{-1}(W) := \{(a,a')\in A^2 : (h(a),h(a'))\in W\}, \qquad W\in\mathcal{W},$
$
where $h_2 = h\times h : A^2\to B^2$.

Applying this to the three maps in the problem:

- **$U'$** (on $Y$, induced by $g: Y\to (Z,U'')$) has base $\bigl\{\,g_2^{-1}(W)
: W\in U''\,\bigr\}$, where $g_2^{-1}(W)=\{(y,y')\in Y^2:(g(y),g(y'))\in W\}$.

- **$U$** (on $X$, induced by $f: X\to (Y,U')$) has base $\bigl\{\,f_2^{-1}(V):
V\in U'\,\bigr\}$, where $f_2^{-1}(V)=\{(x,x')\in X^2:(f(x),f(x'))\in V\}$.

- **$U_1$** (on $X$, induced by $g\circ f: X\to (Z,U'')$) has base $\bigl\{\,(g\
circ f)_2^{-1}(W): W\in U''\,\bigr\}$, where $(g\circ f)_2^{-1}(W)=\{(x,x')\in X
^2:(g(f(x)),g(f(x')))\in W\}$.

**Key observation.** Since $\{g_2^{-1}(W):W\in U''\}$ is a base for $U'$, the co
llection $\{f_2^{-1}(g_2^{-1}(W)):W\in U''\}$ is a base for $U$ (taking the prei
mage under $f_2$ of a base gives a base of the induced structure, because $U'$ i
s a filter: every $V\in U'$ contains some $g_2^{-1}(W)$, so every $f_2^{-1}(V)$
contains $f_2^{-1}(g_2^{-1}(W))$).

**Computation.** For every $W\in U''$:
$$f_2^{-1}\bigl(g_2^{-1}(W)\bigr) = \{(x,x')\in X^2 : (f(x),f(x'))\in g_2^{-1}(W
)\} = \{(x,x')\in X^2 : (g(f(x)),\,g(f(x')))\in W\} = (g\circ f)_2^{-1}(W).$$

Therefore the base $\{f_2^{-1}(g_2^{-1}(W)):W\in U''\}$ of $U$ is *identical* to
 the base $\{(g\circ f)_2^{-1}(W):W\in U''\}$ of $U_1$.

**Conclusion.** $U$ and $U_1$ have the same base, hence they generate the same f
ilter on $X^2$, i.e.,

$$\boxed{U = U_1.}$$

This is the standard composition property of initial uniform structures: taking
the initial structure in two successive steps (first along $g$, then along $f$)
yields the same result as taking it once along the composition $g\circ f$.
