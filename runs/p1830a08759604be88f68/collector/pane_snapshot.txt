## Example: The Right Shift Operator on ℓ²

Let $H = \ell^2(\mathbb{N})$, the Hilbert space of square-summable sequences ove
r $\mathbb{N} = \{1, 2, 3, \dots\}$, with inner product
$$\langle x, y \rangle = \sum_{n=1}^{\infty} x_n \overline{y_n}.$$

Define the **right shift operator** $R: H \to H$ by
$$R(x_1, x_2, x_3, \dots) = (0, x_1, x_2, x_3, \dots).$$

### $R$ is linear

For $x, y \in H$ and scalars $\alpha, \beta$:
$$R(\alpha x + \beta y) = (0,\, \alpha x_1 + \beta y_1,\, \alpha x_2 + \beta y_2
,\, \dots) = \alpha R x + \beta R y.$$

So $R$ is linear.

### $R$ is an isometry

For any $x \in H$:
$$\|R x\|^2 = |0|^2 + \sum_{n=1}^{\infty} |x_n|^2 = \sum_{n=1}^{\infty} |x_n|^2
= \|x\|^2.$$

Hence $\|R x\| = \|x\|$ for all $x$, so $R$ is an isometry. (Equivalently, $R^*
R = I$, since $R$ preserves the inner product: $\langle R x, R y \rangle = \lang
le x, y \rangle$.)

### $R$ is not surjective

Consider the vector $e_1 = (1, 0, 0, \dots) \in H$. Suppose $R x = e_1$ for some
 $x = (x_1, x_2, \dots) \in H$. Then
$$R x = (0, x_1, x_2, \dots) = (1, 0, 0, \dots),$$
which requires $0 = 1$ in the first coordinate — a contradiction. Therefore $e_1
 \notin \operatorname{range}(R)$, and so $R$ is not surjective.

### Conclusion

The right shift operator $R$ on $\ell^2(\mathbb{N})$ is a linear isometry (it pr
eserves the norm of every vector) but is not surjective (its range is the proper
 closed subspace of sequences whose first coordinate is $0$). This gives the des
ired example of a linear operator in infinite dimensions that is an isometry but
 not surjective.
