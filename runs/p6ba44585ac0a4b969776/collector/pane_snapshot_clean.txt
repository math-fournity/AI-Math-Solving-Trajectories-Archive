## Proof

Let $E \subseteq (0,1)$ be the set of numbers whose decimal expansion contains a
 run of 100 consecutive 4's. We prove $m(E) = 1$ by showing $m(E^c) = 0$.

**Handling non-unique expansions.** The set of $x \in (0,1)$ admitting two decim
al expansions (the rationals of the form $k/10^n$) is countable, hence has measu
re $0$. We set it aside; for every other $x$, the non-terminating decimal expans
ion $x = 0.d_1 d_2 d_3 \ldots$ is unique and well-defined.

**Digit blocks.** Partition the digit positions into disjoint blocks of length $
100$:
$$B_k = \{100k+1,\, 100k+2,\, \ldots,\, 100(k+1)\}, \qquad k = 0, 1, 2, \ldots$$

For each $k$, let
$$A_k = \{x : d_i = 4 \text{ for every } i \in B_k\},$$
the set of numbers whose $k$-th block is entirely 4's.

**Measure of each $A_k$.** Specifying the $100$ digits in positions $B_k$ to any
 fixed pattern confines $x$ to a union of intervals of total length $10^{-100}$:
 among the $10^{100}$ equally-likely patterns for those $100$ positions, each co
ntributes measure $10^{-100}$. (This follows from the standard fact that fixing
the first $n$ digits partitions $(0,1)$ into $10^n$ intervals of length $10^{-n}
$; relabeling positions does not change the measure.) Hence
$$m(A_k) = 10^{-100} \quad \text{for every } k.$$

**Independence.** Since the blocks $B_k$ occupy disjoint sets of digit positions
, the events $A_0, A_1, A_2, \ldots$ are independent. Therefore
$$m\!\left(\bigcap_{k=0}^{N-1} A_k^c\right) = \prod_{k=0}^{N-1} m(A_k^c) = \left
(1 - 10^{-100}\right)^N.$$

**Bounding $E^c$.** If $x \in E^c$ (ignoring the countable ambiguous set), then
$x$ has no run of $100$ consecutive 4's anywhere, so in particular none of the d
isjoint blocks $B_k$ is all-4's. Thus for every $N$,
$$E^c \;\subseteq\; \bigcap_{k=0}^{N-1} A_k^c,$$
and consequently
$$m(E^c) \;\le\; \left(1 - 10^{-100}\right)^N \quad \text{for all } N \ge 1.$$

**Conclusion.** Since $0 < 1 - 10^{-100} < 1$, we have $\left(1 - 10^{-100}\righ
t)^N \to 0$ as $N \to \infty$. Hence
$$m(E^c) = 0, \qquad \text{and therefore} \qquad m(E) = m((0,1)) - m(E^c) = 1 -
0 = 1.$$

The Lebesgue measure of the set of numbers in $(0,1)$ containing $100$ consecuti
ve 4's in their decimal expansion is $\boxed{1}$.
