## Answer

**Yes**, such a set exists. Below is an explicit construction.

---

### Proof

Let $D = \mathbb{R} \setminus \mathbb{Q}$ be the irrationals. $D$ is uncountable
 and dense in $\mathbb{R}$. We will partition $D$ into two disjoint uncountable
dense sets $A$ and $B$. Then setting $S := A$ gives:

- $S = A$ is uncountable and dense, and
- $\mathbb{R} \setminus S = \mathbb{Q} \cup B$, which is **uncountable** (it con
tains $B$) and **dense** (it contains $\mathbb{Q}$, which is dense).

It remains to partition $D$ into two disjoint uncountable dense sets.

**Step 1: Two disjoint countable dense subsets of $D$.**

Let $\{U_n\}_{n \geq 1}$ be a countable base for $\mathbb{R}$ (e.g., all open in
tervals with rational endpoints). We recursively pick points
$$a_n \in U_n \cap D \setminus \{a_1,\dots,a_{n-1},\, b_1,\dots,b_{n-1}\},$$
$$b_n \in U_n \cap D \setminus \{a_1,\dots,a_n,\, b_1,\dots,b_{n-1}\}.$$
This is always possible because every nonempty open interval contains uncountabl
y many irrationals, so removing finitely many points from $U_n \cap D$ leaves it
 nonempty. Set
$$D_A = \{a_n : n \geq 1\}, \qquad D_B = \{b_n : n \geq 1\}.$$
Then $D_A$ and $D_B$ are countable, disjoint, and each is dense in $\mathbb{R}$
(since $a_n \in U_n \cap D_A$ and $b_n \in U_n \cap D_B$ for every $n$).

**Step 2: Split the remainder.**

The set $D \setminus (D_A \cup D_B)$ has cardinality $\mathfrak{c}$ (the continu
um), since $|D| = \mathfrak{c}$ and we removed only countably many points. Becau
se $\mathfrak{c} = \mathfrak{c} + \mathfrak{c}$, there exists a partition of $D
\setminus (D_A \cup D_B)$ into two disjoint sets $R_A, R_B$, each of cardinality
 $\mathfrak{c}$.

**Step 3: Define $A$ and $B$.**

Set
$$A = D_A \cup R_A, \qquad B = D_B \cup R_B.$$
Then:
- $A \cap B = \emptyset$ and $A \cup B = D$;
- $A$ is **dense** (it contains the dense set $D_A$) and **uncountable** (it con
tains $R_A$, of cardinality $\mathfrak{c}$);
- $B$ is **dense** (it contains the dense set $D_B$) and **uncountable** (it con
tains $R_B$, of cardinality $\mathfrak{c}$).

**Conclusion.** Taking $S = A$, we obtain an uncountable dense subset of $\mathb
b{R}$ whose complement $\mathbb{R} \setminus S = \mathbb{Q} \cup B$ is also unco
untable and dense. $\blacksquare$
