**Theorem.** The sharp bound is $n$: a graph $G$ on $n \geq 3$ vertices is Hamil
tonian if $\deg u + \deg v \geq n$ for every pair of nonadjacent vertices, and t
he constant $n$ cannot be lowered.

**Part 1 — Sufficiency of $n$ (Ore's Theorem).**

Suppose $G$ satisfies $\deg u + \deg v \geq n$ for all nonadjacent pairs. Add ed
ges one at a time to $G$ as long as the graph remains non-Hamiltonian, obtaining
 a maximal non-Hamiltonian supergraph $G'$. Since adding edges only increases de
grees, $G'$ still satisfies the degree-sum condition.

Let $u, v$ be a nonadjacent pair in $G'$. By maximality, $G' + uv$ contains a Ha
miltonian cycle, so $G'$ contains a Hamiltonian path
$$u = v_1, v_2, \dots, v_n = v.$$

Define
$$S = \{v_i : v_1 v_{i+1} \in E(G'),\; 1 \leq i \leq n-1\}, \qquad T = \{v_i : v
_i v_n \in E(G'),\; 1 \leq i \leq n-1\}.$$

Then $|S| = \deg_{G'}(v_1) = \deg_{G'}(u)$ and $|T| = \deg_{G'}(v_n) = \deg_{G'}
(v)$.

**Claim:** $S \cap T = \emptyset$. If some $v_i \in S \cap T$, then $v_1 v_{i+1}
$ and $v_i v_n$ are both edges, yielding the Hamiltonian cycle
$$v_1 v_{i+1} v_{i+2} \cdots v_n v_i v_{i-1} \cdots v_2 v_1,$$
contradicting that $G'$ is non-Hamiltonian.

Since $S, T \subseteq \{v_1, \dots, v_{n-1}\}$ are disjoint:
$$|S| + |T| \leq n - 1.$$

But $|S| + |T| = \deg(u) + \deg(v) \geq n$, a contradiction. Therefore $G'$ (and
 hence $G$) is Hamiltonian. $\square$

**Part 2 — Sharpness: $n-1$ is not sufficient.**

For $n \geq 4$, set $a = 1, b = n - 2$ (so $a + b + 1 = n$) and consider
$$G = K_1 \vee (K_a \cup K_b),$$
i.e., a universal vertex $w$ joined to every vertex of two disjoint cliques $K_a
$ and $K_b$ with no edges between the cliques. Concretely, $G$ consists of verte
x $w$ adjacent to all others, a single vertex $x$ (the $K_1$), and a clique $K_{
n-2}$ on the remaining vertices, with $x$ adjacent only to $w$.

**Degree-sum check.** The only nonadjacent pairs are $(x, y)$ with $y \in K_{n-2
}$:
$$\deg(x) = 1 \quad (\text{only } w), \qquad \deg(y) = (n-3) + 1 = n-2 \quad (n-
3 \text{ in } K_{n-2} \text{ plus } w).$$
$$\deg(x) + \deg(y) = 1 + (n-2) = n - 1.$$

So the condition $\deg u + \deg v \geq n-1$ holds for every nonadjacent pair (wi
th equality).

**Non-Hamiltonicity.** The vertex $w$ is a cut vertex: $G - w$ consists of the i
solated vertex $x$ and the clique $K_{n-2}$, which is disconnected. A Hamiltonia
n graph cannot have a cut vertex (deleting any vertex from a Hamiltonian cycle l
eaves a Hamiltonian path, which is connected). Hence $G$ is not Hamiltonian.

This shows the bound cannot be lowered below $n$. $\square$

**Conclusion.** The sharp bound is $n$: the condition $\deg u + \deg v \geq n$ f
or all nonadjacent pairs is both sufficient (by Ore's theorem) and best possible
 (the graph $K_1 \vee (K_1 \cup K_{n-2})$ satisfies the condition with bound $n-
1$ but is not Hamiltonian). The bound $n-1$ stated in the problem is not suffici
