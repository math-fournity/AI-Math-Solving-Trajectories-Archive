## Setup

The playing field is $\{(i,j) : 1 \le j \le i \le n\}$. A selection assigns to e
ach column $j$ a row $f(j) \ge j$. The student knows the row sums $r_i = |\{j :
f(j)=i\}|$ and that each column has exactly one selected cell.

Two functions have the same row sums iff they have the same **multiset** of valu
es. So $f$ is a Master Sudoku iff it is the *unique* function $g$ with $g(j)\ge
j$ having the same value-multiset as $f$.

## Counting functions with a given multiset

Given a multiset $M=\{a_1\le\cdots\le a_n\}$, count functions $f$ with $f(j)\ge
j$ and value-multiset $M$. Process values smallest-to-largest: the $k$-th smalle
st $a_k$ goes to some unused column $\le a_k$. Since the previous $k-1$ values a
re all $\le a_k$ (hence placed in columns $\le a_k$), there are $a_k-k+1$ choice
s. This counts **labeled** assignments; dividing by $\prod_v m_v!$ for repeated
values:

$$N(M)=\frac{\prod_{k=1}^n(a_k-k+1)}{\prod_v m_v!}$$

(valid when $a_k\ge k$ for all $k$; otherwise $N(M)=0$). $M$ is a Master Sudoku
multiset iff $N(M)=1$.

## Characterizing $N(M)=1$

Group sorted values into maximal runs: group $i$ has value $v_i$, size $m_i$, oc
cupying positions $k_i,\ldots,k_i+m_i-1$ (consecutive, $k_1=1$, $k_{i+1}=k_i+m_i
$).

Group $i$ contributes to the numerator:
$$\prod_{j=0}^{m_i-1}(v_i-k_i+1-j)=\frac{(v_i-k_i+1)!}{(v_i-k_i+1-m_i)!}=\binom{
v_i-k_i+1}{m_i}\cdot m_i!$$

The condition $N(M)=1$ becomes $\prod_i \binom{v_i-k_i+1}{m_i}=1$. Since each $\
binom{v_i-k_i+1}{m_i}\ge 1$ (as $v_i-k_i+1\ge m_i$ for validity), equality holds
 iff **each** $\binom{v_i-k_i+1}{m_i}=1$, i.e.:

$$v_i - k_i + 1 = m_i \quad\Longleftrightarrow\quad v_i = k_i + m_i - 1.$$

**Interpretation:** The value of each group equals the **last position** it occu
pies. The groups partition $\{1,\ldots,n\}$ into consecutive intervals $[k_i,\,
k_i+m_i-1]$, and the group's value is the right endpoint $k_i+m_i-1$.

## Counting partitions

Each such partition is determined by choosing which of the $n-1$ gaps between co
nsecutive positions are boundaries. This gives $2^{n-1}$ partitions.

**Validity check:** For position $k$ in interval $[k_i, v_i]$, the value is $v_i
 \ge k$, so $a_k\ge k$ holds automatically. Since $N(M)=1>0$, a valid function e
xists and is unique. Different partitions yield different multisets (hence diffe
rent functions), since the multiset is determined by the partition.

## Verification

- **$n=1$:** $\{1\}$, answer $2^0=1$. ✓
- **$n=2$:** $\{1,2\}$ (identity) and $\{2,2\}$ (both in row 2), answer $2^1=2$.
 ✓
- **$n=3$:** $\{1,2,3\},\{1,3,3\},\{2,2,3\},\{3,3,3\}$ — all give $N=1$; $\{2,3,
3\}$ gives $N=2$ (functions $(2,3,3)$ and $(3,2,3)$ collide). Answer $2^2=4$. ✓
- **$n=4$:** $2^3=8$ partitions, e.g. $\{2,2,4,4\}$: numerator $=2\cdot1\cdot2\c
dot1=4$, denominator $=2!\cdot2!=4$, $N=1$. ✓

## Conclusion

The number of Master Sudokus is $\boxed{2^{n-1}}$.
