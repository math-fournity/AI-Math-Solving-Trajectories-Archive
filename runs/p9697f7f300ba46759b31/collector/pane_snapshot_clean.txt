# Solution

We work on $[a,b] = [0,1]$. We construct $f = a + s + j$ and the corresponding m
easure decomposition $\mu_f = \alpha + \sigma + \kappa$, verifying that every co
mponent is nontrivial on every open subinterval of $[0,1]$.

---

## Component $a$ (absolutely continuous)

Set $a(x) = x$ on $[0,1]$.

- **Absolutely continuous:** $a(x) = \int_0^x 1\,dt$, so $a$ is AC with $a' = 1$
 a.e.
- **Nondecreasing:** $a' = 1 > 0$.
- **Nontrivial on every open subinterval:** For any $(c,d) \subset [0,1]$, $a(d)
 - a(c) = d - c > 0$.

The associated Lebesgue-Stieltjes measure is $\mu_a = \lambda|_{[0,1]}$ (Lebesgu
e measure restricted to $[0,1]$), since $\mu_a((c,d]) = d - c = \lambda((c,d])$.
 Set $\alpha := \mu_a$. Then $\alpha \ll \lambda$ and $\alpha(U) = \lambda(U) >
0$ for every open subinterval $U$.

---

## Component $s$ (continuous, singular, strictly increasing)

**Construction of a singular continuous measure with full support.**

1. **Enumerate the rationals:** Let $\{q_1, q_2, q_3, \ldots\} = \mathbb{Q} \cap
 (0,1)$.

2. **Place a Cantor set near each rational:** For each $k \geq 1$, choose $\vare
psilon_k > 0$ small enough that $[q_k - \varepsilon_k,\, q_k + \varepsilon_k] \s
ubset (0,1)$ (possible since $q_k \in (0,1)$). Perform the standard middle-third
s Cantor construction inside $[q_k - \varepsilon_k,\, q_k + \varepsilon_k]$ to o
btain a Cantor set $C_k$. Each $C_k$ is perfect, nowhere dense, and $\lambda(C_k
) = 0$.

3. **Cantor measure on each $C_k$:** Let $\mu_k$ be the Cantor measure on $C_k$
— the unique non-atomic probability measure supported on $C_k$, defined by assig
ning mass $1/2$ to the left and right subintervals at each stage of the Cantor c
onstruction. Then $\mu_k(C_k) = 1$, $\mu_k$ is non-atomic, and $\operatorname{su
pp}(\mu_k) = C_k$.

4. **Combine:** Define
$$\sigma = \sum_{k=1}^{\infty} 2^{-k}\, \mu_k.$$
This is a finite Borel measure with $\sigma([0,1]) = \sum_{k=1}^\infty 2^{-k} =
1$.

**Verification of properties:**

- **Non-atomic (hence $s$ is continuous):** For any $x \in [0,1]$,
$$\sigma(\{x\}) = \sum_{k=1}^{\infty} 2^{-k}\, \mu_k(\{x\}) = 0,$$
since each $\mu_k$ is non-atomic. Thus $s(x) := \sigma([0,x])$ is continuous.

- **Singular ($\sigma \perp \lambda$):** Set $E = \bigcup_{k=1}^{\infty} C_k$. T
hen $\lambda(E) \leq \sum_k \lambda(C_k) = 0$, so $\lambda(E) = 0$. On the other
 hand,
$$\sigma(E) = \sum_{k=1}^{\infty} 2^{-k}\, \mu_k(E) \geq \sum_{k=1}^{\infty} 2^{
-k}\, \mu_k(C_k) = \sum_{k=1}^{\infty} 2^{-k} = 1.$$
So $\sigma(E) = 1$ and $\lambda(E) = 0$, giving $\sigma \perp \lambda$.

- **Full support (hence $s$ is strictly increasing):** Each $C_k$ is a nonempty
perfect set contained in $(q_k - \varepsilon_k,\, q_k + \varepsilon_k)$. Since $
\{q_k\}$ is dense in $[0,1]$, the set $E = \bigcup_k C_k$ is dense in $[0,1]$. T
he support of $\sigma$ is the smallest closed set $F$ with $\sigma(F^c) = 0$; si
nce $\sigma$ is concentrated on $E$ and $\overline{E} = [0,1]$, we get $\operato
rname{supp}(\sigma) = [0,1]$. Therefore $\sigma(U) > 0$ for every open subinterv
al $U \subset [0,1]$, and $s(x) = \sigma([0,x])$ is strictly increasing.

Define $s(x) = \sigma([0,x])$. Then $s$ is continuous, strictly increasing, and
singular — nontrivial on every open subinterval.

*(Remark: The Minkowski question mark function $?(x)$, defined via continued fra
ctions, provides an alternative explicit example: it is continuous, strictly inc
reasing, and $?'(x) = 0$ a.e., hence singular.)*

## Component $j$ (pure jump)

Let $\{r_n\}_{n=1}^{\infty}$ be an enumeration of $\mathbb{Q} \cap [0,1]$. Defin
e
$$j(x) = \sum_{\{n \,:\, r_n \leq x\}} 2^{-n}.$$

**Properties:**

- **Pure jump function:** $j$ is a right-continuous step function with a jump of
 size $2^{-n}$ at each point $r_n$. The total variation is $\sum_{n=1}^{\infty}
2^{-n} = 1 < \infty$, so $j$ is bounded and well-defined. Between consecutive ju
mp points, $j$ is constant.

- **Nondecreasing:** Each summand $2^{-n} \cdot \mathbf{1}_{\{r_n \leq x\}}$ is
nondecreasing, so $j$ is nondecreasing.

- **Nontrivial on every open subinterval:** Every open subinterval $U \subset [0
,1]$ contains some rational $r_n$, hence contains a jump point of $j$. So $j$ is
 nonconstant on $U$.

The associated measure is
$$\kappa = \sum_{n=1}^{\infty} 2^{-n}\, \delta_{r_n},$$
a pure atomic measure with atoms $\{r_n\} = \mathbb{Q} \cap [0,1]$. Every open s
ubinterval contains an atom, so $\kappa(U) > 0$ for every open subinterval $U$.

---

## The function $f$ and its decomposition

Define
$$f(x) = a(x) + s(x) + j(x) = x + s(x) + j(x).$$

Since $a$, $s$, and $j$ are each nondecreasing and right-continuous on $[0,1]$,
so is $f$, and the Lebesgue-Stieltjes measure decomposes as:
$$\mu_f = \mu_a + \mu_s + \mu_j = \alpha + \sigma + \kappa,$$

where:
- $\alpha = \mu_a = \lambda|_{[0,1]}$: $\alpha \ll \lambda$. ✓
- $\sigma = \mu_s$: $\sigma \perp \lambda$ (singular continuous). ✓
- $\kappa = \mu_j = \sum_n 2^{-n}\,\delta_{r_n}$: pure atomic. ✓

---

## Verification of nontriviality on every open subinterval

Let $U \subset [0,1]$ be any open subinterval.

| Component | Function nontrivial? | Measure nontrivial? |
|---|---|---|
| $a(x) = x$ | $a(d)-a(c) = d-c > 0$ for $U=(c,d)$ | $\alpha(U) = \lambda(U) > 0
$ |
| $s(x) = \sigma([0,x])$ | $s$ strictly increasing ⟹ nonconstant on $U$ | $\sigm
a(U) > 0$ (full support) |
| $j(x) = \sum_{r_n \leq x} 2^{-n}$ | $U \cap \mathbb{Q} \neq \emptyset$ ⟹ jump
in $U$ | $\kappa(U) \geq 2^{-n} > 0$ for $r_n \in U$ |

All three functions and all three measures are nontrivial on every open subinter
val of $[0,1]$, as required. $\blacksquare$
