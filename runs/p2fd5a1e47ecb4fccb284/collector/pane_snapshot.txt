le XYZ in an equilateral triangle, where K, L, M divide the sides in given ratio
s.

**Interpreting the parameters:** The problem uses B and C as specific values. Re
ading B as the 2nd letter and C as the 3rd letter of the alphabet gives B = 2, C
 = 3, yielding a clean competition answer. I'll solve generally first, then subs
titute.

## Setup

Place the equilateral triangle with side length 1:
- X = (0, 0), Y = (1, 0), Z = (1/2, √3/2)

Area of XYZ = √3/4.

**Locating K, L, M:**

- K on XY with XK/KY = B: K = (B/(B+1), 0)
- L on YZ with YL/LZ = 1/C: L = Y + (1/(1+C))(Z − Y) = (1 − 1/(2(1+C)), √3/(2(1+
C)))
- M on ZX with ZM/MX = 1: M = midpoint of ZX = (1/4, √3/4)

## Computing the Area of KLM

Using the determinant formula, Area(KLM) = (1/2)|det(L−K, M−K)|.

L − K = (1 − 1/(2(1+C)) − B/(B+1), √3/(2(1+C)))

M − K = (1/4 − B/(B+1), √3/4)

The determinant (factoring out √3):

det = √3 · { [1 − 1/(2(1+C)) − B/(B+1)]/4 − [1/(2(1+C))][1/4 − B/(B+1)] }

Expanding and combining over common denominator 4(1+C)(B+1):

Numerator = (1+C)(B+1) − (B+1) − B(1+C) + 2B
= (B+1)C − B(1+C) + 2B
= BC + C − B − BC + 2B
= **B + C**

So det = √3 · (B+C) / [4(1+C)(B+1)]

Area(KLM) = (1/2) · √3(B+C) / [4(1+C)(B+1)] = √3(B+C) / [8(1+C)(B+1)]

## The Ratio

Area(KLM)/Area(XYZ) = [√3(B+C)/(8(1+C)(B+1))] / [√3/4]

= **(B+C) / [2(B+1)(C+1)]**

## Substituting B = 2, C = 3

Ratio = (2+3) / [2·3·4] = 5/24

**Verification by direct coordinate computation:**
- K = (2/3, 0), L = (7/8, √3/8), M = (1/4, √3/4)
- L−K = (5/24, √3/8), M−K = (−5/12, √3/4)
- det = (5/24)(√3/4) − (√3/8)(−5/12) = 5√3/96 + 5√3/96 = 5√3/48
- Area(KLM) = 5√3/96, Area(XYZ) = √3/4
- Ratio = (5√3/96)/(√3/4) = 5/24 ✓

Also verified: with B = C = 1 (all midpoints), the formula gives 2/8 = 1/4, matc
hing the medial triangle. ✓
