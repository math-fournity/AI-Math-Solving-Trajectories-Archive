## Setup

A Hamiltonian path on 400 cells has **399 steps**. Each step is either *internal
* (within a domino) or *external* (between dominoes). A domino tiling is a perfe
ct matching of the grid graph (200 edges). An internal step corresponds to a pat
h edge that is also a matching edge. So I need to find, over all Hamiltonian pat
hs P and perfect matchings D of the 20×20 grid graph G:

- **M₁₀** = max |E(P) ∩ D|
- **m₁₀** = min |E(P) ∩ D|

## Maximum: M₁₀ = 200

**Upper bound:** Each domino contributes at most 1 internal step (the path visit
s each cell once, so the two cells of a domino can be consecutive at most once).
 With 200 dominoes, M₁₀ ≤ 200.

**Construction achieving 200:** Tile the grid with all horizontal dominoes: {(i,
 2k−1), (i, 2k)} for each row i. Use the **snake (boustrophedon) path**: travers
e row 1 left-to-right, drop to row 2, traverse right-to-left, drop to row 3, etc
.

Within each row, consecutive path cells are exactly the domino pairs, so every d
omino's two cells are consecutive in the path. The 19 inter-row transitions are
external. Total internal = 10 dominoes/row × 20 rows = **200**. ✓

## Minimum: m₁₀ = 2

**Lower bound (≥ 2 for any path):**

The 20×20 grid has **4 corners**, each with degree 2. Any Hamiltonian path has *
*2 endpoints**. At most 2 corners can be endpoints, so **at least 2 corners are
non-endpoint** vertices of the path.

A non-endpoint corner c has both its grid edges used by the path (the path enter
s from one neighbor and exits to the other). Therefore, in G − E(P), the corner
c is **isolated** (degree 0).

An isolated vertex in G − E(P) must be matched using a path edge in any perfect
matching. Since no two corners of a 20×20 grid are adjacent (minimum pairwise di
stance is 19), the ≥2 isolated corners require **≥2 distinct path edges**.

No other vertices can be isolated: degree-3 (edge) and degree-4 (interior) verti
ces have more grid edges than path edges (at most 2), so they always retain non-
path edges.

Thus **m₁₀ ≥ 2** for every Hamiltonian path.

**Construction achieving 2:** Use the snake path P (start at (1,1), end at (20,1
)). The non-endpoint corners are (1,20) and (20,20), both isolated in G − E(P).

Analyze G − E(P): The snake path uses all 380 horizontal edges and 19 vertical "
turn" edges (alternating at columns 20 and 1). So G − E(P) contains only vertica
l edges:
- **Column 1**: 10 remaining vertical edges forming a perfect matching of all 20
 vertices.
- **Columns 2–19**: all 19 vertical edges each, forming paths on 20 vertices (ea
ch has a perfect matching of size 10).
- **Column 20**: 9 remaining vertical edges (a matching of size 9), leaving (1,2
0) and (20,20) unmatched.

Construct the perfect matching D as follows:
- Columns 1–18: use the perfect matching within each column (10 edges each).
- **Column 19**: match (2,19)-(3,19), (4,19)-(5,19), …, (18,19)-(19,19) — 9 edge

- **Path edges**: (1,19)-(1,20) and (19,20)-(20,20) — exactly **2 path edges**.

Verification: 10 + 17×10 + 9 + 9 + 2 = 200 edges total. The 2 path edges match t
he 4 freed vertices perfectly. No conflicts arise since columns 19 and 20's inte

So m₁₀ = 2.
