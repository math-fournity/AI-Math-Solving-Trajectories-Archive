Looking at this problem, I need to determine whether the given conditions force
$X_n \to 0$ almost surely, or whether a counterexample exists.

**Answer: No, $X_n$ does not necessarily converge to $0$ almost surely.**

## Proof by Counterexample

**Construction.** Let $(Y_n)_{n \ge 1}$ be independent Bernoulli random variable
s with $P(Y_n = 1) = p_n = \frac{1}{n}$. We define a process $(X_n)$ with values
 in $\{0, 1\}$ using an auxiliary state variable $S_n \in \{\text{idle}, \text{u
p}\}$:

- Initialize $X_0 = 0$, $S_1 = \text{idle}$.
- **If $S_n = \text{idle}$:** If $Y_n = 1$, set $X_n = 1$ and $S_{n+1} = \text{u
p}$. If $Y_n = 0$, set $X_n = 0$ and $S_{n+1} = \text{idle}$.
- **If $S_n = \text{up}$:** Set $X_n = 0$ and $S_{n+1} = \text{idle}$ (the "tria
ngle" completes; $Y_n$ is ignored).

**Verification of the three conditions.**

**(1) Bounded increments.** Since $X_n \in \{0, 1\}$, the only transitions are $
0 \to 0$, $0 \to 1$, and $1 \to 0$, so $|X_{n+1} - X_n| \le 1$ surely for all $n
$. ✓

**(2) Expectation condition.** Let $q_n = P(S_n = \text{idle})$. The recursion i
s:
$$q_{n+1} = P(S_{n+1} = \text{idle}) = P(S_n = \text{up}) + P(S_n = \text{idle},
\, Y_n = 0) = (1 - q_n) + q_n(1 - p_n) = 1 - q_n p_n.$$
Since $q_n \le 1$, we get $q_{n+1} \ge 1 - p_n$. Now:
$$\mathbb{E}[X_n] = P(X_n = 1) = q_n \cdot p_n \le p_n = \frac{1}{n}.$$
Since $\log n \le n$ for $n \ge e$, we have $\frac{1}{n} \le \frac{1}{\log n}$,
so $\mathbb{E}[X_n] = O(1/\log n)$. ✓

**(3) Variance condition.** Since $X_n \in \{0, 1\}$, we have $X_n^2 = X_n$, so:
$$\text{Var}[X_n] = \mathbb{E}[X_n^2] - (\mathbb{E}[X_n])^2 = \mathbb{E}[X_n](1
- \mathbb{E}[X_n]) \le \mathbb{E}[X_n] \le \frac{1}{n}.$$
Thus $\text{Var}[X_n] = O(1/n)$. ✓

**Non-convergence to $0$ almost surely.**

Define events $B_n = \{Y_{2n} = 1,\; Y_{2n-1} = 0\}$ for $n \ge 1$. Since the ev
ents $B_n$ depend on disjoint pairs of independent random variables $(Y_{2n-1},
Y_{2n})$, the $B_n$ are mutually independent. Their probabilities are:
$$P(B_n) = p_{2n}(1 - p_{2n-1}) = \frac{1}{2n} \cdot \frac{2n-2}{2n-1} \sim \fra
c{1}{2n}.$$
Since $\sum_{n=1}^{\infty} P(B_n) = \infty$, the Borel–Cantelli lemma (second pa
rt, using independence) gives:
$$P(B_n \text{ infinitely often}) = 1.$$

Now, whenever $B_n$ occurs, we have $Y_{2n-1} = 0$. We claim this forces $S_{2n}
 = \text{idle}$:

- If $S_{2n-1} = \text{idle}$ and $Y_{2n-1} = 0$: then $S_{2n} = \text{idle}$ by
 definition.
- If $S_{2n-1} = \text{up}$: then $S_{2n} = \text{idle}$ (the triangle completes
 regardless of $Y_{2n-1}$).

In either case, $S_{2n} = \text{idle}$. Since also $Y_{2n} = 1$, we conclude $X_
{2n} = 1$.

Therefore $X_{2n} = 1$ infinitely often almost surely, which means $X_n$ does **
not** converge to $0$ almost surely. $\blacksquare$
