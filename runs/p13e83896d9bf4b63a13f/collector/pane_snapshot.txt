- ∠BAE = ∠BAC = 50° (given)
- ∠EAD = ∠CAD = 60° (given), so ∠BAD = 110°
- ∠EBC = ∠DBC = 30° (given)
- ∠EDC = ∠BDC = 25° (given)

**Finding all triangle angles at E in terms of x:**

| Triangle | Angles |
|----------|--------|
| △ABE | 50°, x, 130°−x |
| △ADE | 60°, 180°−x, x−60° |
| △BCE | 30°, 180°−x, x−30° |
| △CDE | 25°, x, 155°−x |

(Validity requires 60° < x < 130°, ensuring all angles are positive.)

**Deriving the key equation via the Sine Rule.**

In △ABC: ∠BAC = 50°, ∠ABC = (130°−x)+30° = 160°−x, ∠BCA = x−30°. By the sine rul
e:
$$\frac{AC}{\sin(160°-x)} = \frac{BC}{\sin 50°} \implies AC = \frac{BC\,\sin(160
°-x)}{\sin 50°}$$

In △ACD: ∠CAD = 60°, ∠ADC = (x−60°)+25° = x−35°, ∠ACD = 155°−x. By the sine rule
:
$$\frac{AC}{\sin(x-35°)} = \frac{CD}{\sin 60°} \implies AC = \frac{CD\,\sin(x-35
°)}{\sin 60°}$$

Equating the two expressions for AC:
$$\frac{BC\,\sin(160°-x)}{\sin 50°} = \frac{CD\,\sin(x-35°)}{\sin 60°} \quad (\s
tar)$$

**Finding BC/CD independently.**

In △BCE: $\frac{CE}{\sin 30°} = \frac{BC}{\sin(180°-x)}$, so $CE = \frac{BC\sin
30°}{\sin x}$.

In △CDE: $\frac{CE}{\sin 25°} = \frac{CD}{\sin x}$, so $CE = \frac{CD\sin 25°}{\
sin x}$.

Equating: $BC\sin 30° = CD\sin 25°$, giving:
$$\frac{BC}{CD} = \frac{\sin 25°}{\sin 30°}$$

**Substituting into (⋆):**
$$\frac{\sin 25°}{\sin 30°} \cdot \frac{\sin(160°-x)}{\sin 50°} = \frac{\sin(x-3
5°)}{\sin 60°}$$

Since $\sin 30° = \tfrac{1}{2}$ and $\sin 60° = \tfrac{\sqrt{3}}{2}$, this simpl
ifies to:

$$\sqrt{3}\,\sin 25°\,\sin(160°-x) = \sin 50°\,\sin(x-35°) \quad (\star\star)$$

**Solving the equation.**

Note $\sin(160°-x) = \sin(20°+x)$. I test $x = 95°$:

- **Left side:** $\sqrt{3}\sin 25°\sin 115° = \sqrt{3}\sin 25°\cos 25° = \sqrt{3

- **Right side:** $\sin 50°\sin 60° = \sin 50°\cdot\tfrac{\sqrt{3}}{2} = \tfrac{
\sqrt{3}}{2}\sin 50°$

Both sides are equal. ✓

**Uniqueness.** Define $f(x) = \sqrt{3}\sin 25°\sin(20°+x) - \sin 50°\sin(x-35°)
$. Expanding via angle-addition:

$$f'(x) = \underbrace{[\sqrt{3}\sin 25°\cos 20° - \sin 50°\cos 35°]}_{A}\cos x -
