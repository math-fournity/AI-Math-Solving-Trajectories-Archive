## Proof

Make the substitution
$$a = \frac{x}{x-1},\quad b = \frac{y}{y-1},\quad c = \frac{z}{z-1}.$$
Since $x,y,z\neq 1$, each of $a,b,c$ is well defined. Conversely $x = \frac{a}{a
-1}$ (and similarly for $y,z$), so the substitution is a bijection from $\{x\neq
 1\}$ to $\{a\neq 1\}$; in particular $a,b,c\neq 1$.

The constraint $xyz = 1$ becomes
$$\frac{a}{a-1}\cdot\frac{b}{b-1}\cdot\frac{c}{c-1}=1,$$
i.e.
$$abc = (a-1)(b-1)(c-1).$$

Expanding the right-hand side,
$$(a-1)(b-1)(c-1)=abc-ab-bc-ca+a+b+c-1.$$

Substituting and cancelling $abc$ from both sides gives
$$ab+bc+ca = a+b+c-1. \tag{$\ast$}$$

The desired inequality is $a^2+b^2+c^2 \ge 1$. Using the identity
$$a^2+b^2+c^2 = (a+b+c)^2 - 2(ab+bc+ca),$$
and applying $(\ast)$ with $s = a+b+c$,
$$a^2+b^2+c^2 = s^2 - 2(s-1) = s^2 - 2s + 2 = (s-1)^2 + 1 \ge 1.$$

This completes the proof. (Equality holds exactly when $a+b+c=1$, which is attai
nable, e.g. $a=b=c=\tfrac13$ gives $x=y=z=\tfrac{1}{1-3}\cdot... $ — explicitly
$x=y=z=-\tfrac12$? Let's verify: $a=\frac13 \Rightarrow x = \frac{1/3}{1/3-1}=\f
rac{1/3}{-2/3}=-\frac12$, and $xyz=(-\tfrac12)^3 = -\tfrac18\neq 1$. So that par
ticular triple doesn't satisfy the constraint; the equality condition $a+b+c=1$
must be combined with $(\ast)$. The existence of an equality case is not needed
for the inequality, but one exists: take $a=2, b=2, c=-3$, giving $a+b+c=1$ and
$ab+bc+ca = 4-6-6 = -8 = 1-1-... $ check: $a+b+c-1 = 0$, but $ab+bc+ca = 4-6-6=-
8\neq 0$. So that's not consistent. A consistent equality case: need $a+b+c=1$ a
nd $ab+bc+ca = 0$. E.g. $a=1,b=0,c=0$ gives sum 1, pairwise sum 0, but $a=1$ is
forbidden. Take $a=t, b=t, c=1-2t$; need $ab+bc+ca = t^2 + t(1-2t)+t(1-2t) = t^2
 + 2t-4t^2 = 2t-3t^2 = 0$, so $t=0$ or $t=2/3$. With $t=2/3$: $a=b=2/3, c=-1/3$,
 none equal to 1, sum $=1$, pairwise sum $= 4/9 - 2/9 - 2/9 = 0$ ✓. Then $x = \f
rac{2/3}{-1/3}=-2$, $z=\frac{-1/3}{-4/3}=\frac14$, and $xyz = (-2)(-2)(1/4)=1$ ✓
, with each term $\frac{x^2}{(x-1)^2} = \frac{4}{9}$, summing to $\frac49+\frac4
9+\frac{1}{16}\cdot... $ wait $z^2/(z-1)^2 = (1/16)/(9/16)=1/9$. Sum $= 4/9+4/9+
1/9 = 1$ ✓.)

Thus the bound is sharp and the inequality is proved. $\blacksquare$
