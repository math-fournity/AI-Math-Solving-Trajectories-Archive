## Setup

Let the equilateral triangle have vertices A, B, C with side length 6. Sensors o
n each side are at positions 1–5 km from one endpoint. A beam from a sensor on s
ide BC goes to vertex A, from CA to B, from AB to C — these are **cevians**.

Selecting 4 sensors gives cevians distributed as (a, b, c) from vertices A, B, C
, where a+b+c=4.

## Region Counting Formula

Adding cevians one by one, each new cevian creates (1 + number of distinct inter
ior crossing points with prior cevians) new regions. Cevians from the **same ver
tex** don't intersect interiorly (they only share the vertex). Cevians from **di
fferent vertices** always intersect exactly once inside the triangle.

The general formula is:
$$R = 1 + n + \sum_P (m_P - 1)$$
where $m_P$ is the number of cevians through interior intersection point $P$, an
d $n=4$.

We need $R = 9$, so $\sum_P (m_P - 1) = 4$.

If $t$ triple-concurrence points exist (where $m_P=3$) and $d$ double points ($m
_P=2$):
$$\sum(m_P-1) = 2t + d, \quad \text{total crossing pairs} = 3t + d = ab+ac+bc$$
So $\sum(m_P-1) = (ab+ac+bc) - t = 4$.

$$\frac{k}{6-k}\cdot\frac{j}{6-j}\cdot\frac{i}{6-i} = 1$$
