# Solution

## Setup

We work in polar coordinates $(x^1, x^2) = (r, \theta)$ on $\mathbb{R}^2$ with t
he metric
$$ds^2 = dr^2 + f(r,\theta)\,d\theta^2.$$
The metric components are:
$$g_{rr} = 1, \qquad g_{\theta\theta} = f(r,\theta), \qquad g_{r\theta} = g_{\th
eta r} = 0.$$
The inverse metric is:
$$g^{rr} = 1, \qquad g^{\theta\theta} = \frac{1}{f(r,\theta)}, \qquad g^{r\theta
} = 0.$$

The curve is $\gamma(t) = (t, \theta_0)$ with $\theta_0$ constant, so its coordi
nate tangent is
$$\dot\gamma^r = 1, \qquad \dot\gamma^\theta = 0,$$
which is constant in $t$, hence $\ddot\gamma^k = 0$.

## Covariant derivative formula

For a curve,
$$\bigl(\nabla_{\gamma'}\gamma'\bigr)^k = \ddot\gamma^k + \Gamma^k_{ij}\,\dot\ga
mma^i\,\dot\gamma^j.$$

Since $\dot\gamma^r = 1$ and $\dot\gamma^\theta = 0$, the only surviving term in
 the sum is the one with $i = j = r$:
$$\bigl(\nabla_{\gamma'}\gamma'\bigr)^k = \Gamma^k_{rr}.$$

## Computing $\Gamma^k_{rr}$

The Christoffel symbols are
$$\Gamma^k_{ij} = \tfrac{1}{2}\,g^{kl}\bigl(\partial_i g_{jl} + \partial_j g_{il
} - \partial_l g_{ij}\bigr).$$

Setting $i = j = r$:
$$\Gamma^k_{rr} = \tfrac{1}{2}\,g^{kl}\bigl(2\,\partial_r g_{rl} - \partial_l g_
{rr}\bigr).$$

Now observe:
- $g_{rr} = 1$ is constant, so $\partial_l g_{rr} = 0$ for $l \in \{r, \theta\}$
.
- $g_{r\theta} = 0$ and $g_{rr} = 1$ are both independent of $r$, so $\partial_r
 g_{rl} = 0$ for $l \in \{r, \theta\}$.

Therefore every term inside the parentheses vanishes:
$$\Gamma^k_{rr} = 0 \qquad \text{for } k \in \{r, \theta\}.$$

## Conclusion

$$\bigl(\nabla_{\gamma'(t)}\gamma'(t)\bigr)^r = \Gamma^r_{rr} = 0, \qquad \bigl(
\nabla_{\gamma'(t)}\gamma'(t)\bigr)^\theta = \Gamma^\theta_{rr} = 0.$$

Hence
$$\boxed{\nabla_{\gamma'(t)}\gamma'(t) = 0.}$$

**Geometric interpretation.** The curve $\gamma(t) = (t, \theta_0)$ is a radial
ray with fixed angle $\theta_0$. Since $g_{rr} = 1$, the $r$-coordinate measures
 true arc length along every radial ray, and the vanishing of $\Gamma^k_{rr}$ sh
ows that radial rays are geodesics of this metric. Thus the covariant accelerati
on of $\gamma$ is zero: $\gamma$ is a geodesic parametrized by arc length.
