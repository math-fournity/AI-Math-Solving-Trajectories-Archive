**Goal:** Evaluate $I = \displaystyle\int_0^1 \int_x^1 \frac{f(t)}{t}\,dt\,dx$,
where $f$ is Lebesgue integrable on $[0,1]$ and $\int_0^1 f(t)\,dt = 1$.

**Step 1. Identify the region of integration.**

The iterated integral is over
$$\{(x,t) : 0 \le x \le 1,\; x \le t \le 1\} = \{(x,t) : 0 \le x \le t \le 1\}.$
$

**Step 2. Justify swapping the order of integration (Fubini).**

Set $g(t) = f(t)/t$ and $h(x,t) = g(t)\,\mathbf{1}_{0 \le x \le t \le 1}$. To ap
ply Fubini we verify absolute integrability:
$$\int_0^1\!\!\int_0^1 |h(x,t)|\,dx\,dt = \int_0^1 |g(t)|\left(\int_0^t dx\right
)dt = \int_0^1 t\cdot\frac{|f(t)|}{t}\,dt = \int_0^1 |f(t)|\,dt < \infty,$$
since $f$ is Lebesgue integrable on $[0,1]$. Hence Fubini's theorem applies and
we may swap the order of integration.

**Step 3. Swap and evaluate.**

$$I = \int_0^1 \int_0^t \frac{f(t)}{t}\,dx\,dt = \int_0^1 \frac{f(t)}{t}\cdot t\
,dt = \int_0^1 f(t)\,dt = 1.$$

**Conclusion.** The value of the integral is $\boxed{1}$.
