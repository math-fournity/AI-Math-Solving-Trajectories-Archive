# Surface Area of Revolution of One Arc of a Cycloid

The cycloid is parametrized by
$$x = a(t - \sin t), \qquad y = a(1 - \cos t), \qquad 0 \le t \le 2\pi.$$

**Preliminary: the arc-length element.**
$$\frac{dx}{dt} = a(1-\cos t), \qquad \frac{dy}{dt} = a\sin t,$$
$$ds = \sqrt{a^2(1-\cos t)^2 + a^2\sin^2 t}\,dt = a\sqrt{2-2\cos t}\,dt = a\sqrt
{4\sin^2(t/2)}\,dt = 2a\sin(t/2)\,dt,$$
since $\sin(t/2)\ge 0$ on $[0,2\pi]$. Also note
$$y = a(1-\cos t) = 2a\sin^2(t/2), \qquad 1+\cos t = 2\cos^2(t/2).$$

---

## a) Rotation about the $x$-axis

$$S_x = 2\pi\int y\,ds = 2\pi\int_0^{2\pi} 2a\sin^2(t/2)\cdot 2a\sin(t/2)\,dt =
8\pi a^2\int_0^{2\pi}\sin^3(t/2)\,dt.$$

Substituting $u = t/2$, $dt = 2\,du$:
$$S_x = 16\pi a^2\int_0^{\pi}\sin^3 u\,du = 16\pi a^2\cdot\frac{4}{3} = \boxed{\
dfrac{64\pi a^2}{3}}.$$

---

## b) Rotation about the $y$-axis

$$S_y = 2\pi\int x\,ds = 2\pi\int_0^{2\pi} a(t-\sin t)\cdot 2a\sin(t/2)\,dt = 4\
pi a^2\int_0^{2\pi}(t-\sin t)\sin(t/2)\,dt.$$

With $u = t/2$, $t = 2u$, $dt = 2\,du$, $\sin t = 2\sin u\cos u$:
$$\int_0^{2\pi}(t-\sin t)\sin(t/2)\,dt = \int_0^{\pi}(2u - 2\sin u\cos u)\sin u\
cdot 2\,du$$
$$= 4\int_0^{\pi}u\sin u\,du - 4\int_0^{\pi}\sin^2 u\cos u\,du.$$

The first integral:
$$\int_0^{\pi}u\sin u\,du = \bigl[-u\cos u\bigr]_0^{\pi} + \int_0^{\pi}\cos u\,d
u = \pi + 0 = \pi.$$

The second integral:
$$\int_0^{\pi}\sin^2 u\cos u\,du = \left[\frac{\sin^3 u}{3}\right]_0^{\pi} = 0.$
$

Hence the integral equals $4\pi$, and
$$S_y = 4\pi a^2\cdot 4\pi = \boxed{16\pi^2 a^2}.$$

---

## c) Rotation about the tangent at the highest point

The highest point occurs at $t = \pi$, where $y = 2a$ and $\frac{dy}{dt} = a\sin
\pi = 0$, $\frac{dx}{dt} = 2a \neq 0$. The tangent is therefore the **horizontal
 line** $y = 2a$.

The (perpendicular) distance from a point $(x,y)$ on the curve to this line is
$$2a - y = 2a - a(1-\cos t) = a(1+\cos t) = 2a\cos^2(t/2) \ge 0.$$

Thus
$$S_c = 2\pi\int (2a - y)\,ds = 2\pi\int_0^{2\pi} a(1+\cos t)\cdot 2a\sin(t/2)\,
dt = 4\pi a^2\int_0^{2\pi}(1+\cos t)\sin(t/2)\,dt.$$

Using $1+\cos t = 2\cos^2(t/2)$ and substituting $u = t/2$, $dt = 2\,du$:
$$\int_0^{2\pi}(1+\cos t)\sin(t/2)\,dt = \int_0^{2\pi}2\cos^2(t/2)\sin(t/2)\,dt
= 4\int_0^{\pi}\cos^2 u\sin u\,du.$$
$$= 4\left[-\frac{\cos^3 u}{3}\right]_0^{\pi} = 4\cdot\frac{2}{3} = \frac{8}{3}.
$$

Therefore
$$S_c = 4\pi a^2\cdot\frac{8}{3} = \boxed{\dfrac{32\pi a^2}{3}}.$$

---

**Summary.**
- (a) about the $x$-axis: $\dfrac{64\pi a^2}{3}$
- (b) about the $y$-axis: $16\pi^2 a^2$
- (c) about the tangent at the highest point: $\dfrac{32\pi a^2}{3}$
