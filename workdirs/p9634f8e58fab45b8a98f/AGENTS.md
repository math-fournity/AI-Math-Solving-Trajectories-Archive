# Problem

A specialized logistics company uses three-digit identification codes for its shipping containers. The company only uses "Type-A" containers, which are defined by a specific symmetric security sequence: the first digit must be 1, the third digit must be 1, and the middle digit $a$ can be any integer from 0 to 9.

A technician is tasked with pairing these containers for a weight-loading test. A pair consists of two Type-A containers (note that a container can be paired with another of the same middle digit). The technician defines a "Stable Pair" as any two Type-A containers whose identification codes, when added together, result in a sum that is a palindrome (a number that reads the same forwards and backwards).

How many distinct ordered pairs of Type-A containers $(1a1, 1b1)$ are there such that their sum is a palindrome?
