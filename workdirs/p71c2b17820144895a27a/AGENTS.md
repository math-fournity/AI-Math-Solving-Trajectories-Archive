# Problem

A high-security data vault uses a biometric authentication sequence consisting of a set $S$ of 10 distinct identification codes. Within this specific set, exactly 7 codes are classified as "Standard Access" (represented by real numbers), while the remaining 3 are "Enhanced Access" (represented by non-real complex numbers).

To verify a user, the system applies a transformation function in the form of a quadratic polynomial $f(z) = az^2 + bz + c$ with complex coefficients. A transformation is considered a "Permutation Key" if, when applied to every individual code in the set $S$, the resulting set of outputs is identical to the original set $S$ (i.e., the function maps the set to itself, $f(S) = S$).

Given the specific composition of the set $S$, what is the maximum possible number of distinct quadratic polynomials $N$ that can serve as Permutation Keys?
