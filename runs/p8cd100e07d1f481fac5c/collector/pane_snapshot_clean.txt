## Setup

The grid has m+1 horizontal and n+1 vertical lines, giving grid points (i,j) for
 0≤i≤m, 0≤j≤n. Interior vertices are those with 1≤i≤m-1, 1≤j≤n-1, totaling V = (
m-1)(n-1).

Since the path is a simple closed curve visiting every interior vertex and never
 touching boundary vertices, it uses only edges between interior vertices. Each
interior vertex has degree exactly 2 in the path, so the path is a **Hamiltonian
 cycle** on the (m-1)×(n-1) interior grid graph. The number of path edges equals
 V.

## Categorizing squares

Each square has k ∈ {0,1,2,3,4} sides used by the path. Define:
- **C** = squares with 0 sides used
- **S₁** = squares with 1 side used
- **S₂ₐ** = squares with 2 adjacent sides used
- **B** = squares with 2 opposite sides used
- **S₃** = squares with 3 sides used
- **S₄** = squares with 4 sides used

**Claim: S₄ = 0.** If all 4 sides of a square are used, at each corner two perpe
ndicular sides meet, forcing a turn. The 4 edges form a closed 4-cycle. Since ev
ery vertex has degree 2 in the Hamiltonian cycle, this 4-cycle would be an isola
ted component — contradicting that the path is a single cycle visiting all V ≥ 9
 interior vertices (since m,n ≥ 4).

## Key equations

**Equation (1) — edge-side counting.** Each interior edge is shared by exactly 2
 squares. The path uses V edges, each contributing 2 to the total side-count:

$$S_1 + 2S_{2a} + 2B + 3S_3 = 2V$$

**Equation (2) — total squares:**

$$C + S_1 + S_{2a} + B + S_3 = mn$$

**Equation (3) — turn counting.** At each interior vertex, the path either goes
**straight** (contributing to A) or **turns**. Let T = V − A be the number of tu
rns. Each turn at a vertex opens toward exactly one square (the square whose two
 adjacent sides are the turn's edges). Mapping turns to squares:
- k=0,1,2 opposite: 0 turns open toward the square
- k=2 adjacent: 1 turn; k=3: 2 turns

Therefore: $T = S_{2a} + 2S_3$, and $A = V - S_{2a} - 2S_3$.

## Computing A − B + C

From (2): $C = mn - S_1 - S_{2a} - B - S_3$.

$$A - B + C = (V - S_{2a} - 2S_3) - B + (mn - S_1 - S_{2a} - B - S_3)$$
$$= V + mn - S_1 - 2S_{2a} - 3S_3 - 2B$$

From (1): $S_1 + 2S_{2a} + 3S_3 = 2V - 2B$. Substituting:

$$A - B + C = V + mn - (2V - 2B) - 2B = mn - V$$

$$= mn - (m-1)(n-1) = mn - (mn - m - n + 1) = m + n - 1$$
