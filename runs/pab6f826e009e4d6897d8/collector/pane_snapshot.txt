## Identifying the Curve

On C: z = 1 − y² ≥ 0 gives y ∈ [−1, 1], and 2x + 3(1−y²) = 6 gives x = 3(1+y²)/2

- At y = ±1: z = 0, x = 3 → points (3, ±1, 0)
- At y = 0: z = 1, x = 3/2 → point (3/2, 0, 1)

The curve C is closed: a **parabolic arc** from (3,−1,0) to (3,1,0) through (3/2

## Applying Stokes' Theorem

$$\int_C \mathbf{F}\cdot d\mathbf{r} = \iint_S (\nabla \times \mathbf{F})\cdot \
mathbf{n}\, dS$$

**Curl of F** = (z², xz, 2xy):

$$\nabla \times \mathbf{F} = \left(\frac{\partial(2xy)}{\partial y} - \frac{\par
tial(xz)}{\partial z},\; \frac{\partial(z^2)}{\partial z} - \frac{\partial(2xy)}

y}\right) = (x,\; 2z-2y,\; z)$$

**Surface choice**: the portion of the plane 2x + 3z = 6 bounded by C, parameter

**Normal vector**:
$$\mathbf{r}_y \times \mathbf{r}_z = (0,1,0) \times (-3/2, 0, 1) = (1, 0, 3/2)$$

This points in direction (2, 0, 3) — the outward normal of the plane, with posit

**Dot product on the surface**:
$$(\nabla \times \mathbf{F})\cdot (\mathbf{r}_y \times \mathbf{r}_z) = x\cdot 1
+ (2z-2y)\cdot 0 + z\cdot \tfrac{3}{2} = x + \tfrac{3}{2}z$$

On the surface, x = 3 − 3z/2, so:
$$x + \tfrac{3}{2}z = 3 - \tfrac{3}{2}z + \tfrac{3}{2}z = 3$$

The integrand reduces to the constant **3**.

## Computing the Integral

$$\int_C \mathbf{F}\cdot d\mathbf{r} = \iint_D 3\, dy\, dz = 3 \cdot \text{Area}
(D)$$

$$\text{Area}(D) = \int_{-1}^{1} \int_0^{1-y^2} dz\, dy = \int_{-1}^{1} (1-y^2)\

$$\int_C \mathbf{F}\cdot d\mathbf{r} = 3 \times \frac{4}{3} = \boxed{4}$$
