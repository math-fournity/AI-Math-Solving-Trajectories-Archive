## Solution

We evaluate the infinite tetration $T = 2^{2^{2^{2^{\cdot^{\cdot^\cdot}}}}}$, de
fined as the limit of the sequence
$$a_1 = 2, \qquad a_{n+1} = 2^{a_n}.$$

**Convergence criterion for infinite tetration.** The infinite tetration $x^{x^{
x^{\cdots}}}$ converges to a finite real value if and only if $e^{-e} \le x \le
e^{1/e}$. This follows from the fixed-point analysis of $f(y) = x^y$: a limit $L
$ must satisfy $L = x^L$, and the iteration converges only when the fixed point
is attracting, i.e., $|f'(L)| = |L \ln x| \le 1$. The boundary case $|L\ln x| =
1$ yields $x = e^{1/e}$ (upper) and $x = e^{-e}$ (lower).

**Checking $x = 2$ against the criterion.** We compute
$$e^{1/e} = e^{0.36788\ldots} \approx 1.44467\ldots$$
Since $2 > e^{1/e} \approx 1.4447$, the value $x = 2$ lies **outside** the conve
rgence interval $[e^{-e},\, e^{1/e}]$.

**Direct verification that no fixed point exists.** A finite limit $L$ would nee
d to satisfy $L = 2^L$. Consider $g(y) = 2^y - y$. Its minimum occurs at $g'(y)
= 2^y \ln 2 - 1 = 0$, giving $y^* = \log_2(1/\ln 2) \approx 0.5288$. At this poi
nt:
$$g(y^*) = \frac{1}{\ln 2} - \log_2\!\left(\tfrac{1}{\ln 2}\right) \approx 1.442
7 - 0.5288 = 0.9139 > 0.$$
Since $g(y) > 0$ for all real $y$, we have $2^y > y$ everywhere, so the equation
 $L = 2^L$ has **no real solution**.

**Divergence of the sequence.** Since $2^y > y$ for all $y$, the sequence $a_{n+
1} = 2^{a_n}$ is strictly increasing: $a_{n+1} = 2^{a_n} > a_n$. Moreover, $a_1
= 2$, $a_2 = 4$, $a_3 = 16$, $a_4 = 2^{16} = 65536$, and the growth is super-exp
onential. The sequence is unbounded, hence $a_n \to +\infty$.

**Conclusion.** The infinite tetration $2^{2^{2^{\cdots}}}$ does not converge to
 any finite value; it diverges to $+\infty$.
