## Key Observation

Y(x) is a non-decreasing, integer-valued, right-continuous step function with Y(
0) = 0. It only changes at **jump points** — values of x where at least one floo
r term increases. At each distinct jump point x_i, Y increases by some d_i ≥ 1.

The values taken by Y are the partial sums: 0, d₁, d₁+d₂, ..., Σd_i = Y(100). Si
nce each d_i ≥ 1, these partial sums are strictly increasing, so:

**Number of distinct values = (number of distinct jump points) + 1**

## Inclusion-Exclusion (m ∈ {1,...,6000})

Let A = {m : 15|m}, B = {m : 20|m}, C = {m : 36|m}.

- |A| = ⌊6000/15⌋ = 400
- |B| = ⌊6000/20⌋ = 300
- |C| = ⌊6000/36⌋ = 166 (36×166 = 5976 ≤ 6000)

Pairwise intersections (using lcm):
- lcm(15,20) = 60 → |A∩B| = ⌊6000/60⌋ = 100
- lcm(15,36) = 180 → |A∩C| = ⌊6000/180⌋ = 33
- lcm(20,36) = 180 → |B∩C| = ⌊6000/180⌋ = 33

Triple intersection:
- lcm(15,20,36) = 180 → |A∩B∩C| = 33

**J = |A∪B∪C| = 400 + 300 + 166 − 100 − 33 − 33 + 33 = 733**
