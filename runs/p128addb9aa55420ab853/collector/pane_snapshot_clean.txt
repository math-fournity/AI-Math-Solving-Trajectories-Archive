## Solution

I need to find all $x \in [0, 2\pi]$ such that $\cos(2^n x) < 0$ for every $n \i
n \mathbb{N} = \{1, 2, 3, \dots\}$.

### Setup via binary expansion

Let $x = 2\pi t$ with $t \in [0, 1]$, and write $t = 0.b_1 b_2 b_3 \cdots$ in bi
nary. Then $2^n x = 2\pi \cdot 2^n t$, so

$$\cos(2^n x) = \cos(2\pi \cdot 2^n t).$$

Since $\cos(2\pi y) < 0$ iff the fractional part $\{y\} \in (1/4,\, 3/4)$, the c
ondition becomes:

$$\{2^n t\} \in \left(\tfrac{1}{4},\, \tfrac{3}{4}\right) \quad \text{for all }
n \geq 1.$$

Under the doubling map, $\{2^n t\} = 0.b_{n+1}\, b_{n+2}\, b_{n+3} \cdots$ (bina
ry shift). So the condition is:

$$0.b_k\, b_{k+1}\, b_{k+2} \cdots \;\in\; \left(\tfrac{1}{4},\, \tfrac{3}{4}\ri
ght) \quad \text{for all } k \geq 2.$$

### Forcing strict alternation

Fix any $k \geq 2$ and let $v = 0.b_k\, b_{k+1}\, b_{k+2}\cdots$.

**If $b_k = 0$:** then $v \in [0, 1/2)$. To have $v > 1/4 = 0.01000\ldots_2$, we
 need $b_{k+1} = 1$ (if $b_{k+1}=0$, then $v \leq 0.00111\ldots_2 = 1/4$, violat
ing strict inequality). The upper bound $v < 3/4$ is automatic.

**If $b_k = 1$:** then $v \in [1/2, 1)$. To have $v < 3/4 = 0.11000\ldots_2$, we
 need $b_{k+1} = 0$ (if $b_{k+1}=1$, then $v \geq 0.11000\ldots_2 = 3/4$, violat
ing strict inequality). The lower bound $v > 1/4$ is automatic.

Therefore $b_k \neq b_{k+1}$ for every $k \geq 2$, so the sequence $(b_2, b_3, b
_4, \ldots)$ **strictly alternates**. There are exactly two possibilities:

- **Pattern A:** $b_2 b_3 b_4 \cdots = 010101\ldots$
- **Pattern B:** $b_2 b_3 b_4 \cdots = 101010\ldots$

The bit $b_1$ is unconstrained, giving $2 \times 2 = 4$ candidates.

### Verifying strict inequality for the alternating patterns

For Pattern A, at any position $k \geq 2$: if $b_k = 0$, the tail is $0.010101\l
dots_2 = 1/3 \in (1/4, 3/4)$ ✓; if $b_k = 1$, the tail is $0.101010\ldots_2 = 2/
3 \in (1/4, 3/4)$ ✓.

For Pattern B, the same values $1/3$ and $2/3$ appear, both in $(1/4, 3/4)$ ✓.

No dyadic rational can be a solution (its binary expansion is eventually constan
t, contradicting alternation), so there is no representation ambiguity.

### Computing the four values

**Pattern A** ($b_2 b_3 \cdots = 010101\ldots$): the repeating part $01$ from po
sition 3 gives $0.0010101\ldots_2 = \frac{1/8}{1-1/4} = \frac{1}{6}$.

- $b_1 = 0$: $t = 1/6$, so $x = 2\pi/6 = \pi/3$.
- $b_1 = 1$: $t = 1/2 + 1/6 = 2/3$, so $x = 4\pi/3$.

**Pattern B** ($b_2 b_3 \cdots = 101010\ldots$): the repeating part $10$ from po
sition 2 gives $0.0101010\ldots_2 = \frac{1/4}{1-1/4} = \frac{1}{3}$.

- $b_1 = 0$: $t = 1/3$, so $x = 2\pi/3$.
- $b_1 = 1$: $t = 1/2 + 1/3 = 5/6$, so $x = 5\pi/3$.

### Direct verification

For each candidate, $2^n x \pmod{2\pi}$ alternates between $2\pi/3$ and $4\pi/3$
:

| $x$ | $n=1$: $2x \bmod 2\pi$ | $n=2$: $4x \bmod 2\pi$ | $\cos$ value |
|-----|------------------------|------------------------|--------------|
| $\pi/3$ | $2\pi/3$ | $4\pi/3$ | $-1/2 < 0$ ✓ |
| $2\pi/3$ | $4\pi/3$ | $2\pi/3$ | $-1/2 < 0$ ✓ |
| $4\pi/3$ | $2\pi/3$ | $4\pi/3$ | $-1/2 < 0$ ✓ |
| $5\pi/3$ | $4\pi/3$ | $2\pi/3$ | $-1/2 < 0$ ✓ |

The pattern repeats with period 2, so $\cos(2^n x) = -1/2 < 0$ for all $n \geq 1
$. ✓

### Sum

$$\frac{\pi}{3} + \frac{2\pi}{3} + \frac{4\pi}{3} + \frac{5\pi}{3} = \frac{12\pi
}{3} = \boxed{4\pi}.$$
