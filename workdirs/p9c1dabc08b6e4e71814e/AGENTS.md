# Problem

In a specialized laboratory, a team of engineers is designing a modular micro-satellite in the shape of a perfect cube. The satellite has six distinct exterior panels (top, bottom, and four sides). To manage thermal radiation and sensor interference, the team must apply specialized chemical coatings to these panels.

There are exactly 6 different types of chemical coatings available. The engineers must follow these strict protocols:
1. Each of the six panels must be completely covered by exactly one type of coating.
2. Any two panels that share a common edge must be coated with different chemical types to prevent cross-contamination.
3. The team can choose to use any number of the available 6 colors (from using only 3 colors—the minimum required—up to using all 6 colors).
4. Because the satellite will be tumbling and rotating freely in the vacuum of space, two coating patterns are considered identical if one can be transformed into the other simply by rotating the cube in any direction.

How many unique, non-equivalent coloring schemes can the engineers use to coat the satellite?
