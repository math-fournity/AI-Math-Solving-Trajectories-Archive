## 证明

设 $S(t) = \sum_{i=1}^{N(t)} (X_i + T_i)^2$，其中 $X_i \stackrel{\text{iid}}{\si
m} \text{Uniform}[0,2]$，$N(t)$ 是强度为 $\lambda = 3$ 的泊松过程，且 $N(t)$ 与
序列 $(X_i)$ 独立。

展开平方项：

$$(X_i + T_i)^2 = X_i^2 + 2X_i T_i + T_i^2.$$

根据期望的线性性质，

$$E[S(t)] = E\!\left[\sum_{i=1}^{N(t)} X_i^2\right] + 2\,E\!\left[\sum_{i=1}^{N(
t)} X_i T_i\right] + E\!\left[\sum_{i=1}^{N(t)} T_i^2\right].$$

我们使用以下两个标准事实：

**事实 1 (Wald 等式).** 由于 $(X_i)$ 与 $N(t)$ 独立，且 $X_i$ 独立同分布，对于任
意可和函数 $h$，
$$E\!\left[\sum_{i=1}^{N(t)} h(X_i)\right] = E[N(t)]\,E[h(X)].$$

**事实 2 (Campbell 定理).** 对于强度为 $\lambda$ 的泊松过程，对于任意可测函数 $g
$，
$$E\!\left[\sum_{i=1}^{N(t)} g(T_i)\right] = \lambda \int_0^t g(s)\,ds.$$

（等价地，以 $N(t)=n$ 为条件，到达时间是 $n$ 个在 $[0,t]$ 上独立同分布的均匀随机
变量的次序统计量；对 $n\sim\text{Poisson}(\lambda t)$ 取期望即可得到相同结果。）

### $X$ 的矩

$$E[X] = \int_0^2 x\cdot\tfrac{1}{2}\,dx = 1, \qquad E[X^2] = \int_0^2 x^2\cdot\
tfrac{1}{2}\,dx = \tfrac{4}{3}.$$

### 第一项

由于 $X_i$ 与 $N(t)$ 独立，
$$E\!\left[\sum_{i=1}^{N(t)} X_i^2\right] = E[N(t)]\,E[X^2] = (3t)\cdot\tfrac{4}
{3} = 4t.$$

### 第二项（交叉项）

由于 $X_i$ 与 $T_i$ 和 $N(t)$ 均独立，
$$E\!\left[\sum_{i=1}^{N(t)} X_i T_i\right] = E[X]\cdot E\!\left[\sum_{i=1}^{N(t
)} T_i\right].$$

使用事实 2，令 $g(s)=s$：
$$E\!\left[\sum_{i=1}^{N(t)} T_i\right] = \lambda\int_0^t s\,ds = 3\cdot\frac{t^
2}{2} = \frac{3t^2}{2}.$$

因此
$$2\,E\!\left[\sum_{i=1}^{N(t)} X_i T_i\right] = 2\cdot 1 \cdot \frac{3t^2}{2} =
 3t^2.$$

### 第三项

使用事实 2，令 $g(s)=s^2$：
$$E\!\left[\sum_{i=1}^{N(t)} T_i^2\right] = \lambda\int_0^t s^2\,ds = 3\cdot\fra
c{t^3}{3} = t^3.$$

### 合并各项

$$E[S(t)] = 4t + 3t^2 + t^3.$$

### 验证

交叉验证第三项的条件期望：以 $N(t)=n$ 为条件，到达时间是 $n$ 个在 $[0,t]$ 上独立
同分布的均匀随机变量的次序统计量，因此 $\sum_{i=1}^n T_i^2$ 的期望为 $n\cdot E[U
^2] = n\cdot t^2/3$。对 $n$ 取期望：$\frac{t^2}{3}E[N(t)] = \frac{t^2}{3}\cdot 3
t = t^3$。一致。$\sum T_i$ 的类似验证得出 $\frac{t}{2}\cdot 3t = \frac{3t^2}{2}$
，一致。

$$\boxed{E[S(t)] = 4t + 3t^2 + t^3}$$
