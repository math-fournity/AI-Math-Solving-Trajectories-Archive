## Proof

**Parity analysis.** All 7 numbers must be prime. Since two of $a,b,c$ sum to $8
00$ (even), those two have the same parity. If one of $a,b,c$ equals $2$, say $c
=2$ with $a+b=800$: then $a+b-c = 798$, even and $>2$, not prime. If $a=2$ with
$b+c=800$: then $a+b-c = 2+b-c = 802-2c$, which is even, so must equal $2$, givi
ng $c=400$ (not prime). Hence **none of $a,b,c$ is $2$**; all three are odd prim
es, and the pair summing to $800$ consists of two odd primes.

**Symmetry reduction.** The set $\{a,b,c,\,a+b-c,\,a+c-b,\,b+c-a,\,a+b+c\}$ is s
ymmetric in $a,b,c$. Relabel so that $a+b=800$, with $a,b,c$ distinct odd primes
.

The seven primes become:
$$a,\quad b=800-a,\quad c,\quad 800-c,\quad 2a+c-800,\quad 800-2a+c,\quad 800+c.
$$

**Bounding the maximum.** Since $a,b<800$ and $c>0$:
- $800+c > 800-c$ (as $c>0$);
- $800+c - (2a+c-800) = 1600-2a > 0$ (as $a<800$);
- $800+c - (800-2a+c) = 2a > 0$;
- $800+c > a,\,b,\,c$ when $c$ is large.

So the **largest** of the seven is $800+c$.

**Bounding $c$.** The value $800-c$ must be a positive (odd) prime, so $800-c\ge
q 3$, i.e. $c\leq 797$. The largest admissible $c$ is $c=797$, provided $797$ is
 prime. Checking divisibility by all primes $\leq\sqrt{797}\approx 28$ (namely $
3,5,7,11,13,17,19,23$): none divides $797$, so **$797$ is prime**, and $800-797=
3$ is prime. ✓

**Bounding the minimum.** With $c=797$, the seven values are all odd primes, hen
ce each $\geq 3$. Since $800-c=3$ is among them, the **minimum is exactly $3$**.

**Upper bound on $d$.** For any valid configuration,
$$d = \max - \min = (800+c) - \min \leq (800+797) - 3 = 1597 - 3 = 1594,$$
since $c\leq 797$ and $\min\geq 3$.

**Achieving the bound.** Take $c=797$ and choose $a=13$ (odd prime). Then $b=800
-13=787$.
- $787$ is prime (no prime $\leq 28$ divides it). ✓
- $2a+c-800 = 26+797-800 = 23$, prime. ✓
- $800-2a+c = 800-26+797 = 1571$, prime (no prime $\leq 39$ divides it). ✓
- $800+c = 1597$, prime (no prime $\leq 40$ divides it). ✓

The seven primes are
$$\{13,\;787,\;797,\;3,\;23,\;1571,\;1597\},$$
all distinct and all prime. The largest is $1597$ and the smallest is $3$, givin
g
$$d = 1597 - 3 = 1594.$$

Since $1594$ is an upper bound and is attained, the maximum possible value of $d
$ is

$$\boxed{1594}.$$
