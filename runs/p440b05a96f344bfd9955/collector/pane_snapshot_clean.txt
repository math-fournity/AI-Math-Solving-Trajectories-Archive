## Proof

Let $S = \sum_{k=1}^{99}(x+k)^2$. We compute:

$$S = 99x^2 + 2x\sum_{k=1}^{99}k + \sum_{k=1}^{99}k^2 = 99x^2 + 9900x + \frac{99
 \cdot 100 \cdot 199}{6} = 99x^2 + 9900x + 328350.$$

**Completing the square.** Setting $u = x + 50$:

$$S = 99\bigl((x+50)^2 - 2500\bigr) + 328350 = 99\,u^2 - 247500 + 328350 = 99\,u
^2 + 80850.$$

**Factoring.** Since $\gcd(99,\, 80850) = 33$ (as $99 = 3^2 \cdot 11$ and $80850
 = 2 \cdot 3 \cdot 5^2 \cdot 7^2 \cdot 11$), we factor out $33$:

$$S = 33\bigl(3\,u^2 + 2450\bigr), \qquad u = x + 50.$$

**Key observation — the 3-adic valuation.** We examine $3\,u^2 + 2450$ modulo $3
$:

$$2450 = 3 \cdot 816 + 2 \;\;\Longrightarrow\;\; 2450 \equiv 2 \pmod{3},$$

so

$$3\,u^2 + 2450 \equiv 0 + 2 \equiv 2 \pmod{3}.$$

Therefore $3 \nmid (3\,u^2 + 2450)$, which gives

$$v_3(S) = v_3(33) + v_3(3\,u^2 + 2450) = 1 + 0 = 1.$$

**Conclusion.** Suppose for contradiction that $S = y^z$ for some integer $y$ an
d integer $z > 1$. Then

$$v_3(S) = v_3(y^z) = z \cdot v_3(y).$$

Since $v_3(S) = 1$, we need $z \mid 1$, forcing $z = 1$. This contradicts $z > 1
$.

Hence no integers $x, y, z$ with $z > 1$ satisfy $(x+1)^2 + (x+2)^2 + \cdots + (
x+99)^2 = y^z$. $\blacksquare$
