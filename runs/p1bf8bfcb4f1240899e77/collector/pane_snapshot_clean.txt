**Decompose the integrand.** Write
$$\frac{e^{-x^2}}{x^2} = \frac{1}{x^2} + \frac{e^{-x^2}-1}{x^2}.$$

Set $g(x) = \dfrac{e^{-x^2}-1}{x^2}$ (with $g(0) = -1$ by continuity, using the
given limit). Then

\frac{e^{-x^2}}{x^2}\,dx = -1 + 0 = \boxed{-1}.$$
