## Proof

**Sequence definition:**
- $a_0 = 1$
- If $n$ is even: $a_{n+1} = a_n + 2$
- If $n$ is odd: $a_{n+1} = 2a_n$

**Computing initial terms:**

| $n$ | $a_n$ |
|-----|-------|
| 0 | 1 |
| 1 | 3 |
| 2 | 6 |
| 3 | 8 |
| 4 | 16 |
| 5 | 18 |
| 6 | 36 |
| 7 | 38 |

**Deriving a closed form for even indices.** Let $b_k = a_{2k}$. Then:
- $a_{2k+1} = a_{2k} + 2 = b_k + 2$ (since $2k$ is even)
- $a_{2k+2} = 2 \cdot a_{2k+1} = 2(b_k + 2) = 2b_k + 4$ (since $2k+1$ is odd)

So $b_{k+1} = 2b_k + 4$ with $b_0 = 1$.

Solving this linear recurrence: the fixed point is $c = 2c + 4 \Rightarrow c = -
4$, so $b_k = A \cdot 2^k - 4$. From $b_0 = A - 4 = 1$, we get $A = 5$:

$$b_k = 5 \cdot 2^k - 4, \quad \text{i.e., } a_{2k} = 5 \cdot 2^k - 4.$$

**Closed form for $a_{2015}$.** Since $2015 = 2 \cdot 1007 + 1$ is odd:

$$a_{2015} = a_{2014} + 2 = (5 \cdot 2^{1007} - 4) + 2 = 5 \cdot 2^{1007} - 2.$$

**Computing $a_{2015} \bmod 100$.** We need $2^{1007} \bmod 100$.

The powers of 2 modulo 100 cycle with period 20 starting at $n = 2$ (since $\tex
t{lcm}(\text{ord}_{25}(2), \text{period mod } 4) = \text{lcm}(20, 1) = 20$). Ver
ifying: $2^{22} \bmod 100 = 4 = 2^2 \bmod 100$. ✓

So for $n \geq 2$: $2^n \bmod 100 = 2^{((n-2) \bmod 20) + 2} \bmod 100$.

For $n = 1007$: $(1007 - 2) \bmod 20 = 1005 \bmod 20 = 5$, so $2^{1007} \bmod 10
0 = 2^{7} \bmod 100 = 128 \bmod 100 = 28$.

Therefore:
$$a_{2015} \bmod 100 = (5 \cdot 28 - 2) \bmod 100 = (140 - 2) \bmod 100 = 138 \b
mod 100 = 38.$$

**Verification with small cases:** $a_7 = 5 \cdot 2^3 - 2 = 38$, and indeed $a_7
