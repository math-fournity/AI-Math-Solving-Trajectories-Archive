## Answer

**No**, such an automorphism need not exist in general.

## Proof

Let $H = \mathbb{R}^2$ with the standard inner product, and let $H' = \operatorn
ame{span}(e_1)$. Set
$$a = e_1 + e_2, \qquad b = -e_1 + e_2.$$

**The hypotheses are satisfied.** We have $\|a\| = \sqrt{2} = \|b\|$, and since
$H' = \operatorname{span}(e_1)$,
$$\operatorname{dist}(a, H') = \|a - e_1\| = \|e_2\| = 1, \qquad \operatorname{d
ist}(b, H') = \|b - (-e_1)\| = \|e_2\| = 1.$$

**Characterizing automorphisms fixing $H'$ pointwise.** Let $f: H \to H$ be a un
itary (Hilbert-space automorphism) with $f|_{H'} = \mathrm{id}_{H'}$. For any $x
 \in (H')^\perp = \operatorname{span}(e_2)$ and any $y \in H'$:
$$\langle fx, y\rangle = \langle fx, fy\rangle = \langle x, y\rangle = 0,$$
so $fx \in (H')^\perp$. Thus $f$ preserves the orthogonal decomposition $H = H'
\oplus (H')^\perp$, and $f = \mathrm{id}_{H'} \oplus U$ where $U$ is a unitary o
n the one-dimensional real space $(H')^\perp = \operatorname{span}(e_2)$. The on
ly unitaries on a one-dimensional *real* Hilbert space are $U = \pm\,\mathrm{id}
$. Hence the only two possibilities are:
$$f(x_1 e_1 + x_2 e_2) = x_1 e_1 + x_2 e_2 \quad\text{or}\quad f(x_1 e_1 + x_2 e
_2) = x_1 e_1 - x_2 e_2.$$

**No such $f$ maps $a$ to $b$.** Applying either possibility to $a = e_1 + e_2$:
$$f(a) = e_1 + e_2 = a \qquad\text{or}\qquad f(a) = e_1 - e_2.$$
Neither equals $b = -e_1 + e_2$. Therefore no automorphism of $H$ fixing $H'$ po
intwise sends $a$ to $b$.

**Why the given conditions are insufficient (structural reason).** Any unitary $
f$ fixing $H'$ pointwise splits as $\mathrm{id}_{H'} \oplus U$, so $f(a) = Pa +
U(Qa)$ where $P$ is the orthogonal projection onto $H'$ and $Q = I - P$. For $f(
a) = b$ we need $Pa = Pb$ *and* $U(Qa) = Qb$. The latter is achievable whenever
$\|Qa\| = \|Qb\|$ (i.e., the distance condition). But the hypotheses $\|a\| = \|
b\|$ and $\operatorname{dist}(a,H') = \operatorname{dist}(b,H')$ only imply $\|P
a\| = \|Pb\|$, **not** $Pa = Pb$. In the counterexample, $Pa = e_1$ while $Pb =
-e_1$: equal in norm, but not equal, and this is the obstruction.
