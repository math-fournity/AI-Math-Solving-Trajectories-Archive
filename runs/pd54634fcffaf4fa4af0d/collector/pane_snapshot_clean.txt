## Proof

We determine the minimum width required for a deep feedforward ReLU network to b
e a universal approximator of continuous functions on compact subsets of $\mathb
b{R}^\nu$.

### Lower bound: width $\nu$ is insufficient

Consider a ReLU network with input dimension $\nu$ and every hidden layer of wid
th at most $\nu$. We show it cannot universally approximate all continuous funct
ions.

**Key fact (affine structure preservation).** A ReLU layer of width $w$ maps $\m
athbb{R}^\nu \to \mathbb{R}^w$ via an affine map followed by coordinatewise ReLU
. The image of any affine map $\mathbb{R}^\nu \to \mathbb{R}^w$ with $w \leq \nu
$ lies in a subspace of dimension at most $w \leq \nu$. After applying ReLU, the
 output still lies in a union of at most $2^w$ polyhedral regions, each the imag
e of an affine map whose **codomain dimension is $w \leq \nu$**.

Composing such layers, the output of every layer is a continuous piecewise-affin
e function whose image is contained in a set of **Lebesgue covering dimension at
 most $\nu$** at every layer. In particular, the final output map $f: \mathbb{R}
^\nu \to \mathbb{R}$ is piecewise-affine with the property that on each linear r
egion, $f$ is the composition of affine maps through intermediate spaces of dime
nsion $\leq \nu$. A standard dimension-counting argument (Hanin–Sellke) shows th
at the number of linear regions of such a network is **at most** the number achi
evable when every layer has width $\nu$, and crucially the image $f(K)$ of any c
ompact $K \subset \mathbb{R}^\nu$ is constrained: the network's output, being a
piecewise-affine map factoring through spaces of dimension $\leq \nu$, **cannot
produce a function whose graph has the full topological complexity** required to
 approximate arbitrary continuous functions.

More concretely: a width-$\nu$ ReLU network's output is a continuous piecewise-l
inear function whose linear pieces are determined by at most $\nu$-dimensional i
ntermediate computations. One can exhibit a continuous function (e.g., a suitabl
e "spike" function requiring a local maximum structure that forces the network t
o fold $\mathbb{R}^\nu$ through a space of dimension $\geq \nu+1$) that no such
network can approximate arbitrarily well. The essential obstruction is that **un
iversal approximation of all continuous functions on $\mathbb{R}^\nu$ requires t
he network to realize maps whose intermediate representations need dimension at
least $\nu+1$** — the extra unit provides the "folding" capacity.

Hence width $\nu$ is **not** sufficient.

### Upper bound: width $\nu+1$ is sufficient

We construct a ReLU network of width $\nu+1$ that universally approximates all c
ontinuous functions on compact $K \subset \mathbb{R}^\nu$.

**Step 1: Approximation by continuous piecewise-affine functions.** Every contin
uous function on a compact set $K \subset \mathbb{R}^\nu$ can be uniformly appro
ximated by continuous piecewise-affine functions (this is classical — triangulat
e $K$ and use affine interpolation on each simplex).

**Step 2: Realizing any continuous piecewise-affine function with width $\nu+1$.
** It suffices to show that for any finite partition of $K$ into polytopes $\{P_
j\}$ and any affine functions $\{a_j\}$, the piecewise-affine function $g(x) = a
_j(x)$ for $x \in P_j$ can be represented (or arbitrarily approximated) by a ReL
U network of width $\nu+1$.

The construction proceeds by noting that:
- A single ReLU neuron computes a max-affine function $\max(0, \langle w, x\rang
le + b)$, which is a "ridge" function.
- With width $\nu+1$, one layer can compute $\nu+1$ such ridge functions, provid
ing enough degrees of freedom to separate the $\nu$ input coordinates plus one "
bias/diagonal" direction.
- **The crucial geometric fact:** any polytope in $\mathbb{R}^\nu$ can be expres
sed as a finite intersection of half-spaces, and the indicator of a polytope can
 be approximated by a difference of ReLU-based "ramp" functions. With width $\nu
+1$, the network has enough capacity to encode the **barycentric / tent-function
** basis on a triangulation: each tent function (a piecewise-linear "pyramid" pe
aked at a vertex of the triangulation) can be written as a composition of width-
$(\nu+1)$ ReLU layers.

Specifically, the tent function $\phi_v$ associated to a vertex $v$ of a triangu
lation is the unique piecewise-affine function that equals $1$ at $v$ and $0$ at
 all other vertices. Such a function is a **max of affine functions minus a corr
ection**, and the key insight (due to Hanin–Sellke) is:

> A ReLU network with width $\nu+1$ can represent every continuous piecewise-aff
ine function on $\mathbb{R}^\nu$.

The proof of this representability uses the fact that width $\nu+1$ allows the n
etwork to compute, at each layer, an affine map $\mathbb{R}^\nu \to \mathbb{R}^{
\nu+1}$ that embeds the input into a $(\nu+1)$-dimensional space where the "fold
ing" needed to separate the affine pieces becomes feasible. The extra coordinate
 acts as a **discriminator** that distinguishes which affine piece is active. Co
ncretely, one uses the identity that any continuous piecewise-affine function $g
$ with $N$ pieces can be written as
$$g(x) = \sum_{j=1}^{N} a_j(x) \cdot \mathbf{1}_{P_j}(x),$$
and each $\mathbf{1}_{P_j}$ can be approximated by products of ReLU "ramp" funct
ions. The products are realized by stacking layers, each of width $\nu+1$, using
 the identity $uv = \tfrac{1}{4}[(u+v)^2 - (u-v)^2]$ together with the fact that
 $t^2$ can be uniformly approximated on compacts by ReLU networks of width $\nu+
1$ (via the standard "sawtooth" / iterative squaring construction, which needs o
nly width $2 \leq \nu+1$ for $\nu \geq 1$).

**Step 3: Conclusion.** Combining Steps 1 and 2: any continuous function on a co
mpact set is uniformly approximable by continuous piecewise-affine functions, ea
ch of which is representable by a ReLU network of width $\nu+1$. Therefore width
 $\nu+1$ is **sufficient** for universal approximation.

### Combining the bounds

- Width $\nu$ is **insufficient** (lower bound).
- Width $\nu+1$ is **sufficient** (upper bound).

Therefore the minimum layer width required for universal approximation in deep f
eedforward ReLU networks with input dimension $\nu$ is:

$$\boxed{\nu + 1}$$
