## Proof

We want $E[B_t B_s B_v]$ for $0 < t < s < v$, where $(B_t)$ is standard Brownian
 motion.

**Key fact (Isserlis/Wick theorem).** If $(X_1, X_2, \dots, X_n)$ is jointly Gau
ssian with zero mean, then
$$E[X_1 X_2 \cdots X_n] = 0 \quad \text{whenever } n \text{ is odd},$$
and for even $n$ the moment equals the sum over all pairings of products of pair
wise covariances.

**Applying it.** A standard Brownian motion is a Gaussian process: every finite
collection $(B_{t_1}, \dots, B_{t_n})$ is jointly Gaussian, and $E[B_u] = 0$ for
 all $u$. Hence $(B_t, B_s, B_v)$ is jointly Gaussian with mean zero. Since we a
re taking a moment of **odd** order ($n = 3$), the Isserlis theorem gives
$$E[B_t B_s B_v] = 0.$$

**Direct verification via independent increments (sanity check).** Decompose usi
ng independent increments. Set
$$X = B_t,\qquad Y = B_s - B_t,\qquad Z = B_v - B_s,$$
so that $X, Y, Z$ are independent with $X \sim N(0,t)$, $Y \sim N(0, s-t)$, $Z \
sim N(0, v-s)$, and
$$B_t = X,\quad B_s = X+Y,\quad B_v = X+Y+Z.$$
Then
$$B_t B_s B_v = X(X+Y)(X+Y+Z).$$
Expanding:
$$X(X+Y)(X+Y+Z) = X^3 + 2X^2Y + XY^2 + X^2Z + XYZ.$$
Taking expectations and using independence:
- $E[X^3] = 0$ (third moment of a centered Gaussian),
- $E[X^2Y] = E[X^2]\,E[Y] = t \cdot 0 = 0$,
- $E[XY^2] = E[X]\,E[Y^2] = 0 \cdot (s-t) = 0$,
- $E[X^2Z] = E[X^2]\,E[Z] = t \cdot 0 = 0$,
- $E[XYZ] = E[X]\,E[Y]\,E[Z] = 0$.

Summing, $E[B_t B_s B_v] = 0$.

Both arguments agree. Therefore, for $0 < t < s < v$,

$$\boxed{E[B_t \, B_s \, B_v] = 0.}$$
