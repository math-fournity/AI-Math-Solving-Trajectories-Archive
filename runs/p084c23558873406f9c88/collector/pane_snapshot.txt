现在我来解答该问题。

---

**定理。** PA + TI(ε₀) 的证明论序数为 ε₁（第二个 epsilon 数，即函数 α ↦ ω^α 在 ε
₀ 之后的第一个不动点）。

**定义与背景。**

对于 α < ε₀，TI(α) 表示模式：对于每个公式 φ，
$$\forall \gamma \bigl(\forall \delta < \gamma\, \varphi(\delta) \to \varphi(\ga
mma)\bigr) \;\to\; \forall \beta < \alpha\, \varphi(\beta).$$
如果 T 证明了所有 α < |T| 的 TI(α)，但不证明 TI(|T|)，则理论 T 的证明论序数 |T|
是最小的序数 α，使得 T 不证明 TI(α)。

Gentzen 的经典结果：|PA| = ε₀。具体来说，PA 证明了所有 α < ε₀ 的 TI(α)，且 PA ⊬
TI(ε₀)。此外，Gentzen 归约确立了
$$\text{PRA} + \text{TI}(\epsilon_0) \;\vdash\; \text{Con}(\text{PA}).$$

**上界：PA + TI(ε₀) ⊢ TI(α) 对于所有 α < ε₁。**

*关键引理（乘法引理）。* 如果 T ⊇ PA 证明了 TI(β) 和 TI(α)，那么 T 证明了 TI(β·α
)。

*证明。* 给定满足归纳步骤 ∀γ<β·α (∀δ<γ φ(δ) → φ(γ)) 的公式 φ，我们希望证明 ∀γ<β·
α φ(γ)。将每个 γ < β·α 唯一地写成 γ = β·ξ + η，其中 ξ < α 且 η < β。定义 P(ξ) :=
 ∀η<β φ(β·ξ + η)。我们通过 TI(α) 证明 ∀ξ<α P(ξ)。

对于 ξ 处的归纳步骤：假设 ∀ξ'<ξ P(ξ')，这给出了 ∀δ < β·ξ φ(δ)。为了建立 P(ξ)，将
 TI(β) 应用于公式 ψ(η) := φ(β·ξ + η)。在 η 处 ψ 的归纳步骤要求 ∀η'<η φ(β·ξ+η') →
 φ(β·ξ+η)，这可从全局归纳步骤得出（在 γ = β·ξ+η 处），因为所有 δ < β·ξ+η 要么 <
β·ξ（由归纳假设覆盖），要么在 [β·ξ, β·ξ+η) 范围内（由内部归纳覆盖）。因此 ψ(η)
成立，给出 P(ξ)。通过 TI(α)，∀ξ<α P(ξ)，因此 ∀γ<β·α φ(γ)。 ∎

*迭代。* 由于 TI(ε₀) 是公理，反复应用该引理得出：

1. **TI(ε₀²)** = TI(ε₀·ε₀)：来自 TI(ε₀) 和 TI(ε₀)。
2. **TI(ε₀ⁿ)** 对于每个有限的 n ≥ 1：通过对 n 的外部归纳。
3. **TI(ε₀^ω)** = sup_n TI(ε₀ⁿ)：对于每个公式 φ，通过对 n 的 PA 归纳证明 ∀γ<ε₀ⁿ
φ(γ) 对于所有 n 成立，使用 TI(ε₀) 作为每个块的引擎。
4. **TI(ε₀^α)** 对于 α < ε₀：使用 TI(α)（本身可证明，因为 α < ε₀）进行外部归纳，
使用 TI(ε₀) 进行内部归纳。这给出了 TI(ε₀^ε₀)（取 α = ε₀），然后是 TI(ε₀^(ε₀^ε₀))
，依此类推。
5. **所有有限迭代** α ↦ ε₀^α 从 ε₀+1 开始：序列 b₀ = ε₀+1, b₁ = ω^(ε₀+1) = ε₀·ω,
 b₂ = ω^b₁ = ε₀^ω, b₃ = ω^b₂, ... 的上确界是 ε₁。每个 bₙ 和每个 α < bₙ 都可以通
过上述方法达到，且在每一步中，控制迭代深度的“外部参数”都 < ε₀，因此 TI(ε₀) 就足
够了。

关键的结构事实是：每个 α < ε₁ 都位于某个 bₙ 之下，且 bₙ 的构造仅涉及深度 < ε₀ 的
迭代（因为 ε₁ 是 α ↦ ω^α 在 ε₀ 之上的第一个不动点）。因此，PA + TI(ε₀) 证明了所
有 α < ε₁ 的 TI(α)。

**下界：PA + TI(ε₀) ⊬ TI(ε₁)。**

Gentzen 归约推广如下：对于 T = PA + TI(ε₀)，存在一个在弱基础理论（例如 PRA）中进
行的证明，将 Con(T) 归约为 TI(|T|)。具体来说，T 的证明截断消除和序数赋值将 T-证
明映射到 < ε₁ 范围内的序数，并且 T 的一致性可以从 TI(ε₁) 推导得出：
$$\text{PRA} + \text{TI}(\epsilon_1) \;\vdash\; \text{Con}\bigl(\text{PA} + \tex
t{TI}(\epsilon_0)\bigr).$$

现在假设，为了矛盾，PA + TI(ε₀) ⊢ TI(ε₁)。那么 PA + TI(ε₀) 将证明 Con(PA + TI(ε₀
))（将上述归约形式化在理论内部）。但 PA + TI(ε₀) 是一致的（它有以 ε₀-递归序数为
范围的模型）、递归可公理化的，并且扩展了 PA。根据哥德尔第二不完备定理，没有这样
的一致的、递归可公理化的理论扩展 PA 可以证明自身的一致性。矛盾。

因此 PA + TI(ε₀) ⊬ TI(ε₁)。

**结论。** PA + TI(ε₀) 证明了所有 α < ε₁ 的 TI(α)，但不证明 TI(ε₁)。根据证明论序
数的定义：
$$|\text{PA} + \text{TI}(\epsilon_0)| = \epsilon_1.$$
