## Solution

**Setup.** Place the circle at the origin with radius 1. Since $AC$ is a diamete
r, set $A = (-1, 0)$ and $C = (1, 0)$, so $AC = 2$. Let $B = (\cos\alpha, \sin\a
lpha)$ and $D = (\cos\beta, \sin\beta)$ on the unit circle, with $B$ above and $
D$ below the $x$-axis (so $\alpha \in (0,\pi)$, $\beta \in (-\pi, 0)$).

**Finding $P$.** Since $P$ lies on $AC$ (the $x$-axis), it is where line $BD$ cr
osses $y=0$. Parametrizing $BD$ and solving for $y=0$ gives:

$$x_P = \frac{\sin(\alpha - \beta)}{\sin\alpha - \sin\beta} = \frac{\cos\frac{\a
lpha-\beta}{2}}{\cos\frac{\alpha+\beta}{2}}$$

Since $P$ is between $A$ and $C$: $PC = 1 - x_P = \frac{2}{5}$, so $x_P = \frac{
3}{5}$.

**Using $BD = AB$.** We have:
- $AB = \sqrt{2 + 2\cos\alpha} = 2\cos\frac{\alpha}{2}$
- $BD = \sqrt{2 - 2\cos(\alpha-\beta)} = 2\sin\frac{\alpha-\beta}{2}$

Setting $BD = AB$: $\sin\frac{\alpha-\beta}{2} = \cos\frac{\alpha}{2} = \sin\!\l
eft(\frac{\pi}{2} - \frac{\alpha}{2}\right)$.

The non-degenerate solution gives $\frac{\alpha-\beta}{2} = \frac{\pi}{2} - \fra
c{\alpha}{2}$, hence:

$$\beta = 2\alpha - \pi$$

**Substituting back.** With $\beta = 2\alpha - \pi$:
- $\alpha - \beta = \pi - \alpha$, so $\cos\frac{\alpha-\beta}{2} = \cos\!\left(
\frac{\pi}{2}-\frac{\alpha}{2}\right) = \sin\frac{\alpha}{2}$
- $\alpha + \beta = 3\alpha - \pi$, so $\cos\frac{\alpha+\beta}{2} = \cos\frac{3
\alpha-\pi}{2}$

Setting $u = \frac{\alpha}{2}$, the equation $x_P = \frac{3}{5}$ becomes:

$$\frac{\sin u}{\cos(3u - \pi/2)} = \frac{\sin u}{\sin 3u} = \frac{3}{5}$$

Using $\sin 3u = \sin u\,(3 - 4\sin^2 u)$:

$$\frac{1}{3 - 4\sin^2 u} = \frac{3}{5} \implies 3 - 4\sin^2 u = \frac{5}{3} \im
plies \sin^2 u = \frac{1}{3}$$

**Computing $CD$.** Since $\beta = 2\alpha - \pi$, we get $D = (\cos(2\alpha-\pi
),\, \sin(2\alpha-\pi)) = (-\cos 2\alpha,\, -\sin 2\alpha)$. Then:

$$CD = \sqrt{(1+\cos 2\alpha)^2 + \sin^2 2\alpha} = \sqrt{2 + 2\cos 2\alpha} = 2
\cos\alpha$$

Now $\cos\alpha = 2\cos^2 u - 1 = 2\cdot\frac{2}{3} - 1 = \frac{1}{3}$, so:

$$CD = 2 \cdot \frac{1}{3} = \boxed{\dfrac{2}{3}}$$

**Verification.** $\sin^2 u = \frac{1}{3}$, $\sin u = \frac{1}{\sqrt{3}}$, $\sin
 3u = \frac{1}{\sqrt{3}}\cdot\frac{5}{3} = \frac{5}{3\sqrt{3}}$, and $\frac{\sin
