## Proof

**Step 1: Reducibility criterion.**

Since $\mathbb{C}[X,Y] = \mathbb{C}[Y][X]$ and $X^p + f(Y) + k$ is monic in $X$,
 Gauss's Lemma gives: $X^p + f(Y) + k$ is reducible in $\mathbb{C}[X,Y]$ iff red
ucible in $\mathbb{C}(Y)[X]$.

The field $\mathbb{C}(Y)$ contains all roots of unity. By the Kummer binomial ir
reducibility criterion, $X^p - a$ is reducible over a field $K$ containing the $
p$-th roots of unity iff $a \in K^q$ for some prime $q \mid p$. With $a = -(f(Y)
+k)$:

$$X^p + f(Y) + k \text{ reducible} \iff f(Y)+k \text{ is a } q\text{-th power of
 a polynomial for some prime } q \mid p.$$

(The rational function whose $q$-th power is a polynomial must be a polynomial i
tself, since $\mathbb{C}$ is algebraically closed so all constants are $q$-th po
wers.)

**Step 2: Each prime contributes at most one value of $k$.**

If $f(Y) + k = h(Y)^q$, then $n = q\deg h$, so $q \mid n$. Fix prime $q \mid \gc
d(p,n)$, $m = n/q$, $h = a_m Y^m + \cdots + a_0$. Matching coefficients of $h^q
= f + k$ from degree $n$ down: $a_m^q = c_n$ gives $q$ choices; each subsequent
$a_{m-j}$ is uniquely determined (the coefficient of $Y^{n-j}$ in $h^q$ is linea

Replacing $a_m \to \omega\, a_m$ (for $q$-th root of unity $\omega$) scales ever
y $a_{m-j} \to \omega\, a_{m-j}$ by induction. All constraint equations are homo
geneous of degree $q$, hence invariant, and $k = a_0^q - c_0$ is invariant. So a
ll $q$ choices yield the **same** $k$. Each prime gives at most one $k$.

**Step 3: Distinct primes yield the same $k$ (Mason–Stothers).**

Suppose $f + k_1 = h_1^{q_1}$ and $f + k_2 = h_2^{q_2}$ for distinct primes $q_1
, q_2 \mid \gcd(p,n)$ with $k_1 \neq k_2$. Then $h_1^{q_1} - h_2^{q_2} = k_1 - k
_2 \neq 0$.

If $d = \gcd(h_1, h_2)$ is non-constant, write $h_1 = du$, $h_2 = dv$, $\gcd(u,v
)=1$. Then $d^{q_1}u^{q_1} - d^{q_2}v^{q_2} = k_1-k_2$; factoring $d^{\min(q_1,q
_2)}$ forces $d$ constant — contradiction. So $\gcd(h_1, h_2) = 1$.

Apply Mason–Stothers to $A = h_1^{q_1}$, $B = k_2 - k_1$ (nonzero constant), $C
= h_2^{q_2}$, pairwise coprime with $A + B = C$:
$$n \leq \deg(\operatorname{rad}(ABC)) - 1 = \deg h_1 + \deg h_2 - 1 = \frac{n}{
q_1} + \frac{n}{q_2} - 1.$$
This requires $n\!\left(1 - \frac{1}{q_1} - \frac{1}{q_2}\right) \leq -1$. But f
or distinct primes $\geq 2$: $\frac{1}{q_1} + \frac{1}{q_2} \leq \frac{1}{2} + \
frac{1}{3} = \frac{5}{6}$, so $1 - \frac{1}{q_1} - \frac{1}{q_2} \geq \frac{1}{6
} > 0$, giving $n/6 \leq -1$ — impossible. Hence $k_1 = k_2$.
