**问题**：$c, d$ 独立且均匀地选自 $\{1, \ldots, n\}$。$p_n = \Pr[c+d \text{ 为完
全平方数}]$。求 $\lim_{n\to\infty} p_n\sqrt{n}$，形式为 $r(\sqrt{s}-t)$。

---

### 设定

设 $s = c+d$。满足 $c+d=s$ 且 $1\le c,d\le n$ 的对 $(c,d)$ 的数量为：
$$N(s) = \begin{cases} s-1, & 2 \le s \le n+1, \\ 2n+1-s, & n+2 \le s \le 2n. \e
nd{cases}$$
（两个公式在 $s=n+1$ 时均给出 $n$，因此边界一致。）

总对数 $= n^2$。$[2, 2n]$ 中的完全平方数为 $k^2$，其中 $k=2,3,\ldots,\lfloor\sqr
t{2n}\rfloor$。因此
$$p_n = \frac{1}{n^2}\sum_{k=2}^{\lfloor\sqrt{2n}\rfloor} N(k^2).$$

设 $a = \lfloor\sqrt{n+1}\rfloor$（使得 $k^2\le n+1$ 的最大 $k$）且 $b = \lfloor
\sqrt{2n}\rfloor$。则
$$p_n\sqrt{n} = \frac{\sqrt{n}}{n^2}\bigl(S_1 + S_2\bigr) = \frac{S_1+S_2}{n^{3/
2}},$$
其中
$$S_1 = \sum_{k=2}^{a}(k^2-1), \qquad S_2 = \sum_{k=a+1}^{b}(2n+1-k^2).$$

### 第一部分求和

$$S_1 = \sum_{k=1}^{a}k^2 - 1 - (a-1) = \frac{a(a+1)(2a+1)}{6} - a = \frac{a^3}{
3}+\frac{a^2}{2}-\frac{5a}{6}.$$

由于 $a = \sqrt{n}+O(1)$，有 $a^3 = n^{3/2}+O(n)$ 且 $a^2 = n + O(\sqrt{n})$，因
此
$$\frac{S_1}{n^{3/2}} = \frac{1}{3} + O(n^{-1/2}) \;\longrightarrow\; \frac{1}{3
}.$$

### 第二部分求和

$$S_2 = (2n+1)(b-a) - \sum_{k=a+1}^{b}k^2 = (b-a)\!\left(2n+\tfrac{5}{6}\right)
- \frac{b^3-a^3}{3} - \frac{b^2-a^2}{2}.$$

代入 $b^3-a^3=(b-a)(b^2+ab+a^2)$ 且 $b^2-a^2=(b-a)(b+a)$：
$$S_2 = (b-a)\left[2n+\tfrac{5}{6} - \tfrac{b^2+ab+a^2}{3} - \tfrac{b+a}{2}\righ
t].$$

对于 $a\sim\sqrt{n}$，$b\sim\sqrt{2n}$：$b-a\sim(\sqrt2-1)\sqrt{n}$，$b^2+ab+a^2
\sim(3+\sqrt2)\,n$，$b+a\sim(\sqrt2+1)\sqrt{n}$。括号项为
$$\left(1-\tfrac{\sqrt2}{3}\right)n + O(\sqrt{n}).$$

因此
$$\frac{S_2}{n^{3/2}} \;\longrightarrow\; (\sqrt2-1)\!\left(1-\tfrac{\sqrt2}{3}\
right) = \frac{(\sqrt2-1)(3-\sqrt2)}{3} = \frac{4\sqrt2-5}{3}.$$

### 组合求和

$$\lim_{n\to\infty} p_n\sqrt{n} = \frac{1}{3} + \frac{4\sqrt2-5}{3} = \frac{4\sq
rt2-4}{3} = \frac{4}{3}(\sqrt2-1).$$

### 数值验证

对于 $n=10{,}000$：$a=100$，$b=141$。$S_1 = 338{,}250$，$S_2 = 214{,}020$，总计
$= 552{,}270$，得出 $p_n\sqrt{n} = 0.55227$，对比 $\frac{4(\sqrt2-1)}{3}\approx
0.55228$。✓

### 结果

$$\boxed{\lim_{n\to\infty} p_n\sqrt{n} = \tfrac{4}{3}(\sqrt{2}-1)}$$

形式为 $r(\sqrt{s}-t)$，其中 $r=\frac{4}{3}$，$s=2$，$t=1$。
