## 解答

**第一步：化简被积函数。**

利用 Euler 反射公式 $\Gamma(z)\Gamma(1-z) = \dfrac{\pi}{\sin(\pi z)}$，取 $z = i
x$：

$$\Gamma(ix)\,\Gamma(1-ix) = \frac{\pi}{\sin(\pi i x)} = \frac{\pi}{i\sinh(\pi x
)}.$$

又因 $\Gamma(1+ix) = ix\,\Gamma(ix)$，故

$$\Gamma(1+ix)\,\Gamma(1-ix) = ix\cdot\Gamma(ix)\,\Gamma(1-ix) = ix\cdot\frac{\p
i}{i\sinh(\pi x)} = \frac{\pi x}{\sinh(\pi x)}.$$

于是原积分化为

$$I = \int_{-\infty}^{\infty}\frac{\pi x}{\sinh(\pi x)}\,dx.$$

**第二步：验证收敛性。**

- 在 $x=0$ 附近，$\dfrac{\pi x}{\sinh(\pi x)}\to 1$，无奇性。
- 当 $x\to\pm\infty$，$\sinh(\pi x)\sim \tfrac12 e^{\pi|x|}$，故被积函数 $\sim 2
\pi|x|e^{-\pi|x|}$，指数衰减。

且 $x/\sinh(\pi x)$ 为偶函数（奇/奇），所以

$$I = 2\int_{0}^{\infty}\frac{\pi x}{\sinh(\pi x)}\,dx.$$

**第三步：换元。**

令 $t = \pi x$，$dx = dt/\pi$：

$$I = \frac{2}{\pi}\int_{0}^{\infty}\frac{t}{\sinh t}\,dt.$$

**第四步：展开 $\dfrac{1}{\sinh t}$ 并逐项积分。**

对 $t>0$，

$$\frac{1}{\sinh t} = \frac{2e^{-t}}{1-e^{-2t}} = 2\sum_{n=0}^{\infty}e^{-(2n+1)
t}.$$

由单调收敛可逐项积分：

$$\int_{0}^{\infty}\frac{t}{\sinh t}\,dt = 2\sum_{n=0}^{\infty}\int_{0}^{\infty}
t\,e^{-(2n+1)t}\,dt = 2\sum_{n=0}^{\infty}\frac{1}{(2n+1)^2}.$$

**第五步：求奇数倒数平方和。**

$$\sum_{n=0}^{\infty}\frac{1}{(2n+1)^2} = \sum_{k=1}^{\infty}\frac{1}{k^2} - \su
m_{m=1}^{\infty}\frac{1}{(2m)^2} = \frac{\pi^2}{6} - \frac{1}{4}\cdot\frac{\pi^2
}{6} = \frac{\pi^2}{8}.$$

因此

$$\int_{0}^{\infty}\frac{t}{\sinh t}\,dt = 2\cdot\frac{\pi^2}{8} = \frac{\pi^2}{
4}.$$

**第六步：合并结果。**

$$I = \frac{2}{\pi}\cdot\frac{\pi^2}{4} = \frac{\pi}{2}.$$

$$\boxed{\displaystyle\int_{-\infty}^{\infty}\Gamma(1+ix)\,\Gamma(1-ix)\,dx = \f
rac{\pi}{2}.}$$
