## Proof

The sequence $(u_n)$ consists of integers and is bounded. Since the $u_n$ are bo
unded integers, there exist integers $m \leq M$ such that $m \leq u_n \leq M$ fo
r all $n$. Thus each $u_n$ takes values in the finite set $\{m, m+1, \ldots, M\}
$, which has $M - m + 1$ elements.

The recurrence
$$u_n = \frac{u_{n-1} + u_{n-2} + u_{n-3}\,u_{n-4}}{u_{n-1}\,u_{n-2} + u_{n-3} +
 u_{n-4}}$$
is **deterministic of order 4**: the value of $u_n$ is completely determined by
the 4-tuple of preceding values $(u_{n-1}, u_{n-2}, u_{n-3}, u_{n-4})$. (The pro
blem states the sequence satisfies this recurrence, so the denominator is nonzer
o whenever the recurrence is applied.)

Define the **state** at index $n$ (for $n \geq 5$) as:
$$S_n = (u_{n-1},\; u_{n-2},\; u_{n-3},\; u_{n-4}).$$

Each component of $S_n$ lies in $\{m, \ldots, M\}$, so $S_n$ takes values in the
 finite set $\{m, \ldots, M\}^4$, which has $(M - m + 1)^4$ elements.

Since the sequence is infinite, we have infinitely many states $S_5, S_6, S_7, \
ldots$ drawn from a **finite** set. By the **Pigeonhole Principle**, there exist
 indices $i < j$ with $j \geq 5$ such that:
$$S_i = S_j,$$
that is,
$$(u_{i-1}, u_{i-2}, u_{i-3}, u_{i-4}) = (u_{j-1}, u_{j-2}, u_{j-3}, u_{j-4}).$$

Because the recurrence is deterministic, equal states produce equal successors:
$$u_i = u_j.$$

Then the states at the next step also coincide:
$$S_{i+1} = (u_i, u_{i-1}, u_{i-2}, u_{i-3}) = (u_j, u_{j-1}, u_{j-2}, u_{j-3})
= S_{j+1},$$

which gives $u_{i+1} = u_{j+1}$. By induction, for all $k \geq 0$:
$$u_{i+k} = u_{j+k}.$$

Setting $p = j - i > 0$, this means $u_{n+p} = u_n$ for all $n \geq i$. Therefor
e the sequence is **periodic with period $p$** for all $n \geq i$, i.e., periodi
c for sufficiently large $n$. $\blacksquare$
