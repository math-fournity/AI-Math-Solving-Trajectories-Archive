## Proof

We seek the number of 3×3 matrices $A$ with integer entries satisfying $AA^{T} =
 I$.

**Step 1: Each row is an integer unit vector.**

Let the rows of $A$ be $r_1, r_2, r_3 \in \mathbb{Z}^3$. The condition $AA^T = I
$ means the rows are orthonormal: $\|r_i\|^2 = 1$ and $r_i \cdot r_j = 0$ for $i
 \neq j$.

For a row $r_i = (a, b, c)$ with $a, b, c \in \mathbb{Z}$, the condition $\|r_i\
|^2 = a^2 + b^2 + c^2 = 1$ forces exactly one of $a, b, c$ to be $\pm 1$ and the
 other two to be $0$. Thus each row is a signed standard basis vector: $r_i \in
\{\pm e_1, \pm e_2, \pm e_3\}$.

**Step 2: Rows form a signed permutation of the basis.**

Mutual orthogonality ($r_i \cdot r_j = 0$ for $i \neq j$) forces the three rows
to point in three distinct coordinate directions. Hence the underlying (unsigned
) directions form a permutation of $\{e_1, e_2, e_3\}$, and each chosen directio
n carries an independent sign $\pm 1$.

**Step 3: Count.**

- Number of permutations of the three basis directions: $3! = 6$.
- Number of independent sign choices (one per row): $2^3 = 8$.

Total: $6 \times 8 = 48$.

**Verification.** Every such matrix is a signed permutation matrix, which is ort
hogonal: $AA^T = I$ since rows are orthonormal. Conversely, every integer orthog
onal matrix must have unit-norm integer rows, which are signed basis vectors as
shown. So the count is exact.

The cardinality of the set is $\boxed{48}$.
