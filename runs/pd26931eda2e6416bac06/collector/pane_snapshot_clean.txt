## Proof

**Setup.** Let $ABC$ be isosceles with the apex at $A$ (where the two equal side
s meet), so $AB = AC$ and $\angle BAC = \theta$. Set $AB = AC = 1$. Place coordi
nates with $A$ at the origin and the angle bisector of $\angle A$ along the posi
tive $x$-axis:

$$A = (0,0),\quad B = (\cos\tfrac{\theta}{2},\,\sin\tfrac{\theta}{2}),\quad C =
(\cos\tfrac{\theta}{2},\,-\sin\tfrac{\theta}{2}).$$

The base $BC$ is the vertical line $x = \cos\frac{\theta}{2}$.

**Computing the reflections.**

- **$A'$** (reflect $A$ across line $BC$, i.e. across $x=\cos\frac\theta2$):
$$A' = \bigl(2\cos\tfrac\theta2,\;0\bigr).$$

- **$B'$** (reflect $B$ across line $AC$). Line $AC$ passes through the origin w
ith unit direction $u = (\cos\frac\theta2, -\sin\frac\theta2)$. The reflection f
ormula is $P' = 2(P\cdot u)u - P$. With $P = B$:
$$B\cdot u = \cos^2\tfrac\theta2 - \sin^2\tfrac\theta2 = \cos\theta,$$
$$B' = 2\cos\theta\,(\cos\tfrac\theta2,-\sin\tfrac\theta2) - (\cos\tfrac\theta2,
\sin\tfrac\theta2) = \bigl(\cos\tfrac\theta2(2\cos\theta-1),\;-\sin\tfrac\theta2
(2\cos\theta+1)\bigr).$$

- **$C'$** (reflect $C$ across line $AB$). By symmetry (line $AB$ has direction
$(\cos\frac\theta2,\sin\frac\theta2)$):
$$C' = \bigl(\cos\tfrac\theta2(2\cos\theta-1),\;\sin\tfrac\theta2(2\cos\theta+1)
\bigr).$$

Note $B'$ and $C'$ are mirror images across the $x$-axis, and $A'$ lies on the $
x$-axis, so $\triangle A'B'C'$ is isosceles with symmetry axis the $x$-axis. It
is equilateral iff $A'B' = B'C'$.

**Side lengths.** Let $c = \cos\theta$.

$$B'C' = 2\sin\tfrac\theta2\,(2c+1), \qquad B'C'^2 = 4\sin^2\tfrac\theta2\,(2c+1
)^2.$$

$$A'B'^2 = \cos^2\tfrac\theta2\,(3-2c)^2 + \sin^2\tfrac\theta2\,(2c+1)^2.$$

**Equilateral condition** $A'B'^2 = B'C'^2$:

$$\cos^2\tfrac\theta2\,(3-2c)^2 = 3\sin^2\tfrac\theta2\,(2c+1)^2.$$

Using $\cos^2\frac\theta2 = \frac{1+c}{2}$, $\sin^2\frac\theta2 = \frac{1-c}{2}$
:

$$\frac{1+c}{2}(3-2c)^2 = 3\cdot\frac{1-c}{2}(2c+1)^2,$$

$$(1+c)(3-2c)^2 = 3(1-c)(2c+1)^2.$$

Expanding both sides:
- Left: $(1+c)(9-12c+4c^2) = 9 - 3c - 8c^2 + 4c^3$.
- Right: $3(1-c)(4c^2+4c+1) = 3(-4c^3+3c+1) = -12c^3+9c+3$.

Setting equal and simplifying:

$$16c^3 - 8c^2 - 12c + 6 = 0 \;\;\Longrightarrow\;\; 8c^3 - 4c^2 - 6c + 3 = 0.$$

**Factoring.** Testing $c = \tfrac12$: $1 - 1 - 3 + 3 = 0$. ✓ So $(c-\tfrac12)$
is a factor. Synthetic division gives

$$8c^3 - 4c^2 - 6c + 3 = (c-\tfrac12)(8c^2 - 6) = 2\bigl(c-\tfrac12\bigr)\bigl(4
c^2-3\bigr).$$

Roots: $c = \tfrac12$, $c = \tfrac{\sqrt3}{2}$, $c = -\tfrac{\sqrt3}{2}$, i.e.

$$\theta = 60^\circ,\quad \theta = 30^\circ,\quad \theta = 150^\circ.$$

**Validity check.** All three lie in $(0^\circ,180^\circ)$. The triangle $A'B'C'
$ is non-degenerate iff $B'C'\neq 0$, i.e. $2\cos\theta+1\neq 0$, i.e. $\theta\n
eq 120^\circ$ — none of our solutions equals $120^\circ$. Quick verification for
 $\theta=60^\circ$: $A'=(\sqrt3,0)$, $B'=(0,-1)$, $C'=(0,1)$, giving side length
s $2,2,2$. ✓

**Conclusion.** $S = \{30^\circ,\, 60^\circ,\, 150^\circ\}$, and

$$\sum_{\theta\in S}\theta = 30 + 60 + 150 = \boxed{240}.$$
