# Problem

A high-security data center consists of 5 server racks, each containing 4 designated drive slots, every one of which is currently occupied by a unique hard drive. To prevent data corruption during a system overhaul, a technician must perform a "total migration": every drive must be removed and re-inserted into a slot. 

The migration follows one strict security protocol: no two drives that previously occupied the same rack are permitted to be placed together in the same rack again. Every rack and every individual slot within those racks is distinct and distinguishable.

If the total number of valid ways to rearrange the 20 hard drives into the slots can be expressed in the form $2^a \cdot 3^b \cdot 5^c$ (where $a, b,$ and $c$ are non-negative integers), find the value of $a+b+c$.
