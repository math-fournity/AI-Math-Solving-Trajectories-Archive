## Proof

**Well-definedness.** For each $n \geq 1$, the integrand $f_n(x) = \frac{\sin(x^
2+n^2)}{x^2+n^2}$ is continuous on $\mathbb{R}$ (the denominator satisfies $x^2+
n^2 \geq n^2 > 0$). Moreover,

$$|f_n(x)| = \frac{|\sin(x^2+n^2)|}{x^2+n^2} \leq \frac{1}{x^2+n^2} \leq \frac{1
}{x^2+1},$$

and $g(x) = \frac{1}{x^2+1}$ is Lebesgue-integrable on $\mathbb{R}$ with $\int_{
\mathbb{R}} g\,d\lambda = \pi < \infty$. Hence $f_n$ is dominated by an integrab
le function, so $f_n \in L^1(\mathbb{R},\lambda)$ and $I_n = \int_{\mathbb{R}} f
_n\,d\lambda$ is well-defined (in fact absolutely integrable) for every $n \geq
1$.

**The limit.** Using the same domination, we obtain the sharp bound

$$|I_n| \leq \int_{\mathbb{R}} |f_n(x)|\,d\lambda(x) \leq \int_{\mathbb{R}} \fra
c{dx}{x^2+n^2}.$$

Computing the last integral explicitly,

$$\int_{\mathbb{R}} \frac{dx}{x^2+n^2} = \frac{1}{n}\Big[\arctan\!\Big(\frac{x}{
n}\Big)\Big]_{-\infty}^{+\infty} = \frac{1}{n}\cdot\Big(\frac{\pi}{2}-\Big(-\fra
c{\pi}{2}\Big)\Big) = \frac{\pi}{n}.$$

Therefore, for every $n \geq 1$,

$$0 \leq |I_n| \leq \frac{\pi}{n}.$$

Since $\frac{\pi}{n} \to 0$ as $n \to \infty$, the squeeze theorem yields

$$\lim_{n\to\infty} I_n = 0.$$
