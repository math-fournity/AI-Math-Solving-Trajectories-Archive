## Solution

**Setup.** Write $x = n + f$ where $n = \lfloor x \rfloor$ is a non-negative int
eger and $f = \{x\} \in [0,1)$. Since $1 \le x \le 99$, we have $n \in \{1, 2, \
dots, 99\}$ (with $n=99$ only when $f=0$).

**Deriving the condition.**
$$x^2 = (n+f)^2 = n^2 + 2nf + f^2,$$
so $\{x^2\} = \{2nf + f^2\}$ (since $n^2$ is an integer), while $\{x\}^2 = f^2$.

The Balanced condition $\{x^2\} = \{x\}^2$ becomes
$$\{2nf + f^2\} = f^2.$$
Since $0 \le f^2 < 1$, this holds if and only if $2nf + f^2 = f^2 + k$ for some
integer $k \ge 0$, i.e.
$$2nf \in \mathbb{Z}.$$

**Enumerating solutions.** For a fixed integer $n$, the condition $2nf \in \math
bb{Z}$ with $0 \le f < 1$ gives
$$f = \frac{m}{2n}, \qquad m = 0, 1, \dots, 2n-1,$$
yielding $x = n + \tfrac{m}{2n}$. We must also enforce $x \le 99$.

- For $n = 1, 2, \dots, 98$: the largest value is $n + \tfrac{2n-1}{2n} = n+1 -
\tfrac{1}{2n} < n+1 \le 99$, so all $2n$ values are valid.
- For $n = 99$: we need $99 + f \le 99$, so $f = 0$, giving only $x = 99$.

**Summing.** For $n \in \{1,\dots,98\}$:
$$\sum_{m=0}^{2n-1}\!\Bigl(n + \tfrac{m}{2n}\Bigr) = 2n\cdot n + \frac{1}{2n}\cd
ot\frac{(2n-1)(2n)}{2} = 2n^2 + \frac{2n-1}{2}.$$

Therefore
$$S = \sum_{n=1}^{98}\!\Bigl(2n^2 + \tfrac{2n-1}{2}\Bigr) + 99 = 2\sum_{n=1}^{98
}n^2 + \frac{1}{2}\sum_{n=1}^{98}(2n-1) + 99.$$

Using $\sum_{n=1}^{98} n^2 = \dfrac{98\cdot 99\cdot 197}{6} = 318549$ and $\sum_
{n=1}^{98}(2n-1) = 98^2 = 9604$:

$$S = 2\cdot 318549 + \frac{9604}{2} + 99 = 637098 + 4802 + 99 = 641999.$$

Since $S = 641999$ is already an integer,

$$\lfloor S \rfloor = \boxed{641999}.$$
