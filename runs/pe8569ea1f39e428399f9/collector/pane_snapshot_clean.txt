## Proof

**Reformulation.** The condition $x - y \geq \frac{xy}{25}$ for $x > y$ is equiv
alent to:
$$\frac{1}{y} - \frac{1}{x} \geq \frac{1}{25}.$$

**Key observation.** If $A = \{a_1 < a_2 < \cdots < a_k\}$ satisfies the conditi
on for all consecutive pairs (i.e., $\frac{1}{a_i} - \frac{1}{a_{i+1}} \geq \fra
c{1}{25}$ for all $i$), then it satisfies the condition for all pairs, since for
 $i < j$:
$$\frac{1}{a_i} - \frac{1}{a_j} = \sum_{m=i}^{j-1}\left(\frac{1}{a_m} - \frac{1}
{a_{m+1}}\right) \geq \frac{j-i}{25} \geq \frac{1}{25}.$$

So it suffices to enforce the condition on consecutive elements.

**The recurrence.** The condition $\frac{1}{a_i} - \frac{1}{a_{i+1}} \geq \frac{
1}{25}$ rearranges to:
$$a_{i+1} \geq \frac{25\,a_i}{25 - a_i},$$
which requires $a_i < 25$ (i.e., $a_i \leq 24$) for any successor to exist.

Define $f(x) = \frac{25x}{25-x}$. Note $f$ is strictly increasing on $[0,25)$ si
nce $f'(x) = \frac{625}{(25-x)^2} > 0$.

**Greedy is optimal.** Define the greedy sequence $g_1 = 1$ and $g_{i+1} = \lcei
l f(g_i) \rceil$ (the smallest integer $\geq f(g_i)$).

*Claim:* For any valid set $\{a_1 < \cdots < a_k\}$, we have $a_i \geq g_i$ for
all $i \leq k$.

*Proof by induction:* $a_1 \geq 1 = g_1$. If $a_i \geq g_i$, then $a_{i+1} \geq
f(a_i) \geq f(g_i)$ (since $f$ is increasing), and since $a_{i+1}$ is an integer
, $a_{i+1} \geq \lceil f(g_i) \rceil = g_{i+1}$. $\square$

**Upper bound: $|A| \leq 9$.** For any valid set of size $\geq 9$, the claim giv

rac{1}{54} < \frac{1}{25}$. A 10th element would require $\frac{1}{a_9} - \frac{

a_9} \leq \frac{1}{54} < \frac{1}{25}$. Contradiction. So $|A| \leq 9$.
