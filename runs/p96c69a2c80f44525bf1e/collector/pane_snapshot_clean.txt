## Proof

**Claim:** Yes, $f$ must be constant.

**Proof.**

Since $\Omega$ is simply connected, it is in particular connected. The function
$f$ is analytic on $\Omega$, hence continuous. The hypothesis is that $\cos f$ i
s constant, i.e., there exists $c \in \mathbb{C}$ such that
$$\cos(f(z)) = c \quad \text{for all } z \in \Omega.$$

Consider the preimage
$$S := \{w \in \mathbb{C} : \cos w = c\}.$$

We show $S$ is a discrete subset of $\mathbb{C}$. The function $w \mapsto \cos w
$ is entire and nonconstant, so for every $w_0 \in S$, $w_0$ is an isolated poin
t of $S$: indeed, since $\cos$ is holomorphic and nonconstant, its zeros of $\co
s w - c$ are isolated (the zeros of a nonconstant holomorphic function on a doma
in are isolated, and $\cos w - c$ is nonconstant entire). Hence every point of $
S$ is isolated, so $S$ is discrete.

Now $f(\Omega) \subseteq S$, since $\cos(f(z)) = c$ for all $z \in \Omega$. Beca
use $f$ is continuous and $\Omega$ is connected, the image $f(\Omega)$ is a conn
ected subset of $\mathbb{C}$. A connected subset of a discrete set must be a sin
gle point: for if $f(\Omega)$ contained two distinct points, discreteness would
give disjoint open neighborhoods separating them, contradicting connectedness.

Therefore $f(\Omega) = \{w_0\}$ for some $w_0 \in \mathbb{C}$, i.e., $f(z) = w_0
$ for all $z \in \Omega$. Hence $f$ is constant. $\blacksquare$

**Remark.** The argument uses only that $\Omega$ is connected; simple connectivi
ty is not needed. The key ingredients are: (i) the continuity of $f$ preserves c
onnectedness of $\Omega$, and (ii) the level set of a nonconstant entire functio
n ($\cos w - c$) is discrete, so any connected subset of it is a point. In fact
the same conclusion holds for any nonconstant entire function $g$ in place of $\
cos$: if $g \circ f$ is constant with $g$ nonconstant entire, then $f$ is consta
nt on any connected domain.
