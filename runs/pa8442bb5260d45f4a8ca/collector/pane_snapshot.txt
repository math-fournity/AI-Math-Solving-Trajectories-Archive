**Answer: Yes, such a function exists.**

**Construction.** Let $1 \le p < \infty$. We construct a continuous function $f
\in L^p(\mathbb{R})$ and a sequence $\{x_n\}$ with $|x_n| \to \infty$ such that
$f(x_n) \to +\infty$.

For each integer $n \ge 2$, define a triangular "spike" centered at $x_n = n$ wi
th height $h_n = n$ and half-width $w_n = n^{-(p+2)}$:

$$\varphi_n(x) = \begin{cases} n\left(1 - \dfrac{|x - n|}{w_n}\right) & \text{if
 } |x - n| \le w_n, \\[6pt] 0 & \text{otherwise.} \end{cases}$$

Set
$$f(x) = \sum_{n=2}^{\infty} \varphi_n(x).$$

**The spikes are disjoint.** Since $w_n = n^{-(p+2)}$ and $p \ge 1$, we have $w_
n \le 2^{-3} = 1/8 < 1/2$ for all $n \ge 2$. The supports $[n - w_n, n + w_n]$ a
re contained in $(n - 1/2, n + 1/2)$, so they are pairwise disjoint.

**$f$ is continuous.** Each $\varphi_n$ is continuous, the supports are disjoint
 and locally finite (any bounded interval meets only finitely many supports), so
 $f$ is continuous. Moreover, $f$ is zero outside the union of the supports, so
$f$ is continuous on all of $\mathbb{R}$.

**$f \in L^p(\mathbb{R})$.** The $L^p$ contribution of a single triangular spike
 of height $h$ and half-width $w$ is:

$$\int_{-w}^{w} \left(h\frac{w - |x|}{w}\right)^p dx = 2h^p \int_0^w \left(\frac
{w-x}{w}\right)^p dx = 2h^p \cdot \frac{w}{p+1}.$$

By disjointness of supports:

$$\|f\|_p^p = \sum_{n=2}^{\infty} \frac{2\, h_n^p\, w_n}{p+1} = \frac{2}{p+1}\su
m_{n=2}^{\infty} n^p \cdot n^{-(p+2)} = \frac{2}{p+1}\sum_{n=2}^{\infty} \frac{1
}{n^2} < \infty.$$

**$f(x_n) \to \infty$.** At the center of each spike, $f(n) = \varphi_n(n) = n \
to +\infty$, while $|x_n| = n \to \infty$.

**Conclusion.** The function $f$ is continuous, belongs to $L^p(\mathbb{R})$ for
 every $1 \le p < \infty$, and satisfies $f(n) \to \infty$ along the sequence $x
_n = n$ with $|x_n| \to \infty$. The key mechanism is that $L^p$ integrability c
ontrols the *total mass* $\int |f|^p$, not pointwise values—so arbitrarily tall
spikes are permitted as long as they are sufficiently narrow.
