 whose partial sums each have the maximum number of distinct roots, while the co
efficients satisfy some algebraic relation over ℚ.

**Answer: Yes, such a power series exists.**

## Proof

**Lemma.** Let *P(x)* be a real polynomial of degree *n* ≥ 1 with *n* distinct r
eal roots and leading coefficient *aₙ* ≠ 0. Then there exists *ε* > 0 such that
for every real *a* with 0 < |*a*| < *ε*, the polynomial *P(x)* + *axⁿ⁺¹* has *n*
+1 distinct real roots.

*Proof of Lemma.* Let *r₁* < ··· < *rₙ* be the roots of *P*. Since each root is
simple, *P*′(*rᵢ*) ≠ 0. Set *F(x,a)* = *P(x)* + *axⁿ⁺¹*. We have *F(rᵢ, 0)* = 0
and ∂*F*/∂*x*(*rᵢ*, 0) = *P*′(*rᵢ*) ≠ 0. By the implicit function theorem, for |
*a*| sufficiently small, there exist real analytic functions *r̃ᵢ(a)* with *r̃ᵢ*(0
) = *rᵢ* and *F(r̃ᵢ(a), a)* = 0. These give *n* distinct real roots (distinct by
continuity, since the *rᵢ* are distinct).

For *a* ≠ 0, *F* has degree *n*+1, hence *n*+1 roots in ℂ (with multiplicity). S
ince *n* are real and non-real roots come in conjugate pairs, the remaining root
 is real.

By Vieta's formulas, the sum of all *n*+1 roots equals −*aₙ*/*a*. Thus the (*n*+
1)-th root equals −*aₙ*/*a* − Σ*r̃ᵢ(a)*, which diverges as *a* → 0 (since −*aₙ*/*
a* → ±∞ while Σ*r̃ᵢ(a)* → Σ*rᵢ*, which is bounded). For small enough |*a*|, this
root is far from all *r̃ᵢ(a)*, so all *n*+1 roots are distinct. □

**Construction.** Set *a₀* = 1 and *a₁* = 1. Then:
- *S₀(x)* = 1 has 0 roots. ✓
- *S₁(x)* = 1 + *x* has 1 distinct real root (*x* = −1). ✓

Inductively, suppose *Sₙ(x)* = Σₖ₌₀ⁿ *aₖxᵏ* has degree *n* (*aₙ* ≠ 0) and *n* di
stinct real roots. By the Lemma, there exists *εₙ₊₁* > 0 such that for 0 < |*a*|
 < *εₙ₊₁*, *Sₙ(x)* + *axⁿ⁺¹* has *n*+1 distinct real roots. Choose *aₙ₊₁* with:

0 < |*aₙ₊₁*| < min(*εₙ₊₁*, 1/(*n*+1)!)

This ensures:
1. *Sₙ₊₁* has *n*+1 distinct real roots (by the Lemma).
2. |*aₙ₊₁*| < 1/(*n*+1)!, so Σ|*aₖ*||*x*|ᵏ ≤ Σ|*x*|ᵏ/*k*! = *e*|ˣ|, giving infin
ite radius of convergence.

**Algebraic dependence.** Since *a₀* = 1 ∈ ℚ, the polynomial *x₀* − 1 ∈ ℚ[*x₀*]
vanishes at *a₀*. Thus {*a₀*} is algebraically dependent over ℚ, hence {*a₀*, *a
₁*, *a₂*, …} is **not** algebraically independent over ℚ.

**Conclusion.** The power series Σ*aₖxᵏ* constructed above satisfies:
- Each partial sum *Sₙ* has *n* distinct real roots (for all *n* ≥ 0).
- The coefficients are not algebraically independent over ℚ (since *a₀* = 1 ∈ ℚ)
.
- The series converges everywhere.

Therefore, such a power series exists. □
