## Proof

**Key idea.** The substitution $t = x^2$ is a bijection $[0,1] \to [0,1]$, which
 converts "polynomials in $x^2$" into ordinary polynomials in $t$, and converts
$L^2([0,1],dx)$ into a weighted $L^2$ space on $[0,1]$ where polynomials are den
se by the classical Weierstrass theorem.

---

**Step 1: Reformulation via substitution.**

Set $t = x^2$, so $x = \sqrt{t}$ and $dx = \frac{dt}{2\sqrt{t}}$. Define the uni
tary map
$$U : L^2([0,1],dx) \to L^2\!\left([0,1],\tfrac{dt}{2\sqrt{t}}\right), \qquad (U
f)(t) = f(\sqrt{t}).$$
This is an isometric isomorphism: $\|Uf\|^2 = \int_0^1 |f(\sqrt{t})|^2 \frac{dt}
{2\sqrt{t}} = \int_0^1 |f(x)|^2\,dx = \|f\|^2.$

Under $U$, a function $f_n(x) = \sum_{k=0}^n a_k x^{2k}$ maps to the ordinary po
lynomial $(Uf_n)(t) = \sum_{k=0}^n a_k t^k.$

So the question becomes: **Does $L^2([0,1], \mu)$ with $\mu = \frac{dt}{2\sqrt{t
}}$ have an orthonormal basis of polynomials?**

---

**Step 2: Polynomials are dense in $L^2([0,1],\mu)$.**

The measure $\mu$ is a finite Borel measure on $[0,1]$ with total mass $\mu([0,1
]) = \int_0^1 \frac{dt}{2\sqrt{t}} = 1$.

Two standard facts:
1. **Continuous functions are dense in $L^2([0,1],\mu)$** for any finite Borel m
easure $\mu$ on $[0,1]$ (Lusin's theorem / standard measure theory).
2. **Polynomials are uniformly dense in $C([0,1])$** (Weierstrass approximation
theorem).

Since $\|p - g\|_{L^2(\mu)} \le \sqrt{\mu([0,1])}\,\|p - g\|_\infty = \|p-g\|_\i
nfty$, uniform approximation implies $L^2(\mu)$-approximation. Composing: for an
y $f \in L^2([0,1],\mu)$ and $\varepsilon > 0$, pick $g \in C([0,1])$ with $\|f
- g\|_{L^2(\mu)} < \varepsilon/2$, then pick a polynomial $p$ with $\|g - p\|_\i
nfty < \varepsilon/2$, giving $\|f - p\|_{L^2(\mu)} < \varepsilon$.

Hence $\overline{\operatorname{span}\{1, t, t^2, \ldots\}} = L^2([0,1],\mu)$.

---

**Step 3: Gram–Schmidt produces the desired basis.**

Pulling back through $U^{-1}$: the set $\{1, x^2, x^4, x^6, \ldots\}$ has dense
linear span in $L^2([0,1],dx)$. These functions are linearly independent (a fini
te linear combination $\sum_{k=0}^N a_k x^{2k}$ vanishing a.e. on $[0,1]$ is a p
olynomial in $x$ vanishing on a set of positive measure, hence identically zero)
.

Apply Gram–Schmidt to the sequence $v_k(x) = x^{2k}$, $k = 0, 1, 2, \ldots$:
$$e_0 = \frac{v_0}{\|v_0\|}, \qquad e_n = \frac{v_n - \sum_{j=0}^{n-1}\langle e_
j, v_n\rangle\, e_j}{\|\,\cdot\,\|}, \quad n \ge 1.$$

Each $e_n$ is a linear combination of $v_0, \ldots, v_n$, so
$$e_n(x) = \sum_{k=0}^{n} c_{n,k}\, x^{2k},$$
which is exactly of the required form $f_n(x) = \sum_{k=0}^n a_k x^{2k}$.

The resulting $\{e_n\}_{n \ge 0}$ is an orthonormal set whose closed span equals
 the closed span of $\{x^{2k}\}_{k\ge 0}$, which is all of $L^2([0,1])$ by Step
2 (pulled back). Therefore $\{e_n\}_{n \ge 0}$ is a **complete orthonormal syste
m**, i.e., an orthonormal basis of $L^2([0,1])$.

---

**Conclusion.** $L^2([0,1])$ does admit an orthonormal basis $\{f_n\}_{n \ge 0}$
 with each $f_n(x) = \sum_{k=0}^n a_k x^{2k}$, obtained by applying Gram–Schmidt
 to $\{1, x^2, x^4, \ldots\}$. The crucial point is that $x \mapsto x^2$ is a bi
jection on $[0,1]$, so even polynomials are as expressive as all polynomials on
this interval. $\blacksquare$
