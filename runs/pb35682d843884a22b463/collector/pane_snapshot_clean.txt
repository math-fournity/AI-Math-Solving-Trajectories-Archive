## Solution

I need to count the number of non-similar triangles with all integer angles (in
degrees).

**Setup.** Two triangles are similar iff they have the same angles (up to orderi
ng). So I need to count unordered triples $\{a, b, c\}$ of positive integers wit
h $a + b + c = 180$. This is exactly the number of **partitions of 180 into exac
tly 3 positive parts**.

**Counting.** I count triples with $1 \le a \le b \le c$ and $a+b+c = 180$.

For fixed $a$, we need $b + c = 180 - a$ with $a \le b \le c$, i.e., $a \le b \l
e \lfloor(180-a)/2\rfloor$. The number of valid $b$ is:

$$\left\lfloor \frac{180-a}{2}\right\rfloor - a + 1$$

This is non-negative when $a \le 60$, so $a$ ranges from $1$ to $60$.

**Computing the sum.** Split by parity of $a$:

- **Odd** $a = 2k+1$ ($k = 0, 1, \ldots, 29$; 30 terms): Since $180 - (2k+1)$ is
 odd,
$$\left\lfloor \frac{179-2k}{2}\right\rfloor - (2k+1) + 1 = (89 - k) - 2k = 89 -
 3k$$

- **Even** $a = 2k$ ($k = 1, 2, \ldots, 30$; 30 terms): Since $180 - 2k$ is even
,
$$\frac{180-2k}{2} - 2k + 1 = 90 - k - 2k + 1 = 91 - 3k$$

**Sum over odd $a$:**
$$\sum_{k=0}^{29}(89 - 3k) = 30 \cdot 89 - 3 \cdot \frac{29 \cdot 30}{2} = 2670
- 1305 = 1365$$

**Sum over even $a$:**
$$\sum_{k=1}^{30}(91 - 3k) = 30 \cdot 91 - 3 \cdot \frac{30 \cdot 31}{2} = 2730
- 1395 = 1335$$

**Total:**
$$N = 1365 + 1335 = 2700$$

**Verification via known formula.** The number of partitions of $n$ into exactly
 3 parts is $\left\lfloor \frac{n^2+3}{12}\right\rfloor$. For $n=180$:

$$\left\lfloor \frac{32400+3}{12}\right\rfloor = \left\lfloor 2700.25\right\rflo
or = 2700 \quad \checkmark$$

Every triple of positive integers summing to 180 corresponds to a valid (non-deg
enerate) triangle, since all angles are strictly positive.

**Result:**

$$\frac{N}{100} = \frac{2700}{100} = \boxed{27}$$
