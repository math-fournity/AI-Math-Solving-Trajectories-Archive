## Solution

Let $N = 2020!$ and $M = 2019!$, so $N = 2020M$.

**Step 1: Reduce the sum.** As $\omega_k$ ranges over all $N$-th roots of unity,
 $\omega_k^{2020}$ ranges over all $M$-th roots of unity, each attained exactly
$2020$ times. Therefore

$$S = \sum_{k=1}^{N} \frac{2^M - 1}{\omega_k^{2020}+2} = 2020\sum_{\zeta^M=1} \f
rac{2^M-1}{\zeta+2}.$$

**Step 2: Evaluate via logarithmic derivative.** Let $f(x) = x^M - 1 = \prod_{\z
eta^M=1}(x-\zeta)$. Then

$$\frac{f'(x)}{f(x)} = \sum_{\zeta^M=1}\frac{1}{x-\zeta}.$$

Setting $x = -2$:

$$\sum_{\zeta^M=1}\frac{1}{-2-\zeta} = \frac{f'(-2)}{f(-2)} = \frac{M(-2)^{M-1}}
{(-2)^M-1}.$$

Hence

$$\sum_{\zeta^M=1}\frac{1}{\zeta+2} = -\frac{M(-2)^{M-1}}{(-2)^M-1}.$$

Since $M = 2019!$ is even, $(-2)^M = 2^M$ and $(-2)^{M-1} = -2^{M-1}$ (as $M-1$
is odd). Thus

$$\sum_{\zeta^M=1}\frac{1}{\zeta+2} = -\frac{M\cdot(-2^{M-1})}{2^M-1} = \frac{M\
cdot 2^{M-1}}{2^M-1}.$$

**Step 3: Compute $S$.**

$$S = 2020\cdot(2^M-1)\cdot\frac{M\cdot 2^{M-1}}{2^M-1} = 2020\cdot M\cdot 2^{M-
1} = 2020!\cdot 2^{2019!-1}.$$

**Step 4: Find $v_2(S)$.**

$$v_2(S) = v_2(2020!) + 2019! - 1.$$

Computing $v_2(2020!)$:

$$v_2(2020!) = 1010+505+252+126+63+31+15+7+3+1 = 2013.$$

Therefore

$$n = v_2(S) = 2013 + 2019! - 1 = 2019! + 2012.$$

**Step 5: Write $n = a! + b$ with $a$ maximal.** We need $a! \le n-1 = 2019!+201
1$ with $b = n - a! \ge 1$.

- $a = 2019$: $2019! \le 2019!+2011$ ✓, giving $b = 2012 \ge 1$ ✓.
- $a = 2020$: requires $2020! = 2020\cdot 2019! \le 2019!+2011$, i.e. $2019\cdot
 2019! \le 2011$, which is false.

So $a = 2019$, $b = 2012$, and

$$a + b = 2019 + 2012 = 4031 \equiv 31 \pmod{1000}.$$

**Answer: 31**
