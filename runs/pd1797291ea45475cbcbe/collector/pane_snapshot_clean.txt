# Solution

## Problem

Determine $f(k) = \lim_{n \to \infty} \frac{|S_n(k)|}{\pi(n)}$, where $S_n(k) =
\{1 \leq m \leq n : m \text{ has exactly } k \text{ ones in its binary represent
ation and } m \text{ is prime}\}$.

## Proof

**Key observation.** For any fixed non-negative integer $k$, the total number of
 integers in $[1, n]$ whose binary representation contains exactly $k$ ones is p
olynomial in $\log n$, while $\pi(n)$ grows like $n / \log n$. Hence the fractio
n of primes falling into such a vanishingly thin set must tend to zero.

---

**Step 1: Upper bound on the size of the ambient set.**

Let $L = \lfloor \log_2 n \rfloor + 1$, so every integer $m$ with $1 \leq m \leq
 n$ has a binary representation using at most $L$ bits. An integer with exactly
$k$ ones among (at most) $L$ bit positions is obtained by choosing which $k$ pos
itions carry a $1$. Therefore the number of integers in $[1, n]$ with exactly $k
$ ones in binary satisfies

$$\#\{1 \leq m \leq n : s_2(m) = k\} \;\leq\; \binom{L}{k},$$

where $s_2(m)$ denotes the number of ones in the binary expansion of $m$.

Since $S_n(k)$ consists of primes drawn from this ambient set,

$$|S_n(k)| \;\leq\; \binom{L}{k}.$$

**Step 2: Growth rate of the bound for fixed $k$.**

For fixed $k$,

$$\binom{L}{k} = \frac{L(L-1)\cdots(L-k+1)}{k!} \leq \frac{L^k}{k!} = O\!\left((
\log n)^k\right),$$

since $L = \lfloor \log_2 n \rfloor + 1 = \Theta(\log n)$.

**Step 3: Comparison with $\pi(n)$.**

By the Prime Number Theorem, $\pi(n) \sim \dfrac{n}{\log n}$, and in particular
$\pi(n) \to \infty$. Combining,

$$0 \;\leq\; \frac{|S_n(k)|}{\pi(n)} \;\leq\; \frac{\binom{L}{k}}{\pi(n)} \;\sim
\; \frac{O\!\left((\log n)^k\right)}{n/\log n} \;=\; O\!\left(\frac{(\log n)^{k+
1}}{n}\right).$$

**Step 4: Taking the limit.**

For every fixed $k \geq 0$,

$$\frac{(\log n)^{k+1}}{n} \;\xrightarrow{n \to \infty}\; 0,$$

since any fixed power of $\log n$ is $o(n)$. By the squeeze theorem,

$$f(k) = \lim_{n \to \infty} \frac{|S_n(k)|}{\pi(n)} = 0.$$

**Step 5: Sanity checks for small $k$.**

- **$k = 0$:** The only integer with zero ones in binary is $0 \notin [1,n]$, so
 $S_n(0) = \emptyset$ and $f(0) = 0$. ✓
- **$k = 1$:** Numbers with one $1$ in binary are powers of $2$; the only prime
power of $2$ is $2$ itself, so $|S_n(1)| = 1$ for all $n \geq 2$ and $f(1) = \li
m 1/\pi(n) = 0$. ✓
- **$k = 2$:** Such numbers have the form $2^a + 2^b$ ($a > b \geq 0$) $= 2^b(2^
{a-b}+1)$; primality forces $b = 0$, giving Fermat-type numbers $2^a + 1$, of wh
ich there are only $O(\log n)$ candidates up to $n$, so again $f(2) = 0$. ✓

These special cases are all consistent with the general argument.

---

## Conclusion

For every fixed non-negative integer $k$,

$$\boxed{f(k) = 0.}$$
