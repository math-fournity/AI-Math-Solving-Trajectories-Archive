## Proof

Let the hexagon have vertices $A_1, A_2, \dots, A_6$ on a circle of radius $R$,
with consecutive side lengths $2, 2, 7, 7, 11, 11$.

**Central angles.** Each side of length $s_i$ subtends a central angle $2\alpha_
i$ where
$$s_i = 2R\sin\alpha_i.$$
Since the six vertices lie on the circle and the hexagon is traversed once, the
central angles sum to $2\pi$:
$$\sum_{i=1}^{6} 2\alpha_i = 2\pi \implies \sum_{i=1}^{6}\alpha_i = \pi.$$

**Pairing equal sides.** The side lengths come in equal pairs, so:
$$\sin\alpha_1=\sin\alpha_2=\frac{1}{R},\quad \sin\alpha_3=\sin\alpha_4=\frac{7}
{2R},\quad \sin\alpha_5=\sin\alpha_6=\frac{11}{2R}.$$

Set $a=\alpha_1=\alpha_2$, $b=\alpha_3=\alpha_4$, $c=\alpha_5=\alpha_6$ (each in
 $(0,\pi/2)$ since $s_i < 2R$). Then
$$2a+2b+2c=\pi \implies a+b+c=\frac{\pi}{2}.$$

**Key equation.** Since $c = \frac{\pi}{2}-a-b$,
$$\sin c = \cos(a+b)=\cos a\cos b - \sin a\sin b.$$
Substituting $\sin a = 1/R$, $\sin b = 7/(2R)$, $\sin c = 11/(2R)$, and $\cos a
= \sqrt{1-1/R^2}$, $\cos b = \sqrt{1-49/(4R^2)}$:
$$\frac{11}{2R} = \sqrt{1-\frac{1}{R^2}}\sqrt{1-\frac{49}{4R^2}} - \frac{1}{R}\c
dot\frac{7}{2R}.$$

Let $x = R^2$. Rearranging:
$$\frac{11\sqrt{x}+7}{2x} = \frac{\sqrt{(x-1)(4x-49)}}{2x},$$
so $11\sqrt{x}+7 = \sqrt{(x-1)(4x-49)}$. Squaring:
$$121x + 154\sqrt{x} + 49 = 4x^2 - 53x + 49,$$
$$154\sqrt{x} = 4x^2 - 174x.$$
Setting $y = \sqrt{x} = R > 0$ and dividing by $y$:
$$4y^3 - 174y - 154 = 0 \implies 2y^3 - 87y - 77 = 0.$$

**Solving.** Test $y = 7$: $2(343) - 87(7) - 77 = 686 - 609 - 77 = 0$. ✓

Factoring: $2y^3 - 87y - 77 = (y-7)(2y^2+14y+11)$. The quadratic $2y^2+14y+11=0$
 has discriminant $196-88=108$ and roots $y = \frac{-14\pm\sqrt{108}}{4} < 0$, s
o $R = 7$ is the unique positive real root.

**Verification.** With $R=7$: $\sin a = 1/7$, $\sin b = 1/2$ (so $b=\pi/6$), $\s
in c = 11/14$. Check $a+b+c=\pi/2$:
$$\cos a\cos b - \sin a\sin b = \frac{4\sqrt{3}}{7}\cdot\frac{\sqrt{3}}{2} - \fr
ac{1}{7}\cdot\frac{1}{2} = \frac{12}{14}-\frac{1}{14} = \frac{11}{14} = \sin c.\
 \checkmark$$

All central angles $2a, 2b, 2c$ are less than $\pi$ (since $a,b,c\in(0,\pi/2)$),
 so the hexagon is convex and non-self-intersecting.

The distance from the command station (center) to the perimeter is the radius:

$$\boxed{R = 7\text{ km}}$$
