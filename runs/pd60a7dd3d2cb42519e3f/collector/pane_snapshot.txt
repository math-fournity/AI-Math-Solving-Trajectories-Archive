## Solution

This is an **isoperimetric problem** in the calculus of variations: minimize $J[
y]=\int_0^1\!\bigl[y^2+(y')^2\bigr]\,dt$ subject to $y(0)=0$, $y(1)=1$, and the
integral constraint $K[y]=\int_0^1 y\,dt=0$.

### Step 1. Augmented functional and Euler–Lagrange equation

Introduce a Lagrange multiplier $\lambda$ and form the augmented integrand
$$F(t,y,y') = y^2 + (y')^2 + \lambda\, y.$$
The Euler–Lagrange equation is
$$\frac{\partial F}{\partial y} - \frac{d}{dt}\frac{\partial F}{\partial y'} = 0
 \;\Longrightarrow\; (2y+\lambda) - 2y'' = 0,$$
i.e.
$$y'' - y = \frac{\lambda}{2}. \tag{1}$$

### Step 2. General solution

The ODE (1) has general solution
$$y(t) = A\,e^{t} + B\,e^{-t} - \frac{\lambda}{2}. \tag{2}$$

### Step 3. Apply the three constraints

**Boundary $y(0)=0$:**
$$A + B - \tfrac{\lambda}{2} = 0 \;\Longrightarrow\; A+B = \tfrac{\lambda}{2}. \
tag{3}$$

**Boundary $y(1)=1$:**
$$Ae + Be^{-1} - \tfrac{\lambda}{2} = 1. \tag{4}$$

**Integral constraint $\int_0^1 y\,dt = 0$:**
$$\int_0^1\!\bigl(Ae^t+Be^{-t}-\tfrac{\lambda}{2}\bigr)dt = A(e-1)+B(1-e^{-1})-\
tfrac{\lambda}{2}=0. \tag{5}$$

Using (3) to eliminate $\lambda/2 = A+B$:

From (5): $A(e-1)+B(1-e^{-1})-(A+B)=0$, which gives
$$A(e-2) - Be^{-1}=0 \;\Longrightarrow\; B = A\,e\,(e-2). \tag{6}$$

From (4): $Ae+Be^{-1}-(A+B)=1$, i.e. $A(e-1)+B(e^{-1}-1)=1$. Using $e^{-1}-1 = -
(e-1)/e$ and (6):
$$A(e-1) - A\,e(e-2)\cdot\frac{e-1}{e} = A(e-1)\bigl[1-(e-2)\bigr] = A(e-1)(3-e)
 = 1.$$
Hence
$$A = \frac{1}{(e-1)(3-e)},\qquad B = \frac{e(e-2)}{(e-1)(3-e)},\qquad \frac{\la
mbda}{2} = A+B = \frac{e-1}{3-e}.$$

### Step 4. The minimizing curve

Substituting into (2):
$$\boxed{\;y(t) = \frac{e^{t} + e(e-2)\,e^{-t} - (e-1)^{2}}{(e-1)(3-e)}\;}$$

**Verification of all constraints:**

- $y(0)=\frac{1+e(e-2)-(e-1)^2}{(e-1)(3-e)}=\frac{1+e^2-2e-e^2+2e-1}{(e-1)(3-e)}
=0.$ ✓
- $y(1)=\frac{e+(e-2)-(e-1)^2}{(e-1)(3-e)}=\frac{2e-2-e^2+2e-1}{(e-1)(3-e)}=\fra
c{4e-e^2-3}{(e-1)(3-e)}=\frac{-(e-1)(e-3)}{(e-1)(3-e)}=1.$ ✓
- $\int_0^1 y\,dt = A(e-1)+B(1-e^{-1})-\lambda/2 = \frac{1}{3-e}+\frac{e-2}{3-e}
-\frac{e-1}{3-e}=\frac{1+e-2-e+1}{3-e}=0.$ ✓

### Step 5. This is a global minimum

The integrand $L(y,y')=y^2+(y')^2$ is strictly convex in $(y,y')$, so $J$ is a c
onvex functional. The constraints (linear endpoint and integral conditions) defi
ne a convex feasible set. Therefore the stationary point satisfying the Euler–La
grange equation is the **unique global minimizer**.
