Proof

Let $\mathcal{H} = \ell^2(\mathbb{N})$ with orthonormal basis $(e_n){n=1}
^{\infty}$, and let $S$ be the unilateral shift defined by $Se_n = e{n+1}$ for
all $n \geq 1$.

Goal. Compute $d(S,\mathbb{K}(\mathcal{H})) = \inf_{K \in \mathbb{K}
(\mathcal{H})} |S - K|$.

────────────────────────────────────────────────────────────────────────────────

Step 1. $S$ is an isometry, so $|S| = 1$.

For every $x = \sum x_n e_n \in \mathcal{H}$, $$|Sx|^2 = \Big|\sum x_n
e_{n+1}\Big|^2 = \sum |x_n|^2 = |x|^2.$$ Hence $|S| = 1$. Since $0 \in
\mathbb{K}(\mathcal{H})$, $$d(S,\mathbb{K}(\mathcal{H})) \leq |S - 0| = 1.$$

────────────────────────────────────────────────────────────────────────────────

Step 2. The image of $S$ in the Calkin algebra is unitary.

Let $\pi : \mathbb{B}(\mathcal{H}) \to \mathcal{Q}(\mathcal{H}) := \mathbb{B}
(\mathcal{H})/\mathbb{K}(\mathcal{H})$ be the quotient map. We compute the
adjoint relations: $$S^S = I, \qquad SS^ = I - P_{e_1},$$ where $P_{e_1} =
\langle \cdot, e_1\rangle e_1$ is the rank-one projection onto $
\operatorname{span}(e_1)$, hence compact.

Passing through $\pi$: $$\pi(S)^\pi(S) = \pi(S^S) = \pi(I) = 1, \qquad
\pi(S)\pi(S)^ = \pi(SS^) = \pi(I - P_{e_1}) = \pi(I) = 1.$$ Therefore $\pi(S)$
is a unitary element of the Calkin algebra $\mathcal{Q}(\mathcal{H})$.

────────────────────────────────────────────────────────────────────────────────

Step 3. A unitary in a $C^*$-algebra has norm $1$.

For any unitary $u$ in a unital $C^*$-algebra, $u^*u = 1$, so $|u|^2 = |u^*u| =
|1| = 1$, giving $|u| = 1$. Thus $$|\pi(S)| = 1.$$

────────────────────────────────────────────────────────────────────────────────

Step 4. Lower bound via the quotient norm.

For every compact operator $K \in \mathbb{K}(\mathcal{H})$, we have $\pi(K) =
0$, so $$|\pi(S - K)| = |\pi(S) - \pi(K)| = |\pi(S)| = 1.$$ By definition of the
quotient norm (which equals the distance to the ideal), $$|\pi(S)| = \inf_{K \in
\mathbb{K}(\mathcal{H})} |S - K| = d(S, \mathbb{K}(\mathcal{H})).$$ Hence $$d(S,
\mathbb{K}(\mathcal{H})) = |\pi(S)| = 1.$$

────────────────────────────────────────────────────────────────────────────────

Conclusion

Combining the upper bound $d(S,\mathbb{K}(\mathcal{H})) \leq 1$ (Step 1) and the
lower bound $d(S,\mathbb{K}(\mathcal{H})) \geq 1$ (Steps 2–4),

$$\boxed{d!\left(S,,\mathbb{K}(\mathcal{H})\right) = 1}.$$
