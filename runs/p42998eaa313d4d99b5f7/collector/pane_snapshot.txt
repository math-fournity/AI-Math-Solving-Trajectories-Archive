## Solution

### Setup and Reformulation

Let $K$ be a simplicial complex. Choose orientations for all simplices, so the $
p$-simplices $\sigma_1, \dots, \sigma_m$ form a basis for $C_p(K)$ and the $(p+1
)$-simplices $\tau_1, \dots, \tau_n$ form a basis for $C_{p+1}(K)$. The boundary
 map $\partial_{p+1} : C_{p+1}(K) \to C_p(K)$ is represented by a matrix $B \in
\mathbb{Z}^{m \times n}$ with entries in $\{0, \pm 1\}$.

Two $p$-cycles $x$ and $z_j$ are **homologous** if and only if $x - z_j \in \ope
ratorname{im}(\partial_{p+1})$, i.e., there exists a $(p+1)$-chain $c$ such that
:
$$x = z_j + Bc.$$

Note that $x$ is automatically a cycle: $\partial_p(x) = \partial_p(z_j) + \part
ial_p(\partial_{p+1}c) = 0 + 0 = 0$, since $z_j \in Z_p(K)$ and $\partial_p \cir
c \partial_{p+1} = 0$.

Therefore, the optimization problem for each $j$ is:
$$\min_{c} \|z_j + Bc\|_1.$$

### Linear Programming Formulation

The 1-norm minimization is reformulated as a linear program by introducing auxil
iary variables $t_i \geq 0$ to bound each coordinate:

$$\boxed{\min \sum_{i=1}^{m} t_i \quad \text{subject to} \quad -t_i \leq (z_j +
Bc)_i \leq t_i \ \forall\, i, \quad t_i \geq 0 \ \forall\, i.}$$

Equivalently, splitting $x = z_j + Bc$ into positive and negative parts $x = u -
 v$ with $u, v \geq 0$:

$$\min \sum_{i=1}^m (u_i + v_i) \quad \text{s.t.} \quad Bc - u + v = -z_j, \quad
 u, v \geq 0.$$

To handle the free variable $c \in \mathbb{R}^n$, split $c = c^+ - c^-$ with $c^
+, c^- \geq 0$:

$$\min \ \mathbf{1}^T(u + v) \quad \text{s.t.} \quad \big[B \;\big|\; {-B} \;\bi
g|\; {-I_m} \;\big|\; I_m\big]\begin{pmatrix} c^+ \\ c^- \\ u \\ v \end{pmatrix}
 = -z_j, \quad c^+, c^-, u, v \geq 0.$$

### Total Unimodularity Guarantees Integer Solutions

**Key claim**: The boundary matrix $B$ of any simplicial complex is **totally un
imodular (TU)**.

**Proof of claim**: Any simplicial complex $K$ on $N$ vertices is a subcomplex o
f the standard $(N{-}1)$-simplex $\Delta^{N-1}$. The boundary matrix of $K$ is a
 submatrix of the boundary matrix of $\Delta^{N-1}$ (restricted to simplices pre
sent in $K$). By Heller's classical theorem (1957), the boundary matrices of a s
implex are TU. Since submatrices of TU matrices are TU, $B$ is TU. $\square$

**The constraint matrix $M = [B \mid {-B} \mid {-I_m} \mid I_m]$ is TU:**

1. **$(B \mid {-B})$ is TU**: Any $k \times k$ submatrix selecting columns from
$\{b_1, \dots, b_n, -b_1, \dots, -b_n\}$ either (a) selects both $b_j$ and $-b_j
$ for some $j$, giving two columns that are negatives of each other, hence deter
minant $0$; or (b) selects at most one from each pair $\{b_j, -b_j\}$, yielding
a submatrix that is a column-negated submatrix of $B$, hence determinant in $\{0
, \pm 1\}$.

2. **Appending unit columns preserves TU**: If $A$ is TU, then $(A \mid e_i)$ is
 TU for any unit vector $e_i$, because any square submatrix either avoids the ne
w column (hence is a submatrix of $A$) or uses it, in which case cofactor expans
ion along the single nonzero entry reduces to a minor of $A$. By induction, $(B
\mid {-B} \mid {-I_m} \mid I_m)$ is TU.

Since $M$ is TU and the right-hand side $-z_j$ is integer, the **Hoffman–Kruskal
 theorem** guarantees that the feasible polyhedron $\{x \geq 0 : Mx = -z_j\}$ ha
s **integer vertices**. Therefore, the LP has integer optimal solutions, and sol
ving the LP over $\mathbb{R}$ automatically produces integer-valued optimal chai
ns.

### The Solution Set $P_j(z_1, \ldots, z_r)$

For each $j \in \{1, \ldots, r\}$, define:

$$P_j(z_1, \ldots, z_r) = \left\{ z_j + Bc^* \ :\ c^* \text{ is an optimal solut
ion of } \min_c \|z_j + Bc\|_1 \right\}.$$

The optimization for each $j$ is **independent** of the other cycles (the homolo
gy class of $z_j$ and the boundary matrix $B$ are all that matter). The notation
 $P_j(z_1, \ldots, z_r)$ simply indexes the $j$-th cycle within the given collec
tion.

**Structure of $P_j$**: The set of optimal solutions of an LP forms a **face of
the feasible polytope**. Under the affine map $c \mapsto z_j + Bc$, the set $P_j
$ is the image of this optimal face—a convex polytope in $C_p(K)$. If the optima
l face is a single vertex, then $P_j$ is a singleton $\{x_j^*\}$, the unique opt
imal cycle. In general, $P_j$ may contain multiple optimal cycles, all achieving
 the same minimal 1-norm.

### Algorithm Summary

1. **Construct** the boundary matrix $B = \partial_{p+1} \in \mathbb{Z}^{m \time
s n}$ from the simplicial complex $K$.
2. **For each** $j = 1, \ldots, r$: solve the LP $\min \sum_i t_i$ subject to $-
t \leq z_j + Bc \leq t$, $t \geq 0$, with variables $c \in \mathbb{R}^n$, $t \in
 \mathbb{R}^m$.
3. **Extract** the optimal cycle(s) $x_j^* = z_j + Bc^*$ for each optimal soluti
on $c^*$.
4. The set of all such $x_j^*$ is $P_j(z_1, \ldots, z_r)$.

The LP is solvable in **polynomial time** (e.g., via interior-point or simplex m
ethods). Total unimodularity of $B$ ensures that the LP solutions are integral,
so no separate integer programming step is needed—the real relaxation exactly so
lves the integer problem.

### Correctness Verification

- **Feasibility**: $c = 0$ gives $x = z_j$, which is a valid cycle homologous to
 $z_j$, so the feasible region is nonempty.
- **Boundedness**: $\|z_j + Bc\|_1 \geq 0$, so the objective is bounded below by
 $0$.
- **Homology**: Every feasible $x = z_j + Bc = z_j + \partial_{p+1}c$ differs fr
om $z_j$ by a boundary, hence is homologous to $z_j$. ✓
- **Optimality**: The LP finds the global minimum of $\|x\|_1$ over the homology

- **Integrality**: TU of $B$ (via Heller's theorem and submatrix closure) + Hoff
