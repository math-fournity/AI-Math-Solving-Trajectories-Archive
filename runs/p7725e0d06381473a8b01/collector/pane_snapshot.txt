Since the roots of $F$ are expressible using the adjoined roots, $L \subseteq K(
M_1,\dots,M_m)$. (Even if individual roots rather than full splitting fields are
 adjoined, the field they generate is contained in $K(M_1,\dots,M_m)$, so $L$ is
 contained there as well.)

**Define the chain.** Set $K_i = K(M_1,\dots,M_i)$ and $G_i = \mathrm{Gal}(LK_i/
K_i) \cong \mathrm{Gal}(L/(L\cap K_i))$. Then:
- $G_0 = \mathrm{Gal}(L/K) = G$,
- $G_m = \{e\}$ (since $L \subseteq K_m$),
- $G_i \leq G_{i-1}$ for each $i$ (extending the base field shrinks the Galois g

**Claim.** $G_i \trianglelefteq G_{i-1}$ and $|G_{i-1}/G_i|$ divides $|H_i|$.

*Proof of Claim.* Since $M_i$ is a splitting field over $K_{i-1}$, the extension
 $K_i/K_{i-1}$ is Galois with $\mathrm{Gal}(K_i/K_{i-1}) = H_i$.

Both $L \cap K_i$ and $L \cap K_{i-1}$ are Galois over $K$ (as intersections of
Galois extensions of $K$). Since $L \cap K_{i-1} \subseteq L \cap K_i$, the exte
nsion $(L\cap K_i)/(L\cap K_{i-1})$ is Galois. By the fundamental theorem of Gal
ois theory, $G_i = \mathrm{Gal}(L/(L\cap K_i))$ is **normal** in $G_{i-1} = \mat
hrm{Gal}(L/(L\cap K_{i-1}))$.

For the order divisibility: the quotient satisfies
$$G_{i-1}/G_i \cong \mathrm{Gal}\big((L\cap K_i)/(L\cap K_{i-1})\big),$$
so $|G_{i-1}/G_i| = [(L\cap K_i):(L\cap K_{i-1})]$.

Since $(L\cap K_i)/(L\cap K_{i-1})$ is Galois, the standard compositum formula g
ives:
$$[(L\cap K_i):(L\cap K_{i-1})] = [(L\cap K_i)\cdot K_{i-1} : K_{i-1}].$$
(Here we used $(L\cap K_i)\cap K_{i-1} = L\cap K_{i-1}$, which holds because $K_
{i-1}\subseteq K_i$.)

Since $(L\cap K_i)\cdot K_{i-1} \subseteq K_i$, we get:
$$[(L\cap K_i):(L\cap K_{i-1})] \leq [K_i:K_{i-1}] = |H_i|.$$

Hence $|G_{i-1}/G_i|$ divides $|H_i|$. $\square$

**Applying simplicity.** Since $G$ is simple, its only normal subgroups are $\{e
\}$ and $G$. Now $G_1 \trianglelefteq G_0 = G$, so $G_1 \in \{G, \{e\}\}$.

- If $G_1 = \{e\}$: then $|G_0/G_1| = |G|$ divides $|H_1|$. Done.
- If $G_1 = G$: no progress was made. Then $G_2 \trianglelefteq G_1 = G$, so $G_
2 \in \{G, \{e\}\}$, and we repeat the argument.

Since $G_m = \{e\}$, there exists a smallest index $j$ with $G_j = \{e\}$. For a

$$G_{j-1} = G, \quad G_j = \{e\}, \quad |G_{j-1}/G_j| = |G| \text{ divides } |H_
j|.$$

**Conclusion.** The $j$-th auxiliary equation has Galois group $H_j$ with $|G| \
mid |H_j|$, i.e., $|H_j|$ is a multiple of $|G|$. All auxiliary equations before
