## Setup

Place the unit square with coordinates: A = (0,0), B = (1,0), C = (1,1), D = (0,
1). Let P = (x, y) with 0 ≤ x ≤ 1, 0 ≤ y ≤ 1.

## Key Construction: Rotation by 90°

Rotate the entire plane **90° counterclockwise** about A = (0,0). Under this rot
ation:
- Any point (x, y) maps to (−y, x).
- Let P' = (−y, x) be the image of P.
- Let C' = (−1, 1) be the image of C = (1, 1).

Since rotation is a rigid motion (preserves all distances):

**Claim 1:** PP' = √2 · AP.

*Proof:* P' = (−y, x), so PP' = √((x+y)² + (y−x)²) = √(2x² + 2y²) = √2 · √(x²+y²
) = √2 · AP. ∎

**Claim 2:** CP = C'P'.

*Proof:* Rotation preserves distances, so |C − P| = |C' − P'|. ∎

## Rewriting the Objective

Using Claims 1 and 2:

$$\sqrt{2}\cdot AP + BP + CP = |PP'| + |BP| + |C'P'|$$

This is the length of the path **B → P → P' → C'**.

## Applying the Triangle Inequality

By the triangle inequality (applied twice):

$$|BP| + |PP'| + |C'P'| \geq |BC'|$$

with equality if and only if B, P, P', C' are collinear with P and P' on the seg
ment BC'.

Compute |BC'|:

$$|BC'| = |(1,0) - (-1,1)| = |(2,-1)| = \sqrt{4+1} = \sqrt{5}$$

## Achieving Equality

We need B, P, P', C' collinear. The line from B = (1, 0) to C' = (−1, 1) has dir
ection (−2, 1). Parametrize points on this line as (1 − 2t, t) for t ∈ [0, 1].

Set P = (1 − 2t, t). Then P' = (−t, 1 − 2t). For P' to also lie on this line, we
 need (1 − 2t', t') = (−t, 1 − 2t) for some t', giving:

$$t' = 1 - 2t \quad \text{and} \quad 1 - 2t' = -t$$

Substituting: 1 − 2(1 − 2t) = −t ⟹ −1 + 4t = −t ⟹ **t = 1/5**.

This gives:
- **P = (3/5, 1/5)** — inside the unit square ✓
- P' = (−1/5, 3/5) — on segment BC' at parameter t' = 3/5 ∈ [0, 1] ✓
- P is on segment BC' at parameter t = 1/5 ∈ [0, 1] ✓

The collinear order is B (t=0) → P (t=1/5) → P' (t=3/5) → C' (t=1), so the path
is a straight line.

$$\sqrt{2}\cdot AP + BP + CP = \frac{\sqrt{20}}{5} + \frac{1}{\sqrt{5}} + \frac{
2}{\sqrt{5}} = \frac{2\sqrt{5}}{5} + \frac{3\sqrt{5}}{5} = \frac{5\sqrt{5}}{5} =

## Conclusion

For any point P in square ABCD:

$$\sqrt{2}\cdot AP + BP + CP = |BP| + |PP'| + |C'P'| \geq |BC'| = \sqrt{5}$$

where P' is the 90° rotation of P about A, and C' = (−1, 1) is the 90° rotation
of C about A. Equality holds at P = (3/5, 1/5).

The minimum value is $\boxed{\sqrt{5}}$.
