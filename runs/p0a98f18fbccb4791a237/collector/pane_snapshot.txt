## Solution

We evaluate $\displaystyle L = \lim_{n\to\infty} n\int_0^{\pi/4}(\tan x)^n\,dx$.

**Step 1: Substitution.** Let $u = \tan x$, so $dx = \dfrac{du}{1+u^2}$. The lim
its $x:0\to\pi/4$ become $u:0\to 1$. Hence

$$\int_0^{\pi/4}(\tan x)^n\,dx = \int_0^1 \frac{u^n}{1+u^2}\,du.$$

So

$$L = \lim_{n\to\infty} n\int_0^1 \frac{u^n}{1+u^2}\,du.$$

**Step 2: Change of variable $u^n = w$.** Set $w = u^n$, i.e. $u = w^{1/n}$, $du
 = \tfrac{1}{n}w^{1/n-1}\,dw$. Then

$$n\int_0^1 \frac{u^n}{1+u^2}\,du = n\int_0^1 \frac{w}{1+w^{2/n}}\cdot\frac{1}{n
}\,w^{1/n-1}\,dw = \int_0^1 \frac{w^{1/n}}{1+w^{2/n}}\,dw.$$

**Step 3: Dominated convergence.** Define $g_n(w) = \dfrac{w^{1/n}}{1+w^{2/n}}$
for $w\in[0,1]$.

- For every $w\in(0,1]$, $w^{1/n}\to 1$ and $w^{2/n}\to 1$ as $n\to\infty$, so $
g_n(w)\to \dfrac{1}{1+1}=\dfrac{1}{2}$.
- For $w=0$, $g_n(0)=0\to 0$, a single point (measure zero).
- **Domination:** Since $0\le w^{1/n}\le 1$ and $1+w^{2/n}\ge 1$, we have $|g_n(
w)|\le 1$ for all $w\in[0,1]$ and all $n$.

By the Dominated Convergence Theorem,

$$L = \lim_{n\to\infty}\int_0^1 g_n(w)\,dw = \int_0^1 \lim_{n\to\infty}g_n(w)\,d
w = \int_0^1 \frac{1}{2}\,dw = \frac{1}{2}.$$

**Conclusion.**

$$\boxed{\displaystyle\lim_{n\to\infty} n\int_0^{\pi/4}(\tan x)^n\,dx = \frac{1}
{2}.}$$
