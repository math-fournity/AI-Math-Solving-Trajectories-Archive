## Proof

**Step 1: Linearize via reciprocals.**

Since all $x_n \neq 0$, set $y_n = 1/x_n$. Then:
$$\frac{1}{x_n} = \frac{2x_{n-2}-x_{n-1}}{x_{n-2}\,x_{n-1}} = \frac{2}{x_{n-1}}
- \frac{1}{x_{n-2}},$$
so
$$y_n = 2\,y_{n-1} - y_{n-2}, \qquad n \ge 3.$$

**Step 2: Solve the linear recurrence.**

The characteristic equation is $r^2 - 2r + 1 = 0$, i.e., $(r-1)^2 = 0$, giving a
 double root $r=1$. The general solution is:
$$y_n = A + Bn.$$
From $y_1 = A+B$ and $y_2 = A+2B$: $B = y_2 - y_1$ and $A = 2y_1 - y_2$. Thus
$$y_n = y_1 + (n-1)(y_2 - y_1).$$

Setting $a = y_1 = 1/x_1$ and $d = y_2 - y_1 = 1/x_2 - 1/x_1$, we get
$$\boxed{x_n = \frac{1}{a + (n-1)\,d}}.$$

**Step 3: Well-definedness.**

The sequence is defined for all $n \ge 1$ (with $2x_{n-2}-x_{n-1}\neq 0$) iff $a
+(n-1)d \neq 0$ for every integer $n\ge 1$. (One checks that $2x_{n-2}=x_{n-1} \
iff y_{n-1}=\tfrac12 y_{n-2} \iff y_n = 0$, so the two conditions coincide.)

**Step 4: When are infinitely many $x_n$ integers?**

$x_n \in \mathbb{Z}\setminus\{0\}$ iff $a+(n-1)d = 1/k$ for some nonzero integer
 $k$.

**Case $d = 0$:** Then $x_n = 1/a$ for all $n$. Infinitely many (in fact all) $x
_n$ are integers iff $1/a \in \mathbb{Z}\setminus\{0\}$, i.e., $a = 1/m$ for som
e $m\in\mathbb{Z}\setminus\{0\}$, giving $x_1 = x_2 = m$. The sequence is consta
nt $x_n = m$, well-defined since $m\neq 0$.

**Case $d \neq 0$:** The values $\{a+(n-1)d : n\ge 1\}$ form an arithmetic progr
ession with nonzero common difference, hence are all distinct and **unbounded**
(tending to $+\infty$ if $d>0$, to $-\infty$ if $d<0$). Therefore only finitely
many terms lie in the bounded interval $[-1,1]$.

But $\{1/k : k \in \mathbb{Z}\setminus\{0\}\} = \{\pm 1, \pm\tfrac12, \pm\tfrac1
3, \ldots\} \subset [-1,1]\setminus\{0\}$. So $a+(n-1)d = 1/k$ can hold for only
 finitely many $n$. Hence $x_n$ is an integer for only **finitely** many $n$.

**Step 5: Conclusion.**

The values of $x_1, x_2$ for which $x_n$ is an integer for infinitely many $n$ a
re precisely:
$$\boxed{x_1 = x_2 = m, \quad m \in \mathbb{Z}\setminus\{0\}.}$$

That is, $x_1$ and $x_2$ must be equal nonzero integers.
