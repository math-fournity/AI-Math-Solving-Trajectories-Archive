## Solution

Let $v_2(n)$ denote the 2-adic valuation of $n$.

### Case 1: $a$ is even

Then $a^k$ is even for all $k \geq 1$, so $a^k - 1$ is odd, giving $v_2(a^k-1)=0
 < 2000$. **No such $k$ exists.**

### Case 2: $a$ is odd

We use the **Lifting the Exponent Lemma for $p=2$**.

**Lemma.** For odd $a$ and positive integer $n$:
- If $n$ is odd: $v_2(a^n - 1) = v_2(a-1)$.
- If $n$ is even: $v_2(a^n - 1) = v_2(a-1) + v_2(a+1) + v_2(n) - 1$.

**Proof of Lemma.** *Odd $n$:* $a^n - 1 = (a-1)(a^{n-1} + \cdots + 1)$. The seco
nd factor is a sum of $n$ odd terms with $n$ odd, hence odd. So $v_2(a^n-1) = v_
2(a-1)$.

*Even $n$:* Write $n = 2^s m$ with $m$ odd, $s \geq 1$. Then $a^n - 1 = (a^{2^s}
)^m - 1 = (a^{2^s}-1)\cdot S$ where $S$ is a sum of $m$ odd terms ($m$ odd), hen
ce odd. So $v_2(a^n-1) = v_2(a^{2^s}-1)$.

Factor: $a^{2^s}-1 = (a-1)(a+1)(a^2+1)(a^4+1)\cdots(a^{2^{s-1}}+1)$. For odd $a$
, every odd square satisfies $a^2 \equiv 1 \pmod{8}$, and by induction $a^{2^j}
\equiv 1 \pmod{8}$ for all $j \geq 1$, so $v_2(a^{2^j}+1) = 1$ for $j=1,\ldots,s
-1$. Therefore:
$$v_2(a^{2^s}-1) = v_2(a-1)+v_2(a+1)+(s-1) = v_2(a-1)+v_2(a+1)+v_2(n)-1. \quad\s
quare$$

Now we find the minimum $k$ with $v_2(a^k-1) \geq 2000$.

**Sub-case 2a: $v_2(a-1) \geq 2000$.** Taking $k=1$ (odd), the lemma gives $v_2(
a-1) \geq 2000$. So $k = 1$.

**Sub-case 2b: $v_2(a-1) < 2000$.** For any odd $k$, $v_2(a^k-1) = v_2(a-1) < 20
00$, so **no odd $k$ works**. We need $k$ even.

For even $k$, set $S := v_2(a^2-1) = v_2(a-1)+v_2(a+1)$. The lemma gives:
$$v_2(a^k-1) = S + v_2(k) - 1 \geq 2000 \iff v_2(k) \geq 2001 - S.$$

Since $a$ is odd, exactly one of $a-1, a+1$ is $\equiv 2\pmod{4}$, so $\min(v_2(
a-1),v_2(a+1))=1$ and $S \geq 2$.

The minimum even $k$ satisfying $v_2(k) \geq 2001-S$ is $k = 2^{\max(1,\; 2001-S
)}$ (the $\max$ with $1$ ensures $k$ is even). Since no odd $k$ works, this is t
he overall minimum.

### Verification (small examples)

- $a=3, n=3$: $v_2(3-1)=1<3$, $S=v_2(8)=3$, $k=2^{\max(1,1)}=2$. Check: $3^2-1=8
=2^3$. ✓
- $a=9, n=3$: $v_2(9-1)=3\geq 3$, $k=1$. Check: $9-1=8=2^3$. ✓
- $a=7, n=4$: $v_2(7-1)=1<4$, $S=v_2(48)=4$, $k=2^{\max(1,1)}=2$. Check: $7^2-1=
48=2^4\cdot3$. ✓
- Edge case $v_2(a-1)=1, v_2(a+1)=2000$: $S=2001$, $k=2^{\max(1,0)}=2$. Check: $
v_2(a^2-1)=2001\geq 2000$, and $k=1$ fails since $v_2(a-1)=1<2000$. ✓

### Final Answer

$$k = \begin{cases} \text{does not exist} & \text{if } 2 \mid a, \\ 1 & \text{if
 } 2 \nmid a \text{ and } v_2(a-1) \geq 2000, \\ 2^{\max\{1,\; 2001 - v_2(a^2-1)
\}} & \text{if } 2 \nmid a \text{ and } v_2(a-1) < 2000. \end{cases}$$
