## 解题过程

**Setup.** Let $BC = a$, $CA = b$, $AB = c$, with $a+b+c=100$. Let $BD = x$, so
$DC = a-x$. Place $B$ at the origin, $C$ at $(a,0)$, and $A = (c\cos\beta,\, c\s
in\beta)$ where $\beta = \angle ABC$.

**Key computations (Power of a Point).**

- Circle through $A,B,D$ meets $AC$ at $E$: by power of point $C$, $CA\cdot CE =
 CB\cdot CD$, so $CE = \frac{a(a-x)}{b}$ and $AE = b - \frac{a(a-x)}{b}$.
- Circle through $A,D,C$ meets $AB$ at $F$: by power of point $B$, $BA\cdot BF =
 BD\cdot BC$, so $BF = \frac{ax}{c}$ and $AF = c - \frac{ax}{c}$.

**Computing $DE$ and $DF$ via coordinates.** With $D=(x,0)$:

$$DE^2 = \left[\frac{c(a-x)}{b^2}\right]^2\left[(c-a\cos\beta)^2 + a^2\sin^2\bet
a\right] = \left[\frac{c(a-x)}{b^2}\right]^2 \cdot b^2 = \frac{c^2(a-x)^2}{b^2}$
$

So $DE = \frac{c(a-x)}{b} = 14$. Similarly $DF = \frac{xb}{c} = 11$.

**Angle condition.** A coordinate calculation gives:

$$\tan(\angle EBC) = \frac{c(a-x)\sin\beta}{c^2 - c(a+x)\cos\beta + ax}, \qquad
\tan(\angle BCF) = \frac{x\sin\beta}{c - x\cos\beta}$$

Setting these equal and simplifying yields:

$$c^2(a-2x) = x^2(a - 2c\cos\beta) \quad (\star)$$

Using the law of cosines, $a - 2c\cos\beta = \frac{b^2-c^2}{a}$, so $(\star)$ be
comes $ac^2(a-2x) = x^2(b^2-c^2)$.

**Solving the system.** From $DE=14$ and $DF=11$:

$$x = \frac{11c}{b}, \qquad a - x = \frac{14b}{c}, \qquad a = \frac{11c^2+14b^2}
{bc}$$

Substituting into $ac^2(a-2x)=x^2(b^2-c^2)$:

$$\frac{(11c^2+14b^2)(14b^2-11c^2)}{b^2} = \frac{121c^2(b^2-c^2)}{b^2}$$

$$196b^4 - 121c^4 = 121c^2 b^2 - 121c^4 \implies 196b^4 = 121c^2 b^2 \implies \f
rac{c}{b} = \frac{14}{11}$$

**Finding all sides.** With $c = \frac{14b}{11}$: $x = \frac{11c}{b} = 14$ and $
a-x = \frac{14b}{c} = 11$, so $a = 25$. Perimeter: $25 + b + \frac{14b}{11} = 10
0 \Rightarrow \frac{25b}{11}=75 \Rightarrow b=33$, $c=42$.

**Verification:** $a+b+c = 25+33+42 = 100$ ✓; $DE = \frac{42\cdot 11}{33}=14$ ✓;
 $DF = \frac{14\cdot 33}{42}=11$ ✓; angle condition: $42^2(25-28) = -5292 = 196(
25-52)$ ✓ (using $\cos\beta = 13/21$).

**Computing the ratio.**

$$CE = \frac{25\cdot 11}{33} = \frac{25}{3} \implies AE = 33 - \frac{25}{3} = \f
rac{74}{3}$$

$$BF = \frac{25\cdot 14}{42} = \frac{25}{3} \implies AF = 42 - \frac{25}{3} = \f
rac{101}{3}$$

$$\frac{AE}{AF} = \frac{74/3}{101/3} = \frac{74}{101}$$

Since $101$ is prime and $\gcd(74,101)=1$, the fraction is irreducible.

$$a + b = 74 + 101 = \boxed{175}$$
