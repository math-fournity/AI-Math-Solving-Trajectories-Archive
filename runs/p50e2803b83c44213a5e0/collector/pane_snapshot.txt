## Proof

We establish the relationship between $\aleph_0$ (the cardinality of $\mathbb{N}
$) and $c$ (the cardinality of $\mathbb{R}$) in three parts: (i) $c = 2^{\aleph_
0}$, (ii) $\aleph_0 < c$, and (iii) the precise status of whether $c = \aleph_1$
.

### 1. $c = 2^{\aleph_0}$

Recall that $2^{\aleph_0}$ denotes the cardinality of the power set $\mathcal{P}
(\mathbb{N})$, equivalently the set of all functions $\mathbb{N} \to \{0,1\}$, e
quivalently the set of all binary sequences $\{0,1\}^{\mathbb{N}}$.

**Injection $\mathbb{R} \to \{0,1\}^{\mathbb{N}}$.** Every real number $x \in [0
,1]$ has a binary expansion $x = 0.b_1 b_2 b_3 \dots$ with $b_i \in \{0,1\}$, gi
ving a map $[0,1] \to \{0,1\}^{\mathbb{N}}$. To make it injective we resolve the
 countably many dyadic rationals (which have two expansions) by consistently cho
osing the terminating expansion. Since $\mathbb{R}$ is in bijection with $[0,1)$
 (e.g. via $x \mapsto \frac{1}{\pi}\arctan x + \frac{1}{2}$ composed with a shif
t), and $[0,1)$ injects into $\{0,1\}^{\mathbb{N}}$, we get $|\mathbb{R}| \le 2^
{\aleph_0}$.

**Injection $\{0,1\}^{\mathbb{N}} \to \mathbb{R}$.** A binary sequence $(b_1, b_
2, \dots)$ maps to the real number $\sum_{n=1}^{\infty} \frac{2 b_n}{3^n} \in [0
,1]$. This is the Cantor-set encoding: digits $0$ and $2$ in base $3$. The map i
s injective because ternary expansions using only digits $0$ and $2$ are unique
(the only ambiguity in base $3$ comes from trailing $2$'s vs. a leading incremen
t, but a sequence ending in all $2$'s would require a digit $1$ in the alternati
ve expansion, which never appears). Hence $2^{\aleph_0} \le |\mathbb{R}|$.

By the Cantor–Bernstein theorem, $|\mathbb{R}| = 2^{\aleph_0}$, i.e.

$$\boxed{c = 2^{\aleph_0}.}$$

### 2. $\aleph_0 < c$ (Cantor's theorem)

By Cantor's theorem, for any set $S$ there is no surjection $S \to \mathcal{P}(S
)$, so $|\mathcal{P}(S)| > |S|$. Taking $S = \mathbb{N}$:

$$2^{\aleph_0} = |\mathcal{P}(\mathbb{N})| > |\mathbb{N}| = \aleph_0.$$

Combined with Part 1:

$$\boxed{\aleph_0 < c.}$$

Concretely, this is Cantor's diagonal argument: suppose $f : \mathbb{N} \to \{0,
1\}^{\mathbb{N}}$ were surjective, with $f(n) = (b_{n,1}, b_{n,2}, \dots)$. Defi
ne $d = (1 - b_{1,1},\, 1 - b_{2,2},\, 1 - b_{3,3}, \dots)$. Then $d \in \{0,1\}
^{\mathbb{N}}$ but $d \neq f(n)$ for every $n$ (they differ in coordinate $n$),
contradicting surjectivity.

### 3. The status of $c = \aleph_1$ (Continuum Hypothesis)

Since $\aleph_0 < c$ and the $\aleph$-hierarchy lists all infinite cardinals in
increasing order, $c = \aleph_\alpha$ for some $\alpha \ge 1$. The **Continuum H
ypothesis (CH)** is the claim

$$c = \aleph_1,$$

i.e., there is no cardinal strictly between $\aleph_0$ and $c$. Equivalently, ev
ery uncountable subset of $\mathbb{R}$ has cardinality $c$.

The precise relationship between $\aleph_0$ and $c$ that is **provable in ZFC**
is exactly:

$$\aleph_0 < c = 2^{\aleph_0}, \qquad c = \aleph_\alpha \text{ for some } \alpha
 \ge 1.$$

The further identification $c = \aleph_1$ is **independent of ZFC**:

- **Gödel (1940):** If ZFC is consistent, then so is $\mathrm{ZFC} + \mathrm{CH}
$. He constructed the constructible universe $L$ in which CH holds ($c = \aleph_
1$).
- **Cohen (1963):** If ZFC is consistent, then so is $\mathrm{ZFC} + \neg\mathrm
{CH}$. Using forcing, one can make $c = \aleph_2$ (or, with Easton's theorem ref
inements, $c = \aleph_\alpha$ for many regular $\alpha$).

By the completeness theorem, since both $\mathrm{ZFC}+\mathrm{CH}$ and $\mathrm{
ZFC}+\neg\mathrm{CH}$ are consistent relative to ZFC, CH is neither provable nor
 refutable in ZFC.

### Summary

The relationship between $\aleph_0$ and $c$ is:

$$\aleph_0 < c = 2^{\aleph_0},$$

with $\aleph_0$ the smallest infinite cardinal and $c$ the cardinality of the co
ntinuum. The stronger statement $c = \aleph_1$ (the Continuum Hypothesis) is ind
ependent of ZFC: it can neither be proved nor disproved from the standard axioms
 of set theory. Thus ZFC fixes the strict inequality $\aleph_0 < c$ and the iden
tity $c = 2^{\aleph_0}$, but leaves open exactly which $\aleph_\alpha$ ($\alpha
\ge 1$) equals $c$.
