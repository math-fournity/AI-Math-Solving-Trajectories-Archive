## Proof

Set $S_k = a_1 + \cdots + a_k$ (with $S_0 = 0$) and define $t_k = S_k/r$, $u_k =
 a_k/r = t_k - t_{k-1}$. Then $u_k \geq 0$, $t_0 = 0$, $t_n \leq 1$, and $t_k =
u_1 + \cdots + u_k$. Dividing the desired inequality by $r^2$ reduces it to

$$\sum_{k=1}^n \frac{u_k}{1 - u_k}\, t_{k-1}^2 < \frac{1}{3}. \tag{$\star$}$$

(If $a_k = r$ for some $k$, then $\sum a_i = r$ forces $a_j = 0$ for all $j \neq
 k$ and $S_{k-1} = 0$, so the sum is $0 < r^2/3$. Hence we may assume $a_k < r$,
 i.e. $u_k < 1$, for every $k$.)

**Key identity.** Since $t_k = t_{k-1} + u_k$,
$$t_k^3 - t_{k-1}^3 = u_k\bigl(t_k^2 + t_k t_{k-1} + t_{k-1}^2\bigr) = u_k\bigl(
3t_{k-1}^2 + 3t_{k-1}u_k + u_k^2\bigr).$$
Telescoping over $k = 1, \ldots, n$ gives
$$\frac{t_n^3}{3} = \sum_{k=1}^n u_k\, t_{k-1}^2 \;+\; \sum_{k=1}^n t_{k-1}\, u_
k^2 \;+\; \frac{1}{3}\sum_{k=1}^n u_k^3. \tag{1}$$

**Rewriting the target sum.** Using $\dfrac{u_k}{1-u_k} = u_k + \dfrac{u_k^2}{1-
u_k}$,
$$\sum_{k=1}^n \frac{u_k}{1-u_k}\,t_{k-1}^2 = \sum_{k=1}^n u_k\, t_{k-1}^2 + \su
m_{k=1}^n \frac{u_k^2}{1-u_k}\,t_{k-1}^2.$$
Substituting (1) for the first sum and combining the remaining terms:
$$= \frac{t_n^3}{3} + \sum_{k=1}^n u_k^2\, t_{k-1}\!\left(\frac{t_{k-1}}{1-u_k}
- 1\right) - \frac{1}{3}\sum_{k=1}^n u_k^3$$
$$= \frac{t_n^3}{3} + \sum_{k=1}^n u_k^2\, t_{k-1}\cdot\frac{t_k - 1}{1 - u_k} \
;-\; \frac{1}{3}\sum_{k=1}^n u_k^3. \tag{2}$$

**Sign analysis.** Because $t_k \leq t_n \leq 1$ and $1 - u_k > 0$, each factor
$\dfrac{t_k - 1}{1 - u_k} \leq 0$, while $u_k^2\, t_{k-1} \geq 0$. Hence the mid
dle sum in (2) is $\leq 0$, and $\frac{1}{3}\sum u_k^3 \geq 0$. Therefore
$$\sum_{k=1}^n \frac{u_k}{1-u_k}\,t_{k-1}^2 \;\leq\; \frac{t_n^3}{3} \;\leq\; \f
rac{1}{3}.$$

**Strictness.**
- If $t_n < 1$, then $\dfrac{t_n^3}{3} < \dfrac{1}{3}$, and ($\star$) holds stri
ctly.
- If $t_n = 1$, then $\sum_{k} u_k = 1 > 0$, so some $u_k > 0$ and thus $\sum_k
u_k^3 > 0$. From (2),
$$\sum_{k=1}^n \frac{u_k}{1-u_k}\,t_{k-1}^2 = \frac{1}{3} + \underbrace{\sum_{k=
1}^n u_k^2\, t_{k-1}\cdot\frac{t_k - 1}{1 - u_k}}_{\leq\, 0} \;-\; \underbrace{\
frac{1}{3}\sum_{k=1}^n u_k^3}_{>\,0} \;<\; \frac{1}{3}.$$

In both cases the inequality is strict. Multiplying by $r^2 > 0$ yields

$$\sum_{k = 1}^n \frac{a_k}{r - a_k}\,(a_1 + a_2 + \cdots + a_{k-1})^2 < \frac{r
^2}{3}. \qquad\blacksquare$$
