Answer: Yes.

Proof

We exhibit an explicit example: the elliptic curve

$$E: y^2 = x^3 - 2.$$

We verify that $E$ is a non-rational, irreducible algebraic curve over $
\mathbb{Q}$ possessing infinitely many rational points.

────────────────────────────────────────────────────────────────────────────────

1. Irreducibility

The defining polynomial is $f(x,y) = y^2 - x^3 + 2 \in \mathbb{Q}[x,y]$.

  • $x^3 - 2$ is irreducible over $\mathbb{Q}$ (Eisenstein at $p=2$).
  • Hence $x^3 - 2$ is not a square in $\mathbb{Q}(x)$, so $y^2 - (x^3-2)$ is
  irreducible over $\mathbb{Q}(x)$, and therefore irreducible in $\mathbb{Q}
  [x,y]$.

Thus $E$ is an irreducible algebraic curve.

2. Smoothness and genus

The projective closure is $\overline{E}: Y^2 Z = X^3 - 2Z^3$, i.e. $F = Y^2Z -
X^3 + 2Z^3 = 0$.

Partial derivatives: $F_X = -3X^2$, $F_Y = 2YZ$, $F_Z = Y^2 + 6Z^2$.

A singular point requires all three to vanish simultaneously. $F_X = 0
\Rightarrow X = 0$; $F_Y = 0 \Rightarrow Y=0$ or $Z=0$; $F_Z = 0 \Rightarrow Y^2
= -6Z^2$.

  • If $Z \neq 0$: $Y^2 = -6Z^2 < 0$ over $\mathbb{R}$, impossible (and also
  $F=0$ gives $Y^2 Z = -2Z^3$, i.e. $Y^2 = -2Z^2$, contradicting $Y^2 = -6Z^2$).
  • If $Z = 0$: then $F_Z = Y^2 = 0 \Rightarrow Y = 0$, giving the point
  $[0:0:0]$, which is not a projective point.
  • The point at infinity is $[0:1:0]$: $F_X = 0$, $F_Y = 0$, $F_Z = 1 \neq 0$.
  Smooth.

So $\overline{E}$ is a smooth plane cubic, hence has genus

$$g = \frac{(3-1)(3-2)}{2} = 1.$$

3. Non-rationality

A curve over a field is rational (birational to $\mathbb{P}^1$) if and only if
it has genus $0$. Since $g(E) = 1 \neq 0$, the curve $E$ is not rational.

4. Infinitely many rational points

The point $P = (3, 5)$ is rational on $E$ since $5^2 = 25 = 27 - 2 = 3^3 - 2$. ✓

We show $P$ has infinite order using the Nagell–Lutz theorem: on $y^2 = x^3 + ax
+ b$ with $a, b \in \mathbb{Z}$, every torsion point $(x,y) \in E(\mathbb{Q})$
has $x, y \in \mathbb{Z}$ and $y^2 \mid 4a^3 + 27b^2$.

Here $a = 0$, $b = -2$, so $4a^3 + 27b^2 = 108$.

Compute $2P$ via the doubling formula (slope $m = \frac{3x^2}{2y} = \frac{27}
{10}$):

$$x(2P) = m^2 - 2x = \frac{729}{100} - 6 = \frac{129}{100}, \qquad y(2P) = m(x -
x(2P)) - y = \frac{27}{10}\cdot\frac{171}{100} - 5 = -\frac{383}{1000}.$$

So $2P = \left(\tfrac{129}{100},, -\tfrac{383}{1000}\right)$. This point has
non-integer coordinates, so by Nagell–Lutz it is not a torsion point. Hence $P$
itself is not torsion (a torsion $P$ would give torsion $2P$).

Therefore $P$ has infinite order, generating a copy of $\mathbb{Z}$ inside
$E(\mathbb{Q})$. The multiples

$$nP, \quad n = 1, 2, 3, \dots$$

are all distinct rational points on $E$.

5. Conclusion

The curve $E: y^2 = x^3 - 2$ is:

  • irreducible (shown in step 1),
  • non-rational (genus $1 \neq 0$, step 3),
  • has infinitely many rational points (step 4: the distinct points $nP$ for $n
  \in \mathbb{Z}_{\geq 1}$).

Hence the answer to the question is yes: such a curve exists. $\blacksquare$
