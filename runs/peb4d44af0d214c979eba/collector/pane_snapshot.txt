## Solution

**Interpretation.** Each round consists of 2 coin flips. After $n$ rounds, $2n$
total flips have occurred, and $X_n$ denotes the cumulative number of heads. Set
ting $Z_k$ = number of heads in round $k$, we have $Z_k \sim \text{Binomial}(2,
\tfrac{1}{2})$ i.i.d. with $P(Z_k=0)=\tfrac14,\; P(Z_k=1)=\tfrac12,\; P(Z_k=2)=\
tfrac14$, and $X_n = \sum_{k=1}^n Z_k$ is a renewal process with mean increment
$\mu = \mathbb{E}[Z_1] = 1$.

We seek $r_m = P(\exists\, n\ge 1 : X_n = m)$ and its limit as $m\to\infty$.

---

### Step 1: Renewal Measure via Renewal Theorem

Define the **renewal measure** $u(m) = \sum_{n=0}^{\infty} P(X_n = m)$, where $X
_0 = 0$.

Since $X_n \sim \text{Binomial}(2n, \tfrac12)$, we compute $u(m)$ exactly. Using
 the generating function identity:

$$\sum_{n=0}^{\infty} \binom{2n}{m} x^{2n} = [y^m]\,\frac{1}{1-x^2(1+y)^2},$$

setting $x = \tfrac12$ and doing partial fractions on $\frac{4}{(1-y)(3+y)} = \f
rac{1}{1-y} + \frac{1}{3+y}$:

$$u(m) = \sum_{n=0}^{\infty}\binom{2n}{m}4^{-n} = 1 + \frac{(-1)^m}{3^{m+1}}, \q
quad m \ge 1.$$

This confirms the **arithmetic renewal theorem**: since the increments have span
 1 and mean $\mu=1$,

$$u(m) \longrightarrow \frac{1}{\mu} = 1 \quad\text{as } m\to\infty.$$

---

### Step 2: Relating $r_m$ to $u(m)$

The key observation is that the walk is **non-decreasing** (increments $\ge 0$).
 Once the walk leaves level $m$ via a positive increment, it can **never return*
* to $m$.

Let $T_m = \min\{n \ge 1 : X_n = m\}$ be the first passage time. Given $T_m = k$
, the event $X_n = m$ (for $n > k$) holds iff all subsequent increments are zero
: $Z_{k+1} = \cdots = Z_n = 0$, which has probability $(\tfrac14)^{n-k}$.

Therefore, for $m \ge 1$ (so $\delta_0(m)=0$):

$$u(m) = \sum_{n=1}^{\infty} P(X_n = m) = \sum_{k=1}^{\infty} P(T_m = k)\sum_{n=
k}^{\infty}\left(\tfrac14\right)^{n-k} = \sum_{k=1}^{\infty} P(T_m = k)\cdot\fra
c{1}{1-1/4} = r_m \cdot \frac{4}{3}.$$

Hence:

$$r_m = \frac{3}{4}\, u(m).$$

---

### Step 3: Taking the Limit

By the renewal theorem, $u(m) \to \frac{1}{\mu} = 1$. Therefore:

$$\lim_{m\to\infty} r_m = \frac{3}{4}\lim_{m\to\infty} u(m) = \frac{3}{4} \cdot
1 = \boxed{\dfrac{3}{4}}.$$

---

### Verification (exact formula)

From the exact expression $u(m) = 1 + \frac{(-1)^m}{3^{m+1}}$:

$$r_m = \frac{3}{4}\left(1 + \frac{(-1)^m}{3^{m+1}}\right) = \frac{3}{4} + \frac
{(-1)^m}{4\cdot 3^m}.$$

**Check $m=1$:** $r_1 = \frac34 - \frac{1}{12} = \frac23$. Direct: $P(\text{neve
r hit }1) = P(Z_1=2) + P(Z_1=0)\cdot P(\text{never hit }1)$, giving $q = \frac14
 + \frac14 q \Rightarrow q=\frac13$, so $r_1 = \frac23$. ✓

**Check $m=2$:** $r_2 = \frac34 + \frac{1}{36} = \frac{7}{9}$. From the recursio
n $r_m = \frac23 r_{m-1} + \frac13 r_{m-2}$ (for $m\ge 3$) with $r_1=\frac23, r_
2=\frac79$, the characteristic roots are $1$ and $-\frac13$, confirming $r_m = \
frac34 + \frac14(-\frac13)^m \to \frac34$. ✓

The factor $\frac34$ arises because each visit to $m$ is followed by a geometric
$(\frac34)$ number of additional stays (due to zero-increments), contributing a
multiplicative factor $\frac{4}{3}$ to $u(m)$ relative to $r_m$.
