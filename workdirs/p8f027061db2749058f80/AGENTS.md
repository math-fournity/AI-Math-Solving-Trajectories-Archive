A specialized digital decryption system operates using a sequence of security codes, $f(n)$, where $n$ represents the generation index. The system initialization requires the first two codes to be zero, such that $f(0) = 0$ and $f(1) = 0$.

For all subsequent generations ($n = 0, 1, 2, \dots$), the next security code is generated by the following protocol:
The code for generation $n+2$ is calculated by taking the code from the previous generation, $f(n+1)$, and multiplying it by $4^{n+2}$. From this result, the system subtracts the product of the code from two generations prior, $f(n)$, and a scaling factor of $16^{n+1}$. Finally, an external entropy value equal to $n \cdot 2^{n^2}$ is added to the total.

The system's integrity is verified by summing the specific codes generated at the 10th, 11th, and 12th generations. To produce the final validation key, the supervisor needs to calculate the remainder when the sum $f(10) + f(11) + f(12)$ is divided by 13.

Find the value of this validation key.
