## Proof

**Setup.** Encode each student $i$ as a binary vector $v_i \in \{0,1\}^{10}$, wh
ere $v_i(g)=1$ iff student $i$ belongs to group $g$. The constraint "each group
has exactly 16 students" becomes $\sum_{i=1}^{32} v_i(g) = 16$ for every $g$.

For a pair $(i,j)$, the number of groups involving exactly one of the two is the
 Hamming distance $d_{ij} = \sum_{g=1}^{10}(v_i(g)\oplus v_j(g))$, and the inter
ests-disparity is $d_{ij}^2$. Thus
$$S = \sum_{1\le i<j\le 32} d_{ij}^2.$$

**Expanding the square.** Write $d_{ij}^2 = \sum_g (v_i(g)\oplus v_j(g)) + 2\sum
_{g<h}(v_i(g)\oplus v_j(g))(v_h(i)\oplus v_h(j))$, using $(v_i(g)\oplus v_j(g))^
2 = v_i(g)\oplus v_j(g)$.

**First term.** For each group $g$, $\sum_{i<j}(v_i(g)\oplus v_j(g))$ counts pai
rs split by $g$: exactly $16\cdot 16 = 256$. Summing over 10 groups:
$$\sum_g \sum_{i<j}(v_i(g)\oplus v_j(g)) = 10\cdot 256 = 2560.$$

**Second term.** Fix a pair of groups $(g,h)$. Let $b_{gh}$ = number of students
 in $g$ but not $h$. Since $|g|=|h|=16$, the number in $h$ but not $g$ is also $
b_{gh}$, the number in both is $16-b_{gh}$, and the number in neither is $16-b_{
gh}$. The pairs differing in **both** coordinates are:
- (in both) paired with (in neither): $(16-b_{gh})^2$,
- (in $g$ only) paired with (in $h$ only): $b_{gh}^2$.

Hence $\sum_{i<j}(v_i(g)\oplus v_j(g))(v_i(h)\oplus v_j(h)) = (16-b_{gh})^2 + b_
{gh}^2 = 2(b_{gh}-8)^2 + 128 \geq 128$, with equality iff $b_{gh}=8$.

**Lower bound.** There are $\binom{10}{2}=45$ pairs of groups, so
$$S = 2560 + 2\sum_{g<h}\bigl[(16-b_{gh})^2 + b_{gh}^2\bigr] \geq 2560 + 2\cdot
45\cdot 128 = 2560 + 11520 = 14080.$$

**Achieving the bound.** Equality requires $b_{gh}=8$ for every pair $(g,h)$, i.
e., every two groups intersect in exactly 8 students. Map each group $g$ to a si
gn vector $y_g \in \{+1,-1\}^{32}$ via $y_g(i) = 2v_i(g)-1$. Then $|g|=16$ gives
 $\sum_i y_g(i)=0$, and $|g\cap h|=8$ gives
$$\langle y_g, y_h\rangle = 4|g\cap h| - 32 = 0.$$
So we need 10 mutually orthogonal $\pm1$ vectors of length 32, each summing to 0
. The Sylvester Hadamard matrix $H_{32}$ of order 32 provides 32 mutually orthog
onal $\pm1$ rows; all rows except the all-ones row sum to 0. Taking any 10 of th
ese 31 non-trivial rows yields the desired configuration. Translating back gives
 10 groups of size 16 with pairwise intersections of size 8.

**Conclusion.** The minimum is attained, so
$$\boxed{S_{\min} = 14080}.$$
