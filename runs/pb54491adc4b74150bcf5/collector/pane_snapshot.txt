## Solution

Let $C$ be the Cantor set equipped with the natural Cantor measure $\mu$ (the se
lf-similar probability measure assigning mass $2^{-n}$ to each of the $2^n$ basi
c intervals at level $n$). We compute

$$D = \mathbb{E}[|X-Y|], \qquad X,Y \stackrel{\text{iid}}{\sim} \mu.$$

### Self-similar decomposition

The Cantor measure satisfies the self-similarity identity

$$\mu = \tfrac{1}{2}\,\mu\circ S_0^{-1} + \tfrac{1}{2}\,\mu\circ S_2^{-1}, \qqua
d S_0(x)=\tfrac{x}{3},\quad S_2(x)=\tfrac{x+2}{3}.$$

Equivalently, a $\mu$-distributed random variable $X$ can be generated as
$$X = \tfrac{B + X'}{3}, \qquad B\in\{0,2\}\text{ with probability }1/2\text{ ea
ch},\quad X'\sim\mu\text{ independent}.$$

Draw $X = (B_1+X')/3$ and $Y=(B_2+Y')/3$ independently. There are two cases.

**Case 1: Same third** ($B_1=B_2$, probability $1/2$). Then
$$|X-Y| = \frac{|X'-Y'|}{3},$$
so the conditional expectation is $D/3$. Contribution: $\tfrac{1}{2}\cdot\tfrac{
D}{3} = \tfrac{D}{6}$.

**Case 2: Different thirds** ($B_1\ne B_2$, probability $1/2$). WLOG $X\in[0,\tf
rac13]$, $Y\in[\tfrac23,1]$, so
$$|X-Y| = Y-X = \frac{2+Y'-X'}{3}.$$
By the symmetry $\mu(x)=\mu(1-x)$, the Cantor measure has mean $\mathbb{E}[X']=\
mathbb{E}[Y']=\tfrac12$. Hence
$$\mathbb{E}\bigl[|X-Y|\;\big|\;\text{different}\bigr] = \frac{2+\tfrac12-\tfrac
12}{3} = \frac{2}{3}.$$
Contribution: $\tfrac{1}{2}\cdot\tfrac{2}{3} = \tfrac{1}{3}$.

### Solving for $D$

Combining the two cases,
$$D = \frac{D}{6} + \frac{1}{3}.$$
Therefore
$$\frac{5D}{6} = \frac{1}{3} \implies D = \frac{2}{5}.$$

### Verification of the mean

The symmetry argument $\mathbb{E}_\mu[X]=\tfrac12$ follows from the self-similar
ity:
$$m = \mathbb{E}[X] = \tfrac12\,\mathbb{E}\!\left[\tfrac{X'}{3}\right] + \tfrac1
2\,\mathbb{E}\!\left[\tfrac{2+X'}{3}\right] = \tfrac12\cdot\tfrac{m}{3} + \tfrac
12\cdot\tfrac{2+m}{3} = \tfrac{m+1}{3},$$
giving $3m = m+1$, so $m=\tfrac12$. ✓

### Result

The average distance between two randomly chosen points of the Cantor set is

$$\boxed{\dfrac{2}{5}}.$$
