**Answer: Yes, it is necessarily true.** Any two points of a connected open set
Ω ⊂ ℂ can be joined by an injective continuous curve γ:[0,1] → Ω (in fact, by a
simple polygonal path).

## Proof

The argument has three steps.

### Step 1. A connected open set Ω ⊂ ℂ is polygonally path-connected.

Fix z₀ ∈ Ω and define
$$A = \{z \in \Omega : z \text{ can be joined to } z_0 \text{ by a polygonal pat
h in } \Omega\}.$$

- **A is nonempty**, since z₀ ∈ A (the constant path).
- **A is open.** If z ∈ A, since Ω is open there is r > 0 with B(z, r) ⊂ Ω. For
any w ∈ B(z, r), the straight segment [z, w] lies in B(z, r) ⊂ Ω; appending it t
o a polygonal path from z₀ to z gives a polygonal path from z₀ to w. Hence B(z,
r) ⊂ A.
- **Ω \ A is open.** If z ∉ A, pick r > 0 with B(z, r) ⊂ Ω. If some w ∈ B(z, r)
belonged to A, then z could be reached from z₀ by a polygonal path to w followed
 by the segment [w, z] ⊂ B(z, r) ⊂ Ω, contradicting z ∉ A. Hence B(z, r) ⊂ Ω \ A
.

Thus A is both open and closed in the connected space Ω, and nonempty, so A = Ω.
 Consequently any two points a, b ∈ Ω can be joined by a polygonal path in Ω.

### Step 2. Any polygonal path in Ω can be simplified to a simple (injective) po
lygonal path.

Let P = (p₀, p₁, …, pₙ) be a polygonal path in Ω with p₀ = a, pₙ = b, each segme
nt [pₖ, pₖ₊₁] ⊂ Ω. We show: if P is not injective, we can replace it by a polygo
nal path in Ω from a to b with **strictly fewer segments**. Iterating, the proce
ss terminates (the number of segments is a nonnegative integer) at an injective
polygonal path.

Suppose P is not injective. We distinguish the ways a self-intersection can occu
r; in each case we remove a closed loop.

**(i) A vertex is revisited:** pᵢ = pⱼ for some i < j. The subpath pᵢ, pᵢ₊₁, …,
pⱼ is a closed loop based at pᵢ = pⱼ. Remove it, replacing
$$(p_0,\dots,p_i,p_{i+1},\dots,p_j,p_{j+1},\dots,p_n)$$
by
$$(p_0,\dots,p_i,p_{j+1},\dots,p_n).$$
The new segment [pᵢ, pⱼ₊₁] equals [pⱼ, pⱼ₊₁] ⊂ Ω, so the new path lies in Ω. The
 number of segments drops by j − i ≥ 1.

**(ii) A vertex lies on a non-adjacent segment:** pᵢ ∈ [pⱼ, pⱼ₊₁] with i < j and
 i+1 < j (non-adjacency; the case i = j is impossible, and i = j−1 with pᵢ ∈ [pⱼ
,pⱼ₊₁] means pᵢ, pⱼ, pⱼ₊₁ collinear with pᵢ between, which is still a self-inter
section handled below). Replace
$$(p_0,\dots,p_i,p_{i+1},\dots,p_j,p_{j+1},\dots,p_n)$$
by
$$(p_0,\dots,p_i,p_{j+1},\dots,p_n),$$
using the segment [pᵢ, pⱼ₊₁] ⊂ [pⱼ, pⱼ₊₁] ⊂ Ω. The number of segments drops by j
 − i ≥ 2.

**(iii) Two non-adjacent segments intersect:** [pᵢ, pᵢ₊₁] ∩ [pⱼ, pⱼ₊₁] ≠ ∅ with
i+1 < j. Let q be an intersection point. Replace
$$(p_0,\dots,p_i,p_{i+1},\dots,p_j,p_{j+1},\dots,p_n)$$
by
$$(p_0,\dots,p_i,q,p_{j+1},\dots,p_n).$$
Here [pᵢ, q] ⊂ [pᵢ, pᵢ₊₁] ⊂ Ω and [q, pⱼ₊₁] ⊂ [pⱼ, pⱼ₊₁] ⊂ Ω. The number of segm
ents changes from (j − i + 1) to 2, a net decrease of j − i − 1 ≥ 1 (since j ≥ i
+2). If q = pᵢ or q = pⱼ₊₁, the corresponding new segment is degenerate and is s
imply dropped, decreasing the count further.

**(iv) Degenerate segment** pₖ = pₖ₊₁: remove it, decreasing the count by 1.

Every form of non-injectivity falls into one of these cases (a non-injective pol
ygonal map either revisits a vertex, passes a vertex through a non-adjacent segm
ent, crosses two non-adjacent segments, or has a degenerate segment). In each ca
se the segment count strictly decreases while the path remains in Ω and still co
nnects a to b. By the well-foundedness of ℕ, after finitely many reductions no s
elf-intersection remains.

### Step 3. Conclusion.

The resulting polygonal path P* = (q₀, …, qₘ) with q₀ = a, qₘ = b has:
- no degenerate segments (qₖ ≠ qₖ₊₁),
- no two non-adjacent segments intersecting,
- no vertex lying on a non-adjacent segment,
- no vertex revisited.

Adjacent segments [qₖ₋₁, qₖ] and [qₖ, qₖ₊₁] meet only at qₖ (their common endpoi
nt; they cannot overlap since that would force qₖ₋₁ = qₖ₊₁, a revisited vertex a
lready excluded). Hence the piecewise-linear parametrization
$$\gamma:[0,1]\to\Omega,\qquad \gamma(t)=q_k + (nt-k)(q_{k+1}-q_k)\ \text{for }t
\in[k/m,(k+1)/m]$$
is injective: γ(s) = γ(t) with s < t would place a point in the intersection of
two segments; if they are the same segment, injectivity of a nondegenerate line
segment gives s = t; if they are adjacent, the only common point is the shared e
ndpoint, corresponding to the same parameter; if they are non-adjacent, they are
 disjoint by construction. Thus γ is a continuous injective map [0,1] → Ω with γ
(0) = a, γ(1) = b.

Therefore any two points of Ω can be joined by a non-self-intersecting curve. ∎
