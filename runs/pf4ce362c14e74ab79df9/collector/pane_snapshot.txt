设 $N_t = e^{3B_t}\,e^{-ct} = e^{3B_t - ct}$。记 $X_t = 3B_t - ct$，则 $dX_t = 3
\,dB_t - c\,dt$ 且 $(dX_t)^2 = 9\,dt$。

对 $N_t = e^{X_t}$ 应用 Itô 公式：

$$dN_t = N_t\,dX_t + \tfrac{1}{2}N_t\,(dX_t)^2 = N_t\bigl(3\,dB_t - c\,dt\bigr)
+ \tfrac{1}{2}N_t\cdot 9\,dt.$$

合并 $dt$ 项：

$$dN_t = 3N_t\,dB_t + N_t\!\left(\tfrac{9}{2} - c\right)dt.$$

$N_t$ 是 Itô 积分（局部鞅），它成为（真正的）鞅当且仅当漂移项为零，即

$$\tfrac{9}{2} - c = 0 \quad\Longrightarrow\quad c = \tfrac{9}{2}.$$

**验证**：当 $c = \tfrac{9}{2}$ 时，$N_t = \exp\!\bigl(3B_t - \tfrac{9}{2}t\bigr
)$。由于 $3B_t \sim \mathcal{N}(0,9t)$，有

$$\mathbb{E}[N_t] = \mathbb{E}\bigl[e^{3B_t}\bigr]\,e^{-\frac{9}{2}t} = e^{\frac
{1}{2}\cdot 9t}\,e^{-\frac{9}{2}t} = e^{0} = 1,$$

且 $N_t = \mathcal{E}(3B)_t$（指数鞅），满足可积性条件 $\mathbb{E}\!\left[\int_0
^t (3N_s)^2\,ds\right] < \infty$，因此 $N_t$ 确为鞅。

$$\boxed{c = \dfrac{9}{2}}$$

### 证明完成
