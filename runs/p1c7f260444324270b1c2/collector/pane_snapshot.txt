## 解答

**答案：不成立。** $(a_n X_n + b_n Y_n)$ 不一定依分布收敛到 $(X+Y)$。

### 反例构造

设 $Z$ 为非退化随机变量（例如标准正态分布）。定义：

$$X_n = n, \quad Y_n = -n + Z, \quad a_n = 1 + \frac{1}{n}, \quad b_n = 1.$$

其中 $X_n, a_n, b_n$ 均为确定性序列。

### 验证条件

**条件 1：$(X_n + Y_n) \xrightarrow{d} (X+Y)$**

$$X_n + Y_n = n + (-n + Z) = Z, \quad \forall\, n.$$

因此 $(X_n + Y_n)$ 恒等于 $Z$，平凡地依分布收敛到 $Z$。即 $X + Y = Z$。

**条件 2：$a_n \xrightarrow{d} 1$**

$a_n = 1 + \frac{1}{n}$ 是确定性序列，逐点收敛到常数 $1$，因此依分布收敛到退化随
机变量 $1$。✓

**条件 3：$b_n \xrightarrow{d} 1$**

$b_n = 1$ 恒等于常数 $1$。✓

### 计算极限

$$a_n X_n + b_n Y_n = \left(1 + \frac{1}{n}\right) \cdot n + 1 \cdot (-n + Z) =
n + 1 - n + Z = 1 + Z.$$

因此 $(a_n X_n + b_n Y_n) \equiv 1 + Z$ 对所有 $n$ 成立，故

$$a_n X_n + b_n Y_n \xrightarrow{d} 1 + Z.$$

由于 $Z$ 非退化，$1 + Z \not\overset{d}{=} Z = X + Y$。

### 结论

$(a_n X_n + b_n Y_n) \xrightarrow{d} 1 + Z \neq X + Y$，故命题**不成立**。

### 根本原因

依分布收敛仅约束 $X_n + Y_n$ 的**和**，不约束 $X_n$ 与 $Y_n$ 的**个体行为**。两
者可以各自无界增长而相互抵消（如 $X_n = n$, $Y_n = -n + Z$）。乘子 $a_n, b_n \to
 1$ 虽然趋于 $1$，但其微小偏差（如 $a_n - 1 = 1/n$）与无界增长的个体项相乘后，可
产生**非消失的扰动**（如 $\frac{1}{n} \cdot n = 1$），从而改变极限分布。Slutsky
定理在此失效，因其要求乘子作用于**自身已收敛**的序列，而此处 $X_n, Y_n$ 各自并不
收敛。
