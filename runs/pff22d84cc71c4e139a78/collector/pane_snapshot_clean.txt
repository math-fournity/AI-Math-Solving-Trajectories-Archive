- **1976 faces**: 1975 triangular lateral faces + 1 polygonal base.
- **1976 vertices**: 1 apex + 1975 base vertices.
- **3950 edges**: 1975 lateral edges + 1975 base edges.

The pyramid graph is **3-connected** (removing any two vertices leaves a connect

tz's theorem**, it admits a convex realization.

**Key property: every vertex has odd degree.** The apex has degree 1975 (odd); e
ach base vertex has degree 3 (odd).

**Algebraic setup.** Fix a canonical orientation of each edge. For edge $e$ from
 $u$ to $v$, set $\vec{d}_e = \vec{v} - \vec{u}$. For a signing $\epsilon_e \in
\{+1, -1\}$, the sum decomposes as:

$$S = \sum_e \epsilon_e \,\vec{d}_e = \sum_{v} c_v\, \vec{v},$$

where $c_v = \sum_{e \text{ into } v} \epsilon_e \;-\; \sum_{e \text{ out of } v
} \epsilon_e$.

**Critical observation.** For any vertex $v$ of odd degree $d_v$, the quantity $
c_v$ is a sum of $d_v$ terms each equal to $\pm 1$, hence $c_v$ is **odd**, and
therefore $c_v \neq 0$.

Since **every** vertex of our pyramid has odd degree, we have $c_v \neq 0$ for e
very vertex $v$, for **every** signing $\epsilon$.

**Consequence.** For each signing $\epsilon$, the sum $S = \sum_v c_v \,\vec{v}$
 is a **non-trivial** linear combination of vertex position vectors (not all coe
fficients are zero). Therefore $S$ is not identically zero as a function of the
vertex positions $\{\vec{v}\} \in \mathbb{R}^{3 \times 1976}$.

The set of vertex positions where $S = 0$ for a fixed signing is a **proper line
ar subspace** of $\mathbb{R}^{3 \times 1976}$ (the zero set of a non-trivial lin
ear map).

**Avoiding all bad subspaces simultaneously.** There are $2^{3950}$ signings, gi
ving finitely many proper linear subspaces $H_1, \dots, H_N$. A finite union of
proper linear subspaces cannot cover $\mathbb{R}^{3 \times 1976}$: indeed, the p
roduct of the defining non-trivial linear forms is a non-zero polynomial, so its
 zero set (the union) is proper. Hence the complement $\mathbb{R}^{3 \times 1976

**Convexity.** By Steinitz's theorem, the set $\mathcal{C}$ of convex realizatio

$$\mathcal{C} \;\cap\; \bigl(\mathbb{R}^{3 \times 1976} \setminus (H_1 \cup \cdo
