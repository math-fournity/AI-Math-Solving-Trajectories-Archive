## Proof

**Setup.** Write $a = A/D$, $b = B/D$ where $A, B, D$ are positive integers and
$D = \operatorname{lcm}(\text{den}(a), \text{den}(b))$. Then:
- $a + b \in \mathbb{Z} \iff D \mid (A+B)$
- $a^n + b^n \in \mathbb{Z} \iff D^n \mid (A^n + B^n)$
- $a, b \notin \mathbb{Z} \iff D \nmid A$ and $D \nmid B$

---

### Even $n \geq 2$ are NOT in $S$

Let $n \geq 2$ be even. Fix any prime $p$ with $p^e \| D$. We show $p^e \mid A$
and $p^e \mid B$.

**Odd prime $p$:** Since $p^e \mid (A+B)$, we have $B \equiv -A \pmod{p}$. As $n
$ is even, $A^n + B^n \equiv 2A^n \pmod{p}$. Since $p \mid (A^n+B^n)$ and $p$ is
 odd, $p \mid A$, hence $p \mid B$. Write $A = pA_1, B = pB_1$. Then $p^{(e-1)n}
 \mid (A_1^n + B_1^n)$ and $p^{e-1} \mid (A_1+B_1)$. By induction on $e$, $p^{e-
1} \mid A_1$ and $p^{e-1} \mid B_1$, giving $p^e \mid A, p^e \mid B$.

**Prime $p = 2$:** Let $\alpha = v_2(A)$, $\beta = v_2(B)$.

- If $\alpha \neq \beta$, say $\alpha < \beta$: then $v_2(A+B) = \alpha \geq e$,
 so $\alpha \geq e$, forcing both $\alpha, \beta \geq e$.

- If $\alpha = \beta = \gamma < e$: write $A = 2^\gamma A'$, $B = 2^\gamma B'$ w
ith $A', B'$ odd. Then $v_2(A^n + B^n) = n\gamma + v_2(A'^n + B'^n)$. Since $A',
 B'$ are odd and $n$ is even, $A'^n \equiv B'^n \equiv 1 \pmod{8}$, so $v_2(A'^n
 + B'^n) = 1$. Thus $v_2(A^n+B^n) = n\gamma + 1$. We need $n\gamma + 1 \geq ne$,
 i.e., $\gamma \geq e - 1/n$. Since $\gamma$ is an integer and $n \geq 2$, this
gives $\gamma \geq e$, contradicting $\gamma < e$.

So in all cases $2^e \mid A$ and $2^e \mid B$.

**Conclusion for even $n$:** Every prime power $p^e \| D$ divides both $A$ and $
B$, so $D \mid A$ and $D \mid B$, making $a, b$ integers. Contradiction. Thus **
no even $n \geq 2$ belongs to $S$**.

### All odd $n$ are in $S$

For any odd $n \geq 1$, take $a = \tfrac{1}{2}$, $b = \tfrac{2^n - 1}{2}$.

- **Non-integer, positive:** $2^n - 1$ is odd, so both $a, b$ are non-integer ha
lf-integers, and both positive. ✓
- **$a + b = \frac{2^n}{2} = 2^{n-1} \in \mathbb{Z}$.** ✓
- **$a^n + b^n = \frac{1 + (2^n-1)^n}{2^n}$.** Since $n$ is odd and $1, (2^n-1)$
 are both odd with $2 \mid (1 + (2^n-1))$, the Lifting the Exponent Lemma for $p
=2$ (odd exponent) gives $v_2(1 + (2^n-1)^n) = v_2(1 + (2^n-1)) = v_2(2^n) = n$.
 So the numerator is divisible by $2^n$, making $a^n + b^n$ an integer. ✓

**Verification for $n = 3$:** $a = \tfrac12, b = \tfrac72$. $a+b = 4$. $a^3+b^3
= \tfrac{1+343}{8} = 43$. ✓

**Verification for $n = 5$:** $a = \tfrac12, b = \tfrac{31}{2}$. $a+b = 16$. $a^
5+b^5 = \tfrac{1+28629151}{32} = 894661$. ✓

### Final Computation

$S = \{1, 3, 5, 7, \ldots\}$ — all positive odd integers.

Elements of $S$ less than $100$: $1, 3, 5, \ldots, 99$ — fifty odd numbers.

$$\sum_{k=1}^{50} (2k-1) = 2 \cdot \frac{50 \cdot 51}{2} - 50 = 2550 - 50 = 2500
$$

The sum of the elements of $S$ that are less than $100$ is $\boxed{2500}$.
