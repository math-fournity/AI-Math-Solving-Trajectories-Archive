## Solution

**Claim:** For every positive integer $n$ and every integer $0 \le k \le n$, the
 set
$$\mathcal{R}_k = \{A \in M_n(\mathbb{C}) : \operatorname{rank}(A) = k\}$$
is path-connected (hence connected).

---

### Key facts

**Fact 1.** $GL_n(\mathbb{C})$ is path-connected.

*Proof of Fact 1.* Let $A \in GL_n(\mathbb{C})$. By polar decomposition, $A = UP
$ where $U$ is unitary and $P$ is positive-definite Hermitian. Since $P$ is posi
tive-definite, it is diagonalizable with positive real eigenvalues $\lambda_1, \
dots, \lambda_n > 0$. Define $P(t) = P^{\,t}$ for $t \in [0,1]$ via functional c
alculus (i.e., raise each eigenvalue to the power $t$). Then $P(t)$ is positive-
definite for all $t$, $P(0) = I$, and $P(1) = P$, giving a path in $GL_n(\mathbb
{C})$ from $I$ to $P$.

Since $U$ is unitary, it is unitarily diagonalizable: $U = V \operatorname{diag}
(e^{i\theta_1}, \dots, e^{i\theta_n}) V^*$ for some unitary $V$. Define
$$U(t) = V \operatorname{diag}(e^{i(1-t)\theta_1}, \dots, e^{i(1-t)\theta_n}) V^
*, \quad t \in [0,1].$$
Then $U(t)$ is unitary (hence invertible) for all $t$, $U(0) = U$, and $U(1) = I
$.

Thus $A(t) = U(t)\,P(t)$ is a continuous path in $GL_n(\mathbb{C})$ from $A(0) =
 UP = A$ to $A(1) = I \cdot I = I$. $\square$

**Fact 2.** Every $A \in \mathcal{R}_k$ can be written as $A = P\,D_k\,Q$ where
$P, Q \in GL_n(\mathbb{C})$ and $D_k = \operatorname{diag}(\underbrace{1,\dots,1
}_{k},\underbrace{0,\dots,0}_{n-k})$.

*Proof of Fact 2.* A rank-$k$ matrix has $k$ linearly independent rows and $k$ l
inearly independent columns. By performing suitable invertible row operations (l
eft-multiplication by some $P^{-1} \in GL_n(\mathbb{C})$) and invertible column
operations (right-multiplication by some $Q^{-1} \in GL_n(\mathbb{C})$), we redu
ce $A$ to its rank normal form $D_k$. Equivalently, $P^{-1} A Q^{-1} = D_k$, so
$A = P\,D_k\,Q$. $\square$

---

### Main proof

**Case $k = 0$:** $\mathcal{R}_0 = \{0\}$, a single point, which is (path-)conne
cted.

**Case $1 \le k \le n$:** Let $A \in \mathcal{R}_k$. By Fact 2, write $A = P\,D_
k\,Q$ with $P, Q \in GL_n(\mathbb{C})$. By Fact 1, there exist continuous paths
$P(t), Q(t) \in GL_n(\mathbb{C})$ for $t \in [0,1]$ with $P(0) = P$, $P(1) = I$,
 $Q(0) = Q$, $Q(1) = I$.

Define
$$\gamma(t) = P(t)\,D_k\,Q(t), \quad t \in [0,1].$$

- **Continuity:** $\gamma$ is a product of continuous matrix-valued functions, h
ence continuous.
- **Rank preservation:** For each $t$, $P(t)$ and $Q(t)$ are invertible, so $\op
eratorname{rank}(\gamma(t)) = \operatorname{rank}(D_k) = k$. Thus $\gamma(t) \in
 \mathcal{R}_k$ for all $t$.
- **Endpoints:** $\gamma(0) = P\,D_k\,Q = A$ and $\gamma(1) = I\,D_k\,I = D_k$.

Therefore every $A \in \mathcal{R}_k$ is path-connected to the fixed base point
$D_k \in \mathcal{R}_k$. Given any two matrices $A, B \in \mathcal{R}_k$, concat
enating the path from $A$ to $D_k$ with the reverse of the path from $B$ to $D_k
$ yields a path from $A$ to $B$ within $\mathcal{R}_k$.

Hence $\mathcal{R}_k$ is path-connected, and therefore connected. $\square$

---

**Remark.** The argument relies crucially on working over $\mathbb{C}$ (or any a
lgebraically closed / sufficiently large field), since $GL_n(\mathbb{C})$ is pat
h-connected. Over $\mathbb{R}$, $GL_n(\mathbb{R})$ has two connected components
(distinguished by the sign of the determinant), and the rank-$k$ stratum need no
t be connected—for instance, $\mathcal{R}_n(\mathbb{R}) = GL_n(\mathbb{R})$ has
two components.
