# Solution

## Setup and Key Definitions

Given $n$, let $k(n)$ be the minimal degree of a monic polynomial $f \in \mathbb
{Z}[x]$ such that $n \mid f(x)$ for every integer $x$.

**Kempner function.** For a prime power $p^a$, define $\mu(p^a)$ as the smallest
 positive integer $d$ such that $p^a \mid d!$.

## Step 1: Characterization via Falling Factorials

Write any polynomial $f(x) = \sum_{k=0}^{d} c_k (x)_k$ where $(x)_k = x(x-1)\cdo
ts(x-k+1)$ is the falling factorial and $c_k \in \mathbb{Z}$ (this is always pos
sible since $\{(x)_k\}$ is a $\mathbb{Z}$-basis for $\mathbb{Z}[x]$).

Setting $d_k = c_k \cdot k!$, we get $f(x) = \sum_k d_k \binom{x}{k}$. For integ
er $x$, each $\binom{x}{k}$ is an integer.

**Claim:** $p^a \mid f(x)$ for all $x \in \mathbb{Z}$ if and only if $p^a \mid d
_k$ for all $k$.

*Proof.* The matrix $\left[\binom{x}{k}\right]$ for $x, k = 0, \ldots, d$ is low
er triangular with 1's on the diagonal (since $\binom{x}{k}=0$ for $k>x$ and $\b
inom{x}{x}=1$), hence invertible over $\mathbb{Z}/p^a\mathbb{Z}$. So the system
$\sum_k d_k \binom{x}{k} \equiv 0 \pmod{p^a}$ for $x = 0, \ldots, d$ holds iff $
d_k \equiv 0 \pmod{p^a}$ for all $k$. Since a polynomial of degree $d$ is determ
ined by its values at $d+1$ points, this suffices. $\square$

## Step 2: $k(p^a) = \mu(p^a)$

Since $(x)_d$ has leading coefficient 1 in the monomial basis, a monic $f$ of de
gree $d$ has $c_d = 1$, hence $d_d = d!$.

- **Necessity:** The null condition requires $p^a \mid d_d = d!$, so $d \geq \mu
(p^a)$.
- **Sufficiency:** The polynomial $(x)_{\mu(p^a)}$ is monic of degree $\mu(p^a)$
 and equals $\mu(p^a)! \cdot \binom{x}{\mu(p^a)}$, which is divisible by $p^a$ f
or all $x$ since $p^a \mid \mu(p^a)!$.

Therefore $k(p^a) = \mu(p^a)$.

## Step 3: CRT Reduction — $k(n) = \max_i \mu(p_i^{a_i})$

For $n = \prod p_i^{a_i}$:

**Lower bound:** If $f$ is monic of degree $d$ and null mod $n$, then $f$ is nul
l mod each $p_i^{a_i}$, so $d \geq k(p_i^{a_i}) = \mu(p_i^{a_i})$ for all $i$.

**Upper bound:** Let $D = \max_i \mu(p_i^{a_i})$. Then $p_i^{a_i} \mid D!$ for e
very $i$, so $n \mid D!$. The polynomial $(x)_D = D!\binom{x}{D}$ is monic of de
gree $D$ and divisible by $n$ for all $x$.

Thus $k(n) = \max_i \mu(p_i^{a_i})$.

## Step 4: Compute $k(10^6)$

$$10^6 = 2^6 \cdot 5^6$$

**Compute $\mu(2^6) = \mu(64)$:** We need the smallest $d$ with $v_2(d!) \geq 6$
, where $v_2(d!) = \sum_{j \geq 1} \lfloor d/2^j \rfloor$.

| $d$ | $v_2(d!)$ | $\geq 6$? |
|-----|-----------|-----------|
| 7   | $3+1=5$   | No        |
| 8   | $4+2+1=7$ | Yes       |

So $\mu(64) = 8$.

**Compute $\mu(5^6) = \mu(15625)$:** We need the smallest $d$ with $v_5(d!) \geq
 6$, where $v_5(d!) = \sum_{j \geq 1} \lfloor d/5^j \rfloor$.

| $d$ | $v_5(d!)$ | $\geq 6$? |
|-----|-----------|-----------|
| 24  | $4+0=4$   | No        |
| 25  | $5+1=6$   | Yes       |

So $\mu(5^6) = 25$.

## Result

$$k(10^6) = \max\!\big(\mu(2^6),\; \mu(5^6)\big) = \max(8,\; 25) = \boxed{25}$$
