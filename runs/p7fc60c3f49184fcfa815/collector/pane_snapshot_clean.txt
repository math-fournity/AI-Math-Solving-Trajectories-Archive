## Solution

Let $x_1, x_2, \dots, x_n$ be i.i.d. uniform random variables on $[0,1]$, and le
t $S_n = x_1 + \cdots + x_n$. The integral equals the expectation

$$I_n = \mathbb{E}\!\left[\frac{n}{S_n}\right] = \mathbb{E}\!\left[\frac{1}{\bar
{x}_n}\right], \qquad \bar{x}_n = \frac{S_n}{n}.$$

**Goal:** Show $\lim_{n\to\infty} I_n = 2$.

### Step 1: Almost-sure limit

By the Strong Law of Large Numbers, $\bar{x}_n \to \mathbb{E}[x_1] = \tfrac{1}{2
}$ almost surely. Since $\bar{x}_n > 0$ and the map $t \mapsto 1/t$ is continuou
s on $(0,\infty)$,

$$\frac{n}{S_n} = \frac{1}{\bar{x}_n} \;\xrightarrow{\text{a.s.}}\; \frac{1}{1/2
} = 2.$$

### Step 2: Splitting the expectation

Fix $\delta = 1/4$ and decompose:

$$I_n = \underbrace{\mathbb{E}\!\left[\frac{n}{S_n}\,\mathbf{1}_{\{S_n \le n/4\}
}\right]}_{A_n} + \underbrace{\mathbb{E}\!\left[\frac{n}{S_n}\,\mathbf{1}_{\{S_n
 > n/4\}}\right]}_{B_n}.$$

### Step 3: The tail $A_n$ vanishes

Split further: $A_n = \mathbb{E}\!\left[\frac{n}{S_n}\,\mathbf{1}_{\{S_n \le 1\}
}\right] + \mathbb{E}\!\left[\frac{n}{S_n}\,\mathbf{1}_{\{1 < S_n \le n/4\}}\rig
ht]$.

**Sub-case $S_n \le 1$:** For $0 \le s \le 1$, the Irwin–Hall density is $f_{S_n
}(s) = \dfrac{s^{n-1}}{(n-1)!}$, so

$$\mathbb{E}\!\left[\frac{n}{S_n}\,\mathbf{1}_{\{S_n \le 1\}}\right] = \int_0^1
\frac{n}{s}\cdot\frac{s^{n-1}}{(n-1)!}\,ds = \frac{n}{(n-1)!}\int_0^1 s^{n-2}\,d
s = \frac{n}{(n-1)(n-1)!} \;\xrightarrow{n\to\infty}\; 0.$$

**Sub-case $1 < S_n \le n/4$:** Here $n/S_n \le n$, and by Hoeffding's inequalit
y (since $x_i \in [0,1]$, $\mathbb{E}x_i = 1/2$),

$$\mathbb{P}(S_n \le n/4) = \mathbb{P}(\bar{x}_n - 1/2 \le -1/4) \le \exp\!\bigl
(-2n(1/4)^2\bigr) = e^{-n/8}.$$

Hence

$$\mathbb{E}\!\left[\frac{n}{S_n}\,\mathbf{1}_{\{1 < S_n \le n/4\}}\right] \le n
\,\mathbb{P}(S_n \le n/4) \le n\,e^{-n/8} \;\xrightarrow{n\to\infty}\; 0.$$

Therefore $A_n \to 0$.

### Step 4: The main part $B_n$ via bounded convergence

On the event $\{S_n > n/4\}$, we have $\dfrac{n}{S_n} < 4$, so the integrand is
bounded by the constant $4$. Moreover, $\dfrac{n}{S_n}\,\mathbf{1}_{\{S_n > n/4\
}} \to 2\cdot\mathbf{1}_{\{1 > 1/4\}} = 2$ almost surely (since $S_n/n \to 1/2 >
 1/4$ a.s., the indicator $\to 1$ a.s.). By the Bounded Convergence Theorem,

$$B_n \;\xrightarrow{n\to\infty}\; 2.$$

### Step 5: Conclusion

$$\lim_{n\to\infty} I_n = \lim_{n\to\infty} A_n + \lim_{n\to\infty} B_n = 0 + 2
= 2.$$

$$\boxed{\displaystyle \lim_{n\to\infty}\int_0^1\!\cdots\!\int_0^1 \frac{n}{x_1+
\cdots+x_n}\,dx_1\cdots dx_n = 2}$$
