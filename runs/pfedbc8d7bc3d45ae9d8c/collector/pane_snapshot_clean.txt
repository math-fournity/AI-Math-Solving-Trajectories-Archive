## Proof

**Setup.** The order on $X$ is $(x_1,y_1) < (x_2,y_2)$ iff $y_1 < y_2$, or ($y_1
 = y_2$ and $x_1 < x_2$). This is lexicographic order with $y$ as the primary ke
y. The order topology is generated by open intervals $((a,b),(c,d)) = \{p \in X
: (a,b) < p < (c,d)\}$. Since $X$ has no minimum or maximum element (for any $y_
0 \in (0,1)$, points with smaller/larger $y$ exist), no rays are needed.

**Key observation — fiber structure.** For each $y_0 \in (0,1)$, the *fiber* $F_
{y_0} = \{(x,y_0) : x \in (0,1)\}$ is a copy of $(0,1)$ ordered by $x$. Points o
n the same fiber are ordered by $x$-coordinate; points on different fibers are o
rdered by $y$-coordinate.

**Classification of basic neighborhoods.** Fix $p = (x_0, y_0) \in X$. A basic o
pen interval $I = ((a,b),(c,d))$ containing $p$ must satisfy $(a,b) < (x_0,y_0)
< (c,d)$. There are four cases depending on whether the bounds lie on the same f
iber as $p$:

- **(A)** $b < y_0 < d$: $I$ contains the *entire* fiber $F_{y_0}$ (since $(a,b)
 < (x,y_0) < (c,d)$ for all $x \in (0,1)$).
- **(B)** $b < y_0 = d$, $x_0 < c$: $I \cap F_{y_0} = \{x : x < c\} \cap (0,1) =
 (0,c) \times \{y_0\}$.
- **(C)** $b = y_0 < d$, $a < x_0$: $I \cap F_{y_0} = (a,1) \times \{y_0\}$.
- **(D)** $b = y_0 = d$, $a < x_0 < c$: $I \cap F_{y_0} = (a,c) \times \{y_0\}$,
 and $I$ contains no other fibers.

**Case-D intervals are cofinal.** I claim every basic open interval containing $
p$ contains a case-D interval $(a',c') \times \{y_0\}$ with $a' < x_0 < c'$:

- Case (A): $I \supseteq F_{y_0} \supseteq (a',c')\times\{y_0\}$ for any $0 < a'
 < x_0 < c' < 1$.
- Case (B): $I \supseteq (0,c)\times\{y_0\} \supseteq (a',c')\times\{y_0\}$ for
$0 < a' < x_0 < c' < c$.
- Case (C): $I \supseteq (a,1)\times\{y_0\} \supseteq (a',c')\times\{y_0\}$ for
$a < a' < x_0 < c' < 1$.
- Case (D): $I = (a,c)\times\{y_0\} \supseteq (a',c')\times\{y_0\}$ for $a \le a
' < x_0 < c' \le c$.

Since every open neighborhood of $p$ contains a basic interval, which in turn co
ntains a case-D interval, the case-D intervals form a **cofinal subfamily** of t
he neighborhood system at $p$.

**Subspace topology on fibers.** The case-D interval $(a,c)\times\{y_0\}$ is exa
ctly the basic open interval $((a,y_0),(c,y_0))$ in the order topology, so it is
 open in $X$. The intersection of all four cases with $F_{y_0}$ shows the subspa
ce topology on $F_{y_0}$ is the usual order topology on $(0,1)$.

**Character at each point is $\aleph_0$.** Since case-D intervals are cofinal am
ong neighborhoods, a local base at $p = (x_0,y_0)$ in $X$ is equivalent to a loc
al base at $x_0$ in $(0,1)$ with the usual topology.

*Countable base exists:* The collection $\mathcal{B}_p = \{((x_0 - \tfrac{1}{n},
\, y_0),\; (x_0 + \tfrac{1}{n},\, y_0)) : n \in \mathbb{N},\; n \text{ large eno
ugh}\}$ (with endpoints clamped to $(0,1)$) is a countable family of case-D inte
rvals. Given any open $V \ni p$, it contains a basic interval, which contains so
me $(a',c')\times\{y_0\}$ with $a' < x_0 < c'$. Choose $n$ large enough that $x_
0 - \tfrac{1}{n} > a'$ and $x_0 + \tfrac{1}{n} < c'$; then the $n$-th element of
 $\mathcal{B}_p \subseteq V$. So $\mathcal{B}_p$ is a countable local base.

*No finite base exists:* Suppose $\{U_1,\dots,U_k\}$ is a finite local base at $
p$. Each $U_i$ contains a case-D interval $(a_i, c_i)\times\{y_0\}$ with $a_i <
x_0 < c_i$. Set $a^* = \max_i a_i$, $c^* = \min_i c_i$, so $a^* < x_0 < c^*$. Th
e open set $V = (a^*, c^*)\times\{y_0\}$ is a neighborhood of $p$, so some $U_j
\subseteq V$. But $U_j \supseteq (a_j,c_j)\times\{y_0\}$ with $a_j \le a^*$ and
$c_j \ge c^*$, so $U_j \not\subseteq (a^*,c^*)\times\{y_0\} = V$ unless $a_j = a
^*$ and $c_j = c^*$, in which case $U_j \supseteq V$ and $U_j \subseteq V$ gives
 $U_j = V$. Now take $V' = (\tfrac{a^*+x_0}{2},\, \tfrac{x_0+c^*}{2})\times\{y_0
\}$, a proper sub-neighborhood; no $U_i \subseteq V'$ since each $U_i \supseteq
(a_i,c_i)\times\{y_0\} \supseteq V \supsetneq V'$. Contradiction. So no finite l
ocal base exists.

Therefore $\chi(p, X) = \aleph_0$ for every $p \in X$.

**Conclusion.** The character of the space is:
$$\chi(X) = \sup_{p \in X} \chi(p, X) = \aleph_0.$$

The space $X = (0,1)\times(0,1)$ with the anti-lexicographic order topology is *
*first countable** (character $\aleph_0$) but not second countable (the uncounta
bly many disjoint open fibers $F_y$, $y \in (0,1)$, preclude a countable base fo
r the whole space).
