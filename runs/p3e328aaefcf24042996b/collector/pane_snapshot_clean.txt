**Answer: No.** Not every continuous function $f : \bar{\mathbb{Q}} \to \mathbb{

## Proof

**Key observation.** The set $\bar{\mathbb{Q}}$ (algebraic numbers) is a countab
le dense subset of $\mathbb{R}$, but it does **not** contain any transcendental
numbers. In particular, $\pi \notin \bar{\mathbb{Q}}$.

**Construction.** Let $\alpha = \pi$ (any fixed transcendental number works). Si
nce $\pi \notin \bar{\mathbb{Q}}$, every $x \in \bar{\mathbb{Q}}$ satisfies eith
er $x < \pi$ or $x > \pi$. Define:

$$f : \bar{\mathbb{Q}} \to \mathbb{Q}, \qquad f(x) = \begin{cases} 0 & \text{if
} x < \pi, \\ 1 & \text{if } x > \pi. \end{cases}$$

This is well-defined because $\pi \notin \bar{\mathbb{Q}}$, so the two cases par
tition the entire domain.

**$f$ is non-constant.** We have $0 \in \bar{\mathbb{Q}}$ with $0 < \pi$, so $f(
0) = 0$. We have $4 \in \bar{\mathbb{Q}}$ with $4 > \pi$, so $f(4) = 1$. Thus $f
$ is non-constant. ✓

**$f$ is continuous.** We equip both $\bar{\mathbb{Q}}$ and $\mathbb{Q}$ with th
e subspace topology from $\mathbb{R}$. Set:

$$A = \{x \in \bar{\mathbb{Q}} : x < \pi\} = \bar{\mathbb{Q}} \cap (-\infty, \pi
), \qquad B = \{x \in \bar{\mathbb{Q}} : x > \pi\} = \bar{\mathbb{Q}} \cap (\pi,
 +\infty).$$

**$A$ is clopen (both open and closed) in $\bar{\mathbb{Q}}$:**
- *Open:* $A = \bar{\mathbb{Q}} \cap (-\infty, \pi)$, and $(-\infty, \pi)$ is op
en in $\mathbb{R}$. ✓
- *Closed:* Since $\pi \notin \bar{\mathbb{Q}}$, we have $\bar{\mathbb{Q}} \cap
(-\infty, \pi) = \bar{\mathbb{Q}} \cap (-\infty, \pi]$. The set $(-\infty, \pi]$
 is closed in $\mathbb{R}$, so $A$ is closed in $\bar{\mathbb{Q}}$. ✓

By the identical argument (using $(\pi, +\infty)$ and $[\pi, +\infty)$), **$B$ i
s also clopen** in $\bar{\mathbb{Q}}$.

Now let $V = \mathbb{Q} \cap U$ be any open set in $\mathbb{Q}$ (where $U$ is op
en in $\mathbb{R}$). We check all cases:

| Condition | $f^{-1}(V)$ | Open in $\bar{\mathbb{Q}}$? |
|---|---|---|
| $0 \in U,\; 1 \in U$ | $\bar{\mathbb{Q}}$ | Yes (whole space) |
| $0 \in U,\; 1 \notin U$ | $A$ | Yes (clopen) |
| $0 \notin U,\; 1 \in U$ | $B$ | Yes (clopen) |
| $0 \notin U,\; 1 \notin U$ | $\emptyset$ | Yes (empty) |

In every case, $f^{-1}(V)$ is open in $\bar{\mathbb{Q}}$. Therefore $f$ is conti
nuous. ✓

## Conclusion

We have exhibited a continuous, non-constant function $f : \bar{\mathbb{Q}} \to
\mathbb{Q}$. The essential reason this works is that $\bar{\mathbb{Q}}$, while d
ense in $\mathbb{R}$, **omits all transcendental numbers**. Cutting $\bar{\mathb
b{Q}}$ at any transcendental number $\alpha$ produces a separation into two clop
en sets, yielding a non-constant continuous (locally constant) function into the
 discrete-valued subset $\{0, 1\} \subset \mathbb{Q}$.

Therefore, **not every** continuous function $f : \bar{\mathbb{Q}} \to \mathbb{Q
}$ must be constant.
