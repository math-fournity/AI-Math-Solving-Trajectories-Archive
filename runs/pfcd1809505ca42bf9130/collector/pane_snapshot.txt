Looking at this problem, I need to find the maximum number of alternating knight
/diagonal moves on a 5×6 grid without revisiting any cell.

## Proof

**Setup.** Label cells $(r,c)$ with $0 \le r \le 4$, $0 \le 0 \le c \le 5$. Colo
r the grid as a checkerboard: cell $(r,c)$ has color $(r+c) \bmod 2$. Each color
 class has exactly 15 cells.

**Key observation.** A knight move changes $r+c$ by an odd number (since $\pm 2
\pm 1$ is odd), so it **flips** color. A diagonal move changes $r+c$ by an even
number ($\pm 1 \pm 1 \in \{-2,0,2\}$), so it **preserves** color.

**Color pattern of the path.** Let the path visit cells $c_0, c_1, \ldots, c_M$
(so $M$ moves). Move $k$ (from $c_{k-1}$ to $c_k$) is a knight move if $k$ is od
d, diagonal if $k$ is even. Starting at color $C$:
- $c_0$: color $C$
- $c_1, c_2$: color $1-C$ (knight flips, diagonal preserves)
- $c_3, c_4$: color $C$
- $c_5, c_6$: color $1-C$, and so on.

So the path consists of a starting cell, followed by **pairs** of same-color cel
ls connected by a diagonal move, with knight moves connecting consecutive pairs.

**Diagonal matching constraint.** The diagonal moves within each color class mus
t connect pairs of cells of that color, and since no cell is revisited, these di
agonal edges form a **matching** in the *diagonal graph* of that color class (wh
ere two same-color cells are adjacent if they differ by $(\pm1,\pm1)$).

**Structure of the diagonal graph.** Within a color class, a diagonal move chang
es $r$ by $\pm1$, so it connects cells with $r$-even to cells with $r$-odd. Thus
 the diagonal graph is **bipartite**. For each color class on the $5 \times 6$ g
rid:
- **$r$-even part:** 9 cells (rows 0, 2, 4)
- **$r$-odd part:** 6 cells (rows 1, 3)

By König's theorem, the maximum matching equals at most the size of the smaller
part: **6**. One can verify a matching of size 6 exists in each color class (e.g
., for color 0: $(1,1)\text{--}(0,0)$, $(1,3)\text{--}(0,2)$, $(1,5)\text{--}(0,
4)$, $(3,1)\text{--}(2,0)$, $(3,3)\text{--}(4,2)$, $(3,5)\text{--}(4,4)$; simila
rly for color 1). So the maximum matching is **exactly 6** in each color class.

**Upper bound: $M \le 25$.** For $M$ moves, there are $\lfloor M/2 \rfloor$ diag
onal moves. These alternate between the two color classes: the 1st, 3rd, 5th, ..
. diagonal moves are in color $1{-}C$; the 2nd, 4th, 6th, ... are in color $C$.
So the number of diagonal edges in color $1{-}C$ is $\lceil \lfloor M/2 \rfloor
/ 2 \rceil$.

For $M = 26$: $\lfloor 26/2 \rfloor = 13$ diagonal moves, with $\lceil 13/2 \rce
il = 7$ in one color class. But the maximum matching is 6, so **7 disjoint diago
nal edges in one color class is impossible**. Therefore $M \le 25$.

(The same holds regardless of starting color, by symmetry.)

**Construction achieving $M = 25$.** The following path of 25 moves visits 26 di
stinct cells, alternating knight (odd) and diagonal (even) moves:

4,2), (4,3)$). After move 25, the drone is at $(2,5)$, whose only diagonal neigh
bors are $(1,4)$ and $(3,4)$—both already visited—so no further move is possible
 from this endpoint. (This is consistent with the matching bound: we used all 6
diagonal edges in each color class.)

**Conclusion.** The upper bound $M \le 25$ follows from the bipartite matching c
onstraint on the diagonal graph within each color class (maximum matching size 6
, while $M = 26$ would require 7). The explicit construction achieves $M = 25$.
Therefore, the maximum number of moves is:
