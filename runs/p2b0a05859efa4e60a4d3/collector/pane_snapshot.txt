## Proof

**Setup.** A positive integer $n$ is *squarish* if $n$ is a perfect square, or t
he distance from $n$ to the nearest perfect square is a perfect square. Let $S(N
)$ count squarish integers in $[1, N]$.

**Partition into cells.** For each $k \geq 1$, define the $k$-th cell as $C_k =
[k^2,\; (k+1)^2 - 1]$, which contains $2k+1$ integers. These cells partition $[1
, \infty)$.

**Counting squarish integers in a full cell.** In $C_k = \{k^2, k^2+1, \ldots, k
^2+2k\}$:

- $k^2$ itself is a perfect square, hence squarish. **(1 number)**

- For $j = 1, \ldots, k$: $n = k^2 + j$. The nearest perfect square is $k^2$ (si
nce $j \leq k < k+\tfrac{1}{2}$), with distance $j$. This $n$ is squarish iff $j
$ is a perfect square. The number of perfect squares in $\{1, \ldots, k\}$ is $\
lfloor \sqrt{k} \rfloor$.

- For $j = k+1, \ldots, 2k$: $n = k^2 + j$. The nearest perfect square is $(k+1)
^2$ (since $j > k+\tfrac{1}{2}$), with distance $(k+1)^2 - (k^2+j) = 2k+1-j$, wh
ich ranges over $\{1, 2, \ldots, k\}$. This $n$ is squarish iff $2k+1-j$ is a pe
rfect square, giving $\lfloor \sqrt{k} \rfloor$ squarish numbers.

Therefore the number of squarish integers in the full cell $C_k$ is:
$$f(k) = 1 + 2\lfloor \sqrt{k} \rfloor.$$

**Verification.** For $N=10$: $K = \lfloor\sqrt{10}\rfloor = 3$. Full cells $C_1
=[1,3]$, $C_2=[4,8]$. $f(1)=1+2\cdot1=3$, $f(2)=1+2\cdot1=3$. Partial cell $[9,1
0]$: $9=3^2$ (squarish), $10$: distance to $9$ is $1=1^2$ (squarish), giving $2$
. Total $S(10)=3+3+2=8$. Indeed only $6$ and $7$ are non-squarish in $[1,10]$. ✓

**Asymptotic sum.** Let $K = \lfloor \sqrt{N} \rfloor$, so $K^2 \leq N < (K+1)^2
$. The full cells are $C_1, \ldots, C_{K-1}$ (covering $[1, K^2-1]$), and the pa
rtial cell is $[K^2, N]$.

$$S(N) = \sum_{k=1}^{K-1} f(k) \;+\; \underbrace{g(K, N)}_{\text{partial cell}}.
$$

The partial cell contributes at most $1 + 2\lfloor\sqrt{K}\rfloor = O(\sqrt{K})$

For the main sum:
$$\sum_{k=1}^{K-1} f(k) = \sum_{k=1}^{K-1}\left(1 + 2\lfloor\sqrt{k}\rfloor\righ
t) = (K-1) + 2\sum_{k=1}^{K-1}\lfloor\sqrt{k}\rfloor.$$

**Estimating** $\sum_{k=1}^{K-1}\lfloor\sqrt{k}\rfloor$. Since $\lfloor\sqrt{k}\
rfloor = \sqrt{k} + O(1)$:
$$\sum_{k=1}^{K-1}\lfloor\sqrt{k}\rfloor = \sum_{k=1}^{K-1}\sqrt{k} + O(K).$$

By the Euler–Maclaurin formula (or integral comparison):
$$\sum_{k=1}^{K-1}\sqrt{k} = \int_0^{K}\sqrt{x}\,dx + O(\sqrt{K}) = \frac{2}{3}K
^{3/2} + O(\sqrt{K}).$$

Therefore:
$$\sum_{k=1}^{K-1}\lfloor\sqrt{k}\rfloor = \frac{2}{3}K^{3/2} + O(K).$$

**Combining:**
$$S(N) = (K-1) + 2\left(\frac{2}{3}K^{3/2} + O(K)\right) + O(\sqrt{K}) = \frac{4
}{3}K^{3/2} + O(K).$$

$$K^{3/2} = \left(\sqrt{N} + O(1)\right)^{3/2} = N^{3/4}\left(1 + O(N^{-1/2})\ri
ght)^{3/2} = N^{3/4} + O(N^{1/4}).$$

Thus:
$$S(N) = \frac{4}{3}N^{3/4} + O(N^{1/2}).$$

**Conclusion.** Dividing by $N^{3/4}$:
$$\frac{S(N)}{N^{3/4}} = \frac{4}{3} + O(N^{-1/4}) \;\longrightarrow\; \frac{4}{
3} \quad\text{as } N \to \infty.$$
