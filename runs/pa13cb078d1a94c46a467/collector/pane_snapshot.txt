**Intersection with y = 100 − x:**

For θ = 90°: x = 0 meets y = 100 − x at (0, 100), so **x_{90°} = 0** (consistent

**Special case:** At θ = 135°, tan(135°) = −1, so the line y = −x is **parallel*

## Pairing Strategy

Pair each angle k° with (90 + k)° for k = 0, 1, ..., 89. This gives 90 pairs cov
ering all 180 lines.

**Compute the pair sum** (for k ≠ 45, where both lines intersect):

$$x_k + x_{90+k} = \frac{100}{\tan k + 1} + \frac{100}{\tan(90°+k) + 1}$$

Since tan(90° + k) = −cot k = −1/tan k:

$$= \frac{100}{\tan k + 1} + \frac{100\tan k}{\tan k - 1}$$

$$= 100 \cdot \frac{(\tan k - 1) + \tan k(\tan k + 1)}{(\tan k+1)(\tan k - 1)} =
 100 \cdot \frac{\tan^2 k + 2\tan k - 1}{\tan^2 k - 1}$$

Using the equivalent form x_θ = 100 cos θ/(sin θ + cos θ), and substituting cos(
90°+k) = −sin k, sin(90°+k) = cos k:

$$\frac{\cos k}{\sin k + \cos k} + \frac{-\sin k}{\cos k - \sin k} = \frac{\sin
2k - \cos 2k}{-\cos 2k} = 1 - \tan 2k$$

So each pair contributes: **100(1 − tan 2k°)**.
