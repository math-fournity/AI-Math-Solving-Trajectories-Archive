## 解答

**建立坐标系。** 设 $A$ 为原点。设 $l_i$ 为通过 $A$ 的直线，方向单位向量为 $u_i$
。$l_i$ 上的点表示为 $t\,u_i$。$l_i$ 上距离 $B_i$ 为 6 的点满足：

$$|t\,u_i - B_i|^2 = 36 \implies t^2 - 2(u_i \cdot B_i)\,t + |B_i|^2 - 36 = 0.$$

由于 $|B_i|=8$，得到 $t^2 - 2d_i\,t + 28 = 0$，其中 $d_i = u_i \cdot B_i$。根据
韦达定理（Vieta's），两根乘积为 $28$。

**确定 $AP_i$。** 对于 $l_1$：根为 $t$ 和 $28/t$，且 $|t|=9$（即 $Q_1$ 的距离）
。取 $t=9$，另一个根为 $28/9$，因此 $AP_1 = 28/9$。同理，对于 $l_2$：$AQ_2=11$
得到 $AP_2 = 28/11$。由于两根乘积 $28>0$，$P_i$ 和 $Q_i$ 位于从 $A$ 出发的同一条
射线上，因此 $\angle Q_1 A Q_2 = \angle P_1 A P_2 =: \alpha$。

**利用外接圆（circumradius）条件。** 设 $a = AP_1 = 28/9$，$b = AP_2 = 28/11$。$
\triangle AP_1P_2$ 的外接圆半径为：

$$R = \frac{P_1P_2}{2\sin\alpha} = 2 \implies P_1P_2^2 = 16\sin^2\alpha.$$

由于 $P_1P_2^2 = a^2 + b^2 - 2ab\cos\alpha$，令 $c = \cos\alpha$：

$$a^2 + b^2 - 2ab\,c = 16(1-c^2) \implies 16c^2 - 2ab\,c + (a^2+b^2-16) = 0.$$

计算：$a^2+b^2 = \tfrac{784}{81}+\tfrac{784}{121} = \tfrac{784\cdot 202}{9801} =
 \tfrac{158368}{9801}$，所以 $a^2+b^2-16 = \tfrac{1552}{9801}$，且 $2ab = \tfrac
{1568}{99}$。乘以 $9801$：

$$156816\,c^2 - 155232\,c + 1552 = 0 \implies 9801\,c^2 - 9702\,c + 97 = 0.$$

判别式：$9702^2 - 4\cdot9801\cdot97 = 94128804 - 3802788 = 90326016 = 9504^2$。
因此：

$$c = \frac{9702 \pm 9504}{19602} \implies c = \frac{1067}{1089} \quad\text{或}\
quad c = \frac{1}{99}.$$

**计算 $Q_1Q_2$。** 由于 $Q_1 = 9\,u_1$，$Q_2 = 11\,u_2$，且它们之间的夹角为 $\a
lpha$：

$$(Q_1Q_2)^2 = 9^2 + 11^2 - 2\cdot 9\cdot 11\cos\alpha = 202 - 198\cos\alpha.$$

- 若 $\cos\alpha = \tfrac{1067}{1089}$：$(Q_1Q_2)^2 = 202 - \tfrac{198\cdot1067}
{1089} = 202 - 194 = 8$。
- 若 $\cos\alpha = \tfrac{1}{99}$：$(Q_1Q_2)^2 = 202 - \tfrac{198}{99} = 202 - 2
 = 200$。

**可行性。** 对于每种情况，有效的 $B_1, B_2$ 均存在：$B_i$ 距离 $A$ 为 8，且在 $
l_i$ 上的投影为 $d_1 = 109/18 < 8$ 和 $d_2 = 149/22 < 8$，因此垂线距离 $\sqrt{64
-d_i^2}$ 均为实数。$B_1$ 和 $B_2$ 的放置是独立的（仅要求 $|B_i|=8$），因此两种 $
\alpha$ 值均可实现。当 $\cos\alpha = 1/99$ 时，$B_1 \neq B_2$（直线夹角约为 $89.
4°$），因此三角形非退化。

**最大值。** 在 $\cos\alpha = \tfrac{1}{99}$ 时取得最大值：

$$(Q_1Q_2)^2_{\max} = \boxed{200}.$$
