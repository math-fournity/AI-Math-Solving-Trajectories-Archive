# Problem

In a circular research facility, there are 100 white emergency lights arranged in a perfect ring. A technician is testing a specific maintenance protocol defined by an integer $k$, where $1 \le k \le 50$.

Under this protocol, the technician can perform a "Toggle Operation" with the following constraints:
1. They must select a sequence of exactly $k$ consecutive lights.
2. The operation can only be performed if both the first light and the last light in that chosen sequence are currently white.
3. Upon performing the operation, those two specific white lights (the first and the last of the sequence) are painted black.

The technician wants to determine if a given value of $k$ allows them to eventually paint all 100 lights black through a series of these operations.

Let $S$ be the set of all integers $k \in \{1, 2, \dots, 50\}$ for which it is possible to turn all 100 white lights into black lights.

Find the sum of all elements in $S$.
