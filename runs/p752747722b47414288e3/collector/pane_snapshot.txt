### Setup

The region is:
$$\Omega = \{(x,y,z) \mid x\ge 0,\; y\ge 0,\; z\ge 0,\; x\le y+z,\; \tfrac12 \le
 x+y+z \le 1\}$$

where I rewrote $1 \le 2(x+y+z)\le 2$ as $\frac12 \le x+y+z \le 1$.

### Change of variables

Let $s = x+y+z$, keeping $y,z$ as the other variables. Then $x = s-y-z$ and the
Jacobian is $1$, so $dx\,dy\,dz = ds\,dy\,dz$.

The constraints become:
- $x \ge 0 \Rightarrow y+z \le s$
- $y \ge 0,\; z \ge 0$
- $x \le y+z \Rightarrow s \le 2(y+z) \Rightarrow y+z \ge s/2$
- $\frac12 \le s \le 1$

So the integral is:
$$I = \int_{1/2}^{1}\!\!\iint\limits_{\substack{y\ge0,\,z\ge0\\ s/2\,\le\, y+z\,
\le\, s}} \frac{z}{y+z}\,dy\,dz\,ds.$$

### Inner double integral

Set $t = y+z$ (with $z$ kept), so $y = t-z$, $dy\,dz = dt\,dz$. Constraints: $0
\le z \le t$, $\;s/2 \le t \le s$.

$$\int_{s/2}^{s}\int_{0}^{t} \frac{z}{t}\,dz\,dt = \int_{s/2}^{s} \frac{1}{t}\cd
ot\frac{t^{2}}{2}\,dt = \int_{s/2}^{s}\frac{t}{2}\,dt = \frac{1}{4}\Big[t^{2}\Bi
g]_{s/2}^{s} = \frac{1}{4}\!\left(s^{2}-\frac{s^{2}}{4}\right)=\frac{3s^{2}}{16}
.$$

### Outer integral

$$I = \int_{1/2}^{1}\frac{3s^{2}}{16}\,ds = \frac{3}{16}\cdot\frac{s^{3}}{3}\big
g|_{1/2}^{1} = \frac{1}{16}\!\left(1-\frac{1}{8}\right)=\frac{1}{16}\cdot\frac{7
}{8}=\boxed{\frac{7}{128}}.$$
