## Proof

**Setup.** Let $\mathcal{C} = \{[b,c] : b, c \in \mathbb{R},\; b \le c\}$ be the
 set of all finite closed intervals. The evaluation map is
$$E([b,c]) = \int_b^c 1\,dx = c - b.$$
We form $\operatorname{Span}\,\mathcal{C}$, the vector space of all finite forma
l linear combinations $\sum_i a_i [b_i, c_i]$, and extend $E$ linearly:
$$E\!\left(\sum_i a_i [b_i, c_i]\right) = \sum_i a_i (c_i - b_i).$$

**Key observation: the equivalence relation is the kernel relation of $E$.**

The relation $X \sim \widetilde{X}$ is defined by $E(X) = E(\widetilde{X})$, i.e
., $E(X - \widetilde{X}) = 0$, i.e., $X - \widetilde{X} \in \ker E$. This is pre
cisely the coset equivalence relation modulo $\ker E$. Therefore, by the first i
somorphism theorem for vector spaces:

$$\operatorname{Span}\,\mathcal{C}\,/\!\sim \;\cong\; \operatorname{Span}\,\math
cal{C}\,/\,\ker E \;\cong\; \operatorname{im}(E).$$

**The image of $E$ is all of $\mathbb{R}$.**

- $E$ maps into $\mathbb{R}$, so $\operatorname{im}(E) \subseteq \mathbb{R}$.
- For any $r \in \mathbb{R}$, consider the element $r \cdot [0,1] \in \operatorn
ame{Span}\,\mathcal{C}$. Then
$$E(r \cdot [0,1]) = r \cdot (1 - 0) = r.$$
Hence every real number is in the image, so $\operatorname{im}(E) = \mathbb{R}$.

**Conclusion.**

$$\operatorname{Span}\,\mathcal{C}\,/\!\sim \;\cong\; \mathbb{R},$$

which is a one-dimensional vector space over $\mathbb{R}$.

$$\boxed{\dim\!\big(\operatorname{Span}\,\mathcal{C}\,/\!\sim\big) = 1}$$
