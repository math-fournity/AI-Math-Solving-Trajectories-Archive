## Solution

**Setup and duality.** Let $f$ be integrable on $[0,1]$ with $\int_0^1 x^k f(x)\
,dx = 0$ for $k=0,\dots,9$ and $\int_0^1 x^{10} f(x)\,dx = 1$. We seek the large
st $C$ such that for every such $f$, the set $\{x : |f(x)| \ge C\}$ has positive
 measure.

For any polynomial $p(x) = \sum_{k=0}^{10} c_k x^k$ of degree $\le 10$, the mome
nt conditions give $\int_0^1 f(x)\,p(x)\,dx = c_{10}$. By Hölder's inequality:

$$|c_{10}| = \left|\int_0^1 f\,p\right| \le \|f\|_\infty \cdot \int_0^1 |p(x)|\,
dx.$$

So $\|f\|_\infty \ge |c_{10}|/\int_0^1|p|\,dx$ for every such $p$. Taking the su
premum:

$$\|f\|_\infty \ge \sup_p \frac{|c_{10}|}{\int_0^1 |p|\,dx} = \frac{1}{\min\left
\{\int_0^1 |p|\,dx : [x^{10}]\,p = 1\right\}}.$$

Let $m = \min \int_0^1 |p|\,dx$ over monic degree-10 polynomials. Then $C = 1/m$
 (strong duality holds; we verify achievability below).

**Finding the extremal polynomial.** The optimal $p^*$ satisfies the first-order
 condition: for every polynomial $q$ of degree $\le 9$,

$$\int_0^1 \operatorname{sgn}(p^*(x))\,q(x)\,dx = 0,$$

since perturbing $p^* \to p^* + \varepsilon q$ (with $\deg q \le 9$, preserving
the leading coefficient) must not decrease the objective.

**Shifted Chebyshev polynomial of the second kind.** Let $U_n(t) = \frac{\sin((n
+1)\theta)}{\sin\theta}$ where $t = \cos\theta$, the Chebyshev polynomial of the
 second kind. It has leading coefficient $2^n$ in $t$. Define the shifted versio
n $\widetilde{U}_n(x) = U_n(2x-1)$, which has leading coefficient $4^n$ in $x$.

**Key computation.** With $x = (1+\cos\theta)/2$, $dx = -\sin\theta/2\,d\theta$:

$$\int_0^1 |U_n(2x-1)|\,dx = \frac{1}{2}\int_0^\pi \left|\frac{\sin((n+1)\theta)
}{\sin\theta}\right|\sin\theta\,d\theta = \frac{1}{2}\int_0^\pi |\sin((n+1)\thet
a)|\,d\theta = \frac{1}{2}\cdot 2 = 1.$$

(The last step uses $\int_0^\pi|\sin((n+1)\theta)|\,d\theta = \frac{1}{n+1}\int_
0^{(n+1)\pi}|\sin u|\,du = \frac{2(n+1)}{n+1} = 2$.)

**$\widetilde{U}_n/4^n$ is the extremal monic polynomial.** $U_n(2x-1)$ has exac
tly $n$ simple zeros in $(0,1)$ (at $x = (1+\cos(k\pi/(n+1)))/2$, $k=1,\dots,n$)
, so $\operatorname{sgn}(\widetilde{U}_n)$ is a $\pm 1$ step function changing s
ign $n$ times. We verify the orthogonality condition:

$$\int_0^1 \operatorname{sgn}(\widetilde{U}_n(x))\,q(x)\,dx = 0 \quad \text{for
all } \deg q \le n-1.$$

This holds because $\widetilde{U}_n$ is orthogonal to all polynomials of degree
$< n$ with respect to the weight $\sqrt{x(1-x)}$ on $[0,1]$, and the sign functi
on of $\widetilde{U}_n$ produces the same orthogonality via the equioscillation
structure. (Concretely, the substitution $x=(1+\cos\theta)/2$ converts this to $
\int_0^\pi \operatorname{sgn}(\sin((n+1)\theta))\,Q(\cos\theta)\sin\theta\,d\the
ta = 0$ for $\deg Q \le n-1$, which follows from the Fourier orthogonality of th
e square-wave $\operatorname{sgn}(\sin((n+1)\theta))$ against $\sin\theta\cdot P
(\cos\theta)$ for polynomials $P$ of degree $\le n-1$.)

Therefore $p^*(x) = \widetilde{U}_{10}(x)/4^{10} = U_{10}(2x-1)/4^{10}$ is the m
onic degree-10 polynomial minimizing $\int_0^1|p|\,dx$, and:

$$m = \int_0^1 |p^*(x)|\,dx = \frac{1}{4^{10}} \cdot 1 = \frac{1}{4^{10}} = \fra
c{1}{2^{20}}.$$

**Achievability (primal feasible).** Set $f^*(x) = A\cdot\operatorname{sgn}(p^*(
x))$ with $A = 2^{20}$. Then:
- $\int_0^1 f^*\,x^k = A\int_0^1 \operatorname{sgn}(p^*)\,x^k = 0$ for $k=0,\dot
s,9$ (orthogonality). ✓
- $\int_0^1 f^*\,x^{10} = A\int_0^1 \operatorname{sgn}(p^*)\,x^{10} = A\int_0^1
\operatorname{sgn}(p^*)\,p^* = A\int_0^1|p^*| = 2^{20}\cdot 2^{-20} = 1$. ✓
- $\|f^*\|_\infty = 2^{20}$, and $|f^*(x)| = 2^{20}$ a.e., so $\{|f^*| \ge 2^{20
}\} = [0,1]$ has positive measure. ✓

**$C$ is the largest such constant.** For any valid $f$ with $\|f\|_\infty = 2^{
20}$, equality in Hölder forces $f = A\,\operatorname{sgn}(p^*)$ a.e. with $|A|=
2^{20}$, so $|f|=2^{20}$ a.e. and $\{|f|\ge 2^{20}\}$ has full measure. For any
valid $f$ with $\|f\|_\infty > 2^{20}$, the set $\{|f| > 2^{20}\}$ has positive
measure, hence $\{|f|\ge 2^{20}\}$ does too. Thus $|f|\ge 2^{20}$ on a set of po
sitive measure for **every** valid $f$.

For any $C' > 2^{20}$, the function $f^*$ has $\|f^*\|_\infty = 2^{20} < C'$, so
 $\{|f^*|\ge C'\}=\emptyset$, which has measure zero. Hence $C'$ fails.

**Conclusion.**

$$\boxed{C = 2^{20} = 1048576.}$$
