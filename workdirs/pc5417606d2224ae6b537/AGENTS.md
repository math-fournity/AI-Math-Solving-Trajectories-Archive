# Problem

In a futuristic circular city, there are $n$ distinct districts arranged in a perfect ring, where $n \geq 2$. Within these districts, there are a total of $mn$ specialized sensor stations. Each sensor belongs to one of $n$ different network types, and there are exactly $m$ sensors of each network type distributed around the ring.

A central operator needs to select a "Master Array" consisting of exactly $n$ sensors. To ensure the array is functional and stable, the selection must satisfy two strict protocols:
1.  **Diversity Protocol:** The array must contain exactly one sensor from each of the $n$ network types.
2.  **Interference Protocol:** No two selected sensors in the array can be positioned immediately next to each other along the circular perimeter.

Determine the minimum integer value of $M$ such that for every possible distribution of sensors where $m \geq M$, it is guaranteed that at least one such Master Array exists.
