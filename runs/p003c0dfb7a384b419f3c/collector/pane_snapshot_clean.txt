## Proof

We consider the inviscid Burgers' equation
$$u_t + u\,u_x = 0, \qquad u(x,0) = \cos(\pi x).$$

**Method of characteristics.** Along a characteristic curve $(x(t), t)$ we have
$$\frac{dx}{dt} = u, \qquad \frac{du}{dt} = u_t + u_x \frac{dx}{dt} = u_t + u\,u
_x = 0.$$

Hence $u$ is constant along each characteristic. Label each characteristic by it
s footpoint $x_0 = x(0)$. Then
$$u(x(t), t) = u_0(x_0) = \cos(\pi x_0),$$
and integrating $\dot x = u$:
$$x(t) = x_0 + \cos(\pi x_0)\,t. \tag{1}$$

Equation (1) defines the map $\Phi_t : x_0 \mapsto x(t)$ from the Lagrangian lab
el $x_0$ to the Eulerian position $x$. As long as $\Phi_t$ is a diffeomorphism,
the solution $u(x,t) = \cos(\pi x_0(x,t))$ is single-valued, where $x_0(x,t)$ is
 the inverse of (1).

**Multi-valuedness criterion.** The solution becomes multi-valued at the first t
ime $t_b$ at which $\Phi_t$ ceases to be locally invertible, i.e. when
$$\frac{\partial x}{\partial x_0} = 0 \quad \text{for some } x_0. \tag{2}$$

Differentiating (1):
$$\frac{\partial x}{\partial x_0} = 1 + t\,\frac{d}{dx_0}\cos(\pi x_0) = 1 - \pi
 t\,\sin(\pi x_0). \tag{3}$$

Condition (2) becomes
$$1 - \pi t\,\sin(\pi x_0) = 0 \quad\Longleftrightarrow\quad \sin(\pi x_0) = \fr
ac{1}{\pi t}.$$

This equation has a solution in $x_0$ if and only if $\frac{1}{\pi t} \le 1$, i.
e. $t \ge \frac{1}{\pi}$. Therefore the **first** time at which the Jacobian van
ishes — and hence the first time at which characteristics cross and the classica
l solution becomes multi-valued — is

$$\boxed{t_b = \frac{1}{\pi}}.$$

**Location of the gradient catastrophe.** At $t_b = 1/\pi$ the critical value is
 $\sin(\pi x_0) = 1$, achieved at $x_0 = \tfrac{1}{2} + 2k$ (and by periodicity
also $x_0 = \tfrac{1}{2}$ within one period). The corresponding Eulerian positio
n is, from (1),
$$x_b = \tfrac{1}{2} + \cos(\pi/2)\cdot\tfrac{1}{\pi} = \tfrac{1}{2} + 0 = \tfra
c{1}{2}.$$

**Verification via the breaking-time formula.** For a general scalar conservatio
n law $u_t + f(u)_x = 0$ with $f'(u) = u$ here, the breaking time is
$$t_b = \frac{-1}{\min_{x_0} u_0'(x_0)}.$$

Here $u_0'(x_0) = -\pi\sin(\pi x_0)$, whose minimum is $-\pi$ (attained at $x_0
= 1/2$). Thus
$$t_b = \frac{-1}{-\pi} = \frac{1}{\pi},$$

confirming the result. At $t = 1/\pi$ the spatial gradient $u_x = u_0'(x_0)/(\pa
rtial x/\partial x_0)$ blows up (since $\partial x/\partial x_0 \to 0$ while $u_
0'(x_0) = -\pi \neq 0$ at $x_0 = 1/2$), the classical solution ceases to exist,
and for $t > 1/\pi$ the method-of-characteristics construction yields a multi-va
lued (folded) profile.
