Yes, it is possible. Two non-isomorphic graphs can share the same adjacency spec
trum; such graphs are called **cospectral** (or isospectral). I prove this by ex
hibiting an explicit pair.

## The example

Consider the following two simple undirected graphs, each on 5 vertices:

- **G = K_{1,4}**, the star with one center and four leaves (the complete bipart
ite graph K_{1,4}).
- **H = C_4 ∪ K_1**, the disjoint union of a 4-cycle and a single isolated verte
x.

## They are non-isomorphic

G = K_{1,4} is connected (every leaf is adjacent to the center). H = C_4 ∪ K_1 i
s disconnected (it has an isolated vertex). A graph isomorphism preserves connec
tedness, so G and H cannot be isomorphic.

## Spectrum of G = K_{1,4}

The adjacency matrix of the complete bipartite graph K_{m,n} has eigenvalues

√(mn), −√(mn), and 0 with multiplicity m+n−2.

For K_{1,4} we have m=1, n=4, so the eigenvalues are

√4 = 2,  −√4 = −2,  and 0 with multiplicity 1+4−2 = 3.

Thus Spec(G) = {2, −2, 0, 0, 0}.

## Spectrum of H = C_4 ∪ K_1

The adjacency matrix of a disjoint union is block diagonal, so its spectrum is t
he union (multiset sum) of the spectra of the blocks.

The cycle C_n has eigenvalues 2 cos(2πk/n) for k = 0,…,n−1. For C_4:

- k=0: 2 cos 0 = 2
- k=1: 2 cos(π/2) = 0
- k=2: 2 cos π = −2
- k=3: 2 cos(3π/2) = 0

So Spec(C_4) = {2, 0, 0, −2}. The isolated vertex K_1 contributes the single eig
envalue 0. Therefore

Spec(H) = {2, 0, 0, −2} ∪ {0} = {2, −2, 0, 0, 0}.

## Conclusion

Spec(G) = Spec(H) = {2, −2, 0, 0, 0}, yet G ≇ H. Hence two non-isomorphic graphs
 can indeed have the same adjacency spectrum; the spectrum does not determine a
graph up to isomorphism.
