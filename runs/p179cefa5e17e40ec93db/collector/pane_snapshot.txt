## Proof

**Setup.** Place the circumcircle of △ABC as the unit circle centered at $O = (0
,0)$. Rotate so that $B$ and $C$ are symmetric about the $x$-axis:
$$B = (\cos\theta,\, \sin\theta), \qquad C = (\cos\theta,\, -\sin\theta), \qquad
 A = (\cos\alpha,\, \sin\alpha),$$
with $|A|=|B|=|C|=1$. The inscribed angle $\angle BAC = \theta$ (or $\pi-\theta$
), so the condition $\angle BAC \neq 90°$ gives $\cos\theta \neq 0$.

**Step 1: Equation of $\Gamma$ and the point $N$.**

The circumcircle $\Gamma$ of $\triangle BOC$ passes through $O=(0,0)$, $B$, $C$.
 By symmetry its center is $M = (m, 0)$. From $|M|=|M-B|$:
$$m^2 = (m-\cos\theta)^2 + \sin^2\theta = m^2 - 2m\cos\theta + 1 \implies m = \f
rac{1}{2\cos\theta}.$$
The equation of $\Gamma$ is $\left(x - \tfrac{1}{2\cos\theta}\right)^2 + y^2 = \
frac{1}{4\cos^2\theta}$, which simplifies to:
$$x^2 + y^2 = \frac{x}{\cos\theta}. \tag{1}$$
Since $ON$ is a diameter of $\Gamma$, the point $N$ is the reflection of $O$ thr
ough $M$:
$$N = 2M = \left(\frac{1}{\cos\theta},\, 0\right) = (\sec\theta,\, 0).$$
Note that (1) can be written as $|X|^2 = X \cdot N$ for any point $X=(x,y)$.

**Step 2: Find $P$ (second intersection of line $AB$ with $\Gamma$).**

Parametrize line $AB$: $X(t) = (1-t)\,A + t\,B$, where $t=0$ gives $A$ and $t=1$
 gives $B$. Substituting into $|X|^2 = X \cdot N$:
$$(1-t)^2|A|^2 + 2t(1-t)\,A\!\cdot\!B + t^2|B|^2 = (1-t)\,A\!\cdot\!N + t\,B\!\c
dot\!N.$$
Using $|A|=|B|=1$ and $B\cdot N = \cos\theta\cdot\sec\theta = 1$:
$$(1-t)^2 + 2t(1-t)(A\!\cdot\!B) + t^2 = (1-t)(A\!\cdot\!N) + t.$$
Rearranging and factoring out $(1-t)$ (since $t=1$ corresponds to $B$):
$$(1-t)\big[(1 - 2t) + 2t(A\!\cdot\!B) - A\!\cdot\!N\big] = 0.$$
The second root (giving $P$) is:
$$t_P = \frac{A\cdot N - 1}{2(A\cdot B - 1)} = \frac{\cos\alpha\,\sec\theta - 1}
{2(\cos(\alpha-\theta) - 1)}. \tag{2}$$

**Step 3: Find $Q$ (second intersection of line $AC$ with $\Gamma$).**

By the identical computation with $C$ replacing $B$ (noting $A\cdot C = \cos(\al
pha+\theta)$):
$$s_Q = \frac{\cos\alpha\,\sec\theta - 1}{2(\cos(\alpha+\theta) - 1)}. \tag{3}$$

**Step 4: Prove $P + Q = A + N$ (diagonals bisect each other).**

We have $P = (1-t_P)A + t_P B$ and $Q = (1-s_Q)A + s_Q C$, so:
$$P + Q = (2 - u)\,A + t_P B + s_Q C, \qquad u := t_P + s_Q.$$
Since $B + C = (2\cos\theta,\, 0)$ and $B - C = (0,\, 2\sin\theta)$:
$$t_P B + s_Q C = \big(u\cos\theta,\; v\sin\theta\big), \qquad v := t_P - s_Q.$$
Thus $P + Q = \big((2-u)\cos\alpha + u\cos\theta,\;(2-u)\sin\alpha + v\sin\theta
\big)$, and we need this to equal $A + N = (\cos\alpha + \sec\theta,\;\sin\alpha
)$. This gives two conditions:

- **(I)** $(1-u)\cos\alpha + u\cos\theta = \sec\theta$
- **(II)** $(1-u)\sin\alpha + v\sin\theta = 0$

**Verifying (I).** From (2)–(3), using $\cos\alpha\,\sec\theta - 1 = \frac{\cos\
alpha - \cos\theta}{\cos\theta}$:
$$u = \frac{\cos\alpha - \cos\theta}{2\cos\theta}\left[\frac{1}{\cos(\alpha-\the
ta)-1} + \frac{1}{\cos(\alpha+\theta)-1}\right].$$
The bracketed sum has numerator $\cos(\alpha+\theta)-1+\cos(\alpha-\theta)-1 = 2
\cos\alpha\cos\theta - 2 = -2(1-\cos\alpha\cos\theta)$, and denominator (using $
\cos(\alpha-\theta)\cos(\alpha+\theta) = \cos^2\alpha+\cos^2\theta-1$):
$$(\cos(\alpha-\theta)-1)(\cos(\alpha+\theta)-1) = 1 - 2\cos\alpha\cos\theta + \
cos^2\alpha + \cos^2\theta - 1 = (\cos\alpha - \cos\theta)^2.$$
So:
$$u = \frac{\cos\alpha - \cos\theta}{2\cos\theta}\cdot\frac{-2(1-\cos\alpha\cos\
theta)}{(\cos\alpha-\cos\theta)^2} = \frac{1 - \cos\alpha\cos\theta}{\cos\theta(
\cos\theta - \cos\alpha)}. \tag{4}$$
Now check (I): $(1-u)\cos\alpha + u\cos\theta = \cos\alpha + u(\cos\theta - \cos
\alpha)$. From (4):
$$u(\cos\theta - \cos\alpha) = \frac{1 - \cos\alpha\cos\theta}{\cos\theta} = \se
c\theta - \cos\alpha.$$
Hence $(1-u)\cos\alpha + u\cos\theta = \cos\alpha + \sec\theta - \cos\alpha = \s
ec\theta.$ ✓

**Verifying (II).** We need $v = -(1-u)\sin\alpha/\sin\theta$. Compute $1-u$ fro
m (4):
$$1 - u = \frac{\cos\theta(\cos\theta-\cos\alpha) - (1-\cos\alpha\cos\theta)}{\c
os\theta(\cos\theta-\cos\alpha)} = \frac{\cos^2\theta - 1}{\cos\theta(\cos\theta
-\cos\alpha)} = \frac{-\sin^2\theta}{\cos\theta(\cos\theta-\cos\alpha)}.$$
So $-(1-u)\sin\alpha/\sin\theta = \frac{\sin\alpha\sin\theta}{\cos\theta(\cos\th
eta-\cos\alpha)}$. Now compute $v$ directly:
$$v = \frac{\cos\alpha - \cos\theta}{2\cos\theta}\cdot\frac{\cos(\alpha+\theta)-
\cos(\alpha-\theta)}{(\cos\alpha-\cos\theta)^2} = \frac{\cos\alpha-\cos\theta}{2
\cos\theta}\cdot\frac{-2\sin\alpha\sin\theta}{(\cos\alpha-\cos\theta)^2} = \frac
{\sin\alpha\sin\theta}{\cos\theta(\cos\theta-\cos\alpha)}.$$
This matches. ✓

**Conclusion.** Both conditions hold, so $P + Q = A + N$. The midpoints of the d
iagonals $AN$ and $PQ$ of quadrilateral $APNQ$ coincide, which means $APNQ$ is a
 **parallelogram**. $\blacksquare$
