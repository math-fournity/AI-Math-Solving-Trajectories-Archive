## Proof

Define the map $\varphi: C_0 \to \mathbb{R}$ by
$$\varphi\big((x_n)\big) = x_1 + x_2 + \cdots + x_{10}.$$

**Linearity.** For $(x_n), (y_n) \in C_0$ and $\alpha, \beta \in \mathbb{R}$,
$$\varphi(\alpha x + \beta y) = \alpha x_1 + \cdots + \alpha x_{10} + \beta y_1
+ \cdots + \beta y_{10} = \alpha\,\varphi(x) + \beta\,\varphi(y),$$
so $\varphi$ is linear.

**Well-definedness on $C_0$.** The value $\varphi((x_n))$ depends only on the fi
rst 10 terms, which are well-defined real numbers for every sequence in $C_0$. N
o convergence issue arises.

**Kernel.** By definition,
$$\ker\varphi = \{(x_n) \in C_0 : x_1 + \cdots + x_{10} = 0\} = M.$$

**Surjectivity.** Consider the sequence $e = (1, 0, 0, \ldots) \in C_0$ (it conv
erges to $0$). Then $\varphi(e) = 1 \neq 0$, so $\varphi$ is surjective onto $\m
athbb{R}$.

**Quotient isomorphism.** By the first isomorphism theorem for vector spaces,
$$C_0 / \ker\varphi \cong \operatorname{im}\varphi,$$
that is,
$$C_0 / M \cong \mathbb{R}.$$

Therefore,
$$\dim\!\left(\frac{C_0}{M}\right) = \dim \mathbb{R} = \boxed{1}.$$
