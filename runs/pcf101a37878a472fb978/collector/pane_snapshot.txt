## Solution

**Answer leak check:** The problem statement contains only the integral to evalu
ate — no solutions, sketches, or answer values. Proceeding.

We evaluate
$$I = \int_0^\infty \frac{\ln^2(1+x)}{x^{3/2}}\,dx.$$

### Step 1. Integration by parts

Set $u = \ln^2(1+x)$ and $dv = x^{-3/2}\,dx$, so that
$$v = -2x^{-1/2}, \qquad du = \frac{2\ln(1+x)}{1+x}\,dx.$$

Then
$$I = \Bigl[-2x^{-1/2}\ln^2(1+x)\Bigr]_0^\infty + 4\int_0^\infty \frac{\ln(1+x)}
{x^{1/2}(1+x)}\,dx.$$

**Boundary terms vanish:** as $x\to 0^+$, $\ln^2(1+x)\sim x^2$, so $x^{-1/2}\ln^
2(1+x)\sim x^{3/2}\to 0$; as $x\to\infty$, $x^{-1/2}\ln^2(1+x)\to 0$. Hence
$$I = 4\int_0^\infty \frac{\ln(1+x)}{x^{1/2}(1+x)}\,dx.$$

### Step 2. Substitution $x = t^2$

With $x=t^2$, $dx = 2t\,dt$, $x^{1/2}=t$, $1+x = 1+t^2$:
$$I = 4\int_0^\infty \frac{\ln(1+t^2)}{t(1+t^2)}\cdot 2t\,dt = 8\int_0^\infty \f
rac{\ln(1+t^2)}{1+t^2}\,dt.$$

### Step 3. Substitution $t = \tan\theta$

With $t=\tan\theta$, $dt = \sec^2\theta\,d\theta$, $1+t^2 = \sec^2\theta$, and $
\theta\in[0,\pi/2)$:
$$\int_0^\infty \frac{\ln(1+t^2)}{1+t^2}\,dt = \int_0^{\pi/2} \frac{\ln(\sec^2\t
heta)}{\sec^2\theta}\,\sec^2\theta\,d\theta = \int_0^{\pi/2}\ln(\sec^2\theta)\,d
\theta = -2\int_0^{\pi/2}\ln(\cos\theta)\,d\theta.$$

### Step 4. Classical integral

Using the standard result
$$\int_0^{\pi/2}\ln(\cos\theta)\,d\theta = -\frac{\pi}{2}\ln 2,$$
we obtain
$$\int_0^\infty \frac{\ln(1+t^2)}{1+t^2}\,dt = -2\left(-\frac{\pi}{2}\ln 2\right
) = \pi\ln 2.$$

### Step 5. Conclusion

$$I = 8\cdot \pi\ln 2 = \boxed{8\pi\ln 2}.$$
