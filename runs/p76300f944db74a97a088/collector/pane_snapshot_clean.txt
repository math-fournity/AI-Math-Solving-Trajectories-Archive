设三角形顶点为 $A$（起点）、$B$、$C$。定义 $p_n$ 为虫子在第 $n$ 步后位于 $A$ 的
概率，并设 $q_n = 1 - p_n$ 为其位于 $B$ 或 $C$ 的概率。

**转移规则。** 从 $A$ 出发，虫子必然移动到 $B$ 或 $C$，因此它无法留在 $A$。从 $B
$ 或 $C$ 出发，它以相等的概率 $\tfrac12$ 选择两个相邻顶点中的一个；其中一个是 $A
$。因此，在给定第 $n$ 步位置的情况下，第 $n+1$ 步到达 $A$ 的概率为：

$$p_{n+1} = \tfrac12\,q_n = \tfrac12(1-p_n), \qquad p_1 = 0.$$

**求解递推关系。** 设 $p^\ast$ 为不动点：$p^\ast = \tfrac12(1-p^\ast)$，得 $p^\a
st = \tfrac13$。令 $a_n = p_n - \tfrac13$，则

$$a_{n+1} = p_{n+1} - \tfrac13 = \tfrac12(1-p_n) - \tfrac13 = -\tfrac12\!\left(p
_n - \tfrac13\right) = -\tfrac12\,a_n.$$

因此 $a_n = \left(-\tfrac12\right)^{n-1} a_1 = \left(-\tfrac12\right)^{n-1}\!\le
ft(0 - \tfrac13\right) = -\tfrac13\left(-\tfrac12\right)^{n-1}$，且

$$p_n = \tfrac13\!\left[1 - \left(-\tfrac12\right)^{n-1}\right].$$

**计算 $p_{10}$。** 由于 $n-1 = 9$ 为奇数，$\left(-\tfrac12\right)^9 = -\tfrac{1

$$p_{10} = \tfrac13\!\left(1 + \tfrac{1}{512}\right) = \tfrac13\cdot\tfrac{513}{
512} = \tfrac{513}{1536} = \tfrac{171}{512}.$$
