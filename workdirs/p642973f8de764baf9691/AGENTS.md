# Problem

In a remote digital archive, there are two primary data servers: Server A and Server B. At the start of the simulation, Server B is completely empty, while Server A contains 29 unique, encrypted data files. 

An automated security protocol begins transferring these files between the servers. The protocol must follow these strict rules:
1. The process starts by selecting a set of one or more files from the current source (Server A) and moving them to the destination (Server B).
2. For every subsequent move, the protocol alternates the direction of transfer: the next move must select one or more files from the server that just received the previous batch and transfer them back to the other server.
3. To prevent system loops, the protocol is programmed so that no specific subset of the 29 files can ever be chosen for a transfer more than once throughout the entire process.

Under these constraints, what is the maximum number of moves the protocol can perform before it is impossible to make another transfer?
