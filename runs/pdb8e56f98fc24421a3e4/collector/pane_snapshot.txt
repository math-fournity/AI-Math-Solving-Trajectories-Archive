## Proof

**Setup.** Let the side vectors of $ABCDEF$ be $\vec{u_1} = \vec{AB}, \vec{u_2}
= \vec{BC}, \ldots, \vec{u_6} = \vec{FA}$, with $\sum_{i=1}^6 \vec{u_i} = \vec{0
}$ (closure). The perimeter is $p = \sum_{i=1}^6 |\vec{u_i}|$.

**Step 1: Express the midpoint hexagon sides.** The midpoint hexagon $A_1B_1C_1D
_1E_1F_1$ has side vectors:
$$\vec{v_i} = \vec{A_iA_{i+1}} = \frac{\vec{u_i} + \vec{u_{i+1}}}{2}, \quad i =
1,\ldots,6 \pmod{6}.$$
So $p_1 = \sum_{i=1}^6 |\vec{v_i}| = \frac{1}{2}\sum_{i=1}^6 |\vec{u_i} + \vec{u
_{i+1}}|$.

**Step 2: The equiangular condition forces the midpoint hexagon to be regular.**
 Since all inner angles of $A_1B_1\cdots F_1$ equal $120°$ (sum $= 720°$, six eq
ual angles), each exterior angle is $60°$. Working in complex numbers, the side
vectors satisfy $\vec{v_i} = \ell_i \,\omega^{i-1} e^{i\theta_0}$ where $\omega
= e^{i\pi/3}$ and $\ell_i > 0$.

**Closure of $\vec{v_i}$** ($\sum \vec{v_i} = 0$, which is automatic since $\sum
 \vec{v_i} = \sum \vec{u_i} = 0$): factoring out $e^{i\theta_0}$, we need $\sum
\ell_i \omega^{i-1} = 0$. Using $\omega^3 = -1$, $\omega^4 = -\omega$, $\omega^5
 = -\omega^2$:
$$(\ell_1 - \ell_4) + (\ell_2 - \ell_5)\omega + (\ell_3 - \ell_6)\omega^2 = 0.$$
Since $1, \omega, \omega^2$ are linearly independent over $\mathbb{R}$: $\ell_1
= \ell_4$, $\ell_2 = \ell_5$, $\ell_3 = \ell_6$.

**Closure of $\vec{u_i}$** gives an additional constraint. Solving $\vec{u_i} +
\vec{u_{i+1}} = 2\vec{v_i}$ for $\vec{u_i}$ in terms of $\vec{u_1}$ and $\vec{v_
i}$, the consistency condition (that $\vec{u_6} + \vec{u_1} = 2\vec{v_6}$) requi
res:
$$\vec{v_1} + \vec{v_3} + \vec{v_5} = \vec{0}.$$
Substituting $\vec{v_i} = \ell_i \omega^{i-1} e^{i\theta_0}$ and using $\ell_5 =
 \ell_2$:
$$\ell_1 + \ell_3 \omega^2 + \ell_2 \omega^4 = 0.$$
With $\omega^2 = -\frac{1}{2} + \frac{\sqrt{3}}{2}i$ and $\omega^4 = -\frac{1}{2
} - \frac{\sqrt{3}}{2}i$:
- **Real part:** $\ell_1 - \frac{\ell_3}{2} - \frac{\ell_2}{2} = 0 \implies 2\el
l_1 = \ell_2 + \ell_3$
- **Imaginary part:** $\frac{\sqrt{3}}{2}(\ell_3 - \ell_2) = 0 \implies \ell_2 =
 \ell_3$

Therefore $\ell_1 = \ell_2 = \ell_3$, and with the earlier relations, **all six
$\ell_i$ are equal**. The midpoint hexagon is **regular** with side length $s$,
so $p_1 = 6s$.

**Step 3: Parametrize the original hexagon.** Set $s = 1$ and $\theta_0 = 0$ (WL
OG by scaling and rotation). Then $\vec{v_i} = \omega^{i-1}$ and $\vec{u_i} + \v
ec{u_{i+1}} = 2\omega^{i-1}$. Let $\vec{u_1} = z \in \mathbb{C}$ be a free param
eter. Solving:
$$\vec{u_1} = z, \quad \vec{u_2} = 2 - z, \quad \vec{u_3} = z - 1 + \sqrt{3}\,i,
$$
$$\vec{u_4} = -z, \quad \vec{u_5} = z - 2, \quad \vec{u_6} = -z + 1 - \sqrt{3}\,
i.$$

Key symmetry: $\vec{u_4} = -\vec{u_1}$, $\vec{u_5} = -\vec{u_2}$, $\vec{u_6} = -
\vec{u_3}$. Therefore:
$$p = 2\bigl(|z| + |2-z| + |z - 1 + \sqrt{3}\,i|\bigr), \qquad p_1 = 6.$$

**Step 4: Minimize $|z| + |2-z| + |z - 1 + \sqrt{3}\,i|$.** The three points $A
= 0$, $B = 2$, $C = 1 - \sqrt{3}\,i$ form an **equilateral triangle** with side
length $2$ (since $|AB| = |BC| = |CA| = 2$).

**Lower bound via rotation.** Rotate any point $P = z$ by $-60°$ (i.e., multiply
 by $\bar{\omega} = e^{-i\pi/3}$) around $A = 0$, obtaining $P' = z\bar{\omega}$
. Then:
- $|PA| = |PP'|$ (triangle $APP'$ is equilateral),
- $|PC| = |P'C'|$ where $C' = C\bar{\omega} = (1-\sqrt{3}\,i)(\frac{1}{2}-\frac{
\sqrt{3}}{2}i) = -1 - \sqrt{3}\,i$.

Therefore:
$$|PA| + |PC| = |PP'| + |P'C'| \geq |PC'| \quad \text{(triangle inequality)}.$$
$$|PA| + |PB| + |PC| \geq |PC'| + |PB| \geq |BC'| \quad \text{(triangle inequali
ty)}.$$

Compute $|BC'| = |2 - (-1 - \sqrt{3}\,i)| = |3 + \sqrt{3}\,i| = \sqrt{9 + 3} = 2
\sqrt{3}$.

Thus $|z| + |2-z| + |z - 1 + \sqrt{3}\,i| \geq 2\sqrt{3}$ for all $z \in \mathbb
{C}$.

**Equality holds** when $P, P', C'$ are collinear (with $P'$ between $P$ and $C'
$) and $B, P, C'$ are collinear (with $P$ between $B$ and $C'$). This occurs at
the **Fermat point** of the equilateral triangle, which is its centroid:
$$z = \frac{0 + 2 + (1 - \sqrt{3}\,i)}{3} = 1 - \frac{1}{\sqrt{3}}\,i.$$

**Step 5: Verify convexity at equality.** At $z = 1 - \frac{1}{\sqrt{3}}i$:
$$\vec{u_1} = 1 - \tfrac{1}{\sqrt{3}}i \;(\arg = -30°), \quad \vec{u_2} = 1 + \t
frac{1}{\sqrt{3}}i \;(\arg = 30°), \quad \vec{u_3} = \tfrac{2}{\sqrt{3}}i \;(\ar
g = 90°),$$
$$\vec{u_4} = -1 + \tfrac{1}{\sqrt{3}}i \;(\arg = 150°), \quad \vec{u_5} = -1 -
\tfrac{1}{\sqrt{3}}i \;(\arg = 210°), \quad \vec{u_6} = -\tfrac{2}{\sqrt{3}}i \;
(\arg = 270°).$$

The direction increases by exactly $60°$ at each step, so all exterior angles ar
e $60°$ and all interior angles are $120°$. The hexagon is convex (in fact, regu
lar with side $\frac{2}{\sqrt{3}}$). ✓

**Conclusion.** The minimum ratio is:
$$\frac{p}{p_1} = \frac{2 \cdot 2\sqrt{3}}{6} = \frac{2\sqrt{3}}{3} = \frac{2}{\
sqrt{3}}.$$

So $k = \frac{2\sqrt{3}}{3}$ and:
$$k^2 = \frac{4}{3}.$$
