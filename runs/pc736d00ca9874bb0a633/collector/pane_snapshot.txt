Looking at this problem, I need to determine whether the harmonic series can be
rearranged so that infinitely many of its partial sums are integers.

**Answer: Yes.**

## Proof

**Key Lemma.** *For any finite set $F \subset \mathbb{N}$ and any positive ratio
nal $r$, there exists a finite set $G \subset \mathbb{N} \setminus F$ such that
$\sum_{k \in G} \frac{1}{k} = r$.*

*Proof of Lemma.* Write $r = p/q$ in lowest terms. Choose a prime $P > \max(F)$
(if $F = \emptyset$, take any prime $P \geq 2$) with $P \nmid q$. Such a prime e
xists since there are infinitely many primes. Since $P > \max(F)$, every multipl
e of $P$ exceeds $\max(F)$, so no multiple of $P$ belongs to $F$.

Since $\gcd(P, q) = 1$ and $\gcd(p, q) = 1$, the fraction $pP/q$ is in lowest te
rms. By the **Egyptian fraction theorem** (Fibonacci, 1202), every positive rati
onal can be written as a finite sum of distinct unit fractions. Applying the gre
edy algorithm to $pP/q$, we obtain distinct positive integers $k_1, \ldots, k_m$
 with
$$\frac{pP}{q} = \sum_{i=1}^{m} \frac{1}{k_i}.$$

Set $G = \{k_1 P,\, k_2 P,\, \ldots,\, k_m P\}$. The elements are distinct (sinc
e the $k_i$ are distinct), and each satisfies $k_i P \geq P > \max(F)$, so $G \c
ap F = \emptyset$. Moreover,
$$\sum_{k \in G} \frac{1}{k} = \frac{1}{P}\sum_{i=1}^{m} \frac{1}{k_i} = \frac{1
}{P} \cdot \frac{pP}{q} = \frac{p}{q} = r. \qquad \square$$

*(For completeness, the greedy algorithm terminates because at each step the num
erator of the remainder strictly decreases: choosing $n = \lceil q/p \rceil$ giv
es remainder $(pn - q)/(qn)$ with $0 < pn - q < p$.)*

---

**Construction.** We build the rearrangement inductively in stages. Let $U_0 = \
emptyset$ (used denominators) and $S_0 = 0$ (running partial sum).

**Stage $j$** ($j = 1, 2, 3, \ldots$):
1. Let $n_j$ be the smallest positive integer not in $U_{j-1}$.
2. If $n_j = 1$: set $A_j = \{1\}$ (since $1/1 = 1$), $G_j = \emptyset$.
3. If $n_j \geq 2$: the value $r_j = 1 - \frac{1}{n_j}$ is a positive rational.
Apply the Lemma with $F = U_{j-1} \cup \{n_j\}$ and $r = r_j$ to obtain a finite
 set $G_j \subset \mathbb{N} \setminus (U_{j-1} \cup \{n_j\})$ with $\sum_{k \in
 G_j} \frac{1}{k} = 1 - \frac{1}{n_j}$.
4. Set $A_j = \{n_j\} \cup G_j$. Then $\sum_{k \in A_j} \frac{1}{k} = \frac{1}{n
_j} + \left(1 - \frac{1}{n_j}\right) = 1$.
5. Update $U_j = U_{j-1} \cup A_j$ and $S_j = S_{j-1} + 1 = j$.

The rearrangement lists all elements of $A_1$ (in any order), then all elements
of $A_2$, then $A_3$, and so on.

---

**Verification.**

*Valid rearrangement (partition of $\mathbb{N}$):* The sets $A_1, A_2, \ldots$ a
re pairwise disjoint by construction ($A_j \subset \mathbb{N} \setminus U_{j-1}$
, which excludes all earlier $A_i$). Every positive integer $n$ is eventually in
cluded: at each stage the smallest unused number is selected, so after finitely
many stages $n$ becomes the smallest unused and is placed into some $A_j$. Thus
$\{A_1, A_2, \ldots\}$ partitions $\mathbb{N}$, and every term $1/k$ appears exa
ctly once.

*Infinitely many integer partial sums:* After all elements of $A_1 \cup \cdots \
cup A_j$ have been listed, the partial sum equals
$$S_j = \sum_{i=1}^{j} \sum_{k \in A_i} \frac{1}{k} = \sum_{i=1}^{j} 1 = j \in \
mathbb{Z}.$$
This holds for every $j = 1, 2, 3, \ldots$, yielding infinitely many indices at
which the partial sum is an integer.

---

**Conclusion.** The harmonic series $\sum_{k=1}^{\infty} \frac{1}{k}$ can be rea
rranged so that its partial sums are integers for infinitely many terms. The con
struction partitions $\mathbb{N}$ into finite blocks $A_1, A_2, \ldots$, each su
mming (in reciprocals) to exactly $1$, using the Egyptian fraction theorem (via
a prime-avoidance trick) to ensure each block avoids all previously used denomin
ators while including the smallest unused one.
