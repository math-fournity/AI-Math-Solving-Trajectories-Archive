# Problem

In a remote digital landscape, there are 2017 unique data-processing nodes. Each node is programmed to monitor a specific "link" between two different server hubs. In this network, every possible pair of server hubs can be connected by at most one node, and no two nodes monitor the same pair of hubs.

For every server hub in the network, a "Maintenance Cost" is generated, which is exactly equal to the number of nodes currently monitoring that specific hub. 

For each of the 2017 nodes, the system provider must pay an "Operational Fee." This fee is calculated by looking at the two hubs connected by that node and selecting the lower of their two Maintenance Costs (if the costs are identical, either value is used).

Considering all possible configurations of server hubs and node assignments that satisfy these conditions, find the maximum possible total Operational Fee that the system provider might have to pay for all 2017 nodes combined.
