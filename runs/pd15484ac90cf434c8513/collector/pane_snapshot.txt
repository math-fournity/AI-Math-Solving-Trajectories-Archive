# Multipoint Iteration Method — Determining α and β for Maximal Order

## Setup and Error Analysis

Let $\xi$ be a simple root of $f$, so $f(\xi)=0$, $f'(\xi)\neq 0$. Set $e_k = x_
k - \xi$ and introduce normalized derivatives at $\xi$:

$$c = \frac{f''(\xi)}{f'(\xi)},\quad d = \frac{f'''(\xi)}{f'(\xi)},\quad e = \fr
ac{f^{(4)}(\xi)}{f'(\xi)}.$$

All Taylor expansions below are in powers of $e_k$.

### Step 1. Expand $f(x_k)/f'(x_k)$

$$f(x_k) = f'\Big(e_k + \tfrac{c}{2}e_k^2 + \tfrac{d}{6}e_k^3 + \cdots\Big),$$
$$f'(x_k) = f'\Big(1 + c\,e_k + \tfrac{d}{2}e_k^2 + \cdots\Big).$$

Dividing and inverting the denominator series:

$$\frac{f(x_k)}{f'(x_k)} = e_k - \frac{c}{2}e_k^2 + \Big(\frac{c^2}{2}-\frac{d}{
3}\Big)e_k^3 + O(e_k^4). \tag{1}$$

### Step 2. Expand $f'(y_k)$ where $y_k = x_k - \beta\, f(x_k)/f'(x_k)$

Using (1):

$$u := y_k - \xi = (1-\beta)e_k + \frac{\beta c}{2}e_k^2 - \beta\Big(\frac{c^2}{
2}-\frac{d}{3}\Big)e_k^3 + O(e_k^4).$$

Then

$$\frac{f'(y_k)}{f'} = 1 + c\,u + \frac{d}{2}u^2 + \frac{e}{6}u^3 + O(e_k^4).$$

Collecting powers of $e_k$:

$$\frac{f'(y_k)}{f'} = 1 + b_1 e_k + b_2 e_k^2 + b_3 e_k^3 + O(e_k^4),$$

with

$$b_1 = c(1-\beta),$$
$$b_2 = \frac{\beta c^2}{2} + \frac{d(1-\beta)^2}{2},$$
$$b_3 = -\frac{\beta c^3}{2} + cd\,\beta\!\left(\frac{5}{6}-\frac{\beta}{2}\righ
t) + \frac{e(1-\beta)^3}{6}.$$

### Step 3. Form $f(x_k)/f'(y_k) = \big(f(x_k)/f'\big)\big/\big(f'(y_k)/f'\big)$

Write $A = f(x_k)/f' = e_k + \frac{c}{2}e_k^2 + \frac{d}{6}e_k^3 + \cdots$ and $
B = f'(y_k)/f' = 1 + b_1 e_k + b_2 e_k^2 + b_3 e_k^3 + \cdots$. Then

$$\frac{A}{B} = A\Big(1 - b_1 e_k + (b_1^2 - b_2)e_k^2 + (-b_1^3 + 2b_1 b_2 - b_
3)e_k^3 + \cdots\Big).$$

Multiplying out:

$$\frac{f(x_k)}{f'(y_k)} = e_k + c\!\left(\beta - \tfrac{1}{2}\right)e_k^2 + \Bi
g[c^2\!\left(\beta^2 - 2\beta + \tfrac{1}{2}\right) + d\!\left(-\tfrac{1}{3} + \
beta - \tfrac{\beta^2}{2}\right)\Big]e_k^3 + O(e_k^4). \tag{2}$$

### Step 4. Error equation

Since $x_{k+1} = x_k - \alpha\, f(x_k)/f'(y_k)$, we have $e_{k+1} = e_k - \alpha
\cdot(2)$:

$$\boxed{e_{k+1} = (1-\alpha)\,e_k \;-\; \alpha\, c\!\left(\beta - \tfrac{1}{2}\
right)e_k^2 \;-\; \alpha\!\left[c^2\!\left(\beta^2 - 2\beta + \tfrac{1}{2}\right
) + d\!\left(-\tfrac{1}{3} + \beta - \tfrac{\beta^2}{2}\right)\right]e_k^3 + O(e
_k^4).} \tag{3}$$

## Determining the Parameters

**Order ≥ 2** requires the $e_k$ coefficient to vanish:

$$1 - \alpha = 0 \;\Longrightarrow\; \alpha = 1.$$

**Order ≥ 3** requires (with $\alpha = 1$) the $e_k^2$ coefficient to vanish:

$$-c\!\left(\beta - \tfrac{1}{2}\right) = 0.$$

Since $c = f''(\xi)/f'(\xi)$ is arbitrary (the method must work for *all* $f$ wi
th a simple root), we need

$$\beta - \tfrac{1}{2} = 0 \;\Longrightarrow\; \beta = \tfrac{1}{2}.$$

**Can we reach order 4?** With $\alpha = 1$, $\beta = \tfrac{1}{2}$, the $e_k^3$
 coefficient in (3) becomes

$$c^2\!\left(\tfrac{1}{4} - 1 + \tfrac{1}{2}\right) + d\!\left(-\tfrac{1}{3} + \
tfrac{1}{2} - \tfrac{1}{8}\right) = -\frac{c^2}{4} + \frac{d}{24} = \frac{1}{24}
\big(d - 6c^2\big).$$

Hence

$$e_{k+1} = \frac{1}{24}\big(6c^2 - d\big)\,e_k^3 + O(e_k^4) = \left[\frac{f''(\
xi)^2}{4\,f'(\xi)^2} - \frac{f'''(\xi)}{24\,f'(\xi)}\right]e_k^3 + O(e_k^4). \ta
g{4}$$

The coefficient $\frac{1}{24}(6c^2 - d)$ depends on $f$ through the two **indepe
ndent** quantities $c^2$ and $d$ (e.g., for $f(x)=x^2-1$ at $\xi=1$: $c=-1, d=0$
, giving $6c^2-d=6\neq 0$). Since both parameters $\alpha, \beta$ are already ex
hausted in killing the $e_k$ and $e_k^2$ terms, there is no remaining freedom to
 annihilate the $e_k^3$ coefficient for a general $f$. Therefore **order 4 is un
attainable**, and the maximal order is **3**.

## Conclusion

The optimal parameters are

$$\boxed{\alpha = 1,\qquad \beta = \tfrac{1}{2},}$$

yielding the third-order iteration

$$x_{k+1} = x_k - \frac{f(x_k)}{f'\!\left(x_k - \dfrac{f(x_k)}{2\,f'(x_k)}\right
)},$$

with error constant $\frac{1}{24}\!\left(6\!\left(\frac{f''(\xi)}{f'(\xi)}\right
)^{\!2} - \frac{f'''(\xi)}{f'(\xi)}\right)$, i.e. $e_{k+1} = O(e_k^3)$.
