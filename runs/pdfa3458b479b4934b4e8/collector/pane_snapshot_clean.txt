## Proof for finite $n$ ($2 \leq n < \omega$)

**Setup.** Let $2 \leq n < \omega$, $|F| \leq n$, $Q \subseteq \mathbb{P}$ an $n
$-linked subset (every subset of $Q$ of size $\leq n$ has a common lower bound i
n $\mathbb{P}$), and $\dot{a}$ a $\mathbb{P}$-name with $\Vdash \dot{a} \in F$.

**Proof by contradiction.** Suppose for every $c \in F$, there exists $p_c \in Q
$ with $p_c \Vdash \dot{a} \neq c$.

Consider the set $S = \{p_c : c \in F\} \subseteq Q$. Since $|S| \leq |F| \leq n
$ and $Q$ is $n$-linked, $S$ has a common lower bound: there exists $r \in \math
bb{P}$ with $r \leq p_c$ for all $c \in F$.

By **monotonicity of forcing** (if $p \Vdash \varphi$ and $q \leq p$, then $q \V
dash \varphi$), we have:
$$r \Vdash \dot{a} \neq c \quad \text{for all } c \in F,$$
hence $r \Vdash \dot{a} \notin F$.

But $\Vdash \dot{a} \in F$ means **every** condition forces $\dot{a} \in F$, so
in particular $r \Vdash \dot{a} \in F$.

This is a **contradiction**: no condition can force both $\dot{a} \in F$ and $\d
ot{a} \notin F$ (the forcing relation is consistent — no condition forces both $
\varphi$ and $\neg\varphi$, since any condition can be extended to a generic fil
ter satisfying exactly one truth value).

Therefore, there exists $c \in F$ such that for all $p \in Q$, $p \nVdash \dot{a
} \neq c$. $\square$

## Counterexample for $n = \omega$ (with $F$ infinite)

The ordering is: $(s_2, A_2) \leq (s_1, A_1)$ iff $s_1 \subseteq s_2$ and $A_1 \

The maximum element is $(\emptyset, \emptyset)$. The generic object is a functio

*$Q$ is $\omega$-linked:* Any finite subset $\{(\emptyset, \{c_1\}), \ldots, (\e

**Each $c \in F$ is ruled out by some $p \in Q$.** For any $c \in \omega$, the c

*Proof:* We must show $(\emptyset, \{c\}) \Vdash g(0) \neq c$, i.e., no extensio

**No $c$ survives.** For every $c \in F = \omega$, the condition $(\emptyset, \{
c\}) \in Q$ satisfies $(\emptyset, \{c\}) \Vdash \dot{a} \neq c$. Therefore, the

**Why the finite proof breaks down.** When $F = \omega$ is infinite, the set $\{
p_c : c \in F\} = Q$ is countably infinite. The $\omega$-linkedness of $Q$ only
guarantees common lower bounds for **finite** subsets, not for the entire counta
ble set. For each finite $F_0 \subseteq F$, the common lower bound $(\emptyset,
F_0)$ forces $\dot{a} \notin F_0$ but $\dot{a} \in F \setminus F_0$, which is co
nsistent since $F \setminus F_0 \neq \emptyset$. No contradiction arises from an
y finite approximation.
