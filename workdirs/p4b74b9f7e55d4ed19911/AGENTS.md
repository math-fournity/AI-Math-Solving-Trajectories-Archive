# Problem

In a vast digital archive, a librarian is auditing data packets labeled with identification numbers $n$, where $n$ is a positive integer such that $1 \leq n < 10100$.

The librarian uses two different compression algorithms to test the density of these packets. 
- The first algorithm, the "Down-Scale," calculates the value of exactly $100/101$ of the packet's ID number and then rounds the result down to the nearest whole integer.
- The second algorithm, the "Up-Scale," calculates the value of exactly $99/100$ of the packet's ID number and then rounds the result up to the nearest whole integer.

The librarian is interested in "Stable Packets," which are packets where the output of the Down-Scale algorithm is exactly equal to the output of the Up-Scale algorithm.

How many integers $n$ in the specified range qualify as Stable Packets?
