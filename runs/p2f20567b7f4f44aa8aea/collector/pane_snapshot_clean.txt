## Key Setup

Since 10 is a primitive root mod 2017, $\text{ord}_{2017}(10) = 2016$. By Fermat
: $10^{2016-n} \equiv 10^{-n} \pmod{2017}$, so:

$$a_n \equiv 10^n + 10^{-n} \pmod{2017}$$

Setting $x = 10^n$, we get $a_n = x + x^{-1}$. As $n$ ranges over $\{1, \dots, 1
007\}$, the values $a_n$ are all **distinct** (since $x \neq x^{-1}$ requires $x
 = \pm 1$, which needs $n \equiv 0$ or $1008 \pmod{2016}$, neither in range). Ea
ch valid $a_n$-value corresponds to exactly one index.

## Analyzing Each Set

**$S_1$:** $a_n \equiv 1 \Rightarrow x + x^{-1} = 1 \Rightarrow x^2 - x + 1 = 0
\Rightarrow x^3 = -1, x^6 = 1$ (primitive 6th root of unity).

$2016 \mid 6n \Rightarrow 336 \mid n$. Candidates: $n \in \{336, 672\}$.
- $n=336$: order $= 2016/336 = 6$ ✓ (primitive)
- $n=672$: order $= 2016/672 = 3$ ✗ (gives $a_n = -1$)

$$S_1 = \{336\}$$

**$S_2$:** $a_n^2 \equiv 2 \Rightarrow (x+x^{-1})^2 = 2 \Rightarrow x^2 + x^{-2}
 = 0 \Rightarrow x^4 = -1$ (primitive 8th root).

$2016 \mid 8n \Rightarrow 252 \mid n$. Candidates: $n \in \{252, 504, 756\}$.
- $n=252$: order $= 8$ ✓
- $n=504$: order $= 4$ ✗ ($x^4=1$, gives $a_n^2 = 0$)
- $n=756$: $\gcd(756,2016)=252$, order $= 8$ ✓

$$S_2 = \{252, 756\}$$

**$S_3$:** $a_n^3 - 3a_n \equiv 1$. Using $(x+x^{-1})^3 - 3(x+x^{-1}) = x^3 + x^
{-3}$, this becomes $x^3 + x^{-3} = 1$.

Let $y = x^3 = 10^{3n}$. Then $y + y^{-1} = 1$, so $y$ is a primitive 6th root:
$y \in \{10^{336}, 10^{1680}\}$.

- $3n \equiv 336 \pmod{2016} \Rightarrow n \equiv 112 \pmod{672}$: $n \in \{112,
 784\}$
- $3n \equiv 1680 \pmod{2016} \Rightarrow n \equiv 560 \pmod{672}$: $n \in \{560

All have $x \neq \pm 1$ and give distinct $a_n$-values (verified by checking $n
\not\equiv \pm m \pmod{2016}$).

$$S_3 = \{112, 560, 784\}$$

**$S_4$:** $a_n^3 + a_n^2 - 2a_n \equiv 1$, i.e., $t^3 + t^2 - 2t - 1 \equiv 0$
where $t = x + x^{-1}$.

Expanding: $t^3 + t^2 - 2t - 1 = x^3 + x^{-3} + x^2 + x^{-2} + x + x^{-1} + 1 =
\frac{(x^7-1)/(x-1)}{x^3} \cdot x^3$.

This equals zero iff $x^7 = 1, x \neq 1$ (primitive 7th root of unity).

$2016 \mid 7n$. Since $\gcd(7, 2016) = 7$, we need $288 \mid n$. Candidates: $n
\in \{288, 576, 864\}$.
- All have order $2016/288 = 7$ ✓ (primitive 7th roots, all distinct)

$$S_4 = \{288, 576, 864\}$$
