# Problem

In a remote sector of the grid-based metropolis of Deca-City, a real estate developer owns a square plot of land measuring 100 square blocks, arranged in a perfect $10 \times 10$ grid. 

The developer wishes to install "L-pavilions" to occupy space. Each pavilion is a rigid structure that covers exactly three grid squares: a $2 \times 2$ square area with one corner square removed. These pavilions can be rotated or flipped to fit any orientation, but they must align perfectly with the grid squares and cannot overlap one another or extend past the $10 \times 10$ boundary of the plot.

The developer's goal is to place these pavilions in a "maximally obstructive" layout. They want to use the fewest number of pavilions possible so that the remaining empty space on the grid contains no $2 \times 2$ area with one corner missing—meaning it is physically impossible to add even one more L-pavilion to the plot.

Determine the minimum number of L-pavilions required to achieve this state.
