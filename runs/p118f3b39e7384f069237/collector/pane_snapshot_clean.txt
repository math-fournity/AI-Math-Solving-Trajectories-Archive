# Proof

**Yes, the statement is true.** Every root of $g(t)=0$ is an eigenvalue of $A$ w
ith a corresponding eigenvector in $\operatorname{span}\{X, AX, \dots, A^{k-1}X\
}$.

---

## Setup and key observations

Since $k$ is the **least** positive integer such that $\{X, AX, \dots, A^k X\}$
is linearly dependent, the set $\{X, AX, \dots, A^{k-1}X\}$ is **linearly indepe
ndent**.

The given relation is
$$\sum_{i=1}^{k} c_i A^i X = 0, \qquad \text{i.e., } g(A)\,X = 0,$$
where $g(t) = \sum_{i=1}^{k} c_i\, t^i$.

**Claim:** $c_k \neq 0$. Indeed, if $c_k = 0$, then $\sum_{i=1}^{k-1} c_i A^i X
= 0$ is a nontrivial linear relation among $\{AX, \dots, A^{k-1}X\} \subseteq \{
X, \dots, A^{k-1}X\}$, contradicting independence. Hence $c_k \neq 0$, so $g$ is
 a nonzero polynomial of degree $k$.

Note that $g(t) = t\cdot h(t)$ where $h(t) = c_1 + c_2 t + \cdots + c_k t^{k-1}$
, so $t = 0$ is always a root of $g$.

---

## Main argument

Let $\lambda$ be any root of $g(t) = 0$. Factor
$$g(t) = (t - \lambda)\, q(t),$$
where $q(t)$ is a polynomial of degree $k - 1$ (and $q \not\equiv 0$ since $g \n
ot\equiv 0$).

Define the vector
$$v_\lambda := q(A)\,X.$$

**Step 1: $v_\lambda$ is an eigenvector of $A$ with eigenvalue $\lambda$.**

Since $g(A)\,X = 0$, we have
$$(A - \lambda I)\, v_\lambda = (A - \lambda I)\, q(A)\, X = g(A)\, X = 0,$$
so $A\, v_\lambda = \lambda\, v_\lambda$.

**Step 2: $v_\lambda \neq 0$.**

Since $\deg q \leq k - 1$, the vector $v_\lambda = q(A)\,X$ is a linear combinat
ion of $\{X, AX, \dots, A^{k-1}X\}$. If $v_\lambda = 0$, this would give a nontr
ivial linear relation among the independent set $\{X, AX, \dots, A^{k-1}X\}$ (no
ntrivial because $q \not\equiv 0$). This is a contradiction. Hence $v_\lambda \n
eq 0$.

**Step 3: $v_\lambda \in \operatorname{span}\{X, AX, \dots, A^{k-1}X\}$.**

This is immediate from $\deg q \leq k - 1$.

---

## Verification for $\lambda = 0$

When $\lambda = 0$, we have $q(t) = g(t)/t = h(t) = c_1 + c_2 t + \cdots + c_k t
^{k-1}$, and
$$v_0 = h(A)\,X = c_1 X + c_2 AX + \cdots + c_k A^{k-1}X.$$
Then $A\, v_0 = \sum_{i=1}^k c_i A^i X = 0 = 0 \cdot v_0$, confirming $v_0$ is a
n eigenvector for eigenvalue $0$. Since $c_k \neq 0$ and $\{X, \dots, A^{k-1}X\}
$ is independent, $v_0 \neq 0$.

---

## Conclusion

For **every** root $\lambda$ of $g(t) = 0$, the vector $v_\lambda = q(A)\,X$ (wh
ere $g(t) = (t-\lambda)\,q(t)$) is a **nonzero** eigenvector of $A$ with eigenva
lue $\lambda$, and $v_\lambda$ lies in $\operatorname{span}\{X, AX, \dots, A^{k-
1}X\}$.

Therefore, **yes**, each root of $g(t) = 0$ is an eigenvalue of $A$ correspondin
g to an eigenvector in the span of $\{X, AX, \dots, A^{k-1}X\}$.
