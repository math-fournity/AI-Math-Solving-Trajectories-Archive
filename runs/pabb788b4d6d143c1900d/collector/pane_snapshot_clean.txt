## Proof

Let $U = H_n(\mathbb{F}_p)$ denote the group of upper unitriangular $n\times n$
matrices over $\mathbb{F}_p$. A general element is
$$X = I + \sum_{1\le i<j\le n} x_{ij}\,E_{ij}, \qquad x_{ij}\in\mathbb{F}_p,$$
where $E_{ij}$ is the matrix unit. The group $U$ is generated by the elementary
unipotent matrices $I+aE_{ij}$ ($i<j$, $a\in\mathbb{F}_p$), so $X$ is central if
f it commutes with every $I+aE_{ij}$, i.e. iff
$$E_{ij}X = XE_{ij} \quad\text{for all } 1\le i<j\le n. \tag{$\ast$}$$

**Computing both sides.** Using $E_{ij}E_{kl}=\delta_{jk}\,E_{il}$:

$$E_{ij}X = E_{ij} + \sum_{l:\,j<l} x_{jl}\,E_{il}, \qquad XE_{ij} = E_{ij} + \s
um_{k:\,k<i} x_{ki}\,E_{kj}.$$

Thus $(\ast)$ becomes
$$\sum_{l>j} x_{jl}\,E_{il} \;=\; \sum_{k<i} x_{ki}\,E_{kj} \qquad\text{for all
} i<j. \tag{$\ast\ast$}$$

**Key observation.** On the left, every matrix unit $E_{il}$ has column index $l
>j$. On the right, every matrix unit $E_{kj}$ has column index $j$. Since $l>j$
on the left and $=j$ on the right, no matrix unit appearing on the left can equa
l one appearing on the right. By linear independence of the $E_{ab}$, both sides
 of $(\ast\ast)$ must be **zero**:

$$\boxed{x_{jl}=0 \text{ for all } l>j,\ j\ge 2} \qquad\text{and}\qquad \boxed{x
_{ki}=0 \text{ for all } k<i,\ i\le n-1}.$$

(The first applies for every $j\ge 2$ since some $i<j$ exists; the second for ev
ery $i\le n-1$ since some $j>i$ exists.)

**First condition** ($x_{jl}=0$ for $j\ge 2$, $l>j$): all entries not in **row 1
** must vanish, so the only possibly nonzero entries lie in the first row: $x_{1
l}$, $2\le l\le n$.

**Second condition** ($x_{ki}=0$ for $i\le n-1$, $k<i$): all entries not in **co
lumn $n$** must vanish, so the only possibly nonzero entries lie in the last col
umn: $x_{kn}$, $1\le k\le n-1$.

**Intersection.** An entry must be in *both* row 1 and column $n$ to survive bot
h conditions. The unique such entry is $x_{1n}$. Hence
$$Z(U) = \bigl\{\,I + a\,E_{1n} : a\in\mathbb{F}_p\,\bigr\}.$$

**Group structure.** $(I+aE_{1n})(I+bE_{1n}) = I+(a+b)E_{1n}$ since $E_{1n}^2=0$
 (as $n\ne 1$). Thus $Z(U)\cong(\mathbb{F}_p,+)\cong\mathbb{F}_p$.

**Consistency check.** For $n=3$, $Z(H_3(\mathbb{F}_p))=\{I+aE_{13}\}\cong\mathb
b{F}_p$, matching the given. For $n=2$, $U_2$ is abelian and equals $\{I+aE_{12}
\}\cong\mathbb{F}_p$, also consistent (the $(1,2)$ entry is the $(1,n)$ entry).

**Conclusion.** For every $n\ge 2$,
$$\boxed{Z\bigl(H_n(\mathbb{F}_p)\bigr) \;=\; \bigl\{\,I_n + a\,E_{1n} : a\in\ma
thbb{F}_p\,\bigr\} \;\cong\; (\mathbb{F}_p,+) \;\cong\; \mathbb{F}_p.}$$

The center consists precisely of the scalar multiples of the single elementary m
atrix $E_{1n}$ added to the identity — the "top-right corner" subgroup — and is
isomorphic to the additive group of $\mathbb{F}_p$ for all $n\ge 2$.
