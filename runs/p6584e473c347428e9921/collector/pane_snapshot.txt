### Setup

We seek the largest integer $V$ that **cannot** be written as $V = 2008x + 2009y
 + 2010z$ with $x,y,z \geq 1$.

Substitute $x = a+1,\ y = b+1,\ z = c+1$ with $a,b,c \geq 0$:

$$V = 2008a + 2009b + 2010c + (2008+2009+2010) = 2008a + 2009b + 2010c + 6027.$$

So $V$ is deliverable **iff** $m := V - 6027$ is representable as $2008a + 2009b
 + 2010c$ with $a,b,c \geq 0$. The problem reduces to finding the largest non-re
presentable $m$, then adding $6027$.

### Characterizing representable $m$

Since $2009 = 2008+1$ and $2010 = 2008+2$:

$$m = 2008a + 2009b + 2010c = 2008(a+b+c) + (b + 2c).$$

Let $s = a+b+c \geq 0$ and $r = b + 2c$. The constraint $a = s - b - c \geq 0$ g
ives $b + c \leq s$, with $b, c \geq 0$.

For fixed $s$, $r = b + 2c$ ranges over the union of intervals $\bigcup_{c=0}^{s
} [2c,\ s+c]$:
- $c=0$: $[0,\ s]$
- $c=1$: $[2,\ s+1]$
- $c=k$: $[2k,\ s+k]$

For $s \geq 1$, consecutive intervals overlap (since $2(c+1) \leq s + c \iff c \
leq s-2$, and the gap is bridged), giving the full range $r \in [0,\ 2s]$. (Dire
ct check: $s=1 \Rightarrow \{0,1,2\}=[0,2]$; $s=2 \Rightarrow [0,4]$; etc.)

Therefore the representable set is:
$$\{0\} \ \cup\ \bigcup_{s \geq 1} \big[2008s,\ 2010s\big].$$

### Finding the gaps

A gap exists between $[2008s,\ 2010s]$ and $[2008(s+1),\ 2010(s+1)]$ iff
$$2010s + 1 \leq 2008(s+1) - 1 \iff 2010s + 1 \leq 2008s + 2007 \iff 2s \leq 200
6 \iff s \leq 1003.$$

The gap at parameter $s$ is the integer interval $\big[2010s+1,\ 2008s+2007\big]
$, and these gaps shift upward as $s$ grows, so the **largest** non-representabl
e $m$ lies in the **last** gap, at $s = 1003$:

$$m_{\max} = 2008 \cdot 1003 + 2007 = 2\,014\,024 + 2\,007 = 2\,016\,031.$$

**Verification that $m = 2\,016\,031$ is not representable:** With $s = 1003$, w
e need $r = 2\,016\,031 - 2\,014\,024 = 2\,007$, but $r \leq 2s = 2\,006$ — exce
eds the bound. With $s = 1004$, $2008 \cdot 1004 = 2\,016\,032 > 2\,016\,031$, t
oo large. So $m = 2\,016\,031$ is not representable. ✓

**Verification that $m = 2\,016\,032$ is representable:** $2008 \cdot 1004 = 2\,
016\,032$, $r = 0 \leq 2\cdot 1004$. ✓

For all $s \geq 1004$, the intervals $[2008s, 2010s]$ are contiguous ($2010s \ge
q 2008(s+1)-1$), so every $m \geq 2\,016\,032$ is representable. Thus $2\,016\,0
31$ is indeed the largest non-representable $m$.

### Final answer

The largest non-deliverable volume is
$$V = m_{\max} + 6027 = 2\,016\,031 + 6\,027 = \boxed{2\,022\,058}.$$
