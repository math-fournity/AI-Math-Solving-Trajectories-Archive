# Problem

In a specialized digital telecommunications network, engineers use a coordination protocol called "Phase-M." This protocol governs the connections within a cluster of $N$ server nodes. Every possible pair of nodes is linked by a communication channel, and each channel is assigned a specific frequency band from a set of exactly $M$ available bands (where $M \geq 3$ is a natural number).

A cluster configuration is classified as "Interference-Free" if it satisfies the following security constraint: for any three distinct server nodes within the cluster, the three communication channels connecting them must either all use the same frequency band or all use three different frequency bands. It is strictly forbidden for exactly two of the three channels to share the same frequency.

Let $N(M)$ represent the maximum number of server nodes that can be integrated into a single Interference-Free cluster using exactly $M$ frequency bands.

Given that 11 is a prime number, determine the value of $N(12)$.
