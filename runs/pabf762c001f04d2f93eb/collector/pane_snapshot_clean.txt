Answer: Yes, such a partition exists.

Proof.

We construct a partition of $\mathbb{R}$ into uncountably many uncountable sets.

Step 1: A bijection between $\mathbb{R}$ and $\mathbb{R}^2$.

It is a standard fact that $|\mathbb{R}| = |\mathbb{R}^2|$. Concretely, there
exists a bijection $f : \mathbb{R} \to \mathbb{R} \times \mathbb{R}$. For
completeness, here is one way to see it:

  • The map $g : (0,1) \to \mathbb{R}$ given by $g(x) = \tan(\pi(x - \tfrac{1}
  {2}))$ is a bijection, so $|\mathbb{R}| = |(0,1)|$.
  • Interleaving decimal (or binary) expansions gives a bijection between
  $(0,1)$ and $(0,1)^2$. Specifically, writing $x \in (0,1)$ in binary expansion
  $x = 0.x_1 x_2 x_3 \dots$ (choosing the non-terminating expansion to avoid
  ambiguity), the map $$h(x) = \big(0.x_1 x_3 x_5 \dots,; 0.x_2 x_4 x_6
  \dots\big)$$ is a bijection $(0,1) \to (0,1) \times (0,1)$.
  • Composing with $g$ on each coordinate yields a bijection $\mathbb{R} \to
  \mathbb{R} \times \mathbb{R}$.

Let $f : \mathbb{R} \to \mathbb{R} \times \mathbb{R}$ be such a bijection.

Step 2: The vertical-line partition of $\mathbb{R}^2$.

For each $a \in \mathbb{R}$, define the vertical line $$L_a = {a} \times
\mathbb{R} = {(a, y) : y \in \mathbb{R}}.$$

The family ${L_a : a \in \mathbb{R}}$ has the following properties:

  • Pairwise disjoint: If $a \neq b$, then $L_a \cap L_b = \emptyset$, since no
  point has two different first coordinates.
  • Covers $\mathbb{R}^2$: Every $(x, y) \in \mathbb{R}^2$ belongs to $L_x$.
  • Uncountably many parts: The index set is $\mathbb{R}$, which is uncountable.
  • Each part is uncountable: Each $L_a = {a} \times \mathbb{R}$ is in bijection
  with $\mathbb{R}$ (via $y \mapsto (a, y)$), hence uncountable.

So ${L_a : a \in \mathbb{R}}$ is a partition of $\mathbb{R}^2$ into uncountably
many uncountable sets.

Step 3: Pull back to $\mathbb{R}$.

For each $a \in \mathbb{R}$, define $$S_a = f^{-1}(L_a) = {x \in \mathbb{R} :
f(x) \in L_a} = {x \in \mathbb{R} : \pi_1(f(x)) = a},$$ where $\pi_1 :
\mathbb{R}^2 \to \mathbb{R}$ is projection onto the first coordinate.

We verify that ${S_a : a \in \mathbb{R}}$ is a partition of $\mathbb{R}$ into
uncountably many uncountable sets:

  • Pairwise disjoint: If $a \neq b$, then $L_a \cap L_b = \emptyset$, so
  $f^{-1}(L_a) \cap f^{-1}(L_b) = f^{-1}(L_a \cap L_b) = \emptyset$. Thus $S_a
  \cap S_b = \emptyset$.
  • Covers $\mathbb{R}$: Since $\bigcup_{a \in \mathbb{R}} L_a = \mathbb{R}^2$
  and $f$ is surjective onto $\mathbb{R}^2$, $$\bigcup_{a \in \mathbb{R}} S_a =
  \bigcup_{a \in \mathbb{R}} f^{-1}(L_a) = f^{-1}!\left(\bigcup_{a \in
  \mathbb{R}} L_a\right) = f^{-1}(\mathbb{R}^2) = \mathbb{R}.$$
  • Uncountably many parts: The index set is $\mathbb{R}$, which is uncountable.
  • Each part is uncountable: The restriction $f|_{S_a} : S_a \to L_a$ is a
  bijection (since $f$ is a bijection and $S_a = f^{-1}(L_a)$). Since $L_a$ is
  uncountable, $S_a$ is uncountable.

Conclusion.

The family ${S_a : a \in \mathbb{R}}$ is a partition of $\mathbb{R}$ into
uncountably many pairwise-disjoint uncountable sets. Therefore, such a partition
exists. $\blacksquare$
