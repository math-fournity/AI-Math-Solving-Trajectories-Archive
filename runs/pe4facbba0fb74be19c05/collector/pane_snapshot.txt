# Solution

We determine all values of $z$ (complex) for which $\varphi(t) = \exp(-2z\sin^2
t)$ is the characteristic function of a discrete random variable.

## Step 1: Reduction via Fourier expansion

Using the identity $\sin^2 t = \frac{1-\cos 2t}{2}$:

$$-2z\sin^2 t = -z(1-\cos 2t) = -z + z\cos 2t,$$

so

$$\varphi(t) = e^{-z}\, e^{z\cos 2t}.$$

By the Jacobi–Anger expansion for modified Bessel functions,

$$e^{z\cos\theta} = \sum_{n=-\infty}^{\infty} I_n(z)\, e^{in\theta},$$

where $I_n(z)$ is the modified Bessel function of the first kind. Setting $\thet
a = 2t$:

$$\varphi(t) = e^{-z}\sum_{n=-\infty}^{\infty} I_n(z)\, e^{2int} = \sum_{n=-\inf
ty}^{\infty} \underbrace{e^{-z}I_n(z)}_{p_n}\, e^{i(2n)t}.$$

This is a Fourier series in $e^{2int}$. If $\varphi$ is the characteristic funct
ion of a discrete random variable $X$, then $X$ takes values $\{2n : n\in\mathbb
{Z}\}$ with probabilities $p_n = e^{-z}I_n(z)$.

## Step 2: Necessary conditions

**Normalization.** Using the generating-function identity $\sum_{n=-\infty}^{\in
fty} I_n(z) = e^z$ (valid for all finite $z$), we get $\sum_n p_n = e^{-z}\cdot
e^z = 1$. ✓ (holds for every $z$).

**Conjugate symmetry (forces $z$ real).** A characteristic function of a real-va
lued random variable must satisfy $\varphi(-t) = \overline{\varphi(t)}$. Since $
\sin^2(-t)=\sin^2 t$,

$$\varphi(-t) = \exp(-2z\sin^2 t) = \varphi(t).$$

Hence $\varphi(t) = \overline{\varphi(t)}$, i.e., $\varphi(t)\in\mathbb{R}$ for
all $t$. Write $z = a+bi$. Then

$$-2z\sin^2 t = -2a\sin^2 t - 2bi\sin^2 t.$$

For $e^{-2z\sin^2 t}$ to be real for **all** $t$, we need $\operatorname{Im}(-2z
\sin^2 t) = -2b\sin^2 t \in \pi\mathbb{Z}$ for every $t$. Since $\sin^2 t$ varie
s continuously over $[0,1]$, this forces $b = 0$. **Therefore $z$ must be real.*
*

**Non-negativity of probabilities.** We need $p_n = e^{-z}I_n(z) \ge 0$ for ever
y $n\in\mathbb{Z}$.

## Step 3: Analyzing $I_n(z)$ for real $z$

Recall $I_{-n}(z) = I_n(z)$ for integer $n$, and for $n\ge 0$:

$$I_n(z) = \sum_{k=0}^{\infty} \frac{1}{k!\,(k+n)!}\left(\frac{z}{2}\right)^{2k+
n}.$$

**Case $z > 0$:** Every term in the series is strictly positive, so $I_n(z) > 0$
 for all $n$. Also $e^{-z} > 0$. Thus $p_n = e^{-z}I_n(z) > 0$ for all $n$. ✓

**Case $z = 0$:** $I_0(0)=1$ and $I_n(0)=0$ for $n\neq 0$, giving $p_0 = 1$ and
$p_n=0$ otherwise — the degenerate distribution at $0$. ✓

**Case $z < 0$:** Using $I_n(-x) = (-1)^n I_n(x)$ for integer $n$ and real $x>0$
, we get $I_n(z) = (-1)^n I_n(|z|)$. For odd $n$, $I_n(z) < 0$ while $e^{-z} = e
^{|z|} > 0$, so $p_n < 0$. ✗

## Step 4: Sufficiency for $z \ge 0$

For every real $z \ge 0$, the coefficients $p_n = e^{-z}I_n(z)$ are non-negative
 (strictly positive for $z>0$) and sum to $1$. Hence

$$\varphi(t) = \sum_{n=-\infty}^{\infty} p_n\, e^{i(2n)t}$$

is the characteristic function of the discrete random variable $X$ with $\Pr(X =
 2n) = e^{-z}I_n(z)$. (For $z>0$ this is the **Skellam distribution** with equal
 parameters — the distribution of $N_1 - N_2$ where $N_1, N_2$ are independent $
\operatorname{Poisson}(z)$.)

## Conclusion

The function $\exp(-2z\sin^2 t)$ is the characteristic function of a discrete ra
ndom variable **if and only if $z$ is a non-negative real number**, i.e.,

$$\boxed{z \in \mathbb{R},\quad z \ge 0.}$$
