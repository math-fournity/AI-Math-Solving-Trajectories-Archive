We solve the wave equation on the half-line $x>0$ with homogeneous initial data
and a Neumann boundary condition.

### General form

The general solution of $u_{tt} - c^2 u_{xx} = 0$ is
$$u(x,t) = F(x - ct) + G(x + ct),$$
for arbitrary (sufficiently smooth) functions $F$ and $G$.

### Applying the initial data ($t = 0$, $x > 0$)

From $u(x,0) = 0$:
$$F(x) + G(x) = 0 \quad (x > 0), \tag{1}$$
so $G(x) = -F(x)$ for $x > 0$.

From $u_t(x,0) = 0$:
$$-cF'(x) + cG'(x) = 0 \quad (x > 0). \tag{2}$$
Using (1), $G' = -F'$, so (2) gives $-F' - F' = 0$, i.e. $F'(x) = 0$ for $x > 0$
. Hence $F$ (and $G$) are constant on $(0,\infty)$. By (1) we may take this cons
tant to be $0$:
$$F(s) = 0,\quad G(s) = 0 \qquad (s > 0). \tag{3}$$

Consequently, in the region $x > ct$ (where $x - ct > 0$ and $x + ct > 0$),
$$u(x,t) = F(x-ct) + G(x+ct) = 0 + 0 = 0. \tag{4}$$

### Determining $F$ on negative arguments from the boundary condition

The boundary condition $u_x(0,t) = h(t)$ gives
$$u_x(0,t) = F'(-ct) + G'(ct) = h(t).$$
By (3), $G'(ct) = 0$, so
$$F'(-ct) = h(t).$$
Setting $s = -ct$ (so $t = -s/c$), we obtain
$$F'(s) = h\!\left(-\frac{s}{c}\right), \qquad s < 0. \tag{5}$$

Integrating from $0$ (where $F(0) = 0$ by continuity from (3)):
$$F(s) = \int_0^{s} h\!\left(-\frac{\sigma}{c}\right) d\sigma, \qquad s < 0. \ta
g{6}$$

### The solution in the region $0 < x < ct$

Here $x - ct < 0$ and $x + ct > 0$, so by (3) $G(x+ct) = 0$ and
$$u(x,t) = F(x - ct) = \int_0^{x - ct} h\!\left(-\frac{\sigma}{c}\right) d\sigma
.$$

Substituting $\tau = -\sigma/c$, so $d\sigma = -c\,d\tau$; when $\sigma = 0$, $\
tau = 0$; when $\sigma = x - ct$, $\tau = (ct - x)/c = t - x/c$:
$$u(x,t) = \int_0^{t - x/c} h(\tau)\,(-c)\,d\tau = -c\int_0^{t - x/c} h(\tau)\,d
\tau. \tag{7}$$

### Verification

- **PDE:** In $0 < x < ct$, $u = -c\int_0^{t-x/c} h(\tau)\,d\tau$. Then $u_x = -
c\cdot h(t - x/c)\cdot(-1/c) = h(t - x/c)$ and $u_{xx} = h'(t - x/c)\cdot(-1/c)$
. Also $u_t = -c\,h(t - x/c)\cdot 1$ and $u_{tt} = -c\,h'(t - x/c)$. Thus $u_{tt
} - c^2 u_{xx} = -c\,h' - c^2(-1/c)h' = -c\,h' + c\,h' = 0$. ✓ In $x > ct$, $u \
equiv 0$ satisfies the PDE trivially. ✓

- **Initial condition $u(x,0) = 0$:** At $t = 0$ and $x > 0$, we have $x > 0 = c
\cdot 0$, so $x > ct$ and $u = 0$. ✓

- **Initial condition $u_t(x,0) = 0$:** Same region, $u \equiv 0$ locally. ✓

- **Boundary condition $u_x(0,t) = h(t)$:** From (7), $u_x(x,t) = h(t - x/c)$, s
o $u_x(0,t) = h(t)$. ✓

- **Continuity across $x = ct$:** At $x = ct$, (7) gives $u = -c\int_0^0 h = 0$,
 matching (4). ✓

### Final answer

$$\boxed{u(x,t) = \begin{cases} 0, & x \geq ct, \\[6pt] -c\displaystyle\int_0^{\
,t - x/c} h(\tau)\,d\tau, & 0 \leq x < ct. \end{cases}}$$
