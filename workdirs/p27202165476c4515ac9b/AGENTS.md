# Problem

In a specialized logistics hub, a manager is assigning unique identification numbers to 15 different delivery drones. Each drone is indexed by its serial number $k$, where $k$ ranges from 1 to 15.

The manager must follow two strict protocols:
1. Each drone's assigned ID number $a_k$ must be a multiple of its own serial number $k$.
2. All 15 ID numbers must be distinct from one another.

The security system at the hub only allows ID numbers to be chosen from a specific range of integers starting from 16 up to a maximum value $n$ (inclusive). That is, each $a_k$ must satisfy $16 \leq a_k \leq n$.

What is the smallest possible value of $n$ that allows the manager to assign these 15 distinct ID numbers while satisfying all protocols?
