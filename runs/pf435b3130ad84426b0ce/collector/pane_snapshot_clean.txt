## Proof

We work in units where $\hbar = 1$. The operators $X_+, X_-, X_3$ form the compo
nents of a rank-1 spherical tensor (a vector operator), satisfying the standard
$\mathfrak{su}(2)$ commutation relations:

$$[X_3, X_+] = X_+, \qquad [X_3, X_-] = -X_-, \qquad [X_+, X_-] = 2X_3.$$

A rotation about the 3-axis by angle $\theta$ is generated by $X_3$ via the unit
ary operator

$$R_3(\theta) = e^{-i\theta X_3}.$$

The transformation of an operator $X_+$ under this rotation is given by the simi
larity transformation

$$X_+' = R_3(\theta)\, X_+\, R_3(\theta)^{-1} = e^{-i\theta X_3}\, X_+\, e^{i\th
eta X_3}.$$

To evaluate this, we use the **Hadamard lemma** (a consequence of the Baker–Camp
bell–Hausdorff expansion):

$$e^{A}\, B\, e^{-A} = \sum_{n=0}^{\infty} \frac{1}{n!}\,[A, B]_n,$$

where the iterated commutator is defined recursively by $[A,B]_0 = B$ and $[A,B]
_n = [A, [A, B]_{n-1}]$.

Setting $A = -i\theta X_3$ and $B = X_+$, we obtain

$$e^{-i\theta X_3}\, X_+\, e^{i\theta X_3} = \sum_{n=0}^{\infty} \frac{1}{n!}\,[
-i\theta X_3,\, X_+]_n = \sum_{n=0}^{\infty} \frac{(-i\theta)^n}{n!}\,[X_3, X_+]
_n.$$

Now we compute the iterated commutators. From $[X_3, X_+] = X_+$:

$$[X_3, X_+]_0 = X_+,$$
$$[X_3, X_+]_1 = [X_3, X_+] = X_+,$$
$$[X_3, X_+]_2 = [X_3, X_+] = X_+,$$

and by induction,

$$[X_3, X_+]_n = X_+ \qquad \text{for all } n \geq 0.$$

This is the key simplification: because $X_+$ is an eigenoperator of $\operatorn
ame{ad}_{X_3}$ with eigenvalue $+1$, every iterated commutator returns $X_+$ its
elf.

Substituting back:

$$X_+' = \sum_{n=0}^{\infty} \frac{(-i\theta)^n}{n!}\, X_+ = X_+ \sum_{n=0}^{\in
fty} \frac{(-i\theta)^n}{n!} = e^{-i\theta}\, X_+.$$

Therefore, the transformation of $X_+$ under the rotation $R_3(\theta)$ is:

$$\boxed{R_3(\theta)\, X_+\, R_3(\theta)^{-1} = e^{-i\theta X_3}\, X_+\, e^{i\th
eta X_3} = e^{-i\theta}\, X_+.}$$

**Interpretation.** The result $X_+' = e^{-i\theta} X_+$ shows that $X_+$ transf
orms as the $q = +1$ component of a rank-1 spherical tensor under rotations abou
t the 3-axis. More generally, for a rank-$k$ spherical tensor component $T^{(k)}
_q$ satisfying $[J_3, T^{(k)}_q] = q\, T^{(k)}_q$, the same calculation gives

$$e^{-i\theta J_3}\, T^{(k)}_q\, e^{i\theta J_3} = e^{-iq\theta}\, T^{(k)}_q,$$

which is the defining transformation law of spherical tensor operators. Here $X_
+$ corresponds to $q = +1$, confirming the phase factor $e^{-i\theta}$.
