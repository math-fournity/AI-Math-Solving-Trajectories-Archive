Looking at this problem, I need to find all positive integers $n$ where $\frac{2
n}{\varphi(n)}$ is an integer, then sum $\frac{1}{n}$ over them.

## Setting Up the Condition

Using $\varphi(n) = n\prod_{p\mid n}\frac{p-1}{p}$, we get $\frac{2n}{\varphi(n)
} = 2\prod_{p\mid n}\frac{p}{p-1}$.

This depends only on the **set of prime divisors** $P$ of $n$, not their exponen
ts. So I need:
$$\prod_{p\in P}(p-1) \;\Big|\; 2\prod_{p\in P} p$$

## Deriving the Constraints

Since $\prod p$ is squarefree (distinct primes), for each **odd** prime $q$:
- $v_q\!\left(\sum_{p\in P}(p-1)\right) \leq 1$ (at most one factor of $q$ in th
e denominator)
- If $q \mid (p-1)$ for some $p\in P$, then $q \in P$ (closure condition)

For the **power of 2**: $v_2(\prod(p-1)) \leq v_2(2\prod p)$.

## Case Analysis

**Case 1: $2 \notin P$.** Then $v_2(2\prod p) = 1$, but each odd $p$ contributes
 $v_2(p-1)\geq 1$, so at most one odd prime. For $P=\{p\}$: need $(p-1)\mid 2p$,
 so $(p-1)\mid 2$, giving $p=3$. Plus $P=\emptyset$ ($n=1$).

**Case 2: $2 \in P$.** Let $Q = P\setminus\{2\}$. Need $\sum_{p\in Q} v_2(p-1) \
leq 2$, so $|Q|\leq 2$.

- **$|Q|=0$:** $P=\{2\}$. ✓
- **$|Q|=1$:** $Q=\{p\}$. Odd prime factors of $p-1$ must be in $Q=\{p\}$, but t
hey're $<p$, so $p-1$ must be a pure power of 2 with $v_2\leq 2$: $p-1\in\{2,4\}
$, giving $p\in\{3,5\}$. So $P\in\{\{2,3\},\{2,5\}\}$. ✓
- **$|Q|=2$:** Both $p_i\equiv 3\pmod{4}$ (so $v_2(p_i-1)=1$). Odd prime factors
 of $(p_1-1)/2$ must equal $p_2$ and vice versa. Solving: $m_1\in\{1,p_2\}$, $m_
2\in\{1,p_1\}$ where $m_i=(p_i-1)/2$. The only valid solution is $\{3,7\}$ (sinc
e $7-1=6=2\cdot3$). So $P=\{2,3,7\}$. ✓

**Verification of $\{2,3,7\}$:** $f = 2\cdot\frac{2}{1}\cdot\frac{3}{2}\cdot\fra
c{7}{6} = 7$. ✓

## Computing the Sum

For a prime set $P$, the contribution is $\prod_{p\in P}\frac{1}{p-1}$:

$$\sum_{n\in S}\frac{1}{n} = 1 + \frac{1}{2} + 1 + \frac{1}{2} + \frac{1}{4} + \
frac{1}{12}$$

With common denominator 12:
$$= \frac{12+6+12+6+3+1}{12} = \frac{40}{12} = \frac{10}{3}$$

## Result

The sum is $\frac{10}{3}$, which is already irreducible ($\gcd(10,3)=1$).
