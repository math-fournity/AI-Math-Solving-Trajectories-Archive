# Problem

A high-security data vault requires a sequence of 9 unique digital keys to be entered into a console. The keys are labeled with the characters {a, b, c, p, q, r, x, y, z}. 

Due to a specific hardware constraint in the vault's logic gate, the sequence is only valid if the key labeled "y" is entered at some point after key "x" has been entered, but before key "z" is entered (or alternatively, if "y" is entered after "z" but before "x"). In other words, in the final chronological sequence of 9 keys, the key "y" must be positioned somewhere between the keys "x" and "z". The three keys x, y, and z do not need to be entered consecutively; other keys from the set may be interspersed between them.

How many valid 9-key sequences are possible?
