## Proof

Let $f: M \to N$ be a smooth map of smooth manifolds, and let $p \in M$. Set $r
= \mathrm{rnk}_p(f)$.

Choose coordinate charts $(U,\varphi)$ about $p$ in $M$ and $(W,\psi)$ about $f(
p)$ in $N$ with $f(U)\subseteq W$. In these coordinates, $f$ is represented by a
 smooth map
$$\tilde f = \psi\circ f\circ\varphi^{-1}:\ \varphi(U)\subseteq\mathbb R^m \long
rightarrow \psi(W)\subseteq\mathbb R^n.$$
For every $q\in U$, the rank $\mathrm{rnk}_q(f)$ equals the rank of the Jacobian
 matrix $D\tilde f_{\varphi(q)}$, an $n\times m$ matrix whose entries are the pa
rtial derivatives $\frac{\partial \tilde f^i}{\partial x^j}$, evaluated at $\var
phi(q)$. Since $\tilde f$ is smooth, each partial derivative is a continuous (in
deed smooth) function on $\varphi(U)$.

Because $r = \mathrm{rank}\bigl(D\tilde f_{\varphi(p)}\bigr)$, there exist row i
ndices $i_1,\dots,i_r$ and column indices $j_1,\dots,j_r$ such that the $r\times
 r$ minor
$$\Delta(x) \;=\; \det\!\left(\frac{\partial \tilde f^{i_a}}{\partial x^{j_b}}\r
ight)_{a,b=1}^{r}$$
satisfies $\Delta(\varphi(p))\neq 0$.

The function $\Delta:\varphi(U)\to\mathbb R$ is continuous (it is a polynomial i
n the partial derivatives, which are themselves continuous). Since $\Delta(\varp
hi(p))\neq 0$, by continuity there is an open neighborhood $\tilde V\subseteq\va
rphi(U)$ of $\varphi(p)$ on which $\Delta$ is everywhere nonzero:
$$\Delta(x)\neq 0\quad\text{for all }x\in\tilde V.$$

For every $x\in\tilde V$, the corresponding $r\times r$ submatrix of $D\tilde f_
x$ is invertible, so
$$\mathrm{rank}(D\tilde f_x)\;\geq\; r.$$

Set $V = \varphi^{-1}(\tilde V)$. This is an open neighborhood of $p$ in $M$, an
d for every $q\in V$,
$$\mathrm{rnk}_q(f) \;=\; \mathrm{rank}\bigl(D\tilde f_{\varphi(q)}\bigr) \;\geq
\; r \;=\; \mathrm{rnk}_p(f).$$

Thus the set $\{q\in M : \mathrm{rnk}_q(f)\geq \mathrm{rnk}_p(f)\}$ contains an
open neighborhood of $p$. Since $p$ was arbitrary, the non-falling rank conditio
n is open. $\blacksquare$
