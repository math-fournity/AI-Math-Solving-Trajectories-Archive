# Problem

In a remote industrial complex, an automated logistics system manages the distribution of specialized power cells across 2006 designated storage sectors. The system follows a strict incremental protocol for stocking each sector:

The first sector is initialized with an integer number of power cells, denoted by $x_1$, where $x_1 > 0$. For every subsequent sector from the 2nd to the 2006th, the number of cells allocated to that sector ($x_{n+1}$) is exactly equal to the sum of the squares of the cell counts in all preceding sectors (from sector $1$ to $n$).

The central computer requires that the total number of power cells stored in the final sector, $x_{2006}$, must be perfectly divisible by the total number of sectors, 2006, to allow for an even redistribution cycle.

Find the minimum possible value for the initial quantity $x_1$ that allows this divisibility condition for $x_{2006}$ to be met.
