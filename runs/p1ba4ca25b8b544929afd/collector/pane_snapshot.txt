Looking at this problem, I need to find the perimeter of a large rectangle tiled
 by 9 identical smaller rectangles, each with longer side 10 cm.

**Setting up the problem:**

Let each small rectangle have dimensions $10 \times a$, where $a \leq 10$ (since
 10 is the longer side). The total area is $9 \times 10a = 90a$.

**The 3×3 grid arrangement:**

The most natural tiling of 9 identical rectangles is a 3×3 grid, producing a lar
ge rectangle of $30 \times 3a$ with perimeter $P = 2(30 + 3a) = 60 + 6a$.

This depends on $a$, so I need to determine $a$.

**Non-trivial (mixed-orientation) tiling:**

Consider a tiling where some rectangles are horizontal ($10 \times a$) and some
are vertical ($a \times 10$). Place $k$ vertical rectangles in a block of $c$ co
lumns × $r$ rows (so $cr = k$), forming a block of $ca \times 10r$, and $9-k$ ho
rizontal rectangles in $c'$ columns × $r'$ rows (so $c'r' = 9-k$), forming a blo
ck of $10c' \times ar'$.

For these two blocks to form a rectangle, they must share a common dimension. Re
quiring equal heights: $10r = ar'$, giving $a = \frac{10r}{r'}$.

**Uniqueness requirement:**

For the problem to have a unique answer, the perimeter must be the same whether
we use the 3×3 grid or a non-trivial tiling. Setting the 3×3 grid rectangle ($30
 \times 3a$) equal to the mixed tiling rectangle:

Taking $r = 3$ (so the height $10r = 30 = 3a$), we get $a = \frac{30}{r'}$. The
mixed tiling then has the same height as the grid, and width $ca + 10c' = 30$ is
 automatically satisfied (since $3c + c'r' = 9$ always holds).

For $a < 10$ (non-square, as "longer side" implies), we need $r' > 3$. With $k =
 3$ ($c = 1, r = 3$) and $9 - k = 6 = c'r'$, taking $(c', r') = (1, 6)$:

$$a = \frac{30}{6} = 5$$

**Verification with $a = 5$:**

- **3×3 grid:** Nine $10 \times 5$ rectangles in 3 columns × 3 rows → $30 \times
 15$ rectangle.
- **Non-trivial tiling:** 3 vertical rectangles (each $5 \times 10$) stacked → $
5 \times 30$; 6 horizontal rectangles (each $10 \times 5$) stacked → $10 \times
30$; combined → $15 \times 30$.

Both arrangements produce the same rectangle ($30 \times 15$, up to rotation), c
onfirming uniqueness.

**Computing the perimeter:**

$$P = 2 \times (30 + 15) = 2 \times 45 = 90$$

For any other value of $a$, the 3×3 grid and non-trivial tilings yield **differe
nt** rectangles with different perimeters, so no unique answer would exist. The
value $a = 5$ is the only one where all natural tilings agree.

The answer is $\boxed{90}$, which is option **(a)**.
