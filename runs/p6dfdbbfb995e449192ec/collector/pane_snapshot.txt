## Proof

Let $y = x^{x^{x^{\cdot^{\cdot^{\cdot}}}}}$ denote the infinite power tower. For
 $x$ near 1 (within the convergence range $e^{-e} \le x \le e^{1/e}$), the tower
 satisfies the fixed-point equation $y = x^y$.

Since $\sqrt{x-1}$ requires $x > 1$, we take $x \to 1^+$. Set $t = x - 1 \to 0^+
$ and $s = y - 1 \to 0$.

**Step 1: Relate $s$ and $t$ via the implicit equation.**

The equation $y = x^y$ becomes $(1+s) = (1+t)^{1+s}$, i.e.,
$$\ln(1+s) = (1+s)\ln(1+t).$$

Expand both sides to second order:
$$s - \tfrac{s^2}{2} + O(s^3) = (1+s)\!\left(t - \tfrac{t^2}{2} + O(t^3)\right)
= t + st - \tfrac{t^2}{2} + O(t^3).$$

At leading order $s = t + O(t^2)$. Substitute $s = t + \alpha t^2 + O(t^3)$:

- **LHS:** $t + \alpha t^2 - \frac{t^2}{2} + O(t^3) = t + (\alpha - \tfrac{1}{2}
)t^2 + O(t^3)$
- **RHS:** $t + t\cdot t - \tfrac{t^2}{2} + O(t^3) = t + \tfrac{t^2}{2} + O(t^3)
$

Equating $t^2$-coefficients: $\alpha - \tfrac{1}{2} = \tfrac{1}{2}$, so $\alpha
= 1$.

Therefore:
$$s = t + t^2 + O(t^3), \qquad \frac{s}{t} = 1 + t + O(t^2).$$

**Step 2: Evaluate the limit.**

The expression is
$$L = \lim_{t\to 0^+}\left(\frac{s}{t}\right)^{1/\sqrt{t}}.$$

This is a $1^\infty$ form (base $\to 1^+$, exponent $\to +\infty$). Take logarit
hms:
$$\ln L = \lim_{t\to 0^+} \frac{1}{\sqrt{t}}\,\ln\!\left(\frac{s}{t}\right).$$

Since $\frac{s}{t} = 1 + t + O(t^2)$, we get
$$\ln\!\left(\frac{s}{t}\right) = \ln(1 + t + O(t^2)) = t + O(t^2) = O(t).$$

Therefore
$$\ln L = \lim_{t\to 0^+} \frac{O(t)}{\sqrt{t}} = \lim_{t\to 0^+} O\!\left(\sqrt
{t}\right) = 0.$$

**Conclusion:**
$$L = e^0 = \boxed{1}.$$
