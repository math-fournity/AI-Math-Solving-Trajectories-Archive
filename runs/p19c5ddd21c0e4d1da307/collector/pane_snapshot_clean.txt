**Key observation:** Reconfiguring node A toggles all edges incident to A. Switc
hing a set S of vertices (one at a time) toggles exactly the edges crossing the
cut (S, V\S), leaving all other edges unchanged. The order doesn't matter, and s
witching a vertex twice cancels. So any sequence of switches equals switching so
me set S, with cost |S|.

**Isolation strategy:** To isolate vertex v after switching S:
- If v ∉ S: v's G-neighbors must be exactly S, so |S| = deg(v).
- If v ∈ S: v's G-non-neighbors must be exactly S\{v}, so |S| = n − deg(v).

Thus isolating v costs min(deg(v), n − deg(v)).
