# Problem

In a remote digital archives facility, a central security system generates an encrypted sequence of access codes known as "Level-Keys." The sequence is governed by a strict recursive protocol: the first key ($L_0$) is set to the value 2, and the second key ($L_1$) is set to 1. For every subsequent step $n \geq 0$, the $(n+2)$-th key is generated by summing the two immediately preceding keys ($L_{n+2} = L_{n+1} + L_n$).

An auditor is reviewing a specific block of these keys, starting from the first generated key ($n=1$) up to and including the 2016th key ($n=2016$). The auditor is flagging every key in this range that contains at least one instance of the digit '1' in its decimal representation.

Let $N$ be the total number of integers $n$ in the range $1 \leq n \leq 2016$ for which the key $L_n$ contains the digit 1. Estimate the value of $N$.
