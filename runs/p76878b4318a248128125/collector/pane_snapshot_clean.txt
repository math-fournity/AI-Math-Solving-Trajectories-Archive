# IMO 1981 Problem 6

The function defined is the Ackermann function. We compute it layer by layer.

## Layer 1: f(1, y)

$f(1, 0) = f(0, 1) = 2$, and $f(1, y+1) = f(0, f(1, y)) = f(1, y) + 1$.

By induction: $f(1, y) = y + 2$.

## Layer 2: f(2, y)

$f(2, 0) = f(1, 1) = 3$, and $f(2, y+1) = f(1, f(2, y)) = f(2, y) + 2$.

By induction: $f(2, y) = 2y + 3$.

## Layer 3: f(3, y)

$f(3, 0) = f(2, 1) = 5$, and $f(3, y+1) = f(2, f(3, y)) = 2\,f(3, y) + 3$.

Set $g(y) = f(3, y) + 3$. Then $g(y+1) = 2\,f(3, y) + 6 = 2\,g(y)$, with $g(0) =
 8 = 2^3$.

So $g(y) = 2^{y+3}$, giving $f(3, y) = 2^{y+3} - 3$.

## Layer 4: f(4, y)

$f(4, 0) = f(3, 1) = 2^4 - 3 = 13$, and $f(4, y+1) = f(3, f(4, y)) = 2^{f(4, y)
+ 3} - 3$.

Set $h(y) = f(4, y) + 3$. Then $h(y+1) = 2^{f(4, y) + 3} = 2^{h(y)}$, with $h(0)
 = 16 = 2^{2^2}$.

Define tetration $2 \uparrow\uparrow n$ by $2\uparrow\uparrow 1 = 2$, $2\uparrow
\uparrow (n+1) = 2^{2\uparrow\uparrow n}$. Then $h(0) = 2\uparrow\uparrow 3$, an
d the recurrence $h(y+1) = 2^{h(y)}$ gives exactly

$$h(y) = 2\uparrow\uparrow (y+3).$$

Therefore $f(4, y) = 2\uparrow\uparrow (y+3) - 3$.

## Conclusion

$$f(4, 1981) = 2\uparrow\uparrow 1984 - 3,$$

i.e. a tower of $1984$ twos, minus $3$:

$$f(4, 1981) = \underbrace{2^{2^{2^{\cdot^{\cdot^{\cdot^{2}}}}}}}_{1984 \text{ t
wos}} - 3.$$
