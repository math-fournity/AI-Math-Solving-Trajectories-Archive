## Solution

**Notation.** For vertices $1,\dots,N$ with $N\ge 3$, every edge $i\to j$ ($i<j$
) is colored red (R) or blue (B). A *monochromatic path* is one all of whose edg
es share a color. The coloring is *valid* if no pair $A<B$ admits both an all-re
d path and an all-blue path from $A$ to $B$.

**Reachability relations.** Define
- $R=\{(i,j): i<j,\ \exists\text{ red path }i\to\cdots\to j\}$,
- $B=\{(i,j): i<j,\ \exists\text{ blue path }i\to\cdots\to j\}$.

Both are transitive (reachability is transitive). The validity condition is exac
tly $R\cap B=\varnothing$.

**Every pair is reached in exactly one color.** For any $i<j$, the direct edge $
i\to j$ is itself a monochromatic path (of length 1), so $(i,j)$ belongs to at l
east one of $R,B$. Validity forbids both. Hence $R,B$ partition the set of all p
airs $\{(i,j):i<j\}$ into two transitive relations.

**Bijection with permutations.** Given a permutation (total order) $\prec$ on $\
{1,\dots,N\}$, color $i\to j$ ($i<j$) red iff $i\prec j$, blue iff $j\prec i$. T
hen a red path $i=v_0<v_1<\cdots<v_k=j$ forces $i=v_0\prec v_1\prec\cdots\prec v
_k=j$, so $i\prec j$; a blue path forces $i\succ j$. Both cannot hold, so the co
loring is valid.

Conversely, given a valid coloring, define a relation on vertices:
$$i\prec j \iff \bigl(i<j\ \wedge\ (i,j)\in R\bigr)\ \vee\ \bigl(i>j\ \wedge\ (j
,i)\in B\bigr).$$
Since $R,B$ partition all pairs, for $i\ne j$ exactly one of $i\prec j$, $j\prec
 i$ holds. It remains to verify transitivity: suppose $i\prec j$ and $j\prec k$;
 we show $i\prec k$ by considering the relative order of $i,j,k$.

- **$i<j<k$:** $(i,j),(j,k)\in R$; $R$ transitive $\Rightarrow$ $(i,k)\in R$ $\R
ightarrow$ $i\prec k$.
- **$i<k<j$:** $(i,j)\in R$, $(k,j)\in B$. If $(i,k)\notin R$ then $(i,k)\in B$;
 with $(k,j)\in B$, transitivity of $B$ gives $(i,j)\in B$, contradicting $(i,j)
\in R$. So $(i,k)\in R$.
- **$j<i<k$:** $(j,i)\in B$, $(j,k)\in R$. If $(i,k)\notin R$ then $(i,k)\in B$;
 with $(j,i)\in B$ gives $(j,k)\in B$, contradiction. So $(i,k)\in R$.
- **$j<k<i$:** $(j,i)\in B$, $(j,k)\in R$. If $(k,i)\notin B$ then $(k,i)\in R$;
 with $(j,k)\in R$ gives $(j,i)\in R$, contradiction. So $(k,i)\in B$.
- **$k<i<j$:** $(i,j)\in R$, $(k,j)\in B$. If $(k,i)\notin B$ then $(k,i)\in R$;
 with $(i,j)\in R$ gives $(k,j)\in R$, contradiction. So $(k,i)\in B$.
- **$k<j<i$:** $(j,i),(k,j)\in B$; $B$ transitive $\Rightarrow$ $(k,i)\in B$.

In every case $i\prec k$, so $\prec$ is a strict total order, i.e. a permutation
. The edge coloring is recovered from $\prec$ by "$i\to j$ red iff $i\prec j$",
so the two constructions are inverse to each other.

**Count.** The valid colorings are in bijection with the $N!$ permutations of $\
{1,\dots,N\}$.

**Sanity check.** $N=2$: $2!=2$ (both colorings valid). $N=3$: direct enumeratio
n gives $6=3!$ valid colorings (only $(R,R,B)$ and $(B,B,R)$ among the $8$ fail,
 each creating both a red $1\to2\to3$ and blue $1\to3$, or vice versa).

$$\boxed{N!}$$
