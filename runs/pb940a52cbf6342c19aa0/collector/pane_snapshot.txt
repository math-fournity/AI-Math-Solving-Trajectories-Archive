**Problem.** Find all positive integers $k$ such that: whenever positive reals $
a,b,c$ satisfy $k(ab+bc+ca) > 5(a^2+b^2+c^2)$, then $a,b,c$ are the side lengths
 of a triangle.

## Step 1: Reformulation via contrapositive

A triangle with sides $a,b,c$ exists iff the strict triangle inequalities hold:
$$a < b+c,\quad b < a+c,\quad c < a+b.$$

The condition we want is:

> For all positive $a,b,c$: if $k(ab+bc+ca) > 5(a^2+b^2+c^2)$, then $a,b,c$ form
 a triangle.

By contrapositive, this is equivalent to:

> For all positive $a,b,c$ that do **not** form a triangle, $k(ab+bc+ca) \le 5(a
^2+b^2+c^2)$.

Define the ratio
$$R(a,b,c) = \frac{5(a^2+b^2+c^2)}{ab+bc+ca}.$$

Then the requirement becomes: $k \le R(a,b,c)$ for **every** non-triangle triple
 $(a,b,c)$. Hence
$$k \le \inf_{\text{non-triangle}} R(a,b,c).$$

So we must compute this infimum.

---

## Step 2: Reduction to the boundary $a = b+c$

Without loss of generality, among a non-triangle triple let $a$ be the largest s
ide, so $a \ge b+c$ (with equality being the degenerate case). Write $a = b+c+t$
 with $t \ge 0$, and set $S = b+c$, $B = b^2+c^2$, $P = bc$. Then
$$R = \frac{5(a^2+B)}{aS+P} =: f(a).$$

Compute the derivative:
$$f'(a) = \frac{5\big[2a(aS+P) - (a^2+B)S\big]}{(aS+P)^2} = \frac{5\big[a^2 S +
2aP - BS\big]}{(aS+P)^2}.$$

At $a = S = b+c$:
$$a^2 S + 2aP - BS = S^3 + 2SP - BS = S\big(S^2 + 2P - B\big) = S\big((b+c)^2 +
2bc - (b^2+c^2)\big) = S\cdot 4bc > 0.$$

So $f$ is strictly increasing at $a = b+c$, and one checks $f'(a) > 0$ for all $
a \ge b+c$ (the numerator $a^2S+2aP-BS$ is increasing in $a$ and already positiv
e at $a=S$). Therefore $R$ is minimized when $a = b+c$ (the degenerate boundary)
, i.e. $t = 0$.

## Step 3: Minimizing on the boundary $a = b+c$

With $a = b+c$:
$$a^2+b^2+c^2 = (b+c)^2 + b^2 + c^2 = 2b^2+2c^2+2bc,$$
$$ab+bc+ca = (b+c)b + bc + c(b+c) = b^2 + c^2 + 3bc.$$

So
$$R = \frac{10(b^2+c^2+bc)}{b^2+c^2+3bc}.$$

Let $u = \dfrac{bc}{b^2+c^2} \in \left(0,\, \tfrac{1}{2}\right]$ (the maximum $u
=\tfrac12$ is attained at $b=c$). Then
$$R = \frac{10(1+u)}{1+3u}.$$

Since $\dfrac{d}{du}\dfrac{1+u}{1+3u} = \dfrac{(1+3u)-3(1+u)}{(1+3u)^2} = \dfrac
{-2}{(1+3u)^2} < 0,$

$R$ is **decreasing** in $u$, hence minimized at the largest value $u = \tfrac12
$, i.e. $b = c$. There:
$$R = \frac{10\cdot \tfrac{3}{2}}{1+\tfrac{3}{2}} = \frac{15}{\tfrac{5}{2}} = 6.
$$

Thus
$$\inf_{\text{non-triangle}} R(a,b,c) = 6,$$
attained (in the limit / at the degenerate point) by $b = c$, $a = b+c = 2b$.

## Step 4: Determining the valid $k$

The condition requires $k \le 6$.

**$k \le 6$ works.** For any non-triangle triple, $R(a,b,c) \ge 6 \ge k$, so $k(
ab+bc+ca) \le 5(a^2+b^2+c^2)$; the hypothesis $k(ab+bc+ca) > 5(a^2+b^2+c^2)$ is
never triggered by a non-triangle. Hence every triple satisfying the hypothesis
must be a triangle.

Concretely, at the extremal degenerate point $b=c$, $a=2b$: $ab+bc+ca = 5b^2$ an

**$k \ge 7$ fails.** Take $b = c = 1$, $a = 2$ (degenerate, not a triangle). The

The hypothesis is satisfied, yet $a = b+c$ means no (non-degenerate) triangle ex
