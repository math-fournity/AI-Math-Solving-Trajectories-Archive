## Proof

**Setup.** The efficiency $E(x)$ is periodic with period 2, defined on one perio
d by
$$E(x) = \begin{cases} x, & 0 \le x < 1, \\ 2 - x, & 1 \le x < 2. \end{cases}$$

We compute $\displaystyle L = \lim_{n\to\infty}\int_0^{2n} E(x)\,e^{-x}\,dx$.

**Step 1 — Single-period integral.** Let
$$I = \int_0^2 E(x)\,e^{-x}\,dx = \int_0^1 x\,e^{-x}\,dx + \int_1^2 (2-x)\,e^{-x
}\,dx.$$

For the first piece, integration by parts gives
$$\int_0^1 x\,e^{-x}\,dx = \bigl[-x\,e^{-x} - e^{-x}\bigr]_0^1 = \bigl(-e^{-1}-e
^{-1}\bigr) - (0-1) = 1 - 2e^{-1}.$$

For the second piece, integration by parts with $f = 2-x$, $g' = e^{-x}$:
$$\int_1^2 (2-x)\,e^{-x}\,dx = \bigl[-(2-x)\,e^{-x}\bigr]_1^2 - \int_1^2 e^{-x}\
,dx.$$
The boundary term: at $x=2$ gives $0$; at $x=1$ gives $-e^{-1}$, so the boundary
 evaluates to $0 - (-e^{-1}) = e^{-1}$. The remaining integral is $\int_1^2 e^{-
x}\,dx = e^{-1} - e^{-2}$. Hence
$$\int_1^2 (2-x)\,e^{-x}\,dx = e^{-1} - (e^{-1}-e^{-2}) = e^{-2}.$$

Therefore
$$I = \bigl(1 - 2e^{-1}\bigr) + e^{-2} = 1 - 2e^{-1} + e^{-2} = \bigl(1 - e^{-1}
\bigr)^2.$$

**Step 2 — Sum over cycles.** Substituting $x = 2k + t$ in the $k$-th period $[2
k, 2k+2]$ and using periodicity $E(2k+t) = E(t)$:
$$\int_{2k}^{2k+2} E(x)\,e^{-x}\,dx = \int_0^2 E(t)\,e^{-(2k+t)}\,dt = e^{-2k}\,
I.$$

Summing over $k = 0, 1, \dots, n-1$:
$$\int_0^{2n} E(x)\,e^{-x}\,dx = I\sum_{k=0}^{n-1} e^{-2k} = I\cdot\frac{1 - e^{
-2n}}{1 - e^{-2}}.$$

**Step 3 — Take the limit.** As $n \to \infty$, $e^{-2n} \to 0$, so
$$L = \frac{I}{1 - e^{-2}} = \frac{(1 - e^{-1})^2}{(1 - e^{-1})(1 + e^{-1})} = \
frac{1 - e^{-1}}{1 + e^{-1}}.$$

Multiplying numerator and denominator by $e$:
$$L = \frac{e - 1}{e + 1}.$$

**Result:**
$$\boxed{\displaystyle \lim_{n \to \infty} \int_{0}^{2n} E(x)\,e^{-x}\,dx = \fra
c{e-1}{e+1}}$$
