## Proof

**Construction.** Let $\alpha$ be any irrational number (e.g. $\alpha = \sqrt{2}
$), and define
$$f:\mathbb{R}\to\mathbb{R},\qquad f(x) = (x-\alpha)^2.$$

**Continuity.** $f$ is a polynomial, hence continuous on all of $\mathbb{R}$.

**$f$ is not injective on $\mathbb{R}$.** Take $x_1 = \alpha+1$ and $x_2 = \alph
a-1$. These are distinct real numbers, yet
$$f(x_1) = 1^2 = 1 = (-1)^2 = f(x_2).$$
So $f$ is not injective.

**$f|_{\mathbb{Q}}$ is injective.** Suppose $q_1, q_2\in\mathbb{Q}$ and $f(q_1)=
f(q_2)$. Then
$$(q_1-\alpha)^2 = (q_2-\alpha)^2,$$
which gives $q_1-\alpha = \pm(q_2-\alpha)$.

- If $q_1-\alpha = +(q_2-\alpha)$, then $q_1 = q_2$.
- If $q_1-\alpha = -(q_2-\alpha)$, then $q_1+q_2 = 2\alpha$.

In the second case, the left-hand side $q_1+q_2$ is rational (sum of rationals),
 while the right-hand side $2\alpha$ is irrational (since $\alpha$ is irrational
). This is a contradiction, so the second case cannot occur.

Therefore $q_1 = q_2$, proving that $f|_{\mathbb{Q}}$ is injective.

**Conclusion.** The function $f(x) = (x-\sqrt{2})^2$ is continuous, is not injec
tive on $\mathbb{R}$, yet its restriction to $\mathbb{Q}$ is injective. $\blacks
quare$
