# Problem

In a specialized digital signal processing facility, an automated system generates an infinite stream of binary bits, $a_1, a_2, a_3, \dots$, where each bit must be either $1$ or $-1$.

The system’s logic is governed by two strict operational protocols:

1.  **Multiplicative Consistency:** For any two positive integers $m$ and $n$, the value of the bit at position $m \times n$ must be exactly equal to the product of the bit at position $m$ and the bit at position $n$. This relationship ($a_{mn} = a_m a_n$) must hold for all possible index pairs.
2.  **Anti-Repetition Protocol:** To prevent signal synchronization errors, the sequence is forbidden from ever containing three identical consecutive bits. That is, there is no integer $n$ such that $a_n, a_{n+1},$ and $a_{n+2}$ all share the same value.

Determine the total number of distinct infinite sequences that satisfy both of these protocols.
