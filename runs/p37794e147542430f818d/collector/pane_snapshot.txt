## Proof that the statement is TRUE

**Theorem.** For any $n \times n$ skew-symmetric matrix $M$ over a field of char
acteristic $\neq 2$, there exists a principal submatrix of $M$ whose rank equals
 $\operatorname{rank}(M)$.

Since the rank of a skew-symmetric matrix is always even, write $\operatorname{r
ank}(M) = 2k$. We prove by induction on $n$ that there exists a principal submat
rix of order $2k$ with nonzero determinant.

**Base case:** $n = 1$. Then $M = [0]$, $\operatorname{rank}(M) = 0$, and the re
sult holds trivially.

**Inductive step.** Assume the result for all skew-symmetric matrices of size $<
 n$. Let $M$ be $n \times n$ skew-symmetric with $\operatorname{rank}(M) = 2k$.

If $k = 0$, then $M = 0$ and the result is trivial.

If $k > 0$, then $M \neq 0$, so there exist indices $i, j$ with $M[i,j] \neq 0$.
 By simultaneously permuting rows and columns (which preserves the skew-symmetri
c property and merely relabels principal submatrices), assume $M[1,2] \neq 0$.

The $2 \times 2$ principal submatrix $A = M[\{1,2\},\{1,2\}] = \begin{pmatrix} 0
 & M[1,2] \\ -M[1,2] & 0 \end{pmatrix}$ has $\det(A) = M[1,2]^2 \neq 0$, so $A$
is nonsingular.

Form the Schur complement $S = D - C A^{-1} B$, where $B = M[\{1,2\}, \{3,\dots,
n\}]$, $C = M[\{3,\dots,n\}, \{1,2\}]$, $D = M[\{3,\dots,n\}, \{3,\dots,n\}]$.

**$S$ is skew-symmetric.** Since $M^T = -M$: $D^T = -D$, $B^T = -C$, $C^T = -B$,
 and $(A^{-1})^T = (A^T)^{-1} = (-A)^{-1} = -A^{-1}$. Then:
$$S^T = D^T - B^T (A^{-1})^T C^T = (-D) - (-C)(-A^{-1})(-B) = -D + CA^{-1}B = -S
.$$

**Rank of $S$.** Since $A$ is nonsingular, $\operatorname{rank}(M) = \operatorna
me{rank}(A) + \operatorname{rank}(S) = 2 + \operatorname{rank}(S)$, so $\operato
rname{rank}(S) = 2k - 2 = 2(k-1)$.

**Applying induction.** $S$ is an $(n{-}2) \times (n{-}2)$ skew-symmetric matrix
 with rank $2(k{-}1)$. By the inductive hypothesis, there exists $I \subseteq \{
3,\dots,n\}$ with $|I| = 2(k{-}1)$ and $\det(S[I,I]) \neq 0$.

**Lifting back to $M$.** Set $K = \{1,2\} \cup I$, so $|K| = 2k$. By the Schur c
omplement determinant formula:
$$\det(M[K,K]) = \det(A) \cdot \det(S[I,I]) \neq 0.$$

Thus $M[K,K]$ is a principal submatrix of $M$ of order $2k = \operatorname{rank}
(M)$ with nonzero determinant, hence rank $2k = \operatorname{rank}(M)$.

This completes the induction. $\square$

**Conclusion.** The statement is **true**: among all largest-rank submatrices of
 a skew-symmetric matrix $M$, there is always at least one that is principal.
