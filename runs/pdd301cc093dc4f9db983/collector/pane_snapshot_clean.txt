## 解答

**变量代换。** 令 $x = \sin^2\theta$，其中 $\theta \in [0, \pi/2]$。由于 $\sin$
在 $[0,\pi/2]$ 上严格递增，这给出了 $[0,1] \to [0,\pi/2]$ 的一一对应。计算：
$$f(x) = 4\sin^2\theta\cos^2\theta = \sin^2(2\theta).$$
由归纳法，$f^{n}(x) = \sin^2(2^{n}\theta)$。

**化简方程。** $f^{1992}(x) = x$ 等价于
$$\sin^2(2^{1992}\theta) = \sin^2\theta.$$
利用 $\sin^2 A = \sin^2 B \iff A = B + k\pi \text{ 或 } A = \pi - B + k\pi$（$k\
in\mathbb{Z}$），得两类：

- **情形一：** $(2^{1992}-1)\theta = k\pi$，即 $\theta = \dfrac{k\pi}{2^{1992}-1
}$。
- **情形二：** $(2^{1992}+1)\theta = (k+1)\pi$，即 $\theta = \dfrac{m\pi}{2^{199
2}+1}$（$m=k+1\in\mathbb{Z}$）。

**计数情形一。** 要求 $\theta\in[0,\pi/2]$，即 $0\le k\le \tfrac{2^{1992}-1}{2}$
。因 $2^{1992}-1$ 为奇数，$\lfloor\tfrac{2^{1992}-1}{2}\rfloor = 2^{1991}-1$。故
 $k=0,1,\dots,2^{1991}-1$，共 $\boxed{2^{1991}}$ 个。

**计数情形二。** 要求 $0\le m\le \tfrac{2^{1992}+1}{2}$。因 $2^{1992}+1$ 为奇数
，$\lfloor\tfrac{2^{1992}+1}{2}\rfloor = 2^{1991}$。故 $m=0,1,\dots,2^{1991}$，
共 $\boxed{2^{1991}+1}$ 个。

**去重。** 设某 $\theta$ 同时属于两类：
$$\frac{k\pi}{2^{1992}-1} = \frac{m\pi}{2^{1992}+1} \implies k(2^{1992}+1) = m(2
^{1992}-1).$$
因 $\gcd(2^{1992}-1,\,2^{1992}+1)=\gcd(2^{1992}-1,2)=1$（二者皆奇），故 $(2^{199
2}-1)\mid k$。但 $0\le k\le 2^{1991}-1 < 2^{1992}-1$，故 $k=0$，从而 $m=0$，对应
 $\theta=0$（即 $x=0$）。**唯一重叠点是 $\theta=0$。**

**总计。** 不同 $\theta$（从而不同 $x$）的个数为
$$2^{1991} + (2^{1991}+1) - 1 = 2^{1992}.$$

**小情形验证。** $n=1$：$f(x)=x \Rightarrow 4x(1-x)=x \Rightarrow x=0,\tfrac34$
，共 $2=2^1$ 个，吻合。$n=2$：$f^2(x)=x$ 给出周期整除 $2$ 的点，共 $4=2^2$ 个，
吻合。

因此，方程 $f^{1992}(x)=x$ 的不同根的个数为

$$\boxed{2^{1992}}.$$
