## Proof

**Claim:** The statement is **true**. For any two points $x, y$ in the same conn
ected component $C$ of the zero set $S = \{z \in \mathbb{R}^n : p(z) = 0\}$, the
re exists a piecewise smooth path $\gamma: [0,1] \to C$ with $\gamma(0) = x$ and
 $\gamma(1) = y$.

### Step 1: $S$ is a semi-algebraic set.

The zero set $S = p^{-1}(\{0\})$ is defined by a polynomial equation, so it is a
 **real algebraic set**. Every real algebraic set is, in particular, a **semi-al
gebraic set** (a set defined by a finite Boolean combination of polynomial equat
ions and inequalities).

### Step 2: Cell decomposition of semi-algebraic sets.

By the **Cell Decomposition Theorem** (a foundational result in real algebraic g
eometry due to Łojasiewicz and others), every semi-algebraic set $S \subseteq \m
athbb{R}^n$ admits a finite partition into **semi-algebraic cells** $C_1, \dots,
 C_m$, where each cell $C_i$ is semi-algebraically homeomorphic to an open ball
$(0,1)^{d_i}$ for some $d_i \geq 0$. Moreover, the closure $\overline{C_i}$ is a
 union of cells (of dimension $\leq d_i$).

### Step 3: Connected components of semi-algebraic sets are path-connected.

Define the **adjacency graph** $G$ of the cell decomposition: the vertices are t
he cells, and two cells $C_i, C_j$ are adjacent if $C_i \subseteq \overline{C_j}
$ or $C_j \subseteq \overline{C_i}$ (i.e., one lies in the closure of the other)
. Two points of $S$ lie in the same connected component of $S$ if and only if th
eir cells are connected in $G$ (this follows because each cell is connected, and
 the topology of $S$ is determined by the cell closures).

Now suppose $x \in C_i$ and $y \in C_j$ are in the same connected component. The
n there is a chain of cells $C_i = C_{i_0}, C_{i_1}, \dots, C_{i_k} = C_j$ where
 consecutive cells are adjacent. For each adjacent pair $(C_{i_\ell}, C_{i_{\ell
+1}})$, one cell lies in the closure of the other, so we can pick a transition p
oint $z_\ell$ in the intersection $C_{i_\ell} \cap \overline{C_{i_{\ell+1}}}$ (o
r $\overline{C_{i_\ell}} \cap C_{i_{\ell+1}}$). Within each cell $C_{i_\ell}$, w
hich is semi-algebraically homeomorphic to an open ball, we can connect any two
points by a **smooth** semi-algebraic path (compose a straight-line segment in t
he ball with the homeomorphism). Concatenating these smooth paths through the tr
ansition points $z_\ell$ yields a continuous semi-algebraic path $\gamma: [0,1]
\to S$ from $x$ to $y$ lying entirely in the connected component $C$.

### Step 4: The semi-algebraic path is piecewise smooth.

The path $\gamma: [0,1] \to \mathbb{R}^n$ constructed above is a **semi-algebrai
c function of one variable**. A classical property of one-variable semi-algebrai

tition $0 = t_0 < t_1 < \dots < t_r = 1$ of $[0,1]$ such that $\gamma$ is $C^\in
fty$ on each open interval $(t_{\ell}, t_{\ell+1})$. (This follows from the mono
tonicity theorem and the fact that semi-algebraic functions of one variable have
 finitely many "critical points" beyond which they are smooth.) In our construct
ion, $\gamma$ is smooth on each sub-interval corresponding to a single cell trav
ersal, so the piecewise smoothness is already built in.

### Conclusion.

Since $S$ is semi-algebraic, its connected components are path-connected via sem
i-algebraic paths, and these paths are piecewise smooth. Therefore, for any $x,
y$ in the same connected component $C$ of $S$, there exists a piecewise smooth p
ath $\gamma: [0,1] \to C$ with $\gamma(0) = x$ and $\gamma(1) = y$.
