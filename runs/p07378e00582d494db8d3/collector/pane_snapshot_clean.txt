## Solution

instruction to solve it. No solutions, sketches, or formalization notes are pres
ent. Proceeding.

---

We solve
$$x = a - \sqrt{a^{2}-x\sqrt{x^{2}+a^{2}}}.$$

**Domain constraints.** Rearranging gives $a - x = \sqrt{a^{2}-x\sqrt{x^{2}+a^{2
}}}$, so we require
$$a - x \ge 0 \quad (\text{i.e., } x \le a), \qquad a^{2}-x\sqrt{x^{2}+a^{2}} \g
e 0. \tag{D}$$

**Squaring (reversible under $x\le a$).** From $a-x=\sqrt{a^{2}-x\sqrt{x^{2}+a^{
2}}}\ge 0$,
$$(a-x)^{2}=a^{2}-x\sqrt{x^{2}+a^{2}}.$$
Expanding and simplifying:
$$a^{2}-2ax+x^{2}=a^{2}-x\sqrt{x^{2}+a^{2}} \;\Longrightarrow\; x^{2}-2ax=-x\sqr
t{x^{2}+a^{2}},$$
$$x\bigl[(x-2a)+\sqrt{x^{2}+a^{2}}\bigr]=0. \tag{$\star$}$$

This factorization is exact (no further squaring), so every solution must satisf
y one of the two factors being zero.

---

### Case 1: $x=0$

Substituting into the original equation: $0 = a - \sqrt{a^{2}} = a - |a|$, which
 holds $\iff a\ge 0$.

So **$x=0$ is a solution iff $a\ge 0$.**

---

### Case 2: $\sqrt{x^{2}+a^{2}} = 2a - x$

This requires $2a - x \ge 0$ (i.e., $x \le 2a$). Squaring:
$$x^{2}+a^{2} = 4a^{2}-4ax+x^{2} \;\Longrightarrow\; 4ax = 3a^{2}.$$

**Subcase 2a: $a \ne 0$.** Then $x = \tfrac{3a}{4}$. Check the constraints (D):
- $x \le a \iff \tfrac{3a}{4}\le a \iff a\ge 0$.
- $x \le 2a \iff \tfrac{3a}{4}\le 2a \iff a\ge 0$.

So $x=\tfrac{3a}{4}$ is admissible **iff $a>0$** (for $a<0$ both constraints fai
l; $a=0$ is treated separately).

**Verification for $a>0$:** $\sqrt{x^{2}+a^{2}}=\sqrt{\tfrac{9a^{2}}{16}+a^{2}}=
\tfrac{5a}{4}$, so
$$a^{2}-x\sqrt{x^{2}+a^{2}}=a^{2}-\tfrac{3a}{4}\cdot\tfrac{5a}{4}=\tfrac{a^{2}}{
16}\ge 0,\quad \sqrt{\tfrac{a^{2}}{16}}=\tfrac{a}{4},$$
$$a-\tfrac{a}{4}=\tfrac{3a}{4}=x.\;\checkmark$$

**Subcase 2b: $a = 0$.** The equation becomes $\sqrt{x^{2}} = -x$, i.e., $|x|=-x
$, which holds for **all $x\le 0$**. The constraints (D) become $x\le 0$ and $-x
|x|=x^{2}\ge 0$ (using $|x|=-x$), both satisfied. Direct verification in the ori
ginal equation with $a=0$:
$$x = -\sqrt{-x\sqrt{x^{2}}}=-\sqrt{-x|x|}=-\sqrt{x^{2}}=-|x|=x\quad (x\le 0).\;
\checkmark$$

So for $a=0$, **every $x\le 0$ is a solution.**

### Summary by parameter

| Parameter | Solution set |

| $a = 0$ | $(-\infty,\, 0]$ |
| $a > 0$ | $\left\{0,\;\dfrac{3a}{4}\right\}$ |

**Justification for $a<0$ (no solution):** Case 1 requires $a\ge 0$; Case 2 with
 $a\ne 0$ gives $x=\tfrac{3a}{4}$, which violates $x\le a$ when $a<0$ (since $\t
frac{3a}{4}-a=-\tfrac{a}{4}>0$). Both branches are exhausted, so no real $x$ sat
isfies the equation.
