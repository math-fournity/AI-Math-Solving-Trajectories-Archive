Looking at this problem, I need to find the maximum number $K$ of consecutive po
sitive integer zeros of $f(x) = \sum_{m=1}^n a_m m^x$ with $a_1 = 1$ and all $a_
m$ integers.

**Answer: $K = n - 2$.**

---

## Proof

### Setup

Let $f(x) = \sum_{m=1}^n a_m m^x$ with $a_1 = 1$ and $a_2, \ldots, a_n \in \math
bb{Z}$. Suppose $f$ vanishes at $K$ consecutive positive integers $x = s, s+1, \
ldots, s+K-1$ with $s \geq 1$.

Set $b_m = a_m \cdot m^s$. Then the vanishing conditions become:
$$\sum_{m=1}^n b_m \, m^j = 0, \quad j = 0, 1, \ldots, K-1. \tag{$\star$}$$

This is a Vandermonde-type system in the $n$ unknowns $b_1, \ldots, b_n$.

### Upper Bound: $K \leq n-2$

**Step 1 ($K \leq n-1$).** If $K \geq n$, then $(\star)$ for $j = 0, \ldots, n-1
$ gives an $n \times n$ Vandermonde system with nodes $1, 2, \ldots, n$ (distinc
t), whose determinant is $\prod_{1 \leq i < j \leq n}(j - i) \neq 0$. The unique
 solution is $b_m = 0$ for all $m$, hence $a_m = 0$ for all $m$ (since $m^s \neq
 0$), contradicting $a_1 = 1$. So $K \leq n-1$.

**Step 2 ($K \neq n-1$).** Suppose $K = n-1$. Then $(\star)$ holds for $j = 0, \
ldots, n-2$, giving an $(n-1) \times n$ system with a $1$-dimensional null space
.

**Claim:** The null space is spanned by $b_m = (-1)^{m-1}\binom{n-1}{m-1}$.

*Proof of claim.* For $j \leq n-2$, the sum $\sum_{m=1}^n (-1)^{m-1}\binom{n-1}{
m-1} m^j$ equals (up to sign) the $(n-1)$-th forward difference of the polynomia
l $t \mapsto (t+1)^j$ at $t=0$. Since $(t+1)^j$ has degree $j \leq n-2 < n-1$, i
ts $(n-1)$-th forward difference vanishes. (One can also verify directly: this i
s $\sum_{k=0}^{n-1}(-1)^k\binom{n-1}{k}(k+1)^j = (-1)^{n-1}\Delta^{n-1}[(t+1)^j]
\big|_{t=0} = 0$.) Since the null space is $1$-dimensional and this is a nonzero
 vector in it, it spans. $\square$

Since $b_1 = a_1 \cdot 1^s = 1$ and $b_1 = c \cdot 1 = c$ for the scalar $c$, we
 get $c = 1$. Then:
$$b_n = (-1)^{n-1}\binom{n-1}{n-1} = (-1)^{n-1}, \quad \text{so} \quad a_n = \fr
ac{b_n}{n^s} = \frac{(-1)^{n-1}}{n^s}.$$
Since $n \geq 2$ and $s \geq 1$, we have $n^s \geq 2$, so $a_n \notin \mathbb{Z}
$. **Contradiction.** Therefore $K \leq n-2$.

### Lower Bound: $K = n-2$ is achievable

Define $a_m = (-1)^{m-1}\binom{n-1}{m-1}$ for $m = 1, \ldots, n$. These are inte
gers with $a_1 = \binom{n-1}{0} = 1$.

Then:
$$f(x) = \sum_{m=1}^n (-1)^{m-1}\binom{n-1}{m-1} m^x = \sum_{k=0}^{n-1} (-1)^k \
binom{n-1}{k}(k+1)^x = (-1)^{n-1}\,\Delta^{n-1}\!\big[(t+1)^x\big]\Big|_{t=0},$$
where $\Delta$ is the forward difference operator.

For each $x \in \{0, 1, \ldots, n-2\}$, the function $t \mapsto (t+1)^x$ is a po
lynomial in $t$ of degree $x \leq n-2 < n-1$. The $(n-1)$-th forward difference
of any polynomial of degree $< n-1$ is identically zero. Therefore:
$$f(x) = 0 \quad \text{for } x = 0, 1, \ldots, n-2.$$

In particular, $f(x) = 0$ for $x = 1, 2, \ldots, n-2$, which gives $n-2$ consecu
tive positive integer zeros (for $n \geq 3$; for $n = 2$ this set is empty and $
K = 0 = n-2$).

**Verification that we don't get more:** For $x = n-1$, the function $t \mapsto
(t+1)^{n-1}$ has degree $n-1$ with leading coefficient $1$, so its $(n-1)$-th fo
rward difference is $(n-1)! \neq 0$. Thus $f(n-1) = (-1)^{n-1}(n-1)! \neq 0$, co
nfirming the zeros stop at $x = n-2$.

**Small cases check:**
- $n=2$: $f(x) = 1 - 2^x$, zero only at $x=0$ (not positive), so $K = 0 = n-2$.
✓
- $n=3$: $f(x) = 1 - 2\cdot 2^x + 3^x$; $f(1) = 1-4+3 = 0$, $f(2) = 1-8+9 = 2 \n
eq 0$, so $K = 1 = n-2$. ✓
- $n=4$: $f(x) = 1 - 3\cdot 2^x + 3\cdot 3^x - 4^x$; $f(1) = 0$, $f(2) = 0$, $f(
3) = -6 \neq 0$, so $K = 2 = n-2$. ✓

### Conclusion

The upper bound $K \leq n-2$ and the matching construction together yield:

$$\boxed{K = n - 2}.$$
