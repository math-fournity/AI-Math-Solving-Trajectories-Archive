## Proof

**Yes**, such a sequence exists.

**Key fact.** For an invertible matrix $M$, the 2-norm condition number is
$$\kappa_2(M) = \frac{\sigma_{\max}(M)}{\sigma_{\min}(M)},$$
the ratio of the largest to smallest singular value. Hence $\kappa_2(M)=1$ if an
d only if all singular values of $M$ are equal, which holds if and only if $M =
c\,Q$ for some scalar $c>0$ and some orthogonal matrix $Q$ (in the real case; un
itary in the complex case).

**Construction.** Fix any dimension $d\ge 1$ and define
$$M_n = \tfrac{1}{n}\, I_d \qquad (n = 1, 2, 3, \dots).$$

Each $M_n$ is invertible (so $\kappa_2$ is well-defined) and is a positive scala
r multiple of the identity, hence of an orthogonal matrix. All singular values o
f $M_n$ equal $\tfrac{1}{n}$, so
$$\kappa_2(M_n) = \frac{1/n}{1/n} = 1 \quad \text{for every } n.$$

On the other hand,
$$\det(M_n) = \left(\tfrac{1}{n}\right)^{d} \xrightarrow{n\to\infty} 0.$$

Thus $\lim_{n\to\infty}\det(M_n)=0$ while $\kappa_2(M_n)=1$ for all $n$.

**Remark on the mechanism.** The condition number $\kappa_2$ is *scale-invariant
*: multiplying a matrix by any nonzero scalar leaves $\kappa_2$ unchanged, since
 both $\sigma_{\max}$ and $\sigma_{\min}$ scale by the same factor. The determin
ant, however, is *not* scale-invariant — it scales by $c^d$. Therefore one can d
rive the determinant to zero by shrinking the overall scale, while the condition
 number remains fixed at $1$. The matrices $M_n$ remain invertible for every fin
ite $n$; only the *limit* is singular.
