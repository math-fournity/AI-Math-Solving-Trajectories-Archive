## Proof

**Setup.** A passcode is an ordered sequence of digits from {1,2,…,9} (0 is forb
idden), all distinct. The condition "exactly one digit equals the sum of all the
 other digits" is the key constraint.

**Reduction to a subset condition.** Let S be the set of digits used, with total
 T = ΣS. A digit d ∈ S equals the sum of the other digits iff d = T − d, i.e., 2
d = T, i.e., d = T/2. Since all digits are distinct, **at most one** digit can s
atisfy this. Hence "exactly one" holds precisely when:
- T is even, and
- T/2 ∈ S.

So the problem becomes: count all subsets S ⊆ {1,…,9} with |S| ≥ 3, T even, and
T/2 ∈ S, then multiply each by |S|! (every permutation of such a set is a valid
passcode).

**Why |S| ≥ 3.** For |S| = 1, the "sum of other digits" is 0, requiring the digi
t to be 0 (forbidden). For |S| = 2 with distinct digits a,b, the condition a = b
 is impossible. So |S| ≥ 3.

**Parametrizing by the special digit.** Let m = T/2 ∈ S. Then the remaining digi
ts form a set R ⊆ {1,…,9}\{m} with ΣR = m and |R| ≥ 2 (since |S| ≥ 3). Note m ≤
9, and the minimum sum of 4 distinct positive integers is 1+2+3+4 = 10 > 9, so |
R| ∈ {2,3} only.

**Enumerating R for each m.**

| m | Pairs {a,b}, a+b=m | Triples {a,b,c}, a+b+c=m | #pairs | #triples |
|---|---|---|---|---|
| 1 | none (min 1+2=3>1) | none | 0 | 0 |
| 2 | none (min 1+2=3>2) | none | 0 | 0 |
| 3 | {1,2} | none | 1 | 0 |
| 4 | {1,3} | none | 1 | 0 |
| 5 | {1,4},{2,3} | none | 2 | 0 |
| 6 | {1,5},{2,4} | {1,2,3} | 2 | 1 |
| 7 | {1,6},{2,5},{3,4} | {1,2,4} | 3 | 1 |
| 8 | {1,7},{2,6},{3,5} | {1,2,5},{1,3,4} | 3 | 2 |
| 9 | {1,8},{2,7},{3,6},{4,5} | {1,2,6},{1,3,5},{2,3,4} | 4 | 3 |

(Triples require m ≥ 6 since the minimum triple sum is 1+2+3 = 6; pairs require
m ≥ 3 since the minimum pair sum is 1+2 = 3.)

**Counting.** Each pair gives |S| = 3, contributing 3! = 6 passcodes. Each tripl
e gives |S| = 4, contributing 4! = 24 passcodes.

- Total pairs = 1+1+2+2+3+3+4 = **16** → 16 × 6 = 96.
- Total triples = 1+1+2+3 = **7** → 7 × 24 = 168.

**Total = 96 + 168 = 264.**
