**Proof.** Place the circumcircle of $\triangle ABC$ as the unit circle in the c
omplex plane, with circumcenter $O = 0$. Let $A = a$, $B = b$, $C = c$ with $|a|
 = |b| = |c| = 1$. The midpoint of $AB$ is
$$M = m = \frac{a+b}{2}, \qquad \bar{m} = \frac{1/a + 1/b}{2} = \frac{m}{ab}.$$

**Step 1: Find $K$.**

Since $K$ lies on the circumcircle of $ABC$, we have $|k| = 1$, so $\bar{k} = 1/
k$. The concyclicity of $O = 0$, $C = c$, $M = m$, $K = k$ requires the cross-ra
tio $\frac{c(m-k)}{m(c-k)}$ to be real, hence equal to its conjugate:
$$\frac{c(m-k)}{m(c-k)} = \frac{\bar{c}(\bar{m}-\bar{k})}{\bar{m}(\bar{c}-\bar{k
})} = \frac{(1/c)\bigl(m/(ab) - 1/k\bigr)}{(m/(ab))(1/c - 1/k)} = \frac{mk - ab}
{m(k-c)} = \frac{ab - mk}{m(c-k)}.$$
Equating: $c(m-k) = ab - mk$, giving $k(m - c) = ab - cm$, so
$$\boxed{k = \frac{ab - cm}{m - c} = \frac{2ab - c(a+b)}{a + b - 2c}.}$$
One verifies $|k| = 1$: since $\bar{k} = \frac{a+b-2c}{2ab - c(a+b)}$, we get $k
\bar{k} = 1$. ✓

**Step 2: Find $P = OM \cap CK$.**

The line through $O = 0$ and $M = m$ has equation $z\bar{m} = \bar{z}m$, i.e., $
\bar{z} = z/(ab)$.

The line through $C = c$ and $K = k$ (both on the unit circle) has equation $z +
 \bar{z}\,ck = c + k$.

Substituting $\bar{z} = z/(ab)$:
$$z\left(1 + \frac{ck}{ab}\right) = c + k \implies P = z = \frac{ab(c+k)}{ab + c
k}.$$

Compute the pieces:
$$c + k = \frac{c(a+b-2c) + 2ab - c(a+b)}{a+b-2c} = \frac{2(ab - c^2)}{a+b-2c},$
$
$$ab + ck = \frac{ab(a+b-2c) + c\bigl(2ab - c(a+b)\bigr)}{a+b-2c} = \frac{(a+b)(
ab - c^2)}{a+b-2c}.$$

Therefore
$$\boxed{P = \frac{ab \cdot 2(ab-c^2)/(a+b-2c)}{(a+b)(ab-c^2)/(a+b-2c)} = \frac{
2ab}{a+b}.}$$

(Note: $P = 1/\bar{M}$, the inverse of $M$ with respect to the circumcircle—cons
istent with $P \in OM$.)

**Step 3: Prove $\angle PAK = \angle MCB$.**

We show $\frac{k - a}{p - a} \cdot \frac{m - c}{b - c}$ is real, which gives $\a
rg\frac{k-a}{p-a} = \arg\frac{b-c}{m-c}$, i.e., $\angle PAK = \angle MCB$ (direc
ted angles mod $\pi$).

Compute each factor:
$$p - a = \frac{2ab}{a+b} - a = \frac{a(b-a)}{a+b},$$
$$k - a = \frac{2ab - c(a+b) - a(a+b-2c)}{a+b-2c} = \frac{(b-a)(a-c)}{a+b-2c},$$
$$m - c = \frac{a+b-2c}{2}.$$

Thus
$$\frac{k-a}{p-a} = \frac{(b-a)(a-c)/(a+b-2c)}{a(b-a)/(a+b)} = \frac{(a-c)(a+b)}
{a(a+b-2c)},$$
$$\frac{m-c}{b-c} = \frac{a+b-2c}{2(b-c)},$$

and the product is
$$R := \frac{k-a}{p-a}\cdot\frac{m-c}{b-c} = \frac{(a-c)(a+b)}{2a(b-c)}.$$

**Step 4: Verify $R$ is real.**

Using $\bar{a} = 1/a$, $\bar{b} = 1/b$, $\bar{c} = 1/c$:
$$\bar{R} = \frac{(1/a - 1/c)(1/a + 1/b)}{(1/a)(1/b - 1/c)} = \frac{\dfrac{(c-a)
(a+b)}{a^2bc}}{\dfrac{c-b}{abc}} = \frac{(c-a)(a+b)}{a(c-b)} = \frac{(a-c)(a+b)}
{a(b-c)} = R.$$

Since $\bar{R} = R$, the quantity $R$ is real. Therefore
$$\arg\frac{k-a}{p-a} = \arg\frac{b-c}{m-c} \pmod{\pi},$$
which is precisely $\angle PAK = \angle MCB$. $\blacksquare$
