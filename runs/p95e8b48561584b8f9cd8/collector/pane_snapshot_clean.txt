## Solution

I model the problem as follows. A "perfectly synchronized" schedule is a 3×n arr
ay in which every row is a permutation of {1,…,n} and every column is (as a set)
 a 3-term arithmetic progression with positive common difference. Since d>0, the
 three entries of each column are distinct.

**Key reduction.** In such an array each number k∈{1,…,n} appears exactly once i
n each of the 3 rows, hence exactly 3 times overall. Conversely, suppose we can
partition three copies of {1,…,n} (i.e. a multiset where each number has multipl
icity 3) into n triples, each triple being a 3-term AP with d>0. Build the bipar
tite (multi)graph H whose left vertices are the numbers 1,…,n and whose right ve
rtices are the n triples, with an edge joining number k to triple T whenever k∈T
. Each left vertex has degree 3 (each number is in exactly 3 triples) and each r
ight vertex has degree 3 (each triple has 3 elements), so H is 3-regular and bip
artite. By König's line-coloring theorem, H admits a proper 3-edge-coloring. Ass
igning color r to the edge (k,T) means placing number k in row r of column T. Pr
operness gives each column three distinct rows, and each number gets all three c
olors exactly once, so every row is a permutation of {1,…,n}.

Therefore **n works ⇔ three copies of {1,…,n} can be partitioned into n three-te
rm APs (d>0).**

---

**n=1, n=2: impossible.** A 3-term AP with d>0 needs three distinct values, but
{1} and {1,2} have fewer than 3 elements.

**n=3: works.** The only AP is {1,2,3}; use it three times. Each of 1,2,3 appear
s 3 times. ✓

**n=4: impossible.** The only 3-term APs inside {1,2,3,4} are {1,2,3} and {2,3,4
}. Number 1 occurs only in {1,2,3}, so it must be used 3 times; number 4 occurs
only in {2,3,4}, so it must be used 3 times. That already forces 3+3=6 triples,
but we need exactly 4. Contradiction.

**n=5: impossible.** Every 3-term AP inside {1,…,5} — namely {1,2,3},{2,3,4},{3,
4,5},{1,3,5} — contains the number 3. Hence 3 appears in all 5 triples, but it m
ay appear only 3 times. Contradiction.

**n=6: works.** Use {1,2,3} three times and {4,5,6} three times. Counts: 1,2,3 e
ach 3; 4,5,6 each 3. ✓

**n=7: works.** Use
{1,2,3},{1,2,3},{2,3,4},{4,5,6},{5,6,7},{5,6,7},{1,4,7}.
Counts: 1→3, 2→3, 3→3, 4→3, 5→3, 6→3, 7→3. ✓

**n=8: works.** Use
{1,4,7},{2,5,8},{1,3,5},{2,4,6},{3,5,7},{4,6,8},{1,2,3},{6,7,8}.
Counts: each of 1,…,8 appears exactly 3 times. ✓

**n=9: works.** Use
{1,4,7},{2,5,8},{3,6,9},{1,5,9},{2,4,6},{3,5,7},{1,2,3},{7,8,9},{4,6,8}.
Counts: each of 1,…,9 appears exactly 3 times. ✓

**n=10: works.** Use
{1,4,7},{2,5,8},{3,6,9},{4,7,10},{1,5,9},{2,6,10},{3,5,7},{4,6,8},{1,2,3},{8,9,1
0}.
Counts: each of 1,…,10 appears exactly 3 times. ✓

(Each listed triple is a genuine AP: the first groups have d=3, then d=4, d=2, d
=1 as indicated by their gaps.)

---

The admissible floors are n ∈ {3, 6, 7, 8, 9, 10}. Their sum is

3 + 6 + 7 + 8 + 9 + 10 = **43**.
