## Proof

**Yes**, such a sequence exists.

**Construction.** Let $X \sim \mathrm{Uniform}[0,1]$. Express $X$ in its binary
expansion
$$
X = \sum_{k=1}^{\infty} \frac{B_k}{2^k},
$$
where the $B_k$ are i.i.d. $\mathrm{Bernoulli}(1/2)$. (The set of dyadic rationa
ls in $[0,1]$ — those with two binary expansions — has Lebesgue measure zero, so
 the expansion is a.s. unique; we fix one convention there, which is irrelevant
for a.s. statements.)

For each $n \geq 1$, define the truncation
$$
X_n := \sum_{k=1}^{n} \frac{B_k}{2^k}.
$$

**Each $X_n$ is discrete.** $X_n$ takes values in the finite set
$$
\left\{ \frac{j}{2^n} : j = 0, 1, \dots, 2^n - 1 \right\},
$$
with $P(X_n = j/2^n) = 2^{-n}$ for each $j$. A random variable supported on a fi
nite set is discrete.

**The convergence is almost sure (in fact sure).** For every $\omega$ for which
the binary expansion is valid (i.e., outside the null set of dyadic rationals),
$$
|X_n(\omega) - X(\omega)| = \sum_{k=n+1}^{\infty} \frac{B_k(\omega)}{2^k} \leq \
sum_{k=n+1}^{\infty} \frac{1}{2^k} = \frac{1}{2^n} \xrightarrow{n\to\infty} 0.
$$
Hence $X_n \to X$ pointwise on a set of probability one, i.e., $X_n \to X$ almos
t surely.

**The limit is uniform on $[0,1]$.** By construction $X \sim \mathrm{Uniform}[0,
1]$.

**Conclusion.** The sequence $(X_n)$ of discrete (indeed finitely-supported) ran
dom variables converges almost surely to a $\mathrm{Uniform}[0,1]$ random variab
le. $\blacksquare$
