## 证明

设 $S = \sum_{i=1}^n \sum_{j=1}^n \left\lfloor \frac{ij}{n+1} \right\rfloor$。对
于每一对 $(i,j)$，带余除法给出 $ij = (n+1)\left\lfloor \frac{ij}{n+1} \right\rfl
oor + r_{ij}$，其中 $r_{ij} = ij \bmod (n+1) \in \{0,1,\dots,n\}$。求和得：

$$S = \frac{1}{n+1}\Biggl(\sum_{i=1}^n\sum_{j=1}^n ij \;-\; \sum_{i=1}^n\sum_{j=
1}^n r_{ij}\Biggr) = \frac{1}{n+1}\Biggl(\frac{n^2(n+1)^2}{4} - R\Biggr),$$

因为 $\sum_{i,j} ij = \bigl(\sum_i i\bigr)^2 = \frac{n^2(n+1)^2}{4}$，且记 $R :=
 \sum_{i,j} r_{ij}$。因此

$$4S = n^2(n+1) - \frac{4R}{n+1}.$$

所求不等式 $4S \ge n^2(n-1)$ 等价于

$$n^2(n+1) - \frac{4R}{n+1} \ge n^2(n-1) \iff \frac{4R}{n+1} \le 2n^2 \iff R \le
 \frac{n^2(n+1)}{2}. \tag{$\star$}$$

**计算 $R$。** 固定 $i$，设 $d = \gcd(i,\,n+1)$，并记 $m = (n+1)/d$，$i' = i/d$
，使得 $\gcd(i', m)=1$。则

$$r_{ij} = ij \bmod (n+1) = d\,(i'j \bmod m).$$

当 $j$ 取遍 $1, 2, \dots, n = md-1$ 时，值 $i'j \bmod m$（仅取决于 $j \bmod m$）
取 $0$ 共 $d-1$ 次，取 $\{1,\dots,m-1\}$ 中的每个值共 $d$ 次（因为 $\{0,1,\dots,
md-1\}$ 给出每个剩余类模 $m$ 恰好 $d$ 次，我们仅去掉了 $j=0$，它贡献了 $0$）。因
此

$$\sum_{j=1}^n (i'j \bmod m) = (d-1)\cdot 0 + d\sum_{k=1}^{m-1} k = d\cdot\frac{
m(m-1)}{2},$$

且

$$\sum_{j=1}^n r_{ij} = d \cdot d\cdot\frac{m(m-1)}{2} = d^2 \cdot \frac{\frac{n
+1}{d}\bigl(\frac{n+1}{d}-1\bigr)}{2} = \frac{(n+1)(n+1-d)}{2}. \tag{1}$$

对 $i$ 求和，其中 $d_i := \gcd(i, n+1)$：

$$R = \sum_{i=1}^n \frac{(n+1)(n+1 - d_i)}{2} = \frac{n+1}{2}\Biggl(n(n+1) - \su
m_{i=1}^n d_i\Biggr). \tag{2}$$

**完成 $(\star)$。** 由于每个 $d_i = \gcd(i, n+1) \ge 1$，我们有 $\sum_{i=1}^n d
_i \ge n$。代入 (2)：

$$R = \frac{n+1}{2}\Biggl(n(n+1) - \sum_{i=1}^n d_i\Biggr) \le \frac{n+1}{2}\big
l(n(n+1) - n\bigr) = \frac{n+1}{2}\cdot n^2 = \frac{n^2(n+1)}{2},$$

这恰好是 $(\star)$。不等式得证。$\blacksquare$

**等号情形。** 当且仅当 $\sum_{i=1}^n d_i = n$ 时等号成立，即当且仅当每个 $d_i =
 \gcd(i, n+1) = 1$ 对于 $i = 1, \dots, n$ 成立。这等价于 $n+1$ 与 $\{1, 2, \dots
, n\}$ 中的每个整数互质，这恰好说明 **$n+1$ 是素数**。

*验证。* $n=1$ ($n+1=2$，素数): $4\lfloor 1/2\rfloor = 0 = 1^2\cdot 0$. ✓
$n=2$ ($n+1=3$，素数): $4(0+0+0+1) = 4 = 2^2\cdot 1$. ✓
$n=4$ ($n+1=5$，素数): 直接计算可得 $4S = 48 = 4^2\cdot 3$. ✓
$n=3$ ($n+1=4$，合数): $4S = 20 > 18 = 3^2\cdot 2$. ✓ (严格不等号成立，正如预期
。)
