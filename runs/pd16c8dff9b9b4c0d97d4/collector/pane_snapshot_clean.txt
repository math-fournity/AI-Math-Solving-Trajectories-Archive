## Proof

**Setup.** A *ticket* is a permutation of {1, 2, ..., 50}. The *winning permutat
ion* σ is an unknown permutation of {1, ..., 50}. A *cell match* occurs at posit
ion *i* if the ticket's value at position *i* equals σ(i). We seek the minimum n
umber *k* of tickets such that for every permutation σ, at least one ticket matc
hes σ in at least one position.

Equivalently, we need a set of *k* permutations {τ₁, ..., τₖ} such that **no per
mutation σ is a derangement relative to all of them** — i.e., there is no σ with
 σ(i) ≠ τⱼ(i) for all positions *i* and all tickets *j*.

**Reformulation as a bipartite matching problem.** Given tickets τ₁, ..., τₖ, de
fine a bipartite graph *G* with left vertices = positions {1,...,50}, right vert
ices = values {1,...,50}, and edge (i, v) present iff v ∉ {τ₁(i), ..., τₖ(i)} (i
.e., v is *allowed* at position i). A perfect matching in *G* corresponds exactl
y to a permutation σ that is a derangement relative to all *k* tickets. Thus:

- The tickets **fail** (a derangement exists) iff *G* has a perfect matching.
- The tickets **succeed** iff *G* has **no** perfect matching, i.e., Hall's cond
ition fails for some subset *S* of positions: |N(S)| < |S|.

### Lower Bound: k ≤ 25 tickets never suffice

For any *k* ≤ 25 tickets, we show Hall's condition always holds, so a perfect ma
tching (derangement) always exists.

For any subset *S* of positions, let N(S) = set of values allowed at some positi
on in *S*. Then:

$$\{1,...,50\} \setminus N(S) = \{v : v \text{ is forbidden at every position in
 } S\} = \bigcap_{i \in S} \{\tau_1(i), \ldots, \tau_k(i)\}.$$

**Key observation:** A value *v* is forbidden at position *i* iff v = τⱼ(i) for
some *j*. Since each ticket τⱼ is a permutation, value *v* appears at exactly on
e position in each ticket, hence at **at most *k* positions** total across all t
ickets. Therefore:

- **If |S| > k:** No value *v* can be forbidden at all positions in *S* (since *
v* is forbidden at ≤ k < |S| positions). So the intersection is empty and N(S) =
 {1,...,50}, giving |N(S)| = 50 ≥ |S|. ✓

- **If |S| ≤ k:** Each set {τ₁(i),...,τₖ(i)} has size ≤ k, so the intersection h
as size ≤ k. Thus |{1,...,50} \ N(S)| ≤ k, giving |N(S)| ≥ 50 − k. Since k ≤ 25,
 we get |N(S)| ≥ 50 − 25 = 25 ≥ k ≥ |S|. ✓

In both cases, |N(S)| ≥ |S|, so **Hall's condition holds for every subset S**. B
y Hall's theorem, *G* has a perfect matching, so a derangement relative to all *
k* tickets exists. Therefore no set of k ≤ 25 tickets can guarantee a match. ∎

### Upper Bound: k = 26 tickets suffice

**Construction.** Let S = {1, 2, ..., 26} and C = {1, 2, ..., 26}. Define 26 tic
kets using a **Latin square of order 26** on S × C:

$$\tau_j(i) = ((i + j - 2) \bmod 26) + 1, \quad \text{for } i \in S,\ j = 1, \ld
ots, 26.$$

Extend each τⱼ to a full permutation by setting τⱼ(i) = i for i ∈ {27, ..., 50}.

**Verification.** For each position i ∈ S, the values {τ₁(i), ..., τ₂₆(i)} are a
ll distinct (Latin square property), so they equal C = {1,...,26}. Thus:

$$\text{Forbidden}(i) = \{1, 2, \ldots, 26\}, \quad \text{Allowed}(i) = \{27, 28
, \ldots, 50\} \quad \text{for all } i \in S.$$

Now consider the subset S = {1,...,26} in Hall's condition:

$$N(S) = \bigcup_{i \in S} \text{Allowed}(i) = \{27, 28, \ldots, 50\}, \quad |N(
S)| = 24.$$

Since |N(S)| = 24 < 26 = |S|, **Hall's condition fails**. Therefore *G* has no p
erfect matching, meaning no permutation σ is a derangement relative to all 26 ti
ckets. Every winning permutation must match at least one ticket in at least one
cell. ∎

- **k ≤ 25:** For any choice of tickets, a derangement always exists (Hall's con
