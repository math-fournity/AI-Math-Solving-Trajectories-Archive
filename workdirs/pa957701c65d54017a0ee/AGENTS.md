# Problem

In a sprawling subterranean fiber-optic network, there are 2019 primary server hubs arranged in a vast circle. Engineers have installed direct data cables connecting every possible pair of these hubs. The network layout is designed such that no three cables intersect at the exact same physical junction point within the circle.

Every point where two cables cross is referred to as a "relay node." Two relay nodes are considered "linked" if they are located on the same direct data cable. A "data cycle" is defined as a closed transmission path formed by connecting a sequence of relay nodes, provided that each node in the sequence is linked to the next and no three consecutive nodes in the path lie on the same cable.

A cybersecurity task force is deploying "sentinel programs" to monitor these relay nodes. However, to prevent feedback interference, they must ensure that no subset of the monitored nodes forms a "data cycle."

Calculate the maximum possible number of relay nodes that can be monitored by sentinel programs such that no data cycle is formed among the monitored nodes.
