## Proof

We determine the cardinality of the family of infinite subsets of $\mathbb{N}$.

Let $\mathcal{P}(\mathbb{N})$ denote the power set of $\mathbb{N}$, and let $\ma
thcal{F}$ denote the family of all **finite** subsets of $\mathbb{N}$, and $\mat
hcal{I}$ the family of all **infinite** subsets. Then
$$\mathcal{P}(\mathbb{N}) = \mathcal{F} \sqcup \mathcal{I},$$
a disjoint union, so $|\mathcal{I}| = |\mathcal{P}(\mathbb{N})| - |\mathcal{F}|$
 (in the cardinal sense).

**Step 1: $|\mathcal{P}(\mathbb{N})| = 2^{\aleph_0}$.**

This is the standard result: the power set of a countably infinite set has cardi
nality $2^{\aleph_0}$, which is uncountable (by Cantor's theorem).

**Step 2: $|\mathcal{F}| = \aleph_0$ (the finite subsets are countable).**

For each $n \in \mathbb{N}$, let $\mathcal{F}_n = \{F \subseteq \mathbb{N} : |F|
 = n\}$ be the family of $n$-element subsets. Each $\mathcal{F}_n$ is countable:
 indeed, the map sending an $n$-element subset $\{a_1 < a_2 < \cdots < a_n\}$ to
 the natural number $2^{a_1} + 2^{a_2} + \cdots + 2^{a_n}$ (its characteristic-v
ector binary encoding) is an injection $\mathcal{F}_n \hookrightarrow \mathbb{N}
$, so $|\mathcal{F}_n| \le \aleph_0$. (In fact $|\mathcal{F}_n| = \aleph_0$ for
$n \ge 1$, but the upper bound suffices.)

Therefore
$$\mathcal{F} = \bigcup_{n=0}^{\infty} \mathcal{F}_n$$
is a countable union of countable sets, hence countable: $|\mathcal{F}| \le \ale
ph_0$. Since $\mathcal{F}$ is infinite (it contains all singletons), $|\mathcal{
F}| = \aleph_0$.

**Step 3: $|\mathcal{I}| = 2^{\aleph_0}$.**

Since $\mathcal{P}(\mathbb{N}) = \mathcal{F} \sqcup \mathcal{I}$ and $|\mathcal{
P}(\mathbb{N})| = 2^{\aleph_0}$ is uncountable while $|\mathcal{F}| = \aleph_0$
is countable, removing a countable set from an uncountable set of cardinality $2
^{\aleph_0}$ leaves a set of the same cardinality. Formally, $\mathcal{I}$ is un
countable (since a countable set cannot be the complement of a countable set wit
hin an uncountable set), so $|\mathcal{I}| > \aleph_0$. On the other hand $|\mat
hcal{I}| \le |\mathcal{P}(\mathbb{N})| = 2^{\aleph_0}$.

To pin down the exact value: we exhibit an injection $\mathcal{P}(\mathbb{N}) \h
ookrightarrow \mathcal{I}$. Define $\phi: \mathcal{P}(\mathbb{N}) \to \mathcal{I
}$ by
$$\phi(A) = \{2n : n \in \mathbb{N}\} \cup \{2n+1 : n \in A\}.$$
For every $A \subseteq \mathbb{N}$, the set $\phi(A)$ contains all even natural
numbers, hence is infinite; and $\phi$ is injective because $A$ is recoverable f
rom $\phi(A)$ via $A = \{n : 2n+1 \in \phi(A)\}$. Thus $|\mathcal{I}| \ge |\math
cal{P}(\mathbb{N})| = 2^{\aleph_0}$.

Combined with $|\mathcal{I}| \le 2^{\aleph_0}$, by the Cantor–Schröder–Bernstein
 theorem,
$$|\mathcal{I}| = 2^{\aleph_0}.$$

**Conclusion.** The number of infinite subsets of $\mathbb{N}$ is $2^{\aleph_0}$
, the cardinality of the continuum.
