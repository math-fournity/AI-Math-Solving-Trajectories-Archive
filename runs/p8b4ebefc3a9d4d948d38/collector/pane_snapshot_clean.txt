Looking at this problem, I need to determine whether for any permutation ω of ℤ
and any ε > 0, there exists a syndetic set A with D⁺(ω(A)) < ε.

**Answer: Yes.**

**Proof.**

Let ω: ℤ → ℤ be a permutation and let ε > 0. Set σ = ω⁻¹. Choose an integer G >
1/ε.

**Step 1: Two partitions.** Partition the codomain of σ (i.e., ℤ) into consecuti
ve blocks I_k = [kG, (k+1)G) for k ∈ ℤ. Define S_k = σ⁻¹(I_k). Since σ is a bije
ction, {S_k} is a partition of the domain of σ into sets of size G.

Separately, partition the domain of σ into consecutive blocks J_m = [mG, (m+1)G)
 for m ∈ ℤ.

**Step 2: Bipartite matching via Hall's theorem.** Form a bipartite graph with l
eft part X = {S_k} and right part Y = {J_m}, where S_k ~ J_m iff S_k ∩ J_m ≠ ∅.

Each S_k has G elements, so it meets at most G blocks J_m (finite degree). For a
ny finite subset 𝒮 ⊆ X, the union ⋃_{S_k ∈ 𝒮} S_k has exactly G|𝒮| elements (dis
jointness). Each block J_m contains at most G of these, so the number of blocks
intersecting the union is at least G|𝒮|/G = |𝒮|. Hall's condition is satisfied.

By the infinite Hall's marriage theorem (for locally finite bipartite graphs), t
here exists a matching covering every vertex in X. This assigns each S_k a *dist
inct* block J_{m(k)} with S_k ∩ J_{m(k)} ≠ ∅.

**Step 3: Construct B.** For each k, pick b_k ∈ S_k ∩ J_{m(k)} and set B = {b_k
: k ∈ ℤ}.

**Step 4: B has low upper uniform density.** Since the matching is injective, ea
ch block J_m contains at most one element of B. Any interval [x, x+N) intersects
 at most ⌈N/G⌉ + 1 blocks J_m, so:

|B ∩ [x, x+N)| ≤ ⌈N/G⌉ + 1 ≤ N/G + 2.

Therefore:

D⁺(B) = lim_{N→∞} sup_x |B ∩ [x,x+N)| / N ≤ 1/G < ε.

**Step 5: A = σ(B) is syndetic.** Since b_k ∈ S_k = σ⁻¹(I_k), we have σ(b_k) ∈ I
_k for every k. Thus σ(B) intersects every block I_k = [kG, (k+1)G). Any interva
l of length 2G contains at least one complete block I_k, hence contains an eleme
nt of σ(B). So σ(B) is syndetic with gap at most 2G.

**Conclusion.** Set A = σ(B) = ω⁻¹(B). Then A is syndetic, and ω(A) = ω(ω⁻¹(B))
= B, so D⁺(ω(A)) = D⁺(B) < ε. ∎
