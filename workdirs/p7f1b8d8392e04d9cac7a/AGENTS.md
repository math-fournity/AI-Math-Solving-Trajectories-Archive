# Problem

In a cutting-edge data center, an engineer is organizing 100 unique server modules, labeled with identification codes from 1 to 100, into a square high-density rack system. The rack is configured as a 10x10 grid, containing exactly 100 slots arranged in 10 horizontal shelves and 10 vertical columns.

The engineer must install every module into the grid so that each slot contains exactly one module. Once the installation is complete, the "thermal tension" of a row or column is defined as the maximum difference between any two identification codes located within that same line (either horizontally or vertically).

The engineer wants to know the guaranteed minimum thermal tension that will exist in at least one line of the rack, regardless of how the modules are arranged.

What is the greatest positive integer $A$ such that, no matter how the identification codes $1, 2, \ldots, 100$ are distributed across the 10x10 grid, there will always exist at least one pair of modules in the same shelf or the same column whose codes differ by at least $A$?
