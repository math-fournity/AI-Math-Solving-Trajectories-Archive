Proof

Claim: Yes. There exists a polynomial-time algorithm to find an optimal point of
a linear program, even when the feasible region (polyhedron) is unbounded.

Setup

Consider the linear program

$$\min; c^\top x \quad \text{s.t.}\quad Ax \le b,; x \ge 0, \tag{LP}$$

where $A \in \mathbb{Z}^{m \times n}$, $b \in \mathbb{Z}^m$, $c \in \mathbb{Z}
^n$, and all entries have bit-length bounded by $L$. The feasible region $P = {x
: Ax \le b,; x \ge 0}$ is a polyhedron that may be unbounded. We show that an
optimal solution (if one exists) can be found in time polynomial in the input
size $(m, n, L)$, regardless of whether $P$ is bounded.

Step 1: Reduction to a bounded region when the optimum is finite

Suppose (LP) has a finite optimum. Then there exists an optimal basic feasible
solution (BFS). A BFS is determined by selecting $n$ linearly independent tight
constraints; its components are ratios of subdeterminants of the constraint
matrix. Concretely, each component $x_j$ of a BFS equals $\det(B_j)/\det(B)$ for
some $n \times n$ submatrix $B$ of the constraint system, where $B_j$ is $B$
with one column replaced.

By the Hadamard bound, $|\det(B)| \le \prod_i |b_i| \le (2^L \sqrt{n})^n$, so
every component of every BFS satisfies

$$|x_j| \le \frac{(2^L\sqrt n)^n}{1} \le 2^{n(L + \frac12 \log n)}.$$

Thus every BFS (hence every optimal BFS) lies in the box $[-M, M]^n$ with $M =
2^{nL + n}$, which has bit-length $O(nL)$ — polynomial in the input. Define the
bounded LP:

$$\min; c^\top x \quad \text{s.t.}\quad Ax \le b,; x \ge 0,; x \le M\mathbf{1}.
\tag{LP'}$$

Since every optimal BFS of (LP) lies in this box, (LP') has the same optimal
value as (LP), and every optimal solution of (LP') is optimal for (LP).

Step 2: Solving the bounded LP in polynomial time

The feasible region of (LP') is a bounded polytope $P' \subseteq [-M, M]^n$
contained in a ball of radius $R = M\sqrt{n}$ and (if nonempty and full-
dimensional) containing a ball of radius $r = 2^{-\text{poly}(m,n,L)}$ (the
latter follows from standard bit-complexity bounds on the volume / inscribed
ball of a rational polytope, via the same determinant bounds).

Khachiyan's ellipsoid method (1979) solves the feasibility problem for such a
polytope using a separation oracle in $O(n^2 \cdot \text{polylog}(R/r)) =
\text{poly}(m, n, L)$ iterations, each calling the oracle (which is just
checking $Ax \le b$) in polynomial time. Optimization is reduced to feasibility
via binary search on the objective value $v$, testing feasibility of ${x \in
P' : c^\top x \le v}$, which is itself a polytope with a polynomial separation
oracle.

Alternatively, Karmarkar's interior-point method (1984) and its successors solve
(LP') directly in $\text{poly}(m, n, L)$ arithmetic operations, with no
requirement that the original polyhedron be bounded — the algorithm works on the
standard-form LP and its dual simultaneously.

Step 3: Handling the unbounded-optimum case

If (LP) has no finite optimum (the objective is unbounded below on $P$), this is
detected during the algorithm: the binary search on $v$ never finds
infeasibility, or the ellipsoid method / interior-point method reports that the
objective can be driven to $-\infty$. This detection also runs in polynomial
time, because unboundedness is witnessed by an extreme ray of $P$ along which
$c^\top x \to -\infty$, and such a ray has polynomially-bounded bit complexity
(same determinant argument as for vertices). Equivalently, by LP duality, (LP)
is unbounded iff the dual is infeasible — and infeasibility is detectable in
polynomial time by the same algorithms.

Step 4: Conclusion

Combining the steps:

  1. If (LP) is unbounded → detected in polynomial time (Step 3).
  2. If (LP) has a finite optimum → reduced to bounded (LP') with the same
  optimum (Step 1) → solved in polynomial time by the ellipsoid or interior-
  point method (Step 2).

In both cases the running time is polynomial in $(m, n, L)$, and the algorithm
works regardless of whether $P$ is bounded. The unboundedness of the polyhedron
introduces no additional computational difficulty: it is either detected
(unbounded objective) or circumvented by the polynomial bound on optimal vertex
bit-sizes (finite optimum).

of a linear program even when the polytope is unbounded. $\blacksquare$
