## Proof

**Problem:** Three dimensions $x, y, z$ of a rectangular prism satisfy $x + y +
z = L = 18$. Find $V_{\max} = \max(xyz)$ and $S_{\max} = \max\,2(xy + yz + zx)$,
 then compute $V_{\max} + S_{\max}$.

### Maximum of Volume $V = xyz$

By the AM–GM inequality applied to the positive reals $x, y, z$:

$$\frac{x+y+z}{3} \geq \sqrt[3]{xyz}$$

$$\frac{18}{3} = 6 \geq \sqrt[3]{xyz}$$

$$xyz \leq 216$$

Equality holds if and only if $x = y = z = 6$, which satisfies the constraint $6
+6+6 = 18$.

$$\boxed{V_{\max} = 216}$$

### Maximum of Surface Area $S = 2(xy + yz + zx)$

We maximize $f = xy + yz + zx$ subject to $x + y + z = 18$ with $x, y, z > 0$.

Using the identity:

$$(x+y+z)^2 = x^2 + y^2 + z^2 + 2(xy + yz + zx)$$

$$2(xy + yz + zx) = 324 - (x^2 + y^2 + z^2)$$

So maximizing $S$ is equivalent to **minimizing** $x^2 + y^2 + z^2$ subject to $
x + y + z = 18$.

By the Cauchy–Schwarz inequality (or QM–AM):

$$x^2 + y^2 + z^2 \geq \frac{(x+y+z)^2}{3} = \frac{324}{3} = 108$$

with equality if and only if $x = y = z = 6$.

Therefore:

$$S_{\max} = 324 - 108 = 216$$

**Verification that this is a global maximum (not a boundary case):** On the bou
ndary where, say, $z \to 0$ and $x + y = 18$, we get $f = xy \leq 81$ (max at $x
 = y = 9$), giving $S = 162 < 216$. The interior critical point dominates every
boundary value, confirming $x = y = z = 6$ gives the global maximum.

$$\boxed{S_{\max} = 216}$$

### Final Sum

$$V_{\max} + S_{\max} = 216 + 216 = \boxed{432}$$
