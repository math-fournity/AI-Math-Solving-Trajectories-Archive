**Problem.** Find the extreme points of the unit ball of $M_n(\mathbb{C})$.

We take the unit ball with respect to the operator (spectral) norm $\|A\| = \sup
_{\|x\|=1}\|Ax\|$, the canonical norm on the $C^*$-algebra $M_n(\mathbb{C})$:

$$\mathcal{B} = \{A \in M_n(\mathbb{C}) : \|A\| \le 1\}.$$

**Claim.** The extreme points of $\mathcal{B}$ are exactly the unitary matrices,
 i.e. $\mathcal{U}(n) = \{U \in M_n(\mathbb{C}) : U^*U = UU^* = I\}$.

---

### Proof

#### Direction 1: Every unitary matrix is an extreme point.

Let $U$ be unitary and suppose $U = \tfrac{1}{2}(A+B)$ with $A, B \in \mathcal{B
}$. We show $A = B = U$.

For any unit vector $x \in \mathbb{C}^n$, since $U$ is unitary, $\|Ux\| = 1$. We
 have

$$Ux = \tfrac{1}{2}(Ax + Bx), \quad \|Ax\| \le 1, \quad \|Bx\| \le 1.$$

By the triangle inequality,

$$1 = \|Ux\| \le \tfrac{1}{2}\|Ax\| + \tfrac{1}{2}\|Bx\| \le 1.$$

Hence equality holds throughout: $\|Ax\| = \|Bx\| = 1$ and $\|Ax + Bx\| = \|Ax\|
 + \|Bx\| = 2$.

Equality in the triangle inequality for a Hilbert space requires the two vectors
 to be positively collinear: $\operatorname{Re}\langle Ax, Bx\rangle = \|Ax\|\|B
x\| = 1$, which by the equality case of Cauchy–Schwarz forces $Ax = Bx$ (both ha
ve norm $1$, so the proportionality constant is $1$). Then $Ux = \tfrac{1}{2}(Ax
 + Bx) = Ax = Bx$.

Since $Ax = Ux$ for every unit vector $x$, we conclude $A = U$; likewise $B = U$
. Therefore $U$ is extreme. $\checkmark$

#### Direction 2: Every non-unitary element of $\mathcal{B}$ is not an extreme p
oint.

Let $A \in \mathcal{B}$.

**Case (a): $\|A\| < 1$.** Then $A$ lies in the interior of $\mathcal{B}$, so it
 cannot be extreme (any interior point of a convex body is a non-trivial midpoin
t: pick any nonzero $C$ with $\|C\|$ small enough that $A \pm C \in \mathcal{B}$
).

**Case (b): $\|A\| = 1$ but $A$ is not unitary.** Take the singular value decomp
osition $A = U\Sigma V^*$, where $U, V$ are unitary and $\Sigma = \operatorname{
diag}(\sigma_1, \dots, \sigma_n)$ with $1 = \sigma_1 \ge \sigma_2 \ge \cdots \ge
 \sigma_n \ge 0$.

Since $A$ is not unitary, $A^*A \neq I$, so not all singular values equal $1$; t
here exists an index $k$ with $\sigma_k < 1$. Choose $\varepsilon > 0$ small eno
ugh that $\sigma_k + \varepsilon \le 1$ (and $\sigma_k - \varepsilon \ge 0$ if d
esired, though only $|\sigma_k \pm \varepsilon| \le 1$ is needed). Define the di
agonal matrix

$$E = \varepsilon \, e_k e_k^* = \operatorname{diag}(0, \dots, 0, \varepsilon, 0
, \dots, 0).$$

Set $A_+ = U(\Sigma + E)V^*$ and $A_- = U(\Sigma - E)V^*$. Then:

- $A = \tfrac{1}{2}(A_+ + A_-)$.
- $A_+ \neq A_-$ since $\varepsilon > 0$.
- $\|A_\pm\| = \|\Sigma \pm E\| = \max_i |\sigma_i \pm \varepsilon\,\delta_{ik}|
$. For $i \neq k$ this is $\sigma_i \le 1$; for $i = k$ it is $|\sigma_k \pm \va
repsilon| \le 1$ by our choice of $\varepsilon$. Hence $\|A_\pm\| \le 1$, so $A_
\pm \in \mathcal{B}$.

Thus $A$ is a non-trivial midpoint of two distinct elements of $\mathcal{B}$, so
 $A$ is not extreme. $\checkmark$

---

### Conclusion

Combining both directions, the extreme points of the closed unit ball $\{A \in M
_n(\mathbb{C}) : \|A\| \le 1\}$ are precisely the **unitary matrices**:

$$\operatorname{Ext}(\mathcal{B}) = \mathcal{U}(n) = \{U \in M_n(\mathbb{C}) : U
^*U = I\}.$$
