## 解答

题目要求确定从 ω 到 ω 的所有函数集合的**基数**（即 |ω^ω|）。

### 证明

设 F = ω^ω 为从 ω 到 ω 的所有函数的集合。我们证明 |F| = 2^{ℵ₀} = 𝔠（连续统的基数
）。

**上界：** 每个函数 f: ω → ω 是其图——即 ω × ω 的一个子集，满足对于每个 n ∈ ω，存
在唯一的 m，使得 (n, m) ∈ graph(f)。因此 F ⊆ P(ω × ω)。由于 |ω × ω| = ℵ₀，我们得
到

|F| ≤ |P(ω × ω)| = 2^{|ω × ω|} = 2^{ℵ₀}.

**下界：** 定义一个映射 Φ: P(ω) → F，将每个子集 A ⊆ ω 映射为其特征函数 χ_A: ω →
ω，定义如下：

χ_A(n) = 1 如果 n ∈ A，χ_A(n) = 0 如果 n ∉ A。

此映射是单射：如果 A ≠ B，则存在某个 n 属于其中一个而不属于另一个，因此 χ_A(n) ≠
 χ_B(n)。因此 |P(ω)| ≤ |F|，即

2^{ℵ₀} ≤ |F|.

**结论：** 结合这两个不等式，

2^{ℵ₀} ≤ |F| ≤ 2^{ℵ₀},

因此 |ω^ω| = 2^{ℵ₀} = 𝔠.

从 ω 到 ω 的所有函数集合的秩（基数）为 **2^{ℵ₀}**，即连续统的基数。
