## Solution

n sketches, or formalization notes. Proceeding.

---

### Step 1: Identify the boundary $\partial S$

The surface $S$ is the graph of $z = x^2+y^2$ over the closed unit disk $B$. Its
 boundary is the rim circle:

$$\partial S = \{(x,y,z) \in \mathbb{R}^3 : x^2+y^2 = 1,\; z = 1\}.$$

The parametrization $\alpha(x,y)=(x,y,x^2+y^2)$ induces the normal

$$\alpha_x \times \alpha_y = (1,0,2x)\times(0,1,2y) = (-2x,\,-2y,\,1),$$

whose $z$-component is $+1$ (upward orientation). By the induced orientation con
vention, $\partial S$ is traversed **counterclockwise** when viewed from above.

---

### Step 2: Apply Stokes' Theorem

Let $\omega = \cos(z)\,dx + (xz+\tan y)\,dy + y^2z^3\,dz$, i.e. $P=\cos z$, $Q=x
z+\tan y$, $R=y^2z^3$. Stokes' Theorem gives

$$\int_{\partial S}\omega = \int_S d\omega.$$

Compute $d\omega = (Q_x-P_y)\,dx\wedge dy + (R_y-Q_z)\,dy\wedge dz + (P_z-R_x)\,
dz\wedge dx$:

- $Q_x - P_y = z - 0 = z$
- $R_y - Q_z = 2yz^3 - x$
- $P_z - R_x = -\sin z - 0 = -\sin z$

$$d\omega = z\,dx\wedge dy + (2yz^3-x)\,dy\wedge dz - \sin z\,dz\wedge dx.$$

---

### Step 3: Pull back to $B$

On $S$, $z = x^2+y^2$ and $dz = 2x\,dx + 2y\,dy$, so:

$$dy\wedge dz = dy\wedge(2x\,dx+2y\,dy) = -2x\,dx\wedge dy,$$
$$dz\wedge dx = (2x\,dx+2y\,dy)\wedge dx = -2y\,dx\wedge dy.$$

Therefore

$$\alpha^*(d\omega) = \bigl[z + (2yz^3-x)(-2x) + (-\sin z)(-2y)\bigr]\,dx\wedge
dy$$

$$= \bigl[z - 4xyz^3 + 2x^2 + 2y\sin z\bigr]\,dx\wedge dy.$$

Substituting $z = x^2+y^2$:

$$\alpha^*(d\omega) = \bigl[3x^2 + y^2 - 4xy(x^2+y^2)^3 + 2y\sin(x^2+y^2)\bigr]\
,dx\wedge dy.$$

---

### Step 4: Integrate over the unit disk $B$

$$\int_S d\omega = \iint_B \bigl[3x^2+y^2 - 4xy(x^2+y^2)^3 + 2y\sin(x^2+y^2)\big
r]\,dA.$$

Evaluate each term:

1. **$\iint_B (3x^2+y^2)\,dA$:** By symmetry $\iint_B x^2\,dA = \iint_B y^2\,dA
= \frac{\pi}{4}$ (in polar: $\int_0^{2\pi}\cos^2\theta\,d\theta \cdot \int_0^1 r
^3\,dr = \pi\cdot\frac{1}{4}$). Hence $3\cdot\frac{\pi}{4}+\frac{\pi}{4} = \pi$.

2. **$\iint_B -4xy(x^2+y^2)^3\,dA$:** The integrand is odd in $x$ (for fixed $y$
) and $B$ is symmetric in $x$, so this equals $0$.

3. **$\iint_B 2y\sin(x^2+y^2)\,dA$:** The integrand is odd in $y$ and $B$ is sym
metric in $y$, so this equals $0$.

---

### Result

$$\int_{\partial S}\omega = \int_S d\omega = \pi + 0 + 0 = \boxed{\pi}.$$
