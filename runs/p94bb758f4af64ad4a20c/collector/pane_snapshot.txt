**Answer.** The minimum possible number of edges is

$$\boxed{\begin{cases} 4, & n=4,\\[2pt] n-1, & n\ge 5. \end{cases}}$$

**Proof.**

An edge may be removed exactly when it lies in a 4-cycle. The process terminates
 precisely when the graph contains no 4-cycle (is $C_4$-free); since removing ed
ges only decreases the edge count, the minimum is attained at a terminal ($C_4$-
free) graph.

**Connectivity invariant.** An edge that lies in a 4-cycle lies in a cycle, henc
e is not a bridge. Removing a non-bridge preserves connectivity. Since $K_n$ is
connected, every graph appearing during the process is connected. Therefore ever
y terminal graph has at least $n-1$ edges.

---

**Upper bound for $n\ge 5$: a tree is reachable.** We prove by induction on $n\g
e 5$ that $K_n$ can be reduced to a tree (exactly $n-1$ edges).

*Base case $n=5$.* Label the vertices $1,2,3,4,5$. Perform the following removal
s (each edge listed lies in the displayed 4-cycle at the moment of removal):

1. remove $13$ — 4-cycle $1\!-\!3\!-\!4\!-\!2\!-\!1$;
2. remove $24$ — 4-cycle $2\!-\!4\!-\!3\!-\!5\!-\!2$;
3. remove $25$ — 4-cycle $2\!-\!5\!-\!4\!-\!1\!-\!2$;
4. remove $45$ — 4-cycle $4\!-\!5\!-\!3\!-\!1\!-\!4$;
5. remove $35$ — 4-cycle $3\!-\!5\!-\!1\!-\!2\!-\!3$;
6. remove $12$ — 4-cycle $1\!-\!2\!-\!3\!-\!4\!-\!1$.

The surviving edges are $\{14,15,23,34\}$, which form the path $5\!-\!1\!-\!4\!-
\!3\!-\!2$: a tree with $4=n-1$ edges.

*Inductive step ($n\ge 6$).* Assume $K_{n-1}$ can be reduced to a tree. In $K_n$
 on $\{1,\dots,n\}$, remove the edges $n2,n3,\dots,n(n{-}1)$ in this order, reta
ining only $n1$. When removing $ni$ ($2\le i\le n-1$), choose any $j\in\{2,\dots
,n-1\}\setminus\{i\}$ (nonempty since $n\ge 6$); the 4-cycle $n\!-\!i\!-\!j\!-\!
1\!-\!n$ uses edges $ni,ij,j1,1n$, all present ($ij,j1$ lie in the untouched $K_
{n-1}$, and $1n$ is retained). Hence every $ni$ is removable. Afterwards vertex
$n$ is pendant (its only edge is $1n$), so it lies in no 4-cycle. Reducing the $
K_{n-1}$ on $\{1,\dots,n-1\}$ to a tree (inductive hypothesis) does not involve
vertex $n$; attaching the pendant edge $1n$ yields a tree on $n$ vertices with $
n-1$ edges.

Thus for $n\ge 5$ a tree with $n-1$ edges is reachable, matching the connectivit
y lower bound.

$$\text{Min}=n-1\quad\text{for }n\ge 5.$$

---

**The case $n=4$: a tree is unreachable, so the minimum is $4$.**

To reach $3$ edges (a tree), the final removal takes a $4$-edge graph to a $3$-e
dge graph; the removed edge must lie in a $4$-cycle, so the $4$-edge graph conta
ins a $4$-cycle. A $4$-edge graph on $4$ vertices is necessarily connected (a di
sconnected graph on $4$ vertices has at most $3$ edges) with exactly one cycle;
if that cycle is a $4$-cycle, the graph is $C_4=K_4$ minus a perfect matching. T
he three perfect matchings of $K_4$ are $\{13,24\},\{14,23\},\{12,34\}$.

We show no such $C_4$ is reachable. Consider $C_4=K_4\setminus\{13,24\}$; both $
13$ and $24$ must be removed. Suppose $13$ is removed first. The remaining graph
 $\{12,14,23,24,34\}$ has a unique $4$-cycle, namely $1\!-\!2\!-\!3\!-\!4\!-\!1$
 (edges $12,23,34,14$). The edge $24$ lies in no $4$-cycle: a $4$-cycle through
$24$ must use the two remaining vertices $1,3$ as intermediates, requiring edge
$13$, which is already gone. Hence $24$ cannot be removed next. By symmetry, the
 two edges of any perfect matching can never both be removed. Therefore no $C_4$
 is reachable, no tree is reachable, and the minimum is $\ge 4$.

Four edges is attainable: from $K_4$ remove $13$ (4-cycle $1\!-\!3\!-\!4\!-\!2\!
-\!1$), then remove $12$ (4-cycle $1\!-\!2\!-\!3\!-\!4\!-\!1$). The remaining ed
ges $\{14,23,24,34\}$ form a triangle $234$ with pendant edge $14$, which is $C_
4$-free.

$$\text{Min}=4\quad\text{for }n=4.$$

$\blacksquare$
