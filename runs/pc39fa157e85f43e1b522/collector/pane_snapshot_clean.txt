Answer: Yes. Such a function exists. Here is the construction and proof.

────────────────────────────────────────────────────────────────────────────────

Construction. Let $c:[0,1]\to[0,1]$ be the Cantor (devil's staircase) function,
and define $$g(x)=c(x)+x,\qquad x\in[0,1].$$ Since $c$ is non-decreasing and
$x\mapsto x$ is strictly increasing, $g$ is strictly increasing and continuous,
hence a homeomorphism $[0,1]\to[0,2]$. Let $f:=g^{-1}:[0,2]\to[0,1]$. We claim
$f$ is the desired function.

────────────────────────────────────────────────────────────────────────────────

Step 1: $f^{-1}$ maps every Borel set to a measurable set.

Since $g$ is a homeomorphism, it maps Borel sets to Borel sets. For any Borel
set $B\subseteq[0,1]$, $$f^{-1}(B)=g(B),$$ which is Borel, hence Lebesgue
measurable. So $f$ is (Lebesgue) measurable, satisfying the first condition.

────────────────────────────────────────────────────────────────────────────────

Step 2: $g$ maps the null Cantor set $C$ to a set of measure $1$.

Let $C$ be the Cantor set ($\lambda(C)=0$). The complement $[0,1]\setminus
C=\bigcup_n(a_n,b_n)$ is a countable disjoint union of open intervals with $
\sum_n(b_n-a_n)=1$. On each such interval $c$ is constant, so $$g(b_n)-
g(a_n)=(b_n-a_n)+\bigl(c(b_n)-c(a_n)\bigr)=(b_n-a_n).$$ Since $g$ is injective,
the images $g(a_n,b_n)$ are disjoint, so $$\lambda\bigl(g([0,1]\setminus
C)\bigr)=\sum_n(b_n-a_n)=1.$$ As $g([0,1])=[0,2]$ has measure $2$, we get $$
\lambda(g(C))=2-1=1.$$

────────────────────────────────────────────────────────────────────────────────

Step 3: A measurable set whose $f$-preimage is non-measurable.

Since $g(C)$ has positive measure, it contains a non-Lebesgue-measurable set
$V\subseteq g(C)$ (by Vitali's theorem / existence of non-measurable subsets of
positive-measure sets). Define $$M:=g^{-1}(V)\subseteq C.$$ Since $M\subseteq C$
and $\lambda(C)=0$, the set $M$ is Lebesgue measurable (with measure $0$).

Now compute the preimage under $f$: $$f^{-1}(M)=g(M)=g\bigl(g^{-1}(V)\bigr)=V.$$
But $V$ is not Lebesgue measurable. Thus $f^{-1}$ maps the measurable set $M$ to
a non-measurable set.

────────────────────────────────────────────────────────────────────────────────

Conclusion. The function $f=g^{-1}:[0,2]\to[0,1]$ (where $g(x)=c(x)+x$) is
continuous, hence $f^{-1}(B)$ is Borel (in particular measurable) for every
Borel set $B$, yet there exists a Lebesgue measurable set $M\subseteq C$ (a
subset of the null Cantor set) such that $f^{-1}(M)=V$ is non-measurable.

Therefore, yes, such a function exists. $\blacksquare$
