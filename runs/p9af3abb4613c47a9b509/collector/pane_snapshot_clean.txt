Looking at this problem, I need to determine whether for every integer $k > 1$,
there exist natural numbers $w_1, \ldots, w_k$ (all $\neq 1$) and an odd prime $
p$ such that $p \mid \sum w_i^2$ but $p \nmid w_i$ for all $i$.

**Answer: Yes.**

**Proof.**

We handle two cases.

**Case 1: $k$ has an odd prime factor $p$.**

Set $w_1 = w_2 = \cdots = w_k = p + 1$. Then:
- Each $w_i = p+1 \geq 4 \neq 1$. ✓
- $p \nmid (p+1)$, so $p$ does not divide any $w_i$. ✓
- $\sum_{i=1}^k w_i^2 = k(p+1)^2$. Since $p \mid k$, we have $p \mid k(p+1)^2$.
✓
- $p \neq 2$ since $p$ is an odd prime. ✓

**Case 2: $k = 2^m$ for some $m \geq 1$ (i.e., $k$ is a power of 2).**

We use $p = 5$. Choose $w_i \in \{2, 4\}$ for each $i$: let $a$ of the $w_i$ equ
al $4$ and the remaining $k - a$ equal $2$, where $a$ is the unique integer with
 $0 \leq a \leq 4$ and $a \equiv 3k \pmod{5}$.

*Verification that $0 \leq a \leq k$:* Since $k = 2^m$, the residue $3k = 3 \cdo
t 2^m \pmod{5}$ cycles with period 4 as $m$ increases:
$$m=1: 1,\quad m=2: 2,\quad m=3: 4,\quad m=4: 3,\quad m=5: 1, \ldots$$
So $a \in \{1, 2, 3, 4\}$ (never $0$). We check $a \leq k = 2^m$ in each subcase
:
- $a = 1$ (when $m \equiv 1 \pmod{4}$): $2^m \geq 2 \geq 1$. ✓
- $a = 2$ (when $m \equiv 2 \pmod{4}$): $2^m \geq 4 \geq 2$. ✓
- $a = 4$ (when $m \equiv 3 \pmod{4}$): smallest $m = 3$, $2^3 = 8 \geq 4$. ✓
- $a = 3$ (when $m \equiv 0 \pmod{4}$): smallest $m = 4$, $2^4 = 16 \geq 3$. ✓

*Verification of the divisibility condition:* Each $w_i \in \{2, 4\}$, so $w_i \
neq 1$ and $5 \nmid w_i$. ✓ The sum is:
$$\sum_{i=1}^k w_i^2 = 16a + 4(k - a) = 4k + 12a.$$
Modulo 5: $4k + 12a \equiv 4k + 2a \pmod{5}$. Since $a \equiv 3k \pmod{5}$, we g
et $2a \equiv 6k \equiv k \pmod{5}$, so:
$$4k + 2a \equiv 4k + k = 5k \equiv 0 \pmod{5}. ✓$$

**Conclusion:** In both cases, we have constructed natural numbers $w_1, \ldots,
 w_k$ (all different from 1) and an odd prime $p$ such that $p \mid \sum w_i^2$
but $p \nmid w_i$ for every $i$. Since every integer $k > 1$ either has an odd p
rime factor or is a power of $2$, the answer is **yes** for all $k > 1$.
