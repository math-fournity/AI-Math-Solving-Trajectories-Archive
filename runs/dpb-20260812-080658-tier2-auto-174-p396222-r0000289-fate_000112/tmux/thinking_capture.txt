我们将 Eisenstein 判别法 (Eisenstein's criterion) 应用于素数 $p = 2$。

Eisenstein 判别法回顾。 如果多项式 $f(X) = a_n X^n + a_{n-1}X^{n-1} + \cdots +
a_1 X + a_0 \in \mathbb{Z}[X]$ 满足以下条件，对于某个素数 $p$：

  1. $p \nmid a_n$（首项系数不被 $p$ 整除），
  2. 对于每个 $i < n$，都有 $p \mid a_i$（每个非首项系数都能被 $p$ 整除），
  3. $p^2 \nmid a_0$（常数项不被 $p^2$ 整除），

那么 $f$ 在 $\mathbb{Q}$ 上是不可约的。

验证 $f(X) = X^n - 2$ 的三个条件，其中 $p = 2$：

写出 $f(X) = 1 \cdot X^n + 0 \cdot X^{n-1} + \cdots + 0 \cdot X + (-2)$，因此
$a_n = 1$，对于 $1 \le i \le n-1$ 有 $a_i = 0$，且 $a_0 = -2$。

  1. $p \nmid a_n$： 首项系数为 $a_n = 1$，而 $2 \nmid 1$。✓
  2. 对于所有 $i < n$，$p \mid a_i$： 当 $1 \le i \le n-1$ 时，$a_i = 0$，且 $2
  \mid 0$。常数项为 $a_0 = -2$，且 $2 \mid (-2)$。因此，每个非首项系数都能被 $2$
  整除。✓
  3. $p^2 \nmid a_0$： 常数项为 $a_0 = -2$，且 $4 \nmid (-2)$。✓

所有三个条件都成立，因此根据 Eisenstein 判别法，$f(X) = X^n - 2$ 在 $\mathbb{Q}$
上是不可约的。

从 $\mathbb{Q}$ 上的不可约性推导 $\mathbb{Z}$ 上的不可约性：

多项式 $f(X) = X^n - 2$ 是 本原的 (primitive)，因为其系数 $1, 0, \ldots, 0, -2$
的最大公约数为 $\gcd(1, 2) = 1$。

根据 高斯引理 (Gauss's Lemma)，一个次数 $\ge 1$ 的本原多项式在 $\mathbb{Z}$ 上是
