## Proof

Let $X_1, X_2, \ldots, X_n$ be identically and symmetrically distributed normal
random variables with common correlation $\rho$ between any pair. Without loss o
f generality, assume each $X_i \sim N(0,1)$, so $\operatorname{Var}(X_i)=1$ and
$\operatorname{Cov}(X_i,X_j)=\rho$ for $i\neq j$.

### The correlation matrix

The covariance (correlation) matrix is
$$\Sigma = (1-\rho)\,I_n + \rho\,\mathbf{1}\mathbf{1}^\top,$$
where $\mathbf{1}=(1,\ldots,1)^\top$. For $\Sigma$ to be a valid covariance matr
ix it must be **positive semidefinite**.

### Eigenvalues

The rank-one matrix $\rho\,\mathbf{1}\mathbf{1}^\top$ has:
- eigenvalue $n\rho$ with eigenvector $\mathbf{1}$,
- eigenvalue $0$ with multiplicity $n-1$ (the orthogonal complement of $\mathbf{
1}$).

Adding $(1-\rho)I_n$ shifts every eigenvalue by $1-\rho$, so the eigenvalues of
$\Sigma$ are:
$$\lambda_1 = 1+(n-1)\rho \quad(\text{multiplicity }1), \qquad \lambda_2 = 1-\rh
o \quad(\text{multiplicity }n-1).$$

### Semidefiniteness constraints

Positive semidefiniteness requires both eigenvalues to be non-negative:

$$1+(n-1)\rho \ge 0 \;\Longrightarrow\; \rho \ge -\frac{1}{n-1},$$
$$1-\rho \ge 0 \;\Longrightarrow\; \rho \le 1.$$

Therefore
$$\boxed{\rho \ge -\frac{1}{n-1}}.$$

### The bound is achieved

We show $\rho = -\tfrac{1}{n-1}$ is attainable. Let $Z_1,\ldots,Z_n$ be i.i.d. $
N(0,1)$ and set
$$X_i = Z_i - \bar{Z}, \qquad \bar{Z}=\tfrac{1}{n}\sum_{k=1}^n Z_k.$$

**Variance.**
$$\operatorname{Var}(X_i)=\operatorname{Var}(Z_i-\bar Z)=1-\tfrac{2}{n}+\tfrac{1
}{n}=\tfrac{n-1}{n}.$$

**Covariance** ($i\neq j$):
$$\operatorname{Cov}(X_i,X_j)=\operatorname{Cov}(Z_i-\bar Z,\,Z_j-\bar Z)=0-\tfr
ac{1}{n}-\tfrac{1}{n}+\tfrac{1}{n}=-\tfrac{1}{n}.$$

**Correlation:**
$$\operatorname{Corr}(X_i,X_j)=\frac{-1/n}{(n-1)/n}=-\frac{1}{n-1}.$$

The variables $X_i$ are jointly normal (linear combinations of independent norma
ls), identically distributed, and symmetrically correlated, so this is a valid c
onstruction. Geometrically, at $\rho=-\tfrac{1}{n-1}$ the eigenvalue $\lambda_1=
0$, meaning the variables satisfy the linear constraint $\sum_i X_i=0$ — they li
ve in the $(n-1)$-dimensional subspace orthogonal to $\mathbf{1}$, which is exac
tly what the construction $X_i=Z_i-\bar Z$ enforces.

### Conclusion

The most negative common correlation coefficient possible among $n$ identically
and symmetrically distributed normal random variables is

$$\rho_{\min}=-\frac{1}{n-1}.$$
