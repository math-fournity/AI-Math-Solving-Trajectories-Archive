# Solution

**Setting up the substitution.** Let $x = e^{-t}$ with $t > 0$, so $t \to 0^+$ a
s $x \to 1^-$. Then
$$F_a(e^{-t}) = \sum_{n \ge 1} n^a\, e^{2n - tn^2}.$$

**Completing the square.** The exponent $2n - tn^2$ is maximized at $n = 1/t$, a
nd:
$$2n - tn^2 = \frac{1}{t} - t\!\left(n - \frac{1}{t}\right)^2.$$
Hence
$$F_a(e^{-t}) = e^{1/t}\sum_{n \ge 1} n^a\, e^{-t(n-1/t)^2}.$$

**Expanding the exponential weight.** Since $1 - e^{-t} = t - \frac{t^2}{2} + O(
t^3)$,
$$\frac{1}{1-x} = \frac{1}{1-e^{-t}} = \frac{1}{t} + \frac{1}{2} + O(t),$$
so
$$e^{-1/(1-x)} = e^{-1/t - 1/2 + O(t)}.$$

**Combining,** the $e^{1/t}$ and $e^{-1/t}$ cancel:
$$F_a(e^{-t})\,e^{-1/(1-x)} = e^{-1/2+O(t)}\;\underbrace{\sum_{n \ge 1} n^a\, e^
{-t(n-1/t)^2}}_{=:\, S_a(t)}.$$

**Estimating $S_a(t)$ via Laplace's method.** The Gaussian $e^{-t(n-1/t)^2}$ has
 width $1/\sqrt{t} \to \infty$, so the lattice spacing $1$ is fine relative to t
he width, and the sum is excellently approximated by an integral. By the Poisson
 summation formula, the correction terms are exponentially small ($\sim e^{-\pi^
2/t}$), so:
$$S_a(t) = \int_0^\infty n^a\, e^{-t(n-1/t)^2}\,dn\;\cdot\bigl(1 + o(1)\bigr).$$

Substitute $n = \frac{1}{t} + \frac{u}{\sqrt{t}}$, $dn = \frac{du}{\sqrt{t}}$:
$$\int_0^\infty n^a\, e^{-t(n-1/t)^2}\,dn = \frac{1}{\sqrt{t}}\int_{-1/\sqrt{t}}
^\infty \left(\frac{1}{t}+\frac{u}{\sqrt{t}}\right)^{\!a} e^{-u^2}\,du.$$

As $t\to 0^+$, the lower limit $\to -\infty$, and $\left(\frac{1}{t}+\frac{u}{\s
qrt{t}}\right)^a = t^{-a}\!\left(1+u\sqrt{t}\right)^a = t^{-a}\bigl(1+O(\sqrt{t}
)\bigr)$ uniformly on compacts. By dominated convergence (with Gaussian dominati
ng):
$$= \frac{t^{-a}}{\sqrt{t}}\int_{-\infty}^{\infty} e^{-u^2}\,du\;\cdot\bigl(1+O(
\sqrt{t})\bigr) = \sqrt{\pi}\; t^{-a-1/2}\bigl(1+o(1)\bigr).$$

**Conclusion.** Therefore
$$F_a(e^{-t})\,e^{-1/(1-x)} \;=\; e^{-1/2}\,\sqrt{\pi}\; t^{-a-1/2}\,\bigl(1+o(1
)\bigr).$$

Since $e^{-1/2}\sqrt{\pi} > 0$ is a fixed positive constant and $t \to 0^+$:

- If $a < -\tfrac{1}{2}$: the exponent $-a - \tfrac{1}{2} > 0$, so $t^{-a-1/2} \
to 0$, giving limit **$0$**.
- If $a > -\tfrac{1}{2}$: the exponent $-a - \tfrac{1}{2} < 0$, so $t^{-a-1/2} \
to \infty$, giving limit **$\infty$**.
- If $a = -\tfrac{1}{2}$: the limit is the finite constant $e^{-1/2}\sqrt{\pi}$.

$$\boxed{c = -\dfrac{1}{2}}$$
