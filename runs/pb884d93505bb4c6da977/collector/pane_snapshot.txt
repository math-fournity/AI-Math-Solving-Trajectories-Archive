## Solution

We compute \(E(B_1^2 B_2 B_3)\) for standard Brownian motion \(B_t\).

**Method 1: Wick's (Isserlis) theorem.** Since \((B_t)\) is a centered Gaussian
process, for any four times \(a,b,c,d\),

\[
E(B_a B_b B_c B_d) = \operatorname{Cov}(B_a,B_b)\operatorname{Cov}(B_c,B_d) + \o
peratorname{Cov}(B_a,B_c)\operatorname{Cov}(B_b,B_d) + \operatorname{Cov}(B_a,B_
d)\operatorname{Cov}(B_b,B_c).
\]

With \(a=b=1,\, c=2,\, d=3\) and \(\operatorname{Cov}(B_s,B_t)=\min(s,t)\):

\[
E(B_1^2 B_2 B_3) = \underbrace{\operatorname{Cov}(B_1,B_1)\operatorname{Cov}(B_2
,B_3)}_{1\cdot 2=2} + \underbrace{\operatorname{Cov}(B_1,B_2)\operatorname{Cov}(
B_1,B_3)}_{1\cdot 1=1} + \underbrace{\operatorname{Cov}(B_1,B_3)\operatorname{Co
v}(B_1,B_2)}_{1\cdot 1=1}.
\]

\[
E(B_1^2 B_2 B_3) = 2 + 1 + 1 = 4.
\]

**Method 2 (verification via independent increments).** Let \(X_1=B_1,\; X_2=B_2
-B_1,\; X_3=B_3-B_2\), i.i.d. \(N(0,1)\). Then \(B_1=X_1,\; B_2=X_1+X_2,\; B_3=X
_1+X_2+X_3\), so

\[
B_1^2 B_2 B_3 = X_1^2(X_1+X_2)(X_1+X_2+X_3).
\]

Expanding \((X_1+X_2)(X_1+X_2+X_3)=X_1^2+2X_1X_2+X_1X_3+X_2^2+X_2X_3\):

\[
B_1^2 B_2 B_3 = X_1^4 + 2X_1^3X_2 + X_1^3X_3 + X_1^2X_2^2 + X_1^2X_2X_3.
\]

Taking expectations using independence and \(E[X_i]=0,\; E[X_i^2]=1,\; E[X_i^4]=
3\):

\[
E = \underbrace{E[X_1^4]}_{3} + 0 + 0 + \underbrace{E[X_1^2]E[X_2^2]}_{1} + 0 =
3 + 1 = 4.
\]

Both methods agree.

\[
\boxed{E(B_1^2 B_2 B_3) = 4}
\]
