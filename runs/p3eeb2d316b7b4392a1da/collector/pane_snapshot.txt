## Solution

We compute
$$I = \int_{\mathbb{R}} \frac{i\omega - \omega^2}{1+\omega^6}\,d\omega = \int_{\
mathbb{R}} \frac{i\omega}{1+\omega^6}\,d\omega - \int_{\mathbb{R}} \frac{\omega^
2}{1+\omega^6}\,d\omega.$$

**First term (vanishes by symmetry).** The map $\omega \mapsto \frac{i\omega}{1+
\omega^6}$ is odd: the numerator $i\omega$ is odd and the denominator $1+\omega^
6$ is even, so the ratio is odd. The domain $\mathbb{R}$ is symmetric, and the i
ntegrand is absolutely integrable (it decays like $|\omega|^{-5}$). Hence
$$\int_{\mathbb{R}} \frac{i\omega}{1+\omega^6}\,d\omega = 0.$$

**Second term (substitution).** Set $u = \omega^3$, so $du = 3\omega^2\,d\omega$
, i.e. $\omega^2\,d\omega = \tfrac{1}{3}du$. As $\omega$ runs from $-\infty$ to
$+\infty$, so does $u$, and $\omega^6 = u^2$. Thus
$$\int_{\mathbb{R}} \frac{\omega^2}{1+\omega^6}\,d\omega = \int_{-\infty}^{+\inf
ty} \frac{1}{1+u^2}\cdot\frac{du}{3} = \frac{1}{3}\Big[\arctan u\Big]_{-\infty}^
{+\infty} = \frac{1}{3}\left(\frac{\pi}{2}-\left(-\frac{\pi}{2}\right)\right) =
\frac{\pi}{3}.$$

**Combining.**
$$I = 0 - \frac{\pi}{3} = -\frac{\pi}{3}.$$
