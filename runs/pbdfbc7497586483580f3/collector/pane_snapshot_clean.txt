## Proof

We evaluate
$$I = \int_0^{2\pi} \cot(e^{it})\,ie^{it}\,dt.$$

**Substitution.** Set $z = e^{it}$, so $dz = ie^{it}\,dt$. As $t$ ranges over $[
0,2\pi)$, the point $z = e^{it}$ traverses the unit circle $|z|=1$ once counterc
lockwise. Hence
$$I = \oint_{|z|=1} \cot(z)\,dz.$$

**Locate the poles.** Since $\cot z = \dfrac{\cos z}{\sin z}$, the poles occur a
t the zeros of $\sin z$, namely $z = n\pi$ for $n\in\mathbb{Z}$, and each is sim
ple (since $\sin'(n\pi)=\cos(n\pi)=(-1)^n\neq 0$).

**Poles inside the contour.** We need $|n\pi|<1$, i.e. $|n|<1/\pi\approx 0.318$.
 The only integer satisfying this is $n=0$, giving the single pole $z=0$. No pol
e lies *on* the contour since $|n\pi|\ge \pi > 1$ for $|n|\ge 1$.

**Compute the residue at $z=0$.**
$$\operatorname{Res}(\cot,\,0)=\lim_{z\to 0} z\,\cot z=\lim_{z\to 0}\frac{z}{\si
n z}\cdot\cos z = 1\cdot 1 = 1,$$
using the standard limit $\lim_{z\to 0}\frac{\sin z}{z}=1$.

**Apply the residue theorem.**
$$I = \oint_{|z|=1}\cot z\,dz = 2\pi i\sum_{|n\pi|<1}\operatorname{Res}(\cot,\,n
\pi)=2\pi i\cdot\operatorname{Res}(\cot,0)=2\pi i\cdot 1 = 2\pi i.$$

Therefore,
$$\boxed{\int_0^{2\pi}\cot(e^{it})\,ie^{it}\,dt = 2\pi i.}$$
