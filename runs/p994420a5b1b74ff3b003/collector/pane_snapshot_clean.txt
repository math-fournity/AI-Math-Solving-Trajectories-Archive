## Solution

Let $a = BC$, $b = CA$, $c = AB$, and let $x = PD$, $y = PE$, $z = PF$ denote th
e perpendicular distances from $P$ to the sides $BC$, $CA$, $AB$ respectively.

**Area decomposition.** Since $P$ lies inside $\triangle ABC$, the three triangl
es $\triangle PBC$, $\triangle PCA$, $\triangle PAB$ partition $\triangle ABC$.
Hence, with $S = [\triangle ABC]$,

$$S = \tfrac{1}{2}ax + \tfrac{1}{2}by + \tfrac{1}{2}cz,$$

so

$$ax + by + cz = 2S \quad \text{(a constant, independent of } P\text{)}.$$

**Lower bound via Cauchy–Schwarz (Engel/Titu form).** We rewrite each term as $\
dfrac{a}{x} = \dfrac{a^2}{ax}$, and similarly for the others. Then

$$\frac{a}{x} + \frac{b}{y} + \frac{c}{z} = \frac{a^2}{ax} + \frac{b^2}{by} + \f
rac{c^2}{cz} \geq \frac{(a+b+c)^2}{ax+by+cz} = \frac{(a+b+c)^2}{2S}.$$

**Equality condition.** Equality in the Engel form of Cauchy–Schwarz holds if an
d only if

$$\frac{a}{ax} = \frac{b}{by} = \frac{c}{cz}, \quad\text{i.e.,}\quad \frac{1}{x}
 = \frac{1}{y} = \frac{1}{z}, \quad\text{i.e.,}\quad x = y = z.$$

Thus the minimum is attained precisely when $P$ is equidistant from all three si
des of $\triangle ABC$.

**Attainability.** The unique point inside a triangle that is equidistant from a
ll three sides is the **incenter** $I$ (the center of the inscribed circle). Set
ting $x = y = z = r$ (the inradius) in the constraint gives $(a+b+c)\,r = 2S$, i
.e., $r = \dfrac{2S}{a+b+c} = \dfrac{S}{s}$ where $s = \tfrac{a+b+c}{2}$, which
is exactly the well-known formula for the inradius. Hence the incenter lies insi
de the triangle and satisfies the equality condition, so the lower bound is achi
eved.

**Uniqueness.** The incenter is the unique interior point with $PD = PE = PF$, s
o it is the unique minimizer.

**Conclusion.** The unique point $P$ minimizing $\dfrac{BC}{PD} + \dfrac{CA}{PE}
 + \dfrac{AB}{PF}$ is the **incenter** of $\triangle ABC$, and the minimum value
 is $\dfrac{(a+b+c)^2}{2S}$.
