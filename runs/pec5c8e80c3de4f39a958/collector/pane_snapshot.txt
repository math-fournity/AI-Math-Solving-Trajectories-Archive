# Solution

**Answer: FALSE.**

Not every vector bundle on a projective variety admits a filtration by line bund
les. We provide an explicit counterexample: the tangent bundle $T_{\mathbb{P}^2}
$ on the projective plane $\mathbb{P}^2$ (over an algebraically closed field).

## Counterexample: $T_{\mathbb{P}^2}$ has no filtration by line bundles

**Setup.** Let $X = \mathbb{P}^2$ with hyperplane class $H$. The tangent bundle
$T_{\mathbb{P}^2}$ has rank 2. Its total Chern class is
$$c(T_{\mathbb{P}^2}) = (1+H)^3 = 1 + 3H + 3H^2,$$
so $c_1(T_{\mathbb{P}^2}) = 3H$ and $c_2(T_{\mathbb{P}^2}) = 3$.

**Stability.** $T_{\mathbb{P}^n}$ is stable for $n \geq 2$ (with respect to the
hyperplane polarization). In particular, $T_{\mathbb{P}^2}$ is stable, so every
line subbundle $\mathcal{O}(a) \hookrightarrow T_{\mathbb{P}^2}$ must satisfy
$$a = \mu(\mathcal{O}(a)) < \mu(T_{\mathbb{P}^2}) = \frac{c_1}{\mathrm{rank}} =
\frac{3}{2}.$$
Hence $a \leq 1$.

**Suppose a filtration by line bundles exists.** Since $T_{\mathbb{P}^2}$ has ra
nk 2, a filtration by line bundles amounts to a short exact sequence
$$0 \to \mathcal{O}(a) \to T_{\mathbb{P}^2} \to \mathcal{O}(b) \to 0$$
with $a + b = c_1 = 3$, i.e. $b = 3 - a$. By stability, $a \leq 1$, so $b \geq 2
$.

The Chern classes of such an extension satisfy $c_2 = a \cdot b = a(3-a)$. Evalu
ating for all admissible $a \leq 1$:

| $a$ | $b = 3-a$ | $c_2 = a(3-a)$ |
|-----|-----------|-----------------|
| $1$ | $2$ | $2$ |
| $0$ | $3$ | $0$ |
| $-1$ | $4$ | $-4$ |
| $\leq -2$ | $\geq 5$ | $\leq -10$ |

In every case $c_2 \neq 3$, contradicting $c_2(T_{\mathbb{P}^2}) = 3$.

**Conclusion.** No short exact sequence $0 \to \mathcal{O}(a) \to T_{\mathbb{P}^
2} \to \mathcal{O}(b) \to 0$ exists, so $T_{\mathbb{P}^2}$ admits no filtration
by line bundles. Therefore the statement is **false**: not every vector bundle o
n a projective variety has a filtration by line bundles.
