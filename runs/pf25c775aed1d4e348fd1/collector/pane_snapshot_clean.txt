## Solution

**Identifying the singularities.** The function $f(z) = \frac{1}{1+e^z}$ is sing
ular where $1 + e^z = 0$, i.e. $e^z = -1$. Writing $-1 = e^{(2k+1)\pi i}$, the s
ingularities are precisely
$$z_k = (2k+1)\pi i, \quad k \in \mathbb{Z}.$$

**Type of singularity.** At each $z_k$, the denominator $g(z) = 1 + e^z$ has a s
imple zero since $g'(z_k) = e^{z_k} = -1 \neq 0$. Hence each $z_k$ is a simple p
ole of $f$.

**Laurent expansion about $z_k$.** Set $w = z - z_k$ so that $e^z = e^{z_k}e^w =
 -e^w$. Then
$$f(z) = \frac{1}{1 - e^w}.$$

Using the Bernoulli generating function
$$\frac{w}{e^w - 1} = \sum_{n=0}^{\infty} B_n \frac{w^n}{n!} = 1 - \frac{w}{2} +
 \frac{w^2}{12} - \frac{w^4}{720} + \cdots$$
(with $B_0=1,\, B_1=-\tfrac12,\, B_2=\tfrac16,\, B_3=0,\, B_4=-\tfrac1{30},\ldot
s$), we get
$$\frac{1}{e^w - 1} = \frac{1}{w} - \frac{1}{2} + \frac{w}{12} - \frac{w^3}{720}
 + \cdots$$

Since $\frac{1}{1-e^w} = -\frac{1}{e^w-1}$, the Laurent series of $f$ about $z_k
$ is
$$\boxed{f(z) = -\frac{1}{z - z_k} + \frac{1}{2} - \frac{z - z_k}{12} + \frac{(z
-z_k)^3}{720} - \cdots}$$
valid for $0 < |z - z_k| < 2\pi$ (the distance to the nearest neighboring pole).

**Residue.** The residue is the coefficient of $(z - z_k)^{-1}$ in the Laurent s
eries:
$$\operatorname{Res}(f,\, z_k) = -1, \qquad z_k = (2k+1)\pi i,\; k \in \mathbb{Z
}.$$

This agrees with the general formula for a simple pole:
$$\operatorname{Res}(f, z_k) = \frac{1}{g'(z_k)} = \frac{1}{e^{z_k}} = \frac{1}{
-1} = -1.$$
