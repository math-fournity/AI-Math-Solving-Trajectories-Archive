**Answer: Yes.** For every closed subset $A \subseteq \mathbb{R}$, there exists
a smooth ($C^\infty$) function $f:\mathbb{R}\to\mathbb{R}$ with $f^{-1}(0)=A$.

---

### Proof

**Step 1. Decompose the complement.** Since $A$ is closed, $U:=\mathbb{R}\setmin
us A$ is open. Every open subset of $\mathbb{R}$ is a countable union of pairwis
e disjoint open intervals (including possibly half-infinite or doubly-infinite i
ntervals). Write

$$U = \bigcup_{n} I_n, \qquad I_n = (a_n, b_n),$$

where the $I_n$ are disjoint, and each $a_n, b_n \in \{-\infty\}\cup A \cup \{+\
infty\}$ (endpoints are either finite and belong to $A$, or infinite).

**Step 2. A smooth bump on each interval.** We use the standard smooth function

$$\varphi(t) = \begin{cases} e^{-1/(t(1-t))}, & 0 < t < 1,\\ 0, & \text{otherwis
e}, \end{cases}$$

which is $C^\infty$ on $\mathbb{R}$, strictly positive on $(0,1)$, and vanishes
to infinite order (all derivatives zero) at $t=0$ and $t=1$.

For each **bounded** complementary interval $I_n=(a_n,b_n)$ with finite endpoint
s, define

$$\varphi_n(x) = \varphi\!\left(\frac{x-a_n}{b_n-a_n}\right).$$

This is $C^\infty$, strictly positive exactly on $(a_n,b_n)$, and vanishes to in
finite order at $a_n$ and $b_n$.

For a **half-infinite** interval $I_n=(a_n,+\infty)$, use

$$\varphi_n(x) = \begin{cases} e^{-1/(x-a_n)}, & x > a_n,\\ 0, & x \le a_n. \end
{cases}$$

This is $C^\infty$, positive on $(a_n,+\infty)$, and vanishes to infinite order
at $a_n$.

For $I_n=(-\infty,b_n)$, use the reflected version $\varphi_n(x)=e^{-1/(b_n-x)}$
 for $x<b_n$ and $0$ otherwise.

For $I_n=(-\infty,+\infty)$ (i.e., $A=\emptyset$), simply set $\varphi_n \equiv
1$.

**Step 3. Sum the bumps.** Define

$$f(x) = \sum_{n} \varphi_n(x).$$

Because the intervals $I_n$ are pairwise disjoint, for each $x$ **at most one**
summand is nonzero. Hence the sum is locally finite: it is in fact a finite (sin
gle-term) sum pointwise. So $f$ is well-defined, and:

- If $x \in A$, then $x \notin U$, so $x \notin I_n$ for every $n$, hence $\varp
hi_n(x)=0$ for all $n$, giving $f(x)=0$.
- If $x \in U$, then $x \in I_n$ for a unique $n$, and $\varphi_n(x)>0$ while al
l other terms vanish, giving $f(x)=\varphi_n(x)>0$.

Therefore $f^{-1}(0) = A$ exactly.

**Step 4. Smoothness.** We verify $f \in C^\infty(\mathbb{R})$:

- **On each open interval $I_n$:** $f = \varphi_n$, which is $C^\infty$.
- **On $\operatorname{int}(A)$:** $f \equiv 0$, which is $C^\infty$.
- **At a boundary point $p \in \partial A$:** Such a point is an endpoint of one
 or two complementary intervals. On the $A$-side, $f\equiv 0$ in a neighborhood
(within $A$). On the interval side, $f = \varphi_n$ near $p$, and $\varphi_n$ va
nishes to infinite order at $p$ (all derivatives of $\varphi_n$ at $p$ are $0$).
 Since both one-sided limits of every derivative agree (they are all $0$), $f$ i
s $C^\infty$ at $p$ with $f^{(k)}(p)=0$ for all $k$.

Since every point of $\mathbb{R}$ falls into one of these three cases, $f$ is $C
^\infty$ everywhere.

**Step 5. Edge cases.**
- $A = \mathbb{R}$: $U=\emptyset$, so $f\equiv 0$, which is $C^\infty$ with zero
 set $\mathbb{R}$.
- $A = \emptyset$: $U=\mathbb{R}=(-\infty,+\infty)$, and we set $\varphi\equiv 1
$, giving $f\equiv 1$, $C^\infty$ with empty zero set.

---

**Conclusion.** For every closed set $A\subseteq\mathbb{R}$, the function $f=\su
m_n \varphi_n$ constructed above is real-valued, continuous, and infinitely diff
erentiable, with $f^{-1}(0)=A$. Hence the answer is **yes**: every closed subset
 of $\mathbb{R}$ arises as the zero set of some $C^\infty$ function $\mathbb{R}\
to\mathbb{R}$.
