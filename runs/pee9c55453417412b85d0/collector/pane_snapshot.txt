mu^*\!\left(\bigcup_{\alpha < \kappa} E_\alpha\right)$, where $\mu^*$ is the out

For any finite $F \subseteq \lambda$, the cylinder set $C_F = \{\phi : \phi(\alp

$$\mu^*\!\left(\bigcup_{\alpha < \aleph_0} E_\alpha\right) \le \sum_{\alpha < \a
leph_0} \mu^*(E_\alpha) = 0.$$
Hence $P(\aleph_0, \lambda) = 0$.

Let $B$ be any measurable set with $A \subseteq B$, and let $J \subseteq \kappa

$$\mu^*(A) = \inf\{\mu(B) : B \text{ measurable},\; A \subseteq B\} = 1.$$
