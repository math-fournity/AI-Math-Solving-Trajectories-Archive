## 解答

**答案：** 当且仅当 $m \mid n$ 时，存在一个满足 $f(I_m) = I_n$ 的 $k$-代数同态 $
f: M_m(k) \to M_n(k)$。

---

### 证明

**必要性 ($m \mid n$)：**

设 $f: M_m(k) \to M_n(k)$ 是一个满足 $f(I_m) = I_n$ 的 $k$-代数同态。

**步骤 1：$f$ 是单射。** $M_m(k)$ 的核是一个双边理想。由于 $M_m(k)$ 是单代数（它
没有非平凡的双边理想），因此 $\ker f$ 要么是 $\{0\}$，要么是 $M_m(k)$。但是 $f(I
_m) = I_n \neq 0$，所以 $\ker f \neq M_m(k)$，从而 $\ker f = \{0\}$。

**步骤 2：$k^n$ 是一个 $M_m(k)$-模。** 通过 $f$，自然 $M_n(k)$-模 $k^n$ 限制为一
个 $M_m(k)$-模。由于 $f$ 是酉的（$f(I_m) = I_n$），这是一个酉模。

**步骤 3：$M_m(k)$-模的分类。** $M_m(k) \cong \operatorname{End}_k(k^m)$ 是一个
单、半单代数。其唯一的单模（在同构意义下）是自然模 $k^m$。由于 $M_m(k)$ 是半单的
，每个 $M_m(k)$-模都是半单的，即单模的直和。因此，作为 $M_m(k)$-模：
$$k^n \cong (k^m)^{\oplus r}$$
对于某个整数 $r \geq 1$（因为模是酉的，$r \geq 1$）。

比较维数：$n = mr$，所以 $m \mid n$。

**充分性 ($m \mid n \Rightarrow$ 存在 $f$)：**

假设 $n = mr$。通过行/列分块将 $k^n$ 与 $k^m \otimes_k k^r$ 等同起来，这给出了一
个代数同构 $M_n(k) \cong M_m(k) \otimes_k M_r(k)$，其中 $A \otimes B$ 作用于 $k^
m \otimes k^r$ 上，为 $(A \otimes B)(v \otimes w) = Av \otimes Bw$。

定义：
$$f: M_m(k) \to M_n(k), \quad f(A) = A \otimes I_r.$$

这显然是一个 $k$-代数同态：
- $f(A + B) = (A+B) \otimes I_r = A \otimes I_r + B \otimes I_r = f(A) + f(B)$,
- $f(AB) = (AB) \otimes I_r = (A \otimes I_r)(B \otimes I_r) = f(A)f(B)$,
- $f(I_m) = I_m \otimes I_r = I_{mr} = I_n$.

因此 $f$ 是一个满足 $f(I_m) = I_n$ 的酉 $k$-代数同态。$\square$
