## Proof

have exactly one common neighbor. Let $d_v$ denote the degree of vertex $v$.

**Counting paths of length 2.** The number of length-2 paths equals $\sum_v \bin
om{d_v}{2}$. Since every pair of vertices has exactly one common neighbor (which
 is the middle of a unique length-2 path between them), this count equals $\bino
m{451}{2}$.

**Adjacency matrix relation.** Let $A$ be the adjacency matrix and $D = \text{di
ag}(d_1, \ldots, d_{451})$. The condition gives $(A^2)_{ij} = 1$ for $i \neq j$
and $(A^2)_{ii} = d_i$, so:
$$A^2 = J - I + D$$
where $J$ is the all-ones matrix. Applying to $\mathbf{1}$: since $A\mathbf{1} =
 \mathbf{d}$ (the degree vector), we get $A\mathbf{d} = A^2\mathbf{1} = (J-I+D)\
mathbf{1} = 450\cdot\mathbf{1} + \mathbf{d}$, yielding the key relation:
$$\sum_{u \sim v} d_u = 450 + d_v \quad \text{for every vertex } v. \tag{$\star$
}$$

**Step 2: The regular case gives only $K_3$.**

If $G$ is $k$-regular on $n$ vertices, then $A^2 = J + (k-1)I$. Eigenvalues of $
A$: $k$ (multiplicity 1, from $\mathbf{1}$) and $\pm\sqrt{k-1}$ (total multiplic
ity $n-1$). The all-ones eigenvector gives $k^2 = n + k - 1$, so $n = k^2 - k +
1$. The trace condition $k + (m_+ - m_-)\sqrt{k-1} = 0$ with $m_+ + m_- = n-1$ f
orces either $\sqrt{k-1}$ irrational (giving $k=0$, trivial) or $k-1 = t^2$ with
 $t \mid (t^2+1)$, so $t=1$, $k=2$, $n=3$. Thus the only regular solution is $K_
3 = F_1$ (3 vertices). Since $451 \neq 3$, **$G$ is not regular**.

**Step 3: A non-regular graph has a universal vertex.**

Since $G$ is not regular, there exist $u, v$ with $d_u \neq d_v$. By Step 1, the
y must be **adjacent**. Let $w$ be their unique common neighbor ($w \sim u$, $w
\sim v$, $w \neq u, v$).

For any $x \notin \{u, v, w\}$: $x$ cannot be adjacent to both $u$ and $v$ (else

Define: $A = \{x \notin \{u,v,w\} : x \sim u,\; x \not\sim v\}$, $B = \{x \notin

Then $|A| + |B| = 448$, $d_u = 2 + |A|$, $d_v = 2 + |B|$, and $d_u \neq d_v$ imp

**For $x \in A$:** $d_x = d_v$ (non-adjacent to $v$, Step 1). The pair $(x, v)$
has $u$ as unique common neighbor ($u \sim x, u \sim v$; uniqueness means no oth

ny vertex in $B$. Thus $x$'s neighbors are $u$ and $d_v - 1 = 1 + |B|$ vertices
in $A \setminus \{x\}$. The induced subgraph on $A$ is $(1+|B|)$-regular.

**For $y \in B$:** Similarly, $d_y = d_u$, and the induced subgraph on $B$ is $(
1+|A|)$-regular.

If $|B| > 0$: each vertex in $B$ needs $1 + |A|$ neighbors in $B$, so $1 + |A| \
leq |B| - 1$, giving $|A| \leq |B| - 2$.
If $|A| > 0$: each vertex in $A$ needs $1 + |B|$ neighbors in $A$, so $1 + |B| \
leq |A| - 1$, giving $|B| \leq |A| - 2$.

If **both** $|A| > 0$ and $|B| > 0$: $|A| \leq |B| - 2$ and $|B| \leq |A| - 2$ g

Since $|A| + |B| = 448 > 0$, at least one is positive. If $|B| = 0$: $|A| = 448$

**Step 4: A universal vertex forces a windmill graph.**

Let $u$ be universal ($d_u = 450$). For any $x, y \neq u$: $u$ is a common neigh
bor, and by uniqueness it is the **only** common neighbor. So no vertex other th
an $u$ is adjacent to both $x$ and $y$.

Each $x \neq u$ is adjacent to $u$. If $x \sim y$ for some $y \neq u, x$, then $
x$ cannot be adjacent to any $z \neq u, y$ (else $y, z$ have common neighbors $u
$ and $x$). So $x$ has degree $\leq 2$.

**Degree 1 is impossible:** If $x \neq u$ has degree 1 (adjacent only to $u$), t
hen $N(u) \cap N(x) = (V \setminus \{u\}) \cap \{u\} = \emptyset$, so $u$ and $x
$ have **zero** common neighbors — contradiction.

So every $x \neq u$ has degree exactly 2: adjacent to $u$ and exactly one partne
r $x'$. The pair $\{x, x'\}$ with $u$ forms a triangle. No two such pairs share
a vertex (if $x' = y$ for another pair $\{y, y'\}$, then $x$ and $y'$ have commo
n neighbors $u$ and $y = x'$, contradiction). So the 450 non-universal vertices
partition into 225 disjoint pairs, each forming a triangle with $u$.

This is the **windmill graph** $F_{225}$. $\square$

**Step 5: Compute $n$ and verify.**

In $F_{225}$: the center $u$ has degree $450$, and all other 450 vertices have d
egree $2$.

Verification that every pair has exactly one common neighbor:
- $(u, x)$: $N(u) \cap N(x) = \{x'\}$ (the partner of $x$). ✓
- $(x, x')$ (partners): $N(x) \cap N(x') = \{u\}$. ✓
- $(x, y)$ (different pairs): $N(x) \cap N(y) = \{u\}$. ✓

So $n = \deg_{\max} - \deg_{\min} = 450 - 2 = \boxed{448}$.

Since the Friendship Theorem structure is **unique** (the graph is forced to be
$F_{225}$ up to isomorphism), the only possible value is:

$$n = 448.$$
