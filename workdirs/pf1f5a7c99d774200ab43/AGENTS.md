# Problem

A high-tech digital security firm uses a central database containing 1,024 unique data packets. Each packet represents a distinct binary signature corresponding to a subset of ten specific security sensors, labeled 0 through 9 (including one "null" packet with no sensors triggered).

Two systems administrators, Alice and Bob, are tasked with auditing these packets. They take turns selecting one packet at a time from the database, with Alice choosing first, until all 1,024 packets have been distributed between them.

Once the audit is complete, a supervisor evaluates their collections. A participant "clears" their set if they can remove exactly one packet from their possession such that, in the remaining collection, every one of the ten security sensors is represented an even number of times across all combined signatures.

If only one administrator is able to clear their set, that person is declared the winner. If both can or neither can, the result is a stalemate.

How many different initial packets can Alice select on her first turn to ensure she has a guaranteed winning strategy, regardless of Bob’s subsequent choices?
