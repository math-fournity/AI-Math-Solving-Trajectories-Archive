## Solution

Write $z = x+iy$. Note that
$$z^2 = (x+iy)^2 = x^2 - y^2 + 2ixy, \qquad -\frac{i z^2}{2} = xy - \frac{i(x^2-
y^2)}{2}.$$
Hence
$$\operatorname{Re}\!\left(-\frac{i z^2}{2}\right) = xy, \qquad \left|e^{-i z^2/
2}\right| = e^{xy}.$$

The hypothesis $|f(z)| \le e^{xy}$ therefore reads
$$\left|f(z)\right| \le \left|e^{-i z^2/2}\right| \quad\text{for all } z\in\math
bb{C}.$$

Define the entire function
$$g(z) = f(z)\, e^{i z^2/2}.$$
Since $e^{i z^2/2}$ is entire and $f$ is entire, $g$ is entire. Moreover,
$$|g(z)| = |f(z)|\,\left|e^{i z^2/2}\right| = |f(z)|\,e^{-xy} \le e^{xy}\cdot e^
{-xy} = 1$$
for every $z\in\mathbb{C}$. Thus $g$ is a bounded entire function.

By **Liouville's theorem**, $g$ is constant: $g(z) \equiv c$ for some $c\in\math
bb{C}$ with $|c|\le 1$.

Therefore
$$f(z) = c\, e^{-i z^2/2}, \qquad |c|\le 1.$$

**Conversely**, for any $c$ with $|c|\le 1$,
$$|f(z)| = |c|\,\left|e^{-i z^2/2}\right| = |c|\,e^{xy} \le e^{xy},$$
so the bound is satisfied, and $f$ is clearly entire.

### Conclusion

The entire functions satisfying $|f(x+iy)|\le e^{xy}$ for all $x,y\in\mathbb{R}$
 are exactly
$$\boxed{\,f(z) = c\,e^{-i z^2/2},\quad c\in\mathbb{C},\ |c|\le 1\,}.$$
