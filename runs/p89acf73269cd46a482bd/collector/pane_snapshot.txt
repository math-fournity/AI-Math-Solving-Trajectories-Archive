## Proof

**Yes, such a set exists.** We construct it explicitly via a generalized Cantor
set with carefully chosen scaling ratios.

### Construction

Let $c_n = \tfrac{1}{2}e^{-1/n}$ for $n = 1, 2, 3, \dots$ Note $0 < 2c_n = e^{-1
/n} < 1$, so each ratio is valid and leaves a nonempty gap.

Define sets $E_n$ inductively:
- $E_0 = [0,1]$.
- Given $E_{n-1}$, a union of $2^{n-1}$ disjoint closed intervals each of length
 $L_{n-1} = \prod_{k=1}^{n-1} c_k$, obtain $E_n$ by replacing every interval $I
\subseteq E_{n-1}$ with the two closed subintervals of length $L_n = c_n L_{n-1}
$ sitting at the left and right ends of $I$ (deleting the open middle portion of
 relative length $1 - 2c_n$).

Set $C = \bigcap_{n=0}^{\infty} E_n \subseteq [0,1]$.

### Lebesgue measure is zero

$E_n$ consists of $2^n$ intervals each of length $L_n = \prod_{k=1}^{n} c_k$, so

$$|E_n| = 2^n \prod_{k=1}^{n} c_k = \prod_{k=1}^{n} (2c_k) = \prod_{k=1}^{n} e^{
-1/k} = \exp\!\Big(-\sum_{k=1}^{n} \tfrac{1}{k}\Big) = e^{-H_n},$$

where $H_n$ is the $n$-th harmonic number. Since $H_n \to \infty$, we get $|E_n|
 \to 0$. The sets $E_n$ are nested and decreasing, so by continuity from above,

$$|C| = \lim_{n\to\infty} |E_n| = 0.$$

### Hausdorff dimension is 1

The construction is a Moran construction with varying ratios: at step $k$ each i
nterval spawns $m_k = 2$ children each scaled by $c_k$, and the children are sep
arated by a gap (since $2c_k < 1$), so the **open set condition** is satisfied a
t every stage. By the standard dimension formula for such Cantor-like sets (see
e.g. Falconer, *Fractal Geometry*, or the Moran covering theorem),

$$\dim_H C = \liminf_{n\to\infty} \frac{\sum_{k=1}^{n} \log m_k}{-\sum_{k=1}^{n}
 \log c_k} = \liminf_{n\to\infty} \frac{n \log 2}{-\sum_{k=1}^{n} \log c_k}.$$

(Sketch of the two directions: the **upper bound** uses the natural cover by the
 $2^n$ intervals of $E_n$, each of diameter $L_n$; the **lower bound** uses the
natural self-similar measure assigning mass $2^{-n}$ to each level-$n$ interval
and applies the mass distribution principle. The gaps guarantee the needed separ
ation in both arguments.)

Now compute the denominator. Since $c_k = \tfrac12 e^{-1/k}$,

$$-\log c_k = \log 2 + \tfrac{1}{k}, \qquad -\sum_{k=1}^{n} \log c_k = n\log 2 +
 H_n.$$

Therefore

$$\frac{n\log 2}{-\sum_{k=1}^{n} \log c_k} = \frac{n\log 2}{n\log 2 + H_n} = \fr
ac{n\log 2}{n\log 2 + \log n + O(1)} \xrightarrow{n\to\infty} 1.$$

Hence $\dim_H C = 1$.

### Conclusion

The set $C \subseteq [0,1]$ has Lebesgue measure $0$ and Hausdorff dimension $1$
. Therefore such a set exists. $\blacksquare$
