# Problem

In a specialized cyber-security facility, a master server generates unique identification codes represented by integers $x$ in the range $0 \leq x < 121$. To maintain system integrity, a code is deemed "valid" only if it passes a specific polynomial validation check based on the facility's security prime power, 121.

The validation process requires calculating the total system load generated by the code $x$, which is defined by the formula:
$$x^5 + 5x^2 + x + 1$$

A code $x$ is authorized for use if and only if the resulting system load is exactly divisible by 121 (leaving a remainder of 0). 

How many unique integer identification codes $x$ satisfy this security requirement?
