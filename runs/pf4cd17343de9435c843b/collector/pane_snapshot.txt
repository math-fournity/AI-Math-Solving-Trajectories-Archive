## Solution

Setting up the 8 conditions from p(x,y) = 0 at each given point, with a₀ = 0 fro
m (0,0):

**From (1,0) and (−1,0):** Adding gives 2a₃ = 0, so a₃ = 0; then a₆ = −a₁.

**From (0,1) and (0,−1):** Adding gives 2a₅ = 0, so a₅ = 0; then a₉ = −a₂.

**From (1,1):** a₄ + a₇ + a₈ = 0.

**From (1,−1):** −a₄ − a₇ + a₈ = 0, giving a₈ = a₄ + a₇. Substituting: 2(a₄+a₇)
= 0, so a₇ = −a₄ and a₈ = 0.

**From (2,2):** 2a₁ + 2a₂ + 4a₄ + 8(−a₁) + 8(−a₄) + 8(−a₂) = 0, giving −6a₁ − 6a
₂ − 4a₄ = 0, so a₄ = −(3/2)(a₁ + a₂).

With free parameters a₁, a₂, the polynomial factors as:

$$p(x,y) = a_1 \cdot f(x,y) + a_2 \cdot g(x,y)$$

where
- $f(x,y) = x(1-x)\!\left[(1+x) - \tfrac{3}{2}y\right]$
- $g(x,y) = y(1-y^2) - \tfrac{3}{2}xy(1-x)$

For p to vanish for **all** (a₁, a₂), we need f = 0 **and** g = 0 simultaneously
.

**Case f = 0:**
- x = 0 → g = y(1−y²) = 0 → (0,0), (0,±1). All given.
- x = 1 → g = y(1−y²) = 0 → (1,0), (1,±1). All given.
- $(1+x) - \tfrac{3}{2}y = 0$, i.e. $y = \tfrac{2}{3}(1+x)$: substituting into g
 (dividing by y ≠ 0):

$$1 - y^2 - \tfrac{3}{2}x(1-x) = 0$$

With $y = \tfrac{2}{3}(1+x)$, multiplying through by 18:

$$18 - 8(1+x)^2 - 27x(1-x) = 0 \;\Longrightarrow\; 19x^2 - 43x + 10 = 0$$

Discriminant: $1849 - 760 = 1089 = 33^2$, so $x = \frac{43 \pm 33}{38}$.

- $x = 2 \Rightarrow y = 2$: point (2,2), given.
- $x = \frac{5}{19} \Rightarrow y = \frac{2}{3}\cdot\frac{24}{19} = \frac{16}{19
}$: **new point** $\left(\frac{5}{19}, \frac{16}{19}\right)$.

**Verification:** At (5/19, 16/19):
- f: the bracket $(1+\tfrac{5}{19}) - \tfrac{3}{2}\cdot\tfrac{16}{19} = \tfrac{2
4}{19} - \tfrac{24}{19} = 0$. ✓
- g: $1 - \tfrac{256}{361} - \tfrac{3}{2}\cdot\tfrac{70}{361} = \tfrac{105}{361}
 - \tfrac{105}{361} = 0$. ✓

This point is distinct from all eight listed coordinates. With $a=5$, $b=16$, $c
=19$: $\gcd(5,19)=1$ and $c>1$. ✓

$$a + b + c = 5 + 16 + 19 = \boxed{40}$$

### PROOF COMPLETE
