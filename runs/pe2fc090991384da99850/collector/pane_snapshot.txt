**Claim:** The unique function is $f(x) = \dfrac{1}{x}$.

### Step 1. Determine $f(1)$ and establish the involution property

Set $x = 1$ in condition (1):
$$f(f(y)) = y\,f(1) \quad \text{for all } y > 0. \tag{★}$$

Denote $c := f(1) > 0$, so $f(f(y)) = cy$.

Set $y = 1$ in (1):
$$f(x\,f(1)) = 1\cdot f(x) \implies f(cx) = f(x) \quad \text{for all } x > 0. \t
ag{1}$$

Now apply $f$ to both sides of (★): $f(f(f(y))) = f(cy)$. But using (★) with $y$
 replaced by $f(y)$ gives $f(f(f(y))) = c\,f(y)$. Hence
$$f(cy) = c\,f(y) \quad \text{for all } y > 0. \tag{2}$$

Combining (1) and (2): $f(y) = f(cy) = c\,f(y)$, so $(c-1)f(y) = 0$ for all $y >
 0$. Since $f(y) \in \mathbb{R}_+$, we get $c = 1$, i.e.
$$\boxed{f(1) = 1}, \qquad f(f(y)) = y \;\;\text{for all } y > 0.$$

Thus $f$ is a bijection (its own inverse).

### Step 2. Reduce to the multiplicative Cauchy equation

Since $f$ is surjective, every $t > 0$ can be written as $t = f(y)$ for some $y$
, and then $f(t) = f(f(y)) = y$. Substituting $y \mapsto f(t)$ (so $f(y) = t$) i
nto (1):
$$f(xt) = f(t)\,f(x) \quad \text{for all } x, t > 0. \tag{3}$$

So $f$ is **multiplicative**.

### Step 3. Use the limit condition to obtain strict monotonicity

For $x > 1$: the sequence $x^n \to +\infty$, so by condition (2), $f(x^n) \to 0$
. By multiplicativity, $f(x^n) = f(x)^n \to 0$, which forces
$$f(x) < 1 \quad \text{for all } x > 1. \tag{4}$$

For $0 < x < 1$: since $f(x)\,f(1/x) = f(1) = 1$ and $1/x > 1$ gives $f(1/x) < 1
$, we get $f(x) > 1$.

Now if $x_2 > x_1 > 0$, then $x_2/x_1 > 1$, so $f(x_2/x_1) < 1$ by (4). By multi
plicativity,
$$\frac{f(x_2)}{f(x_1)} = f\!\left(\frac{x_2}{x_1}\right) < 1 \implies f(x_2) <
f(x_1).$$

Hence **$f$ is strictly decreasing** on $\mathbb{R}_+$.

### Step 4. A monotone multiplicative function is a power function

Define $g: \mathbb{R} \to \mathbb{R}$ by $g(t) = \ln f(e^t)$. Then:
- **Additivity:** $g(s+t) = \ln f(e^{s+t}) = \ln\bigl(f(e^s)f(e^t)\bigr) = g(s)
+ g(t)$.
- **Monotonicity:** $f$ strictly decreasing and $t \mapsto e^t$ increasing $\imp
lies$ $g$ is strictly decreasing.

A monotone additive function on $\mathbb{R}$ is linear: $g(t) = at$ for some con
stant $a$. Since $g$ is decreasing, $a < 0$. Therefore
$$f(x) = e^{a\ln x} = x^{a}, \qquad a < 0.$$

### Step 5. Pin down the exponent via the involution

The involution $f(f(x)) = x$ gives $(x^a)^a = x^{a^2} = x$ for all $x > 0$, so $
a^2 = 1$. With $a < 0$:
$$a = -1, \qquad \boxed{f(x) = \frac{1}{x}}.$$

1. $f(xf(y)) = f\!\left(x\cdot\tfrac{1}{y}\right) = \dfrac{y}{x} = y\cdot\dfrac{
1}{x} = y\,f(x)$. ✓
2. $\displaystyle\lim_{x\to+\infty}\frac{1}{x} = 0$. ✓

Both conditions are satisfied, and the derivation shows uniqueness.
