## Proof

**Claim:** $f = 0$ is a solution. Moreover, for $1 \leq p < \infty$ and $g \not\
equiv 0$, it is the *only* solution.

### Part 1: $f=0$ is a solution

Set $f \equiv 0$. Then $f \in L^p(\mathbb{R})$ for every $1 \leq p \leq \infty$,
 and
$$f * g = 0 * g = 0 = \|g\|_1 \cdot 0 = \|g\|_1 \cdot f. \quad \checkmark$$

### Part 2: Uniqueness for $1 \leq p < \infty$, $g \geq 0$, $g \not\equiv 0$

Assume $f \in L^p(\mathbb{R})$, $1 \leq p < \infty$, satisfies $f * g = \|g\|_1
f$ with $g \geq 0$, $g \in L^1$, $g \not\equiv 0$.

**Step 1 (Equality in Young/Minkowski).** By Young's convolution inequality,
$$\|f * g\|_p \leq \|f\|_p \|g\|_1.$$
But the eigenvalue equation gives $\|f * g\|_p = \|g\|_1 \|f\|_p$, so **equality
** holds.

Writing the convolution as an integral and applying Minkowski's integral inequal
ity:
$$\|f * g\|_p = \left(\int \left|\int f(x-y)\,g(y)\,dy\right|^p dx\right)^{1/p}
\leq \int \left(\int |f(x-y)|^p dx\right)^{1/p} g(y)\,dy = \|f\|_p \|g\|_1.$$

Equality in Minkowski's integral inequality (for $1 \leq p < \infty$) holds if a
nd only if the integrands $f(x-y)\,g(y)$ are non-negative scalar multiples of a
common function of $x$, for $g$-a.e. $y$. Concretely, there exist $h(x)$ and $c(
y) \geq 0$ such that
$$f(x - y) = c(y)\,h(x), \quad \text{for } g\text{-a.e. } y \text{ and a.e. } x.
 \tag{$\star$}$$

**Step 2 ($f$ is translation-invariant on the difference set of $\operatorname{s
upp} g$).** Let $E = \{y : g(y) > 0\}$; since $g \geq 0$, $g \not\equiv 0$, $g \
in L^1$, we have $m(E) > 0$. Pick $y_1, y_2 \in E$ (in the essential support sen
se). From $(\star)$:
$$f(x - y_1) = c(y_1)\,h(x), \qquad f(x - y_2) = c(y_2)\,h(x).$$
Dividing (where $h \neq 0$): $f(x - y_1) = \lambda\, f(x - y_2)$ with $\lambda =
 c(y_1)/c(y_2) \geq 0$. Substituting $u = x - y_2$:
$$f(u - \tau) = \lambda\, f(u), \quad \tau := y_1 - y_2, \quad \text{a.e. } u. \
tag{$\star\star$}$$

Iterating $(\star\star)$: $f(u - n\tau) = \lambda^n f(u)$. Taking $L^p$-norms an
d using translation-invariance of Lebesgue measure:
$$\|f\|_p = \|f(\cdot - n\tau)\|_p = \lambda^n \|f\|_p.$$
Since $f \not\equiv 0$ (otherwise done), $\|f\|_p > 0$, so $\lambda^n = 1$ for a
ll $n \in \mathbb{Z}$, giving $\lambda = 1$.

Therefore $f(u - \tau) = f(u)$ for every $\tau \in E - E$ (the difference set),
a.e.

**Step 3 (Steinhaus theorem forces $f$ to be constant).** Since $m(E) > 0$, by *
*Steinhaus's theorem**, the difference set $E - E$ contains an open interval $(-
\delta, \delta)$ around $0$. Thus $f$ is invariant under all translations $\tau
\in (-\delta, \delta)$.

Any function invariant under all sufficiently small translations is constant a.e
.: for any $a \in \mathbb{R}$, write $a = n \cdot (\delta/2) + r$ with $|r| < \d
elta/2$ and $n \in \mathbb{Z}$; then $f(x - a) = f(x - r) = f(x)$, so $f$ is inv
ariant under every translation, hence $f \equiv \text{const}$ a.e.

**Step 4 (Conclusion).** A constant function belongs to $L^p(\mathbb{R})$ for $1
 \leq p < \infty$ only if it is identically zero (since $\mathbb{R}$ has infinit
e measure). Therefore $f = 0$.

### Part 3: The case $p = \infty$

For $p = \infty$, any **constant** function $f \equiv c$ satisfies:
$$f * g = c \int g(y)\,dy = c\,\|g\|_1 = \|g\|_1 \cdot f,$$
and $f \in L^\infty(\mathbb{R})$. So nontrivial solutions exist when $p = \infty
$.

### Summary

| Range of $p$ | Solutions |
|---|---|
| $1 \leq p < \infty$ | $f = 0$ (unique, when $g \geq 0$, $g \not\equiv 0$) |
| $p = \infty$ | $f \equiv c$ for any constant $c$ |

The function $f = 0$ is always a valid answer for every $1 \leq p \leq \infty$.
