## Proof

**Notation.** Let $c = g(0)$ and define $h(x) = f(x) - f(0)$, so $h(0)=0$ and $f
(x)=h(x)+f(0)$.

### Step 1. Reduction to a single unknown function

Setting $y=0$ in the original equation: $f(x+g(0))=g(x)+f(0)$, so
$$g(x)=f(x+c)-f(0)=h(x+c). \tag{1}$$

Setting $x=0$: $f(g(y))=g(0)+f(y)+ay=c+f(y)+ay$, i.e., $h(g(y))=c+h(y)+ay$. Sinc
e $g(y)=h(y+c)$:
$$h(h(y+c))=c+h(y)+ay. \tag{2}$$

Substituting $g(x)=h(x+c)$ into the original equation:
$$h\bigl(x+h(y+c)\bigr)=h(x+c)+h(y)+ay. \tag{3}$$

### Step 2. Key relation $h(x+c)=h(x)+c$

Set $y=-c$ in (3): $h(x+h(0))=h(x+c)+h(-c)-ac$, i.e., $h(x)=h(x+c)+h(-c)-ac$. Th
us $h(x+c)=h(x)+\beta$ where $\beta=-h(-c)+ac$ is constant. Setting $x=0$: $h(c)
=\beta$.

Set $y=0$ in (2): $h(h(c))=c$. Applying $h(x+c)=h(x)+\beta$ with $x=0$ gives $h(
c)=\beta$, and with $x=c$ gives $h(2c)=h(c)+\beta=2\beta$. By induction $h(nc)=n
\beta$ for all $n\in\mathbb{Z}$.

From $h(c)=\beta$ and (2) at $y=0$: $h(\beta)=c$. Also $h(h(c))=h(\beta)=c$. Now
 apply $h(x+c)=h(x)+\beta$ to $x=\beta-c$: $h(\beta)=h(\beta-c)+\beta$, so $c=h(
\beta-c)+\beta$, giving $h(\beta-c)=c-\beta$.

We can also get $\beta=c$ directly: from (2) at $y=0$, $h(h(c))=c$, i.e., $h(\be
ta)=c$. From $h(x+c)=h(x)+\beta$ at $x=\beta-c$: $h(\beta)=h(\beta-c)+\beta=c$,
so $h(\beta-c)=c-\beta$.

To pin down $\beta$, use (3) at $x=0$: $h(h(y+c))=h(c)+h(y)+ay=\beta+h(y)+ay$. C
omparing with (2): $c+h(y)+ay=\beta+h(y)+ay$, so $\boxed{c=\beta}$. Therefore:
$$h(x+c)=h(x)+c \quad\text{for all }x, \qquad h(c)=c. \tag{4}$$

### Step 3. Simplification: $d(y)=h(y)$ and the Cauchy-type equation

Define $d(y)=g(y)-c=h(y+c)-c$. By (4), $h(y+c)=h(y)+c$, so $d(y)=h(y)$.

Equation (3) becomes $h(x+h(y))=h(x)+h(y)+ay$. Setting $x=0$: $h(h(y))=h(y)+ay$,
 so:
$$h(x+h(y))=h(x)+h(h(y)) \quad\text{for all }x,y. \tag{5}$$

Let $G=\langle\operatorname{Im}(h)\rangle$ be the subgroup of $(\mathbb{Q},+)$ g
enerated by the image of $h$. Equation (5) says:
$$h(x+t)=h(x)+h(t) \quad\text{for all }x\in\mathbb{Q},\; t\in G. \tag{6}$$

In particular, $h|_G:G\to G$ is a group endomorphism (since $h(t)\in\operatornam
e{Im}(h)\subseteq G$ for $t\in G$).

### Step 4. $G$ is nontrivial; $h|_G$ is multiplication by $r\in\mathbb{Q}$

If $G=\{0\}$ then $h\equiv 0$, and $h(h(y))=h(y)+ay$ gives $0=ay$ for all $y$, f
orcing $a=0$, contradiction. So $G$ is a nontrivial subgroup of $\mathbb{Q}$.

Any nontrivial subgroup of $\mathbb{Q}$ has rank 1. Every endomorphism of a rank
-1 subgroup of $\mathbb{Q}$ is multiplication by a rational: pick $g_0\in G\setm
inus\{0\}$, set $r=\phi(g_0)/g_0\in\mathbb{Q}$, and for any $g\in G$ with $mg=ng
_0$ ($m\neq 0$), $m\phi(g)=n\phi(g_0)=nrg_0=rmg$, so $\phi(g)=rg$.

Thus $h|_G$ is multiplication by some $r\in\mathbb{Q}$. From $h(h(y))=h(y)+ay$ w
ith $y\in G$: $r^2 y = (r+a)y$, so:
$$r^2=r+a, \quad\text{i.e.,}\quad r^2-r-a=0. \tag{7}$$

### Step 5. $c=0$

Since $c=h(c)\in\operatorname{Im}(h)\subseteq G$ and $h(c)=c=rc$, we get $c(r-1)
=0$. From (7) with $a\neq 0$: $r\neq 0$ and $r\neq 1$. Hence $c=0$.

### Step 6. $h$ is linear on all of $\mathbb{Q}$

With $c=0$: $g(x)=h(x)$ and $f(x)=h(x)+f(0)$. Define $\psi(x)=h(x)-rx$. From (6)
, $\psi(x+t)=\psi(x)$ for all $t\in G$, so $\psi$ is constant on cosets of $G$.
For $t\in G$: $\psi(t)=h(t)-rt=rt-rt=0$.

Now $h(y)=ry+\psi(y)\in\operatorname{Im}(h)\subseteq G$ for every $y$, so $ry+\p
si(y)\in G$, meaning $\psi(ry+\psi(y))=0$. From $h(h(y))=h(y)+ay$:
$$h(ry+\psi(y))=r(ry+\psi(y))+\psi(ry+\psi(y))=r^2y+r\psi(y),$$
$$h(y)+ay=(r+a)y+\psi(y).$$
Using $r^2=r+a$: $r\psi(y)=\psi(y)$, so $(r-1)\psi(y)=0$. Since $r\neq 1$, $\psi
\equiv 0$.

Therefore $h(x)=rx$ for all $x\in\mathbb{Q}$.

### Step 7. Determining $a$ and the solutions

We have $f(x)=rx+\beta$, $g(x)=rx$ with $\beta=f(0)\in\mathbb{Q}$ arbitrary, $r\
in\mathbb{Q}$ satisfying $r^2-r-a=0$ and $r\neq 0,1$.

**Verification:** $f(x+g(y))=f(x+ry)=r(x+ry)+\beta=rx+r^2y+\beta=rx+(r+a)y+\beta
=g(x)+f(y)+ay$. ✓

For $r\in\mathbb{Q}$, the discriminant $1+4a$ must be a perfect square in $\math
bb{Z}$ (an integer that is a rational square is an integer square). Write $1+4a=
m^2$ with $m\geq 0$ integer. Then $a=(m^2-1)/4$, which is an integer iff $m$ is
odd. Set $m=2k+1$, $k\geq 0$:
$$a=\frac{(2k+1)^2-1}{4}=k(k+1), \qquad r=\frac{1\pm(2k+1)}{2}=k+1 \;\text{ or }
\; -k.$$

For $a\neq 0$ we need $k\geq 1$. The two roots are $r_1=k+1$ and $r_2=-k$ (note
$r_1+r_2=1$, $r_1 r_2=-a$).

### Conclusion

**The nonzero integers $a$ are exactly $a=k(k+1)$ for positive integers $k$, i.e
., $a\in\{2,6,12,20,30,\dots\}$.**

Equivalently, $a=n(n-1)$ for integers $n$ with $|n|\geq 2$.

**For each such $a=k(k+1)$ ($k\geq 1$), all pairs $(f,g)$ are:**

$$\boxed{f(x)=(k+1)x+\beta,\quad g(x)=(k+1)x} \qquad\text{and}\qquad \boxed{f(x)
=-kx+\beta,\quad g(x)=-kx},$$

where $\beta\in\mathbb{Q}$ is arbitrary.
