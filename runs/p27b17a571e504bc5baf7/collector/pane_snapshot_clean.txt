## Solution

**Setup.** Let $r_1, r_2$ be the roots of $P(x) = x^2 + ax + b$, so $r_1 + r_2 =
 -a$ and $r_1 r_2 = b$. The condition "$P(x) \mid x^{2n} + ax^n + b$ for all $n
\ge 1$" means every root $r$ of $P$ satisfies $r^{2n} + ar^n + b = 0$ for all $n
 \ge 1$, i.e., **$r^n$ is a root of $P$ for every $n \ge 1$**.

Thus we need: for all $n \ge 1$, $r_1^n \in \{r_1, r_2\}$ and $r_2^n \in \{r_1,
r_2\}$.

---

### Case 1: Double root ($a^2 = 4b$), $r_1 = r_2 = r$

We need $r^n = r$ for all $n \ge 1$. For $n = 2$: $r^2 = r \Rightarrow r \in \{0
, 1\}$.

- **$r = 0$**: $(a, b) = (0, 0)$, $P(x) = x^2$. Check: $x^2 \mid x^{2n}$ for all
 $n \ge 1$. ✓  $M = 0 + 0 = 0$.
- **$r = 1$**: $(a, b) = (-2, 1)$, $P(x) = (x-1)^2$. Check: $x^{2n} - 2x^n + 1 =
 (x^n - 1)^2 = (x-1)^2(1 + x + \cdots + x^{n-1})^2$. ✓  $M = 4 + 1 = 5$.

### Case 2: Distinct roots $r_1 \neq r_2$

From $n = 2$: $r_1^2, r_2^2 \in \{r_1, r_2\}$. Four subcases:

**(a)** $r_1^2 = r_1,\ r_2^2 = r_2$: Both $r_i \in \{0,1\}$, distinct $\Rightarr
ow \{r_1, r_2\} = \{0, 1\}$. Then $a = -1,\ b = 0$, $P(x) = x^2 - x = x(x-1)$. C
heck: $x^{2n} - x^n = x^n(x^n - 1)$, divisible by $x(x-1)$ since $x \mid x^n$ an
d $(x-1) \mid (x^n - 1)$. ✓  $M = 1 + 0 = 1$.

**(b)** $r_1^2 = r_2,\ r_2^2 = r_1$: Then $r_1^4 = r_1$, so $r_1^3 = 1$ (nonzero
 since distinct). With $r_1 \neq 1$, we get $r_1 = \omega$ (primitive cube root
of unity), $r_2 = \omega^2$. Then $a = 1,\ b = 1$. **But** at $n = 3$: $\omega^6
 + \omega^3 + 1 = 1 + 1 + 1 = 3 \neq 0$. ✗ **Fails.**

**(c)** $r_1^2 = r_2,\ r_2^2 = r_2$ (or symmetrically $r_1^2 = r_1,\ r_2^2 = r_1
$): $r_2 \in \{0,1\}$. If $r_2 = 0 \Rightarrow r_1 = 0$ (not distinct). If $r_2
= 1 \Rightarrow r_1^2 = 1,\ r_1 \neq 1 \Rightarrow r_1 = -1$. So $\{r_1, r_2\} =
 \{-1, 1\}$, $a = 0,\ b = -1$, $P(x) = x^2 - 1$. Check: $x^{2n} - 1 = (x^2)^n -
1$, divisible by $x^2 - 1$. ✓  $M = 0 + 1 = 1$.

### Completeness check (complex roots)

If $r_1, r_2$ are complex conjugates with $|r_i| = \rho$, then $|r_1^n| = \rho^n
$ must equal $\rho$ for all $n$, forcing $\rho = 1$. Writing $r_1 = e^{i\theta}$
, the $n = 2$ constraint gives $e^{2i\theta} \in \{e^{i\theta}, e^{-i\theta}\}$,
 yielding only $\theta = 2\pi/3$ (the cube root case, which fails) or $\theta =
0$ (not distinct). No other complex cases exist.

### Discriminant verification

All four candidates satisfy $a^2 \ge 4b$:
- $(0, 0)$: $0 \ge 0$ ✓
- $(-2, 1)$: $4 \ge 4$ ✓
- $(-1, 0)$: $1 \ge 0$ ✓
- $(0, -1)$: $0 \ge -4$ ✓
