## Proof

**Reformulation.** The condition $B - A \geq \frac{AB}{100}$ for $A < B$ is equi
valent to:
$$B(100 - A) \geq 100A \quad\Longleftrightarrow\quad B \geq \frac{100A}{100 - A}
.$$

Define $f(x) = \frac{100x}{100-x}$ for $x \in (0,100)$. Note $f$ is **strictly i
ncreasing** on $(0,100)$.

**Key observation:** If $A \geq 100$, then $100 - A \leq 0$ while $100A > 0$, ma
king the condition impossible for any $B > A$. Therefore, **at most one element
can be $\geq 100$**, and it must be the largest. All other elements must lie in
$\{1, 2, \ldots, 99\}$.

**Consecutive pairs suffice.** For a sorted sequence $a_1 < a_2 < \cdots < a_n$,
 the condition for pair $(a_i, a_j)$ with $i < j$ is $a_j \geq f(a_i)$. Since $f
$ is increasing and $a_i \leq a_{j-1}$, we get $f(a_i) \leq f(a_{j-1})$. Thus if
 the consecutive condition $a_{j} \geq f(a_{j-1})$ holds, then $a_j \geq f(a_{j-
1}) \geq f(a_i)$ for all $i < j$. So **only consecutive pairs need to be checked
**.

**Greedy construction.** To maximize length, start at $a_1 = 1$ and choose each
$a_{k+1} = \lceil f(a_k) \rceil$ (the smallest valid integer). Since $f$ is incr
easing, this greedy choice minimizes every subsequent element.
