# Proof: Asymptotic Upper Bound on Elementary Matrix Decomposition of $GL(n,K)$

## Setup and Definitions

Let $K$ be an infinite field. The **elementary matrices** are of three types:
- **Type 1** (row swap): the permutation matrix $P_{ij}$ transposing rows $i$ an
d $j$.
- **Type 2** (row scaling): the diagonal matrix $D_i(\lambda) = \operatorname{di
ag}(1,\dots,1,\lambda,1,\dots,1)$ with $\lambda \in K^\times$ in position $i$.
- **Type 3** (row addition / transvection): $T_{ij}(\alpha) = I + \alpha\, e_i e
_j^\top$ with $\alpha \in K$, $i \neq j$.

We seek the asymptotic behavior (as $n \to \infty$) of the minimal number $L(n)$
 such that every $A \in GL(n,K)$ is a product of at most $L(n)$ elementary matri
ces.

---

## Upper Bound: $L(n) \leq n^2 + O(n)$ via Gaussian Elimination

Every $A \in GL(n,K)$ is invertible, so Gaussian elimination reduces $A$ to $I$
using elementary row operations. We count the operations.

**Forward elimination** (reduce to upper triangular). For each pivot $i = 1, \do
ts, n-1$:
- If $a_{ii} = 0$, swap row $i$ with some row $j > i$ having $a_{ji} \neq 0$ (su
ch $j$ exists since $A$ is invertible). At most $n-1$ swaps total.
- For each $j = i+1, \dots, n$: apply the transvection $T_{ji}(-a_{ji}/a_{ii})$
to clear entry $(j,i)$.

Number of type-3 operations: $\sum_{i=1}^{n-1}(n-i) = \frac{n(n-1)}{2}$.

**Backward elimination** (reduce upper triangular to diagonal). For each $i = n,
 \dots, 2$:
- For each $j = 1, \dots, i-1$: apply $T_{ji}(-a_{ji}/a_{ii})$ to clear entry $(
j,i)$.

Number of type-3 operations: $\sum_{i=2}^{n}(i-1) = \frac{n(n-1)}{2}$.

**Diagonal scaling.** Apply $D_i(1/a_{ii})$ for $i = 1, \dots, n$: $n$ type-2 op
erations.

**Total (if all three types count as elementary):**

$$\underbrace{n(n-1)}_{\text{transvections}} + \underbrace{(n-1)}_{\text{swaps}}
 + \underbrace{n}_{\text{scaling}} = n^2 + n - 1 = O(n^2).$$

**If type-1 (swaps) must themselves be decomposed:** A transposition $P_{ij}$ eq
uals
$$P_{ij} = T_{ij}(1)\, T_{ji}(-1)\, T_{ij}(1)\, D_j(-1),$$
i.e., $3$ transvections $+\ 1$ diagonal $= 4$ elementary matrices. With at most
$n-1$ swaps, this adds $4(n-1)$, giving

$$n(n-1) + 4(n-1) + n = n^2 + 4n - 4 = O(n^2).$$

In either convention, $L(n) \leq n^2 + O(n)$, hence **$L(n) = O(n^2)$**.

---

## Lower Bound: $L(n) \geq n^2$ via Dimension Count

We show the bound is tight, i.e., $L(n) = \Omega(n^2)$, so the true asymptotic i
s $\Theta(n^2)$.

**Algebraic-geometric argument.** $GL(n,K)$ is a Zariski-open (hence irreducible
) subvariety of $\mathbb{A}^{n^2}$ of dimension $n^2$.

Consider a product of $k$ elementary matrices. At each of the $k$ positions, we
choose:
- which type of elementary matrix (finitely many types), and
- which pair of indices $(i,j)$ or which index $i$ (finitely many choices, at mo
st $O(n^2)$), and
- one scalar parameter $\alpha \in K$ or $\lambda \in K^\times$.

For each fixed combinatorial choice of types and indices, the resulting map
$$\varphi: K^k \dashrightarrow GL(n,K), \qquad (\alpha_1, \dots, \alpha_k) \maps
to E_1 \cdots E_k$$
is a morphism (or rational map, since type-2 requires $\lambda \neq 0$) of algeb
raic varieties. Its image is a constructible set of **dimension at most $k$** (t
he dimension of the source).

There are only finitely many combinatorial choices (at most $C \cdot n^{2k}$ for
 a constant $C$ depending on the types). The union of all images over all choice
s is

$$GL(n,K) = \bigcup_{\text{choices}} \operatorname{Im}(\varphi_{\text{choice}}).
$$

Since $GL(n,K)$ is **irreducible** of dimension $n^2$, and a finite union of con
structible sets of dimension $< n^2$ cannot contain a Zariski-dense (hence dimen
sion-$n^2$) subset, at least one image must have dimension $\geq n^2$. Since eac
h image has dimension $\leq k$, we conclude

$$k \geq n^2.$$

Therefore $L(n) \geq n^2$, i.e., $L(n) = \Omega(n^2)$.

---

## Conclusion

Combining both bounds:

$$n^2 \leq L(n) \leq n^2 + O(n),$$

so the asymptotic upper bound on the number of elementary matrices required to d
ecompose any matrix in $GL(n,K)$ is

$$\boxed{L(n) = \Theta(n^2) \sim n^2 \text{ as } n \to \infty.}$$

The upper bound $O(n^2)$ is achieved by Gaussian elimination, and the lower boun
d $\Omega(n^2)$ follows from the irreducibility and dimension of $GL(n,K)$ as an
 algebraic variety over the infinite field $K$.
