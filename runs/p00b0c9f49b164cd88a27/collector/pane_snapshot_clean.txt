## Proof

Let $X = C[0,1]$ with the sup norm $\|\cdot\|_\infty$, and let $M = C_0[0,1] = \
{x \in X : x(0)=0\}$.

**Step 1: $M$ is a closed subspace.**

$M = \ker \phi$ where $\phi:X\to\mathbb{R}$ is the evaluation map $\phi(x)=x(0)$
. Since $\phi$ is a bounded linear functional ($|\phi(x)|\le \|x\|_\infty$), its
 kernel is closed. Hence the quotient $X/M$ is a Banach space.

**Step 2: Cosets are classified by the value at $0$.**

For $x,y\in X$:
$$x+M = y+M \iff x-y\in M \iff (x-y)(0)=0 \iff x(0)=y(0).$$

So each coset $x+M$ is completely determined by the scalar $x(0)$.

**Step 3: Algebraic isomorphism.**

Define $\Phi:X/M\to\mathbb{R}$ by $\Phi(x+M)=x(0)$. This is well-defined by Step
 2, clearly linear, injective (if $\Phi(x+M)=0$ then $x(0)=0$ so $x\in M$ and $x
+M=M$), and surjective (the constant function $c\cdot\mathbf{1}$ maps to $c$). T
hus $X/M\cong\mathbb{R}$ as vector spaces.

**Step 4: Isometric isomorphism (quotient norm).**

The quotient norm is
$$\|x+M\| = \inf_{m\in M}\|x+m\|_\infty.$$

*Lower bound.* For every $m\in M$, $m(0)=0$, so $(x+m)(0)=x(0)$, giving $\|x+m\|
_\infty\ge |x(0)|$. Hence $\|x+M\|\ge|x(0)|$.

*Upper bound (attained).* Take $m = -x + x(0)\cdot\mathbf{1}\in X$. Then $m(0)=-
x(0)+x(0)=0$, so $m\in M$, and $x+m = x(0)\cdot\mathbf{1}$, which has norm $|x(0
)|$. Therefore
$$\|x+M\|\le\|x(0)\cdot\mathbf{1}\|_\infty = |x(0)|.$$

Combining both bounds: $\|x+M\|=|x(0)|=|\Phi(x+M)|$.

So $\Phi$ is a **linear isometric isomorphism** between the Banach space $C[0,1]
/C_0[0,1]$ and $\mathbb{R}$ (with the usual absolute value norm).

**Conclusion.** Yes, the quotient space $C[0,1]/C_0[0,1]$ is isomorphic to $\mat
hbb{R}$ — in fact, isometrically isomorphic as a Banach space, via the map $x +
C_0[0,1] \mapsto x(0)$.
