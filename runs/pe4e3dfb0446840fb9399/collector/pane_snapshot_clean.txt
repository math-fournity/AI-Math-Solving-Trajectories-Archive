## Proof

**Claim:** $H \cap SL_n(\mathbb{Z})$ has finite index in $SL_n(\mathbb{Z})$.

**Key observation:** This is a purely group-theoretic fact that requires no spec
ial properties of $\hat{\mathbb{Z}}$, $n$, or any congruence subgroup property.

Since $\hat{\mathbb{Z}}$ is an extension of $\mathbb{Z}$, we have $\mathbb{Z} \s
ubseteq \hat{\mathbb{Z}}$, and therefore $SL_n(\mathbb{Z})$ is a subgroup of $SL
_n(\hat{\mathbb{Z}})$: any $n \times n$ matrix with integer entries and determin
ant $1$ also has entries in $\hat{\mathbb{Z}}$ and determinant $1$.

We use the following standard lemma:

> **Lemma.** Let $G$ be a group, $H \leq G$ a subgroup with $[G : H] < \infty$,
and $K \leq G$ any subgroup. Then $ : H \cap K] \leq [G : H] < \infty$.

*Proof of Lemma.* Define the map
$$\varphi: K/(H \cap K) \longrightarrow G/H, \qquad k\,(H \cap K) \longmapsto k\
,H.$$

We show $\varphi$ is well-defined and injective.

- **Well-defined:** If $k_1(H \cap K) = k_2(H \cap K)$, then $k_2^{-1}k_1 \in H
\cap K \subseteq H$, so $k_1 H = k_2 H$.

- **Injective:** If $k_1 H = k_2 H$ for $k_1, k_2 \in K$, then $k_2^{-1}k_1 \in
H$. Since $k_1, k_2 \in K$, we also have $k_2^{-1}k_1 \in K$, hence $k_2^{-1}k_1
 \in H \cap K$, giving $k_1(H \cap K) = k_2(H \cap K)$.

Since $\varphi$ is an injection from the coset space $K/(H \cap K)$ into the fin
ite set $G/H$, the number of cosets $ : H \cap K]$ is at most $[G : H] < \inft
y$. $\square$

**Applying the lemma:** Set
$$G = SL_n(\hat{\mathbb{Z}}), \qquad H = H \text{ (the given finite-index subgro
up)}, \qquad K = SL_n(\mathbb{Z}).$$

By hypothesis, $[G : H] = [SL_n(\hat{\mathbb{Z}}) : H] < \infty$. By the lemma,

$$\bigl[SL_n(\mathbb{Z}) : H \cap SL_n(\mathbb{Z})\bigr] \leq \bigl[SL_n(\hat{\m
athbb{Z}}) : H\bigr] < \infty.$$

Therefore $H \cap SL_n(\mathbb{Z})$ has finite index in $SL_n(\mathbb{Z})$. $\bl
acksquare$
