## Solution

We compute the sum
$$S = \sum_{k=1}^{2019} \tan\frac{k\pi}{43}\cdot\tan\frac{(k+1)\pi}{43}.$$

**Key identity.** From the subtraction formula
$$\tan(A-B) = \frac{\tan A - \tan B}{1+\tan A\tan B},$$
we obtain
$$\tan A\,\tan B = \frac{\tan A - \tan B}{\tan(A-B)} - 1.$$

**Apply with** $A = \frac{(k+1)\pi}{43}$, $B = \frac{k\pi}{43}$, so $A - B = \fr
ac{\pi}{43}$:
$$\tan\frac{k\pi}{43}\cdot\tan\frac{(k+1)\pi}{43} = \frac{\tan\frac{(k+1)\pi}{43
} - \tan\frac{k\pi}{43}}{\tan\frac{\pi}{43}} - 1.$$

**Sum from $k=1$ to $2019$.** The numerator telescopes:
$$\sum_{k=1}^{2019}\left(\tan\frac{(k+1)\pi}{43} - \tan\frac{k\pi}{43}\right) =
\tan\frac{2020\pi}{43} - \tan\frac{\pi}{43}.$$

**Reduce the endpoint.** Since $43\cdot 47 = 2021$, we have $2020 = 43\cdot 47 -
 1$, hence
$$\frac{2020\pi}{43} = 47\pi - \frac{\pi}{43},$$
and therefore
$$\tan\frac{2020\pi}{43} = \tan\!\left(47\pi - \frac{\pi}{43}\right) = \tan\!\le
ft(-\frac{\pi}{43}\right) = -\tan\frac{\pi}{43}.$$

So the telescoping sum equals
$$-\tan\frac{\pi}{43} - \tan\frac{\pi}{43} = -2\tan\frac{\pi}{43}.$$

**Assemble.**
$$S = \frac{-2\tan\frac{\pi}{43}}{\tan\frac{\pi}{43}} - 2019 = -2 - 2019 = \boxe
d{-2021}.$$
