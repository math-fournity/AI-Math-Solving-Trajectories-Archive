## Proof

Let $P(x,y)$ denote the assertion $f(x-f(y))=f(f(x))-f(y)-1$.

**Finding candidate solutions.** Testing $f(x)=c$ (constant): $c = c - c - 1 = -
1$, so $f\equiv -1$. Testing $f(x)=x+b$: comparing coefficients gives $b=1$, so
$f(x)=x+1$. Both verify directly. We prove these are the only solutions.

**Step 1: Reformulation via the range.** Let $R=\{f(y):y\in\mathbb{Z}\}$. Since
the RHS of $P(x,y)$ depends on $y$ only through $f(y)$, for every $r\in R$ (choo
sing $y$ with $f(y)=r$):

$$f(x-r)=f(f(x))-r-1 \quad \forall\, x\in\mathbb{Z},\; r\in R. \tag{$\star$}$$

**Step 2: Difference structure.** For $r_1,r_2\in R$, subtracting two instances
of $(\star)$:

$$f(x-r_1)-f(x-r_2)=r_2-r_1 \quad \forall\,x.$$

Setting $t=x-r_2$ and $d=r_2-r_1$, this gives $f(t+d)=f(t)+d$ for all $t\in\math
bb{Z}$ and all $d\in D:=R-R$. Define $h(x):=f(x)-x$; then $h$ is periodic with p
eriod $d$ for every $d\in D$.

**Step 3: Case split.**

*Case 1: $D=\{0\}$.* Then $R$ is a singleton, $f$ is constant, and $f\equiv -1$.

*Case 2: $D$ contains a nonzero element.* The set of periods of $h$ is a subgrou
p $k\mathbb{Z}$ for some $k\geq 1$, and $D\subseteq k\mathbb{Z}$.

**Step 4: Pinning down the range.** Setting $x=f(y)$ in $P(x,y)$: $f(0)=f(f(f(y)
))-f(y)-1$, so

$$f(f(f(y)))=f(0)+f(y)+1. \tag{$\dagger$}$$

Let $c:=f(0)$. Applying $(\star)$ with $x$ replaced by $f(y)$ and using $(\dagge
r)$:

$$f(f(y)-r)=f(f(f(y)))-r-1=(c+f(y)+1)-r-1=c+f(y)-r$$

for all $y\in\mathbb{Z}$, $r\in R$. Setting $u=f(y)\in R$: $f(u-r)=c+u-r$ for al
l $u,r\in R$, i.e.,

$$f(t)=t+c \quad \forall\, t\in D=R-R. \tag{$\star\star$}$$

In particular $h(t)=c$ for all $t\in D$. Since $h$ has period $k$ and $0\in D$,
we get $h(t)=c$ for all $t\in k\mathbb{Z}$.

Now $R=\{x+h(x):x\in\mathbb{Z}\}$. Since $h$ has period $k$, for each residue $s
\bmod k$, $f$ maps the class $s\bmod k$ to the class $(s+h(s))\bmod k$. For $D\s
ubseteq k\mathbb{Z}$, all these target classes must coincide, so $R$ is a **sing
le residue class** $c\bmod k$ (using $h(0)=c$, so $0\mapsto c$). This gives $h(s
)\equiv c-s\pmod{k}$, so we write $h(s)=c-s+km_s$ for integers $m_s$, with $m_0=
0$ (since $h(0)=c$).

**Step 5: The key equation.** Computing $P(x,y)$ with $x\equiv s\pmod{k}$: since
 $f(y)\equiv c\pmod{k}$, the argument $x-f(y)\equiv s-c\pmod{k}$. Setting $c_0:=
c\bmod k$ and $s':=(s-c_0)\bmod k$, both sides of $P(x,y)$ reduce (after cancell
ation) to:

$$h(s')=h(s)+h(c_0)-1 \quad \forall\, 0\le s<k. \tag{$\star\star\star$}$$

Substituting $h(s)=c-s+km_s$:

$$c-s'+km_{s'} = (c-s+km_s)+(c-c_0+km_{c_0})-1.$$

Since $s-s'-c_0\in\{0,-k\}$ (depending on whether $s\geq c_0$), this simplifies
to $c-1\equiv 0\pmod{k}$, i.e., $c\equiv 1\pmod{k}$, so $c_0=1$ (for $k\geq 2$).

**Step 6: Ruling out $k\geq 2$.** With $c_0=1$, the recurrence from $(\star\star
\star)$ for $s\geq 1$ (where $s'=s-1$) gives:

$$m_{s-1}-m_s = \alpha + m_1, \quad \text{where } \alpha:=\frac{c-1}{k}\in\mathb
b{Z}.$$

Iterating from $m_0=0$: $m_s=-s(\alpha+m_1)$. For $s=1$: $m_1=-(\alpha+m_1)$, so
 $m_1=-\alpha/2$, requiring $\alpha$ even.

The $s=0$ equation (where $s'=k-1$) gives $m_{k-1}-m_1=\alpha+1$. Substituting $
m_{k-1}=-(k-1)\alpha/2$ and $m_1=-\alpha/2$:

$$-\frac{(k-1)\alpha}{2}+\frac{\alpha}{2}=\alpha+1 \implies -\frac{(k-2)\alpha}{
2}=\alpha+1 \implies \alpha=\frac{-2}{k}.$$

For $\alpha\in\mathbb{Z}$: $k\mid 2$, so $k\in\{1,2\}$.

- **$k=2$:** $\alpha=-1$, so $m_1=-\alpha/2=1/2\notin\mathbb{Z}$. **Contradictio
n.**

-y=x+c-y-1$, giving $c=1$, hence $f(x)=x+1$.

**Conclusion.** The only solutions are:

$$\boxed{f(x)=-1 \quad\text{and}\quad f(x)=x+1.}$$
