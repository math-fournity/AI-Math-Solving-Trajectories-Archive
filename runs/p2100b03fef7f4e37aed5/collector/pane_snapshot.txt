# Proof

**Claim.** Yes. A (unital) ring in which every principal right ideal is generate
d by an idempotent is necessarily a von Neumann regular ring.

**Definitions.** A ring $R$ is *von Neumann regular* if for every $a \in R$ ther
e exists $x \in R$ with $axa = a$. The hypothesis is: for every $a \in R$, the p
rincipal right ideal $aR$ equals $eR$ for some idempotent $e \in R$ (i.e. $e^2 =
 e$).

**Proof.** Let $a \in R$ be arbitrary. By hypothesis there exists an idempotent
$e \in R$ with
$$aR = eR.$$

Since $R$ is unital, $a = a\cdot 1 \in aR = eR$, so there exists $b \in R$ with
$$a = eb.$$

Likewise $e = e\cdot 1 \in eR = aR$, so there exists $c \in R$ with
$$e = ac.$$

Now compute:
$$aca = (ac)a = ea = e(eb) = e^2 b = eb = a,$$
where we used $a = eb$ (twice), $e = ac$, and $e^2 = e$.

Thus for the arbitrary element $a$ we have produced $x = c \in R$ with $axa = a$
. Hence every element of $R$ is von Neumann regular, so $R$ is a regular ring. $
\blacksquare$

**Remark.** The converse is also true: in a regular ring, given $axa = a$, setti
ng $x' = xax$ yields $ax'a = a$ and $x'ax' = x'$, so $e = ax'$ is idempotent wit
h $aR = eR$. Thus "every principal right ideal is generated by an idempotent" is
 in fact *equivalent* to regularity (for unital rings).
