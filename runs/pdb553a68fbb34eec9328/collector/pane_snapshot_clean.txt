## Solution

We evaluate
$$I = \int_{0}^{+\infty} \frac{\cos x\,\sin\sqrt{1+x^{2}}}{\sqrt{1+x^{2}}}\,dx.$
$

**Step 1: Substitution $x = \sinh t$.** Then $\sqrt{1+x^2} = \cosh t$, $dx = \co
sh t\,dt$, with $x:0\to\infty$ corresponding to $t:0\to\infty$. The $\cosh t$ fa
ctors cancel:

$$I = \int_{0}^{\infty} \cos(\sinh t)\,\sin(\cosh t)\,dt.$$

**Step 2: Product-to-sum.** Using $\cos A\sin B = \tfrac12[\sin(A+B)+\sin(B-A)]$
:

$$I = \frac12\int_{0}^{\infty}\bigl[\sin(\sinh t+\cosh t)+\sin(\cosh t-\sinh t)\
bigr]dt.$$

Since $\sinh t+\cosh t = e^t$ and $\cosh t-\sinh t = e^{-t}$:

$$I = \frac12\int_{0}^{\infty}\sin(e^t)\,dt + \frac12\int_{0}^{\infty}\sin(e^{-t
})\,dt.$$

**Step 3: Reduce both integrals to $\int \frac{\sin u}{u}\,du$.**

- For $\int_0^\infty \sin(e^t)\,dt$: set $u=e^t$, $dt=du/u$, limits $1\to\infty$
:
$$\int_{0}^{\infty}\sin(e^t)\,dt = \int_{1}^{\infty}\frac{\sin u}{u}\,du.$$

- For $\int_0^\infty \sin(e^{-t})\,dt$: set $u=e^{-t}$, $dt=-du/u$, limits $1\to
 0$:
$$\int_{0}^{\infty}\sin(e^{-t})\,dt = \int_{0}^{1}\frac{\sin u}{u}\,du.$$

**Step 4: Combine.**

$$I = \frac12\int_{1}^{\infty}\frac{\sin u}{u}\,du + \frac12\int_{0}^{1}\frac{\s
in u}{u}\,du = \frac12\int_{0}^{\infty}\frac{\sin u}{u}\,du.$$

By the classical Dirichlet integral, $\displaystyle\int_{0}^{\infty}\frac{\sin u
}{u}\,du = \frac{\pi}{2}$.

**Convergence justification.** For large $x$, $\sqrt{1+x^2}=x+\frac{1}{2x}+O(x^{
-3})$, so the integrand is $\frac{\cos x\,\sin(x+1/(2x)+O(x^{-3}))}{x}$. Product
-to-sum yields a rapidly oscillating term $\frac{\sin(2x+\cdots)}{2x}$ (converge
nt by Dirichlet's test) and a term $\frac{\sin(1/(2x)+\cdots)}{2x}\sim\frac{1}{4
x^2}$ (absolutely integrable). Hence the original integral converges, validating
 the substitution. $\square$

$$\boxed{I = \frac{\pi}{4}}$$
