## Proof

Let $F: \mathbb{R}^{n \times n} \to \mathrm{Sym}(n, \mathbb{R})$ be the map $F(X
) = X^T X - I_n$, where the codomain is the space of real symmetric $n \times n$
 matrices (dimension $\tfrac{n(n+1)}{2}$). The proposed zero set is $F^{-1}(0)$.

### Step 1. Set-theoretic correctness

By definition, $O(n) = \{X \in \mathbb{R}^{n \times n} : X^T X = I_n\} = F^{-1}(
0)$. So the zero set equals $O(n)$ as a set. The remaining question is whether t
his zero set is genuinely a *manifold*, i.e., whether $0$ is a regular value of
$F$.

### Step 2. $0$ is a regular value of $F$

The derivative of $F$ at $X$ in direction $H$ is
$$dF_X(H) = X^T H + H^T X,$$
which is symmetric, so it lands in $\mathrm{Sym}(n, \mathbb{R})$ as required.

We claim $dF_X$ is surjective for every $X \in O(n)$. Given any $S \in \mathrm{S
ym}(n, \mathbb{R})$, set $H = \tfrac{1}{2} X S$. Then, using $X^T X = I_n$,
$$dF_X(H) = X^T\!\left(\tfrac{1}{2}XS\right) + \left(\tfrac{1}{2}XS\right)^T X =
 \tfrac{1}{2}(X^T X) S + \tfrac{1}{2} S^T (X^T X) = \tfrac{1}{2}S + \tfrac{1}{2}
S = S.$$
Hence $dF_X$ is surjective at every point of $F^{-1}(0)$, so $0$ is a regular va
lue. By the **Regular Value Theorem**, $O(n) = F^{-1}(0)$ is a smooth embedded s
ubmanifold of $\mathbb{R}^{n \times n}$ of dimension
$$n^2 - \tfrac{n(n+1)}{2} = \tfrac{n(n-1)}{2},$$
which is the well-known dimension of $O(n)$.

### Step 3. Check $n = 1$

Here $X = [x]$, and the single equation is
$$x^2 - 1 = 0 \implies x \in \{-1, +1\}.$$
The zero set is the two-point set $\{-1, +1\} = O(1)$, a $0$-dimensional manifol

### Step 4. Check $n = 2$

$$f_1 = a^2 + c^2 - 1 = 0, \qquad f_2 = ab + cd = 0, \qquad f_3 = b^2 + d^2 - 1
= 0.$$

The $3 \times 4$ Jacobian is

At any solution, $(a,c) \neq 0$ (from $f_1$) and $(b,d) \neq 0$ (from $f_3$), an
d $f_2$ says $(a,c) \cdot (b,d) = 0$, so the two vectors $(a,c)$ and $(b,d)$ are
