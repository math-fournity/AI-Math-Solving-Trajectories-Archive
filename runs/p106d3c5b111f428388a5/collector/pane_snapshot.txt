## Proof

Define $P(z) = \prod_{i=1}^{n}(z - a_i)$, a monic polynomial of degree $n = 2k+1
$. Then

$$\frac{P'(z)}{P(z)} = \sum_{i=1}^{n}\frac{1}{z-a_i}, \qquad \frac{d}{dz}\!\left
(\frac{P'(z)}{P(z)}\right) = -\sum_{i=1}^{n}\frac{1}{(z-a_i)^2}.$$

**Step 1. The first condition gives $P'(b_j)=0$.**

Since $b_j$ is real and each $b_j$ satisfies $\sum_i \frac{1}{b_j-a_i}=0$, we ha
ve $\frac{P'(b_j)}{P(b_j)}=0$. In particular $b_j \neq a_i$ for all $i$ (otherwi
se the sum is undefined), so $P(b_j)\neq 0$, hence

$$P'(b_j) = 0, \qquad j=1,\dots,k. \tag{1}$$

**Step 2. The second condition gives $P''(b_j)=0$.**

Using $\left(\frac{P'}{P}\right)' = \frac{P''P-(P')^2}{P^2}$ and (1) (so $P'(b_j
)=0$):

$$\left(\frac{P'}{P}\right)'\bigg|_{z=b_j} = \frac{P''(b_j)}{P(b_j)}.$$

The second condition $\sum_i \frac{1}{(b_j-a_i)^2}=0$ says $-\left(\frac{P'}{P}\
right)'\big|_{b_j}=0$, hence

$$P''(b_j) = 0, \qquad j=1,\dots,k. \tag{2}$$

**Step 3. $P'(z)$ is a constant times a perfect square.**

From (1) and (2), each $b_j$ is a common root of $P'$ and $P''=(P')'$, i.e. a mu
ltiple root of $P'$. Thus $Q(z):=\prod_{j=1}^{k}(z-b_j)$ satisfies $Q^2 \mid P'$
. Since $\deg P' = n-1 = 2k = 2\deg Q$, we must have

$$P'(z) = c\, Q(z)^2$$

for some constant $c$.

**Step 4. Compare leading coefficients.**

Write $P(z) = z^n - e_1 z^{n-1} + \cdots$ with $e_1 = \sum_{i=1}^n a_i$. Then

$$P'(z) = n\,z^{n-1} - (n-1)e_1\, z^{n-2} + \cdots.$$

On the other hand, with $S := b_1+\cdots+b_k$,

$$Q(z) = z^k - S\,z^{k-1} + \cdots, \qquad Q(z)^2 = z^{2k} - 2S\,z^{2k-1} + \cdo
ts.$$

Comparing the two leading coefficients of $P'(z) = c\,Q(z)^2$:

- $z^{2k}$ term: $c = n$.
- $z^{2k-1}$ term: $-(n-1)e_1 = -c\cdot 2S = -2nS$.

Therefore

$$S = \frac{(n-1)\,e_1}{2n} = \frac{(n-1)\sum_{i=1}^{n} a_i}{2n}.$$

Since $n-1 = 2k$, this is equivalently $S = \dfrac{k\sum_i a_i}{n}$.

$$\boxed{\,b_1 + b_2 + \cdots + b_k = \dfrac{(n-1)\sum_{i=1}^{n} a_i}{2n}\,}$$
