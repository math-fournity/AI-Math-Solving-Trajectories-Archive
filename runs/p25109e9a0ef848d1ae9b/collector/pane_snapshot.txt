Since $X$ is a bounded continuous martingale, there exists a constant $C>0$ such
 that $|X_s|\le C$ for all $s\ge 0$ almost surely. In particular,

$$e^{X_s} \ge e^{-C} > 0 \quad \text{for all } s\ge 0 \text{ a.s.}$$

Since $X$ is continuous, its quadratic variation $\langle X\rangle_s$ is a conti
nuous, non-decreasing process, so $d\langle X\rangle_s$ defines a non-negative m
easure on $[0,t]$. The integrand $e^{X_s}$ is strictly positive, hence

$$\int_0^t e^{X_s}\,d\langle X\rangle_s \ge 0 \quad \text{a.s.}$$

This is a non-negative random variable whose expectation is zero by hypothesis.
Therefore

$$\int_0^t e^{X_s}\,d\langle X\rangle_s = 0 \quad \text{a.s.}$$

Using the lower bound $e^{X_s}\ge e^{-C}$:

$$0 = \int_0^t e^{X_s}\,d\langle X\rangle_s \ge e^{-C}\int_0^t d\langle X\rangle
_s = e^{-C}\,\langle X\rangle_t,$$

so $\langle X\rangle_t = 0$ a.s. for every $t\ge 0$.

Since $\langle X\rangle$ is a continuous process and $\langle X\rangle_t=0$ a.s.
 for each $t$, we may take a countable dense subset $\{t_n\}_{n\ge 1}\subset[0,\
infty)$ and intersect the corresponding probability-one events to conclude

$$\langle X\rangle_t = 0 \quad \text{for all } t\ge 0, \text{ a.s.}$$

Now set $M_t := X_t - X_0 = X_t$. Then $M$ is a bounded (hence square-integrable
) continuous martingale with $M_0=0$ and $\langle M\rangle_t = \langle X\rangle_
t = 0$ for all $t\ge 0$ a.s.

For a square-integrable martingale, the process $M_t^2 - \langle M\rangle_t$ is
a martingale. Taking expectations:

$$\mathbb{E}[M_t^2] = \mathbb{E}[M_0^2] + \mathbb{E}[\langle M\rangle_t] = 0 + 0
 = 0.$$

Since $M_t^2\ge 0$ and $\mathbb{E}[M_t^2]=0$, we obtain $M_t=0$ a.s. for each $t
\ge 0$. By continuity of the sample paths, a countability argument yields

$$M_t = 0 \quad \text{for all } t\ge 0, \text{ a.s.}$$

Therefore $X_t = M_t = 0$ for all $t\ge 0$ almost surely, i.e., $X_t$ is identic
