## Proof

Let $E$ be the set of numbers in $(0,1)$ whose decimal expansion contains a run
of $100$ consecutive $4$'s, and let $F = (0,1) \setminus E$ be its complement (n
umbers whose decimal expansion contains no such run). We show $m(F) = 0$, which
gives $m(E) = 1$.

**Decimal expansion convention.** Every $x \in (0,1)$ has a decimal expansion $x
 = 0.d_1 d_2 d_3 \dots$ with $d_i \in \{0,1,\dots,9\}$. The set of numbers with
two distinct expansions (the rationals of the form $k/10^n$) is countable, hence
 has Lebesgue measure $0$, and is irrelevant to the computation. For all other n
umbers the expansion is unique. Under Lebesgue measure on $(0,1)$, the digits $d
_1, d_2, \dots$ are independent and uniformly distributed on $\{0,1,\dots,9\}$.

**Key estimate.** For each $n \geq 1$, let $A_n$ be the set of $x \in (0,1)$ suc
h that among the first $n$ digits $d_1, \dots, d_n$ there is **no** run of $100$
 consecutive $4$'s. Since a number in $F$ has no such run in its entire expansio
n, it certainly has none in the first $n$ digits, so
$$F \subseteq A_n \quad \text{for all } n, \qquad \text{hence } m(F) \le m(A_n)
\text{ for all } n.$$

Now partition the first $n$ digits into $\lfloor n/100 \rfloor$ **disjoint** blo
cks of $100$ consecutive digits:
$$B_1 = (d_1, \dots, d_{100}),\quad B_2 = (d_{101}, \dots, d_{200}),\quad \dots,
\quad B_{\lfloor n/100\rfloor} = (d_{100(\lfloor n/100\rfloor-1)+1}, \dots, d_{1
00\lfloor n/100\rfloor}).$$

If any block $B_j$ consists entirely of $4$'s, then $x$ has a run of $100$ conse
cutive $4$'s, so $x \notin A_n$. Contrapositively,
$$A_n \subseteq \{\text{no block } B_j \text{ is all } 4\text{'s}\}.$$

The blocks depend on disjoint sets of independent digits, so the events "$B_j$ i
s all $4$'s" are independent. Each has probability $10^{-100}$. Therefore
$$m(A_n) \le \Pr(\text{no } B_j \text{ is all } 4\text{'s}) = \left(1 - 10^{-100
}\right)^{\lfloor n/100 \rfloor}.$$

**Taking the limit.** Since $0 < 1 - 10^{-100} < 1$ and $\lfloor n/100 \rfloor \
to \infty$ as $n \to \infty$,
$$\left(1 - 10^{-100}\right)^{\lfloor n/100 \rfloor} \xrightarrow{n \to \infty}
0.$$

Combining,
$$m(F) \le m(A_n) \le \left(1 - 10^{-100}\right)^{\lfloor n/100 \rfloor} \xright
arrow{n \to \infty} 0.$$

Since $m(F) \ge 0$, we conclude $m(F) = 0$.

**Conclusion.** The set $E$ of numbers in $(0,1)$ containing $100$ consecutive $
4$'s in their decimal expansion is the complement of a null set within $(0,1)$,
so
$$\boxed{m(E) = 1}.$$
