## 分析

这是 **Erdős Problem 968**，一个公认的研究开放问题。让我来分析一下已知信息以及为
何它仍未解决。

**设置：** $u_n = p_n / n$，其中 $p_n$ 是第 $n$ 个素数。根据素数定理 (PNT)，$p_n
 \sim n \log n$，因此 $u_n \sim \log n \to \infty$。

**核心条件：** $u_n < u_{n+1}$ 当且仅当 $n \cdot g_n > p_n$，其中 $g_n = p_{n+1}
 - p_n$ 是素数间隙。由于 $u_n \sim \log n$，这大致等同于素数间隙超过其“预期”大小
 $\log n$。

**已知信息（Erdős–Prachar [ErPr61]）：**
1. $\sum_{p_n < x} |u_{n+1} - u_n| \asymp (\log x)^2$ —— 总变差很大。
2. 集合 $\{n : u_n > u_{n+1}\}$（递减步长）具有**正下密度**。

**变差分析：** 设 $A(N) = \sum_{n \le N, u_n < u_{n+1}} (u_{n+1} - u_n)$ 且 $B(N
) = \sum_{n \le N, u_n > u_{n+1}} (u_n - u_{n+1})$。则：
- $A(N) - B(N) = u_{N+1} - u_1 \sim \log N$（净变化）。
- $A(N) + B(N) \sim (\log N)^2$（总变差）。

因此 $A(N) \sim B(N) \sim \frac{(\log N)^2}{2}$。向上的总运动和向下的总运动都很
大，且渐近相等。

**为什么这不能解决该问题：** 大总变差 $A(N) \sim (\log N)^2/2$ 与递增集的正密度
并**不**等价。递增集 $\{n : u_n < u_{n+1}\}$ 可能具有零下密度，但伴随罕见的大跳
跃，而递减集则具有正密度但伴随许多小步长——这仍然与所有已知约束相容。从总变差界限
到密度结论的推导需要控制个体步长的大小，这取决于未知的素数间隙精细分布。

**为什么这是一个真正开放的问题：** Erdős 本人在 erdosproblems.com/968 上提出了这
个问题。Lean 形式化将 `erdos_968` 标记为 `category research open`。解决它需要关
于素数间隙的新思路，这超越了 Erdős–Prachar 的变差方法以及目前关于素数间隙分布的
知识（即使有 Maynard、Banks–Freiberg–Turnage-Butterbaugh 等人关于小间隙和有界间
隙的最先进成果，也无法解决这个问题）。

这是一个开放的研究问题，我无法解决。
