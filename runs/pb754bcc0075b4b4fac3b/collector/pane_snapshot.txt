**Claim.** $P_M - P_N$ is the orthogonal projection onto $M \cap N^\perp$ (the o
rthogonal complement of $N$ within $M$, often denoted $M \ominus N$).

---

**Step 1: The projections commute in a useful way.**

Since $N \subset M$, for any $x \in H$ we can decompose $M = N \oplus (M \cap N^
\perp)$, so
$$P_M x = P_N x + P_{M\cap N^\perp} x.$$
Applying $P_N$ to $P_M x$: since $P_M x \in M$ and $N \subset M$, the component
of $P_M x$ along $N$ is exactly $P_N x$, while the component along $M \cap N^\pe
rp \subset N^\perp$ is annihilated. Hence
$$P_N P_M = P_N.$$
Likewise $P_M P_N = P_N$ since $P_N x \in N \subset M$ implies $P_M(P_N x) = P_N
 x$.

**Step 2: $P_M - P_N$ is self-adjoint and idempotent.**

Self-adjointness is immediate:
$$(P_M - P_N)^* = P_M^* - P_N^* = P_M - P_N.$$

For idempotence, using Step 1:
$$(P_M - P_N)^2 = P_M^2 - P_M P_N - P_N P_M + P_N^2 = P_M - P_N - P_N + P_N = P_
M - P_N.$$

A self-adjoint idempotent operator on a Hilbert space is an orthogonal projectio
n. So $P_M - P_N$ is an orthogonal projection; its range is the subspace it proj
ects onto.

**Step 3: Identify the range.**

The range of an orthogonal projection $P$ is $\{x : Px = x\}$. We find all $x$ w
ith $(P_M - P_N)x = x$.

*($\supseteq$)* If $x \in M \cap N^\perp$, then $P_M x = x$ (since $x \in M$) an
d $P_N x = 0$ (since $x \in N^\perp$), so $(P_M - P_N)x = x$.

*($\subseteq$)* Suppose $(P_M - P_N)x = x$, i.e., $P_M x - P_N x = x$. Apply $P_
N$ to both sides:
$$P_N P_M x - P_N^2 x = P_N x \implies P_N x - P_N x = P_N x \implies P_N x = 0.
$$
So $x \in N^\perp$. Substituting back: $P_M x = x$, so $x \in M$. Therefore $x \
in M \cap N^\perp$.

**Conclusion.** The range of $P_M - P_N$ is exactly $M \cap N^\perp$. Thus $P_M
- P_N$ is the orthogonal projection onto the subspace

$$\boxed{M \cap N^\perp \;=\; M \ominus N},$$

the orthogonal complement of $N$ within $M$.
