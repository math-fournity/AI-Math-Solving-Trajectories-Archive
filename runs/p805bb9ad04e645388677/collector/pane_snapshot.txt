**Proof.**

Define $S_n = \frac{1}{n}\sum_{i=1}^n Y_{i,n}^2$. We expand each $Y_{i,n}^2$:

$$Y_{i,n}^2 = \frac{1}{n^2}\left(\sum_{j=1}^n X_{ij}\right)^2 = \frac{1}{n^2}\su
m_{j=1}^n X_{ij}^2 + \frac{1}{n^2}\sum_{\substack{j,l=1\\j\neq l}}^n X_{ij}X_{il
}.$$

Thus $S_n = T_n + U_n$, where:

$$T_n = \frac{1}{n^3}\sum_{i=1}^n\sum_{j=1}^n X_{ij}^2, \qquad U_n = \frac{1}{n^
3}\sum_{i=1}^n\sum_{\substack{j,l=1\\j\neq l}}^n X_{ij}X_{il}.$$

**Step 1: $T_n \to 0$ a.s.**

Write $T_n = \frac{1}{n}\cdot\frac{1}{n^2}\sum_{i=1}^n\sum_{j=1}^n X_{ij}^2$. Th
e random variables $\{X_{ij}^2\}$ are i.i.d. with $E[X_{ij}^2] = E[X^2] = 1 < \i
nfty$. By the Strong Law of Large Numbers:

$$\frac{1}{n^2}\sum_{i=1}^n\sum_{j=1}^n X_{ij}^2 \to 1 \quad \text{a.s.}$$

Therefore $T_n \sim \frac{1}{n}\to 0$ a.s.

**Step 2: $U_n \to 0$ a.s.**

Set $W_i = \sum_{\substack{j,l=1\\j\neq l}}^n X_{ij}X_{il}$, so $U_n = \frac{1}{
n^3}\sum_{i=1}^n W_i$, where $W_1,\dots,W_n$ are i.i.d.

*Mean:* $E[W_i] = \sum_{j\neq l} E[X_{ij}]\,E[X_{il}] = 0$ by independence and $
E[X]=0$.

*Second moment:* We compute $E[W_i^2] = \sum_{\substack{j\neq l}}\sum_{\substack
{j'\neq l'}} E[X_{ij}X_{il}X_{ij'}X_{il'}]$.

By independence and $E[X]=0$, a term is nonzero only if each index among $\{j,l,
j',l'\}$ appears at least twice. Given the constraints $j\neq l$ and $j'\neq l'$
, the only possibilities are:
- $j=j',\; l=l'$: contributes $E[X_{ij}^2]\,E[X_{il}^2]=1$, giving $n(n-1)$ term
s.
- $j=l',\; l=j'$: contributes $E[X_{ij}^2]\,E[X_{il}^2]=1$, giving $n(n-1)$ term
s.

All other pairings force some $X_{ij}$ to appear with odd exponent, yielding $E[
X]=0$. Crucially, **no fourth moment is needed**—each surviving term factors as
$E[X^2]\cdot E[X^2]=1$.

Therefore $E[W_i^2] = 2n(n-1)$, and:

$$\text{Var}(U_n) = E[U_n^2] = \frac{1}{n^6}\sum_{i=1}^n E[W_i^2] = \frac{n\cdot
 2n(n-1)}{n^6} = \frac{2(n-1)}{n^4} \leq \frac{2}{n^3}.$$

By Chebyshev's inequality, for any $\varepsilon > 0$:

$$P(|U_n| \geq \varepsilon) \leq \frac{\text{Var}(U_n)}{\varepsilon^2} \leq \fra
c{2}{n^3\,\varepsilon^2}.$$

Since $\sum_{n=1}^\infty \frac{1}{n^3} < \infty$, we have $\sum_{n=1}^\infty P(|
U_n|\geq\varepsilon) < \infty$. By the Borel–Cantelli lemma, $P(|U_n|\geq\vareps
ilon \text{ i.o.})=0$ for every $\varepsilon>0$. Taking $\varepsilon = 1/k$ for
$k=1,2,\dots$, it follows that $U_n\to 0$ a.s.

**Conclusion.**

$$S_n = T_n + U_n \to 0 + 0 = 0 \quad \text{a.s.}$$

The proof uses only $E[X]=0$, $E[X^2]=1$, and independence—no higher moment assu
mptions are required. The key insight is that the cross-term $U_n$ has variance
$O(n^{-3})$ (summable) because the fourth-moment contributions vanish by indepen
dence and the zero-mean condition, leaving only the pairwise $E[X^2]^2$ terms.
