Definition: For a cardinal α, the intersection number i(α) is the least cardinal

(i) A_ξ ∩ A_η ≠ ∅ for all ξ ≠ η (pairwise intersecting), and
(ii) ⋂_{ξ<α} A_ξ = ∅ (empty total intersection).

Claim: For every infinite cardinal α, i(α) = min{β : 2^β ≥ α}.

Proof of Claim:
Lower bound: Any family of α distinct subsets of X requires |P(X)| = 2^|X| ≥ α,
so 2^β ≥ α where β = |X|.

Upper bound: Let β be an infinite cardinal with 2^β ≥ α. We construct a family
of 2^β ≥ α distinct, pairwise intersecting subsets of a set of size β with empty
total intersection.

Let X be a set of size β. Choose distinct a, b, c ∈ X and let Y = X \ {a,b,c}
(so |Y| = β since β is infinite). For each S ⊆ Y, define:
- A_S^{(1)} = {a,b} ∪ S,  A_S^{(2)} = {b,c} ∪ S,  A_S^{(3)} = {a,c} ∪ S.

These 3·2^β = 2^β sets are distinct (they differ on membership of a, b, c). Any
two intersect: same-type sets share {a,b}, {b,c}, or {a,c}; cross-type sets
share a, b, or c. The total intersection is {a,b} ∩ {b,c} ∩ {a,c} = ∅. Selecting
any α of these 2^β sets gives the desired family. □

Main result: For any infinite cardinal κ, take α = 2^κ. Then:
- α = 2^κ > κ ≥ κ, so α ≥ κ. ✓
- i(α) = i(2^κ) = min{β : 2^β ≥ 2^κ} ≤ κ (since 2^κ ≥ 2^κ with β = κ).
- By Cantor's theorem, κ < 2^κ = α.
- Therefore i(α) ≤ κ < α, hence i(α) < α. ✓

定义回顾。 基数 $\alpha$ 的交数 (intersection number) $i(\alpha)$ 定义为满足以下
条件的最小基数 $\beta$：存在一个由 $\alpha$ 个互不相同的集合组成的族 ${A_\xi :
\xi < \alpha}$，它们是某个基数为 $\beta$ 的集合 $X$ 的子集，满足

  1. 两两相交：$A_\xi \cap A_\eta \neq \emptyset$（对所有 $\xi \neq \eta$），
  2. 总交为空：$\bigcap_{\xi < \alpha} A_\xi = \emptyset$。

────────────────────────────────────────────────────────────────────────────────

引理：对任意无穷基数 $\alpha$，$i(\alpha) = \min{\beta : 2^\beta \geq \alpha}$。

下界。 $\alpha$ 个互不相同的子集需要 $2^{|X|} = 2^\beta \geq \alpha$，故 $\beta
\geq \min{\gamma : 2^\gamma \geq \alpha}$。

上界。 设 $\beta$ 为无穷基数且 $2^\beta \geq \alpha$。取集合 $X$，$|X| =
\beta$。选三个不同元素 $a, b, c \in X$，令 $Y = X \setminus {a,b,c}$，则 $|Y| =
\beta$（因 $\beta$ 无穷）。

对每个 $S \subseteq Y$，定义三个集合： $$A_S^{(1)} = {a,b} \cup S, \quad
A_S^{(2)} = {b,c} \cup S, \quad A_S^{(3)} = {a,c} \cup S.$$

  • 互异性：三类集合在 $a, b, c$ 的隶属关系上不同（第一类含 $a,b$ 不含 $c$；第二
  类含 $b,c$ 不含 $a$；第三类含 $a,c$ 不含 $b$），故 $3 \cdot 2^\beta = 2^\beta$
  个集合互不相同。
  • 两两相交：同类不同 $S$ 共享 ${a,b}$（或 ${b,c}$、${a,c}$）；异类共享
  $a$、$b$ 或 $c$。
  • 总交为空：$\bigcap_{S \subseteq Y} A_S^{(1)} = {a,b}$，$\bigcap_{S}
  A_S^{(2)} = {b,c}$，$\bigcap_{S} A_S^{(3)} = {a,c}$，三者之交 $= {a,b} \cap
  {b,c} \cap {a,c} = \emptyset$。

现在从这 $2^\beta$ 个集合中选出 $\alpha$ 个：取每类各一个（共 3 个），再从剩余
$2^\beta - 3 = 2^\beta$ 个中取 $\alpha - 3 = \alpha$ 个（因 $\alpha$ 无穷且
$2^\beta \geq \alpha$）。这 $\alpha$ 个集合互异、两两相交，且总交包含于
${a,b}\cap{b,c}\cap{a,c} = \emptyset$。故 $i(\alpha) \leq \beta$。

取 $\beta = \min{\gamma : 2^\gamma \geq \alpha}$（对无穷 $\alpha$，此 $\beta$ 必
无穷），即得 $i(\alpha) = \beta$。$\square$

主定理：对任意无穷基数 $\kappa$，取 $\alpha = 2^\kappa$，则 $\alpha \geq \kappa$
且 $i(\alpha) < \alpha$。

证明。 令 $\alpha = 2^\kappa$。

  1. $\alpha \geq \kappa$：由 Cantor 定理，$2^\kappa > \kappa \geq \kappa$。✓
  2. $i(\alpha) \leq \kappa$：由引理， $$i(2^\kappa) = \min{\beta : 2^\beta \geq
  2^\kappa} \leq \kappa,$$ 因为取 $\beta = \kappa$ 时 $2^\kappa \geq 2^\kappa$
  成立。✓
  3. $\kappa < \alpha$：由 Cantor 定理，$\kappa < 2^\kappa = \alpha$。✓
  4. 综合：$i(\alpha) \leq \kappa < 2^\kappa = \alpha$，故 $i(\alpha) <
  \alpha$。✓
