## Answer

**Yes, $g$ is necessarily integrable over $Q$, and $\int_Q g = \int_Q f$.**

### Proof

We work with Lebesgue measure on $\mathbb{R}^n$, which is **complete** (every su
bset of a null set is measurable). Recall that an integrable function is by defi
nition measurable with finite $L^1$-norm. Thus $f$ is measurable, and we must sh
ow $g$ is measurable and $\int_Q |g| < \infty$.

**Step 1: $g$ is measurable.**

Since $E$ is closed, $E$ is Borel (hence Lebesgue) measurable, and its complemen
t $E^c$ is open. Therefore
$$Q - E = Q \cap E^c \quad\text{and}\quad E$$
are both measurable sets partitioning $Q$.

- On $Q - E$, we have $g = f$, and $f$ is measurable, so $g\big|_{Q-E}$ is measu
rable.
- On $E$: $E$ has measure zero. For any $a \in \mathbb{R}$, the sublevel set
  $$\{x \in E : g(x) > a\} \subseteq E,$$
  and since $E$ is a null set, completeness of Lebesgue measure makes this subse
t measurable. Hence $g\big|_E$ is measurable (every function on a measurable nul
l set is measurable).

Combining the two pieces,
$$g = g\big|_{Q-E}\cdot \mathbf{1}_{Q-E} + g\big|_E \cdot \mathbf{1}_E,$$
is a sum of products of measurable functions, so $g$ is measurable on $Q$.

**Step 2: $g = f$ almost everywhere.**

By hypothesis $f(x) = g(x)$ for all $x \in Q - E$, and $E$ has measure zero. Hen
ce $f$ and $g$ differ only on the null set $E$; i.e. $f = g$ a.e. on $Q$.

**Step 3: $g$ is integrable and has the same integral as $f$.**

Set $h = g - f$. Then $h$ is measurable (difference of measurable functions) and
 $h = 0$ a.e. The nonnegative measurable function $|h|$ vanishes a.e., so
$$\int_Q |h| = 0.$$

By the triangle inequality,
$$|g| = |f + h| \le |f| + |h|.$$

Integrating (all terms nonnegative measurable),
$$\int_Q |g| \le \int_Q |f| + \int_Q |h| = \int_Q |f| + 0 = \int_Q |f| < \infty,
$$

where the last inequality uses the integrability of $f$. Hence $g \in L^1(Q)$.

Moreover,
$$\left|\int_Q g - \int_Q f\right| = \left|\int_Q h\right| \le \int_Q |h| = 0,$$

so $\displaystyle\int_Q g = \int_Q f$.

### Remark on the hypotheses

Each hypothesis is used essentially:
- **$E$ closed** is not strictly needed for the conclusion (any measurable null
set $E$ would do); what matters is that $E$ is measurable with measure zero, so
that $Q - E$ is measurable and $g\big|_E$ is measurable by completeness.
- **$g$ bounded** guarantees $g\big|_E$ is a genuine (finite) function on $E$, b
ut the argument above only needs $g$ to be a well-defined function; boundedness
is a harmless strengthening. In fact the conclusion holds for *any* measurable $
g$ equal to $f$ a.e.
- **Completeness of Lebesgue measure** is the crucial ingredient: it is what mak
es an arbitrary function on the null set $E$ automatically measurable. Without c
ompleteness (e.g. with Borel measure restricted to the Borel $\sigma$-algebra),
a function equal a.e. to an integrable function need not be measurable, and the
conclusion can fail.
