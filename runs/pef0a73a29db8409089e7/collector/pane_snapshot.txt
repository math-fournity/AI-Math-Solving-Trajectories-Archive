# Proof: Every discrete absolute value on a field is non-archimedean

We prove the **contrapositive**: if an absolute value is archimedean, then its v
alue group is dense in $\mathbb{R}_{>0}$, hence not discrete.

## Setup and definitions

Recall:
- An absolute value $|\cdot|$ on a field $F$ is **non-archimedean** if $|x+y|\le
 \max(|x|,|y|)$ for all $x,y\in F$; otherwise it is **archimedean**.
- The **value group** is $\Gamma = |F^\times| = \{|x| : x \in F^\times\} \subset
eq \mathbb{R}_{>0}$.
- The absolute value is **discrete** if $\Gamma$ is a discrete subgroup of $\mat
hbb{R}_{>0}$, equivalently $\Gamma = \{c^n : n\in\mathbb{Z}\}$ for some $c\in(0,
1)$ (or $c>1$).

## Key tool: Ostrowski's theorem (general form)

**Theorem (Ostrowski).** Let $|\cdot|$ be an archimedean absolute value on a fie
ld $F$. Then there exists a field embedding $\sigma: F \hookrightarrow \mathbb{C
}$ and a real number $0 < \alpha \le 1$ such that
$$|x| = |\sigma(x)|_{\mathbb{C}}^{\,\alpha} \quad \text{for all } x \in F,$$
where $|\cdot|_{\mathbb{C}}$ is the usual complex absolute value.

*(This follows by completing $F$ with respect to $|\cdot|$; the completion is a
complete archimedean valued field, hence isomorphic to $\mathbb{R}$ or $\mathbb{
C}$, yielding the embedding $\sigma$ and the exponent $\alpha$.)*

## The value group of an archimedean absolute value is dense

Let $|\cdot|$ be archimedean on $F$, and let $\sigma$, $\alpha$ be as in Ostrows
ki's theorem. Since $\sigma$ is a field embedding, $\sigma(1_F)=1$, hence $\sigm
a(n\cdot 1_F)=n$ and $\sigma(1/n)=1/n$ for every nonzero integer $n$. Therefore
$\sigma(F)$ contains $\mathbb{Q}$ as a subfield.

The value group is:
$$\Gamma = |F^\times| = \bigl\{|\sigma(x)|_{\mathbb{C}}^{\,\alpha} : x \in F^\ti
mes\bigr\}.$$

Since $\mathbb{Q}^\times \subseteq F^\times$ (via the identification $q \leftrig
htarrow \sigma^{-1}(q)$), we have:
$$\bigl\{|q|^\alpha : q \in \mathbb{Q}^\times\bigr\} \subseteq \Gamma.$$

Now $\{|q|_{\mathbb{C}} : q \in \mathbb{Q}^\times\} = \mathbb{Q}_{>0}$, which is
 **dense** in $\mathbb{R}_{>0}$. The map $t \mapsto t^\alpha$ is a homeomorphism
 of $\mathbb{R}_{>0}$ (as $\alpha > 0$), so it maps dense sets to dense sets. He
nce $\{q^\alpha : q \in \mathbb{Q}_{>0}\}$ is dense in $\mathbb{R}_{>0}$.

Since $\Gamma$ contains a dense subset of $\mathbb{R}_{>0}$, the group $\Gamma$
itself is **dense** in $\mathbb{R}_{>0}$.

## Conclusion

A dense subgroup of $\mathbb{R}_{>0}$ cannot be discrete: the only discrete subg
roups of $\mathbb{R}_{>0}$ (under multiplication) are cyclic groups $\{c^n : n \
in \mathbb{Z}\}$, which are closed and have no accumulation points—manifestly no
t dense.

Therefore: **archimedean $\Longrightarrow$ value group is dense $\Longrightarrow
$ value group is not discrete.**

Taking the contrapositive:

$$\text{value group is discrete} \Longrightarrow \text{absolute value is not arc
himedean} \Longrightarrow \text{absolute value is non-archimedean}.$$

Hence **every discrete absolute value on a field is non-archimedean**. $\blacksq
uare$
