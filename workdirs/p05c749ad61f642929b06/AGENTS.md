# Problem

In the futuristic city of Neoterra, a modular data-processing core is constructed using $2015^{100}$ identical $1 \times 1 \times 1$ nanoblock units. An architect must organize all these units into a single configuration consisting of one or more "Processing Clusters."

Every Processing Cluster in a given configuration must be a rectangular prism of identical dimensions (length, width, and height), and every single nanoblock must be used. For example, the blocks could be arranged into one giant rectangular prism, or split into several smaller, perfectly congruent rectangular prisms.

Let $B(2015^{100})$ represent the total number of distinct ways to choose the dimensions of these congruent clusters such that all $2015^{100}$ units are utilized. 

Determine the integer $m$ that satisfies the inequality:
$10^m < B(2015^{100}) < 10^{m+1}$
