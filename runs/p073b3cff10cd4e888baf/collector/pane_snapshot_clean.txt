Looking at this problem, I need to find the maximum size of a set $A \subseteq \
{1, 2, \ldots, 2018\}$ such that every 3-element subset contains a pair $(m, n)$
 with $|n - m| \ge \sqrt{n} + \sqrt{m}$.

## Key Reduction

**Definition.** For $m < n$, call the pair "close" if $n - m < \sqrt{n} + \sqrt{
m}$, i.e., $n - \sqrt{n} < m + \sqrt{m}$.

The condition requires: no 3 elements of $A$ are pairwise close.

**Lemma 1.** Three elements $a < b < c$ are pairwise close if and only if $c - \
sqrt{c} < a + \sqrt{a}$.

*Proof.* If $c - \sqrt{c} < a + \sqrt{a}$, then since $f(x) = x - \sqrt{x}$ is i
ncreasing: $b - \sqrt{b} < c - \sqrt{c} < a + \sqrt{a}$ (so $(a,b)$ close), and
since $g(x) = x + \sqrt{x}$ is increasing: $c - \sqrt{c} < a + \sqrt{a} < b + \s
qrt{b}$ (so $(b,c)$ close), and $(a,c)$ close by assumption. Conversely, if all
three pairs are close, in particular $(a,c)$ is close. $\square$

**Lemma 2.** The condition is equivalent to: for every three *consecutive* eleme
nts $a_i < a_{i+1} < a_{i+2}$ in $A$, we have $a_{i+2} - \sqrt{a_{i+2}} \ge a_i
+ \sqrt{a_i}$.

*Proof.* If some non-consecutive triple $a_i < a_j < a_k$ ($j \ge i+2$, $k \ge j
+2$) violated the condition, then $a_k - \sqrt{a_k} < a_i + \sqrt{a_i}$. Since $
a_{i+2} \le a_k$ and $f$ is increasing, $a_{i+2} - \sqrt{a_{i+2}} \le a_k - \sqr
t{a_k} < a_i + \sqrt{a_i}$, so the consecutive triple $(a_i, a_{i+1}, a_{i+2})$
also violates it. $\square$

## Two-Chain Decomposition

Write $A = \{a_1 < a_2 < \cdots < a_k\}$. The constraint $a_{i+2} - \sqrt{a_{i+2
}} \ge a_i + \sqrt{a_i}$ links only elements two apart. Define $T(a)$ = smallest
 integer $n$ with $n - \sqrt{n} \ge a + \sqrt{a}$. Then the constraint is $a_{i+
2} \ge T(a_i)$.

The odd-indexed subsequence $\{a_1, a_3, a_5, \ldots\}$ and even-indexed subsequ
ence $\{a_2, a_4, a_6, \ldots\}$ are independent chains, each satisfying "next $
\ge T$(prev)". To maximize $|A|$, we maximize the sum of chain lengths.

**Greedy is optimal:** Since $T$ is increasing, taking the smallest possible nex
t element at each step keeps all future elements as small as possible, maximizin
g chain length before exceeding 2018.

## Computing Chain Lengths

**Chain from 1 (perfect squares):** $T(n^2) = (n+1)^2$ since $(n+1)^2 - (n+1) =
n^2 + n = n^2 + \sqrt{n^2}$, and $(n+1)^2 - 1$ fails. The chain is $1, 4, 9, \ld
ots, 44^2 = 1936$ (since $T(1936) = 45^2 = 2025 > 2018$). **Length = 44.**

**Chain from 2 (pronic numbers):** $T(n^2+n) = (n+1)^2+(n+1)$. Verification: nee
d $2(n+1) \ge \sqrt{(n+1)(n+2)} + \sqrt{n(n+1)} = \sqrt{n+1}(\sqrt{n+2}+\sqrt{n}
)$, i.e., $2\sqrt{n+1} \ge \sqrt{n+2}+\sqrt{n}$, which holds by concavity of $\s
qrt{x}$. Also $(n+1)^2+(n+1)-1$ fails (checked: $2n+1 < \sqrt{n^2+3n+1}+\sqrt{n^
2+n}$). The chain is $2, 6, 12, 20, \ldots, 44 \cdot 45 = 1980$ (since $T(1980)
= 45 \cdot 46 = 2070 > 2018$). **Length = 44.**

## Construction: $|A| = 88$

$$A = \{n^2 : 1 \le n \le 44\} \cup \{n(n+1) : 1 \le n \le 44\}$$

**Interleaving works:** $n^2 < n^2 + n < (n+1)^2$ for $n \ge 1$, so the sorted o
rder is $1, 2, 4, 6, 9, 12, 16, 20, \ldots$

**Verification of consecutive triples:**
- **Type** $(n^2,\; n^2{+}n,\; (n{+}1)^2)$: Need $(n{+}1)^2 - (n{+}1) \ge n^2 +
n$, i.e., $n^2+n \ge n^2+n$. ✓ (equality)
- **Type** $(n^2{+}n,\; (n{+}1)^2,\; (n{+}1)(n{+}2))$: Need $2(n{+}1) \ge \sqrt{
(n{+}1)(n{+}2)}+\sqrt{n(n{+}1)}$, i.e., $2\sqrt{n{+}1} \ge \sqrt{n{+}2}+\sqrt{n}
$. ✓ by concavity of $\sqrt{x}$.

All 88 elements are $\le 1980 \le 2018$. ✓

## Upper Bound: $|A| \le 88$

Any valid $A$ decomposes into two chains starting at $a_1 \ge 1$ and $a_2 \ge 2$
. Since $L(s)$ (max chain length from $s$) is decreasing in $s$:

$$|A| = L(a_1) + L(a_2) \le L(1) + L(2) = 44 + 44 = 88.$$
