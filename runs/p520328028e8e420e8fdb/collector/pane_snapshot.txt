非同构良序的计数

问题

确定自然数集 $\mathbb{N}$ 上非同构良序的个数。

证明

第一步：良序与序型的一一对应。

$\mathbb{N}$ 上的一个良序是一个二元关系，它将 $\mathbb{N}$ 良序化。每个这样的良
序具有唯一的序型（order type），即某个序数 $\alpha$。两个 $\mathbb{N}$ 上的良序
同构当且仅当它们具有相同的序型（这是良序理论的标准事实：任意两个良序同构当且仅当
序型相同）。

因此，非同构良序的个数 = 可作为 $\mathbb{N}$ 上良序序型的序数 $\alpha$ 的个数。

第二步：确定哪些序数可以作为 $\mathbb{N}$ 上良序的序型。

  • 必要条件：若 $\alpha$ 是 $\mathbb{N}$ 上某良序的序型，则 $|\alpha| = |
  \mathbb{N}| = \aleph_0$，即 $\alpha$ 是可数无穷序数。因此 $\omega \leq \alpha
  < \omega_1$（其中 $\omega_1$ 是第一个不可数序数）。
  • 充分条件：设 $\alpha$ 是任意满足 $\omega \leq \alpha < \omega_1$ 的序数。由
  于 $\alpha$ 是可数的，存在双射 $f: \mathbb{N} \to \alpha$。在 $\mathbb{N}$ 上
  定义关系 $a \prec b \iff f(a) < f(b)$（其中 $<$ 是 $\alpha$ 中的序数序）。因为
  $f$ 是双射且 $\alpha$ 是良序，$(\mathbb{N}, \prec)$ 是良序，其序型恰为 $
  \alpha$。

因此，$\mathbb{N}$ 上良序的序型恰好是集合 ${\alpha : \omega \leq \alpha <
\omega_1}$。

第三步：计数。

所有可数序数的集合是 $\omega_1 = {\alpha : \alpha < \omega_1}$，其基数为 $
\aleph_1$。

从中去掉有限序数 ${0, 1, 2, \ldots}$（共 $\aleph_0$ 个），得到 ${\alpha : \omega
\leq \alpha < \omega_1}$，其基数为：

$$\aleph_1 - \aleph_0 = \aleph_1$$

（因为 $\aleph_1$ 是不可数基数，减去可数多个仍为 $\aleph_1$。）

结论。

$\mathbb{N}$ 上非同构良序的个数为 $\boxed{\aleph_1}$。
