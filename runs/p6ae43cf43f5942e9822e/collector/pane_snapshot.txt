## Theorem 1: `zagierDim_first_values`

**Statement.** The first ten values of the Zagier dimension sequence are $[1, 0,
 1, 1, 1, 2, 2, 3, 4, 5]$.

**Proof.** The sequence is defined by:
$$d_0 = 1,\quad d_1 = 0,\quad d_2 = 1,\quad d_{n+3} = d_{n+1} + d_n \text{ for }
 n \geq 0.$$

We compute each value by direct application of the recurrence:

| $n$ | Computation | $d_n$ |
|-----|-------------|-------|
| 0 | base case | 1 |
| 1 | base case | 0 |
| 2 | base case | 1 |
| 3 | $d_1 + d_0 = 0 + 1$ | 1 |
| 4 | $d_2 + d_1 = 1 + 0$ | 1 |
| 5 | $d_3 + d_2 = 1 + 1$ | 2 |
| 6 | $d_4 + d_3 = 1 + 1$ | 2 |
| 7 | $d_5 + d_4 = 2 + 1$ | 3 |
| 8 | $d_6 + d_5 = 2 + 2$ | 4 |
| 9 | $d_7 + d_6 = 3 + 2$ | 5 |

This yields $[d_0, \ldots, d_9] = [1, 0, 1, 1, 1, 2, 2, 3, 4, 5]$. $\square$

*(In Lean, since `zagierDim` is defined by structural recursion on $\mathbb{N}$,
 it is computable, and the equality is verified by `decide`.)*

## Theorem 2: `no_admissible_weight_one`

**Statement.** For any $s : \text{List}\ \mathbb{N}$, if $\text{AdmissibleIndex}
\ s$, then $\text{weight}\ s \neq 1$.

**Proof.** We proceed by cases on the list $s$.

**Case 1: $s = []$.** Then $\text{weight}(s) = \text{List.sum}\ [] = 0 \neq 1$.

**Case 2: $s = s_1 :: \text{rest}$.** By the definition of `AdmissibleIndex`, we
 have:
- $1 < s_1$, i.e., $s_1 \geq 2$, and
- $\forall\, s_i \in \text{rest},\ 0 < s_i$, i.e., every element of `rest` is $\
geq 1$.

The weight is:
$$\text{weight}(s) = s_1 + \text{List.sum}(\text{rest}).$$

- If $\text{rest} = []$: $\text{weight}(s) = s_1 \geq 2 > 1$.
- If $\text{rest} \neq []$: every element of $\text{rest}$ is $\geq 1$, so $\tex
t{List.sum}(\text{rest}) \geq |\text{rest}| \geq 1$, giving $\text{weight}(s) \g
eq s_1 + 1 \geq 3 > 1$.

In all subcases, $\text{weight}(s) \geq 2$, hence $\text{weight}(s) \neq 1$. $\s
quare$

## Theorem 3: $\mathcal{Z}_0 = \mathbb{Q}$, so $\dim_{\mathbb{Q}}(\mathcal{Z}_0)
 = 1$

**Statement.** $\text{Module.finrank}\ \mathbb{Q}\ (\text{mzvSpanOfWeight}\ 0) =
 \text{zagierDim}\ 0 = 1$.

**Proof.** We proceed in four steps.

**Step 1: Characterize the admissible indices of weight 0.**

We claim $\{s \mid \text{AdmissibleIndex}\ s \wedge \text{weight}\ s = 0\} = \{[
]\}$.

- $s = []$: $\text{AdmissibleIndex}([]) = \text{True}$ and $\text{weight}([]) =
0$. ✓
- $s = s_1 :: \text{rest}$: $\text{AdmissibleIndex}$ requires $s_1 \geq 2$, so $
\text{weight}(s) = s_1 + \text{sum}(\text{rest}) \geq 2 > 0$. ✗

So the empty list is the unique admissible index of weight 0.

**Step 2: Compute the MZV set of weight 0.**

$$\text{mzvSetOfWeight}(0) = \text{multiZeta}''\{[]\} = \{\text{multiZeta}([])\}
 = \{1\},$$

since $\text{multiZeta}([]) = 1$ by the empty product convention.

**Step 3: Compute the $\mathbb{Q}$-span.**

$$\text{mzvSpanOfWeight}(0) = \text{Submodule.span}_{\mathbb{Q}}\ \{1\} = \{q \c
dot 1 : q \in \mathbb{Q}\} \cong \mathbb{Q}.$$

This is a 1-dimensional $\mathbb{Q}$-vector space (the element $1$ is $\mathbb{Q
}$-linearly independent, since $q \cdot 1 = 0$ in $\mathbb{R}$ implies $q = 0$).

**Step 4: Conclude.**

$$\text{Module.finrank}\ \mathbb{Q}\ (\text{mzvSpanOfWeight}\ 0) = 1 = \text{zag
ierDim}(0). \quad \square$$

This verifies the Zagier conjecture in the base case $n = 0$.

## Summary of the Research-Level Theorems

- **`zagier_upper_bound`** (solved): The inequality $\dim_{\mathbb{Q}} \mathcal{
Z}_n \leq d_n$ was established by Terasoma (2002) and independently by Deligne–G
oncharov (2005). The proof proceeds by identifying MZVs with periods of mixed Ta
te motives over $\mathbb{Z}$, then bounding the dimension of the weight-$n$ grad
ed piece of the motivic Hopf algebra $\mathcal{A} = \mathbb{Q}\langle e_0, e_1 \
rangle / (e_0^2 = e_1^2 = 0)$ by $d_n$ via the theory of the motivic fundamental
 group of $\mathbb{P}^1 \setminus \{0, 1, \infty\}$. The key computation shows t
hat the dimensions of the motivic Lie algebra's graded pieces satisfy the same r
ecurrence $d_n = d_{n-2} + d_{n-3}$.

- **`zagier_conjecture`** (open): The equality $\dim_{\mathbb{Q}} \mathcal{Z}_n
= d_n$ remains unproven. The lower bound $\dim_{\mathbb{Q}} \mathcal{Z}_n \geq d
_n$ (which combined with the upper bound would give equality) is verified numeri
cally to high weights and is supported by extensive computational evidence (Brow
n, Gangl–Komiyama, etc.), but no proof is known. The conjecture predicts that th
e only $\mathbb{Q}$-linear relations among MZVs of a given weight are those gene
rated by the standard double-shuffle and duality relations.
