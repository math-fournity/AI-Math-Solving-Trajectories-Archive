## Proof

**Theorem.** Let (R, m) be an infinite local ring (not necessarily commutative)
that is not a division ring. Then |R| = |m|.

**Proof.**

Since R is not a division ring, the maximal ideal m is nonzero. Indeed, if m = 0
, then 0 is the unique maximal ideal of R, so R has no proper nonzero (left/righ
t/two-sided) ideals, which means R is a division ring—a contradiction. Thus **m
≠ 0**.

Pick any nonzero element c ∈ m. Consider the map of additive groups

$$\varphi: R \to cR, \quad r \mapsto cr.$$

This map is surjective onto cR = {cr : r ∈ R} with kernel $\ker(\varphi) = \{r \
in R : cr = 0\}$, which we denote $\operatorname{ann}(c)$.

**Key observations:**

1. **cR ⊆ m.** Since c ∈ m and m is a (right) ideal, we have cR ⊆ m, so |cR| ≤ |
m|.

2. **ann(c) ⊆ m.** The set ann(c) is a proper right ideal of R: it is a right id
eal because if cr = 0, then c(rs) = (cr)s = 0 for all s ∈ R; and it is proper be
cause 1 ∉ ann(c) (since c·1 = c ≠ 0). In a local ring, every proper (right) idea
l is contained in the unique maximal (right) ideal m. Hence ann(c) ⊆ m, so |ann(
c)| ≤ |m|.

By the first isomorphism theorem for additive groups, $R/\operatorname{ann}(c) \
cong cR$, so

$$|R| = |\operatorname{ann}(c)| \cdot |cR|.$$

Since R is infinite, at least one of $|\operatorname{ann}(c)|$, $|cR|$ must be i
nfinite (a product of two finite cardinals is finite). By the standard rule for
infinite cardinal arithmetic—if at least one factor is infinite and both are ≥ 1
, then the product equals the maximum:

$$|R| = \max\big(|\operatorname{ann}(c)|,\; |cR|\big).$$

Applying the bounds from observations (1) and (2):

$$|R| = \max\big(|\operatorname{ann}(c)|,\; |cR|\big) \leq \max(|m|,\, |m|) = |m
|.$$

Since m ⊆ R, we also have |m| ≤ |R|. Therefore:

$$|R| = |m|. \quad \blacksquare$$

---

**Remark on the necessity of hypotheses.**

- **R infinite:** If R is finite, the result can fail. For example, R = 𝔽₂[ε]/(ε
²) is a finite local ring with |R| = 4 and |m| = 2.
- **R not a division ring:** If R is an infinite division ring, then m = 0 and |
R| ≠ |m| = 1. The proof uses m ≠ 0 crucially (to pick a nonzero c ∈ m), which is
 equivalent to R not being a division ring.
