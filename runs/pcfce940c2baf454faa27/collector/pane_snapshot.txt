## Proof

**Claim:** The set of all epsilon numbers less than $\omega_1$ has cardinality $
\aleph_1$.

Recall that an *epsilon number* is an ordinal $\varepsilon$ satisfying $\omega^{
\varepsilon} = \varepsilon$, i.e., a fixed point of the normal function $f(\alph
a) = \omega^{\alpha}$.

**Step 1: $f(\alpha) = \omega^{\alpha}$ is a normal function.**

A normal function is strictly increasing and continuous (commutes with suprema o
f nonempty sets). It is standard that $\alpha \mapsto \omega^{\alpha}$ is normal
:
- *Strictly increasing*: if $\alpha < \beta$ then $\omega^{\alpha} < \omega^{\be
ta}$.
- *Continuous*: for any limit ordinal $\lambda$, $\omega^{\lambda} = \sup_{\alph
a < \lambda} \omega^{\alpha}$.

**Step 2: The fixed points of a normal function form a closed unbounded (club) c
lass.**

Let $f$ be normal. Define the fixed-point enumeration by transfinite recursion:
$$\varepsilon_0 = \sup_{n < \omega} f^{(n)}(0), \qquad \varepsilon_{\xi+1} = \su
p_{n < \omega} f^{(n)}(\varepsilon_\xi + 1), \qquad \varepsilon_\lambda = \sup_{
\xi < \lambda} \varepsilon_\xi \text{ (limit)}.$$
Each $\varepsilon_\xi$ is a fixed point of $f$ by continuity, and the sequence i
s strictly increasing and continuous. Hence the class of fixed points $\{\vareps
ilon_\xi : \xi \in \mathrm{Ord}\}$ is closed and unbounded in $\mathrm{Ord}$.

**Step 3: The epsilon numbers below $\omega_1$ form a club subset of $\omega_1$.
**

- *Closure under countability*: If $\alpha < \omega_1$ is countable, then $\omeg
a^{\alpha}$ is countable (a countable supremum of countable ordinals), so $\omeg
a^{\alpha} < \omega_1$. Thus the iteration building $\varepsilon_\xi$ from a cou
ntable starting point stays below $\omega_1$, and every $\varepsilon_\xi$ with $
\xi < \omega_1$ is itself countable, i.e., $< \omega_1$.
- *Unboundedness in $\omega_1$*: For any $\beta < \omega_1$, the sequence $\beta
, f(\beta), f(f(\beta)), \dots$ has countable length and countable values, so it
s supremum $\gamma = \sup_n f^{(n)}(\beta) \leq \omega^{\gamma} \leq \gamma$ is
a countable epsilon number above $\beta$. Hence the epsilon numbers are cofinal
in $\omega_1$.
- *Closedness*: The supremum of any countable increasing sequence of epsilon num
bers is again a fixed point (by continuity of $f$) and is countable, hence below
 $\omega_1$.

Therefore $E = \{\varepsilon < \omega_1 : \omega^{\varepsilon} = \varepsilon\}$
is a club subset of $\omega_1$.

**Step 4: A club subset of $\omega_1$ has cardinality $\aleph_1$.**

Any club subset of $\omega_1$ is unbounded, so it has cardinality at least $\ale
ph_1$ (since $\omega_1$ is regular: no countable set is cofinal in $\omega_1$).
It is a subset of $\omega_1$, so its cardinality is at most $\aleph_1$. Hence it
s cardinality is exactly $\aleph_1$.

**Conclusion.** The set of all epsilon numbers less than $\omega_1$ has cardinal
ity

$$\boxed{\aleph_1}.$$
