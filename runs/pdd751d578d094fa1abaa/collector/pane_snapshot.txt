## Proof

**Classification of automorphisms.** A ring automorphism $\psi$ of $\mathbb{C}[x
]$ restricts to a field automorphism $\sigma$ of $\mathbb{C}$ (since $\psi$ maps
 units to units and fixes $0,1$). Then $\psi(x) = f(x)$ for some $f \in \mathbb{
C}[x]$, and surjectivity requires $\mathbb{C}[f(x)] = \mathbb{C}[x]$, which forc
es $f(x) = ax + b$ with $a \in \mathbb{C}^*$, $b \in \mathbb{C}$. In particular,
 every $\mathbb{C}$-algebra automorphism (where $\sigma = \mathrm{id}$) of the f
orm $x \mapsto ax + b$ is a ring automorphism.

**Construction.** Fix any positive integer $n$.

- **$n = 1$:** The identity automorphism has order $1$.

- **$n \geq 2$:** Let $\zeta = e^{2\pi i / n}$, a primitive $n$-th root of unity
. Define $\psi: \mathbb{C}[x] \to \mathbb{C}[x]$ by
$$\psi(c) = c \quad \text{for all } c \in \mathbb{C}, \qquad \psi(x) = \zeta x.$
$
This is a $\mathbb{C}$-algebra homomorphism (hence a ring homomorphism). It is a
n automorphism because $\zeta \neq 0$, so $\mathbb{C}[\zeta x] = \mathbb{C}[x]$,
 with inverse $x \mapsto \zeta^{-1} x$.

**Verification of exact order.** By induction, $\psi^r(x) = \zeta^r x$ and $\psi
^r(c) = c$ for all $c \in \mathbb{C}$. Therefore:
- $\psi^n(x) = \zeta^n x = x$ and $\psi^n|_{\mathbb{C}} = \mathrm{id}$, so $\psi
^n = \mathrm{id}$.
- For $0 < r < n$: since $\zeta$ is a primitive $n$-th root of unity, $\zeta^r \
neq 1$, so $\psi^r(x) = \zeta^r x \neq x$, hence $\psi^r \neq \mathrm{id}$.

Thus $\psi$ has exact order $n$.
