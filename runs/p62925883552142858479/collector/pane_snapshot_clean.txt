## 证明

**断言：** $g(\nabla f_p, \nabla f_p)$ 与坐标的选择无关。

**设置。** 设 $M = \mathbb{R}^2$，并赋予 Riemannian 度量 $g$。梯度 $\nabla f$ 是
通过以下对偶关系内在定义的向量场：

$$g(\nabla f, X) = df(X) \quad \text{对于每个向量场 } X,$$

其中 $df$ 是 $f$ 的微分。这个定义仅使用了度量 $g$ 和 1-形式 $df$，两者都是流形上
的内在对象（张量），而不依赖于任何特定的坐标系。

**张量论证。** 度量 $g$ 是一个 $(0,2)$-张量场，$df$ 是一个 $(0,1)$-张量场（余切
向量/1-形式），逆度量 $g^{-1}$（通过在切空间上的非退化配对从 $g$ 诱导得出）是一
个 $(2,0)$-张量场。梯度是提升后的向量场

$$\nabla f = g^{-1}(df, \cdot),$$

即一个 $(1,0)$-张量场。那么

$$g(\nabla f, \nabla f) = g^{-1}(df, df)$$

是 $(2,0)$-张量 $g^{-1}$ 与两个 $df$ 副本的完全缩并。完全缩并的张量是 **标量场**
 —— 即流形上的函数，其在每一点 $p$ 的值是在 $T_pM$ 或 $T_p^*M$ 上内在定义的，而
不依赖于基的选择。因此 $g(\nabla f_p, \nabla f_p)$ 在坐标变换下是不变的。

**显式验证。** 在标准坐标 $(x,y)$ 中，$g = dx^2 + dy^2$，因此 $g^{-1} = \partial
_x^2 + \partial_y^2$ 且

$$g(\nabla f, \nabla f) = f_x^2 + f_y^2.$$

切换到极坐标 $(r,\theta)$，度量变为 $g = dr^2 + r^2\,d\theta^2$，因此 $g^{-1} =
\partial_r^2 + \frac{1}{r^2}\partial_\theta^2$。梯度为

$$\nabla f = f_r\,\partial_r + \tfrac{1}{r^2}f_\theta\,\partial_\theta,$$

所以

$$g(\nabla f, \nabla f) = f_r^2 + \tfrac{1}{r^2}f_\theta^2.$$

链式法则给出了经典恒等式 $f_x^2 + f_y^2 = f_r^2 + \frac{1}{r^2}f_\theta^2$，证实
了在 $p$ 点的值是相同的，无论使用哪种坐标系来计算它。

**结论。** $g(\nabla f_p, \nabla f_p)$ 是一个内在标量 —— 即逆度量 $g^{-1}$ 与两
个微分 $df$ 副本的完全缩并 —— 因此它与坐标的选择无关。
