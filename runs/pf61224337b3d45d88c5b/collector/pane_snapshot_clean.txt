## Proof

**Claim:** Yes, $\lim_{n\to\infty} f(n^2 x) = 0$ almost everywhere.

**Setup.** Let $f \in L^1(\mathbb{R})$. For each $\varepsilon > 0$, define the m
easurable sets
$$A_n(\varepsilon) := \{x \in \mathbb{R} : |f(n^2 x)| > \varepsilon\}, \qquad n
= 1, 2, 3, \dots$$

We will show that for every $\varepsilon > 0$, the set of $x$ belonging to infin
itely many $A_n(\varepsilon)$ has measure zero. By the Borel–Cantelli lemma, it
suffices to prove
$$\sum_{n=1}^{\infty} m\bigl(A_n(\varepsilon)\bigr) < \infty.$$

**Measure computation.** The substitution $y = n^2 x$ (so $dx = dy/n^2$) gives a
 dilation:
$$A_n(\varepsilon) = \{x : n^2 x \in \{|f| > \varepsilon\}\} = \tfrac{1}{n^2}\{|
f| > \varepsilon\},$$
hence by scaling of Lebesgue measure,
$$m\bigl(A_n(\varepsilon)\bigr) = \frac{1}{n^2}\, m\bigl(\{|f| > \varepsilon\}\b
igr).$$

**Bounding the level set.** By Markov's inequality (Chebyshev),
$$m\bigl(\{|f| > \varepsilon\}\bigr) \le \frac{1}{\varepsilon}\int_{\mathbb{R}}
|f(t)|\,dt = \frac{\|f\|_{L^1}}{\varepsilon} < \infty.$$

**Summability.** Therefore
$$\sum_{n=1}^{\infty} m\bigl(A_n(\varepsilon)\bigr) = m\bigl(\{|f|>\varepsilon\}
\bigr)\sum_{n=1}^{\infty}\frac{1}{n^2} = m\bigl(\{|f|>\varepsilon\}\bigr)\cdot\f
rac{\pi^2}{6} < \infty.$$

**Applying Borel–Cantelli.** Since $\sum_n m(A_n(\varepsilon)) < \infty$, the fi
rst Borel–Cantelli lemma yields
$$m\Bigl(\limsup_{n\to\infty} A_n(\varepsilon)\Bigr) = 0.$$
Equivalently, for almost every $x$, the inequality $|f(n^2 x)| > \varepsilon$ ho
lds for only finitely many $n$; that is, $|f(n^2 x)| \le \varepsilon$ for all su
fficiently large $n$.

**Removing $\varepsilon$.** Take $\varepsilon = 1/k$ for $k = 1, 2, 3, \dots$. F
or each $k$ there is a null set $N_k$ such that for all $x \notin N_k$, $|f(n^2
x)| \le 1/k$ eventually. Set $N = \bigcup_{k=1}^{\infty} N_k$; this is a countab
le union of null sets, hence $m(N) = 0$. For every $x \notin N$ and every $k \ge
 1$, we have $|f(n^2 x)| \le 1/k$ for all large enough $n$. Since $k$ is arbitra
ry,
$$\lim_{n\to\infty} f(n^2 x) = 0 \qquad \text{for all } x \notin N,$$
i.e., $f(n^2 x) \to 0$ almost everywhere. $\blacksquare$

**Remark.** The argument hinges on $\sum 1/n^2 < \infty$. The same proof works f
or any sequence $(a_n)$ with $a_n \to \infty$ and $\sum 1/a_n < \infty$. (The cl
assical result that $f(nx) \to 0$ a.e. also holds, but requires a subtler argume
nt since $\sum 1/n = \infty$ defeats direct Borel–Cantelli.)
