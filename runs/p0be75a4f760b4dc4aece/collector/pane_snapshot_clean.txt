Yes. The Axiom of ∈-induction implies the Axiom of Foundation, and the proof use

## Proof

**Definitions.**

- **Axiom of ∈-induction (schema):** For every first-order formula φ(x) (with pa
rameters), the following is an axiom:
$$\bigl[\forall x\,\bigl((\forall y\in x\;\varphi(y))\to\varphi(x)\bigr)\bigr]\;
\\longrightarrow\;\ \forall x\;\varphi(x).$$

- **Axiom of Foundation:** Every non-empty set $A$ has an $\in$-minimal element:
$$\forall A\;\bigl(A\neq\emptyset\;\longrightarrow\;\exists y\in A\;(y\cap A=\em
ptyset)\bigr).$$

**Claim.** In ZF without Choice (ZF − AC), ∈-induction ⊢ Foundation.

**Proof.** Fix an arbitrary set $A$. We apply the ∈-induction schema to the form
ula
$$\varphi(x)\;\equiv\; x\notin A,$$
where $A$ is used as a parameter (this is a legitimate first-order formula).

The instance of ∈-induction for this $\varphi$ reads:
$$\Bigl[\forall x\,\Bigl(\bigl(\forall y\in x\;(y\notin A)\bigr)\to(x\notin A)\B
igr)\Bigr]\;\longrightarrow\;\ \forall x\;(x\notin A).\tag{$\star$}$$

We reason by contraposition. The consequent $\forall x\,(x\notin A)$ is equivale
nt to $A=\emptyset$. So the contrapositive of $(\star)$ is:

$$A\neq\emptyset\;\longrightarrow\;\ \exists x\,\Bigl(\bigl(\forall y\in x\;(y\n
otin A)\bigr)\;\wedge\; x\in A\Bigr).$$

Indeed: if $A\neq\emptyset$, then $\neg\forall x\,(x\notin A)$, so by contraposi
tion of $(\star)$ the antecedent fails, meaning there exists some $x$ for which
$$\bigl(\forall y\in x\;(y\notin A)\bigr)\to(x\notin A)$$
is false, i.e., $\bigl(\forall y\in x\;(y\notin A)\bigr)$ holds **and** $x\in A$
.

Now observe that $\forall y\in x\;(y\notin A)$ is exactly $x\cap A=\emptyset$. T
herefore the conclusion of the contrapositive is:

$$\exists x\;\bigl(x\in A\;\wedge\; x\cap A=\emptyset\bigr),$$

which is precisely the statement that $A$ has an $\in$-minimal element. Since $A
$ was an arbitrary set, we have derived the Axiom of Foundation. $\square$

**Why no Choice is needed.** The entire argument is a single application of the
∈-induction schema to the formula $x\notin A$, followed by pure first-order logi
c (contraposition). No selection function, no well-ordering, no transitive closu
re construction, and no Replacement or Union axiom is invoked. The proof goes th
rough in any theory containing first-order logic with equality and the ∈-inducti
on schema—Choice is entirely irrelevant to this direction.

**Remark (the converse, for context).** The reverse implication Foundation $\Rig
htarrow$ ∈-induction *also* does not require Choice: given a predicate $\varphi$
 satisfying the induction hypothesis and a counterexample $x_0$ with $\neg\varph
i(x_0)$, one forms the transitive closure $\mathrm{TC}(\{x_0\})$ (a set, using R
eplacement and Union—no Choice), applies Foundation to the non-empty set $\mathr
m{TC}(\{x_0\})\cap\{x:\neg\varphi(x)\}$, and obtains an $\in$-minimal counterexa
mple, contradicting the induction hypothesis. Thus ∈-induction and Foundation ar
e equivalent over ZF − AC.
