## Proof

We have 128 nodes in a ring (indices 1–128). The ring distance between nodes *i*
 and *j* is min(|i−j|, 128−|i−j|). Process 1 → node 1. Each subsequent process g
oes to the available node maximizing distance to the nearest active node, breaki
ng ties by lowest index.

**Key structural observation.** This is a dyadic halving process on a ring of si
ze 128 = 2⁷. At each "level," every maximal arc gets its midpoint filled, and ti
es break by lowest index — so midpoints fill left-to-right (lowest index first)
within each level.

**Level-by-level trace:**

| Process | Node | Arcs created | New arc length |
|---|---|---|---|
| 1 | 1 | one arc of 128 | 64 (to antipode) |
| 2 | 65 | two arcs of 64 | 32 |
| 3 | 33 | arcs: 32, 32, 64 | 32 |
| 4 | 97 | four arcs of 32 | 16 |
| 5 | 17 | fills first 32-arc midpoint | 16 |
| 6 | 49 | | 16 |
| 7 | 81 | | 16 |
| 8 | 113 | eight arcs of 16 | 8 |

After process 8: active = {1, 17, 33, 49, 65, 81, 97, 113}, all arcs = 16.

**Processes 9–16** (distance-8 level): fill midpoints of the eight 16-arcs, lowe
st index first:
9, 25, 41, 57, 73, 89, 105, 121. → 16 nodes, all arcs = 8.

**Processes 17–32** (distance-4 level): fill midpoints of the sixteen 8-arcs, lo
west index first:
5, 13, 21, 29, 37, 45, 53, 61, 69, 77, 85, 93, 101, 109, 117, 125. → 32 nodes, a
ll arcs = 4.

After process 32, active nodes are exactly {4k+1 : k = 0, 1, …, 31} = {1, 5, 9,
13, …, 125}, with every arc of length 4.

**Processes 33–64** (distance-2 level): fill midpoints of the thirty-two 4-arcs.
 Each arc [4k+1, 4k+5] has midpoint 4k+3. Filled lowest-index first:
3, 7, 11, 15, 19, 23, 27, 31, …

The j-th process in this level (j = 1, 2, 3, …) fills node 4(j−1)+3 = 4j−1.

Process 39 is the (39 − 32) = 7th process in this level, so j = 7:
**node = 4(7) − 1 = 27.**

**Verification.** At process 39, the active nodes after process 38 are {4k+1 : k
=0..31} ∪ {4k+3 : k=0..5} = {1,5,9,…,125} ∪ {3,7,11,15,19,23}. The remaining 4-a
rcs without midpoints start at 25, 29, 33, … The lowest-index unfilled midpoint
is 25+2 = **27**, at distance 2 from both node 25 and node 29. No node offers gr
eater isolation (all unfilled arcs are length 4, giving max isolation 2). Lowest
-index tie-break selects 27. ✓

**The 39th process is hosted at node 27.**
