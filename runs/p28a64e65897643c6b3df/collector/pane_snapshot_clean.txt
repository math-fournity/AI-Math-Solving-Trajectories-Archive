## 解题思路

这是一个在两个仓库上进行的不偏博弈。每个仓库是一个单堆博弈，其中从大小为 $n$ 的
堆中，你可以移除 $1$ 到 $\lfloor n/2 \rfloor$ 个物品，从而将堆减小到 $[\lceil n/
2 \rceil,\ n-1]$ 范围内的任何值。根据 Sprague-Grundy 定理，第二个玩家（Bianca）
获胜当且仅当 $g(a) \oplus g(100-a) = 0$，即 $g(a) = g(100-a)$。

## Sprague-Grundy 值

设 $g(n)$ 为单堆大小为 $n$ 的 Grundy 值。基本情况：$g(0) = g(1) = 0$（无法进行有
效操作）。对于 $n \ge 2$，写出 $n = 2^k + j$，其中 $0 \le j < 2^k$。通过计算可达
位置（即 $[\lceil n/2\rceil, n-1]$ 范围内的 Grundy 值集合）的 mex，可以得出递归
结构：

- **$j$ 为偶数**：$g(n) = 2^{k-1} + j/2$
- **$j$ 为奇数**：$g(n) = g\!\bigl(2^{k-1} + (j-1)/2\bigr)$

我通过直接计算 $n = 0,\ldots,31$ 的 mex 验证了这一点，并确认该模式成立。关键性质
：$g(2^m - 1) = 0$（全为 1 的二进制数），且每个块 $[2^k, 2^{k+1}-1]$ 都是 $\{0,
1, \ldots, 2^k - 1\}$ 的一个排列。

## 计算至 $n = 100$

使用该递归公式，我计算了所有 $n$ 从 $0$ 到 $100$ 的 $g(n)$。一些关键值：

| $n$ | $g(n)$ | $n$ | $g(n)$ |
|-----|--------|-----|--------|
| 0 | 0 | 50 | 25 |
| 5 | 1 | 63 | 0 |
| 33 | 8 | 67 | 8 |
| 95 | 1 | 100 | 50 |

我通过直接 mex 验证了 $g(100) = 50$：从 100 可以到达 $\{50, \ldots, 99\}$，它们
的 Grundy 值涵盖了 $\{0, 1, \ldots, 49\}$，因此 mex = 50。✓

## 寻找 $S$

我检查了所有 $a$ 从 $0$ 到 $100$，寻找满足 $g(a) = g(100 - a)$ 的值：

- **$a = 5$, $b = 95$**：$g(5) = 1 = g(95)$ ✓
- **$a = 33$, $b = 67$**：$g(33) = 8 = g(67)$ ✓
- **$a = 50$, $b = 50$**：$g(50) = 25 = g(50)$ ✓
- **$a = 67$, $b = 33$**：与上述对称 ✓
- **$a = 95$, $b = 5$**：与上述对称 ✓

所有其他 $a$ 值得到的 $g(a) \ne g(100-a)$（已逐一验证，例如 $g(13)=3 \ne 5=g(87)
$，$g(47)=1 \ne 13=g(53)$ 等）。

## 结果

$$S = \{5,\ 33,\ 50,\ 67,\ 95\}$$

$$\sum_{a \in S} a = 5 + 33 + 50 + 67 + 95 = \boxed{250}$$
