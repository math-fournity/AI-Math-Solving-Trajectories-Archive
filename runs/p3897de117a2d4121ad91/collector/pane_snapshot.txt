## 证明

**设置。** 设 $v_1, v_2, \ldots, v_{10}$ 为位置 $1, \ldots, 10$ 处的序列，其中 $
v_1 = 1$，$v_{10} = 10$，内部位置 $2,\ldots,9$ 持有 $\{2,\ldots,9\}$ 的一个排列
。定义符号 $d_i = \operatorname{sgn}(v_{i+1}-v_i) \in \{+,-\}$（$i = 1,\ldots,9$
）。

**局部极小值和符号转换。** 位置 $i$（$2 \le i \le 9$）处的局部极小值意味着 $v_{i
-1} > v_i < v_{i+1}$，即 $d_{i-1} = -$ 且 $d_i = +$ —— 在符号序列中存在一个 $-+$
 转换。因此，内部局部极小值的数量等于 $d_1, \ldots, d_9$ 中 $-+$ 转换的数量。

**边界强制符号。** 由于 $v_1 = 1$ 是全局极小值，$v_2 > v_1$，所以 $d_1 = +$。由
于 $v_{10} = 10$ 是全局极大值，$v_{10} > v_9$，所以 $d_9 = +$。序列以 $+$ 开头并
以 $+$ 结尾，因此 $-+$ 转换的数量等于 $+-$ 转换的数量。要求**恰好一个**局部极小
值意味着恰好一个 $-+$ 转换，因此符号序列必须为：
$$+\underbrace{\cdots}_{a} \; -\underbrace{\cdots}_{b} \; +\underbrace{\cdots}_{
c}, \qquad a,b,c \ge 1,\; a+b+c = 9.$$
这给出了一个单一峰值（在位置 $p = a+1$）和一个单一谷值（在位置 $q = a+b+1$），其
中 $2 \le p < q \le 9$。

**结构。** 该序列在位置 $1 \to p$ 递增，在 $p \to q$ 递减，在 $q \to 10$ 递增：
$$v_1 < v_2 < \cdots < v_p > v_{p+1} > \cdots > v_q < v_{q+1} < \cdots < v_{10}.
$$
一旦选择了值，每个部分内的排序就是固定的，所以我们只需要计算有效的**值分配**数量
。

**计算分配数量。** 固定谷值 $t = v_q$ 和峰值 $v_p = t + s + 1$，其中 $s = v_p -
v_q - 1 \ge 0$。$\{2,\ldots,9\} \setminus \{v_p, v_q\}$ 中的六个剩余值分为三组：
- $L = \{2, \ldots, t-1\}$，大小 $\ell = t-2$：必须放置在左侧递增部分（值 $< v_q
$ 不能进入中间或右侧）。
- $H = \{v_p+1, \ldots, 9\}$，大小 $h = 9 - v_p$：必须放置在右侧递增部分。
- $M = \{t+1, \ldots, v_p-1\}$，大小 $m = s$：可以自由分配给三个部分中的任何一个
。

设 $a' = p - 2 - \ell$ 为从 $M$ 中分配给左侧的值的数量，$b' = 9 - q - h$ 分配给
右侧，$c' = q - p - 1$ 分配给中间。那么 $a' + b' + c' = s = m$，且 $a', b', c' \
ge 0$。分配的数量为 $\binom{s}{a'}\binom{s-a'}{b'}$。

**对自由分配求和。** 对于固定的 $s$，对所有 $a'+b'+c'=s$ 且 $a',b',c' \ge 0$ 的
情况求和：
$$\sum_{a'+b'+c'=s} \binom{s}{a'}\binom{s-a'}{b'} = \sum_{a'=0}^{s} \binom{s}{a'
}\, 2^{s-a'} = (2+1)^s = 3^s.$$

**约束条件。** 唯一的约束是 $v_p \le 9$，即 $t + s + 1 \le 9$，因此 $t + s \le 8
$，其中 $t \ge 2$，$s \ge 0$。

**最终求和。**
$$\text{Total} = \sum_{t=2}^{8} \sum_{s=0}^{8-t} 3^s = \sum_{t=2}^{8} \frac{3^{\
,9-t}-1}{2}.$$

计算每一项：
| $t$ | $s$ 范围 | $\sum 3^s$ |
|---|---|---|
| 2 | 0–6 | $(3^7-1)/2 = 1093$ |
| 3 | 0–5 | $(3^6-1)/2 = 364$ |
| 4 | 0–4 | $(3^5-1)/2 = 121$ |
| 5 | 0–3 | $(3^4-1)/2 = 40$ |
| 6 | 0–2 | $(3^3-1)/2 = 13$ |
| 7 | 0–1 | $(3^2-1)/2 = 4$ |
| 8 | 0 | $1$ |

$$\text{Total} = 1093 + 364 + 121 + 40 + 13 + 4 + 1 = \boxed{1636}.$$

**验证。** 对于 $n = 4$，公式给出 $1$（唯一有效的排列 $1,3,2,4$）。对于 $n = 5$
，公式给出 $5$，通过穷举法验证：$\{2,3,4\}$ 的 6 种排列中有 5 种恰好产生一个内部
局部极小值。两者均符合。
