Looking at this problem, I need to determine whether a decreasing sequence of se
ts with finite outer measure can have the outer measure of the intersection stri
ctly less than the limit of the outer measures. This is a question about whether
 continuity from above fails for Lebesgue outer measure (as opposed to Lebesgue
measure, where it holds for measurable sets).

**Answer: Yes, such a sequence exists.**

## Construction and Proof

**Setup.** Work in $[0,1)$ with addition modulo 1, denoted $\oplus$. Define the
equivalence relation on $[0,1)$: $x \sim y \iff x - y \in \mathbb{Q}$. By the Ax
iom of Choice, let $V \subseteq [0,1)$ be a set containing exactly one represent
ative from each equivalence class (a **Vitali set**).

**Key properties of $V$:**
- The sets $\{V \oplus q : q \in \mathbb{Q} \cap [0,1)\}$ form a partition of $[
0,1)$.
- $m^*(V) > 0$: if $m^*(V)=0$, then $V$ is measurable with measure 0, so every $
V\oplus q$ is measurable with measure 0, and $[0,1)=\bigcup_q (V\oplus q)$ would
 have measure 0—contradiction.
- $m_*(V)=0$ (inner measure): if $V$ contained a measurable subset $M$ with $m(M
)>0$, the **Steinhaus theorem** gives $M-M \supseteq (-\varepsilon,\varepsilon)$
 for some $\varepsilon>0$, so there exist $x\neq y \in M$ with $x-y\in\mathbb{Q}
$, contradicting $V$ having one representative per class.

**Construction of the sequence.** Enumumerate $\mathbb{Q}\cap[0,1) = \{q_1, q_2,
 q_3, \ldots\}$. Define:
$$A_n = \bigcup_{k=n}^{\infty} (V \oplus q_k), \qquad n = 1, 2, 3, \ldots$$

**Verification of the required properties:**

**(1) Decreasing:** $A_{n+1} = \bigcup_{k=n+1}^{\infty}(V\oplus q_k) \subseteq \
bigcup_{k=n}^{\infty}(V\oplus q_k) = A_n$. ✓

**(2) Finite outer measure:** $A_n \subseteq [0,1)$, so $m^*(A_n) \leq 1 < \inft
y$. ✓

**(3) The intersection is empty:** Since $\{V\oplus q_k\}$ partitions $[0,1)$, e
ach $x \in [0,1)$ lies in exactly one $V\oplus q_{k_0}$. Then $x \notin A_n$ for
 all $n > k_0$. Hence:
$$\bigcap_{n=1}^{\infty} A_n = \emptyset, \qquad m^*\!\left(\bigcap_{n=1}^{\inft
y} A_n\right) = 0.$$

**(4) $m^*(A_n) = 1$ for every $n$ (the crucial step).**

Set $C_n = [0,1)\setminus A_n = \bigcup_{k=1}^{n-1}(V\oplus q_k)$ (a finite unio
n of translates of $V$).

**Claim:** $m_*(C_n) = 0$, i.e., $C_n$ contains no measurable subset of positive
 measure.

*Proof of Claim.* Suppose $M \subseteq C_n$ is measurable with $m(M) > 0$. By th
e Steinhaus theorem, $M - M \supseteq (-\varepsilon, \varepsilon)$ for some $\va
repsilon > 0$. Choose any nonzero rational $q \in (-\varepsilon, \varepsilon)$.
Then there exist $x, y \in M$ with $x - y = q$.

Since $M \subseteq C_n$, we have $x \in V \oplus q_i$ and $y \in V \oplus q_j$ f
or some $i,j \in \{1,\ldots,n-1\}$. Write $x = (v_1 + q_i)\!\mod 1$ and $y = (v_
2 + q_j)\!\mod 1$ with $v_1, v_2 \in V$. Then:
$$v_1 - v_2 = q + \ell - q_i + q_j \in \mathbb{Q} \quad (\text{for some integer
} \ell).$$
Since $v_1, v_2 \in V$ and $v_1 - v_2 \in \mathbb{Q}$, the definition of $V$ for
ces $v_1 = v_2$. Thus $q = q_i - q_j - \ell$ for some $\ell \in \mathbb{Z}$.

This means every nonzero rational $q \in (-\varepsilon,\varepsilon)$ must be of
the form $q_i - q_j - \ell$ with $i,j \in \{1,\ldots,n-1\}$, $\ell \in \mathbb{Z
}$. But there are only **finitely many** such values (at most $(n-1)^2$ choices
for $(i,j)$, and for each, $\ell$ is determined since $q \in (-\varepsilon,\vare
psilon)$ and $q_i - q_j \in (-1,1)$). This contradicts the fact that $(-\varepsi
lon,\varepsilon)\setminus\{0\}$ contains **infinitely many** rationals. $\square
$

**Now compute $m^*(A_n)$.** Since $m^*(A_n) < \infty$, there exists a measurable
 cover $B$ with $A_n \subseteq B \subseteq [0,1)$ and $m(B) = m^*(A_n)$ (take a
$G_\delta$ cover intersected with $[0,1)$). Then:
$$[0,1) \setminus B \subseteq [0,1) \setminus A_n = C_n,$$
and $[0,1)\setminus B$ is measurable. By the Claim, $m([0,1)\setminus B) = 0$. T
herefore:
$$m^*(A_n) = m(B) = m([0,1)) - m([0,1)\setminus B) = 1 - 0 = 1.$$

**Conclusion.** We have:
$$m^*\!\left(\bigcap_{n=1}^{\infty} A_n\right) = m^*(\emptyset) = 0 < 1 = \lim_{
n\to\infty} m^*(A_n).$$

The sequence $\{A_n\}$ is decreasing, each $A_n$ has finite outer measure, and t
he strict inequality holds. $\blacksquare$
