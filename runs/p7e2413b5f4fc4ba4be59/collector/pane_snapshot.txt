## Setup

Place the equilateral triangle ABC with center O at the origin. The circumradius
 is R = 1/√3. The medial triangle A'B'C' is equilateral with side 1/2, circumrad
ius r = R/2 = 1/(2√3), also centered at O.

Using complex coordinates with A' = r, B' = rω, C' = rω² where ω = e^{2πi/3}.

Since PQ is a diameter of the circumcircle of ABC (center O, radius 2r), we have
 P = 2r·e^{iθ} and Q = −P for some θ.

## Barycentric Coordinates

For a point z with barycentric coords (u,v,w) w.r.t. A'B'C': z = r(u + vω + wω²)
, u+v+w=1. Setting ζ = z/r, we get ζ = u + vω + wω². Solving:

- u = (2·Re(ζ)+1)/3, v = (1−Re(ζ))/3 + Im(ζ)/√3, w = (1−Re(ζ))/3 − Im(ζ)/√3.

Let a = Re(ζ_P) = 2cosθ, b = Im(ζ_P) = 2sinθ, so a²+b² = 4. Define:

- U = 2a+1, V = 1−a+b√3, W = 1−a−b√3 (so u=U/3, v=V/3, w=W/3, and U+V+W=3).

For Q = −P (ζ_Q = −ζ_P), the barycentric components satisfy:

- U_Q = 1−2a = 2−U, V_Q = 1+a−b√3 = 2−V, W_Q = 1+a+b√3 = 2−W.

## Isogonal Conjugation (Equilateral Case)

For an equilateral triangle (all sides equal), isogonal conjugation sends baryce
ntric coords (u:v:w) → (1/u : 1/v : 1/w). Thus:

**P'** has coords (1/U : 1/V : 1/W):
$$z_{P'} = r \cdot \frac{VW + \omega\cdot UW + \omega^2\cdot UV}{VW + UW + UV} =
 r\cdot\frac{N}{S}$$

where S = UV+VW+WU and N = VW + ω·UW + ω²·UV.

**Q'** has coords (1/(2−U) : 1/(2−V) : 1/(2−W)):
$$z_{Q'} = r \cdot \frac{(2{-}V)(2{-}W) + \omega(2{-}U)(2{-}W) + \omega^2(2{-}U)
(2{-}V)}{(2{-}V)(2{-}W)+(2{-}U)(2{-}W)+(2{-}U)(2{-}V)}$$

## Computing the Denominators

**Denominator of Q':** Expanding:
$$(2{-}V)(2{-}W)+(2{-}U)(2{-}W)+(2{-}U)(2{-}V) = 12 - 4(U{+}V{+}W) + (UV{+}VW{+}
UW) = 12-12+S = S$$

So both denominators equal S.

## Computing the Difference

Expanding the numerator of Q' using 1+ω = −ω², 1+ω² = −ω, ω+ω² = −1:

$$N_Q = 2(U + \omega V + \omega^2 W) + N = 2\cdot 3\zeta_P + N = 6\zeta_P + N$$

since U + ωV + ω²W = 3ζ_P. Therefore:

$$z_{Q'} - z_{P'} = r\cdot\frac{(6\zeta_P + N) - N}{S} = \frac{6r\,\zeta_P}{S}$$

$$|z_{Q'} - z_{P'}| = \frac{6r\cdot|\zeta_P|}{|S|} = \frac{6r\cdot 2}{|S|} = \fr
ac{12r}{|S|}$$

## Computing S

$$S = UV + UW + VW$$

$$UV + UW = 2(2a+1)(1-a) = -4a^2+2a+2$$

$$VW = (1-a)^2 - 3b^2$$

$$S = -4a^2+2a+2 + 1-2a+a^2-3b^2 = -3a^2+3-3b^2 = 3(1-a^2-b^2) = 3(1-4) = -9$$

This is **constant**, independent of θ!

## Final Computation

$$P'Q' = \frac{12r}{|S|} = \frac{12r}{9} = \frac{4r}{3} = \frac{4}{3}\cdot\frac{
1}{2\sqrt{3}} = \frac{2}{3\sqrt{3}} = \frac{2\sqrt{3}}{9}$$

## Answer

$$\boxed{P'Q' = \dfrac{2\sqrt{3}}{9}}$$
