## Solution

Let $m = \overline{abcd} = 1000a+100b+10c+d$ and $n = \overline{dcba} = 1000d+10
0c+10b+a$, where $a,d \in \{1,\dots,9\}$ and $b,c \in \{0,\dots,9\}$.

**Form of the product.** The condition $mn = \overline{xxyyzz00}$ means
$$mn = 11000000x + 110000y + 1100z = 1100\,(10000x+100y+z).$$
So $1100 \mid mn$. Since $\gcd(11,100)=1$, this requires $11\mid mn$ and $100\mi
d mn$.

**Divisibility by 11.** $m \bmod 11 \equiv a-b+c-d$ and $n\bmod 11 \equiv d-c+b-
a = -(a-b+c-d)$, so $11\mid m \iff 11\mid n$. Thus we need $a-b+c-d\equiv 0\pmod
{11}$. With digits, $a-b+c-d\in\{-11,0,11\}$.

**Divisibility by 100.** $mn\bmod 100 = (10c+d)(10b+a)\bmod 100$. Set $u=10c+d$,
 $v=10b+a$; note $d,a\ge1$, so neither $u$ nor $v$ is divisible by 10. For $100\
mid uv$ we need $4\mid uv$ and $25\mid uv$.

For $25\mid uv$: $v_5(u)+v_5(v)\ge2$, giving three cases — (A) $25\mid u$, (B) $
25\mid v$, (C) $5\mid u$ and $5\mid v$.

- $25\mid u$: $u\in\{25,75\}\Rightarrow (c,d)\in\{(2,5),(7,5)\}$ (u=50 needs d=0
, excluded).
- $25\mid v$: $(b,a)\in\{(2,5),(7,5)\}$.
- $5\mid u,5\mid v$: $d=5,a=5$.

**Case C ($a=d=5$):** $u=10c+5$, $v=10b+5$, both odd, so $uv$ is odd $\Rightarro
w 4\nmid uv$. No solutions.

**Case A ($d=5$, $c\in\{2,7\}$, $u$ odd ⇒ need $4\mid v$, i.e. $2b+a\equiv0\pmod
4$).**

*Subcase $c=2$:* $a-b+c-5\equiv0\pmod{11}\Rightarrow a-b\in\{-8,3\}$. Checking $
2b+a\equiv0\pmod4$ over $a-b=3$ candidates $(a,b)\in\{(3,0),\dots,(9,6)\}$ yield
s only $(a,b)=(6,3)$. So $m=6325$, $n=5236$.
$$mn = 6325\times 5236 = 33\,117\,700 = \overline{33117700} = \overline{33\,11\,
77\,00}.\checkmark$$
Four identical-adjacent-digit pairs ($33,11,77,00$), ending in $00$. ✓

*Subcase $c=7$:* $a-b\in\{-2,9\}$. The only $4\mid v$ candidate is $(a,b,c,d)=(4
,6,7,5)$, giving $m=4675,n=5764$, $mn=26\,946\,700=\overline{26946700}$ — pairs
$26,94,67,00$, not all identical. ✗

**Case B ($a=5$, $b\in\{2,7\}$, $v$ odd ⇒ need $4\mid u$).**

*Subcase $b=2$:* yields $(a,b,c,d)=(5,2,3,6)$, i.e. $m=5236,n=6325$ — the same p
air as Case A. ✓

*Subcase $b=7$:* yields $(5,7,6,4)$, i.e. $m=5764,n=4675$ — same invalid product
 as Case A's $c=7$ subcase. ✗

All cases exhausted; the unique solution is the pair $\{6325, 5236\}$.

$$m+n = 6325 + 5236 = \boxed{11561}$$
