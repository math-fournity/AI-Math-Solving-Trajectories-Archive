## Proof

We compute
$$L = \lim_{x \to \infty}\left(\sum_{n=1}^{\infty}\left(\frac{x}{n}\right)^{n}\r
ight)^{\frac{1}{x}}.$$

**Convergence of the series.** For fixed $x>0$, the terms $(x/n)^n \to 0$ super-
exponentially once $n > 2x$ (since $x/n < 1/2$), so the series converges.

**Setup.** Write $f(n) = n\ln(x/n)$, so $(x/n)^n = e^{f(n)}$. Then $f'(n) = \ln(
x/n)-1$, which vanishes at $n_0 = x/e$, and $f(n_0) = x/e$. Since $f$ is concave
 ($f''(n)=-1/n<0$), the maximum of $f$ over $n\ge 1$ is $x/e$, attained near $n=
x/e$.

**Lower bound.** Let $n_0 = \lfloor x/e\rfloor$. Then
$$S(x) \ge \left(\frac{x}{n_0}\right)^{n_0} = e^{n_0 \ln(x/n_0)}.$$
As $x\to\infty$, $n_0/x \to 1/e$, so
$$\frac{n_0 \ln(x/n_0)}{x} = \frac{n_0}{x}\ln\!\left(\frac{x}{n_0}\right) \to \f
rac{1}{e}\ln e = \frac{1}{e}.$$
Hence $S(x)^{1/x} \ge \exp\!\big(n_0\ln(x/n_0)/x\big) \to e^{1/e}$, giving $\lim
inf L \ge e^{1/e}$.

**Upper bound.** We split the sum into three regions.

*Region 1: $1 \le n \le \lceil x/e\rceil$.* Here $f(n)\le x/e$ (by concavity, th
e maximum on $[1,x/e]$ is at $x/e$), and there are $\le x/e+1 \le 2x$ terms (for
 large $x$). Thus
$$\sum_{n\le \lceil x/e\rceil} e^{f(n)} \le 2x\, e^{x/e}.$$

*Region 2: $\lceil x/e\rceil < n \le x$.* Here $f$ is decreasing, so $f(n) < x/e
$, and there are $\le x$ terms:
$$\sum_{\lceil x/e\rceil < n \le x} e^{f(n)} \le x\, e^{x/e}.$$

*Region 3: $n > x$.* Here $x/n < 1$, so each term $(x/n)^n < 1$. For $x < n \le
2x$ there are $\le x$ terms, each $<1$, contributing $\le x$. For $n > 2x$, $x/n
 < 1/2$, so $(x/n)^n < 2^{-n}$, and $\sum_{n>2x} 2^{-n} < 1$. Thus
$$\sum_{n>x} \left(\frac{x}{n}\right)^n \le x + 1.$$

Combining, for large $x$:
$$S(x) \le 2x\, e^{x/e} + x\, e^{x/e} + x + 1 \le 4x\, e^{x/e}.$$
Therefore
$$S(x)^{1/x} \le (4x)^{1/x}\, e^{1/e}.$$
Since $(4x)^{1/x} \to 1$ as $x\to\infty$, we get $\limsup L \le e^{1/e}$.

**Conclusion.** The lower and upper bounds together yield
$$L = e^{1/e}.$$
