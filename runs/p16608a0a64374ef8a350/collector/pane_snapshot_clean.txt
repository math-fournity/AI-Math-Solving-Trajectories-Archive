解答

答案：不能。 在 ZFC 中无法推出"非 Borel 可测集必然具有连续统基数"。事实上，该命
题等价于连续统假设 (CH)，因此独立于 ZFC。

────────────────────────────────────────────────────────────────────────────────

证明

引理（Borel 集的完美集性质）

每个不可数 Borel 集 $A \subseteq \mathbb{R}$ 都包含一个完美子集，因而 $|A| =
\mathfrak{c}$。

证明概要。 定义 $\mathcal{C}$ 为所有满足"不可数则含完美子集"的 $\mathbb{R}$ 的子
集构成的族。验证 $\mathcal{C}$ 是一个 $\sigma$-代数且包含所有开集：

  • 开集：每个不可数开集是至多可数个开区间的并，其中至少一个开区间不可数；开区间
  包含 Cantor 集的同构像（完美集），故开集属于 $\mathcal{C}$。
  • 补集封闭：若 $A \in \mathcal{C}$，考虑 $\mathbb{R} \setminus A$。若 $
  \mathbb{R} \setminus A$ 不可数，需证其含完美子集。关键事实：$\mathbb{R}$ 中任
  意不可数闭集含完美子集（Cantor–Bendixson 定理：闭集 = 完美集 $\cup$ 可数集）。
  利用 Cantor–Bendixson 分解和 $\mathcal{C}$ 对可数并封闭，可完成补集封闭性的验
  证。
  • 可数并封闭：设 $A_n \in \mathcal{C}$，$A = \bigcup_n A_n$。若 $A$ 不可数，则
  某个 $A_n$ 不可数，故 $A_n$ 含完美子集 $P$，而 $P \subseteq A$。

因此 $\mathcal{C}$ 是包含所有开集的 $\sigma$-代数，故 Borel $\sigma$-代数 $
\mathcal{B}(\mathbb{R}) \subseteq \mathcal{C}$。每个 Borel 集属于 $
\mathcal{C}$，即不可数 Borel 集含完美子集。

完美集 $P \subseteq \mathbb{R}$ 满足 $|P| = \mathfrak{c}$（标准事实：完美集是连
续统基数）。故不可数 Borel 集 $A$ 满足 $\mathfrak{c} \leq |A| \leq
\mathfrak{c}$，即 $|A| = \mathfrak{c}$。$\square$

推论。 每个 Borel 集 $A \subseteq \mathbb{R}$ 要么可数，要么 $|A| =
\mathfrak{c}$。

────────────────────────────────────────────────────────────────────────────────

第一步：非 Borel 集必定不可数

每个可数子集 $C \subseteq \mathbb{R}$ 是 $F_\sigma$ 集（单点集是闭集，可数并仍
Borel），故 Borel 可测。因此，非 Borel 集 $B$ 必定不可数，即 $|B| > \aleph_0$。

────────────────────────────────────────────────────────────────────────────────

第二步：在 ZFC + ¬CH 下，存在基数 $< \mathfrak{c}$ 的非 Borel 集

设 ¬CH 成立，即 $\aleph_0 < \mathfrak{c}$（存在中间基数）。取基数 $\kappa$ 满足
$\aleph_0 < \kappa < \mathfrak{c}$。由于 $|\mathbb{R}| = \mathfrak{c}$，存在子集
$A \subseteq \mathbb{R}$ 使得 $|A| = \kappa$。

  • $A$ 不可数（因 $\kappa > \aleph_0$）。
  • $|A| = \kappa < \mathfrak{c}$。
  • 由引理，每个 Borel 集要么可数要么 $|A| = \mathfrak{c}$。$A$ 不可数且 $|A|
  \neq \mathfrak{c}$，故 $A$ 不是 Borel 集。

于是 $A$ 是一个非 Borel 集，且 $|A| = \kappa < \mathfrak{c}$。在 ¬CH 下，"非
Borel 集必有连续统基数"为假。

────────────────────────────────────────────────────────────────────────────────

第三步：在 ZFC + CH 下，命题为真

设 CH 成立，即 $\mathfrak{c} = \aleph_1$。$\mathbb{R}$ 的每个不可数子集 $S$ 满足
$|S| \geq \aleph_1 = \mathfrak{c}$，又 $|S| \leq \mathfrak{c}$，故 $|S| =
\mathfrak{c}$。

非 Borel 集 $B$ 不可数（第一步），故 $|B| = \mathfrak{c}$。在 CH 下，"非 Borel
集必有连续统基数"为真。

────────────────────────────────────────────────────────────────────────────────

第四步：独立性结论

由第二步和第三步：

  • ZFC + CH ⊢ "每个非 Borel 集 $B \subseteq \mathbb{R}$ 满足 $|B| =
  \mathfrak{c}$"。
  • ZFC + ¬CH ⊬ 该命题（事实上 ZFC + ¬CH ⊢ 其否定）。

由 Gödel（1940：CH 与 ZFC 相容，构造可构成宇宙 $L$ 满足 CH）和 Cohen（1963：¬CH
与 ZFC 相容，力迫方法），CH 与 ¬CH 均与 ZFC 相容（假设 ZFC 自身相容）。

因此，ZFC 既不能证明也不能否证"每个非 Borel 集 $B \subseteq \mathbb{R}$ 满足 $|
B| = \mathfrak{c}$"。该命题在 ZFC 上独立，且事实上等价于 CH：

  • CH $\Rightarrow$ 命题成立（第三步）。
  • 命题成立 $\Rightarrow$ CH：若 ¬CH，则存在 $\kappa$ 满足 $\aleph_0 < \kappa <
  \mathfrak{c}$，取 $A \subseteq \mathbb{R}$，$|A| = \kappa$，由引理 $A$ 非
  Borel 且 $|A| < \mathfrak{c}$，与命题矛盾。故命题蕴含 ¬¬CH，即 CH。

────────────────────────────────────────────────────────────────────────────────

结论

不能在 ZFC 中（不假设 CH 或 ¬CH）推出非 Borel 集 $B$ 必然具有连续统基数。 该结论
等价于连续统假设，是 ZFC 中的独立命题。具体而言：

  • 在 CH 下，命题成立（所有不可数子集都有连续统基数）。
  • 在 ¬CH 下，命题不成立（存在中间基数的子集，它们自动非 Borel）。
