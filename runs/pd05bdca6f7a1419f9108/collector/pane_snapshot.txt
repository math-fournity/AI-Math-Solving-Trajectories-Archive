Looking at this problem, I need to count residues $x \pmod{p}$ such that $x$ is
a square and $x$ is a square plus one (i.e., $x \equiv y^2$ and $x \equiv z^2+1$
 for some $y,z$).

**Setup.** Let $\chi$ be the Legendre symbol mod $p$, extended by $\chi(0)=0$. S
ince $0 = 0^2$ is a square, the indicator that $x$ is a square (including $0$) i
s:
$$f(x) = \frac{1 + \chi(x) + \delta_0(x)}{2},$$
where $\delta_0(x) = 1$ if $x \equiv 0$, else $0$. (Check: nonzero QR gives $(1+
1+0)/2=1$; non-residue gives $(1-1+0)/2=0$; $x=0$ gives $(1+0+1)/2=1$. ✓)

**The count.** We want
$$N = \sum_{x \bmod p} f(x)\,f(x-1) = \frac{1}{4}\sum_{x}\bigl(1+\chi(x)+\delta_
0(x)\bigr)\bigl(1+\chi(x-1)+\delta_0(x-1)\bigr).$$

Expanding and summing each term over $x \bmod p$:

| Term | Sum | Reason |
|------|-----|--------|
| $1$ | $p$ | |
| $\chi(x-1)$ | $0$ | $\sum_y \chi(y)=0$ |
| $\delta_0(x-1)$ | $1$ | only $x=1$ |
| $\chi(x)$ | $0$ | |
| $\chi(x)\chi(x-1)$ | $-1$ | standard: $\sum_x \chi(x(x-1))=-1$ for non-degener
ate quadratic |
| $\chi(x)\,\delta_0(x-1)$ | $1$ | only $x=1$, $\chi(1)=1$ |
| $\delta_0(x)$ | $1$ | only $x=0$ |
| $\delta_0(x)\,\chi(x-1)$ | $\chi(-1)$ | only $x=0$ |
| $\delta_0(x)\,\delta_0(x-1)$ | $0$ | $x\neq 0$ and $x\neq 1$ can't both hold |

**The quadratic character sum.** For $f(x)=x(x-1)=x^2-x$ with leading coefficien
t $a=1$ and discriminant $\Delta = 1 \not\equiv 0$, the standard identity gives
$\sum_x \chi(x(x-1)) = -\chi(a) = -1$. (Verified: $p=5$ gives $-1$; $p=7$ gives
$-1$.)

**Combining:**
$$N = \frac{1}{4}\bigl[p + 0 + 1 + 0 + (-1) + 1 + 1 + \chi(-1) + 0\bigr] = \frac
{p + 2 + \chi(-1)}{4}.$$

Since $\chi(-1) = (-1)^{(p-1)/2}$:
- If $p \equiv 1 \pmod{4}$: $\chi(-1)=1$, so $N = \dfrac{p+3}{4}$.
- If $p \equiv 3 \pmod{4}$: $\chi(-1)=-1$, so $N = \dfrac{p+1}{4}$.

**Verification.**
- $p=3$: squares $\{0,1\}$, squares$+1$ $\{1,2\}$, intersection $\{1\}$, count $
= 1 = (3+1)/4$. ✓
- $p=5$: squares $\{0,1,4\}$, squares$+1$ $\{0,1,2\}$, intersection $\{0,1\}$, c
ount $= 2 = (5+3)/4$. ✓
- $p=7$: squares $\{0,1,2,4\}$, squares$+1$ $\{1,2,3,5\}$, intersection $\{1,2\}
$, count $= 2 = (7+1)/4$. ✓
- $p=13$: squares $\{0,1,3,4,9,10,12\}$, squares$+1$ $\{0,1,2,4,5,10,11\}$, inte
rsection $\{0,1,4,10\}$, count $= 4 = (13+3)/4$. ✓

**Answer.** The number of residues mod $p$ that are both squares and squares plu
s one is:

$$\boxed{\dfrac{p + 2 + (-1)^{(p-1)/2}}{4}}$$

equivalently, $\dfrac{p+3}{4}$ if $p \equiv 1 \pmod{4}$, and $\dfrac{p+1}{4}$ if
 $p \equiv 3 \pmod{4}$.
