# Problem

A specialized digital factory operates using a unique power-distribution protocol. For any given energy level $n$ (where $n$ is a positive integer), the factory requires a configuration of exactly $k$ energy-regulating modules. Each module’s capacity must be a factor of $n$.

The factory has two potential operational modes:
1.  **The Quadratic Configuration:** This mode is activated if there exist $k$ module capacities (where a capacity can be used more than once) such that the sum of their squares is exactly equal to $n$.
2.  **The Linear Configuration:** This mode is activated if there exist $k$ module capacities (where a capacity can be used more than once) such that their sum is exactly equal to $n$.

The factory's control system is considered "universally stable" for a specific value $k$ if the following condition holds: for every possible energy level $n$, whenever a Quadratic Configuration is possible, a Linear Configuration must also be possible.

Find the sum of all positive integers $k$ for which the factory's control system is universally stable.
