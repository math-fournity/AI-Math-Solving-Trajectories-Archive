$ and $\alpha\beta = 9-p$, so $\alpha,\beta$ are roots of $x^2 - 6x + (9-p)=0$.
Define $a_k = \alpha^k + \beta^k$, which is an integer satisfying $a_k = 6a_{k-1
} - (9-p)a_{k-2}$ with $a_0=2, a_1=6$.

**Reduction via the floor.** If $0 < \beta < 1$ (i.e., $2 < \sqrt{p} < 4$, so $p
 \in \{5,7,11,13\}$), then $0 < \beta^{2n} < 1$ for all $n \geq 1$, giving $\alp
ha^{2n} = a_{2n} - \beta^{2n}$ with $\beta^{2n}\in(0,1)$. Thus $\lfloor\alpha^{2
n}\rfloor = a_{2n}-1$ and $\lfloor\alpha^{2n}\rfloor+1 = a_{2n}$. The condition
becomes $a_{2n} \equiv 0 \pmod{2^{n+1}}$ for all $n\geq 1$.

**Eliminating small primes.** For $p=2$: at $n=2$, $(3+\sqrt2)^4 = 193+132\sqrt2
 \approx 379.68$, so $\lfloor\cdot\rfloor+1 = 380$, but $8\nmid 380$. Fails. For
 $p=3$: at $n=1$, $(3+\sqrt3)^2 \approx 22.39$, so $\lfloor\cdot\rfloor+1=23$, b
ut $4\nmid 23$. Fails.

**Testing $p=5$.** Here $q = 9-p = 4$, and $\beta = 3-\sqrt5 \approx 0.764 \in (
0,1)$. Set $b_n = a_{2n} = \alpha^{2n}+\beta^{2n}$. Let $\gamma = \alpha^2 = 14+
6\sqrt5$, $\delta = \beta^2 = 14-6\sqrt5$. Then $b_n = \gamma^n + \delta^n$ with
 $\gamma+\delta = 28$, $\gamma\delta = 16 = 2^4$, and recurrence $b_n = 28b_{n-1
}-16b_{n-2}$, $b_0=2, b_1=28$.

**Key claim:** $v_2(b_n) \geq 2n$ for all $n \geq 0$, where $v_2$ is the 2-adic
valuation.

*Proof of claim.* Work in $\mathbb{Q}_2(\sqrt5)$ (a ramified quadratic extension
 since $5\equiv 5\pmod 8$). The 2-adic valuation extends, and $\sqrt5$ is a unit
. Compute $v_2(\gamma)$:
$$\gamma = 14+6\sqrt5 = 2(7+3\sqrt5).$$
Since $(7+3\sqrt5)(7-3\sqrt5) = 49-45 = 4$, we get $v_2(7+3\sqrt5)+v_2(7-3\sqrt5
)=2$. The Galois automorphism $\sqrt5\mapsto -\sqrt5$ preserves the valuation, s
o $v_2(7+3\sqrt5)=v_2(7-3\sqrt5)=1$. Therefore $v_2(\gamma)=1+1=2$, and by conju
gation $v_2(\delta)=2$.

Thus $v_2(\gamma^n)=2n$ and $v_2(\delta^n)=2n$. Since both terms in $b_n=\gamma^
n+\delta^n$ have valuation $2n$:
$$v_2(b_n) \geq \min(v_2(\gamma^n),\, v_2(\delta^n)) = 2n.$$
This holds for all $n\geq 0$. $\square$

**Conclusion.** For $n\geq 1$: $v_2(b_n) \geq 2n \geq n+1$, so $2^{n+1}\mid b_n$
. For $n=0$: $b_0=2$ and $2^1\mid 2$. Since $0<\beta<1$, we have $\lfloor\alpha^
