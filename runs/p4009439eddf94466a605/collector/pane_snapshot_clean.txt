Looking at this problem, I need to find when the four outer vertices of two exte
rnally-constructed squares are concyclic.

## Setup

Place $C$ at the origin, $B = (a, 0)$, $A = (b\cos C^\circ, b\sin C^\circ)$, whe
re $a = BC$, $b = CA$.

**Square $BCD_1D_2$ (outside, below):** $D_1 = (0, -a)$, $D_2 = (a, -a)$.

**Square $ACE_1E_2$ (outside, away from $B$):** The outward direction from $AC$
is $(-\sin C^\circ, \cos C^\circ)$, giving:
$$E_1 = (-b\sin C^\circ,\; b\cos C^\circ), \quad E_2 = (b(\cos C^\circ - \sin C^
\circ),\; b(\sin C^\circ + \cos C^\circ))$$

## Concyclicity Condition

Let $s = \sin C^\circ$, $c = \cos C^\circ$. Using the circle equation $x^2 + y^2
 + Dx + Ey + F = 0$:

**From $D_1$:** $a^2 - Ea + F = 0$, so $F = Ea - a^2$.

**From $D_2$:** $2a^2 + Da - Ea + F = 0 \Rightarrow D = -a$.

**From $E_1$:** $b^2 + ab\,s + E(b\,c + a) - a^2 = 0$, giving $E = \frac{a^2 - b
^2 - ab\,s}{a + b\,c}$.

**From $E_2$:** $2b^2 - ab(c - s) + E(a + b\,s + b\,c) - a^2 = 0$, giving $E = \
frac{a^2 - 2b^2 + ab(c - s)}{a + b\,s + b\,c}$.

Setting the two expressions for $E$ equal and cross-multiplying:

$$(a^2 - b^2 - ab\,s)(a + b\,s + b\,c) = (a^2 - 2b^2 + ab\,c - ab\,s)(a + b\,c)$
$

Expanding both sides and simplifying, the $ab^2$ terms cancel completely (using
$c^2 + s^2 = 1$), leaving:

$$a^2 b(c - s) - b^3(c - s) = 0 \quad\Longrightarrow\quad b(c - s)(a^2 - b^2) =
0$$

Since $b > 0$:

$$\boxed{(\cos C^\circ - \sin C^\circ)(a^2 - b^2) = 0}$$

This gives two cases: **$C = 45^\circ$** or **$a = b$** (i.e., $A = B$).

## Counting Ordered Triples

**Case 1: $C = 45^\circ$.** Then $A + B = 135$ with $A, B \geq 1$ integers. The
number of ordered pairs $(A, B)$ is $134$.

**Case 2: $A = B$.** Then $2A + C = 180$, so $C = 180 - 2A$ with $A \geq 1$, $C
\geq 1$, giving $A \in \{1, 2, \ldots, 89\}$: **$89$** triples.

**Overlap:** $C = 45^\circ$ and $A = B$ requires $A = 67.5^\circ \notin \mathbb{
Z}$, so there is **no overlap**.

## Final Count

$$134 + 89 = \boxed{223}$$
