## Solution

**Step 1: Find an antiderivative.**

We look for a function whose derivative gives the integrand $e^{nx}(\tan^{n-1}x
+ \tan^n x + \tan^{n+1}x)$.

Compute:
$$\frac{d}{dx}\!\left[e^{nx}\tan^n x\right] = n\,e^{nx}\tan^n x + e^{nx}\cdot n\
tan^{n-1}x\,\sec^2 x.$$

Using $\sec^2 x = 1 + \tan^2 x$:
$$= n\,e^{nx}\!\left[\tan^n x + \tan^{n-1}x(1+\tan^2 x)\right] = n\,e^{nx}\!\lef
t(\tan^{n-1}x + \tan^n x + \tan^{n+1}x\right).$$

This is exactly $n$ times the integrand. Therefore:

**Step 2: Evaluate $I_n$ by the Fundamental Theorem.**

$$I_n = \int_0^{\pi/4} e^{nx}\!\left(\tan^{n-1}x + \tan^n x + \tan^{n+1}x\right)
dx = \frac{1}{n}\Big[e^{nx}\tan^n x\Big]_0^{\pi/4}.$$

At the bounds: $\tan^n(\pi/4) = 1^n = 1$, and $\tan^n(0) = 0$ (for $n\ge 1$). He
nce

$$I_n = \frac{1}{n}\,e^{n\pi/4}.$$

**Step 3: Compute $nI_n$ and the $n^2$-th root.**

$$nI_n = e^{n\pi/4}, \qquad \sqrt[n^2]{nI_n} = \left(e^{n\pi/4}\right)^{1/n^2} =
 e^{\,\pi/(4n)}.$$

**Step 4: Evaluate the limit.**

$$n\!\left(\sqrt[n^2]{nI_n}-1\right) = n\!\left(e^{\,\pi/(4n)}-1\right).$$

As $n\to\infty$, $\frac{\pi}{4n}\to 0$, so using $e^u - 1 \sim u$ as $u\to 0$:

$$n\!\left(e^{\,\pi/(4n)}-1\right) \sim n\cdot\frac{\pi}{4n} = \frac{\pi}{4}.$$

Therefore

$$\boxed{\lim_{n\to\infty} n\!\left(\sqrt[n^2]{nI_n}-1\right) = \frac{\pi}{4}.}$
