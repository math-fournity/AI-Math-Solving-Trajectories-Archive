# Problem

In the high-tech city of Cyberia, there are $n$ dormant security terminals. Each terminal requires a specific activation code in the form of a quadratic polynomial: $Ax^2 + Bx + C$. Currently, each terminal shows three empty slots represented by asterisks: $*x^2 + *x + *$.

Two hackers, Alpha and Beta, take turns filling these slots. Alpha goes first. In each turn, a player selects any empty slot on any terminal and replaces the asterisk with any non-zero real number. The game continues for exactly $3n$ turns until all $3n$ slots across the $n$ terminals are filled.

Alpha’s objective is to sabotage the system by ensuring as many terminals as possible have "unstable" codes (quadratic equations that have no real roots). Beta’s objective is to protect the system by ensuring as many terminals as possible have "stable" codes (quadratic equations that have at least one real root).

What is the maximum number of unstable terminals Alpha can guaranteed, regardless of how Beta plays?
