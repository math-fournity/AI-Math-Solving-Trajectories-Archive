## Solution

We evaluate
$$S_k = \sum_{r=0}^{k}\frac{\zeta(2k-2r)}{r!}.$$

**Step 1: Decompose ζ(2n).** Write $\zeta(2n) = 1 + \varepsilon_n$, where $\vare
psilon_n = \zeta(2n)-1$. Note:
- $\varepsilon_0 = \zeta(0)-1 = -\tfrac{3}{2}$.
- For $n \ge 1$: $\varepsilon_n = \sum_{m=2}^{\infty} m^{-2n} > 0$, and $\vareps
ilon_n \to 0$ as $n\to\infty$ (since $2^{-2n}\to 0$ dominates).
- $|\varepsilon_n|$ is uniformly bounded: $|\varepsilon_n|\le \max(|\varepsilon_
0|,\varepsilon_1)=\max(\tfrac32,\zeta(2)-1)=\tfrac32=:C$.

**Step 2: Split the sum.**
$$S_k = \sum_{r=0}^{k}\frac{1+\varepsilon_{k-r}}{r!} = \underbrace{\sum_{r=0}^{k
}\frac{1}{r!}}_{A_k} + \underbrace{\sum_{r=0}^{k}\frac{\varepsilon_{k-r}}{r!}}_{
R_k}.$$

Clearly $A_k \to \sum_{r=0}^{\infty}\frac{1}{r!}=e$. It remains to show $R_k\to
0$.

**Step 3: Show $R_k\to 0$.** Rewrite with $s=k-r$:
$$R_k = \sum_{s=0}^{k}\frac{\varepsilon_s}{(k-s)!}.$$

Fix $\delta>0$. Since $\varepsilon_s\to 0$, choose $M$ so that $|\varepsilon_s|<
\delta$ for all $s>M$. Split:
$$R_k = \underbrace{\sum_{s=0}^{M}\frac{\varepsilon_s}{(k-s)!}}_{P_k} + \underbr
ace{\sum_{s=M+1}^{k}\frac{\varepsilon_s}{(k-s)!}}_{Q_k}.$$

- **Bound $P_k$:** For fixed $M$ and $k>M$,
$$|P_k| \le \sum_{s=0}^{M}\frac{C}{(k-s)!}\le \frac{C(M+1)}{(k-M)!}\xrightarrow{
k\to\infty}0.$$

- **Bound $Q_k$:** Using $|\varepsilon_s|<\delta$ for $s>M$,
$$|Q_k|\le \delta\sum_{s=M+1}^{k}\frac{1}{(k-s)!}=\delta\sum_{j=0}^{k-M-1}\frac{
1}{j!}\le \delta\,e.$$

Therefore $\limsup_{k\to\infty}|R_k|\le \delta\,e$. Since $\delta>0$ was arbitra
ry, $R_k\to 0$.

**Step 4: Conclude.**
$$\lim_{k\to\infty}S_k = \lim_{k\to\infty}A_k + \lim_{k\to\infty}R_k = e + 0 = e
.$$
