**Goal:** Evaluate $\displaystyle L = \lim_{x\to 0}\bigl(x\,\Gamma(x)\bigr)^{1/x
}$.

---

### Step 1. Simplify using the Gamma recurrence

The Gamma function satisfies $\Gamma(x+1) = x\,\Gamma(x)$ for all $x$ where both
 sides are defined. Hence

$$x\,\Gamma(x) = \Gamma(x+1),$$

so the limit becomes

$$L = \lim_{x\to 0}\,\Gamma(x+1)^{1/x}.$$

### Step 2. Reduce to a logarithmic limit

Since $\Gamma(1)=1$, the base tends to $1$ and the exponent $1/x\to\pm\infty$, s
o we take logarithms:

$$\ln L = \lim_{x\to 0}\frac{\ln\Gamma(x+1)}{x}.$$

This is a $\tfrac{0}{0}$ indeterminate form since $\ln\Gamma(1)=\ln 1 = 0$.

### Step 3. Apply L'Hôpital's rule

Differentiating numerator and denominator with respect to $x$:

$$\ln L = \lim_{x\to 0}\frac{\frac{d}{dx}\ln\Gamma(x+1)}{\frac{d}{dx}x} = \lim_{
x\to 0}\frac{\psi(x+1)}{1},$$

where $\psi = \Gamma'/\Gamma$ is the digamma function.

### Step 4. Evaluate the digamma function at $1$

The standard value is

$$\psi(1) = -\gamma,$$

where $\gamma$ is the Euler–Mascheroni constant. (This follows from $\psi(1) = \
Gamma'(1)/\Gamma(1) = \Gamma'(1)$ and the classical series $\gamma = -\int_0^\in
fty e^{-t}\ln t\,dt = -\Gamma'(1)$.)

Therefore

$$\ln L = \psi(1) = -\gamma.$$

### Step 5. Exponentiate

$$L = e^{-\gamma}.$$

---

### Verification via Taylor expansion (independent check)

The known expansion around $x=0$ is

$$\ln\Gamma(1+x) = -\gamma\,x + \sum_{n=2}^{\infty}\frac{(-1)^n\zeta(n)}{n}\,x^n
,\qquad |x|<1.$$

Dividing by $x$:

$$\frac{\ln\Gamma(1+x)}{x} = -\gamma + O(x)\xrightarrow{x\to 0}-\gamma,$$

confirming $\ln L = -\gamma$ and thus $L = e^{-\gamma}$.

---

$$\boxed{\displaystyle\lim_{x\to 0}\bigl(x\,\Gamma(x)\bigr)^{1/x}=e^{-\gamma}}$$

where $\gamma\approx 0.5772$ is the Euler–Mascheroni constant.
