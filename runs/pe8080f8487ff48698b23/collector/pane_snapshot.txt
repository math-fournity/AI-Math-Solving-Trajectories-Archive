## 证明

我们使用关于 `K[x, y]` 的 **generic initial ideal**（一般初始理想，gin），其定义
为关于 **degree reverse lexicographic order**（分次逆字典序，x > y）的（这是标准
约定；根据 Galligo–Bayer–Stillman 定理，关于 revlex 的 gin 是 Borel-fixed 的，且
与 Hilbert 函数相关联）。

### 第 1 步：`I` 的 Hilbert 函数

`I = (x², y²)` 是两个二次式的完整交集。商 `R = K[x,y]/I` 的单项式基为 `{1, x, y,
 xy}`，因为 `x² = 0` 且 `y² = 0`。因此

| d | 0 | 1 | 2 | ≥3 |
|---|---|---|---|---|
| H_R(d) | 1 | 2 | 1 | 0 |

所以 `H = (1, 2, 1, 0, 0, …)`。gin `J = gin(I)` 是一个具有相同 Hilbert 函数的 Bo
rel-fixed 单项式理想。

### 第 2 步：对具有 `H = (1,2,1,0,…)` 的 Borel-fixed 单项式理想进行分类

在 `K[x, y]` 中（特征 0，因此 Borel-fixed = strongly stable），条件为：每当 `x^a
 y^b ∈ J` 且 `b ≥ 1` 时，必有 `x^{a+1} y^{b-1} ∈ J`（将一个 `y` 替换为 `x`）。

`J` 中余项的约束条件：
- 次数 0：`1 ∉ J`（唯一不在 `J` 中的次数为 0 的单项式）。
- 次数 1：`x, y ∉ J`（需要 2 个单项式，且只有 2 个存在）。
- 次数 2：`{x², xy, y²}` 中恰好有一个 **不在** `J` 中。
- 次数 ≥ 3：所有单项式都在 `J` 中（因为 `H(d) = 0`）。

测试三种可能性：

**情况 A：`x² ∉ J`**（因此 `xy, y² ∈ J`）。强稳定性应用于 `xy ∈ J`（`a=1, b=1`）
得到 `x² ∈ J` —— 与 `x² ∉ J` 矛盾。不可能。

**情况 B：`xy ∉ J`**（因此 `x², y² ∈ J`）。强稳定性应用于 `y² ∈ J`（`a=0, b=2`）
得到 `xy ∈ J` —— 与 `xy ∉ J` 矛盾。不可能。

**情况 C：`y² ∉ J`**（因此 `x², xy ∈ J`）。验证强稳定性：
- `xy ∈ J` ⇒ `x² ∈ J` ✓。
- 次数 ≥ 3 的单项式都在 `J` 中：`y³ ∈ J` ⇒ `xy² ∈ J` ✓；`xy² ∈ J` ⇒ `x²y ∈ J` ✓
；`x²y ∈ J` ⇒ `x³ ∈ J` ✓。
- 没有规则强制 `y² ∈ J`（强稳定性仅向“更偏向 `x`”的单项式移动），因此 `y² ∉ J`
是一致的。

因此，**唯一**具有此 Hilbert 函数的 Borel-fixed 单项式理想是 `J = (x², xy, y³)`
（极小生成元集：`x²`, `xy`, `y³`；这包含了所有次数 ≥ 3 的单项式，且排除了 `y²`）
。

### 第 3 步：通过一般坐标下的直接 Gröbner 基进行确认

应用一般线性坐标变换：设 `L_1 = a_1 x + b_1 y`, `L_2 = a_2 x + b_2 y`，其中 `a_i
, b_i` 为一般值（`a_1 b_2 - a_2 b_1 ≠ 0`，`a_1, a_2 ≠ 0`）。则 `g(I) = (L_1², L_
2²)`。

- `in_revlex(L_1²) = a_1² x²`, `in_revlex(L_2²) = a_2² x²`。两项的首项均为 `x²`
。
- S-多项式约化：`L_2² - (a_2/a_1)² L_1² = (L_2 - (a_2/a_1)L_1)(L_2 + (a_2/a_1)L_
1)`。第一个因子是 `γ y`，其中 `γ = b_2 - a_2 b_1/a_1 ≠ 0`（一般情况）；第二个因
子是 `2 a_2 x + δ y`，其中 `δ = b_2 + a_2 b_1/a_1`。因此该元素为 `γ(2 a_2 xy + δ
 y²)`，其 revlex 首项为 `xy`（因为 `xy > y²` 在 revlex 中，`x > y`）。
- 继续对 S-多项式进行约化，最终产生一个首项为 `y³` 的元素（次数为 3 的部分必须被
消去以匹配 `H(3)=0`，且 `xy²` 可被 `xy` 约简，留下 `y³` 作为新的首项，其系数为 `
b_1²` 加上来自约简的贡献 —— 对于一般选择，该值非零）。

因此，`g(I)` 的简化 Gröbner 基的首项为 `x², xy, y³`，证实了

$$\operatorname{gin}(I) = (x^2,\, xy,\, y^3).$$
