# Problem

A specialized microchip architecture consists of a grid of processing nodes arranged in 2009 rows and 2011 columns. To optimize heat dissipation, the nodes are manufactured in two different materials, "Type-A" and "Type-B," alternating in a checkerboard pattern across the entire grid.

Due to a manufacturing defect, a total of $k$ specific nodes must be deactivated and removed from the circuitry. Engineers have discovered that as long as the remaining active nodes contain an equal number of Type-A and Type-B materials, the circuit can still function, provided that every single active node can be paired with an adjacent active node (sharing a horizontal or vertical boundary) to form a "dual-core bridge" (a 1x2 or 2x1 block).

What is the largest natural number $k$ such that, regardless of which $k$ nodes are removed, if the remaining set of nodes has an equal count of Type-A and Type-B materials, it is guaranteed that the entire remaining set can be perfectly partitioned into these dual-core bridges?
