## Solution

**Setup.** Place $O$ at the origin with the angle bisector of $\angle AOB$ as th
e axis. Since $\measuredangle AOB = 120°$, the bisector makes angle $\alpha = 60
°$ with each ray.

**Center and radius relation.** A circle of radius $r$ tangent to both rays $\ov
errightarrow{OA}$ and $\overrightarrow{OB}$ has its center on the bisector at di
stance
$$d = \frac{r}{\sin 60°} = \frac{2r}{\sqrt{3}}$$
from $O$.

For $\omega_0$: $r_0 = 6$, so $d_0 = \frac{12}{\sqrt{3}} = 4\sqrt{3}$.

**Recurrence.** All centers lie on the bisector. Since $r_i < r_{i-1}$, circle $
\omega_i$ is closer to $O$, so $d_i < d_{i-1}$. External tangency of $\omega_i$
and $\omega_{i-1}$ gives:
$$d_{i-1} - d_i = r_{i-1} + r_i.$$

Substituting $d = \frac{2r}{\sqrt{3}}$:
$$\frac{2}{\sqrt{3}}(r_{i-1} - r_i) = r_{i-1} + r_i.$$

Multiplying by $\sqrt{3}$:
$$2r_{i-1} - 2r_i = \sqrt{3}\,r_{i-1} + \sqrt{3}\,r_i,$$
$$r_{i-1}(2 - \sqrt{3}) = r_i(2 + \sqrt{3}),$$
$$r_i = r_{i-1}\cdot\frac{2-\sqrt{3}}{2+\sqrt{3}}.$$

**Common ratio.** Rationalizing:
$$k = \frac{2-\sqrt{3}}{2+\sqrt{3}} = \frac{(2-\sqrt{3})^2}{(2+\sqrt{3})(2-\sqrt
{3})} = \frac{7 - 4\sqrt{3}}{1} = 7 - 4\sqrt{3}.$$

Note $k = 7 - 4\sqrt{3} \approx 0.0718 < 1$. ✓

**Geometric series.** Since $r_i = 6\cdot k^i$:
$$S = \sum_{i=1}^{\infty} r_i = 6\sum_{i=1}^{\infty} k^i = 6\cdot\frac{k}{1-k}.$
$

Compute $1 - k = 1 - (7 - 4\sqrt{3}) = 4\sqrt{3} - 6$.

$$\frac{k}{1-k} = \frac{7 - 4\sqrt{3}}{4\sqrt{3} - 6}.$$

Rationalize by multiplying by $\frac{4\sqrt{3}+6}{4\sqrt{3}+6}$:

- Numerator: $(7-4\sqrt{3})(4\sqrt{3}+6) = 28\sqrt{3} + 42 - 48 - 24\sqrt{3} = 4
\sqrt{3} - 6$.
- Denominator: $(4\sqrt{3})^2 - 36 = 48 - 36 = 12$.

$$\frac{k}{1-k} = \frac{4\sqrt{3}-6}{12} = \frac{2\sqrt{3}-3}{6}.$$

Therefore:
$$S = 6\cdot\frac{2\sqrt{3}-3}{6} = 2\sqrt{3} - 3.$$

**Final answer.** We have $S = a\sqrt{b} + c$ with $a = 2$, $b = 3$, $c = -3$ (a
nd $b=3$ is square-free). Thus:
$$100a + 10b + c = 100(2) + 10(3) + (-3) = 200 + 30 - 3 = \boxed{227}.$$
