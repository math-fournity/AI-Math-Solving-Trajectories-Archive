## Solution

**Answer: No, it does not have to hold that $c_n \to 0$.**

### Counterexample

Define the sequences as follows:

- Let $c_n = 1$ for all $n \geq 1$.
- Let $X_n$ be a random variable with distribution
$$X_n = \begin{cases} 0 & \text{with probability } 1 - \tfrac{1}{n}, \\ 1 & \tex
t{with probability } \tfrac{1}{n}. \end{cases}$$

(These may be defined on any common probability space; only the marginal distrib
utions matter for the argument.)

### Verification

**Condition 1: $\mathbf{P}(|X_n| > 0) > 0$ for all $n$.**

$$\mathbf{P}(|X_n| > 0) = \mathbf{P}(X_n = 1) = \frac{1}{n} > 0 \quad \text{for
all } n \geq 1. \checkmark$$

**Condition 2: $c_n X_n \overset{P}{\to} 0$.**

Since $c_n = 1$, we have $c_n X_n = X_n$. For any $\varepsilon > 0$:

- If $\varepsilon \geq 1$: $\mathbf{P}(|X_n| > \varepsilon) = 0$ for all $n$.
- If $0 < \varepsilon < 1$: $\mathbf{P}(|X_n| > \varepsilon) = \mathbf{P}(X_n =
1) = \frac{1}{n} \to 0$.

In both cases $\mathbf{P}(|c_n X_n| > \varepsilon) \to 0$, so $c_n X_n \overset{
P}{\to} 0$. $\checkmark$

**Yet $c_n \not\to 0$:** $c_n = 1$ for all $n$, so $c_n \to 1 \neq 0$.

### Why the implication fails

The condition $\mathbf{P}(|X_n|>0)>0$ only guarantees that $X_n$ is *not almost
surely zero*, but it places no lower bound on how much mass $X_n$ places away fr
om zero. By letting $\mathbf{P}(|X_n|>0) = 1/n \to 0$, the random variables $X_n
$ themselves already converge to $0$ in probability. Multiplying by a bounded (e
ven constant) sequence $c_n$ preserves this convergence, so $c_n$ need not tend
to $0$.
