We evaluate
$$I = \int_0^{\infty} \frac{2\sin x\,\cos^2 x}{x\,e^{x\sqrt{3}}}\,dx = 2\int_0^{
\infty} \frac{\sin x\,\cos^2 x}{x}\,e^{-\sqrt{3}\,x}\,dx.$$

**Step 1. Linearize the trigonometric factor.**

Using $\cos^2 x = \tfrac{1+\cos 2x}{2}$,
$$I = \int_0^{\infty} \frac{\sin x\,(1+\cos 2x)}{x}\,e^{-\sqrt{3}\,x}\,dx = \und
erbrace{\int_0^{\infty} \frac{\sin x}{x}\,e^{-\sqrt{3}\,x}\,dx}_{J_1} + \underbr
ace{\int_0^{\infty} \frac{\sin x\,\cos 2x}{x}\,e^{-\sqrt{3}\,x}\,dx}_{J_2}.$$

For $J_2$, apply the product-to-sum identity $\sin x\cos 2x = \tfrac{1}{2}[\sin
3x - \sin x]$:
$$J_2 = \frac{1}{2}\int_0^{\infty}\frac{\sin 3x}{x}\,e^{-\sqrt{3}\,x}\,dx - \fra
c{1}{2}\int_0^{\infty}\frac{\sin x}{x}\,e^{-\sqrt{3}\,x}\,dx = \frac{1}{2}J_3 -
\frac{1}{2}J_1,$$
where $J_3 = \int_0^{\infty}\frac{\sin 3x}{x}\,e^{-\sqrt{3}\,x}\,dx$.

Combining,
$$I = J_1 + \frac{1}{2}J_3 - \frac{1}{2}J_1 = \frac{1}{2}J_1 + \frac{1}{2}J_3.$$

**Step 2. A standard Laplace–Dirichlet integral.**

For $a>0,\; b\ge 0$, define
$$F(b)=\int_0^{\infty}\frac{\sin(ax)}{x}\,e^{-bx}\,dx.$$
Differentiating under the integral (justified since the differentiated integrand
 $\sin(ax)e^{-bx}$ is absolutely integrable for $b>0$):
$$F'(b)=-\int_0^{\infty}\sin(ax)\,e^{-bx}\,dx = -\frac{a}{a^2+b^2}.$$
Integrating back, $F(b) = -\arctan\!\left(\tfrac{b}{a}\right) + C$. As $b\to\inf
ty$, $F(b)\to 0$ (Riemann–Lebesgue dominated convergence) while $\arctan(b/a)\to
\pi/2$, so $C=\pi/2$. Hence
$$F(b) = \frac{\pi}{2}-\arctan\!\left(\frac{b}{a}\right)=\arctan\!\left(\frac{a}
{b}\right),\qquad a>0,\; b\ge 0.$$

**Step 3. Apply with $b=\sqrt{3}$.**

- $J_1 = F(\sqrt{3})$ with $a=1$: $\;J_1 = \arctan\!\left(\tfrac{1}{\sqrt{3}}\ri
ght) = \arctan\!\left(\tfrac{\sqrt{3}}{3}\right) = \dfrac{\pi}{6}.$
- $J_3 = F(\sqrt{3})$ with $a=3$: $\;J_3 = \arctan\!\left(\tfrac{3}{\sqrt{3}}\ri
ght) = \arctan(\sqrt{3}) = \dfrac{\pi}{3}.$

**Step 4. Combine.**

$$I = \frac{1}{2}J_1 + \frac{1}{2}J_3 = \frac{1}{2}\cdot\frac{\pi}{6} + \frac{1}
{2}\cdot\frac{\pi}{3} = \frac{\pi}{12} + \frac{\pi}{6} = \frac{\pi}{12} + \frac{
2\pi}{12} = \frac{3\pi}{12} = \frac{\pi}{4}.$$
