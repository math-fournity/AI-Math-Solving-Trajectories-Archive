## Proof

We prove by induction on $n$ that there exists an $n$-digit number, all of whose
 digits are odd, that is divisible by $5^n$.

**Base case ($n=1$).** The number $5$ is a one-digit number with an odd digit, a
nd $5 \mid 5$. ✓

**Inductive step.** Suppose $N$ is an $n$-digit number, every digit odd, with $5
^n \mid N$. We construct an $(n+1)$-digit number with the same properties divisi
ble by $5^{n+1}$.

Write $N = 5^n \cdot k$ for some integer $k$. We prepend an odd digit $d \in \{1
,3,5,7,9\}$ to the left of $N$, forming
$$M = d \cdot 10^n + N = d \cdot 10^n + 5^n k = 5^n\!\bigl(d \cdot 2^n + k\bigr)
.$$
Thus $5^{n+1} \mid M$ iff $5 \mid \bigl(d \cdot 2^n + k\bigr)$, i.e.
$$d \cdot 2^n \equiv -k \pmod{5}.$$

Since $\gcd(2^n, 5) = 1$, the element $2^n$ is invertible modulo $5$, so this co
ngruence determines a **unique** residue class for $d$ modulo $5$:
$$d \equiv -k \cdot (2^n)^{-1} \pmod{5}.$$

It remains to check that this residue class is represented among the odd digits.
 The odd digits $\{1,3,5,7,9\}$ give residues modulo $5$:
$$1 \equiv 1,\quad 3 \equiv 3,\quad 5 \equiv 0,\quad 7 \equiv 2,\quad 9 \equiv 4
 \pmod{5},$$
which is exactly the complete set $\{0,1,2,3,4\}$. Hence **every** residue class
 modulo $5$ is hit by some odd digit, so we may choose $d \in \{1,3,5,7,9\}$ sat
isfying the required congruence.

With this choice, $M = d\cdot 10^n + N$ is an $(n+1)$-digit number (since $d \ne
q 0$), all of its digits are odd (the new leading digit $d$ is odd, and the rema
ining digits are those of $N$, all odd by hypothesis), and $5^{n+1} \mid M$.

**Conclusion.** By induction, for every positive integer $n$ there exists an $n$
-digit number, all of whose digits are odd, divisible by $5^n$. $\blacksquare$
