## Proof

**Claim.** There exists a continuous linear map $F_\infty : X \to \mathcal{Y}_\i
nfty$ satisfying $F_N = \pi_N \circ F_\infty$ for every $N$. Moreover, it is uni
que.

### Construction

Define $F_\infty : X \to \mathcal{Y}_\infty = \prod_{n=1}^{\infty} Y_n$ by

$$F_\infty(x) := \big(f_1(x),\, f_2(x),\, f_3(x),\, \ldots\big), \qquad x \in X.
$$

This is well defined: for each $x \in X$ and each $n \geq 1$, $f_n(x) \in Y_n$,
so the tuple $(f_n(x))_{n \geq 1}$ is an element of the Cartesian product $\prod
_n Y_n$.

### Linearity

Let $x, y \in X$ and $\alpha, \beta$ be scalars. Since every $f_n$ is linear,

$$F_\infty(\alpha x + \beta y) = \big(f_n(\alpha x + \beta y)\big)_{n \geq 1} =
\big(\alpha\, f_n(x) + \beta\, f_n(y)\big)_{n \geq 1} = \alpha\, F_\infty(x) + \
beta\, F_\infty(y),$$

where the last equality uses the **coordinatewise** (product) vector-space struc
ture on $\prod_n Y_n$. Hence $F_\infty$ is linear.

### Continuity

The space $\mathcal{Y}_\infty = \prod_n Y_n$ carries the **product topology**, w
hich is the initial (coarsest) topology with respect to the coordinate projectio
ns $p_n : \mathcal{Y}_\infty \to Y_n$. A standard characterization of the produc
t topology states:

> *A map $g : Z \to \prod_n Y_n$ from any topological space $Z$ is continuous if
 and only if every coordinate $p_n \circ g : Z \to Y_n$ is continuous.*

Apply this with $g = F_\infty$ and $Z = X$. The $n$-th coordinate of $F_\infty$
is

$$p_n \circ F_\infty = f_n,$$

which is continuous by hypothesis. Therefore $F_\infty$ is continuous.

### The factorization property $F_N = \pi_N \circ F_\infty$

The projection $\pi_N : \mathcal{Y}_\infty \to \mathcal{Y}_N$ extracts the first
 $N$ coordinates. Thus for every $x \in X$,

$$\pi_N\big(F_\infty(x)\big) = \big(f_1(x), \ldots, f_N(x)\big) = F_N(x).$$

Hence $F_N = \pi_N \circ F_\infty$ for all $N$.

### Uniqueness

Suppose $G : X \to \mathcal{Y}_\infty$ is any map (continuous linear or otherwis
e) with $\pi_N \circ G = F_N$ for every $N$. Writing $G(x) = (g_1(x), g_2(x), \l
dots)$ in coordinates, the condition $\pi_N \circ G = F_N$ forces

$$g_n(x) = f_n(x) \quad \text{for all } n \geq 1 \text{ and all } x \in X.$$

Therefore $G(x) = (f_1(x), f_2(x), \ldots) = F_\infty(x)$ for every $x$, i.e., $
G = F_\infty$. The map is unique.

### Conclusion

The map $F_\infty(x) = (f_1(x), f_2(x), \ldots)$ is a well-defined, continuous,
linear map $X \to \mathcal{Y}_\infty$ satisfying $F_N = \pi_N \circ F_\infty$ fo
r all $N$, and it is the unique such map. The key ingredient is the universal pr
operty of the product topology: continuity into a product is equivalent to coord
inatewise continuity, and each coordinate $f_n$ is continuous by assumption.
