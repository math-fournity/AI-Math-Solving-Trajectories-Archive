## Proof

**Claim.** If $f$ is an entire function with uncountably many zeros, then $f \eq
uiv 0$.

**Proof.**

Let $f$ be an entire function (holomorphic on all of $\mathbb{C}$). Suppose, for
 contradiction, that $f$ has uncountably many zeros but $f \not\equiv 0$.

A standard theorem of complex analysis states:

> **Isolated Zeros Theorem.** If $f$ is holomorphic and non-identically-zero on
a connected open set $D$, and $f(z_0) = 0$, then $z_0$ is an isolated zero of $f
$; i.e., there exists $r > 0$ such that $f(z) \neq 0$ for all $z$ with $0 < |z -
 z_0| < r$.

Since $f \not\equiv 0$ and $\mathbb{C}$ is connected, every zero of $f$ is isola
ted.

Now consider the set of zeros $Z = f^{-1}(0) \subseteq \mathbb{C}$. We show $Z$
is countable, contradicting the hypothesis that $Z$ is uncountable.

For each $n \in \mathbb{N}$, define the closed disk $\overline{D_n} = \{z \in \m
athbb{C} : |z| \le n\}$. Then
$$Z = \bigcup_{n=1}^{\infty} (Z \cap \overline{D_n}).$$

Each $Z \cap \overline{D_n}$ is a set of isolated points contained in the compac
t set $\overline{D_n}$. A compact set can contain only finitely many isolated po
ints of a given set: indeed, if $Z \cap \overline{D_n}$ were infinite, then by c
ompactness (Bolzano–Weierstrass) it would have an accumulation point $z^*$ in $\
overline{D_n}$, and $z^*$ would be a non-isolated zero of $f$—contradicting the
Isolated Zeros Theorem (which forces $f \equiv 0$ in a neighborhood of any accum
ulation point of zeros, hence $f \equiv 0$ on $\mathbb{C}$).

Therefore each $Z \cap \overline{D_n}$ is finite, and so
$$Z = \bigcup_{n=1}^{\infty} (Z \cap \overline{D_n})$$
is a countable union of finite sets, hence **countable**.

This contradicts the assumption that $Z$ is uncountable. The contradiction force
s $f \equiv 0$.

**Conclusion.** An entire function with uncountably many zeros must be identical
ly zero:
$$\boxed{f \equiv 0.}$$

s that if the zero set of a holomorphic function on a connected domain has an ac
cumulation point within the domain, then the function is identically zero. An un
countable subset of $\mathbb{C}$ necessarily has an accumulation point (since $\
mathbb{C} = \bigcup_n \overline{D_n}$, pigeonhole gives some $\overline{D_n}$ co
ntaining uncountably—hence infinitely many—zeros, which then accumulate in the c
ompact $\overline{D_n}$). Applying the identity theorem at that accumulation poi
nt yields $f \equiv 0$ immediately.
