## Proof

**Claim:** It is not possible for a non-constant analytic function to map a poin
t in its domain to a point in the unit disc, under the hypothesis that the funct
ion maps the entire complex plane into the unit disc.

**Setup.** Let $f \colon \mathbb{C} \to \mathbb{C}$ be an analytic (entire) func
tion such that $f(\mathbb{C}) \subseteq \mathbb{D}$, where $\mathbb{D} = \{z \in
 \mathbb{C} : |z| < 1\}$ is the (open) unit disc. We show that $f$ must be const
ant, which immediately implies that no *non-constant* such function can exist —
and hence, a fortiori, no non-constant such function can map any point of its do
main into the unit disc.

**Boundedness.** Since $f(\mathbb{C}) \subseteq \mathbb{D}$, we have $|f(z)| < 1
$ for every $z \in \mathbb{C}$. Thus $f$ is a bounded entire function, with the
global bound $|f(z)| \le 1$.

**Application of Liouville's theorem.** Liouville's theorem states that every bo
unded entire function is constant. Concretely, writing the Taylor expansion $f(z
) = \sum_{n=0}^{\infty} a_n z^n$ (valid for all $z$, since $f$ is entire), the C
auchy estimates give
$$|a_n| \le \frac{M(R)}{R^n}, \qquad M(R) = \max_{|z|=R} |f(z)| \le 1.$$
Letting $R \to \infty$, for every $n \ge 1$ we obtain $|a_n| \le \lim_{R\to\inft
y} 1/R^n = 0$, so $a_n = 0$ for all $n \ge 1$. Hence $f(z) = a_0$ is constant.

**Conclusion.** Any entire function whose image lies in the unit disc is constan
t. Therefore a *non-constant* analytic function mapping the entire complex plane
 into the unit disc cannot exist, and consequently cannot map any point of its d
omain to a point in the unit disc. The answer to the question is **no**.
