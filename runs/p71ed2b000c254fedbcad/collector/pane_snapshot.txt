Proof

Yes, such a regular curve and non-identity rigid motion exist.

Construction. Consider the circular helix

$$\gamma(t) = (\cos t,; \sin t,; t), \qquad t \in \mathbb{R}.$$

Regularity. We have $\gamma'(t) = (-\sin t,; \cos t,; 1)$, so

$$|\gamma'(t)|^2 = \sin^2 t + \cos^2 t + 1 = 2 > 0$$

for all $t$. Hence $\gamma$ is regular.

The rigid motion. Fix any $\alpha \neq 0$ and define the screw motion $f :
\mathbb{R}^3 \to \mathbb{R}^3$ by

$$f(x, y, z) = (x\cos\alpha - y\sin\alpha,; x\sin\alpha + y\cos\alpha,; z +
\alpha).$$

This is a rigid motion (a rotation by angle $\alpha$ about the $z$-axis composed
with a translation by $\alpha$ along the $z$-axis). It is not the identity: if $
\alpha \not\equiv 0 \pmod{2\pi}$ the rotational part is nontrivial; if $\alpha =
2k\pi$ with $k \neq 0$, the rotational part is the identity but the translation
$(0,0,\alpha)$ is nontrivial. In every case $f \neq \mathrm{id}$.

Reparametrization. Compute:

$$f(\gamma(t)) = (\cos t \cos\alpha - \sin t \sin\alpha,; \cos t \sin\alpha +
\sin t \cos\alpha,; t + \alpha) = (\cos(t+\alpha),; \sin(t+\alpha),; t+\alpha) =
\gamma(t + \alpha).$$

Setting $\varphi(t) = t + \alpha$, we have $f \circ \gamma = \gamma \circ
\varphi$. The map $\varphi : \mathbb{R} \to \mathbb{R}$ is a smooth
diffeomorphism with smooth inverse $\varphi^{-1}(s) = s - \alpha$.

Therefore $f \circ \gamma$ is a reparametrization of $\gamma$, $f$ is a rigid
motion that is not the identity, and $\gamma$ is regular. $\blacksquare$
