## Proof

Let $X$ be a topological space and $\mathcal{B}(X)$ its Borel $\sigma$-algebra (
the smallest $\sigma$-algebra containing all open sets). We build the **Borel hi
erarchy** by transfinite induction over countable ordinals and show it exhausts
$\mathcal{B}(X)$.

### Construction of the hierarchy

Define, for each countable ordinal $1 \le \alpha < \omega_1$:

- $\boldsymbol{\Sigma}^0_1 = \{U \subseteq X : U \text{ is open}\}$, and $\bolds
ymbol{\Pi}^0_1 = \{X \setminus A : A \in \boldsymbol{\Sigma}^0_1\}$ (closed sets
).
- For $\alpha \ge 2$: $\boldsymbol{\Sigma}^0_\alpha = \left\{\bigcup_{n \in \mat
hbb{N}} A_n : A_n \in \boldsymbol{\Pi}^0_{\beta_n} \text{ for some } \beta_n < \
alpha\right\}$ — countable unions of sets from lower $\Pi$-classes.
- $\boldsymbol{\Pi}^0_\alpha = \{X \setminus A : A \in \boldsymbol{\Sigma}^0_\al
pha\}$ — complements.

Set $\mathcal{S} = \bigcup_{\alpha < \omega_1} \boldsymbol{\Sigma}^0_\alpha$.

### Claim: $\mathcal{B}(X) = \mathcal{S}$.

**($\mathcal{S} \subseteq \mathcal{B}(X)$).** By transfinite induction on $\alph
a$: $\boldsymbol{\Sigma}^0_1$ = open sets $\subseteq \mathcal{B}(X)$. If every $
\boldsymbol{\Sigma}^0_\beta$ for $\beta < \alpha$ lies in $\mathcal{B}(X)$, then
 every $\boldsymbol{\Pi}^0_\beta$ ($\beta < \alpha$) lies in $\mathcal{B}(X)$ (c
losed under complement), and $\boldsymbol{\Sigma}^0_\alpha$ — being countable un
ions of these — also lies in $\mathcal{B}(X)$ (closed under countable union). He
nce $\mathcal{S} \subseteq \mathcal{B}(X)$.

**($\mathcal{B}(X) \subseteq \mathcal{S}$).** It suffices to show $\mathcal{S}$
is a $\sigma$-algebra containing all open sets; then $\mathcal{B}(X) \subseteq \
mathcal{S}$ since $\mathcal{B}(X)$ is the *smallest* such $\sigma$-algebra.

- **Contains open sets:** $\boldsymbol{\Sigma}^0_1 = \text{open sets} \subseteq
\mathcal{S}$. ✓

- **Closed under complementation:** Let $A \in \boldsymbol{\Sigma}^0_\alpha$. Th
en $X \setminus A \in \boldsymbol{\Pi}^0_\alpha$. Since $\boldsymbol{\Pi}^0_\alp
ha \subseteq \boldsymbol{\Sigma}^0_{\alpha+1}$ (a single set is a countable unio
n of one set from $\boldsymbol{\Pi}^0_\alpha$, and $\alpha < \alpha+1$), we have
 $X \setminus A \in \mathcal{S}$. ✓

- **Closed under countable unions:** Let $A_n \in \boldsymbol{\Sigma}^0_{\alpha_
n}$ for $n \in \mathbb{N}$. Each $A_n = \bigcup_m B_{n,m}$ with $B_{n,m} \in \bo
ldsymbol{\Pi}^0_{\beta_{n,m}}$, $\beta_{n,m} < \alpha_n$. Set $\alpha = \sup_n \
alpha_n$. Since $\{\alpha_n\}$ is a countable set of countable ordinals, $\alpha

hen
$$\bigcup_n A_n = \bigcup_{n,m} B_{n,m},$$
a countable union of sets from $\bigcup_{\beta < \alpha} \boldsymbol{\Pi}^0_\bet
a$, hence $\bigcup_n A_n \in \boldsymbol{\Sigma}^0_{\alpha+1} \subseteq \mathcal
{S}$. ✓

Thus $\mathcal{S}$ is a $\sigma$-algebra containing all open sets, so $\mathcal{
B}(X) \subseteq \mathcal{S}$.

Combining both inclusions: $\mathcal{B}(X) = \mathcal{S} = \bigcup_{\alpha < \om
ega_1} \boldsymbol{\Sigma}^0_\alpha$.

### Why this is a "countable sequence" for each Borel set

Every Borel set $B$ belongs to $\boldsymbol{\Sigma}^0_\alpha$ for some countable
 ordinal $\alpha < \omega_1$. Membership in $\boldsymbol{\Sigma}^0_\alpha$ means
 $B$ is obtained from open sets by a transfinite construction of length $\alpha$
: at each successor stage one applies a countable union or a complementation, an
d at limit stages one takes countable unions of previously constructed sets. Sin
ce $\alpha$ is a **countable** ordinal, this construction involves only countabl
y many operations in total. Equivalently, $B$ admits a **Borel code**: a countab
le well-founded tree whose leaves are labeled by open sets and whose internal no
des are labeled by "countable union" or "complement," and $B$ is recovered by ev
aluating this tree bottom-up.

### Remark on strictness

For uncountable Polish spaces, the hierarchy is **strict** at every countable le
vel: $\boldsymbol{\Sigma}^0_\alpha \subsetneq \boldsymbol{\Sigma}^0_{\alpha+1}$
for all $\alpha < \omega_1$. Thus one cannot stop at any fixed countable ordinal
 — the full $\omega_1$-sequence of levels is needed to capture *all* Borel sets
simultaneously. But each *individual* Borel set is reached at some countable sta
ge, by a countable sequence of operations.

### Conclusion

Every Borel set can be constructed through a countable sequence of (countable) u
nions, intersections, and complementations, starting from open sets, where "coun
table sequence" is indexed by a countable ordinal. $\blacksquare$
