## Proof

Let $\overline{abcd} = 1000a + 100b + 10c + d$, with $a \in \{1,\dots,9\}$ and $
b,c,d \in \{0,\dots,9\}$.

**Constraint 1:** $1000a + 100b + 10c + d = 16(a^2+b^2+c^2+d^2) + (a+b)$.

**Constraint 2:** $b^2 - a^2 = 2(c^2 + d^2)$.

Let $S = c^2 + d^2$. From Constraint 2, $S = \tfrac{1}{2}(b^2 - a^2)$, which for
ces $b \geq a$ and $b \equiv a \pmod 2$.

Substituting $16S = 8(b^2-a^2)$ into Constraint 1:

$$1000a + 100b + 10c + d = 16a^2 + 16b^2 + 8b^2 - 8a^2 + a + b = 8a^2 + 24b^2 +
a + b.$$

Rearranging:

$$999a + 99b + 10c + d = 8a^2 + 24b^2. \tag{*}$$

**Bounding $a$.** The left side is at least $999a$, while the right side is at m
ost $8\cdot81 + 24\cdot81 = 2592$. Hence $999a \leq 2592$, so $a \leq 2$. Thus $
a \in \{1, 2\}$.

**Case $a = 2$.** From $(*)$: $1998 + 99b + 10c + d = 32 + 24b^2$, i.e. $24b^2 -
 99b - 1966 = 10c + d$. For this to be $\geq 0$ requires $b \geq \lceil(99+\sqrt
{198537})/48\rceil \approx 12$, impossible since $b \leq 9$. No solution.

**Case $a = 1$.** From $(*)$: $999 + 99b + 10c + d = 8 + 24b^2$, i.e.

$$24b^2 - 99b - 991 = 10c + d, \quad 0 \leq 10c+d \leq 99.$$

Solving $24b^2 - 99b - 991 \geq 0$ gives $b \geq 9$; solving $24b^2 - 99b - 991
\leq 99$ gives $b \leq 9$. Hence $b = 9$.

Then $10c + d = 24\cdot81 - 99\cdot9 - 991 = 1944 - 891 - 991 = 62$, so $c = 6,\
 d = 2$.

**Verification.** The candidate is $\overline{abcd} = 1962$.

- Constraint 2: $b^2 - a^2 = 81 - 1 = 80 = 2(36+4) = 2(c^2+d^2)$. ✓
- Constraint 1: $16(1+81+36+4) + (1+9) = 16\cdot122 + 10 = 1952 + 10 = 1962$. ✓

Both constraints are satisfied, and the case analysis shows this is the unique s
olution.

$$\boxed{\overline{abcd} = 1962}$$
