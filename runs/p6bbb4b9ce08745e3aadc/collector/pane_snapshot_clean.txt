**Problem.** Determine whether there exists a topology on the interval $[0,1]$ t
hat makes it pseudocompact but not compact.

**Answer: Yes.** Such a topology exists.

---

## Proof

Recall:
- A space $X$ is **pseudocompact** if every continuous function $f:X\to\mathbb{R
}$ is bounded.
- A space $X$ is **compact** if every open cover admits a finite subcover.

Neither definition requires any separation axiom.

### Construction

Equip the set $[0,1]$ with the **particular point topology** at $p=0$:
$$\tau \;=\;\{\,U\subseteq[0,1] : 0\in U\,\}\;\cup\;\{\varnothing\}.$$
That is, a set is open iff it is empty or contains the point $0$. One readily ch
ecks this is a topology: $\varnothing$ and $[0,1]$ are open; arbitrary unions of
 sets containing $0$ contain $0$; finite intersections of sets containing $0$ co
ntain $0$.

### Claim 1: $([0,1],\tau)$ is pseudocompact

Let $f:[0,1]\to\mathbb{R}$ be continuous. We show $f$ is constant (hence bounded
).

Suppose for contradiction that $f$ is not constant. Then there exists $x\in[0,1]
$ with $f(x)\neq f(0)$. Choose disjoint open intervals $V,W\subseteq\mathbb{R}$
with $f(x)\in V$ and $f(0)\in W$.

By continuity, $f^{-1}(V)$ is open in $([0,1],\tau)$. Since $x\in f^{-1}(V)$, th
is preimage is **nonempty**. But $f(0)\in W$ and $V\cap W=\varnothing$, so $f(0)
\notin V$, hence $0\notin f^{-1}(V)$.

This is a contradiction: every nonempty open set in $\tau$ must contain $0$, yet
 $f^{-1}(V)$ is nonempty and does not contain $0$.

Therefore $f$ is constant, hence bounded. Since every continuous real-valued fun
ction is bounded, $([0,1],\tau)$ is pseudocompact. $\checkmark$

### Claim 2: $([0,1],\tau)$ is not compact

Consider the family
$$\mathcal{U} \;=\;\bigl\{\,\{0,x\} : x\in[0,1],\; x\neq 0\,\bigr\}.$$

Each $\{0,x\}$ contains $0$, so each is open in $\tau$. The family $\mathcal{U}$
 covers $[0,1]$: the point $0$ belongs to every member, and each $x\neq 0$ belon
gs to $\{0,x\}$. Thus $\mathcal{U}$ is an open cover.

Suppose $\mathcal{U}'\subseteq\mathcal{U}$ is a finite subcover, say $\mathcal{U
}'=\bigl\{\{0,x_1\},\dots,\{0,x_n\}\bigr\}$. Then
$$\bigcup\mathcal{U}' \;=\; \{0,x_1,\dots,x_n\},$$
which is a finite set. Since $[0,1]$ is uncountable, $\bigcup\mathcal{U}'\neq[0,
1]$. Hence no finite subcover exists.

Therefore $([0,1],\tau)$ is not compact. $\checkmark$

### Conclusion

The particular point topology on $[0,1]$ at $0$ makes $[0,1]$ pseudocompact (eve
ry continuous real-valued function is constant) but not compact (the open cover
$\{\{0,x\}:x\neq 0\}$ has no finite subcover). Hence such a topology exists. $\b
lacksquare$
