## Proof

**Setup.** Label the rays 0, 1, …, N−1. A rotation by angle 2πk/N maps the point
 on circle *i* at ray *a* to ray *a*+*k* (mod N). Let R_i ⊆ Z_N be the set of re
d ray-indices on circle *i*. The condition becomes:

> For every (a₁, …, a₂₀₂₁) ∈ Z_N²⁰²¹, there exists *k* such that a_i + k ∈ R_i f
or all *i*.

**Reformulation.** Set b = a₁ + k and d_i = a_i − a₁. As (a₁, …, a₂₀₂₁) ranges o
ver all choices, (d₂, …, d₂₀₂₁) ranges over all of Z_N²⁰²⁰. The condition is equ
ivalent to:

> **(★)** For every (d₂, …, d₂₀₂₁) ∈ Z_N²⁰²⁰, there exists b ∈ R₁ such that b +
d_i ∈ R_i for all i = 2, …, 2021.

This means ⋃_{b ∈ R₁} ∏_{i=2}^{2021}(R_i − b) = Z_N²⁰²⁰.

### Lower Bound

Each set ∏_{i=2}^{2021}(R_i − b) has size ∏_{i=2}^{2021}|R_i|. The union over b
∈ R₁ has at most |R₁| · ∏_{i=2}^{2021}|R_i| = ∏_{i=1}^{2021}|R_i| elements. Sinc
e it must cover Z_N²⁰²⁰ (size N²⁰²⁰):

$$\prod_{i=1}^{2021}|R_i| \geq N^{2020}.$$

By AM-GM:

$$\sum_{i=1}^{2021}|R_i| \geq 2021\left(\prod_{i=1}^{2021}|R_i|\right)^{1/2021}
\geq 2021 \cdot N^{2020/2021} = 2021 \cdot (n^{2021})^{2020/2021} = 2021\,n^{202
0}.$$

### Upper Bound (Construction)

Write each x ∈ Z_N in base *n* with 2021 digits: x = (x₀, x₁, …, x₂₀₂₀), where x
_j ∈ {0,…,n−1}.

Define **R_i = {x ∈ Z_N : x_{i−1} = 0}** (the (i−1)-th base-*n* digit is 0).

Then |R_i| = n²⁰²⁰ for each *i*, so ∑|R_i| = 2021·n²⁰²⁰.

**Verification of (★).** Given any (d₂, …, d₂₀₂₁) ∈ Z_N²⁰²⁰, we construct b = (b
₀, b₁, …, b₂₀₂₀) with b₀ = 0 (so b ∈ R₁) such that digit (i−1) of (b + d_i) is 0
 for each i = 2, …, 2021.

We determine b sequentially. The key observation is that digit *j* of the sum b
+ d_i depends only on b₀, …, b_j and d_{i,0}, …, d_{i,j} (via carries from lower
 digits). The constraint for circle *j*+1 involves digits 0 through *j* of *b*,
and digits 0 through *j*−1 are already fixed when we choose b_j. This gives a **
triangular system**:

- **b₀ = 0** (required for b ∈ R₁).
- **For j = 1, 2, …, 2020** (corresponding to circle j+1):
  - Compute the carry c_j into digit *j* for the sum b + d_{j+1}. This carry is
determined by b₀, …, b_{j−1} (already chosen) and d_{j+1,0}, …, d_{j+1,j−1} via:
    c₀ = 0,  c_{m+1} = ⌊(b_m + d_{j+1,m} + c_m)/n⌋ for m = 0, …, j−1.
  - Set **b_j = (−d_{j+1, j} − c_j) mod n**. This ensures (b_j + d_{j+1,j} + c_j
) mod n = 0, so digit *j* of (b + d_{j+1}) equals 0. ✓

Since b_j ∈ {0, …, n−1}, we have b ∈ Z_N with b₀ = 0, hence b ∈ R₁. By construct
ion, b + d_i ∈ R_i for all i = 2, …, 2021. ✓

**Why the triangular structure works:** The constraint for circle *i* (digit i−1
 of b + d_i = 0) determines b_{i−1} uniquely, given b₀, …, b_{i−2}. This b_{i−1}
 then feeds into carry computations for later circles, but those later constrain
ts have their own free variable (b_i, b_{i+1}, …) to satisfy. No constraint is o
ver-determined — each b_j is pinned by exactly one equation, and the carry propa
gation is deterministic. The process never gets stuck because at each step, the
equation (b_j + d_{j+1,j} + c_j) ≡ 0 (mod n) always has a unique solution in {0,
 …, n−1}.
