## Proof

Let $(S_n)$ be a simple symmetric random walk on $\mathbb{Z}$, so $S_0 = 0$ and
$S_{n+1} = S_n + X_{n+1}$ where $X_{n+1} \in \{+1, -1\}$ each with probability $
\tfrac{1}{2}$, independent of $\mathcal{F}_n$.

**Key moments of $X_{n+1}$:** $\mathbb{E}[X_{n+1}] = 0$, $\mathbb{E}[X_{n+1}^2]
= 1$, $\mathbb{E}[X_{n+1}^3] = 0$.

**Compute $\mathbb{E}[S_{n+1}^3 \mid \mathcal{F}_n]$:**

$$S_{n+1}^3 = (S_n + X_{n+1})^3 = S_n^3 + 3S_n^2 X_{n+1} + 3S_n X_{n+1}^2 + X_{n
+1}^3.$$

Taking conditional expectation and using independence of $X_{n+1}$ from $\mathca
l{F}_n$:

$$\mathbb{E}[S_{n+1}^3 \mid \mathcal{F}_n] = S_n^3 + 3S_n^2 \cdot 0 + 3S_n \cdot
 1 + 0 = S_n^3 + 3S_n.$$

**Compute $\mathbb{E}[\alpha_{n+1} S_{n+1} \mid \mathcal{F}_n]$:**

Since $\alpha_{n+1}$ is deterministic (a real number, hence $\mathcal{F}_n$-meas
urable):

$$\mathbb{E}[\alpha_{n+1} S_{n+1} \mid \mathcal{F}_n] = \alpha_{n+1}\,\mathbb{E}
[S_n + X_{n+1} \mid \mathcal{F}_n] = \alpha_{n+1} S_n.$$

**Martingale condition $\mathbb{E}[Y_{n+1} \mid \mathcal{F}_n] = Y_n$:**

$$\mathbb{E}[Y_{n+1} \mid \mathcal{F}_n] = S_n^3 + 3S_n + \alpha_{n+1} S_n = S_n
^3 + (3 + \alpha_{n+1})S_n.$$

This must equal $Y_n = S_n^3 + \alpha_n S_n$, giving the recurrence:

$$\alpha_n = 3 + \alpha_{n+1}, \qquad \text{i.e.,} \qquad \alpha_{n+1} = \alpha_
n - 3.$$

**Solving the recurrence:** $\alpha_n = \alpha_0 - 3n$. Choosing $\alpha_0 = 0$
(any constant works; the choice only shifts $Y_n$ by a constant multiple of the
martingale $S_n$):

$$\boxed{\alpha_n = -3n.}$$

**Verification:** With $\alpha_n = -3n$,

$$Y_n = S_n^3 - 3n\,S_n.$$

Check the martingale property directly:

$$\mathbb{E}[Y_{n+1} \mid \mathcal{F}_n] = S_n^3 + 3S_n - 3(n+1)S_n = S_n^3 + (3
 - 3n - 3)S_n = S_n^3 - 3n\,S_n = Y_n. \checkmark$$

Also $Y_n$ is integrable (it is a polynomial in the bounded-increment walk) and
$\mathcal{F}_n$-measurable, so $(Y_n)$ is a martingale.
