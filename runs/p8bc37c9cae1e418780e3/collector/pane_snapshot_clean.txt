**Classification of the 14 regions.** Since $(a - a_P) + (b - b_P) + (c - c_P) +
 (d - d_P) = 0$, the four differences cannot all share the same sign. Each regio
n is determined by which differences are positive/negative:

- **3 positive, 1 negative** (4 regions): e.g., $a > a_P, b > b_P, c > c_P, d <
d_P$. This region is a **tetrahedron** with one vertex at $P$ and a triangular f

- **1 positive, 3 negative** (4 regions): e.g., $a > a_P, b < b_P, c < c_P, d <
d_P$. In $(b,c,d)$-coordinates this is the box $[0, b_P] \times [0, c_P] \times

is a **parallelepiped**.
- **2 positive, 2 negative** (6 regions): the remaining regions — neither tetrah

Total: $4 + 4 + 6 = 14$. ✓

By symmetry, the four parallelepipeds have volumes $6bcd, 6acd, 6abd, 6abc$.

$$f(P) = 1 - (a^3+b^3+c^3+d^3) - 6(abc+abd+acd+bcd).$$

$$f(P) = 3\sum_{i \neq j} a_i^2 a_j = 3\sum_{i=1}^{4} a_i^2(1 - a_i).$$
