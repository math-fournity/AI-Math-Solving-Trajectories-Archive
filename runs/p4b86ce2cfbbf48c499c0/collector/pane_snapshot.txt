Looking at this problem, I need to find the largest $n$ such that pairwise diffe
rent sets $S_1, \ldots, S_n$ satisfy the two union conditions on $\{1, \ldots, 2
008\}$.

## Proof

Let $U = \{1, 2, \ldots, 2008\}$ and define $T_i = U \setminus S_i$ for each $i$
. The conditions translate to:

- **Condition 1**: $|S_i \cup S_j| \leq 2004 \iff |T_i \cap T_j| \geq 4$ for all
 $i \neq j$.
- **Condition 2**: $S_i \cup S_j \cup S_k = U \iff T_i \cap T_j \cap T_k = \empt
yset$ for all distinct $i, j, k$.
- The $T_i$ are pairwise different (since the $S_i$ are).

### Upper bound: $n \leq 32$

For each element $x \in U$, let $A_x = \{i : x \in T_i\}$. The triple-intersecti
on condition $T_i \cap T_j \cap T_k = \emptyset$ means no element belongs to thr
ee or more $T_i$'s, so $|A_x| \leq 2$ for every $x$.

For each pair $\{i,j\}$, let $c_{ij} = |\{x : A_x = \{i,j\}\}|$, the number of e
lements belonging to exactly $T_i$ and $T_j$. Since $|A_x| \leq 2$, any element
in $T_i \cap T_j$ must satisfy $A_x = \{i,j\}$, so $|T_i \cap T_j| = c_{ij} \geq
 4$.

Each element $x$ with $|A_x| = 2$ contributes to exactly one pair, while element
s with $|A_x| \leq 1$ contribute to none. Therefore:

$$\sum_{1 \leq i < j \leq n} c_{ij} \leq 2008$$

Combined with $c_{ij} \geq 4$:

$$4\binom{n}{2} \leq 2008 \implies 2n(n-1) \leq 2008 \implies n(n-1) \leq 1004$$

Checking: $32 \times 31 = 992 \leq 1004$ ✓, but $33 \times 32 = 1056 > 1004$ ✗.
Hence $n \leq 32$.

### Construction: $n = 32$ is achievable

Take $n = 32$. There are $\binom{32}{2} = 496$ pairs. Assign to each pair $\{i,j
\}$ a distinct block of 4 elements from $U$, using $4 \times 496 = 1984$ element
s. Define:

$$T_i = \bigcup_{j \neq i} \{\text{4 elements assigned to pair } \{i,j\}\}$$

The remaining $2008 - 1984 = 24$ elements belong to no $T_i$. Set $S_i = U \setm
inus T_i$.

**Verification:**
- $|T_i \cap T_j| = 4$ (exactly the block assigned to $\{i,j\}$) $\geq 4$ ✓, so
$|S_i \cup S_j| = 2008 - 4 = 2004 \leq 2004$ ✓.
- Each element is in at most 2 of the $T_i$'s, so $T_i \cap T_j \cap T_k = \empt
yset$ ✓, giving $S_i \cup S_j \cup S_k = U$ ✓.
- For $i \neq j$, the set $T_i \setminus T_j$ contains the 4 elements of pair $\
{i, k\}$ for any $k \neq i, j$ (such $k$ exists since $n = 32 \geq 3$), so $T_i
\neq T_j$, hence $S_i \neq S_j$ ✓.

All conditions are satisfied with $n = 32$.

### Conclusion

The largest positive integer $n$ is $\boxed{32}$.
