IMO 2020 Problem 4 — Solution

Answer: The smallest such $k$ is $\boxed{n^2 - n + 1}$.

────────────────────────────────────────────────────────────────────────────────

Setup and key reformulation

Order the $n^2$ stations by altitude: $1 < 2 < \cdots < n^2$.

Company structure. Company $A$ operates $k$ cable cars with distinct starting
points and distinct finishing points, and the matching is order-preserving (a
car starting higher finishes higher). Since every station is the start of at
most one car and the finish of at most one car, $A$'s directed graph has in-
degree $\le 1$ and out-degree $\le 1$ at every vertex. Therefore $A$'s graph is
a disjoint union of directed paths (plus isolated vertices). The same holds for
$B$.

Linked = same path. Since every edge goes from a lower station to a higher one,
each path is totally ordered by altitude. Two distinct stations $x < y$ are
linked by $A$ if and only if they belong to the same $A$-path (the lower one can
walk up the path to the higher one). Thus:

│ $x$ and $y$ are linked by both companies $\iff$ $x$ and $y$ lie in the same
│ $A$-path and the same $B$-path.

────────────────────────────────────────────────────────────────────────────────

Lower bound: $k = n^2 - n$ does not suffice

Construction. Place the stations on an $n \times n$ grid $(i,j)$, $1 \le i,j \le
n$, with altitude order row-major: $(i,j) < (i',j')$ iff $i < i'$, or $i = i'$
and $j < j'$.

  • Company $A$ — rows. For each row $i$, connect $(i,1) \to (i,2) \to \cdots
  \to (i,n)$. This gives $n(n-1) = n^2 - n$ edges. The $A$-paths are exactly the
  $n$ rows.
  • Company $B$ — columns. For each column $j$, connect $(1,j) \to (2,j) \to
  \cdots \to (n,j)$. This gives $n^2 - n$ edges. The $B$-paths are exactly the
  $n$ columns.

Order-preserving check. For $A$: edges are $(i,j)\to(i,j{+}1)$; sorted by start,
both the start sequence and finish sequence are increasing (row-major), and each
finish is one step above its start. For $B$: edges are $(i,j)\to(i{+}1,j)$; the
$r$-th edge in start-order has start rank $r$ and finish rank $r + n$, so both
sequences are increasing. Both matchings are order-preserving. ✓

No common linked pair. Row $i$ (an $A$-path) and column $j$ (a $B$-path)
intersect in the single station $(i,j)$. Hence no two distinct stations share
both an $A$-path and a $B$-path. So $k = n^2 - n$ does not guarantee a common
linked pair.

────────────────────────────────────────────────────────────────────────────────

Upper bound: $k = n^2 - n + 1$ suffices

Suppose for contradiction that $A$ and $B$ each have $k = n^2 - n + 1$ edges and
no two stations are linked by both.

Let:

  • $a$ = number of non-trivial $A$-paths (paths with $\ge 1$ edge), with vertex
  counts $\alpha_1, \ldots, \alpha_a$ (each $\ge 2$).
  • $b$ = number of non-trivial $B$-paths, with vertex counts $\beta_1, \ldots,
  \beta_b$ (each $\ge 2$).

Counting edges. Since each non-trivial $A$-path of size $\alpha_i$ contributes $
\alpha_i - 1$ edges: $$k = \sum_{i=1}^{a}(\alpha_i - 1) = \Big(\sum
\alpha_i\Big) - a.$$ Let $S_A = \bigcup \text{(non-trivial } A\text{-paths)}$,
so $|S_A| = k + a$. The number of isolated $A$-stations is $$n^2 - |S_A| = n^2 -
k - a = n^2 - (n^2 - n + 1) - a = (n - 1) - a \ge 0,$$ so $\boxed{a \le n - 1}$.
Similarly $\boxed{b \le n - 1}$.

Grid constraint. "No common linked pair" means every non-trivial $A$-path and
every non-trivial $B$-path share at most one station. Therefore $$|S_A \cap S_B|
\le a \cdot b.$$

Inclusion–exclusion lower bound. On the other hand, $$|S_A \cap S_B| \ge |S_A| +
|S_B| - n^2 = (k+a)+(k+b)-n^2 = 2k + a + b - n^2.$$

Combining: $$2k + a + b - n^2 \le ab \implies 2k \le n^2 - a - b + ab = n^2 +
(a-1)(b-1) - 1.$$

Substituting $k = n^2 - n + 1$: $$2(n^2 - n + 1) \le n^2 + (a-1)(b-1) - 1
\implies (a-1)(b-1) \ge n^2 - 2n + 3.$$

But $a \le n-1$ and $b \le n-1$ with $a,b \ge 1$ (since $k > 0$), so $$(a-1)
(b-1) \le (n-2)^2 = n^2 - 4n + 4.$$

Thus we need $$n^2 - 2n + 3 \le n^2 - 4n + 4 \implies 2n \le 1,$$ which is
impossible for $n > 1$. Contradiction.

Therefore, when $k = n^2 - n + 1$, every pair of valid configurations $A, B$
must have two stations linked by both companies.

────────────────────────────────────────────────────────────────────────────────

Conclusion

  • $k = n^2 - n$ fails (grid construction: rows vs. columns).
  • $k = n^2 - n + 1$ always works (counting argument with the isolated-vertex
  constraint $a, b \le n-1$).

The smallest positive integer $k$ that guarantees two stations linked by both
companies is

$$\boxed{k = n^2 - n + 1}.$$
