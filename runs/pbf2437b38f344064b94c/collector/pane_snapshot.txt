in Oakland. After each SF game, a 3-game lead ends the series (lead rule, checke

**Achievable states.** Tracking the lead *before* each game:
- Before an SF game: $d \in \{-2, 0, 2\}$ (even).
- Before an Oakland game: $d \in \{-1, 1\}$ (odd).

After an SF game the lead is odd (and nonzero), so an earthquake always finds a
clear leader — no ties arise.

Define $P_S(d)$ = P(Gammas win | lead $d$, next game in SF), and $P_O(d)$ = P(Ga

$$p = \tfrac25\bigl(\tfrac34 + \tfrac14 p\bigr) + \tfrac35 b = \tfrac{3}{10} + \

$$b = \tfrac14 + \tfrac14\Bigl(\tfrac13 + \tfrac23 b\Bigr) + \tfrac14\Bigl(\tfra

$$\tfrac{73}{102}b = \tfrac13 \;\Longrightarrow\; b = \frac{102}{3\cdot 73} = \f

is $b = \dfrac{34}{73}$, which is irreducible ($73$ is prime).

$$a + b = 34 + 73 = \boxed{107}.$$
