## Proof

Let $u = y_1$, $v = y_2$, and set $w = \sqrt{uv}$. We compute $w''$ and relate i
t to the desired equation.

**Wronskian.** Since $u'' = fu$ and $v'' = fv$, the Wronskian $W = u'v - uv'$ sa
tisfies
$$W' = u''v + u'v' - u'v' - uv'' = f\cdot uv - uv\cdot f = 0,$$
so $W$ is a constant. Linear independence of $u, v$ gives $W \neq 0$.

**Computing $w''$.** With $w = (uv)^{1/2}$:
$$w' = \tfrac{1}{2}(uv)^{-1/2}(u'v + uv'),$$
$$w'' = -\tfrac{1}{4}(uv)^{-3/2}(u'v+uv')^2 + \tfrac{1}{2}(uv)^{-1/2}(u''v + 2u'
v' + uv'').$$

Using $u''v + uv'' = f\cdot uv + f\cdot uv = 2f\cdot uv$:
$$w'' = -\tfrac{1}{4}(uv)^{-3/2}(u'v+uv')^2 + f(uv)^{1/2} + (uv)^{-1/2}u'v'.$$

Since $w^2 = uv$, i.e. $(uv)^{-3/2} = w^{-3}$ and $(uv)^{-1/2} = w^{-1}$:
$$w'' = fw - \frac{(u'v+uv')^2}{4w^3} + \frac{u'v'}{w} = fw + \frac{-\tfrac{1}{4
}(u'v+uv')^2 + u'v'\cdot uv}{w^3}.$$

Expanding the numerator:
$$-\tfrac{1}{4}(u'v+uv')^2 + u'v'\cdot uv = -\tfrac{1}{4}\big[(u'v)^2 + 2u'v'\cd
ot uv + (uv')^2\big] + u'v'\cdot uv$$
$$= -\tfrac{1}{4}\big[(u'v)^2 - 2u'v'\cdot uv + (uv')^2\big] = -\tfrac{1}{4}(u'v
 - uv')^2 = -\frac{W^2}{4}.$$

Therefore
$$w'' = fw - \frac{W^2}{4w^3}, \qquad\text{i.e.,}\quad w'' + \frac{W^2}{4w^3} =
fw.$$

**Choosing $c$.** Set $z = cw$ with $c > 0$. Then $z'' = cw''$ and $1/z^3 = 1/(c
^3 w^3)$, so
$$z'' + \frac{1}{z^3} = c\!\left(fw - \frac{W^2}{4w^3}\right) + \frac{1}{c^3 w^3
} = fz + \frac{1}{w^3}\!\left(\frac{1}{c^3} - \frac{cW^2}{4}\right).$$

For this to equal $fz$, we require $\dfrac{1}{c^3} = \dfrac{cW^2}{4}$, i.e. $c^4
 W^2 = 4$. Since $W \neq 0$ is constant, we take
$$c = \frac{\sqrt{2}}{|W|} > 0,$$
which satisfies $c^4 W^2 = \frac{4}{W^2}\cdot W^2 = 4$. With this choice,
$$z'' + \frac{1}{z^3} = f(x)\,z \quad\text{on } I. \qquad\blacksquare$$
