## Proof

We determine the cardinality of
$$A = \{f \in C^1[0,1] : f(0)=0,\ f(1)=1,\ |f'(t)| \le 1\ \forall\, t \in [0,1]\
}.$$

**Step 1: A candidate.** The function $f(t) = t$ belongs to $A$: it is $C^1$, sa
tisfies $f(0)=0$, $f(1)=1$, and $f'(t)=1$, so $|f'(t)|=1\le 1$. Hence $A\neq\var
nothing$.

**Step 2: Uniqueness.** Let $f\in A$. Since $f\in C^1[0,1]$, the Fundamental The
orem of Calculus gives
$$f(1)-f(0) = \int_0^1 f'(t)\,dt.$$
Using the boundary conditions $f(0)=0$ and $f(1)=1$,
$$\int_0^1 f'(t)\,dt = 1. \tag{1}$$

The constraint $|f'(t)|\le 1$ implies $f'(t)\le 1$ for all $t\in[0,1]$. Define
$$g(t) := 1 - f'(t).$$
Then $g$ is continuous on $[0,1]$ (since $f'$ is continuous) and $g(t)\ge 0$ for
 all $t\in[0,1]$. Moreover, using (1),
$$\int_0^1 g(t)\,dt = \int_0^1 \bigl(1 - f'(t)\bigr)\,dt = 1 - \int_0^1 f'(t)\,d
t = 1 - 1 = 0. \tag{2}$$

A continuous, nonneg function on $[0,1]$ with zero integral must vanish identica
lly: if $g(t_0)>0$ at some point $t_0$, by continuity $g>0$ on a neighborhood of
 $t_0$, giving a strictly positive integral, contradicting (2). Therefore
$$g(t) = 0 \quad\forall\, t\in[0,1],$$
i.e., $f'(t) = 1$ for all $t\in[0,1]$.

Integrating, $f(t) = t + c$ for some constant $c$. The condition $f(0)=0$ forces
 $c=0$, so
$$f(t) = t.$$

**Step 3: Conclusion.** Every element of $A$ equals the function $t\mapsto t$, a
nd this function does lie in $A$. Hence $A = \{\,t\mapsto t\,\}$, a singleton. T
herefore
$$|A| = 1.$$
