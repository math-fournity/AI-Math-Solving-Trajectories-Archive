### Fourier expansion

For $x\in(0,\pi)$,
$$\log(\sin x) = -\log 2 - \sum_{n=1}^{\infty}\frac{\cos(2nx)}{n}.$$

So for any $k$,
$$\int_0^\pi x^k\log(\sin x)\,dx = -\log 2\int_0^\pi x^k\,dx - \sum_{n=1}^{\inft
y}\frac{1}{n}\int_0^\pi x^k\cos(2nx)\,dx. \tag{1}$$

### Auxiliary integrals $\int_0^\pi x^k\cos(2nx)\,dx$

**Case $k=2$.** Integrating by parts twice (boundary terms vanish since $\sin(2n
\pi)=\sin 0=0$):
$$\int_0^\pi x^2\cos(2nx)\,dx = -\frac{1}{n}\int_0^\pi x\sin(2nx)\,dx = -\frac{1
}{n}\!\left(-\frac{\pi}{2n}\right) = \frac{\pi}{2n^2}.$$

**Case $k=3$.** Similarly:
$$\int_0^\pi x^3\cos(2nx)\,dx = -\frac{3}{2n}\int_0^\pi x^2\sin(2nx)\,dx,$$
and
$$\int_0^\pi x^2\sin(2nx)\,dx = -\frac{\pi^2}{2n}+\frac{1}{n}\underbrace{\int_0^
\pi x\cos(2nx)\,dx}_{=\,0},$$
so
$$\int_0^\pi x^3\cos(2nx)\,dx = -\frac{3}{2n}\!\left(-\frac{\pi^2}{2n}\right)=\f
rac{3\pi^2}{4n^2}.$$

### Computing $A$

Using (1) with $k=3$ and $\int_0^\pi x^3\,dx=\pi^4/4$:
$$A = -\frac{\pi^4}{4}\log 2 - \sum_{n=1}^{\infty}\frac{1}{n}\cdot\frac{3\pi^2}{
4n^2} = -\frac{\pi^4}{4}\log 2 - \frac{3\pi^2}{4}\zeta(3) = -\frac{\pi^2}{4}\big
l(\pi^2\log 2 + 3\zeta(3)\bigr). \tag{2}$$

### Computing $B$

Since $\log(\sqrt{2}\sin x)=\tfrac12\log 2+\log(\sin x)$,
$$B = \frac{\log 2}{2}\int_0^\pi x^2\,dx + \int_0^\pi x^2\log(\sin x)\,dx = \fra
c{\pi^3}{6}\log 2 + \int_0^\pi x^2\log(\sin x)\,dx.$$

Using (1) with $k=2$ and $\int_0^\pi x^2\,dx=\pi^3/3$:
$$\int_0^\pi x^2\log(\sin x)\,dx = -\frac{\pi^3}{3}\log 2 - \sum_{n=1}^{\infty}\
frac{1}{n}\cdot\frac{\pi}{2n^2} = -\frac{\pi^3}{3}\log 2 - \frac{\pi}{2}\zeta(3)
.$$

Therefore
$$B = \frac{\pi^3}{6}\log 2 - \frac{\pi^3}{3}\log 2 - \frac{\pi}{2}\zeta(3) = -\
frac{\pi^3}{6}\log 2 - \frac{\pi}{2}\zeta(3) = -\frac{\pi}{6}\bigl(\pi^2\log 2 +
 3\zeta(3)\bigr). \tag{3}$$

### The ratio

From (2) and (3), the common factor $\bigl(\pi^2\log 2 + 3\zeta(3)\bigr)$ cancel
s:

$$\frac{A}{B} = \frac{-\dfrac{\pi^2}{4}\bigl(\pi^2\log 2 + 3\zeta(3)\bigr)}{-\df
rac{\pi}{6}\bigl(\pi^2\log 2 + 3\zeta(3)\bigr)} = \frac{\pi^2/4}{\pi/6} = \frac{
\pi^2\cdot 6}{4\pi} = \frac{3\pi}{2}.$$
