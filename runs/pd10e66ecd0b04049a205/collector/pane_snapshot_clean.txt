$$g(z) = f(z) - e^z \sin(2z).$$

**Apply Liouville's Theorem.** An entire function bounded on all of $\mathbb{C}$
 is constant. Since $|g(z)| < 4$ everywhere, $g$ is bounded, hence
$$g(z) = c$$
for some constant $c \in \mathbb{C}$ with $|c| < 4$.

$$f(z) = e^z \sin(2z) + c.$$

$$f(0) = e^0 \sin(0) + c = 0 + c = c.$$
