## Solution

**Answer-leak check:** The problem statement contains no solutions, sketches, or
 leaked answers. Proceeding.

**Setup.** We evaluate $\displaystyle I = \oint_C \frac{dz}{\cos z - 1}$, where
$C$ is the circle of radius $7$ centered at the origin (standard convention when
 no center is specified), traversed counterclockwise.

**Singularities.** The integrand $f(z) = \frac{1}{\cos z - 1}$ is singular where
 $\cos z = 1$, i.e. at
$$z = 2\pi k, \qquad k \in \mathbb{Z}.$$

Since $2\pi \approx 6.283 < 7 < 4\pi \approx 12.566$, the singularities inside $
|z| = 7$ are exactly
$$z = 0,\quad z = 2\pi,\quad z = -2\pi.$$

**Nature of the singularities.** Near any singularity $z_0 = 2\pi k$, set $w = z
 - z_0$. Since $\cos(z_0 + w) = \cos w$,
$$\cos z - 1 = \cos w - 1 = -\frac{w^2}{2!} + \frac{w^4}{4!} - \frac{w^6}{6!} +
\cdots = -\frac{w^2}{2}\left(1 - \frac{w^2}{12} + \frac{w^4}{360} - \cdots\right
).$$

Hence each singularity is a **pole of order 2**, and
$$\frac{1}{\cos z - 1} = \frac{-2}{w^2}\left(1 - \frac{w^2}{12} + \cdots\right)^
{-1} = \frac{-2}{w^2}\left(1 + \frac{w^2}{12} + \cdots\right) = -\frac{2}{w^2} -
 \frac{1}{6} - \cdots.$$

The Laurent expansion contains only even powers of $w$; in particular the coeffi
cient of $w^{-1} = (z-z_0)^{-1}$ is **zero**. Therefore
$$\operatorname{Res}\!\left(\frac{1}{\cos z - 1},\, z_0\right) = 0 \quad \text{f
or every } z_0 = 2\pi k.$$

*Symmetry argument (alternative):* $\frac{1}{\cos z - 1}$ is an even function of
 $w = z - z_0$ about each pole, so its Laurent series has no odd-power terms, fo
rcing the residue to vanish.

**Applying the residue theorem.**
$$I = 2\pi i \sum_{z_0 \in \{0,\,2\pi,\,-2\pi\}} \operatorname{Res}(f, z_0) = 2\
pi i\,(0 + 0 + 0) = 0.$$

**Conclusion.**
$$\boxed{\displaystyle \oint_C \frac{dz}{\cos z - 1} = 0.}$$
