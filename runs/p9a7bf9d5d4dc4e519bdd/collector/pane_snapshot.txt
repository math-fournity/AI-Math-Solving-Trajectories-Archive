## Solution

Let $y = (y_1, y_2)^T$. The system reads

$$y_1' = y_2,\qquad y_2' = \lambda^2 y_1 + (1-\lambda^2)e^x,$$

so $y_1$ satisfies the scalar ODE

$$y_1'' - \lambda^2 y_1 = (1-\lambda^2)e^x.\tag{*}$$

The boundary conditions become (reading off the two rows):

$$y_1(0) = 0,\qquad y_1(b) = e^b.$$

### Particular solution

For $\lambda \neq 1$, try $y_1^p = \alpha e^x$. Substituting into $(*)$: $\alpha
(1-\lambda^2)e^x = (1-\lambda^2)e^x$, giving $\alpha = 1$.

For $\lambda = 1$, the RHS vanishes and $(*)$ is homogeneous; the formula below
will be seen to extend continuously to this case.

### General solution ($\lambda \neq 1$)

$$y_1(x) = C_1 e^{\lambda x} + C_2 e^{-\lambda x} + e^x.$$

Applying the boundary conditions:

- $y_1(0)=0:\ C_1 + C_2 = -1$,
- $y_1(b)=e^b:\ C_1 e^{\lambda b} + C_2 e^{-\lambda b} = 0$.

Solving: $C_2 = -C_1 e^{2\lambda b}$, hence $C_1(1-e^{2\lambda b})=-1$, giving

$$C_1 = \frac{1}{e^{2\lambda b}-1},\qquad C_2 = \frac{-e^{2\lambda b}}{e^{2\lamb
da b}-1}.$$

Thus

$$y_1(x) = \frac{e^{\lambda x} - e^{2\lambda b - \lambda x}}{e^{2\lambda b}-1} +
 e^x.$$

Rewriting in hyperbolic form using $e^{2\lambda b}-1 = 2e^{\lambda b}\sinh(\lamb
da b)$ and $e^{\lambda x}-e^{2\lambda b-\lambda x} = -2e^{\lambda b}\sinh(\lambd
a(b-x))$:

$$\boxed{y_1(x) = e^x - \frac{\sinh(\lambda(b-x))}{\sinh(\lambda b)}.}$$

Then $y_2 = y_1'$:

$$\boxed{y_2(x) = e^x + \frac{\lambda\cosh(\lambda(b-x))}{\sinh(\lambda b)}.}$$

### Verification

**Boundary conditions.** $y_1(0) = 1 - \sinh(\lambda b)/\sinh(\lambda b) = 0$. ✓
 $\ y_1(b) = e^b - 0 = e^b$. ✓

**ODE.** $y_2' = e^x - \lambda^2\sinh(\lambda(b-x))/\sinh(\lambda b)$, and

$$\lambda^2 y_1 + (1-\lambda^2)e^x = \lambda^2 e^x - \frac{\lambda^2\sinh(\lambd
a(b-x))}{\sinh(\lambda b)} + e^x - \lambda^2 e^x = e^x - \frac{\lambda^2\sinh(\l
ambda(b-x))}{\sinh(\lambda b)} = y_2'.\ \checkmark$$

### The case $\lambda = 1$

Here $(*)$ becomes $y_1'' - y_1 = 0$, so $y_1 = C_1 e^x + C_2 e^{-x}$. The bound
ary conditions give $C_1+C_2=0$ and $C_1 e^b + C_2 e^{-b} = e^b$, yielding $C_1
= e^b/(2\sinh b)$, $C_2 = -e^b/(2\sinh b)$, hence

$$y_1(x) = \frac{e^b\sinh x}{\sinh b},\qquad y_2(x) = \frac{e^b\cosh x}{\sinh b}
.$$

One checks directly that the $\lambda\neq 1$ formula reduces to this: since $e^x
\sinh b - \sinh(b-x) = e^b\sinh x$, we have $e^x - \sinh(b-x)/\sinh b = e^b\sinh
 x/\sinh b$. So the boxed formula is valid for **all** $\lambda > 0$, $b > 0$ (n
o singularity at $\lambda=1$).

### Final answer

For all $\lambda > 0$, $b > 0$,

$$\boxed{y(x) = \begin{pmatrix} e^x - \dfrac{\sinh(\lambda(b-x))}{\sinh(\lambda
b)} \\[6pt] e^x + \dfrac{\lambda\,\cosh(\lambda(b-x))}{\sinh(\lambda b)} \end{pm
atrix},\qquad x\in[0,b].}$$
