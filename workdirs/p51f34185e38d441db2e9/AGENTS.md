# Problem

A specialized logistics drone is tasked with moving a "Beacon" from the origin point (0) to a destination marker located at the unit distance (1). To assist in navigation, a "Reference Signal" is initially placed at the unit distance (1).

The drone operates using a propulsion constant $r$, where $r > 1$ is a rational number. In each maneuver, the operator selects an integer power $k$. The operator then designates one object (either the Beacon or the Signal) as the "Pivot" at position $x$ and the other object as the "Mobile" at position $y$. The Mobile object is then relocated to a new position $y'$ according to the calibration formula:
$y' = x + r^k(y - x)$

The mission is successful if the Beacon can be moved to the destination marker (1) in 2021 or fewer maneuvers.

Let $S$ be the set of all rational numbers $r > 1$ for which the mission can be successfully completed. Determine the number of elements in $S$.
