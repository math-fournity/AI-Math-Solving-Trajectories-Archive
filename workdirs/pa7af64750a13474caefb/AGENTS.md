# Problem

In the strategic logistics hub of Sector T, a massive triangular grid is constructed to manage data storage. This triangular mainframe has a side length of 111 units. Within this mainframe, smaller equilateral storage cells with a side length of 1 unit are partitioned by internal cooling channels that run parallel to the three outer boundaries of the sector.

Every intersection point of these cooling channels—including the points on the outer perimeter—is designated as a potential data node. However, the exact geometric center of the mainframe is deemed unstable and is the only intersection point that does not contain a marked node.

A group of nodes is defined as a "Linear Array" if all nodes in the set lie along a single straight cooling channel parallel to one of the three boundaries of Sector T. 

A logistics engineer is tasked with partitioning every single marked node in the mainframe into exactly 111 disjoint Linear Arrays. Each marked node must belong to exactly one of these arrays.

In how many distinct ways can the set of all marked nodes be partitioned into exactly 111 Linear Arrays?
