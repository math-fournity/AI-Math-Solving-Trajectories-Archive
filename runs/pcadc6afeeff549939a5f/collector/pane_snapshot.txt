## Proof

Let $f(x) = \dfrac{x^2 - x}{x^3 - 3x + 1} = \dfrac{x(x-1)}{x^3-3x+1}$.

**Step 1: Identify the transformations.**

The three integration intervals are related to $[-100,-10]$ by Möbius transforma
tions:

- $T_1(x) = x$ maps $[-100,-10] \to [-100,-10]$.
- $T_2(x) = \dfrac{1}{1-x}$: $T_2(-100) = \tfrac{1}{101}$, $T_2(-10) = \tfrac{1}
{11}$. ✓
- $T_3(x) = \dfrac{x-1}{x}$: $T_3(-100) = \tfrac{101}{100}$, $T_3(-10) = \tfrac{
11}{10}$. ✓

These form a cyclic group of order 3 (permuting $\{0,1,\infty\}$), with $T_2 \ci
rc T_2 = T_3$ and $T_2^3 = \mathrm{id}$.

**Step 2: Show $f$ is invariant under $T_2$.**

Compute $f(T_2(x))$ with $T_2(x) = \frac{1}{1-x}$:

$$T_2^2 - T_2 = \frac{1}{(1-x)^2} - \frac{1}{1-x} = \frac{x}{(1-x)^2}$$

$$T_2^3 - 3T_2 + 1 = \frac{1 - 3(1-x)^2 + (1-x)^3}{(1-x)^3} = \frac{-(x^3-3x+1)}
{(1-x)^3}$$

Therefore:
$$f(T_2(x)) = \frac{x/(1-x)^2}{-(x^3-3x+1)/(1-x)^3} = \frac{x(1-x)}{-(x^3-3x+1)}
 = \frac{x(x-1)}{x^3-3x+1} = f(x)$$

By the group property, $f(T_3(x)) = f(x)$ as well.

**Step 3: Combine the three integrals.**

Using $u = T_2(x)$ in the second integral ($T_2'(x) = \frac{1}{(1-x)^2}$) and $u
 = T_3(x)$ in the third ($T_3'(x) = \frac{1}{x^2}$):

$$S = \int_{-100}^{-10} f(x)^2\left(1 + \frac{1}{(1-x)^2} + \frac{1}{x^2}\right)
dx$$

**Step 4: Simplify the weight.**

$$1 + \frac{1}{x^2} + \frac{1}{(1-x)^2} = \frac{x^2(1-x)^2 + (1-x)^2 + x^2}{x^2(
1-x)^2} = \frac{(x^2-x+1)^2}{x^2(1-x)^2}$$

since $x^2(1-x)^2 + (1-x)^2 + x^2 = x^4 - 2x^3 + 3x^2 - 2x + 1 = (x^2-x+1)^2$.

Thus:
$$S = \int_{-100}^{-10} \frac{x^2(1-x)^2}{(x^3-3x+1)^2} \cdot \frac{(x^2-x+1)^2}
{x^2(1-x)^2}\,dx = \int_{-100}^{-10} \frac{(x^2-x+1)^2}{(x^3-3x+1)^2}\,dx$$

**Step 5: Find an antiderivative.**

We seek $P(x)$ such that $\dfrac{d}{dx}\dfrac{P(x)}{x^3-3x+1} = \dfrac{(x^2-x+1)
^2}{(x^3-3x+1)^2}$, i.e.,

$$P'(x)(x^3-3x+1) - P(x)(3x^2-3) = (x^2-x+1)^2$$

Trying $P(x) = ax^2+bx+c$ and matching coefficients with $(x^2-x+1)^2 = x^4-2x^3
+3x^2-2x+1$ yields $a=-1,\, b=1,\, c=0$, so $P(x) = -x^2+x$.

**Verification:**
$$\frac{d}{dx}\frac{-x^2+x}{x^3-3x+1} = \frac{(-2x+1)(x^3-3x+1)-(-x^2+x)(3x^2-3)
}{(x^3-3x+1)^2} = \frac{(x^2-x+1)^2}{(x^3-3x+1)^2}\;\checkmark$$

**Step 6: Evaluate.**

$$S = \left[\frac{-x^2+x}{x^3-3x+1}\right]_{-100}^{-10} = \frac{-110}{-969} - \f
rac{-10100}{-999699} = \frac{110}{969} - \frac{10100}{999699}$$

Both terms are rational numbers, so their difference is rational. $\blacksquare$
