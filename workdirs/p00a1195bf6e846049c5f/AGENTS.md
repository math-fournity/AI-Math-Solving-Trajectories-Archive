# Problem

A high-tech server farm consists of a square grid of 25 distinct processing modules, arranged in 5 rows and 5 columns. Each module is assigned a unique power consumption rating from the set of integers $\{1, 2, \ldots, 25\}$ watts, such that every value in the set is used exactly once across the grid.

A safety inspector is monitoring the heat density of the farm. They define a "cooling zone" as any $2 \times 2$ cluster of four adjacent modules within the grid. The inspector wants to determine the highest possible "guaranteed threshold" $k$. 

Regardless of how the 25 specific power ratings are distributed across the 25 modules, there must always exist at least one cooling zone where the total power consumption of its four modules is at least $k$ watts. Find the maximal value of this integer $k$.
