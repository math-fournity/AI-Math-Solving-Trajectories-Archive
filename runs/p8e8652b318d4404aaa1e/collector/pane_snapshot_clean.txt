# Solution

**Answer: 4044 minutes.**

## Setup

Let $n = 2023$. There are $\binom{n}{2} = n \cdot 1011$ containers, one per unor
dered pair of keys. A container for pair $\{i,j\}$ is unlocked at time $t$ iff b
oth keys $i$ and $j$ are active.

Alex chooses a toggle sequence of length $T$ (one key toggled per minute). Let $
A_i \subseteq \{1,\dots,T\}$ be the set of times key $i$ is active. The **signat
ure** of pair $\{i,j\}$ is $A_i \cap A_j$. Alex succeeds iff all $\binom{n}{2}$
signatures are distinct.

## Lower Bound: $T \ge 2n - 2$

**Lemma 1.** Every key must be toggled at least once.

*Proof.* If key $i$ is never toggled, then $A_i = \emptyset$, so every pair $\{i
,j\}$ has signature $\emptyset$. Since $n \ge 3$, at least two such pairs collid
e. $\square$

**Lemma 2.** At most 2 keys can be toggled exactly once.

*Proof.* Suppose keys $i, j, k$ are each toggled exactly once, with first-activa
tion times $\sigma(i) < \sigma(j) < \sigma(k)$. Then $A_i = [\sigma(i), T]$, $A_
j = [\sigma(j), T]$, $A_k = [\sigma(k), T]$. Since $\sigma(i) < \sigma(j) < \sig
ma(k)$:

$$A_i \cap A_k = [\sigma(k), T] = A_j \cap A_k.$$

So pairs $\{i,k\}$ and $\{j,k\}$ have identical signatures — a collision. $\squa
re$

**Theorem (Lower Bound).** $T \ge 2n - 2$.

*Proof.* By Lemma 1, each key is toggled $\ge 1$ time. By Lemma 2, at most 2 key
s are toggled exactly once, so at least $n-2$ keys are toggled $\ge 2$ times. Th
erefore:

$$T = \sum_{i=1}^{n} (\text{toggles of key } i) \ge 2 \cdot 1 + 2(n-2) = 2n - 2.
 \quad\square$$

## Construction: $T = 2n - 2$ suffices

**Toggle sequence:** Activate keys $1, 2, \dots, n$ in order (steps $1$ to $n$),
 then deactivate keys $1, 2, \dots, n{-}2$ in order (steps $n{+}1$ to $2n{-}2$).
 Keys $n{-}1$ and $n$ remain active throughout.

**Activity sets:**
- $A_i = [i,\; n+i-1]$ for $i = 1, \dots, n{-}2$ (activated at step $i$, deactiv
ated at step $n+i$).
- $A_{n-1} = [n{-}1,\; 2n{-}2]$, $\quad A_n = [n,\; 2n{-}2]$.

**Signatures** (for $i < j$), all of which are intervals $[a,b]$:

| Pair type | Signature $[a, b]$ |
|---|---|
| $\{i,j\},\; j \le n{-}2$ | $[j,\; n{+}i{-}1]$ |
| $\{i,\, n{-}1\},\; i \le n{-}2$ | $[n{-}1,\; n{+}i{-}1]$ |
| $\{i,\, n\},\; i \le n{-}2$ | $[n,\; n{+}i{-}1]$ |
| $\{n{-}1,\, n\}$ | $[n,\; 2n{-}2]$ |

**Distinctness:** Each interval $[a,b]$ uniquely determines its pair:
- $a \in \{2,\dots,n{-}2\}$: pair is $\{b{-}n{+}1,\; a\}$ with $b{-}n{+}1 < a \l
e n{-}2$.
- $a = n{-}1$: pair is $\{b{-}n{+}1,\; n{-}1\}$.
- $a = n,\; b \le 2n{-}3$: pair is $\{b{-}n{+}1,\; n\}$.
- $a = n,\; b = 2n{-}2$: pair is $\{n{-}1,\; n\}$.

No two cases overlap, and within each case the pair is uniquely recovered from $
[a,b]$. So all $\binom{n}{2}$ signatures are distinct. $\square$

## Conclusion

The minimum number of minutes is:

$$T = 2n - 2 = 2 \times 2023 - 2 = \boxed{4044}.$$
