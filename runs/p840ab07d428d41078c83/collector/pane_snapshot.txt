## Solution

We count the zeros of $f(z) = 10\sin(z^{2019}) - z$ in $D = \{|z|<1\}$ using **R
ouché's theorem**, comparing $f$ with $g(z) = 10\sin(z^{2019})$ on the boundary
$|z|=1$.

### Step 1. A lower bound for $|\sin(w)|$ on $|w|=1$

Write $w = \cos\theta + i\sin\theta$ with $|w|=1$. Using
$$\sin(w) = \sin(\cos\theta)\cosh(\sin\theta) + i\cos(\cos\theta)\sinh(\sin\thet
a),$$
we get
$$|\sin(w)|^{2} = \sin^{2}(\cos\theta)\cosh^{2}(\sin\theta) + \cos^{2}(\cos\thet
a)\sinh^{2}(\sin\theta).$$
Since $\cosh^{2}t = 1+\sinh^{2}t$,
$$|\sin(w)|^{2} = \sin^{2}(\cos\theta) + \sinh^{2}(\sin\theta).$$

Both terms are non-negative. The second vanishes only when $\sin\theta = 0$, i.e
. $\theta = 0$ or $\pi$, giving $w = \pm 1$ and $|\sin(w)|^{2} = \sin^{2}(1)$. F
or all other $\theta$, $\sinh^{2}(\sin\theta) > 0$ while $\sin^{2}(\cos\theta) \
geq 0$, so the value is at least $\sin^{2}(1)$. Hence
$$\min_{|w|=1}|\sin(w)| = \sin(1) \approx 0.8415.$$

### Step 2. Apply Rouché on $|z|=1$

On $|z|=1$ we have $|z^{2019}| = 1$, so by Step 1,
$$|g(z)| = 10|\sin(z^{2019})| \geq 10\sin(1) \approx 8.415 > 1 = |z| = |f(z)-g(z
)|.$$

Thus $|f-g| < |g|$ on $|z|=1$. By Rouché's theorem, $f$ and $g$ have the **same
number of zeros** (counting multiplicity) inside $|z|<1$.

### Step 3. Count zeros of $g(z) = 10\sin(z^{2019})$ in $D$

$\sin(z^{2019}) = 0 \iff z^{2019} = k\pi$ for some $k\in\mathbb{Z}$. Inside $|z|
<1$ we need $|z^{2019}| = |z|^{2019} < 1$, so $|k\pi| < 1$, i.e. $|k| < 1/\pi \a
pprox 0.318$. The only integer is $k = 0$, giving $z^{2019} = 0$, i.e. $z = 0$.

Near $z = 0$,
$$\sin(z^{2019}) = z^{2019} - \tfrac{z^{3\cdot 2019}}{6} + \cdots = z^{2019}\big
l(1 - \tfrac{z^{2\cdot 2019}}{6} + \cdots\bigr),$$
so $z = 0$ is a zero of order exactly **2019**.

Therefore $g$ has $2019$ zeros (counting multiplicity) in $D$, and by Rouché so
does $f$.

### Answer

The number of zeros of $f(z) = 10\sin(z^{2019}) - z$ in the unit disk is

$$\boxed{2019}.$$
