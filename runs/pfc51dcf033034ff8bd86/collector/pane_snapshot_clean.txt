## Proof

**Step 1: Last-digit constraint.**

Since $2014 \equiv 4 \pmod{10}$, the last digit of $c^n + 2014$ equals $(\text{l
ast digit of } c^n + 4) \bmod 10$. For this to be in $\{0,1,2,3,4\}$, the last d
igit of $c^n$ must lie in $\{6,7,8,9,0\}$ for **every** $n \ge 1$.

Checking each possible last digit $d$ of $c$ and the cycle of last digits of $c^
n$:

| $d$ | Cycle of $c^n \bmod 10$ | All in $\{0,6,7,8,9\}$? |
|-----|--------------------------|--------------------------|
| 0   | $0, 0, 0, \ldots$       | ✓ |
| 1   | $1, 1, 1, \ldots$       | ✗ (1 not in set) |
| 2   | $2, 4, 8, 6, \ldots$    | ✗ (2 not in set) |
| 3   | $3, 9, 7, 1, \ldots$    | ✗ (1 at $n=4$) |
| 4   | $4, 6, 4, 6, \ldots$    | ✗ (4 not in set) |
| 5   | $5, 5, 5, \ldots$       | ✗ |
| 6   | $6, 6, 6, \ldots$       | ✓ |
| 7   | $7, 9, 3, 1, \ldots$    | ✗ (3 at $n=3$) |
| 8   | $8, 4, 2, 6, \ldots$    | ✗ (4 at $n=2$) |
| 9   | $9, 1, 9, 1, \ldots$    | ✗ (1 at $n=2$) |

So $c$ must end in **0** or **6**.

**Step 2: Eliminate $c = 6$.**

- $n=1$: $6 + 2014 = 2020$, digits $\{2,0,2,0\}$ — all $< 5$. ✓
- $n=2$: $36 + 2014 = 2050$, digit $5$ appears. ✗

So $c = 6$ fails.

**Step 3: Verify $c = 10$ works for all $n$.**

- $n=1$: $10 + 2014 = 2024$, digits $\{2,0,2,4\}$. ✓
- $n=2$: $100 + 2014 = 2114$, digits $\{2,1,1,4\}$. ✓
- $n=3$: $1000 + 2014 = 3014$, digits $\{3,0,1,4\}$. ✓
- $n \ge 4$: $10^n = \underbrace{1\underbrace{00\cdots0}_{n}}_{n+1\text{ digits}
}$, so $10^n + 2014 = 1\underbrace{00\cdots0}_{n-4}2014$. The digits are exactly
 $\{1, 0, \ldots, 0, 2, 0, 1, 4\}$, all of which are $< 5$. ✓

**Step 4: Minimality.**

The positive integers ending in 0 or 6, in increasing order, are $6, 10, 16, 20,
 \ldots$. The only candidate below 10 is $c = 6$, which fails (Step 2). Since $c
 = 10$ works (Step 3), it is the smallest.

---

The smallest positive integer $c$ is $\boxed{10}$.
