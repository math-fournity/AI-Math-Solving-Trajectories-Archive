# Problem

In the city of Gridland, the municipal park is designed as an 8x8 grid of square plots. The city council has commissioned a local gardening firm to install exactly 16 rectangular flower beds, each measuring 2x1 plots (or 1x2 plots). These beds must be placed within the park boundaries such that they occupy exactly two plots each and do not overlap.

The city’s safety regulations specify a strict "open space" requirement for the park: in every possible 2x2 cluster of plots within the 8x8 grid, there must remain at least two plots that are not covered by any flower beds. Furthermore, for each such 2x2 cluster, these two (or more) uncovered plots must be situated in the same row or the same column as each other.

Determine the total number of distinct arrangements in which the 16 flower beds can be placed to satisfy these safety regulations.
