**Claim.** If $m$ is even, the unique solution is $(n, x, y) = \left(m+1,\; 2^{m
/2},\; 2^{m/2}\right)$. If $m$ is odd, there are no solutions.

---

### Proof

Let $d = \gcd(x,y)$, and write $x = da$, $y = db$ with $\gcd(a,b)=1$ and $a,b$ p
ositive integers. Substituting into $(x^2+y^2)^m = (xy)^n$:

$$\bigl(d^2(a^2+b^2)\bigr)^m = (d^2 ab)^n \implies d^{2m}(a^2+b^2)^m = d^{2n}(ab
)^n,$$

hence

$$d^{2(m-n)}(a^2+b^2)^m = (ab)^n. \tag{$\star$}$$

**Key observation.** Since $\gcd(a,b)=1$, we have $\gcd(ab,\, a^2+b^2)=1$. Indee
d, if a prime $p\mid a$ and $p\mid(a^2+b^2)$, then $p\mid b^2$, so $p\mid b$, co
ntradicting $\gcd(a,b)=1$; similarly for primes dividing $b$.

---

**Case 1: $m \geq n$.** Then $d^{2(m-n)}(a^2+b^2)^m = (ab)^n$. Take any prime $p
\mid(a^2+b^2)$. Since $p\nmid ab$, the right side has $v_p = 0$, while the left
side has $v_p \geq m\cdot v_p(a^2+b^2) \geq m \geq 1 > 0$—a contradiction. Thus
$a^2+b^2$ has no prime factors, i.e., $a^2+b^2=1$. But $a,b\geq 1$ gives $a^2+b^
2\geq 2$. **No solutions exist when $m\geq n$.**

**Case 2: $m < n$.** Rewrite $(\star)$ as $(a^2+b^2)^m = d^{2(n-m)}(ab)^n$. Take
 any prime $p\mid ab$. Since $p\nmid(a^2+b^2)$, the left side has $v_p=0$, while
 the right side has $v_p = 2(n-m)v_p(d) + n\cdot v_p(ab) \geq n \geq 1 > 0$—a co
ntradiction. Thus $ab$ has no prime factors, i.e., $ab=1$, so $a=b=1$.

Substituting $a=b=1$ into $(\star)$ with $k:=n-m>0$:

$$2^m = d^{2k}. \tag{$\star\star$}$$

Since $d^{2k}=2^m$, $d$ has no odd prime factors, so $d=2^t$ for some integer $t
\geq 0$. Then $2^{2tk}=2^m$, giving $m=2tk$. Since $k=n-m$, we get $m = 2t(n-m)$
, hence:

$$n = m + k = m + \frac{m}{2t} = \frac{m(2t+1)}{2t}.$$

For $n$ to be a positive integer, we need $2t\mid m(2t+1)$. Since $\gcd(2t,\,2t+
1)=1$, this requires $2t\mid m$. Write $m = 2ts$ for a positive integer $s$. The
n:

$$n = s(2t+1), \qquad m = 2ts.$$

Now impose $\gcd(n,m)=1$:

$$\gcd\bigl(s(2t+1),\; 2ts\bigr) = s\cdot\gcd(2t+1,\,2t) = s\cdot 1 = s.$$

So $\gcd(n,m)=1$ forces $s=1$, giving:

$$m = 2t, \quad n = 2t+1 = m+1, \quad d = 2^t = 2^{m/2}.$$

Therefore $x = y = d = 2^{m/2}$, and this requires $m=2t$ to be **even** (with $
t\geq 1$ since $m\geq 1$, i.e., $m\geq 2$).

---

**Verification.** With $m$ even, $n=m+1$, $x=y=2^{m/2}$:

$$(x^2+y^2)^m = \left(2\cdot 2^m\right)^m = \left(2^{m+1}\right)^m = 2^{m(m+1)},
$$

$$(xy)^n = \left(2^{m/2}\cdot 2^{m/2}\right)^{m+1} = \left(2^m\right)^{m+1} = 2^
{m(m+1)}. \quad\checkmark$$

$$\gcd(n,m) = \gcd(m+1,m) = 1. \quad\checkmark$$

---

**Conclusion.** For a given positive integer $m$:

- **If $m$ is even**, the unique triple is $\boxed{(n,\, x,\, y) = \left(m+1,\;
2^{m/2},\; 2^{m/2}\right)}$.
- **If $m$ is odd**, no solution exists.
