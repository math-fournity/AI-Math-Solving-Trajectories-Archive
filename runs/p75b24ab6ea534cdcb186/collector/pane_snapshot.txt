## Key Observation: The Difference $d = a - b$

Let $d = a - b$. Since $\gcd(a+k, b+k) = \gcd(a-b, b+k) = \gcd(d, b+k)$, the gam
e depends crucially on $d$.

**The game ends iff $d = 1$.** If $d \geq 2$, then $d$ has a prime factor $p$, a
nd some multiple of $p$ lies in $\{b+1, b+2, \ldots\}$, so a valid $k$ always ex
ists. When $d = 1$, $\gcd(1, b+k) = 1$ for all $k$, so the game ends.

**The final fraction is always of the form $\frac{n-1}{n}$.** Since the game end
s when $d = 1$, the final fraction is $\frac{b}{b+1}$, i.e., $\frac{n-1}{n}$.

## Main Theorem

b \geq 1$, the game ends at the fraction $\frac{t+1}{t+2}$ where $t = \left\lflo
or \frac{b-1}{d} \right\rfloor$.

**Proof by strong induction on $d$.**

*Base case* ($d = 1$): The game ends immediately at $\frac{b}{b+1}$. Here $t = \
lfloor(b-1)/1\rfloor = b-1$, so $\frac{t+1}{t+2} = \frac{b}{b+1}$. ✓

*Inductive step* ($d \geq 2$): Assume the claim for all $d' < d$. Let $r = b \bm
od d$; since $\gcd(b, d) = 1$ and $d \geq 2$, we have $1 \leq r \leq d-1$. Write

\leq r-1 < d$).

The game finds the smallest $k_0 > 0$ with $\gcd(d, r + k_0) > 1$. Setting $k =
d - r$ gives $r + k = d$ with $\gcd(d, d) = d > 1$, so $k_0 \leq d - r$, hence $
r + k_0 \leq d$.

Let $g = \gcd(d, r + k_0) \geq 2$ and $d' = d/g < d$. The new fraction is $b'/a'

Write $s = (r + k_0)/g$ (a positive integer). Since $1 \leq r + k_0 \leq d$ and

$$t' = \left\lfloor \frac{b' - 1}{d'} \right\rfloor = \left\lfloor \frac{(b + k_

s-1}{d'} \right\rfloor.$$

Since $0 \leq s - 1 \leq d' - 1 < d'$, we have $\lfloor(s-1)/d'\rfloor = 0$, so
**$t' = t$**.

## Complete Answer

**For $q \in \mathbb{Q}_{(0,1)}$ not of the form $\frac{n-1}{n}$ ($n \geq 2$ int
eger):** No initial value ends at $q$. The set is empty.

**For $q = \frac{n-1}{n}$ with $n \geq 2$:** The initial values $\frac{b}{a}$ (r
educed, $0 < b < a$) that end at $q$ are exactly those satisfying:
$$\left\lfloor \frac{b-1}{a-b} \right\rfloor = n - 2.$$

Equivalently, setting $d = a - b \geq 1$, the condition is:
$$(n-2)\,d + 1 \;\leq\; b \;\leq\; (n-1)\,d, \qquad \gcd(b,\, d) = 1.$$
