## Theorem (Existence and Uniqueness)

Let Ω = (0,1), a ∈ C^∞(Ω̄) with a(x) ≥ δ > 0 for some δ > 0, and let u_0, u_1 ∈ C
_0^∞(Ω). Consider

$$u_{tt} + u_t = (a\,u_x)_x + f \quad\text{in } \Omega\times(0,T),\qquad u|_{\pa
rtial\Omega\times(0,T)}=0,\qquad u(x,0)=u_0,\; u_t(x,0)=u_1.$$

**(a)** If f ≡ 0, there exists a unique function

$$u \in C^2([0,T];L^2(\Omega))\cap C^1([0,T];H_0^1(\Omega))\cap C^0([0,T];H^2(\O
mega)\cap H_0^1(\Omega))$$

satisfying the equation in C^0([0,T];L^2(Ω)), the Dirichlet boundary condition,
and the initial conditions.

**(b)** If f ∈ C^1([0,T); H^2(Ω)∩H_0^1(Ω)), there exists a unique function with
the *same* regularity as in (a) satisfying u_tt + u_t = (a u_x)_x + f in C^0([0,
T];L^2(Ω)), with the same boundary and initial conditions.

## Proof

### 1. Functional setup

Set the energy Hilbert space

$$\mathcal H = H_0^1(\Omega)\times L^2(\Omega),\qquad \langle (u,v),(\varphi,\ps
i)\rangle_{\mathcal H} = \int_\Omega a\,u_x\varphi_x\,dx + \int_\Omega v\,\psi\,
dx.$$

This inner product is equivalent to the standard H_0^1×L^2 norm because a ≥ δ >
0.

Define the operator 𝒜 on 𝓗 by

$$\mathcal A(u,v) = \bigl(v,\; (a\,u_x)_x - v\bigr),\qquad D(\mathcal A)=\{(u,v)
\in\mathcal H : u\in H^2(\Omega)\cap H_0^1(\Omega),\; v\in H_0^1(\Omega)\}.$$

For u ∈ H^2∩H_0^1 we have (a u_x)_x ∈ L^2 (a is smooth, u_x ∈ H^1), so 𝒜 maps D(
𝒜) into 𝓗. The domain is dense since it contains C_0^∞(Ω)×C_0^∞(Ω).

Writing U = (u, u_t), the PDE (with f = 0) is equivalent to the abstract Cauchy
problem

$$U'(t) = \mathcal A\,U(t),\qquad U(0) = (u_0,u_1).$$

### 2. 𝒜 is dissipative

For (u,v) ∈ D(𝒜),

$$\langle \mathcal A(u,v),(u,v)\rangle_{\mathcal H} = \int a\,v_x u_x\,dx + \int
 (a\,u_x)_x\,v\,dx - \int |v|^2\,dx.$$

Integration by parts (v ∈ H_0^1, a u_x ∈ H^1, so the boundary term vanishes):

$$\int (a\,u_x)_x\,v\,dx = -\int a\,u_x v_x\,dx.$$

Hence the first two terms cancel and

$$\langle \mathcal A(u,v),(u,v)\rangle_{\mathcal H} = -\|v\|_{L^2}^2 \le 0.$$

So 𝒜 is dissipative.

### 3. Range condition: I − 𝒜 is surjective

Given (f,g) ∈ 𝓗, solve (I − 𝒜)(u,v) = (f,g):

$$u - v = f,\qquad v - (a\,u_x)_x + v = g.$$

Substituting v = u − f gives 2u − (a u_x)_x = 2f + g, i.e.

$$(2I - A)\,u = 2f + g,\qquad A u := (a\,u_x)_x,\quad D(A)=H^2\cap H_0^1.$$

The operator A is self-adjoint and non-positive on L^2 (since ⟨Au,u⟩ = −∫ a|u_x|
² ≤ −δ‖u_x‖² ≤ 0), so −A is a positive self-adjoint operator with spectrum in [λ
_1,∞), λ_1 > 0. Therefore 2I − A = 2I + (−A) is boundedly invertible, and

$$u = (2I - A)^{-1}(2f+g) \in H^2\cap H_0^1.$$

Then v = u − f ∈ H_0^1 (both u, f ∈ H_0^1), so (u,v) ∈ D(𝒜) and (I − 𝒜)(u,v) = (
f,g). Thus I − 𝒜 is surjective.

### 4. Semigroup generation (Lumer–Phillips)

By the Lumer–Phillips theorem, 𝒜 generates a C_0 contraction semigroup {S(t)}_{t
≥0} on 𝓗.

### 5. Homogeneous solution — part (a), existence

Since u_0, u_1 ∈ C_0^∞(Ω) ⊂ H^2∩H_0^1 and u_1 ∈ H_0^1, we have (u_0,u_1) ∈ D(𝒜).
 For initial data in D(𝒜), the semigroup yields the classical solution

$$U(t) = (u(t),u_t(t)) = S(t)(u_0,u_1) \in C^1([0,T];\mathcal H)\cap C^0([0,T];D
(\mathcal A)).$$

Decomposing this regularity:

- u ∈ C^1([0,T]; H_0^1) ∩ C^0([0,T]; H^2∩H_0^1),
- u_t ∈ C^1([0,T]; L^2) ∩ C^0([0,T]; H_0^1),
- u_tt ∈ C^0([0,T]; L^2),

which is exactly the regularity stated in the theorem. The equation u_tt + u_t =
 (a u_x)_x holds in C^0([0,T];L^2), u|_{∂Ω} = 0 since u(t) ∈ H_0^1, and u(0)=u_0
, u_t(0)=u_1 by construction.

### 6. Uniqueness — part (a)

Let u, ũ be two solutions with the stated regularity and the same data, and set
w = u − ũ. Then

$$w_{tt} + w_t = (a\,w_x)_x,\qquad w|_{\partial\Omega}=0,\qquad w(0)=w_t(0)=0.$$

Define the energy

$$E(t) = \tfrac12\int_\Omega a\,|w_x|^2\,dx + \tfrac12\int_\Omega |w_t|^2\,dx \;
\ge\; 0.$$

Using w ∈ C^2([0,T];L^2) ∩ C^1([0,T];H_0^1) ∩ C^0([0,T];H^2∩H_0^1), differentiat
e:

$$E'(t) = \int a\,w_x(w_t)_x\,dx + \int w_t\,w_{tt}\,dx.$$

Substituting w_tt = (a w_x)_x − w_t and integrating by parts (∫ w_t(a w_x)_x = −
∫ a w_x(w_t)_x, boundary term vanishes):

$$E'(t) = \int a\,w_x(w_t)_x\,dx - \int a\,w_x(w_t)_x\,dx - \int |w_t|^2\,dx = -
\|w_t\|_{L^2}^2 \le 0.$$

Hence E(t) ≤ E(0) = 0, so E(t) ≡ 0, giving w_x ≡ 0 and w_t ≡ 0; with w(0)=0 this
 yields w ≡ 0. Uniqueness follows.

### 7. Forced solution — part (b), existence

Now f ∈ C^1([0,T); H^2∩H_0^1) ⊂ C^1([0,T); L^2). Define F(s) = (0, f(s)) ∈ 𝓗. Th
en F ∈ C^1([0,T); 𝓗), and in fact F(s) ∈ D(𝒜) because 0 ∈ H^2∩H_0^1 and f(s) ∈ H
^2∩H_0^1 ⊂ H_0^1.

By the standard inhomogeneous semigroup theorem (see e.g. Pazy, *Semigroups of L
inear Operators and Applications to PDE*, Thm. 1.7, Chapter 6): if 𝒜 generates a
 C_0 semigroup, (u_0,u_1) ∈ D(𝒜), and F ∈ C^1([0,T); 𝓗), then

$$U(t) = S(t)(u_0,u_1) + \int_0^t S(t-s)\,F(s)\,ds$$

is the unique classical solution in C^1([0,T]; 𝓗) ∩ C^0([0,T]; D(𝒜)) of

$$U'(t) = \mathcal A\,U(t) + F(t),\qquad U(0) = (u_0,u_1).$$

Decomposing as in Step 5, this gives u with exactly the regularity of part (a),
satisfying u_tt + u_t = (a u_x)_x + f in C^0([0,T];L^2), u|_{∂Ω} = 0, u(0) = u_0
, u_t(0) = u_1.

### 8. Uniqueness — part (b)

If u, ũ are two solutions of the forced problem with the same data, their differ
ence w = u − ũ satisfies the *homogeneous* equation with zero initial data. The
energy argument of Step 6 applies verbatim and gives w ≡ 0. ∎
