Looking at this problem, I need to find the minimum value of the maximum of n re
al numbers (n > 3) subject to sum ≥ n and sum of squares ≥ n².

## Proof

**Setup.** Let $M = \max\{a_1, \ldots, a_n\}$. We seek the smallest $M$ for whic
h the feasible region
$$\mathcal{F}_M = \left\{\mathbf{a} \in \mathbb{R}^n : \sum a_i \ge n,\; a_i \le
 M \;\forall i\right\}$$
contains a point with $\sum a_i^2 \ge n^2$.

**Necessary condition: $M \ge 1$.** If $M < 1$, then $\sum a_i \le nM < n$, cont
radicting $\sum a_i \ge n$.

**Boundedness of $\mathcal{F}_M$.** For $M \ge 1$, each $a_i \ge n - (n-1)M$ (si
nce the other $n-1$ terms are at most $M$), so $\mathcal{F}_M$ is bounded. The c
onvex function $f(\mathbf{a}) = \sum a_i^2$ attains its maximum at a vertex of $
\mathcal{F}_M$.

**Identifying the vertices.** A vertex of $\mathcal{F}_M$ requires $n$ tight con
straints among $\{\sum a_i \ge n\} \cup \{a_i \le M : i=1,\ldots,n\}$. This give
s two types:

- **Type A:** $\sum a_i = n$ tight and $n-1$ of the $a_i \le M$ tight, yielding
(up to permutation) $(M, M, \ldots, M,\; n-(n-1)M)$.
- **Type B:** All $a_i = M$, giving $\sum a_i = nM \ge n$ (valid when $M \ge 1$)
.

**Computing the maximum of $\sum a_i^2$.**

*Type A:* $\sum a_i^2 = (n-1)M^2 + (n-(n-1)M)^2 = n + n(n-1)(M-1)^2.$

*Type B:* $\sum a_i^2 = nM^2.$

Comparing: $nM^2 \ge n + n(n-1)(M-1)^2$ iff $(n-2)M^2 - 2(n-1)M + n \le 0$, whic
h holds for $M \in \left[1,\; \tfrac{n}{n-2}\right]$ (roots at $M=1$ and $M=\tfr
ac{n}{n}{n-2}$). Therefore:

$$\max_{\mathbf{a} \in \mathcal{F}_M} \sum a_i^2 = \begin{cases} nM^2 & \text{if
 } 1 \le M \le \frac{n}{n-2},\\ n + n(n-1)(M-1)^2 & \text{if } M \ge \frac{n}{n-
2}. \end{cases}$$

**Showing $M < 2$ is infeasible.** For $1 \le M < 2$:

- If $M \le \frac{n}{n-2}$: then $\max \sum a_i^2 = nM^2 < 4n$. For $n > 3$, we
have $4n \le n^2$ iff $n \ge 4$, with equality only at $n=4, M=2$. So for $M < 2
$, $nM^2 < n^2$.

- If $M > \frac{n}{n-2}$ (and $M < 2$): then $\max \sum a_i^2 = n + n(n-1)(M-1)^
2 < n + n(n-1) \cdot 1 = n^2$, since $(M-1)^2 < 1$ for $0 < M < 2$.

In both cases, $\max \sum a_i^2 < n^2$, so no feasible point satisfies $\sum a_i
^2 \ge n^2$.

**Showing $M = 2$ is achievable.** Take $a_1 = a_2 = \cdots = a_{n-1} = 2$ and $
a_n = 2 - n$. Then:

$$\sum a_i = 2(n-1) + (2-n) = n \ge n. \quad\checkmark$$

$$\sum a_i^2 = 4(n-1) + (2-n)^2 = 4n - 4 + n^2 - 4n + 4 = n^2 \ge n^2. \quad\che
ckmark$$

$$\max\{a_1, \ldots, a_n\} = 2.\quad\checkmark$$

**Conclusion.** The minimum value of $\max\{a_1, a_2, \ldots, a_n\}$ is $\boxed{
2}$.
