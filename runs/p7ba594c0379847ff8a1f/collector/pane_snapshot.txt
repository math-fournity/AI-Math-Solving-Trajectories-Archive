Looking at this problem, I need to find the maximum sum of areas of rectangles o
n a $(2m+1)\times(2n+1)$ grid, with corners on grid points, sides parallel to gr
id lines, and no shared corners.

**Answer check:** The problem contains no leaked answers or solution hints.

## Solution

**Setup.** Place grid points at $(i,j)$ for $0 \le i \le 2m$, $0 \le j \le 2n$.
A rectangle is determined by $x_1 < x_2$ and $y_1 < y_2$, with area $(x_2 - x_1)
(y_2 - y_1)$ and corners $(x_1,y_1), (x_1,y_2), (x_2,y_1), (x_2,y_2)$.

### Upper Bound

Define the weight function $w(i,j) = |i - m| \cdot |j - n|$ on each grid point.

**Claim:** For any rectangle with $x_1 < x_2$, $y_1 < y_2$:
$$(x_2 - x_1)(y_2 - y_1) \le w(x_1,y_1) + w(x_1,y_2) + w(x_2,y_1) + w(x_2,y_2).$
$

*Proof of Claim.* Set $f(i) = |i - m|$ and $g(j) = |j - n|$, so $w(i,j) = f(i)\,
g(j)$. The right side equals $(f(x_1)+f(x_2))(g(y_1)+g(y_2))$. We show $x_2 - x_
1 \le f(x_1) + f(x_2)$ and $y_2 - y_1 \le g(y_1) + g(y_2)$ separately.

For $x_1 < x_2$: by the triangle inequality for the absolute value,
$$f(x_1) + f(x_2) = |x_1 - m| + |x_2 - m| \ge |x_2 - x_1| = x_2 - x_1.$$
The same argument gives $y_2 - y_1 \le g(y_1) + g(y_2)$. Multiplying (all quanti
ties non-negative):
$$(x_2-x_1)(y_2-y_1) \le (f(x_1)+f(x_2))(g(y_1)+g(y_2)). \quad \square$$

**Summing over all rectangles.** Since no two rectangles share a corner, each gr
id point contributes its weight at most once:
$$\sum_{\text{rectangles}} \text{area} \le \sum_{\text{all grid points}} w(i,j)
= \left(\sum_{i=0}^{2m} |i-m|\right)\left(\sum_{j=0}^{2n} |j-n|\right).$$

Computing each sum:
$$\sum_{i=0}^{2m} |i-m| = 2(0 + 1 + \cdots + m) = m(m+1), \qquad \sum_{j=0}^{2n}
 |j-n| = n(n+1).$$

Therefore:
$$\sum \text{area} \le m(m+1)\,n(n+1).$$

### Construction Achieving the Bound

Pair the $x$-coordinates below $m$ with those above $m$ symmetrically: for $i =
0, 1, \ldots, m-1$, form the pair $(i,\; 2m-i)$. This gives $m$ pairs with $x$-g
aps $2m, 2m-2, \ldots, 2$.

Similarly, for $j = 0, 1, \ldots, n-1$, form the $y$-pair $(j,\; 2n-j)$, giving
$n$ pairs with $y$-gaps $2n, 2n-2, \ldots, 2$.

For each combination of an $x$-pair $(i, 2m-i)$ and a $y$-pair $(j, 2n-j)$, form
 the rectangle with corners:
$$(i,\, j),\quad (i,\, 2n-j),\quad (2m-i,\, j),\quad (2m-i,\, 2n-j).$$

This gives $mn$ rectangles. **No two share a corner:** distinct $x$-pairs use di
sjoint $x$-coordinates (the values $0,\ldots,m-1$ and $m+1,\ldots,2m$ are all di
stinct), and distinct $y$-pairs use disjoint $y$-coordinates. So all $4mn$ corne
r points are distinct, and none lies on the middle row $i=m$ or middle column $j
=n$.

**Total area:**
$$\sum_{i=0}^{m-1}\sum_{j=0}^{n-1} (2m-2i)(2n-2j) = 4\left(\sum_{i=0}^{m-1}(m-i)
\right)\left(\sum_{j=0}^{n-1}(n-j)\right) = 4 \cdot \frac{m(m+1)}{2} \cdot \frac
{n(n+1)}{2} = m(m+1)\,n(n+1).$$

### Conclusion

The upper bound and the construction match, so the maximum possible value of the
 sum of areas is:

$$\boxed{m(m+1)\,n(n+1)}$$
