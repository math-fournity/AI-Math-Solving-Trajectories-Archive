## Proof

**Step 1: Identify the adjacency structure.**

For each level $a \in \{1,2,3,4,5\}$, the valid successors $b$ satisfy $|a-b| \g
eq 3$:

| Level $a$ | Valid successors $b$ |
|-----------|---------------------|
| 1         | $\{4, 5\}$          |
| 2         | $\{5\}$             |
| 3         | $\varnothing$       |
| 4         | $\{1\}$             |
| 5         | $\{1, 2\}$          |

Level **3 has no valid neighbors**, so for $n \geq 2$, level 3 cannot appear in
any valid assignment (every station has at least one adjacent station). Thus for
 $n \geq 2$ we work only with $\{1, 2, 4, 5\}$.

**Step 2: Recognize the path graph.**

The allowed adjacencies among $\{1,2,4,5\}$ form the undirected edges:
$$4 - 1, \quad 1 - 5, \quad 5 - 2.$$
This is a **path graph** $P_4$ on vertices ordered as $4 - 1 - 5 - 2$, with endp
oints $\{4, 2\}$ and internal vertices $\{1, 5\}$.

A valid assignment of $n$ stations is exactly a **walk of length $n-1$** on this
 path graph.

**Step 3: Set up the recurrence.**

By the symmetry of the path, let:
- $e_n$ = number of valid length-$n$ sequences ending at a **specific** endpoint
 (4 or 2),
- $i_n$ = number of valid length-$n$ sequences ending at a **specific** internal
 vertex (1 or 5).

The total count is $f(n) = 2\,e_n + 2\,i_n = 2(e_n + i_n)$.

**Transitions** (each endpoint has one neighbor = internal; each internal vertex
 has one endpoint neighbor and one internal neighbor):
$$e_{n+1} = i_n, \qquad i_{n+1} = e_n + i_n.$$

**Initial conditions** (length-1 sequences on the path, i.e., $n=1$ restricted t
o $\{1,2,4,5\}$): $e_1 = 1$, $i_1 = 1$.

**Step 4: Solve the recurrence.**

From $e_{n+1} = i_n$ we get $e_n = i_{n-1}$. Substituting into the second equati
on:
$$i_{n+1} = i_{n-1} + i_n.$$
This is the **Fibonacci recurrence**, with $i_1 = 1$, $i_2 = e_1 + i_1 = 2$. The
refore $i_n = F_{n+1}$ (where $F_1 = F_2 = 1$, $F_3 = 2$, $F_4 = 3, \ldots$). Th
en $e_n = i_{n-1} = F_n$.

**Step 5: Compute the closed form.**

For $n \geq 2$:
$$f(n) = 2(e_n + i_n) = 2(F_n + F_{n+1}) = 2\,F_{n+2}.$$

**Step 6: Verify.**

| $n$ | $F_{n+2}$ | $2F_{n+2}$ | Direct count | ✓ |
|-----|-----------|------------|--------------|---|
| 2   | $F_4 = 3$ | 6          | $2+1+0+1+2 = 6$ | ✓ |

**Step 7: Handle $n = 1$.**

For $n = 1$, there are no adjacency constraints, so all 5 levels are valid: $f(1
) = 5$. (The formula $2F_3 = 4$ excludes level 3, which is only forbidden when $
n \geq 2$.)

## Answer

$$\boxed{f(n) = \begin{cases} 5 & \text{if } n = 1, \\[4pt] 2\,F_{n+2} & \text{i

where $F_k$ is the $k$-th Fibonacci number ($F_1 = F_2 = 1$, $F_3 = 2$, $F_4 = 3
