## Proof

Let $z = x - y \in \{-1, 0, 1\}^n$ and let $T = \{j \in [n] : z_j \neq 0\}$, so
$T$ is the set of coordinates where $x$ and $y$ differ. Note that
$$\langle a_i, x\rangle - \langle a_i, y\rangle = \langle a_i, z\rangle = \sum_{
j \in T} a_{i,j}\, z_j.$$

**Case $T = \emptyset$ (i.e., $x = y$).** Then every term is $0$, so the sum is
$0$.

**Case $T \neq \emptyset$.** For each $i \in [m]$, define the parity
$$b_i \;=\; \sum_{j \in T} a_{i,j} \pmod{2}.$$

Since each $z_j \in \{-1, +1\}$ satisfies $z_j \equiv 1 \pmod{2}$, we have
$$\langle a_i, z\rangle \;=\; \sum_{j \in T} a_{i,j}\, z_j \;\equiv\; \sum_{j \i
n T} a_{i,j} \;\equiv\; b_i \pmod{2}.$$

Consequences:
- If $b_i = 1$, then $\langle a_i, z\rangle$ is an odd integer, so $|\langle a_i
, z\rangle| \geq 1$.
- If $b_i = 0$, then $|\langle a_i, z\rangle| \geq 0$.

In both cases,
$$|\langle a_i, z\rangle| \;\geq\; \mathbf{1}[b_i = 1] \;=\; \frac{1 - (-1)^{b_i
}}{2}.$$

Summing over $i = 1, \dots, m$:
$$\sum_{i=1}^{m} |\langle a_i, z\rangle| \;\geq\; \sum_{i=1}^{m} \frac{1 - (-1)^
{b_i}}{2} \;=\; \frac{m}{2} - \frac{1}{2}\sum_{i=1}^{m} (-1)^{b_i}.$$

Now apply the $\epsilon$-biased property of $S_n$ to the nonempty set $T$. By de
finition, for every nonempty $T \subseteq [n]$,
$$\left|\frac{1}{m}\sum_{i=1}^{m} (-1)^{\sum_{j \in T} a_{i,j}}\right| \;\leq\;
\epsilon,$$
i.e., $\left|\frac{1}{m}\sum_{i=1}^{m} (-1)^{b_i}\right| \leq \epsilon$, which g
ives $\sum_{i=1}^{m} (-1)^{b_i} \leq \epsilon\, m$.

Substituting:
$$\sum_{i=1}^{m} |\langle a_i, x\rangle - \langle a_i, y\rangle| \;\geq\; \frac{
m}{2} - \frac{\epsilon\, m}{2} \;=\; \frac{m(1 - \epsilon)}{2}.$$

**Tightness.** When $x$ and $y$ differ in a single coordinate $j$, we have $z =
\pm e_j$ and $\langle a_i, z\rangle = \pm a_{i,j} \in \{0, \pm 1\}$, so $|\langl
e a_i, z\rangle| = a_{i,j}$. The sum becomes $\sum_i a_{i,j}$, and the bias cond
ition on $T = \{j\}$ gives exactly $\sum_i a_{i,j} \geq \frac{m(1-\epsilon)}{2}$
, with equality when the bias equals $\epsilon$. Hence the bound is achieved.

**Conclusion.** For all $x \neq y \in \{0,1\}^n$,
$$\sum_{i=1}^{m} \left|\langle a_i, x\rangle - \langle a_i, y\rangle\right| \;\g
eq\; \boxed{\dfrac{m(1-\epsilon)}{2}}.$$
