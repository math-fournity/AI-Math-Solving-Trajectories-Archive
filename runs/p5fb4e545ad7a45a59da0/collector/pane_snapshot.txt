## Solution

We compute
$$I = \int_{\mathbb{R}}\int_{\mathbb{R}} \frac{1}{(1+(x-y)^2)^2}\,dx\,dy.$$

The integrand $f(x,y)=\frac{1}{(1+(x-y)^2)^2}$ is nonnegative and measurable on
$\mathbb{R}^2$, so by Tonelli's theorem we may evaluate the iterated integral in
 either order (the value, finite or $+\infty$, is unambiguous).

**Inner integral (in $x$, with $y$ fixed).** Substitute $t = x - y$, so $dx = dt
$:
$$\int_{\mathbb{R}} \frac{1}{(1+(x-y)^2)^2}\,dx = \int_{\mathbb{R}} \frac{1}{(1+
t^2)^2}\,dt.$$

This is a standard integral. Using $t = \tan\theta$, $dt = \sec^2\theta\,d\theta
$, $1+t^2 = \sec^2\theta$:
$$\int_{-\pi/2}^{\pi/2} \frac{\sec^2\theta}{\sec^4\theta}\,d\theta = \int_{-\pi/
2}^{\pi/2}\cos^2\theta\,d\theta = \frac{\pi}{2}.$$

So for every $y\in\mathbb{R}$,
$$\int_{\mathbb{R}} \frac{1}{(1+(x-y)^2)^2}\,dx = \frac{\pi}{2}.$$

**Outer integral (in $y$).** Therefore
$$I = \int_{\mathbb{R}} \frac{\pi}{2}\,dy = +\infty.$$

The integrand is strictly positive everywhere and the inner integral is a positi
ve constant ($\pi/2$) independent of $y$, so integrating over all $y\in\mathbb{R
}$ diverges to $+\infty$.

**Verification via change of variables.** Set $u = x-y$, $v = y$; the Jacobian i
s $1$, and the domain is still $\mathbb{R}^2$:
$$I = \int_{\mathbb{R}}\int_{\mathbb{R}} \frac{1}{(1+u^2)^2}\,du\,dv = \left(\in
t_{\mathbb{R}}\frac{1}{(1+u^2)^2}\,du\right)\!\left(\int_{\mathbb{R}}1\,dv\right
) = \frac{\pi}{2}\cdot(+\infty) = +\infty.$$

Both methods agree.

## Conclusion

The integral diverges:
$$\boxed{\int_{\mathbb{R}}\int_{\mathbb{R}} \frac{1}{(1+(x-y)^2)^2}\,dx\,dy = +\
infty.}$$
