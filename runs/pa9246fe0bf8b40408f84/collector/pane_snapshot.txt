## Checking the Recurrence

The recurrence is stated as $T(n) = n + \sum_{k=1}^{n}[T(n-k) + T(k)]$ with $T(1
)=1$.

Expanding the sum:
$$\sum_{k=1}^{n} T(n-k) = \sum_{j=0}^{n-1} T(j), \qquad \sum_{k=1}^{n} T(k) = \s
um_{k=1}^{n-1} T(k) + T(n)$$

So the full sum equals $T(0) + 2\sum_{k=1}^{n-1} T(k) + T(n)$. Substituting:

$$T(n) = n + T(0) + 2\sum_{k=1}^{n-1} T(k) + T(n)$$

The $T(n)$ on both sides cancels, yielding $0 = n + T(0) + 2\sum_{k=1}^{n-1} T(k
)$, which for $n=1$ gives $0 = 1 + T(0)$, i.e., $T(0) = -1$. But for $n=2$: $0 =
 2 + (-1) + 2T(1) = 1 + 2 = 3$, a **contradiction**.

The recurrence as literally written (sum to $n$) is degenerate/inconsistent. The
 only well-defined, standard interpretation consistent with $T(1)=1$ is the sum
running from $k=1$ to $n-1$:

$$\boxed{T(n) = n + \sum_{k=1}^{n-1}[T(n-k) + T(k)], \quad T(1) = 1}$$

This is the classic form of this recurrence. I solve it below.

## Solution

**Step 1: Simplify the sum.** By the substitution $j = n-k$ (as $k$ runs $1$ to
$n-1$, $j$ runs $n-1$ to $1$):

$$\sum_{k=1}^{n-1} T(n-k) = \sum_{j=1}^{n-1} T(j)$$

Therefore:
$$T(n) = n + 2\sum_{k=1}^{n-1} T(k)$$

**Step 2: Convert to a first-order recurrence.** Let $S(n) = \sum_{k=1}^{n} T(k)
$, so $T(n) = n + 2S(n-1)$. Then:

$$S(n) = S(n-1) + T(n) = S(n-1) + n + 2S(n-1) = n + 3S(n-1)$$

with $S(1) = T(1) = 1$.

**Step 3: Solve $S(n) = n + 3S(n-1)$.** The homogeneous solution is $C \cdot 3^n
$. For a particular solution, try $S_p(n) = an + b$:

$$an + b = n + 3(a(n-1)+b) = (1+3a)n + (-3a+3b)$$

Matching coefficients: $a = 1+3a \Rightarrow a = -\tfrac{1}{2}$, and $b = -3a+3b
 \Rightarrow b = \tfrac{3a}{2} = -\tfrac{3}{4}$.

So $S(n) = C\cdot 3^n - \tfrac{n}{2} - \tfrac{3}{4}$. Using $S(1)=1$:

$$1 = 3C - \tfrac{1}{2} - \tfrac{3}{4} = 3C - \tfrac{5}{4} \implies C = \tfrac{3
}{4}$$

$$S(n) = \tfrac{3^{n+1}}{4} - \tfrac{n}{2} - \tfrac{3}{4}$$

**Step 4: Recover $T(n)$.**

$$T(n) = n + 2S(n-1) = n + 2\left[\tfrac{3^n}{4} - \tfrac{n-1}{2} - \tfrac{3}{4}
\right] = n + \tfrac{3^n}{2} - (n-1) - \tfrac{3}{2} = \tfrac{3^n - 1}{2}$$

**Step 5: Verification via generating functions.** Let $T(x) = \sum_{n\ge 1} T(n
)x^n$. From $T(n) = n + 2\sum_{k=1}^{n-1}T(k)$:

$$T(x) = \frac{x}{(1-x)^2} + \frac{2x}{1-x}\,T(x)$$

Solving: $T(x)\left[1 - \frac{2x}{1-x}\right] = \frac{x}{(1-x)^2}$, i.e., $T(x)\
cdot\frac{1-3x}{1-x} = \frac{x}{(1-x)^2}$, giving:

$$T(x) = \frac{x}{(1-x)(1-3x)} = \frac{1}{2}\left(\frac{1}{1-3x} - \frac{1}{1-x}
\right) = \sum_{n\ge 0} \frac{3^n - 1}{2}\,x^n$$

This confirms $T(n) = \frac{3^n - 1}{2}$.

**Step 6: Numerical check.**
- $T(1) = (3-1)/2 = 1$ ✓
- $T(2) = (9-1)/2 = 4$; check: $2 + 2\cdot1 = 4$ ✓
- $T(3) = (27-1)/2 = 13$; check: $3 + 2(1+4) = 13$ ✓
- $T(4) = (81-1)/2 = 40$; check: $4 + 2(1+4+13) = 4 + 36 = 40$ ✓

## Conclusion

$$T(n) = \frac{3^n - 1}{2} = \Theta(3^n)$$

The asymptotic order of $T(n)$ is $\boxed{\Theta(3^n)}$.
