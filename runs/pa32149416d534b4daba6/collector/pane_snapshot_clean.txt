# Solution

**Claim.** The possible values of the digit sum of a guayaquilean number are exa
ctly the positive integers congruent to $0$ or $1 \pmod{9}$.

Let $s(n)$ denote the sum of the decimal digits of $n$.

## Necessity

Recall the standard fact $s(n) \equiv n \pmod{9}$. If $n$ is guayaquilean, then
$s(n) = s(n^2)$, so
$$n \equiv s(n) = s(n^2) \equiv n^2 \pmod{9},$$
hence $n^2 - n = n(n-1) \equiv 0 \pmod{9}$. Since $\gcd(n, n-1) = 1$, this force
s $9 \mid n$ or $9 \mid (n-1)$, i.e.,
$$n \equiv 0 \text{ or } 1 \pmod{9}.$$
Therefore $s(n) \equiv n \pmod{9}$ gives $s(n) \equiv 0$ or $1 \pmod{9}$.

Since $n \geq 1$, we have $s(n) \geq 1$, so the digit sum is a positive integer
$\equiv 0$ or $1 \pmod{9}$.

## Sufficiency

We exhibit guayaquilean numbers realizing every positive integer $\equiv 0$ or $
1 \pmod{9}$.

**Values $\equiv 0 \pmod{9}$: $9k$ for $k \geq 1$.** Take $n = 10^k - 1 = \under
brace{99\ldots9}_{k}$, so $s(n) = 9k$. Then
$$n^2 = (10^k - 1)^2 = 10^{2k} - 2\cdot 10^k + 1 = \underbrace{99\ldots9}_{k-1}\
,8\,\underbrace{00\ldots0}_{k-1}\,1,$$
so $s(n^2) = 9(k-1) + 8 + 0 + 1 = 9k = s(n)$. Thus $n$ is guayaquilean with digi
t sum $9k$.

**Values $\equiv 1 \pmod{9}$: $9k+1$ for $k \geq 0$.** Take $n = 2\cdot 10^k - 1
 = 1\underbrace{99\ldots9}_{k}$ (for $k=0$ this is $n=1$), so $s(n) = 1 + 9k$. T
hen
$$n^2 = (2\cdot 10^k - 1)^2 = 4\cdot 10^{2k} - 4\cdot 10^k + 1 = 3\underbrace{99
\ldots9}_{k-1}\,6\,\underbrace{00\ldots0}_{k-1}\,1$$
(for $k \geq 1$; for $k=0$, $n^2 = 1$), giving
$$s(n^2) = 3 + 9(k-1) + 6 + 0 + 1 = 9k + 1 = s(n).$$
For $k=0$: $n=1$, $n^2=1$, $s(n)=s(n^2)=1$. Thus $n$ is guayaquilean with digit
sum $9k+1$.

## Conclusion

The necessary condition (digit sum $\equiv 0$ or $1 \pmod 9$, and positive) is a
lso sufficient, realized by the families $n = 10^k - 1$ and $n = 2\cdot 10^k - 1
$.

The set of all possible values of the digit sum of a guayaquilean number is
$$\boxed{\{\, m \in \mathbb{Z}_{>0} : m \equiv 0 \text{ or } 1 \pmod{9}\,\}} = \
{1, 9, 10, 18, 19, 27, 28, 36, 37, \ldots\}.$$
