## Setup and Analysis

**B's objective:** B wins when $F(k) < n$, so B minimizes $F(k)$ by choosing bot
h the partition and the function values. A wins iff $F_{\min}(k) \ge n$.

**Per-segment contribution.** For a segment of length $L = a_i - a_{i-1}$, the i
ntegers are $a_{i-1}, a_{i-1}+1, \ldots, a_i$ (that's $L+1$ integers). Setting $
j = a - a_{i-1} \in \{0, 1, \ldots, L\}$, B chooses $f(a) = \min(2j,\; L-j)$ for
 each $j$. Define:

$$S(L) = \sum_{j=0}^{L} \min(2j,\; L-j)$$

The crossover $2j = L-j$ gives $j = L/3$. Computing by cases:

- **$L = 3m$:** $S = \sum_{j=0}^{m} 2j + \sum_{j=m+1}^{3m}(3m-j) = m(m+1) + m(2m
-1) = 3m^2$
- **$L = 3m+1$:** $S = \sum_{j=0}^{m} 2j + \sum_{j=m+1}^{3m+1}(3m+1-j) = m(m+1)
+ m(2m+1) = 3m^2+2m$
- **$L = 3m+2$:** $S = \sum_{j=0}^{m} 2j + \sum_{j=m+1}^{3m+2}(3m+2-j) = m(m+1)
+ (2m+1)(m+1) = 3m^2+4m+1$

**Convexity.** The marginal differences $d(L) = S(L)-S(L-1)$ are:
$$d(3m)=2m,\quad d(3m+1)=2m,\quad d(3m+2)=2m+1$$
This sequence $0,1,2,2,3,4,4,5,6,6,\ldots$ is non-decreasing, so **$S$ is convex
**.

**Optimal partition.** By the exchange argument (convexity), to minimize $\sum_{
i=1}^k S(L_i)$ subject to $\sum L_i = 36$, $L_i \ge 1$ integers, B makes all $L_
i$ as equal as possible: if $36 = qk + r$ ($0 \le r < k$), then $r$ segments hav
e length $q+1$ and $k-r$ have length $q$.
