Looking at this problem, I need to find the maximum size of a subset $S \subsete
q \{1,\ldots,n\}$ such that for some $c$ with $1 \le c \le n/2$, no two elements
 of $S$ differ by exactly $c$.

## Setup

For a fixed $c$, the condition "$|s_1 - s_2| \neq c$ for all pairs" means $S$ is
 an independent set in the graph $G_c$ on vertices $\{1,\ldots,n\}$ with edges $
(i, i+c)$. This graph is a disjoint union of paths, one per residue class mod $c
$:

- Residue $r$ (for $r=1,\ldots,c$) forms the path $r, r+c, r+2c, \ldots$ up to $
\le n$.

Writing $n = qc + s$ with $0 \le s < c$: there are $s$ paths of length $q+1$ and
 $c-s$ paths of length $q$. The maximum independent set of a path with $m$ verti
ces is $\lceil m/2 \rceil$, so:

$$g(n,c) = s\left\lceil\frac{q+1}{2}\right\rceil + (c-s)\left\lceil\frac{q}{2}\r
ight\rceil, \quad f(n) = \max_{1 \le c \le \lfloor n/2 \rfloor} g(n,c).$$

## Summation

$$\sum_{n=4}^{20} f(n) = 2+3+4+4+5+6+6+7+8+8+9+10+10+11+12+12+13 = 130$$

## Proof of correctness

The key insight is that for each $c$, the "forbidden difference" graph $G_c$ (ed
ges between elements differing by $c$) decomposes into disjoint paths indexed by
 residue classes mod $c$. The maximum independent set of a path on $m$ vertices
is $\lceil m/2\rceil$ (take every other vertex starting from an endpoint). Since
 $f(n)$ maximizes over all valid $c$, and we've exhaustively checked every $c \l
e n/2$ for each $n$ from 4 to 20, the values above are exact.
