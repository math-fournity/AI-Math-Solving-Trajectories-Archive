## Solution

**Claim.** Yes, such a function exists.

**Proof.** Take $g(x) \equiv 0$ on $(a,b)$.

1. **$g$ is of class $C^{\infty}$.** The identically-zero function has every der
ivative identically zero: $g^{(n)}(x)=0$ for all $n\ge 0$ and all $x\in(a,b)$. H
ence $g\in C^{\infty}(a,b)$.

2. **$fg$ is differentiable everywhere.** For every $x\in(a,b)$,
$$
(fg)(x)=f(x)\,g(x)=f(x)\cdot 0 = 0.
$$
Thus $fg\equiv 0$, which is itself $C^{\infty}$ (hence differentiable) on all of
 $(a,b)$.

This construction uses **only** the continuity of $f$ (in fact it uses nothing a
bout $f$ at all), so it applies to every continuous $f$ on $(a,b)$, including th
ose that fail to be differentiable on any prescribed subset. $\blacksquare$

### Remarks (for completeness, on the nontrivial variants)

The literal statement imposes no condition on $g$ beyond smoothness, so the zero
 function is admissible and the answer is immediately **yes**. The question beco
mes more interesting under additional restrictions on $g$; the answer then depen
ds on the restriction:

- **If $g$ is required to be nowhere zero on $(a,b)$:** then $fg$ differentiable
 everywhere would force $f=\dfrac{fg}{g}$ to be differentiable everywhere (quoti
ent of a differentiable function by a smooth, nonvanishing function), contradict
ing the hypothesis. So in this case **no** such $g$ exists.

- **If $g$ is required to be not identically zero (but may vanish somewhere):**
the answer is **not always**. Key observation: at any point $c$ with $g(c)=0$,
  $$
  \frac{(fg)(x)-(fg)(c)}{x-c}=\frac{f(x)g(x)-0}{x-c}=f(x)\,\frac{g(x)-g(c)}{x-c}
\;\xrightarrow[x\to c]{}\;f(c)\,g'(c),
  $$
  since $f$ is continuous and $g$ is differentiable. So $fg$ is automatically di
fferentiable at every zero of $g$, regardless of whether $f$ is differentiable t
here. At points where $g\neq 0$, differentiability of $fg$ forces differentiabil
ity of $f$. Thus a nonzero smooth $g$ works **iff** the non-differentiability se
t $N(f)$ is contained in the zero set of some nonzero smooth function, i.e. iff
$N(f)$ is contained in a *proper closed* subset of $(a,b)$. This fails, for exam
ple, when $f$ is differentiable at exactly one point: taking a nowhere-different
iable continuous function $W$ and setting $f(x)=(x-p)W(x)$ gives a continuous $f
$ differentiable only at $p$, so $N(f)=(a,b)\setminus\{p\}$ is dense; any closed
 set containing it is all of $(a,b)$, forcing $g\equiv 0$.

Under the statement as written, however, no such restriction is imposed, so the
zero function provides a valid witness.
