## Proof

We recognize $J(\chi) = J(\chi,\chi)$ as a **Jacobi sum** over $\mathbb{F}_{p^2}
$ (with $q = p^2$). We use the standard convention $\chi(0) = 0$ for nontrivial
$\chi$.

### Setup: Gauss Sums and Key Identity

Let $\psi: \mathbb{F}_{p^2} \to \mathbb{C}^*$ be a nontrivial additive character
. Define the **Gauss sum** $g(\chi) = \sum_{a \in \mathbb{F}_{p^2}} \chi(a)\,\ps
i(a)$.

**Key Identity.** For nontrivial $\chi_1, \chi_2$ with $\chi_1\chi_2$ nontrivial
:
$$g(\chi_1)\,g(\chi_2) = J(\chi_1,\chi_2)\,g(\chi_1\chi_2).$$

*Proof.* Expand $g(\chi_1)g(\chi_2) = \sum_{a,b}\chi_1(a)\chi_2(b)\psi(a+b) = \s
um_t \psi(t)\sum_a \chi_1(a)\chi_2(t-a)$. For $t \neq 0$, substituting $a = tu$
gives $\sum_a \chi_1(a)\chi_2(t-a) = (\chi_1\chi_2)(t)\,J(\chi_1,\chi_2)$. For $
t=0$, the inner sum equals $\chi_2(-1)\sum_a(\chi_1\chi_2)(a) = 0$ since $\chi_1
\chi_2$ is nontrivial. Summing over $t \neq 0$ yields the identity. $\square$

**Standard fact.** For nontrivial $\chi$: $|g(\chi)|^2 = q = p^2$. (This follows
 from $g(\bar\chi) = \chi(-1)\overline{g(\chi)}$ and a direct orthogonality comp
utation.)

### Case 1: $\chi^2 = \varepsilon$ (Quadratic Character)

Here $\chi\bar\chi = \chi^2 = \varepsilon$, so the Key Identity does not apply d
irectly. We compute $g(\chi)g(\bar\chi)$ from first principles.

From the expansion above with $\chi_1 = \chi$, $\chi_2 = \bar\chi$ (so $\chi_1\c
hi_2 = \varepsilon$):
- For $t \neq 0$: $\sum_a \chi(a)\bar\chi(t-a) = J(\chi,\bar\chi)$.
- For $t = 0$: $\sum_a \chi(a)\bar\chi(-a) = \bar\chi(-1)\sum_a|\chi(a)|^2 = \ba
r\chi(-1)(q-1)$.

Therefore:
$$g(\chi)\,g(\bar\chi) = J(\chi,\bar\chi)\sum_{t\neq 0}\psi(t) + \bar\chi(-1)(q-
1) = -J(\chi,\bar\chi) + \bar\chi(-1)(q-1).$$

Using $g(\bar\chi) = \chi(-1)\overline{g(\chi)}$ and $|g(\chi)|^2 = q$:
$$g(\chi)\,g(\bar\chi) = \chi(-1)\,|g(\chi)|^2 = \chi(-1)\,q.$$

Equating:
$$\chi(-1)\,q = -J(\chi,\bar\chi) + \bar\chi(-1)(q-1).$$

Since $\chi$ is quadratic, $\bar\chi = \chi$, so $\bar\chi(-1) = \chi(-1)$:
$$J(\chi,\chi) = \chi(-1)(q-1) - \chi(-1)\,q = -\chi(-1).$$

**For $\mathbb{F}_{p^2}$ with $p$ odd:** $\chi(-1) = (-1)^{(p^2-1)/2}$. Since $p
$ is odd, $p^2 \equiv 1 \pmod{8}$, so $(p^2-1)/2$ is even, giving $\chi(-1) = 1$
. Thus:

$$\boxed{J(\chi) = -1.}$$

---

### Case 2: $\chi^2 \neq \varepsilon$ (and $\chi^2$ nontrivial)

Apply the Key Identity with $\chi_1 = \chi_2 = \chi$:
$$g(\chi)^2 = J(\chi,\chi)\,g(\chi^2).$$

Since $\chi$ and $\chi^2$ are both nontrivial, $|g(\chi)|^2 = q = p^2$ and $|g(\
chi^2)| = \sqrt{q} = p$. Therefore:

$$J(\chi) = \frac{g(\chi)^2}{g(\chi^2)}, \qquad |J(\chi)| = \frac{|g(\chi)|^2}{|
g(\chi^2)|} = \frac{p^2}{p} = p.$$

---

### Summary (Closed Form)

$$J(\chi) = \begin{cases} -\chi(-1) & \text{if } \chi^2 = \varepsilon \text{ (qu
adratic)}, \\[6pt] \dfrac{g(\chi)^2}{g(\chi^2)} \text{ with } |J(\chi)| = p & \t
ext{if } \chi^2 \neq \varepsilon. \end{cases}$$

In particular, for the **quadratic character** of $\mathbb{F}_{p^2}$ ($p$ odd),
the closed form is $J(\chi) = -1$. For any other non-trivial character, $J(\chi)
$ is a complex number of absolute value $p$, expressible as the ratio $g(\chi)^2
/g(\chi^2)$ of Gauss sums.
