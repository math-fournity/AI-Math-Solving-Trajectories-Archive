**Answer: Yes.**

**Construction.** The set ℚ of rational numbers is countable, so there exists an
 enumeration ℚ = {q₁, q₂, q₃, …}. Define a sequence (aₙ) by concatenating finite
 "blocks":

- Block 1: q₁
- Block 2: q₁, q₂
- Block 3: q₁, q₂, q₃
- Block k: q₁, q₂, …, qₖ

and so on. Explicitly the sequence is

q₁, q₁, q₂, q₁, q₂, q₃, q₁, q₂, q₃, q₄, …

**Every rational is a limit point.** Fix any rational r ∈ ℚ. Since {qₙ} enumerat
es ℚ, there is an index m with qₘ = r. For every block k ≥ m, the term qₘ = r ap
pears in block k. Hence r occurs infinitely many times in the sequence (aₙ). Sel
ecting the subsequence (aₙⱼ) consisting exactly of these occurrences gives a con
stant subsequence aₙⱼ = r for all j, which converges to r. Therefore r is a limi
t point of (aₙ).

Since r ∈ ℚ was arbitrary, **every rational number is a limit point** of (aₙ).

**Remark.** No hypothesis on uniqueness or on excluding irrationals is needed —
the question only asks that all rationals be limit points, which the constructio
n above achieves. (In fact this particular sequence also has many irrational lim
it points, but that is irrelevant to the claim.)
