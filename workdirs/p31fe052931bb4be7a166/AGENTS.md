# Problem

A specialized logistics firm manages a sequence of $n$ cargo containers, labeled consecutively from $1$ to $n$. Each container must be assigned to one of three shipping lines: the Red Fleet, the Blue Fleet, or the Yellow Fleet. The assignment process is governed by the following strict operational protocols:

(1) For any container $x$ assigned to a specific fleet, the very next container in the sequence (with a label greater than $x$) that is assigned to that same fleet must have a label with a different parity than $x$. (For example, if container 4 is Red, the next container assigned to the Red Fleet must be odd).

(2) If a manifest uses all three fleets, exactly one of those fleets must have an even-numbered container as its lowest-indexed shipment.

How many different ways can the $n$ containers be assigned to the three shipping lines while following these protocols?
