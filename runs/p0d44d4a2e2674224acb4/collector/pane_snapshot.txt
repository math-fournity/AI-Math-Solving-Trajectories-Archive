## Solution

We need positive integers $m < n$ with

$$\frac{1}{m}+\frac{1}{n}=\frac{3}{2008}.$$

**Step 1: Transform to a factored equation.**

Cross-multiplying: $3mn = 2008(m+n)$, i.e. $3mn - 2008m - 2008n = 0$. Multiplyin
g by $3$ and completing the product:

$$9mn - 3\cdot 2008\,m - 3\cdot 2008\,n = 0$$
$$(3m-2008)(3n-2008) = 2008^2.$$

Set $d = 3m-2008$, $e = 3n-2008$. Then $d\cdot e = 2008^2$, and $m<n$ gives $d<e
$.

**Step 2: Determine sign and congruence constraints.**

Since $de = 2008^2 > 0$, $d,e$ share sign. If both negative, $|e| = 2008^2/|d| >
 2008$ (as $|d|<2008$ is forced by $m>0$), giving $n<0$ — impossible. Hence $d,e
 > 0$.

Congruence: $2008 = 3\cdot 669 + 1$, so $2008 \equiv 1 \pmod{3}$, thus $d = 3m-2
008 \equiv -1 \equiv 2 \pmod{3}$. Likewise $e \equiv 2 \pmod{3}$. Since $de = 20
08^2 \equiv 1\pmod{3}$ and $d\equiv 2$, automatically $e\equiv 2$. So the only c
onstraint is $d\equiv 2\pmod{3}$.

With $d<e$ and $de = 2008^2$ (a perfect square), $d = e = 2008$ would give $m=n$
, excluded. So $d < 2008 < e$ strictly.

**Step 3: Factor and count.**

$$2008 = 2^3 \times 251,\qquad 251\text{ prime},\qquad 2008^2 = 2^6 \times 251^2
.$$

Every divisor $d = 2^a \cdot 251^b$ with $0\le a\le 6$, $0\le b\le 2$. Modulo 3:
 $2\equiv 2$, $251\equiv 2\pmod{3}$, so $d \equiv 2^{a+b}\pmod{3}$. The conditio
n $d\equiv 2\pmod{3}$ is equivalent to $a+b$ **odd**.

Now enumerate with $d < 2008 = 2^3\cdot 251$:

| $b$ | allowed $a$ (parity) | $d = 2^a\cdot 251^b$ | $d<2008$? |
|-----|----------------------|----------------------|-----------|
| 0 | $a\in\{1,3,5\}$ | $2,\ 8,\ 32$ | all ✓ (3) |
| 1 | $a\in\{0,2,4,6\}$ | $251,\ 1004,\ 4016,\ 16064$ | $251$✓, $1004$✓, rest ✗
(2) |
| 2 | $a\in\{1,3,5\}$ | $126002,\ \ldots$ | all ✗ (0) |

Total: $3 + 2 + 0 = \mathbf{5}$.

**Step 4: Verify the five pairs.**

| $d$ | $m=(d+2008)/3$ | $e=2008^2/d$ | $n=(e+2008)/3$ | check |
|-----|----------------|--------------|----------------|-------|
| 2 | 670 | 2016032 | 672680 | ✓ |
| 8 | 672 | 504008 | 168672 | ✓ |
| 32 | 680 | 126002 | 42670 | ✓ |
| 251 | 753 | 16064 | 6024 | ✓ |
| 1004 | 1004 | 4016 | 2008 | ✓ |

Each gives $m<n$ and $1/m+1/n = 3/2008$. No other divisors qualify.

## Answer

The number of distinct pairs $(m,n)$ is $\boxed{5}$.
