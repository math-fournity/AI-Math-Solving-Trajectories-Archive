## 解：非齐次线性系统 `y'(t) = Ay(t) + g(t)` 的通解

### 1. 齐次解

考虑齐次系统 `y'(t) = Ay(t)`，其中 `A` 为常数 `n×n` 矩阵。设 `y(t₀) = c`。通过将
候选解 `y(t) = e^{(t-t₀)A}c` 代入，并使用矩阵指数的定义性质，即 `d/dt e^{(t-t₀)A
} = A e^{(t-t₀)A}`（由 `A` 与其幂可交换的幂级数 `e^{(t-t₀)A} = Σ_{k=0}^∞ (t-t₀)^
k A^k / k!` 逐项求导得出），我们得到 `y'(t) = A e^{(t-t₀)A}c = Ay(t)`，且 `y(t₀)
 = c`。因此齐次解为：

$$\mathbf{y}_h(t) = e^{(t-t_0)A}\mathbf{c}, \quad \mathbf{c}\in\mathbb{R}^n.$$

### 2. 参数变易法（Duhamel 原理）

对于非齐次系统，我们寻找以下形式的解：

$$\mathbf{y}(t) = e^{(t-t_0)A}\,\mathbf{c}(t),$$

其中 `c(t)` 是一个待定函数（“变参数”）。求导：

$$\mathbf{y}'(t) = A\,e^{(t-t_0)A}\mathbf{c}(t) + e^{(t-t_0)A}\mathbf{c}'(t).$$

将其代入 `y'(t) = Ay(t) + g(t)` 中：

$$A\,e^{(t-t_0)A}\mathbf{c}(t) + e^{(t-t_0)A}\mathbf{c}'(t) = A\,e^{(t-t_0)A}\ma
thbf{c}(t) + \mathbf{g}(t).$$

消去公共项 `A e^{(t-t₀)A}c(t)`：

$$e^{(t-t_0)A}\mathbf{c}'(t) = \mathbf{g}(t).$$

由于对于所有 `t`，`e^{(t-t₀)A}` 都是可逆的（其逆矩阵为 `e^{-(t-t₀)A}`，由 `e^M e
^{-M}=I` 得出），我们得到：

$$\mathbf{c}'(t) = e^{-(t-t_0)A}\,\mathbf{g}(t).$$

从 `t₀` 到 `t` 积分，取 `c(t₀) = c₀`（任意常数向量）：

$$\mathbf{c}(t) = \mathbf{c}_0 + \int_{t_0}^{t} e^{-(s-t_0)A}\,\mathbf{g}(s)\,ds
.$$

### 3. 通解

代回原式：

$$\mathbf{y}(t) = e^{(t-t_0)A}\!\left[\mathbf{c}_0 + \int_{t_0}^{t} e^{-(s-t_0)A
}\,\mathbf{g}(s)\,ds\right].$$

由于 `e^{(t-t₀)A} e^{-(s-t₀)A} = e^{(t-s)A}`（矩阵指数的半群性质 `e^{P}e^{Q}=e^{
P+Q}`，当 `P=(t-t₀)A` 且 `Q=-(s-t₀)A` 时，它们可交换），这简化为：

$$\boxed{\mathbf{y}(t) = e^{(t-t_0)A}\,\mathbf{c}_0 + \int_{t_0}^{t} e^{(t-s)A}\
,\mathbf{g}(s)\,ds,\quad \mathbf{c}_0\in\mathbb{R}^n.}$$

### 4. 验证

- **初始条件：** 当 `t = t₀` 时，积分项消失（上限 = 下限），且 `e^{0·A} = I`，因
此 `y(t₀) = c₀`。 ✓
- **满足方程：** 对 `t` 求导：

$$\mathbf{y}'(t) = A\,e^{(t-t_0)A}\mathbf{c}_0 + \frac{d}{dt}\int_{t_0}^{t}e^{(t
-s)A}\mathbf{g}(s)\,ds.$$

利用莱布尼茨积分求导法则，积分项的导数为：

$$e^{(t-t)A}\mathbf{g}(t) + \int_{t_0}^{t} A\,e^{(t-s)A}\mathbf{g}(s)\,ds = \mat
hbf{g}(t) + A\int_{t_0}^{t}e^{(t-s)A}\mathbf{g}(s)\,ds.$$

因此：

$$\mathbf{y}'(t) = A\,e^{(t-t_0)A}\mathbf{c}_0 + A\int_{t_0}^{t}e^{(t-s)A}\mathb
f{g}(s)\,ds + \mathbf{g}(t) = A\,\mathbf{y}(t) + \mathbf{g}(t). \checkmark$$

### 5. 结构解释

通解是两项之和：

- **齐次（瞬态/自由）部分：** `y_h(t) = e^{(t-t₀)A}c₀` ——由初始条件 `c₀` 参数化
的齐次系统的通解。
- **特解（强迫/受迫）部分：** `y_p(t) = ∫_{t₀}^{t} e^{(t-s)A}g(s)ds` ——Duhamel
卷积，表示在时间 `s` 施加的输入 `g(s)` 的贡献，通过基础矩阵 `e^{(t-s)A` 传播到时
间 `t`。这对应于 `y_p(t₀) = 0`。

常数 `n` 维向量 `c₀ ∈ ℝⁿ` 是 `n` 个任意常数，提供了完整的 `n` 参数通解族。
