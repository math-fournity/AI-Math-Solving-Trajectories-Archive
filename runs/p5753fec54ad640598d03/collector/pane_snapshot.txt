Looking at this problem, I need to find how many distinct shapes (up to congruen
ce) can partition a 4×4 grid into 4 congruent pieces, where boundaries follow gr
id lines.

## Setup

Each piece has area 16/4 = 4, and must be a connected polyomino (union of unit s
quares). So each piece is a **tetromino**. There are exactly **5 free tetrominoe
s** (up to rotation and reflection): I, O, T, L, and S/Z. I need to determine wh
ich can tile the 4×4 grid with 4 copies.

## Constructive tilings (4 shapes work)

**I-tetromino (1×4 strip):** Four horizontal (or vertical) strips tile the 4×4 g
rid. ✓

**O-tetromino (2×2 square):** A 2×2 arrangement of 2×2 blocks tiles the grid. ✓

**T-tetromino:** Label cells (r,c). The four pieces are:
- T1 (stem down): (1,1),(1,2),(1,3),(2,2)
- T2 (stem up): (4,2),(4,3),(4,4),(3,3)
- T3 (stem right): (2,1),(3,1),(4,1),(3,2)
- T4 (stem left): (1,4),(2,4),(3,4),(2,3)

All 16 cells covered, no overlaps. ✓

**L-tetromino:** The four pieces are:
- L1: (1,1),(1,2),(1,3),(2,1)
- L2: (4,2),(4,3),(4,4),(3,4)
- L3: (1,4),(2,2),(2,3),(2,4)
- L4: (3,1),(3,2),(3,3),(4,1)

All 16 cells covered, no overlaps. ✓

## Impossibility for S/Z-tetromino

**Key observation:** No S/Z-tetromino can contain two corners of the 4×4 grid. I
n any orientation, the S/Z-tetromino spans at most 3 cells in any direction. Any
 two corners of the 4×4 grid are separated by at least 3 units in some direction
, but the S/Z spans only 3 *consecutive* cells — it cannot reach both endpoints
of a span of 4. Therefore each corner belongs to a distinct piece.

**Enumerating corner placements.** For each corner, I list every S/Z placement c
ontaining it:

- **(1,1):** A1 = {(1,1),(1,2),(2,2),(2,3)} [Z-h] or A2 = {(1,1),(2,1),(2,2),(3,
2)} [S-v]
- **(1,4):** B1 = {(1,3),(1,4),(2,2),(2,3)} [S-h] or B2 = {(1,4),(2,3),(2,4),(3,
3)} [Z-v]
- **(4,1):** C1 = {(3,2),(3,3),(4,1),(4,2)} [S-h], C2 = {(3,1),(3,2),(4,2),(4,3)
} [Z-h], or C3 = {(2,2),(3,1),(3,2),(4,1)} [Z-v]
- **(4,4):** D1 = {(3,2),(3,3),(4,3),(4,4)} [Z-h] or D2 = {(2,3),(3,3),(3,4),(4,
4)} [S-v]

**Checking pairwise disjointness:**

*Top corners (A vs B):*
- A1 ∩ B1 = {(2,2),(2,3)} — overlap ✗
- A1 ∩ B2 = {(2,3)} — overlap ✗
- A2 ∩ B1 = {(2,2)} — overlap ✗
- A2 ∩ B2 = {} — disjoint ✓

So the **only** viable top-corner assignment is A2 + B2.

*Bottom-left corner (A2 vs C):*
- A2 ∩ C1 = {(3,2)} — overlap ✗
- A2 ∩ C2 = {(3,2)} — overlap ✗
- A2 ∩ C3 = {(2,2),(3,2)} — overlap ✗

A2 conflicts with **every** option for (4,1). Since A2 is forced by the top corn
ers, no valid tiling exists.

**Conclusion:** The S/Z-tetromino cannot tile the 4×4 grid. ✗

## Answer

Of the 5 free tetrominoes, exactly **4** (I, O, T, L) can tile the 4×4 grid into
 4 congruent pieces. The S/Z-tetromino cannot.
