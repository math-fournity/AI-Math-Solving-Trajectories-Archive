of 1000 distinct positive integers, all $\le 2014$, with $a_1 < \dots < a_{1000}
$, such that whenever $i + j \le 1000$, we have $a_i + a_j \in S$.

## Key Observation: Forcing Arithmetic Progression

**Step 1: The translate $\{a_1 + a_j\}$ almost fills $S$.**

Setting $i = 1$: for every $j$ with $1 + j \le 1000$ (i.e., $j = 1, \dots, 999$)
, we need $a_1 + a_j \in S$.

Since the $a_j$ are distinct, the 999 values $a_1 + a_1, a_1 + a_2, \dots, a_1 +
 a_{999}$ are **distinct** elements of $S$.

**Step 2: $a_1$ is not among these 999 values.**

Every $a_1 + a_j \ge a_1 + a_1 = 2a_1 > a_1$ (since $a_1 \ge 1$). So $a_1 \notin
 \{a_1 + a_j : 1 \le j \le 999\}$.

**Step 3: $S$ is exactly $\{a_1\} \cup \{a_1 + a_j : 1 \le j \le 999\}$.**

$S$ has 1000 elements. The set $\{a_1 + a_j : 1 \le j \le 999\}$ contributes 999
 distinct elements of $S$, and $a_1$ is a 1000th element not in that set. Theref
ore:

$$S = \{a_1\} \cup \{a_1 + a_j : 1 \le j \le 999\}.$$

**Step 4: The sorted order forces an arithmetic progression.**

The elements $a_1 + a_1 < a_1 + a_2 < \dots < a_1 + a_{999}$ are the 999 largest
 elements of $S$ (since $a_1 < 2a_1$). Matching with the sorted order $a_1 < a_2
 < \dots < a_{1000}$:

$$a_{k+1} = a_1 + a_k \quad \text{for } k = 1, 2, \dots, 999.$$

This recurrence gives $a_{k+1} - a_k = a_1$ (constant), so:

$$a_k = k \cdot a_1 \quad \text{for all } k = 1, \dots, 1000.$$

**Step 5: Determine valid $a_1$.**

We need $a_{1000} = 1000 \cdot a_1 \le 2014$, so $a_1 \le \lfloor 2014/1000 \rfl
oor = 2$.

Since $a_1$ is a positive integer: $a_1 \in \{1, 2\}$.

**Step 6: Verify both candidates satisfy all conditions.**

For $a_k = k \cdot c$ with $c \in \{1, 2\}$: whenever $i + j \le 1000$,

$$a_i + a_j = c \cdot i + c \cdot j = c(i+j) = a_{i+j} \in S.$$

- **$c = 1$:** $S = \{1, 2, \dots, 1000\}$, max element $1000 \le 2014$. ✓
- **$c = 2$:** $S = \{2, 4, \dots, 2000\}$, max element $2000 \le 2014$. ✓

Both satisfy the condition for **all** pairs $(i, j)$ with $i + j \le 1000$, not
 just those with $i = 1$.

## Conclusion

The derivation shows any valid set must be an arithmetic progression $\{c, 2c, \
dots, 1000c\}$ with common difference $c = a_1$, and the bound $1000c \le 2014$
restricts $c$ to $\{1, 2\}$. Both values yield valid sets.

The total number of different sets of ID numbers satisfying the requirements is
$\boxed{2}$.
