## Proof

**Step 1: The polynomial R' + R² must be identically zero.**

Since lim_{t→∞} R(t) = 0, we have deg P < deg Q, so R is a proper rational funct
ion. Then R' = (P'Q − PQ')/Q² has numerator of degree at most deg P + deg Q − 1
< 2·deg Q = deg(Q²), so R' is also proper and lim_{t→∞} R'(t) = 0. Likewise R(t)
² → 0. Therefore

$$\lim_{t\to\infty}\bigl(R'(t)+R(t)^2\bigr) = 0.$$

But R' + R² is assumed to be a polynomial. The only polynomial that tends to 0 a
t infinity is the zero polynomial. Hence

$$R'(t) + R(t)^2 = 0, \quad\text{i.e.,}\quad R' = -R^2. \tag{$\star$}$$

**Step 2: Solve the ODE R' = −R² among rational functions.**

**Case A: R ≡ 0.** This satisfies ($\star$) and lim R = 0. ✓

**Case B: R is not identically zero.** Then R is nonzero on some open interval,
and on that interval we may divide by R²:

$$-\frac{R'}{R^2} = 1 \implies \frac{d}{dt}\!\left(\frac{1}{R}\right) = 1 \impli
es \frac{1}{R(t)} = t - a$$

for some constant a. Hence R(t) = 1/(t − a). This is indeed a rational function.
 Since R is real-valued (real for real t where defined), the constant a must be
**real** (if a = α + iβ with β ≠ 0, then 1/(t−a) is not real for real t).

**Verification:** For R(t) = 1/(t − a) with a ∈ ℝ:
- R'(t) = −1/(t−a)² and R(t)² = 1/(t−a)², so R' + R² = 0, a polynomial. ✓
- lim_{t→∞} 1/(t−a) = 0. ✓

**Step 3: Confirm these are the only solutions.**

Equation ($\star$) is a first-order ODE. Its solutions are uniquely determined b
y the value at any point where R ≠ 0: the general nonzero solution is R(t) = 1/(
t − a), and R ≡ 0 is the unique solution through any point where R = 0. Since R
is a rational function (hence meromorphic), the identity R' = −R² extends global
ly, so no other rational solutions exist.

---

## Conclusion

The real-valued rational functions satisfying both conditions are exactly:

$$\boxed{R(t) = 0 \quad\text{and}\quad R(t) = \frac{1}{t - a}\ \text{for any } a
 \in \mathbb{R}.}$$
