## Solution

We seek the stationary function of the functional
$$J[y] = \int_1^{\infty} \bigl(x^2\, y'^2 + 2\,y^2\bigr)\,dx, \qquad y(1)=2,$$
where the upper limit is free (at infinity) and no condition is imposed there, s
o a natural (transversality) boundary condition applies.

### Euler–Lagrange Equation

With $F(x,y,y') = x^2 y'^2 + 2y^2$:

$$\frac{\partial F}{\partial y} = 4y, \qquad \frac{\partial F}{\partial y'} = 2x
^2 y', \qquad \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right) = 2x^2 y
'' + 4x\,y'.$$

The Euler–Lagrange equation $\frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\
partial F}{\partial y'} = 0$ gives:

$$4y - 2x^2 y'' - 4x\,y' = 0 \quad\Longrightarrow\quad x^2 y'' + 2x\,y' - 2y = 0
.$$

### Solving the Cauchy–Euler Equation

This is a Cauchy–Euler equation. Setting $y = x^m$:

$$m(m-1) + 2m - 2 = 0 \;\Longrightarrow\; m^2 + m - 2 = 0 \;\Longrightarrow\; (m
+2)(m-1)=0,$$

so $m = 1$ or $m = -2$. The general solution is:

$$y(x) = c_1\, x + c_2\, x^{-2}.$$

### Boundary Conditions

**At $x = 1$ (fixed endpoint):** $y(1) = c_1 + c_2 = 2$.

**At $x \to \infty$ (free endpoint — natural boundary condition):** The natural
boundary condition requires

$$\lim_{x\to\infty} \frac{\partial F}{\partial y'} = \lim_{x\to\infty} 2x^2\, y'
(x) = 0.$$

Computing $y' = c_1 - 2c_2\, x^{-3}$, we get

$$2x^2 y' = 2c_1\, x^2 - \frac{4c_2}{x}.$$

As $x \to \infty$, the term $2c_1 x^2 \to \infty$ unless $c_1 = 0$. Therefore $c
_1 = 0$.

Substituting into $y(1) = c_1 + c_2 = 2$ gives $c_2 = 2$.

### Verification

The stationary function is:

$$\boxed{y(x) = \frac{2}{x^2}}.$$

**Check the Euler–Lagrange equation:** $y = 2x^{-2}$, $y' = -4x^{-3}$, $y'' = 12
x^{-4}$.

$$x^2(12x^{-4}) + 2x(-4x^{-3}) - 2(2x^{-2}) = 12x^{-2} - 8x^{-2} - 4x^{-2} = 0.\
;\checkmark$$

**Check $y(1) = 2$:** $y(1) = 2/1 = 2$. ✓

**Check the natural BC:** $2x^2 y' = 2x^2(-4x^{-3}) = -8/x \to 0$ as $x \to \inf
ty$. ✓

**Finiteness of $J$:** $x^2 y'^2 = x^2 \cdot 16x^{-6} = 16x^{-4}$, $2y^2 = 8x^{-
4}$, so

$$J = \int_1^{\infty} 24\,x^{-4}\,dx = 24\left[-\frac{x^{-3}}{3}\right]_1^{\inft
y} = \frac{24}{3} = 8 < \infty. \;\checkmark$$
