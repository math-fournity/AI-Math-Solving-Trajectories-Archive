## Solution

**Setup.** Let $n = 1992$ and $k = n+1 = 1993$. Since $x^3 - x = x(x-1)(x+1)$, w
e perform partial fractions:

$$\frac{p(x)}{x(x-1)(x+1)} = r(x) + \frac{A}{x} + \frac{B}{x-1} + \frac{C}{x+1}$
$

where $r(x)$ is the polynomial part and
$$A = \frac{p(0)}{(0-1)(0+1)} = -p(0),\quad B = \frac{p(1)}{1\cdot 2} = \frac{p(
1)}{2},\quad C = \frac{p(-1)}{(-1)(-2)} = \frac{p(-1)}{2}.$$

By hypothesis $p(0), p(1), p(-1) \neq 0$, so $A, B, C \neq 0$.

**Polynomial part vanishes.** Since $\deg p \leq 1991$, we have $\deg r \leq 198
8 < n = 1992$, so $r^{(n)}(x) = 0$.

**Computing the $n$-th derivative.** Using $\frac{d^n}{dx^n}\frac{1}{(x-a)^1} =
\frac{(-1)^n\, n!}{(x-a)^{n+1}}$:

$$\left(\frac{p(x)}{x^3-x}\right)^{(n)} = (-1)^n\, n!\left[\frac{A}{x^k} + \frac
{B}{(x-1)^k} + \frac{C}{(x+1)^k}\right], \quad k = 1993.$$

**Common denominator.** Placing over $g(x) = x^k(x-1)^k(x+1)^k = (x^3-x)^k$ (deg
ree $3k = 5979$):

$$f(x) = (-1)^n\, n!\Big[A(x^2-1)^k + B(x^2+x)^k + C(x^2-x)^k\Big].$$

Each of the three polynomials $P_0 = (x^2-1)^k$, $P_+ = (x^2+x)^k$, $P_- = (x^2-
x)^k$ has degree $2k = 3986$.

**Linear independence.** Evaluating at $x = 0, 1, -1$:

| | $x=0$ | $x=1$ | $x=-1$ |
|---|---|---|---|
| $P_0$ | $(-1)^k$ | $0$ | $0$ |
| $P_+$ | $0$ | $2^k$ | $0$ |
| $P_-$ | $0$ | $0$ | $2^k$ |

This diagonal matrix (non-zero entries) confirms $P_0, P_+, P_-$ are linearly in
dependent, so they span a 3-dimensional space $V$.

**Minimizing the degree.** Setting $t = 1/x$, we write $F(x) = x^{2k}\, H(t)$ wh
ere
$$H(t) = A(1-t^2)^k + B(1+t)^k + C(1-t)^k.$$
The degree of $F$ equals $2k - m$ where $m$ is the order of vanishing of $H$ at
$t = 0$.

- $H(0) = A + B + C = 0$ gives the first condition.
- $H'(0) = k(B - C) = 0$ gives $B = C$.

These two conditions determine $(A, B, C)$ up to scale: $A = -2,\; B = C = 1$ (a
ll non-zero ✓). With 3 parameters and 1 lost to scaling, we can impose at most *
*2** independent conditions, so we can cancel at most the top 2 coefficients.

**The third coefficient is non-zero.** With $A = -2, B = C = 1$:
$$H(t) = -2(1-t^2)^k + (1+t)^k + (1-t)^k.$$
The coefficient of $t^2$ is $-2\cdot(-1)\binom{k}{1} + 2\binom{k}{2} = 2k + k(k-
1) = k(k+1) = 1993 \cdot 1994 \neq 0$.

So $H$ vanishes to order exactly 2 at $t=0$, giving $\deg F = 2k - 2 = 3984$.

**No reduction possible.** We check whether $f$ shares factors with $g = x^k(x-1
)^k(x+1)^k$:
- $f(0) = A(-1)^k \neq 0$, so $x \nmid f$.
- $f(1) = B\cdot 2^k \neq 0$, so $(x-1) \nmid f$.
- $f(-1) = C\cdot 2^k \neq 0$, so $(x+1) \nmid f$.

Thus $f/g$ is already in lowest terms—no cancellation reduces $\deg f$.

**Achievability.** The choice $A = -2, B = C = 1$ corresponds to $p(0) = 2,\; p(
1) = 2,\; p(-1) = 2$, realized by the constant polynomial $p(x) = 2$ (degree $0
< 1992$, all values non-zero ✓).

**Conclusion.** The smallest possible degree of $f(x)$ is

$$\boxed{3984}$$
