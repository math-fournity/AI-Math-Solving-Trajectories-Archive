## Setup

tex C is found from the side lengths. With AC = √5/2, BC = √2:

- x₀² + h² = 5/4, (x₀ − 3/2)² + h² = 2
- Subtracting: 3x₀ − 9/4 = −3/4, so x₀ = 1/2, h = 1.
- **C = (1/2, 1).** Triangle area = ½ · (3/2) · 1 = 3/4.

The left edge (A to C) is x = y/2; the right edge (C to B) is x = 3/2 − y. At he
ight y ∈ [0, 1], the triangle spans x ∈ [y/2, 3/2 − y].

## Folding Analysis

The fold line x = t (perpendicular to the longest side) divides the triangle. Fo
ld the left part (x ≤ t) over to the right by reflection. The reflected left par
t at height y spans x ∈ [t, 2t − y/2]. The stationary right part spans x ∈ [t, 3
/2 − y].

**Overlap width** at height y = min(2t − y/2, 3/2 − y) − t.

Both parts exist when y ≤ min(2t, 3/2 − t). The crossover between the two cases
of the min occurs at y = 3 − 4t.

**Case A** (y ≤ 3 − 4t): width = t − y/2.
**Case B** (y > 3 − 4t): width = 3/2 − t − y.

## Computing the Area

**Range t ∈ [0, 1/2]:** min(2t, 3/2−t) = 2t, and 3−4t ≥ 1 ≥ 2t, so always Case A
.
$$A(t) = \int_0^{2t}\!\left(t - \tfrac{y}{2}\right)dy = t^2.$$
Maximum at t = 1/2: A = 1/4.

**Range t ∈ [1/2, 3/4]:** min(2t, 3/2−t) = 3/2−t, and 0 < 3−4t < 3/2−t. Split at
 y = 3−4t:
$$A(t) = \int_0^{3-4t}\!\left(t-\tfrac{y}{2}\right)dy + \int_{3-4t}^{3/2-t}\!\le
ft(\tfrac{3}{2}-t-y\right)dy.$$
The second integral evaluates to (3t − 3/2)²/2 (it is ½(a−b)² with a = 3/2−t, b
= 3−4t). The first integral is (3−4t)(2t − 3/4). Combining:
$$A(t) = -\tfrac{7}{2}t^2 + \tfrac{9}{2}t - \tfrac{9}{8}.$$
This is a downward parabola; vertex at t = 9/14 ∈ (1/2, 3/4). ✓

$$A(9/14) = -\tfrac{7}{2}\cdot\tfrac{81}{196} + \tfrac{9}{2}\cdot\tfrac{9}{14} -

+ 1134 - 441}{392} = \tfrac{126}{392} = \tfrac{9}{28}.$$

**Range t ∈ [3/4, 3/2]:** 3−4t ≤ 0, always Case B. A(t) = (3/2−t)²/2, decreasing
