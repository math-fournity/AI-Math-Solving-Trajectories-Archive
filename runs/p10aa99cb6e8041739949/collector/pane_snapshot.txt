## Proof

Let $X$ be a continuous random variable with cumulative distribution function $F
_X$, and let $U = F_X(X)$.

**Claim:** $U \sim \mathrm{Uniform}(0,1)$, hence $E[F_X(X)] = E[U] = \tfrac{1}{2
}$.

**Step 1: $U$ takes values in $[0,1]$.**

Since $F_X$ is a CDF, $0 \le F_X(x) \le 1$ for all $x$, so $U = F_X(X) \in [0,1]
$ almost surely.

**Step 2: The CDF of $U$.**

For any $u \in [0,1]$, compute $P(U \le u) = P(F_X(X) \le u)$.

Since $X$ is continuous, $F_X$ is continuous. Define the quantile function
$$F_X^{-1}(u) = \inf\{x : F_X(x) \ge u\}.$$

Because $F_X$ is continuous, we have the key property:
$$F_X(x) \le u \iff x \le F_X^{-1}(u).$$

(The forward direction $x \le F_X^{-1}(u) \Rightarrow F_X(x) \le u$ holds by def
inition of infimum and monotonicity. The reverse direction $F_X(x) \le u \Righta
rrow x \le F_X^{-1}(u)$ holds because if $x > F_X^{-1}(u)$, then by continuity o
f $F_X$ and the definition of $F_X^{-1}$ as an infimum, there exists $y$ with $F
_X^{-1}(u) \le y < x$ and $F_X(y) \ge u$, so $F_X(x) \ge F_X(y) \ge u$, contradi
cting $F_X(x) \le u$ when the inequality is strict; continuity rules out the bou
ndary issue.)

Therefore:
$$P(U \le u) = P(F_X(X) \le u) = P(X \le F_X^{-1}(u)) = F_X(F_X^{-1}(u)).$$

By continuity of $F_X$ and the definition of $F_X^{-1}$, $F_X(F_X^{-1}(u)) = u$
for all $u \in [0,1]$.

**Step 3: Conclusion.**

We have shown $P(U \le u) = u$ for all $u \in [0,1]$, which is exactly the CDF o
f a $\mathrm{Uniform}(0,1)$ random variable. Hence
$$U = F_X(X) \sim \mathrm{Uniform}(0,1).$$

Therefore:
$$\boxed{E[F_X(X)] = \frac{1}{2}}$$
