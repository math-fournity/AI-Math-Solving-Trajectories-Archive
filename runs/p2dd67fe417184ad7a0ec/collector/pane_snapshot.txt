## Solution

We seek the curve $y(x)$ passing through $(0,0)$ and $(1,1)$ that extremizes

$$J[y] = \int \left\{ [y'(x)]^2 + 12x\,y(x) \right\} dx.$$

### Step 1. The Euler–Lagrange equation

Let the integrand be

$$F(x, y, y') = (y')^2 + 12x\,y.$$

A necessary condition for $y(x)$ to be an extremal is the Euler–Lagrange equatio
n:

$$\frac{\partial F}{\partial y} - \frac{d}{dx}\!\left(\frac{\partial F}{\partial
 y'}\right) = 0.$$

Computing the partial derivatives:

$$\frac{\partial F}{\partial y} = 12x, \qquad \frac{\partial F}{\partial y'} = 2
y'.$$

Hence

$$\frac{d}{dx}(2y') = 2y'',$$

and the Euler–Lagrange equation becomes

$$12x - 2y'' = 0 \quad\Longrightarrow\quad y'' = 6x.$$

### Step 2. Solve the ODE

Integrating once:

$$y' = 3x^2 + C_1.$$

Integrating again:

$$y = x^3 + C_1 x + C_2.$$

### Step 3. Apply the boundary conditions

The curve must pass through $(0,0)$ and $(1,1)$:

- $y(0) = 0 \;\Longrightarrow\; 0 + 0 + C_2 = 0 \;\Longrightarrow\; C_2 = 0.$
- $y(1) = 1 \;\Longrightarrow\; 1 + C_1 + 0 = 1 \;\Longrightarrow\; C_1 = 0.$

Therefore the extremal is

$$\boxed{y = x^3}.$$

### Step 4. Verify it is a (weak) minimum

Apply the **Legendre necessary condition**: a sufficient condition for a minimum
 requires $F_{y'y'} \ge 0$ along the extremal. Here

$$F_{y'y'} = \frac{\partial^2 F}{\partial (y')^2} = 2 > 0 \quad \text{for all }
x,$$

so the strengthened Legendre condition is satisfied. Combined with the fact that
 the extremal $y = x^3$ has no conjugate points on $[0,1]$ (the Jacobi equation
$\eta'' = 0$ with $\eta(0)=0$ gives $\eta = kx$, which vanishes again only at $x
=0$), the **Jacobi condition** is also satisfied. Hence $y = x^3$ furnishes a **
weak minimum** of the functional.

### Verification

With $y = x^3$, $y' = 3x^2$:

- $y(0) = 0$ ✓, $y(1) = 1$ ✓.
- $y'' = 6x$, so $12x - 2y'' = 12x - 12x = 0$ ✓ — the Euler–Lagrange equation is
 satisfied.

### Conclusion

The curve passing through $(0,0)$ and $(1,1)$ that is an extremal for the given
functional is

$$y(x) = x^3,$$

and it yields a weak minimum of $J$.
