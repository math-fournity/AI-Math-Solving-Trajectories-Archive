# Problem

A high-security circular data ring consists of 60 individual server nodes linked in a continuous loop. To ensure data diversity, the network administrator has assigned specific security protocols to each node: 30 nodes are programmed with Red-level encryption, 20 nodes with Blue-level encryption, and 10 nodes with Green-level encryption.

The connections (links) between adjacent nodes in the loop incur different maintenance costs based on the encryption protocols of the two servers they connect:
- A link connecting a Red node and a Green node costs 1 unit.
- A link connecting a Red node and a Blue node costs 2 units.
- A link connecting a Blue node and a Green node costs 3 units.
- Any link connecting two nodes of the same encryption level (Red-Red, Blue-Blue, or Green-Green) costs 0 units.

The administrator wants to arrange the 60 nodes around the ring in an order that maximizes the total maintenance cost of all 60 links. What is the greatest possible sum of these costs?
