## Proof

**Claim:** Yes. Every distributional solution $x \in \mathcal{D}'(\mathbb{R})$ o
f $x' = x$ is of the form $x = Ce^{t}$ for some constant $C \in \mathbb{R}$.

---

### Step 1. Reduce to "$T' = 0 \Rightarrow T = \text{const}$" via an integrating
 factor

Recall that for a smooth function $f \in C^{\infty}(\mathbb{R})$ and a distribut
ion $T \in \mathcal{D}'(\mathbb{R})$, the product $fT$ is well-defined and satis
fies the Leibniz rule
$$(fT)' = f'\,T + f\,T'.$$

Define the distribution
$$y := e^{-t}\,x \;\in\; \mathcal{D}'(\mathbb{R}).$$

Then
$$y' = (e^{-t})'\,x + e^{-t}\,x' = -e^{-t}x + e^{-t}x' = e^{-t}(x' - x) = e^{-t}
\cdot 0 = 0.$$

So the problem reduces to the classical lemma:

> **Lemma.** If $T \in \mathcal{D}'(\mathbb{R})$ and $T' = 0$, then $T$ is a con
stant (i.e. $T = C$ for some $C \in \mathbb{R}$, identified with the regular dis
tribution $\phi \mapsto C\!\int\!\phi$).

---

### Step 2. Prove the lemma

$T' = 0$ means, by definition of distributional derivative,
$$\langle T', \varphi\rangle = -\langle T, \varphi'\rangle = 0 \quad\text{for al
l } \varphi \in \mathcal{D}(\mathbb{R}),$$
hence
$$\langle T, \varphi'\rangle = 0 \quad\text{for all } \varphi \in \mathcal{D}(\m
athbb{R}). \tag{$\ast$}$$

**Characterization of derivatives of test functions.** A test function $\psi \in
 \mathcal{D}(\mathbb{R})$ equals $\varphi'$ for some $\varphi \in \mathcal{D}(\m
athbb{R})$ if and only if $\int_{\mathbb{R}} \psi = 0$.

*Proof.* Necessity: $\int \varphi' = \varphi(+\infty) - \varphi(-\infty) = 0$. S
ufficiency: set $\varphi(t) = \int_{-\infty}^{t} \psi(s)\,ds$; since $\psi$ is c
ompactly supported with total integral $0$, this $\varphi$ is also compactly sup
ported, and $\varphi' = \psi$. ∎

From $(\ast)$ and the characterization,
$$\langle T, \psi\rangle = 0 \quad\text{for every } \psi \in \mathcal{D}(\mathbb
{R}) \text{ with } \textstyle\int \psi = 0. \tag{$\ast\ast$}$$

**Decomposition of an arbitrary test function.** Fix once and for all a test fun
ction $\rho \in \mathcal{D}(\mathbb{R})$ with $\int \rho = 1$. For any $\phi \in
 \mathcal{D}(\mathbb{R})$, set
$$\psi := \phi - \Big(\textstyle\int \phi\Big)\,\rho.$$
Then $\int \psi = \int\phi - (\int\phi)(\int\rho) = 0$, so by $(\ast\ast)$, $\la
ngle T, \psi\rangle = 0$. Therefore
$$\langle T, \phi\rangle = \Big(\textstyle\int \phi\Big)\,\langle T, \rho\rangle
 + \langle T, \psi\rangle = \Big(\textstyle\int \phi\Big)\,\langle T, \rho\rangl
e.$$

Let $C := \langle T, \rho\rangle \in \mathbb{R}$. Then for every $\phi$,
$$\langle T, \phi\rangle = C\!\int_{\mathbb{R}}\phi(t)\,dt = \langle C, \phi\ran
gle,$$
which is exactly the statement $T = C$ as a distribution. ∎ (Lemma)

---

### Step 3. Conclude

Applying the lemma to $y = e^{-t}x$ with $y' = 0$, there exists $C \in \mathbb{R
}$ such that
$$e^{-t}\,x = C \quad\text{in } \mathcal{D}'(\mathbb{R}).$$

Multiplying both sides by the nowhere-vanishing smooth function $e^{t}$ (multipl
ication by $e^{t}$ is an automorphism of $\mathcal{D}'(\mathbb{R})$),
$$x = C\,e^{t} \quad\text{in } \mathcal{D}'(\mathbb{R}).$$

### Step 4. Converse (sanity check)

The regular distribution $x = Ce^{t}$ satisfies
$$x' = (Ce^{t})' = Ce^{t} = x,$$
so every such distribution is indeed a solution.

---

### Conclusion

The classical result **does** extend to the distributional setting: the full sol
ution set of $x' = x$ in $\mathcal{D}'(\mathbb{R})$ is
$$\boxed{\,x = Ce^{t},\quad C \in \mathbb{R}\,}.$$

The key ingredients are (i) the Leibniz rule for the product of a smooth functio
n with a distribution, which lets the classical integrating factor $e^{-t}$ go t
hrough unchanged, and (ii) the rigidity of distributions on $\mathbb{R}$ — a dis
tribution with zero derivative is necessarily a constant, so no "hidden" singula
r solutions (such as those supported at a point) can appear. (Indeed, any distri
bution supported at a single point is a finite linear combination of derivatives
 of the Dirac delta, and none of these except $0$ can satisfy $T' = T$.)
