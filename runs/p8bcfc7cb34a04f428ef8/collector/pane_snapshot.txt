**Problem.** Find all $f:\mathbb{R}^+\to\mathbb{R}^+$ such that for each $x\in\m
athbb{R}^+$, there is exactly one $y\in\mathbb{R}^+$ with $xf(y)+yf(x)\le 2$.

**Answer.** $f(x)=\dfrac{1}{x}$.

---

**Proof.**

**Verification.** For $f(x)=1/x$: $xf(y)+yf(x)=x/y+y/x\ge 2$ by AM-GM, with equa
lity iff $x=y$. So $xf(y)+yf(x)\le 2$ iff $y=x$; the unique $y$ is $y=x$. ✓

**Uniqueness.** For each $x>0$ let $S_x=\{y>0:xf(y)+yf(x)\le 2\}$. By hypothesis
 $|S_x|=1$; write $S_x=\{\sigma(x)\}$.

*Step 1: $\sigma$ is an involution.* Since $xf(y)+yf(x)$ is symmetric in $x,y$:
$y\in S_x\iff x\in S_y$. As $S_x=\{\sigma(x)\}$, we get $\sigma(x)\in S_x\Righta
rrow x\in S_{\sigma(x)}\Rightarrow x=\sigma(\sigma(x))$.

*Step 2: $\sigma(x)=x$ for all $x$.* Suppose $\sigma(x_0)\ne x_0$ for some $x_0$
. Set $g(t):=tf(t)$.

- Since $x_0\notin S_{x_0}=\{\sigma(x_0)\}$: $2x_0 f(x_0)>2$, so $g(x_0)>1$.
- Since $\sigma(x_0)\notin S_{\sigma(x_0)}=\{x_0\}$: $g(\sigma(x_0))>1$.
- Since $\sigma(x_0)\in S_{x_0}$: $\dfrac{x_0}{\sigma(x_0)}g(\sigma(x_0))+\dfrac
{\sigma(x_0)}{x_0}g(x_0)\le 2$.

But $g(x_0)>1$ and $g(\sigma(x_0))>1$ give
$$\frac{x_0}{\sigma(x_0)}g(\sigma(x_0))+\frac{\sigma(x_0)}{x_0}g(x_0)>\frac{x_0}
{\sigma(x_0)}+\frac{\sigma(x_0)}{x_0}\ge 2,$$
contradicting $\le 2$. Hence $\sigma(x)=x$ for all $x$.

*Step 3: Consequences of $\sigma(x)=x$.* For every $x$: $x\in S_x$ gives $2xf(x)
\le 2$, i.e.
$$g(x)\le 1\quad\text{for all }x>0.$$
For $y\ne x$: $y\notin S_x$ gives
$$\frac{x}{y}\,g(y)+\frac{y}{x}\,g(x)>2\quad\text{for all }x\ne y.\tag{$*$}$$

*Step 4: $g\equiv 1$.* Suppose for contradiction that $g(x_0)=c<1$ for some $x_0
$. Apply $(*)$ with $x=x_0$ and $y=x_0 s$ ($s>0,\,s\ne 1$):
$$\frac{1}{s}\,g(x_0 s)+s\,c>2\quad\Longrightarrow\quad g(x_0 s)>2s-cs^2.$$
Choose $s=1/c$ (valid since $c<1\Rightarrow s>1\ne 1$ and $s>0$):
$$g\!\left(\frac{x_0}{c}\right)>\frac{2}{c}-\frac{c}{c^2}=\frac{2}{c}-\frac{1}{c
}=\frac{1}{c}>1,$$
contradicting $g\le 1$. Hence $g(x)=1$ for all $x$, i.e. $xf(x)=1$, so $f(x)=1/x
$.

**Conclusion.** The unique function is $f(x)=\dfrac{1}{x}$ for all $x\in\mathbb{
R}^+$.
