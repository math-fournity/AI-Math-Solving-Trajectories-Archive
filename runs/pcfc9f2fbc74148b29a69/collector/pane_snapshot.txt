## Solution

**Step 1: Solve the cubic by substitution.**

The equation is $x^3 - 3\sqrt{3}\,x^2 + 9x - 3\sqrt{3} - 64 = 0$.

Let $x = t + \sqrt{3}$. Expanding each term:

- $(t+\sqrt{3})^3 = t^3 + 3\sqrt{3}\,t^2 + 9t + 3\sqrt{3}$
- $-3\sqrt{3}(t+\sqrt{3})^2 = -3\sqrt{3}\,t^2 - 18t - 9\sqrt{3}$
- $+9(t+\sqrt{3}) = 9t + 9\sqrt{3}$
- $-3\sqrt{3} - 64$

Summing: the $t^2$, $t$, and $\sqrt{3}$ coefficients all cancel, leaving

$$t^3 - 64 = 0 \implies t^3 = 64 \implies t = 4.$$

Hence $x = 4 + \sqrt{3}$.

**Step 2: Compute the powers of $x = 4+\sqrt{3}$.**

| 5 | $3124 + 1769\sqrt{3}$ |

(Each row verified by multiplying the previous by $4+\sqrt{3}$.)

**Step 3: Evaluate $P = x^6 - 8x^5 + 13x^4 - 5x^3 + 49x^2 - 137x + 2015$.**

*Rational parts:*
$$17803 - 8(3124) + 13(553) - 5(100) + 49(19) - 137(4) + 2015$$
$$= 17803 - 24992 + 7189 - 500 + 931 - 548 + 2015$$
$$= (17803 - 24992 + 7189) + (-500 + 931 - 548) + 2015$$
$$= 0 + (-117) + 2015 = 1898.$$

*Irrational ($\sqrt{3}$) parts:*
$$10200 - 8(1769) + 13(304) - 5(51) + 49(8) - 137(1)$$
$$= 10200 - 14152 + 3952 - 255 + 392 - 137$$
$$= (10200 - 14152 + 3952) + (-255 + 392 - 137)$$
$$= 0 + 0 = 0.$$

The $\sqrt{3}$ terms cancel completely, confirming the result is rational.

$$\boxed{P = 1898}$$
