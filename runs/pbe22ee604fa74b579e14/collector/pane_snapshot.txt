# Solution

We determine whether $\lim_{x\to\infty} \frac{S(x)}{x}$ exists, where $S(x)$ cou
nts positive integers $\le x$ expressible as a sum of three squares.

## Key Tool: Legendre's Three-Square Theorem

A positive integer $n$ can be written as $n = a^2 + b^2 + c^2$ (with $a,b,c \in
\mathbb{Z}$) **if and only if** $n$ is **not** of the form
$$n = 4^a(8b+7), \qquad a,b \ge 0 \text{ integers.}$$

We accept this classical result (Gauss/Legendre) and use it to compute the natur
al density of the representable integers.

## Density of the Excluded Set

Define $E = \{n \ge 1 : n = 4^a(8b+7) \text{ for some } a,b \ge 0\}$. We compute
 the density of $E$.

For a **fixed** $a \ge 0$, the set $\{4^a(8b+7) : b \ge 0\}$ consists of all pos
itive integers $\equiv 7\cdot 4^a \pmod{8\cdot 4^a}$, i.e., those in a single re
sidue class modulo $8\cdot 4^a = 2^{3+2a}$. Its density is
$$\frac{1}{8\cdot 4^a}.$$

The sets for different $a$ are **disjoint**: if $4^a(8b+7) = 4^{a'}(8b'+7)$ with
 $a < a'$, then $8b+7 = 4^{a'-a}(8b'+7)$, but $8b+7 \equiv 7 \pmod 8$ while $4^{
a'-a}(8b'+7)$ is divisible by $4$ (since $a'-a \ge 1$), giving $4^{a'-a}(8b'+7)
\equiv 0 \pmod 4$, contradicting $\equiv 7 \pmod 8$. Hence disjointness holds.

By countable additivity of natural density on disjoint families (each set is a u
nion of residue classes, and the partial sums converge),
$$d(E) = \sum_{a=0}^{\infty} \frac{1}{8\cdot 4^a} = \frac{1}{8}\cdot\frac{1}{1-\
tfrac14} = \frac{1}{8}\cdot\frac{4}{3} = \frac{1}{6}.$$

## Density of the Representable Set

By Legendre's theorem, the set of representable positive integers is exactly $\m
athbb{Z}_{>0} \setminus E$. Therefore its natural density is
$$1 - d(E) = 1 - \frac{1}{6} = \frac{5}{6}.$$

## Rigorous Justification of the Limit

We verify that the natural density exists, i.e., $\frac{S(x)}{x} \to \frac{5}{6}
$.

Let $E(x) = |E \cap [1,x]|$. Since $E = \bigsqcup_{a\ge 0} E_a$ with $E_a = \{4^
a(8b+7): b\ge 0\}$ disjoint,

$$E(x) = \sum_{a=0}^{\infty} |E_a \cap [1,x]|.$$

For each $a$, $|E_a \cap [1,x]| = \left\lfloor \frac{x - 7\cdot 4^a}{8\cdot 4^a}
\right\rfloor + 1$ when $x \ge 7\cdot 4^a$, and $0$ otherwise. In particular,
$$\left|\frac{|E_a \cap [1,x]|}{x} - \frac{1}{8\cdot 4^a}\right| \le \frac{1}{x}
.$$

Only finitely many $a$ contribute (those with $7\cdot 4^a \le x$, i.e., $a \le \
log_4(x/7)$). For the tail, $\sum_{a > \log_4(x/7)} \frac{1}{8\cdot 4^a} \le \fr
ac{1}{8}\cdot\frac{4^{-\lceil\log_4(x/7)\rceil}}{1-1/4} = O(1/x)$.

Thus
$$\frac{E(x)}{x} = \sum_{a:\, 7\cdot 4^a \le x} \frac{|E_a\cap[1,x]|}{x} = \sum_
{a=0}^{\infty}\frac{1}{8\cdot 4^a} + O\!\left(\frac{\log x}{x}\right) + O\!\left
(\frac{1}{x}\right) = \frac{1}{6} + O\!\left(\frac{\log x}{x}\right).$$

Since $S(x) = \lfloor x\rfloor - E(x)$ (every positive integer $\le x$ is either
 representable or in $E$, by Legendre),
$$\frac{S(x)}{x} = \frac{\lfloor x\rfloor}{x} - \frac{E(x)}{x} = 1 - O(1/x) - \f
rac{1}{6} - O\!\left(\frac{\log x}{x}\right) \;\longrightarrow\; 1 - \frac{1}{6}
 = \frac{5}{6}.$$

## Conclusion

The limit **exists** and equals

$$\boxed{\dfrac{5}{6}}.$$
