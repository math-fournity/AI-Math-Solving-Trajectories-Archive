Looking at this problem, I need to determine whether intervals in a countably in
finite, scattered (nowhere dense) semilattice of finite width must be finite.

**Answer: No.** I'll construct a counterexample.

---

**Counterexample.** Let $S = \{0\} \cup \{1/n : n \in \mathbb{N},\, n \geq 1\}$,
 ordered by the usual order on $\mathbb{R}$.

**$S$ is a countably infinite semilattice of finite width.** Since $S$ is a chai
n, it is a semilattice with meet $x \wedge y = \min(x,y)$ and join $x \vee y = \
max(x,y)$. It is countably infinite and has width $n = 1$ (every two elements ar
e comparable, so the largest antichain has size 1).

**$S$ is nowhere dense (scattered).** We show no subset $T \subseteq S$ is dense
-in-itself, i.e., no $T$ satisfies: for all $a < b$ in $T$, there exists $c \in
T$ with $a < c < b$.

Take any $T \subseteq S$ with at least two elements.

*Case 1: $0 \notin T$.* Then $T = \{1/n : n \in A\}$ for some $A \subseteq \math
bb{N}_{\geq 1}$. Let $n_0 = \min(A)$ and $n_1 = \min(A \setminus \{n_0\})$ (both
 exist since $A$ is a nonempty subset of $\mathbb{N}$, which is well-ordered). T
hen $1/n_1 < 1/n_0$ are consecutive in $T$: any $c \in T$ with $1/n_1 < c < 1/n_
0$ would require $k \in A$ with $n_0 < k < n_1$, contradicting $n_1 = \min(A \se
tminus \{n_0\})$. So $T$ is not dense-in-itself.

*Case 2: $0 \in T$.* Then $T \setminus \{0\} \subseteq \{1/n\}$, which by Case 1
 is not dense-in-itself. So there exist $a < b$ in $T \setminus \{0\}$ with no e
lement of $T \setminus \{0\}$ strictly between them. Since $0 < a$ (as $a = 1/n$
 for some $n$), the element $0$ is not between $a$ and $b$ either. Hence $T$ is
not dense-in-itself.

In both cases, $T$ is not dense-in-itself, so $S$ is nowhere dense. ✓

**The interval $(0,1)$ is infinite.** Take $a = 0$, $b = 1$. Then:
$$\{x \in S : 0 < x < 1\} = \{1/n : n \geq 2\},$$
which is infinite.

---

**Conclusion.** $S$ is a countably infinite semilattice, nowhere dense (scattere
d), with finite width $n=1$, yet the interval $\{x \in S : 0 < x < 1\}$ is infin
ite. Therefore, the set $\{x \in S : a < x < b\}$ is **not** necessarily finite.

The key observation is that a chain is a semilattice, and scattered chains like
$1 + \omega^*$ (the order type of $S$) can have infinite intervals — the scatter
ed condition only forbids dense-in-itself subsets, not infinite subsets. The sem
ilattice structure and finite width do not prevent this, since width $1$ (a chai
n) is already the simplest semilattice.
