## Proof

Let $S = \{10^n + 1000 : n \geq 0\} = \{1001, 1010, 1100, 2000, 11000, 101000, \
dots\}$.

**Setup.** A positive integer $N$ is representable as a sum of elements of $S$ (
with repetition) iff there exist non-negative integers $a_0, a_1, a_2, \dots$ (f
initely many nonzero) with
$$N = \sum_{n \ge 0} a_n(10^n + 1000) = \underbrace{\sum_{n \ge 0} a_n \cdot 10^
n}_{D} + 1000\underbrace{\sum_{n \ge 0} a_n}_{A}.$$

So $N = D + 1000A$ where $D = \sum a_n 10^n$ and $A = \sum a_n$, with the $a_n$
being the "generalized base-10 digits" of $D$ (allowing values $\ge 10$).

**Key Lemma.** *For a non-negative integer $D$ with standard digit sum $s(D)$, t
he set of achievable values of $A = \sum a_n$ over all representations $D = \sum
 a_n 10^n$ with $a_n \ge 0$ is exactly*
$$\{s(D) + 9k : 0 \le k \le (D - s(D))/9\}.$$

*Proof.* Any representation satisfies $A \equiv D \equiv s(D) \pmod{9}$ (since $
10^n \equiv 1 \pmod 9$). The standard representation achieves $A = s(D)$; the re
presentation $a_0 = D$ achieves $A = D$. Starting from the standard representati
on, we perform "carry-down" operations: replace $1 \cdot 10^i$ with $10 \cdot 10
^{i-1}$ for $i \ge 1$, which increases the digit sum by exactly $9$. We perform
these one at a time until reaching $a_0 = D$, and can stop at any intermediate s
tage, achieving every value $s(D) + 9k$. $\square$

**Reduction.** Write $N = 1000Q + R$ with $0 \le R \le 999$. Set $B = Q - A$, so
 $D = 1000B + R$. Since $R < 1000$, there is no carry, so $s(D) = s(B) + s(R)$.
By the lemma, $N$ is representable iff there exists $B \ge 0$ satisfying:

1. $B \le Q - 1$ (from $A = Q - B \ge 1$),
2. $1001B \ge Q - R$ (from $A \le D$),
3. $s(B) + B \le Q - s(R)$ (from $s(D) \le A$),
4. $B \equiv 5(Q - R) \pmod{9}$ (from $A \equiv s(D) \pmod 9$, using $s(B) \equi
v B$, $s(R) \equiv R \pmod 9$).

**Case $B = 0$:** Works iff $Q \le R$, $Q \ge s(R)$, and $Q \equiv R \pmod 9$.

**Case $B \ge 1$:** For $Q \le R + 1001$ (which holds whenever $Q \le 1001$), th
e lower bound from condition 2 is $B \ge 1$, so the effective interval is $[1,\;
 Q - s(R) - 1]$ (using $s(B) \ge 1$ in condition 3). This interval contains a va
lue $\equiv c \pmod 9$ (where $c = 5(Q-R) \bmod 9$) iff $Q - s(R) - 1 \ge c'$, w
here $c' = c$ if $c \ge 1$ and $c' = 9$ if $c = 0$.

**Non-representability criterion.** $N$ is non-representable iff:
- **(I)** $B = 0$ fails: ($Q > R$) or ($Q < s(R)$) or ($Q \not\equiv R \pmod 9$)
, **and**
- **(II)** No valid $B \ge 1$: $Q - s(R) - 1 < c'$, i.e., $Q < s(R) + c'$.

Since $s(R) \le 27$ (as $R \le 999$) and $c' \le 9$, condition (II) requires $Q
< 36$.

**$Q \ge 36$: Always representable.** For $Q \ge 36$ and $Q \le 1001$: $Q \ge 36
 \ge s(R) + c'$, so condition (II) fails. For $Q > 1001$: the interval $[\lceil(
Q-R)/1001\rceil,\; Q - s(R) - 1]$ has length $\gg 9$, so it contains every resid
ue class mod $9$. Thus all $N$ with $Q \ge 36$ are representable.

**$Q = 35$: Always representable.** Condition (II) requires $s(R) + c' > 35$, so
 $s(R) + c' = 36$, forcing $s(R) = 27$ (i.e., $R = 999$) and $c' = 9$ (i.e., $c
= 0$). But $c = 5(35 - 999) \bmod 9 = 5 \cdot 8 \bmod 9 = 4 \ne 0$, contradictio
n.

**$Q = 34$, $R = 999$: Non-representable.** Here $s(R) = 27$, $c = 5(34 - 999) \
bmod 9 = 5 \cdot 7 \bmod 9 = 8$, $c' = 8$, and $s(R) + c' = 35 > 34$, so conditi
on (II) holds. For condition (I): $Q \equiv R \pmod 9$? We have $34 \equiv 7$ an
d $999 \equiv 0 \pmod 9$, so no — $B = 0$ fails. Both conditions hold, so $N = 3
4999$ is **not representable**.

**Direct verification.** For $N = 34999$: we need $A$ with $1 \le A \le 34$, $A
\equiv 8 \pmod 9$ (from $2A \equiv 7 \pmod 9$), and $s(34999 - 1000A) \le A$. Th
e candidates are $A \in \{8, 17, 26\}$:

| $A$ | $D = 34999 - 1000A$ | $s(D)$ | $s(D) \le A$? |
|-----|---------------------|--------|---------------|
| 8   | 26999               | 35     | $35 > 8$ ✗   |
| 17  | 17999               | 35     | $35 > 17$ ✗  |
| 26  | 8999                | 35     | $35 > 26$ ✗  |

No valid representation exists. ✓

**$35000$ is representable:** Take $A = 4$, $D = 31000$, $s(D) = 4 \le 4$. ✓ Con
cretely, $35000 = 3 \cdot 11000 + 1 \cdot 2000$.
