Looking at this problem, I need to find the smallest degree of a polynomial with
 rational coefficients having all values $S(r) = r^{2^n} + r^{2^{n-1}} + \cdots
+ r^2 + r$ as roots, where $r$ ranges over primitive $2^{n+1}$-th roots of unity
.

## Proof

**Setup.** The roots of unity satisfying $r^{2^{n+1}} = 1$ but $r^{2^n} \neq 1$
are exactly the primitive $2^{n+1}$-th roots of unity. Setting $\zeta = e^{2\pi
i/2^{n+1}}$, these are $\zeta^k$ for odd $k \in \{1, 3, \ldots, 2^{n+1}-1\}$, gi
ving $\varphi(2^{n+1}) = 2^n$ roots.

Define $S(r) = \sum_{j=0}^{n} r^{2^j}$. We seek the degree of the minimal polyno
mial over $\mathbb{Q}$ having all $S(\zeta^k)$ as roots.

**Galois invariance.** The Galois group $\operatorname{Gal}(\mathbb{Q}(\zeta)/\m
athbb{Q}) \cong (\mathbb{Z}/2^{n+1}\mathbb{Z})^\times$ acts via $\sigma_a(\zeta)
 = \zeta^a$ for odd $a$. Since $S$ is a polynomial in $r$:
$$\sigma_a(S(\zeta^k)) = S(\sigma_a(\zeta^k)) = S(\zeta^{ak}).$$
As $a$ and $k$ are both odd, $ak$ is odd, so $\zeta^{ak}$ is again a primitive $
2^{n+1}$-th root. Thus the set $\{S(\zeta^k) : k \text{ odd}\}$ is **Galois-inva
riant** — it is a union of Galois orbits. The minimal polynomial with rational c
oefficients having all these values as roots is the product of the minimal polyn
omials of orbit representatives, and its degree equals the **total number of dis
tinct values** (sum of orbit sizes).

**Basis representation.** The cyclotomic polynomial $\Phi_{2^{n+1}}(x) = x^{2^n}
 + 1$ has degree $2^n$, so $\{1, \zeta, \zeta^2, \ldots, \zeta^{2^n - 1}\}$ is a
 $\mathbb{Q}$-basis for $\mathbb{Q}(\zeta)$. Using the relation $\zeta^{2^n} = -
1$, we reduce each term:

- **$j = n$:** $k \cdot 2^n \equiv 2^n \pmod{2^{n+1}}$ (since $k$ is odd), so $\
zeta^{k \cdot 2^n} = -1$.
- **$j < n$:** The residue $k \cdot 2^j \pmod{2^{n+1}}$ has 2-adic valuation $j
< n$, so it is neither $0$ nor $2^n$. Writing $b_j(k) = (k \cdot 2^j) \bmod 2^n
\in \{1, \ldots, 2^n - 1\}$:
  - If $k \cdot 2^j \bmod 2^{n+1} < 2^n$: contributes $+\zeta^{b_j(k)}$ (sign $\
epsilon_j = +1$).
  - If $k \cdot 2^j \bmod 2^{n+1} > 2^n$: contributes $-\zeta^{b_j(k)}$ (sign $\
epsilon_j = -1$).

The values $b_0(k), b_1(k), \ldots, b_{n-1}(k)$ have **distinct 2-adic valuation
s** $0, 1, \ldots, n-1$, so they are all different. Therefore the coefficient of
 $\zeta^m$ in $S(\zeta^k)$ is $\epsilon_j(k)$ if $m = b_j(k)$ for some $j$, and
$0$ otherwise. By linear independence of the basis, the representation is unique
.

**Distinctness of all values.** Suppose $S(\zeta^k) = S(\zeta^{k'})$. Then for e
ach $j$:
1. $b_j(k) = b_j(k')$: equivalently $(k - k') \cdot 2^j \equiv 0 \pmod{2^n}$, i.
e., $2^{n-j} \mid (k - k')$.
2. $\epsilon_j(k) = \epsilon_j(k')$.

Condition (1) for $j = 0$ gives $2^n \mid (k - k')$, which is the strongest (for
 $j \geq 1$ we only need $2^{n-j} \mid (k-k')$ with $n - j < n$). So condition (
1) for all $j$ is equivalent to $k \equiv k' \pmod{2^n}$.

Since $k, k'$ are odd and in $\{1, \ldots, 2^{n+1}-1\}$, the condition $k \equiv
 k' \pmod{2^n}$ with $k \neq k'$ forces $k' = k + 2^n$. Now check the signs:
- $\epsilon_0(k) = +1$ since $k < 2^n$ (so $k \bmod 2^{n+1} = k < 2^n$).
- $\epsilon_0(k + 2^n) = -1$ since $(k + 2^n) \bmod 2^{n+1} = k + 2^n \geq 2^n$.

For $j \geq 1$: $(k + 2^n) \cdot 2^j = k \cdot 2^j + 2^{n+j} \equiv k \cdot 2^j
\pmod{2^{n+1}}$ (since $n + j \geq n + 1$), so $\epsilon_j(k+2^n) = \epsilon_j(k
)$.

Thus $\epsilon_0(k) \neq \epsilon_0(k + 2^n)$, so **condition (2) fails**. This
means $S(\zeta^k) \neq S(\zeta^{k + 2^n})$ for every odd $k$.

Since the only way to satisfy condition (1) with $k \neq k'$ is $k' = k + 2^n$,
and this always fails condition (2), we conclude:

**All $2^n$ values $S(\zeta^k)$ are distinct.**

**Conclusion.** The set $\{S(\zeta^k)\}$ is Galois-invariant with $2^n$ distinct
 elements. The minimal polynomial with rational coefficients having all of them
as roots has degree equal to the number of distinct values, which is $2^n$.

$$\boxed{2^n}$$
