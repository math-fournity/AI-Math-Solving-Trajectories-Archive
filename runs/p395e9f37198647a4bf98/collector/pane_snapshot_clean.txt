## Proof

**Claim:** If $A$ is a normal operator on a finite-dimensional complex inner pro
duct space, then $A^*$ is a polynomial in $A$.

**Proof:**

Let $A$ be a normal operator on a finite-dimensional complex Hilbert space $V$.
By the **Spectral Theorem** for normal operators, $A$ is unitarily diagonalizabl
e: there exists a unitary $U$ and a diagonal matrix $\Lambda = \operatorname{dia
g}(\lambda_1, \dots, \lambda_n)$ such that
$$A = U \Lambda U^*.$$
The adjoint is then
$$A^* = U \overline{\Lambda}\, U^* = U \operatorname{diag}(\overline{\lambda_1},
 \dots, \overline{\lambda_n})\, U^*.$$

Let $\mu_1, \dots, \mu_k$ be the **distinct** eigenvalues of $A$. We construct a
 polynomial $p \in \mathbb{C}[z]$ satisfying
$$p(\mu_j) = \overline{\mu_j}, \quad j = 1, \dots, k.$$

Such a polynomial exists by **Lagrange interpolation**:
$$p(z) = \sum_{j=1}^{k} \overline{\mu_j} \prod_{\substack{i=1 \\ i \neq j}}^{k}
\frac{z - \mu_i}{\mu_j - \mu_i}.$$

This is well-defined since the $\mu_j$ are distinct, and by construction $p(\mu_
j) = \overline{\mu_j}$ for each $j$.

Now evaluate $p(A)$. Since $A = U \Lambda U^*$, we have $p(A) = U\, p(\Lambda)\,
 U^*$, where
$$p(\Lambda) = \operatorname{diag}\big(p(\lambda_1), \dots, p(\lambda_n)\big).$$

Each eigenvalue $\lambda_i$ equals some $\mu_j$, so $p(\lambda_i) = \overline{\m
u_j} = \overline{\lambda_i}$. Therefore:
$$p(\Lambda) = \operatorname{diag}\big(\overline{\lambda_1}, \dots, \overline{\l
ambda_n}\big) = \overline{\Lambda},$$
and hence
$$p(A) = U\, \overline{\Lambda}\, U^* = A^*.$$

**Conclusion:** $A^* = p(A)$, so the adjoint of a normal operator is indeed a po
lynomial in $A$. $\blacksquare$

**Remark (converse):** If $A^* = p(A)$ for some polynomial $p$, then $A$ is auto
matically normal, since $AA^* = A\,p(A) = p(A)\,A = A^*A$. Thus, in finite dimen
sions, **$A$ is normal if and only if $A^*$ is a polynomial in $A$**.

**Remark (infinite-dimensional caveat):** For a bounded normal operator on an in
finite-dimensional Hilbert space, the spectral theorem gives $A^* = \int_{\sigma
(A)} \overline{\lambda}\, dE(\lambda)$. Requiring $A^* = p(A)$ demands $p(\lambd
a) = \overline{\lambda}$ on $\sigma(A)$. If $\sigma(A)$ is infinite (e.g., has a
 limit point), this is impossible since $p$ is holomorphic while $z \mapsto \ove
rline{z}$ is not. So the result holds in full generality only in finite dimensio
ns (or when the spectrum is finite).
