Looking at this problem, I need to find for how many values of $n$ we can insert
 $+$ signs into a string of $n$ sevens to get a sum of 7000.

**Setup.** Inserting $+$ signs partitions the string of $n$ sevens into blocks.
A block of length $k$ (i.e., $k$ consecutive 7's) has value $7 \cdot \underbrace
{11\ldots1}_{k} = 7R_k$, where $R_k = \frac{10^k-1}{9}$ is the $k$-th repunit. I
f the blocks have lengths $a_1, a_2, \ldots, a_m$ (with $\sum a_i = n$), the tot
al value is:

$$7\sum_{i=1}^m R_{a_i} = 7000 \implies \sum_{i=1}^m R_{a_i} = 1000.$$

**Available repunits.** Since $R_1=1, R_2=11, R_3=111, R_4=1111 > 1000$, only bl
ocks of length 1, 2, or 3 can appear. Let $a, b, c$ be the number of blocks of l
ength 1, 2, 3 respectively. Then:

$$a + 11b + 111c = 1000, \qquad n = a + 2b + 3c,$$

where $a,b,c \geq 0$ are non-negative integers (not all zero, but $a=1000-11b-11
1c$ is forced positive in all valid cases).

**Expressing $n$.** Substituting $a = 1000 - 11b - 111c$:

$$n = (1000 - 11b - 111c) + 2b + 3c = 1000 - 9b - 108c = 1000 - 9(b + 12c).$$

Let $d = b + 12c$. Then $n = 1000 - 9d$, so **distinct values of $n$ correspond
bijectively to distinct achievable values of $d$**.

**Finding achievable $d$.** The constraints are: $c \in \{0,1,\ldots,9\}$ (since
 $111 \cdot 9 = 999 \leq 1000$) and $0 \leq b \leq \left\lfloor\frac{1000 - 111c
}{11}\right\rfloor$. For each $c$, the achievable $d = b + 12c$ forms an interva
l:

| $c$ | max $b$ | $d$ range |
|-----|---------|-----------|
| 0 | 90 | $\{0, \ldots, 90\}$ |
| 1 | 80 | $\{12, \ldots, 92\}$ |
| 2 | 70 | $\{24, \ldots, 94\}$ |
| 3 | 60 | $\{36, \ldots, 96\}$ |
| 4 | 50 | $\{48, \ldots, 98\}$ |
| 5 | 40 | $\{60, \ldots, 100\}$ |
| 6 | 30 | $\{72, \ldots, 102\}$ |
| 7 | 20 | $\{84, \ldots, 104\}$ |
| 8 | 10 | $\{96, \ldots, 106\}$ |
| 9 | 0 | $\{108\}$ |

**Taking the union.** Each successive interval starts 12 higher and extends 2 fu
rther, so consecutive intervals overlap. The cumulative union through $c=8$ is $
\{0, 1, \ldots, 106\}$ (107 values). Adding $c=9$ contributes the isolated value
 $d = 108$.

**Is $d = 107$ achievable?** For each $c$: $c=9 \Rightarrow b=-1$ (invalid); $c=
8 \Rightarrow b=11 > 10$ (exceeds max); $c=7 \Rightarrow b=23 > 20$; and lower $
c$ is even worse. So $d=107$ is **not** achievable.

**Counting.** The achievable $d$-values are $\{0,\ldots,106\} \cup \{108\}$, giv
ing $107 + 1 = \mathbf{108}$ distinct values.

**Corresponding $n$-values.** These give $n = 1000 - 9d \in \{46, 55, 64, \ldots
, 1000\} \cup \{28\}$ — all distinct (since $28 < 46$).

**Verification of two boundary cases:**
- $d=0$: $a=1000, b=c=0$, $n=1000$. Sum = $1000 \times 1 = 1000$. ✓
- $d=108$: $c=9, b=0, a=1$, $n=28$. Sum = $1 + 9 \times 111 = 1000$, i.e., $7 +
9 \times 777 = 7000$. ✓
