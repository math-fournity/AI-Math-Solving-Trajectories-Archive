## Proof

**Key Idea.** If $k$ is chosen so that $n+k \equiv n$ modulo the multiplicative
orders of $2$, $3$, and $5$ modulo $p$, then each exponential term in $q(n+k)$ m
atches the corresponding term in $q(n)$ modulo $p$, giving $q(n+k) \equiv q(n) \
equiv 0 \pmod{p}$.

### Case 1: $p = 3$

We show $3 \nmid q(n)$ for every positive integer $n$, so the premise is vacuous
.

Modulo 3: $2 \equiv -1$ and $3 \equiv 0$, so
$$q(n) \equiv (-1)^{n^3+1} + (-1)^{n+1} \pmod{3}.$$
Since $n^3 \equiv n \pmod{2}$ (as $n^3 - n = n(n-1)(n+1)$ is always even), we ha
ve $n^3 + 1 \equiv n + 1 \pmod{2}$, so
$$q(n) \equiv 2 \cdot (-1)^{n+1} \pmod{3},$$
which equals $\pm 2 \not\equiv 0 \pmod{3}$. Thus $p = 3$ never divides $q(n)$.

### Case 2: $p = 5$

Here $5^{n+1} \equiv 0 \pmod{5}$, so $q(n) \equiv 2^{n^3+1} - 3^{n^2+1} \pmod{5}
$. The multiplicative orders are $\operatorname{ord}_5(2) = 4$ and $\operatornam
e{ord}_5(3) = 4$.

Take $k = 4$. Then $n + k \equiv n \pmod{4}$, so:
- $(n+4)^3 \equiv n^3 \pmod{4}$, hence $2^{(n+4)^3+1} \equiv 2^{n^3+1} \pmod{5}$
.
- $(n+4)^2 \equiv n^2 \pmod{4}$, hence $3^{(n+4)^2+1} \equiv 3^{n^2+1} \pmod{5}$
.
- $5^{(n+4)+1} \equiv 0 \equiv 5^{n+1} \pmod{5}$.

Therefore $q(n+4) \equiv q(n) \equiv 0 \pmod{5}$. ✓

### Case 3: $p \geq 7$

$$2^{(n+k)^3+1} \equiv 2^{n^3+1} \pmod{p}.$$

By the identical argument with $d_3 \mid k$:
$$3^{(n+k)^2+1} \equiv 3^{n^2+1} \pmod{p},$$

$$5^{(n+k)+1} \equiv 5^{n+1} \pmod{p}.$$

Combining:
$$q(n+k) = 2^{(n+k)^3+1} - 3^{(n+k)^2+1} + 5^{(n+k)+1} \equiv 2^{n^3+1} - 3^{n^2
+1} + 5^{n+1} = q(n) \equiv 0 \pmod{p}.$$
