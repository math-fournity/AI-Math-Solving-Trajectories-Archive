Looking at this problem, I need to determine whether, for every interval $[a, b]
$, there exists a continuous $f: [a, b] \to [0,1]$ with a period-3 point.

**Answer: No.**

## Proof

**Counterexample.** Take $[a, b] = [2, 3]$. Suppose $f: [2, 3] \to [0, 1]$ is co
ntinuous. For any $x \in [2, 3]$, we have $f(x) \in [0, 1]$. Since $[0, 1] \cap
[2, 3] = \emptyset$, it follows that $f(x) \notin [2, 3] = \operatorname{dom}(f)
$. Therefore $f^2(x) = f(f(x))$ is **undefined** for every $x$. Consequently $f^
3(x)$ is undefined everywhere, and no periodic point of any period $\geq 2$ can
exist — in particular, no period-3 point.

This already shows the answer is **No**: such a function does not exist on an ar
bitrary interval.

---

**Complete characterization.** A continuous $f: [a, b] \to [0, 1]$ can have a pe
riod-3 point **if and only if** $[a, b] \cap [0, 1]$ has nonempty interior.

**Necessity.** Let $I = [a, b] \cap [0, 1]$.

- *Case $I = \emptyset$ (i.e., $b < 0$ or $a > 1$):* As shown above, $f(x) \in [
0,1] \setminus [a,b]$, so $f^2$ is undefined everywhere. No periodic points of a
ny period.

- *Case $I = \{p\}$ (a single point):* For $f^2(x)$ to be defined, $f(x) \in [a,
b]$, so $f(x) \in [0,1] \cap [a,b] = \{p\}$, giving $f(x) = p$. Then $f(p) \in [
0,1] \cap [a,b] = \{p\}$, so $f(p) = p$. Thus $f^3(x) = p$ for all $x$ in any or
bit. For $f^3(x) = x$ we need $x = p$, but then $f(x) = f(p) = p = x$, so $x$ is
 a **fixed point**, not period 3.

**Sufficiency.** Suppose $I = [c, d]$ with $c < d$. We construct a continuous $f
: [a, b] \to [0, 1]$ with a period-3 point.

*Step 1: Period-3 map on $[c, d]$.* Let $\phi: [0,1] \to [c,d]$ be the affine ma
p $\phi(t) = c + (d-c)t$. Define $g_0: [0,1] \to [0,1]$ as the piecewise-linear
function through the points $(0, \tfrac{1}{2})$, $(\tfrac{1}{2}, 1)$, $(1, 0)$.
Then:
- $g_0(0) = \tfrac{1}{2}$, $g_0^2(0) = g_0(\tfrac{1}{2}) = 1$, $g_0^3(0) = g_0(1
) = 0$.
- Since $g_0(0) = \tfrac{1}{2} \neq 0$ and $g_0^2(0) = 1 \neq 0$, the point $0$
is a **period-3 point** of $g_0$.
- On $[0, \tfrac{1}{2}]$, $g_0$ ranges over $[\tfrac{1}{2}, 1] \subset [0,1]$; o
n $[\tfrac{1}{2}, 1]$, $g_0$ ranges over $[0, 1]$. So $g_0: [0,1] \to [0,1]$. ✓

Set $g = \phi \circ g_0 \circ \phi^{-1}: [c, d] \to [c, d] \subset [0, 1]$. Then
 $g$ is continuous and $c = \phi(0)$ is a period-3 point of $g$.

*Step 2: Extension to $[a, b]$.* Define $f: [a, b] \to [0, 1]$ by:
$$f(x) = \begin{cases} g(c) & \text{if } x \in [a, c], \\ g(x) & \text{if } x \i
n [c, d], \\ g(d) & \text{if } x \in [d, b]. \end{cases}$$
(If $[a, c]$ or $[d, b]$ is empty, the corresponding case is vacuous.) Since $g(
c), g(d) \in [c, d] \subset [0, 1]$, the function $f$ is well-defined, continuou
s, and maps $[a, b] \to [0, 1]$. The period-3 orbit $\{c, g(c), g^2(c)\} \subset
 [c, d] \subset [a, b]$ is preserved, so $f$ has a period-3 point. ✓

---

**Conclusion.** The answer is **No**: a continuous function $f: [a, b] \to [0, 1
]$ with a periodic point of period 3 does **not** exist on every interval $[a, b
]$. It exists if and only if $[a, b] \cap [0, 1]$ contains a non-degenerate inte
rval. For example, on $[2, 3]$ no such function can exist because $f^2$ is undef
ined everywhere.
