## Setup via Galois Theory

We have $\text{Gal}(E/\mathbb{Q}) \cong S_7$ with $|S_7| = 5040$, so $[E:\mathbb
{Q}] = 5040$.

By the Galois correspondence, subfields $K \subseteq E$ with $[E:K] = 7$ corresp
ond to subgroups $H \leq S_7$ with $|H| = 7$.

**Subgroups of order 7 in $S_7$:** These are exactly the cyclic subgroups genera
ted by 7-cycles. The number of 7-cycles in $S_7$ is $6! = 720$, and each cyclic
subgroup of order 7 contains $\varphi(7) = 6$ elements of order 7, giving $720/6
 = 120$ distinct subgroups of order 7.

Let $H_1, H_2, \ldots, H_{120}$ be these subgroups, with corresponding fixed fie
lds $K_i = E^{H_i}$.

## The Intersection

The intersection $\bigcap_i K_i = \bigcap_i E^{H_i} = E^{\langle H_1, H_2, \ldot
s, H_{120}\rangle}$, the fixed field of the subgroup generated by all the $H_i$.

Since each $H_i$ is generated by a 7-cycle, $\langle H_1, \ldots, H_{120}\rangle
 = \langle \text{all 7-cycles in } S_7 \rangle$.

**Claim:** $\langle \text{all 7-cycles} \rangle = A_7$.

*Proof of claim:*
- Every 7-cycle $(a_1\, a_2\, \ldots\, a_7)$ is a product of 6 transpositions, h

- The set of all 7-cycles is a full conjugacy class in $S_7$ (cycle type $(7)$).
 The subgroup $N$ they generate is therefore **normal in $S_7$**, and hence norm

- $N$ is non-trivial (it contains 7-cycles).
- $A_7$ is **simple** (since $A_n$ is simple for $n \geq 5$).
- Therefore $N = A_7$. $\checkmark$
