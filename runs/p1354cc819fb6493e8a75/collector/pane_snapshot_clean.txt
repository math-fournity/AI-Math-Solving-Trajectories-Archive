Looking at this problem, I need to find the minimum number of roads in a graph o
n 25 vertices where every 4-vertex induced subgraph is connected.

## Proof

Let $G$ be the graph on 25 vertices (cities) and $H = \overline{G}$ its compleme
nt (non-roads). The total number of possible edges is $\binom{25}{2} = 300$, so
$|E(G)| = 300 - |E(H)|$. To minimize $|E(G)|$, I maximize $|E(H)|$.

**Translating the condition.** A 4-vertex subset $S$ induces a disconnected subg
raph in $G$ iff there exists a partition $S = A \cup B$ (both nonempty) with no
$G$-edge crossing between $A$ and $B$, i.e., all $|A| \cdot |B|$ cross-edges bel
ong to $H$.

For $|S|=4$, the partition types are $1|3$ and $2|2$.

**Condition from $1|3$ partitions:** Some vertex $v \in S$ has all 3 edges to th
e other vertices of $S$ in $H$. This requires $\deg_H(v) \geq 3$. To prevent thi
s for all 4-subsets: **every vertex in $H$ has degree $\leq 2$.**

**Condition from $2|2$ partitions:** For a partition $\{a,b\}|\{c,d\}$, all four
 edges $ac, ad, bc, bd$ are in $H$. With max degree 2, this forces $N_H(a) = N_H
(b) = \{c,d\}$, forming a 4-cycle $a\text{-}c\text{-}b\text{-}d\text{-}a$. So: *
*$H$ contains no $C_4$.**

**Sufficiency:** If $H$ has max degree $\leq 2$ and no $C_4$, then no $1|3$ disc
onnection (needs degree $\geq 3$) and no $2|2$ disconnection (needs $C_4$) can o
ccur. So every 4-subset is connected in $G$. ✓

**Maximizing $|E(H)|$.** With max degree $\leq 2$, $H$ is a disjoint union of pa
ths and cycles. A path on $k$ vertices has $k-1$ edges; a cycle on $k$ vertices
has $k$ edges. Cycles are strictly more efficient. To maximize edges, every vert
ex should have degree exactly 2, making $H$ a 2-regular graph (union of cycles c
overing all 25 vertices), giving $|E(H)| = 25$.

We must avoid $C_4$ components. Since $25$ is odd, we can use, e.g., a single $C
_{25}$ (a 25-cycle), which has no $C_4$ component. This achieves $|E(H)| = 25$.

No graph $H$ on 25 vertices with max degree $\leq 2$ can exceed 25 edges (since
$\sum \deg = 2|E(H)| \leq 2 \cdot 25$), so 25 is optimal.

**Conclusion.** The minimum number of roads is:
$$|E(G)| = 300 - 25 = \boxed{275}.$$

**Construction:** Take $G = K_{25} \setminus C_{25}$, i.e., the complete graph m
inus a Hamiltonian cycle. The complement $H = C_{25}$ has maximum degree 2 and c
ontains no $C_4$, so every 4-city group is connected. This uses exactly 275 road
s, and no fewer suffices.
