## 证明

设 $g = \frac{d\nu}{d(\mu+\nu)}$ 为 $\nu$ 关于 $\mu+\nu$ 的 Radon-Nikodym 导数。
令 $h = \frac{d\mu}{d(\mu+\nu)}$ 为 $\mu$ 关于 $\mu+\nu$ 的 Radon-Nikodym 导数。

**步骤 1：建立 $g + h = 1$。**

由于 $\mu$ 和 $\nu$ 都是关于 $\mu+\nu$ 绝对连续的（因为 $\mu \ll \mu+\nu$ 且 $\n
u \ll \mu+\nu$），且
$$\frac{d(\mu+\nu)}{d(\mu+\nu)} = 1 = \frac{d\mu}{d(\mu+\nu)} + \frac{d\nu}{d(\m
u+\nu)} = h + g,$$
故 $g + h = 1$ 关于 $(\mu+\nu)$-几乎处处成立。

**步骤 2：利用 $\mu$ 的非负性。**

因为 $\mu$ 是（非负）测度，$h = \frac{d\mu}{d(\mu+\nu)} \geq 0$ 关于 $(\mu+\nu)$
-几乎处处成立。

**步骤 3：分析集合 $A = \{x : g(x) > 2\}$。**

在 $A$ 上，$h = 1 - g < 1 - 2 = -1 < 0$。但 $h \geq 0$ 关于 $(\mu+\nu)$-a.e.，所
以
$$A \subseteq \{x : h(x) < 0\} \quad \text{（关于 } g > 2 \text{ 的点）},$$
而 $\{x : h(x) < 0\}$ 的 $(\mu+\nu)$-测度为 $0$。因此 $(\mu+\nu)(A) = 0$。

**步骤 4：得出 $\mu(A) = 0$。**

由于 $\mu \ll \mu+\nu$，且 $(\mu+\nu)(A) = 0$，故
$$\mu(A) = \mu(\{x : g(x) > 2\}) = 0.$$

（注：条件 $\nu(\Omega) = 3$ 在此论证中并非必需——结论对任意非负测度 $\nu$ 均成立
。）

$$\boxed{\mu(\{x : g(x) > 2\}) = 0}$$
