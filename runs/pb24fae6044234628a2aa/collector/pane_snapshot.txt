# Proof: Number of Bijections from ℕ⁺ to ℕ⁺

We show the number of bijections $f: \mathbb{N}^+ \to \mathbb{N}^+$ is $2^{\alep
h_0}$ (the cardinality of the continuum).

## Upper Bound: at most $2^{\aleph_0}$

Every bijection is, in particular, a function $\mathbb{N}^+ \to \mathbb{N}^+$, h
ence an element of $(\mathbb{N}^+)^{\mathbb{N}^+}$, the set of all sequences of
positive integers. The cardinality of this set is

$$|\mathbb{N}^+|^{\,|\mathbb{N}^+|} = \aleph_0^{\aleph_0}.$$

Since $\aleph_0 \geq 2$, we have $\aleph_0^{\aleph_0} \geq 2^{\aleph_0}$. For th
e reverse inequality, every positive integer $n$ can be encoded as a finite bina
ry string, so a sequence of positive integers is a countable concatenation of fi
nite binary strings, i.e., an element of $\{0,1\}^{\mathbb{N}}$ (padded appropri
ately). Concretely, $\aleph_0^{\aleph_0} \leq (2^{\aleph_0})^{\aleph_0} = 2^{\al
eph_0 \cdot \aleph_0} = 2^{\aleph_0}$. Hence $\aleph_0^{\aleph_0} = 2^{\aleph_0}
$.

Therefore the set of bijections, being a subset of $(\mathbb{N}^+)^{\mathbb{N}^+
}$, has cardinality $\leq 2^{\aleph_0}$.

## Lower Bound: at least $2^{\aleph_0}$

We construct an injection from $\{0,1\}^{\mathbb{N}^+}$ (the set of all infinite
 binary sequences, cardinality $2^{\aleph_0}$) into the set of bijections.

Partition $\mathbb{N}^+$ into consecutive pairs: $\{1,2\}, \{3,4\}, \{5,6\}, \ld
ots$, i.e., the pair indexed by $k$ is $\{2k-1, 2k\}$.

For each binary sequence $b = (b_1, b_2, b_3, \ldots) \in \{0,1\}^{\mathbb{N}^+}
$, define $\sigma_b : \mathbb{N}^+ \to \mathbb{N}^+$ by:

$$\sigma_b(2k-1) = \begin{cases} 2k-1 & \text{if } b_k = 0, \\ 2k & \text{if } b
_k = 1, \end{cases} \qquad \sigma_b(2k) = \begin{cases} 2k & \text{if } b_k = 0,
 \\ 2k-1 & \text{if } b_k = 1. \end{cases}$$

Each $\sigma_b$ is a bijection: it permutes each pair $\{2k-1, 2k\}$ independent
ly (either fixing or swapping), so it is a product of disjoint transpositions an
d is invertible (indeed $\sigma_b^{-1} = \sigma_b$).

The map $b \mapsto \sigma_b$ is injective: if $b \neq b'$, there exists $k$ with
 $b_k \neq b'_k$, and then $\sigma_b$ and $\sigma_{b'}$ differ on the input $2k-
1$. Hence we have embedded $\{0,1\}^{\mathbb{N}^+}$ into the set of bijections,
giving at least $2^{\aleph_0}$ bijections.

## Conclusion

The number of bijections is at most $2^{\aleph_0}$ and at least $2^{\aleph_0}$,
so it equals exactly

$$\boxed{2^{\aleph_0}},$$

the cardinality of the continuum (equivalently, $|\mathbb{R}|$ or $\mathfrak{c}$
).
