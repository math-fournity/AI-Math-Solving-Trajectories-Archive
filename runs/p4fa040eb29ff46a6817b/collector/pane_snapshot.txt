**Yes.** The condition $|f(z)| = |g(z)|$ for all $z \in \mathbb{C}^n$ implies $g
 = cf$ for some constant $c \in \mathbb{C}$ with $|c| = 1$.

## Proof

**Case 1: $f \equiv 0$.** Then $|g(z)| = 0$ for all $z$, so $g \equiv 0$ as well
. The conclusion holds trivially with any $c$ satisfying $|c|=1$ (e.g., $c = 1$)
.

**Case 2: $f \not\equiv 0$.** Then $g \not\equiv 0$ either, since $|g| \equiv |f
| \not\equiv 0$.

Since $|f(z)| = |g(z)|$ for all $z$, we have
$$f(z) = 0 \iff g(z) = 0.$$

Define the open set
$$U := \{z \in \mathbb{C}^n : g(z) \neq 0\} = \{z \in \mathbb{C}^n : f(z) \neq 0
\}.$$

Since $g \not\equiv 0$, $U$ is nonempty and open.

**$U$ is connected.** The zero set $Z(g) = \{z : g(z) = 0\}$ is a complex analyt
ic subset of $\mathbb{C}^n$. For $n = 1$, the zeros of a nonzero entire function
 form a discrete set, and $\mathbb{C}$ minus a discrete set is connected. For $n
 \geq 2$, $Z(g)$ is a complex analytic hypersurface (or empty), which has real c
odimension $\geq 2$ in $\mathbb{C}^n$ (real dimension $2n$). A subset of real co
dimension $\geq 2$ cannot disconnect a connected manifold, so $\mathbb{C}^n \set
minus Z(g) = U$ is connected. (The same real-codimension argument unifies all $n
 \geq 1$.)

**Constructing the ratio.** On $U$, both $f$ and $g$ are nonzero, so the functio
n
$$h := \frac{f}{g} : U \to \mathbb{C}$$
is well-defined and holomorphic. Moreover,
$$|h(z)| = \frac{|f(z)|}{|g(z)|} = 1 \quad \text{for all } z \in U.$$

**$h$ is constant.** A holomorphic function on a connected open set with constan
t modulus is constant. (This holds in several variables: restrict $h$ to any com
plex line in $U$; the resulting one-variable holomorphic function has constant m
odulus, hence is constant by the open mapping theorem. This shows $h$ is locally
 constant, and since $U$ is connected, $h$ is constant.) Thus $h \equiv c$ on $U
$ for some constant $c \in \mathbb{C}$ with $|c| = 1$.

**Extending to all of $\mathbb{C}^n$.** We have $f(z) = c\,g(z)$ for all $z \in
U$. The function $F := f - c\,g$ is entire (holomorphic on all of $\mathbb{C}^n$
) and vanishes on the nonempty open set $U$. By the identity theorem for holomor
phic functions of several variables, $F \equiv 0$ on $\mathbb{C}^n$. Therefore
$$f = c\,g \quad \text{on } \mathbb{C}^n,$$
i.e., $g = c^{-1} f = c' f$ where $c' = 1/c$ satisfies $|c'| = 1/|c| = 1$.

This completes the proof. $\blacksquare$
