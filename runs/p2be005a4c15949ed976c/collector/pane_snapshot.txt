Looking at this problem, I need to find the largest $n$ such that there exists a
n $n$-digit number $N = a_1 a_2 \cdots a_n$ (all digits non-zero) where $N$ is d
ivisible by $M = a_2 a_3 \cdots a_n$ (the $(n-1)$-digit number obtained by remov
ing the first digit).

## Proof

**Setup.** Let $N = a_1 \cdot 10^{n-1} + M$ where $M$ is the $(n-1)$-digit numbe
r formed by digits $a_2, \ldots, a_n$. The divisibility condition $M \mid N$ is
equivalent to $M \mid a_1 \cdot 10^{n-1}$.

**Introducing the quotient.** Define $q = \frac{a_1 \cdot 10^{n-1}}{M}$, a posit
ive integer. Then $N = (q+1)M$. Since $M$ is an $(n-1)$-digit number with non-ze
ro leading digit: $10^{n-2} \le M < 10^{n-1}$, which gives:
$$a_1 < q \le 10\,a_1$$
In particular $2 \le q \le 90$ (since $a_1 \le 9$).

**Decimal expansion connection.** We have $M = \frac{a_1}{q} \cdot 10^{n-1}$. Si
nce $M$ is an integer, $a_1/q$ is a terminating decimal. Let $L$ be the number o
f decimal places of $a_1/q$ in lowest terms. Then $M = \frac{a_1}{q}\cdot 10^{n-
1}$ has $n-1-L$ trailing zeros unless $n-1 = L$.

**No trailing zeros forces $n = L+1$.** Since all digits of $M$ must be non-zero
, $M$ cannot have trailing zeros. Therefore $n - 1 = L$, i.e., **$n = L + 1$**,
and $M$ is exactly the $L$-digit integer obtained from the decimal expansion of
$a_1/q$.

**Maximizing $L$.** Write $a_1/q$ in lowest terms as $p/s$ where $s = 2^a \cdot
5^b$ (only factors 2 and 5 for termination). Then $L = \max(a, b)$ and $q = \gcd
(a_1, q) \cdot s$, with $\gcd(a_1, q) \le a_1 \le 9$.

**Upper bound on $L$.** Since $q \le 90$:
- If $a \ge 7$: $s \ge 2^7 = 128$, so $q \ge 128 > 90$. Impossible.
- If $b \ge 3$: $s \ge 5^3 = 125$, so $q \ge 125 > 90$. Impossible.
- If $b \ge 1$ and $a \ge 6$: $s \ge 64 \cdot 5 = 320 > 90$. Impossible.

So $L \le 6$, giving $n \le 7$.

**Checking $L = 6$ (i.e., $n = 7$).** We need $\max(a,b) = 6$ with $q \le 90$.
- $b = 6$: $s \ge 5^6 = 15625 > 90$. Impossible.
- $a = 6, b = 0$: $s = 64$, $q = 64 \cdot \gcd(a_1, q) \le 90$ forces $\gcd(a_1,
 64) = 1$, so $a_1$ is odd. The constraint $q \le 10a_1$ gives $a_1 \ge 7$. Thus
 $a_1 \in \{7, 9\}$.
  - $a_1 = 7$: $\frac{7}{64} = 0.109375$ — contains digit **0**. ✗
  - $a_1 = 9$: $\frac{9}{64} = 0.140625$ — contains digit **0**. ✗

Both fail. Therefore **$n = 7$ is impossible**, and $n \le 6$.

**Constructing $n = 6$ (i.e., $L = 5$).** Take $q = 32 = 2^5$, $a_1 = 5$ (odd, a
nd $5 < 32 \le 50$ ✓):
$$M = \frac{5 \cdot 10^5}{32} = 15625, \qquad N = 5 \cdot 10^5 + 15625 = 515625$
$
- $M = 15625$: digits $1, 5, 6, 2, 5$ — all non-zero. ✓
- $N = 515625$: digits $5, 1, 5, 6, 2, 5$ — all non-zero. ✓
- $N / M = 515625 / 15625 = 33$ — integer. ✓
- $a_1 = 5 \neq 0$, $a_2 = 1 \neq 0$, $a_6 = 5 \neq 0$. ✓

(Other valid examples: $a_1 = 7$ gives $M = 21875, N = 721875$; $a_1 = 9$ gives
$M = 28125, N = 928125$.)

**Conclusion.** The largest $n$ for which such a code exists is $\boxed{6}$.
