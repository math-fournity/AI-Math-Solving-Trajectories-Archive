## Answer: No — not every integrable function on $[0,N]$ can be approximated by
its Fourier series (partial sums).

Below is a complete proof. I show that there exist $L^1$ functions on $[0,N]$ wh
ose Fourier partial sums do **not** converge to the function in $L^1$-norm, and
in fact the set of such "bad" functions is topologically generic (residual) in $
L^1$.

---

### Step 1. Reduction to the standard interval $[-\pi,\pi]$

Via the linear change of variables $x \mapsto \frac{N}{2\pi}\,t$, the interval $
[0,N]$ is mapped to $[0,2\pi]$, and integrability is preserved. The Fourier syst
em $\{e^{2\pi i k x/N}\}_{k\in\mathbb Z}$ on $[0,N]$ is sent to the standard sys
tem $\{e^{ikt}\}_{k\in\mathbb Z}$ on $[0,2\pi]$. Shifting to $[-\pi,\pi]$ change
s nothing of substance. Hence it suffices to work on $[-\pi,\pi]$ with the stand
ard Fourier series
$$f(t)\sim \sum_{k=-\infty}^{\infty}\hat f(k)\,e^{ikt},\qquad \hat f(k)=\frac1{2
\pi}\int_{-\pi}^{\pi}f(t)\,e^{-ikt}\,dt.$$

### Step 2. The partial-sum operator and the Dirichlet kernel

The $n$-th symmetric partial sum is a convolution:
$$S_n(f)(x)=\sum_{k=-n}^{n}\hat f(k)\,e^{ikx}=\frac1{2\pi}\int_{-\pi}^{\pi}f(t)\
,D_n(x-t)\,dt,$$
where the **Dirichlet kernel** is
$$D_n(u)=\sum_{k=-n}^{n}e^{iku}=\frac{\sin\!\big((n+\tfrac12)u\big)}{\sin(u/2)}.
$$

$S_n:L^1([-\pi,\pi])\to L^1([-\pi,\pi])$ is a bounded linear operator (convoluti
on with $D_n$). Its operator norm equals the $L^1$-norm of the kernel:
$$\|S_n\|_{L^1\to L^1}=\|D_n\|_1=\frac1{2\pi}\int_{-\pi}^{\pi}|D_n(u)|\,du.$$

### Step 3. The $L^1$-norm of the Dirichlet kernel diverges (Lebesgue constants)

**Claim.** $\|D_n\|_1 = \dfrac{4}{\pi^2}\log n + O(1)\to\infty$.

*Proof of claim.* Near $u=0$, $\sin(u/2)\sim u/2$, so $|D_n(u)|\sim \dfrac{|\sin
((n+\tfrac12)u)|}{|u|/2}$. Splitting the integral:

$$\|D_n\|_1 \ge \frac1{2\pi}\int_{1/(2n+1)}^{\pi}\frac{2\,|\sin((n+\tfrac12)u)|}
{u}\,du.$$

On each interval where $\sin((n+\tfrac12)u)$ keeps a constant sign (there are $\
asymp n$ such intervals in $[1/(2n+1),\pi]$), the integral of $|\sin((n+\tfrac12
)u)|/u$ contributes $\asymp 1/\text{(interval index)}$. Summing gives $\sum_{j=1
}^{n}\frac1j\sim\log n$. Using $\frac1{2\pi}\int_0^\pi|\sin((n+\tfrac12)u)|\,du\
to\frac1\pi$ (mean value of $|\sin|$ is $2/\pi$), one obtains the precise asympt
otic
$$\|D_n\|_1=\frac{4}{\pi^2}\log n+O(1).\qquad\square$$

In particular $\|S_n\|_{L^1\to L^1}=\|D_n\|_1\to\infty$.

### Step 4. Banach–Steinhaus theorem (Uniform Boundedness Principle)

$L^1([-\pi,\pi])$ is a Banach space, and each $S_n$ is a bounded linear operator
 on it. Since
$$\sup_n\|S_n\|_{L^1\to L^1}=\sup_n\|D_n\|_1=\infty,$$
the **Banach–Steinhaus theorem** implies that the set
$$B:=\Big\{f\in L^1:\sup_n\|S_n(f)\|_1<\infty\Big\}$$
is of **first category** (meager) in $L^1$. Its complement $L^1\setminus B$ is r
esidual (dense $G_\delta$), hence in particular **nonempty** — indeed topologica
lly generic.

### Step 5. Failure of $L^1$-approximation

Take any $f\in L^1\setminus B$, so $\sup_n\|S_n(f)\|_1=\infty$. By the triangle
inequality,
$$\|S_n(f)-f\|_1\ge\big|\|S_n(f)\|_1-\|f\|_1\big|.$$
Since $\|S_n(f)\|_1$ is unbounded while $\|f\|_1$ is a fixed finite number, $\|S
_n(f)-f\|_1\to\infty$ along a subsequence. Therefore $S_n(f)\not\to f$ in $L^1$.

Moreover, the set of $f\in L^1$ for which $S_n(f)\to f$ in $L^1$ is contained in
 $B$, hence is **meager**. So not only does a single counterexample exist — *mos
t* $L^1$ functions (in the Baire-category sense) fail to be approximated by thei
r Fourier partial sums.

### Step 6. Conclusion

There exist integrable functions on $[0,N]$ — in fact a residual (topologically
generic) set of them — whose Fourier partial sums do not converge to the functio
n in $L^1$-norm. Hence the answer to the question is:

> **No.** Not every integrable function on $[0,N]$ can be approximated by its Fo
urier series (partial sums).

### Remarks (context, not part of the main argument)

1. **$L^2$ is fine.** If $f\in L^2\subset L^1$, the Riesz–Fischer theorem gives
$\|S_n(f)-f\|_2\to0$. The obstruction above is specific to $L^1\setminus L^2$.

2. **Fejér means work for all of $L^1$.** The Cesàro averages $\sigma_n(f)=\frac
1n\sum_{k=0}^{n-1}S_k(f)$ (Fejér means) satisfy $\|\sigma_n(f)-f\|_1\to0$ for **
every** $f\in L^1$, because the Fejér kernel $F_n$ has $\|F_n\|_1=1$ and is an a
pproximate identity. So every $L^1$ function *can* be recovered by a summability
 method — just not by the raw partial sums.

3. **Pointwise failure is even more dramatic.** Kolmogorov (1923) constructed an
 $L^1$ function whose Fourier series diverges at *every* point. (Later refined b
y others to divergence everywhere for an $L^1$ function, and to an $L^1$ functio
n whose partial sums are unbounded at every point.)

The distinction between "Fourier series" (partial sums, which fail for general $
L^1$) and "Fejér/Cesàro means" (which succeed for all $L^1$) is the crux of the
matter.
