## Solution

Let $H_k = 1 + \frac{1}{2} + \dots + \frac{1}{k}$ and $H_k^{(2)} = \sum_{j=1}^k
\frac{1}{j^2}$. Define the partial sum
$$S_n = \sum_{k=1}^n \left(H_k - \ln k - \gamma - \frac{1}{2k} + \frac{1}{12k^2}
\right).$$

**Step 1: Rewrite the partial sum.** Using $\sum_{k=1}^n H_k = (n+1)H_n - n$ and
 $\sum_{k=1}^n \ln k = \ln n!$:

$$S_n = (n+1)H_n - n - \ln n! - n\gamma - \tfrac{1}{2}H_n + \tfrac{1}{12}H_n^{(2
)} = \left(n+\tfrac{1}{2}\right)H_n - n - \ln n! - n\gamma + \tfrac{1}{12}H_n^{(
2)}.$$

**Step 2: Apply the asymptotic expansion of $H_n$.** The Euler–Maclaurin expansi
on gives
$$H_n = \ln n + \gamma + \frac{1}{2n} - \frac{1}{12n^2} + \frac{1}{120n^4} - \cd
ots$$
Multiplying by $\left(n+\frac{1}{2}\right)$ and collecting terms:
$$\left(n+\tfrac{1}{2}\right)H_n = n\ln n + \tfrac{1}{2}\ln n + n\gamma + \tfrac
{\gamma}{2} + \tfrac{1}{2} + \tfrac{1}{6n} - \tfrac{1}{24n^2} + \tfrac{1}{120n^3
} + \cdots$$

**Step 3: Apply Stirling's expansion.**
$$\ln n! = \left(n+\tfrac{1}{2}\right)\ln n - n + \tfrac{1}{2}\ln(2\pi) + \tfrac
{1}{12n} - \tfrac{1}{360n^3} + \cdots$$

**Step 4: Combine.** Subtracting:
$$\left(n+\tfrac{1}{2}\right)H_n - n - \ln n! - n\gamma = \tfrac{\gamma}{2} + \t
frac{1}{2} - \tfrac{1}{2}\ln(2\pi) + \tfrac{1}{12n} - \tfrac{1}{24n^2} + \tfrac{
1}{90n^3} + \cdots$$

**Step 5: Add the $H_n^{(2)}$ term.** Since $H_n^{(2)} = \zeta(2) - \frac{1}{n}
+ \frac{1}{2n^2} - \frac{1}{6n^3} + \cdots$,
$$\tfrac{1}{12}H_n^{(2)} = \tfrac{\pi^2}{72} - \tfrac{1}{12n} + \tfrac{1}{24n^2}
 - \tfrac{1}{72n^3} + \cdots$$

**Step 6: Take the limit.** Adding Steps 4 and 5, the $\frac{1}{12n}$ and $\frac
{1}{24n^2}$ terms cancel exactly, leaving
$$S_n = \frac{\gamma}{2} + \frac{1}{2} - \frac{1}{2}\ln(2\pi) + \frac{\pi^2}{72}
 + O\!\left(\frac{1}{n^3}\right).$$

Since the general term is $O(1/k^4)$ (as seen from the next term $\frac{1}{120k^
4}$ in the $H_k$ expansion), the series converges, and

$$\sum_{k=1}^\infty \left(H_k - \ln k - \gamma - \frac{1}{2k} + \frac{1}{12k^2}\
right) = \frac{\gamma}{2} + \frac{1}{2} - \frac{1}{2}\ln(2\pi) + \frac{\pi^2}{72
}.$$
