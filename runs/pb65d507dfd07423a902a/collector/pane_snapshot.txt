## Proof

**Setup.** Let $L = \{x \in C[0,1] : x \text{ is constant}\}$ and $f_0 \in L^*$
be defined by $f_0(x) = x(0)$. Since every $x \in L$ is constant, $x(0)$ equals
the constant value of $x$, so
$$\|f_0\| = \sup_{\substack{x \in L \\ \|x\|_\infty \le 1}} |x(0)| = \sup_{\subs
tack{x \in L \\ \|x\|_\infty \le 1}} \|x\|_\infty = 1.$$

The space $L_1 = \operatorname{span}(L, t)$ consists of all affine functions $x(
t) = a + bt$ ($a, b \in \mathbb{R}$), equipped with the sup norm $\|x\|_\infty =
 \max_{t \in [0,1]} |a+bt| = \max(|a|, |a+b|)$.

**Claim.** The functional $f \in L_1^*$ defined by
$$f(x) = x(0) \quad \text{for all } x \in L_1$$
satisfies $f|_L = f_0$ and $\|f\| = \|f_0\| = 1$.

**Verification that $f|_L = f_0$.** For any $x \in L$, $x$ is constant and $f(x)
 = x(0) = f_0(x)$ by definition. Hence $f|_L = f_0$. ✓

**Verification that $\|f\| = 1$.**

*Upper bound ($\|f\| \le 1$):* For every $x \in L_1$ (indeed for every $x \in C[
0,1]$),
$$|f(x)| = |x(0)| \le \sup_{t \in [0,1]} |x(t)| = \|x\|_\infty.$$
Therefore $\|f\| = \sup_{\|x\|_\infty \le 1} |f(x)| \le 1$.

*Lower bound ($\|f\| \ge 1$):* The constant function $\mathbf{1}(t) = 1$ belongs
 to $L \subset L_1$, with $\|\mathbf{1}\|_\infty = 1$, and
$$f(\mathbf{1}) = \mathbf{1}(0) = 1.$$
Hence $\|f\| \ge |f(\mathbf{1})| / \|\mathbf{1}\|_\infty = 1$.

Combining both bounds, $\|f\| = 1 = \|f_0\|$. ✓

**Explicit form.** For $x(t) = a + bt \in L_1$,
$$f(x) = x(0) = a.$$

**Remark (non-uniqueness).** More generally, any evaluation functional $f_\tau(x
) = x(\tau)$ for $\tau \in [0,1]$ is a norm-preserving extension of $f_0$ to $L_
1$: the restriction to $L$ recovers $f_0$ (constants evaluate to themselves at a
ny point), and $\|f_\tau\| = 1$ by the same argument ($|x(\tau)| \le \|x\|_\inft
y$, with equality at $x = \mathbf{1}$). Equivalently, writing $f(a+bt) = a + b\a
lpha$ with $\alpha = \tau$, the norm is $|1-\alpha| + |\alpha| = 1$ precisely fo
r $\alpha \in [0,1]$. The choice $\alpha = 0$ (i.e., $f(x) = x(0)$) given above
is the canonical Hahn–Banach extension.
