## Proof

We find all polynomials $p(x)$ such that $p(q(x)) = q(p(x))$ for every polynomia
l $q(x)$.

**Step 1. Reduce to degree $\leq 1$.**

Choose $q(x) = x + c$ for an arbitrary constant $c$. The identity gives
$$p(x+c) = p(x) + c \qquad \text{for all } x, c.$$

Write $p(x) = a_n x^n + \cdots + a_1 x + a_0$ with $a_n \neq 0$ (if $p$ is nonco
nstant, $n \geq 1$). Then
$$p(x+c) - p(x) = a_n\bigl((x+c)^n - x^n\bigr) + \cdots + a_1\bigl((x+c)-x\bigr)
.$$

If $n \geq 2$, the leading term of $(x+c)^n - x^n$ is $n x^{n-1} c$, so $p(x+c)-
p(x)$ is a nonconstant polynomial in $x$ (of degree $n-1 \geq 1$). But the right
 side $c$ is constant in $x$ — a contradiction. Hence $n \leq 1$.

If $p$ is constant, say $p(x) = a_0$, then $p(q(x)) = a_0$ while $q(p(x)) = q(a_
0)$. Taking $q(x) = x+1$ gives $a_0 = a_0 + 1$, impossible. So $p$ is nonconstan
t, $n=1$.

**Step 2. Determine the linear polynomial.**

Let $p(x) = ax + b$. From $p(x+c) = p(x) + c$:
$$a(x+c) + b = (ax+b) + c \implies ac = c \quad \text{for all } c \implies a = 1
.$$
So $p(x) = x + b$.

**Step 3. Pin down $b$.**

Now impose the original identity with $q(x) = x^2$:
$$p(q(x)) = x^2 + b, \qquad q(p(x)) = (x+b)^2 = x^2 + 2bx + b^2.$$
Equating: $x^2 + b = x^2 + 2bx + b^2$ for all $x$, so $2bx + (b^2 - b) = 0$ for
all $x$. This forces $b = 0$.

**Step 4. Verification.**

With $p(x) = x$: $p(q(x)) = q(x) = q(p(x))$ for every polynomial $q$. ✓

**Conclusion.** The unique polynomial satisfying the condition is
$$\boxed{p(x) = x}.$$
