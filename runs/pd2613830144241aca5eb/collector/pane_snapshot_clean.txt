## Answer

**No.** Not every subset of $\mathbb{R}$ with Lebesgue measure zero is a $K_{\si
gma}$ set. Below is a construction of a null set that is not $K_{\sigma}$, toget
her with the proof.

---

### Preliminary observation

In $\mathbb{R}$, every closed set $F$ is $K_{\sigma}$, since
$$F = \bigcup_{n=1}^{\infty} \bigl(F \cap [-n,n]\bigr),$$
and each $F \cap [-n,n]$ is closed and bounded, hence compact. Consequently
$$K_{\sigma} = F_{\sigma} \quad\text{in } \mathbb{R}.$$
So it suffices to produce a null set that is **not** $F_{\sigma}$.

---

### Construction of a dense $G_{\delta}$ null set

Enumerate the rationals: $\mathbb{Q} = \{q_1, q_2, \dots\}$. For each $n \ge 1$,
 define the open set
$$U_n = \bigcup_{k=1}^{\infty} \Bigl(q_k - \varepsilon_{n,k},\; q_k + \varepsilo
n_{n,k}\Bigr), \qquad \text{where } \varepsilon_{n,k} = \frac{1}{n \cdot 2^{k+2}
}.$$

Each $U_n$ is open and contains $\mathbb{Q}$, hence is **dense**. Its measure sa
tisfies
$$m(U_n) \le \sum_{k=1}^{\infty} 2\varepsilon_{n,k} = \sum_{k=1}^{\infty} \frac{
2}{n \cdot 2^{k+2}} = \frac{1}{n}\sum_{k=1}^{\infty}\frac{1}{2^{k+1}} = \frac{1}
{n}.$$

Now set
$$G = \bigcap_{n=1}^{\infty} U_n.$$

**Properties of $G$:**

1. **$G$ is $G_{\delta}$** — a countable intersection of open sets.

2. **$G$ is dense (in fact comeager)** — each $U_n$ is open and dense, so by the
 Baire category theorem $G$ is a dense $G_{\delta}$, i.e. **comeager** in $\math
bb{R}$.

3. **$m(G) = 0$** — since $G \subseteq U_n$ for every $n$, we have $m(G) \le m(U
_n) \le 1/n$ for every $n$, giving $m(G) = 0$.

So $G$ is a **comeager set of Lebesgue measure zero**.

---

### $G$ is not $K_{\sigma}$ (equivalently, not $F_{\sigma}$)

Suppose for contradiction that $G$ were $F_{\sigma}$, say $G = \bigcup_{m=1}^{\i
nfty} F_m$ with each $F_m$ closed.

Since $m(G) = 0$ and $F_m \subseteq G$, we have $m(F_m) = 0$ for every $m$. A cl
osed set in $\mathbb{R}$ with positive measure must contain a nondegenerate inte
rval and hence have nonempty interior; contrapositively, **each $F_m$ has empty
interior**. Being closed with empty interior, each $F_m$ is **nowhere dense**.

Therefore
$$G = \bigcup_{m=1}^{\infty} F_m$$
is a countable union of nowhere dense sets, i.e. $G$ is **meager**.

But $G$ is **comeager** (its complement $\mathbb{R}\setminus G = \bigcup_n (\mat
hbb{R}\setminus U_n)$ is a countable union of nowhere dense sets, hence meager).
 A set cannot be both meager and comeager in $\mathbb{R}$: if $G$ were both, the
n $\mathbb{R} = G \cup (\mathbb{R}\setminus G)$ would be meager, contradicting t
he Baire category theorem (which states that the complete metric space $\mathbb{
R}$ is not meager in itself).

This contradiction shows that $G$ is **not** $F_{\sigma}$, hence **not** $K_{\si
gma}$.

---

### Conclusion

The set $G$ constructed above has Lebesgue measure zero but is not a countable u
nion of compact sets. Therefore **not every subset of $\mathbb{R}$ of zero Lebes
gue measure is a $K_{\sigma}$ set**.
