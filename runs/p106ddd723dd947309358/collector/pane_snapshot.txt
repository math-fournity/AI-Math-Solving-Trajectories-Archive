## Answer

**No.** Not all singular functions are of bounded variation. Below is a countere
xample: a continuous, non-constant function on $[0,1]$ whose derivative vanishes
 almost everywhere, yet whose total variation is infinite.

---

### Definitions

A function $f:[a,b]\to\mathbb{R}$ is **singular** if it is continuous, non-const
ant, and $f'(x)=0$ for Lebesgue-almost-every $x\in[a,b]$. (The Cantor–Lebesgue "
devil's staircase" is the canonical example; note the definition does **not** re
quire monotonicity.)

A function is of **bounded variation (BV)** if its total variation $V_a^b(f)=\su
p_{\mathcal{P}}\sum|f(x_i)-f(x_{i-1})|$ is finite.

---

### Counterexample construction

Let $C:[0,1]\to[0,1]$ denote the Cantor function (continuous, non-decreasing, $C
'=0$ a.e., $C(0)=0$, $C(1)=1$).

Choose a sequence of pairwise disjoint closed intervals $I_n=[a_n,b_n]\subset[0,
1]$ with midpoints $m_n=(a_n+b_n)/2$, with $\sum_n(b_n-a_n)<1$, and with the int
ervals accumulating only at $0$ (so that $\max_{k\ge n} b_k\to 0$). Set $h_n=\tf
rac{1}{n}$, so $h_n\to 0$ and $\sum_n h_n=\infty$.

Define $f:[0,1]\to\mathbb{R}$ by

$$
f(x)=\begin{cases}
h_n\,C\!\Big(\dfrac{x-a_n}{m_n-a_n}\Big), & x\in[a_n,m_n],\\[6pt]
h_n\,C\!\Big(\dfrac{b_n-x}{b_n-m_n}\Big), & x\in[m_n,b_n],\\[6pt]
0, & x\in[0,1]\setminus\bigcup_n I_n .
\end{cases}
$$

So on each $I_n$ the graph is a "tent" of height $h_n$ built from two copies of
the Cantor staircase; outside the $I_n$ the function is identically $0$.

---

### Verification of the four required properties

**1. Continuity.** On each $I_n$, $f$ is a composition of the continuous Cantor
function with affine maps, hence continuous. At the endpoints $a_n,b_n$ we have
$f(a_n)=f(b_n)=0$, matching the value $0$ on the exterior, so $f$ is continuous
there. At the unique accumulation point $0$: since $h_n\to 0$ and $b_n\to 0$, fo
r any $\varepsilon>0$ choose $N$ with $h_N<\varepsilon$; then for all $x\in[0,b_
N]$ we have $|f(x)|\le \max_{n\ge N}h_n<\varepsilon$. Hence $f$ is continuous at
 $0$ as well. Thus $f\in C[0,1]$.

**2. Non-constant.** $f(m_n)=h_n\cdot C(1)=h_n=1/n>0$, while $f=0$ on the exteri
or. So $f$ is non-constant.

**3. Derivative vanishes a.e.** On the open set $[0,1]\setminus\bigcup_n I_n$ th
e function is constant ($\equiv 0$), so $f'=0$ there. On each $I_n$, $f$ is an a
ffine rescaling of $C$ on each half; since $C'=0$ a.e. on $[0,1]$, we get $f'=0$
 a.e. on $I_n$, the exceptional set being a rescaled copy of the Cantor set (mea
sure $0$). The set where $f'\ne 0$ (or $f'$ does not exist) is contained in $\bi
gcup_n\{\text{rescaled Cantor set in }I_n\}$, a countable union of measure-zero
sets, hence of measure $0$. Therefore

$$f'(x)=0 \quad\text{for a.e. }x\in[0,1].$$

So $f$ is singular.

**4. Not of bounded variation.** On each $I_n$ the function rises from $0$ to $h
_n$ (at $m_n$) and falls back to $0$ (at $b_n$). Hence the variation of $f$ on $
I_n$ is at least $2h_n$. For any $N$,

$$V_0^1(f)\;\ge\;\sum_{n=1}^{N}V_{I_n}(f)\;\ge\;\sum_{n=1}^{N}2h_n=2\sum_{n=1}^{
N}\frac1n.$$

As $N\to\infty$ the harmonic series diverges, so $V_0^1(f)=+\infty$. Thus $f\not
in BV[0,1]$.

---

### Conclusion

We have exhibited a function $f$ that is continuous, non-constant, and satisfies
 $f'=0$ a.e. (hence singular), yet has infinite total variation. Therefore

> **Not all singular functions are of bounded variation.**

*(Remark. If one adopts the alternative, narrower convention that a "singular fu
nction" must additionally be monotone non-decreasing—as is sometimes done when d
iscussing the Lebesgue decomposition of BV functions—then every such function is
 automatically BV, with $V_a^b(f)=f(b)-f(a)$. Under the standard definition used
 above, however, the answer is negative, and the construction above is the count
erexample.)*
