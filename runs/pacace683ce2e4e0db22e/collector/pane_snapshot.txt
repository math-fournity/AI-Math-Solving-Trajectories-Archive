# Full Asymptotic Expansion of Ai(x) for Large Positive x

## Setup and Change of Variable

The Airy function satisfies $y'' - xy = 0$, i.e., $y'' = xy$. Introduce the stan
dard phase variable

$$\zeta = \tfrac{2}{3}\,x^{3/2}, \qquad x = \left(\tfrac{3\zeta}{2}\right)^{2/3}
.$$

Since $d\zeta/dx = x^{1/2}$, we have $d/dx = x^{1/2}\,d/d\zeta$ and

$$\frac{d^2}{dx^2} = \tfrac{1}{2}\,x^{-1/2}\frac{d}{d\zeta} + x\,\frac{d^2}{d\ze
ta^2}.$$

The Airy equation becomes (dividing by $x$, using $x^{-3/2} = 2/(3\zeta)$):

$$\frac{d^2 y}{d\zeta^2} + \frac{1}{3\zeta}\,\frac{dy}{d\zeta} - y = 0. \tag{1}$
$

## Removing the First-Derivative Term

Set $y = \zeta^{-1/6}\,u(\zeta)$. A standard calculation gives:

$$y_{\zeta\zeta} + \frac{1}{3\zeta}\,y_\zeta = \zeta^{-1/6}\,u'' + \frac{5}{36}\
,\zeta^{-13/6}\,u,$$

so equation (1) reduces to

$$u'' = \left(1 - \frac{5}{36\,\zeta^2}\right)u. \tag{2}$$

## Peeling Off the Leading Exponential

For the **decaying** solution (Ai), set $u = e^{-\zeta}\,w(\zeta)$. Then $u'' =
e^{-\zeta}(w'' - 2w' + w)$, and (2) becomes:

$$w'' - 2w' = -\frac{5}{36\,\zeta^2}\,w. \tag{3}$$

## Series Expansion of the Remaining Factor

Seek a formal asymptotic series $w \sim \sum_{n=0}^{\infty} b_n\,\zeta^{-n}$ wit
h $b_0 = 1$. Substituting into (3):

- $w'' = \sum_{n=1}^{\infty} n(n+1)\,b_n\,\zeta^{-n-2}$,
- $-2w' = 2\sum_{n=1}^{\infty} n\,b_n\,\zeta^{-n-1}$,
- RHS $= -\frac{5}{36}\sum_{n=0}^{\infty} b_n\,\zeta^{-n-2}$.

Re-indexing all sums to the power $\zeta^{-k}$ and equating coefficients:

**At $k=2$** (i.e. $\zeta^{-2}$): $\;2\,b_1 = -\frac{5}{36}\,b_0$, giving $b_1 =
 -\frac{5}{72}$.

**At $k \geq 3$**: collecting the $w''$ contribution $(k{-}2)(k{-}1)\,b_{k-2}$ a
nd the $-2w'$ contribution $2(k{-}1)\,b_{k-1}$:

$$2(k-1)\,b_{k-1} = -\frac{5}{36}\,b_{k-2} - (k-2)(k-1)\,b_{k-2}.$$

Setting $m = k-1$:

$$\boxed{b_m = -\frac{36m^2 - 36m + 5}{72\,m}\;b_{m-1} = -\frac{(6m-1)(6m-5)}{72
\,m}\;b_{m-1}}, \qquad m \geq 1. \tag{4}$$

Since $b_n = (-1)^n u_n$, the coefficients $u_n = (-1)^n b_n$ satisfy the **posi
tive** recurrence:

$$u_0 = 1, \qquad u_n = \frac{(6n-1)(6n-5)}{72\,n}\;u_{n-1}. \tag{5}$$

## Closed Form for the Coefficients

Iterating (5):

$$u_n = \frac{\displaystyle\prod_{m=1}^{n}(6m-1)(6m-5)}{72^n\,n!}.$$

Recognizing the products via Pochhammer symbols $(a)_n = \Gamma(a{+}n)/\Gamma(a)
$:

$$\prod_{m=1}^{n}(6m-5) = 6^n\left(\tfrac{1}{6}\right)_n, \qquad \prod_{m=1}^{n}
(6m-1) = 6^n\left(\tfrac{5}{6}\right)_n,$$

so

$$\boxed{u_n = \frac{\left(\frac{1}{6}\right)_n\left(\frac{5}{6}\right)_n}{2^n\,
n!}}. \tag{6}$$

**First few values:**

| $n$ | $u_n$ |
|-----|-------|
| 0 | $1$ |
| 1 | $\dfrac{5}{72}$ |
| 2 | $\dfrac{385}{10368}$ |
| 3 | $\dfrac{85085}{2239488}$ |
| 4 | $\dfrac{37182145}{644972544}$ |

## Normalization

The overall multiplicative constant is fixed by the integral representation $\ma
thrm{Ai}(x) = \frac{1}{\pi}\int_0^\infty \cos\!\bigl(\frac{t^3}{3}+xt\bigr)\,dt$
. Applying the method of steepest descent (saddle at $t_0 = -\sqrt{x}$, $\zeta_0
 = \frac{2}{3}x^{3/2}$) yields the Gaussian prefactor $\frac{1}{2\sqrt{\pi}\,x^{
1/4}}$. Equivalently, $\zeta^{-1/6} = (2/3)^{-1/6}x^{-1/4}$ from our substitutio
n, and the saddle-point integral supplies the constant $(2/3)^{1/6}/(2\sqrt{\pi}
)$, giving the net factor $\frac{1}{2\sqrt{\pi}\,x^{1/4}}$.

## Result

Assembling $y = \zeta^{-1/6}\,e^{-\zeta}\,w$ with $\zeta = \frac{2}{3}x^{3/2}$ a
nd $w = \sum_{n=0}^{\infty}(-1)^n u_n\,\zeta^{-n}$:

$$\boxed{\mathrm{Ai}(x) \sim \frac{1}{2\sqrt{\pi}\;x^{1/4}}\;\exp\!\left(-\tfrac
{2}{3}\,x^{3/2}\right)\;\sum_{n=0}^{\infty}(-1)^n\;\frac{u_n}{\left(\tfrac{2}{3}
\,x^{3/2}\right)^n}}, \qquad x \to +\infty, \tag{7}$$

where

$$u_n = \frac{\left(\frac{1}{6}\right)_n\left(\frac{5}{6}\right)_n}{2^n\;n!} = \
frac{\displaystyle\prod_{m=1}^{n}(6m-1)(6m-5)}{72^n\;n!}, \qquad u_0 = 1.$$

The series is **asymptotic** (divergent for every fixed $x$): the ratio $|u_{n+1
}/u_n| \sim 36n/(72) = n/2 \to \infty$, so the terms eventually grow. For fixed
large $x$, optimal truncation occurs at $n \sim \zeta = \frac{2}{3}x^{3/2}$, yie
lding an exponentially small remainder $O\!\bigl(e^{-c\,x^{3/2}}\bigr)$ beyond t
he leading exponential.
