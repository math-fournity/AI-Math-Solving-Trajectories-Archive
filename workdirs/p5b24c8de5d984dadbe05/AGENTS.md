# Problem

In a specialized research facility, an 8x8 grid of containment pods houses 64 genetically engineered fireflies, with exactly one firefly per pod. The facility manager initiates a synchronization protocol that forces every firefly to relocate simultaneously according to a strict directional algorithm:

Each firefly must attempt to move to a new pod based on these two options:
1. Move exactly one pod to the left.
2. Move exactly one pod diagonally to the right and down.

If a firefly’s specific location on the grid makes both of these moves impossible (i.e., both moves would lead outside the 8x8 boundaries), that firefly is required to remain in its current pod. If a firefly has only one valid move out of the two options, it must take that move. If both moves are physically possible, the firefly may choose either one. 

After all fireflies have completed their movement according to these rules, multiple fireflies may end up occupying the same pod. What is the maximum number of pods that can be left entirely unoccupied?
