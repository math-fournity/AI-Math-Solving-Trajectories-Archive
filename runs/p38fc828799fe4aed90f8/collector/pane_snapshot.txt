## Solution

**Claim:** $N = |\mathbb{R}| = 2^{\aleph_0}$, the cardinality of the continuum.

### Proof

We establish $N = |\mathbb{R}|$ by showing $N \geq |\mathbb{R}|$ and $N \leq |\m
athbb{R}|$.

**Lower bound: $N \geq |\mathbb{R}|$.**

For each point $p \in S^2$, define the constant map $f_p : S^2 \to S^2$ by $f_p(
x) = p$ for all $x \in S^2$. This map is continuous. Its fixed-point set is
$$\operatorname{Fix}(f_p) = \{x \in S^2 : f_p(x) = x\} = \{x \in S^2 : p = x\} =
 \{p\},$$
which is a single point. Since $|S^2| = |\mathbb{R}|$ and distinct points $p \ne
q p'$ yield distinct constant maps $f_p \neq f_{p'}$, we obtain at least $|\math
bb{R}|$ distinct continuous maps with exactly one fixed point. Hence
$$N \geq |\mathbb{R}|.$$

**Upper bound: $N \leq |\mathbb{R}|$.**

The sphere $S^2$ is a compact metric space, hence **separable**: it admits a cou
ntable dense subset $D \subset S^2$. A key fact is that a continuous map into a
Hausdorff space is determined by its values on any dense subset. Indeed, if $f,
g : S^2 \to S^2$ are continuous and $f|_D = g|_D$, then for any $x \in S^2$, tak
e a sequence $(d_n) \subset D$ with $d_n \to x$; by continuity, $f(x) = \lim f(d
_n) = \lim g(d_n) = g(x)$. Thus the restriction map
$$C(S^2, S^2) \longrightarrow (S^2)^D, \qquad f \longmapsto f|_D$$
is injective. Therefore
$$|C(S^2, S^2)| \leq |S^2|^{|D|} = |\mathbb{R}|^{\aleph_0} = (2^{\aleph_0})^{\al
eph_0} = 2^{\aleph_0 \cdot \aleph_0} = 2^{\aleph_0} = |\mathbb{R}|.$$
Since the set of maps with exactly one fixed point is a subset of $C(S^2, S^2)$,
 we have
$$N \leq |\mathbb{R}|.$$

**Conclusion.**

Combining both bounds:
$$N = |\mathbb{R}| = 2^{\aleph_0}.$$

The number of distinct continuous maps $f : S^2 \to S^2$ with exactly one fixed
point equals the cardinality of the continuum. $\blacksquare$
