Looking at this problem, I need to arrange 1, 2, ..., 1962 in a cycle to maximiz
e the sum of absolute consecutive differences.

## Proof

**Contribution decomposition.** For each edge $|a_i - a_{i+1}| = \max(a_i,a_{i+1
}) - \min(a_i,a_{i+1})$. Summing over all 1962 edges of the cycle:

$$S = \sum_{v} c_v \cdot v,$$

where $c_v = (\text{#edges in which } v \text{ is the larger endpoint}) - (\text
{#edges in which } v \text{ is the smaller endpoint})$.

Each vertex has degree exactly 2 in the cycle, so $c_v \in \{-2, 0, +2\}$:
- $c_v = +2$: $v$ is a local maximum (peak),
- $c_v = -2$: $v$ is a local minimum (valley),
- $c_v = 0$: $v$ is a slope point.

**Counting constraint.** Since each edge contributes $+1$ to one endpoint and $-
1$ to the other, $\sum_v c_v = 0$. Hence the number of peaks equals the number o
f valleys; call this number $k$. Then $2k \le 1962$, so $k \le 981$.

**Upper bound.** To maximize $S = 2\sum_{\text{peaks}} v - 2\sum_{\text{valleys}
} v$, assign the $k$ largest values to peaks and the $k$ smallest to valleys. Wi
th $k \le 981$:

$$S \le 2\!\sum_{i=982}^{1962} i \;-\; 2\!\sum_{i=1}^{981} i.$$

Computing:
- $\sum_{i=1}^{981} i = \dfrac{981 \cdot 982}{2} = 481671$,
- $\sum_{i=1}^{1962} i = \dfrac{1962 \cdot 1963}{2} = 1925703$,
- $\sum_{i=982}^{1962} i = 1925703 - 481671 = 1444032$.

$$S \le 2 \cdot 1444032 - 2 \cdot 481671 = 2888064 - 963342 = 1924722.$$

**Construction achieving the bound.** Take $k = 981$ and arrange:

$$1,\; 1962,\; 2,\; 1961,\; 3,\; 1960,\; \ldots,\; 981,\; 982,$$

i.e., $a_{2j-1} = j$ and $a_{2j} = 1963 - j$ for $j = 1, \ldots, 981$.

*Verification.* Each even-positioned element $a_{2j} = 1963 - j \ge 982$ sits be
tween $a_{2j-1} = j$ and $a_{2j+1} = j+1$ (with $a_{1963} = a_1 = 1$ for the wra
p-around), and $1963 - j > j+1$ for all $j \le 981$, so every even position is a
 peak. Each odd-positioned element $a_{2j-1} = j \le 981$ sits between two value
s $\ge 982$, so every odd position is a valley.

Thus peaks $= \{982, \ldots, 1962\}$ (all $c_v = +2$) and valleys $= \{1, \ldots
, 981\}$ (all $c_v = -2$), giving exactly

$$S = 2\sum_{i=982}^{1962} i - 2\sum_{i=1}^{981} i = 1924722.$$

## Answer

The maximum value of the sum is $\boxed{1924722}$, achieved for example by the a
rrangement $1, 1962, 2, 1961, 3, 1960, \ldots, 981, 982$.
