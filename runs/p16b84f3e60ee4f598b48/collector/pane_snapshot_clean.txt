**Key facts I'll use:**

## Denominator Analysis

$$D(n) = \log\frac{\pi(n)}{n} + \log\frac{m_n}{\phi(m_n)}$$

**First term:** By PNT, $\pi(n) \sim n/\log n$, so:
$$\log\frac{\pi(n)}{n} = \log\pi(n) - \log n = \bigl(\log n - \log\log n + o(1)\
bigr) - \log n = -\log\log n + o(1).$$

**Second term:** By Mertens' third theorem (with $x = p_n$):
$$\log\frac{m_n}{\phi(m_n)} = \sum_{p \le p_n}\log\frac{p}{p-1} = \gamma + \log\
log p_n + o(1).$$

**Combining:**
$$D(n) = -\log\log n + \gamma + \log\log p_n + o(1) = \gamma + \log\!\left(\frac
{\log p_n}{\log n}\right) + o(1).$$

Since $p_n \sim n\log n$, we have $\log p_n = \log n + \log\log n + o(1)$, so:
$$\frac{\log p_n}{\log n} = 1 + \frac{\log\log n}{\log n} + o\!\left(\frac{1}{\l
og n}\right) \longrightarrow 1,$$
and therefore $\log\!\left(\frac{\log p_n}{\log n}\right) \to 0$.

$$\boxed{D(n) \to \gamma \approx 0.5772}$$

## Numerator Analysis

$$N(n) = \sum_{n < p \le p_n}\log\frac{p}{p-1} = \sum_{p \le p_n}\log\frac{p}{p-
1} \;-\; \sum_{p \le n}\log\frac{p}{p-1}$$

Applying Mertens' third theorem to both sums:

$$N(n) = \bigl(\gamma + \log\log p_n + o(1)\bigr) - \bigl(\gamma + \log\log n +

$$N(n) = \log\!\left(\frac{\log p_n}{\log n}\right) + o(1) \longrightarrow 0.$$

## The Limit

Since $N(n) \to 0$ and $D(n) \to \gamma \neq 0$:

$$\lim_{n\to\infty}\frac{N(n)}{D(n)} = \frac{0}{\gamma} = 0.$$
