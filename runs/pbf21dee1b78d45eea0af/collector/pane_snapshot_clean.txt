## Solution

**Step 1: Substitution.** Define $b_n = \sqrt{1+24a_n}$ (positive since $a_n>0$)
. Then $a_n = \frac{b_n^2-1}{24}$, and $b_1 = \sqrt{1+24\cdot 1} = 5$.

**Step 2: Recurrence for $b_n$.** Using the given recurrence:
$$a_{n+1} = \frac{1}{16}\!\left(1 + 4\cdot\frac{b_n^2-1}{24} + b_n\right) = \fra
c{1}{16}\cdot\frac{6 + b_n^2-1 + 6b_n}{6} = \frac{b_n^2+6b_n+5}{96} = \frac{(b_n
+1)(b_n+5)}{96}.$$

Hence
$$b_{n+1}^2 = 1 + 24a_{n+1} = 1 + \frac{(b_n+1)(b_n+5)}{4} = \frac{4 + b_n^2+6b_
n+5}{4} = \frac{(b_n+3)^2}{4}.$$

Since $b_n>0$, we take the positive root:
$$b_{n+1} = \frac{b_n+3}{2}.$$

**Step 3: Solve the linear recurrence.** The fixed point is $b=3$. Setting $c_n
= b_n - 3$:
$$c_{n+1} = \frac{c_n}{2}, \qquad c_1 = b_1 - 3 = 2.$$
Thus $c_n = 2\cdot 2^{-(n-1)} = 2^{2-n}$, giving
$$b_n = 3 + 2^{2-n}.$$

**Step 4: Recover $a_n$.**
$$a_n = \frac{b_n^2-1}{24} = \frac{(3+2^{2-n})^2-1}{24} = \frac{8 + 6\cdot 2^{2-
n} + 2^{4-2n}}{24} = \frac{1}{3} + \frac{1}{2^n} + \frac{2}{3\cdot 4^n}.$$

Combining over the common denominator $3\cdot 4^n = 3\cdot 2^{2n}$:
$$a_n = \frac{2^{2n} + 3\cdot 2^n + 2}{3\cdot 2^{2n}} = \frac{(2^n+1)(2^n+2)}{3\
cdot 4^n}.$$

**Verification.**
- $n=1$: $\frac{3\cdot 4}{3\cdot 4}=1$ ✓
- $n=2$: $\frac{5\cdot 6}{3\cdot 16}=\frac{30}{48}=\frac{5}{8}$, and direct comp
utation gives $\frac{1}{16}(1+4+\sqrt{25})=\frac{10}{16}=\frac{5}{8}$ ✓
- $n=3$: $\frac{9\cdot 10}{3\cdot 64}=\frac{90}{192}=\frac{15}{32}$, matching di
rect computation ✓

**Inductive check of the recurrence.** With $b_n = 3+2^{2-n}$ we have $b_{n+1}=\
frac{b_n+3}{2}=3+2^{1-n}=3+2^{2-(n+1)}$ ✓, and the derivation above is reversibl
e, so the closed form satisfies the recurrence with the correct initial value.

$$\boxed{\,a_n = \frac{(2^n+1)(2^n+2)}{3\cdot 4^n} = \frac{1}{3}+\frac{1}{2^n}+\
frac{2}{3\cdot 4^n}\,}$$
