## Proof

**Step 1: Compute the integral.**

Let $f(x) = \sum_{k=0}^n a_k x^k$ with $a_k \in \mathbb{Z}$, $a_n \neq 0$. Then

$$I = \int_{-1}^1 x^n f(x)\,dx = \sum_{k=0}^n a_k \int_{-1}^1 x^{n+k}\,dx.$$

Since $\int_{-1}^1 x^m\,dx = 0$ for $m$ odd and $= \frac{2}{m+1}$ for $m$ even,
only terms with $n+k$ even (i.e., $k \equiv n \pmod{2}$) contribute:

$$I = \sum_{\substack{0 \le k \le n \\ k \equiv n \!\!\pmod{2}}} \frac{2\,a_k}{n
+k+1}.$$

**Step 2: Identify the lattice.**

Let $S = \{k \in \{0,\ldots,n\} : k \equiv n \pmod{2}\}$ and $r_k = \frac{2}{n+k
+1}$ for $k \in S$. The set of achievable values is $\{\sum_{k \in S} a_k r_k :
a_k \in \mathbb{Z},\, a_n \neq 0\}$.

The denominators $d_k = n+k+1$ for $k \in S$ are **consecutive odd numbers**: fo
r $n$ even, $\{n+1, n+3, \ldots, 2n+1\}$; for $n$ odd, $\{n+2, n+4, \ldots, 2n+1
\}$. In both cases these are odd numbers in $[n+1, 2n+1]$ with maximum $2n+1$.

The full lattice $L = \{\sum_{k\in S} a_k r_k : a_k \in \mathbb{Z}\}$ is generat
ed by $\{2/d_k\}$. Since each $d_k$ is odd, $\gcd(2, d_k)=1$, so each $r_k = 2/d
_k$ is in lowest terms. Setting $Q = \operatorname{lcm}(d_1,\ldots,d_m)$, the la
ttice $L = \frac{2g}{Q}\mathbb{Z}$ where $g = \gcd(Q/d_1, \ldots, Q/d_m)$.

**Step 3: Show $g = 1$.**

For any prime $p$:
$$v_p(g) = \min_i v_p(Q/d_i) = \min_i\bigl(v_p(Q) - v_p(d_i)\bigr) = v_p(Q) - \m
ax_i v_p(d_i) = 0,$$
since $v_p(Q) = \max_i v_p(d_i)$ by definition of lcm. Therefore $g = 1$ and the
 lattice generator is $d = 2/Q$.

**Step 4: The constraint $a_n \neq 0$ doesn't change $\alpha_n$.**

Let $L' \subseteq L$ be the sublattice generated by $\{r_k : k \in S, k \neq n\}
$, with $L' = d'\mathbb{Z}$, $d' \ge d$.

- If $L' = L$: take $a_n = 1$; then $d = r_n + (d - r_n)$ with $d - r_n \in L' =
 L$, so $d$ is achieved with $a_n = 1 \neq 0$.
- If $L' \neq L$ ($d' > d$): the achievable values with $a_n \neq 0$ are $\{a_n
r_n + m d' : a_n \neq 0, m \in \mathbb{Z}\}$, whose smallest positive element is
 $\gcd(r_n, d') = d$ (since $L = \gcd(r_n, d')\mathbb{Z}$).

In both cases, $\alpha_n = d = 2/Q$.

**Step 5: Compute $\log Q$ asymptotically.**

For each odd prime $p$, I claim $v_p(Q) = \lfloor \log_p(2n+1) \rfloor$:

- If $p^k \le 2n+1$ and $p^k \ge n+1$: then $p^k$ itself lies in $[n+1, 2n+1]$ a
nd is odd, so $v_p(Q) \ge k$.
- If $p^k < n+1$: the interval $[n+1, 2n+1]$ has length $n \ge p^k$, so it conta
ins a multiple of $p^k$; since $p^k$ is odd, consecutive multiples alternate in
parity, guaranteeing an **odd** multiple of $p^k$ in the interval. Thus $v_p(Q)
\ge k$.
- If $p^k > 2n+1$: no multiple of $p^k$ lies in the interval, so $v_p(Q) < k$.

Therefore:
$$\log Q = \sum_{\substack{p \le 2n+1 \\ p \text{ odd prime}}} \lfloor \log_p(2n
+1)\rfloor \log p = \psi(2n+1) - \lfloor \log_2(2n+1)\rfloor \log 2,$$

where $\psi(x) = \sum_{p^k \le x} \log p$ is the Chebyshev function. By the Prim
e Number Theorem, $\psi(x) \sim x$, so $\psi(2n+1) \sim 2n$. The correction term
 is $O(\log n)$. Hence:

$$\log Q \sim 2n.$$

**Step 6: Compute the limit.**

$$\frac{\log \alpha_n}{n} = \frac{\log(2/Q)}{n} = \frac{\log 2}{n} - \frac{\log
Q}{n} \;\longrightarrow\; 0 - 2 = -2.$$
