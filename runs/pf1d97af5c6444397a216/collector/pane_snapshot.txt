## Proof

Assume $f$ is bounded and Borel measurable (so that $f_n$ is measurable; this is
 the standard interpretation under which the integral is well-defined). Let $M =
 \sup_{x\in\mathbb{R}} |f(x)| < \infty$.

**Pointwise limit of $f_n$.** Consider $x \in \mathbb{R}$:

- If $|x| < 1$, then $x^n \to 0$, so $f_n(x) = f(x^n) \to f(0)$.
- If $x = 1$, then $f_n(1) = f(1)$ for all $n$.
- If $x = -1$, then $f_n(-1) = f((-1)^n)$, which oscillates but stays bounded.
- If $|x| > 1$, then $\mathbb{1}_{[-1,1]}(x) = 0$, so $f_n(x) = 0$.

Thus $f_n(x) \to f(0)\cdot\mathbb{1}_{[-1,1]}(x)$ for every $x \in \mathbb{R}\se
tminus\{-1,1\}$, i.e. **almost everywhere** (since $\{-1,1\}$ has Lebesgue measu
re $0$).

**Domination.** For all $n$ and all $x$,
$$|f_n(x)| = |f(x^n)|\,\mathbb{1}_{[-1,1]}(x) \le M\cdot\mathbb{1}_{[-1,1]}(x),$
$
and $M\cdot\mathbb{1}_{[-1,1]}$ is integrable since $\lambda([-1,1]) = 2 < \inft
y$.

**Applying Dominated Convergence.** By the Dominated Convergence Theorem,
$$\lim_{n\to\infty}\int f_n\,d\lambda = \int \lim_{n\to\infty} f_n\,d\lambda = \
int f(0)\,\mathbb{1}_{[-1,1]}\,d\lambda = f(0)\cdot\lambda([-1,1]) = 2f(0).$$

$$\boxed{\lim_{n\to\infty}\int f_n\,d\lambda = 2f(0).}$$
