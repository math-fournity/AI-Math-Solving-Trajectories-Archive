# Problem

In a specialized laboratory, a high-precision robotic arm moves along a straight laser track. The track is calibrated with two starting beacons: one at the "Origin" (Position 0) and one at the "First Marker" (Position 1).

The robot can perform only one specific maneuver: it chooses any two existing markers on the track, designated as Marker A and Marker B, and places a new marker at a position such that Marker B is the exact midpoint between Marker A and the new marker. (For example, if the robot uses the Origin and the First Marker as its reference points, it would place a new marker at Position 2).

Let $f(n)$ represent the minimum number of these maneuvers required to place a marker at an integer coordinate $n$ on the laser track.

Calculate the value of $f(2025) + f(-100)$.
