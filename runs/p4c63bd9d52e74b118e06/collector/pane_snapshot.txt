## Solution

The Bessel equation of order $\nu = \tfrac{3}{2}$ is:
$$x^2 y'' + xy' + \left(x^2 - \tfrac{9}{4}\right)y = 0, \quad x > 0.$$

Since $\nu = \tfrac{3}{2}$ is not an integer, the two Bessel functions $J_{3/2}(
x)$ and $J_{-3/2}(x)$ are linearly independent solutions. I will derive their cl
osed forms and verify them directly.

### Known base cases

For $\nu = \tfrac{1}{2}$:
$$J_{1/2}(x) = \sqrt{\frac{2}{\pi x}}\sin x, \qquad J_{-1/2}(x) = \sqrt{\frac{2}
{\pi x}}\cos x.$$

### Recurrence relation

$$J_{\nu+1}(x) = \frac{2\nu}{x}J_\nu(x) - J_{\nu-1}(x).$$

**Computing $J_{3/2}$** (set $\nu = \tfrac{1}{2}$):
$$J_{3/2}(x) = \frac{1}{x}J_{1/2}(x) - J_{-1/2}(x) = \sqrt{\frac{2}{\pi x}}\left
(\frac{\sin x}{x} - \cos x\right) = \sqrt{\frac{2}{\pi}}\,\frac{\sin x - x\cos x
}{x^{3/2}}.$$

**Computing $J_{-3/2}$** (set $\nu = -\tfrac{1}{2}$ in $J_{\nu-1} = \tfrac{2\nu}
{x}J_\nu - J_{\nu+1}$):
$$J_{-3/2}(x) = -\frac{1}{x}J_{-1/2}(x) - J_{1/2}(x) = -\sqrt{\frac{2}{\pi x}}\l
eft(\frac{\cos x}{x} + \sin x\right) = -\sqrt{\frac{2}{\pi}}\,\frac{\cos x + x\s
in x}{x^{3/2}}.$$

### Verification

It suffices to verify $y = u\,x^{-3/2}$ for $u \in \{\sin x - x\cos x,\; \cos x
+ x\sin x\}$, since the constant $\sqrt{2/\pi}$ is irrelevant.

For $y = u\,x^{-3/2}$:
$$y' = u'x^{-3/2} - \tfrac{3}{2}u\,x^{-5/2}, \qquad y'' = u''x^{-3/2} - 3u'x^{-5
/2} + \tfrac{15}{4}u\,x^{-7/2}.$$

Substituting into $x^2y'' + xy' + (x^2 - \tfrac{9}{4})y$:

$$x^{1/2}(u'' + u) - 2u'\,x^{-1/2} + x^{-3/2}\underbrace{\left(\tfrac{15}{4} - \
tfrac{3}{2} - \tfrac{9}{4}\right)}_{=\,0}u = x^{1/2}(u'' + u) - 2u'\,x^{-1/2}.$$

**Case 1:** $u = \sin x - x\cos x$, so $u' = x\sin x$, $u'' = \sin x + x\cos x$,
 and $u'' + u = 2\sin x$.
$$x^{1/2}\cdot 2\sin x - 2(x\sin x)\,x^{-1/2} = 2x^{1/2}\sin x - 2x^{1/2}\sin x
= 0.\ \checkmark$$

**Case 2:** $u = \cos x + x\sin x$, so $u' = x\cos x$, $u'' = \cos x - x\sin x$,
 and $u'' + u = 2\cos x$.
$$x^{1/2}\cdot 2\cos x - 2(x\cos x)\,x^{-1/2} = 2x^{1/2}\cos x - 2x^{1/2}\cos x
= 0.\ \checkmark$$

### Linear independence

Near $x = 0$: $\sin x - x\cos x \sim \tfrac{x^3}{3}$, so $y_1 \sim C\,x^{3/2} \t
o 0$; while $\cos x + x\sin x \to 1$, so $y_2 \sim C\,x^{-3/2} \to \infty$. Thei
r distinct asymptotic behavior guarantees linear independence. (Equivalently, $J
_{3/2}$ and $J_{-3/2}$ are independent since $\tfrac{3}{2}\notin\mathbb{Z}$.)

### Result

Two linearly independent solutions are:

$$\boxed{y_1(x) = \sqrt{\frac{2}{\pi}}\,\frac{\sin x - x\cos x}{x^{3/2}}, \qquad
 y_2(x) = -\sqrt{\frac{2}{\pi}}\,\frac{\cos x + x\sin x}{x^{3/2}}.}$$
