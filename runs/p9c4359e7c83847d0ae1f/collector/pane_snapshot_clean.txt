## Setting Up the Integrator

Let $g(x) = x\cdot\operatorname{sign}(\sin x)$ on $[-\pi,\pi]$.

**Determining $\operatorname{sign}(\sin x)$:**
- $x\in(-\pi,0)$: $\sin x<0$, so $\operatorname{sign}(\sin x)=-1$, giving $g(x)=
-x$
- $x\in(0,\pi)$: $\sin x>0$, so $\operatorname{sign}(\sin x)=+1$, giving $g(x)=x
$
- $x=0$: $\sin 0=0$, so $g(0)=0$
- $x=\pm\pi$: $\sin(\pm\pi)=0$, so $g(\pm\pi)=0$

**Key observation:** $g(x)=|x|$ on the *open* interval $(-\pi,\pi)$, but $g(-\pi
)=0\neq\pi$ and $g(\pi)=0\neq\pi$. So $g$ has jumps at both endpoints.

## Analyzing Jumps and Continuous Parts

**At $x=-\pi$ (left endpoint):** $g(-\pi)=0$ but $g(-\pi^+)=\lim_{x\to-\pi^+}(-x
)=\pi$. Jump $= \pi$.

**At $x=0$:** $g(0^-)=0$, $g(0)=0$, $g(0^+)=0$. **No jump** — $g$ is continuous
here.

**At $x=\pi$ (right endpoint):** $g(\pi^-)=\lim_{x\to\pi^-}x=\pi$ but $g(\pi)=0$
. Jump $= -\pi$.

**Continuous derivatives:** $g'(x)=-1$ on $(-\pi,0)$; $g'(x)=+1$ on $(0,\pi)$.

## Computing the Integral

Using the decomposition into continuous and jump parts for the Riemann–Stieltjes
 integral (with $f(x)=x+2$):

**Jump at $x=-\pi$:** In the Riemann–Stieltjes sum, the first subinterval $[-\pi

$$f(-\pi)\cdot\pi = (-\pi+2)\pi = -\pi^2+2\pi$$

$$\int_{-\pi}^{0}(x+2)(-1)\,dx = -\left[\tfrac{x^2}{2}+2x\right]_{-\pi}^{0} = -\

**Continuous part on $(0,\pi)$:**
$$\int_{0}^{\pi}(x+2)(+1)\,dx = \left[\tfrac{x^2}{2}+2x\right]_{0}^{\pi} = \tfra
c{\pi^2}{2}+2\pi$$

**Jump at $x=\pi$:** The last subinterval $[x_{n-1},\pi]$ contributes $f(\xi_n)[
g(\pi)-g(x_{n-1})]\to f(\pi)\cdot(-\pi)$:
$$f(\pi)\cdot(-\pi) = (\pi+2)(-\pi) = -\pi^2-2\pi$$

$$I = \underbrace{(-\pi^2+2\pi)}_{\text{jump at }-\pi} + \underbrace{\left(\tfra

## Verification via Decomposition

Set $h(x)=|x|$ on $[-\pi,\pi]$ (continuous, $h(\pm\pi)=\pi$). Then $g=h+j$ where
 $j(-\pi)=-\pi$, $j(\pi)=-\pi$, $j\equiv 0$ on $(-\pi,\pi)$.

- $\int_{-\pi}^{\pi} f\,dh = \int_{-\pi}^{0}f(-1)\,dx+\int_{0}^{\pi}f(+1)\,dx =

- $\int_{-\pi}^{\pi} f\,dj$: only the first and last subintervals contribute (si

- Total: $\pi^2 + (-2\pi^2) = -\pi^2$ ✓
