# Solution

The answer is **No**. The existence of a uniformly bounded family of right-inver
se extension operators does not guarantee strong convergence on compact sets. Be
low is an explicit counterexample.

## Setup

Let $U_\infty = [0,1]$ and, for $r \in [1,\infty)$, let $U_r = [0,\, 1 - 1/r]$.
Each $U_r$ is compact, the family is increasing, and
$$\overline{\bigcup_{r\ge 1} U_r} = \overline{[0,1)} = [0,1] = U_\infty.$$

## Constructing the extension operators

For each $r \ge 1$, define $m_r : C(U_r,\mathbb{R}) \to C([0,1],\mathbb{R})$ as
follows. Given $f \in C([0,\,1-1/r])$:

- **On $[0,\, 1-1/r]$:** $\;m_r(f)(x) = f(x).$
- **On $[1-1/r,\, 1]$:** $\;m_r(f)(x) = f(1\!-\!1/r) + \dfrac{x-(1-1/r)}{1/r}\bi
gl(-f(0)-f(1\!-\!1/r)\bigr).$

This is the linear interpolation between the value $f(1-1/r)$ at $x=1-1/r$ and t
he value $-f(0)$ at $x=1$.

**Verification of the required properties.**

1. **Well-defined and continuous:** $m_r(f)$ is continuous on each subinterval a
nd agrees at the junction $x = 1-1/r$, so $m_r(f) \in C([0,1])$.

2. **Linearity:** Both pieces depend linearly on $f$, so $m_r$ is linear.

3. **Right inverse ($\phi_r \circ m_r = \mathrm{id}$):** On $U_r = [0, 1-1/r]$,
we have $m_r(f)(x) = f(x)$ by definition, so $\phi_r(m_r(f)) = f$.

4. **Uniform norm bound ($\|m_r\| \le M$ with $M=1$):** If $\|f\|_{U_r} \le 1$,
then $|f(x)| \le 1$ on $U_r$, so $|f(1-1/r)| \le 1$ and $|f(0)| \le 1$. On $[0,
1-1/r]$, $|m_r(f)(x)| = |f(x)| \le 1$. On $[1-1/r, 1]$, $m_r(f)(x)$ is a convex
combination of $f(1-1/r)$ and $-f(0)$, both lying in $[-1, 1]$, so $|m_r(f)(x)|
\le 1$. Hence $\|m_r(f)\|_\infty \le 1$, giving $\|m_r\| \le 1$ for every $r$. S
et $M = 1$.

## Failure of strong convergence

Let $y_0 \in C([0,1])$ be the constant function $y_0 \equiv 1$, and let $\Gamma
= \{y_0\}$, which is a compact subset of $Y_\infty$.

For any $r \ge 1$:
- $\phi_r(y_0) = 1|_{U_r} \equiv 1$.
- $m_r(\phi_r(y_0)) = m_r(1)$, where $1$ denotes the constant function on $U_r$.
- On $[0, 1-1/r]$: $m_r(1)(x) = 1$.
- At $x = 1$: $m_r(1)(1) = -f(0) = -1$ (with $f \equiv 1$).

Therefore:
$$\|m_r \circ \phi_r(y_0) - y_0\|_{Y_\infty} \ge \bigl|m_r(1)(1) - y_0(1)\bigr|
= |-1 - 1| = 2.$$

Since $\Gamma$ is a singleton,
$$\sup_{y \in \Gamma}\|(m_r \circ \phi_r)(y) - y\|_{Y_\infty} = 2 \quad \text{fo
r all } r \ge 1.$$

This does **not** converge to $0$ as $r \to \infty$.

## Conclusion

The hypothesis — that there exists a uniformly bounded family of continuous line
ar right-inverses $m_r : Y_r \to Y_\infty$ with $\phi_r \circ m_r = \mathrm{id}_
{Y_r}$ — is insufficient to guarantee that $m_r \circ \phi_r$ converges strongly
 to the identity on compact subsets of $Y_\infty$. The obstruction is that the n
orm bound $M$ controls only the *magnitude* of the extension on $U_\infty \setmi
nus U_r$, not its *agreement* with the original function. A bounded linear exten
sion operator may extend the restricted function to $U_\infty \setminus U_r$ in
a manner that is uniformly bounded but persistently disagrees with the original
function, even on a compact (indeed, singleton) set $\Gamma$.
