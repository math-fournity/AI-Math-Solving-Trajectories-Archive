## Proof

Let $G$ be a finite non-abelian simple group. Since $Z(G)$ is a normal subgroup
and $G$ is non-abelian simple, $Z(G) = 1$. Hence every non-identity conjugacy cl
ass has size $\geq 2$.

Let $k(G)$ denote the number of conjugacy classes. We prove $k(G) \geq 5$ (i.e.,
 at least 4 non-identity classes) by ruling out $k(G) \leq 4$.

The class equation gives $|G| = 1 + c_1 + \cdots + c_{k-1}$ where each $c_i \geq
 2$ is a class size, and each $c_i \mid |G|$.

**Case $k = 1$:** $|G| = 1$, so $G$ is trivial — not non-abelian simple.

**Case $k = 2$:** $|G| = 1 + (|G|-1)$, so the single non-identity class has size
 $|G|-1$. Since it divides $|G|$, we get $|G|-1 \mid |G|$, hence $|G|-1 \mid 1$,
 giving $|G| = 2$. But $C_2$ is abelian — contradiction.

**Case $k = 3$:** Let $|G| = n = 1 + a + b$ with $2 \leq a \leq b$ and $a, b \mi
d n$. Then $a \mid n - a = 1 + b$ and $b \mid n - b = 1 + a$. Since $a \leq b$,
we have $b \mid 1 + a \leq 1 + b \leq 2b$, so $1 + a = b$ (the case $1+a = 2b$ w
ould force $a > b$). Then $a \mid 1 + b = 2 + a$ gives $a \mid 2$, so $a = 2$, $
b = 3$, $n = 6$. No group of order 6 is non-abelian simple ($S_3$ is not simple,
 $C_6$ is abelian) — contradiction.

**Case $k = 4$:** Let $n = |G| = 1 + a + b + c$ with $2 \leq a \leq b \leq c$ an
d $a, b, c \mid n$. Since $c \mid n$ and $c \mid c$, we get $c \mid 1 + a + b$.
Write $1 + a + b = mc$ with $m \geq 1$. Since $a, b \leq c$, we have $1 + a + b
\leq 1 + 2c$, so $mc \leq 1 + 2c$, giving $(m-2)c \leq 1$. As $c \geq 2$, this f
orces $m \leq 2$.

*Subcase $m = 1$:* $c = 1 + a + b$, $n = 2c$. Then $b \mid 1 + a + c = 2 + 2a +
b$ gives $b \mid 2(1+a)$, and $a \mid 1 + b + c = 2 + a + 2b$ gives $a \mid 2(1+
b)$. Since $a \leq b$ and $b \geq 2$, we have $2(1+a) \leq 4b$, so $2(1+a) = qb$
 with $q \in \{1,2,3,4\}$.

- $q=1$: $b = 2a+2$, $a \mid 2(1+b) = 4a+6$ gives $a \mid 6$, so $a \in \{2,3,6\
}$, yielding $(n) \in \{18, 24, 42\}$.
- $q=2$: $b = a+1$, $a \mid 2(1+b) = 2a+4$ gives $a \mid 4$, so $a \in \{2,4\}$,
 yielding $n \in \{12, 20\}$.
- $q=3$: $b = 2(1+a)/3$ with $a \equiv 2 \pmod{3}$ and $b \geq a$ forces $a = 2$
, $b = 2$, $c = 5$, $n = 10$.
- $q=4$: $b = (1+a)/2 \geq a$ forces $a \leq 1$, impossible.

*Subcase $m = 2$:* $c = (1+a+b)/2$, $n = 3c$. The condition $b \leq c$ gives $b
\leq 1 + a$, so $b \in \{a, a+1\}$.

- $b = a$: $b \mid 3(1+a) = 3(1+b)$ gives $b \mid 3$, so $b = 3$, $a = 3$, but $
c = 7/2$ is not an integer — no solution.
- $b = a+1$: $a \mid 3(1+b) = 3(2+a) = 6 + 3a$ gives $a \mid 6$, so $a \in \{2,3
,6\}$, yielding $n \in \{9, 12, 21\}$.

Collecting all solutions: $n \in \{9, 10, 12, 18, 20, 21, 24, 42\}$.

**None of these is the order of a non-abelian simple group:**
- $9 = 3^2$: prime power, center nontrivial.
- $10 = 2 \cdot 5$: $n_5 \mid 2$, $n_5 \equiv 1 \pmod{5}$, so $n_5 = 1$ — normal
 Sylow 5-subgroup.
- $12 = 2^2 \cdot 3$: $n_3 \mid 4$, $n_3 \equiv 1 \pmod{3}$; if $n_3 = 1$ done,
if $n_3 = 4$ then 8 elements of order 3 leave only 4 elements forming the unique
 Sylow 2-subgroup. Not simple.
- $18 = 2 \cdot 3^2$: $n_3 \mid 2$, $n_3 \equiv 1 \pmod{3}$, so $n_3 = 1$ — norm
al Sylow 3-subgroup.
- $20 = 2^2 \cdot 5$: $n_5 \mid 4$, $n_5 \equiv 1 \pmod{5}$, so $n_5 = 1$ — norm
al Sylow 5-subgroup.
- $21 = 3 \cdot 7$: $n_7 \mid 3$, $n_7 \equiv 1 \pmod{7}$, so $n_7 = 1$ — normal
 Sylow 7-subgroup.
- $24 = 2^3 \cdot 3$: solvable by Burnside's $p^a q^b$ theorem (or Sylow countin
g). Not simple.
- $42 = 2 \cdot 3 \cdot 7$: $n_7 \mid 6$, $n_7 \equiv 1 \pmod{7}$, so $n_7 = 1$
— normal Sylow 7-subgroup.

Every case yields a contradiction. Therefore $k(G) \geq 5$, meaning $G$ has at l
east **4 non-identity conjugacy classes**. $\blacksquare$
