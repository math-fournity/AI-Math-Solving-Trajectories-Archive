## Solution

Let $p(x) = \prod_{j=1}^n (x - a_j)$, a monic polynomial of degree $n$, so that
$\prod_{j=1}^n |x-a_j| = |p(x)|$. Define
$$M_1(p) = \max_{0 \le x \le 1}|p(x)|, \qquad M_2(p) = \max_{0 \le x \le 2}|p(x)
|.$$
We seek the smallest $C$ with $M_2(p) \le C^n M_1(p)$ for all $n$ and all monic
$p$ of degree $n$.

### Step 1. A Chebyshev extremal lemma (exterior point)

**Lemma.** *For $|t_0|>1$ and any polynomial $q$ of degree $\le n$ with $\max_{[
-1,1]}|q|\le 1$,*
$$|q(t_0)| \le |T_n(t_0)|,$$
*where $T_n$ is the Chebyshev polynomial. Equality holds iff $q = \pm T_n$.*

*Proof.* Assume $t_0 > 1$ and, adjusting signs, $q(t_0) > T_n(t_0) > 0$. Set $c
= q(t_0)/T_n(t_0) > 1$ and $r = q - c\,T_n$. Then $r(t_0)=0$. At the $n+1$ extre
ma $x_k = \cos(k\pi/n)$, $k=0,\dots,n$, we have $T_n(x_k)=(-1)^k$, so
$$r(x_k) = q(x_k) - c(-1)^k.$$
Since $|q(x_k)|\le 1 < c = |c(-1)^k|$, the sign of $r(x_k)$ is $(-1)^{k+1}$, giv
ing $n$ sign changes and hence $n$ zeros in $(-1,1)$. Together with the zero at
$t_0>1$, $r$ has $n+1$ zeros but $\deg r \le n$ — contradiction. $\square$

Recall $T_n(t) = \cosh(n\operatorname{arcosh} t)$ for $t \ge 1$, which is nonneg
ative and increasing on $[1,\infty)$.

### Step 2. Bounding the ratio $M_2/M_1$

Map $[0,1]\to[-1,1]$ via $t = 2x-1$ and set $Q(t) = p\!\left(\tfrac{t+1}{2}\righ
t)$, a polynomial of degree $n$. Then
$$\max_{[-1,1]}|Q| = M_1(p), \qquad \max_{[-1,3]}|Q| = M_2(p),$$
since $[0,2]\ni x \mapsto t=2x-1 \in [-1,3]$.

For $t\in[-1,1]$: $|Q(t)|\le M_1$.

For $t\in[1,3]$: apply the Lemma to $q = Q/M_1$ (so $\max_{[-1,1]}|q|\le 1$):
$$|Q(t)| \le M_1\cdot T_n(t) \le M_1\cdot T_n(3),$$
because $T_n$ is increasing on $[1,\infty)$ and $t\le 3$. Combining both ranges,
$$\boxed{M_2(p) \le T_n(3)\cdot M_1(p) = \cosh\!\bigl(n\operatorname{arcosh} 3\b
igr)\cdot M_1(p).}$$

### Step 3. Sharpness

Take $p(x) = 2^{1-2n}T_n(2x-1)$ (monic, since $T_n(2x-1)$ has leading coefficien
t $2^{2n-1}$). Then
- $M_1(p) = 2^{1-2n}\cdot 1 = 2^{1-2n}$ (max of $T_n$ on $[-1,1]$ is $1$),
- $M_2(p) = 2^{1-2n}T_n(3)$ (max on $[0,2]$ attained at $x=2$, i.e. $t=3$).

So $M_2/M_1 = T_n(3) = \cosh(n\operatorname{arcosh} 3)$, achieving equality. The
 bound is sharp for every $n$.

### Step 4. Determining $C$

Let $\lambda = 3 + 2\sqrt 2$ and $\mu = 3 - 2\sqrt 2 = \lambda^{-1}$ (since $\la
mbda\mu = 9-8=1$). With $\alpha = \operatorname{arcosh} 3$, $e^\alpha = \lambda$
, so
$$R_n := \cosh(n\alpha) = \frac{\lambda^n + \lambda^{-n}}{2} = \frac{\lambda^n +
 \mu^n}{2}.$$

The inequality $M_2 \le C^n M_1$ for all $n$ and all $p$ is equivalent to $C^n \
ge R_n$ for all $n\ge 1$.

**$C = \lambda$ works:** $C^n = \lambda^n \ge \frac{\lambda^n + \lambda^{-n}}{2}
 = R_n$, since $\lambda^n \ge \lambda^{-n}$.

**No smaller $C$ works:** For any $C < \lambda$,
$$R_n^{1/n} = \lambda\left(\frac{1+\lambda^{-2n}}{2}\right)^{1/n} \xrightarrow[n
\to\infty]{} \lambda,$$
so for all sufficiently large $n$, $R_n^{1/n} > C$, i.e. $C^n < R_n$, violating
the inequality.

### Conclusion

The smallest possible value of $C$ is
$$\boxed{C = 3 + 2\sqrt{2}.}$$
