### Setup

Place the station $O$ at the origin and the beacon $H = (6, 0)$. The sensor netw
ork $\Omega$ is the circle $x^2 + y^2 = 100$ (radius $R = 10$). The three teams
$A, B, C$ lie on $\Omega$, and $H$ is the orthocenter of $\triangle ABC$ for eve
ry valid configuration.

**Key fact.** For a triangle inscribed in a circle centered at the circumcenter
$O$ (here the origin), the orthocenter equals the vector sum of the vertices:
$$H = A + B + C.$$

Rescale to the **unit circle** ($R = 1$): set $h = OH/R = 6/10 = 3/5$, so $H = (
h, 0) = (3/5, 0)$. The constraint on valid triangles becomes:
$$A + B + C = (h, 0), \qquad |A| = |B| = |C| = 1.$$

### Identifying the constraint family

Fix vertex $A$ on the unit circle. Since $H$ is the orthocenter, the altitude fr
om $A$ passes through $H$, so side $BC \perp AH$. Moreover $B + C = H - A$, givi
ng the midpoint of $BC$:
$$M = \tfrac{1}{2}(H - A).$$

One verifies $M = -\tfrac{1}{2}(A - H)$, which is indeed along the direction of
$AH$, consistent with $BC$ being a chord perpendicular to $AH$.

Parameterize by $\varphi$, the direction of $A - H$. Write $A = H + d\,(\cos\var
phi, \sin\varphi)$ where $d = |A - H| = -h\cos\varphi + \sqrt{1 - h^2\sin^2\varp
hi}$. Set $s(\varphi) = \sqrt{1 - h^2\sin^2\varphi}$, so $d = s - h\cos\varphi$.

The line $BC$ passes through $M = -\frac{d}{2}(\cos\varphi, \sin\varphi)$ and is
 perpendicular to $(\cos\varphi, \sin\varphi)$, giving:
$$x\cos\varphi + y\sin\varphi = -\frac{d}{2} = \frac{h\cos\varphi - s}{2} =: f(\
varphi).$$

The half-plane containing $A$ is $x\cos\varphi + y\sin\varphi \ge f(\varphi)$. B
y symmetry, edges $AC$ and $AB$ produce the **same family** of constraint lines
(just relabeling vertices). So:

$$\text{Safe Haven region} = \bigcap_{\varphi}\left\{(x,y) : x\cos\varphi + y\si
n\varphi \ge f(\varphi)\right\}.$$

### Computing the envelope (boundary)

The boundary is the envelope of the lines $x\cos\varphi + y\sin\varphi = f(\varp
hi)$, given by:
$$x = f\cos\varphi - f'\sin\varphi, \qquad y = f\sin\varphi + f'\cos\varphi.$$

With $f = \frac{h\cos\varphi - s}{2}$ and $f' = \frac{hf\sin\varphi}{s}$ (obtain
ed by differentiating and using $s' = -h^2\sin\varphi\cos\varphi / s$), a carefu
l simplification yields:

$$\boxed{x(\varphi) = \frac{h}{2} - \frac{\cos\varphi}{2s}, \qquad y(\varphi) =
-\frac{(1-h^2)\sin\varphi}{2s}.}$$

### Verifying the boundary is an ellipse

Compute:
$$(x - h/2)^2 = \frac{\cos^2\varphi}{4s^2}, \qquad y^2 = \frac{(1-h^2)^2\sin^2\v
arphi}{4s^2}.$$

Then:
$$\frac{(x - h/2)^2}{1/4} + \frac{y^2}{(1-h^2)/4} = \frac{\cos^2\varphi}{s^2} +
\frac{(1-h^2)\sin^2\varphi}{s^2} = \frac{\cos^2\varphi + (1-h^2)\sin^2\varphi}{1
 - h^2\sin^2\varphi} = \frac{1 - h^2\sin^2\varphi}{1 - h^2\sin^2\varphi} = 1.$$

So the boundary is an **ellipse** (in unit-circle coordinates) with:
- Center $\left(\frac{h}{2}, 0\right) = \left(\frac{3}{10}, 0\right)$,
- Semi-axes $a = \frac{1}{2}$, $\;b = \frac{\sqrt{1-h^2}}{2} = \frac{2}{5}$.

The center satisfies all constraints ($s \ge 0$ guarantees $\frac{h}{2}\cos\varp
hi \ge f(\varphi)$), so the region is the **interior** of this ellipse.

### Area

The Safe Haven region is the interior of the ellipse with semi-axes $a = 5$ km a
nd $b = 4$ km:

$$\text{Area} = \pi \cdot a \cdot b = \pi \cdot 5 \cdot 4 = \boxed{20\pi}.$$
