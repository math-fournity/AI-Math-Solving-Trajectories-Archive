## Solution

**Setting up the integral.** Since $x > 0$ on $(0,1]$, we have $|ax + x\ln x| =
x|a + \ln x|$. The sign of $a + \ln x$ changes where $\ln x = -a$, i.e. at $x_0
= e^{-a} \in (0,1)$ (since $a>0$). Thus

$$f(a) = \int_0^{e^{-a}} x\bigl(-(a+\ln x)\bigr)\,dx + \int_{e^{-a}}^{1} x(a+\ln
 x)\,dx.$$

**Antiderivatives.** We use
$$\int x\,dx = \tfrac{x^2}{2}, \qquad \int x\ln x\,dx = \tfrac{x^2}{2}\ln x - \t
frac{x^2}{4}.$$

**First integral** $\displaystyle\int_0^{e^{-a}}(-ax - x\ln x)\,dx$:

$$= -\frac{a\,x^2}{2}\Big|_0^{e^{-a}} - \left(\frac{x^2}{2}\ln x - \frac{x^2}{4}
\right)\Bigg|_0^{e^{-a}}.$$

At $x=e^{-a}$: $x^2=e^{-2a}$, $\ln x=-a$, giving $-\frac{a\,e^{-2a}}{2} - \bigl(
-\frac{a\,e^{-2a}}{2}-\frac{e^{-2a}}{4}\bigr) = \frac{e^{-2a}}{4}$. At $x\to 0^+
$ all terms vanish (since $x^2\ln x\to 0$). So the first integral $= \dfrac{e^{-
2a}}{4}$.

**Second integral** $\displaystyle\int_{e^{-a}}^{1}(ax+x\ln x)\,dx$:

$$= \frac{a\,x^2}{2}\Big|_{e^{-a}}^{1} + \left(\frac{x^2}{2}\ln x - \frac{x^2}{4
}\right)\Bigg|_{e^{-a}}^{1}.$$

At $x=1$: $\frac{a}{2}$ and $-\frac{1}{4}$. At $x=e^{-a}$: $\frac{a\,e^{-2a}}{2}
$ and $-\frac{a\,e^{-2a}}{2}-\frac{e^{-2a}}{4}$. Subtracting:

$$\frac{a}{2}-\frac{a\,e^{-2a}}{2} + \left(-\frac{1}{4}\right)-\left(-\frac{a\,e
^{-2a}}{2}-\frac{e^{-2a}}{4}\right) = \frac{a}{2}-\frac{1}{4}+\frac{e^{-2a}}{4}.
$$

**Combining:**

$$f(a) = \frac{e^{-2a}}{4} + \frac{a}{2} - \frac{1}{4} + \frac{e^{-2a}}{4} = \fr
ac{a}{2} - \frac{1}{4} + \frac{e^{-2a}}{2}.$$

**Minimizing.** Differentiate:

$$f'(a) = \frac{1}{2} - e^{-2a}, \qquad f''(a) = 2e^{-2a} > 0.$$

Setting $f'(a)=0$: $e^{-2a}=\frac{1}{2}$, so $a = \frac{\ln 2}{2}$. Since $f''>0
$, this is a global minimum (on $(0,\infty)$; note $f(a)\to\frac{1}{4}$ as $a\to
 0^+$ and $f(a)\to+\infty$ as $a\to\infty$, confirming the interior critical poi
nt is the global min).

**Evaluating** at $a = \frac{\ln 2}{2}$:

$$f\!\left(\frac{\ln 2}{2}\right) = \frac{\ln 2}{4} - \frac{1}{4} + \frac{e^{-\l
n 2}}{2} = \frac{\ln 2}{4} - \frac{1}{4} + \frac{1}{4} = \frac{\ln 2}{4}.$$

The minimum value of $f(a)$ is $\boxed{\dfrac{\ln 2}{4}}$.
