Looking at this problem, I need to determine whether 100 positive integers ≤ 250
00 can have all pairwise sums distinct — this is asking for a **Sidon set** (B₂
set) of size 100 inside {1, …, 25000}.

**Answer: Yes.**

## Proof

I will use the **Erdős–Turán construction** of Sidon sets.

**Construction.** Let *p* be a prime. Define the set
$$S = \{\,a_k = 2pk + (k^2 \bmod p) : k = 0, 1, \dots, p-1\,\},$$
where $k^2 \bmod p$ denotes the least nonnegative residue. I claim $S$ is a Sido
n set (all pairwise sums distinct).

**Claim: $S$ is a Sidon set.**

Suppose $a_i + a_j = a_k + a_\ell$ with $0 \le i,j,k,\ell \le p-1$. Write $r_m =
 m^2 \bmod p \in \{0,\dots,p-1\}$, so $a_m = 2pm + r_m$. Then:
$$2p(i+j) + r_i + r_j = 2p(k+\ell) + r_k + r_\ell.$$

Since $0 \le r_i + r_j \le 2(p-1) < 2p$, reducing mod $2p$ gives $r_i + r_j = r_
k + r_\ell$ (as integers), and then the full equation gives $i + j = k + \ell$.

Now $r_i + r_j = r_k + r_\ell$ means $i^2 + j^2 \equiv k^2 + \ell^2 \pmod{p}$. C
ombined with $i+j = k+\ell$:
$$(i+j)^2 - 2ij \equiv (k+\ell)^2 - 2k\ell \pmod{p},$$
so $ij \equiv k\ell \pmod{p}$. Thus $i,j$ and $k,\ell$ are roots of the same qua
dratic $x^2 - (i+j)x + ij \equiv 0 \pmod{p}$, giving $\{i,j\} \equiv \{k,\ell\}
\pmod{p}$. Since all lie in $\{0,\dots,p-1\}$, we conclude $\{i,j\} = \{k,\ell\}
$. Hence the pairwise sum $a_i+a_j$ determines $\{i,j\}$ uniquely, so **all pair
wise sums are distinct**. $\square$

**Choosing parameters.** Take $p = 101$ (which is prime). Then $|S| = 101$ and t
he largest element is
$$a_{100} = 2\cdot 101 \cdot 100 + (100^2 \bmod 101) = 20200 + 1 = 20201,$$
so $S \subseteq \{0, 1, \dots, 20201\}$.

**Obtaining 100 positive integers ≤ 25000.** Shift every element up by 1: $S' =
\{a+1 : a \in S\} \subseteq \{1, 2, \dots, 20202\}$. This shift preserves the Si
don property (pairwise sums all increase by 2, remaining distinct). Now $S'$ has
 101 elements, all positive and at most $20202 \le 25000$. Selecting **any 100 o
f these 101 elements** yields a set of 100 positive integers, each $\le 20202 \l
e 25000$, with all pairwise sums distinct.

Therefore, **yes**, it is possible to find 100 positive integers not exceeding 2
5000 such that all pairwise sums are different. $\blacksquare$
