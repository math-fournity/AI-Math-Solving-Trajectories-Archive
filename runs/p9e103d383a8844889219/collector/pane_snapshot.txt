nd k₂ cannot both be successful.

*Proof.* Suppose both are successful. Consider any k₂×k₂ subgrid W. Since k₁ | k
₂, we can partition W into (k₂/k₁)² disjoint k₁×k₁ subgrids. Each is a valid k₁×
k₁ subgrid of the table (contained in W ⊆ table), so each contains exactly k₁ bl
ack cells (since k₁ is successful). Being disjoint, W contains at least k₁·(k₂/k
₁)² = k₂²/k₁ black cells. But W contains exactly k₂ black cells (since k₂ is suc
cessful). So k₂²/k₁ ≤ k₂, giving k₂ ≤ k₁ — contradicting k₁ < k₂. □

**Upper Bound:** The set of successful numbers forms an antichain under divisibi
lity (no element divides another). The maximum antichain under divisibility in {
1, …, 2016} has size **1008**:

- *Achievability of bound:* The set {1009, 1010, …, 2016} is an antichain: if a
| b with a < b, then b ≥ 2a > 2·1008 = 2016, impossible.
- *Upper bound via Dilworth's theorem:* Decompose {1, …, 2016} into chains {m, 2
m, 4m, …} ∩ {1,…,2016} for each odd m. There are 1008 odd numbers in {1, …, 2016
}, giving 1008 chains, so no antichain exceeds 1008.

**Construction achieving 1008:** Paint every cell in column 1008 black; all othe
r cells white.

For a k×k subgrid starting at row r, column c, the black cell count is k if 1008

- **k ≥ 1009 is successful:** Every valid column range [c, c+k−1] with 1 ≤ c ≤ 2

- **k ≤ 1008 is not successful:** The subgrid starting at column c = 1009 is val

The successful numbers are exactly {1009, 1010, …, 2016}, giving **1008** succes

**Conclusion:** The maximum number of successful numbers is $\boxed{1008}$.
