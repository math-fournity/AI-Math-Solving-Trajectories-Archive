## Principal Curvatures of the Conicoid

Let $r = u^1$, $\theta = u^2$, and write $f' = f'(u^2)$, $f'' = f''(u^2)$ for br
evity. The parametrization is
$$\mathbf{x}(r,\theta) = (r\cos\theta,\; r\sin\theta,\; f(\theta)).$$

### First fundamental form

$$\mathbf{x}_r = (\cos\theta,\sin\theta,0),\qquad \mathbf{x}_\theta = (-r\sin\th
eta,\; r\cos\theta,\; f').$$

Hence
$$E = \mathbf{x}_r\cdot\mathbf{x}_r = 1,\quad F = \mathbf{x}_r\cdot\mathbf{x}_\t
heta = 0,\quad G = \mathbf{x}_\theta\cdot\mathbf{x}_\theta = r^2 + (f')^2.$$

Denote $W := r^2 + (f')^2$, so $g = \mathrm{diag}(1, W)$ and $g^{-1} = \mathrm{d
iag}(1, 1/W)$.

### Unit normal

$$\mathbf{x}_r\times\mathbf{x}_\theta = (f'\sin\theta,\,-f'\cos\theta,\, r),\qqu
ad |\mathbf{x}_r\times\mathbf{x}_\theta| = \sqrt{(f')^2 + r^2} =: D = \sqrt{W}.$
$
$$\mathbf{n} = \frac{1}{D}(f'\sin\theta,\,-f'\cos\theta,\, r).$$

### Second fundamental form

$$\mathbf{x}_{rr} = \mathbf{0},\quad \mathbf{x}_{r\theta} = (-\sin\theta,\cos\th
eta,0),\quad \mathbf{x}_{\theta\theta} = (-r\cos\theta,\,-r\sin\theta,\, f'').$$

$$L = \mathbf{x}_{rr}\cdot\mathbf{n} = 0,$$
$$M = \mathbf{x}_{r\theta}\cdot\mathbf{n} = \frac{-f'\sin^2\theta - f'\cos^2\the
ta}{D} = -\frac{f'}{D},$$
$$N = \mathbf{x}_{\theta\theta}\cdot\mathbf{n} = \frac{-rf'\cos\theta\sin\theta
+ rf'\sin\theta\cos\theta + rf''}{D} = \frac{rf''}{D}.$$

So $b = \begin{pmatrix} 0 & -f'/D \\ -f'/D & rf''/D \end{pmatrix}$.

### Shape operator

The mixed shape operator $S^i{}_j = g^{ik}b_{kj}$ is
$$S = \begin{pmatrix} 0 & -f'/D \\[2pt] -f'/(WD) & rf''/(WD) \end{pmatrix}.$$

### Principal curvatures (eigenvalues of $S$)

The characteristic equation $\det(S - \kappa I) = 0$:
$$\kappa^2 - \kappa\,\frac{rf''}{WD} - \frac{(f')^2}{W D^2} = 0.$$

Since $D^2 = W$, the constant term is $-(f')^2/W^2$. Solving,
$$\kappa = \frac{1}{2}\!\left[\frac{rf''}{WD} \pm \sqrt{\frac{(rf'')^2}{W^2D^2}
+ \frac{4(f')^2}{W^2}}\right] = \frac{1}{2WD}\!\left[rf'' \pm \sqrt{(rf'')^2 + 4
(f')^2 W}\right].$$

Using $WD = W^{3/2}$ and restoring $r = u^1$, $W = (u^1)^2 + (f'(u^2))^2$:

$$\boxed{\;\kappa_{1,2} = \frac{u^1\, f''(u^2) \;\pm\; \sqrt{\big(u^1 f''(u^2)\b
ig)^2 + 4\big(f'(u^2)\big)^2\Big((u^1)^2 + \big(f'(u^2)\big)^2\Big)}}{2\Big((u^1
)^2 + \big(f'(u^2)\big)^2\Big)^{3/2}}\;}$$

### Consistency checks

- **Mean curvature**: $H = \tfrac{1}{2}\mathrm{tr}\,S = \dfrac{u^1 f''(u^2)}{2\b
ig((u^1)^2 + (f'(u^2))^2\big)^{3/2}}$, matching $\tfrac{1}{2}(\kappa_1+\kappa_2)
$. ✓
- **Gaussian curvature**: $K = \det S = -\dfrac{(f'(u^2))^2}{\big((u^1)^2 + (f'(
u^2))^2\big)^2}$, matching $\kappa_1\kappa_2 = \dfrac{1}{4W^2D^2}\big[(rf'')^2 -
 ((rf'')^2 + 4(f')^2W)\big] = -\dfrac{(f')^2}{W^2}$. ✓

The negative Gaussian curvature confirms the surface is saddle-shaped (as expect
ed for a general conicoid), and the two principal curvatures above are the eigen
values of the shape operator at each regular point.
