## Proof

**Setup and reformulation.** Define
$$I_n = \int_{-\infty}^{\infty} \frac{dx}{n(e^{x^2}-1)+1/n}.$$
Factoring out $n$ from the denominator:
$$I_n = \frac{1}{n}\int_{-\infty}^{\infty} \frac{dx}{e^{x^2}-1+\varepsilon}, \qq
uad \varepsilon := \frac{1}{n^2}.$$
Set $J(\varepsilon) = \int_{-\infty}^{\infty} \frac{dx}{e^{x^2}-1+\varepsilon}$,
 so $I_n = \frac{1}{n}\,J(1/n^2)$. As $n\to\infty$, $\varepsilon\to 0^+$.

**Well-definedness.** For each $n$, the denominator $n(e^{x^2}-1)+1/n$ equals $1
/n>0$ at $x=0$, is positive for all $x$ (since $e^{x^2}-1\geq 0$), and grows lik
e $ne^{x^2}$ for large $|x|$, so the integrand decays super-exponentially. Each
$I_n$ is finite.

**Identifying the singular behavior.** The integrand $\frac{1}{e^{x^2}-1+\vareps
ilon}$ is singular near $x=0$ as $\varepsilon\to 0$, since $e^{x^2}-1 = x^2 + \f
rac{x^4}{2}+\cdots \approx x^2$. The natural comparison is $\frac{1}{x^2+\vareps
ilon}$.

**Splitting the integral.** Fix a small $\delta>0$ (independent of $\varepsilon$
). Write
$$J(\varepsilon) = \underbrace{\int_{|x|<\delta}\frac{dx}{x^2+\varepsilon}}_{A(\
varepsilon)} + \underbrace{\int_{|x|<\delta}\left(\frac{1}{e^{x^2}-1+\varepsilon
}-\frac{1}{x^2+\varepsilon}\right)dx}_{B(\varepsilon)} + \underbrace{\int_{|x|\g
eq\delta}\frac{dx}{e^{x^2}-1+\varepsilon}}_{C(\varepsilon)}.$$

**Evaluating $A(\varepsilon)$.** By direct computation:
$$A(\varepsilon) = \frac{2\arctan(\delta/\sqrt{\varepsilon})}{\sqrt{\varepsilon}
} = \frac{\pi}{\sqrt{\varepsilon}} - \frac{2\arctan(\sqrt{\varepsilon}/\delta)}{
\sqrt{\varepsilon}}.$$
Since $\arctan(\sqrt{\varepsilon}/\delta) = \sqrt{\varepsilon}/\delta + O(\varep
silon^{3/2})$,
$$A(\varepsilon) = \frac{\pi}{\sqrt{\varepsilon}} - \frac{2}{\delta} + O(\sqrt{\
varepsilon}).$$

**Bounding $B(\varepsilon)$.** We have
$$\frac{1}{e^{x^2}-1+\varepsilon} - \frac{1}{x^2+\varepsilon} = \frac{x^2-(e^{x^
2}-1)}{(e^{x^2}-1+\varepsilon)(x^2+\varepsilon)}.$$
Since $e^{x^2}-1-x^2 = \frac{x^4}{2}+\cdots = O(x^4)$ and $e^{x^2}-1 \geq x^2$ (
so $e^{x^2}-1+\varepsilon \geq x^2+\varepsilon$):
$$\left|\frac{x^2-(e^{x^2}-1)}{(e^{x^2}-1+\varepsilon)(x^2+\varepsilon)}\right|
\leq \frac{C\,x^4}{(x^2+\varepsilon)^2}.$$
Substituting $x = \sqrt{\varepsilon}\,t$:
$$\int_{-\delta}^{\delta}\frac{x^4}{(x^2+\varepsilon)^2}\,dx = \sqrt{\varepsilon
}\int_{-\delta/\sqrt{\varepsilon}}^{\delta/\sqrt{\varepsilon}}\frac{t^4}{(t^2+1)
^2}\,dt = O(\delta),$$
since $\frac{t^4}{(t^2+1)^2}\to 1$ as $|t|\to\infty$ makes the integral grow as
$2\delta/\sqrt{\varepsilon}$, and the prefactor $\sqrt{\varepsilon}$ yields $O(\
delta)$. Thus $B(\varepsilon) = O(\delta)$, **bounded as $\varepsilon\to 0$**.

**Evaluating $C(\varepsilon)$.** For $|x|\geq\delta$, $e^{x^2}-1 \geq e^{\delta^
2}-1 > 0$, so $\frac{1}{e^{x^2}-1+\varepsilon} \to \frac{1}{e^{x^2}-1}$ uniforml
y, and by dominated convergence (dominator: $\frac{1}{e^{x^2}-1}$ which is integ
rable on $|x|\geq\delta$):
$$C(\varepsilon) \to \int_{|x|\geq\delta}\frac{dx}{e^{x^2}-1} \quad\text{as }\va
repsilon\to 0.$$

**Combining.** As $\varepsilon\to 0$:
$$J(\varepsilon) = \frac{\pi}{\sqrt{\varepsilon}} + \underbrace{\left(-\frac{2}{
\delta} + \int_{|x|\geq\delta}\frac{dx}{e^{x^2}-1}\right)}_{\text{bounded in }\v
arepsilon} + O(\delta) + O(\sqrt{\varepsilon}).$$
The key point: $J(\varepsilon) = \frac{\pi}{\sqrt{\varepsilon}} + O(1)$ as $\var
epsilon\to 0^+$.

**Final computation.** With $\varepsilon = 1/n^2$ (so $\sqrt{\varepsilon} = 1/n$
):
$$I_n = \frac{1}{n}\,J\!\left(\frac{1}{n^2}\right) = \frac{1}{n}\left(\pi n + O(
1)\right) = \pi + O\!\left(\frac{1}{n}\right) \xrightarrow{n\to\infty} \pi.$$

---

$$\boxed{\lim_{n\to\infty} \int_{-\infty}^{\infty} \frac{dx}{n(e^{x^2}-1)+1/n} =
 \pi}$$
