## Solution

We evaluate \( J = \displaystyle\oint_{C}\frac{1}{\cos z+1}\,dz \) where \( C: |
z|=5 \), using the residue theorem.

### Step 1: Locate the poles

The integrand \( f(z) = \dfrac{1}{\cos z + 1} \) has singularities where \( \cos
 z + 1 = 0 \), i.e. \( \cos z = -1 \), giving

\[
z = (2k+1)\pi,\qquad k\in\mathbb{Z}.
\]

Inside the contour \( |z|=5 \): since \( \pi \approx 3.14159 \), we need \( |(2k
+1)\pi| < 5 \), i.e. \( |2k+1| < 5/\pi \approx 1.59 \). The odd integers satisfy
ing this are \( 2k+1 \in \{-1, 1\} \), giving the two poles

\[
z = \pi \quad\text{and}\quad z = -\pi.
\]

(For \( 2k+1 = \pm 3 \), \( |z| = 3\pi \approx 9.42 > 5 \), outside the contour.
)

### Step 2: Determine the order of each pole

Using \( \cos z + 1 = 2\cos^{2}(z/2) \), the zeros of \( \cos z + 1 \) are the z
eros of \( \cos(z/2) \), each of order 1, so \( \cos z + 1 \) has zeros of order
 2. Hence \( f(z) \) has **poles of order 2** at \( z = \pm\pi \).

Equivalently, near \( z = \pi \), setting \( w = z - \pi \):

\[
\cos z + 1 = \cos(\pi + w) + 1 = -\cos w + 1 = \frac{w^{2}}{2} - \frac{w^{4}}{24
} + \cdots = \frac{w^{2}}{2}\left(1 - \frac{w^{2}}{12} + \cdots\right),
\]

confirming a zero of order 2.

### Step 3: Compute the residues

Write \( f(z) = \dfrac{1}{2}\sec^{2}(z/2) \). Near a pole \( z_{k} = (2k+1)\pi \
), set \( u = \dfrac{z - z_{k}}{2} \). Then \( z/2 = \dfrac{\pi}{2} + k\pi + u \
), and

\[
\cos(z/2) = \cos\!\left(\tfrac{\pi}{2}+k\pi+u\right) = (-1)^{k+1}\sin u,
\]

so \( \cos^{2}(z/2) = \sin^{2} u \) and

\[
f(z) = \frac{1}{2}\csc^{2} u = \frac{1}{2}\left(\frac{1}{u^{2}} + \frac{1}{3} +
\frac{u^{2}}{15} + \cdots\right).
\]

Since \( u = (z - z_{k})/2 \), we have \( 1/u^{2} = 4/(z-z_{k})^{2} \), hence

\[
f(z) = \frac{2}{(z-z_{k})^{2}} + \frac{1}{6} + \cdots.
\]

The Laurent expansion contains **no \( (z-z_{k})^{-1} \) term**, so

\[
\operatorname{Res}(f,\, z_{k}) = 0 \quad\text{for each pole } z_{k}.
\]

In particular:

\[
\operatorname{Res}(f,\,\pi) = 0, \qquad \operatorname{Res}(f,\,-\pi) = 0.
\]

### Step 4: Apply the residue theorem

By the residue theorem,

\[
J = 2\pi i \sum_{\text{poles inside } C} \operatorname{Res}(f,\,z_{k}) = 2\pi i\
,\bigl(0 + 0\bigr) = 0.
\]

### Result

\[
\boxed{J = 0}
\]
