## Solution

**Setup.** Let the square $ABCD$ have side length $4$, with $A=(0,0)$, $B=(4,0)$
, $C=(4,4)$, $D=(0,4)$. Since $AF:AD = 1:4$, we have $F=(0,1)$.

**Finding $E$.** Since $AECF$ is a parallelogram, its diagonals bisect each othe
r: $A+C = E+F$, giving $E = (0,0)+(4,4)-(0,1) = (4,3)$, which lies on $BC$. ✓

**Reflection across diagonal $AC$ (the line $y=x$).** Swapping coordinates:
- $E=(4,3) \mapsto E'=(3,4)$ (on $CD$), $F=(0,1) \mapsto F'=(1,0)$ (on $AB$).

The second parallelogram is $AE'CF'$ with vertices $A=(0,0)$, $E'=(3,4)$, $C=(4,
4)$, $F'=(1,0)$.

**Interior inequalities.** Both parallelograms share center $(2,2)$.

Parallelogram 1 ($AECF$): $\frac{3}{4}x \le y \le \frac{3}{4}x+1$, $\;0\le x\le
4$.

Parallelogram 2 ($AE'CF'$): $\frac{4}{3}x - \frac{4}{3} \le y \le \frac{4}{3}x$,
 $\;0\le y\le 4$.

**Overlap region.** The four boundary lines are:
- $L_1: y=\frac{3}{4}x$ (lower, P1), $\;L_2: y=\frac{3}{4}x+1$ (upper, P1)
- $L_3: y=\frac{4}{3}x-\frac{4}{3}$ (lower, P2), $\;L_4: y=\frac{4}{3}x$ (upper,
 P2)

Key intersections:
- $L_1 \cap L_4$: $(0,0) = A$
- $L_2 \cap L_4$: $\frac{3}{4}x+1 = \frac{4}{3}x \Rightarrow x=\frac{12}{7}$, $y
=\frac{16}{7}$ → $P_1 = \left(\frac{12}{7},\frac{16}{7}\right)$
- $L_2 \cap L_3$: $\frac{3}{4}x+1 = \frac{4}{3}x-\frac{4}{3} \Rightarrow x=4$, $
y=4$ → $C$
- $L_1 \cap L_3$: $\frac{3}{4}x = \frac{4}{3}x-\frac{4}{3} \Rightarrow x=\frac{1
6}{7}$, $y=\frac{12}{7}$ → $P_2 = \left(\frac{16}{7},\frac{12}{7}\right)$

The Heritage Garden is the quadrilateral $A\,P_1\,C\,P_2$.

**Area $m$ (shoelace).**
$$2m = \left|0\cdot\tfrac{16}{7} + \tfrac{12}{7}\cdot 4 + 4\cdot\tfrac{12}{7} +
\tfrac{16}{7}\cdot 0 - \left(0\cdot\tfrac{12}{7} + \tfrac{16}{7}\cdot 4 + 4\cdot
\tfrac{16}{7} + \tfrac{12}{7}\cdot 0\right)\right|$$
$$= \left|\tfrac{48}{7} + \tfrac{48}{7} - \tfrac{64}{7} - \tfrac{64}{7}\right| =
 \left|\tfrac{96-128}{7}\right| = \tfrac{32}{7}$$
$$m = \frac{16}{7}$$

*Cross-check via diagonals:* $d_1 = |AC| = 4\sqrt{2}$, $\;d_2 = |P_1P_2| = \frac
{4\sqrt{2}}{7}$. Area $= \frac{1}{2}\cdot 4\sqrt{2}\cdot\frac{4\sqrt{2}}{7} = \f
rac{16}{7}$. ✓

**Perimeter $n$.** Each side:
$$|AP_1| = \sqrt{\left(\tfrac{12}{7}\right)^2+\left(\tfrac{16}{7}\right)^2} = \s
qrt{\tfrac{400}{49}} = \frac{20}{7}$$
By symmetry, all four sides equal $\frac{20}{7}$ (the garden is a **rhombus**).
$$n = 4\cdot\frac{20}{7} = \frac{80}{7}$$

**The ratio.**
$$\frac{m}{n^2} = \frac{16/7}{(80/7)^2} = \frac{16/7}{6400/49} = \frac{16\cdot 4
9}{7\cdot 6400} = \frac{16\cdot 7}{6400} = \frac{112}{6400} = \frac{7}{400}$$

This is irreducible ($\gcd(7,400)=1$), so $a=7$, $b=400$.

$$a + b = 7 + 400 = \boxed{407}$$
