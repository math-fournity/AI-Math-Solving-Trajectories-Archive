## Setup

Using $\sin^2(x) = \frac{1-\cos(2x)}{2}$, I get $E = \frac{2007 - \sum \cos(2x_i
)}{2}$.

Let $y_i = 2x_i \geq 0$ with $\sum y_i = 2\pi$. Maximizing $E$ is equivalent to
**minimizing** $S = \sum_{i=1}^{2007} \cos(y_i)$.

## KKT Analysis

At any local minimum with $\lambda$ as the Lagrange multiplier for $\sum y_i = 2
\pi$:

- **Active variables** ($y_i > 0$): $\sin(y_i) = -\lambda$
- **Inactive variables** ($y_i = 0$): requires $\lambda \leq 0$

Since $\lambda \leq 0$, active variables satisfy $\sin(y_i) \geq 0$, so $y_i \in
 (0, \pi]$. Each active variable takes one of two values: $\alpha$ or $\pi - \al
pha$, where $\alpha \in (0, \pi/2]$.

Let $p$ variables equal $\alpha$ and $q$ variables equal $\pi - \alpha$, with $p
\alpha + q(\pi-\alpha) = 2\pi$.

Setting $r = p - q$, the constraint gives $q = 2 - r\alpha/\pi$, and the objecti
ve becomes:

$$S = r\cdot h(\alpha) + 2003, \quad \text{where } h(\alpha) = \cos\alpha - 1 +
\frac{2\alpha}{\pi}$$

## Bounding $h(\alpha)$

Compute $h(0) = 0$, $h(\pi/2) = 0$, and $h''(\alpha) = -\cos\alpha < 0$ on $(0,
\pi/2)$, so $h$ is **concave** with $h \geq 0$ on $[0, \pi/2]$.

Since $h(\alpha) \geq 0$, to minimize $S$ we want $r$ as **negative** as possibl
e. The constraint $p \geq 0$ gives $r \geq -2\pi/(\pi - \alpha)$, achieved when
$p = 0$ (all active variables equal $\pi - \alpha$).

## Symmetric Solution

At $p = 0$: all $q$ active variables equal $\pi - \alpha = 2\pi/q$, giving:

$$E = q\sin^2\!\left(\frac{\pi}{q}\right)$$

## Maximizing over integer $q$

Define $f(q) = q\sin^2(\pi/q)$:

| $q$ | $f(q)$ |
|-----|--------|
| 1 | $0$ |
| 2 | $2\sin^2(\pi/2) = 2$ |
| 3 | $3\sin^2(\pi/3) = 3\cdot\frac{3}{4} = \frac{9}{4}$ |
| 4 | $4\sin^2(\pi/4) = 2$ |
| 5 | $\approx 1.727$ |
| 6 | $6\cdot\frac{1}{4} = 1.5$ |

For the continuous function $f(x)$, $f'(x) = \sin(t)[\sin(t) - 2t\cos(t)]$ where
 $t = \pi/x$. For $x \geq 3$ (i.e., $t \leq \pi/3$), the inequality $\tan(t) < 2
t$ holds (verified: $3\sqrt{3}/\pi \approx 1.654 < 2$), so $f'(x) < 0$. Thus **$
f$ is strictly decreasing for $x \geq 3$**.

The maximum over positive integers is at $q = 3$: $f(3) = 9/4$.

## Ruling out $y_i > \pi$

If some $y_1 > \pi$, then $\sum_{i\geq 2} y_i = 2\pi - y_1 < \pi$, so all remain
ing variables lie in $[0, \pi)$ where $\cos$ is **concave**. By the concave merg
ing inequality ($f(a)+f(b) \geq f(a+b)+f(0)$), the sum is minimized by concentra
ting the remaining mass into one variable:

$$S \geq \cos(y_1) + \cos(2\pi - y_1) + 2005 = 2\cos(y_1) + 2005$$

Minimized at $y_1 = \pi$: $S \geq 2003$, giving $E \leq 2 < 9/4$.
