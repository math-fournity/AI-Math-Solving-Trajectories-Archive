## Proof

**Claim:** The number of valid orderings is $2^{n-1}$.

**Key observation.** Build the ordering left to right, tracking the set $S$ of i
ntegers placed so far. The condition says: every element after the first differs
 by $1$ from some element already in $S$.

**Lemma.** At every stage, $S$ is a set of consecutive integers (an interval).

*Proof by induction.* Initially $S = \{a_1\}$, a single-element interval. Suppos
e $S = \{l, l+1, \dots, r\}$ is an interval. The next element $x$ must differ by
 $1$ from some element of $S$, so $x \in \{l-1, r+1\}$ (since $l-1$ and $r+1$ ar
e the only integers not in $S$ that differ by $1$ from a member of $S$). Adding
$x$ extends the interval to $\{l-1,\dots,r\}$ or $\{l,\dots,r+1\}$, still an int
erval. ∎

**Counting.** Suppose the first element is $k$ (where $1 \le k \le n$). The inte
rval starts as $\{k\}$ and must grow to $\{1,\dots,n\}$. To reach the full range
 we must add:
- the **left** elements $k{-}1, k{-}2, \dots, 1$ — necessarily in this exact dec
reasing order (each is the unique left-neighbor available when added), giving $k
-1$ additions;
- the **right** elements $k{+}1, k{+}2, \dots, n$ — necessarily in this exact in
creasing order, giving $n-k$ additions.

The only freedom is **interleaving** these two fixed ordered sequences. The numb
er of interleavings of a sequence of length $k-1$ with a sequence of length $n-k
$ is
$$\binom{n-1}{k-1}.$$

Summing over all possible first elements $k$:
$$\sum_{k=1}^{n} \binom{n-1}{k-1} = \sum_{j=0}^{n-1}\binom{n-1}{j} = 2^{n-1}.$$

**Verification for small $n$.**
- $n=1$: only $(1)$; $2^0 = 1$. ✓
- $n=2$: $(1,2),(2,1)$ both valid; $2^1 = 2$. ✓
- $n=3$: valid orderings are $(1,2,3),(3,2,1),(2,1,3),(2,3,1)$; $2^2 = 4$. ✓ (Th
e orderings $(1,3,2)$ and $(3,1,2)$ fail since $3$ is not adjacent to $1$.)

Therefore the number of orderings is $\boxed{2^{n-1}}$.
