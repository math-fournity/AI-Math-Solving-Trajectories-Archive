## Solution

**The answer is 3.**

### Setup and Key Concept

Let $G$ be the graph whose vertices are the $99^2$ cells, with two cells adjacen
t (in the problem's sense: sharing a vertex or side, i.e., Chebyshev distance 1)
. A labeling by Maéna is a bijection $f: V(G) \to \{1, 2, \dots, 99^2\}$. An *in
creasing path* is a sequence of cells $v_1, v_2, \dots, v_k$ where consecutive c
ells are adjacent and $f(v_1) < f(v_2) < \cdots < f(v_k)$. The number of moves i
s $k - 1$.

Théodore seeks to maximize the path length; Maéna seeks to minimize it. We compu
te:
$$\min_{f}\;\max_{\text{increasing paths}} (\text{length in vertices}).$$

### The General Theorem

**Theorem.** For any graph $G$, the minimum over all labelings of the longest in
creasing path (in vertices) equals $\chi(G)$, the chromatic number of $G$.

**Lower bound (Théodore can always achieve $\chi(G)$ vertices).** Given any labe
ling $f$, define $g(v)$ = length of the longest increasing path ending at $v$:
$$g(v) = 1 + \max\{g(u) : u \sim v,\; f(u) < f(v)\},$$
with $g(v)=1$ if no such $u$ exists. Let $M = \max_v g(v)$, so the longest incre
asing path has $M$ vertices.

Define a coloring $c(v) = g(v)$, using values in $\{1, \dots, M\}$. For any edge
 $(u, v)$ with $f(u) < f(v)$, we have $g(v) \geq g(u) + 1$, so $c(u) \neq c(v)$.
 Thus $c$ is a proper $M$-coloring, giving $M \geq \chi(G)$.

**Upper bound (Maéna can limit to $\chi(G)$ vertices).** Take a proper $\chi(G)$
-coloring with color classes $C_1, \dots, C_{\chi(G)}$. Maéna assigns numbers $1
$ through $|C_1|$ to cells of $C_1$, then $|C_1|+1$ through $|C_1|+|C_2|$ to cel
ls of $C_2$, and so on. In any increasing path, consecutive cells must be adjace
nt, hence in different color classes (each class is an independent set). Moreove
r, the labels are strictly increasing, so the color class indices must be strict
ly increasing. The path therefore uses at most one cell per class, giving at mos
t $\chi(G)$ vertices, i.e., at most $\chi(G) - 1$ moves.

Combining both bounds, the guaranteed number of moves is exactly $\chi(G) - 1$.

### Computing $\chi(G)$ for the $99 \times 99$ King's Graph

**Lower bound $\chi(G) \geq 4$:** Any $2 \times 2$ block of cells forms a clique
 $K_4$, since every pair of cells in a $2 \times 2$ block shares a side or verte
x. Such blocks exist in a $99 \times 99$ grid, so $\omega(G) \geq 4$, hence $\ch
i(G) \geq 4$.

**Upper bound $\chi(G) \leq 4$:** The coloring $c(i,j) = 2(i \bmod 2) + (j \bmod
 2)$ assigns one of 4 colors to each cell $(i,j)$. If two distinct cells share t
he same color, then $i \equiv i' \pmod{2}$ and $j \equiv j' \pmod{2}$, so $|i -
i'| \geq 2$ or $|j - j'| \geq 2$, giving Chebyshev distance $\geq 2$. They are n
ot adjacent. This is a proper 4-coloring.

Therefore $\chi(G) = 4$.

### Conclusion

The number of moves Théodore can guarantee is $\chi(G) - 1 = 4 - 1 = \boxed{3}$.
