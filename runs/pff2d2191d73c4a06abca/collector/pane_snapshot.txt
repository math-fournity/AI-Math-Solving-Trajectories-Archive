## Solution

Alice, Bob, Carol roll fair dice, obtaining $a, b, c \in \{1,2,3,4,5,6\}$ indepe
ndently and uniformly. The polynomial with roots $a, b, c$ is
$$f(x) = x^3 + px^2 + qx + r, \quad p = -(a+b+c),\ q = ab+ac+bc,\ r = -abc.$$

The sum of squares of the coefficients (including the leading $1$) is
$$S = 1 + p^2 + q^2 + r^2.$$

**Useful moments.** $E[a] = \tfrac{7}{2}$, $\ E[a^2] = \tfrac{91}{6}$, and by in
dependence $E[a^2b^2]=\big(\tfrac{91}{6}\big)^2$, $E[a^2bc]=\tfrac{91}{6}\cdot\b
ig(\tfrac{7}{2}\big)^2$, $E[a^2b^2c^2]=\big(\tfrac{91}{6}\big)^3$.

**$E[p^2]$.** $p^2=(a+b+c)^2$, so
$$E[p^2] = 3\cdot\tfrac{91}{6} + 2\cdot 3\cdot\big(\tfrac{7}{2}\big)^2 = \tfrac{
273}{6} + 6\cdot\tfrac{49}{4} = 45.5 + 73.5 = 119.$$

**$E[q^2]$.** $q^2 = (ab+ac+bc)^2 = (ab)^2+(ac)^2+(bc)^2 + 2\big(a^2bc + ab^2c +
 abc^2\big)$.
$$E[q^2] = 3\cdot\big(\tfrac{91}{6}\big)^2 + 2\cdot 3\cdot\tfrac{91}{6}\cdot\big
(\tfrac{7}{2}\big)^2 = \tfrac{8281}{12} + \tfrac{4459}{4} = \tfrac{8281+13377}{1
2} = \tfrac{21658}{12} = \tfrac{10829}{6}.$$

**$E[r^2]$.** $r^2 = (abc)^2 = a^2b^2c^2$, so
$$E[r^2] = \big(\tfrac{91}{6}\big)^3 = \tfrac{753571}{216}.$$

**Total.**
$$E[S] = 1 + 119 + \tfrac{10829}{6} + \tfrac{753571}{216} = \tfrac{216 + 25704 +
 389844 + 753571}{216} = \tfrac{1169335}{216}.$$

Check coprimality: $216 = 2^3\cdot 3^3$. The numerator $1169335$ is odd and its
digit sum is $28$ (not divisible by $3$), so $\gcd(m,n)=1$.

Thus $m = 1169335$, $n = 216$, and
$$m + n = 1169551 \equiv 551 \pmod{1000}.$$

The remainder when $m+n$ is divided by $1000$ is $\boxed{551}$.
