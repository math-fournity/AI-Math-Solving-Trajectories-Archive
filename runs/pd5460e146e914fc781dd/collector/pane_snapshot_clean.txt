## Proof

We wish to compute $\partial_{\overline{z}}\!\left(\dfrac{z}{z-w}\right)$, where
 $z$ is the variable and $w$ is a fixed parameter, using the given identity
$$\partial_{\overline{z}}\!\left(\frac{1}{z-w}\right) = \delta(z-w).$$

**Step 1: Product rule.** Since $z$ is a holomorphic function of $z$, we have $\
partial_{\overline{z}}\, z = 0$. Applying the product (Leibniz) rule for the Wir
tinger derivative $\partial_{\overline{z}}$:

$$\partial_{\overline{z}}\!\left(\frac{z}{z-w}\right) = \partial_{\overline{z}}\
!\left(z \cdot \frac{1}{z-w}\right) = \left(\partial_{\overline{z}}\, z\right)\f
rac{1}{z-w} + z\,\partial_{\overline{z}}\!\left(\frac{1}{z-w}\right).$$

**Step 2: Substitute the known identity.** Using $\partial_{\overline{z}}\, z =
0$ and the given fact $\partial_{\overline{z}}\!\left(\frac{1}{z-w}\right) = \de
lta(z-w)$:

$$\partial_{\overline{z}}\!\left(\frac{z}{z-w}\right) = 0 \cdot \frac{1}{z-w} +
z\,\delta(z-w) = z\,\delta(z-w).$$

**Step 3: Simplify using the support of the delta function.** The distribution $
\delta(z-w)$ is supported entirely at the point $z = w$. Therefore, when multipl
ied by any smooth test function $f(z)$, we may replace $z$ by $w$:

$$z\,\delta(z-w) = w\,\delta(z-w).$$

**Verification via partial fractions.** As a consistency check, write
$$\frac{z}{z-w} = \frac{(z-w)+w}{z-w} = 1 + \frac{w}{z-w}.$$
Then
$$\partial_{\overline{z}}\!\left(\frac{z}{z-w}\right) = \partial_{\overline{z}}(
1) + w\,\partial_{\overline{z}}\!\left(\frac{1}{z-w}\right) = 0 + w\,\delta(z-w)
 = w\,\delta(z-w),$$
which agrees with the result above.

## Result

$$\boxed{\partial_{\overline{z}}\!\left(\frac{z}{z-w}\right) = w\,\delta(z-w).}$
