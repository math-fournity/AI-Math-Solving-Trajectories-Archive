## Proof

**Claim:** Yes, there exists a continuous positive function on $(0,\infty)$ whos
e integral converges, yet $\lim_{x\to\infty} f(x) \neq 0$.

**Construction.** For each integer $n \geq 1$, define the tent (triangular bump)
 function

$$h_n(x) = \max\!\bigl(0,\; 1 - 2^{n+1}|x - n|\bigr).$$

Each $h_n$ is continuous, supported on the interval $I_n = \bigl[n - 2^{-(n+1)},
\; n + 2^{-(n+1)}\bigr]$, satisfies $h_n(n)=1$, and has area

$$\int_0^\infty h_n(x)\,dx = \tfrac{1}{2}\cdot \underbrace{2^{-n}}_{\text{base}}
\cdot \underbrace{1}_{\text{height}} = 2^{-(n+1)}.$$

The supports $I_n$ are pairwise disjoint: the center spacing is $1$, while the t
otal width of $I_n$ is $2^{-n}\le \tfrac12$, so $I_n$ and $I_{n+1}$ never overla
p (and likewise all others).

Define $h(x) = \sum_{n=1}^{\infty} h_n(x)$. Since the supports are disjoint, at
every point at most one term is nonzero, so $h$ is well-defined and continuous (
each $h_n$ vanishes at the endpoints of $I_n$, so there is no jump at support bo
undaries). Now set

$$\boxed{f(x) = e^{-x} + h(x), \qquad x > 0.}$$

**Verification of the required properties.**

1. **Continuity.** $f$ is the sum of the continuous function $e^{-x}$ and the co
ntinuous function $h$, hence continuous.

2. **Positivity.** Since $e^{-x}>0$ for all $x>0$ and $h(x)\ge 0$, we have $f(x)
>0$ for all $x\in(0,\infty)$.

3. **Convergence of the integral.** By disjointness of supports and monotone con
vergence,

$$\int_0^\infty h(x)\,dx = \sum_{n=1}^{\infty}\int_0^\infty h_n(x)\,dx = \sum_{n
=1}^{\infty}2^{-(n+1)} = \frac{1}{2}.$$

Therefore

$$\int_0^\infty f(x)\,dx = \int_0^\infty e^{-x}\,dx + \int_0^\infty h(x)\,dx = 1
 + \frac{1}{2} = \frac{3}{2}<\infty.$$

4. **The limit is not zero.** Evaluate $f$ at two interleaved sequences:
   - At $x = n$ (the peak of the $n$-th tent): $f(n) = e^{-n} + h_n(n) = e^{-n}+
1 \to 1$.
   - At $x = n+\tfrac12$ (the midpoint between consecutive integers): for all $n
\ge 1$, the point $n+\tfrac12$ lies outside every support $I_k$ (since each $I_k
$ has half-width $2^{-(k+1)}\le \tfrac14 < \tfrac12$), so $h(n+\tfrac12)=0$ and
$f(n+\tfrac12)=e^{-(n+1/2)}\to 0$.

   Thus $f(n)\to 1$ while $f(n+\tfrac12)\to 0$. The limit $\lim_{x\to\infty}f(x)
$ does not exist, and in particular it is **not** equal to $0$.

**Conclusion.** The function $f(x)=e^{-x}+\sum_{n=1}^{\infty}\max\bigl(0,\,1-2^{
n+1}|x-n|\bigr)$ is continuous and strictly positive on $(0,\infty)$, has a conv
ergent integral ($=\tfrac32$), and yet $\lim_{x\to\infty}f(x)\neq 0$. Hence such
 a function exists. $\blacksquare$
