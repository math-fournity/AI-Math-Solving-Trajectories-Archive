## Proof

Let $g = f'$ and $F(x) = f(x) = \int_0^x g(t)\,dt$. We may assume $g \ge 0$: rep
lacing $g$ by $|g|$ preserves the constraint $\int_0^1 g^2 \le 1$ and only incre
ases $|F|$ (hence the objective). With $g \ge 0$, we have $F \ge 0$.

**Key definitions.** Set $G(x) = \int_0^x g(t)^2\,dt$, so $G'(x) = g(x)^2$ and $
G(1) \le 1$.

**Cauchy–Schwarz bound.** For each $x \in [0,1]$:
$$F(x) = \int_0^x g(t)\,dt \le \sqrt{x}\;\sqrt{\int_0^x g(t)^2\,dt} = \sqrt{x}\;
\sqrt{G(x)},$$
so $\dfrac{F(x)}{\sqrt{x}} \le \sqrt{G(x)}$.

**Upper bound on the objective.** Using $g(x)^2 = G'(x)$ and the pointwise bound
 above:
$$\int_0^1 g(x)^2\,F(x)\,x^{-1/2}\,dx = \int_0^1 G'(x)\,\frac{F(x)}{\sqrt{x}}\,d
x \le \int_0^1 G'(x)\,\sqrt{G(x)}\,dx.$$

Since $\frac{d}{dx}\!\left(\tfrac{2}{3}\,G(x)^{3/2}\right) = G'(x)\,\sqrt{G(x)}$
, the fundamental theorem of calculus gives:
$$\int_0^1 G'(x)\,\sqrt{G(x)}\,dx = \tfrac{2}{3}\,G(x)^{3/2}\Big|_{0}^{1} = \tfr
ac{2}{3}\,G(1)^{3/2} \le \tfrac{2}{3}\cdot 1^{3/2} = \tfrac{2}{3}.$$

**Equality is attained.** Take $f(x) = x$, so $g(x) = f'(x) = 1$. Then:
- Constraint: $\int_0^1 g(x)^2\,dx = 1 \le 1$. ✓
- Objective: $\int_0^1 1^2 \cdot x \cdot x^{-1/2}\,dx = \int_0^1 x^{1/2}\,dx = \
frac{2}{3}$.

All inequalities are tight: Cauchy–Schwarz holds with equality because $g \equiv
 1$ is constant on every $[0,x]$, and $G(1) = 1$.

**Conclusion.** The maximum value is $\boxed{\dfrac{2}{3}}$.
