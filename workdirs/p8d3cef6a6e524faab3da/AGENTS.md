# Problem

A high-security data ring consists of 2021 individual server nodes, labeled uniquely with the ID numbers 1 through 2021, arranged in a physical circle. In this network, for any specific ID value $i$ (where $1 \le i \le 2021$), we examine a "cluster" consisting of the node $i$ and the two nodes representing its immediate consecutive values, $i+1$ and $i+2$. (Note: Node IDs are considered cyclic, so for $i=2021$, the values are 2021, 1, and 2).

A node $i$ is designated as "Optimal" if, in their current physical arrangement along the circle, the node labeled $i+1$ is not positioned spatially between node $i$ and node $i+2$. 

The system administrator wants to rearrange the nodes in the circle to maximize the efficiency of the network. What is the maximum possible number of "Optimal" nodes that can exist in the ring?
