## Proof

Let $x = p - a$, $y = p - b$, $z = p - c$. Since $a, b, c$ are the sides of a tr
iangle, each of $x, y, z$ is positive, and
$$a = y + z,\quad b = x + z,\quad c = x + y,\quad p = x + y + z.$$

By Heron's formula, the area of the triangle is
$$\Delta = \sqrt{p(p-a)(p-b)(p-c)} = \sqrt{(x+y+z)\,xyz}.$$

Since $\Delta = pr$, we have
$$r = \frac{\Delta}{p} = \frac{\sqrt{(x+y+z)\,xyz}}{x+y+z} = \sqrt{\frac{xyz}{x+
y+z}}.$$

Therefore
$$\frac{1}{r^2} = \frac{x+y+z}{xyz} = \frac{1}{yz} + \frac{1}{xz} + \frac{1}{xy}
.$$

The desired inequality becomes
$$\frac{1}{x^2} + \frac{1}{y^2} + \frac{1}{z^2} \ge \frac{1}{xy} + \frac{1}{yz}
+ \frac{1}{xz}.$$

Setting $u = 1/x$, $v = 1/y$, $w = 1/z$, this is equivalent to
$$u^2 + v^2 + w^2 \ge uv + vw + uw,$$

which rearranges to
$$\frac{1}{2}\bigl[(u-v)^2 + (v-w)^2 + (w-u)^2\bigr] \ge 0.$$

This holds for all real $u, v, w$, and in particular for $u, v, w > 0$. Equality
 holds if and only if $u = v = w$, i.e., $x = y = z$, i.e., $a = b = c$ (the equ
ilateral triangle).

Therefore
$$\frac{1}{(p-a)^2} + \frac{1}{(p-b)^2} + \frac{1}{(p-c)^2} \ge \frac{1}{r^2},$$
as required. $\blacksquare$
