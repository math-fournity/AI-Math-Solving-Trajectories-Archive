## Proof

We seek an entire function $f(z)$ with $f(0)=1$ and
$$\operatorname{Re}(f(z)) = x^2 - y^2 + e^{-x}\cos y, \qquad z=x+iy.$$

**Step 1: Recognize the real part as the real part of an entire function.**

Recall two standard facts:
- $z^2 = (x+iy)^2 = (x^2-y^2) + 2ixy$, so $\operatorname{Re}(z^2) = x^2 - y^2$.
- $e^{-z} = e^{-x-iy} = e^{-x}(\cos y - i\sin y)$, so $\operatorname{Re}(e^{-z})
 = e^{-x}\cos y$.

Therefore
$$x^2 - y^2 + e^{-x}\cos y = \operatorname{Re}(z^2) + \operatorname{Re}(e^{-z})
= \operatorname{Re}\!\left(z^2 + e^{-z}\right).$$

**Step 2: Use the uniqueness of an entire function with a prescribed real part.*
*

Let $g(z) = z^2 + e^{-z}$, which is entire. Then $\operatorname{Re}(f(z)) = \ope
ratorname{Re}(g(z))$ for all $z\in\mathbb{C}$. Hence $f(z) - g(z)$ is an entire
function whose real part is identically zero. Writing $h(z) = f(z)-g(z) = u(z)+i
v(z)$ with $u\equiv 0$, the Cauchy–Riemann equations give $u_x = v_y = 0$ and $u
_y = -v_x = 0$, so $v$ is constant. Thus
$$f(z) = z^2 + e^{-z} + iC$$
for some real constant $C$.

**Step 3: Determine the constant from $f(0)=1$.**

$$f(0) = 0^2 + e^{0} + iC = 1 + iC.$$
The condition $f(0)=1$ forces $C=0$.

**Conclusion.**

$$\boxed{f(z) = z^2 + e^{-z}}.$$

*Verification:* $\operatorname{Re}(z^2+e^{-z}) = (x^2-y^2)+e^{-x}\cos y$ ✓, and
$f(0)=0+1=1$ ✓.
