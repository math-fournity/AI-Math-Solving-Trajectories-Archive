## Solution

**Setup.** Let $f(a) = |\{x \in \{0,\dots,72\} : x^2 \equiv a \pmod{73}\}|$ for
$a \in \mathbb{Z}/73\mathbb{Z}$. Then $T_k$ is the value at $1$ of the $k$-fold
convolution $f^{*k}$, i.e. the number of $k$-tuples with $\sum x_i^2 \equiv 1 \p
mod{73}$.

**Fourier analysis.** Let $\omega = e^{2\pi i/73}$. The Fourier transform is $\w
idehat{f}(j) = \sum_{x=0}^{72} f(x)\omega^{jx} = \sum_{t=0}^{72}\omega^{jt^2}$,
which is the Gauss sum $G(j,73)$. By convolution/inversion:
$$T_k = f^{*k}(1) = \frac{1}{73}\sum_{j=0}^{72}\widehat{f}(j)^k\,\omega^{-j}.$$

We have $\widehat{f}(0)=73$, and for $j\neq 0$, since $73\equiv 1\pmod 4$,
$$\widehat{f}(j)=G(j,73)=\left(\tfrac{j}{73}\right)\sqrt{73}, \qquad G(1,73)^2=7
3.$$

So
$$T_k=\frac{1}{73}\left[73^k+73^{k/2}\sum_{j=1}^{72}\left(\tfrac{j}{73}\right)^k
\omega^{-j}\right].$$

**Evaluating the inner sum.**
- *$k$ even:* $\left(\frac{j}{73}\right)^k=1$, so $\sum_{j=1}^{72}\omega^{-j}=-1
$, giving $T_k=\frac{73^k-73^{k/2}}{73}=73^{k-1}-73^{k/2-1}$.
- *$k$ odd:* $\left(\frac{j}{73}\right)^k=\left(\frac{j}{73}\right)$, so $\sum_{
j=1}^{72}\left(\frac{j}{73}\right)\omega^{-j}=\left(\frac{-1}{73}\right)G(1,73)=
\sqrt{73}$ (since $73\equiv1\pmod4$), giving $T_k=\frac{73^k+73^{(k+1)/2}}{73}=7
3^{k-1}+73^{(k-1)/2}$.

*Check:* $T_1=1+1=2$ (solutions $x=\pm1$); $T_2=73-1=72$ (matches the standard c
ount for $x^2+y^2\equiv a$, $a\neq0$, $p\equiv1\pmod4$). ✓

**Summing $T_1+\cdots+T_{2017}$.** Set $n=k-1\in\{0,\dots,2016\}$.
- $n=2m$ even ($m=0,\dots,1008$): $T=73^{2m}+73^m$.
- $n=2m+1$ odd ($m=0,\dots,1007$): $T=73^{2m+1}-73^m$.

Summing:
$$\sum_{k=1}^{2017}T_k=\underbrace{\sum_{m=0}^{1008}73^{2m}+\sum_{m=0}^{1007}73^
{2m+1}}_{\sum_{n=0}^{2016}73^n=\frac{73^{2017}-1}{72}}+\underbrace{\sum_{m=0}^{1
008}73^m-\sum_{m=0}^{1007}73^m}_{73^{1008}}.$$

So
$$\sum_{k=1}^{2017}T_k=\frac{73^{2017}-1}{72}+73^{1008}.$$

**Reducing mod $2017$.** Since $2017$ is prime and $\gcd(73,2017)=\gcd(72,2017)=
1$:
- By Fermat, $73^{2016}\equiv1\pmod{2017}$, so $73^{2017}\equiv73\pmod{2017}$, h
ence $\frac{73^{2017}-1}{72}\equiv\frac{73-1}{72}=1\pmod{2017}$.
- By Euler's criterion, $73^{1008}\equiv\left(\frac{73}{2017}\right)\pmod{2017}$
.

**Computing $\left(\frac{73}{2017}\right)$.** Since $73\equiv1\pmod4$, quadratic
 reciprocity gives $\left(\frac{73}{2017}\right)=\left(\frac{2017}{73}\right)$.
Now $2017\equiv46\pmod{73}$, so
$$\left(\frac{46}{73}\right)=\left(\frac{2}{73}\right)\left(\frac{23}{73}\right)
.$$
- $\left(\frac{2}{73}\right)=(-1)^{(73^2-1)/8}=(-1)^{666}=1$ (since $73\equiv1\p
mod8$).
- For $\left(\frac{23}{73}\right)$: $23\equiv3\pmod4$, $73\equiv1\pmod4$, so $\l
eft(\frac{23}{73}\right)=\left(\frac{73}{23}\right)=\left(\frac{4}{23}\right)=1$
.

Thus $\left(\frac{73}{2017}\right)=1$, so $73^{1008}\equiv1\pmod{2017}$.

**Final answer.**
$$\sum_{k=1}^{2017}T_k\equiv 1+1=\boxed{2}\pmod{2017}.$$
