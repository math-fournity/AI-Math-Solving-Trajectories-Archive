## Solution

We want to evaluate

$$S=\sum_{k=1}^{\infty}\frac{6^{k}}{(3^{k+1}-2^{k+1})(3^{k}-2^{k})}.$$

**Set up a telescoping decomposition.** Let $a_k = 3^k - 2^k$, so $a_{k+1}=3^{k+
1}-2^{k+1}$ and the summand is $\dfrac{6^k}{a_k\,a_{k+1}}$.

We seek a telescoping form $\dfrac{b_k}{a_k}-\dfrac{b_{k+1}}{a_{k+1}}$, which eq
uals

$$\frac{b_k\,a_{k+1}-b_{k+1}\,a_k}{a_k\,a_{k+1}}.$$

We need $b_k\,a_{k+1}-b_{k+1}\,a_k = 6^k$. **Try $b_k=2^k$:**

$$b_k\,a_{k+1}-b_{k+1}\,a_k = 2^k(3^{k+1}-2^{k+1})-2^{k+1}(3^k-2^k).$$

Expanding:

$$=2^k\cdot 3^{k+1}-2^{2k+1}-2^{k+1}\cdot 3^k+2^{2k+1}=2^k\cdot 3^k(3-2)=6^k.\ \
checkmark$$

So the identity holds:

$$\frac{6^k}{a_k\,a_{k+1}}=\frac{2^k}{a_k}-\frac{2^{k+1}}{a_{k+1}}.$$

**Telescope the sum.** The partial sum is

$$S_N=\sum_{k=1}^{N}\left(\frac{2^k}{a_k}-\frac{2^{k+1}}{a_{k+1}}\right)=\frac{2
^1}{a_1}-\frac{2^{N+1}}{a_{N+1}}.$$

Since $a_1=3-2=1$, the first term is $2$.

**Evaluate the limit.** As $N\to\infty$,

$$\frac{2^{N+1}}{a_{N+1}}=\frac{2^{N+1}}{3^{N+1}-2^{N+1}}=\frac{(2/3)^{N+1}}{1-(
2/3)^{N+1}}\longrightarrow 0.$$

Therefore

$$S=\lim_{N\to\infty}S_N = 2 - 0 = 2.$$

**Numerical check.** The first few terms are $\frac65,\frac{36}{95},\frac{216}{1
235},\frac{1296}{13715},\dots\approx 1.2,\,0.379,\,0.175,\,0.0945,\dots$, whose
partial sums $1.2,1.579,1.754,1.848,\dots$ approach $2$, confirming the result.

$$\boxed{S=2}$$
