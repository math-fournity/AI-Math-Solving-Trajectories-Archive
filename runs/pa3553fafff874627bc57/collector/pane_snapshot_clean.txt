## 解答

**第一步：重写被乘项。** 利用恒等式 $4\sin^2\theta = 2 - 2\cos(2\theta)$，可得
$$4\sin^2\!\Big(\frac{k\pi}{2^{2000}}\Big) - 3 = -1 - 2\cos\!\Big(\frac{k\pi}{2^
{1999}}\Big) = -\Big(1 + 2\cos\!\Big(\frac{k\pi}{2^{1999}}\Big)\Big).$$

令 $n = 2^{1999}$。则所求乘积为
$$\Pi = \prod_{k=0}^{n}\Big(1+2\cos\frac{k\pi}{n}\Big)\cdot(-1)^{n+1}.$$

由于 $n = 2^{1999}$ 为偶数，$n+1$ 为奇数，故 $(-1)^{n+1} = -1$，即
$$\Pi = -P, \qquad P := \prod_{k=0}^{n}\Big(1+2\cos\frac{k\pi}{n}\Big).$$

**第二步：分离端点。**
- $k=0$：$1+2\cos 0 = 3$；
- $k=n$：$1+2\cos\pi = -1$。

因此
$$P = -3\prod_{k=1}^{n-1}\Big(1+2\cos\frac{k\pi}{n}\Big).$$

**第三步：用 Chebyshev 多项式 $U_{n-1}$ 求中间乘积。** 第二类 Chebyshev 多项式满
足
$$U_{n-1}(x) = 2^{n-1}\prod_{k=1}^{n-1}\Big(x - \cos\frac{k\pi}{n}\Big),$$
其根为 $\cos\frac{k\pi}{n}$，$k=1,\dots,n-1$。代入 $x = -\tfrac12$：
$$\prod_{k=1}^{n-1}\Big(\cos\frac{k\pi}{n}+\frac12\Big) = \frac{(-1)^{n-1}}{2^{n
-1}}\,U_{n-1}\!\Big(-\frac12\Big).$$
于是
$$\prod_{k=1}^{n-1}\Big(1+2\cos\frac{k\pi}{n}\Big) = 2^{n-1}\cdot\frac{(-1)^{n-1
}}{2^{n-1}}\,U_{n-1}\!\Big(-\frac12\Big) = (-1)^{n-1}\,U_{n-1}\!\Big(-\frac12\Bi
g).$$

**第四步：计算 $U_{n-1}(-1/2)$。** 由 $U_{m}(\cos\theta) = \dfrac{\sin((m+1)\the
ta)}{\sin\theta}$，取 $\cos\theta = -\frac12$，即 $\theta = \frac{2\pi}{3}$：
$$U_{n-1}\!\Big(-\frac12\Big) = \frac{\sin\!\big(\frac{2n\pi}{3}\big)}{\sin\frac
{2\pi}{3}} = \frac{\sin\!\big(\frac{2n\pi}{3}\big)}{\sqrt3/2}.$$

**第五步：合并。** 注意 $(-1)^{n+1}\cdot(-1)^{n-1} = (-1)^{2n} = 1$，因此
$$\Pi = (-1)^{n+1}\cdot(-3)\cdot(-1)^{n-1}\cdot\frac{\sin\!\big(\frac{2n\pi}{3}\
big)}{\sqrt3/2} = -3\cdot\frac{\sin\!\big(\frac{2n\pi}{3}\big)}{\sqrt3/2} = -2\s
qrt3\,\sin\!\Big(\frac{2n\pi}{3}\Big).$$

**第六步：代入 $n = 2^{1999}$。** 需计算 $\sin\!\Big(\dfrac{2^{2000}\pi}{3}\Big)
$。由于 $2\equiv -1\pmod 6$ 的循环：$2^k\bmod 6$ 在 $k$ 奇时为 $2$、$k$ 偶时为 $
4$。$2000$ 为偶数，故
$$2^{2000}\equiv 4\pmod 6 \implies \frac{2^{2000}\pi}{3}\equiv \frac{4\pi}{3}\pm
od{2\pi} \implies \sin\!\Big(\frac{2^{2000}\pi}{3}\Big) = \sin\frac{4\pi}{3} = -
\frac{\sqrt3}{2}.$$

**第七步：得出最终结果。**
$$\Pi = -2\sqrt3\cdot\Big(-\frac{\sqrt3}{2}\Big) = 3.$$

**验证（小情形）：** 取 $n=2$（即 $2^{1999}\mapsto 2$，$2^{2000}\mapsto 4$）：
