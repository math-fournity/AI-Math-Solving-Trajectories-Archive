# Problem

In a specialized technology hub, there are three distinct server clusters—Alpha, Beta, and Gamma—each containing exactly $n = 50$ individual processing units. 

Every processing unit in each cluster is hard-wired to exactly $k$ units located in the other two clusters (a unit in Alpha is connected to a total of $k$ units distributed across Beta and Gamma, and the same rule applies to units in Beta and Gamma). Connections are always mutual; if unit A is connected to unit B, then unit B is connected to unit A.

Data can only be processed in a "Triple-Sync" if we can identify three units—one from Cluster Alpha, one from Cluster Beta, and one from Cluster Gamma—where every unit in the trio is directly connected to the other two.

What is the minimum value of $k$ required to guarantee that, regardless of how the connections are distributed, a "Triple-Sync" trio must exist?
