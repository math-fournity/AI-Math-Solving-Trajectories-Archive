## Proof

**Step 1: Swap the order of summation.**

Write $k = dj$ where $d$ is an odd divisor of $k$. The condition $d < \sqrt{2k}$
 becomes $d < \sqrt{2dj}$, i.e., $j > d/2$. Since $d$ is odd, this means $j \geq
 (d+1)/2$.

Since $d$ is odd, $(-1)^{k-1} = (-1)^{dj-1} = (-1)^{j-1}$. So:

$$\sum_{k=1}^\infty (-1)^{k-1}\frac{A(k)}{k} = \sum_{\substack{d \geq 1 \\ d \te
xt{ odd}}} \frac{1}{d}\sum_{j=(d+1)/2}^{\infty} \frac{(-1)^{j-1}}{j}.$$

Setting $d = 2m+1$ for $m = 0, 1, 2, \ldots$, the inner sum starts at $j = m+1$:

$$= \sum_{m=0}^{\infty} \frac{1}{2m+1}\sum_{j=m+1}^{\infty} \frac{(-1)^{j-1}}{j}
.$$

**Step 2: Swap again.** For fixed $j \geq 1$, $m$ ranges from $0$ to $j-1$. Defi
ne $T(j) = \sum_{m=0}^{j-1} \frac{1}{2m+1}$. The swap is justified by absolute c
onvergence ($|S(m+1)| \leq \frac{1}{m+1}$ gives $\sum \frac{1}{(2m+1)(m+1)} < \i
nfty$):

$$= \sum_{j=1}^{\infty} \frac{(-1)^{j-1}}{j}\, T(j).$$

**Step 3: Integral representation.** Using $T(j) = \int_0^1 \frac{1 - t^{2j}}{1-
t^2}\,dt$ (since $\int_0^1 t^{2m}\,dt = \frac{1}{2m+1}$):

$$= \int_0^1 \frac{1}{1-t^2}\sum_{j=1}^{\infty} \frac{(-1)^{j-1}(1-t^{2j})}{j}\,
dt = \int_0^1 \frac{\ln 2 - \ln(1+t^2)}{1-t^2}\,dt = \int_0^1 \frac{\ln\frac{2}{
1+t^2}}{1-t^2}\,dt.$$

The interchange is valid by dominated convergence (the partial sums are bounded
as an alternating series, and the singularity at $t=1$ is removable since $\ln\f
rac{2}{1+t^2} \to 0$).

**Step 4: Simplify via substitution.** Let $t = \tan\theta$, so $1+t^2 = \sec^2\
theta$, $1-t^2 = \frac{\cos 2\theta}{\cos^2\theta}$, $dt = \sec^2\theta\,d\theta
$:

$$I = \int_0^{\pi/4} \frac{\ln(2\cos^2\theta)}{\cos 2\theta}\,d\theta = \int_0^{
\pi/4} \frac{\ln(1+\cos 2\theta)}{\cos 2\theta}\,d\theta,$$

using $2\cos^2\theta = 1 + \cos 2\theta$. Now set $w = \cos 2\theta$, $dw = -2\s
in 2\theta\,d\theta = -2\sqrt{1-w^2}\,d\theta$:

$$I = \frac{1}{2}\int_0^1 \frac{\ln(1+w)}{w\sqrt{1-w^2}}\,dw.$$

**Step 5: Evaluate the integral.** Apply the substitution $w = \frac{2t}{1+t^2}$
 (which maps $[0,1] \to [0,1]$). Then:
- $\sqrt{1-w^2} = \frac{1-t^2}{1+t^2}$, $\quad dw = \frac{2(1-t^2)}{(1+t^2)^2}\,
dt$
- $1 + w = \frac{(1+t)^2}{1+t^2}$, $\quad$ so $\ln(1+w) = 2\ln(1+t) - \ln(1+t^2)
$

Substituting:

$$I = \frac{1}{2}\int_0^1 \frac{2\ln(1+t) - \ln(1+t^2)}{t}\,dt = \int_0^1 \frac{
\ln(1+t)}{t}\,dt - \frac{1}{2}\int_0^1 \frac{\ln(1+t^2)}{t}\,dt.$$

**First integral:** $\displaystyle\int_0^1 \frac{\ln(1+t)}{t}\,dt = -\operatorna

**Second integral:** Substituting $u = t^2$:

$$\int_0^1 \frac{\ln(1+t^2)}{t}\,dt = \frac{1}{2}\int_0^1 \frac{\ln(1+u)}{u}\,du

**Combining:**

$$I = \frac{\pi^2}{12} - \frac{1}{2}\cdot\frac{\pi^2}{24} = \frac{\pi^2}{12} - \
frac{\pi^2}{48} = \frac{4\pi^2 - \pi^2}{48} = \frac{3\pi^2}{48} = \frac{\pi^2}{1

$$\boxed{\sum_{k=1}^\infty (-1)^{k-1}\frac{A(k)}{k} = \frac{\pi^2}{16}}$$
