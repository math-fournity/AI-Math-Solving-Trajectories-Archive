# Problem

In a specialized logistics network, two types of servers, designated as Model $p$ and Model $q$, are assigned to handle data packets. To ensure network stability, these servers must meet specific security protocols based on their hardware identification numbers.

Both server ID numbers, $p$ and $q$, must be prime numbers strictly less than 2005. The security protocol requires a mutual compatibility condition:
1. The ID number $p$ must be a perfect divisor of the value $(q^2 + 8)$.
2. The ID number $q$ must be a perfect divisor of the value $(p^2 + 8)$.

Let $S$ represent the set of all unique pairs $(p, q)$ that satisfy these specific hardware requirements. Calculate the total sum of the values $(p + q)$ for every valid pair $(p, q)$ found in the set $S$.
