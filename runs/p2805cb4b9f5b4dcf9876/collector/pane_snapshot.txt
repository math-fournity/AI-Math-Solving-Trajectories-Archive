^2+b^2}$ and $\theta = \arg(a+bi)$. Then $(a+bi)^\ell = r^\ell e^{i\ell\theta}$
is real if and only if $\ell\theta \in \pi\mathbb{Z}$, i.e., $\theta/\pi \in \ma
thbb{Q}$.

**Special cases:** $(0,0)$ is real (take $\ell=1$), so primitive. If $b=0, a>0$:
 $a+bi=a$ is real, primitive. If $a=0, b>0$: $(bi)^\ell = b^\ell i^\ell$ is real
 when $\ell$ is even, primitive.

**Case $a,b > 0$:** Here $\tan\theta = b/a \in \mathbb{Q}$. I claim $(a,b)$ is p
rimitive if and only if $a = b$.

If $a = b > 0$: $a+bi = a\sqrt{2}\,e^{i\pi/4}$, so $(a+bi)^4 = 4a^4 \in \mathbb{
R}$. Primitive. ✓

If $a \neq b$ (both positive): Suppose for contradiction that $\theta/\pi \in \m
athbb{Q}$ and $\tan\theta = b/a \in \mathbb{Q}$. Set $c = \tan\theta \in \mathbb
{Q}_{>0}$ and $w = e^{2i\theta}$, a root of unity. Then:
$$w = \frac{1+ci}{1-ci} = \frac{1-c^2}{1+c^2} + \frac{2c}{1+c^2}\,i.$$
Since $w$ is a root of unity, $\arg(w)/\pi \in \mathbb{Q}$, and $\operatorname{R
e}(w) = \frac{1-c^2}{1+c^2} \in \mathbb{Q}$. By **Niven's theorem** (if $\phi/\p
i \in \mathbb{Q}$ and $\cos\phi \in \mathbb{Q}$, then $\cos\phi \in \{0, \pm\tfr
ac{1}{2}, \pm 1\}$), we need:
$$\frac{1-c^2}{1+c^2} \in \left\{0, \pm\tfrac{1}{2}, \pm 1\right\}.$$

Solving each case for rational $c > 0$:
- $= 1$: gives $c=0$ (excluded since $b>0$).
- $= -1$: gives $1=-1$, impossible.
- $= 0$: gives $c^2=1$, so $c=1$.
- $= \frac{1}{2}$: gives $3c^2=1$, so $c=1/\sqrt{3} \notin \mathbb{Q}$.
- $= -\frac{1}{2}$: gives $c^2=3$, so $c=\sqrt{3} \notin \mathbb{Q}$.

Thus $c = \tan\theta = 1$, meaning $b/a = 1$, i.e., $a = b$—contradicting $a \ne

**Counting primitive pairs in $\{0,1,\ldots,n\}^2$.** The primitive pairs are:
- $(0,0)$: 1 pair
- $(a,0)$ for $1 \le a \le n$: $n$ pairs

These four sets are pairwise disjoint (distinguished by which coordinates are ze

**Finding the smallest $n$.** We need:
$$\frac{3n+1}{(n+1)^2} < \frac{1}{100},$$

$$n = \frac{298 + \sqrt{298^2 + 396}}{2} = \frac{298 + \sqrt{89200}}{2} \approx
