## Proof

The curve is $E: y^2 + y = x^3$ over $\mathbb{F}_{2^4}$ (characteristic 2). This
 is in general Weierstrass form $y^2 + a_1 xy + a_3 y = x^3 + a_2 x^2 + a_4 x +
a_6$ with $a_1 = 0,\; a_2 = 0,\; a_3 = 1,\; a_4 = 0,\; a_6 = 0$.

**Key fact.** A point $P$ satisfies $2P = O$ if and only if $P = -P$.

**Negation formula.** For a point $P = (x, y)$ on a general Weierstrass curve, t
he inverse is
$$-P = (x,\; -y - a_1 x - a_3).$$

Substituting $a_1 = 0$ and $a_3 = 1$:
$$-P = (x,\; -y - 1).$$

**Working in characteristic 2.** In $\mathbb{F}_{2^4}$, every element satisfies
$-a = a$ (since $a + a = 2a = 0$). In particular $-y = y$ and $-1 = 1$. Therefor
e:
$$-P = (x,\; y + 1).$$

**Solving $P = -P$.** We need $(x, y) = (x, y+1)$, which requires:
$$y = y + 1 \implies 0 = 1,$$
a contradiction. So **no affine point** $P = (x,y)$ satisfies $P = -P$.

**The point at infinity.** The identity element $O$ (point at infinity) always s
atisfies $2O = O$.

**Conclusion.** The only point $P$ on $E(\mathbb{F}_{2^4})$ with $2P = O$ is the
 point at infinity $O$.

**Remark.** This is consistent with the fact that $y^2 + y = x^3$ is a *supersin
gular* elliptic curve in characteristic 2 (its $j$-invariant is $0$). Supersingu
lar curves in characteristic $p$ have trivial $p$-torsion over $\overline{\mathb
b{F}_p}$, so the 2-torsion subgroup is $\{O\}$ regardless of which extension fie
ld $\mathbb{F}_{2^n}$ we work over.

$$\boxed{\{P \in E(\mathbb{F}_{2^4}) : 2P = O\} = \{O\}}$$
