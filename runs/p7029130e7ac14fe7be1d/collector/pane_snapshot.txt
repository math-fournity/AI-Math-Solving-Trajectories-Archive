## Proof

**Answer: TRUE.**

We interpret $F$ as the Fourier transform on $L^2(\mathbb{R}^3)$ (the standard o
perator denoted $F$ in this context, mapping $u \mapsto \hat u$). We prove the s
tatement by **contrapositive**.

The contrapositive of the statement is:

> If $\|u\|_{L^2} = 0$, then it is **not** the case that $F(u) < 0$ almost every
where.

**Step 1.** Suppose $\|u\|_{L^2} = 0$. By the definiteness of the $L^2$ norm, th
is holds if and only if $u = 0$ almost everywhere in $\mathbb{R}^3$.

**Step 2.** The Fourier transform $F$ is a **linear** operator. Hence
$$F(u) = F(0) = 0 \quad \text{everywhere.}$$
(Here we use the convention $F(0) \equiv 0$, which holds for the Fourier transfo
rm since the integral $\int 0 \cdot e^{-i\xi\cdot x}\,dx = 0$ for every $\xi$; a
nd by $L^2$-continuity the same holds for the extension to all of $L^2$.)

**Step 3.** Since $F(u) \equiv 0$, the set $\{x \in \mathbb{R}^3 : F(u)(x) < 0\}
$ is **empty**, hence has measure zero. Therefore the assertion "$F(u) < 0$ almo
st everywhere" is **false**.

**Step 4.** We have shown: $\|u\|_{L^2} = 0 \Rightarrow \neg\big(F(u) < 0 \text{
 a.e.}\big)$. This is exactly the contrapositive of the original statement. Ther
efore the original statement holds:

$$F(u) < 0 \text{ a.e.} \;\Longrightarrow\; \|u\|_{L^2} > 0.$$

**Remark.** The key point is purely structural: the hypothesis $F(u) < 0$ a.e. f
orces $F(u)$ to be nontrivial, which (by linearity and injectivity of the Fourie
r transform on $L^2$) forces $u$ to be nontrivial, i.e. $\|u\|_{L^2} > 0$. The z
ero function is excluded because $F(0) = 0 \not< 0$.
