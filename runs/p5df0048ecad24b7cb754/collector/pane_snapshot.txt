The Lebesgue measure of the set is **1**.

## Proof

Let
$$A = \{x \in (0,1) : \text{the decimal expansion of } x \text{ contains a block
 of 100 consecutive 4s}\},$$
and let $B = (0,1)\setminus A$ be its complement.

**Step 1: Reduction to digit sequences.** The set of real numbers in $(0,1)$ wit
h a non-unique decimal expansion (those eventually ending in all 0s or all 9s) i
s countable—hence of Lebesgue measure zero—so we may work with the unique non-te
rminating decimal expansion. Under Lebesgue measure on $(0,1)$, the decimal digi
ts $d_1, d_2, d_3, \ldots$ are independent and uniformly distributed on $\{0,1,\
ldots,9\}$: the set on which the first $n$ digits equal a prescribed sequence $(
a_1,\ldots,a_n)$ is an interval of length $10^{-n}$, and independence follows fr
om the product structure.

**Step 2: Upper bound on the complement.** For each $n \geq 1$, define
$$B_n = \{x \in (0,1) : \text{no run of 100 consecutive 4s appears among } d_1,\
ldots,d_n\}.$$
Since $B \subseteq B_n$ for every $n$ (no run anywhere implies no run in the fir
st $n$ digits), we have $m(B) \leq m(B_n)$ for all $n$.

Now partition the first $n$ digit positions into $\lfloor n/100 \rfloor$ disjoin
t, consecutive blocks of 100 digits:
$$\underbrace{d_1\cdots d_{100}}_{\text{block 1}},\; \underbrace{d_{101}\cdots d
_{200}}_{\text{block 2}},\; \ldots$$
If $x \in B_n$, then in particular **none** of these $\lfloor n/100\rfloor$ bloc
ks can consist entirely of 4s (since such a block would itself be a run of 100 c
onsecutive 4s). Therefore
$$B_n \subseteq \{x : \text{none of the } \lfloor n/100\rfloor \text{ disjoint b
locks is all 4s}\}.$$

By independence of the digit blocks, each block is all-4s with probability $10^{
-100}$, so
$$m\!\left(\{x : \text{none of the } \lfloor n/100\rfloor \text{ blocks is all 4
s}\}\right) = \left(1 - 10^{-100}\right)^{\lfloor n/100\rfloor}.$$

Hence
$$m(B) \leq m(B_n) \leq \left(1 - 10^{-100}\right)^{\lfloor n/100\rfloor}.$$

**Step 3: Limit.** Since $0 < 1 - 10^{-100} < 1$ and $\lfloor n/100\rfloor \to \
infty$ as $n \to \infty$,
$$\left(1 - 10^{-100}\right)^{\lfloor n/100\rfloor} \longrightarrow 0.$$
Therefore $m(B) = 0$.

**Step 4: Conclusion.** Since $A$ and $B$ partition $(0,1)$ up to a null set,
$$m(A) = m\big((0,1)\big) - m(B) = 1 - 0 = 1.$$

The Lebesgue measure of the set of numbers in $(0,1)$ whose decimal expansion co
ntains one hundred consecutive 4s is $\boxed{1}$.
