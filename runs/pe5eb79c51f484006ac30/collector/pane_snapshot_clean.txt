## Solution

**Setting up coordinates.** Place the pumping station A at the origin, with the
angle bisector ℓ along the x-axis. Let the half-angle between the pipes be θ, so
:
- **Pipe AC** lies along direction (cos θ, sin θ), with C = c(cos θ, sin θ) for
some length c = AC.
- **Pipe AB** lies along direction (cos θ, −sin θ), with B = 21(cos θ, −sin θ) s
ince AB = 21.

**Midpoint M of BC:**
$$M = \frac{B+C}{2} = \left(\frac{(21+c)\cos\theta}{2},\;\frac{(c-21)\sin\theta}
{2}\right)$$

**The fiber-optic cable** passes through M and is parallel to ℓ (the x-axis), so
 it is the horizontal line:
$$y = \frac{(c-21)\sin\theta}{2}$$

**Finding E (on line AC):** A point on AC is t(cos θ, sin θ), with y = t sin θ.
Setting equal:
$$t_E = \frac{c-21}{2}, \qquad AE = |t_E| = \frac{|c-21|}{2}$$

**Finding F (on line AB):** A point on AB is t(cos θ, −sin θ), with y = −t sin θ
. Setting equal:
$$t_F = \frac{21-c}{2}, \qquad AF = |t_F| = \frac{|c-21|}{2}$$

**Using AE = 1:**
$$\frac{|c-21|}{2} = 1 \implies |c-21| = 2 \implies c = 23 \text{ or } c = 19$$

**Computing EF:** Both E and F lie on the same horizontal line, so:
$$E = \left(\frac{c-21}{2}\cos\theta,\;\frac{c-21}{2}\sin\theta\right), \quad F
= \left(\frac{21-c}{2}\cos\theta,\;\frac{21-c}{2}\sin\theta\right)$$
$$EF = \left|\frac{c-21}{2}\cos\theta - \frac{21-c}{2}\cos\theta\right| = |c-21|
\cos\theta$$

**Using EF = √3:**
$$2\cos\theta = \sqrt{3} \implies \cos\theta = \frac{\sqrt{3}}{2},\quad \sin\the
ta = \frac{1}{2}, \quad \theta = 30°$$

The full angle ∠BAC = 2θ = 60°, which is acute. ✓

**Computing BC²:**
$$BC^2 = (21\cos\theta - c\cos\theta)^2 + (-21\sin\theta - c\sin\theta)^2 = (21-
c)^2\cos^2\theta + (21+c)^2\sin^2\theta$$
$$= \frac{3}{4}(21-c)^2 + \frac{1}{4}(21+c)^2$$

**Case 1: c = 23:**
$$BC^2 = \frac{3}{4}(−2)^2 + \frac{1}{4}(44)^2 = 3 + 484 = 487 \implies BC = \sq
rt{487}$$

**Case 2: c = 19:**
$$BC^2 = \frac{3}{4}(2)^2 + \frac{1}{4}(40)^2 = 3 + 400 = 403 \implies BC = \sqr
t{403}$$

**Sum of all possible values:**
$$BC = \sqrt{487} + \sqrt{403}$$

Both 487 and 403 are square-free (487 is prime; 403 = 13 × 31), so this is alrea
dy in the form √a + √b with a = 487, b = 403.

$$a + b = 487 + 403 = \boxed{890}$$
