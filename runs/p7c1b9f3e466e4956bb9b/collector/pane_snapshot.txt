## Solution

We solve the nonhomogeneous wave equation on $(0,\pi)$ with homogeneous Dirichle
t boundary conditions using eigenfunction expansion.

### Step 1: Eigenfunction basis

The eigenfunctions of $-\partial_{xx}$ on $(0,\pi)$ with $u(0,t)=u(\pi,t)=0$ are
 $\{\sin(nx)\}_{n=1}^{\infty}$, with eigenvalues $n^2$. We expand

$$u(x,t) = \sum_{n=1}^{\infty} T_n(t)\sin(nx).$$

### Step 2: Project the forcing

The source term $\sin x\,\sin t$ is already a single eigenfunction: it equals $\
sin(1\cdot x)\cdot\sin t$, so its Fourier sine coefficients are

$$f_1(t) = \sin t, \qquad f_n(t) = 0 \;\;(n\neq 1).$$

### Step 3: Project the initial data

From $u(x,0)=0$: $\;T_n(0)=0$ for all $n$.

From $u_t(x,0)=\sin 3x$: $\;T_n'(0) = 0$ for $n\neq 3$, and $T_3'(0)=1$.

### Step 4: Decoupled ODEs

Substituting into $u_{tt}=u_{xx}+\sin x\sin t$ gives, for each $n$,

$$T_n''(t) + n^2 T_n(t) = f_n(t).$$

- **$n=1$ (forced, resonant):** $T_1'' + T_1 = \sin t$, with $T_1(0)=0$, $T_1'(0
)=0$.
- **$n=3$ (free):** $T_3'' + 9T_3 = 0$, with $T_3(0)=0$, $T_3'(0)=1$.
- **$n\neq 1,3$:** $T_n''+n^2 T_n = 0$ with zero data, so $T_n\equiv 0$.

### Step 5: Solve the $n=1$ ODE (resonance)

The homogeneous solution is $A\cos t + B\sin t$. Since the forcing $\sin t$ matc
hes the homogeneous frequency, we seek a particular solution of the form $T_p =
t(C\cos t + D\sin t)$. A standard computation gives

$$T_p(t) = -\tfrac{t}{2}\cos t, \quad\text{since}\quad T_p''+T_p = \sin t.$$

Thus $T_1(t) = A\cos t + B\sin t - \tfrac{t}{2}\cos t$.

- $T_1(0) = A = 0$.
- $T_1'(t) = -A\sin t + B\cos t - \tfrac{1}{2}\cos t + \tfrac{t}{2}\sin t$, so $
T_1'(0) = B - \tfrac{1}{2} = 0 \Rightarrow B = \tfrac{1}{2}$.

Hence

$$T_1(t) = \tfrac{1}{2}\sin t - \tfrac{t}{2}\cos t.$$

### Step 6: Solve the $n=3$ ODE

$T_3(t) = A\cos 3t + B\sin 3t$. From $T_3(0)=0$: $A=0$. From $T_3'(0)=3B=1$: $B=
\tfrac{1}{3}$. Thus

$$T_3(t) = \tfrac{1}{3}\sin 3t.$$

### Step 7: Assemble and verify

$$\boxed{\,u(x,t) = \left(\tfrac{1}{2}\sin t - \tfrac{t}{2}\cos t\right)\sin x \
;+\; \tfrac{1}{3}\sin 3t\,\sin 3x\,}$$

**Verification.**

- *Boundary conditions:* Each term contains a factor $\sin(nx)$ with $n\in\{1,3\
}$, so $u(0,t)=u(\pi,t)=0$. ✓
- *Initial displacement:* $u(x,0) = (0-0)\sin x + 0\cdot\sin 3x = 0$. ✓
- *Initial velocity:* $u_t(x,0) = \big(\tfrac{1}{2}\cos 0 - \tfrac{1}{2}\cos 0 +
 0\big)\sin x + \tfrac{1}{3}\cdot 3\cos 0\,\sin 3x = \sin 3x$. ✓
- *PDE:* For the first term, $T_1''+T_1 = \sin t$ (checked above), so its contri
bution to $u_{tt}-u_{xx}$ is $\sin t\cdot\sin x$. For the second term, $T_3''+9T
_3=0$, so it contributes $0$. Thus $u_{tt}-u_{xx} = \sin x\sin t$. ✓

All conditions are satisfied.
