# Proof

## Part (a)

We use the pigeonhole principle. Set $N = 10^6$. Consider all $N^3 = 10^{18}$ va
lues
$$v_{a,b,c} = a + b\sqrt{2} + c\sqrt{3}, \qquad 0 \le a, b, c \le N-1.$$
These values all lie in the interval $[0,\; (N-1)(1+\sqrt{2}+\sqrt{3})] \subset
[0,\; N(1+\sqrt{2}+\sqrt{3})]$.

Divide this interval into $N^3 - 1 = 10^{18}-1$ subintervals of equal length
$$\frac{N(1+\sqrt{2}+\sqrt{3})}{N^3 - 1}.$$
Since there are $10^{18}$ values and only $10^{18}-1$ subintervals, by the pigeo
nhole principle two distinct triples $(a_1,b_1,c_1) \ne (a_2,b_2,c_2)$ yield val
ues in the same subinterval. Set
$$a = a_1 - a_2,\quad b = b_1 - b_2,\quad c = c_1 - c_2.$$
Then $(a,b,c) \ne (0,0,0)$, each of $|a|,|b|,|c| \le N-1 < 10^6$, and
$$|a + b\sqrt{2} + c\sqrt{3}| < \frac{N(1+\sqrt{2}+\sqrt{3})}{N^3-1} < \frac{4.1
5 \times 10^6}{10^{18}-1} < 4.15 \times 10^{-12} < 10^{-11}.$$
This completes part (a). $\square$

## Part (b)

Let $a, b, c$ be integers, not all zero, with $|a|,|b|,|c| < 10^6$. Set $\alpha
= a + b\sqrt{2} + c\sqrt{3}$, which is a nonzero algebraic integer in the field
$\mathbb{Q}(\sqrt{2},\sqrt{3})$ of degree $4$ over $\mathbb{Q}$.

The four Galois conjugates of $\alpha$ are:
$$\alpha_1 = a + b\sqrt{2} + c\sqrt{3},\quad \alpha_2 = a - b\sqrt{2} + c\sqrt{3
},\quad \alpha_3 = a + b\sqrt{2} - c\sqrt{3},\quad \alpha_4 = a - b\sqrt{2} - c\
sqrt{3}.$$

The **norm** $N(\alpha) = \alpha_1 \alpha_2 \alpha_3 \alpha_4$ is a nonzero rati
onal integer (it is fixed by the Galois group and is an algebraic integer). Sinc
e $\alpha \ne 0$, we have $|N(\alpha)| \ge 1$.

**Upper bound on the conjugates.** For each $i = 2, 3, 4$:
$$|\alpha_i| \le |a| + |b|\sqrt{2} + |c|\sqrt{3} < 10^6(1 + \sqrt{2} + \sqrt{3})
 < 4.15 \times 10^6.$$

**Lower bound on $\alpha_1$.** Since $|N(\alpha)| = |\alpha_1|\cdot|\alpha_2|\cd
ot|\alpha_3|\cdot|\alpha_4| \ge 1$, we get
$$|\alpha_1| \ge \frac{1}{|\alpha_2|\,|\alpha_3|\,|\alpha_4|} > \frac{1}{(4.15 \
times 10^6)^3}.$$

Computing:
$$(4.15 \times 10^6)^3 = 4.15^3 \times 10^{18} < 72 \times 10^{18} = 7.2 \times
10^{19}.$$

Therefore
$$|a + b\sqrt{2} + c\sqrt{3}| = |\alpha_1| > \frac{1}{7.2 \times 10^{19}} \appro
x 1.39 \times 10^{-20} > 10^{-21}.$$

This completes part (b). $\square$
