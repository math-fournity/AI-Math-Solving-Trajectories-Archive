# Solution

## Problem

Determine the fourth-last digit of $N = 3^{3^{3^{3^{3^3}}}}$ (a power tower of s
ix 3s).

## Setup

The fourth-last digit is the thousands digit, so I need $N \bmod 10000$. Since $
10000 = 16 \times 625$ with $\gcd(16,625)=1$, I compute $N \bmod 16$ and $N \bmo
d 625$ separately and combine via CRT.

Define the tower levels:
- $a_1 = 3,\ a_2 = 3^3 = 27,\ a_3 = 3^{27},\ a_4 = 3^{3^{27}},\ a_5 = 3^{3^{3^{2
7}}},\ a_6 = N = 3^{a_5}$.

## Step 1: $N \bmod 16$

The order of $3$ modulo $16$ is $4$ (since $3^4 = 81 \equiv 1$). I need $a_5 \bm
od 4$. Since $a_5 = 3^{a_4}$ is an odd power of $3$, $a_5 \equiv 3 \pmod{4}$. Th
erefore
$$N \equiv 3^3 = 27 \equiv 11 \pmod{16}.$$

## Step 2: $N \bmod 625$

The order of $3$ modulo $625$ is $500$ (verified: $\operatorname{ord}_5(3)=4$, $
\operatorname{ord}_{25}(3)=20$, $\operatorname{ord}_{125}(3)=100$, and $3^{100}\
equiv 126\not\equiv 1\pmod{625}$, so $\operatorname{ord}_{625}(3)=500$). I need
$a_5 \bmod 500$.

### Step 2a: $a_5 \bmod 500$ via CRT ($500 = 4 \times 125$)

- $a_5 \bmod 4 = 3$ (odd power of $3$).
- $a_5 \bmod 125$: $\operatorname{ord}_{125}(3)=100$, so I need $a_4 \bmod 100$.

### Step 2b: $a_4 \bmod 100$ via CRT ($100 = 4 \times 25$)

- $a_4 \bmod 4 = 3$.
- $a_4 \bmod 25$: $\operatorname{ord}_{25}(3)=20$, so I need $a_3 \bmod 20$.

### Step 2c: $a_3 \bmod 20$ via CRT ($20 = 4 \times 5$)

$a_3 = 3^{27}$.
- $a_3 \bmod 4 = 3$ (odd).
- $a_3 \bmod 5$: $\operatorname{ord}_5(3)=4$, $27 \bmod 4 = 3$, so $a_3 \equiv 3
^3 = 27 \equiv 2 \pmod{5}$.

CRT: $\equiv 3\pmod{4},\ \equiv 2\pmod{5}$ gives $a_3 \equiv 7 \pmod{20}$.

### Step 2d: Back to $a_4 \bmod 25$

$a_4 \equiv 3^7 \pmod{25}$. $3^7 = 2187 = 25\times 87 + 12$, so $a_4 \equiv 12 \
pmod{25}$.

### Step 2e: Back to $a_4 \bmod 100$

CRT: $\equiv 3\pmod{4},\ \equiv 12\pmod{25}$. Candidates $12, 37, 62, 87$; check
ing mod 4: $12\equiv0, 37\equiv1, 62\equiv2, 87\equiv3$. So $a_4 \equiv 87 \pmod
{100}$.

### Step 2f: Back to $a_5 \bmod 125$

$a_5 \equiv 3^{87} \pmod{125}$. Computing by repeated squaring (mod 125):
$$3^1\equiv3,\ 3^2\equiv9,\ 3^4\equiv81,\ 3^8\equiv61,\ 3^{16}\equiv96,\ 3^{32}\
equiv91,\ 3^{64}\equiv31.$$
$87 = 64+16+4+2+1$, so
$$3^{87}\equiv 31\times96\times81\times9\times3 \equiv 101\times81\times9\times3
 \equiv 56\times9\times3 \equiv 4\times3 = 12 \pmod{125}.$$

### Step 2g: Back to $a_5 \bmod 500$

CRT: $\equiv 3\pmod{4},\ \equiv 12\pmod{125}$. Candidates $12,137,262,387$; mod
4: $12\equiv0,137\equiv1,262\equiv2,387\equiv3$. So $a_5 \equiv 387 \pmod{500}$.

### Step 2h: $N \bmod 625$

$N \equiv 3^{387} \pmod{625}$. Repeated squaring (mod 625):
$$3^1\equiv3,\ 3^2\equiv9,\ 3^4\equiv81,\ 3^8\equiv311,\ 3^{16}\equiv471,\ 3^{32
}\equiv591,\ 3^{64}\equiv531,\ 3^{128}\equiv86,\ 3^{256}\equiv521.$$
$387 = 256+128+2+1$, so
$$3^{387}\equiv 521\times86\times9\times3 \equiv 431\times9\times3 \equiv 129\ti
mes3 = 387 \pmod{625}.$$

## Step 3: CRT for $N \bmod 10000$

$N \equiv 11\pmod{16}$ and $N \equiv 387\pmod{625}$. Write $N = 625k + 387$. Sin
ce $625\equiv1\pmod{16}$ and $387\equiv3\pmod{16}$:
$$k + 3 \equiv 11 \pmod{16}\ \Longrightarrow\ k \equiv 8 \pmod{16}.$$
So $k = 16m+8$ and
$$N \equiv 625(16m+8)+387 = 10000m + 5387 \pmod{10000}.$$

## Verification

- $5387 \bmod 16 = 5387 - 336\times16 = 5387-5376 = 11$. ✓
- $5387 \bmod 625 = 5387 - 8\times625 = 5387-5000 = 387$. ✓

As a sanity check, applying the identical method to the smaller tower $3^{3^3}=3
^{27}=7625597484987$ (last four digits $4987$) recovers $4987$ exactly, confirmi
ng the method.

## Conclusion

The last four digits of $N$ are $\mathbf{5387}$, so the fourth-last digit (thous
ands digit) is

$$\boxed{5}$$
