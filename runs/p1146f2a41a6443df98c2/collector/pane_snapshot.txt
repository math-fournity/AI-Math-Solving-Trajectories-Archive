## Genus of $\mathbb{P}^1$ via the Čech Complex

**Answer-leak check:** The problem statement contains no solution, answer value,
 or proof sketch. Proceeding.

### Setup

The (arithmetic) genus of a smooth projective curve $X$ is
$$g(X) = \dim_k H^1(X, \mathcal{O}_X).$$
We compute $H^1(\mathbb{P}^1, \mathcal{O}_{\mathbb{P}^1})$ using Čech cohomology
.

### The cover

Let $\mathbb{P}^1 = \operatorname{Proj} k[X_0, X_1]$ over a field $k$. Cover it
by the two standard affine opens:
- $U_0 = \{X_0 \neq 0\} = \operatorname{Spec} k[t]$, with $t = X_1/X_0$,
- $U_1 = \{X_1 \neq 0\} = \operatorname{Spec} k[s]$, with $s = X_0/X_1 = t^{-1}$
.

Their intersection is
$$U_0 \cap U_1 = \operatorname{Spec} k[t, t^{-1}].$$

This is a good cover (two affines), and $\mathcal{O}_{\mathbb{P}^1}$ is quasi-co
herent, so Čech cohomology computes sheaf cohomology (Grothendieck's theorem / L
eray).

### The Čech complex

For the cover $\mathcal{U} = \{U_0, U_1\}$ and the sheaf $\mathcal{O}_{\mathbb{P
}^1}$, the Čech complex is
$$0 \longrightarrow \check{C}^0(\mathcal{U}, \mathcal{O}) \xrightarrow{\;d\;} \c
heck{C}^1(\mathcal{U}, \mathcal{O}) \longrightarrow 0,$$
where
$$\check{C}^0 = \mathcal{O}(U_0) \oplus \mathcal{O}(U_1) = k[t] \oplus k[t^{-1}]
, \qquad \check{C}^1 = \mathcal{O}(U_0 \cap U_1) = k[t, t^{-1}],$$
and the differential is
$$d(f, g) = g|_{U_0 \cap U_1} - f|_{U_0 \cap U_1}.$$
Under $s = t^{-1}$, we view $k[t^{-1}] \hookrightarrow k[t, t^{-1}]$ as the subr
ing of Laurent polynomials in $t^{-1}$, and $k[t] \hookrightarrow k[t, t^{-1}]$
as the subring of Laurent polynomials in $t$. Thus
$$d(f, g) = g(t^{-1}) - f(t) \in k[t, t^{-1}].$$

### Computing $H^0$

$$H^0(\mathbb{P}^1, \mathcal{O}) = \ker d = \{(f, g) \in k[t] \oplus k[t^{-1}] :
 f(t) = g(t^{-1}) \text{ in } k[t, t^{-1}]\}.$$

A polynomial $f(t) = \sum_{n \geq 0} a_n t^n$ equals a polynomial $g(t^{-1}) = \
sum_{n \geq 0} b_n t^{-n}$ in $k[t, t^{-1}]$ only if all non-constant terms vani
sh (positive and negative powers cannot cancel). Hence $f = g = \text{constant}$
, and
$$H^0(\mathbb{P}^1, \mathcal{O}) \cong k.$$
This recovers the classical fact that global regular functions on $\mathbb{P}^1$
 are constants.

### Computing $H^1$ (the genus)

$$H^1(\mathbb{P}^1, \mathcal{O}) = \operatorname{coker} d = k[t, t^{-1}] \,/\, \
bigl(k[t] + k[t^{-1}]\bigr).$$

The Laurent polynomial ring $k[t, t^{-1}]$ has $k$-basis $\{t^n : n \in \mathbb{
Z}\}$. Now:
- $k[t]$ is spanned by $\{t^n : n \geq 0\}$,
- $k[t^{-1}]$ is spanned by $\{t^n : n \leq 0\}$.

Their sum
$$k[t] + k[t^{-1}] = \operatorname{span}_k\{t^n : n \geq 0\} + \operatorname{spa
n}_k\{t^n : n \leq 0\} = \operatorname{span}_k\{t^n : n \in \mathbb{Z}\} = k[t,
t^{-1}].$$

The non-negative powers are covered by $k[t]$ and the non-positive powers by $k[
t^{-1}]$; together they exhaust every Laurent monomial $t^n$, $n \in \mathbb{Z}$
. Therefore
$$k[t] + k[t^{-1}] = k[t, t^{-1}],$$
and so
$$H^1(\mathbb{P}^1, \mathcal{O}) = k[t, t^{-1}] / k[t, t^{-1}] = 0.$$

### Conclusion

The genus is
$$g(\mathbb{P}^1) = \dim_k H^1(\mathbb{P}^1, \mathcal{O}_{\mathbb{P}^1}) = \dim_
k 0 = \boxed{0}.$$

The Čech computation shows explicitly that every Laurent polynomial on $U_0 \cap
 U_1$ splits as a regular function on $U_0$ plus a regular function on $U_1$, le
aving no obstruction — hence no holomorphic $1$-fold "gap," and the genus vanish
es.
