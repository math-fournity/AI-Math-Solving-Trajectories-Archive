## Part (a)

Let $\mu = \operatorname{cf}(\alpha) < \alpha$. Since $\mu$ is a regular cardina
l, it is a limit ordinal. Choose a continuous strictly increasing sequence $\lan
gle \alpha_i : i \le \mu \rangle$ with $\alpha_0 = 0$, $\alpha_\mu = \alpha$, an
d $\alpha_i < \alpha$ for all $i < \mu$ (each $\alpha_i < \alpha$ because $\mu$
is a limit ordinal, so $i < \mu \Rightarrow i+1 < \mu$).

**Define** $f: \alpha \setminus \{0\} \to \alpha$ as follows. For each $\beta \i
n \alpha \setminus \{0\}$, there is a unique $i < \mu$ with $\alpha_i < \beta \l
e \alpha_{i+1}$ (uniqueness and existence follow from continuity, strict monoton
icity, and cofinality with $\alpha_\mu = \alpha$). Set $f(\beta) = \alpha_i$.

**Regressive:** $f(\beta) = \alpha_i < \beta$ by construction. ✓

**Each fiber is bounded:** For $\xi < \alpha$:
- If $\xi = \alpha_i$ for some $i < \mu$: then $f^{-1}(\alpha_i) \subseteq (\alp
ha_i, \alpha_{i+1}]$, which is bounded by $\alpha_{i+1} < \alpha$ (since $i+1 <
\mu$, as $\mu$ is a limit ordinal).
- If $\xi \notin \{\alpha_i : i < \mu\}$: then $f^{-1}(\xi) = \emptyset$, which
is bounded.

Thus every fiber $f^{-1}(\xi)$ is bounded in $\alpha$. $\square$

## Part (b)

We work in the standard setting where $\alpha$ is a regular uncountable cardinal
 ($\operatorname{cf}(\alpha) = \alpha > \omega$), so that clubs and stationary s
ets are well-defined and Fodor's lemma applies. We prove the **stronger** statem
ent (Fodor's Lemma): there exist $\xi < \alpha$ and a stationary $S' \subseteq S
$ on which $f$ is **constant** (hence bounded).

**Setup.** Without loss of generality, $0 \notin S$ (removing a single point doe
s not affect stationarity). Suppose for contradiction that for every $\xi < \alp
ha$, the fiber $A_\xi := f^{-1}(\{\xi\}) \cap S$ is **non-stationary**. Then for

ap A_\xi = \emptyset$, i.e., $f(\beta) \neq \xi$ for all $\beta \in S \cap C_\xi
$.

**Diagonal intersection.** Define:
$$C = \triangle_{\xi < \alpha}\, C_\xi = \{\beta < \alpha : \forall \xi < \beta,
\; \beta \in C_\xi\}.$$

**Claim:** $C$ is a club.

*Closed:* Let $\langle \beta_j : j < \lambda \rangle$ be an increasing sequence
in $C$ with $\lambda < \alpha$ and $\beta = \sup_{j<\lambda} \beta_j$. For any $
\xi < \beta$, there exists $j$ with $\xi < \beta_j$. Then $\beta_j \in C_\xi$. F
or all $j' \ge j$, we have $\xi < \beta_j \le \beta_{j'}$, so $\beta_{j'} \in C_
\xi$. Since $C_\xi$ is closed, $\beta = \sup_{j' \ge j} \beta_{j'} \in C_\xi$. T
his holds for all $\xi < \beta$, so $\beta \in C$.

*Unbounded:* Given $\gamma < \alpha$, build an increasing $\omega$-sequence $\la
ngle \beta_n : n < \omega \rangle$. Set $\beta_0 > \gamma$. Having chosen $\beta
_n$, the set $\bigcap_{\xi < \beta_n} C_\xi$ is an intersection of $|\beta_n| <
\alpha$ many clubs; since $\alpha$ is regular, this is a club, so choose $\beta_
{n+1} > \beta_n$ in this intersection. Let $\beta = \sup_n \beta_n$. Since $\ope
ratorname{cf}(\alpha) = \alpha > \omega$, we have $\beta < \alpha$. For any $\xi

d by closure $\beta \in C_\xi$. Thus $\beta \in C$ and $\beta > \gamma$.

**Contradiction.** Since $C$ is a club and $S$ is stationary, $S \cap C \neq \em
ptyset$. Let $\beta \in S \cap C$. Then for every $\xi < \beta$, $\beta \in C_\x
i$, so $f(\beta) \neq \xi$. But $f$ is regressive, so $f(\beta) < \beta$, meanin

Therefore, some $A_{\xi_0} = f^{-1}(\{\xi_0\}) \cap S$ is stationary. Setting $S
' = A_{\xi_0}$, the function $f$ is constant (equal to $\xi_0$) on $S'$, hence b
ounded. $\square$
