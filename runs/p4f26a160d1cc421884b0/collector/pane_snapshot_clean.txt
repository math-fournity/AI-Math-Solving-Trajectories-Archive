## 解法

**建立坐标系。** 设 $M$ 为原点，$AB$ 沿 $x$ 轴。设 $A = (-c, 0)$，$B = (c, 0)$，
则 $AB = 2c$，$M = (0,0)$。

由于 $AD = BD$，点 $D$ 在 $AB$ 的垂直平分线上，即 $y$ 轴上。设 $D = (0, d)$。由
于 $AB \parallel CD$，点 $C$ 的 $y$ 坐标为 $d$。为使 $ABCD$ 构成不自交的梯形，取
 $C = (25, d)$（因为 $CD = 25$）。

**验证约束条件：**
- $AD = \sqrt{c^2 + d^2} = BD$ ✓ （自动满足）
- $BC = \sqrt{(25-c)^2 + d^2} = 27$，故 $(25-c)^2 + d^2 = 729$。

**求 $\triangle BCD$ 的外接圆。** 设圆方程为 $x^2 + y^2 + ex + fy + g = 0$。代入
 $B, C, D$：

- $B(c,0)$：$c^2 + ec + g = 0$
- $D(0,d)$：$d^2 + fd + g = 0$
- $C(25,d)$：$625 + d^2 + 25e + fd + g = 0$

由 $C - D$ 得 $e = -25$；由 $B$ 得 $g = 25c - c^2$；由 $D$ 得 $f = \frac{c^2 - 2
5c - d^2}{d}$。

**利用圆幂定理。** 直线 $AB$（$y=0$）与圆的交点：$x^2 - 25x + (25c - c^2) = 0$，
一根为 $x = c$（点 $B$），另一根为 $x = 25 - c$（点 $Q$）。

点 $A(-c, 0)$ 关于外接圆的幂：
$$\text{pow}(A) = \overrightarrow{AB} \cdot \overrightarrow{AQ} = 2c \cdot 25 =
50c.$$

直线 $AC$ 与圆交于 $C$ 和 $P$，故 $AP \cdot AC = 50c$。代入 $AP = 10$：
$$AC = 5c, \quad \text{即 } AC^2 = 25c^2.$$

**联立方程求解 $c$：**
$$AC^2 = (25+c)^2 + d^2 = 25c^2, \qquad BC^2 = (25-c)^2 + d^2 = 729.$$

两式相减：$(25+c)^2 - (25-c)^2 = 25c^2 - 729$，即 $100c = 25c^2 - 729$，得：
$$25c^2 - 100c - 729 = 0 \implies c = \frac{10 + \sqrt{829}}{5} \quad (\text{取
正根}).$$

由此 $c^2 = 4c + \frac{729}{25}$，$d^2 = 104 + 50c - c^2 = \frac{1871}{25} + 46c
$。

**计算 $MP$。** 参数 $t = \frac{AP}{AC} = \frac{2}{c}$，点 $P = A + t(C - A)$：
$$P = \left(\frac{50 + 2c - c^2}{c},\; \frac{2d}{c}\right).$$

设 $w = 50 + 2c - c^2 = \frac{521}{25} - 2c$，则：
$$MP^2 = \frac{w^2 + 4d^2}{c^2}.$$

展开（利用 $c^2 = 4c + \frac{729}{25}$ 和 $d^2 = \frac{1871}{25} + 46c$）：
$$w^2 + 4d^2 = \frac{531441 + 72900c}{625}, \qquad c^2 = \frac{100c + 729}{25}.$
$

因此：
$$MP^2 = \frac{531441 + 72900c}{625 \cdot \frac{100c+729}{25}} = \frac{25(531441
 + 72900c)}{625(100c + 729)} = \frac{531441 + 72900c}{25(100c + 729)}.$$

验证分子与分母的关系：
$$729 \cdot (100c + 729) = 72900c + 531441. \quad \checkmark$$

故 $MP^2 = \frac{729}{25}$，即 $MP = \frac{27}{5}$。

**验证 $P$ 在 $A$ 与 $C$ 之间：** $t = \frac{2}{c} \approx 0.258 \in (0,1)$ ✓

因此 $a = 27$，$b = 5$（互素），$100a + b = \boxed{2705}$。
