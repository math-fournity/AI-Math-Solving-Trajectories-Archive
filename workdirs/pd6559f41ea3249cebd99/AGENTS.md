# Problem

A logistics manager at a distribution center is comparing two different delivery systems for processing a batch of identical $x$ inventory units, where $x$ must be a positive integer.

In System A, items are packed into large crates that hold exactly 20 units each. Any units that do not fill a complete crate are set aside, and the manager only records the total number of fully completed crates, calculated as $\lfloor x/20 \rfloor$.

In System B, items are packed into smaller crates that hold exactly 17 units each. Similarly, any partial crates are ignored, and only the number of fully completed crates, $\lfloor x/17 \rfloor$, is recorded.

The manager notices that for certain shipment sizes, both systems result in the exact same number of completed crates being recorded. For how many different positive integer values of $x$ is the number of completed crates in System A equal to the number of completed crates in System B?
