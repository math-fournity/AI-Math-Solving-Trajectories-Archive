## Proof

**Example.** Let $c$ be the unique real number in $(1,2)$ satisfying
$$c^{c}=2.$$
Equivalently, $c = e^{W(\ln 2)} = \dfrac{\ln 2}{W(\ln 2)}$, where $W$ is the Lam
bert $W$-function.

**Existence and uniqueness of $c$.** The function $f(x)=x^{x}$ is continuous on
$(1,\infty)$ with
$$f'(x)=x^{x}(\ln x+1)>0 \quad\text{for } x>1,$$
so $f$ is strictly increasing on $(1,\infty)$. Since $f(1)=1<2<4=f(2)$, the Inte
rmediate Value Theorem gives a unique $c\in(1,2)$ with $c^{c}=2$. In particular
$c\neq 0,1$.

**Claim.** $c$ is transcendental.

Suppose, for contradiction, that $c$ is algebraic.

*Step 1: $c$ is not rational.* If $c=p/q$ with $p,q\in\mathbb{Z}_{>0}$ and $\gcd
(p,q)=1$, then $c^{c}=2$ gives
$$\left(\frac{p}{q}\right)^{p/q}=2 \;\Longrightarrow\; \left(\frac{p}{q}\right)^
{p}=2^{q} \;\Longrightarrow\; p^{p}=2^{q}\,q^{p}.$$
Since $\gcd(p,q)=1$, we have $\gcd(p^{p},q^{p})=1$, so $q^{p}\mid p^{p}$ forces
$q^{p}=1$, hence $q=1$. Then $c=p$ is a positive integer satisfying $p^{p}=2$, w
hich has no solution ($1^{1}=1$, $2^{2}=4$). Contradiction. Hence $c\notin\mathb
b{Q}$.

*Step 2: Apply Gelfond–Schneider.* Since $c$ is algebraic and not rational, $c$
is an **algebraic irrational**. Also $c\neq 0,1$. The Gelfond–Schneider theorem
states: if $a$ is algebraic with $a\neq 0,1$ and $b$ is an algebraic irrational,
 then $a^{b}$ is transcendental.

Taking $a=c$ and $b=c$, we conclude that $c^{c}$ is transcendental. But by const
ruction $c^{c}=2$, which is algebraic. This is a contradiction.

Therefore the assumption that $c$ is algebraic is false; **$c$ is transcendental
**.

**Conclusion.** There exists a known transcendental number $c$ such that $c^{c}$
 is algebraic. An explicit example is
$$\boxed{\,c = e^{W(\ln 2)}\,}\quad\text{(the unique real solution of } x^{x}=2
\text{ in } (1,2)\text{)},$$
which is transcendental and satisfies $c^{c}=2\in\overline{\mathbb{Q}}$.
