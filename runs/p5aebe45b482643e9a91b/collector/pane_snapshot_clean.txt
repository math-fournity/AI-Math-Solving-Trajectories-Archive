Looking at this problem, I need to find ∠OPQ where O is the circumcenter, P is t
he midpoint of AO, and Q is the midpoint of BC, given that ∠ABC = 4∠OPQ and ∠ACB
 = 6∠OPQ.

## Proof

Let θ = ∠OPQ. Then ∠ABC = 4θ, ∠ACB = 6θ, and ∠BAC = π − 10θ.

**Coordinate setup.** Place the circumcenter O at the origin with circumradius R
 = 1. Set:
- A = (1, 0)
- B = (cos 2C, sin 2C)
- C = (cos 2B, −sin 2B)

where A, B, C denote the triangle's angles. One verifies that the inscribed angl
es are correct: the arc BC not containing A has measure 2A, giving ∠BAC = A, and
 similarly for the other vertices.

**Key points.** Since P is the midpoint of AO:
$$P = \left(\tfrac{1}{2},\, 0\right).$$

Since Q is the midpoint of BC, using sum-to-product formulas:
$$\cos 2C + \cos 2B = -2\cos A\cos(C-B), \quad \sin 2C - \sin 2B = -2\cos A\sin(
C-B),$$
so
$$Q = \left(-\cos A\cos(C-B),\; -\cos A\sin(C-B)\right).$$

**Computing ∠OPQ.** With O = (0,0):
$$\vec{PO} = \left(-\tfrac{1}{2},\, 0\right), \quad \vec{PQ} = \left(-\cos A\cos
(C-B)-\tfrac{1}{2},\; -\cos A\sin(C-B)\right).$$

The cross product (z-component) and dot product give:
$$|\vec{PO}\times\vec{PQ}| = \tfrac{1}{2}|\cos A\sin(C-B)|, \quad \vec{PO}\cdot\
vec{PQ} = \tfrac{1}{2}\cos A\cos(C-B)+\tfrac{1}{4}.$$

Therefore:
$$\tan\theta = \frac{|\cos A\sin(C-B)|}{\cos A\cos(C-B)+\tfrac{1}{2}}.$$

**Substituting the angle relations.** With A = π − 10θ and C − B = 2θ:
$$\cos A = -\cos 10\theta, \quad \sin(C-B)=\sin 2\theta, \quad \cos(C-B)=\cos 2\
theta.$$

For the valid configuration (verified below), the signs work out so:
$$\tan\theta = \frac{\cos 10\theta\,\sin 2\theta}{\cos 10\theta\cos 2\theta - \t
frac{1}{2}}.$$

**Solving the equation.** Cross-multiplying:
$$\cos 10\theta\cos 2\theta\,\tan\theta - \tfrac{1}{2}\tan\theta = \cos 10\theta
\sin 2\theta.$$

Rearranging:
$$\cos 10\theta\bigl(\cos 2\theta\,\tan\theta - \sin 2\theta\bigr) = \tfrac{1}{2
}\tan\theta.$$

The key simplification:
$$\cos 2\theta\,\tan\theta - \sin 2\theta = \frac{\cos 2\theta\sin\theta - \sin
2\theta\cos\theta}{\cos\theta} = \frac{\sin(\theta - 2\theta)}{\cos\theta} = \fr
ac{-\sin\theta}{\cos\theta} = -\tan\theta.$$

Substituting back:
$$\cos 10\theta\,(-\tan\theta) = \tfrac{1}{2}\tan\theta.$$

Since θ > 0 (so tan θ ≠ 0), we divide both sides by tan θ:
$$-\cos 10\theta = \tfrac{1}{2} \quad\Longrightarrow\quad \cos 10\theta = -\tfra
c{1}{2}.$$

**Finding θ.** The equation cos 10θ = −1/2 gives 10θ = 2π/3 or 10θ = 4π/3 (withi
n one period). The constraint A = π − 10θ > 0 requires θ < π/10 = 18°, and B = 4
θ, C = 6θ must both be positive with B + C < π.

- 10θ = 2π/3 → θ = π/15 = 12°: gives A = 60°, B = 48°, C = 72°. ✓ (valid triangl
e)
- 10θ = 4π/3 → θ = 2π/15 = 24°: gives A = −60°. ✗ (invalid)

**Verification.** With θ = 12°, A = 60°, B = 48°, C = 72°:

Q = (−cos 60° cos 24°, −cos 60° sin 24°) = (−cos 24°/2, −sin 24°/2).

$$\tan(\angle OPQ) = \frac{\sin 24°/4}{(1+\cos 24°)/4} = \frac{\sin 24°}{1+\cos
24°} = \tan 12° = \tan\theta. \checkmark$$

This confirms ∠OPQ = θ = 12°.

$$\boxed{\angle OPQ = \frac{\pi}{15} = 12°}$$
