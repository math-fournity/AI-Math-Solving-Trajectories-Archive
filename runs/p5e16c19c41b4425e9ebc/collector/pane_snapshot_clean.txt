## Proof

**Setup and known identities.** Let $R$ be the circumradius of $\triangle ABC$,
with $\angle A = 60°$, so $B + C = 120°$. For the orthocenter $H$, the standard
vertex-to-orthocenter distances are:

$$BH = 2R\cos B, \qquad CH = 2R\cos C, \qquad AH = 2R\cos A = R.$$

The Euler–Otholae relation gives:

$$OH^{2} = R^{2}\!\left(1 - 8\cos A\cos B\cos C\right).$$

Since $\cos A = \tfrac{1}{2}$:

$$OH^{2} = R^{2}\!\left(1 - 4\cos B\cos C\right). \tag{1}$$

**Locating M and N.** Let $BM = CN = d$.

- $M$ lies on segment $BH$, so $0 \le d \le BH$, giving $MH = BH - d$.
- $N$ lies on the ray from $C$ through $H$ beyond $H$, so $CN = CH + HN$, giving
 $NH = d - CH$.

The existence of such $d$ requires $CH < d \le BH$, hence $BH > CH$, i.e. $\cos
B > \cos C$, i.e. $B < C$.

**The key simplification.** Adding:

$$MH + NH = (BH - d) + (d - CH) = BH - CH = 2R(\cos B - \cos C). \tag{2}$$

The parameter $d$ cancels — the sum depends only on the triangle, not on the tec
hnicians' positions.

**Parametrizing with $B+C = 120°$.** Write $B = 60° - t,\; C = 60° + t$ with $0
< t < 60°$ (so $B < C$ as required). Then:

$$\cos B - \cos C = \cos(60°-t) - \cos(60°+t) = 2\sin 60°\sin t = \sqrt{3}\,\sin
 t. \tag{3}$$

$$\cos B\cos C = \cos(60°-t)\cos(60°+t) = \cos^{2}60° - \sin^{2}t = \tfrac{1}{4}
 - \sin^{2}t. \tag{4}$$

Substituting (4) into (1):

$$OH^{2} = R^{2}\!\left(1 - 4\!\left(\tfrac{1}{4} - \sin^{2}t\right)\right) = R^
{2}\!\left(4\sin^{2}t\right), \qquad OH = 2R\sin t. \tag{5}$$

**Computing the ratio.** From (2), (3), (5):

$$\frac{MH + NH}{OH} = \frac{2R\sqrt{3}\,\sin t}{2R\sin t} = \sqrt{3}.$$

The $\sin t$ and $R$ cancel, leaving a value **independent of $t$** (hence indep
endent of the shape of the triangle, depending only on $\angle A = 60°$).

**Verification.** Take $B = 50°$, $C = 70°$: $\cos B - \cos C \approx 0.3008$; $
1 - 4\cos B\cos C \approx 0.1207$; ratio $= 2(0.3008)/\sqrt{0.1207} \approx 1.73
1 \approx \sqrt{3}$. ✓

$$\boxed{\dfrac{MH+NH}{OH}=\sqrt{3}}$$
