Looking at this problem, I need to find the ratio AB/BC for a kite ABCD with per
pendicular diagonals, right angles at B and D, where a specific parallelism cond
ition holds between contact points of two incircles.

## Setup and Coordinates

Place the kite with symmetry axis AC along the x-axis, A at the origin. Let the
diagonal intersection be O = (d, 0), with B = (d, b) and D = (d, −b) (symmetric
about AC), and C = (c, 0) with c > d. Set e = c − d > 0.

**Right angle condition at B:** BA · BC = 0 gives (−d)(−e) + (−b)(−b) = de + b².
.. wait, BA = (−d, −b), BC = (e, −b), so BA · BC = −de + b² = 0, hence **b² = de
**.

**Side lengths:** AB = √(d² + b²) = √(d² + de) = √(dc) =: p, and BC = √(e² + b²)
 = √(e² + de) = √(ec) =: q. The target ratio is **AB/BC = p/q = √(d/e)**.

## Incircle of ABCD

By symmetry the incenter I = (t, 0) lies on AC. Distance from I to line AB (equa
tion bx − dy = 0) is bt/p; distance to line BC (equation bx + ey = bc) is b(c−t)
/q. Setting equal:

t/p = (c−t)/q ⟹ **t = pc/(p+q)**, and inradius r = bc/(p+q).

**Touch point M on AB:** Projecting I onto line AB (direction (d,b)) gives param
eter s = td/p², so M = (td²/p², tdb/p²) = (cd²/(p(p+q)), cdb/(p(p+q))).

**Touch point N on BC:** Projecting I onto line BC gives parameter u = et/q² = t
/c, so N = (d + et/c, b(c−t)/c).

## Second Kite and Reflecting Pool ω

The similar kite AB'C'D' is a scaling of ABCD about A by factor k. Its incircle
is ω, centered at C = (c, 0). The scaled incenter is (kt, 0), so **kt = c**, giv
ing k = c/t = (p+q)/p = 1 + q/p.

**Verification:** The radius of ω is kr = (c/t)·bc/(p+q) = bc²/(t(p+q)) = bc²/(p
c) = bc/p, which equals the distance from C to line AB (= bc/p). ✓ So ω is indee
d tangent to the extended lines AB and AD.

## Touch Point N' on B'C'

Line B'C' has the same direction (e, −b) as BC, with equation bx + ey = kbc. The
 foot of perpendicular from C = (c, 0) to this line:

N' = (c, 0) − (bc(1−k)/q²)(b, e) = (c + b²c(k−1)/q², ebc(k−1)/q²).

Substituting k−1 = q/p, b² = de, q² = ec:

- x-component: c + de·c·(q/p)/(ec) = c + dq/p
- y-component: eb·c·(q/p)/(ec) = bq/p

So **N' = (c + dq/p, bq/p)**.

## The Parallelism Condition MN' ∥ AC

Since AC is along the x-axis, MN' ∥ AC requires M and N' to have equal y-coordin
ates:

cdb/(p(p+q)) = bq/p

Dividing by b and multiplying by p(p+q):

**cd = q(p+q)**

## Solving the Equation

Substitute c = d+e, p = √(dc), q = √(ec), and let r = d/e:

Left side: cd = (d+e)d = d² + de.

Right side: q(p+q) = √(ec)·(√(dc) + √(ec)) = c√(de) + ec = (d+e)√(de) + e(d+e).

So: d² + de = (d+e)√(de) + de + e², which simplifies to:

**d² = (d+e)√(de) + e²**

Setting d = re (r > 0) and dividing by e²:

r² = (r+1)√r + 1 ⟹ r² − 1 = (r+1)√r ⟹ (r−1)(r+1) = (r+1)√r

Since r > 0, divide by (r+1): **r − 1 = √r**.

Let u = √r: u² − u − 1 = 0, giving u = (1+√5)/2 (the golden ratio φ).

## Result

AB/BC = p/q = √(d/e) = √r = u = **(1+√5)/2**.

**Verification:** r = φ² = φ+1, so r−1 = φ = √r. ✓

The ratio of the length of boundary wall AB to the length of boundary wall BC is
 **(1+√5)/2**.
