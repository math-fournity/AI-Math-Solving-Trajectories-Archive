## Proof

**Yes**, such compact sets $C$ and $D$ exist.

Since $A \cup B = X$, the complements $X \setminus A$ and $X \setminus B$ are di
sjoint closed sets (disjoint because any $x$ in both would satisfy $x \notin A$
and $x \notin B$, contradicting $A \cup B = X$).

A compact Hausdorff space is normal, so by Urysohn's lemma there exists a contin
uous function $f : X \to [0,1]$ with
$$f|_{X \setminus A} = 0 \quad\text{and}\quad f|_{X \setminus B} = 1.$$

Define
$$C = f^{-1}\!\bigl([\tfrac{1}{2},\,1]\bigr), \qquad D = f^{-1}\!\bigl([0,\,\tfr
ac{1}{2}]\bigr).$$

**Compactness.** $C$ and $D$ are closed subsets of the compact space $X$, hence
compact.

**Containment $C \subseteq A$.** If $x \in X \setminus A$, then $f(x) = 0 < \tfr
ac{1}{2}$, so $x \notin C$. Thus $C \cap (X \setminus A) = \emptyset$, i.e. $C \
subseteq A$.

**Containment $D \subseteq B$.** If $x \in X \setminus B$, then $f(x) = 1 > \tfr
ac{1}{2}$, so $x \notin D$. Thus $D \cap (X \setminus B) = \emptyset$, i.e. $D \
subseteq B$.

**Covering.** $C \cup D = f^{-1}([\tfrac{1}{2},1]) \cup f^{-1}([0,\tfrac{1}{2}])
 = f^{-1}([0,1]) = X$.

Therefore $X$ is covered by the compact sets $C \subseteq A$ and $D \subseteq B$
. $\blacksquare$
