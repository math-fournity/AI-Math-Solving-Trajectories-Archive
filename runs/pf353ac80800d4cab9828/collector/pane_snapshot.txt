## Solution

Let $z = a+bi$ and $w = c+di$ with $a,b,c,d \in \mathbb{R}$. The two calibration
 equations are:

$$|z|^2 + zw + \bar{w} = 2+6i, \qquad |w|^2 + \overline{zw} + z = 2-4i.$$

**Expanding into real and imaginary parts.** Using $zw = (ac-bd)+(ad+bc)i$, $\ba
r w = c-di$, $\overline{zw}=(ac-bd)-(ad+bc)i$:

| | Real | Imaginary |
|---|---|---|
| Eq 1 | $a^2+b^2+ac-bd+c = 2$ | $ad+bc-d = 6$ |
| Eq 2 | $c^2+d^2+ac-bd+a = 2$ | $-(ad+bc)+b = -4$ |

**Step 1: Determining $b$ and $d$ in terms of $s=\operatorname{Im}(zw)$.**

From the imaginary parts: $ad+bc = d+6$ and $ad+bc = b+4$, giving $b-d=2$, i.e.
$b=d+2$. Setting $s = ad+bc = \operatorname{Im}(zw)$, we get $d = s-6$ and $b =
s-4$.

**Step 2: Reducing the real-part equations.** Let $r = ac-bd = \operatorname{Re}
(zw)$. Substituting $r = ac-(s-4)(s-6)$ into the two real equations and simplify
ing (using $(s-4)^2-(s-4)(s-6)=2s-8$ and $(s-6)^2-(s-4)(s-6)=-2s+12$):

$$a^2 + ac + c = 10 - 2s \tag{C'}$$
$$c^2 + ac + a = 2s - 10 \tag{D'}$$

**Adding (C') and (D'):** $a^2+c^2+2ac+a+c = 0$, i.e. $(a+c)^2+(a+c)=0$, so

$$a+c = 0 \quad\text{or}\quad a+c = -1.$$

**Step 3: Using the remaining constraint.** From $s = ad+bc = (a+c)s - 6a - 4c$
(substituting $b=s-4, d=s-6$):

$$(a+c)\,s - 6a - 4c = s. \tag{B}$$

**Case 1: $a+c=0$, so $c=-a$.** Equation (B) gives $-6a+4a = s$, so $a = -s/2$,
$c=s/2$. Substituting into (C'): $-a = s/2 = 10-2s$, yielding $s=4$. Thus $a=-2,
 c=2, b=0, d=-2$, giving

$$u_1 = zw = -4+4i.$$

**Case 2: $a+c=-1$, so $c=-1-a$.** Equation (B) gives $-s-6a+4+4a=s$, so $a=2-s$
, $c=s-3$. Substituting into (C'):

$$(2-s)^2+(2-s)(s-3)+(s-3) = -5+2s = 10-2s,$$

yielding $s=15/4$. Then $a=-7/4, c=3/4, b=-1/4, d=-9/4$, giving

$$u_2 = zw = -\tfrac{15}{8}+\tfrac{15}{4}i.$$

**Verification.** Both solutions satisfy the original equations (checked by dire
ct substitution: $|z_1|^2+u_1+\bar w_1 = 4+(-4+4i)+(2+2i)=2+6i$ ✓; $|w_1|^2+\bar
 u_1+z_1 = 8+(-4-4i)+(-2)=2-4i$ ✓; similarly for Case 2).

**Step 4: Computing the answer.** The set is $S = \{-4+4i,\; -\tfrac{15}{8}+\tfr
ac{15}{4}i\}$.

$$|u_1|^2 = 16+16 = 32,$$
$$|u_2|^2 = \tfrac{225}{64}+\tfrac{225}{16} = \tfrac{225+900}{64} = \tfrac{1125}
{64}.$$

$$\sum_{u\in S}|u|^2 = 32 + \frac{1125}{64} = \frac{2048+1125}{64} = \boxed{\fra
c{3173}{64}}.$$
