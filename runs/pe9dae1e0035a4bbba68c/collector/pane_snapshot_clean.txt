## Proof

**Answer: No, $A^*$ does not in general map $C_b(X^*)$ into itself.**

We construct an explicit counterexample.

### Setup

Let $X = \mathbb{N}$ equipped with the discrete metric $d(m,n) = \mathbf{1}_{m \
neq n}$. Then:

- **Complete:** Every Cauchy sequence is eventually constant, hence convergent.
- **Separable:** $\mathbb{N}$ is countable.
- **Non-compact:** An infinite discrete space is not compact.

So $X$ satisfies all hypotheses. We have $C_b(X) = C_b(\mathbb{N}) = \ell^\infty
(\mathbb{N})$.

The Alexandroff (one-point) compactification is $X^* = \mathbb{N} \cup \{\infty\
}$, where neighborhoods of $\infty$ are of the form $\{\infty\} \cup (\mathbb{N}
 \setminus F)$ for finite $F \subset \mathbb{N}$. Since $X^*$ is compact, $C_b(X
^*) = C(X^*)$, which is naturally isomorphic to the space $c$ of convergent real
 sequences (a sequence $(a_n)$ converging to $L$ corresponds to the function $f(
n) = a_n$, $f(\infty) = L$).

The larger space $C_b^*(X^*)$ consists of all $f: X^* \to \mathbb{R}$ with $f|_{
\mathbb{N}} \in \ell^\infty$, with no continuity requirement at $\infty$; this i
s isomorphic to $\ell^\infty \times \mathbb{R}$ (an arbitrary bounded sequence p
aired with an arbitrary value at $\infty$).

### The operator

Define $A: \ell^\infty \to \ell^\infty$ by
$$(Ax)_n = x_1 \quad \text{for all } n \in \mathbb{N}.$$
This is linear and bounded with $\|A\| = 1$, and it maps $\ell^\infty$ into $\el
l^\infty$ (constant sequences are bounded). So $A$ is a valid bounded linear ope
rator on $C_b(X)$.

### The counterexample

Define $f \in C_b(X^*) = C(X^*)$ by
$$f(1) = 1, \quad f(n) = 0 \text{ for } n \geq 2, \quad f(\infty) = 0.$$
The sequence $(f(n))_{n \geq 1} = (1, 0, 0, 0, \ldots)$ converges to $0 = f(\inf
ty)$, so $f$ is continuous at $\infty$, and clearly continuous at every isolated
 point of $\mathbb{N}$. Hence $f \in C_b(X^*)$.

Now compute $A^* f$. Let $g = f|_X = (1, 0, 0, \ldots) \in \ell^\infty$. Then:
$$(A^*f)(n) = A(g)(n) = g_1 = 1 \quad \text{for all } n \in \mathbb{N},$$
$$(A^*f)(\infty) = f(\infty) = 0.$$

So $A^*f$ restricted to $\mathbb{N}$ is the constant sequence $(1, 1, 1, \ldots)
$, which converges to $1$, but $(A^*f)(\infty) = 0$. Since
$$\lim_{n \to \infty} (A^*f)(n) = 1 \neq 0 = (A^*f)(\infty),$$
the function $A^*f$ is **not continuous at $\infty$**, and therefore $A^*f \noti
n C_b(X^*)$.

### Conclusion

We have exhibited a complete separable non-compact metric space $X = \mathbb{N}$
 (discrete), a bounded linear operator $A: C_b(X) \to C_b(X)$, and a function $f
 \in C_b(X^*)$ such that $A^*f \notin C_b(X^*)$. Therefore, **$A^*$ does not in
general map $C_b(X^*)$ into itself.**

The essential reason is that continuity at $\infty$ requires $\lim_{x \to \infty
} A(f|_X)(x) = f(\infty)$, which demands both that $A$ maps $C_0(X)$ into $C_0(X
)$ and that $A(\mathbf{1}) \to \mathbf{1}$ at infinity—conditions that an arbitr
ary bounded linear operator on $C_b(X)$ need not satisfy.
