## Step 1: Necessary condition on roots modulo primes

For any prime $p$ and residue $r \pmod{p}$: if $f(r) \equiv 0 \pmod{p}$, then fo
r all large $n \equiv r \pmod{p}$, we need $p \mid n^{n-1}-1$.

**Case $r = 0$:** Then $p \mid n$, so $n^{n-1} \equiv 0 \pmod{p}$, giving $n^{n-
1}-1 \equiv -1 \pmod{p}$. This is never divisible by $p$. So $f(0) \not\equiv 0
\pmod{p}$ for every prime $p$, forcing $f(0) = \pm 1$.

**Case $r \neq 0, r \neq 1$:** We need $r^{n-1} \equiv 1 \pmod{p}$ for all large
 $n \equiv r \pmod{p}$. Writing $n = r + kp$, by Fermat $r^{kp} \equiv r^k \pmod
{p}$, so we need $r^{r-1+k} \equiv 1 \pmod{p}$ for all large $k$. If $d = \text{
ord}_p(r)$, this requires $d \mid r-1+k$ for all large $k$, which is impossible
unless $d = 1$, i.e., $r \equiv 1 \pmod{p}$ — contradicting $r \neq 1$.

**Conclusion:** For every prime $p$, the only root of $f$ in $\mathbb{F}_p$ is $
x = 1$.

## Step 2: Form of $f$

Write $f(x) = (x-1)^j \cdot g(x)$ where $g(1) \neq 0$ and $j \geq 0$. Then $g$ h
as **no roots** in $\mathbb{F}_p$ for all sufficiently large primes $p$ (since $
g(1) \not\equiv 0 \pmod{p}$ for large $p$, and $1$ is the only allowed root of $
f$).

If $g$ is non-constant, let $g_i$ be an irreducible factor of degree $\geq 1$. B
y the Chebotarev density theorem, $g_i$ splits completely mod $p$ for a positive
 density of primes, giving roots in $\mathbb{F}_p$. For large enough such $p$, t
hese roots are $\neq 1$ (since $g(1) \not\equiv 0$). This contradicts our condit
ion.

So $g$ is constant. If $|g| \geq 2$, take a prime $p \mid g$; then $p \mid f(n)$

on. So $g = \pm 1$.

**Therefore $f(x) = \pm(x-1)^j$ for some $j \geq 0$.**

## Step 3: Determining which $j$ work

We need $(n-1)^j \mid n^{n-1}-1$ for all large $n$. Set $q = n-1$, so $n^{n-1}-1

By the binomial theorem:
$$(1+q)^q - 1 = q^2\left(1 + \binom{q}{2} + \binom{q}{3}q + \cdots\right)$$

**For odd primes $p \mid q$:** Since $p \mid q$ and $p$ is odd, every term in th
e parenthetical factor except $1$ is divisible by $p$ (as $\binom{q}{2} = q(q-1)
/2$ has $v_p \geq 1$, and higher terms have even more factors of $q$). So the fa
ctor is $\equiv 1 \pmod{p}$, giving:
$$v_p(n^{n-1}-1) = 2\,v_p(n-1)$$

For $(n-1)^j \mid n^{n-1}-1$, we need $j \cdot v_p(n-1) \leq 2\,v_p(n-1)$, i.e.,
 **$j \leq 2$**.

**Verification that $j = 0, 1, 2$ all work:**
- $j=0$: $f = \pm 1$, trivially divides everything. ✓
- $j=1$: $n-1 \mid n^{n-1}-1$ since $n \equiv 1 \pmod{n-1}$. ✓
