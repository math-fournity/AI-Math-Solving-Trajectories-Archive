## Proof

**Step 1: Integral Representation.** Rewrite the series as $S(x) = \sum_{k=1}^\i
nfty (-1)^k k^m (x/k)^k$. Using the identity $\frac{1}{k^k} = \frac{1}{(k-1)!}\i
nt_0^\infty t^{k-1} e^{-kt}\,dt$ (since $\int_0^\infty t^{k-1}e^{-kt}dt = (k-1)!
/k^k$), we get:

$$S(x) = \int_0^\infty \frac{1}{t}\sum_{k=1}^\infty k^m \frac{(-xte^{-t})^k}{(k-
1)!}\,dt$$

The interchange of sum and integral is justified by Fubini (absolute convergence
: $\sum k^m (x/k)^k < \infty$ for all $x$). Setting $u = -xte^{-t}$ and using $\
sum_{k=1}^\infty k^m \frac{u^k}{(k-1)!} = u\, P_m(u)\, e^u$, where $P_m$ is the
polynomial defined by $P_m(u)\,e^u = \sum_{j=0}^\infty (j+1)^m \frac{u^j}{j!}$,
we obtain:

$$S(x) = -x\int_0^\infty e^{-t - xte^{-t}}\, P_m(-xte^{-t})\,dt$$

**Step 2: Asymptotic Analysis.** The function $g(t) = te^{-t}$ increases on $(0,
1)$ (from $0$ to $1/e$) and decreases on $(1,\infty)$ (from $1/e$ to $0$). Subst
itute $s = xg(t)$ in each region.

*Part 1* ($t \in (0,1)$, $t = t_1(s)$ the smaller root): $ds = x(1-t)e^{-t}dt$,
giving

$$I_1(x) = -\int_0^{x/e} \frac{e^{-s}\,P_m(-s)}{1 - t_1(s)}\,ds$$

For fixed $s$ as $x\to\infty$: $t_1(s) \approx s/x \to 0$, so $\frac{1}{1-t_1(s)
} \to 1$. The integrand converges pointwise to $e^{-s}P_m(-s)$. For domination:
when $s \leq x/(2e)$, $t_1(s)$ is bounded away from $1$, so $\frac{1}{1-t_1(s)}
\leq C$ and the integrand is bounded by $C\,e^{-s}(1+s)^m$ (integrable). When $s
 > x/(2e)$, $e^{-s} \leq e^{-x/(2e)}$ makes the contribution exponentially small
. By dominated convergence:

$$I_1(x) \to -\int_0^\infty e^{-s}\,P_m(-s)\,ds$$

*Part 2* ($t \in (1,\infty)$, $t = t_2(s)$ the larger root):

$$I_2(x) = \int_0^{x/e} \frac{e^{-s}\,P_m(-s)}{1 - t_2(s)}\,ds$$

For fixed $s$: $t_2(s) \sim \ln(x/s) \to \infty$, so $\frac{1}{1-t_2(s)} \to 0$.
 The integrand converges pointwise to $0$, with the same type of domination boun
d. By dominated convergence: $I_2(x) \to 0$.

Therefore: $\lim_{x\to+\infty} S(x) = -\int_0^\infty e^{-s}\,P_m(-s)\,ds$.

**Step 3: Evaluating the Integral via Generating Functions.** Compute the expone
ntial generating function of $P_m$:

$$\sum_{m=0}^\infty P_m(u)\,\frac{t^m}{m!} = \sum_{m=0}^\infty \frac{t^m}{m!}\,e
^{-u}\sum_{j=0}^\infty (j+1)^m\frac{u^j}{j!} = e^{-u}\sum_{j=0}^\infty \frac{u^j
}{j!}\,e^{(j+1)t} = e^{t + u(e^t - 1)}$$

Now compute the generating function of the integrals:

$$\sum_{m=0}^\infty \frac{t^m}{m!}\int_0^\infty e^{-s}\,P_m(-s)\,ds = \int_0^\in
fty e^{-s}\,e^{t - s(e^t-1)}\,ds = e^t\int_0^\infty e^{-s\,e^t}\,ds = e^t \cdot
\frac{1}{e^t} = 1$$

Since the generating function is identically $1$, we read off the coefficients:

$$\int_0^\infty e^{-s}\,P_m(-s)\,ds = \begin{cases} 1 & m = 0 \\ 0 & m \geq 1 \e
nd{cases}$$

**Conclusion.** For $m > 1$ (indeed for all $m \geq 1$):

$$\lim_{x\to+\infty} \sum_{k=1}^\infty (-1)^k \frac{x^k}{k^{k-m}} = -\int_0^\inf
ty e^{-s}\,P_m(-s)\,ds = \boxed{0}$$
