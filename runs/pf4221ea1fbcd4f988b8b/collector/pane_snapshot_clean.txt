## Proof

Let the circle have $n$ digits total, with $o$ ones and $z$ zeros ($n = o + z$).
 For any arc $w$ of length $L$, we have $Z(w) + N(w) = L$.

**Step 1: The target length.** Since $Z$ and $N$ are both integers,
$$L := Z + N = \frac{1}{k}\sum_{j=1}^k \bigl(Z(w_j) + N(w_j)\bigr) = \frac{1}{k}
\sum_{j=1}^k |w_j|$$
is a non-negative integer (the average arc length). It suffices to find an arc o
f length $L$ with $N$ ones (then automatically $Z$ zeros, since $Z = L - N$).

**Step 2: Possible 1-counts for arcs of a fixed length.** For any length $\ell \
geq 0$, there are $n$ arcs of length $\ell$ (one starting at each position). The
 sum of their 1-counts over all $n$ starting positions equals $\ell \cdot o$ (ea
ch 1 in the circle is covered by exactly $\ell$ arcs), so the average 1-count is
 $\ell\, o / n$. By hypothesis, all 1-counts for arcs of the same length differ
by at most $1$. Since they are integers with average $\ell\, o/n$, every such 1-
count lies in $\bigl\{\lfloor \ell\, o/n \rfloor,\; \lceil \ell\, o/n \rceil\big
r\}$. Moreover, if $\ell\, o/n$ is not an integer, both values are achieved (the
 average being non-integral forces at least two distinct values); if $\ell\, o/n
$ is an integer, all arcs of length $\ell$ have 1-count exactly $\ell\, o/n$.

**Step 3: Decomposing each $N(w_j)$.** Let $L_j = |w_j|$ and write
$$\frac{L_j\, o}{n} = q_j + r_j, \qquad q_j = \left\lfloor \frac{L_j\, o}{n} \ri
ght\rfloor, \quad r_j \in [0,1).$$
By Step 2, $N(w_j) \in \{q_j,\; q_j + 1\}$. Write $N(w_j) = q_j + \varepsilon_j$
 with $\varepsilon_j \in \{0, 1\}$. Crucially, if $r_j = 0$ (i.e., $L_j\, o/n$ i
s an integer), then every arc of length $L_j$ has 1-count $q_j$, forcing $\varep
silon_j = 0$.

**Step 4: Relating $N$ to $Lo/n$.** We compute:
$$N = \frac{1}{k}\sum_{j=1}^k N(w_j) = \frac{1}{k}\sum_{j=1}^k q_j + \frac{1}{k}
\sum_{j=1}^k \varepsilon_j,$$
and
$$\frac{L\, o}{n} = \frac{o}{n}\cdot\frac{1}{k}\sum_{j=1}^k L_j = \frac{1}{k}\su
m_{j=1}^k \frac{L_j\, o}{n} = \frac{1}{k}\sum_{j=1}^k (q_j + r_j) = \frac{1}{k}\
sum_{j=1}^k q_j + \frac{1}{k}\sum_{j=1}^k r_j.$$

Subtracting:
$$N - \frac{L\, o}{n} = \frac{1}{k}\sum_{j=1}^k (\varepsilon_j - r_j).$$

**Step 5: Each summand lies in $(-1, 1)$.** For each $j$:
- If $\varepsilon_j = 0$: then $\varepsilon_j - r_j = -r_j \in (-1,\, 0]$.
- If $\varepsilon_j = 1$: then $r_j > 0$ (by the observation in Step 3), so $\va
repsilon_j - r_j = 1 - r_j \in (0,\, 1)$.

In either case, $\varepsilon_j - r_j \in (-1, 1)$. Averaging preserves this stri
ct bound:
$$\left|N - \frac{L\, o}{n}\right| < 1.$$

**Step 6: $N$ is an achievable 1-count for arcs of length $L$.** Since $N$ is an
 integer and $\left|N - Lo/n\right| < 1$, we have
$$N \in \left\{\left\lfloor \frac{L\, o}{n} \right\rfloor,\; \left\lceil \frac{L
\, o}{n} \right\rceil\right\}.$$

By Step 2, the 1-counts of arcs of length $L$ take exactly the values in this se
t (both values are achieved when they differ; when they coincide, every arc of l
ength $L$ has that 1-count). Therefore there exists an arc $w$ of length $L$ wit
h $N(w) = N$, and consequently $Z(w) = L - N = Z$.

$\blacksquare$
