## Proof

Setting $y = 1$: $f(f(x)^2) = x^3 f(x)$. (B)

Define $g(x) = f(x)^2/x$. Substituting $y \mapsto y/x$ in the original equation

$$f(g(x)\,y) = x^3 f(y) \quad \text{for all } x,y \in \mathbb{Q}^+. \tag{2}$$

Setting $y=1$ in (2): $f(g(x)) = x^3 f(1)$.

Now $g(c) = f(c)^2/c = f(1)^2/c = c/c = 1$ (using $f(c)=f(1)$). So $f(g(c)) = f(
1) = c^3 f(1)$, giving $c^3 = 1$, hence $c = 1$ and $f(1) = 1$.

**Step 2: Show the period group $P = \{1\}$.**

Let $P = \{p \in \mathbb{Q}^+ : f(py) = f(y) \text{ for all } y\}$. We have $1 \
in P$.

From (2) with $f(1)=1$: $f(g(x)) = x^3$ and $f(g(x)\,y) = x^3 f(y)$.

Applying (2) twice: $f(g(x_1)\,g(x_2)\,y) = x_1^3 f(g(x_2)\,y) = x_1^3 x_2^3 f(y
) = f(g(x_1 x_2)\,y)$.

So $f\!\left(\tfrac{g(x_1)g(x_2)}{g(x_1 x_2)}\,u\right) = f(u)$ for all $u$, mea
ning $\frac{g(x_1)g(x_2)}{g(x_1 x_2)} \in P$. Thus $\bar{g}: \mathbb{Q}^+ \to \m
athbb{Q}^+/P$ (sending $x$ to the coset of $g(x)$) is a **homomorphism**.

$\bar{g}$ is **injective**: if $\bar{g}(x) = \bar{g}(x')$, then $g(x)/g(x') \in
P$, so $f(g(x)) = f(g(x'))$, giving $x^3 = x'^3$, hence $x = x'$.

For $p \in P$: $g(px) = f(px)^2/(px) = f(x)^2/(px) = g(x)/p$, so $\bar{g}(px) =
\bar{g}(x) \cdot \bar{p}^{-1} = \bar{g}(x)$. By injectivity, $px = x$, so $p = 1

**Step 3: $g$ is multiplicative, hence $f$ is multiplicative.**

Since $P = \{1\}$, the relation $\frac{g(x_1)g(x_2)}{g(x_1 x_2)} \in P$ gives $g

Then $f(xy)^2/(xy) = g(xy) = g(x)g(y) = f(x)^2 f(y)^2/(xy)$, so $f(xy)^2 = f(x)^
2 f(y)^2$. Since $f > 0$, we get $f(xy) = f(x)\,f(y)$. So **$f$ is multiplicativ

**Step 4: Matrix equation and uniqueness.**

From (B) and multiplicativity: $f(f(x))^2 = f(f(x)^2) = x^3 f(x)$, i.e.,
$$f(f(x))^2 = x^3\,f(x). \tag{C}$$

Since $f$ is multiplicative with $f(1)=1$, it is determined by its values on pri

thbf{v}(x)$ for all $x$. Since valuation vectors span all finitely-supported int

$$2A^2 - A - 3I = 0. \tag{$\star$}$$

$$2B^2 - 5B = 0, \quad \text{i.e., } 2(B^2)_{r,q} = 5\,B_{r,q} \text{ for all pr

Each $(B^2)_{r,q} = \sum_p B_{r,p}\,B_{p,q}$ is a finite sum of integers (row $r

$$f(x) = \frac{1}{x} \quad \text{for all } x \in \mathbb{Q}^+.$$
