## Setup

The coefficients satisfy $a_1=1$, $a_{j+1}-a_j=k$ for $1\le j\le n-1$, and $a_{j
+1}-a_j=-k$ for $n\le j\le 2n-2$. This gives:
$$a_j = 1 + k\cdot\min(j-1,\, 2n-1-j).$$

So $p(x) = g(x) + k\cdot h(x)$ where:
$$g(x)=\sum_{j=1}^{2n-1}x^j = \frac{x(1-x^{2n-1})}{1-x}, \qquad h(x)=\sum_{j=1}^
{2n-1}\min(j-1,2n-1-j)\,x^j.$$

## Computing $h(x)$

Split at $j=n$: $h(x)=\sum_{j=1}^{n}(j-1)x^j + \sum_{j=n+1}^{2n-1}(2n-1-j)x^j$.

Using the standard formula $\sum_{i=0}^{m}ix^i = \frac{x-(m+1)x^{m+1}+mx^{m+2}}{
(1-x)^2}$ and a substitution $i=2n-1-j$ in the second sum, both pieces combine (
after careful algebra) to:

$$h(x) = \frac{x^2(1-x^{n-1})^2}{(1-x)^2}.$$

## Solving for $k$

Setting $p(-3)=0$: $k = -g(-3)/h(-3)$.

$$g(-3)=\frac{(-3)(1-(-3)^{2n-1})}{4}=\frac{-3(1+3^{2n-1})}{4}, \qquad h(-3)=\fr
ac{9(1-(-3)^{n-1})^2}{16}.$$

$$k_n = \frac{4(1+3^{2n-1})}{3(1-(-3)^{n-1})^2}.$$

Setting $t=3^{n-1}$ (so $3^{2n-1}=3t^2$):

- **$n$ even** ($n-1$ odd, $(-3)^{n-1}=-t$): $\displaystyle k_n=\frac{4(1+3t^2)}
{3(1+t)^2}$
- **$n$ odd** ($n-1$ even, $(-3)^{n-1}=t$): $\displaystyle k_n=\frac{4(1+3t^2)}{
3(1-t)^2}$

## Asymptotics and bounding

**Even $n$:** $k_n < 4$ since $1+3t^2 < 3(1+2t+t^2)=3+6t+3t^2$ iff $0<2+6t$. Als
o $k_n>3$ iff $3t^2-18t-5>0$ iff $t>3+\frac{4\sqrt6}{3}\approx 6.27$.

- $n=2$: $t=3$, $k=7/3\approx 2.33\le 3$ ✓
- $n\ge 4$: $t\ge 27>6.27$, so $3<k<4$ (excluded).

**Odd $n$:** $k_n>4$ since $1+3t^2>3(1-2t+t^2)=3-6t+3t^2$ iff $1>3-6t$ (true for
 $t>1/3$). Also $k_n<5$ iff $3t^2-30t+11>0$ iff $t>5+\frac{8\sqrt3}{3}\approx 9.
62$.

- $n=3$: $t=9<9.62$, so $k\ge 5$ possible. $k=\frac{4\cdot244}{3\cdot64}=\frac{6
1}{12}\approx 5.08\ge 5$ ✓
- $n\ge 5$: $t\ge 81>9.62$, so $4<k<5$ (excluded).
