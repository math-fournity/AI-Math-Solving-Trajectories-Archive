## Proof

**Step 1: Reduction to a constrained optimization.**

Since $P(0) = 1 \neq 0$, any real root $r$ satisfies $r \neq 0$. If $r$ is a rea
l root, then:
$$\sum_{i=1}^{n-1} a_i\, r^i = -(r^n + 1).$$

For a **fixed** $r \neq 0$, this is a linear constraint on $(a_1, \ldots, a_{n-1
})$. By the Cauchy–Schwarz inequality:
$$\left(\sum_{i=1}^{n-1} a_i^2\right)\left(\sum_{i=1}^{n-1} r^{2i}\right) \geq \
left(\sum_{i=1}^{n-1} a_i\, r^i\right)^2 = (r^n+1)^2,$$
so $\sum a_i^2 \geq \frac{(r^n+1)^2}{\sum_{i=1}^{n-1} r^{2i}}$, with equality wh
en $a_i = \frac{-(r^n+1)\,r^i}{\sum_{j=1}^{n-1} r^{2j}}$.

We then minimize over all real $r \neq 0$:
$$f(r) = \frac{(r^n+1)^2}{\sum_{i=1}^{n-1} r^{2i}}.$$

**Step 2: Substitution.**

Since $n$ is even, $r^n = (r^2)^{n/2} \geq 0$ and $r^{2i} = (r^2)^i$. Set $t = r
^2 > 0$ and $m = n/2 \geq 1$:
$$f = \frac{(t^m + 1)^2}{\sum_{i=1}^{2m-1} t^i}.$$

At $t = 1$: $f = \frac{4}{2m-1} = \frac{4}{n-1}$.

**Step 3: Key inequality.**

We prove $(2m-1)(t^m+1)^2 \geq 4\sum_{i=1}^{2m-1} t^i$ for all $t > 0$, with equ
ality at $t=1$.

Set $t = e^{2u}$ ($u \in \mathbb{R}$). Dividing both sides by $t^m = e^{2mu}$ an
d using $t^i + t^{2m-i} = 2t^m\cosh((m-i)\cdot 2u)$, the inequality reduces (aft
er algebraic manipulation) to:

$$\phi(u) := (2m-1)\cosh(2mu) + (2m-3) - 4\sum_{j=1}^{m-1}\cosh(2ju) \geq 0 \qua
d \forall\, u.$$

**Verification of the reduction:** Expanding $g(t) = (2m-1)(t^m+1)^2 - 4\sum_{i=
1}^{2m-1}t^i$ and dividing by $t^m$, substituting $t = e^{2u}$, and using $t^j +
 t^{-j} = 2\cosh(2ju)$, one obtains $g(t)/t^m = 2\phi(u)$. Thus $g(t) \geq 0 \if
f \phi(u) \geq 0$.

**Step 4: Proving $\phi(u) \geq 0$.**

Note $\phi$ is even, so assume $u \geq 0$. We have:
- $\phi(0) = (2m-1) + (2m-3) - 4(m-1) = 0$.
- $\phi'(u) = 2m(2m-1)\sinh(2mu) - 8\sum_{j=1}^{m-1} j\,\sinh(2ju)$.

We use the fact that $\frac{\sinh(s)}{s}$ is increasing for $s > 0$ (since $\fra
c{d}{ds}\frac{\sinh s}{s} = \frac{s\cosh s - \sinh s}{s^2} \geq 0$, as $\frac{d}
{ds}(s\cosh s - \sinh s) = s\sinh s \geq 0$ with value $0$ at $s=0$).

Therefore, for $1 \leq j \leq m-1$ and $u \geq 0$:
$$\frac{\sinh(2ju)}{2ju} \leq \frac{\sinh(2mu)}{2mu} \implies \sinh(2ju) \leq \f
rac{j}{m}\sinh(2mu).$$

Hence:
$$8\sum_{j=1}^{m-1} j\,\sinh(2ju) \leq \frac{8\sinh(2mu)}{m}\sum_{j=1}^{m-1} j^2
 = \frac{8\sinh(2mu)}{m}\cdot\frac{(m-1)m(2m-1)}{6} = \frac{4(m-1)(2m-1)}{3}\sin
h(2mu).$$

Therefore:
$$\phi'(u) \geq (2m-1)\sinh(2mu)\left[2m - \frac{4(m-1)}{3}\right] = (2m-1)\sinh
(2mu)\cdot\frac{2(m+2)}{3} \geq 0$$
for all $u \geq 0$ (since $m \geq 1$ implies every factor is non-negative, and $
\sinh(2mu) \geq 0$).

Since $\phi(0) = 0$ and $\phi'(u) \geq 0$ for $u \geq 0$, we conclude $\phi(u) \
geq 0$ for $u \geq 0$, and by evenness, for all $u$.

**Step 5: Equality and the minimum.**

Equality holds when $u = 0$, i.e., $t = 1$, i.e., $r = \pm 1$. The optimal coeff
icients are:
$$a_i = \frac{-(1^n+1)\cdot 1^i}{\sum_{j=1}^{n-1} 1^{2j}} = \frac{-2}{n-1} \quad
 \text{for all } i = 1, \ldots, n-1.$$

**Verification:** $P(1) = 1 + (n-1)\cdot\left(-\frac{2}{n-1}\right) + 1 = 1 - 2
+ 1 = 0$. ✓

$$\sum_{i=1}^{n-1} a_i^2 = (n-1)\cdot\frac{4}{(n-1)^2} = \frac{4}{n-1}.$$

## Answer

The minimum possible value of $a_1^2 + a_2^2 + \cdots + a_{n-1}^2$ is:

$$\boxed{\dfrac{4}{n-1}}$$
