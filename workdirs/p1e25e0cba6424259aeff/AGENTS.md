# Problem

A high-security data center consists of 52 unique server blades installed in a single vertical rack, one on top of the other. A junior technician needs to document the exact sequence of these blades (from the top position to the bottom position) for the facility's inventory records.

The head engineer already knows the full sequence but is only permitted to verify the physical distance between specific units. The technician may submit a list of queries to the engineer. Each query must name two specific server blades (for example, "the Database Blade and the Firewall Blade"), and the engineer will respond with the exact number of other blades currently installed between them in the rack.

What is the minimum number of such queries the technician must submit to the engineer to uniquely determine the full vertical order of all 52 blades?
