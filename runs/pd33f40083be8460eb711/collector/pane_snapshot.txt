## 证明

**论断：TRUE.**

设 $R$ 为一个域，并考虑 Hamilton 四元数代数 $R[i,j,k]$，其满足关系 $i^2 = j^2 =
k^2 = ijk = -1$。每个元素 $q \in R[i,j,k]$ 可以唯一地写成 $q = a + bi + cj + dk$
，其中 $a,b,c,d \in R$，其**约化范数 (reduced norm)** 为：

$$N(q) = q\bar{q} = a^2 + b^2 + c^2 + d^2,$$

其中 $\bar{q} = a - bi - cj - dk$ 是共轭元。注意 $\bar{q}\,q = N(q)$ 同样成立。

**关键引理：** $R[i,j,k]$ 是一个除环 $\iff$ 范数形式 $N(q) = a^2+b^2+c^2+d^2$ 是
**非迷向的 (anisotropic)**，即 $N(q)=0 \Rightarrow q=0$。

*证明：* $(\Rightarrow)$ 如果 $R[i,j,k]$ 是一个除环且 $N(q)=0$，那么 $q\bar{q}=0
$。由于除环没有零因子，因此 $q=0$ 或 $\bar{q}=0$（这蕴含 $q=0$）。所以 $q=0$。

$(\Leftarrow)$ 如果范数形式是非迷向的且 $q \neq 0$，那么 $N(q) \neq 0$，因此 $q^
{-1} = \bar{q}/N(q)$ 存在。所以每个非零元素都是可逆的，从而 $R[i,j,k]$ 是一个除
环。$\square$

现在，范数形式是 $a^2 + b^2 + c^2 + d^2$ —— 恰好是**四个平方和**。非迷向条件表明
：

$$a^2 + b^2 + c^2 + d^2 = 0 \implies a = b = c = d = 0.$$

在有序域 $R$ 中（这正是“正数”有意义的情况），平方和始终 $\geq 0$。因此，条件“每
个四个平方和都是正数，除非所有平方均为零”转化为：

$$a^2+b^2+c^2+d^2 > 0 \quad \text{ whenever } \quad (a,b,c,d) \neq (0,0,0,0),$$

这等价于 $a^2+b^2+c^2+d^2 = 0 \implies a=b=c=d=0$，即范数形式是非迷向的。

**将两个方向结合起来：**

- ($\Rightarrow$) 如果 $R[i,j,k]$ 是一个除环，那么范数形式是非迷向的，因此每个四
个平方和都是正数，除非所有平方均为零。
- ($\Leftarrow$) 如果每个四个平方和都是正数，除非所有平方均为零，那么范数形式是
非迷向的，因此 $R[i,j,k]$ 是一个除环。

因此，对于域 $R$：

$$R[i,j,k] \text{ 是一个除环} \iff \text{每个四个平方和都是正数，除非所有平方均
为零。}$$

**该论断为 TRUE。** $\blacksquare$
