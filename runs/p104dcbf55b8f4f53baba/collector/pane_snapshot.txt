This is precisely the statement of **Farkas' Lemma**. The answer is **yes**: the
 coefficients $t_i$ can be chosen so that $t_i \geq 0$ for every $i$ (and $L = \
sum_i t_i L_i$ still holds).

---

## Proof

Let $V$ be a real vector space and let $L_1, \dots, L_n, L \in V^*$ be linear fu
nctionals. The hypothesis is:

> (**H**) For every $x \in V$ with $L_i(x) \geq 0$ for all $i = 1, \dots, n$, we
 have $L(x) \geq 0$.

We prove that there exist $t_1, \dots, t_n \geq 0$ with $L = \sum_{i=1}^n t_i L_
i$.

### Reduction to the finite-dimensional case

Let $W = \operatorname{span}\{L_1, \dots, L_n, L\} \subseteq V^*$. This is a fin
ite-dimensional subspace. Let $K = \{x \in V : L_i(x) \geq 0 \text{ for all } i\
}$ be the cone of feasible points. The hypothesis says $L \geq 0$ on $K$.

Consider the map $\varphi: V \to \mathbb{R}^{n+1}$ defined by $\varphi(x) = (L_1
(x), \dots, L_n(x), L(x))$. The image $C := \varphi(V)$ is a linear subspace of
$\mathbb{R}^{n+1}$. The hypothesis (H) says:

$$\text{If } (a_1, \dots, a_n, b) \in C \text{ and } a_i \geq 0 \text{ for all }
 i, \text{ then } b \geq 0. \tag{H$'$}$$

This is now a purely finite-dimensional statement about a subspace $C \subseteq
\mathbb{R}^{n+1}$, so we may work entirely in $\mathbb{R}^{n+1}$.

### Separation argument

Let $P = \mathbb{R}^n_{\geq 0} \times \mathbb{R}_{< 0}$ be the set of points $(a
_1,\dots,a_n,b)$ with all $a_i \geq 0$ and $b < 0$. This is a (relatively open)
convex cone.

**Claim:** $C \cap P = \emptyset$.

Indeed, if $(a_1,\dots,a_n,b) \in C \cap P$, then $a_i \geq 0$ for all $i$ and $
b < 0$. But $(a_1,\dots,a_n,b) \in C = \varphi(V)$ means there exists $x \in V$
with $L_i(x) = a_i \geq 0$ and $L(x) = b < 0$, contradicting (H).

Since $C$ is a (closed) convex set (a subspace) and $P$ is a non-empty convex se
t disjoint from $C$, by the **Hahn–Banach / hyperplane separation theorem** (fin
ite-dimensional version), there exists a non-zero linear functional $\psi$ on $\
mathbb{R}^{n+1}$ and $\alpha \in \mathbb{R}$ with

$$\psi(c) \geq \alpha \geq \psi(p) \quad \text{for all } c \in C,\; p \in P.$$

Since $C$ is a linear subspace, $\psi$ must vanish on $C$ (otherwise $\psi$ woul
d be unbounded on $C$). So $\alpha \geq 0$ and $\psi|_C = 0$, while $\psi(p) \le
q 0$ for all $p \in P$.

Write $\psi(a_1,\dots,a_n,b) = \sum_{i=1}^n s_i a_i + s_{n+1} b$ for some real c
oefficients $s_1,\dots,s_{n+1}$.

**Sign of $s_{n+1}$:** Consider $p = (0,\dots,0,b)$ with $b < 0$. Then $p \in P$
 and $\psi(p) = s_{n+1} b \leq 0$. Since $b < 0$, this gives $s_{n+1} \geq 0$. W
e must have $s_{n+1} > 0$ (if $s_{n+1} = 0$, then $\psi = (s_1,\dots,s_n,0)$ van
ishes on $C$; but we'll see this leads to $\psi = 0$, contradicting $\psi \neq 0
$). Let me verify: if $s_{n+1} = 0$, then $\psi(a) = \sum s_i a_i \leq 0$ for al
l $a \in \mathbb{R}^n_{\geq 0}$, which forces $s_i \leq 0$ for all $i$. But also
 $\psi$ vanishes on $C$, and $\varphi(V) = C$ projects onto some subspace of $\m
athbb{R}^n$ in the first $n$ coordinates. Actually, let me just handle this more
 carefully below.

**Sign of $s_i$ ($i \leq n$):** Consider $p = (0,\dots,0,a_i,\dots,0,b)$ with $a
_i \geq 0$ and $b < 0$ (all other $a_j = 0$). Then $\psi(p) = s_i a_i + s_{n+1}
b \leq 0$. Letting $b \to 0^-$ and $a_i$ fixed, we get $s_i a_i \leq 0$ for all
$a_i \geq 0$, hence $s_i \leq 0$ for every $i = 1,\dots,n$.

**$s_{n+1} > 0$:** Since $\psi \neq 0$ and $\psi$ vanishes on $C$, $\psi$ is not
 identically zero. If $s_{n+1} = 0$, then $\psi = (s_1,\dots,s_n, 0)$ with all $
s_i \leq 0$. Now $\psi$ vanishes on $C = \varphi(V)$, meaning $\sum_{i=1}^n s_i
L_i(x) = 0$ for all $x \in V$, i.e., $\sum s_i L_i = 0$ with $s_i \leq 0$. This
is possible (e.g., if the $L_i$ are linearly dependent), but it doesn't yet give
 a contradiction. However, we can still proceed: we need to show $s_{n+1} \neq 0
$.

Actually, the cleaner approach: we need $\psi$ to separate $C$ from $P$, and $P$
 contains points with $b \to -\infty$. If $s_{n+1} = 0$, then $\psi(p) = \sum s_
i a_i$ which is $\leq 0$ for $p \in P$ (fine), but $\psi$ vanishing on $C$ only
constrains the first $n$ coordinates. The issue is whether $\psi \neq 0$ with $s
_{n+1} = 0$ can actually separate.

Let me use a cleaner version. Since $C$ is a closed convex cone (subspace) and $
P$ is a convex cone with $C \cap P = \emptyset$, by the **separation theorem for
 cones**, there exists $\psi \neq 0$ with $\psi(c) \geq 0$ for all $c \in C$ and
 $\psi(p) \leq 0$ for all $p \in P$. Since $C$ is a subspace, $\psi(c) = 0$ for
all $c \in C$.

Now suppose $s_{n+1} = 0$. Then $\sum_{i=1}^n s_i L_i(x) = 0$ for all $x$ (since
 $\psi$ vanishes on $C = \varphi(V)$), with $s_i \leq 0$. Set $u_i = -s_i \geq 0
$. Then $\sum u_i L_i = 0$. This is consistent but $\psi$ doesn't involve $L$.

The key point: we need $s_{n+1} \neq 0$. Here's why it must be: Consider the poi
nt $e = (0,\dots,0,-1) \in P$ (all $a_i = 0$, $b = -1$). Then $\psi(e) = -s_{n+1
} \leq 0$, so $s_{n+1} \geq 0$. Now consider the closure $\bar{P} = \mathbb{R}^n
_{\geq 0} \times \mathbb{R}_{\leq 0}$. We have $\psi \leq 0$ on $\bar{P}$ as wel
l (by continuity). The point $(0,\dots,0,0) \in C \cap \bar{P}$, and $\psi(0) =
0$, consistent.

If $s_{n+1} = 0$: $\psi = (s_1,\dots,s_n,0)$ with all $s_i \leq 0$, and $\psi$ v
anishes on $C$. This means $\sum s_i L_i = 0$. Now I claim we can still find the
 desired representation. Consider two cases:

**Case 1: $s_{n+1} > 0$.** Divide by $s_{n+1}$: set $t_i = -s_i / s_{n+1} \geq 0
$ (since $s_i \leq 0$). The condition $\psi|_C = 0$ means: for all $x \in V$,
$$\sum_{i=1}^n s_i L_i(x) + s_{n+1} L(x) = 0 \implies L(x) = \sum_{i=1}^n \frac{
-s_i}{s_{n+1}} L_i(x) = \sum_{i=1}^n t_i L_i(x),$$
with $t_i \geq 0$. Done.

**Case 2: $s_{n+1} = 0$.** Then $\sum s_i L_i = 0$ with $s_i \leq 0$, i.e., $\su
m u_i L_i = 0$ with $u_i \geq 0$. In this case the separating hyperplane doesn't
 directly give us $L$. But this case arises only when we chose a "bad" separator
. We need to argue that a separator with $s_{n+1} > 0$ exists.

Here is the cleanest way to handle this: instead of separating $C$ from $P$, we
separate $C$ from the single ray $\{(-\mathbf{0}, -\lambda) : \lambda > 0\}$...
no, let me use the standard Farkas approach directly.

### Standard Farkas argument (clean version)

Define $C = \varphi(V) \subseteq \mathbb{R}^{n+1}$ as above, a subspace. The hyp
othesis (H') says $C \cap (\mathbb{R}^n_{\geq 0} \times \mathbb{R}_{<0}) = \empt
yset$.

Equivalently, $C \cap \mathbb{R}^n_{\geq 0} \times \{-1\} = \emptyset$, i.e., th
ere is no $x \in V$ with $L_i(x) \geq 0$ for all $i$ and $L(x) = -1$.

Let $S = \{(L_1(x), \dots, L_n(x)) : x \in V\} \subseteq \mathbb{R}^n$ (a subspa
ce) and let $f: S \to \mathbb{R}$ be the linear functional $f(a) = L(x)$ where $
x$ is any preimage (well-defined since if $L_i(x) = L_i(x')$ for all $i$, we nee
d $L(x) = L(x')$; this follows from (H): if $L(x) \neq L(x')$, say $L(x) > L(x')
$, then for $y = x - x'$ we have $L_i(y) = 0 \geq 0$ for all $i$ but $L(y) > 0$.
.. hmm, this doesn't directly give well-definedness).

Let me use the most standard formulation. Consider the cone $K = \{(L_1(x), \dot
s, L_n(x), L(x)) : x \in V\} \subseteq \mathbb{R}^{n+1}$. Wait, this is a subspa
ce, not just a cone. Let me instead use the cone generated by the "columns."

**Cleanest approach — direct Farkas:** Represent each $L_i$ and $L$ as row vecto
rs (after choosing a basis, reducing to $\mathbb{R}^m$). Then the hypothesis is:
 $Ax \geq 0 \implies c^T x \geq 0$, where $A$ has rows $L_i$ and $c^T = L$. Fark
as' lemma states:

> **Farkas' Lemma:** $[Ax \geq 0 \implies c^T x \geq 0]$ if and only if $c = A^T
 t$ for some $t \geq 0$.

**Proof of Farkas' Lemma:** The "$\Leftarrow$" direction is immediate: if $c = A
^T t$ with $t \geq 0$ and $Ax \geq 0$, then $c^T x = t^T A x \geq 0$.

For "$\Rightarrow$": Suppose $c \neq A^T t$ for any $t \geq 0$. Let $Q = \{A^T t
 : t \geq 0\}$ be the closed convex cone generated by the columns of $A^T$ (i.e.
, the rows of $A$, viewed as vectors $L_i$). Since $Q$ is closed (finitely gener
ated cone) and $c \notin Q$, by the **strict separation theorem** there exists a
 hyperplane strictly separating $c$ from $Q$: there exists $y$ and $\epsilon > 0
$ with

$$y^T c < 0 \quad \text{and} \quad y^T q \geq 0 \text{ for all } q \in Q.$$

Since $Q = \{A^T t : t \geq 0\}$, the condition $y^T q \geq 0$ for all $q \in Q$
 is equivalent to $y^T A^T t \geq 0$ for all $t \geq 0$, which (taking $t = e_i$
) gives $(Ay)_i \geq 0$ for all $i$, i.e., $Ay \geq 0$.

But $y^T c < 0$ means $c^T y < 0$, i.e., $L(y) < 0$, while $Ay \geq 0$ means $L_
i(y) \geq 0$ for all $i$. This contradicts the hypothesis (H).

Therefore $c \in Q$, i.e., $c = A^T t = \sum_i t_i L_i$ for some $t_i \geq 0$. $
\blacksquare$

### Conclusion

**Yes**, the coefficients can be redefined so that $t_i \geq 0$ for every $i$. S
pecifically, there exist $t_1, \dots, t_n \geq 0$ such that

$$L = \sum_{i=1}^{n} t_i L_i.$$

This is exactly the content of **Farkas' Lemma** (J. Farkas, 1902), which is one
 of the fundamental results of linear programming duality and convex analysis. S
tandard references include:

- Schrijver, *Theory of Linear and Integer Programming* (Wiley, 1986), §7.3.
- Rockafellar, *Convex Analysis* (Princeton, 1970), §22, Theorem 22.7.
- Boyd & Vandenberghe, *Convex Optimization* (Cambridge, 2004), §5.8.3.
