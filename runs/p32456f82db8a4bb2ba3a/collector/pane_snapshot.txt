Looking at this problem, I need to determine whether there exists a function $f:
 \mathbb{R} \to \mathbb{R}$ that is discontinuous exactly at the rationals, cont
inuous at all irrationals, non-constant on the irrationals, and such that $f(q_n
)$ converges for some sequence of rationals $\{q_n\}$.

**Answer: Yes, such a function exists.**

## Construction

Let $T: \mathbb{R} \to \mathbb{R}$ be **Thomae's function** (the popcorn functio
n):
$$T(x) = \begin{cases} \frac{1}{q} & \text{if } x = \frac{p}{q} \text{ in lowest
 terms, } q > 0, \\ 0 & \text{if } x \text{ is irrational.} \end{cases}$$

Define:
$$\boxed{f(x) = x + T(x).}$$

## Verification of all properties

### Property 1: $f$ is continuous at every irrational

Let $\alpha$ be irrational, so $f(\alpha) = \alpha + 0 = \alpha$. We show $\lim_
{x \to \alpha} f(x) = \alpha$, i.e., $\lim_{x \to \alpha} T(x) = 0$.

**Proof that $T$ is continuous at irrationals:** Given $\varepsilon > 0$, consid
er the interval $[\alpha - 1, \alpha + 1]$. There are only **finitely many** rat
ionals $p/q$ in this interval with $q \leq 1/\varepsilon$ (since for each fixed
$q$, there are at most $2q+1$ such rationals, and we sum over finitely many $q$)
. Let $\delta > 0$ be the minimum distance from $\alpha$ to these finitely many
rationals (and $\delta < 1$). Then for any $x$ with $|x - \alpha| < \delta$:
- If $x$ is irrational: $T(x) = 0 < \varepsilon$.
- If $x = p/q$ is rational: since $|x - \alpha| < \delta$, $x$ is not one of the
 finitely many rationals with $q \leq 1/\varepsilon$, so $q > 1/\varepsilon$, gi
ving $T(x) = 1/q < \varepsilon$.

Thus $T(x) \to 0$ as $x \to \alpha$, so $f(x) = x + T(x) \to \alpha + 0 = \alpha
 = f(\alpha)$. ✓

### Property 2: $f$ is discontinuous at every rational

Let $r = p/q$ (in lowest terms, $q \geq 1$). Then $f(r) = r + 1/q$.

Take any sequence of irrationals $\{\alpha_n\}$ with $\alpha_n \to r$ (such a se
quence exists since irrationals are dense). Then:
$$f(\alpha_n) = \alpha_n + T(\alpha_n) = \alpha_n + 0 = \alpha_n \to r.$$

But $f(r) = r + 1/q \neq r$ (since $1/q > 0$). Therefore $f$ is discontinuous at
 $r$. ✓

### Property 3: $f|_{\mathbb{R} \setminus \mathbb{Q}}$ is not constant

For every irrational $\alpha$, $f(\alpha) = \alpha + 0 = \alpha$. Since there ex
ist distinct irrationals (e.g., $\sqrt{2} \neq \sqrt{3}$), we have $f(\sqrt{2})
= \sqrt{2} \neq \sqrt{3} = f(\sqrt{3})$. So $f$ restricted to the irrationals is
 the identity, which is non-constant. ✓

### Property 4: $f(q_n)$ converges for some sequence of rationals $\{q_n\}$

Take $q_n = \frac{1}{n}$ for $n \geq 1$. Each $q_n$ is rational, and in lowest t
erms $\frac{1}{n}$ has denominator $n$, so $T(1/n) = 1/n$. Therefore:
$$f(q_n) = \frac{1}{n} + \frac{1}{n} = \frac{2}{n} \to 0.$$

The sequence $\{f(q_n)\}$ converges to $0$. ✓

(As an even simpler example, the constant sequence $q_n = 0$ gives $f(q_n) = f(0
) = 0 + T(0) = 0 + 1 = 1$ for all $n$, which trivially converges.)

## Conclusion

The function $f(x) = x + T(x)$, where $T$ is Thomae's function, satisfies all fo
ur required properties simultaneously:

1. **Discontinuous exactly at rationals** — the discontinuity of $T$ at each rat
ional $p/q$ (where $T$ jumps to $1/q$ while approaching $0$ along nearby points)
 is preserved under addition with the continuous function $x \mapsto x$.
2. **Continuous at all irrationals** — both $x \mapsto x$ and $T$ are continuous
 at irrationals, so their sum is.
3. **Non-constant on irrationals** — $f$ acts as the identity on irrationals.
4. **$f(q_n)$ converges for a sequence of rationals** — e.g., $q_n = 1/n$ gives
$f(q_n) = 2/n \to 0$.

The key insight is that adding a continuous function (the identity) to Thomae's
function preserves the discontinuity structure (since continuity/discontinuity o
f a sum $g + h$ where $g$ is continuous is determined by $h$), while making the
restriction to irrationals non-constant (since Thomae's function vanishes on irr
ationals, the identity dominates there).
