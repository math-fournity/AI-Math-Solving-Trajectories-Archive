Proof

We seek all positive integers $n$ such that $n^2 + 2n + 2$ is a perfect square.

Rewrite. Observe that $$n^2 + 2n + 2 = (n+1)^2 + 1.$$

So we need $(n+1)^2 + 1 = k^2$ for some non-negative integer $k$.

Factor. Rearranging, $$k^2 - (n+1)^2 = 1,$$ $$\bigl(k - (n+1)\bigr)\bigl(k +
(n+1)\bigr) = 1.$$

Analyze the factors. Since $n \geq 1$, we have $n+1 \geq 2 > 0$. Also $k^2 =
(n+1)^2 + 1 > (n+1)^2$, so $k > n+1 \geq 2$, meaning both factors $k-(n+1)$ and
$k+(n+1)$ are positive integers.

The product of two positive integers equals $1$ only if both equal $1$: $$k -
(n+1) = 1 \quad\text{and}\quad k + (n+1) = 1.$$

Adding these equations gives $2k = 2$, so $k = 1$. Substituting back, $n+1 = k -
1 = 0$, i.e., $n = -1$.

Contradiction. This gives $n = -1$, which is not a positive integer. Moreover,
with $n+1 = 0$ and $k = 1$, the second factor $k + (n+1) = 1 + 0 = 1$ checks
out, but $n = -1$ fails the requirement $n \geq 1$.
