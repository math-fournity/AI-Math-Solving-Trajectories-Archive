**Answer: No.** Projections of Lebesgue-measurable sets need not be Lebesgue-mea
surable.

**Proof.**

We work in $\mathbb{R}^2$ and project onto the first coordinate, $\pi:\mathbb{R}
^2\to\mathbb{R}$, $\pi(x,y)=x$.

**Step 1: A Vitali set.** By the axiom of choice, there exists a Vitali set $V\s
ubseteq[0,1]$: a set containing exactly one representative from each coset of $\
mathbb{R}/\mathbb{Q}$ in $[0,1]$. It is standard that $V$ is **not** Lebesgue-me
asurable. (If it were measurable, the countable union $\bigcup_{q\in\mathbb{Q}\c
ap[-1,1]}(V+q)$, which contains $[0,1]$ and is contained in $[-1,2]$, would have
 measure between $1$ and $3$; but the translated copies are pairwise disjoint, f
orcing the measure to be either $0$ or $+\infty$, a contradiction.)

**Step 2: Lift it to a null set in $\mathbb{R}^2$.** Define
$$A := V\times\{0\} \subseteq \mathbb{R}^2.$$
The set $A$ is contained in the $x$-axis $\mathbb{R}\times\{0\}$, which is a one
-dimensional affine subspace of $\mathbb{R}^2$ and hence has two-dimensional Leb
esgue measure zero. Therefore $A$ is a **null set** in $\mathbb{R}^2$, and conse
quently $A$ is **Lebesgue-measurable** (every null set is Lebesgue-measurable, s
ince Lebesgue measure is complete).

**Step 3: Project.** The projection of $A$ onto the first coordinate is
$$\pi(A) = V.$$
By Step 1, $V$ is **not** Lebesgue-measurable.

**Conclusion.** We have exhibited a Lebesgue-measurable set $A\subseteq\mathbb{R
}^2$ whose projection $\pi(A)\subseteq\mathbb{R}$ is not Lebesgue-measurable. He
nce projections of Lebesgue-measurable sets are not, in general, Lebesgue-measur
able. $\blacksquare$

**Remark.** The subtlety is that Lebesgue measure is *complete*: it sees all sub
sets of null sets as measurable. The projection map destroys this completeness,
since a null set in the plane (e.g., a subset of a line) can project onto an arb
itrary subset of the line — including a non-measurable one. By contrast, project
ions of *Borel* sets (the analytic sets) are always Lebesgue-measurable; the fai
lure is specific to the larger class of Lebesgue-measurable sets.
