## Setting Up Coordinates

Since $A_1A \perp$ face $ABCD$, the parallelepiped is right (lateral edges perpe
ndicular to base). I place:
- $C = (0,0,0)$, $B = (b,0,0)$ (so $CB$ along $x$-axis), $C_1 = (0,0,h)$, $B_1 =

- $D = (10\cos\alpha, 10\sin\alpha, 0)$ where $CD = CK + KD = 9 + 1 = 10$ and $\

- $A = B + D - C$, and $A_1, D_1$ at height $z = h$

The face $BCC_1B_1$ lies in the $xz$-plane ($y=0$), a rectangle with sides $b$ a

## Sphere Touches All Four Edges of Rectangle $BCC_1B_1$

For sphere center $O=(x_0, y_0, z_0)$ and radius $R$, equidistant from all four
edges:

- Dist to $CB$ ($y{=}0,z{=}0$): $\sqrt{y_0^2+z_0^2}=R$
- Dist to $C_1C$ ($x{=}0,y{=}0$): $\sqrt{x_0^2+y_0^2}=R$ → $x_0 = z_0$
- Dist to $B_1C_1$ ($y{=}0,z{=}h$): $\sqrt{y_0^2+(z_0-h)^2}=R$ → $z_0 = h/2$
- Dist to $BB_1$ ($x{=}b,y{=}0$): $\sqrt{(x_0-b)^2+y_0^2}=R$ → $x_0 = b/2$

From $x_0 = z_0$: $b/2 = h/2$, so **$h = b$** (the face is a square). Center: $O
 = (b/2,\, y_0,\, b/2)$, with $R^2 = y_0^2 + (b/2)^2$.

## Sphere Touches Edge $CD$ at $K$ with $CK = 9$

Distance from $O$ to line $CD$ (direction $\hat{d}=(\cos\alpha,\sin\alpha,0)$) e
quals $R$. Computing $|\vec{CO}\times\hat{d}|^2 = R^2$ and simplifying (dividing

$$\left(\frac{b}{2}\right)^2 - b\,y_0\cot\alpha - y_0^2 = 0 \quad \textbf{(1)}$$

The foot of perpendicular gives $CK = \vec{CO}\cdot\hat{d} = \frac{b}{2}\cos\alp
ha + y_0\sin\alpha = 9 \quad \textbf{(2)}$

## Sphere Touches Edge $A_1D_1$

$A_1D_1$ is at height $z=b$, through $D_1=(10\cos\alpha, 10\sin\alpha, b)$, dire
ction $(1,0,0)$. Distance from $O$ to this line:

$$\sqrt{(b/2)^2 + (y_0 - 10\sin\alpha)^2} = R = \sqrt{y_0^2 + (b/2)^2}$$

$$(y_0 - 10\sin\alpha)^2 = y_0^2 \implies y_0 = 5\sin\alpha \quad \textbf{(3)}$$

(rejecting $\sin\alpha=0$ as it gives a degenerate parallelogram)

## Solving the System

Substituting (3) into (2): $\frac{b}{2}\cos\alpha + 5\sin^2\alpha = 9$, so $b\co
s\alpha = 18 - 10\sin^2\alpha$ **(4)**

Substituting (3) into (1): $\frac{b^2}{4} - 5b\cos\alpha - 25\sin^2\alpha = 0$.
Using (4):

$$\frac{b^2}{4} - 5(18 - 10\sin^2\alpha) - 25\sin^2\alpha = 0 \implies \frac{b^2

Substituting $b = \frac{18-10s}{\cos\alpha}$ (from (4), with $s=\sin^2\alpha$) i

$$\frac{(18-10s)^2}{4(1-s)} = 90 - 25s$$

$$324 - 360s + 100s^2 = 360 - 460s + 100s^2$$

$$100s = 36 \implies s = 0.36$$

So $\sin\alpha = 0.6$, $\cos\alpha = 0.8$.

**Back-substituting:**
- $y_0 = 5(0.6) = 3$

- $h = b = 18$
- $R^2 = 3^2 + 9^2 = 90$, so $R = 3\sqrt{10}$
