## Chain Decomposition

 odd m ∈ {1,3,5,…,99}, the chain C_m = {m, 2m, 4m, …} (≤ 100) consists of pairwi
se comparable elements. This partitions {1,…,100} into **50 chains** (one per od
d m ≤ 99).

Any antichain picks **at most one** element per chain. Since we need 50 elements
, we pick **exactly one** per chain — i.e., we choose an exponent a(m) ≥ 0 for e
ach odd m, keeping element 2^{a(m)}·m.

## Divisibility Condition

For odd m ≠ m', the element 2^{a(m)}·m divides 2^{a(m')}·m' **iff** a(m) ≤ a(m')

> **m | m' (m < m', both odd) ⟹ a(m) > a(m').**

Also need 2^{a(m)}·m ≤ 100 (upper bound on each exponent).
