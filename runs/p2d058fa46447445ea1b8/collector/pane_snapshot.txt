## Solution

Let $f(x) = x^3 - x^2 + px - 1 = (x-\alpha)(x-\beta)(x-\gamma)$. By Vieta's form
ulas:
$$\alpha+\beta+\gamma = 1, \quad \alpha\beta+\beta\gamma+\gamma\alpha = p, \quad
 \alpha\beta\gamma = 1.$$

**Step 1: Reduce $\alpha^3+1$ using the root equation.**

Since $f(\alpha)=0$, we have $\alpha^3 = \alpha^2 - p\alpha + 1$, hence
$$\alpha^3 + 1 = \alpha^2 - p\alpha + 2.$$
Define $h(x) = x^2 - px + 2$. Then
$$(\alpha^3+1)(\beta^3+1)(\gamma^3+1) = h(\alpha)\,h(\beta)\,h(\gamma) = \operat
orname{Res}(f, h),$$
since $f$ is monic and $\operatorname{Res}(f,h) = \prod_i h(\alpha_i)$.

**Step 2: Compute the resultant via polynomial division.**

Divide $f(x) = x^3 - x^2 + px - 1$ by $h(x) = x^2 - px + 2$:
$$f(x) = \bigl(x + (p-1)\bigr)\,h(x) + r(x),$$
where the remainder is
$$r(x) = (p^2-2)\,x + (1-2p).$$

Using the resultant property $\operatorname{Res}(f,h) = \operatorname{Res}(h,r)$
 (since $f(\beta_j)=r(\beta_j)$ at roots $\beta_j$ of $h$):

For the linear $r(x) = ax+b$ with $a = p^2-2$, $b = 1-2p$,
$$\operatorname{Res}(h, r) = a^2\, h\!\left(-\tfrac{b}{a}\right) = (p^2-2)^2\, h
\!\left(\tfrac{2p-1}{p^2-2}\right).$$

**Step 3: Expand.**

$$h\!\left(\tfrac{2p-1}{p^2-2}\right) = \frac{(2p-1)^2 - p(2p-1)(p^2-2) + 2(p^2-
2)^2}{(p^2-2)^2}.$$

Multiplying by $(p^2-2)^2$ and expanding each term:
- $(2p-1)^2 = 4p^2 - 4p + 1$
- $p(2p-1)(p^2-2) = 2p^4 - p^3 - 4p^2 + 2p$
- $2(p^2-2)^2 = 2p^4 - 8p^2 + 8$

Combining with signs $+,-,+$:
$$N = (4p^2-4p+1) - (2p^4 - p^3 - 4p^2 + 2p) + (2p^4 - 8p^2 + 8)$$
$$= p^3 + (4+4-8)p^2 + (-4-2)p + (1+8) = p^3 - 6p + 9.$$

(The $p^4$ terms cancel.) This polynomial identity also covers the degenerate ca
se $p^2=2$ by continuity, verified directly: at $p=\sqrt{2}$, both sides give $9
-4\sqrt{2}$; at $p=-\sqrt{2}$, both give $9+4\sqrt{2}$. ✓

**Step 4: Solve for $p$.**

Setting the product equal to $2019$:
$$p^3 - 6p + 9 = 2019 \implies p^3 - 6p - 2010 = 0.$$

**Step 5: Product of all possible values of $p$.**

The possible values of $p$ are exactly the three roots of $p^3 - 6p - 2010 = 0$
(over $\mathbb{C}$, and $p$ is allowed to be complex). By Vieta's formulas for $
p^3 + 0\cdot p^2 - 6p - 2010 = 0$, the product of all roots is
$$-(-2010) = 2010.$$

Every root $p$ of this cubic yields a valid configuration (the cubic $x^3-x^2+px
-1$ always has three roots over $\mathbb{C}$, and the resultant identity holds f
or all $p$), so all three roots are admissible.

$$\boxed{2010}$$
