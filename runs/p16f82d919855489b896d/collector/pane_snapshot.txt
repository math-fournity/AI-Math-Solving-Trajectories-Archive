## Solution

**Claim:** Yes. For every constant $c > 0$, the inequality
$$\sum_{\substack{p \le n \\ p \text{ prime}}} \frac{1}{\ln p} < c\,\frac{n}{\ln
 n}$$
holds for all sufficiently large $n$.

### Proof

Let $\pi(x)$ denote the prime-counting function and set
$$S(n) := \sum_{\substack{p \le n \\ p \text{ prime}}} \frac{1}{\ln p}.$$

**Step 1: Abel (partial) summation.** Viewing the sum as a Stieltjes integral an
d integrating by parts with $f(t) = 1/\ln t$,

$$S(n) = \int_{2^{-}}^{n} \frac{1}{\ln t}\,d\pi(t) = \frac{\pi(n)}{\ln n} + \int
_{2}^{n} \frac{\pi(t)}{t\,(\ln t)^{2}}\,dt. \tag{1}$$

**Step 2: Apply the Prime Number Theorem.** The PNT gives $\pi(t) \sim \dfrac{t}
{\ln t}$, i.e.
$$\pi(t) = \frac{t}{\ln t} + O\!\left(\frac{t}{(\ln t)^{2}}\right).$$

*First term in (1):*
$$\frac{\pi(n)}{\ln n} = \frac{n}{(\ln n)^{2}} + O\!\left(\frac{n}{(\ln n)^{3}}\
right). \tag{2}$$

*Second term in (1):* substituting the PNT estimate,
$$\int_{2}^{n} \frac{\pi(t)}{t\,(\ln t)^{2}}\,dt = \int_{2}^{n} \frac{1}{(\ln t)
^{3}}\,dt + O\!\left(\int_{2}^{n} \frac{1}{(\ln t)^{4}}\,dt\right). \tag{3}$$

To evaluate $\displaystyle\int_{2}^{n} \frac{dt}{(\ln t)^{k}}$, substitute $u =
\ln t$ ($t = e^{u}$, $dt = e^{u}\,du$):
$$\int_{\ln 2}^{\ln n} \frac{e^{u}}{u^{k}}\,du.$$

Repeated integration by parts shows $\displaystyle\int \frac{e^{u}}{u^{k}}\,du =
 \frac{e^{u}}{u^{k}}\bigl(1 + O(1/u)\bigr)$, hence
$$\int_{2}^{n} \frac{dt}{(\ln t)^{k}} \sim \frac{n}{(\ln n)^{k}} \qquad (n \to \
infty). \tag{4}$$

Applying (4) with $k = 3$ (and $k=4$ for the error term) to (3):
$$\int_{2}^{n} \frac{\pi(t)}{t\,(\ln t)^{2}}\,dt = \frac{n}{(\ln n)^{3}} + O\!\l
eft(\frac{n}{(\ln n)^{4}}\right). \tag{5}$$

**Step 3: Combine.** From (1), (2), and (5):
$$S(n) = \frac{n}{(\ln n)^{2}} + O\!\left(\frac{n}{(\ln n)^{3}}\right),$$
so
$$S(n) \sim \frac{n}{(\ln n)^{2}}. \tag{6}$$

**Step 4: Compare with $c\,\dfrac{n}{\ln n}$.** From (6),
$$\frac{S(n)}{n/\ln n} \sim \frac{1}{\ln n} \xrightarrow{n \to \infty} 0.$$

Therefore, for any fixed $c > 0$, there exists $N = N(c)$ such that for all $n \
ge N$,
$$\frac{S(n)}{n/\ln n} < c,$$
i.e.,
$$\sum_{\substack{p \le n \\ p \text{ prime}}} \frac{1}{\ln p} < c\,\frac{n}{\ln
 n}.$$

The key mechanism is that each summand $1/\ln p \le 1/\ln 2$ is bounded, while t
he number of summands $\pi(n) \sim n/\ln n$ grows slower than $n/\ln n$ by a ful
l factor of $\ln n$; equivalently, the average value of $1/\ln p$ over primes $p
 \le n$ is $\sim 1/\ln n \to 0$, which is eventually smaller than any positive c
onstant $c$.
