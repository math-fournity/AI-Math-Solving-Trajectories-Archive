## Proof

Let $D = R/p_1 \times \cdots \times R/p_n$. For an element $d \in D$, its annihi
lator is
$$\operatorname{ann}_D(d) = \{c \in D : c\,d = 0\}.$$

**Claim.** Any element $x \in (p_2 \cap \cdots \cap p_n) \setminus p_1$ satisfie
s
$$\operatorname{ann}_D(x+p_1, \ldots, x+p_n) = \operatorname{ann}_D(1+p_1, 0, \l
dots, 0).$$

Such an $x$ exists, so this gives the desired element.

---

**Step 1: Compute $\operatorname{ann}_D(1+p_1, 0, \ldots, 0)$.**

An element $c = (c_1+p_1, \ldots, c_n+p_n) \in D$ annihilates $(1+p_1, 0, \ldots
, 0)$ iff
$$(c_1 \cdot 1 + p_1,\; 0, \ldots, 0) = (0, \ldots, 0),$$
i.e., $c_1 \in p_1$. Hence
$$\operatorname{ann}_D(1+p_1, 0, \ldots, 0) = \{0\} \times R/p_2 \times \cdots \
times R/p_n.$$

**Step 2: Compute $\operatorname{ann}_D(x+p_1, \ldots, x+p_n)$.**

We have $c \cdot (x+p_1, \ldots, x+p_n) = (c_1 x + p_1, \ldots, c_n x + p_n)$, w
hich is zero iff $c_i x \in p_i$ for every $i$. Thus
$$\operatorname{ann}_D(x+p_1, \ldots, x+p_n) = \prod_{i=1}^{n} (p_i : x)/p_i, \q
uad \text{where } (p_i:x) = \{c \in R : cx \in p_i\}.$$

**Step 3: Show the two annihilators coincide for $x \in (p_2\cap\cdots\cap p_n)\
setminus p_1$.**

- **Component $i \geq 2$:** Since $x \in p_i$, we have $c_i x \in p_i$ for *all*
 $c_i \in R$, so $(p_i : x) = R$ and the $i$-th component is $R/p_i$. This match
es $\operatorname{ann}_D(1+p_1,0,\ldots,0)$.

- **Component $i = 1$:** Since $p_1$ is a **prime** ideal, $R/p_1$ is an integra
l domain. In a domain, multiplication by a nonzero element is injective. Since $
x \notin p_1$, the element $x + p_1 \in R/p_1$ is nonzero, hence a non-zerodivis
or. Therefore
$$\{c_1 \in R : c_1 x \in p_1\} = p_1,$$
so the first component is $\{0\} \subset R/p_1$. This also matches.

Combining both steps:
$$\operatorname{ann}_D(x+p_1, \ldots, x+p_n) = \{0\} \times R/p_2 \times \cdots
\times R/p_n = \operatorname{ann}_D(1+p_1, 0, \ldots, 0).$$

**Step 4: Existence of $x \in (p_2 \cap \cdots \cap p_n) \setminus p_1$.**

The ideals $p_1, \ldots, p_n$ are **distinct minimal primes** of $R$. Since $p_1
$ is minimal and $p_1 \neq p_i$ for $i \geq 2$, we have $p_1 \not\supseteq p_i$
for every $i \geq 2$ (otherwise $p_1 \supseteq p_i$ with both minimal forces $p_
1 = p_i$).

Suppose for contradiction that $p_2 \cap \cdots \cap p_n \subseteq p_1$. Since $
p_1$ is prime and contains a finite intersection, by the prime-avoidance-type fa
ct *(a prime containing a finite intersection of ideals contains one of them)*,
we get $p_1 \supseteq p_i$ for some $i \geq 2$—a contradiction.

Hence $p_2 \cap \cdots \cap p_n \not\subseteq p_1$, so the set $(p_2 \cap \cdots
 \cap p_n) \setminus p_1$ is nonempty.

---

**Conclusion.** Choosing any
$$\boxed{x \in (p_2 \cap \cdots \cap p_n) \setminus p_1}$$
(which is nonempty by the argument above) yields
$$\operatorname{ann}_D(x+p_1, \ldots, x+p_n) = \operatorname{ann}_D(1+p_1, 0, \l
dots, 0).$$

### PROOF COMPLETE
