## Solution

**Setup.** Let ζ be a root of unity (so ζⁿ = 1 for some n ≥ 1) and also a root o
f z² + az + b = 0 with a, b ∈ ℤ.

Since the coefficients a, b are real (integers), the conjugate ζ̄ is the other ro
ot. By Vieta's formulas:

- ζ + ζ̄ = −a ∈ ℤ
- ζ · ζ̄ = b ∈ ℤ

**Bounding b.** Since ζ is a root of unity, |ζ| = 1, so

$$b = \zeta\bar{\zeta} = |\zeta|^2 = 1.$$

**Bounding 2Re(ζ).** Since |ζ| = 1, we have Re(ζ) ∈ [−1, 1], hence 2Re(ζ) ∈ [−2,
 2]. The requirement ζ + ζ̄ = 2Re(ζ) = −a ∈ ℤ forces 2Re(ζ) ∈ {−2, −1, 0, 1, 2}.

This gives five cases:

| 2Re(ζ) | Re(ζ) | ζ | root of unity? | polynomial |
|---|---|---|---|---|
| 2 | 1 | 1 | yes (n=1) | z² − 2z + 1 |
| 1 | 1/2 | e^{±πi/3} | yes (n=6) | z² − z + 1 |
| 0 | 0 | ±i | yes (n=4) | z² + 1 |
| −1 | −1/2 | e^{±2πi/3} | yes (n=3) | z² + z + 1 |
| −2 | −1 | −1 | yes (n=2) | z² + 2z + 1 |

Each polynomial has integer coefficients (a = −2Re(ζ), b = 1), confirming every
listed ζ is genuinely a root of some z² + az + b = 0 with a, b ∈ ℤ.

**Counting.** The distinct roots of unity obtained are:

$$1,\quad -1,\quad i,\quad -i,\quad e^{\pi i/3},\quad e^{-\pi i/3},\quad e^{2\pi
 i/3},\quad e^{-2\pi i/3}.$$

That is **8** roots of unity.

**No others are possible**, since any qualifying ζ must satisfy 2Re(ζ) ∈ {−2,−1,
0,1,2} and |ζ| = 1, which exhausts all solutions.
