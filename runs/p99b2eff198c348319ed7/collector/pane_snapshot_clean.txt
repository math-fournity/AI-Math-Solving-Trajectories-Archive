## 证明

**设置。** 设 **p** = (p₁, …, pₘ)，其中每个 pᵢ ~ Uniform[0,1] 是独立的。在 n 次
试验的每一次中，我们生成一个二元数组 x = (x₁, …, xₘ) ∈ {0,1}ᵐ，其中 xᵢ ~ Bernoul
li(pᵢ) 是独立的。设 q_x 为数组 x 在 n 次试验中出现的次数。频率 {q_x : x ∈ {0,1}ᵐ
} 按照二元数组 x 的规范（排序）顺序列出，且 r 为前 k 个频率之和。

**单次试验概率。** 给定 p，在单次试验中生成数组 x 的概率为：

$$P(\mathbf{x} \mid \mathbf{p}) = \prod_{i:\, x_i=1} p_i \;\cdot\! \prod_{i:\, x
_i=0} (1-p_i).$$

**期望计数。** 给定 p，计数 q_x 服从 Binomial(n, P(x | p))，因此 E[q_x | p] = n
· P(x | p)。对 p 取期望：

$$\mathbb{E}[q_{\mathbf{x}}] = n \cdot \mathbb{E}\!\left[\prod_{i:\, x_i=1} p_i
\;\cdot\! \prod_{i:\, x_i=0} (1-p_i)\right].$$

由于 p₁, …, pₘ 是独立的，乘积的期望等于各期望的乘积：

$$\mathbb{E}[q_{\mathbf{x}}] = n \cdot \prod_{i:\, x_i=1} \mathbb{E}[p_i] \;\cdo
t\! \prod_{i:\, x_i=0} \mathbb{E}[1-p_i].$$

由于 pᵢ ~ Uniform[0,1]，我们有 E[pᵢ] = 1/2 和 E[1−pᵢ] = 1/2。总共有 m 个因子（每
个坐标一个），因此：

$$\mathbb{E}[q_{\mathbf{x}}] = n \cdot \left(\tfrac{1}{2}\right)^m = \frac{n}{2^
m}.$$

关键在于，这对于**每一个**二元数组 x 都是相同的，与 x 的具体位模式无关。

**对 r/n 的期望。** 设 x⁽¹⁾, x⁽²⁾, …, x⁽ᵏ⁾ 为排序序列中的前 k 个数组。则 r = q_{
x⁽¹⁾} + ⋯ + q_{x⁽ᵏ⁾}。根据期望的线性性质：

$$\mathbb{E}[r] = \sum_{j=1}^{k} \mathbb{E}\!\left[q_{\mathbf{x}^{(j)}}\right] =
 \sum_{j=1}^{k} \frac{n}{2^m} = \frac{k \cdot n}{2^m}.$$

除以 n：

$$\boxed{\mathbb{E}\!\left[\frac{r}{n}\right] = \frac{k}{2^m}.}$$
