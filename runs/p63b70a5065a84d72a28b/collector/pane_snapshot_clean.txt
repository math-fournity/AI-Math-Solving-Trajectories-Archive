odd, where s is its parallel class size. This means every parallel class size s
satisfies s ≡ N−1 (mod 2), i.e., all class sizes share the same parity, opposite

**Determining the parity condition.** If all class sizes have parity p, then N ≡

od 2), i.e., (#classes − 1)·p ≡ 1 (mod 2).

- If p = 0 (all even): 0 ≡ 1, contradiction.
- If p = 1 (all odd): #classes − 1 ≡ 1, so #classes is even.

**Conclusion:** A collection is nice iff all parallel classes have **odd** size
and the **number of parallel classes is even**.
