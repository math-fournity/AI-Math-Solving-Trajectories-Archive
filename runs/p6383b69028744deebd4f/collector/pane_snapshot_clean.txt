### Step 1: Characterize Harmonic functions

Let $p = 491$ (prime, $p \equiv 3 \pmod{4}$). Packets are vectors in $\mathbb{F}
_p^k$, and Signal Resonance is the standard dot product $\langle u, v\rangle = \
sum a_i b_i \pmod{p}$.

**Claim:** Every Harmonic $f$ is a linear orthogonal map, so $m(k) = |O(k, \math
bb{F}_p)|$.

*Proof.* Let $w_i = f(e_i)$. Then $\langle w_i, w_j\rangle = \langle e_i, e_j\ra
ngle = \delta_{ij}$, so $\{w_i\}$ is an orthonormal basis. For any $x = \sum x_j
 e_j$:
$$\langle f(x), w_j\rangle = \langle f(x), f(e_j)\rangle = \langle x, e_j\rangle
 = x_j.$$
Since $\{w_j\}$ is an orthonormal basis, $f(x) = \sum_j \langle f(x), w_j\rangle
\, w_j = \sum_j x_j w_j$, which is linear. The matrix $W = [w_1|\cdots|w_k]$ sat
isfies $W^\top W = I$, so $f$ is orthogonal. ∎

### Step 2: Orders of orthogonal groups

The form $I_k$ has discriminant $\det(I_k)=1$. For even $k=2n$, the type is $O^+
$ iff $(-1)^n$ is a square mod $p$. Since $p\equiv 3\pmod{4}$, $-1$ is a non-squ
are, so:
- $n$ even $\Rightarrow$ type $O^+(2n,p)$, order $2\,p^{n(n-1)}(p^n-1)\prod_{i=1
}^{n-1}(p^{2i}-1)$
- $n$ odd $\Rightarrow$ type $O^-(2n,p)$, order $2\,p^{n(n-1)}(p^n+1)\prod_{i=1}
^{n-1}(p^{2i}-1)$

Combined: $m(2n) = 2\,p^{n(n-1)}\bigl(p^n - (-1)^n\bigr)\prod_{i=1}^{n-1}(p^{2i}
-1)$.

For odd $k = 2n+1$: $m(2n+1) = 2\,p^{n^2}\prod_{i=1}^{n}(p^{2i}-1)$.
