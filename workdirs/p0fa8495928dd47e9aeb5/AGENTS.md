# Problem

A specialized global architecture firm is evaluating the structural integrity of a series of large-scale circular pavilions. Each pavilion is identified by an ID number $n$, representing the total number of load-bearing columns supporting it. The firm is specifically auditing "complex" pavilions—those where $n$ is a composite number—within the range $4 \le n \le 2022$.

A pavilion is deemed "perfectly balanced" if it satisfies a specific weight-distribution property: for every possible team size $k$ of structural sensors that can be installed (where $k$ is any natural number in the range $1 \le k \le \sqrt{n}-1$), the total number of distinct ways to choose a set of $k$ columns from the $n$ available columns to house these sensors must be exactly divisible by the total number of columns $n$.

Based on these criteria, how many complex pavilions in the specified range are perfectly balanced?
