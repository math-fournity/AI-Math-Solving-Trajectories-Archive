# Problem

In a specialized logistics center, two different shipment codes are generated using three distinct, non-zero secret digits: $I$, $K$, and $S$. The first shipment code is the three-digit number $\overline{IKS}$, and the second shipment code is the three-digit number $\overline{KSI}$.

To generate a master security key, a technician multiplies these two codes together ($\overline{IKS} \times \overline{KSI}$). The resulting product is a six-digit integer that ends with the digit $S$.

A strange error occurs in the digital display: every single zero is erased from this six-digit product. When these zeros are removed, the digits that remain (in their original relative order) form exactly the three-digit number $\overline{IKS}$.

Determine the value of the original six-digit product.
