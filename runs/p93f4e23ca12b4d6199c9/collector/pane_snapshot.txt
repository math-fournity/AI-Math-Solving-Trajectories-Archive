## Proof

Let $g(x) = x \ln x$, so $(x^x)^n = e^{n\,g(x)}$.

**Critical point.** $g'(x) = \ln x + 1 = 0 \implies x = 1/e \approx 0.3679$. Sin
ce $g''(x) = 1/x > 0$, this is a **minimum** of $g$ (g is convex).

**Numerator interval $[1/4,\, 1/2]$.** The point $1/e \in [1/4, 1/2]$ is the min
imum, so the maximum of $g$ is at the endpoints. Compute:
$$g(1/4) = \tfrac{1}{4}\ln\tfrac{1}{4} = -\tfrac{1}{2}\ln 2, \qquad g(1/2) = \tf
rac{1}{2}\ln\tfrac{1}{2} = -\tfrac{1}{2}\ln 2.$$
Both endpoints give the same value $g_{\max}^{(1)} = -\tfrac{1}{2}\ln 2$, so $M_
1 := e^{g_{\max}^{(1)}} = 2^{-1/2} = 1/\sqrt{2}$.

**Denominator interval $[1/2,\, 3/4]$.** Here $x > 1/e$, so $g'(x) > 0$ and $g$
is strictly increasing. The maximum is at $x = 3/4$:
$$g_{\max}^{(2)} = g(3/4) = \tfrac{3}{4}\ln\tfrac{3}{4}, \qquad M_2 := e^{g_{\ma
x}^{(2)}} = \left(\tfrac{3}{4}\right)^{3/4}.$$

**Comparison.**
$$M_1 = 2^{-1/2} \approx 0.7071, \qquad M_2 = (3/4)^{3/4} \approx 0.8060.$$
So $M_1 < M_2$, i.e., $M_1/M_2 < 1$.

**Laplace asymptotics.** Both maxima occur at **boundary** points (not interior)
, so each integral contributes a factor of $1/n$ (not $1/\sqrt{n}$).

*Numerator:* Both endpoints are maxima. Near $x=1/4$: $g'(1/4) = \ln(1/4)+1 = 1-
\ln 4 < 0$ (g decreasing to the right), contributing $\frac{e^{n\,g_{\max}^{(1)}
}}{n\,|g'(1/4)|}$. Near $x=1/2$: $g'(1/2) = 1-\ln 2 > 0$ (g increasing to the ri
ght), contributing $\frac{e^{n\,g_{\max}^{(1)}}}{n\,g'(1/2)}$. Thus
$$\int_{1/4}^{1/2} e^{n g(x)}\,dx \sim \frac{e^{n\,g_{\max}^{(1)}}}{n}\left(\fra
c{1}{\ln 4 - 1} + \frac{1}{1 - \ln 2}\right).$$

*Denominator:* Maximum at right endpoint $x=3/4$ with $g'(3/4) = 1 + \ln(3/4) =
1 - \ln(4/3) > 0$. Thus
$$\int_{1/2}^{3/4} e^{n g(x)}\,dx \sim \frac{e^{n\,g_{\max}^{(2)}}}{n}\cdot\frac
{1}{1-\ln(4/3)}.$$

**Ratio:**
$$\frac{\int_{1/4}^{1/2}(x^x)^n\,dx}{\int_{1/2}^{3/4}(x^x)^n\,dx} \sim \left(\fr
ac{M_1}{M_2}\right)^n \cdot \frac{\left(\frac{1}{\ln 4 - 1} + \frac{1}{1-\ln 2}\
right)}{\left(\frac{1}{1-\ln(4/3)}\right)}.$$

The second factor is a positive constant. The first factor is $(M_1/M_2)^n$ with
 $M_1/M_2 < 1$, hence
$$\left(\frac{M_1}{M_2}\right)^n \to 0 \quad \text{as } n\to\infty.$$

Therefore,
$$\boxed{\lim_{n\to\infty}\frac{\int_{1/4}^{1/2}(x^x)^n\,dx}{\int_{1/2}^{3/4}(x^
x)^n\,dx} = 0.}$$
