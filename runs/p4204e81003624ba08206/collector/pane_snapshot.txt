## Proof

Let the roots be $r_1, r_2, \ldots, r_{100} \in (0,1)$. Since $f$ is monic of de
gree $100$,

$$f(x) = \prod_{i=1}^{100}(x - r_i).$$

**Evaluating the given condition.** Since $100$ is even,

$$f(0) = \prod_{i=1}^{100}(-r_i) = (-1)^{100}\prod_{i=1}^{100} r_i = \prod_{i=1}
^{100} r_i > 0,$$

so $|f(0)| = \prod r_i$. Also

$$f(1) = \prod_{i=1}^{100}(1 - r_i) > 0.$$

The condition $|f(0)| = f(1)$ becomes

$$\prod_{i=1}^{100} r_i = \prod_{i=1}^{100}(1-r_i), \qquad\text{i.e.,}\qquad \pr
od_{i=1}^{100}\frac{r_i}{1-r_i} = 1.$$

**Substitution.** Set $t_i = \dfrac{r_i}{1-r_i} > 0$, so $r_i = \dfrac{t_i}{1+t_
i}$. The constraint is

$$\prod_{i=1}^{100} t_i = 1, \qquad\text{equivalently}\qquad \sum_{i=1}^{100} \l
og t_i = 0.$$

The product of the roots is

$$P = \prod_{i=1}^{100} r_i = \prod_{i=1}^{100}\frac{t_i}{1+t_i}.$$

Taking logarithms with $u_i = \log t_i$ (so $\sum u_i = 0$):

$$\log P = \sum_{i=1}^{100}\bigl(\log t_i - \log(1+t_i)\bigr) = -\sum_{i=1}^{100
}\log(1+e^{u_i}).$$

**Applying Jensen's inequality.** The function $g(u) = \log(1+e^u)$ is convex (i
ts second derivative $g''(u) = \dfrac{e^u}{(1+e^u)^2} > 0$). Hence by Jensen,

$$\sum_{i=1}^{100} g(u_i) \;\ge\; 100\cdot g\!\left(\frac{\sum_{i=1}^{100} u_i}{
100}\right) = 100\cdot g(0) = 100\log 2.$$

Therefore

$$\log P = -\sum_{i=1}^{100} g(u_i) \;\le\; -100\log 2 = \log\!\left(2^{-100}\ri
ght),$$

so

$$P \le 2^{-100} = \frac{1}{2^{100}} = \frac{1}{4^{50}}.$$

**Equality.** Equality in Jensen holds when all $u_i$ are equal, i.e. $u_i = 0$
for all $i$, giving $t_i = 1$ and $r_i = \tfrac12$ for every $i$. This is admiss
ible (all roots in $(0,1)$) and satisfies $\prod r_i = \prod(1-r_i) = (1/2)^{100
}$. So the bound is attained.

**Conclusion.** The maximum of the product of the roots is $\dfrac{1}{4^{50}} =
\dfrac{1}{m^{50}}$, giving

$$m = 4.$$
