## Proof

**Statement.** For an unbounded (Lebesgue-measurable) domain $\Omega \subseteq \
mathbb{R}^n$, the Lebesgue integral $\displaystyle\int_\Omega d\mu$ equals the L
ebesgue measure $|\Omega|$.

**Claim: The statement is TRUE.**

---

### Setup and definitions

Let $\Omega \subseteq \mathbb{R}^n$ be a Lebesgue-measurable set (possibly unbou
nded), and let $\mu$ denote Lebesgue measure. The notation $\int_\Omega d\mu$ is
 shorthand for $\int_\Omega \mathbf{1}\, d\mu$, the Lebesgue integral of the con
stant function $f \equiv \mathbf{1}_\Omega$ (the indicator of $\Omega$, extended
 by $0$ outside $\Omega$).

We work in the extended non-negative reals $[0, +\infty]$, so both the integral
and the measure may take the value $+\infty$.

### Key identity

By the very definition of the Lebesgue integral of a non-negative measurable fun
ction,

$$\int_\Omega \mathbf{1}\, d\mu \;=\; \sup\left\{\, \int_\Omega s\, d\mu \;:\; s
 \text{ simple, } 0 \le s \le \mathbf{1} \,\right\}.$$

The constant function $\mathbf{1}$ is itself a simple function (it takes the sin
gle value $1$ on $\Omega$), and it is the **largest** simple function bounded ab
ove by $\mathbf{1}$. Hence the supremum is attained:

$$\int_\Omega \mathbf{1}\, d\mu \;=\; \int_\Omega \mathbf{1}\, d\mu \quad\text{(
tautologically),}$$

and by the definition of the integral of a simple function,

$$\int_\Omega \mathbf{1}\, d\mu \;=\; 1 \cdot \mu(\Omega) \;=\; \mu(\Omega) \;=\
; |\Omega|.$$

This uses only:
- $\mathbf{1}_\Omega$ is non-negative and measurable (since $\Omega$ is measurab
le),
- the integral of a simple function $s = \sum_i a_i\,\mathbf{1}_{A_i}$ is $\sum_
i a_i\,\mu(A_i)$,
- here $a_1 = 1$, $A_1 = \Omega$, giving $1 \cdot \mu(\Omega)$.

### Why unboundedness causes no problem

The standard machine (monotone convergence / approximation by simple functions)
builds the integral of any non-negative measurable function as a supremum over s
imple functions. For $f = \mathbf{1}_\Omega$ this approximation **stabilizes at
the first step**: $\mathbf{1}_\Omega$ is already simple, so no limiting argument
 is needed. In particular:

- **No boundedness of $\Omega$ is ever invoked.** The identity $\int_\Omega \mat
hbf{1}\,d\mu = \mu(\Omega)$ holds for *every* measurable $\Omega$, bounded or no
t.
- If $\Omega$ is unbounded with infinite measure (e.g. $\Omega = \mathbb{R}^n$,
or a half-space, or the complement of a ball), then $|\Omega| = +\infty$, and co
rrespondingly $\int_\Omega \mathbf{1}\,d\mu = +\infty$. Both sides are $+\infty$
, and the equality $+\infty = +\infty$ is valid in $[0,+\infty]$.
- If $\Omega$ is unbounded but has *finite* measure (e.g. a countable union of i
ntervals of rapidly decreasing length whose total length converges, such as $\Om
ega = \bigcup_{k=1}^\infty (k,\, k+2^{-k})$), then $|\Omega| = \sum 2^{-k} = 1 <
 \infty$, and $\int_\Omega \mathbf{1}\,d\mu = 1 = |\Omega|$ as well.

### Verification via truncation (optional cross-check)

For an unbounded $\Omega$, let $\Omega_R = \Omega \cap B_R(0)$ (intersect with t
he ball of radius $R$). Each $\Omega_R$ is bounded and measurable, so

$$\int_{\Omega_R} \mathbf{1}\,d\mu = |\Omega_R| \quad\text{(standard bounded cas
e)}.$$

The sets $\Omega_R$ increase to $\Omega$ as $R \to \infty$. By the **Monotone Co
nvergence Theorem**,

$$\int_\Omega \mathbf{1}\,d\mu = \lim_{R\to\infty} \int_{\Omega_R}\mathbf{1}\,d\
mu = \lim_{R\to\infty} |\Omega_R| = |\Omega|,$$

where the last equality is continuity of measure from below ($\mu(\bigcup_R \Ome
ga_R) = \lim_R \mu(\Omega_R)$). This recovers the same identity without relying
on $\mathbf{1}_\Omega$ being simple, confirming consistency.

### Conclusion

For every Lebesgue-measurable set $\Omega$ — bounded or unbounded —

$$\boxed{\int_\Omega d\mu \;=\; \int_\Omega \mathbf{1}\,d\mu \;=\; \mu(\Omega) \
;=\; |\Omega|},$$

with all quantities understood in $[0,+\infty]$. Unboundedness affects only *whe
ther the common value is finite or $+\infty$*, never the validity of the equalit
y. The statement is **true**.
