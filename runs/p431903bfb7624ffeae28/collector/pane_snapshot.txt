**Claim:** The exponent of convergence is $\rho = 2$.

### Step 1. Convergence for $\lambda > 2$

Consider $f(x,y) = (x^2+y^2)^{-\lambda/2}$, which is radially decreasing. For ea
ch lattice point $(m,n)$ with $m^2+n^2 \geq 2$, let $Q_{m,n} = [m-\tfrac12, m+\t
frac12]\times[n-\tfrac12, n+\tfrac12]$. For any $(x,y)\in Q_{m,n}$, by the trian
gle inequality,
$$\sqrt{x^2+y^2} \leq \sqrt{m^2+n^2} + \tfrac{\sqrt{2}}{2} \leq \sqrt{m^2+n^2}\l
eft(1 + \tfrac{\sqrt{2}/2}{\sqrt{2}}\right) = \tfrac{3}{2}\sqrt{m^2+n^2},$$
since $\sqrt{m^2+n^2}\geq\sqrt{2}$. Hence
$$f(x,y) \geq \left(\tfrac{3}{2}\right)^{-\lambda}(m^2+n^2)^{-\lambda/2} = \left
(\tfrac{3}{2}\right)^{-\lambda}f(m,n),$$
so
$$f(m,n) \leq \left(\tfrac{3}{2}\right)^{\lambda}\int_{Q_{m,n}} f(x,y)\,dx\,dy.$
$

Summing over all $(m,n)$ with $m^2+n^2\geq 2$ (the squares $Q_{m,n}$ are disjoin
t and cover $\mathbb{R}^2$):
$$\sum_{\substack{(m,n)\neq(0,0)\\m^2+n^2\geq 2}} \frac{1}{(m^2+n^2)^{\lambda/2}
} \leq \left(\tfrac{3}{2}\right)^{\lambda}\int_{|z|\geq\, 1/\sqrt{2}} \frac{dx\,
dy}{(x^2+y^2)^{\lambda/2}}.$$

Converting to polar coordinates:
$$\int_{|z|\geq 1/\sqrt{2}} \frac{dx\,dy}{(x^2+y^2)^{\lambda/2}} = 2\pi\int_{1/\
sqrt{2}}^{\infty} r^{1-\lambda}\,dr,$$
which converges if and only if $\lambda - 1 > 1$, i.e., $\lambda > 2$. The finit
ely many terms with $m^2+n^2 < 2$ are harmless. Therefore $\sum 1/|z_n|^\lambda
< +\infty$ for every $\lambda > 2$.

### Step 2. Divergence for $\lambda = 2$ (hence for $\lambda \leq 2$)

We show $\sum_{(m,n)\neq(0,0)} \frac{1}{m^2+n^2} = +\infty$. Let $r_2(N) = |\{(m
,n)\in\mathbb{Z}^2 : m^2+n^2 = N\}|$. Then
$$\sum_{(m,n)\neq(0,0)} \frac{1}{m^2+n^2} = \sum_{N=1}^{\infty} \frac{r_2(N)}{N}
.$$

By Gauss's circle theorem, the partial sums satisfy
$$R(M) := \sum_{N=1}^{M} r_2(N) = \pi M + O(\sqrt{M}).$$

Applying Abel's summation formula:
$$\sum_{N=1}^{M} \frac{r_2(N)}{N} = \frac{R(M)}{M} + \sum_{N=1}^{M-1} \frac{R(N)
}{N(N+1)}.$$

The first term: $\frac{R(M)}{M} = \pi + O(M^{-1/2}) \to \pi$.

The second term splits as:
$$\sum_{N=1}^{M-1} \frac{\pi N + O(\sqrt{N})}{N(N+1)} = \pi\sum_{N=1}^{M-1}\frac
{1}{N+1} + \sum_{N=1}^{M-1}\frac{O(\sqrt{N})}{N(N+1)}.$$

The first sub-sum is $\pi\log M + O(1) \to +\infty$. The second sub-sum is $\sum
 O(N^{-3/2})$, which converges. Therefore
$$\sum_{N=1}^{M} \frac{r_2(N)}{N} = \pi\log M + O(1) \to +\infty.$$

So the sum diverges for $\lambda = 2$. For $\lambda < 2$ and $|z|\geq 1$, we hav
e $|z|^{-\lambda} \geq |z|^{-2}$, so the sum diverges as well.

### Step 3. Conclusion

- For every $\lambda > 2$: $\sum 1/|z_n|^\lambda < +\infty$ (Step 1).
- For every $\lambda \leq 2$: $\sum 1/|z_n|^\lambda = +\infty$ (Step 2).

Therefore
$$\rho = \inf\{\lambda \geq 0 : \textstyle\sum_n |z_n|^{-\lambda} < +\infty\} =
\boxed{2}.$$
