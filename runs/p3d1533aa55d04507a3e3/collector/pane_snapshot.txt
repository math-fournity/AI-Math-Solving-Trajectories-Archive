## Proof

Let $c = \ln\alpha > 0$. The defining condition is $\ln(a_n!) \le cn < \ln((a_n+
1)!)$.

### Step 1: Asymptotics of $\ln a_n$ via Stirling + Lambert W

By Stirling's formula, $\ln(k!) = k\ln k - k + \tfrac12\ln(2\pi k) + O(1/k)$. Si
nce $a_n \to \infty$ (as $\alpha > 1$), we write:

$$cn = a_n \ln a_n - a_n + \tfrac12\ln(2\pi a_n) + \rho_n + O(1/a_n)$$

where $\rho_n := cn - \ln(a_n!) \in [0,\, \ln(a_n+1))$. Setting $u_n := \ln a_n
- 1$ (so $a_n = e^{u_n+1}$):

$$u_n\, e^{u_n} = \frac{cn}{e}\left(1 - \varepsilon_n\right), \qquad \varepsilon
_n := \frac{\tfrac12\ln(2\pi a_n) + \rho_n + O(1/a_n)}{cn}.$$

Since $a_n \ln a_n \sim cn$ (which gives $a_n \sim cn/\ln n$ self-consistently),
 we have $\ln a_n = O(\ln n)$ and $\rho_n = O(\ln n)$, so $\varepsilon_n = O(\ln
 n / n) \to 0$.

By the Lambert W function: $u_n = W\!\bigl(\tfrac{cn(1-\varepsilon_n)}{e}\bigr)$
. Since $W'(x) = \frac{W(x)}{x(1+W(x))} \sim \frac{e}{cn}$ near $x = cn/e$, and
the argument perturbation is $O(\ln n)$:

$$\boxed{\ln a_n = 1 + W(cn/e) + O(\ln n\,/\,n).}$$

### Step 2: Cesàro mean of $\ln a_j$

Summing over $j$:

$$\frac{1}{n}\sum_{j=1}^n \ln a_j = 1 + \frac{1}{n}\sum_{j=1}^n W(cj/e) + \frac{
1}{n}\sum_{j=1}^n O(\ln j\,/\,j).$$

The error sum satisfies $\sum_{j=1}^n O(\ln j/j) = O((\ln n)^2)$, so the last te
rm is $O((\ln n)^2/n) \to 0$.

### Step 3: Asymptotics of $\frac{1}{n}\sum_{j=1}^n W(cj/e)$

Set $h(x) = W(cx/e)$, which is smooth and increasing. For monotone $h$ with $h(n
)\to\infty$:

$$\sum_{j=1}^n h(j) = \int_1^n h(x)\,dx + O(h(n)).$$

**Exact antiderivative.** Via $t = cx/e$ and integration by parts with $u = W(t)
$:

$$\int W(t)\,dt = t\!\left(W(t) - 1 + \frac{1}{W(t)}\right) + C,$$

verified by differentiating: $\frac{d}{dt}\bigl[t(W-1+1/W)\bigr] = (W - 1 + 1/W)
 + tW'(1 - 1/W^2) = W$, using $tW' = W/(1+W)$.

Therefore:

$$\int_1^n W(cx/e)\,dx = n\!\left(W(cn/e) - 1 + \frac{1}{W(cn/e)}\right) - \left
(W(c/e) - 1 + \frac{1}{W(c/e)}\right).$$

Dividing by $n$:

$$\frac{1}{n}\int_1^n h(x)\,dx = W(cn/e) - 1 + \frac{1}{W(cn/e)} + O(1/n).$$

Since $h(n)/n = W(cn/e)/n = O(\ln n / n) \to 0$:

$$\frac{1}{n}\sum_{j=1}^n W(cj/e) = W(cn/e) - 1 + \frac{1}{W(cn/e)} + o(1).$$

### Step 4: The limit

Combining Steps 2 and 3:

$$\frac{1}{n}\sum_{j=1}^n \ln a_j - \ln a_n = \underbrace{\left(\frac{1}{n}\sum_
{j=1}^n W(cj/e) - W(cn/e)\right)}_{\to\; -1 + 0 = -1} + o(1) \;\longrightarrow\;
 -1.$$

The convergence holds because $W(cn/e) \to \infty$ so $1/W(cn/e) \to 0$, and all
 other error terms are $o(1)$.

### Conclusion

$$\lim_{n\to\infty} \frac{\sqrt[n]{a_1 a_2 \cdots a_n}}{a_n} = \exp\!\left(\lim_
{n\to\infty}\left[\frac{1}{n}\sum_{j=1}^n \ln a_j - \ln a_n\right]\right) = e^{-
1} = \boxed{\dfrac{1}{e}}.$$
