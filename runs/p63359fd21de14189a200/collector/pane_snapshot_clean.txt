# Class Scheduling with Penalties and Soft Constraints: NP-hard and NP-complete

## Problem Statement

We consider the **class scheduling problem with penalties**: given a set of cour
ses, a set of time slots (and possibly rooms), a set of hard constraints (must b
e satisfied, e.g., no two courses sharing a student in the same slot, room capac
ity), and a set of soft constraints (each carrying a penalty when violated), fin
d a schedule satisfying all hard constraints that minimizes the total penalty fr
om soft-constraint violations.

We analyze both the **optimization version** (minimize total penalty) and its **
decision version**: given a threshold $K$, does there exist a feasible schedule
(all hard constraints satisfied) with total penalty $\leq K$?

## Claim

- The **decision version** is **NP-complete**.
- The **optimization version** is **NP-hard**.

---

## Part 1: The Decision Version is in NP

Given a candidate schedule (an assignment of each course to a time slot and room
), we can verify in polynomial time:

1. **Hard constraints**: For each hard constraint, check it is satisfied. Confli
ct constraints (no two courses sharing a student in the same slot) require check
ing all pairs — $O(n^2)$ in the worst case, or $O(m)$ where $m$ is the number of
 conflict pairs. Room capacity and other constraints are checked per-course. All
 polynomial.

2. **Total penalty**: For each soft constraint, determine whether it is violated
 by the candidate schedule and add its penalty. This is polynomial in the number
 of soft constraints and courses.

3. **Threshold check**: Compare the computed total penalty to $K$.

Since verification takes polynomial time, the decision version is in NP.

---

## Part 2: NP-hardness — Reduction from Graph $k$-Coloring

**Graph $k$-Coloring** (NP-complete): Given a graph $G = (V, E)$ and a positive
integer $k$, does there exist a proper coloring $f: V \to \{1, 2, \ldots, k\}$ s
uch that for every edge $(u, v) \in E$, $f(u) \neq f(v)$?

### Construction

Given an instance $(G, k)$ of graph $k$-coloring, construct a class scheduling i
nstance as follows:

- **Courses**: For each vertex $v_i \in V$, create a course $c_i$. Thus $|V|$ co
urses.
- **Time slots**: Create exactly $k$ time slots $t_1, t_2, \ldots, t_k$.
- **Hard constraints (conflict constraints)**: For each edge $(v_i, v_j) \in E$,
 add a hard constraint: courses $c_i$ and $c_j$ cannot be assigned to the same t
ime slot. (Interpretation: they share a student.)
- **Soft constraints**: None (or equivalently, all soft constraints have zero pe
nalty).
- **Penalty threshold**: $K = 0$.

This construction is polynomial in $|V| + |E|$.

### Correctness

($\Rightarrow$) Suppose $G$ has a proper $k$-coloring $f: V \to \{1, \ldots, k\}
$. Assign course $c_i$ to time slot $t_{f(v_i)}$. For every edge $(v_i, v_j) \in
 E$, since $f(v_i) \neq f(v_j)$, courses $c_i$ and $c_j$ are in different time s
lots — the hard constraint is satisfied. There are no soft constraints, so total
 penalty $= 0 \leq K$. Thus the scheduling instance has a feasible schedule with
 penalty $\leq K$.

($\Leftarrow$) Suppose the scheduling instance has a feasible schedule with pena
lty $\leq K = 0$. Since all conflict constraints are hard, they must all be sati
sfied: for every edge $(v_i, v_j) \in E$, courses $c_i$ and $c_j$ are in differe
nt time slots. Define $f(v_i)$ = the index of the time slot assigned to $c_i$. S
ince there are exactly $k$ time slots, $f: V \to \{1, \ldots, k\}$. For every ed
ge $(v_i, v_j) \in E$, $f(v_i) \neq f(v_j)$. Thus $f$ is a proper $k$-coloring o
f $G$.

Therefore, $G$ has a proper $k$-coloring **if and only if** the constructed sche
duling instance has a feasible schedule with penalty $\leq 0$.

### Conclusion of Part 2

Since graph $k$-coloring is NP-complete and the reduction is polynomial, the dec
ision version of the class scheduling problem is **NP-hard**.

---

## Part 3: Combining Parts 1 and 2

- The decision version is in NP (Part 1) and NP-hard (Part 2), therefore it is *
*NP-complete**.
- The optimization version (minimize penalty) is at least as hard as its decisio
n version: if we could solve the optimization version in polynomial time, we cou
ld solve the decision version by comparing the optimal penalty to $K$. Since the
 decision version is NP-hard, the optimization version is **NP-hard**. (The opti
mization version is not a decision problem, so "NP-complete" does not directly a
pply to it in the standard formulation.)

---

## Remark on Generalization

The reduction above uses only hard constraints (conflict constraints) and no sof
t constraints. The full problem — with soft constraints carrying penalties, room
 assignments, capacity constraints, teacher availability, etc. — is a **generali
zation** of this basic instance. Adding soft constraints and additional hard con
straints only makes the problem harder (the basic instance is a special case). T
herefore the general class scheduling problem with penalties and soft constraint
s is also NP-hard (decision: NP-complete).

Specifically, any instance of the basic problem (conflict constraints only, $K=0
$) is a valid instance of the general problem (set all soft-constraint penalties
 to zero, or include no soft constraints). So the general problem's decision ver
sion is also NP-hard, and by the same membership-in-NP argument (verifying a sch
edule against all hard and soft constraints is polynomial), it is NP-complete.

---

## Final Answer

The **decision version** of the class scheduling problem with penalties and soft
 constraint violations ("is there a feasible schedule with total penalty $\leq K
$?") is **NP-complete**: it is in NP (a candidate schedule can be verified in po
lynomial time) and NP-hard (graph $k$-coloring reduces to it in polynomial time)
.

The **optimization version** (find a feasible schedule minimizing total penalty)
 is **NP-hard**: it is at least as hard as the NP-complete decision version, and
 being an optimization problem, it is not classified as NP-complete in the stand
ard sense.
