## Solution

We compute $\int_C y\,dx + z\,dy + x\,dz$ where $C$ is the intersection of the c
ylinder $x^2+y^2=1$ and the surface $z=xy$, oriented counterclockwise (viewed fr
om above).

**Apply Stokes' theorem.** Let $\vec{F} = (P,Q,R) = (y,\, z,\, x)$, so the integ
ral is $\int_C \vec{F}\cdot d\vec{r}$.

Choose the capping surface $S$ to be the portion of $z = xy$ lying over the disk
 $D = \{(x,y): x^2+y^2 \le 1\}$. The counterclockwise orientation of $C$ (viewed
 from above) corresponds, by the right-hand rule, to the **upward** normal on $S
$.

**Compute the curl:**
$$\nabla \times \vec{F} = \left(\frac{\partial R}{\partial y}-\frac{\partial Q}{
\partial z},\;\frac{\partial P}{\partial z}-\frac{\partial R}{\partial x},\;\fra
c{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right) = (0-1,\;0-1,\;0-
1) = (-1,\,-1,\,-1).$$

**Compute the normal.** Parametrize $S$ by $\vec{r}(x,y) = (x,\, y,\, xy)$. Then
$$\vec{r}_x = (1,0,y),\qquad \vec{r}_y = (0,1,x),$$
$$\vec{r}_x \times \vec{r}_y = (-y,\,-x,\, 1).$$
The $z$-component is $1>0$, so this is the upward normal — consistent with the c
ounterclockwise orientation.

**Apply Stokes:**
$$\int_C \vec{F}\cdot d\vec{r} = \iint_S (\nabla\times\vec{F})\cdot (\vec{r}_x\t
imes\vec{r}_y)\,dA = \iint_D (-1,\,-1,\,-1)\cdot(-y,\,-x,\,1)\,dA$$
$$= \iint_D (y + x - 1)\,dA.$$

**Evaluate over the disk $D$.** By symmetry,
$$\iint_D x\,dA = 0,\qquad \iint_D y\,dA = 0,\qquad \iint_D 1\,dA = \pi\cdot 1^2
 = \pi.$$

Therefore
$$\int_C y\,dx + z\,dy + x\,dz = 0 + 0 - \pi = \boxed{-\pi}.$$
