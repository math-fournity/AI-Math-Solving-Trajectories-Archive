## Solution

We minimize $J(f) = \int_0^1 (1+x^2)\,f(x)^2\,dx$ subject to $\int_0^1 f(x)\,dx
= 1$, with $f \in C[0,1]$.

**Step 1: Cauchy–Schwarz (lower bound).**

Write $f(x) = \sqrt{1+x^2}\,f(x)\cdot\dfrac{1}{\sqrt{1+x^2}}$ and apply Cauchy–S
chwarz:

$$\left(\int_0^1 f(x)\,dx\right)^2 \le \left(\int_0^1 (1+x^2)\,f(x)^2\,dx\right)
\left(\int_0^1 \frac{dx}{1+x^2}\right).$$

Computing the second factor:

$$\int_0^1 \frac{dx}{1+x^2} = \arctan(x)\Big|_0^1 = \frac{\pi}{4}.$$

Using the constraint $\int_0^1 f\,dx = 1$:

$$1 \le J(f)\cdot\frac{\pi}{4}\quad\Longrightarrow\quad J(f)\ge\frac{4}{\pi}.$$

**Step 2: Equality condition.**

Equality in Cauchy–Schwarz holds iff the two factors are proportional:

$$\sqrt{1+x^2}\,f(x) = c\cdot\frac{1}{\sqrt{1+x^2}}\quad\Longrightarrow\quad f(x
) = \frac{c}{1+x^2}.$$

**Step 3: Determine $c$ from the constraint.**

$$\int_0^1 \frac{c}{1+x^2}\,dx = c\cdot\frac{\pi}{4} = 1\quad\Longrightarrow\qua
d c = \frac{4}{\pi}.$$

So the extremal function is

$$f^*(x) = \frac{4}{\pi(1+x^2)},$$

which is continuous on $[0,1]$, hence admissible ($f^*\in C[0,1]$).

**Step 4: Verify the value is attained.**

$$J(f^*) = \int_0^1 (1+x^2)\cdot\frac{16}{\pi^2(1+x^2)^2}\,dx = \frac{16}{\pi^2}
\int_0^1\frac{dx}{1+x^2} = \frac{16}{\pi^2}\cdot\frac{\pi}{4} = \frac{4}{\pi}.$$

This matches the lower bound, so the minimum is attained.

**Conclusion.** The minimum value of $J(f)$ is

$$\boxed{\dfrac{4}{\pi}}.$$
