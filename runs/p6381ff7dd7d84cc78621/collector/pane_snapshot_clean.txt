## Key Structural Analysis

**Observation 1 (Third-color requirement):** For an edge between two vertices of
 different colors to form, they need a common neighbor of the *third* color. If
X (red) and Y (blue) need a common friend Z, then Z must differ in color from bo
th X and Y, so Z must be green.

**Observation 2 (Two-color components are frozen):** If a connected component us
es only 2 colors (say R and B), no new edges can form within it — every edge for
mation requires a common neighbor of the third color, which doesn't exist in the
 component.

**Theorem (Three-color components become complete tripartite):** If a connected
component contains all 3 colors, the closure makes it a complete tripartite grap
h on its vertices.

*Proof:* Since the component is connected and 3-colored, there exists a path a–b
–c where a, b, c have three distinct colors. Then b is a common neighbor (third
color) of a and c, so edge a–c forms, creating a triangle {a,b,c} (complete trip
artite on 1+1+1).

**Absorption Lemma:** If S is a complete tripartite subgraph (all three color cl
asses nonempty) and vertex v is adjacent to some s ∈ S, then S ∪ {v} becomes com
plete tripartite.

*Proof:* Say v is red, s is blue. Since S is complete tripartite, s is friends w
ith all green vertices in S. Any green vertex g ∈ S is a common neighbor of v an
d every blue vertex b ∈ S (g is friends with v via the edge v–s... wait, more ca
refully: v is friends with s; s is friends with all g ∈ S_G; so v and any g shar
e common blue neighbor s, forming v–g edges). Then v (red) and any blue b ∈ S_B
share common green neighbor (any g ∈ S_G), forming v–b edges. So v connects to a
ll of S_B and S_G. ✓

Since the component is connected, every vertex is reachable from the triangle vi
a a path, and each vertex along the path is adjacent to the already-absorbed set
. By induction, all vertices are absorbed. ✓

**Corollary:** All cross-color pairs become friends **if and only if** the origi
nal graph is connected (which forces all 120 vertices into one 3-colored compone
nt).

*Why "only if":* If the graph is disconnected, there exist vertices in different
 components. Since all three colors appear (30+40+50), some cross-color pair mus
t straddle components — they can never become friends (no common neighbor across
 components).

## Computing M₁ and M₂

The problem reduces to:
- **M₁** = largest M such that every tripartite graph on (30,40,50) with M edges
 is **disconnected**
- **M₂** = smallest M such that every tripartite graph on (30,40,50) with M edge
s is **connected**

**Finding M₁:** A connected graph on 120 vertices requires ≥ 119 edges. So for M
 ≤ 118, *every* graph (tripartite or not) on 120 vertices is disconnected. For M
 = 119, there exists a connected tripartite graph (construct a tree: pick b₁ as
hub, connect all 30 R and 50 G to b₁ giving 80 B–R and B–G edges, then connect t
he remaining 39 B vertices to r₁ giving 39 B–R edges; total 119 edges, all cross
-color, forming a tree). So **M₁ = 118**.

**Finding M₂:** The total edges in a complete tripartite graph on (30,40,50) is
30·40 + 30·50 + 40·50 = 1200 + 1500 + 2000 = **4700**.

The maximum edges in a *disconnected* tripartite graph: partition vertices into
two components and minimize lost cross-component edges. Isolating a single verte
x loses the fewest edges. The optimal isolated vertex is green (largest color cl
ass), losing 30 + 40 = 70 edges (its connections to all R and B vertices). The r

 − 70 = **4630** edges.

No other partition does better: isolating an R vertex loses 90 edges, a B vertex

For M = 4630, a disconnected graph exists (isolated G + complete rest), so not e
very graph is connected. For M = 4631 > D, no disconnected tripartite graph exis
