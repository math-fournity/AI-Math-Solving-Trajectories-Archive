## Proof

Let $t = |x| \in [0,1]$. Define the error $e_n(x) = |x| - f_n(x)$. We prove by i
nduction that for all $n \ge 0$ and all $x \in [-1,1]$,
$$0 \le f_n(x) \le |x|, \qquad \text{equivalently } 0 \le e_n(x) \le |x|.$$

**Base case.** $f_0 = 0$, so $0 \le 0 \le |x|$ and $e_0(x) = |x|$. ✓

**Inductive step.** Assume $0 \le f_n \le |x|$. Then $x^2 - f_n^2 = (|x|-f_n)(|x
|+f_n) \ge 0$, so
$$f_{n+1} = f_n + \tfrac{1}{2}(|x|-f_n)(|x|+f_n) \ge f_n \ge 0.$$
Moreover,
$$|x| - f_{n+1} = (|x|-f_n)\Big(1 - \tfrac{|x|+f_n}{2}\Big).$$
Since $0 \le f_n \le |x| \le 1$, we have $0 \le \tfrac{|x|+f_n}{2} \le 1$, hence
 the factor lies in $[0,1]$, giving $0 \le e_{n+1} \le e_n \le |x|$. ✓

**Recurrence for the error.** Using $f_n = |x| - e_n$, i.e. $|x| + f_n = 2|x| -
e_n$:
$$e_{n+1} = e_n\Big(1 - \tfrac{2|x|-e_n}{2}\Big) = e_n(1 - |x|) + \tfrac{e_n^2}{
2}.$$

**Key bound.** Since $e_n \le |x|$, we have $\tfrac{e_n^2}{2} \le \tfrac{e_n |x|
}{2}$, so
$$e_{n+1} \le e_n(1 - |x|) + \tfrac{e_n |x|}{2} = e_n\Big(1 - \tfrac{|x|}{2}\Big
).$$
Iterating from $e_0 = |x|$:
$$e_n(x) \le |x|\Big(1 - \tfrac{|x|}{2}\Big)^n.$$

**Uniform convergence.** With $u = |x|/2 \in [0, \tfrac12]$, the right-hand side
 is $2u(1-u)^n$. The function $u \mapsto u(1-u)^n$ is maximized on $[0,\tfrac12]
$ at $u^\* = \tfrac{1}{n+1}$ (which lies in $[0,\tfrac12]$ for $n \ge 1$), givin
g
$$\sup_{x \in [-1,1]} e_n(x) \le \frac{2}{n+1}\Big(\frac{n}{n+1}\Big)^n \xrighta
rrow{n\to\infty} 0.$$

Hence $\|f_n - |\cdot|\,||_\infty \to 0$, and the limit in the supremum norm is

$$\boxed{\lim_{n\to\infty} f_n = |x|.}$$
