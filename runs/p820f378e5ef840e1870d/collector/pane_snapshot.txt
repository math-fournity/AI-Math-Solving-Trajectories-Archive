Complexity of the 3D Ising Model Partition Function

Problem Setup

Consider the 3D Ising model on an $n \times n \times n$ lattice $\Lambda$ with
spins $s_i \in {-1,+1}$, Hamiltonian

$$H(\mathbf{s}) = -\sum_{\langle i,j\rangle} J_{ij}, s_i s_j - \sum_i h_i, s_i,$
$

and partition function

$$Z = \sum_{\mathbf{s} \in {-1,+1}^{|\Lambda|}} \exp!\bigl(-\beta,
H(\mathbf{s})\bigr).$$

We are asked whether exactly computing $Z$ belongs to #P or NP.

────────────────────────────────────────────────────────────────────────────────

Step 1: The Partition Function Is a Function Problem, Not a Decision Problem

NP is a class of decision problems (languages): given an input $x$, the answer
is YES or NO. The partition function $Z$ is a number — it is the value of a sum
over $2^{|\Lambda|}$ configurations. Computing $Z$ is a function problem (it
returns a value, not a yes/no verdict).

Therefore, strictly by type, the problem "compute $Z$" cannot be in NP, because
NP contains only decision problems. The natural complexity class for counting/
summation problems is #P.

────────────────────────────────────────────────────────────────────────────────

Step 2: Membership in #P (via the High-Temperature Expansion)

Using the identity $e^{\beta J_{ij} s_i s_j} = \cosh(\beta J_{ij}),(1 + s_i s_j
\tanh(\beta J_{ij}))$, the partition factorizes over edges. Summing over all
spins (each vertex sum $\sum_{s_i=\pm 1} s_i^{d_i}$ vanishes unless $d_i$ is
even) yields the high-temperature expansion:

$$Z = 2^{|\Lambda|}\prod_{\langle i,j\rangle}\cosh(\beta J_{ij});
\sum_{\substack{E' \subseteq E \ E' \text{ even}}} \prod_{(i,j)\in E'}
\tanh(\beta J_{ij}),$$

where the sum runs over all even subgraphs (Eulerian subgraphs — subgraphs in
which every vertex has even degree) of the lattice graph $G=(V,E)$.

When all couplings are equal ($J_{ij}=J$), setting $x = \tanh(\beta J)$ gives

$$Z = 2^{|V|}(\cosh\beta J)^{|E|}; P_G(x), \qquad P_G(x) = \sum_{k=0}^{|E|} a_k,
x^k,$$

where $a_k$ = the number of even subgraphs of $G$ with exactly $k$ edges.

Claim: Computing $a_k$ is in #P.

Proof of claim. A nondeterministic Turing machine, on input $(G, k)$, guesses a
subset $E' \subseteq E$ with $|E'|=k$ and verifies in polynomial time that every
vertex of $G$ has even degree in the subgraph $(V, E')$. The number of accepting
computation paths equals $a_k$. Hence $a_k \in \text{#P}$. $\square$

Since $Z$ is a polynomial-time computable function of the coefficients ${a_k}$
(given $x$), and each $a_k$ is #P-computable, computing $Z$ is in #P (more
precisely, in the closure of #P under polynomial-time Turing reductions, i.e.,
FP$^{\text{#P}}$; with uniform couplings and fixed $\beta$, $Z$ is a single #P
query).

────────────────────────────────────────────────────────────────────────────────

Theorem (Barahona, 1982). Computing the partition function of the 3D Ising model
with general (non-uniform) couplings is #P-hard.

The reduction proceeds as follows:

  1. Ground-state NP-hardness. Barahona showed that finding the ground state
  (minimum-energy configuration) of a 3D Ising spin glass is NP-hard, by
  reducing from the max-cut problem on general graphs. The key geometric fact is
  that the 3D lattice is rich enough to embed arbitrary planar (and sufficiently
  general) graphs as subgraphs of the cubic lattice, so that spin-glass
  frustration patterns can encode arbitrary cut problems.
  2. From NP-hardness to #P-hardness. The partition function encodes the ground-
  state energy in its low-temperature limit. More directly, the Ising partition
  function is a specialization of the Tutte polynomial $T_G(x,y)$:

$$Z_{\text{Ising}} \propto T_G!\Bigl(x=\sqrt{q},e^{2\beta J},;
y=\sqrt{q},e^{-2\beta J}\Bigr) \quad (q=2 \text{ for Ising}).$$

Jaeger, Vertigan, and Welsh (1990) proved that evaluating the Tutte polynomial
is #P-hard at all but a small set of exceptional points. The 3D lattice graph
family is sufficiently general (it contains arbitrary-degree-bounded graphs as
minors/subgraphs) that this #P-hardness transfers. Concretely, one can reduce
#SAT (counting satisfying assignments, the canonical #P-complete problem) to
computing the Ising partition function on a 3D lattice by encoding Boolean
variables as spin variables and clauses as frustration-inducing coupling gadgets
— a standard parsimonious reduction.

Since computing $Z$ is both in #P and #P-hard:

$$\boxed{\text{Computing } Z \text{ for the 3D Ising model is \textbf{#P-
complete}.}}$$
