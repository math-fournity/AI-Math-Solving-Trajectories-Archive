**Answer: Yes.** For every closed set $A \subseteq \mathbb{R}$, there exists an
infinitely differentiable function $f \colon \mathbb{R} \to \mathbb{R}$ with $f^
{-1}(0) = A$.

---

### Proof

**Step 1: Decompose the complement.** Since $A$ is closed, $U := \mathbb{R} \set
minus A$ is open. Every open subset of $\mathbb{R}$ is a countable union of pair
wise disjoint open intervals, so write
$$U = \bigcup_{n=1}^{\infty} I_n, \qquad I_n = (a_n, b_n),$$
where $a_n, b_n \in [-\infty, +\infty]$ and the $I_n$ are pairwise disjoint. (If
 $U = \emptyset$, the union is empty; if $U = \mathbb{R}$, there is a single int
erval $(-\infty,+\infty)$.)

**Step 2: Build a smooth non-negative bump on each interval.** Define $\varphi(t
) = e^{-1/t}$ for $t > 0$ and $\varphi(t) = 0$ for $t \le 0$. It is standard (an
d verified by induction on derivatives) that $\varphi \in C^{\infty}(\mathbb{R})
$, $\varphi \ge 0$, and $\varphi^{(k)}(0) = 0$ for every $k$.

For each interval $I_n = (a_n, b_n)$ define a non-negative $C^\infty$ function $
g_n$ supported on $\overline{I_n}$ and strictly positive on $I_n$:

- **Both endpoints finite:** $g_n(x) = \varphi(x - a_n)\,\varphi(b_n - x)$.
- **$a_n = -\infty$, $b_n$ finite:** $g_n(x) = \varphi(b_n - x)$.
- **$a_n$ finite, $b_n = +\infty$:** $g_n(x) = \varphi(x - a_n)$.
- **$a_n = -\infty$, $b_n = +\infty$ (i.e. $U = \mathbb{R}$):** $g_n(x) = 1$.

In each case $g_n \in C^{\infty}(\mathbb{R})$, $g_n \ge 0$, $g_n > 0$ on $I_n$,
$g_n = 0$ on $\mathbb{R} \setminus I_n$, and every derivative $g_n^{(k)}$ vanish
es at the finite endpoints of $I_n$.

**Step 3: Choose scaling constants to guarantee smooth convergence.** Because th
e intervals $I_n$ are disjoint, the functions $g_n$ have *pairwise disjoint inte
riors of their supports*. However, infinitely many intervals may accumulate at a
 point of $A$, so the naive sum need not converge with all derivatives. We scale
 each bump.

For each $n$, let $M_{n,k} := \sup_{x \in \mathbb{R}} |g_n^{(k)}(x)| < \infty$ (
each $g_n^{(k)}$ is continuous and vanishes outside a bounded set, except for th
e half-line or full-line cases where it is still bounded). Choose $c_n > 0$ smal
l enough that
$$c_n \cdot M_{n,k} \le 2^{-n} \qquad \text{for all } k = 0, 1, \dots, n.$$
This is possible since only finitely many constraints are imposed per $n$ and ea
ch $M_{n,k}$ is finite.

**Step 4: Define $f$ and verify it is $C^\infty$.** Set
$$f(x) := \sum_{n=1}^{\infty} c_n\, g_n(x).$$
All summands are non-negative, so the series is well-defined (possibly $+\infty$
); we show it is finite and $C^\infty$.

Fix any derivative order $k \ge 0$. For $n \ge k$ we have $|c_n g_n^{(k)}(x)| \l
e c_n M_{n,k} \le 2^{-n}$ for all $x$. Hence $\sum_{n \ge k} c_n g_n^{(k)}$ conv
erges uniformly by the Weierstrass $M$-test. The finitely many terms with $n < k
$ are each $C^\infty$. A standard theorem (uniform convergence of derivatives pl
us pointwise convergence of the function) gives, by induction on $k$, that $f \i
n C^{\infty}(\mathbb{R})$ and
$$f^{(k)}(x) = \sum_{n=1}^{\infty} c_n\, g_n^{(k)}(x) \qquad \text{for every } k
 \ge 0.$$
In particular $f$ is finite everywhere (take $k=0$: $\sum c_n g_n(x) \le \sum 2^
{-n} = 1$ once $n \ge 1$... more precisely the tail is bounded by $\sum_{n\ge 1}
 2^{-n} = 1$, and finitely many leading terms are finite).

**Step 5: Identify the zero set.** Since every summand $c_n g_n(x) \ge 0$ and $c
_n > 0$:
$$f(x) = 0 \iff g_n(x) = 0 \text{ for every } n \iff x \notin I_n \text{ for eve
ry } n \iff x \notin U \iff x \in A.$$
Therefore $f^{-1}(0) = A$.

**Step 6: Edge cases.**
- $A = \mathbb{R}$: $U = \emptyset$, the sum is empty, $f \equiv 0$, and $f^{-1}
(0) = \mathbb{R} = A$. ✓
- $A = \emptyset$: $U = \mathbb{R} = (-\infty,+\infty)$, a single interval with
$g_1 \equiv 1$, so $f = c_1 > 0$ everywhere and $f^{-1}(0) = \emptyset = A$. ✓

**Conclusion.** For every closed set $A \subseteq \mathbb{R}$ there exists a fun
ction $f \in C^{\infty}(\mathbb{R})$ (hence continuous) whose zero set is exactl
y $A$. $\blacksquare$
