## Proof

Let $z = e^{i\theta} = \cos\theta + i\sin\theta$ be a point on the unit circle,
with $a = \sqrt{17}$ and $b = i\sqrt{19}$.

**Step 1: Compute the squared distances.**

$$|a - z|^2 = (\sqrt{17} - \cos\theta)^2 + \sin^2\theta = 17 - 2\sqrt{17}\cos\th
eta + 1 = 18 - 2\sqrt{17}\cos\theta.$$

$$|b - z|^2 = \cos^2\theta + (\sqrt{19} - \sin\theta)^2 = 1 + 19 - 2\sqrt{19}\si
n\theta = 20 - 2\sqrt{19}\sin\theta.$$

Setting $x = \cos\theta$, $y = \sin\theta$ (so $x^2 + y^2 = 1$), the ratio to ma
ximize is

$$R = \frac{|a-z|^2}{|b-z|^2} = \frac{18 - 2\sqrt{17}\,x}{20 - 2\sqrt{19}\,y} =
\frac{9 - \sqrt{17}\,x}{10 - \sqrt{19}\,y}.$$

Since $|a-z|$ and $|b-z|$ are both positive on the unit circle (the points $a$,
$b$ lie outside it), maximizing $|a-z|/|b-z|$ is equivalent to maximizing $R$.

**Step 2: Reduce to a tangency condition.**

For a candidate value $t = R$, the equation $\frac{9 - \sqrt{17}\,x}{10 - \sqrt{
19}\,y} = t$ rearranges to the line

$$\sqrt{17}\,x - t\sqrt{19}\,y = 9 - 10t.$$

The extremal values of $t$ occur when this line is **tangent** to the unit circl
e $x^2 + y^2 = 1$, i.e., when the distance from the origin to the line equals $1
$:

$$\frac{|9 - 10t|}{\sqrt{17 + 19t^2}} = 1 \quad\Longrightarrow\quad (9 - 10t)^2
= 17 + 19t^2.$$

**Step 3: Solve the resulting quadratic.**

$$81 - 180t + 100t^2 = 17 + 19t^2,$$
$$81t^2 - 180t + 64 = 0.$$

The discriminant is

$$\Delta = 180^2 - 4\cdot 81\cdot 64 = 32400 - 20736 = 11664 = 108^2.$$

Thus

$$t = \frac{180 \pm 108}{162} \in \left\{\frac{288}{162},\; \frac{72}{162}\right
\} = \left\{\frac{16}{9},\; \frac{4}{9}\right\}.$$

**Step 4: Identify the maximum and verify.**

The two extremal values are $t = \frac{16}{9}$ (maximum) and $t = \frac{4}{9}$ (
minimum). Verification for $t = \frac{16}{9}$:

$$\left(9 - 10\cdot\tfrac{16}{9}\right)^2 = \left(\tfrac{81 - 160}{9}\right)^2 =
 \tfrac{6241}{81}, \qquad 17 + 19\cdot\tfrac{256}{81} = \tfrac{1377 + 4864}{81}
= \tfrac{6241}{81}. \checkmark$$

The tangency point corresponds to a valid point on the unit circle (the line is
indeed tangent, not disjoint), so the value is attained.

**Conclusion.** The maximum possible value of $\dfrac{|a - z|}{|b - z|}$ is $\sq
rt{R_{\max}} = \sqrt{\tfrac{16}{9}} = \dfrac{4}{3}$.
