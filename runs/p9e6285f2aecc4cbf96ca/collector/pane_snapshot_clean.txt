## Solution

We want to compute
$$\|A\| = \sup_{\|f\|\le 1} \|Af\|_\infty, \qquad \text{where } |||f||| = \|f\|_
\infty + \|Af\|_\infty.$$

### Upper bound

For any $f \in C^1[0,1]$ with $|||f||| \le 1$, set $g = Af$, so
$$g(x) = \int_0^x f(t)\,dt, \quad g(0)=0, \quad g' = f.$$

Since $|g(x)| = \left|\int_0^x f(t)\,dt\right| \le x\,\|f\|_\infty \le \|f\|_\in
fty$, we have
$$\|g\|_\infty \le \|f\|_\infty. \tag{1}$$

The constraint $|||f||| \le 1$ gives $\|f\|_\infty + \|g\|_\infty \le 1$, i.e.
$$\|f\|_\infty \le 1 - \|g\|_\infty. \tag{2}$$

Combining (1) and (2):
$$\|g\|_\infty \le 1 - \|g\|_\infty \;\Longrightarrow\; 2\|g\|_\infty \le 1 \;\L
ongrightarrow\; \|Af\|_\infty = \|g\|_\infty \le \tfrac{1}{2}.$$

Hence $\|A\| \le \tfrac{1}{2}$.

### Lower bound (attainment)

Take $f \equiv \tfrac{1}{2}$. Then
$$Af(x) = \int_0^x \tfrac{1}{2}\,dt = \tfrac{x}{2}, \qquad \|f\|_\infty = \tfrac
{1}{2}, \qquad \|Af\|_\infty = \tfrac{1}{2}.$$

So $|||f||| = \tfrac{1}{2} + \tfrac{1}{2} = 1$, and $\|Af\|_\infty = \tfrac{1}{2
}$.

Therefore the supremum is attained and
$$\boxed{\|A\| = \tfrac{1}{2}}.$$

### PROOF COMPLETE
