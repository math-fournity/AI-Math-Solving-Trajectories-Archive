## 解答

**解释说明：** "正交投影全等于同一个三角形" 意味着存在一个位于平面 α 上的固定三
角形 $T = A_0B_0C_0$，且每个空间三角形的投影都等于 $T$（位置和形状相同）。我将证
明其重心的轨迹是一条垂直于 α 且通过 $T$ 的重心的直线。

---

**设定。** 设 $\alpha$ 为固定平面，$T = A_0B_0C_0$ 为 $\alpha$ 中的固定三角形。
设 $\mathbf{n}$ 为垂直于 $\alpha$ 的单位法向量。设 $G_0 = \tfrac{1}{3}(A_0 + B_0
 + C_0)$ 为 $T$ 的重心。

设 $ABC$ 为任意空间三角形，其到 $\alpha$ 的正交投影为 $T$，即 $A$ 投影到 $A_0$，
$B$ 投影到 $B_0$，$C$ 投影到 $C_0$。那么存在实数 $a, b, c$（即顶点在 α 之上的高
度）使得：

$$A = A_0 + a\,\mathbf{n}, \quad B = B_0 + b\,\mathbf{n}, \quad C = C_0 + c\,\ma
thbf{n}.$$

（任何投影到 $A_0$ 的点都具有 $A_0 + t\,\mathbf{n}$ 的形式，其中 $t \in \mathbb{
R}$，因为正交投影是沿着法线方向 $\mathbf{n}$ 进行的。）

**重心的计算。** $ABC$ 的重心为：

$$G = \frac{A+B+C}{3} = \frac{A_0+B_0+C_0}{3} + \frac{a+b+c}{3}\,\mathbf{n} = G_
0 + h\,\mathbf{n},$$

其中 $h := \tfrac{a+b+c}{3} \in \mathbb{R}$。

**$h$ 是任意的。** 参数 $a, b, c$ 是不受约束的实数（任何选择都会产生一个非退化的
空间三角形，因为投影 $A_0B_0C_0$ 是非退化的，所以 $A, B, C$ 不可能共线）。因此 $
h = \tfrac{a+b+c}{3}$ 可以取 $\mathbb{R}$ 中的任何值。具体来说，对于任何所需的 $
h$，选择 $a = b = c = h$ 即可得到一个位于高度 $h$ 处平行于 $\alpha$ 的三角形。

**轨迹。** $G$ 的所有可能位置的集合为：

$$\{\, G_0 + h\,\mathbf{n} : h \in \mathbb{R}\,\},$$

这正是通过 $G_0$ 且方向为 $\mathbf{n}$ 的直线，即 **垂直于 $\alpha$ 且通过固定三
角形 $T$ 的重心的直线**。

**反向包含关系（可达性）。** 反之，该直线上的每一点都是可达到的：给定任何 $h \in
 \mathbb{R}$，三角形 $A_0 + h\,\mathbf{n},\; B_0 + h\,\mathbf{n},\; C_0 + h\,\ma
thbf{n}$ 是一个合法的空间三角形，其投影为 $T$，且重心为 $G_0 + h\,\mathbf{n}$。

---

**结论。** 重心的几何轨迹是一条 **垂直于平面 $\alpha$ 且通过固定（投影）三角形重
心的直线**。
