## Solution

Let $a = 2+\sqrt{3}$ and $b = 2-\sqrt{3}$. Observe:

- $ab = (2+\sqrt{3})(2-\sqrt{3}) = 4 - 3 = 1$, so $b = a^{-1}$.
- $a + b = 4$.
- $0 < b = 2 - \sqrt{3} \approx 0.2679 < 1$.

Define $S_n = a^n + b^n$. Since $a,b$ are roots of $t^2 - 4t + 1 = 0$, the seque
nce satisfies the recurrence
$$S_n = 4S_{n-1} - S_{n-2}, \quad S_0 = 2,\ S_1 = 4.$$
By induction, **$S_n$ is a positive integer for every $n \ge 0$**.

Since $0 < b < 1$, for every $n \ge 1$ we have $0 < b^n < 1$. Therefore
$$a^n = S_n - b^n, \qquad S_n - 1 < a^n < S_n,$$
where both bounds are strict (since $0 < b^n < 1$). Hence $S_n$ is an integer st
rictly greater than $a^n$, and $S_n - 1$ is an integer strictly less than $a^n$,
 giving
$$\lfloor a^n \rfloor = S_n - 1 = a^n + b^n - 1.$$

Applying this with $n = 2019$:

$$\boxed{\left\lfloor \left(2+\sqrt{3}\right)^{2019}\right\rfloor = \left(2+\sqr
t{3}\right)^{2019} + \left(2-\sqrt{3}\right)^{2019} - 1.}$$
