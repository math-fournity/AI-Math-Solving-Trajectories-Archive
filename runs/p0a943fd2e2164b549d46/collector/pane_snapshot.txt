## Solution

Given $\tan x = 5$.

Using the double-angle identities in terms of $\tan x$:

$$\sin 2x = \frac{2\tan x}{1+\tan^2 x}, \qquad \cos 2x = \frac{1-\tan^2 x}{1+\ta
n^2 x}.$$

With $\tan x = 5$, we have $1 + \tan^2 x = 1 + 25 = 26$, so

$$\sin 2x = \frac{2 \cdot 5}{26} = \frac{10}{26} = \frac{5}{13},$$

$$\cos 2x = \frac{1 - 25}{26} = \frac{-24}{26} = -\frac{12}{13}.$$

Now substitute into the expression:

$$\frac{6 + \sin 2x}{1 + \cos 2x} = \frac{6 + \frac{5}{13}}{1 + \left(-\frac{12}
{13}\right)} = \frac{\frac{78}{13} + \frac{5}{13}}{\frac{13}{13} - \frac{12}{13}
} = \frac{\frac{83}{13}}{\frac{1}{13}} = 83.$$

Therefore,

$$\frac{6 + \sin 2x}{1 + \cos 2x} = \boxed{83}.$$
