# Computational Complexity of Verifying Matrix Orthogonality

## Problem

Determine the computational complexity of verifying whether an $n \times n$ matr
ix $A$ is orthogonal, using the matrix product method and fast matrix multiplica
tion algorithms.

## Proof

### Definition and Verification Criterion

An $n \times n$ real matrix $A$ is **orthogonal** if and only if

$$A^T A = I_n,$$

where $A^T$ is the transpose of $A$ and $I_n$ is the $n \times n$ identity matri
x. This single matrix equation encodes all $n^2$ orthogonality conditions on the
 rows (equivalently columns) of $A$:

- The diagonal entries $(A^T A)_{ii} = 1$ enforce that each row has unit norm.
- The off-diagonal entries $(A^T A)_{ij} = 0$ for $i \neq j$ enforce pairwise or
thogonality of distinct rows.

Thus the matrix product method reduces orthogonality verification to: **(1)** co
mpute the product $B = A^T A$, and **(2)** check whether $B = I_n$.

### Step 1 — Computing $A^T A$

Forming $A^T$ from $A$ requires only $O(n^2)$ work (a transpose is a permutation
 of entries, no arithmetic). The dominant cost is the matrix multiplication $A^T
 \cdot A$, which is a product of two $n \times n$ matrices.

Let $\omega$ denote the **matrix multiplication exponent**, i.e., the infimum of
 all exponents $e$ such that two $n \times n$ matrices can be multiplied in $O(n
^e)$ arithmetic operations. Then computing $A^T A$ costs

$$O(n^\omega).$$

**Known values of $\omega$:**

| Algorithm | $\omega$ (approx.) |
|---|---|
| Naive (schoolbook) | $3$ |
| Strassen (1969) | $\log_2 7 \approx 2.807$ |
| Coppersmith–Winograd (1990) | $\approx 2.376$ |
| Stothers / Williams / Le Gall (2012–2014) | $\approx 2.373$ |
| Alman–Williams (2021) / Duan–Wu–Zhou (2025) | $\approx 2.3715$–$2.3716$ |
| Theoretical lower bound | $\omega \geq 2$ |

**Remark on symmetry.** The product $A^T A$ is always symmetric, so one might ho
pe to exploit structure. However, the best known algorithms for computing a symm
etric product $A^T A$ still run in $O(n^\omega)$ time — the symmetry saves at mo
st a constant factor, not the asymptotic exponent. (There is no known method tha
t computes $A^T A$ asymptotically faster than general matrix multiplication.)

### Step 2 — Checking $B = I_n$

Once $B = A^T A$ is computed, verifying $B = I_n$ requires comparing each of the
 $n^2$ entries of $B$ against the identity: $B_{ii} = 1$ and $B_{ij} = 0$ for $i
 \neq j$. This is

$$O(n^2)$$

arithmetic comparisons.

### Combining the Steps

The total cost is:

$$T(n) = \underbrace{O(n^\omega)}_{\text{compute } A^T A} + \underbrace{O(n^2)}_
{\text{check } = I_n} = O(n^\omega),$$

since $\omega \geq 2$, so the $O(n^2)$ verification is dominated by the multipli
cation cost.

### Lower Bound Consideration

The output $A^T A$ has $n^2$ entries, and any algorithm must at least read the i
nput $A$ (which has $n^2$ entries), giving a trivial lower bound of $\Omega(n^2)
$. Whether orthogonality can be verified **faster** than matrix multiplication (
i.e., in $o(n^\omega)$) is an open question. No algorithm is known that verifies
 $A^T A = I$ without essentially computing (or being able to compute) the full p
roduct. In particular:

- **Freivalds' algorithm** (randomized fingerprinting) can verify $AB = C$ for g
iven $A, B, C$ in $O(n^2)$ time with one-sided error. Applied here with $B = A^T
$, $C = I$, this would verify $A^T A = I$ in $O(n^2)$ randomized time — **but**
this requires already having the candidate product, and in our setting we must *
compute* $A^T A$ first (there is no pre-given $C$ to check against except $I$, a
nd Freivalds' check $A^T(Ar) = r$ for random $r$ still requires computing $Ar$ a
nd $A^T(Ar)$, which is two matrix-vector products at $O(n^2)$ each).

  **Important refinement:** Actually, Freivalds-style verification *can* be appl
ied directly: pick a random vector $r \in \mathbb{R}^n$, compute $y = Ar$ ($O(n^
2)$), then compute $z = A^T y$ ($O(n^2)$), and check $z = r$. If $A^T A \neq I$,
 then with high probability $z \neq r$. This gives a **randomized** $O(n^2)$ ver
ification! However, this only gives a *probabilistic* guarantee (Monte Carlo, on
e-sided error). The **deterministic** matrix product method requires the full pr
oduct.

### Summary of Results

**Deterministic (matrix product method):**

$$\boxed{T(n) = O(n^\omega)}$$

where $\omega$ is the matrix multiplication exponent ($\omega = 3$ for schoolboo
k, $\omega = \log_2 7 \approx 2.807$ for Strassen, $\omega \approx 2.373$ for th
e best known algorithms, and $\omega \geq 2$ is the theoretical lower bound).

**Randomized (Freivalds-type fingerprinting):**

$$T(n) = O(n^2)$$

with one-sided error (false positives possible with exponentially small probabil
ity, false negatives impossible), since $A^T A = I$ can be tested by checking $A
^T(Ar) = r$ for a random vector $r$.

### Conclusion

Using the **deterministic matrix product method** with fast matrix multiplicatio
n, verifying orthogonality of an $n \times n$ matrix costs $O(n^\omega)$, where
$\omega$ is the matrix multiplication exponent. The computation of $A^T A$ domin
ates; the final identity check costs only $O(n^2)$. With the best known fast mat
rix multiplication algorithms, this is approximately $O(n^{2.373})$. A randomize
d variant via Freivalds' fingerprint achieves $O(n^2)$.
