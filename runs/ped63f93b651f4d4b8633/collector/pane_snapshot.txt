## Proof

**Claim:** The set of $n \times n$ symmetric copositive matrices is convex.

**Definition.** A symmetric matrix $A \in \mathbb{R}^{n \times n}$ is *copositiv
e* if
$$x^T A x \geq 0 \quad \text{for all } x \in \mathbb{R}^n \text{ with } x \geq 0
.$$
Let $\mathcal{C}_n$ denote the set of all such matrices.

**Proof.** Let $A, B \in \mathcal{C}_n$ be two copositive matrices, and let $\la
mbda \in [0,1]$. We show that $M = \lambda A + (1-\lambda) B \in \mathcal{C}_n$.

First, $M$ is symmetric since $A$ and $B$ are symmetric and $\lambda, (1-\lambda
)$ are real scalars:
$$M^T = \lambda A^T + (1-\lambda) B^T = \lambda A + (1-\lambda) B = M.$$

Now let $x \in \mathbb{R}^n$ with $x \geq 0$ be arbitrary. Then
$$x^T M x = x^T\bigl(\lambda A + (1-\lambda)B\bigr)x = \lambda\, x^T A x + (1-\l
ambda)\, x^T B x.$$

Since $A$ is copositive and $x \geq 0$, we have $x^T A x \geq 0$. Since $B$ is c
opositive and $x \geq 0$, we have $x^T B x \geq 0$. Because $\lambda \in [0,1]$,
 both $\lambda \geq 0$ and $(1-\lambda) \geq 0$. Therefore each term is a produc
t of two nonneg quantities:
$$\lambda\, x^T A x \geq 0 \quad \text{and} \quad (1-\lambda)\, x^T B x \geq 0.$
$

Summing,
$$x^T M x = \lambda\, x^T A x + (1-\lambda)\, x^T B x \geq 0 + 0 = 0.$$

Since $x \geq 0$ was arbitrary, $M$ is copositive, i.e., $M \in \mathcal{C}_n$.

We have shown that for all $A, B \in \mathcal{C}_n$ and all $\lambda \in [0,1]$,
 $\lambda A + (1-\lambda)B \in \mathcal{C}_n$. Hence $\mathcal{C}_n$ is convex.
$\blacksquare$

**Remark.** In fact the same argument shows $\mathcal{C}_n$ is a *convex cone*:
for $\alpha, \beta \geq 0$ and $A, B \in \mathcal{C}_n$, the matrix $\alpha A +
\beta B$ is copositive, since $x^T(\alpha A + \beta B)x = \alpha\, x^T A x + \be
ta\, x^T B x \geq 0$ for all $x \geq 0$. Convexity is the special case $\alpha +
 \beta = 1$.
