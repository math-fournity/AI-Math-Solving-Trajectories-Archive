Looking at this problem, I need to find the minimum number of orthogonal matrice
s whose linear combination equals a standard basis matrix $M_{i,j}$ (the $n \tim
es n$ matrix with 1 in position $(i,j)$ and 0 elsewhere), for $n > 1$.

## Proof

**Claim:** The minimum number is **2**.

### Lower bound: 1 is impossible

A linear combination of a single orthogonal matrix $Q$ is $cQ$ for some scalar $
c$. If $c \neq 0$, then $cQ$ has rank $n$ (since $Q$ is invertible). If $c = 0$,
 then $cQ = 0$ has rank $0$. Since $M_{i,j}$ has rank $1$ and $n > 1$, we have $
1 \neq n$ and $1 \neq 0$, so $M_{i,j}$ cannot be expressed as $cQ$ for any ortho
gonal $Q$ and scalar $c$.

### Upper bound: 2 suffices

We construct two orthogonal matrices $Q_1, Q_2$ and scalars $a = b = \tfrac{1}{2
}$ such that $\tfrac{1}{2}Q_1 + \tfrac{1}{2}Q_2 = M_{i,j}$.

**Case 1: $i \neq j$ (off-diagonal).**

Since $n > 1$, pick any index set. Define $Q_1$ and $Q_2$ as block-diagonal matr
ices:
- On the $2 \times 2$ block indexed by $\{i, j\}$ (ordered as $i$-row, $j$-row):
$$Q_1\big|_{\{i,j\}} = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \quad Q_2\b
ig|_{\{i,j\}} = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$$
- For every remaining coordinate $k \notin \{i, j\}$: set $(Q_1)_{kk} = 1$ and $
(Q_2)_{kk} = -1$.

Both $Q_1$ and $Q_2$ are block-diagonal with orthogonal blocks, hence orthogonal
.

Computing the linear combination on the $\{i,j\}$ block:
$$\tfrac{1}{2}\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} + \tfrac{1}{2}\begin{
pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pma
trix}$$
This places $1$ in the $(i,j)$ position and $0$ in the $(j,i)$ position.

For each remaining diagonal entry $k \notin \{i,j\}$:
$$\tfrac{1}{2}(1) + \tfrac{1}{2}(-1) = 0$$

All off-block entries are $0$ in both $Q_1$ and $Q_2$. Therefore $\tfrac{1}{2}Q_
1 + \tfrac{1}{2}Q_2 = M_{i,j}$.

**Case 2: $i = j$ (diagonal).**

Since $n > 1$, pick any $j \neq i$. Define:
- On the $2 \times 2$ block indexed by $\{i, j\}$:
$$Q_1\big|_{\{i,j\}} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}, \quad Q_2\b
ig|_{\{i,j\}} = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$$
- For every remaining coordinate $k \notin \{i, j\}$: set $(Q_1)_{kk} = 1$ and $
(Q_2)_{kk} = -1$.

Again both are orthogonal. On the block:
$$\tfrac{1}{2}\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} + \tfrac{1}{2}\begin{
pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pma
trix}$$
giving $1$ in position $(i,i)$ and $0$ in position $(j,j)$. For remaining $k \no
tin \{i,j\}$: $\tfrac{1}{2}(1) + \tfrac{1}{2}(-1) = 0$.

Thus $\tfrac{1}{2}Q_1 + \tfrac{1}{2}Q_2 = M_{i,i}$.

### Conclusion

One orthogonal matrix is insufficient (rank obstruction), and two orthogonal mat
rices always suffice (explicit construction). The minimum number is:

$$\boxed{2}$$
