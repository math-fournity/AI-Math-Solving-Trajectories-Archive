Looking at this problem, I need to determine whether a function that is non-zero
 at only countably many points can have a graph dense in ℝ².

## Proof

**Yes, such a function exists.**

**Construction.** Let $\{U_n\}_{n=1}^{\infty}$ be an enumeration of all open rec
tangles in $\mathbb{R}^2$ with rational endpoints (i.e., each $U_n = (a_n, c_n)
\times (b_n, d_n)$ with $a_n, c_n, b_n, d_n \in \mathbb{Q}$). This is a countabl
e collection forming a basis for the topology on $\mathbb{R}^2$.

We inductively select points $(x_n, y_n) \in U_n$ for each $n$ such that:
- $y_n \neq 0$, and
- $x_n \notin \{x_1, \dots, x_{n-1}\}$ (all $x$-coordinates are distinct).

**This selection is always possible.** At step $n$, the rectangle $U_n$ is a non
empty open set, hence uncountable. The forbidden set — points whose $x$-coordina
te lies in the finite set $\{x_1, \dots, x_{n-1}\}$, or whose $y$-coordinate equ
als $0$ — is a finite union of vertical lines together with the $x$-axis. Removi
ng these from $U_n$ leaves a nonempty (indeed uncountable) open set, so a valid
choice $(x_n, y_n)$ exists.

**Define the function** $f: \mathbb{R} \to \mathbb{R}$ by:
$$f(x_n) = y_n \quad \text{for each } n \in \mathbb{N}, \qquad f(x) = 0 \quad \t
ext{for } x \notin \{x_n : n \in \mathbb{N}\}.$$

**The support of $f$ is countable.** The set $\{x : f(x) \neq 0\} = \{x_n : n \i
n \mathbb{N}\}$ is countable by construction.

**The graph of $f$ is dense in $\mathbb{R}^2$.** The graph is $\Gamma(f) = \{(x,
 f(x)) : x \in \mathbb{R}\}$. For each $n$, the point $(x_n, f(x_n)) = (x_n, y_n
)$ lies in $\Gamma(f) \cap U_n$.

Now let $V \subseteq \mathbb{R}^2$ be any nonempty open set. Since $\{U_n\}$ is
a basis, there exists some $n$ with $U_n \subseteq V$. Then $(x_n, y_n) \in \Gam
ma(f) \cap U_n \subseteq \Gamma(f) \cap V$, so $\Gamma(f) \cap V \neq \emptyset$
.

Since every nonempty open set in $\mathbb{R}^2$ intersects $\Gamma(f)$, the grap
h is dense in $\mathbb{R}^2$.

**Remark on why the "function" constraint doesn't obstruct density.** The key su
btlety is that a function's graph has at most one point per vertical line (each
$x$ maps to a single $f(x)$). One might worry this prevents density. However, de
nsity only requires hitting every *open rectangle*, and each open rectangle has
positive width — so it contains a continuum of available $x$-values. At each ste
p of the construction, only finitely many $x$-values have been used, leaving inf
initely many free $x$-values inside the target rectangle. The countability of th
e support is thus sufficient (and in fact, countability of the nonzero-points is
 exactly what makes the inductive construction feasible: we never run out of unu
sed $x$-coordinates).
