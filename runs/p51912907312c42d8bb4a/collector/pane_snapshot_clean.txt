### Setting up the recurrence

Let $N = p+3 = 2020$ threes with $N-1 = 2019$ operators, each i.i.d. uniform on
$\{+,-,\times,\div\}$, evaluated with **standard operator precedence** ($\times,
\div$ bind tighter than $+,-$; equal-precedence operators are left-associative).

Let $A(n)$ = expected value of an expression with $n$ threes.

**Key idea:** With standard precedence, $+$ and $-$ act as separators. The expre
ssion splits into "terms" (maximal runs of 3's joined by $\times,\div$), each pr
eceded by a sign ($+$ or $-$).

Let $L$ = length (number of 3's) of the **first** term. Then:
- $L = k < n$: operators $op_1,\dots,op_{k-1} \in \{\times,\div\}$ and $op_k \in
 \{+,-\}$, with probability $(1/2)^k$.
- $L = n$: all operators are $\times$ or $\div$, with probability $(1/2)^{n-1}$.

### The rest vanishes in expectation

When $L = k < n$, the operator $op_k$ is $+$ or $-$ (equally likely). The remain
der is an expression of $n-k$ threes:
- If $op_k = +$: value $= (\text{first term}) + A(n\!-\!k)$
- If $op_k = -$: value $= (\text{first term}) - A(n\!-\!k)$

Averaging: the remainder contributes $\tfrac{1}{2}A(n\!-\!k) - \tfrac{1}{2}A(n\!
-\!k) = 0$.

### Expected value of a pure $\times/\div$ term

Let $T(k)$ = expected value of $3\;op_1\;3\;\cdots\;op_{k-1}\;3$ with each $op_i
$ uniform on $\{\times,\div\}$, evaluated left-to-right. Setting $S(1)=3$ and $S
(j\!+\!1) = \tfrac{1}{2}(3\,S(j)) + \tfrac{1}{2}(S(j)/3) = \tfrac{5}{3}\,S(j)$:

$$T(k) = S(k) = 3\left(\frac{5}{3}\right)^{k-1}.$$

### Closed form for $A(n)$

$$A(n) = \sum_{k=1}^{n} P(L\!=\!k)\,T(k) = \sum_{k=1}^{n-1}\left(\frac12\right)^
k \cdot 3\left(\frac53\right)^{k-1} + \left(\frac12\right)^{n-1}\cdot 3\left(\fr
ac53\right)^{n-1}.$$

Since $(1/2)^k(5/3)^{k-1} = \tfrac12(5/6)^{k-1}$:

$$A(n) = \frac32\sum_{j=0}^{n-2}\left(\frac56\right)^j + 3\left(\frac56\right)^{
n-1} = \frac32\cdot\frac{1-(5/6)^{n-1}}{1/6} + 3\left(\frac56\right)^{n-1} = 9\!
\left(1-\left(\frac56\right)^{n-1}\right)+3\left(\frac56\right)^{n-1}.$$

$$\boxed{A(n) = 9 - 6\left(\frac56\right)^{n-1}}.$$

**Verification:** $A(1)=9-6=3$ ✓. $A(2)=9-5=4$; direct: $(6+0+9+1)/4=4$ ✓. $A(3)
=9-6\cdot25/36=29/6$; direct enumeration of 16 cases gives $232/48 = 29/6$ ✓.

### Computing the fraction

With $n = 2020$:

$$A(2020) = 9 - 6\cdot\frac{5^{2019}}{6^{2019}} = \frac{9\cdot 6^{2019} - 6\cdot
 5^{2019}}{6^{2019}} = \frac{6\,(9\cdot 6^{2018} - 5^{2019})}{6^{2019}} = \frac{
9\cdot 6^{2018} - 5^{2019}}{6^{2018}}.$$

**Coprimality:** The numerator $9\cdot 6^{2018}-5^{2019}$ is odd (since $9\cdot
6^{2018}\equiv 0$, $5^{2019}\equiv 1 \pmod 2$) and $\equiv 0 - 5^{2019} \equiv -
2^{2019} \equiv 1 \pmod 3$. So it shares no factor with $6^{2018}=2^{2018}\cdot
3^{2018}$. Thus:

$$m = 9\cdot 6^{2018} - 5^{2019},\qquad n = 6^{2018},\qquad \gcd(m,n)=1.$$

### Reducing modulo $p = 2017$

$$m + n = 10\cdot 6^{2018} - 5^{2019}.$$

Since $2017$ is prime, by Fermat's little theorem $a^{2016}\equiv 1\pmod{2017}$
for $\gcd(a,2017)=1$:

- $2018 \bmod 2016 = 2$, so $6^{2018}\equiv 6^2 = 36 \pmod{2017}$.
- $2019 \bmod 2016 = 3$, so $5^{2019}\equiv 5^3 = 125 \pmod{2017}$.

$$m+n \equiv 10\cdot 36 - 125 = 360 - 125 = 235 \pmod{2017}.$$

Since $0 \le 235 < 2017$, the remainder is $\boxed{235}$.
