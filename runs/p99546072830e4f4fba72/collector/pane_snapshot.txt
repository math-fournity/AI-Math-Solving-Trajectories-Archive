# 证明

设 $\{X_n\}$ 为独立同分布 (i.i.d.) 的指数随机变量序列，均值为 $1$，因此对于 $x \
geq 0$，其累积分布函数 (CDF) 为
$$F(x) = 1 - e^{-x}, \qquad x \geq 0,$$
且对于 $x < 0$，有 $F(x) = 0$。尾部分布为
$$\bar{F}(x) = 1 - F(x) = e^{-x}, \qquad x \geq 0.$$

设 $M_n = \max(X_1, \dots, X_n)$。根据独立性，
$$P(M_n \leq y) = F(y)^n.$$

## 归一化序列的选择

我们寻找 $a_n$ 使得 $P(M_n - a_n \leq x) = F(a_n + x)^n$ 收敛到一个非退化的极限
。一个自然的选择是求解 $a_n$，使得 $n\,\bar{F}(a_n)$ 趋于一个正常数。由于 $\bar{
F}(y) = e^{-y}$，
$$n\,\bar{F}(a_n) = n\,e^{-a_n}.$$
令其等于 $1$ 得到 $e^{-a_n} = 1/n$，即
$$\boxed{a_n = \log n.}$$

## 极限的计算

对于固定的 $x \in \mathbb{R}$ 和足够大的 $n$（使得 $\log n + x \geq 0$），我们有
$$P(M_n - \log n \leq x) = P(M_n \leq \log n + x) = \bigl(1 - e^{-(\log n + x)}\
bigr)^{n}.$$

由于 $e^{-\log n} = 1/n$，这变为
$$P(M_n - \log n \leq x) = \left(1 - \frac{e^{-x}}{n}\right)^{n}.$$

使用标准极限 $\left(1 - \frac{c}{n}\right)^{n} \to e^{-c}$（对于常数 $c$），我们
得到
$$\lim_{n\to\infty} P(M_n - \log n \leq x) = e^{-e^{-x}}.$$

## 验证极限是一个合法的、非退化的分布函数

定义 $G(x) = e^{-e^{-x}}$，$x \in \mathbb{R}$（Gumbel 分布）。

- **非退化性**：当 $x \to -\infty$ 时，$e^{-x} \to \infty$，因此 $G(x) = e^{-e^{
-x}} \to 0$。当 $x \to +\infty$ 时，$e^{-x} \to 0$，因此 $G(x) \to e^{0} = 1$。
此外 $G$ 在 $\mathbb{R}$ 上严格递增，且取值在 $(0,1)$ 内，因此它是非退化的。
- **右连续性 / 单调性**：$x \mapsto -e^{-x}$ 是严格递增的，且 $t \mapsto e^{t}$
是严格递增的，因此 $G$ 是严格递增且连续的（实际上是无限可微的）。
- **边界条件**：$\lim_{x\to-\infty}G(x)=0$ 且 $\lim_{x\to+\infty}G(x)=1$。

因此 $G$ 是一个合法的、非退generate的分布函数，它在**所有** $x \in \mathbb{R}$
处连续（因此根据题目要求，收敛性在所有 $x$ 处均成立）。

## 为什么 $a_n = \log n$ 是正确的归一化（简述）

指数分布属于 Gumbel 最大吸引域 (Gumbel domain of attraction for maxima)。辅助函
数为 $h(y) = \bar{F}(y)/\bar{F}'(y) = e^{-y}/e^{-y} = 1$（常数），且特征最大值 $
a_n$ 由 $n\,\bar{F}(a_n) \to 1$ 唯一确定（至多相差 $o(1)$），得出 $a_n = \log n$
。任何 $a_n = \log n + o(1)$ 都会得到相同的极限 $G(x) = e^{-e^{-x}}$。

## 结论

序列 $a_n = \log n$ 满足
$$P\bigl(M_n - \log n \leq x\bigr) \xrightarrow{n\to\infty} G(x) = e^{-e^{-x}},
\qquad x \in \mathbb{R},$$
其中 $G$ 是（标准）Gumbel 分布——一个非退化的、处处连续的分布函数。
