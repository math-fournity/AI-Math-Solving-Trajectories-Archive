## Proof

Consider the equation $x = \tan(x)$. The function $\tan(x)$ has vertical asympto
tes at $x = (k+\tfrac{1}{2})\pi$ for each integer $k$, and on each interval $\bi
g((k-\tfrac{1}{2})\pi,\,(k+\tfrac{1}{2})\pi\big)$ it is strictly increasing from
 $-\infty$ to $+\infty$.

**Existence and location of positive solutions.** For each integer $n \geq 1$, o
n the interval $I_n = \big((n-\tfrac{1}{2})\pi,\,(n+\tfrac{1}{2})\pi\big)$, the
function $f(x) = \tan(x) - x$ satisfies $f \to -\infty$ as $x \to (n-\tfrac{1}{2
})\pi^{+}$ and $f \to +\infty$ as $x \to (n+\tfrac{1}{2})\pi^{-}$. Since $f$ is
continuous and strictly increasing on $I_n$ (as $f'(x) = \sec^2(x) - 1 = \tan^2(
x) \geq 0$, with $f'>0$ except at isolated points), there is exactly one solutio
n $x_n$ in $I_n$. Together with the trivial solution $x_0 = 0$, these give all n
on-negative solutions.

**Asymptotic form of $x_n$.** For large $n$, $x_n$ is large, so $\tan(x_n) = x_n
$ is large, which forces $x_n$ to be close to the right asymptote $(n+\tfrac{1}{
2})\pi$. Write
$$x_n = \left(n+\tfrac{1}{2}\right)\pi - \varepsilon_n, \qquad \varepsilon_n > 0
,\quad \varepsilon_n \to 0.$$

Using $\tan\!\big((n+\tfrac{1}{2})\pi - \varepsilon_n\big) = \cot(\varepsilon_n)
$, the equation $x_n = \tan(x_n)$ becomes
$$\left(n+\tfrac{1}{2}\right)\pi - \varepsilon_n = \cot(\varepsilon_n).$$

Since the right-hand side is dominated by $1/\varepsilon_n$, we get
$$\varepsilon_n = \frac{1}{\left(n+\tfrac{1}{2}\right)\pi} + O\!\left(\frac{1}{n
^3}\right).$$

Therefore
$$x_n = \left(n+\tfrac{1}{2}\right)\pi - \frac{1}{\left(n+\tfrac{1}{2}\right)\pi
} + O\!\left(\frac{1}{n^3}\right).$$

**The limit of consecutive differences.** Compute
$$x_{n+1} - x_n = \pi - \frac{1}{\left(n+\tfrac{3}{2}\right)\pi} + \frac{1}{\lef

dfrac{1}{(n+\tfrac{1}{2})\pi}$ tend to $0$ (their difference is $O(1/n^2)$), and
 the $O(1/n^3)$ term vanishes as well. Hence
$$\lim_{n\to\infty}\,(x_{n+1} - x_n) = \pi.$$
