## 紧自伴算子的正负分解

**定理。** 设 $T$ 为 Hilbert 空间 $\mathcal{H}$ 上的紧自伴算子。则存在唯一的紧自
伴算子 $T_+, T_-$，满足：
1. $T = T_+ + T_-$,
2. $T_+ \geq 0$（正算子，即对所有 $x \in \mathcal{H}$，有 $\langle T_+ x, x\rang
le \geq 0$），
3. $T_- \leq 0$（负算子），
4. $T_+ T_- = 0$。

该分解的构造仅使用紧自伴算子的谱定理，不涉及 $C^*$-代数理论。

---

### 证明

**步骤 1. 紧自伴算子的谱定理。**

由于 $T$ 是紧且自伴的，谱定理（Hilbert–Schmidt 形式）给出了正交分解

$$\mathcal{H} = \ker(T) \oplus \bigoplus_{\lambda \in \Lambda} E_\lambda,$$

其中 $\Lambda \subset \mathbb{R} \setminus \{0\}$ 是至多可数且无非零聚点的（特征
值）集合，每个 $E_\lambda = \ker(T - \lambda I)$ 是对应于非零特征值 $\lambda$ 的
有限维特征空间，且这些子空间两两正交。对于每个 $x \in \mathcal{H}$，我们将其写为

$$x = x_0 + \sum_{\lambda \in \Lambda} x_\lambda, \qquad x_0 \in \ker(T),\quad x
_\lambda \in E_\lambda,$$

该级数在 $\mathcal{H}$ 的范数下收敛，且

$$Tx = \sum_{\lambda \in \Lambda} \lambda\, x_\lambda.$$

（当 $\Lambda$ 为无限时，级数 $\sum_\lambda \lambda x_\lambda$ 在 $\mathcal{H}$
中绝对收敛，因为 $T$ 是紧的，所以 $\lambda \to 0$，且 $\|x_\lambda\| \leq \|x\|$
。）

**步骤 2. 正部和负部的定义。**

将特征值集合划分为
$$\Lambda_+ = \{\lambda \in \Lambda : \lambda > 0\}, \qquad \Lambda_- = \{\lambd
a \in \Lambda : \lambda < 0\}.$$

定义闭合子空间
$$\mathcal{H}_+ = \ker(T) \oplus \bigoplus_{\lambda \in \Lambda_+} E_\lambda, \q
quad \mathcal{H}_- = \bigoplus_{\lambda \in \Lambda_-} E_\lambda.$$

这些是约化子空间（$T$-不变且正交的），且 $\mathcal{H} = \mathcal{H}_+ \oplus \ma
thcal{H}_-$ 为正交直和。设 $P_+, P_-$ 为对应的正交投影，因此 $P_+ + P_- = I$ 且
$P_+ P_- = 0$。

定义
$$T_+ := T P_+ = P_+ T, \qquad T_- := T P_- = P_- T.$$

（等式 $TP_\pm = P_\pm T$ 成立，因为 $\mathcal{H}_\pm$ 是 $T$-不变的，所以 $P_\p
m$ 与 $T$ 可交换。）显然有 $T = T_+ + T_-$，且两者均为紧算子（紧算子与有界算子的
复合仍为紧算子）且自伴（可交换自伴算子的复合）。

**步骤 3. $T_+$ 为正算子，$T_-$ 为负算子。**

对于任意 $x \in \mathcal{H}$，写 $x = x_+ + x_-$，其中 $x_\pm \in \mathcal{H}_\p
m$。则

$$\langle T_+ x, x\rangle = \langle T x_+, x_+\rangle = \sum_{\lambda \in \Lambd
a_+} \lambda \|x_\lambda\|^2 \geq 0,$$

因为每个 $\lambda \in \Lambda_+$ 都是严格正的。因此 $T_+ \geq 0$。同理，

$$\langle T_- x, x\rangle = \langle T x_-, x_-\rangle = \sum_{\lambda \in \Lambd
a_-} \lambda \|x_\lambda\|^2 \leq 0,$$

因为每个 $\lambda \in \Lambda_-$ 都是严格负的。因此 $T_- \leq 0$。

**步骤 4. 正交性 $T_+ T_- = 0$。**

由于 $P_+ P_- = 0$ 且 $P_\pm$ 与 $T$ 可交换，

$$T_+ T_- = (TP_+)(TP_-) = T^2 P_+ P_- = T^2 \cdot 0 = 0.$$

等价地，$T_+$ 的值域包含在 $\mathcal{H}_+$ 中，而 $T_-$ 的值域包含在 $\mathcal{H
}_-$ 中；由于 $\mathcal{H}_+ \perp \mathcal{H}_-$，一个算子将 $\mathcal{H}_-$ 映
入 $\mathcal{H}_-$，另一个将 $\mathcal{H}_+$ 映入 $\mathcal{H}_+$，它们的复合在
两个方向上均为零：$T_+ T_- = 0$ 且 $T_- T_+ = 0$。

**步骤 5. 唯一性。**

假设 $T = A + B$，其中 $A \geq 0$，$B \leq 0$，且 $AB = 0$。由于 $A$ 和 $B$ 是 $
T$ 的多项式/函数——实际上，我们首先注意到 $A$ 和 $B$ 与 $T$ 可交换：由 $AB=0$ 得
$BA = (AB)^* = 0$，且 $AT = A(A+B) = A^2 = (A+B)A = TA$，类似地有 $BT = TB$。因
此 $A$ 和 $B$ 保留了每个特征空间 $E_\lambda$（以及 $\ker T$）。

在 $E_\lambda$ 上，$T = \lambda I$，所以 $A|_{E_\lambda} + B|_{E_\lambda} = \lam
bda I$，且 $A|_{E_\lambda} \geq 0$，$B|_{E_\lambda} \leq 0$，$A|_{E_\lambda} B|_
{E_\lambda} = 0$。若 $\lambda > 0$：对于 $v \in E_\lambda$，$\langle Av, v\rangl
e + \langle Bv, v\rangle = \lambda\|v\|^2 > 0$，且 $\langle Bv,v\rangle \leq 0$
，所以 $\langle Av, v\rangle \geq \lambda\|v\|^2 > 0$，这迫使 $Bv = 0$（否则 $\l
angle Bv,v\rangle < 0$ 且 $AB=0$ 意味着 $A$ 在 $B$ 的值域上为零，产生矛盾），因
此 $Av = \lambda v$，$Bv = 0$。即 $A|_{E_\lambda} = \lambda I = T_+|_{E_\lambda}
$，$B|_{E_\lambda} = 0 = T_-|_{E_\lambda}$。若 $\lambda < 0$，同理可得 $A|_{E_\l
ambda} = 0$，$B|_{E_\lambda} = \lambda I$。在 $\ker T$ 上，$A + B = 0$，且 $A \g
eq 0$，$B \leq 0$，$AB = 0$ 迫使 $A = B = 0$。因此 $A = T_+$ 且 $B = T_-$。$\squ
are$

---

**方法总结。** 该分解是通过**符号分割的谱分解**实现的：将 $T$ 的非零特征值分离为
正特征值 $\Lambda_+$ 和负特征值 $\Lambda_-$，设 $\mathcal{H}_\pm$ 为对应特征空间
（正部包含 $\ker T$）的张量积，并定义 $T_\pm = T P_\pm$，其中 $P_\pm$ 为对应的正
交投影。$T_\pm$ 的正/负性来自于对应特征值的符号，而正交性 $T_+ T_- = 0$ 则源于 $
\mathcal{H}_+$ 和 $\mathcal{H}_-$ 的正交性以及投影的乘积 $P_+ P_- = 0$。整个过程
仅使用了**紧自伴算子的谱定理**（一种 Hilbert 空间结果），并未使用任何 $C^*$-代数
理论。
