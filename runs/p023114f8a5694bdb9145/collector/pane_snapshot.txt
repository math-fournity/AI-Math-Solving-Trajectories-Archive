## Proof

Since $a$ is a root of order $k$ of $P(X) - P(a)$, we can write
$$P(X) - P(a) = (X-a)^k Q(X)$$
where $Q \in \mathbb{C}[X]$ and $Q(a) \neq 0$.

Set $w = P(a) \neq 0$ and parametrize the circle by $z = a + \rho e^{i\theta}$,
$\theta \in [0,2\pi)$. Expanding $P$ around $a$:
$$P(a + \rho e^{i\theta}) = w + \sum_{j=k}^{d} b_j\, \rho^j e^{ij\theta},$$
where $d = \deg P$, $b_k = Q(a) \neq 0$, and the $b_j$ are constants (coefficien
ts of the Taylor expansion of $P$ at $a$, which is just $P$ itself rewritten).

**Computing $|P(z)|^2 - |w|^2$.** Since $\rho$ is real, $\overline{e^{ij\theta}}
 = e^{-ij\theta}$, so
$$|P(a+\rho e^{i\theta})|^2 = \left(w + \sum_{j \ge k} b_j \rho^j e^{ij\theta}\r
ight)\!\left(\overline{w} + \sum_{j \ge k} \overline{b_j}\, \rho^j e^{-ij\theta}
\right).$$

Expanding:
$$|P|^2 - |w|^2 = 2\sum_{j \ge k} \operatorname{Re}\!\big(\overline{w}\, b_j\, e
^{ij\theta}\big)\,\rho^j \;+\; \sum_{j,\ell \ge k} b_j \overline{b_\ell}\, e^{i(
j-\ell)\theta}\,\rho^{j+\ell}.$$

The lowest-order term in $\rho$ comes from $j = k$ in the first sum:
$$2\,\operatorname{Re}\!\big(\overline{w}\, b_k\, e^{ik\theta}\big)\,\rho^k.$$
All remaining terms are $O(\rho^{k+1})$ (from $j = k+1$ in the first sum) or $O(
\rho^{2k})$ (from the double sum with $j = \ell = k$), both of which are $o(\rho
^k)$.

Define $c := \overline{w}\, b_k = \overline{P(a)}\, Q(a)$. Since $P(a) \neq 0$ a
nd $Q(a) \neq 0$, we have $c \neq 0$. Write $c = |c|\,e^{i\varphi}$. Then
$$|P(a+\rho e^{i\theta})|^2 - |w|^2 = 2\,|c|\,\rho^k \cos(k\theta + \varphi) + \
rho^{k+1}\,H(\theta,\rho),$$
where $H$ is a real-analytic function of $(\theta,\rho)$, bounded for $\rho$ in
a neighborhood of $0$.

**Rescaling.** Define
$$F(\theta, \rho) := \frac{|P(a+\rho e^{i\theta})|^2 - |w|^2}{2\,|c|\,\rho^k} =
\cos(k\theta + \varphi) + \rho\,\widetilde{H}(\theta,\rho),$$
where $\widetilde{H} = H/(2|c|)$ is bounded. Then $|P(z)| = |P(a)|$ if and only
if $F(\theta,\rho) = 0$.

**The unperturbed equation ($\rho = 0$).** At $\rho = 0$:
$$F(\theta, 0) = \cos(k\theta + \varphi).$$
This has exactly $2k$ zeros in $[0, 2\pi)$, namely
$$\theta_n^{(0)} = \frac{\pi/2 - \varphi + n\pi}{k}, \qquad n = 0, 1, \dots, 2k-
1.$$
At each such zero, the derivative with respect to $\theta$ is
$$\frac{\partial F}{\partial \theta}\big(\theta_n^{(0)}, 0\big) = -k\sin(k\theta
_n^{(0)} + \varphi) = -k\sin\!\left(\tfrac{\pi}{2} + n\pi\right) = \pm k \neq 0.
$$

**Applying the Implicit Function Theorem.** Since $\partial F/\partial\theta \ne
q 0$ at each $(\theta_n^{(0)}, 0)$, the Implicit Function Theorem guarantees: fo
r each $n \in \{0,\dots,2k-1\}$, there exist $\rho_n > 0$ and a smooth function
$\theta_n : [0, \rho_n] \to \mathbb{R}$ with $\theta_n(0) = \theta_n^{(0)}$ and
$$F\big(\theta_n(\rho),\, \rho\big) = 0 \quad \text{for all } \rho \in [0, \rho_
n].$$

**Distinctness for small $\rho$.** The $2k$ initial values $\theta_0^{(0)}, \dot
s, \theta_{2k-1}^{(0)}$ are distinct modulo $2\pi$. By continuity, $\theta_n(\rh
o) \to \theta_n^{(0)}$ as $\rho \to 0^+$, so there exists $\rho_0 > 0$ (with $\r
ho_0 \le \min_n \rho_n$) such that for all $0 < \rho \le \rho_0$, the values $\t
heta_0(\rho), \dots, \theta_{2k-1}(\rho)$ remain pairwise distinct modulo $2\pi$
.

**Conclusion.** For every $0 < \rho \le \rho_0$, the $2k$ points
$$z_n = a + \rho\, e^{i\theta_n(\rho)}, \qquad n = 0, 1, \dots, 2k-1,$$
are $2k$ distinct points on the circle $\{z : |z - a| = \rho\}$, and each satisf
ies
$$|P(z_n)|^2 = |P(a)|^2, \quad\text{i.e.,}\quad |P(z_n)| = |P(a)|.$$

This completes the proof. $\blacksquare$
