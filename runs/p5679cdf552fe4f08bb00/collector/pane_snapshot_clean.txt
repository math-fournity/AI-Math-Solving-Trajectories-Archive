## Proof

We determine the cardinality of the family of all countable subsets of ℝ, i.e.

$$\mathcal{C} = \{ A \subseteq \mathbb{R} : |A| \le \aleph_0 \}.$$

We show $|\mathcal{C}| = \mathfrak{c} = 2^{\aleph_0}$.

### Lower bound: $|\mathcal{C}| \ge \mathfrak{c}$

For each $x \in \mathbb{R}$, the singleton $\{x\}$ is a countable subset of $\ma
thbb{R}$. The map $x \mapsto \{x\}$ is an injection $\mathbb{R} \to \mathcal{C}$
, so

$$|\mathcal{C}| \ge |\mathbb{R}| = \mathfrak{c}.$$

### Upper bound: $|\mathcal{C}| \le \mathfrak{c}$

Every countable subset $A \subseteq \mathbb{R}$ is the range of some sequence in
 $\mathbb{R}$. Indeed:

- If $A$ is countably infinite, enumerate it as $A = \{a_0, a_1, a_2, \dots\}$;
then $A = \operatorname{range}(f)$ for $f: \mathbb{N} \to \mathbb{R}$, $f(n) = a
_n$.
- If $A$ is finite, say $A = \{a_0, \dots, a_{k-1}\}$, define $f: \mathbb{N} \to
 \mathbb{R}$ by $f(n) = a_{n \bmod k}$; then $A = \operatorname{range}(f)$.

Thus the surjection

$$\operatorname{range}: \mathbb{R}^{\mathbb{N}} \twoheadrightarrow \mathcal{C},
\qquad f \mapsto \operatorname{range}(f)$$

shows $|\mathcal{C}| \le |\mathbb{R}^{\mathbb{N}}|$.

Now compute:

$$|\mathbb{R}^{\mathbb{N}}| = |\mathbb{R}|^{|\mathbb{N}|} = \mathfrak{c}^{\aleph
_0} = (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0 \cdot \aleph_0} = 2^{\aleph_0} = \
mathfrak{c},$$

using $\aleph_0 \cdot \aleph_0 = \aleph_0$. Therefore

$$|\mathcal{C}| \le \mathfrak{c}.$$

### Conclusion

Combining both bounds:

$$\mathfrak{c} \le |\mathcal{C}| \le \mathfrak{c},$$

so by the Cantor–Bernstein theorem,

$$|\mathcal{C}| = \mathfrak{c} = 2^{\aleph_0}.$$

The number of distinct countable subsets of $\mathbb{R}$ is exactly $2^{\aleph_0
}$, the cardinality of the continuum.
