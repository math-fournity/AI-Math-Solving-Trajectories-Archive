## Solution

We count nondegenerate triangles formed by 3 points from the 5×5 integer grid $\
{(s,t) : 0 \le s \le 4,\; 0 \le t \le 4,\; s,t \in \mathbb{Z}\}$, which has **25
 points**.

**Total triples:** $\binom{25}{3} = \frac{25 \cdot 24 \cdot 23}{6} = 2300$.

We subtract all **collinear triples**. A line through $k$ grid points contribute
s $\binom{k}{3}$ collinear triples. We enumerate every line with $\geq 3$ grid p
oints by its slope.

### Axis-aligned lines

- **Horizontal** ($t = \text{const}$): 5 lines, each with 5 points → $5 \cdot \b
inom{5}{3} = 5 \cdot 10 = 50$.
- **Vertical** ($s = \text{const}$): 5 lines, each with 5 points → $5 \cdot 10 =
 50$.

### Slope $+1$ lines ($t - s = c$)

| $c$ | Points | $\binom{k}{3}$ |
|-----|--------|----------------|
| $0$ | 5 | 10 |
| $\pm 1$ | 4 each | $4 + 4 = 8$ |
| $\pm 2$ | 3 each | $1 + 1 = 2$ |

Total: $10 + 8 + 2 = \mathbf{20}$.

### Slope $-1$ lines ($t + s = c$)

| $c$ | Points | $\binom{k}{3}$ |
|-----|--------|----------------|
| $4$ | 5 | 10 |
| $3, 5$ | 4 each | $4 + 4 = 8$ |
| $2, 6$ | 3 each | $1 + 1 = 2$ |

Total: $10 + 8 + 2 = \mathbf{20}$.

### Other slopes

A primitive direction $(\Delta s, \Delta t)$ with $\gcd(|\Delta s|,|\Delta t|)=1
$ yields $\geq 3$ grid points only if $2|\Delta s| \leq 4$ and $2|\Delta t| \leq
 4$, i.e., $|\Delta s|, |\Delta t| \leq 2$. The remaining primitive directions (
beyond those already counted) are $(2,1),\, (1,2),\, (2,-1),\, (1,-2)$. Each pro
duces exactly 3 lines of exactly 3 points:

- **Slope $\tfrac{1}{2}$** (direction $(2,1)$): $(0,0),(2,1),(4,2)$; $(0,1),(2,2
),(4,3)$; $(0,2),(2,3),(4,4)$ → $3 \cdot \binom{3}{3} = \mathbf{3}$.
- **Slope $2$** (direction $(1,2)$): $(0,0),(1,2),(2,4)$; $(1,0),(2,2),(3,4)$; $
(2,0),(3,2),(4,4)$ → $\mathbf{3}$.
- **Slope $-\tfrac{1}{2}$** (direction $(2,-1)$): $(0,2),(2,1),(4,0)$; $(0,3),(2
,2),(4,1)$; $(0,4),(2,3),(4,2)$ → $\mathbf{3}$.
- **Slope $-2$** (direction $(1,-2)$): $(0,4),(1,2),(2,0)$; $(1,4),(2,2),(3,0)$;
 $(2,4),(3,2),(4,0)$ → $\mathbf{3}$.

No line with these slopes can have 4+ points (3 steps would exceed the grid). No
 other primitive directions fit within the grid for 3 points.

### Total collinear triples

$$50 + 50 + 20 + 20 + 3 + 3 + 3 + 3 = 152.$$

Each collinear triple lies on a unique line, and lines of distinct slopes (or di
stinct intercepts) are distinct, so there is no double-counting.

### Final count

$$\binom{25}{3} - 152 = 2300 - 152 = \boxed{2148}.$$
