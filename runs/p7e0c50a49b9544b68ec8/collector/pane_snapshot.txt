# 波方程 $u_{tt} = c^2 u_{xx}$ 的解

## 问题

求解波方程
$$u_{tt} = c^2 u_{xx}$$
其初始条件为
$$u(x, 0) = f(x), \qquad u_t(x, 0) = g(x).$$

## 解

**第一步：变量代换。** 引入特征坐标
$$\xi = x + ct, \qquad \eta = x - ct.$$
设 $u(x,t) = U(\xi, \eta)$。通过链式法则，
$$u_x = U_\xi + U_\eta, \qquad u_{xx} = U_{\xi\xi} + 2U_{\xi\eta} + U_{\eta\eta}
,$$
$$u_t = cU_\xi - cU_\eta, \qquad u_{tt} = c^2(U_{\xi\xi} - 2U_{\xi\eta} + U_{\et
a\eta}).$$
代入 $u_{tt} = c^2 u_{xx}$ 得到
$$c^2(U_{\xi\xi} - 2U_{\xi\eta} + U_{\eta\eta}) = c^2(U_{\xi\xi} + 2U_{\xi\eta}
+ U_{\eta\eta}),$$
化简后得 $-4c^2 U_{\xi\eta} = 0$，即
$$U_{\xi\eta} = 0.$$

**第二步：通解。** 对 $\xi$ 积分得 $U_\eta = \varphi(\eta)$（$\xi$ 的任意函数）
。对 $\eta$ 积分得
$$U(\xi, \eta) = \Phi(\xi) + \Psi(\eta),$$
其中 $\Phi, \Psi$ 为任意 $C^2$ 函数。回到 $(x,t)$ 坐标，
$$u(x,t) = \Phi(x + ct) + \Psi(x - ct). \tag{1}$$

**第三步：应用初始条件。** 由 $u(x,0) = f(x)$，
$$\Phi(x) + \Psi(x) = f(x). \tag{2}$$
由 $u_t(x,0) = g(x)$，由于 $u_t = c\Phi'(x+ct) - c\Psi'(x-ct)$，在 $t=0$ 时，
$$c\Phi'(x) - c\Psi'(x) = g(x) \implies \Phi'(x) - \Psi'(x) = \frac{g(x)}{c}. \t
ag{3}$$

对 (3) 从 $x_0$ 到 $x$ 积分：
$$\Phi(x) - \Psi(x) = \frac{1}{c}\int_{x_0}^{x} g(s)\,ds + \Phi(x_0) - \Psi(x_0)
.$$
设 $K = \Phi(x_0) - \Psi(x_0)$。与 (2) 联立求解：
$$\Phi(x) = \frac{1}{2}f(x) + \frac{1}{2c}\int_{x_0}^{x} g(s)\,ds + \frac{K}{2},
$$
$$\Psi(x) = \frac{1}{2}f(x) - \frac{1}{2c}\int_{x_0}^{x} g(s)\,ds - \frac{K}{2}.
$$

**第四步：d'Alembert 公式。** 将 $\Phi, \Psi$ 代入 (1)，取 $x_0$ 为任意方便的参
考点（常数 $K/2$ 项抵消）：
$$u(x,t) = \Phi(x+ct) + \Psi(x-ct)$$
$$= \frac{1}{2}f(x+ct) + \frac{1}{2c}\int_{x_0}^{x+ct} g(s)\,ds + \frac{1}{2}f(x
-ct) - \frac{1}{2c}\int_{x_0}^{x-ct} g(s)\,ds$$
$$= \frac{1}{2}\bigl[f(x+ct) + f(x-ct)\bigr] + \frac{1}{2c}\int_{x-ct}^{x+ct} g(
s)\,ds.$$

## 结果

$$\boxed{\,u(x,t) = \frac{1}{2}\bigl[f(x+ct) + f(x-ct)\bigr] + \frac{1}{2c}\int_
{x-ct}^{x+ct} g(s)\,ds\,}$$

## 验证

- **初始位移：** 在 $t=0$ 时，$u(x,0) = \frac{1}{2}[f(x)+f(x)] + \frac{1}{2c}\in
t_x^x g\,ds = f(x) + 0 = f(x).$ ✓
- **初始速度：** $u_t = \frac{c}{2}[f'(x+ct) - f'(x-ct)] + \frac{1}{2}[g(x+ct) +
 g(x-ct)]$，因此在 $t=0$ 时，$u_t(x,0) = 0 + g(x) = g(x).$ ✓
- **PDE：** $u_{tt} = \frac{c^2}{2}[f''(x+ct)+f''(x-ct)] + \frac{c}{2}[g'(x+ct)-
g'(x-ct)]$，且 $u_{xx} = \frac{1}{2}[f''(x+ct)+f''(x-ct)] + \frac{1}{2}[g'(x+ct)
-g'(x-ct)]$，因此 $u_{tt} = c^2 u_{xx}.$ ✓
