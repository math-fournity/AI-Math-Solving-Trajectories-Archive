## Proof

**Setup.** Each $A_i \in \mathbb{R}^{p \times n}$ (with $p < n$) has reduced SVD
 $A_i = V_i \Sigma_i U_i^\top$, where $U_i \in \mathbb{R}^{n \times p}$ has orth
onormal columns, $V_i \in \mathbb{R}^{p \times p}$ is orthogonal, and $\Sigma_i
\in \mathbb{R}^{p \times p}$ is diagonal. The matrix $P_i := U_i U_i^\top \in \m
athbb{R}^{n \times n}$ is the orthogonal projector onto the column space $S_i :=
 \operatorname{col}(U_i)$, a $p$-dimensional subspace of $\mathbb{R}^n$. We stud
y $S^{(m)} := \sum_{i=1}^m P_i$ and seek the minimum $m$ for which $S^{(m)}$ is
full rank (rank $n$).

**Key fact (rank of a sum of projectors).** For orthogonal projectors $P_1, \dot
s, P_m$ onto subspaces $S_1, \dots, S_m$,
$$\operatorname{rank}\!\Big(\sum_{i=1}^m P_i\Big) = \dim\big(\operatorname{span}
(S_1, \dots, S_m)\big).$$
*Proof of fact.* Each $P_i$ is positive semidefinite with $\operatorname{im}(P_i
) = S_i$ and $\ker(P_i) = S_i^\perp$. The sum $S^{(m)} = \sum P_i$ is positive s
emidefinite. Its kernel is
$$\ker(S^{(m)}) = \{x : x^\top S^{(m)} x = 0\} = \{x : \sum_i \|P_i x\|^2 = 0\}
= \bigcap_{i=1}^m \ker(P_i) = \bigcap_{i=1}^m S_i^\perp = \big(\operatorname{spa
n}(S_1,\dots,S_m)\big)^\perp.$$
Hence $\operatorname{rank}(S^{(m)}) = n - \dim\ker(S^{(m)}) = \dim(\operatorname
{span}(S_1,\dots,S_m))$. $\square$

**Upper bound on the span.** Each $S_i$ is $p$-dimensional, so $\dim(\operatorna
me{span}(S_1,\dots,S_m)) \le mp$. Therefore
$$\operatorname{rank}(S^{(m)}) \le mp.$$
For full rank $n$, we **must** have $mp \ge n$, i.e.,
$$m \ge \left\lceil \frac{n}{p} \right\rceil. \tag{$\star$}$$

**Generic (Haar) subspaces attain the bound.** Since $A_i$ are i.i.d. Gaussian,
each column space $S_i$ is distributed according to the Haar measure on the Gras
smannian $\mathrm{Gr}(p, n)$, and the $S_i$ are independent. We show that for $m
$ independent Haar-random $p$-dimensional subspaces, $\dim(\operatorname{span}(S
_1,\dots,S_m)) = \min(n, mp)$ almost surely.

Proceed by induction on $m$. For $m=1$ this is $\dim(S_1) = p = \min(n,p)$. Supp
ose $\dim(\operatorname{span}(S_1,\dots,S_{m-1})) = \min(n, (m-1)p) =: d < n$. T
hen $S_m$ is Haar-distributed and independent of $W := \operatorname{span}(S_1,\
dots,S_{m-1})$. The intersection $S_m \cap W$ has dimension $\max(0, p + d - n)$
 almost surely (a Haar-random $p$-plane meets a fixed $d$-plane in the generic d
imension). Therefore
$$\dim(\operatorname{span}(S_1,\dots,S_m)) = \dim(W + S_m) = d + p - \dim(W \cap
 S_m) = d + p - \max(0, p+d-n).$$
If $d + p \le n$, this gives $d + p = \min(n, mp)$. If $d + p > n$, this gives $
d + p - (p + d - n) = n = \min(n, mp)$. In both cases the induction holds. $\squ
are$

**Conclusion.** Combining the two parts: with Haar-distributed $U_i$,
$$\operatorname{rank}\!\Big(\sum_{i=1}^m U_i U_i^\top\Big) = \min(n,\, mp) \quad
 \text{almost surely.}$$
This equals $n$ (full rank) if and only if $mp \ge n$. The necessary condition (
$\star$) is also sufficient almost surely. Hence the minimum value is

$$\boxed{m = \left\lceil \dfrac{n}{p} \right\rceil.}$$
