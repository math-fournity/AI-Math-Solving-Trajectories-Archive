## Proof

Let $\lambda_{i,1}, \lambda_{i,2}, \dots, \lambda_{i,n}$ denote the eigenvalues
of $A_i$ (over $\mathbb{C}$, counted with algebraic multiplicity). The key obser
vation is that the matrix condition $A_1^k + A_2^k + \cdots + A_m^k = 0$ already
 implies the trace condition, since taking the trace of both sides gives
$$\operatorname{Tr}(A_1^k) + \operatorname{Tr}(A_2^k) + \cdots + \operatorname{T
r}(A_m^k) = 0 \quad \text{for all } k \geq 1.$$
So the trace condition is redundant; we work with it directly.

Using the spectral mapping property, the eigenvalues of $A_i^k$ are $\lambda_{i,
1}^k, \dots, \lambda_{i,n}^k$, and the trace equals the sum of eigenvalues:
$$\operatorname{Tr}(A_i^k) = \sum_{j=1}^{n} \lambda_{i,j}^k.$$

Summing over all matrices $i = 1, \dots, m$, we obtain the **power sums** of the
 full multiset of $N = mn$ eigenvalues $\{\lambda_{i,j}\}$:
$$p_k := \sum_{i=1}^{m}\sum_{j=1}^{n} \lambda_{i,j}^k = 0 \quad \text{for every
} k = 1, 2, 3, \dots$$

Now apply **Newton's identities**. Let $e_1, e_2, \dots, e_N$ be the elementary
symmetric polynomials in the $N = mn$ values $\lambda_{i,j}$. Newton's identity
states:
$$p_k - e_1\, p_{k-1} + e_2\, p_{k-2} - \cdots + (-1)^{k-1}\, e_{k-1}\, p_1 + (-
1)^k\, k\, e_k = 0.$$

We prove by induction on $k$ (for $k = 1, 2, \dots, N$) that $e_k = 0$:

- **Base case** ($k=1$): $p_1 + (-1)^1 \cdot 1 \cdot e_1 = 0$, i.e., $p_1 - e_1
= 0$. Since $p_1 = 0$, we get $e_1 = 0$.
- **Inductive step**: Assume $e_1 = e_2 = \cdots = e_{k-1} = 0$. Since also $p_1
 = p_2 = \cdots = p_k = 0$, every term in Newton's identity vanishes except the
last:
$$(-1)^k\, k\, e_k = 0 \implies e_k = 0.$$

Thus $e_1 = e_2 = \cdots = e_N = 0$. The monic polynomial whose roots are the $N
$ eigenvalues is therefore
$$\prod_{i=1}^{m}\prod_{j=1}^{n}(x - \lambda_{i,j}) = x^N - e_1\, x^{N-1} + e_2\
, x^{N-2} - \cdots = x^N.$$

Since $x^N = 0$ has only the root $0$ (with multiplicity $N$), every eigenvalue
satisfies $\lambda_{i,j} = 0$.

Therefore, **all eigenvalues of all the matrices $A_1, A_2, \dots, A_m$ are zero
**. $\blacksquare$
