## 证明

设 $C$ 为原点，$B = (b, 0)$ 在 $x$ 轴上（因此 $BC$ 为 $x$ 轴），且 $A = (a, h)$
，其中 $h > 0$。

**垂心和反射。** 从 $A$ 到 $BC$ 的高是垂直线 $x = a$。从 $B$ 到 $AC$（方向 $(a,
h)$）的高给出垂心 $H = \left(a,\, \frac{a(b-a)}{h}\right)$。令 $p = \frac{a(b-a)
}{h}$，则 $H = (a, p)$ 且 $P = (a, -p)$（关于 $x$ 轴的反射）。

**垂足 $F$。** 令 $d = (b-a)^2 + h^2 = AB^2$ 且 $N = h^2 - a(b-a)$。将 $C$ 投影
到直线 $AB$ 上：$F = A + t(B - A)$，其中 $t = N/d$，得到
$$F = \left(a + \frac{(b-a)N}{d},\; \frac{h\,b(b-a)}{d}\right).$$

**$\Gamma = (AFP)$ 的外接圆圆心。** 由于 $A = (a, h)$ 和 $P = (a, -p)$ 共享 $x$
坐标，$AP$ 的垂直平分线是 $y = \frac{h-p}{2}$，因此 $\Gamma$ 的圆心为 $O_\Gamma
= \left(c_x,\, \frac{h-p}{2}\right)$。

我们断言 $c_x = 0$。由 $|O_\Gamma A|^2 = |O_\Gamma F|^2$ 得到
$$2(f_x - a)\,c_x \;=\; f_x^2 + f_y^2 - a^2 - h^2 + (h - p)(h - f_y).$$
因此 $c_x = 0$ 当且仅当右边为零。代入 $f_x, f_y, p$ 并设 $u = b - a$：

$$\text{RHS} = \underbrace{\frac{2auN}{d} + \frac{u^2(N^2 + h^2 b^2)}{d^2}}_{f_x
^2+f_y^2-a^2} \;\underbrace{- \frac{b\,u\,N}{d}}_{f_y(p-h)} \;\underbrace{- a\,u
}_{-ph}.$$

提取公因式 $u$ 并乘以 $d^2$：

$$u\bigl[\,N(2a-b)\,d \;+\; u\,(N^2 + h^2 b^2) \;-\; a\,d^2\,\bigr].$$

现在计算关键恒等式：
$$N^2 + h^2 b^2 = (h^2 - au)^2 + h^2(a+u)^2 = h^4 + a^2 u^2 + a^2 h^2 + u^2 h^2
= (h^2 + a^2)\,d.$$

因此括号内的部分变为：
$$(h^2 - au)(a - u)\,d \;+\; u(h^2 + a^2)\,d \;-\; a\,d^2 \;=\; d\Bigl[(h^2 - au
)(a-u) + u(h^2 + a^2) - a\,d\Bigr].$$

展开方括号：
$$\bigl(ah^2 - uh^2 - a^2 u + au^2\bigr) + \bigl(uh^2 + ua^2\bigr) - a(u^2 + h^2
) = ah^2 - uh^2 - a^2u + au^2 + uh^2 + ua^2 - au^2 - ah^2 = 0.$$

因此 $\text{RHS} = 0$，这给出了 $c_x = 0$。

**结论。** $\Gamma$ 的圆心位于 $y$ 轴上，即通过 $C$ 且垂直于 $BC$ 的直线。圆上任
意弦的中点是从圆心到该弦所在直线的垂足。由于 $XY$ 是沿 $BC$（$x$ 轴）的弦，且 $\
Gamma$ 的圆心位于 $y$ 轴上，从圆心到 $BC$ 的垂足正是 $C = (0,0)$。因此 $C$ 是 $X
Y$ 的中点。$\blacksquare$
