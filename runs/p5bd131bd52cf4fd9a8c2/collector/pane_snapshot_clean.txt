Looking at this problem, I need to find the minimum $n$ such that an $n \times n
$ grid can be tiled with an equal number of $2\times 2$ squares (area 4) and L-t
riominoes (area 3).

## Area Constraint

If we use $k$ of each tile, the total area is $4k + 3k = 7k$, so $n^2 = 7k$. Sin
ce 7 is prime, $7 \mid n^2$ implies $7 \mid n$. Thus $n \in \{7, 14, 21, \dots\}
$.

## Ruling Out $n = 7$ via 4-Coloring

**Coloring.** Assign each cell $(i,j)$ the color $(i \bmod 2,\, j \bmod 2) \in \
{0,1\}^2$. Every $2\times 2$ block (and hence every $2\times 2$ square and every
 L-triomino) occupies a $2\times 2$ block containing exactly one cell of each of
 the 4 colors. A $2\times 2$ **square** covers all 4 colors; an **L-triomino** c
overs exactly 3 (missing one).

**Color counts in the $7\times 7$ grid** (rows/cols numbered 1–7):

| Color | Odd rows × Odd/Even cols | Count |
|-------|--------------------------|-------|
| (0,0) | 4 odd rows × 4 odd cols | 16 |
| (0,1) | 4 odd rows × 3 even cols | 12 |
| (1,0) | 3 even rows × 4 odd cols | 12 |
| (1,1) | 3 even rows × 3 even cols | 9 |

With $k=7$ squares, each color receives 7 cells from squares. The triominoes mus
t supply the remainder:

$$(16-7,\; 12-7,\; 12-7,\; 9-7) = (9,\; 5,\; 5,\; 2).$$

If $m_c$ triominoes miss color $c$, then color $c$ receives $7 - m_c$ cells from
 triominoes. For color $(0,0)$:

$$7 - m_{(0,0)} = 9 \implies m_{(0,0)} = -2 < 0.$$

This is impossible, so **$n = 7$ cannot be tiled**. $\square$

## Constructing a Tiling for $n = 14$

Here $k = 28$ of each tile. I build the tiling from two reusable blocks.

### Block 1: $7 \times 4$ rectangle (4 squares + 4 triominoes)

Rows 1–7, columns 1–4. Place:
- **Squares** at rows (1–2) × cols (1–2), rows (1–2) × cols (3–4), rows (6–7) ×
cols (1–2), rows (6–7) × cols (3–4).
- **Triominoes** tiling the remaining $3 \times 4$ region (rows 3–5):

| Triomino | $2\times 2$ block | Cells covered | Missing |
|----------|-------------------|---------------|---------|
| $T_1$ | rows 3–4, cols 1–2 | (3,1),(3,2),(4,1) | (4,2) |
| $T_2$ | rows 3–4, cols 3–4 | (3,3),(3,4),(4,4) | (4,3) |
| $T_3$ | rows 4–5, cols 1–2 | (4,2),(5,1),(5,2) | (4,1) |
| $T_4$ | rows 4–5, cols 3–4 | (4,3),(5,3),(5,4) | (4,4) |

One checks every cell in rows 3–5 is covered exactly once. (The "missing" cells
of $T_3, T_4$ are already covered by $T_1, T_2$ respectively.) Total: $4+4$ tile
s, area $16+12=28=7\times 4$. ✓

### Block 2: $7 \times 2$ rectangle (2 squares + 2 triominoes)

Rows 1–7, columns 1–2. Place:
- **Squares** at rows (1–2) and rows (6–7).
- **Triominoes** in the $3\times 2$ region (rows 3–5):
  - $T_1$: block rows 3–4, cols 1–2, covers (3,1),(3,2),(4,1), misses (4,2).
  - $T_2$: block rows 4–5, cols 1–2, covers (4,2),(5,1),(5,2), misses (4,1).

All 14 cells covered. ✓

### Assembling the $14 \times 14$ grid

Split the grid into:
- **Region A** ($14 \times 8$, columns 1–8): four $7 \times 4$ blocks (rows 1–7
/ 8–14 × cols 1–4 / 5–8). Each contributes 4 squares + 4 triominoes → **16 + 16*
*.
- **Region B** ($14 \times 6$, columns 9–14): two $7 \times 6$ blocks (rows 1–7
/ 8–14). Each $7 \times 6 = 7\times 4 + 7\times 2$ contributes $4+2 = 6$ of each
 → **12 + 12**.

**Total: $16+12 = 28$ squares and $16+12 = 28$ triominoes**, covering $28\cdot 4
 + 28\cdot 3 = 196 = 14^2$. ✓

## Conclusion

- $n$ must be a multiple of 7 (area constraint).
- $n = 7$ is impossible (4-coloring obstruction: color $(0,0)$ requires a negati
ve number of triominoes to miss it).
- $n = 14$ is achievable (explicit construction above).

The minimum $n$ is $\boxed{14}$.
