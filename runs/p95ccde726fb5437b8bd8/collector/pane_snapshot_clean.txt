## Proof

Let
$$f_n(x) = \frac{n\sin(x/n)}{x(1+x^2)}, \qquad x \in [0,\infty).$$

**Domain at the origin.** Since $\sin t \sim t$ as $t\to 0$, we have $n\sin(x/n)
 \sim x$ near $x=0$, so $f_n(0):=\lim_{x\to 0^+}f_n(x) = \frac{1}{1+0}=1$. Hence
 each $f_n$ is defined and continuous on $[0,\infty)$, and the integral is over
a set of full measure with no singularity.

**Pointwise limit.** For every fixed $x\ge 0$,
$$n\sin(x/n) = x\cdot\frac{\sin(x/n)}{x/n}\;\xrightarrow[n\to\infty]{}\; x\cdot
1 = x,$$
using $\lim_{t\to 0}\frac{\sin t}{t}=1$ (with $t=x/n$). Therefore
$$f_n(x) = \frac{n\sin(x/n)}{x(1+x^2)} \;\xrightarrow[n\to\infty]{}\; \frac{x}{x
(1+x^2)} = \frac{1}{1+x^2}=:f(x).$$

**Dominating function.** Using the elementary bound $|\sin t|\le |t|$ for all $t
\in\mathbb{R}$,
$$|n\sin(x/n)| \le n\cdot\frac{x}{n} = x \qquad (x\ge 0).$$
Consequently
$$|f_n(x)| = \frac{|n\sin(x/n)|}{x(1+x^2)} \le \frac{x}{x(1+x^2)} = \frac{1}{1+x
^2} = g(x).$$

**Integrability of the dominator.**
$$\int_{[0,\infty)} g\,dm = \int_0^\infty \frac{dx}{1+x^2} = \Big[\arctan x\Big]
_0^\infty = \frac{\pi}{2} < \infty.$$
So $g\in L^1([0,\infty),m)$.

**Applying the Dominated Convergence Theorem.** We have
- $f_n \to f$ pointwise $m$-a.e. on $[0,\infty)$,
- $|f_n|\le g$ for all $n$, with $g\in L^1$.

By the Dominated Convergence Theorem,
$$\lim_{n\to\infty}\int_{[0,\infty)} f_n\,dm = \int_{[0,\infty)} f\,dm = \int_0^
\infty \frac{dx}{1+x^2} = \frac{\pi}{2}.$$

$$\boxed{\displaystyle \lim_{n\to\infty}\int_{[0,\infty]}\frac{n\sin(x/n)}{x(1+x
^2)}\,dm(x)=\frac{\pi}{2}.}$$
