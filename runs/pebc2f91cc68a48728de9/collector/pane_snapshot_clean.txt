## Solution

**Find the intersection points.** Substitute $y = 4/x$ into $x^4 + y^4 = 100$:

$$x^4 + \frac{256}{x^4} = 100 \;\Longrightarrow\; u^2 - 100u + 256 = 0, \quad u
= x^4.$$

The roots are $u = 50 \pm 2\sqrt{561}$, both positive. Let

$$a^4 = 50 + 2\sqrt{561}, \qquad b^4 = 50 - 2\sqrt{561}, \qquad a > b > 0.$$

Since $xy = 4 > 0$, the four intersection points lie in quadrants I and III:

$$P_1=(a,\,4/a),\;\; P_2=(b,\,4/b),\;\; P_3=(-a,-4/a),\;\; P_4=(-b,-4/b).$$

**Shape of the quadrilateral.** The curves $x^4+y^4=100$ and $xy=4$ are both inv
ariant under $(x,y)\mapsto(-x,-y)$, so the four points are symmetric about the o
rigin: $P_3=-P_1$, $P_4=-P_2$. A quadrilateral with central (point) symmetry is
a **parallelogram**. Ordered as $P_1, P_2, P_3, P_4$ it is convex and non-self-i
ntersecting (since $a>b>0$ places $P_1$ right-low and $P_2$ left-high in QI).

**Area of a centrally-symmetric parallelogram** with vertices $A, B, -A, -B$ is

$$\text{Area} = 2\,|\det(A,B)| = 2\left|a\cdot\frac{4}{b} - \frac{4}{a}\cdot b\r
ight| = 8\left|\frac{a}{b}-\frac{b}{a}\right| = 8\,\frac{|a^2-b^2|}{ab}.$$

**Compute the ingredients.**

- $a^4 b^4 = (50)^2 - (2\sqrt{561})^2 = 2500 - 2244 = 256$, so $(ab)^4 = 256$, h
ence $ab = 4$.
- $a^4 + b^4 = 100$, so $(a^2+b^2)^2 = a^4+b^4+2a^2b^2 = 100 + 2(ab)^2 = 100 + 3
2 = 132$, giving $a^2+b^2 = \sqrt{132} = 2\sqrt{33}$.
- $a^4 - b^4 = 4\sqrt{561}$, and $a^4-b^4 = (a^2-b^2)(a^2+b^2)$, so
  $$a^2 - b^2 = \frac{4\sqrt{561}}{2\sqrt{33}} = 2\sqrt{\frac{561}{33}} = 2\sqrt
{17} \qquad(\text{since } 33\cdot 17 = 561).$$

**Assemble the area:**

$$\text{Area} = 8\cdot\frac{2\sqrt{17}}{4} = 8\cdot\frac{\sqrt{17}}{2} = 4\sqrt{
17}.$$

**Numerical check.** $a\approx 3.141,\; b\approx 1.273,\; ab\approx 3.999\approx
 4$ ✓; $a^2-b^2\approx 8.247 = 2\sqrt{17}$ ✓; area $\approx 16.49 = 4\sqrt{17}$
✓.

### Answer

$$\boxed{\,4\sqrt{17}\,}$$
