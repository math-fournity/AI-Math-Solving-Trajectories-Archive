## Solution

**Factor the denominator.** Note that
$$n^4 + n^2 + 1 = (n^2+n+1)(n^2-n+1).$$

**Partial fraction decomposition.** We seek
$$\frac{n}{(n^2+n+1)(n^2-n+1)} = \frac{An+B}{n^2+n+1} + \frac{Cn+D}{n^2-n+1}.$$

Expanding and matching coefficients of $n = (An+B)(n^2-n+1) + (Cn+D)(n^2+n+1)$:
- $n^3$: $A + C = 0$
- $n^2$: $-A + B + C + D = 0$
- $n^1$: $A - B + C + D = 1$
- $n^0$: $B + D = 0$

Solving: $C = -A$, $D = -B$, then $-2A = 0 \Rightarrow A = 0$, and $-2B = 1 \Rig
htarrow B = -\tfrac{1}{2}$, $D = \tfrac{1}{2}$. Thus
$$\frac{n}{n^4+n^2+1} = \frac{1}{2}\!\left(\frac{1}{n^2-n+1} - \frac{1}{n^2+n+1}
\right).$$

**Telescoping.** The key observation is
$$n^2 + n + 1 = (n+1)^2 - (n+1) + 1,$$
i.e., the second summand at index $n$ equals the first summand at index $n+1$. T
herefore the $N$-th partial sum telescopes:
$$S_N = \frac{1}{2}\sum_{n=1}^{N}\!\left(\frac{1}{n^2-n+1} - \frac{1}{(n+1)^2-(n
+1)+1}\right) = \frac{1}{2}\!\left(\frac{1}{1} - \frac{1}{(N+1)^2-(N+1)+1}\right
) = \frac{1}{2}\!\left(1 - \frac{1}{N^2+N+1}\right).$$

**Take the limit.** As $N \to \infty$, $\frac{1}{N^2+N+1} \to 0$, so
$$\sum_{n=1}^{\infty} \frac{n}{n^4+n^2+1} = \frac{1}{2}.$$
