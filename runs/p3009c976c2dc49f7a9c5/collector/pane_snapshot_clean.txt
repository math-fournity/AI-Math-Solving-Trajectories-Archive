# Proof: Viète's Formula

**Goal.** Prove that
$$\frac{\sqrt{2}}{2}\cdot\frac{\sqrt{2+\sqrt{2}}}{2}\cdot\frac{\sqrt{2+\sqrt{2+\
sqrt{2}}}}{2}\cdots = \frac{2}{\pi}.$$

---

## Step 1. Define the nested radical sequence

Let
$$a_1 = \sqrt{2}, \qquad a_{n+1} = \sqrt{2 + a_n}\quad(n\ge 1).$$

The infinite product in question is
$$P = \prod_{n=1}^{\infty}\frac{a_n}{2}.$$

## Step 2. Closed form via the half-angle identity

**Claim.** $\displaystyle a_n = 2\cos\!\left(\frac{\pi}{2^{n+1}}\right)$ for all
 $n\ge 1$.

**Proof by induction.**

*Base case* ($n=1$):
$$a_1 = \sqrt{2} = 2\cdot\frac{\sqrt{2}}{2} = 2\cos\frac{\pi}{4}. \checkmark$$

*Inductive step.* Assume $a_n = 2\cos(\pi/2^{n+1})$. Then
$$a_{n+1} = \sqrt{2 + a_n} = \sqrt{2 + 2\cos\!\left(\frac{\pi}{2^{n+1}}\right)}
= \sqrt{2\!\left(1 + \cos\!\left(\frac{\pi}{2^{n+1}}\right)\right)}.$$

Using the half-angle identity $1 + \cos\theta = 2\cos^2(\theta/2)$ with $\theta
= \pi/2^{n+1}$:
$$a_{n+1} = \sqrt{4\cos^2\!\left(\frac{\pi}{2^{n+2}}\right)} = 2\cos\!\left(\fra
c{\pi}{2^{n+2}}\right). \checkmark$$

This completes the induction. $\square$

## Step 3. Rewrite the product as a cosine product

Since $a_n = 2\cos(\pi/2^{n+1})$, each factor is
$$\frac{a_n}{2} = \cos\!\left(\frac{\pi}{2^{n+1}}\right).$$

Re-indexing with $k = n+1$ (so $k$ runs from $2$ to $\infty$):
$$P = \prod_{k=2}^{\infty}\cos\!\left(\frac{\pi}{2^{k}}\right).$$

## Step 4. Telescope using the double-angle formula

From $\sin(2\theta) = 2\sin\theta\cos\theta$ we get
$$\cos\theta = \frac{\sin(2\theta)}{2\sin\theta}.$$

Applying this with $\theta = \pi/2^k$:
$$\cos\!\left(\frac{\pi}{2^k}\right) = \frac{\sin(\pi/2^{k-1})}{2\,\sin(\pi/2^{k
})}.$$

The **$N$-th partial product** ($N\ge 2$) is therefore
$$P_N = \prod_{k=2}^{N}\frac{\sin(\pi/2^{k-1})}{2\,\sin(\pi/2^{k})}.$$

This is a **telescoping product** — the numerator $\sin(\pi/2^{k-1})$ at index $
k$ cancels the denominator $\sin(\pi/2^{(k-1)})$ at index $k-1$:

$$P_N = \frac{\sin(\pi/2^{1})}{2^{N-1}\,\sin(\pi/2^{N})} = \frac{\sin(\pi/2)}{2^
{N-1}\,\sin(\pi/2^{N})} = \frac{1}{2^{N-1}\,\sin(\pi/2^{N})}.$$

## Step 5. Take the limit $N\to\infty$

We use the standard limit $\lim_{x\to 0}\frac{\sin x}{x} = 1$. Setting $x = \pi/
2^N$, as $N\to\infty$ we have $x\to 0$, so
$$\sin\!\left(\frac{\pi}{2^N}\right) \sim \frac{\pi}{2^N}.$$

Therefore
$$P = \lim_{N\to\infty} P_N = \lim_{N\to\infty}\frac{1}{2^{N-1}\,\sin(\pi/2^{N})
} = \lim_{N\to\infty}\frac{1}{2^{N-1}\cdot(\pi/2^N)} = \lim_{N\to\infty}\frac{2^
N}{2^{N-1}\,\pi} = \frac{2}{\pi}.$$

## Conclusion

$$\frac{\sqrt{2}}{2}\cdot\frac{\sqrt{2+\sqrt{2}}}{2}\cdot\frac{\sqrt{2+\sqrt{2+\
sqrt{2}}}}{2}\cdots = \frac{2}{\pi}. \qquad \blacksquare$$
