# Problem

In a specialized logistics network, a protocol $f$ maps each positive integer shipment ID to a new positive integer destination ID. A protocol is classified as "Synchronized" if it satisfies a strict balance requirement: for any two shipment IDs $x$ and $y$, the greatest common divisor of the destination of the destination of $x$, and the destination of the sum of $x$ and $y$, must be exactly equal to the greatest common divisor of the original IDs $x$ and $y$. Mathematically, this is expressed as:
$$\gcd(f(f(x)), f(x+y)) = \gcd(x, y)$$

Certain shipment IDs are "Fixed Points" if every possible Synchronized protocol $f$ always maps that ID to itself (meaning $f(m)=m$ for all such protocols).

Let $M$ be the set of all such Fixed Point IDs. Calculate the sum of all elements $m$ in the set $M$ that fall within the range $1 \leq m \leq 20$.
