## Proof

The non-degenerate triangle condition gives three strict inequalities for all $a
, b \geq 1$:

- **(T1)** $a < f(b) + f(b + f(a) - 1)$
- **(T2)** $f(b) < a + f(b + f(a) - 1)$
- **(T3)** $f(b + f(a) - 1) < a + f(b)$

From (T2) and (T3), since all values are integers:

$$f(b) - a + 1 \;\leq\; f(b + f(a) - 1) \;\leq\; a + f(b) - 1,$$

that is, $|f(b + f(a) - 1) - f(b)| \leq a - 1$ for all $a, b$. $\quad(\star)$

### Step 1: Setting $a = 1$

With $a = 1$: $|f(b + f(1) - 1) - f(b)| \leq 0$, so

$$f(b + f(1) - 1) = f(b) \quad \text{for all } b \geq 1. \quad (\dagger)$$

Let $c = f(1)$.

**Case A: $c \geq 2$.** Then $(\dagger)$ says $f$ is periodic with period $p = c
 - 1 \geq 1$. So $f$ takes only finitely many values and is bounded: $f(n) \leq
M$ for some constant $M$. But (T1) gives $a < f(b) + f(b + f(a) - 1) \leq 2M$ fo
r all $a$, which is impossible for large $a$. **Contradiction.**

**Case B: $c = 1$, i.e., $f(1) = 1$.** Then $(\dagger)$ is trivially satisfied.
We proceed.

### Step 2: $f$ is an involution

From $(\star)$ with $b = 1$: $|f(f(a)) - f(1)| \leq a - 1$, so $f(f(a)) \leq a$.

From (T1) with $b = 1$: $a < f(1) + f(f(a)) = 1 + f(f(a))$, so $f(f(a)) \geq a$.

Therefore $f(f(a)) = a$ for all $a \geq 1$. In particular, $f$ is a bijection.

### Step 3: Subadditivity reformulation

Substituting $a \mapsto f(a)$ (valid since $f(f(a)) = a$) into (T3):

$$f(b + a - 1) \leq f(a) + f(b) - 1 \quad \text{for all } a, b \geq 1. \quad (\d
dagger)$$

Define $F(k) = f(k+1) - 1$ for $k \geq 0$. Then $F: \mathbb{Z}_{\geq 0} \to \mat
hbb{Z}_{\geq 0}$, $F(0) = f(1) - 1 = 0$, and $(\ddagger)$ becomes:

$$F(m + n) \leq F(m) + F(n) \quad \text{for all } m, n \geq 0 \qquad \text{(suba
dditivity)}.$$

The involution $f(f(a)) = a$ translates to $F(F(k)) = k$ for all $k \geq 0$, so
$F$ is an involution (hence a bijection).

### Step 4: Proving $F(1) = 1$

Suppose for contradiction that $F(1) = t \geq 2$. By involution, $F(t) = 1$.

**Claim:** $F(kt) = k$ and $F(k) = kt$ for all $k \geq 0$, by induction.

*Base:* $F(0) = 0$ and $F(0 \cdot t) = 0$. ✓

*Inductive step:* Assume $F(jt) = j$ for $j = 0, 1, \ldots, k-1$. By subadditivi

$$F(kt) = F((k-1)t + t) \leq F((k-1)t) + F(t) = (k-1) + 1 = k.$$

Since $F$ is injective and $F(jt) = j$ for $j < k$ with $kt \neq jt$ (as $t \geq

Applying this at $k = t$: $F(t) = t \cdot t = t^2$. But $F(t) = 1$, so $t^2 = 1$

Therefore $F(1) = 1$.

### Step 5: Proving $F(k) = k$ for all $k$

By induction. Assume $F(j) = j$ for $j = 0, \ldots, k-1$. By subadditivity:

$$F(k) \leq F(k-1) + F(1) = (k-1) + 1 = k.$$

Since $F$ is injective and $F(j) = j$ for $j < k$, we have $F(k) \notin \{0, \ld

### Step 6: Conclusion

$F(k) = k$ for all $k \geq 0$ gives $f(n) = F(n-1) + 1 = n$ for all $n \geq 1$.

**Verification:** For $f(n) = n$, the three sides are $a, b, b + a - 1$. The tri

- $b + a - 1 < a + b$ ✓ (since $-1 < 0$),
- $a < b + (b + a - 1) = a + 2b - 1$ ✓ (since $2b - 1 \geq 1 > 0$),
- $b < a + (b + a - 1) = 2a + b - 1$ ✓ (since $2a - 1 \geq 1 > 0$).

All are strict, so the triangle is non-degenerate. ✓

The unique solution is $\boxed{f(n) = n}$ for all positive integers $n$.
