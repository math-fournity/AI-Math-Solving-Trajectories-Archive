# Problem

A city is planning a complex layout of $1996$ straight, infinitely long high-speed transit cables across a flat desert. The engineers have two strict safety requirements for the layout:
1. Every cable must cross every other cable at some point.
2. No more than two cables are permitted to intersect at any single point.

These cables partition the desert into several distinct zones. A "V-Zone" is defined as a specific type of open-ended region that is bounded by exactly two cable segments (forming a single vertex) and extends infinitely without being crossed by any other cables.

The Lead Architect, tasked with optimizing the layout, defines two variables:
- $m(1996)$ is the minimum possible number of V-Zones that can be formed using $1996$ cables.
- $M(1996)$ is the maximum possible number of V-Zones that can be formed using $1996$ cables.

Calculate the value of $m(1996) + M(1996)$.
