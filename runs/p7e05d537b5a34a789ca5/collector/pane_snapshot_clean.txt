## Proof

**Setup.** Let $g(t)=f(t)-t$, so $f(t)=t+g(t)$. The condition $f(t)+f^{-1}(t)=2t
$ gives $f^{-1}(t)=t-g(t)$. Since $f^{-1}$ is the inverse of $f$, applying $f$ t
o both sides of $f^{-1}(t)=t-g(t)$: if $s=f(t)=t+g(t)$, then $f^{-1}(s)=t$, so $
s-g(s)=t$, giving $g(t+g(t))=g(t)$. Equivalently, $g(f(t))=g(t)$, so **$g$ is co
nstant on each orbit of $f$**. Iterating: $f^n(t)=t+n\cdot g(t)$ for all $n\in\m
athbb{Z}$, so each orbit is $\{t+n\,g(t):n\in\mathbb{Z}\}$.

**Monotonic bijections are continuous.** A monotonic bijection $f:\mathbb{R}\to\
mathbb{R}$ is strictly monotonic. If strictly increasing with a jump at $a$, the
 interval $(\lim_{t\to a^-}f(t),\lim_{t\to a^+}f(t))$ is omitted from the range,
 contradicting surjectivity. Hence $f$ is continuous; $g$ is continuous.

### Case 1: $f$ strictly increasing

Suppose some orbit has common difference $c>0$ (the case $c<0$ is analogous). Se
t $t_0$ on this orbit; WLOG $t_0=0$, so the orbit is $\{nc:n\in\mathbb{Z}\}$ and
 $g(nc)=c$ for all $n$.

Since $f$ is continuous and strictly increasing with $f(nc)=(n+1)c$, $f$ maps ea
ch interval $[nc,(n+1)c]$ homeomorphically onto $[(n+1)c,(n+2)c]$.

Take any $s\in(0,c)$ with $d:=g(s)$. Then:
- $f(s)=s+d\in(c,2c)$, so $d\in(c-s,\,2c-s)$.
- $f^2(s)=s+2d\in(2c,3c)$, so $d\in(c-s/2,\,3c/2-s/2)$.
- By induction, $f^n(s)=s+nd\in(nc,(n+1)c)$ for all $n\geq 0$, giving $d\in(c-s/
n,\,c+(c-s)/n)$.
- Similarly $f^{-n}(s)=s-nd\in(-nc,-(n-1)c)$ for $n\geq 1$, giving $d\in(c-(c-s)
/n,\,c+s/n)$.

As $n\to\infty$, both bounds converge to $c$, forcing $d=c$. So $g(s)=c$ for all
 $s\in(0,c)$, and by continuity $g\equiv c$ on $[0,c]$. The same argument on eac
h $[nc,(n+1)c]$ gives $g\equiv c$ on $\mathbb{R}$.

If every orbit is a fixed point ($g\equiv 0$), then $f=\mathrm{id}=f_0$.

In all subcases, $g$ is constant: $f(t)=t+c$ for some $c\in\mathbb{R}$.

### Case 2: $f$ strictly decreasing

 $-t$ is decreasing). We show $g\equiv 0$, contradicting $f$ being decreasing.

- If $g(t_0)<0$ for some $t_0$: then $f(t_0)<t_0$. Since $f$ is decreasing, $f(f

*

So $g\equiv 0$, i.e., $f=\mathrm{id}$, which is increasing—not decreasing. **No
