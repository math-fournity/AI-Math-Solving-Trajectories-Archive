## Solution

We solve $y^3 - xy + 1 = 0$ for $y$ as a Puiseux series in $x$ about $x = 0$.

### Step 1: Newton Polygon Analysis

The monomials of $F(x,y) = y^3 - xy + 1$ give points $(i,j)$ for the term $x^i y
^j$:
- $y^3 \to (0,3)$, $\;-xy \to (1,1)$, $\;1 \to (0,0)$.

The lower Newton polygon has two edges:
- $(0,0) \to (1,1)$ with slope $+1$,
- $(1,1) \to (0,3)$ with slope $-2$.

The edge of slope $+1$ (horizontal length $1$) corresponds to the root $y = -1$
(from $y + 1 = 0$, the factor of the initial form $y^3+1$ associated with this e
dge). The edge of slope $-2$ (horizontal length $1$) corresponds to the remainin
g factor $y^2 - y + 1 = 0$, giving $y = e^{\pm i\pi/3}$.

The **discriminant** of $y^3 + py + q$ with $p = -x,\, q = 1$ is
$$\Delta = -4p^3 - 27q^2 = 4x^3 - 27,$$
which satisfies $\Delta(0) = -27 \neq 0$. Therefore all three roots are **simple
** at $x=0$, and each branch is an ordinary power series in $x$ (a Puiseux serie
s with all integer exponents — the ramification index is $1$).

### Step 2: Series Substitution

Set $y = \omega + c_1 x + c_2 x^2 + c_3 x^3 + \cdots$ where $\omega^3 = -1$, i.e
., $\omega \in \{-1,\; e^{i\pi/3},\; e^{-i\pi/3}\}$.

Write $y = \omega + u$ with $u = \sum_{n\geq 1} c_n x^n$. Then:
$$y^3 = \omega^3 + 3\omega^2 u + 3\omega\, u^2 + u^3 = -1 + 3\omega^2 u + 3\omeg
a\, u^2 + u^3,$$
$$F = y^3 - xy + 1 = 3\omega^2 u + 3\omega\, u^2 + u^3 - x(\omega + u).$$

Using $\omega^3 = -1$ (so $1/\omega = -\omega^2$, $1/\omega^2 = -\omega$), we ma
tch coefficients order by order:

**$x^1$:** $3\omega^2 c_1 - \omega = 0 \;\Longrightarrow\; c_1 = \dfrac{1}{3\ome
ga} = -\dfrac{\omega^2}{3}.$

**$x^2$:** $3\omega^2 c_2 + 3\omega\, c_1^2 - c_1 = 0$. Since $\omega\, c_1 = \o
mega\cdot\frac{1}{3\omega} = \frac{1}{3}$, we get $c_1(1 - 3\omega c_1) = c_1\cd
ot 0 = 0$, so $c_2 = 0$.

**$x^3$:** $3\omega^2 c_3 + 6\omega\, c_1 c_2 + c_1^3 - c_2 = 0$. With $c_2=0$:
$c_3 = -\dfrac{c_1^3}{3\omega^2} = -\dfrac{1}{27\omega^3\cdot 3\omega^2} = \dfra
c{1}{81\omega^2} = -\dfrac{\omega}{81}.$

**$x^4$:** $3\omega^2 c_4 + 3\omega(2c_1 c_3) + 3c_1^2 c_2 - c_3 = 0$. With $c_2
=0$: $3\omega^2 c_4 = c_3(1 - 6\omega c_1) = c_3(1-2) = -c_3$, giving $c_4 = -\d
frac{c_3}{3\omega^2} = -\dfrac{1}{243\,\omega^4} = \dfrac{1}{243\omega} = -\dfra
c{\omega^2}{243}$ (using $\omega^4 = -\omega$).

**$x^5$:** $3\omega^2 c_5 + 6\omega\, c_1 c_4 + 3c_1^2 c_3 - c_4 = 0$. One check
s $6\omega\, c_1 c_4 + 3c_1^2 c_3 - c_4 = 0$ identically (each term is $\pm\omeg
a^2/243$ and they cancel), so $c_5 = 0$.

**$x^6$:** $3\omega^2 c_6 + 3\omega\, c_3^2 + 3c_1^2 c_4 - c_5 = 0$. With $c_5=0
$:
$$3\omega\, c_3^2 = 3\omega\cdot\frac{\omega^2}{6561} = \frac{3\omega^3}{6561} =
 -\frac{1}{2187}, \qquad 3c_1^2 c_4 = 3\cdot\frac{\omega^4}{9}\cdot\left(-\frac{
\omega^2}{243}\right) = \frac{3\omega^6}{-2187} = -\frac{3}{2187} = -\frac{1}{72
9}.$$
So $3\omega^2 c_6 = \frac{1}{2187} + \frac{1}{729} = \frac{4}{2187}$, giving $c_
6 = \dfrac{4}{6561\,\omega^2} = -\dfrac{4\omega}{6561}.$

### Step 3: The Three Branches

For each $\omega$ with $\omega^3 = -1$, the Puiseux series (here an ordinary pow
er series) is:

$$\boxed{y_\omega \;=\; \omega \;-\; \frac{\omega^2}{3}\,x \;-\; \frac{\omega}{8
1}\,x^3 \;-\; \frac{\omega^2}{243}\,x^4 \;-\; \frac{4\omega}{6561}\,x^6 \;+\; \c
dots}$$

Explicitly, the three branches are:

**Branch 1** ($\omega = -1$):
$$y = -1 - \frac{x}{3} + \frac{x^3}{81} - \frac{x^4}{243} + \frac{4\,x^6}{6561}
+ \cdots$$

**Branch 2** ($\omega = e^{i\pi/3} = \tfrac{1+i\sqrt{3}}{2}$):
$$y = e^{i\pi/3} - \frac{e^{2i\pi/3}}{3}\,x - \frac{e^{i\pi/3}}{81}\,x^3 - \frac
{e^{2i\pi/3}}{243}\,x^4 - \frac{4\,e^{i\pi/3}}{6561}\,x^6 + \cdots$$

**Branch 3** ($\omega = e^{-i\pi/3} = \tfrac{1-i\sqrt{3}}{2}$):
$$y = e^{-i\pi/3} - \frac{e^{-2i\pi/3}}{3}\,x - \frac{e^{-i\pi/3}}{81}\,x^3 - \f
rac{e^{-2i\pi/3}}{243}\,x^4 - \frac{4\,e^{-i\pi/3}}{6561}\,x^6 + \cdots$$

### Step 4: Verification

We verify Branch 1 up to $O(x^5)$. With $y = -1 - \frac{x}{3} + \frac{x^3}{81} -
 \frac{x^4}{243} + \cdots$ and $u = -\frac{x}{3} + \frac{x^3}{81} - \frac{x^4}{2
43} + \cdots$:

$$y^3 = -1 + 3u - 3u^2 + u^3 = -1 - x - \frac{x^2}{3} + \frac{x^4}{81} + O(x^5),
$$
$$-xy = x + \frac{x^2}{3} - \frac{x^4}{81} + O(x^5),$$
$$y^3 - xy + 1 = \left(-1 - x - \frac{x^2}{3} + \frac{x^4}{81}\right) + \left(x
+ \frac{x^2}{3} - \frac{x^4}{81}\right) + 1 + O(x^5) = O(x^5).\;\checkmark$$

Each coefficient through $x^4$ vanishes, confirming the series. The conjugate br
anches (2 and 3) satisfy the same identity by the symmetry $\omega \mapsto \bar{
\omega}$, since the original equation has real coefficients.
