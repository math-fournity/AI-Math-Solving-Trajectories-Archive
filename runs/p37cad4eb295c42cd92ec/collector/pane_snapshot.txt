## Proof

**Definition.** A function $f: \omega \to \omega$ is *regressive* if $f(0)=0$ an
d $f(n) < n$ for every $n > 0$.

Let $R$ denote the set of regressive functions. We show $|R| = 2^{\aleph_0}$.

**Upper bound.** Every regressive function is in particular a function $\omega \
to \omega$, so
$$R \subseteq \omega^\omega.$$
Hence $|R| \le |\omega^\omega| = \aleph_0^{\aleph_0} = 2^{\aleph_0}$.

**Lower bound.** For each $n \ge 2$, a regressive function may assign $f(n)$ to
be either $0$ or $1$ (both satisfy $f(n) < n$). Consider the map
$$\{0,1\}^{\omega \setminus \{0,1\}} \longrightarrow R$$
which sends a binary sequence $(b_n)_{n \ge 2}$ to the regressive function
$$f(0)=0,\quad f(1)=0,\quad f(n)=b_n \;\text{ for } n\ge 2.$$
This map is injective, since distinct binary sequences yield distinct regressive
 functions. Therefore
$$|R| \ge \left|\{0,1\}^{\omega}\right| = 2^{\aleph_0}.$$

**Conclusion.** Combining both bounds,
$$2^{\aleph_0} \le |R| \le 2^{\aleph_0},$$
so $|R| = 2^{\aleph_0}$.

The cardinality of the set of regressive functions from $\omega$ to $\omega$ is
$\boxed{2^{\aleph_0}}$ (the cardinality of the continuum).
