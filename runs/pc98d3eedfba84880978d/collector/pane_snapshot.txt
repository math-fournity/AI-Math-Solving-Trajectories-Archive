**问题：** 找出最大的自然数 $n$，使得对于所有具有正判别式且系数 $p, q$ 均能被 5
整除的二次三项式 $x^2 + px + q$，其根的 100 次方之和能被 $5^n$ 整除。

## 证明

设根为 $r_1, r_2$，满足 $r_1 + r_2 = -p$，$r_1 r_2 = q$，其中 $5 \mid p$ 且 $5 \
mid q$。记 $S_k = r_1^k + r_2^k$。由于 $p, q \in \mathbb{Z}$，所有 $S_k$ 均为整
数，且满足递推关系 $S_k = -p\,S_{k-1} - q\,S_{k-2}$，其中 $S_0 = 2$，$S_1 = -p$
。

令 $p = 5a$，$q = 5b$，其中 $a, b \in \mathbb{Z}$。判别式 $D = p^2 - 4q = 25a^2
- 20b = 5(5a^2 - 4b) > 0$。

**在 $\mathbb{Q}_5$ 的二次扩张中进行 5-adic 赋值分析。**

根为 $r_{\pm} = \frac{-5a \pm \sqrt{D}}{2}$。设 $m = v_5(5a^2 - 4b) \geq 0$，因
此 $v_5(D) = 1 + m$。

设 $s_i = v_5(r_i)$ 为 5-adic 赋值（在扩张中可能是半整数）。关键关系如下：
- $s_1 + s_2 = v_5(r_1 r_2) = v_5(5b) = 1 + v_5(b) \geq 1$。
- $v_5(r_1 + r_2) = v_5(5a) = 1 + v_5(a) \geq 1$。

**情况 1：$s_1 \neq s_2$。** 则 $v_5(r_1 + r_2) = \min(s_1, s_2) = 1 + v_5(a) \g
eq 1$。由于 $s_1 \neq s_2$，有 $v_5(r_1^{100} + r_2^{100}) = 100\min(s_1, s_2) =
 100(1 + v_5(a)) \geq 100$。

**情况 2：$s_1 = s_2 = s$。** 则 $2s = 1 + v_5(b) \geq 1$，因此 $s \geq 1/2$。两
项 $r_1^{100}$ 和 $r_2^{100}$ 的 5-adic 赋值均为 $100s$，因此 $v_5(S_{100}) \geq
 100s \geq 50$。

结合两种情况：**$v_5(S_{100}) \geq 50$** 对所有有效的三项式成立。

**证明下界 50 是紧的（即可达）。**

取 $p = 0$，$q = -5$（即 $a = 0$，$b = -1$）。判别式 $D = 20 > 0$ ✓，且 $5 \mid
0$，$5 \mid (-5)$ ✓。根为 $r_1 = \sqrt{5}$，$r_2 = -\sqrt{5}$，两者在 $\mathbb{Q
}_5(\sqrt{5})$ 中的赋值均为 $s = 1/2$。

$$S_{100} = (\sqrt{5})^{100} + (-\sqrt{5})^{100} = 5^{50} + 5^{50} = 2 \cdot 5^{
50}.$$

因此 $v_5(S_{100}) = 50$ 恰好成立。

**使用 $p = 5, q = -5$ 进行验证**（即 $a=1, b=-1$, $D = 45 > 0$）：根为 $\frac{-
5 \pm 3\sqrt{5}}{2}$，两者赋值均为 $1/2$。计算 $S_{100} = \frac{5^{50}}{2^{100}}
\bigl[(3+\sqrt5)^{100} + (3-\sqrt5)^{100}\bigr]$。序列 $U_k = (3+\sqrt5)^k + (3-
\sqrt5)^k$ 满足 $U_k = 6U_{k-1} - 4U_{k-2}$，且 $U_k \equiv U_{k-1} + U_{k-2} \p
mod{5}$，周期为 4：$2, 1, 3, 4, \ldots$。由于 $100 \equiv 0 \pmod{4}$，$U_{100}
\equiv 2 \pmod{5}$，因此 $v_5(U_{100}) = 0$，且 $v_5(S_{100}) = 50$。✓

由于 $v_5(S_{100}) \geq 50$ 对所有此类三项式成立，且存在三项式使得 $v_5(S_{100})
 = 50$ 恰好成立，因此最大的自然数 $n$ 为：

$$\boxed{50}$$
