# Solution

**Claim.** The polynomials satisfying the condition are exactly $f(x) = x^n$ and
 $f(x) = -x^n$ for integers $n \geq 0$.

## Sufficiency

If $f(x) = \pm x^n$, then for distinct primes $p, q$ we have $f(p) = \pm p^n$ an
d $f(q) = \pm q^n$, so $\gcd(f(p), f(q)) = \gcd(p^n, q^n) = 1$. ✓

## Necessity

Suppose $f \in \mathbb{Z}[x]$ satisfies the condition.

**Step 1: For every prime $p$, $f(p) = \pm p^{e_p}$ for some integer $e_p \geq 0
$.**

Fix a prime $p$. We first note $f(p) \neq 0$, since $f(p) = 0$ would be divisibl
e by every prime, in particular by some $\ell \neq p$, which (as shown below) is
 impossible.

We claim no prime $\ell \neq p$ divides $f(p)$. Suppose for contradiction that a
 prime $\ell \neq p$ divides $f(p)$. Since $p$ is prime and $\ell \neq p$, we ha
ve $\gcd(p, \ell) = 1$, so the residue $r := p \bmod \ell$ lies in $\{1, 2, \ldo
ts, \ell-1\}$. Then
$$f(p) \equiv f(r) \pmod{\ell},$$
so $\ell \mid f(r)$. By Dirichlet's theorem on primes in arithmetic progressions
, there are infinitely many primes $q$ with $q \equiv r \pmod{\ell}$; choose one
 with $q \neq p$. Then $f(q) \equiv f(r) \equiv 0 \pmod{\ell}$, so $\ell \mid f(
q)$. But $\ell \mid f(p)$ as well, contradicting $\gcd(f(p), f(q)) = 1$.

Hence the only prime that may divide $f(p)$ is $p$ itself, so $f(p) = \pm p^{e_p
}$ for some $e_p \geq 0$.

**Step 2: $f$ is a monomial $\pm x^d$.**

If $f$ is constant, then $f(p) = f(q) = c$ for all primes, so $\gcd(c,c) = |c| =
 1$, giving $f \equiv \pm 1 = \pm x^0$.

Now suppose $f$ is nonconstant of degree $d \geq 1$ with leading coefficient $c_
d \neq 0$. From Step 1,
$$|f(p)| = p^{e_p} \quad \text{for every prime } p.$$
But also $|f(p)| = |c_d|\, p^d\,(1 + o(1))$ as $p \to \infty$. Therefore
$$p^{\,e_p - d} \longrightarrow |c_d| \in (0,\infty).$$
Since each $e_p - d$ is an integer and $p^{e_p - d}$ converges to a finite posit
ive limit, we must have $e_p = d$ for all sufficiently large primes $p$, and $|c
_d| = 1$. Writing $\varepsilon := c_d \in \{+1, -1\}$, we get
$$f(p) = \varepsilon\, p^d \quad \text{for all sufficiently large primes } p.$$
The polynomial $g(x) := f(x) - \varepsilon x^d$ vanishes at infinitely many prim
es, hence $g \equiv 0$, i.e.,
$$f(x) = \varepsilon\, x^d.$$

## Conclusion

The polynomials with integer coefficients such that $f(p)$ and $f(q)$ are relati
vely prime for all distinct primes $p, q$ are precisely
$$\boxed{f(x) = x^n \text{ or } f(x) = -x^n, \quad n \in \mathbb{Z}_{\geq 0}.}$$
