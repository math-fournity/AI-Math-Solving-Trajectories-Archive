## Solution

**Problem.** Find all positive integers $n$ such that $xy + 1 \equiv 0 \pmod{n}$
 implies $x + y \equiv 0 \pmod{n}$.

### Step 1: Reformulation

Suppose $xy \equiv -1 \pmod{n}$. Then $x$ is a unit modulo $n$ (with inverse $-y
$), and $y \equiv -x^{-1} \pmod{n}$. The desired conclusion $x + y \equiv 0 \pmo
d{n}$ is equivalent to $y \equiv -x \pmod{n}$, which combined with $y \equiv -x^
{-1}$ gives:

$$x^{-1} \equiv x \pmod{n} \quad\Longleftrightarrow\quad x^2 \equiv 1 \pmod{n}.$
$

Conversely, if every unit $x$ mod $n$ satisfies $x^2 \equiv 1$, then for any $xy
 \equiv -1$, we get $y \equiv -x^{-1} \equiv -x$, so $x+y \equiv 0$.

**Therefore the condition is equivalent to: every unit modulo $n$ has order divi
ding 2**, i.e., $(\mathbb{Z}/n\mathbb{Z})^*$ is an elementary abelian 2-group (e
xponent $\leq 2$).

### Step 2: Reduce via CRT

Write $n = \prod p_i^{a_i}$. By CRT, $(\mathbb{Z}/n\mathbb{Z})^* \cong \prod (\m
athbb{Z}/p_i^{a_i}\mathbb{Z})^*$. The product has exponent $\leq 2$ iff each fac
tor does.

### Step 3: Classify prime powers

**Odd prime $p$:** $(\mathbb{Z}/p^a\mathbb{Z})^*$ is cyclic of order $p^{a-1}(p-
1)$. For exponent $\leq 2$ we need $p^{a-1}(p-1) \mid 2$. Since $p \geq 3$, we n
eed $a = 1$ and $p - 1 \mid 2$, giving $p = 3$. So the only odd prime power is *
*$3$**.

**$p = 2$:**
- $a = 1$: $(\mathbb{Z}/2\mathbb{Z})^* = \{1\}$, trivial. ✓
- $a = 2$: $(\mathbb{Z}/4\mathbb{Z})^* = \{1, 3\}$, $3^2 = 9 \equiv 1$. ✓
- $a = 3$: $(\mathbb{Z}/8\mathbb{Z})^* = \{1,3,5,7\}$, and $3^2 \equiv 5^2 \equi
v 7^2 \equiv 1 \pmod{8}$. ✓
- $a \geq 4$: $(\mathbb{Z}/2^a\mathbb{Z})^* \cong \mathbb{Z}/2 \times \mathbb{Z}
/2^{a-2}$ has an element of order $2^{a-2} \geq 4$. For instance $3^2 = 9 \not\e
quiv 1 \pmod{16}$. ✗

So the valid 2-powers are **$2, 4, 8$**.

### Step 4: Combine

The admissible prime powers are $2, 4, 8$ (prime 2) and $3$ (prime 3). Combining
 via CRT (choosing at most one power of each prime):

$$n \in \{1,\, 2,\, 4,\, 8\} \times \{1,\, 3\} = \{1, 2, 3, 4, 6, 8, 12, 24\}.$$

### Step 5: Verification

- **$n = 24$:** Units are $\{1,5,7,11,13,17,19,23\}$. Each is $\equiv \pm 1, \pm
 5, \pm 7, \pm 11 \pmod{24}$, and $5^2=25\equiv1$, $7^2=49\equiv1$, $11^2=121\eq
uiv1$. ✓
- **$n = 12$:** Units $\{1,5,7,11\}$, all square to $1$ mod $12$. ✓
- **$n = 8$:** Units $\{1,3,5,7\}$, all square to $1$ mod $8$. ✓
- **$n = 6, 4, 3, 2, 1$:** Direct check confirms all units square to $1$. ✓
- **$n = 5$ (excluded):** $x=2, y=2$: $xy+1 = 5 \equiv 0 \pmod{5}$ but $x+y = 4
\not\equiv 0 \pmod{5}$. ✗
- **$n = 16$ (excluded):** $x=3, y=5$: $xy+1 = 16 \equiv 0 \pmod{16}$ but $x+y =
 8 \not\equiv 0 \pmod{16}$. ✗
- **$n = 9$ (excluded):** $x=2, y=4$: $xy+1 = 9 \equiv 0 \pmod{9}$ but $x+y = 6
\not\equiv 0 \pmod{9}$. ✗

### Conclusion

The positive integers $n$ satisfying the condition are:

$$\boxed{n \in \{1, 2, 3, 4, 6, 8, 12, 24\}}.$$
