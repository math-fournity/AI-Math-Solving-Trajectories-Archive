Looking at this problem, I need to find the greatest $n$ such that non-negative
integers $x_1, \dots, x_n$ exist where every nonzero $\{-1,0,1\}$-combination is
 not divisible by $n^3$.

## Key Equivalence

**Claim:** The condition "every nonzero $\{-1,0,1\}$-combination $\sum \epsilon_
i x_i \not\equiv 0 \pmod{n^3}$" is equivalent to "all $2^n$ subset sums $\sum_{i
 \in S} x_i$ are distinct modulo $n^3$."

**Proof of equivalence:**

*($\Rightarrow$)* Take distinct subsets $S \neq T$. Set $A = S \setminus T$, $B
= T \setminus S$ (disjoint, not both empty). Define $\epsilon_i = \mathbf{1}_{i
\in A} - \mathbf{1}_{i \in B} \in \{-1,0,1\}$. This is nonzero, so $\sum_S x_i -
 \sum_T x_i = \sum \epsilon_i x_i \not\equiv 0 \pmod{n^3}$.

*($\Leftarrow$)* Take nonzero $(\epsilon_i) \in \{-1,0,1\}^n$. Set $A = \{i : \e
psilon_i = 1\}$, $B = \{i : \epsilon_i = -1\}$ (disjoint, not both empty, so $A
\neq B$). Distinctness of subset sums gives $\sum_A x_i \neq \sum_B x_i \pmod{n^
3}$, hence $\sum \epsilon_i x_i \not\equiv 0 \pmod{n^3}$. $\square$

## Upper Bound: $n \leq 9$

Since all $2^n$ subset sums must be distinct in $\mathbb{Z}_{n^3}$ (which has $n
^3$ elements):

$$2^n \leq n^3$$

Checking: $2^9 = 512 \leq 729 = 9^3$ ✓, but $2^{10} = 1024 > 1000 = 10^3$ ✗.

So **$n \leq 9$**.

## Construction: $n = 9$ works

Take $x_i = 2^{i-1}$ for $i = 1, \dots, 9$, i.e., $x_1, \dots, x_9 = 1, 2, 4, 8,
 16, 32, 64, 128, 256$.

For any $(\epsilon_1, \dots, \epsilon_9) \in \{-1, 0, 1\}^9$:

$$\left|\sum_{i=1}^{9} \epsilon_i \, 2^{i-1}\right| \leq \sum_{i=1}^{9} 2^{i-1}
= 2^9 - 1 = 511$$

Since $n^3 = 729 > 511$, any nonzero combination satisfies $1 \leq |\sum \epsilo
n_i x_i| \leq 511 < 729$, so it cannot be divisible by $729$.

Therefore $n = 9$ is achievable.

## Conclusion

The greatest integer $n$ is $\boxed{9}$.
