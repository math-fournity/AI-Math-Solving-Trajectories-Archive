## Analysis

**(a) At most countably many continuous maps R² → R.**

A continuous function is determined by its values on the dense countable subset
Q², so there are at most |R|^{ℵ₀} = 𝔠 such functions — uncountably many. Indeed,
 f(x,y) = ax+by is continuous for every (a,b) ∈ R², already giving uncountably m
any. **(a) is false.**

**(b) At most finitely many continuous surjective maps R² → R.**

Each f(x,y) = ax+by with (a,b) ≠ (0,0) is continuous and surjective onto R, givi
ng uncountably many. **(b) is false.**

**(c) Infinitely many continuous injective maps R² → R.**

I claim there are **none**. Suppose f: R² → R is continuous and injective. Pick
any point p ∈ R². Since R² \ {p} is connected (path-connected, in fact) and f is
 continuous, the image f(R² \ {p}) is connected, hence an interval in R. By inje
ctivity,

f(R² \ {p}) = f(R²) \ {f(p)}.

So f(R²) \ {f(p)} is an interval, which means f(p) must be an endpoint of the in
terval f(R²).

But this reasoning applies to **every** p ∈ R². Hence every value f(p) is an end
point of the interval f(R²). An interval has at most two endpoints, yet f(R²) co
ntains uncountably many points (R² is uncountable and f is injective). This is a
 contradiction.

Therefore **no continuous injective map R² → R exists**, so there are not infini
tely many. **(c) is false.**

**(d) No continuous bijective maps R² → R.**

A bijection is in particular injective. By the argument above, no continuous inj
ective map R² → R exists, so certainly no continuous bijection exists. **(d) is
true.**

## Proof of (d)

**Theorem.** There is no continuous bijective map from R² to R.

**Proof.** Suppose for contradiction that f: R² → R is continuous and bijective
(hence injective).

**Step 1 (key topological fact).** For any point p ∈ R², the punctured plane R²
\ {p} is path-connected: any two points avoiding p can be joined by a polygonal
path that, if necessary, detours around p using a third point not collinear with
 them and p.

**Step 2 (image of punctured plane is connected).** Since R² \ {p} is connected
and f is continuous, the image f(R² \ {p}) is a connected subset of R, i.e., an
interval.

**Step 3 (injectivity identifies the punctured image).** By injectivity, removin
g p from the domain removes exactly f(p) from the image:
$$f(\mathbb{R}^2 \setminus \{p\}) = f(\mathbb{R}^2) \setminus \{f(p)\}.$$
Since f is surjective (bijective), f(R²) = R, so
$$f(\mathbb{R}^2 \setminus \{p\}) = \mathbb{R} \setminus \{f(p)\}.$$

**Step 4 (contradiction).** R \ {f(p)} is **not** connected (it splits into (-∞,
 f(p)) and (f(p), ∞)). But Step 2 says it must be an interval (connected). This
is a contradiction.

Therefore no continuous bijective map R² → R exists. $\blacksquare$

The true statement is **(d)**.
