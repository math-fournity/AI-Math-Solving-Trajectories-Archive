## Answer: Yes

**Construction.** Consider the closed unit disk $\overline{D} = \{(x,y) \in \mat
hbb{R}^2 : x^2 + y^2 \leq 1\}$, which is a closed set in $\mathbb{R}^2$. Define
the curve $\gamma: [0,\infty) \to \mathbb{R}^2$ by

$$\gamma(t) = \left(\frac{\cos(t^2)}{1+t},\; \frac{\sin(t^2)}{1+t}\right).$$

This is a spiral winding around the origin with radius $r(t) = \frac{1}{1+t}$ an
d angle $\theta(t) = t^2$.

**No self-intersections (injectivity).** Suppose $\gamma(t_1) = \gamma(t_2)$. Ta
king norms, $|\gamma(t_1)| = |\gamma(t_2)|$, so $\frac{1}{1+t_1} = \frac{1}{1+t_
2}$, hence $t_1 = t_2$. The radius is strictly decreasing, so distinct parameter
 values give distinct points. Thus $\gamma$ is injective.

**Infinite length.** Using the polar-coordinate speed formula $|\gamma'(t)|^2 =
r'(t)^2 + r(t)^2\theta'(t)^2$:

$$|\gamma'(t)|^2 = \frac{1}{(1+t)^4} + \frac{4t^2}{(1+t)^2}.$$

For $t \geq 1$, we have $(1+t)^2 \leq (2t)^2 = 4t^2$, so $\frac{4t^2}{(1+t)^2} \
geq 1$. Therefore $|\gamma'(t)| \geq 1$ for all $t \geq 1$, and the arc length s
atisfies

$$L = \int_0^\infty |\gamma'(t)|\,dt \geq \int_1^\infty 1\,dt = \infty.$$

**Contained in a closed set.** Since $|\gamma(t)| = \frac{1}{1+t} \leq 1$ for al
l $t \geq 0$, the entire image of $\gamma$ lies in $\overline{D}$, which is clos
ed.

**Conclusion.** The curve $\gamma$ is injective (no self-intersections), has inf
inite arc length, and is contained in the closed unit disk $\overline{D} \subset
 \mathbb{R}^2$. Therefore, yes, it is possible to construct an infinitely long c
urve within a closed set in $\mathbb{R}^2$ without any self-intersections.

athbb{R}\}$ is closed and contains the ray $\gamma(t) = (t, 0)$, $t \in [0,\inft
