## Proof

Consider the functional
$$J[y] = \int_0^1 \left(y^2 + x^2 y'\right)\,dx, \qquad y(0)=0,\; y(1)=A.$$

The integrand is $F(x,y,y') = y^2 + x^2 y'$.

### Step 1. Euler–Lagrange equation

The Euler–Lagrange equation is
$$\frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\partial F}{\partial y'} = 0
.$$

Compute the partial derivatives:
$$\frac{\partial F}{\partial y} = 2y, \qquad \frac{\partial F}{\partial y'} = x^
2.$$

Hence
$$\frac{d}{dx}\frac{\partial F}{\partial y'} = \frac{d}{dx}(x^2) = 2x.$$

The Euler–Lagrange equation becomes
$$2y - 2x = 0 \quad\Longrightarrow\quad y = x.$$

### Step 2. Degeneracy of the equation

Note that $F$ is **linear** in $y'$ (the term $x^2 y'$), and $\frac{\partial F}{
\partial y'} = x^2$ depends only on $x$, so $\frac{d}{dx}\frac{\partial F}{\part
ial y'} = 2x$ is a known function of $x$. Consequently the Euler–Lagrange equati
on reduces to an **algebraic** relation $y = x$, not a differential equation. Th
ere is no family of extremals with constants of integration; there is a single c
andidate curve.

### Step 3. Imposing the boundary conditions

The unique candidate extremal is $y(x) = x$. Checking the boundary conditions:
- $y(0) = 0$ ✓ (satisfied automatically),
- $y(1) = 1$, which requires $A = 1$.

### Step 4. Conclusion

- **If $A = 1$**: the boundary conditions are compatible with the Euler–Lagrange
 equation, and the unique extremal is
$$\boxed{y(x) = x.}$$

- **If $A \neq 1$**: the algebraic constraint $y = x$ forced by the Euler–Lagran
ge equation is incompatible with the terminal condition $y(1) = A$. Since the eq
uation is degenerate (no integration constants to adjust), **no smooth extremal
exists** satisfying both boundary conditions. In this case the variational probl
em has no extremal in the class of $C^1$ functions satisfying the given endpoint
s; the infimum/ supremum is approached by sequences of admissible functions but
is not attained.

### Remark (equivalent viewpoint)

Writing $x^2 y' = \frac{d}{dx}(x^2 y) - 2xy$, the functional becomes
$$J[y] = \int_0^1 (y^2 - 2xy)\,dx + \bigl[x^2 y\bigr]_0^1 = \int_0^1 (y^2 - 2xy)
\,dx + A.$$

The constant $A$ does not affect the extremal. The reduced integrand $G = y^2 -
2xy$ is independent of $y'$, so the Euler–Lagrange equation is simply $G_y = 2y
- 2x = 0$, confirming $y = x$. Completing the square, $y^2 - 2xy = (y-x)^2 - x^2
 \geq -x^2$, so $J[y] \geq -\int_0^1 x^2\,dx + A = -\tfrac{1}{3} + A$, with equa
lity iff $y = x$ — attainable precisely when $A = 1$.
