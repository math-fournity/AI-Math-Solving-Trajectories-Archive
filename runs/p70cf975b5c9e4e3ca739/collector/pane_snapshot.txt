## Solution

A number $n$ is **awesome** if:
- (i) 3 digits in base 12: $12^2 \le n \le 12^3-1$, i.e. $144 \le n \le 1727$.
- (ii) 4 digits in base 7: $7^3 \le n \le 7^4-1$, i.e. $343 \le n \le 2400$.
- (iii) No digit of $n$ in base 10 is $0$.

The intersection of (i) and (ii) is:
$$343 \le n \le 1727.$$

We count numbers in $[343, 1727]$ with no zero digit in base 10.

### 3-digit numbers: $[343, 999]$

Total 3-digit numbers with no zero digit: $9 \times 9 \times 9 = 729$ (each digi
t $\in \{1,\dots,9\}$), ranging from $111$ to $999$.

Those **below** $343$ with no zero digit:
- $d_1 \in \{1,2\}$: $2 \times 81 = 162$.
- $d_1 = 3,\ d_2 \in \{1,2,3\}$: $3 \times 9 = 27$ (all $< 340$).
- $d_1 = 3,\ d_2 = 4,\ d_3 \in \{1,2\}$: $341, 342$ → $2$.

Total below $343$: $162 + 27 + 2 = 191$.

3-digit awesome candidates: $729 - 191 = \mathbf{538}$.

### 4-digit numbers: $[1000, 1727]$

All have $d_1 = 1$ (no zero). We need $d_2, d_3, d_4 \in \{1,\dots,9\}$ and valu
e $\le 1727$.

- $d_2 \in \{1,2,3,4,5,6\}$: any $d_3, d_4 \in \{1,\dots,9\}$ → $6 \times 81 = 4
86$ (range $1111$–$1699$, all $\le 1727$). ✓
- $d_2 = 7$:
  - $d_3 = 1$: $d_4 \in \{1,\dots,9\}$ → $9$ (range $1711$–$1719$). ✓
  - $d_3 = 2$: $d_4 \in \{1,\dots,7\}$ → $7$ (range $1721$–$1727$). ✓
  - $d_3 \ge 3$: exceeds $1727$. ✗
  - Subtotal: $16$.

4-digit awesome candidates: $486 + 16 = \mathbf{502}$.

### Total

$$538 + 502 = \boxed{1040}.$$
