## 解答

**不等式不成立。** 下面给出一个反例。

---

### 反例

设 $\alpha = \dfrac{3-\sqrt{5}}{2}$，则 $\alpha$ 是多项式 $x^2 - 3x + 1$ 的根。
由于该多项式是首一整系数多项式，$\alpha$ 是代数整数。其共轭为 $\alpha' = \dfrac{
3+\sqrt{5}}{2}$。

注意 $|\alpha| = \dfrac{3-\sqrt{5}}{2} \approx 0.382 < 1$，而 $|\alpha'| = \dfra
c{3+\sqrt{5}}{2} \approx 2.618 > 1$。

取 $a_0 = 1,\ a_1 = \alpha$，考虑射影点 $P = [1 : \alpha] \in \mathbb{P}^1$，数
域 $K = \mathbb{Q}(\sqrt{5})$，$:\mathbb{Q}] = 2$，$K$ 有两个实嵌入 $\sigma_1,
 \sigma_2$。

### 高的计算

对数 Weil 高定义为
$$h(P) = \frac{1}{:\mathbb{Q}]} \sum_{v \in M_K} \max(\log|a_0|_v,\ \log|a_1|_
v).$$

**有限位：** 因为 $a_0 = 1$，所以 $|a_0|_v = 1$ 对所有 $v$ 成立，故 $\max(\log|1
|_v, \log|\alpha|_v) = \max(0, \log|\alpha|_v) = 0$（因为 $\alpha$ 是代数整数，$
|\alpha|_v \le 1$）。有限位贡献为 $0$。

**实位：**
- $\sigma_1(\alpha) = \dfrac{3-\sqrt{5}}{2}$：$\max(\log 1,\ \log|\sigma_1(\alph
a)|) = \max(0,\ \log\frac{3-\sqrt{5}}{2}) = 0$（因为 $\frac{3-\sqrt{5}}{2} < 1$
）。
- $\sigma_2(\alpha) = \dfrac{3+\sqrt{5}}{2}$：$\max(\log 1,\ \log|\sigma_2(\alph
a)|) = \max(0,\ \log\frac{3+\sqrt{5}}{2}) = \log\frac{3+\sqrt{5}}{2}$。

因此
$$h(P) = \frac{1}{2}\left(0 + \log\frac{3+\sqrt{5}}{2}\right) = \frac{1}{2}\log\
frac{3+\sqrt{5}}{2} > 0.$$

### 右端的计算

$$\max_{0 \le i \le 1} \log(\max(1, |a_i|)) = \max\!\left(\log(\max(1,|1|)),\ \l
og(\max(1,|\alpha|))\right) = \max(\log 1,\ \log 1) = 0,$$

其中用到 $|\alpha| = \frac{3-\sqrt{5}}{2} < 1$，故 $\max(1, |\alpha|) = 1$。

### 结论

$$h(a_0, a_1) = \frac{1}{2}\log\frac{3+\sqrt{5}}{2} > 0 = \max_{0 \le i \le 1}\l
og(\max(1, |a_i|)).$$

**不等式不成立。**

### 根本原因

对数 Weil 高对所有共轭（所有嵌入）取值求和，而右端 $\max_i \log(\max(1, |a_i|))$
 仅涉及恒等嵌入下的绝对值。一个代数整数可以在恒等嵌入下模长 $< 1$（使右端为零）
，但在某个共轭嵌入下模长 $> 1$（使高为正），从而导致不等式被违反。
