## Proof

**Setup.** Let $\phi = \frac{1+\sqrt{5}}{2}$, $\bar{\phi} = \frac{1-\sqrt{5}}{2}
$, so that $F_n = \frac{\phi^n - \bar{\phi}^n}{\sqrt{5}}$ and $\phi - \bar{\phi}
 = \sqrt{5}$, $\phi\bar{\phi} = -1$.

**Step 1: 5 is a quadratic non-residue mod $p$.**

By quadratic reciprocity (with $p$ odd): $\left(\frac{5}{p}\right) = \left(\frac
{p}{5}\right)$. Since $p \equiv \pm 2 \pmod{5}$, i.e. $p \equiv 2$ or $3 \pmod{5
}$, and $2,3$ are non-residues mod $5$, we get $\left(\frac{5}{p}\right) = -1$.

**Step 2: Work in $\mathbb{F}_{p^2} = \mathbb{F}_p(\sqrt{5})$.**

Since $\left(\frac{5}{p}\right)=-1$, $\sqrt{5}\notin\mathbb{F}_p$. The Frobenius
 automorphism $\sigma: x\mapsto x^p$ acts on $\sqrt{5}$ by:
$$(\sqrt{5})^p = 5^{(p-1)/2}\cdot\sqrt{5} = \left(\tfrac{5}{p}\right)\sqrt{5} =
-\sqrt{5}.$$

Therefore:
$$\phi^p = \frac{1+(-\sqrt{5})}{2} = \bar{\phi}, \qquad \bar{\phi}^p = \frac{1-(
-\sqrt{5})}{2} = \phi.$$

**Step 3: Key identity $\phi^{p+1} = -1$.**

$$\phi^{p+1} = \phi\cdot\phi^p = \phi\bar{\phi} = \frac{(1+\sqrt{5})(1-\sqrt{5})
}{4} = \frac{1-5}{4} = -1.$$

Likewise $\bar{\phi}^{p+1} = \bar{\phi}\cdot\bar{\phi}^p = \bar{\phi}\phi = -1$.

**Step 4: Compute $\phi^{(p^2+1)/2}$ and $\bar{\phi}^{(p^2+1)/2}$.**

Since $p$ is odd, $p^2+1$ is even, so $n:=\frac{p^2+1}{2}$ is an integer. We dec
ompose:
$$\frac{p^2+1}{2} = \frac{p^2-1}{2}+1 = \frac{(p+1)(p-1)}{2}+1 = (p+1)\cdot\frac
{p-1}{2}+1.$$

Using $\phi^{p+1}=-1$:
$$\phi^{(p^2+1)/2} = \phi^{(p+1)\cdot\frac{p-1}{2}+1} = \left(\phi^{p+1}\right)^
{\frac{p-1}{2}}\cdot\phi = (-1)^{\frac{p-1}{2}}\cdot\phi.$$

Now we use the hypothesis $p\equiv 3\pmod{4}$: then $\frac{p-1}{2}\equiv 1\pmod{
2}$ is odd, so $(-1)^{\frac{p-1}{2}} = -1$. Thus:
$$\phi^{(p^2+1)/2} = -\phi.$$

By the identical computation (using $\bar{\phi}^{p+1}=-1$):
$$\bar{\phi}^{(p^2+1)/2} = (-1)^{\frac{p-1}{2}}\cdot\bar{\phi} = -\bar{\phi}.$$

**Step 5: Conclude.**

$$F_{\frac{p^2+1}{2}} = \frac{\phi^{(p^2+1)/2}-\bar{\phi}^{(p^2+1)/2}}{\sqrt{5}}
 = \frac{(-\phi)-(-\bar{\phi})}{\sqrt{5}} = \frac{\bar{\phi}-\phi}{\sqrt{5}} = \
frac{-(\phi-\bar{\phi})}{\sqrt{5}} = \frac{-\sqrt{5}}{\sqrt{5}} = -1.$$

Therefore:
$$F_{\frac{p^2+1}{2}} \equiv -1 \equiv p-1 \pmod{p}. \qquad\blacksquare$$
