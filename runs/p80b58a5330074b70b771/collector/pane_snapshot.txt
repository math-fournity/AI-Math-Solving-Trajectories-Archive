## Proof

**Answer: No, $G$ is not necessarily a $2$-group.**

### Setup and key observation

Since $G$ is abelian and periodic (every element has finite order), $G$ is a **t
orsion abelian group**. A standard fact: every torsion abelian group decomposes
as the direct product of its $p$-primary components

$$G = \prod_{p \in \mathbb{P}} G_p, \qquad G_p = \{x \in G : \operatorname{ord}(
x) \text{ is a power of } p\}.$$

Because $G$ is abelian, every subgroup is normal, so $O_\pi(G)$ — the normal sub
group generated by all $\pi$-subgroups — is simply the subgroup generated by all
 $\pi$-elements. In a torsion abelian group this set is already a subgroup, name
ly

$$O_\pi(G) = \prod_{p \in \pi} G_p.$$

In particular,

$$O_{2'}(G) = \prod_{p \neq 2} G_p \quad (\text{the odd-order part of } G),$$

and the quotient is

$$G / O_{2'}(G) \cong G_2,$$

which is **always a $2$-group**, for *any* torsion abelian group $G$.

### The hypothesis is vacuous

The hypothesis "$G/O_{2'}(G)$ is a $2$-group" holds for **every** torsion abelia
n group, since the quotient is isomorphic to the $2$-primary component $G_2$. Th
erefore the hypothesis imposes no restriction on the odd-order part $O_{2'}(G)$,
 and $G$ can have arbitrarily large odd-order components while still satisfying
the hypothesis.

### Counterexample

Take $G = \mathbb{Z}/3\mathbb{Z}$, the cyclic group of order $3$. This is abelia
n and periodic.

- Every non-identity element has order $3$, which is odd, so $G$ itself is a $2'
$-subgroup.
- Hence $O_{2'}(G) = G$.
- The quotient $G/O_{2'}(G) \cong \{e\}$ is the trivial group, which is a $2$-gr
oup (the identity has order $1 = 2^0$).

Yet $G = \mathbb{Z}/3\mathbb{Z}$ is a $3$-group, **not** a $2$-group.

### Conclusion

The condition that $G/O_{2'}(G)$ is a $2$-group is automatically satisfied by ev
ery torsion abelian group and does not force $G$ to be a $2$-group. The cyclic g
roup $\mathbb{Z}/3\mathbb{Z}$ provides an explicit counterexample.
