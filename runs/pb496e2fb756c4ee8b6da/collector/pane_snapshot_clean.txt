Looking at this problem, I need to find which 2-connected n-vertex graph maximiz
es S(G) = Σ d_G(x,y).

**Answer: The cycle C_n.**

## Proof

We prove that among all 2-connected graphs on n vertices (n ≥ 3), the cycle C_n
uniquely maximizes S(G).

**Notation.** For a vertex v, let D(v) = Σ_{u≠v} d_G(v,u). Then S(G) = Σ_v D(v).
 Define σ(n) as D(v) for any vertex in C_n:
- n even: σ(n) = n²/4
- n odd: σ(n) = (n²−1)/4

Since every vertex of C_n has distance sum σ(n), we have S(C_n) = n·σ(n).

---

### Step 1: BFS Layer Constraint

Let G be 2-connected on n vertices. Fix v and let L₀={v}, L₁,…,L_r be BFS layers
 (L_i = {u : d(v,u)=i}, r = ecc(v)), with a_i = |L_i|.

**Claim:** a_i ≥ 2 for all 1 ≤ i ≤ r−1.

*Proof.* First, a₁ = deg(v) ≥ 2 since 2-connectivity implies minimum degree ≥ 2.

For i ≥ 2: suppose a_i = 1, say L_i = {w}. In BFS, every edge connects vertices
in the same or adjacent layers (if (u,w') is an edge with u ∈ L_j, w' ∈ L_k, the
n |j−k| ≤ 1). Therefore every path from L_{i+1} ∪ ⋯ ∪ L_r to L₀ ∪ ⋯ ∪ L_{i−1} mu
st pass through L_i = {w}. Since i ≤ r−1, L_{i+1} ≠ ∅, and L₀ = {v} ≠ ∅. Thus G
− w is disconnected, contradicting 2-connectivity. □

---

### Step 2: Per-Vertex Bound

**Claim:** For every vertex v in a 2-connected G on n vertices, D(v) ≤ σ(n).

*Proof.* We maximize D(v) = Σ_{i=1}^r i·a_i subject to:
- a_i ≥ 2 for 1 ≤ i ≤ r−1, a_r ≥ 1 (Step 1),
- Σ a_i = n−1,
- r ≤ ⌊n/2⌋ (since n−1 = Σ a_i ≥ 2(r−1)+1 = 2r−1, so r ≤ n/2).

To maximize, we want r as large as possible and as much mass as possible in the
highest layer. Set r = ⌊n/2⌋ and a_i = 2 for 1 ≤ i ≤ r−1 (the minimum), with all
 remaining mass in layer r.

**n even (r = n/2):** a_r = (n−1) − 2(n/2−1) = 1.
$$D(v) = 2\!\left(1+2+\cdots+\tfrac{n}{2}-1\right) + \tfrac{n}{2} = \left(\tfrac
{n}{2}-1\right)\tfrac{n}{2} + \tfrac{n}{2} = \tfrac{n^2}{4} = \sigma(n).$$

**n odd (r = (n−1)/2):** a_r = (n−1) − 2((n−1)/2−1) = 2.
$$D(v) = 2\!\left(1+\cdots+\tfrac{n-3}{2}\right) + 2\cdot\tfrac{n-1}{2} = \tfrac
{(n-3)(n-1)}{4} + (n-1) = \tfrac{n^2-1}{4} = \sigma(n).$$

For any r < ⌊n/2⌋, the sum is strictly smaller: reducing r by 1 removes the high
est layer (losing at least 2·r from the sum) and redistributes that mass to lowe
r layers. For example, with r = n/2−1 (n even): D(v) = (n/2−1)(n/2+1) = n²/4 − 1
 < σ(n). Similarly for n odd. Hence D(v) ≤ σ(n). □

---

### Step 3: Global Bound and Equality

Summing over all vertices:
$$S(G) = \sum_{v \in V} D(v) \le n \cdot \sigma(n) = S(C_n).$$

**Equality** holds iff D(v) = σ(n) for every v. The tight case of Step 2 require
s a₁ = 2 for every vertex v, meaning every vertex has degree exactly 2. A connec
ted 2-regular graph is a cycle, so G = C_n. Conversely, C_n achieves S(C_n) = n·
σ(n). ∎

---

**Conclusion:** The cycle C_n is the unique 2-connected n-vertex graph that maxi
mizes S(G) = Σ_{x,y} d_G(x,y).
