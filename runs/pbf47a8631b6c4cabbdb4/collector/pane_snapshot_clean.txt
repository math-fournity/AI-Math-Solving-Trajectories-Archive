## Proof

**Interpretation.** We seek a function $f(A,B)$ of the operator pair $(A,B)$ wit
h $B=A^\dagger$, such that (i) $f(A,B)^\dagger = f(A,B)$ (Hermitian), and (ii) $
f(A,B)$ is **not** expressible as a function of the single operator $A+B$ alone
(i.e. there is no function $g$ with $f(A,B)=g(A+B)$ identically).

**Construction.** Define
$$f(A,B) := AB.$$

**Hermiticity.** Using $A^\dagger = B$ (hence $B^\dagger = A$):
$$(AB)^\dagger = B^\dagger A^\dagger = A\cdot B = AB.$$
So $f(A,B)^\dagger = f(A,B)$. $\checkmark$

**Not a function of $A+B$ alone.** It suffices to exhibit a single pair $(A,B)$
with $B=A^\dagger$ for which $AB$ is not in the algebra generated by $A+B$ (equi
valently, not a function of $A+B$).

Take the $2\times 2$ matrix
$$A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, \qquad B = A^\dagger = \begi
n{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}.$$

Then
$$A + B = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} = \sigma_x \quad\text{(Pa
uli }X\text{)},$$
while
$$AB = AA^\dagger = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} = P_+ \quad\tex
t{(projector onto }|0\rangle\langle 0|\text{)}.$$

Any function $g(A+B) = g(\sigma_x)$ is diagonal in the eigenbasis of $\sigma_x$,
 namely $\{|+\rangle,|-\rangle\}$ with $|{\pm}\rangle = \tfrac{1}{\sqrt2}(|0\ran
gle \pm |1\rangle)$. Concretely,
$$g(\sigma_x) = \begin{pmatrix} g(1) & 0 \\ 0 & g(-1) \end{pmatrix}_{\{|+\rangle
,|-\rangle\}}.$$

But $AB = P_+ = |0\rangle\langle 0|$ in the $\{|+\rangle,|-\rangle\}$ basis is
$$P_+ = \frac12\begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}_{\{|+\rangle,|-\rang
le\}},$$
which is **not diagonal** — hence not of the form $g(\sigma_x)$ for any $g$. (Eq
uivalently: $g(\sigma_x)$ always commutes with $\sigma_x$, yet $[AB,\,\sigma_x]
= [P_+,\sigma_x] \neq 0$, since $P_+\sigma_x = \begin{pmatrix}0&1\\0&0\end{pmatr
ix}$ while $\sigma_x P_+ = \begin{pmatrix}0&0\\1&0\end{pmatrix}$.)

Therefore $AB \neq g(A+B)$ for any function $g$.

**Conclusion.** Such a Hermitian function exists; $f(A,B)=AB$ is an explicit exa
mple that is Hermitian yet not reducible to a function of $A+B$ alone.
