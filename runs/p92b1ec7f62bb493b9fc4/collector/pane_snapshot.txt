## Proof

The net vertical force is:

$$F = \sin 80° + \sin 50° - \sin 20°$$

**Step 1: Combine $\sin 80° - \sin 20°$ using the sum-to-product identity.**

$$\sin A - \sin B = 2\cos\!\left(\tfrac{A+B}{2}\right)\sin\!\left(\tfrac{A-B}{2}
\right)$$

$$\sin 80° - \sin 20° = 2\cos 50° \sin 30° = 2\cos 50° \cdot \tfrac{1}{2} = \cos
 50°$$

**Step 2: Add $\sin 50°$.**

$$F = \cos 50° + \sin 50°$$

**Step 3: Express as a single sine with amplitude $\sqrt{2}$.**

$$\cos 50° + \sin 50° = \sqrt{2}\left(\tfrac{1}{\sqrt{2}}\sin 50° + \tfrac{1}{\s
qrt{2}}\cos 50°\right) = \sqrt{2}\,\sin(50° + 45°) = \sqrt{2}\,\sin 95°$$

**Step 4: Reduce into the range $0 \le n \le 90$.**

Since $\sin 95° = \sin(180° - 95°) = \sin 85°$,

$$F = \sqrt{2}\,\sin 85°$$

**Step 5: Identify $n$.**

The stability constant is $\sqrt{2}\sin n°$ with $0 \le n \le 90$ integer. Match
ing:

$$\sqrt{2}\,\sin n° = \sqrt{2}\,\sin 85° \implies n = 85$$

$$\boxed{n = 85}$$
