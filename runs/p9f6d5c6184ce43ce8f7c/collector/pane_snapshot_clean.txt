- **N**: maximum size of a subset of {1,...,200} where no element divides anothe

- **m**: largest integer such that every maximum antichain has all elements ≥ m

## Finding N

**Chain decomposition**: Every integer n ≤ 200 can be written uniquely as 2^k ·
d where d is odd. For each odd d ∈ {1, 3, 5, ..., 199}, form the chain C_d = {d,
 2d, 4d, ...} ∩ {1,...,200}. These 100 chains partition {1,...,200}.

By **Dilworth's theorem**, the maximum antichain size ≤ number of chains = 100.

The set {101, 102, ..., 200} achieves 100 elements (if a | b with both > 100, th
en b ≥ 2a > 200, contradiction). So **N = 100**.

A maximum antichain must pick exactly one element from each chain. If we pick 2^

**For all odd d₁ | d₂ with d₁ < d₂: i(d₁) > i(d₂)**

(since 2^{i(d₁)}d₁ | 2^{i(d₂)}d₂ requires d₁|d₂ and i(d₁) ≤ i(d₂); we prevent th
is by requiring i(d₁) > i(d₂)).

**Minimum feasible i(d)**: Let L(d) = (longest chain of odd numbers starting at
d) − 1. Since i must be strictly decreasing along divisibility chains, i(d) ≥ L(
d). The function L itself is strictly order-reversing (if d₁|d₂, any chain from

**Longest odd divisibility chain in {1,...,199}**: Each ratio in the chain is an
