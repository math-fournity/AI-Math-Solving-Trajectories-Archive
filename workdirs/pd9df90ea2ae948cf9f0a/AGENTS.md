# Problem

A specialized high-performance supercomputer is processing two different types of computational tasks. 

The first task involves a sequence of "Power-Up" cycles. In this sequence, the value starts with the number 2, and for each level of the sequence, the previous result becomes the exponent of a new base of 2. For a sequence of length $n$, the total value is represented by a power tower of $n$ twos.

The second task involves a sequence of "Factorial-Stress" tests. This process begins with the value $100!$ (the product of all integers from 1 to 100). The system then repeatedly applies the factorial operation to the previous result. This stress test is performed for a total of 100 nested factorial operations (where the first operation is the $100!$ inside the chain).

Find the smallest positive integer $n$ such that the value produced by the "Power-Up" sequence of length $n$ is strictly greater than the value produced by the 100-level "Factorial-Stress" test.
