## Analysis of a Single Parallel Shift

Since all packets start in the same row and end in the same row after each shift
, every packet has the same vertical displacement $\Delta r$. Since each moves a
long a diagonal, $|\Delta c| = |\Delta r|$ for every packet. Setting $d = |\Delt
a r|$, each packet at column $c$ moves to column $c + d$ or $c - d$ (whichever s
tays in bounds), and all resulting columns must be distinct.

**Determining valid $d$:** The columns $\{1, \ldots, 2^n\}$ split into residue c
lasses mod $d$, each forming a path. A valid assignment requires a perfect match
ing on each path, so every class must have even size. This forces $d \mid 2^n$ w
ith $2^n/d$ even, meaning $d = 2^k$ for $k \in \{0, 1, \ldots, n-1\}$.

**Uniqueness of the column permutation:** For $d = 2^k$, each residue class (pat
h) has $2^{n-k}$ vertices. A path graph $P_m$ with $m$ even has a **unique** per
fect matching: $\{1,2\}, \{3,4\}, \ldots$ (vertex 1 must match vertex 2, then ve
rtex 3 must match vertex 4, etc.). So the column permutation is uniquely determi
ned.

**Identifying the permutation:** In 0-indexed columns $\{0, \ldots, 2^n-1\}$, th
e matching pairs $c$ with $c \oplus 2^k$ — this is exactly **flipping bit $k$**
of the column index. Call this permutation $\pi_k$.

## Composition of Shifts

The overall column permutation is $\pi_{k_1} \circ \pi_{k_2} \circ \cdots \circ
\pi_{k_m}$. Since bit-flips on different bits commute, the result is determined
by which bits are flipped an **odd** number of times. Let $S \subseteq \{0, \ldo
ts, n-1\}$ be the set of bits flipped an odd number of times. The final permutat
ion is:
$$\sigma(i) = (i-1) \oplus \left(\textstyle\sum_{k \in S} 2^k\right) + 1$$

This is always a bit-flip permutation, so only bit-flip permutations are achieva
ble.

## Row Trajectory Constraint

The row starts at 1 and must reach $2^n$, with each step changing the row by $\p
m 2^k$. The total displacement is:
$$\sum_{k=0}^{n-1} c_k \cdot 2^k = 2^n - 1$$
where $c_k$ is the net signed count of steps using $d = 2^k$. Bit $k$ is in $S$
iff $c_k$ is odd (and nonzero).

**Bit 0 is forced into $S$:** Reducing mod 2: $c_0 \equiv 1 \pmod{2}$, so $c_0$
is always odd. Thus $0 \in S$ always.

**Bits $1, \ldots, n-1$ are free:** Starting from the canonical solution $c_k =
1$ for all $k$ (giving $S = \{0,1,\ldots,n-1\}$, with path $1 \to 2 \to 4 \to \c
dots \to 2^n$), I can toggle bit $k$ out of $S$ by replacing the step $+2^k$ wit
h $2^k$ steps of $+1$. This changes $c_k$ from 1 to 0 (even) and $c_0$ from 1 to
 $1 + 2^k$ (still odd), preserving the sum. The row trajectory becomes monotone
increasing through $[1, 2^n]$, so it stays in bounds.

For any subset $T \subseteq \{1, \ldots, n-1\}$, applying this replacement to ea
ch $k \in T$ yields $S = \{0\} \cup (\{1,\ldots,n-1\} \setminus T)$, with a vali
d monotone trajectory. This produces all $2^{n-1}$ subsets containing bit 0.

The achievable permutations are exactly the bit-flip permutations $\sigma(i) = (
