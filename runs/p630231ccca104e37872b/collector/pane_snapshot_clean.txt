## Proof

Let $A_1 = \{a_1 < |z| < a_2\}$ and $A_2 = \{b_1 < |z| < b_2\}$, and let $f: A_1
 \to A_2$ be a conformal (biholomorphic) mapping.

### Step 1: Lifting to the universal cover

The universal cover of an annulus $\{r_1 < |z| < r_2\}$ is the vertical strip $\
{\log r_1 < \operatorname{Re} w < \log r_2\}$ via the covering map $w \mapsto e^
w$. Set
$$T_1 = \{\log a_1 < \operatorname{Re} w < \log a_2\}, \qquad T_2 = \{\log b_1 <
 \operatorname{Re} w < \log b_2\}.$$
Both have deck transformation $w \mapsto w + 2\pi i$.

The map $f$ lifts to a biholomorphism $F: T_1 \to T_2$ satisfying $e^{F(w)} = f(
e^w)$. Since $f$ is a bijection, the induced map on $\pi_1(A_1)\cong\mathbb{Z}$
is an isomorphism, so
$$F(w + 2\pi i) = F(w) + 2\pi i k, \qquad k \in \{+1, -1\}. \tag{$*$}$$

### Step 2: $F$ is affine

The biholomorphism $F: T_1 \to T_2$ maps each boundary line $\operatorname{Re} w
 = \log a_j$ to a boundary line of $T_2$. By the Schwarz reflection principle, $
F$ extends analytically across each boundary line by simultaneous reflection in
the source and target strips. Iterating this reflection extends $F$ to an entire
 function $\widetilde{F}: \mathbb{C} \to \mathbb{C}$. Since each reflected piece
 is a biholomorphism on its strip and the pieces glue uniquely by analytic conti
nuation, $\widetilde{F}$ is injective on all of $\mathbb{C}$. An injective entir
e function is affine, so
$$F(w) = \alpha w + \beta, \qquad \alpha \neq 0.$$

### Step 3: Determining $\alpha$ — the modulus condition

Since $F$ maps the vertical strip $T_1$ (where $\operatorname{Re} w$ is bounded
and $\operatorname{Im} w$ is free) onto the vertical strip $T_2$, we need $\oper
atorname{Re} F = \operatorname{Re}(\alpha)\operatorname{Re} w - \operatorname{Im
}(\alpha)\operatorname{Im} w + \operatorname{Re}\beta$ to be bounded for all $\o
peratorname{Im} w \in \mathbb{R}$. This forces $\operatorname{Im}(\alpha) = 0$,
so $\alpha \in \mathbb{R}\setminus\{0\}$.

The image of the interval $(\log a_1, \log a_2)$ under $x \mapsto \alpha x + \op
eratorname{Re}\beta$ must equal $(\log b_1, \log b_2)$, giving
$$|\alpha| = \frac{\log(b_2/b_1)}{\log(a_2/a_1)}.$$

From the deck transformation condition $(*)$: $F(w+2\pi i) = F(w) + 2\pi i\,\alp
ha$, so $\alpha = k \in \{+1,-1\}$. Therefore
$$\frac{\log(b_2/b_1)}{\log(a_2/a_1)} = 1, \qquad\text{i.e.,}\qquad \boxed{\dfra
c{a_2}{a_1} = \dfrac{b_2}{b_1}}.$$

**If $a_2/a_1 \neq b_2/b_1$, no conformal mapping exists.**

### Step 4: Classification when $a_2/a_1 = b_2/b_1$

Assume $a_2/a_1 = b_2/b_1 =: \rho$.

**Case $k = +1$ ($\alpha = 1$):** Then $F(w) = w + \beta$ with $\operatorname{Re
}\beta = \log(b_1/a_1)$ and $\operatorname{Im}\beta =: \theta \in \mathbb{R}$ fr
ee. Writing $\beta = \log(b_1/a_1) + i\theta$:
$$f(z) = e^{F(\log z)} = e^{\log z + \log(b_1/a_1) + i\theta} = \frac{b_1}{a_1}\
,e^{i\theta}\, z.$$
Verification: $|f(z)| = \frac{b_1}{a_1}|z| \in \bigl(b_1,\; b_1\rho\bigr) = (b_1
, b_2)$. ✓

**Case $k = -1$ ($\alpha = -1$):** Then $F(w) = -w + \beta$ with $\operatorname{
Re}\beta = \log(a_1 b_2)$ (from $-\log a_1 + \operatorname{Re}\beta = \log b_2$)
 and $\operatorname{Im}\beta =: \theta \in \mathbb{R}$ free. Writing $\beta = \l
og(a_1 b_2) + i\theta$:
$$f(z) = e^{F(\log z)} = e^{-\log z + \log(a_1 b_2) + i\theta} = \frac{a_1 b_2\,
 e^{i\theta}}{z}.$$
Verification: $|f(z)| = \frac{a_1 b_2}{|z|}$. At $|z|=a_1$: $|f|=b_2$; at $|z|=a
_2$: $|f|=\frac{a_1 b_2}{a_2} = b_1$ (using $a_1/a_2 = b_1/b_2$). So $|f(z)|\in(
b_1,b_2)$. ✓ (The inner and outer boundaries are swapped.)

Note that $a_1 b_2 = b_1 a_2$ (since $b_2/b_1 = a_2/a_1$), so the second family
can equivalently be written $f(z) = \frac{a_2 b_1\, e^{i\theta}}{z}$.

### Conclusion

A conformal mapping $f: \{a_1 < |z| < a_2\} \to \{b_1 < |z| < b_2\}$ exists **if
 and only if**
$$\frac{a_2}{a_1} = \frac{b_2}{b_1}.$$

When this holds, every such mapping is of one of the following two forms, for so
me $\theta \in \mathbb{R}$:

$$\boxed{f(z) = \frac{b_1}{a_1}\,e^{i\theta}\,z} \qquad\text{or}\qquad \boxed{f(
z) = \frac{a_1 b_2\,e^{i\theta}}{z} = \frac{a_2 b_1\,e^{i\theta}}{z}.}$$

The first family consists of rotations composed with the scaling $z \mapsto \fra
c{b_1}{a_1}z$ (preserving inner/outer boundaries); the second consists of rotati
ons composed with the inversion $z \mapsto \frac{a_1 b_2}{z}$ (swapping inner/ou
ter boundaries).
