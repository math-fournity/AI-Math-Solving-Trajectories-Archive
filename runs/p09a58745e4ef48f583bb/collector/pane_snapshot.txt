## Setup

Let $M = \Phi_q(p) = 1 + p + p^2 + \cdots + p^{q-1} = \frac{p^q - 1}{p-1}$.

**Base-$p$ representation of $M$:** Since $M = \sum_{i=0}^{q-1} p^i$, in base $p
$ we have $M = \underbrace{11\cdots1}_{q}$ (all digits are 1).

**Base-$p$ representation of $2M$:** $2M = \sum_{i=0}^{q-1} 2p^i$. Since $p \ge
3 > 2$, no carries occur, so $2M = \underbrace{22\cdots2}_{q}$ in base $p$.

## Applying Lucas' Theorem

By Lucas' theorem, $\binom{n}{k} \not\equiv 0 \pmod{p}$ iff each base-$p$ digit
of $k$ is $\le$ the corresponding digit of $n$.

**Condition $\binom{N}{M} \not\equiv 0 \pmod{p}$:** Each digit of $M$ is 1 (posi
tions $0$ to $q-1$) and 0 beyond. So we need $N_i \ge 1$ for $i = 0, \ldots, q-1
$.

**Condition $\binom{2M}{N} \not\equiv 0 \pmod{p}$:** Each digit of $2M$ is 2 (po
sitions $0$ to $q-1$) and 0 beyond. So we need $N_i \le 2$ for $i = 0, \ldots, q
-1$, and $N_i = 0$ for $i \ge q$.

**Combined:** $N$ has exactly $q$ base-$p$ digits, each equal to 1 or 2.

## Computing the congruence

Let $b$ = number of digits of $N$ equal to 2 (so $q - b$ digits equal 1).

By Lucas' theorem:
$$\binom{N}{M} \equiv \prod_{i=0}^{q-1} \binom{N_i}{1} = \prod_{i=0}^{q-1} N_i =
 2^b \pmod{p}$$

$$\binom{2M}{N} \equiv \prod_{i=0}^{q-1} \binom{2}{N_i} = 2^{q-b} \pmod{p}$$

since $\binom{2}{1} = 2$ and $\binom{2}{2} = 1$.

The congruence $\binom{N}{M} \equiv \binom{2M}{N} \pmod{p}$ becomes:
$$2^b \equiv 2^{q-b} \pmod{p} \iff 2^{2b - q} \equiv 1 \pmod{p}$$

## The key condition

Let $d = \operatorname{ord}_p(2)$. We need $d \mid (2b - q)$ for some $b \in \{0
, 1, \ldots, q\}$, i.e., $2b \equiv q \pmod{d}$.

**If $d$ is even:** $\gcd(2, d) = 2$, so $2b \equiv q \pmod{d}$ requires $q \equ
iv 0 \pmod{2}$. But $q$ is an odd prime — **no solution**.

**If $d$ is odd:** $\gcd(2, d) = 1$, so for any $q$ there exists a unique $b_0 \
in \{0, \ldots, d-1\}$ with $2b_0 \equiv q \pmod{d}$. Choosing any odd prime $q
\ge d - 1$ ensures $b_0 \le q$. **Solution exists**.

Therefore, $p$ qualifies **if and only if $\operatorname{ord}_p(2)$ is odd**.
