Looking at this problem, I need to determine whether the condition $\mu^*(A \cap
 I) < \mu(I)$ for all open intervals $I$ forces a bounded set $A$ to have measur
e zero.

**Answer: No.** A fat Cantor set provides a counterexample.

## Proof

**Construction (Smith–Volterra–Cantor set).** Define a set $C \subset [0,1]$ as
follows. Start with $[0,1]$. At step $n \geq 1$, from each of the $2^{n-1}$ rema
ining closed intervals, remove the middle open interval of length $\frac{1}{2^{2
n}}$. The total length removed is

$$\sum_{n=1}^{\infty} 2^{n-1} \cdot \frac{1}{2^{2n}} = \sum_{n=1}^{\infty} \frac
{1}{2^{n+1}} = \frac{1}{2}.$$

Let $C$ be the intersection of all the closed sets remaining after each step. Th
en:

1. **$C$ is closed** (intersection of closed sets), hence Lebesgue measurable.
2. **$C$ is nowhere dense**: at every step, open intervals are removed from ever
y remaining interval, so $C$ contains no open interval; equivalently, the comple
ment $[0,1]\setminus C$ is open and dense in $[0,1]$.
3. **$\mu(C) = 1 - \frac{1}{2} = \frac{1}{2} > 0$.**

**Verification of the condition.** Let $I$ be any open interval. We show $\mu^*(
C \cap I) < \mu(I)$.

*Case 1: $I \cap [0,1] = \emptyset$.* Then $C \cap I = \emptyset$, so $\mu^*(C \
cap I) = 0 < \mu(I)$. ✓

*Case 2: $I \subseteq [0,1]$ (open interval).* Since $C$ is nowhere dense, the o
pen set $I \setminus C$ is nonempty (in fact dense in $I$). Being a nonempty ope
n set, it contains an open subinterval, so $\mu(I \setminus C) > 0$. Since $C$ i
s measurable:

$$\mu(C \cap I) = \mu(I) - \mu(I \setminus C) < \mu(I).$$

Since $C$ is measurable, $\mu^*(C \cap I) = \mu(C \cap I) < \mu(I)$. ✓

*Case 3: $I$ extends beyond $[0,1]$.* Then $I \setminus [0,1]$ is a nonempty ope
n set with positive measure, and $I \setminus C \supseteq I \setminus [0,1]$, so
 $\mu(I \setminus C) \geq \mu(I \setminus [0,1]) > 0$. Again by measurability of
 $C$:

$$\mu^*(C \cap I) = \mu(C \cap I) = \mu(I) - \mu(I \setminus C) < \mu(I). \quad
\checkmark$$

**Conclusion.** The set $C$ is bounded, satisfies $\mu^*(C \cap I) < \mu(I)$ for
 every open interval $I$, yet $\mu(C) = \frac{1}{2} \neq 0$. Therefore, the cond
ition does **not** force $A$ to have measure zero.

The key insight is that the condition $\mu^*(A \cap I) < \mu(I)$ for all open $I
$ is equivalent (for measurable $A$) to saying that $A$ is **nowhere dense** in
measure-theoretic terms—every open interval has a portion of positive measure ou
tside $A$. This is strictly weaker than having measure zero: a nowhere dense clo
sed set can still carry positive measure, as the fat Cantor set demonstrates.
