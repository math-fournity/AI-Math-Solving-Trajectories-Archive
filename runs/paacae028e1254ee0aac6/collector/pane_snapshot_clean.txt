# Proof: Maximum Number of Laboratories is 5

## Setup

We model the network as a complete graph $K_n$ with each edge colored one of thr
ee colors $\{1, 2, 3\}$ (Fiber-optic, Satellite, Microwave), subject to:

- **Constraint 1:** Each vertex uses at most 2 colors among its incident edges.
- **Constraint 2:** No monochromatic triangle.

For each vertex $v$, let $C(v)$ denote the set of colors appearing on edges inci
dent to $v$. We have $|C(v)| \leq 2$.

## Key Structural Observation

For any edge $uv$ of color $c$, we need $c \in C(u) \cap C(v)$. Therefore **ever
y pair of vertices must share at least one color**: $C(u) \cap C(v) \neq \emptys
et$ for all $u, v$.

Partition vertices by their color-use set $C(v) \in \big\{\{1\}, \{2\}, \{3\}, \
{1,2\}, \{1,3\}, \{2,3\}\big\}$. Denote $S_{ij} = \{v : C(v) = \{i,j\}\}$ and $S
_k = \{v : C(v) = \{k\}\}$.

**Compatibility:** Two groups can coexist only if their color sets intersect. Th
is rules out many pairs:
- $S_1$ cannot coexist with $S_2$, $S_3$, or $S_{23}$ (disjoint color sets). Sim
ilarly for $S_2$, $S_3$.
- At most **one** single-color group $S_k$ can be non-empty.

## Case Analysis

### Case 1: Only one two-color group is non-empty (e.g., $S_{12} \neq \emptyset$
, all others empty)

All edges use colors 1 and 2 — a 2-coloring of $K_n$. Constraint 2 requires no m
onochromatic triangle. By the Ramsey number $R(3,3) = 6$, every 2-coloring of $K
_6$ contains a monochromatic triangle, so $n \leq 5$. The 5-cycle coloring achie
ves $n = 5$ (verified below).

### Case 2: Exactly two two-color groups non-empty (e.g., $S_{12}, S_{13} \neq \
emptyset$)

Edges between $S_{12}$ and $S_{13}$ are forced to color 1 (the only common color
). Pick any $w \in S_{13}$; for $u_1, u_2 \in S_{12}$, edges $u_1w, u_2w$ are bo
th color 1, so $u_1u_2$ must be color 2 (to avoid a monochromatic triangle). Thu
s **all edges within $S_{12}$ are color 2**, forcing $|S_{12}| \leq 2$. Symmetri
cally, $|S_{13}| \leq 2$. Total: $n \leq 4$.

### Case 3: All three two-color groups non-empty ($S_{12}, S_{13}, S_{23} \neq \
emptyset$)

Edges between groups are forced: $S_{12}$–$S_{13}$ → color 1, $S_{12}$–$S_{23}$
→ color 2, $S_{13}$–$S_{23}$ → color 3.

Within $S_{12}$: Since $S_{13} \neq \emptyset$, edges within $S_{12}$ cannot be
color 1 (else monochromatic triangle with any vertex of $S_{13}$), so they must
be color 2. Since $S_{23} \neq \emptyset$, edges within $S_{12}$ cannot be color
 2, so they must be color 1. **Contradiction** unless $|S_{12}| \leq 1$. Similar
ly $|S_{13}| \leq 1$, $|S_{23}| \leq 1$. Total: $n \leq 3$.

### Case 4: One two-color group + one compatible single-color group (e.g., $S_{1
2}, S_1 \neq \emptyset$)

Edges between $S_1$ and $S_{12}$ are color 1. Within $S_1$: all edges color 1, s
o $|S_1| \leq 2$. Within $S_{12}$: any $w \in S_1$ forces edges within $S_{12}$
to be color 2, so $|S_{12}| \leq 2$. Total: $n \leq 4$.

### Case 5: Three groups including a single-color group (e.g., $S_{12}, S_{13},
S_1 \neq \emptyset$)

Edges $S_{12}$–$S_{13}$ = color 1, $S_1$–$S_{12}$ = color 1, $S_1$–$S_{13}$ = co
lor 1. Taking $u \in S_{12}, v \in S_{13}, w \in S_1$: triangle $uvw$ has all ed
ges color 1 — **monochromatic triangle**. Impossible. All such three-group confi
gurations with a single-color group yield either incompatibility (Case: disjoint
 sets) or monochromatic triangles.

### Case 6: Only single-color groups

At most one $S_k$ can be non-empty; all edges are one color, so $|S_k| \leq 2$.
Total: $n \leq 2$.

## Summary of Upper Bounds

| Configuration | Max $n$ |
|---|---|
| One two-color group | **5** |
| Two two-color groups | 4 |
| Three two-color groups | 3 |
| One two-color + one single-color | 4 |
| Three groups with single-color | impossible |
| One single-color group | 2 |

The overall maximum is $n \leq 5$.

## Construction Achieving $n = 5$

Take 5 vertices $\{1,2,3,4,5\}$. Color the 5-cycle edges $\{12, 23, 34, 45, 51\}
$ with color 1, and the complementary 5-cycle edges $\{13, 35, 52, 24, 41\}$ wit
h color 2. (Color 3 is unused.)

- **No monochromatic triangle:** Each color class is a 5-cycle, which contains n
o triangle. ✓
- **Each vertex uses at most 2 colors:** Each vertex has 2 edges of color 1 and
2 edges of color 2, using exactly colors $\{1, 2\}$. ✓

## Conclusion

The maximum possible number of laboratories is $\boxed{5}$.
