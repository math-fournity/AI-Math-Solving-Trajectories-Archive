Looking at this problem, I need to determine whether checking membership of a po
int $t$ in the fundamental parallelepiped of a lattice can be done in polynomial
 time.

## Proof

**Setup.** Let $\mathcal{L}(B) = \{\sum_{i=1}^n x_i b_i : x_i \in \mathbb{Z}\}$
where $B = [b_1 | \cdots | b_n]$ is an $n \times n$ matrix with linearly indepen
dent (hence full-rank, hence invertible) columns. The **fundamental parallelepip
ed** is:
$$\mathcal{P}(B) = \{Bx : x \in \mathbb{R}^n,\; 0 \le x_i < 1 \text{ for all } i
\}.$$
We assume the standard computational model: $B$ and $t$ have rational (in partic
ular, integer) entries, and the input size is the total number of bits to repres
ent them.

**Claim.** Yes, it is possible to check in polynomial time whether $t \in \mathc
al{P}(B)$.

**Algorithm.**

1. **Solve the linear system $Bx = t$.** Since $B$ is invertible, the solution $
x = B^{-1}t$ exists and is unique. Compute it via Gaussian elimination (or Crame
r's rule).

2. **Check the coordinate bounds.** Output YES if and only if $0 \le x_i < 1$ fo
r every $i = 1, \ldots, n$.

**Correctness.** By definition, $t \in \mathcal{P}(B)$ if and only if there exis
ts $x \in \mathbb{R}^n$ with $Bx = t$ and $0 \le x_i < 1$ for all $i$. Since $B$
 is invertible, the representation $t = Bx$ is unique, so $x = B^{-1}t$ is the o
nly candidate. The check $0 \le x_i < 1$ for all $i$ is therefore both necessary
 and sufficient.

**Polynomial-time analysis (bit complexity).** Suppose all entries of $B$ and $t
$ are integers with bit size at most $s$.

- **Solving $Bx = t$:** Using Cramer's rule, $x_i = \det(B_i)/\det(B)$, where $B
_i$ is $B$ with its $i$-th column replaced by $t$. By the Hadamard bound, $|\det
(B)|$ and $|\det(B_i)|$ are at most $\prod_j \|b_j\| \le (2^s \sqrt{n})^n$, so t
heir bit sizes are $O(ns)$. Computing an $n \times n$ determinant is polynomial
time (e.g., via the Bareiss algorithm, which performs $O(n^3)$ arithmetic operat
ions with intermediate values of bit size $O(ns)$). Thus each $x_i$ is a ratio o
f two integers of polynomial bit size, computable in polynomial time. (Equivalen
tly, Gaussian elimination with rational arithmetic maintains polynomially-bounde
d intermediate bit sizes.)

- **Checking $0 \le x_i < 1$:** Each $x_i = p_i/q_i$ is rational with $|p_i|, |q
_i|$ of bit size $O(ns)$. The test $0 \le p_i/q_i < 1$ reduces to comparing inte
gers of polynomial bit size (accounting for the sign of $q_i$), which is polynom
ial time.

- **Total:** The algorithm performs $O(n)$ determinant computations (or one Gaus
sian elimination) plus $n$ rational comparisons, all in time polynomial in $n$ a
nd $s$. $\square$

**Remark.** This problem is fundamentally easier than hard lattice problems (SVP
, CVP). Those problems require searching over an exponentially large set of latt
ice vectors. In contrast, fundamental parallelepiped membership reduces to a sin
gle linear solve (inverting $B$) followed by trivial coordinate comparisons—pure
 linear algebra, with no combinatorial search.
