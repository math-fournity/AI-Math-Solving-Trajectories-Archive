## Proof

**Setup.** Let $f(t,x)$ be a solution periodic in $t$ with period $T > 0$. Set $
\omega = 2\pi/T$. Since $f$ is periodic in $t$, under suitable regularity assump
tions (e.g., $f$ is $C^2$), we may expand $f$ in a Fourier series in $t$:

$$f(t,x) = \sum_{n=-\infty}^{\infty} f_n(x)\, e^{in\omega t},$$

where $f_n(x) = \frac{1}{T}\int_0^T f(t,x)\,e^{-in\omega t}\,dt$, and the series
 converges appropriately.

**Substitution into the PDE.** Computing the derivatives:

$$\frac{\partial^2 f}{\partial t^2} = \sum_{n=-\infty}^{\infty} \left(-n^2\omega
^2\right) f_n(x)\, e^{in\omega t}, \qquad \frac{\partial^2 f}{\partial x^2} = \s
um_{n=-\infty}^{\infty} f_n''(x)\, e^{in\omega t}.$$

Substituting into $f_{tt} - f_{xx} = cf$:

$$\sum_{n=-\infty}^{\infty} \left[-n^2\omega^2\, f_n(x) - f_n''(x)\right] e^{in\
omega t} = c \sum_{n=-\infty}^{\infty} f_n(x)\, e^{in\omega t}.$$

By the uniqueness of Fourier coefficients (orthogonality of $\{e^{in\omega t}\}$
), each mode must satisfy independently:

$$-n^2\omega^2\, f_n(x) - f_n''(x) = c\, f_n(x),$$

that is,

$$\boxed{f_n''(x) + \left(n^2\omega^2 + c\right) f_n(x) = 0.}$$

**Solving the ODE for each mode.** This is a second-order linear ODE with consta
nt coefficients. The characteristic equation is $r^2 + (n^2\omega^2 + c) = 0$, i
.e., $r^2 = -(n^2\omega^2 + c)$. Set $\lambda_n = n^2\omega^2 + c$. Three cases
arise:

- **Case $\lambda_n > 0$:** $r = \pm i\sqrt{\lambda_n}$, giving
$$f_n(x) = A_n \cos\!\left(\sqrt{\lambda_n}\, x\right) + B_n \sin\!\left(\sqrt{\
lambda_n}\, x\right).$$

- **Case $\lambda_n = 0$:** $r = 0$ (double root), giving
$$f_n(x) = A_n + B_n\, x.$$

- **Case $\lambda_n < 0$:** $r = \pm\sqrt{-\lambda_n}$ (real), giving
$$f_n(x) = A_n\, e^{\sqrt{-\lambda_n}\, x} + B_n\, e^{-\sqrt{-\lambda_n}\, x} =
A_n \cosh\!\left(\sqrt{-\lambda_n}\, x\right) + B_n \sinh\!\left(\sqrt{-\lambda_
n}\, x\right).$$

**General form.** Combining all modes, the general periodic-in-$t$ solution (wit
h period $T = 2\pi/\omega$) is:

$$\boxed{f(t,x) = \sum_{n=-\infty}^{\infty} f_n(x)\, e^{in\omega t}, \qquad f_n'
'(x) + \left(n^2\omega^2 + c\right) f_n(x) = 0,}$$

where each $f_n(x)$ is a general solution of the ODE above, determined by the si
gn of $\lambda_n = n^2\omega^2 + c$ as described.

**Real form.** For real-valued solutions, using $f_{-n} = \overline{f_n}$ and wr
iting $f_0 = u_0$, $f_n = \frac{1}{2}(u_n - i v_n)$ for $n \geq 1$ with real $u_
n, v_n$:

$$f(t,x) = u_0(x) + \sum_{n=1}^{\infty}\left[u_n(x)\cos(n\omega t) + v_n(x)\sin(
n\omega t)\right],$$

where each of $u_n(x), v_n(x)$ satisfies the same ODE $y'' + (n^2\omega^2 + c)\,
y = 0$, with solutions:

- **$n^2\omega^2 + c > 0$:** $\;y = \alpha\cos(\sqrt{n^2\omega^2+c}\,x) + \beta\
sin(\sqrt{n^2\omega^2+c}\,x)$,
- **$n^2\omega^2 + c = 0$:** $\;y = \alpha + \beta\, x$,
- **$n^2\omega^2 + c < 0$:** $\;y = \alpha\cosh(\sqrt{-(n^2\omega^2+c)}\,x) + \b
eta\sinh(\sqrt{-(n^2\omega^2+c)}\,x)$,

for arbitrary constants $\alpha, \beta$.

**Verification.** Each term $f_n(x)e^{in\omega t}$ satisfies the PDE by construc
tion: $f_{tt} = -n^2\omega^2 f_n e^{in\omega t}$ and $f_{xx} = f_n'' e^{in\omega
 t} = -(n^2\omega^2+c)f_n e^{in\omega t}$, so $f_{tt} - f_{xx} = [-n^2\omega^2 +
 n^2\omega^2 + c]f_n e^{in\omega t} = c\,f$. By linearity, any superposition als
o satisfies the PDE, and periodicity in $t$ is preserved since each mode is peri
odic with period dividing $T$. Conversely, any $C^2$ solution periodic in $t$ ad
mits a Fourier expansion, so every periodic solution is of this form. $\blacksqu
are$
