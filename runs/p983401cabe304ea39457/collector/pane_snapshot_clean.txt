## Proof

**Setup.** Let $S \subseteq \text{End}(V)$ be a commutative subspace with $\dim
V = 4$ over $\mathbb{C}$, and suppose $A \in S$ has three distinct eigenvalues $
\lambda_1, \lambda_2, \lambda_3$.

**Step 1: $A$ is diagonalizable.** Since $A$ has three distinct eigenvalues, its
 minimal polynomial has three distinct linear factors, hence $A$ is diagonalizab
le. The eigenspace decomposition is
$$V = E_{\lambda_1} \oplus E_{\lambda_2} \oplus E_{\lambda_3}, \quad \dim E_{\la
mbda_1} + \dim E_{\lambda_2} + \dim E_{\lambda_3} = 4.$$
The only possibility (up to relabeling) is $\dim E_{\lambda_1} = 2$, $\dim E_{\l
ambda_2} = \dim E_{\lambda_3} = 1$.

**Step 2: The centralizer of $A$.** Every element of $S$ commutes with $A$, so $
S \subseteq C(A)$. Since $A$ is diagonalizable, $B$ commutes with $A$ if and onl
y if $B$ preserves each eigenspace of $A$. Therefore:
$$C(A) \cong \text{End}(E_{\lambda_1}) \oplus \text{End}(E_{\lambda_2}) \oplus \
text{End}(E_{\lambda_3}) \cong M_2(\mathbb{C}) \oplus \mathbb{C} \oplus \mathbb{
C}.$$

**Step 3: Bounding $\dim S$.** Consider the projection $\pi: C(A) \to M_2(\mathb
b{C})$ onto the first factor. Then $\pi(S)$ is a commutative subspace of $M_2(\m
athbb{C})$, and:
$$\dim S \leq \dim \pi(S) + \dim(\ker \pi|_S) \leq \dim \pi(S) + 2,$$
since $\ker \pi \subseteq \{0\} \oplus \mathbb{C} \oplus \mathbb{C}$, which is 2
-dimensional.

**Step 4: Commutative subspaces of $M_2(\mathbb{C})$ have dimension at most 2.**
 Let $T \subseteq M_2(\mathbb{C})$ be a commutative subspace. If $T$ contains a
non-scalar matrix $B$, then $T \subseteq C(B)$. The centralizer of a non-scalar
$2 \times 2$ matrix is $\{aI + bB : a, b \in \mathbb{C}\}$, which is 2-dimension
al. If $T$ contains only scalar matrices, then $\dim T \leq 1$. In either case,
$\dim T \leq 2$.

**Step 5: Upper bound.** Combining Steps 3 and 4:
$$\dim S \leq 2 + 2 = 4.$$

**Step 6: Construction achieving dimension 4.** Let $V = \mathbb{C}^2 \oplus \ma
thbb{C} \oplus \mathbb{C}$ and define:
$$S = \left\{\begin{pmatrix} a & b & 0 & 0 \\ 0 & a & 0 & 0 \\ 0 & 0 & c & 0 \\
0 & 0 & 0 & d \end{pmatrix} : a, b, c, d \in \mathbb{C}\right\}.$$

- **Dimension 4:** The parameters $a, b, c, d$ are free, so $\dim S = 4$.
- **Commutativity:** Any two elements $X = (aI_2 + bN) \oplus c \oplus d$ and $X
' = (a'I_2 + b'N) \oplus c' \oplus d'$ (where $N = \begin{pmatrix} 0 & 1 \\ 0 &
0 \end{pmatrix}$) satisfy $XX' = (aa'I_2 + (ab'+ba')N) \oplus cc' \oplus dd' = X
'X$, since the $2 \times 2$ blocks are polynomials in $N$ (hence commute) and th
e $1 \times 1$ blocks are scalars.
- **Three distinct eigenvalues:** The element with $a = 0, b = 0, c = 1, d = 2$
is $\operatorname{diag}(0, 0, 1, 2)$, which has eigenvalues $\{0, 1, 2\}$ — exac
tly three distinct eigenvalues.

**Conclusion.** The upper bound is 4 and it is achieved, so the maximum dimensio
n is $\boxed{4}$.
