## Proof

**Setup and notation.** Write the model as $y = X\beta + \varepsilon$ with $E(\v
arepsilon)=0$, $\operatorname{Cov}(\varepsilon)=\sigma^2 V$, $V\geq 0$. Denote b
y $V^+$ the Moore–Penrose inverse of $V$ and set $S := X'V^+X$.

---

**Step 1 — Unbiasedness reduces the problem.** An affine estimator of $W\beta$ h
as the form $Ay+c$. Unbiasedness requires $AX\beta + c = W\beta$ for all $\beta$
, hence $AX = W$ and $c=0$. So we seek a linear estimator $Ay$ with $AX=W$ that
minimizes $\operatorname{Cov}(Ay)=\sigma^2 AVA'$ in the Loewner order.

---

**Step 2 — Key identities from $\mathcal{M}(X)\subset\mathcal{M}(V)$.** The matr
ix $VV^+$ is the orthogonal projector onto $\mathcal{M}(V)$; since each column o
f $X$ lies in $\mathcal{M}(V)$,
$$VV^+X = X. \tag{1}$$
Because $V$ is symmetric, $V^+V = VV^+$, so $V^+VX = X$ and consequently
$$X'V^+V = X'. \tag{2}$$

---

**Step 3 — Column space of $S$.** We have $S = (V^{+/2}X)'(V^{+/2}X)$, so $\oper
atorname{rank}(S)=\operatorname{rank}(V^{+/2}X)$. From the spectral decompositio
n, $V^{1/2}V^{+/2} = VV^+$ (the projector onto $\mathcal{M}(V)$), so by (1):
$$V^{1/2}(V^{+/2}X) = VV^+X = X,$$
which gives $\operatorname{rank}(V^{+/2}X) = \operatorname{rank}(X)$. Hence $\op
eratorname{rank}(S)=\operatorname{rank}(X)$. Since $\mathcal{M}(S)\subset\mathca
l{M}(X')$ trivially and the ranks agree,
$$\mathcal{M}(S) = \mathcal{M}(X'). \tag{3}$$

---

**Step 4 — The candidate estimator and its unbiasedness.** Define
$$A := WS^+X'V^+,\qquad \hat{W}\beta := Ay = WS^+X'V^+y.$$
Then
$$AX = WS^+X'V^+X = WS^+S.$$
By (3), $S^+S$ is the orthogonal projector onto $\mathcal{M}(X')$. Since $\mathc
al{M}(W')\subset\mathcal{M}(X')$, every row of $W$ lies in $\mathcal{M}(X')$ and
 is therefore fixed by this projector:
$$WS^+S = W.$$
Thus $AX = W$, confirming unbiasedness. ∎

---

**Step 5 — Optimality (minimum variance).** Let $By$ be any unbiased estimator,
so $BX = W$. Set $D := B - A$, so $DX = 0$. Then
$$BVB' = AVA' + AVD' + DVA' + DVD'.$$

We claim $AVD' = 0$. Using (2):
$$AV = WS^+X'V^+V = WS^+X',$$
and therefore
$$AVD' = WS^+X'D' = WS^+(DX)' = WS^+\cdot 0 = 0.$$

Hence
$$BVB' = AVA' + DVD' \geq AVA',$$
since $V\geq 0$ implies $DVD'\geq 0$. This proves $Ay$ is the best (minimum-vari
ance) affine unbiased estimator. ∎

---

**Step 6 — Variance computation.**
$$\operatorname{Cov}(\hat{W}\beta) = \sigma^2 AVA' = \sigma^2\, WS^+X'V^+\!\cdot
 V\!\cdot\! V^+XS^+W'.$$
Using the Moore–Penrose identity $V^+VV^+ = V^+$:
$$= \sigma^2\, WS^+X'V^+XS^+W' = \sigma^2\, WS^+SS^+W'.$$
Since $S$ is symmetric, $S^+SS^+ = S^+$, giving
$$\operatorname{Cov}(\hat{W}\beta) = \sigma^2\, WS^+W' = \sigma^2\, W(X'V^+X)^+W
'.$$

---

**Remark on the consistency condition.** Since $\mathcal{M}(X)\subset\mathcal{M}
(V)$, we have $\mathcal{M}(X:V)=\mathcal{M}(V)$. The assumption $y\in\mathcal{M}
(X:V)$ a.s. ensures $y\in\mathcal{M}(V)$ a.s., so the error $\varepsilon = y - X
\beta$ has support in $\mathcal{M}(V)$, consistent with $\operatorname{Cov}(\var
epsilon)=\sigma^2 V$. This guarantees the model is well-defined and the estimato
r $V^+y$ is meaningful.

---

**Conclusion.** Under the stated conditions, the best affine unbiased estimator
of $W\beta$ is

$$\boxed{\hat{W}\beta \;=\; W\,(X'V^{+}X)^{+}\,X'V^{+}\,y}$$

and its variance matrix is

$$\boxed{\operatorname{Cov}(\hat{W}\beta) \;=\; \sigma^{2}\,W\,(X'V^{+}X)^{+}\,W
'}$$

where $V^+$ and $(X'V^+X)^+$ denote Moore–Penrose inverses. When $V$ is positive
 definite and $X$ has full column rank, these reduce to the classical GLS formul
as $W(X'V^{-1}X)^{-1}X'V^{-1}y$ and $\sigma^2 W(X'V^{-1}X)^{-1}W'$.
