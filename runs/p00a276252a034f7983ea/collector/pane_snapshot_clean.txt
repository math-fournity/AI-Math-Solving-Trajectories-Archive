## Solution

We minimize $\displaystyle I(a,b,c) = \int_0^\infty \left|x^3 - a - bx - cx^2\ri
ght|^2 e^{-x}\,dx$ over $a,b,c \in \mathbb{R}$.

This is a least-squares projection problem in the Hilbert space $L^2\bigl([0,\in
fty),\, e^{-x}dx\bigr)$: we project $x^3$ onto $\operatorname{span}\{1, x, x^2\}
$ and compute the squared norm of the residual.

**Orthogonal basis.** The standard Laguerre polynomials
$$L_0=1,\quad L_1=1-x,\quad L_2=1-2x+\tfrac{x^2}{2},\quad L_3=1-3x+\tfrac{3x^2}{
2}-\tfrac{x^3}{6}$$
are orthonormal with respect to $e^{-x}dx$ on $[0,\infty)$:
$$\int_0^\infty L_n(x)L_m(x)\,e^{-x}dx = \delta_{nm}.$$
(Verified: $\|L_0\|^2=\int e^{-x}dx=1$; $\|L_1\|^2=\int(1-x)^2e^{-x}dx=1-2+2=1$;
 etc., using $\int_0^\infty x^k e^{-x}dx=k!$.)

**Express $x^3$ in the Laguerre basis.** From $L_1=1-x$ we get $x=L_0-L_1$. From
 $L_2=1-2x+x^2/2$:
$$x^2 = 2(L_2-1+2x)=2L_2-2L_0+4(L_0-L_1)=2L_0-4L_1+2L_2.$$
From $L_3=1-3x+\tfrac{3}{2}x^2-\tfrac{1}{6}x^3$:
$$\tfrac{1}{6}x^3 = 1-3x+\tfrac{3}{2}x^2 - L_3 = L_0-3(L_0-L_1)+3(L_0-4L_1+2L_2)
/\,\cdot\, \ldots$$
Carrying through:
$$x^3 = 6 - 18x + 9x^2 - 6L_3 = 6L_0 - 18(L_0-L_1) + 9(2L_0-4L_1+2L_2) - 6L_3,$$
$$x^3 = (6-18+18)L_0 + (18-36)L_1 + 18L_2 - 6L_3 = 6L_0 - 18L_1 + 18L_2 - 6L_3.$
$

**Projection and residual.** Since $\{L_0,L_1,L_2\}$ spans the same space as $\{
1,x,x^2\}$, the best approximation to $x^3$ is
$$\operatorname{proj}(x^3) = 6L_0 - 18L_1 + 18L_2,$$
with residual
$$x^3 - \operatorname{proj}(x^3) = -6L_3.$$

**Minimum value.** By orthonormality,
$$\min_{a,b,c} I(a,b,c) = \|-6L_3\|^2 = 36\,\|L_3\|^2 = 36\cdot 1 = 36.$$

The minimum is attained at the unique $(a,b,c)$ corresponding to $6L_0-18L_1+18L
_2$, and the minimum value is

$$\boxed{36}$$
