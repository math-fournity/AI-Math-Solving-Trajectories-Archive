## Proof that $C + C = [0, 2]$

**Answer-leak check:** The problem statement contains only the problem and stand
ard instructions. No solution, answer, or proof sketch is leaked. Proceeding.

---

### Setup: base-3 characterization of $C$

The Cantor ternary set $C$ consists of all $x \in [0,1]$ that admit a base-3 (te
rnary) expansion using only the digits $0$ and $2$:

$$C = \left\{\,\sum_{i=1}^{\infty} 2a_i\, 3^{-i} \;:\; a_i \in \{0,1\}\,\right\}
.$$

(This is the standard characterization: each digit is either $0$ or $2 = 2\cdot
1$, so writing $a_i \in \{0,1\}$ and multiplying by $2$ gives digits in $\{0,2\}
$.)

---

### Inclusion $C + C \subseteq [0,2]$

Since $C \subseteq [0,1]$, for any $x, y \in C$ we have $x + y \in [0, 2]$. Henc
e $C + C \subseteq [0,2]$.

---

### Inclusion $[0,2] \subseteq C + C$

Take any $z \in [0,2]$ and set $t = z/2 \in [0,1]$.

**Step 1: Ternary expansion of $t$.** Every real number in $[0,1]$ has a base-3
expansion with digits in $\{0,1,2\}$ (this is the standard existence of position
al expansions, analogous to decimal expansions). So there exist $c_i \in \{0,1,2
\}$ with

$$t = \sum_{i=1}^{\infty} c_i\, 3^{-i}.$$

(For $t = 1$, use the expansion $1 = 0.222\ldots$ in base $3$, i.e., all $c_i =
2$.)

**Step 2: Split each digit.** For each $i$, since $c_i \in \{0,1,2\}$, we can wr
ite $c_i = a_i + b_i$ with $a_i, b_i \in \{0,1\}$:

| $c_i$ | $(a_i, b_i)$ |
|-------|---------------|
| $0$   | $(0, 0)$      |
| $1$   | $(1, 0)$      |
| $2$   | $(1, 1)$      |

**Step 3: Construct $x$ and $y$.** Define

$$x = \sum_{i=1}^{\infty} 2a_i\, 3^{-i}, \qquad y = \sum_{i=1}^{\infty} 2b_i\, 3
^{-i}.$$

Since $a_i, b_i \in \{0,1\}$, the digits $2a_i, 2b_i \in \{0,2\}$, so $x, y \in
C$ by the characterization above.

**Step 4: Verify $x + y = z$.** We compute:

$$x + y = \sum_{i=1}^{\infty} 2a_i\, 3^{-i} + \sum_{i=1}^{\infty} 2b_i\, 3^{-i}
= \sum_{i=1}^{\infty} 2(a_i + b_i)\, 3^{-i} = 2\sum_{i=1}^{\infty} c_i\, 3^{-i}
= 2t = z.$$

The termwise summation is justified since both series converge absolutely (all t
erms non-negative, sums bounded by $1$).

**Step 5: Edge cases.**
- $z = 0$: $t = 0$, all $c_i = 0$, so $x = y = 0 \in C$. ✓
- $z = 2$: $t = 1 = 0.222\ldots$ (base $3$), all $c_i = 2$, so $a_i = b_i = 1$ a
nd $x = y = \sum 2\cdot 3^{-i} = 1$. Since $1 = 0.222\ldots$ (base $3$) uses onl
y the digit $2$, we have $1 \in C$. ✓

Since $z \in [0,2]$ was arbitrary, we conclude $[0,2] \subseteq C + C$.

---

### Conclusion

Combining both inclusions:

$$C + C = [0, 2]. \qquad \blacksquare$$
