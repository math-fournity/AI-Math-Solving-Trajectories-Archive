**回答：不，该等式一般不成立。**

**反例。** 设 $A = M_2(\mathbb{C})$，并设 $T: A \to A$ 为转置映射 $T(a) = a^T$。

**$T$ 是一个正算子。** $A$ 的正锥 $A^+$ 是正半定埃尔米特矩阵的集合。如果 $a \in
A^+$，那么 $a$ 是埃尔米特矩阵且具有非负特征值。转置 $a^T$ 也是埃尔米特矩阵（因为
 $(a^T)^* = \bar{a} = a^T$，利用了 $a = a^* \Rightarrow \bar{a} = a^T$ 这一事实
），且 $a^T$ 与 $a$ 具有相同的特征值（因为 $\det(a^T - \lambda I) = \det(a - \la
mbda I)$）。因此 $a^T \in A^+$，从而证明了 $T(A^+) \subseteq A^+$。

**该等式不成立。** 取 $f = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$。

计算 $T|f|$：
$$f^* f = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 0
 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}, \quad |f| = \
sqrt{f^*f} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix},$$
$$T|f| = |f|^T = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}.$$

计算 $|Tf|$：
$$Tf = f^T = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}, \quad (f^T)^* = \bar{
f} = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix},$$
$$(f^T)^*\, f^T = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\begin{pmatrix} 0
& 0 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix},$$
$$|Tf| = \sqrt{(f^T)^*\,f^T} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}.$$

因此
$$|Tf| = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} \neq \begin{pmatrix} 0 & 0
 \\ 0 & 1 \end{pmatrix} = T|f|.$$

**结论。** 在有限维 C*-代数上，正算子（将正锥映射到其自身的线性映射）一般不满足
$|Tf| = T|f|$。绝对值涉及通过 $a \mapsto a^*a$ 和函数演算 $\sqrt{\cdot}$ 进行的
乘法结构，而正算子仅保留了锥的包含关系——它既不需要是 *-同态，也不需要与乘法或伴
随运算交换，而这些正是等式成立所必需的。转置映射是一个具体的正算子，它不与 $a \m
apsto a^*a$ 交换，从而产生了上述反例。
