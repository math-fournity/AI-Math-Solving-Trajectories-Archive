## Solution

We need the remainder when $S = T_1 + T_2 + \cdots + T_{256}$ is divided by $255
$, where $T_1 = 2$ and $T_n = 2^{T_{n-1}}$.

**Key observation.** Since $255 = 256 - 1 = 2^8 - 1$, we have
$$2^8 \equiv 1 \pmod{255}.$$
One checks that no smaller positive power of $2$ is $\equiv 1 \pmod{255}$ (indee
d $2^1=2$, $2^2=4$, $2^4=16$), so $\operatorname{ord}_{255}(2) = 8$. Consequentl
y
$$2^k \equiv 2^{k \bmod 8} \pmod{255}.$$

**Computing $T_n \bmod 255$.**

| $n$ | $T_n$ | $T_n \bmod 255$ |
|-----|-------|-----------------|
| 1 | $2$ | $2$ |
| 2 | $2^2 = 4$ | $4$ |
| 3 | $2^4 = 16$ | $16$ |
| 4 | $2^{16} = 65536$ | $65536 - 255\cdot257 = 65536-65535 = 1$ |

**Stabilization for $n \geq 4$.** We need $T_n \bmod 8$ for the exponent. Since
$2^k \equiv 0 \pmod{8}$ for all $k \geq 3$:
- $T_1 = 2$, $T_2 = 4$, and $T_3 = 16 \equiv 0 \pmod{8}$.
- For every $n \geq 3$: $T_n = 2^{T_{n-1}}$ with $T_{n-1} \geq 4 \geq 3$, so $T_
n \equiv 0 \pmod{8}$.

Therefore for every $n \geq 4$: the exponent $T_{n-1} \equiv 0 \pmod{8}$, giving
$$T_n = 2^{T_{n-1}} \equiv 2^{0} = 1 \pmod{255}.$$

**Summing up.**
$$S \equiv \underbrace{2}_{T_1} + \underbrace{4}_{T_2} + \underbrace{16}_{T_3} +
 \underbrace{1 + 1 + \cdots + 1}_{253 \text{ terms } (T_4 \text{ through } T_{25
6})} \pmod{255}.$$

$$S \equiv 2 + 4 + 16 + 253 = 275 \pmod{255}.$$

$$275 - 255 = 20.$$

**The remainder is $\boxed{20}$.**
