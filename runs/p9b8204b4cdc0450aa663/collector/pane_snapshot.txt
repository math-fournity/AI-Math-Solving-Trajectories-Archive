## Proof

The answer is **no**. We construct an explicit counterexample.

Let $X$ be an infinite-dimensional real Banach space (e.g., $X = \ell^2$). Using
 a Hamel basis (axiom of choice), there exists a **discontinuous** linear functi
onal $f: X \to \mathbb{R}$ — that is, $f$ is linear but unbounded on the unit ba
ll.

Define
$$A = \{x \in X : |f(x)| < 1\} = f^{-1}\big((-1,1)\big).$$

**$A$ is convex.** Since $f$ is linear and $(-1,1) \subset \mathbb{R}$ is convex
, the preimage $A = f^{-1}((-1,1))$ is convex.

**$A$ is absorbing.** For any $x \in X$ and $t > 0$, we have $|f(tx)| = t\,|f(x)
|$. Choosing $t < 1/(|f(x)|+1)$ gives $|f(tx)| < 1$, so $tx \in A$.

**$\mathrm{cl}(A) = X$, so $\mathrm{cl}(A)$ contains an open ball around $0$.**
We show $A$ is dense in $X$. Let $x_0 \in X$ and $\varepsilon > 0$.

- If $|f(x_0)| < 1$, then $x_0 \in A$ already.
- If $|f(x_0)| \geq 1$: Since $f$ is discontinuous, $f$ is unbounded on every op
en ball (a linear functional on a Banach space is continuous iff it is bounded o
n some ball). So there exists $w \in B(0,\varepsilon)$ with $|f(w)| > |f(x_0)| +
 1$. Set $\alpha = -f(x_0)/f(w)$, so $|\alpha| < 1$. Then $z = \alpha w$ satisfi
es $\|z\| = |\alpha|\,\|w\| < \varepsilon$ and $f(z) = -f(x_0)$. Now $y = x_0 +
z$ satisfies $\|y - x_0\| < \varepsilon$ and $f(y) = f(x_0) + f(z) = 0$, so $|f(
y)| = 0 < 1$ and $y \in A$.

Thus $A$ is dense, hence $\mathrm{cl}(A) = X \supseteq B(0,r)$ for every $r > 0$
.

**$A$ contains no open ball around $0$.** Suppose for contradiction that $B(0,\d
elta) \subseteq A$ for some $\delta > 0$. Then $|f(x)| < 1$ for all $\|x\| < \de
lta$. For any $x \in X \setminus \{0\}$, the vector $y = \frac{\delta}{2\|x\|}\,
x$ satisfies $\|y\| = \delta/2 < \delta$, so $|f(y)| < 1$, giving
$$|f(x)| = \frac{2\|x\|}{\delta}\,|f(y)| < \frac{2\|x\|}{\delta}.$$
Thus $f$ is bounded on the unit ball (by $2/\delta$), hence continuous — contrad
icting the discontinuity of $f$.

---

**Conclusion.** The set $A = \{x \in X : |f(x)| < 1\}$ is convex and absorbing,
its closure $\mathrm{cl}(A) = X$ contains an open ball around $0$ (indeed every
ball), yet $A$ itself contains no open ball around $0$. Therefore, the implicati
on does **not** hold in general.

**Remark.** In finite-dimensional Banach spaces the answer would be yes, since t
he Minkowski functional of any convex absorbing set is continuous (being a finit
e sublinear function). The counterexample exploits the existence of discontinuou
s linear functionals, which is specific to infinite dimensions.
