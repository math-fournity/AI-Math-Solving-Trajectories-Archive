## Solution

**Claim.** In ZFC (without assuming CH), every Lebesgue measurable set $X \subse
t \mathbb{R}$ with $\aleph_0 < |X| < 2^{\aleph_0}$ is a null set.

The key is the following theorem, provable in ZFC alone:

> **Theorem.** *If $E \subseteq \mathbb{R}$ is Lebesgue measurable and has posit
ive Lebesgue measure, then $|E| = 2^{\aleph_0}$.*

Once this is established, the claim follows immediately by contraposition: if $E
$ is measurable and $|E| < 2^{\aleph_0}$, then $E$ cannot have positive measure,
 so $E$ is a null set. In particular, any measurable $E$ with $\aleph_0 < |E| <
2^{\aleph_0}$ is null.

Note that the statement is vacuously true if no intermediate cardinality exists
(i.e., under CH), and substantively true if one does. Either way it holds in ZFC
.

---

### Proof of the Theorem

We use two standard facts, each provable in ZFC:

**Fact 1 (Inner regularity of Lebesgue measure).** If $E \subseteq \mathbb{R}$ i
s Lebesgue measurable, then for every $\varepsilon > 0$ there exists a closed se
t $F \subseteq E$ with $m(E \setminus F) < \varepsilon$.

**Fact 2 (Cantor–Bendixson / Perfect Set Theorem for closed sets).** Every uncou
ntable closed subset of $\mathbb{R}$ contains a nonempty perfect subset, and eve
ry nonempty perfect subset of $\mathbb{R}$ has cardinality $2^{\aleph_0}$.

*Proof of Fact 2 (sketch for completeness).* For a closed set $F$, the Cantor–Be
ndixson theorem gives $F = P \cup C$ where $P$ is perfect, $C$ is countable, and
 $P \cap C = \varnothing$. If $F$ is uncountable then $P \neq \varnothing$. A no
nempty perfect set in $\mathbb{R}$ contains a homeomorphic copy of $\{0,1\}^{\ma
thbb{N}}$ (constructed by recursively choosing disjoint closed subintervals meet
ing $P$), so $|P| \geq 2^{\aleph_0}$, and since $P \subseteq \mathbb{R}$, $|P| =
 2^{\aleph_0}$. $\square$

*Proof of the Theorem.* Let $E$ be Lebesgue measurable with $m(E) > 0$. By Fact
1, choose $\varepsilon = m(E)/2 > 0$ and a closed set $F \subseteq E$ with $m(E
\setminus F) < \varepsilon$. Then
$$m(F) = m(E) - m(E \setminus F) > m(E) - \varepsilon = m(E)/2 > 0.$$
Since $m(F) > 0$, the set $F$ is uncountable (every countable set has measure $0
$). Being a closed uncountable subset of $\mathbb{R}$, Fact 2 yields $|F| = 2^{\
aleph_0}$. Since $F \subseteq E$,
$$|E| \geq |F| = 2^{\aleph_0}.$$
But $E \subseteq \mathbb{R}$ gives $|E| \leq 2^{\aleph_0}$. Therefore $|E| = 2^{
\aleph_0}$. $\square$

### Deriving the Claim

Let $X \subseteq \mathbb{R}$ be Lebesgue measurable with $\aleph_0 < |X| < 2^{\a
leph_0}$. Since $|X| < 2^{\aleph_0}$, the Theorem (contrapositive) forces $m(X)
= 0$, i.e., $X$ is a null set.

No use of CH (or its negation) was made anywhere: inner regularity and the Canto
r–Bendixson theorem are theorems of ZFC, and the cardinality argument only uses
$|X| < 2^{\aleph_0}$, which is given. The conclusion is a theorem of ZFC.
