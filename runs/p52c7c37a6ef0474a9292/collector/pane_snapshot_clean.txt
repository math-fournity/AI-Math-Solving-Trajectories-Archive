## Proof

We are given an $n \times n$ matrix $A$ with $\det(A) = 9$ and
$$A^3 A^T = 3 A^{-1}.$$

Take determinants of both sides.

**Left-hand side.** Using multiplicativity of the determinant and the fact that
$\det(A^T) = \det(A)$:
$$\det(A^3 A^T) = \det(A^3)\,\det(A^T) = \det(A)^3 \cdot \det(A) = \det(A)^4.$$
With $\det(A) = 9$:
$$\det(A^3 A^T) = 9^4 = (3^2)^4 = 3^8.$$

**Right-hand side.** Using $\det(cM) = c^n \det(M)$ for an $n\times n$ matrix, a
nd $\det(A^{-1}) = 1/\det(A)$:
$$\det(3 A^{-1}) = 3^n \det(A^{-1}) = 3^n \cdot \frac{1}{\det(A)} = 3^n \cdot \f
rac{1}{9} = 3^n \cdot 3^{-2} = 3^{n-2}.$$

**Equating both sides:**
$$3^8 = 3^{n-2}.$$

Since the exponential function with base $3$ is injective,
$$8 = n - 2 \implies n = 10.$$
