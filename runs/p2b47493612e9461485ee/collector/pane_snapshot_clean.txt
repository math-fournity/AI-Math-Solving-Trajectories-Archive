## Proof

**Setup.** We have $p = 5a + b$ with $a \geq 0$ integer and $0 \leq b \leq 5$, s
ubject to:
- (P1) If $b = 0$, then $p = 5$ (forcing $a = 1$).
- (P2) If $p \neq 5$, then $1 \leq b \leq 4$.

**Step 1: Determine the admissible values of $p$.**

If $b = 0$: by (P1), $p = 5$, so $a = 1$. This is the unique representation with
 $b = 0$.

If $b \neq 0$: then $p \neq 5$ (else (P1) forces $b = 0$, contradiction), so by
(P2), $1 \leq b \leq 4$. The value $b = 5$ is impossible: if $b = 5$ and $p = 5$
 then $a = 0$ but (P1) forces $b = 0$; if $b = 5$ and $p \neq 5$ then (P2) is vi
olated.

Thus admissible $p$-values are: $\{1,2,3,4,5\} \cup \{n \geq 6 : n \not\equiv 0
\pmod{5}\}$. Equivalently, $p \geq 1$ with $p \equiv 0 \pmod{5}$ only when $p =
5$.

**Step 2: Modular obstruction via $p \bmod 5$.**

We need both $4p^2 + 1$ and $6p^2 + 1$ prime. Compute residues mod $5$:

- $4p^2 + 1 \equiv 0 \pmod{5} \iff 4p^2 \equiv 4 \iff p^2 \equiv 1 \iff p \equiv
 \pm 1 \pmod{5}$.
- $6p^2 + 1 \equiv 0 \pmod{5} \iff p^2 \equiv 4 \iff p \equiv \pm 2 \pmod{5}$.

**Case $p \equiv 2$ or $3 \pmod{5}$:** Then $5 \mid 6p^2+1$. Since $p \geq 2$, w
e have $6p^2+1 \geq 25 > 5$, so $6p^2+1$ is composite. No solutions.

**Case $p \equiv 1$ or $4 \pmod{5}$, with $p > 1$:** Then $5 \mid 4p^2+1$. Since
 $p \geq 4$ (the smallest such $p > 1$ in our admissible set is $4$), $4p^2+1 \g
eq 65 > 5$, so $4p^2+1$ is composite. No solutions.

**Case $p \equiv 1 \pmod{5}$, $p = 1$:** $4(1)^2+1 = 5$ (prime), $6(1)^2+1 = 7$
(prime). ✓

**Case $p \equiv 0 \pmod{5}$:** By admissibility, $p = 5$ is the only possibilit
y. Check: $4(25)+1 = 101$ (prime, since $\sqrt{101}\approx 10$ and $101$ is divi
sible by none of $2,3,5,7$), $6(25)+1 = 151$ (prime, since $\sqrt{151}\approx 12
.3$ and $151$ is divisible by none of $2,3,5,7,11$). ✓

**Step 3: Conclusion.**

All admissible $p$ fall into one of the residue classes above. The modular analy
sis eliminates every value except $p = 1$ and $p = 5$, and direct verification c
onfirms both yield primes for both stress-test expressions.

$$\boxed{p \in \{1,\, 5\}}$$
