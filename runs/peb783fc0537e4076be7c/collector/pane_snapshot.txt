## Proof

**Step 1: Reformulation via discriminant.**

The condition $b^2 \equiv a + a^{-1} \pmod{p^2}$ is equivalent to $a^2 - b^2 a +
 1 \equiv 0 \pmod{p^2}$, a quadratic in $a$ with discriminant $\Delta = b^4 - 4$
. This has a solution $a \bmod p^2$ (with $p \nmid a$, which is automatic since
the product of roots is $1$) if and only if $b^4 - 4$ is a quadratic residue mod
 $p^2$ (including $0$).

**Step 2: Reduction to quadratic residues.**

As $b$ ranges over $\{1, \ldots, \frac{p^2-1}{2}\}$, the values $c = b^2 \bmod p
^2$ cover each nonzero quadratic residue mod $p^2$ exactly once (since $b^2 \equ
iv c^2 \pmod{p^2}$ iff $b \equiv \pm c$, and our range picks one from each pair)
, plus $c = 0$ when $p \mid b$.

For $p \mid b$: $b^4 - 4 \equiv -4 \pmod{p^2}$. Since $p = 107 \equiv 3 \pmod{4}
$, $\left(\frac{-1}{p}\right) = -1$, so $\left(\frac{-4}{p}\right) = -1$, meanin
g $-4$ is not a QR mod $p$, hence not mod $p^2$. These $b$ never work.

So the count equals $\#\{c \in \text{QR}^*(p^2) : c^2 - 4 \text{ is QR mod } p^2
\}$, where $\text{QR}^*(p^2)$ denotes nonzero quadratic residues mod $p^2$.

**Step 3: Splitting by $c \bmod p$.**

For $c \not\equiv \pm 2 \pmod{p}$: $p \nmid (c^2 - 4)$, so by Hensel's lemma, $c
^2 - 4$ is QR mod $p^2$ iff it is QR mod $p$. Each nonzero QR $c_0 \bmod p$ lift
s to exactly $p$ values in $\text{QR}^*(p^2)$ (all $\equiv c_0 \bmod p$), all sh
aring the same Legendre symbol $\left(\frac{c_0^2 - 4}{p}\right)$.

For $c \equiv \pm 2 \pmod{p}$: $p \mid (c^2 - 4)$. Writing $c = \pm 2 + pk$, we
get $c^2 - 4 = p \cdot k(4 \pm pk)$. This is QR mod $p^2$ only if $p^2 \mid (c^2
 - 4)$, which requires $p \mid k$, i.e., $c \equiv \pm 2 \pmod{p^2}$. If $p \par
allel (c^2-4)$, it is not a QR mod $p^2$.

Now check which of $\pm 2$ are QR mod $p = 107$:
- $\left(\frac{2}{107}\right) = (-1)^{(107^2-1)/8} = (-1)^{1431} = -1$, so $2$ i
s **not** QR mod $p$.
- $\left(\frac{-2}{107}\right) = \left(\frac{-1}{107}\right)\left(\frac{2}{107}\
right) = (-1)(-1) = 1$, so $-2$ **is** QR mod $p$.

Thus $c \equiv 2 \pmod{p}$ never occurs in $\text{QR}^*(p^2)$. For $c \equiv -2
\pmod{p}$: only $c = p^2 - 2 \equiv -2 \pmod{p^2}$ gives $c^2 - 4 \equiv 0 \pmod
{p^2}$ (QR), contributing **1**. The other $p-1$ lifts have $p \parallel (c^2-4)
$, contributing 0.

**Step 4: Character sum computation.**

The count from Step 3's first case is $p \cdot N$, where:
$$N = \#\{c_0 \in \text{QR}^*(p) : \left(\tfrac{c_0^2 - 4}{p}\right) = 1\}.$$

Among $\text{QR}^*(p)$ (which has $\frac{p-1}{2} = 53$ elements), the value $c_0
 = -2$ satisfies $c_0^2 - 4 \equiv 0$, giving Legendre symbol $0$. The value $c_
0 = 2$ is not in $\text{QR}^*(p)$. So among the $52$ remaining elements, $\chi(c
_0^2 - 4) \in \{\pm 1\}$, and:
$$N = \frac{1}{2}\left(52 + \sum_{\substack{c_0 \in \text{QR}^*(p) \\ c_0 \neq -
2}} \chi(c_0^2 - 4)\right) = \frac{1}{2}\left(52 + S\right),$$
where $S = \sum_{c_0 \in \text{QR}^*(p)} \chi(c_0^2 - 4)$ (the $c_0 = -2$ term c
ontributes $\chi(0) = 0$).

Using the indicator $[c_0 \in \text{QR}^*] = \frac{1+\chi(c_0)}{2}$ for $c_0 \in
 \mathbb{F}_p^*$:
$$S = \frac{1}{2}\underbrace{\sum_{c_0 \in \mathbb{F}_p^*} \chi(c_0^2 - 4)}_{S_1
} + \frac{1}{2}\underbrace{\sum_{c_0 \in \mathbb{F}_p^*} \chi(c_0^3 - 4c_0)}_{S_
2}.$$

**Computing $S_1$:** $\sum_{x \in \mathbb{F}_p} \chi(x^2 - 4) = -1$ (standard re
sult for $a \neq 0$). Subtracting the $x=0$ term: $S_1 = -1 - \chi(-4) = -1 - (-
1) = 0$ (since $\chi(-4) = \chi(-1)\chi(4) = (-1)(1) = -1$ for $p \equiv 3 \pmod
{4}$).

**Computing $S_2$:** $S_2 = \sum_{x \in \mathbb{F}_p} \chi(x^3 - 4x) = -a_p$, wh
ere $a_p = p + 1 - \#E(\mathbb{F}_p)$ is the trace of Frobenius for the elliptic
 curve $E: y^2 = x^3 - 4x$.

This curve has $j$-invariant $1728$ and **complex multiplication by $\mathbb{Z}[
i]$**. By Deuring's theorem, for a prime $p$ that is **inert** in $\mathbb{Q}(i)
$ — which happens precisely when $p \equiv 3 \pmod{4}$ — the trace of Frobenius
is $a_p = 0$.

Since $107 \equiv 3 \pmod{4}$, we have $a_p = 0$, so $S_2 = 0$.

*(Verification: For $p = 3, 7, 11$ — all $\equiv 3 \pmod{4}$ — direct point coun
ting confirms $\#E(\mathbb{F}_p) = p+1$, i.e., $a_p = 0$.)*

Therefore $S = \frac{1}{2}(0 + 0) = 0$, and:
$$N = \frac{1}{2}(52 + 0) = 26.$$

**Step 5: Final count.**

$$\text{Answer} = p \cdot N + 1 = 107 \times 26 + 1 = 2782 + 1 = \boxed{2783}.$$

The $+1$ accounts for $c = p^2 - 2$ (the unique element of $\text{QR}^*(p^2)$ wi
th $c \equiv -2 \pmod{p^2}$, giving $c^2 - 4 \equiv 0 \pmod{p^2}$).
