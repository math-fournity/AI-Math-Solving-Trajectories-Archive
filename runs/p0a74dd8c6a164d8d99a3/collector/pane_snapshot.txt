## Proof

**Claim.** The smallest closed set containing $C^1[-1,1]$ in $(\mathscr{B}[-1,1]
,\|\cdot\|_\infty)$ is $C[-1,1]$, the set of all continuous real-valued function
s on $[-1,1]$.

**Step 1: $C^1[-1,1]\subset C[-1,1]\subset \mathscr{B}[-1,1]$.**

Every continuously differentiable function is continuous, and every continuous f
unction on the compact interval $[-1,1]$ is bounded, so both inclusions hold.

**Step 2: $C[-1,1]$ is closed in $(\mathscr{B}[-1,1],\|\cdot\|_\infty)$.**

Let $(f_n)\subset C[-1,1]$ converge uniformly to some $f\in\mathscr{B}[-1,1]$, i
.e. $\|f_n-f\|_\infty\to 0$. A uniform limit of continuous functions on a topolo
gical space is continuous. Hence $f\in C[-1,1]$. Therefore $C[-1,1]$ is closed u
nder sup-norm limits, so it is closed in $\mathscr{B}[-1,1]$.

**Step 3: $C^1[-1,1]$ is dense in $C[-1,1]$ with respect to $\|\cdot\|_\infty$.*
*

By the Weierstrass approximation theorem, the polynomials are dense in $C[-1,1]$
 under the sup norm. Every polynomial is in $C^1[-1,1]$ (polynomials are infinit
ely differentiable). Hence for every $f\in C[-1,1]$ and every $\varepsilon>0$, t
here exists a polynomial $p\in C^1[-1,1]$ with $\|f-p\|_\infty<\varepsilon$. Thu
s $\overline{C^1[-1,1]}^{\,\|\cdot\|_\infty}\supseteq C[-1,1]$.

**Step 4: Conclusion.**

Since $C^1[-1,1]\subset C[-1,1]$ and $C[-1,1]$ is closed (Step 2), we have $\ove

p 3), we have $\overline{C^1[-1,1]}\supseteq C[-1,1]$. Therefore

$$\overline{C^1[-1,1]}^{\,\|\cdot\|_\infty}=C[-1,1].$$

The closure of a set is the smallest closed set containing it, so the smallest c
losed set containing $C^1[-1,1]$ in $(\mathscr{B}[-1,1],\|\cdot\|_\infty)$ is:

$$\boxed{C[-1,1]}$$
