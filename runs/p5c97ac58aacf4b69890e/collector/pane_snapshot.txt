## Proof

**Claim.** There exists a non-constant entire function whose image is not all of
 $\mathbb{C}$.

**Example.** The exponential function $f(z) = e^z$.

**Verification.**

*$f$ is entire.* The power series $e^z = \sum_{n=0}^{\infty} \frac{z^n}{n!}$ has
 infinite radius of convergence (since $\lim_{n\to\infty} \sqrt[n]{1/n!} = 0$),
so it defines a holomorphic function on all of $\mathbb{C}$.

*$f$ is non-constant.* For instance, $f(0) = 1$ while $f(\pi i) = e^{\pi i} = -1
 \neq 1$.

*The image of $f$ is not all of $\mathbb{C}$.* We show $0 \notin f(\mathbb{C})$.
 For any $z = x + iy \in \mathbb{C}$,
$$e^z = e^{x}(\cos y + i\sin y),$$
so $|e^z| = e^x > 0$. Hence $e^z \neq 0$ for every $z \in \mathbb{C}$, meaning $
0 \notin f(\mathbb{C})$.

Therefore $f(\mathbb{C}) \subseteq \mathbb{C}\setminus\{0\} \subsetneq \mathbb{C
}$, so the image is a proper subset of $\mathbb{C}$.

**Conclusion.** The non-constant entire function $f(z) = e^z$ has image $\mathbb
{C}\setminus\{0\}$, which is not the entire complex plane. Hence such a function
 exists. $\blacksquare$
