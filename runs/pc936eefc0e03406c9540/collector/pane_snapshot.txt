Answer: No — $L^1(\mathbb{X})$ does not have Schur's property in general

Setup and definitions

Schur's property for a Banach space $X$ means: every weakly convergent sequence
in $X$ is strongly (norm) convergent. Equivalently, if $f_n \rightharpoonup f$
weakly in $X$, then $|f_n - f| \to 0$.

The question asks whether this holds for $L^1(\mathbb{X})$ for a general measure
space $\mathbb{X}$.

Claim: No. There exist measure spaces $\mathbb{X}$ for which $L^1(\mathbb{X})$
fails Schur's property. We give an explicit counterexample on $\mathbb{X} =
[0,1]$ with Lebesgue measure.

The counterexample

Let $\mathbb{X} = ([0,1], \mathcal{B}, \lambda)$ where $\lambda$ is Lebesgue
measure. Define $$f_n(x) = \sin(2\pi n x), \qquad n = 1, 2, 3, \dots$$

We will show:

  1. $f_n \rightharpoonup 0$ weakly in $L^1([0,1])$, but
  2. $|f_n|_1 \not\to 0$,

so weak convergence does not imply strong convergence, and Schur's property
fails.

Step 1: Weak convergence $f_n \rightharpoonup 0$

The dual space of $L^1([0,1])$ is $L^\infty([0,1])$ (this is a standard fact for
$\sigma$-finite measure spaces). Therefore $f_n \rightharpoonup 0$ weakly in
$L^1([0,1])$ iff $$\int_0^1 f_n(x), g(x), dx \to 0 \quad \text{for every } g \in
L^\infty([0,1]).$$

Since $[0,1]$ has finite measure, $L^\infty([0,1]) \subset L^1([0,1])$. So it
suffices to show that for every $g \in L^1([0,1])$, $$\int_0^1 g(x) \sin(2\pi n
x), dx \to 0 \quad \text{as } n \to \infty.$$

This is precisely the Riemann–Lebesgue lemma: for any $g \in L^1([0,1])$, $$
\hat{g}(n) := \int_0^1 g(x), e^{2\pi i n x}, dx \to 0 \quad \text{as } |n| \to
\infty.$$

Taking the imaginary part gives $\int_0^1 g(x)\sin(2\pi n x),dx \to 0$.

Proof of the Riemann–Lebesgue lemma (for completeness): First, for $g =
\mathbf{1}_{[a,b]}$ (an indicator of an interval), a direct computation gives $$
\int_a^b \sin(2\pi n x),dx = \frac{\cos(2\pi n a) - \cos(2\pi n b)}{2\pi n} \to
0.$$ By linearity, the same holds for step functions (finite linear combinations
of interval indicators). Step functions are dense in $L^1([0,1])$. For general
$g \in L^1([0,1])$ and $\varepsilon > 0$, pick a step function $s$ with $|g - s|
_1 < \varepsilon$. Then $$\left|\int_0^1 g(x)\sin(2\pi n x),dx\right| \leq
\left|\int_0^1 s(x)\sin(2\pi n x),dx\right| + |g - s|1 \cdot |\sin(2\pi n
\cdot)|\infty.$$ The first term $\to 0$ (step function case) and the second is
$< \varepsilon$. Since $\varepsilon$ is arbitrary, the integral $\to 0$. $
\square$

Therefore $f_n \rightharpoonup 0$ weakly in $L^1([0,1])$.

Step 2: Failure of strong convergence

Compute the $L^1$-norm: $$|f_n|_1 = \int_0^1 |\sin(2\pi n x)|, dx.$$

By the substitution $u = nx$ and the $1$-periodicity of $|\sin(2\pi \cdot)|$, $$
\int_0^1 |\sin(2\pi n x)|, dx = \int_0^1 |\sin(2\pi x)|, dx = \frac{2}{\pi}
\quad \text{for all } n \geq 1.$$

(The last equality: $\int_0^1 |\sin(2\pi x)|dx = 2\int_0^{1/2} \sin(2\pi x),dx =
2 \cdot \frac{1}{\pi} = \frac{2}{\pi}$.)

Thus $|f_n|_1 = \frac{2}{\pi}$ for all $n$, so $|f_n - 0|_1 = \frac{2}{\pi}
\not\to 0$.

Conclusion

We have exhibited a sequence $(f_n)$ in $L^1([0,1])$ with $f_n \rightharpoonup
0$ weakly but $|f_n|_1 \not\to 0$. Hence $L^1([0,1])$ does not have Schur's
property, and therefore the answer to the question is:

No, $L^1(\mathbb{X})$ does not have Schur's property in general. Schur's
property holds for $L^1$ only when the measure space is purely atomic (the
classical case being $\ell^1 = L^1(\mathbb{N}, \text{counting measure})$, where
Schur's original theorem applies), but it fails for any measure space with a
non-atomic part, as demonstrated by the counterexample above.
