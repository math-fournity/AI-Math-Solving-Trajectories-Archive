## Solution

We determine all polynomials $P(x) \in \mathbb{Z}[x]$ satisfying $P(P(x)) = P(x)
 + P(x^2)$ for every integer $x$.

**Key observation.** Both sides are polynomials in $x$ with rational (in fact in
teger) coefficients. Since they agree on the infinite set $\mathbb{Z}$, they mus
t be **identical as polynomials**. Hence we may compare degrees and coefficients
 directly.

---

### Degree analysis

Let $n = \deg P$.

- If $n \ge 1$, the leading term of $P(P(x))$ is $a_n \cdot (a_n x^n)^n = a_n^{\
,n+1} x^{n^2}$, which is nonzero, so $\deg(P(P(x))) = n^2$.
- The right-hand side has $\deg(P(x) + P(x^2)) = \max(n, 2n) = 2n$.

Equating degrees: $n^2 = 2n$, so $n = 0$ or $n = 2$.

(The case $n = 1$ gives $\deg\text{LHS} = 1$ but $\deg\text{RHS} = 2$, impossibl
e since the $x^2$-coefficient of $\text{RHS}$ is the nonzero leading coefficient
 $a_1$.)

---

### Case $n = 0$: $P(x) = c$ constant

$P(P(x)) = c$ and $P(x) + P(x^2) = c + c = 2c$, so $c = 2c$, giving $c = 0$.

---

### Case $n = 2$: $P(x) = ax^2 + bx + c$, $a \ne 0$

Compute both sides.

$$P(x) + P(x^2) = ax^4 + (a+b)x^2 + bx + 2c.$$

For $P(P(x))$, expand $(ax^2+bx+c)^2 = a^2x^4 + 2abx^3 + (b^2+2ac)x^2 + 2bcx + c
^2$, then

$$P(P(x)) = a^3x^4 + 2a^2bx^3 + (ab^2+2a^2c+ab)x^2 + (2abc+b^2)x + (ac^2+bc+c).$
$

Comparing coefficients:

| Power | Equation |
|---|---|
| $x^4$ | $a^3 = a \;\Rightarrow\; a^2 = 1$, so $a = \pm 1$ |
| $x^3$ | $2a^2 b = 0 \;\Rightarrow\; b = 0$ |
| $x^2$ | $ab^2 + 2a^2 c + ab = a + b \;\Rightarrow\; 2a^2 c = a \;\Rightarrow\;
 2c = a$ (using $a^2=1,\ b=0$) |
| $x^1$ | $2abc + b^2 = b \;\Rightarrow\; 0 = 0$ ✓ |
| $x^0$ | $ac^2 + bc + c = 2c \;\Rightarrow\; ac^2 = c \;\Rightarrow\; c(ac - 1)
 = 0$ |

From $2c = a$ with $a = \pm 1$ we get $c = \pm \tfrac{1}{2}$, which is **not an
integer**. This contradicts the requirement that $P$ have integer coefficients.

(Equivalently, $2c = a$ forces $a$ to be even, but $a^2 = 1$ forces $a = \pm 1$,
 which is odd — a contradiction.)

Hence **no quadratic with integer coefficients** satisfies the equation.

---

### Conclusion

The only polynomial $P(x)$ with integer coefficients satisfying $P(P(x)) = P(x)
+ P(x^2)$ for all integers $x$ is

$$\boxed{P(x) = 0}.$$

A quick verification: $P(P(x)) = 0$ and $P(x) + P(x^2) = 0 + 0 = 0$. ✓
