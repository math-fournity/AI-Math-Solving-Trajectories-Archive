# Problem

A specialized logistics company is designing a secure cargo route with $n+1$ checkpoints. These checkpoints are to be positioned at specific integer mile-markers along a straight highway, denoted as $a_0, a_1, \dots, a_n$, such that the distance between any two checkpoints is strictly increasing ($a_0 < a_1 < \dots < a_n$).

To ensure the security of the transport, the lead engineer mandates a "Composite Gap Rule": the distance between any two distinct checkpoints (the value $a_j - a_i$ for all $0 \le i < j \le n$) must never be a prime number. 

The company wants to minimize the total land usage by placing the final checkpoint at the lowest possible mile-marker. For a given number of intervals defined by $n \ge 1$, determine the smallest possible value for the coordinate of the final checkpoint $a_n$.
