## Solution

**Step 1: Reformulate as an eigenvalue problem.**

Set $y_k = x_{k+1}$ for $k = -1, 0, 1, \ldots, n$, so $y_{-1} = x_0 = 0$, $y_0 =
 x_1 = 1$. The recurrence becomes, for $k \geq 0$:
$$c\, y_k = (k+1)\,y_{k+1} + (n-k)\,y_{k-1}.$$

This is the eigenvalue equation $M\mathbf{y} = c\,\mathbf{y}$ for the $n \times
n$ tridiagonal matrix $M$ (indexed $j = 0, \ldots, n-1$) with:
- $M_{j,j} = 0$,
- $M_{j,j+1} = j+1$ (superdiagonal),
- $M_{j+1,j} = n-j-1$ (subdiagonal).

The condition $x_{n+1} = 0$ is $y_n = 0$, which is exactly the characteristic eq
uation $\det(cI - M) = 0$. To see this precisely: define $q_k = k!\, y_k$. Then
$q_0 = 1$, $q_1 = c$, and the recurrence gives $q_{k+1} = c\,q_k - k(n-k)\,q_{k-
1}$, which is precisely the three-term recurrence for the characteristic polynom
ial $p_k(c) = \det(cI - M_k)$ of the leading $(k+1)\times(k+1)$ principal submat
rix. Thus $y_k = p_k(c)/k!$, and $y_n = 0 \iff p_n(c) = 0$, i.e., $c$ is an eige
nvalue of $M$.

**Step 2: Symmetrize $M$ and identify with $\mathfrak{su}(2)$.**

Let $D = \operatorname{diag}\!\left(\sqrt{\binom{n-1}{0}}, \sqrt{\binom{n-1}{1}}
, \ldots, \sqrt{\binom{n-1}{n-1}}\right)$. One checks that $d_{j+1}/d_j = \sqrt{
(n-1-j)/(j+1)}$, so $S = D^{-1}MD$ is **symmetric** tridiagonal with:
- $S_{j,j} = 0$,
- $S_{j,j+1} = S_{j+1,j} = (j+1)\cdot\frac{d_{j+1}}{d_j} = \sqrt{(j+1)(n-1-j)}$.

This is the matrix $2J_x$ in the spin-$s$ representation of $\mathfrak{su}(2)$ w
ith $s = \frac{n-1}{2}$. Concretely, in the basis $|s,m\rangle$ with $m = s, s-1
, \ldots, -s$ (indexed by $j = 0, \ldots, n-1$ via $m = s - j$):
$$\langle j | J_x | j+1 \rangle = \tfrac{1}{2}\sqrt{s(s+1) - (s-j-1)(s-j)} = \tf
rac{1}{2}\sqrt{(j+1)(n-1-j)},$$
so $S = 2J_x$.

**Step 3: Eigenvalues.**

The eigenvalues of $J_x$ in the spin-$s$ representation are $m = s, s-1, \ldots,
 -s$, i.e., $\frac{n-1}{2}, \frac{n-3}{2}, \ldots, -\frac{n-1}{2}$. Therefore th
e eigenvalues of $S = 2J_x$, and hence of $M$, are:
$$c \in \{n-1,\; n-3,\; n-5,\; \ldots,\; -(n-1)\}.$$
These are $n$ distinct real values. The **largest** is $c = n-1$.

**Step 4: Compute $x_k$ with $c = n-1$.**

We claim $x_k = \binom{n-1}{k-1}$ for $1 \leq k \leq n$. We verify this satisfie
s the recurrence. Substituting $x_k = \binom{n-1}{k-1}$ and $c = n-1$:

$$(k+1)\binom{n-1}{k+1} \stackrel{?}{=} (n-1)\binom{n-1}{k} - (n-k)\binom{n-1}{k
-1}.$$

**LHS:** $(k+1)\binom{n-1}{k+1} = \frac{(n-1)!}{k!\,(n-k-2)!}$.

**RHS:** Using $\binom{n-1}{k} = \frac{(n-1)!}{k!\,(n-k-1)!}$ and $(n-k)\binom{n
-1}{k-1} = \frac{(n-1)!}{(k-1)!\,(n-k-1)!} = \frac{k\,(n-1)!}{k!\,(n-k-1)!}$:

$$\text{RHS} = \frac{(n-1)!}{k!\,(n-k-1)!}\bigl[(n-1) - k\bigr] = \frac{(n-1)!\,
(n-k-1)}{k!\,(n-k-1)!} = \frac{(n-1)!}{k!\,(n-k-2)!}.$$

So LHS $=$ RHS. ✓

**Initial conditions:** $x_0 = 0 = \binom{n-1}{-1}$ (by convention) and $x_1 = 1
 = \binom{n-1}{0}$. ✓

**Step 5: Verification of $x_{n+1} = 0$.**

With $c = n-1$ and $x_k = \binom{n-1}{k-1}$, we get $x_{n+1} = \binom{n-1}{n} =
0$. ✓

**Small-case checks:**
- $n=1$: $c = 0$, $x_1 = \binom{0}{0} = 1$. ✓
- $n=2$: $c = 1$, $x_1 = 1, x_2 = 1$. ✓
- $n=3$: $c = 2$, $x_1 = 1, x_2 = 2, x_3 = 1$. ✓
- $n=4$: $c = 3$, $x_1 = 1, x_2 = 3, x_3 = 3, x_4 = 1$, and $x_5 = \binom{3}{4}
= 0$. ✓

## Answer

$$\boxed{x_k = \binom{n-1}{k-1}}, \qquad 1 \leq k \leq n.$$

The largest value of $c$ for which $x_{n+1} = 0$ is $c = n-1$, and with this cho
ice the sequence is given by the binomial coefficients $\binom{n-1}{k-1}$.
