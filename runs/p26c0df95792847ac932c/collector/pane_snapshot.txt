## Solution

Let $A = \mathbb{N} = \{1, 2, 3, \dots\}$, equipped with the usual metric $d_A(m
,n) = |m - n|$ inherited from $\mathbb{R}$.

**$A$ is unbounded:** For every $M > 0$, the element $n = \lceil M \rceil + 1 \i
n A$ satisfies $n > M$, so $A$ is not bounded.

**Every function $f: A \to (M, d_M)$ is uniformly continuous:** Let $f: \mathbb{
N} \to M$ be any function into any metric space, and let $\varepsilon > 0$ be gi
ven. Set $\delta = \tfrac{1}{2}$.

Suppose $m, n \in \mathbb{N}$ with $|m - n| < \tfrac{1}{2}$. Since $m$ and $n$ a
re positive integers, $|m - n|$ is a non-negative integer. The only non-negative
 integer strictly less than $\tfrac{1}{2}$ is $0$, so $|m - n| = 0$, i.e., $m =
n$. Therefore

$$d_M(f(m), f(n)) = d_M(f(n), f(n)) = 0 < \varepsilon.$$

Thus for every $\varepsilon > 0$ there exists $\delta = \tfrac{1}{2} > 0$ such t
hat for all $m, n \in A$, $|m-n| < \delta \implies d_M(f(m), f(n)) < \varepsilon
$. This is exactly the definition of uniform continuity. Since $f$ was arbitrary
, **every** function from $A$ to any metric space is uniformly continuous.

**Remark on the key idea.** The essential property is that distinct points of $A
$ are separated by a positive minimum distance: $\inf\{|m - n| : m, n \in \mathb
b{N},\, m \ne n\} = 1 > 0$. Any set with this "uniform discreteness" property (a
nd which is unbounded) serves as an example. $\mathbb{N}$ is the canonical insta
nce: choosing $\delta$ below the minimum inter-point distance collapses the unif
orm-continuity condition to the trivial case $m = n$, making the condition hold
for *every* function regardless of its values.
