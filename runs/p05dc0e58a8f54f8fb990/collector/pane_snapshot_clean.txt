Let $S(N) = \sum_{k=1}^{N-1} (N \bmod k)$.

**Direct computation for small $N$:**

| $N$ | Remainders $N \bmod k$, $k=1,\dots,N-1$ | $S(N)$ | $S(N)<N$? |
|-----|------------------------------------------|--------|-----------|
| 2 | 0 | 0 | Yes |
| 3 | 0, 1 | 1 | Yes |
| 4 | 0, 0, 1 | 1 | Yes |
| 5 | 0, 1, 2, 1 | 4 | Yes |
| 6 | 0, 0, 0, 2, 1 | 3 | Yes |
| 7 | 0, 1, 1, 3, 2, 1 | 8 | No |
| 8 | 0, 0, 2, 0, 3, 2, 1 | 8 | No |

So $N = 2, 3, 4, 5, 6$ all satisfy $S(N) < N$, while $N = 7, 8$ do not.

**For $N \ge 9$, the partial sum over $k \in (N/2,\, N)$ already forces $S(N) \g
e N$.**

For every integer $k$ with $\lfloor N/2 \rfloor < k < N$, we have $1 < N/k \le 2
$, so $\lfloor N/k \rfloor = 1$ and thus $N \bmod k = N - k$. These $k$ range ov
er $\lfloor N/2 \rfloor + 1, \dots, N-1$, giving remainders $1, 2, \dots, r$ whe
re
$$r = N - 1 - \lfloor N/2 \rfloor = \lceil N/2 \rceil - 1.$$
The partial sum is
$$T(N) = 1 + 2 + \cdots + r = \frac{r(r+1)}{2}.$$

**Case 1: $N = 2m$ even, $m \ge 5$ (i.e., $N \ge 10$).** Then $r = m-1$ and
$$T = \frac{m(m-1)}{2} \ge 2m = N \iff m-1 \ge 4 \iff m \ge 5.$$
So $T \ge N$, hence $S(N) \ge T \ge N$.

**Case 2: $N = 2m+1$ odd, $m \ge 4$ (i.e., $N \ge 9$).** Then $r = m$ and
$$T = \frac{m(m+1)}{2} \ge 2m+1 = N \iff m^2 - 3m - 2 \ge 0.$$
At $m = 4$: $16 - 12 - 2 = 2 > 0$, and $m^2 - 3m - 2$ is increasing for $m \ge 4
$. So $T \ge N$, hence $S(N) \ge N$.

**Combining all cases:**

- For $N \ge 9$: $S(N) \ge T(N) \ge N$, so $S(N) < N$ is impossible.
- For $N = 7$: $S(7) = 8 \ge 7$.
- For $N = 8$: $S(8) = 8 \ge 8$.

Therefore $S(N) \ge N$ for every $N \ge 7$, and $S(N) < N$ holds **only** for $N
 = 2, 3, 4, 5, 6$.

$$\boxed{N \in \{2,\, 3,\, 4,\, 5,\, 6\}}$$
