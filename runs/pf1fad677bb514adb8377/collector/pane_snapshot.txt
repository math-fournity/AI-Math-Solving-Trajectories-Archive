**Answer: The statement is FALSE.**

## Counterexample: Inverse 3D Bessel Process

Let $R = (R_t)_{t \geq 0}$ be a 3-dimensional Bessel process starting from $R_0
= 1$ (i.e., $R_t = \|B_t\|$ where $B$ is 3D Brownian motion started at $(1,0,0)$
). Define $M_t = 1/R_t$.

### Verification of all properties

**1. Non-negative.** A 3D Bessel process starting from $x > 0$ never hits 0 (3D
Brownian motion is transient; the probability of ever reaching the origin from a
 point at distance $x>0$ is 0). So $R_t > 0$ for all $t$ a.s., hence $M_t > 0$.

**2. Continuous.** $R_t = \|B_t\|$ is continuous (norm of continuous Brownian mo
tion) and strictly positive, so $M_t = 1/R_t$ is continuous.

**3. Local martingale.** The 3D Bessel process satisfies the SDE $dR_t = dW_t +
\frac{1}{R_t}\,dt$ (the Bessel drift $(d-1)/(2R_t) = 1/R_t$ for $d=3$). Applying
 Itô's formula to $f(r) = 1/r$:

$$d\!\left(\frac{1}{R_t}\right) = -\frac{1}{R_t^2}\,dR_t + \frac{1}{2}\cdot\frac
{2}{R_t^3}\,(dR_t)^2 = -\frac{1}{R_t^2}\left(dW_t + \frac{1}{R_t}\,dt\right) + \
frac{1}{R_t^3}\,dt = -\frac{1}{R_t^2}\,dW_t.$$

So $dM_t = -M_t^2\,dW_t$, confirming $M$ is a (continuous) local martingale.

**4. NOT a true martingale (strict local martingale).** Since $M$ is a non-negat
ive local martingale, it is a supermartingale (by Fatou's lemma applied to the l
ocalizing sequence), so $E[M_t] \leq E[M_0] = 1$. We compute $E[M_t]$ explicitly
. The transition density of the 3D Bessel process starting at $x>0$ is:

$$f_{R_t}(r) = \frac{r}{x\sqrt{2\pi t}}\cdot 2\sinh\!\left(\frac{rx}{t}\right) e
^{-(r^2+x^2)/(2t)}, \quad r > 0.$$

Then:

$$E\!\left[\frac{1}{R_t}\right] = \int_0^\infty \frac{1}{r}\,f_{R_t}(r)\,dr = \f
rac{2}{x\sqrt{2\pi t}}\,e^{-x^2/(2t)} \int_0^\infty \sinh\!\left(\frac{rx}{t}\ri
ght)e^{-r^2/(2t)}\,dr.$$

Evaluating the integral using $\int_0^\infty e^{\pm rx/t - r^2/(2t)}\,dr = e^{x^
2/(2t)}\sqrt{2\pi t}\,\Phi(\pm x/\sqrt{t})$:

$$\int_0^\infty \sinh(rx/t)\,e^{-r^2/(2t)}\,dr = e^{x^2/(2t)}\sqrt{2\pi t}\left[
\Phi(x/\sqrt{t}) - \tfrac{1}{2}\right].$$

Substituting and simplifying (with $x=1$):

$$\boxed{E[M_t] = 2\left[\Phi\!\left(\frac{1}{\sqrt{t}}\right) - \frac{1}{2}\rig
ht].}$$

At $t=0$: $E[M_0] = 2[\Phi(\infty) - 1/2] = 1$. For any $t > 0$: $1/\sqrt{t} < \
infty$, so $\Phi(1/\sqrt{t}) < 1$, giving $E[M_t] < 1 = E[M_0]$. Therefore $M$ i
s **not** a true martingale.

**5. Uniformly integrable.** Since 3D Brownian motion is transient, $R_t \to \in
fty$ a.s. as $t \to \infty$, so $M_t \to 0$ a.s. From the explicit formula:

$$E[M_t] = 2\left[\Phi(1/\sqrt{t}) - \frac{1}{2}\right] \xrightarrow{t \to \inft
y} 2\left[\Phi(0) - \frac{1}{2}\right] = 0 = E[M_\infty],$$

where $M_\infty = 0$.

Now we use the standard theorem for non-negative supermartingales: *If $(X_t)$ i
s a non-negative supermartingale with $X_t \to X_\infty$ a.s., then $\{X_t\}$ is
 uniformly integrable if and only if $E[X_t] \to E[X_\infty]$.*

Since $M$ is a non-negative local martingale, it is a non-negative supermartinga
le. We have $M_t \to 0$ a.s. and $E[M_t] \to 0 = E[M_\infty]$. By the theorem, $
\{M_t : t \geq 0\}$ is uniformly integrable.

*(The "if" direction of this theorem follows because $E[M_t] \to E[M_\infty]$ wi
th $M_t \geq 0$ and $M_t \to M_\infty$ a.s. implies $E[|M_t - M_\infty|] \to 0$
by Scheffé's lemma, i.e., $M_t \to M_\infty$ in $L^1$, and $L^1$-convergence of
the family implies uniform integrability.)*

### Conclusion

The process $M_t = 1/R_t$ (inverse 3D Bessel process) is:
- **Non-negative** ✓
- **Continuous** ✓
- **A local martingale** ✓
- **Uniformly integrable** ✓ ($\{M_t\}$ is UI since $M_t \to 0$ a.s. and $E[M_t]
 \to 0$)
- **NOT a true martingale** ✗ ($E[M_t] = 2[\Phi(1/\sqrt{t}) - 1/2] < 1 = E[M_0]$
 for all $t > 0$)

The key insight is that uniform integrability of the family $\{M_t : t \geq 0\}$
 (over deterministic times) is weaker than being of class (D) (uniform integrabi
lity over all stopping times). A local martingale is a true martingale if and on
ly if it is of class (DL), which requires UI over bounded stopping times — a con
dition not guaranteed by UI over deterministic times alone. The inverse Bessel p
rocess exploits exactly this gap: it is UI over deterministic times but loses ma
ss through "leakage to infinity" that only manifests at the level of stopping ti
mes.

**The statement is FALSE.**
