## Proof

**Setup.** The vector field $X(z,t) = (z^2, t)$ is defined on $\mathbb{R}^2$ wit
h coordinates $(z,t)$. The unique zero is at the origin: $z^2 = 0$ and $t = 0$ g
ives $(z,t) = (0,0)$, which is isolated. The index at $(0,0)$ is the Brouwer deg
ree of the map
$$f_r : \partial B(0,r) \cong S^1 \to S^1, \qquad f_r(z,t) = \frac{X(z,t)}{\|X(z
,t)\|}.$$
*(Note: since $X$ takes values in $\mathbb{R}^2$, the target is $S^1 \subset \ma
thbb{R}^2$; the $S^2$ in the problem statement is a typo for $S^1$.)*

**Parametrization.** Set $(z,t) = (r\cos\theta,\, r\sin\theta)$ for $\theta \in
[0, 2\pi]$. Then
$$X(r\cos\theta, r\sin\theta) = (r^2\cos^2\theta,\; r\sin\theta).$$
The index is the winding number of this curve around the origin:
$$\operatorname{ind}(X, 0) = \frac{1}{2\pi}\int_0^{2\pi} \frac{d\phi}{d\theta}\,
d\theta = \frac{\Delta\phi}{2\pi},$$
where $\phi(\theta) = \operatorname{atan2}(r\sin\theta,\; r^2\cos^2\theta)$ is t
he continuous argument.

**Tracking the angle.** I trace $\phi(\theta)$ continuously over $[0, 2\pi]$:

| $\theta$ | $X = (r^2\cos^2\theta,\; r\sin\theta)$ | $\phi$ |
|---|---|---|
| $0$ | $(r^2, 0)$ | $0$ |
| $\nearrow \pi/2$ | first component $\searrow 0^+$, second $\nearrow r$ | $\nea
rrow \pi/2$ |
| $\pi/2$ | $(0, r)$ | $\pi/2$ |
| $\nearrow \pi$ | first component $\nearrow r^2$, second $\searrow 0^+$ | $\sea
rrow 0$ |
| $\pi$ | $(r^2, 0)$ | $0$ |
| $\nearrow 3\pi/2$ | first component $\searrow 0^+$, second $\searrow -r$ | $\s
earrow -\pi/2$ |
| $3\pi/2$ | $(0, -r)$ | $-\pi/2$ |
| $\nearrow 2\pi$ | first component $\nearrow r^2$, second $\nearrow 0^-$ | $\ne
arrow 0$ |
| $2\pi$ | $(r^2, 0)$ | $0$ |

**Key observation:** The first component $r^2\cos^2\theta \geq 0$ for all $\thet
a$, and equals $0$ only at $\theta = \pi/2$ and $\theta = 3\pi/2$. Therefore the
 vector $X$ never enters the left half-plane ($z < 0$), so $\phi(\theta) \in [-\
pi/2, \pi/2]$ for all $\theta$. The angle oscillates:
$$0 \;\xrightarrow{\nearrow}\; \pi/2 \;\xrightarrow{\searrow}\; 0 \;\xrightarrow
{\searrow}\; -\pi/2 \;\xrightarrow{\nearrow}\; 0.$$

The net change is $\Delta\phi = 0 - 0 = 0$, so
$$\operatorname{ind}(X, 0) = \frac{0}{2\pi} = 0.$$

**Verification via product structure.** $X(z,t) = (z^2, t) = F(z) \times G(t)$ w
ith $F(z) = z^2$ and $G(t) = t$. By the product formula for Brouwer degree, $\op
eratorname{ind}(X) = \operatorname{ind}(F) \cdot \operatorname{ind}(G)$.

- **Index of $G(t) = t$ at $0$:** $G'(0) = 1 > 0$, so $\operatorname{ind}(G) = \
operatorname{sgn}(G'(0)) = +1$.
- **Index of $F(z) = z^2$ at $0$:** $F'(0) = 0$ (degenerate). The normalized map
 $F/|F|: S^0 = \{-r, +r\} \to S^0 = \{-1, +1\}$ sends **both** points to $+1$ (s
ince $z^2 > 0$ for $z \neq 0$). This is the constant map to $+1$. Its degree (as
 a map $S^0 \to S^0$) is $0$: for the regular value $+1$, the two preimages $\{+
r, -r\}$ carry opposite orientations of $S^0$, contributing $+1 + (-1) = 0$.

Therefore $\operatorname{ind}(X, 0) = 0 \times 1 = 0$, confirming the direct com
putation.

**Conclusion.** The index of the vector field $X(z,t) = (z^2, t)$ at the point $
(0,0)$ is $\boxed{0}$.
