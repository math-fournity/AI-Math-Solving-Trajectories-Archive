## Proof

**Step 1: Determine f(0).**

Setting z = 0 in f(2z) = f(z)² gives f(0) = f(0)², so f(0)(f(0)−1) = 0. Since f(
0) ≠ 0, we get **f(0) = 1**.

**Step 2: Set up the coefficient recursion.**

Write the power series f(z) = Σ_{n≥0} a_n z^n (entire, so infinite radius). Then

f(2z) = Σ_{n≥0} a_n 2^n z^n,  and  f(z)² = Σ_{n≥0} (Σ_{k=0}^{n} a_k a_{n−k}) z^n
.

Equating coefficients:

a_n · 2^n = Σ_{k=0}^{n} a_k a_{n−k} = 2 a_0 a_n + Σ_{k=1}^{n−1} a_k a_{n−k}.

Since a_0 = 1, this gives

**(2^n − 2) a_n = Σ_{k=1}^{n−1} a_k a_{n−k}**   for n ≥ 1.

- **n = 1:** (2 − 2) a_1 = 0, i.e. 0 = 0. So **a_1 is a free parameter**; call i
t α ∈ ℂ.
- **n ≥ 2:** 2^n − 2 ≥ 2 > 0, so a_n is **uniquely determined** by a_1, …, a_{n−
1}:

a_n = (Σ_{k=1}^{n−1} a_k a_{n−k}) / (2^n − 2).

Thus the entire function is determined by the single free parameter α = a_1.

**Step 3: Show by induction that a_n = α^n / n!.**

*Base cases:* a_0 = 1 = α⁰/0!, a_1 = α = α¹/1!.

*Inductive step:* Assume a_k = α^k / k! for all k < n (n ≥ 2). Then

(2^n − 2) a_n = Σ_{k=1}^{n−1} (α^k/k!)(α^{n−k}/(n−k)!) = α^n · Σ_{k=1}^{n−1} 1/(
k!(n−k)!).

Using the binomial identity Σ_{k=0}^{n} 1/(k!(n−k)!) = (1/n!) Σ_{k=0}^{n} C(n,k)
 = 2^n/n!, we get

Σ_{k=1}^{n−1} 1/(k!(n−k)!) = 2^n/n! − 2/n! = (2^n − 2)/n!.

Therefore (2^n − 2) a_n = α^n · (2^n − 2)/n!, and since 2^n − 2 ≠ 0,

**a_n = α^n / n!.**  ✓

**Step 4: Conclude.**

The power series is f(z) = Σ_{n≥0} α^n z^n / n! = e^{αz}, which is entire for ev
ery α ∈ ℂ.

**Verification:** f(2z) = e^{2αz} = (e^{αz})² = f(z)², and f(0) = 1 ≠ 0. ✓

**Conclusion.** The entire functions satisfying f(2z) = f(z)² with f(0) ≠ 0 are
exactly

$$\boxed{f(z) = e^{\alpha z}, \quad \alpha \in \mathbb{C}.}$$
