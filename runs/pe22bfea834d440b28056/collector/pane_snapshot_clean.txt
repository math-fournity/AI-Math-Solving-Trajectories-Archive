## Proof

We apply **Rouché's theorem**.

**Setup.** Since $f$ is analytic on $\bar{B}(0;1)$, it is analytic on some open
set containing the closed unit disk. The function $z^n$ is entire, hence analyti
c on the same region. Consider

$$g(z) = f(z) - z^n.$$

We count the zeros of $g$ in $B(0;1)$, counting multiplicities.

**Boundary comparison.** On the circle $|z| = 1$:

$$|z^n| = |z|^n = 1.$$

By hypothesis, $|f(z)| < 1$ for every $|z| = 1$. Therefore on $|z| = 1$:

$$|f(z)| < 1 = |z^n|,$$

i.e., $|f(z)| < |-z^n|$ on the boundary. (We compare $f$ against $-z^n$, since $
g = f + (-z^n)$.)

**Applying Rouché.** Both $f$ and $-z^n$ are analytic on and inside $|z| = 1$, a
nd on $|z| = 1$ we have the strict inequality

$$|f(z)| < |-z^n|.$$

Rouché's theorem states that $f + (-z^n) = f - z^n$ and $-z^n$ have the same num
ber of zeros (counting multiplicities) inside $|z| < 1$.

The function $-z^n$ has a single zero at $z = 0$ of multiplicity $n$, so it has
exactly $n$ zeros in $B(0;1)$ counting multiplicities.

**Conclusion.** The equation $f(z) = z^n$, i.e., $g(z) = f(z) - z^n = 0$, has ex
actly

$$\boxed{n}$$

solutions in $B(0;1)$, counting multiplicities.
