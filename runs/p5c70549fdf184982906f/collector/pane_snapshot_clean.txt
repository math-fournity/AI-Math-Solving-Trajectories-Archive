Looking at this problem, I need to determine whether a non-commutative reduced r
ing of order $p^2$ can exist. Since any ring of order $p^2$ *with identity* is c
ommutative (given), the only hope would be a ring *without* identity. I'll show
this is also impossible.

## Proof

Let $R$ be a reduced ring of order $p^2$. The additive group of $R$ has order $p
^2$, so $\operatorname{char}(R) \in \{p, p^2\}$. We show $R$ is commutative in b
oth cases.

### Case 1: $\operatorname{char}(R) = p^2$

The additive group is cyclic of order $p^2$, generated by some element $a$. Ever
y element is $ka$ for $k \in \mathbb{Z}/p^2\mathbb{Z}$, and multiplication is de
termined by $a^2 = ta$ for some $t$. Then
$$(ka)(ma) = km\, a^2 = kmt\, a = mkt\, a = (ma)(ka),$$
so $R$ is commutative.

### Case 2: $\operatorname{char}(R) = p$

Then $R$ is a 2-dimensional algebra over $\mathbb{F}_p$ (not necessarily unital)
. Form the **unitization** $R^1 = \mathbb{F}_p \oplus R$ with multiplication
$$(\alpha, r)(\beta, s) = (\alpha\beta,\; \alpha s + \beta r + rs).$$
This is a ring with identity $(1,0)$ and $|R^1| = p \cdot p^2 = p^3$.

**Claim.** $R^1$ is reduced.

*Proof of claim.* Suppose $(\alpha, r)^n = 0$ for some $n \geq 1$. The projectio
n $\pi: R^1 \to \mathbb{F}_p$, $\pi(\alpha,r) = \alpha$, is a ring homomorphism,
 so $\alpha^n = 0$ in $\mathbb{F}_p$, giving $\alpha = 0$. Then $(0,r)^n = (0, r
^n) = 0$, so $r^n = 0$ in $R$. Since $R$ is reduced, $r = 0$. Thus $(\alpha, r)
= (0,0)$. $\square$

Now $R^1$ is a **finite reduced ring with identity**. Being finite, it is Artini
an. The Jacobson radical $J(R^1)$ is nilpotent (Artinian), but $R^1$ is reduced
so it has no nonzero nilpotent ideals; hence $J(R^1) = 0$ and $R^1$ is semisimpl
e.

By the **Wedderburn–Artin theorem**,
$$R^1 \cong \prod_{i=1}^{k} M_{n_i}(\mathbb{F}_{q_i})$$
for finite fields $\mathbb{F}_{q_i}$. Since $R^1$ is reduced, each factor $M_{n_
i}(\mathbb{F}_{q_i})$ must be reduced. But for $n_i \geq 2$, the matrix ring con
tains the nonzero nilpotent element $E_{12}$ with $E_{12}^2 = 0$. Therefore $n_i
 = 1$ for all $i$, and
$$R^1 \cong \prod_{i=1}^{k} \mathbb{F}_{q_i},$$
which is **commutative**.

The embedding $\iota: R \hookrightarrow R^1$, $r \mapsto (0, r)$, is an injectiv
e ring homomorphism. Since $R^1$ is commutative, so is $R$.

### Conclusion

In both cases ($\operatorname{char} = p^2$ and $\operatorname{char} = p$), every
 reduced ring of order $p^2$ is commutative. Therefore, **there does not exist a
 non-commutative reduced ring of order $p^2$**.
