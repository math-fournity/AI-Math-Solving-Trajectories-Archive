## `problem_10_3_of_waldschmidt` 的证明

**定理：** Waldschmidt 猜想蕴含 Mahler 问题 10.3。具体来说，如果存在 $c > 0$ 使
得对于所有 $n \geq 2$ 都有 $\|e^n\| > n^{-c}$，那么存在 $c' > 0$ 使得对于所有 $n
 \geq 1$ 都有 $\|e^n\| > e^{-c'n}$。

（这里 $\|x\| = \mathrm{distToNearestInt}(x)$ 表示 $x$ 到最近整数的距离。）

**证明：**

假设 Waldschmidt 猜想成立，设 $c > 0$ 为使得对于所有 $n \geq 2$ 都有 $\|e^n\| >
n^{-c}$ 的常数。

**步骤 1：$n = 1$ 的情况。** 因为 $e \approx 2.718$，距离 $e$ 最近的整数是 $3$，
所以
$$\|e\| = |e - 3| = 3 - e > 0,$$
利用了 $e < 3$ 的事实。记 $d = \|e\| = 3 - e$。

选择 $c_0 = -\log d + 1$。那么：
$$e^{-c_0} = e^{\log d - 1} = \frac{d}{e} < d,$$
因为 $e > 1$（这由 $e > 2.7$ 得出，这是 Mathlib 中的一个标准界限）。

**步骤 2：定义 $c' = \max(c,\, c_0)$。** 因为 $c > 0$，我们有 $c' \geq c > 0$，
所以 $c' > 0$。

**步骤 3：验证 $n = 1$ 的情况。** 我们有：
$$e^{-c' \cdot 1} = e^{-c'} \leq e^{-c_0} < d = \|e\| = \|e^1\|.$$
不等式 $e^{-c'} \leq e^{-c_0}$ 成立是因为 $c' = \max(c, c_0) \geq c_0$，且 $\exp
$ 是单调递增的。

**步骤 4：验证 $n \geq 2$ 的情况。** 根据 Waldschmidt 猜想，对于 $n \geq 2$，$\|
e^n\| > n^{-c}$。

关键观察是 $\log n \leq n$ 对于所有 $n \geq 1$ 成立（因为对于所有 $x > 0$ 都有 $
\log x \leq x$）。因此：

$$e^{-c' n} \;\leq\; e^{-c\, n} \;\leq\; e^{-c \log n} \;=\; n^{-c} \;<\; \|e^n\
|.$$

详细说明：
- **第一个不等式：** $c' \geq c$ 蕴含 $-c'n \leq -cn$，且 $\exp$ 是单调递增的，
所以 $e^{-c'n} \leq e^{-cn}$。
- **第二个不等式：** $\log n \leq n$ 蕴含 $-cn \leq -c\log n$（乘以 $-c < 0$ 会
反转不等号），且 $\exp$ 是单调递增的，所以 $e^{-cn} \leq e^{-c\log n}$。
- **等式：** 对于 $n > 0$，$e^{-c\log n} = \left(e^{\log n}\right)^{-c} = n^{-c}
$。
- **最后一个不等式：** Waldschmidt 猜想应用于 $n \geq 2$ 的情况。

**结论：** 常数 $c' = \max(c, c_0)$ 满足 $c' > 0$ 且对于所有 $n \geq 1$ 都有 $e^
{-c'n} < \|e^n\|$。这恰好就是 Mahler 问题 10.3 的陈述。 $\blacksquare$

theorem problem_10_3_of_waldschmidt (h : type_of% waldschmidt) : type_of% proble
m_10_3 := by
  obtain ⟨c, hc, hyp⟩ := h
  -- ||e|| = |e - 3| = 3 - e > 0
  have hd_pos : 0 < distToNearestInt (Real.exp 1) := by
    simp only [distToNearestInt, Real.round_exp_one_eq_three, Int.cast_ofNat]
    rw [abs_pos]
    linarith [Real.exp_one_lt_three]
  -- Set c₀ = -log(||e||) + 1 so that exp(-c₀) = ||e||/e < ||e||
  set c₀ := -Real.log (distToNearestInt (Real.exp 1)) + 1
  refine ⟨max c c₀, lt_max_of_lt_left hc, fun n hn => ?_⟩
  rcases Nat.lt_or_ge n 2 with h2 | h2
  · -- Case n = 1
    have : n = 1 := by omega
    subst this
    simp only [Nat.cast_one]
    calc Real.exp (-(max c c₀) * 1)
        ≤ Real.exp (-c₀) := by
          apply Real.exp_le_exp.mpr
          nlinarith [le_max_right c c₀]
      _ < distToNearestInt (Real.exp 1) := by
          rw [show -c₀ = Real.log (distToNearestInt (Real.exp 1)) - 1 by ring]
          rw [Real.exp_sub, Real.exp_log hd_pos]
          have he : (1 : ℝ) < Real.exp 1 := Real.exp_one_gt_d9.trans' (by norm_n
um)
          exact (lt_div_iff he).mpr hd_pos
  · -- Case n ≥ 2: use Waldschmidt's bound
    have hwald := hyp n h2
    have hn_ne : (n : ℝ) ≠ 0 := by exact_mod_cast (ne_of_gt (by exact_mod_cast h
n))
    have hn_cast_pos : (0 : ℝ) < (n : ℝ) := by exact_mod_cast hn
    calc Real.exp (-(max c c₀) * (n : ℝ))
        ≤ Real.exp (-(c : ℝ) * (n : ℝ)) := by
          apply Real.exp_le_exp.mpr
          nlinarith [le_max_left c c₀]
      _ ≤ Real.exp (-(c : ℝ) * Real.log (n : ℝ)) := by
          apply Real.exp_le_exp.mpr
          nlinarith [Real.log_le_self (n : ℝ)]
      _ = (n : ℝ) ^ (-(c : ℝ)) := by
          rw [Real.rpow_def_of_pos hn_cast_pos]
          ring
      _ < distToNearestInt (Real.exp n) := hwald
