## Proof

We show:
- **For α = 1:** No such function exists (Lipschitz ⟹ bounded variation).
- **For every α ∈ (0, 1):** Such a function exists (explicit construction).

Without loss of generality, we work on [0,1] (an affine change of variables pres
erves both the Hölder and bounded-variation properties, up to constants).

---

### Case α = 1: Lipschitz ⟹ Bounded Variation

Suppose f : [0,1] → ℝ is Lipschitz: |f(x) − f(y)| ≤ L|x − y| for all x, y. For a
ny partition 0 = t₀ < t₁ < ⋯ < tₙ = 1,

$$V(f, P) = \sum_{i=1}^{n} |f(t_i) - f(t_{i-1})| \leq L \sum_{i=1}^{n} |t_i - t_
{i-1}| = L.$$

Taking the supremum over all partitions, V(f) ≤ L < ∞. Hence every Lipschitz fun
ction is of bounded variation, and **no such function exists for α = 1**.

---

### Case α ∈ (0, 1): Construction

Set

$$\gamma = \frac{\alpha}{1-\alpha} > 0, \qquad \beta = \alpha(\gamma+1) = \frac{
\alpha}{1-\alpha}.$$

Note that **β = γ**, hence **β/γ = 1**. Define f : [0,1] → ℝ by

$$f(0) = 0, \qquad f(x) = x^{\beta} \sin\!\left(\frac{1}{x^{\gamma}}\right) \tex
t{ for } x \in (0,1].$$

Since |f(x)| ≤ xᵝ → 0 as x → 0⁺, f is continuous on [0,1].

#### Claim 1: f is Hölder-α

We prove |f(x) − f(y)| ≤ C|x − y|ᵅ for all x, y ∈ [0,1], with C = max(1, 2^{β+1}
, β+γ).

**Subcase x = 0:** |f(y) − f(0)| = yᵝ|sin(1/yᵞ)| ≤ yᵝ. Since β = α(γ+1) > α and
y ≤ 1, we have yᵝ ≤ yᵅ. ✓

**Subcase 0 < x ≤ y, h := y − x ≥ x^{γ+1}:**
$$|f(y) - f(x)| \leq y^{\beta} + x^{\beta} \leq 2(x+h)^{\beta}.$$
From h ≥ x^{γ+1} we get x ≤ h^{1/(γ+1)}; from h ≤ 1 we get h ≤ h^{1/(γ+1)}. Thus
 x + h ≤ 2h^{1/(γ+1)}, giving
$$|f(y)-f(x)| \leq 2^{\beta+1} h^{\beta/(\gamma+1)} = 2^{\beta+1} h^{\alpha}. \q
uad \checkmark$$

**Subcase 0 < x ≤ y, h < x^{γ+1}:**
By the Mean Value Theorem, |f(y) − f(x)| ≤ h · max_{t∈[x,y]} |f'(t)|. Now

$$f'(t) = \beta\, t^{\beta-1}\sin(1/t^{\gamma}) - \gamma\, t^{\beta-\gamma-1}\co
s(1/t^{\gamma}),$$

so |f'(t)| ≤ β t^{β−1} + γ t^{β−γ−1}. Since β − γ − 1 = β − β − 1 = −1 < 0 (usin
g β = γ), we have t^{β−γ−1} = t^{−1} ≥ x^{−1} for t ≥ x. Also, for x ≤ 1: since
β − γ − 1 < 0, x^{β−γ−1} ≥ 1 ≥ x^{β−1} (the latter because β − 1 may be positive
 or negative, but t^{β−1} ≤ max(1, x^{β−1}) ≤ x^{β−γ−1} for x ≤ 1). Therefore

$$|f'(t)| \leq (\beta + \gamma)\, x^{\beta - \gamma - 1} \quad \text{for } t \in
 [x,y].$$

Hence |f(y) − f(x)| ≤ (β+γ) h x^{β−γ−1}. We need (β+γ) h^{1−α} x^{β−γ−1} ≤ C. Si
nce h < x^{γ+1}:

$$h^{1-\alpha} < x^{(\gamma+1)(1-\alpha)},$$

so

$$h^{1-\alpha}\, x^{\beta-\gamma-1} < x^{(\gamma+1)(1-\alpha) + \beta - \gamma -
 1} = x^{\beta - \alpha(\gamma+1)} = x^{0} = 1,$$

using β = α(γ+1). Thus |f(y) − f(x)| < (β+γ) hᵅ. ✓

Combining all cases, f is Hölder-α on [0,1].

#### Claim 2: f is not of bounded variation

The points where sin(1/xᵞ) = ±1 are

$$x_k = \left(\frac{\pi}{2} + k\pi\right)^{-1/\gamma} = \bigl[\pi(k + \tfrac{1}{
2})\bigr]^{-1/\gamma}, \quad k = 0, 1, 2, \ldots$$

with sin(1/xₖᵞ) = (−1)ᵏ, so f(xₖ) = (−1)ᵏ xₖᵝ. The sequence x₀ > x₁ > x₂ > ⋯ → 0
.

For each N, consider the partition Pₙ = {0, xₙ, xₙ₋₁, …, x₁, x₀} (or extended to
 include 1). The variation satisfies

$$V(f, P_N) \geq \sum_{k=0}^{N-1} |f(x_k) - f(x_{k+1})| = \sum_{k=0}^{N-1} \bigl
|x_k^{\beta} + x_{k+1}^{\beta}\bigr| = \sum_{k=0}^{N-1} \bigl(x_k^{\beta} + x_{k
+1}^{\beta}\bigr).$$

Now xₖᵝ = [π(k + 1/2)]^{−β/γ} = [π(k + 1/2)]^{−1} since **β/γ = 1**. Therefore

$$V(f, P_N) \geq \frac{1}{\pi} \sum_{k=0}^{N-1} \frac{1}{k + 1/2} \xrightarrow{N
 \to \infty} \infty.$$

Hence V(f) = ∞, and **f is not of bounded variation**.

---

### Conclusion

- **For α = 1:** Every Lipschitz function on [a,b] is of bounded variation, so n
o such function exists.
- **For every α ∈ (0, 1):** The function f(x) = x^{α/(1−α)} sin(1/x^{α/(1−α)}) (
with f(0) = 0) is Hölder-α on [0,1] but not of bounded variation.

Therefore, **yes**, such a function exists for every α ∈ (0, 1), but **not** for
 α = 1.
