# Problem

In a specialized digital logistics warehouse, every inventory batch is assigned a unique identification code $n$. This code is a sequence of decimal digits represented as $a_m \dots a_2 a_1 a_0$. 

The facility utilizes a "Cycle-Shift" security protocol to verify batch integrity. To generate a verification key $r$, the security system takes the last two digits of the identification code ($a_1$ and $a_0$) and moves them to the front of the sequence, shifting all other digits to the right. For example, if a code were $12345$, the verification key would be $45123$.

A high-priority shipment requires a specific identification code $n$ where the resulting verification key $r$ is exactly double the value of the original code ($r = 2n$).

Calculate the smallest possible natural number $n$ that satisfies this security protocol.
