Looking at this problem, I need to analyze the system for each $n \geq 2$:
$$n(n-1)x_i + \left(\prod_{j \neq i} x_j\right)S = n^2(n-1), \quad S = \sum x_j^
2.$$

## Step 1: No $x_i$ can be zero

If $x_1 = 0$, then for $i \neq 1$: $P_i = \prod_{j \neq i} x_j = 0$ (since it in
cludes $x_1$), so $n(n-1)x_i = n^2(n-1)$, giving $x_i = n$ for all $i \neq 1$. T
hen $P_1 = n^{n-1}$, $S = (n-1)n^2$, and the equation for $i=1$ requires $n^{n-1
} \cdot (n-1)n^2 = n^2(n-1)$, i.e., $n^{n-1} = 1$, impossible for $n \geq 2$.

## Step 2: At most two distinct values

Subtracting equations $i$ and $k$ (with all $x_j \neq 0$, so $P_i = P/x_i$):
$$(x_i - x_k)\left[n(n-1) - \frac{SP}{x_i x_k}\right] = 0.$$
So either $x_i = x_k$ or $x_i x_k = \frac{SP}{n(n-1)}$ (a constant $C$ for all d
iffering pairs). If three distinct values $a, b, c$ existed, then $ab = ac = bc
= C$ forces $b = c$, contradiction. So **at most two distinct values**.

## Step 3: Two distinct values — derive $a + b = n$

Let value $a$ appear $k$ times, value $b$ appear $n-k$ times ($1 \leq k \leq n-1
$, $a \neq b$). From $ab = \frac{SP}{n(n-1)}$ and $S = ka^2 + (n-k)b^2$, $P = a^
k b^{n-k}$:

$$n(n-1) = a^{k-1}b^{n-k-1}\left[ka^2 + (n-k)b^2\right]. \quad (*)$$

Substituting back into the original equation for $x_i = a$:
$$n(n-1)a + b \cdot n(n-1) = n^2(n-1) \implies \boxed{a + b = n}.$$

## Step 4: Classify all solutions

**Symmetric case** ($x_i = c$): $c[(n-1) + c^n] = n(n-1)$. For $n = 2$: $(c-1)(c
^2+c+2) = 0$ gives $c = 1$. For $n \geq 3$: checking all divisors of $n(n-1)$ vi
a the rational root theorem yields no integer solutions (verified for each $n =
3, \ldots, 10$).

**Two-distinct-values case** with $a + b = n$, $a, b \neq 0$:

*Both positive, $a, b \geq 2$:* Then $a^{k-1}b^{n-k-1} \geq 2^{n-2}$ and $ka^2 +

\geq 3$. No solutions.

*One value equals 1:* Take $\{a, b\} = \{1, n-1\}$. Setting $a = 1, b = n-1$ in
$(*)$:
$$(n-1)^{n-k-1}\left[k + (n-k)(n-1)^2\right] = n(n-1).$$
For $k = n-1$ (one copy of $b = n-1$): $(n-1)^0[(n-1) + (n-1)^2] = n(n-1)$ ✓.
For $k \leq n-2$: $(n-1)^{n-k-1} \geq n-1$ and the bracket $\geq 2(n-1)^2$, so L

*One value negative:* If $a < 0$, then $b = n - a > n$, making $|b|^{n-k-1}$ eno

**For $n = 2$:** Only solution is $(1, 1)$. So $N_2 = 1$, $M_2 = 2$.
