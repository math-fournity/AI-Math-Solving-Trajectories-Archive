Looking at this problem, I need to determine whether φ(a) = 0 with a ≥ 0 implies
 φ(b*ab) = 0 for all b ∈ A.

**Answer: No, this is not true in general.**

## Counterexample

Let $A = M_2(\mathbb{C})$, the $C^*$-algebra of $2 \times 2$ complex matrices. D
efine the state $\phi: A \to \mathbb{C}$ by
$$\phi(x) = x_{11},$$
i.e., $\phi$ picks out the $(1,1)$-entry. This is indeed a state:
- $\phi(I) = 1$, so it is normalized.
- $\phi(x^*x) = (x^*x)_{11} = |x_{11}|^2 + |x_{21}|^2 \geq 0$ for all $x \in A$,
 so $\phi$ is positive.

Now let
$$a = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}.$$
This is positive (it is a projection, hence $a = a^* = a^2$, with eigenvalues $0
$ and $1$). We have
$$\phi(a) = a_{11} = 0.$$

Take
$$b = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}, \quad b^* = \begin{pmatrix}
0 & 1 \\ 0 & 0 \end{pmatrix}.$$

Compute $b^*ab$:
$$b^* a = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\begin{pmatrix} 0 & 0 \\ 0
 & 1 \end{pmatrix} = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix},$$
$$b^* a\, b = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\begin{pmatrix} 0 & 0
\\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}.$$

Therefore
$$\phi(b^*ab) = (b^*ab)_{11} = 1 \neq 0.$$

## Why the naive approach fails

One might hope to use the GNS/Cauchy–Schwarz machinery. Since $a \geq 0$ and $\p
hi(a) = 0$, writing $a = (a^{1/2})^* a^{1/2}$ gives $\phi((a^{1/2})^* a^{1/2}) =
 0$, so $a^{1/2} \in N_\phi := \{x \in A : \phi(x^*x) = 0\}$. By the Cauchy–Schw
arz inequality $|\phi(y^*x)|^2 \leq \phi(y^*y)\,\phi(x^*x)$, the set $N_\phi$ is
 a **left ideal**: $x \in N_\phi \Rightarrow cx \in N_\phi$ for all $c \in A$.

However, $\phi(b^*ab) = \phi((a^{1/2}b)^*(a^{1/2}b))$ requires $a^{1/2}b \in N_\
phi$, i.e., **right** multiplication closure. The null space $N_\phi$ of a gener
al state is only a left ideal, not a two-sided ideal, so this implication fails
— exactly as the counterexample demonstrates.

## Conclusion

The statement is **false**. A positive element $a$ with $\phi(a) = 0$ need not s
atisfy $\phi(b^*ab) = 0$ for all $b \in A$.
