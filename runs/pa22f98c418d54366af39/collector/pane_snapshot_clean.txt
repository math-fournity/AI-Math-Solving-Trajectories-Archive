## Solution

Let $a_{ij} \in \{+1, -1\}$ be the entry in row $i$, column $j$. Define row sums
 $r_i = \sum_{j=1}^{10} a_{ij}$ and column sums $c_j = \sum_{i=1}^{10} a_{ij}$.
Since each line has 10 entries of $\pm 1$, every $r_i$ and $c_j$ is an even inte
ger in $\{-10, -8, \dots, 8, 10\}$. Thus "Positive-Leaning" means sum $\geq 2$ a
nd "Negative-Leaning" means sum $\leq -2$.

Let $p, q, z_r$ be the numbers of positive, negative, and zero rows, and $P, Q,
z_c$ the numbers of positive, negative, and zero columns. The condition is $P =
q = k$, and we wish to maximize $k$.

### Upper bound: $k \leq 8$

The total sum $S = \sum_i r_i = \sum_j c_j$ satisfies:

**From rows** (positive rows contribute $\leq 10$, negative rows contribute $\le
q -2$, zero rows contribute $0$):
$$S \leq 10p - 2q = 10(10 - k - z_r) - 2k = 100 - 12k - 10z_r.$$

**From columns** (positive columns contribute $\geq 2$, negative columns contrib
ute $\geq -10$, zero columns contribute $0$):
$$S \geq 2P - 10Q = 2k - 10(10 - k - z_c) = 12k - 100 + 10z_c.$$

Combining (column lower bound $\leq$ row upper bound):
$$12k - 100 + 10z_c \leq 100 - 12k - 10z_r,$$
$$24k \leq 200 - 10(z_r + z_c).$$

Since $z_r, z_c \geq 0$, we get $24k \leq 200$, so $k \leq \lfloor 200/24 \rfloo
r = 8$.

For $k = 9$: $24 \cdot 9 = 216 > 200 \geq 200 - 10(z_r+z_c)$, which is impossibl
e. So **$k \leq 8$**.

### Construction: $k = 8$ is achievable

For $k = 8$, the inequality forces $z_r = z_c = 0$. Then $p = 2$, $q = 8$, $P =
8$, $Q = 2$.

We construct a $\{0,1\}$-matrix $B$ (where $b_{ij} = (a_{ij}+1)/2$) with:
- **Row sums**: 2 rows with sum 9, 8 rows with sum 4. (This gives 2 positive row
s with $r_i = 2\cdot9-10 = 8$, and 8 negative rows with $r_i = 2\cdot4-10 = -2$.
)
- **Column sums**: 8 columns with sum 6, 2 columns with sum 1. (This gives 8 pos
itive columns with $c_j = 2\cdot6-10 = 2$, and 2 negative columns with $c_j = 2\
cdot1-10 = -8$.)

Total $+1$ count: $2\cdot9 + 8\cdot4 = 18 + 32 = 50 = 8\cdot6 + 2\cdot1$. ✓ Tota
l sum $S = 2\cdot8 + 8\cdot(-2) = 0 = 8\cdot2 + 2\cdot(-8)$. ✓

**Existence via the Gale–Ryser theorem.** Sort row sums descending: $(9, 9, 4, 4
, 4, 4, 4, 4, 4, 4)$. Sort column sums descending: $(6, 6, 6, 6, 6, 6, 6, 6, 1,
1)$. We verify the Gale–Ryser condition $\sum_{i=1}^{t} r_i \leq \sum_{j=1}^{10}
 \min(t, c_j)$ for all $t$:
