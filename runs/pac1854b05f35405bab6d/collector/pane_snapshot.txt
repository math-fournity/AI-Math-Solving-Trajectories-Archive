## Solution

### Part (a): Finding the value of $a$

At equilibrium, $\partial u/\partial t = 0$, so the steady-state solution $u(r)$
 satisfies:

$$\frac{1}{r}\frac{d}{dr}\!\left[r\frac{du}{dr}\right] = 4, \qquad 0 \le r < a,$
$

with $|u(0^+)|<\infty$ and $u'(a)=5$.

**Solving the ODE.** Let $w(r) = u'(r)$. Then:

$$\frac{d}{dr}[rw] = 4r \implies rw = 2r^2 + C_1 \implies w = 2r + \frac{C_1}{r}
.$$

Boundedness at $r=0$ forces $C_1 = 0$, giving $u'(r) = 2r$ and thus $u(r) = r^2
+ C_2$.

**Applying the boundary condition** $u'(a) = 5$:

$$2a = 5 \implies \boxed{a = \tfrac{5}{2}}.$$

For any other value of $a$, the boundary condition $u'(a)=5$ is incompatible wit
h the ODE solution $u'(r)=2r$, so **no equilibrium exists**. The unique value is
 $a = \frac{5}{2}$.

---

### Part (b): The equilibrium solution and solvability condition

**Equilibrium solution.** With $a = 5/2$, the steady-state solution is:

$$\boxed{u(r) = r^2 + C}, \qquad 0 \le r \le \tfrac{5}{2},$$

where $C$ is an arbitrary constant (the solution is determined only up to a cons
tant since both conditions are of derivative/Neumann type).

**Verification.**
- $u'(r) = 2r$, so $u'(a) = 2 \cdot \frac{5}{2} = 5$ ✓
- $\frac{1}{r}\frac{d}{dr}[r \cdot 2r] = \frac{1}{r}\frac{d}{dr}[2r^2] = \frac{4
r}{r} = 4$, so $\frac{1}{r}\frac{d}{dr}[ru'] - 4 = 0$ ✓
- $u(0) = C < \infty$ ✓

**Solvability (compatibility) condition.** The steady-state equation $\frac{1}{r
}\frac{d}{dr}[ru'] = 4$ with Neumann-type data has a solution only if a Fredholm
-type compatibility condition holds. We derive it by integrating the steady-stat
e equation against the weight $r$ (the radial measure) over $[0, a]$:

$$\int_0^a \frac{1}{r}\frac{d}{dr}\!\left[r\frac{du}{dr}\right] r\,dr = \int_0^a
 4\,r\,dr.$$

The left side collapses via the fundamental theorem:

$$\int_0^a \frac{d}{dr}\!\left[r\frac{du}{dr}\right] dr = \left[r\frac{du}{dr}\r
ight]_{0}^{a} = a\,u'(a) - \lim_{r\to 0^+} r\,u'(r).$$

Since $u'(r) = 2r$ is bounded at the origin, $\lim_{r\to 0^+} r\,u'(r) = 0$. The
 right side gives $2a^2$. Thus the compatibility condition is:

$$a\,u'(a) = 2a^2.$$

Substituting $u'(a) = 5$:

$$5a = 2a^2 \implies a(5 - 2a) = 0.$$

Since $a > 0$, this yields $a = \frac{5}{2}$, **exactly confirming** the value f
ound in part (a).

**Physical interpretation.** The compatibility condition expresses heat balance:
 the total heat generated by the source $4$ over the disk of radius $a$ (which i
s $\int_0^a 4 \cdot 2\pi r\,dr = 4\pi a^2$) must equal the total heat flux out t
hrough the boundary $r = a$ (which is $-u'(a) \cdot 2\pi a = -10\pi a$ in the ou
tward-normal convention, or $+10\pi a$ accounting for the sign convention of the
 given Neumann data). Setting source $=$ outflow: $4\pi a^2 = 10\pi a$, i.e., $a
 = 5/2$. This is precisely the solvability condition, confirming that the equili
brium exists if and only if the internal generation balances the boundary flux.
