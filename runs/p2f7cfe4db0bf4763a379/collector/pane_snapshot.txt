## Proof

**Notation.** Let $\mathrm{SLO}$ denote the class of strict linear orders and $\
mathrm{SPO}$ the class of strict partial orders, both in the language $L = \{<\}
$ with a single binary relation symbol. Let $\mathrm{Th}^*(\mathcal{K})$ denote
the equality-free theory of a class $\mathcal{K}$: the set of all equality-free
$L$-sentences true in every member of $\mathcal{K}$.

**Claim.** $\mathrm{Th}^*(\mathrm{SLO}) \neq \mathrm{Th}^*(\mathrm{SPO})$.

**The inclusion that always holds.** Since every strict linear order is a strict
 partial order, $\mathrm{SLO} \subseteq \mathrm{SPO}$. Therefore any sentence tr
ue in *all* strict partial orders is true in all strict linear orders:
$$\mathrm{Th}^*(\mathrm{SPO}) \subseteq \mathrm{Th}^*(\mathrm{SLO}).$$

**The separating sentence.** Consider the equality-free sentence:
$$\varphi \;:=\; \forall x\,\forall y\,\forall z\,\bigl(x < y \;\rightarrow\; (x
 < z \;\vee\; z < y)\bigr).$$

This sentence contains no equality symbol, so it is a legitimate equality-free s
entence.

**Step 1: $\varphi$ is true in every strict linear order.**

Let $(L, <)$ be a strict linear order. Fix arbitrary $x, y, z \in L$ and suppose
 $x < y$. By linearity (totality for distinct elements), applied to the pair $z,
 x$, exactly one of the following holds: $z < x$, $z = x$, or $x < z$.

- **Case $z < x$:** By transitivity, $z < x$ and $x < y$ imply $z < y$. So $z <
y$ holds, hence $x < z \vee z < y$ holds.
- **Case $z = x$:** Then $z < y$ is the same as $x < y$, which is true by assump
tion. So $x < z \vee z < y$ holds.
- **Case $x < z$:** Then $x < z$ holds directly, so $x < z \vee z < y$ holds.

In every case, $x < y \rightarrow (x < z \vee z < y)$ holds. Since $x, y, z$ wer
e arbitrary, $\varphi$ is true in $(L, <)$. $\checkmark$

**Step 2: $\varphi$ is false in some strict partial order.**

Consider the structure $(P, <_P)$ where $P = \{a, b, c\}$ and $<_P \;=\; \{(a, b
)\}$ (i.e., $a <_P b$ and $c$ is incomparable to both $a$ and $b$).

- **Irreflexivity:** No element is related to itself. $\checkmark$
- **Transitivity:** The only related pair is $a < b$. There is no $b < c$ or sim
ilar chain, so transitivity holds vacuously. $\checkmark$

So $(P, <_P)$ is a strict partial order. It is not a strict linear order since $
c$ is incomparable to $a$ and $b$.

Now evaluate $\varphi$ with $x = a$, $y = b$, $z = c$:
- $x < y$: $a <_P b$ is **true**.
- $x < z$: $a <_P c$ is **false** ($a$ and $c$ are incomparable).
- $z < y$: $c <_P b$ is **false** ($c$ and $b$ are incomparable).

So $x < z \vee z < y$ is false, while $x < y$ is true. Therefore $x < y \rightar
row (x < z \vee z < y)$ is false, and $\varphi$ is **false** in $(P, <_P)$. $\ch
eckmark$

**Conclusion.** The sentence $\varphi$ belongs to $\mathrm{Th}^*(\mathrm{SLO})$
but not to $\mathrm{Th}^*(\mathrm{SPO})$. Therefore:
$$\mathrm{Th}^*(\mathrm{SLO}) \;\neq\; \mathrm{Th}^*(\mathrm{SPO}).$$

The equality-free theory of the class of strict linear orders is **not** the sam
e as the equality-free theory of the class of strict partial orders. The separat
ing sentence $\forall x\,\forall y\,\forall z\,(x < y \rightarrow (x < z \vee z
< y))$ expresses a consequence of linearity (every element is comparable to at l
east one endpoint of any ordered pair) that fails in partial orders with incompa
rable elements, and crucially this property is expressible without equality beca
use the case $z = x$ is handled by the disjunct $z < y$ (which becomes $x < y$,
true by assumption) rather than requiring an explicit inequality $z \neq x$.
