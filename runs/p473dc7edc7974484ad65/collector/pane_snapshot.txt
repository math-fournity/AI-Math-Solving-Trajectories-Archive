## Setting up the equations

From the Linear Balance condition:
$$c = \frac{a+b}{2} \implies a + b = 2c. \tag{1}$$

From the Reciprocal Balance condition (substituting $a+b = 2c$ from (1)):
$$c = \frac{2ab}{a+b} = \frac{2ab}{2c} = \frac{ab}{c}.$$

Multiplying both sides by $c$:
$$c^2 = ab \implies ab = c^2. \tag{2}$$

## Analyzing the system

We now have the system:
- $a + b = 2c$
- $ab = c^2$

The values $a$ and $b$ are the roots of the quadratic:
$$t^2 - (a+b)t + ab = 0 \implies t^2 - 2ct + c^2 = 0 \implies (t - c)^2 = 0.$$

This gives a **double root** $t = c$, meaning:
$$a = c \quad \text{and} \quad b = c.$$
