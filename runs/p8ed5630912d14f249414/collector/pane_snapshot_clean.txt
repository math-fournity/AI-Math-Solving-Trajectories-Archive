## Solution

### Setting up the characteristic equations

The PDE is quasilinear of the form $a\,u_x + b\,u_y = c$ with $a = u$, $b = u$,
$c = 1+u^2$. The characteristic ODEs are:

$$\frac{dx}{ds} = u, \qquad \frac{dy}{ds} = u, \qquad \frac{du}{ds} = 1 + u^2.$$

### First integral: $x - y = \text{const}$

Since $\frac{dx}{ds} = \frac{dy}{ds}$, we immediately get

$$\frac{d}{ds}(x - y) = 0 \implies x - y = \text{const} =: 2\alpha,$$

where $\alpha$ labels each characteristic.

### Parametrizing the initial curve

The initial data is prescribed on the line $x + y = 0$ (i.e., $y = -x$). We para
metrize the initial curve at $s = 0$ by

$$x(0) = \alpha, \quad y(0) = -\alpha, \quad u(0) = \tan\alpha,$$

so that $x(0) - y(0) = 2\alpha$, consistent with the first integral.

### Solving for $u$ along characteristics

The equation $\frac{du}{ds} = 1 + u^2$ separates:

$$\frac{du}{1+u^2} = ds \implies \arctan u = s + C.$$

Applying $u(0) = \tan\alpha$ (with $\alpha \in (-\pi/2, \pi/2)$ so that $\arctan
(\tan\alpha) = \alpha$):

$$\arctan u = s + \alpha \implies \boxed{u = \tan(s + \alpha).}$$

### Solving for $x$ and $y$ along characteristics

From $\frac{dx}{ds} = u = \tan(s+\alpha)$:

$$x = -\ln|\cos(s+\alpha)| + C_1.$$

At $s=0$: $\alpha = -\ln\cos\alpha + C_1$ (using $\cos\alpha > 0$ for $\alpha \i
n (-\pi/2,\pi/2)$), so $C_1 = \alpha + \ln\cos\alpha$. Thus

$$x = -\ln\cos(s+\alpha) + \alpha + \ln\cos\alpha.$$

Similarly, $\frac{dy}{ds} = \tan(s+\alpha)$ gives $y = -\ln\cos(s+\alpha) + C_2$
, and $y(0) = -\alpha$ yields $C_2 = -\alpha + \ln\cos\alpha$:

$$y = -\ln\cos(s+\alpha) - \alpha + \ln\cos\alpha.$$

### Eliminating $s$ in favor of $x, y$

**Subtracting** the two equations confirms $x - y = 2\alpha$, so

$$\alpha = \frac{x - y}{2}.$$

**Adding** the two equations:

$$x + y = -2\ln\cos(s+\alpha) + 2\ln\cos\alpha.$$

Solving for $\cos(s+\alpha)$:

$$\cos(s+\alpha) = \cos\alpha \cdot e^{-(x+y)/2} = \cos\!\left(\frac{x-y}{2}\rig
ht) e^{-(x+y)/2}.$$

### Expressing $u$ explicitly

Since $u = \tan(s+\alpha) = \frac{\sin(s+\alpha)}{\cos(s+\alpha)}$ and $\cos(s+\
alpha) = \cos\frac{x-y}{2}\,e^{-(x+y)/2}$, we use $\sin^2 + \cos^2 = 1$:

$$\sin^2(s+\alpha) = 1 - \cos^2\!\left(\frac{x-y}{2}\right) e^{-(x+y)} = \frac{e
^{x+y} - \cos^2\frac{x-y}{2}}{e^{x+y}}.$$

Therefore

$$u = \frac{\sin(s+\alpha)}{\cos(s+\alpha)} = \frac{\pm\sqrt{e^{x+y} - \cos^2\fr
ac{x-y}{2}}}{\cos\frac{x-y}{2}}.$$

**Determining the sign.** At $s = 0$ (the initial curve $x+y=0$), we have $s + \
alpha = \alpha = \frac{x-y}{2}$, and $u = \tan\alpha$. By continuity along each
characteristic, $s + \alpha$ retains the sign of $\alpha$ (it can only vanish at
 the boundary of the domain of existence). Hence $\sin(s+\alpha)$ has the same s
ign as $\sin\frac{x-y}{2}$, and:

$$\boxed{u(x,y) = \operatorname{sgn}\!\left(\sin\tfrac{x-y}{2}\right)\cdot \frac
{\sqrt{e^{x+y} - \cos^2\!\frac{x-y}{2}}}{\cos\!\frac{x-y}{2}}.}$$

Equivalently, $u$ is determined by the implicit relation

$$1 + u^2 = \frac{e^{x+y}}{\cos^2\!\frac{x-y}{2}},$$

with the sign of $u$ matching $\operatorname{sgn}(\tan\frac{x-y}{2})$ from the i
nitial condition.

### Verification

**Initial condition.** At $y = -x$: $x + y = 0$, $\frac{x-y}{2} = x$, so

$$u = \operatorname{sgn}(\sin x)\cdot\frac{\sqrt{1 - \cos^2 x}}{\cos x} = \opera
torname{sgn}(\sin x)\cdot\frac{|\sin x|}{\cos x} = \frac{\sin x}{\cos x} = \tan
x. \checkmark$$

**PDE verification.** Let $p = x+y$, $\alpha = \frac{x-y}{2}$, and $u = \frac{\s
qrt{e^p - \cos^2\alpha}}{\cos\alpha}$ (taking the positive branch; the negative
branch works identically). Then $u_x = u_p + u_\alpha$ and $u_y = u_p - u_\alpha
$, so

$$u\,u_x + u\,u_y = 2u\,u_p.$$

Computing $u_p = \frac{e^p}{2\sqrt{e^p - \cos^2\alpha}\,\cos\alpha} = \frac{e^p}
{2u\cos^2\alpha}$, we get

$$2u\,u_p = \frac{e^p}{\cos^2\alpha}.$$

On the other hand,

$$1 + u^2 = 1 + \frac{e^p - \cos^2\alpha}{\cos^2\alpha} = \frac{e^p}{\cos^2\alph
a}.$$

Thus $u\,u_x + u\,u_y = 1 + u^2$. $\checkmark$

### Domain of existence

The solution requires $e^{x+y} \geq \cos^2\frac{x-y}{2}$, i.e.,

$$x + y \geq 2\ln\cos\!\left(\frac{x-y}{2}\right),$$

which is automatically satisfied on the initial curve ($x+y=0 \geq 2\ln\cos\frac
{x-y}{2}$ since $\cos \leq 1$). The solution blows up when $e^{x+y} \to \infty$
or $\cos\frac{x-y}{2} \to 0$.
