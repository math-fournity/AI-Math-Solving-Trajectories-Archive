## Proof

Let $H$ be a class of $\{0,1\}$-valued functions with VC-dimension $d \geq 1$. R
ecall that the growth function (shattering coefficient) is

$$\Pi_H(m) = \max_{x_1,\dots,x_m} \bigl|\{(h(x_1),\dots,h(x_m)) : h \in H\}\bigr
|,$$

i.e. the maximum number of distinct dichotomies that $H$ can realize on a sample
 of size $m$. We prove the **Sauer–Shelah lemma**:

$$\boxed{\Pi_H(m) \leq \sum_{i=0}^{d} \binom{m}{i}.}$$

### Proof by induction on $m + d$

We prove the stronger statement that for every set $S$ of $m$ points,

$$|\Pi_H(S)| \leq \sum_{i=0}^{d}\binom{m}{i},$$

where $\Pi_H(S) = \{(h(x_1),\dots,h(x_m)) : h \in H\}$ is the set of dichotomies
 realized on $S = \{x_1,\dots,x_m\}$, and $d = \text{VCdim}(H)$.

**Base cases.**
- $m = 0$: the empty sample supports exactly one dichotomy (the empty pattern),
and $\sum_{i=0}^{d}\binom{0}{i} = \binom{0}{0} = 1$. ✓
- $d = 0$: VC-dimension $0$ means no point is shattered, i.e. on every singleton
 the class realizes at most one label. Equivalently $H$ realizes at most one dic
hotomy on every sample, so $\Pi_H(S) \le 1 = \binom{m}{0} = \sum_{i=0}^{0}\binom
{m}{i}$. ✓

**Inductive step.** Assume the bound holds for all pairs $(m', d')$ with $m' + d
' < m + d$. Let $S = \{x_1, \dots, x_m\}$ with $m \geq 1$, $d \geq 1$. Fix the l
ast point $x_m$ and partition the dichotomies on $S$ according to their restrict
ion to $S' = \{x_1,\dots,x_{m-1}\}$.

For each dichotomy $\sigma = (\sigma_1,\dots,\sigma_{m-1})$ on $S'$ that is exte
nded by $H$ to $S$, define:
- $\sigma \in \Pi^+_H(S')$ if **both** extensions $(\sigma, 0)$ and $(\sigma, 1)
$ are realized by $H$ on $S$ (i.e. some $h \in H$ agrees with $\sigma$ on $S'$ a
nd gives $h(x_m)=0$, and some $h' \in H$ agrees with $\sigma$ on $S'$ and gives
$h'(x_m)=1$).
- $\sigma \in \Pi^-_H(S')$ if **exactly one** extension is realized.

Then
$$|\Pi_H(S)| = |\Pi^+_H(S')| + |\Pi^-_H(S')| + |\Pi^+_H(S')| = 2|\Pi^+_H(S')| +
|\Pi^-_H(S')|,$$
because each $\sigma \in \Pi^+_H(S')$ contributes two dichotomies on $S$ (one wi
th last bit 0, one with last bit 1), and each $\sigma \in \Pi^-_H(S')$ contribut
es one. Also $|\Pi_H(S')| = |\Pi^+_H(S')| + |\Pi^-_H(S')|$, so

$$|\Pi_H(S)| = |\Pi_H(S')| + |\Pi^+_H(S')|. \tag{1}$$

**Bounding $|\Pi_H(S')|$.** The restriction of $H$ to $S'$ has VC-dimension $\le
q d$ (removing a point cannot increase VC-dimension). By the inductive hypothesi
s applied to $(m-1, d)$:

$$|\Pi_H(S')| \leq \sum_{i=0}^{d}\binom{m-1}{i}. \tag{2}$$

**Bounding $|\Pi^+_H(S')|$.** Define a derived class $H^*$ of $\{0,1\}$-valued f
unctions on $S'$ as follows. For each $\sigma \in \Pi^+_H(S')$, pick two functio
ns $h_0, h_1 \in H$ that both agree with $\sigma$ on $S'$ and satisfy $h_0(x_m)
= 0$, $h_1(x_m) = 1$. Define $h^* \in H^*$ by $h^*(x_j) = h_0(x_j) = h_1(x_j)$ f
or $j$ where they agree, and $h^*(x_j) = h_1(x_j)$ (arbitrarily, say $h_1$) wher
e they disagree. The key point: the set of points in $S'$ on which $h_0$ and $h_
1$ **disagree** is exactly where $h^*$ "marks" a disagreement. The crucial obser
vation is:

> A subset $T \subseteq S'$ is shattered by $H^*$ only if $T \cup \{x_m\}$ is sh
attered by $H$.

Indeed, for any labeling of $T$ by $H^*$, the construction lets us lift it to a
labeling of $T \cup \{x_m\}$ by $H$: the label of $x_m$ is chosen freely (0 or 1
) by selecting $h_0$ or $h_1$, and the labels on $T$ are reproduced because on $
T$, $H^*$'s value equals one of $h_0, h_1$ which we can select. Hence any $T$ sh
attered by $H^*$ gives $T \cup \{x_m\}$ shattered by $H$, so $|T| \leq d - 1$, i
.e.

$$\text{VCdim}(H^*) \leq d - 1.$$

Applying the inductive hypothesis to $H^*$ on $S'$ with VC-dimension $\leq d-1$
(the pair $(m-1, d-1)$, and $m-1+d-1 < m+d$):

$$|\Pi^+_H(S')| \leq |\Pi_{H^*}(S')| \leq \sum_{i=0}^{d-1}\binom{m-1}{i}. \tag{3
}$$

(The first inequality holds because the map $\sigma \mapsto h^*$ is injective on
 $\Pi^+_H(S')$: distinct $\sigma$'s give distinct $h^*$'s on $S'$.)

**Combining.** Adding (2) and (3) into (1):

$$|\Pi_H(S)| \leq \sum_{i=0}^{d}\binom{m-1}{i} + \sum_{i=0}^{d-1}\binom{m-1}{i}.
$$

Using the Pascal identity $\binom{m-1}{i} + \binom{m-1}{i-1} = \binom{m}{i}$ (wi
th $\binom{m-1}{-1} = 0$):

$$|\Pi_H(S)| \leq \sum_{i=0}^{d}\binom{m-1}{i} + \sum_{i=0}^{d-1}\binom{m-1}{i}
= \sum_{i=0}^{d}\left[\binom{m-1}{i} + \binom{m-1}{i-1}\right] = \sum_{i=0}^{d}\
binom{m}{i}.$$

Since this holds for every $S$ of size $m$, taking the maximum over $S$:

$$\Pi_H(m) \leq \sum_{i=0}^{d}\binom{m}{i}.$$

### Conclusion

For a class $H$ of $\{0,1\}$-valued functions with VC-dimension $d \geq 1$, the
growth function satisfies

$$\Pi_H(m) \leq \sum_{i=0}^{d}\binom{m}{i} = \binom{m}{0} + \binom{m}{1} + \cdot
s + \binom{m}{d}.$$

This is $O(m^d)$ for fixed $d$, polynomial in $m$ of degree $d$. (When $m \leq d
$, the sum equals $2^m$, consistent with the fact that $H$ can shatter samples o
f size up to $d$.) $\blacksquare$
