**Answer: Yes, such topologies exist.**

**Construction.** Let $X$ be an uncountable set (e.g., $X = \mathbb{R}$). Define
- $\tau_1$ = the discrete topology (every subset is open),
- $\tau_2$ = the cocountable topology (a nonempty set $U$ is open iff $X \setmin
us U$ is countable; together with $\emptyset$).

---

**Claim 1: $\tau_1$ is metrizable.**

The discrete metric $d(x,y) = 0$ if $x = y$ and $d(x,y) = 1$ if $x \neq y$ induc
es the discrete topology. So $\tau_1$ is metrizable. $\checkmark$

---

**Claim 2: $\tau_2$ is not metrizable.**

The cocountable topology on an uncountable set is not Hausdorff. Indeed, let $U,
 V$ be any two nonempty $\tau_2$-open sets. Then $X \setminus U$ and $X \setminu
s V$ are both countable, so $X \setminus (U \cap V) = (X \setminus U) \cup (X \s
etminus V)$ is countable. Since $X$ is uncountable, $U \cap V \neq \emptyset$. T
hus no two distinct points of $X$ can be separated by disjoint open sets, so $\t
au_2$ is not Hausdorff, hence not metrizable. $\checkmark$

---

**Claim 3: $\tau_1$ and $\tau_2$ have exactly the same convergent sequences, wit
h the same limits.**

*In $\tau_1$ (discrete):* A sequence $(x_n)$ converges to $x$ iff it is eventual
ly equal to $x$ (since $\{x\}$ is open).

*In $\tau_2$ (cocountable):* Every eventually constant sequence $x_n \to x$ conv
erges in any topology, so certainly in $\tau_2$. Conversely, suppose $x_n \to x$
 in $\tau_2$ and the sequence is **not** eventually equal to $x$. Set $S = \{x_n
 : x_n \neq x,\ n \in \mathbb{N}\}$; this is a countable set. Then $U = X \setmi
nus S$ is $\tau_2$-open (its complement $S$ is countable), and $x \in U$ (since
$x \notin S$). By convergence, $x_n \in U$ for all sufficiently large $n$. But $
U \cap S = \emptyset$, so for all sufficiently large $n$, $x_n \notin S$, which
forces $x_n = x$. This contradicts the assumption that the sequence is not event
ually equal to $x$.

Therefore the convergent sequences in $\tau_2$ are exactly the eventually consta
nt ones—precisely the same as in $\tau_1$, with the same limits. $\checkmark$

---

**Claim 4: $\tau_1 \neq \tau_2$.**

For any $x \in X$, the singleton $\{x\}$ is open in $\tau_1$ (discrete) but not
open in $\tau_2$, since $X \setminus \{x\}$ is uncountable, so $\{x\}$ is not co
countable-open. Hence $\tau_1 \neq \tau_2$. $\checkmark$

---

**Conclusion.** The topologies $\tau_1$ (discrete, metrizable) and $\tau_2$ (coc
ountable, non-metrizable) on the same uncountable underlying set $X$ share exact
ly the same convergent sequences with the same limits, yet are distinct. This wo
rks because $\tau_2$ is a non-sequential topology: its open sets are not determi
ned by sequential convergence, while $\tau_1$ (being metrizable, hence first-cou
ntable) is completely determined by its convergent sequences. The two agree on s
equential data but differ on non-sequentially-detectable open sets.
