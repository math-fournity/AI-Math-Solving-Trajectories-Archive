Looking at this problem, I need to find the smallest $k$ such that after sorting
 each column in descending order, every row from $k$ to 100 has sum ≤ 1, regardl
ess of the initial configuration (where each original row sums to ≤ 1).

**Answer: $k = 97$**

## Proof

**Notation.** Let $A = (a_{ij})$ be the $100 \times 25$ original matrix, with $\
sum_{j=1}^{25} a_{ij} \le 1$ for each row $i$. Let $B = (b_{ij})$ be the matrix
after sorting each column in descending order: $b_{1j} \ge b_{2j} \ge \cdots \ge
 b_{100j}$. Let $S_k = \sum_{j=1}^{25} b_{kj}$.

**Key observation (monotonicity).** Since each column is sorted descending, $b_{
k'j} \le b_{kj}$ for $k' \ge k$, so $S_{k'} \le S_k$. Thus it suffices to show $
S_k \le 1$ for the single row $k$.

---

### Part 1: $k = 96$ fails (construction with $S_{96} > 1$)

Partition the 100 rows into 25 groups $G_1, \dots, G_{25}$ of size 4. For each r
ow $i \in G_j$, set:
$$a_{ij} = 0, \qquad a_{i\ell} = \tfrac{1}{24} \text{ for all } \ell \ne j.$$

**Row sums:** Each row has 24 entries equal to $\frac{1}{24}$ and one entry equa
l to 0, so the row sum is $24 \cdot \frac{1}{24} = 1 \le 1$. ✓

**After sorting:** In column $j$, exactly 4 rows (those in $G_j$) have value 0,
and 96 rows have value $\frac{1}{24}$. Sorting descending gives $b_{1j} = \cdots
 = b_{96,j} = \frac{1}{24}$ and $b_{97,j} = \cdots = b_{100,j} = 0$.

Therefore:
$$S_{96} = \sum_{j=1}^{25} b_{96,j} = 25 \cdot \frac{1}{24} = \frac{25}{24} > 1.
$$

So $k = 96$ does not guarantee the safety condition.

---

### Part 2: $k = 97$ works ($S_{97} \le 1$ for every valid configuration)

Consider any valid initial configuration. For each column $j$, let $R_j \subsete
q \{1, \dots, 100\}$ be the set of original rows whose entries become the top 97
 positions in column $j$ after sorting. Then $|R_j| = 97$, and for every $i \in
R_j$, we have $a_{ij} \ge b_{97,j}$.

Define $t_i = |\{j : i \in R_j\}|$, the number of columns for which row $i$ appe
ars in the top 97. By double-counting:
$$\sum_{i=1}^{100} t_i = \sum_{j=1}^{25} |R_j| = 25 \cdot 97 = 2425.$$

Since there are only 25 columns, $t_i \le 25$ for every $i$. If all $t_i \le 24$
, then $\sum t_i \le 100 \cdot 24 = 2400 < 2425$, a contradiction. Therefore, th
ere exists a row $i^*$ with $t_{i^*} = 25$, meaning $i^* \in R_j$ for **all** 25
 columns.

For this row $i^*$, since $a_{i^*,j} \ge b_{97,j}$ for every $j$:
$$S_{97} = \sum_{j=1}^{25} b_{97,j} \le \sum_{j=1}^{25} a_{i^*,j} \le 1.$$

By monotonicity, $S_i \le S_{97} \le 1$ for all $i \ge 97$.

---

### Conclusion

- $k = 96$ fails: the construction above gives $S_{96} = \frac{25}{24} > 1$.
- $k = 97$ works: the pigeonhole argument forces $S_{97} \le 1$, and monotonicit
y extends this to all rows $97$ through $100$.

$$\boxed{k = 97}$$
