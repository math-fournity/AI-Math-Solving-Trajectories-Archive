## Proof

**Claim:** $C = \sqrt{2}+1$.

### Lower Bound: $C \geq \sqrt{2}+1$

Consider the extremal sequence with equality $x_{n+1} = S_n$:
- $x_1 = 1$, $S_1 = 1$; $x_2 = 1$, $S_2 = 2$; $x_3 = 2$, $S_3 = 4$; generally $S
_n = 2^{n-1}$ and $x_i = 2^{i-2}$ for $i \geq 2$.

Then $\sqrt{x_1} = 1$ and $\sqrt{x_i} = 2^{(i-2)/2} = (\sqrt{2})^{i-2}$ for $i \
geq 2$. Setting $r = \sqrt{2}$:

$$\sum_{i=1}^n \sqrt{x_i} = 1 + \sum_{j=0}^{n-2} r^j = 1 + \frac{r^{n-1}-1}{r-1}
, \qquad \sqrt{S_n} = r^{n-1}.$$

The ratio is:
$$R_n = \frac{1}{r^{n-1}} + \frac{1}{r-1}\left(1 - \frac{1}{r^{n-1}}\right) = \f
rac{1}{r-1} - \frac{2-r}{(r-1)\,r^{n-1}}.$$

Since $r = \sqrt{2} < 2$, the second term is negative and vanishes as $n\to\inft
y$, so $R_n \nearrow \frac{1}{\sqrt{2}-1} = \sqrt{2}+1$. Thus any valid $C$ must
 satisfy $C \geq \sqrt{2}+1$.

### Upper Bound: $C = \sqrt{2}+1$ suffices

**By induction on $n$.** Let $C = \sqrt{2}+1$.

*Base case* ($n=1$): $\sqrt{x_1} \leq C\sqrt{x_1}$ since $C > 1$. ✓

*Inductive step:* Assume $\sum_{i=1}^{n-1}\sqrt{x_i} \leq C\sqrt{S_{n-1}}$. Then
$$\sum_{i=1}^n \sqrt{x_i} \leq C\sqrt{S_{n-1}} + \sqrt{x_n} = C\sqrt{S_{n-1}} +
\sqrt{S_n - S_{n-1}}.$$

Set $t = S_{n-1}/S_n$. The constraint $S_n \geq 2S_{n-1}$ gives $t \leq 1/2$. Di
viding by $\sqrt{S_n}$, it suffices to show:
$$g(t) := C\sqrt{t} + \sqrt{1-t} \leq C \quad \text{for all } t \in (0,\, 1/2].$
$

**Analysis of $g$:** We have $g'(t) = \frac{C}{2\sqrt{t}} - \frac{1}{2\sqrt{1-t}
}$, and $g'(t)=0$ when $C^2(1-t)=t$, i.e., $t^* = \frac{C^2}{C^2+1}$.

With $C = \sqrt{2}+1$: $C^2 = 3+2\sqrt{2}$, so $t^* = \frac{3+2\sqrt{2}}{4+2\sqr
t{2}} = \frac{2+\sqrt{2}}{4} \approx 0.854 > \frac{1}{2}$.

Since $g'(t) \to +\infty$ as $t \to 0^+$ and the only critical point satisfies $
t^* > 1/2$, the function $g$ is **strictly increasing** on $(0,\, 1/2]$. Therefo
re:
$$g(t) \leq g(1/2) = \frac{C}{\sqrt{2}} + \frac{1}{\sqrt{2}} = \frac{C+1}{\sqrt{
2}}.$$

It remains to verify $\frac{C+1}{\sqrt{2}} \leq C$, i.e., $C+1 \leq C\sqrt{2}$,
i.e., $1 \leq C(\sqrt{2}-1)$, i.e., $C \geq \frac{1}{\sqrt{2}-1} = \sqrt{2}+1$.
This holds with **equality** for $C = \sqrt{2}+1$. ✓

This completes the induction, proving $\sum_{i=1}^n \sqrt{x_i} \leq (\sqrt{2}+1)
\sqrt{S_n}$ for all $n$ and all valid sequences.

### Conclusion

The lower bound shows $C \geq \sqrt{2}+1$ (the extremal sequence achieves ratios
 approaching $\sqrt{2}+1$), and the upper bound shows $C = \sqrt{2}+1$ suffices.
 Therefore:

$$\boxed{C = \sqrt{2}+1}$$
