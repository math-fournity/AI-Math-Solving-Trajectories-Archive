# Resolvent of the Kernel $K(x,t) = xt + x^2t^2$ on $[-1, 1]$

## Setup

The kernel is **degenerate (separable)**:
$$K(x,t) = \varphi_1(x)\psi_1(t) + \varphi_2(x)\psi_2(t), \quad \varphi_1(x)=x,\
 \psi_1(t)=t,\ \varphi_2(x)=x^2,\ \psi_2(t)=t^2.$$

The resolvent $R(x,t;\lambda)$ satisfies the Fredholm resolvent equation:
$$R(x,t;\lambda) = K(x,t) + \lambda\int_{-1}^{1} K(x,s)\,R(s,t;\lambda)\,ds.$$

Since $K$ is degenerate, $R$ is also degenerate over the same basis. We write th
e **general** form:
$$R(x,t;\lambda) = a_{11}\,xt + a_{12}\,xt^2 + a_{21}\,x^2t + a_{22}\,x^2t^2.$$

## Substitution into the resolvent equation

Compute the integral term:
$$\int_{-1}^{1}(xs + x^2s^2)\bigl(a_{11}\,st + a_{12}\,st^2 + a_{21}\,s^2t + a_{
22}\,s^2t^2\bigr)\,ds.$$

Using the symmetry of $[-1,1]$:
$$\int_{-1}^{1}s^2\,ds = \tfrac{2}{3},\quad \int_{-1}^{1}s^3\,ds = 0,\quad \int_
{-1}^{1}s^4\,ds = \tfrac{2}{5},$$

the integral becomes:
$$x\Bigl[\tfrac{2}{3}a_{11}\,t + \tfrac{2}{3}a_{12}\,t^2\Bigr] + x^2\Bigl[\tfrac
{2}{5}a_{21}\,t + \tfrac{2}{5}a_{22}\,t^2\Bigr].$$

(The cross terms vanish because $\int_{-1}^{1}s^3\,ds=0$ — this is the key simpl
ification from the symmetric interval.)

## Matching coefficients

Equating coefficients of the four independent products $xt,\,xt^2,\,x^2t,\,x^2t^
2$:

| Term | Equation |
|------|----------|
| $xt$ | $a_{11} = 1 + \tfrac{2\lambda}{3}\,a_{11}$ |
| $xt^2$ | $a_{12} = \tfrac{2\lambda}{3}\,a_{12}$ |
| $x^2t$ | $a_{21} = \tfrac{2\lambda}{5}\,a_{21}$ |
| $x^2t^2$ | $a_{22} = 1 + \tfrac{2\lambda}{5}\,a_{22}$ |

Solving (for generic $\lambda$, i.e. away from characteristic values):

$$a_{11} = \frac{1}{1-\frac{2\lambda}{3}} = \frac{3}{3-2\lambda},\qquad a_{12}=0
,\qquad a_{21}=0,\qquad a_{22} = \frac{1}{1-\frac{2\lambda}{5}} = \frac{5}{5-2\l
ambda}.$$

## Verification

Substitute back:
$$\lambda\int_{-1}^{1}K(x,s)R(s,t;\lambda)\,ds = \frac{2\lambda}{3-2\lambda}\,xt
 + \frac{2\lambda}{5-2\lambda}\,x^2t^2.$$

Then:
$$K + \lambda\int KR\,ds = xt\!\left(1+\frac{2\lambda}{3-2\lambda}\right) + x^2t
^2\!\left(1+\frac{2\lambda}{5-2\lambda}\right) = \frac{3\,xt}{3-2\lambda} + \fra
c{5\,x^2t^2}{5-2\lambda} = R.\ \checkmark$$

## Result

The resolvent kernel is:

$$\boxed{R(x,t;\lambda) = \frac{3\,xt}{3-2\lambda} + \frac{5\,x^2t^2}{5-2\lambda
}}$$

equivalently $R(x,t;\lambda) = \dfrac{xt}{1-\frac{2\lambda}{3}} + \dfrac{x^2t^2}
{1-\frac{2\lambda}{5}}$, with characteristic values $\lambda_1 = \tfrac{3}{2}$ a
nd $\lambda_2 = \tfrac{5}{2}$.
