We solve the initial-boundary value problem
$$u_t = u_{xx} - a\,u, \qquad u(0,t)=u(\pi,t)=0,\qquad u(x,0)=(\sin x)^3.$$

**Step 1. Eigenfunction expansion.**

The operator $-\partial_{xx}$ on $[0,\pi]$ with Dirichlet boundary conditions ha
s eigenfunctions $\sin(nx)$ and eigenvalues $n^2$ for $n=1,2,3,\dots$. Seeking s
eparated solutions $u(x,t)=T(t)\sin(nx)$ gives
$$T'(t)=(-n^2-a)\,T(t)\implies T(t)=e^{(-n^2-a)t}.$$
Hence the general solution is
$$u(x,t)=\sum_{n=1}^{\infty} c_n\, e^{(-n^2-a)t}\sin(nx).$$

**Step 2. Expand the initial data.**

Using the triple-angle identity $\sin(3x)=3\sin x-4\sin^3 x$, we obtain
$$(\sin x)^3 = \tfrac{3}{4}\sin x - \tfrac{1}{4}\sin(3x).$$
Thus only the modes $n=1$ and $n=3$ are present, with coefficients $c_1=\tfrac34
$ and $c_3=-\tfrac14$. The solution is exactly
$$u(x,t)=\tfrac34\,e^{(-1-a)t}\sin x - \tfrac14\,e^{(-9-a)t}\sin(3x).$$

**Step 3. Uniform convergence to zero.**

Since $|\sin(nx)|\le 1$,
$$\|u(\cdot,t)\|_{\infty}\le \tfrac34\,e^{(-1-a)t}+\tfrac14\,e^{(-9-a)t}.$$

- If $a>-1$: then $-1-a<0$ and $-9-a<-1-a<0$, so both exponentials decay to $0$.
 Hence $\|u(\cdot,t)\|_\infty\to 0$, i.e. $u\to 0$ uniformly.
- If $a=-1$: the $n=1$ term becomes $\tfrac34\sin x$ (constant in $t$), so $u(x,
t)\to \tfrac34\sin x\neq 0$; convergence to zero fails.
- If $a<-1$: then $-1-a>0$ and the $n=1$ term grows exponentially, so $u$ diverg
es; convergence to zero fails.

**Conclusion.** The solution converges to zero uniformly as $t\to\infty$ if and
only if
$$\boxed{a>-1.}$$
