# Problem

In a remote archipelago, there are 6 distinct islands. The Ministry of Transport decides to establish ferry routes between them. For every possible pair of islands, a harbor official flips a fair coin: if it lands on heads, a two-way ferry route is established between those two islands; if it lands on tails, no route is created.

A ferry network is classified as "Optimized" if it satisfies the following condition: for any island $V$ that has at least one ferry route connected to it, a captain can start a journey at $V$, traverse every single ferry route in the entire network exactly once, and finish the journey back at island $V$.

Let the probability that the resulting ferry network is "Optimized" be represented as an irreducible fraction $\frac{a}{b}$. Compute the value of $a + b$.
