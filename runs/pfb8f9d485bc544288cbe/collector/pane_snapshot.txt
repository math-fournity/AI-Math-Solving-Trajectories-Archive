## Solution

**Claim:** The number of Hahn–Banach extensions is **exactly 1** (the extension
is unique).

**Key observation:** $c_{00}$ is **dense** in $\ell^1$ with respect to $\|\cdot\
|_1$.

*Proof of density.* For any $x = (x_1, x_2, \ldots) \in \ell^1$, define the trun
cation $x^{(N)} = (x_1, \ldots, x_N, 0, 0, \ldots) \in c_{00}$. Then
$$\|x - x^{(N)}\|_1 = \sum_{n=N+1}^{\infty} |x_n| \to 0 \quad \text{as } N \to \
infty,$$
since the tail of a convergent series vanishes. Hence $c_{00}$ is dense in $\ell
^1$. $\square$

**Uniqueness of continuous extension.** Let $f : c_{00} \to \mathbb{C}$ be a con
tinuous (i.e., bounded) linear functional with norm $\|f\| = \sup_{x \in c_{00},
\, \|x\|_1 \leq 1} |f(x)| < \infty$.

For any $x \in \ell^1$, choose a sequence $(x^{(N)}) \subset c_{00}$ with $x^{(N
)} \to x$ in $\|\cdot\|_1$ (e.g., the truncations above). Define
$$F(x) := \lim_{N \to \infty} f(x^{(N)}).$$

This is **well-defined**: if $(y^{(N)})$ is another sequence in $c_{00}$ converg
ing to $x$, then
$$|f(x^{(N)}) - f(y^{(N)})| \leq \|f\| \cdot \|x^{(N)} - y^{(N)}\|_1 \leq \|f\|\
bigl(\|x^{(N)}-x\|_1 + \|x - y^{(N)}\|_1\bigr) \to 0.$$

$F$ is linear (inherited from $f$) and **bounded**:
$$|F(x)| = \lim |f(x^{(N)})| \leq \|f\| \lim \|x^{(N)}\|_1 = \|f\|\|x\|_1,$$
so $\|F\| \leq \|f\|$. Since $F|_{c_{00}} = f$, we also have $\|F\| \geq \|f\|$.
 Thus $\|F\| = \|f\|$ — the extension **preserves the norm**.

**Uniqueness.** Suppose $G : \ell^1 \to \mathbb{C}$ is any continuous linear ext
ension of $f$. For any $x \in \ell^1$ and any $(x^{(N)}) \subset c_{00}$ with $x
^{(N)} \to x$:
$$G(x) = \lim G(x^{(N)}) = \lim f(x^{(N)}) = F(x).$$
So $G = F$. The continuous extension is unique.

**Conclusion.** A Hahn–Banach extension is by definition a norm-preserving exten
sion. Since $c_{00}$ is dense in $\ell^1$, every continuous extension is unique,
 and this unique extension automatically preserves the norm. Therefore there is
**exactly one** Hahn–Banach extension.

**The number of Hahn–Banach extensions is $\boxed{1}$.**
