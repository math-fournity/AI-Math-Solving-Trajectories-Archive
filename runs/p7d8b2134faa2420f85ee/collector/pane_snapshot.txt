## 证明

设 $a = BC$，$b = CA$，$c = AB$，并设 Brocard 角 $\omega = \angle PAB = \angle P
BC = \angle PCA$。

**步骤 1：$P$ 点处的角度。**

在 $\triangle PAB$ 中：$\angle PAB = \omega$，$\angle PBA = B - \omega$，因此 $\
angle APB = \pi - B$。
在 $\triangle PBC$ 中：$\angle PBC = \omega$，$\angle PCB = C - \omega$，因此 $\
angle BPC = \pi - C$。
在 $\triangle PCA$ 中：$\angle PCA = \omega$，$\angle PAC = A - \omega$，因此 $\
angle CPA = \pi - A$。

**步骤 2：$\triangle PBC$ 的外接圆半径。**

根据正弦定理：$2R_{PBC} = \dfrac{BC}{\sin \angle BPC} = \dfrac{a}{\sin(\pi - C)}
 = \dfrac{a}{\sin C}$。

**步骤 3：计算 $BA_1$ 和 $CA_1$。**

由于 $A_1$ 位于 $\triangle PBC$ 的外接圆上，且在射线 $AP$ 上（在 $P$ 点之外），
射线 $PA_1$ 是 $PA$ 在 $P$ 点之外的延长线。因此：

$$\angle BPA_1 = \pi - \angle BPA = \pi - (\pi - B) = B, \qquad \angle CPA_1 = \
pi - \angle CPA = \pi - (\pi - A) = A.$$

根据圆内接角定理（弦长 $= 2R \cdot \sin(\text{圆内接角})$）：

$$BA_1 = 2R_{PBC} \cdot \sin B = \frac{a \sin B}{\sin C} = \frac{ab}{c}, \qquad
CA_1 = 2R_{PBC} \cdot \sin A = \frac{a \sin A}{\sin C} = \frac{a^2}{c}.$$

**步骤 4：计算 $S_{A_1BC}$。**

由于 $A_1$ 和 $P$ 都在 $\triangle PBC$ 的外接圆上，且张角均为弦 $BC$，因此 $\ang
le BA_1C$ 和 $\angle BPC$ 相等或互补，所以 $\sin \angle BA_1C = \sin \angle BPC
= \sin C$。因此：

$$S_{A_1BC} = \tfrac{1}{2} \cdot BA_1 \cdot CA_1 \cdot \sin \angle BA_1C = \tfra
c{1}{2} \cdot \frac{ab}{c} \cdot \frac{a^2}{c} \cdot \sin C = \frac{a^3 b \sin C
}{2c^2}.$$

由于 $S_{ABC} = \frac{1}{2} bc \sin A$ 且 $\frac{\sin C}{\sin A} = \frac{c}{a}$
：

$$\frac{S_{A_1BC}}{S_{ABC}} = \frac{a^3 b \sin C / (2c^2)}{bc \sin A / 2} = \fra
c{a^3 \sin C}{c^3 \sin A} = \frac{a^2}{c^2}.$$

**步骤 5：根据循环对称性：**

$$\frac{S_{B_1CA}}{S_{ABC}} = \frac{b^2}{a^2}, \qquad \frac{S_{C_1AB}}{S_{ABC}}
= \frac{c^2}{b^2}.$$

**步骤 6：应用 AM-GM 不等式。**

$$\frac{S_{A_1BC} + S_{B_1CA} + S_{C_1AB}}{S_{ABC}} = \frac{a^2}{c^2} + \frac{b^
2}{a^2} + \frac{c^2}{b^2} \geq 3 \left(\frac{a^2}{c^2} \cdot \frac{b^2}{a^2} \cd
ot \frac{c^2}{b^2}\right)^{1/3} = 3.$$

当且仅当 $\frac{a^2}{c^2} = \frac{b^2}{a^2} = \frac{c^2}{b^2}$ 时等号成立，这推
导出 $a = b = c$（等边三角形）。等边三角形是锐角三角形，其 Brocard 点即为中心，
因此等号成立。

因此，最大的 $\lambda$ 值为 $\boxed{3}$。
