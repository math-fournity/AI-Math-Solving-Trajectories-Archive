### Method of characteristics

The PDE is
$$x\,u_x + y\,u_y + u\,u_z = 0, \qquad u(x,y,0)=xy,\; x>0,\;y>0.$$

The characteristic system is
$$\frac{dx}{x}=\frac{dy}{y}=\frac{dz}{u}=\frac{du}{0}.$$

**First integrals.**

1. From $\dfrac{du}{0}$: $u$ is constant along each characteristic, so
$$u = c_1.$$

2. From $\dfrac{dx}{x}=\dfrac{dy}{y}$: $\ln x-\ln y=\text{const}$, hence
$$\frac{y}{x}=c_2.$$

3. From $\dfrac{dx}{x}=\dfrac{dz}{u}$ with $u=c_1$ constant: $dz=\dfrac{c_1}{x}\
,dx$, giving $z=c_1\ln x+c_3$, i.e.
$$z-u\ln x = c_3.$$

The general integral is therefore
$$z - u\ln x = F\!\left(u,\;\frac{y}{x}\right) \tag{1}$$
for an arbitrary function $F$.

### Imposing the initial condition

On the initial surface $z=0$ we have $u=xy$. Substituting into (1):
$$0 - (xy)\ln x = F\!\left(xy,\;\frac{y}{x}\right). \tag{2}$$

Introduce parameters $s=xy$ and $t=\dfrac{y}{x}$, so that $x=\sqrt{s/t}$ and $\l
n x=\tfrac12(\ln s-\ln t)$. Then (2) gives
$$F(s,t)=-s\cdot\tfrac12(\ln s-\ln t)=-\tfrac{s}{2}\ln s+\tfrac{s}{2}\ln t.$$

Hence
$$F\!\left(u,\frac{y}{x}\right)=-\tfrac{u}{2}\ln u+\tfrac{u}{2}\ln\frac{y}{x}=\t
frac{u}{2}\ln\frac{y}{xu}.$$

Substituting back into (1):
$$z = u\ln x + \tfrac{u}{2}\ln\frac{y}{xu}=\tfrac{u}{2}\ln x+\tfrac{u}{2}\ln y-\
tfrac{u}{2}\ln u.$$

Therefore the solution is given implicitly by
$$\boxed{\,z=\dfrac{u}{2}\ln\dfrac{xy}{u}\,}. \tag{3}$$

### Verification

**Initial condition.** Setting $z=0$ in (3) forces $\ln\frac{xy}{u}=0$, i.e. $u=
xy$. ✓

**PDE.** Define $G(x,y,z,u)=z-\dfrac{u}{2}\ln\dfrac{xy}{u}$. From (3), $\ln\frac
{xy}{u}=\frac{2z}{u}$. Differentiating $G=0$ implicitly:
$$G_x=-\frac{u}{2x},\quad G_y=-\frac{u}{2y},\quad G_z=1,\quad G_u=-\tfrac12\ln\f
rac{xy}{u}+\tfrac12=-\frac{z}{u}+\frac12=\frac{u-2z}{2u}.$$

Thus
$$u_x=-\frac{G_x}{G_u}=\frac{u^2}{x(u-2z)},\qquad u_y=\frac{u^2}{y(u-2z)},\qquad
 u_z=-\frac{G_z}{G_u}=\frac{2u}{2z-u}.$$

Substituting into the PDE:
$$xu_x+yu_y+u\,u_z=\frac{u^2}{u-2z}+\frac{u^2}{u-2z}+u\cdot\frac{2u}{2z-u}=\frac
{2u^2}{u-2z}-\frac{2u^2}{u-2z}=0.\;\checkmark$$

Both the boundary condition and the differential equation are satisfied. The sol
ution is
$$z=\frac{u}{2}\ln\frac{xy}{u},\qquad x>0,\;y>0,$$
equivalently $u$ is determined implicitly by $xy = u\,e^{\,2z/u}$.
