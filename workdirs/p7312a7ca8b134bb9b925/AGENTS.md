# Problem

A digital security architect is designing a series of encryption keys for a high-security vault. The architect must generate a list of valid identification codes based on a specific set of parameters determined by a security level, defined by a positive integer $k$.

To be valid, a code $n$ must meet the following cryptographic requirements:
1. The code must be a non-negative integer that does not exceed a maximum value of $10^k$.
2. The code must be a multiple of 3 to pass the system's checksum verification.
3. When viewed in the system's decimal display, the code can only consist of the digits 0, 1, 2, or 7. Any code containing other digits is automatically rejected by the hardware.

Determine the total number of unique identification codes $n$ that satisfy these security constraints for a given level $k$.
