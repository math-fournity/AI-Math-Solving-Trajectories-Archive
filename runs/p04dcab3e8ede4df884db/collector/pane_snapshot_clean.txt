## 证明

设 $K = \mathbb{Q}(\beta)$，其中 $\beta$ 为 $f(X) = X^3 + X + 1$ 的根。我们将计
算域判别式 $\Delta_K$。

### 第 1 步：$\mathbb{Q}(\beta^2) = \mathbb{Q}(\beta)$

由 $f(\beta) = 0$，我们得到 $\beta^3 + \beta + 1 = 0$，因此 $\beta^3 = -\beta -
1$。乘以 $\beta$：

$$\beta^4 = -\beta^2 - \beta.$$

现在 $\beta\cdot\beta^2 = \beta^3 = -\beta - 1$，因此 $\beta(\beta^2 + 1) = -1$
，得出

$$\beta = -\frac{1}{\beta^2 + 1} \in \mathbb{Q}(\beta^2).$$

因此 $\mathbb{Q}(\beta) \subseteq \mathbb{Q}(\beta^2)$。由于显然有 $\mathbb{Q}(\
beta^2) \subseteq \mathbb{Q}(\beta)$，我们得到 $\mathbb{Q}(\beta^2) = \mathbb{Q}
(\beta) = K$。所以 $\beta^2$ 也是 $K$ 的本原元素，且 $g(X) = X^3 + 2X^2 + X - 1$
 是其极小多项式（$g$ 在 $\mathbb{Q}$ 上不可约，因为它在 $\mathbb{Q}$ 中没有有理
根：$g(0)=-1$, $g(1)=3$, $g(-1)=-1$，且由有理根定理，可能的有理根为 $\pm1$，两者
都不成立）。

### 第 2 步：计算 $\operatorname{disc}(f)$ 和 $\operatorname{disc}(g)$

对于约化三次多项式 $X^3 + pX + q$，判别式为 $-4p^3 - 27q^2$。对于 $f(X) = X^3 +
X + 1$，$p = 1$，$q = 1$：

$$\operatorname{disc}(f) = -4(1)^3 - 27(1)^2 = -4 - 27 = -31.$$

对于一般三次多项式 $X^3 + aX^2 + bX + c$，判别式为 $a^2b^2 - 4b^3 - 4a^3c - 27c^
2 + 18abc$。对于 $g(X) = X^3 + 2X^2 + X - 1$，$a=2$, $b=1$, $c=-1$：

$$\operatorname{disc}(g) = (2)^2(1)^2 - 4(1)^3 - 4(2)^3(-1) - 27(-1)^2 + 18(2)(1
)(-1)$$
$$= 4 - 4 + 32 - 27 - 36 = -31.$$

### 第 3 步：利用 $\beta^2$ 的信息连接两个幂基

幂基 $\{1, \beta, \beta^2\}$ 的判别式为 $\operatorname{disc}(f) = -31$。幂基 $\{
1, \beta^2, \beta^4\}$ 的判别式为 $\operatorname{disc}(g) = -31$。

从基 $\{1, \beta, \beta^2\}$ 到 $\{1, \beta^2, \beta^4\}$ 的变换矩阵如下。使用 $
\beta^4 = -\beta - \beta^2$：

$$1 = 1,\qquad \beta^2 = \beta^2,\qquad \beta^4 = -\beta - \beta^2.$$

将 $\{1, \beta^2, \beta^4\}$ 表示为 $\{1, \beta, \beta^2\}$ 坐标的列向量为：

$$\begin{pmatrix} 1 & 0 & 0 \\ 0 & 0 & -1 \\ 0 & 1 & -1 \end{pmatrix}, \qquad \d
et = 1\cdot(0\cdot(-1) - (-1)\cdot 1) = 1.$$

因此，基变换的行列式为 $\pm 1$，且两个基的判别式相差 $\det^2 = 1$ —— 这与 $\oper
atorname{disc}(f) = \operatorname{disc}(g) = -31$ 相符。这证实了这两个独立的计算
是一致的，并验证了 $g$ 确实是 $\beta^2$ 的极小多项式。

### 第 4 步：从多项式判别式到域判别式

设 $\mathcal{O}_K$ 为 $K$ 的整数环。幂基 $\mathbb{Z}[\beta]$ 的判别式与域判别式
的关系为

$$\operatorname{disc}(f) = [\mathcal{O}_K : \mathbb{Z}[\beta]]^2 \cdot \Delta_K.
$$

因此 $[\mathcal{O}_K : \mathbb{Z}[\beta]]^2$ 整除 $\operatorname{disc}(f) = -31$
。由于 $31$ 是素数，$-31$ 是无平方因子的，所以 $[\mathcal{O}_K : \mathbb{Z}[\bet
a]]^2 = 1$，即 $[\mathcal{O}_K : \mathbb{Z}[\beta]] = 1$。

因此 $\mathcal{O}_K = \mathbb{Z}[\beta]$，且

$$\Delta_K = \operatorname{disc}(f) = -31.$$

（同样地，使用 $g$：$[\mathcal{O}_K : \mathbb{Z}[\beta^2]]^2$ 整除 $\operatornam
e{disc}(g) = -31$，由于 $-31$ 是无平方因子的，得出 $[\mathcal{O}_K : \mathbb{Z}[
\beta^2]] = 1$，因此 $\mathcal{O}_K = \mathbb{Z}[\beta^2]$ 且 $\Delta_K = \opera
torname{disc}(g) = -31$。两个本原元素通过 $g$ 给出的信息得出相同的域判别式，证实
了结果。）

### 结论

数域 $\mathbb{Q}(\beta)$ 的判别式为

$$\boxed{-31}.$$
