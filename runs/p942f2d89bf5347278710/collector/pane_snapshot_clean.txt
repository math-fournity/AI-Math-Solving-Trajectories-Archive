## Proof

We work on $C[0,1]$ equipped with the supremum norm $\|x\|_\infty = \sup_{t\in[0
,1]}|x(t)|$. The operator is
$$Sx(t) = t^2\int_0^t x(s)\,ds.$$

**Upper bound.** For any $x\in C[0,1]$ with $\|x\|_\infty\le 1$ and any $t\in[0,
1]$,
$$|Sx(t)| = \left|t^2\int_0^t x(s)\,ds\right| \le t^2\int_0^t |x(s)|\,ds \le t^2
\int_0^t 1\,ds = t^2\cdot t = t^3 \le 1.$$
Taking the supremum over $t$ gives $\|Sx\|_\infty\le 1$, hence
$$\|S\| = \sup_{\|x\|_\infty\le 1}\|Sx\|_\infty \le 1.$$

**Lower bound (attainment).** Take the constant function $x_0\equiv 1$, which sa
tisfies $\|x_0\|_\infty=1$. Then
$$Sx_0(t) = t^2\int_0^t 1\,ds = t^3,$$
so $\|Sx_0\|_\infty = \sup_{t\in[0,1]}t^3 = 1$ (attained at $t=1$).

Therefore $\|S\|\ge 1$.

Combining both bounds,
$$\boxed{\|S\| = 1}.$$
