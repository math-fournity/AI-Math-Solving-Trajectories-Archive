## Proof

**Definitions and setup.** Let $\chi$ be a Dirichlet character modulo $N$. Recal
l that $\chi$ is *defined modulo* $m$ (where $m \mid N$) if $\chi(a)=1$ whenever
 $\gcd(a,N)=1$ and $a\equiv 1\pmod{m}$. The *conductor* $c(\chi)$ is the smalles
t positive integer $c$ such that $\chi$ is defined modulo $c$.

We are given that $\chi$ is defined modulo $N'$ with $N'\mid N$, and must show $
c(\chi)\mid N'$.

**Key equivalence.** $\chi$ is defined modulo $m$ if and only if $\chi(a)=\chi(b
)$ whenever $\gcd(a,N)=\gcd(b,N)=1$ and $a\equiv b\pmod{m}$.

*Proof of equivalence.* $(\Leftarrow)$: Take $b=1$. $(\Rightarrow)$: If $a\equiv
 b\pmod{m}$ with both coprime to $N$, then since $m\mid N$ we have $\gcd(b,m)=1$
, so $b$ has an inverse $b^{-1}$ modulo $N$ (hence modulo $m$) with $\gcd(b^{-1}
,N)=1$. Then $ab^{-1}\equiv 1\pmod{m}$ and $\gcd(ab^{-1},N)=1$, so $\chi(ab^{-1}
)=1$. By complete multiplicativity and $N$-periodicity, $\chi(a)\chi(b)^{-1}=1$,
 giving $\chi(a)=\chi(b)$. $\square$

**Lemma.** If $\chi$ is defined modulo $m_1$ and modulo $m_2$ (with $m_1,m_2\mid
 N$), then $\chi$ is defined modulo $g=\gcd(m_1,m_2)$.

*Proof of Lemma.* Suppose $\gcd(a,N)=1$ and $a\equiv 1\pmod{g}$. We must show $\
chi(a)=1$.

By the Chinese Remainder Theorem, the system
$$x\equiv a\pmod{m_1},\qquad x\equiv 1\pmod{m_2}$$
is consistent (since $a\equiv 1\pmod{g}$ and $g=\gcd(m_1,m_2)$), yielding a solu
tion $b\pmod{\operatorname{lcm}(m_1,m_2)}$. Note $\gcd(b,m_1)=\gcd(a,m_1)=1$ and
 $\gcd(b,m_2)=1$.

We need a prime $p$ satisfying this congruence and also $\gcd(p,N)=1$. Set $L=\o
peratorname{lcm}(m_1,m_2)$. For each prime $q\mid N$ with $q\nmid L$, the congru
ence $x\equiv b\pmod{L}$ imposes no condition modulo $q$, so we may additionally
 require $x\not\equiv 0\pmod{q}$. Let
$$M = L\cdot\prod_{\substack{q\mid N\\ q\nmid L}} q.$$
By CRT there exists $r\pmod{M}$ with $r\equiv b\pmod{L}$ and $r\not\equiv 0\pmod
{q}$ for each such prime $q$. Then $\gcd(r,M)=1$, so by **Dirichlet's theorem on
 primes in arithmetic progressions**, there exists a prime $p\equiv r\pmod{M}$.
This prime satisfies:
- $p\equiv a\pmod{m_1}$,
- $p\equiv 1\pmod{m_2}$,
- $\gcd(p,N)=1$.

Now apply the key equivalence:
- Since $\chi$ is defined modulo $m_1$ and $p\equiv a\pmod{m_1}$ with $\gcd(p,N)
=\gcd(a,N)=1$: $\chi(p)=\chi(a)$.
- Since $\chi$ is defined modulo $m_2$ and $p\equiv 1\pmod{m_2}$ with $\gcd(p,N)
=1$: $\chi(p)=\chi(1)=1$.

Therefore $\chi(a)=\chi(p)=1$, proving the Lemma. $\square$

**Conclusion.** By definition of conductor, $\chi$ is defined modulo $c(\chi)$.
By hypothesis, $\chi$ is defined modulo $N'$. Applying the Lemma with $m_1=c(\ch
i)$ and $m_2=N'$, $\chi$ is defined modulo $\gcd(c(\chi),N')$. Since $c(\chi)$ i
s the *smallest* positive integer modulo which $\chi$ is defined, we have
$$c(\chi)\leq \gcd(c(\chi),N')\leq c(\chi),$$
so $\gcd(c(\chi),N')=c(\chi)$, which means $c(\chi)\mid N'$. $\blacksquare$
