# Problem

A digital security architect is designing a "signal grid" for a new encryption protocol. The grid consists of various nodes, where each node is identified by a pair of coordinates $(x, y)$. Each coordinate must be an integer such that the horizontal index $x$ satisfies $1 \le x \le n$ and the vertical index $y$ satisfies $0 \le y \le n$.

The architect needs to select a subset of these nodes, called an "interference-free set" $S$, to transmit data. To prevent signal crosstalk, the set $S$ must satisfy a strict isolation rule: for any two distinct nodes $(a, b)$ and $(c, d)$ selected for the set $S$, the squared distance of the first node from the origin, $a^2 + b^2$, must not be a common divisor of the two specific interference values $ac + bd$ and $ad - bc$.

Based on the integer limit $n$, what is the maximum number of nodes that can be included in this interference-free set $S$?
