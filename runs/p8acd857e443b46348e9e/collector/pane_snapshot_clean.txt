## Proof

Let $M = \max_{1 \le i \le n} |x_i - a_i|$. We must show $M \ge d/2$.

Choose an index $i^*$ with $d_{i^*} = d$. Set
$$A = \max\{a_j : 1 \le j \le i^*\}, \qquad B = \min\{a_j : i^* \le j \le n\},$$
so $d = A - B$.

Pick $p \le i^*$ with $a_p = A$ and $q \ge i^*$ with $a_q = B$. Then $p \le i^*
\le q$, hence $p \le q$.

Since the sequence $(x_i)$ is non-decreasing and $p \le q$, we have
$$x_p \le x_q. \tag{1}$$

From $|x_p - a_p| \le M$ and $a_p = A$:
$$x_p \ge a_p - M = A - M. \tag{2}$$

From $|x_q - a_q| \le M$ and $a_q = B$:
$$x_q \le a_q + M = B + M. \tag{3}$$

Combining (1), (2), (3):
$$A - M \;\le\; x_p \;\le\; x_q \;\le\; B + M,$$
so $A - M \le B + M$, i.e. $A - B \le 2M$.

Since $A - B = d$, we obtain $d \le 2M$, that is,
$$\max_{1 \le i \le n} |x_i - a_i| = M \ge \frac{d}{2}. \qquad \blacksquare$$
