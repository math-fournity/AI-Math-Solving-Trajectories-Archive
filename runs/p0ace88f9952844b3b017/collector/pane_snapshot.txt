## Proof

We work in the normed linear space $G = C[-1,1]$ with the supremum norm $\|f\|_\
infty = \max_{x\in[-1,1]}|f(x)|$. The linear functional is

$$I(f) = \int_{-1}^{1} f(x)\,dx,$$

with kernel $K = \{g \in C[-1,1] : I(g) = 0\}$. We seek $d(x^2, K) = \inf_{g\in
K}\|x^2 - g\|_\infty$.

### Step 1. A general distance formula

**Claim.** For any bounded nonzero linear functional $I$ on a normed space $X$,
with $K = \ker I$,

$$d(f, K) = \frac{|I(f)|}{\|I\|}.$$

**Lower bound.** For every $g \in K$, $I(g)=0$, so $I(f-g) = I(f)$. Hence

$$|I(f)| = |I(f-g)| \le \|I\|\,\|f-g\|,$$

giving $\|f-g\| \ge |I(f)|/\|I\|$ for all $g\in K$, i.e. $d(f,K)\ge |I(f)|/\|I\|
$.

**Upper bound.** By definition of $\|I\| = \sup_{\|h\|=1}|I(h)|$, for every $\va
repsilon>0$ there exists $h_\varepsilon$ with $\|h_\varepsilon\|=1$ and $|I(h_\v
arepsilon)|>\|I\|-\varepsilon$. Assume $I(f)\ge 0$ and (replacing $h_\varepsilon
$ by $-h_\varepsilon$ if needed) $I(h_\varepsilon)>0$. Set

$$g_\varepsilon = f - \frac{I(f)}{I(h_\varepsilon)}\,h_\varepsilon.$$

Then $I(g_\varepsilon) = I(f) - \frac{I(f)}{I(h_\varepsilon)}I(h_\varepsilon) =
0$, so $g_\varepsilon \in K$, and

$$\|f - g_\varepsilon\| = \frac{I(f)}{I(h_\varepsilon)}\|h_\varepsilon\| = \frac
{I(f)}{I(h_\varepsilon)} < \frac{I(f)}{\|I\|-\varepsilon}.$$

Letting $\varepsilon\to 0$: $d(f,K)\le I(f)/\|I\| = |I(f)|/\|I\|$. Combining bot
h bounds proves the claim. $\square$

### Step 2. Compute $I(x^2)$

$$I(x^2) = \int_{-1}^{1} x^2\,dx = \left[\frac{x^3}{3}\right]_{-1}^{1} = \frac{1
}{3} - \left(-\frac{1}{3}\right) = \frac{2}{3}.$$

### Step 3. Compute $\|I\|$

For any $f\in C[-1,1]$:

$$|I(f)| = \left|\int_{-1}^{1}f(x)\,dx\right| \le \int_{-1}^{1}|f(x)|\,dx \le \i
nt_{-1}^{1}\|f\|_\infty\,dx = 2\|f\|_\infty,$$

so $\|I\|\le 2$.

To show equality, define for each $n\ge 1$ a continuous "plateau" function

$$f_n(x) = \begin{cases} 1, & |x|\le 1-\tfrac{1}{n},\\ n(1-|x|), & 1-\tfrac{1}{n
} < |x| \le 1.\end{cases}$$

Then $\|f_n\|_\infty = 1$ and $I(f_n) = 2 - \frac{1}{n} \to 2$, so $\|I\| = 2$.

### Step 4. Apply the formula

$$d(x^2, K) = \frac{|I(x^2)|}{\|I\|} = \frac{2/3}{2} = \frac{1}{3}.$$

### Step 5. The infimum is attained

The function $g(x) = x^2 - \tfrac{1}{3}$ is continuous, and

$$I(g) = I(x^2) - \tfrac{1}{3}\,I(1) = \frac{2}{3} - \frac{1}{3}\cdot 2 = \frac{
2}{3}-\frac{2}{3} = 0,$$

so $g \in K$. Moreover

$$\|x^2 - g\|_\infty = \left\|x^2 - \left(x^2 - \tfrac{1}{3}\right)\right\|_\inf
ty = \left\|\tfrac{1}{3}\right\|_\infty = \frac{1}{3}.$$

Hence the infimum is achieved and

$$\boxed{d(x^2,\, K) = \inf_{g\in K}\|x^2 - g(x)\|_\infty = \frac{1}{3}}.$$
