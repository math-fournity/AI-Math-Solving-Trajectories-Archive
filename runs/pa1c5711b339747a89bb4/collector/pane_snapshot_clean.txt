## Proof

We seek all $3\times 3$ integer matrices $A$ with $AA'=I$.

**Step 1: Each column has unit norm.**

Let $c_1, c_2, c_3$ be the columns of $A$. The condition $AA' = I$ means the col
umns are orthonormal. In particular, for each column $c_j = (a_{1j}, a_{2j}, a_{
3j})^T$ with integer entries,

$$\|c_j\|^2 = a_{1j}^2 + a_{2j}^2 + a_{3j}^2 = 1.$$

Since each $a_{ij}\in\mathbb{Z}$, each $a_{ij}^2\geq 0$ is a nonneg­ative intege
r. The only way three nonneg­ative integer squares sum to $1$ is that exactly on
e of them equals $1$ and the other two equal $0$. Hence each column is a **signe
d standard basis vector**: $c_j = \pm e_k$ for some $k\in\{1,2,3\}$.

**Step 2: Columns are mutually orthogonal.**

Orthonormality also gives $c_i\cdot c_j = 0$ for $i\neq j$. Two signed standard
basis vectors $\pm e_k$ and $\pm e_\ell$ are orthogonal iff $k\neq \ell$. Theref
ore the three columns must correspond to **three distinct** basis directions. So
 $A$ is a **signed permutation matrix**: each row and each column has exactly on
e nonzero entry, which is $\pm 1$.

**Step 3: Count.**

A signed permutation matrix is determined by:
- A permutation $\sigma\in S_3$ selecting which basis vector goes in each column
: $3! = 6$ choices.
- A sign $\varepsilon_j\in\{+1,-1\}$ for each of the 3 columns: $2^3 = 8$ choice
s.

These choices are independent, giving

$$|S| = 6 \times 8 = 48.$$

**Step 4: Verification that all 48 work.**

Every signed permutation matrix $A$ satisfies $A' = A^{-1}$ (its transpose is it
s inverse, since permuting and re-signing standard basis vectors is inverted by
the reverse operation), so $AA' = I$. All entries are integers. Hence all 48 mat
rices belong to $S$, and by Steps 1–2 no others do.

$$\boxed{|S| = 48}$$
