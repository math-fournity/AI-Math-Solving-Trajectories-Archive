Looking at this problem, I need to determine the probability that two random mat
rices generate the full matrix algebra.

## Solution

**Answer: The probability is $\boxed{1}$.**

### Step 1: The generating condition is Zariski-open

For $(A, B) \in M_n(\mathbb{R})^2$, let $\mathcal{A}(A,B)$ denote the unital $\m
athbb{R}$-algebra generated by $A$ and $B$ — the linear span of all words $w(A,B
)$ in $A$ and $B$ (including the empty word $I$). Since $\mathcal{A}(A,B) \subse
teq M_n(\mathbb{R})$, we have $\dim \mathcal{A}(A,B) \leq n^2$, with equality if
 and only if $\mathcal{A}(A,B) = M_n(\mathbb{R})$.

For any ordered $n^2$-tuple of words $(w_1, \ldots, w_{n^2})$, form the $n^2 \ti
mes n^2$ matrix $M_w(A,B)$ whose $j$-th column is $\operatorname{vec}(w_j(A,B))$
. Then $\det M_w(A,B)$ is a polynomial in the $2n^2$ entries of $A$ and $B$. The
 set
$$U_w = \{(A,B) : \det M_w(A,B) \neq 0\}$$
is Zariski-open, and on $U_w$ the words are linearly independent, so $\mathcal{A
}(A,B) = M_n(\mathbb{R})$. Therefore
$$S = \{(A,B) : \mathcal{A}(A,B) = M_n(\mathbb{R})\} = \bigcup_w U_w$$
is a union of Zariski-open sets, hence **Zariski-open**.

### Step 2: $S$ is non-empty — explicit construction

**Case $n = 1$:** $M_1(\mathbb{R}) = \mathbb{R}$, and the unital algebra generat
ed by any element is $\mathbb{R}$ (since $1 \in \mathcal{A}$). So $S = \mathbb{R
}^2$.

**Case $n \geq 2$:** Let $A = \operatorname{diag}(1, 2, \ldots, n)$ and let $B$
be the cyclic permutation matrix ($Be_i = e_{i+1}$ for $i < n$, $Be_n = e_1$).

**Diagonal matrices are in $\mathcal{A}$:** Since $A$ has $n$ distinct eigenvalu
es, $\{I, A, \ldots, A^{n-1}\}$ are linearly independent (Vandermonde argument),
 so the algebra generated by $A$ is the $n$-dimensional space of all diagonal ma
trices.

**Isolating matrix units:** For any invertible diagonal $D = \operatorname{diag}
(d_1, \ldots, d_n) \in \mathcal{A}$, the conjugation $DBD^{-1} \in \mathcal{A}$
satisfies:
$$DBD^{-1} = \sum_{i=1}^{n-1} \frac{d_i}{d_{i+1}} E_{i,i+1} + \frac{d_n}{d_1} E_
{n,1}.$$

The coefficient vector $c = (c_1, \ldots, c_n)$ with $c_i = d_i/d_{i+1}$ for $i
< n$ and $c_n = d_n/d_1$ ranges over the hypersurface $\{c \in (\mathbb{R}\setmi
nus\{0\})^n : c_1 c_2 \cdots c_n = 1\}$.

**This hypersurface is not contained in any hyperplane.** Indeed, if $a_1 c_1 +
\cdots + a_n c_n = b$ held identically on the hypersurface, setting $c_1 = t, c_
2 = 1/t, c_3 = \cdots = c_n = 1$ gives $a_1 t + a_2/t + (a_3 + \cdots + a_n) = b
$ for all $t \neq 0$, forcing $a_1 = a_2 = 0$. Repeating for each pair $(a_i, a_
j)$ yields $a_1 = \cdots = a_n = 0$, $b = 0$.

Since the hypersurface's linear span is all of $\mathbb{R}^n$, we can find $n$ l
inearly independent matrices $D_k B D_k^{-1}$ in $\mathcal{A}$, each a linear co
mbination of $E_{1,2}, \ldots, E_{n-1,n}, E_{n,1}$. Taking linear combinations i
solates each matrix unit $E_{i,i+1}$ ($i = 1, \ldots, n-1$) and $E_{n,1}$.

**All matrix units are in $\mathcal{A}$:**
- $E_{i,j}$ for $i < j$: $E_{i,j} = E_{i,i+1} E_{i+1,i+2} \cdots E_{j-1,j}$.
- $E_{i,j}$ for $i > j$: wrap around the cycle: $E_{i,j} = E_{i,i+1} \cdots E_{n
-1,n} \cdot E_{n,1} \cdot E_{1,2} \cdots E_{j-1,j}$.
- $E_{i,i}$: already in $\mathcal{A}$ (all diagonal matrices).

Since all matrix units $E_{ij} \in \mathcal{A}(A,B)$, we conclude $\mathcal{A}(A
,B) = M_n(\mathbb{R})$. Thus $S \neq \emptyset$.

### Step 3: Full measure conclusion

Since $S$ is a **non-empty Zariski-open** subset of $\mathbb{R}^{2n^2}$, its com
plement $S^c$ is a **proper Zariski-closed** set — the zero set of some non-zero
 polynomial. Any such set has **Lebesgue measure zero** (a non-zero polynomial c
annot vanish on a set of positive measure).

Therefore, for any probability distribution on $M_n(\mathbb{R})^2$ absolutely co
ntinuous with respect to Lebesgue measure (e.g., i.i.d. Gaussian entries — the s
tandard model for "random matrices"), the probability that $\mathcal{A}(A,B) = M
_n(\mathbb{R})$ is:

$$\boxed{1}$$
