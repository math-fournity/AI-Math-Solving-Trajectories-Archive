### Step 1: Determine p and q

The condition "$|f(x)| > \tfrac12$ has no solutions on $[4,6]$" means $|f(x)| \l
e \tfrac12$ for all $x \in [4,6]$, i.e. $f([4,6]) \subseteq [-\tfrac12, \tfrac12
]$.

Since $f(x)=x^2+px+q$ is a convex parabola, its maximum on $[4,6]$ is at an endp
oint and its minimum is at the vertex $x=-p/2$ (if it lies in $[4,6]$) or at an
endpoint.

**Center the interval.** Let $t = x-5$, so $x\in[4,6]\Leftrightarrow t\in[-1,1]$
. Then
$$f(x) = t^2 + (10+p)t + (25+5p+q).$$

**Claim: $p=-10$, $q=\tfrac{49}{2}$ is the unique solution.**

*Vertex in $[4,6]$ (i.e. $p\in[-12,-8]$):* minimum $= q - p^2/4 \ge -\tfrac12$,
so $q \ge \tfrac{p^2}{4}-\tfrac12$.

- If $p\ge -10$: $\max = f(6) = q+36+6p \le \tfrac12 \Rightarrow q \le -\tfrac{7
1}{2}-6p$. Combining: $\tfrac{p^2}{4}-\tfrac12 \le -\tfrac{71}{2}-6p \Rightarrow
 p^2+24p+140\le 0 \Rightarrow (p+10)(p+14)\le 0 \Rightarrow p\in[-14,-10]$. Inte
rsecting $p\ge -10$ gives $p=-10$.
- If $p\le -10$: $\max = f(4) = q+16+4p \le \tfrac12 \Rightarrow q \le -\tfrac{3
1}{2}-4p$. Combining: $\tfrac{p^2}{4}-\tfrac12 \le -\tfrac{31}{2}-4p \Rightarrow
 p^2+16p+60\le 0 \Rightarrow (p+6)(p+10)\le 0 \Rightarrow p\in[-10,-6]$. Interse
cting $p\le -10$ gives $p=-10$.

Both cases force $p=-10$. Then $f(x)=(x-5)^2 + (q-25)$; on $[4,6]$ the range is
$[q-25,\, q-24]$. Requiring this inside $[-\tfrac12,\tfrac12]$ gives $q-25\ge -\
tfrac12$ and $q-24\le \tfrac12$, both yielding $q=\tfrac{49}{2}$.

*Vertex outside $[4,6]$:*
- $p>-8$ (vertex $<4$, increasing on $[4,6]$): need $f(6)\le\tfrac12$ and $f(4)\
ge -\tfrac12$, giving $-16.5-4p \le -35.5-6p \Rightarrow p\le -9.5$, contradicti
ng $p>-8$.
- $p<-12$ (vertex $>6$, decreasing on $[4,6]$): need $f(4)\le\tfrac12$ and $f(6)
\ge -\tfrac12$, giving $-36.5-6p \le -15.5-4p \Rightarrow p\ge -10.5$, contradic
ting $p<-12$.

**Therefore uniquely** $p=-10,\ q=\tfrac{49}{2}$, i.e.
$$f(x) = x^2 - 10x + \tfrac{49}{2} = (x-5)^2 - \tfrac12.$$

### Step 2: Behavior of the starting value

Let $y_0 = \dfrac{9-\sqrt{19}}{2}$. From $2y_0 = 9-\sqrt{19}$ we get $\sqrt{19}=
9-2y_0$, so $19 = (9-2y_0)^2 = 81-36y_0+4y_0^2$, hence
$$y_0^2 = 9y_0 - \tfrac{31}{2}.$$

Apply $f$:
$$f(y_0) = y_0^2 - 10y_0 + \tfrac{49}{2} = \bigl(9y_0-\tfrac{31}{2}\bigr) - 10y_
0 + \tfrac{49}{2} = -y_0 + 9.$$

So $f(y_0) = 9 - y_0 = \dfrac{9+\sqrt{19}}{2} =: y_1$.

Now apply $f$ to $y_1 = 9 - y_0$. By the same algebra, $y_1^2 = 9y_1 - \tfrac{31
}{2}$ (since $y_1$ is the other root of $t^2-9t+\tfrac{31}{2}=0$), so
$$f(y_1) = y_1^2 - 10y_1 + \tfrac{49}{2} = -y_1 + 9 = 9 - (9-y_0) = y_0.$$

Thus $f$ **swaps** $y_0$ and $y_1 = 9-y_0$: the orbit has period 2.

### Step 3: Compute the 2017-fold iterate

Since $f(y_0)=y_1$ and $f(y_1)=y_0$, we have $f^{(n)}(y_0) = y_1$ for odd $n$ an
d $y_0$ for even $n$. Since $2017$ is odd,
$$\underbrace{f(f(\cdots f}_{2017}(y_0)\cdots)) = y_1 = \frac{9+\sqrt{19}}{2}.$$

Numerically, $\sqrt{19}\approx 4.3589$, so
$$\frac{9+\sqrt{19}}{2} \approx \frac{13.3589}{2} \approx 6.6794 \approx \boxed{
6.68}.$$
