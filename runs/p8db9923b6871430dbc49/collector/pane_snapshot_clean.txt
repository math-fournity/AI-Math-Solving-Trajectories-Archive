# 证明

设 $a, b, c$ 为三角形的三边，$R$ 为外接圆半径，$r$ 为内切圆半径。使用标准代换：
令 $x = s - a$, $y = s - b$, $z = s - c$，其中 $s = (a+b+c)/2$。则 $x, y, z > 0$
 且：

- $a = y+z$, $b = x+z$, $c = x+y$, $s = x+y+z$
- $\Delta^2 = s \cdot xyz$ (海伦公式)
- $R = \frac{(x+y)(y+z)(z+x)}{4\sqrt{s \cdot xyz}}$, $\ r = \sqrt{\frac{xyz}{s}}
$

因此 $\frac{R}{2r} = \frac{(x+y)(y+z)(z+x)}{8xyz}$。

令 $p = x+y+z$, $q = xy+yz+zx$, $\rho = xyz$。则：

- $(x+y)(y+z)(z+x) = pq - \rho$
- $(a-b)^2 + (b-c)^2 + (c-a)^2 = (x-y)^2 + (y-z)^2 + (z-x)^2 = 2p^2 - 6q$
- $(a+b+c)^2 = 4p^2$

该不等式变为：

$$\frac{pq - \rho}{8\rho} \geq 1 + \frac{k(2p^2 - 6q)}{4p^2}$$

化简为：

$$\frac{pq - 9\rho}{8\rho} \geq \frac{k(p^2 - 3q)}{2p^2}$$

对于非等边三角形，$p^2 - 3q > 0$，因此：

$$k \leq \frac{p^2(pq - 9\rho)}{4\rho(p^2 - 3q)}$$

最大的 $k$ 是该式在所有非等边三角形中的下确界。通过齐次性（零次），令 $p = 1$。

## 结论：$k^* = 4$

**第一部分：$k = 4$ 是有效的。**

我们需要证明 $\frac{q - 9\rho}{4\rho(1-3q)} \geq 4$，即 $q(1 + 48\rho) \geq 25\r
ho$，适用于所有满足 $x+y+z=1$ 的 $x, y, z > 0$。

**引理：** 对于固定的 $\rho = xyz > 0$ 且 $x+y+z=1$，$q = xy+yz+zx$ 的最小值在 $
x, y, z$ 中有两个相等时取得。

*证明：* 通过拉格朗日乘数法，$q$ 在约束 $x+y+z=1$, $xyz=\rho$ 下的任何内部临界点
都满足 $(y-x)(1-\mu z) = 0$, $(z-y)(1-\mu x) = 0$, $(z-x)(1-\mu y) = 0$。如果所
有三个变量都不同，则 $\mu x = \mu y = \mu z = 1$，这迫使 $x = y = z$，产生矛盾。
因此，至少有两个变量相等。由于可行集是紧致的，且最小值在内部取得，因此结论成立。
$\square$

根据该引理，只需验证 $y = z$ 的情况即可。令 $x = t$, $y = z = (1-t)/2$，其中 $t
\in (0,1)$。则：

$$q = \frac{(1-t)(3t+1)}{4}, \quad \rho = \frac{t(1-t)^2}{4}$$

计算如下：

$$q(1+48\rho) - 25\rho = \frac{1-t}{4}\left[(3t+1)\left(1 + 12t(1-t)^2\right) -
25t(1-t)\right]$$

展开括号内的表达式：

$$(3t+1)\left(1 + 12t(1-t)^2\right) - 25t(1-t) = 36t^4 - 60t^3 + 37t^2 - 10t + 1
$$

这可以因式分解为一个**完全平方**：

$$36t^4 - 60t^3 + 37t^2 - 10t + 1 = (2t-1)^2(3t-1)^2$$

因此：

$$q(1+48\rho) - 25\rho = \frac{(1-t)(2t-1)^2(3t-1)^2}{4} \geq 0$$

适用于所有 $t \in (0,1)$。这证明了 $k = 4$ 对所有三角形均成立。

**第二部分：$k = 4$ 是紧致的。**

当 $(2t-1)^2(3t-1)^2 = 0$ 时等号成立，即 $t = 1/3$（等边三角形）或 $t = 1/2$。

当 $t = 1/2$ 时：$x = 1/2$, $y = z = 1/4$，对应边长为 $a = 1/2$, $b = c = 3/4$，
即三角形 $(2, 3, 3)$。

**在 $(2,3,3)$ 处验证：** $s = 4$, $\Delta = 2\sqrt{2}$, $R = \frac{18}{8\sqrt{2
}} = \frac{9}{4\sqrt{2}}$, $r = \frac{\sqrt{2}}{2}$, $\frac{R}{2r} = \frac{9}{8}
$。

右边 $= 1 + \frac{4}{64}\left[1 + 0 + 1\right] = 1 + \frac{1}{8} = \frac{9}{8}$
。✓ 等号成立。

由于等号在非等边三角形处成立，因此 $k$ 不能超过 $4$。

## 结论

最大的正数值为 $k = \boxed{4}$。
