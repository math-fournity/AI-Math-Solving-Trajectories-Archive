## Proof

**Setup.** Since $N = p_1 \cdots p_k$ is squarefree, each divisor $d \mid N$ cor
responds bijectively to a subset $T \subseteq [k] := \{1,\dots,k\}$ via $d_T = \
prod_{i \in T} p_i$, with $\omega(d_T) = |T|$. Define the sign $\varepsilon(T) =
 (-1)^{|T|}$. Then:

$$|S_1| - |S_2| = \sum_{\substack{T \subseteq [k] \\ a \le d_T \le b}} \varepsil
on(T).$$

**Order ideals.** For any real $t \ge 0$, define $G(t) = \sum_{\substack{T \subs
eteq [k] \\ d_T \le t}} \varepsilon(T)$ and the **order ideal** $I_t = \{T \subs
eteq [k] : d_T \le t\}$. This is indeed an order ideal of the Boolean lattice $2
^{[k]}$: if $T \in I_t$ and $T' \subseteq T$, then $d_{T'} \le d_T \le t$, so $T
' \in I_t$.

Since $I_{a-1} \subseteq I_b$ (as $a \le b$), we have:

$$|S_1| - |S_2| = G(b) - G(a-1) = \sum_{T \in I_b \setminus I_{a-1}} \varepsilon
(T).$$

**Symmetric Chain Decomposition (SCD).** By the classical theorem of de Bruijn–T
engbergen–Kruyswijk (1951), the Boolean lattice $2^{[k]}$ admits a partition int
o **symmetric chains**. Each chain $C$ has the form:

$$T_j \subset T_{j+1} \subset \cdots \subset T_{k-j}, \quad |T_i| = i, \quad j \
le k/2 \le k-j.$$

Since $k$ is even, every chain passes through exactly one subset of size $k/2$.
The chains partition $2^{[k]}$, so the number of chains equals $|\{T : |T| = k/2
\}| = \binom{k}{k/2}$.

**Signs alternate along each chain.** Along chain $C$, the signs are $\varepsilo
n(T_i) = (-1)^i$ for $i = j, j+1, \dots, k-j$, which is an alternating $\pm 1$ s
equence.

**Key claim: the intersection of $I_b \setminus I_{a-1}$ with each chain is a co
ntiguous segment.**

- $I_b \cap C$ is a **prefix** of $C$: if $T \in I_b \cap C$ and $T' \subset T$
with $T' \in C$, then $T' \in I_b$ (order ideal), so $T' \in I_b \cap C$.
- Similarly, $I_{a-1} \cap C$ is a prefix of $C$.
- Since $I_{a-1} \subseteq I_b$, we have $I_{a-1} \cap C \subseteq I_b \cap C$,
so $(I_b \setminus I_{a-1}) \cap C$ is a **contiguous segment** of $C$.

**Sum over a contiguous segment of an alternating sequence.** The sum of $(-1)^i
$ over any contiguous range $i = l, l+1, \dots, r$ is:

$$\sum_{i=l}^{r} (-1)^i = \begin{cases} (-1)^l & \text{if } r - l \text{ is even
 (odd number of terms)}, \\ 0 & \text{if } r - l \text{ is odd (even number of t
erms)}. \end{cases}$$

In either case, this sum lies in $\{-1, 0, 1\}$, and in particular is **at most
$1$**.

**Combining.** Let the SCD chains be $C_1, \dots, C_{\binom{k}{k/2}}$. Then:

$$|S_1| - |S_2| = \sum_{m=1}^{\binom{k}{k/2}} \sum_{T \in (I_b \setminus I_{a-1}
) \cap C_m} \varepsilon(T).$$

Each inner sum is the sum of alternating signs over a contiguous segment, hence
is at most $1$. Therefore:

$$|S_1| - |S_2| \le \sum_{m=1}^{\binom{k}{k/2}} 1 = \binom{k}{k/2} = C_k^{k/2}.$
$

$\blacksquare$
