## Proof

**Claim:** Yes. The function $f = \mathbf{1}_{[0,\,1/2]}$ (the indicator of $[0,
1/2]$) satisfies both conditions.

**Measurability.** The set $[0,1/2]$ is Lebesgue measurable, so its indicator $f
$ is a Lebesgue measurable function.

**Disagreement with every continuous function.** We must show that for every con
tinuous $g\colon[0,1]\to\mathbb{R}$, the set $\{x\in[0,1]: f(x)\neq g(x)\}$ has
positive measure. Equivalently, we show that **no** continuous $g$ agrees with $
f$ almost everywhere.

We use the following elementary lemma:

> **Lemma.** If $h\colon[a,b]\to\mathbb{R}$ is continuous and $h = c$ a.e. on $[
a,b]$ for some constant $c$, then $h(x)=c$ for every $x\in[a,b]$.
>
> *Proof of lemma.* The set $E=\{x\in[a,b]: h(x)=c\}$ is closed (as the preimage
 of $\{c\}$ under a continuous function, intersected with $[a,b]$) and has full
measure in $[a,b]$, so its complement $[a,b]\setminus E$ is open (relative to $[
a,b]$) and has measure zero. A nonempty relatively open subset of an interval al
ways contains a nondegenerate subinterval and hence has positive measure. Theref
ore $[a,b]\setminus E=\varnothing$, i.e., $h\equiv c$ on $[a,b]$. $\square$

Now suppose, for contradiction, that some continuous $g\colon[0,1]\to\mathbb{R}$
 satisfies $f=g$ a.e. on $[0,1]$.

- **On $[0,1/2]$:** here $f\equiv 1$, so $g=1$ a.e. on $[0,1/2]$. By the lemma (
applied to $g$ restricted to $[0,1/2]$), $g(x)=1$ for all $x\in[0,1/2]$. In part
icular $g(1/2)=1$.

- **On $[1/2,1]$:** here $f\equiv 0$, so $g=0$ a.e. on $[1/2,1]$. By the lemma (
applied to $g$ restricted to $[1/2,1]$), $g(x)=0$ for all $x\in[1/2,1]$. In part
icular $g(1/2)=0$.

This gives $g(1/2)=1$ and $g(1/2)=0$, a contradiction.

Therefore no continuous function $g$ agrees with $f$ almost everywhere. Hence fo
r every continuous $g$, the set $\{x: f(x)\neq g(x)\}$ cannot have measure zero;
 since $f$ is measurable and $g$ is measurable, this set is measurable, so it mu
st have **positive** measure.

Both required conditions are satisfied, so such a function exists. $\blacksquare
