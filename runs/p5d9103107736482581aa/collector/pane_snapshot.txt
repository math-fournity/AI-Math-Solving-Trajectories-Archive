## Optimal Homologous Cycle via Linear Programming

### Setup and Key Observation

Let $K$ be a simplicial complex. Fix a basis for $C_p(K)$ (the $p$-simplices) an
d for $C_{p+1}(K)$ (the $(p+1)$-simplices). Let $\partial_{p+1} \in \mathbb{R}^{
n \times m}$ be the boundary matrix, where $n = |K_p|$ and $m = |K_{p+1}|$. Repr
esent the given cycle $z \in Z_p(K)$ as a vector $z \in \mathbb{R}^n$.

**Key fact.** Two $p$-cycles $x$ and $z$ are homologous if and only if $x - z \i
n B_p(K)$, i.e., there exists a $(p+1)$-chain $c \in C_{p+1}(K)$ with
$$x - z = \partial_{p+1}\, c, \quad \text{equivalently} \quad x = z + \partial_{
p+1}\, c.$$

Therefore the set of cycles homologous to $z$ is the **affine subspace**
$$z + \operatorname{im}(\partial_{p+1}) = \{\, z + \partial_{p+1}\, c : c \in \m
athbb{R}^m \,\}.$$

Our task is to find the element of this affine subspace of minimum $\ell_1$-norm
:
$$\min_{c \,\in\, \mathbb{R}^m}\; \big\|\, z + \partial_{p+1}\, c \,\big\|_1.$$

### The Minimum Is Attained

The function $f(c) = \|z + \partial_{p+1}\, c\|_1$ is continuous. Decompose $\ma
thbb{R}^m = \ker(\partial_{p+1}) \oplus \ker(\partial_{p+1})^\perp$. For any $c
= c_0 + k$ with $k \in \ker(\partial_{p+1})$, we have $f(c) = f(c_0)$, so $f$ is
 constant along kernel directions and we may restrict to $\ker(\partial_{p+1})^\
perp$. On this subspace $\partial_{p+1}$ is injective, so $\|\partial_{p+1}\, c\
| \to \infty$ as $\|c\| \to \infty$, making $f$ **coercive**. A continuous coerc
ive function on a closed set attains its infimum. Hence an optimal $c^\*$ exists
 and $x^* = z + \partial_{p+1}\, c^*$ is the desired minimizer.

### Linear Programming Formulation

The $\ell_1$-minimization over an affine subspace is a **linear program**. Intro
duce auxiliary non-negative variables $t \in \mathbb{R}^n_{\ge 0}$ to linearize
the absolute values. Setting $y = z + \partial_{p+1}\, c$, the constraint $t_i \
ge |y_i|$ is equivalent to the two linear inequalities $t_i \ge y_i$ and $t_i \g
e -y_i$.

**The LP:**

$$
\begin{aligned}
\min_{c \,\in\, \mathbb{R}^m,\; t \,\in\, \mathbb{R}^n_{\ge 0}} \quad & \sum_{i=
1}^{n} t_i \\[4pt]
\text{subject to} \quad
& t \;\ge\; z + \partial_{p+1}\, c, \\
& t \;\ge\; -\big(z + \partial_{p+1}\, c\big), \\
& t \;\ge\; 0, \\
& c \;\text{free}.
\end{aligned}
$$

Here $t \ge v$ denotes componentwise inequality. The variables are $c$ (free, on
e per $(p{+}1)$-simplex) and $t$ (non-negative, one per $p$-simplex). The constr
aints are $2n + n = 3n$ linear inequalities in $m + n$ variables.

**Recovering the answer.** Let $(c^*, t^*)$ be an optimal solution. Then
$$\boxed{\; x^* \;=\; z \;+\; \partial_{p+1}\, c^* \;}$$
is the cycle homologous to $z$ of minimum $\ell_1$-norm, and $\|x^*\|_1 = \sum_i
 t_i^*$.

### Correctness Proof

We verify three things:

**(1) Feasibility encodes exactly the homologous cycles.** Any feasible $(c, t)$
 satisfies $t \ge |z + \partial_{p+1}\, c|$ componentwise, so $\sum t_i \ge \|z
+ \partial_{p+1}\, c\|_1$. Conversely, for any $c$, setting $t_i = |(z + \partia
l_{p+1}\, c)_i|$ yields a feasible point with objective value exactly $\|z + \pa
rtial_{p+1}\, c\|_1$. Hence
$$\min_{\text{feasible}} \sum t_i \;=\; \min_{c \in \mathbb{R}^m}\; \|z + \parti
al_{p+1}\, c\|_1,$$
which is precisely the minimum $\ell_1$-norm over the homology class $[z]$.

**(2) The optimizer is homologous to $z$.** By construction $x^* - z = \partial_
{p+1}\, c^* \in B_p(K)$, so $[x^*] = [z]$ in $H_p(K)$.

**(3) The optimizer achieves the global minimum.** Since every homologous cycle
has the form $z + \partial_{p+1}\, c$ and the LP explores all $c \in \mathbb{R}^
m$, no homologous cycle is excluded. The LP is convex (linear objective, linear
constraints), so any optimal solution is a global optimum.

### Complexity Remark

This LP has $m + n$ variables and $O(n)$ constraints, so it is solvable in **pol
ynomial time** (e.g., via interior-point methods) over $\mathbb{Q}$ or $\mathbb{
R}$. If integer coefficients are required (working over $\mathbb{Z}$), the probl
em becomes an **integer linear program**; however, in the important special case
 where $K$ has no $(p{+}1)$-simplices (i.e., $B_p = 0$), every cycle in the clas
s equals $z$ itself and the problem is trivial. Over $\mathbb{Z}_2$, the $\ell_1
$-norm reduces to the Hamming weight (support size) and the problem becomes the
**minimum-weight homologous cycle problem**, which is NP-hard in general.

### Summary

To find the $\ell_1$-minimal cycle homologous to $z \in Z_p(K)$:

1. Form the boundary matrix $\partial_{p+1}$ (rows indexed by $p$-simplices, col
umns by $(p{+}1)$-simplices).
2. Solve the LP above (minimize $\sum t_i$ subject to $t \ge \pm(z + \partial_{p
+1}\, c)$, $t \ge 0$).
3. Output $x^* = z + \partial_{p+1}\, c^*$.

This is the **Optimal Homologous Cycle Problem (OHCP)**, and the LP formulation
is both necessary and sufficient: it exactly characterizes the minimum $\ell_1$-
norm representative of the homology class $[z]$.
