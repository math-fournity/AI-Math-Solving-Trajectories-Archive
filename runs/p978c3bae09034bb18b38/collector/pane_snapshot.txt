**Setup.** Let $f(x) = x^{2007} + 17x^{2006} + 1 = \prod_{j=1}^{2007}(x - r_j)$
(monic). Since $f(0)=1$, all $r_j \neq 0$, so $s_j := r_j + 1/r_j$ is well-defin
ed.

**The $s_j$ are distinct.** Note $s_j = s_k$ (with $j \neq k$) iff $r_j r_k = 1$
, i.e., $1/r_j$ is also a root of $f$. If both $r$ and $1/r$ are roots:
$$f(r)=0 \Rightarrow r^{2007}+17r^{2006}+1=0, \qquad f(1/r)=0 \Rightarrow r^{200
7}+17r+1=0.$$
Subtracting: $17r(r^{2005}-1)=0$, so $r^{2005}=1$ (since $r\neq 0$). Substitutin
g back: $r^2+17r+1=0$ (using $r^{2007}=r^2$). The roots of $r^2+17r+1=0$ are rea
l with $r+1/r=-17$, but the only real $2005$th root of unity (2005 odd) is $r=1$
, which doesn't satisfy $r^2+17r+1=0$. Contradiction — so all $s_j$ are distinct
.

Since $P$ has degree $2007$ and vanishes at the $2007$ distinct values $s_j$, we
 have $P(x) = c\prod_j(x-s_j)$, and the ratio $P(1)/P(-1)$ is independent of $c$
.

**Computing the ratio.**
$$\frac{P(1)}{P(-1)} = \prod_{j=1}^{2007}\frac{1-s_j}{-1-s_j} = (-1)^{2007}\prod
_j\frac{1-s_j}{1+s_j} = -\prod_j\frac{1-s_j}{1+s_j}.$$

Since $\dfrac{1-s_j}{1+s_j} = \dfrac{r_j - r_j^2 - 1}{r_j + r_j^2 + 1} = -\dfrac
{r_j^2 - r_j + 1}{r_j^2 + r_j + 1}$,

$$\frac{P(1)}{P(-1)} = -\prod_j\left(-\frac{r_j^2-r_j+1}{r_j^2+r_j+1}\right) = -
(-1)^{2007}\prod_j\frac{r_j^2-r_j+1}{r_j^2+r_j+1} = \prod_j\frac{r_j^2-r_j+1}{r_
j^2+r_j+1}.$$

Using $r^2-r+1 = \frac{r^3+1}{r+1}$ and $r^2+r+1 = \frac{r^3-1}{r-1}$:

$$\frac{P(1)}{P(-1)} = \frac{\prod_j(r_j^3+1)\cdot\prod_j(r_j-1)}{\prod_j(r_j^3-
1)\cdot\prod_j(r_j+1)}.$$

**Evaluating each product.** Since $f$ is monic: $\prod_j(1-r_j)=f(1)=19$ and $\
prod_j(1+r_j)=-f(-1)=-17$ (as $f(-1)=(-1)^{2007}+17(-1)^{2006}+1=-1+17+1=17$). H
ence
$$\prod_j(r_j-1) = -19, \qquad \prod_j(r_j+1) = -17.$$

For the cubic products, let $\omega = e^{2\pi i/3}$. Since $r^3 - a = \prod_{k=0
}^2(r - \omega^k a^{1/3})$ and $\prod_j(r_j - c) = -f(c)$:
$$\prod_j(r_j^3 - a) = \prod_{k=0}^2\prod_j(r_j - \omega^k a^{1/3}) = \prod_{k=0
}^2(-f(\omega^k a^{1/3})) = -\prod_{k=0}^2 f(\omega^k a^{1/3}).$$

**At $a=1$** (cube roots $1,\omega,\omega^2$): Since $2007 = 3\cdot 669$ and $20
06 = 3\cdot 668+2$,
$$f(\omega) = 1 + 17\omega^2 + 1 = 2+17\omega^2, \quad f(\omega^2) = 1 + 17\omeg
a + 1 = 2+17\omega.$$
$$f(\omega)f(\omega^2) = (2+17\omega^2)(2+17\omega) = 4 + 34(\omega+\omega^2) +
289\omega^3 = 4 - 34 + 289 = 259.$$
$$\prod_j(r_j^3-1) = -f(1)f(\omega)f(\omega^2) = -19\cdot 259.$$

**At $a=-1$** (cube roots $-1,-\omega,-\omega^2$):
$$f(-\omega) = -1 + 17\omega^2 + 1 = 17\omega^2, \quad f(-\omega^2) = -1 + 17\om
ega + 1 = 17\omega.$$
$$f(-\omega)f(-\omega^2) = 17\omega^2 \cdot 17\omega = 289\omega^3 = 289.$$
$$\prod_j(r_j^3+1) = -f(-1)f(-\omega)f(-\omega^2) = -17\cdot 289.$$

**Combining:**
$$\frac{P(1)}{P(-1)} = \frac{(-17\cdot 289)(-19)}{(-19\cdot 259)(-17)} = \frac{1
7\cdot 289\cdot 19}{19\cdot 259\cdot 17} = \frac{289}{259}.$$

**Reduction.** $289 = 17^2$ and $259 = 7\cdot 37$, so $\gcd(289,259)=1$. Thus $m
=289$, $n=259$.

$$m + n = 289 + 259 = \boxed{548}.$$
