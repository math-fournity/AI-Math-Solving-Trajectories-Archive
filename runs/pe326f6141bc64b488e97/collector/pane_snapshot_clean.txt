## Proof

We seek $h(t)$ such that $M_t = [B_t + h(t)]\,e^{-B_t - t/2}$ is a martingale. W
e apply Itô's formula to $f(t,x) = (x + h(t))\,e^{-x - t/2}$.

**Partial derivatives.**

$$f_x = e^{-x-t/2} - (x+h(t))e^{-x-t/2} = e^{-x-t/2}\bigl[1 - x - h(t)\bigr],$$

$$f_{xx} = -e^{-x-t/2}\bigl[1-x-h(t)\bigr] - e^{-x-t/2} = e^{-x-t/2}\bigl[x + h(
t) - 2\bigr],$$

$$f_t = h'(t)\,e^{-x-t/2} - \tfrac{1}{2}(x+h(t))\,e^{-x-t/2} = e^{-x-t/2}\Bigl[h
'(t) - \tfrac{1}{2}\bigl(x+h(t)\bigr)\Bigr].$$

**Itô expansion.** Setting $x = B_t$,

$$dM_t = f_t\,dt + f_x\,dB_t + \tfrac{1}{2}f_{xx}\,dt.$$

The drift (the $dt$ coefficient) is

$$f_t + \tfrac{1}{2}f_{xx} = e^{-B_t-t/2}\Bigl[h'(t) - \tfrac{1}{2}\bigl(B_t+h(t
)\bigr) + \tfrac{1}{2}\bigl(B_t+h(t)-2\bigr)\Bigr].$$

The $B_t$ and $h(t)$ terms cancel:

$$= e^{-B_t-t/2}\Bigl[h'(t) - \tfrac{1}{2}B_t - \tfrac{1}{2}h(t) + \tfrac{1}{2}B
_t + \tfrac{1}{2}h(t) - 1\Bigr] = e^{-B_t-t/2}\bigl[h'(t) - 1\bigr].$$

**Martingale condition.** For $M_t$ to be a (local) martingale the finite-variat
ion part must vanish, so

$$h'(t) - 1 = 0 \quad\Longrightarrow\quad h'(t) = 1 \quad\Longrightarrow\quad h(
t) = t + C,\quad C\in\mathbb{R}.$$

**True martingale verification.** With $h(t)=t+C$, the diffusion coefficient is

$$\sigma_t = f_x\big|_{x=B_t} = e^{-B_t-t/2}\bigl[1 - B_t - t - C\bigr].$$

For any $T>0$,

$$\mathbb{E}\!\int_0^T \sigma_s^2\,ds = \int_0^T \mathbb{E}\Bigl[e^{-2B_s-s}\big
l(1-B_s-s-C\bigr)^2\Bigr]ds.$$

Since $B_s\sim N(0,s)$, $e^{-2B_s}$ is lognormal with $\mathbb{E}[e^{-2B_s}]=e^{
2s}$, and all moments $\mathbb{E}[e^{-2B_s}B_s^k]$ are finite (polynomial times
lognormal). Hence the integrand is bounded on $[0,T]$ and the integral is finite
. By the BDG/Itô integrability criterion, $M_t$ is a **true** martingale on ever
y finite interval $[0,T]$.

**Conclusion.** The general solution is

$$\boxed{h(t) = t + C,\quad C\in\mathbb{R}.}$$

The simplest choice is $h(t)=t$, giving the martingale $M_t = (B_t+t)\,e^{-B_t-t
/2}$.
