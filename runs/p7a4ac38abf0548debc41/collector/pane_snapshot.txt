Let
$$h(t) = \frac{\sin t}{t}\,g(t).$$

We determine the parity of $h$.

- $\sin t$ is odd: $\sin(-t) = -\sin t$.
- $t$ is odd, so $\dfrac{\sin t}{t}$ is **even**, since
$$\frac{\sin(-t)}{-t} = \frac{-\sin t}{-t} = \frac{\sin t}{t}.$$
- $g(t)$ is **odd** by hypothesis: $g(-t) = -g(t)$.

Therefore $h$ is the product of an even function and an odd function, hence **od
d**:
$$h(-t) = \frac{\sin(-t)}{-t}\,g(-t) = \frac{\sin t}{t}\bigl(-g(t)\bigr) = -h(t)
.$$

Since $g$ is integrable on every closed interval and $\frac{\sin t}{t}$ is conti
nuous (with the removable singularity at $t=0$ filled by the value $1$), the pro
duct $h(t)$ is integrable on every closed interval. In particular, for every $R>
0$ the integral $\int_{-R}^{R} h(t)\,dt$ exists.

Because $h$ is odd and $[-R,R]$ is symmetric about the origin,
$$\int_{-R}^{R} h(t)\,dt = 0 \qquad \text{for all } R>0.$$

The Cauchy Principal Value is defined as
$$\text{PV}\int_{-\infty}^{\infty} h(t)\,dt = \lim_{R\to\infty} \int_{-R}^{R} h(
t)\,dt = \lim_{R\to\infty} 0 = 0.$$

Hence
$$\boxed{\text{PV}\int_{-\infty}^{\infty} \frac{\sin t}{t}\,g(t)\,dt = 0.}$$
