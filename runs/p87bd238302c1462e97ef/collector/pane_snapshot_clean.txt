## Proof

Denote the equation $P(x,y,z)$.

**Step 1: Reduction to a Cauchy-type relation.**

Fix $y, z$ and let $A = f(y + f(z))$, $B = f(f(y)) + f(f(f(z)))$. Then $P$ gives
$$f(x + A) = f(x) + B \quad \text{for all } x \in \mathbb{R}.$$

If $A = f(y_1 + f(z_1)) = f(y_2 + f(z_2))$, then comparing the two instances of
$P$ gives $f(f(y_1)) + f(f(f(z_1))) = f(f(y_2)) + f(f(f(z_2)))$, so $B$ depends
only on $A$. Thus there is a function $\varphi$ on $S := \{f(y + f(z)) : y,z \in
 \mathbb{R}\}$ with $f(x+A) = f(x) + \varphi(A)$.

Since $f$ is continuous, for any fixed $z$ the map $y \mapsto y + f(z)$ is a bij
ection on $\mathbb{R}$, so $S = f(\mathbb{R}) =: I$, the image of $f$. Setting $
x = 0$: $\varphi(A) = f(A) - f(0)$, hence
$$f(x + A) = f(x) + f(A) - f(0) \quad \text{for all } x \in \mathbb{R},\; A \in
I. \tag{1}$$

**Step 2: Constant case.** If $f \equiv k$, then $k = 3k$, so $k = 0$. This is $
f(x) = 0 \cdot x$, included in the family below.

**Step 3: Non-constant case — $f$ is affine.** Suppose $f$ is non-constant. By c
ontinuity and the intermediate value theorem, $I = f(\mathbb{R})$ is a non-degen
erate interval, so it contains an open subinterval $(a, b)$ with $a < b$.

Set $g(x) = f(x) - f(0)$, so $g(0) = 0$ and (1) becomes
$$g(x + A) = g(x) + g(A) \quad \text{for all } x \in \mathbb{R},\; A \in I. \tag
{2}$$

For $A_1, A_2 \in (a,b) \subseteq I$, applying (2) twice:
$$g(x + A_1) = g(x) + g(A_1), \quad g(x + A_1) - g(x + A_2) = g(A_1) - g(A_2).$$
Setting $h = A_1 - A_2 \in (a-b,\, b-a)$, we get $g(x+h) - g(x) = g(A_1) - g(A_2
)$ for all $x$. With $x = 0$: $g(h) = g(A_1) - g(A_2)$, so
$$g(x + h) = g(x) + g(h) \quad \text{for all } x \in \mathbb{R},\; h \in (a-b,\,
 b-a). \tag{3}$$

Let $\ell = b - a > 0$. For $h_1, h_2 \in (-\ell/2, \ell/2)$, we have $h_1 + h_2
 \in (-\ell, \ell)$, so applying (3):
$$g(h_1 + h_2) = g(h_1) + g(h_2) \quad \text{for } h_1, h_2 \in (-\ell/2, \ell/2
).$$

Since $g$ is continuous, the local Cauchy equation implies $g(h) = ch$ on $(-\el
l/2, \ell/2)$ for some constant $c$. Then (3) gives $g(x + h) = g(x) + ch$ for a
ll $x$ and $h \in (-\ell, \ell)$, meaning $g$ is affine with slope $c$ in a neig
hborhood of every $x \in \mathbb{R}$. Hence $g(x) = cx$ on all of $\mathbb{R}$ (
using $g(0) = 0$).

Therefore $f(x) = cx + d$ where $d = f(0)$.

**Step 4: Determine which affine functions work.** Substitute $f(x) = cx + d$:

**LHS:** $f(z) = cz+d$; $\;y + f(z) = y + cz + d$; $\;f(y+f(z)) = cy + c^2 z + c
d + d$; $\;x + f(y+f(z)) = x + cy + c^2 z + cd + d$;
$$\text{LHS} = c(x + cy + c^2 z + cd + d) + d = cx + c^2 y + c^3 z + c^2 d + cd
+ d.$$

**RHS:** $f(x) = cx + d$; $\;f(f(y)) = c^2 y + cd + d$; $\;f(f(f(z))) = c^3 z +
c^2 d + cd + d$;
$$\text{RHS} = cx + c^2 y + c^3 z + 3d + 2cd + c^2 d.$$

Equating: $(c^2 d + cd + d) = (3d + 2cd + c^2 d)$, which simplifies to
$$d(2 + c) = 0.$$

- **If $d = 0$:** $f(x) = cx$ for any $c \in \mathbb{R}$.
- **If $c = -2$:** $f(x) = -2x + d$ for any $d \in \mathbb{R}$.

**Step 5: Verification.**

*Family 1:* $f(x) = cx$. Then LHS $= c(x + c(y+cz)) = cx + c^2 y + c^3 z$ and RH
S $= cx + c^2 y + c^3 z$. ✓

*Family 2:* $f(x) = -2x + d$. Then $f(z) = -2z+d$; $f(y+f(z)) = -2y+4z-d$; LHS $
= f(x-2y+4z-d) = -2x+4y-8z+3d$. For RHS: $f(f(y)) = 4y - d$; $f(f(f(z))) = -8z +
 3d$; RHS $= (-2x+d) + (4y-d) + (-8z+3d) = -2x+4y-8z+3d$. ✓

(Note: $f(x) = -2x$ belongs to both families, with $c = -2, d = 0$.)

## Conclusion

All continuous solutions are:
$$\boxed{f(x) = cx \text{ for any } c \in \mathbb{R}, \qquad \text{or} \qquad f(
x) = -2x + d \text{ for any } d \in \mathbb{R}.}$$
