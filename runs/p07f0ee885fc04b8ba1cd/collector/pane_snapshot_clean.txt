## Setup

Place A at the origin, B at (6, 0). Let ∠BAG = α, so G = (7cos α, 7sin α) with s
in α > 0. Denote c = cos α, s = sin α.

## The 60° Condition

Joint X = (x, 0) lies on AB. The angle at X between segments XB and XG is 60°:

$$\cos 60° = \frac{\overrightarrow{XB}\cdot\overrightarrow{XG}}{|XB||XG|} = \fra
c{(6-x)(7c - x)}{(6-x)\sqrt{(7c-x)^2 + 49s^2}} = \frac{7c - x}{|XG|}$$

So |XG| = 2(7c − x). Squaring: (7c−x)² + 49s² = 4(7c−x)², giving **49s² = 3(7c−x
)²**, hence:

$$x = 7c - \frac{7s}{\sqrt{3}}, \qquad |GX| = \frac{14s}{\sqrt{3}}.$$

## The Perpendicular Condition (BP ⊥ AG, BP = 4)

Rotate to coordinates (e₁, e₂) with e₁ along AG, e₂ perpendicular. Then:
- A = (0, 0), G = (7, 0), B = (6c, −6s).

The line through B perpendicular to AG is the e₂-direction. Point P lies on this
 line at distance 4 from B, so **P = (6c, −6s + 4)** (choosing the +4 direction
so P lies on segment GX; the −4 direction places P below X, off the cable).

Since P lies on line GX, write P = G + λ(X − G). In (e₁, e₂) coordinates, X = (x
c, −xs), so:

$$\text{e}_1:\quad 6c = 7 + \lambda(xc - 7), \qquad \text{e}_2:\quad -6s + 4 = -
\lambda x s.$$

From the e₂ equation: 4 = s(6 − λx). From the e₁ equation: λ = (6c − 7)/(xc − 7)
.

Substituting λ into the e₂ equation and using x = 7c − 7s/√3, after simplificati
on:

$$\frac{6 - 7c + 7s/\sqrt{3}}{s + c/\sqrt{3}} = 4.$$

Multiplying through: **(4 − 7/√3)s + (7 + 4/√3)c = 6**, with c² + s² = 1.

## Solving the System

Multiply the constraint by √3 and set u = c + √3 s, w = √3 c − s:

$$7w + 4u = 6\sqrt{3}, \qquad u^2 + w^2 = 4.$$

Substituting w = (6√3 − 4u)/7 into u² + w² = 4:

$$65u^2 - 48\sqrt{3}\,u - 88 = 0.$$

By the quadratic formula (discriminant = 48²·3 + 4·65·88 = 6912 + 22880 = 29792
= (28√38)²):

$$u = \frac{48\sqrt{3} \pm 28\sqrt{38}}{130} = \frac{24\sqrt{3} \pm 14\sqrt{38}}
{65}.$$

Since u = c + √3 s > 0, we take the **+** sign: u = (24√3 + 14√38)/65.

## Computing GP

We have GP = λ·|GX|. From the parametrization:

$$\lambda = \frac{6c - 7}{xc - 7} = \frac{6c-7}{-7s(s + c/\sqrt{3})}, \qquad |GX
| = \frac{14s}{\sqrt{3}}.$$

Therefore:

$$GP = \lambda \cdot |GX| = \frac{2(7 - 6c)}{c + \sqrt{3}\,s} = \frac{2(7-6c)}{u
}.$$

From u and w, we recover c = (u + √3 w)/4, giving:

$$7 - 6c = \frac{1064 - 144\sqrt{3} - 84\sqrt{38} + 48\sqrt{114}}{260}.$$

So:

$$GP = \frac{266 - 36\sqrt{3} - 21\sqrt{38} + 12\sqrt{114}}{12\sqrt{3} + 7\sqrt{
38}}.$$

## Rationalization

Multiply numerator and denominator by (12√3 − 7√38). The denominator becomes (12
√3)² − (7√38)² = 432 − 1862 = −1430.

Expanding the numerator (collecting like radicals):

| Term | Contribution |
|------|-------------|
| √3 | 3192√3 − 3192√3 = 0 |
| √38 | −1862√38 + 432√38 = −1430√38 |
| √114 | 252√114 − 252√114 = 0 |
| constant | −1296 + 5586 = 4290 |

(using √(114·38) = √4332 = 38√3)

Thus:

$$GP = \frac{4290 - 1430\sqrt{38}}{-1430} = \frac{1430\sqrt{38} - 4290}{1430} =
\sqrt{38} - 3.$$
