# Problem

In the futuristic city of Tetra-Grid, an architect is designing triangular energy networks. A large equilateral triangular plot is divided into a grid of $n^2$ identical smaller equilateral triangular zones using power lines parallel to the plot's outer boundaries. This grid creates a set $V$ of interconnected junctions, totaling exactly $\frac{(n+1)(n+2)}{2}$ individual nodes.

At each junction $v \in V$, the architect installs a regulator that outputs a real-numbered voltage $x_v$. To maintain grid stability, the system must follow a strict "Equilateral Balance Rule": for any three junctions that form the vertices of an equilateral triangle (of any size) whose sides are parallel to the main boundary, the sum of their voltages must be exactly zero.

Let $S_n$ represent the dimension of the real vector space containing all possible valid voltage assignments for a grid of size $n$. Determine the value of the sum:
$$S_2 + S_3 + S_4 + S_{2024}$$
