## Proof

The Volterra operator on $L^2[0,1]$ is
$$A(f)(x) = \int_0^x f(t)\,dt.$$

**Step 1: Compute the iterates $A^n$.**

By induction, the $n$-th iterate is
$$A^n(f)(x) = \int_0^x \frac{(x-t)^{n-1}}{(n-1)!}\,f(t)\,dt, \qquad n \geq 1.$$
The base case $n=1$ is the definition. For the inductive step:
$$A^{n+1}f(x) = \int_0^x A^n f(s)\,ds = \int_0^x \left(\int_0^s \frac{(s-t)^{n-1
}}{(n-1)!}f(t)\,dt\right)ds.$$
Switching the order of integration over the triangle $0 \leq t \leq s \leq x$:
$$= \int_0^x \frac{f(t)}{(n-1)!}\left(\int_t^x (s-t)^{n-1}\,ds\right)dt = \int_0
^x \frac{(x-t)^n}{n!}\,f(t)\,dt. \checkmark$$

**Step 2: Bound $\|A^n\|$.**

For $f \in L^2[0,1]$ and $x \in [0,1]$:
$$|A^n f(x)| \leq \int_0^x \frac{(x-t)^{n-1}}{(n-1)!}|f(t)|\,dt \leq \frac{\|(x-
t)^{n-1}\|_{\infty,\, t\in[0,x]}}{(n-1)!}\int_0^1 |f(t)|\,dt.$$

By the hint, for $t \in [0,x]$ with $x \leq 1$, we have $(x-t)^{n-1} \leq x^{n-1
} \leq 1$, so $\|(x-t)^{n-1}\|_\infty = 1$. Hence
$$|A^n f(x)| \leq \frac{1}{(n-1)!}\|f\|_1 \leq \frac{1}{(n-1)!}\|f\|_2,$$
using $\|f\|_1 \leq \|f\|_2$ on the probability space $[0,1]$. This holds for ev
ery $x$, so
$$\|A^n f\|_\infty \leq \frac{1}{(n-1)!}\|f\|_2.$$
Therefore
$$\|A^n f\|_2 \leq \|A^n f\|_\infty \cdot \|1\|_2 = \frac{1}{(n-1)!}\|f\|_2,$$
giving the operator norm bound
$$\|A^n\| \leq \frac{1}{(n-1)!}.$$

**Step 3: Take the spectral radius limit.**

Using Gelfand's formula $\rho(A) = \lim_{n\to\infty}\|A^n\|^{1/n}$ and the bound
 above:
$$0 \leq \rho(A) = \lim_{n\to\infty}\|A^n\|^{1/n} \leq \lim_{n\to\infty}\left(\f
rac{1}{(n-1)!}\right)^{1/n} = 0,$$
since $(n-1)!$ grows faster than any exponential, so $\bigl((n-1)!\bigr)^{1/n} \
to \infty$ (equivalently, by Stirling's approximation, $((n-1)!)^{1/n} \sim (n/e
) \to \infty$).

By the squeeze theorem, $\rho(A) = 0$.

**Conclusion.** The spectral radius of the Volterra operator is
$$\boxed{\rho(A) = 0}.$$

This reflects the well-known fact that the Volterra operator is quasinilpotent:
its spectrum is the single point $\{0\}$.
