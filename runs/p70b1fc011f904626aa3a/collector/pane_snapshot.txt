## Solution

Let $f$ be a polynomial of degree $n \geq 1$, and write $f(x) = a_n x^n + \cdots
 + a_0$ with $a_n \neq 0$.

**Step 1: Determine the degree.**

The condition $(f(x))^2 = f(f(x))$ gives us the degree equation. The left side h
as degree $2n$, while the right side has degree $n \cdot n = n^2$. Equating:

$$n^2 = 2n \implies n(n-2) = 0 \implies n = 0 \text{ or } n = 2.$$

Since we require $\deg f \geq 1$, we must have $n = 2$.

**Step 2: Determine the coefficients.**

Write $f(x) = ax^2 + bx + c$ with $a \neq 0$. Use the condition $f(x^2) = (f(x))
^2$:

$$f(x^2) = ax^4 + bx^2 + c,$$

$$(f(x))^2 = (ax^2+bx+c)^2 = a^2x^4 + 2abx^3 + (2ac+b^2)x^2 + 2bcx + c^2.$$

Comparing coefficients:

| Power | $f(x^2)$ | $(f(x))^2$ | Equation |
|-------|----------|-------------|----------|
| $x^4$ | $a$ | $a^2$ | $a = a^2 \Rightarrow a=1$ (since $a\neq 0$) |
| $x^3$ | $0$ | $2ab$ | $2ab=0 \Rightarrow b=0$ |
| $x^2$ | $b$ | $2ac+b^2$ | $b = 2ac+b^2 \Rightarrow 0 = 2c \Rightarrow c=0$ |
| $x^1$ | $0$ | $2bc$ | $0=0$ ✓ |
| $x^0$ | $c$ | $c^2$ | $c = c^2 \Rightarrow c=0$ or $c=1$; but $c=0$ from above
 |

Thus $a=1,\; b=0,\; c=0$, giving $f(x) = x^2$.

**Step 3: Verify the second condition $(f(x))^2 = f(f(x))$.**

With $f(x) = x^2$:
- $(f(x))^2 = (x^2)^2 = x^4$.
- $f(f(x)) = f(x^2) = (x^2)^2 = x^4$. ✓

Both conditions $f(x^2) = (f(x))^2$ and $(f(x))^2 = f(f(x))$ hold for all real $
x$.

**Conclusion.** The unique polynomial function of degree $\geq 1$ satisfying the
 given equation is $f(x) = x^2$. The number of such functions is:
