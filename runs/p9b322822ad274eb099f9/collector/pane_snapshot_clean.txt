## Proof

**Claim.** The entire functions $f$ for which $|f|$ is harmonic are exactly the
constant functions $f(z) \equiv c$, $c \in \mathbb{C}$.

---

**Constant functions work.** If $f \equiv c$, then $|f| \equiv |c|$ is constant,
 hence harmonic.

**Now suppose $f$ is entire and $|f|$ is harmonic.** We show $f$ is constant.

**Case 1: $f \equiv 0$.** Done — this is constant.

**Case 2: $f \not\equiv 0$.** Since $f$ is holomorphic and not identically zero,
 its zeros are isolated. Thus the set
$$U = \{z \in \mathbb{C} : f(z) \neq 0\} = \mathbb{C} \setminus Z(f)$$
is the complement of a discrete set in $\mathbb{C}$, and is therefore **connecte
d** (indeed path-connected: any two points in $U$ can be joined by a polygonal p
ath avoiding the isolated zeros).

On $U$, $f$ is holomorphic and nonzero, so there exists a holomorphic branch of
$\log f$ locally, and
$$\log|f| = \operatorname{Re}(\log f)$$
is **harmonic** on $U$.

Since $|f| = e^{\log|f|}$ on $U$ and $|f|$ is harmonic by hypothesis, we compute
 the Laplacian using the chain rule. Setting $g = \log|f|$ (harmonic, so $\Delta
 g = 0$):
$$\Delta|f| = \Delta e^{g} = e^{g}\bigl(\Delta g + |\nabla g|^{2}\bigr) = |f|\,|
\nabla \log|f||^{2}.$$
The harmonicity of $|f|$ gives $\Delta|f| = 0$ on $U$. Since $|f| > 0$ on $U$, w
e conclude
$$|\nabla \log|f||^{2} = 0 \quad\text{on } U,$$
so $\nabla \log|f| \equiv 0$ on $U$. Because $U$ is connected, $\log|f|$ is cons
tant on $U$, hence **$|f|$ is constant on $U$**, say $|f| \equiv c > 0$.

**$f$ has no zeros.** Suppose for contradiction that $f(z_{0}) = 0$ for some $z_
{0}$. Since $z_{0}$ is an isolated zero, there is a punctured disk $D'(z_{0}, r)
 \subset U$ on which $|f| \equiv c > 0$. But $|f|$ is continuous and $|f(z_{0})|
 = 0$, so $|f(z)| \to 0$ as $z \to z_{0}$, contradicting $|f| \equiv c > 0$ on $
D'(z_{0},r)$.

Therefore $f$ has no zeros, $U = \mathbb{C}$, and $|f| \equiv c$ on all of $\mat
hbb{C}$. Then $f$ is a bounded entire function ($|f| \leq c$), so by **Liouville
's theorem**, $f$ is constant. $\blacksquare$

---

**Conclusion.** The entire functions $f$ for which $|f|$ is harmonic are precise
ly the constant functions $f(z) \equiv c$, $c \in \mathbb{C}$.
