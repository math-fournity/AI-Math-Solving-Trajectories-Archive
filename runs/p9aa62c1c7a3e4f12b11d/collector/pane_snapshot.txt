## Solution

**Setup.** Place rectangle $ABCD$ with $A$ at the origin, $B = (a, 0)$, $D = (0,
 b)$, $C = (a, b)$, where $a = AB$ and $b = AD$.

The midpoints are:
- $M = \text{midpoint of } BC = \left(a, \dfrac{b}{2}\right)$
- $N = \text{midpoint of } CD = \left(\dfrac{a}{2}, b\right)$

**Perpendicularity condition.**
$$\vec{AM} = \left(a, \dfrac{b}{2}\right), \qquad \vec{MN} = \left(-\dfrac{a}{2}
, \dfrac{b}{2}\right).$$

Since $AM \perp MN$, the dot product is zero:
$$a\left(-\dfrac{a}{2}\right) + \dfrac{b}{2}\cdot\dfrac{b}{2} = 0 \implies -\dfr
ac{a^2}{2} + \dfrac{b^2}{4} = 0 \implies b^2 = 2a^2.$$

**Length condition.** $AN = 60$:
$$AN^2 = \dfrac{a^2}{4} + b^2 = 3600.$$

Substituting $b^2 = 2a^2$:
$$\dfrac{a^2}{4} + 2a^2 = 3600 \implies \dfrac{9a^2}{4} = 3600 \implies a^2 = 16
00 \implies a = 40.$$

Then $b^2 = 2 \cdot 1600 = 3200$, so $b = 40\sqrt{2}$.

**Area.**
$$\text{Area} = ab = 40 \cdot 40\sqrt{2} = 1600\sqrt{2}.$$

So $m = 1600$ and $n = 2$ (which is square-free).

**Verification.** $N = (20, 40\sqrt{2})$, so $AN^2 = 400 + 3200 = 3600 = 60^2$.

$$100m + n = 100(1600) + 2 = \boxed{160002}.$$
