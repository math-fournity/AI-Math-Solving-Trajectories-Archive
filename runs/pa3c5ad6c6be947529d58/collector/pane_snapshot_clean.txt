Looking at this problem, I need to determine whether $G/\Gamma$ necessarily has
a $G$-invariant measure when $G$ is locally compact Hausdorff and $\Gamma$ is di
screte.

**Answer: No.** I'll prove this with an explicit counterexample.

---

## Setup and Counterexample

Let $G = \mathbb{R}_{>0} \rtimes \mathbb{R}$, the affine group of the real line,
 with multiplication
$$(a_1, b_1)(a_2, b_2) = (a_1 a_2,\; a_1 b_2 + b_1).$$
This is a locally compact Hausdorff topological group (with the product topology
 on $\mathbb{R}_{>0} \times \mathbb{R}$).

Let $\Gamma = \{(2^n, 0) : n \in \mathbb{Z}\}$. This is a subgroup since $(2^m,0
)(2^n,0) = (2^{m+n},0)$ and $(2^n,0)^{-1} = (2^{-n},0)$. It is **discrete**: the
 set $\{2^n : n \in \mathbb{Z}\}$ has no accumulation point in $\mathbb{R}_{>0}$
 (the only limit points are $0$ and $\infty$, neither in $\mathbb{R}_{>0}$).

## Identifying $G/\Gamma$

The right coset $(c,d)\Gamma = \{(c \cdot 2^n, d) : n \in \mathbb{Z}\}$ is deter
mined by $(\log_2 c \bmod 1,\; d)$. This gives a homeomorphism
$$G/\Gamma \;\cong\; \mathbb{R}/\mathbb{Z} \times \mathbb{R}, \qquad (c,d)\Gamma
 \;\mapsto\; (\log_2 c \bmod 1,\; d).$$

The left $G$-action on $G/\Gamma$: for $g = (a,b)$ with $\alpha = \log_2 a$,
$$(a,b) \cdot (u, v) = \bigl((u + \alpha) \bmod 1,\; 2^\alpha v + b\bigr).$$

## Proof that no nonzero $G$-invariant Radon measure exists

Suppose $\mu$ is a $G$-invariant Radon measure on $\mathbb{R}/\mathbb{Z} \times
\mathbb{R}$.

**Step 1 (Invariance under $v$-translations).** The subgroup $\{(1, b) : b \in \
mathbb{R}\} \subset G$ acts by $(u, v) \mapsto (u, v + b)$. So $\mu$ is invarian
t under all translations in the $v$-coordinate. Disintegrating $\mu$ over the pr
ojection $\pi(u,v) = u$ to $\mathbb{R}/\mathbb{Z}$, we write $\mu = \int \mu_u \
, d\lambda(u)$ where $\lambda = \pi_*\mu$ and $\mu_u$ is a measure on $\{u\}\tim
es\mathbb{R} \cong \mathbb{R}$. The translation invariance forces each $\mu_u$ t
o be translation-invariant for $\lambda$-a.e. $u$, hence $\mu_u = c(u)\,dv$ for
some measurable $c(u) \geq 0$. Absorbing $c$ into $\lambda$, we get
$$\mu = \tilde{\lambda} \otimes dv$$
for some Radon measure $\tilde{\lambda}$ on $\mathbb{R}/\mathbb{Z}$ (where $dv$
is Lebesgue measure on $\mathbb{R}$).

**Step 2 (Invariance under scaling).** The element $(2, 0) \in G$ (with $\alpha
= 1, b = 0$) acts by
$$(u, v) \mapsto (u, 2v).$$
(Note: $(2,0) \in \Gamma$, but $\Gamma$ is not normal in $G$, so this action is
**nontrivial** on $G/\Gamma$.)

The pushforward of $\tilde{\lambda} \otimes dv$ under $(u,v) \mapsto (u, 2v)$ is
 $\tilde{\lambda} \otimes \frac{1}{2}\,dv$ (since $v \mapsto 2v$ pushes Lebesgue
 measure to $\frac{1}{2}\,dv$). The $G$-invariance of $\mu$ requires:
$$\tilde{\lambda} \otimes dv = \tilde{\lambda} \otimes \tfrac{1}{2}\,dv.$$

For any $f \in C_c(\mathbb{R}/\mathbb{Z} \times \mathbb{R})$:
$$\int f\,d\tilde{\lambda}\,dv = \frac{1}{2}\int f\,d\tilde{\lambda}\,dv,$$
which forces $\int f\,d\mu = 0$ for all $f$, hence $\mu = 0$.

**Conclusion.** The only $G$-invariant Radon measure on $G/\Gamma$ is the zero m
easure. Therefore $G/\Gamma$ does **not** have a (nonzero) $G$-invariant measure
.

## General principle

This aligns with the classical theorem (Weil): for a closed subgroup $H$ of a lo
cally compact group $G$, the quotient $G/H$ admits a nonzero $G$-invariant Radon
 measure if and only if $\Delta_G|_H = \Delta_H$. Since $\Gamma$ is discrete, $\
Delta_\Gamma \equiv 1$, so the condition becomes $\Delta_G|_\Gamma = 1$. In our
example, $\Delta_G(a,b) = 1/a$, giving $\Delta_G(2^n, 0) = 2^{-n} \neq 1$ for $n
 \neq 0$, so the condition fails.
