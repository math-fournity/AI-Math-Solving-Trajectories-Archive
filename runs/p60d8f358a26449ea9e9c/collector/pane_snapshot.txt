Looking at this problem, I need to find the maximum number of protocols (colors)
 for an $n \times n$ grid where each color interfaces with at most 2 others.

## Key Reformulation

The **color adjacency graph** has colors as vertices, with an edge between two c
olors if some node of one is side-adjacent to a node of the other. The constrain
t says this graph has maximum degree $\leq 2$.

Since the grid is connected, the color adjacency graph (restricted to used color
s) is connected, so it must be a **path** $P_k$ or a **cycle** $C_k$.

## Path Case: $k \leq 2n - 1$

If the color adjacency graph is a path, we need a surjective $f: V(G_{n,n}) \to
\{1, \ldots, k\}$ with $|f(u) - f(v)| \leq 1$ for every edge (a 1-Lipschitz func
tion). The diameter of the $n \times n$ grid is $2(n-1)$, so the range is at mos
t $2(n-1) + 1 = 2n - 1$.

**Achievability:** Set $f(i,j) = i + j$ (0-indexed). Values range from $0$ to $2
(n-1)$, giving $k = 2n - 1$ colors. Adjacent cells differ by exactly 1, so the c
olor adjacency graph is the path $0 - 1 - \cdots - (2n-2)$. ✓

## Cycle Case: $k \geq 5$ gives $k \leq 2n - 1$

For a cycle $C_k$ with $k \geq 5$, we need surjective $f: V(G) \to \mathbb{Z}_k$
 with $f(u) - f(v) \in \{0, \pm 1\} \pmod{k}$ for all edges.

For each edge $e = uv$, define $d(e) \in \{-1, 0, 1\}$ as the unique lift of $f(
u) - f(v) \pmod{k}$ (unique since $k \geq 3$). For any **4-cycle** $C$ in the gr
id, the telescoping sum $\sum_{e \in C} \pm d(e) \equiv 0 \pmod{k}$. This sum li
es in $[-4, 4]$, and for $k \geq 5$, the only multiple of $k$ in this range is *
*0**.

Since the cycle space of the grid is generated by 4-cycles (facial cycles), **ev
ery** cycle has zero winding. Therefore $f$ lifts to $g: V(G) \to \mathbb{Z}$ wi
th $g \pmod{k} = f$ and $|g(u) - g(v)| \leq 1$ for all edges. Then $g$ is 1-Lips
chitz, so $\max g - \min g \leq 2(n-1)$, giving $k \leq 2n - 1$.

## Cycle Case: $k = 4$ can exceed $2n - 1$ for small $n$

For $k = 4$, 4-cycles can have winding $\pm 4 \equiv 0 \pmod{4}$, so the lift ma
y fail. On the $2 \times 2$ grid:
$$\begin{pmatrix} 0 & 1 \\ 3 & 2 \end{pmatrix}$$
Every edge difference is $\pm 1 \pmod{4} \in \{0, \pm 1\} \pmod{4}$. All 4 color
s used; color adjacency graph is $C_4$ (max degree 2). ✓

So $K(2) = 4$ (also $k \leq 4$ since only 4 cells exist).

For $n \geq 3$: $2n - 1 \geq 5 > 4$, so the path construction dominates and $k =
 4$ is irrelevant.

## Summary

$$K(n) = \max(2n - 1,\ 4) \quad \text{for } n \geq 2$$

- $K(2) = \max(3, 4) = 4$
- $K(3) = \max(5, 4) = 5$
- $K(4) = \max(7, 4) = 7$
- $K(5) = \max(9, 4) = 9$

- **$K(5) = 9$:** $f(i,j) = i+j$ gives colors $0,1,\ldots,8$ — all used, path ad
