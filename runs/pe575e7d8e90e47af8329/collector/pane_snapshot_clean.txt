Looking at this problem, I need to find the largest constant $C$ such that the i
nequality holds for all $n$ and all reals $a_i, b_i$.

## Setting Up the Framework

**Notation.** Let $L = \sum_{\text{cyc}}(a_i^2 + b_i^2 - a_i a_{i+1} - b_i b_{i+
1})$ and $R = \sum_{\text{cyc}} a_i(b_{i+1} - b_{i-1})$, with cyclic indices.

**Key observations:**
- $L = \frac{1}{2}\sum_i(a_i - a_{i+1})^2 + \frac{1}{2}\sum_i(b_i - b_{i+1})^2 \
ge 0$, with equality iff all $a_i$ equal and all $b_i$ equal.
- Substituting $b_i \mapsto -b_i$ leaves $L$ unchanged but sends $R \mapsto -R$.
 So the constraint from $R > 0$ (namely $C \le nL/R$) and from $R < 0$ (namely $
C \ge nL/R$) are symmetric, giving $C = \inf_{R>0} \frac{nL}{R}$.
- For $n = 1$: $L = 0, R = 0$. For $n = 2$: $b_{i+1} = b_{i-1}$ always, so $R =
0$. No constraint from $n \le 2$.

## Fourier Analysis (for $n \ge 3$)

Let $\omega = e^{2\pi i/n}$. Write $a_k = \sum_{m} \alpha_m \omega^{mk}$, $b_k =
 \sum_m \beta_m \omega^{mk}$ (real sequences, so $\alpha_{-m} = \overline{\alpha
_m}$, etc.).

**Left side.** Using Parseval and $|1 - \omega^m|^2 = 4\sin^2(\pi m/n)$:
$$L = 2n \sum_{m=0}^{n-1} \sin^2(\pi m/n)\,(|\alpha_m|^2 + |\beta_m|^2).$$

**Right side.** Since $b_{k+1} - b_{k-1} = \sum_m \beta_m \omega^{mk}(\omega^m -
 \omega^{-m}) = \sum_m \beta_m \omega^{mk} \cdot 2i\sin(2\pi m/n)$:
$$R = \sum_k a_k(b_{k+1} - b_{k-1}) = 2ni \sum_m \overline{\alpha_m}\,\beta_m \s
in(2\pi m/n).$$

Pairing conjugate modes $m$ and $n-m$ (using $\overline{\alpha_{n-m}}\,\beta_{n-
m} = \overline{\overline{\alpha_m}\beta_m}$ and $\sin(2\pi(n-m)/n) = -\sin(2\pi
m/n)$), and noting the $m=0$ and (if $n$ even) $m=n/2$ modes vanish since $\sin(
2\pi m/n)=0$:

$$R = -4n \sum_{m=1}^{M} \sin(2\pi m/n)\, d_m, \qquad M = \lfloor(n-1)/2\rfloor,
$$

where $d_m = \operatorname{Im}(\overline{\alpha_m}\beta_m)$. Similarly:
$$L = 4n \sum_{m=1}^{M} \sin^2(\pi m/n)\, s_m, \qquad s_m = |\alpha_m|^2 + |\bet
a_m|^2.$$

## Bounding the Ratio

By AM-GM and the fact that $|\operatorname{Im}(z)| \le |z|$:
$$|d_m| \le |\alpha_m||\beta_m| \le \frac{|\alpha_m|^2 + |\beta_m|^2}{2} = \frac
{s_m}{2},$$
with equality when $|\alpha_m| = |\beta_m|$ and $\overline{\alpha_m}\beta_m$ is
purely imaginary.

Therefore:
$$R \le 4n \sum_m |\sin(2\pi m/n)| \cdot \frac{s_m}{2} = 2n \sum_m |\sin(2\pi m/
n)|\, s_m.$$

Using $\sin(2\pi m/n) = 2\sin(\pi m/n)\cos(\pi m/n)$:
$$\frac{R}{L} \le \frac{\sum_m |\sin(2\pi m/n)|\, s_m}{2\sum_m \sin^2(\pi m/n)\,
 s_m} \le \max_m \frac{|\sin(2\pi m/n)|}{2\sin^2(\pi m/n)} = \max_m |\cot(\pi m/
n)|.$$

For $m = 1, \dots, M$ with $M = \lfloor(n-1)/2\rfloor$, the maximum of $|\cot(\p
i m/n)|$ is at $m = 1$, giving $\cot(\pi/n)$.

**Equality is achieved:** Take $\alpha_1 = 1, \beta_1 = -i$ (and conjugate at $m
 = n-1$), all other modes zero. This gives real sequences $a_k = 2\cos(2\pi k/n)
$, $b_k = 2\sin(2\pi k/n)$.

**Direct verification:** With $a_k = 2\cos(2\pi k/n)$, $b_k = 2\sin(2\pi k/n)$:
- $\sum_k (a_k - a_{k+1})^2 = 8n\sin^2(\pi/n)$, same for $b$, so $L = 8n\sin^2(\
pi/n)$.
- $b_{k+1} - b_{k-1} = 4\cos(2\pi k/n)\sin(2\pi/n)$, so $R = 8\sin(2\pi/n)\sum_k
 \cos^2(2\pi k/n) = 4n\sin(2\pi/n)$.
- $\frac{nL}{R} = \frac{8n^2\sin^2(\pi/n)}{4n\sin(2\pi/n)} = \frac{n\sin(\pi/n)}
{\cos(\pi/n)} = n\tan(\pi/n)$.

## Computing the Infimum

So $C = \inf_{n \ge 3} n\tan(\pi/n)$. Let $f(x) = x\tan(\pi/x)$ for $x > 2$. Set
ting $t = \pi/x$:
$$f'(x) = \tan t - t\sec^2 t = \frac{\sin t\cos t - t}{\cos^2 t} = \frac{\tfrac{
1}{2}\sin(2t) - t}{\cos^2 t}.$$

Since $\sin(2t) < 2t$ for $t > 0$, we have $f'(x) < 0$, so $f$ is strictly decre
asing. Values:
- $n=3$: $3\sqrt{3} \approx 5.196$
- $n=4$: $4$
- $n=5$: $\approx 3.633$
- $n \to \infty$: $n\tan(\pi/n) \to \pi$ (since $\tan u \approx u$ for small $u$
).

Thus $\inf_{n \ge 3} n\tan(\pi/n) = \lim_{n\to\infty} n\tan(\pi/n) = \pi$.

## Verifying $C = \pi$ Works

For $n \ge 3$ and $R > 0$: $\frac{nL}{R} \ge n\tan(\pi/n) > \pi$, so $L > \frac{
\pi}{n}R$.
For $R \le 0$: $L \ge 0 \ge \frac{\pi}{n}R$ (since $\pi/n > 0$).
For $n = 1, 2$: $R = 0$, so $L \ge 0 = \frac{\pi}{n}R$.

## Verifying $C > \pi$ Fails

For any $C > \pi$, choose $n$ large enough that $n\tan(\pi/n) < C$ (possible sin
ce $n\tan(\pi/n) \to \pi$). Then with $a_k = 2\cos(2\pi k/n)$, $b_k = 2\sin(2\pi
 k/n)$, we get $\frac{nL}{R} = n\tan(\pi/n) < C$, violating the inequality.

## Conclusion

The largest constant is:

$$\boxed{C = \pi}$$
