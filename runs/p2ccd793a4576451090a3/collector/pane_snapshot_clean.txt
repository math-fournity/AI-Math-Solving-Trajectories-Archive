### Setup

Let $a = \gcd(y,z)$, $b = \gcd(z,x)$, $c = \gcd(x,y)$. I claim that under $\gcd(
x,y,z)=1$, the numbers $x,y,z$ factor as
$$x = bc,\quad y = ac,\quad z = ab$$
with $a,b,c$ **pairwise coprime** positive integers.

**Proof of claim (prime-by-prime).** For any prime $p$, let $(\alpha,\beta,\gamm
a) = (v_p(x), v_p(y), v_p(z))$. Since $\gcd(x,y,z)=1$, we have $\min(\alpha,\bet
a,\gamma)=0$. The equation $\operatorname{lcm}(x,y,z)=\gcd(x,y)+\gcd(y,z)+\gcd(z
,x)$ gives, $p$-adically:
$$\max(\alpha,\beta,\gamma) = \min(\alpha,\beta)+\min(\beta,\gamma)+\min(\gamma,
\alpha).$$

- If exactly two valuations are $0$ (say $\beta=\gamma=0,\alpha>0$): LHS $=\alph
a$, RHS $=0$, forcing $\alpha=0$ — contradiction. So this cannot occur for any $
p\mid xyz$.
- If exactly one valuation is $0$ (say $\gamma=0$, $\alpha,\beta>0$): LHS $=\max
(\alpha,\beta)$, RHS $=\min(\alpha,\beta)+0+0=\min(\alpha,\beta)$, forcing $\alp
ha=\beta$.

Thus every prime dividing $xyz$ divides **exactly two** of $x,y,z$, with **equal
** valuation in those two. Collecting primes shared by each pair into $a,b,c$ re
spectively gives $x=bc,\,y=ac,\,z=ab$ with $a,b,c$ pairwise coprime. ∎

### Reducing the equation

With $x=bc,\,y=ac,\,z=ab$ and $a,b,c$ pairwise coprime:
$$\operatorname{lcm}(x,y,z)=abc,\qquad \gcd(x,y)+\gcd(y,z)+\gcd(z,x)=c+a+b.$$
So the equation becomes
$$abc = a+b+c.$$

The ordering $x\le y\le z$ gives $bc\le ac\le ab$, i.e. $b\le a$ and $c\le b$, h
ence
$$c \le b \le a.$$

### Bounding

Since $a\ge b\ge c\ge 1$:
$$abc = a+b+c \le a+a+a = 3a \implies bc \le 3.$$

Enumerating all $(c,b)$ with $c\le b$ and $bc\le 3$:

| $(c,b)$ | Equation $abc=a+b+c$ | Solution $a$ | Valid? |
|---|---|---|---|
| $(1,1)$ | $a = a+2$ | none | ✗ |
| $(1,2)$ | $2a = a+3$ | $a=3$ | ✓ ($1\le2\le3$, pairwise coprime) |
| $(1,3)$ | $3a = a+4$ | $a=2 < b=3$ | ✗ (violates $a\ge b$) |
| $(2,1)$ | — | — | ✗ ($c>b$) |
| $(3,1)$ | — | — | ✗ ($c>b$) |

The **unique** solution is $(a,b,c)=(3,2,1)$.

### Recovering $(x,y,z)$

$$x = bc = 2,\quad y = ac = 3,\quad z = ab = 6.$$

**Verification:**
- $\operatorname{lcm}(2,3,6)=6$; $\gcd(2,3)+\gcd(3,6)+\gcd(6,2)=1+3+2=6$. ✓
- $2\le 3\le 6$. ✓
- $\gcd(2,3,6)=1$. ✓

### Conclusion

$S=\{(2,3,6)\}$, so
$$\sum_{(x,y,z)\in S}(x+y+z) = 2+3+6 = \boxed{11}.$$
