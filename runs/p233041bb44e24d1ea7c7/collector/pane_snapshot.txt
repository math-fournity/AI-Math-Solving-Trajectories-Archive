# 解决方案

## 设置

我们有一个由单位正方形瓷砖组成的 $m \times n$ 网格。每块瓷砖的四条边颜色各不相同
，选自 $\{R, Y, B, G\}$。相邻的瓷砖在共享边上颜色必须匹配。四个边界（上、下、左
、右）各自是单色的，且这四个边界颜色各不相同。

设四个边界颜色分别为 $A$（上）、$B$（下）、$C$（左）、$D$（右），其中 $\{A,B,C,D
\} = \{R,Y,B,G\}$。

**符号说明：** 设 $h_k[j]$ 为第 $k$ 行水平边上的第 $j$ 条边颜色（$k = 0, \ldots,
 m$），$v_l[i]$ 为第 $l$ 列垂直边上的第 $i$ 条边颜色（$l = 0, \ldots, n$）。则：

- $h_0[j] = A$，$h_m[j] = B$（上下边界）
- $v_0[i] = C$，$v_n[i] = D$（左右边界）
- 位于 $(i,j)$ 的瓷砖：$\{h_{i-1}[j],\; h_i[j],\; v_{j-1}[i],\; v_j[i]\} = \{A,B
,C,D\}$，且四个元素各不相同。

## 瓷砖类型

由于每块瓷砖恰好包含所有四种颜色，水平对 $\{h_{i-1}[j], h_i[j]\}$ 和垂直对 $\{v_
{j-1}[i], v_j[i]\}$ 将 $\{A,B,C,D\}$ 划分为两个互补的对。共有三种类型：

| 类型 | 水平对 | 垂直对 |
|------|---------------|---------------|
| 1    | $\{A, B\}$    | $\{C, D\}$    |
| 2    | $\{A, C\}$    | $\{B, D\}$    |
| 3    | $\{A, D\}$    | $\{B, C\}$    |

## $m$ 必须为奇数

**沿列的垂直传播：** 固定列 $j$。从 $h_0[j] = A$ 开始。

- **从 $h = A$ 出发：** 三种类型均有效。$h$ 变为 $B$（类型 1）、$C$（类型 2）或
$D$（类型 3）。
- **从 $h = B$ 出发：** 只有类型 1 的水平对 $\{A,B\}$ 包含 $B$。所以 $h$ 必须变
为 $A$。
- **从 $h = C$ 出发：** 只有类型 2 的水平对 $\{A,C\}$ 包含 $C$。所以 $h$ 必须变
为 $A$。
- **从 $h = D$ 出发：** 只有类型 3 的水平对 $\{A,D\}$ 包含 $D$。所以 $h$ 必须变
为 $A$。

因此，颜色序列交替出现：$A, X_1, A, X_2, A, X_3, \ldots$，其中每个 $X_k \in \{B,
 C, D\}$。所有偶数位置均为 $A$；所有奇数位置均可自由选择。

由于 $h_m[j] = B \neq A$，索引 $m$ 必须是**奇数**。这对每一列都成立，且与类型选
择无关。

## $n$ 必须为奇数

由于 $m$ 是奇数，$m-1$ 是偶数，因此 $h_{m-1}[j] = A$ 对所有 $j$ 成立。第 $m$ 行
的瓷砖其上边为 $A$，且需要下边为 $B$。唯一包含 $A$ 和 $B$ 的水平对是类型 1 的 $\
{A, B\}$。因此，**第 $m$ 行的每块瓷砖都必须是类型 1**。

现在考虑第 $m$ 行的垂直传播。所有瓷砖均为类型 1，因此每个垂直对都是 $\{C, D\}$：

$$v_0[m] = C,\; v_1[m] = D,\; v_2[m] = C,\; v_3[m] = D,\; \ldots$$

这以周期 2 交替：当 $j$ 为偶数时 $v_j[m] = C$，当 $j$ 为奇数时 $v_j[m] = D$。我
们需要 $v_n[m] = D$，这要求 **$n$ 为奇数**。

## 充分性：全类型 1 构造

当 $m$ 和 $n$ 均为奇数时，将**每块瓷砖都设为类型 1**：

- **水平：** $h_k[j] = A$（$k$ 为偶数），$h_k[j] = B$（$k$ 为奇数）。由于 $m$ 为
奇数，$h_m[j] = B$。 ✓
- **垂直：** $v_l[i] = C$（$l$ 为偶数），$v_l[i] = D$（$l$ 为奇数）。由于 $n$ 为
奇数，$v_n[i] = D$。 ✓
- **每块瓷砖：** $\{A \text{ 或 } B,\; B \text{ 或 } A,\; C \text{ 或 } D,\; D \
text{ 或 } C\} = \{A,B,C,D\}$，所有颜色各不相同。 ✓

因此，充要条件是：**$m$ 和 $n$ 均为奇数**。

## 计算对数

我们计算满足 $1 \le m \le 100$，$1 \le n \le 100$ 且 $m, n$ 均为奇数的整数对 $(m
, n)$ 的数量。

从 1 到 100 的奇数为 $1, 3, 5, \ldots, 99$：共有 50 个数。

$$\text{总数} = 50 \times 50 = 2500.$$
