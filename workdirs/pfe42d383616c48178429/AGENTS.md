# Problem

A metropolitan city grid is designed as an $n \times n$ square of blocks, where each block is a $1 \times 1$ unit. The grid lines between the blocks are referred to as "street segments." A modern art installation involves placing several large, triangular solar canopies over the grid. 

Each canopy is shaped like an isosceles right triangle with a hypotenuse of length 2. The project mandates that every canopy must be positioned so that all three of its vertices land exactly on the intersections of the street segments. A street segment is considered "covered" if it lies perfectly along any of the three edges of a canopy.

The city planners want to determine which grid sizes $n$ allow for a layout where every single street segment in the entire $n \times n$ grid is covered by the edge of exactly one canopy (no segment can be left uncovered, and no segment can be doubled up).

Let $S$ be the set of all such positive integers $n \le 100$ for which such a perfect covering is mathematically possible. Find the sum of all elements in $S$.
