## Proof

**Setup.** We have an $n \times n$ grid. Entry $f(x,y) \geq 0$ is an integer. Ro
w sums: $\sum_y f(x,y) = n-1$ for each ship $x$. Non-crossing: if $f(x_1,y_1)>0$
 and $f(x_2,y_2)>0$ with $x_1 < x_2$, then $y_1 \leq y_2$.

**Key bijection.** I claim there is a bijection between valid plans and weak com
positions of $n(n-1)$ into $n$ non-negative parts $(c_1, \dots, c_n)$, where $c_
j = \sum_x f(x,j)$ is the column sum (total containers received by warehouse $j$
).

**Forward direction.** Given a valid plan, compute column sums. We have $\sum_j
c_j = \sum_x (n-1) = n(n-1)$, with each $c_j \geq 0$.

**Reverse direction (existence via greedy construction).** Given $(c_1, \dots, c
_n)$ with $\sum c_j = n(n-1)$, construct the plan as follows. Process ships $x =
 1, 2, \dots, n$ in order. Maintain a pointer $p$ to the "current warehouse," st
arting at $p = 1$. For each ship $x$, it must send $n-1$ containers. Starting fr
om warehouse $p$, fill warehouses left to right: ship $x$ sends $\min(n-1 - \tex
t{sent so far},\; c_j - \text{already filled})$ containers to warehouse $j$, adv
ancing $p$ when warehouse $j$ is completely filled. Ship $x$ stops when it has s
ent $n-1$ containers. Set $p$ to the last warehouse ship $x$ touched (ship $x+1$
 starts there).

This produces row sums exactly $n-1$ (each ship sends $n-1$ by construction) and
 column sums exactly $c_j$ (each warehouse receives $c_j$ by construction). The
non-crossing property holds: ship $x+1$ starts at the warehouse where ship $x$ e
nded, so $\max(S_x) \leq \min(S_{x+1})$.

**Reverse direction (uniqueness).** I show any valid non-crossing plan with colu
mn sums $(c_1,\dots,c_n)$ must equal the greedy plan, by induction on the ship n
umber $x$.

For ship $1$: Let $M_1 = \max(S_1)$. Any ship $x > 1$ uses only warehouses $\geq
 M_1$. So for every warehouse $j < M_1$, all containers in column $j$ come from
ship $1$ alone: $f(1,j) = c_j$. Ship $1$ sends $n-1$ total, so $f(1, M_1) = n-1
- \sum_{j < M_1} c_j$. Since $f(1, M_1) \geq 1$ (ship 1 is active at $M_1$) and
$f(1, M_1) \leq c_{M_1}$ (column sum constraint), $M_1$ is the **unique** smalle
st warehouse with $\sum_{j \leq M_1} c_j \geq n-1$. This determines ship $1$'s e
ntire row uniquely — and it matches the greedy assignment.

By induction, assuming ships $1, \dots, x-1$ are uniquely determined (matching g
reedy), the remaining column sums for warehouses $\geq \max(S_{x-1})$ are fixed,
 and the same argument forces ship $x$'s assignment uniquely. $\square$

**Counting.** The number of weak compositions of $n(n-1)$ into $n$ non-negative
parts is:
$$N(n) = \binom{n(n-1) + n - 1}{n - 1} = \binom{n^2 - 1}{n - 1}.$$

**Verification for small cases:**
- $N(1) = \binom{0}{0} = 1$: the only plan is $f(1,1) = 0$. ✓

- $N(3) = \binom{8}{2} = 28$, confirmed by direct dynamic programming enumeratio

$$N(4) = \binom{4^2 - 1}{4 - 1} = \binom{15}{3} = \frac{15 \cdot 14 \cdot 13}{6}
