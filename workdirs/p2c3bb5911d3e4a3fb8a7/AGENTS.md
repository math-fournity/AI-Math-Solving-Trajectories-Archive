# Problem

In a remote mountain range, a rescue team is mapping out three observation outposts—Base A, Base B, and Base C—which form a triangular perimeter. A straight supply trail connects Base A to Base B, measuring exactly 6 kilometers. A secondary straight boundary line connects Base A to Base C, measuring exactly 7 kilometers.

A specialized communications relay, Station X, is positioned on the supply trail (segment AB). From the perspective of an observer at Station X, the angle between the supply trail leading to Base B and the direct path to Base C is exactly 60°.

A technician is sent to install a sensor at Point P along the straight path connecting Base C to Station X. To ensure optimal signal strength, Point P is located at the exact coordinate where a straight line drawn from Base B to the sensor is perpendicular to the boundary line AC. 

If the distance from Base B to the sensor at Point P is 4 kilometers, what is the distance from the sensor at Point P to Base C?
