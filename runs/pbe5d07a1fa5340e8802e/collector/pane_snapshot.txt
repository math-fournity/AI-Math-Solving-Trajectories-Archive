## 求解

将积分转换为极坐标：令 $x = r\cos\theta$，$y = r\sin\theta$，则 $d(x,y) = r\,dr\
,d\theta$，$\sqrt{x^2+y^2} = r$。区域 $D(\varepsilon)$ 变为 $\{(r,\theta): 0 < r
 < \varepsilon,\ 0 \le \theta < 2\pi\}$。

被积函数中的因子 $r$ 与雅可比行列式 $r$ 抵消：

$$\int_{D(\varepsilon)} \frac{1+\sin x+\sin y}{\sqrt{x^2+y^2}}\,d(x,y) = \int_0^
{2\pi}\!\!\int_0^{\varepsilon} \bigl(1+\sin(r\cos\theta)+\sin(r\sin\theta)\bigr)
\,dr\,d\theta.$$

**常数项。**

$$\int_0^{2\pi}\!\!\int_0^{\varepsilon} 1\,dr\,d\theta = 2\pi\,\varepsilon.$$

**正弦项。** 对于任意固定的 $r$，利用泰勒级数 $\sin(r\cos\theta) = \sum_{k=0}^{\
infty} \frac{(-1)^k (r\cos\theta)^{2k+1}}{(2k+1)!}$。每一项都是 $\cos^{2k+1}\the
ta$ 的常数倍，且

$$\int_0^{2\pi} \cos^{2k+1}\theta\,d\theta = 0 \quad\text{对所有 } k\ge 0$$

（$\cos^{2k+1}\theta$ 的奇数次幂在完整周期上积分为零）。该级数对于所有 $r$ 绝对
一致收敛，因此可以逐项积分，得到

$$\int_0^{2\pi} \sin(r\cos\theta)\,d\theta = 0 \quad\text{对所有 } r.$$

根据相同的论证（将 $\cos\theta$ 替换为 $\sin\theta$；$\sin^{2k+1}\theta$ 在 $[0,
2\pi]$ 上积分为零），

$$\int_0^{2\pi} \sin(r\sin\theta)\,d\theta = 0 \quad\text{对所有 } r.$$

因此，两个正弦项对重积分的贡献为零，且

$$\int_{D(\varepsilon)} \frac{1+\sin x+\sin y}{\sqrt{x^2+y^2}}\,d(x,y) = 2\pi\,\
varepsilon.$$

**极限。**

$$\lim_{\varepsilon\to 0}\frac{1}{\varepsilon}\int_{D(\varepsilon)}\frac{1+\sin
x+\sin y}{\sqrt{x^2+y^2}}\,d(x,y) = \lim_{\varepsilon\to 0}\frac{2\pi\,\varepsil
on}{\varepsilon} = 2\pi.$$
