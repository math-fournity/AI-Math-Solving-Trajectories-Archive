# Problem

In a specialized network of 100 industrial servers, each unit has a unique processing speed. Every server must attempt to sync data with every other server exactly once. 

A clandestine group of "saboteur" servers has been programmed with a specific malware script. During a data sync attempt between two servers, the outcome (the "dominant" sync) is determined by the following protocol:
1. If exactly one of the two servers is running the malware script, the server with the script always achieves the dominant sync, regardless of speed.
2. If both servers are running the script, or if neither server is running it, the server with the higher processing speed achieves the dominant sync.

Following the completion of all possible pairings, an audit reveals a statistical anomaly: there are exactly three servers in the network that each achieved a strictly higher total count of dominant syncs than any of the three fastest servers in the entire network.

What is the minimum number of saboteur servers required for this scenario to be possible?
