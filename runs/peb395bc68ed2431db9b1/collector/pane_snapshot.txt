## Solution

We evaluate $I = \int_{0}^{2\pi} e^{\sin t}\,\sin(\cos t + 5t)\,dt$.

**Key observation.** Note that
$$\sin t + i\cos t = i(\cos t - i\sin t) = ie^{-it},$$
so
$$e^{\sin t + i\cos t} = e^{ie^{-it}}.$$

Therefore
$$e^{\sin t}\,e^{i(\cos t + 5t)} = e^{\sin t + i\cos t}\,e^{i5t} = e^{ie^{-it}}\
,e^{i5t},$$
and taking imaginary parts,
$$e^{\sin t}\,\sin(\cos t + 5t) = \operatorname{Im}\!\left(e^{ie^{-it}}\,e^{i5t}
\right).$$

Hence
$$I = \operatorname{Im}\!\int_{0}^{2\pi} e^{ie^{-it}}\,e^{i5t}\,dt.$$

**Expanding via power series.** Since $e^{ie^{-it}} = \sum_{n=0}^{\infty} \frac{
(ie^{-it})^n}{n!} = \sum_{n=0}^{\infty} \frac{i^n\,e^{-int}}{n!}$, we get (justi
fying termwise integration by uniform convergence):

$$\int_{0}^{2\pi} e^{ie^{-it}}\,e^{i5t}\,dt = \sum_{n=0}^{\infty} \frac{i^n}{n!}
\int_{0}^{2\pi} e^{i(5-n)t}\,dt.$$

By orthogonality of exponentials on $[0,2\pi]$:
$$\int_{0}^{2\pi} e^{i(5-n)t}\,dt = \begin{cases} 2\pi & n = 5,\\ 0 & n \neq 5.\
end{cases}$$

So the entire sum collapses to the single term $n=5$:

$$\int_{0}^{2\pi} e^{ie^{-it}}\,e^{i5t}\,dt = \frac{i^5}{5!}\cdot 2\pi = \frac{i
}{120}\cdot 2\pi = \frac{\pi\, i}{60}.$$

**Taking the imaginary part:**
$$I = \operatorname{Im}\!\left(\frac{\pi\, i}{60}\right) = \frac{\pi}{60}.$$

$$\boxed{\displaystyle\int_{0}^{2\pi} e^{\sin t}\,\sin(\cos t + 5t)\,dt = \frac{
\pi}{60}}$$
