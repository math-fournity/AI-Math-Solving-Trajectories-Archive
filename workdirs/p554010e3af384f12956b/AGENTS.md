# Problem

In a remote digital archives facility, a master database contains exactly 10 unique data packets, forming a core set called the "Root Directory." An engineer is tasked with creating a system of "Security Folders" using the data from this Root Directory. 

Each Security Folder must be a distinct collection of one or more data packets from the Root Directory. To ensure the integrity of the file system, the engineer establishes a strict "Non-Overlap Rule" for any two different Security Folders, Folder A and Folder B:
1. Folder A and Folder B must have no data packets in common; or
2. Folder A must be entirely contained within Folder B; or
3. Folder B must be entirely contained within Folder A.

No two folders can contain the exact same set of data packets. What is the maximum number of unique Security Folders the engineer can create while adhering to these structural constraints?
