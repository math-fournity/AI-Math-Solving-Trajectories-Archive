## Proof

**Claim:** $E(\Delta_n) \sim n$ as $n \to \infty$.

### Step 1: Distribution of a single gap

For $X, Y$ i.i.d. uniform on $\{1, \ldots, n\}$, we have $P(|X - Y| = j) = \frac
{2(n-j)}{n^2}$ for $j \geq 1$, and $P(|X-Y|=0) = \frac{1}{n}$. Therefore:

$$P(|X - Y| \geq k) = \sum_{j=k}^{n-1} \frac{2(n-j)}{n^2} = \frac{2}{n^2} \sum_{
m=1}^{n-k} m = \frac{(n-k)(n-k+1)}{n^2}, \quad 1 \leq k \leq n-1.$$

### Step 2: Tail-sum formula

Using the tail-sum identity $E[\Delta_n] = \sum_{k=0}^{n-2} P(\Delta_n > k) = (n
-1) - \sum_{k=0}^{n-2} P(\Delta_n \leq k)$, we substitute $s = n-1-k$ (so $s$ ra
nges from $1$ to $n-1$):

$$E[\Delta_n] = (n-1) - \sum_{s=1}^{n-1} P(\Delta_n \leq n-1-s).$$

Now $P(\Delta_n \leq n-1-s) = P\!\left(\max_i |X_{i+1}-X_i| \leq n-1-s\right) =
P(N_s = 0)$, where

$$N_s = \#\{i \in \{1,\ldots,n-1\} : |X_{i+1} - X_i| \geq n - s\}.$$

### Step 3: Upper bound $E[\Delta_n] \leq n-1$

Since $\Delta_n \leq n-1$ always, $E[\Delta_n] \leq n-1$.

### Step 4: Lower bound via even-index independence

Define events $A_i^{(s)} = \{|X_{i+1} - X_i| \geq n-s\}$ for $i = 1, \ldots, n-1
$. The key observation: **events with even indices are mutually independent**, s
ince $A_{2j}^{(s)}$ depends only on $(X_{2j}, X_{2j+1})$, and these pairs are di
sjoint for different $j$ (all $X_i$ are independent).

There are $\lfloor (n-1)/2 \rfloor$ even indices in $\{1, \ldots, n-1\}$. For $n
 \geq 4$, $\lfloor(n-1)/2\rfloor \geq n/4$. Each event has probability:

$$P(A_i^{(s)}) = \frac{s(s+1)}{n^2} \geq \frac{s^2}{n^2}.$$

Since $P(N_s = 0) \leq P(\text{no even-indexed } A_i^{(s)})$:

$$P(N_s = 0) \leq \prod_{\text{even } i} \left(1 - P(A_i^{(s)})\right) \leq \exp
\!\left(-\sum_{\text{even } i} P(A_i^{(s)})\right) \leq \exp\!\left(-\frac{n}{4}
 \cdot \frac{s^2}{n^2}\right) = e^{-s^2/(4n)}.$$

### Step 5: Bounding the sum

$$\sum_{s=1}^{n-1} P(N_s = 0) \leq \sum_{s=1}^{\infty} e^{-s^2/(4n)} \leq \int_0
^{\infty} e^{-x^2/(4n)}\, dx = 2\sqrt{n} \cdot \frac{\sqrt{\pi}}{2} = \sqrt{\pi
n}.$$

### Step 6: Conclusion

Combining Steps 2 and 5:

$$E[\Delta_n] = (n-1) - \sum_{s=1}^{n-1} P(N_s = 0) \geq (n-1) - \sqrt{\pi n}.$$

Together with the upper bound $E[\Delta_n] \leq n-1$:

$$n - 1 - \sqrt{\pi n} \leq E[\Delta_n] \leq n - 1.$$

Dividing by $n$:

$$1 - \frac{1}{n} - \sqrt{\frac{\pi}{n}} \leq \frac{E[\Delta_n]}{n} \leq 1 - \fr
ac{1}{n} \xrightarrow{n \to \infty} 1.$$

By the squeeze theorem, $\frac{E[\Delta_n]}{n} \to 1$, hence:

$$\boxed{E(\Delta_n) \sim n}$$
