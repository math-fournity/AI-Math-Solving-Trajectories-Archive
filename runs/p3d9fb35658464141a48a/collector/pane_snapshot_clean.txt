## Proof

**Answer leak check:** The problem statement contains no leaked answers, solutio
ns, or solution sketches. Proceeding.

---

We evaluate $I = \displaystyle\int_0^\infty \frac{\sin^2 x}{x^2}\,dx$.

**Step 1: Reformulation.** Using $\sin^2 x = \tfrac{1}{2}(1-\cos 2x)$,
$$I = \frac{1}{2}\int_0^\infty \frac{1-\cos 2x}{x^2}\,dx.$$

Since $\frac{1-\cos 2x}{x^2}$ is even, define
$$J := \int_{-\infty}^{\infty} \frac{1-\cos 2x}{x^2}\,dx = 2\int_0^\infty \frac{
1-\cos 2x}{x^2}\,dx = 4I.$$

**Step 2: Complexification.** Observe $1-\cos 2x = \operatorname{Re}(1 - e^{2ix}
)$. Consider
$$f(z) = \frac{1 - e^{2iz}}{z^2}.$$
Near $z=0$: $1-e^{2iz} = -2iz + 2z^2 + O(z^3)$, so
$$f(z) = \frac{-2i}{z} + 2 + O(z),$$
i.e. $f$ has a **simple pole** at $z=0$ with residue $\operatorname{Res}(f,0) =
-2i$.

For $z = x+iy$ with $y>0$: $|e^{2iz}| = e^{-2y} \le 1$, so $|1-e^{2iz}|\le 2$; $
f$ is analytic in the open upper half-plane $\mathbb{H}$ except at $z=0$.

**Step 3: Contour.** Let $\mathcal{C}$ be the positively-oriented boundary of th
e region $\{z : \varepsilon \le |z| \le R,\ \operatorname{Im} z \ge 0\}$, traver
sed as:
- $\gamma_1$: $[-R,-\varepsilon]$ on the real axis,
- $\gamma_2 = C_\varepsilon$: the upper semicircle $|z|=\varepsilon$ traversed *
*clockwise** (from $-\varepsilon$ to $+\varepsilon$),
- $\gamma_3$: $[\varepsilon, R]$ on the real axis,
- $\gamma_4 = C_R$: the upper semicircle $|z|=R$ traversed **counterclockwise**.

Since $f$ is analytic on and inside $\mathcal{C}$ (the pole at $0$ is excluded),
 Cauchy's theorem gives
$$\int_{\gamma_1} f\,dz + \int_{C_\varepsilon} f\,dz + \int_{\gamma_3} f\,dz + \
int_{C_R} f\,dz = 0. \tag{$\ast$}$$

**Step 4: The large arc $C_R$.** For $z = Re^{i\theta}$, $\theta\in[0,\pi]$:
$$|f(z)| = \frac{|1-e^{2iz}|}{R^2} \le \frac{1+e^{-2R\sin\theta}}{R^2} \le \frac
{2}{R^2}.$$
Hence $\left|\int_{C_R} f\,dz\right| \le \frac{2}{R^2}\cdot \pi R = \frac{2\pi}{
R}\to 0$ as $R\to\infty$.

**Step 5: The small arc $C_\varepsilon$.** Parametrize $z = \varepsilon e^{i\the
ta}$, $\theta:\pi\to 0$ (clockwise). Using the Laurent expansion $f(z) = -2i/z +
 2 + O(z)$:
$$\int_{C_\varepsilon} f\,dz = -2i\int_{C_\varepsilon}\frac{dz}{z} + \int_{C_\va
repsilon}\bigl(2+O(z)\bigr)\,dz.$$
The second integral is $O(\varepsilon)\to 0$. For the first:
$$\int_{C_\varepsilon}\frac{dz}{z} = \int_\pi^0 \frac{i\varepsilon e^{i\theta}}{
\varepsilon e^{i\theta}}\,d\theta = \int_\pi^0 i\,d\theta = -i\pi.$$
Therefore
$$\int_{C_\varepsilon} f\,dz \;\to\; -2i\cdot(-i\pi) = -2\pi \quad\text{as }\var
epsilon\to 0.$$

**Step 6: Take limits in $(\ast)$.** As $\varepsilon\to 0^+$ and $R\to\infty$,
$$\operatorname{PV}\!\int_{-\infty}^{\infty} f(x)\,dx \;-\; 2\pi \;+\; 0 \;=\; 0
,$$
so
$$\operatorname{PV}\!\int_{-\infty}^{\infty} \frac{1-e^{2ix}}{x^2}\,dx = 2\pi.$$

Taking real parts (the imaginary part $\frac{-\sin 2x}{x^2}$ is odd and contribu
tes $0$ in the principal value):
$$\operatorname{PV}\!\int_{-\infty}^{\infty} \frac{1-\cos 2x}{x^2}\,dx = 2\pi.$$

The integrand $\frac{1-\cos 2x}{x^2}$ is continuous at $0$ (with limit $2$) and
decays as $O(x^{-2})$, so the principal value equals the ordinary convergent int
egral:
$$J = \int_{-\infty}^{\infty} \frac{1-\cos 2x}{x^2}\,dx = 2\pi.$$

**Step 7: Conclude.** Since $J = 4I$,
$$I = \frac{J}{4} = \frac{2\pi}{4} = \frac{\pi}{2}.$$

$$\boxed{\displaystyle\int_0^\infty \frac{\sin^2 x}{x^2}\,dx = \frac{\pi}{2}.}$$
