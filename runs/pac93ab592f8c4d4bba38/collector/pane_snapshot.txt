## Solution

**Answer:** The number of partitions of $\mathbb{N}$ into countably many countab
le sets is $2^{\aleph_0}$ (the cardinality of the continuum).

---

**Proof.**

Let $\mathcal{P}$ denote the set of all partitions of $\mathbb{N}$ into countabl
y many countable sets.

**Upper bound: $|\mathcal{P}| \leq 2^{\aleph_0}$.**

Every partition $P \in \mathcal{P}$ can be encoded by a surjection $f: \mathbb{N
} \to \mathbb{N}$, where $f(n)$ is the index of the part containing $n$. Surject
ivity ensures every part is nonempty, yielding countably many parts; each part $
f^{-1}(k)$ is a subset of $\mathbb{N}$, hence countable. The total number of fun
ctions $\mathbb{N} \to \mathbb{N}$ is
$$\aleph_0^{\aleph_0} = 2^{\aleph_0},$$
so $|\mathcal{P}| \leq 2^{\aleph_0}$.

**Lower bound: $|\mathcal{P}| \geq 2^{\aleph_0}$.**

We construct an injection $2^{\mathbb{N}} \hookrightarrow \mathcal{P}$. Fix a bi
jection $\mathbb{N} \cong \mathbb{N} \times \mathbb{N}$, so we partition $\mathb
b{N} \times \mathbb{N}$.

For each binary sequence $f \in 2^{\mathbb{N}}$ (i.e., $f: \mathbb{N} \to \{0,1\
}$), define:
$$A_k^f = \{(k,\, 2m + f(k)) : m \in \mathbb{N}\}, \qquad k \in \mathbb{N},$$
$$B^f = \{(k,\, 2m + 1 - f(k)) : k, m \in \mathbb{N}\}.$$

Set $P_f = \{A_k^f : k \in \mathbb{N}\} \cup \{B^f\}$.

*This is a valid partition of $\mathbb{N} \times \mathbb{N}$:*
- **Pairwise disjointness of the $A_k^f$:** If $k \neq j$, then $A_k^f$ and $A_j
^f$ have different first coordinates, so they are disjoint.
- **Disjointness of $A_k^f$ and $B^f$:** Elements of $A_k^f$ have second coordin
ate $\equiv f(k) \pmod{2}$, while elements of $B^f$ with first coordinate $k$ ha
ve second coordinate $\equiv 1 - f(k) \pmod{2}$. Hence $A_k^f \cap B^f = \emptys
et$.
- **Coverage:** Every $(k, j) \in \mathbb{N} \times \mathbb{N}$ satisfies $j \eq
uiv f(k)$ or $j \equiv 1 - f(k) \pmod{2}$. In the first case $(k,j) \in A_k^f$;
in the second, $(k,j) \in B^f$.
- **Countably many countable parts:** Each $A_k^f$ and $B^f$ is countably infini
te, and there are $\aleph_0 + 1 = \aleph_0$ parts.

*The map $f \mapsto P_f$ is injective:* Suppose $f \neq g$, and pick $k_0$ with
$f(k_0) \neq g(k_0)$. Then $A_{k_0}^f \neq A_{k_0}^g$. We claim $A_{k_0}^f \noti
n P_g$:
- $A_{k_0}^f \neq A_j^g$ for $j \neq k_0$, since $A_{k_0}^f$ contains only eleme
nts with first coordinate $k_0$, while $A_j^g$ contains only elements with first
 coordinate $j$.
- $A_{k_0}^f \neq B^g$, since $B^g$ contains elements with every first coordinat
e, while $A_{k_0}^f$ has only first coordinate $k_0$.
- $A_{k_0}^f \neq A_{k_0}^g$ by choice of $k_0$.

So $A_{k_0}^f \in P_f \setminus P_g$, hence $P_f \neq P_g$.

This injection yields $|\mathcal{P}| \geq |2^{\mathbb{N}}| = 2^{\aleph_0}$.

**Conclusion.** Combining both bounds, $|\mathcal{P}| = 2^{\aleph_0}$.
