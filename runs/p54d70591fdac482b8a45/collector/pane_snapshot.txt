## Proof

The answer is **No** — it is not always possible. We give an explicit counterexa
mple.

**The space and the functional.** Let $X = c_0$, the Banach space of all real se
quences $x = (x_1, x_2, \dots)$ converging to $0$, equipped with the supremum no
rm
$$\|x\|_\infty = \sup_{n \ge 1} |x_n|.$$
Define the linear functional $f : c_0 \to \mathbb{R}$ by
$$f(x) = \sum_{n=1}^{\infty} \frac{x_n}{2^n}.$$

**$f$ is bounded and $\|f\| = 1$.** For every $x \in c_0$,
$$|f(x)| \le \sum_{n=1}^{\infty} \frac{|x_n|}{2^n} \le \|x\|_\infty \sum_{n=1}^{
\infty} \frac{1}{2^n} = \|x\|_\infty,$$
so $\|f\| \le 1$. For the reverse inequality, set $x^{(N)} = (\underbrace{1,\dot
s,1}_{N},0,0,\dots) \in c_0$. Then $\|x^{(N)}\|_\infty = 1$ and
$$f\!\left(x^{(N)}\right) = \sum_{n=1}^{N} \frac{1}{2^n} = 1 - \frac{1}{2^N} \xr
ightarrow[N\to\infty]{} 1,$$
so $\|f\| \ge 1 - 2^{-N}$ for all $N$, hence $\|f\| = 1$.

**No unit vector attains the norm.** Suppose, for contradiction, that some $x \i
n c_0$ satisfies $\|x\|_\infty = 1$ and $f(x) = \|f\| = 1$. Then
$$1 = f(x) = \sum_{n=1}^{\infty} \frac{x_n}{2^n} \le \sum_{n=1}^{\infty} \frac{|
x_n|}{2^n} \le \sum_{n=1}^{\infty} \frac{1}{2^n} = 1.$$
For both inequalities to be equalities we need, term-by-term, $x_n = |x_n| = 1$
for every $n \ge 1$. (Each summand $|x_n|/2^n \le 1/2^n$, and the total equals $
1$ only if every summand equals its upper bound $1/2^n$, forcing $|x_n|=1$; the
first inequality being equality forces $x_n \ge 0$, so $x_n = 1$.)

Thus $x = (1, 1, 1, \dots)$, which does **not** converge to $0$ — contradicting
$x \in c_0$.

**Conclusion.** The bounded linear functional $f$ on the non-zero normed space $
c_0$ has $\|f\| = 1$, yet there is no $x \in c_0$ with $\|x\|_\infty = 1$ and $f
(x) = \|f\|$. Therefore it is **not** always possible to find such a vector.
