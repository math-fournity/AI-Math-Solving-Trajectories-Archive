$$g(t) = \sqrt{(t-7)^2 + \left(\tfrac{t^2}{8}-3\right)^2} \;+\; \frac{t^2}{8}.$$

$$A'(t) = 2(t-7) + \tfrac{t}{2}\!\left(\tfrac{t^2}{8}-3\right) = \frac{t^3 + 8t

Setting $g'(t) = \dfrac{A'(t)}{2\sqrt{A}} + \dfrac{t}{4} = 0$ gives $A'(t) = -\d
frac{t}{2}\sqrt{A}$, i.e. (squaring, with the sign condition $\operatorname{sgn}
 A' = -\operatorname{sgn} t$):

$$4\,A'(t)^2 = t^2\, A(t).$$

Expanding both sides using $A(t) = \tfrac{t^4}{64} + \tfrac{t^2}{4} - 14t + 58$
and $A'(t) = \tfrac{t^3+8t-224}{16}$, and simplifying, yields

Testing $t=7$: $7\cdot343 - 57\cdot49 - 56\cdot7 + 784 = 2401 - 2793 - 392 + 784

$$(t-7)(7t^2 - 8t - 112) = 0,$$
