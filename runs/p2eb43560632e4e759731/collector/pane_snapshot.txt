## Proof

**Definition.** The *Lagrange number* of an irrational $\alpha$ is
$$L(\alpha) = \sup\left\{ c > 0 : \left|\alpha - \tfrac{p}{q}\right| < \tfrac{1}
{c\,q^2} \text{ for infinitely many } \tfrac{p}{q}\right\} = \limsup_{q\to\infty
} \frac{1}{q\,|q\alpha - p|}.$$
The *Lagrange spectrum* $\mathbb{L}$ is the set $\{L(\alpha) : \alpha \in \mathb
b{R}\setminus\mathbb{Q}\}$.

---

**Step 1. The minimum of $\mathbb{L}$ is $\sqrt{5}$ (Hurwitz, 1891).**

Hurwitz's theorem states that for every irrational $\alpha$, the inequality
$$\left|\alpha - \tfrac{p}{q}\right| < \frac{1}{\sqrt{5}\,q^2}$$
has infinitely many rational solutions $p/q$, and the constant $\sqrt{5}$ is bes
t possible: it cannot be replaced by any larger constant, since for $\alpha = \v
arphi = \frac{1+\sqrt{5}}{2}$ (the golden ratio) one has $L(\varphi) = \sqrt{5}$
 exactly. Indeed, the convergents of $\varphi$ are ratios of consecutive Fibonac
ci numbers, and the worst-case (limiting) approximation constant is precisely $\
sqrt{5}$. Hence $\min \mathbb{L} = \sqrt{5}$.

---

**Step 2. The part of $\mathbb{L}$ below $3$ is governed by Markov numbers.**

A *Markov number* is a positive integer $m$ appearing in a positive integer solu
tion of the **Markov equation**
$$x^2 + y^2 + z^2 = 3xyz.$$

The classical theorem of Markov (1879), as refined by Frobenius and later Cusick
–Flahive, establishes:

> **Theorem.** The Lagrange spectrum below $3$ is exactly
> $$\mathbb{L} \cap (-\infty, 3) = \left\{ \sqrt{9 - \tfrac{4}{m^2}} \;\middle|\
; m \text{ is a Markov number} \right\}.$$

The correspondence is via the continued fraction: each Markov number $m$ determi
nes a periodic continued fraction (associated to a solution $(a, m, c)$ of the M
arkov equation), and the Lagrange number of the corresponding quadratic irration
al is $\sqrt{9 - 4/m^2}$.

Since $f(m) = \sqrt{9 - 4/m^2}$ is strictly increasing for $m \geq 1$ and $\lim_
{m\to\infty} f(m) = 3$, the values below $3$ are in bijection with — and ordered
 the same as — the Markov numbers.

---

**Step 3. The first Markov numbers.**

The Markov equation $x^2+y^2+z^2=3xyz$ has the solution $(1,1,1)$. From any solu
tion $(a,b,c)$ with $a\le b\le c$, two new solutions are obtained by the *mutati
on* $(a,b,c)\mapsto(a,b,3ab-c)$, generating the entire **Markov tree**. Verifyin
g directly:

| Triple $(a,b,c)$ | Check $a^2+b^2+c^2 = 3abc$ |
|---|---|
| $(1,1,1)$ | $3 = 3$ ✓ |
| $(1,1,2)$ | $6 = 6$ ✓ |
| $(1,2,5)$ | $30 = 30$ ✓ |
| $(1,5,13)$ | $195 = 195$ ✓ |
| $(2,5,29)$ | $870 = 870$ ✓ |
| $(1,13,34)$ | $1326 = 1326$ ✓ |
| $(1,34,89)$ | $9078 = 9078$ ✓ |
| $(2,29,169)$ | $29406 = 29406$ ✓ |
| $(5,13,194)$ | $37830 = 37830$ ✓ |
| $(1,89,233)$ | $62211 = 62211$ ✓ |

Collecting all distinct entries in ascending order, the first Markov numbers are
:
$$1,\; 2,\; 5,\; 13,\; 29,\; 34,\; 89,\; 169,\; 194,\; 233,\; \ldots$$

---

**Step 4. Computing the first values of $\mathbb{L}$.**

Applying $L_m = \sqrt{9 - 4/m^2} = \sqrt{(9m^2-4)/m^2} = \sqrt{9m^2-4}\,/m$:

| $m$ | $9m^2 - 4$ | $L_m$ | $\approx$ |
|---|---|---|---|
| $1$ | $5$ | $\sqrt{5}$ | $2.2361$ |
| $2$ | $32$ | $\sqrt{8}$ | $2.8284$ |
| $5$ | $221$ | $\sqrt{221}/5$ | $2.9732$ |
| $13$ | $1517$ | $\sqrt{1517}/13$ | $2.9961$ |
| $29$ | $7565$ | $\sqrt{7565}/29$ | $2.9989$ |
| $34$ | $10400$ | $\sqrt{10400}/34 = \tfrac{10\sqrt{26}}{17}$ | $2.9994$ |
| $89$ | $71285$ | $\sqrt{71285}/89$ | $2.99986$ |
| $169$ | $257045$ | $\sqrt{257045}/169$ | $2.99993$ |
| $194$ | $338540$ | $\sqrt{338540}/194$ | $2.99995$ |
| $233$ | $488005$ | $\sqrt{488005}/233$ | $2.99996$ |

All values are strictly increasing (since $f$ is increasing) and approach $3$ fr
om below.

---

**Conclusion.**

The first few values of the Lagrange spectrum $\mathbb{L}$ in ascending order, s
tarting from $\sqrt{5}$, are:

$$\boxed{\sqrt{5},\;\; \sqrt{8},\;\; \frac{\sqrt{221}}{5},\;\; \frac{\sqrt{1517}
}{13},\;\; \frac{\sqrt{7565}}{29},\;\; \frac{\sqrt{10400}}{34},\;\; \frac{\sqrt{
71285}}{89},\;\; \frac{\sqrt{257045}}{169},\;\; \ldots}$$

equivalently written as $\sqrt{9 - 4/m^2}$ for Markov numbers $m = 1, 2, 5, 13,
29, 34, 89, 169, \ldots$, forming a discrete sequence accumulating at $3$ from b
elow.
