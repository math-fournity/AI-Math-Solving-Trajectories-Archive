# Proof: The Set of All True Statements Provable by Induction Has the Same Cardi
nality as ℕ

## Setup and Definitions

Let **S** denote the set of all true statements (about natural numbers) that are
 provable by mathematical induction. We show that |S| = |ℕ|, i.e., **S** is coun
tably infinite.

## Part 1: |S| ≤ |ℕ| (S is at most countable)

A mathematical statement is a finite string of symbols drawn from a finite (or a
t most countable) alphabet — logical connectives, quantifiers, variables, relati
on symbols, function symbols, numerals, and punctuation.

The set of all finite strings over a finite alphabet is countable. This is a sta
ndard result: finite strings can be enumerated by length, and within each length
, lexicographically (a finite product of a finite set is finite). Equivalently,
each finite string maps injectively to a natural number via a Gödel-style encodi
ng.

Therefore, the set of **all** mathematical statements (true or false, provable o
r not) is countable. Since **S** is a subset of this countable set, we have:

$$|S| \leq |\mathbb{N}|.$$

## Part 2: |S| ≥ |ℕ| (S is infinite)

We exhibit an injection from ℕ into **S**, i.e., infinitely many distinct true s
tatements each provable by induction.

For each $k \in \mathbb{N}$, consider the statement:

$$\phi_k \;:=\; \forall n \in \mathbb{N}:\; \sum_{i=0}^{n} k = k \cdot (n+1).$$

**Each $\phi_k$ is true:** The left-hand side sums $k$ exactly $(n+1)$ times, gi
ving $k(n+1)$.

**Each $\phi_k$ is provable by induction on $n$:**
- **Base case** ($n = 0$): $\sum_{i=0}^{0} k = k = k \cdot 1$. ✓
- **Inductive step:** Assume $\sum_{i=0}^{n} k = k(n+1)$. Then
$$\sum_{i=0}^{n+1} k = \left(\sum_{i=0}^{n} k\right) + k = k(n+1) + k = k(n+2).
\quad \checkmark$$

**The $\phi_k$ are pairwise distinct:** If $k_1 \neq k_2$, then $\phi_{k_1}$ and
 $\phi_{k_2}$ are syntactically different statements (they contain different num
erals), so $\phi_{k_1} \neq \phi_{k_2}$.

The map $k \mapsto \phi_k$ is thus an injection $\mathbb{N} \hookrightarrow S$,
giving:

$$|S| \geq |\mathbb{N}|.$$

## Conclusion

Combining both parts:

$$|\mathbb{N}| \leq |S| \leq |\mathbb{N}|.$$

By the Schröder–Bernstein theorem (or directly, since **S** is an infinite subse
t of a countable set), we conclude:

$$|S| = |\mathbb{N}|.$$

**The set of all true statements provable by induction has the same cardinality
as the set of natural numbers.** $\blacksquare$
