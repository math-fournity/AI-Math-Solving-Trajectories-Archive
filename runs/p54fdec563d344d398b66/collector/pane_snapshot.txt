## Proof

We seek integers $n$ with $10^6 \le n \le 10^9$ such that $7 \mid n$ and $n$ is
a perfect square.

**Key observation.** Write $n = j^2$. Since $7$ is prime and $7 \mid j^2$, we mu
st have $7 \mid j$. Thus $j = 7m$ for some positive integer $m$, giving
$$n = 49\,m^2.$$

So the problem reduces to counting integers $m \ge 1$ with
$$10^6 \le 49\,m^2 \le 10^9,$$
i.e.
$$\frac{10^6}{49} \le m^2 \le \frac{10^9}{49}.$$

**Lower bound.** $\frac{10^6}{49} = \frac{1000000}{49} \approx 20408.16$, so $m
\ge \lceil\sqrt{20408.16}\rceil = \lceil 142.85\ldots\rceil = 143$.

Check: $m=143 \Rightarrow 49\cdot 143^2 = 49\cdot 20449 = 1{,}002{,}001 \ge 10^6
$. ✓
Check: $m=142 \Rightarrow 49\cdot 142^2 = 49\cdot 20164 = 988{,}036 < 10^6$. ✗

**Upper bound.** $\frac{10^9}{49} = \frac{1000000000}{49} \approx 20408163.26$,
so $m \le \lfloor\sqrt{20408163.26}\rfloor$.

Compute: $4517^2 = 20{,}403{,}289 \le 20{,}408{,}163.26$ ✓, while $4518^2 = 20{,
}412{,}324 > 20{,}408{,}163.26$ ✗. So $m \le 4517$.

Check: $m=4517 \Rightarrow 49\cdot 4517^2 = 49\cdot 20403289 = 999{,}961{,}161 \
le 10^9$. ✓
Check: $m=4518 \Rightarrow 49\cdot 4518^2 = 49\cdot 20412324 = 1{,}000{,}203{,}8
76 > 10^9$. ✗

**Counting.** The valid values of $m$ are $143, 144, \ldots, 4517$, giving
$$4517 - 143 + 1 = \boxed{4375}.$$

*(Note: the endpoints $10^6 = 1000^2$ and $10^9$ are not multiples of $7$, so in
clusivity of the interval does not affect the count.)*
