$$A = \sin\gamma\cos\theta\sin\alpha = 0.1, \quad B = \sin\gamma\sin\theta\cos\a

$$C = \cos\gamma\cos\theta\sin\beta = 0.3, \quad D = \cos\gamma\sin\theta\cos\be

**Key grouping by $\theta$.** Compute $A^2+C^2$ and $B^2+D^2$:

$$A^2+C^2 = \cos^2\theta\,(\sin^2\gamma\sin^2\alpha + \cos^2\gamma\sin^2\beta) =
 0.01+0.09 = 0.10$$

$$B^2+D^2 = \sin^2\theta\,(\sin^2\gamma\cos^2\alpha + \cos^2\gamma\cos^2\beta) =
 0.04+0.16 = 0.20$$

Define $X = \sin^2\gamma\sin^2\alpha + \cos^2\gamma\sin^2\beta$ and $Y = \sin^2\
gamma\cos^2\alpha + \cos^2\gamma\cos^2\beta$. Then:

$$X + Y = \sin^2\gamma(\sin^2\alpha+\cos^2\alpha) + \cos^2\gamma(\sin^2\beta+\co
s^2\beta) = \sin^2\gamma + \cos^2\gamma = 1$$

So we have the system:
$$\cos^2\theta \cdot X = 0.10, \qquad \sin^2\theta \cdot Y = 0.20, \qquad X+Y=1$
$

**Solving for $\cos^2\theta$.** Let $t = \cos^2\theta$, so $\sin^2\theta = 1-t$.
 Then $X = 0.10/t$ and $Y = 0.20/(1-t)$, and $X+Y=1$ gives:

$$\frac{0.10}{t} + \frac{0.20}{1-t} = 1$$

Multiplying by $t(1-t)$:

$$0.10(1-t) + 0.20\,t = t(1-t)$$
$$0.10 + 0.10\,t = t - t^2$$
$$t^2 - 0.90\,t + 0.10 = 0$$

Applying the quadratic formula:

$$t = \frac{0.90 \pm \sqrt{0.81 - 0.40}}{2} = \frac{0.90 \pm \sqrt{0.41}}{2}$$

Since $\sqrt{0.41} \approx 0.64031$:

$$t_1 = \frac{0.90 + 0.64031}{2} \approx 0.77016, \qquad t_2 = \frac{0.90 - 0.64
