## Setup

sines (setting 2R = 1): a = sin 65°, b = sin 60° = √3/2, c = sin 55°.

Place B = (0,0), C = (a, 0), so A = (c cos 60°, c sin 60°) = (c/2, c√3/2), and M

## Step 1: Find AP from the perimeter condition

Perimeter of ABMP = AB + BM + MP + PA = c + a/2 + MP + AP.
Perimeter of △PMC = PM + MC + PC = PM + a/2 + (AC − AP) = PM + a/2 + b − AP.

Equating: c + AP = b − AP, so **AP = (b − c)/2**.

## Step 2: Parametrize P and compute vectors

Set t = AP/AC = (b−c)/(2b). Then P = (1−t)A + tC, and:

- **PC** = C − P = (1−t)(C − A) = (b+c)/(2b)·(C − A)
- **PM** = M − P = C/2 − (1−t)A − tC = c/(2b)·**u**, where u = (a − (b+c)/2, −(b
+c)√3/2)

Since scalar factors don't affect angles, ∠MPC = angle between **u** and (C − A)
, where C − A = (a − c/2, −c√3/2).

$$\mathbf{u} \times (C-A) = \tfrac{\sqrt{3}}{2}\bigl[-c(a - \tfrac{b+c}{2}) + (b

{2}$$

$$\mathbf{u}\cdot(C-A) = \bigl(a-\tfrac{b+c}{2}\bigr)\bigl(a-\tfrac{c}{2}\bigr)

So $\tan(\angle MPC) = \dfrac{\sqrt{3}\,ab/2}{D}$.
