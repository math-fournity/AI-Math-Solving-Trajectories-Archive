 "splits" some level of products for every infinite prime set $P$.

## Proof

Let $q_1 < q_2 < q_3 < \cdots$ be all primes in order. For a positive integer $m
$, let $b_j(m)$ denote the $j$-th binary digit of $m$ (0-indexed from LSB).

**Definition of $A$.** For squarefree $n > 1$, write $n = q_{i_1} q_{i_2} \cdots
 q_{i_k}$ with $i_1 < i_2 < \cdots < i_k$ and $k \geq 1$. Define:
$$n \in A \iff b_{k-1}(i_1) = 0.$$
For $n = 1$ and non-squarefree $n$, assign membership arbitrarily (irrelevant to
 the argument).

**Claim.** For any infinite set $P$ of primes, there exist $m \in A$ and $n \not
in A$, both products of $k$ distinct elements of $P$ for some $k \geq 1$.

**Proof.** Let $P$ be an infinite set of primes and let $S = \{i : q_i \in P\}$
be the corresponding infinite set of indices. Since $S$ is an infinite set of **
distinct** positive integers, its elements cannot all share the same binary repr
esentation. Therefore, there exists a bit position $j \geq 0$ such that $b_j$ is
 **not constant** on $S$: there exist $a, b \in S$ with $b_j(a) \neq b_j(b)$.

Set $k = j + 1 \geq 1$. Without loss of generality, assume $a < b$ (otherwise sw
ap).

Since $S$ is infinite, $S \cap (a, \infty)$ is infinite, so we can pick $k-1$ in
dices $s_2 < \cdots < s_k$ from it. Define:
$$m = q_a \cdot q_{s_2} \cdots q_{s_k}.$$
This is a product of $k$ distinct primes from $P$, with smallest prime factor $q
_a$ (index $a$), so $\omega(m) = k$ and by definition $m \in A \iff b_{k-1}(a) =
 0$.

Similarly, $S \cap (b, \infty)$ is infinite, so pick $k-1$ indices $t_2 < \cdots
 < t_k$ from it. Define:
$$n = q_b \cdot q_{t_2} \cdots q_{t_k}.$$
This is a product of $k$ distinct primes from $P$, with smallest prime factor $q
_b$ (index $b$), so $n \in A \iff b_{k-1}(b) = 0$.

Since $k - 1 = j$ and $b_j(a) \neq b_j(b)$, exactly one of $b_j(a), b_j(b)$ equa
ls $0$. Hence exactly one of $m, n$ belongs to $A$. Relabeling if necessary, we
have $m \in A$ and $n \notin A$, both products of $k$ distinct elements of $P$.
$\square$

**Key insight:** Each level $k$ examines bit $k-1$ of the *smallest* prime index
. For any infinite $S$, every element can serve as the minimum of some $k$-subse
t (since infinitely many larger elements exist), so level $k$ is monochromatic o
n $S$ iff bit $k-1$ is constant on **all** of $S$. If $S$ were monochromatic on
every level, all bits would be constant on $S$, forcing all elements identical—c
ontradicting $S$ being infinite.
