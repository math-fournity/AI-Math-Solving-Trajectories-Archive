设 $X = Z(2)$，$Y = Z(3) - Z(2)$。由布朗运动的独立增量性，$X$ 与 $Y$ 独立，且
$$X \sim N(0,\,2),\qquad Y \sim N(0,\,1).$$

所求事件为
$$Z(3) > Z(2) > 0 \iff X > 0 \;\text{且}\; X + Y > 0 \iff X > 0,\; Y > -X.$$

令 $U = X/\sqrt{2} \sim N(0,1)$，$V = Y \sim N(0,1)$，二者独立。条件变为
$$U > 0,\qquad \sqrt{2}\,U + V > 0 \iff V > -\sqrt{2}\,U.$$

因此
$$P = \int_{0}^{\infty} \varphi(u)\,\Phi(\sqrt{2}\,u)\,du,$$
其中 $\varphi,\Phi$ 为标准正态的密度与分布函数。

**计算积分** $I(a) = \int_{0}^{\infty}\varphi(u)\,\Phi(au)\,du$。对 $a$ 求导：
$$I'(a) = \int_{0}^{\infty}\varphi(u)\,u\,\varphi(au)\,du = \frac{1}{2\pi}\int_{
0}^{\infty} u\,e^{-(1+a^{2})u^{2}/2}\,du = \frac{1}{2\pi}\cdot\frac{1}{1+a^{2}}.
$$

积分得 $I(a) = \tfrac{1}{2\pi}\arctan(a) + C$。由 $I(0)=\tfrac12\cdot\tfrac12=\t
frac14$ 得 $C=\tfrac14$，故
$$I(a) = \frac14 + \frac{1}{2\pi}\arctan(a).$$

代入 $a=\sqrt{2}$：
$$\boxed{P\bigl(Z(3)>Z(2)>0\bigr) = \frac14 + \frac{1}{2\pi}\arctan(\sqrt{2}) \a
pprox 0.4021.}$$
