## Proof

Let $f(z) = c_1^\top z + b_1$ and $g(z) = c_2^\top z + b_2$. We seek
$$M = \sup_{z \in S} \frac{|f(z)|}{g(z)}, \qquad S = \{z \in \mathbb{R}^n : g(z)
 > 0\},$$
with $c_1 \neq 0$ and $c_2 \neq 0$.

### Key observation

The ratio $\frac{|f(z)|}{g(z)}$ depends on $z$ only through the pair $(c_1^\top
z,\; c_2^\top z)$. Consider the linear map $L:\mathbb{R}^n \to \mathbb{R}^2$, $z
 \mapsto (c_1^\top z,\, c_2^\top z)$. Its image is a subspace $W \subseteq \math
bb{R}^2$.

- If $c_1, c_2$ are **linearly independent**, then $W = \mathbb{R}^2$ (the map i
s surjective).
- If $c_1, c_2$ are **linearly dependent**, then $W$ is a one-dimensional subspa
ce (a line through the origin).

---

### Case 1: $c_1, c_2$ linearly independent

Since $L$ is surjective, for any $(u,v) \in \mathbb{R}^2$ there exists $z$ with
$c_1^\top z = u$ and $c_2^\top z = v$. The constraint $g(z) > 0$ becomes $v > -b
_2$.

Fix any $v_0 > -b_2$ (e.g., $v_0 = -b_2 + 1$) and set $u \to \infty$. Then
$$\frac{|f(z)|}{g(z)} = \frac{|u + b_1|}{v_0 + b_2} \to +\infty.$$
Hence $M = +\infty$.

---

### Case 2: $c_1, c_2$ linearly dependent

Since both are nonzero, there exists a unique $\alpha \in \mathbb{R}\setminus\{0
\}$ with $c_1 = \alpha\, c_2$. Set $t = g(z) = c_2^\top z + b_2 > 0$. Then
$$f(z) = c_1^\top z + b_1 = \alpha\, c_2^\top z + b_1 = \alpha(t - b_2) + b_1 =
\alpha\, t + \underbrace{(b_1 - \alpha\, b_2)}_{\displaystyle=:\,\beta}.$$

As $z$ ranges over $S$, $t = g(z)$ ranges over $(0, +\infty)$ (since $c_2 \neq 0
$, we can achieve any positive value of $g$). Thus
$$M = \sup_{t > 0} \frac{|\alpha\, t + \beta|}{t} = \sup_{t > 0}\left|\alpha + \
frac{\beta}{t}\right|.$$

**Subcase 2a: $\beta = 0$ (i.e., $b_1 = \alpha\, b_2$).** Then $\frac{|\alpha\,
t|}{t} = |\alpha|$ for all $t > 0$, so
$$M = |\alpha| = \frac{\|c_1\|}{\|c_2\|}.$$

**Subcase 2b: $\beta \neq 0$ (i.e., $b_1 \neq \alpha\, b_2$).** As $t \to 0^+$,
$\left|\alpha + \frac{\beta}{t}\right| \geq \frac{|\beta|}{t} - |\alpha| \to +\i
nfty$, so
$$M = +\infty.$$

---

### Unified statement

The condition "$c_1 = \alpha\, c_2$ and $b_1 = \alpha\, b_2$ for some $\alpha$"
is equivalent to saying the affine functions $f$ and $g$ are proportional: $f =
\alpha\, g$. Combining all cases:

$$\boxed{\sup_{z \in S} \frac{|c_1^\top z + b_1|}{c_2^\top z + b_2} = \begin{cas
es} \dfrac{\|c_1\|}{\|c_2\|} & \text{if } \exists\, \alpha \in \mathbb{R}:\; c_1
 = \alpha\, c_2 \text{ and } b_1 = \alpha\, b_2, \\[6pt] +\infty & \text{otherwi
se.} \end{cases}}$$

In words: the supremum is finite **if and only if** the affine function $z \maps
to c_1^\top z + b_1$ is a scalar multiple of $z \mapsto c_2^\top z + b_2$; in th
at case it equals $\|c_1\|/\|c_2\|$. In all other cases the supremum is $+\infty
$.
