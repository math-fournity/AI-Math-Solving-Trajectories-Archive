## Proof

**Setup.** Index the grid cells by $(i,j)$ with $i,j \in \{1,\dots,2016\}$, wher
e $i$ is the row and $j$ is the column. Identify each cell's center with the pos
ition vector $\mathbf{p}_{ij}=(i,j)$. Let $a_{ij}$ be the entry in cell $(i,j)$;
 the values $a_{ij}$ are a permutation of $\{1,2,\dots,2016^2\}$.

**Reformulating the vector sum.** For every ordered pair of distinct cells $(P,Q
)$, a vector $\overrightarrow{PQ}=\mathbf{q}-\mathbf{p}$ is drawn exactly when $
a_P<a_Q$. Equivalently, for every unordered pair $\{P,Q\}$ with $a_P\neq a_Q$, t
he drawn vector points from the smaller value to the larger. Thus the total sum
is

$$\mathbf{V}=\sum_{P\neq Q}\operatorname{sgn}(a_Q-a_P)\,(\mathbf{q}-\mathbf{p}).
$$

We compute the two components separately.

**Row component.** The row index of $P=(i_P,j_P)$ is $i_P$, so

$$V_{\text{row}}=\sum_{P\neq Q}\operatorname{sgn}(a_Q-a_P)\,(i_Q-i_P).$$

Splitting and swapping the dummy labels $P\leftrightarrow Q$ in the first piece,

$$\sum_{P\neq Q}\operatorname{sgn}(a_Q-a_P)\,i_Q=\sum_{Q\neq P}\operatorname{sgn
}(a_P-a_Q)\,i_P=-\sum_{P\neq Q}\operatorname{sgn}(a_Q-a_P)\,i_P,$$

hence

$$V_{\text{row}}=-2\sum_{P\neq Q}\operatorname{sgn}(a_Q-a_P)\,i_P=-2\sum_{P} i_P
\!\left(\sum_{Q\neq P}\operatorname{sgn}(a_Q-a_P)\right).$$

For a cell $P$ holding value $v=a_P$, the number of cells with larger value is $
2016^2-v$ and with smaller value is $v-1$, so

$$\sum_{Q\neq P}\operatorname{sgn}(a_Q-a_P)=(2016^2-v)-(v-1)=2016^2-2v+1.$$

Therefore

$$V_{\text{row}}=-2(2016^2+1)\sum_{P}i_P+4\sum_{P}i_P\,a_P.$$

Now use the equal-row-sum hypothesis. Let $R_i=\sum_{j}a_{ij}$ be the sum of row
 $i$; by assumption $R_i=S$ for all $i$. Since the total is $\sum_{k=1}^{2016^2}
k=\frac{2016^2(2016^2+1)}{2}$ and there are $2016$ rows,

$$S=\frac{2016(2016^2+1)}{2}.$$

Then

$$\sum_{P}i_P\,a_P=\sum_{i=1}^{2016}i\,R_i=S\sum_{i=1}^{2016}i=S\cdot\frac{2016\
cdot 2017}{2},$$

and

$$\sum_{P}i_P=\sum_{i=1}^{2016}\sum_{j=1}^{2016}i=2016\cdot\frac{2016\cdot 2017}
{2}=2016^2\cdot\frac{2017}{2}.$$

Substituting,

$$V_{\text{row}}=-2(2016^2+1)\cdot 2016^2\cdot\frac{2017}{2}+4\cdot S\cdot\frac{
2016\cdot 2017}{2}$$

$$=-(2016^2+1)\cdot 2016^2\cdot 2017+4\cdot\frac{2016(2016^2+1)}{2}\cdot\frac{20
16\cdot 2017}{2}$$

$$=-(2016^2+1)\cdot 2016^2\cdot 2017+(2016^2+1)\cdot 2016^2\cdot 2017=0.$$

**Column component.** The identical calculation with column index $j_P$ in place
 of $i_P$ uses the equal-column-sum hypothesis. Writing $C_j=\sum_i a_{ij}=S$ fo
r every column, the same algebra gives

$$V_{\text{col}}=-2(2016^2+1)\sum_{P}j_P+4\sum_{P}j_P\,a_P=0,$$

since $\sum_P j_P=2016^2\cdot\frac{2017}{2}$ and $\sum_P j_P\,a_P=S\cdot\frac{20
16\cdot 2017}{2}$, exactly as before.

**Conclusion.** Both components vanish, so the sum of all drawn vectors is

$$\boxed{\mathbf{0}}.$$
