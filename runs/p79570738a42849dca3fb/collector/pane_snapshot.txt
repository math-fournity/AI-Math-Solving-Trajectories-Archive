## Solution

**Simplify each term.** Note that
$$\frac{n}{n^2-1} = \frac{n}{(n-1)(n+1)} = \frac{1}{2}\!\left(\frac{1}{n-1}+\fra
c{1}{n+1}\right).$$

So each summand becomes
$$\frac{1}{2}\!\left(\frac{1}{n-1}+\frac{1}{n+1}\right) - \frac{1}{n}.$$

**Sum over $n=2$ to $N$ (with $N=100$).** Writing $H_m = \sum_{k=1}^{m}\frac{1}{
k}$:

$$S_N = \frac{1}{2}\sum_{n=2}^{N}\frac{1}{n-1} + \frac{1}{2}\sum_{n=2}^{N}\frac{
1}{n+1} - \sum_{n=2}^{N}\frac{1}{n}.$$

Re-index:
- $\displaystyle\sum_{n=2}^{N}\frac{1}{n-1} = H_{N-1}$
- $\displaystyle\sum_{n=2}^{N}\frac{1}{n+1} = H_{N+1}-\tfrac{3}{2}$
- $\displaystyle\sum_{n=2}^{N}\frac{1}{n} = H_{N}-1$

Hence
$$S_N = \tfrac{1}{2}H_{N-1} + \tfrac{1}{2}H_{N+1} - H_N + \tfrac{1}{4}.$$

**Telescoping.** Using $H_{N+1}=H_{N-1}+\frac{1}{N}+\frac{1}{N+1}$ and $H_N = H_
{N-1}+\frac{1}{N}$:

$$\tfrac{1}{2}H_{N-1}+\tfrac{1}{2}H_{N+1} = H_{N-1}+\tfrac{1}{2N}+\tfrac{1}{2(N+
1)},$$

so
$$S_N = H_{N-1}+\tfrac{1}{2N}+\tfrac{1}{2(N+1)} - H_{N-1}-\tfrac{1}{N}+\tfrac{1}
{4} = \frac{1}{4} - \frac{1}{2N(N+1)}.$$

**Plug in $N=100$:**
$$S = \frac{1}{4} - \frac{1}{2\cdot100\cdot101} = \frac{1}{4}-\frac{1}{20200} =
\frac{5050-1}{20200} = \frac{5049}{20200}.$$

**Check coprimality.** Factor:
- $5049 = 3^3\cdot 11\cdot 17$
- $20200 = 2^3\cdot 5^2\cdot 101$

No common prime factor, so $\gcd(5049,20200)=1$. Thus $s=5049$, $t=20200$.

$$s+t = 5049+20200 = \boxed{25249}.$$
