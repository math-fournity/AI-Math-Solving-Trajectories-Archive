## Solution

**Setup.** Place D (foot of altitude from A to BC) at the origin, with BC along
the x-axis. Since triangle ABC is acute, D lies between B and C. Then:

- A = (0, h) for some h > 0 (the altitude length),
- B = (−10, 0) since DB = 10,
- C = (c, 0) where c = DC (unknown).

The orthocenter H lies on the altitude from A (the y-axis, x = 0), and since the
 triangle is acute, H is inside the triangle, so H = (0, 10) (using DH = 10, wit
h 0 < 10 < h).

**Finding the orthocenter.** The altitude from B is perpendicular to AC. The slo
pe of AC is −h/c, so the altitude from B has slope c/h and passes through B = (−
10, 0):

$$y = \frac{c}{h}(x + 10).$$

Setting x = 0 (intersection with the altitude from A):

$$y_H = \frac{10c}{h} = 10 \implies \frac{c}{h} = 1 \implies h = c.$$

**Using angle A = 75°.** With h = c, the vectors from A are:

$$\vec{AB} = (-10,\, -h), \qquad \vec{AC} = (h,\, -h).$$

$$\cos 75° = \frac{(-10)(h) + (-h)(-h)}{\sqrt{100+h^2}\cdot h\sqrt{2}} = \frac{h
(h-10)}{h\sqrt{2}\sqrt{100+h^2}} = \frac{h-10}{\sqrt{2}\sqrt{100+h^2}}.$$

Using $\cos 75° = \frac{\sqrt{6}-\sqrt{2}}{4} = \frac{\sqrt{3}-1}{2}\cdot\frac{1
}{\sqrt{2}}\cdot\sqrt{2}\cdot\frac{\sqrt{6}-\sqrt{2}}{4}$... let me simplify dir
ectly:

$$\frac{h-10}{\sqrt{2}\sqrt{100+h^2}} = \frac{\sqrt{6}-\sqrt{2}}{4}.$$

Multiplying through by $\sqrt{2}$:

$$\frac{h-10}{\sqrt{100+h^2}} = \frac{\sqrt{3}-1}{2}.$$

Squaring both sides:

$$(h-10)^2 = \frac{4-2\sqrt{3}}{4}(100+h^2) = \frac{2-\sqrt{3}}{2}(100+h^2).$$

Expanding and multiplying by 2:

$$2h^2 - 40h + 200 = (2-\sqrt{3})(100 + h^2) = 200 - 100\sqrt{3} + 2h^2 - \sqrt{
3}\,h^2.$$

Canceling $2h^2$ and 200:

$$-40h = -100\sqrt{3} - \sqrt{3}\,h^2 \implies \sqrt{3}\,h^2 - 40h + 100\sqrt{3}
 = 0.$$

**Quadratic formula:**

$$h = \frac{40 \pm \sqrt{1600 - 4\cdot\sqrt{3}\cdot 100\sqrt{3}}}{2\sqrt{3}} = \
frac{40 \pm \sqrt{1600 - 1200}}{2\sqrt{3}} = \frac{40 \pm 20}{2\sqrt{3}}.$$

So $h = \frac{60}{2\sqrt{3}} = 10\sqrt{3}$ or $h = \frac{20}{2\sqrt{3}} = \frac{
10\sqrt{3}}{3} \approx 5.77$.

Since H = (0, 10) must lie below A (orthocenter inside the acute triangle), we n
eed h > 10. Only $h = 10\sqrt{3} \approx 17.32$ satisfies this. So:

$$h = 10\sqrt{3}, \qquad c = 10\sqrt{3}.$$

**Verification of angle A.** With h = c = 10√3:

$$\cos A = \frac{300 - 100\sqrt{3}}{20 \cdot 10\sqrt{6}} = \frac{3-\sqrt{3}}{2\s
qrt{6}} = \frac{3(\sqrt{6}-\sqrt{2})}{12} = \frac{\sqrt{6}-\sqrt{2}}{4} = \cos 7
5°. \checkmark$$

**Acute check.** Sides: AB = 20, AC = 10√6, BC = 10 + 10√3. One verifies AB² + A
C² = 1000 > BC² = 400 + 200√3 ≈ 746, and similarly for the other two angles — al
l acute. ✓

**Area.**

$$\text{Area} = \frac{1}{2} \cdot BC \cdot h = \frac{1}{2}\cdot(10 + 10\sqrt{3})
\cdot 10\sqrt{3} = 50\sqrt{3}(1+\sqrt{3}) = 50\sqrt{3} + 150.$$

Using $\sqrt{3} \approx 1.732$:

$$\text{Area} = 150 + 50(1.732) = 150 + 86.6 = 236.6.$$

**Rounded to the nearest integer: 237.**
