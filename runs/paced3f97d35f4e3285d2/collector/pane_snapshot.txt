# Solution

## Setting up the structure

**Claim:** The condition that all transversals have the same sum is equivalent t
o $a_{ij} = r_i + c_j$ for some real numbers $r_1, \ldots, r_n, c_1, \ldots, c_n
$.

*Proof.* If two permutations $\sigma, \sigma'$ differ only by swapping the colum
ns assigned to rows $i$ and $j$ (say $\sigma$ assigns columns $k, l$ and $\sigma
'$ assigns $l, k$), then equal transversal sums give:
$$a_{ik} + a_{jl} = a_{il} + a_{jk}, \quad \text{i.e., } a_{ik} - a_{il} = a_{jk
} - a_{jl}.$$
So $a_{ik} - a_{il}$ is independent of the row $i$. Setting $c_j = a_{1j}$ and $
r_i = a_{i1} - a_{11}$, we get $a_{ij} = r_i + c_j$ (with $r_1 = 0$). Conversely
, if $a_{ij} = r_i + c_j$, every transversal sum equals $\sum r_i + \sum c_j$. $
\square$

## Counting

The representation $a_{ij} = r_i + c_j$ is unique up to shifting $r_i \to r_i +
t,\ c_j \to c_j - t$. We **normalize $r_1 = 0$**, making the representation uniq
ue: $c_j = a_{1j}$ and $r_i = a_{i1} - a_{11}$.

The matrix is then determined by the first row $(c_1, \ldots, c_n) \in \{-1,0,1\
}^n$ and the values $r_2, \ldots, r_n$, subject to $r_i + c_j \in \{-1,0,1\}$ fo
r all $i,j$.

Let $V = \{c_1, \ldots, c_n\}$ (set of distinct values in the first row). For ea
ch $r_i$ ($i \geq 2$), the constraint is $r_i \in \bigcap_{v \in V}(\{-1,0,1\} -
 v)$. The number of valid choices $f(V)$ depends only on $V$:

| $V$ | $f(V)$ | # first rows |
|---|---|---|
| $\{-1\}, \{0\}, \{1\}$ | $3$ | $1$ each |
| $\{-1,0\}, \{0,1\}$ | $2$ | $2^n - 2$ each |
| $\{-1,1\}$ | $1$ | $2^n - 2$ |
| $\{-1,0,1\}$ | $1$ | $3^n - 3\cdot 2^n + 3$ |

(For $|V|=k$, the number of first rows using exactly the values in $V$ is $k^n -
 \binom{k}{k-1}(k-1)^n + \cdots$ by inclusion-exclusion.)

## The formula

$$r(n) = \underbrace{3 \cdot 1 \cdot 3^{n-1}}_{\text{singletons}} + \underbrace{
2(2^n-2)\cdot 2^{n-1} + (2^n-2)\cdot 1}_{\text{pairs}} + \underbrace{(3^n - 3\cd
ot 2^n + 3)\cdot 1}_{\text{triple}}$$

Simplifying:
- Singletons: $3^n$
- Pairs: $(2^n - 2)(2 \cdot 2^{n-1} + 1) = (2^n-2)(2^n+1) = 4^n - 2^n - 2$
- Triple: $3^n - 3\cdot 2^n + 3$

$$r(n) = 3^n + 4^n - 2^n - 2 + 3^n - 3\cdot 2^n + 3 = 4^n + 2\cdot 3^n - 4\cdot
2^n + 1.$$

This matches the given form $a\cdot u^n + b\cdot v^n + c\cdot w^n + d$ with $(u,
v,w)=(4,3,2)$, $(a,b,c,d)=(1,2,-4,1)$, and $u > v > w > 0$. ✓

## Verification

- **$n=1$:** Any $1\times 1$ matrix works, so $r(1) = 3$. Formula: $4+6-8+1 = 3$
. ✓
- **$n=2$:** Direct count: 9 (equal entries) + 4 + 2 + 4 (distinct entries) = 19
. Formula: $16+18-16+1 = 19$. ✓
- **$n=3$:** Direct count: $27 + 24 + 6 + 24 + 6 = 87$. Formula: $64+54-32+1 = 8
7$. ✓

## Final answer

$$r(1) + r(2) + r(3) = 3 + 19 + 87 = \boxed{109}$$
