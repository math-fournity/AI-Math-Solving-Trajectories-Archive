# Solution

**Answer: (C) The graph of $T^{-1}$ is closed.**

## Proof

Recall the graph of $T$ is
$$G(T) = \{(x, Tx) \in X \times Y : x \in X\},$$
and the graph of $T^{-1}$ is
$$G(T^{-1}) = \{(y, T^{-1}y) \in Y \times X : y \in Y\}.$$

**Key observation.** A pair $(y, x)$ belongs to $G(T^{-1})$ if and only if $T^{-
1}y = x$, i.e. $Tx = y$, which holds if and only if $(x, y) \in G(T)$. Hence
$$G(T^{-1}) = \{(y, x) : (x, y) \in G(T)\}.$$

Define the **swap map**
$$S : X \times Y \to Y \times X, \qquad S(x, y) = (y, x).$$

Then $G(T^{-1}) = S(G(T))$.

Equip $X \times Y$ and $Y \times X$ with, say, the product norm $\|(x,y)\| = \|x
\|_X + \|y\|_Y$ (any equivalent product norm works identically). Then
$$\|S(x,y)\|_{Y\times X} = \|y\|_Y + \|x\|_X = \|(x,y)\|_{X\times Y}.$$

So $S$ is a linear **isometric isomorphism** between $X \times Y$ and $Y \times
X$. In particular $S$ is a homeomorphism, and homeomorphisms map closed sets to
closed sets.

Since $G(T)$ is closed in $X \times Y$ by hypothesis, it follows that
$$G(T^{-1}) = S(G(T))$$
is closed in $Y \times X$.

Therefore **(C) is necessarily true.** ∎

## Why the other options are not necessarily true

**(A)** $G(T) = X \times Y$ would require that for every $(x, y)$ we have $y = T
x$, i.e. $Y = \{Tx : x \in X\}$ is a singleton for each $x$ — impossible unless
$Y = \{0\}$. False in general.

**(D) and (B)** The Closed Graph Theorem guarantees continuity only when the dom
ain and codomain are **complete** (Banach / F-spaces). Here $X, Y$ are merely no
rmed spaces, so the theorem does not apply. A concrete counterexample:

Let $E = C[0,1]$, and set $X = (E, \|\cdot\|_1)$ with $\|f\|_1 = \int_0^1 |f|$,
and $Y = (E, \|\cdot\|_\infty)$. Let $T : X \to Y$ be the identity. Then:

- $T$ is bijective and linear.
- $G(T)$ is closed: if $(f_n, f_n) \to (f, g)$ in $X \times Y$, then $\|f_n - f\
|_1 \to 0$ and $\|f_n - g\|_\infty \to 0$. The latter gives $\|f_n - g\|_1 \to 0
$ (since $\|\cdot\|_1 \le \|\cdot\|_\infty$), so $\|f - g\|_1 = 0$, hence $f = g
$ (both continuous), and $(f, g) = (f, f) \in G(T)$.
- Yet $T : (E, \|\cdot\|_1) \to (E, \|\cdot\|_\infty)$ is **not continuous** (e.
g. $f_n$ with tall narrow spikes: $\|f_n\|_1 \to 0$ but $\|f_n\|_\infty = 1$).

So **(D) fails**. Swapping the roles of $X$ and $Y$ (identity from $(E, \|\cdot\
|_\infty)$ to $(E, \|\cdot\|_1)$) gives a case where $T$ is continuous but $T^{-
1}$ is not, so **(B) fails** as well.

Thus only **(C)** is necessarily true.
