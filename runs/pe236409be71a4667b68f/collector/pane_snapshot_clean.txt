## Proof

Let $N$ have digits $d_1 d_2 \cdots d_n$ (with $d_1 \geq 1$). The condition requ
ires that for each $2 \leq i \leq n-1$:
$$d_i < \frac{d_{i-1} + d_{i+1}}{2}, \quad\text{i.e.,}\quad 2d_i < d_{i-1} + d_{
i+1}.$$

**Reformulation.** Define $a_i = d_{i+1} - d_i$ for $i = 1, \ldots, n-1$. The co
ndition $2d_i < d_{i-1} + d_{i+1}$ is equivalent to $a_i > a_{i-1}$, so **the co
nsecutive differences $a_1, a_2, \ldots, a_{n-1}$ are strictly increasing intege
rs**, each in $\{-9, \ldots, 9\}$.

The digits are $d_{k+1} = d_1 + S_k$ where $S_0 = 0$, $S_k = \sum_{i=1}^k a_i$.
All must lie in $[0,9]$ with $d_1 \in [1,9]$.

**Bounding the number of digits.** Since the $a_i$ are strictly increasing, the
partial sums $S_0, S_1, \ldots, S_{n-1}$ form a **convex** sequence (differences
 increasing), so the maximum is at an endpoint. Since $S_0 = 0$: $\min S_k \leq
0$, $\max S_k \geq 0$.

Let $p$ = number of negative $a_i$, $q$ = number of non-negative $a_i$, so $m =
n-1 = p+q$. Set
$$D = \sum_{a_i < 0} |a_i|, \qquad A = \sum_{a_i \geq 0} a_i.$$
The walk descends by $D$ then ascends by $A$; its minimum is $-D$ and $S_m = A -
 D$. The range is
$$R = \max S_k - \min S_k = \max(A, D).$$
All digits fit in $[0,9]$ only if $R \leq 9$ (with a minor extra condition autom
atically satisfied when $p \geq 1$).

The sum of absolute values of $p$ **distinct** negative integers is at least $1+
2+\cdots+p = \frac{p(p+1)}{2}$, so $D \geq \frac{p(p+1)}{2}$. The sum of $q$ **d
istinct** non-negative integers is at least $0+1+\cdots+(q-1) = \frac{q(q-1)}{2}
$, so $A \geq \frac{q(q-1)}{2}$. The constraint $\max(A,D) \leq 9$ gives:
$$\frac{p(p+1)}{2} \leq 9 \implies p \leq 3, \qquad \frac{q(q-1)}{2} \leq 9 \imp
lies q \leq 4.$$
Therefore $m = p + q \leq 7$, hence **$n \leq 8$**.

**Achieving $n = 8$.** For $m = 7$ we need $p = 3$, $q = 4$ with $D = \frac{3\cd
ot4}{2} = 6$ and $A = \frac{4\cdot3}{2} = 6$. The minimal sums are achieved uniq
uely by the difference set $\{-3, -2, -1, 0, 1, 2, 3\}$ — the **only** set of 7
strictly increasing integers satisfying the constraints.

**Maximizing the number.** The partial sums are $S = (0,\, -3,\, -5,\, -6,\, -6,
\, -5,\, -3,\, 0)$, with $\max S_k = 0$ and $\min S_k = -6$. To maximize $d_1$:
we need $d_1 \leq 9 - \max S_k = 9$ and $d_1 \geq \max(1, -\min S_k) = 6$. Setti
ng $d_1 = 9$ yields:
$$d = (9,\; 6,\; 4,\; 3,\; 3,\; 4,\; 6,\; 9), \qquad N = 96433469.$$

**Verification.** The consecutive differences are $-3, -2, -1, 0, 1, 2, 3$ (stri
ctly increasing ✓). Equivalently:
- $d_2 = 6 < \tfrac{9+4}{2} = 6.5$ ✓
- $d_3 = 4 < \tfrac{6+3}{2} = 4.5$ ✓
- $d_4 = 3 < \tfrac{4+3}{2} = 3.5$ ✓
- $d_5 = 3 < \tfrac{3+4}{2} = 3.5$ ✓
- $d_6 = 4 < \tfrac{3+6}{2} = 4.5$ ✓
- $d_7 = 6 < \tfrac{4+9}{2} = 6.5$ ✓

**Uniqueness as the maximum.** The 8-digit configuration is unique (differences
must be exactly $\{-3,-2,-1,0,1,2,3\}$), and $d_1 = 9$ is the unique maximum fir
st digit. No 9-or-more-digit number satisfies the property ($n \leq 8$), and eve
ry 8-digit number with $d_1 < 9$ is smaller.

The greatest natural number possessing the stated property is $\boxed{96433469}$
.
