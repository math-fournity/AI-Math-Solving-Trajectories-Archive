Using standard notation: a = BC = 15, b = CA, c = AB, with angles A, B, C.

**Key formulas:**
- By law of sines: a = 2R sin A → 15 = 18 sin A → **sin A = 5/6**, so cos A = √1

- Centroid distance: **OG² = R² − (a² + b² + c²)/9**
- Median relation: **AG² = (2b² + 2c² − a²)/9**

**Vector analysis** (with O at origin, vectors A, B, C):
- OA · OG = (|A|² + A·B + A·C)/3 = 27(1 + cos 2B + cos 2C)
- AG · OG = 9(2cos 2A − cos 2B − cos 2C)

So the **right angle cannot be at A**. It can be at **O** or at **G**.

## Case 1: Right angle at O

**OG²** = 81 − (225 + 486)/9 = 81 − 79 = **2**, so OG = √2

**Area** = ½·OA·OG = ½·9·√2 = **9√2/2**
