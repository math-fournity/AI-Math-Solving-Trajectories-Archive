## Solution

**Step 1: Recognize the logarithmic derivative structure.**

Let $f(z) = z^6 - 5z^4 + 10$. Then
$$f'(z) = 6z^5 - 20z^3 = 2(3z^5 - 10z^3).$$

Hence the integrand is
$$\frac{3z^5 - 10z^3}{z^6 - 5z^4 + 10} = \frac{1}{2}\cdot\frac{f'(z)}{f(z)}.$$

By the **argument principle**, if $f$ has $N$ zeros inside $C$ (counting multipl
icity) and no poles (since $f$ is a polynomial, it has no poles), then
$$\oint_C \frac{f'(z)}{f(z)}\,dz = 2\pi i\, N.$$

Therefore
$$\int_C \frac{3z^5 - 10z^3}{z^6 - 5z^4 + 10}\,dz = \frac{1}{2}\cdot 2\pi i\, N
= \pi i\, N.$$

It remains to determine $N$, the number of zeros of $f(z) = z^6 - 5z^4 + 10$ ins
ide $|z| = 2$.

**Step 2: Verify no zeros lie on $|z| = 2$.**

On $|z| = 2$:
$$|z^6 - 5z^4| \geq \bigl||z^6| - |5z^4|\bigr| = |64 - 80| = 16 > 10 = |-10|.$$

So $z^6 - 5z^4 + 10 \neq 0$ on $|z| = 2$, confirming the integrand has no poles
on the contour.

**Step 3: Apply Rouché's theorem.**

Write $f(z) = g(z) + h(z)$ with $g(z) = -5z^4$ and $h(z) = z^6 + 10$.

On $|z| = 2$:
- $|g(z)| = 5\cdot 2^4 = 80$,
- $|h(z)| \leq |z|^6 + 10 = 64 + 10 = 74$.

Since $|g(z)| = 80 > 74 \geq |h(z)|$ on $|z| = 2$, Rouché's theorem applies: $f(
z)$ and $g(z)$ have the same number of zeros inside $|z| = 2$.

The function $g(z) = -5z^4$ has a zero of multiplicity $4$ at $z = 0$, so it has
 exactly **4** zeros inside $|z| = 2$ (counting multiplicity).

**Step 4: Conclude.**

$$N = 4, \qquad \int_C \frac{3z^5 - 10z^3}{z^6 - 5z^4 + 10}\,dz = \pi i \cdot 4
= \boxed{4\pi i}.$$
