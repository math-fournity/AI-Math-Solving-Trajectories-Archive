## Proof

**Claim:** Yes, it is possible.

**Construction.** The set of rationals in $[0,1]$ is countable, so enumerate it
as
$$\mathbb{Q}\cap[0,1] = \{q_1, q_2, q_3, \dots\}.$$

Fix $\varepsilon > 0$ with $\varepsilon < \tfrac{1}{2}$ (for instance $\varepsil
on = \tfrac{1}{3}$). For each $i \geq 1$, define the open interval
$$I_i = \left(q_i - \frac{\varepsilon}{2^{i+1}},\; q_i + \frac{\varepsilon}{2^{i
+1}}\right),$$
which has length $\ell(I_i) = \dfrac{\varepsilon}{2^{i}}$.

Now set
$$G = \bigcup_{i=1}^{\infty} I_i.$$

**$G$ is open.** It is a countable union of open intervals, hence open.

**$G$ contains every rational in $[0,1]$.** For every $q_i \in \mathbb{Q}\cap[0,
1]$, we have $q_i \in I_i \subseteq G$.

**The outer measure of $G$ is less than $\tfrac{1}{2}$.** By countable subadditi
vity of Lebesgue outer measure,
$$m^*(G) = m^*\!\left(\bigcup_{i=1}^{\infty} I_i\right) \leq \sum_{i=1}^{\infty}
 m^*(I_i) = \sum_{i=1}^{\infty} \ell(I_i) = \sum_{i=1}^{\infty} \frac{\varepsilo
n}{2^{i}} = \varepsilon.$$

Choosing $\varepsilon = \tfrac{1}{3}$ (or any value in $(0,\tfrac{1}{2})$) gives
$$m^*(G) \leq \frac{1}{3} < \frac{1}{2}.$$

**Remark.** The key fact being exploited is that $\mathbb{Q}\cap[0,1]$ is *count
able*, hence has Lebesgue outer measure $0$. Any set of outer measure $0$ can be
 covered by an open set of arbitrarily small outer measure, by the construction
above. The fact that the rationals are *dense* in $[0,1]$ does not prevent this
— density is a topological property, while outer measure is a metric/measure-the
oretic one, and countable sets always have measure zero regardless of density.
