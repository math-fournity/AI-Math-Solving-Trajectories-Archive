Let $c = f(1)$. We first verify that every constant function is a solution. If $
f \equiv c$, then
$$yf(x)+xf(y) = yc + xc = (x+y)c = (x+y)f(x^2+y^2),$$
so all constant functions $f\equiv c$ ($c\in\mathbb{N}$) work.

It remains to show these are the only solutions. Define $g(x) = f(x) - c$, so $g
:\mathbb{N}\to\mathbb{Z}$ and $g(1)=0$. Substituting $f = g+c$ into the equation
:
$$y(g(x)+c)+x(g(y)+c) = (x+y)(g(x^2+y^2)+c),$$
which simplifies (the $c(x+y)$ terms cancel) to
$$y\,g(x)+x\,g(y) = (x+y)\,g(x^2+y^2). \tag{$\ast$}$$

**Step 1: Two key identities.** Setting $x=y$ in $(\ast)$:
$$xg(x)+xg(x) = 2x\,g(2x^2) \implies g(x) = g(2x^2). \tag{1}$$

Setting $y=1$ in $(\ast)$ and using $g(1)=0$:
$$g(x) = (x+1)\,g(x^2+1). \tag{2}$$

**Step 2: $g(x)$ is divisible by arbitrarily large integers.** Fix any $x\ge 1$.
 Define the sequence $a_0 = x$, $\ a_{n+1} = a_n^2+1$. Since $a_{n+1} = a_n^2+1
> a_n$, the sequence is strictly increasing, so in particular $a_n \to \infty$.

Applying (2) with $x = a_n$ gives $g(a_n) = (a_n+1)\,g(a_{n+1})$, hence by induc
tion
$$g(x) = g(a_0) = \Bigl(\prod_{i=0}^{n-1}(a_i+1)\Bigr)\cdot g(a_n) \qquad\text{f
or all } n\ge 1.$$

Since each $g(a_n) = f(a_n)-c$ is an integer, $g(x)$ is an integer divisible by
$\prod_{i=0}^{n-1}(a_i+1)$ for every $n$.

**Step 3: Conclusion.** Because $a_i \ge a_0 = x \ge 1$, each factor $a_i+1 \ge
2$, and the factors grow without bound (indeed $a_i\to\infty$). Thus $\prod_{i=0
}^{n-1}(a_i+1)\to\infty$ as $n\to\infty$. The only integer divisible by arbitrar
ily large positive integers is $0$. Therefore $g(x)=0$.

Since $x\ge 1$ was arbitrary, $g\equiv 0$, i.e. $f(x) = c$ for all $x\in\mathbb{
N}$.

Combining with the verification above, the solutions are exactly the constant fu
nctions $f\equiv c$ for $c\in\mathbb{N}$.
