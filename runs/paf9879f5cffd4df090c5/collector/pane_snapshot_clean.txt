## 解答

**建立坐标系。** 设正三棱柱的底面为正三角形，边长为 $s$。将底面置于 $xy$ 平面，
顶点为：
- $A = (0, 0)$，$B = (s, 0)$，$C = (s/2,\; s\sqrt{3}/2)$

三个半径为 $r$ 的小球放在下底面上，球心在高度 $r$ 处。每个球恰好转两个侧面（即底
面三角形的两条边）。

**确定三个小球的水平投影位置。** 考虑靠近顶点 $A$ 的球，它接触过 $A$ 的两条边 $A
B$ 和 $AC$。球心投影到这两条边的距离均为 $r$。$A$ 处的内角为 $60°$，角平分线方向
为 $(\cos 30°, \sin 30°) = (\sqrt{3}/2, 1/2)$。沿角平分线距 $A$ 为 $d$ 时，到每
条边的垂直距离为 $d \sin 30° = d/2$。令 $d/2 = r$，得 $d = 2r$。

因此球 $A$ 的球心投影为 $2r(\sqrt{3}/2, 1/2) = (r\sqrt{3},\; r)$。

同理，球 $B$ 的球心投影为 $(s - r\sqrt{3},\; r)$。

**利用球间相切求 $s$。** 两球相切，球心距 $= 2r$：

$$|s - r\sqrt{3} - r\sqrt{3}| = s - 2r\sqrt{3} = 2r \implies s = 2r(1 + \sqrt{3}
)$$

**验证球 $A$ 不接触第三条边 $BC$。** 边 $BC$ 的方程为 $\sqrt{3}\,x + y = \sqrt{3
}\,s$。球 $A$ 投影 $(r\sqrt{3}, r)$ 到 $BC$ 的距离：

$$\frac{|\sqrt{3}\cdot r\sqrt{3} + r - \sqrt{3}\,s|}{2} = \frac{|4r - 2r(\sqrt{3
}+3)|}{2} = r(1+\sqrt{3}) > r \quad \checkmark$$

故每个小球恰好接触两条侧棱面，符合题意。

**第四个球（大球）。** 大球接触全部三个侧棱面，故其球心投影在底面正三角形的内心
（即重心）：

$$\text{内心} = \left(\frac{s}{2},\; \frac{s\sqrt{3}}{6}\right)$$

大球半径 $R$ 等于内心到各边的距离（内切圆半径）：

$$R = \frac{s\sqrt{3}}{6} = \frac{2r(1+\sqrt{3})\sqrt{3}}{6} = \frac{r(3+\sqrt{3
})}{3}$$

**计算内心到小球 $A$ 球心的水平距离。** 代入 $s = 2r(1+\sqrt{3})$：

$$\frac{s}{2} - r\sqrt{3} = r(1+\sqrt{3}) - r\sqrt{3} = r$$

$$\frac{s\sqrt{3}}{6} - r = \frac{r(3+\sqrt{3})}{3} - r = \frac{r\sqrt{3}}{3}$$

水平距离平方 $= r^2 + \frac{r^2}{3} = \frac{4r^2}{3}$，即水平距离 $= \frac{2r\sq
rt{3}}{3}$。

**大球坐在三个小球上。** 设大球球心高度为 $h_c$，小球球心高度为 $r$。大球与小球
外切，球心距 $= R + r$：

$$(h_c - r)^2 + \frac{4r^2}{3} = (R+r)^2$$

$$R + r = \frac{r(3+\sqrt{3})}{3} + r = \frac{r(6+\sqrt{3})}{3}$$

$$(R+r)^2 = \frac{r^2(39 + 12\sqrt{3})}{9}$$

$$(h_c - r)^2 = \frac{r^2(39 + 12\sqrt{3})}{9} - \frac{4r^2}{3} = \frac{r^2(27 +
 12\sqrt{3})}{9} = \frac{r^2(9 + 4\sqrt{3})}{3}$$

$$h_c = r\left(1 + \sqrt{\frac{9 + 4\sqrt{3}}{3}}\right) = r\left(1 + \sqrt{3 +
\frac{4\sqrt{3}}{3}}\right)$$

**棱柱高度 $H$。** 大球接触上底面，故 $H = h_c + R$：

$$H = r\left(1 + \sqrt{3 + \frac{4\sqrt{3}}{3}}\right) + \frac{r(3+\sqrt{3})}{3}
 = r\left(1 + 1 + \frac{\sqrt{3}}{3} + \sqrt{3 + \frac{4\sqrt{3}}{3}}\right)$$

$$\boxed{H = r\left(2 + \frac{\sqrt{3}}{3} + \sqrt{3 + \frac{4\sqrt{3}}{3}}\righ
t)}$$

**与题目形式 $r\!\left(a + \frac{\sqrt{b}}{c} + \sqrt{d + \frac{e\sqrt{f}}{g}}\r
ight)$ 对应：**

| 参数 | 值 |
|------|----|
| $a$ | $2$ |
| $b$ | $3$ |
| $c$ | $3$ |
| $d$ | $3$ |
| $e$ | $4$ |
| $f$ | $3$ |
| $g$ | $3$ |

$$a + b + c + d + e + f + g = 2 + 3 + 3 + 3 + 4 + 3 + 3 = \boxed{21}$$
