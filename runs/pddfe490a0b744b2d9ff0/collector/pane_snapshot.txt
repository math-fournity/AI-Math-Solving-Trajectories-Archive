# Solution

We seek $\sup |P'(0)|$ over all real quadratic polynomials $P$ with $|P(x)|\le 1
$ on $[0,1]$.

## Reduction to $[-1,1]$

Set $t = 2x-1$, so $x\in[0,1]\Leftrightarrow t\in[-1,1]$, and define $Q(t)=P\!\b
ig(\tfrac{t+1}{2}\big)$. Then $Q$ is a real quadratic with $|Q(t)|\le 1$ on $[-1
,1]$, and
$$P'(x)=Q'(t)\cdot\frac{dt}{dx}=2\,Q'(t).$$
At $x=0$ we have $t=-1$, so $P'(0)=2\,Q'(-1)$. It suffices to find $\sup|Q'(-1)|
$.

## Bounding $|Q'(-1)|$ via Lagrange interpolation

Write $Q(t)=at^2+bt+c$. Using the three nodes $t=-1,0,1$ (where $|Q|\le 1$), Lag
range interpolation gives
$$Q(t)=Q(-1)\,\frac{t(t-1)}{2}+Q(0)\,(1-t^2)+Q(1)\,\frac{t(t+1)}{2}.$$
Differentiating and evaluating at $t=-1$:
$$Q'(-1)=-\tfrac{3}{2}\,Q(-1)+2\,Q(0)-\tfrac{1}{2}\,Q(1).$$
Since $|Q(-1)|,|Q(0)|,|Q(1)|\le 1$,
$$|Q'(-1)|\le \tfrac{3}{2}+2+\tfrac{1}{2}=4.$$

## The bound is attained

Take $Q(t)=T_2(t)=2t^2-1$, the Chebyshev polynomial. Then $|T_2(t)|\le 1$ on $[-
1,1]$ (standard fact: $T_2(\cos\theta)=\cos 2\theta$), and
$$T_2(-1)=1,\quad T_2(0)=-1,\quad T_2(1)=1,$$
$$T_2'(-1)=4t\big|_{t=-1}=-4,\qquad |T_2'(-1)|=4.$$
This matches the upper bound, so $\sup|Q'(-1)|=4$.

## Conclusion

$$\sup|P'(0)|=2\sup|Q'(-1)|=2\cdot 4=8.$$

The extremal polynomial is $P(x)=T_2(2x-1)=2(2x-1)^2-1=8x^2-8x+1$, which satisfi
es $P(0)=P(1)=1$, $P(\tfrac12)=-1$, $|P|\le 1$ on $[0,1]$, and $P'(0)=-8$.

$$\boxed{\sup_{P\in V}|P'(0)|=8}$$
