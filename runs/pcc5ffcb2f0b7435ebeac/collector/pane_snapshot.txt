## Proof

**Setup.** An $M$-partition $(A_1, A_2)$ requires both parts to be $M$-free: no
two elements in the same part sum to an element of $M$. This is equivalent to a
proper 2-coloring of the graph $G$ on vertex set $A$ where $\{x, y\}$ is an edge
 iff $x + y \in M$ (with $x \neq y$). The number of $M$-partitions equals the nu
mber of proper 2-colorings of $G$.

**Building the graph.** The edges come from three sum conditions:

- **Sum $2n+1$:** pairs $(i,\; 2n+1-i)$ for $i = 1, \ldots, n$. (Partner in $A$
requires $i \leq 2n$; since $2n+1$ is odd, $i \neq$ partner always.)
- **Sum $4n+3$:** pairs $(i,\; 4n+3-i)$ for $i = 1, \ldots, 2n+1$. (Every vertex
 $v \in A$ has partner $4n+3-v \in A$; $4n+3$ odd so $v \neq$ partner.)
- **Sum $6n+5$:** pairs $(i,\; 6n+5-i)$ for $i = 2n+3, \ldots, 3n+2$. (Partner i
n $A$ requires $2n+3 \leq i \leq 4n+2$; combined with $i < $ partner gives $i \l
eq 3n+2$.)

**Degree analysis.** For each vertex $v \in A$:
- $v \in \{1, \ldots, 2n\}$: has edges from sums $2n+1$ and $4n+3$ → **degree 2*
*.
- $v = 2n+1$: sum $4n+3$ gives partner $2n+2$; sum $2n+1$ gives partner $0 \noti
n A$; sum $6n+5$ gives partner $4n+4 \notin A$ → **degree 1**.
- $v = 2n+2$: sum $4n+3$ gives partner $2n+1$; sum $6n+5$ gives partner $4n+3 \n
otin A$; sum $2n+1$ gives partner $-1 \notin A$ → **degree 1**.
- $v \in \{2n+3, \ldots, 4n+2\}$: has edges from sums $4n+3$ and $6n+5$ → **degr
ee 2**.

Since exactly two vertices have degree 1 and all others have degree 2, $G$ is a
disjoint union of paths and cycles. With exactly two degree-1 vertices, there is
 exactly one path component (and the rest are cycles).

**The path component.** Vertices $2n+1$ and $2n+2$ are each other's only neighbo
r (via sum $4n+3$, since $2n+1 + 2n+2 = 4n+3$). So $\{2n+1, 2n+2\}$ forms an **i
solated edge**.

**The cycle components.** Starting from vertex $i \in \{1, \ldots, n\}$, trace:
$$i \xrightarrow{+2n+1} (2n+1-i) \xrightarrow{+4n+3} (2n+2+i) \xrightarrow{+6n+5
} (4n+3-i) \xrightarrow{+4n+3} i$$

This is a **4-cycle** for each $i \in \{1, \ldots, n\}$. Verification of each ed
ge:
- $i + (2n+1-i) = 2n+1 \in M$ ✓
- $(2n+1-i) + (2n+2+i) = 4n+3 \in M$ ✓
- $(2n+2+i) + (4n+3-i) = 6n+5 \in M$ ✓
- $(4n+3-i) + i = 4n+3 \in M$ ✓

**Coverage check.** As $i$ ranges over $\{1, \ldots, n\}$, the four vertices of
each cycle cover:
- $i$: $\{1, \ldots, n\}$
- $2n+1-i$: $\{n+1, \ldots, 2n\}$
- $2n+2+i$: $\{2n+3, \ldots, 3n+2\}$
- $4n+3-i$: $\{3n+3, \ldots, 4n+2\}$

Together with $\{2n+1, 2n+2\}$, this covers all of $A = \{1, \ldots, 4n+2\}$ exa
ctly once. So $G$ consists of **$n$ disjoint 4-cycles** and **1 isolated edge**.

**Counting proper 2-colorings.** Each connected component contributes independen
tly:
- Each 4-cycle (even cycle) has **2** proper 2-colorings.
- The isolated edge has **2** proper 2-colorings.

Total: $2^n \times 2 = 2^{n+1}$.

**Non-emptiness check.** Every proper 2-coloring of a graph with at least one ed
ge uses both colors (adjacent vertices must differ). Since $G$ has edges, both $
A_1$ and $A_2$ are non-empty in every proper 2-coloring. So all $2^{n+1}$ colori
ngs are valid $M$-partitions.

**Verification with $n=1$:** $A = \{1,...,6\}$, $M = \{3,7,11\}$. The 4-cycle is
 $1{-}2{-}5{-}6{-}1$ (edges: $1{+}2{=}3$, $2{+}5{=}7$, $5{+}6{=}11$, $6{+}1{=}7$
) and the isolated edge is $\{3,4\}$ ($3{+}4{=}7$). This gives $2^2 = 4$ partiti
ons, confirmed by enumeration.

**Conclusion.** The number of $M$-partitions of $A$ is:

$$\boxed{2^{n+1}}$$
