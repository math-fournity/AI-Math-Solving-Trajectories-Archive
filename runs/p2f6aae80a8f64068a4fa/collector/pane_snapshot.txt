rom $B$ meets the midpoint of $CD$, and $CD = 3 \cdot AD$.

## Proof

**Setup.** Place $B$ at the origin. Let $\angle ABC = 2\beta$ with the bisector
along the positive $x$-axis. Set $AB = c$, $BC = a$, and let $t = c/a$ be the de
sired ratio. Then:
$$A = (c\cos\beta,\; c\sin\beta), \quad C = (a\cos\beta,\; -a\sin\beta).$$

**Locating $D$ via the midpoint condition.** The bisector meets $CD$ at its midp
oint $M = (m, 0)$ on the $x$-axis. Since $M = \tfrac{C+D}{2}$:
$$D = 2M - C = (2m - a\cos\beta,\; a\sin\beta).$$

**Applying $\angle BAD = \angle BCD$.** Using $\tan\theta = \frac{|\text{cross}|
}{\text{dot}}$ for each angle:

- $AB \times AD = 2c\sin\beta\,(m - a\cos\beta)$, $\quad AB \cdot AD = c\bigl[-2
m\cos\beta + a\cos 2\beta + c\bigr]$
- $CB \times CD = -2am\sin\beta$, $\quad CB \cdot CD = 2a(a - m\cos\beta)$

Assuming $m > a\cos\beta$ (verified later), the condition $\angle BAD = \angle B
CD$ gives:
$$\frac{2(m - a\cos\beta)}{-2m\cos\beta + a\cos 2\beta + c} = \frac{m}{a - m\cos
\beta}.$$

Cross-multiplying and expanding, the $-2m^2\cos\beta$ terms cancel. Substituting
 $\cos 2\beta = 2\cos^2\beta - 1$, the $2am\cos^2\beta$ terms also cancel, yield
ing:
$$3am - 2a^2\cos\beta = cm \quad\Longrightarrow\quad m = \frac{2a^2\cos\beta}{3a
 - c}.$$

**Applying $CD = 3\cdot AD$.** Normalize $a = 1$, $c = t$, so $m = \frac{2\cos\b
eta}{3 - t}$. Compute:

$$m - \cos\beta = \cos\beta\cdot\frac{t-1}{3-t}, \qquad 2m - (1+t)\cos\beta = \c
os\beta\cdot\frac{(1-t)^2}{3-t}.$$

Then:
$$CD = 2\sqrt{\cos^2\beta\cdot\frac{(1-t)^2}{(3-t)^2} + \sin^2\beta},$$
$$AD = |1-t|\sqrt{\cos^2\beta\cdot\frac{(1-t)^2}{(3-t)^2} + \sin^2\beta}.$$

The expressions under the square roots are **identical**; call this common quant
ity $S > 0$. The condition $CD = 3\cdot AD$ becomes:
$$2\sqrt{S} = 3|1-t|\sqrt{S} \quad\Longrightarrow\quad |1-t| = \frac{2}{3}.$$

So $t = \frac{5}{3}$ or $t = \frac{1}{3}$.

**Eliminating $t = \frac{1}{3}$.** When $t = \frac{1}{3}$, we get $m = \frac{3\c
os\beta}{4} < \cos\beta$, contradicting $m > a\cos\beta$. Redoing the angle cond
ition with the correct sign $|m - a\cos\beta| = \cos\beta - m$ and substituting
$t = 1/3$, $m = \frac{3\cos\beta}{4}$ yields:
$$\frac{\cos\beta}{4}(5 - 3\cos^2\beta) = \frac{\cos\beta}{4} \quad\Longrightarr
ow\quad \cos^2\beta = \frac{4}{3},$$
which is impossible. Hence $t = \frac{1}{3}$ is rejected.

**Verifying $t = \frac{5}{3}$.** With $t = 5/3$: $m = \frac{3\cos\beta}{2}$, so
$m - \cos\beta = \frac{\cos\beta}{2} > 0$ ✓. The vertices become:
$$A = \bigl(\tfrac{5}{3}\cos\beta,\; \tfrac{5}{3}\sin\beta\bigr),\; B = (0,0),\;
 C = (\cos\beta,\; -\sin\beta),\; D = (2\cos\beta,\; \sin\beta).$$

For any $\beta \in (0, \pi/2)$, all consecutive cross products are positive, con
firming convexity. A direct numerical check (e.g., $\beta = 30°$) confirms $\ang
le BAD = \angle BCD \approx 101°$ and $CD/AD = 3$ exactly.

**Conclusion.** The ratio is:

$$\frac{AB}{BC} = \frac{5}{3}.$$
