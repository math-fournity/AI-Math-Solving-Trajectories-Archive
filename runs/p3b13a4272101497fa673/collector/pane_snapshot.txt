## Proof

Let $C \subseteq [0,1]$ denote the standard middle-thirds Cantor set. We recall
three facts:

1. **$C$ is non-empty and perfect** (closed, with no isolated points).
2. **$C$ has Lebesgue measure zero**, since the total length remaining at stage
$n$ of its construction is $(2/3)^n \to 0$.

**Key construction.** Define the "bad" set
$$B \;=\; \mathbb{Q} - C \;=\;\{\,q - c \;:\; q \in \mathbb{Q},\; c \in C\,\} \;
=\; \bigcup_{q\,\in\,\mathbb{Q}} (q - C).$$
Each $q - C$ is a translate of $C$, hence has Lebesgue measure $m(q-C)=m(C)=0$.
Since $\mathbb{Q}$ is countable, by countable subadditivity:
$$m(B) \;\le\; \sum_{q\,\in\,\mathbb{Q}} m(q-C) \;=\; 0.$$
Therefore $B$ has measure zero, so $B \neq \mathbb{R}$, and its complement $\mat
hbb{R}\setminus B$ is non-empty (indeed of full measure).

**Choose** any $\alpha \in \mathbb{R} \setminus B$. Set
$$P \;=\; C + \alpha \;=\;\{\,c + \alpha \;:\; c \in C\,\}.$$

We claim $P$ is the desired set.

**$P$ is non-empty.** Since $C$ is non-empty (e.g. $0 \in C$), $P = C + \alpha$
is non-empty.

**$P$ is perfect.** The map $x \mapsto x + \alpha$ is a homeomorphism of $\mathb
b{R}$. It preserves closedness and the property of having no isolated points. Si
nce $C$ is closed with no isolated points, so is $P = C + \alpha$. Hence $P$ is
perfect.

**$P$ consists only of irrationals.** Suppose for contradiction that $P$ contain
s a rational $q \in \mathbb{Q}$. Then $q = c + \alpha$ for some $c \in C$, givin
g $\alpha = q - c \in \mathbb{Q} - C = B$. This contradicts the choice $\alpha \
notin B$. Therefore $P \cap \mathbb{Q} = \emptyset$, so every element of $P$ is
irrational.

**Conclusion.** $P = C + \alpha$ is a non-empty perfect subset of $\mathbb{R}$ c
onsisting entirely of irrational numbers. $\blacksquare$
