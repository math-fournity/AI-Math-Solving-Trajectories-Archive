## Proof

**Step 1: Derive the key functional equation.**

From $f(x) + g(x) = 2x$, substitute $x \mapsto f(x)$:
$$f(f(x)) + g(f(x)) = 2f(x).$$
Since $g(f(x)) = x$, we get
$$f(f(x)) = 2f(x) - x \quad \text{for all } x. \tag{$\star$}$$

**Step 2: Define $h(x) = f(x) - x$ and establish its invariance.**

Let $h(x) = f(x) - x$. Then $f(x) = x + h(x)$, and $g(x) = 2x - f(x) = x - h(x)$
.

From $(\star)$: $f(f(x)) = f(x) + h(f(x))$, and $2f(x) - x = 2(x + h(x)) - x = x
 + 2h(x)$. Also $f(f(x)) = f(x) + h(f(x)) = x + h(x) + h(f(x))$. Setting equal:
$$x + h(x) + h(f(x)) = x + 2h(x),$$
so
$$h(f(x)) = h(x) \quad \text{for all } x. \tag{1}$$

Since $f$ is a bijection (it has a composition inverse $g$), we can iterate: $h(
f^n(x)) = h(x)$ for all $n \in \mathbb{Z}$.

**Step 3: Establish that $h$ is a strict contraction.**

Since $f$ is strictly increasing, for $x < y$:
$$f(x) < f(y) \implies x + h(x) < y + h(y) \implies h(y) - h(x) > -(y - x). \tag
{2}$$

Since $g = f^{-1}$ is also strictly increasing (the inverse of a strictly increa
sing bijection), for $x < y$:
$$g(x) < g(y) \implies x - h(x) < y - h(y) \implies h(y) - h(x) < y - x. \tag{3}
$$

Combining (2) and (3):
$$|h(y) - h(x)| < |y - x| \quad \text{for all } x \neq y. \tag{4}$$

So $h$ is a **strict** contraction (Lipschitz with constant $< 1$). In particula
r, $h$ is continuous.

**Step 4: The orbit structure.**

From (1), $h$ is constant on each orbit $\{f^n(x) : n \in \mathbb{Z}\}$. Since $
h(f^n(x)) = h(x)$ for all $n$, and $f^n(x) = x + n\,h(x)$ (proved by induction:
$f^{n+1}(x) = f^n(x) + h(f^n(x)) = f^n(x) + h(x)$), the orbit of $x$ is:
$$\mathcal{O}(x) = \{x + n\,h(x) : n \in \mathbb{Z}\}.$$

**Step 5: $h$ must be constant.**

Suppose for contradiction that $h$ is not constant. Then there exist $x, y$ with
 $h(x) = c$, $h(y) = d$, and $c \neq d$.

For every integer $n$, the points $f^n(x) = x + nc$ and $f^n(y) = y + nd$ satisf
y:
- $h(f^n(x)) = c$ and $h(f^n(y)) = d$ (by invariance),
- $f^n(x) \neq f^n(y)$ (since their $h$-values differ).

Applying the strict contraction (4) to the pair $(f^n(x), f^n(y))$:
$$|c - d| = |h(f^n(x)) - h(f^n(y))| < |f^n(x) - f^n(y)| = |(x - y) + n(c - d)|.
\tag{5}$$

Now choose $n^* \in \mathbb{Z}$ to minimize $|(x - y) + n(c - d)|$ over all inte
gers $n$. This minimum is the distance from $x - y$ to the lattice $(c - d)\math
bb{Z}$, which satisfies:
$$\min_{n \in \mathbb{Z}} |(x - y) + n(c - d)| \leq \frac{|c - d|}{2}.$$

Applying (5) with $n = n^*$:
$$|c - d| < \frac{|c - d|}{2}.$$

Since $c \neq d$, $|c - d| > 0$, and dividing gives $1 < \frac{1}{2}$, a **contr
adiction**.

Therefore, $h$ is constant: $h(x) = c_0$ for some constant $c_0 \in \mathbb{R}$
and all $x$.

**Step 6: Conclusion and verification.**

Thus $f(x) = x + c_0$ for some constant $c_0$. We verify:
- **Strictly increasing:** $f(x) = x + c_0$ is strictly increasing. ✓
- **Composition inverse:** $g(x) = x - c_0$, and $f(g(x)) = (x - c_0) + c_0 = x$
, $g(f(x)) = (x + c_0) - c_0 = x$. ✓
- **Sum condition:** $f(x) + g(x) = (x + c_0) + (x - c_0) = 2x$. ✓

Every real constant $c_0$ yields a valid solution, and by Step 5 these are the o
nly ones.
