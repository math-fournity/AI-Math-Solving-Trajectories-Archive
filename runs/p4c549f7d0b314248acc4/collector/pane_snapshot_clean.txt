# Irreducible Representations of SO(3)

## 1. Setup: The Space $\mathcal{H}_\ell$

Let $G = \mathrm{SO}(3)$ act on $\mathbb{R}^3$ in the natural way. This induces
an action on polynomial functions by $(g \cdot f)(v) = f(g^{-1}v)$.

**Definition.** For $\ell \geq 0$, let $\mathcal{H}_\ell$ denote the space of **
homogeneous harmonic polynomials of degree $\ell$** in $(x,y,z)$, i.e., polynomi
als $f$ that are homogeneous of degree $\ell$ and satisfy $\Delta f = 0$, where
$\Delta = \partial_x^2 + \partial_y^2 + \partial_z^2$.

**$\mathcal{H}_\ell$ is $G$-invariant.** Homogeneity is preserved because $G$ ac
ts linearly. Harmonicity is preserved because $\Delta$ is $\mathrm{SO}(3)$-invar
iant: for any rotation $g$, $\Delta(f \circ g^{-1}) = (\Delta f) \circ g^{-1}$,
since $\Delta$ commutes with orthogonal transformations. Hence $g \cdot \mathcal
{H}_\ell \subseteq \mathcal{H}_\ell$.

## 2. Dimension of $\mathcal{H}_\ell$

The space of homogeneous polynomials of degree $\ell$ in 3 variables has dimensi
on $\binom{\ell+2}{2} = \frac{(\ell+1)(\ell+2)}{2}$.

The Laplacian $\Delta$ maps homogeneous polynomials of degree $\ell$ to homogene
ous polynomials of degree $\ell - 2$. This map is **surjective**: for any monomi
al $x^\alpha y^\beta z^\gamma$ of degree $\ell - 2$, one checks inductively (usi
ng $\Delta(r^2 p) = (4\ell - 2)p + r^2 \Delta p$ for $p$ homogeneous of degree $
\ell - 2$, with base case $\Delta(r^2/6) = 1$) that every degree-$(\ell-2)$ poly
nomial lies in the image.

Therefore:
$$\dim \mathcal{H}_\ell = \frac{(\ell+1)(\ell+2)}{2} - \frac{(\ell-1)\ell}{2} =
2\ell + 1.$$

## 3. The Infinitesimal Method: Lie Algebra $\mathfrak{so}(3)$

The Lie algebra $\mathfrak{so}(3)$ consists of $3 \times 3$ real skew-symmetric
matrices. The infinitesimal action on functions gives differential operators. De
fine:

$$L_x = z\,\partial_y - y\,\partial_z, \quad L_y = x\,\partial_z - z\,\partial_x
, \quad L_z = y\,\partial_x - x\,\partial_y.$$

A direct computation of commutators gives:
$$[L_x, L_y] = L_z, \quad [L_y, L_z] = L_x, \quad [L_z, L_x] = L_y,$$
i.e., $[L_i, L_j] = \varepsilon_{ijk} L_k$ — the standard $\mathfrak{so}(3)$ rel
ations. (The sign works out because the action $(g \cdot f)(v) = f(g^{-1}v)$ is
the contragredient, and we chose the signs of $L_i$ accordingly.)

**Complexification and physics convention.** Set $J_k = iL_k$ (so we work over $
\mathbb{C}$). Then:
$$[J_i, J_j] = i\,\varepsilon_{ijk}\, J_k.$$

Define the **ladder operators**:
$$J_+ = J_x + iJ_y, \quad J_- = J_x - iJ_y.$$

The commutation relations become:
$$[J_z, J_+] = J_+, \quad [J_z, J_-] = -J_-, \quad [J_+, J_-] = 2J_z.$$

Thus $J_+$ **raises** the $J_z$-eigenvalue by $1$, and $J_-$ **lowers** it by $1
$.

## 4. The Casimir Operator

Define the **Casimir element** $\mathcal{C} = J_x^2 + J_y^2 + J_z^2 = -(L_x^2 +
L_y^2 + L_z^2)$, which is central in the universal enveloping algebra.

**Key identity.** Let $E = x\partial_x + y\partial_y + z\partial_z$ be the Euler
 operator (which acts as multiplication by $\ell$ on homogeneous polynomials of
degree $\ell$), and $r^2 = x^2 + y^2 + z^2$. Then:

$$L_x^2 + L_y^2 + L_z^2 = r^2 \Delta - E(E+1).$$

*Proof of identity.* Expanding $L_x^2 = (z\partial_y - y\partial_z)^2$ and cycli
cally:
$$L_x^2 + L_y^2 + L_z^2 = (y^2{+}z^2)\partial_x^2 + (x^2{+}z^2)\partial_y^2 + (x
^2{+}y^2)\partial_z^2 - 2yz\,\partial_{yz} - 2xz\,\partial_{xz} - 2xy\,\partial_
{xy} - 2E.$$

Meanwhile $r^2\Delta = (x^2{+}y^2{+}z^2)(\partial_x^2+\partial_y^2+\partial_z^2)
$, so:
$$r^2\Delta - (L_x^2+L_y^2+L_z^2) = x^2\partial_x^2 + y^2\partial_y^2 + z^2\part
ial_z^2 + 2yz\,\partial_{yz} + 2xz\,\partial_{xz} + 2xy\,\partial_{xy} + 2E.$$

Expanding $E^2 = (x\partial_x + y\partial_y + z\partial_z)^2$ gives exactly $x^2
\partial_x^2 + y^2\partial_y^2 + z^2\partial_z^2 + 2yz\,\partial_{yz} + 2xz\,\pa
rtial_{xz} + 2xy\,\partial_{xy} + E$. Hence $r^2\Delta - (L_x^2+L_y^2+L_z^2) = E
^2 + E = E(E+1)$. $\square$

**Consequence.** On $\mathcal{H}_\ell$, we have $E = \ell$ and $\Delta = 0$, so:
$$\boxed{\mathcal{C}\big|_{\mathcal{H}_\ell} = J_x^2 + J_y^2 + J_z^2 = \ell(\ell
+1) \cdot \mathrm{Id}.}$$

(Verification: $\ell=1$: $\mathcal{C}(x) = -2x = -1(2)x$ via $L$'s, so $J^2 = 2
= 1\cdot2$. ✓. $\ell=2$: $\mathcal{C}(x^2-y^2) = -6(x^2-y^2)$, so $J^2 = 6 = 2\c
dot 3$. ✓.)

## 5. Irreducibility of $\mathcal{H}_\ell$

We work over $\mathbb{C}$ (complexify $\mathcal{H}_\ell$). Since $J_z$ is a line
ar operator on the finite-dimensional space $\mathcal{H}_\ell$, it has an eigenv
ector $v$ with $J_z v = m v$.

**Existence of a highest weight vector.** Apply $J_+$ repeatedly: $v, J_+v, J_+^
2 v, \ldots$ have $J_z$-eigenvalues $m, m+1, m+2, \ldots$. Since $\mathcal{H}_\e
ll$ is finite-dimensional, these cannot all be nonzero. So $J_+^N v = 0$ for som
e $N \geq 1$. Set $v_\ell = J_+^{N-1}v$. Then:
$$J_+ v_\ell = 0, \quad J_z v_\ell = (m + N - 1) v_\ell.$$

**Determining the highest weight.** Using $J^2 = J_- J_+ + J_z(J_z + 1)$ (which
follows from $J_-J_+ = J_x^2 + J_y^2 - J_z$):
$$J^2 v_\ell = J_-(\underbrace{J_+ v_\ell}_{=0}) + J_z(J_z+1) v_\ell = (m{+}N{-}
1)(m{+}N) \, v_\ell.$$

But $J^2 = \ell(\ell+1)$ on $\mathcal{H}_\ell$, so $(m{+}N{-}1)(m{+}N) = \ell(\e
ll+1)$. Setting $m_{\max} = m + N - 1$, we get $m_{\max}(m_{\max}+1) = \ell(\ell
+1)$, hence $m_{\max} = \ell$ or $m_{\max} = -(\ell+1)$.

**Ruling out $m_{\max} = -(\ell+1)$.** The lowest weight vector $w = J_-^{k-1} v
_\ell$ (where $k$ is the smallest integer with $J_-^k v_\ell = 0$) has $J_- w =
0$ and $J_z$-eigenvalue $m_{\max} - k + 1$. Using $J^2 = J_+ J_- + J_z(J_z - 1)$
:
$$(m_{\max} - k + 1)(m_{\max} - k) = \ell(\ell+1).$$

So $m_{\max} - k = \ell$ or $-(\ell+1)$. If $m_{\max} = -(\ell+1)$: $m_{\max} -
k = \ell$ gives $k = -(2\ell+1) < 0$ (impossible), and $m_{\max} - k = -(\ell+1)
$ gives $k = 0$ (impossible since $k \geq 1$). Contradiction.

Therefore **$m_{\max} = \ell$**, and $m_{\max} - k = -\ell$, giving $k = 2\ell +
 1$.

**The chain spans $\mathcal{H}_\ell$.** The vectors $v_\ell, J_- v_\ell, J_-^2 v
_\ell, \ldots, J_-^{2\ell} v_\ell$ have distinct $J_z$-eigenvalues $\ell, \ell-1

 Since $\dim \mathcal{H}_\ell = 2\ell + 1$, this subspace is all of $\mathcal{H}
_\ell$.

**Any nonzero submodule must contain a $J_z$-eigenvector, hence a highest weight
 vector, hence the entire chain.** Therefore $\mathcal{H}_\ell$ has no proper no
nzero invariant subspace: **$\mathcal{H}_\ell$ is irreducible.** $\square$

## 6. Explicit Basis (Spherical Harmonics)

The highest weight vector is realized concretely. Consider $(x + iy)^\ell$:
- $J_z(x+iy)^\ell = \ell\,(x+iy)^\ell$ (since $J_z(x+iy) = (x+iy)$),

So $Y_\ell^\ell := (x+iy)^\ell$ is a highest weight vector. The full basis is:
$$Y_\ell^m \propto J_-^{\ell - m}\, Y_\ell^\ell, \quad m = \ell, \ell-1, \ldots,

with $J_z Y_\ell^m = m\, Y_\ell^m$ and $J_\pm Y_\ell^m = \sqrt{\ell(\ell+1) - m(
m\pm 1)}\, Y_\ell^{m\pm 1}$. These are (up to normalization) the **solid spheric
al harmonics**, which form a basis of $\mathcal{H}_\ell$.
