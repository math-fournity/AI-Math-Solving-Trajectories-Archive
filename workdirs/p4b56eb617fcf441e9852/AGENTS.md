# Problem

In a remote industrial facility, a master control panel consists of a 5x5 array of toggle switches. However, due to the system's design, the switches located at the top-left corner and the bottom-right corner are permanently locked and disabled. To fully activate the remaining 23 switches, an engineer must successfully input two sets of codes: five "Horizontal Override" codes (one for each row) and five "Vertical Override" codes (one for each column).

A switch is successfully activated if and only if the engineer provides at least one of its two corresponding codes (the code for its row or the code for its column). To fully boot the system, every single one of the 23 enabled switches must be activated.

Jeffrey, the technician on duty, has exactly a 50% chance of correctly remembering any individual code. If his ability to recall each of the 10 total codes is an independent event, what is the probability that he will be able to activate every unshaded (enabled) switch in the control panel?
