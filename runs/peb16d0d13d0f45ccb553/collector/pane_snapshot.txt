## Setting up the p-adic framework

For a prime p, let a = v_p(L) = ⌊log_p n⌋, and write L = p^a · L' with gcd(L', p
) = 1. Then:

$$L \cdot H_n = \sum_{j=0}^{a} p^{a-j} \cdot T_j, \quad T_j = \sum_{\substack{1
\le m \le \lfloor n/p^j \rfloor \\ \gcd(m,p)=1}} \frac{L'}{m}$$

Each term L'/m is a p-adic unit (coprime to p), so v_p(L·H_n) = v_p(T_a + p·V) w
here V = T_{a-1} + p·T_{a-2} + ⋯.

**Key fact:** v_p(L·H_n) ≥ 1 iff p | T_a iff H_M ≡ 0 (mod p), where M = ⌊n/p^a⌋
and H_M = Σ_{m=1}^M 1/m in 𝔽_p (since T_a = L'·H_M and gcd(L',p)=1).

## Condition for v₅ ≥ 1

Since p^a ≤ n < p^{a+1}, we have M = ⌊n/5^a⌋ ∈ {1,2,3,4}. Computing H_M mod 5:
- M=1: H=1 ≠ 0
- M=2: H=3/2 ≡ 4 ≠ 0
- M=3: H=11/6 ≡ 1 ≠ 0
- M=4: H=25/12 ≡ 0 ✓

So **v₅ ≥ 1 iff M=4**, i.e., n ∈ [4·5^a, 5^{a+1}−1], giving ranges: {4}, [20,24]

## Condition for v₃ ≥ 2

Here M ∈ {1,2}. H_1 mod 3 = 1 ≠ 0; H_2 mod 3 = 1+2 = 3 ≡ 0. So v₃ ≥ 1 requires M
=2 (i.e., n ≥ 2·3^a).

When M=2: T_a = L'(1 + 1/2) = 3L'/2, so T_a/3 = L'/2. Then:

$$v_3(L \cdot H_n) = 1 + v_3\!\left(\tfrac{L'}{2} + V\right)$$

Since V ≡ T_{a-1} (mod 3), and T_{a-1} = L'·S(Q) where Q = ⌊n/3^{a-1}⌋ and S(Q)
= Σ_{gcd(m,3)=1, 1≤m≤Q} 1/m mod 3:

$$v_3 \ge 2 \iff 3 \mid L'\!\left(\tfrac{1}{2} + S(Q)\right) \iff S(Q) \equiv 1
\pmod{3}$$

The 3-adic units pair up as {1,2}, {4,5}, {7,8}, … with each pair summing to 0 m
od 3. So S(Q) ≡ 1 mod 3 iff Q ≡ 1 mod 3 (with Q ≥ 4), i.e., Q ∈ {4, 7}.

- **Q=4** requires n < 5·3^{a-1}, but M=2 requires n ≥ 6·3^{a-1}. Contradiction

- **Q=7** requires n ∈ [7·3^{a-1}, 8·3^{a-1}−1], which is compatible with M=2.

So **v₃ ≥ 2 iff n ∈ [7·3^{a-1}, 8·3^{a-1}−1]** where a = ⌊log₃ n⌋, giving ranges
