**Answer: Yes.** For any two distinct points $x, y \in X$, there exists $f \in \
mathcal{A}$ with $f(x)=0$ and $f(y)=1$.

**Proof.** Endow $\mathcal{C}(X,\mathbb{R})$ with the sup norm, so $\mathcal{A}$
 is dense in $\mathcal{C}(X,\mathbb{R})$.

**Step 1. $\mathcal{A}$ separates points of $X$.** Suppose not: $\exists\, x\neq
 y$ with $f(x)=f(y)$ for all $f\in\mathcal{A}$. The set $\{f\in\mathcal{C}(X,\ma
thbb{R}):f(x)=f(y)\}$ is closed (it is the kernel of the continuous map $f\mapst
o f(x)-f(y)$), so it contains $\overline{\mathcal{A}}=\mathcal{C}(X,\mathbb{R})$
. Hence every continuous function satisfies $f(x)=f(y)$. But the inclusion $\iot
a(t)=t$ is continuous on $X\subseteq\mathbb{R}$ and $\iota(x)=x\neq y=\iota(y)$,
 a contradiction.

**Step 2. $\mathcal{A}$ has no common zero.** If some $x_0\in X$ satisfied $f(x_
0)=0$ for all $f\in\mathcal{A}$, then the closed set $\{f:f(x_0)=0\}$ would cont
ain $\overline{\mathcal{A}}=\mathcal{C}(X,\mathbb{R})$, forcing the constant fun
ction $\mathbf{1}$ to vanish at $x_0$—impossible.

**Step 3. Construct $f$.** Let $x\neq y\in X$. By Step 1, pick $g\in\mathcal{A}$
 with $g(x)\neq g(y)$; set $a=g(x)$, $b=g(y)$, so $a\neq b$.

*Case A: $a\neq 0$ and $b\neq 0$.* Seek a quadratic $q(t)=ct^2+dt$ (zero constan
t term, so $q(g)\in\mathcal{A}$) with $q(a)=0$, $q(b)=1$:
$$ca^2+da=0,\qquad cb^2+db=1.$$
The determinant is $a^2b-ab^2=ab(a-b)\neq 0$ (since $a,b\neq0$, $a\neq b$), so a
 unique solution $(c,d)$ exists. Then $f=q(g)=c\,g^2+d\,g\in\mathcal{A}$, with $
f(x)=q(a)=0$, $f(y)=q(b)=1$. ✓

*Case B: $a=0$ (so $b\neq 0$).* Then $f=g/b\in\mathcal{A}$ satisfies $f(x)=0$, $
f(y)=1$. ✓

*Case C: $b=0$ (so $a\neq 0$); $g$ vanishes at $y$.* By Step 2, pick $h\in\mathc
al{A}$ with $h(y)\neq 0$; rescale so $h(y)=1$. Let $\beta=h(x)$.

- If $\beta=0$: $f=h$ gives $f(x)=0$, $f(y)=1$. ✓
- If $\beta\neq 0,1$: set $s=h^2-h\in\mathcal{A}$. Then $s(y)=1-1=0$ and $s(x)=\
beta^2-\beta=\beta(\beta-1)\neq 0$. Define
$$f=h-\frac{1}{\beta-1}\,s\in\mathcal{A}.$$
Then $f(y)=1-0=1$ and $f(x)=\beta-\frac{1}{\beta-1}\beta(\beta-1)=\beta-\beta=0$
. ✓
- If $\beta=1$: $h(x)=h(y)=1$, so $h$ does not separate $x,y$; use $g$ instead.
Set $u=g/a\in\mathcal{A}$, so $u(x)=1$, $u(y)=0$. Then
$$f=h-u\cdot h\in\mathcal{A},$$
and $f(x)=1-1\cdot1=0$, $f(y)=1-0\cdot1=1$. ✓

In every case we have produced $f\in\mathcal{A}$ with $f(x)=0$ and $f(y)=1$. $\b
lacksquare$
