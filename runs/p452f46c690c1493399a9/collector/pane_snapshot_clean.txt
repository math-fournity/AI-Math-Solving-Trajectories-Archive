Looking at this problem, I need to determine whether a distance-preserving bijec
tion between Riemannian manifolds is necessarily a Riemannian isometry. This is
the **Myers–Steenrod theorem**. The answer is **yes**, and I'll provide a comple
te proof.

---

**Theorem.** *Let $f: M \to N$ be a distance-preserving bijection between connec
ted Riemannian manifolds (without boundary). Then $f$ is a smooth Riemannian iso
metry.*

**Proof.**

**Step 0: Preliminaries.**

Since $f$ preserves distances, $f$ and $f^{-1}$ are both 1-Lipschitz, hence cont
inuous. So $f$ is a homeomorphism, which implies $\dim M = \dim N =: n$.

Throughout, $d_M, d_N$ denote the Riemannian distance functions, and $\exp_p$ de
notes the exponential map at $p$.

**Step 1: $f$ maps minimizing geodesics to minimizing geodesics.**

Let $\gamma: [0,L] \to M$ be a unit-speed minimizing geodesic, so $d_M(\gamma(s)
, \gamma(t)) = |t - s|$ for all $s, t \in [0,L]$. Then $f \circ \gamma$ is a con
tinuous curve in $N$ satisfying
$$d_N(f(\gamma(s)), f(\gamma(t))) = d_M(\gamma(s), \gamma(t)) = |t - s|.$$
The length of $f \circ \gamma$ equals $\sup \sum d_N(f(\gamma(t_i)), f(\gamma(t_
{i+1}))) = \sup \sum |t_{i+1} - t_i| = L$, and the endpoint distance is $d_N(f(\
gamma(0)), f(\gamma(L))) = L$. Hence $f \circ \gamma$ is a minimizing geodesic p
arametrized by arc length.

**Step 2: Construction of $\psi$ and homogeneity.**

Fix $p \in M$. For $v \in T_p M$ sufficiently small, $\gamma_v(t) = \exp_p(tv)$
is a minimizing geodesic for $t \in [0,1]$. By Step 1, $f(\exp_p(tv))$ is a mini
mizing geodesic in $N$ through $f(p)$ with speed $|v|$ (since $d_N(f(p), f(\exp_
p(tv))) = |tv|$). Therefore there exists a unique vector, which we call $\psi(v)
 \in T_{f(p)} N$, with $|\psi(v)| = |v|$, such that
$$f(\exp_p(tv)) = \exp_{f(p)}(t\,\psi(v)), \quad \text{for all small } t.$$

Setting $t = 1$ gives $f(\exp_p(v)) = \exp_{f(p)}(\psi(v))$. Comparing $f(\exp_p
(tv)) = \exp_{f(p)}(\psi(tv))$ with $f(\exp_p(tv)) = \exp_{f(p)}(t\,\psi(v))$, a
nd using injectivity of $\exp_{f(p)}$ on a small ball:
$$\psi(tv) = t\,\psi(v) \quad \text{for all small } t.$$
Thus $\psi$ is **homogeneous** (for all real $t$ with $tv$ in the domain, using
negative $t$ via geodesics extended through $p$).

**Step 3: $\psi$ preserves inner products.**

We use the expansion of squared distance in normal coordinates. Since $g_{ij}(0)
 = \delta_{ij}$ and $\partial_k g_{ij}(0) = 0$ in normal coordinates, for $v, w$
 in a small ball:
$$d_M(\exp_p(v), \exp_p(w))^2 = |v - w|^2 + O\!\left(|v|^2|w|^2 + |v|^4 + |w|^4\
right).$$

Now take unit vectors $u, u' \in T_p M$ (i.e., $|u| = |u'| = 1$) and set $v = ru
$, $w = ru'$ for small $r > 0$. Since $f$ preserves distances:
$$d_N\!\big(\exp_{f(p)}(\psi(ru)),\, \exp_{f(p)}(\psi(ru'))\big)^2 = d_M\!\big(\
exp_p(ru),\, \exp_p(ru')\big)^2.$$

By homogeneity, $\psi(ru) = r\,\psi(u)$ and $\psi(ru') = r\,\psi(u')$. Applying
the distance expansion to both sides:
$$r^2|\psi(u) - \psi(u')|^2 + O(r^4) = r^2|u - u'|^2 + O(r^4).$$

Dividing by $r^2$ and letting $r \to 0$:
$$|\psi(u) - \psi(u')|^2 = |u - u'|^2.$$

Since $|\psi(u)| = |u| = 1$ and $|\psi(u')| = |u'| = 1$, expanding both sides:
$$2 - 2\langle \psi(u), \psi(u') \rangle = 2 - 2\langle u, u' \rangle,$$
so $\langle \psi(u), \psi(u') \rangle = \langle u, u' \rangle$ for all unit vect
ors $u, u'$.

For general $v, w \in T_p M$ (not both zero), by homogeneity:
$$\langle \psi(v), \psi(w) \rangle = |v|\,|w|\,\langle \psi(v/|v|), \psi(w/|w|)
\rangle = |v|\,|w|\,\langle v/|v|, w/|w| \rangle = \langle v, w \rangle.$$
(If $v = 0$ or $w = 0$, both sides are $0$ since $\psi(0) = 0$ by homogeneity.)
Thus **$\psi$ preserves the inner product**.

**Step 4: $\psi$ is linear.**

We show additivity. Using inner product preservation:
$$|\psi(v + w) - \psi(v) - \psi(w)|^2$$
$$= |\psi(v+w)|^2 + |\psi(v)|^2 + |\psi(w)|^2 - 2\langle\psi(v+w),\psi(v)\rangle
 - 2\langle\psi(v+w),\psi(w)\rangle + 2\langle\psi(v),\psi(w)\rangle$$
$$= |v+w|^2 + |v|^2 + |w|^2 - 2\langle v+w, v\rangle - 2\langle v+w, w\rangle +
2\langle v, w\rangle$$
$$= |v+w|^2 - |v|^2 - |w|^2 - 2\langle v, w\rangle + 2|v|^2 + 2|w|^2 + 2\langle
v, w\rangle - 2|v|^2 - 2|w|^2$$

Let me recompute carefully:
$$= |v+w|^2 + |v|^2 + |w|^2 - 2\langle v+w, v\rangle - 2\langle v+w, w\rangle +
2\langle v, w\rangle.$$

Now $|v+w|^2 = |v|^2 + 2\langle v,w\rangle + |w|^2$, $\langle v+w, v\rangle = |v
|^2 + \langle w,v\rangle$, $\langle v+w, w\rangle = \langle v,w\rangle + |w|^2$.
 Substituting:
$$= (|v|^2 + 2\langle v,w\rangle + |w|^2) + |v|^2 + |w|^2 - 2(|v|^2 + \langle v,
w\rangle) - 2(\langle v,w\rangle + |w|^2) + 2\langle v,w\rangle$$
$$= |v|^2 + 2\langle v,w\rangle + |w|^2 + |v|^2 + |w|^2 - 2|v|^2 - 2\langle v,w\
rangle - 2\langle v,w\rangle - 2|w|^2 + 2\langle v,w\rangle$$
$$= 0.$$

Hence $\psi(v + w) = \psi(v) + \psi(w)$. Combined with homogeneity $\psi(tv) = t
\,\psi(v)$, **$\psi$ is linear**.

**Step 5: $f$ is a smooth Riemannian isometry.**

We have shown that for each $p \in M$, there exists a **linear isometry** $\psi_
p: T_p M \to T_{f(p)} N$ such that
$$f(\exp_p(v)) = \exp_{f(p)}(\psi_p(v))$$
for all $v$ in a neighborhood of $0 \in T_p M$. Since $\exp_p$ is a diffeomorphi
sm near $0$ and $\psi_p$ is linear (hence smooth), $f$ is smooth near $p$. The d
ifferential $df_p$ equals $\psi_p$, which is a linear isometry, so $f^* g_N = g_
M$ at $p$.

Since $p$ is arbitrary, $f$ is smooth on all of $M$ and $f^* g_N = g_M$ everywhe
re. Since $f$ is a bijection and $df_p$ is invertible at every $p$, the inverse
function theorem gives that $f$ is a local diffeomorphism; being bijective, $f$
is a global diffeomorphism.

Therefore $f$ is a **Riemannian isometry**. $\blacksquare$

**Conclusion:** Yes, a distance-preserving bijection between Riemannian manifold
s is a Riemannian isometry. This is the content of the Myers–Steenrod theorem (1
939).
