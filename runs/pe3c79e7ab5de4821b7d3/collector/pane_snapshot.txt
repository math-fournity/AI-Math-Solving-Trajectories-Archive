## Proof

**Setup.** Every element of $U(3, F)$ has the form
$$g(a,b,c) = \begin{pmatrix} 1 & a & b \\ 0 & 1 & c \\ 0 & 0 & 1 \end{pmatrix},
\quad a, b, c \in F.$$
The group has order $q^3$. Using coordinates $(a, b, c)$, the multiplication law
 is
$$(a, b, c)\cdot(a', b', c') = (a+a',\; b+b'+ac',\; c+c').$$

**Center and commutators.** The inverse of $(a', b', c')$ is $(-a',\; -b'+a'c',\
; -c')$. A direct computation gives the conjugation formula:
$$h\, g(a,b,c)\, h^{-1} = \bigl(a,\; b + a'c - ac',\; c\bigr), \quad h = (a', b'
, c').$$

The commutator $[g(a,b,c),\, g(a',b',c')] = (0,\; ac' - a'c,\; 0)$, which lies i
n the center. The center is $Z = \{(0, b, 0) : b \in F\}$, of order $q$, and $U/
Z \cong (F^2, +)$ is abelian. So $U(3,F)$ is nilpotent of class 2.

**Conjugacy classes.** From the conjugation formula, the conjugacy class of $(a,
 b, c)$ is
$$\mathcal{C}(a,b,c) = \bigl\{(a,\; b + a'c - ac',\; c) : a', c' \in F\bigr\}.$$

The set of offsets $\{a'c - ac' : a', c' \in F\}$ is the image of the linear map
 $\varphi_{a,c}: F^2 \to F$ defined by $\varphi_{a,c}(a', c') = a'c - ac'$.

**Case 1: $(a, c) = (0, 0)$.** Then $\varphi = 0$, so $\mathcal{C}(0, b, 0) = \{
(0, b, 0)\}$ is a singleton. These are the central elements, giving **$q$ conjug
acy classes** (one per $b \in F$).

**Case 2: $(a, c) \neq (0, 0)$.** Then $\varphi_{a,c}$ is a nonzero linear funct
ional on $F^2$, hence surjective (its image is a nonzero subspace of the 1-dimen
sional $F$-vector space $F$, i.e., all of $F$). Therefore $\{a'c - ac'\} = F$, a
nd
$$\mathcal{C}(a,b,c) = \{(a, t, c) : t \in F\},$$
which has size $q$ and depends only on the pair $(a, c)$, not on $b$. The number
 of nonzero pairs $(a, c) \in F^2$ is $q^2 - 1$, giving **$q^2 - 1$ conjugacy cl
asses**.

**Total count.** The number of conjugacy classes is
$$\underbrace{q}_{\text{central}} + \underbrace{(q^2 - 1)}_{\text{non-central}}
= q^2 + q - 1.$$

**Verification.** For $q = 2$: $|U(3, \mathbb{F}_2)| = 8$, and $q^2 + q - 1 = 5$
. The group $U(3, \mathbb{F}_2)$ is isomorphic to the dihedral group $D_4$ of or
der 8, which indeed has 5 conjugacy classes. ✓

For $q = 3$: the count gives $9 + 3 - 1 = 11$ classes for a group of order 27 wi
th center of order 3, consistent with the class-2 nilpotent structure. ✓

**Conclusion.** The number of distinct conjugacy classes of $U(3, F)$ is
$$q^2 + q - 1,$$
which is a polynomial in $q$ with integer coefficients. The answer is **yes**.
