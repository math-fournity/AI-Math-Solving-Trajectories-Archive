Looking at this problem, I need to find all primes $p$ such that $p \mid n^{n+1}
 + (n+1)^n$ for infinitely many positive integers $n$.

## Proof

**Case $p = 2$:** For any positive integer $n$, exactly one of $n, n+1$ is even.
 If $n$ is even, $n^{n+1}$ is even and $(n+1)^n$ is odd, so the sum is odd. If $
n$ is odd, $n^{n+1}$ is odd and $(n+1)^n$ is even, so the sum is odd. Thus $2 \n
mid n^{n+1}+(n+1)^n$ for all $n$, and $p=2$ does not work.

**Case $p$ an odd prime:** We show infinitely many $n$ satisfy the divisibility.

Set $a = p-2$, so $a \equiv -2 \pmod{p}$. Note $a \in \{1,\ldots,p-2\}$ (valid s
ince $p \geq 3$) and $a \not\equiv 0, -1 \pmod{p}$.

For $n \equiv a \pmod{p}$, we have $n \equiv -2 \pmod{p}$ and $n+1 \equiv -1 \pm
od{p}$, so:
$$n^{n+1} + (n+1)^n \equiv (-2)^{n+1} + (-1)^n \pmod{p}.$$

We want this $\equiv 0 \pmod{p}$, i.e.:
$$(-2)^{n+1} \equiv -(-1)^n = (-1)^{n+1} \pmod{p}.$$

Since $(-2)^{n+1} = (-1)^{n+1} \cdot 2^{n+1}$ and $(-1)^{n+1} \not\equiv 0 \pmod
{p}$ (as $p$ is odd), we divide both sides by $(-1)^{n+1}$ to obtain the equival
ent condition:
$$2^{n+1} \equiv 1 \pmod{p}.$$

Let $d = \operatorname{ord}_p(2)$. Then $2^{n+1} \equiv 1 \pmod{p}$ iff $n+1 \eq
uiv 0 \pmod{d}$, i.e., $n \equiv -1 \pmod{d}$.

So we need the simultaneous congruences:
$$n \equiv -2 \pmod{p}, \qquad n \equiv -1 \pmod{d}.$$

Since $d \mid (p-1)$ and $p$ is prime, $\gcd(d, p) = 1$. By the **Chinese Remain
der Theorem**, this system has a unique solution modulo $pd$, yielding an arithm
etic progression of infinitely many positive integers $n$.

For every such $n$: $p \mid n^{n+1} + (n+1)^n$.
