# Proof

**Setup.** Let $\omega = e^{2\pi i/3} = -\tfrac{1}{2} + \tfrac{\sqrt{3}}{2}i$ be
 the primitive third root of unity in the upper half-plane, and let $\Lambda = \
mathbb{Z} \oplus \omega\mathbb{Z}$ be the equianharmonic (hexagonal) lattice. Th
e Weierstrass $\wp$-function of a lattice $L$ satisfies
$$(\wp'(z;L))^2 = 4\wp(z;L)^3 + g_2(L)\,\wp(z;L) + g_3(L).$$

**Step 1: Scaling law for the invariants.** For any nonzero $\tau \in \mathbb{C}
$, the scaled lattice $\tau L = \{\tau\lambda : \lambda \in L\}$ has Eisenstein
series
$$G_{2k}(\tau L) = \sum_{\omega \in \tau L\setminus\{0\}} \omega^{-2k} = \sum_{\
lambda \in L\setminus\{0\}} (\tau\lambda)^{-2k} = \tau^{-2k}\, G_{2k}(L).$$
Since $g_2 = 60\,G_4$ and $g_3 = 140\,G_6$, we obtain the standard scaling laws:
$$g_2(\tau L) = \tau^{-4}\, g_2(L), \qquad g_3(\tau L) = \tau^{-6}\, g_3(L).$$

**Step 2: Apply to $\Lambda$.** By hypothesis $g_2(\Lambda) = 0$ (the equianharm
onic case). Hence for the scaled lattice $\tau\Lambda = \tau\mathbb{Z} \oplus \t
au\omega\mathbb{Z}$:
$$g_2(\tau\Lambda) = \tau^{-4}\cdot 0 = 0,$$
$$g_3(\tau\Lambda) = \tau^{-6}\, g_3(\Lambda).$$

**Step 3: Choose $\tau$.** Set $\tau = \left(\dfrac{g_3(\Lambda)}{b}\right)^{1/6
}$, so that $\tau^6 = g_3(\Lambda)/b$ and therefore $\tau^{-6} = b\,/\,g_3(\Lamb
da)$. (This requires $g_3(\Lambda)\neq 0$ and $b\neq 0$; both hold since otherwi
se the corresponding elliptic curves would be singular — for the equianharmonic
lattice $g_2=0$ but $g_3\neq 0$.) Then:
$$g_3(\tau\Lambda) = \tau^{-6}\, g_3(\Lambda) = \frac{b}{g_3(\Lambda)}\cdot g_3(
\Lambda) = b.$$

**Step 4: The differential equation for $\wp(z;\,\tau\Lambda)$.** Substituting $
g_2(\tau\Lambda)=0$ and $g_3(\tau\Lambda)=b$ into the Weierstrass equation:
$$(\wp'(z;\,\tau\Lambda))^2 = 4\,\wp(z;\,\tau\Lambda)^3 + b.$$

Setting $x = \wp(z;\,\tau\Lambda)$ and $y = \wp'(z;\,\tau\Lambda)$, the map
$$z \;\longmapsto\; \bigl(\wp(z;\,\tau\Lambda),\;\wp'(z;\,\tau\Lambda)\bigr)$$
defines a holomorphic map $\mathbb{C}/(\tau\Lambda) \to E_b : y^2 = 4x^3 + b$.

**Step 5: Identifying $\mathbb{C}/\Lambda$ with $\mathbb{C}/(\tau\Lambda)$.** Th
e multiplication map $m_\tau : \mathbb{C} \to \mathbb{C}$, $z \mapsto \tau z$, s
ends $\Lambda$ onto $\tau\Lambda$, so it descends to a biholomorphism $\mathbb{C
}/\Lambda \xrightarrow{\;\sim\;} \mathbb{C}/(\tau\Lambda)$. Composing with the $
\wp$-map above yields a map from $\mathbb{C}/\Lambda$ onto $E_b$.

**Conclusion.** Yes — the curve $y^2 = 4x^3 + b$ is the image of $\mathbb{C}/\La
mbda$ (equivalently $\mathbb{C}/(\tau\Lambda)$) under the map $z \mapsto (\wp(z;
\,\tau\Lambda),\,\wp'(z;\,\tau\Lambda))$, where $\tau = (g_3(\Lambda)/b)^{1/6}$.
 The key mechanism is the homogeneity $g_3(\tau L) = \tau^{-6} g_3(L)$, which le
ts us tune $g_3$ to any desired nonzero value $b$ by scaling, while $g_2$ remain
s zero throughout because it vanishes for the equianharmonic lattice and scales
homogeneously of degree $-4$.
