## 证明

设 $f = t_1^2 + t_2^2 + t_3^2 \in k[t_1, t_2, t_3]$，因此 $X = V(f)$ 且 $I_X = I
(V(f)) = \sqrt{(f)}$（根据代数闭域上的 Hilbert Nullstellensatz，这是本问题的标准
设定）。

---

### 情况 1：$\operatorname{char}(k) = 2$

在特征为 2 时，交叉项消失，因为 $2 = 0$，所以

$$
(t_1 + t_2 + t_3)^2 = t_1^2 + t_2^2 + t_3^2 + 2t_1t_2 + 2t_1t_3 + 2t_2t_3 = t_1^
2 + t_2^2 + t_3^2 = f.
$$

因此 $f = (t_1 + t_2 + t_3)^2$，从而 $(f) = \bigl((t_1+t_2+t_3)^2\bigr)$。其根式
为

$$
\sqrt{(f)} = \sqrt{\bigl((t_1+t_2+t_3)^2\bigr)} = (t_1 + t_2 + t_3),
$$

因为 $t_1 + t_2 + t_3$ 是线性的（因此是不可约的/素元），所以 $(t_1+t_2+t_3)$ 是
一个素理想，且是其生成元的幂的根式。等价地，作为簇，

$$
X = V\bigl((t_1+t_2+t_3)^2\bigr) = V(t_1+t_2+t_3),
$$

这是一个超平面，其消没理想是 $(t_1+t_2+t_3)$（通过将 $t_1+t_2+t_3$ 变量替换为 $t
_1$ 可得）。

$$
\boxed{I_X = (t_1 + t_2 + t_3) \quad \text{当 } \operatorname{char}(k) = 2.}
$$

---

### 情况 2：$\operatorname{char}(k) \neq 2$

我声明 $f = t_1^2 + t_2^2 + t_3^2$ 在 $k$ 上是不可约的（因此，由于 $k$ 是代数闭
域，它在 $k[t_1,t_2,t_3]$ 中是不可约的）。通过线性形式分解的反证法证明：假设

$$
f = \Bigl(\sum_{i=1}^3 a_i t_i\Bigr)\Bigl(\sum_{i=1}^3 b_i t_i\Bigr).
$$

比较系数得出 $a_1b_1 = a_2b_2 = a_3b_3 = 1$（因此所有 $a_i, b_i$ 均非零），且对
于 $i \neq j$，有 $a_i b_j + a_j b_i = 0$。由前两个交叉项方程，利用 $a_1 = 1/b_1
$ 和 $a_2 = 1/b_2$：

$$
a_1 b_2 + a_2 b_1 = \frac{b_2}{b_1} + \frac{b_1}{b_2} = 0 \implies b_2^2 = -b_1^
2.
$$

类似地，$a_1b_3 + a_3b_1 = 0 \implies b_3^2 = -b_1^2$，且 $a_2b_3 + a_3b_2 = 0 \
implies b_3^2 = -b_2^2$。结合前两个结果得到 $b_3^2 = b_2^2$，因此 $b_3 = \pm b_2
$。现在第三个交叉项方程给出

$$
\frac{b_3}{b_2} + \frac{b_2}{b_3} = 0 \implies \left(\frac{b_3}{b_2}\right)^2 =
-1.
$$

如果 $b_3 = b_2$，则 $(b_3/b_2)^2 = 1 = -1$，与 $\operatorname{char}(k) \neq 2$
矛盾。如果 $b_3 = -b_2$，则 $b_3/b_2 = -1$ 且 $b_2/b_3 = -1$，所以和为 $-2$，在
$\operatorname{char}(k) \neq 2$ 时非零——再次矛盾。因此不存在这样的分解，且 $f$
是不可约的。

由于 $k[t_1, t_2, t_3]$ 是一个 UFD（唯一析因整环），其中每个不可约元素都是素元，
理想 $(f)$ 是素理想，因此是根式理想。所以

$$
I_X = \sqrt{(f)} = (f) = (t_1^2 + t_2^2 + t_3^2).
$$

$$
\boxed{I_X = (t_1^2 + t_2^2 + t_3^2) \quad \text{当 } \operatorname{char}(k) \ne
q 2.}
$$

---

### 总结

这两种情况之间的区别反映了在特征为 2 时 Frobenius 平方的非约化现象：当 $\operato
rname{char}(k) = 2$ 时，多项式 $t_1^2 + t_2^2 + t_3^2$ 成为线性形式 $t_1 + t_2 +
 t_3$ 的平方，因此其消没簇是一个超平面，其理想是线性理想 $(t_1 + t_2 + t_3)$，而
不是二次理想。当 $\operatorname{char}(k) \neq 2$ 时，二次型是不可约的，生成的理
想是素理想且根式理想，因此 $I_X = (t_1^2 + t_2^2 + t_3^2)$。
