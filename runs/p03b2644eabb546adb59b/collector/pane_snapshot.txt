## Solution

We seek the monic polynomial $f(x) = x^k + a_{k-1}x^{k-1} + \cdots + a_0$ with e
ach $a_i \in \{-1, 0, 1\}$, of smallest degree, such that $30 \mid f(n)$ for all
 positive integers $n$.

### Key observation: reduction modulo primes

Since $30 = 2 \cdot 3 \cdot 5$, the condition $30 \mid f(n)$ for all $n$ is equi
valent (by CRT) to:
- $f(n) \equiv 0 \pmod{2}$ for all $n$,
- $f(n) \equiv 0 \pmod{3}$ for all $n$,
- $f(n) \equiv 0 \pmod{5}$ for all $n$.

For a prime $p$, a polynomial with integer coefficients vanishes on all of $\mat
hbb{F}_p$ if and only if it is divisible by $x^p - x$ in $\mathbb{F}_p[x]$ (sinc
e $x^p - x = \prod_{a \in \mathbb{F}_p}(x-a)$). Therefore:
- **Mod 2:** $x^2 - x \mid f$ in $\mathbb{F}_2[x]$,
- **Mod 3:** $x^3 - x \mid f$ in $\mathbb{F}_3[x]$,
- **Mod 5:** $x^5 - x \mid f$ in $\mathbb{F}_5[x]$.

### Lower bound: degree $\geq 5$

The mod-5 condition requires $x^5 - x \mid f$ in $\mathbb{F}_5[x]$. Since $f$ is
 monic, its leading coefficient is $1 \not\equiv 0 \pmod{5}$, so $f$ is not the
zero polynomial mod 5. A nonzero polynomial divisible by $x^5 - x$ (degree 5) mu
st have degree $\geq 5$. Hence $\deg f \geq 5$.

### Constructing the degree-5 solution

Let $f(x) = x^5 + a_4 x^4 + a_3 x^3 + a_2 x^2 + a_1 x + a_0$ with $a_i \in \{-1,
 0, 1\}$.

**Mod 5 condition:** Since $f$ is monic of degree 5 and $x^5 - x \mid f$ in $\ma
thbb{F}_5[x]$, we must have $f \equiv x^5 - x \pmod{5}$ as polynomials. Matching
 coefficients mod 5:

| Coefficient | Required mod 5 | Value in $\{-1,0,1\}$ |
|---|---|---|
| $a_4$ | $\equiv 0$ | $a_4 = 0$ |
| $a_3$ | $\equiv 0$ | $a_3 = 0$ |
| $a_2$ | $\equiv 0$ | $a_2 = 0$ |
| $a_1$ | $\equiv -1 \equiv 4$ | $a_1 = -1$ |
| $a_0$ | $\equiv 0$ | $a_0 = 0$ |

This uniquely determines $f(x) = x^5 - x$.

### Verification

**Coefficients:** $f(x) = x^5 - x$ has coefficients $1, 0, 0, 0, -1, 0$ — all in
 $\{-1, 0, 1\$. ✓

**Divisibility by 30 for all $n$:** Factor:
$$f(n) = n^5 - n = n(n^4 - 1) = n(n-1)(n+1)(n^2+1).$$

- **Divisible by 2:** Among $n-1, n, n+1$ (three consecutive integers), at least
 one is even.
- **Divisible by 3:** Among $n-1, n, n+1$ (three consecutive integers), exactly
one is divisible by 3.
- **Divisible by 5:** By Fermat's little theorem, $n^5 \equiv n \pmod{5}$ for al
l integers $n$, so $5 \mid n^5 - n$.

Since $\gcd(2,3)=\gcd(6,5)=1$, we conclude $30 \mid n^5 - n$ for all positive in
tegers $n$. ✓

### Conclusion

The polynomial of smallest degree is:

$$\boxed{f(x) = x^5 - x}$$

It is the **unique** monic polynomial of degree 5 with coefficients in $\{-1, 0,
 1\}$ divisible by 30 for all positive integers $n$, and no polynomial of smalle
r degree can satisfy the mod-5 divisibility condition.
