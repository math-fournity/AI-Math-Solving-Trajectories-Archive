## Setup and Notation

Let $f(x) = \frac{x}{x+1}$ for $x \geq 0$ (concave since $f''(x) = -\frac{2}{(x+
1)^3} < 0$).

Define row sums $S_i = \sum_{j=1}^{2n} f(a_i b_j)$ and column sums $T_j = \sum_{
i=1}^{2n} f(a_i b_j)$.

Note $f(a_i b_j) = 0$ iff $a_i = 0$ or $b_j = 0$. So $S_i \neq 0$ iff $a_i > 0$,
 and $T_j \neq 0$ iff $b_j > 0$. Let:
- $R$ = set of indices with $a_i > 0$, $r = |R|$
- $C$ = set of indices with $b_j > 0$, $c = |C|$

Then $A = \{S_i : i \in R\}$, $B = \{T_j : j \in C\}$, so $|A| = r$, $|B| = c$.

The total is $W := \sum_{i \in R, j \in C} f(a_i b_j) = \sum_{i \in R} S_i = \su
m_{j \in C} T_j$.

## Achieving $m = n/2$

Take $a_1 = \cdots = a_n = 1$, $a_{n+1} = \cdots = a_{2n} = 0$, and $b_1 = \cdot
s = b_n = 1$, $b_{n+1} = \cdots = b_{2n} = 0$. Then $\sum a_i = \sum b_j = n$. F
or $1 \leq i,j \leq n$: $a_i b_j = 1$, $f(1) = \frac{1}{2}$. Each $S_i = n \cdot
 \frac{1}{2} = \frac{n}{2}$ for $i \leq n$ (and $0$ otherwise); each $T_j = \fra
c{n}{2}$ for $j \leq n$ (and $0$ otherwise). Thus $A = B = \{\frac{n}{2}\}$, giv
ing $m = \frac{n}{2}$.

## Upper Bound: $m \leq n/2$

Suppose for contradiction that all nonzero $S_i > \frac{n}{2}$ and all nonzero $
T_j > \frac{n}{2}$.

**Step 1 (Jensen upper bound on $W$).** Since $\sum_{i \in R, j \in C} a_i b_j =
 \left(\sum_{i \in R} a_i\right)\left(\sum_{j \in C} b_j\right) = n \cdot n = n^
2$, by concavity of $f$ and Jensen's inequality applied to the $rc$ nonneg value
s $a_i b_j$:

$$W = \sum_{i \in R, j \in C} f(a_i b_j) \leq rc \cdot f\!\left(\frac{n^2}{rc}\r
ight) = \frac{rc \cdot n^2}{n^2 + rc}.$$

**Step 2 (Lower bound from the assumption).** Since each $S_i > \frac{n}{2}$ for
 $i \in R$:

$$W = \sum_{i \in R} S_i > r \cdot \frac{n}{2}.$$

Similarly $W > c \cdot \frac{n}{2}$. Setting $p = \min(r,c)$, $q = \max(r,c)$, w
e get $W > q \cdot \frac{n}{2}$.

**Step 3 (Combining).** We need:

$$q \cdot \frac{n}{2} < W \leq \frac{pq \cdot n^2}{n^2 + pq}.$$

Dividing by $q > 0$:

$$\frac{n}{2} < \frac{p \cdot n^2}{n^2 + pq}.$$

Rearranging: $n(n^2 + pq) < 2pn^2$, i.e., $n^3 + npq < 2pn^2$, i.e., $n^2 + pq <
 2pn$ (dividing by $n > 0$), i.e.:

$$pq - 2pn + n^2 < 0 \implies p(q - 2n) + n^2 < 0.$$

Since $q \leq 2n$ (there are only $2n$ indices), we have $q - 2n \leq 0$, so $p(
q-2n) \leq 0$, giving $p(q-2n) + n^2 \leq n^2$.

More precisely, $p(q - 2n) + n^2 = n^2 - p(2n - q)$. Since $p \leq q \leq 2n$ an
d $p \leq 2n$:

$$p(2n - q) \leq q(2n - q) = 2nq - q^2 = n^2 - (q - n)^2 \leq n^2.$$

(The inequality $p \leq q$ gives $p(2n-q) \leq q(2n-q)$ since $2n - q \geq 0$.)
Therefore:

$$p(2n - q) + n^2 \cdot (\text{negative sign}) \quad\Longrightarrow\quad n^2 - p
(2n-q) \geq n^2 - (n^2 - (q-n)^2) = (q-n)^2 \geq 0.$$

So $p(q - 2n) + n^2 = n^2 - p(2n - q) \geq (q-n)^2 \geq 0$, contradicting the re
quired strict inequality $p(q-2n) + n^2 < 0$.

**Conclusion.** The assumption that all nonzero row and column sums exceed $\fra
c{n}{2}$ is impossible. Hence $\min(A \cup B) \leq \frac{n}{2}$ for every config
