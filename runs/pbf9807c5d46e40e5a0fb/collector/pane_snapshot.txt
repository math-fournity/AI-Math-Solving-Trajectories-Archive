## Solution

We solve the Volterra integral equation of the second kind

$$\varphi(x) = e^{x^{2}} + \int_{0}^{x} e^{x^{2} - t^{2}} \varphi(t) \, dt$$

with $f(x) = e^{x^2}$ and kernel $K(x,t) = e^{x^2 - t^2}$.

### Resolvent kernel via iterated kernels

Define $K_1(x,t) = K(x,t) = e^{x^2-t^2}$ and $K_{n+1}(x,t) = \int_t^x K(x,s)\,K_
n(s,t)\,ds$.

**$K_2$:**
$$K_2(x,t) = \int_t^x e^{x^2-s^2}\,e^{s^2-t^2}\,ds = e^{x^2-t^2}\int_t^x ds = (x
-t)\,e^{x^2-t^2}.$$

**$K_3$:**
$$K_3(x,t) = \int_t^x e^{x^2-s^2}\,(s-t)\,e^{s^2-t^2}\,ds = e^{x^2-t^2}\int_t^x
(s-t)\,ds = \frac{(x-t)^2}{2}\,e^{x^2-t^2}.$$

**Induction:** Suppose $K_n(x,t) = \dfrac{(x-t)^{n-1}}{(n-1)!}\,e^{x^2-t^2}$. Th
en
$$K_{n+1}(x,t) = \int_t^x e^{x^2-s^2}\,\frac{(s-t)^{n-1}}{(n-1)!}\,e^{s^2-t^2}\,
ds = e^{x^2-t^2}\,\frac{1}{(n-1)!}\int_t^x (s-t)^{n-1}\,ds = \frac{(x-t)^n}{n!}\
,e^{x^2-t^2}.$$

So $K_n(x,t) = \dfrac{(x-t)^{n-1}}{(n-1)!}\,e^{x^2-t^2}$ for all $n \ge 1$.

### Summing the resolvent

$$R(x,t) = \sum_{n=1}^{\infty} K_n(x,t) = e^{x^2-t^2}\sum_{n=1}^{\infty}\frac{(x
-t)^{n-1}}{(n-1)!} = e^{x^2-t^2}\sum_{m=0}^{\infty}\frac{(x-t)^m}{m!} = e^{x^2-t
^2}\,e^{x-t}.$$

### Applying the resolvent formula

$$\varphi(x) = f(x) + \int_0^x R(x,t)\,f(t)\,dt = e^{x^2} + \int_0^x e^{x^2-t^2+
x-t}\,e^{t^2}\,dt = e^{x^2} + e^{x^2+x}\int_0^x e^{-t}\,dt.$$

$$= e^{x^2} + e^{x^2+x}\bigl(1 - e^{-x}\bigr) = e^{x^2} + e^{x^2+x} - e^{x^2} =
e^{x^2+x}.$$

### Verification

$$\text{RHS} = e^{x^2} + \int_0^x e^{x^2-t^2}\,e^{t^2+t}\,dt = e^{x^2} + e^{x^2}
\int_0^x e^t\,dt = e^{x^2} + e^{x^2}(e^x-1) = e^{x^2+x} = \varphi(x).\ \checkmar
k$$

### Answer

$$\boxed{\varphi(x) = e^{x^{2}+x}}$$
