Proof

Claim: Yes. Every Hilbert space is isomorphic (unitarily equivalent) to an $L^2$
space.

Key facts used.

  1. Every Hilbert space has an orthonormal basis. By Zorn's lemma, every
  Hilbert space $H$ admits a maximal orthonormal set $E$. The Hilbert dimension
  $\kappa := |E|$ is well-defined (any two orthonormal bases have the same
  cardinality), and $H$ decomposes as $$H \cong \ell^2(E) = \Big{f : E \to
  \mathbb{C} ;\Big|; \textstyle\sum_{e\in E}|f(e)|^2 < \infty\Big},$$ via the
  unitary $U: H \to \ell^2(E)$, $Ux = (\langle x, e\rangle)_{e\in E}$ (Fourier
  coefficients). This is the standard Parseval / Riesz–Fischer theorem, valid
  for bases of arbitrary cardinality.
  2. $\ell^2(E) = L^2(E, \mathcal{P}(E), \nu)$ where $\nu$ is counting measure.
  With counting measure $\nu$ on $E$, every function is measurable, and $$\int_E
  |f|^2,d\nu = \sum_{e\in E}|f(e)|^2,$$ where the sum over an arbitrary index
  set is defined as $\sup\big{\sum_{e\in F}|f(e)|^2 : F\subseteq E
  \text{ finite}\big}$. This is finite iff $f$ has at most countable support and
  the ordinary series converges — exactly the condition defining $\ell^2(E)$.
  Hence $\ell^2(E) = L^2(E,\mathcal{P}(E),\nu)$ as sets, with identical norms
  and inner products.

Construction. Given any Hilbert space $H$:

  • Choose an orthonormal basis $E\subseteq H$; let $\kappa = |E|$.
  • Take the measure space $(X,\mathcal{M},\mu) := (E,,\mathcal{P}(E),,\nu)$
  where $\nu$ is counting measure.
  • The map $U: H \to L^2(\mu)$ defined by $Ux = \big(\langle
  x,e\rangle\big)_{e\in E}$ is:
    • Linear: clear.
    • Isometric: $|Ux|^2_{L^2} = \sum_{e}|\langle x,e\rangle|^2 = |x|^2$
    (Parseval).
    • Surjective: given $f\in L^2(\mu) = \ell^2(E)$, the vector $x := \sum_{e\in
    E} f(e),e$ (converging in $H$ since $\sum|f(e)|^2<\infty$) satisfies $Ux =
    f$.

Thus $U$ is a unitary isomorphism $H \cong L^2(\mu)$.

Verification of all cases.

  • $\kappa = n < \infty$: $E = {1,\dots,n}$, counting measure; $L^2 =
  \mathbb{C}^n$. ✓
  • $\kappa = \aleph_0$: $E = \mathbb{N}$, counting measure; $L^2 =
  \ell^2(\mathbb{N})$. ✓
  • $\kappa$ uncountable: $E$ any set of cardinality $\kappa$, counting measure;
  $L^2 = \ell^2(E)$ with orthonormal basis ${\delta_e : e\in E}$ of cardinality
  $\kappa$. ✓

Every cardinal $\kappa$ is realized as $|E|$ for some set $E$, and counting
measure is always a legitimate (positive) measure, so the construction covers
all Hilbert spaces without exception.

Remark on minimality. Counting measure on a set of size $\kappa$ is the
canonical choice. One can also use, e.g., $X = {0,1}^\kappa$ with product
measure, but the counting-measure construction is the simplest and works
uniformly for all $\kappa$.

Conclusion. For every Hilbert space $H$ there exists a measure space $(X,
\mathcal{M},\mu)$ — namely $(E,\mathcal{P}(E),\text{counting})$ where $E$ is an
orthonormal basis of $H$ — such that $H \cong L^2(\mu)$. The answer is yes.
