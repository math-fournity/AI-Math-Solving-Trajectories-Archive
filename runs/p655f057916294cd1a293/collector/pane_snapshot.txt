## Proof

### Setup

Label each chord by its **step** $d$ = the smaller arc length between endpoints,
 where $1 \le d \le \lfloor n/2 \rfloor$. The Euclidean length is $L_d = 2R\sin(
d\pi/n)$. The count of step-$d$ chords is:
- $n$ if $d < n/2$,
- $n/2$ if $d = n/2$ (n even, diameters).

Three chords of steps $a \le b \le c$ form a triangle iff $\sin(a\pi/n) + \sin(b
\pi/n) > \sin(c\pi/n)$ (strict triangle inequality).

### Necessary Condition

The total $\frac{n(n-1)}{2}$ must be divisible by 3, so $n(n-1) \equiv 0 \pmod{6
}$. Since $n(n-1)$ is always even, we need $n \equiv 0$ or $1 \pmod{3}$. If $n \
equiv 2 \pmod{3}$, the partition is impossible.

### Sufficiency: Case $n \equiv 0 \pmod{3}$, $n > 3$

**All groups are equilateral.** For each step $d$, form groups of three identica
l chords $(d,d,d)$.

- If $n$ is odd ($n \equiv 3 \pmod 6$): every step has exactly $n$ chords, and $
3 \mid n$, so each step partitions cleanly into $n/3$ equilateral triangles.
- If $n$ is even ($n \equiv 0 \pmod 6$): steps $d < n/2$ have $n$ chords ($3 \mi
d n$ ✓), and the diameter step $d = n/2$ has $n/2$ chords, with $3 \mid n/2$ sin
ce $n \equiv 0 \pmod 6$ ✓.

Every equilateral group trivially satisfies the triangle inequality. ✓

### Sufficiency: Case $n \equiv 1 \pmod{3}$, $n \ge 4$

**Strategy:** Make as many equilateral groups as possible, then handle leftovers

### Validity of Consecutive-Triples

**Claim:** For $n \ge 7$ and $d \ge 1$ with $(d+2)\pi/n < \pi/2$, the triple $(d

*Proof.* Set $\theta = \pi/n$. We need $\sin(d\theta) + \sin((d+1)\theta) > \sin

By sum-to-product: $\sin(d\theta) + \sin((d+1)\theta) = 2\sin\!\left(\frac{(2d+1

cos(\theta/2) > \cos v$ (since $\theta/2 < v$). Therefore $\sin u \cos(\theta/2)

eta/2)$, which holds since $\theta/2 < 3\theta/2$ and cosine is strictly decreas
