# Solution

## Step 1: Solve the Cauchy-Euler equation

The equation $x^2 y'' + x y' + \lambda y = 0$ is a Cauchy-Euler equation. Trying
 $y = x^r$ gives $y' = r x^{r-1}$, $y'' = r(r-1)x^{r-2}$, so

$$x^2 \cdot r(r-1)x^{r-2} + x \cdot r x^{r-1} + \lambda x^r = [r(r-1) + r + \lam
bda]x^r = [r^2 + \lambda]x^r = 0.$$

Hence the indicial equation is $r^2 + \lambda = 0$, i.e. $r^2 = -\lambda$.

For $\lambda > 0$, write $\mu = \sqrt{\lambda}$, so $r = \pm i\mu$. The general
real solution is

$$y(x) = c_1 \cos(\mu \ln x) + c_2 \sin(\mu \ln x).$$

**Boundary condition $y(1)=0$:** $\ln 1 = 0$, so $y(1) = c_1 \cos 0 + c_2 \sin 0
 = c_1 = 0$. Thus $c_1 = 0$ and $y(x) = c_2 \sin(\mu \ln x)$.

**Boundary condition $y(b)=0$:** $c_2 \sin(\mu \ln b) = 0$. For a nontrivial sol
ution, $\sin(\mu \ln b) = 0$, giving

$$\mu_n \ln b = n\pi, \quad n = 1, 2, 3, \dots$$

So the eigenvalues and eigenfunctions are

$$\mu_n = \frac{n\pi}{\ln b}, \qquad \lambda_n = \mu_n^2 = \frac{n^2\pi^2}{(\ln
b)^2}, \qquad y_n(x) = \sin\!\left(\frac{n\pi \ln x}{\ln b}\right).$$

## Step 2: Reduce to self-adjoint (Sturm-Liouville) form

Divide the equation by $x$:

$$x\,y'' + y' + \frac{\lambda}{x}\,y = 0.$$

Recognize that $x\,y'' + y' = (x\,y')'$, so

$$(x\,y')' + \frac{\lambda}{x}\,y = 0.$$

This is the Sturm-Liouville form $(p\,y')' + \lambda\, w\, y = 0$ with

$$p(x) = x, \qquad w(x) = \frac{1}{x}.$$

**The weight function is $w(x) = \dfrac{1}{x}$.**

## Step 3: Verify orthogonality by direct integration

For $m \neq n$, compute

$$I_{mn} = \int_1^b y_m(x)\,y_n(x)\,w(x)\,dx = \int_1^b \sin\!\left(\frac{m\pi\l
n x}{\ln b}\right)\sin\!\left(\frac{n\pi\ln x}{\ln b}\right)\frac{dx}{x}.$$

Substitute $u = \ln x$, $du = \frac{dx}{x}$. Limits: $x=1 \Rightarrow u=0$; $x=b
 \Rightarrow u=\ln b$:

$$I_{mn} = \int_0^{\ln b}\sin\!\left(\frac{m\pi u}{\ln b}\right)\sin\!\left(\fra
c{n\pi u}{\ln b}\right)du.$$

Substitute $t = \frac{u}{\ln b}$, $du = (\ln b)\,dt$. Limits: $u=0 \Rightarrow t
=0$; $u=\ln b \Rightarrow t=1$:

$$I_{mn} = (\ln b)\int_0^1 \sin(m\pi t)\,\sin(n\pi t)\,dt.$$

Using the product-to-sum identity $\sin A\sin B = \tfrac{1}{2}[\cos(A-B) - \cos(
A+B)]$:

$$I_{mn} = \frac{\ln b}{2}\int_0^1\!\bigl[\cos((m-n)\pi t) - \cos((m+n)\pi t)\bi
gr]dt.$$

For $m \neq n$ (both integers), $\sin((m\pm n)\pi) = 0$, so

$$\int_0^1 \cos(k\pi t)\,dt = \frac{\sin(k\pi t)}{k\pi}\bigg|_0^1 = 0 \quad (k =
 m-n,\, m+n \neq 0).$$

Therefore

$$\boxed{I_{mn} = 0 \quad \text{for } m \neq n.}$$

For $m = n$, the first term gives $\int_0^1 1\,dt = 1$ and the second gives $0$,
 so

$$I_{nn} = \frac{\ln b}{2},$$

confirming the eigenfunctions are nonzero and the orthogonality is non-degenerat
e.

## Conclusion

The differential equation $x^2 y'' + x y' + \lambda y = 0$ with $y(1)=0$, $y(b)=
0$ reduces to the Sturm-Liouville form $(xy')' + \lambda\,\dfrac{1}{x}\,y = 0$.
The **weight function** with respect to which the eigenfunctions $y_n(x) = \sin\
!\left(\dfrac{n\pi\ln x}{\ln b}\right)$ are orthogonal is

$$\boxed{w(x) = \frac{1}{x}},$$

and the direct integration above confirms $\displaystyle\int_1^b y_m(x)\,y_n(x)\
,\frac{dx}{x} = 0$ for $m \neq n$.
