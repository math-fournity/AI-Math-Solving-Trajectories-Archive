Looking at this problem, I need to determine whether a finitely additive set fun
ction on **all** subsets of ℝ, agreeing with length on intervals, exists.

**Answer: Yes.**

## Proof

The key distinction is that the problem requires only **finite additivity** (add
itivity for pairs of disjoint sets), not countable additivity. This is substanti
ally weaker, and the Hahn–Banach theorem provides the construction.

### Step 1: Construction on $[0,1)$

Let $X = [0,1)$. Denote by $B(X)$ the vector space of all bounded real-valued fu
nctions on $X$, and by $R(X) \subset B(X)$ the subspace of Riemann-integrable fu
nctions on $[0,1]$ (restricted to $[0,1)$; this is harmless since $\{1\}$ has Jo
rdan content zero). The Riemann integral $I: R(X) \to \mathbb{R}$ is a **positiv
e** linear functional: $I(f) \ge 0$ whenever $f \ge 0$.

Define $p: B(X) \to \mathbb{R}$ by
$$p(f) = \inf\{I(g) : g \in R(X),\; g \ge f \text{ pointwise}\}.$$
This is well-defined since for any bounded $f$, the constant $\sup f$ belongs to
 $R(X)$ and dominates $f$.

**$p$ is sublinear.** Positive homogeneity is immediate. For subadditivity: give
n $\varepsilon > 0$, pick $g_1, g_2 \in R(X)$ with $g_1 \ge f$, $g_2 \ge h$, $I(
g_1) \le p(f)+\varepsilon$, $I(g_2) \le p(h)+\varepsilon$. Then $g_1+g_2 \ge f+h
$, lies in $R(X)$, and $I(g_1+g_2) \le p(f)+p(h)+2\varepsilon$. Letting $\vareps
ilon \to 0$ gives $p(f+h) \le p(f)+p(h)$.

**$p = I$ on $R(X)$.** Clearly $p(f) \le I(f)$ (take $g = f$). Conversely, if $g
 \in R(X)$ with $g \ge f$, then $g - f \ge 0$ and $g-f \in R(X)$, so $I(g) \ge I
(f)$ by positivity; hence $p(f) \ge I(f)$.

By the **Hahn–Banach theorem**, there exists a linear functional $L: B(X) \to \m
athbb{R}$ extending $I$, with $L(f) \le p(f)$ for all $f \in B(X)$.

**$L$ is positive.** If $f \ge 0$, then $-f \le 0$, and $0 \in R(X)$ with $0 \ge
 -f$, so $p(-f) \le I(0) = 0$. Thus $L(-f) \le 0$, giving $L(f) \ge 0$.

Define $\mu: \mathcal{P}(X) \to [0,1]$ by $\mu(A) = L(\chi_A)$. Since $0 \le \ch
i_A \le 1$ and $L$ is positive and linear:
$$0 \le \mu(A) \le L(\mathbf{1}) = I(\mathbf{1}) = 1.$$

**Finite additivity:** If $A, B \subset X$ are disjoint, $\chi_{A \cup B} = \chi
_A + \chi_B$, so $\mu(A \cup B) = L(\chi_A) + L(\chi_B) = \mu(A) + \mu(B)$.

**Agreement with length:** For any interval $J \subset [0,1)$, $\chi_J \in R(X)$
 (it is Riemann integrable, discontinuous only at endpoints), so $\mu(J) = L(\ch
i_J) = I(\chi_J) = |J|$.

**Singletons have measure zero:** For $c \in [0,1)$, $\chi_{\{c\}}$ is Riemann i
ntegrable with integral $0$, so $\mu(\{c\}) = 0$.

### Step 2: Extend to all of $\mathbb{R}$

For each $n \in \mathbb{Z}$, let $X_n = [n, n+1)$ and define $\mu_n: \mathcal{P}
(X_n) \to [0,1]$ by $\mu_n(A) = \mu(A - n)$, where $A - n = \{x - n : x \in A\}
\subset [0,1)$. Each $\mu_n$ is finitely additive and agrees with Lebesgue measu
re on intervals contained in $X_n$.

Define $m: \mathcal{P}(\mathbb{R}) \to [0, \infty]$ by
$$m(S) = \sum_{n \in \mathbb{Z}} \mu_n(S \cap X_n).$$
This is a sum of non-negative terms, hence well-defined in $[0,\infty]$.

**Finite additivity:** Let $S, T \subset \mathbb{R}$ be disjoint. Since all summ
ands are non-negative,
$$m(S) + m(T) = \sum_n \mu_n(S \cap X_n) + \sum_n \mu_n(T \cap X_n) = \sum_n \bi
gl[\mu_n(S \cap X_n) + \mu_n(T \cap X_n)\bigr].$$
Since $S \cap X_n$ and $T \cap X_n$ are disjoint subsets of $X_n$,
$$= \sum_n \mu_n\bigl((S \cup T) \cap X_n\bigr) = m(S \cup T).$$

**Agreement on intervals:** Let $a < b$. The half-open interval $[a, b)$ is part
itioned by the sets $[a,b) \cap X_n$, so
$$m([a,b)) = \sum_n \mu_n([a,b) \cap X_n) = \sum_n |[a,b) \cap X_n| = b - a.$$
The singleton $\{b\}$ satisfies $m(\{b\}) = 0$ (it lies in some $X_n$ and has $\
mu_n$-measure $0$). By finite additivity,
$$m([a,b]) = m([a,b)) + m(\{b\}) = (b - a) + 0 = b - a. \quad \checkmark$$

### Conclusion

The function $m: \mathcal{P}(\mathbb{R}) \to [0,\infty]$ defined above satisfies
 $m([a,b]) = b - a$ for all $a < b$ and is finitely additive on disjoint sets. T
herefore, **yes**, such a function exists.

**Remark.** The crucial point is that only *finite* additivity is required. Had
*countable* additivity been demanded, the answer would be negative (by Vitali's
construction of a non-measurable set). Finite additivity is weak enough that the
 Hahn–Banach theorem yields an extension to all subsets.
