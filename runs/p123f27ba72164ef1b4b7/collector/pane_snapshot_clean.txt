## Setup

Since 19 is prime, the multiplicative group mod 19 is cyclic of order 18. For an

The sequence $2^n \bmod 18$ has period 6: $\{2, 4, 8, 16, 14, 10\}$. So the cond
ition reduces to:
$$p_k := x^k + y^k + z^k \equiv 0 \pmod{19} \quad \text{for } k \in \{2, 4, 8, 1
6, 14, 10\}.$$

## Applying Newton's Identities

Let $e_1 = x+y+z$, $e_2 = xy+yz+zx$, $e_3 = xyz$. The power sums satisfy:
$$p_k = e_1 p_{k-1} - e_2 p_{k-2} + e_3 p_{k-3} \quad (k \ge 3), \quad p_0 = 3,\
; p_1 = e_1.$$

**From $p_2 = 0$:** $p_2 = e_1^2 - 2e_2 = 0$, so $e_2 = e_1^2/2$.

**From $p_4 = 0$:** Computing $p_3 = -e_1 e_2 + 3e_3$ and $p_4 = -e_1^2 e_2 + 4e
_1 e_3 = 0$. Substituting $e_2 = e_1^2/2$:
$$-\frac{e_1^4}{2} + 4e_1 e_3 = 0 \implies e_1 = 0 \;\text{or}\; e_3 = \frac{e_1
^3}{8}.$$

## Case 1: $e_1 = 0$ (hence $e_2 = 0$)

The recurrence becomes $p_k = e_3 \cdot p_{k-3}$ with $p_0=3, p_1=0, p_2=0$. Thi

2,4,8,10,14,16\}$. ✓

The condition $e_1 = e_2 = 0$ means $x,y,z$ are roots of $t^3 - e_3 = 0$, i.e.,
$x^3 \equiv y^3 \equiv z^3 \pmod{19}$. The cubing map on $(\mathbb{Z}/19)^*$ has

Each coset sums to $19a \equiv 0$ and has $xy+yz+zx = 95a^2 \equiv 0$. The 6 cos

## Case 2: $e_1 \ne 0$, $e_3 = e_1^3/8$
