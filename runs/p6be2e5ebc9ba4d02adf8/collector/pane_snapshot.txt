**Answer: Yes.**

**Proof.**

Since $H$ is an infinite-dimensional Hilbert space, it possesses an orthonormal
basis of some infinite cardinality $\kappa$. For any finite $n$ and any infinite
 cardinal $\kappa$, we have $n\cdot\kappa = \kappa$. Hence we may partition an o
rthonormal basis of $H$ into $n$ disjoint subsets $B_1, B_2, \ldots, B_n$, each
of cardinality $\kappa$.

Let $H_i = \overline{\operatorname{span}}\, B_i$ be the closed linear span of $B
_i$. Then each $H_i$ is a closed subspace of $H$ with Hilbert-space dimension $\
kappa$, so $H_i \cong H$ as Hilbert spaces. Moreover, the subspaces $H_1, \ldots
, H_n$ are pairwise orthogonal and

$$H = H_1 \oplus H_2 \oplus \cdots \oplus H_n.$$

For each $i \in \{1, \ldots, n\}$, choose a unitary operator $U_i : H \to H_i$ (
which exists because $H$ and $H_i$ have the same dimension). Define

$$s_i := U_i \in B(H),$$

viewing $U_i$ as an operator from $H$ into $H$ with range $H_i$.

**Claim 1: Each $s_i$ is an isometry.** For any $x \in H$,

$$\|s_i x\|^2 = \|U_i x\|^2 = \|x\|^2,$$

since $U_i$ is unitary. Equivalently, $s_i^* s_i = I_H$: indeed, for $x \in H$,
$s_i x = U_i x \in H_i$, so the adjoint $s_i^* : H \to H$ acts as $s_i^*(y) = U_
i^{-1}(P_{H_i} y)$ where $P_{H_i}$ is the orthogonal projection onto $H_i$. Then

$$s_i^* s_i\, x = s_i^*(U_i x) = U_i^{-1}\!\big(P_{H_i}(U_i x)\big) = U_i^{-1}(U
_i x) = x,$$

so $s_i^* s_i = I_H$.

**Claim 2: $\sum_{i=1}^n s_i s_i^* = I_H$.** For any $y \in H$,

$$s_i s_i^*\, y = s_i\!\big(U_i^{-1}(P_{H_i} y)\big) = U_i\!\big(U_i^{-1}(P_{H_i
} y)\big) = P_{H_i}\, y.$$

Thus $s_i s_i^*$ is exactly the orthogonal projection $P_{H_i}$ onto $H_i$. Summ
ing over all $i$:

$$\sum_{i=1}^n s_i s_i^* = \sum_{i=1}^n P_{H_i} = I_H,$$

where the last equality uses the fact that $H = H_1 \oplus \cdots \oplus H_n$ is
 an orthogonal direct-sum decomposition, so the projections sum to the identity.

Therefore, the $n$ isometries $s_1, \ldots, s_n \in B(H)$ satisfy

$$s_1 s_1^* + s_2 s_2^* + \cdots + s_n s_n^* = 1. \qquad \blacksquare$$
