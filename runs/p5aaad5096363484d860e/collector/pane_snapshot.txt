## Solution

We count the number of ways to write 2000 as an ordered-irrelevant sum of three
positive integers, i.e., the number of partitions of 2000 into exactly 3 parts.

**Setup.** A configuration is a triple $(a, b, c)$ with $1 \le a \le b \le c$ an
d $a + b + c = 2000$. We count such triples.

**Fixing the smallest part.** For a fixed $a$ with $1 \le a \le \lfloor 2000/3 \
rfloor = 666$, we need $b + c = 2000 - a$ with $a \le b \le c$, i.e., $a \le b \
le (2000-a)/2$. The number of valid $b$ is:

$$N(a) = \left\lfloor \frac{2000 - a}{2} \right\rfloor - a + 1.$$

**Evaluating $N(a)$ by parity.**

- **$a$ even**, $a = 2k$, $k = 1, \ldots, 333$:
$$\left\lfloor \frac{2000 - 2k}{2} \right\rfloor = 1000 - k, \quad N(2k) = (1000
 - k) - 2k + 1 = 1001 - 3k.$$

- **$a$ odd**, $a = 2k-1$, $k = 1, \ldots, 333$:
$$\left\lfloor \frac{2000 - (2k-1)}{2} \right\rfloor = \left\lfloor \frac{2001 -
 2k}{2} \right\rfloor = 1000 - k, \quad N(2k-1) = (1000 - k) - (2k-1) + 1 = 1002
 - 3k.$$

**Summing over even $a$** ($k = 1$ to $333$):
$$\sum_{k=1}^{333}(1001 - 3k) = 333 \cdot 1001 - 3 \cdot \frac{333 \cdot 334}{2}
 = 333333 - 166833 = 166500.$$

**Summing over odd $a$** ($k = 1$ to $333$):
$$\sum_{k=1}^{333}(1002 - 3k) = 333 \cdot 1002 - 166833 = 333666 - 166833 = 1668
33.$$

**Total:**
$$166500 + 166833 = 333333.$$

**Verification via closed form.** The number of partitions of $n$ into exactly 3
 parts equals $\operatorname{round}(n^2/12)$. For $n = 2000$:
$$\frac{2000^2}{12} = \frac{4000000}{12} = 333333.33\ldots, \quad \operatorname{
round} = 333333.$$

Equivalently, $\lfloor (n^2 + 3)/12 \rfloor = \lfloor 4000003/12 \rfloor = \lflo
or 333333.58\ldots \rfloor = 333333$. Both agree with the direct enumeration abo
ve.

**Answer:** The number of distinct configurations is $\boxed{333333}$.
