## Proof

Let $p = 101$ (prime). We compute
$$S = \sum_{k=1}^{\infty} \sum_{j=1}^{p-1} 2^{-\lfloor pk/j \rfloor}.$$

**Step 1: Swap summation and exploit periodicity.**

Since $\gcd(p, j) = 1$ for all $1 \le j \le p-1$ (as $p$ is prime), we have $\lf
loor p(k+j)/j \rfloor = \lfloor pk/j \rfloor + p$. So the inner sum over $k$ is
periodic with period $j$:

$$\sum_{k=1}^{\infty} 2^{-\lfloor pk/j \rfloor} = \frac{1}{1 - 2^{-p}} \sum_{r=1
}^{j} 2^{-\lfloor pr/j \rfloor} = \frac{U_j}{1 - 2^{-p}},$$

where $U_j := \sum_{r=1}^{j} 2^{-\lfloor pr/j \rfloor}$.

Thus $S = \frac{1}{1-2^{-p}} \sum_{j=1}^{p-1} U_j$.

**Step 2: Analyze $U_j$ via the floor values.**

For $r = j$: $\lfloor pj/j \rfloor = p$, contributing $2^{-p}$.

For $r = 1, \dots, j-1$: the values $\lfloor pr/j \rfloor$ are **distinct** (if
two were equal, then $|p(r_1 - r_2)/j| < 1$, forcing $r_1 = r_2$ since $j < p$).
 They lie in $\{1, \dots, p-1\}$ (lower bound: $\lfloor p/j \rfloor \ge 1$; uppe
r bound: $\lfloor p(j-1)/j \rfloor \le p-1$). So these $j-1$ distinct values for
m a subset $S_j \subseteq \{1, \dots, p-1\}$ with $|S_j| = j-1$.

**Claim:** $p - 1 \notin S_j$ for all $j$. Indeed, $q = p-1 \in S_j$ requires an
 integer in $[(p-1)j/p,\; j) \cap \{1,\dots,j-1\}$. Since $(p-1)j/p = j - j/p \i
n (j-1, j)$, the ceiling is $j$, which is excluded. So no such integer exists. ✓

Therefore: $U_j = 2^{-p} + \sum_{q \in S_j} 2^{-q}$, and summing over $j$:

$$\sum_{j=1}^{p-1} U_j = (p-1)\cdot 2^{-p} + \sum_{q=1}^{p-2} 2^{-q} \cdot N_q,$
$

where $N_q := |\{j \in \{1,\dots,p-1\} : q \in S_j\}|$.

**Step 3: Compute $N_q$.**

For $1 \le q \le p-2$: since $\gcd(p,j)=1$ and $1 \le q \le p-2$, neither $qj/p$
 nor $(q+1)j/p$ is an integer. So $q \in S_j$ iff $\lfloor (q+1)j/p \rfloor - \l
floor qj/p \rfloor = 1$ (the interval $[qj/p, (q+1)j/p)$ of length $j/p < 1$ con
tains an integer).

Using the classical identity $\sum_{j=1}^{p-1} \lfloor mj/p \rfloor = \frac{(m-1
)(p-1)}{2}$ for $\gcd(m,p)=1$ (proved via: residues $mj \bmod p$ permute $\{1,\d
ots,p-1\}$, so $\sum (mj \bmod p) = p(p-1)/2$, and $mj = p\lfloor mj/p\rfloor +
(mj \bmod p)$):

$$\sum_{j=1}^{p-1}\bigl(\lfloor (q+1)j/p\rfloor - \lfloor qj/p\rfloor\bigr) = \f
rac{q(p-1)}{2} - \frac{(q-1)(p-1)}{2} = \frac{p-1}{2}.$$

Each summand is $0$ or $1$, so $N_q = \frac{p-1}{2}$ for every $q = 1, \dots, p-
2$.

**Step 4: Assemble the result.**

$$\sum_{j=1}^{p-1} U_j = (p-1)\cdot 2^{-p} + \frac{p-1}{2}\sum_{q=1}^{p-2} 2^{-q
} = (p-1)\cdot 2^{-p} + \frac{p-1}{2}\bigl(1 - 2^{-(p-2)}\bigr).$$

$$= (p-1)\left(2^{-p} + \frac{1}{2} - 2^{-(p-1)}\right) = (p-1)\left(\frac{1}{2}
 - 2^{-p}\right).$$

Therefore:

$$S = \frac{(p-1)\left(\frac{1}{2} - 2^{-p}\right)}{1 - 2^{-p}} = (p-1)\cdot\fra
c{2^{p-1} - 1}{2^p - 1}.$$
