## Proof

**Setup and Reduction.** Let the cube have coordinates $(i,j,k) \in \{1,\ldots,n
\}^3$ with $n=10$. For each $x$-slice $\{i=\text{const}\}$, let $S^x_i$ be its s
et of colors; similarly $S^y_j, S^z_k$. The condition is $\{S^x_i\} = \{S^y_j\}
= \{S^z_k\}$ as multisets.

For each color $\alpha$, let $X_\alpha, Y_\alpha, Z_\alpha \subseteq \{1,\ldots,
n\}$ be the sets of indices where $\alpha$ appears in $x$-, $y$-, $z$-slices res
pectively. Since the three multisets are identical, the number of sets containin
g $\alpha$ is the same in each group, so $|X_\alpha| = |Y_\alpha| = |Z_\alpha|$.

**Relabeling.** There exist permutations $\sigma, \tau$ of $\{1,\ldots,n\}$ with
 $S^y_j = S^x_{\sigma(j)}$ and $S^z_k = S^x_{\tau(k)}$. Then $Y_\alpha = \sigma^
{-1}(X_\alpha)$ and $Z_\alpha = \tau^{-1}(X_\alpha)$. Substituting $(u,v,w) = (i
, \sigma(j), \tau(k))$ — a bijection on $\{1,\ldots,n\}^3$ — transforms the prob
lem so that every color $\alpha$ has the **same projection** $I_\alpha := X_\alp
ha$ on all three axes. In this relabeled problem, the slice condition is automat
ically satisfied (all three groups yield $\{T_1,\ldots,T_n\}$ where $T_u = \{\al
pha : u \in I_\alpha\}$), so we need only:

> **Reduced Problem.** Partition $\{1,\ldots,n\}^3$ into color classes $P_\alpha
$, where each $P_\alpha \subseteq I_\alpha^3$ projects surjectively to $I_\alpha
$ on every axis. Maximize the number of classes.

**Upper Bound via Weighting.** Assign to each cell $c = (u,v,w)$ the weight $w(c
) = 1/d(c)$, where $d(c)$ is the number of distinct values among $u,v,w$ (so $d
\in \{1,2,3\}$).

*Claim:* For any valid color $\alpha$ with $|I_\alpha| = m$ and cell set $P_\alp
ha$, we have $W(P_\alpha) := \sum_{c \in P_\alpha} w(c) \geq 1$.

*Proof of claim:* Since $P_\alpha$ projects surjectively to $I_\alpha$ on each a
xis, $|P_\alpha| \geq m$. Every cell in $I_\alpha^3$ has $d(c) \leq \min(3, m)$,
 so $w(c) \geq 1/\min(3,m)$.
- $m = 1$: all cells have $d=1$, so $W \geq 1$.
- $m = 2$: all cells have $d \leq 2$, so $w(c) \geq 1/2$ and $W \geq |P_\alpha|/
2 \geq 1$.
- $m \geq 3$: all cells have $d \leq 3$, so $w(c) \geq 1/3$ and $W \geq |P_\alph
a|/3 \geq m/3 \geq 1$. $\square$

Since colors partition all $n^3$ cells and each has weight $\geq 1$:

$$\text{# colors} \leq \sum_{\text{all cells}} w(c).$$

**Counting total weight.** The number of cells with $d$ distinct coordinates:
- $d=1$ (all equal): $n$ cells, weight $1$ each → total $n$.
- $d=2$ (exactly two equal): $6\binom{n}{2} = 3n(n-1)$ cells, weight $1/2$ each
→ total $\frac{3n(n-1)}{2}$.
- $d=3$ (all distinct): $6\binom{n}{3} = n(n-1)(n-2)$ cells, weight $1/3$ each →
 total $\frac{n(n-1)(n-2)}{3}$.

Total weight $= n + \frac{3n(n-1)}{2} + \frac{n(n-1)(n-2)}{3} = \frac{n(n+1)(2n+
1)}{6}$.

**Construction achieving the bound.** We construct a coloring in the relabeled p
roblem ($\sigma = \tau = \mathrm{id}$):

1. **Type-1 cells** $(a,a,a)$, $a=1,\ldots,n$: One color per cell with $I = \{a\
}$. Gives $n$ colors.

2. **Type-2 cells** (exactly two distinct coordinates): For each pair $\{a,b\}$,
 the 6 type-2 cells in $\{a,b\}^3$ are partitioned into 3 pairs, each projecting
 to $\{a,b\}$ on every axis:
   - $\{(a,a,b),(b,b,a)\}$, $\{(a,b,a),(b,a,b)\}$, $\{(b,a,a),(a,b,b)\}$.

   Gives $3\binom{n}{2}$ colors.

3. **Type-3 cells** (all coordinates distinct): For each triple $\{a,b,c\}$, the
 6 permutations of $(a,b,c)$ are partitioned into 2 Latin squares, each projecti
ng to $\{a,b,c\}$ on every axis:
   - $\{(a,b,c),(b,c,a),(c,a,b)\}$ (cyclic),
   - $\{(a,c,b),(b,a,c),(c,b,a)\}$ (anti-cyclic).

   Gives $2\binom{n}{3}$ colors.

**Verification.** Every cell is covered exactly once (cells are partitioned by t
ype, and within each type by value-set). Each color's cells project to its index
 set on all three axes. The slice condition holds automatically in the relabeled
 problem. The total number of colors is:

$$n + 3\binom{n}{2} + 2\binom{n}{3} = \frac{n(n+1)(2n+1)}{6}.$$

**Computation for $n = 10$:**

$$\frac{10 \cdot 11 \cdot 21}{6} = \frac{2310}{6} = 385.$$

This equals $1^2 + 2^2 + \cdots + 10^2 = 385$.

The upper bound and construction match, so the maximum number of colors is $\box
ed{385}$.
