Looking at this problem, I need to find the minimum number of vertices for a con
nected graph with minimum degree ≥ m ≥ 3 that has no Hamiltonian path.

## Proof

**Answer: 2m + 2.**

### Lower Bound: n ≥ 2m + 2

**Theorem (Hamiltonian path sufficient condition).** *If G is a connected graph
on n vertices with minimum degree δ(G) ≥ (n−1)/2, then G has a Hamiltonian path.
*

*Proof of theorem.* Add a new vertex v* adjacent to every vertex of G. The resul
ting graph G' has n+1 vertices and minimum degree δ(G') ≥ δ(G) + 1 ≥ (n−1)/2 + 1
 = (n+1)/2. By **Dirac's theorem** (a graph on n' ≥ 3 vertices with minimum degr
ee ≥ n'/2 is Hamiltonian), G' possesses a Hamiltonian cycle. Deleting v* from th
is cycle yields a Hamiltonian path in G. ∎

**Contrapositive:** If G has no Hamiltonian path, then δ(G) < (n−1)/2, i.e., (n−
1)/2 > δ(G) ≥ m, giving n − 1 > 2m, hence **n ≥ 2m + 2**.

### Upper Bound: Construction achieving n = 2m + 2

Consider the complete bipartite graph **K_{m, m+2}**, with parts A (size m) and
B (size m+2).

- **Vertex count:** m + (m+2) = **2m + 2**.
- **Connected:** Yes (complete bipartite with both parts nonempty).
- **Minimum degree:** Every vertex in A has degree m+2; every vertex in B has de
gree m. So δ = **m**. ✓
- **No Hamiltonian path:** In any bipartite graph with parts A, B, every path al
ternates between the parts, so the number of vertices used from each part differ
s by at most 1. A Hamiltonian path on 2m+2 (even) vertices would require exactly
 m+1 vertices from each part. But |A| = m < m+1, so **no Hamiltonian path exists
**. ✓

### Conclusion

The lower bound forces n ≥ 2m + 2, and the construction K_{m, m+2} achieves n =
2m + 2 with minimum degree m and no Hamiltonian path. Therefore the least possib
le number of vertices is:

$$\boxed{2m+2}$$
