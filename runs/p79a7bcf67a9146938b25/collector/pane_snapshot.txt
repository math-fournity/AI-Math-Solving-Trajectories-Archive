## Solution

**Answer leak check:** The problem statement contains only the integral to evalu
ate — no solution, hint, or answer is embedded. Proceeding.

On the unit circle $\mathcal{C}$, write $z = e^{i\theta}$, so $|z|=1$ and hence
$\bar z = z^{-1}$. Therefore for any integer $k$,
$$\overline{z^k} = \bar z^{\,k} = z^{-k}.$$

Expand the squared modulus:
$$|1+z^3+z^6|^2 = (1+z^3+z^6)\,\overline{(1+z^3+z^6)} = (1+z^3+z^6)(1+z^{-3}+z^{
-6}).$$

Multiplying out term by term:

| term | power of $z$ |
|---|---|
| $1\cdot 1,\; z^3\cdot z^{-3},\; z^6\cdot z^{-6}$ | $0$ (three copies $\Rightar
row 3$) |
| $1\cdot z^{-3},\; z^3\cdot z^{-6}$ | $-3$ (two copies $\Rightarrow 2z^{-3}$) |
| $z^3\cdot 1,\; z^6\cdot z^{-3}$ | $3$ (two copies $\Rightarrow 2z^{3}$) |
| $1\cdot z^{-6}$ | $-6$ ($\Rightarrow z^{-6}$) |
| $z^6\cdot 1$ | $6$ ($\Rightarrow z^{6}$) |

Hence on $\mathcal{C}$,
$$|1+z^3+z^6|^2 = 3 + 2z^{3} + 2z^{-3} + z^{6} + z^{-6}.$$

The integral in question is the contour integral
$$\frac{1}{2\pi i}\oint_{\mathcal{C}} |1+z^3+z^6|^2\,dz = \frac{1}{2\pi i}\oint_
{\mathcal{C}}\bigl(3 + 2z^{3} + 2z^{-3} + z^{6} + z^{-6}\bigr)\,dz.$$

By the standard identity (Cauchy's integral formula / residue theorem)
$$\frac{1}{2\pi i}\oint_{\mathcal{C}} z^{n}\,dz = \begin{cases} 1, & n = -1,\\[2
pt] 0, & n \neq -1,\end{cases}$$
the value of the integral equals the coefficient of $z^{-1}$ in the Laurent expa
nsion of the integrand on $\mathcal{C}$.

The expansion $3 + 2z^{3} + 2z^{-3} + z^{6} + z^{-6}$ contains only powers $0, \
pm 3, \pm 6$. **There is no $z^{-1}$ term**, so its coefficient is $0$.

Therefore
$$\frac{1}{2\pi i}\int_{\mathcal{C}} |1+z^3+z^6|^2\,dz = 0.$$
