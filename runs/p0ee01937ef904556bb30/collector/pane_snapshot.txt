## Proof

Let $k$ be any field, and define

$$R = k[x_1, x_2, x_3, \dots]$$

to be the polynomial ring over $k$ in countably infinitely many indeterminates $
x_1, x_2, x_3, \ldots$. Concretely, an element of $R$ is a finite $k$-linear com
bination of monomials $x_{i_1}^{a_1}\cdots x_{i_m}^{a_m}$ where $m \ge 0$, $i_1
< \cdots < i_m$, and $a_j \ge 0$; only finitely many variables appear in any giv
en element.

### Step 1. $R$ is non-Noetherian.

Consider the ideal

$$I = (x_1, x_2, x_3, \dots) \subseteq R,$$

i.e. the ideal of all polynomials with zero constant term. Suppose for contradic
tion that $I$ is finitely generated, say $I = (f_1, \dots, f_n)$. Each $f_j$ is
a polynomial, hence involves only finitely many of the variables $x_i$. Therefor
e the set

$$S = \bigcup_{j=1}^{n} \{\text{variables appearing in } f_j\}$$

is finite. Choose an index $m$ with $x_m \notin S$.

Since $x_m \in I = (f_1, \dots, f_n)$, there exist $g_1, \dots, g_n \in R$ with
$x_m = g_1 f_1 + \cdots + g_n f_n$. Every monomial on the right-hand side is div
isible by some monomial of some $f_j$, hence every monomial on the right involve
s at least one variable from $S$. But the left-hand side $x_m$ is a monomial inv
olving only $x_m \notin S$, a contradiction (a monomial in a variable outside $S
$ cannot equal a sum of monomials each involving a variable in $S$, by uniquenes
s of monomial representations in a polynomial ring).

Hence $I$ is not finitely generated, so $R$ is not Noetherian.

### Step 2. $R \cong R[x]$.

The polynomial ring in one variable over $R$ is

$$R[x] = k[x_1, x_2, x_3, \dots][x],$$

i.e. the polynomial ring over $k$ in the countably infinite set of indeterminate
s $\{x, x_1, x_2, x_3, \dots\}$.

Define a $k$-algebra homomorphism

$$\varphi : R[x] \longrightarrow R$$

by specifying its values on the indeterminates (which determines it uniquely, si
nce $R[x]$ is the free commutative $k$-algebra on $\{x, x_1, x_2, \dots\}$):

$$\varphi(x) = x_1, \qquad \varphi(x_i) = x_{i+1} \;\; (i \ge 1), \qquad \varphi
|_k = \mathrm{id}_k.$$

The map $\varphi$ sends the set of indeterminates $\{x, x_1, x_2, x_3, \dots\}$
bijectively onto the set $\{x_1, x_2, x_3, x_4, \dots\}$, which is the full set
of indeterminates of $R$. A homomorphism of polynomial rings over $k$ that maps
the set of indeterminates bijectively onto the set of indeterminates is an isomo
rphism (its inverse is the homomorphism induced by the inverse bijection on vari
ables). Explicitly, the inverse $\psi : R \to R[x]$ is determined by

$$\psi(x_1) = x, \qquad \psi(x_{i+1}) = x_i \;\; (i \ge 1), \qquad \psi|_k = \ma
thrm{id}_k,$$

and one checks directly that $\varphi \circ \psi = \mathrm{id}_R$ and $\psi \cir
c \varphi = \mathrm{id}_{R[x]}$.

Therefore $R[x] \cong R$.

### Conclusion.

The ring $R = k[x_1, x_2, x_3, \dots]$ is non-Noetherian (Step 1) and satisfies
$R \cong R[x]$ (Step 2), providing the required example.
