## Solution

**Total outcomes:** $20^3 = 8000$ ordered triples $(a,b,c)$ with each value in $
\{1,\dots,20\}$.

**Triangle condition (positive area):** The three values form a non-degenerate t
riangle iff the strict triangle inequalities hold:
$$a+b>c,\quad a+c>b,\quad b+c>a.$$

**Counting the complement.** A triple fails iff at least one inequality is viola
ted, i.e. $a+b\le c$ or $a+c\le b$ or $b+c\le a$.

These three failure events are **disjoint**: if $a+b\le c$ and $a+c\le b$ both h
eld, then $2a \le 0$, impossible since $a\ge 1$. By symmetry they have equal siz
e.

Consider the event $a+b\le c$. Since $a,b\ge 1$, this forces $c \ge a+b \ge a+1
> a$ and $c > b$, so $c$ is strictly the largest—confirming disjointness.

**Count $N = \#\{(a,b,c): a,b,c\in\{1,\dots,20\},\ a+b\le c\}$.**

For fixed $c$, the number of positive-integer pairs $(a,b)$ with $a+b\le c$ is
$$\sum_{s=2}^{c}(s-1) = \frac{c(c-1)}{2}.$$
Since $c\le 20$, we have $a+b\le 20$, so $a,b\le 19 < 20$; the upper bound of 20
 never binds. Thus
$$N = \sum_{c=1}^{20}\frac{c(c-1)}{2} = \frac{1}{2}\!\left(\sum_{c=1}^{20}c^2 -
\sum_{c=1}^{20}c\right) = \frac{1}{2}\!\left(\frac{20\cdot21\cdot41}{6} - 210\ri
ght) = \frac{1}{2}(2870-210)=1330.$$

**Total failing triples:** $3N = 3\cdot 1330 = 3990$.

**Successful triples:** $8000 - 3990 = 4010$.

**Probability:**
$$\frac{4010}{8000} = \frac{401}{800}.$$

Since $401$ is prime (no prime divisor $\le \sqrt{401}\approx 20$) and $800 = 2^
5\cdot 5^2$, we have $\gcd(401,800)=1$. So $a=401$, $b=800$.

$$a+b = 401 + 800 = \boxed{1201}.$$
