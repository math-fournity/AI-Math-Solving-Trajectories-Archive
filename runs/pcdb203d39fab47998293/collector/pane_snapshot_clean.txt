## Proof

Let $t = c^2 \geq 0$. The system is:
$$xy + xz = 20, \quad xy + yz = 13, \quad xz + yz = t.$$

**Step 1: Solve for the pairwise products.**

Adding all three equations: $2(xy + yz + xz) = 33 + t$, so $xy + yz + xz = \frac
{33+t}{2}$.

Subtracting each equation in turn:
$$yz = \tfrac{33+t}{2} - 20 = \tfrac{t-7}{2}, \qquad xz = \tfrac{33+t}{2} - 13 =
 \tfrac{t+7}{2}, \qquad xy = \tfrac{33+t}{2} - t = \tfrac{33-t}{2}.$$

**Step 2: Determine when real $x, y, z$ exist.**

Given $p = xy$, $q = yz$, $r = xz$, real $x,y,z$ exist iff:

- **All nonzero:** $pqr > 0$ (then $x^2 = pr/q$, $y^2 = pq/r$, $z^2 = qr/p$ are
all positive when $pqr > 0$).
- **Some zero:** If exactly one product is zero, say $q = yz = 0$ with $p, r \ne
q 0$, then $y=0$ forces $p=xy=0$ (contradiction) and $z=0$ forces $r=xz=0$ (cont
radiction) — **impossible**. Two products can be zero only if they share a varia
ble set to zero, but checking all pairs shows no two of $\frac{33-t}{2}, \frac{t
-7}{2}, \frac{t+7}{2}$ vanish simultaneously for $t \geq 0$.

So we need all three products nonzero and:
$$pqr = \frac{(33-t)(t-7)(t+7)}{8} = \frac{(33-t)(t^2-49)}{8} > 0.$$

**Step 3: Sign analysis of $g(t) = (33-t)(t-7)(t+7)$ for $t \geq 0$.**

Zeros at $t = 7, 33$ (and $t=-7$, outside domain).

| Interval | $33-t$ | $t-7$ | $t+7$ | Product |
|---|---|---|---|---|
| $0 \leq t < 7$ | $+$ | $-$ | $+$ | $-$ |
| $7 < t < 33$ | $+$ | $+$ | $+$ | $+$ |
| $t > 33$ | $-$ | $+$ | $+$ | $-$ |

So $g(t) > 0$ iff $t \in (7, 33)$.

**Step 4: Boundary verification.**

- $t = 7$: $yz = 0$, $xy = 13$, $xz = 7$. Then $y=0 \Rightarrow xy=0\neq 13$; $z
=0 \Rightarrow xz=0\neq 7$. No solution.
- $t = 33$: $xy = 0$, $yz = 13$, $xz = 20$. Then $x=0 \Rightarrow xz=0\neq 20$;
$y=0 \Rightarrow yz=0\neq 13$. No solution.

Both endpoints are excluded, confirming $t \in (7, 33)$ (open interval).

**Step 5: Verification with a sample.**

Take $t = 20$: $xy = \frac{13}{2}$, $yz = \frac{13}{2}$, $xz = \frac{27}{2}$.
- $x(y+z) = xy + xz = \frac{13+27}{2} = 20$ ✓
- $y(z+x) = yz + xy = \frac{13+13}{2} = 13$ ✓
- $z(x+y) = xz + yz = \frac{27+13}{2} = 20 = t$ ✓
- $x^2 = \frac{(xy)(xz)}{yz} = \frac{27}{2} > 0$, $y^2 = \frac{(xy)(yz)}{xz} = \
frac{169}{54} > 0$, $z^2 = \frac{27}{2} > 0$ ✓

**Step 6: Enumerate integer values and sum.**

The integer values of $c^2 = t$ in $(7, 33)$ are $8, 9, 10, \ldots, 32$ — that i
s, $32 - 8 + 1 = 25$ integers.

$$\text{Sum} = \frac{(8 + 32) \times 25}{2} = \frac{40 \times 25}{2} = 500.$$

## Answer

The sum of all possible integer values of $c^2$ is $\boxed{500}$.
