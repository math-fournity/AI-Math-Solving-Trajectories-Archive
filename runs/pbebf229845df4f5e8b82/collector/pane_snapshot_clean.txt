## Proof

**Setup.** We consider the standard sequential coin-revelation game. There are $
2m$ coins, exactly $m$ showing heads and $m$ showing tails, arranged in a unifor
mly random order. The coins are revealed one at a time. Before each coin is reve
aled, the player—knowing the results of all previously revealed coins and knowin
g the total split is $m$ heads / $m$ tails—must guess whether the next coin is h
eads or tails. The player's score is the total number of correct guesses. We pro
ve that the **minority strategy** (guess heads when more tails have been reveale
d so far, guess tails when more heads have been revealed so far) is optimal.

---

**Reduction to a greedy rule.** Suppose that after some number of reveals, $h$ h
eads and $t$ tails have been determined ($h+t$ coins revealed). Among the $2m -
h - t$ remaining coins, there are $m - h$ heads and $m - t$ tails. Since the rem
aining coins form a uniformly random permutation of this residual multiset, the
probability that the next coin is heads is

$$\frac{m-h}{2m-h-t},$$

and the probability it is tails is

$$\frac{m-t}{2m-h-t}.$$

Now $m - h > m - t$ if and only if $t > h$. Hence:

- **More tails determined ($t > h$)** $\Rightarrow$ heads is the more probable s
ide $\Rightarrow$ the minority strategy says *guess heads*. ✓
- **More heads determined ($h > t$)** $\Rightarrow$ tails is the more probable s
ide $\Rightarrow$ the minority strategy says *guess tails*. ✓
- **Equal ($h = t$)** $\Rightarrow$ both sides equally probable $\Rightarrow$ ei
ther guess is equally good. ✓

So the minority strategy is exactly the **greedy strategy**: at every step, gues
s the side that is more likely given the current information. It remains to prov
e that this greedy strategy is *optimal* (maximizes the expected total number of
 correct guesses), not merely locally reasonable.

---

**Optimality of the greedy strategy.** We prove a general lemma.

> **Lemma.** A random permutation of a multiset containing $a$ copies of $H$ and
 $b$ copies of $T$ is revealed element by element. Before each reveal the predic
tor guesses the next element, knowing $a$ and $b$ and all past reveals. The stra
tegy that at each step guesses the majority-remaining element (either when $a=b$
) maximizes the expected number of correct guesses.

*Proof of Lemma.* Define $\mathrm{OPT}(a,b)$ to be the maximum achievable expect
ed number of correct guesses starting from a state with $a$ heads and $b$ tails
remaining, and define $G(a,b)$ to be the expected score achieved by the greedy (
majority-remaining) strategy from that state. We prove $\mathrm{OPT}(a,b) = G(a,
b)$ for all $a, b \ge 0$ by strong induction on $a+b$.

**Base cases.** When $a+b = 0$: $\mathrm{OPT}(0,0)=G(0,0)=0$. When $a+b=1$: only
 one type remains, so every strategy (including greedy) guesses it correctly; $\
mathrm{OPT}(a,0)=G(a,0)=a$ and $\mathrm{OPT}(0,b)=G(0,b)=b$.

**Inductive step.** Assume $\mathrm{OPT}(a',b') = G(a',b')$ for all $a'+b' < a+b
$. At state $(a,b)$ with $a+b\ge 2$, the player chooses a guess $g\in\{H,T\}$. C
onditioning on the actual next coin:

- **Guess $H$:** correct with probability $\frac{a}{a+b}$ (transitioning to $(a-
1,b)$), wrong with probability $\frac{b}{a+b}$ (transitioning to $(a,b-1)$). Usi
ng the induction hypothesis to replace $\mathrm{OPT}$ by $G$ in the successor st
ates:
$$V_H \;=\; \frac{a}{a+b}\bigl(1 + G(a-1,b)\bigr) + \frac{b}{a+b}\,G(a,b-1).$$

- **Guess $T$:** by the same reasoning,
$$V_T \;=\; \frac{b}{a+b}\bigl(1 + G(a,b-1)\bigr) + \frac{a}{a+b}\,G(a-1,b).$$

The optimal value is $\mathrm{OPT}(a,b) = \max(V_H, V_T)$. Computing the differe
nce:

$$V_H - V_T \;=\; \frac{a}{a+b} - \frac{b}{a+b} \;=\; \frac{a-b}{a+b}.$$

- If $a > b$: $V_H > V_T$, so $\mathrm{OPT}(a,b) = V_H$. Greedy guesses $H$ (the
 majority-remaining side), so $G(a,b) = V_H = \mathrm{OPT}(a,b)$. ✓
- If $b > a$: $V_T > V_H$, so $\mathrm{OPT}(a,b) = V_T$. Greedy guesses $T$, so
$G(a,b) = V_T = \mathrm{OPT}(a,b)$. ✓
- If $a = b$: $V_H = V_T$, so $\mathrm{OPT}(a,b) = V_H = V_T$. Greedy guesses ei
ther (both give the same value), so $G(a,b) = \mathrm{OPT}(a,b)$. ✓

This closes the induction, proving the Lemma. $\square$

---

**Applying the Lemma to the original game.** In our game the total split is $m$
heads and $m$ tails. After $h$ heads and $t$ tails have been determined, the res
idual multiset has $a = m - h$ heads and $b = m - t$ tails. By the Lemma, the op
timal action is to guess the majority-remaining side:

$$a > b \;\Longleftrightarrow\; m-h > m-t \;\Longleftrightarrow\; t > h \;\Longl
eftrightarrow\; \text{more tails determined} \;\Longrightarrow\; \text{guess hea
ds},$$

$$b > a \;\Longleftrightarrow\; m-t > m-h \;\Longleftrightarrow\; h > t \;\Longl
eftrightarrow\; \text{more heads determined} \;\Longrightarrow\; \text{guess tai
ls},$$

and when $h = t$ (equivalently $a = b$) either guess is equally optimal.

This is precisely the stated strategy: **choose heads when more coins have been
determined tails, and choose tails when more coins have been determined heads.**
 By the Lemma this strategy achieves $\mathrm{OPT}$ at every state, hence it is
globally optimal. $\blacksquare$
