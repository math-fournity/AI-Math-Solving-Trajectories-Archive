# Problem

In a secure server facility, a technician named Leo must map out the internal data architecture of a 7x7 grid of 49 processing cores. Each core has been assigned a unique identification code, consisting of a distinct natural number from 1 to 49, but the specific layout of these codes is encrypted and unknown to him.

Leo has access to a diagnostic tool that allows him to select any square-shaped sub-region of the grid (from a 1x1 single core up to the full 7x7 grid). When he selects a square, the system generates a readout listing exactly which ID codes are contained within that specific sub-region, though it does not specify which code belongs to which individual core.

By strategically querying different square zones and comparing the sets of IDs provided by the system, Leo aims to pinpoint the exact location of every ID code in the 7x7 grid. 

What is the minimum number of square-region queries Leo must perform to uniquely determine the location of every ID code from 1 to 49?
