# Solution

## Setup

Both $T_1$ (inside, $r<a$) and $T_2$ (outside, $r>a$) satisfy Laplace's equation
 (steady state, sources only on the boundary). Using the axisymmetric expansion
in Legendre polynomials $P_n(\cos\theta)$:

**Inside** (finite at $r=0$):
$$T_1(r,\theta) = \sum_{n=0}^{\infty} \alpha_n\, r^n\, P_n(\cos\theta)$$

**Outside** ($T_2\to T_\infty$ as $r\to\infty$):
$$T_2(r,\theta) = T_\infty + \sum_{n=0}^{\infty} \beta_n\, r^{-(n+1)}\, P_n(\cos
\theta)$$

## Boundary Conditions at $r=a$

**1. Temperature continuity** $T_1(a,\theta)=T_2(a,\theta)$:

- $n=0$: $\;\alpha_0 = T_\infty + \beta_0/a$
- $n\ge 1$: $\;\alpha_n\, a^n = \beta_n\, a^{-(n+1)} \;\Longrightarrow\; \beta_n
 = \alpha_n\, a^{2n+1}$

**2. Flux jump** $k_1\frac{\partial T_1}{\partial r} - k_2\frac{\partial T_2}{\p
artial r} = \frac{1}{a}\sum q_n P_n(\cos\theta)$:

Computing the radial derivatives at $r=a$:
$$k_1\sum_{n} n\,\alpha_n\, a^{n-1} P_n + k_2\sum_{n}(n+1)\,\beta_n\, a^{-(n+2)}
 P_n = \frac{1}{a}\sum_n q_n P_n$$

Matching coefficients for each $n$:
$$k_1\, n\,\alpha_n\, a^{n-1} + k_2\,(n+1)\,\beta_n\, a^{-(n+2)} = \frac{q_n}{a}
$$

## Solving for the Coefficients

**For $n\ge 1$**: Substitute $\beta_n = \alpha_n\, a^{2n+1}$:

$$\alpha_n\, a^{n-1}\bigl[k_1\, n + k_2\,(n+1)\bigr] = \frac{q_n}{a}$$

$$\boxed{\alpha_n = \frac{q_n}{a^n\bigl[k_1\, n + k_2\,(n+1)\bigr]}, \qquad \bet
a_n = \frac{q_n\, a^{n+1}}{k_1\, n + k_2\,(n+1)}}$$

**For $n=0$**: The $k_1$ term vanishes ($n=0$), giving:
$$k_2\,\beta_0\, a^{-2} = \frac{q_0}{a} \;\Longrightarrow\; \beta_0 = \frac{q_0\
, a}{k_2}$$

From continuity: $\alpha_0 = T_\infty + \beta_0/a = T_\infty + \dfrac{q_0}{k_2}$
.

Note the $n=0$ formulas are consistent with the general expressions above (setti
ng $n=0$ gives $\alpha_0 = q_0/k_2$ for the source-driven part, with $T_\infty$
added separately).

## Complete Solutions

$$\boxed{T_1(r,\theta) = T_\infty + \sum_{n=0}^{\infty} \frac{q_n\, r^n}{a^n\big
l[k_1\, n + k_2\,(n+1)\bigr]}\, P_n(\cos\theta), \qquad r \le a}$$

$$\boxed{T_2(r,\theta) = T_\infty + \sum_{n=0}^{\infty} \frac{q_n\, a^{n+1}}{\bi
gl[k_1\, n + k_2\,(n+1)\bigr]\, r^{n+1}}\, P_n(\cos\theta), \qquad r \ge a}$$

## Verification

- **$n=0$ flux**: $k_1\cdot 0 - k_2\cdot(-\beta_0/a^2) = k_2\, q_0 a/(k_2 a^2) =
 q_0/a$ ✓
- **$n\ge 1$ flux**: $k_1 n\alpha_n a^{n-1}+k_2(n+1)\beta_n a^{-(n+2)} = \alpha_
n a^{n-1}[k_1 n+k_2(n+1)]=q_n/a$ ✓
- **Continuity**: $\alpha_n a^n = \beta_n a^{-(n+1)}$ follows from $\beta_n=\alp
ha_n a^{2n+1}$ ✓
- **Regularity**: $T_1$ finite at $r=0$ (only non-negative powers); $T_2\to T_\i
nfty$ as $r\to\infty$ ✓

## Temperature at the Center

At $r=0$, all terms with $n\ge 1$ vanish (since $r^n\to 0$), and $P_0(\cos\theta
)=1$:

$$T_1(0,\theta) = T_\infty + \frac{q_0}{k_2}$$

$$\boxed{T_{\text{center}} = T_\infty + \frac{q_0}{k_2}}$$

where $q_0 = \frac{1}{2}\int_0^\pi q(\theta)\, a\,\sin\theta\, d\theta$ is the t
otal heat source strength (the $n=0$ Legendre coefficient of $a\,q(\theta)$). Ph
ysically, the total heat output $Q_{\text{tot}} = 4\pi a\, q_0$ flows radially o
utward through the infinite medium, giving a steady temperature rise $q_0/k_2 =
Q_{\text{tot}}/(4\pi k_2 a)$ above $T_\infty$ — exactly the monopole contributio
n.
