## Proof

**Definition.** A ring $R$ is *simple* if its only two-sided ideals are $0$ and
$R$. A ring is *(left) Artinian* if it satisfies the descending chain condition
on left ideals.

**Counterexample.** Let $k$ be a field of characteristic $0$. The *first Weyl al
gebra* is
$$A_1(k) = k\langle x, y \rangle / (xy - yx - 1).$$
Using the relation $yx = xy - 1$, every element admits a unique expression $\sum
_{i,j} c_{ij}\, x^i y^j$ (finite sum, $c_{ij} \in k$), so $\{x^i y^j : i,j \ge 0
\}$ is a $k$-basis.

### Claim 1. $A_1(k)$ is simple.

Let $I \ne 0$ be a two-sided ideal and pick $0 \ne a \in I$. Write $a = \sum_{i=
0}^{N} p_i(y)\, x^i$ with $p_i(y) \in k[y]$ and $p_N(y) \ne 0$ (collecting by po
wers of $x$). Since $I$ is two-sided, $[a, y] = ay - ya \in I$.

A short induction using $yx = xy - 1$ gives $yx^i = x^i y - i\, x^{i-1}$, hence
$$[x^i, y] = i\, x^{i-1}, \qquad\text{so}\qquad [a, y] = \sum_{i=1}^{N} i\, p_i(
y)\, x^{i-1}.$$
The leading coefficient is $N\, p_N(y) \ne 0$ (since $\operatorname{char} k = 0$
), so $[a,y]$ is a *nonzero* element of $I$ whose $x$-degree is $N-1$. Repeating
, we obtain a nonzero element $b = p(y) \in I \cap k[y]$.

Now use $[b, x] = bx - xb \in I$. From $y^j x = x y^j - j\, y^{j-1}$ we get $[y^
j, x] = -j\, y^{j-1}$, so $[b, x] = -p'(y)$ (formal derivative). Since $\operato
rname{char} k = 0$, if $\deg p \ge 1$ then $p' \ne 0$, yielding a nonzero elemen
t of $I$ of smaller $y$-degree. Iterating reduces to a nonzero constant $c \in k
^\times \cap I$. Then $c$ is a unit, so $I = A_1(k)$. ∎

### Claim 2. $A_1(k)$ is a domain but not a division ring.

*Domain.* Filter $A_1(k)$ by total degree: $F_d = \operatorname{span}\{x^i y^j :
 i+j \le d\}$. The associated graded ring is $\operatorname{gr} A_1(k) \cong k[x
,y]$, a polynomial ring in two variables, hence a domain. A standard result for
filtered rings says: if $\operatorname{gr} R$ is a domain, then $R$ is a domain.
 So $A_1(k)$ has no zero divisors.

*Not a division ring.* Define a $k$-algebra homomorphism $\rho: A_1(k) \to \oper
atorname{End}_k(k[t])$ by
$$\rho(x) = \text{multiplication by } t, \qquad \rho(y) = -\tfrac{d}{dt}.$$
Indeed $\rho(x)\rho(y) - \rho(y)\rho(x) = -t\tfrac{d}{dt} + \tfrac{d}{dt}\circ t
 = \mathrm{id}$, so the defining relation is satisfied and $\rho$ is a unital ho
momorphism. The operator $\rho(x) = M_t$ is not surjective (the constant polynom
ial $1$ is not $t \cdot f(t)$ for any $f$), hence not invertible in $\operatorna
me{End}_k(k[t])$. If $x$ were a unit in $A_1(k)$, its image under the unital map
 $\rho$ would be a unit — contradiction. So $x$ is not invertible and $A_1(k)$ i
s not a division ring.

### Claim 3. $A_1(k)$ is not left Artinian.

We use the standard theorem: **a left Artinian domain is a division ring.**

*Proof of the theorem.* Let $R$ be a left Artinian domain and $0 \ne a \in R$. T
he descending chain $R \supseteq Ra \supseteq Ra^2 \supseteq \cdots$ stabilizes:
 $Ra^n = Ra^{n+1}$ for some $n$. So $a^n = b\, a^{n+1}$ for some $b \in R$, and
since $R$ is a domain we cancel $a^n$ to get $1 = ba$. Thus every nonzero elemen
t has a left inverse; in a domain a left inverse is also a right inverse ($ba =
1 \Rightarrow (ab-1)a = a(ba) - a = a - a = 0 \Rightarrow ab = 1$). Hence $R$ is
 a division ring. ∎

By Claim 2, $A_1(k)$ is a domain but not a division ring. By the theorem above,
$A_1(k)$ cannot be left Artinian.

### Conclusion

$A_1(k)$ is a simple ring (Claim 1) that is not Artinian (Claim 3). Therefore **
not every simple ring is Artinian**. $\blacksquare$
