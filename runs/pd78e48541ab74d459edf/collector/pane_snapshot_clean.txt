## Proof

**Step 1: Relate the partial sum to a binomial probability.**

Set $p = \frac{a-1}{a}$ and $q = \frac{1}{a}$, so $p + q = 1$ and $p, q \in (0,1
)$ since $a > 1$.

Observe that $1 - \frac{1}{a} = \frac{a-1}{a} = p$, so the cutoff is $k \leq np$
.

Rewrite each term using $(a-1)^k = a^k \cdot p^k / q^k$... more directly:

$$\binom{n}{k}(a-1)^k = a^n \binom{n}{k} \left(\frac{a-1}{a}\right)^k \left(\fra
c{1}{a}\right)^{n-k} = a^n \binom{n}{k} p^k q^{n-k}.$$

Therefore, defining $S_n = \sum_{k \leq np} \binom{n}{k}(a-1)^k$ (whether $k$ st
arts at 0 or 1 is immaterial for the exponential rate, as the $k=0$ term is the
constant 1):

$$S_n = a^n \sum_{k \leq np} \binom{n}{k} p^k q^{n-k} = a^n \cdot P(X_n \leq np)
,$$

where $X_n \sim \operatorname{Binomial}(n, p)$.

**Verification of the full sum:** Indeed $\sum_{k=0}^{n}\binom{n}{k}(a-1)^k = (1
+(a-1))^n = a^n$, confirming the normalization.

**Step 2: Show $P(X_n \leq np) \to \frac{1}{2}$.**

The random variable $X_n$ has mean $np$ and variance $npq$. By the Central Limit
 Theorem:

$$\frac{X_n - np}{\sqrt{npq}} \xrightarrow{d} N(0,1).$$

Since $P(X_n \leq np) = P\!\left(\frac{X_n - np}{\sqrt{npq}} \leq 0\right)$, and
 the limiting standard normal CDF is continuous at 0:

$$P(X_n \leq np) \longrightarrow \Phi(0) = \frac{1}{2}.$$

(The integer lattice correction is $O(1/\sqrt{n})$ and vanishes; whether $np$ is
 an integer or not does not affect the limit, since $P(X_n = \lfloor np \rfloor)
 = O(1/\sqrt{n}) \to 0$ by the local CLT.)

**Step 3: Compute the limit.**

Since $P(X_n \leq np) \to \frac{1}{2} > 0$, the logarithm $\log_a P(X_n \leq np)
 \to \log_a \frac{1}{2}$, which is a **finite constant**.

Now:

$$\frac{\log_a S_n}{n} = \frac{\log_a\!\big(a^n \cdot P(X_n \leq np)\big)}{n} =
\frac{n + \log_a P(X_n \leq np)}{n} = 1 + \frac{\log_a P(X_n \leq np)}{n}.$$

Since $\log_a P(X_n \leq np)$ converges to a finite constant, $\frac{\log_a P(X_
n \leq np)}{n} \to 0$.

Therefore:

$$\lim_{n\to\infty} \frac{\log_a S_n}{n} = 1 + 0 = \boxed{1}.$$

**Sanity checks:**
- **$a=2$:** $p=q=\tfrac12$, $S_n = \sum_{k \le n/2}\binom{n}{k} \approx 2^{n-1}
$ by symmetry, so $\log_2 S_n / n \to 1$. ✓
- **$a=3$:** $p=\tfrac23$, $S_n = \sum_{k\le 2n/3}\binom{n}{k}2^k \approx 3^n/2$
, so $\log_3 S_n/n \to 1$. ✓
