## Solution

**Answer:** The series converges if and only if $\alpha > \dfrac{n}{k}$.

### Proof

Let $g(x) = (x_1^k + x_2^k + \cdots + x_n^k)^{-\alpha}$ for $x = (x_1,\ldots,x_n
) \in [1,\infty)^n$. Since each $x_i^k$ is increasing in $x_i$ (for $x_i \geq 1$
, $k$ a positive integer), $g$ is **decreasing in each coordinate**. The standar
d multivariate integral test then gives:

$$\int_{[1,\infty)^n} g(x)\,dx \;\leq\; \sum_{a \in \mathbb{N}^n} g(a) \;\leq\;
g(1,\ldots,1) + \int_{[1,\infty)^n} g(x)\,dx.$$

(The lower bound holds because $g(a) \geq g(x)$ for $x \in [a_1,a_1+1]\times\cdo
ts\times[a_n,a_n+1]$; the upper bound because $g(a) \leq g(x)$ for $x \in [a_1-1
,a_1]\times\cdots\times[a_n-1,a_n]$ when all $a_i \geq 2$, with the finitely man
y terms having some $a_i=1$ absorbed into the constant.) Hence the series conver
ges **if and only if** the integral $I = \int_{[1,\infty)^n} (x_1^k+\cdots+x_n^k
)^{-\alpha}\,dx$ converges.

**Evaluating the integral via the layer-cake (distribution function) method.**

Define the distribution function
$$\mu(t) = \operatorname{vol}\bigl\{x \in [0,\infty)^n : x_1^k + \cdots + x_n^k
\leq t\bigr\}.$$

By the scaling $x_i = t^{1/k} y_i$, the region $\{x_1^k+\cdots+x_n^k \leq t\}$ m
aps to $\{y_1^k+\cdots+y_n^k \leq 1\}$, so
$$\mu(t) = t^{n/k}\, V, \qquad V := \operatorname{vol}\bigl\{y \in [0,\infty)^n
: y_1^k+\cdots+y_n^k \leq 1\bigr\} < \infty.$$

Thus $\mu(t) = V\, t^{n/k}$ exactly (a homogeneous function of degree $n/k$).

Now write $I$ using the layer-cake representation. Setting $f(x) = (x_1^k+\cdots
+x_n^k)^{-\alpha}$, we have $\{f > s\} = \{x_1^k+\cdots+x_n^k < s^{-1/\alpha}\}$
, so $|\{f>s\}| = \mu(s^{-1/\alpha}) = V\, s^{-n/(k\alpha)}$. Therefore
$$I = \int_0^\infty |\{f > s\}|\,ds = \int_0^\infty V\, s^{-n/(k\alpha)}\,ds.$$

(The contribution from $s$ near $0$ corresponds to the bounded part of the domai
n and is finite; the only question is the behavior as $s \to \infty$, i.e., $x \
to \infty$.)

The integral $\int^\infty s^{-n/(k\alpha)}\,ds$ converges at infinity if and onl
y if the exponent satisfies
$$-\frac{n}{k\alpha} < -1 \quad\Longleftrightarrow\quad \frac{n}{k\alpha} > 1 \q
uad\Longleftrightarrow\quad \alpha > \frac{n}{k}.$$

When $\alpha \leq n/k$, the exponent $-n/(k\alpha) \geq -1$ and the integral div
erges.

**Conclusion.** The series
$$\sum_{a\in\mathbb{N}^n}\left(\sum_{i=1}^n a_i^k\right)^{-\alpha}$$
converges if and only if $\boxed{\alpha > \dfrac{n}{k}}$.
