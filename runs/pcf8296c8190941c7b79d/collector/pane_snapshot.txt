## Solution

**Claim:** $\mathbb{Q}(\pi^2) \cap \mathbb{Q}(\pi^2 - \pi) = \mathbb{Q}$.

**Proof.**

Since $\pi$ is transcendental over $\mathbb{Q}$, we may treat it as an indetermi
nate $t$. Any element of $\mathbb{Q}(\pi^2)$ has the form $R(\pi^2)$ for some $R
 \in \mathbb{Q}(x)$, and any element of $\mathbb{Q}(\pi^2-\pi)$ has the form $S(
\pi^2-\pi)$ for some $S \in \mathbb{Q}(x)$.

Suppose $f \in \mathbb{Q}(\pi^2) \cap \mathbb{Q}(\pi^2-\pi)$. Then there exist r
ational functions $R, S \in \mathbb{Q}(x)$ with
$$R(\pi^2) = S(\pi^2 - \pi).$$
Since $\pi$ is transcendental, this holds as an identity of rational functions i
n $\mathbb{Q}(t)$:
$$R(t^2) = S(t^2 - t). \tag{$\star$}$$

**Step 1: Symmetrize.** Substitute $t \mapsto -t$ in $(\star)$. Since $(-t)^2 =
t^2$ and $(-t)^2 - (-t) = t^2 + t$, we get
$$R(t^2) = S(t^2 + t).$$
Combining with $(\star)$: $S(t^2 - t) = S(t^2 + t)$ for all $t$.

**Step 2: Reduce to a polynomial identity.** Write $S = P/Q$ where $P, Q \in \ma
thbb{Q}[x]$ are coprime. Set $A = t^2 - t$ and $B = t^2 + t$. The identity $S(A)
 = S(B)$ gives
$$P(A)\,Q(B) = P(B)\,Q(A).$$

Since $\gcd(P, Q) = 1$ in $\mathbb{Q}[x]$, there exist $a(x), b(x) \in \mathbb{Q
}[x]$ with $a(x)P(x) + b(x)Q(x) = 1$. Substituting $x = A(t)$ yields $a(A)P(A) +
 b(A)Q(A) = 1$, so $\gcd(P(A), Q(A)) = 1$ in $\mathbb{Q}[t]$; similarly $\gcd(P(
B), Q(B)) = 1$.

From $P(A)\,Q(B) = P(B)\,Q(A)$:
- $P(A) \mid P(B)\,Q(A)$ and $\gcd(P(A), Q(A)) = 1$ imply $P(A) \mid P(B)$.
- $P(B) \mid P(A)\,Q(B)$ and $\gcd(P(B), Q(B)) = 1$ imply $P(B) \mid P(A)$.

Hence $P(A) = c \cdot P(B)$ for some constant $c$. If $P$ has degree $n$ with le
ading coefficient $a_n$, then $P(A) = a_n(t^2 - t)^n + \cdots$ and $P(B) = a_n(t
^2 + t)^n + \cdots$ both have leading term $a_n t^{2n}$, so $c = 1$. Thus
$$P(t^2 - t) = P(t^2 + t).$$
By the same argument, $Q(t^2 - t) = Q(t^2 + t)$.

**Step 3: Conclude $P$ (and $Q$) are constant.** Evaluate $P(t^2 - t) = P(t^2 +
t)$ at $t = n$ for each non-negative integer $n$:
$$P(n^2 - n) = P(n^2 + n).$$
But $n^2 + n = (n+1)^2 - (n+1)$, so by induction
$$P(0) = P(n^2 - n) \quad \text{for all } n \geq 0.$$
The values $\{n^2 - n : n \geq 2\} = \{2, 6, 12, 20, 30, \ldots\}$ are infinitel
y many distinct numbers. Thus the polynomial $P - P(0)$ has infinitely many root
s, so $P$ is constant. The identical argument shows $Q$ is constant.

Therefore $S$ is constant, and from $(\star)$, $R$ is constant as well. This mea
ns $f \in \mathbb{Q}$.

Since $\mathbb{Q} \subseteq \mathbb{Q}(\pi^2) \cap \mathbb{Q}(\pi^2 - \pi)$ triv
ially, we conclude
$$\boxed{\mathbb{Q}(\pi^2) \cap \mathbb{Q}(\pi^2 - \pi) = \mathbb{Q}.}$$
