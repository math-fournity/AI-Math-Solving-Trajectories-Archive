## Solution

**Setting up coordinates.** Place the circle as the unit circle. By the inscribe
d angle theorem, each 30° inscribed angle corresponds to a 60° central angle for
 the intercepted arc (the arc not containing the vertex).

Applying this to each condition:
- $\angle A_5A_2A_4 = 30°$ → minor arc $A_4A_5 = 60°$
- $\angle A_1A_3A_5 = 30°$ → arc $A_5A_1 = 60°$
- $\angle A_2A_4A_1 = 30°$ → minor arc $A_1A_2 = 60°$
- $\angle A_3A_5A_2 = 30°$ → minor arc $A_2A_3 = 60°$

The four arcs sum to $240°$, so arc $A_3A_4 = 120°$. Setting $A_1$ at angle $0°$
:
- $A_1 = (1, 0)$, $A_2 = (1/2,\, \sqrt{3}/2)$, $A_3 = (-1/2,\, \sqrt{3}/2)$, $A_
4 = (-1/2,\, -\sqrt{3}/2)$, $A_5 = (1/2,\, -\sqrt{3}/2)$

**Finding the lines.**
- $A_2A_4$: passes through $(1/2, \sqrt{3}/2)$ and $(-1/2, -\sqrt{3}/2)$ → $y =
\sqrt{3}\,x$
- $A_3A_5$: passes through $(-1/2, \sqrt{3}/2)$ and $(1/2, -\sqrt{3}/2)$ → $y =
-\sqrt{3}\,x$
- $A_5A_2$: vertical line $x = 1/2$
- $A_4A_1$: slope $1/\sqrt{3}$ → $y = (x-1)/\sqrt{3}$
- $A_1A_3$: slope $-1/\sqrt{3}$ → $y = (1-x)/\sqrt{3}$

**Computing intersections.**
- $B_1 = A_2A_4 \cap A_3A_5$: $\sqrt{3}x = -\sqrt{3}x \Rightarrow x=0, y=0$ → $B
_1 = (0, 0)$
- $B_2 = A_3A_5 \cap A_4A_1$: $-\sqrt{3}x = (x-1)/\sqrt{3} \Rightarrow -3x = x-1
 \Rightarrow x=1/4, y=-\sqrt{3}/4$ → $B_2 = (1/4,\, -\sqrt{3}/4)$
- $B_3 = A_5A_2 \cap A_4A_1$: $x=1/2, y=(1/2-1)/\sqrt{3} = -\sqrt{3}/6$ → $B_3 =
 (1/2,\, -\sqrt{3}/6)$
- $B_4 = A_5A_2 \cap A_1A_3$: $x=1/2, y=(1-1/2)/\sqrt{3} = \sqrt{3}/6$ → $B_4 =
(1/2,\, \sqrt{3}/6)$
- $B_5 = A_1A_3 \cap A_2A_4$: $\sqrt{3}x = (1-x)/\sqrt{3} \Rightarrow 3x = 1-x \
Rightarrow x=1/4, y=\sqrt{3}/4$ → $B_5 = (1/4,\, \sqrt{3}/4)$

**Area via the Shoelace formula.** The vertices in order are $B_1, B_2, B_3, B_4
, B_5$:

$$\text{Area} = \frac{1}{2}\left|\sum x_i y_{i+1} - \sum y_i x_{i+1}\right|$$

First sum: $0 + (1/4)(-\sqrt{3}/6) + (1/2)(\sqrt{3}/6) + (1/2)(\sqrt{3}/4) + 0 =
 \sqrt{3}\left(-\frac{1}{24}+\frac{1}{12}+\frac{1}{8}\right) = \sqrt{3}\cdot\fra
c{4}{24} = \frac{\sqrt{3}}{6}$

Second sum: $0 + (-\sqrt{3}/4)(1/2) + (-\sqrt{3}/6)(1/2) + (\sqrt{3}/6)(1/4) + 0
 = \sqrt{3}\left(-\frac{1}{8}-\frac{1}{12}+\frac{1}{24}\right) = \sqrt{3}\cdot\f
rac{-4}{24} = -\frac{\sqrt{3}}{6}$

$$\text{Area} = \frac{1}{2}\left|\frac{\sqrt{3}}{6} - \left(-\frac{\sqrt{3}}{6}\
right)\right| = \frac{1}{2}\cdot\frac{\sqrt{3}}{3} = \frac{\sqrt{3}}{6}$$

The area of pentagon $B_1B_2B_3B_4B_5$ is $\boxed{\dfrac{\sqrt{3}}{6}}$.
