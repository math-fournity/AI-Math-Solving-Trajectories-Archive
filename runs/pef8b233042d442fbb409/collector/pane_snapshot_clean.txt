**Step 1: Odd $k$ are not pretty.**

Since $n^2+n = n(n+1)$ is always even, $n^2+n+k$ has the same parity as $k$. If
$k$ is odd, then $n^2+n+k$ is always odd, so $v_2(n^2+n+k)=0$ for all $n$. We ca
nnot achieve $v_2 = 1$, so odd $k$ fails.

**Step 2: Even $k$ are pretty — 2-adic root analysis.**

Let $k$ be even. Consider $f(n) = n^2+n+k$ as a polynomial over $\mathbb{Z}_2$.
Its discriminant is $1-4k$. Since $k$ is even, $4k \equiv 0 \pmod{8}$, so $1-4k
\equiv 1 \pmod{8}$. A 2-adic unit is a square in $\mathbb{Z}_2$ if and only if i
t is $\equiv 1 \pmod{8}$, so $\sqrt{1-4k} \in \mathbb{Z}_2$.

The roots of $f$ in $\mathbb{Z}_2$ are:
$$\alpha = \frac{-1+\sqrt{1-4k}}{2}, \qquad \beta = \frac{-1-\sqrt{1-4k}}{2}.$$

Since $\sqrt{1-4k}$ is odd, both $-1 \pm \sqrt{1-4k}$ are even, so $\alpha, \bet
a \in \mathbb{Z}_2$. They satisfy $\alpha+\beta=-1$ (odd) and $\alpha\beta = k$
(even). Since their sum is odd, exactly one root is even and the other is odd. W
ithout loss of generality, say $v_2(\alpha) \geq 1$ (even) and $v_2(\beta)=0$ (o
dd).

**Step 3: Valuation computation.**

For $n \in \mathbb{Z}$, we factor in $\mathbb{Z}_2$:
$$v_2(f(n)) = v_2(n-\alpha) + v_2(n-\beta).$$

- **$n$ even:** $n-\alpha$ is even (even $-$ even), so $v_2(n-\alpha)\geq 1$. $n
-\beta$ is odd (even $-$ odd), so $v_2(n-\beta)=0$. Thus $v_2(f(n)) = v_2(n-\alp
ha)$.

- **$n$ odd:** $n-\alpha$ is odd (odd $-$ even), so $v_2(n-\alpha)=0$. $n-\beta$
 is even (odd $-$ odd), so $v_2(n-\beta)\geq 1$. Thus $v_2(f(n)) = v_2(n-\beta)$
.

**Step 4: All valuations $\{1,2,3,\ldots\}$ are achieved.**

Write $n=2m$ for even $n$. Then $v_2(n-\alpha) = v_2(2m - \alpha) = 1 + v_2(m -
\alpha/2)$, where $\alpha/2 \in \mathbb{Z}_2$ since $v_2(\alpha)\geq 1$.

**Claim:** For any $\gamma \in \mathbb{Z}_2$ and any $a \geq 0$, there exists $m

*Proof:* The condition $v_2(m-\gamma)=a$ means $m \equiv \gamma \pmod{2^a}$ but
$m \not\equiv \gamma \pmod{2^{a+1}}$. The residue class $\gamma \bmod 2^a$ split

 $(\gamma \bmod 2^a) + 2^a$. Choosing $m$ in the latter class gives $v_2(m-\gamm
a)=a$. $\square$

Applying this with $\gamma = \alpha/2$, as $m$ ranges over $\mathbb{Z}$, $v_2(m
- \alpha/2)$ takes all values in $\{0,1,2,\ldots\}$, so $v_2(n-\alpha)$ for even

\mathbb{Z}_2$), $v_2(n-\beta)$ for odd $n$ also takes all values in $\{1,2,3,\ld

Therefore $v_2(f(n))$ takes every value in $\{1,2,3,\ldots\}$, so every even $k$
