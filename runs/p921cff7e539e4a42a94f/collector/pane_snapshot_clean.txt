## Solution

$$x^2 - ax = \tfrac{1}{2} \qquad (1)$$
$$x^3 - ax = \tfrac{2}{3} \qquad (2)$$

**Step 1: Express $x^2$ from (1).**
$$x^2 = ax + \tfrac{1}{2} = \tfrac{5}{3}x + \tfrac{1}{2}. \qquad (\star)$$

**Step 2: Reduce $x^3$ to a linear expression in $x$ using $(\star)$ twice.**
$$x^3 = x \cdot x^2 = x\!\left(\tfrac{5}{3}x + \tfrac{1}{2}\right) = \tfrac{5}{3
}x^2 + \tfrac{1}{2}x.$$

Substitute $(\star)$ for $x^2$ again:
$$x^3 = \tfrac{5}{3}\!\left(\tfrac{5}{3}x + \tfrac{1}{2}\right) + \tfrac{1}{2}x
= \tfrac{25}{9}x + \tfrac{5}{6} + \tfrac{1}{2}x = \left(\tfrac{25}{9}+\tfrac{1}{
2}\right)x + \tfrac{5}{6}.$$

Since $\tfrac{25}{9}+\tfrac{1}{2} = \tfrac{50}{18}+\tfrac{9}{18} = \tfrac{59}{18
}$,
$$x^3 = \tfrac{59}{18}x + \tfrac{5}{6}. \qquad (\star\star)$$

**Step 3: Substitute $(\star\star)$ into (2).**
$$x^3 - ax = \tfrac{2}{3} \;\Longrightarrow\; \tfrac{59}{18}x + \tfrac{5}{6} - \
tfrac{5}{3}x = \tfrac{2}{3}.$$

Combine the $x$-terms: $\tfrac{59}{18} - \tfrac{5}{3} = \tfrac{59}{18} - \tfrac{
30}{18} = \tfrac{29}{18}$, so
$$\tfrac{29}{18}x + \tfrac{5}{6} = \tfrac{2}{3}.$$

**Step 4: Solve for $x$.**
$$\tfrac{29}{18}x = \tfrac{2}{3} - \tfrac{5}{6} = \tfrac{4}{6} - \tfrac{5}{6} =
-\tfrac{1}{6},$$
$$x = \left(-\tfrac{1}{6}\right)\!\left(\tfrac{18}{29}\right) = -\tfrac{18}{174}
