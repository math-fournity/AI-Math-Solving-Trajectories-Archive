# Problem

In a specialized logistics warehouse, cargo crates of identical size are stacked into vertical layers following a specific structural protocol:

1.  The bottom layer (Row 1) consists of a single, continuous line of crates placed side-by-side.
2.  In every layer above the first, each crate must be positioned so that it rests directly on top of exactly two crates from the layer immediately below it.
3.  The crates in every layer must always form one single, unbroken block.

Let $A(n)$ represent the total number of unique stable stacking configurations that can be built given that the bottom layer (Row 1) contains exactly $n$ crates. 

Find the smallest value of $n$ for which the number of possible configurations $A(n)$ exceeds $10,000$.
