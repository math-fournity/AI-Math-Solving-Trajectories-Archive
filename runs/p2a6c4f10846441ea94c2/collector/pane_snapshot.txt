## Solution

The left adjoint to δ: Set → Cat is the **connected components functor** π₀: Cat
 → Set.

### Definition

For a category **C**, define π₀(**C**) to be the set of *connected components* o
f **C**, where the connected components are the equivalence classes of objects u
nder the equivalence relation generated by: a ~ b if there exists a morphism a →
 b or b → a in **C**.

On functors: for a functor F: **C** → **D**, define π₀(F): π₀(**C**) → π₀(**D**)
 by sending the component of an object c to the component of F(c). This is well-
defined because F maps morphisms to morphisms, preserving the generating relatio
n.

### Proof of adjunction π₀ ⊣ δ

We must establish a natural bijection

$$\text{Hom}_{\mathbf{Set}}(\pi_0(\mathbf{C}),\, S) \;\cong\; \text{Hom}_{\mathb
f{Cat}}(\mathbf{C},\, \delta(S))$$

for every category **C** and set S.

**Direction 1 (→).** Given a function φ: π₀(**C**) → S, define a functor F_φ: **
C** → δ(S) as follows. For each object c ∈ **C**, let [c] denote its connected c
omponent and set F_φ(c) = φ([c]). For a morphism f: c → d in **C**, since c ~ d,
 we have [c] = [d], hence F_φ(c) = F_φ(d) = φ([c]). The only morphism in δ(S) fr
om an object to itself is the identity, so we set F_φ(f) = id_{φ([c])}. This is
a valid functor: identities map to identities, and composition of identities is
the identity.

**Direction 2 (←).** Given a functor G: **C** → δ(S), define ψ_G: π₀(**C**) → S
as follows. For a component [c], set ψ_G([c]) = G(c). This is well-defined: if c
 ~ d, there is a chain of morphisms connecting c and d, and G must send each mor
phism to an identity morphism in δ(S) (the only morphisms available), forcing G(
c) = G(d) along the chain. Hence the value depends only on the component.

**Inverse relationship.** The two constructions are mutually inverse: starting f
rom φ, the induced ψ_{F_φ} recovers φ since ψ_{F_φ}([c]) = F_φ(c) = φ([c]); star
ting from G, the induced F_{ψ_G} recovers G on objects (F_{ψ_G}(c) = ψ_G([c]) =
G(c)) and on morphisms (both send every morphism to the appropriate identity).

**Naturality.** The bijection is natural in both variables:
- In **C**: for a functor H: **C'** → **C**, precomposition with H corresponds u
nder the bijection to precomposition with π₀(H), which is exactly naturality in
**C**.
- In S: for a function α: S → S', postcomposition with α corresponds to postcomp
osition with δ(α): δ(S) → δ(S'), which is naturality in S.

### Conclusion

The left adjoint to δ: Set → Cat is the connected components functor

$$\pi_0: \mathbf{Cat} \to \mathbf{Set},$$

sending each category to the set of its connected components (equivalence classe
s of objects under the relation generated by the existence of a morphism in eith
er direction), and the adjunction π₀ ⊣ δ is witnessed by the natural bijection

$$\text{Hom}_{\mathbf{Set}}(\pi_0(\mathbf{C}),\, S) \cong \text{Hom}_{\mathbf{Ca
t}}(\mathbf{C},\, \delta(S)).$$
