## Proof

**Reformulation.** For positive reals, $x^2y^2 = z^2 \iff xy = z$. The set $\{1^
2, 2^2, \ldots, m^2\} = \{1, 4, 9, \ldots, m^2\}$ consists of perfect squares. W
riting $x = a^2,\, y = b^2,\, z = c^2$ with $1 \le a,b,c \le m$, the equation $x
y = z$ becomes $a^2b^2 = c^2$, i.e., $ab = c$.

A $k$-coloring of $\{1, 4, 9, \ldots, m^2\}$ induces a $k$-coloring $\chi:\{1,\l
dots,m\}\to[k]$ via $\chi(a) = \text{color}(a^2)$. The problem reduces to:

> For every $k$, does there exist $m$ such that every $k$-coloring of $\{1,\ldot
s,m\}$ yields $a,b,c \in \{1,\ldots,m\}$ with $ab = c$, $\chi(a)=\chi(b)=\chi(c)
$, and not all equal?

(The trivial solution $a=b=c=1$ is excluded as non-informative; we seek a non-tr
ivial monochromatic solution.)

**Key tool — Schur's Theorem.** For every $k \ge 1$, there exists a positive int
eger $S(k)$ such that any $k$-coloring of $\{1, 2, \ldots, S(k)\}$ contains $a,
b, c \in \{1, \ldots, S(k)\}$ with $a + b = c$, all of the same color. Moreover,
 since $a, b \ge 1$, we have $c = a+b \ge 2 > a$ and $c > b$, so $c$ is distinct
 from both $a$ and $b$ — the solution is automatically non-trivial.

**Construction.** Set $m(k) = 2^{S(k)}$. Consider any $k$-coloring of $\{1, 4, 9
, \ldots, m^2\}$, inducing $\chi:\{1,\ldots,m\}\to[k]$.

Define a $k$-coloring $\chi':\{1,\ldots,S(k)\}\to[k]$ by $\chi'(j) = \chi(2^j)$.
 This is valid since $2^j \le 2^{S(k)} = m$ for $j \le S(k)$.

By Schur's theorem, there exist $a, b, c \in \{1, \ldots, S(k)\}$ with $a + b =
c$ and $\chi'(a) = \chi'(b) = \chi'(c)$.

**Verification.** Set $A = 2^a,\; B = 2^b,\; C = 2^c$. Then:

1. **Membership:** $A, B, C \le 2^{S(k)} = m$, so $A, B, C \in \{1, \ldots, m\}$
, hence $A^2, B^2, C^2 \in \{1, 4, 9, \ldots, m^2\}$.

2. **Monochromaticity:** $\chi(A) = \chi'(a) = \chi'(b) = \chi(B) = \chi'(c) = \
chi(C)$. Therefore $A^2, B^2, C^2$ all receive the same color in the original co
loring.

3. **Equation satisfied:** $A \cdot B = 2^a \cdot 2^b = 2^{a+b} = 2^c = C$, so $
A^2 \cdot B^2 = (AB)^2 = C^2$, i.e., $x^2 y^2 = z^2$ holds with $x = A^2,\, y =
B^2,\, z = C^2$.

4. **Non-triviality:** Since $c = a + b > a$ and $c > b$ (as $a, b \ge 1$), we h
ave $C = 2^c > 2^a = A$ and $C > B$, so $x, y, z$ are not all equal.

**Conclusion.** For every positive integer $k$, taking $m(k) = 2^{S(k)}$ (where
$S(k)$ is the $k$-color Schur number) guarantees that any $k$-coloring of $\{1^2
, 2^2, \ldots, m^2\}$ contains a non-trivial monochromatic solution to $x^2 y^2
= z^2$. $\blacksquare$
