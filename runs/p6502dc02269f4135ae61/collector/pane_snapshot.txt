## Proof

**Claim:** Yes, $M$ must be closed.

**Key observation.** For any $x \in X$,
$$\|x+M\| = \inf\{\|x+y\| : y \in M\} = \inf\{\|x - y\| : y \in M\} = \operatorn
ame{dist}(x, M),$$
where the second equality uses that $M$ is a subspace (so $-y \in M$ whenever $y
 \in M$), and the last expression is the distance from $x$ to $M$.

**Lemma.** $\operatorname{dist}(x, M) = 0 \iff x \in \overline{M}$.

*Proof of Lemma.* Since $X$ is a normed space, it is metrizable, so the closure
$\overline{M}$ equals the sequential closure.

$(\Leftarrow)$: If $x \in \overline{M}$, there exists a sequence $(y_n) \subset
M$ with $y_n \to x$. Then $\|x - y_n\| \to 0$, so $\operatorname{dist}(x,M) \le
\inf_n \|x-y_n\| = 0$, giving $\operatorname{dist}(x,M)=0$.

$(\Rightarrow)$: If $\operatorname{dist}(x,M)=0$, then for each $n$ there exists
 $y_n \in M$ with $\|x - y_n\| < 1/n$ (by definition of infimum). Thus $y_n \to
x$, so $x \in \overline{M}$. $\square$

**Main argument.** The hypothesis is that the seminorm is a norm:
$$\|x+M\| = 0 \implies x + M = 0 + M, \quad\text{i.e., } x \in M.$$

By the observation and the lemma,
$$\|x+M\| = 0 \iff x \in \overline{M}.$$

Therefore the hypothesis becomes
$$x \in \overline{M} \implies x \in M,$$
i.e., $\overline{M} \subseteq M$. Since $M \subseteq \overline{M}$ always holds,
 we conclude $M = \overline{M}$, so $M$ is closed.

**Remark (converse).** Conversely, if $M$ is closed, then $\overline{M}=M$, so $
\|x+M\|=0 \iff x \in M$, and the seminorm is a norm. Thus the seminorm on $X/M$
is a norm **if and only if** $M$ is closed.
