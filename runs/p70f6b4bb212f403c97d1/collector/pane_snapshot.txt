## Proof

**Notation and setup.** Let $(X, \mu)$ be a measure space. For $f \in L^\infty(X
,\mu)$, define $T_f: L^2(X,\mu) \to L^2(X,\mu)$ by $T_f(g) = fg$. This is well-d
efined and bounded since $\|fg\|_2 \leq \|f\|_\infty \|g\|_2$. An **atom** is a
measurable set $A$ with $\mu(A)>0$ such that every measurable $B\subseteq A$ sat
isfies $\mu(B)=0$ or $\mu(B)=\mu(A)$. An **infinite atom** is an atom with $\mu(
A)=\infty$.

**Key Claim.** *If $(X,\mu)$ has no infinite atoms and $E$ is measurable with $\
mu(E)>0$, then there exists $F\subseteq E$ with $0<\mu(F)<\infty$.*

*Proof of Claim.* If $\mu(E)<\infty$, take $F=E$. If $\mu(E)=\infty$, suppose fo
r contradiction that every measurable $F\subseteq E$ has $\mu(F)=0$ or $\mu(F)=\
infty$. Then $E$ is an atom: $\mu(E)=\infty>0$, and every subset $B\subseteq E$
has $\mu(B)=0$ or $\mu(B)=\infty=\mu(E)$. This is an infinite atom, contradictin
g the hypothesis. $\square$

### Part (a): $\|T_f\|=\|f\|_\infty$ for all $f\in L^\infty$ iff $X$ has no infi
nite atoms.

**The upper bound (always holds).** For any $g\in L^2$:
$$\|T_f g\|_2^2 = \int |f|^2|g|^2\,d\mu \leq \|f\|_\infty^2 \int|g|^2\,d\mu = \|
f\|_\infty^2\|g\|_2^2.$$
Hence $\|T_f\|\leq\|f\|_\infty$.

**($\Leftarrow$) No infinite atoms $\Rightarrow$ $\|T_f\|=\|f\|_\infty$ for all
$f$.**

Let $M=\|f\|_\infty$. If $M=0$ this is trivial. Fix $\varepsilon>0$ with $\varep
silon<M$. By definition of essential supremum, the set $E_\varepsilon=\{x:|f(x)|
\geq M-\varepsilon\}$ has $\mu(E_\varepsilon)>0$. By the Key Claim, there exists
 $F\subseteq E_\varepsilon$ with $0<\mu(F)<\infty$. Set $g = \mathbf{1}_F/\sqrt{
\mu(F)}$. Then $\|g\|_2=1$ and
$$\|T_f g\|_2^2 = \frac{1}{\mu(F)}\int_F |f|^2\,d\mu \geq \frac{(M-\varepsilon)^
2\,\mu(F)}{\mu(F)} = (M-\varepsilon)^2.$$
So $\|T_f\|\geq M-\varepsilon$ for every $\varepsilon>0$, giving $\|T_f\|\geq M=
\|f\|_\infty$. Combined with the upper bound, $\|T_f\|=\|f\|_\infty$.

**($\Rightarrow$) $\|T_f\|=\|f\|_\infty$ for all $f$ $\Rightarrow$ no infinite a
toms.**

We prove the contrapositive. Suppose $A$ is an infinite atom ($\mu(A)=\infty$).
Set $f=\mathbf{1}_A$, so $\|f\|_\infty=1$. We claim $T_f=0$, i.e., $fg=0$ a.e. f
or every $g\in L^2$.

Since $A$ is an atom, any measurable function is a.e. constant on $A$: for any $
g$, the sets $\{x\in A: |g(x)|>1/n\}$ are measurable subsets of $A$, hence have
measure $0$ or $\infty$. If $\mu(\{x\in A:|g(x)|>1/n\})=\infty$ for some $n$, th
en $\int_A|g|^2\,d\mu\geq \frac{1}{n^2}\cdot\infty=\infty$, contradicting $g\in
L^2$. So $\mu(\{x\in A:|g(x)|>1/n\})=0$ for all $n$, meaning $g=0$ a.e. on $A$.

Therefore $fg = g\cdot\mathbf{1}_A = 0$ a.e. on $A$, and $fg=0$ on $X\setminus A
$ (where $f=0$). So $T_f g=0$ for all $g\in L^2$, giving $\|T_f\|=0<1=\|f\|_\inf
ty$. The equality fails, completing the contrapositive. $\square$

### Part (b): No infinite atoms and $\|k\|_\infty=\infty$ $\Rightarrow$ $k\cdot
L^2(X,\mu)\not\subseteq L^2(X,\mu)$.

Here $k$ is measurable with $\|k\|_\infty=\infty$ (so $k\notin L^\infty$). We mu
st find $g\in L^2$ with $kg\notin L^2$.

Since $\|k\|_\infty=\infty$, for every $n\in\mathbb{N}$ the set $A_n=\{x:|k(x)|\
geq n\}$ has $\mu(A_n)>0$.

**Case 1: $\mu(\{|k|=\infty\})>0$.** By the Key Claim, there exists $F\subseteq\
{|k|=\infty\}$ with $0<\mu(F)<\infty$. Set $g=\mathbf{1}_F/\sqrt{\mu(F)}\in L^2$
. Then $|kg|=\infty$ on $F$, so $\|kg\|_2^2\geq\int_F\infty\,d\mu=\infty$. Hence
 $kg\notin L^2$.

**Case 2: $\mu(\{|k|=\infty\})=0$.** Define $D_j=\{x: j\leq |k(x)|<j+1\}$ for $j
\in\mathbb{N}$. These are pairwise disjoint and $A_n = \bigcup_{j\geq n} D_j$ (a
.e., since $\{|k|=\infty\}$ is null).

We claim infinitely many $D_j$ have positive measure. If only finitely many did,
 with largest index $N$, then for $n>N$: $\mu(A_n)=\mu\!\left(\bigcup_{j\geq n}D
_j\right)=0$, contradicting $\mu(A_n)>0$.

Let $j_1<j_2<j_3<\cdots$ enumerate those $j$ with $\mu(D_j)>0$. Since the $j_m$
are distinct positive integers in increasing order, $j_m\geq m$. By the Key Clai
m, for each $m$ there exists $F_m\subseteq D_{j_m}$ with $0<\mu(F_m)<\infty$. Th
e $F_m$ are disjoint (since the $D_j$ are), and on $F_m$ we have $|k|\geq j_m$.

Define:
$$g = \sum_{m=1}^{\infty} \frac{1}{m\sqrt{\mu(F_m)}}\,\mathbf{1}_{F_m}.$$

Then:
$$\|g\|_2^2 = \sum_{m=1}^{\infty}\frac{1}{m^2\,\mu(F_m)}\cdot\mu(F_m) = \sum_{m=
1}^{\infty}\frac{1}{m^2}<\infty,$$
so $g\in L^2$. On the other hand:
$$\|kg\|_2^2 = \int|k|^2|g|^2\,d\mu \geq \sum_{m=1}^{\infty}\int_{F_m}|k|^2|g|^2
\,d\mu \geq \sum_{m=1}^{\infty} j_m^2\cdot\frac{1}{m^2\,\mu(F_m)}\cdot\mu(F_m) =
 \sum_{m=1}^{\infty}\frac{j_m^2}{m^2}\geq\sum_{m=1}^{\infty}1=\infty.$$

Hence $kg\notin L^2$, so $k\cdot L^2(X,\mu)\not\subseteq L^2(X,\mu)$. $\square$
