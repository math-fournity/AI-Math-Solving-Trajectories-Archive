converges, where $a_n$ is the smallest $k$ with $n \mid k!$.

## Proof

**Key function.** For a prime power $q^e$, let $\mu(q^e) = \min\{k : q^e \mid k!
\}$. Since $n \mid k!$ iff $q^{v_q(n)} \mid k!$ for every prime $q \mid n$, we h
ave
$$a_n = \max_{q \mid n} \mu\!\big(q^{v_q(n)}\big).$$

**Basic bound.** For any prime $q$ and $e \geq 1$: $v_q((eq)!) = \sum_{i\geq 1}\
lfloor eq/q^i\rfloor \geq e$, so
$$\mu(q^e) \leq eq. \tag{$\star$}$$

We split the composites into two classes.

---

### Class A: $n$ has at least two distinct prime factors

Let $p$ be the **largest** prime factor of $n$, with $v = v_p(n) \geq 1$, and wr
ite $n = p^v \cdot m$ where $m \geq 2$ and $p \nmid m$. Since $n$ has two distin
ct primes, $p \geq 3$.

**Claim.** $a_n \leq n/2$.

Using $(\star)$: $a_n = \max\big(\mu(p^v),\; \max_{q \mid m} \mu(q^{v_q(m)})\big
) \leq \max\big(vp,\; \max_{q\mid m} v_q(m)\,q\big)$.

We show every term in the max is $\leq n/2 = p^v m/2$.

**Term $\mu(p^v) \leq vp$:** Need $vp \leq p^v m/2$, i.e. $2v \leq p^{v-1}m$. Si
nce $m\geq 2$: $p^{v-1}m \geq 2p^{v-1} \geq 2\cdot 2^{v-1} \geq 2v$ (using $2^{v
-1}\geq v$ for $v\geq 1$). ✓

**Term $v_q(m)\,q$ for $q \mid m$:** Since $q^{v_q(m)} \mid m$, we have $m \geq
q^{v_q(m)}$, so $p^v m/2 \geq p^v q^{v_q(m)}/2$. Need $v_q(m)\,q \leq p^v q^{v_q
(m)}/2$, i.e. $2v_q(m) \leq p^v\, q^{v_q(m)-1}$.

- If $v_q(m) = 1$: need $2 \leq p^v$. Since $p\geq 3, v\geq 1$: $p^v \geq 3$. ✓
- If $v_q(m) \geq 2$: $q^{v_q(m)-1} \geq 2^{v_q(m)-1} \geq v_q(m)$, so $p^v q^{v
_q(m)-1} \geq 3\cdot v_q(m) \geq 2v_q(m)$. ✓

Therefore $a_n \leq n/2$ for every composite $n$ with $\geq 2$ distinct prime fa
ctors, giving
$$\sum_{\substack{n \in C \\ \geq 2\text{ distinct primes}}} \left(\frac{a_n}{n}
\right)^n \leq \sum_{n=6}^{\infty}\left(\frac12\right)^n = \frac{(1/2)^6}{1-1/2}
 = \frac{1}{32} < \infty. \tag{A}$$

---

### Class B: $n = p^k$ is a prime power, $k \geq 2$

By $(\star)$: $a_n = \mu(p^k) \leq kp$, so $\dfrac{a_n}{n} \leq \dfrac{k}{p^{k-1
}}$, hence
$$\left(\frac{a_n}{n}\right)^n \leq \left(\frac{k}{p^{k-1}}\right)^{p^k}.$$

**Subcase $k=2$:** $\sum_{p\text{ prime}} (2/p)^{p^2}$. The terms are $1$ (at $p
=2$), $(2/3)^9 \approx 0.026$, $(2/5)^{25}, (2/7)^{49}, \ldots$ which decay supe
r-exponentially. For $p \geq 5$, $(2/p)^{p^2} \leq (2/5)^{p^2} \leq (2/5)^{5p}$
(since $p^2 \geq 5p$ for $p\geq 5$), and $\sum_{p\geq 5}(2/5)^{5p} \leq \sum_{n\
geq 5}(2/5)^{5n}<\infty$. ✓

**Subcase $k \geq 3$:** Here $k/p^{k-1} \leq k/2^{k-1}$. For $k=3$: $3/4$, givin
g $(3/4)^{p^3}$; sum over $p$ dominated by $\sum_{n\geq 2}(3/4)^{n^3}<\infty$. F
or $k=4$: $4/8=1/2$, giving $(1/2)^{p^4}$, convergent. For $k\geq 5$: $k/2^{k-1}
 \leq 5/16 < 1$, and $(k/2^{k-1})^{2^k} \leq (5/16)^{2^k}$, super-exponentially
small; the double sum $\sum_{k\geq 5}\sum_p (k/p^{k-1})^{p^k}$ converges. ✓

Therefore
$$\sum_{\substack{n=p^k\in C\\k\geq 2}} \left(\frac{a_n}{n}\right)^n < \infty. \
tag{B}$$

---

### Conclusion

Every composite number belongs to exactly one of Class A or Class B. By (A) and
(B), both partial sums converge, so

$$\boxed{\sum_{n \in C}\left(\frac{a_n}{n}\right)^n \text{ converges.}}$$
