# Problem

A specialized logistics company manages a high-security warehouse containing several individual storage vaults, each identified by a unique positive integer ID ranging from $1$ to $n$. An auditor arrives to select exactly 9 distinct vaults from this set to form a 3x3 grid of secure data nodes.

For the system to achieve "Perfect Sync," the auditor must arrange these 9 unique vault IDs in the grid such that the product of the IDs in every row is identical, the product of the IDs in every column is identical, and the product of the IDs along both main diagonals is also identical to that same constant value.

What is the minimum possible value of $n$ (the highest vault ID in the available set) that allows the auditor to select 9 such distinct IDs and successfully configure the grid?
