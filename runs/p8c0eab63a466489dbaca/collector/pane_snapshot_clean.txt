## Solution

**Yes, $P$ is necessarily a probability measure.**

**Proof.**

We are given that each $P_n$ is a probability measure on the $\sigma$-field $F$
and that $P_n(A) \to P(A)$ for every $A \in F$. We verify the three defining pro
perties of a probability measure.

**Nonnegativity.** For every $A \in F$ and every $n$, $P_n(A) \geq 0$. Hence
$$P(A) = \lim_{n\to\infty} P_n(A) \geq 0.$$

**Total mass.** Since each $P_n$ is a probability measure, $P_n(\Omega) = 1$ for
 all $n$, so
$$P(\Omega) = \lim_{n\to\infty} P_n(\Omega) = 1.$$

**Countable additivity.** This is the nontrivial part. We use the **Vitali–Hahn–
Saks theorem**:

> *Let $\lambda$ be a finite measure on a $\sigma$-field $F$. If $\{\mu_n\}$ is
a sequence of signed measures on $F$, each absolutely continuous with respect to
 $\lambda$, and $\mu(A) = \lim_n \mu_n(A)$ exists for every $A \in F$, then $\mu
$ is countably additive (and $\mu \ll \lambda$).*

To apply this, we construct a common dominating measure. Define
$$\lambda = \sum_{n=1}^{\infty} 2^{-n}\, P_n.$$
This is a finite measure on $F$ with $\lambda(\Omega) = \sum_n 2^{-n} = 1$. More
over, each $P_n$ is absolutely continuous with respect to $\lambda$: if $\lambda
(A) = 0$, then $2^{-n}P_n(A) \leq \lambda(A) = 0$, so $P_n(A) = 0$.

Since each $P_n \ll \lambda$ and $P(A) = \lim_n P_n(A)$ exists for every $A \in
F$, the Vitali–Hahn–Saks theorem applies, giving that $P$ is countably additive
on $F$.

**Conclusion.** $P$ is a nonnegative, countably additive set function on $F$ wit
h $P(\Omega) = 1$. Therefore $P$ is a probability measure. $\blacksquare$

**Remark.** The countable additivity is the subtle point: one cannot simply inte
rchange $\lim_n$ and $\sum_k$ in $P_n\!\left(\bigcup_k A_k\right) = \sum_k P_n(A
_k)$ without justification. The Vitali–Hahn–Saks theorem (equivalently, the Broo
ks–Jewett theorem, which does not even require constructing a dominating measure
) is precisely the deep result that guarantees this interchange is valid under t
he given hypotheses.
