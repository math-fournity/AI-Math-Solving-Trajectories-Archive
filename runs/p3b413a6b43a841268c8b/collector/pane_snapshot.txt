## Solution

**Setting.** Let $\Omega = [0,1)$ and suppose, for contradiction, that there exi
sts a probability measure $\mu : 2^{\Omega} \to [0,1]$ satisfying:

1. **(Normalization)** $\mu(\Omega) = 1$,
2. **(Countable additivity)** for every pairwise-disjoint sequence $(A_n)_{n\ge
1}$ in $2^{\Omega}$, $\mu\!\left(\bigcup_n A_n\right) = \sum_n \mu(A_n)$,
3. **(Translation invariance mod 1)** for every $A\subseteq\Omega$ and every $t\
in[0,1)$, $\mu(A) = \mu\big((A+t)\!\!\pmod 1\big)$.

We show these three requirements are mutually inconsistent, so no such measure o
n the full power set $2^{\Omega}$ can exist.

**Construction of the Vitali set.** Define an equivalence relation on $\Omega$ b
y
$$x \sim y \iff x - y \in \mathbb{Q}.$$
This partitions $\Omega$ into equivalence classes, each of the form $x + \mathbb
{Q} \pmod 1$. By the Axiom of Choice, select exactly one representative from eac
h equivalence class; call the resulting set $V \subseteq \Omega$ (the *Vitali se
t*). Note $V \in 2^{\Omega}$, so by hypothesis $\mu(V)$ is defined.

**Countable disjoint translates cover $\Omega$.** Let $Q = \mathbb{Q} \cap [0,1)
$, which is countable. Enumerate it as $Q = \{q_1, q_2, \dots\}$. For each $n$,
define
$$V_n := (V + q_n) \pmod 1 = \{\, (v + q_n) \!\!\pmod 1 : v \in V \,\}.$$

*Disjointness.* If $V_m \cap V_n \neq \varnothing$ for $m \ne n$, pick $v, v' \i
n V$ with $(v + q_m) \equiv (v' + q_n) \pmod 1$. Then $v - v' \equiv q_n - q_m \
pmod 1$, so $v - v' \in \mathbb{Q}$, meaning $v \sim v'$. But $V$ contains exact
ly one representative per class, so $v = v'$, giving $q_m \equiv q_n \pmod 1$, i
.e. $q_m = q_n$ since both lie in $[0,1)$. Contradiction. Hence the $V_n$ are pa
irwise disjoint.

*Covering.* For any $x \in \Omega$, its equivalence class $[x]$ has a unique rep
resentative $v \in V$, so $x - v \in \mathbb{Q}$, i.e. $x = (v + q) \pmod 1$ for
 some $q \in Q$. Thus $x \in V_n$ for the corresponding $n$. Therefore
$$\Omega = \bigsqcup_{n=1}^{\infty} V_n.$$

**Deriving the contradiction.** By translation invariance, $\mu(V_n) = \mu(V)$ f
or every $n$. By countable additivity and normalization,
$$1 = \mu(\Omega) = \mu\!\left(\bigsqcup_n V_n\right) = \sum_{n=1}^{\infty} \mu(
V_n) = \sum_{n=1}^{\infty} \mu(V).$$

Now there are only two cases for the value $a := \mu(V) \in [0,1]$:

- If $a = 0$, then $\sum_n a = 0 \ne 1$ — contradicts normalization.
- If $a > 0$, then $\sum_n a = +\infty \ne 1$ — contradicts normalization.

Both cases are impossible. Hence no probability measure on $2^{\Omega}$ can be s
imultaneously countably additive, translation-invariant, and normalized.

**The paradox/contradiction.** This is the **Vitali paradox**: a translation-inv
ariant "uniform" probability measure on $[0,1)$ — the natural model for "pick a
real number uniformly at random" — cannot be defined on the entire power set $2^
{[0,1)}$. The sets $V_n$ are individually well-defined subsets of $\Omega$, yet
assigning any value to $\mu(V)$ leads to $1 = 0$ or $1 = \infty$. The only escap
e is to *exclude* such pathological sets from the domain of $\mu$, which is exac
tly why measure theory restricts attention to a $\sigma$-algebra (e.g. the Lebes
gue $\sigma$-algebra) strictly smaller than $2^{\Omega}$.

**The property $X$.** The property that measures typically possess — and that ca
nnot be simultaneously satisfied here together with translation invariance and n
ormalization on the full power set — is **countable additivity** (a.k.a. $\sigma
$-additivity):

$$\mu\!\left(\bigsqcup_{n=1}^{\infty} A_n\right) = \sum_{n=1}^{\infty} \mu(A_n).
$$

It is countable additivity that forces $\sum_n \mu(V)$ to equal $\mu(\Omega)=1$,
 and since every translate has the same measure, the series is either $0$ or $+\
infty$, never $1$. Dropping to *finite* additivity alone would not produce the c
ontradiction (one can have finitely-additive translation-invariant probability m
easures on $2^{\Omega}$ via Banach limits / the Hahn–Banach theorem, in dimensio
n 1), but the standard, countably-additive notion of measure — the one used thro
ughout probability theory — is incompatible with being defined on all of $2^{\Om
ega}$ for an uncountable $\Omega$.

**Summary.** The Vitali construction exhibits the contradiction: assuming a coun
tably additive, translation-invariant, normalized measure on $2^{[0,1)}$ yields
$1 \in \{0, +\infty\}$. The property $X$ is **countable additivity**, and the re
solution is to define the measure only on a proper $\sigma$-subalgebra of $2^{\O
mega}$ (the Lebesgue-measurable sets), leaving the Vitali set non-measurable.
