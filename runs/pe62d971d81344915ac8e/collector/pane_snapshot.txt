### Setup

The deck has 32 cards:
- For each $k = 1, 2, \ldots, 10$: three cards (red/yellow/blue), each worth $2^
k$ points.
- Two jokers (big and small), each numbered $0$, worth $2^0 = 1$ point.

A "good card group" is a subset of the 32 cards whose total score equals $2004$.
 Cards of the same number but different colors are distinguishable, so we count
subsets.

Let $n_k$ = number of cards chosen with number $k$:
- $n_0 \in \{0,1,2\}$ (two jokers), contributing $\binom{2}{n_0}$ color-choices,
- $n_k \in \{0,1,2,3\}$ for $k=1,\ldots,10$, contributing $\binom{3}{n_k}$ color
-choices.

We need $\sum_{k=0}^{10} n_k \cdot 2^k = 2004$.

### Binary expansion of 2004

$$2004 = 2^{10}+2^9+2^8+2^7+2^6+2^4+2^2,$$

so the bits are $b_0{=}0, b_1{=}0, b_2{=}1, b_3{=}0, b_4{=}1, b_5{=}0, b_6{=}1,
b_7{=}1, b_8{=}1, b_9{=}1, b_{10}{=}1$.

### Carry DP

Process positions $k = 0, 1, \ldots, 10$ with carry $c_k$ into position $k$ ($c_
0 = 0$). At position $k$:
$$n_k + c_k = b_k + 2\,c_{k+1}.$$
We require $c_{11} = 0$ (no carry beyond the top, since $2004 < 2^{11}$ and ther
e are no cards numbered $\geq 11$).

Let $f_k(c)$ = total weighted count (product of binomial coefficients) after pro
cessing positions $0,\ldots,k{-}1$, with carry $c$ into position $k$.

**Position 0** ($b_0=0$, $n_0\in\{0,1,2\}$, weights $\binom{2}{n_0}=1,2,1$): nee
d $n_0 = 2c_1$, so $n_0\in\{0,2\}$:
$$f_1(0)=1,\quad f_1(1)=1.$$

**Position 1** ($b_1=0$): $n_1+c_1 = 2c_2$ (even).
$$f_2(0)=1,\quad f_2(1)=6,\quad f_2(2)=1.$$

**Position 2** ($b_2=1$): $n_2+c_2 = 1+2c_3$.
$$f_3(0)=9,\quad f_3(1)=22,\quad f_3(2)=1.$$

**Position 3** ($b_3=0$): $n_3+c_3 = 2c_4$.
$$f_4(0)=9,\quad f_4(1)=94,\quad f_4(2)=25.$$

**Position 4** ($b_4=1$): $n_4+c_4 = 1+2c_5$.
$$f_5(0)=121,\quad f_5(1)=366,\quad f_5(2)=25.$$

**Position 5** ($b_5=0$): $n_5+c_5 = 2c_6$.
$$f_6(0)=121,\quad f_6(1)=1486,\quad f_6(2)=441.$$

**Position 6** ($b_6=1$): $n_6+c_6 = 1+2c_7$.
$$f_7(0)=1849,\quad f_7(1)=5902,\quad f_7(2)=441.$$

**Position 7** ($b_7=1$): $n_7+c_7 = 1+2c_8$.
$$f_8(0)=11449,\quad f_8(1)=20878,\quad f_8(2)=441.$$

**Position 8** ($b_8=1$): $n_8+c_8 = 1+2c_9$.
$$f_9(0)=55225,\quad f_9(1)=75406,\quad f_9(2)=441.$$

**Position 9** ($b_9=1$): $n_9+c_9 = 1+2c_{10}$.
$$f_{10}(0)=241081,\quad f_{10}(1)=282766,\quad f_{10}(2)=441.$$

**Position 10** ($b_{10}=1$, require $c_{11}=0$): $n_{10}+c_{10} = 1$.
- $c_{10}=0$: $n_{10}=1$, weight $\binom{3}{1}=3$ → contributes $241081 \times 3
 = 723243$.
- $c_{10}=1$: $n_{10}=0$, weight $\binom{3}{0}=1$ → contributes $282766 \times 1
 = 282766$.
- $c_{10}=2$: would need $n_{10}=-1$, impossible.

### Final count

$$723243 + 282766 = \boxed{1006009}.$$

The number of good card groups is **1006009**.
