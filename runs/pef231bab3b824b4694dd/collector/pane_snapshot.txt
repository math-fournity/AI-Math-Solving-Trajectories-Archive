Looking at the problem, I need to prove: for real numbers $x_1, \ldots, x_n$,
$$\sum_{i,j} \sqrt{|x_i - x_j|} \le \sum_{i,j} \sqrt{|x_i + x_j|}.$$

**Proof.**

We use the integral representation: for $a \ge 0$,
$$\sqrt{a} = \frac{1}{2\sqrt{\pi}} \int_0^\infty \frac{1 - e^{-as}}{s^{3/2}}\, d
s. \tag{1}$$

*Verification of (1):* Substituting $u = as$ gives $\sqrt{a} = \frac{\sqrt{a}}{2
\sqrt{\pi}} \int_0^\infty \frac{1-e^{-u}}{u^{3/2}}\,du$. Using $1 - e^{-u} = u\i
nt_0^1 e^{-ut}\,dt$ and Fubini,
$$\int_0^\infty \frac{1-e^{-u}}{u^{3/2}}\,du = \int_0^1 \int_0^\infty u^{-1/2}e^
{-ut}\,du\,dt = \int_0^1 \frac{\sqrt{\pi}}{\sqrt{t}}\,dt = 2\sqrt{\pi},$$
confirming (1).

Applying (1) with $a = |x_i - x_j|$ and summing over all $i,j$:
$$\sum_{i,j} \sqrt{|x_i - x_j|} = \frac{1}{2\sqrt{\pi}} \int_0^\infty \frac{n^2
- \sum_{i,j} e^{-s|x_i - x_j|}}{s^{3/2}}\, ds, \tag{2}$$
and similarly
$$\sum_{i,j} \sqrt{|x_i + x_j|} = \frac{1}{2\sqrt{\pi}} \int_0^\infty \frac{n^2
- \sum_{i,j} e^{-s|x_i + x_j|}}{s^{3/2}}\, ds. \tag{3}$$

Both integrals converge: near $s = 0$, the numerator is $O(s)$ (since $e^{-|t|s}
 = 1 - |t|s + O(s^2)$), giving an $O(s^{-1/2})$ integrand; near $s = \infty$, th
e numerator is bounded, giving an $O(s^{-3/2})$ integrand.

It suffices to show that for every $s > 0$:
$$\sum_{i,j} e^{-s|x_i - x_j|} \ge \sum_{i,j} e^{-s|x_i + x_j|}. \tag{4}$$

**Positive definiteness.** Fix $s > 0$ and set $f(t) = e^{-s|t|}$. We claim $f$
is positive definite. The Fourier inversion formula gives
$$e^{-s|t|} = \int_{-\infty}^{\infty} e^{i\omega t} \frac{s}{\pi(s^2 + \omega^2)
}\, d\omega,$$
so for any real $c_1, \ldots, c_m$ and $t_1, \ldots, t_m$:
$$\sum_{a,b=1}^m c_a c_b\, f(t_a - t_b) = \int_{-\infty}^{\infty} \frac{s}{\pi(s
^2+\omega^2)} \left|\sum_{a=1}^m c_a\, e^{i\omega t_a}\right|^2 d\omega \ge 0. \
tag{5}$$

**Applying the quadratic form.** Apply (5) with $m = 2n$, using the $2n$ points
$$t_1 = x_1,\ \ldots,\ t_n = x_n,\quad t_{n+1} = -x_1,\ \ldots,\ t_{2n} = -x_n,$
$
and coefficients $c_1 = \cdots = c_n = 1$, $c_{n+1} = \cdots = c_{2n} = -1$.

Since $f$ is even ($f(-t) = f(t)$), the four blocks of the double sum evaluate a
s:

- **Block $(a,b) \in [1,n]\times[1,n]$:** $c_a c_b = 1$, $t_a - t_b = x_a - x_b$
. Contributes $\sum_{i,j} f(x_i - x_j)$.
- **Block $(a,b) \in [1,n]\times[n{+}1,2n]$:** $c_a c_b = -1$, $t_a - t_b = x_a
+ x_{b-n}$. Contributes $-\sum_{i,j} f(x_i + x_j)$.
- **Block $(a,b) \in [n{+}1,2n]\times[1,n]$:** $c_a c_b = -1$, $t_a - t_b = -(x_
{a-n}+x_b)$, and $f$ is even. Contributes $-\sum_{i,j} f(x_i + x_j)$.
- **Block $(a,b) \in [n{+}1,2n]\times[n{+}1,2n]$:** $c_a c_b = 1$, $t_a - t_b =
x_{b-n} - x_{a-n}$. Contributes $\sum_{i,j} f(x_j - x_i) = \sum_{i,j} f(x_i - x_
j)$.

Summing all four blocks, positive definiteness (5) yields:
$$0 \le 2\sum_{i,j} f(x_i - x_j) - 2\sum_{i,j} f(x_i + x_j),$$
which is exactly (4).

atisfy
$$n^2 - \sum_{i,j} e^{-s|x_i - x_j|} \le n^2 - \sum_{i,j} e^{-s|x_i + x_j|} \qua
d \text{for all } s > 0.$$
Integrating over $s \in (0, \infty)$ against the positive weight $s^{-3/2}$ give
s
$$\sum_{i,j} \sqrt{|x_i - x_j|} \le \sum_{i,j} \sqrt{|x_i + x_j|}. \qquad \black
square$$
