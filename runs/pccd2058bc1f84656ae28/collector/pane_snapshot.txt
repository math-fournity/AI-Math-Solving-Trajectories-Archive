## Solution

**Problem:** Find the 100th derivative of \(y = \ln(2x - x^2)\) evaluated at \(x
 = 1\).

### Step 1: Decompose the logarithm

Factor the argument:
$$2x - x^2 = x(2 - x).$$

For \(x \in (0,2)\) both factors are positive, so
$$y = \ln x + \ln(2 - x).$$

### Step 2: Compute the general \(n\)-th derivative (\(n \ge 1\))

For \(g(x) = \ln x\), the standard formula gives
$$g^{(n)}(x) = \frac{(-1)^{n-1}(n-1)!}{x^n}.$$

For \(f(x) = \ln(2-x)\), compute the first few derivatives:
- \(f'(x) = -\dfrac{1}{2-x} = (x-2)^{-1}\)
- \(f''(x) = -(x-2)^{-2} = \dfrac{-1}{(x-2)^2}$
- $f'''(x) = 2(x-2)^{-3} = \dfrac{2}{(x-2)^3}$

The pattern is
$$f^{(n)}(x) = \frac{(-1)^{n-1}(n-1)!}{(x-2)^n}, \qquad n \ge 1.$$

(Check: \(n=1\): \((-1)^0\cdot 0!\cdot(x-2)^{-1} = (x-2)^{-1}\) ✓; \(n=2\): \((-
1)^1\cdot 1!\cdot(x-2)^{-2} = -(x-2)^{-2}\) ✓.)

Therefore, by linearity,
$$\boxed{y^{(n)}(x) = (-1)^{n-1}(n-1)!\left[\frac{1}{x^n} + \frac{1}{(x-2)^n}\ri
ght], \qquad n \ge 1.}$$

### Step 3: Evaluate at \(x = 1\)

At \(x = 1\): \(x^n = 1\) and \((x-2)^n = (-1)^n\). Hence
$$y^{(n)}(1) = (-1)^{n-1}(n-1)!\left[1 + (-1)^n\right].$$

**Sanity checks:**
- \(n=1\): \(y'(1) = (-1)^0\cdot 0!\cdot[1 + (-1)] = 0\). Directly, \(y' = \frac
{2-2x}{2x-x^2}\), so \(y'(1) = 0\). ✓
- \(n=2\): \(y''(1) = (-1)^1\cdot 1!\cdot[1+1] = -2\). Direct computation of \(y
''\) at \(x=1\) gives \(-2\). ✓
- For odd \(n\): \([1 + (-1)^n] = 0\), so all odd derivatives vanish at \(x=1\).
 This is consistent with the symmetry \(2x - x^2 = 1 - (x-1)^2\), which makes \(
y\) an even function about \(x = 1\); hence all odd-order derivatives at \(x=1\)
 are zero. ✓

### Step 4: Apply to \(n = 100\)

Since \(100\) is even, \((-1)^{100} = 1\) and \((-1)^{99} = -1\):
$$y^{(100)}(1) = (-1)^{99}\cdot 99!\cdot[1 + 1] = -1 \cdot 99! \cdot 2.$$

### Result

$$\boxed{y^{(100)}(1) = -2\,(99!)}$$
