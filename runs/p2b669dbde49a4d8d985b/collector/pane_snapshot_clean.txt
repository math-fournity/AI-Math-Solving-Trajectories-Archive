The statement is **true**. Here is the proof.

---

**Theorem.** Let $f$ be an entire function. If there exists a nonzero polynomial
 $P \in \mathbb{C}[X,Y]$ such that $P(z, f(z)) = 0$ for all $z \in \mathbb{C}$,
then $f$ is a polynomial.

**Proof.**

Write $P$ as a polynomial in $Y$ with coefficients in $\mathbb{C}[X]$:
$$P(X,Y) = a_0(X)\,Y^n + a_1(X)\,Y^{n-1} + \cdots + a_{n-1}(X)\,Y + a_n(X),$$
where $a_i \in \mathbb{C}[X]$, $a_0 \not\equiv 0$, and $n = \deg_Y P \geq 1$.

(The case $n = 0$ is impossible: if $P \in \mathbb{C}[X]$ and $P(z) = 0$ for all
 $z$, then $P \equiv 0$, contradicting the hypothesis.)

Substituting $Y = f(z)$:
$$a_0(z)\,f(z)^n + a_1(z)\,f(z)^{n-1} + \cdots + a_n(z) = 0 \quad \text{for all
} z \in \mathbb{C}. \tag{1}$$

**Step 1: A polynomial growth bound on $f$.**

Let $d_i = \deg a_i$ (with $\deg 0 = -\infty$). Set
$$K = \max_{1 \le i \le n}\bigl(d_i - d_0\bigr), \qquad K^+ = \max(K, 0).$$

Since $a_0 \not\equiv 0$, there exists $R_0 > 0$ such that $|a_0(z)| \geq c\,|z|
^{d_0}$ for $|z| \geq R_0$ (where $c > 0$). Also, for each $i$, $|a_i(z)| \leq C
_i\,|z|^{d_i}$ for $|z|$ large.

Fix $z$ with $|z| \geq R_0$ and set $M = |f(z)|$.

- **If $M \geq 1$:** From (1), using $M^{n-i} \leq M^{n-1}$ for $i \geq 1$:
$$|a_0(z)|\,M^n \leq \sum_{i=1}^{n}|a_i(z)|\,M^{n-i} \leq M^{n-1}\sum_{i=1}^{n}|
a_i(z)|.$$
Dividing by $M^{n-1} > 0$:
$$M \leq \frac{\sum_{i=1}^{n}|a_i(z)|}{|a_0(z)|} \leq \frac{\sum_{i=1}^{n}C_i\,|
z|^{d_i}}{c\,|z|^{d_0}} = C'\,|z|^{K}.$$

- **If $M < 1$:** Then $M < 1 \leq |z|^{K^+}$ for $|z| \geq 1$ (when $K^+ \geq 0
$), so $M \leq |z|^{K^+} \leq C''|z|^{K}$ for a suitable constant.

Combining both cases, there exist constants $C, R > 0$ such that
$$|f(z)| \leq C\,|z|^{K^+} \quad \text{for all } |z| \geq R. \tag{2}$$

**Step 2: Entire + polynomial growth $\Rightarrow$ polynomial.**

This is the standard characterization. Expand $f$ as a power series $f(z) = \sum
_{k=0}^{\infty} c_k z^k$. By Cauchy's estimate, for any $r \geq R$:
$$|c_k| \leq \frac{\max_{|z|=r}|f(z)|}{r^k} \leq \frac{C\,r^{K^+}}{r^k} = C\,r^{
K^+ - k}.$$

For $k > K^+$, letting $r \to \infty$ gives $|c_k| = 0$. Hence $c_k = 0$ for all
 $k > K^+$, so $f$ is a polynomial of degree at most $\lfloor K^+ \rfloor$.

**Conclusion.** $f$ is a polynomial. $\blacksquare$
