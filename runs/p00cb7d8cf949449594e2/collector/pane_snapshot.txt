## Solution

**Legendre's three-square theorem** states that a positive integer $n$ cannot be
 expressed as a sum of three squares if and only if
$$n = 4^a(8b+7) \quad \text{for some integers } a \ge 0,\; b \ge 0.$$

### Counting the excluded integers

Let $N(x) = \#\{n \le x : n = 4^a(8b+7) \text{ for some } a,b \ge 0\}$.

**No double-counting.** Suppose $4^a(8b+7) = 4^{a'}(8b'+7)$ with $a < a'$. Then
$4^{a'-a}(8b+7) = 8b'+7$. Since $8b+7$ is odd, the left side is divisible by $4$
, but $8b'+7 \equiv 7 \pmod{8}$ is odd — contradiction. So each excluded integer
 has a *unique* representation $4^a(8b+7)$.

**Count per layer.** For fixed $a$, the count of $b \ge 0$ with $4^a(8b+7) \le x
$ is
$$\left\lfloor \frac{\lfloor x/4^a\rfloor - 7}{8}\right\rfloor + 1 \quad \text{(
when } x/4^a \ge 7\text{)},$$
which is $\dfrac{x}{8\cdot 4^a} + O(1)$.

**Sum over all layers.** Only finitely many $a$ contribute (those with $4^a \le
x/7$), so
$$N(x) = \sum_{a \ge 0} \left(\frac{x}{8\cdot 4^a} + O(1)\right) = \frac{x}{8}\s
um_{a\ge 0}\frac{1}{4^a} + O(\log x).$$

The geometric series gives
$$\sum_{a=0}^{\infty}\frac{1}{4^a} = \frac{1}{1-\tfrac14} = \frac{4}{3},$$
hence
$$N(x) = \frac{x}{8}\cdot\frac{4}{3} + O(\log x) = \frac{x}{6} + O(\log x).$$

### The limit

$$\lim_{x\to\infty}\frac{N(x)}{x} = \lim_{x\to\infty}\frac{x/6 + O(\log x)}{x} =
 \frac{1}{6}.$$

$$\boxed{\dfrac{1}{6}}$$
