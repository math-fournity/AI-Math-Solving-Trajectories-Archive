**Counterexample: $G = K_4$.**

$K_4$ has vertex set $V = \{1,2,3,4\}$ and every 3-element subset forms a triang
le. The cycles of $K_4$ include the four triangles $\{1,2,3\}, \{1,2,4\}, \{1,3,
4\}, \{2,3,4\}$ (as well as 4-cycles).

A set $V_i \subseteq V$ intersects every cycle iff its complement $V \setminus V
_i$ is acyclic (contains no cycle). In $K_4$, any 3 vertices induce a triangle,
so any acyclic induced subgraph has at most 2 vertices. Hence $|V \setminus V_i|
 \le 2$, i.e., $|V_i| \ge 2$.

Therefore every feedback vertex set (every set hitting all cycles) in $K_4$ has
size at least 2. Three pairwise disjoint such sets $V_1, V_2, V_3$ would require
$$|V_1| + |V_2| + |V_3| \ge 2 + 2 + 2 = 6$$
distinct vertices. But $|V| = 4 < 6$, so three pairwise disjoint feedback vertex
 sets cannot exist.

Thus the conjecture fails for $K_4$ (and indeed for every $K_n$ with $n \ge 4$,
since the minimum feedback vertex set of $K_n$ has size $n-2$, demanding $3(n-2)
 \le n$, i.e. $n \le 3$).
