## Solution

Let $x_n$ be the solution to $x = \tan x$ in $(n\pi,\, n\pi + \tfrac{\pi}{2})$.
Set
$$x_n = n\pi + \frac{\pi}{2} - \varepsilon_n, \qquad \varepsilon_n > 0.$$
As $n\to\infty$ the root approaches the vertical asymptote $n\pi+\pi/2$, so $\va
repsilon_n \to 0^+$. The desired limit is $\lim_{n\to\infty} n\,\varepsilon_n$.

**Rewriting the equation.** Since $\tan(n\pi + y) = \tan y$,
$$\tan(x_n) = \tan\!\Big(\frac{\pi}{2}-\varepsilon_n\Big) = \cot\varepsilon_n.$$
The defining equation $x_n = \tan(x_n)$ becomes
$$n\pi + \frac{\pi}{2} - \varepsilon_n = \cot\varepsilon_n. \tag{1}$$

**Asymptotic expansion.** For small $\varepsilon>0$,
$$\cot\varepsilon = \frac{1}{\varepsilon} - \frac{\varepsilon}{3} - \frac{\varep
silon^3}{45} - \cdots$$
Seek an expansion $\varepsilon_n = \dfrac{c}{n} + \dfrac{d}{n^2} + O(n^{-3})$. T
hen
$$\frac{1}{\varepsilon_n} = \frac{n}{c+d/n+O(n^{-2})} = \frac{n}{c} - \frac{d}{c
^{2}} + O(n^{-1}),$$
and
$$\cot\varepsilon_n = \frac{n}{c} - \frac{d}{c^{2}} - \frac{c}{3n} + O(n^{-2}).$
$

Substituting into (1):
$$n\pi + \frac{\pi}{2} - \frac{c}{n} - \frac{d}{n^{2}} + O(n^{-3}) = \frac{n}{c}
 - \frac{d}{c^{2}} - \frac{c}{3n} + O(n^{-2}).$$

**Matching powers of $n$:**

- $O(n)$: $\;\pi = \dfrac{1}{c}\;\Longrightarrow\; c = \dfrac{1}{\pi}.$
- $O(1)$: $\;\dfrac{\pi}{2} = -\dfrac{d}{c^{2}} = -d\pi^{2}\;\Longrightarrow\; d
 = -\dfrac{1}{2\pi}.$

(The $O(1/n)$ terms need not agree; they are absorbed by the next, undetermined
coefficient in $\varepsilon_n$, which is irrelevant for the limit.)

**Computing the limit.** With $c = 1/\pi$ and $d = -1/(2\pi)$,
$$\varepsilon_n = \frac{1}{\pi n} - \frac{1}{2\pi n^{2}} + O(n^{-3}),$$
so
$$n\,\varepsilon_n = \frac{1}{\pi} - \frac{1}{2\pi n} + O(n^{-2}) \;\xrightarrow
{n\to\infty}\; \frac{1}{\pi}.$$

Therefore
$$\boxed{\lim_{n\to\infty} n\left(n\pi+\frac{\pi}{2}-x_n\right) = \frac{1}{\pi}.
}$$
