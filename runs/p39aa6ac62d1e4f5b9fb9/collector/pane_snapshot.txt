## Proof

Let $X_t$ be standard Brownian motion with $X_0 = 0$, and $T_a = \inf\{t \geq 0
: X_t = a\}$.

We want $\mathbb{P}(T_2 < T_{-1} < T_3)$.

**Step 1: Decompose via the strong Markov property.**

The event $T_2 < T_{-1} < T_3$ means:
1. The process hits $2$ before $-1$ (i.e. $T_2 < T_{-1}$), and
2. Starting from the hitting point $X_{T_2} = 2$, the process then hits $-1$ bef
ore $3$ (i.e. $T_{-1} < T_3$ when "restarted" at time $T_2$).

By the strong Markov property, $X_{T_2 + t} - X_{T_2}$ is an independent Brownia
n motion, so these two events are independent. Hence

$$\mathbb{P}(T_2 < T_{-1} < T_3) = \mathbb{P}_0(T_2 < T_{-1}) \cdot \mathbb{P}_2
(T_{-1} < T_3).$$

**Step 2: Gambler's ruin formula for Brownian motion.**

For Brownian motion starting at $x$ with $a < x < b$,

$$\mathbb{P}_x(T_b < T_a) = \frac{x - a}{b - a}, \qquad \mathbb{P}_x(T_a < T_b)
= \frac{b - x}{b - a}.$$

(This follows since $X_t$ is a martingale and $X_{T_{a,b}} \in \{a,b\}$ a.s., so
 $x = a\,\mathbb{P}(T_a<T_b) + b\,\mathbb{P}(T_b<T_a)$.)

**Step 3: Compute each factor.**

First factor, starting at $x = 0$ with barriers $a = -1$, $b = 2$:

$$\mathbb{P}_0(T_2 < T_{-1}) = \frac{0 - (-1)}{2 - (-1)} = \frac{1}{3}.$$

Second factor, starting at $x = 2$ with barriers $a = -1$, $b = 3$:

$$\mathbb{P}_2(T_{-1} < T_3) = \frac{3 - 2}{3 - (-1)} = \frac{1}{4}.$$

**Step 4: Combine.**

$$\mathbb{P}(T_2 < T_{-1} < T_3) = \frac{1}{3} \cdot \frac{1}{4} = \boxed{\dfrac
{1}{12}}.$$
