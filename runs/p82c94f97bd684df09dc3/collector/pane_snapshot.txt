## Proof

We claim the limit equals $\xi$.

**Setup.** Note first that
$$\int_0^1 n\,x^n\,dx = \frac{n}{n+1}\xrightarrow[n\to\infty]{}1.$$

Decompose
$$\int_0^1 n\,x^n f(x)\,dx \;-\; \xi \;=\; \underbrace{\int_0^1 n\,x^n\bigl(f(x)
-\xi\bigr)\,dx}_{\displaystyle I_n} \;+\; \xi\!\left(\frac{n}{n+1}-1\right).$$

The second term is $-\xi/(n+1)\to 0$, so it suffices to show $I_n\to 0$.

**Estimating $I_n$.** Fix $\varepsilon>0$. Since $\lim_{x\to 1^-}f(x)=\xi$, ther
e exists $\delta\in(0,1)$ such that
$$|f(x)-\xi|<\varepsilon \quad\text{for all } x\in(1-\delta,\,1].$$

Split $I_n$ at $1-\delta$:
$$I_n = \underbrace{\int_0^{1-\delta} n\,x^n\bigl(f(x)-\xi\bigr)\,dx}_{A_n} + \u
nderbrace{\int_{1-\delta}^{1} n\,x^n\bigl(f(x)-\xi\bigr)\,dx}_{B_n}.$$

**Bound on $B_n$.** On $[1-\delta,1]$ we have $|f-\xi|<\varepsilon$, so
$$|B_n|\le \varepsilon\int_{1-\delta}^{1} n\,x^n\,dx \le \varepsilon\int_0^1 n\,
x^n\,dx = \varepsilon\cdot\frac{n}{n+1}<\varepsilon.$$

**Bound on $A_n$.** Since $f$ is Lebesgue integrable on $[0,1]$, the function $|
f-\xi|$ is integrable on the subinterval $[0,1-\delta]$. Set
$$M_\delta:=\int_0^{1-\delta}|f(x)-\xi|\,dx<\infty.$$
Then
$$|A_n|\le n\,(1-\delta)^n\int_0^{1-\delta}|f(x)-\xi|\,dx = M_\delta\cdot n\,(1-
\delta)^n.$$
Since $0<1-\delta<1$, the exponential decay dominates the linear factor: $n(1-\d
elta)^n\to 0$. Hence there exists $N$ such that for all $n\ge N$,
$$|A_n|<\varepsilon.$$

**Conclusion.** For all $n\ge N$,
$$|I_n|\le |A_n|+|B_n|<\varepsilon+\varepsilon=2\varepsilon.$$
Since $\varepsilon>0$ was arbitrary, $I_n\to 0$. Therefore
$$\lim_{n\to\infty}\int_0^1 n\,x^n f(x)\,dx = \xi + 0 = \boxed{\xi}.$$
