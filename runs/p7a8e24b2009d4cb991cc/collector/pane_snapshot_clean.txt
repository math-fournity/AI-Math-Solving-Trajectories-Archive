解答

答案：在 ZFC 中不可判定（独立于 ZFC）。 即 $2^{\mathfrak m} = 2^{\mathfrak n}$
蕴含 $\mathfrak m = \mathfrak n$ 这一命题既不是 ZFC 的定理，其否定也不是 ZFC 的
定理。

下面分两部分证明。

────────────────────────────────────────────────────────────────────────────────

第一部分：该蕴含关系不是 ZFC 的定理（存在反例模型）

我们利用 Easton 定理构造一个 ZFC 模型，其中 $2^{\aleph_0} = 2^{\aleph_1}$ 但 $
\aleph_0 \neq \aleph_1$。

Easton 定理（1970）：设 $F$ 是定义在所有正则基数上的函数，满足：

  1. （单调性）$\kappa \leq \lambda \Rightarrow F(\kappa) \leq F(\lambda)$；
  2. （König 约束）$\operatorname{cf}(F(\kappa)) > \kappa$。

则存在 ZFC 的传递模型（从满足 GCH 的模型出发做力迫），使得对所有正则基数 $
\kappa$，$2^\kappa = F(\kappa)$。

构造 $F$：

$$F(\kappa) = \begin{cases} \aleph_2 & \text{若 } \kappa \in {\aleph_0,
\aleph_1}, \ \kappa^+ & \text{若 } \kappa \geq \aleph_2 \text{ 为正则基数}.
\end{cases}$$

验证单调性：

  • $F(\aleph_0) = \aleph_2 \leq \aleph_2 = F(\aleph_1)$。 ✓
  • $F(\aleph_1) = \aleph_2 \leq \aleph_3 = F(\aleph_2)$。 ✓
  • 对 $\kappa \geq \aleph_2$ 的正则基数，$F(\kappa) = \kappa^+$，后继基数函数单
  调递增。 ✓

验证 König 约束：

  • $\operatorname{cf}(\aleph_2) = \aleph_2 > \aleph_1 \geq \aleph_0$。 ✓
  • 对正则 $\kappa \geq \aleph_2$，$\operatorname{cf}(\kappa^+) = \kappa^+ >
  \kappa$。 ✓

因此 $F$ 是合法的 Easton 函数。由 Easton 定理，存在 ZFC 的模型使得：

$$2^{\aleph_0} = \aleph_2 = 2^{\aleph_1}, \quad \text{但 } \aleph_0 \neq
\aleph_1.$$

取 $\mathfrak m = \aleph_0$，$\mathfrak n = \aleph_1$（均为无限基数），则
$2^{\mathfrak m} = 2^{\mathfrak n}$ 但 $\mathfrak m \neq \mathfrak n$。

结论： 该蕴含关系在 ZFC 中不成立（不是 ZFC 定理）。 $\square$

────────────────────────────────────────────────────────────────────────────────

第二部分：该蕴含关系的否定也不是 ZFC 的定理（在 GCH 下成立）

在 GCH（广义连续统假设）下，对所有无限基数 $\kappa$，有 $2^\kappa = \kappa^+$。

假设 $2^{\mathfrak m} = 2^{\mathfrak n}$，则在 GCH 下：

$$\mathfrak m^+ = \mathfrak n^+.$$

后继基数运算是单射的： 若 $\mathfrak m^+ = \mathfrak n^+$ 但 $\mathfrak m <
\mathfrak n$，则 $\mathfrak m^+ \leq \mathfrak n < \mathfrak n^+$，与 $\mathfrak
m^+ = \mathfrak n^+$ 矛盾。同理 $\mathfrak n < \mathfrak m$ 亦矛盾。故 $
\mathfrak m = \mathfrak n$。

由 Gödel 的可构成宇宙 $L$ 满足 GCH，而 $L$ 是 ZFC 的模型（若 ZFC 一致），故 GCH
与 ZFC 一致。

结论： 在 GCH 的模型中，$2^{\mathfrak m} = 2^{\mathfrak n} \Rightarrow \mathfrak
m = \mathfrak n$ 成立，故该蕴含关系的否定也不是 ZFC 定理。 $\square$

────────────────────────────────────────────────────────────────────────────────

综合结论

  • 存在 ZFC 模型（由 Easton 定理）使得 $2^{\aleph_0} = 2^{\aleph_1} = \aleph_2$
  而 $\aleph_0 \neq \aleph_1$，故蕴含关系不成立。
  • 存在 ZFC 模型（GCH / 可构成宇宙 $L$）使得 $2^{\mathfrak m} = 2^{\mathfrak n}
  \Rightarrow \mathfrak m = \mathfrak n$ 成立。

因此，命题"$2^{\mathfrak m} = 2^{\mathfrak n}$ 蕴含 $\mathfrak m = \mathfrak
n$"是 独立于 ZFC 的：它既不能在 ZFC 中被证明，也不能被否证。
