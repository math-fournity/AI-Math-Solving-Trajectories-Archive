$$N = (a-1)^{a^{1992}} + (a+1)^{a^{1990}}.$$

## Binomial Expansion

$$(a-1)^{a^{1992}} = \sum_{j=0}^{a^{1992}} \binom{a^{1992}}{j} a^j (-1)^{a^{1992
}-j}, \qquad (a+1)^{a^{1990}} = \sum_{j=0}^{a^{1990}} \binom{a^{1990}}{j} a^j.$$

Since a = 1991 is odd, a^{1992} is odd, so (-1)^{a^{1992}} = -1. The **j = 0** t

For **j ≥ 1**, since (-1)^{a^{1992}-j} = (-1)^{j+1} (because a^{1992} is odd):

$$c_j := (-1)^{j+1}\binom{a^{1992}}{j} + \binom{a^{1990}}{j}, \qquad N = \sum_{j

## p-adic Valuation of Each Term

$$v_p\!\left(\binom{a^n}{j}\right) = n - v_p(j),$$

*Proof.* Write a^n = p^n · M with p ∤ M. For each i with 1 ≤ i ≤ j−1 and v_p(i)

(This holds for all j ≤ a^{1990} since a^{1990} < p^{1992}, ensuring v_p(i) < 19

**Applying the lemma:**
