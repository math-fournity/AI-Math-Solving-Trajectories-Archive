证明：不存在从序数 α 到更小序数 β 的保序单射

问题

设 α, β 为序数，α > β。是否存在保序且单射的函数 f: α → β？

答案

不存在。 即：若存在保序单射 f: α → β，则必有 α ≤ β。

证明

设 f: α → β 保序且单射。这里"保序"指：对任意 ξ < η < α，有 f(ξ) < f(η)（严格保
序）。注意：严格保序已蕴含单射性，但题目同时要求单射，二者等价，不影响论证。

核心引理： 对所有 ξ < α，有 f(ξ) ≥ ξ。

我们对 ξ < α 作超限归纳。

  • 基础步 (ξ = 0)： f(0) ≥ 0，平凡成立。
  • 后继步： 设 f(ξ) ≥ ξ。由保序性，f(ξ+1) > f(ξ) ≥ ξ。因 f(ξ+1) 是序数且严格大
  于 ξ，故 f(ξ+1) ≥ ξ + 1。
  • 极限步 (ξ = λ 为极限序数)： 设对所有 ξ < λ，f(ξ) ≥ ξ。由保序性，对每个 ξ < λ
  有 f(λ) > f(ξ) ≥ ξ，故 $$f(\lambda) \geq \sup{f(\xi) : \xi < \lambda} \geq
  \sup{\xi : \xi < \lambda} = \lambda.$$ 因此 f(λ) ≥ λ。

归纳完成，故对所有 ξ < α，f(ξ) ≥ ξ。

导出矛盾： 由 f 的值域在 β 中，对所有 ξ < α 有 f(ξ) < β。结合引理 f(ξ) ≥ ξ，得 $
$\xi \leq f(\xi) < \beta \quad \text{对所有 } \xi < \alpha.$$ 这意味着每个 ξ < α
都满足 ξ < β，即 α ⊆ β。作为序数，α ⊆ β 等价于 α ≤ β。

但这与假设 α > β 矛盾。因此，不存在从 α 到更小序数 β 的保序单射。$\blacksquare$

等价表述

上述结果可重述为：序数 α 不能保序嵌入到任何严格更小的序数中。这正是序数的"刚
性"（rigidity）——序数与其序结构唯一对应，不存在将较大序数压缩进较小序数而不破坏
序结构的映射。
