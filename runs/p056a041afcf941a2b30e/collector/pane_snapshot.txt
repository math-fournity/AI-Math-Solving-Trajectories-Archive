## Proof

Let $n = 2^i$ with $i \geq 1$. We show the immersion dimension of $\mathbb{R}P^n
$ is $2n - 1 = 2^{i+1} - 1$ by establishing matching lower and upper bounds.

### Lower Bound: Immersion dimension $\geq 2n - 1$

We use Stiefel–Whitney class obstructions. Recall that $H^*(\mathbb{R}P^n;\,\mat
hbb{Z}/2) = \mathbb{Z}/2[a]/(a^{n+1})$ with $|a|=1$, and the total Stiefel–Whitn
ey class is
$$w(\mathbb{R}P^n) = (1+a)^{n+1}.$$

If $\mathbb{R}P^n$ immerses in $\mathbb{R}^{n+k}$, the normal bundle $\nu$ has r
ank $k$ and satisfies $\tau \oplus \nu \cong \epsilon^{n+k}$, so $\bar{w} := w^{
-1} = w(\nu)$. Since $w(\nu)$ is a polynomial of degree $\leq k$, we need $\bar{
w}_j = 0$ for all $j > k$.

We compute $\bar{w} = (1+a)^{-(n+1)}$ with $n+1 = 2^i + 1$:
$$\bar{w} = (1+a)^{-2^i}\cdot(1+a)^{-1}.$$

**First factor.** By the Frobenius endomorphism in $\mathbb{Z}/2$, $(1+a)^{2^i}
= 1 + a^{2^i}$, so
$$(1+a)^{-2^i} = (1+a^{2^i})^{-1} = 1 + a^{2^i} + a^{2\cdot 2^i} + \cdots$$
Since $a^{n+1} = a^{2^i+1} = 0$, all terms $a^j$ with $j \geq 2^i+1$ vanish, so
$(1+a)^{-2^i} = 1 + a^{2^i}$.

**Second factor.** $(1+a)^{-1} = 1 + a + a^2 + \cdots + a^n$ (geometric series,
truncated at $a^{n+1}=0$).

**Product.**
$$\bar{w} = (1 + a^{2^i})(1 + a + a^2 + \cdots + a^{2^i})$$
$$= (1 + a + \cdots + a^{2^i}) + a^{2^i}(1 + a + \cdots + a^{2^i}).$$

The second sum is $a^{2^i} + a^{2^i+1} + \cdots$, but $a^{2^i+1} = a^{n+1} = 0$,
 so it reduces to just $a^{2^i}$. Therefore:
$$\bar{w} = (1 + a + a^2 + \cdots + a^{n}) + a^{n} = 1 + a + a^2 + \cdots + a^{n
-1},$$
since $a^n + a^n = 0$ in $\mathbb{Z}/2$.

The highest nonzero component is $\bar{w}_{n-1} = a^{n-1} \neq 0$ (as $n-1 < n$)
. Thus any immersion $\mathbb{R}P^n \to \mathbb{R}^{n+k}$ requires $k \geq n-1$,
 giving:
$$\text{immersion dimension} \geq n + (n-1) = 2n - 1.$$

### Upper Bound: Immersion dimension $\leq 2n - 1$

By the **Whitney Immersion Theorem**, every smooth $n$-manifold with $n \geq 2$
admits an immersion into $\mathbb{R}^{2n-1}$. Since $n = 2^i \geq 2$ for $i \geq
 1$, this applies to $\mathbb{R}P^n$, giving:
$$\text{immersion dimension} \leq 2n - 1.$$

### Conclusion

The lower and upper bounds coincide:
$$\text{immersion dimension of } \mathbb{R}P^n = 2n - 1 = 2^{i+1} - 1.$$

**Verification for small cases:**
- $i=1$, $n=2$: immersion dimension $= 3$. Indeed, $\mathbb{R}P^2$ immerses in $
\mathbb{R}^3$ (Boy's surface) and $\bar{w}_1 \neq 0$ rules out $\mathbb{R}^2$. ✓
- $i=2$, $n=4$: immersion dimension $= 7$. The class $\bar{w}_3 \neq 0$ rules ou
t $\mathbb{R}^6$, and Whitney gives $\mathbb{R}^7$. ✓

$$\boxed{\text{The immersion dimension of } \mathbb{R}P^{2^i} \text{ is } 2^{i+1
} - 1.}$$
