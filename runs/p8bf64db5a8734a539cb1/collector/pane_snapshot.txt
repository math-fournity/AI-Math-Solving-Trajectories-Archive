# Solution

**Claim.** A function $f : \mathbb{R}^+ \to \mathbb{R}^+$ satisfies $f(f(f(x)))
= x$ for all $x > 0$ if and only if $f$ is a bijection of $\mathbb{R}^+$ in whic
h every orbit has size $1$ or $3$. Equivalently, $\mathbb{R}^+$ can be partition
ed into a set of fixed points and a collection of $3$-element sets $\{a, b, c\}$
, on each of which $f$ acts as the cycle $a \mapsto b \mapsto c \mapsto a$.

---

## Proof

### Necessity ($f^3 = \mathrm{id} \Rightarrow$ orbit structure)

Suppose $f(f(f(x))) = x$ for all $x > 0$; write $f^3 = \mathrm{id}$.

**Step 1: $f$ is bijective.** Since $f \circ f \circ f = \mathrm{id}$, the funct
ion $f$ has a two-sided inverse, namely $f^2 = f \circ f$:
$$f \circ f^2 = f^3 = \mathrm{id} = f^3 = f^2 \circ f.$$
Hence $f$ is both injective and surjective.

**Step 2: Every orbit has size $1$ or $3$.** Fix $x \in \mathbb{R}^+$ and consid
er its orbit under $f$:
$$\mathcal{O}(x) = \{x,\; f(x),\; f^2(x),\; f^3(x),\; \dots\}.$$
Since $f^3(x) = x$, the orbit is $\{x, f(x), f^2(x)\}$, which has size $1$, $2$,
 or $3$.

- **Size $1$:** $f(x) = x$ — $x$ is a fixed point.
- **Size $2$:** $f(x) \neq x$ but $f^2(x) = x$. Then $f^3(x) = f(f^2(x)) = f(x)
\neq x$, contradicting $f^3 = \mathrm{id}$. **This case is impossible.**
- **Size $3$:** $x, f(x), f^2(x)$ are pairwise distinct, and $f$ permutes them c
yclically: $x \mapsto f(x) \mapsto f^2(x) \mapsto x$.

Thus every orbit has size $1$ or $3$, and $\mathbb{R}^+$ is the disjoint union o
f fixed points and $3$-cycles.

### Sufficiency (orbit structure $\Rightarrow f^3 = \mathrm{id}$)

Conversely, suppose $\mathbb{R}^+$ is partitioned into a set $F$ of fixed points
 and a family $\{C_\alpha\}_{\alpha}$ of $3$-element sets, and define $f$ by:
- $f(x) = x$ for $x \in F$,
- On each $C_\alpha = \{a_\alpha, b_\alpha, c_\alpha\}$, set $f(a_\alpha) = b_\a
lpha,\; f(b_\alpha) = c_\alpha,\; f(c_\alpha) = a_\alpha$.

Then for any fixed point $x$: $f^3(x) = x$. For any $x$ in a $3$-cycle, say $x =
 a_\alpha$:
$$f^3(a_\alpha) = f^2(b_\alpha) = f(c_\alpha) = a_\alpha = x.$$
The same holds for $b_\alpha$ and $c_\alpha$ by the cyclic symmetry. Hence $f^3(
x) = x$ for all $x > 0$. $\checkmark$

### Existence of nontrivial solutions

The identity $f(x) = x$ is the trivial solution (all orbits of size $1$). Nontri
vial solutions exist: for example, partition $\mathbb{R}^+$ into triples and cyc
le each. A concrete example: pair up elements of $\mathbb{R}^+$ into $3$-element
 sets $\{a, b, c\}$ (possible since $\mathbb{R}^+$ is uncountable) and define $f
$ as a $3$-cycle on each. One explicit construction uses the fact that $\mathbb{
R}^+$ has the same cardinality as $\mathbb{R}^+ \times \{0,1,2\}$, so choose a b
ijection $\varphi : \mathbb{R}^+ \to \mathbb{R}^+ \times \{0,1,2\}$ and define
$$f(x) = \varphi^{-1}\!\big((y,\, (i+1)\bmod 3)\big), \quad \text{where } \varph
i(x) = (y, i).$$
Then $f^3 = \mathrm{id}$ and $f$ has no fixed points (a pure product of $3$-cycl
es).

---

## Summary

The complete set of solutions to $f(f(f(x))) = x$ on $\mathbb{R}^+$ is:

> **All bijections $f : \mathbb{R}^+ \to \mathbb{R}^+$ whose orbits under iterat
ion all have size $1$ or $3$.**

Equivalently, $f$ is obtained by partitioning $\mathbb{R}^+$ into fixed points a
nd $3$-element cycles, and letting $f$ fix the former and cyclically permute the
 latter. The identity $f(x) = x$ is the unique solution with all orbits of size
$1$; every other solution involves at least one $3$-cycle.
