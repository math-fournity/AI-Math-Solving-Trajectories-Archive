### Setting up the substitution

The constraint is $abc + a + c = b$ with $a, b, c > 0$. Rearranging:

$$b(1 - ac) = a + c \implies b = \frac{a + c}{1 - ac}.$$

Since $a + c > 0$ and $b > 0$, we need $1 - ac > 0$, i.e. $ac < 1$.

Set $a = \tan\alpha$, $c = \tan\gamma$ with $\alpha, \gamma \in (0, \pi/2)$. The
 condition $ac < 1$ becomes $\tan\alpha\tan\gamma < 1$, which is equivalent to $
\alpha + \gamma < \pi/2$. Then by the tangent addition formula:

$$b = \frac{\tan\alpha + \tan\gamma}{1 - \tan\alpha\tan\gamma} = \tan(\alpha + \
gamma).$$

Let $\beta = \alpha + \gamma \in (0, \pi/2)$, so $b = \tan\beta$.
