## Proof

BM = x.

**Configuration.** Since β > 90° > 60° = ∠ABC, the point M lies outside the tria
ngle, with ray BM outside ∠ABC beyond BC. Thus:

$$\beta = \angle ABC + \angle CBM = 60° + x. \quad \text{(i)}$$

**Angles at A.** In △ABM: ∠BAM = 180° − 40° − β = 140° − β. Since β > 90°, we ge
t ∠BAM = 140° − β < 50° < 60° = ∠BAC, so ray AM lies **inside** ∠BAC, giving:

$$\angle CAM = 60° - (140° - \beta) = \beta - 80°. \quad \text{(ii)}$$

**Applying the sine rule in △ABM:**

$$\frac{AM}{\sin\beta} = \frac{AB}{\sin 40°} = \frac{1}{\sin 40°} \implies AM =
\frac{\sin\beta}{\sin 40°}. \quad \text{(iii)}$$

**Applying the sine rule in △ACM.** Here ∠AMC = 30°, ∠CAM = β − 80°, so ∠ACM = 1
80° − 30° − (β − 80°) = 230° − β:

$$\frac{AM}{\sin(230°-\beta)} = \frac{AC}{\sin 30°} = 2 \implies AM = 2\sin(230°
-\beta). \quad \text{(iv)}$$

**Equating (iii) and (iv):**

$$\frac{\sin\beta}{\sin 40°} = 2\sin(230°-\beta).$$

Substituting β = 60° + x from (i), and noting 230° − β = 170° − x:

$$\frac{\sin(60°+x)}{\sin 40°} = 2\sin(170°-x).$$

Since sin(170° − x) = sin(10° + x):

$$\sin(60°+x) = 2\sin 40°\cdot\sin(10°+x).$$

**Applying the product-to-sum identity** 2 sin A sin B = cos(A−B) − cos(A+B):

$$2\sin 40°\cdot\sin(10°+x) = \cos(30°-x) - \cos(50°+x).$$

So the equation becomes:

$$\sin(60°+x) = \cos(30°-x) - \cos(50°+x).$$

**Key identity:** sin(60° + x) = cos(30° − x), since sin θ = cos(90° − θ). Subst
ituting:

$$\cos(30°-x) = \cos(30°-x) - \cos(50°+x).$$

This collapses to:

$$\cos(50°+x) = 0.$$

Therefore 50° + x = 90°, giving:

$$\boxed{\angle CBM = x = 40°}.$$
