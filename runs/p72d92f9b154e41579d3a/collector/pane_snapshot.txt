Looking at this problem, I need to find the circumradius of triangle DEF, where
D, E, F are incenters of the three triangles formed by the altitude feet.

## Setup

Triangle ABC with a=BC=13, b=CA=14, c=AB=15. Place B=(0,0), C=(13,0).

**Finding A:** From AB=15, AC=14: x²+y²=225, (x−13)²+y²=196 → x=99/13, y=168/13.
 So **A=(99/13, 168/13)**.

**Angles (Law of Cosines):**
- cos A = (b²+c²−a²)/(2bc) = 252/420 = **3/5**, sin A = 4/5
- cos B = (a²+c²−b²)/(2ac) = 198/390 = **33/65**
- cos C = (a²+b²−c²)/(2ab) = 140/364 = **5/13**

**Area** = ½·b·c·sin A = ½·14·15·(4/5) = 84. **Inradius** r = 84/21 = **4** (s=2
1).

**Incenter:** I = (aA + bB + cC)/(a+b+c) = (13·(99/13,168/13) + 15·(13,0))/42 =
(99+195, 168)/42 = **(7, 4)**. ✓ (distance 4 from BC)

## Altitude feet

- **A'** = (99/13, 0) (foot from A to BC, the x-axis)
- **B'** = (144/13, 60/13) (foot from B to AC; verified AB'=9, B'C=5)
- **C'** = (1089/325, 1848/325) (foot from C to AB; verified AC'=42/5, C'B=33/5)

## Key insight: each corner triangle is similar to ABC

**Triangle AB'C'** has sides AB'=9, AC'=42/5, B'C'=39/5, with ratio 9:42/5:39/5
= 45:42:39 = 15:14:13 = c:b:a. So AB'C' ~ ABC with ratio **cos A = 3/5**.

The similarity maps A→A, B→B' (on ray AC), C→C' (on ray AB). This swaps rays AB
and AC: a **reflection over the angle bisector of A** (which fixes I) followed b
y **homothety centered at A with ratio cos A**.

Since I lies on the angle bisector of A, the reflection fixes I, so:
$$D = A + \cos A \cdot (I - A) = \tfrac{2}{5}A + \tfrac{3}{5}I$$

By identical reasoning:
$$E = B + \cos B \cdot (I - B), \qquad F = C + \cos C \cdot (I - C)$$

(Verified: BC'A' has sides a cos B : c cos B : b cos B = 33/5 : 99/13 : 462/65 ∝
 13:15:14, similar to ABC with ratio cos B; CA'B' similarly with ratio cos C.)

## Computing D, E, F

- **D** = (2/5)(99/13, 168/13) + (3/5)(7, 4) = (198/65 + 273/65, 336/65 + 156/65
) = **(471/65, 492/65)**
- **E** = (33/65)(7, 4) = **(231/65, 132/65)**
- **F** = (8/13)(13, 0) + (5/13)(7, 4) = (139/13, 20/13) = **(695/65, 100/65)**

## Side lengths of DEF

- **DE²** = (240² + 360²)/65² = 187200/4225 = 576/13 → DE = 24/√13
- **EF²** = (464² + 32²)/65² = 216320/4225 = 256/5 → EF = 16/√5
- **FD²** = (224² + 392²)/65² = 203840/4225 = 3136/65 → FD = 56/√65

## Area of DEF

$$\text{Area} = \tfrac{1}{2}\left|\det\begin{pmatrix} -240 & -360 \\ 224 & -392
\end{pmatrix}\right|/65^2 = \tfrac{240\cdot392 + 360\cdot224}{2\cdot 4225} = \tf
rac{174720}{8450} = \tfrac{1344}{65}$$

## Circumradius

$$R_{DEF} = \frac{DE \cdot EF \cdot FD}{4\cdot\text{Area}} = \frac{(24/\sqrt{13}
)(16/\sqrt{5})(56/\sqrt{65})}{4\cdot 1344/65}$$

The numerator: 24·16·56/√(13·5·65) = 21504/√4225 = **21504/65**.

$$R_{DEF} = \frac{21504/65}{5376/65} = \frac{21504}{5376} = \boxed{4}$$

**Remark:** This equals the inradius r = 4 of triangle ABC. This is in fact a ge
neral result: for any acute triangle, the circumradius of DEF (constructed as ab
ove) equals the inradius r. One can verify this via the equilateral case (where
DEF is the homothetic image of ABC under ratio 1/2 centered at I, giving R_DEF =
 R/2 = r), and the coordinate proof above confirms it for the 13-14-15 triangle.
