## Proof

**Today's date:** 2026-08-13 (August 13, 2026).

**Goal.** Count all valid calendar dates, written in a standard `YYYY-MM-DD` for
mat (the argument is identical for `DD/MM/YYYY` or `MM/DD/YYYY`), whose digits a
re drawn only from {0, 2}, and which are strictly in the future relative to toda
y.

---

### Step 1 — Restrict the month

The month field `MM` uses two digits, each ∈ {0, 2}. The four candidates are:

- `00` — not a valid month (months run 01–12)
- `02` — February ✓
- `20` — not a valid month
- `22` — not a valid month

So **the only admissible month is 02 (February)**.

### Step 2 — Restrict the day

The day field `DD` uses two digits, each ∈ {0, 2}. Candidates:

- `00` — invalid (days run 01–31)
- `02` — valid ✓
- `20` — valid ✓
- `22` — valid ✓

February has at most 29 days, and all three candidates (02, 20, 22) are ≤ 29, so
 each is a valid February day in **every** year (leap or not). Thus there are **
3 admissible days**.

### Step 3 — Restrict the year to the future

The year field `YYYY` uses four digits, each ∈ {0, 2}. All 16 combinations are:

```
0000 0002 0020 0022 0200 0202 0220 0222
2000 2002 2020 2022 2200 2202 2220 2222
```

A date is in the future relative to 2026-08-13. Since the month is fixed at Febr
uary (02) and today is in August 2026:

- Any year **≤ 2026** gives a February that is already in the past (February 202
6 or earlier).
- We therefore need **year > 2026**.

From the list, the years strictly greater than 2026 are:

```
2200, 2202, 2220, 2222
```

That is **4 admissible future years**.

### Step 4 — Verify calendar validity of all candidates

Each candidate date is `YYYY-02-DD` with `DD ∈ {02, 20, 22}`. We only need to co
nfirm February has enough days:

| Year | Leap? (div by 4, and by 400 if century) | Feb length | Days 02/20/22 va
lid? |
|------|------------------------------------------|-----------|-----------------
-----|
| 2200 | century, 2200/400 = 5.5 → **not leap** | 28 | all ≤ 28 ✓ |
| 2202 | 2202/4 = 550.5 → not leap | 28 | ✓ |
| 2220 | century, 2220/400 = 5.55 → not leap | 28 | ✓ |
| 2222 | 2222/4 = 555.5 → not leap | 28 | ✓ |

All 4 × 3 = 12 dates are valid calendar dates.

### Step 5 — Count

- Admissible future years: **4**
- Admissible months: **1** (February)
- Admissible days: **3** (02, 20, 22)

Total = 4 × 1 × 3 = **12**.

The twelve dates are:

```
2200-02-02   2200-02-20   2200-02-22
2202-02-02   2202-02-20   2202-02-22
2220-02-02   2220-02-20   2220-02-22
2222-02-02   2222-02-20   2222-02-22
```

Each uses only the digits 0 and 2, each is a valid calendar date, and each is st
rictly after 2026-08-13.

### Answer
