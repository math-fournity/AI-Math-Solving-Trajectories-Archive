## Solution

**Claim:** The smallest such $r$ is $\boxed{2}$.

**Setup.** Let $f_a(x) = ax^3 + x^2 - 4$ with $a > 0$. Note $f_a(0) = -4 < 0$ an
d $f_a(2) = 8a > 0$. Since $f_a'(x) = x(3ax+2) > 0$ for $x > 0$, the function $f
_a$ is strictly increasing on $(0,\infty)$, so there is a **unique positive root
** $x_+(a) \in (0,2)$.

**Reformulation.** The interval $[2-ar,\, 2]$ always contains $2$ as its right e
ndpoint and $x_+(a) < 2$ always. So the condition "$f_a$ has a root in $[2-ar,2]
$" is equivalent (using monotonicity on $(0,\infty)$ and the fact that the only
positive root is $x_+(a)$) to:
$$2 - ar \;\le\; x_+(a), \quad\text{i.e.,}\quad r \;\ge\; \frac{2 - x_+(a)}{a}.$
$
(When $2-ar \le 0$ this is automatic since $x_+(a)>0$; the binding case is $2-ar
>0$.) Thus we need
$$r \;\ge\; \sup_{a>0}\,\frac{2-x_+(a)}{a}.$$

**Parametrization.** Since $x_+(a) \in (0,2)$ and $a = \dfrac{4-x^2}{x^3}$ is a
bijection from $(0,2)$ onto $(0,\infty)$ (decreasing, with $a\to\infty$ as $x\to
 0^+$ and $a\to 0^+$ as $x\to 2^-$), we may parametrize by $x \in (0,2)$:
$$\frac{2 - x_+(a)}{a} \;=\; \frac{(2-x)\,x^3}{4-x^2} \;=\; \frac{(2-x)\,x^3}{(2
-x)(2+x)} \;=\; \frac{x^3}{x+2} \;=:\; g(x).$$

**Maximizing $g$.** For $x \in (0,2)$:
$$g'(x) = \frac{3x^2(x+2)-x^3}{(x+2)^2} = \frac{x^2(2x+6)}{(x+2)^2} = \frac{2x^2
(x+3)}{(x+2)^2} > 0.$$
So $g$ is strictly increasing on $(0,2)$, and
$$\sup_{x\in(0,2)} g(x) = \lim_{x\to 2^-} \frac{x^3}{x+2} = \frac{8}{4} = 2,$$
with $g(x) < 2$ for every $x \in (0,2)$ (the supremum is **not attained**).

**$r = 2$ works.** For every $a > 0$, $\dfrac{2-x_+(a)}{a} = g(x_+(a)) < 2 = r$,
 so $2 - 2a < x_+(a) < 2$, giving $x_+(a) \in [2-2a,\, 2]$. ✓

**No $r < 2$ works.** Pick any $r < 2$. Since $\sup g = 2$, choose $x_0 \in (0,2
)$ with $g(x_0) > r$, and set $a_0 = (4-x_0^2)/x_0^3 > 0$. Then $x_+(a_0) = x_0$
 and
$$\frac{2 - x_+(a_0)}{a_0} = g(x_0) > r \;\Longrightarrow\; x_+(a_0) < 2 - a_0 r
.$$
Moreover $2 - a_0 r > x_0 > 0$, so the interval $[2-a_0 r,\, 2]$ lies entirely i
n $(0,\infty)$, where $f_{a_0}$ is strictly increasing with its **only** positiv
e root $x_+(a_0) = x_0 < 2 - a_0 r$. Hence $f_{a_0}$ has **no root** in $[2-a_0
r,\, 2]$. So $r$ fails. ✗

**Conclusion.** The smallest positive $r$ with the required property is $r = 2$.
