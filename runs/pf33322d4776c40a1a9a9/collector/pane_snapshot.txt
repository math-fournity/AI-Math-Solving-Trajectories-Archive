## Solution

### Setup: relate the real integral to a complex integral

Let $f(z) = u(x,y) + i\,v(x,y)$ and $z = x+iy$, so $dz = dx + i\,dy$. Expanding:

$$\oint_C f\,dz = \oint_C (u+iv)(dx+i\,dy) = \oint_C (u\,dx - v\,dy) + i\oint_C
(u\,dy + v\,dx).$$

Therefore the requested integral is the imaginary part:

$$\oint_C u\,dy + v\,dx = \operatorname{Im}\!\left(\oint_C f\,dz\right). \tag{1}
$$

### Locate the singularities

$$f(z) = \frac{1}{z^2-6z+8} = \frac{1}{(z-2)(z-4)}.$$

Poles at $z=2$ and $z=4$. On the curve $C: |z|=3$:
- $|2|=2<3$ → pole **inside** $C$,
- $|4|=4>3$ → pole **outside** $C$.

### Justifying the reduction (Green's theorem with a puncture)

The Cauchy–Riemann equations give $u_x = v_y$ wherever $f$ is analytic, so the i
ntegrand $u_x - v_y$ of Green's theorem vanishes on $D\setminus\{2\}$. Excising
a small disk $B_\varepsilon(2)$ with boundary $C_\varepsilon$ (counterclockwise)
, Green's theorem yields

$$\oint_C (v\,dx+u\,dy) - \oint_{C_\varepsilon}(v\,dx+u\,dy) = \iint_{D\setminus
 B_\varepsilon(2)}(u_x-v_y)\,dA = 0,$$

hence $\oint_C (v\,dx+u\,dy) = \operatorname{Im}\oint_{C_\varepsilon} f\,dz$, co
nfirming (1) is valid via the residue theorem applied to the punctured domain.

### Apply the residue theorem

Only the pole at $z=2$ lies inside $C$. It is a simple pole, so

$$\operatorname{Res}_{z=2}\frac{1}{(z-2)(z-4)} = \left.\frac{1}{z-4}\right|_{z=2
} = \frac{1}{2-4} = -\frac{1}{2}.$$

Thus

$$\oint_C f\,dz = 2\pi i\cdot\operatorname{Res}_{z=2} f = 2\pi i\cdot\left(-\fra
c{1}{2}\right) = -\pi i.$$

### Extract the answer

$$\oint_C u\,dy + v\,dx = \operatorname{Im}(-\pi i) = -\pi.$$

### Result

$$\boxed{\oint_C u\,dy + v\,dx = -\pi}$$
