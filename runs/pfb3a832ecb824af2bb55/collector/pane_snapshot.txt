# Solution

## Setup and notation

Let $\mu$ denote the uniform (fair-coin) product measure on $\{0,1\}^\omega$. Fo
r a finite binary string $s$, let $[s]$ denote the cylinder set of all infinite
sequences beginning with $s$, so $\mu([s]) = 2^{-|s|}$.

For each $n \ge 1$, define:
$$B_n = \{w \in \{0,1\}^\omega : w \text{ starts with } pp \text{ for some } p \
in \{0,1\}^n\} = \bigcup_{p \in \{0,1\}^n} [pp].$$

Then define:
$$A_N = \bigcup_{n \ge N} B_n = \{w : w \text{ has a prefix } pp \text{ with } |
p| \ge N\}.$$

The set in question is $S = \bigcap_{N=1}^{\infty} A_N$.

## Measurability

Each $[pp]$ is a cylinder set (clopen in the product topology). Each $B_n$ is a
finite union of cylinders, and each $A_N$ is a countable union of Borel sets. Th
us $S = \bigcap_N A_N$ is Borel measurable.

## Computing $\mu(B_n)$

For fixed $n$, the cylinders $\{[pp] : p \in \{0,1\}^n\}$ are **pairwise disjoin
t** (distinct strings $p$ of length $n$ yield distinct first-$2n$-bit patterns).
 Therefore:
$$\mu(B_n) = \sum_{p \in \{0,1\}^n} \mu([pp]) = 2^n \cdot 2^{-2n} = 2^{-n}.$$

## Bounding $\mu(A_N)$

By the union bound:
$$\mu(A_N) = \mu\!\left(\bigcup_{n \ge N} B_n\right) \le \sum_{n=N}^{\infty} \mu
(B_n) = \sum_{n=N}^{\infty} 2^{-n} = 2^{1-N}.$$

## Concluding $\mu(S) = 0$

Since $S = \bigcap_{N=1}^{\infty} A_N \subseteq A_N$ for every $N$:
$$0 \le \mu(S) \le \mu(A_N) \le 2^{1-N} \quad \text{for all } N \ge 1.$$

Taking $N \to \infty$, the right-hand side tends to $0$, so:
$$\mu(S) = 0.$$

## Remark (non-emptiness)

$S$ is nonempty: the all-zeros sequence $w = 000\ldots$ lies in $S$, since for e
very $N$, it begins with $0^{2N} = pp$ where $p = 0^N$ and $|p| = N \ge N$. Like
wise for the all-ones sequence. So $S$ is a nonempty null set.

## Answer

$$\boxed{\mu(S) = 0}$$
