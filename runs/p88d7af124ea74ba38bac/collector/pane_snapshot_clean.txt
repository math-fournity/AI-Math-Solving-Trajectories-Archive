### 问题

使用复分析方法计算
$$I = \int_{-\infty}^{\infty} \frac{x^2}{x^4+4}\,dx.$$

### 第一步：识别有理函数并选择围道

设
$$f(z) = \frac{z^2}{z^4+4}.$$
这是一个满足 $f(-z)=f(z)$ 的有理函数，因此被积函数是偶函数，且 $f(z)$ 在上半平面
 $\operatorname{Im} z > 0$ 内除在 $z^4+4=0$ 的根处外是全纯的。我们使用由实轴区间
 $[-R,R]$ 和上半圆 $C_R = \{Re^{i\theta}:0\le\theta\le\pi\}$ 组成的标准闭合围道
$\Gamma_R$，并令 $R\to\infty$。

### 第二步：求 $z^4+4=0$ 的极点

我们需要 $z^4 = -4 = 4e^{i\pi}$，因此
$$z_k = \sqrt{2}\,e^{i(\pi+2k\pi)/4},\qquad k=0,1,2,3.$$
明确地写出：
$$z_0 = \sqrt{2}\,e^{i\pi/4} = 1+i,\qquad z_1 = \sqrt{2}\,e^{i3\pi/4} = -1+i,$$
$$z_2 = \sqrt{2}\,e^{i5\pi/4} = -1-i,\qquad z_3 = \sqrt{2}\,e^{i7\pi/4} = 1-i.$$

只有 **$z_0 = 1+i$** 和 **$z_1 = -1+i$** 位于上半平面。两者都是单极点（$z^4+4$
的根都是单根，因为 $4z^3\neq 0$ 在每个根处都成立）。

### 第三步：计算留数

由于 $z^4+4$ 的根都是单根，在根 $a$ 处的留数为
$$\operatorname{Res}_{z=a} f(z) = \frac{z^2}{(z^4+4)'}\bigg|_{z=a} = \frac{a^2}{
4a^3} = \frac{1}{4a}.$$

**在 $a = 1+i$ 处：**
$$\operatorname{Res}_{z=1+i} f = \frac{1}{4(1+i)} = \frac{1}{4}\cdot\frac{1}{1+i
}\cdot\frac{1-i}{1-i} = \frac{1}{4}\cdot\frac{1-i}{2} = \frac{1-i}{8}.$$

**在 $a = -1+i$ 处：**
$$\operatorname{Res}_{z=-1+i} f = \frac{1}{4(-1+i)} = \frac{1}{4}\cdot\frac{1}{-
1+i}\cdot\frac{-1-i}{-1-i} = \frac{1}{4}\cdot\frac{-1-i}{2} = \frac{-1-i}{8}.$$

### 第四步：应用留数定理

对于足够大的 $R$（使得两个上半平面的极点都在 $\Gamma_R$ 内部），柯西留数定理给出
$$\oint_{\Gamma_R} f(z)\,dz = 2\pi i\Big(\operatorname{Res}_{z=1+i} f + \operato
rname{Res}_{z=-1+i} f\Big).$$

留数之和为
$$\frac{1-i}{8} + \frac{-1-i}{8} = \frac{(1-i)+(-1-i)}{8} = \frac{-2i}{8} = \fra
c{-i}{4}.$$

因此
$$\oint_{\Gamma_R} f(z)\,dz = 2\pi i\cdot\frac{-i}{4} = 2\pi i\cdot\frac{-i}{4}
= \frac{2\pi\cdot (-i^2)}{4} = \frac{2\pi\cdot 1}{4} = \frac{\pi}{2}.$$

### 第五步：证明弧积分消失

在 $C_R$ 上，$z = Re^{i\theta}$，所以 $|z^2| = R^2$ 且 $|z^4+4|\ge R^4 - 4$。因
此
$$|f(z)| \le \frac{R^2}{R^4-4}\sim \frac{1}{R^2}\quad (R\to\infty).$$
弧的长度为 $\pi R$，所以
$$\left|\int_{C_R} f(z)\,dz\right| \le \pi R\cdot\frac{R^2}{R^4-4} \sim \frac{\p
i}{R}\to 0\quad (R\to\infty).$$

### 第六步：取极限 $R\to\infty$

我们有
$$\oint_{\Gamma_R} f(z)\,dz = \int_{-R}^{R} \frac{x^2}{x^4+4}\,dx + \int_{C_R} f
(z)\,dz.$$
令 $R\to\infty$，弧积分消失，实轴积分变为 $I$，围道积分变为 $\pi/2$。因此
$$I = \frac{\pi}{2}.$$

### 验证（数值合理性检验）

被积函数为偶函数，所以
$$I = 2\int_0^\infty \frac{x^2}{x^4+4}\,dx.$$
代入 $x = \sqrt{2}\,t$，$dx = \sqrt{2}\,dt$：
$$\int_0^\infty \frac{x^2}{x^4+4}\,dx = \int_0^\infty \frac{2t^2}{4t^4+4}\cdot\s
qrt{2}\,dt = \frac{2\sqrt{2}}{4}\int_0^\infty \frac{t^2}{t^4+1}\,dt = \frac{\sqr
t{2}}{2}\cdot\frac{\pi}{2\sqrt{2}} = \frac{\pi}{4},$$
其中我们使用了标准结果 $\int_0^\infty \frac{t^2}{t^4+1}\,dt = \frac{\pi}{2\sqrt{
2}}$。因此 $I = 2\cdot\frac{\pi}{4} = \frac{\pi}{2}$，证实了我们的计算。

### 结论

$$\boxed{\int_{-\infty}^{\infty} \frac{x^2}{x^4+4}\,dx = \frac{\pi}{2}}.$$
