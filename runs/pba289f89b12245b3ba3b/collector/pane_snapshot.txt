**证明。**

设 $a, b, c > 0$ 且 $abc = 1$。我们将证明
$$\frac{1}{a^3(b+c)} + \frac{1}{b^3(c+a)} + \frac{1}{c^3(a+b)} \ge \frac{3}{2}.$
$

**替换。** 令 $x = 1/a$, $y = 1/b$, $z = 1/c$。则 $x, y, z > 0$ 且
$$xyz = \frac{1}{abc} = 1.$$

将每一项进行转换：
$$\frac{1}{a^3(b+c)} = \frac{1}{(1/x)^3(1/y + 1/z)} = \frac{x^3}{\dfrac{z+y}{yz}
} = \frac{x^3 yz}{y+z}.$$

由于 $xyz = 1$，我们有 $yz = 1/x$，因此
$$\frac{1}{a^3(b+c)} = \frac{x^3 \cdot (1/x)}{y+z} = \frac{x^2}{y+z}.$$

同理可得，
$$\frac{1}{b^3(c+a)} = \frac{y^2}{z+x}, \qquad \frac{1}{c^3(a+b)} = \frac{z^2}{x
+y}.$$

因此，只需证明
$$\frac{x^2}{y+z} + \frac{y^2}{z+x} + \frac{z^2}{x+y} \ge \frac{3}{2}, \qquad xy
z = 1. \tag{$\ast$}$$

**第一步 — Cauchy–Schwarz (Titu 引理)。**
$$\frac{x^2}{y+z} + \frac{y^2}{z+x} + \frac{z^2}{x+y} \ge \frac{(x+y+z)^2}{(y+z)
+(z+x)+(x+y)} = \frac{(x+y+z)^2}{2(x+y+z)} = \frac{x+y+z}{2}.$$

**第二步 — AM-GM。** 由于 $x, y, z > 0$ 且 $xyz = 1$，
$$x + y + z \ge 3\sqrt[3]{xyz} = 3 \cdot 1 = 3.$$

结合这两个步骤：
$$\frac{x^2}{y+z} + \frac{y^2}{z+x} + \frac{z^2}{x+y} \ge \frac{x+y+z}{2} \ge \f
rac{3}{2}.$$

这证明了 $(\ast)$，从而证明了原不等式。

**等号成立条件。** 当且仅当以下条件满足时等号成立：(i) Cauchy–Schwarz 中 $\frac{
x}{y+z} = \frac{y}{z+x} = \frac{z}{x+y}$，以及 (ii) AM-GM 中 $x = y = z$。后者给
出 $x = y = z = 1$ (因为 $xyz = 1$)，即 $a = b = c = 1$，这确实满足 $abc = 1$ 且
使不等式两边相等。$\blacksquare$
