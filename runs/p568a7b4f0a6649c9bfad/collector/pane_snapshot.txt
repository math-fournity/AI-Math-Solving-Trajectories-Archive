**Claim.** The cardinality of the set of all partial orders on $\mathbb{N}$ havi
ng exactly one least element and infinitely many maximal elements is $2^{\aleph_
0}$.

---

### Upper bound: $\leq 2^{\aleph_0}$

A partial order on $\mathbb{N}$ is a subset $R \subseteq \mathbb{N}\times\mathbb
{N}$ satisfying reflexivity, antisymmetry, and transitivity. The set of all bina
ry relations on $\mathbb{N}$ is $\mathcal{P}(\mathbb{N}\times\mathbb{N})$, which
 has cardinality

$$|\mathcal{P}(\mathbb{N}\times\mathbb{N})| = 2^{|\mathbb{N}\times\mathbb{N}|} =
 2^{\aleph_0}.$$

The collection of partial orders satisfying our two conditions is a subset of th
is, so its cardinality is at most $2^{\aleph_0}$.

---

### Lower bound: $\geq 2^{\aleph_0}$

We construct an injection from $\mathcal{P}(\mathbb{N})$ into the set of qualify
ing posets.

**Setup.** Partition $\mathbb{N}$ into three disjoint pieces:
$$\{0\},\quad A = \{a_n : n\geq 1\},\quad B = \{b_n : n\geq 1\},$$
using any fixed bijection of this countable set with $\mathbb{N}$ (e.g., $0\maps
to 0$, $a_n\mapsto 2n-1$, $b_n\mapsto 2n$).

**Construction.** For each subset $S\subseteq\mathbb{N}$ with $S\subseteq\{1,2,3
,\dots\}$, define a partial order $\leq_S$ on $\mathbb{N}$ by:

- $0 \leq_S x$ for every $x\in\mathbb{N}$ (reflexivity handled separately);
- $a_n \leq_S b_n$ if and only if $n\in S$;
- No other nontrivial comparabilities (each element is reflexively $\leq_S$ itse
lf).

**Verification that $\leq_S$ is a partial order.**
- *Reflexivity:* built in.
- *Antisymmetry:* the only nontrivial relations are $0 <_S x$ and $a_n <_S b_n$
(for $n\in S$). These form a strict order of height 2 (a bipartite DAG from $\{0
\}$ to everything, plus edges $a_n\to b_n$), so no cycles exist; antisymmetry ho
lds.
- *Transitivity:* the only chain of length 2 is $0 \leq_S a_n \leq_S b_n$ (when
$n\in S$), and $0\leq_S b_n$ is already present. No other two-step chains exist.
 So transitivity holds.

**One least element.** The element $0$ is below every element, so it is the uniq
ue least element.

**Infinitely many maximal elements.** For every $n\geq 1$, the element $b_n$ has
 nothing strictly above it (the only possible element above $b_n$ would be via s
ome relation $b_n \leq_S y$, but no such nontrivial relation exists). Hence ever
y $b_n$ is maximal. Since $\{b_n : n\geq 1\}$ is infinite, there are infinitely
many maximal elements.

**Injectivity.** If $S\neq S'$, say $n\in S\setminus S'$, then $a_n \leq_S b_n$
but $a_n \not\leq_{S'} b_n$, so $\leq_S \neq \leq_{S'}$. Thus the map $S\mapsto
{\leq_S}$ is injective.

Since $|\mathcal{P}(\{1,2,3,\dots\})| = 2^{\aleph_0}$, we obtain $2^{\aleph_0}$
distinct qualifying partial orders.

---

### Conclusion

The upper and lower bounds together give

$$\boxed{2^{\aleph_0}}.$$
