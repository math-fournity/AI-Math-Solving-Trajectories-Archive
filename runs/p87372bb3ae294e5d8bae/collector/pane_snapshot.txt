## 证明

设 $I = (x^2 + 1) \subseteq \mathbb{Z}[x]$。我将证明 $\mathbb{Z}[x]/I \cong \mat
hbb{Z}[i]$。

**定义求值同态。** 定义环同态
$$\varphi: \mathbb{Z}[x] \to \mathbb{Z}[i], \qquad \varphi(f) = f(i).$$
这是有明确定义的，因为 $\mathbb{Z}[i]$ 是一个交换环，且 $\mathbb{Z} \subseteq \m
athbb{Z}[i]$，因此将 $x$ 代入 $i$ 的标准求值映射是一个环同态。

**$\varphi$ 是满射。** $\mathbb{Z}[i] = \{a + bi : a, b \in \mathbb{Z}\}$ 中的每
个元素都可以写成 $a + bx$ 在 $\varphi$ 下的像，因为 $\varphi(a + bx) = a + bi$。
因此 $\varphi$ 是满射。

**计算核。** 我证明 $\ker\varphi = (x^2 + 1)$。

包含关系 $(x^2+1) \subseteq \ker\varphi$：对于任意 $g \in \mathbb{Z}[x]$，有 $\v
arphi((x^2+1)g) = (i^2+1)g(i) = 0 \cdot g(i) = 0$。

反向包含关系 $\ker\varphi \subseteq (x^2+1)$：设 $f \in \ker\varphi$，即 $f(i) =
 0$。由于 $x^2 + 1$ 是 $\mathbb{Z}[x]$ 中的**首一**多项式，带余除法在 $\mathbb{Z
}[x]$ 中适用：存在唯一的 $q, r \in \mathbb{Z}[x]$，满足
$$f = (x^2 + 1)\,q + r, \qquad \deg r < 2.$$
因此 $r = ax + b$，其中 $a, b \in \mathbb{Z}$。在 $x = i$ 处求值得
$$0 = f(i) = (i^2 + 1)\,q(i) + r(i) = 0 + (ai + b) = ai + b.$$
由于 $1$ 和 $i$ 在 $\mathbb{R}$ 上线性无关（且 $a, b \in \mathbb{Z} \subseteq \m
athbb{R}$），我们得到 $a = 0$ 且 $b = 0$。因此 $r = 0$，从而 $f = (x^2+1)\,q \in
 (x^2+1)$。

所以 $\ker\varphi = (x^2 + 1) = I$。

**结论。** 根据环同态基本定理，
$$\mathbb{Z}[x]/I = \mathbb{Z}[x]/(x^2+1) = \mathbb{Z}[x]/\ker\varphi \;\cong\;
\operatorname{im}\varphi = \mathbb{Z}[i].$$

因此，所求的理想是 $I = (x^2 + 1)$。
