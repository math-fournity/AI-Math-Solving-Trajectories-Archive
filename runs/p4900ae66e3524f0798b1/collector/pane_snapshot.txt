Actually, in the standard setup (e.g., Richardson-Springer), the map is indeed
from K-orbits to W, and it's defined as follows: each K-orbit on G/B has a
unique open B-orbit (in some sense), or the map is defined via the closure
relations.

Actually, I recall now. The map φ is defined using the fact that each K-orbit is
a union of B-orbits, and the map sends the K-orbit to the B-orbit of maximal
dimension contained in it (or something like that). Or perhaps it's defined via
the Bruhat decomposition more carefully.

Let me look at this from the double coset perspective. K\G/B → B\G/B sends KgB ↦
BgB. For this to be well-defined, we need: if g' = kgb for some k ∈ K, b ∈ B,
then Bg'B = BgB. But Bg'B = BkgbB. We need BkgB = BgB for all k ∈ K. This is not
true in general!

So the map φ is not simply the double coset map.
