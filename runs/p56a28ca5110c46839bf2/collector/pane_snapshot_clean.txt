## Proof

**Setup and branch choice.** The integrand $f(z) = \sqrt{(z-a)(z-b)}$ has branch
 points at $z=a$ and $z=b$. Following the hint, we write

$$\sqrt{(z-a)(z-b)} = e^{\frac12\ln(z-a)}\cdot e^{\frac12\ln(z-b)} = |z-a|^{1/2}
\,|z-b|^{1/2}\; e^{\,i\,\arg(z-a)/2}\; e^{\,i\,\arg(z-b)/2}.$$

We choose the branch with the cut along the segment $[a,b]$. Concretely, for a p
oint $z\notin[a,b]$, we select $\arg(z-a)$ and $\arg(z-b)$ continuously so that
$f$ is single-valued and analytic on $\mathbb{C}\setminus[a,b]$, with the normal
ization $f(z)\sim z$ as $z\to\infty$ (i.e., $f(z)/z\to 1$). One verifies this no
rmalization is consistent: for $z$ real with $z\gg 1$, both $z-a$ and $z-b$ have
 argument $0$, so $f(z)=|z-a|^{1/2}|z-b|^{1/2}>0\sim z$; for $z$ real with $z\ll
 -1$ (to the left of both $a,b$), both arguments equal $\pi$, giving $e^{i\pi/2}
\cdot e^{i\pi/2}=i\cdot i=-1$, so $f(z)=-|z-a|^{1/2}|z-b|^{1/2}\sim z<0$. ✓

Since $R>\max(|a|,|b|)$ and the disk $\{|z|<R\}$ is convex, the entire segment $
[a,b]$ lies strictly inside $|z|<R$. Hence $f$ is analytic on the contour $|z|=R
$ and throughout the exterior region $\{|z|>R\}\cup\{\infty\}$.

**Laurent expansion at infinity.** Set $w=1/z$. Then

$$(z-a)(z-b)=z^2\bigl(1-(a+b)w+ab\,w^2\bigr),$$

so

$$f(z)=z\sqrt{1-(a+b)w+ab\,w^2}.$$

Using $\sqrt{1+u}=1+\tfrac12 u-\tfrac18 u^2+O(u^3)$ with $u=-(a+b)w+ab\,w^2$:

$$\sqrt{1+u}=1-\frac{a+b}{2}\,w+\Bigl(\frac{ab}{2}-\frac{(a+b)^2}{8}\Bigr)w^2+O(
w^3)=1-\frac{a+b}{2}\,w-\frac{(a-b)^2}{8}\,w^2+O(w^3).$$

Therefore

$$f(z)=z-\frac{a+b}{2}-\frac{(a-b)^2}{8\,z}+O(z^{-2}),\qquad z\to\infty.$$

The coefficient of $z^{-1}$ is $c_{-1}=-\dfrac{(a-b)^2}{8}$.

**Residue at infinity.** By definition,

$$\operatorname{Res}_{z=\infty} f(z)=-\operatorname{Res}_{w=0}\frac{f(1/w)}{w^2}
=-c_{-1}=\frac{(a-b)^2}{8}.$$

**Applying the residue theorem (exterior domain).** Since $f$ is analytic in $\{
|z|>R\}\cup\{\infty\}$ except for the isolated singularity at $\infty$, and the
contour $|z|=R$ is positively (counterclockwise) oriented,

$$\oint_{|z|=R} f(z)\,dz=-2\pi i\;\operatorname{Res}_{z=\infty}f(z)=-2\pi i\cdot
\frac{(a-b)^2}{8}.$$

**Verification (special case $a=1,\,b=-1$).** Then $f(z)=\sqrt{z^2-1}$ with cut
on $[-1,1]$. Shrinking the contour to a dogbone around $[-1,1]$: above the cut (
traversed right-to-left), $\arg(z-1)=\pi$, $\arg(z+1)=0$, so $f\big|_{\text{abov
e}}=i\sqrt{1-x^2}$; below the cut, $\arg(z-1)=-\pi$, giving $f\big|_{\text{below
}}=-i\sqrt{1-x^2}$. Thus

$$\oint = \int_1^{-1}i\sqrt{1-x^2}\,dx+\int_{-1}^{1}(-i)\sqrt{1-x^2}\,dx=-2i\int
_{-1}^{1}\sqrt{1-x^2}\,dx=-2i\cdot\frac{\pi}{2}=-\pi i,$$

which equals $-\dfrac{\pi i\,(1-(-1))^2}{4}=-\pi i$. ✓

)^2}{4}}$$
