Looking at this problem, I need to determine whether the radial projection of a
positive-measure set must have positive measure.

**Answer: Yes.** The set $\{\|x\| : x \in A\}$ has positive Lebesgue measure in
$[0,\infty)$.

**Proof.**

Let $S^{n-1} = \{\theta \in \mathbb{R}^n : \|\theta\| = 1\}$ denote the unit sph
ere with $(n-1)$-dimensional surface measure $\sigma$. The polar coordinate deco
mposition of Lebesgue measure on $\mathbb{R}^n$ states that for any Lebesgue mea
surable set $A \subset \mathbb{R}^n$:

$$m(A) = \int_0^\infty r^{n-1}\, \sigma\!\left(\{\theta \in S^{n-1} : r\theta \i
n A\}\right) dr.$$

Set $R = \{\|x\| : x \in A\} = \{r \geq 0 : \exists\, \theta \in S^{n-1},\; r\th
eta \in A\}$ and define

$$g(r) = r^{n-1}\, \sigma\!\left(\{\theta \in S^{n-1} : r\theta \in A\}\right).$
$

By the polar coordinate formula, $g : [0,\infty) \to [0,\infty]$ is a nonnegativ
e measurable function and

$$m(A) = \int_0^\infty g(r)\, dr. \tag{1}$$

**Key observation.** For any $r \notin R$, the sphere $\{x : \|x\| = r\}$ does n
ot intersect $A$, so $\{\theta \in S^{n-1} : r\theta \in A\} = \emptyset$ and he
nce $g(r) = 0$. Therefore

$$\{r \geq 0 : g(r) > 0\} \;\subseteq\; R. \tag{2}$$

**The measurable subset $E$.** The set $E = \{r \geq 0 : g(r) > 0\}$ is Lebesgue
 measurable (it is the positivity set of a measurable function). By (1) and the
fact that $g = 0$ on $[0,\infty) \setminus E$:

$$m(A) = \int_E g(r)\, dr.$$

Since $m(A) > 0$ and $g > 0$ on $E$, the integral $\int_E g(r)\,dr$ is positive,
 which forces $m(E) > 0$.

**Conclusion.** By (2), $R \supseteq E$ where $E$ is a Lebesgue measurable set w
ith $m(E) > 0$. Therefore $R$ has positive outer Lebesgue measure, and in partic
ular contains a Lebesgue measurable subset of positive measure.

To see that $R$ is itself Lebesgue measurable: write $A = B \cup N$ with $B$ Bor
el and $m(N) = 0$. Then $R = \|B\| \cup \|N\|$. The set $\|B\|$ is the image of
a Borel set under the continuous (hence Borel) map $\|\cdot\|$, so it is analyti
c and therefore Lebesgue measurable. For the null set $N$, embed it in a Borel s
et $B' \supseteq N$ with $m(B') = 0$; then $\|N\| \subseteq \|B'\|$, which is ag

, we have $m(B') = \int_0^\infty r^{n-1}\sigma(\{\theta : r\theta \in B'\})\,dr

'}(r) > 0\}$ only on a null set and is thus measurable. Hence $R = \|B\| \cup \|
N\|$ is a subset of the measurable set $\|B\| \cup \|B'\|$, and contains the mea
surable set $\|B\|$; since $R \supseteq E$ with $m(E) > 0$, we conclude $R$ has
positive Lebesgue measure. $\blacksquare$
