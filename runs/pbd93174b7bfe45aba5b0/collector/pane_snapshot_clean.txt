# Zero-Set of a Hermitian Symmetric Quadratic Polynomial

## Setup and Reduction to Real Coordinates

Write $z = x + iy$ with $x, y \in \mathbb{R}$, and decompose $\alpha = a_1 + i a
_2$, $\beta = b_1 + i b_2$ ($a_1, a_2, b_1, b_2 \in \mathbb{R}$). Since $\Phi$ i
s Hermitian symmetric, $\Phi(z,\bar z) \in \mathbb{R}$ for all $z$, and we expan
d each term:

**Quadratic part.** $\alpha z^2 + \bar\alpha \bar z^2 = 2\operatorname{Re}(\alph
a z^2)$. With $z^2 = (x^2 - y^2) + 2ixy$:
$$2\operatorname{Re}(\alpha z^2) = 2a_1(x^2 - y^2) - 4a_2\, xy.$$

**Linear part.** $\beta z + \bar\beta \bar z = 2\operatorname{Re}(\beta z) = 2(b
_1 x - b_2 y)$.

**Mixed term.** $\gamma z\bar z = \gamma(x^2 + y^2)$.

Assembling, $\Phi = 0$ becomes the real conic
$$\underbrace{(2a_1 + \gamma)}_{A}\,x^2 \;+\; \underbrace{(-4a_2)}_{B}\,xy \;+\;
 \underbrace{(-2a_1 + \gamma)}_{C}\,y^2 \;+\; \underbrace{2b_1}_{D}\,x \;+\; \un
derbrace{(-2b_2)}_{E}\,y \;+\; F \;=\; 0. \tag{$*$}$$

## The Parametrization is Surjective onto All Real Conics

Given **any** real conic $Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$, set
$$a_1 = \tfrac{A-C}{4},\quad a_2 = -\tfrac{B}{4},\quad \gamma = \tfrac{A+C}{2},\
quad b_1 = \tfrac{D}{2},\quad b_2 = -\tfrac{E}{2},$$
i.e. $\alpha = \frac{A-C}{4} - i\frac{B}{4}$, $\beta = \frac{D}{2} - i\frac{E}{2
}$. One checks directly that this reproduces $(*)$. Hence **every real conic ari
ses** as the zero-set of some Hermitian symmetric quadratic polynomial — the Her
mitian symmetry imposes no geometric restriction beyond reality of the coefficie
nts.

## Conic Type via the Discriminant

The conic type is governed by $\Delta := B^2 - 4AC$:
$$\Delta = 16a_2^2 - 4(2a_1+\gamma)(-2a_1+\gamma) = 16(a_1^2+a_2^2) - 4\gamma^2
= 4\bigl(4|\alpha|^2 - \gamma^2\bigr).$$

- **$\Delta > 0$**, i.e. $4|\alpha|^2 > \gamma^2$: **hyperbola** type.
- **$\Delta = 0$**, i.e. $4|\alpha|^2 = \gamma^2$: **parabola** type.
- **$\Delta < 0$**, i.e. $4|\alpha|^2 < \gamma^2$: **ellipse** type (circle when
 $\alpha = 0$).

Each type has non-degenerate and degenerate realizations, determined by the rank
 of the associated $3\times 3$ conic matrix
$$Q = \begin{pmatrix} A & B/2 & D/2 \\ B/2 & C & E/2 \\ D/2 & E/2 & F \end{pmatr
ix}.$$

## All Geometric Objects Are Realized

We exhibit explicit parameter choices for every possible zero-set:

| Object | Parameters | Resulting equation |
|---|---|---|
| **Empty set** | $\alpha=0,\ \beta=0,\ \gamma=1,\ F=1$ | $x^2+y^2+1=0$ |
| **Single point** | $\alpha=0,\ \beta=0,\ \gamma=1,\ F=0$ | $x^2+y^2=0\Rightarr
ow z=0$ |
| **A line** | $\alpha=0,\ \gamma=0,\ \beta=1,\ F=0$ | $2x=0$ |
| **Two intersecting lines** | $\alpha=1,\ \gamma=0,\ \beta=0,\ F=0$ | $2(x^2-y^
2)=0\Rightarrow x=\pm y$ |
| **Ellipse (circle)** | $\alpha=0,\ \beta=0,\ \gamma=1,\ F=-1$ | $x^2+y^2=1$ |
| **Hyperbola** | $\alpha=1,\ \gamma=0,\ \beta=0,\ F=-1$ | $2(x^2-y^2)=1$ |
| **Parabola** | $\alpha=1,\ \gamma=2,\ \beta=i,\ F=0$ | $4x^2-2y=0\Rightarrow y
=2x^2$ |

(Non-circular ellipses and non-degenerate cases of each type follow by perturbin
g these examples, e.g. $\alpha = \tfrac{1}{2}, \gamma = 2, \beta = 0, F = -1$ gi
ves $3x^2 + y^2 = 1$.)

## Conclusion

The zero-set of
$$\Phi(z,\bar z) = \alpha z^2 + \bar\alpha\,\bar z^2 + \beta z + \bar\beta\,\bar
 z + \gamma\, z\bar z + F = 0$$
is, after the substitution $z = x+iy$, a **general real conic** $Ax^2+Bxy+Cy^2+D
x+Ey+F=0$ with no restriction beyond reality of coefficients. The conic type is
classified by $\Delta = 4(4|\alpha|^2 - \gamma^2)$:

- **$4|\alpha|^2 > \gamma^2$**: a **hyperbola**, or degenerately, two real inter
secting lines.
- **$4|\alpha|^2 = \gamma^2$**: a **parabola**, or degenerately, two parallel/co
incident lines or the empty set.
- **$4|\alpha|^2 < \gamma^2$**: an **ellipse** (a circle when $\alpha = 0$), or
degenerately, a single point or the empty set.
- **$\alpha = 0,\ \gamma = 0$**: the conic reduces to a **line** (or is empty/id
entically the whole plane in trivial cases).

Thus the possible geometric objects are precisely the **conic sections and their
 degenerations**: the empty set, a single point, a line, a pair of lines (inters
ecting or parallel), an ellipse (including a circle), a hyperbola, and a parabol
a.
