## Setup

Let $N$ have digits at positions $0, 1, \ldots, n-1$ (position $k$ has place val
ue $10^k$). Swapping positions $k_1 < k_2$ (digits $a, b$) changes $N$ by $(b-a)
(10^{k_1} - 10^{k_2})$. Since $N \equiv 0 \pmod{2020}$, the swap preserves divis
ibility iff $(b-a)(10^{k_1}-10^{k_2}) \equiv 0 \pmod{2020}$.

**Factorization:** $2020 = 4 \times 5 \times 101$.

**Key fact:** $10^2 \equiv -1 \pmod{101}$, so $10^4 \equiv 1 \pmod{101}$. The or
der of 10 mod 101 is 4, so $10^{k_1} \equiv 10^{k_2} \pmod{101}$ iff $k_1 \equiv
 k_2 \pmod{4}$.

Since $|b-a| \leq 9 < 101$, the mod-101 condition requires $k_1 \equiv k_2 \pmod
{4}$.

## Critical Observation

When **both** $k_1, k_2 \geq 2$: $10^{k_1} \equiv 10^{k_2} \equiv 0 \pmod{4}$ an

 Combined with the mod-101 condition ($k_1 \equiv k_2 \pmod 4$), the swap **alwa

**Therefore:** for fragility, each residue class mod 4 can contain **at most one

## Upper Bound: $n \leq 6$

Positions $\geq 2$ are $\{2, 3, \ldots, n-1\}$, giving $n-2$ positions across 4
residue classes. By pigeonhole, if $n - 2 > 4$, i.e., $n \geq 7$, some class has
 $\geq 2$ positions $\geq 2$, making fragility impossible. So $n \leq 6$.

For $n = 6$: positions $\{2,3,4,5\}$ occupy exactly one per class — the maximum
is achievable.

- $n \leq 5$: impossible (no multiples of 2020 with all distinct digits)
