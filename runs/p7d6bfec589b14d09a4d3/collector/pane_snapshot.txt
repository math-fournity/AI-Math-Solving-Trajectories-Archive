## Proof

We are given the characteristic function
$$\phi(z) = E[e^{izW_1}] = \bigl(\cos\sqrt{2iz}\bigr)^{-1/2}, \qquad W_1=\int_0^
1 W^2(t)\,dt.$$

Moments are recovered from derivatives at the origin:
$$E[W_1] = \frac{\phi'(0)}{i}, \qquad E[W_1^2] = \frac{\phi''(0)}{i^2} = -\phi''
(0),$$
so
$$\operatorname{Var}(W_1) = E[W_1^2] - (E[W_1])^2 = -\phi''(0) + (\phi'(0))^2.$$

**Series expansion of $\phi$ near $z=0$.** Put $u=\sqrt{2iz}$, so $u^2=2iz$, $u^
4=-4z^2$, $u^6=-8iz^3$. Then
$$\cos u = 1 - \frac{u^2}{2} + \frac{u^4}{24} - \frac{u^6}{720} + \cdots = 1 - i
z - \frac{z^2}{6} + \frac{iz^3}{90} + \cdots.$$

Write $\cos u = 1+w$ with $w = -iz - \tfrac{z^2}{6} + O(z^3)$. Using $(1+w)^{-1/
2}=1-\tfrac{w}{2}+\tfrac{3w^2}{8}+\cdots$ and
$$w^2 = (-iz)^2 + 2(-iz)\!\left(-\tfrac{z^2}{6}\right)+\cdots = -z^2 + O(z^3),$$
we get
$$\phi(z) = 1 - \tfrac{1}{2}\!\left(-iz - \tfrac{z^2}{6}\right) + \tfrac{3}{8}(-
z^2) + O(z^3) = 1 + \frac{iz}{2} + \left(\frac{1}{12}-\frac{3}{8}\right)z^2 + O(
z^3).$$

Since $\frac{1}{12}-\frac{3}{8} = \frac{2-9}{24} = -\frac{7}{24}$,
$$\phi(z) = 1 + \frac{i}{2}\,z - \frac{7}{24}\,z^2 + O(z^3).$$

**Extracting the moments.**
$$\phi'(0) = \frac{i}{2}, \qquad \phi''(0) = -\frac{7}{12}.$$

Hence
$$E[W_1] = \frac{\phi'(0)}{i} = \frac{i/2}{i} = \frac{1}{2}, \qquad E[W_1^2] = -
\phi''(0) = \frac{7}{12}.$$

Therefore
$$\operatorname{Var}(W_1) = E[W_1^2] - (E[W_1])^2 = \frac{7}{12} - \left(\frac{1
}{2}\right)^2 = \frac{7}{12} - \frac{3}{12} = \frac{4}{12} = \boxed{\frac{1}{3}}
.$$

**Verification (independent of the characteristic function).** Since $W(t)\sim N
(0,t)$, $E[W^2(t)]=t$, giving $E[W_1]=\int_0^1 t\,dt=\tfrac12$, agreeing with ab
ove. For the second moment, $(W(s),W(t))$ is jointly Gaussian with $E[W(s)W(t)]=
\min(s,t)$, so by Isserlis' theorem
$$E[W^2(s)W^2(t)] = st + 2\min(s,t)^2.$$
Thus
$$E[W_1^2] = \int_0^1\!\!\int_0^1 st\,ds\,dt + 2\int_0^1\!\!\int_0^1 \min(s,t)^2
\,ds\,dt.$$
The first term is $(\tfrac12)^2=\tfrac14$. By symmetry the second is
$$2\cdot 2\int_0^1\!\int_0^t s^2\,ds\,dt = 4\int_0^1 \frac{t^3}{3}\,dt = \frac{4
}{12}=\frac{1}{3},$$
so $E[W_1^2]=\tfrac14+\tfrac13=\tfrac{7}{12}$, and $\operatorname{Var}(W_1)=\tfr
ac{7}{12}-\tfrac14=\tfrac13$. This confirms the result obtained from the charact
