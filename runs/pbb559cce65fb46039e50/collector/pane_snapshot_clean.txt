**Setup.** Let $a = x^2,\; b = y^2,\; c = z^2$. Then $a,b,c \ge 0$ and $a+b+c=1$
. We maximize
$$F = (a-b)(b-c)(c-a).$$
Since $F$ is antisymmetric under any permutation of $(a,b,c)$, the maximum of $F
$ equals the maximum of $|F|$. We compute $M = \max |F|$.

**Centering.** Write $a = \tfrac13+u,\; b = \tfrac13+v,\; c = \tfrac13+w$ with $
u+v+w=0$. Then $a-b=u-v$, etc., so
$$F = (u-v)(v-w)(w-u).$$

**Trigonometric parametrization.** Every triple $(u,v,w)$ with $u+v+w=0$ can be
written
$$u = r\cos\theta,\quad v = r\cos\!\bigl(\theta-\tfrac{2\pi}{3}\bigr),\quad w =
r\cos\!\bigl(\theta+\tfrac{2\pi}{3}\bigr).$$
Using $\cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$:

$$u-v = -\sqrt{3}\,r\sin\!\bigl(\theta-\tfrac{\pi}{3}\bigr),\quad v-w = \sqrt{3}
\,r\sin\theta,\quad w-u = -\sqrt{3}\,r\sin\!\bigl(\theta+\tfrac{\pi}{3}\bigr).$$

Therefore
$$F = 3\sqrt{3}\,r^3\,\sin\!\bigl(\theta-\tfrac{\pi}{3}\bigr)\sin\theta\,\sin\!\
bigl(\theta+\tfrac{\pi}{3}\bigr).$$

Using $\sin(\theta-\frac{\pi}{3})\sin(\theta+\frac{\pi}{3}) = \sin^2\theta - \fr
ac{3}{4}$ and $\sin^3\theta = \frac{3\sin\theta-\sin 3\theta}{4}$:

$$\sin\!\bigl(\theta-\tfrac{\pi}{3}\bigr)\sin\theta\,\sin\!\bigl(\theta+\tfrac{\
pi}{3}\bigr) = -\tfrac14\sin 3\theta.$$

Hence
$$|F| = \frac{3\sqrt{3}}{4}\,r^3\,|\sin 3\theta|.$$

**Feasibility constraint.** We need $a,b,c\ge 0$, i.e. $\min(u,v,w)\ge -\frac13$
. For $\theta\in[0,\frac{\pi}{3}]$ (one period of the symmetric pattern), the mi
nimum is $w = r\cos(\theta+\frac{2\pi}{3})$, which lies in $[-r,-\frac{r}{2}]$.
The binding constraint is
$$r\le \frac{1}{3\,|\cos(\theta+\frac{2\pi}{3})|}.$$

To maximize $|F|$ we take $r$ at its upper bound, giving
$$|F| = \frac{\sqrt{3}}{36}\cdot\frac{|\sin 3\theta|}{|\cos(\theta+\frac{2\pi}{3
})|^3}.$$

**One-variable optimization.** Set $\phi = \theta+\frac{2\pi}{3}\in[\frac{2\pi}{
3},\pi]$ and $t = -\cos\phi\in[\frac12,1]$. Then $|\sin 3\theta| = |\sin 3\phi|
= \sqrt{1-t^2}\,|4t^2-1| = \sqrt{1-t^2}\,(4t^2-1)$ (since $t\ge\frac12$). So we
maximize
$$g(t) = \frac{\sqrt{1-t^2}\,(4t^2-1)}{t^3},\qquad t\in\bigl[\tfrac12,1\bigr].$$

Taking $\ln g$ and differentiating:
$$\frac{d}{dt}\ln g = \frac{-t}{1-t^2}+\frac{8t}{4t^2-1}-\frac{3}{t}=0.$$

Clearing denominators $t(1-t^2)(4t^2-1)$ and expanding:
$$(-4t^4+t^2)+(8t^2-8t^4)-(15t^2-12t^4-3)=0,$$
$$(-4-8+12)t^4+(1+8-15)t^2+3=0 \;\Longrightarrow\; -6t^2+3=0 \;\Longrightarrow\;
 t=\frac{1}{\sqrt 2}.$$

This lies in $[\frac12,1]$. At the endpoints $g=0$, so this is the global max. E
valuating:
$$g\!\Bigl(\frac{1}{\sqrt2}\Bigr)=\frac{\frac{1}{\sqrt2}\cdot(4\cdot\frac12-1)}{
\frac{1}{2\sqrt2}}=\frac{\frac{1}{\sqrt2}\cdot 1}{\frac{1}{2\sqrt2}}=2.$$

**Computing $M$.**
$$M = \frac{\sqrt{3}}{36}\cdot 2 = \frac{\sqrt{3}}{18}.$$

**Verification at the optimum.** At $t=\frac{1}{\sqrt2}$: $\phi=\frac{3\pi}{4}$,
 $\theta=\frac{\pi}{12}$, $r=\frac{\sqrt2}{3}$. This gives
$$a=\frac{3+\sqrt3}{6},\quad b=\frac{3-\sqrt3}{6},\quad c=0.$$
Check: $a+b+c=1$, all $\ge 0$. Then
$$(a-b)(b-c)(c-a)=\frac{\sqrt3}{3}\cdot\frac{3-\sqrt3}{6}\cdot\Bigl(-\frac{3+\sq
rt3}{6}\Bigr)=\frac{\sqrt3}{3}\cdot\Bigl(-\frac{6}{36}\Bigr)=-\frac{\sqrt3}{18},
$$
confirming $|F|=\frac{\sqrt3}{18}=M$. (Permuting variables yields the positive v
alue.)

**Final answer.**
$$M^2 = \frac{3}{324}=\frac{1}{108},\qquad \boxed{\frac{1}{M^2}=108}.$$
