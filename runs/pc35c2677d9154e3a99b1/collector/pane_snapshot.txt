## Proof

^2, d = s^2$ with $p,q,r,s \geq 0$ and $p^2+q^2+r^2+s^2 = 1$.

Each term becomes $(x+y)\sqrt{xy} = (u^2+v^2)\,uv = u^3v + uv^3$, so:

$$f = p^3q + pq^3 + q^3r + qr^3 + r^3s + rs^3 + s^3p + sp^3.$$

**Step 2: Regrouping.** Group terms by the "opposite" pairs in the cycle $p \to
q \to r \to s \to p$:

$$f = p^3(q+s) + q^3(p+r) + r^3(q+s) + s^3(p+r) = (p^3+r^3)(q+s) + (q^3+s^3)(p+r
).$$

Set $A = p+r$, $B = q+s$, $P = pr$, $Q = qs$. Using the identity $p^3+r^3 = (p+r
)(p^2 - pr + r^2) = A(A^2 - 3P)$ (and similarly $q^3+s^3 = B(B^2-3Q)$):

$$f = A(A^2-3P)\cdot B + B(B^2-3Q)\cdot A = AB\bigl(A^2+B^2 - 3(P+Q)\bigr).$$

**Step 3: Eliminating $P+Q$.** Since $A^2 + B^2 = (p+r)^2+(q+s)^2 = (p^2+q^2+r^2
+s^2) + 2(pr+qs) = 1 + 2(P+Q)$, we get $P+Q = \frac{A^2+B^2-1}{2}$. Substituting
:

$$f = AB\!\left(A^2+B^2 - \frac{3(A^2+B^2-1)}{2}\right) = \frac{AB\bigl(3 - A^2
- B^2\bigr)}{2}.$$

**Step 4: Bounding $A^2+B^2$.** Since $P,Q \geq 0$: $A^2+B^2 = 1+2(P+Q) \geq 1$.
 By Cauchy–Schwarz, $(p+r)^2 \leq 2(p^2+r^2)$ and $(q+s)^2 \leq 2(q^2+s^2)$, so
$A^2+B^2 \leq 2(p^2+q^2+r^2+s^2) = 2$. Thus $w := A^2+B^2 \in [1,2]$, and $3 - w
 \in [1,2] > 0$.

**Step 5: Applying AM–GM.** With $u = A^2, v = B^2, w = u+v$:

$$f = \frac{\sqrt{uv}\,(3-w)}{2} \leq \frac{\frac{w}{2}\,(3-w)}{2} = \frac{w(3-w
)}{4},$$

where we used $\sqrt{uv} \leq \frac{u+v}{2} = \frac{w}{2}$ (AM–GM), valid since
$3-w > 0$.

**Step 6: Maximizing the quadratic.** The function $g(w) = \frac{w(3-w)}{4} = \f
rac{-(w-\frac{3}{2})^2 + \frac{9}{4}}{4}$ achieves its maximum $\frac{9}{16}$ at
 $w = \frac{3}{2} \in [1,2]$.

Therefore $f \leq \frac{9}{16}$.

**Step 7: Equality is achieved.** Equality requires:
- $u = v$ (AM–GM): $A^2 = B^2 = \frac{3}{4}$, so $A = B = \frac{\sqrt{3}}{2}$.
- $w = \frac{3}{2}$: satisfied.
- $P + Q = \frac{1}{4}$: take $P = Q = \frac{1}{8}$, i.e., $pr = qs = \frac{1}{8

With $p+r = \frac{\sqrt{3}}{2}$ and $pr = \frac{1}{8}$, the values $p, r$ are ro
ots of $t^2 - \frac{\sqrt{3}}{2}t + \frac{1}{8} = 0$, giving $p = \frac{\sqrt{3}
+1}{4},\; r = \frac{\sqrt{3}-1}{4}$ (both positive). Similarly $q = \frac{\sqrt{
3}+1}{4},\; s = \frac{\sqrt{3}-1}{4}$.

This yields:
$$a = b = \frac{(\sqrt{3}+1)^2}{16} = \frac{2+\sqrt{3}}{8}, \qquad c = d = \frac
{(\sqrt{3}-1)^2}{16} = \frac{2-\sqrt{3}}{8}.$$

**Verification:** $a+b+c+d = 2\cdot\frac{2+\sqrt{3}}{8} + 2\cdot\frac{2-\sqrt{3}

$$f = 2a^2 + 2c^2 + \sqrt{ac} = 2\cdot\frac{7}{32} + \frac{1}{8} = \frac{7}{16}
