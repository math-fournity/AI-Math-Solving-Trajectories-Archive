## Proof

**Setup.** For each integer $m \geq 2$, write $m = L(m) \cdot k$ where $k = m/L(
m)$ is the cofactor (the part of $m$ remaining after removing its largest prime
factor). Note that $k$ is a positive integer and all prime factors of $k$ are $\
leq L(m)$. The ratio $L(m)/m = 1/k$, so studying the distribution of $L(m)/m$ is
 equivalent to studying the distribution of the cofactor $k = m/L(m)$.

**Key counting lemma.** Fix a positive integer $K$. I count the integers $m$ wit
h $2 \leq m \leq n$ and $m/L(m) \leq K$.

An integer $m$ with $m/L(m) = k$ (for $1 \leq k \leq K$) has the form $m = p \cd
ot k$ where $p = L(m)$ is a prime satisfying $p > P(k)$ (the largest prime facto
r of $k$, with the convention $P(1) = 1$) and $pk \leq n$. For each fixed $k$, t
he admissible primes are those in the interval $(P(k),\, n/k]$, giving a count o
f $\pi(n/k) - \pi(P(k))$, where $\pi$ is the prime-counting function (with $\pi(
x) = 0$ for $x < 2$).

Therefore:
$$A(n, K) := \#\{m \leq n : m/L(m) \leq K\} = \sum_{k=1}^{K}\bigl[\pi(n/k) - \pi
(P(k))\bigr].$$

**Asymptotic estimate.** By the Prime Number Theorem, $\pi(x) \sim x/\ln x$. For
 fixed $k$ and $n \to \infty$:
$$\pi(n/k) \sim \frac{n/k}{\ln(n/k)} \sim \frac{n}{k \ln n},$$
while $\pi(P(k))$ is a fixed constant (depending on $k$ but not on $n$). Summing
 over $k = 1, \ldots, K$:
$$A(n, K) \sim \frac{n}{\ln n}\sum_{k=1}^{K}\frac{1}{k} = \frac{n\, H_K}{\ln n},
$$
where $H_K = \sum_{k=1}^{K} 1/k$ is the $K$-th harmonic number.

Since the total number of integers $m$ with $2 \leq m \leq n$ is $n - 1 \sim n$,
 the fraction satisfying $m/L(m) \leq K$ is:
$$\frac{A(n,K)}{n-1} \sim \frac{H_K}{\ln n} \xrightarrow{n\to\infty} 0 \quad \te
xt{for each fixed } K.$$

**Bounding the median.** Let $\varepsilon > 0$ be arbitrary and set $K = \lfloor
 1/\varepsilon \rfloor$. If $L(m)/m \geq \varepsilon$, then $m/L(m) \leq 1/\vare
psilon$, and since $m/L(m)$ is a positive integer, $m/L(m) \leq K$. Hence:
$$\#\{m \leq n : L(m)/m \geq \varepsilon\} \leq A(n, K) = o(n).$$

Equivalently:
$$\#\{m \leq n : L(m)/m < \varepsilon\} \geq (n-1) - o(n) = n - o(n).$$

$$M(n) < \varepsilon \quad \text{for all sufficiently large } n.$$
