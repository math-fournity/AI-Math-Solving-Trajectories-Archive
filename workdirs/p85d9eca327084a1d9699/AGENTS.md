# Problem

In the city of Digitopolis, a specialized robot named "Unit-10" moves through a grid of control stations, each identified by a unique two-digit identification code (from 10 to 99). The robot begins its mission at station **10**. 

The robot’s movement is governed by strict protocols. It must move from one station to a new station (one it has never visited before in the current sequence) by performing exactly one of the following mechanical adjustments to the current station's two-digit ID:
1. Increase one digit of the code by exactly 1 and keep the other digit the same.
2. Increase one digit of the code by exactly 1 and decrease the other digit by exactly 1.

The robot’s mission is complete as soon as it reaches any station where the sum of the two digits in the station's ID code equals **7**. 

How many unique sequences of station IDs are possible for the robot's mission, starting at 10 and ending at a station with a digit sum of 7, such that no ID is repeated within a sequence?
