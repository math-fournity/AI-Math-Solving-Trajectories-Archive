# 黎曼 Zeta 函数零点归一化间距的下确界

## 问题表述

设 $0 < \gamma_1 \leq \gamma_2 \leq \cdots$ 为黎曼 zeta 函数非平凡零点的纵坐标（
按递增顺序排列）。Riemann–von Mangoldt 公式给出：

$$N(T) := \#\{n : 0 < \gamma_n \leq T\} = \frac{T}{2\pi}\log\frac{T}{2\pi} - \fr
ac{T}{2\pi} + O(\log T).$$

在高度 $T$ 附近的平均间距为 $\frac{2\pi}{\log(T/2\pi)}$。定义**归一化间距**：

$$\delta_n = \frac{(\gamma_{n+1} - \gamma_n)\,\log(\gamma_n/2\pi)}{2\pi}.$$

我们将证明 $\inf_n \delta_n = 0$。

## 证明

### 第一步：Montgomery 对关联定理

**定理 (Montgomery, 1973)**。*在假设黎曼假设 (RH) 的条件下，对于 $0 < \alpha < \
beta < 1$：*

$$\lim_{T\to\infty} \frac{1}{N(T)} \#\left\{(\gamma_j, \gamma_k) : 0 < \gamma_j,
 \gamma_k \leq T,\ \gamma_j \neq \gamma_k,\ \alpha < \frac{(\gamma_k - \gamma_j)
\log T}{2\pi} < \beta\right\} = \int_\alpha^\beta \left(1 - \left(\frac{\sin\pi
u}{\pi u}\right)^2\right) du.$$

这是 Montgomery 在其 1973 年论文中证明的结果（在范围 $0 < \alpha < \beta < 1$ 内
，对关联函数精确匹配 GUE 预测，无修正项）。

### 第二步：对关联在原点附近为正

对于小的 $u > 0$，利用 Taylor 展开：

$$\frac{\sin\pi u}{\pi u} = 1 - \frac{\pi^2 u^2}{6} + O(u^4),$$

因此：

$$\left(\frac{\sin\pi u}{\pi u}\right)^2 = 1 - \frac{\pi^2 u^2}{3} + O(u^4),$$

$$1 - \left(\frac{\sin\pi u}{\pi u}\right)^2 = \frac{\pi^2 u^2}{3} + O(u^4).$$

于是对于任意 $0 < \epsilon < 1$：

$$\int_0^\epsilon \left(1 - \left(\frac{\sin\pi u}{\pi u}\right)^2\right) du = \
frac{\pi^2 \epsilon^3}{9} + O(\epsilon^5) > 0.$$

### 第三步：存在归一化间距小于 $\epsilon$ 的零点对

固定 $0 < \epsilon < 1$。在 Montgomery 定理中取 $\alpha \to 0^+$、$\beta = \epsi
lon$，对于充分大的 $T$，满足 $0 < \frac{(\gamma_k - \gamma_j)\log T}{2\pi} < \ep
silon$（即 $\gamma_k > \gamma_j$）的零点对 $(\gamma_j, \gamma_k)$ 的数量渐近于：

$$N(T) \cdot \int_0^\epsilon \left(1 - \left(\frac{\sin\pi u}{\pi u}\right)^2\ri
ght) du \sim N(T) \cdot \frac{\pi^2 \epsilon^3}{9} \to \infty \quad (T \to \inft
y).$$

因此，对于充分大的 $T$，至少存在一对零点 $\gamma_j < \gamma_k \leq T$ 使得：

$$0 < \gamma_k - \gamma_j < \frac{2\pi\epsilon}{\log T}.$$

### 第四步：从零点对到相邻间距

在 $\gamma_j$ 与 $\gamma_k$ 之间的相邻零点 $\gamma_j, \gamma_{j+1}, \ldots, \gam
ma_k$ 中，由鸽巢原理，存在某个 $n$（$j \leq n < k$）使得：

$$\gamma_{n+1} - \gamma_n \leq \frac{\gamma_k - \gamma_j}{k - j} \leq \gamma_k -
 \gamma_j < \frac{2\pi\epsilon}{\log T}.$$

由于 $\gamma_n \in [\gamma_j, \gamma_k] \subset (0, T]$，有 $\log(\gamma_n / 2\p
i) \leq \log(T/2\pi) < \log T$（当 $T > 2\pi$ 时）。因此：

$$\delta_n = \frac{(\gamma_{n+1} - \gamma_n)\,\log(\gamma_n/2\pi)}{2\pi} < \frac
{\epsilon \cdot \log(\gamma_n/2\pi)}{\log T} \leq \epsilon \cdot \frac{\log(T/2\
pi)}{\log T} < \epsilon.$$

### 第五步：结论

对于任意 $\epsilon > 0$，存在 $n$ 使得 $\delta_n < \epsilon$。由于零点的纵坐标互
不相同（$\gamma_{n+1} > \gamma_n$，即 $\delta_n > 0$），下确界不被取到。因此：

$$\inf_n \delta_n = \inf_n \frac{(\gamma_{n+1} - \gamma_n)\,\log(\gamma_n/2\pi)}
{2\pi} = 0.$$

**物理直觉**：这一结果与 GUE（Gaussian Unitary Ensemble）随机矩阵理论一致。GUE
的能级排斥是二次的（level repulsion: $p(s) \sim \frac{\pi^2}{3}s^2$，当 $s \to 0
$），即小间距被抑制但概率为正。由于有无穷多个零点，任意小的归一化间距都会出现，
故下确界为 $0$。
