# Problem

In a futuristic data center, a quantum processor executes tasks using a series of 8-bit memory addresses. Each address is represented by a unique integer from 1 to 255. When the processor reads an address, it interprets the number in its standard binary format.

The processor’s efficiency is determined by "power bursts." A power burst occurs whenever the processor encounters a continuous sequence of high-voltage signals (represented by the digit 1) that cannot be extended further in either direction within that specific binary address. For example, the address 107 is processed as $1101011_2$; this specific address triggers exactly 3 power bursts because there are three distinct blocks of 1s separated by 0s.

The system administrator needs to calculate the total workload for a full diagnostic cycle. This workload is defined as the sum of all power bursts generated as the processor sequences through every address from 1 to 255 inclusive. 

What is the total number of power bursts generated during this cycle?
