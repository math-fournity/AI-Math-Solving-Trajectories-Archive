Looking at this problem, I need to find odd primes $p$ for which no infinite seq
uence exists making all the continued-fraction expressions congruent mod $p$.

## Setting Up the Framework

Define $v_n$ as the $n$-th expression:
- $v_1 = 1 + \frac{1}{a_1} = [1; a_1]$
- $v_2 = 1 + \frac{1}{1+\frac{1}{a_2}} = [1; 1, a_2]$
- $v_n = [1; \underbrace{1,1,\ldots,1}_{n}, a_n]$

Using the standard continued fraction recurrence with Fibonacci numbers $F_1=F_2
=1, F_3=2, F_4=3, F_5=5,\ldots$:

$$v_n = \frac{a_n F_{n+1} + F_n}{a_n F_n + F_{n-1}}$$

## Translating the Congruence Condition

We need $v_n \equiv a_0 \pmod{p}$ for all $n \geq 1$, with $p \nmid (a_n F_n + F
_{n-1})$ (denominator condition). Setting $c = a_0 \bmod p$:

$$a_n(F_{n+1} - c\,F_n) \equiv c\,F_{n-1} - F_n \pmod{p} \quad (\star)$$

**Case 1:** $F_{n+1} - c\,F_n \not\equiv 0 \pmod{p}$. Then $a_n$ is uniquely det
ermined mod $p$. Checking the denominator:

$$a_n F_n + F_{n-1} \equiv \frac{(c\,F_{n-1}-F_n)F_n + F_{n-1}(F_{n+1}-c\,F_n)}{
F_{n+1}-c\,F_n} = \frac{F_{n-1}F_{n+1} - F_n^2}{F_{n+1}-c\,F_n} = \frac{(-1)^n}{
F_{n+1}-c\,F_n} \not\equiv 0 \pmod{p}$$

by **Cassini's identity** $F_{n-1}F_{n+1} - F_n^2 = (-1)^n$. Since $p$ is odd, t
he numerator is nonzero, and the denominator is nonzero by assumption. So **Case
 1 always works automatically**.

**Case 2:** $F_{n+1} - c\,F_n \equiv 0 \pmod{p}$. For $(\star)$ to have a soluti
on, we also need $c\,F_{n-1} - F_n \equiv 0$. But if both hold, then $F_{n+1} \e
quiv c\,F_n$ and $F_n \equiv c\,F_{n-1}$, giving $F_{n+1}F_{n-1} \equiv c^2 F_{n
-1}F_n \equiv c \cdot F_n \cdot F_{n-1} \equiv F_{n+1}F_{n-1}$... more directly:
 $F_{n+1}F_{n-1} \equiv (cF_n)(F_n/c) = F_n^2 \pmod{p}$, so $(-1)^n \equiv 0 \pm
od{p}$, **impossible for odd $p$**.

## The Forbidden Set

So $p$ is **adjective** iff there exists $c \in \mathbb{Z}/p\mathbb{Z}$ such tha
t $F_{n+1} - c\,F_n \not\equiv 0 \pmod{p}$ for all $n \geq 1$.

The **forbidden values** are $c = F_{n+1}/F_n \pmod{p}$ (when $F_n \not\equiv 0$
). Define the Möbius map $T(r) = \frac{r+1}{r}$, so $T(r_n) = r_{n+1}$ where $r_
n = F_{n+1}/F_n$.

The orbit of $r_1 = 1$ under $T$ visits $r_1, r_2, \ldots, r_{\alpha-1} = 0$ (wh
ere $\alpha = \alpha(p)$ is the **rank of apparition**, the smallest $k$ with $p
 \mid F_k$), then jumps back to $r_{\alpha+1} = 1$ (since $F_{\alpha+2}/F_{\alph
a+1} \equiv F_{\alpha-1}/F_{\alpha-1} = 1$).

**Distinctness:** $T^i(1) = T^j(1)$ for $0 \leq i < j \leq \alpha-2$ implies $M^
{j-i}$ fixes $1$, where $M = \begin{pmatrix}1&1\\1&0\end{pmatrix}$. This gives $
F_{j-i} \equiv 0 \pmod{p}$, impossible for $1 \leq j-i \leq \alpha-2 < \alpha$.

Therefore the forbidden set $S$ has $|S| = \alpha(p) - 1$ (containing $0$ and $\
alpha-2$ nonzero elements).

## When is $p$ NOT Adjective?

$p$ is **not adjective** iff $S = \mathbb{Z}/p\mathbb{Z}$, i.e., $\alpha(p) - 1
= p$, i.e., $\boxed{\alpha(p) = p+1}$.

By the theory of Fibonacci numbers mod $p$:
- If $p \equiv \pm 1 \pmod{5}$: $\alpha(p) \mid p-1$, so $\alpha(p) \leq p-1 < p
+1$. These primes are **always adjective**.
- If $p \equiv \pm 2 \pmod{5}$: $\alpha(p) \mid p+1$, and $\alpha(p) = p+1$ iff
$p \nmid F_d$ for every proper divisor $d$ of $p+1$.
