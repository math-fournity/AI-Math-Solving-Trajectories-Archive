## Proof

**Key observation:** A primitive root mod n must be coprime to n (if gcd(a,n) >
1, then gcd(a^k, n) > 1 for all k, so a^k can never equal an element coprime to
n). Therefore, the condition "every QNR is a primitive root" implies **every QNR
 is coprime to n**, i.e., every element NOT coprime to n must be a quadratic res
idue (QR).

**Step 1: n must admit primitive roots.** For n ≥ 3, the squaring map x ↦ x² mod
 n is never surjective (x and n−x give the same square, so at most ⌈n/2⌉ < n dis
tinct squares), so QNRs always exist. If n has no primitive roots, the condition
 fails. By the classical theorem, (ℤ/nℤ)* is cyclic only for n = 1, 2, 4, p^k, 2
p^k (p odd prime). Since n ≥ 3, candidates are n = 4, p^k, 2p^k.

**Step 2: Eliminate n = 4.** Squares mod 4 are {0, 1}. Then 2 is a QNR mod 4, bu
t gcd(2, 4) = 2 > 1, so 2 is not a primitive root. ✗

**Step 3: Eliminate n = p^k, k ≥ 2.** Consider a = p. Is p a QR mod p^k? We'd ne
ed b² ≡ p (mod p^k). Then p | b² so p | b, say b = pc. Then p²c² ≡ p (mod p^k),
giving pc² ≡ 1 (mod p^{k−1}). But pc² ≡ 0 (mod p) while 1 ≢ 0 (mod p) — contradi
ction for k ≥ 2. So p is a QNR mod p^k but not coprime to p^k. ✗

**Step 4: Eliminate n = 2p^k, k ≥ 2.** Same argument: p is a QNR mod p^k (hence
mod 2p^k) and not coprime to n. ✗

**Step 5: Eliminate n = 2p (k = 1).** Consider even numbers 2m with gcd(m, p) =
1. Such 2m is a QR mod 2p iff 2m is a QR mod p (the mod-2 condition is automatic
 since 2m ≡ 0 mod 2 and 0 = 0²). The set {2m mod p : m ∈ (ℤ/pℤ)*} = (ℤ/pℤ)*, whi
ch contains both QRs and QNRs mod p. So some even number 2m is a QNR mod 2p, but
 gcd(2m, 2p) ≥ 2 > 1, so it's not a primitive root. ✗

**Step 6: n = p (odd prime).** Here (ℤ/pℤ)* is cyclic of order p−1. Let g be a p
rimitive root. The nonzero QRs are {g^{2j}} and the QNRs are {g^{2j+1}} (the odd
 powers). The primitive roots are {g^k : gcd(k, p−1) = 1}.

The condition requires: every odd k with 1 ≤ k ≤ p−2 satisfies gcd(k, p−1) = 1.

- If p−1 has an odd prime factor q, then q is odd, 1 ≤ q ≤ (p−1)/2 ≤ p−2, and gc
d(q, p−1) ≥ q > 1. ✗
- So p−1 has no odd prime factor, meaning **p−1 = 2^m**, i.e., p = 2^m + 1 is pr
ime.

For 2^m + 1 to be prime, m must itself be a power of 2 (if m = rs with s odd > 1
, then 2^m + 1 = (2^r)^s + 1 is divisible by 2^r + 1). So p = 2^{2^j} + 1 is a *
*Fermat prime**.

Conversely, if p−1 = 2^m, then every odd k has gcd(k, 2^m) = 1, so every QNR is
a primitive root. ✓
