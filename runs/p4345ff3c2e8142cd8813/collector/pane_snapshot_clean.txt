## Proof

We determine the cardinality of the set $\mathcal{T}$ of all total orders on $\m
athbb{N}$.

**Upper bound.** A total order on $\mathbb{N}$ is, in particular, a binary relat
ion on $\mathbb{N}$, i.e., a subset of $\mathbb{N} \times \mathbb{N}$. Since $|\
mathbb{N} \times \mathbb{N}| = \aleph_0$, the collection of all binary relations
 is $\mathcal{P}(\mathbb{N} \times \mathbb{N})$, which has cardinality $2^{\alep
h_0}$. Therefore:

$$|\mathcal{T}| \leq 2^{\aleph_0}.$$

**Lower bound.** We exhibit an injection from the symmetric group $\operatorname
{Sym}(\mathbb{N})$ (the set of all bijections $\sigma: \mathbb{N} \to \mathbb{N}
$) into $\mathcal{T}$.

*Step 1: $|\operatorname{Sym}(\mathbb{N})| = 2^{\aleph_0}$.*

- Upper bound: every permutation is a function $\mathbb{N} \to \mathbb{N}$, so $
\operatorname{Sym}(\mathbb{N}) \subseteq \mathbb{N}^{\mathbb{N}}$, and $|\mathbb
{N}^{\mathbb{N}}| = \aleph_0^{\aleph_0} = 2^{\aleph_0}$ (since $2^{\aleph_0} \le
q \aleph_0^{\aleph_0} \leq (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0}$).
- Lower bound: for each subset $S \subseteq \mathbb{N}$, define the permutation
$\sigma_S$ that swaps $2n$ and $2n+1$ if $n \in S$, and fixes both $2n$ and $2n+
1$ if $n \notin S$. Distinct subsets $S$ yield distinct permutations, giving $2^
{\aleph_0}$ permutations.

Hence $|\operatorname{Sym}(\mathbb{N})| = 2^{\aleph_0}$.

*Step 2: Map each permutation to a distinct total order.*

For a permutation $\sigma \in \operatorname{Sym}(\mathbb{N})$, define the relati
on $\prec_\sigma$ on $\mathbb{N}$ by:

$$a \prec_\sigma b \iff \sigma(a) < \sigma(b),$$

where $<$ is the standard order on $\mathbb{N}$. Since $\sigma$ is a bijection,
$\prec_\sigma$ is a total order on $\mathbb{N}$:
- **Totality**: for $a \neq b$, injectivity gives $\sigma(a) \neq \sigma(b)$, so
 either $\sigma(a) < \sigma(b)$ or $\sigma(b) < \sigma(a)$.
- **Transitivity, antisymmetry, reflexivity**: inherited from the standard order
 $<$.

*Step 3: The map $\sigma \mapsto {\prec_\sigma}$ is injective.*

Suppose $\prec_\sigma = \prec_\tau$. Then for all $a, b \in \mathbb{N}$:

$$\sigma(a) < \sigma(b) \iff \tau(a) < \tau(b).$$

Set $f = \tau \circ \sigma^{-1}: \mathbb{N} \to \mathbb{N}$. Substituting $m = \
sigma(a)$, $n = \sigma(b)$, we get: for all $m, n \in \mathbb{N}$,

$$m < n \iff f(m) < f(n).$$

So $f$ is an order-preserving bijection of $(\mathbb{N}, <)$. We claim $f = \mat
hrm{id}$: since $f$ preserves the order and is a bijection, $f(0)$ must be the l
east element of $\mathbb{N}$, so $f(0) = 0$; inductively, $f(k)$ must be the lea
st element of $\mathbb{N} \setminus \{f(0), \dots, f(k-1)\} = \mathbb{N} \setmin
us \{0, \dots, k-1\}$, so $f(k) = k$. Thus $f = \mathrm{id}$, hence $\tau = \sig
ma$.

Therefore the map $\sigma \mapsto {\prec_\sigma}$ is an injection, giving:

$$|\mathcal{T}| \geq |\operatorname{Sym}(\mathbb{N})| = 2^{\aleph_0}.$$

**Conclusion.** Combining both bounds:

$$|\mathcal{T}| = 2^{\aleph_0}.$$

The set of all total orders on $\mathbb{N}$ has cardinality $2^{\aleph_0}$ (the
cardinality of the continuum).
