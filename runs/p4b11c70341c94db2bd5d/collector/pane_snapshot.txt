## Solution

We compute $75^{75^{75}} \bmod 100$.

### Setup via CRT

Since $100 = 4 \cdot 25$ with $\gcd(4,25)=1$, we compute the residue modulo $4$
and modulo $25$ separately, then recombine.

Note $\gcd(75, 100) = 25 \neq 1$, so Euler's theorem does **not** apply directly
 to modulus $100$. We instead work prime-power-by-prime-power (the standard way
the Carmichael-function machinery handles non-coprime bases), where each prime-p
ower component becomes tractable.

### Residue modulo 4

$75 \equiv 3 \equiv -1 \pmod{4}$, so
$$75^{75^{75}} \equiv (-1)^{75^{75}} \pmod{4}.$$
Since $75^{75}$ is odd, $(-1)^{75^{75}} = -1 \equiv 3 \pmod{4}$.
$$\boxed{75^{75^{75}} \equiv 3 \pmod{4}.}$$

### Residue modulo 25

$75 = 3 \cdot 25 \equiv 0 \pmod{25}$. Since the exponent $75^{75} \geq 2$,
$$75^{75^{75}} \equiv 0 \pmod{25}.$$

*(Carmichael-function remark: $\lambda(25)=\varphi(25)=20$, and indeed $75^{20}\
equiv 0\pmod{25}$ trivially since $25\mid 75$; the coprimality-based statement o
f Euler/Carmichael is consistent with — and here superseded by — the direct divi
sibility.)*
$$\boxed{75^{75^{75}} \equiv 0 \pmod{25}.}$$

### Recombine via CRT

We need $x$ with
$$x \equiv 3 \pmod{4}, \qquad x \equiv 0 \pmod{25}.$$

Write $x = 25k$. Then $25k \equiv 3 \pmod{4}$. Since $25 \equiv 1 \pmod{4}$, thi
s gives $k \equiv 3 \pmod{4}$, so $k = 3$ and
$$x = 25 \cdot 3 = 75.$$

### Verification (direct cycle check)

$75^1 \equiv 75$, $75^2 = 5625 \equiv 25$, $75^3 = 75\cdot 25 = 1875 \equiv 75 \
pmod{100}$. The residues cycle $\{75, 25\}$: **odd** exponents give $75$, **even
** exponents give $25$. Since $75^{75}$ is odd,
$$75^{75^{75}} \equiv 75 \pmod{100}. \checkmark$$

### Answer

$$\boxed{75^{75^{75}} \equiv 75 \pmod{100}.}$$
