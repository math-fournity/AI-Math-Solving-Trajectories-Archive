## Proof

**Define** $a_n = \sum_{k=1}^{n} \frac{1}{\sqrt{k}} - 2\sqrt{n}$.

**Step 1: Compute $a_1$.**

$$a_1 = \frac{1}{\sqrt{1}} - 2\sqrt{1} = 1 - 2 = -1.$$

**Step 2: Show $(a_n)$ is strictly decreasing.**

$$a_{n+1} - a_n = \frac{1}{\sqrt{n+1}} - 2\bigl(\sqrt{n+1} - \sqrt{n}\bigr).$$

Since $\sqrt{n+1} - \sqrt{n} = \frac{1}{\sqrt{n+1}+\sqrt{n}}$, we get:

$$a_{n+1} - a_n = \frac{1}{\sqrt{n+1}} - \frac{2}{\sqrt{n+1}+\sqrt{n}} = \frac{\
sqrt{n+1}+\sqrt{n} - 2\sqrt{n+1}}{\sqrt{n+1}\,(\sqrt{n+1}+\sqrt{n})} = \frac{\sq
rt{n}-\sqrt{n+1}}{\sqrt{n+1}\,(\sqrt{n+1}+\sqrt{n})^2}.$$

Since $\sqrt{n} < \sqrt{n+1}$ for all $n \geq 1$, the numerator is negative and
the denominator is positive, so:

$$a_{n+1} - a_n < 0 \quad \text{for all } n \geq 1.$$

Thus $(a_n)$ is **strictly decreasing**.

**Step 3: Establish a lower bound (so the sequence is well-behaved).**

For the decreasing function $f(x) = x^{-1/2}$, the integral test bound gives:

$$\sum_{k=1}^{n} \frac{1}{\sqrt{k}} \geq \int_1^{n+1} \frac{dx}{\sqrt{x}} = 2\sq
rt{n+1} - 2.$$

Therefore:

$$a_n \geq 2\sqrt{n+1} - 2 - 2\sqrt{n} = 2\bigl(\sqrt{n+1}-\sqrt{n}\bigr) - 2 >
-2.$$

So $(a_n)$ is bounded below and decreasing, hence convergent. But we do not need
 the exact limit.

**Step 4: Key inequality — $a_n^2 \geq 1$ for all $n$.**

Since $(a_n)$ is strictly decreasing and $a_1 = -1$:

$$a_n \leq a_1 = -1 < 0 \quad \text{for all } n \geq 1.$$

Since $a_n \leq -1 < 0$, we have $|a_n| = -a_n \geq 1$, and therefore:

$$a_n^2 \geq 1 \quad \text{for all } n \geq 1.$$

**Step 5: Comparison with the harmonic series.**

$$\frac{a_n^2}{n} \geq \frac{1}{n} \quad \text{for all } n \geq 1.$$

Summing:

$$\sum_{n=1}^{\infty} \frac{1}{n}\left(\sum_{k=1}^{n}\frac{1}{\sqrt{k}} - 2\sqrt
{n}\right)^2 = \sum_{n=1}^{\infty} \frac{a_n^2}{n} \geq \sum_{n=1}^{\infty} \fra
c{1}{n} = +\infty.$$

**Conclusion.** The series diverges to $+\infty$.

4603$ (via the Euler–Maclaurin formula / analytic continuation of the Riemann ze

using only that $a_n$ is decreasing with $a_1 = -1$ — suffices to establish dive
