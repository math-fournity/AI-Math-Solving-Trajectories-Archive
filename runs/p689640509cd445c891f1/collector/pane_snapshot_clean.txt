## Key Definitions and Setup

Let $E_t$ = number of empty squares before the pigeon's turn $t$. The pigeon fil
ls $m$ empty squares; if $E_t \leq m$, the pigeon wins immediately. Otherwise, t
he seagull clears a $k \times k$ subgrid, creating $f$ new empty squares (where
$f$ = filled squares in that subgrid), giving $E_{t+1} = (E_t - m) + f$.

**Minimum hitting set.** A set of squares hitting every $k \times k$ subgrid (i.
e., every subgrid contains at least one set member) has minimum size $\lfloor n/
k \rfloor^2$.

*Proof:* The $\lfloor n/k \rfloor^2$ disjoint subgrids at positions $(1{+}(i{-}1
)k,\, 1{+}(j{-}1)k)$ each require a separate marker (lower bound). Markers at $(
ik, jk)$ for $i,j = 1,\ldots,\lfloor n/k\rfloor$ hit every subgrid (upper bound)
. ✓

## Determining $f(n,k)$

**Lower bound ($m = k^2$ fails when $n \geq 2k$):** The seagull's strategy: if a
ny fully-filled $k \times k$ subgrid exists after the pigeon's turn, clear it; o
therwise clear the densest subgrid.

After the pigeon fills $k^2$ squares, $E_t - k^2$ empty squares remain. These fo
rm a hitting set only if $E_t - k^2 \geq \lfloor n/k \rfloor^2$. If not, some su
bgrid is fully filled, the seagull clears $k^2$ squares, and $E_{t+1} = E_t$ (no
 progress). The pigeon gets stuck at $E_t = k^2 + \lfloor n/k \rfloor^2 - 1$.

- For $n \geq 2k$: $\lfloor n/k \rfloor^2 \geq 4$, so $E_t \geq k^2 + 3 > k^2 =
m$. **Pigeon cannot win.**
- For $k \leq n < 2k$: $\lfloor n/k \rfloor^2 = 1$, so $E_t$ reaches $k^2$, and
the pigeon fills all $k^2$ empty squares and wins.

**Lower bound ($m = k^2 - 1$ fails for all $n \geq k$):** Even with a hitting se
t of size 1, $E_{t+1} \leq 1 + (k^2 - 1) = k^2 > k^2 - 1 = m$. The pigeon can ne
ver fill all empty squares.

**Upper bound ($m = k^2 + 1$ suffices for all $n \geq k$):** The pigeon fills an
y $k^2 + 1$ empty squares. The seagull creates at most $k^2$ new empty squares.
So $E_{t+1} \leq E_t - 1$. Eventually $E_t \leq k^2 + 1 = m$ and the pigeon wins
.

$$f(n,k) = \begin{cases} k^2 & \text{if } k \leq n < 2k \quad (\lfloor n/k \rflo

$$\sum_{n=k}^{2k} f(n,k) = k \cdot k^2 + (k^2 + 1) = k^3 + k^2 + 1$$
