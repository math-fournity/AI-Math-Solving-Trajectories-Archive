## Solution

We compute the four Dini derivates of $f(x) = x\sin(x^{-1})$ (with $f(0)=0$) at
$x=0$.

### Setup

The four Dini derivates at $x=0$ are defined via the difference quotient
$$\frac{f(0+h)-f(0)}{h} = \frac{f(h)}{h},$$
since $f(0)=0$.

For $h\neq 0$,
$$\frac{f(h)}{h} = \frac{h\sin(1/h)}{h} = \sin\!\left(\frac{1}{h}\right).$$

Thus every Dini derivate is a $\limsup$ or $\liminf$ of $\sin(1/h)$ along $h\to
0^+$ or $h\to 0^-$.

### Right Dini derivates ($h\to 0^+$)

As $h\to 0^+$, we have $1/h\to +\infty$. The function $\sin(1/h)$ oscillates den
sely in $[-1,1]$:

- **Density of values.** For any $y\in[-1,1]$ and any $\varepsilon>0$, choose $t
\in\mathbb{R}$ with $\sin t$ arbitrarily close to $y$ (e.g. $t=\arcsin y + 2\pi
n$ for large $n$). Setting $h=1/t$, we get $h\to 0^+$ and $\sin(1/h)=\sin t\to y
$. Hence every value in $[-1,1]$ is a cluster value.
- **Boundedness.** $|\sin(1/h)|\le 1$ always.

Therefore
$$D^+ f(0) = \limsup_{h\to 0^+}\sin(1/h) = 1,\qquad D_+ f(0) = \liminf_{h\to 0^+
}\sin(1/h) = -1.$$

The supremum $1$ is attained (in the limit) along $h_n = 1/(\pi/2 + 2\pi n)\to 0
^+$, where $\sin(1/h_n)=1$; the infimum $-1$ is attained along $h_n = 1/(3\pi/2
+ 2\pi n)\to 0^+$, where $\sin(1/h_n)=-1$.

### Left Dini derivates ($h\to 0^-$)

As $h\to 0^-$, write $h=-|h|$, so $1/h = -1/|h|\to -\infty$. Using $\sin(-u)=-\s
in u$,
$$\sin(1/h)=\sin(-1/|h|)=-\sin(1/|h|).$$

As $|h|\to 0^+$, $\sin(1/|h|)$ again oscillates densely in $[-1,1]$, and so does
 $-\sin(1/|h|)$. Concretely:

- $1$ is attained (in the limit) along $h_n = -1/(3\pi/2 + 2\pi n)\to 0^-$, wher
e $\sin(1/h_n)=\sin(-(3\pi/2+2\pi n))=-\sin(3\pi/2+2\pi n)=-(-1)=1$.
- $-1$ is attained along $h_n = -1/(\pi/2 + 2\pi n)\to 0^-$, where $\sin(1/h_n)=
\sin(-(\pi/2+2\pi n))=-\sin(\pi/2+2\pi n)=-1$.

Since $|\sin(1/h)|\le 1$, these are the extreme cluster values, and the value se
t is dense in $[-1,1]$. Hence
$$D^- f(0) = \limsup_{h\to 0^-}\sin(1/h) = 1,\qquad D_- f(0) = \liminf_{h\to 0^-
}\sin(1/h) = -1.$$

### Conclusion

All four Dini derivates of $f$ at $x=0$ are:

| Dini derivate | Symbol | Value |
|---|---|---|
| Upper right | $D^+ f(0)$ | $1$ |
| Lower right | $D_+ f(0)$ | $-1$ |
| Upper left | $D^- f(0)$ | $1$ |
| Lower left | $D_- f(0)$ | $-1$ |

The key observation is that the difference quotient collapses exactly to $\sin(1
/h)$, whose oscillation between $-1$ and $1$ is symmetric under $h\mapsto -h$ (b
ecause $\sin$ is odd), so the left and right derivates coincide pairwise.
