Looking at this problem, I need to find the maximum number of nonzero coefficien
ts $a_{ij}$ such that the quadratic form $S(x) = \sum_{i<j} a_{ij} x_i x_j$ alwa
ys takes values in $\{-1, 1\}$ for $x \in \{-1,1\}^n$.

**Answer: 4**

## Proof

**Step 1: The Flip Lemma.**

Define $b_k(x) = \sum_{j \neq k} a_{\min(k,j),\max(k,j)}\, x_j$ for each vertex
$k$. If we flip $x_k$ to $-x_k$ (call the new vector $x'$), then:
$$S(x') - S(x) = -2\,x_k\, b_k(x).$$
Since $S(x), S(x') \in \{-1, 1\}$, their difference lies in $\{-2, 0, 2\}$, so $
x_k\, b_k(x) \in \{-1, 0, 1\}$, hence $b_k(x) \in \{-1, 0, 1\}$ for **all** $x \
in \{-1,1\}^n$.

**Step 2: Linear Form Constraint.**

The function $b_k(x) = \sum_{j \neq k} c_j\, x_j$ (where $c_j = a_{\min(k,j),\ma
x(k,j)}$) takes values in $\{-1, 0, 1\}$ for all $x_j \in \{-1,1\}$.

- **Bounded range:** The range of $\sum c_j x_j$ over the hypercube is $2\sum |c
_j|$. Since all values lie in $[-1,1]$, we get $\sum |c_j| \leq 1$.
- **Integrality:** Flipping $x_j$ changes the sum by $2c_j$, which must be an in
teger (difference of two values in $\{-1,0,1\}$). So each $c_j \in \frac{1}{2}\m
athbb{Z}$.
- **Sparsity:** Each nonzero $|c_j| \geq \frac{1}{2}$, so at most **2** coeffici
ents are nonzero. If exactly 1 is nonzero, $|c_j| = 1$ (since $|c_j| = \frac{1}{
2}$ gives values $\pm\frac{1}{2} \notin \{-1,0,1\}$). If exactly 2 are nonzero,
each has $|c_j| = \frac{1}{2}$ (and the values $\pm\frac{y_1 \pm y_2}{2} \in \{-
1, 0, 1\}$ check out).

**Step 3: Graph Structure.**

Form a graph $G$ on $\{1,\ldots,n\}$ with edges where $a_{ij} \neq 0$. Each vert
ex has degree $\leq 2$:
- **Degree 1:** the single incident edge has weight $\pm 1$.
- **Degree 2:** both incident edges have weight $\pm \frac{1}{2}$.

**Edge-weight consistency:** If edge $\{i,j\}$ connects a degree-1 vertex $i$ (r
equiring $|a_{ij}|=1$) and a degree-2 vertex $j$ (requiring $|a_{ij}|=\frac{1}{2
}$), we get a contradiction. So **adjacent vertices must have the same degree**.

Therefore $G$ is a disjoint union of:
- **Isolated edges** (both endpoints degree 1, weight $\pm 1$), and
- **Cycles** (all vertices degree 2, all weights $\pm \frac{1}{2}$).

(Paths of length $\geq 2$ are impossible since endpoints have degree 1 and inter
nal vertices degree 2.)

**Step 4: The Span Argument.**

Since components use disjoint variable sets, their values are independent. The s
pan (max $-$ min) of the total equals the **sum of component spans**.

$S$ is a nonzero quadratic form (if all $a_{ij}=0$, then $S=0 \notin \{-1,1\}$).
 Since the monomials $\{x_i x_j\}$ are linearly independent on $\{-1,1\}^n$ for
$n \geq 2$, $S$ is non-constant, so it takes **both** values $+1$ and $-1$. Thus
 the total span is exactly $2$.

**Every nontrivial component has span $\geq 2$:**
- An isolated edge takes values $\{-1, 1\}$, span $2$.
- A cycle of length $m$: the value is $\frac{1}{2}\sum_{i=1}^m \epsilon_i y_i$ w
here $y_i = \pm 1$ with $\prod y_i = \pm 1$. Consecutive achievable values diffe
r by exactly $2$ (changing one $y_i$ from $1$ to $-1$ shifts the sum by $2$, and
 the parity constraint means achievable $k$-values differ by $2$). So if non-con
stant, span $\geq 2$.

Since total span $= 2$ and each nontrivial component has span $\geq 2$, there is
 **exactly one nontrivial component**, and its span must be exactly $2$ with val
ues in $\{-1, 1\}$.

**Step 5: Which Components Work?**

- **Isolated edge:** Values $\{-1, 1\}$. ✓ — gives **1** nonzero pair.
- **4-cycle (Case B):** Choose signs with $\prod \epsilon_i = -1$ (e.g., three e
dges $+\frac{1}{2}$, one edge $-\frac{1}{2}$). Then $\prod y_i = -1$, so the num
ber of $-1$'s among $y_i$ is odd: $k \in \{1, 3\}$. The values are $\frac{1}{2}(
4-2) = 1$ and $\frac{1}{2}(4-6) = -1$. So values $= \{-1, 1\}$. ✓ — gives **4**
nonzero pairs.
- **3-cycle:** Values are $\{\frac{3}{2}, -\frac{1}{2}\}$ (Case A) or $\{\frac{1
}{2}, -\frac{3}{2}\}$ (Case B). Neither lies in $\{-1, 1\}$. ✗
- **$m$-cycle, $m \geq 5$:** The minimum span is $m-2 \geq 3$ (Case B, even $m$)
 or $m-1 \geq 4$ (Case B, odd $m$), so span $> 2$. ✗

**Step 6: Construction for $n \geq 4$.**

Select any 4 vertices, say $1,2,3,4$, and set:
$$a_{12} = a_{23} = a_{34} = \tfrac{1}{2}, \quad a_{14} = -\tfrac{1}{2}, \quad \
text{all other } a_{ij} = 0.$$

Then $S(x) = \frac{1}{2}(x_1 x_2 + x_2 x_3 + x_3 x_4 - x_4 x_1)$. Setting $y_1 =
 x_1x_2,\, y_2 = x_2x_3,\, y_3 = x_3x_4$ (free), $y_4 = x_4x_1 = y_1 y_2 y_3$, w
e get $S = \frac{1}{2}(y_1 + y_2 + y_3 - y_1 y_2 y_3)$, which equals $+1$ when a
n even number of $y_1, y_2, y_3$ are $-1$, and $-1$ otherwise. All values lie in
 $\{-1, 1\}$. ✓

**Conclusion.** The maximum number of nonzero pairs $(i,j)$ is $\boxed{4}$.
