Looking at this problem, I need to find the minimum even $n$ such that for all $
p, q \in \mathbb{N}^*$ with $1 \leq q \leq p$, the number $(\sqrt{p^2+q}+p)^n$ h
as its first 9 decimal digits all equal to 9.

## Proof

**Setup.** Let $\alpha = \sqrt{p^2+q}+p$ and $\beta = \sqrt{p^2+q}-p$. Then:
- $\alpha\beta = q$, $\alpha + \beta = 2\sqrt{p^2+q}$
- $\alpha^2 + \beta^2 = 4p^2+2q \in \mathbb{Z}$, $\alpha^2\beta^2 = q^2 \in \mat
hbb{Z}$

**Key bound on $\beta$.** Since $\beta = \frac{q}{\sqrt{p^2+q}+p}$ and $1 \leq q
 \leq p$:
- $\beta > 0$ (since $\sqrt{p^2+q} > p$)
- $\beta < \frac{q}{2p} \leq \frac{1}{2}$, so $0 < \beta < \frac{1}{2}$ strictly
.
- $\beta$ is increasing in $q$ (for fixed $p$), maximized at $q=p$: $\beta = \fr
ac{1}{\sqrt{1+1/p}+1} \to \frac{1}{2}$ as $p\to\infty$.

So $\sup \beta = \frac{1}{2}$, never attained.

**Integer property for even $n$.** Setting $u=\alpha^2, v=\beta^2$: $u+v = 4p^2+
2q \in \mathbb{Z}$, $uv = q^2 \in \mathbb{Z}$. By the recurrence $u^{k+1}+v^{k+1
}=(u+v)(u^k+v^k)-uv(u^{k-1}+v^{k-1})$, we get $\alpha^{2k}+\beta^{2k} \in \mathb
b{Z}$ for all $k \geq 0$.

For even $n=2k$: since $0 < \beta^n < 1$, we have $\alpha^n = \underbrace{(\alph
a^n+\beta^n)}_{\in\mathbb{Z}} - \beta^n$, so the fractional part is:
$$\{\alpha^n\} = 1 - \beta^n$$

**Condition for 9 nines.** The first 9 decimal digits are all 9 iff $\{\alpha^n\
} \geq 1-10^{-9}$, i.e., $\beta^n \leq 10^{-9}$.

**Finding minimum even $n$.** We need $\beta^n \leq 10^{-9}$ for **all** valid $
(p,q)$.

- **If $(1/2)^n \leq 10^{-9}$:** Since $\beta < 1/2$ always, $\beta^n < (1/2)^n
\leq 10^{-9}$. Condition holds for all $(p,q)$. ✓
- **If $(1/2)^n > 10^{-9}$:** Since $\beta$ can approach $1/2$ arbitrarily close
ly (take $q=p$, $p$ large), there exists $(p,q)$ with $\beta^n > 10^{-9}$. Condi
tion fails. ✗

So the condition holds for all $(p,q)$ iff $2^n \geq 10^9$.

**Computation:**
- $2^{29} = 536{,}870{,}912 < 10^9$ → fails
- $2^{30} = 1{,}073{,}741{,}824 > 10^9$ → works

**Verification that $n=28$ fails:** Take $p=q=5$. Then $\beta = \frac{1}{\sqrt{1
.2}+1} \approx 0.47722$, and $\log_{10}(\beta^{28}) = 28 \times (-0.32135) = -8.
9978$, so $\beta^{28} \approx 1.005 \times 10^{-9} > 10^{-9}$. The 9th digit is
not 9. ✗

**Verification that $n=30$ works:** For all valid $(p,q)$, $\beta^{30} < (1/2)^{
30} = 2^{-30} \approx 9.31 \times 10^{-10} < 10^{-9}$, so $\{\alpha^{30}\} > 1-1
0^{-9}$, giving 9 nines. ✓

The minimum even $n$ is $\boxed{30}$.
