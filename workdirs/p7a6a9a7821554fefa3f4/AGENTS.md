# Problem

A high-security data vault uses a transmission frequency formula $V(t) = a t^3 + b t$ to encrypt daily signals, where $t$ represents the hour mark of the transmission. The security protocol requires two specific parameters, the amplification factor $a$ and the baseline offset $b$, to be chosen from the set of integers $\{1, 2, 3, \ldots, 2013\}$.

The vault’s integrity depends on a "collision-free" cycle. This means that for the first 2013 hour marks ($t = 1, 2, 3, \ldots, 2013$), no two resulting signal values $V(t)$ can be congruent modulo 2013. In other words, for any two distinct hours $t_1$ and $t_2$ within that range, the difference $V(t_1) - V(t_2)$ must not be a multiple of 2013.

How many unique pairs of settings $(a, b)$ exist that satisfy these security requirements?
