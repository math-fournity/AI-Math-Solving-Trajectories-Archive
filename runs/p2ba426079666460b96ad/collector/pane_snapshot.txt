**Solution.**

Let $d = \gcd(n^2+1,\,(n+1)^2+1)$. Since $(n+1)^2+1 = n^2+2n+2$, we have $d\mid
n^2+1$ and $d\mid n^2+2n+2$.

**Step 1: Reduce $d$.** Since $d$ divides both,
$$d \mid \bigl(n^2+2n+2\bigr) - \bigl(n^2+1\bigr) = 2n+1.$$
So $d\mid 2n+1$ and $d\mid n^2+1$. Eliminating $n$:
$$d \mid 2(n^2+1) - n(2n+1) = 2n^2+2 - 2n^2 - n = 2 - n,$$
hence $d\mid n-2$. Now using $d\mid 2n+1$ and $d\mid n-2$:
$$d \mid (2n+1) - 2(n-2) = 2n+1-2n+4 = 5.$$

Therefore $d\mid 5$, so $d\in\{1,5\}$.

**Step 2: Both values are attained.**

- $n=1$: $n^2+1 = 2$, $(n+1)^2+1 = 5$, so $d = \gcd(2,5) = 1$.
- $n=2$: $n^2+1 = 5$, $(n+1)^2+1 = 10$, so $d = \gcd(5,10) = 5$.

(More generally, $d=5$ exactly when $5\mid n^2+1$, i.e. $n\equiv \pm 2\pmod 5$;
otherwise $d=1$.)

**Conclusion.** The possible values of $d$ are $\boxed{1 \text{ and } 5}$.
