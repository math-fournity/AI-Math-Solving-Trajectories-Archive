## Proof

Let $Q = (I+A)(I-A)^{-1}$, where $A$ is a real $n\times n$ matrix and $I-A$ is i
nvertible. We seek conditions on $A$ such that $Q$ is orthogonal, i.e. $Q^{T}Q =
 I$.

**Step 1: Compute $Q^T$.**

$$Q^T = \big((I-A)^{-1}\big)^T (I+A)^T = (I - A^T)^{-1}(I + A^T).$$

**Step 2: Set up the orthogonality condition $Q^T Q = I$.**

$$(I - A^T)^{-1}(I + A^T)(I + A)(I - A)^{-1} = I.$$

Left-multiply by $(I - A^T)$ and right-multiply by $(I - A)$:

$$(I + A^T)(I + A) = (I - A^T)(I - A).$$

**Step 3: Expand both sides.**

Left side:
$$I + A + A^T + A^T A.$$

Right side:
$$I - A - A^T + A^T A.$$

Equating and cancelling $I$ and $A^T A$ from both sides:

$$A + A^T = -A - A^T,$$

$$2(A + A^T) = 0,$$

$$A^T = -A.$$

So a **necessary** condition is that $A$ is **skew-symmetric**.

**Step 4: Verify sufficiency and invertibility of $I - A$.**

Suppose $A^T = -A$. Then reversing the algebra above shows $Q^T Q = I$, so $Q$ i
s orthogonal — provided $I - A$ is invertible.

For a real skew-symmetric matrix $A$, all eigenvalues are purely imaginary (or z
ero): if $Av = \lambda v$ with $v \neq 0$, then $\lambda\|v\|^2 = v^* A v = (v^*
 A v)^* = \overline{\lambda}\|v\|^2$ combined with $A^T = -A$ gives $\overline{\
lambda} = -\lambda$, i.e. $\operatorname{Re}(\lambda) = 0$. Hence $1$ is **not**
 an eigenvalue of $A$, so $I - A$ is invertible. Thus the expression is well def
ined and the orthogonality holds.

**Conclusion.**

The matrix $(I+A)(I-A)^{-1}$ is orthogonal if and only if $A$ is **skew-symmetri
c** ($A^T = -A$). The invertibility of $I - A$ is then automatic, since a real s
kew-symmetric matrix has no real eigenvalue equal to $1$.
