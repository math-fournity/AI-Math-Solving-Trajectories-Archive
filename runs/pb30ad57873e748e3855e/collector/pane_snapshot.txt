## 解答

我们需要计算 $t = \sum_{i=1}^{\infty} \arctan\!\left(\dfrac{1}{2i^{2}}\right)$，
然后求 $\tan t$。

**关键观察：将每一项分解为反正切的差。**

尝试将 $\arctan\!\left(\dfrac{1}{2i^{2}}\right)$ 写成 $\arctan\!\left(\dfrac{1}{
2i-1}\right) - \arctan\!\left(\dfrac{1}{2i+1}\right)$ 的形式。

利用恒等式（当各项均为正且差为正时成立）：
$$\arctan a - \arctan b = \arctan\!\left(\frac{a-b}{1+ab}\right).$$

取 $a = \dfrac{1}{2i-1}$，$b = \dfrac{1}{2i+1}$：

**分子：**
$$a - b = \frac{1}{2i-1} - \frac{1}{2i+1} = \frac{(2i+1)-(2i-1)}{(2i-1)(2i+1)} =
 \frac{2}{4i^{2}-1}.$$

**分母：**
$$1 + ab = 1 + \frac{1}{(2i-1)(2i+1)} = 1 + \frac{1}{4i^{2}-1} = \frac{4i^{2}}{4
i^{2}-1}.$$

**比值：**
$$\frac{a-b}{1+ab} = \frac{2/(4i^{2}-1)}{4i^{2}/(4i^{2}-1)} = \frac{2}{4i^{2}} =
 \frac{1}{2i^{2}}.$$

因此
$$\arctan\!\left(\frac{1}{2i^{2}}\right) = \arctan\!\left(\frac{1}{2i-1}\right)
- \arctan\!\left(\frac{1}{2i+1}\right).$$

**级数求和（裂项相消）：**

$$\sum_{i=1}^{N}\arctan\!\left(\frac{1}{2i^{2}}\right) = \sum_{i=1}^{N}\left[\ar
ctan\!\left(\frac{1}{2i-1}\right) - \arctan\!\left(\frac{1}{2i+1}\right)\right].
$$

这是一个裂项相消级数。展开各项：

$$= \left[\arctan 1 - \arctan\frac{1}{3}\right] + \left[\arctan\frac{1}{3} - \ar
ctan\frac{1}{5}\right] + \cdots + \left[\arctan\frac{1}{2N-1} - \arctan\frac{1}{
2N+1}\right].$$

所有中间项相消，剩下：

$$= \arctan 1 - \arctan\!\left(\frac{1}{2N+1}\right).$$

**取 $N \to \infty$ 时的极限：**

$$t = \lim_{N\to\infty}\left[\arctan 1 - \arctan\!\left(\frac{1}{2N+1}\right)\ri
ght] = \arctan 1 - \arctan 0 = \frac{\pi}{4} - 0 = \frac{\pi}{4}.$$

**结论：**

$$\tan t = \tan\!\left(\frac{\pi}{4}\right) = \boxed{1}.$$

### 证明完成
