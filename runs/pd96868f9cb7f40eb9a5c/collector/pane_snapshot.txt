Looking at this problem, I need to find the largest $n \leq 2015$ such that ther

sqrt{n})) = 0$.

## Setting Up the Key Equation

Let $t = \sqrt{n}$. Then $f(t) = an + c + b\sqrt{n}$. Let $p = an+c$, $q = b$, s
o $f(\sqrt{n}) = p + q\sqrt{n}$.

Now compute $f(p + q\sqrt{n}) = a(p+q\sqrt{n})^2 + b(p+q\sqrt{n}) + c$, which ex
pands to:
$$\underbrace{a(p^2 + q^2 n) + bp + c}_{\text{rational part}} + \underbrace{(2ap
q + bq)\sqrt{n}}_{\text{irrational part}}$$

**Case 1: $n$ is a perfect square.** Then $\sqrt{n}$ is an integer and we just n
eed $f(f(m))=0$ for $m=\sqrt{n}$. Taking $f(x)=ax(x-m)$ (i.e., $a=1, b=-m, c=0$)
 gives $f(m)=0$, $f(0)=0$. So every perfect square is stable. The largest $\leq
2015$ is $44^2 = 1936$.

**Case 2: $n$ is not a perfect square.** Then $\sqrt{n}$ is irrational, so both
parts must vanish separately:
- $q(2ap + b) = 0$
- $a(p^2 + q^2 n) + bp + c = 0$

## Sub-case 2a: $q = b = 0$

Then $f(x) = ax^2 + c$, $p = an + c$, and $f(p) = ap^2 + c = 0$, giving $c = -ap
^2$.

Substituting back: $p = an - ap^2 = a(n - p^2)$, so $p = a(n-p^2)$. Setting $k =
 p/a$ (requiring $a \mid p$), we get:

$$\boxed{n = a^2 k^2 + k}$$

for integers $a \neq 0$, $k \neq 0$, with $c = -a^3 k^2$.

**Verification:** $f(\sqrt{n}) = a \cdot n + c = a(a^2k^2+k) - a^3k^2 = ak = p$,
 and $f(p) = a \cdot a^2k^2 - a^3k^2 = 0$. ✓

## Sub-case 2b: $b \neq 0$, $2ap + b = 0$

This yields $n = \frac{b(b+2)}{4a^2(b-1)(b+1)}$. For $|b| \geq 2$ with $a = \pm
1$, we get $n < 1$ (since $b(b+2) < 4(b^2-1)$ for $|b|\geq 2$). For $b = \pm 1$,
 the denominator vanishes and direct substitution gives contradictions ($3=0$ or
 $-1=0$). **No solutions exist in this sub-case.**

## Maximizing $n = a^2 k^2 + k \leq 2015$

Let $m = ak$ (nonzero integer), so $n = m^2 + k$ where $k = m/a$ divides... equi
valently $n = m^2 + d$ where $d$ is a nonzero divisor of $m$.

**If $m^2 < 2015$ (i.e., $m \leq 44$):** $d > 0$, max $n = m^2 + m = m(m+1)$. Be
st: $m=44 \Rightarrow n = 1980$.

**If $m^2 > 2015$ (i.e., $m \geq 45$):** $d < 0$, need $|d| \mid m$ and $|d| \ge
q m^2 - 2015$ and $|d| \leq m$.

- **$m = 45$:** $m^2 - 2015 = 10$. Divisors of 45 in $[10, 45]$: $\{15, 45\}$.
  - $|d| = 15 \Rightarrow n = 2025 - 15 = \mathbf{2010}$
  - $|d| = 45 \Rightarrow n = 2025 - 45 = 1980$

- **$m \geq 46$:** $m^2 - 2015 > m$ (since $m(m-1) > 2015$ for $m \geq 46$), so
no divisor of $m$ can satisfy $|d| \geq m^2 - 2015$ and $|d| \leq m$ simultaneou
sly. **No solutions.**

## Checking $n \in \{2011, 2012, 2013, 2014, 2015\}$

For each, I verify no valid $(m, d)$ exists:
- Need $d \mid m$ with $n = m^2 + d$, $d \neq 0$.
- For $m = 44$: $d = n - 1936 \in \{75,76,77,78,79\}$, none divides 44.
- For $m = 45$: $|d| = 2025 - n \in \{10,11,12,13,14\}$, none divides 45.
- For other $m$: either $|n - m^2| > m$ (no divisor possible) or $m(m\pm1) = n$
has no integer solution.

None of 2011–2015 are stable.

## Explicit Construction for $n = 2010$

Take $a = 3$, $k = -15$ (so $m = ak = -45$, $|m| = 45$), $b = 0$, $c = -a^3k^2 =
 -27 \cdot 225 = -6075$.

$$f(x) = 3x^2 - 6075$$

**Check:**
- $f(\sqrt{2010}) = 3 \cdot 2010 - 6075 = 6030 - 6075 = -45$
- $f(-45) = 3 \cdot 2025 - 6075 = 6075 - 6075 = 0$ ✓

$f$ is quadratic with integer coefficients, and $2010$ is not a perfect square (
$44^2 = 1936 < 2010 < 2025 = 45^2$).
