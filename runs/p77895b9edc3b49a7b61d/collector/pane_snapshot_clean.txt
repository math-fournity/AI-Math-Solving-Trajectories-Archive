## Proof

**Claim:** Yes, there exists a constant $\xi \in \mathbb{R}$ such that $\mu(\{f
\le \xi < g\}) > 0$.

**Key observation.** We claim that
$$
\{f < g\} = \bigcup_{\xi \in \mathbb{Q}} \{f \le \xi < g\}.
$$

*Proof of the identity.* The inclusion "$\supseteq$" is immediate, since $\{f \l
e \xi < g\} \subseteq \{f < g\}$ for every $\xi$.

For the inclusion "$\subseteq$", take $\omega$ with $f(\omega) < g(\omega)$. The
n the interval $(f(\omega), g(\omega))$ is a nonempty open interval, so it conta
ins a rational number $q$. If $f(\omega) \in \mathbb{Q}$, we may simply take $\x
i = f(\omega)$, which gives $f(\omega) \le \xi < g(\omega)$. Otherwise $f(\omega
) \notin \mathbb{Q}$, and any rational $q \in (f(\omega), g(\omega))$ satisfies
$f(\omega) < q < g(\omega)$, hence $f(\omega) \le q < g(\omega)$. In either case
 $\omega \in \{f \le \xi < g\}$ for some $\xi \in \mathbb{Q}$. ∎

**Applying countable additivity.** Since $f$ and $g$ are $(\mathscr{F}, \mathscr
{B})$-measurable, each set $\{f \le \xi\} = f^{-1}((-\infty, \xi])$ and $\{\xi <
 g\} = g^{-1}((\xi, \infty))$ is $\mathscr{F}$-measurable, so $\{f \le \xi < g\}
 = \{f \le \xi\} \cap \{\xi < g\} \in \mathscr{F}$. The union above is over the
countable set $\mathbb{Q}$, so by subadditivity,
$$
0 < \mu(\{f < g\}) = \mu\!\left(\bigcup_{\xi \in \mathbb{Q}} \{f \le \xi < g\}\r
ight) \le \sum_{\xi \in \mathbb{Q}} \mu(\{f \le \xi < g\}).
$$

A sum of nonnegative terms over a countable index set can be strictly positive o
nly if at least one summand is strictly positive. Hence there exists $\xi_0 \in
\mathbb{Q} \subseteq \mathbb{R}$ with
$$
\mu(\{f \le \xi_0 < g\}) > 0.
$$

**Conclusion.** The desired constant exists (indeed, it may be chosen to be rati
onal). $\blacksquare$
