# Problem

In a sprawling urban grid of $200$ East-West streets and $200$ North-South avenues, a tech company is installing $200 \times 200$ potential server nodes. In some of these intersections, a server is installed; others are left empty. Each server is assigned one of two distinct signals: "Infrared" or "Ultraviolet."

A server is considered "connected" to another server if they occupy the same street or the same avenue. Due to frequency interference regulations, the network is configured such that every single Infrared server is connected to exactly five Ultraviolet servers. Conversely, every single Ultraviolet server is connected to exactly five Infrared servers. (Servers may be connected to any number of other servers sharing their own signal color without restriction).

What is the maximum possible total number of servers that can be installed in this $200 \times 200$ grid under these constraints?
