## Proof

Let $f(x) = \dfrac{1}{\sqrt[2011]{1-x^{2011}}}$, and let $F_n = f$ applied $n$ t
imes to $2011$. We want $F_{2010}^{\,2011}$.

**Key substitution.** Define $g_n = F_n^{\,2011}$ (the 2011-th power of the $n$-
th iterate). Then
$$g_0 = 2011^{2011},$$
and the recurrence is
$$g_{n+1} = F_{n+1}^{\,2011} = \left(\frac{1}{\sqrt[2011]{1-F_n^{2011}}}\right)^
{2011} = \frac{1}{1-F_n^{2011}} = \frac{1}{1-g_n}.$$

So $g_n$ evolves under the Möbius transformation
$$T(y) = \frac{1}{1-y}.$$

**$T$ has order 3.** Compute:
$$T^2(y) = T\!\left(\frac{1}{1-y}\right) = \frac{1}{1-\frac{1}{1-y}} = \frac{1}{
\frac{(1-y)-1}{1-y}} = \frac{1-y}{-y} = \frac{y-1}{y} = 1 - \frac{1}{y},$$
$$T^3(y) = T\!\left(1-\frac{1}{y}\right) = \frac{1}{1-\left(1-\frac{1}{y}\right)
} = \frac{1}{\frac{1}{y}} = y.$$

Hence $T^3 = \mathrm{id}$.

**Apply to our problem.** Since $2010 = 3 \times 670$,
$$g_{2010} = T^{2010}(g_0) = (T^3)^{670}(g_0) = g_0 = 2011^{2011}.$$

Therefore
$$\bigl(f(f(\ldots(f(2011))\ldots))\bigr)^{2011} = g_{2010} = 2011^{2011}.$$
