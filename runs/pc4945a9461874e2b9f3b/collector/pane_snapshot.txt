## Solution

**Setup.** Let the state be $(a, b, \text{blue})$ where $a$ = T1 wins, $b$ = JDG
 wins, and $\text{blue} \in \{T1, JDG\}$ is the team on blue side for the next g
ame. The series ends when $a=3$ or $b=3$.

Define $E(a,b,\text{blue})$ = expected number of future blue-side wins from this
 state. In each game, blue wins with probability $\frac{2}{3}$, red with $\frac{
1}{3}$. The loser of each game plays blue next.

**Recurrences.** If blue = T1:
$$E(a,b,T1) = \tfrac{2}{3}\bigl(1 + E(a{+}1,b,JDG)\bigr) + \tfrac{1}{3}E(a,b{+}1
,T1)$$
(T1 blue wins → T1 wins game, JDG loses → JDG blue next. T1 blue loses → JDG win
s, T1 loses → T1 blue next, no blue win credited.)

If blue = JDG:
$$E(a,b,JDG) = \tfrac{2}{3}\bigl(1 + E(a,b{+}1,T1)\bigr) + \tfrac{1}{3}E(a{+}1,b
,JDG)$$

Base case: $E = 0$ when $a=3$ or $b=3$.

**Computing bottom-up** (by decreasing $a+b$):

| State | $E(\cdot, T1)$ | $E(\cdot, JDG)$ |
|-------|----------------|-----------------|
| $(2,2)$ | $\frac{2}{3}$ | $\frac{2}{3}$ |
| $(2,1)$ | $\frac{8}{9}$ | $\frac{10}{9}$ |
| $(1,2)$ | $\frac{10}{9}$ | $\frac{8}{9}$ |
| $(2,0)$ | $\frac{26}{27}$ | $\frac{34}{27}$ |
| $(1,1)$ | $\frac{16}{9}$ | $\frac{16}{9}$ |
| $(0,2)$ | $\frac{34}{27}$ | $\frac{26}{27}$ |
| $(1,0)$ | $\frac{170}{81}$ | $\frac{184}{81}$ |
| $(0,1)$ | $\frac{184}{81}$ | $\frac{170}{81}$ |

**Sample verifications:**

- $E(2,2,T1) = \frac{2}{3}(1+0)+\frac{1}{3}(0) = \frac{2}{3}$. ✓
- $E(2,1,T1) = \frac{2}{3}(1+0)+\frac{1}{3}\cdot\frac{2}{3} = \frac{2}{3}+\frac{
2}{9}=\frac{8}{9}$. ✓
- $E(1,1,T1) = \frac{2}{3}(1+\frac{10}{9})+\frac{1}{3}\cdot\frac{10}{9} = \frac{
38}{27}+\frac{10}{27}=\frac{48}{27}=\frac{16}{9}$. ✓ (Symmetric in $T1 \leftrigh
tarrow JDG$ at $(1,1)$, as expected.)
- $E(1,0,JDG) = \frac{2}{3}(1+\frac{16}{9})+\frac{1}{3}\cdot\frac{34}{27} = \fra
c{50}{27}+\frac{34}{81}=\frac{184}{81}$. ✓

**Final computation.** Game 1 has T1 on blue, so we need $E(0,0,T1)$:

$$E(0,0,T1) = \tfrac{2}{3}\bigl(1 + E(1,0,JDG)\bigr) + \tfrac{1}{3}E(0,1,T1)$$
$$= \tfrac{2}{3}\left(1 + \tfrac{184}{81}\right) + \tfrac{1}{3}\cdot\tfrac{184}{
81} = \tfrac{2}{3}\cdot\tfrac{265}{81} + \tfrac{184}{243} = \tfrac{530}{243} + \
tfrac{184}{243} = \tfrac{714}{243} = \tfrac{238}{81}.$$

**Sanity check via Wald-type identity.** Conditional on game $i$ being played, t
he blue team is determined by prior history, but $P(\text{blue wins}) = \frac{2}
{3}$ regardless of identity. So $E[\text{blue wins}] = \frac{2}{3}E[N]$ where $N
$ = number of games. This gives $E[N] = \frac{3}{2}\cdot\frac{238}{81} = \frac{1
19}{27} \approx 4.407$, which exceeds the no-advantage value of $\frac{33}{8}=4.
125$ — consistent with the comeback mechanic (loser gets blue advantage) making
sweeps harder.

**Result.** The expected number of blue-side wins is $\frac{238}{81}$, which is
irreducible ($\gcd(238,81)=1$ since $238=2\cdot7\cdot17$ and $81=3^4$).

$$a + b = 238 + 81 = \boxed{319}$$
