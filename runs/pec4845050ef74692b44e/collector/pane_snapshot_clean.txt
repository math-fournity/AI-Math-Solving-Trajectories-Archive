$$M_{x,y} = (-1)^{\operatorname{popcount}(x\mathbin{\&}y)}.$$
This is the character table of $(\mathbb{Z}/2\mathbb{Z})^{2017}$, so by characte

$$\det M_{i,j} = \det M + (a_{i,j} - M_{ij})\,C_{i,j} = 0,$$
where $C_{i,j}$ is the $(i,j)$-cofactor. Since $M$ is symmetric, $C_{i,j} = \ope
ratorname{adj}(M)_{j,i} = \frac{\det M}{N}M_{ij}$. Solving:
$$a_{i,j} = M_{ij} - \frac{\det M}{C_{i,j}} = M_{ij} - \frac{N}{M_{ij}} = M_{ij}
(1 - N),$$
using $M_{ij} = \pm 1$. Therefore $A = (1-N)\,M$ and
$$\det A = (1-N)^N \cdot \det M.$$
