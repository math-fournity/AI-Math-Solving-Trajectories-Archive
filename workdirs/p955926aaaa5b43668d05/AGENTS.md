# Problem

In a large logistics hub, a security engineer is auditing the "stability codes" of 100 different automated cargo units, labeled with unique identification numbers $a$ where $2 \leq a \leq 101$.

Each unit follows a specific recursive encryption protocol to generate a security sequence. The protocol starts with an initial key and then, for every subsequent step $n$, it generates a new value by squaring the previous value. Specifically, the system tracks the security status based on the last two digits (the remainder when divided by 100) of the value $a^{2^n}$.

A cargo unit is considered "stably encrypted" if there exists some point in the sequence $N$ such that for every step $n$ from $N$ onwards, the last two digits of the encryption value remain constant and never change again.

Out of the 100 units labeled from 2 to 101, how many units possess an identification number $a$ that results in a stably encrypted sequence?
