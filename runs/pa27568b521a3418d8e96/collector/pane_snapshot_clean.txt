## Proof

We interpret "the field $\mathbb{Z}_p$" as $\mathbb{F}_p = \mathbb{Z}/p\mathbb{Z
}$, the finite field with $p$ elements ($p$ an odd prime, since $p \neq 2$). We
determine the Witt group $W(\mathbb{F}_p)$.

### Step 1. Classification of anisotropic forms over $\mathbb{F}_p$

**Lemma 1 (Chevalley–Warning).** *Every non-degenerate quadratic form over $\mat
hbb{F}_p$ of dimension $n \geq 3$ is isotropic.*

*Proof.* Let $q(x_1,\dots,x_n)$ be non-degenerate of degree $2$. Since $n > 2 =
\deg q$, the Chevalley–Warning theorem gives that the number of zeros of $q$ in
$\mathbb{F}_p^n$ is divisible by $p$. Since $(0,\dots,0)$ is a zero, the number
of zeros is $\geq p \geq 3$, so there exists a non-trivial zero. $\square$

**Lemma 2 (Classification by dimension and discriminant).** *Over $\mathbb{F}_p$
 ($p$ odd), two non-degenerate quadratic forms are isometric if and only if they
 have the same dimension and the same discriminant $d = \prod a_i \in \mathbb{F}
_p^*/(\mathbb{F}_p^*)^2 \cong \mathbb{Z}/2\mathbb{Z}$.*

*Proof (sketch).* Since $\mathbb{F}_p^*/(\mathbb{F}_p^*)^2 = \{1, \epsilon\}$ wh
ere $\epsilon$ is a non-square, any diagonal form $\langle a_1,\dots,a_n\rangle$
 can be reduced (by extracting square factors) to one with each $a_i \in \{1,\ep
silon\}$. A non-degenerate form of dimension $\geq 2$ represents at least $(p+1)
/2$ values, hence represents both a square and a non-square (since $p \geq 3$).
If $q$ represents $v$, then $q \cong \langle v\rangle \oplus q'$; choosing $v$ a
 square lets us normalize the first coefficient to $1$. By induction, $q \cong \
langle 1, \dots, 1, d\rangle$ where $d$ is the discriminant, so the form is dete
rmined by $(n, d)$. $\square$

**Corollary 3.** *In each dimension $n \geq 1$ there are exactly two isometry cl
asses, with discriminants $1$ and $\epsilon$.*

### Step 2. Enumerate the anisotropic forms

By the **Witt decomposition theorem**, every non-degenerate form $q$ over $\math
bb{F}_p$ decomposes uniquely (up to isometry) as
$$q \cong q_{\mathrm{an}} \oplus H^{\oplus r},$$
where $q_{\mathrm{an}}$ is anisotropic and $H = \langle 1, -1\rangle$ is the hyp
erbolic plane. The Witt group $W(\mathbb{F}_p)$ is in bijection with the set of
anisotropic forms (up to isometry). By Lemma 1, anisotropic forms have dimension
 $\leq 2$:

- **Dimension 0:** the zero form — $1$ class.
- **Dimension 1:** $\langle 1\rangle$ and $\langle \epsilon\rangle$ — $2$ classe
s (both anisotropic).
- **Dimension 2:** two classes by Corollary 3. One is the hyperbolic plane $H$ (
isotropic); the other, call it $Q_2$, is anisotropic — $1$ class.

A binary form $\langle a,b\rangle$ is isotropic iff $-ab$ is a square, i.e., iff
 $-d$ is a square where $d = \mathrm{disc}$. So:

- **If $p \equiv 1 \pmod{4}$:** $-1$ is a square, so $H$ has discriminant $1$, a
nd $Q_2$ has discriminant $\epsilon$.
- **If $p \equiv 3 \pmod{4}$:** $-1 = \epsilon$ is a non-square, so $H$ has disc
riminant $\epsilon$, and $Q_2$ has discriminant $1$.

Thus $|W(\mathbb{F}_p)| = 4$ in all cases, with elements $\{0,\, a,\, b,\, c\}$
where
$$a = [\langle 1\rangle], \quad b = [\langle \epsilon\rangle], \quad c = [Q_2].$
$

### Step 3. Determine the group structure

We compute the addition table. Note $\langle \epsilon,\epsilon\rangle \cong \lan
gle 1,1\rangle$ (same discriminant $1$, by Lemma 2), so $2a = 2b$.

**$2a = [\langle 1,1\rangle]$:** discriminant $1$; isotropic iff $-1$ is a squar
e.

**$a + b = [\langle 1,\epsilon\rangle]$:** discriminant $\epsilon$; isotropic if
f $-\epsilon$ is a square.

**$2c = [Q_2 \oplus Q_2]$:** dimension $4$, hence isotropic (Lemma 1). So $Q_2 \
oplus Q_2 \cong H \oplus q'$ where $q'$ is binary with $\mathrm{disc}(q') = \mat
hrm{disc}(Q_2)^2 / \mathrm{disc}(H) = 1/(-1) = -1$.

**Case 1: $p \equiv 1 \pmod{4}$** ($-1$ is a square).

- $2a = 0$ (since $-1$ square $\Rightarrow$ $\langle 1,1\rangle$ is hyperbolic).
 Likewise $2b = 0$.
- $a + b$: $-\epsilon = (-1)\epsilon$; $-1$ is a square so $-\epsilon$ is a **no
n-square**; $\langle 1,\epsilon\rangle$ is anisotropic, so $a + b = c$.
- $2c$: $\mathrm{disc}(q') = -1$ is a square, so $q' \cong \langle 1,1\rangle \c
ong H$ (hyperbolic). Thus $Q_2 \oplus Q_2 \cong H \oplus H \sim 0$, giving $2c =
 0$.

The group is $\{0, a, b, c\}$ with $2a = 2b = 2c = 0$ and $a + b = c$. This is t
he **Klein four-group**:
$$\boxed{W(\mathbb{F}_p) \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb
{Z}} \quad (p \equiv 1 \pmod{4}).$$

---

**Case 2: $p \equiv 3 \pmod{4}$** ($-1 = \epsilon$ is a non-square).

- $2a = [\langle 1,1\rangle]$: $-1$ is a non-square, so $\langle 1,1\rangle$ is
**anisotropic** with discriminant $1$, i.e., $2a = c$. Likewise $2b = c$.
- $a + b$: $-\epsilon = (-1)\epsilon = \epsilon \cdot \epsilon = \epsilon^2$ is
a **square**, so $\langle 1,\epsilon\rangle$ is hyperbolic, giving $a + b = 0$,
i.e., $b = -a$.
- $2c$: $\mathrm{disc}(q') = -1 = \epsilon$, so $q'$ is the binary form with dis
criminant $\epsilon$, which is $H$ (since $H$ has discriminant $-1 = \epsilon$).
 Thus $Q_2 \oplus Q_2 \cong H \oplus H \sim 0$, giving $2c = 0$.

The group is $\{0, a, 2a, 3a\} = \{0, a, c, b\}$ with $4a = 2c = 0$ and $a$ of o
rder $4$. This is the **cyclic group of order 4**:
$$\boxed{W(\mathbb{F}_p) \cong \mathbb{Z}/4\mathbb{Z}} \quad (p \equiv 3 \pmod{4
}).$$

### Conclusion

The Witt group of non-degenerate quadratic forms over $\mathbb{F}_p = \mathbb{Z}
/p\mathbb{Z}$ ($p$ odd) is a group of order $4$, whose structure depends on $p \
bmod 4$:

$$W(\mathbb{F}_p) \cong \begin{cases} \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2
\mathbb{Z} & \text{if } p \equiv 1 \pmod{4},\\[6pt] \mathbb{Z}/4\mathbb{Z} & \te
xt{if } p \equiv 3 \pmod{4}. \end{cases}$$

In both cases the four Witt classes are represented by the anisotropic forms $\{
0,\;\langle 1\rangle,\;\langle \epsilon\rangle,\; Q_2\}$, where $\epsilon$ is a
fixed non-square in $\mathbb{F}_p^*$ and $Q_2$ is the unique anisotropic binary
form. The difference in group structure arises from whether $-1$ is a square: wh
en $p \equiv 1 \pmod{4}$, every non-trivial element has order $2$; when $p \equi
v 3 \pmod{4}$, the class of $\langle 1\rangle$ generates the group and has order
 $4$.
