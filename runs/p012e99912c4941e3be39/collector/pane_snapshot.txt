## 解答

**设置与建模。**

轨道槽位编号为 1, 2, 3, … 从 1 开始。设 $p_i$ 为放置集装箱 $i$ 的槽位。放置时，
所有在 $p_i$ 处或右侧的集装箱向右移动一位；集装箱 $i$ 进入槽位 $p_i$；随后起重机
移动到 $p_i + 1$。在放置操作之间，“退后”指令将起重机向左移动一位，但不会低于槽位
 1。

因此，放置位置序列满足：
- $p_1 = 1$（起重机从槽位 1 开始；无法退后）。
- $p_i \in \{1, 2, \dots, p_{i-1}+1\}$，其中 $i = 2, \dots, 6$（在 $i-1$ 位于 $p
_{i-1}$ 后，起重机位于 $p_{i-1}+1$；退后可到达任何 $\geq 1$ 的槽位）。

集装箱始终占据从槽位 1 开始的连续块，因此最终布局是 $\{1,\dots,6\}$ 的一个排列。

**与排列的双射映射。**

定义 $a_i$ = 在最终排列 $\pi$ 中，排在 $i$ 前面的 $\{1,\dots,i-1\}$ 中的元素数量
。那么 $i$ 在限制于 $\{1,\dots,i\}$ 的子序列中的位置为 $\text{pos}_i = a_i + 1$
，且 $p_i = \text{pos}_i$。序列 $(a_1, \dots, a_6)$ 与排列 $\pi$ 之间存在双射关
系（通过按顺序插入 $1, 2, \dots, 6$ 重建 $\pi$，使得 $a_i$ 个较小的元素位于 $i$
之前），且 $a_i \in \{0, \dots, i-1\}$。

约束 $p_i \le p_{i-1}+1$ 变为：
$$a_i + 1 \le a_{i-1} + 2 \quad\Longrightarrow\quad a_i \le a_{i-1} + 1,$$
其中 $a_1 = 0$，$a_i \ge 0$。（上限 $a_i \le i-1$ 是自动满足的，因为从 $0$ 开始
，每步最多增加 $1$。）

**计算有效序列的数量。**

设 $f(i, h)$ = 满足所有约束且以 $a_i = h$ 结束的序列 $(a_1, \dots, a_i)$ 的数量
。递推关系为：
$$f(i, h) = \sum_{j \ge h-1} f(i-1, j).$$

| $i$ | $h{=}0$ | $h{=}1$ | $h{=}2$ | $h{=}3$ | $h{=}4$ | $h{=}5$ | **总计** |
|-----|---------|---------|---------|---------|---------|---------|---------|
| 1   | 1       |         |         |         |         |         | **1**   |
| 2   | 1       | 1       |         |         |         |         | **2**   |
| 3   | 2       | 2       | 1       |         |         |         | **5**   |
| 4   | 5       | 5       | 3       | 1       |         |         | **14**  |
| 5   | 14      | 14      | 9       | 4       | 1       |         | **42**  |
| 6   | 42      | 42      | 28      | 14      | 5       | 1       | **132** |

**验证。** 总数 $1, 2, 5, 14, 42, 132$ 正好是卡塔兰数 (Catalan numbers) $C_1, \d
ots, C_6$。这是已知结果：满足 $b_1=0$ 且 $0 \le b_i \le b_{i-1}+1$ 的序列 $(b_1,
\dots,b_n)$ 的数量为 $C_n$（可通过反射原理或满足卡塔兰递推关系的生成函数 $T(n) =
 \sum_{k} T(k)\,T(n-1-k)$ 证明）。

**小规模情况检查。** 对于 $n=3$，6 个排列中除 $(2,1,3)$ 外均有效：要获得 $(2,1,3
)$，需要 $p_3=3$，但在将 $2$ 放置在位置 $1$（得到 $(2,1)$）后，起重机位于位置 $2
$，因此最大 $p_3=2$。这 5 个有效排列符合 $C_3=5$。

**最终答案：** 有效配置的数量为 $\boxed{132}$。
