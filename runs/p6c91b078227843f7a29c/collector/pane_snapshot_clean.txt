## Setup and Reformulation

Let the ten degree-5 polynomials be $P_1, \ldots, P_{10}$. Vasil calls $n$ conse
cutive natural numbers $a, a+1, \ldots, a+n-1$. For each called number $a+i$, Pe
ter chooses some polynomial $P_{j_i}$ and records $P_{j_i}(a+i)$. The recorded s
equence must be arithmetic, so there exist constants $A, D$ with:
$$P_{j_i}(a+i) = A + Di \quad \text{for all } i = 0, 1, \ldots, n-1.$$

Define the linear function $L(x) = A + D(x-a)$, so $L(a+i) = A + Di$. The condit
ion becomes: **for each $i \in \{0,\ldots,n-1\}$, there exists $j$ such that $P_
j(a+i) = L(a+i)$**.

Now define $R_j(x) = P_j(x) - L(x)$ for each $j = 1, \ldots, 10$. Since $P_j$ ha
s degree 5 and $L$ has degree 1, each $R_j$ is a degree-5 polynomial. The condit
ion becomes:

> For each $i \in \{0, \ldots, n-1\}$, at least one of $R_1(a+i), \ldots, R_{10}
(a+i)$ equals zero.

In other words, the block $\{a, a+1, \ldots, a+n-1\}$ of $n$ consecutive integer
s must be contained in the union of the integer roots of $R_1, \ldots, R_{10}$.

## Upper Bound: $n \le 50$

Each $R_j$ is a degree-5 polynomial, so it has **at most 5 real roots** (by the
fundamental theorem of algebra), hence at most 5 integer roots. The union of the
 integer root sets of $R_1, \ldots, R_{10}$ contains at most $10 \times 5 = 50$
integers. Since the block of $n$ consecutive integers must be entirely contained
 in this union, we have:
$$n \le 50.$$

## Construction Achieving $n = 50$

Take the starting number $a = 1$ and the linear function $L(x) = x$ (giving the
arithmetic progression $1, 2, 3, \ldots, 50$ with common difference $1$).

Partition the set $\{1, 2, \ldots, 50\}$ into 10 groups of 5 consecutive integer
s:
$$S_j = \{5(j-1)+1, \, 5(j-1)+2, \, 5(j-1)+3, \, 5(j-1)+4, \, 5(j-1)+5\}, \quad
j = 1, \ldots, 10.$$

For each $j$, define:
$$R_j(x) = \prod_{r \in S_j}(x - r),$$
which is a degree-5 polynomial whose roots are exactly the 5 integers in $S_j$.
Then set:
$$P_j(x) = R_j(x) + L(x) = R_j(x) + x.$$

Since $R_j$ has degree 5 and $L$ has degree 1, each $P_j$ is a degree-5 polynomi
al. ✓

**Verification:** For each integer $m \in \{1, 2, \ldots, 50\}$, the value $m$ b
elongs to exactly one group $S_j$. For that $j$, we have $R_j(m) = 0$, so:
$$P_j(m) = R_j(m) + L(m) = 0 + m = m.$$

Peter, when Vasil calls the number $m$, chooses the polynomial $P_j$ correspondi

$$1, 2, 3, \ldots, 50,$$
which is an arithmetic progression with first term $1$ and common difference $1$
. ✓

This achieves $n = 50$ called numbers.
