## Proof

We need to count pairs $(a, b)$ with $a + b = 1000$, $a \geq 1$, $b \geq 1$, whe
re both $a$ and $b$ have no digit equal to $0$ in their standard decimal represe
ntation.

**Key observation.** Write $a$ in 3-digit padded form $a = 100a_2 + 10a_1 + a_0$
 (allowing leading zeros in this representation). Since $a \leq 999$, we have $b
 = 1000 - a \geq 1$.

**Computing $b$'s digits.** If $a_0 \geq 1$, the subtraction $1000 - a$ requires
 borrowing through all zero positions, giving:
$$b = (9 - a_2)\cdot 100 + (9 - a_1)\cdot 10 + (10 - a_0).$$
If $a_0 = 0$, then $b$'s units digit is $0$, which is a non-leading zero (since
$b \geq 1$), so $b$ fails the no-zero condition. **Therefore $a_0 \in \{1,\dots,
9\}$ is necessary**, and then $b_0 = 10 - a_0 \in \{1,\dots,9\}$ automatically.

**Conditions for $b$ to have no zero digit.** With $b_2 = 9-a_2$, $b_1 = 9-a_1$,
 $b_0 = 10-a_0$:
- $b_0 \in \{1,\dots,9\}$ always — no constraint.
- If $b_2 > 0$ (i.e., $a_2 < 9$): $b$ is 3-digit, so $b_1$ must be nonzero, requ
iring $a_1 \neq 9$.
- If $b_2 = 0$ (i.e., $a_2 = 9$): $b_1$ is either a leading zero (dropped) or a
real nonzero digit — no constraint on $a_1$.

**Conditions for $a$ to have no zero digit** (in standard form, leading zeros dr
opped):
- If $a_2 > 0$: $a_2, a_1, a_0 \in \{1,\dots,9\}$.
- If $a_2 = 0, a_1 > 0$: $a_1, a_0 \in \{1,\dots,9\}$.
- If $a_2 = 0, a_1 = 0$: $a_0 \in \{1,\dots,9\}$.

**Combining by cases:**

**Case 1: $a_2 = 0, a_1 = 0$ ($a$ is 1-digit).** $a$'s condition: $a_0 \in \{1,\
dots,9\}$. $b$'s condition: $a_2 = 0 < 9$ requires $a_1 \neq 9$; $a_1 = 0 \neq 9
$ ✓. All 9 values work.
$$\text{Count} = 9.$$

**Case 2: $a_2 = 0, a_1 \geq 1$ ($a$ is 2-digit).** $a$'s condition: $a_1 \in \{
1,\dots,9\}$, $a_0 \in \{1,\dots,9\}$. $b$'s condition: $a_2 = 0 < 9$ requires $
a_1 \neq 9$, so $a_1 \in \{1,\dots,8\}$.
$$\text{Count} = 8 \times 9 = 72.$$

**Case 3: $a_2 \geq 1$ ($a$ is 3-digit).** $a$'s condition: $a_2, a_1, a_0 \in \
{1,\dots,9\}$. $b$'s condition splits:
- **$a_2 = 9$** ($b_2 = 0$): no constraint on $a_1$. Count: $1 \times 9 \times 9
 = 81$.
- **$a_2 \in \{1,\dots,8\}$** ($b_2 > 0$): need $a_1 \neq 9$, so $a_1 \in \{1,\d
ots,8\}$. Count: $8 \times 8 \times 9 = 576$.
$$\text{Count} = 81 + 576 = 657.$$

**Verification of samples:**
- $a = 1, b = 999$: both zero-free ✓
- $a = 89, b = 911$: both zero-free ✓ (Case 2, $a_1 = 8$)
- $a = 91, b = 909$: $b$ has zero ✗ (Case 2, $a_1 = 9$ excluded)
- $a = 191, b = 809$: $b$ has zero ✗ (Case 3, $a_2 = 1 < 9$, $a_1 = 9$ excluded)
- $a = 911, b = 89$: both zero-free ✓ (Case 3, $a_2 = 9$, no constraint on $a_1$
)
- $a = 999, b = 1$: both zero-free ✓

All consistent with the case analysis.

**Total:**
$$9 + 72 + 657 = \boxed{738}.$$
