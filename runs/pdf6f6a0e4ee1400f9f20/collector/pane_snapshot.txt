## Solution

I apply Rouché's Theorem on two circles, $|z| = \frac{5}{4}$ and $|z| = \frac{1}
{2}$, then subtract.

### Step 1: Zeros inside $|z| < \frac{5}{4}$

On $|z| = \frac{5}{4}$, split $P(z) = \underbrace{z^6}_{f(z)} + \underbrace{(1+i
)z + 1}_{g(z)}$.

$$|f(z)| = |z|^6 = \left(\tfrac{5}{4}\right)^6 = \frac{15625}{4096} \approx 3.81
5$$

$$|g(z)| \le |1+i|\,|z| + 1 = \sqrt{2}\cdot\tfrac{5}{4} + 1 = \frac{5\sqrt{2}+4}
{4} \approx 2.768$$

Since $\frac{15625}{4096} > \frac{5\sqrt{2}+4}{4}$ (equivalently $11529 > 5120\s
qrt{2}\approx 7241$), we have $|f|>|g|$ on $|z|=\frac{5}{4}$.

By Rouché's Theorem, $P(z)$ and $f(z)=z^6$ have the same number of zeros inside
$|z|<\frac{5}{4}$, namely **6**. The strict inequality also guarantees no zeros
lie on $|z|=\frac{5}{4}$.

### Step 2: Zeros inside $|z| < \frac{1}{2}$

On $|z| = \frac{1}{2}$, split $P(z) = \underbrace{1}_{f(z)} + \underbrace{z^6 +
(1+i)z}_{g(z)}$.

$$|f(z)| = 1$$

$$|g(z)| \le |z|^6 + |1+i|\,|z| = \frac{1}{64} + \frac{\sqrt{2}}{2} \approx 0.01
56 + 0.7071 = 0.7227$$

Since $1 > \frac{1}{64}+\frac{\sqrt{2}}{2}$, we have $|f|>|g|$ on $|z|=\frac{1}{
2}$.

By Rouché's Theorem, $P(z)$ and $f(z)=1$ have the same number of zeros inside $|
z|<\frac{1}{2}$, namely **0**. The strict inequality guarantees no zeros on $|z|
=\frac{1}{2}$.

### Step 3: Zeros in the annulus $\frac{1}{2}<|z|<\frac{5}{4}$

Since there are no zeros on either boundary circle:

$$N_{\text{annulus}} = N_{|z|<5/4} - N_{|z|\le 1/2} = 6 - 0 = \boxed{6}.$$

### PROOF COMPLETE
