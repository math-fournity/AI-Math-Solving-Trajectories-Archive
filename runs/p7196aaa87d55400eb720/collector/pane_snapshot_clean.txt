## Solution

**Setup.** Let $f(x) = x^4 - 6x^2 + 4$. Setting $y = x^2$ gives $y^2 - 6y + 4 =
0$, so $y = 3 \pm \sqrt{5}$. Hence the four roots are
$$\alpha = \sqrt{3+\sqrt{5}},\quad -\alpha,\quad \beta = \sqrt{3-\sqrt{5}},\quad
 -\beta.$$

**Key relation.** Observe
$$\alpha\beta = \sqrt{(3+\sqrt{5})(3-\sqrt{5})} = \sqrt{9-5} = \sqrt{4} = 2,$$
so $\beta = 2/\alpha$. Therefore the splitting field is
$$L = \mathbb{Q}(\alpha, \beta) = \mathbb{Q}(\alpha),$$
since $\beta$ is a rational function of $\alpha$.

**Irreducibility of $f$.** There are no rational roots ($f(\pm1)=-1$, $f(\pm2)=-
4$, $f(\pm4)\neq 0$). For a factorization into two quadratics $(x^2+ax+b)(x^2-ax
+d)$ over $\mathbb{Q}$: comparing coefficients gives $bd=4$, $b+d-a^2=-6$, $a(d-
b)=0$.

- If $a=0$: $b+d=-6$, $bd=4$, so $b,d$ are roots of $t^2+6t+4=0$, namely $-3\pm\
sqrt{5}\notin\mathbb{Q}$.
- If $d=b$: $b^2=4$, so $b=\pm2$; then $a^2=2b+6$, giving $a^2=10$ or $a^2=2$, n
either rational.

So $f$ is irreducible over $\mathbb{Q}$, and $[L:\mathbb{Q}] = 4$.

**Degree of the extension.** Since $\alpha^2 = 3+\sqrt{5}$, we have $\sqrt{5} =
\alpha^2 - 3 \in \mathbb{Q}(\alpha)$, confirming $L = \mathbb{Q}(\alpha)$ with $
[L:\mathbb{Q}] = \deg f = 4$. As $L$ is the splitting field of a separable polyn
omial (characteristic $0$), $|\operatorname{Gal}(L/\mathbb{Q})| = 4$.

**Determining the automorphisms.** Any $\sigma \in \operatorname{Gal}(L/\mathbb{
Q})$ is determined by $\sigma(\alpha)$, which must be a root of $f$:

1. **$\sigma_1(\alpha) = \alpha$**: the identity.

2. **$\sigma_2(\alpha) = -\alpha$**: Then $\sigma_2(\sqrt{5}) = \sigma_2(\alpha^
2-3) = (-\alpha)^2 - 3 = \sqrt{5}$, and $\sigma_2(\beta) = 2/\sigma_2(\alpha) =
-\beta$. Valid: $\sigma_2$ fixes $\sqrt{5}$, negates $\alpha,\beta$.

3. **$\tau(\alpha) = \beta$**: Then $\tau(\sqrt{5}) = \beta^2 - 3 = (3-\sqrt{5})
-3 = -\sqrt{5}$, and $\tau(\beta) = 2/\tau(\alpha) = 2/\beta = \alpha$ (using $\
alpha\beta=2$). Valid: $\tau$ swaps $\alpha \leftrightarrow \beta$, $-\alpha \le
ftrightarrow -\beta$, and sends $\sqrt{5}\to -\sqrt{5}$.

4. **$\tau\sigma_2(\alpha) = -\beta$**: This is the composition $\tau\circ\sigma
_2$, since $\tau(\sigma_2(\alpha)) = \tau(-\alpha) = -\beta$. It sends $\sqrt{5}
\to -\sqrt{5}$ and $\beta\to -\alpha$.

**Group structure.** Compute:
- $\sigma_2^2(\alpha) = \sigma_2(-\alpha) = \alpha$, so $\sigma_2^2 = 1$.
- $\tau^2(\alpha) = \tau(\beta) = \alpha$, so $\tau^2 = 1$.
- $\sigma_2\tau(\alpha) = \sigma_2(\beta) = 2/\sigma_2(\alpha) = -\beta$.
- $\tau\sigma_2(\alpha) = \tau(-\alpha) = -\beta$.

Since $\sigma_2\tau$ and $\tau\sigma_2$ agree on $\alpha$ (which generates $L$),
 they are equal: $\sigma_2\tau = \tau\sigma_2$.

**Conclusion.** The Galois group has four elements, all of order $2$, and is abe
lian:
$$\operatorname{Gal}(L/\mathbb{Q}) = \{1,\ \sigma_2,\ \tau,\ \sigma_2\tau\} \con
g \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}.$$

This is the **Klein four-group $V_4$**.
