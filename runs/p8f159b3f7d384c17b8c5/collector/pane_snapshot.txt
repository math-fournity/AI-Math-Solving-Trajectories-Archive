## 解题思路

**第一步：建立模型**

设 $X_1, X_2, X_3, \ldots$ 为独立同分布的随机变量，满足 $P(X = k) = 2^{-k}$（$k
\geq 1$）。这是参数为 $p = 1/2$ 的几何分布。

- Unit A 的日志累积：$S_A(j) = X_1 + X_3 + X_5 + \cdots$（奇数轮）
- Unit D 的日志累积：$S_D(j) = X_2 + X_4 + X_6 + \cdots$（偶数轮）

定义 $T(n) = \min\{j : S_j \geq n\}$，即达到阈值 $n$ 所需的轮数。则 $j_A = T(N)$
，$j_D = T'(M)$，二者独立。

A 先手，A 的第 $j$ 轮是第 $2j-1$ 个周期，D 的第 $j$ 轮是第 $2j$ 个周期。因此：
- A 为 Primary 当且仅当 $2j_A - 1 < 2j_D$，即 $j_A \leq j_D$
- D 为 Primary 当且仅当 $j_D < j_A$

这两个事件互补，平衡条件为 $P(T(N) \leq T'(M)) = \frac{1}{2}$。

**第二步：联系二项分布**

关键恒等式：$X_i \sim \text{Geom}(1/2)$（支撑集 $\{1,2,\ldots\}$），$S_j = X_1 +
 \cdots + X_j$ 是获得 $j$ 次成功所需的试验次数。因此 $S_j \geq n$ 当且仅当前 $n-
1$ 次试验中至多 $j-1$ 次成功，即 $\text{Bin}(n-1, 1/2) \leq j-1$。

由此：
$$P(T(n) \leq j) = P(\text{Bin}(n-1, 1/2) \leq j-1)$$

计算 $P(T(N) \leq T'(M))$：

$$P(T(N) \leq T'(M)) = \sum_{j=1}^{\infty} P(T(N)=j)\, P(T'(M) \geq j)$$

其中 $P(T(N)=j) = P(\text{Bin}(N-1, 1/2) = j-1)$，$P(T'(M) \geq j) = P(\text{Bin
}(M-1, 1/2) \geq j-1)$。

令 $i = j-1$，得：
$$P(T(N) \leq T'(M)) = \sum_{i=0}^{N-1} P(\text{Bin}(N-1, 1/2) = i) \cdot P(\tex
t{Bin}(M-1, 1/2) \geq i) = P(B_N \leq B_M)$$

其中 $B_N \sim \text{Bin}(N-1, 1/2)$，$B_M \sim \text{Bin}(M-1, 1/2)$，二者独立
。

**第三步：利用对称性求解**

设 $D = B_N - B_M$。由于 $p = 1/2$ 的二项分布满足 $n - B \sim \text{Bin}(n, 1/2)
$，可以验证 $D$ 关于 $\frac{N-M}{2}$ 对称：

$$D \stackrel{d}{=} (N-M) - D$$

因此 $P(D \leq 0) = P(D \geq N-M)$。

**情形 1：$N - M$ 为奇数。** 此时 $c = \frac{N-M}{2}$ 为半整数，$D$ 为整数，$P(D
 = c) = 0$。由对称性：
$$P(D \leq \lfloor c \rfloor) = \frac{1}{2}$$

需要 $P(D \leq 0) = \frac{1}{2}$，即 $\lfloor c \rfloor = 0$，即 $0 \leq \frac{N
-M}{2} < 1$，即 $N - M = 1$。

验证 $N - M = -1, 3, -3$ 等其他奇数值均不满足 $P(D \leq 0) = \frac{1}{2}$（分别
给出 $P(D \leq 0) > 1/2$ 或 $< 1/2$）。

**情形 2：$N - M$ 为偶数。** 此时 $c$ 为整数，$P(D = c) > 0$：
- $c = 0$（$N = M$）：$P(D \leq 0) = \frac{1 + P(D=0)}{2} > \frac{1}{2}$
- $c > 0$（$N > M$）：$D$ 的均值 $(N-M)/2 > 0$，$P(D \leq 0) < \frac{1}{2}$
- $c < 0$（$N < M$）：$D$ 的均值 $(N-M)/2 < 0$，$P(D \leq 0) > \frac{1}{2}$

均无解。

**唯一解：$N = M + 1 = 2^{2018} + 1$。**

**第四步：计算 $N \bmod 2018$**

$$N \bmod 2018 = (2^{2018} + 1) \bmod 2018$$

$2018 = 2 \times 1009$，其中 $1009$ 为素数。

由中国剩余定理：
- $2^{2018} \equiv 0 \pmod{2}$
- 由费马小定理，$2^{1008} \equiv 1 \pmod{1009}$，故 $2^{2018} = (2^{1008})^2 \cd
ot 2^2 \equiv 4 \pmod{1009}$

求解 $x \equiv 0 \pmod{2}$，$x \equiv 4 \pmod{1009}$：$x = 4$ 满足（$4$ 为偶数，
$4 < 1009$）。

因此 $2^{2018} \equiv 4 \pmod{2018}$，故：
$$N \bmod 2018 = (4 + 1) \bmod 2018 = \boxed{5}$$

**验证（小规模例子）：** 取 $M = 2$，则 $N = 3$。$B_N \sim \text{Bin}(2, 1/2)$，
$B_M \sim \text{Bin}(1, 1/2)$。
$$P(B_N \leq B_M) = \tfrac{1}{4}\cdot\tfrac{1}{2} + \tfrac{1}{4}\cdot\tfrac{1}{2
} + \tfrac{1}{2}\cdot\tfrac{1}{2} = \tfrac{1}{8} + \tfrac{1}{8} + \tfrac{1}{4} =
 \tfrac{1}{2} \checkmark$$
