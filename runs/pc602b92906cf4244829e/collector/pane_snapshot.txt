Looking at this problem, I need to find the maximum number of sides of a convex
polygon where adjacent interior angles always differ by exactly 18°.

## Setup

Let the interior angles be $A_1, A_2, \ldots, A_n$ (cyclically), with $|A_{i+1}
- A_i| = 18°$ for all $i$.

Define offsets: $o_1 = 0$, $o_{i+1} = o_i + d_i$ where $d_i \in \{+1, -1\}$, so
$A_i = A_1 + 18° \cdot o_i$.

Since the walk is closed, $\sum d_i = 0$, so **$n$ must be even**.

## Key Constraints

**Sum constraint:** $\sum A_i = (n-2) \cdot 180°$, giving $A_1 = \frac{180(n-2)
- 18S}{n}$ where $S = \sum o_i$.

**Convexity** ($0 < A_i < 180°$ for all $i$) yields two inequalities:

$$n \cdot \max(o_i) - S < 20 \quad \text{...(I)}$$
$$S - n \cdot \min(o_i) < 10n - 20 \quad \text{...(II)}$$

Let $M = \max(o_i)$, $m = \min(o_i)$, $R = M - m$, and $D_1 = nM - S = \sum(M -
o_i)$.

Constraint (I) becomes: $D_1 \leq 19$ (since $D_1$ is an integer and $D_1 < 20$)
.

## Minimizing the Deficit $D_1$

To maximize $n$, I minimize $D_1 = \sum(M - o_i)$ for a walk with maximum offset
 $M$.

The walk starts at $0$, must reach $M$, and must return to $0$. Going below $0$
only increases $D_1$ (positions below $0$ have deficit $> M$), so optimally $m =
 0$.

The walk decomposes into:
- **Excursion** (0 → M → 0): minimum $2M$ steps, deficit $= \frac{M(M+1)}{2} + \
frac{M(M-1)}{2} = M^2$
- **Oscillation** near $M$: alternating $M, M-1, M, M-1, \ldots$ — each pair add
s 2 steps with deficit $0 + 1 = 1$

So the minimum deficit is:
$$D_1^{\min} = M^2 + \frac{n - 2M}{2}$$

## Maximizing $n$

Setting $D_1^{\min} \leq 19$:
$$M^2 + \frac{n - 2M}{2} \leq 19 \implies n \leq 38 + 2M - 2M^2$$

Maximizing $f(M) = 38 + 2M - 2M^2$ over integers $M \geq 1$:

| $M$ | $n_{\max}$ |
|-----|-----------|
| 1   | 38        |
| 2   | 34        |
| 3   | 26        |
| 4   | 14        |

The maximum is $n = 38$ at $M = 1$.

## Verification for $n = 38$

**Walk:** $0, 1, 0, 1, \ldots, 0, 1$ (19 pairs, 38 positions).

- $D_1 = 19 \leq 19$ ✓ (Constraint I)
- $S = 19$, $\mu = 0.5$, $D_2 = 19 < 10(38) - 20 = 360$ ✓ (Constraint II)
- $A_1 = \frac{180 \times 36 - 18 \times 19}{38} = \frac{6138}{38} = \frac{3069}
{19} \approx 161.53°$
- Angles alternate: $\frac{3069}{19}°$ and $\frac{3411}{19}° \approx 179.53°$, b
oth in $(0°, 180°)$ ✓
- Sum $= 19 \times \frac{3069}{19} + 19 \times \frac{3411}{19} = 3069 + 3411 = 6
480 = 36 \times 180$ ✓
- Exterior angles: $\frac{351}{19}°$ and $\frac{9}{19}°$, all positive, summing
to $360°$ → convex polygon realizable ✓

## $n = 40$ is Impossible

For any $M \geq 1$: $D_1^{\min} = M^2 + \frac{40 - 2M}{2} = M^2 - M + 20 \geq 20
 > 19$. ✗

(For $M=1$: $D_1 = 20$; for $M \geq 2$: even larger.)

## Conclusion

The maximum value of $n$ is $\boxed{38}$.
