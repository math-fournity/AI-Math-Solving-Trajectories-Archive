## Solution

**Key observation.** Since $\alpha = xy + yz + zx$, we can rewrite each factor o
n the left. For instance:

$$1 + \frac{\alpha}{x^2} = \frac{x^2 + xy + yz + zx}{x^2} = \frac{x(x+y) + z(x+y
)}{x^2} = \frac{(x+y)(x+z)}{x^2}.$$

Similarly,

$$1 + \frac{\alpha}{y^2} = \frac{(x+y)(y+z)}{y^2}, \qquad 1 + \frac{\alpha}{z^2}
 = \frac{(x+z)(y+z)}{z^2}.$$

**Rewriting the inequality.** The left-hand side becomes

$$\prod_{\text{cyc}}\left(1+\frac{\alpha}{x^2}\right) = \frac{(x+y)^2\,(y+z)^2\,
(x+z)^2}{x^2\,y^2\,z^2}.$$

The right-hand side factor is

$$\frac{x}{z}+\frac{z}{x}+2 = \frac{(x+z)^2}{xz}.$$

So the inequality is equivalent to

$$\frac{(x+y)^2\,(y+z)^2\,(x+z)^2}{x^2\,y^2\,z^2} \;\geq\; C\cdot\frac{(x+z)^2}{
xz}.$$

Since $x,z>0$, we may cancel $(x+z)^2/(xz)>0$ from both sides, yielding the equi
valent form

$$\frac{(x+y)^2\,(y+z)^2}{x\,y^2\,z} \;\geq\; C. \tag{$\star$}$$

**The constraint disappears.** The expression $\frac{(x+y)^2(y+z)^2}{xy^2 z}$ is
 homogeneous of degree $0$ (numerator and denominator both have degree $4$). The
refore its infimum over the surface $\{xy+yz+zx=\alpha\}$ equals its infimum ove
r all positive reals $x,y,z$. The greatest admissible $C$ is thus

$$C = \inf_{x,\,y,\,z\,>\,0}\;\frac{(x+y)^2\,(y+z)^2}{x\,y^2\,z},$$

which is **independent of $\alpha$**.

**Minimizing.** Set $a = x/y > 0$ and $b = z/y > 0$. Then

$$\frac{(x+y)^2\,(y+z)^2}{x\,y^2\,z} = \frac{(a+1)^2\,(b+1)^2}{a\,b} = \varphi(a
)\cdot\varphi(b),$$

where $\varphi(t) = \frac{(t+1)^2}{t} = t + 2 + \frac{1}{t}$ for $t>0$.

By AM–GM, $t + \frac{1}{t} \geq 2$, so $\varphi(t) \geq 4$, with equality if and
 only if $t = 1$.

Therefore

$$\varphi(a)\,\varphi(b) \;\geq\; 4 \times 4 = 16,$$

with equality if and only if $a = b = 1$, i.e., $x = y = z$.

**Conclusion.** The greatest constant is

$$\boxed{C = 16}.$$

**Equality condition.** Equality holds if and only if $x = y = z$. Under the con
straint $xy + yz + zx = \alpha$, this gives $3x^2 = \alpha$, i.e.,

$$x = y = z = \sqrt{\frac{\alpha}{3}}.$$

**Verification.** At $x=y=z=\sqrt{\alpha/3}$: each factor $1+\alpha/x^2 = 1+3 =
4$, so LHS $= 4^3 = 64$. The RHS factor is $1+1+2=4$, so RHS $= 16\cdot 4 = 64$.
 Both sides agree. ✓
