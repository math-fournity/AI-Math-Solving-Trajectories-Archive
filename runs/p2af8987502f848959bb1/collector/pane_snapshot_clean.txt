## Proof

**Claim:** Yes. Every bounded analytic function on $\mathbb{D}\setminus\{0,1/2,1
/3,\dots\}$ extends to an analytic function on all of $\mathbb{D}$.

Let $S = \{0\}\cup\{1/n : n\ge 2\}$, and let $f$ be analytic and bounded on $\Om
ega := \mathbb{D}\setminus S$, say $|f(z)|\le M$ for all $z\in\Omega$.

**Step 1: Each $1/n$ ($n\ge 2$) is a removable singularity.**

For each $n\ge 2$, the point $a_n = 1/n$ is isolated in $S$: there is a neighbor
hood of $a_n$ containing no other point of $S$. On the punctured neighborhood $U
_n\setminus\{a_n\}\subset\Omega$, $f$ is analytic and bounded (by $M$). By the R
iemann removable singularity theorem, $f$ extends analytically across $a_n$.

Performing this extension for every $n\ge 2$ yields an analytic function $\tilde
 f$ on $\mathbb{D}\setminus\{0\}$. The extended values satisfy $|\tilde f(a_n)|\
le M$ since each is a limit of values bounded by $M$. Hence $|\tilde f(z)|\le M$
 for all $z\in\mathbb{D}\setminus\{0\}$.

**Step 2: $0$ is a removable singularity.**

The function $\tilde f$ is analytic and bounded (by $M$) on the punctured disk $
\mathbb{D}\setminus\{0\}$. By the Riemann removable singularity theorem applied
at $0$, $\tilde f$ extends analytically across $0$.

**Conclusion.** The resulting function is analytic on all of $\mathbb{D}$ and ag
rees with $f$ on $\Omega$. Therefore $f$ can necessarily be extended to an analy
tic function on $\mathbb{D}$.

The key point is that although the singularities $\{1/2,1/3,\dots\}$ accumulate
at $0$, the accumulation point $0$ is itself a singularity at which $f$ is bound
ed, so it too is removable. Boundedness is preserved through each extension, so
the argument chains: isolated singularities first, then the accumulation point.
