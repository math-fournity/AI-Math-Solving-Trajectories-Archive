**Answer: Yes.**

**Construction.** Let $p$ be a prime, and let $K = \mathbb{F}_p(t)$ where $t$ is
 transcendental over $\mathbb{F}_p$. Define
$$L = \bigcup_{n=1}^{\infty} \mathbb{F}_p\!\left(t^{1/p^n}\right) \subseteq \ove
rline{K}.$$
We claim $L/K$ is an infinite algebraic extension with separable degree $[L:K]_s
 = 1$.

---

**Step 1: $L/K$ is algebraic.**

Every element of $L$ lies in some $\mathbb{F}_p(t^{1/p^n})$, which is a finite (
hence algebraic) extension of $K$. Thus $L/K$ is algebraic.

---

**Step 2: Each $\mathbb{F}_p(t^{1/p^n})/K$ is purely inseparable of degree $p^n$
.**

Set $K_n = \mathbb{F}_p(t^{1/p^n})$ and $\alpha_n = t^{1/p^n}$, so $\alpha_n^{p^
n} = t \in K$. Hence $\alpha_n$ is purely inseparable over $K$ and its minimal p
olynomial divides $X^{p^n} - t$.

We show $[K_n : K] = p^n$ by induction on $n$, using the tower
$$K = K_0 \subset K_1 \subset \cdots \subset K_n.$$

*Base case:* $X^p - t$ is irreducible over $K = \mathbb{F}_p(t)$. Indeed, the Fr
obenius gives $(f(t)/g(t))^p = f(t^p)/g(t^p)$, so the set of $p$-th powers in $\
mathbb{F}_p(t)$ is exactly $\mathbb{F}_p(t^p)$. Since $t \notin \mathbb{F}_p(t^p
)$ (as $t$ has degree $p$ over $\mathbb{F}_p(t^p)$), $t$ is not a $p$-th power,
so $X^p - t$ is irreducible. Thus $[K_1:K] = p$.

*Inductive step:* Over $K_k = \mathbb{F}_p(t^{1/p^k})$, the element $\alpha_{k+1
} = t^{1/p^{k+1}}$ satisfies $\alpha_{k+1}^p = \alpha_k$. By the same Frobenius
argument (the $p$-th powers in $K_k$ are $K_k^p = \mathbb{F}_p(t^{1/p^{k-1}}) =
K_{k-1}$), $\alpha_k$ is not a $p$-th power in $K_k$, so $X^p - \alpha_k$ is irr
educible over $K_k$, giving $[K_{k+1}:K_k] = p$.

Therefore $[K_n : K] = p^n$ for every $n$.

---

**Step 3: $L/K$ is infinite.**

Since $K_n \subsetneq K_{n+1}$ for all $n$ (degrees $p^n < p^{n+1}$), the union
$L = \bigcup_n K_n$ is an infinite extension: $[L:K] \geq [K_n:K] = p^n$ for eve
ry $n$, so $[L:K] = \infty$.

---

**Step 4: The separable degree $[L:K]_s$ is finite (in fact, equals $1$).**

Every element $\alpha \in L$ lies in some $K_n$, and $\alpha^{p^n} \in K$ (since
 $K_n/K$ is purely inseparable of exponent $\leq n$). Thus every element of $L$
is purely inseparable over $K$. The separable closure of $K$ in $L$ is therefore
 $K$ itself:
$$\{x \in L : x \text{ is separable over } K\} = K.$$

The separable degree is $[L:K]_s = [K:K] = 1$, which is finite.

---

**Conclusion.** The extension $L = \mathbb{F}_p(t^{1/p}, t^{1/p^2}, t^{1/p^3}, \
dots)$ over $K = \mathbb{F}_p(t)$ is an infinite algebraic extension whose separ
able degree is $1$. Hence such an extension exists. $\blacksquare$
