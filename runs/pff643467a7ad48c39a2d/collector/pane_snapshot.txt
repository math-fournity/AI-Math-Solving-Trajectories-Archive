## Setup

Place C at the origin with legs along axes: C = (0,0), B = (b,0), A = (0,a), whe
re a,b > 0. Then ∠C = 90° and AB is the hypotenuse.

**Finding H (foot of altitude from C to AB):**

Line AB has direction (b,−a). The projection parameter is t = a²/(a²+b²), giving
:
$$H = \left(\frac{a^2 b}{a^2+b^2},\; \frac{a b^2}{a^2+b^2}\right)$$

**Computing the two quantities in the condition:**

- **Distance from H to side BC** (the x-axis) = y-coordinate of H = $\frac{ab^2}
{a^2+b^2}$

- **HA**:
$$HA^2 = \left(\frac{a^2 b}{a^2+b^2}\right)^2 + \left(\frac{ab^2}{a^2+b^2}-a\rig
ht)^2 = \frac{a^4 b^2 + a^6}{(a^2+b^2)^2} = \frac{a^4(a^2+b^2)}{(a^2+b^2)^2} = \
frac{a^4}{a^2+b^2}$$
$$HA = \frac{a^2}{\sqrt{a^2+b^2}}$$

## Applying the condition

Setting distance from H to BC equal to HA:
$$\frac{ab^2}{a^2+b^2} = \frac{a^2}{\sqrt{a^2+b^2}}$$

Dividing by a and multiplying by (a²+b²):
$$b^2 = a\sqrt{a^2+b^2}$$

Squaring: $b^4 = a^2(a^2+b^2)$, i.e., $b^4 - a^2 b^2 - a^4 = 0$.

Setting $r = b^2/a^2$: $r^2 - r - 1 = 0$, so $r = \frac{1+\sqrt{5}}{2} = \varphi
$ (golden ratio).

Thus $b^2 = \varphi\, a^2$ and $a^2 + b^2 = a^2(1+\varphi) = a^2\varphi^2$ (usin
g $1+\varphi=\varphi^2$).

## Computing sin²(∠BDC)

The key observation: D lies on line AB extended beyond B, so line BD coincides w
ith line AB. The altitude from C to line BD equals CH (the altitude from C to AB
):

$$CH = \frac{ab}{\sqrt{a^2+b^2}}$$

In triangle BDC, using the area formula:
$$\text{Area} = \tfrac{1}{2}\cdot BD \cdot CH = \tfrac{1}{2}\cdot BD\cdot DC\cdo
t\sin(\angle BDC)$$

Therefore:
$$\sin(\angle BDC) = \frac{CH}{DC} = \frac{ab/\sqrt{a^2+b^2}}{2b} = \frac{a}{2\s
qrt{a^2+b^2}}$$

(The factor involving BD cancels, so we don't even need to find D's exact positi
on—only that DC = 2b and D lies on line AB.)

Squaring:
$$\sin^2(\angle BDC) = \frac{a^2}{4(a^2+b^2)} = \frac{a^2}{4a^2\varphi^2} = \fra
c{1}{4\varphi^2}$$

Since $\varphi^2 = \frac{3+\sqrt{5}}{2}$:
$$\sin^2(\angle BDC) = \frac{1}{2(3+\sqrt{5})} = \frac{3-\sqrt{5}}{(3+\sqrt{5})(
3-\sqrt{5})\cdot 2/（3-\sqrt{5})}$$

Rationalizing:
$$\sin^2(\angle BDC) = \frac{1}{2(3+\sqrt{5})}\cdot\frac{3-\sqrt{5}}{3-\sqrt{5}}
 = \frac{3-\sqrt{5}}{2(9-5)} = \frac{3-\sqrt{5}}{8}$$
