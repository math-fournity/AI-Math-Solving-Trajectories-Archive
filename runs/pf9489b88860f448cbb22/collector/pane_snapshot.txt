## Proof

We want to find $b$ such that $M_t = e^{5B_t} e^{-bt}$ is a martingale, where $B
_t$ is a standard Brownian motion.

**Step 1: Apply Itô's lemma to $e^{5B_t}$.**

Let $f(x) = e^{5x}$. Then $f'(x) = 5e^{5x}$ and $f''(x) = 25e^{5x}$. By Itô's le
mma, since $dB_t = dB_t$ and $dt$ is the quadratic variation term with $\langle
B\rangle_t = t$:

$$d(e^{5B_t}) = 5e^{5B_t}\,dB_t + \tfrac{1}{2}\cdot 25\,e^{5B_t}\,dt = 5e^{5B_t}
\,dB_t + \tfrac{25}{2}e^{5B_t}\,dt.$$

**Step 2: Apply the product rule to $M_t = e^{5B_t}\cdot e^{-bt}$.**

Using $d(X_t Y_t) = X_t\,dY_t + Y_t\,dX_t + dX_t\,dY_t$, with $X_t = e^{5B_t}$ a
nd $Y_t = e^{-bt}$ (finite variation, so $dY_t = -b\,e^{-bt}\,dt$):

$$dM_t = e^{-bt}\,d(e^{5B_t}) + e^{5B_t}\,d(e^{-bt}).$$

Substituting:

$$dM_t = e^{-bt}\left(5e^{5B_t}\,dB_t + \tfrac{25}{2}e^{5B_t}\,dt\right) + e^{5B
_t}\left(-b\,e^{-bt}\,dt\right).$$

$$dM_t = 5\,M_t\,dB_t + \left(\tfrac{25}{2} - b\right)M_t\,dt.$$

**Step 3: Enforce the martingale condition.**

For $M_t$ to be a (local) martingale, the $dt$ (drift) term must vanish. Since $
M_t > 0$ a.s., this requires:

$$\tfrac{25}{2} - b = 0 \quad\Longrightarrow\quad b = \tfrac{25}{2}.$$

**Step 4: Verify integrability.**

With $b = \tfrac{25}{2}$, we have $M_t = \exp\!\left(5B_t - \tfrac{25}{2}t\right
)$, which is the Doléans-Dade exponential of $5B_t$. Since $5B_t \sim N(0, 25t)$
,

$$\mathbb{E}[M_t] = \mathbb{E}\!\left[e^{5B_t - \frac{25}{2}t}\right] = e^{-\fra
c{25}{2}t}\cdot e^{\frac{1}{2}\cdot 25\,t} = e^{-\frac{25}{2}t}\cdot e^{\frac{25
}{2}t} = 1 = M_0.$$

Thus $\mathbb{E}[M_t] = 1 < \infty$ for all $t$, and $M_t$ is a true martingale
(not merely local).

**Conclusion.**

$$\boxed{b = \dfrac{25}{2}}$$
