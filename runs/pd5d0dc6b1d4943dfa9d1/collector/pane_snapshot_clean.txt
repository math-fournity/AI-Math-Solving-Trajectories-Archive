## Proof

**Yes**, such an enumeration exists. We construct an enumeration $\{r_n\}$ of $\
mathbb{Q}$ such that $\sqrt{2} \notin \bigcup_{n=1}^{\infty}\!\left(r_n-\tfrac{1
}{n},\, r_n+\tfrac{1}{n}\right)$, so the complement is non-empty.

---

### Setup

Fix $x = \sqrt{2}$ (irrational). For each $n \geq 1$ define

$$A_n \;=\; \bigl\{\,r \in \mathbb{Q} : |r - x| \geq \tfrac{1}{n}\,\bigr\} \;=\;
 \mathbb{Q}\setminus\bigl(x-\tfrac{1}{n},\,x+\tfrac{1}{n}\bigr).$$

We seek a bijection $\sigma:\mathbb{N}\to\mathbb{Q}$ with $\sigma(n)\in A_n$ for
 every $n$. Then setting $r_n=\sigma(n)$ gives $|r_n-x|\geq 1/n$, hence $x\notin
\bigl(r_n-\frac1n,\,r_n+\frac1n\bigr)$ for all $n$, and $x$ lies in the compleme
nt.

**Two key observations:**

1. **Each $A_n$ is infinite.** It excludes only the bounded interval $\bigl(x-\f
rac1n,\,x+\frac1n\bigr)$, so infinitely many rationals remain.
2. **Every rational is eventually admissible.** If $q\in\mathbb{Q}$, then $|q-x|
>0$ (since $x$ is irrational), so there exists $N_q$ with $\frac{1}{N_q}\leq |q-
x|$, giving $q\in A_n$ for all $n\geq N_q$.

---

### Construction (back-and-forth)

Fix any enumeration $\mathbb{Q}=\{q_1,q_2,q_3,\dots\}$. We build a partial bijec
tion $\sigma$ from a finite subset of $\mathbb{N}$ to a finite subset of $\mathb
b{Q}$, maintaining $\sigma(n)\in A_n$ throughout. Proceed in stages $k=1,2,3,\do
ts$:

**Forward step (stage $2k-1$):** Let $n$ be the smallest positive integer **not*
* in the domain of $\sigma$. Since $A_n$ is infinite and only finitely many rati
onals have been used, pick any $r\in A_n$ not yet in the range and set $\sigma(n
)=r$.

**Backward step (stage $2k$):** Consider $q_k$. If $q_k$ is already in the range
, do nothing. Otherwise, by observation (2) there exists $N$ such that $q_k\in A
_n$ for all $n\geq N$. Among the infinitely many indices $n\geq N$, only finitel
y many are in the domain of $\sigma$, so pick any unused $n\geq N$ and set $\sig
ma(n)=q_k$.

Both steps are always feasible by observations (1) and (2), and each step preser
ves the constraint $\sigma(n)\in A_n$.

---

### Verification

- **Every $n\in\mathbb{N}$ is in the domain:** The forward step at stage $2k-1$
adds the smallest missing index, so by induction every positive integer is event
ually included.
- **Every $q\in\mathbb{Q}$ is in the range:** The backward step at stage $2k$ en
sures $q_k$ is in the range, so every rational is eventually placed.
- **$\sigma$ is injective:** We always choose unused elements on both sides.
- **Constraint holds:** $\sigma(n)\in A_n$ for all $n$ by construction.

Thus $\sigma$ extends to a bijection $\mathbb{N}\to\mathbb{Q}$. Setting $r_n=\si
gma(n)$:

$$|r_n - \sqrt{2}| \;\geq\; \frac{1}{n} \quad\text{for all } n\geq 1,$$

so $\sqrt{2}\notin\bigl(r_n-\frac1n,\,r_n+\frac1n\bigr)$ for every $n$ (the ineq
uality is non-strict, so $\sqrt{2}$ is at or beyond the endpoint of each *open*
interval). Therefore

$$\sqrt{2}\;\notin\;\bigcup_{n=1}^{\infty}\!\left(r_n-\tfrac{1}{n},\,r_n+\tfrac{
1}{n}\right),$$

and the complement is non-empty. $\blacksquare$
