## Solution

Let the garden's radius be $R$. A chord subtending a central angle $\theta$ has
length $2R\sin(\theta/2)$.

**Setup.** Let $s = \sin(d/2)$ and $c = \cos(d/2)$. From condition 1:
$$2R\sin(d/2) = 22 \implies 2R = \frac{22}{s}.$$

**Express the other two chords.**
- $\text{chord}(2d) = 2R\sin d = \frac{22}{s}\cdot 2sc = 44c.$
- $\text{chord}(3d) = 2R\sin(3d/2) = \frac{22}{s}(3s-4s^3) = 22(3-4s^2) = 66 - 8
8s^2.$

**Apply condition 2:** $\text{chord}(2d) = \text{chord}(3d) + 20$, so
$$44c = (66 - 88s^2) + 20 = 86 - 88s^2.$$

Substitute $s^2 = 1 - c^2$:
$$44c = 86 - 88(1-c^2) = -2 + 88c^2,$$
$$88c^2 - 44c - 2 = 0 \implies 44c^2 - 22c - 1 = 0.$$

**Solve for $c$:**
$$c = \frac{22 \pm \sqrt{484 + 176}}{88} = \frac{22 \pm \sqrt{660}}{88} = \frac{
11 \pm \sqrt{165}}{44}.$$

Since $d < 120$, we have $d/2 < 60°$, so $c = \cos(d/2) > \cos 60° = 0.5$. The r
oot $\frac{11-\sqrt{165}}{44} < 0$ is rejected, giving
$$c = \frac{11+\sqrt{165}}{44}, \qquad d/2 = \arccos(0.542\ldots) \approx 57.2°,
\; d \approx 114.4° < 120.\;\checkmark$$

**Compute $\text{chord}(3d)$:**
$$\text{chord}(3d) = 66 - 88s^2 = 66 - 88(1-c^2) = -22 + 88c^2.$$

Now
$$c^2 = \frac{(11+\sqrt{165})^2}{44^2} = \frac{121 + 22\sqrt{165} + 165}{1936} =
 \frac{286 + 22\sqrt{165}}{1936},$$
$$88c^2 = \frac{88(286 + 22\sqrt{165})}{1936} = \frac{286 + 22\sqrt{165}}{22} =
13 + \sqrt{165}.$$

Therefore
$$\text{chord}(3d) = -22 + 13 + \sqrt{165} = -9 + \sqrt{165}.$$

**Verification.** $\sqrt{165} \approx 12.845$, so $\text{chord}(3d) \approx 3.84
5$ m. Also $\text{chord}(2d) = 44c \approx 23.845$ m, and indeed $23.845 - 3.845
 = 20$. ✓

This matches the required form $-m + \sqrt{n}$ with $m = 9$ and $n = 165$, both
positive integers.

$$m + n = 9 + 165 = \boxed{174}.$$
