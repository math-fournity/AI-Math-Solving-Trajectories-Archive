## Solution

**Notation.** Let $d_{ij} = |a_i - a_j|$ for $i \neq j$. Since the $a_i$ are mut
ually distinct, all $d_{ij} > 0$, and $d_{ij} = d_{ji}$. The system is $A\mathbf
{x} = \mathbf{1}$ where

$$A = \begin{pmatrix} 0 & d_{12} & d_{13} & d_{14} \\ d_{12} & 0 & d_{23} & d_{2
4} \\ d_{13} & d_{23} & 0 & d_{34} \\ d_{14} & d_{24} & d_{34} & 0 \end{pmatrix}
.$$

**Reduction to ordered case.** Relabeling the indices $1,2,3,4$ by a permutation
 $\sigma$ simultaneously permutes the rows and columns of $A$ by the same permut
ation, sending $A$ to $PAP^T$ with $\det(PAP^T) = \det(A)$. The system is theref
ore equivalent under relabeling. We may assume **WLOG** that

$$a_1 < a_2 < a_3 < a_4.$$

**Parametrization.** Set $p = a_2 - a_1 > 0$, $q = a_3 - a_2 > 0$, $r = a_4 - a_
3 > 0$. Then:

$$d_{12} = p,\quad d_{13} = p+q,\quad d_{14} = p+q+r,\quad d_{23} = q,\quad d_{2
4} = q+r,\quad d_{34} = r.$$

**Claim.** The unique solution is

$$\boxed{x_1 = x_4 = \frac{1}{a_4 - a_1} = \frac{1}{p+q+r}, \qquad x_2 = x_3 = 0
.}$$

**Verification.** Substituting into each equation:

- **Eq 1:** $p\cdot 0 + (p+q)\cdot 0 + (p+q+r)\cdot\frac{1}{p+q+r} = 1.$ ✓
- **Eq 2:** $p\cdot\frac{1}{p+q+r} + q\cdot 0 + (q+r)\cdot\frac{1}{p+q+r} = \fra
c{p+q+r}{p+q+r} = 1.$ ✓
- **Eq 3:** $(p+q)\cdot\frac{1}{p+q+r} + q\cdot 0 + r\cdot\frac{1}{p+q+r} = \fra
c{p+q+r}{p+q+r} = 1.$ ✓
- **Eq 4:** $(p+q+r)\cdot\frac{1}{p+q+r} + (q+r)\cdot 0 + r\cdot 0 = 1.$ ✓

The key identity making Eqs 2 and 3 work is the **collinearity (additivity) of d
istances on the real line**: $d_{12} + d_{24} = p + (q+r) = p+q+r = d_{14}$ and
$d_{13} + d_{34} = (p+q) + r = p+q+r = d_{14}$.

**Uniqueness.** We show the homogeneous system $A\mathbf{x} = \mathbf{0}$ has on
ly the trivial solution, i.e., $A$ is invertible. The homogeneous system is:

$$\begin{aligned} p\,x_2 + (p+q)\,x_3 + (p+q+r)\,x_4 &= 0 \quad &(1)\\ p\,x_1 +
q\,x_3 + (q+r)\,x_4 &= 0 \quad &(2)\\ (p+q)\,x_1 + q\,x_2 + r\,x_4 &= 0 \quad &(
3)\\ (p+q+r)\,x_1 + (q+r)\,x_2 + r\,x_3 &= 0 \quad &(4) \end{aligned}$$

**Step 1.** Subtract (2) from (1):

$$p(x_2 - x_1) + p\,x_3 + p\,x_4 = 0 \implies x_1 = x_2 + x_3 + x_4. \quad \text
{(I)}$$

**Step 2.** Subtract (2) from (3):

$$q\,x_1 + q\,x_2 - q\,x_3 - q\,x_4 = 0 \implies x_1 + x_2 = x_3 + x_4. \quad \t
ext{(II)}$$

**Step 3.** Subtract (3) from (4):

$$r\,x_1 + r\,x_2 + r\,x_3 - r\,x_4 = 0 \implies x_4 = x_1 + x_2 + x_3. \quad \t
ext{(III)}$$

**Step 4.** From (I) and (III):

$$x_1 + x_4 = (x_2 + x_3 + x_4) + (x_1 + x_2 + x_3) = x_1 + x_4 + 2(x_2 + x_3),$
$

so $x_2 + x_3 = 0$, i.e., $x_3 = -x_2$.

**Step 5.** From (II): $x_1 + x_2 = x_3 + x_4 = -x_2 + x_4$, giving $x_4 = x_1 +
 2x_2$.
From (I): $x_1 = x_2 + x_3 + x_4 = x_2 - x_2 + x_4 = x_4$.
Hence $x_1 = x_4$ and $x_1 + 2x_2 = x_1$ gives $x_2 = 0$, so $x_3 = 0$.

**Step 6.** Substituting $x_2 = x_3 = 0$ and $x_1 = x_4$ into (2):

$$p\,x_1 + (q+r)\,x_1 = 0 \implies (p+q+r)\,x_1 = 0.$$

Since $p + q + r = a_4 - a_1 > 0$, we get $x_1 = 0$, hence $x_4 = 0$.

All variables are zero, so $A$ is invertible and the solution is **unique**. $\b
lacksquare$

---

**Summary.** Among $a_1, a_2, a_3, a_4$, let $a_s = \min_i a_i$ and $a_t = \max_
i a_i$ (with $s \neq t$). The unique solution to the system is:

$$x_s = x_t = \frac{1}{a_t - a_s}, \qquad x_u = x_v = 0 \quad \text{(where } \{u
,v\} = \{1,2,3,4\} \setminus \{s,t\}\text{)}.$$

That is, the variables corresponding to the **smallest** and **largest** of the
four numbers equal $\frac{1}{\max a_i - \min a_i}$, and the two middle variables
 are zero.
