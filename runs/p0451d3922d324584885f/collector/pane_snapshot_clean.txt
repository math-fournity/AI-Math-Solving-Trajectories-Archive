## Solution

We compute $E(W_6 \mid W_2, W_4)$ for a standard Brownian motion $W$.

**Key fact (independent increments).** For Brownian motion, increments over disj
oint time intervals are independent. In particular, the increment $W_6 - W_4$ is
 independent of the $\sigma$-algebra generated by $\{W_t : 0 \le t \le 4\}$, hen
ce independent of $(W_2, W_4)$.

**Decomposition.** Write
$$W_6 = W_4 + (W_6 - W_4).$$

**Conditioning.** Taking conditional expectation with respect to $(W_2, W_4)$:
$$E(W_6 \mid W_2, W_4) = E\bigl(W_4 + (W_6 - W_4) \mid W_2, W_4\bigr).$$

Since $W_4$ is $\sigma(W_2, W_4)$-measurable, $E(W_4 \mid W_2, W_4) = W_4$. Sinc
e $W_6 - W_4$ is independent of $(W_2, W_4)$ and has mean $0$ (as $W_6 - W_4 \si
m N(0, 2)$),
$$E(W_6 - W_4 \mid W_2, W_4) = E(W_6 - W_4) = 0.$$

Therefore,
$$\boxed{E(W_6 \mid W_2, W_4) = W_4.}$$

**Alternative view (martingale + tower property).** Brownian motion is a marting
ale with respect to its natural filtration $\{\mathcal{F}_t\}$, so $E(W_6 \mid \
mathcal{F}_4) = W_4$. Since $\sigma(W_2, W_4) \subseteq \mathcal{F}_4$, the towe
r property gives
$$E(W_6 \mid W_2, W_4) = E\bigl(E(W_6 \mid \mathcal{F}_4) \mid W_2, W_4\bigr) =
E(W_4 \mid W_2, W_4) = W_4.$$

Both arguments agree.
