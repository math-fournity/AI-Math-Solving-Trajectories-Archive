# Solution

## Setup and Simplification

Given:
- $B = \{1/k \mid k \in \mathbb{N} \setminus \{0\}\} = \{1, 1/2, 1/3, 1/4, \ldot
s\}$ — a countably infinite set.
- $A_n = [0, 1/n]$ — a closed interval.
- $n \in \mathbb{N} \setminus \{0, 1\}$, so $n \geq 2$.

## Computing $B - A_n$

We need $B \setminus A_n = \{1/k \mid k \geq 1\} \setminus [0, 1/n]$.

An element $1/k \in [0, 1/n]$ iff $1/k \leq 1/n$, i.e., $k \geq n$. Therefore:

$$B - A_n = \{1/k \mid 1 \leq k \leq n-1\} = \{1, 1/2, \ldots, 1/(n-1)\}$$

This is a **finite set** with $n-1$ elements. Note the nesting: $B - A_2 \subset
eq B - A_3 \subseteq B - A_4 \subseteq \cdots$, since $A_n$ shrinks as $n$ grows
.

## Identifying the Union

Each $\mathcal{P}(B - A_n)$ is the power set of a finite set, so every element o
f $\mathcal{P}(B - A_n)$ is a **finite** subset of $B$. Thus:

$$\bigcup_{n \geq 2} \mathcal{P}(B - A_n) \subseteq \{F \subseteq B \mid F \text
{ is finite}\}$$

**Conversely**, let $F = \{1/k_1, 1/k_2, \ldots, 1/k_m\}$ be any finite subset o
f $B$. Set $N = \max(k_1, \ldots, k_m)$. For any $n > N$, we have $k_i \leq N <
n$ for all $i$, so each $1/k_i \in B - A_n$, meaning $F \subseteq B - A_n$, henc
e $F \in \mathcal{P}(B - A_n)$.

Therefore:

$$\bigcup_{n \geq 2} \mathcal{P}(B - A_n) = \{F \subseteq B \mid F \text{ is fin
ite}\} = [B]^{<\omega}$$

## Cardinality of the Set of Finite Subsets

The set $[B]^{<\omega}$ of all finite subsets of a countably infinite set $B$ is
 **countably infinite**:

- Subsets of size 0: exactly 1 (the empty set).
- Subsets of size 1: countably infinite (one for each element of $B$).
- Subsets of size $k$ (fixed $k$): countably infinite — can be injected into $\m
athbb{N}^k$, which is countable.
- A countable union ($k = 0, 1, 2, \ldots$) of countable sets is countable.

Since $[B]^{<\omega}$ is infinite (it contains all singletons $\{1/k\}$) and cou
ntable, its cardinality is $\aleph_0$.

## Conclusion

$$\left|\bigcup_{n \in \mathbb{N}\setminus\{0,1\}} \mathcal{P}(B - A_n)\right| =
 \aleph_0$$
