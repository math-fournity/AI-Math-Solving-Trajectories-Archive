## 证明

我们断言：存在一个非零的连续函数 $f$ 满足给定条件。

**第一步：重新表述。** 对于 $k = 0, 1, \ldots, n$，函数 $x^k(1-x)^{n-k}$ 是 Bern
stein 基多项式（忽略二项式系数 $\binom{n}{k}$）。这些 $n+1$ 个多项式中的每一个都
是 $n$ 次多项式，且它们是线性无关的（这是一个标准事实：例如，Bernstein 算子可以
重构多项式，或者可以直接验证它们张成的空间）。由于 $\leq n$ 次多项式空间 $\mathc
al{P}_n$ 的维数为 $n+1$，这些函数构成了 $\mathcal{P}_n$ 的一组基。

因此，条件
$$\int_0^1 x^k(1-x)^{n-k} f(x)\,dx = 0, \quad k = 0, 1, \ldots, n,$$
等价于
$$\int_0^1 p(x)\,f(x)\,dx = 0 \quad \text{对于所有 } p \in \mathcal{P}_n.$$

**第二步：显式构造。** 设 $P_{n+1}(t)$ 为 $n+1$ 次 Legendre 多项式，通过构造（通
过 Gram–Schmidt 正交化）它满足正交关系
$$\int_{-1}^{1} P_{n+1}(t)\,q(t)\,dt = 0 \quad \text{对于所有满足 } \deg q \leq
n \text{ 的多项式 } q.$$

定义 $f(x) = P_{n+1}(2x - 1)$。这是一个 $n+1$ 次多项式，因此它是连续的且不恒为零
。

对于任何 $p \in \mathcal{P}_n$，进行变量代换 $t = 2x - 1$（因此 $x = (t+1)/2$，$
dx = dt/2$）：
$$\int_0^1 p(x)\,P_{n+1}(2x-1)\,dx \;=\; \frac{1}{2}\int_{-1}^{1} p\!\left(\tfra
c{t+1}{2}\right) P_{n+1}(t)\,dt \;=\; 0,$$
因为 $p\!\left(\frac{t+1}{2}\right)$ 是关于 $t$ 的次数 $\leq n$ 的多项式，而 $P_
{n+1}$ 与 $[-1,1]$ 上的所有此类多项式正交。

根据第一步，这得出了对于所有 $k = 0, 1, \ldots, n$，有 $\int_0^1 x^k(1-x)^{n-k}
f(x)\,dx = 0$。

**一致性检查 ($n = 0$)：** 当 $n = 0$ 时，条件简化为 $\int_0^1 f(x)\,dx = 0$，而
我们的构造给出了 $f(x) = P_1(2x-1) = 2x - 1$，这是一个满足积分为零的非零连续函数
。✓

**结论。** 函数 $f(x) = P_{n+1}(2x - 1)$ 是一个满足所有要求条件的非零连续函数。
因此，**是的，对于每个非负整数 $n$，这样的函数都存在。** $\blacksquare$
