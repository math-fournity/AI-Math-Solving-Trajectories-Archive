# Problem

In a specialized telecommunications network, a set of $n$ servers is linked by physical fiber-optic cables. The hardware specifications of these servers strictly limit each unit to a maximum of 3 direct cable connections. The network is designed with a high-redundancy protocol: for any two distinct servers that are not directly connected by a cable, there must be a third server in the network that is directly connected to both of them.

Let $M_1$ represent the maximum possible number of servers $n$ that can exist in such a network configuration.

Now, consider a second scenario where a different engineering team imposes one additional constraint: the network must contain at least one "priority triad," which is a group of three servers where every server in the triad is directly connected to the other two (forming a triangle). Let $M_2$ represent the maximum possible number of servers $n$ under this additional requirement.

Calculate the product of $M_1$ and $M_2$.
