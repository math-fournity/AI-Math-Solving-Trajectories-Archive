## Proof

Define
$$I_n = \int_0^\infty x^{4n-1}\sin(x)\,e^{-x}\,dx,\qquad n\in\mathbb{Z}_{>0}.$$

**Key idea.** Write $\sin x = \operatorname{Im}(e^{ix})$ and use the Laplace-tra
nsform identity
$$\int_0^\infty x^{k}\,e^{-sx}\,dx = \frac{k!}{s^{k+1}},\qquad \operatorname{Re}
(s)>0,\; k\in\mathbb{Z}_{\ge 0}.$$

**Step 1 — Reduce to a complex integral.** Since $e^{-x}\sin x = \operatorname{I
m}\!\big(e^{-(1-i)x}\big)$ and $\operatorname{Re}(1-i)=1>0$,
$$I_n = \operatorname{Im}\!\int_0^\infty x^{4n-1}\,e^{-(1-i)x}\,dx.$$

**Step 2 — Evaluate the complex integral.** Applying the identity with $k=4n-1$
and $s=1-i$,
$$\int_0^\infty x^{4n-1}\,e^{-(1-i)x}\,dx = \frac{(4n-1)!}{(1-i)^{4n}}.$$

Hence
$$I_n = (4n-1)!\;\operatorname{Im}\!\left(\frac{1}{(1-i)^{4n}}\right).$$

**Step 3 — Compute $(1-i)^{4n}$.** In polar form $1-i = \sqrt{2}\,e^{-i\pi/4}$,
so
$$(1-i)^{4n} = \big(\sqrt{2}\big)^{4n}\,e^{-i\pi n} = 2^{2n}\,(-1)^{n} = 4^{n}(-
1)^{n}.$$

This is **real** for every integer $n$. Therefore its reciprocal
$$\frac{1}{(1-i)^{4n}} = \frac{(-1)^{n}}{4^{n}}$$
is also real, and consequently
$$\operatorname{Im}\!\left(\frac{1}{(1-i)^{4n}}\right) = 0.$$

**Step 4 — Conclude.** Since $(4n-1)!\neq 0$,
$$\boxed{I_n = (4n-1)!\cdot 0 = 0\quad\text{for every positive integer } n.}$$

**Sanity checks.**
- $n=1$: $(1-i)^4 = 4\cdot(-1)=-4$, so $I_1 = 3!\,\operatorname{Im}(-1/4)=0$. ✓
- $n=2$: $(1-i)^8 = 16\cdot 1 = 16$, so $I_2 = 7!\,\operatorname{Im}(1/16)=0$. ✓

The vanishing occurs precisely because $4n$ is a multiple of $4$: the argument $
-\pi/4$ of $1-i$ is rotated to $-\pi n$, landing on the real axis. (For exponent
s $k$ with $k+1\not\equiv 0\pmod 4$, the corresponding integral $\int_0^\infty x
^k\sin x\,e^{-x}dx$ is generally nonzero.)
