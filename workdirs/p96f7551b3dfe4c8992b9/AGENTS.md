# Problem

A logistics company manages an infinite sequence of numbered storage containers: $1, 2, 3, \dots$. The company needs to assign a specific security clearance level to each container. There are $n$ possible clearance levels available.

The company’s safety protocol prohibits any four containers—let's call their ID numbers $w, x, y$, and $z$—from having the same security clearance if they satisfy the following structural integrity formula:
$$w + 6x = 2y + 3z$$
(Note that $w, x, y$, and $z$ do not have to be distinct containers; for example, a single container could theoretically fulfill multiple roles in the equation if its ID number permits).

Determine the smallest positive integer $n$ (the minimum number of security clearance levels) required to ensure that no four containers of the same level ever satisfy this equation.
