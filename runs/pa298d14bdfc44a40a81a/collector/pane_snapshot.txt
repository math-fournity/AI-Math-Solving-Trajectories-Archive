## Solution

We check each statement for whether it can be realized by a **bounded** linear o
perator on $H$.

**(b) is possible.** Define $T(e_n) = e_{n+1}$ and extend linearly/continuously.
 This is the **unilateral shift** (forward shift). For $x = \sum_{n=1}^{\infty}
a_n e_n \in H$,
$$\|Tx\|^2 = \sum_{n=1}^{\infty}|a_n|^2 = \|x\|^2,$$
so $T$ is an isometry, hence bounded with $\|T\|=1$. ✓

**(c) is possible.** Define $T(e_1)=0$ and $T(e_n)=e_{n-1}$ for $n\ge 2$. This i
s the **backward shift**. For $x=\sum_{n=1}^{\infty}a_n e_n$,
$$Tx = \sum_{n=2}^{\infty} a_n e_{n-1}, \qquad \|Tx\|^2 = \sum_{n=2}^{\infty}|a_
n|^2 \le \sum_{n=1}^{\infty}|a_n|^2 = \|x\|^2.$$
So $T$ is bounded with $\|T\|\le 1$ (in fact $\|T\|=1$). ✓

d. Consider the unit vectors
$$x_N = \frac{1}{\sqrt{N}}\sum_{n=1}^{N} e_n.$$
Then $\|x_N\|^2 = N\cdot\tfrac{1}{N}=1$, so $\|x_N\|=1$. By linearity,
$$T(x_N) = \frac{1}{\sqrt{N}}\sum_{n=1}^{N} T(e_n) = \frac{1}{\sqrt{N}}\sum_{n=1
}^{N} e_1 = \sqrt{N}\, e_1.$$
Hence $\|T(x_N)\| = \sqrt{N}\to\infty$ while $\|x_N\|=1$. This contradicts the b
oundedness of $T$ (which would require $\|Tx_N\|\le \|T\|\cdot\|x_N\|=\|T\|$).

Therefore statement **(a) cannot be true**.
