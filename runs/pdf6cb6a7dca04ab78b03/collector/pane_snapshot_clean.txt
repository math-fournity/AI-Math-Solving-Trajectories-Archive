## Proof of Theorem 1 (`error_le`)

**Method:** Compare lattice point counts with areas using centered unit squares.

For each (m,n) ∈ ℤ², associate the half-open square S(m,n) = [m−½, m+½) × [n−½,
n+½). These squares partition ℝ² and each has area 1.

**Upper bound.** Let (m,n) with m²+n² ≤ r². For any (x,y) ∈ S(m,n), we have |x−m
| ≤ ½ and |y−n| ≤ ½, so by the triangle inequality and Cauchy–Schwarz:

$$x^2 + y^2 \le (|m|+\tfrac12)^2 + (|n|+\tfrac12)^2 = m^2+n^2 + |m|+|n| + \tfrac
12 \le r^2 + \sqrt{2}\,r + \tfrac12 = \left(r+\tfrac{1}{\sqrt2}\right)^2.$$

Therefore $\bigcup\{S(m,n) : m^2+n^2 \le r^2\} \subseteq \overline{B}(0,\, r+1/\
sqrt2)$, giving:

$$N(r) \le \pi\!\left(r+\tfrac{1}{\sqrt2}\right)^2 = \pi r^2 + \sqrt2\,\pi r + \
tfrac{\pi}{2}.$$

**Lower bound.** Let (x,y) with $x^2+y^2 \le (r - 1/\sqrt2)^2$ (for $r > 1/\sqrt
2$). Let (m,n) be the unique lattice point with (x,y) ∈ S(m,n). Then |x−m| ≤ ½,
|y−n| ≤ ½, so:

$$m^2+n^2 \le (|x|+\tfrac12)^2+(|y|+\tfrac12)^2 = x^2+y^2+|x|+|y|+\tfrac12 \le \
left(r-\tfrac{1}{\sqrt2}\right)^2 + \sqrt2\!\left(r-\tfrac{1}{\sqrt2}\right)+\tf
rac12 = r^2.$$

Therefore $\overline{B}(0,\, r-1/\sqrt2) \subseteq \bigcup\{S(m,n):m^2+n^2\le r^
2\}$, giving:

$$N(r) \ge \pi\!\left(r-\tfrac{1}{\sqrt2}\right)^2 = \pi r^2 - \sqrt2\,\pi r + \
tfrac{\pi}{2}.$$

**Combining:** $|E(r)| = |N(r) - \pi r^2| \le \sqrt2\,\pi r + \tfrac{\pi}{2}$.

For $r \ge \tfrac{1}{2\sqrt2}$, we have $\tfrac{\pi}{2} \le \sqrt2\,\pi r$, henc

This is the **Hardy–Landau theorem** (1915/1920s). It is a deep result in analyt

1. **Theta function connection.** The generating function $\sum_{n=0}^{\infty} r

2. **Partial sums and the error term.** $N(r) = \sum_{k \le r^2} r_2(k)$ is a pa
rtial sum of the coefficients of a modular form. The error $E(r) = N(r) - \pi r^
2$ is governed by the analytic behavior of the associated Dirichlet series / Mel
lin transform.

3. **Voronoi-type summation.** Using the modularity of $\vartheta_3$, one derive
s a summation formula (Voronoi-type) for $\sum_{k \le X} r_2(k)$, expressing the

not cancel below the threshold $r^{1/2}(\log r)^{1/4}$.

— meaning $E(r)$ is **not** $o(r^{1/2}(\log r)^{1/4})$ — by analyzing the behavi
