**Yes, it is possible.**

**Construction.** Let $C \subset [0,1]$ be a fat Cantor set (the Smith–Volterra–
Cantor set), obtained by the standard construction: start with $[0,1]$, remove a
n open interval of length $1/4$ from the middle, then from each of the two remai
ning intervals remove a middle open interval of length $1/16$, then $1/64$, and
so on. The total length removed is

$$\frac{1}{4} + 2\cdot\frac{1}{16} + 4\cdot\frac{1}{64} + \cdots = \frac{1}{4}\s
um_{n=0}^{\infty}\left(\frac{1}{2}\right)^n = \frac{1}{2}.$$

So $C$ is closed and has Lebesgue measure $m(C) = 1 - \tfrac{1}{2} = \tfrac{1}{2
} > 0$. Being a Cantor-type set, $C$ is nowhere dense, hence has empty interior:
 it contains no interval.

**Define** $f:[0,1]\to\mathbb{R}$ by

$$f(x) = d(x, C) = \inf\{|x - c| : c \in C\}.$$

The distance-to-a-closed-set function is continuous (in fact $1$-Lipschitz).

**Zero set.** Since $C$ is closed, $d(x,C)=0$ if and only if $x\in C$. Thus

$$Z(f) = \{x : f(x)=0\} = C,$$

which has measure $m(Z(f)) = m(C) = \tfrac{1}{2} > 0$. In particular $Z(f)$ does
 **not** have measure zero.

**Not zero on any interval.** Suppose $f$ were identically zero on some interval
 $I$. Then $I\subseteq Z(f)=C$, contradicting that $C$ has empty interior (conta
ins no interval). Hence $f$ is not identically zero on any interval.

**Conclusion.** The function $f(x)=d(x,C)$ is continuous, is not zero on any int
erval, yet its zero set equals the fat Cantor set $C$ of measure $\tfrac{1}{2}$,
 which is not of measure zero. Therefore such a function exists.
