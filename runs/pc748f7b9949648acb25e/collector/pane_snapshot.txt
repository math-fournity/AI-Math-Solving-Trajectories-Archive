Looking at this problem, I need to find the maximum number of unit-length sensor
s that form a minimal cover of [0,100].

## Setup

Sort sensors by left endpoint: $a_1 < a_2 < \cdots < a_N$ (distinct, since two s
ensors with the same start are mutually redundant).

**Coverage conditions:** $a_1 = 0$, $a_N = 99$, and $a_{i+1} \leq a_i + 1$ (no g
aps between consecutive sensors).

**Minimality condition:** Removing sensor $i$ must create a gap. The union of al
l sensors except $i$ equals $[0, a_{i-1}+1] \cup [a_{i+1}, 100]$ (sensors to the
 left cover $[0, a_{i-1}+1]$ continuously; sensors to the right cover $[a_{i+1},
 100]$ continuously). Sensor $i$ is essential iff $[a_i, a_i+1] \not\subseteq [0
, a_{i-1}+1] \cup [a_{i+1}, 100]$, which holds iff $a_{i-1}+1 < a_{i+1}$, i.e.:

$$a_{i+1} - a_{i-1} > 1 \quad \text{(strict inequality)}$$

The boundary sensors $i=1$ and $i=N$ are always essential (by distinctness and c
overage).

## Reduction to Gap Sequence

Define gaps $d_i = a_{i+1} - a_i > 0$ for $i = 1, \ldots, n$ where $n = N-1$. Th
en:
- $d_i \leq 1$ (coverage)
- $d_{i-1} + d_i > 1$ for $i = 2, \ldots, n$ (minimality)
- $\sum_{i=1}^{n} d_i = a_N - a_1 = 99$

## Upper Bound

**Pair the gaps:** $(d_1, d_2), (d_3, d_4), \ldots$ Each pair $(d_{2k-1}, d_{2k}
)$ satisfies $d_{2k-1} + d_{2k} > 1$ (minimality at $i = 2k$).

- **If $n = 2m$ (even):** $m$ pairs, each summing to $> 1$, so $\sum d_i > m$. S
ince $\sum = 99$, we get $m < 99$, so $m \leq 98$, $n \leq 196$, $N \leq 197$.

- **If $n = 2m+1$ (odd):** $m$ pairs plus $d_{2m+1} > 0$, so $\sum d_i > m$. Sin
ce $\sum = 99$, we get $m < 99$, so $m \leq 98$, $n \leq 197$, $N \leq 198$.

Therefore $N \leq 198$.

## Construction Achieving $N = 198$

Set $n = 197$ gaps. Choose:
- $d_{2k-1} = \tfrac{1}{196}$ for $k = 1, \ldots, 98$
- $d_{2k} = 1$ for $k = 1, \ldots, 98$
- $d_{197} = \tfrac{1}{2}$

**Verification:**
- All $d_i > 0$: ✓
- All $d_i \leq 1$: ✓ ($\frac{1}{196} \leq 1$, $1 \leq 1$, $\frac{1}{2} \leq 1$)
- $d_{2k-1} + d_{2k} = \frac{1}{196} + 1 = \frac{197}{196} > 1$: ✓
- $d_{2k} + d_{2k+1} = 1 + \frac{1}{196} = \frac{197}{196} > 1$ for $k = 1, \ldo
ts, 97$: ✓
- $d_{196} + d_{197} = 1 + \frac{1}{2} = \frac{3}{2} > 1$: ✓
- $\sum d_i = 98 \cdot \frac{197}{196} + \frac{1}{2} = \frac{197}{2} + \frac{1}{
2} = 99$: ✓

This gives $a_1 = 0$, $a_{198} = 99$, with all coverage and minimality condition
s satisfied.

## Conclusion

The maximum possible number of sensors is:

$$\boxed{N = 198}$$
