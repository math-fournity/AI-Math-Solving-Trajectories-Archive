## Proof

**Setup and reduction.** Let $s = a+b+c$, $q = ab+bc+ca$, $p = abc$. The constra
int is $q = s-1$. The inequality becomes:
$$(s-2)^2 \ge k \cdot p(s-3).$$

**Case 1: $p(s-3) \le 0$.** The RHS is $\le 0$ (for $k>0$) while LHS $\ge 0$, so
 the inequality holds trivially.

**Case 2: $p(s-3) > 0$.** We seek the infimum of $F = \frac{(s-2)^2}{p(s-3)}$.

**Discriminant constraint.** Since $a,b,c$ are real roots of $t^3 - st^2 + (s-1)
t - p = 0$, the discriminant must be non-negative:
$$\Delta = -27p^2 - 2ps(2s-3)(s-3) + (s-1)^2(s-2)^2 \ge 0.$$
This is a downward-opening parabola in $p$, so the valid range is $p \in [p_-, p
_+]$ where $\Delta(p_\pm) = 0$.

**Key computation.** Define $p^* = \frac{8(s-2)^2}{27(s-3)}$. Substituting into
$\Delta$:

$$\Delta(p^*) = (s-2)^2\left[-\frac{64(s-2)^2}{27(s-3)^2} - \frac{16s(2s-3)}{27}
 + (s-1)^2\right].$$

Putting over common denominator $27(s-3)^2$, the numerator becomes:

$$N = 27(s-1)^2(s-3)^2 - 16s(2s-3)(s-3)^2 - 64(s-2)^2.$$

Expanding and collecting:

$$N = -5s^4 + 24s^3 - 46s^2 + 40s - 13.$$

**Factoring.** Testing $s=1$: $N(1) = -5+24-46+40-13 = 0$. Dividing:

$$N = (s-1)(-5s^3+19s^2-27s+13).$$

Testing $s=1$ again: $-5+19-27+13=0$. Dividing:

$$N = (s-1)^2(-5s^2+14s-13).$$

The quadratic $-5s^2+14s-13$ has discriminant $196-260 = -64 < 0$ with negative
leading coefficient, so $-5s^2+14s-13 < 0$ for all real $s$. Therefore:

$$\Delta(p^*) = \frac{(s-2)^2(s-1)^2(-5s^2+14s-13)}{27(s-3)^2} \le 0 \quad \text
{for all } s \neq 3,$$

with equality only at $s=1$ or $s=2$.

**Consequence.** Since $\Delta$ is a downward parabola in $p$ with $\Delta \ge 0
$ on $[p_-, p_+]$, and $\Delta(p^*) \le 0$, the value $p^*$ lies outside (or on
the boundary of) the valid interval $[p_-, p_+]$.

- **Sub-case 2a ($s > 3$, $p > 0$):** Here $p^* > 0$. At $s=1$ and $s=2$, $p^* =
 p_-$ (the lower root). As $s \to 3^+$, $p^* \to +\infty > p_+$. Since $\Delta(p
^*) < 0$ strictly for all $s > 3$, $p^*$ cannot cross through $[p_-, p_+]$, so $
p^* \ge p_+$ for all $s > 3$. Thus every valid $p$ satisfies $p \le p_+ \le p^*$
, and since $s-3 > 0$:
$$p(s-3) \le p^*(s-3) = \frac{8(s-2)^2}{27}.$$

- **Sub-case 2b ($s < 3$, $p < 0$):** Here $p^* < 0$. At $s=1$: $p^* = -4/27 = p
_-$. At $s=2$: $p^* = 0 = p_-$. By continuity and $\Delta(p^*) < 0$ (strict for
$s \neq 1,2$), $p^*$ cannot cross through $[p_-, p_+]$, so $p^* \le p_-$ for all
 $s < 3$. Thus every valid $p$ satisfies $p \ge p_- \ge p^*$, and since $s-3 < 0
$ (inequality flips):
$$p(s-3) \le p^*(s-3) = \frac{8(s-2)^2}{27}.$$

In both sub-cases: $\frac{(s-2)^2}{p(s-3)} \ge \frac{27}{8}$, so the inequality
holds with $k = \frac{27}{8}$.

**Sharpness.** At $a = b = \frac{2}{3}$, $c = -\frac{1}{3}$:
- Constraint: $ab+bc+ca = \frac{4}{9} - \frac{2}{9} - \frac{2}{9} = 0$, and $a+b
+c = 1$, so $0 + 1 = 1$. ✓
- LHS: $(0-1)^2 = 1$.
- RHS factor: $abc(a+b+c-3) = \frac{4}{9}\cdot(-\frac{1}{3})\cdot(-2) = \frac{8}
{27}$.
- Ratio: $\frac{1}{8/27} = \frac{27}{8}$.

Equality holds, so $k$ cannot exceed $\frac{27}{8}$.

**Conclusion.** The largest constant is:

$$\boxed{k = \dfrac{27}{8}}$$
