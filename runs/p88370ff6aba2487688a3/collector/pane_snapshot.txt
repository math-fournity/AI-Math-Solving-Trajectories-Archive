## Part (a): Solving the mixed boundary value problem

**Setup.** Following the hint, assume $u(x,y) = X(x) + Y(y)$. Then $u_{xx} = X''
(x)$ and $u_{yy} = Y''(y)$, and the PDE becomes

$$x^2 X''(x) - y^2 Y''(y) = 1.$$

**Separation.** The left term depends only on $x$ and the second only on $y$, ye
t their difference is the constant $1$. Hence each must be a constant:

$$x^2 X''(x) = c, \qquad y^2 Y''(y) = c - 1.$$

**Solving the ODEs.**

For $X$: $X''(x) = c/x^2$, so
$$X'(x) = -\frac{c}{x} + a_1, \qquad X(x) = -c\ln x + a_1 x + a_0.$$

For $Y$: $Y''(y) = (c-1)/y^2$, so
$$Y'(y) = -\frac{c-1}{y} + b_1, \qquad Y(y) = -(c-1)\ln y + b_1 y + b_0.$$

Thus
$$u(x,y) = -c\ln x - (c-1)\ln y + a_1 x + b_1 y + (a_0+b_0).$$

**Applying the boundary conditions.**

*From $u(x,1) = \ln x$ (using $\ln 1 = 0$):*
$$-c\ln x + a_1 x + b_1 + (a_0+b_0) = \ln x, \quad \forall x>1.$$

Matching coefficients of $\ln x$, $x$, and the constant:
$$-c = 1 \;\Rightarrow\; c = -1, \qquad a_1 = 0, \qquad b_1 + (a_0+b_0) = 0. \ta
g{1}$$

*From $u_y(x,1) = 2$:* Since $u_y = -(c-1)/y + b_1$,
$$-(c-1) + b_1 = 2.$$
With $c=-1$: $-(-2) + b_1 = 2 \;\Rightarrow\; b_1 = 0$. Then from (1), $a_0+b_0
= 0$.

*From $u(1,y) = 2\ln y$ (using $\ln 1 = 0$, $a_1=b_1=0$, $a_0+b_0=0$):*
$$-(c-1)\ln y = 2\ln y.$$
With $c=-1$: $-(-2)\ln y = 2\ln y$ ✓ — automatically satisfied.

**Solution.** Substituting $c=-1$, $a_1=b_1=0$, $a_0+b_0=0$:

$$\boxed{u(x,y) = \ln x + 2\ln y.}$$

**Verification.**
- $u_{xx} = -1/x^2$, $u_{yy} = -2/y^2$, so $x^2 u_{xx} - y^2 u_{yy} = -1-(-2) =
1$ ✓
- $u(x,1) = \ln x$ ✓
- $u_y = 2/y$, so $u_y(x,1) = 2$ ✓
- $u(1,y) = 2\ln y$ ✓

## Part (b): Characteristics of the PDE

The PDE $x^2 u_{xx} - y^2 u_{yy} = 1$ has coefficients $A = x^2$, $2B = 0$, $C =
 -y^2$. The discriminant is

$$B^2 - AC = 0 - x^2(-y^2) = x^2 y^2 > 0 \quad (x,y>1),$$

so the equation is **hyperbolic** throughout the domain.

The characteristic equation $A\,(dy)^2 - 2B\,dx\,dy + C\,(dx)^2 = 0$ gives

$$x^2 (dy)^2 - y^2 (dx)^2 = 0 \;\Longrightarrow\; x\,dy = \pm\, y\,dx \;\Longrig
htarrow\; \frac{dy}{y} = \pm \frac{dx}{x}.$$

Integrating: $\ln y = \pm \ln x + \text{const}$, i.e.

$$\frac{y}{x} = \text{const} \qquad\text{and}\qquad xy = \text{const}.$$

**The two families of characteristics are the curves $xy = \text{const}$ and $y/
x = \text{const}$.**
