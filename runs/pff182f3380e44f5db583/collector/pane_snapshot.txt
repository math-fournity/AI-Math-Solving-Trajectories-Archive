## Proof

**Answer: Yes, such a partition exists.**

### Reformulation

Let $A, B$ be a partition of $\mathbf{N}_+$ with $B = \mathbf{N}_+ \setminus A$.

**Condition 2** says $B$ contains no infinite non-constant arithmetic progressio
n, i.e., there is no set $\{a, a+d, a+2d, \dots\}$ (with $d \ge 1$) entirely con
tained in $B$. Such a progression is contained in $B$ iff it is disjoint from $A
$, i.e., iff $A$ has **no** element $\ge a$ in the residue class $a \pmod d$. He
nce:

> Condition 2 holds $\iff$ for every $d \ge 1$ and every residue $r \in \{0,1,\d
ots,d-1\}$, the set $A \cap \{n : n \equiv r \pmod d\}$ is **unbounded** (equiva
lently, infinite).

So we need $A$ to be (i) free of 3-term arithmetic progressions, and (ii) unboun
ded in every residue class modulo every $d \ge 1$.

### Key Lemma

**Lemma.** Let $S \subset \mathbf{N}_+$ be a finite 3-AP-free set, and let $r \p
mod d$ be any residue class. Then there exist arbitrarily large $n \equiv r \pmo
d d$ such that $S \cup \{n\}$ is still 3-AP-free.

*Proof.* Since $S$ is 3-AP-free, any 3-AP in $S \cup \{n\}$ must involve $n$ tog
ether with two elements $s_1 < s_2 \in S$. Three values $n, s_1, s_2$ form a 3-A
P only if the middle one equals the average of the other two. This gives at most
 three forbidden values of $n$ per pair $(s_1, s_2)$:
- $n < s_1 < s_2$: $s_1 = \tfrac{n+s_2}{2}$, so $n = 2s_1 - s_2$;
- $s_1 < n < s_2$: $n = \tfrac{s_1+s_2}{2}$ (only if $s_1+s_2$ is even);
- $s_1 < s_2 < n$: $s_2 = \tfrac{s_1+n}{2}$, so $n = 2s_2 - s_1$.

There are $\binom{|S|}{2}$ pairs, hence only finitely many forbidden values. The
 residue class $r \pmod d$ contains infinitely many positive integers, so infini
tely many of them are **not** forbidden. In particular we can choose one exceedi
ng any prescribed bound. $\square$

### Construction

Enumerate all triples $(d, r, k)$ with $d \ge 1$, $0 \le r < d$, $k \ge 1$, as $
(d_1, r_1, k_1), (d_2, r_2, k_2), \dots$. We build an increasing sequence of fin
ite 3-AP-free sets $S_0 \subset S_1 \subset S_2 \subset \cdots$.

Start with $S_0 = \emptyset$. At stage $i \ge 1$, consider the requirement $(d_i
, r_i, k_i)$. By the Lemma, choose $n_i \equiv r_i \pmod{d_i}$ with $n_i > \max
S_{i-1}$ and $S_{i-1} \cup \{n_i\}$ 3-AP-free. Set $S_i = S_{i-1} \cup \{n_i\}$.

Let $A = \bigcup_{i \ge 0} S_i$ and $B = \mathbf{N}_+ \setminus A$.

### Verification

**$A$ is 3-AP-free.** Any three elements of $A$ all lie in some $S_i$ (since $A
= \bigcup S_i$ and the $S_i$ are nested and each element is added at a finite st
age). Each $S_i$ is 3-AP-free by construction, so no three elements of $A$ form
an arithmetic progression. ✓

**$A$ is unbounded in every residue class mod $d$.** Fix $d \ge 1$ and residue $
r$. For every $k \ge 1$, the triple $(d, r, k)$ appears as some $(d_i, r_i, k_i)
$ in the enumeration, and at that stage we added an element $n_i \equiv r \pmod
d$ with $n_i > \max S_{i-1}$. Since the sequence $(\max S_i)$ is strictly increa
sing and tends to infinity, the elements added for $(d, r, 1), (d, r, 2), \dots$
 are distinct and tend to infinity. Hence $A \cap \{n : n \equiv r \pmod d\}$ is
 infinite. ✓

**$B$ contains no infinite non-constant AP.** By the reformulation, since $A$ is
 unbounded in every residue class mod $d$ for every $d \ge 1$, no infinite arith
metic progression $\{a, a+d, a+2d, \dots\}$ ($d \ge 1$) can be entirely containe
d in $B$. ✓

### Conclusion

The partition $A, B$ constructed above satisfies both conditions: $A$ is free of
 3-term arithmetic progressions, and $B$ contains no infinite non-constant arith
metic progression. Therefore **such a partition is possible**.
