## Solution

Let $\alpha = 3 + 2\sqrt{2}$ and $\beta = 3 - 2\sqrt{2}$. Observe:

- $\alpha\beta = 9 - 8 = 1$, so $\beta = 1/\alpha$.
- $\alpha + \beta = 6$.
- $\alpha > 1$ and $0 < \beta < 1$.

Both $\alpha$ and $\beta$ are roots of the quadratic $x^2 - 6x + 1 = 0$. Define

$$S_n = \alpha^n + \beta^n.$$

Since $\alpha$ and $\beta$ satisfy $x^2 = 6x - 1$, the sequence $S_n$ satisfies
the recurrence

$$S_n = 6S_{n-1} - S_{n-2}, \qquad S_0 = 2,\; S_1 = 6.$$

By induction, **$S_n$ is an integer for every $n \geq 0$**.

Now rewrite:

$$\alpha^n = S_n - \beta^n.$$

Since $0 < \beta < 1$, for every $n \geq 1$ we have $0 < \beta^n < 1$. Therefore

$$S_n - 1 < \alpha^n < S_n,$$

which gives $\lfloor \alpha^n \rfloor = S_n - 1$. Hence the fractional part is

$$\{(3+2\sqrt{2})^n\} = \alpha^n - \lfloor \alpha^n \rfloor = (S_n - \beta^n) -
(S_n - 1) = 1 - \beta^n = 1 - (3-2\sqrt{2})^n.$$

As $n \to \infty$, since $0 < 3 - 2\sqrt{2} < 1$, we have $(3-2\sqrt{2})^n \to 0
$, and therefore

$$\lim_{n\to\infty}\{(3+2\sqrt{2})^n\} = 1 - 0 = \boxed{1}.$$

### PROOF COMPLETE
