## Proof

**Yes, such a function exists.**

### Step 1: Construct a suitable discontinuity set $D$.

Let $\{q_n\}_{n=1}^\infty$ be an enumeration of $\mathbb{Q}\cap(0,1)$. For each
$n$, set $r_n = \tfrac{1}{4n}$, and let $F_n$ be a **fat Cantor set** (closed, n
owhere dense, positive Lebesgue measure, no isolated points — hence uncountable)
 contained in $(q_n - r_n,\; q_n + r_n)\cap(0,1)$. Such sets exist: a Smith–Volt
erra–Cantor–type construction yields a nowhere-dense closed set of positive meas
ure inside any open interval.

Define
$$D = \bigcup_{n=1}^{\infty} F_n.$$

### Step 2: $D$ is a dense $F_\sigma$, and $D\cap I$ is uncountable for every op
en interval $I\subseteq(0,1)$.

Each $F_n$ is closed, so $D$ is $F_\sigma$. Each $F_n$ is nowhere dense, so $D$
is **meager**.

**$D$ is dense and meets every interval uncountably.** Let $I=(a,b)\subseteq(0,1
)$ and set $\delta=\tfrac{b-a}{4}$. The subinterval $(a+\delta,\; b-\delta)$ con
tains infinitely many rationals; pick $q_m\in(a+\delta,\,b-\delta)$ with $m$ lar
ge enough that $r_m<\delta$. Then
$$F_m \subseteq (q_m-r_m,\; q_m+r_m) \subseteq (a+\delta-\delta,\; b-\delta+\del
ta)=(a,b)=I.$$
Since $F_m$ is a fat Cantor set, it is uncountable (cardinality continuum). Henc
e $D\cap I\supseteq F_m$ is **uncountable**.

### Step 3: The complement $C=(0,1)\setminus D$ is a dense $G_\delta$, and $C\ca
p I$ is uncountable for every open interval $I$.

Since $D$ is $F_\sigma$, $C$ is $G_\delta$. Since $D$ is meager, the **Baire Cat
egory Theorem** implies $C$ is comeager in $(0,1)$, hence dense. For any open in
terval $I\subseteq(0,1)$, the set $D\cap I$ is meager in $I$, so $C\cap I = I\se
tminus(D\cap I)$ is comeager in $I$; by Baire's theorem $C\cap I$ is **uncountab
le** (indeed of cardinality continuum).

### Step 4: Realize $C$ as the continuity set of a function.

By the classical characterization (Young's theorem): *a set $E\subseteq\mathbb{R
}$ is the set of continuity points of some function $f:\mathbb{R}\to\mathbb{R}$
if and only if $E$ is a $G_\delta$ set.*

Since $C$ is $G_\delta$, there exists a function $f:(0,1)\to\mathbb{R}$ whose se
t of continuity points is exactly $C$ and whose set of discontinuity points is e

### Step 5: Verification.

Let $U\subseteq(0,1)$ be any neighborhood; $U$ contains some open interval $I\su
bseteq(0,1)$.

- **Continuity points in $U$:** include $C\cap I$, which is uncountable. ✓
- **Discontinuity points in $U$:** include $D\cap I$, which is uncountable. ✓

Therefore $f$ has uncountably many continuity points and uncountably many discon
tinuity points in **every** neighborhood contained in $(0,1)$. $\blacksquare$
