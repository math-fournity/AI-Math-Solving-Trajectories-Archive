Looking at this problem, I need to find $m(n)$, the maximum number of active nod
es in a Critical configuration on an $n \times n$ grid, for $n = 5, 6, 7, 8, 9,
10$.

## Key Structural Observation

**Definition recap:** A configuration is *Stable* if every row and column has ≥
2 active nodes. It is *Critical* if Stable, and removing any single active node
makes it unstable.

**Lemma 1 (Essential Node Property).** In a Critical configuration, every active
 node lies in a row with exactly 2 active nodes or a column with exactly 2 activ
e nodes.

*Proof.* Suppose active node at $(i,j)$ lies in a row with $\geq 3$ active nodes
 AND a column with $\geq 3$ active nodes. Removing it leaves row $i$ with $\geq
2$ and column $j$ with $\geq 2$, so the configuration remains Stable — contradic
ting Criticality. $\square$

## Setting Up the Framework

Partition rows into **light** ($r_i = 2$) and **heavy** ($r_i \geq 3$); similarl
y columns into **light** ($c_j = 2$) and **heavy** ($c_j \geq 3$). Let $a$ = num
ber of light rows, $b$ = number of light columns.

By Lemma 1, the **heavy×heavy block** (heavy rows × heavy columns) contains **no
 active nodes**.

The grid splits into four blocks:
- **LL** ($a \times b$): $N_{LL}$ nodes
- **LH** ($a \times (n{-}b)$): $N_{LH}$ nodes
- **HL** ($(n{-}a) \times b$): $N_{HL}$ nodes
- **HH**: empty

**Counting constraints:**
- Light rows have exactly 2 each: $N_{LL} + N_{LH} = 2a$
- Light columns have exactly 2 each: $N_{LL} + N_{HL} = 2b$
- Heavy rows (≥3 each, all in light columns): $N_{HL} \geq 3(n{-}a)$ when $n > a
$
- Heavy columns (≥3 each, all in light rows): $N_{LH} \geq 3(n{-}b)$ when $n > b
$

**Total:** $N = N_{LL} + N_{LH} + N_{HL} = 2a + 2b - N_{LL}$.

To maximize $N$, minimize $N_{LL} \geq 0$.

## Upper Bound

**Case 1: Both heavy rows and heavy columns exist** ($a < n$, $b < n$).

Setting $N_{LL} = 0$ gives $N = 2a + 2b$, with constraints:
$$2a \geq 3(n-b), \quad 2b \geq 3(n-a)$$

**Capacity constraints:** $N_{LH} = 2a$ must fit in $a \times (n{-}b)$ cells, re
quiring $n - b \geq 2$, i.e., $b \leq n{-}2$. Similarly $a \leq n{-}2$.

So maximize $a + b$ subject to $a \leq n{-}2$, $b \leq n{-}2$, $2a + 3b \geq 3n$
, $3a + 2b \geq 3n$.

At $a = b = n{-}2$: check $5(n{-}2) \geq 3n \iff 2n \geq 10 \iff n \geq 5$. ✓

Since both $a, b \leq n{-}2$, we get $a + b \leq 2(n{-}2)$, so $N \leq 4(n{-}2)$
.

**Case 2: $a = n$ (all rows light).** Then $N = 2n$, and every column must have
≥ 2, forcing all columns to have exactly 2. So $N = 2n < 4(n{-}2)$ for $n \geq 5
$.

**Case 3: $a = n{-}1$.** Capacity forces $N_{LL} \geq b$, giving $N \leq 2(n{-}1
) + 2b - b = 2n - 2 + b \leq 3n - 4 < 4n - 8$ for $n \geq 5$.

All other cases are symmetric or worse. **Therefore $m(n) \leq 4(n-2)$ for $n \g
eq 5$.**

## Construction Achieving the Bound

For $n \geq 5$, set $a = b = n - 2$:
- **Light rows** $1, \ldots, n{-}2$; **heavy rows** $n{-}1, n$
- **Light columns** $1, \ldots, n{-}2$; **heavy columns** $n{-}1, n$
- **LL block:** empty
- **LH block:** each light row $i$ activates $(i, n{-}1)$ and $(i, n)$ — one in
each heavy column
- **HL block:** each light column $j$ activates $(n{-}1, j)$ and $(n, j)$ — one
in each heavy row
- **HH block:** empty

**Verification:**
- Each light row: 2 active nodes ✓
- Each heavy row: $n - 2 \geq 3$ active nodes ✓
- Each light column: 2 active nodes ✓
- Each heavy column: $n - 2 \geq 3$ active nodes ✓
- **Critical:** Every active node in LH is in a light row (removing it → row has
 1); every active node in HL is in a light column (removing it → column has 1).
All removals cause instability. ✓

**Total:** $2(n{-}2) + 2(n{-}2) = 4(n{-}2)$. ✓
