## Proof

We work in the Hilbert space $\ell_2$ with inner product $\langle x, y \rangle =
 \sum_{k=1}^{\infty} x_k y_k$.

**The set.** Define
$$M = \left\{ x \in \ell_2 : \sum_{k=1}^{n} x_k = 0 \right\}.$$

**Claim.** $M^{\perp} = \left\{ \lambda(1,1,\dots,1,0,0,\dots) : \lambda \in \ma
thbb{R} \right\}$, where the vector has $n$ copies of $1$ followed by zeros.

**Step 1: Identify $M$ as the kernel of a continuous linear functional.**

Define $a = (1,1,\dots,1,0,0,\dots) \in \ell_2$ (with $n$ ones). Since $a \in \e
ll_2$ (it has only finitely many nonzero entries), the map
$$f(x) = \langle x, a \rangle = \sum_{k=1}^{n} x_k$$
is a continuous linear functional on $\ell_2$ (by Cauchy–Schwarz, $|f(x)| \le \|
a\| \cdot \|x\|$). Therefore
$$M = \ker f = \{x \in \ell_2 : \langle x, a \rangle = 0\} = \{a\}^{\perp}.$$

**Step 2: Compute $M^{\perp}$.**

Since $M = \{a\}^{\perp}$, we have
$$M^{\perp} = \left(\{a\}^{\perp}\right)^{\perp} = \overline{\operatorname{span}
\{a\}}.$$

The set $\operatorname{span}\{a\} = \{\lambda a : \lambda \in \mathbb{R}\}$ is a
 one-dimensional (hence closed) subspace of $\ell_2$. Therefore
$$M^{\perp} = \operatorname{span}\{a\} = \left\{ \lambda(1,1,\dots,1,0,0,\dots)
: \lambda \in \mathbb{R} \right\}.$$

**Step 3: Verification.**

- *Forward inclusion:* Let $y = \lambda a \in \operatorname{span}\{a\}$. For any
 $x \in M$, $\langle x, y \rangle = \lambda \langle x, a \rangle = \lambda \cdot
 0 = 0$. So $y \in M^{\perp}$.

- *Reverse inclusion:* Let $y = (y_1, y_2, \dots) \in M^{\perp}$, so $\langle x,
 y \rangle = 0$ for all $x \in M$. For each $i \in \{1,\dots,n\}$, consider $x =
 e_i - e_n$ (the vector with $1$ in position $i$, $-1$ in position $n$, zeros el
sewhere). Then $\sum_{k=1}^n x_k = 1 - 1 = 0$, so $x \in M$. The condition $\lan
gle x, y \rangle = 0$ gives $y_i - y_n = 0$, hence $y_i = y_n$ for all $i = 1, \
dots, n$.

  For $j > n$, take $x = e_j$ (the $j$-th standard basis vector). Then $\sum_{k=
1}^n x_k = 0$, so $x \in M$, and $\langle x, y \rangle = y_j = 0$. Thus $y_j = 0
$ for all $j > n$.

  Combining: $y_1 = y_2 = \cdots = y_n = y_n =: \lambda$ and $y_j = 0$ for $j >
n$, so $y = \lambda a \in \operatorname{span}\{a\}$.

Both inclusions give $M^{\perp} = \operatorname{span}\{a\}$.

$$\boxed{M^{\perp} = \left\{ \lambda\,(1,1,\dots,1,0,0,\dots) : \lambda \in \mat
hbb{R} \right\}, \text{ with } n \text{ ones.}}$$
