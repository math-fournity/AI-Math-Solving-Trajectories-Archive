## Solution

**Claim.** If $F \subseteq K$ is an algebraic extension, then $K$ is **not** iso
morphic (as an $F$-algebra) to any proper subfield $L$ with $F \subseteq L \subs
etneq K$.

**Proof.** Suppose, for contradiction, that there exists an $F$-algebra isomorph
ism
$$\varphi : K \xrightarrow{\;\sim\;} L, \qquad F \subseteq L \subsetneq K.$$
Since $\varphi$ is an $F$-algebra homomorphism, $\varphi|_F = \mathrm{id}_F$, an
d since $K$ is a field, $\varphi$ is injective. Composing with the inclusion $L
\hookrightarrow K$, we obtain an $F$-algebra endomorphism
$$\sigma : K \hookrightarrow K, \qquad \sigma = \iota \circ \varphi,$$
which is injective and fixes $F$ pointwise. We will show that $\sigma$ is necess
arily **surjective**, contradicting $L \subsetneq K$ (since $\sigma(K) = L$).

Let $a \in K$ be arbitrary. Since $K/F$ is algebraic, $a$ has a minimal polynomi
al $p(x) \in F[x]$. Let
$$S = \{\, b \in K : p(b) = 0 \,\}$$
be the set of roots of $p$ lying in $K$. This is a **finite** set, since $p$ has
 finite degree.

Because $\sigma$ fixes $F$ pointwise, for every $b \in S$,
$$p(\sigma(b)) = \sigma(p(b)) = \sigma(0) = 0,$$
so $\sigma(b) \in S$. Thus $\sigma$ restricts to a map $S \to S$.

Since $\sigma$ is injective on $K$, its restriction $\sigma|_S : S \to S$ is inj
ective. An injective map from a **finite** set to itself is bijective. Hence $\s
igma|_S$ is surjective.

Now $a \in S$ (as $p(a)=0$), so by surjectivity of $\sigma|_S$, there exists $c
\in S$ with $\sigma(c) = a$. Therefore
$$a \in \sigma(K).$$

Since $a \in K$ was arbitrary, $\sigma(K) = K$, i.e., $\sigma$ is surjective. Bu
t $\sigma(K) = L$, so $L = K$, contradicting the assumption that $L$ is a **prop
er** subfield.

Therefore no such proper subfield $L$ exists. $\blacksquare$

**Remark.** The algebraicity hypothesis is essential. For a transcendental exten
sion such as $K = F(t)$, the map $t \mapsto t^2$ defines an $F$-algebra embeddin
g $F(t) \hookrightarrow F(t)$ whose image $F(t^2)$ is a proper subfield isomorph
ic to $F(t)$ as an $F$-algebra. The argument above breaks down precisely because
 the minimal polynomial of a transcendental element does not exist, so there is
no finite root-set on which to force surjectivity.
