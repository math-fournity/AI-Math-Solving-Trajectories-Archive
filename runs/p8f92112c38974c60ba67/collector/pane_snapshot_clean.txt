## Answer

The statement, taken literally, is **false**: compact subsets can certainly exis
t inside infinite-dimensional normed spaces (every finite set is compact; the Hi
lbert cube is a compact subset of ℓ²). However, the question is really pointing
at the **Heine–Borel property**, and the correct theorem is:

> **Theorem (Riesz).** *A normed vector space X is finite-dimensional if and onl
y if its closed unit ball B = {x ∈ X : ‖x‖ ≤ 1} is compact. Equivalently, X is f
inite-dimensional if and only if every closed and bounded subset of X is compact
.*

So the Heine–Borel property ("closed + bounded ⟺ compact") **characterizes** fin
ite-dimensionality. Below is the complete proof.

---

### Proof

We prove the equivalence of three statements for a normed space X over 𝕂 (ℝ or ℂ
):

1. X is finite-dimensional.
2. The closed unit ball B is compact.
3. Every closed bounded subset of X is compact.

**(1) ⇒ (2).** Suppose dim X = n < ∞. Fix a basis e₁,…,eₙ and the coordinate iso
morphism T : 𝕂ⁿ → X, which is a linear homeomorphism (all norms on a finite-dime
nsional space are equivalent, so T and T⁻¹ are continuous). The closed unit ball
 B ⊂ X is closed and bounded; T⁻¹(B) is closed and bounded in 𝕂ⁿ, hence compact
by the classical Heine–Borel theorem. Therefore B = T(T⁻¹(B)) is compact. ∎

**(2) ⇒ (3).** If C ⊂ X is closed and bounded, then C ⊂ rB for some r > 0. Since
 B is compact, rB is compact (scaling is continuous), and C is a closed subset o
f the compact set rB, hence compact. ∎

**(3) ⇒ (2).** B is closed and bounded, so by (3) it is compact. ∎

**(2) ⇒ (1)** — the substantive direction. We prove the contrapositive: **if X i
s infinite-dimensional, then B is not compact.** The key tool is:

> **Riesz's Lemma.** Let Y ⊊ X be a proper *closed* subspace. For every r ∈ (0,1
) there exists x ∈ X with ‖x‖ = 1 and dist(x, Y) ≥ r.

*Proof of the lemma.* Pick v ∉ Y, ‖v‖ = 1. Since Y is closed and v ∉ Y, d := dis
t(v, Y) > 0. Given r < 1, choose ε > 0 with d/(d+ε) ≥ r, and pick y₀ ∈ Y with ‖v
 − y₀‖ ≤ d + ε. Set

  x := (v − y₀)/‖v − y₀‖,   so ‖x‖ = 1.

For any y ∈ Y, the vector y₀ + ‖v − y₀‖·y lies in Y, so

  ‖x − y‖ = ‖v − (y₀ + ‖v − y₀‖ y)‖ / ‖v − y₀‖ ≥ d / ‖v − y₀‖ ≥ d/(d+ε) ≥ r.

Taking the infimum over y ∈ Y gives dist(x, Y) ≥ r. ∎

*Constructing a bad sequence.* Assume X is infinite-dimensional. Pick x₁ with ‖x
₁‖ = 1 and set Y₁ = span{x₁}, which is finite-dimensional, hence closed, and pro
per (X is infinite-dimensional). Apply Riesz's lemma with r = 1/2 to obtain x₂ w
ith ‖x₂‖ = 1 and dist(x₂, Y₁) ≥ 1/2; in particular ‖x₂ − x₁‖ ≥ 1/2.

Inductively, having chosen x₁,…,xₖ with ‖xᵢ‖ = 1, set Yₖ = span{x₁,…,xₖ}. This i
s finite-dimensional (hence closed) and, because X is infinite-dimensional, a pr
oper subspace. Riesz's lemma gives xₖ₊₁ with ‖xₖ₊₁‖ = 1 and dist(xₖ₊₁, Yₖ) ≥ 1/2
, so for every i ≤ k,

  ‖xₖ₊₁ − xᵢ‖ ≥ 1/2.

Thus {xₙ} ⊂ B satisfies ‖xₙ − xₘ‖ ≥ 1/2 for all n ≠ m. No subsequence is Cauchy,
 hence **no subsequence converges**. In a metric space compactness equals sequen
tial compactness, so B is **not compact**. ∎

---

### Conclusion

- Compact subsets do **not** have to "be finite-dimensional" — infinite-dimensio
nal normed spaces contain many compact sets (finite sets, convergent sequences w
ith their limits, the Hilbert cube in ℓ², etc.).
- What *is* true, and is the precise content of the question, is the **Riesz the
orem**: the Heine–Borel property — "closed and bounded **⇔** compact" — holds in
 a normed space **if and only if** the space is finite-dimensional. The obstruct
ion in infinite dimensions is Riesz's lemma, which forces the closed unit ball t
o contain an infinite 1/2-separated sequence with no convergent subsequence.
