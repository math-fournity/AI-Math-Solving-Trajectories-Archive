## Proof

**Lemma.** Let $f \in \mathbb{Z}[x]$. The following are equivalent:

(i) For all coprime integers $m,n$, $\gcd(f(m),f(n))=1$.

(ii) For every prime $p$ and every integer $m$, if $p\mid f(m)$ then $p\mid m$.

*Proof of Lemma.* (ii)$\Rightarrow$(i): Suppose $m,n$ coprime and a prime $p\mid
\gcd(f(m),f(n))$. Then $p\mid f(m)\Rightarrow p\mid m$ and $p\mid f(n)\Rightarro
w p\mid n$, so $p\mid\gcd(m,n)=1$, contradiction. (Note: if $f(m)=0$ for some $m
\neq 0$, then every prime $p$ divides $f(m)$, so (ii) forces $p\mid m$ for all $
p$, hence $m=0$ — contradiction; thus $f(m)\neq 0$ for $m\neq 0$, and the gcd is
 well-defined. If $m=0$, coprimality forces $|n|=1$; then $f(\pm1)=\pm1$ by (ii)
 applied to $m=\pm1$, so $\gcd(f(0),f(\pm1))=1$.)

(i)$\Rightarrow$(ii): Suppose $p\mid f(m)$ but $p\nmid m$. Set $n=m+p$. Then $n\
equiv m\pmod p$, so $f(n)\equiv f(m)\equiv 0\pmod p$, i.e. $p\mid f(n)$. Also $\
gcd(m,n)=\gcd(m,p)=1$ since $p\nmid m$. This contradicts (i). $\square$

---

Now let $f\in\mathbb{Z}[x]$ satisfy the condition, and write $f(x)=a_dx^d+a_{d-1
}x^{d-1}+\cdots+a_0$ with $a_d\neq 0$.

**Step 1. Values at primes are prime powers.** For any prime $p$ with $f(p)\neq
0$, condition (ii) says every prime divisor of $f(p)$ divides $p$, so $f(p)=\pm
p^{t(p)}$ for some $t(p)\geq 0$. Since $f$ has finitely many integer roots, $f(p
)\neq 0$ for all sufficiently large primes.

**Step 2. The exponent stabilizes at $d$.** For large primes $p$,
$$|f(p)|=\bigl|a_d p^d\bigr|\cdot(1+o(1)).$$
Since $|f(p)|=p^{t(p)}$, we get $p^{t(p)-d}\to |a_d|$. If $t(p)>d$ eventually, t
he left side tends to $\infty$; if $t(p)<d$ eventually, it tends to $0$. Hence $
t(p)=d$ for all large primes, and $|a_d|=1$.

**Step 3. $f$ is a monomial.** For all sufficiently large primes $p$, $f(p)=\pm
p^d$, so $f(p)^2=p^{2d}$. The polynomial $g(x)=f(x)^2-x^{2d}\in\mathbb{Z}[x]$ va
nishes at infinitely many primes, hence $g\equiv 0$. Therefore $f(x)^2=x^{2d}$,
which (over the UFD $\mathbb{Z}[x]$, or by comparing the unique factorization) f
orces $f(x)=\pm x^d$.

**Step 4. Conclusion.** The only polynomials in $\mathbb{Z}[x]$ satisfying the c
ondition are $f(x)=\pm x^d$ ($d\ge 0$), i.e. monomials (including the constants
$\pm1$ when $d=0$). A *trinomial* is, by definition, a polynomial with exactly t
hree nonzero terms. The polynomial $\pm x^d$ has exactly one term, so it is not
a trinomial.

Therefore **there are no trinomials** $f\in\mathbb{Z}[x]$ satisfying the given c
ondition. $\square$
