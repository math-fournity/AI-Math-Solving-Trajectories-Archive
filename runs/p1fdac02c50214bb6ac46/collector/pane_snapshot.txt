## Proof

Let $A = \mathbb{C}[x]/((x-\alpha)^n)$. The ring in question is
$$R_n = \begin{bmatrix} A & A \\ A & A \end{bmatrix} = M_2(A),$$
the full $2\times 2$ matrix ring over $A$.

**Claim:** $R_n$ is semisimple (semisimple Artinian) if and only if $n = 1$.

---

### Key facts

1. **$A$ is a commutative Artinian local ring.** The ideal $((x-\alpha)) \subset
 \mathbb{C}[x]$ is maximal (since $\mathbb{C}[x]/(x-\alpha) \cong \mathbb{C}$),
so $A = \mathbb{C}[x]/((x-\alpha)^n)$ is a local ring with unique maximal ideal
$$\mathfrak{m} = ((x-\alpha))/((x-\alpha)^n).$$
The Jacobson radical of a commutative Artinian local ring equals its unique maxi
mal ideal, so $J(A) = \mathfrak{m}$.

2. **$J(A) = 0 \iff n = 1$.** For $n = 1$, $A = \mathbb{C}[x]/(x-\alpha) \cong \
mathbb{C}$, a field, so $J(A) = 0$. For $n \geq 2$, the element $\overline{x-\al
pha} \in A$ is nonzero (since $x - \alpha \notin ((x-\alpha)^n)$ for $n \geq 2$)
 but nilpotent (its $n$-th power is zero). Hence $\mathfrak{m} \neq 0$, so $J(A)
 \neq 0$.

3. **Jacobson radical of a matrix ring.** For any ring $A$, $J(M_2(A)) = M_2(J(A
))$. This is a standard result: the Jacobson radical of $M_n(A)$ is $M_n(J(A))$.

---

### Case $n = 1$: semisimple

When $n=1$, $A \cong \mathbb{C}$, so $R_1 = M_2(\mathbb{C})$. This is a simple A
rtinian ring (in fact a full matrix ring over a division ring), hence semisimple
. ✓

---

### Case $n \geq 2$: not semisimple

When $n \geq 2$, $J(A) = \mathfrak{m} \neq 0$ by fact (2). By fact (3),
$$J(R_n) = J(M_2(A)) = M_2(J(A)) = M_2(\mathfrak{m}) \neq 0.$$
A ring is semisimple (Artinian semisimple) if and only if its Jacobson radical i
s zero. Since $J(R_n) \neq 0$, $R_n$ is **not** semisimple. ✗

---

### Conclusion

$R_n$ is semisimple if and only if $n = 1$.
