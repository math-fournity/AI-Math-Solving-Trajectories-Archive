Looking at this problem, I need to find the minimum number of vertices in a conn
ected graph with minimum degree ≥ m (m ≥ 3) that has no Hamiltonian path.

## Lower Bound

**Theorem:** Any graph on n vertices with minimum degree δ ≥ (n−1)/2 has a Hamil
tonian path.

*Proof:* Add a universal vertex v* adjacent to all n vertices, forming G' on n+1
 vertices. Then δ(G') ≥ δ(G)+1 ≥ (n−1)/2 + 1 = (n+1)/2. By Dirac's theorem (δ ≥
|V|/2 ⟹ Hamiltonian cycle), G' has a Hamiltonian cycle. Removing v* from this cy
cle yields a Hamiltonian path in G. ∎

**Contrapositive:** If G has no Hamiltonian path, then δ(G) < (n−1)/2, so n > 2δ
(G)+1, giving **n ≥ 2δ(G)+2 ≥ 2m+2**.

## Construction Achieving 2m+2

**Graph G:**
- Let S = {v₁, v₂, …, vₘ} form a clique Kₘ.
- Add m+2 vertices w₁, w₂, …, w_{m+2}, each adjacent to **all** vertices in S (a
nd to no other wⱼ).
- Total vertices: m + (m+2) = **2m+2**.

**Verification of minimum degree:**
- Each vᵢ ∈ S has degree (m−1) + (m+2) = 2m+1 ≥ m. ✓
- Each wⱼ has degree m (connected to all of S, nothing else) = m. ✓

**No Hamiltonian path:**
Remove S from G. The remaining m+2 vertices w₁,…,w_{m+2} are all isolated, givin
g **m+2 components**.

A Hamiltonian path visiting all vertices, when restricted to S, can use at most
|S| = m vertices of S as "bridges" between components of G−S. With m bridge vert
ices, a path can connect at most m+1 components. Since G−S has m+2 > m+1 compone
nts, **no Hamiltonian path exists**. ✓

**Connectedness:** Every wⱼ connects to every vᵢ, and S is a clique, so G is con
nected. ✓

## Conclusion

The lower bound 2m+2 and the construction achieving 2m+2 match, so the least pos
sible number of vertices is:

$$\boxed{2m+2}$$
