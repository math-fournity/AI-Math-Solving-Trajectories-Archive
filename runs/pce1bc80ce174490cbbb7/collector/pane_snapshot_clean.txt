This is well-defined since distinct elements of $2^\omega$ differ at some finite

### Triangle-Free Verification

- $x_\alpha, x_\beta$ first differ at $n$: $x_\alpha\upharpoonright n = x_\beta\

- $x_\beta, x_\gamma$ first differ at $n$: $x_\beta\upharpoonright n = x_\gamma\
upharpoonright n$ and $x_\beta(n) \neq x_\gamma(n)$.

The three values $x_\alpha(n), x_\beta(n), x_\gamma(n) \in \{0,1\}$ are pairwise
 distinct, requiring $|\{0,1\}| \geq 3$. **Contradiction.** So the family is tri
angle-free. ✓

### No Extension Exists

$$A_n \subseteq \{x \in 2^\omega : x(n) = \phi_n(x\upharpoonright n)\}.$$

$$x^*(n) = 1 - \phi_n(x^*\upharpoonright n), \quad \text{for each } n \in \omega
.$$

At each step $n$, the prefix $x^*\upharpoonright n$ is already determined, so $\
phi_n(x^*\upharpoonright n)$ is determined, and $x^*(n)$ is determined. This uni

$$x^* \notin \{x : x(n) = \phi_n(x\upharpoonright n)\} \quad \text{for all } n.$

Hence $x^* \notin \bigcup_{n<\omega} A_n = 2^\omega$. But $x^* \in 2^\omega$ by
