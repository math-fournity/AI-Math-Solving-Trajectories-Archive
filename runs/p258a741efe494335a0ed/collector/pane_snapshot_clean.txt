Looking at this problem, I need to find the smallest n > 4 for a graph where adj
acent pairs share 0 common neighbors and non-adjacent pairs share exactly 2 comm
on neighbors.

## Proof

**Setup.** Model the crew as a graph $G$ on $n$ vertices, where edges represent
partnerships. The conditions are:
- (i) Adjacent vertices have **0** common neighbors ($\lambda = 0$).
- (ii) Non-adjacent vertices have exactly **2** common neighbors ($\mu = 2$).

**Step 1: The graph is connected.** If $G$ were disconnected, vertices $x, y$ in
 different components would be non-adjacent with 0 common neighbors, contradicti
ng $\mu = 2 > 0$.

**Step 2: The graph is regular.** For any vertex $v$ with degree $d(v)$, count e
dges between $N(v)$ and the non-neighbors $M(v)$ of $v$:

- Each $w \in M(v)$ has exactly $\mu = 2$ neighbors in $N(v)$, contributing $2|M
(v)| = 2(n-1-d(v))$ edges.
- Each $u \in N(v)$ has $d(u)-1$ neighbors in $M(v)$ (since $N(v)$ is an indepen
dent set — any edge within $N(v)$ would make $v$ a common neighbor of two adjace
nt vertices, violating $\lambda=0$).

This gives the identity valid for every vertex $v$:
$$\sum_{u \in N(v)} d(u) = -d(v) + 2(n-1). \quad (\star)$$

Let $\Delta$ and $\delta$ be the maximum and minimum degrees. Applying $(\star)$
 to a vertex $v$ with $d(v) = \Delta$:
$$\sum_{u \in N(v)} d(u) = 2(n-1) - \Delta \geq \Delta \cdot \delta \implies 2(n
-1) \geq \Delta(\delta+1).$$

Applying $(\star)$ to a vertex $w$ with $d(w) = \delta$:
$$\sum_{u \in N(w)} d(u) = 2(n-1) - \delta \leq \delta \cdot \Delta \implies 2(n
-1) \leq \delta(\Delta+1).$$

Combining: $\Delta(\delta+1) \leq \delta(\Delta+1)$, so $\Delta\delta + \Delta \
leq \delta\Delta + \delta$, giving $\Delta \leq \delta$. Since $\Delta \geq \del
ta$ by definition, $\Delta = \delta$, proving **regularity** with common degree
$k$.

**Step 3: Deriving $n$ from $k$.** For a $k$-regular graph with $\lambda=0, \mu=
2$, the standard strongly regular graph relation gives:
$$k(k - \lambda - 1) = \mu(n - k - 1) \implies k(k-1) = 2(n-k-1) \implies n = \f
rac{k^2+k+2}{2}.$$

**Step 4: Checking feasibility via eigenvalues.** For $\text{srg}(n, k, 0, 2)$,
the non-principal eigenvalues $r, s$ satisfy $r+s = \lambda-\mu = -2$ and $rs =
\mu - k = 2-k$, with multiplicities $f, g$ satisfying $f+g = n-1$ and $k + fr +
gs = 0$.

- **$k=2$:** $n = 4$, not $> 4$. ✗
- **$k=3$:** $n = 7$. Then $r, s = -1 \pm \sqrt{2}$ (irrational). The multiplici
ty equation yields $f - g = \frac{3}{\sqrt{2}}$, which is **irrational** — impos
sible for integer multiplicities. No such graph exists. ✗
- **$k=4$:** $n = 11$. Then $r, s = -1 \pm \sqrt{3}$ (irrational). The multiplic
ity equation yields $f - g = \frac{6}{\sqrt{3}} = 2\sqrt{3}$, again **irrational
**. No such graph exists. ✗
- **$k=5$:** $n = 16$. Then $r, s$ satisfy $t^2 + 2t - 3 = 0$, giving $r = 1, s
= -3$ (rational). Multiplicities: $f + g = 15$ and $5 + f - 3g = 0$, yielding $g
 = 5, f = 10$ — both **integers**. ✓

**Step 5: The graph exists — the Clebsch graph.** Construct a graph on $\text{GF
}(2)^4$ (16 vertices) where $x \sim y$ iff $x \oplus y \in S$, with $S = \{e_1,
e_2, e_3, e_4, e_1{+}e_2{+}e_3{+}e_4\}$. This is 5-regular by translation invari
ance.

- **$\lambda = 0$:** The 10 pairwise sums $\{s_i \oplus s_j : i < j\}$ are $\{11
00, 1010, 1001, 0111, 0110, 0101, 1011, 0011, 1101, 1110\}$, none of which lie i
n $S$. So no adjacent pair has a common neighbor.
- **$\mu = 2$:** For non-adjacent $x, y$ (with $x \oplus y \notin S$, $x \neq y$
), the value $x \oplus y$ is one of the 10 pairwise sums. Each such sum arises f
rom exactly one unordered pair $\{s_i, s_j\}$, yielding exactly 2 ordered soluti
ons $(s_1, s_2)$, hence exactly **2 common neighbors**.

This confirms the Clebsch graph $\text{srg}(16, 5, 0, 2)$ satisfies both conditi
ons.

**Conclusion.** The candidates with $n > 4$ are $n = 7, 11, 16$ (for $k = 3, 4,
5$). The first two are ruled out by the irrational eigenvalue multiplicity condi
tion. The Clebsch graph realizes $n = 16$.

$$\boxed{n = 16}$$
