## Solution

**Domain.** We require $2x-1 \ge 0$, i.e. $x \ge \tfrac12$. We also need $x - \s
qrt{2x-1} \ge 0$. Since $x \ge \tfrac12 > 0$, squaring $x \ge \sqrt{2x-1}$ gives
 $x^2 \ge 2x-1 \iff (x-1)^2 \ge 0$, always true. So the domain is $x \ge \tfrac1
2$.

**Substitution.** Let $t = \sqrt{2x-1} \ge 0$, so $x = \tfrac{t^2+1}{2}$. Then
$$x+\sqrt{2x-1} = \tfrac{t^2+1}{2}+t = \tfrac{(t+1)^2}{2}, \qquad x-\sqrt{2x-1}
= \tfrac{t^2+1}{2}-t = \tfrac{(t-1)^2}{2}.$$
Hence
$$\sqrt{x+\sqrt{2x-1}} = \frac{t+1}{\sqrt2}, \qquad \sqrt{x-\sqrt{2x-1}} = \frac
{|t-1|}{\sqrt2},$$
and the left-hand side equals
$$f(x) = \frac{t+1+|t-1|}{\sqrt2}.$$

**Case $0 \le t \le 1$ (i.e. $\tfrac12 \le x \le 1$).** Here $|t-1| = 1-t$, so
$$f(x) = \frac{t+1+1-t}{\sqrt2} = \frac{2}{\sqrt2} = \sqrt2.$$

**Case $t \ge 1$ (i.e. $x \ge 1$).** Here $|t-1| = t-1$, so
$$f(x) = \frac{t+1+t-1}{\sqrt2} = \frac{2t}{\sqrt2} = t\sqrt2 = \sqrt{2(2x-1)} =
 \sqrt{4x-2},$$
which is strictly increasing on $[1,\infty)$ with $f(1)=\sqrt2$ and $f(x)\to\inf
ty$.

Therefore $f$ takes the constant value $\sqrt2$ on $[\tfrac12, 1]$ and increases
 from $\sqrt2$ on $[1,\infty)$. Its range is $[\sqrt2, \infty)$.

**(a) $A = \sqrt2$:** $f(x) = \sqrt2 \iff x \in \left[\tfrac12,\, 1\right]$.

**(b) $A = 1$:** Since $\min f = \sqrt2 > 1$, there is **no real solution**.

**(c) $A = 2$:** We need $x \ge 1$ and $\sqrt{4x-2} = 2$, giving $4x-2 = 4$, so
$x = \tfrac32$. (Check: $t = \sqrt{2\cdot\frac32 - 1} = \sqrt2$, $f = \sqrt2 \cd
ot \sqrt2 = 2$. ✓)

- **(b)** No real solution
- **(c)** $x = \dfrac{3}{2}$
