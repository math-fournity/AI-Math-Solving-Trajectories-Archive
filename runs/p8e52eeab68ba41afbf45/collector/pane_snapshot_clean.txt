## Solution

Let $n = 2017$ (an odd positive integer). The equation becomes

$$n x^{n} - n + x = \sqrt[n]{\,n+1 - nx\,}.$$

**Step 1. Identify a solution.** Testing $x = 1$:

- Left side: $n\cdot 1^{n} - n + 1 = n - n + 1 = 1$.
- Right side: $\sqrt[n]{\,n+1 - n\cdot 1\,} = \sqrt[n]{1} = 1$.

So $x = 1$ is a solution.

**Step 2. Prove uniqueness via monotonicity.** Rewrite the equation as

$$g(x) = h(x),$$

where

$$g(x) = n x^{n} + x - n, \qquad h(x) = \sqrt[n]{\,n+1 - nx\,}.$$

Both $g$ and $h$ are defined and continuous on all of $\mathbb{R}$ (the $n$-th r
oot with $n$ odd is defined for every real number).

- **$g$ is strictly increasing.** Its derivative is
$$g'(x) = n^{2} x^{n-1} + 1.$$
Since $n-1 = 2016$ is even, $x^{n-1} \ge 0$ for all $x$, hence $g'(x) \ge 1 > 0$
. So $g$ is strictly increasing on $\mathbb{R}$.

- **$h$ is strictly decreasing.** The inner expression $n+1 - nx$ is strictly de
creasing (slope $-n < 0$), and the map $t \mapsto \sqrt[n]{t}$ is strictly incre
asing for odd $n$ (defined on all of $\mathbb{R}$). The composition of a strictl
y decreasing function with a strictly increasing function is strictly decreasing
. Hence $h$ is strictly decreasing on $\mathbb{R}$.

**Step 3. Conclude.** A strictly increasing continuous function and a strictly d
ecreasing continuous function on $\mathbb{R}$ can intersect in **at most one** p
oint. Since $x = 1$ is an intersection point, it is the **unique** real solution
.

$$\boxed{x = 1}$$
