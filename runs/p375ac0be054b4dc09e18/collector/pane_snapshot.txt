## Proof

**Definition.** A *naïve metric space* (quasi-metric space) is a set $X$ with $d
: X \times X \to [0,\infty)$ satisfying (i) $d(x,y)=0 \iff x=y$, and (ii) the tr
iangle inequality $d(x,z)\le d(x,y)+d(y,z)$. Symmetry is **not** required.

**Construction.** Let $X=\{a,b,c\}$, set $d(x,x)=0$ for all $x$, and define
$$d(a,b)=d(b,a)=d(a,c)=d(c,a)=d(b,c)=1,\qquad d(c,b)=2.$$

**Triangle inequality check** (all triples of distinct points):
- $d(a,b)=1\le d(a,c)+d(c,b)=1+2=3$ ✓
- $d(a,c)=1\le d(a,b)+d(b,c)=1+1=2$ ✓
- $d(b,a)=1\le d(b,c)+d(c,a)=1+1=2$ ✓
- $d(b,c)=1\le d(b,a)+d(a,c)=1+1=2$ ✓
- $d(c,a)=1\le d(c,b)+d(b,a)=2+1=3$ ✓
- $d(c,b)=2\le d(c,a)+d(a,b)=1+1=2$ ✓

All hold, so $(X,d)$ is a naïve metric space.

**Disconnected open ball.** Consider $B(c,\tfrac{3}{2})=\{y:d(c,y)<\tfrac{3}{2}\
}$:
- $d(c,c)=0<\tfrac32$ ✓, $d(c,a)=1<\tfrac32$ ✓, $d(c,b)=2\not<\tfrac32$ ✗.

Thus $B(c,\tfrac32)=\{a,c\}$.

The topology: for $r\le 1$, each ball $B(x,r)$ is a singleton ($d(a,b)=d(a,c)=d(
b,a)=d(b,c)=d(c,a)=1$ and $d(c,b)=2$, so all nonzero distances from any center a
re $\ge 1$). Hence every singleton is open, the topology is **discrete**, and ev
ery subset is clopen.

In the subspace $\{a,c\}$, both $\{a\}$ and $\{c\}$ are non-empty, disjoint, ope
n (and closed), with $\{a\}\cup\{c\}=\{a,c\}$. Therefore $B(c,\tfrac32)=\{a,c\}$
 is **disconnected**.

**Completeness.** The nonzero distances in $X$ are $\{1,2\}$. A (forward) Cauchy
 sequence $(x_n)$ must satisfy $d(x_n,x_m)<\varepsilon$ for all $m\ge n\ge N$. T
aking $\varepsilon=\tfrac12$ forces $d(x_n,x_m)=0$, i.e. $x_n=x_m$, so every Cau
chy sequence is eventually constant and hence converges. The space is **complete
**.

**Conclusion.** The naïve metric space $(\{a,b,c\},d)$ is complete and has the d
isconnected open ball $B(c,\tfrac32)=\{a,c\}$. Therefore, **yes**, such a space
exists.
