## Solution

**Reformulation.** Represent each number by its "distance to 6": for value $v \i
n \{1,\dots,6\}$, set $d = (6-v)\bmod 6 \in \{0,1,\dots,5\}$. The goal "all numb
ers equal to 6" is exactly "all distances $= 0$." A move chooses exactly $t$ num
bers and increments each by $1$ cyclically, i.e. adds $1$ to each chosen distanc
e modulo $6$. Thus the state space is $(\mathbb{Z}/6\mathbb{Z})^{2014}$, and a m
ove adds a vector with exactly $t$ coordinates equal to $1$ and the rest $0$.

We need: from **every** initial state we can reach $0$. Equivalently, the subgro
up $G \le (\mathbb{Z}/6\mathbb{Z})^{2014}$ generated by all weight-$t$ vectors e
quals the whole space.

---

**Necessity: $\gcd(t,6)=1$.** Every move vector has coordinate sum $\equiv t \pm
od 6$, so every element of $G$ has coordinate sum in the subgroup $\langle t \ra
ngle \le \mathbb{Z}/6\mathbb{Z}$, which is $\langle \gcd(t,6)\rangle$. If $\gcd(
t,6)>1$, then $G$ only contains vectors whose coordinate sum is a multiple of $\
gcd(t,6)$, so $G \ne (\mathbb{Z}/6\mathbb{Z})^{2014}$. Concretely, a configurati
on with total distance $\equiv 1\pmod{\gcd(t,6)}$ (e.g. one number at distance $
1$, all others at $0$) can never reach all-zeros. Hence $\gcd(t,6)=1$ is necessa
ry.

**Necessity: $t \le 2013$.** If $t = 2014 = n$, every move adds $(1,1,\dots,1)$,
 so all distances shift together and relative differences are invariant. A non-c
onstant configuration can never become constant. So $t \le 2013$ is necessary (a
nd $t \ge 1$ since a move must choose at least one number).

**Sufficiency: $\gcd(t,6)=1$ and $1 \le t \le 2013$.** For $1 \le t \le n-1$ wit
h $n=2014$: pick any two positions $i,j$. Since $t \le n-1$ and $t \ge 1$, we ca
n find two weight-$t$ subsets differing only by swapping $i$ for $j$ (take a com
mon core of $t-1$ elements from the remaining $n-2 \ge t-1$ positions). Their di
fference is $e_i - e_j \in G$. The vectors $\{e_i - e_j\}$ generate the kernel $
H$ of the coordinate-sum map $\Sigma: (\mathbb{Z}/6\mathbb{Z})^n \to \mathbb{Z}/
6\mathbb{Z}$, i.e. all sum-$0$ vectors.

Since $\gcd(t,6)=1$, some weight-$t$ vector $w \in G$ has $\Sigma(w) = t$ genera
ting $\mathbb{Z}/6\mathbb{Z}$. Thus $G \supseteq H$ and $G$ maps surjectively on
to $\mathbb{Z}/6\mathbb{Z}$ under $\Sigma$, giving $G = (\mathbb{Z}/6\mathbb{Z})
^n$. Every configuration reaches $0$. ✓

---

**Conclusion.** $S = \{\, t \in \mathbb{N} : 1 \le t \le 2013,\ \gcd(t,6)=1 \,\}
$, i.e. $t \equiv 1$ or $5 \pmod 6$.

**Computing the sum.** In $[1,2010]$ there are $335$ full blocks of length $6$;
each block $\{6m+1,\dots,6m+6\}$ contributes $6m+1$ and $6m+5$, sum $12m+6$. The
n $2011 = 6\cdot335+1$ is coprime to $6$ (included); $2012, 2013$ are not.

$$\sum_{m=0}^{334}(12m+6) = 12\cdot\frac{334\cdot335}{2} + 6\cdot335 = 12\cdot 5
5945 + 2010 = 671340 + 2010 = 673350.$$

Adding $2011$:

$$\sum_{t\in S} t = 673350 + 2011 = \boxed{675361}.$$
