# Problem

In a specialized cyber-security facility, a series of $n$ high-security data nodes are arranged in a ring, where $n$ is an integer such that $7 \le n \le 100$. A technician is tasked with identifying all "independent" nodes—those whose index labels $a_i$ (where $1 \le a_i < n$) share no common factors with $n$ other than 1.

The technician identifies all such independent nodes and lists their indices in strictly increasing order: $a_1, a_2, \dots, a_k$. Upon inspection, the technician discovers a remarkable pattern: the spacing between every consecutive index in this list is perfectly uniform, meaning the sequence of indices forms an arithmetic progression.

Let $S$ be the set of all possible values for the total number of nodes $n$ that satisfy these specific conditions. Calculate the sum of all elements in the set $S$.
