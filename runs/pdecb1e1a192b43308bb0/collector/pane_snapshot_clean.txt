## Key Lemma: (a,b) is good ⟺ rad(a) = rad(b)

where rad(n) denotes the product of distinct prime factors of n.

**Necessity:** Suppose ab | a^k + b^k. Let p be a prime dividing a but not b. Th
en v_p(ab) = v_p(a) > 0, but v_p(a^k + b^k) = 0 since a^k ≡ 0 (mod p) and b^k ≢
0 (mod p), so a^k + b^k ≡ b^k ≢ 0 (mod p). This contradicts ab | a^k + b^k. By s
ymmetry, a and b share the same prime factors.

**Sufficiency:** Suppose rad(a) = rad(b). Let g = gcd(a,b), a = gu, b = gv, gcd(
u,v) = 1. Since rad(a) = rad(b), every prime dividing u or v also divides g (if
p | u then p | a = gu, so p | b = gv; since gcd(u,v)=1, p ∤ v, so p | g). Thus r
ad(uv) | g.

We need g²uv | g^k(u^k + v^k). Since gcd(u,v) = 1, we have gcd(uv, u^k+v^k) = 1.
 For each prime p:
- If p | uv: v_p(u^k + v^k) = 0, so we need v_p(uv) ≤ (k−2)v_p(g). Since v_p(g)
≥ 1, this holds for large k.
- If p | g, p ∤ uv: we need 2v_p(g) ≤ k·v_p(g) + v_p(u^k+v^k), which holds for k
 ≥ 2.

Taking k sufficiently large satisfies all conditions simultaneously. ∎
