Looking at this problem, I need to find the minimum total sum in an $n \times n$
 table ($n = 2007$) of non-negative integers where every zero cell has row-sum +
 column-sum $\geq n$.

**Answer: $2014025$.**

## Construction (Upper Bound)

Partition rows into $A$ (size $k = 1003$) and $B$ (size $1004$); columns into $A
'$ (size $1003$) and $B'$ (size $1004$). Fill:
- $A \times A'$ and $B \times B'$ with **1**,
- $A \times B'$ and $B \times A'$ with **0**.

**Row sums:** rows in $A$ have sum $1003$; rows in $B$ have sum $1004$.
**Column sums:** columns in $A'$ have sum $1003$; columns in $B'$ have sum $1004
$.

**Zero check:** Every zero lies in $A \times B'$ or $B \times A'$, where $r_i +
c_j = 1003 + 1004 = 2007 = n$. ✓

**Total:** $1003^2 + 1004^2 = 1006009 + 1008016 = \mathbf{2014025}$.

## Lower Bound

Let $r_i, c_j$ be row/column sums, $S = \sum r_i = \sum c_j$, and $Z$ the set of
 zero cells, with $z_i$ (resp. $z'_j$) the number of zeros in row $i$ (resp. col
umn $j$).

**Bound 1.** Each row has $n - z_i$ nonzero entries (each $\geq 1$), so $r_i \ge
q n - z_i$. Summing: $S \geq n^2 - |Z|$, i.e., $|Z| \geq n^2 - S$.

**Bound 2.** At each zero $(i,j)$: $r_i + c_j \geq n$. Summing over all zeros:
$$\sum_i z_i\, r_i + \sum_j z'_j\, c_j \geq n\,|Z|.$$

Write $r_i = (n - z_i) + e_i$ with $e_i \geq 0$. Then $\sum e_i = S - n^2 + |Z|$
, and:
$$\sum_i z_i\, r_i = \sum_i z_i(n - z_i) + \sum_i z_i\, e_i = n|Z| - \sum_i z_i^
2 + \sum_i z_i\, e_i.$$
Since $z_i \leq n$: $\sum z_i e_i \leq n\sum e_i = n(S - n^2 + |Z|)$, giving:
$$\sum_i z_i\, r_i \leq 2n|Z| - \sum_i z_i^2 + nS - n^3.$$
Applying the same to columns and substituting into the constraint:
$$n|Z| \leq 4n|Z| - \sum_i z_i^2 - \sum_j (z'_j)^2 + 2nS - 2n^3,$$
$$\sum_i z_i^2 + \sum_j (z'_j)^2 \leq 3n|Z| + 2nS - 2n^3.$$

By Cauchy–Schwarz ($\sum z_i^2 \geq |Z|^2/n$, same for columns):
$$\frac{2|Z|^2}{n} \leq 3n|Z| + 2nS - 2n^3 \implies S \geq \frac{|Z|^2}{n^2} + n
^2 - \frac{3|Z|}{2}.$$

**Combining.** Set $E = |Z|$, $f(E) = n^2 - E$, $g(E) = E^2/n^2 + n^2 - 3E/2$. W
e need $S \geq \max(f(E), g(E))$.

Note $f(E) - g(E) = E/2 - E^2/n^2 = \frac{E}{2}\!\left(1 - \frac{2E}{n^2}\right)
$, which is positive for $E < n^2/2$ and negative for $E > n^2/2$. So:
- If $E < n^2/2$: $\max = f(E) > n^2/2$.
- If $E > n^2/2$: $\max = g(E) > n^2/2$.
- If $E = n^2/2$: both equal $n^2/2$.

Therefore $S \geq n^2/2$ for all $E$, hence $S \geq \lceil n^2/2 \rceil$.

For $n = 2007$: $S \geq \lceil 2007^2/2 \rceil = \lceil 2014024.5 \rceil = \math
bf{2014025}$.

## Conclusion

The construction achieves $S = 2014025 = \lceil n^2/2 \rceil$, matching the lowe
r bound. The minimum possible value is:

$$\boxed{2014025}$$
