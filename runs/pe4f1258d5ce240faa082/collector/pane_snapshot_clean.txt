Looking at this problem, I need to find when $\frac{x^2+y^2+z^2}{xy+yz+zx} = 2$,
 then maximize the count over all valid choices of $S$.

## Proof

**Step 1: Characterize when the ratio equals 2.**

The ratio equals 2 iff $x^2+y^2+z^2 = 2(xy+yz+zx)$, i.e., $x^2 - 2x(y+z) + (y-z)
^2 = 0$. Solving for $x$:

$$x = (y+z) \pm 2\sqrt{yz}$$

For $x$ to be a positive integer, $\sqrt{yz}$ must be an integer, so $yz$ is a p
erfect square. Writing $y = da^2$, $z = db^2$ with $d$ squarefree (same squarefr
ee part), we get $x = d(a+b)^2$ or $x = d(a-b)^2$. In all cases, $x, y, z$ share
 the same squarefree part $d$.

Conversely, if $x = du^2, y = dv^2, z = dw^2$ for the same squarefree $d$, the r
atio becomes $\frac{u^4+v^4+w^4}{u^2v^2+v^2w^2+w^2u^2}$, which equals 2 iff:

$$u^4+v^4+w^4 - 2(u^2v^2+v^2w^2+w^2u^2) = 0$$

Using the identity $(u+v+w)(-u+v+w)(u-v+w)(u+v-w) = 2(u^2v^2+v^2w^2+w^2u^2) - (u
^4+v^4+w^4)$, this factors as:

$$(u+v+w)(-u+v+w)(u-v+w)(u+v-w) = 0$$

Since $u,v,w > 0$, we need one of $u = v+w$, $v = u+w$, or $w = u+v$. **The rati
o equals 2 iff all three numbers belong to the same square class $d$ and, writin
g them as $du^2, dv^2, dw^2$, one of $u, v, w$ is the sum of the other two.**

**Step 2: Count good triples for a given set $U$ of $u$-values.**

Let $U \subset \mathbb{N}$ with $|U| = n$. The number of ordered triples $(u,v,w
) \in U^3$ where one equals the sum of the other two equals $3P$, where $P = |\{
(a,b) \in U^2 : a+b \in U\}|$ (each Schur triple $\{a, b, a+b\}$ with $a < b$ co
ntributes 6 ordered triples, and with $a = b$ contributes 3; the total simplifie
s to $3P$).

**Claim:** $P \leq \frac{n(n-1)}{2}$, with equality iff $U = \{1, 2, \ldots, n\}
$.

*Proof:* Let $U = \{u_1 < u_2 < \cdots < u_n\}$. For each $u_i \in U$, the pairs
 $(a,b) \in U^2$ with $a + b = u_i$ require $a \in U$ and $a < u_i$, so $a \in \
{u_1, \ldots, u_{i-1}\}$, giving at most $i - 1$ pairs. Therefore:

$$P = \sum_{i=1}^{n} |\{(a,b) \in U^2 : a+b = u_i\}| \leq \sum_{i=1}^{n} (i-1) =
 \frac{n(n-1)}{2}$$

Equality holds when for every $i$ and every $j < i$, $u_i - u_j \in U$. This is
satisfied by $U = \{1, 2, \ldots, n\}$ (since $i - j \in \{1, \ldots, i-1\} \sub
set U$). $\square$

**Step 3: Optimize over the choice of $S$.**

Good triples require all three elements in the same square class. If we select $
n_d$ elements from square class $d$ (with $u$-value set $U_d$), the total count
is:

$$\sum_d 3P(U_d) \leq 3 \sum_d \frac{n_d(n_d - 1)}{2}$$

Since $f(x) = x(x-1)/2$ is convex and $\sum_d n_d = 100$:

$$\sum_d \frac{n_d(n_d-1)}{2} = \frac{1}{2}\left(\sum_d n_d^2 - 100\right) \leq
\frac{1}{2}(100^2 - 100) = \frac{100 \cdot 99}{2} = 4950$$

with equality iff all 100 elements are in a single square class. The only square
 class with $\geq 100$ elements is $d = 1$ (perfect squares: $1^2, 2^2, \ldots,
100^2 = 10000$, giving exactly 100 elements, since $m_d = \lfloor 100/\sqrt{d} \
rfloor \geq 100$ requires $d = 1$).

**Step 4: Verify the maximum.**

Take $S = \{1, 4, 9, 16, \ldots, 10000\}$ (the first 100 perfect squares). Then
$U = \{1, 2, \ldots, 100\}$, and the count is:

$$3 \cdot \frac{100 \cdot 99}{2} = 3 \cdot 4950 = 14850$$

**Verification of the count:** The unordered pairs $\{a, b\}$ with $1 \leq a \le
q b$ and $a + b \leq 100$:
- Pairs with $a < b$: $\sum_{a=1}^{49}(100 - 2a) = 2450$, contributing $6 \times
 2450 = 14700$ ordered triples.
- Pairs with $a = b$: $a = 1, \ldots, 50$, contributing $3 \times 50 = 150$ orde
red triples.
- **Total: $14700 + 150 = 14850$.** ✓

**Examples:** $(1, 1, 4)$: $\frac{1+1+16}{1+4+4} = \frac{18}{9} = 2$ ✓. $(1, 4,
9)$: $\frac{1+16+81}{4+36+9} = \frac{98}{49} = 2$ ✓. $(4, 9, 25)$: $\frac{16+81+
625}{36+225+100} = \frac{722}{361} = 2$ ✓.
