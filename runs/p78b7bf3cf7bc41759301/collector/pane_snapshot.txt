## Solution

**Setup.** Frequencies $\{1,2,3,4}$, each generated with probability $1/4$. Freq
uency $y$ is *recorded* after $x$ iff $x+y\ne 5$; otherwise it is discarded and
a new attempt is made. Since exactly one of the four values (namely $5-x$) is di
scarded, each *recorded* term after the first is uniformly distributed over the
three values $\{1,2,3,4\}\setminus\{5-x\}$. The log is therefore a Markov chain
$X_1,X_2,\dots$ with $X_1$ uniform on $\{1,2,3,4\}$ and
$$\Pr(X_{n+1}=y\mid X_n=x)=\tfrac13\mathbf 1_{y\ne 5-x}.$$
We want $E[N]$ where $N=\min\{n:\{X_1,\dots,X_n\}=\{1,2,3,4\}\}$.

**Symmetries.** The map $x\mapsto 5-x$ (swapping $1\leftrightarrow4$, $2\leftrig
htarrow3$) and the pair-swap $1\leftrightarrow2,\;4\leftrightarrow3$ both preser
ve the transition rule. Hence all singletons are equivalent.

Let $f(S,L)$ = expected number of *additional recorded terms* needed to complete
, given seen set $S$ and current position $L\in S$, with $f(\{1,2,3,4\},\cdot)=0
$. Then $E[N]=1+f(\{X_1\},X_1)$.

**States with $|S|=3$.** Let the missing frequency be $m$. The "bad" position is
 $L^*=5-m$ (the unique element of $S$ whose enemy is the missing $m$). Take $S=\
{1,2,3\}$, $m=4$, so $L^*=1$.

- $L=1$ (bad): allowed set $=\{1,2,3\}=S$, none completes.
$$f(S,1)=1+\tfrac13\bigl(f(S,1)+f(S,2)+f(S,3)\bigr).$$
- $L=2$: $e(2)=3\in S$; allowed $=\{1,2,4\}$, so $y=4$ completes.
$$f(S,2)=1+\tfrac13\bigl(f(S,1)+f(S,2)+0\bigr)\;\Rightarrow\;2f(S,2)=3+f(S,1).$$
- $L=3$: similarly $2f(S,3)=3+f(S,1)$, so $f(S,2)=f(S,3)$.

From the bad equation: $\tfrac23 f(S,1)=1+\tfrac23 f(S,2)$, i.e. $f(S,1)=\tfrac3
2+f(S,2)$. Substituting:
$$2f(S,2)=3+\tfrac32+f(S,2)=\tfrac92+f(S,2)\;\Rightarrow\;f(S,2)=\tfrac92,\quad
f(S,1)=6.$$

By the symmetries, **every** $|S|=3$ state has value $6$ at its bad position and
 $\tfrac92$ at the other two positions.

**States with $|S|=2$.** Two structural types, but both yield the same value.

*Cross pair* $\{1,2\}$ (by pair-swap $f(\{1,2\},1)=f(\{1,2\},2)=:f_C$):
$$f_C=1+\tfrac13\bigl(f_C+f_C+f(\{1,2,3\},3)\bigr),\quad f(\{1,2,3\},3)=\tfrac92
.$$
So $\tfrac13 f_C=1+\tfrac32=\tfrac52$, giving $f_C=\tfrac{15}{2}$.

*Enemy pair* $\{1,4\}$:
$$f(\{1,4\},1)=1+\tfrac13\bigl(f(\{1,4\},1)+f(\{1,2,4\},2)+f(\{1,3,4\},3)\bigr).
$$
Here $f(\{1,2,4\},2)=6$ (bad position, missing $3$) and $f(\{1,3,4\},3)=6$ (bad
position, missing $2$). Thus $\tfrac23 f(\{1,4\},1)=1+4=5$, giving $f(\{1,4\},1)
=\tfrac{15}{2}$.

So **all** $|S|=2$ states have value $\tfrac{15}{2}$.

**States with $|S|=1$.** With $f_1=f(\{1\},1)$, allowed set from $1$ is $\{1,2,3
\}$:
$$f_1=1+\tfrac13\bigl(f_1+f(\{1,2\},2)+f(\{1,3\},3)\bigr)=1+\tfrac13\Bigl(f_1+\t
frac{15}{2}+\tfrac{15}{2}\Bigr).$$
Hence $\tfrac23 f_1=1+5=6$, so $f_1=9$.

**Final answer.** The first term is always recorded, after which we are in a $|S
|=1$ state. Therefore
$$E[N]=1+f_1=1+9=\boxed{10}.$$
