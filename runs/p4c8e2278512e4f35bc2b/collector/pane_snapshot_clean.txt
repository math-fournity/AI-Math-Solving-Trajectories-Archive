## Proof

**Setup.** Let $a = BC$, $c = AB$, $b = AC$. The given condition is $b = \tfrac{
a+c}{2}$.

Place $B$ at the origin with the bisector of $\angle ABC$ along the positive $x$
-axis. Then:

$$A = \bigl(c\cos\tfrac{\beta}{2},\; c\sin\tfrac{\beta}{2}\bigr),\qquad C = \big
l(a\cos\tfrac{\beta}{2},\; -a\sin\tfrac{\beta}{2}\bigr).$$

**Finding $L$.** The line $AC$ meets the $x$-axis (the bisector) at $L$. Paramet
rize $AC$: the $y$-coordinate vanishes at $t = c/(a+c)$, giving

$$L = \left(\frac{2ac\cos(\beta/2)}{a+c},\; 0\right).$$

(This agrees with the angle-bisector theorem: $AL:LC = c:a$.)

**Midpoints.**

$$K = \left(\tfrac{c}{2}\cos\tfrac{\beta}{2},\; \tfrac{c}{2}\sin\tfrac{\beta}{2}
\right),\qquad M = \left(\tfrac{a}{2}\cos\tfrac{\beta}{2},\; -\tfrac{a}{2}\sin\t
frac{\beta}{2}\right).$$

**Vectors from $L$.** Setting $u = \frac{c-3a}{a+c}$, $v = \frac{a-3c}{a+c}$, an
d $C_0 = \cos^2\frac{\beta}{2}$, $S_0 = \sin^2\frac{\beta}{2}$:

$$\vec{LK} = \frac{c}{2}\bigl(u\cos\tfrac{\beta}{2},\; \sin\tfrac{\beta}{2}\bigr
),\qquad \vec{LM} = \frac{a}{2}\bigl(v\cos\tfrac{\beta}{2},\; -\sin\tfrac{\beta}
{2}\bigr).$$

**The key constraint.** By the law of cosines, $b^2 = a^2 + c^2 - 2ac\cos\beta$.
 Substituting $b = (a+c)/2$:

$$\frac{(a+c)^2}{4} = a^2 + c^2 - 2ac\cos\beta \;\;\Longrightarrow\;\; 8ac\cos\b
eta = 3(a^2+c^2) - 2ac.$$

Using $\cos\beta = 2\cos^2\frac\beta2 - 1$ and $a^2+c^2 = (a+c)^2 - 2ac$:

$$16\,ac\cos^2\tfrac{\beta}{2} = 3(a+c)^2 \;\;\Longrightarrow\;\; \frac{ac}{(a+c
)^2} = \frac{3}{16\cos^2(\beta/2)} = \frac{3}{16\,C_0}.$$

**Computing $uv$.** Note $u+v = -2$ and

$$uv = \frac{(c-3a)(a-3c)}{(a+c)^2} = \frac{16ac - 3(a+c)^2}{(a+c)^2} = \frac{16
ac}{(a+c)^2} - 3 = \frac{3}{C_0} - 3 = \frac{3S_0}{C_0}.$$

**Computing $\cos\angle KLM$.**

$$\cos\angle KLM = \frac{uv\,C_0 - S_0}{\sqrt{(u^2 C_0 + S_0)(v^2 C_0 + S_0)}}.$
$

The numerator: $uv\,C_0 - S_0 = \frac{3S_0}{C_0}\cdot C_0 - S_0 = 2S_0$.

For the denominator, expand the product under the square root:

$$(u^2 C_0 + S_0)(v^2 C_0 + S_0) = u^2v^2 C_0^2 + (u^2+v^2)C_0 S_0 + S_0^2.$$

Since $u^2 + v^2 = (u+v)^2 - 2uv = 4 - 2\cdot\frac{3S_0}{C_0} = \frac{4C_0 - 6S_
0}{C_0}$:

$$= \frac{9S_0^2}{C_0^2}\cdot C_0^2 + \frac{4C_0-6S_0}{C_0}\cdot C_0 S_0 + S_0^2
 = 9S_0^2 + (4C_0 - 6S_0)S_0 + S_0^2$$
$$= 9S_0^2 + 4C_0 S_0 - 6S_0^2 + S_0^2 = 4S_0^2 + 4C_0 S_0 = 4S_0(S_0 + C_0) = 4
S_0.$$

Therefore:

$$\cos\angle KLM = \frac{2S_0}{\sqrt{4S_0}} = \frac{2S_0}{2\sqrt{S_0}} = \sqrt{S
_0} = \sin\frac{\beta}{2}.$$

Since $\sin\frac\beta2 = \cos\!\left(90^\circ - \frac\beta2\right)$, we conclude
:

$$\boxed{\angle KLM = 90^\circ - \frac{\beta}{2}.}$$
