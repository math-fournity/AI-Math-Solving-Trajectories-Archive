## Proof

Let $B(t)$ be a standard Brownian motion. By definition, Brownian motion has ind
ependent increments, and for $t \geq s \geq 0$, the increment $B(t) - B(s)$ is n
ormally distributed with mean $0$ and variance $t - s$:

$$B(t) - B(s) \sim N(0,\, t-s).$$

Set $\sigma^2 = t - s$, so that $X := B(t) - B(s) \sim N(0, \sigma^2)$. We compu
te the fourth moment $E[X^4]$.

**Method (Gaussian integration by parts / Stein's lemma).** For $X \sim N(0,\sig
ma^2)$, the Gaussian integration-by-parts identity states

$$E[X\,g(X)] = \sigma^2\, E[g'(X)]$$

for any sufficiently smooth $g$. Applying this with $g(x) = x^3$ (so $g'(x) = 3x
^2$):

$$E[X^4] = E[X \cdot X^3] = \sigma^2\, E[3X^2] = 3\sigma^2\, E[X^2].$$

Since $E[X^2] = \operatorname{Var}(X) = \sigma^2$ (the mean is zero), we obtain

$$E[X^4] = 3\sigma^2 \cdot \sigma^2 = 3\sigma^4.$$

**Verification via the moment generating function (cross-check).** The MGF of $X
 \sim N(0,\sigma^2)$ is

$$M(u) = E[e^{uX}] = e^{\sigma^2 u^2/2}.$$

The fourth moment is $E[X^4] = M^{(4)}(0)$. Differentiating:

$$M'(u) = \sigma^2 u\, e^{\sigma^2 u^2/2},$$
$$M''(u) = (\sigma^2 + \sigma^4 u^2)\, e^{\sigma^2 u^2/2},$$
$$M'''(u) = (3\sigma^4 u + \sigma^6 u^3)\, e^{\sigma^2 u^2/2},$$
$$M^{(4)}(u) = (3\sigma^4 + 6\sigma^6 u^2 + \sigma^8 u^4)\, e^{\sigma^2 u^2/2}.$
$

Evaluating at $u = 0$:

$$E[X^4] = M^{(4)}(0) = 3\sigma^4.$$

Both methods agree. Substituting back $\sigma^2 = t - s$:

$$\sigma^4 = (t-s)^2,$$

and therefore

$$E\bigl(B(t) - B(s)\bigr)^4 = 3\sigma^4 = 3(t-s)^2.$$

This completes the proof. $\blacksquare$
