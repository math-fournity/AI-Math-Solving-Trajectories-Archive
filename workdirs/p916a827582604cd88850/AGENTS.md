# Problem

A specialized microchip consists of a grid of 40 light-emitting diodes (LEDs) arranged in 5 rows and 8 columns. Initially, all LEDs are switched OFF. The circuitry is designed such that the only way to toggle the state of the LEDs is by using a "Triple-Bit Overwrite" command. This command allows a technician to select any three consecutive LEDs in a straight line (either a $1 \times 3$ horizontal block or a $3 \times 1$ vertical block) and flip their current states (ON becomes OFF, and OFF becomes ON).

Let $M$ be the maximum number of LEDs that can be simultaneously in the ON state through any sequence of these commands.
Let $N$ be the total number of unique patterns of ON and OFF LEDs on the grid that contain exactly $M$ ON LEDs.
Let $K$ be the smallest number of commands required to transition the grid from the all-OFF state to any one of these $N$ specific patterns.

Calculate the value of $M + N + K$.
