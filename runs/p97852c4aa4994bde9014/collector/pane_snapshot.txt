## Proof

We count sequences of length $n$ over the alphabet $S=\{1,3,4,6,7,9\}$ whose ele
ment-sum is divisible by $7$.

**Step 1: Reduce mod 7.** Only residues matter. Reducing $S$ modulo $7$:
$$S \bmod 7 = \{1,3,4,6,0,2\} = \{0,1,2,3,4,6\}.$$
So the set of residues used is $\{0,1,2,3,4,6\}$ — every residue mod $7$ **excep
t** $5$.

**Step 2: Roots of unity filter.** Let $\omega=e^{2\pi i/7}$. The number of sequ
ences with sum $\equiv 0\pmod 7$ is
$$N=\frac{1}{7}\sum_{j=0}^{6}\bigl(f(j)\bigr)^n,\qquad f(j)=\sum_{a\in\{0,1,2,3,
4,6\}}\omega^{ja}.$$

**Step 3: Evaluate $f(j)$.** Since $\{0,1,2,3,4,6\}=\{0,1,\dots,6\}\setminus\{5\
}$,
$$f(j)=\sum_{a=0}^{6}\omega^{ja}-\omega^{5j}.$$
- For $j=0$: $\sum_{a=0}^{6}1=7$, so $f(0)=7-1=6$.
- For $j\neq 0$: $\sum_{a=0}^{6}\omega^{ja}=0$ (full geometric sum, $\omega^j\ne
q 1$), so $f(j)=-\omega^{5j}$.

**Step 4: Substitute.**
$$N=\frac{1}{7}\left[6^n+\sum_{j=1}^{6}(-\omega^{5j})^n\right]=\frac{1}{7}\left[
6^n+(-1)^n\sum_{j=1}^{6}\omega^{5jn}\right].$$

**Step 5: Evaluate the inner sum.** Let $m=5n$. We need $\sum_{j=1}^{6}\omega^{m
j}$.

- If $m\equiv 0\pmod 7$, i.e. $7\mid n$ (since $\gcd(5,7)=1$): every term is $1$
, so the sum equals $6$.
- If $m\not\equiv 0\pmod 7$, i.e. $7\nmid n$: the full sum $\sum_{j=0}^{6}\omega
^{mj}=0$, hence $\sum_{j=1}^{6}\omega^{mj}=-1$.

**Step 6: Combine.**

- **If $7\mid n$:**
$$\boxed{N=\dfrac{6^n+6(-1)^n}{7}}.$$

- **If $7\nmid n$:**
$$\boxed{N=\dfrac{6^n-(-1)^n}{7}}.$$

**Verification.**
- $n=1$ ($7\nmid 1$): $N=\frac{6-(-1)}{7}=1$. Indeed only the single element $7\
equiv 0\pmod 7$ works. ✓
- $n=2$ ($7\nmid 2$): $N=\frac{36-1}{7}=5$. Checking pairs $(a,b)$ with $a+b\equ
iv 0$: $a=0\to b=0$✓, $a=1\to b=6$✓, $a=2\to b=5$✗, $a=3\to b=4$✓, $a=4\to b=3$✓
, $a=6\to b=1$✓ — exactly $5$. ✓
- $n=7$ ($7\mid 7$): $N=\frac{6^7-6}{7}=\frac{279936-6}{7}=\frac{279930}{7}=3999
0$, an integer. ✓

In both cases the numerator is divisible by $7$: when $7\mid n$, $6^n\equiv (-1)
^n\pmod 7$ so $6^n+6(-1)^n\equiv (-1)^n(1+6)\equiv 0\pmod 7$; when $7\nmid n$, $
6^n\equiv (-1)^n\pmod 7$ so $6^n-(-1)^n\equiv 0\pmod 7$. Hence $N$ is always a n
on-negative integer, as required.
