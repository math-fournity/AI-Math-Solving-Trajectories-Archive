## Proof

Let $\mathcal{T}$ denote the class of balanced 2-3 trees, with size = number of
leaves. We decompose by depth.

**Depth-indexed decomposition.** For $d \geq 0$, let $\mathcal{T}_d$ be the subc
lass of trees whose leaves are all at distance exactly $d$ from the root, and le
t $T_d(z)$ be its generating function. The classes $\{\mathcal{T}_d\}_{d\ge 0}$
are disjoint (every tree has a unique leaf-depth), so

$$T(z) = \sum_{d\ge 0} T_d(z).$$

**Base case.** A tree of depth $0$ is a single leaf, so

$$T_0(z) = z.$$

**Recursion.** A tree of depth $d+1$ consists of a root (an internal node, contr
ibuting $0$ to size since only leaves count) together with either $2$ or $3$ ord
ered subtrees, each of which must independently be a balanced 2-3 tree of depth
exactly $d$ (so that all leaves remain at the same distance from the new root).
Since the trees are planar, the children form an ordered sequence, giving a prod
uct of generating functions. Summing over the two allowed degrees:

$$T_{d+1}(z) = T_d(z)^2 + T_d(z)^3, \qquad d \ge 0.$$

**Iterate form.** Setting $f(w) = w^2 + w^3$, the recursion reads $T_{d+1} = f(T
_d)$ with $T_0(z)=z$. Hence $T_d = f^{\circ d}(z)$ (the $d$-fold iterate, with $
f^{\circ 0}(z)=z$), and

$$\boxed{\,T(z) = \sum_{d\ge 0} f^{\circ d}(z), \qquad f(w)=w^2+w^3,\; f^{\circ
0}(z)=z\,}.$$

Equivalently, written out:

$$T(z) = z + (z^2+z^3) + (z^2+z^3)^2 + (z^2+z^3)^3 + (z^2+z^3)^4 + 2(z^2+z^3)^5
+ \cdots$$

where each successive group of terms is obtained by substituting $w \mapsto w^2+
w^3$ into the previous polynomial and the coefficient of $z^n$ in $T_d(z)$ count
s balanced 2-3 trees with $n$ leaves and depth $d$.

**Why no algebraic closed form exists.** The recursion $T_{d+1}=f(T_d)$ is an *i
terated* functional equation. The total $T = \sum_d T_d$ satisfies no algebraic
equation $P(z,T)=0$: each $T_d$ is a polynomial whose lowest-degree term is $z^{
2^d}$, so $T(z)$ has coefficients supported on a set of integers that grows doub
ly-exponentially in the minimum index per depth level, and the series is not alg
ebraic (in fact not D-finite). The iterate-sum above is therefore the canonical
generating-function form for this class.

**Verification of first terms.**
- $T_0 = z$: one tree with $1$ leaf. ✓
- $T_1 = z^2 + z^3$: a root with $2$ leaves (size $2$) or $3$ leaves (size $3$).
 ✓
- $T_2 = (z^2+z^3)^2 + (z^2+z^3)^3 = z^4 + 2z^5 + z^6 + z^6 + 3z^7 + 3z^8 + z^9
= z^4+2z^5+2z^6+3z^7+3z^8+z^9$: trees of depth $2$, i.e. a root with $2$ or $3$
children, each child being a depth-$1$ tree ($2$ or $3$ leaves). E.g. $z^4$: roo
t with $2$ children each a $2$-leaf subtree. $2z^5$: root with $2$ children, one
 $2$-leaf and one $3$-leaf subtree (two orderings). ✓

The generating function for the class of balanced 2-3 trees (leaves counted as s
ize) is

$$T(z) = \sum_{d\ge 0} f^{\circ d}(z), \qquad f(w) = w^2 + w^3.$$
