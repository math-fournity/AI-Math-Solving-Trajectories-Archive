## Proof

We work in the triangular lattice using coordinates $(x, y, z)$ with $x + y + z
= 0$, where the hexagonal grid of radius $n = 1000$ consists of all lattice poin
ts satisfying $|x| \le n,\ |y| \le n,\ |z| \le n$.

The $60°$ rotation about the origin maps $(x, y, z) \mapsto (-y, -z, -x)$, and p
reserves the lattice.

### Key Invariant

Define $f(x, y, z) = x + 2y \pmod{3}$. We claim that for **every** equilateral t
riangle with lattice vertices $A, B, C$:
$$f(A) + f(B) + f(C) \equiv 0 \pmod{3}.$$

**Proof of claim.** Every equilateral triangle with vertices in the triangular l
attice has the form $\{A,\ A+v,\ A+R(v)\}$, where $v$ is a lattice vector and $R
$ is rotation by $\pm 60°$ about the origin (the third vertex is obtained by rot
ating the second vertex around the first by $\pm 60°$, and the triangular lattic
e is closed under such rotations). Since $f$ is linear:

$$f(A) + f(A+v) + f(A+Rv) = 3f(A) + f(v) + f(Rv) \equiv f(v) + f(Rv) \pmod{3}.$$

**Case $R = R_{60°}$:** $(x,y,z) \mapsto (-y,-z,-x)$, so $f(Rv) = -y - 2z$. Then
:
$$f(v) + f(Rv) = (x + 2y) + (-y - 2z) = x + y - 2z.$$
Since $x + y + z = 0$, we have $z = -x - y$, so $x + y - 2(-x-y) = 3(x+y) \equiv
 0 \pmod{3}$. ✓

**Case $R = R_{-60°}$:** $(x,y,z) \mapsto (-z,-x,-y)$, so $f(Rv) = -z - 2x$. The
n:
$$f(v) + f(Rv) = (x + 2y) + (-z - 2x) = -x + 2y - z.$$
With $z = -x - y$: $-x + 2y + x + y = 3y \equiv 0 \pmod{3}$. ✓

This establishes the invariant for all equilateral triangles of any size and ori
entation.

### Total Sum

The sum $S = \sum_P f(P)$ over all lattice points $P$ in the hexagon satisfies $
S \equiv 0 \pmod{3}$. This follows from the central symmetry $(x,y,z) \mapsto (-
x,-y,-z)$ of the hexagon, which gives $\sum x = 0$ and $\sum y = 0$ as integers,
 hence $S = \sum x + 2\sum y = 0$.

### Necessary Condition on the Last Node

Since each triple removal subtracts $0 \pmod{3}$ from the total, and the initial
 total is $0 \pmod{3}$, the single remaining node $P$ must satisfy:
$$f(P) = x_P + 2y_P \equiv 0 \pmod{3}.$$

### Evaluating the Six Vertices

The six vertices of the hexagon of radius $n = 1000$ are:
$$(n, 0, -n),\ (n, -n, 0),\ (0, -n, n),\ (-n, 0, n),\ (-n, n, 0),\ (0, n, -n).$$

Since $n = 1000 \equiv 1 \pmod{3}$, their $f$-values are:

| Vertex | $f = x + 2y$ | $f \bmod 3$ |
|---|---|---|
| $(n, 0, -n)$ | $n$ | $1$ |
| $(n, -n, 0)$ | $-n$ | $2$ |
| $(0, -n, n)$ | $-2n$ | $1$ |
| $(-n, 0, n)$ | $-n$ | $2$ |
| $(-n, n, 0)$ | $n$ | $1$ |
| $(0, n, -n)$ | $2n$ | $2$ |

All six vertices have $f \equiv 1$ or $2 \pmod{3}$ — **never** $0$.

### Conclusion

The invariant $f(P) \equiv 0 \pmod{3}$ is a **necessary** condition for any node
 to be the last remaining uncolored node. Since none of the six original vertice
s satisfy this condition, **none** of them can be the single remaining uncolored
 node.
