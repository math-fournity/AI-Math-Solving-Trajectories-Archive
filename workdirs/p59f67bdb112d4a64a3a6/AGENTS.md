# Problem

In a specialized cryptographic archive, a master security code is generated by cataloging every possible unique sequence that uses each of the nine digits $\{1, 2, 3, 4, 5, 6, 7, 8, 9\}$ exactly once. These nine-digit sequences are known as "Permutation Keys."

The archive’s master ledger, $S$, is formed by concatenating every single Permutation Key into one continuous string of digits, arranged strictly such that the keys appear in increasing numerical order (from $123,456,789$ to $987,654,321$).

A security auditor needs to determine the minimum window size, $k$, required for a scanning sensor. This sensor must be able to slide across the entire master ledger $S$ and capture a substring of length $k$. For the system to be perfectly secure, every possible $k$-length substring captured from anywhere within $S$ must be unique. If a $k$-length string appears more than once in the ledger, the system is compromised.

Find the smallest integer $k$ such that no two distinct substrings of length $k$ in the ledger $S$ are identical.
