Looking at this problem, I need to find ∠PAQ in a triangle with ∠A = 20°, ∠C = 7
0°, ∠B = 90°.

## Proof

**Setup.** Since ∠A + ∠C = 90°, we have ∠B = 90°. Place B at the origin, C = (1,
 0), A = (0, tan70°). Let t = tan70°. The circumcenter O of a right triangle is
the midpoint of the hypotenuse AC, so O = (1/2, t/2).

**Key angle at B.** Triangle AOB is isosceles (OA = OB = circumradius). Since ∠O
AB = ∠BAC = 20°, we get ∠ABO = 20°, hence ∠OBC = 90° − 20° = 70°.

**Locating D.** BO bisects ∠ABD, so ∠ABD = 2·∠ABO = 40°, giving ∠DBC = 50°. Thus
 ray BD makes angle 50° with BC (the x-axis).

**Locating E.** BE bisects ∠CBD = 50°, so ∠CBE = 25°. Ray BE makes angle 25° wit
h BC.

**Parametrizing AC.** Points on AC: (s, t(1−s)) for s ∈ [0,1]. A ray from B at a
ngle α (from x-axis) has direction (cos α, sin α) and meets AC when:
$$\lambda \sin\alpha = t(1 - \lambda\cos\alpha) \implies \lambda = \frac{t}{\sin
\alpha + t\cos\alpha}.$$

Using the identity $\sin\alpha + \tan70°\cos\alpha = \frac{\sin(\alpha+70°)}{\co
s70°}$, the parameter values are:
$$s_D = \frac{\sin70°\cos50°}{\sin120°}, \qquad s_E = \frac{\sin70°\cos25°}{\sin
95°}.$$

**Projecting onto BC.** The perpendicular to AC has direction (t, 1). From point
 D = (s_D, t(1−s_D)), dropping perpendicular to AC and finding where it meets li
ne BC (y = 0) gives:
$$P_x = s_D(1+t^2) - t^2 = \frac{s_D}{\cos^2 70°} - \tan^2 70°.$$

Dividing by t = tan70°:
$$\frac{P_x}{t} = \frac{\cos50°/\sin120° - \sin70°}{\cos70°}.$$

Now simplify the numerator. Since $\sin120° = \cos30°$:
$$\frac{\cos50°}{\sin120°} = \frac{\cos50°}{\cos30°} = \frac{\sin40°}{\cos30°} =
 \frac{\sin(70°-30°)}{\cos30°} = \frac{\sin70°\cos30° - \cos70°\sin30°}{\cos30°}
 = \sin70° - \tan30°\cos70°.$$

Therefore:
$$\frac{P_x}{t} = \frac{(\sin70° - \tan30°\cos70°) - \sin70°}{\cos70°} = -\tan30
°.$$

By identical reasoning for Q, using $\sin95° = \cos5°$ and $\cos25° = \sin65° =
\sin(70°-5°)$:
$$\frac{\cos25°}{\sin95°} = \frac{\sin65°}{\cos5°} = \frac{\sin(70°-5°)}{\cos5°}
 = \sin70° - \tan5°\cos70°,$$
$$\frac{Q_x}{t} = \frac{(\sin70° - \tan5°\cos70°) - \sin70°}{\cos70°} = -\tan5°.
$$

**Computing ∠PAQ.** Both P and Q lie on line BC (the x-axis), to the left of B.
From A = (0, t):
- Ray AP makes angle $\arctan(|P_x|/t) = \arctan(\tan30°) = 30°$ with the downwa
rd vertical.
- Ray AQ makes angle $\arctan(|Q_x|/t) = \arctan(\tan5°) = 5°$ with the downward
 vertical.

Therefore:
$$\angle PAQ = 30° - 5° = \boxed{25°}.$$

### PROOF COMPLETE
