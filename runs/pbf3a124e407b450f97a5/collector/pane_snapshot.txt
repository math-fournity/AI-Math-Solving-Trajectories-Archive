## Solution

We compute the series $\displaystyle S = \sum_{k=1}^{\infty}\operatorname{arccot
}\frac{1-k^2+k^4}{2k}$.

**Key identity.** For $B > A \geq 0$, using $\operatorname{arccot} x = \frac{\pi
}{2}-\arctan x$:

$$\operatorname{arccot} A - \operatorname{arccot} B = \arctan B - \arctan A = \a
rctan\frac{B-A}{1+AB} = \operatorname{arccot}\frac{1+AB}{B-A}.$$

**Choosing $A = k^2-k$, $B = k^2+k$.** Then:
- $B - A = 2k > 0$ for all $k \geq 1$,
- $1 + AB = 1 + (k^2-k)(k^2+k) = 1 + k^4 - k^2 = k^4 - k^2 + 1$.

Therefore:
$$\operatorname{arccot}\frac{k^4-k^2+1}{2k} = \operatorname{arccot}(k^2-k) - \op

e{arccot}\big(k(k+1)\big).$$

**Telescoping.** The $N$-th partial sum is:
$$S_N = \sum_{k=1}^{N}\Big[\operatorname{arccot}\big(k(k-1)\big) - \operatorname
{arccot}\big(k(k+1)\big)\Big].$$

Writing out the terms:
- $k=1$: $\operatorname{arccot}(0) - \operatorname{arccot}(2)$
- $k=2$: $\operatorname{arccot}(2) - \operatorname{arccot}(6)$
- $k=3$: $\operatorname{arccot}(6) - \operatorname{arccot}(12)$
- $\vdots$
- $k=N$: $\operatorname{arccot}(N(N-1)) - \operatorname{arccot}(N(N+1))$

All intermediate terms cancel, giving:
$$S_N = \operatorname{arccot}(0) - \operatorname{arccot}\big(N(N+1)\big).$$

Since $\operatorname{arccot}(0) = \dfrac{\pi}{2}$ and $\operatorname{arccot}\big
(N(N+1)\big) \to 0$ as $N \to \infty$:

$$S = \lim_{N\to\infty} S_N = \frac{\pi}{2} - 0 = \boxed{\dfrac{\pi}{2}}.$$
