## Setup and Key Definitions

A set H is **quasi-complete** if every row and column has ≥1 cell in H. A set K
is **quasi-perfect** if it contains a transversal (n cells, one per row, one per
 column) as a **proper** subset, requiring both a transversal and |K| > n.

So a quasi-complete H is **not** quasi-perfect iff either:
- **(a)** H has no transversal (Hall's condition fails), or
- **(b)** |H| = n and H is itself a transversal (no proper subset of size n exis
ts).
