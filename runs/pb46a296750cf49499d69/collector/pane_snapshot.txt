Looking at this problem, I need to determine whether a continuous, a.e. differen
tiable function with $f'(x) \geq 0$ a.e. must be non-decreasing.

**Answer: No.**

**Counterexample.** Let $c:[0,1]\to[0,1]$ be the Cantor function (devil's stairc
ase). Recall that $c$ is continuous, non-decreasing, and satisfies $c'(x)=0$ for
 almost every $x\in[0,1]$ (specifically, at every point of the complement of the
 Cantor set, which is an open set of full measure).

Define $f(x) = -c(x)$ on $[0,1]$.

**Verification of the hypotheses:**

1. **Continuity:** $f$ is continuous since $c$ is continuous.

2. **Differentiable a.e.:** $c$ is differentiable a.e. (with $c'=0$ a.e.), so $f
$ is differentiable a.e. with $f'(x) = -c'(x) = 0$ for a.e. $x$.

3. **The set where $f$ is decreasing has measure 0:** The set $\{x : f'(x) < 0\}
 = \{x : -c'(x) < 0\} = \{x : c'(x) > 0\}$. Since $c'(x)=0$ for a.e. $x$, this s
et has measure $0$.

**$f$ is not increasing:** Since $c$ is non-decreasing with $c(0)=0$ and $c(1)=1
$, we have
$$f(0) = -c(0) = 0 > -1 = -c(1) = f(1).$$
Thus $f(0) > f(1)$, so $f$ is not non-decreasing (and hence not increasing in an
y sense) on $[0,1]$.

**Why the naive intuition fails.** One might expect that $f'\geq 0$ a.e. forces
$f$ to be non-decreasing via the Fundamental Theorem of Calculus. However, the F
TC in the form $f(b)-f(a)=\int_a^b f'(x)\,dx$ requires **absolute continuity**,
not merely continuity plus a.e. differentiability. The Cantor function is the ca
nonical example of a *singular* function: it is continuous and of bounded variat
ion, but its total variation is entirely concentrated on the Cantor set (a null
set), so it is not absolutely continuous. Taking its negative produces a functio
n whose derivative vanishes a.e. yet which decreases — the "missing" variation i
s hidden in the singular part, undetected by the a.e. derivative.
