我将通过将 Black-Scholes PDE 转化为一维热传导方程并使用高斯核来求解它。

## 问题重述

求解
$$\partial_t u + r s\, \partial_s u + \tfrac{\sigma^2}{2} s^2 \partial_s^2 u - r
 u = 0, \quad s>0,\; t\in[0,T],$$
其终值条件为 $u(s,T)=\max(0,s-p)$，边界条件为 $u(0,t)=0$。

## 第一步：转换为剩余期限

令 $\tau = T - t$（剩余期限，随到期日临近而减小），并令 $U(s,\tau) = u(s, T-\tau
)$。则 $\partial_t u = -\partial_\tau U$，PDE 变为
$$\partial_\tau U = \tfrac{\sigma^2}{2} s^2 \partial_s^2 U + r s\, \partial_s U
- r U, \qquad U(s,0) = (s-p)^+.$$

## 第二步：对数化变量

令 $x = \ln s$（因此 $s = e^x$，$x\in\mathbb{R}$）并令 $U(e^x,\tau) =: v(x,\tau)
$。利用链式法则：
$$\partial_s U = \tfrac{1}{s} v_x, \qquad \partial_s^2 U = \tfrac{1}{s^2}(v_{xx}
 - v_x).$$
代入后得到
$$\partial_\tau v = \tfrac{\sigma^2}{2}(v_{xx}-v_x) + r\, v_x - r v = \tfrac{\si
gma^2}{2} v_{xx} + \bigl(r-\tfrac{\sigma^2}{2}\bigr) v_x - r v,$$
初始条件为
$$v(x,0) = (e^x - p)^+.$$

## 第三步：消除漂移项和折现项

令 $\alpha = r - \sigma^2/2$ 和 $\kappa = \sigma^2/2$。设
$$v(x,\tau) = e^{-r\tau}\, w(x,\tau).$$
则 $\partial_\tau v = e^{-r\tau}(\partial_\tau w - r w)$，代入后得到
$$\partial_\tau w - r w = \kappa\, w_{xx} + \alpha\, w_x - r w \;\;\Longrightarr
ow\;\; \partial_\tau w = \kappa\, w_{xx} + \alpha\, w_x.$$

现在通过 $y = x + \alpha\tau$ 消除对流项 $\alpha w_x$，即令 $w(x,\tau) =: q(y,\t
au)$，其中 $y = x + \alpha\tau$。则
$$\partial_\tau w = \partial_\tau q + \alpha\, q_y, \qquad w_x = q_y, \qquad w_{
xx} = q_{yy},$$
因此 $\partial_\tau q + \alpha q_y = \kappa q_{yy} + \alpha q_y$，即
$$\partial_\tau q = \kappa\, q_{yy}, \qquad \kappa = \tfrac{\sigma^2}{2}.$$
这是**热传导方程**。初始条件为：在 $\tau=0$ 时，$y=x$，所以
$$q(y,0) = w(y,0) = v(y,0) = (e^y - p)^+.$$

## 第四步：通过热核求解

热传导方程 $\partial_\tau q = \kappa\, q_{yy}$ 在 $\mathbb{R}$ 上的解为
$$q(y,\tau) = \int_{-\infty}^{\infty} \frac{1}{\sqrt{4\pi\kappa\tau}}\, \exp\!\B
igl(-\frac{(y-\xi)^2}{4\kappa\tau}\Bigr)\, q(\xi,0)\,d\xi.$$

由于 $q(\xi,0) = (e^\xi - p)^+ = 0$（当 $\xi < \ln p$ 时），积分范围从 $\ln p$
到 $\infty$：
$$q(y,\tau) = \int_{\ln p}^{\infty} \frac{1}{\sqrt{4\pi\kappa\tau}}\, e^{-(y-\xi
)^2/(4\kappa\tau)}\, (e^\xi - p)\, d\xi.$$

## 第五步：计算积分

设 $d = \sqrt{2\kappa\tau} = \sigma\sqrt{\tau}$，并令 $\eta = (\xi - y)/\sqrt{2\
kappa\tau}$，因此 $\xi = y + \eta\sqrt{2\kappa\tau}$，$d\xi = \sqrt{2\kappa\tau}
\,d\eta$。则
$$q(y,\tau) = \int_{\eta_0}^{\infty} \frac{1}{\sqrt{2\pi}} e^{-\eta^2/2}\Bigl(e^
{\,y + \eta\sqrt{2\kappa\tau}} - p\Bigr)d\eta,$$
其中 $\eta_0 = (\ln p - y)/\sqrt{2\kappa\tau} = (\ln p - y)/(\sigma\sqrt\tau)$。

**第一项：** $\frac{e^y}{\sqrt{2\pi}}\int_{\eta_0}^{\infty} e^{-\eta^2/2 + \eta\
sigma\sqrt\tau}\,d\eta$。配方：$-\tfrac12(\eta - \sigma\sqrt\tau)^2 + \tfrac12\s
igma^2\tau$，因此
$$= \frac{e^{y + \sigma^2\tau/2}}{\sqrt{2\pi}}\int_{\eta_0}^{\infty} e^{-(\eta-\
sigma\sqrt\tau)^2/2}\,d\eta = e^{y+\sigma^2\tau/2}\,\Phi\!\bigl(\sigma\sqrt\tau
- \eta_0\bigr),$$
其中 $\Phi$ 为标准正态 CDF。

**第二项：** $\frac{p}{\sqrt{2\pi}}\int_{\eta_0}^{\infty} e^{-\eta^2/2}\,d\eta =
 p\,\Phi(-\eta_0)$。

因此
$$q(y,\tau) = e^{y+\sigma^2\tau/2}\,\Phi\!\bigl(\sigma\sqrt\tau - \eta_0\bigr) -
 p\,\Phi(-\eta_0).$$

## 第六步：代回原变量

我们有 $y = x + \alpha\tau = \ln s + (r-\sigma^2/2)\tau$，因此
$$-\eta_0 = \frac{y - \ln p}{\sigma\sqrt\tau} = \frac{\ln(s/p) + (r-\sigma^2/2)\
tau}{\sigma\sqrt\tau} =: d_1,$$
且 $\sigma\sqrt\tau - \eta_0 = \frac{\ln(s/p)+(r-\sigma^2/2)\tau}{\sigma\sqrt\ta
u} + \sigma\sqrt\tau = \frac{\ln(s/p)+(r+\sigma^2/2)\tau}{\sigma\sqrt\tau} =: d_
2.$

注意 $d_2 = d_1 - \sigma\sqrt\tau$（等价地 $d_1 = d_2 + \sigma\sqrt\tau$）。此外
 $e^{y+\sigma^2\tau/2} = e^{\ln s + (r-\sigma^2/2)\tau + \sigma^2\tau/2} = s\, e
^{r\tau}$。

由于 $u = U = e^{-r\tau} v = e^{-r\tau} w = e^{-r\tau} q$，折现因子 $e^{-r\tau}$
 抵消了 $e^{r\tau}$：
$$u(s,t) = s\,\Phi(d_1) - p\,e^{-r\tau}\,\Phi(d_2).$$

## 第七步：验证边界/终值条件

- **终值条件 $\tau\to 0$：** $d_1,d_2\to +\infty$（当 $s>p$ 时，$\Phi\to1$，得 $
s-p$）；$\to-\infty$（当 $s<p$ 时，$\Phi\to0$，得 $0$）；在 $s=p$ 处连续。因此 $
u(s,T)=(s-p)^+$。 ✓
- **边界 $s=0$：** $\ln(s/p)\to-\infty$，$d_1,d_2\to-\infty$，$\Phi\to0$，因此 $
u(0,t)=0$。 ✓
- **PDE：** 变量代换是可逆的微分同胚，且 $q$ 满足热传导方程，因此 $u$ 满足 Black
-Scholes PDE。 ✓

## 结论

Black-Scholes PDE 在给定终值条件 $u(s,T)=\max(0,s-p)$ 和边界条件 $u(0,t)=0$ 下的
解为：

$$\boxed{\;u(s,t) \;=\; s\,\Phi(d_1) \;-\; p\,e^{-r(T-t)}\,\Phi(d_2)\;}$$

其中
$$d_1 = \frac{\ln(s/p) + (r + \tfrac{\sigma^2}{2})(T-t)}{\sigma\sqrt{T-t}}, \qqu
ad d_2 = d_1 - \sigma\sqrt{T-t} = \frac{\ln(s/p) + (r - \tfrac{\sigma^2}{2})(T-t
)}{\sigma\sqrt{T-t}},$$

且 $\Phi$ 为标准正态累积分布函数 $\Phi(z)=\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{z
}e^{-\xi^2/2}\,d\xi$。
