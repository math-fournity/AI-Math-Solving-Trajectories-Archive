## Solution

Let $f(t, x) = (x + t)e^{-x + kt}$, so $Y_t = f(t, W_t)$. We apply Itô's lemma.

**Partial derivatives.**

$$f_t = e^{-x+kt} + (x+t)\cdot k\,e^{-x+kt} = e^{-x+kt}\bigl[1 + k(x+t)\bigr]$$

$$f_x = e^{-x+kt} + (x+t)(-1)e^{-x+kt} = e^{-x+kt}\bigl[1 - (x+t)\bigr]$$

$$f_{xx} = \frac{\partial}{\partial x}\Bigl[e^{-x+kt}(1-x-t)\Bigr] = -e^{-x+kt}(
1-x-t) - e^{-x+kt} = e^{-x+kt}\bigl[x+t-2\bigr]$$

**Itô's lemma.**

$$dY_t = \left(f_t + \tfrac{1}{2}f_{xx}\right)dt + f_x\,dW_t$$

The drift coefficient is

$$f_t + \tfrac{1}{2}f_{xx} = e^{-x+kt}\Bigl[1 + k(x+t)\Bigr] + \tfrac{1}{2}e^{-x
+kt}\bigl[x+t-2\bigr]$$

$$= e^{-x+kt}\Bigl[1 + k(x+t) + \tfrac{1}{2}(x+t) - 1\Bigr]$$

$$= e^{-x+kt}\,(x+t)\left(k + \tfrac{1}{2}\right).$$

**Zero-drift condition.** For $Y_t$ to have zero drift, this expression must van
ish for all $t \ge 0$ and all values of $W_t$. The factor $e^{-W_t+kt} > 0$ is n
ever zero, and the factor $(W_t + t)$ is not identically zero (e.g. at $t=0$, $W
_0+t=0$, but for $t>0$ it takes nonzero values almost surely). Therefore the onl
y way the drift vanishes identically is

$$k + \tfrac{1}{2} = 0.$$

**Conclusion.**

$$\boxed{k = -\dfrac{1}{2}}$$

With this choice, $dY_t = e^{-W_t - t/2}(1 - W_t - t)\,dW_t$, which is a (local)
 martingale with zero drift.
