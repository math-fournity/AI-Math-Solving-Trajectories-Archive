## Proof

**Simplify the integrand.** Since $\sin(2x) = 2\sin x\cos x$,

$$\frac{\sin(2x)^x}{2^x} = \frac{(2\sin x\cos x)^x}{2^x} = (\sin x\cos x)^x.$$

So the integral becomes

$$I = \int_0^{\pi/2} (\sin x\cos x)^x\Big[\ln(\sin x)+\ln(\cos x)-x(\tan x-\cot
x)\Big]\,dx.$$

**Recognize the integrand as a total derivative.** Set $g(x) = (\sin x\cos x)^x
= e^{\,x\ln(\sin x\cos x)}$. Then

$$g'(x) = (\sin x\cos x)^x\cdot\frac{d}{dx}\Big[x\ln(\sin x\cos x)\Big] = (\sin
x\cos x)^x\Big[\ln(\sin x\cos x)+x\cdot\frac{d}{dx}\ln(\sin x\cos x)\Big].$$

Now $\ln(\sin x\cos x) = \ln(\sin x)+\ln(\cos x)$, and

$$\frac{d}{dx}\ln(\sin x\cos x)=\frac{\cos^2 x-\sin^2 x}{\sin x\cos x}=\frac{\co
s(2x)}{\sin x\cos x}.$$

Also,

$$\tan x-\cot x = \frac{\sin x}{\cos x}-\frac{\cos x}{\sin x}=\frac{\sin^2 x-\co
s^2 x}{\sin x\cos x}=-\frac{\cos(2x)}{\sin x\cos x},$$

hence $-x(\tan x-\cot x)=x\cdot\frac{\cos(2x)}{\sin x\cos x}$. Therefore the bra
cket in the integrand is exactly

$$\ln(\sin x)+\ln(\cos x)-x(\tan x-\cot x)=\ln(\sin x\cos x)+x\cdot\frac{\cos(2x
)}{\sin x\cos x}=\frac{d}{dx}\Big[x\ln(\sin x\cos x)\Big].$$

Thus the integrand equals $g'(x)$, and

$$I = \int_0^{\pi/2} g'(x)\,dx = \Big[(\sin x\cos x)^x\Big]_0^{\pi/2}.$$

**Evaluate the boundary values.**

- As $x\to(\pi/2)^-$: $\sin x\cos x\to 0^+$ while $x\to\pi/2>0$, so $(\sin x\cos
 x)^x\to 0$.
- As $x\to 0^+$: $(\sin x\cos x)^x = e^{x\ln(\sin x\cos x)}$. Here $x\to 0$ and
$\ln(\sin x\cos x)\to-\infty$, but $x\ln(\sin x\cos x)\to 0$ (since $x\ln x\to 0
$), so the limit is $e^0=1$.

Therefore

$$I = 0 - 1 = -1.$$
