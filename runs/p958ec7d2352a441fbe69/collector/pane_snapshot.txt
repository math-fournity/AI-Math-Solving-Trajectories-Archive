**Answer: Yes, such a sequence exists.**

## Proof

**Construction (Greedy Algorithm).** Set $a_1 = 1$. For $N \geq 2$, given $a_1,
\dots, a_{N-1}$, let $S_{N-1} = \sum_{k=1}^{N-1} a_k$ and define the required re
sidue $r_N \equiv -S_{N-1} \pmod{N}$. Choose $a_N$ to be the **smallest unused**
 positive integer congruent to $r_N$ modulo $N$.

This is always possible since the residue class is infinite and only finitely ma
ny numbers have been used. By construction, $N \mid S_N$ for all $N$. It remains
 to prove the resulting sequence is a permutation of $\mathbb{N}$.

**Setup.** Define $c_N = S_N / N$ (an integer by construction). Since $S_{N-1} =
 (N-1)c_{N-1}$, the required residue at step $N$ is:
$$r_N \equiv -(N-1)c_{N-1} \equiv c_{N-1} \pmod{N}.$$

We write $a_N = c_{N-1} + j_N \cdot N$ where $j_N \geq 0$ is the smallest intege
r making $c_{N-1} + j_N N$ a positive unused integer. Then:
$$c_N = \frac{S_{N-1} + a_N}{N} = \frac{(N-1)c_{N-1} + c_{N-1} + j_N N}{N} = c_{
N-1} + j_N.$$

**Claim 1 (Boundedness):** $c_N \leq N$ and $j_N \in \{0, 1\}$ for all $N \geq 1
$.

*Proof by strong induction.* Base: $c_1 = 1 \leq 1$. ✓

Inductive step: Assume $c_k \leq k$ and $j_k \in \{0,1\}$ for all $k < N$. Then
$c_{N-1} \leq N-1 < N$, so $r_N = c_{N-1}$.

Every number used before step $N$ is of one of two types:
- **Pick numbers** ($j_k = 0$): $a_k = c_{k-1}$. Since $c$ is non-decreasing, al
l pick numbers satisfy $c_{k-1} \leq c_{N-1}$.
- **Jump numbers** ($j_k = 1$): $a_k = c_{k-1} + k$. For $k < N$, using $c_{k-1}
 \leq c_{N-2} \leq c_{N-1}$:
$$c_{k-1} + k \leq c_{N-1} + (N-1) < c_{N-1} + N.$$

Therefore $c_{N-1} + N$ **exceeds every previously used number** (it is greater
than all pick numbers and all jump numbers), so it is unused.

- If $c_{N-1}$ is **unused**: $a_N = c_{N-1}$, so $j_N = 0$, $c_N = c_{N-1} \leq
 N-1 \leq N$. ✓
- If $c_{N-1}$ is **used**: $c_{N-1}$ is used and $c_{N-1}+N$ is unused, so $a_N
 = c_{N-1} + N$, giving $j_N = 1$, $c_N = c_{N-1} + 1 \leq N$. ✓

This completes the induction. ∎

**Claim 2 (Divergence):** $c_N \to \infty$.

After a pick step ($j_N = 0$), the value $c_{N-1}$ becomes used, forcing the nex
t step to be a jump ($j_{N+1} = 1$). Thus **no two consecutive steps are both pi
cks**, so $c$ increases by $1$ at least every two steps. Hence $c_N \geq 1 + \lf
loor N/2 \rfloor \to \infty$. ∎

**Claim 3 (Surjectivity):** Every positive integer $m$ appears in the sequence.

Since $c$ is non-decreasing, increases by $0$ or $1$, and $c_N \to \infty$, the
sequence $(c_N)$ attains every positive integer value. Let $N$ be the first inde
x with $c_{N-1} = m$.

- **Case 1:** $m$ is unused at step $N$. Then $a_N = m$ (greedy picks it), so $m
$ is in the sequence.
- **Case 2:** $m$ is already used at step $N$. Then $m$ was used at some earlier
 step $k < N$ as a jump number $a_k = c_{k-1} + k = m$, so $m$ is in the sequenc
e.

In both cases, $m$ appears. Since the greedy algorithm never selects a previousl
y used number, each $m$ appears **exactly once**. ∎

**Conclusion.** The greedy algorithm produces a sequence $(a_n)$ that is a permu
tation of $\mathbb{N}$ (every natural number appears exactly once) and satisfies
 $N \mid \sum_{k=1}^N a_k$ for every positive integer $N$.
