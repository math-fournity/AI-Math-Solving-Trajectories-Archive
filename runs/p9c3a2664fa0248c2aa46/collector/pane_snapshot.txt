## Key Setup

$$S = \{\varepsilon_1 a + \varepsilon_2 b + \varepsilon_3 c + \varepsilon_4 d :
\varepsilon_i \in \{-1, 0, 1\}\}$$

This set has at most $3^4 = 81$ elements (including 0). By the symmetry $\vareps

## When Can Mass *m* Be Determined?

With unlimited adaptive weighings, we can determine $m \in \{1, \dots, n\}$ if a
nd only if every consecutive pair $(k, k+1)$ can be **separated** by some testab
le value. Specifically, for each $k = 1, \dots, n-1$, there must exist $s \in S$
 with $k \le s \le k+1$.

**Necessity:** If no $s \in S$ lies in $[k, k+1]$, then every testable value is
either $\le k$ or $\ge k+1$. Testing $m$ against any such $s$ cannot distinguish
 $m = k$ from $m = k+1$ (both give the same comparison result). So once we narro
w to $\{k, k+1\}$, we're stuck.

**Sufficiency:** If every interval $[k, k+1]$ contains a testable value $s_k$, w
e can **binary search**: test $m$ against $s_k$ for a suitable $k$. The outcome
tells us whether $m \le k$ or $m \ge k+1$ (or $m = s_k$ if $s_k$ is an integer).
 Recursively splitting the candidate range identifies $m$ exactly.

## Upper Bound: *n* ≤ 81

Each positive testable value $s$ covers those $k$ with $k \le s \le k+1$, i.e.,
$k \in [s-1, s] \cap \mathbb{Z}$:
- If $s$ is an **integer**: covers $k = s-1$ and $k = s$ (at most **2** values).
- If $s$ is **non-integer**: covers $k = \lfloor s \rfloor$ (exactly **1** value
).

With at most **40 distinct positive testable values**, each covering at most **2
** values of $k$, the total number of separable pairs is at most $40 \times 2 =
80$. Therefore:

$$n - 1 \le 80 \implies n \le 81.$$

## Construction Achieving *n* = 81

Choose weights $\mathbf{2, 6, 18, 54}$ (i.e., $2 \times \{1, 3, 9, 27\}$, twice
the balanced ternary weights).

The testable values are:
$$S = \{2(\varepsilon_1 + 3\varepsilon_2 + 9\varepsilon_3 + 27\varepsilon_4)\} =
 \{0, \pm 2, \pm 4, \dots, \pm 80\}.$$

Since $\{1, 3, 9, 27\}$ are powers of 3, the balanced ternary representation is
unique, so all **81 values are distinct**. The 40 positive values are $\{2, 4, 6

Each even integer $2j$ (for $j = 1, \dots, 40$) covers $k = 2j-1$ and $k = 2j$:

All $k$ from 1 to 80 are covered with **no gaps and no overlaps**. Thus $n - 1 =
