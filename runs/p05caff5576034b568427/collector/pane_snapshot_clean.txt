## Key Observation

Each vertex in $K_n$ has degree $n-1$. A Universal Node must see all $n-1$ color
s among its $n-1$ incident edges. Since there are exactly $n-1$ edges and $n-1$
colors required, **every incident edge of a Universal Node must have a distinct
color**. In other words, a Universal Node is a *rainbow vertex* — all its edges
bear different colors.

If **all** $n$ vertices are Universal, then every vertex has all-distinct edge c
olors, meaning the coloring is a **proper edge coloring** of $K_n$ using $n-1$ c
olors.

## Upper Bound

**Case 1: $n$ even.** All $n$ vertices can potentially be Universal. (No contrad
iction yet.)

**Case 2: $n$ odd.** Suppose all $n$ vertices are Universal. Then the coloring i
s a proper edge coloring of $K_n$ with $n-1$ colors. But by the classical result
 on edge-chromatic numbers:

$$\chi'(K_n) = \begin{cases} n-1 & \text{if } n \text{ is even} \\ n & \text{if
} n \text{ is odd} \end{cases}$$

For odd $n$, $\chi'(K_n) = n > n-1$, so **no proper $(n-1)$-edge-coloring exists
**. Therefore not all $n$ vertices can be Universal, giving an upper bound of **
$n-1$** for odd $n$.

*Proof of $\chi'(K_n) = n$ for odd $n$:* In any proper edge coloring, each color
 class is a matching. In $K_n$ with $n$ odd, a matching has at most $\frac{n-1}{
2}$ edges, so $n-1$ colors cover at most $(n-1)\cdot\frac{n-1}{2} = \frac{(n-1)^
2}{2}$ edges. But $K_n$ has $\frac{n(n-1)}{2}$ edges. Since $\frac{(n-1)^2}{2} <
 \frac{n(n-1)}{2}$ for $n \geq 2$, we cannot cover all edges — contradiction. $\
square$

## Lower Bound (Constructions)

**Case 1: $n$ even — achieve $n$ Universal Nodes.**

Since $\chi'(K_n) = n-1$ for even $n$, there exists a proper $(n-1)$-edge-colori
ng of $K_n$. In such a coloring, each color class is a perfect matching of size
$n/2$, so all $n-1$ colors are used (total: $(n-1)\cdot n/2 = \binom{n}{2}$ edge
s ✓). Every vertex has $n-1$ edges with $n-1$ distinct colors, hence sees all $n
-1$ colors. **All $n$ vertices are Universal.**

**Case 2: $n$ odd — achieve $n-1$ Universal Nodes.**

Pick one vertex $v$ to be the non-Universal node. The remaining $n-1$ vertices (
an even number) induce $K_{n-1}$, which admits a proper $(n-2)$-edge-coloring us
ing colors $\{1, 2, \ldots, n-2\}$. In this coloring, each of the $n-1$ vertices
 sees all $n-2$ colors on its $n-2$ internal edges.

Now color **all** $n-1$ edges from $v$ to the other vertices with the remaining
color $n-1$.

- Each of the $n-1$ vertices now sees colors $\{1, \ldots, n-2\}$ from its inter
nal edges plus color $n-1$ from its edge to $v$ — **all $n-1$ colors** → Univers
al. ✓
- Vertex $v$ sees only color $n-1$ — not Universal (as intended).
- All $n-1$ colors are used: colors $1, \ldots, n-2$ in $K_{n-1}$, color $n-1$ o
n edges from $v$. ✓

This gives **$n-1$ Universal Nodes**.
