# Nondimensionalization and Stability Analysis of the CO₂ Delay Differential Equ
ation

## 1. The Steady State

The governing equation is
$$\frac{dc(t)}{dt} = p - \frac{b\,V_{\max}\,c(t)\,c^m(t-T)}{a^m + c^m(t-T)}.$$

At a steady state $c(t)=c(t-T)=c_*$ with $\dot c = 0$:
$$p = \frac{b\,V_{\max}\,c_*^{\,m+1}}{a^m + c_*^{\,m}}. \tag{1}$$

## 2. Nondimensionalization

Introduce the dimensionless variables
$$c(t) = c_*\,u(\tau), \qquad \tau = \frac{t}{T},$$
so that the delay $T$ becomes a unit delay in $\tau$. Define the dimensionless p
arameter
$$\alpha = \frac{a}{c_*}.$$

Substituting and dividing the numerator and denominator of the Hill-type term by
 $c_*^{\,m}$:
$$\frac{c_*}{T}\frac{du}{d\tau} = p - \frac{b\,V_{\max}\,c_*\,u(\tau)\,u^m(\tau-
1)}{\alpha^m + u^m(\tau-1)}.$$

Using (1) in the form $p = \dfrac{b\,V_{\max}\,c_*}{\alpha^m+1}$ and dividing th
rough:
$$\frac{du}{d\tau} = \mu\left[1 - \frac{(\alpha^m+1)\,u(\tau)\,u^m(\tau-1)}{\alp
ha^m + u^m(\tau-1)}\right], \tag{2}$$
where the single dimensionless parameter grouping the delay is
$$\boxed{\mu = \frac{T\,b\,V_{\max}}{\alpha^m + 1} = \frac{T\,b\,V_{\max}\,c_*^{
\,m}}{a^m + c_*^{\,m}}.} \tag{3}$$

The steady state of (2) is $u=1$, corresponding to $c=c_*$, as is readily verifi
ed.

## 3. Linearization about $u=1$

Set $u(\tau) = 1 + \varepsilon\,v(\tau)$ and expand the right-hand side of (2) t
o first order. Define
$$h(u,w) = \frac{(\alpha^m+1)\,u\,w^m}{\alpha^m+w^m}.$$

At $(u,w)=(1,1)$: $h=1$, and the partial derivatives are
$$h_u\Big|_{(1,1)} = \frac{(\alpha^m+1)\,w^m}{\alpha^m+w^m}\Bigg|_{(1,1)} = 1,$$
$$h_w\Big|_{(1,1)} = (\alpha^m+1)\,u\,\frac{m\,w^{m-1}\,\alpha^m}{(\alpha^m+w^m)
^2}\Bigg|_{(1,1)} = \frac{m\,\alpha^m}{\alpha^m+1}.$$

Introducing the **feedback gain**
$$\boxed{\beta = \frac{m\,\alpha^m}{\alpha^m+1} = \frac{m\,a^m}{a^m + c_*^{\,m}}
,} \tag{4}$$
the linearized equation is
$$\frac{dv}{d\tau} = -\mu\,v(\tau) - \mu\,\beta\,v(\tau-1). \tag{5}$$

## 4. Characteristic Equation

Seeking solutions $v(\tau)=e^{\lambda\tau}$ in (5) gives the characteristic equa
tion
$$\boxed{\lambda + \mu + \mu\,\beta\,e^{-\lambda} = 0.} \tag{6}$$

The steady state is (locally asymptotically) stable if and only if every root $\
lambda$ of (6) satisfies $\operatorname{Re}(\lambda)<0$.

**No-delay limit ($T\to 0$, i.e. $\mu\to 0$):** Equation (6) reduces to $\lambda
 = -\mu(1+\beta)<0$, so the steady state is stable for sufficiently small delay.

## 5. Hopf Bifurcation: Loss of Stability

We determine when a root of (6) crosses the imaginary axis. Set $\lambda = i\ome
ga$ with $\omega>0$:
$$i\omega + \mu + \mu\,\beta(\cos\omega - i\sin\omega) = 0.$$

Separating real and imaginary parts:
$$\mu(1 + \beta\cos\omega) = 0 \;\;\Longrightarrow\;\; \cos\omega = -\frac{1}{\b
eta}, \tag{7}$$
$$\omega - \mu\,\beta\sin\omega = 0 \;\;\Longrightarrow\;\; \mu = \frac{\omega}{
\beta\sin\omega}. \tag{8}$$

**Necessary condition for a crossing.** Equation (7) requires $|\beta|\geq 1$. S
ince $\beta>0$, this demands
$$\beta \geq 1 \quad\Longleftrightarrow\quad \frac{m\,a^m}{a^m + c_*^{\,m}} \geq
 1 \quad\Longleftrightarrow\quad (m-1)\,a^m \geq c_*^{\,m}. \tag{9}$$

This in particular requires the Hill exponent $m>1$.

- **If $\beta < 1$** (i.e. $(m-1)a^m < c_*^{\,m}$): no root can cross the imagin
ary axis. The steady state remains stable for **all** $T>0$; there is no finite
bifurcation value.

- **If $\beta > 1$** (i.e. $(m-1)a^m > c_*^{\,m}$): there is a unique $\omega_c\
in(\pi/2,\pi)$ satisfying (7):
$$\omega_c = \arccos\!\left(-\frac{1}{\beta}\right), \qquad \sin\omega_c = \frac
{\sqrt{\beta^2-1}}{\beta}. \tag{10}$$

Substituting into (8):
$$\mu_c = \frac{\omega_c}{\beta\sin\omega_c} = \frac{\omega_c}{\sqrt{\beta^2-1}}
. \tag{11}$$

Using (3) to convert back to the physical delay:
$$\boxed{T_c = \frac{\mu_c\,(\alpha^m+1)}{b\,V_{\max}} = \frac{(\alpha^m+1)\,\om
ega_c}{b\,V_{\max}\,\sqrt{\beta^2-1}} = \frac{(a^m+c_*^{\,m})\,\omega_c}{c_*^{\,
m}\,b\,V_{\max}\,\sqrt{\beta^2-1}},} \tag{12}$$
with $\omega_c$ and $\beta$ given by (10) and (4).

## 6. Transversality (Genuine Hopf Bifurcation)

To confirm the crossing is from stable to unstable (a Hopf bifurcation, not mere
ly a tangency), differentiate (6) implicitly in $\mu$:
$$\frac{d\lambda}{d\mu} = -\frac{1+\beta\,e^{-\lambda}}{1-\mu\,\beta\,e^{-\lambd
a}}.$$

At $\lambda=i\omega_c$, $\mu=\mu_c$, using (7):
$$1+\beta\,e^{-i\omega_c} = 1+\beta\!\left(-\tfrac{1}{\beta}-i\tfrac{\sqrt{\beta
^2-1}}{\beta}\right) = -i\sqrt{\beta^2-1},$$
$$1-\mu_c\beta\,e^{-i\omega_c} = 1+\mu_c + i\,\mu_c\sqrt{\beta^2-1}.$$

Hence
$$\operatorname{Re}\!\left(\frac{d\lambda}{d\mu}\right)\Bigg|_{\mu_c} = \frac{\m
u_c(\beta^2-1)}{(1+\mu_c)^2+\mu_c^2(\beta^2-1)} > 0.$$

The real part of $\lambda$ increases through zero as $\mu$ (equivalently $T$) pa
sses $\mu_c$ (equivalently $T_c$), so the stability loss is a **transcritical Ho
pf bifurcation** producing a family of periodic solutions.

## 7. Summary: Stability Relation and Bifurcation

The steady state $c_*$ defined by (1) is **locally asymptotically stable** if an
d only if
$$\boxed{T < T_c,} \tag{13}$$
where $T_c$ is given by (12), **provided** the feedback gain exceeds unity:
$$\beta = \frac{m\,a^m}{a^m+c_*^{\,m}} > 1 \quad\Longleftrightarrow\quad (m-1)\,
a^m > c_*^{\,m}. \tag{14}$$

- When (14) holds, increasing the delay $T$ through the critical value $T_c$ tri
ggers a **Hopf bifurcation**: the stable steady state loses stability and a bran
ch of periodic (oscillatory) solutions emanates. This is the origin of Cheyne–St
okes-type periodic breathing in the CO₂ control model.
- When (14) fails (in particular for $m\leq 1$, or when $c_*$ is large relative
to $a$), the steady state is stable for all $T\geq 0$ and no finite bifurcation
value exists.

The critical delay in closed form is
$$T_c = \frac{(a^m+c_*^{\,m})}{c_*^{\,m}\,b\,V_{\max}}\cdot\frac{\arccos\!\left(
-\dfrac{a^m+c_*^{\,m}}{m\,a^m}\right)}{\sqrt{\left(\dfrac{m\,a^m}{a^m+c_*^{\,m}}
\right)^{\!2}-1}},$$
with $c_*$ determined implicitly by (1). This establishes the existence of a bif
urcation value $T_c$ for the delay whenever condition (14) is satisfied.
