## Proof

Let $X$ be a topological space. We compute the unoriented bordism group $\Omega_
0(X)$ and the oriented bordism group $\Omega_0^{\mathrm{SO}}(X)$ from the defini
tion, without appealing to the general Thom/Conner–Floyd isomorphism (though our
 result agrees with it).

A **0-dimensional manifold** is a finite discrete set of points. A **0-dimension
al manifold over $X$** (a bordism cycle) is a continuous map $f:M\to X$ where $M
$ is a compact 0-manifold. Since $M$ is discrete, $f$ is simply a finite list of
 points $x_1,\dots,x_n\in X$ (with multiplicity). Two cycles $f_0:M_0\to X$ and
$f_1:M_1\to X$ are **bordant** if there exists a compact 1-manifold $W$ with $\p
artial W = M_0\sqcup M_1$ and a map $F:W\to X$ restricting to $f_0,f_1$ on the b
oundary.

A compact 1-manifold is a disjoint union of finitely many circles $S^1$ and inte
rvals $[0,1]$. Circles have empty boundary; each interval contributes exactly tw
o endpoints to $\partial W$, and $F$ maps each interval into a single path compo
nent of $X$.

---

### Unoriented case: $\Omega_0(X)$

Here $M$ carries no orientation. For a cycle $f:M\to X$ and a path component $C\
subseteq X$, let $n_C(M)=|f^{-1}(C)|$ be the number of points (with multiplicity
) landing in $C$.

**Bordism invariance.** If $\partial W=M_0\sqcup M_1$, each interval of $W$ has
both endpoints in one path component $C$ and contributes $2$ to $n_C(M_0)+n_C(M_
1)$. Hence
$$n_C(M_0)+n_C(M_1)\equiv 0\pmod 2,\quad\text{i.e.}\quad n_C(M_0)\equiv n_C(M_1)
\pmod 2.$$
So the parity of $n_C$ is a bordism invariant.

**Completeness.** Conversely, suppose $n_C(M_0)\equiv n_C(M_1)\pmod 2$ for every
 path component $C$. Within a fixed component $C$ (which is path-connected), pai
r up points of $M_0|_C$ with points of $M_1|_C$ using intervals; the leftover po
ints on each side have even cardinality (since the parities agree), and pair tho
se leftovers among themselves with intervals whose both endpoints lie on the sam
e side. Each interval is mapped to a path in $C$. Doing this for every component
 yields a bordism $W$ between $M_0$ and $M_1$.

Thus the map
$$\Omega_0(X)\longrightarrow \bigoplus_{C\in\pi_0(X)}\mathbb Z/2,\qquad [f:M\to
X]\mapsto \big(n_C(M)\bmod 2\big)_{C\in\pi_0(X)}$$
is a well-defined isomorphism. The group operation (disjoint union) corresponds
to addition mod 2, and the inverse of a cycle is itself (since $n_C+n_C\equiv 0$
).

$$\boxed{\;\Omega_0(X)\cong \bigoplus_{\pi_0(X)}\mathbb Z/2 \;=\; H_0(X;\mathbb
Z/2).\;}$$

(For $X=\varnothing$, $\pi_0(X)=\varnothing$ and the direct sum is $0$, consiste
nt with the only cycle being the empty manifold.)

### Oriented case: $\Omega_0^{\mathrm{SO}}(X)$

Now each point of $M$ carries an orientation $\varepsilon_i\in\{+1,-1\}$. The **
reversed** cycle $-M$ flips every sign. A bordism between $f_0:M_0\to X$ and $f_
1:M_1\to X$ is an *oriented* compact 1-manifold $W$ with $\partial W = M_0\sqcup
(-M_1)$ and a map $F:W\to X$.

For a path component $C$, define the signed count
$$\sigma_C(M)=\sum_{\substack{i\\ x_i\in C}}\varepsilon_i\in\mathbb Z.$$

**Bordism invariance.** An oriented interval $[0,1]$ has boundary orientation $-
1$ at $0$ and $+1$ at $1$. Hence each interval of $W$ lying in component $C$ con
tributes $+1$ and $-1$ to the signed count of $\partial W$ in $C$. Summing,
$$\sigma_C(M_0)-\sigma_C(M_1)=0,\qquad\text{i.e.}\quad \sigma_C(M_0)=\sigma_C(M_
1).$$
So $\sigma_C$ is a bordism invariant.

**Completeness.** Conversely, suppose $\sigma_C(M_0)=\sigma_C(M_1)$ for every $C
$. Fix a component $C$. Pair a $+1$-point of $M_0|_C$ with a $+1$-point of $-M_1
|_C$ (i.e. a $-1$-point of $M_1|_C$) by an oriented interval whose $+1$-end is t
he $M_0$ point and $-1$-end is the $-M_1$ point; similarly pair $-1$-points of $
M_0$ with $+1$-points of $-M_1$. The equality $\sigma_C(M_0)=\sigma_C(M_1)$ guar
antees that after pairing across the two sides, the remaining unmatched points o
n each side have signed sum $0$, so they can be paired among themselves by orien
ted intervals (a $+1$ with a $-1$ on the same side). Path-connectedness of $C$ s
upplies the maps. Repeating over all components builds the bordism $W$.

Thus the map
$$\Omega_0^{\mathrm{SO}}(X)\longrightarrow \bigoplus_{C\in\pi_0(X)}\mathbb Z,\qq
uad [f:M\to X]\mapsto \big(\sigma_C(M)\big)_{C\in\pi_0(X)}$$
is a well-defined isomorphism. Disjoint union corresponds to addition of signed
counts, and the inverse of a cycle is obtained by reversing all orientations (ne
gating every $\varepsilon_i$).

$$\boxed{\;\Omega_0^{\mathrm{SO}}(X)\cong \bigoplus_{\pi_0(X)}\mathbb Z \;=\; H_
0(X;\mathbb Z).\;}$$

(For $X=\varnothing$ this gives $0$, again consistent with the empty cycle being
 the only one.)

### Summary

For a topological space $X$ with set of path components $\pi_0(X)$:

$$\Omega_0(X)\cong \bigoplus_{\pi_0(X)}\mathbb Z/2 \;=\; H_0(X;\mathbb Z/2),\qqu
ad \Omega_0^{\mathrm{SO}}(X)\cong \bigoplus_{\pi_0(X)}\mathbb Z \;=\; H_0(X;\mat
hbb Z).$$

The unoriented group records the parity of the number of points in each path com
ponent; the oriented group records the signed (integer) count of points in each
path component. Both are free (respectively $\mathbb Z/2$-vector-space) objects
generated by the path components of $X$, and both vanish when $X$ is empty.
