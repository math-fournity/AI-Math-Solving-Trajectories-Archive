**Answer: Yes, $(K_{1},\tau)$ is metrizable.**

**Proof.**

Let $\mathbb{F}\in\{\mathbb{R},\mathbb{C}\}$ denote the scalar field. Write $q:K
\to K_{1}$ for the quotient map.

**Step 1. The functions $f_{n}$ descend to $K_{1}$.**

Since $t_{1}Rt_{2}\Rightarrow f_{n}(t_{1})=f_{n}(t_{2})$, each $f_{n}$ is consta
nt on $R$-equivalence classes. Hence there are well-defined maps
$$g_{n}:K_{1}\to\mathbb{F},\qquad g_{n}([t]):=f_{n}(t).$$
For any open $U\subseteq\mathbb{F}$,
$$g_{n}^{-1}(U)\text{ is open in }K_{1}\iff q^{-1}(g_{n}^{-1}(U))=f_{n}^{-1}(U)\
text{ is open in }K,$$
and the latter holds because $f_{n}$ is continuous. Thus each $g_{n}$ is continu
ous on $(K_{1},\tau)$.

**Step 2. The family $\{g_{n}\}_{n}$ separates the points of $K_{1}$.**

If $[t_{1}]\neq[t_{2}]$, then by definition $t_{1}\not R\,t_{2}$, so there exist
s $n$ with $f_{n}(t_{1})\neq f_{n}(t_{2})$, i.e. $g_{n}([t_{1}])\neq g_{n}([t_{2
}])$.

**Step 3. $K_{1}$ is compact Hausdorff.**

$K$ is compact and $q$ is a continuous surjection, so $K_{1}$ is compact. To see
 that $K_{1}$ is Hausdorff, it suffices (for a quotient of a compact Hausdorff s
pace) to show that $R$ is closed in $K\times K$. Indeed
$$R=\bigcap_{n}\{(t_{1},t_{2})\in K\times K:f_{n}(t_{1})=f_{n}(t_{2})\}.$$
Each set in the intersection is $(f_{n}\times f_{n})^{-1}(\Delta_{\mathbb{F}})$,
 where $\Delta_{\mathbb{F}}$ is the diagonal in $\mathbb{F}\times\mathbb{F}$; si
nce $\mathbb{F}$ is Hausdorff, $\Delta_{\mathbb{F}}$ is closed, and $f_{n}\times
 f_{n}$ is continuous, so each set is closed. Hence $R$ is closed, and therefore
 $K_{1}$ is compact Hausdorff.

**Step 4. Embedding into a metrizable product.**

Define
$$\Phi:K_{1}\to\mathbb{F}^{\mathbb{N}},\qquad \Phi([t]):=(g_{n}([t]))_{n}=(f_{n}
(t))_{n}.$$
- $\Phi$ is continuous, since each coordinate $g_{n}$ is continuous.
- $\Phi$ is injective, since $\{g_{n}\}$ separates points (Step 2).
- $K_{1}$ is compact and $\mathbb{F}^{\mathbb{N}}$ is Hausdorff (a countable pro
duct of Hausdorff spaces).

A continuous injection from a compact space into a Hausdorff space is a homeomor
phism onto its image. Thus $K_{1}\cong\Phi(K_{1})$.

**Step 5. The image is metrizable.**

The countable product $\mathbb{F}^{\mathbb{N}}$ is metrizable, e.g. via
$$d(x,y)=\sum_{n=1}^{\infty}2^{-n}\min\{1,\,|x_{n}-y_{n}|\}.$$
(The hypothesis $\sup_{n}\sup_{t}|f_{n}(t)|<\infty$ guarantees $\Phi(K_{1})$ lie
s in a bounded subset, but is not actually needed for metrizability of the produ
ct.) Any subspace of a metrizable space is metrizable, so $\Phi(K_{1})$ is metri
zable, and hence $K_{1}$ is metrizable. $\blacksquare$
