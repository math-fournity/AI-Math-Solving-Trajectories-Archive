## Proof

arphi = (x^1, \dots, x^m))$ around $p$, the vector field is written

$$X = \sum_{\mu=1}^{m} X^{\mu}\,\frac{\partial}{\partial x^{\mu}},$$

where each $X^{\mu} \colon U \to \mathbb{R}$ is a smooth function.

### 1. Coordinate form of the defining condition

A curve $\sigma \colon I \to \mathcal{M}$ (with $I$ an open interval containing
$0$) is an integral curve of $X$ through $p$ if and only if

$$\sigma(0) = p, \qquad \sigma_{*}\!\left(\tfrac{d}{dt}\Big|_{t}\right) = X_{\si
gma(t)} \quad \text{for all } t \in I.$$

a^{m}(t)\big)$ in the chart, the push-forward of the coordinate vector $\frac{d}

$$\sigma_{*}\!\left(\tfrac{d}{dt}\right) = \sum_{\mu=1}^{m} \dot{\sigma}^{\mu}(t

Equating this with $X_{\sigma(t)} = \sum_{\mu} X^{\mu}(\sigma(t))\,\frac{\partia

$$\boxed{\;\dot{\sigma}^{\mu}(t) = X^{\mu}\!\big(\sigma(t)\big), \qquad \mu = 1,
 \dots, m,\;}$$

with the **initial condition**

$$\sigma^{\mu}(0) = x^{\mu}(p), \qquad \mu = 1, \dots, m.$$

### 2. Existence and uniqueness (local)

The right-hand side $F = (X^{1}, \dots, X^{m}) \colon \varphi(U) \subset \mathbb

- an open interval $I_{p} = (-\varepsilon, \varepsilon)$ for some $\varepsilon >

$$\dot{\gamma}(t) = F(\gamma(t)), \qquad \gamma(0) = q_{0}.$$

Pulling back to the manifold via $\sigma = \varphi^{-1} \circ \gamma$, we obtain
 a curve $\sigma \colon I_{p} \to \mathcal{M}$ satisfying $\sigma(0) = p$ and $\
dot{\sigma}^{\mu}(t) = X^{\mu}(\sigma(t))$ for all $\mu$, i.e. $\sigma_{*}(\frac
{d}{dt}) = X_{\sigma(t)}$.

### 3. Smoothness

Because $F$ is $C^{\infty}$, the standard regularity theorem for ODEs (solutions
