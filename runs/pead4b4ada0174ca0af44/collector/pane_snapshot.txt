## Solution

**Interpreting the measure.** The function $\mu(x)$ given is the distribution fu
nction $F(x) = \mu((-\infty, x])$ of a Lebesgue–Stieltjes Borel measure:
$$F(x) = \begin{cases} 2x+1, & x \le 2 \\ 2x^2, & x > 2 \end{cases}$$

**Decomposing $\mu$.** $F$ is differentiable except at $x=2$, where it has a jum
p:
- $F(2) = 5$, $\lim_{x\to 2^+} F(x) = 8$, so the jump is $8 - 5 = 3$: an **atom
at $x=2$ of mass $3$**.
- On $(-\infty, 2)$: $F'(x) = 2$, giving density $2$.
- On $(2, \infty)$: $F'(x) = 4x$, giving density $4x$.

Thus $\mu = \mu_{\mathrm{ac}} + 3\,\delta_2$, where $\mu_{\mathrm{ac}}$ has dens
ity $g(x) = 2$ on $(-\infty,2)$ and $g(x)=4x$ on $(2,\infty)$.

**The integrand.** $f = 1$ on $\mathbb{Z}\cap[-1,3] = \{-1,0,1,2,3\}$, $f = 2$ o
n $[-1,3]\setminus\mathbb{Z}$, $f=0$ outside $[-1,3]$.

**Computing the integral.** Since $\mathbb{Z}$ is Lebesgue-null, $f = 2$ $\mu_{\
mathrm{ac}}$-a.e. on $[-1,3]$. The integers only matter at the atom $x=2$.

$$\int f\,d\mu = \underbrace{\int f\,d\mu_{\mathrm{ac}}}_{\text{continuous part}
} + \underbrace{f(2)\cdot 3}_{\text{atom at 2}}$$

**Continuous part:**
$$\int_{-1}^{3} f\,d\mu_{\mathrm{ac}} = \int_{-1}^{2} 2\cdot 2\,dx + \int_{2}^{3
} 2\cdot 4x\,dx = 4\cdot 3 + 8\int_{2}^{3} x\,dx = 12 + 8\cdot\tfrac{5}{2} = 12
+ 20 = 32$$

**Atom at $x=2$:** $f(2) = 1$ (since $2\in\mathbb{Z}$), so the contribution is $
1 \cdot 3 = 3$.

**Total:**
$$\int_{\mathbb{R}} f\,d\mu = 32 + 3 = \boxed{35}$$

**Verification via layer-cake.** Since $f\in\{0,1,2\}$:
$$\int f\,d\mu = \int_0^1 \mu(\{f>t\})\,dt + \int_1^2 \mu(\{f>t\})\,dt = \mu([-1
,3]) + \mu([-1,3]\setminus\mathbb{Z})$$

- $\mu([-1,3]) = F(3)-F(-1) + \text{jump at 2} = (18-(-1)) + 3 = 19 + 3$... chec
king: $\mu_{\mathrm{ac}}([-1,3]) = \int_{-1}^{2}2\,dx + \int_{2}^{3}4x\,dx = 6 +
 10 = 16$, plus atom $3$ gives $19$. ✓
- $\mu([-1,3]\setminus\mathbb{Z}) = 16$ (the atom at $2\in\mathbb{Z}$ is exclude
d; $\mu_{\mathrm{ac}}$ unchanged since $\mathbb{Z}$ is null).

$$19 + 16 = 35 \checkmark$$
