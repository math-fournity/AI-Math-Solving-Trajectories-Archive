Looking at this problem, I need to determine whether the bisection property (eve

o be centrally symmetric.

**Answer: Yes, U = -U.**

## Proof

**Step 1: The origin lies in U.**

Suppose $0 \notin U$. Since $U$ is open and convex:

- If $0 \notin \overline{U}$, the strict separating hyperplane theorem gives $v
\in S^{n-1}$ and $c > 0$ with $v \cdot x > c$ for all $x \in U$. Then $U \subset
 \{v \cdot x > 0\}$, so $\operatorname{vol}(U \cap \{v \cdot x > 0\}) = \operato
rname{vol}(U) \neq \operatorname{vol}(U)/2$, contradiction.

- If $0 \in \partial U$, there exists a supporting hyperplane: $v \in S^{n-1}$ w
ith $v \cdot x > 0$ for all $x \in U$ (since $U$ is open). Same contradiction.

So $0 \in U$.

**Step 2: Polar coordinates and the hemispherical transform.**

Since $U$ is convex with $0 \in U$, it is star-shaped with respect to $0$. Defin
e the radial function $\rho: S^{n-1} \to (0,\infty)$ by $\rho(\omega) = \sup\{r
\geq 0 : r\omega \in U\}$, so $U = \{r\omega : 0 \le r < \rho(\omega)\}$.

The bisection condition gives, for every $v \in S^{n-1}$:
$$\operatorname{vol}(U \cap \{v \cdot x > 0\}) = \operatorname{vol}(U \cap \{v \
cdot x < 0\}).$$

In polar coordinates, with $g(\omega) = \rho(\omega)^n$:
$$\frac{1}{n}\int_{v \cdot \omega > 0} g(\omega)\,d\omega = \frac{1}{n}\int_{v \
cdot \omega < 0} g(\omega)\,d\omega,$$

equivalently, defining the **hemispherical transform** $Hf(v) = \int_{v \cdot \o
mega > 0} f(\omega)\,d\omega$:
$$Hg(v) = \frac{1}{2}\int_{S^{n-1}} g(\omega)\,d\omega \quad \text{for all } v \
in S^{n-1}. \tag{$\star$}$$

**Step 3: Spectral analysis of the hemispherical transform.**

The operator $H$ is a Funk–Hecke operator with kernel $K(t) = \mathbf{1}_{t > 0}
$. By the Funk–Hecke theorem, every spherical harmonic $Y_l$ of degree $l$ is an
 eigenfunction: $HY_l = \lambda_l Y_l$, where (with $\alpha = (n-2)/2$):
$$\lambda_l \propto \int_0^1 C_l^{(\alpha)}(t)\,(1-t^2)^{(n-3)/2}\,dt,$$
and the proportionality constant is nonzero (it involves $C_l^{(\alpha)}(1) \neq
 0$).

- **$l = 0$:** $\lambda_0 \neq 0$; $H$ maps constants to constants.

- **$l$ even, $l > 0$:** $C_l^{(\alpha)}$ is even, so $\int_0^1 C_l^{(\alpha)}(t
)\,w(t)\,dt = \frac{1}{2}\int_{-1}^1 C_l^{(\alpha)}(t)\,w(t)\,dt = 0$ by orthogo
nality with $C_0^{(\alpha)} = 1$. Thus $\lambda_l = 0$.

- **$l$ odd:** We show $\lambda_l \neq 0$. Using the Rodrigues formula for Gegen
bauer polynomials and integrating by parts:
$$\int_0^1 C_l^{(\alpha)}(t)\,(1-t^2)^{\alpha - 1/2}\,dt = \frac{(-1)^l(2\alpha)
_l}{2^l\, l!\,(\alpha+1/2)_l}\left[\frac{d^{l-1}}{dt^{l-1}}(1-t^2)^{l+\alpha-1/2
}\right]_0^1.$$
  The boundary term at $t=1$ vanishes (the exponent $l + \alpha - 1/2 = l + (n-3
)/2 \ge l$ ensures a zero of order $\ge l > l-1$). At $t = 0$, since $l-1$ is ev
en, the derivative evaluates to:
$$\left.\frac{d^{l-1}}{dt^{l-1}}(1-t^2)^{l+\alpha-1/2}\right|_{t=0} = (l-1)!\bin
om{l+\alpha-1/2}{(l-1)/2}(-1)^{(l-1)/2} \neq 0,$$
  since $l + \alpha - 1/2 > (l-1)/2$ (equivalently $(l+n-2)/2 > 0$, true for $l
\ge 1, n \ge 2$), and $(2\alpha)_l \neq 0$, $(\alpha+1/2)_l \neq 0$ for $n \ge 3
$.

  For $n = 2$ ($\alpha = 0$, degenerate Gegenbauer), we verify directly via Four
ier analysis on $S^1$: for $f(\theta) = e^{il\theta}$, $Hf(\varphi) = e^{il\varp
hi}\cdot 2\sin(l\pi/2)/l$, which is nonzero for all odd $l$ (since $\sin(l\pi/2)
 = \pm 1$).

  For $n = 1$, $S^0 = \{+1,-1\}$ and the condition $Hg = \text{const}$ directly
gives $g(+1) = g(-1)$.

Thus $\lambda_l \neq 0$ for all odd $l$.

**Step 4: Conclusion.**

Since $U$ is bounded, $g = \rho^n$ is bounded and hence $g \in L^2(S^{n-1})$. Ex
pand $g = \sum_l g_l$ in spherical harmonics. Condition $(\star)$ says $Hg$ has
only degree-$0$ component, i.e., $\lambda_l\, g_l = 0$ for all $l > 0$. Since $\
lambda_l \neq 0$ for odd $l$, we get $g_l = 0$ for all odd $l$.

Therefore $g$ contains only even-degree spherical harmonics, which means $g(-\om
ega) = g(\omega)$ for a.e. $\omega$, i.e., $g$ is **even**. Since $g(\omega) = \
rho(\omega)^n > 0$:
$$\rho(\omega)^n = \rho(-\omega)^n \implies \rho(\omega) = \rho(-\omega) \quad \
text{for all } \omega \in S^{n-1}.$$

Hence:
$$U = \{r\omega : 0 \le r < \rho(\omega)\} = \{r\omega : 0 \le r < \rho(-\omega)
\} = \{r(-\omega') : 0 \le r < \rho(\omega')\} = -U.$$

$\blacksquare$
