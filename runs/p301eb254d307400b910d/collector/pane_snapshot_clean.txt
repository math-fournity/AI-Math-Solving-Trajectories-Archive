## Proof

**Setup.** A circle lies in some plane *P* with unit normal **n** = (a, b, c). B
y permuting coordinates and negating, assume a ≥ b ≥ c ≥ 0, with a² + b² + c² =
1.

**Upper bound.** Let the circle have radius *r* and center *C* = (cₓ, c_y, c_z).
 For every point on the circle to lie in [0,1]³, each coordinate must stay in [0
,1].

The circle contains points *C* ± r**v** for any unit vector **v** ⊥ **n**. The x
-coordinate of such a point is cₓ ± r·v₁. The maximum of |v₁| over unit vectors
**v** ⊥ **n** is √(1−a²) (the length of the x-axis projected onto *P*). So the x
-coordinates on the circle span an interval of width 2r√(1−a²), requiring:

2r√(1−a²) ≤ 1 ⟹ r ≤ 1/(2√(1−a²))

By the same argument for y and z:

r ≤ 1/(2√(1−b²)), &nbsp; r ≤ 1/(2√(1−c²))

Since a ≥ b ≥ c ≥ 0, we have 1−a² ≤ 1−b² ≤ 1−c², so the binding constraint is:

**r ≤ 1/(2√(1−c²)) = 1/(2√(a²+b²))**

**Maximizing the bound.** Since a² + b² = 1 − c², maximizing *r* means maximizin
g c². Under a ≥ b ≥ c ≥ 0 and a²+b²+c² = 1, the maximum of c² is 1/3, achieved w
hen a = b = c = 1/√3. This gives:

r ≤ 1/(2√(2/3)) = √3/(2√2) = **√6/4**

**Achievability.** Consider the plane x + y + z = 3/2 through the cube's center.
 Its intersection with [0,1]³ is a regular hexagon with vertices:

(1, ½, 0), (½, 1, 0), (0, 1, ½), (0, ½, 1), (½, 0, 1), (1, 0, ½)

Each side has length 1/√2. The inradius of a regular hexagon with side *s* is *s
*√3/2, giving:

inradius = (1/√2)(√3/2) = √6/4

This incircle is centered at (½, ½, ½) with radius √6/4. Verification that it fi
ts exactly: the x-extent is 2·(√6/4)·√(1−1/3) = 2·(√6/4)·√(2/3) = 1, so the circ
le spans exactly [0,1] in each coordinate — it is tangent to all six faces of th
e cube.

**Conclusion.** The upper bound √6/4 is achieved by the incircle of the regular
hexagonal cross-section, so the radius of the largest circle fitting entirely wi
thin a unit cube is:

$$\boxed{\dfrac{\sqrt{6}}{4}}$$
