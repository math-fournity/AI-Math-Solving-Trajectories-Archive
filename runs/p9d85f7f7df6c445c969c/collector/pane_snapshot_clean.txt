## Proof

Let $A, B \in \mathbb{R}^{n\times n}$ (the Hermitian case is identical) with $A
\succ 0$ and $B \succeq 0$. We determine when
$$\det(A+B) = \det(A) + \det(B).$$

**Reduction to eigenvalues.** Since $A \succ 0$, write $A = A^{1/2}A^{1/2}$ with
 $A^{1/2}\succ 0$. Set
$$C := A^{-1/2} B A^{-1/2} \succeq 0.$$
Then
$$\det(A+B) = \det\!\big(A^{1/2}(I+C)A^{1/2}\big) = \det(A)\det(I+C),$$
and
$$\det(B) = \det\!\big(A^{1/2} C A^{1/2}\big) = \det(A)\det(C).$$
Since $\det(A)>0$, divide both sides of the desired equality by $\det(A)$ to obt
ain the equivalent condition
$$\det(I+C) = 1 + \det(C).$$

Let $\lambda_1,\dots,\lambda_n \geq 0$ be the eigenvalues of $C$. Then
$$\det(I+C) = \prod_{i=1}^n (1+\lambda_i), \qquad \det(C) = \prod_{i=1}^n \lambd
a_i.$$
So we need
$$\prod_{i=1}^n (1+\lambda_i) = 1 + \prod_{i=1}^n \lambda_i. \tag{$\ast$}$$

**Expanding.** Expanding the left side via elementary symmetric polynomials $e_k
$:
$$\prod_{i=1}^n(1+\lambda_i) = \sum_{k=0}^{n} e_k(\lambda_1,\dots,\lambda_n) = 1
 + e_1 + e_2 + \cdots + e_{n-1} + \prod_{i=1}^n\lambda_i.$$
Thus $(\ast)$ becomes
$$e_1 + e_2 + \cdots + e_{n-1} = 0. \tag{$\ast\ast$}$$

**Nonnegativity.** Every $\lambda_i \geq 0$, so each elementary symmetric polyno
mial
$$e_k = \sum_{i_1<\cdots<i_k} \lambda_{i_1}\cdots\lambda_{i_k} \geq 0.$$
Hence the left side of $(\ast\ast)$ is a sum of nonnegative terms equal to $0$,
forcing every $e_k = 0$ for $k=1,\dots,n-1$.

**Case $n \geq 2$.** In particular $e_1 = \lambda_1+\cdots+\lambda_n = 0$. With
all $\lambda_i\geq 0$, this forces $\lambda_1=\cdots=\lambda_n=0$, i.e. $C = 0$,
 hence $B = A^{1/2} C A^{-1/2} = 0$. Conversely, $B=0$ gives $\det(A+0)=\det(A)=
\det(A)+0$, which holds. So for $n\geq 2$ the equality holds **iff $B=0$**.

**Case $n = 1$.** Here the sum in $(\ast\ast)$ is empty (there is no $e_k$ with
$1\leq k \leq n-1 = 0$), so $(\ast\ast)$ is vacuously $0=0$. Indeed for scalars
$a>0$, $b\geq 0$: $\det(A+B)=a+b=\det(A)+\det(B)$ always. So for $n=1$ the equal
ity **holds for all** $A\succ 0$, $B\succeq 0$.

**Conclusion.** The equality $\det(A+B)=\det(A)+\det(B)$ holds:
- for $n=1$: always (for every $A\succ 0$, $B\succeq 0$);
- for $n\geq 2$: if and only if $B = 0$.

Equivalently, for $n\geq 2$ the only way the determinant is additive on the cone
 $\{A\succ 0,\, B\succeq 0\}$ is the trivial case $B=0$; the determinant is stri
ctly superadditive otherwise (since $\det(A+B) > \det(A)+\det(B)$ whenever $B\su
cceq 0$, $B\neq 0$, $n\geq 2$, as the sum $\sum_{k=1}^{n-1} e_k > 0$).
