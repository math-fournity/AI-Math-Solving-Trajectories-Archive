## Solution

On the circle $|z| = 2$, we have $z\bar{z} = |z|^2 = 4$, so $\bar{z} = \dfrac{4}
{z}$. Substituting this into the integrand:

$$\int_\gamma \frac{e^{\bar{z}}}{z^2}\,dz = \oint_{|z|=2} \frac{e^{4/z}}{z^2}\,d
z.$$

The function $f(z) = \dfrac{e^{4/z}}{z^2}$ is meromorphic on $\mathbb{C}\setminu
s\{0\}$ with an essential singularity at $z=0$ (which lies inside $\gamma$). We
compute the residue at $z=0$ via the Laurent expansion.

Expanding $e^{4/z}$ around $z=0$:

$$e^{4/z} = \sum_{n=0}^{\infty} \frac{1}{n!}\left(\frac{4}{z}\right)^n = \sum_{n
=0}^{\infty} \frac{4^n}{n!}\,z^{-n}.$$

Dividing by $z^2$:

$$\frac{e^{4/z}}{z^2} = \sum_{n=0}^{\infty} \frac{4^n}{n!}\,z^{-n-2}.$$

The residue at $z=0$ is the coefficient of $z^{-1}$, which requires $-n-2 = -1$,
 i.e., $n = -1$. Since the sum runs over $n \geq 0$, **no term produces $z^{-1}$
**. Therefore:

$$\operatorname{Res}_{z=0}\left(\frac{e^{4/z}}{z^2}\right) = 0.$$

By the residue theorem (the only singularity inside $|z|=2$ is at $z=0$):

$$\oint_{|z|=2} \frac{e^{4/z}}{z^2}\,dz = 2\pi i \cdot \operatorname{Res}_{z=0}\
left(\frac{e^{4/z}}{z^2}\right) = 2\pi i \cdot 0 = 0.$$

**Verification via direct parameterization.** Let $z = 2e^{i\theta}$, $\theta \i
n [0,2\pi]$, so $\bar{z} = 2e^{-i\theta}$ and $dz = 2ie^{i\theta}\,d\theta$:

$$\int_0^{2\pi} \frac{e^{2e^{-i\theta}}}{4e^{2i\theta}}\cdot 2ie^{i\theta}\,d\th
eta = \frac{1}{2}\int_0^{2\pi} i\,e^{-i\theta}\,e^{2e^{-i\theta}}\,d\theta.$$

Setting $w = e^{-i\theta}$, $dw = -ie^{-i\theta}\,d\theta$, so $ie^{-i\theta}\,d
\theta = -dw$. As $\theta$ runs from $0$ to $2\pi$, $w$ traces the unit circle *
*clockwise**. Thus:

$$\frac{1}{2}\int_{CW} -e^{2w}\,dw = \frac{1}{2}\oint_{CCW} e^{2w}\,dw.$$

Since $e^{2w}$ is entire, Cauchy's theorem gives $\oint_{CCW} e^{2w}\,dw = 0$, c
onfirming the result.

$$\boxed{\int_\gamma \frac{e^{\bar{z}}}{z^2}\,dz = 0}$$
