# Problem

In a remote industrial mining facility, an engineer is calibrating a deep-bore extraction drill. The depth of the drill bit, $f(x)$, is modeled by the function $f(x) = x^2 + ax + b$, where $x$ represents the horizontal displacement from the central shaft. Due to structural constraints of the soil layers, the coefficients $a$ and $b$ must be integers.

Safety regulations dictate that the drill bit must never descend below a critical safety floor. Specifically, for all possible horizontal displacements $x$, the depth must satisfy $f(x) \geq -c$, where the safety constant $c$ is set to $\frac{9}{10}$.

The engineer's goal is to find the deepest possible point the drill reaches (the minimum value of the function) under these constraints. Among all possible configurations of the integer coefficients $a$ and $b$ that satisfy the safety requirement, let $m$ be the largest possible value that this minimum depth can take.

Determine the value of $m$.
