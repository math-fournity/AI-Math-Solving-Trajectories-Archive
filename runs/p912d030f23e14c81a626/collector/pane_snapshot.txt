## Proof

We construct an injection $\Phi$ from the set of all functions $g: X \to \{1,2,\
ldots,n\}$ (which has $n^n$ elements) into the set of nice functions $f: X \to \
{1,2,\ldots,n+1\}$.

**Key Lemma.** *If $X_a, X_b$ are distinct non-empty subsets with $X_a \subsetne
q X_b$, then for any $g: X \to \{1,\ldots,n\}$, we have $\sum_{x \in X_b} g(x) >
 \sum_{x \in X_a} g(x)$.*

*Proof.* Since $X_a \subsetneq X_b$, the set $X_b \setminus X_a$ is non-empty. A
s $g(x) \geq 1$ for all $x$:
$$\sum_{x \in X_b} g(x) = \sum_{x \in X_a} g(x) + \sum_{x \in X_b \setminus X_a}
 g(x) \geq \sum_{x \in X_a} g(x) + 1 > \sum_{x \in X_a} g(x). \qquad \square$$

**Corollary.** If $T_a(g) = T_b(g)$ (both achieve the same sum), then neither $X
_a \subseteq X_b$ nor $X_b \subseteq X_a$. In particular $|X_a \cap X_b| < |X_a|
$ and $|X_a \cap X_b| < |X_b|$.

**Construction of $\Phi$.** Given $g: X \to \{1,\ldots,n\}$, define $T_i = \sum_
{x \in X_i} g(x)$ for each $i$. Let $M = \max_i T_i$, let $W = \{i : T_i = M\}$,
 and set $k = \min W$. Define:
$$\Phi(g)(x) = \begin{cases} g(x) + 1 & \text{if } x \in X_k, \\ g(x) & \text{if
 } x \notin X_k. \end{cases}$$

Since $g(x) \leq n$, we have $\Phi(g)(x) \leq n+1$ for all $x$, and since $g(x)
\geq 1$, we have $\Phi(g)(x) \geq 1$. So $\Phi(g): X \to \{1,\ldots,n+1\}$ is we
ll-defined.

**Claim 1: $\Phi(g)$ is nice, with $X_k$ as the unique winner.**

Let $S_i = \sum_{x \in X_i} \Phi(g)(x) = T_i + |X_i \cap X_k|$. Note $S_k = M +
|X_k|$.

- *For $j \in W \setminus \{k\}$:* Since $T_j = T_k = M$, the Corollary gives $X
_k \not\subseteq X_j$, so $|X_j \cap X_k| < |X_k|$. Thus $S_j = M + |X_j \cap X_
k| < M + |X_k| = S_k$.

- *For $j \notin W$:* We have $T_j \leq M - 1$, so $S_j = T_j + |X_j \cap X_k| \
leq (M-1) + |X_k| < M + |X_k| = S_k$.

Therefore $S_k > S_j$ for all $j \neq k$, confirming $\Phi(g)$ is nice with uniq
ue winner $X_k$. $\checkmark$

**Claim 2: $\Phi$ is injective.**

Suppose $\Phi(g_1) = \Phi(g_2) = f$. By Claim 1, $f$ has a unique winner; call i
t $X_k$. The construction guarantees that the winner of $\Phi(g_i)$ is $X_{k_i}$

_2}$. Because the subsets $X_1, \ldots, X_m$ are **pairwise distinct**, the inde
x is uniquely determined by the subset, so $k_1 = k_2 = k$.

Now both $g_1$ and $g_2$ are recovered from $f$ and $X_k$ by the same rule:
$$g(x) = f(x) - 1 \text{ for } x \in X_k, \qquad g(x) = f(x) \text{ for } x \not
in X_k.$$
Hence $g_1 = g_2$, proving injectivity. $\checkmark$

**Conclusion.** The map $\Phi$ is an injection from $\{1,\ldots,n\}^X$ (which ha
