**Proof.**

We claim the smallest irreducible algebraic set in $\mathbb{R}^3$ containing all
 integer-coordinate points $\mathbb{Z}^3$ is $\mathbb{R}^3$ itself.

**Key lemma.** If $f \in \mathbb{R}[x,y,z]$ vanishes on every point of $\mathbb{
Z}^3$, then $f$ is the zero polynomial.

*Proof of lemma.* Write $f(x,y,z) = \sum_{i,j} c_{ij}(z)\, x^i y^j$ where $c_{ij
}(z) \in \mathbb{R}[z]$. Fix any integer $k \in \mathbb{Z}$. The polynomial $g_k
(x,y) = f(x,y,k) = \sum_{i,j} c_{ij}(k)\, x^i y^j$ vanishes on all of $\mathbb{Z
}^2$ (since $(m,n,k) \in \mathbb{Z}^3$ for all $m,n \in \mathbb{Z}$).

We use the standard fact: a polynomial in $\mathbb{R}[x_1,\dots,x_n]$ vanishing
on all of $\mathbb{Z}^n$ is identically zero. This follows by induction on $n$:
for $n=1$, a univariate polynomial with infinitely many roots is zero. For the i
nductive step, write $h(x_1,\dots,x_n) = \sum_j a_j(x_1,\dots,x_{n-1})\, x_n^j$;
 fixing $(x_1,\dots,x_{n-1}) \in \mathbb{Z}^{n-1}$ gives a univariate polynomial
 in $x_n$ vanishing on all of $\mathbb{Z}$, so each $a_j$ vanishes on $\mathbb{Z
}^{n-1}$, hence $a_j \equiv 0$ by induction, hence $h \equiv 0$.

Applying this to $g_k(x,y)$: $g_k \equiv 0$, so every coefficient $c_{ij}(k) = 0
$. Since this holds for every integer $k$, each univariate polynomial $c_{ij}(z)
$ vanishes on all of $\mathbb{Z}$, hence $c_{ij} \equiv 0$. Therefore $f \equiv
0$. $\square$

**Main argument.** Let $V \subseteq \mathbb{R}^3$ be any algebraic set containin
g $\mathbb{Z}^3$. By definition $V = \mathbf{V}(S)$ for some set $S \subseteq \m
athbb{R}[x,y,z]$. Every $f \in S$ vanishes on $V \supseteq \mathbb{Z}^3$, so by
the lemma $f \equiv 0$. Thus $S \subseteq \{0\}$ and $V = \mathbf{V}(S) \supsete
q \mathbf{V}(\{0\}) = \mathbb{R}^3$. Hence $V = \mathbb{R}^3$.

So the **only** algebraic set in $\mathbb{R}^3$ containing $\mathbb{Z}^3$ is $\m
athbb{R}^3$ itself.

**Irreducibility.** $\mathbb{R}^3 = \mathbf{V}(0)$ is the zero set of the zero p
olynomial, corresponding to the zero ideal, which is prime. Equivalently, $\math
bb{R}^3$ cannot be written as a union of two proper algebraic subsets (any prope
r algebraic subset is contained in some hypersurface, and $\mathbb{R}^3$ is not
a finite union of proper algebraic subsets — its coordinate ring $\mathbb{R}[x,y
,z]$ is an integral domain, so $\mathbf{V}(0)$ is irreducible).

**Conclusion.** Since $\mathbb{R}^3$ is the unique algebraic set containing $\ma
thbb{Z}^3$, it is trivially the smallest irreducible one.
