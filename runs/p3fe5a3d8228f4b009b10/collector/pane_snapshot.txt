Looking at this problem, I need to determine whether $\mathbb{E}[|Y_n|^r - |Y_{n
-1}|^r] \leq C\mathbb{E}|X_n|^r$ holds for $1 < r < 2$.

**Answer: Yes, the inequality is valid.** Here is the proof.

---

## Proof

**Key pointwise inequality.** For $1 < r < 2$ and all $a, b \in \mathbb{R}$:
$$|a+b|^r - |a|^r \leq r\,\operatorname{sgn}(a)\,|a|^{r-1}\,b + 2^{2-r}|b|^r. \t
ag{$\star$}$$

**Proof of ($\star$).** Define $g(x) = \operatorname{sgn}(x)|x|^{r-1}$, so that
$\frac{d}{dx}|x|^r = r\,g(x)$ for $x \neq 0$. By the fundamental theorem of calc
ulus applied to $t \mapsto |a+tb|^r$:

$$|a+b|^r - |a|^r = \int_0^1 r\,g(a+tb)\,b\,dt.$$

Subtracting the linear term $r\,g(a)\,b$:

$$\bigl||a+b|^r - |a|^r - r\,g(a)\,b\bigr| \leq r|b|\int_0^1 |g(a+tb) - g(a)|\,d
t. \tag{1}$$

We now bound $|g(u)-g(v)|$. Set $\alpha = r-1 \in (0,1)$.

- **Same sign** ($u,v$ both $\geq 0$ or both $\leq 0$): WLOG $u \geq v \geq 0$.
Then $|u^\alpha - v^\alpha| \leq |u-v|^\alpha$, since setting $t = v/u \in [0,1]
$, this becomes $1 - t^\alpha \leq (1-t)^\alpha$, i.e., $t^\alpha + (1-t)^\alpha
 \geq 1$, which holds because $t^\alpha \geq t$ and $(1-t)^\alpha \geq 1-t$ for
$\alpha \in (0,1)$.

- **Opposite signs** ($u \geq 0 \geq v$): $|g(u)-g(v)| = u^\alpha + |v|^\alpha \
leq 2^{1-\alpha}(u+|v|)^\alpha = 2^{2-r}|u-v|^{r-1}$, using concavity of $t^\alp
ha$: $u^\alpha + |v|^\alpha \leq 2\bigl(\frac{u+|v|}{2}\bigr)^\alpha = 2^{1-\alp
ha}(u+|v|)^\alpha$.

Combining both cases: $|g(u)-g(v)| \leq 2^{2-r}|u-v|^{r-1}$ for all $u,v$.

Applying this to (1) with $u = a+tb$, $v = a$:

$$\bigl||a+b|^r - |a|^r - r\,g(a)\,b\bigr| \leq r|b|\int_0^1 2^{2-r}\,(t|b|)^{r-
1}\,dt = 2^{2-r}\,r\,|b|^r\int_0^1 t^{r-1}\,dt = 2^{2-r}\,|b|^r.$$

This establishes ($\star$). (The case $a=0$ is immediate since $g(0)=0$ and $|b|
^r \leq 2^{2-r}|b|^r$ as $2^{2-r}\geq 1$.)

---

**Applying to the martingale.** Set $a = Y_{n-1}$, $b = X_n$ in ($\star$):

$$|Y_n|^r - |Y_{n-1}|^r \leq r\,\operatorname{sgn}(Y_{n-1})\,|Y_{n-1}|^{r-1}\,X_
n + 2^{2-r}\,|X_n|^r.$$

Take expectations. Since $Y_{n-1}$ is $\mathcal{F}_{n-1}$-measurable, the functi
on $\operatorname{sgn}(Y_{n-1})|Y_{n-1}|^{r-1}$ is also $\mathcal{F}_{n-1}$-meas
urable. Using the martingale difference property $\mathbb{E}[X_n \mid \mathcal{F
}_{n-1}] = 0$:

$$\mathbb{E}\bigl[\operatorname{sgn}(Y_{n-1})\,|Y_{n-1}|^{r-1}\,X_n\bigr] = \mat
hbb{E}\bigl[\operatorname{sgn}(Y_{n-1})\,|Y_{n-1}|^{r-1}\,\mathbb{E}[X_n \mid \m
athcal{F}_{n-1}]\bigr] = 0.$$

Therefore:

$$\boxed{\mathbb{E}\bigl[|Y_n|^r - |Y_{n-1}|^r\bigr] \leq 2^{2-r}\,\mathbb{E}|X_
n|^r.}$$

The inequality is valid with $C = 2^{2-r}$ (which lies in $[1,2)$ for $r \in (1,
2)$). $\blacksquare$
