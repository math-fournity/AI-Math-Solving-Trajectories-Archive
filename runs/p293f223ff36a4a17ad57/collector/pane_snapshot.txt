## Solution

We compute $E\big[|B(t)|\cdot B(1-t)\big]$ for standard Brownian motion $B$.

**Key observation.** The pair $(B(t),\, B(1-t))$ is jointly Gaussian. Set
$$X = B(t)\sim N(0,t),\qquad Y = B(1-t)\sim N(0,1-t),\qquad \operatorname{Cov}(X
,Y)=\min(t,1-t)=:c.$$

**Linear decomposition.** By joint Gaussianity we can write
$$Y = \beta\, X + \varepsilon,\qquad \beta = \frac{\operatorname{Cov}(X,Y)}{\ope
ratorname{Var}(X)}=\frac{c}{t},$$
where $\varepsilon\sim N\!\big(0,\,(1-t)-c^{2}/t\big)$ is **independent** of $X$
 (and in particular $E[\varepsilon]=0$). This is valid for every $t\in(0,1)$; th
e boundary cases $t=0,1$ give $0$ trivially since one factor vanishes.

**Taking the expectation.**
$$E\big[|X|\,Y\big]=E\big[|X|\,(\beta X+\varepsilon)\big]=\beta\,E\big[|X|\,X\bi
g]+E\big[|X|\big]\,E[\varepsilon].$$

- $E[\varepsilon]=0$ since $\varepsilon$ is centered Gaussian.
- $E[|X|\,X]=0$: indeed $X\sim N(0,t)$ has a density symmetric about $0$, and $x
\mapsto |x|\,x$ is an **odd** function, so the integral vanishes.

Both terms are therefore $0$, giving
$$E\big[|B(t)|\cdot B(1-t)\big]=\beta\cdot 0+E[|B(t)|]\cdot 0 = 0.$$

**Sanity check via direct conditioning.** For $t\le \tfrac12$ we have $1-t\ge t$
, so $B(1-t)=B(t)+\big(B(1-t)-B(t)\big)$ with the increment independent of $B(t)
$ and centered. Hence
$$E\big[|B(t)|\,B(1-t)\big]=\underbrace{E[|B(t)|\,B(t)]}_{=\,0\text{ (odd)}}+\un
derbrace{E[|B(t)|]}_{\ge 0}\cdot\underbrace{E[B(1-t)-B(t)]}_{=\,0}=0.$$
For $t\ge \tfrac12$ the same conclusion follows from the general Gaussian argume
nt above. Both regimes agree.

**Result.** For every $t\in[0,1]$,
$$\boxed{E\big[|B(t)|\cdot B(1-t)\big]=0.}$$

The vanishing has a clean structural reason: $B(1-t)$ decomposes into a part pro
portional to $B(t)$ (which pairs with the odd integrand $|B(t)|B(t)=0$ in expect
ation) plus an independent centered Gaussian (which factors out and dies against
 $E[\varepsilon]=0$).
