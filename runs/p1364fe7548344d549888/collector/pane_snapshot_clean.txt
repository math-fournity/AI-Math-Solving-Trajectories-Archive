## 证明

### 关键定义和事实

**`sumRep A n`** 计算了将 `n` 表示为 `A` 中两个元素之和的方法数量，即 `|{(a, b)
∈ A × A : a + b = n}|`。

**`lowerDensity S`** = `liminf_{N→∞} |S ∩ [0, N)| / N` 且 **`upperDensity S`** =
 `limsup_{N→∞} |S ∩ [0, N)| / N`，两者均为 `[0, 1]` 中的实数。

**反例：** 取 `A = ℕ`（即 `Set.univ`）和 `g(n) = n + 1`。

---

### 定理 3: `erdos_1193.variants.sumRep_univ`

**声明：** `sumRep (Set.univ : Set ℕ) n = n + 1`

**证明：** 我们需要计算满足 `a + b = n` 的数对 `(a, b) ∈ ℕ × ℕ` 的数量。对于从 `
0` 到 `n` 的每个 `a`，值 `b = n - a` 是唯一确定的，并且满足 `b ∈ ℕ`（因为 `a ≤ n
` 意味着 `n - a ≥ 0`）。这给出了数对 `(0, n), (1, n-1), ..., (n, 0)` —— 恰好是 `
n + 1` 个数对。

反之，任何满足 `a + b = n` 且 `a, b ∈ ℕ` 的数对 `(a, b)` 必须满足 `a ≤ n`（因为
`b = n - a ≥ 0`），因此 `a ∈ {0, 1, ..., n}`。映射 `a ↦ (a, n - a)` 是 `{0, 1, .
.., n}` 与满足 `a + b = n` 的数对 `(a, b) ∈ ℕ × ℕ` 之间的双射。

因此 `sumRep univ n = n + 1`。 ∎

### 定理 1: `erdos_1193.parts.i`

**声明：** `answer(False) ↔ ∀ (A : Set ℕ) (g : ℕ → ℕ), Monotone g → (∀ n, 0 < g
n) → {n : ℕ | sumRep A n = g n}.lowerDensity = 0`

由于 `answer(False) = False`，这等价于证明：

**¬(∀ A g, Monotone g → (∀ n, 0 < g n) → {n | sumRep A n = g n}.lowerDensity = 0
)**

**证明：** 我们通过反证法证明这一点。假设右侧的全称命题成立。我们将构造一个反例
。

取 `A = Set.univ`（所有自然数的集合）和 `g : ℕ → ℕ` 定义为 `g(n) = n + 1`。我们
验证假设：

1. **`g` 是单调的：** 如果 `n ≤ m`，那么 `n + 1 ≤ m + 1`，所以 `g(n) ≤ g(m)`。因
此 `Monotone g` 成立。

2. **`g` 总是正的：** 对于所有 `n : ℕ`，`g(n) = n + 1 ≥ 1 > 0`。因此 `∀ n, 0 < g
 n` 成立。

3. **求和集合：** 根据定理 3，`sumRep univ n = n + 1 = g(n)` 对于所有 `n` 成立。
因此：
   `{n : ℕ | sumRep univ n = g n} = {n : ℕ | n + 1 = n + 1} = Set.univ`

4. **`univ` 的下密度：** 对于每个 `N`，`|univ ∩ [0, N)| = N`，所以密度比率为 `N
/ N = 1`。liminf 为 `1`。因此 `lowerDensity univ = 1`。

根据假设的全称命题，我们应该有 `lowerDensity univ = 0`。但我们刚刚证明了 `lowerD
ensity univ = 1`。由于在实数上 `1 ≠ 0`，这产生了矛盾。

因此，该全称命题为假，从而 `¬P` 成立，这等价于 `answer(False) ↔ P`。 ∎

### 定理 2: `erdos_1193.parts.ii`

**声明：** `answer(False) ↔ ∃ c < (1 : ℝ), ∀ (A : Set ℕ) (g : ℕ → ℕ), Monotone g
 → (∀ n, 0 < g n) → {n : ℕ | sumRep A n = g n}.upperDensity < c`

由于 `answer(False) = False`，这等价于证明：

**¬(∃ c < 1, ∀ A g, Monotone g → (∀ n, 0 < g n) → {n | sumRep A n = g n}.upperDe
nsity < c)**

这等价于：**∀ c < 1, ∃ A g, Monotone g ∧ (∀ n, 0 < g n) ∧ ¬({n | sumRep A n = g
n}.upperDensity < c)**

**证明：** 设 `c : ℝ` 满足 `c < 1`。取 `A = Set.univ` 和 `g(n) = n + 1`。

与定理 1 中相同的验证表明：
- `Monotone g` 成立。
- `∀ n, 0 < g n` 成立。
- `{n | sumRep univ n = g n} = Set.univ`。
- `upperDensity univ = 1`（因为对于所有 `N`，密度比率为 `1`，limsup 也是 `1`）。

现在我们需要证明 `¬(1 < c)`，即 `1 ≥ c`。由于 `c < 1`，我们有 `1 > c`，所以 `1 ≥
 c`，这意味着 `¬(1 < c)`。因此 `¬(upperDensity univ < c)`，因为 `upperDensity un
iv = 1` 且 `1 > c` 意味着 `1 < c` 为假。

由于 `c < 1` 是任意的，不存在满足该全称命题界的 `c < 1`。因此该存在命题为假，从
而其否定为真。 ∎

### 定理 4: `erdos_1193.variants.upper_density_pos`

**声明：** `∃ (A : Set ℕ) (g : ℕ → ℕ), Monotone g ∧ (∀ n, 0 < g n) ∧ 0 < {n : ℕ
| sumRep A n = g n}.upperDensity`

**证明：** 取 `A = Set.univ` 和 `g(n) = n + 1`。

1. **`Monotone g`：** `n ≤ m → n + 1 ≤ m + 1`，所以 `g(n) ≤ g(m)`。 ✓

2. **`∀ n, 0 < g n`：** `g(n) = n + 1 ≥ 1 > 0`。 ✓

3. **`0 < upperDensity`：** 根据定理 3，`sumRep univ n = n + 1 = g(n)` 对于所有
`n` 成立。所以 `{n | sumRep univ n = g n} = Set.univ`。`univ` 的上密度是 `1`（对
于所有 `N`，密度比率为 `N/N = 1`，limsup = `1`）。由于 `0 < 1`，我们得到 `0 < up
perDensity univ`。 ✓

因此，该存在命题成立。 ∎

### 总结

所有四个定理都通过同一个反例得到证明：**`A = ℕ`（所有自然数）和 `g(n) = n + 1`**
。关键事实是：

1. `sumRep ℕ n = n + 1`（将 `n` 表示为两个自然数之和的方法数是 `n + 1`：即数对 `
(0,n), (1,n-1), ..., (n,0)`）。

2. 当 `g(n) = n + 1` 时，集合 `{n : sumRep ℕ n = g(n)}` 是所有自然数的集合，其下
密度和上密度均为 `1`。

3. 这立即给出：
   - **部分 i：** 下密度并不总是 `0`（它可以是 `1`），所以答案是 **False**。
   - **部分 ii：** 上密度并不总是以某个 `c < 1` 为界（它可以是 `1`），所以答案是
 **False**。
   - **变体 sumRep_univ：** `sumRep univ n = n + 1`，通过双射 `a ↦ (a, n-a)` 可
证。
   - **变体 upper_density_pos：** 上密度可以是正数（它是 `1`）。
