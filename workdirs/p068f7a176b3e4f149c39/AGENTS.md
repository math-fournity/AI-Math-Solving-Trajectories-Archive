# Problem

In the city of Arithmos, an architectural project is deemed "Synchronized" if it satisfies a specific structural requirement regarding its blueprint. For any given building height $n$ (a positive integer), let the set of all possible room lengths be defined by the divisors of $n$.

A building height $n$ is "Synchronized" if there exist two specific room lengths $d_1$ and $d_2$ among its set of divisors ($1 \leq d_1, d_2 \leq n$) such that their difference, $d_2 - d_1$, is equal to every single intermediate room length $d$ of the building (where an intermediate length is any divisor $d$ such that $1 < d < n$).

A developer is looking to construct a Synchronized building. The height $n$ must be a multiple of the zoning code $401$, and for safety regulations, the height must be strictly greater than $401$. 

Find the smallest possible height $n$ that satisfies these conditions.
