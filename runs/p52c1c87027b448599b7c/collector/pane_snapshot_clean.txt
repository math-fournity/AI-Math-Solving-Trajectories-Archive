Looking at this problem, I need to determine whether a non-abelian finite group
can have more than half its elements be of order 2.

**Answer: Yes.**

**Proof.**

Consider the dihedral group of order 8, i.e., the symmetry group of a square:

$$D_8 = \langle r, s \mid r^4 = s^2 = e,\; srs = r^{-1} \rangle.$$

This group has 8 elements: $e, r, r^2, r^3, s, sr, sr^2, sr^3$.

**$D_8$ is non-abelian:** $rs = sr^{-1} = sr^3 \neq sr$, so $rs \neq sr$.

**Counting elements of order 2:**

- $e$: order 1.
- $r$: order 4.
- $r^2$: $(r^2)^2 = r^4 = e$ and $r^2 \neq e$, so order 2. ✓
- $r^3$: order 4.
- $s$: $s^2 = e$, $s \neq e$, so order 2. ✓
- $sr$: Using $srs = r^{-1}$, i.e., $rs = sr^{-1}$:
$$(sr)^2 = s(rs)r = s(sr^{-1})r = s^2 r^{-1}r = e.$$
Since $sr \neq e$, order 2. ✓
- $sr^2$: $(sr^2)^2 = s(r^2 s)r^2$. From $rs = sr^{-1}$ we get $r^2 s = r(rs) =
r \cdot sr^{-1} = (rs)r^{-1} = sr^{-1} \cdot r^{-1} = sr^{-2}$. So:
$$(sr^2)^2 = s \cdot sr^{-2} \cdot r^2 = s^2 \cdot e = e.$$
Since $sr^2 \neq e$, order 2. ✓
- $sr^3$: Similarly, $r^3 s = sr^{-3}$, so:
$$(sr^3)^2 = s(r^3 s)r^3 = s \cdot sr^{-3} \cdot r^3 = s^2 \cdot e = e.$$
Since $sr^3 \neq e$, order 2. ✓

**Tally:** The elements of order 2 are $r^2, s, sr, sr^2, sr^3$ — that is **5 ou
t of 8** elements.

Since $\frac{5}{8} > \frac{1}{2}$, the dihedral group $D_8$ is a non-abelian fin
ite group in which more than half of the elements have order 2. $\blacksquare$

**Remark (general pattern).** More generally, the dihedral group of order $2n$ (
symmetries of a regular $n$-gon) has $n$ reflections, all of order 2. When $n$ i
s even, the rotation $r^{n/2}$ also has order 2, giving $n+1$ involutions out of
 $2n$ elements, and $\frac{n+1}{2n} > \frac{1}{2}$ for every even $n \geq 4$. Th
is yields infinitely many examples.
