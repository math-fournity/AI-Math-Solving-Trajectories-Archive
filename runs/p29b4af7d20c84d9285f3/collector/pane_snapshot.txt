## Proof

**Theorem.** There exist numbers $n$ in bases $b > 2$ satisfying $n = s_b(n)^{s_
b(n)}$. Specifically, for every odd integer $k \geq 3$, the number $n = k^k$ sat
isfies this equation in base $b = k^2$.

**Construction.** Let $k \geq 3$ be an odd integer and set $b = k^2$. Since $k \
geq 3$, we have $b = k^2 \geq 9 > 2$, so $b$ is a valid base. Since $k \geq 3$,
we have $1 \leq k < k^2 = b$, so $k$ is a valid single digit in base $b$.

Because $k$ is odd, $(k-1)/2$ is a non-negative integer, and we can write:
$$k^k = k \cdot k^{k-1} = k \cdot (k^2)^{(k-1)/2} = k \cdot b^{(k-1)/2}.$$

This is the base-$b$ representation of $k^k$ with digit $k$ in the $b^{(k-1)/2}$
 position and zeros elsewhere:
$$k^k = (\underbrace{k, 0, 0, \ldots, 0}_{(k-1)/2 \text{ zeros}})_b.$$

The digit sum is therefore:
$$s_b(k^k) = k + 0 + 0 + \cdots + 0 = k.$$

It follows that:
$$s_b(n)^{s_b(n)} = k^k = n. \qquad \checkmark$$
