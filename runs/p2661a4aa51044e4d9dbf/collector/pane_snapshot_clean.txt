## Proof

**Setting up the framework.** Let the number have digits $d_1 d_2 \cdots d_n$ (l
eft to right). Define $\epsilon_i = (-1)^{n-i}$, so the alternating sum is $S =
\sum_{i=1}^n \epsilon_i d_i$. The number is divisible by 11 iff $S \equiv 0 \pmo
d{11}$.

When digit $d_i$ is replaced by $d_i'$, the alternating sum changes by $(d_i' -
d_i)\epsilon_i$.

**Step 1: Every digit must be 0 or 9.**

Suppose some digit $d_i$ satisfies $1 \le d_i \le 8$. Then both $d_i+1$ and $d_i
-1$ are valid replacements (each with $|a-a'|=1$). Self-Correcting requires:
$$S + \epsilon_i \equiv 0 \pmod{11} \quad \text{and} \quad S - \epsilon_i \equiv
 0 \pmod{11}$$
Subtracting gives $2\epsilon_i \equiv 0 \pmod{11}$. Since $\epsilon_i = \pm 1$ a
nd $\gcd(2,11)=1$, this is impossible. **Contradiction.** So every digit is eith
er 0 or 9.

**Step 2: Position constraints.**

For a digit $d_i = 0$: only replacement is $0 \to 1$, requiring $S + \epsilon_i
\equiv 0 \pmod{11}$, i.e., $S \equiv -\epsilon_i \pmod{11}$.

For a digit $d_i = 9$: only replacement is $9 \to 8$, requiring $S - \epsilon_i
\equiv 0 \pmod{11}$, i.e., $S \equiv \epsilon_i \pmod{11}$.

For all positions to agree on the same $S \pmod{11}$:
- All 0-digits must share the same $\epsilon$ value (call it $\epsilon_0$).
- All 9-digits must share the same $\epsilon$ value (call it $\epsilon_9$).
- We need $-\epsilon_0 \equiv \epsilon_9 \pmod{11}$, so $\epsilon_9 = -\epsilon_
0$.

Thus 0-digits and 9-digits occupy positions of **opposite parity** (from the rig
ht).

**Step 3: Counting the nines.**

Let $k$ = number of 9-digits. Since all 9s are at positions with the same $\epsi
lon$ value:

- **Case A** ($\epsilon_9 = -1$): $S = -9k$, need $S \equiv -(-1) = 1 \pmod{11}$
, so $-9k \equiv 1 \pmod{11}$, giving $k \equiv 5 \pmod{11}$.
- **Case B** ($\epsilon_9 = 1$): $S = 9k$, need $S \equiv 1 \pmod{11}$, so $9k \
equiv 1 \pmod{11}$, giving $k \equiv 5 \pmod{11}$.

In both cases $k \equiv 5 \pmod{11}$, so $k \ge 5$. Also $S \equiv 1 \pmod{11} \
neq 0$, confirming System-Stable.

**Step 4: Minimizing the number of digits.**

We need at least 5 nines at positions of one parity, and at least one zero at th
e opposite parity (all-9 fails since positions of both parities exist for $n \ge
 2$, forcing contradictory $\epsilon$ requirements; all-0 gives $S=0$, violating
 System-Stable).

- **Case A**: 9s at $\epsilon=-1$ positions (count $= \lfloor n/2 \rfloor$). Nee
d $\lfloor n/2 \rfloor \ge 5 \Rightarrow n \ge 10$.
- **Case B**: 9s at $\epsilon=1$ positions (count $= \lceil n/2 \rceil$). Need $
\lceil n/2 \rceil \ge 5 \Rightarrow n \ge 9$.

Case B with $n=9$ gives the fewest digits. For $n=9$: $\epsilon_i = 1$ at odd po
sitions $(1,3,5,7,9)$ — exactly 5 positions, all must be 9. Even positions $(2,4
,6,8)$ — 4 positions, all must be 0.

This yields the unique number: $\boxed{909090909}$.

**Step 5: Verification.**

- **System-Stable**: $S = 9(1+1+1+1+1) = 45 \equiv 1 \pmod{11}$. Not divisible b
y 11. ✓
- **Self-Correcting (9→8 at any odd position)**: $S$ decreases by $1 \cdot \epsi
lon_i = 1$, giving $44 \equiv 0 \pmod{11}$. ✓
- **Self-Correcting (0→1 at any even position)**: $S$ changes by $1 \cdot \epsil
on_i = 1 \cdot (-1) = -1$, giving $44 \equiv 0 \pmod{11}$. ✓

No number with fewer than 9 digits can satisfy the constraints (maximum same-par
ity positions for $n \le 8$ is 4, but $k \ge 5$ is required). Therefore **909090
909** is the minimum.
