## Proof

**Problem.** Find the extremals with corner point for
$$J[y] = \int_0^2 y'^2(y'-1)^2\,dx, \qquad y(0)=0,\; y(2)=1.$$

---

### Step 1. Setup and the Euler–Lagrange equation

The integrand $F(x,y,y') = y'^2(y'-1)^2$ depends only on $y'$, so on every smoot
h segment the Euler–Lagrange equation gives
$$\frac{d}{dx}F_{y'} = 0 \implies F_{y'} = \text{const}.$$
Computing:
$$F_{y'}(p) = 2p(p-1)(2p-1), \qquad p = y'.$$
Since $F_{y'}=c$ is an algebraic equation in $p$ (with no $x$ or $y$ dependence)
, **$y'$ is constant on each smooth segment**, i.e., the extremal is **piecewise
 linear**.

---

### Step 2. Weierstrass–Erdmann corner conditions

At a corner $x=c$ where $y'$ jumps from $p_1$ to $p_2$ ($p_1 \neq p_2$), the two
 Weierstrass–Erdmann conditions require:

**(WE-1)** $F_{y'}$ continuous: $\;F_{y'}(p_1) = F_{y'}(p_2)$.

**(WE-2)** $F - y'F_{y'}$ continuous: $\;\bigl[F - p\,F_{y'}\bigr](p_1) = \bigl[
F - p\,F_{y'}\bigr](p_2)$.

Compute the second expression:
$$F - p\,F_{y'} = p^2(p-1)^2 - p\cdot 2p(p-1)(2p-1) = p^2(p-1)\bigl[(p-1)-2(2p-1
)\bigr] = -p^2(p-1)(3p-1).$$

So we need $p_1 \neq p_2$ satisfying:
$$2p_1(p_1-1)(2p_1-1) = 2p_2(p_2-1)(2p_2-1), \tag{I}$$
$$p_1^2(p_1-1)(3p_1-1) = p_2^2(p_2-1)(3p_2-1). \tag{II}$$

---

### Step 3. Solving the corner conditions

Let $s = p_1+p_2$, $q = p_1 p_2$. Factoring out $(p_1-p_2)\neq 0$:

From (I): $4(s^2 - q) - 6s + 2 = 0 \implies q = s^2 - \tfrac{3}{2}s + \tfrac{1}{
2}.$

From (II): $3s(s^2-2q) - 4(s^2-q) + s = 0 \implies q = \frac{s(3s-1)(s-1)}{2(3s-
2)}.$

Equating and simplifying (using $2s^2-3s+1=(2s-1)(s-1)$):
$$(2s-1)(s-1)(3s-2) = s(3s-1)(s-1).$$

**Case $s=1$:** Then $q = 1 - \tfrac{3}{2} + \tfrac{1}{2} = 0$, so $\{p_1,p_2\}
= \{0,1\}$. The discriminant $s^2-4q = 1 > 0$, giving **distinct** roots. ✓

**Case $s\neq 1$:** Dividing by $(s-1)$ yields $3s^2-6s+2=0$, so $s = 1 \pm \tfr
ac{1}{\sqrt{3}}$. For both values, the discriminant $s^2 - 4q = -3s^2+6s-2 = 0$,
 giving $p_1 = p_2$ (a double root — **no corner**). ✗

**Conclusion:** The only corner-compatible pair is $\{p_1, p_2\} = \{0, 1\}$.

---

### Step 4. Determining the corner location

With a single corner at $x=c$, $y'$ takes value $a$ on $[0,c]$ and $b$ on $[c,2]
$, with $\{a,b}=\{0,1\}$. The boundary conditions require:
$$y(2)-y(0) = \int_0^2 y'\,dx = 1.$$

- **$a=1,\, b=0$:** $\int_0^2 y'\,dx = c\cdot 1 + (2-c)\cdot 0 = c = 1 \implies
c=1$.
- **$a=0,\, b=1$:** $\int_0^2 y'\,dx = (2-c)\cdot 1 = 1 \implies c=1$.

In both cases the corner is at $x=1$.

---

### Step 5. The two extremals

**Extremal 1** ($y'=1$ on $[0,1]$, $y'=0$ on $[1,2]$):
$$\boxed{y(x) = \begin{cases} x, & 0 \le x \le 1, \\ 1, & 1 \le x \le 2. \end{ca
ses}}$$

**Extremal 2** ($y'=0$ on $[0,1]$, $y'=1$ on $[1,2]$):
$$\boxed{y(x) = \begin{cases} 0, & 0 \le x \le 1, \\ x-1, & 1 \le x \le 2. \end{
cases}}$$

Both have a corner at $x=1$ where $y'$ jumps between $0$ and $1$.

---

### Step 6. Verification

**Corner conditions at $p\in\{0,1\}$:**
- $F_{y'}(0) = 0 = F_{y'}(1)$. ✓ (WE-1)
- $[F-pF_{y'}](0) = 0 = [F-pF_{y'}](1)$. ✓ (WE-2)

**Boundary conditions:** Both satisfy $y(0)=0$, $y(2)=1$. ✓

**Functional value:** Since $y'\in\{0,1\}$ a.e., $F = y'^2(y'-1)^2 = 0$ a.e., so
 $J=0$. As $F\ge 0$ everywhere, **$J\ge 0$ for all admissible $y$**, hence these
 are **global minimizers**.

**Weierstrass excess function** (sufficient condition for strong minimum):
$$E(p,q) = F(q) - F(p) - (q-p)F_{y'}(p) = q^2(q-1)^2 \ge 0 \quad \text{for } p\i
n\{0,1\},\; \forall q.$$
Confirmed. ✓

---

### Summary

The extremals with a corner point are the two piecewise-linear functions above,
each with a single corner at $x=1$ where $y'$ jumps between $0$ and $1$. Both ac
hieve the global minimum $J=0$.

### PROOF COMPLETE
