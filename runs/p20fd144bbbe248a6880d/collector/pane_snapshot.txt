Looking at this problem, I need to find the maximum $n$ such that there exists a
 set of $n$ distinct charges where, for every nontrivial partition into Alpha/Be
ta, a single swap (one from Alpha→Beta, then one from Beta→Alpha) makes both uni
ts sum to zero.

## Formalization

Let charges be $c_1, \ldots, c_n$ (distinct). For a partition $(S, T)$ with $S \
cup T = C$, $|S|,|T| \geq 1$, we move $a \in S$ to $T$, then move $b \in T \cup
\{a\}$ back to $S$. The final Alpha set is $(S \setminus \{a\}) \cup \{b\}$ with
 sum $\sigma_S - c_a + c_b = 0$.

**Necessary condition:** Since both units sum to 0 after the exchange, the total
 $\sum c_i = 0$ (this is distribution-independent, so it must hold).

**Key condition:** For every nonempty proper subset $S \subset C$:
- If $\sigma_S = 0$: pick $b = a$ (swap the same isotope back), automatically sa
tisfied.
- If $\sigma_S \neq 0$: there must exist $a \in S$ with $c_a - \sigma_S \in C \s
etminus S$ (i.e., $b \in T$ with $c_b = c_a - \sigma_S$).

## $n = 3$ is achievable

Take $C = \{a, -a, 0\}$ with $a \neq 0$. Verify all nonempty proper subsets:

| $S$ | $\sigma_S$ | Check |
|-----|-----------|-------|
| $\{a\}$ | $a$ | $a - a = 0 \in C \setminus S$ ✓ |
| $\{-a\}$ | $-a$ | $-a-(-a) = 0 \in C \setminus S$ ✓ |
| $\{0\}$ | $0$ | Auto ✓ |
| $\{a,-a\}$ | $0$ | Auto ✓ |
| $\{a,0\}$ | $a$ | $0 - a = -a \in C\setminus S$ ✓ |
| $\{-a,0\}$ | $-a$ | $0-(-a) = a \in C\setminus S$ ✓ |

All subsets satisfy the condition, so $n = 3$ works.

## $n = 4$ is impossible

Suppose $C = \{c_1, c_2, c_3, c_4\}$, all distinct, $\sum c_i = 0$.

**Step 1: $0 \in C$ is forced.** For any singleton $S = \{c_i\}$ with $c_i \neq
0$, we need $c_i - c_i = 0 \in C \setminus \{c_i\}$, so $0 \in C$. (If $c_i = 0$
, $\sigma_S = 0$ is automatic.)

Write $C = \{0, a, b, c\}$ with $a, b, c \neq 0$, all distinct, and $a + b + c =
 0$.

**Step 2: Derive a contradiction from the pair $\{0, a\}$.** For $S = \{0, a\}$,
 $\sigma_S = a \neq 0$. We need some element $x \in S$ with $x - a \in C \setmin
us S = \{b, c\}$:
- $x = 0$: $0 - a = -a \in \{b, c\}$, so $-a = b$ or $-a = c$.
- $x = a$: $a - a = 0 \in \{b, c\}$, so $b = 0$ or $c = 0$ — **impossible** sinc
e $b, c \neq 0$.

So $-a \in \{b, c\}$. WLOG $-a = b$ (the case $-a = c$ is symmetric). Then $a +
b = 0$, so $c = -(a+b) = 0$, contradicting $c \neq 0$.

Therefore **no set of 4 distinct charges can satisfy the condition**, and $n \ge
q 4$ is impossible.

## Conclusion

The maximum possible value is $n = \boxed{3}$.
