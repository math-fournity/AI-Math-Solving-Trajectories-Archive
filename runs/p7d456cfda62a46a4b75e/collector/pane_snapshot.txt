Looking at this problem, I need to determine whether two compact measure-zero su
bsets of a locally compact group can have a product set of positive measure.

**Answer: Yes.**

## Proof

Consider $G = \mathbb{R}$ under addition, a locally compact group with Haar meas
ure equal to Lebesgue measure $\mu$.

**The Cantor set.** Let $C \subset [0,1]$ be the standard middle-thirds Cantor s
et. It is well known that:

1. **$C$ is compact** — it is closed (intersection of closed sets) and bounded.
2. **$\mu(C) = 0$** — at stage $n$ of its construction, $2^n$ intervals of lengt
h $3^{-n}$ remain, so $\mu(C) \le \lim_{n\to\infty} 2^n \cdot 3^{-n} = 0$.

**Characterization of $C$.** The Cantor set admits the characterization:
$$C = \left\{\sum_{n=1}^{\infty} a_n\, 3^{-n} : a_n \in \{0, 2\}\right\}.$$

**Claim: $C + C = [0, 2]$.**

*Proof of claim.*

($\subseteq$): Since $C \subseteq [0,1]$, we have $C + C \subseteq [0, 2]$.

($\supseteq$): Let $z \in [0, 2]$. Then $z/2 \in [0, 1]$, so $z/2$ admits a tern
ary expansion
$$\frac{z}{2} = \sum_{n=1}^{\infty} c_n\, 3^{-n}, \qquad c_n \in \{0, 1, 2\}.$$

For each $n$, choose $a_n, b_n \in \{0, 2\}$ such that $a_n + b_n = 2c_n$:
- If $c_n = 0$: set $a_n = 0,\; b_n = 0$.
- If $c_n = 1$: set $a_n = 0,\; b_n = 2$.
- If $c_n = 2$: set $a_n = 2,\; b_n = 2$.

Define
$$x = \sum_{n=1}^{\infty} a_n\, 3^{-n} \in C, \qquad y = \sum_{n=1}^{\infty} b_n
\, 3^{-n} \in C.$$

Then
$$x + y = \sum_{n=1}^{\infty} (a_n + b_n)\, 3^{-n} = \sum_{n=1}^{\infty} 2c_n\,
3^{-n} = 2 \cdot \frac{z}{2} = z.$$

Hence $z \in C + C$, proving $C + C = [0, 2]$. $\square$

**Conclusion.** Taking $A = B = C$, both are compact subsets of the locally comp
act group $\mathbb{R}$ with $\mu(A) = \mu(B) = 0$, yet
$$\mu(A + B) = \mu(C + C) = \mu([0, 2]) = 2 > 0.$$

Therefore, the product (here, the Minkowski sum) of two compact measure-zero sub
sets of a locally compact group **can** have non-zero measure. $\blacksquare$
