Looking at this problem, I need to count arrangements of 2500 sensors on a 100×1
00 grid where no two sensors share a 2×2 block (Chebyshev distance ≥ 2), and eve
ry row and column has exactly 25 sensors.

## Proof

**Step 1: Partition into 2×2 blocks.**

Partition the grid into 50×50 disjoint 2×2 blocks: block $(i,j)$ covers rows $\{
2i-1, 2i\}$ and columns $\{2j-1, 2j\}$, for $i,j \in \{1,\dots,50\}$. There are
2500 such blocks. Since each 2×2 block contains at most 1 sensor (by condition (
i)), and we need 2500 sensors total, **every block contains exactly one sensor**
.

**Step 2: Encode positions.**

Each block $(i,j)$ has its sensor at row $2i-1+a_{ij}$, column $2j-1+b_{ij}$, wh
ere $a_{ij} \in \{0,1\}$ (row offset) and $b_{ij} \in \{0,1\}$ (column offset).

**Step 3: Derive monotonicity constraints from straddling 2×2 blocks.**

Consider 2×2 blocks that straddle partition boundaries:

- **Horizontal straddlers** (rows $\{2i-1,2i\}$, cols $\{2j,2j+1\}$): Two sensor
s land here iff $b_{ij}=1$ and $b_{i,j+1}=0$. Avoiding this gives **$b_{ij} \leq
 b_{i,j+1}$ for all $i,j$** — $b$ is non-decreasing in each row. Call this **C1*
*.

- **Vertical straddlers** (rows $\{2i,2i+1\}$, cols $\{2j-1,2j\}$): Similarly gi
ves **$a_{ij} \leq a_{i+1,j}$** — $a$ is non-decreasing in each column. Call thi
s **C2**.

- **Diagonal straddlers** (rows $\{2i,2i+1\}$, cols $\{2j,2j+1\}$): Up to 4 corn
er sensors can land here. Given C1 and C2, the only possible double-occupancies
are two "checkerboard" patterns, which must be forbidden. This gives additional
constraints (analyzed in Step 6).

**Step 4: Apply row/column sum constraints.**

- **Row $2i-1$ has 25 sensors**: exactly 25 blocks in row-pair $i$ have $a_{ij}=
0$. So each row of the block grid has 25 blocks with $a=0$ and 25 with $a=1$.

- **Column $2j-1$ has 25 sensors**: exactly 25 blocks in column-pair $j$ have $b
_{ij}=0$. So each column of the block grid has 25 blocks with $b=0$ and 25 with
$b=1$.

**Step 5: C1 + column sums force $b$ to be constant per row.**

By C1, row $i$ has $b_{ij}=0$ for $j \leq s_i$ and $b_{ij}=1$ for $j > s_i$ (non
-decreasing, transition at $s_i$). Column $j$ has 25 ones: $\#\{i : s_i < j\} =
25$ for every $j$. Setting $m_k = \#\{i : s_i = k\}$:
- $j=1$: $m_0 = 25$
- $j=2$: $m_0 + m_1 = 25 \Rightarrow m_1 = 0$
- Inductively: $m_1 = m_2 = \cdots = m_{49} = 0$, and $m_{50} = 25$.

So $s_i \in \{0, 50\}$: **$b$ is constant in each row** — exactly 25 rows are al
l-$b=1$ (set $B$) and 25 rows are all-$b=0$.

By the identical argument (C2 + row sums): **$a$ is constant in each column** —
exactly 25 columns are all-$a=1$ (set $A$) and 25 columns are all-$a=0$, where $
A \subseteq \{1,\dots,50\}$, $|A|=25$.

**Step 6: Apply checkerboard constraints.**

With $a$ constant per column and $b$ constant per row, the block type at $(i,j)$
 is $(a_{ij}, b_{ij}) = (\mathbf{1}_{j \in A}, \mathbf{1}_{i \in B})$.

The two forbidden checkerboard patterns reduce to:
- **Pattern 1**: $j \in A, j+1 \notin A, i \in B, i+1 \notin B$ — requires a *de
scent* in both $A$ and $B$.
- **Pattern 2**: $j \notin A, j+1 \in A, i \notin B, i+1 \in B$ — requires an *a
scent* in both $A$ and $B$.

Define $D_A = \{j : j \in A, j+1 \notin A\}$ (descents), $U_A = \{j : j \notin A
, j+1 \in A\}$ (ascents), similarly for $B$. The constraints are:

$$(D_A = \emptyset \text{ or } D_B = \emptyset) \quad \text{and} \quad (U_A = \e
mptyset \text{ or } U_B = \emptyset)$$

For a size-25 subset of $\{1,\dots,50\}$:
- $D_A = \emptyset$ iff $A = \{26,\dots,50\}$ (final segment), which gives $U_A
= \{25\} \neq \emptyset$.
- $U_A = \emptyset$ iff $A = \{1,\dots,25\}$ (initial segment), which gives $D_A
 = \{25\} \neq \emptyset$.
- If $A$ is neither, both $D_A, U_A \neq \emptyset$.

The four combinations:
1. $D_A = \emptyset, U_A = \emptyset$: impossible (would need $|A| \in \{0,50\}$
).
2. $D_A = \emptyset, U_B = \emptyset$: $A = \{26,\dots,50\}, B = \{1,\dots,25\}$
. ✓
3. $D_B = \emptyset, U_A = \emptyset$: $B = \{26,\dots,50\}, A = \{1,\dots,25\}$
. ✓
4. $D_B = \emptyset, U_B = \emptyset$: impossible.

**Exactly 2 valid configurations.**

**Step 7: Verify both configurations satisfy all constraints.**

**Config 1** ($A=\{26,\dots,50\}, B=\{1,\dots,25\}$): Block types form four quad
rants — NE/SW/NW/SE arranged so the critical boundary 2×2 at $(25,25)$ is $\begi
n{smallmatrix} \text{NE} & \text{SE} \\ \text{NW} & \text{SW} \end{smallmatrix}$
, which is not a forbidden checkerboard. All row sums = 25, all column sums = 25
, all Chebyshev distances ≥ 2. ✓

**Config 2** ($A=\{1,\dots,25\}, B=\{26,\dots,50\}$): Block quadrants are SW/NW/
SE/NE, with boundary 2×2 $\begin{smallmatrix} \text{SW} & \text{NW} \\ \text{SE}
 & \text{NE} \end{smallmatrix}$, also not forbidden. All constraints satisfied.
✓

The two configurations are distinct (and rotations/reflections are counted separ
ately regardless).
