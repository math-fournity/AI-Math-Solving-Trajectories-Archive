## Setting Up the Zero Structure

The zeros of $f_n$ satisfy $f_n(x)=0 \iff f_{n-1}(|x-n|)=0 \iff |x-n|$ is a zero
 of $f_{n-1}$. So if $z$ is a zero of $f_{n-1}$, then $x = n+z$ or $x = n-z$ is
a zero of $f_n$.

Let $D_n$ denote the set of distinct zeros of $f_n$. Then:
$$D_n = \{n+z,\; n-z : z \in D_{n-1}\}$$

**Computing small cases:**
- $D_1 = \{1\}$
- $D_2 = \{3, 1\}$
- $D_3 = \{6, 0, 4, 2\}$
- $D_4 = \{10, -2, 4, 8, 0, 6, 2\}$ (note: 4 appears twice, so 7 distinct)
- $D_5 = \{-5, -3, -1, 1, 3, 5, 7, 9, 11, 13, 15\}$ (11 distinct)
- $D_6 = \{-9, -7, \ldots, 19, 21\}$ (16 distinct)

## Key Claim: $D_n$ is a complete arithmetic sequence with common difference 2

**Proof by induction.** The base cases $D_1, D_2, D_3$ are verified above.

**Inductive step.** Assume $D_{n-1} = \{m_{n-1}, m_{n-1}+2, \ldots, M_{n-1}\}$ i
s a complete arithmetic sequence with step 2. Then $D_n$ is the union of:
- $A = \{n+m_{n-1},\; n+m_{n-1}+2, \ldots, n+M_{n-1}\}$ (from $n+z$)
- $B = \{n-M_{n-1},\; n-M_{n-1}+2, \ldots, n-m_{n-1}\}$ (from $n-z$)

Both are arithmetic sequences with step 2 and the same parity. The gap between $
B$ (ending at $n - m_{n-1}$) and $A$ (starting at $n + m_{n-1}$) is $2m_{n-1}$.

Since $m_{n-1} = (n-1)(4-n)/2 \leq 1$ for all $n \geq 2$ (verified: $m_1=1, m_2=
1, m_3=0$, and $m_k < 0$ for $k \geq 4$), the gap is at most 2, so $A \cup B$ fo
rms a **complete** arithmetic sequence with step 2. $\square$

## Deriving the Formulas

**Maximum:** $M_n = n + M_{n-1} = n(n+1)/2$ (all positive signs).

**Minimum:** $m_n = n - M_{n-1} = n - n(n-1)/2 = n(3-n)/2$ (for $n \geq 2$).

**Count of distinct zeros:**
$$|D_n| = \frac{M_n - m_n}{2} + 1 = \frac{n(n+1)/2 - n(3-n)/2}{2} + 1 = \frac{n(
n-1)}{2} + 1 = \binom{n}{2}+1$$

**Verification:** $|D_1|=1, |D_2|=2, |D_3|=4, |D_4|=7, |D_5|=11, |D_6|=16$. All
match $\binom{n}{2}+1$. ✓

**Sum of distinct zeros** (arithmetic series):
$$S_n = |D_n| \cdot \frac{m_n + M_n}{2} = \left(\frac{n(n-1)}{2}+1\right) \cdot
\frac{n(3-n)/2 + n(n+1)/2}{2} = \left(\frac{n(n-1)}{2}+1\right) \cdot n = \frac{
n(n^2 - n + 2)}{2}$$

**Verification:** $S_1=1, S_2=4, S_3=12, S_4=28, S_5=55, S_6=96$. All match dire
