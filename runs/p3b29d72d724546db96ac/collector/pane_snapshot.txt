## Solution

Evaluate
$$I = \int_{-\infty}^{\infty} \frac{dx}{(x^2+1)(x^2-2x+2)}.$$

### Step 1. Complexify and identify poles

Set
$$f(z) = \frac{1}{(z^2+1)(z^2-2z+2)}.$$

Factor the denominators:
- $z^2+1 = (z-i)(z+i)$,
- $z^2-2z+2 = (z-(1+i))(z-(1-i))$.

The poles are $z = i,\,-i,\,1+i,\,1-i$, all simple.

### Step 2. Choose the contour

Use the standard semicircular contour $C_R$ consisting of $[-R,R]$ on the real a
xis plus the upper semicircle $\Gamma_R$ of radius $R$, traversed counterclockwi
se. For $R > \sqrt{2}$ the contour encloses exactly the two upper-half-plane pol
es:
$$z = i \quad\text{and}\quad z = 1+i.$$

On $\Gamma_R$, since $\deg(\text{denominator})=4$ and $\deg(\text{numerator})=0$
, we have $|f(z)| = O(R^{-4})$ and $|\Gamma_R| = \pi R$, so
$$\left|\int_{\Gamma_R} f(z)\,dz\right| \le \frac{\pi R \cdot M_R}{1} = O(R^{-3}
) \to 0 \quad\text{as } R\to\infty.$$

Hence
$$I = \lim_{R\to\infty}\int_{-R}^{R} f(x)\,dx = 2\pi i \sum_{\operatorname{Im} z
_k > 0} \operatorname{Res}(f, z_k).$$

### Step 3. Compute the residues

**At $z = i$** (simple pole from $z^2+1=(z-i)(z+i)$):
$$\operatorname{Res}(f, i) = \frac{1}{(z+i)(z^2-2z+2)}\bigg|_{z=i} = \frac{1}{(2
i)\bigl(i^2-2i+2\bigr)} = \frac{1}{(2i)(1-2i)}.$$
Multiplying out, $(2i)(1-2i) = 2i - 4i^2 = 4 + 2i$, so
$$\operatorname{Res}(f, i) = \frac{1}{4+2i} = \frac{4-2i}{(4+2i)(4-2i)} = \frac{
4-2i}{16+4} = \frac{4-2i}{20} = \frac{2-i}{10}.$$

**At $z = 1+i$** (simple pole from $z^2-2z+2=(z-(1+i))(z-(1-i))$):
$$\operatorname{Res}(f, 1+i) = \frac{1}{(z^2+1)\,(z-(1-i))}\bigg|_{z=1+i}.$$
Compute each factor:
- $(1+i)^2 + 1 = (1+2i+i^2)+1 = 2i+1 = 1+2i$,
- $(1+i)-(1-i) = 2i$.

Thus
$$\operatorname{Res}(f, 1+i) = \frac{1}{(1+2i)(2i)} = \frac{1}{2i+4i^2} = \frac{
1}{-4+2i} = \frac{-4-2i}{(-4+2i)(-4-2i)} = \frac{-4-2i}{16+4} = \frac{-2-i}{10}.
$$

### Step 4. Sum and apply the residue theorem

$$\sum \operatorname{Res} = \frac{2-i}{10} + \frac{-2-i}{10} = \frac{(2-2)+(-i-i
)}{10} = \frac{-2i}{10} = -\frac{i}{5}.$$

Therefore
$$I = 2\pi i \cdot \left(-\frac{i}{5}\right) = 2\pi i \cdot \frac{-i}{5} = \frac
{2\pi \cdot (-i^2)}{5} = \frac{2\pi}{5}.$$

### Step 5. Verification (real-variable check)

Partial fractions give
$$\frac{1}{(x^2+1)(x^2-2x+2)} = \frac{\tfrac{2}{5}x+\tfrac{1}{5}}{x^2+1} + \frac
{-\tfrac{2}{5}x+\tfrac{3}{5}}{x^2-2x+2}.$$

Integrating term-by-term (with $u = x-1$ in the second):
$$\int \frac{dx}{(x^2+1)(x^2-2x+2)} = \frac{1}{5}\Bigl[\ln(x^2+1) + \arctan x -
\ln\bigl((x-1)^2+1\bigr) + \arctan(x-1)\Bigr].$$

As $x\to\pm\infty$ the logarithmic terms cancel (both $\sim 2\ln|x|$), and the a
rctangent terms contribute
$$\frac{1}{5}\Bigl[\bigl(\tfrac{\pi}{2}+\tfrac{\pi}{2}\bigr) - \bigl(-\tfrac{\pi
}{2}-\tfrac{\pi}{2}\bigr)\Bigr] = \frac{1}{5}\cdot 2\pi = \frac{2\pi}{5},$$
confirming the contour-integration result.

### Result

$$\boxed{\displaystyle \int_{-\infty}^{\infty} \frac{dx}{(x^2+1)(x^2-2x+2)} = \f
rac{2\pi}{5}}.$$
