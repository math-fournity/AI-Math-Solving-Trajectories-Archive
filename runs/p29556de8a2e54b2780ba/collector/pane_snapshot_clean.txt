## Proof of Existence

=0}^{N} \epsilon_i \cdot 3^i$ with $\epsilon_i \in \{-1, 0, 1\}$ via the followi

- If $k \equiv 0 \pmod{3}$: set $\epsilon_0 = 0$, recurse on $k/3$.
- If $k \equiv 1 \pmod{3}$: set $\epsilon_0 = 1$, recurse on $(k-1)/3$.
- If $k \equiv 2 \pmod{3}$: set $\epsilon_0 = -1$, recurse on $(k+1)/3$.

**Termination**: At each step, $k$ is replaced by $(k - \epsilon_0)/3$ where $\e
psilon_0 \in \{-1,0,1\}$ is chosen so that $3 \mid (k - \epsilon_0)$. We have $|

$. The base cases $k \in \{-1, 0, 1\}$ are resolved in one step. Hence the algor
ithm terminates, producing a finite representation.
