## Solution

We solve the homogeneous Fredholm equation

$$y(x) = \lambda \int_{0}^{\pi} \sin(x+z)\, y(z)\, dz.$$

**Step 1. Decompose the kernel.** Using the addition formula,

$$\sin(x+z) = \sin x \cos z + \cos x \sin z.$$

Hence

$$y(x) = \lambda \sin x \int_{0}^{\pi} \cos z\, y(z)\, dz \;+\; \lambda \cos x \
int_{0}^{\pi} \sin z\, y(z)\, dz.$$

Define the two constants

$$A = \int_{0}^{\pi} \cos z\, y(z)\, dz, \qquad B = \int_{0}^{\pi} \sin z\, y(z)
\, dz.$$

Then every solution has the form

$$y(x) = \lambda A \sin x + \lambda B \cos x. \tag{1}$$

So any eigenfunction must be a linear combination of $\sin x$ and $\cos x$.

**Step 2. Derive the algebraic system for $A, B$.** Substitute (1) into the defi
nitions of $A$ and $B$:

$$A = \int_{0}^{\pi} \cos z\,(\lambda A \sin z + \lambda B \cos z)\, dz = \lambd
a A \int_{0}^{\pi} \sin z \cos z\, dz + \lambda B \int_{0}^{\pi} \cos^{2} z\, dz
,$$

$$B = \int_{0}^{\pi} \sin z\,(\lambda A \sin z + \lambda B \cos z)\, dz = \lambd
a A \int_{0}^{\pi} \sin^{2} z\, dz + \lambda B \int_{0}^{\pi} \sin z \cos z\, dz
.$$

Compute the three elementary integrals:

$$\int_{0}^{\pi} \sin z \cos z\, dz = \tfrac{1}{2}\int_{0}^{\pi} \sin 2z\, dz =
\tfrac{1}{4}\bigl[-\cos 2z\bigr]_{0}^{\pi} = \tfrac{1}{4}(-\cos 2\pi + \cos 0) =
 0,$$

$$\int_{0}^{\pi} \cos^{2} z\, dz = \int_{0}^{\pi} \sin^{2} z\, dz = \frac{\pi}{2
}.$$

Therefore the system reduces to

$$A = \frac{\lambda \pi}{2}\, B, \qquad B = \frac{\lambda \pi}{2}\, A. \tag{2}$$

**Step 3. Find the eigenvalues.** Substituting one equation of (2) into the othe
r gives

$$A = \left(\frac{\lambda \pi}{2}\right)^{2} A.$$

A nontrivial solution ($A$ and $B$ not both zero, otherwise $y \equiv 0$) requir
es

$$\left(\frac{\lambda \pi}{2}\right)^{2} = 1 \quad\Longrightarrow\quad \frac{\la
mbda \pi}{2} = \pm 1 \quad\Longrightarrow\quad \lambda = \pm \frac{2}{\pi}.$$

These are the two eigenvalues.

**Step 4. Find the eigenfunctions.**

*Case $\lambda = \dfrac{2}{\pi}$:* From (2), $A = B$. Then (1) gives

$$y(x) = \frac{2}{\pi}A\,(\sin x + \cos x).$$

So the eigenfunction (up to a nonzero multiplicative constant) is

$$\boxed{y_{1}(x) = \sin x + \cos x, \qquad \lambda_{1} = \frac{2}{\pi}.}$$

*Case $\lambda = -\dfrac{2}{\pi}$:* From (2), $A = -B$. Then (1) gives

$$y(x) = -\frac{2}{\pi}A\,\sin x + \frac{2}{\pi}A\,\cos x = \frac{2A}{\pi}(\cos
x - \sin x).$$

So the eigenfunction (up to a nonzero multiplicative constant) is

$$\boxed{y_{2}(x) = \cos x - \sin x, \qquad \lambda_{2} = -\frac{2}{\pi}.}$$

**Verification.** For $y_{1}(x) = \sin x + \cos x$:

$$\int_{0}^{\pi} \sin(x+z)(\sin z + \cos z)\, dz = \sin x \int_{0}^{\pi}(\sin z\
cos z + \cos^{2} z)\, dz + \cos x \int_{0}^{\pi}(\sin^{2} z + \sin z\cos z)\, dz
$$
$$= \sin x \cdot \frac{\pi}{2} + \cos x \cdot \frac{\pi}{2} = \frac{\pi}{2}(\sin
 x + \cos x) = \frac{\pi}{2} y_{1}(x).$$

Thus $y_{1} = \lambda \cdot \frac{\pi}{2} y_{1}$ gives $\lambda = \frac{2}{\pi}$
. ✓

For $y_{2}(x) = \cos x - \sin x$:

$$\int_{0}^{\pi} \sin(x+z)(\cos z - \sin z)\, dz = \sin x \int_{0}^{\pi}(\cos^{2
} z - \sin z\cos z)\, dz + \cos x \int_{0}^{\pi}(\sin z\cos z - \sin^{2} z)\, dz
$$
$$= \sin x \cdot \frac{\pi}{2} + \cos x \cdot \left(-\frac{\pi}{2}\right) = -\fr
ac{\pi}{2}(\cos x - \sin x) = -\frac{\pi}{2} y_{2}(x).$$

Thus $y_{2} = \lambda \cdot \left(-\frac{\pi}{2}\right) y_{2}$ gives $\lambda =
-\frac{2}{\pi}$. ✓

**Conclusion.** The Fredholm equation has exactly two eigenvalues, each of multi
plicity one:

| Eigenvalue | Eigenfunction |
|---|---|
| $\lambda_{1} = \dfrac{2}{\pi}$ | $y_{1}(x) = \sin x + \cos x$ |
| $\lambda_{2} = -\dfrac{2}{\pi}$ | $y_{2}(x) = \cos x - \sin x$ |
