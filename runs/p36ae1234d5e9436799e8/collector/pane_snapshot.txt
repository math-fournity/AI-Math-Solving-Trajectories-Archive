Looking at this problem, I need to show that $\frac{1}{p-1}\sum_{a=1}^{p-1}|S_a|
$ is an integer, where $S_a$ is the set of values attained by $P_a(x) = x^n + ax
$ modulo $p$.

**Proof.**

Let $g = \gcd(n-1, p-1)$ and let $H = (\mathbb{F}_p^*)^{n-1}$ be the subgroup of
 $(n-1)$-th power residues, which has index $g$ in $\mathbb{F}_p^*$.

**Step 1: $|S_a|$ is constant on cosets of $H$.**

If $\lambda \in H$, write $\lambda = \mu^{n-1}$ for some $\mu \in \mathbb{F}_p^*
$. Then for any $c \in \mathbb{F}_p$:
$$P_{\lambda a}(\mu c) = (\mu c)^n + \lambda a(\mu c) = \mu^n c^n + \mu^{n-1} a
\cdot \mu c = \mu^n(c^n + ac) = \mu^n P_a(c).$$
Since $c \mapsto \mu c$ is a bijection on $\mathbb{F}_p$, we get $S_{\lambda a}
= \mu^n \cdot S_a$, so $|S_{\lambda a}| = |S_a|$.

**Step 2: $|S_a| \equiv 1 \pmod{g}$ for every $a \in \mathbb{F}_p^*$.**

Consider $\phi: \mathbb{F}_p^* \to H$, $\phi(c) = c^{n-1}$. Its kernel $K = \{c
: c^{n-1}=1\}$ has $|K| = g$, and each fiber $\phi^{-1}(u)$ for $u \in H$ is a c
oset of $K$ with $g$ elements.

For $c \in \mathbb{F}_p^*$, $P_a(c) = c(c^{n-1}+a) = c(u+a)$ where $u = c^{n-1}
\in H$.

- If $u = -a$ (only when $-a \in H$): $P_a(c) = 0$ for all $c$ in this fiber.
- If $u \neq -a$: the set $\{c(u+a) : c \in \phi^{-1}(u)\} = (u+a)\cdot\phi^{-1}
(u)$ is a coset of $K$ in $\mathbb{F}_p^*$, having exactly $g$ nonzero elements.

Two fibers over $u_1 \neq u_2$ (both $\neq -a$) yield the same coset iff $(u_1+a
)\phi^{-1}(u_1) = (u_2+a)\phi^{-1}(u_2)$, which holds iff $\frac{(u_1+a)c_1}{(u_
2+a)c_2} \in K$ for $c_i \in \phi^{-1}(u_i)$, i.e., $\left(\frac{(u_1+a)c_1}{(u_
2+a)c_2}\right)^{n-1} = 1$, i.e.:
$$\frac{(u_1+a)^{n-1}\, u_1}{(u_2+a)^{n-1}\, u_2} = 1.$$

Define $\Phi_a(u) = (u+a)^{n-1} u$ for $u \in H$, $u \neq -a$ (or all $u \in H$
if $-a \notin H$). Since $u \in H$ and $(u+a)^{n-1} \in H$, we have $\Phi_a(u) \
in H$. The number of distinct cosets produced equals $|\operatorname{Im}(\Phi_a)
|$.

Since distinct cosets of $K$ are disjoint, and $0 \in S_a$ (from $c=0$) while al
l cosets lie in $\mathbb{F}_p^*$:
$$|S_a| = 1 + g \cdot m_a, \quad \text{where } m_a := |\operatorname{Im}(\Phi_a)
| \geq 0.$$

**Step 3: Conclusion.**

By Step 1, $|S_a|$ (hence $m_a$) is constant on the $g$ cosets of $H$, each of s
ize $\frac{p-1}{g}$. Let $a_1, \dots, a_g$ be coset representatives. Then:
$$\sum_{a=1}^{p-1} |S_a| = \sum_{a=1}^{p-1}(1 + g\, m_a) = (p-1) + g\sum_{a=1}^{
p-1} m_a = (p-1) + g \cdot \frac{p-1}{g}\sum_{j=1}^{g} m_{a_j} = (p-1)\!\left(1
+ \sum_{j=1}^{g} m_{a_j}\right).$$

Therefore:
$$\frac{1}{p-1}\sum_{a=1}^{p-1}|S_a| = 1 + \sum_{j=1}^{g} m_{a_j},$$
which is an integer. $\blacksquare$
