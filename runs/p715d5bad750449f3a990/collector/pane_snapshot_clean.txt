## Solution

Let $g(y) = f^{-1}(y)$. First find where $f(x)=1$:
$$\sin x + x^2 + 1 = 1 \implies \sin x + x^2 = 0.$$
At $x=0$: $\sin 0 + 0 = 0$. ✓ So $g(1)=0$.

**Setup.** Let $x = g(y)$, so $f(x)=y$ and $\frac{d}{dy} = \frac{1}{f'(x)}\frac{
d}{dx}$. Denote
$$p=f'(x)=\cos x+2x,\quad q=f''(x)=-\sin x+2,\quad r=f'''(x)=-\cos x,\quad s=f^{
(4)}(x)=\sin x.$$
At $x=0$: $p=1,\ q=2,\ r=-1,\ s=0$.

**Recursive differentiation.** Using $g^{(n+1)}(y) = \frac{1}{p}\frac{d}{dx}\big
[g^{(n)}(y)\big]$:

- $g' = \dfrac{1}{p}$
- $g'' = \dfrac{1}{p}\cdot\dfrac{d}{dx}\!\left(\dfrac{1}{p}\right) = \dfrac{1}{p
}\!\left(-\dfrac{q}{p^2}\right) = -\dfrac{q}{p^3}$
- $g''' = \dfrac{1}{p}\!\left[-\dfrac{r}{p^3}+\dfrac{3q^2}{p^4}\right] = -\dfrac
{r}{p^4}+\dfrac{3q^2}{p^5}$
- $g^{(4)} = \dfrac{1}{p}\!\left[-\dfrac{s}{p^4}+\dfrac{10qr}{p^5}-\dfrac{15q^3}
{p^6}\right] = -\dfrac{s}{p^5}+\dfrac{10qr}{p^6}-\dfrac{15q^3}{p^7}$

where the last step uses
$$\frac{d}{dx}\!\left(-\frac{r}{p^4}\right)=-\frac{s}{p^4}+\frac{4rq}{p^5},\qqua
d \frac{d}{dx}\!\left(\frac{3q^2}{p^5}\right)=\frac{6qr}{p^5}-\frac{15q^3}{p^6}.
$$

**Evaluate at $x=0$** ($p=1,q=2,r=-1,s=0$):
$$g^{(4)}(1) = -\frac{0}{1} + \frac{10\cdot 2\cdot(-1)}{1} - \frac{15\cdot 8}{1}
 = -20 - 120 = -140.$$

**Verification via Taylor series.** $f(x)-1 = x + x^2 - \tfrac{x^3}{6} + 0\cdot
x^4 + \cdots$ (i.e. $a_1=1,a_2=1,a_3=-\tfrac16,a_4=0$). Invert $t = y-1$ as $x =
 b_1 t + b_2 t^2 + b_3 t^3 + b_4 t^4+\cdots$:

- $t^1$: $1 = b_1 \Rightarrow b_1=1$
- $t^2$: $0 = b_2 + b_1^2 \Rightarrow b_2=-1$
- $t^3$: $0 = b_3 + 2b_1b_2 + a_3 b_1^3 = b_3-2-\tfrac16 \Rightarrow b_3=\tfrac{
13}{6}$ (checks: $g'''(1)=6\cdot\tfrac{13}{6}=13$ ✓)
- $t^4$: $0 = b_4 + (2b_1b_3+b_2^2) + a_3(3b_1^2b_2) + a_4 b_1^4 = b_4 + \tfrac{
26}{6}+1 + \tfrac{3}{6} = b_4 + \tfrac{35}{6}$
  $$\Rightarrow b_4 = -\tfrac{35}{6},\qquad g^{(4)}(1) = 4!\,b_4 = 24\!\left(-\t
frac{35}{6}\right) = -140.\ \checkmark$$

$$\boxed{\dfrac{d^4}{dy^4}\big(f^{-1}(y)\big)\bigg|_{y=1} = -140}$$
