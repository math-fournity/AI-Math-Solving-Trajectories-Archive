Looking at this problem, I need to determine whether an injective immersion on a
 compact convex set must be locally bi-Lipschitz from below.

**Answer: Yes, such constants $a, b > 0$ must exist.**

**Proof:**

Since $f$ is an immersion, $f$ is $C^1$ and $df(x)$ has full rank $n$ for every
$x \in U$ (in particular $n \le m$). Since $K$ is compact and $U$ is an open nei
ghborhood of $K$, there exists $\delta_0 > 0$ such that the closed $\delta_0$-ne
ighborhood
$$K' = \{z \in \mathbb{R}^n : \operatorname{dist}(z, K) \le \delta_0\}$$
is compact and contained in $U$.

The function $\sigma(x) = \sigma_{\min}(df(x))$ (the smallest singular value of
the $m \times n$ matrix $df(x)$) is continuous and strictly positive on $U$, sin
ce $df(x)$ has full rank $n$. On the compact set $K'$, $\sigma$ attains a positi
ve minimum:
$$m_0 = \min_{x \in K'} \sigma(x) > 0.$$

Since $df$ is continuous on the compact set $K'$, it is uniformly continuous. Th
ere exists $\delta_1 > 0$ such that for all $z, z' \in K'$ with $|z - z'| < \del
ta_1$,
$$|df(z) - df(z')| < \frac{m_0}{2},$$
where $|\cdot|$ denotes the operator norm.

Set $a = \min(\delta_0, \delta_1) > 0$ and $b = m_0/2 > 0$.

**Claim:** For all $x, y \in K$ with $|x - y| < a$, $|f(x) - f(y)| \ge b\,|x - y
|$.

*Proof of claim:* Let $x, y \in K$ with $|x - y| < a$. The segment $[x, y] = \{x
 + t(y - x) : t \in [0,1]\}$ lies in $K'$, since every point on it is within dis
tance $|x - y| < \delta_0$ of $x \in K$. If $x = y$ the inequality is trivial. A
ssume $x \ne y$ and set $v = (y - x)/|y - x|$, a unit vector in $\mathbb{R}^n$.

By the fundamental theorem of calculus:
$$f(y) - f(x) = \int_0^1 df(x + t(y - x))\cdot(y - x)\,dt = |y - x|\int_0^1 df(x
 + t(y - x))\cdot v\,dt.$$

Decompose the integral:
$$\int_0^1 df(x + t(y - x))\cdot v\,dt = df(x)\cdot v + \int_0^1 \big[df(x + t(y
 - x)) - df(x)\big]\cdot v\,dt.$$

- **First term:** $|df(x)\cdot v| \ge \sigma_{\min}(df(x)) \ge m_0$ (since $x \i
n K \subset K'$).

- **Second term:** For each $t \in [0,1]$, the point $x + t(y - x)$ lies in $K'$
 and $|(x + t(y - x)) - x| = t|x - y| < \delta_1$, so $|df(x + t(y - x)) - df(x)
| < m_0/2$. Therefore:
$$\left|\int_0^1 \big[df(x + t(y - x)) - df(x)\big]\cdot v\,dt\right| \le \int_0
^1 |df(x + t(y - x)) - df(x)|\,dt \le \frac{m_0}{2}.$$

By the reverse triangle inequality:
$$\left|\int_0^1 df(x + t(y - x))\cdot v\,dt\right| \ge |df(x)\cdot v| - \frac{m
_0}{2} \ge m_0 - \frac{m_0}{2} = \frac{m_0}{2}.$$

Therefore:
$$|f(y) - f(x)| = |y - x|\cdot\left|\int_0^1 df(x + t(y - x))\cdot v\,dt\right|
\ge |y - x|\cdot\frac{m_0}{2} = b\,|y - x|.$$

This establishes the desired inequality for all $x, y \in K$ with $|x - y| < a$.
 $\square$

**Remark.** The injectivity of $f$ and convexity of $K$ are not needed for this
local lower Lipschitz estimate. The argument uses only that $f$ is a $C^1$ immer
sion (so $df$ has full rank everywhere and is continuous), and that $K$ is compa
ct with $K \subset U$ open. Convexity of $K$ ensures the segment $[x,y]$ stays i
n $K$ (hence in $U$), but compactness already guarantees a uniform tubular neigh
borhood $K' \subset U$ through which all short segments pass. Injectivity would
be required for a *global* bi-Lipschitz estimate (all $x, y \in K$, not just nea
rby pairs), which is a stronger statement.
