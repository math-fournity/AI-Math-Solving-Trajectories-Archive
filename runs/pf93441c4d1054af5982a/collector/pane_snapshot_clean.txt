## Proof

**Claim.** The only continuous real-valued function $f$ on $[0,1]$ satisfying
$$\int_0^1 f(x)\,x^n\,dx = 0 \quad\text{for all } n = 0,1,2,\dots$$
is the identically zero function $f \equiv 0$.

---

### Necessity ($f \equiv 0$ is the only possibility)

Assume $f \in C([0,1])$ satisfies the hypothesis. By linearity of the integral,
for every polynomial
$$p(x) = \sum_{k=0}^{N} a_k x^k,$$
we have
$$\int_0^1 f(x)\,p(x)\,dx = \sum_{k=0}^{N} a_k \int_0^1 f(x)\,x^k\,dx = \sum_{k=
0}^{N} a_k \cdot 0 = 0. \tag{1}$$

By the **Weierstrass approximation theorem**, there exists a sequence of polynom
ials $\{p_m\}_{m=1}^{\infty}$ converging **uniformly** to $f$ on $[0,1]$:
$$\|p_m - f\|_{\infty} \to 0 \quad\text{as } m \to \infty.$$

From (1), with $p = p_m$,
$$\int_0^1 f(x)\,p_m(x)\,dx = 0 \quad\text{for every } m. \tag{2}$$

Now consider
$$\int_0^1 f(x)^2\,dx = \int_0^1 f(x)\bigl(f(x) - p_m(x)\bigr)\,dx + \int_0^1 f(
x)\,p_m(x)\,dx.$$

The second term vanishes by (2). For the first term, since $f$ is continuous on
the compact interval $[0,1]$, it is bounded: $|f(x)| \le M$ for some $M \ge 0$.
Hence
$$\left|\int_0^1 f(x)\bigl(f(x) - p_m(x)\bigr)\,dx\right| \le M\,\|f - p_m\|_{\i
nfty} \cdot 1 \to 0 \quad\text{as } m \to \infty.$$

Therefore
$$\int_0^1 f(x)^2\,dx = \lim_{m\to\infty}\left[\int_0^1 f(x)\bigl(f(x)-p_m(x)\bi
gr)\,dx + 0\right] = 0. \tag{3}$$

Since $f$ is continuous and $f(x)^2 \ge 0$ for all $x \in [0,1]$, the identity (
3) forces
$$f(x)^2 = 0 \quad\text{for all } x \in [0,1],$$
and consequently
$$f(x) = 0 \quad\text{for all } x \in [0,1].$$

(Indeed, if $f(x_0)^2 > 0$ at some point $x_0$, continuity of $f^2$ would make $
f^2$ strictly positive on a neighbourhood of $x_0$, giving a strictly positive i
ntegral — contradicting (3).)

### Sufficiency ($f \equiv 0$ works)

If $f \equiv 0$, then $\int_0^1 f(x)\,x^n\,dx = \int_0^1 0\,dx = 0$ for every $n
 \ge 0$, so the condition is trivially satisfied.

---

**Conclusion.** The unique real-valued continuous function on $[0,1]$ satisfying
 $\int_0^1 f(x)\,x^n\,dx = 0$ for all $n = 0,1,2,\dots$ is

$$\boxed{f \equiv 0.}$$
