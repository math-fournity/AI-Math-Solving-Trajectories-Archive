## Solution

ructions; no solution, hint, or formalization is leaked.

Let $c = f(0)$.

**Step 1 — Surjectivity.** Set $x = 0$ in
$$f\bigl(xf(x)+f(x)f(y)+y-1\bigr)=f\bigl(xf(x)+xy\bigr)+y-1.$$
We get
$$f\bigl(c\,f(y)+y-1\bigr)=c+y-1 \qquad \text{for all } y\in\mathbb R. \tag{1}$$
The right-hand side $c+y-1$ ranges over all of $\mathbb R$ as $y$ varies, so $f$
 is **surjective**.

**Step 2 — A useful root.** Since $f$ is surjective, there exists $a\in\mathbb R
$ with $f(a)=0$.

Set $x=a$ in the original equation. Using $f(a)=0$:
- LHS: $f\bigl(a\cdot 0+0\cdot f(y)+y-1\bigr)=f(y-1)$.
- RHS: $f\bigl(a\cdot 0+a\,y\bigr)+y-1=f(ay)+y-1$.

Hence
$$f(y-1)=f(ay)+y-1 \qquad \text{for all } y. \tag{2}$$

**Step 3 — $f(0)=0$.** Put $y=1$ in (2):
$$f(0)=f(a)+0=0.$$
So $c=f(0)=0$.

**Step 4 — $f$ is the identity.** Substituting $c=0$ back into (1):
$$f\bigl(0\cdot f(y)+y-1\bigr)=0+y-1,$$
i.e.
$$f(y-1)=y-1 \qquad \text{for all } y\in\mathbb R.$$
As $y$ ranges over $\mathbb R$, the quantity $t=y-1$ ranges over all of $\mathbb
 R$, so
$$f(t)=t \qquad \text{for all } t\in\mathbb R.$$

**Step 5 — Verification.** With $f(x)=x$:
- LHS $= f\bigl(x^{2}+xy+y-1\bigr)=x^{2}+xy+y-1$.
- RHS $= f\bigl(x^{2}+xy\bigr)+y-1=x^{2}+xy+y-1$.

Both sides agree for all $x,y\in\mathbb R$. ✓

Therefore the unique function satisfying the equation is

$$\boxed{f(x)=x}.$$
