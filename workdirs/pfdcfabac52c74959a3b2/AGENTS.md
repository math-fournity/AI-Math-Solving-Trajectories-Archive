# Problem

In the digital archives of a high-security vault, every security clearance code is represented by a four-digit identification number ranging from 1000 to 9999. To maintain system integrity, a code is deemed "Valid" only if it satisfies two specific criteria related to the number 27:

First, the four-digit identification number itself must be a multiple of 27. 

Second, the sum of the four individual digits that make up the identification number must also be a multiple of 27.

For context, the three-digit legacy code 999 is Valid because 999 is divisible by 27 and its digit sum (9+9+9=27) is divisible by 27. Similarly, the four-digit code 5778 is Valid because it is divisible by 27 and its digit sum (5+7+7+8=27) is divisible by 27.

How many four-digit identification numbers in the range 1000 to 9999 are Valid?
