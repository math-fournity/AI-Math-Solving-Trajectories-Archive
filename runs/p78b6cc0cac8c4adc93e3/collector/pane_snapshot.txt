# Solution

**Claim:** Yes, such a form exists. The form $q(X,Y,Z,W) = X^2 + Y^2 + Z^2 + W^2
$ (with $a = b = c = d = 1$, all 2-adic units) is anisotropic over $\mathbb{Z}_2
$.

---

## Proof

Set $a = b = c = d = 1$. Each coefficient is a 2-adic unit since $2 \nmid 1$. We
 show that $q(x,y,z,w) = x^2 + y^2 + z^2 + w^2 = 0$ with $(x,y,z,w) \in \mathbb{
Z}_2^4$ forces $x = y = z = w = 0$.

**Key fact.** For any 2-adic unit $u \in \mathbb{Z}_2^*$, we have $u^2 \equiv 1
\pmod{8}$.

*Proof of key fact.* Since $u$ is odd, $u \equiv 1, 3, 5,$ or $7 \pmod{8}$. Squa
ring gives $1, 9 \equiv 1, 25 \equiv 1, 49 \equiv 1 \pmod{8}$ respectively. ∎

**Main argument.** Suppose for contradiction that $x^2 + y^2 + z^2 + w^2 = 0$ wi
th $(x,y,z,w) \neq (0,0,0,0)$.

Let $k = \min\bigl(v_2(x),\, v_2(y),\, v_2(z),\, v_2(w)\bigr)$, where $v_2$ is t
he 2-adic valuation ($v_2(0) = \infty$). Since not all entries are zero, $k < \i
nfty$. Write $x = 2^k x'$, $y = 2^k y'$, $z = 2^k z'$, $w = 2^k w'$. Dividing th
e equation by $4^k$ yields
$$x'^2 + y'^2 + z'^2 + w'^2 = 0,$$
where at least one of $x', y', z', w'$ is a 2-adic unit (i.e., $\min v_2 = 0$).

Reduce modulo 2: each $x'^2 \bmod 2$ is $0$ if $x'$ is even, $1$ if $x'$ is odd.
 For the sum to be $\equiv 0 \pmod{2}$, an **even** number of the four entries m
ust be odd. Since at least one is a unit (odd), the number of odd entries is $2$
 or $4$.

**Case 1: Exactly 2 entries are odd.** Without loss, say $x', y'$ are odd and $z
', w'$ are even. By the key fact, $x'^2 \equiv 1 \pmod{8}$ and $y'^2 \equiv 1 \p
mod{8}$, so $x'^2 + y'^2 \equiv 2 \pmod{8}$. Since $z', w'$ are even, $z'^2 + w'
^2 \equiv 0 \pmod{4}$. Therefore
$$x'^2 + y'^2 + z'^2 + w'^2 \equiv 2 \pmod{4},$$
so $v_2\!\left(x'^2 + y'^2 + z'^2 + w'^2\right) = 1 < \infty$, meaning the sum i
s **not zero**. Contradiction.

**Case 2: All 4 entries are odd.** By the key fact, each square is $\equiv 1 \pm
od{8}$, so
$$x'^2 + y'^2 + z'^2 + w'^2 \equiv 4 \pmod{8},$$
giving $v_2 = 2 < \infty$, so the sum is **not zero**. Contradiction.

Both cases yield a contradiction, so no non-trivial zero exists. Hence $q = X^2
+ Y^2 + Z^2 + W^2$ is **anisotropic** over $\mathbb{Z}_2$, with all coefficients
 being 2-adic units. $\blacksquare$

**Remark.** This aligns with the general theory: $\langle 1,1,1,1\rangle = \lang

mathbb{Q}_2$ because the Hilbert symbol $(-1,-1)_2 = -1$ (equivalently, $x^2 + y
^2 = -1$ has no solution in $\mathbb{Q}_2$, since $-1 \equiv 7 \pmod{8}$ is not
a sum of two squares mod 8). The u-invariant of $\mathbb{Q}_2$ being 4 confirms
that 4 is the maximal dimension for anisotropic forms, and this form realizes th
at maximum with unit coefficients.
