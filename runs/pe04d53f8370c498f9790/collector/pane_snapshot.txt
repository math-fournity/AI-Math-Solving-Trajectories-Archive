## Solution

**Answer: $C = \dfrac{1}{h}$.**

### Setup

Let $Q_n = \prod_{i=1}^{n}(1-a_i)$ with $Q_0 = 1$, so that $P_n := \prod_{i=1}^{
n}(1-a_i)^h = Q_n^h$. The sum is
$$S = \sum_{n=1}^{\infty} a_n\, Q_n^h.$$
Since $Q_n = Q_{n-1}(1-a_n)$, we have $Q_n \le Q_{n-1}$, and the sequence $\{Q_n
\}$ is non-increasing with $Q_n \in [0,1]$.

### Upper Bound: $S \le 1/h$

We claim that for each $n$,
$$a_n\, Q_n^h \;\le\; \frac{Q_{n-1}^h - Q_n^h}{h}. \tag{$\star$}$$

**Proof of ($\star$):** Since $Q_n = Q_{n-1}(1-a_n)$, dividing both sides by $Q_
{n-1}^h > 0$ (the case $Q_{n-1}=0$ is trivial), ($\star$) is equivalent to
$$a_n(1-a_n)^h \;\le\; \frac{1-(1-a_n)^h}{h}.$$
Setting $u = 1-a_n \in [0,1]$, this becomes
$$h(1-u)\,u^h \;\le\; 1 - u^h \quad\Longleftrightarrow\quad g(u) := (h+1)u^h - h
\,u^{h+1} \;\le\; 1.$$
Now $g(0)=0$, $g(1)=(h+1)-h=1$, and
$$g'(u) = h(h+1)u^{h-1}(1-u) \ge 0 \quad\text{for } u\in[0,1].$$
So $g$ is non-decreasing on $[0,1]$ with $g(1)=1$, hence $g(u)\le 1$ for all $u\
in[0,1]$. This proves ($\star$).

**Telescoping:** Summing ($\star$) over $n=1,2,\dots$:
$$S = \sum_{n=1}^{\infty} a_n\, Q_n^h \;\le\; \sum_{n=1}^{\infty} \frac{Q_{n-1}^
h - Q_n^h}{h} = \frac{Q_0^h - \lim_{n\to\infty} Q_n^h}{h} = \frac{1 - Q_\infty^h
}{h} \;\le\; \frac{1}{h}.$$

### Sharpness: $S$ can be made arbitrarily close to $1/h$

Fix any $\varepsilon > 0$. Choose a small $\delta > 0$ and set $a_n = \delta$ fo
r $n = 1, \dots, N$, with $N$ chosen so that $N\delta \to \infty$. Then
$$S = \sum_{n=1}^{N} \delta\,(1-\delta)^{hn} = \delta\,(1-\delta)^h\,\frac{1-(1-
\delta)^{hN}}{1-(1-\delta)^h}.$$
As $\delta \to 0^+$, by Taylor expansion $1-(1-\delta)^h = h\delta + O(\delta^2)
$, so
$$\frac{\delta\,(1-\delta)^h}{1-(1-\delta)^h} \;\longrightarrow\; \frac{1}{h}.$$
Choosing $N$ so that $(1-\delta)^{hN} \to 0$ (i.e., $N\delta \to \infty$), we ge
t $S \to 1/h$. Thus for any $\varepsilon>0$ there exists a sequence with $S > 1/
h - \varepsilon$.

### Conclusion

The best (smallest) constant is
$$\boxed{C = \frac{1}{h}}.$$
