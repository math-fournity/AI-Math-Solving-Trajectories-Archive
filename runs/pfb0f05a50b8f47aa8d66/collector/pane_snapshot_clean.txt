## Answer

The question concerns the characteristic function $\chi_{\mathbb{R}\setminus\mat
hbb{Q}}$, which equals $1$ on every irrational and $0$ on every rational. The an
swer depends on the domain, but on the natural domain $\mathbb{R}$, **no**, it i
s not Lebesgue integrable.

### Proof

**Definition.** A measurable function $f$ is *Lebesgue integrable* (on a measure
 space $(X,\mu)$) if $\int_X |f|\,d\mu < \infty$.

**Measurability.** The set $\mathbb{Q}$ is countable, hence a Borel set, so $\ma
thbb{R}\setminus\mathbb{Q}$ is Borel and therefore Lebesgue measurable. Thus $\c
hi_{\mathbb{R}\setminus\mathbb{Q}}$ is a measurable function.

**Case 1: Domain $\mathbb{R}$ (the natural interpretation).** For a nonnegative
characteristic function,
$$
\int_{\mathbb{R}} \chi_{\mathbb{R}\setminus\mathbb{Q}}\,d\mu = \mu(\mathbb{R}\se
tminus\mathbb{Q}).
$$
Since $\mathbb{Q}$ is countable, $\mu(\mathbb{Q})=0$. By countable additivity an
d the fact that $\mathbb{R}=\bigcup_{n\in\mathbb{Z}}[n,n+1)$,
$$
\mu(\mathbb{R}\setminus\mathbb{Q}) = \mu(\mathbb{R})-\mu(\mathbb{Q}) = \infty -
0 = \infty.
$$
Therefore $\int_{\mathbb{R}}|\chi_{\mathbb{R}\setminus\mathbb{Q}}|\,d\mu = \inft
y$, and $\chi_{\mathbb{R}\setminus\mathbb{Q}}$ is **not** Lebesgue integrable on
 $\mathbb{R}$.

**Case 2: Domain a bounded interval $[a,b]$ (for completeness).** On any finite-
measure set $E$,
$$
\int_E \chi_{\mathbb{R}\setminus\mathbb{Q}}\,d\mu = \mu\big(E\cap(\mathbb{R}\set
minus\mathbb{Q})\big) = \mu(E)-\mu(E\cap\mathbb{Q}) = \mu(E)-0 = \mu(E) < \infty
.
$$
So restricted to $[a,b]$, the function *is* Lebesgue integrable, with integral $
b-a$.

**Conclusion.** Taking the characteristic function on its natural domain $\mathb
b{R}$, the integral is infinite, so it is **not Lebesgue integrable**. (It is, h
owever, locally integrable on every bounded interval.)
