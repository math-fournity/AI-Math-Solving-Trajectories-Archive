## Solution

**The polynomial.** We have $P(x) = \sum_{j=1}^{2014} j^2 x^{2014-j}$. Reindexin
g with $k = 2014-j$ (so $j = 2014-k$, $k$ from $2013$ down to $0$):

$$P(x) = \sum_{k=0}^{2013} (2014-k)^2 x^k.$$

The leading coefficient (at $x^{2013}$) is $(2014-2013)^2 = 1$, so $P$ is **moni
c** of degree $n = 2013$. Writing $P(x) = x^n + c_1 x^{n-1} + \cdots + c_n$, the
 coefficient of $x^{n-j}$ is $(j+1)^2$, hence

$$c_j = (j+1)^2, \qquad j = 1,\dots,n.$$

**Generating function for power sums.** Let $p_k = \sum_{i=1}^{n} a_i^k$. Settin
g $C(t) = 1 + c_1 t + \cdots + c_n t^n$ (so $P(x) = x^n C(1/x)$), the standard i
dentity from $P'(x)/P(x) = \sum_i \frac{1}{x-a_i}$ gives

$$\sum_{k\ge 1} p_k\, t^k = -\,\frac{t\,C'(t)}{C(t)}.$$

**Key observation.** For $k \le n$, the coefficient of $t^k$ in $-tC'(t)/C(t)$ d
epends only on $c_1,\dots,c_k$ (since $1/C(t)$ up to degree $k$ uses only $c_1,\
dots,c_k$). Therefore, for computing $p_1,\dots,p_n$ we may replace $C(t)$ by an
y series agreeing with it through degree $n$. The coefficients $c_j = (j+1)^2$ a
re exactly those of the generating function

$$\widetilde{C}(t) = \sum_{j\ge 0}(j+1)^2 t^j = \frac{1+t}{(1-t)^3}.$$

Since $\widetilde{C}$ agrees with $C$ through degree $n=2013$, we get $p_k = [t^
k]\bigl(-t\widetilde{C}'(t)/\widetilde{C}(t)\bigr)$ for all $1\le k\le n$.

**Computing the generating function.** Taking logarithmic derivatives:

$$\frac{\widetilde{C}'(t)}{\widetilde{C}(t)} = \frac{d}{dt}\Bigl[\ln(1+t) - 3\ln
(1-t)\Bigr] = \frac{1}{1+t} + \frac{3}{1-t}.$$

Hence

$$\sum_{k\ge 1} p_k\, t^k = -t\left(\frac{1}{1+t}+\frac{3}{1-t}\right) = \frac{-
t}{1+t} - \frac{3t}{1-t}.$$

Expanding each term:

$$\frac{-t}{1+t} = \sum_{k\ge 1} (-1)^k\, t^k, \qquad \frac{-3t}{1-t} = \sum_{k\
ge 1} (-3)\, t^k.$$

Therefore

$$p_k = (-1)^k - 3, \qquad 1 \le k \le 2013.$$

**Verification.** $p_1 = -1-3 = -4 = -c_1$ ✓. $p_2 = 1-3 = -2$; Newton gives $p_
2 + 4(-4) + 2\cdot 9 = 0 \Rightarrow p_2 = -2$ ✓. $p_3 = -1-3=-4$; Newton gives
$p_3 + 4(-2)+9(-4)+3\cdot16 = 0 \Rightarrow p_3 = -4$ ✓.

**Applying to $k = 997$.** Since $997 \le 2013$,

$$p_{997} = (-1)^{997} - 3 = -1 - 3 = -4.$$

**Reduction mod 997.** The $a_i$ are roots of a monic integer polynomial, so the
y are algebraic integers; their power sum $p_{997}$ is an ordinary integer, equa
l to $-4$. The remainder when $-4$ is divided by $997$ is

$$997 - 4 = \boxed{993}.$$
