# Problem

A specialized automated fabrication line is constructing a 400-meter long micro-circuit trace. The machine functions by placing conductive solder dots along a straight 1D path. However, the positioning mechanism is imprecise; each time the machine triggers, a single dot is placed at a location chosen uniformly at random anywhere between the start (0 meters) and the finish (400 meters) of the trace.

The circuit is considered functional only when there is a continuous path of connectivity from the start point to the finish point. Connectivity is achieved between two dots (or between a dot and a boundary) if the distance between them is no more than 4 meters. The fabrication process continues, adding one dot at a time, until this continuous path is established.

Let $N$ be the expected number of solder dots required to complete the connection across the 400-meter span. If $x$ is the value of $E[N]$, calculate and report $\lfloor 10^3x \rfloor$.
