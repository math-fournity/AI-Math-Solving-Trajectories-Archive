## Proof

**Setup.** Let triangle $ABC$ have $BC = a = 15$, $CA = b = 10$, $AB = c$ (unkno
wn). Place $B = (0,0)$, $C = (15,0)$. Then
$$A = (x_A, y_A), \quad x_A = \frac{c^2 + 125}{30}, \quad y_A = \sqrt{c^2 - x_A^
2}.$$

**Angle bisector directions.** The internal bisector from $B$ has direction $\ma
thbf{u}_B = (x_A + c,\; y_A)$, and from $C$ has direction $\mathbf{u}_C = (x_A -
 25,\; y_A)$.

**Locating $D$ and $E$.** Since $E \in r$ (bisector from $B$) and $D \in s$ (bis
ector from $C$):
$$E = \lambda\,(x_A+c,\; y_A), \qquad D = (15,0) + \mu\,(x_A-25,\; y_A).$$

**Using $AD \parallel BE$.** Since $BE$ lies along $\mathbf{u}_B$, requiring $AD
 \parallel \mathbf{u}_B$ gives
$$\frac{15 - x_A + \mu(x_A - 25)}{x_A + c} = \mu - 1.$$
Simplifying: $15 - 25\mu = c(\mu - 1)$, hence $\mu = \dfrac{15+c}{25+c}$.

**Using $AE \parallel CD$.** Since $CD$ lies along $\mathbf{u}_C$, requiring $AE
 \parallel \mathbf{u}_C$ gives
$$\frac{\lambda(x_A+c) - x_A}{x_A - 25} = \lambda - 1.$$
Simplifying: $\lambda c = -25\lambda + 25$, hence $\lambda = \dfrac{25}{25+c}$.

**Finding $F = BD \cap CE$.** Parametrize $F = s\,D$ on line $BD$ and $F = C + t
(E-C)$ on line $CE$. From the $y$-components: $s\mu = t\lambda$. Substituting in
to the $x$-equation and using $\mu(25+c)=15+c$:
$$s\bigl[15 - \mu(25+c)\bigr] = 15 - \frac{15s\mu}{\lambda} \;\Longrightarrow\;
-sc = 15 - \frac{15s\mu}{\lambda}.$$
Since $\mu/\lambda = (15+c)/25$:
$$s\!\left(\frac{15(15+c)}{25} - c\right) = 15 \;\Longrightarrow\; s\cdot\frac{4
5-2c}{5} = 15 \;\Longrightarrow\; s = \frac{75}{45-2c}.$$

Therefore
$$F = \frac{75}{45-2c}\,D = \left(\frac{75\bigl[x_A(15+c)-10c\bigr]}{(45-2c)(25+
c)},\;\frac{75(15+c)\,y_A}{(45-2c)(25+c)}\right).$$

**The incenter.** $I = \dfrac{aA + bB + cC}{a+b+c} = \dfrac{15A + cC}{25+c}$, so
$$I = \left(\frac{15(x_A+c)}{25+c},\;\frac{15\,y_A}{25+c}\right).$$

**Collinearity of $A$, $I$, $F$.** Compute:
$$I - A = \left(\frac{15c - x_A(10+c)}{25+c},\;\frac{-y_A(10+c)}{25+c}\right),$$
$$F - A = \left(\frac{2c\bigl[x_A(40+c)-375\bigr]}{(45-2c)(25+c)},\;\frac{2c\,y_
A(40+c)}{(45-2c)(25+c)}\right),$$
where we used $75(15+c) - (45-2c)(25+c) = 2c(40+c)$ and $75(15+c)x_A - x_A(45-2c
)(25+c) = 2c\,x_A(40+c)$.

The cross-product condition $(I-A)\times(F-A) = 0$ becomes (after canceling comm
on factors $y_A$, $2c$, $(45-2c)$, $(25+c)^2$):
$$(40+c)\bigl[15c - x_A(10+c)\bigr] = -(10+c)\bigl[x_A(40+c) - 375\bigr].$$

Expanding both sides, the terms involving $x_A(40+c)(10+c)$ cancel identically,
leaving:
$$15c(40+c) = 375(10+c).$$

Dividing by $15$:
$$c(40+c) = 25(10+c) \;\Longrightarrow\; c^2 + 40c = 250 + 25c \;\Longrightarrow
\; c^2 + 15c - 250 = 0.$$

**Solving:**
$$c = \frac{-15 \pm \sqrt{225 + 1000}}{2} = \frac{-15 \pm 35}{2}.$$

Since $c > 0$, we get $c = \dfrac{20}{2} = 10$.

**Verification.** With $c = 10$: the triangle is isosceles ($AB = AC = 10$, $BC
= 15$), $x_A = 7.5$. By symmetry $D$ and $E$ are mirror images across the axis $
x = 7.5$, so $F$ lies on this axis. The incenter $I$ also lies on this axis, and
 $A = (7.5,\, 5\sqrt{7}/2)$ lies on it too. Hence $A$, $I$, $F$ are collinear. ✓

$$\boxed{c = 10}$$
