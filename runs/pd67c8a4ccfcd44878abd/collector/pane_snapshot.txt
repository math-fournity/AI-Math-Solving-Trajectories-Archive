## Solution

The condition $|a_1 - a_2| = |a_2 - a_3|$ splits into two cases:

- **Case 1 (AP):** $a_1 - a_2 = a_2 - a_3$, i.e., $a_1 + a_3 = 2a_2$.
- **Case 2 ($a_1 = a_3$):** $a_1 - a_2 = -(a_2 - a_3)$, i.e., $a_1 = a_3$.

**Overlap:** both hold iff $a_1 = a_2 = a_3$, giving $n+1$ triples.

By inclusion–exclusion:
$$f(n) = |\text{Case 1}| + |\text{Case 2}| - |\text{overlap}|.$$

### Case 2

$a_1 = a_3$ with $a_2$ free: $(n+1)^2$ triples.

### Case 1

For fixed $a_2 \in \{0,\dots,n\}$, we need $a_3 = 2a_2 - a_1 \in \{0,\dots,n\}$,
 so $a_1 \in [\max(0,\, 2a_2-n),\ \min(n,\, 2a_2)]$.

- If $a_2 \le \lfloor n/2\rfloor$: count $= 2a_2 + 1$.
- If $a_2 \ge \lceil n/2\rceil$: count $= 2(n - a_2) + 1$.

### Combining

$$f(n) = |\text{Case 1}| + (n+1)^2 - (n+1) = |\text{Case 1}| + n(n+1).$$

### $n = 10$

Counts for $a_2 = 0,\dots,10$: $1,3,5,7,9,11,9,7,5,3,1$, sum $= 25+11+25 = 61$.

$$f(10) = 61 + 10\cdot 11 = 61 + 110 = 171.$$

### $n = 11$

Counts for $a_2 = 0,\dots,11$: $1,3,5,7,9,11,11,9,7,5,3,1$, sum $= 36+36 = 72$.

$$f(11) = 72 + 11\cdot 12 = 72 + 132 = 204.$$

### Verification (small case)

For $n=2$: Case 1 sum $= 1+3+1 = 5$; $f(2) = 5 + 2\cdot 3 = 11$. Direct enumerat
ion of all 27 triples over $\{0,1,2\}$ confirms exactly 11 satisfy the condition
. ✓

### Final answer

$$f(10) + f(11) = 171 + 204 = \boxed{375}.$$
