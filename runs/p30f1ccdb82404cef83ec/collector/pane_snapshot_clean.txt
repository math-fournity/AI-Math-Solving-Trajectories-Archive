## Proof

**Step 1: Reindex as a double sum.** Since $A(k)/k = \sum_{\substack{d \text{ od
d}\\ d\mid k\\ d^2<2k}} \frac{1}{k}$, the partial sums are
$$S_N = \sum_{k=1}^N (-1)^{k-1}\frac{A(k)}{k} = \sum_{\substack{d\text{ odd},\,
m\ge 1\\ dm\le N\\ m>d/2}} \frac{(-1)^{m-1}}{dm},$$
using $k=dm$ and $(-1)^{dm-1}=(-1)^{m-1}$ (since $d$ is odd). The condition $d^2
<2k=2dm$ is $m>d/2$.

**Step 2: Identify the limit via an absolutely convergent iterated sum.** Define
$$S^* = \sum_{\substack{d\text{ odd}\\d\ge 1}} \frac{1}{d}\sum_{m>\,d/2}\frac{(-
1)^{m-1}}{m}.$$
The inner tail $T_{\lceil d/2\rceil}:=\sum_{m>d/2}(-1)^{m-1}/m$ satisfies $|T_{\
lceil d/2\rceil}|\le 2/d$ (alternating-series bound), so the outer summand is $O
(1/d^2)$: **$S^*$ converges absolutely.**

**Step 3: $S_N\to S^*$.** The discrepancy is
$$S^*-S_N = \sum_{d\text{ odd}}\frac{1}{d}\!\!\sum_{m>\max(d/2,\,N/d)}\frac{(-1)
^{m-1}}{m}.$$
- For $d\le\sqrt{2N}$: $N/d\ge d/2$, tail $\le d/N$, contribution $\le 1/N$ each
, total $O(\sqrt{N}/N)=O(N^{-1/2})$.
- For $d>\sqrt{2N}$: tail $\le 2/d$, contribution $\le 2/d^2$, total $O(N^{-1/2}
)$.

So $|S^*-S_N|=O(N^{-1/2})\to 0$. **The original series converges to $S^*$.**

**Step 4: Convert to a single sum.** Writing $d=2j+1$ ($j\ge 0$), the condition
$m>d/2$ becomes $m\ge j+1$:
$$S^* = \sum_{j=0}^\infty \frac{1}{2j+1}\sum_{m=j+1}^\infty \frac{(-1)^{m-1}}{m}
.$$
Swapping (now justified by absolute convergence of the $j$-sum):
$$S^* = \sum_{m=1}^\infty \frac{(-1)^{m-1}}{m}\sum_{j=0}^{m-1}\frac{1}{2j+1} = \
sum_{m=1}^\infty (-1)^{m-1}\frac{H_m^{\text{odd}}}{m},$$
where $H_m^{\text{odd}}=1+\frac13+\cdots+\frac1{2m-1}$.

**Step 5: Use $H_m^{\text{odd}}=H_{2m}-\tfrac12 H_m$.** Since $H_{2m}=H_m^{\text
{odd}}+\tfrac12 H_m$,
$$S^* = \underbrace{\sum_{m=1}^\infty (-1)^{m-1}\frac{H_{2m}}{m}}_{=:I} \;-\; \f
rac12\underbrace{\sum_{m=1}^\infty (-1)^{m-1}\frac{H_m}{m}}_{=:J}.$$

**Step 6: Evaluate $J$.** The standard identity (from $\sum H_n x^n = -\ln(1-x)/
(1-x)$, integrating) gives
$$J = \frac{\pi^2}{12}-\frac{(\ln 2)^2}{2}.$$

**Step 7: Evaluate $I$ via an integral.** Using $H_{2m}=\int_0^1\frac{1-t^{2m}}{
1-t}\,dt$ and $\sum_{m\ge1}(-1)^{m-1}\frac{1-t^{2m}}{m}=\ln 2-\ln(1+t^2)$:
$$I=\int_0^1\frac{\ln 2-\ln(1+t^2)}{1-t}\,dt.$$
Substituting $u=1-t$:
$$I=-\int_0^1\frac{\ln(1-u+u^2/2)}{u}\,du.$$
Now set $u=\sqrt{2}\,v$, so $1-u+u^2/2 = 1-\sqrt2\,v+v^2 = 1-2v\cos\frac\pi4+v^2
$:
$$I=-\int_0^{1/\sqrt2}\frac{\ln(1-2v\cos(\pi/4)+v^2)}{v}\,dv.$$
Using $\ln(1-2v\cos\theta+v^2)=-2\sum_{n\ge1}\frac{v^n\cos(n\theta)}{n}$ and int
egrating termwise:
$$I=2\sum_{n=1}^\infty\frac{(1/\sqrt2)^n\cos(n\pi/4)}{n^2}=2\,\mathrm{Re}\,\math
rm{Li}_2\!\Big(\tfrac{1+i}{2}\Big),$$
since $e^{i\pi/4}/\sqrt2=(1+i)/2$.

**Step 8: Dilogarithm identity.** Euler's reflection $\mathrm{Li}_2(z)+\mathrm{L
i}_2(1-z)=\frac{\pi^2}{6}-\log z\,\log(1-z)$ with $z=\frac{1+i}{2}$, $1-z=\bar z
$, gives
$$2\,\mathrm{Re}\,\mathrm{Li}_2(z)=\frac{\pi^2}{6}-|\log z|^2=\frac{\pi^2}{6}-\f
rac{(\ln2)^2}{4}-\frac{\pi^2}{16}=\frac{5\pi^2}{48}-\frac{(\ln2)^2}{4}.$$
So $I=\dfrac{5\pi^2}{48}-\dfrac{(\ln2)^2}{4}$.

**Step 9: Combine.**
$$S^*=I-\frac12 J=\left(\frac{5\pi^2}{48}-\frac{(\ln2)^2}{4}\right)-\frac12\left
(\frac{\pi^2}{12}-\frac{(\ln2)^2}{2}\right)=\frac{5\pi^2}{48}-\frac{\pi^2}{24}=\
frac{5\pi^2-2\pi^2}{48}=\frac{3\pi^2}{48}.$$

The $(\ln 2)^2$ terms cancel exactly, yielding

$$\boxed{\sum_{k=1}^\infty (-1)^{k-1}\frac{A(k)}{k}=\dfrac{\pi^2}{16}}.$$
