**Proof.** Define the integral operator
$$(T_K f)(y) = \int_X K(x,y)\,f(x)\,d\mu_X(x),$$
and set
$$g(y) := \int_X K(x,y)\,d\mu_X(x).$$

We prove both directions and the norm identity.

---

**($\Leftarrow$) Suppose $g \in L^q(Y)$.**

Let $f \in L^\infty(X)$. Since $K \geq 0$ and $|f(x)| \leq \|f\|_{L^\infty(X)}$
for $\mu_X$-a.e. $x$,
$$|(T_K f)(y)| \leq \int_X K(x,y)\,|f(x)|\,d\mu_X(x) \leq \|f\|_{L^\infty(X)}\in
t_X K(x,y)\,d\mu_X(x) = \|f\|_{L^\infty(X)}\,g(y).$$

Taking the $L^q(Y)$ norm (and using that $g \geq 0$ so $|g| = g$):
$$\|T_K f\|_{L^q(Y)} \leq \|f\|_{L^\infty(X)}\,\|g\|_{L^q(Y)}.$$

Hence $T_K$ is of strong type $(\infty, q)$ with
$$\|T_K\|_{L^\infty(X)\to L^q(Y)} \leq \|g\|_{L^q(Y)}.$$

---

**($\Rightarrow$) Suppose $T_K$ is of strong type $(\infty, q)$, i.e. $M := \|T_
K\|_{L^\infty\to L^q} < \infty$.**

Take $f \equiv \mathbf{1}$, the constant function equal to $1$. Then $\|\mathbf{
1}\|_{L^\infty(X)} = 1$, and
$$(T_K \mathbf{1})(y) = \int_X K(x,y)\cdot 1\,d\mu_X(x) = g(y).$$

Therefore
$$\|g\|_{L^q(Y)} = \|T_K \mathbf{1}\|_{L^q(Y)} \leq M\,\|\mathbf{1}\|_{L^\infty(
X)} = M = \|T_K\|_{L^\infty\to L^q}.$$

This shows $g \in L^q(Y)$ and $\|g\|_{L^q} \leq \|T_K\|_{L^\infty\to L^q}$.

---

**Combining both directions:**
$$\|T_K\|_{L^\infty(X)\to L^q(Y)} \leq \|g\|_{L^q(Y)} \leq \|T_K\|_{L^\infty(X)\
to L^q(Y)},$$
so equality holds:
$$\|T_K\|_{L^\infty(X)\to L^q(Y)} = \left\|\int_X K(x,y)\,d\mu_X(x)\right\|_{L^q
_y(Y)}.$$

This completes the proof for all $1 \leq q \leq \infty$ (the argument uses only
the definition of the operator norm and the constant test function $\mathbf{1}$,
 which is valid in $L^\infty$ regardless of whether $q$ is finite or infinite).
$\blacksquare$
