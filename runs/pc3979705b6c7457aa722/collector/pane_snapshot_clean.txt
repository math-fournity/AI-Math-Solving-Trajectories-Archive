## Solution

We compute $I = \int_{[0,1]} x^2 \, d\mu_F$, where $\mu_F$ is the Lebesgue–Stiel
tjes measure of the Cantor function $F$. This is the **Cantor measure**, support
ed on the Cantor set $C$.

### Step 1: Symmetry gives $\int x\, d\mu_F = \tfrac12$

The property $F(1-x)=1-F(x)$ means $\mu_F$ is invariant under $x\mapsto 1-x$. Su
bstituting in $I$:
$$I = \int (1-x)^2\, d\mu_F = \int(1-2x+x^2)\,d\mu_F = 1 - 2\!\int x\,d\mu_F + I
.$$
Hence $\int x\,d\mu_F = \tfrac12$ (and $\mu_F([0,1])=1$ since $F(1)=1$).

### Step 2: Self-similarity of $\mu_F$

From $F(x/3)=F(x)/2$: for $t\in[0,1/3]$, $\mu_F([0,t])=F(t)=F(3t)/2=\tfrac12\mu_
F([0,3t])$. So the map $\phi(y)=y/3$ satisfies $\phi_*\mu_F = \tfrac12\mu_F$.

By symmetry, the map $\psi(y)=(y+2)/3$ onto $[2/3,1]$ also satisfies $\psi_*\mu_
F=\tfrac12\mu_F$. (Check: $F(2/3)=1-F(1/3)=1/2$, and $F((y+2)/3)=1-F((1-y)/3)=1-
F(1-y)/2=1/2+F(y)/2$, so $\mu_F([2/3,(y+2)/3])=F(y)/2$.)

The Cantor set splits as $C = C_1\cup C_2$ with $C_1=\phi(C)$, $C_2=\psi(C)$, an
d $\mu_F(C_1)=\mu_F(C_2)=1/2$; the complement has $\mu_F$-measure $0$.

### Step 3: Functional equation for $I$

Split the integral:
$$I = \int_{C_1} x^2\,d\mu_F + \int_{C_2} x^2\,d\mu_F.$$

**Left part** ($x=\phi(y)=y/3$, pushforward $\tfrac12\mu_F$):
$$\int_{C_1} x^2\,d\mu_F = \int (y/3)^2\cdot\tfrac12\,d\mu_F(y) = \tfrac{1}{18}I
.$$

**Right part** ($x=\psi(y)=(y+2)/3$, pushforward $\tfrac12\mu_F$):
$$\int_{C_2} x^2\,d\mu_F = \tfrac12\int\!\left(\tfrac{y+2}{3}\right)^2 d\mu_F(y)
 = \tfrac{1}{18}\int(y^2+4y+4)\,d\mu_F = \tfrac{1}{18}\!\left(I + 4\cdot\tfrac12
 + 4\right) = \tfrac{1}{18}(I+6).$$

Adding:
$$I = \tfrac{1}{18}I + \tfrac{1}{18}(I+6) = \tfrac{1}{9}I + \tfrac{1}{3}.$$

### Step 4: Solve

$$\tfrac{8}{9}I = \tfrac{1}{3}\quad\Longrightarrow\quad I = \frac{9}{8}\cdot\fra
c{1}{3} = \frac{3}{8}.$$

$$\boxed{\int_{[0,1]} x^2\,d\mu_F = \dfrac{3}{8}}$$
