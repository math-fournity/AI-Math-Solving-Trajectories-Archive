## Proof

**Setup.** Let $X$ be an uncountable set with $|X| = \kappa$, and let $B = B(X,\
mathbb{R})$ denote the set of all bounded real-valued functions on $X$. We deter
mine the cardinality of
$$\mathcal{I} = \{g : X \to B \mid g \text{ is injective}\}.$$

---

**Step 1: Compute $|B|$.**

Every bounded $f:X\to\mathbb{R}$ has image in $[-n,n]$ for some $n\in\mathbb{N}$
, so
$$B = \bigcup_{n=1}^{\infty}\,[-n,n]^X.$$
Each $|[-n,n]^X| = \mathfrak{c}^{\kappa}$, hence $|B| \le \aleph_0\cdot\mathfrak
{c}^{\kappa} = \mathfrak{c}^{\kappa}$.

Conversely $[0,1]^X \subseteq B$, so $|B| \ge \mathfrak{c}^{\kappa}$. Therefore
$$|B| = \mathfrak{c}^{\kappa}.$$

---

**Step 2: Injections exist.**

Since $\mathfrak{c}\ge 2$, we have $|B|=\mathfrak{c}^{\kappa}\ge 2^{\kappa}>\kap
pa$ by Cantor's theorem. Thus $\kappa < |B|$, so injective maps $X\to B$ exist.

---

**Step 3: Count the injections.**

*Upper bound.* $\mathcal{I}\subseteq B^X$, so
$$|\mathcal{I}| \le |B|^{|X|} = (\mathfrak{c}^{\kappa})^{\kappa} = \mathfrak{c}^
{\kappa\cdot\kappa} = \mathfrak{c}^{\kappa}.$$

*Lower bound.* We use the standard fact: for infinite cardinals $\kappa\le\lambd
a$, the number of injections from a set of size $\kappa$ into a set of size $\la
mbda$ is $\lambda^{\kappa}$.

Here $\lambda = |B| = \mathfrak{c}^{\kappa}$ and $\kappa\le\lambda$. Since $\lam
bda$ is infinite and $\kappa\le\lambda$, we can write $B \cong A\times C$ with $
|A|=\kappa$ and $|C|=\lambda$ (using $\kappa\cdot\lambda=\lambda$). Fix a biject
ion $\phi:X\to A$. For each function $h:X\to C$, the map
$$x \longmapsto (\phi(x),\, h(x))$$
is injective (the first coordinate is injective). Distinct $h$ give distinct inj
ections, yielding $\lambda^{\kappa} = (\mathfrak{c}^{\kappa})^{\kappa} = \mathfr
ak{c}^{\kappa}$ injections. Hence
$$|\mathcal{I}| \ge \mathfrak{c}^{\kappa}.$$

---

**Conclusion.** Combining both bounds,
$$|\mathcal{I}| = \mathfrak{c}^{\kappa} = |B(X,\mathbb{R})|.$$

The cardinality of the set of all injective functions from an uncountable set $X
$ (with $|X|=\kappa$) to the set of bounded real-valued functions on $X$ equals
$\mathfrak{c}^{\,|X|}$, which is exactly the cardinality of the set of bounded f
unctions itself.

In particular, for $X=\mathbb{R}$ ($\kappa=\mathfrak{c}$), the answer is $\mathf
rak{c}^{\mathfrak{c}} = 2^{\mathfrak{c}}$.
