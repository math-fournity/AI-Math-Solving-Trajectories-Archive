## Proof

**Symmetry.** The substitution $k \mapsto n-k$ shows $T_n$ is symmetric. Splitti
ng at the midpoint:

$$T_n = 2\sum_{k=1}^{\lfloor(n-1)/2\rfloor} \frac{1}{k^m(n-k)^m} + \mathbb{1}_{2
\mid n}\cdot\frac{1}{(n/2)^{2m}}.$$

The middle term equals $\frac{2^{2m}}{n^{2m}} = o(n^{-m})$ since $2m > m$, so it
 is negligible compared to $n^{-m}$.

**Key asymptotic.** I claim $n^m T_n \to 2\zeta(m)$ as $n\to\infty$.

It suffices to show $n^m \sum_{k=1}^{\lfloor n/2\rfloor} \frac{1}{k^m(n-k)^m} \t
o \zeta(m)$. Rewrite:

$$n^m \sum_{k=1}^{\lfloor n/2\rfloor} \frac{1}{k^m(n-k)^m} = \sum_{k=1}^{\lfloor
 n/2\rfloor} \frac{1}{k^m(1-k/n)^m}.$$

Define $f_n(k) = \frac{1}{k^m(1-k/n)^m}$ for $1 \le k \le \lfloor n/2\rfloor$ an
d $f_n(k)=0$ otherwise. Then:

- **Pointwise limit:** For each fixed $k$, once $n > 2k$ we have $f_n(k) = \frac
{1}{k^m(1-k/n)^m} \to \frac{1}{k^m}$ as $n\to\infty$.

- **Dominating function:** For $k \le n/2$, we have $1 - k/n \ge 1/2$, so $f_n(k

c{2^m}{k^m} = 2^m\zeta(m)$ converges.

By the Dominated Convergence Theorem (for series):

$$\sum_{k=1}^{\infty} f_n(k) \to \sum_{k=1}^{\infty} \frac{1}{k^m} = \zeta(m).$$

(The difference between $\lfloor n/2\rfloor$ and $\lfloor(n-1)/2\rfloor$ affects
 at most one term, which is negligible.) Therefore:

$$n^m T_n \to 2\zeta(m) = 2\zeta(2019) > 0.$$

**Determining $a$.** We have $S_n(a) = n^{a-m}\cdot(n^m T_n)$ where $n^m T_n \to

- If $a > 2019$: $n^{a-2019} \to \infty$, so $S_n(a) \to +\infty$.

- If $a = 2019$: $n^{0} = 1$, so $S_n(2019) \to 2\zeta(2019) > 0$.

**Conclusion.** The unique value of $a$ for which $\{S_n(a)\}_{n\ge 2}$ converge

$$\boxed{a = 2019},$$

with the limit being $2\zeta(2019)$.
