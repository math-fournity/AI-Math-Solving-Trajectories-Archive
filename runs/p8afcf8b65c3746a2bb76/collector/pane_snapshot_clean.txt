## Solution

**Restatement.** For each integer $n$ from 1 to 255, let $r(n)$ denote the numbe
r of maximal runs (blocks) of consecutive 1s in the standard binary representati
on of $n$ (without leading zeros). We seek $\sum_{n=1}^{255} r(n)$.

**Key observation.** A maximal run of 1s begins exactly at a position where a 0
is immediately followed by a 1. If we prepend a single 0 to the left of the stan
dard binary representation, then $r(n)$ equals the number of $0\to 1$ transition
s in the resulting string.

**Reduction to 8-bit strings.** Every $n\in\{1,\dots,255\}$ has a standard binar
y representation of length $\le 8$. Writing it as an 8-bit string $b_7b_6b_5b_4b
_3b_2b_1b_0$ (padding with leading zeros) and then prepending one more 0 above $
b_7$, the count $r(n)$ equals:
- the number of $0\to1$ transitions among the 7 adjacent pairs $(b_{i+1},b_i)$ f
or $i=0,\dots,6$, **plus**
- $1$ if $b_7=1$ (the transition from the prepended 0 to $b_7$).

The number $n=0$ (string $00000000$) contributes $0$ to every term, so summing o
ver all 256 eight-bit strings $00000000,\dots,11111111$ gives the same total as
summing over $n=1,\dots,255$.

**Counting the within-string transitions.** For each adjacent pair $(b_{i+1},b_i
)$, $i=0,\dots,6$, across all $256$ strings the pair takes each of $(00,01,10,11
)$ exactly $64$ times. The $0\to1$ pattern occurs $64$ times per pair. With $7$
pairs:

$$\text{within-string }0\to1\text{ transitions} = 7 \times 64 = 448.$$

**Counting the top transition.** The prepended-0-to-$b_7$ transition contributes
 $1$ exactly when $b_7=1$, which holds for $128$ of the $256$ strings:

$$\text{top transition} = 128.$$

**Total.**

$$\sum_{n=1}^{255} r(n) = 448 + 128 = \boxed{576}.$$

**Verification of the example.** $107 = 1101011_2$ has runs $11$, $1$, $11$, so
$r(107)=3$, matching the problem statement. As a further check on the method wit
h 3-bit numbers $1,\dots,7$: the formula gives $2\times 2 + 4 = 8$, and direct c
ounting gives $r(1)+\cdots+r(7)=1+1+1+1+2+1+1=8$. ✓
