## Proof

**Yes, it is always possible to find such sets $K_1$ and $K$.**

The key tool is the **inner regularity of the Lebesgue measure**: for every Lebe
sgue measurable set $A \subset \mathbb{R}$ and every $\varepsilon > 0$, there ex
ists a compact set $C \subset A$ such that
$$\lambda(C) \geq \lambda(A) - \varepsilon,$$
where we interpret $\lambda(A) - \varepsilon$ in the extended sense (if $\lambda
(A) = \infty$, then $\lambda(C)$ can be made arbitrarily large, in particular po
sitive).

---

### Construction

Since $\lambda(A) > 0$:

- **If $\lambda(A) < \infty$:** take $\varepsilon = \tfrac{1}{2}\lambda(A) > 0$.
 Inner regularity gives a compact $C \subset A$ with $\lambda(C) \geq \lambda(A)
 - \tfrac{1}{2}\lambda(A) = \tfrac{1}{2}\lambda(A) > 0$.

- **If $\lambda(A) = \infty$:** take $\varepsilon = 1$. Inner regularity gives a
 compact $C \subset A$ with $\lambda(C) \geq \infty - 1 = \infty$; more precisel
y, since $A = \bigcup_{n} (A \cap [-n,n])$ and $\lambda(A) = \infty$, some $A \c
ap [-n,n]$ has positive finite measure, and applying inner regularity to that bo
unded piece yields a compact $C \subset A$ with $\lambda(C) > 0$.

In either case we obtain a **compact** set $C \subset A$ with $\lambda(C) > 0$.

Now set
$$K_1 := C, \qquad K := C.$$

### Verification of all six conditions

| Condition | Check |
|---|---|
| $K_1 \subset A$ | $K_1 = C \subset A$ ✓ |
| $K \subset \mathbb{R}$ | $K = C \subset \mathbb{R}$ ✓ |
| $K_1 \subset K$ | $K_1 = C = K$ ✓ |
| $K$ is compact | $C$ is compact by construction ✓ |
| $\lambda(K_1) = \lambda(K)$ | $\lambda(C) = \lambda(C)$ ✓ |
| $\lambda(K_1) > 0$ | $\lambda(C) > 0$ by choice of $\varepsilon$ ✓ |

All conditions are satisfied.

---

### Remark (if proper inclusion $K_1 \subsetneq K$ is required)

If the symbol "$\subset$" is interpreted as **proper** inclusion, the constructi
on is easily adjusted. Since $C$ is compact it is closed and bounded, so $\mathb
b{R} \setminus C \neq \emptyset$. Pick any point $p \in \mathbb{R} \setminus C$
and set
$$K_1 := C, \qquad K := C \cup \{p\}.$$
Then $K$ is closed (finite union of closed sets) and bounded (adding a single po
int to a bounded set preserves boundedness), hence **compact**; $K_1 \subsetneq
K$; and
$$\lambda(K) = \lambda(C) + \lambda(\{p\}) = \lambda(C) + 0 = \lambda(K_1) > 0.$
$
All six conditions remain satisfied with strict inclusion.

---

**Conclusion:** For every measurable set $A \subset \mathbb{R}$ with $\lambda(A)
 > 0$, such sets $K_1$ and $K$ always exist. The answer is **yes**.
