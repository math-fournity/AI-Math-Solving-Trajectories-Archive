# Problem

In a specialized research network, there are 99 distinct high-security servers. Every single pair of servers is linked by a direct data cable. Among all the links in the network, exactly 99 cables are "duplex" lines, meaning data can flow freely in both directions between the two connected servers. Every other cable in the network is a "simplex" line, meaning it is strictly one-way, allowing data to flow in only one specific direction between the two servers.

A cluster of 4 servers is defined as "seamlessly integrated" if, using only the 6 cables that link those 4 specific servers, a data packet can be sent from any server in the cluster to any other server in the cluster.

Based on this network architecture, determine the maximum possible number of such "seamlessly integrated" clusters of 4 servers.
