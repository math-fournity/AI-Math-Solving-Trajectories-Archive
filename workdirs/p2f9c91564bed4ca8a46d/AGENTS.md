# Problem

In a futuristic laboratory, a lead scientist is testing a modular encryption algorithm centered on a specific "Generation Constant," a positive integer denoted as $g$. 

The laboratory subjects this constant to a series of stress tests using every possible "Prime Frequency" $p$, where $p$ represents any odd prime number. For the algorithm to be deemed stable, the scientist must ensure that for every single one of these frequencies $p$, there exists at least one "Activation Cycle" (a positive integer $n$) that satisfies two specific synchronization conditions:

1. The value of $g^n - n^2$ must be perfectly divisible by the prime frequency $p$.
2. The value of $g^{n+1} - (n+1)^2$ must also be perfectly divisible by the same prime frequency $p$.

Determine all possible values of the Generation Constant $g$ that allow the algorithm to remain stable for every odd prime $p$.
