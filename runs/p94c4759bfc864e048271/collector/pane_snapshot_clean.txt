## Solution

**Setting up the column-by-column addition.**

The $k$-th term has $k$ sixes. In the units column (column 0), every one of the
100 terms contributes 6. In column $j$ (the $10^j$ place), only terms with $k \g
eq j+1$ contribute, giving $100 - j$ contributions of 6. So the raw column sum i
s:

$$S_j = 6(100 - j), \quad j = 0, 1, \dots, 99.$$

**Computing digits and carries.** Let $c_j$ be the carry into column $j$ ($c_0 =
 0$). Then digit $d_j = (S_j + c_j) \bmod 10$ and $c_{j+1} = \lfloor(S_j + c_j)/
10\rfloor$.

| Column $j$ | $S_j$ | $c_j$ | Total | $d_j$ | $c_{j+1}$ |
|---|---|---|---|---|---|
| 0 | 600 | 0 | 600 | 0 | 60 |
| 1 | 594 | 60 | 654 | 4 | 65 |
| 2 | 588 | 65 | 653 | 3 | 65 |
| 3 | 582 | 65 | 647 | **7** | 64 |
| 4 | 576 | 64 | 640 | 0 | 64 |
| 5 | 570 | 64 | 634 | 4 | 63 |
| 6 | 564 | 63 | 627 | **7** | 62 |
| 7 | 558 | 62 | 620 | 0 | 62 |
| 8 | 552 | 62 | 614 | 4 | 61 |
| 9 | 546 | 61 | 607 | **7** | 60 |

**Identifying the repeating pattern.** From column 3 onward, the digits cycle as
 **7, 0, 4**. I verify this holds in general. At the "$7$" column $j = 3 + 3m$ (
$m = 0, 1, 2, \dots$), the carry is $c = 65 - 2m$, giving:

$$\text{total} = 6(97 - 3m) + (65 - 2m) = 647 - 20m, \quad d = 7, \quad c_{\text
{out}} = 64 - 2m.$$

At the "$0$" column $j = 4 + 3m$: total $= 640 - 20m$, digit $0$, carry $64 - 2m
$. ✓

At the "$4$" column $j = 5 + 3m$: total $= 634 - 20m$, digit $4$, carry $63 - 2m
$. ✓

Since $647 - 20m \equiv 7 \pmod{10}$, $640 - 20m \equiv 0 \pmod{10}$, and $634 -
 20m \equiv 4 \pmod{10}$ for all $m$, the pattern is exact.

**Checking the pattern survives to the end.** The last column is $j = 99 = 3 + 3
 \cdot 32$, so $m = 32$:

$$c_{99} = 65 - 64 = 1, \quad \text{total} = 6(100 - 99) + 1 = 7, \quad d_{99} =
 7, \quad c_{100} = 0.$$

The pattern holds through the final column with no leftover carry. ✓

**Counting the 7s.** The digit 7 appears at columns $j = 3, 6, 9, \ldots, 99$ (i
.e., $j \equiv 0 \pmod{3}$, $3 \leq j \leq 99$). The number of such columns is:

$$\frac{99 - 3}{3} + 1 = 32 + 1 = 33.$$

Columns 0, 1, 2 have digits 0, 4, 3 — no 7s. The number $N$ reads (most signific
ant first):

$$\underbrace{740\;740\;740\;\cdots\;740}_{32 \text{ blocks}}\;7340,$$

containing 32 sevens from the repeating blocks plus 1 from the trailing 7340.

$$\boxed{33}$$
