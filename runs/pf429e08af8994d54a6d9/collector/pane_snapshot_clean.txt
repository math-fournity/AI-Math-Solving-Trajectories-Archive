## Algorithm $P$

**Goal.** Given a regular expression $R$ over the alphabet $\Sigma=\{0,1\}$, dec
ide whether $L(R)=\Sigma^{*}$ and return $1$ or $0$ accordingly, halting in fini
te time.

### Key observation

$L(R)=\Sigma^{*}$ iff the complement $\overline{L(R)}$ is empty. Since regular l
anguages are closed under complement and emptiness is decidable for DFAs, it suf
fices to build a complete DFA for $L(R)$ and check that **every reachable state
is accepting** (equivalently, that no string is ever rejected).

---

### Step 1 — Parse $R$ into a syntax tree

A regular expression over $\Sigma=\{0,1\}$ is built inductively from the atoms $
\emptyset,\,\varepsilon,\,0,\,1$ and the operators union $+$, concatenation $\cd
ot$, and Kleene star $*$. Parse $R$ into an abstract syntax tree $T$. Parsing a
finite string terminates in finite time.

### Step 2 — Convert $T$ to an $\varepsilon$-NFA $N$ (Thompson's construction)

Apply Thompson's construction recursively:

- $\emptyset \mapsto$ two-state NFA, no accepting path.
- $\varepsilon \mapsto$ two-state NFA with a single $\varepsilon$-transition.
- $a\in\{0,1\} \mapsto$ two-state NFA with a single $a$-transition.
- $A+B \mapsto$ new start with $\varepsilon$-arrows to the starts of $A,B$; new
accept with $\varepsilon$-arrows from the accepts of $A,B$.
- $A\cdot B \mapsto$ connect accept of $A$ to start of $B$ by an $\varepsilon$-a
rrow.
- $A^{*} \mapsto$ new start/accept with $\varepsilon$-loops through $A$ and a di
rect $\varepsilon$-arrow start$\to$accept.

Each rule adds a constant number of states, so $N$ has $O(|R|)$ states and $O(|R
|)$ transitions — a **finite** structure.

### Step 3 — Subset construction: $\varepsilon$-NFA $\to$ DFA $D'$

Let $N=(Q_N,\Sigma,\delta_N,q_0^N,F_N)$. Define the DFA $D'=(Q',\Sigma,\delta',q
_0',F')$:

- $q_0' = \varepsilon\text{-closure}(\{q_0^N\})$.
- For a state $S\subseteq Q_N$ and $a\in\Sigma$: $\delta'(S,a)=\varepsilon\text{
-closure}\!\left(\bigcup_{p\in S}\delta_N(p,a)\right)$.
- $F'=\{S\in Q' : S\cap F_N\neq\emptyset\}$.

Compute $Q'$ by a worklist algorithm: start with $q_0'$, repeatedly expand by ap
plying $\delta'$ to unprocessed states until no new state appears. Since $Q'\sub
seteq 2^{Q_N}$ and $|Q_N|$ is finite, $|Q'|\le 2^{|Q_N|}$ is **finite**, so the
worklist terminates. The transition function $\delta'$ produced this way may be
**partial** (some $(S,a)$ pairs never arise).

### Step 4 — Complete $D'$ to a total DFA $D$

Introduce a fresh trap state $q_\bot\notin Q'$, declared **non-accepting**. Defi
ne $D=(Q,\Sigma,\delta,q_0,F)$ where $Q=Q'\cup\{q_\bot\}$, $F=F'$, and

$$
\delta(S,a)=\begin{cases}\delta'(S,a) & \text{if }\delta'(S,a)\text{ is defined,
}\\ q_\bot & \text{otherwise,}\end{cases}\qquad \delta(q_\bot,a)=q_\bot.
$$

Now $\delta$ is **total**. By construction $L(D)=L(D')=L(N)=L(R)$, and $q_\bot$
is the only state that can be reached precisely by strings not in $L(R)$ (once e
ntered, it is never left).

### Step 5 — Compute reachable states

Run BFS/DFS from $q_0$ in $D$ using $\delta$. Since $Q$ is finite, this visits a
 finite set $\text{Reach}\subseteq Q$ and terminates.

### Step 6 — Decision

$$
P(R)=\begin{cases}1 & \text{if }\text{Reach}\subseteq F\ \text{(every reachable
state is accepting)},\\ 0 & \text{otherwise.}\end{cases}
$$

---

### Correctness

**Claim.** $L(R)=\Sigma^{*}\iff \text{Reach}\subseteq F$.

*Proof.* $D$ is a complete DFA with $L(D)=L(R)$. A string $w\in\Sigma^{*}$ is ac
cepted by $D$ iff the state $\hat\delta(q_0,w)$ reached by processing $w$ lies i
n $F$. Hence

$$
L(R)=\Sigma^{*}\iff \forall w\in\Sigma^{*},\ \hat\delta(q_0,w)\in F \iff \text{e
very reachable state is in }F \iff \text{Reach}\subseteq F.
$$

The second equivalence holds because the set of reachable states is exactly $\{\
hat\delta(q_0,w):w\in\Sigma^{*}\}$ (totality of $\delta$ guarantees every $w$ yi
elds a state). $\square$

Concretely, if some reachable state $S\notin F$ exists, let $w$ be any string le
ading $q_0$ to $S$; then $w\notin L(R)$, so $L(R)\neq\Sigma^{*}$ and $P$ correct
ly returns $0$. If every reachable state is accepting, every string is accepted,
 so $L(R)=\Sigma^{*}$ and $P$ correctly returns $1$.

### Termination

Each step manipulates only finite objects and uses only finite loops:

1. Parsing — finite input.
2. Thompson — linear in $|R|$.
3. Subset construction — at most $2^{|Q_N|}$ states, finite worklist.
4. Completion — one extra state, constant work per missing transition.
5. Reachability — BFS over a finite graph.
6. Membership test $\text{Reach}\subseteq F$ — finite comparison.

Therefore $P$ halts in a finite number of steps for every input regular expressi
on $R$.
