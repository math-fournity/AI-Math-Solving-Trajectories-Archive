# Problem

In a specialized laboratory, a team of cryptographers is testing a security protocol based on a cyclic keypad with 37 distinct keys, labeled $\{0, 1, 2, \ldots, 36\}$. Due to a mechanical constraint, the system considers two keys $x$ and $y$ to be a "valid pair" for a target transmission $k$ if they satisfy the modular equation $ax + y \equiv k \pmod{37}$, where $a$ is a fixed "coupling coefficient" and all calculations are performed using modulo 37 arithmetic.

The head engineer is searching for specific values of the coupling coefficient $a$ (where $a$ is an integer such that $1 \le a \le 37$) that allow for maximum efficiency. Specifically, she needs to find the values of $a$ for which it is possible to select a subset $X$ of exactly 6 integers from the keypad such that every possible non-zero signal $k \in \{1, 2, \ldots, 36\}$ can be generated by at least one pair of integers $x, y$ chosen from the set $X$.

Find the number of such positive integers $a$ in the range $1 \le a \le 37$ that make the existence of such a 6-element set $X$ possible.
