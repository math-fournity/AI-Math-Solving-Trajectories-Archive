## Solution

**Answer:** The unique function satisfying all conditions is $f(z) = e^z$.

### Proof

**Existence.** The function $f(z) = e^z$ is entire (holomorphic on all of $\math
bb{C}$), hence holomorphic on $\Omega$ and continuous on $\bar{\Omega}$. Moreove
r, $f(z) = e^z$ for all $z \in \partial\Omega$ by definition. Thus $f(z)=e^z$ sa
tisfies all three conditions.

**Uniqueness.** Suppose $f, g : \bar{\Omega} \to \mathbb{C}$ both satisfy the th
ree conditions: each is continuous on $\bar{\Omega}$, holomorphic on $\Omega$, a
nd agrees with $e^z$ on $\partial\Omega$.

Set $h = f - g$. Then:
- $h$ is continuous on $\bar{\Omega}$,
- $h$ is holomorphic on $\Omega$,
- $h(z) = 0$ for all $z \in \partial\Omega$.

Assume $\Omega$ is a bounded domain (the standard setting for a problem involvin
g $\bar\Omega$ and boundary values). By the **maximum modulus principle**, since
 $h$ is holomorphic on $\Omega$ and continuous on $\bar{\Omega}$, the function $
|h|$ attains its maximum on $\partial\Omega$:

$$\max_{z \in \bar{\Omega}} |h(z)| = \max_{z \in \partial\Omega} |h(z)|.$$

Since $h|_{\partial\Omega} = 0$, we have $\max_{\partial\Omega}|h| = 0$, and the
refore

$$|h(z)| \le 0 \quad \text{for all } z \in \bar{\Omega},$$

which forces $h \equiv 0$ on $\bar{\Omega}$. Hence $f = g$ on $\bar{\Omega}$.

Since $g(z) = e^z$ is one valid solution, every valid solution must equal $e^z$.
 Therefore $f(z) = e^z$ is the **unique** function satisfying all the given cond
itions. $\blacksquare$
