## Solution

**Factor the modulus.** $5379 = 3 \times 1793 = 3 \times 11 \times 163$, where $
163$ is prime. By CRT I compute $16^{16^{16}} \bmod 3,\ 11,\ 163$ separately.

---

**Mod 3.** $16 \equiv 1 \pmod 3$, so $16^{16^{16}} \equiv 1 \pmod 3$.

**Mod 11.** $16 \equiv 5 \pmod{11}$. The order of $5$ mod $11$ is $5$ (since $5^
5 = 3125 \equiv 1$). Since $16 \equiv 1 \pmod 5$, we get $16^{16} \equiv 1 \pmod
 5$, hence
$$16^{16^{16}} \equiv 5^1 \equiv 5 \pmod{11}.$$

**Mod 163.** $\varphi(163) = 162 = 2\cdot 3^4$. I determine the order of $16$ mo
d $163$ by successive squaring/multiplying:

| $k$ | $16^k \bmod 163$ |
|-----|------------------|
| 1   | 16 |
| 2   | 93 |
| 3   | 21 |
| 6   | 115 |
| 9   | 133 |
| 18  | 85 |
| 27  | 58 |
| 54  | 104 |
| 81  | **1** |

Since $16^1, 16^3, 16^9, 16^{27} \not\equiv 1$ but $16^{81}\equiv 1$, the order
is exactly **81**.

So I need the exponent $16^{16} \bmod 81$:
$$16^2 \equiv 13,\quad 16^4 \equiv 7,\quad 16^8 \equiv 49,\quad 16^{16} \equiv 4
9^2 = 2401 \equiv 52 \pmod{81}.$$

Thus $16^{16^{16}} \equiv 16^{52} \pmod{163}$. Computing $16^{52} = 16^{32}\cdot
 16^{16}\cdot 16^{4}$:
$$16^4 \equiv 10,\quad 16^{16}\equiv 57,\quad 16^{32}\equiv 152 \pmod{163}.$$
$$152\times 57 = 8664 \equiv 25,\qquad 25\times 10 = 250 \equiv 87 \pmod{163}.$$

So $16^{16^{16}} \equiv 87 \pmod{163}$.

---

**Combine via CRT.** We need $x$ with
$$x\equiv 1\pmod 3,\quad x\equiv 5\pmod{11},\quad x\equiv 87\pmod{163}.$$

From the first two: $x = 3k+1$ and $3k+1\equiv 5\pmod{11}$, i.e. $k\equiv 5\pmod
{11}$, giving $x = 33m + 16$.

Then $33m + 16 \equiv 87 \pmod{163}$, so $33m \equiv 71 \pmod{163}$. Via the ext
ended Euclidean algorithm, $33^{-1}\equiv 84\pmod{163}$ (check: $33\times 84 = 2
772 = 17\times 163 + 1$). Hence
$$m \equiv 84\times 71 = 5964 \equiv 96 \pmod{163}.$$

So $m = 163n + 96$ and
$$x = 33(163n+96)+16 = 5379n + 3184.$$

**Verification.** $3184 \bmod 3 = 1$ ✓; $3184 \bmod 11 = 5$ ✓; $3184 \bmod 163 =
 87$ ✓.

---

The remainder when $16^{16^{16}}$ is divided by $5379$ is $\boxed{3184}$.
