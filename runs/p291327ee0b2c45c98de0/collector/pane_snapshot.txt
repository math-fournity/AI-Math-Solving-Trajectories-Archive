## Proof

**Answer: Yes**, such a function can have infinitely many fixed points.

**Construction.** Consider
$$f(z) = z + \sin z.$$
This function is entire (hence meromorphic on all of $\mathbb{C}$ with **zero**
poles, which certainly satisfies "at most one pole").

**Fixed-point analysis.** A fixed point satisfies $f(z) = z$, i.e.,
$$z + \sin z = z \iff \sin z = 0.$$
The zeros of $\sin z$ are exactly $z = n\pi$ for every $n \in \mathbb{Z}$. This
is an infinite set, so $f$ has infinitely many fixed points.

**Remark (the case of exactly one pole).** The same conclusion holds even if we
require exactly one pole. Take
$$g(z) = z + \frac{\sin z}{z - 1}.$$
Since $\sin(1) \neq 0$, the function $\frac{\sin z}{z-1}$ has a genuine (simple)
 pole at $z = 1$ and is otherwise holomorphic, so $g$ is meromorphic on $\mathbb
{C}$ with exactly one pole. Its fixed points satisfy $\frac{\sin z}{z-1} = 0$, i
.e., $\sin z = 0$ with $z \neq 1$. Since $1 \neq n\pi$ for any integer $n$, ever
y $z = n\pi$ is a fixed point, again giving infinitely many.

**Key point.** The equation $f(z) - z = 0$ involves the meromorphic function $h(
z) = f(z) - z$, which has at most one pole. A meromorphic function on $\mathbb{C
}$ with finitely many poles can perfectly well have infinitely many isolated zer
os (as $\sin z$ demonstrates), so there is no theorem forcing $h \equiv 0$ or li
miting the number of fixed points to be finite.
