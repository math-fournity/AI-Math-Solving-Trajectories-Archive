## Proof

**Yes, such functions exist.** We construct an explicit example.

**Setup.** Let the parameter $t$ range over $(0,1)$ equipped with Lebesgue measu
re, and let $x \in [0,1]$. Define

$$f(x, t) = \frac{1}{t}, \qquad x \in [0,1],\; t \in (0,1).$$

**Step 1: Absolute continuity in $x$.** For each fixed $t \in (0,1)$, the functi
on $x \mapsto f(x,t) = 1/t$ is constant in $x$. Constant functions are absolutel
y continuous on $[0,1]$. Hence $f(\cdot, t)$ is absolutely continuous in $x$ for
 every fixed $t$.

**Step 2: The supremum is not dominated by any integrable function.** We compute

$$\sup_{x \in [0,1]} |f(x, t)| = \frac{1}{t}.$$

Suppose, for contradiction, that there exists a Lebesgue-integrable function $B
: (0,1) \to \mathbb{R}$ such that

$$\frac{1}{t} < B(t) \quad \text{a.e. on } (0,1).$$

Then $B(t) > 1/t$ a.e., so

$$\int_0^1 B(t)\, dt \;\geq\; \int_0^1 \frac{1}{t}\, dt \;=\; +\infty,$$

where the last equality holds because $\int_\varepsilon^1 \frac{1}{t}\,dt = -\ln
\varepsilon \to +\infty$ as $\varepsilon \to 0^+$. This contradicts the assumpti
on that $B$ is integrable.

Therefore no integrable function $B(t)$ can satisfy $\sup_x |f(x,t)| < B(t)$ alm
ost everywhere.

**Conclusion.** The function $f(x,t) = 1/t$ on $[0,1] \times (0,1)$ is absolutel
y continuous in $x$ for each fixed $t$, yet $\sup_x |f(x,t)| = 1/t$ is not domin
ated a.e. by any integrable function of $t$. This demonstrates that absolute con
tinuity in the $x$-variable alone imposes no integrability constraint on the $t$
-dependence of $\sup_x |f|$, so such functions do exist.
