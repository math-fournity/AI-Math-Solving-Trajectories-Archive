## Solution

The differential equation is
$$y'' + \frac{1}{y}(y')^2 - y' = 0, \qquad y(0)=0,\; y(1)=1.$$

**Step 1: Reduce order.** Treat $y$ as the independent variable. Set $p = y'$, s
o $y'' = p\,\dfrac{dp}{dy}$. Substituting:

$$p\,\frac{dp}{dy} + \frac{p^{2}}{y} - p = 0.$$

For $p \neq 0$ (the non-constant branch, which is forced by $y(1)=1 \neq 0$), di
vide by $p$:

$$\frac{dp}{dy} + \frac{1}{y}\,p = 1.$$

**Step 2: Solve the linear ODE for $p(y)$.** The integrating factor is $e^{\int
(1/y)\,dy} = y$, giving

$$\frac{d}{dy}(yp) = y \;\;\Longrightarrow\;\; yp = \frac{y^{2}}{2} + C \;\;\Lon
grightarrow\;\; p = \frac{y}{2} + \frac{C}{y}.$$

**Step 3: Separate variables.** With $y' = \dfrac{y}{2} + \dfrac{C}{y} = \dfrac{
y^{2}+2C}{2y}$,

$$\frac{2y\,dy}{y^{2}+2C} = dx.$$

Let $u = y^{2}$, $du = 2y\,dy$; then $\dfrac{du}{u+2C} = dx$, so

$$\ln|u+2C| = x + D \;\;\Longrightarrow\;\; y^{2} + 2C = Ae^{x}.$$

Renaming the constant $B = -2C$, the general solution is

$$\boxed{y^{2} = Ae^{x} + B}.$$

**Step 4: Apply boundary conditions.** From $y(0)=0$: $0 = A + B$, so $B = -A$ a
nd $y^{2} = A(e^{x}-1)$. From $y(1)=1$: $1 = A(e-1)$, so $A = \dfrac{1}{e-1}$. H
ence

$$y^{2} = \frac{e^{x}-1}{e-1}.$$

On $(0,1]$ the right side is positive, so taking the positive root (consistent w
ith $y(1)=1>0$):

$$y(x) = \sqrt{\frac{e^{x}-1}{e-1}}.$$

**Step 5: Verify the ODE.** Let $k = \tfrac{1}{e-1}$, so $y = \sqrt{k(e^{x}-1)}$
. Then $y' = \dfrac{ke^{x}}{2y}$ and

$$y'' = \frac{d}{dx}\!\left(\frac{ke^{x}}{2y}\right) = \frac{ke^{x}}{2y} - \frac
{ke^{x}\,y'}{2y^{2}} = y' - \frac{ke^{x}\,y'}{2y^{2}}.$$

Also $(y')^{2}/y = \dfrac{k^{2}e^{2x}}{4y^{3}}$, and using $y'y = \tfrac{ke^{x}}
{2}$,

$$\frac{ke^{x}\,y'}{2y^{2}} = \frac{ke^{x}\,y'y}{2y^{3}} = \frac{k^{2}e^{2x}}{4y
^{3}}.$$

Therefore
$$y'' - y' + \frac{(y')^{2}}{y} = -\frac{k^{2}e^{2x}}{4y^{3}} + \frac{k^{2}e^{2x
}}{4y^{3}} = 0. \;\checkmark$$

Both boundary conditions hold by construction.

**Step 6: Compute $y(2)$.**

$$y(2) = \sqrt{\frac{e^{2}-1}{e-1}} = \sqrt{\frac{(e-1)(e+1)}{e-1}} = \sqrt{e+1}
.$$

## Answer

$$\boxed{y(2) = \sqrt{e+1}}$$
