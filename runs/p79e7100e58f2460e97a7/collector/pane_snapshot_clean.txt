# Solution: Steady-State Temperature Distribution in an Insulated Strip

## Problem Setup

We solve Laplace's equation $u_{xx} + u_{yy} = 0$ on the strip $D = \{(x,y) \mid
 -\infty < x < \infty,\; 0 < y < 1\}$ with:
- $u(x,0) = 0$ (bottom boundary, homogeneous),
- $u(x,1) = e^{-x^2/4}$ (top boundary, Gaussian data),
- $\int_{-\infty}^{\infty}\int_0^1 |u|\,dy\,dx < \infty$ (integrability).

The lateral surfaces being insulated means no heat flux through $x = \pm\infty$;
 the integrability condition enforces decay.

## Step 1 — Fourier Transform in $x$

Define the Fourier transform $\hat{u}(k,y) = \int_{-\infty}^{\infty} u(x,y)\,e^{
-ikx}\,dx$. Transforming $u_{xx}+u_{yy}=0$ gives:

$$\hat{u}_{yy} - k^2 \hat{u} = 0.$$

General solution: $\hat{u}(k,y) = A(k)\cosh(ky) + B(k)\sinh(ky)$.

**Bottom BC:** $u(x,0)=0 \Rightarrow \hat{u}(k,0)=0 \Rightarrow A(k)=0$, so $\ha
t{u}(k,y)=B(k)\sinh(ky)$.

**Top BC:** $u(x,1)=e^{-x^2/4} \Rightarrow \hat{u}(k,1)=F(k)$, where $F(k)$ is t
he Fourier transform of $e^{-x^2/4}$.

Using the standard Gaussian transform $\int_{-\infty}^{\infty} e^{-ax^2}e^{-ikx}
dx = \sqrt{\pi/a}\,e^{-k^2/(4a)}$ with $a=1/4$:

$$F(k) = 2\sqrt{\pi}\,e^{-k^2}.$$

Since $\hat{u}(k,1) = B(k)\sinh(k) = F(k)$, we get $B(k) = F(k)/\sinh(k)$, givin
g:

$$\boxed{\hat{u}(k,y) = 2\sqrt{\pi}\,e^{-k^2}\,\frac{\sinh(ky)}{\sinh(k)}.}$$

## Step 2 — Fourier Integral Representation

Inverting via $u(x,y) = \frac{1}{2\pi}\int_{-\infty}^{\infty} \hat{u}(k,y)\,e^{i
kx}\,dk$:

$$\boxed{u(x,y) = \frac{1}{\sqrt{\pi}}\int_{-\infty}^{\infty} e^{-k^2}\,\frac{\s
inh(ky)}{\sinh(k)}\,e^{ikx}\,dk.}$$

**Verification of boundary conditions:**
- $y=0$: $\sinh(0)=0 \Rightarrow u(x,0)=0$. ✓
- $y=1$: $\sinh(k)/\sinh(k)=1$, so $u(x,1)=\frac{1}{\sqrt{\pi}}\int e^{-k^2}e^{i
kx}dk = \frac{1}{\sqrt{\pi}}\cdot\sqrt{\pi}\,e^{-x^2/4} = e^{-x^2/4}$. ✓

**Integrability:** For $0\le y\le 1$, $|\sinh(ky)/\sinh(k)|\le 1$ (since $|\sinh
|$ is increasing in its argument and $|ky|\le|k|$). The function $e^{-k^2}\sinh(
ky)/\sinh(k)$ is in the Schwartz class $\mathcal{S}(\mathbb{R})$ in $k$, so its
inverse Fourier transform is also Schwartz class in $x$, hence rapidly decaying
and integrable. Thus $\int_0^1\int_{-\infty}^{\infty}|u|\,dx\,dy < \infty$. ✓

## Step 3 — Evaluation by the Convolution Method

The solution has the form $u = P_y * f$ where $f(x)=e^{-x^2/4}$ and $P_y$ is the
 Poisson kernel for the strip (the inverse Fourier transform of the transfer fun
ction $H(k,y)=\sinh(ky)/\sinh(k)$):

$$P_y(x) = \frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{\sinh(ky)}{\sinh(k)}\,e^{i
kx}\,dk.$$

Since $\sinh(ky)/\sinh(k)$ is even in $k$, only the cosine survives:

$$P_y(x) = \frac{1}{\pi}\int_0^{\infty}\frac{\sinh(ky)}{\sinh(k)}\cos(kx)\,dk.$$

**Series expansion of the kernel.** For $k>0$:

$$\frac{\sinh(ky)}{\sinh(k)} = \frac{e^{k(y-1)}-e^{-k(y+1)}}{1-e^{-2k}} = \sum_{
n=0}^{\infty}\left[e^{-k(2n+1-y)} - e^{-k(2n+1+y)}\right].$$

Termwise integration using $\int_0^\infty e^{-ak}\cos(kx)\,dk = \frac{a}{a^2+x^2
}$ yields the **closed-form Poisson kernel for the strip**:

$$\boxed{P_y(x) = \frac{1}{\pi}\sum_{n=0}^{\infty}\left[\frac{2n+1-y}{(2n+1-y)^2
+x^2} - \frac{2n+1+y}{(2n+1+y)^2+x^2}\right].}$$

The solution is the convolution:

$$u(x,y) = \int_{-\infty}^{\infty} P_y(x-t)\,e^{-t^2/4}\,dt.$$

## Step 4 — Closed-Form Evaluation via the Faddeeva Function

Each convolution integral has the form:

$$I_a(x) = \int_{-\infty}^{\infty}\frac{a}{a^2+(x-t)^2}\,e^{-t^2/4}\,dt = \int_{
-\infty}^{\infty}\frac{a}{a^2+s^2}\,e^{-(x-s)^2/4}\,ds,\quad a>0.$$

Using the representation $\frac{a}{a^2+s^2} = \frac{1}{2}\int_{-\infty}^{\infty}
e^{-a|\omega|}e^{i\omega s}\,d\omega$ and the Gaussian Fourier transform $\int e
^{i\omega s}e^{-(x-s)^2/4}ds = 2\sqrt{\pi}\,e^{-\omega^2}e^{i\omega x}$:

$$I_a(x) = \sqrt{\pi}\int_{-\infty}^{\infty}e^{-\omega^2-a|\omega|}e^{i\omega x}
\,d\omega = 2\sqrt{\pi}\int_0^{\infty}e^{-\omega^2-a\omega}\cos(\omega x)\,d\ome
ga.$$

Completing the square and using $\int_0^\infty e^{-\omega^2-z\omega}\,d\omega =
\frac{\sqrt{\pi}}{2}e^{z^2/4}\operatorname{erfc}(z/2)$ with $z = a-ix$:

$$I_a(x) = \pi\,\operatorname{Re}\!\left[e^{(a-ix)^2/4}\,\operatorname{erfc}\!\l
eft(\tfrac{a-ix}{2}\right)\right].$$

Introducing the **Faddeeva (Kramp) function** $w(z) = e^{-z^2}\operatorname{erfc
}(-iz)$, and using the identity $e^{\zeta^2}\operatorname{erfc}(\zeta) = w(i\zet
a)$ with $\zeta = (a-ix)/2$ (so $i\zeta = (x+ia)/2$):

$$I_a(x) = \pi\,\operatorname{Re}\!\left[w\!\left(\tfrac{x+ia}{2}\right)\right].
$$

Substituting into the convolution:

$$\boxed{u(x,y) = \operatorname{Re}\sum_{n=0}^{\infty}\left[w\!\left(\frac{x+i(2
n+1-y)}{2}\right) - w\!\left(\frac{x+i(2n+1+y)}{2}\right)\right],}$$

where $w(z) = e^{-z^2}\operatorname{erfc}(-iz)$ is the Faddeeva function.

**Verification via telescoping:**
- At $y=0$: each pair $w(\cdot) - w(\cdot)$ has identical arguments $(2n+1)$, so
 every term vanishes: $u(x,0)=0$. ✓
- At $y=1$: the series telescopes to $\operatorname{Re}[w(x/2) - \lim_{N\to\inft
y}w((x+i(2N+2))/2)]$. Since $w(z)\to 0$ as $\operatorname{Im}(z)\to+\infty$, and
 $\operatorname{Re}[w(x/2)] = \operatorname{Re}[e^{-x^2/4}\operatorname{erfc}(-i
x/2)] = e^{-x^2/4}\cdot\operatorname{Re}[\operatorname{erfc}(-ix/2)] = e^{-x^2/4
}\cdot 1 = e^{-x^2/4}$ (because $\operatorname{erf}(ix/2)$ is purely imaginary f
or real $x$). ✓

## Step 5 — Three-Dimensional Surface and Isotherms

The solution $u(x,y)$ defines a smooth surface over the strip $-\infty<x<\infty,
\;0<y<1$ with the following qualitative features (which can be rendered from the
 Fourier integral or Faddeeva series above):

| Feature | Description |
|---|---|
| **Peak** | Maximum value $u=1$ at $(x,y)=(0,1)$, the apex of the Gaussian boun
dary data. |
| **Bottom edge** | $u=0$ identically along $y=0$ (the surface meets the $xy$-pl
ane). |
| **Top edge** | $u=e^{-x^2/4}$ along $y=1$; a Gaussian ridge centered at $x=0$.
 |
| **Decay** | For $|x|\gg 2$, $u\to 0$ uniformly in $y$ (Gaussian decay inherite
d from boundary data). |
| **Symmetry** | $u(-x,y)=u(x,y)$ (even in $x$, since boundary data is even). |
| **Monotonicity** | For each fixed $x$, $u$ increases monotonically from $0$ at
 $y=0$ toward $e^{-x^2/4}$ at $y=1$ (maximum principle + harmonic function with
non-negative boundary data). |

**Isotherms** (level curves $u = c$, $0 < c < 1$): By symmetry and monotonicity
in $y$, each isotherm is a single smooth curve symmetric about $x=0$, connecting
 $(x_-,0^+)$ to $(x_+,0^+)$—actually arching across the strip from one side to t
he other, with its highest point (closest to $y=1$) at $x=0$. Lower isotherms ($
c$ near $0$) span very wide in $x$ and hug the bottom; higher isotherms ($c$ nea
r $1$) are small closed arcs near the peak $(0,1)$. The isotherm $c=e^{-x_0^2/4}
$ touches the top boundary at $x=\pm x_0$.

To generate the 3D surface numerically, evaluate either:
1. The **Fourier integral**: $u(x,y)=\frac{1}{\sqrt{\pi}}\int_{-\infty}^{\infty}
e^{-k^2}\frac{\sinh(ky)}{\sinh(k)}e^{ikx}dk$ (truncate at $|k|\approx 5$, since
$e^{-k^2}$ makes contributions negligible beyond), or
2. The **Faddeeva series** (converges rapidly; 5–10 terms suffice for $0<y<1$ si
nce arguments have imaginary parts $\ge 1-y > 0$).

over a grid such as $x\in[-4,4]$, $y\in[0,1]$, and plot $u(x,y)$ as a surface wi
th contour projections for the isotherms.

## Summary

| Form | Expression |

{-t^2/4}\,dt$ with $P_y$ the strip Poisson kernel (series of Cauchy/Lorentzian t

| **Closed form (Faddeeva)** | $u(x,y)=\operatorname{Re}\sum_{n=0}^{\infty}\left

ht]$ |

All three forms are equivalent and satisfy Laplace's equation, both boundary con
ditions, and the integrability condition.
