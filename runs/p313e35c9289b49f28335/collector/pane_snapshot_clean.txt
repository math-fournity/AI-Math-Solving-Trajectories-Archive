## Solution

We seek all integers $0 \le a \le 124$ with $a^3 \equiv 2 \pmod{125}$.

**Step 1: Reduce mod 5.** Cubes mod 5 are $0,1,3,2,4$ for $a \equiv 0,1,2,3,4$.
Since $a^3 \equiv 2 \pmod 5$, we need $a \equiv 3 \pmod 5$. Write $a = 3 + 5k$ w
ith $k \in \{0,1,\dots,24\}$.

**Step 2: Lift to mod 125.** Expand:
$$(3+5k)^3 = 27 + 135k + 225k^2 + 125k^3.$$
Modulo 125 this becomes $27 + 10k + 100k^2$. Setting this $\equiv 2 \pmod{125}$:
$$100k^2 + 10k + 25 \equiv 0 \pmod{125}.$$
Dividing by 5: $20k^2 + 2k + 5 \equiv 0 \pmod{25}$.

**Step 3: Reduce mod 5 again.** $20k^2 + 2k + 5 \equiv 2k \pmod 5$, so $k \equiv
 0 \pmod 5$. Write $k = 5m$, $m \in \{0,1,2,3,4\}$.

**Step 4: Substitute.** $20(25m^2) + 2(5m) + 5 = 500m^2 + 10m + 5 \equiv 10m + 5
 \pmod{25}$. We need $10m + 5 \equiv 0 \pmod{25}$, i.e. $10m \equiv 20 \pmod{25}
$, i.e. $2m \equiv 4 \pmod 5$, giving $m \equiv 2 \pmod 5$. The only value in ra
nge is $m = 2$.

**Step 5: Conclude.** $k = 10$, so $a = 3 + 50 = 53$.

**Uniqueness check.** Since $\gcd(3, \varphi(125)) = \gcd(3,100) = 1$, the cubin
g map is a bijection on units mod 125, so there is exactly one unit $a$ with $a^
3 \equiv 2 \pmod{125}$. Our found $a = 53$ is a unit, confirming uniqueness.

**Verification.** $53^3 = 148877$, and $148877 - 2 = 148875 = 125 \times 1191$.
