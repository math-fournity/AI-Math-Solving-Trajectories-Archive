## Solution

**Answer.** The polynomials satisfying the condition are:
- If $n = 1$: every polynomial $f \in \mathbb{C}[X]$.
- If $n \geq 2$: exactly the linear polynomials $f(X) = cX$ with $c \in \mathbb{
C}$.

---

### Proof

Write $f(X) = \sum_{k=0}^{d} a_k X^k$. For any matrix $A$,
$$\operatorname{Tr}(f(A)) = \sum_{k=0}^{d} a_k \operatorname{Tr}(A^k), \qquad f(
\operatorname{Tr} A) = \sum_{k=0}^{d} a_k (\operatorname{Tr} A)^k,$$
so the condition $f(\operatorname{Tr} A) = \operatorname{Tr}(f(A))$ is equivalen
t to
$$\sum_{k=0}^{d} a_k\bigl[(\operatorname{Tr} A)^k - \operatorname{Tr}(A^k)\bigr]
 = 0 \quad \text{for all } A \in M_n(\mathbb{C}). \tag{$\ast$}$$

**Step 1. Reduction to diagonal matrices.** It suffices to test $(\ast)$ on diag
onal matrices, since we will extract enough constraints from them alone. Let $A
= \operatorname{diag}(\lambda_1, \dots, \lambda_n)$. Then $\operatorname{Tr} A =
 \lambda_1 + \cdots + \lambda_n$ and $\operatorname{Tr}(A^k) = \lambda_1^k + \cd
ots + \lambda_n^k$, so $(\ast)$ becomes
$$f(\lambda_1 + \cdots + \lambda_n) = f(\lambda_1) + \cdots + f(\lambda_n) \quad
 \text{for all } \lambda_1, \dots, \lambda_n \in \mathbb{C}. \tag{$\ast\ast$}$$

**Step 2. The case $n = 1$.** Here $\operatorname{Tr} A = A$ (a scalar) and $\op
eratorname{Tr}(A^k) = A^k$, so $(\ast)$ holds identically for every polynomial.
Thus **all** $f \in \mathbb{C}[X]$ work.

**Step 3. The case $n \geq 2$: forcing $a_0 = 0$.** Set $\lambda_1 = \cdots = \l
ambda_n = 0$ in $(\ast\ast)$:
$$f(0) = n\, f(0) \implies (n-1) f(0) = 0 \implies a_0 = f(0) = 0.$$

**Step 4. The case $n \geq 2$: forcing additivity.** Set $\lambda_3 = \cdots = \
lambda_n = 0$ in $(\ast\ast)$, using $f(0) = 0$:
$$f(\lambda_1 + \lambda_2) = f(\lambda_1) + f(\lambda_2) \quad \text{for all } \
lambda_1, \lambda_2 \in \mathbb{C}. \tag{$\dagger$}$$

**Step 5. Additive polynomials are linear.** With $a_0 = 0$, write $f(X) = a_1 X
 + a_2 X^2 + \cdots + a_d X^d$. Condition $(\dagger)$ gives, as a polynomial ide
ntity in $x$ (setting $\lambda_2 = 1$):
$$f(x+1) - f(x) - f(1) = \sum_{k=2}^{d} a_k\bigl[(x+1)^k - x^k - 1\bigr] = 0 \qu
ad \text{for all } x.$$
For each $k \geq 2$, the polynomial $(x+1)^k - x^k - 1$ has degree $k - 1$ with
leading coefficient $k$. Hence the sum $\sum_{k=2}^{d} a_k[(x+1)^k - x^k - 1]$ h
as degree $d - 1$ with leading coefficient $d\, a_d$. Vanishing forces $a_d = 0$
; descending inductively yields $a_k = 0$ for all $k \geq 2$. Therefore
$$f(X) = a_1 X.$$

**Step 6. Verification.** For $f(X) = cX$ and any $A \in M_n(\mathbb{C})$:
$$f(\operatorname{Tr} A) = c\,\operatorname{Tr} A, \qquad \operatorname{Tr}(f(A)
) = \operatorname{Tr}(cA) = c\,\operatorname{Tr} A.$$
The identity holds for **all** matrices (not merely diagonal ones), confirming t
hat every $f(X) = cX$ is a solution.

**Conclusion.** Combining all steps:
- For $n = 1$: every $f \in \mathbb{C}[X]$ satisfies the identity.
- For $n \geq 2$: the solutions are precisely $f(X) = cX$, $c \in \mathbb{C}$.
