# Problem

In the realm of structural engineering, a specialized support frame is being designed using four steel struts with lengths $a, b, c$, and $d$ (all measured in meters and strictly positive). 

The total structural integrity of the system is calculated by a specific formula. The "Base Reinforcement" value is defined as six times the sum of the squares of the individual strut lengths: $6(a^2 + b^2 + c^2 + d^2)$. To this, engineers add a "Load Distribution Factor," which is the square of the sum of all strut lengths: $(a + b + c + d)^2$.

For the frame to be safety-certified, this combined integrity value must always be greater than or equal to a "Stress Coefficient" $C$ multiplied by the sum of the adjacent interference products: $(ab + bc + cd)$.

What is the greatest possible value of the constant $C$ such that this safety condition holds true for all possible positive lengths of the four struts?
