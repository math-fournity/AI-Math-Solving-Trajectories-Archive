## Proof

Let $p(x) = x^3 - 2x^2 + ax + b$ with roots $r_1, r_2, r_3$ (counted with multip
licity; every cubic has three complex roots by the Fundamental Theorem of Algebr
a, so this imposes no extra restriction).

By Vieta's formulas, writing the elementary symmetric polynomials as $e_1, e_2,
e_3$:
$$e_1 = r_1+r_2+r_3 = 2, \qquad e_2 = r_1r_2+r_1r_3+r_2r_3 = a, \qquad e_3 = r_1
r_2r_3 = -b.$$

Let $s_k = r_1^k + r_2^k + r_3^k$. Newton's identities give:
$$s_1 = e_1 = 2,$$
$$s_2 = e_1 s_1 - 2e_2 = 2\cdot 2 - 2a = 4 - 2a,$$
$$s_3 = e_1 s_2 - e_2 s_1 + 3e_3 = 2(4-2a) - a\cdot 2 + 3(-b) = 8 - 6a - 3b.$$

The required condition is $s_3 = r_1^3+r_2^3+r_3^3 = 0$, i.e.
$$8 - 6a - 3b = 0 \iff 3(2a + b) = 8.$$

The left-hand side $3(2a+b)$ is an integer divisible by $3$ for every integer pa
ir $(a,b)$. The right-hand side is $8$, which is **not** divisible by $3$. Hence
 the equation has no integer solutions.

Therefore $C = \varnothing$, and
$$|C| = 0.$$
