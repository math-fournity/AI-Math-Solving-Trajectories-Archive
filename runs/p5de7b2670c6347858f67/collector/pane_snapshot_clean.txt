## Proof

Let $S(x) = \sum_{n=1}^{\infty}\left(\frac{x}{n^2}\right)^n$. Then $L = \exp\!\l
eft(\lim_{x\to\infty}\frac{\log S(x)}{x}\right)$, so it suffices to determine $\
lim_{x\to\infty}\frac{\log S(x)}{x}$.

**Key observation.** Define $f(n) = n\log\!\frac{x}{n^2} = n\log x - 2n\log n$ f
or real $n>0$. Then $\log a_n(x) = f(n)$ where $a_n(x)=\left(\frac{x}{n^2}\right
)^n$. Computing:

$$f'(n) = \log x - 2\log n - 2, \qquad f''(n) = -\frac{2}{n}.$$

Setting $f'(n)=0$ gives $n^2 = x/e^2$, i.e., the unique maximizer is $n^* = \fra
c{\sqrt{x}}{e}$, with

$$f(n^*) = \frac{\sqrt{x}}{e}\cdot\Big(\log x - 2\log\frac{\sqrt{x}}{e}\Big) = \
frac{\sqrt{x}}{e}\cdot 2 = \frac{2\sqrt{x}}{e}.$$

So every term satisfies $\log a_n(x) \le \frac{2\sqrt{x}}{e} = O(\sqrt{x})$.

**Lower bound.** The $n=1$ term gives $S(x)\ge x$ for $x\ge1$, hence

$$\frac{\log S(x)}{x}\ge\frac{\log x}{x}\to 0^+.$$

**Upper bound.** We show $\log S(x)=O(\sqrt{x})$.

*Terms $n\le N:=\lceil\sqrt{x}\,\rceil$:* There are $N=O(\sqrt{x})$ terms, each

$$\log\!\sum_{n\le N}a_n \le \log N + \frac{2\sqrt{x}}{e}=O(\sqrt{x}).$$

$$\lim_{x\to\infty}\frac{\log S(x)}{x}=0,$$
