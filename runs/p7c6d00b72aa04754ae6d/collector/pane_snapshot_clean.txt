## Proof

We prove by induction on $k$ ($1 \le k \le n$) that there exist $F_k, G_k \in \G
amma$ with
$$F_k \equiv f \pmod{p}, \quad G_k \equiv g \pmod{p}, \quad F_k G_k \equiv h \pm
od{p^k}.$$

**Base case ($k=1$).** Set $F_1 = f$, $G_1 = g$. The first two congruences are i
mmediate, and $F_1 G_1 = fg \equiv h \pmod{p}$ by hypothesis.

**Inductive step.** Assume the claim holds for some $k \ge 1$; we construct $F_{
k+1}, G_{k+1}$.

Since $F_k G_k \equiv h \pmod{p^k}$, every coefficient of $F_k G_k - h$ is divis
ible by $p^k$, so there exists $C \in \Gamma$ with
$$F_k G_k - h = p^k \, C.$$

Define
$$A = -Cs, \qquad B = -Cr, \qquad F_{k+1} = F_k + p^k A, \qquad G_{k+1} = G_k +
p^k B.$$

Since $C, r, s \in \Gamma$, we have $A, B \in \Gamma$, and thus $F_{k+1}, G_{k+1
} \in \Gamma$.

**Congruences mod $p$.** Since $k \ge 1$, the terms $p^k A$ and $p^k B$ have all
 coefficients divisible by $p$, so
$$F_{k+1} \equiv F_k \equiv f \pmod{p}, \qquad G_{k+1} \equiv G_k \equiv g \pmod
{p}.$$

**Key computation.** Since $F_k \equiv f \pmod{p}$ and $G_k \equiv g \pmod{p}$,
$$F_k B + G_k A \equiv fB + gA = f(-Cr) + g(-Cs) = -C(rf + sg) \pmod{p}.$$
By hypothesis $rf + sg \equiv 1 \pmod{p}$, so
$$F_k B + G_k A \equiv -C \pmod{p}.$$
Hence there exists $D \in \Gamma$ with $F_k B + G_k A = -C + p\,D$.

**Expanding the product.**
$$F_{k+1} G_{k+1} = (F_k + p^k A)(G_k + p^k B) = F_k G_k + p^k(F_k B + G_k A) +
p^{2k} AB.$$

Substituting $F_k B + G_k A = -C + pD$:
$$F_{k+1} G_{k+1} = F_k G_k + p^k(-C + pD) + p^{2k} AB = (F_k G_k - p^k C) + p^{
k+1} D + p^{2k} AB.$$

Since $F_k G_k - p^k C = h$ and $2k \ge k+1$ (as $k \ge 1$), we may write $p^{2k
} AB = p^{k+1}(p^{k-1} AB)$, giving
$$F_{k+1} G_{k+1} = h + p^{k+1}\!\left(D + p^{k-1} AB\right).$$

Therefore $F_{k+1} G_{k+1} \equiv h \pmod{p^{k+1}}$, completing the induction.

**Conclusion.** Taking $F = F_n$ and $G = G_n$, we have $F \equiv f \pmod{p}$, $
G \equiv g \pmod{p}$, and $FG \equiv h \pmod{p^n}$. $\blacksquare$
