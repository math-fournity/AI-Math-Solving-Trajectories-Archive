# Problem

A high-security data facility consists of a grid of $100 \times 100$ server racks. A security firm must install $2500$ specialized EMP sensors across these racks to monitor for interference. The installation must follow two strict safety protocols:

(i) Interference Shielding: To prevent signal cross-talk, no two sensors can be placed in "adjacent" racks. In this grid, racks are considered adjacent if they share a side or a corner (meaning no two sensors can occupy any $2 \times 2$ block of racks).

(ii) Power Load Balancing: To ensure even power distribution across the facility's infrastructure, every single horizontal row and every single vertical column in the $100 \times 100$ grid must contain exactly $25$ sensors.

Find the total number of distinct ways the $2500$ sensors can be arranged within the grid while satisfying both protocols. (Arrangements that are rotations or reflections of each other should be counted as distinct.)
