## Solution

We solve the binary tree recurrence (standard symmetric form, where a tree with
$n$ internal nodes splits into subtrees of sizes $k$ and $n-1-k$):

$$f_n = t_n + \sum_{k=0}^{n-1} \frac{C_k\, C_{n-1-k}}{C_n}\bigl(f_k + f_{n-1-k}\
bigr), \quad n\ge 1,\quad f_0 = t_0.$$

### Step 1: Symmetrization

Under $k \mapsto n-1-k$, the two summands are equal:

$$\sum_{k=0}^{n-1} C_k\, C_{n-1-k}\, f_{n-1-k} = \sum_{k=0}^{n-1} C_{n-1-k}\, C_
k\, f_k.$$

So the recurrence becomes

$$f_n = t_n + \frac{2}{C_n}\sum_{k=0}^{n-1} C_k\, C_{n-1-k}\, f_k. \tag{1}$$

### Step 2: Generating function setup

Define the **Catalan-weighted** generating functions:

$$G(z) = \sum_{n\ge 0} C_n\, f_n\, z^n, \qquad T(z) = \sum_{n\ge 0} C_n\, t_n\,
z^n.$$

Recall $C(z) = \sum_{n\ge 0} C_n z^n = \frac{1-\sqrt{1-4z}}{2z}$, satisfying $C
= 1 + zC^2$ and the convolution $\sum_{k=0}^{n-1} C_k\, C_{n-1-k} = C_n$.

### Step 3: Functional equation

Multiply (1) by $C_n z^n$ and sum over $n \ge 1$:

$$\sum_{n\ge 1} C_n f_n z^n = \sum_{n\ge 1} C_n t_n z^n + 2\sum_{n\ge 1} z^n \su
m_{k=0}^{n-1} C_k\, C_{n-1-k}\, f_k.$$

- **LHS** $= G(z) - f_0$.
- **First RHS** $= T(z) - t_0$.
- **Double sum**: set $j = n{-}1{-}k$ so $n = k{+}j{+}1$:

$$\sum_{k\ge 0,\, j\ge 0} z^{k+j+1}\, C_k f_k\, C_j = z\, G(z)\, C(z).$$

With $f_0 = t_0$:

$$G(z) = T(z) + 2z\, C(z)\, G(z). \tag{2}$$

### Step 4: Solve

Rearranging (2):

$$G(z)\bigl(1 - 2z\, C(z)\bigr) = T(z).$$

Since $2z\,C(z) = 1 - \sqrt{1-4z}$, we get $1 - 2z\,C(z) = \sqrt{1-4z}$, hence:

$$\boxed{\,G(z) = \frac{T(z)}{\sqrt{1-4z}}\,}. \tag{3}$$

**This is the generating function solution**: the Catalan-weighted GF of $\{f_n\
}$ equals the Catalan-weighted GF of $\{t_n\}$ divided by $\sqrt{1-4z}$.

### Step 5: Coefficient formula

Since $\frac{1}{\sqrt{1-4z}} = \sum_{m\ge 0}\binom{2m}{m} z^m$, equation (3) giv
es the convolution:

$$\boxed{\,f_n = \frac{1}{C_n}\sum_{k=0}^{n} C_k\, t_k \binom{2(n-k)}{n-k}\,}. \
tag{4}$$

### Step 6: Asymptotic behavior

The dominant singularity is at $z = 1/4$. Using singularity analysis (transfer t
heorems), suppose $t_n \sim c\, n^\alpha$.

Since $C_n \sim \frac{4^n}{\sqrt{\pi}\, n^{3/2}}$, we have $C_n\, t_n \sim \frac
{c}{\sqrt{\pi}}\, 4^n\, n^{\alpha - 3/2}$.

**Case $\alpha < 1/2$:** The series $T(1/4) = \sum_{k\ge 0} \frac{C_k\, t_k}{4^k
}$ converges (exponent $\alpha - 3/2 < -1$). So $T(z)$ is analytic at $z = 1/4$
and

$$G(z) \sim \frac{T(1/4)}{\sqrt{1-4z}}.$$

Using $[z^n]\frac{1}{\sqrt{1-4z}} = \binom{2n}{n} \sim \frac{4^n}{\sqrt{\pi n}}$
 and $C_n \sim \frac{4^n}{\sqrt{\pi}\, n^{3/2}}$:

$$f_n \sim T(1/4)\cdot n.$$

**Case $\alpha = 1/2$:** Here $T(z) \sim \frac{c}{\sqrt{\pi}}\ln\frac{1}{1-4z}$,
 so $G(z) \sim \frac{c}{\sqrt{\pi}}\frac{\ln(1/(1-4z))}{\sqrt{1-4z}}$. By singul
arity analysis, $[z^n]\frac{\ln(1/(1-4z))}{\sqrt{1-4z}} \sim \frac{4^n \ln n}{\s
qrt{\pi n}}$, giving

$$f_n \sim \frac{c}{\sqrt{\pi}}\, n \ln n.$$

**Case $\alpha > 1/2$:** Now $T(z) \sim \frac{c\,\Gamma(\alpha-1/2)}{\sqrt{\pi}\
,(1-4z)^{\alpha-1/2}}$, so

$$G(z) \sim \frac{c\,\Gamma(\alpha-1/2)}{\sqrt{\pi}}\,(1-4z)^{-\alpha}.$$

By the transfer theorem $[z^n](1-4z)^{-\alpha} \sim \frac{4^n\, n^{\alpha-1}}{\G
amma(\alpha)}$, hence

$$f_n \sim \frac{c\,\Gamma(\alpha-\tfrac{1}{2})}{\Gamma(\alpha)}\, n^{\alpha+1/2
}.$$

### Summary

$$f_n \sim \begin{cases} \displaystyle n\sum_{k\ge 0}\frac{C_k\, t_k}{4^k}, & \a
lpha < \tfrac{1}{2}, \\[8pt] \displaystyle \frac{c}{\sqrt{\pi}}\, n\ln n, & \alp
ha = \tfrac{1}{2}, \\[8pt] \displaystyle \frac{c\,\Gamma(\alpha-\tfrac{1}{2})}{\
Gamma(\alpha)}\, n^{\alpha+1/2}, & \alpha > \tfrac{1}{2}, \end{cases} \qquad (t_
n \sim c\, n^\alpha). \tag{5}$$

The recurrence **amplifies the toll by a factor $n^{1/2}$**: for $\alpha > 1/2$,
 a toll $n^\alpha$ produces $f_n \sim n^{\alpha+1/2}$; for slowly growing tolls
($\alpha < 1/2$), accumulated small contributions yield linear growth.

### Verification

- **$t_n = 1$** ($\alpha=0$): $T(1/4) = C(1/4) = 2$, so $f_n \sim 2n$. Indeed $f
_n = 2n+1$ exactly (verified: the recurrence gives $f_0{=}1, f_1{=}3, f_2{=}5, f
_3{=}7$).
- **$t_n = n-1$** ($\alpha=1$, $c=1$): $f_n \sim \frac{\Gamma(1/2)}{\Gamma(1)}\,
 n^{3/2} = \sqrt{\pi}\, n^{3/2}$, the classical expected internal path length of
 a random Catalan tree.
