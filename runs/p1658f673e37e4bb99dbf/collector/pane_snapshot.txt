## Solution

We count all unordered sets of 3 distinct collinear grid points in $\{0,1,2,3\}^
3$.

**Key constraint on directions.** A line with primitive direction $(a,b,c)$ (wit
h $\gcd(|a|,|b|,|c|)=1$) containing $\ge 3$ grid points must have 3 points at le
ast 2 primitive steps apart, so the span in each coordinate is $\ge 2|a|, 2|b|,
2|c|$. Since the grid has extent 3 in each coordinate, we need $2|a|,2|b|,2|c| \
le 3$, forcing $|a|,|b|,|c| \le 1$. The 13 primitive directions (up to sign) are
:

- **3 axis directions:** $(1,0,0), (0,1,0), (0,0,1)$
- **6 face diagonals:** $(1,\pm1,0), (1,0,\pm1), (0,1,\pm1)$
- **4 space diagonals:** $(\pm1,\pm1,\pm1)$ with first component $+1$.

For each direction, every line with $\ge 3$ grid points contributes $\binom{k}{3
}$ where $k$ is the number of grid points on it.

---

**Axis directions.** For direction $(1,0,0)$: lines are fixed by $(y,z) \in \{0,
1,2,3\}^2$, giving 16 lines each with 4 points. Contribution: $16 \cdot \binom{4
}{3} = 64$. Over 3 axes: $3 \times 64 = \mathbf{192}$.

---

**Face diagonals.** Take $(1,1,0)$. Lines are fixed by $d = x-y$ and $z$. For ea
ch $z$:
- $d=0$: 4 points $\to \binom{4}{3}=4$
- $d=\pm1$: 3 points each $\to \binom{3}{3}=1$ each
- $|d|\ge2$: $\le 2$ points $\to 0$

Per $z$: $4+1+1=6$. Over 4 values of $z$: $4\times6=24$. By symmetry all 6 face
diagonals give 24: $6\times24 = \mathbf{144}$.

---

**Space diagonals.** Take $(1,1,1)$. A line is determined by $(u,v)=(x-y,\, x-z)
$. Grid points on it are $(s,\, s-u,\, s-v)$ for integer $s$ with all coordinate
s in $\{0,1,2,3\}$, i.e. $s \in [\max(0,u,v),\, \min(3,u+3,v+3)]$. The count is
$3 + \min(0,u,v) - \max(0,u,v) + 1 = 4 - \operatorname{range}\{0,u,v\}$.

For $\ge 3$ points we need $\operatorname{range}\{0,u,v\} \le 1$, meaning $\{0,u
,v\} \subseteq \{0,1\}$ or $\{0,u,v\} \subseteq \{-1,0\}$:
- $(u,v)=(0,0)$: range 0, count 4 $\to \binom{4}{3}=4$
- $(u,v) \in \{(1,0),(0,1),(1,1),(-1,0),(0,-1),(-1,-1)\}$: range 1, count 3 $\to
 \binom{3}{3}=1$ each

Total: $4 + 6 = 10$. By cube symmetry all 4 space diagonals give 10: $4\times10
= \mathbf{40}$.

---

**Grand total:**

$$192 + 144 + 40 = \boxed{376}$$
