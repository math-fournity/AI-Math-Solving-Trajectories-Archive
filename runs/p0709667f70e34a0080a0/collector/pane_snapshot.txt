## Proof

**Step 1: Both $p$ and $q$ are nonzero.** If $q \equiv 0$, the left side is $0 \
neq 1$; similarly for $p \equiv 0$.

**Step 2: Degree analysis.** Let $\deg p = m$, $\deg q = n$, with leading coeffi
cients $a, b \neq 0$. Write
$$p(x) = ax^m + a_1 x^{m-1} + \cdots, \qquad q(x) = bx^n + b_1 x^{n-1} + \cdots.
$$
A direct expansion gives:
$$p(x)q(x+1) = ab\, x^{m+n} + \big(a(bn+b_1)+a_1 b\big)x^{m+n-1} + \cdots,$$
$$p(x+1)q(x) = ab\, x^{m+n} + \big(ab_1 + amb + a_1 b\big)x^{m+n-1} + \cdots.$$
Subtracting, the $x^{m+n}$ terms cancel and the coefficient of $x^{m+n-1}$ in $f
(x) := p(x)q(x+1)-p(x+1)q(x)$ is
$$ab(n-m).$$

**Step 3: Reduction when $m = n$.** Observe that replacing $p$ by $p - cq$ (for
any constant $c$) preserves the equation:
$$(p-cq)(x)\,q(x+1) - (p-cq)(x+1)\,q(x) = p(x)q(x+1)-p(x+1)q(x) - c\big(q(x)q(x+
1)-q(x+1)q(x)\big) = 1.$$
Choosing $c = a/b$ reduces the degree of $p$ below $n$. Repeating as needed, we
may assume **WLOG that $m < n$** (unless $p$ becomes $0$, which is impossible si
nce $f=1$).

**Step 4: The case $m < n$.** Since $m \neq n$ and $a,b \neq 0$, the coefficient
 $ab(n-m) \neq 0$, so
$$\deg f = m+n-1.$$
For $f \equiv 1$ (a constant), we need $m + n - 1 = 0$, i.e., $m + n = 1$. With
$m < n$ and $m \geq 0$, $n \geq 1$, the only possibility is $m = 0, n = 1$.

**Step 5: Ruling out $m = n \geq 2$.** If $m = n = k \geq 2$, the reduction in S
tep 3 gives $r = p - (a/b)q$ with $\deg r \leq k-1 < k = \deg q$ and $r(x)q(x+1)
 - r(x+1)q(x) = 1$. By Step 4, $\deg r + k = 1$, so $\deg r = 1 - k \leq -1$, im
possible for a nonzero polynomial. (And $r \neq 0$ since $f = 1$.) The case $m =
 n = 0$ gives $f = 0 \neq 1$.

**Step 6: The case $m > n$.** If $n = 0, m = 1$: this is $m + n = 1$, already co
vered. If $n = 0, m \geq 2$: $\deg f = m-1 \geq 1$, contradiction. If $n \geq 1,
 m > n$: $\deg f = m+n-1 \geq 2n-1 \geq 1$, contradiction.

**Step 7: Solving $m + n \leq 1$.** Both $p$ and $q$ have degree at most $1$. Wr
ite $p(x) = \alpha x + \beta$, $q(x) = \gamma x + \delta$. Direct computation:
$$p(x)q(x+1) - p(x+1)q(x) = \beta\gamma - \alpha\delta.$$
(All $x$-dependent terms cancel.) The equation becomes
$$\beta\gamma - \alpha\delta = 1, \quad\text{i.e.,}\quad \alpha\delta - \beta\ga
mma = -1.$$

**Step 8: Verification.** Conversely, for any $\alpha, \beta, \gamma, \delta \in
 \mathbb{R}$ with $\alpha\delta - \beta\gamma = -1$, the computation above shows
 $p(x)q(x+1) - p(x+1)q(x) = 1$. $\checkmark$

## Conclusion

The pairs $(p, q)$ are exactly:
$$\boxed{p(x) = \alpha x + \beta, \quad q(x) = \gamma x + \delta, \quad \alpha\d
elta - \beta\gamma = -1,}$$
for arbitrary real numbers $\alpha, \beta, \gamma, \delta$ satisfying $\alpha\de
lta - \beta\gamma = -1$ (equivalently, the determinant $\begin{vmatrix}\alpha &
\beta \\ \gamma & \delta\end{vmatrix} = -1$).
