**Step 1: Separate the integrand.**

$$f(x) = [(x+1)\ln x + 1]\, e^{x(e^x \ln x + 1)}.$$

Then
$$I_n = \int_1^{1+1/n} f(x)\,dx + \int_1^{1+1/n} n\,dx = \int_1^{1+1/n} f(x)\,dx
 + n\cdot\frac{1}{n} = 1 + a_n,$$
where $a_n := \int_1^{1+1/n} f(x)\,dx$.

**Step 2: Evaluate $f$ at $x=1$.**

At $x=1$: $\ln 1 = 0$, so
- $(x+1)\ln x + 1 = 2\cdot 0 + 1 = 1$,
- $e^x \ln x + 1 = e\cdot 0 + 1 = 1$,
- $x(e^x\ln x+1) = 1\cdot 1 = 1$.

Hence $f(1) = 1\cdot e^{1} = e$.

**Step 3: Asymptotic expansion of $a_n$.**

Since $f$ is smooth near $x=1$, by the Taylor expansion $f(x) = f(1) + f'(1)(x-1
) + O((x-1)^2)$, and integrating over $[1, 1+1/n]$:
$$a_n = f(1)\cdot\frac{1}{n} + \frac{f'(1)}{2n^2} + O\!\left(\frac{1}{n^3}\right
) = \frac{e}{n} + O\!\left(\frac{1}{n^2}\right).$$

**Step 4: Compute the limit of $I_n^n = (1+a_n)^n$.**

We have
$$\ln(I_n^n) = n\ln(1+a_n).$$

Since $a_n = \frac{e}{n} + O(n^{-2}) \to 0$, using $\ln(1+u) = u - \frac{u^2}{2}
 + \cdots$:
$$n\ln(1+a_n) = n\,a_n - \frac{n\,a_n^2}{2} + O(n\,a_n^3).$$

Now:
- $n\,a_n = e + O(1/n) \to e$,
- $n\,a_n^2 = n\cdot\frac{e^2}{n^2}(1+o(1)) = \frac{e^2}{n}(1+o(1)) \to 0$,
- $n\,a_n^3 = O(n^{-2}) \to 0$.

Therefore
$$\lim_{n\to\infty} n\ln(1+a_n) = e,$$
and by continuity of the exponential,
$$\lim_{n\to\infty} I_n^n = \lim_{n\to\infty} (1+a_n)^n = e^{e}.$$
