Looking at this problem, I need to find integers $a,b,c,d,e,f$ so that the ratio
nal function $F(R)=\frac{aR^2+bR+c}{dR^2+eR+f}$ is a better approximation to $\a

## Proof

Let $\alpha = \sqrt[3]{2}$. We claim that $(a,b,c,d,e,f) = (0,1,2,1,0,1)$ works,
 giving

$$F(R) = \frac{R+2}{R^2+1}.$$

**Step 1: Necessity of $F(\alpha)=\alpha$.** Since $\alpha$ is irrational, every
 non-negative rational $R$ satisfies $|R-\alpha|>0$. For the inequality to hold
for rationals $R$ arbitrarily close to $\alpha$, we need $F(\alpha)=\alpha$ (oth
erwise $|F(R)-\alpha|$ stays bounded away from $0$ while $|R-\alpha|\to 0$). Let
 us verify:

$$F(\alpha) = \frac{\alpha+2}{\alpha^2+1}.$$

Since $\alpha^3=2$, we have $\alpha(\alpha^2+1)=\alpha^3+\alpha=2+\alpha=\alpha+
2$. Thus $F(\alpha)=\alpha$. ✓

**Step 2: Factoring $F(R)-\alpha$.** We compute:

$$F(R)-\alpha = \frac{R+2-\alpha(R^2+1)}{R^2+1} = \frac{-\alpha R^2 + R + (2-\al
pha)}{R^2+1}.$$

The numerator vanishes at $R=\alpha$ (verified above), so we factor out $(R-\alp
ha)$:

$$-\alpha R^2 + R + (2-\alpha) = (R-\alpha)(-\alpha R + 1 - \alpha^2).$$

**Verification of the factorization:** Expanding the right side:
$(R-\alpha)(-\alpha R + 1-\alpha^2) = -\alpha R^2 + R - \alpha^2 R + \alpha^2 \c
dot \alpha - \alpha + \alpha \cdot \alpha^2$... let me verify directly:

$(R-\alpha)(-\alpha R + 1-\alpha^2) = -\alpha R^2 + R(1-\alpha^2) + \alpha^2 R -
 \alpha(1-\alpha^2) = -\alpha R^2 + R - \alpha^2 R + \alpha^2 R - \alpha + \alph
a^3 = -\alpha R^2 + R - \alpha + 2 = -\alpha R^2 + R + (2-\alpha)$. ✓

Therefore:

$$F(R) - \alpha = (R-\alpha)\cdot G(R), \quad \text{where } G(R) = \frac{-\alpha
 R + 1 - \alpha^2}{R^2+1}.$$

**Step 3: Showing $|G(R)|<1$ for all non-negative rational $R$.** Since $R$ is r
ational and $\alpha$ is irrational, $R\neq\alpha$, so $|R-\alpha|>0$. The desire
d inequality $|F(R)-\alpha|<|R-\alpha|$ is equivalent to $|G(R)|<1$.

The denominator $R^2+1\geq 1>0$ for all real $R$, so we need:

$$|-\alpha R + 1 - \alpha^2| < R^2 + 1 \quad \text{for all } R\geq 0.$$

This is equivalent to two inequalities:

**(I)** $-\alpha R + 1 - \alpha^2 < R^2 + 1$, i.e., $R^2 + \alpha R + \alpha^2 >
 0$.

**(II)** $\alpha R - 1 + \alpha^2 < R^2 + 1$, i.e., $R^2 - \alpha R + (2-\alpha^
2) > 0$.

**Inequality (I):** $R^2 + \alpha R + \alpha^2 = \left(R+\frac{\alpha}{2}\right)
^2 + \frac{3\alpha^2}{4} > 0$ for all real $R$. ✓

**Inequality (II):** The quadratic $R^2 - \alpha R + (2-\alpha^2)$ has discrimin
ant:

$$\Delta = \alpha^2 - 4(2-\alpha^2) = 5\alpha^2 - 8.$$

We show $\Delta < 0$, i.e., $5\alpha^2 < 8$, i.e., $\alpha^2 < \frac{8}{5}$.

Since $\alpha^2 = 2^{2/3}$, this is equivalent to $2^2 < \left(\frac{8}{5}\right
)^3 = \frac{512}{125}$, i.e., $4 < 4.096$. This is true. ✓

Therefore $\Delta < 0$, and since the leading coefficient is positive, $R^2 - \a
lpha R + (2-\alpha^2) > 0$ for all real $R$. ✓

**Conclusion.** Both inequalities (I) and (II) hold for all real $R$ (hence cert
ainly for all non-negative rational $R$). Therefore $|G(R)|<1$ for all non-negat
ive rational $R$, which gives:

$$\left|\frac{R+2}{R^2+1} - \sqrt[3]{2}\right| < \left|R - \sqrt[3]{2}\right|$$

for every non-negative rational number $R$.

The required integers are $\boxed{a=0,\ b=1,\ c=2,\ d=1,\ e=0,\ f=1}$.
