Looking at this problem, I need to find all $P(x) = ax^2 + bx$ with $a, b \in \{
0, \ldots, N-1\}$ (where $N = 2010^{18}$) such that for every $n \in \{0, \ldots
, N-1\}$, there exists $Q(x) = cx^2 + dx$ with $c, d \in \{0, \ldots, N-1\}$ sat
isfying $Q(P(n)) \equiv n \pmod{N}$.

## Setting Up the Condition

For a fixed $n$, let $m = P(n) \bmod N$. We need $c, d$ such that $cm^2 + dm \eq
uiv n \pmod{N}$. The set of achievable values $\{cm^2 + dm \bmod N\}$ is the ide
al generated by $\gcd(m, N)$ in $\mathbb{Z}/N\mathbb{Z}$. So the condition is:

$$\gcd(P(n), N) \mid n \quad \text{for all } n \in \{0, \ldots, N-1\}.$$

For $n = 0$: $P(0) = 0$, condition holds trivially.

## Prime Power Analysis

Factor $N = 2010^{18} = 2^{18} \cdot 3^{18} \cdot 5^{18} \cdot 67^{18}$. The con
dition $\gcd(P(n), N) \mid n$ is equivalent to: for each prime $p \mid N$,

$$\min(v_p(P(n)), 18) \le v_p(n) \quad \text{for all } n.$$

**Case $v_p(n) \ge 18$:** Then $18 \le v_p(n)$, so the condition holds automatic
ally.

**Case $v_p(n) < 18$:** We need $v_p(P(n)) \le v_p(n)$.

Since $P(n) = n(an + b)$, for $n \neq 0$ we have $v_p(P(n)) = v_p(n) + v_p(an +
b)$. The condition becomes $v_p(an+b) \le 0$, i.e., $p \nmid (an+b)$.

**Summary for each prime $p$:** For all $n$ with $1 \le n < N$ and $p^{18} \nmid
 n$, we need $p \nmid (an+b)$.

## Determining the Constraints on $a, b$

**If $p \nmid a$:** The congruence $an + b \equiv 0 \pmod{p}$ has the solution $
n \equiv -ba^{-1} \pmod{p}$. Choosing the smallest positive such $n$ (which is $
< p \le 2010 < p^{18}$, so $p^{18} \nmid n$) gives a violation. ✗

**If $p \mid a$ and $p \mid b$:** Then $an + b \equiv 0 \pmod{p}$ for all $n$. T
aking $n = 1$ (with $p^{18} \nmid 1$) gives a violation. ✗

**If $p \mid a$ and $p \nmid b$:** Then $an + b \equiv b \not\equiv 0 \pmod{p}$
for all $n$. ✓

Therefore, for each prime $p \in \{2, 3, 5, 67\}$, we need $p \mid a$ and $p \nm
id b$. These conditions are independent across primes, giving:

$$2010 \mid a \quad \text{and} \quad \gcd(b, 2010) = 1.$$

## Counting

**Valid $a$:** Multiples of $2010$ in $\{0, \ldots, N-1\}$: count $= N/2010 = 20
10^{17}$.

**Valid $b$:** Integers in $\{0, \ldots, N-1\}$ coprime to $2010$. Since $2010 \
mid N$, residues mod $2010$ are evenly distributed:

$$\phi(2010) = 2010 \cdot \frac{1}{2} \cdot \frac{2}{3} \cdot \frac{4}{5} \cdot
\frac{66}{67} = 528.$$

Count $= \frac{N}{2010} \cdot \phi(2010) = 2010^{17} \cdot 528$.

## Verification

- $a = 0$, $\gcd(b, 2010) = 1$: $P(n) = bn$, $v_p(P(n)) = v_p(n)$, condition hol
ds. ✓
- $b = 0$: $\gcd(0, 2010) = 2010 \neq 1$, excluded. Indeed $P(n) = an^2$ with $v
_p(a) \ge 18$ gives $v_p(P(n)) \ge 18 > v_p(n)$ for $v_p(n) < 18$. ✓

## Result

$$\text{Total} = 2010^{17} \times 2010^{17} \times 528 = \boxed{2010^{34} \times
 528}$$
