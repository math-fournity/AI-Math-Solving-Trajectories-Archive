## 解答

我们需要找到所有整数 $a, b, c$，使得集合 $S = \bigl\{\{\sqrt{an^2+bn+c}\} : n\in
\mathbb{Z}_{>0},\; an^2+bn+c\ge 0\bigr\}$ 在 $[0,1]$ 中稠密。

### 第一步：排除不满足条件的情况

**$a < 0$：** 当 $n\to\infty$ 时 $an^2+bn+c\to -\infty$，只有有限个 $n$ 满足非负
条件，$S$ 有限，不稠密。

**$a = 0,\, b \le 0$：** 若 $b=0$，表达式为常数 $c$（$c<0$ 时无合法 $n$；$c\ge 0
$ 时 $S$ 为单点）。若 $b<0$，$bn+c\to -\infty$，只有有限个合法 $n$。均不稠密。

**$a > 0$ 且 $a = k^2$（$k$ 为正整数）：** 计算渐近展开：
$$\sqrt{k^2 n^2 + bn + c} = kn\sqrt{1+\frac{b}{k^2 n}+\frac{c}{k^2 n^2}} = kn +
\frac{b}{2k} + \frac{4k^2 c - b^2}{8k^3 n} + O(n^{-2}).$$
由于 $kn$ 为整数，
$$\bigl\{\sqrt{k^2 n^2+bn+c}\bigr\} = \left\{\frac{b}{2k} + O(1/n)\right\} \long
rightarrow \left\{\frac{b}{2k}\right\} \quad (n\to\infty).$$
故 $S$ 在 $[0,1]$ 中至多有一个聚点 $\{b/(2k)\}$，不稠密。

### 第二步：验证满足条件的情况

**情况一：$a = 0,\, b > 0$（$c$ 任意）：**

对足够大的 $n$，$bn+c > 0$。令 $f(x) = \sqrt{bx+c}$（$x$ 充分大时定义）。则
$$f'(x) = \frac{b}{2\sqrt{bx+c}} > 0, \quad f'(x) \text{ 单调递减趋于 } 0, \quad
 x\,f'(x) = \frac{bx}{2\sqrt{bx+c}} \to \infty.$$
由 **Fejér 定理**，$\{f(n)\} = \{\sqrt{bn+c}\}$ 模 $1$ 一致分布，故在 $[0,1]$ 中
稠密。✓

**情况二：$a > 0$ 且 $a$ 不是完全平方数（$b, c$ 任意）：**

对足够大的 $n$，$an^2+bn+c > 0$。计算渐近展开：
$$\sqrt{an^2+bn+c} = \sqrt{a}\,n + \frac{b}{2\sqrt{a}} + \epsilon(n), \quad \eps
ilon(n) = O(1/n) \to 0.$$

由于 $a$ 是正整数但非完全平方数，$\sqrt{a}$ 为无理数。由 **Weyl 一致分布定理**，
序列 $\bigl\{\sqrt{a}\,n + \frac{b}{2\sqrt{a}}\bigr\}_{n\ge 1}$ 模 $1$ 一致分布
，故稠密。

**稠密性传递：** 任取 $(u,v) \subset [0,1]$，$u < v$。取 $\delta > 0$ 充分小使得
 $(u+\delta,\, v-\delta) \subset (0,1)$ 且非空。由一致分布，存在无穷多个 $n$ 使
$$\bigl\{\sqrt{a}\,n + \tfrac{b}{2\sqrt{a}}\bigr\} \in (u+\delta,\; v-\delta) \s
ubset (\delta,\; 1-\delta).$$
对这些 $n$ 取足够大使得 $|\epsilon(n)| < \delta$。由于 $\bigl\{\sqrt{a}\,n+\tfra
c{b}{2\sqrt{a}}\bigr\} \in (\delta, 1-\delta)$，加上 $|\epsilon(n)|<\delta$ 不会
越过整数边界，故
$$\bigl\{\sqrt{an^2+bn+c}\bigr\} = \bigl\{\sqrt{a}\,n+\tfrac{b}{2\sqrt{a}}\bigr\
} + \epsilon(n) \in (u+\delta-\delta,\; v-\delta+\delta) = (u,\,v).$$
因此 $S$ 在 $[0,1]$ 中稠密。✓

### 结论

满足条件的所有整数 $(a,b,c)$ 为：

$$\boxed{(a,\, b,\, c) \in \mathbb{Z}^3 \;:\; \bigl(a > 0 \text{ 且 } a \text{
不是完全平方数}\bigr) \;\text{或}\; \bigl(a = 0 \text{ 且 } b > 0\bigr)}$$

即：$a$ 为正非完全平方数时 $b,c$ 任意；或 $a=0$ 且 $b>0$ 时 $c$ 任意。
