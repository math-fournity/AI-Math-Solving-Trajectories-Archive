## Proof

**Step 1: Recover the point masses.** Let $a_n = \mu(\{n\})$. Since
$$\mu(\{n,n+1,\dots\}) = \sum_{k=n}^{\infty} a_k = \frac{n}{2^n},$$
telescoping gives
$$a_n = \mu(\{n,n+1,\dots\}) - \mu(\{n+1,n+2,\dots\}) = \frac{n}{2^n} - \frac{n+
1}{2^{n+1}} = \frac{2n-(n+1)}{2^{n+1}} = \frac{n-1}{2^{n+1}}.$$

**Verification:** $\sum_{k=n}^{\infty}\frac{k-1}{2^{k+1}} = \frac12\sum_{k=n}^{\
infty}\frac{k-1}{2^k}$. For $n=1$: $\sum_{k=1}^{\infty}\frac{k-1}{2^k} = \sum_{j
=1}^{\infty}\frac{j}{2^{j+1}} = \frac12\cdot\frac{1/2}{(1/2)^2}=\frac12\cdot 2 =
 1$, so $\mu(\mathbb N)=\frac12\cdot 1 = \frac12 = \frac{1}{2^1}$. ✓

**Step 2: Compute the integral.** Since $\mu$ is a discrete measure on $\mathbb
N$,
$$\int x\,d\mu(x) = \sum_{n=1}^{\infty} n\,a_n = \sum_{n=1}^{\infty}\frac{n(n-1)
}{2^{n+1}} = \frac12\sum_{n=1}^{\infty}\frac{n(n-1)}{2^n}.$$

Using the standard generating function $\sum_{n=0}^{\infty}n(n-1)x^n = \frac{2x^
2}{(1-x)^3}$ at $x=\tfrac12$:
$$\sum_{n=1}^{\infty}\frac{n(n-1)}{2^n} = \frac{2\cdot(1/2)^2}{(1/2)^3} = \frac{
1/2}{1/8} = 4.$$

(The $n=0,1$ terms vanish, so the sum starting at $n=1$ equals the sum starting
at $n=0$.)

Therefore
$$\int x\,d\mu(x) = \frac12 \cdot 4 = \boxed{2}.$$
