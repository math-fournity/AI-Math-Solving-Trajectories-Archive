# Solution

**Answer: No.**

## Proof

We interpret "measure-equivalence class" as the equivalence class under the stan
dard measure-theoretic equivalence relation: two measurable sets $A, B$ are equi
valent ($A \sim B$) if and only if their symmetric difference has measure zero,
i.e., $\mu(A \triangle B) = 0$. A "non-null" set is one with positive measure.

We exhibit a counterexample showing that such an equivalence class need not have
 a non-empty intersection.

**Counterexample.** Consider the measure space $(\mathbb{R}, \mathcal{B}, \lambd
a)$ where $\lambda$ is Lebesgue measure. Let $A = (0,1)$, which is measurable an
d non-null ($\lambda(A) = 1 > 0$).

The measure-equivalence class of $A$ is:
$$[A] = \{B \in \mathcal{B} : \lambda(B \triangle A) = 0\}.$$

We show that $\bigcap_{B \in [A]} B = \emptyset$.

Take any point $x \in \mathbb{R}$. We find a set $B \in [A]$ with $x \notin B$:

- **Case 1: $x \in (0,1)$.** Set $B = A \setminus \{x\} = (0,1) \setminus \{x\}$
. Then $\lambda(B \triangle A) = \lambda(\{x\}) = 0$ (Lebesgue measure of a sing
leton is zero), so $B \in [A]$. But $x \notin B$, so $x \notin \bigcap [A]$.

- **Case 2: $x \notin (0,1)$.** Then $x \notin A$ itself, and $A \in [A]$ (since
 $\lambda(A \triangle A) = 0$). So $x \notin \bigcap [A]$.

Since for every $x \in \mathbb{R}$ we have $x \notin \bigcap_{B \in [A]} B$, it
follows that:
$$\bigcap_{B \in [A]} B = \emptyset.$$

**Key insight.** The argument generalizes: for any non-atomic measure space and
any non-null measurable set $A$, every point $x \in A$ can be removed (yielding
$A \setminus \{x\}$, which remains equivalent to $A$ since single points have me
asure zero), and every point $x \notin A$ is already excluded by $A$ itself. Thu
s the intersection of the entire equivalence class is always empty in non-atomic
 measure spaces.

Since the question asks whether the intersection is **necessarily** non-empty (i
.e., for all measure spaces and all non-null sets), the existence of this counte
rexample gives a definitive **No**.
