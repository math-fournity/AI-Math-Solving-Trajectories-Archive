**Goal.** Find the real value of $\alpha$ for which
$$\Delta u + 2u = x - \alpha, \quad \Omega=(0,\pi)^2,\quad u|_{\partial\Omega}=0
$$
has at least one weak solution $u\in H_0^1(\Omega)$.

---

### Step 1. Spectral structure of the operator

Consider $L := \Delta + 2$ on $\Omega=(0,\pi)^2$ with Dirichlet boundary conditi
ons. The eigenfunctions of $-\Delta$ on $(0,\pi)^2$ with $u|_{\partial\Omega}=0$
 are
$$\phi_{m,n}(x,y)=\sin(mx)\sin(ny),\qquad m,n\ge 1,$$
with eigenvalues $\lambda_{m,n}=m^2+n^2$. Hence the eigenvalues of $L=\Delta+2$
are
$$\mu_{m,n}=2-(m^2+n^2).$$

The operator $L$ is singular precisely when $\mu_{m,n}=0$ for some $(m,n)$, i.e.
 $m^2+n^2=2$. The unique positive-integer solution is $(m,n)=(1,1)$, giving
$$\ker L = \operatorname{span}\{\,\phi_{1,1}\},\qquad \phi_{1,1}(x,y)=\sin x\,\s
in y.$$

### Step 2. Fredholm alternative

Since $L$ is self-adjoint under the Dirichlet boundary condition (symmetric bili
near form on $H_0^1$), the Fredholm alternative states: the equation $Lu = f$ is
 solvable if and only if $f$ is orthogonal (in $L^2$) to $\ker L$:
$$\langle f,\phi_{1,1}\rangle_{L^2(\Omega)} = 0.$$

Here $f(x,y)=x-\alpha$. Thus the solvability condition is
$$\int_0^\pi\!\!\int_0^\pi (x-\alpha)\,\sin x\,\sin y\;dx\,dy = 0.$$

### Step 3. Evaluate the integrals

Separating variables:
$$\int_0^\pi\!\!\int_0^\pi (x-\alpha)\sin x\sin y\,dx\,dy
= \left(\int_0^\pi (x-\alpha)\sin x\,dx\right)\!\left(\int_0^\pi \sin y\,dy\righ
t).$$

Compute each factor:
$$\int_0^\pi \sin y\,dy = \bigl[-\cos y\bigr]_0^\pi = -(-1)-(-1)=2.$$
$$\int_0^\pi x\sin x\,dx = \bigl[-x\cos x\bigr]_0^\pi+\int_0^\pi \cos x\,dx = \p
i\cdot 1 + \bigl[\sin x\bigr]_0^\pi = \pi + 0 = \pi.$$
$$\int_0^\pi \sin x\,dx = 2.$$

Therefore
$$\int_0^\pi (x-\alpha)\sin x\,dx = \pi - 2\alpha,$$
and the orthogonality condition becomes
$$(\pi - 2\alpha)\cdot 2 = 0 \quad\Longrightarrow\quad \pi - 2\alpha = 0 \quad\L
ongrightarrow\quad \alpha = \frac{\pi}{2}.$$

### Step 4. Sufficiency

When $\alpha=\pi/2$, the right-hand side $f(x,y)=x-\pi/2$ satisfies $\langle f,\
phi_{1,1}\rangle=0$, so by the Fredholm alternative there exists $u\in H_0^1(\Om
ega)$ solving $Lu=f$ in the distributional sense. Concretely, expanding $f$ in t
he eigenbasis $\{\phi_{m,n}\}$,
$$f = \sum_{(m,n)\ne(1,1)} c_{m,n}\,\phi_{m,n},\qquad c_{m,n}=\frac{\langle f,\p
hi_{m,n}\rangle}{\|\phi_{m,n}\|^2},$$
the solution is
$$u = \sum_{(m,n)\ne(1,1)} \frac{c_{m,n}}{2-(m^2+n^2)}\,\phi_{m,n},$$
which converges in $H_0^1(\Omega)$ since $f\in L^2(\Omega)$ and the denominators
 $2-(m^2+n^2)$ are bounded away from $0$ on the index set $(m,n)\ne(1,1)$.

---

**Conclusion.** The unique real value of $\alpha$ for which the boundary value p
roblem admits a weak solution is

$$\boxed{\alpha = \dfrac{\pi}{2}}.$$
