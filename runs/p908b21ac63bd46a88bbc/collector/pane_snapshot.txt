## Proof

Let $f \in C^\infty_K(\mathbb{R})$, so $f$ is smooth with compact support. In pa
rticular, every derivative $f^{(k)}$ is continuous and bounded on $\mathbb{R}$.

**Step 1: Taylor expansion with Lagrange remainder.**

Fix $x \in \mathbb{R}$, $t > 0$, and $z \in \mathbb{R}$. Set $h = \sqrt{t}\,z$.
Since $f \in C^\infty(\mathbb{R}) \subset C^4(\mathbb{R})$, Taylor's theorem wit
h Lagrange remainder (expanded to order 3) gives

$$f(x+h) = f(x) + h\,f'(x) + \frac{h^2}{2}\,f''(x) + \frac{h^3}{6}\,f'''(x) + \f
rac{h^4}{24}\,f^{(4)}(\xi),$$

where $\xi = \xi(x,z,t)$ is some point between $x$ and $x + \sqrt{t}\,z$.

Substituting $h = \sqrt{t}\,z$:

$$f(x+\sqrt{t}\,z) = f(x) + \sqrt{t}\,z\,f'(x) + \frac{t\,z^2}{2}\,f''(x) + \fra
c{t^{3/2}\,z^3}{6}\,f'''(x) + \frac{t^2\,z^4}{24}\,f^{(4)}(\xi).$$

Rearranging:

$$f(x+\sqrt{t}\,z) - f(x) - \frac{t}{2}\,f''(x) = \sqrt{t}\,z\,f'(x) + \frac{t^{
3/2}\,z^3}{6}\,f'''(x) + \frac{t^2\,z^4}{24}\,f^{(4)}(\xi).$$

**Step 2: Integrate against the Gaussian weight.**

Multiplying both sides by $e^{-z^2/2}$ and integrating over $\mathbb{R}$:

$$\int_{\mathbb{R}}\!\left(f(x+\sqrt{t}\,z)-f(x)-\frac{t}{2}\,f''(x)\right)e^{-z
^2/2}\,dz = I_1 + I_2 + I_3,$$

where

$$I_1 = \sqrt{t}\,f'(x)\int_{\mathbb{R}} z\,e^{-z^2/2}\,dz, \qquad I_2 = \frac{t
^{3/2}}{6}\,f'''(x)\int_{\mathbb{R}} z^3\,e^{-z^2/2}\,dz,$$

$$I_3 = \frac{t^2}{24}\int_{\mathbb{R}} z^4\,f^{(4)}(\xi(x,z,t))\,e^{-z^2/2}\,dz
.$$

The integrands in $I_1$ and $I_2$ are odd functions ($z\,e^{-z^2/2}$ and $z^3 e^
{-z^2/2}$ respectively) integrated over the symmetric domain $(-\infty, \infty)$
, so

$$I_1 = 0, \qquad I_2 = 0.$$

Therefore:

$$g_t(x) = \frac{1}{t}\cdot I_3 = \frac{t}{24}\int_{\mathbb{R}} z^4\,f^{(4)}(\xi
(x,z,t))\,e^{-z^2/2}\,dz.$$

**Step 3: Uniform bound.**

Since $f \in C^\infty_K(\mathbb{R})$, the fourth derivative $f^{(4)}$ is continu
ous with compact support, hence bounded. Set

$$M := \sup_{y \in \mathbb{R}} |f^{(4)}(y)| < \infty.$$

For every $x \in \mathbb{R}$, $z \in \mathbb{R}$, and $t > 0$, the point $\xi(x,
z,t) \in \mathbb{R}$, so $|f^{(4)}(\xi(x,z,t))| \leq M$. Thus

$$|g_t(x)| \leq \frac{t}{24}\int_{\mathbb{R}} z^4\,|f^{(4)}(\xi(x,z,t))|\,e^{-z^
2/2}\,dz \leq \frac{t\,M}{24}\int_{\mathbb{R}} z^4\,e^{-z^2/2}\,dz.$$

**Step 4: Evaluate the Gaussian moment.**

Using the standard formula $\int_{-\infty}^{\infty} z^{2n}\,e^{-z^2/2}\,dz = \sq
rt{2\pi}\,(2n-1)!!$, with $n=2$:

$$\int_{\mathbb{R}} z^4\,e^{-z^2/2}\,dz = \sqrt{2\pi}\cdot 3!! = \sqrt{2\pi}\cdo
t 3 = 3\sqrt{2\pi}.$$

**Step 5: Conclusion.**

Combining Steps 3 and 4:

$$|g_t(x)| \leq \frac{t\,M}{24}\cdot 3\sqrt{2\pi} = \frac{t\,M\,\sqrt{2\pi}}{8}.
$$

The right-hand side is **independent of $x$**, so

$$\sup_{x \in \mathbb{R}} |g_t(x)| \leq \frac{M\,\sqrt{2\pi}}{8}\,t \;\longright
arrow\; 0 \quad \text{as } t \to 0^+.$$

Hence $g_t \to 0$ uniformly on $\mathbb{R}$ as $t \to 0^+$. $\blacksquare$
