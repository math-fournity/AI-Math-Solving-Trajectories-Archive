## Proof

**Key Observation.** The function $f(x) = a^x$ is convex on $[0,\infty)$ for eve
ry $a > 0$, since $f''(x) = (\ln a)^2 \, a^x \geq 0$.

**Step 1: Fix $r$ and solve the continuous relaxation.**

For fixed $r$, consider the continuous problem: maximize $\Phi(x_1, \dots, x_r)
= \sum_{i=1}^r a^{x_i}$ over the simplex
$$\Delta_r = \Big\{(x_1, \dots, x_r) \in \mathbb{R}^r : x_i \geq 0,\; \sum_{i=1}
^r x_i = k\Big\}.$$

Since each $a^{x_i}$ is convex, $\Phi$ is convex (sum of convex functions). A st
andard result states that **a convex function on a compact convex set attains it
s maximum at an extreme point**. Indeed, if $x = \lambda y + (1-\lambda)z$ with
$0 < \lambda < 1$, then $\Phi(x) \leq \lambda \Phi(y) + (1-\lambda)\Phi(z) \leq
\max(\Phi(y), \Phi(z))$, so no interior point can strictly exceed all extreme po
ints.

The extreme points (vertices) of $\Delta_r$ are $(k, 0, \dots, 0)$, $(0, k, 0, \
dots, 0)$, $\dots$, $(0, \dots, 0, k)$. At every vertex:
$$\Phi = a^k + \underbrace{a^0 + \cdots + a^0}_{r-1} = a^k + (r-1).$$

**Step 2: The integer maximum coincides.**

The vertex $(k, 0, \dots, 0)$ is an integer point (all coordinates are non-negat
ive integers). Since the integer feasible set is a subset of $\Delta_r$, and the
 continuous maximum $a^k + (r-1)$ is achieved at an integer point, the maximum o
ver integer points is also $a^k + (r-1)$.

**Step 3: Maximize over $r$.**

We now maximize $g(r) = a^k + (r - 1)$ over $r \in \{1, 2, \dots, k\}$. Since $g
$ is strictly increasing in $r$, the maximum is at $r = k$:
$$g(k) = a^k + k - 1.$$

**Step 4: The maximum is attained.**

Take $r = k$ with $k_1 = k$ and $k_2 = k_3 = \cdots = k_k = 0$. Then $\sum k_i =
 k$, all $k_i \in \mathbb{N}$, and:
$$a^{k_1} + a^{k_2} + \cdots + a^{k_k} = a^k + \underbrace{1 + 1 + \cdots + 1}_{
k-1} = a^k + k - 1.$$

**Verification of edge cases:**
- $a = 1$: $a^k + k - 1 = 1 + k - 1 = k$. Indeed every term equals $1$, so the s
um is $r$, maximized at $r = k$ giving $k$. ✓
- $k = 1$: $a^1 + 1 - 1 = a$. The only possibility is $r = 1$, $k_1 = 1$, giving
 $a$. ✓

---

**The maximal value is $\boxed{a^k + k - 1}$.**
