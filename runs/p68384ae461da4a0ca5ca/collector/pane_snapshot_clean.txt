## Solution

**Answer: The arc length is $a + b$.**

### Setup

Since $f\colon[0,a]\to[0,b]$ is onto, continuous, and non-decreasing, we have $f
(0)=0$ and $f(a)=b$. Let

$$L=\sup_{\mathcal P}\sum_{i=1}^{n}\sqrt{(\Delta x_i)^2+(\Delta y_i)^2},\qquad \
Delta x_i=x_i-x_{i-1},\;\Delta y_i=f(x_i)-f(x_{i-1}),$$

where the supremum runs over all partitions $\mathcal P=\{0=x_0<x_1<\dots<x_n=a\
}$.

### Upper bound: $L\le a+b$

For every partition, since $\Delta x_i,\Delta y_i\ge 0$ (using $f$ non-decreasin
g),

$$\sqrt{(\Delta x_i)^2+(\Delta y_i)^2}\le \Delta x_i+\Delta y_i.$$

Summing and using that $f$ is non-decreasing (so the $\Delta y_i$ telescope):

$$\sum_i\sqrt{(\Delta x_i)^2+(\Delta y_i)^2}\le \sum_i\Delta x_i+\sum_i\Delta y_
i = a+\bigl(f(a)-f(0)\bigr)=a+b.$$

Hence $L\le a+b$.

### Lower bound: $L\ge a+b$ (uses $f'=0$ a.e.)

Let $\mu=dx$ be Lebesgue measure and let $\nu=df$ be the Stieltjes measure assoc
iated to the non-decreasing continuous function $f$; thus $\mu([0,a])=a$ and $\n
u([0,a])=b$.

Since $f'=0$ a.e., the Lebesgue decomposition of $\nu$ has zero absolutely-conti
nuous part: $\nu$ is **purely singular** with respect to $\mu$. Therefore $\mu\p
erp\nu$: there exists a Borel set $S\subset[0,a]$ with $\mu(S)=0$ and $\nu([0,a]
\setminus S)=0$.

Fix $\varepsilon>0$. By outer regularity of Lebesgue measure, choose an open set
 $U\supset S$ with $\mu(U)<\varepsilon$. Then

$$\nu([0,a]\setminus U)=0,$$

so $f$ has **zero variation** on $[0,a]\setminus U$. Being non-decreasing and co
ntinuous, $f$ is constant on every connected component (closed interval or point
) of $[0,a]\setminus U$.

Write $U$ (relative to $[0,a]$) as a disjoint union of open intervals $(\alpha_j
,\beta_j)$. On each complementary component $f$ is constant, while on each gap $
(\alpha_j,\beta_j)$ the increase is $\Delta f_j:=f(\beta_j)-f(\alpha_j)\ge 0$, a
nd

$$\sum_j \Delta f_j = b,\qquad \sum_j(\beta_j-\alpha_j)=\mu(U)<\varepsilon.$$

Consider the partition $\mathcal P=\{0,a\}\cup\{\alpha_j,\beta_j\}_j$, ordered.
Each subinterval $[p_{i-1},p_i]$ is either

- a gap $[\alpha_j,\beta_j]$, contributing $\sqrt{(\beta_j-\alpha_j)^2+(\Delta f
_j)^2}\ge \Delta f_j$, or
- a complementary component $[c,d]$ on which $f$ is constant, contributing $d-c$
.

Summing,

$$\sum_i\sqrt{(\Delta x_i)^2+(\Delta y_i)^2}\;\ge\;\sum_j\Delta f_j+\sum_{\text{
compl}}(d-c)\;=\;b+\bigl(a-\mu(U)\bigr)\;>\;a+b-\varepsilon.$$

Since $\varepsilon>0$ is arbitrary, $L\ge a+b$.

### Conclusion

Combining both bounds, $L=a+b$.
