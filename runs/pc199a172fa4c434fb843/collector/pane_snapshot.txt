Looking at this problem, I need to find the maximum n such that n marked cells o
n an n×n board can hit every axis-aligned rectangle of area ≥ n.

**Answer: n = 5**

## Proof

**Setup.** Place the board as rows and columns $\{1,\ldots,n\}$. A rectangle of
height $h$ and width $w$ (with $hw \ge n$) occupies $h$ consecutive rows and $w$
 consecutive columns. We mark $n$ cells.

**Step 1: The marked cells form a permutation.** The rectangle consisting of a s
ingle full row ($1 \times n$, area $n$) must contain a marked cell, so every row
 has at least one mark. With $n$ marks in $n$ rows, each row has exactly one. Si
milarly, each full column ($n \times 1$) must contain a mark, so each column has
 exactly one. Thus the marks form a permutation $\pi$: cell $(i, \pi(i))$ is mar
ked for each $i$.

**Step 2: Gap condition.** For a row interval $I$ of $h$ consecutive rows, let $
S = \pi(I) = \{\pi(i) : i \in I\}$, a set of $h$ values in $\{1,\ldots,n\}$. The
 rectangle with rows $I$ and any $w$ consecutive columns avoids all marks iff so
me interval of $w$ consecutive columns is disjoint from $S$. This happens iff $S
$ has a gap of $\ge w$ consecutive non-elements. Defining $G(S)$ as the maximum
number of consecutive non-elements of $S$ in $\{1,\ldots,n\}$, the constraint fo
r height $h$ is:

$$G(\pi(I)) \le \lceil n/h \rceil - 1 \quad \text{for every interval } I \text{
of } h \text{ consecutive rows.}$$

**Step 3: $n = 5$ is achievable.** Take $\pi = (1, 3, 5, 2, 4)$, marking cells $
(1,1),(2,3),(3,5),(4,2),(5,4)$.

The binding constraints (those with $hw \ge 5$ and minimal $w$ for each $h$) are
:

| $h$ | $w_0 = \lceil 5/h \rceil$ | Required $G \le$ |
|-----|--------------------------|-------------------|
| 1 | 5 | 4 (trivial) |
| 2 | 3 | 2 |
| 3 | 2 | 1 |
| 4 | 2 | 1 |
| 5 | 1 | 0 (trivial) |

**$h=2$ (need $G \le 2$):** Consecutive pairs and their gaps:
- $\{1,3\}$: gaps $0, 1, 2$. $G=2$ ✓
- $\{3,5\}$: gaps $2, 1, 0$. $G=2$ ✓
- $\{5,2\}=\{2,5\}$: gaps $1, 2, 0$. $G=2$ ✓
- $\{2,4\}$: gaps $1, 1, 1$. $G=1$ ✓

**$h=3$ (need $G \le 1$):**
- $\{1,3,5\}$: gaps $0,1,1,0$. $G=1$ ✓
- $\{3,5,2\}=\{2,3,5\}$: gaps $1,0,1,0$. $G=1$ ✓
- $\{5,2,4\}=\{2,4,5\}$: gaps $1,1,0,0$. $G=1$ ✓

**$h=4$ (need $G \le 1$):**
- $\{1,3,5,2\}=\{1,2,3,5\}$: gaps $0,0,0,1,0$. $G=1$ ✓
- $\{3,5,2,4\}=\{2,3,4,5\}$: gaps $1,0,0,0,0$. $G=1$ ✓

All constraints satisfied. ✓

**Step 4: $n = 6$ is impossible.** The binding constraints are:

| $h$ | $w_0 = \lceil 6/h \rceil$ | Required $G \le$ |
|-----|--------------------------|-------------------|
| 2 | 3 | 2 |
| 3 | 2 | 1 |

**$h=2$ constraint forces alternation.** For two values $a < b$ in $\{1,\ldots,6
\}$ with $G \le 2$: the gaps $a{-}1$, $b{-}a{-}1$, $6{-}b$ must each be $\le 2$,
 giving $a \le 3$ and $b \ge 4$. So every consecutive pair $\{\pi(i), \pi(i{+}1)
\}$ must have one value in $L = \{1,2,3\}$ and one in $H = \{4,5,6\}$. This forc
es strict alternation: WLOG $\pi(1),\pi(3),\pi(5) \in L$ and $\pi(2),\pi(4),\pi(
6) \in H$.

**$h=3$ constraint: valid 3-element sets with $G \le 1$ in $\{1,\ldots,6\}$.** T
he four gaps sum to $3$ with each $\le 1$, so exactly three gaps equal $1$ and o
ne equals $0$. The four possible sets are:
$$\{1,3,5\},\quad \{2,3,5\},\quad \{2,4,5\},\quad \{2,4,6\}.$$

**Deriving the contradiction.** Consider $\pi(\{1,2,3\})$: it has 2 elements fro
m $L$ and 1 from $H$. Among the valid sets, only $\{1,3,5\}$ and $\{2,3,5\}$ hav
e this composition—both contain $5 \in H$. So $\pi(2) = 5$.

Consider $\pi(\{2,3,4\})$: it has 2 elements from $H$ and 1 from $L$. Among the
valid sets, only $\{2,4,5\}$ and $\{2,4,6\}$ have this composition—both contain
$2 \in L$. So $\pi(3) = 2$.

Since $\pi(2) = 5$ and $\pi(\{2,3,4\}) = \{5, 2, \pi(4)\}$ must be a valid set:
$\{2,4,5\}$ works (giving $\pi(4)=4$), while $\{2,4,6\}$ would require $5 \in \{
4,6\}$, impossible. So $\pi(4) = 4$.

Now consider $\pi(\{3,4,5\}) = \{2, 4, \pi(5)\}$. Since $\pi(3) = 2$ and $\pi$ i
s a permutation with $\pi(5) \in L \setminus \{2\} = \{1,3\}$:
- $\pi(5) = 1$: set is $\{1,2,4\}$, gaps $0,0,1,2$, $G = 2 > 1$. ✗
- $\pi(5) = 3$: set is $\{2,3,4\}$, gaps $1,0,0,2$, $G = 2 > 1$. ✗

Neither satisfies the $h=3$ constraint. **Contradiction.** (The case $\pi(1) \in
 H$ is identical by the symmetry $j \mapsto 7-j$.)

**Conclusion.** Since $n = 5$ is achievable and $n = 6$ is not, the maximum $n$
is $\boxed{5}$.
