Looking at this problem, I need to find the maximal α such that (x³+y³+z³)/3 ≥ x
yz + α|(x-y)(y-z)(z-x)| for all non-negative reals x, y, z.

**Proof.**

**Step 1: Reformulation.** The inequality is equivalent to:
$$\frac{x^3+y^3+z^3 - 3xyz}{3} \geq \alpha\,|(x-y)(y-z)(z-x)|.$$

Using the identity $x^3+y^3+z^3-3xyz = (x+y+z)\cdot\frac{(x-y)^2+(y-z)^2+(z-x)^2
}{2}$, we need:
$$\frac{(x+y+z)\bigl[(x-y)^2+(y-z)^2+(z-x)^2\bigr]}{6} \geq \alpha\,|(x-y)(y-z)(
z-x)|.$$

So $\alpha_{\max} = \inf \frac{(x+y+z)\bigl[(x-y)^2+(y-z)^2+(z-x)^2\bigr]}{6\,|(
x-y)(y-z)(z-x)|}$ over all $x,y,z \geq 0$ with distinct values.

**Step 2: Reduction by symmetry and homogeneity.** The expression is symmetric a
nd homogeneous of degree 0, so WLOG $x \geq y \geq z \geq 0$. Set $a = x-y \geq
0$, $b = y-z \geq 0$, so $x-z = a+b$. Then:
- $(x-y)^2+(y-z)^2+(z-x)^2 = a^2+b^2+(a+b)^2 = 2(a^2+ab+b^2)$,
- $|(x-y)(y-z)(z-x)| = ab(a+b)$,
- $x+y+z = 3z + a + 2b$.

The ratio becomes:
$$R = \frac{(3z+a+2b)(a^2+ab+b^2)}{3\,ab(a+b)}.$$

Since $a^2+ab+b^2 > 0$ and the coefficient of $z$ is $3(a^2+ab+b^2) > 0$, **$R$
is strictly increasing in $z$**, so the infimum is at $z=0$.

**Step 3: One-variable optimization.** With $z=0$, set $r = a/b > 0$ (by homogen
eity):
$$h(r) = \frac{(r+2)(r^2+r+1)}{3r(r+1)} = \frac{r^3+3r^2+3r+2}{3r(r+1)} = \frac{
(r+1)^3+1}{3r(r+1)}.$$

Setting $u = r+1 > 1$, we minimize:
$$g(u) = \frac{u^3+1}{3u(u-1)}, \quad u > 1.$$

**Step 4: Finding the critical point.** Computing $g'(u)$:
$$g'(u) = \frac{3(u^4 - 2u^3 - 2u + 1)}{(3u^2-3u)^2}.$$

Setting $u^4 - 2u^3 - 2u + 1 = 0$: this is a palindromic polynomial. Dividing by
 $u^2$ and substituting $s = u + 1/u$:
$$s^2 - 2s - 2 = 0 \implies s = 1 + \sqrt{3} \quad (\text{since } s > 2 \text{ f
or } u > 1).$$

So $u + 1/u = 1+\sqrt{3}$, giving $u = \frac{(1+\sqrt{3})+\sqrt{2\sqrt{3}}}{2}$.

**Step 5: Computing the minimum value.** Since $g(u) \to \infty$ as $u \to 1^+$
and as $u \to \infty$, this unique critical point is the global minimum. At this
 point, $u^2 = su - 1$ where $s = 1+\sqrt{3}$.

**Claim:** $g = \frac{u^2+1}{u^2-1}$ at the critical point. Indeed, the identity
 $(u^3+1)(u^2-1) = 3u(u-1)(u^2+1)$ is equivalent to $u^5 - 3u^4 + 2u^3 - 2u^2 +
3u - 1 = 0$, which follows from $u^4 = 2u^3 + 2u - 1$ (the critical point equati
on) by substitution. $\checkmark$

Therefore:
$$g_{\min} = \frac{u^2+1}{u^2-1} = \frac{u+1/u}{u-1/u} = \frac{s}{\sqrt{s^2-4}}
= \frac{1+\sqrt{3}}{\sqrt{2\sqrt{3}}}.$$

Squaring: $g_{\min}^2 = \frac{(1+\sqrt{3})^2}{2\sqrt{3}} = \frac{4+2\sqrt{3}}{2\
sqrt{3}} = \frac{3+2\sqrt{3}}{3}$.

**Step 6: Equality is achieved.** At $z=0$, $a/b = u-1 = \frac{(1+\sqrt{3})+\sqr
t{2\sqrt{3}}}{2} - 1$, the ratio equals $g_{\min}$, so the inequality is tight.
For all other values, the ratio is larger. Hence this is the maximal $\alpha$.

$$\boxed{\alpha = \sqrt{\frac{3+2\sqrt{3}}{3}} = \frac{1+\sqrt{3}}{\sqrt{2\sqrt{
3}}}}$$
