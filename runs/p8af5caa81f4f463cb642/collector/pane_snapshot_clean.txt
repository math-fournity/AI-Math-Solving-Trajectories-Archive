## Proof

We seek the positive integer $n$ closest to $\sqrt{123456789}$.

**Step 1: Locate $\sqrt{123456789}$ between consecutive integers.**

Compute:
$$11111^2 = 123{,}454{,}321$$
$$11112^2 = 11111^2 + 2\cdot 11111 + 1 = 123{,}454{,}321 + 22{,}223 = 123{,}476{
,}544$$

Since
$$123{,}454{,}321 < 123{,}456{,}789 < 123{,}476{,}544,$$
we have $11111 < \sqrt{123456789} < 11112$.

**Step 2: Determine which endpoint is closer.**

The midpoint is $11111.5$. Compute:
$$(11111.5)^2 = 11111^2 + 11111 + 0.25 = 123{,}454{,}321 + 11{,}111.25 = 123{,}4
65{,}432.25$$

Since
$$123{,}456{,}789 < 123{,}465{,}432.25,$$
we get $\sqrt{123456789} < 11111.5$, so $\sqrt{123456789}$ is closer to $11111$
than to $11112$.

**Verification via direct differences:**
$$123{,}456{,}789 - 123{,}454{,}321 = 2{,}468 \quad (\text{distance from } 11111
^2)$$
$$123{,}476{,}544 - 123{,}456{,}789 = 19{,}755 \quad (\text{distance from } 1111
2^2)$$

Since $2{,}468 < 19{,}755$, the value $123{,}456{,}789$ lies much closer to $111
11^2$, confirming $\sqrt{123456789}$ is nearest to $11111$.

**Conclusion:** The positive integer $n$ such that $\frac{1}{n}$ is closest to $
\frac{1}{\sqrt{123456789}}$ (equivalently, $n$ closest to $\sqrt{123456789}$) is

$$\boxed{n = 11111}$$
