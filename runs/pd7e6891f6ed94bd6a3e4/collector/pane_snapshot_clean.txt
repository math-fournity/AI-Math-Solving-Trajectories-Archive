## Proof

**Setup.** Let $n < 0$ be square-free and even. Since $n$ is even and square-fre
e, $2 \mid n$ but $4 \nmid n$, so $n \equiv 2 \pmod{4}$. The discriminant of $K
= \mathbb{Q}(\sqrt{n})$ is therefore
$$D = 4n.$$
Since $n = 2 \cdot p_1 \cdots p_k$ where $p_1, \ldots, p_k$ are distinct odd pri
mes, the distinct prime divisors of $D = 4n$ are exactly $\{2, p_1, \ldots, p_k\
}$ — the same as the distinct prime divisors of $n$. Setting $t = \omega(n)$ (th
e number of distinct prime divisors of $n$), we have $t = k + 1$.

**Key tool — Gauss's Genus Theory.** For an imaginary quadratic field $K = \math
bb{Q}(\sqrt{d})$ ($d < 0$) with discriminant $D$ having $t$ distinct prime divis
ors, the **2-rank of the class group** $\mathrm{Cl}(K)$ is exactly
$$\mathrm{2\text{-}rank}(\mathrm{Cl}(K)) = t - 1.$$
This is a classical result: the number of genera is $|\mathrm{Cl}/\mathrm{Cl}^2|
 = 2^{t-1}$, and since $|\mathrm{Cl}/\mathrm{Cl}^2| = 2^{\text{2-rank}}$, the 2-
rank equals $t - 1$. For imaginary quadratic fields this holds without exception
 (unlike real quadratic fields, where the narrow vs. ordinary class group distin
ction introduces a correction depending on the norm of the fundamental unit).

**Applying genus theory.** Since $n < 0$, $K$ is imaginary, so:
$$\mathrm{2\text{-}rank}(\mathrm{Cl}(K)) = \omega(n) - 1.$$

The class number $h(K) = |\mathrm{Cl}(K)|$ is **even** if and only if the 2-rank
 is at least $1$, i.e.,
$$\omega(n) - 1 \geq 1 \iff \omega(n) \geq 2.$$

**Checking the boundary case $\omega(n) = 1$.** The only negative, square-free,
even integer with exactly one prime factor is $n = -2$. Here $D = -8$, $t = 1$,
so the 2-rank is $0$ and the class number is odd. Indeed, $h(\mathbb{Q}(\sqrt{-2
})) = 1$.

**Verification for $\omega(n) = 2$.** For example:
- $n = -6$: $D = -24$, $t = 2$, 2-rank $= 1$. Indeed $h(\mathbb{Q}(\sqrt{-6})) =
 2$. ✓
- $n = -10$: $D = -40$, $t = 2$, 2-rank $= 1$. Indeed $h(\mathbb{Q}(\sqrt{-10}))
 = 2$. ✓
- $n = -14$: $D = -56$, $t = 2$, 2-rank $= 1$. Indeed $h(\mathbb{Q}(\sqrt{-14}))
 = 4$. ✓

In every case with $\omega(n) = 2$, genus theory guarantees 2-rank $\geq 1$, hen
ce the class number is even.

**Conclusion.** With $\omega(n) = 1$ (only $n = -2$), the class number is odd. W
ith $\omega(n) \geq 2$, genus theory forces the 2-rank to be at least $1$, guara
nteeing an even class number. Therefore the minimum number of prime factors requ
ired is:

$$\boxed{2}$$
