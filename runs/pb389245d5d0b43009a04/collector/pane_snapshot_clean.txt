## Setting Up Segment Lengths

Let AC = BD = CE = s. Since X lies on AC with AX = 6, we get XC = s − 6. Since Y
 lies on CE with YE = 7, we get CY = s − 7.

**Order on BD:** For a convex cyclic pentagon with vertices A, B, C, D, E in ord
er, the diagonals AC & BD meet at X, and BD & CE meet at Y, with order B, X, Y,
D (verified by checking that the alternative order B, Y, X, D would require BX >
 XY, giving negative segments).

Let BX = p, YD = q. Then BD = p + 4 + q = s, so q = s − p − 4.

**Intersecting Chords at X:** AX · XC = BX · XD, where XD = 4 + q = s − p:
$$6(s-6) = p(s-p) \quad \Rightarrow \quad s(p-6) = (p-6)(p+6)$$

For p ≠ 6: **s = p + 6**.

**Intersecting Chords at Y:** BY · YD = CY · YE, where BY = p + 4:
$$(p+4)(s-p-4) = 7(s-7)$$

Substituting s = p + 6:
$$(p+4)(2) = 7(p-1) \implies 2p+8 = 7p-7 \implies p = 3$$

So **s = 9, p = 3, q = 2**: AC = BD = CE = 9, BX = 3, XD = 6, BY = 7, YD = 2, CY
 = 2, XC = 3.
