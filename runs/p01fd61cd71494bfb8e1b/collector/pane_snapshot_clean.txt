## Proof

**Step 1: Simplify the functional.**

Expand the integrand:
$$(f(x) - x^2)^2 - x^4 = f(x)^2 - 2x^2 f(x) + x^4 - x^4 = f(x)^2 - 2x^2 f(x).$$

Equivalently, re-complete the square in a different way:
$$(f(x) - x^2)^2 - x^4 = (f(x) - x^2)^2 - x^4.$$

Therefore:
$$\phi(f) = \int_{-1}^{1}(f(x) - x^2)^2\,dx - \int_{-1}^{1} x^4\,dx = \|f - x^2\
|^2_{L^2[-1,1]} - \frac{2}{5},$$

since $\int_{-1}^{1} x^4\,dx = \left[\frac{x^5}{5}\right]_{-1}^{1} = \frac{1}{5}
 - \left(-\frac{1}{5}\right) = \frac{2}{5}$.

**Step 2: Minimize.**

The functional decomposes as:
$$\phi(f) = \|f - x^2\|^2_{L^2} - \frac{2}{5}.$$

Since $\|f - x^2\|^2_{L^2} \geq 0$ for all $f \in L^2_{\mathbb{R}}[-1,1]$, with
equality if and only if $f = x^2$ a.e., we obtain:
$$\phi(f) \geq -\frac{2}{5} \quad \text{for all } f \in L^2_{\mathbb{R}}[-1,1].$
$

**Step 3: Check that the minimizer belongs to $\mathcal{M}$.**

The function $f^*(x) = x^2$ is **even** ($f^*(-x) = (-x)^2 = x^2 = f^*(x)$), hen
ce it is **not odd**. Under the interpretation that $\mathcal{M}$ is the set of
functions "not necessarily odd" (i.e., the full space $L^2_{\mathbb{R}}[-1,1]$,
or equivalently the complement of the odd functions), $f^* = x^2 \in \mathcal{M}
$.

At $f = f^*$:
$$\phi(f^*) = \|x^2 - x^2\|^2 - \frac{2}{5} = 0 - \frac{2}{5} = -\frac{2}{5}.$$

**Step 4: Conclusion.**

The lower bound $-\frac{2}{5}$ is achieved by $f(x) = x^2 \in \mathcal{M}$, so t
he infimum is attained:

$$\inf_{f \in \mathcal{M}} \phi(f) = -\frac{2}{5}.$$
