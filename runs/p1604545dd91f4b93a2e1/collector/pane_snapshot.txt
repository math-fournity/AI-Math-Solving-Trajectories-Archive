## Proof

We work within Euclid's framework (Book X). A **fifth apotome** is an irrational
 $n = a - b$ ($a > b > 0$) such that:

1. $a$ and $b$ are commensurable in square (i.e., $a^2/b^2 \in \mathbb{Q}$) but
**incommensurable in length** (i.e., $a/b \notin \mathbb{Q}$),
2. $h = \sqrt{a^2 - b^2}$ is **incommensurable** with $a$ (i.e., $h/a \notin \ma
thbb{Q}$),
3. $b$ is **commensurable** with the given rationally expressible number $p$ (i.
e., $b/p \in \mathbb{Q}$).

---

### Construction

Set

$$b = p, \qquad a = p\sqrt{2}.$$

Then define

$$n = a - b = p\sqrt{2} - p = p(\sqrt{2} - 1),$$

and

$$h = \sqrt{a^2 - b^2} = \sqrt{2p^2 - p^2} = \sqrt{p^2} = p.$$

---

### Verification of all conditions

**(a) $a > b$.** Since $\sqrt{2} > 1$ and $p > 0$ (a rationally expressible numb
er is positive), we have $a = p\sqrt{2} > p = b$. ✓

**(b) $b$ and $p$ are commensurable.** $b/p = p/p = 1 \in \mathbb{Q}$. ✓

**(c) $a^2 = b^2 + h^2$.**
$$b^2 + h^2 = p^2 + p^2 = 2p^2 = (p\sqrt{2})^2 = a^2.$$ ✓

**(d) $h$ is incommensurable with $a$.**
$$\frac{h}{a} = \frac{p}{p\sqrt{2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2} \n
otin \mathbb{Q},$$
since $\sqrt{2}$ is irrational. Hence $h$ and $a$ are incommensurable. ✓

**(e) $a$ and $b$ are commensurable in square but incommensurable in length** (r
equired for apotome classification).

- *Commensurable in square:* $\dfrac{a^2}{b^2} = \dfrac{2p^2}{p^2} = 2 \in \math
bb{Q}$. ✓
- *Incommensurable in length:* $\dfrac{a}{b} = \dfrac{p\sqrt{2}}{p} = \sqrt{2} \
notin \mathbb{Q}$. ✓

**(f) $n$ is irrational (it is genuinely an apotome).** Since $p$ is rational (n
onzero) and $\sqrt{2}$ is irrational, $n = p(\sqrt{2}-1)$ is irrational. ✓

---

### Conclusion

All conditions for a **fifth apotome** are satisfied:

| Condition | Status |
|---|---|
| $a > b$ | $\sqrt{2} > 1$ ✓ |
| $a, b$ commensurable in square | $a^2/b^2 = 2 \in \mathbb{Q}$ ✓ |
| $a, b$ incommensurable in length | $a/b = \sqrt{2} \notin \mathbb{Q}$ ✓ |
| $b$ commensurable with $p$ | $b/p = 1 \in \mathbb{Q}$ ✓ |
| $a^2 = b^2 + h^2$ | $2p^2 = p^2 + p^2$ ✓ |
| $h$ incommensurable with $a$ | $h/a = 1/\sqrt{2} \notin \mathbb{Q}$ ✓ |

The fifth apotome is:

$$\boxed{n = p(\sqrt{2} - 1), \quad a = p\sqrt{2}, \quad b = p, \quad h = p.}$$
