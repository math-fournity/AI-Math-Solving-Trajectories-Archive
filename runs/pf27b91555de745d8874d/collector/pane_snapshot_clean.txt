## Proof

Let $u_i = \cot(x_i) \geq 0$ for $i = 1,2,3,4$ (corresponding to $x,y,z,t$). Sin
ce $x_i \in (0, \pi/2]$, we have $u_i \geq 0$.

**Reformulating the constraint.** Since $\cot^2(x_i) = \frac{\cos^2(x_i)}{\sin^2
(x_i)}$ and $\frac{1}{1+\cot^2(x_i)} = \sin^2(x_i) = 1 - \cos^2(x_i)$, we get $\
cos^2(x_i) = \frac{u_i^2}{1+u_i^2}$. The constraint becomes:

$$\sum_{i=1}^{4} \frac{u_i^2}{1+u_i^2} = 1 \iff \sum_{i=1}^{4}\left(1 - \frac{1}
{1+u_i^2}\right) = 1 \iff \sum_{i=1}^{4} \frac{1}{1+u_i^2} = 3.$$

We wish to minimize $\sum u_i$.

**Key inequality.** For all $u \geq 0$:
$$u \;\geq\; \frac{2u^2}{1+u^2}.$$

*Proof of inequality:* This is equivalent to $u(1+u^2) \geq 2u^2$, i.e., $u + u^
3 \geq 2u^2$, i.e., $u(u^2 - 2u + 1) \geq 0$, i.e., $u(u-1)^2 \geq 0$, which hol
ds for all $u \geq 0$. $\square$

**Applying the inequality.** Summing over all four indices:

$$\sum_{i=1}^{4} u_i \;\geq\; 2\sum_{i=1}^{4} \frac{u_i^2}{1+u_i^2} = 2 \cdot 1
= 2.$$

**Equality condition.** Equality holds if and only if $u_i(u_i - 1)^2 = 0$ for e
very $i$, i.e., each $u_i \in \{0, 1\}$. The constraint $\sum \frac{1}{1+u_i^2}
= 3$ with $u_i \in \{0,1\}$ requires: if $k$ of the $u_i$ equal $1$ and $4-k$ eq
ual $0$, then $\frac{k}{2} + (4-k) = 3$, giving $k = 2$.

**Verification.** Take $u_1 = u_2 = 1$ and $u_3 = u_4 = 0$, corresponding to $x
= y = \pi/4$ and $z = t = \pi/2$:
- Constraint: $\cos^2(\pi/4) + \cos^2(\pi/4) + \cos^2(\pi/2) + \cos^2(\pi/2) = \
frac{1}{2} + \frac{1}{2} + 0 + 0 = 1$. ✓
- Objective: $\cot(\pi/4) + \cot(\pi/4) + \cot(\pi/2) + \cot(\pi/2) = 1 + 1 + 0
+ 0 = 2$. ✓

All angles lie in $(0, \pi/2]$. The minimum is achieved.

$$\boxed{\min\bigl(\cot x + \cot y + \cot z + \cot t\bigr) = 2}$$
