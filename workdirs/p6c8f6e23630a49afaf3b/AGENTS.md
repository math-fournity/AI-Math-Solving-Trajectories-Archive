# Problem

In the futuristic city of Omeira, a central server processes a specific data packet size, represented by an integer $N$ (where $N > 1$). 

To ensure network stability, the server runs a diagnostic routine. It attempts to distribute the data packet $N$ into smaller sub-channels. Specifically, for every single positive integer channel size smaller than $N$, the server attempts a division. Any data bits that do not fit perfectly into a channel (the remainder of the division) are shunted to a "latency buffer."

The system is designed such that if the total sum of all these buffered remainders is strictly less than the original packet size $N$, the configuration is considered "Hyper-Stable."

Identify all possible integer values for $N$ that result in a Hyper-Stable configuration.
