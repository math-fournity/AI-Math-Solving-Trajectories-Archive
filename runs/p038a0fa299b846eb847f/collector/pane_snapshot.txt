## Algorithm Ranequ

**Representation.** A partition of {1,…,n} is encoded as a *restricted growth st
ring* (RGS) $a_1 a_2 \cdots a_n$ where $a_1 = 1$ and $a_i \leq 1 + \max(a_1,\ldo
ts,a_{i-1})$. The value $a_i$ is the block label of element $i$. There is a bije
ction between RGSs of length $n$ and partitions of $\{1,\ldots,n\}$, so there ar
e $B(n)$ RGSs (the Bell number).

**Precomputation.** Define $T(L, m)$ = the number of ways to extend a partial pa
rtition that currently has $m$ blocks by adding $L$ more elements. This satisfie
s:

$$T(0, m) = 1, \qquad T(L, m) = m \cdot T(L-1, m) + T(L-1, m+1).$$

The recurrence holds because each new element either joins one of the $m$ existi
ng blocks ($m$ choices, each yielding $T(L{-1}, m)$ completions) or starts a new
 block ($1$ choice, yielding $T(L{-1}, m{+1})$ completions).

**Generation.**
1. Set $a_1 = 1$; let $m = 1$ (current block count).
2. For $i = 2, 3, \ldots, n$:
   - With probability $T(n{-}i,\; m{+}1)\,/\,T(n{-}i{+}1,\; m)$: set $a_i = m{+}
1$ (new block), $m \leftarrow m{+}1$.
   - Otherwise: pick $j$ uniformly from $\{1,\ldots,m\}$, set $a_i = j$ (join bl
ock $j$), $m$ unchanged.

**Probabilities sum to 1.** By the recurrence, $T(n{-}i{+}1, m) = m \cdot T(n{-}
i, m) + T(n{-}i, m{+}1)$, so:

$$\frac{T(n{-}i,\, m{+}1)}{T(n{-}i{+}1,\, m)} + \frac{m \cdot T(n{-}i,\, m)}{T(n
{-}i{+}1,\, m)} = 1. \quad\checkmark$$

The probability of joining a *specific* block $j$ is $\frac{m \cdot T(n{-}i,m)}{
T(n{-}i{+}1,m)} \cdot \frac{1}{m} = \frac{T(n{-}i,m)}{T(n{-}i{+}1,m)}$.

**Total count.** $T(n{-}1,\, 1) = B(n)$, since this counts all ways to build a p
artition of $\{1,\ldots,n\}$ starting from element 1 alone. (Verified: $T(0,1)=1
=B(1)$, $T(1,1)=2=B(2)$, $T(2,1)=5=B(3)$, $T(3,1)=15=B(4)$, etc.)

## Proof of Uniformity

**Theorem.** For every partition $\pi$ of $\{1,\ldots,n\}$, $\Pr[\text{Ranequ ou
tputs } \pi] = 1/B(n)$.

**Proof.** Fix any partition $\pi$ with RGS $a_1 \cdots a_n$. Let $m_i = \max(a_
1,\ldots,a_i)$ be the number of blocks after step $i$; note $m_1 = 1$.

Define $f(i, m) = T(n{-}i,\; m)$, the number of completions from step $i$ with $
m$ blocks. The recurrence gives $f(i{-}1,\; m) = m \cdot f(i, m) + f(i, m{+}1)$.

At step $i$, the probability of the specific choice that produces $a_i$ is:

- **New block** ($a_i = m_{i-1}{+}1$): $\;\dfrac{f(i,\; m_{i-1}{+}1)}{f(i{-}1,\;
 m_{i-1})} = \dfrac{f(i,\; m_i)}{f(i{-}1,\; m_{i-1})}$.

- **Join block $a_i$** ($a_i \leq m_{i-1}$, so $m_i = m_{i-1}$): $\;\dfrac{f(i,\
; m_{i-1})}{f(i{-}1,\; m_{i-1})} = \dfrac{f(i,\; m_i)}{f(i{-}1,\; m_{i-1})}$.

In both cases the factor is $\dfrac{f(i,\; m_i)}{f(i{-}1,\; m_{i-1})}$. Therefor
e:

$$\Pr[\pi] = \prod_{i=2}^{n} \frac{f(i,\; m_i)}{f(i{-}1,\; m_{i-1})}.$$

This **telescopes**:

$$\Pr[\pi] = \frac{f(n,\; m_n)}{f(1,\; m_1)} = \frac{T(0,\; m_n)}{T(n{-}1,\; 1)}
 = \frac{1}{B(n)}.$$

- $f(n, m_n) = T(0, m_n) = 1$: no elements remain to place.
- $f(1, m_1) = T(n{-}1, 1) = B(n)$: the total number of partitions.

Since $\Pr[\pi] = 1/B(n)$ for **every** partition $\pi$, and there are exactly $
B(n)$ partitions, the distribution is uniform. $\blacksquare$

**Intuition.** At each step, Ranequ chooses each possible continuation with prob
ability proportional to the number of full partitions consistent with that conti
nuation. Since every partition corresponds to exactly one sequence of choices, a
nd the product of these proportional probabilities telescopes to (number of comp
letions from the end) / (total partitions) = $1/B(n)$, all partitions are equall
y likely.
