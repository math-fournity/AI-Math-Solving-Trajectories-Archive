## Proof

We determine the operator norm $\|T\| = \sup_{\|f\|_{L^2}=1} \|Tf\|_{L^2}$ of th
e multiplication operator $Tf(x) = x^2 f(x)$ on $L^2([0,1])$.

**Upper bound.** For any $f \in L^2([0,1])$,
$$\|Tf\|_{L^2}^2 = \int_0^1 |x^2 f(x)|^2\,dx = \int_0^1 x^4 |f(x)|^2\,dx.$$
Since $x \in [0,1]$, we have $x^4 \le 1$, so
$$\|Tf\|_{L^2}^2 \le \int_0^1 |f(x)|^2\,dx = \|f\|_{L^2}^2.$$
Thus $\|Tf\|_{L^2} \le \|f\|_{L^2}$, giving $\|T\| \le 1$.

**Lower bound.** We exhibit functions nearly attaining the bound. For $n \ge 1$,
 let
$$f_n(x) = \sqrt{2n}\, x^{2n-1}, \qquad x \in [0,1].$$
This is a unit vector:
$$\|f_n\|_{L^2}^2 = 2n \int_0^1 x^{4n-2}\,dx = 2n \cdot \frac{1}{4n-1} \to 1 \qu
ad\text{(in fact } = \tfrac{2n}{4n-1}\text{)}.$$
More cleanly, normalize: set $g_n(x) = c_n x^{2n-1}$ with $c_n = (4n-1)^{1/2}$ s
o that $\|g_n\|_{L^2}=1$. Then
$$\|Tg_n\|_{L^2}^2 = c_n^2 \int_0^1 x^4 \cdot x^{4n-2}\,dx = (4n-1)\int_0^1 x^{4
n+2}\,dx = (4n-1)\cdot\frac{1}{4n+3}.$$
As $n \to \infty$,
$$\|Tg_n\|_{L^2}^2 = \frac{4n-1}{4n+3} \to 1,$$
so $\|Tg_n\|_{L^2} \to 1$. Hence $\|T\| \ge 1$.

**Conclusion.** Combining both bounds, $\|T\| = 1$.

*Remark.* This agrees with the general fact that a multiplication operator $M_\p
hi$ on $L^2$ has operator norm equal to $\|\phi\|_{L^\infty}$ (the essential sup
remum). Here $\phi(x)=x^2$ is continuous on $[0,1]$ with $\sup x^2 = 1$, so $\|T
\| = \|x^2\|_{L^\infty([0,1])} = 1$.
