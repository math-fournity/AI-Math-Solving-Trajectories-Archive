## Setting Up the Equation

For a fixed divisor $k$ of 1995, I need $x^2 + y^2 = k(x - y)$ with $x > y \geq
1$.

**Completing the square** (multiplying by 2):
$$(x - k)^2 + (y + k)^2 = 2k^2$$

Setting $u = x - k$, $v = y + k$, I get $u^2 + v^2 = 2k^2$ with $v \geq k+1$ and
 $v - u < 2k$.

## Reduction to Pythagorean Triples

Since $u^2 + v^2 = 2k^2$ (even), $u$ and $v$ share the same parity. Setting $a =
 (v+u)/2$, $b = (v-u)/2$:

$$a^2 + b^2 = k^2, \quad a > b > 0$$

This is exactly a **Pythagorean triple with hypotenuse $k$**. The parity conditi
on $v \equiv k \pmod{2}$ is automatic since $a^2 + b^2 = k^2$ implies $a + b \eq
uiv k \pmod{2}$.

**Key lemma**: The constraint $v \geq k+2$ (equivalently $a + b \geq k + 2$) is
always satisfied. Proof: $(a+b)^2 = k^2 + 2ab$, so we need $2ab \geq 4k+4$. The
smallest valid triple is $(4, 3, 5)$ where $ab = 12 = 2(5)+2$ (equality). For $b
 \geq 3$ and $k \geq 5$, the inequality $b\sqrt{k^2 - b^2} \geq 2k+2$ holds (ver
ified by checking $5k^2 - 8k - 85 \geq 0$ for $b=3$, with root at $k=5$). No tri
ples exist with $b < 3$.

Each Pythagorean triple $(a, b, k)$ with $a > b > 0$ yields **two** pairs:
$$(x, y) = \left(\frac{k + (a-b)}{2},\; \frac{(a+b) - k}{2}\right) \quad \text{a
nd} \quad \left(\frac{k - (a-b)}{2},\; \frac{(a+b) - k}{2}\right)$$

## Counting Triples per Divisor

The number of representations of $k^2$ as $a^2 + b^2$ with $a > b > 0$ is:

$$N = \frac{\prod_{p_i \equiv 1 \pmod{4}} (2e_i + 1) - 1}{2}$$

where $e_i$ is the exponent of prime $p_i \equiv 1 \pmod{4}$ in $k$.

For $1995 = 3 \times 5 \times 7 \times 19$:
- **Primes $\equiv 1 \pmod{4}$**: only $5$
- **Primes $\equiv 3 \pmod{4}$**: $3, 7, 19$ (don't contribute to representation
s)

So $N$ depends only on whether $5 \mid k$:
- If $5 \nmid k$: $N = 0$ → **0 pairs**
- If $5 \mid k$ (exponent 1): $\prod(2e_i+1) = 3$, so $N = (3-1)/2 = 1$ → **2 pa
