## 解答

**设置。** 设 $x = n + f$，其中 $n = \lfloor x \rfloor \geq 0$ 且 $0 \le f < 1$
。报警条件 $\{x\} > \alpha x$ 变为：

$$f > \alpha(n+f) \implies f(1-\alpha) > \alpha n \implies f > \frac{\alpha n}{1
-\alpha}$$

（要求 $\alpha < 1$，否则当 $\alpha \ge 1$ 时无解。）

**触发区间。** 对于每个满足 $\frac{\alpha n}{1-\alpha} < 1$ 的非负整数 $n$，即 $
n < \frac{1}{\alpha}-1$，触发集为 $f \in \left(\frac{\alpha n}{1-\alpha},\, 1\ri
ght)$，长度为 $1 - \frac{\alpha n}{1-\alpha} = \frac{1-\alpha(1+n)}{1-\alpha}$。
该公式也适用于 $n=0$（长度 $1$）。

**总长度。** 设 $K$ 为有效 $n$ 值的数量（$n = 0, 1, \dots, K-1$），因此 $K$ 是严
格小于 $\frac{1}{\alpha}$ 的最大整数。

$$L = \sum_{n=0}^{K-1} \frac{1-\alpha(1+n)}{1-\alpha} = \frac{1}{1-\alpha}\left[
K - \alpha\cdot\frac{K(K+1)}{2}\right] = \frac{K\bigl(2-\alpha(K+1)\bigr)}{2(1-\
alpha)}.$$

**代入 $\alpha = a/b$（既约分数）。** 则 $\frac{1}{\alpha} = \frac{b}{a}$。由于
$\gcd(a,b)=1$：

- 若 $a=1$：$\frac{1}{\alpha}=b$ 为整数，$K = b-1$，计算得 $L = b/2$。令其等于 $
101/5$ 得 $b = 202/5$，非整数。**不成立。**

- 若 $a \ge 2$：$\frac{b}{a}$ 非整数，$K = \lfloor b/a \rfloor$。记 $b = Ka + r$
，其中 $1 \le r \le a-1$。代入 $L = 101/5$ 并化简得：

$$a(K-1)(5K - 202) + 2r(5K - 101) = 0.$$

**符号分析。** 由于 $a, r, K-1 > 0$：
- $K \le 20$：两项均为负 → 不可能。
- $K \ge 41$：两项均为正 → 不可能。
- $K = 1$：得 $r = 0$ → 不可能。
- $21 \le K \le 40$：第一项为负，第二项为正 → 可能抵消。

此外，我们需要 $r \le a-1$，这要求 $N := (K-1)(202-5K) < D := 2(5K-101)$，化简为
 $K(-5K+197) < 0$，即 $K > 39.4$，因此 $K = 40$ 是**唯一**候选值。

**求解 $K = 40$：**

$$a \cdot 39 \cdot (-2) + 2r \cdot 99 = 0 \implies -78a + 198r = 0 \implies r =
\frac{13a}{33}.$$

设 $d = \gcd(N, D) = \gcd(78, 198) = 6$，$N' = 13$，$D' = 33$。为了使 $\gcd(a,b)
=1$，我们必须取 $a = D' = 33$，$r = N' = 13$，得 $b = 40 \cdot 33 + 13 = 1333$。

**验证：** $\alpha = 33/1333$，$1-\alpha = 1300/1333$，$\frac{\alpha n}{1-\alpha
} = \frac{33n}{1300}$。对于 $n = 0, \dots, 39$（因为 $n=40$ 时 $\frac{33\cdot 40
}{1300} = 1.015 > 1$），所以 $K = 40$。✓

$$L = \sum_{n=0}^{39}\!\left(1 - \tfrac{33n}{1300}\right) = 40 - \frac{33}{1300}
\cdot\frac{39\cdot 40}{2} = 40 - \frac{33\cdot 780}{1300} = 40 - 19.8 = 20.2.\ \
checkmark$$

$\gcd(33, 1333) = 1$：$1333 = 40\cdot 33 + 13$，$33 = 2\cdot 13 + 7$，$13 = 7 +
6$，$7 = 6 + 1$。✓

**答案：** $a = 33$，$b = 1333$，因此

$$100a + b = 3300 + 1333 = \boxed{4633}.$$
