## Setting Up the Divisibility Condition

Compute $2S(m) + 2021 = 2m^2 + 2m + 2042221$.

Since $n$ is odd, I multiply through by 2 (invertible mod $n$) and complete the
square:

$$4m^2 + 4m + 4084442 \equiv 0 \pmod{n}$$
$$(2m+1)^2 - 1 + 4084442 \equiv 0 \pmod{n}$$
$$(2m+1)^2 \equiv -4084441 \pmod{n}$$

**Key factorization:** $4084441 = 2021^2$, since $2021 = 43 \times 47$ and $2021
^2 = 4084441$.

So the condition becomes:

$$(2m+1)^2 + 2021^2 \equiv 0 \pmod{n}$$

Since $2m+1$ ranges over all odd integers, and modulo odd $n$ every residue clas
s has an odd representative, this is equivalent to: **there exists an integer $k
$ with $k^2 \equiv -2021^2 \pmod{n}$**, i.e., $-2021^2$ is a quadratic residue m
od $n$.

## Prime-by-Prime Analysis

By CRT, the condition splits over prime powers $p^a \| n$:

**Case 1: $p \nmid 2021$.** Then $2021$ is invertible mod $p^a$, and the conditi
on becomes $-1$ is a QR mod $p^a$. For odd prime $p$, this holds iff $p \equiv 1
 \pmod{4}$.

**Case 2: $p \mid 2021$ (i.e., $p = 43$ or $p = 47$, both $\equiv 3 \pmod{4}$).*
* Here $v_p(2021) = 1$, so $v_p(2021^2) = 2$. Analyzing $v_p(k^2 + 2021^2)$:
- If $p \nmid k$: valuation is 0 (fails for $a \geq 1$).
- If $v_p(k) = 1$: $k^2 + 2021^2 = p^2(k'^2 + c^2)$ where $p \nmid k', c$. Since
 $p \equiv 3 \pmod{4}$, $-1$ is not a QR mod $p$, so $p \nmid k'^2 + c^2$, givin
g valuation exactly 2.
- If $v_p(k) \geq 2$: valuation equals $v_p(2021^2) = 2$.

So for $p \in \{43, 47\}$: the condition holds iff $a \leq 2$.
