## Proof

**Claim:** Yes. There exists a univalent (holomorphic and injective) function on
 the unit disk whose second derivative vanishes at a point.

**Construction.** Consider
$$f(z) = z + \frac{z^3}{3}, \qquad |z| < 1.$$

This is holomorphic on the open unit disk $\mathbb{D}$, with
$$f'(z) = 1 + z^2, \qquad f''(z) = 2z.$$

In particular $f''(0) = 0$. It remains to verify that $f$ is univalent on $\math
bb{D}$.

**Univalence.** Suppose $f(z_1) = f(z_2)$ with $z_1, z_2 \in \mathbb{D}$. Then
$$0 = f(z_1) - f(z_2) = (z_1 - z_2) + \frac{z_1^3 - z_2^3}{3} = (z_1 - z_2)\left
[1 + \frac{z_1^2 + z_1 z_2 + z_2^2}{3}\right].$$

If $z_1 \neq z_2$, the bracketed factor must vanish, giving
$$z_1^2 + z_1 z_2 + z_2^2 = -3.$$

But for $z_1, z_2 \in \mathbb{D}$ we have $|z_1| < 1$ and $|z_2| < 1$, so by the
 triangle inequality:
$$|z_1^2 + z_1 z_2 + z_2^2| \leq |z_1|^2 + |z_1||z_2| + |z_2|^2 < 1 + 1 + 1 = 3
= |-3|.$$

This is a contradiction, since a complex number with modulus strictly less than
$3$ cannot equal $-3$. Therefore $z_1 = z_2$, proving $f$ is injective on $\math
bb{D}$.

**Remark.** Note also that $f'(z) = 1 + z^2 \neq 0$ on $\mathbb{D}$ (the zeros $
\pm i$ lie on $|\cdot|=1$), so $f$ is locally univalent as well, consistent with
 the global univalence shown above. Furthermore $f(0)=0$, $f'(0)=1$, so $f$ belo
ngs to the normalized schlicht class $\mathcal{S}$, making the example nontrivia
l.

**Conclusion.** The function $f(z) = z + z^3/3$ is univalent on the unit disk an
d satisfies $f''(0) = 0$. Hence the second derivative of a univalent function ca
n indeed vanish at a point.
