# Proof

**Claim.** The set of countably infinite subsets of a countably infinite set $S$
 has cardinality $2^{\aleph_0}$ (the cardinality of the continuum).

---

**Setup.** Let $S$ be a countably infinite set. Define
$$\mathcal{C} = \{A \subseteq S : A \text{ is countably infinite}\}.$$

We show $|\mathcal{C}| = 2^{\aleph_0}$.

---

**Step 1. Every infinite subset of $S$ is countably infinite.**

Since $S$ is countable, every subset of $S$ is countable (a standard theorem: an
y subset of a countable set is countable). An infinite subset of a countable set
 is therefore countably infinite. Hence
$$\mathcal{C} = \{A \subseteq S : A \text{ is infinite}\}.$$

---

**Step 2. Upper bound: $|\mathcal{C}| \le 2^{\aleph_0}$.**

Trivially $\mathcal{C} \subseteq \mathcal{P}(S)$, and $|\mathcal{P}(S)| = 2^{|S|
} = 2^{\aleph_0}$. So $|\mathcal{C}| \le 2^{\aleph_0}$.

---

**Step 3. The set of finite subsets of $S$ is countable.**

Let $\mathcal{F} = \{A \subseteq S : A \text{ is finite}\}$. Write $\mathcal{F}
= \bigcup_{n=0}^{\infty} \mathcal{F}_n$ where $\mathcal{F}_n$ is the set of $n$-
element subsets of $S$. Each $\mathcal{F}_n$ is countable: fixing an enumeration
 $S = \{s_0, s_1, s_2, \dots\}$, every $n$-element subset corresponds to an incr
easing $n$-tuple of natural numbers, and $\mathbb{N}^n$ is countable. A countabl
e union of countable sets is countable, so $\mathcal{F}$ is countable: $|\mathca
l{F}| = \aleph_0$.

---

**Step 4. Lower bound: $|\mathcal{C}| \ge 2^{\aleph_0}$.**

We have the partition
$$\mathcal{P}(S) = \mathcal{F} \sqcup \mathcal{C},$$
since every subset of $S$ is either finite or infinite (and infinite subsets are
 countably infinite by Step 1). Therefore
$$2^{\aleph_0} = |\mathcal{P}(S)| = |\mathcal{F}| + |\mathcal{C}| = \aleph_0 + |
\mathcal{C}|.$$

Since $2^{\aleph_0} > \aleph_0$ (Cantor's theorem), we must have $|\mathcal{C}|
= 2^{\aleph_0}$. (Indeed, if $|\mathcal{C}|$ were $< 2^{\aleph_0}$, then $\aleph
_0 + |\mathcal{C}| = \max(\aleph_0, |\mathcal{C}|) < 2^{\aleph_0}$, a contradict
ion; and $|\mathcal{C}| \le 2^{\aleph_0}$ by Step 2.)

---

**Conclusion.** Combining Steps 2 and 4,
$$|\mathcal{C}| = 2^{\aleph_0}.$$

The set of countably infinite subsets of a countably infinite set has cardinalit
y $2^{\aleph_0}$, the cardinality of the continuum.
