## Proof

**Setup and parametrization.** Since $P$ is symmetric in $a,b,c$, assume WLOG th
at $a < b < c$ (if any two are equal, a denominator vanishes and $P=+\infty$, so
 at the minimum all three are distinct). Set
$$u = b-a > 0, \qquad v = c-b > 0, \qquad \text{so } c-a = u+v.$$
With $a+b+c=1$, solving gives $a = \tfrac{1-2u-v}{3}$, $b = \tfrac{1+u-v}{3}$, $
c = \tfrac{1+u+2v}{3}$.

**Expressing the stability index.** Using $a^2+b^2+c^2 = (a+b+c)^2 - 2(ab+bc+ca)
 = 1-2s$ where $s=ab+bc+ca$, a direct computation gives
$$s = ab+bc+ca = \frac{1 - u^2 - uv - v^2}{3}.$$
Denote $D := u^2+uv+v^2$. The constraint $s>0$ becomes $D<1$, and $\sqrt{s} = \s
qrt{(1-D)/3} = \sqrt{1-D}/\sqrt{3}$.

Thus
$$P = \underbrace{\frac{2}{u}+\frac{2}{v}+\frac{2}{u+v}}_{\displaystyle \varphi(
u,v)} + \frac{5\sqrt{3}}{\sqrt{1-D}}, \qquad u,v>0,\; D<1.$$

**Step 1: For fixed $D$, minimize $\varphi$ over $u,v$.** Let $S=u+v$ and $Q=uv$
. Then $D = S^2 - Q$, so $Q = S^2 - D$. The conditions $u,v>0$ require $Q>0$ and
 $S^2 \ge 4Q$, i.e.
$$D < S^2 \le \tfrac{4D}{3}.$$
Rewriting $\varphi$:
$$\varphi = \frac{2(u+v)}{uv} + \frac{2}{u+v} = \frac{2S}{Q} + \frac{2}{S} = \fr
ac{2S}{S^2-D} + \frac{2}{S}.$$
Treating $\varphi$ as a function of $S$ on $(\sqrt{D},\, 2\sqrt{D/3}]$:
$$\varphi'(S) = \frac{-2(S^2+D)}{(S^2-D)^2} - \frac{2}{S^2} < 0.$$
So $\varphi$ is **strictly decreasing** in $S$, hence minimized at the maximum $
S = 2\sqrt{D/3}$, which corresponds to $u=v=\sqrt{D/3}$ (the unique point where
$S^2=4Q$, i.e. $u=v$). The minimum value is
$$\varphi_{\min}(D) = \frac{2\cdot 2\sqrt{D/3}}{D/3} + \frac{2}{2\sqrt{D/3}} = \
frac{4\sqrt{3}}{\sqrt{D}} + \frac{\sqrt{3}}{\sqrt{D}} = \frac{5\sqrt{3}}{\sqrt{D
}}.$$

**Step 2: Reduce to a single variable.** Therefore
$$P \ge \frac{5\sqrt{3}}{\sqrt{D}} + \frac{5\sqrt{3}}{\sqrt{1-D}} = 5\sqrt{3}\!\
left(\frac{1}{\sqrt{D}}+\frac{1}{\sqrt{1-D}}\right),$$
with equality iff $u=v$. Define $h(D) = \frac{1}{\sqrt{D}}+\frac{1}{\sqrt{1-D}}$
 on $(0,1)$. Then
$$h'(D) = -\frac{1}{2D^{3/2}} + \frac{1}{2(1-D)^{3/2}} = 0 \iff D^{3/2}=(1-D)^{3
/2} \iff D = 1-D \iff D=\tfrac12.$$
Since $h(D)\to+\infty$ as $D\to 0^+$ or $D\to 1^-$, this unique critical point i
s the global minimum:
$$h\!\left(\tfrac12\right) = \frac{1}{\sqrt{1/2}}+\frac{1}{\sqrt{1/2}} = 2\sqrt{
2}.$$

**Step 3: Compute the minimum.**
$$P_{\min} = 5\sqrt{3}\cdot 2\sqrt{2} = 10\sqrt{6}.$$

**Verification of the minimizer.** At $D=\frac12$ and $u=v=\sqrt{D/3}=\frac{1}{\
sqrt6}$:
- $a = \frac{1-3/\sqrt6}{3}$, $b = \frac{1}{3}$, $c = \frac{1}{3}+\frac{1}{\sqrt
6}$, giving $a+b+c=1$. ✓
- $ab+bc+ca = \frac{1-D}{3} = \frac{1}{6} > 0$. ✓
- $|a-b|=|b-c|=\frac{1}{\sqrt6}$, $|c-a|=\frac{2}{\sqrt6}$, all nonzero. ✓
- $\frac{2}{|a-b|}+\frac{2}{|b-c||}+\frac{2}{|c-a|} = 2\sqrt6+2\sqrt6+\sqrt6 = 5
\sqrt6$.
- $\frac{5}{\sqrt{ab+bc+ca}} = \frac{5}{\sqrt{1/6}} = 5\sqrt6$.
- $P = 5\sqrt6 + 5\sqrt6 = 10\sqrt6$. ✓

**Boundary behavior confirms globality.** As $u\to0^+$ or $v\to0^+$ (two tanks c
oincide), $\varphi\to+\infty$. As $D\to 1^-$ (stability index $\to 0^+$), the la
st term $\to+\infty$. Hence $P\to+\infty$ at every boundary of the domain $\{(u,
v): u>0, v>0, D<1\}$, so the unique interior critical point is the global minimu
m.
