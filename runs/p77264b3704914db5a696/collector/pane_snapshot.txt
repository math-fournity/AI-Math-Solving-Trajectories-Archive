## 解答

我们需要找到 $r_1, r_2, \ldots, r_n$，使得对于所有非负实数 $x_1, \ldots, x_n$，
满足：

$$\sum_{i=1}^{n} r_i (x_i - a_i) \leq \left( \sum_{i=1}^{n} x_i^m \right)^{1/m}
- \left( \sum_{i=1}^{n} a_i^m \right)^{1/m}.$$

**答案：**

$$r_i = \frac{a_i^{m-1}}{\left(\sum_{j=1}^{n} a_j^m\right)^{(m-1)/m}}, \qquad i
= 1, 2, \ldots, n.$$

---

**证明：**

记 $A = \left(\sum_{j=1}^n a_j^m\right)^{1/m} > 0$（因所有 $a_j > 0$），则 $r_i
= \dfrac{a_i^{m-1}}{A^{m-1}}$。

**第 1 步：化简不等式。**

将 $r_i$ 代入左边：

$$\sum_{i=1}^n r_i(x_i - a_i) = \frac{1}{A^{m-1}}\sum_{i=1}^n a_i^{m-1} x_i - \f
rac{1}{A^{m-1}}\sum_{i=1}^n a_i^m = \frac{\sum_{i=1}^n a_i^{m-1} x_i}{A^{m-1}} -
 \frac{A^m}{A^{m-1}} = \frac{\sum_{i=1}^n a_i^{m-1} x_i}{A^{m-1}} - A.$$

因此原不等式等价于：

$$\frac{\sum_{i=1}^n a_i^{m-1} x_i}{A^{m-1}} - A \leq \left(\sum_{i=1}^n x_i^m\r
ight)^{1/m} - A,$$

即

$$\sum_{i=1}^n a_i^{m-1} x_i \leq A^{m-1}\left(\sum_{i=1}^n x_i^m\right)^{1/m} =
 \left(\sum_{j=1}^n a_j^m\right)^{(m-1)/m}\left(\sum_{i=1}^n x_i^m\right)^{1/m}.
 \tag{$\star$}$$

**第 2 步：用 Hölder 不等式证明 $(\star)$。**

由于 $m > 1$，取共轭指数 $p = \dfrac{m}{m-1}$ 与 $q = m$，则 $\dfrac{1}{p} + \df
rac{1}{q} = \dfrac{m-1}{m} + \dfrac{1}{m} = 1$。

对所有 $i$，令 $u_i = a_i^{m-1}$，$v_i = x_i$。由 Hölder 不等式（对非负实数成立
）：

$$\sum_{i=1}^n u_i v_i \leq \left(\sum_{i=1}^n u_i^p\right)^{1/p}\left(\sum_{i=1
}^n v_i^q\right)^{1/q}.$$

计算各项：

$$u_i^p = \left(a_i^{m-1}\right)^{m/(m-1)} = a_i^m, \qquad v_i^q = x_i^m,$$

$$\left(\sum u_i^p\right)^{1/p} = \left(\sum a_i^m\right)^{(m-1)/m}, \qquad \lef
t(\sum v_i^q\right)^{1/q} = \left(\sum x_i^m\right)^{1/m}.$$

代入得：

$$\sum_{i=1}^n a_i^{m-1} x_i \leq \left(\sum_{j=1}^n a_j^m\right)^{(m-1)/m}\left
(\sum_{i=1}^n x_i^m\right)^{1/m},$$

这正是 $(\star)$。因此原不等式对所有 $x_i \geq 0$ 成立。

**第 3 步：验证等号在 $x = a$ 时成立。**

当 $x_i = a_i$ 时，左边 $= \sum r_i(a_i - a_i) = 0$，右边 $= \left(\sum a_i^m\ri
ght)^{1/m} - \left(\sum a_i^m\right)^{1/m} = 0$。等号成立，与 Hölder 不等式等号
条件 $u_i^p / v_i^q = \text{const}$（即 $a_i^m / x_i^m = \text{const}$，即 $x_i
\propto a_i$）在 $x = a$ 时满足一致。

**结论：** 取

$$\boxed{r_i = \frac{a_i^{m-1}}{\left(\sum_{j=1}^{n} a_j^m\right)^{(m-1)/m}}}$$

即满足题意。这组 $r_i$ 恰为 $L^m$ 范数 $f(x)=\left(\sum x_i^m\right)^{1/m}$ 在点
 $a$ 处的梯度，由 $f$ 的凸性（$m>1$）保证其为全局最优的线性下界。
