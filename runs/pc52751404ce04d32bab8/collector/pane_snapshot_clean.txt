## Proof

**Step 1: $n$ must be odd.**

If $n$ is even, then $n^{n-1}$ is even, so $n^{n-1}-1$ is odd, giving $v_2(n^{n-
1}-1)=0\neq 2015$. Thus $n$ is odd. The case $n=1$ gives $n^{n-1}-1=1^0-1=0$ wit
h $v_2=\infty$, so $n\geq 3$.

**Step 2: Apply the Lifting the Exponent Lemma (LTE) for $p=2$.**

For odd integers $a,b$ with $a\neq b$ and a positive even exponent $e$:
$$v_2(a^e - b^e) = v_2(a-b)+v_2(a+b)+v_2(e)-1.$$

Set $a=n$, $b=1$, $e=n-1$ (which is even since $n$ is odd). Then:
$$v_2(n^{n-1}-1)=v_2(n-1)+v_2(n+1)+v_2(n-1)-1=2\,v_2(n-1)+v_2(n+1)-1.$$

**Step 3: Exploit the constraint on $n-1$ and $n+1$.**

Since $n$ is odd, both $n-1$ and $n+1$ are even, and they differ by $2$, so exac
tly one of them is divisible by $4$. Hence $\min(v_2(n-1),\,v_2(n+1))=1$.

We need:
$$2\,v_2(n-1)+v_2(n+1)-1=2015,\quad\text{i.e.,}\quad 2\,v_2(n-1)+v_2(n+1)=2016.$
$

**Case A: $v_2(n-1)=1$.** Then $v_2(n+1)=2014$. This is consistent: $n\equiv 3\p
mod{4}$ (from $v_2(n-1)=1$), and $n\equiv -1\pmod{4}$ (from $v_2(n+1)\geq 2$). B
oth give $n\equiv 3\pmod{4}$. ✓

The conditions are:
- $v_2(n+1)=2014$: $n\equiv -1\pmod{2^{2014}}$ but $n\not\equiv -1\pmod{2^{2015}
}$.
- $v_2(n-1)=1$: automatically satisfied, since if $n=2^{2014}m-1$ with $m$ odd,
then $n-1=2(2^{2013}m-1)$ where $2^{2013}m-1$ is odd.

**Case B: $v_2(n+1)=1$.** Then $2\,v_2(n-1)=2015$, giving $v_2(n-1)=2015/2$, whi
ch is not an integer. **Impossible.**

**Step 4: Describe the solution set.**

From Case A, the solutions are exactly:
$$n = 2^{2014}\cdot m - 1,\quad m\text{ a positive odd integer}.$$

Writing $m=2t+1$ for $t\geq 0$:
$$n = 2^{2014}(2t+1)-1 = 2^{2015}\,t + 2^{2014}-1.$$

Equivalently:
$$n \equiv 2^{2014}-1 \pmod{2^{2015}}.$$

**Step 5: Verification.**

Take any such $n=2^{2014}(2t+1)-1$ with $t\geq 0$:
- $n$ is odd (since $2^{2014}(2t+1)$ is even). ✓
- $n\geq 1$: smallest value at $t=0$ is $2^{2014}-1>0$. ✓
- $v_2(n-1)=v_2(2^{2014}(2t+1)-2)=v_2(2(2^{2013}(2t+1)-1))=1$ since $2^{2013}(2t
+1)-1$ is odd. ✓
- $v_2(n+1)=v_2(2^{2014}(2t+1))=2014$ since $2t+1$ is odd. ✓
- $v_2(n^{n-1}-1)=2(1)+2014-1=2015$. ✓

**Conclusion.** The set of all positive integers $n$ satisfying $v_2(n^{n-1}-1)=
2015$ is:
$$\boxed{n \equiv 2^{2014}-1 \pmod{2^{2015}}},$$
i.e., $n = 2^{2015}t + 2^{2014}-1$ for all non-negative integers $t$.
