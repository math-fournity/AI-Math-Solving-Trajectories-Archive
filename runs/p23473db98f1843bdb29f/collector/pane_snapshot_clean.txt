**Theorem.** Let $f \colon \mathbb{R}^d \to \mathbb{R}\cup\{+\infty\}$ be convex
. Then $f$ is continuous $\lambda^d$-almost everywhere.

**Proof.** Let $\operatorname{dom} f = \{x \in \mathbb{R}^d : f(x) < +\infty\}$
be the effective domain of $f$. Since $f$ is convex, $\operatorname{dom} f$ is a
 convex subset of $\mathbb{R}^d$, and $f$ is finite on $\operatorname{dom} f$ an
d $+\infty$ on $\mathbb{R}^d \setminus \operatorname{dom} f$.

We use two standard facts:

*Fact 1 (continuity on the interior of the domain).* A convex function finite on
 a nonempty open convex set is continuous (indeed locally Lipschitz) on that set
. In particular, $f$ is continuous on $\operatorname{int}(\operatorname{dom} f)$
.

*Fact 2 (boundary of a convex body has measure zero).* If $C \subseteq \mathbb{R
}^d$ is convex with $\operatorname{int}(C) \neq \emptyset$, then $\lambda^d(\par
tial C) = 0$. (Indeed, $\partial C$ is locally the graph of a Lipschitz function
 near each of its points, hence is covered by countably many Lipschitz graphs of
 $(d-1)$-dimensional domains, each of $d$-dimensional measure zero.)

We split into two cases.

**Case A: $\operatorname{int}(\operatorname{dom} f) = \emptyset$.** Then the con
vex set $\operatorname{dom} f$ is contained in some affine subspace $H \subseteq
 \mathbb{R}^d$ of dimension $\le d-1$ (a convex set with empty interior lies in
a supporting affine subspace of lower dimension). Hence $\lambda^d(\operatorname
{dom} f) = 0$. For any $x \notin H$, since $H$ is closed, there is a neighborhoo
d of $x$ disjoint from $H$, hence disjoint from $\operatorname{dom} f$, on which
 $f \equiv +\infty$; so $f$ is continuous at $x$. Thus the discontinuity set of
$f$ is contained in $H$, which has $\lambda^d$-measure zero.

**Case B: $\operatorname{int}(\operatorname{dom} f) \neq \emptyset$.** By Fact 1
, $f$ is continuous on $\operatorname{int}(\operatorname{dom} f)$. The set $\mat
hbb{R}^d \setminus \overline{\operatorname{dom} f}$ is open and disjoint from $\
operatorname{dom} f$, so $f \equiv +\infty$ there, and $f$ is continuous at ever
y point of $\mathbb{R}^d \setminus \overline{\operatorname{dom} f}$. Therefore t
he discontinuity set of $f$ is contained in
$$\overline{\operatorname{dom} f} \setminus \operatorname{int}(\operatorname{dom
} f) = \partial(\operatorname{dom} f),$$
which has $\lambda^d$-measure zero by Fact 2.

In both cases the set of discontinuities of $f$ has $\lambda^d$-measure zero, so
 $f$ is $\lambda^d$-almost everywhere continuous. $\blacksquare$
