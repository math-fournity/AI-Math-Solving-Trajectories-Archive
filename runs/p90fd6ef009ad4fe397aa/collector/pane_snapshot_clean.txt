## Proof

**Claim.** A Turing machine with a limited (finite) tape length cannot output ev
ery digit of π one after another correctly.

**Key observation.** A Turing machine with a finite tape is equivalent in power
to a finite automaton. Specifically, it has only finitely many possible configur
ations.

A *configuration* of the machine is determined by:
- the current control state (finitely many),
- the head position (finitely many, since the tape is finite),
- the tape contents (finitely many, since the tape has finitely many cells each
holding one of finitely many symbols).

The product of three finite sets is finite, so the machine has only **finitely m
any configurations**.

**Lemma (eventual periodicity).** Any infinite output sequence produced by a fin
ite-tape Turing machine is eventually periodic.

*Proof of lemma.* As the machine runs and produces output, it passes through a s
equence of configurations. Since there are only finitely many configurations, by
 the pigeonhole principle some configuration $C$ must repeat. Once a configurati
on repeats, the machine's subsequent behavior is deterministic, so the entire tr
ajectory from the first occurrence of $C$ onward repeats forever. The output pro
duced during one such cycle is fixed, so the output sequence is eventually perio
dic. $\square$

**Lemma (irrationality ⟹ non-periodicity).** The digit expansion of an irrationa
l number is not eventually periodic.

*Proof of lemma.* If a number's digit expansion (in any base) is eventually peri
odic, then the number is rational — this is the classical characterization of ra
tionals via eventually periodic expansions. The contrapositive: an irrational nu
mber has a digit expansion that is **not** eventually periodic. $\square$

**Main argument.** Suppose, for contradiction, that a finite-tape Turing machine
 $M$ outputs every digit of $\pi$ correctly, one after another, producing the in
finite digit sequence $d_1 d_2 d_3 \cdots = $ the digits of $\pi$.

By the eventual periodicity lemma, the output of $M$ is eventually periodic. Sin
ce the output equals the digit expansion of $\pi$, the digit expansion of $\pi$
is eventually periodic.

By the irrationality lemma, an eventually periodic expansion implies $\pi$ is ra
tional.

But $\pi$ is **irrational** (in fact, transcendental — proved by Lindemann in 18
82). This is a contradiction.

Therefore, no finite-tape Turing machine can output every digit of $\pi$ correct
ly. $\blacksquare$

**Intuition.** A finite tape gives the machine only finitely many "memory states
," so it can only ever produce eventually-repeating (periodic) output. The digit
s of $\pi$ never repeat, since $\pi$ is irrational. A finite-memory device canno
t generate an aperiodic infinite sequence, so it cannot generate $\pi$.
