Analysis

Key facts about group classification:

  1. The Small Groups Library (Besche, Eick, O'Brien, 2001): In the landmark
  work "The groups of order at most 2000" (J. Algebra, 2001), all groups of
  order at most 2000 were classified and explicitly constructed, with one
  exception: order 1024 = 2¹⁰. The number of groups of order 1024 is
  49,487,365,422 — far too many to enumerate individually in a library.
  2. Cube-free groups (Dietrich, Eick): A separate algorithmic result classifies
  all groups of cube-free order (orders not divisible by p³ for any prime p).
  The Small Groups library includes cube-free groups up to order 50000. This is
  a distinct classification result — it covers only cube-free orders, not all
  orders in the range 2001–50000.
  3. Gaps above 2000: For orders between 2001 and 50000, many orders are not
  fully classified. For example:
    • Order 2048 = 2¹¹: the number of groups is astronomically large and not
    fully enumerated.
    • Order 2187 = 3⁷: similarly not fully classified.
    • Many other non-cube-free orders in this range lack complete
    classification.

Proof

Claim: The highest order for which all groups have been classified is 2000.

Proof:

(a) All groups of order ≤ 2000 are classified (except 1024).

By the theorem of Besche, Eick, and O'Brien (2001), for every integer n with 1 ≤
n ≤ 2000 and n ≠ 1024, the complete set of isomorphism classes of groups of
order n has been determined and is available in the GAP Small Groups Library.
The sole exception is n = 1024 = 2¹⁰, where the number of groups
(49,487,365,422) makes explicit enumeration impractical. The question explicitly
excludes order 1024, so this gap does not affect our answer.

(b) The cube-free classification up to 50000 does not extend the bound.

While all groups of cube-free order up to 50000 have been classified (by
algorithms of Dietrich and Eick), this result covers only cube-free orders. It
does not provide classification for non-cube-free orders in the range 2001–
50000. The question's exclusion of "cube-free groups of order 50000"
acknowledges this as a separate result that does not fill the gaps for non-cube-
free orders.

(c) No order above 2000 has all its groups classified (in the comprehensive
sense).

For n = 2001 and beyond, there exist orders whose groups are not fully
classified. The smallest such gap is n = 2048 = 2¹¹, where the number of groups
of order 2¹¹ is not even known exactly (it vastly exceeds the 1024 case). Other
examples include 2187 = 3⁷, 3125 = 5⁵ (though 5⁵ groups are classified — 77
groups), and various orders with high prime-power factors. The existence of
unclassified orders above 2000 means the comprehensive classification bound
cannot exceed 2000.

(d) Conclusion.
