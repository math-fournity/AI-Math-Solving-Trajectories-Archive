## Proof

**Problem.** Count integers $n$ with $1 \le n \le 999{,}999$ such that $k^3 \mid
 n$ for some integer $k > 1$.

**Reformulation.** A number is *unstable* iff it is **not cube-free**, i.e., som
e prime $p$ has $p^3 \mid n$. So

$$\text{unstable} = N - C(N), \quad N = 999{,}999,$$

where $C(N)$ is the count of cube-free integers up to $N$.

**Inclusion–Exclusion via Möbius.** A number is cube-free iff no prime cube divi
des it. By inclusion–exclusion over primes $p$ with $p^3 \le N$:

$$C(N) = \sum_{\substack{d \ge 1,\; d^3 \le N \\ d \text{ squarefree}}} \mu(d)\l
eft\lfloor \frac{N}{d^3}\right\rfloor.$$

Since $\mu(1)=1$ and $\lfloor N/1\rfloor = N$, the unstable count is

$$U = N - C(N) = \sum_{\substack{d \ge 2,\; d^3 \le N \\ d \text{ squarefree}}}
(-\mu(d))\left\lfloor \frac{N}{d^3}\right\rfloor.$$

**Range of $d$.** We need $d^3 \le 999{,}999$, i.e., $d \le \lfloor 999{,}999^{1
/3}\rfloor = 99$ (since $99^3 = 970{,}299 \le 999{,}999 < 100^3 = 1{,}000{,}000$
).
