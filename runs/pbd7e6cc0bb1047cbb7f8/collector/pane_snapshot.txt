## Solution

**Answer-leak check:** The problem statement contains only the limit to evaluate
; no solution, hint, or answer is embedded. Proceeding.

Let
$$I_n=\int_{0}^{\infty}\frac{\sin x}{(1+x)^n}\,dx.$$

### Substitution

Set $u=\ln(1+x)$, so $x=e^{u}-1$, $dx=e^{u}\,du$, and as $x:0\to\infty$ we have
$u:0\to\infty$. Then
$$I_n=\int_{0}^{\infty}\sin(e^{u}-1)\,e^{-nu}\,e^{u}\,du=\int_{0}^{\infty}\sin(e
^{u}-1)\,e^{-(n-1)u}\,du.$$

Put $\lambda=n-1$ and rescale $s=\lambda u$ ($du=ds/\lambda$):
$$I_n=\frac{1}{\lambda}\int_{0}^{\infty}\sin\!\bigl(e^{s/\lambda}-1\bigr)\,e^{-s
}\,ds.$$

### Extract the leading behavior

Write $\sin(e^{s/\lambda}-1)=\dfrac{\sin(e^{s/\lambda}-1)}{s/\lambda}\cdot\dfrac
{s}{\lambda}$ and define
$$h_{\lambda}(s)=\frac{\sin(e^{s/\lambda}-1)}{s/\lambda},\qquad h_{\lambda}(0):=
1.$$
Then
$$I_n=\frac{1}{\lambda^{2}}\int_{0}^{\infty}h_{\lambda}(s)\,s\,e^{-s}\,ds,$$
so
$$n^{2}I_n=\frac{n^{2}}{(n-1)^{2}}\int_{0}^{\infty}h_{\lambda}(s)\,s\,e^{-s}\,ds
.$$

### Pointwise limit

For each fixed $s\ge 0$, as $\lambda\to\infty$ we have $e^{s/\lambda}-1\to 0$, h
ence
$$h_{\lambda}(s)=\frac{\sin(e^{s/\lambda}-1)}{e^{s/\lambda}-1}\cdot\frac{e^{s/\l
ambda}-1}{s/\lambda}\longrightarrow 1\cdot 1=1.$$

### Domination

For $y\ge 0$, $|\sin y|\le y$, so with $y=e^{s/\lambda}-1\ge 0$,
$$|h_{\lambda}(s)|=\frac{|\sin y|}{y}\le 1.$$
Therefore
$$\bigl|h_{\lambda}(s)\,s\,e^{-s}\bigr|\le s\,e^{-s},$$
and $\int_{0}^{\infty}s\,e^{-s}\,ds=1<\infty$. By dominated convergence,
$$\int_{0}^{\infty}h_{\lambda}(s)\,s\,e^{-s}\,ds\longrightarrow\int_{0}^{\infty}
s\,e^{-s}\,ds=1.$$

### Conclusion

Since $\dfrac{n^{2}}{(n-1)^{2}}=\left(1+\dfrac{1}{n-1}\right)^{2}\longrightarrow
 1$, we obtain
$$\lim_{n\to\infty}n^{2}\int_{0}^{\infty}\frac{\sin x}{(1+x)^n}\,dx=1\cdot 1=\bo
xed{1}.$$
