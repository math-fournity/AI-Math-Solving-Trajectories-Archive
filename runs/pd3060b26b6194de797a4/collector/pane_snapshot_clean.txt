## Proof

Define the linear functional $L: C_0 \to \mathbb{R}$ by
$$L\big((x_n)\big) = x_1 + x_2 + \cdots + x_{10}.$$

**$L$ is well-defined and linear.** For any $(x_n)\in C_0$, the value $L((x_n))$
 is a finite real linear combination of the first ten terms, hence a real number
. Linearity follows from linearity of each coordinate projection.

**$L$ is surjective.** For any $r\in\mathbb{R}$, consider the sequence $e^{(r)}
= (r, 0, 0, \ldots)$, i.e. $x_1 = r$ and $x_n = 0$ for $n\ge 2$. This sequence i
s eventually constant $0$, so it converges to $0$, hence $e^{(r)}\in C_0$, and $
L(e^{(r)}) = r$. Thus $\operatorname{im} L = \mathbb{R}$.

**$M = \ker L$.** By definition,
$$M = \{(x_n)\in C_0 : x_1+\cdots+x_{10}=0\} = \{(x_n)\in C_0 : L((x_n))=0\} = \
ker L.$$

**Apply the first isomorphism theorem.** Since $L: C_0 \to \mathbb{R}$ is a surj
ective linear map with kernel $M$, the induced map
$$\widetilde{L}: C_0/M \to \mathbb{R}, \qquad \widetilde{L}((x_n)+M) = L((x_n))$
$
is a well-defined linear isomorphism. Therefore
$$C_0/M \cong \mathbb{R}.$$

**Conclusion.** The quotient space $C_0/M$ is isomorphic to $\mathbb{R}$ as a re
al vector space, so its (Hamel) dimension is

$$\dim\!\left(\frac{C_0}{M}\right) = \dim \mathbb{R} = 1.$$

### PROOF COMPLETE
