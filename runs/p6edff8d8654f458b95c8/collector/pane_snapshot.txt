## Key Lemma: $S(j) = D(2j)$

**Claim:** For the full range, $\displaystyle S(j) := \sum_{r=1}^{2j} g(j,r) = \

**Proof.** Since $g(j,r)$ is decreasing in $r$ (from $2j$ to $1$), I count $c(j,

$$\frac{2j(v+1)+1}{(v+1)^2} < r \le \frac{2jv+1}{v^2}.$$

Set $B(v) = \left\lfloor\frac{2jv+1}{v^2}\right\rfloor$. One checks $\frac{2jv+1
}{v^2}\notin\mathbb{Z}$ for $v\ge 2$ (since $\gcd(v,2jv+1)=1$ forces $v^2\mid 1$

= 2j - j = j = B(1)-B(2)-1$.

For $v\ge 2$: $c(j,v) = B(v)-B(v+1)$ (with $B(2j+1)=0$).

**Critical observation:** For $v\ge 2$, $\lfloor\frac{2j}{v}+\frac{1}{v^2}\rfloo

**Telescoping:** $S(j) = 1\cdot(B(1)-B(2)-1) + \sum_{v=2}^{2j} v(B(v)-B(v+1))$.
By Abel summation:
$$S(j) = -1 + \sum_{v=1}^{2j} B(v) = -1 + (2j+1) + \sum_{v=2}^{2j}\left\lfloor\f
