The statement is **always true**.

**Proof.**

Let $M$ be a smooth manifold without boundary whose tangent bundle $TM$ is trivi
al. We show that $M$ is orientable.

Since $TM$ is trivial, there exists a vector bundle isomorphism
$$\Phi : TM \xrightarrow{\;\cong\;} M \times \mathbb{R}^n,$$
where $n = \dim M$. Equivalently, $TM$ admits a **global frame**: there exist sm
ooth vector fields $X_1, \dots, X_n$ on $M$ such that for every $p \in M$, the v
ectors $X_1(p), \dots, X_n(p)$ form a basis of $T_p M$.

We use this global frame to define an orientation on $M$. For each $p \in M$, de
clare the ordered basis $(X_1(p), \dots, X_n(p))$ to be **positively oriented**.
 We must verify this gives a well-defined, consistent orientation — i.e., an ori
entation in the sense of smooth manifolds.

Take any connected coordinate chart $(U, \varphi = (x^1, \dots, x^n))$ on $M$. O
n $U$, each vector field $X_i$ can be written as
$$X_i = \sum_{j=1}^n a_i^j \,\frac{\partial}{\partial x^j},$$
where $A = (a_i^j)$ is a smooth $n \times n$ matrix-valued function on $U$. Sinc
e $(X_1, \dots, X_n)$ is a frame, $A(p)$ is invertible for every $p \in U$, so $
\det A : U \to \mathbb{R}\setminus\{0\}$ is a smooth, nowhere-vanishing function
. Since $U$ is connected, $\det A$ has **constant sign** on $U$.

- If $\det A > 0$ on $U$, the chart $(U, \varphi)$ is positively oriented with r
espect to our chosen orientation.
- If $\det A < 0$ on $U$, the chart $(U, \varphi)$ is negatively oriented.

Thus on every connected coordinate chart, the Jacobian relating the frame $(X_1,
 \dots, X_n)$ to the coordinate frame $(\partial/\partial x^1, \dots, \partial/\
partial x^n)$ has constant sign, which is precisely the condition that the orien
tation defined by the global frame is consistent.

Concretely, for any two overlapping connected charts $(U, \varphi)$ and $(V, \ps
i)$, the transition map $\psi \circ \varphi^{-1}$ has Jacobian determinant equal
 to
$$\det\!\big(A_V\big) \cdot \det\!\big(A_U\big)^{-1},$$
where $A_U$, $A_V$ are the matrices expressing the global frame in the two coord
inate systems. Each determinant has constant sign on its domain, so the Jacobian
 of the transition map has constant sign on $U \cap V$. This means we can consis
tently select an oriented atlas: keep all charts with $\det A > 0$ and discard (
or flip) those with $\det A < 0$. The result is a **smoothly varying, consistent
 orientation** on all of $M$.

Therefore $M$ is orientable. $\blacksquare$

**Remark.** This also follows immediately from characteristic class theory: $M$
is orientable iff the first Stiefel–Whitney class $w_1(TM) = 0$, and a trivial b
undle has all Stiefel–Whitney classes (indeed all characteristic classes) equal
to zero. The elementary argument above avoids this machinery.
