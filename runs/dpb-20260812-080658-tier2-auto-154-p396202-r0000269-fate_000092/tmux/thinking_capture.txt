设 $S$ 是一个集合，且 $*$ 是 $S$ 上的运算，满足：

  1. 对所有 $a, b \in S$，有 $a * b = a$。
  2. 对所有 $a, b\in S$，有 $a * b = b * a$。

假设 $S$ 非空，设 $a, b \in S$ 为 $S$ 中的任意两个元素。我们证明 $a = b$。

由规则 1（取 $a$ 为第一个参数，$b$ 为第二个参数）： $$a * b = a.$$

由规则 1（取 $b$ 为第一个参数，$a$ 为第二个参数）： $$b * a = b.$$

由规则 2（交换律）： $$a * b = b * a.$$

将上述三个等式结合： $$a = a * b = b * a = b.$$

因此 $a = b$。由于 $a$ 和 $b$ 是 $S$ 中的任意元素，$S$ 中的任意两个元素都相等，
这意味着 $S$ 最多包含一个元素。

因此，$S$ 最多只能有一个对象。$\blacksquare$
