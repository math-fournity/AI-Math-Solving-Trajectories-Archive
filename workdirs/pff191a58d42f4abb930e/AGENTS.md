# Problem

In the futuristic city of Orizon, a central mainframe monitoring system consists of a massive display wall arranged in a grid of 3 horizontal rows and $n$ vertical columns of light panels. Each individual light panel can be toggled to one of two states: "Active Blue" or "Dormant White."

The system’s integrity protocol requires the detection of "Parity Rectangles." A Parity Rectangle is defined as any four light panels that form the corners of a rectangle within the grid (with sides parallel to the grid boundaries) where all four corner panels are currently set to the same color.

Safety engineers need to determine the critical threshold for the width of this display wall. What is the smallest integer value of $n$ (the number of columns) such that, regardless of how the light panels are colored, there is guaranteed to be at least one Parity Rectangle present on the board?
