## Solution

We solve the functional equation
$$f(xy+1) = f(x)f(y) - f(y) - x + 2, \quad \forall x,y \in \mathbb{R}, \qquad f(
0)=1.$$

**Step 1: Determine $f(1)$.**

Set $x = 0$. The equation becomes
$$f(0\cdot y + 1) = f(0)f(y) - f(y) - 0 + 2 = f(y)\bigl(f(0)-1\bigr) + 2.$$
Since $f(0)=1$, the factor $f(0)-1 = 0$, so
$$f(1) = 2.$$

**Step 2: Determine $f(x)$ for all $x$.**

Set $y = 0$. The equation becomes
$$f(0\cdot x + 1) = f(x)f(0) - f(0) - x + 2.$$
Using $f(1)=2$ and $f(0)=1$:
$$2 = f(x)\cdot 1 - 1 - x + 2 = f(x) - x + 1.$$
Solving for $f(x)$:
$$f(x) = x + 1.$$

**Step 3: Verification.**

Check $f(x) = x+1$ in the original equation.

- **LHS:** $f(xy+1) = (xy+1)+1 = xy+2$.
- **RHS:** $f(x)f(y) - f(y) - x + 2 = (x+1)(y+1) - (y+1) - x + 2$
$$= xy + x + y + 1 - y - 1 - x + 2 = xy + 2.$$

LHS $=$ RHS. ✓

Also $f(0) = 0 + 1 = 1$. ✓

**Uniqueness.** Step 2 derived $f(x) = x+1$ directly from the equation (using on
ly the given value $f(0)=1$ and the consequence $f(1)=2$ from Step 1), with no f
ree parameters remaining. Hence the solution is unique.
