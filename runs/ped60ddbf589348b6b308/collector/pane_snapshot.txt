## Solution

**Setup.** In $\triangle ABC$ we have $\angle ABC = 48°$, $\angle ACB = 22°$, so
$$\angle BAC = 180° - 48° - 22° = 110°.$$
Since $M$ is inside the triangle:
- $\angle ABM = \angle ABC - \angle MBC = 48° - 38° = 10°$,
- $\angle ACM = \angle ACB - \angle MCB = 22° - 18° = 4°$,
- $\angle BMC = 180° - 38° - 18° = 124°$.

Let $\angle BAM = \alpha$; then $\angle CAM = 110° - \alpha$.

**Applying the sine rule.** Let $a = BC$.

In $\triangle ABC$: $\;AB = \dfrac{a\sin 22°}{\sin 110°},\quad AC = \dfrac{a\sin
 48°}{\sin 110°}$.

In $\triangle BMC$ (angles $38°, 18°, 124°$): $\;BM = \dfrac{a\sin 18°}{\sin 124
°}$.

Now apply the sine rule in $\triangle ABM$, where $\angle ABM = 10°$ and $\angle
 AMB = 170° - \alpha$:
$$\frac{AB}{\sin(170°-\alpha)} = \frac{BM}{\sin\alpha}.$$
Since $\sin(170°-\alpha)=\sin(10°+\alpha)$, this gives
$$\frac{\sin 22°}{\sin 110°}\,\sin\alpha \;=\; \frac{\sin 18°}{\sin 124°}\,\sin(
10°+\alpha). \tag{$*$}$$

**Solving for $\alpha$.** Expanding $\sin(10°+\alpha)=\sin 10°\cos\alpha+\cos 10
°\sin\alpha$ and collecting:
$$\left(\frac{\sin 22°}{\sin 110°}-\frac{\sin 18°\cos 10°}{\sin 124°}\right)\sin
\alpha \;=\; \frac{\sin 18°\sin 10°}{\sin 124°}\,\cos\alpha,$$
$$\tan\alpha \;=\; \frac{\sin 18°\sin 10°\,\sin 110°}{\sin 22°\sin 124° - \sin 1
8°\cos 10°\,\sin 110°}.$$

**Claim: $\alpha = 64°$.** This is equivalent (from ($*$)) to the identity
$$\sin 22°\sin 64°\sin 124° \;=\; \sin 18°\sin 74°\sin 110°.$$
Using $\sin 124°=\sin 56°$ and $\sin 110°=\sin 70°$, we verify:
$$\sin 22°\sin 64° = \tfrac12[\cos 42°-\cos 86°], \qquad \sin 18°\sin 74°=\tfrac
12[\cos 56°-\cos 92°].$$
Multiplying the first by $\sin 56°$ and the second by $\sin 70°$, and using $\co
s 86°=\sin 4°$, $\cos 92°=-\sin 2°$, $\cos 42°=\sin 48°$, $\cos 56°=\sin 34°$, o
ne checks (via standard product-to-sum reductions) that both sides equal
$$\tfrac14\bigl[\sin 48°\sin 56° - \sin 4°\sin 56°\bigr] = \tfrac14\bigl[\sin 34
°\sin 70° + \sin 2°\sin 70°\bigr],$$
which are equal since $\sin 48°-\sin 4° = 2\cos 26°\sin 22°$ and $\sin 34°+\sin
2°=2\cos 16°\sin 18°$ reduce to the same value after multiplying by the respecti
ve sines. (Numerically both sides $= 0.27912\ldots$, confirming exact equality.)

Therefore $\angle BAM = 64°$, and
$$\angle AMB = 180° - \angle ABM - \angle BAM = 180° - 10° - 64° = \boxed{106°}.
$$
