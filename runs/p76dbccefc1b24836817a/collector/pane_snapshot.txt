## Solution

**Answer-leak check:** The problem statement contains no solutions, answer value
s, or proof sketches. Proceeding.

---

We seek all prime pairs $(p,q)$ with $p \mid 30q-1$ and $q \mid 30p-1$.

**Step 1: Small primes.** If $p=2$: $30q-1$ is odd, so $2\nmid 30q-1$. If $p=3$:
 $30q-1\equiv -1\equiv 2\pmod 3$. If $p=5$: $30q-1\equiv -1\equiv 4\pmod 5$. Sam
e for $q$. So $p,q\notin\{2,3,5\}$; both are odd primes $\ge 7$.

**Step 2: $p\ne q$.** If $p=q$, then $p\mid 30p-1\Rightarrow p\mid 1$, impossibl
e.

**Step 3: Reduction to a single equation.** Write $30q-1=kp$, $30p-1=\ell q$ ($k
,\ell\in\mathbb Z_{>0}$). Multiplying:
$$(30q-1)(30p-1)=k\ell pq \;\Longrightarrow\; 900pq-30p-30q+1=k\ell pq.$$
Let $n=900-k\ell$. Then
$$npq=30(p+q)-1. \tag{$\star$}$$
Conversely, if $(\star)$ holds for a positive integer $n$, then $p(nq-30)=30q-1$
 and $q(np-30)=30p-1$, recovering both divisibilities. So the problem is equival
ent to finding primes $p,q\notin\{2,3,5\}$, $p\ne q$, and a positive integer $n$
 satisfying $(\star)$.

**Step 4: Bounding $n$.** Assume WLOG $p\le q$. Since $p,q$ are odd, $pq$ is odd
, and $30(p+q)-1$ is odd, so $n$ is odd. From $(\star)$:
- Upper: $npq\le 30(q+q)-1=60q-1<60q$, so $np\le 59$.
- Lower: $npq\ge 30(p+p)-1=60p-1$, so $nq\ge 60-1/p$; since $nq\in\mathbb Z$ and
 $p\ge 7$, $nq\ge 60$.

With $p\ge 7$: $n\le 59/7<9$, so $n\in\{1,3,5,7\}$.

**Step 5: Simon's factoring.** Rewrite $(\star)$: $n^2pq-30np-30nq=-n$, i.e.
$$(np-30)(nq-30)=900-n.$$
Set $A=np-30$, $B=nq-30$. Then $AB=900-n$, with $1\le A\le 29$ (from $31\le np\l
e 59$) and $B\ge 30$. Also $p=(A+30)/n$, $q=(B+30)/n$ must be primes, requiring
$n\mid A+30$ and $n\mid B+30$.

**Step 6: Case check.**

- **$n=1$:** $AB=899=29\cdot 31$. Divisors $\le 29$: $A=1,29$.
  - $A=1,B=899$: $p=31$, $q=929$. Both prime ($929$ checked up to $\sqrt{929}<31
$). ✓ → $(31,929)$.
  - $A=29,B=31$: $p=59$, $q=61$. Both prime. ✓ → $(59,61)$.

- **$n=3$:** $AB=897=3\cdot 13\cdot 23$. Need $3\mid A+30$, i.e. $3\mid A$. Amon
g divisors $\le 29$ ($1,3,13,23$), only $A=3$. Then $B=299$, $B+30=329\not\equiv
 0\pmod 3$. ✗.

- **$n=5$:** $AB=895=5\cdot 179$. Need $5\mid A$. Divisors $\le 29$: $1,5$. $A=5
\Rightarrow B=179$, $B+30=209\not\equiv 0\pmod 5$. ✗.

- **$n=7$:** $AB=893=19\cdot 47$. Need $A\equiv 5\pmod 7$ (since $A+30\equiv 0\p
mod 7$, $30\equiv 2$). Divisors $\le 29$: $1,19$. $19\equiv 5\pmod 7$ ✓. $A=19,B
=47$: $p=49/7=7$, $q=77/7=11$. Both prime. ✓ → $(7,11)$.

**Step 7: Verification.**
- $(7,11)$: $30\cdot 11-1=329=7\cdot 47$ ✓; $30\cdot 7-1=209=11\cdot 19$ ✓.
- $(59,61)$: $30\cdot 61-1=1829=59\cdot 31$ ✓; $30\cdot 59-1=1769=61\cdot 29$ ✓.
- $(31,929)$: $30\cdot 929-1=27869=31\cdot 899$ ✓; $30\cdot 31-1=929=929\cdot 1$
 ✓.

**Step 8: The solution set and sum.** The conditions are symmetric in $p,q$, so
every solution $(p,q)$ yields $(q,p)$. Treating $(p,q)$ as ordered pairs (as the
 notation $S=\{(p_i,q_i)\}$ indicates), the complete set is
$$S=\{(7,11),(11,7),(59,61),(61,59),(31,929),(929,31)\}.$$

The required sum is
$$\sum_{(p,q)\in S}(p+q)=2\big[(7+11)+(59+61)+(31+929)\big]=2(18+120+960)=2\cdot
 1098=\boxed{2196}.$$

(If pairs are taken unordered, the sum is $1098$.)
