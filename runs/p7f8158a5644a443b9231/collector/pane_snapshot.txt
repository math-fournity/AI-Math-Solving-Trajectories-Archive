## Solution

**Setup.** Triangle $ABC$ with $AB=5$, $BC=7$, $CA=8$. Point $P$ inside with $PA
:PB:PC = 2:3:6$. Cevians $AP$, $BP$, $CP$ meet the circumcircle $\omega$ again a
t $X$, $Y$, $Z$.

**Coordinates.** Place $B=(0,0)$, $C=(7,0)$. Then $A=(5/7,\; 20\sqrt{3}/7)$, giv
ing $[ABC]=10\sqrt{3}$ and circumradius $R = 7\sqrt{3}/3$, with circumcenter $O=
(7/2,\; 7\sqrt{3}/6)$, $R^2=49/3$.

**Finding $P$.** Let $PA=2t$, $PB=3t$, $PC=6t$, $s=t^2$. Solving the three dista
nce equations yields:
$$s = \frac{29 - 2\sqrt{51}}{13} \quad\text{(the root giving }P\text{ inside the
 triangle)}$$
$$P = \left(\frac{49-27s}{14},\;\frac{49+19s}{14\sqrt{3}}\right)$$

**Barycentric coordinates of $P$:**
$$\lambda_A = \frac{49+19s}{120},\quad \lambda_B = \frac{2(1+s)}{15},\quad \lamb
da_C = \frac{11-7s}{24}$$

**Power of $P$.** Computing $OP^2 = \frac{637s^2}{147}$, the power gives $k = R^
2 - OP^2 = \frac{4(29\sqrt{51}-102)}{39}$.

**Parametrizing $X,Y,Z$.** Since $P$ is inside $\omega$, by power of a point: $P
A\cdot PX = PB\cdot PY = PC\cdot PZ = k$. Setting $\alpha = k/(4s)$, $\beta = k/
(9s)$, $\gamma = k/(36s)$:
$$X = (1+\alpha)P - \alpha A,\quad Y = (1+\beta)P - \beta B,\quad Z = (1+\gamma)
P - \gamma C$$

**Area via determinant.** Writing the coefficient matrix $M$ (rows $X,Y,Z$; colu
mns $A,B,C$) as $M = \mathbf{u}\boldsymbol{\lambda}^T - \operatorname{diag}(\alp
ha,\beta,\gamma)$, the matrix determinant lemma gives:
$$\det(M) = \beta\gamma\,\lambda_A + \alpha\gamma\,\lambda_B + \alpha\beta\,\lam
bda_C$$

**Computing the key products.** With $\alpha\beta = k^2/(36s^2)$, $\beta\gamma =
 k^2/(324s^2)$, $\alpha\gamma = k^2/(144s^2)$:

$$\beta\gamma\,\lambda_A + \alpha\gamma\,\lambda_B + \alpha\beta\,\lambda_C = \f
rac{k^2}{s^2}\left(\frac{\lambda_A}{324}+\frac{\lambda_B}{144}+\frac{\lambda_C}{
36}\right)$$

The barycentric sum simplifies to $\frac{29-13s}{1944}$. Since $13s = 29 - 2\sqr
t{51}$, this becomes $\frac{2\sqrt{51}}{1944} = \frac{\sqrt{51}}{972}$.

**Computing $k^2/s^2$.** Direct computation gives $k^2 = \frac{16(53295 - 5916\s
qrt{51})}{1521}$ and $s^2 = \frac{1045 - 116\sqrt{51}}{169}$. Rationalizing:
$$\frac{53295 - 5916\sqrt{51}}{1045 - 116\sqrt{51}} = 51 \quad\text{(the cross t
erms cancel exactly since }53295\cdot116 = 5916\cdot1045\text{)}$$
Therefore $k^2/s^2 = \frac{16\cdot 51}{9} = \frac{272}{3}$.

**Final area:**
$$[XYZ] = \frac{272}{3}\cdot\frac{\sqrt{51}}{972}\cdot 10\sqrt{3} = \frac{680\sq
rt{153}}{729} = \frac{680\cdot 3\sqrt{17}}{729} = \frac{680\sqrt{17}}{243}$$

**Verification.** Numerically, $\frac{680\sqrt{17}}{243} \approx 11.534$, matchi
ng direct coordinate computation ($\approx 11.535$). ✓
