# Problem

In a specialized logistics hub, there are four cargo containers, each assigned a unique identification number from a set of four distinct positive integers $\{a, b, c, d\}$. A configuration of containers is classified as "Stable" if one can select two of these identification numbers such that their product is exactly divisible by the greatest common divisor (GCD) of the identification numbers of the remaining two containers.

For instance, a shipment with IDs $\{2, 4, 6, 8\}$ is Stable because the GCD of 2 and 6 is 2, and 2 is a factor of the product $4 \times 8 = 32$.

A safety inspector needs to determine the operational limit for these ID numbers. What is the largest possible integer $n$ such that every possible set of four distinct positive integers, where each integer is less than or equal to $n$, is guaranteed to be a Stable configuration?
