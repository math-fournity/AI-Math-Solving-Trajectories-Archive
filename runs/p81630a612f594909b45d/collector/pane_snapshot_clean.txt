## Solution

Define the continued fraction from the bottom up. Let

$$f_0 = 1 + \sqrt{1+x}, \qquad f_n = 2 + \frac{x}{f_{n-1}} \;\;(n \ge 1).$$

The given equation is $\dfrac{x}{f_{1985}} = 1$, i.e. $x = f_{1985}$.

**Key observation.** The recurrence $f_n = 2 + x/f_{n-1}$ has fixed points satis
fying $f = 2 + x/f$, i.e. $f^2 - 2f - x = 0$, giving

$$f = 1 \pm \sqrt{1+x}.$$

But $f_0 = 1 + \sqrt{1+x}$ is **exactly** one of these fixed points. Therefore $
f_0$ is a fixed point of the recurrence, so by induction

$$f_n = f_0 = 1 + \sqrt{1+x} \quad \text{for all } n \ge 0.$$

In particular $f_{1985} = 1 + \sqrt{1+x}$, and the equation becomes

$$x = 1 + \sqrt{1+x}.$$

**Solving.** We have $x - 1 = \sqrt{1+x} \ge 0$, so $x \ge 1$. Squaring:

$$(x-1)^2 = 1 + x \implies x^2 - 2x + 1 = 1 + x \implies x^2 - 3x = 0 \implies x
(x-3) = 0.$$

This gives $x = 0$ or $x = 3$.

**Checking against $x \ge 1$:**
- $x = 0$: fails $x \ge 1$ (indeed $x - 1 = -1 \ne \sqrt{1} = 1$). Extraneous.
- $x = 3$: $x - 1 = 2 = \sqrt{4} = \sqrt{1+3}$. ✓

**Verification of $x = 3$.** With $x = 3$: $f_0 = 1 + \sqrt{4} = 3 = x$, which i
s a fixed point, so every $f_n = 3$. The continued fraction equals $x / f_{1985}
 = 3/3 = 1$. ✓

$$\boxed{x = 3}$$
