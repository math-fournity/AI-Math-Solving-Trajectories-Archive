## Proof

We show that $A$ is measurable by expressing it via countable set operations on
measurable sets.

**Key idea.** A sequence of real numbers converges to a finite limit if and only
 if it is a Cauchy sequence. Thus
$$x \in A \iff (f_n(x))_{n\geq 1} \text{ is Cauchy} \iff \forall\, k\geq 1,\;\ex
ists\, N\geq 1,\;\forall\, m,n\geq N:\; |f_m(x)-f_n(x)|<\tfrac{1}{k}.$$

**Measurability of the building blocks.** Since each $f_n$ is measurable, the fu
nction $f_m - f_n$ is measurable, hence $|f_m - f_n|$ is measurable. Therefore,
for every $k,m,n\geq 1$, the set
$$B_{k,m,n}:=\{x\in E : |f_m(x)-f_n(x)|<1/k\} = (|f_m-f_n|)^{-1}\bigl((-1/k,\,1/
k)\bigr)$$
is measurable (preimage of an open set under a measurable function).

**Set-theoretic representation.** Translating the Cauchy condition into set oper
ations:
$$A = \bigcap_{k=1}^{\infty}\;\bigcup_{N=1}^{\infty}\;\bigcap_{m=N}^{\infty}\;\b
igcap_{n=N}^{\infty} B_{k,m,n}.$$

Indeed:
- $\bigcap_{m\geq N}\bigcap_{n\geq N} B_{k,m,n}$ is the set of $x$ such that $|f
_m(x)-f_n(x)|<1/k$ for **all** $m,n\geq N$.
- $\bigcup_{N\geq 1}(\cdots)$ asserts this holds for **some** $N$.
- $\bigcap_{k\geq 1}(\cdots)$ requires it for **every** $k$, which is exactly th
e Cauchy condition.

**Closure under countable operations.** Each $B_{k,m,n}$ is measurable. The $\si
gma$-algebra of measurable sets is closed under countable intersections and coun
table unions. The expression for $A$ involves only countably many such operation
s (indexed by $k,N,m,n\in\mathbb{N}$). Hence $A$ is measurable.

**Conclusion.** The set $A = \{x\in E : \lim_{n\to\infty} f_n(x) \text{ exists f
initely}\}$ is measurable. $\blacksquare$
