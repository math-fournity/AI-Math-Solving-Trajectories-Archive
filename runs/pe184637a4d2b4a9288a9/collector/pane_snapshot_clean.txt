## Setup

Define $b_n = a_n / n$, which is a positive integer since $a_n$ is a multiple of
 $n$. The recurrence becomes:
$$b_n = \left\lceil \frac{c(n-1)}{n}\, b_{n-1}\right\rceil, \quad n \geq 2$$
Synchronization means $b_m = 1$ for some $m$. Set $r_n = c(n-1)/n$, so $b_n = \l
ceil r_n\, b_{n-1}\rceil$.

## Part 1: $c \leq 1/2$ always synchronizes

For $c \leq 1/2$, we have $r_n = \frac{c(n-1)}{n} \leq \frac{n-1}{2n} < \frac{1}
{2}$ for all $n \geq 2$.

Since $r_n\, b_{n-1} < \frac{b_{n-1}}{2}$ and the ceiling function is monotone:
$$b_n = \lceil r_n\, b_{n-1}\rceil \leq \left\lceil \frac{b_{n-1}}{2}\right\rcei
l \leq \frac{b_{n-1}+1}{2}.$$

For $b_{n-1} \geq 2$: $\frac{b_{n-1}+1}{2} \leq b_{n-1} - \frac{1}{2} < b_{n-1}$
. Since $b_n$ is an integer with $b_n < b_{n-1}$, we get $b_n \leq b_{n-1} - 1$.

Thus $(b_n)$ is a sequence of positive integers that **strictly decreases by at
least 1** at each step while $b_{n-1} \geq 2$. Starting from any $b_1 = a_1$, it
 reaches $b_m = 1$ within at most $a_1 - 1$ steps. **Every starting value synchr
onizes.**

## Part 2: $c > 1/2$ fails for some starting value

**Key observation (trapping at 2):** Since $2c > 1$, we have $2c\cdot\frac{n-1}{
n} \to 2c > 1$. So there exists $N$ such that for all $n \geq N$:
$$r_n \cdot 2 = \frac{2c(n-1)}{n} > 1.$$
This means: if $b_{n-1} \geq 2$ and $n \geq N$, then $b_n = \lceil r_n\, b_{n-1}
\rceil \geq \lceil r_n \cdot 2\rceil \geq 2$. **Once the sequence is $\geq 2$ at
 some $n \geq N$, it can never drop below 2 again.**

**Lower bound on $b_n$:** Since $b_n = \lceil r_n\, b_{n-1}\rceil \geq r_n\, b_{
n-1}$, by induction:
$$b_n \geq \prod_{j=2}^{n} r_j \cdot b_1 = c^{n-1}\cdot\frac{1}{n}\cdot M, \quad
 \text{where } M = a_1.$$

**Choosing $M$:** Set $M = \left\lceil \max_{1 \leq n \leq N} \frac{2n}{c^{n-1}}
 \right\rceil$. This is a finite positive integer. Then for every $n \leq N$:
$$b_n \geq \frac{c^{n-1}\, M}{n} \geq 2.$$

**Combining:** For $n \leq N$, the lower bound gives $b_n \geq 2$. For $n = N$,
we have $b_N \geq 2$, and the trapping property ensures $b_n \geq 2$ for all $n
> N$ by induction. Therefore $b_n \geq 2$ for **all** $n$, and the sequence **ne
ver synchronizes**.

This construction works for every $c > 1/2$ (including $c \geq 1$, where $N$ sti

ows faster).

## Conclusion

- **$c \leq 1/2$:** For every $a_1$, the sequence synchronizes (strict decrease
to 1).
- **$c > 1/2$:** There exists $a_1$ (chosen large enough) such that the sequence
 never synchronizes (trapped at $\geq 2$).

The supremum of all valid $c$ is:

$$\boxed{\dfrac{1}{2}}$$
