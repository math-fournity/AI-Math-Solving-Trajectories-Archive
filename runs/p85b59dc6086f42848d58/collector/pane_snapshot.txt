## Proof

We find all positive integer solutions $(x, y, z, p)$ of $x^p + y^p = p^z$ with
$p$ prime.

---

### Case 1: $p = 2$

We solve $x^2 + y^2 = 2^z$.

If one of $x, y$ is even and the other odd, then $x^2 + y^2$ is odd, which canno
t equal $2^z$ ($z \geq 1$). So $x, y$ have the same parity.

If both are odd, $x^2 + y^2 \equiv 2 \pmod{4}$, forcing $z = 1$ and $x^2 + y^2 =
 2$, hence $x = y = 1$.

If both are even, write $x = 2a, y = 2b$; then $a^2 + b^2 = 2^{z-2}$. Repeating,
 we extract the common power of 2: let $x = 2^k u,\, y = 2^k v$ with $u, v$ odd.
 Then $u^2 + v^2 = 2^{z - 2k}$, and since $u, v$ are odd, $z - 2k = 1$ and $u^2
+ v^2 = 2$, giving $u = v = 1$.

**Solutions for $p = 2$:** $(x, y, z) = (2^k,\, 2^k,\, 2k+1)$ for $k = 0, 1, 2,
\ldots$

---

### Case 2: $p$ odd

Let $d = \gcd(x, y)$, $x = da$, $y = db$, $\gcd(a, b) = 1$. Then
$$d^p(a^p + b^p) = p^z.$$
Since $d^p \mid p^z$, we have $d = p^s$ for some $s \geq 0$, giving
$$a^p + b^p = p^m, \quad m := z - sp, \quad \gcd(a,b) = 1, \quad a, b \geq 1.$$

Factor: $a^p + b^p = (a+b)\,Q$, where $Q = a^{p-1} - a^{p-2}b + \cdots + b^{p-1}
$. Since the product is $p^m$, both $a+b$ and $Q$ are powers of $p$. As $a + b \
geq 2$, we have $a + b = p^r$ for some $r \geq 1$.

**Applying LTE (Lifting the Exponent).** Since $p$ is an odd prime, $p \mid a +
b$, and $p \nmid a,\; p \nmid b$ (the latter because $\gcd(a,b)=1$ and $p \mid a
+b$ would force $p \mid \gcd(a,b)$ if $p \mid a$), we get:
$$v_p(a^p + b^p) = v_p(a+b) + v_p(p) = r + 1.$$
Thus $m = r + 1$, and consequently
$$Q = \frac{a^p + b^p}{a+b} = \frac{p^{r+1}}{p^r} = p.$$

**Bounding $Q$.** By convexity of $t \mapsto t^p$ (Jensen's inequality),
$$a^p + b^p \geq 2\left(\frac{a+b}{2}\right)^p = \frac{(a+b)^p}{2^{p-1}},$$
so
$$Q = \frac{a^p+b^p}{a+b} \geq \frac{(a+b)^{p-1}}{2^{p-1}} = \left(\frac{p^r}{2}
\right)^{p-1}.$$
Since $Q = p$, we need
$$\left(\frac{p^r}{2}\right)^{p-1} \leq p \quad\Longleftrightarrow\quad p^{r(p-1
)-1} \leq 2^{p-1}.$$

**For $p \geq 5$, $r \geq 1$:** We have $r(p-1) - 1 \geq p - 2 \geq 3$, so $p^{p
-2} \leq 2^{p-1}$. But $5^3 = 125 > 16 = 2^4$, and $p^{p-2}/2^{p-1}$ is increasi
ng for $p \geq 5$. Hence **no solutions exist for $p \geq 5$**.

**For $p = 3$:** The condition becomes $3^{2r - 1} \leq 4$. For $r = 1$: $3^1 =
3 \leq 4$ ✓. For $r \geq 2$: $3^3 = 27 > 4$ ✗. So $r = 1$, meaning $a + b = 3$ a
nd $Q = 3$.

The pairs $(a, b)$ with $a + b = 3$, $a, b \geq 1$, $\gcd(a,b) = 1$ are $(1, 2)$
 and $(2, 1)$. Checking:
$$Q = \frac{1^3 + 2^3}{3} = \frac{9}{3} = 3. \quad\checkmark$$

So $a^3 + b^3 = 9 = 3^2$, i.e., $m = 2$. Recalling $x = 3^s a$, $y = 3^s b$, $z
= 3s + m = 3s + 2$:

**Solutions for $p = 3$:** $(x, y, z) = (3^s,\, 2\cdot 3^s,\, 3s+2)$ or $(2\cdot
 3^s,\, 3^s,\, 3s+2)$ for $s = 0, 1, 2, \ldots$

---

### Verification

- **$p = 2$, $k$:** $(2^k)^2 + (2^k)^2 = 2\cdot 2^{2k} = 2^{2k+1}$. ✓
- **$p = 3$, $s$:** $(3^s)^3 + (2\cdot 3^s)^3 = 3^{3s}(1 + 8) = 9\cdot 3^{3s} =
3^{3s+2}$. ✓

---

### Complete Solution

All positive integer solutions $(x, y, z, p)$ are:

$$\boxed{(x,\, y,\, z,\, p) = (2^k,\, 2^k,\, 2k+1,\, 2), \quad k \geq 0,}$$

$$\boxed{(x,\, y,\, z,\, p) = (3^s,\, 2\cdot 3^s,\, 3s+2,\, 3) \text{ or } (2\cd
ot 3^s,\, 3^s,\, 3s+2,\, 3), \quad s \geq 0,}$$

and there are **no solutions** for primes $p \geq 5$.
