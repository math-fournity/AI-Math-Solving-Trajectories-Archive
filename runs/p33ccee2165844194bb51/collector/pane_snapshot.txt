## Solution

**Setup.** Place the isosceles triangle with $B=(-1,0)$, $C=(1,0)$, $A=(0,h)$, s
o $BC=2$ and $AB=AC=\sqrt{1+h^2}=:d$. The target ratio is $r = AB/BC = d/2$.

**Incircle tangent points.** The semiperimeter is $s = 1+d$, the inradius is $\r
ho = h/(1+d)$, and the incenter is $O=(0,\rho)$. By symmetry $K=(0,0)$ (midpoint
 of $BC$). The tangent lengths give $BM=BK=1$ and $AL=AM=d-1$, yielding:
$$M=\left(-1+\tfrac{1}{d},\;\tfrac{h}{d}\right),\qquad L=\left(1-\tfrac{1}{d},\;
\tfrac{h}{d}\right).$$

**Finding $N = OL \cap KM$.** Line $KM$: $(t(-1+1/d),\; th/d)$. Line $OL$: $(s(1
-1/d),\;\rho + s\cdot h/[d(1+d)])$. From the $x$-equation, $s=-t$; substituting
into the $y$-equation gives $t = d/(d+2)$. Hence:
$$N = \left(\frac{-(d-1)}{d+2},\;\frac{h}{d+2}\right).$$

**Finding $Q = BN \cap CA$.** Line $BN$: $(-1+3u/(d+2),\; uh/(d+2))$. Line $CA$:
 $(1-v,\;vh)$. The $y$-equation gives $v = u/(d+2)$; the $x$-equation gives $u =
 (d+2)/2$, so $v = 1/2$. Therefore:
$$Q = \left(\tfrac{1}{2},\;\tfrac{h}{2}\right),$$
the **midpoint of $CA$**, independent of $h$.

**Foot of perpendicular $P$.** Line $BQ$ has direction $(3,h)$. The projection o
f $A-B = (1,h)$ onto $(3,h)$ gives parameter $t_P = (3+h^2)/(9+h^2)$, so:
$$P = \left(\frac{2h^2}{9+h^2},\;\frac{h(3+h^2)}{9+h^2}\right),\qquad t_Q = \tfr
ac{1}{2}.$$

**Computing the three distances** (each scaled by $1/\sqrt{9+h^2}$):
$$BP = \frac{3+h^2}{\sqrt{9+h^2}},\qquad AP = \frac{2h}{\sqrt{9+h^2}},\qquad PQ
= \frac{|h^2-3|}{2\sqrt{9+h^2}}.$$

(The $AP$ calculation: $AP^2 = 4h^2(h^2+9)/(9+h^2)^2 = 4h^2/(9+h^2)$.)

**Applying the condition $BP = AP + 2PQ$:**
$$3+h^2 = 2h + |h^2 - 3|.$$

- **Case $h^2 \geq 3$:** $3+h^2 = 2h + h^2 - 3 \Rightarrow h = 3$. ✓ ($9 \geq 3$
)
- **Case $h^2 < 3$:** $3+h^2 = 2h + 3 - h^2 \Rightarrow h^2 = h \Rightarrow h =
1$ (rejecting $h=0$). ✓ ($1 < 3$)

**Verification.**
- $h=3$: $BP = 12/\sqrt{18} = 2\sqrt{2}$, $AP = 6/\sqrt{18} = \sqrt{2}$, $PQ = 6
/(2\sqrt{18}) = \sqrt{2}/2$. Then $AP + 2PQ = \sqrt{2} + \sqrt{2} = 2\sqrt{2} =
BP$. ✓
- $h=1$: $BP = 4/\sqrt{10}$, $AP = 2/\sqrt{10}$, $PQ = 1/\sqrt{10}$. Then $AP +
2PQ = 4/\sqrt{10} = BP$. ✓

**Final computation.** With $r = \sqrt{1+h^2}/2$:
$$h=3:\; r^2 = \tfrac{10}{4} = \tfrac{5}{2},\qquad h=1:\; r^2 = \tfrac{2}{4} = \
tfrac{1}{2}.$$
$$r_1^2 + r_2^2 = \frac{5}{2} + \frac{1}{2} = \boxed{3}.$$
