## Proof

We claim that such non-constant polynomials **do exist**.

**Key observation.** Note that for any polynomial $r$,
$$e^{r(z)}(r'(z)+1) = \frac{d}{dz}e^{r(z)} + e^{r(z)}.$$
Setting $F = e^{p}$ and $G = e^{q}$, the given equation becomes
$$(F+G)' + (F+G) = 0.$$
Letting $H = F + G = e^{p} + e^{q}$, this is the ODE $H' + H = 0$, whose general
 solution is $H(z) = Ce^{-z}$ for some constant $C$. Thus the original equation
is equivalent to
$$e^{p(z)} + e^{q(z)} = Ce^{-z}. \tag{$\ast$}$$

**Constructing a solution.** Choose
$$p(z) = -z, \qquad q(z) = -z + 1.$$
Both are non-constant (degree 1) polynomials. Then $p'(z) = -1$ and $q'(z) = -1$
, so
$$p'(z) + 1 = 0, \qquad q'(z) + 1 = 0.$$
Therefore
$$e^{p(z)}(p'(z)+1) + e^{q(z)}(q'(z)+1) = e^{p(z)}\cdot 0 + e^{q(z)}\cdot 0 = 0$
$
for every complex number $z$.

(Equivalently, $e^{p(z)} + e^{q(z)} = e^{-z} + e^{-z+1} = (1+e)\,e^{-z}$, confir
ming $(\ast)$ with $C = 1+e \neq 0$.)

More generally, any pair $p(z) = -z + \alpha$, $q(z) = -z + \beta$ with constant
s $\alpha, \beta$ works, since then $p' = q' = -1$ and both summands vanish indi
vidually.

**Conclusion.** Non-constant polynomials $p$ and $q$ satisfying the given identi
ty do exist; for instance, $p(z) = -z$ and $q(z) = -z+1$.
