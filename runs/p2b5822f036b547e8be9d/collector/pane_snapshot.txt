## Proof

We evaluate the iterated integral
$$I = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} \frac{xy}{1+(x^2+y^2)^2}\,d
x\,dy.$$

**Step 1: Analyze the inner integral (over $x$, with $y$ fixed).**

For each fixed $y \in \mathbb{R}$, define
$$I(y) = \int_{-\infty}^{\infty} \frac{xy}{1+(x^2+y^2)^2}\,dx.$$

Consider the integrand as a function of $x$:
$$g_y(x) = \frac{xy}{1+(x^2+y^2)^2}.$$

The denominator $1+(x^2+y^2)^2$ is an **even** function of $x$, while the numera
tor $xy$ is **odd** in $x$. Hence $g_y(-x) = -g_y(x)$: the integrand is an odd f
unction of $x$.

**Step 2: Verify absolute integrability in $x$ (so the symmetry argument is vali
d).**

We check that $\int_{-\infty}^{\infty} |g_y(x)|\,dx < \infty$ for each fixed $y$
:
- Near $x = 0$: the integrand is bounded (continuous), so no singularity.
- For large $|x|$: $|g_y(x)| = \dfrac{|x||y|}{1+(x^2+y^2)^2} \sim \dfrac{|y|}{|x
|^3}$, and $\int^{\infty} \frac{dx}{x^3}$ converges.

So $g_y$ is absolutely integrable in $x$ for every fixed $y$. Being odd and abso
lutely integrable over the symmetric interval $(-\infty, \infty)$,
$$I(y) = 0 \quad \text{for every } y \in \mathbb{R}.$$

**Step 3: Evaluate the outer integral.**
$$I = \int_{-\infty}^{\infty} I(y)\,dy = \int_{-\infty}^{\infty} 0\,dy = 0.$$

**Conclusion.** The iterated integral equals
$$\boxed{0}.$$
