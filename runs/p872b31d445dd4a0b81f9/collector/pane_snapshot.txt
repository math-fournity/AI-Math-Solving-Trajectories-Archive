## Solution

**Intersection points.** Setting $C_1 = C_2$:
$$ax^2 = -ax^2 + 2abx \implies 2ax(x-b)=0 \implies x=0 \text{ or } x=b.$$
The intersection points are $(0,0)$ and $(b, ab^2)$. For $x \in (0,b)$, $C_2(x)
\ge C_1(x)$ (e.g. at $x=b/2$: $C_2 = 3ab^2/4 > C_1 = ab^2/4$), so $S = \{(x,y):
0 \le x \le b,\; ax^2 \le y \le -ax^2+2abx\}$.

**Volume $V_x$ (revolution about $x$-axis, washer method):**
$$V_x = \pi\int_0^b\!\left[C_2(x)^2 - C_1(x)^2\right]dx = \pi\int_0^b\!\left[(-a
x^2+2abx)^2 - (ax^2)^2\right]dx.$$
Expanding:
$$(-ax^2+2abx)^2 - (ax^2)^2 = (a^2x^4 - 4a^2bx^3 + 4a^2b^2x^2) - a^2x^4 = 4a^2b(
-x^3+b x^2).$$
Therefore
$$V_x = 4\pi a^2 b\int_0^b\!(-x^3+bx^2)\,dx = 4\pi a^2 b\!\left[-\frac{x^4}{4}+\
frac{bx^3}{3}\right]_0^b = 4\pi a^2 b\!\left(-\frac{b^4}{4}+\frac{b^4}{3}\right)
 = 4\pi a^2 b\cdot\frac{b^4}{12} = \frac{\pi a^2 b^5}{3}.$$

**Volume $V_y$ (revolution about $y$-axis, shell method):** A vertical strip at
position $x$ with height $C_2(x)-C_1(x)$ generates a cylindrical shell of radius
 $x$:
$$V_y = 2\pi\int_0^b\! x\left[C_2(x)-C_1(x)\right]dx = 2\pi\int_0^b\! x\left[(-a
x^2+2abx)-ax^2\right]dx = 2\pi\int_0^b\!(-2ax^3+2abx^2)\,dx.$$
$$V_y = 2\pi\!\left[-\frac{2a x^4}{4}+\frac{2ab x^3}{3}\right]_0^b = 2\pi\!\left
(-\frac{ab^4}{2}+\frac{2ab^4}{3}\right) = 2\pi\cdot ab^4\cdot\frac{1}{6} = \frac
{\pi a b^5}{3}.$$

*Verification of $V_y$ via washers.* Solving $C_1: x=\sqrt{y/a}$ and $C_2: x = b
-\sqrt{b^2-y/a}$ (the relevant branch), with $u=y/a$, $dy=a\,du$, $u\in[0,b^2]$:
$$V_y = \pi a\int_0^{b^2}\!\left[u - (b-\sqrt{b^2-u})^2\right]du = 2\pi a\int_0^
{b^2}\!\left[u-b^2+b\sqrt{b^2-u}\right]du.$$
$$= 2\pi a\!\left[\frac{u^2}{2}-b^2 u - \frac{2b}{3}(b^2-u)^{3/2}\right]_0^{b^2}
 = 2\pi a\!\left[\left(-\frac{b^4}{2}\right)-\left(-\frac{2b^4}{3}\right)\right]
 = 2\pi a\cdot\frac{b^4}{6} = \frac{\pi a b^5}{3}. \checkmark$$

**The ratio:**
$$\frac{V_x}{V_y} = \frac{\pi a^2 b^5/3}{\pi a b^5/3} = \boxed{a}.$$
