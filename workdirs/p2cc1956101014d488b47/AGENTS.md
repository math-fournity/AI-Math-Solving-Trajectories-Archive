# Problem

A high-security data center contains a network of 100 distinct servers, indexed from 1 to 100. Every server is programmed to automatically forward its daily backup data to exactly one other server in the network. Two strict security protocols are in place:

1.  **Anti-Loop Protocol:** No server is permitted to forward data to itself.
2.  **Redundancy Protocol:** In any selection of 40 servers, there must be at least one server that receives data from another server within that same selection.

A systems administrator needs to identify a "Primary Set" of servers. A set of servers is considered a Primary Set if every server in the entire network of 100 is either a member of that set or is a recipient of data forwarded by a member of that set.

What is the smallest positive integer $k$ such that, regardless of how the specific forwarding assignments are configured (as long as they follow the protocols), there is always a Primary Set containing exactly $k$ servers?
