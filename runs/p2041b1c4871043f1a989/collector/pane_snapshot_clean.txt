### 设定

递推关系为：对于任意素数 $p$ 和自然数 $k$，
$$a_{kp+1} = p\,a_k - 3\,a_p + 13.$$

目标是求 $a_{2011}$。

### 第一步：猜想闭式

猜想 $a_n = An + B$ 为线性解。代入递推式：

- 左边：$a_{kp+1} = A(kp+1) + B = Akp + A + B$。
- 右边：$p(Ak+B) - 3(Ap+B) + 13 = Akp + Bp - 3Ap - 3B + 13 = Akp + (B-3A)p - 3B
+ 13$。

令两边相等（对所有素数 $p$ 成立）：

$$A + B = (B - 3A)\,p - 3B + 13.$$

对 $p$ 的系数和常数项分别归零：
- $p$ 的系数：$B - 3A = 0 \Rightarrow B = 3A$。
- 常数项：$A + B + 3B = 13 \Rightarrow A + 4B = 13 \Rightarrow A + 12A = 13 \Rig
htarrow A = 1$，$B = 3$。

因此 $a_n = n + 3$ 满足递推关系。

### 第二步：验证序列被唯一确定

**所有 $n \geq 3$ 的项可由更小的项表出。** 对任意 $n \geq 3$，取 $n - 1$ 的任一
素因子 $p$，令 $k = (n-1)/p \geq 1$，则 $n = kp + 1$，且 $k < n$、$p < n$。因此
$a_n$ 由 $a_k$ 和 $a_p$ 决定，二者下标均小于 $n$。整个序列由 $a_1, a_2$ 唯一决定
。

**一致性条件强制 $a_1, a_2$ 取唯一值。** 同一个 $a_n$ 可通过不同的素数 $p$ 计算
，结果必须一致：

1. **由 $a_7$ 的一致性**：
   - $p=2, k=3$：$a_7 = 2a_3 - 3a_2 + 13$。
   - $p=3, k=2$：$a_7 = 3a_2 - 3a_3 + 13$。
   - 两式相等：$2a_3 - 3a_2 = 3a_2 - 3a_3$，即 $5a_3 = 6a_2$，故 $a_3 = \tfrac{6
}{5}a_2$。

2. **由 $a_{11}$ 的一致性**：
   - $p=2, k=5$：$a_{11} = 2a_5 - 3a_2 + 13$。
   - $p=5, k=2$：$a_{11} = 5a_2 - 3a_5 + 13$。
   - 两式相等：$2a_5 - 3a_2 = 5a_2 - 3a_5$，即 $5a_5 = 8a_2$，故 $a_5 = \tfrac{8
}{5}a_2$。

   又由 $p=2, k=2$：$a_5 = 2a_2 - 3a_2 + 13 = -a_2 + 13$。

   因此 $\tfrac{8}{5}a_2 = -a_2 + 13$，即 $\tfrac{13}{5}a_2 = 13$，得 $a_2 = 5$
。

3. **回代求 $a_1$**：
   - $a_3 = \tfrac{6}{5} \cdot 5 = 6$。
   - 由 $p=2, k=1$：$a_3 = 2a_1 - 3a_2 + 13 \Rightarrow 6 = 2a_1 - 15 + 13 \Righ
tarrow 2a_1 = 8 \Rightarrow a_1 = 4$。

因此 $a_1 = 4, a_2 = 5$ 被唯一确定，序列唯一。

### 第三步：归纳验证 $a_n = n + 3$

**归纳基础**：$a_1 = 4 = 1 + 3$ ✓，$a_2 = 5 = 2 + 3$ ✓。

**归纳步骤**：设对所有 $m < n$ 有 $a_m = m + 3$。对 $n \geq 3$，取 $n - 1$ 的素
因子 $p$，令 $k = (n-1)/p$，则 $k < n$ 且 $p < n$：

$$a_n = a_{kp+1} = p\,a_k - 3\,a_p + 13 = p(k+3) - 3(p+3) + 13 = pk + 3p - 3p -
9 + 13 = pk + 4 = (n-1) + 4 = n + 3. \quad\checkmark$$

### 结论

$$a_{2011} = 2011 + 3 = \boxed{2014}.$$
