## Setup: Computing $\|T^n\|$

The kernel of $T$ is $k(x,y) = \mathbf{1}_{x+y \le 1} \ge 0$, so all iterated ke
rnels $k_n \ge 0$. Therefore $\|T^n\| = \sup_x (T^n\mathbf{1})(x)$, where $\math
bf{1}$ is the constant function $1$.

Let $f_n = T^n\mathbf{1}$, so $f_1(x) = 1-x$ and $f_{n+1}(x) = \int_0^{1-x} f_n(
y)\,dy$.

**Substitution.** Set $g_n(u) = f_n(1-u)$. Then $g_1(u) = u$ and
$$g_{n+1}(u) = \int_0^u g_n(1-y)\,dy.$$
Since $g_n'(u) = g_{n-1}(1-u) \ge 0$, each $g_n$ is increasing, so $\|T^n\| = \s
up_u g_n(u) = g_n(1) =: a_n$.

## Generating function

Define $F(u,z) = \sum_{n=1}^\infty g_n(u)z^n$ and $G(u,z) = F(1-u,z)$. From the
recurrence:
$$\frac{F(u,z)}{z} - u = \int_0^u G(y,z)\,dy, \qquad F(u,z) = uz + z\int_0^u G(y
,z)\,dy.$$

Set $P = 1+F$, $Q = 1+G$. Differentiating:
$$P_u = z(1+G) = zQ, \qquad Q_u = -z(1+F) = -zP.$$

Hence $P_{uu} = z\,Q_u = -z^2 P$, giving $P(u) = A\cos(zu) + B\sin(zu)$.

**Boundary conditions.** $F(0,z)=0 \Rightarrow P(0)=1 \Rightarrow A=1$. Also $P_
u(0) = zQ(0) = z(1+G(0,z)) = z(1+F(1,z)) = zP(1)$, while $P_u(0) = Bz$, so $B =
P(1)$. Thus:
$$P(1) = \cos z + P(1)\sin z \implies P(1) = \frac{\cos z}{1 - \sin z}.$$

Since $Q(0) = P(1)$ and $Q(0) = 1 + G(0,z) = 1 + \sum_{n=1}^\infty a_n z^n$:
$$\boxed{\sum_{n=0}^\infty a_n z^n = \frac{\cos z}{1-\sin z} = \frac{1+\sin z}{\
cos z} = \sec z + \tan z.}$$

**Verification of coefficients:** $\sec z + \tan z = 1 + z + \frac{z^2}{2} + \fr

match direct computation of $\|T^n\|$.

## Radius of convergence and the limit

The function $\sec z + \tan z = \frac{1+\sin z}{\cos z}$ has singularities exact
ly at the zeros of $\cos z$, namely $z = \frac{\pi}{2} + k\pi$, $k \in \mathbb{Z
}$. The nearest singularity to the origin is at $z = \pm\frac{\pi}{2}$, so the r
adius of convergence is
$$R = \frac{\pi}{2}.$$

By the Cauchy–Hadamard theorem, $\frac{1}{R} = \limsup_{n\to\infty} |a_n|^{1/n}$
. Since all $a_n > 0$:
$$\lim_{n\to\infty} a_n^{1/n} = \frac{1}{R} = \frac{2}{\pi}.$$
