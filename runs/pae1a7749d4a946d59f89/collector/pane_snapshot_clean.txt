Looking at this problem, I need to determine which $(m,n)$ grids allow complete
removal starting from one active corner.

## Setting Up the Framework

**Reformulation as an ordering problem.** When server $v$ is removed, its state
must be Active (1). Its state at removal time equals its initial state plus the
number of already-removed neighbors (mod 2), since each neighbor removal toggles
 it. So:

- **Corner $c$** (initial state 1): needs $1 + \text{(preceding neighbors)} \equ
iv 1 \pmod{2}$, so **even** number of preceding neighbors.
- **Every other vertex** (initial state 0): needs $0 + \text{(preceding neighbor
s)} \equiv 1 \pmod{2}$, so **odd** number of preceding neighbors.

This is equivalent to finding a **linear ordering** (acyclic orientation) of all
 $mn$ vertices where the corner has even in-degree and all others have odd in-de
gree.

## Necessary Condition

The sum of all in-degrees equals $|E| = 2mn - m - n$. The required parity sum is
 $0 + (mn-1)\cdot 1 = mn - 1 \pmod{2}$. Equating:

$$2mn - m - n \equiv mn - 1 \pmod{2} \implies (m-1)(n-1) \equiv 0 \pmod{2}.$$

So **at least one of $m, n$ must be odd**. If both are even, $(m-1)(n-1)$ is odd
×odd = odd, and no valid ordering exists.

## Sufficient Condition: Construction for $m$ Odd

I give an explicit ordering for any $m$ odd, $n \geq 1$. Label vertices $(i,j)$,
 $1 \le i \le m$, $1 \le j \le n$, corner at $(1,1)$.

**Ordering:**
1. Place corner $(1,1)$ first (in-degree 0, even ✓).
2. **Column 1:** place $(2,1), (3,1), \ldots, (m,1)$ top to bottom.
3. **Each column $j \ge 2$:** place **odd rows first** — $(1,j), (3,j), \ldots,
(m,j)$ — then **even rows** — $(2,j), (4,j), \ldots, (m-1,j)$.

**Verification of in-degree parities:**

- **$(1,1)$:** 0 preceding neighbors. Even ✓.
- **$(i,1)$, $i \ge 2$:** only preceding neighbor is $(i-1,1)$ (already placed).
 Count = 1. Odd ✓.
- **Odd row $(i,j)$, $j \ge 2$:** horizontal neighbor $(i,j-1)$ is placed (count
 1); vertical neighbors $(i\pm1,j)$ have even indices, placed in the second phas
e — not yet placed. Total = 1. Odd ✓.
- **Even row $(i,j)$, $j \ge 2$:** horizontal neighbor $(i,j-1)$ placed (count 1
); both vertical neighbors $(i-1,j)$ and $(i+1,j)$ have odd indices, already pla
ced in phase 1 (count 2). Total = 3. Odd ✓. (For boundary even rows $i=2$ or $i=
m-1$, both vertical neighbors still exist and are odd-indexed since $m$ is odd,
so count remains 3.)

All vertices satisfy the parity condition. By symmetry (transposing the grid), t
he same construction works when $n$ is odd (any $m$).

## Verification on Small Cases

- **$(1,n)$:** path graph; ordering $(1,1),(1,2),\ldots,(1,n)$ gives each vertex
 exactly 1 preceding neighbor. ✓ (special case of $m$ odd).
- **$(2,3)$:** ordering $(1,1),(1,2),(2,1),(1,3),(2,3),(2,2)$ — verified all in-
degrees have correct parity. ✓
- **$(3,3)$:** ordering $(1,1),(1,2),(2,1),(1,3),(2,3),(2,2),(3,1),(3,3),(3,2)$
— verified. ✓
- **$(2,2)$:** both even, $(m-1)(n-1)=1$ odd. ✗ (no ordering possible).

## Counting

The stable pairs are exactly those with **at least one of $m, n$ odd**.

- Total pairs with $1 \le m, n \le 10$: $10 \times 10 = 100$.
- Even values in $\{1,\ldots,10\}$: $\{2, 4, 6, 8, 10\}$ — that's 5 values.
- Pairs with both even (non-stable): $5 \times 5 = 25$.
- Stable pairs: $100 - 25 = \boxed{75}$.
