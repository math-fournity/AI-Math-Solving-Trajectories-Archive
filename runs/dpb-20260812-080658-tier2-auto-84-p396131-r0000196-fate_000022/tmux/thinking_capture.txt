Proof: Let R be a finite commutative ring with identity, and let I be a prime
ideal of R. We need to show I is maximal, i.e., there is no ideal J with I ⊊ J ⊊
R.

Consider the quotient ring R/I. Since I is prime, R/I is an integral domain.
Since R is finite, R/I is also finite. So R/I is a finite integral domain.

Key fact: Every finite integral domain is a field.

Proof of key fact: Let D be a finite integral domain with n elements, and let a
∈ D, a ≠ 0. Consider the map φ: D → D defined by φ(x) = ax. Since D is an
integral domain and a ≠ 0, this map is injective (if ax = ay then a(x−y) = 0, so
x = y). Since D is finite and φ is injective, φ is surjective. Thus there exists
x ∈ D with ax = 1, so a has a multiplicative inverse. Hence every nonzero
element is a unit, so D is a field.

Therefore R/I is a field, which means I is a maximal ideal. QED
