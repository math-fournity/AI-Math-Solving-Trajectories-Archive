# Proof

The answer is **no**. We provide a counterexample.

Let $A = 2^{<\omega}$ be the set of all finite binary sequences (including the e
mpty sequence $\epsilon$), ordered by the prefix relation: $s \leq_A t$ iff $s$
is a prefix of $t$.

Let $B = 3^{<\omega}$ be the set of all finite sequences over $\{0,1,2\}$, order
ed by the prefix relation: $s \leq_B t$ iff $s$ is a prefix of $t$.

## Step 1: Injective order-preserving map $f: A \to B$

Define $f(s)=s$, viewing each binary sequence as a ternary sequence using only d
igits $0,1$. This is injective. If $s\leq_A t$ (s is a prefix of t), then $f(s)=
s$ is a prefix of $t=f(t)$ in $B$, so $f(s)\leq_B f(t)$. ✓

## Step 2: Injective order-preserving map $g: B \to A$

Define the digit encoding $e:\{0,1,2\}\to\{0,1\}^2$ by $e(0)=00,\; e(1)=01,\; e(
2)=10$. For $s=d_1d_2\cdots d_n\in B$, set $g(s)=e(d_1)e(d_2)\cdots e(d_n)\in A$
 (and $g(\epsilon)=\epsilon$).

**Injective:** If $g(s)=g(t)$, the 2-bit blocks uniquely decode (since $00,01,10
$ are distinct), giving $s=t$. ✓

**Order-preserving:** If $s\leq_B t$ (s is a prefix of t), then $g(s)$ is a pref
ix of $g(t)$, so $g(s)\leq_A g(t)$. ✓

## Step 3: No order-preserving bijection $h:A\to B$ exists

Suppose for contradiction that $h:A\to B$ is an order-preserving bijection.

**Key inequality.** For any element $s$ in either tree, the principal down-set $
\downarrow s=\{s':s'\leq s\}$ has exactly $|s|+1$ elements (the sequence and all
 its prefixes, including $\epsilon$), where $|s|$ is the length.

Since $h$ is order-preserving: $h(\downarrow a)\subseteq\downarrow h(a)$ for all
 $a\in A$.
Since $h$ is injective: $|h(\downarrow a)|=|\downarrow a|=|a|+1$.

Therefore $|\downarrow h(a)|\geq|a|+1$, which gives $|h(a)|+1\geq|a|+1$, i.e.:

$$|h(a)|\geq|a| \quad\text{for all } a\in A.$$

**Counting argument.** Let $A_k=\{a\in A:|a|=k\}$ and $B_k=\{b\in B:|b|=k\}$. Th
en $|A_k|=2^k$ and $|B_k|=3^k$.

- **Level 0:** If $b\in B_0$ (so $b=\epsilon$), then $h^{-1}(b)=a$ satisfies $|a
|\leq|b|=0$, so $a\in A_0$. Since $|A_0|=|B_0|=1$, we get $h(A_0)=B_0$.

- **Level 1:** If $b\in B_1$ (so $|b|=1$), then $h^{-1}(b)=a$ satisfies $|a|\leq
 1$, so $a\in A_0\cup A_1$. But $h(A_0)=B_0$, so $h^{-1}(B_1)\subseteq A_1$. The
refore:

$$|B_1|\leq|A_1| \implies 3\leq 2.$$

This is a **contradiction**. Therefore no order-preserving bijection from $A$ to
 $B$ exists.

## Conclusion

We have exhibited partially-ordered sets $A=2^{<\omega}$ and $B=3^{<\omega}$ (bo
th under prefix order) admitting injective order-preserving maps $f:A\to B$ and
$g:B\to A$, yet admitting no order-preserving bijection in either direction. The
 Cantor–Schröder–Bernstein theorem **fails** for partially-ordered sets with ord
er-preserving injections.

**The answer is no.**
