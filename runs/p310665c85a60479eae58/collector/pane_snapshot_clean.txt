## Solution

The given PDE is the first-order quasi-linear equation
$$2yz\,\frac{\partial z}{\partial x} - xz\,\frac{\partial z}{\partial y} = -xy,$
$
of Lagrange form $Pp + Qq = R$ with $P = 2yz$, $Q = -xz$, $R = -xy$.

### Step 1. Lagrange auxiliary (characteristic) system

$$\frac{dx}{2yz} = \frac{dy}{-xz} = \frac{dz}{-xy}.$$

### Step 2. First integrals

**Pair (dx, dy):** $\dfrac{dx}{2yz} = \dfrac{dy}{-xz}$ gives $-xz\,dx = 2yz\,dy$
, hence (dividing by $z\neq 0$) $-x\,dx = 2y\,dy$, so
$$u := x^{2} + 2y^{2} = c_{1}.$$

**Pair (dx, dz):** $\dfrac{dx}{2yz} = \dfrac{dz}{-xy}$ gives $-xy\,dx = 2yz\,dz$
, hence (dividing by $y\neq 0$) $-x\,dx = 2z\,dz$, so
$$v := x^{2} + 2z^{2} = c_{2}.$$

The general integral is $\Phi(u,v)=0$, i.e.
$$\Phi\!\bigl(x^{2}+2y^{2},\; x^{2}+2z^{2}\bigr)=0.$$

### Step 3. Impose the boundary curve $z=0,\; x^{2}+y^{2}=y$

On the curve $z=0$, so $v = x^{2}$. Also $x^{2}+y^{2}=y \Rightarrow x^{2}=y-y^{2
}$, giving
$$u = x^{2}+2y^{2} = (y-y^{2})+2y^{2} = y+y^{2},\qquad v = x^{2} = y-y^{2}.$$

Eliminating the parameter $y$:
$$u+v = 2y,\qquad u-v = 2y^{2},$$
so $(u+v)^{2} = 4y^{2} = 2(u-v)$, i.e.
$$(u+v)^{2} = 2(u-v).$$

### Step 4. Substitute back

With $u = x^{2}+2y^{2}$, $v = x^{2}+2z^{2}$:
$$u+v = 2(x^{2}+y^{2}+z^{2}),\qquad u-v = 2(y^{2}-z^{2}).$$

Hence
$$\bigl[2(x^{2}+y^{2}+z^{2})\bigr]^{2} = 2\cdot 2(y^{2}-z^{2}),$$
$$\boxed{(x^{2}+y^{2}+z^{2})^{2} = y^{2}-z^{2}}.$$

### Step 5. Verification

Let $s = x^{2}+y^{2}+z^{2}$ and $F = s^{2} - y^{2} + z^{2} = 0$. Then
$$F_{x}=4xs,\quad F_{y}=4ys-2y,\quad F_{z}=4zs+2z=2z(2s+1).$$

So
$$p = -\frac{F_{x}}{F_{z}} = -\frac{2xs}{z(2s+1)},\qquad q = -\frac{F_{y}}{F_{z}
} = -\frac{y(2s-1)}{z(2s+1)}.$$

Computing the left side of the PDE:
$$2yz\,p - xz\,q = \frac{-4xys}{2s+1} + \frac{xy(2s-1)}{2s+1} = \frac{xy(-4s+2s-
1)}{2s+1} = \frac{-xy(2s+1)}{2s+1} = -xy. \checkmark$$

**Boundary check:** at $z=0$, $s = x^{2}+y^{2}$, and the surface gives $(x^{2}+y
^{2})^{2} = y^{2}$, i.e. $x^{2}+y^{2} = |y|$. Since $x^{2}+y^{2}=y$ forces $0\le
 y\le 1$ (so $|y|=y$), this is exactly $x^{2}+y^{2}=y$. $\checkmark$

Both the PDE and the boundary condition are satisfied.
