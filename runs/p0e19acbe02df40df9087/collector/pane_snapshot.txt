## Proof

**Yes**, such a positive constant $M$ exists.

**Setup.** Since the integral $\int_V f\,dx$ is discussed, we assume $f$ is meas
urable on $\Omega$. The hypothesis "$f$ is positive almost everywhere" means
$$m\bigl(\{x \in \Omega : f(x) \le 0\}\bigr) = 0.$$
Since $\Omega$ is bounded, $m(\Omega) < \infty$.

**Key construction.** For each integer $n \ge 1$, define the measurable set
$$A_n := \bigl\{x \in \Omega : f(x) < \tfrac{1}{n}\bigr\}.$$
These sets form a decreasing sequence $A_1 \supseteq A_2 \supseteq A_3 \supseteq
 \cdots$, and their intersection is
$$\bigcap_{n=1}^{\infty} A_n = \{x \in \Omega : f(x) \le 0\},$$
which has measure $0$ by the a.e.-positivity hypothesis. Since $m(A_1) \le m(\Om
ega) < \infty$, continuity of measure from above gives
$$m(A_n) \longrightarrow 0 \quad \text{as } n \to \infty.$$

**Choosing $N$.** Since $m(A_n) \to 0$ and $c > 0$, there exists an integer $N$
such that
$$m(A_N) < c.$$

**The lower bound.** Let $V \subseteq \Omega$ be any measurable set with $m(V) \
ge c$. Split the integral:
$$\int_V f(x)\,dx = \int_{V \cap A_N} f(x)\,dx + \int_{V \setminus A_N} f(x)\,dx
.$$
On $V \cap A_N$ the integrand is nonnegative a.e. (since $f>0$ a.e.), so the fir
st term is $\ge 0$. On $V \setminus A_N$ we have $f(x) \ge \tfrac{1}{N}$, hence
$$\int_{V \setminus A_N} f(x)\,dx \ge \frac{1}{N}\, m(V \setminus A_N).$$
Now
$$m(V \setminus A_N) = m(V) - m(V \cap A_N) \ge m(V) - m(A_N) \ge c - m(A_N) > 0
.$$
Combining,
$$\int_V f(x)\,dx \ge \frac{1}{N}\bigl(c - m(A_N)\bigr) > 0.$$

**Conclusion.** Setting
$$M := \frac{1}{N}\bigl(c - m(A_N)\bigr) > 0$$
yields a positive constant, depending only on $f$, $\Omega$, and $c$, such that
for every measurable $V \subseteq \Omega$ with $m(V) \ge c$,
$$\int_V f(x)\,dx \ge M.$$

The essential reason this works is that the sets where $f$ is small, $A_n = \{f
< 1/n\},$ shrink to a null set (because $f>0$ a.e.), so once $n$ is large enough
, the "bad" region $A_n$ has measure strictly less than $c$. Any set $V$ of meas
ure $\ge c$ is then forced to include a portion of measure $\ge c - m(A_n) > 0$
lying outside $A_n$, where $f \ge 1/n$, giving a uniform positive lower bound.
