## Claim
The decision version of the Travelling Salesman Problem (TSP) is **NP-complete**
.

## Part 1: TSP ∈ NP

A certificate is an ordering of the vertices (a permutation $\pi$ of $V$). To ve
rify:

1. Check that $\pi$ is a permutation of all vertices (each appears exactly once)
 — $O(n)$.
2. Compute the tour length $\sum_{i=1}^{n-1} w(\pi_i, \pi_{i+1}) + w(\pi_n, \pi_
1)$ — $O(n)$ arithmetic.
3. Check whether this total is $\leq L$ — $O(1)$.

Verification runs in polynomial time, so **TSP ∈ NP**.

## Part 2: TSP is NP-hard (reduction from Hamiltonian Cycle)

**Hamiltonian Cycle (HC)** is a known NP-complete problem: given an undirected g
raph $G = (V, E)$, does $G$ contain a cycle visiting every vertex exactly once?

### Construction

Given an instance $G = (V, E)$ of HC with $|V| = n$, construct a TSP instance $(
G', w, L)$ as follows:

- $G'$ is the **complete graph** on the same vertex set $V$.
- Define weights (positive integers):
$$w(u, v) = \begin{cases} 1 & \text{if } \{u,v\} \in E \\ 2 & \text{if } \{u,v\}
 \notin E \end{cases}$$
- Set $L = n$.

This construction is polynomial time: building the complete graph and assigning
weights is $O(n^2)$.

### Correctness ($\Rightarrow$)

Suppose $G$ has a Hamiltonian cycle $C = (v_1, v_2, \dots, v_n, v_1)$. Every con
secutive pair $\{v_i, v_{i+1}\}$ (indices mod $n$) is an edge of $G$, hence has
weight $1$ in $G'$. The corresponding TSP tour uses exactly $n$ edges, each of w
eight $1$, giving total length $n = L$. So the TSP instance answers **YES**.

### Correctness ($\Leftarrow$)

Suppose the TSP instance has a tour of length $\leq L = n$. Any TSP tour on $n$
vertices uses exactly $n$ edges. Each edge has weight $\geq 1$, so:

$$\text{tour length} = \sum_{\text{tour edges}} w(e) \geq n \cdot 1 = n.$$

Combined with the assumption that the length is $\leq n$, we get **tour length $
= n$ exactly**, which forces **every edge in the tour to have weight $1$**. By c
onstruction, weight-$1$ edges are precisely the edges of $G$. Therefore the tour
 is a cycle in $G$ visiting every vertex exactly once — a **Hamiltonian cycle**
of $G$.

### Conclusion of Part 2

We have a polynomial-time many-one reduction $\text{HC} \leq_p \text{TSP}$ with
YES mapped to YES and NO mapped to NO. Since HC is NP-complete, **TSP is NP-hard
**.

## Final Conclusion

- TSP ∈ NP (Part 1).
- TSP is NP-hard (Part 2, via reduction from Hamiltonian Cycle).

Therefore **the decision version of the Travelling Salesman Problem is NP-comple
te**. $\blacksquare$
