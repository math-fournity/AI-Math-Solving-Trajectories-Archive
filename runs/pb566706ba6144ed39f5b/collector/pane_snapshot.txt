## Solution

We compute $\mathbb{E}(\tau)$ where $\tau = \inf\{t \geq 0 : B_t^2 = 1-t\}$.

**Step 1: $\tau$ is a bounded stopping time ($\tau \leq 1$ a.s.).**

Define the continuous process $X_t = B_t^2 + t$. At $t=0$: $X_0 = 0 < 1$. At $t=
1$: $X_1 = B_1^2 + 1 \geq 1$. Since $t \mapsto X_t$ is continuous, by the interm
ediate value theorem there exists $\tau \in [0,1]$ with $X_\tau = 1$, i.e., $B_\
tau^2 = 1-\tau$. For $t > 1$, $1-t < 0 \leq B_t^2$, so no solution exists beyond
 $t=1$. Hence $\tau \leq 1$ almost surely.

**Step 2: Apply the Optional Stopping Theorem.**

The process $M_t = B_t^2 - t$ is a martingale (Itô's formula gives $d(B_t^2) = 2
B_t\,dB_t + dt$, so $dM_t = 2B_t\,dB_t$). Since $\tau \leq 1$ is a bounded stopp
ing time, the Optional Stopping Theorem applies directly:

$$\mathbb{E}[M_\tau] = \mathbb{E}[M_0] = 0.$$

**Step 3: Evaluate $\mathbb{E}[\tau]$.**

By definition of $\tau$, $B_\tau^2 = 1 - \tau$, so:

$$M_\tau = B_\tau^2 - \tau = (1 - \tau) - \tau = 1 - 2\tau.$$

Taking expectations and using $\mathbb{E}[M_\tau] = 0$:

$$\mathbb{E}[1 - 2\tau] = 0 \implies 1 - 2\,\mathbb{E}[\tau] = 0 \implies \mathb
b{E}[\tau] = \frac{1}{2}.$$

**Conclusion:**

$$\boxed{\mathbb{E}(\tau) = \dfrac{1}{2}}$$
