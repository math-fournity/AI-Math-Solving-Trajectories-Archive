## Proof

Let $B_t$ be a standard Brownian motion, so $B_t \sim N(0, t)$, and $M_t = e^{5B
_t - bt}$.

For $M_t$ to be a martingale, it must satisfy the drift-free condition. Using th
e moment-generating function of a normal random variable: for $X \sim N(\mu, \si
gma^2)$, $\mathbb{E}[e^{X}] = e^{\mu + \sigma^2/2}$.

Since $B_t \sim N(0, t)$, we have $5B_t \sim N(0, 25t)$, so

$$\mathbb{E}[e^{5B_t}] = e^{\frac{25t}{2}}.$$

Therefore

$$\mathbb{E}[M_t] = \mathbb{E}[e^{5B_t - bt}] = e^{-bt}\,\mathbb{E}[e^{5B_t}] =
e^{-bt}\cdot e^{\frac{25t}{2}} = e^{\left(\frac{25}{2} - b\right)t}.$$

For $M_t$ to be a martingale, its expectation must be constant in time (equal to
 $\mathbb{E}[M_0] = 1$). This requires the exponent's drift to vanish:

$$\frac{25}{2} - b = 0 \implies b = \frac{25}{2}.$$

**Verification via Itô's lemma.** With $b = \frac{25}{2}$, let $X_t = 5B_t - \fr
ac{25}{2}t$. By Itô's lemma,

$$dM_t = M_t\,dX_t + \tfrac{1}{2}M_t\,(dX_t)^2 = M_t(5\,dB_t - \tfrac{25}{2}\,dt
) + \tfrac{1}{2}M_t\cdot 25\,dt = 5M_t\,dB_t.$$

The drift term vanishes, so $M_t = M_0 + \int_0^t 5M_s\,dB_s$ is a (local) marti
ngale. Since the integrand is square-integrable on bounded intervals, it is a tr
ue martingale.

$$\boxed{b = \dfrac{25}{2}}$$
