## Proof

**Claim.** The statement is **true**: if some NP-complete problem can be solved
in polynomial time, then P = NP.

**Definitions (standard).**

- **P** is the class of languages decidable by a deterministic Turing machine in
 time bounded by a polynomial in the input length.
- **NP** is the class of languages for which membership has a certificate verifi
able in polynomial time (equivalently, decidable by a nondeterministic Turing ma
chine in polynomial time).
- A language $L$ is **NP-hard** if for every $A \in \text{NP}$ there exists a po
lynomial-time many-one reduction $A \le_p L$; i.e., a polynomial-time computable
 function $f$ with $x \in A \iff f(x) \in L$.
- A language is **NP-complete** if it is both in NP and NP-hard.
- **P ⊆ NP**: a deterministic polynomial-time machine is a special case of a non
deterministic one (or equivalently, the witness can be ignored). This inclusion
is immediate and unconditional.

**Assumption.** There exists an NP-complete language $L$ such that $L \in \text{
P}$. We show $\text{NP} \subseteq \text{P}$; combined with the trivial $\text{P}
 \subseteq \text{NP}$ this yields $\text{P} = \text{NP}$.

**Key lemma — P is closed downward under polynomial-time many-one reductions.**
If $A \le_p B$ and $B \in \text{P}$, then $A \in \text{P}$.

*Proof of lemma.* Let $f$ be the polynomial-time reduction $A \le_p B$, computab
le in time $p(n)$ for some polynomial $p$, so $|f(x)| \le p(|x|)$. Let $M_B$ dec
ide $B$ in time $q(m)$ for some polynomial $q$. A decider for $A$ on input $x$:
1. Compute $y = f(x)$ in time $p(|x|)$.
2. Run $M_B$ on $y$, taking time $q(|y|) \le q(p(|x|))$.
3. Accept iff $M_B$ accepts $y$.

By construction $x \in A \iff f(x) \in B$, so this correctly decides $A$. The to
tal running time is $p(|x|) + q(p(|x|))$, a polynomial in $|x|$ (compositions an
d sums of polynomials are polynomials). Hence $A \in \text{P}$. ∎

**Main argument.** Let $A$ be an arbitrary language in NP. Since $L$ is NP-compl
ete, it is in particular NP-hard, so there exists a polynomial-time reduction $A
 \le_p L$. By assumption $L \in \text{P}$. Applying the lemma with $B = L$ gives
 $A \in \text{P}$.

Since $A$ was arbitrary, $\text{NP} \subseteq \text{P}$.

**Conclusion.** We have $\text{P} \subseteq \text{NP}$ (trivially) and $\text{NP
} \subseteq \text{P}$ (from the argument above). Therefore $\text{P} = \text{NP}
$.

Thus the statement is **true**: any single NP-complete problem admitting a polyn
omial-time algorithm collapses P and NP. ∎
