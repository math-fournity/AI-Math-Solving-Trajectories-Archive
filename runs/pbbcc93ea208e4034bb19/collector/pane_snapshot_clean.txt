## Proof

**Answer: Yes.** On a convex open set $\Omega \subset \mathbb{C}^n$, every zero-
free holomorphic function $f$ admits a holomorphic branch of $\log f$.

---

**Step 1. $\Omega$ is simply connected.**

A convex open subset of $\mathbb{C}^n \cong \mathbb{R}^{2n}$ is star-shaped (hen
ce contractible, hence simply connected). In particular, every closed piecewise-
$C^1$ curve in $\Omega$ is null-homotopic.

**Step 2. The holomorphic 1-form $\omega := df/f$ is closed.**

Since $f$ has no zeros on $\Omega$, the 1-form
$$\omega = \frac{df}{f} = \frac{1}{f}\sum_{j=1}^{n}\frac{\partial f}{\partial z_
j}\,dz_j$$
is a well-defined holomorphic 1-form on $\Omega$. Computing its exterior derivat
ive:
$$d\omega = d\!\left(\frac{1}{f}\right)\wedge df = -\frac{1}{f^2}\,df\wedge df =
 0,$$
since $df\wedge df = 0$. Hence $\omega$ is closed.

**Step 3. $\omega$ is exact; write $\omega = dg$ with $g$ holomorphic.**

Because $\Omega$ is simply connected, the Poincaré lemma applies: every closed 1
-form is exact. Concretely, fix $z_0\in\Omega$ and define
$$g(z) = \int_{z_0}^{z}\omega,$$
where the integral is taken along any piecewise-$C^1$ path from $z_0$ to $z$ in
$\Omega$. Simple-connectedness guarantees path-independence, so $g$ is a well-de
fined $C^\infty$ function with $dg = \omega$. Since $\omega$ has holomorphic coe
fficients, $g$ is in fact holomorphic on $\Omega$ (its $\bar\partial$-derivative
 vanishes: $\bar\partial g$ is the $(0,1)$-part of $dg = \omega$, which is zero
because $\omega$ is of type $(1,0)$).

**Step 4. $e^g/f$ is constant.**

Compute:
$$d\!\left(\frac{e^g}{f}\right) = \frac{e^g\,dg}{f} - \frac{e^g\,df}{f^2} = \fra
c{e^g}{f}\cdot\frac{df}{f} - \frac{e^g\,df}{f^2} = \frac{e^g\,df}{f^2} - \frac{e
^g\,df}{f^2} = 0.$$

Since $\Omega$ is convex (hence connected), $e^g/f \equiv c$ for some constant $
c\in\mathbb{C}^*$. (We have $c\neq 0$ because both $e^g$ and $f$ are nowhere zer
o.)

**Step 5. Adjust the constant.**

Choose $a\in\mathbb{C}$ with $e^a = c$ (possible since $\exp:\mathbb{C}\to\mathb
b{C}^*$ is surjective). Set
$$G := g - a.$$
Then $G$ is holomorphic on $\Omega$ and
$$e^G = e^{g-a} = \frac{e^g}{c} = \frac{c\,f}{c} = f.$$

Thus $G$ is a holomorphic branch of $\log f$ on $\Omega$. $\blacksquare$

---

**Remark.** The argument uses only: (i) $\Omega$ simply connected (furnished by
convexity), (ii) $f$ holomorphic and zero-free, and (iii) surjectivity of $\exp:
\mathbb{C}\to\mathbb{C}^*$. It works for all $n\geq 1$; the several-variable cas
e presents no additional obstruction because the relevant topological input is $
\pi_1(\Omega)=0$, which convexity guarantees in every dimension.

### PROOF COMPLETE
