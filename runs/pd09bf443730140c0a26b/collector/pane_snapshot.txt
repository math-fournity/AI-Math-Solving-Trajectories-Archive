## Proof

We prove by induction on $n$ that for any valid initial tuple $A_0$, there exist
s $k$ such that $A_{k+2}=A_k$.

**Preliminary observation (constraint preservation).** Since $a_{i+1,j}=\operato
rname{Card}\{l<j : a_{i,l}\ge a_{i,j}\}$ counts a subset of $\{1,\dots,j-1\}$, w
e have $0\le a_{i+1,j}\le j-1$. So all tuples remain in the valid state space $S
_n=\prod_{j=1}^n\{0,\dots,j-1\}$.

**Base case ($n=1$).** The only tuple is $(0)$, which is fixed: $A_{0+2}=A_0$ wi
th $k=0$.

**Inductive step.** Assume the result for length $n-1$ (where $n\ge 2$). Let $A_
0=(a_{0,1},\dots,a_{0,n})$.

**Causality.** The value $a_{i+1,j}$ depends only on the prefix $(a_{i,1},\dots,
a_{i,j})$. In particular, the prefix $(a_{i,1},\dots,a_{i,n-1})$ evolves indepen
dently under the same transformation $T$ on tuples of length $n-1$.

By the induction hypothesis, there exists $k_0$ such that the prefix satisfies p
eriod dividing 2 from step $k_0$ onward. Set
$$P=(a_{k_0,1},\dots,a_{k_0,n-1}),\qquad Q=(a_{k_0+1,1},\dots,a_{k_0+1,n-1}).$$
For all $i\ge k_0$, the prefix equals $P$ at steps $k_0,k_0+2,k_0+4,\dots$ and $
Q$ at steps $k_0+1,k_0+3,\dots$.

**Analysis of the last component.** Define $g_P,g_Q:\{0,\dots,n-1\}\to\{0,\dots,
n-1\}$ by
$$g_P(x)=\operatorname{Card}\{l<n: P_l\ge x\},\qquad g_Q(x)=\operatorname{Card}\
{l<n: Q_l\ge x\}.$$
When the prefix is $P$, the last entry updates as $a_{i+1,n}=g_P(a_{i,n})$; when
 the prefix is $Q$, it updates as $a_{i+1,n}=g_Q(a_{i,n})$.

Both $g_P$ and $g_Q$ are **non-increasing**: if $x\le x'$, then $\{l:P_l\ge x\}\
supseteq\{l:P_l\ge x'\}$, so $g_P(x)\ge g_P(x')$.

Define $h=g_Q\circ g_P$. The composition of two non-increasing functions is **no
n-decreasing**: if $x\le x'$, then $g_P(x)\ge g_P(x')$, so $g_Q(g_P(x))\le g_Q(g
_P(x'))$, i.e., $h(x)\le h(x')$.

Sampling the last entry every two steps from $k_0$:
$$a_{k_0+2m,\,n}=h^m(a_{k_0,n}).$$

**Key claim.** Every orbit of a non-decreasing function $h$ on a finite totally
ordered set reaches a fixed point.

*Proof of claim.* For any $x$, either $h(x)\ge x$ or $h(x)\le x$.
- If $h(x)\ge x$: since $h$ is non-decreasing, $h^2(x)\ge h(x)\ge x$, and induct
ively $x\le h(x)\le h^2(x)\le\cdots$. This non-decreasing sequence is bounded ab
ove by $n-1$, so it stabilizes at a fixed point.
- If $h(x)\le x$: similarly $x\ge h(x)\ge h^2(x)\ge\cdots$, a non-increasing seq
uence bounded below by $0$, which stabilizes. $\square$

By the claim, there exists $m_0$ with $h^{m_0}(a_{k_0,n})=h^{m_0+1}(a_{k_0,n})=:
a^*$. Set $k=k_0+2m_0$. Then:

- **Step $k$:** prefix is $P$ (offset $k-k_0=2m_0$ is even), last entry is $h^{m
_0}(a_{k_0,n})=a^*$. So $A_k=(P,a^*)$.
- **Step $k+1$:** prefix is $Q$, last entry is $g_P(a^*)=:b^*$. So $A_{k+1}=(Q,b
^*)$.
- **Step $k+2$:** prefix is $P$ (period 2), last entry is $g_Q(b^*)=g_Q(g_P(a^*)
)=h(a^*)=a^*$ (fixed point). So $A_{k+2}=(P,a^*)=A_k$.

Therefore $A_{k+2}=A_k$, completing the induction. $\blacksquare$
