**Setting up coordinates.** Place the longest side along the x-axis: A=(0,0), B=
(1.5,0). The third vertex C satisfies AC² + BC² relationships. Solving: if AC =
√5/2, BC = √2, then C = (0.5, 1). (The mirror configuration C=(1,1) gives identi
cal results by symmetry.)

The triangle has height 1 and area 3/4. Its upper boundary:
- For 0 ≤ x ≤ 0.5: y = 2x (edge AC)
- For 0.5 ≤ x ≤ 1.5: y = 1.5 − x (edge BC)

**Fold setup.** A fold along x = c (perpendicular to the base) reflects one side
 onto the other. I analyze folding the left part (x ≤ c) over to the right; the
other direction yields the same maximum by the mirror symmetry of the problem.

**Key cases.** For c ≤ 0.5, the reflected left part's upper boundary (4c − 2x')
is always below the right part's boundary, so the overlap area = c², maximized a
t c = 0.5 giving 1/4.

For 0.5 < c ≤ 0.75 (so 2c ≤ 1.5, reflected part stays within the triangle), the
reflected left part has two regions:
- x' ∈ [c, 2c−0.5]: reflected boundary = 1.5 − 2c + x' (from reflecting edge BC)
- x' ∈ [2c−0.5, 2c]: reflected boundary = 4c − 2x' (from reflecting edge AC)

The right part's boundary is 1.5 − x' throughout. Comparing:
- For x' ∈ [c, 4c−1.5]: reflected ≥ right part, so overlap = 1.5 − x'
- For x' ∈ [4c−1.5, 2c]: reflected ≤ right part, so overlap = 4c − 2x'

(The crossover 4c − 1.5 lies in [2c−0.5, 2c] precisely when 0.5 < c ≤ 0.75.)

**Computing the area:**

$$A(c) = \int_c^{4c-3/2} \left(\tfrac{3}{2} - x'\right) dx' + \int_{4c-3/2}^{2c}
 (4c - 2x')\, dx'$$

- Second integral: $\left[4cx' - x'^2\right]_{4c-3/2}^{2c} = 4c^2 - 6c + \tfrac{
9}{4}$

Combining: $A(c) = -\tfrac{7}{2}c^2 + \tfrac{9}{2}c - \tfrac{9}{8}$.

**Verification at boundary:** At c = 1/2: $A = -7/8 + 9/4 - 9/8 = 1/4 = c^2$. ✓
