## Solution

We evaluate $I = \displaystyle\int_0^{\infty} \dfrac{\ln x}{x^2+1}\,dx$ using th
e residue theorem.

### Setup

Consider the function
$$f(z) = \frac{(\log z)^2}{z^2+1}$$
where $\log z$ is the branch of the logarithm with $0 < \arg z < 2\pi$ (branch c
ut along the positive real axis). We integrate $f$ over a **keyhole contour** $\
Gamma$ consisting of:

- the upper edge of the cut: $z = x$ ($x: \varepsilon \to R$), where $\log z = \
ln x$;
- the large circle $C_R$ of radius $R$ (traversed counterclockwise);
- the lower edge of the cut: $z = x$ with $\arg z = 2\pi$ ($x: R \to \varepsilon
$), where $\log z = \ln x + 2\pi i$;
- the small circle $C_\varepsilon$ of radius $\varepsilon$ (traversed clockwise)
.

### Poles and residues

The poles of $f$ are at $z = i$ and $z = -i$ (both simple, both inside $\Gamma$
for $\varepsilon < 1 < R$).

- $z = i = e^{i\pi/2}$, so $\log i = i\pi/2$:
$$\operatorname{Res}(f, i) = \frac{(\log i)^2}{2i} = \frac{(i\pi/2)^2}{2i} = \fr
ac{-\pi^2/4}{2i} = \frac{\pi^2 i}{8}.$$

- $z = -i = e^{i\,3\pi/2}$ (since $0 < \arg < 2\pi$), so $\log(-i) = i\,3\pi/2$:
$$\operatorname{Res}(f, -i) = \frac{(\log(-i))^2}{-2i} = \frac{(i\,3\pi/2)^2}{-2
i} = \frac{-9\pi^2/4}{-2i} = -\frac{9\pi^2 i}{8}.$$

Sum of residues:
$$\frac{\pi^2 i}{8} - \frac{9\pi^2 i}{8} = -\pi^2 i.$$

By the residue theorem:
$$\oint_\Gamma f(z)\,dz = 2\pi i\,(-\pi^2 i) = 2\pi^3.$$

### Estimating the circular arcs

On $C_R$: $|f(z)| \le \dfrac{(\ln R + 2\pi)^2}{R^2 - 1}$, so
$$\left|\int_{C_R} f\right| \le \frac{2\pi R\,(\ln R + 2\pi)^2}{R^2-1} \xrightar
row{R\to\infty} 0.$$

On $C_\varepsilon$: $|f(z)| \le \dfrac{(|\ln\varepsilon| + 2\pi)^2}{1 - \varepsi
lon^2}$, so
$$\left|\int_{C_\varepsilon} f\right| \le \frac{2\pi\varepsilon\,(|\ln\varepsilo
n|+2\pi)^2}{1-\varepsilon^2} \xrightarrow{\varepsilon\to 0} 0.$$

### Assembling the contour integral

Taking $\varepsilon \to 0$ and $R \to \infty$, only the two straight edges contr
ibute:

- **Upper edge**: $\displaystyle\int_0^\infty \frac{(\ln x)^2}{x^2+1}\,dx$.
- **Lower edge**: $\displaystyle\int_\infty^0 \frac{(\ln x + 2\pi i)^2}{x^2+1}\,
dx = -\int_0^\infty \frac{(\ln x)^2 + 4\pi i\,\ln x - 4\pi^2}{x^2+1}\,dx$.

Adding them, the $(\ln x)^2$ terms cancel:
$$\oint_\Gamma f = -4\pi i \int_0^\infty \frac{\ln x}{x^2+1}\,dx + 4\pi^2 \int_0
^\infty \frac{dx}{x^2+1}.$$

The remaining elementary integral is $\displaystyle\int_0^\infty \frac{dx}{x^2+1
} = \frac{\pi}{2}$, so
$$\oint_\Gamma f = -4\pi i\, I + 4\pi^2\cdot\frac{\pi}{2} = -4\pi i\, I + 2\pi^3
.$$

### Solving for $I$

Equating with the residue-theorem value $2\pi^3$:
$$-4\pi i\, I + 2\pi^3 = 2\pi^3 \implies -4\pi i\, I = 0 \implies I = 0.$$

### Conclusion

$$\boxed{\int_0^{\infty} \frac{\ln x}{x^2+1}\,dx = 0.}$$

A quick sanity check confirms this: the substitution $x \mapsto 1/t$ sends $\ln
x \mapsto -\ln t$ while $\dfrac{dx}{x^2+1}$ is invariant, so the integral equals
 its own negative — hence it must vanish. The residue-theorem computation above
establishes this rigorously.
