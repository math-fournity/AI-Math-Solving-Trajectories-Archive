## Proof

**Reformulation as an operator equation.** Define the operator $S$ on $\ell_2$ b

$$(Sx)_1 = 0, \qquad (Sx)_n = \frac{x_{n-1}}{n-1} \quad (n \ge 2).$$
Then the recursion $x_1 = \lambda y_1$, $x_n = \lambda\!\left(y_n + \frac{x_{n-1
}}{n-1}\right)$ is equivalent to
$$x = \lambda\, y + \lambda\, S\, x, \qquad\text{i.e.,}\qquad (I - \lambda S)\,x
 = \lambda\, y.$$
If $I - \lambda S$ is invertible as a bounded operator on $\ell_2$, then $x = \l
ambda(I-\lambda S)^{-1} y \in \ell_2$ for every $y \in \ell_2$. We prove this in
vertibility for **all** $\lambda \in \mathbb{C}$.

**Step 1: $S$ is bounded on $\ell_2$.**
$$\|Sx\|^2 = \sum_{n=2}^{\infty} \frac{|x_{n-1}|^2}{(n-1)^2} = \sum_{m=1}^{\inft
y} \frac{|x_m|^2}{m^2} \le \sum_{m=1}^{\infty} |x_m|^2 = \|x\|^2,$$
so $\|S\| \le 1$ (in fact $\|S\|=1$, attained at $e_1$).

**Step 2: Compute $\|S^k\|$.** The operator $S^k$ is a weighted shift: for $n >
k$,
$$(S^k x)_n = \frac{x_{n-k}}{(n-1)(n-2)\cdots(n-k)} = \frac{(m-1)!}{(m+k-1)!}\,
x_m, \qquad m = n-k.$$
The norm of such a weighted shift is the supremum of its weights:
$$\|S^k\| = \sup_{m \ge 1} \frac{(m-1)!}{(m+k-1)!} = \sup_{m \ge 1} \frac{1}{m(m
+1)\cdots(m+k-1)}.$$
The function $m \mapsto \frac{1}{m(m+1)\cdots(m+k-1)}$ is decreasing in $m$, so
the supremum is at $m=1$:
$$\|S^k\| = \frac{1}{k!}, \qquad k = 0, 1, 2, \dots$$

**Step 3: The spectral radius of $S$ is $0$.** By the spectral radius formula,
$$r(S) = \lim_{k\to\infty} \|S^k\|^{1/k} = \lim_{k\to\infty} \frac{1}{(k!)^{1/k}
} = 0,$$
since $(k!)^{1/k} \to \infty$ (e.g., by Stirling's approximation $(k!)^{1/k} \si
m k/e$).

**Step 4: $I - \lambda S$ is invertible for every $\lambda \in \mathbb{C}$.** Si
nce $r(\lambda S) = |\lambda|\, r(S) = 0 < 1$ for every $\lambda$, the Neumann s
eries
$$(I - \lambda S)^{-1} = \sum_{k=0}^{\infty} \lambda^k S^k$$
converges in operator norm. Indeed, $\|\lambda^k S^k\|^{1/k} = |\lambda|\,\|S^k\
|^{1/k} \to 0 < 1$, so the series converges absolutely. Each partial sum is boun
ded, hence the limit is a bounded operator on $\ell_2$.

**Conclusion.** The operator $T_\lambda := \lambda(I - \lambda S)^{-1}$ is bound
ed on $\ell_2$ for every $\lambda \in \mathbb{C}$ (for $\lambda = 0$, $T_0 = 0$
trivially). Therefore
$$x = T_\lambda\, y \in \ell_2 \qquad \text{for all } y \in \ell_2 \text{ and al
l } \lambda \in \mathbb{C}.$$

**The answer is yes: the sequence $(x_n)$ is always in $\ell_2$.**
