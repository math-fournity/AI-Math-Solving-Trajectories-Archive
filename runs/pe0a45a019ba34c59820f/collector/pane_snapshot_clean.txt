## 证明

考虑一个边长为 $s$ 的正方形，通过螺旋（回旋）切割方式将其分成 6 个面积相等的矩形
（每个面积为 $s^2/6$）。

切割过程（从底部顺时针进行）：
1. 从底部切下高度为 $a$ 的水平条带。
2. 从剩余区域的右侧切下宽度为 $b$ 的垂直条带。
3. 从剩余区域的顶部切下高度为 $c$ 的水平条带。
4. 从剩余区域的左侧切下宽度为 $d$ 的垂直条带。
5. 从剩余区域的底部切下高度为 $e$ 的水平条带。
6. 剩下的中心矩形即为第 6 个矩形。

**将每个面积设为 $s^2/6$：**

**矩形 1**（底部条带）：$sa = s^2/6 \Rightarrow a = s/6$。

**矩形 2**（右侧条带）：$b(s-a) = s^2/6 \Rightarrow b \cdot \frac{5s}{6} = \frac
{s^2}{6} \Rightarrow b = \frac{s}{5}$。

**矩形 3**（顶部条带）：$(s-b)c = s^2/6 \Rightarrow \frac{4s}{5} \cdot c = \frac
{s^2}{6} \Rightarrow c = \frac{5s}{24}$。

**矩形 4**（左侧条带）：$d(s-a-c) = s^2/6$。因为 $s - a - c = s - \frac{s}{6} -
\frac{5s}{24} = \frac{5s}{8}$，所以 $d \cdot \frac{5s}{8} = \frac{s^2}{6} \Right
arrow d = \frac{4s}{15}$。

**矩形 5**（剩余部分的底部条带）：$(s-b-d)e = s^2/6$。因为 $s - b - d = \frac{8s
}{15}$，所以 $\frac{8s}{15} \cdot e = \frac{s^2}{6} \Rightarrow e = \frac{5s}{16
}$。

**矩形 6**（中心）：$\frac{8s}{15} \cdot \frac{5s}{16} = \frac{s^2}{6}$。 ✓

**沿左边缘的分割**（从下到上）：
- 长度 $a = s/6$（矩形 1），
- 长度 $s - a - c = 5s/8$（矩形 4），
- 长度 $c = 5s/24$（矩形 3）。

设 $A$ 为左下角，$B$ 为第一个分割点，$C$ 为左边缘上的第二个分割点。则：
$$AB = \frac{s}{6}, \quad BC = \frac{5s}{8}.$$

已知 $AB = 5$：
$$\frac{s}{6} = 5 \Rightarrow s = 30.$$

因此：
$$BC = \frac{5 \times 30}{8} = \frac{150}{8} = \frac{75}{4}.$$

因为 $\gcd(75, 4) = 1$，所以该分数不可约，即 $a = 75$，$b = 4$。

$$a + b = 75 + 4 = \boxed{79}.$$
