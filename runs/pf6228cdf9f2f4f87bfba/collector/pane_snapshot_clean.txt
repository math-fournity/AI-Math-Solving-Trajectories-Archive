## Distributional Derivatives

### Setup

Let $\mathcal{D}(\Omega) = C_c^\infty(\Omega)$ be the space of test functions (s
mooth, compactly supported) on an open set $\Omega \subseteq \mathbb{R}$. A **di
stribution** is a continuous linear functional $T: \mathcal{D}(\Omega) \to \math
bb{R}$ (continuity in the standard LF-topology). The **derivative** of $T$ is de
fined by

$$T'(\varphi) := -T(\varphi'), \qquad \varphi \in \mathcal{D}(\Omega).$$

### Why $T'$ is a well-defined distribution

- **Linearity** is immediate: $\varphi \mapsto \varphi'$ is linear, and $T$ is l
inear, so $T'$ is linear.
- **Continuity**: differentiation $\varphi \mapsto \varphi'$ is a continuous map
 $\mathcal{D} \to \mathcal{D}$ (it preserves compact support and is continuous i
n the LF-topology). Composing the continuous $T$ with the continuous $\varphi \m
apsto \varphi'$ and negating gives a continuous functional. Hence $T' \in \mathc
al{D}'(\Omega)$.

The key point: **every** distribution has a derivative, with no differentiabilit
y hypothesis on $T$ itself. The "differentiation" has been pushed onto the test
function $\varphi$, which is always smooth.

### How this gives derivatives to non-classically-differentiable functions

A locally integrable function $f \in L^1_{\mathrm{loc}}(\Omega)$ defines a distr
ibution (the **regular distribution**)

$$T_f(\varphi) = \int_\Omega f(x)\,\varphi(x)\,dx.$$

Even when $f$ is **not** classically differentiable, $T_f$ is still a distributi
on, so $T_f'$ is defined by the rule above. We **call** $T_f'$ the *distribution
al derivative* of $f$, denoted $f'$ or $\frac{df}{dx}$ in the distributional sen
se. If there happens to be a locally integrable $g$ with $T_g = T_f'$, we write
$f' = g$ distributionally.

When $f$ **is** classically $C^1$, integration by parts (no boundary term, since
 $\varphi$ has compact support) gives

$$T_{f'}(\varphi) = \int f'\,\varphi = -\int f\,\varphi' = T_f'(\varphi),$$

so the distributional derivative **agrees** with the classical derivative. Thus
the distributional derivative is a genuine extension of the classical one.

### Example: the Heaviside step function

Let

$$H(x) = \begin{cases} 0, & x < 0, \\ 1, & x > 0. \end{cases}$$

$H$ is locally integrable (bounded, piecewise constant) but **not classically di
fferentiable** at $0$; classically $H'$ does not exist as a function. Yet as a r
egular distribution $T_H(\varphi) = \int_0^\infty \varphi(x)\,dx$, its distribut
ional derivative is

$$T_H'(\varphi) = -T_H(\varphi') = -\int_0^\infty \varphi'(x)\,dx.$$

Since $\varphi$ has compact support, $\varphi(\infty)=0$, so by the fundamental
theorem of calculus

$$-\int_0^\infty \varphi'(x)\,dx = -\bigl[\varphi(\infty)-\varphi(0)\bigr] = \va
rphi(0).$$

The Dirac delta distribution is $\delta(\varphi) = \varphi(0)$. Therefore

$$\boxed{H' = \delta}$$

in the distributional sense. The "jump" of size $1$ at the origin produces a uni
t point mass — exactly the content of $\delta$.

### Verification of the consistency check

If $H$ were replaced by a genuinely $C^1$ function, the same computation would r
eproduce the classical derivative via integration by parts; here the boundary te
rm survives because of the discontinuity, and it is precisely $\varphi(0)$, i.e.
 the delta. This shows concretely how distributional differentiation recovers an
d extends classical differentiation: classical failure at a point becomes a clea
n distributional object ($\delta$) supported at that point.

### Summary

The definition $T'(\varphi)=-T(\varphi')$ transfers the burden of differentiatio
n from the (possibly rough) object $T$ onto the (always smooth) test function $\
varphi$. Because $\varphi\mapsto\varphi'$ is continuous on $\mathcal{D}$, *every
* distribution — in particular every regular distribution $T_f$ with merely $f\i
n L^1_{\mathrm{loc}}$ — acquires a derivative. The Heaviside function illustrate
s this: classically non-differentiable at $0$, it has the perfectly well-defined
 distributional derivative $H'=\delta$.
