## Proof

We prove a general statement: for **any** positive integer $L$, there exists a n
atural number $n$ whose square begins with $L$ consecutive nines. Setting $L = 1
983$ yields the result.

**Key Observation.** A positive integer begins with $L$ consecutive nines if and
 only if it lies in the half-open interval
$$I_{L,m} \;=\; \bigl[(10^L - 1)\cdot 10^m,\;\; 10^L \cdot 10^m\bigr)$$
for some non-negative integer $m$. This is because $(10^L-1)\cdot 10^m = \underb
race{99\ldots9}_{L}\underbrace{00\ldots0}_{m}$ and $10^L\cdot 10^m = 10^{L+m}$,
so $I_{L,m}$ is exactly the set of $(L+m)$-digit numbers whose first $L$ digits
are all $9$.

**Construction.** Set $m = L+1$ and $N = (10^L - 1)\cdot 10^{L+1}$. Define
$$n \;=\; \bigl\lceil \sqrt{N} \bigr\rceil.$$

**Lower bound.** Since $n \geq \sqrt{N}$, we immediately have $n^2 \geq N = (10^
L-1)\cdot 10^m$.

**Upper bound.** Since $n \leq \sqrt{N}+1$, we get
$$n^2 \;\leq\; N + 2\sqrt{N} + 1.$$

We must show $N + 2\sqrt{N} + 1 < 10^L\cdot 10^m = N + 10^m$, equivalently $2\sq
rt{N}+1 < 10^m$.

**Estimating $\sqrt{N}$.** Since $10^L - 1 < 10^L$,
$$\sqrt{N} = \sqrt{(10^L-1)\cdot 10^{L+1}} < \sqrt{10^L \cdot 10^{L+1}} = 10^{L+
\frac{1}{2}} = \sqrt{10}\cdot 10^L.$$

Therefore
$$2\sqrt{N} + 1 \;<\; 2\sqrt{10}\cdot 10^L + 1.$$

**The decisive inequality.** We claim $2\sqrt{10}\cdot 10^L + 1 < 10^{L+1} = 10\
cdot 10^L$ for all $L\geq 1$. This is equivalent to
$$1 \;<\; \bigl(10 - 2\sqrt{10}\bigr)\cdot 10^L.$$

Since $2\sqrt{10} \approx 6.325$, we have $10 - 2\sqrt{10} \approx 3.675 > 0$, s
o for $L \geq 1$:
$$(10 - 2\sqrt{10})\cdot 10^L \;\geq\; 3.675 \times 10 \;=\; 36.75 \;>\; 1. \qua
d\checkmark$$

**Conclusion.** Combining both bounds:
$$(10^L - 1)\cdot 10^m \;\leq\; n^2 \;<\; 10^L\cdot 10^m,$$

so $n^2 \in I_{L,m}$, meaning $n^2$ is an $(L+m)$-digit number whose first $L$ d
igits are all $9$.

(That $n^2$ has exactly $L+m$ digits follows from $10^{L+m-1} \leq (10^L-1)\cdot
 10^m \leq n^2 < 10^{L+m}$.)

**Instantiating $L = 1983$.** Taking $m = 1984$ and
$$n = \Bigl\lceil \sqrt{(10^{1983}-1)\cdot 10^{1984}}\Bigr\rceil,$$

the square $n^2$ begins with 1983 consecutive nines. $\blacksquare$
