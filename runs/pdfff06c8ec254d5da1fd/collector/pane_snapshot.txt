## 证明

设 $B_t$ 为标准布朗运动，并定义
$$X_t = \int_0^t B_s\,ds, \qquad t \ge 0.$$

**步骤 1：$X$ 是连续可微的，因此具有有限变差。**

由于布朗运动几乎必然具有连续路径，映射 $s \mapsto B_s$ 在每个有限区间 $[0,T]$ 上
几乎必然连续。因此，根据微积分基本定理，$t \mapsto X_t$ 在 $[0,T]$ 上几乎必然连
续可微，且
$$\frac{dX_t}{dt} = B_t.$$

因此，$X$ 在 $[0,T]$ 上的全变差正是其导数的绝对值的积分：
$$V_T(X) = \int_0^T |B_s|\,ds.$$

由于 $B_s$ 在 $[0,T]$ 上几乎必然连续（因此有界），该积分几乎必然有限：
$$V_T(X) < \infty \quad \text{a.s.}$$

**步骤 2：具有有限变差的连续过程具有零二次变差。**

设 $\pi = \{0 = t_0 < t_1 < \cdots < t_n = T\}$ 为 $[0,T]$ 的一个划分，网格为 $|
\pi| = \max_i (t_{i+1}-t_i)$，并考虑二次变差和
$$S_\pi = \sum_{i=0}^{n-1} \bigl(X_{t_{i+1}} - X_{t_i}\bigr)^2.$$

我们进行界定
$$S_\pi = \sum_i \bigl|X_{t_{i+1}} - X_{t_i}\bigr|\cdot\bigl|X_{t_{i+1}} - X_{t_
i}\bigr| \le \Bigl(\max_i \bigl|X_{t_{i+1}} - X_{t_i}\bigr|\Bigr)\sum_i \bigl|X_
{t_{i+1}} - X_{t_i}\bigr|.$$

右侧的求和项受总变差限制：$\sum_i |X_{t_{i+1}} - X_{t_i}| \le V_T(X) < \infty$（
几乎必然）。此外，由于 $X$ 在 $[0,T]$ 上几乎必然连续（事实上是一致连续），当 $|\
pi| \to 0$ 时，最大增量 $\max_i |X_{t_{i+1}} - X_{t_i}|$ 几乎必然趋于 $0$。因此
$$\lim_{|\pi|\to 0} S_\pi \le \lim_{|\pi|\to 0}\Bigl(\max_i |X_{t_{i+1}}-X_{t_i}
|\Bigr)\cdot V_T(X) = 0 \quad \text{a.s.}$$

由于 $S_\pi \ge 0$，我们得出 $\lim_{|\pi|\to 0} S_\pi = 0$（几乎必然），且对于任
意划分序列，该极限均相同。根据连续半鞅二次变差的定义，
$$[X]_T = \lim_{|\pi|\to 0} \sum_i \bigl(X_{t_{i+1}} - X_{t_i}\bigr)^2 = 0 \quad
 \text{a.s.}$$

**步骤 3：结论。**

上述结论对所有 $T \ge 0$ 均成立。因此，二次变差过程为
$$[X]_t = 0, \qquad \text{for all } t \ge 0, \text{ a.s.}$$

这反映了这样一个一般事实：任何具有绝对连续路径的连续过程（相对于 Lebesgue 测度）
——因此具有有限变差——其二次变差为零。由于 $X_t = \int_0^t B_s\,ds$ 在 $t$ 中是 $C
^1$ 的，它属于此类，且其鞅部分（在连续半鞅分解 $X = X_0 + M + A$ 中）为零；$[X]
= [M] = 0$。
