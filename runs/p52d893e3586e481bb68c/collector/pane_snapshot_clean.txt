# 证明

## 第一步：利用边界条件将 $f$ 用 $f''$ 表示

因为 $f \in C^2$，所以对于 $x \in [-1,1]$，利用以 $-1$ 为基点的泰勒积分余项形式
：

$$f(x) = f(-1) + f'(-1)(x+1) + \int_{-1}^{x}(x-t)\,f''(t)\,dt = 1 + f'(-1)(x+1)
+ \int_{-1}^{x}(x-t)\,f''(t)\,dt.$$

## 第二步：由 $f(1)=1$ 确定 $f'(-1)$

代入 $x=1$：

$$1 = 1 + 2f'(-1) + \int_{-1}^{1}(1-t)\,f''(t)\,dt,$$

因此

$$f'(-1) = -\frac{1}{2}\int_{-1}^{1}(1-t)\,f''(t)\,dt. \tag{$\ast$}$$

## 第三步：由 $\int_{-1}^{1} f = 0$ 得到 $f''$ 上的唯一线性约束

计算

$$\int_{-1}^{1} f(x)\,dx = \int_{-1}^{1}\!\left[1 + f'(-1)(x+1) + \int_{-1}^{x}(
x-t)f''(t)\,dt\right]dx.$$

其中 $\int_{-1}^{1}1\,dx = 2$，$\int_{-1}^{1}(x+1)\,dx = 2$。对双重积分交换顺序
：

$$\int_{-1}^{1}\!\int_{-1}^{x}(x-t)f''(t)\,dt\,dx = \int_{-1}^{1}\!\left[\int_{t
}^{1}(x-t)\,dx\right]f''(t)\,dt = \int_{-1}^{1}\frac{(1-t)^2}{2}\,f''(t)\,dt.$$

因此

$$0 = 2 + 2f'(-1) + \int_{-1}^{1}\frac{(1-t)^2}{2}\,f''(t)\,dt.$$

代入 $(\ast)$：

$$0 = 2 - \int_{-1}^{1}(1-t)\,f''(t)\,dt + \int_{-1}^{1}\frac{(1-t)^2}{2}\,f''(t
)\,dt = 2 + \int_{-1}^{1}\frac{(1-t)^2 - 2(1-t)}{2}\,f''(t)\,dt.$$

由于 $(1-t)^2 - 2(1-t) = (1-t)(-1-t) = -(1-t)(1+t) = -(1-t^2)$，所以

$$0 = 2 - \int_{-1}^{1}\frac{1-t^2}{2}\,f''(t)\,dt,$$

即

$$\boxed{\int_{-1}^{1}(1-t^2)\,f''(t)\,dt = 4.} \tag{$\ast\ast$}$$

反之，给定任意满足 $(\ast\ast)$ 的连续函数 $g = f''$，令 $f(-1)=1$，$f'(-1)$ 由
$(\ast)$ 给出，则上述推导可逆，所得 $f$ 满足 $f(1)=1$ 且 $\int_{-1}^{1}f=0$。因
此 $(\ast\ast)$ 是 $f''$ 上的**唯一**约束。

## 第四步：Cauchy–Schwarz 不等式

由 Cauchy–Schwarz 不等式，

$$\left(\int_{-1}^{1}(1-t^2)\,f''(t)\,dt\right)^{\!2} \le \int_{-1}^{1}(1-t^2)^2
\,dt \cdot \int_{-1}^{1}\bigl(f''(t)\bigr)^2\,dt.$$

计算

$$\int_{-1}^{1}(1-t^2)^2\,dt = \int_{-1}^{1}(1-2t^2+t^4)\,dt = 2 - \frac{4}{3} +
 \frac{2}{5} = \frac{30-20+6}{15} = \frac{16}{15}.$$

结合 $(\ast\ast)$，左端为 $4^2 = 16$，故

$$16 \le \frac{16}{15}\int_{-1}^{1}\bigl(f''(t)\bigr)^2\,dt,$$

即

$$\int_{-1}^{1}\bigl(f''(x)\bigr)^2\,dx \ge 15.$$

## 第五步：等号成立的条件

Cauchy–Schwarz 等号成立当且仅当 $f''(t)$ 与 $(1-t^2)$ 成比例，即存在常数 $c$ 使

$$f''(t) = c\,(1-t^2).$$

代入 $(\ast\ast)$：$c\cdot\frac{16}{15} = 4$，得 $c = \dfrac{15}{4}$。于是

$$f''(t) = \frac{15}{4}(1-t^2).$$

两次积分：

$$f'(t) = \frac{15}{4}t - \frac{5}{4}t^3 + A,$$

$$f(t) = \frac{15}{8}t^2 - \frac{5}{16}t^4 + At + B.$$

由 $f(1)=1$：$\dfrac{15}{8}-\dfrac{5}{16}+A+B = 1$，即 $A+B = -\dfrac{9}{16}$。

由 $f(-1)=1$：$\dfrac{15}{8}-\dfrac{5}{16}-A+B = 1$，即 $-A+B = -\dfrac{9}{16}$
。

解得 $A=0$，$B=-\dfrac{9}{16}$。因此等号成立当且仅当

$$\boxed{f(x) = \frac{15}{8}x^2 - \frac{5}{16}x^4 - \frac{9}{16}.}$$

**验证**：$f(1) = \frac{30-5-9}{16}=1$，$f(-1)=1$（$f$ 为偶函数）；$\int_{-1}^{1
}f\,dx = 2\bigl(\frac{5}{8}-\frac{1}{16}-\frac{9}{16}\bigr)=2\cdot\frac{10-1-9}{
16}=0$；$\int_{-1}^{1}(f'')^2\,dx = \frac{225}{16}\cdot\frac{16}{15}=15$。全部满
足。$\blacksquare$
