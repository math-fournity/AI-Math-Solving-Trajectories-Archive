Looking at the problem, I need to find all $n \geq 1$ for which there exists $S
\subset \mathbb{Z}^n$ that is (1) an independent set in the grid graph and (2) a
 perfect dominating set (every non-$S$ vertex has exactly one neighbor in $S$).

**Answer:** Such a set exists for **every** $n \geq 1$.

## Proof

**Construction.** Let $m = 2n+1$. Define
$$S = \Big\{(a_1, \dots, a_n) \in \mathbb{Z}^n : a_1 + 2a_2 + 3a_3 + \cdots + n\
,a_n \equiv 0 \pmod{m}\Big\}.$$

Set $\varphi(p) = \sum_{i=1}^n i\,a_i \pmod{m}$ for $p = (a_1,\dots,a_n)$, so $S
 = \varphi^{-1}(0)$.

**Key observation.** The set of values $\{\pm 1, \pm 2, \dots, \pm n\} \pmod{m}$
 equals
$$\{1, \dots, n\} \cup \{m-n, \dots, m-1\} = \{1, \dots, n\} \cup \{n+1, \dots,
2n\} = \{1, 2, \dots, 2n\},$$
which is exactly the set of all nonzero residues modulo $m = 2n+1$.

**Condition 1 (independence).** Let $p \in S$, so $\varphi(p) \equiv 0 \pmod{m}$
. Each neighbor of $p$ is $p \pm e_j$ for some $j \in \{1,\dots,n\}$, and $\varp
hi(p \pm e_j) = \varphi(p) \pm j \equiv \pm j \pmod{m}$. Since $1 \leq j \leq n
< m$, both $j$ and $-j$ are nonzero modulo $m$. Hence no neighbor of $p$ lies in
 $S$. ✓

**Condition 2 (perfect domination).** Let $p \notin S$, so $\varphi(p) \equiv r
\pmod{m}$ for some $r \in \{1, 2, \dots, 2n\}$. A neighbor $p \pm e_j$ lies in $
S$ iff $r \pm j \equiv 0 \pmod{m}$, i.e., $\pm j \equiv -r \pmod{m}$.

Since $r$ is a nonzero residue, $-r \pmod{m}$ is also a nonzero residue, hence $
-r \pmod{m} \in \{1, \dots, 2n\}$. By the key observation, the values $\{\pm j :
 1 \leq j \leq n\}$ enumerate each nonzero residue exactly once. Therefore there
 is **exactly one** pair $(j, \sigma)$ with $\sigma \in \{+1,-1\}$ satisfying $\
sigma j \equiv -r \pmod{m}$, giving exactly one neighbor $p + \sigma e_j$ in $S$
. ✓

Both conditions hold for every $n \geq 1$, so the desired set exists for all pos
itive integers $n$.
