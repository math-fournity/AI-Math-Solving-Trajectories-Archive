Looking at this problem, I need to determine whether the boundary of an open set
 $D \subset \mathbb{R}^n$ (containing the origin, with each ray from $0$ hitting
 $\partial D$ at most once) must have Lebesgue measure 0.

**Answer: Yes, $\partial D$ has Lebesgue measure 0.**

**Proof:**

**Step 1: Measurability.** Since $D$ is open, $D$ is Lebesgue measurable. The cl
osure $\overline{D}$ is closed, hence measurable. Therefore $\partial D = \overl
ine{D} \setminus D$ is Lebesgue measurable (in fact, Borel).

**Step 2: The origin is not on the boundary.** Since $D$ is open and $0 \in D$,
there exists $\varepsilon > 0$ with $B(0,\varepsilon) \subset D$, so $0 \notin \
partial D$.

**Step 3: Polar coordinates.** The map $\Phi: (0,\infty) \times S^{n-1} \to \mat
hbb{R}^n \setminus \{0\}$, $\Phi(t,v) = tv$, is a smooth diffeomorphism with Jac
obian determinant $t^{n-1}$. The polar coordinates integration formula states th
at for any nonnegative measurable function $g$ on $\mathbb{R}^n$:

$$\int_{\mathbb{R}^n} g(x)\,dx = \int_0^\infty \int_{S^{n-1}} g(tv)\, t^{n-1}\,d
\sigma(v)\,dt,$$

where $\sigma$ is the surface measure on $S^{n-1}$. (For $n=1$, $S^0 = \{-1,+1\}
$ with counting measure, and the formula reduces to the standard decomposition $
\int_{\mathbb{R}} g = \int_0^\infty g(t)\,dt + \int_0^\infty g(-t)\,dt$.)

**Step 4: Apply to $\partial D$.** Set $g = \mathbf{1}_{\partial D}$, which is n
onnegative, measurable, and satisfies $g(0)=0$ (since $0 \notin \partial D$). Th
en:

$$\lambda_n(\partial D) = \int_0^\infty \int_{S^{n-1}} \mathbf{1}_{\partial D}(t
v)\, t^{n-1}\,d\sigma(v)\,dt.$$

**Step 5: Swap the order (Tonelli).** Since the integrand is nonnegative, Tonell
i's theorem gives:

$$\lambda_n(\partial D) = \int_{S^{n-1}} \left(\int_0^\infty \mathbf{1}_{\partia
l D}(tv)\, t^{n-1}\,dt\right) d\sigma(v).$$

**Step 6: Each inner integral is 0.** Fix $v \in S^{n-1}$. The ray $\{tv : t \ge
q 0\}$ intersects $\partial D$ in at most one point (by hypothesis). Since $0 \n
otin \partial D$, the set $\{t > 0 : tv \in \partial D\}$ contains **at most one
** element. Therefore the function $t \mapsto \mathbf{1}_{\partial D}(tv)\, t^{n
-1}$ is nonzero at no more than a single point $t \in (0,\infty)$. A function th
at vanishes outside a set of Lebesgue measure 0 has Lebesgue integral 0, so:

$$\int_0^\infty \mathbf{1}_{\partial D}(tv)\, t^{n-1}\,dt = 0 \quad \text{for ev
ery } v \in S^{n-1}.$$

**Step 7: Conclusion.** Substituting back:

$$\lambda_n(\partial D) = \int_{S^{n-1}} 0\, d\sigma(v) = 0.$$

Therefore $\partial D$ has Lebesgue measure $0$. $\blacksquare$

**Key idea:** The hypothesis forces $\partial D$ to be a "radial graph" — at mos
t one boundary point per direction. In polar coordinates, this means the set $E
= \Phi^{-1}(\partial D \setminus \{0\}) \subset (0,\infty) \times S^{n-1}$ inter
sects each fiber $\{(t,v) : t > 0\}$ (fixed $v$) in at most one point. By Fubini
/Tonelli, any such set has measure 0 with respect to the product measure $dt \ti
mes d\sigma$, and the Jacobian factor $t^{n-1}$ does not change this (the inner
1D integral still vanishes). The change-of-variables formula then transfers this
 to $\lambda_n(\partial D) = 0$.
