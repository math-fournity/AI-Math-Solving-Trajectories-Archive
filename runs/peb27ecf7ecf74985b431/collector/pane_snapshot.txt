## Proof

Let the annulus be $X = \{x \in \mathbb{R}^2 : r \le |x| \le R\}$ with $0 < r <
R$. The boundary is $A = C_{\text{in}} \cup C_{\text{out}}$, where $C_{\text{in}
} = \{|x|=r\}$ and $C_{\text{out}} = \{|x|=R\}$.

**The relative 1-cycle.** Define the radial 1-simplex $\sigma : [0,1] \to X$ by
$$\sigma(t) = \big((1-t)r + tR\big)\cdot(1,0).$$
This is a path from $p = (r,0) \in C_{\text{in}}$ to $q = (R,0) \in C_{\text{out
}}$. Its boundary is
$$\partial\sigma = q - p \in C_0(A),$$
so $[\sigma]$ is a relative 1-cycle in $C_1(X, A) = C_1(X)/C_1(A)$.

**$[\sigma]$ is not a relative 1-boundary.** Since $A$ is 1-dimensional, $C_2(A)
 = 0$, hence $C_2(X,A) = C_2(X)$. A relative 1-boundary has the form $[\partial
d]$ for some $d \in C_2(X)$, which means $\sigma - \partial d \in C_1(A)$, i.e.,
$$\sigma = \partial d + e \quad\text{for some } e \in C_1(A).$$

Suppose for contradiction such $d$ and $e$ exist. Taking the boundary of both si
des:
$$\partial\sigma = \partial(\partial d) + \partial e = \partial e,$$
so $q - p = \partial e$.

Now $C_1(A) = C_1(C_{\text{in}}) \oplus C_1(C_{\text{out}})$, so write $e = e_{\
text{in}} + e_{\text{out}}$ with $e_{\text{in}} \in C_1(C_{\text{in}})$ and $e_{
\text{out}} \in C_1(C_{\text{out}})$. Then
$$\partial e = \partial e_{\text{in}} + \partial e_{\text{out}},$$
where $\partial e_{\text{in}}$ is a 0-chain supported on $C_{\text{in}}$ and $\p
artial e_{\text{out}}$ is a 0-chain supported on $C_{\text{out}}$. Matching supp
orts in $q - p = \partial e$ gives:
$$\partial e_{\text{out}} = q, \qquad \partial e_{\text{in}} = -p.$$

But for any 1-chain $e_{\text{out}}$ on the circle $C_{\text{out}}$, the sum of
coefficients of $\partial e_{\text{out}}$ is $0$ (each 1-simplex contributes $+1
$ at one endpoint and $-1$ at the other). The 0-chain $q$ has coefficient sum $1
 \ne 0$. This is a contradiction.

Therefore no such $d$ and $e$ exist, and $[\sigma]$ is **not** a relative 1-boun
dary.

**Conclusion.** The class $[\sigma] \in C_1(X, A)$, represented by the radial se
gment from the inner boundary to the outer boundary, is a relative 1-cycle that
is not a relative 1-boundary. (In fact it generates $H_1(X, A) \cong \mathbb{Z}$
.)
