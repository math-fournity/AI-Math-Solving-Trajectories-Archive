## Proof that the answer is **YES**

We construct an explicit example.

### The curves

- **E₁ : y² = x³ + x** — CM by ℤ[i], conductor 64, rank 0 over ℚ.
- **E₂ : y² = x³ − x** — conductor 32, rank 0 over ℚ, full rational 2-torsion {(
0,0),(1,0),(−1,0)}.

### Ingredient I: E₂ has infinitely many quadratic twists of positive rank

For a prime p, the quadratic twist is E₂^(p) : y² = x³ − p²x (the congruent numb
er curve). By Monsky's computation of 2-Selmer groups:

- For p ≡ 5 or 7 (mod 8): the 2-Selmer rank of E₂^(p) equals **1** (odd).

The Cassels pairing on Ш[2] forces dim Ш[2] to be even, so the Mordell-Weil rank
 has the same parity as the Selmer rank. Therefore **rank E₂^(p)(ℚ) is odd, henc
e ≥ 1**, for every prime p ≡ 5, 7 (mod 8). There are infinitely many such primes
. This is unconditional.

### Ingredient II: E₁ has rank 0 for all but finitely many quadratic twists

E₁ has CM by ℤ[i]. By **Rohrlich's nonvanishing theorem** (1989):

> L(E₁^(d), 1) ≠ 0 for all but finitely many squarefree d.

By **Kolyvagin's theorem** (L(E,1) ≠ 0 ⟹ rank E(ℚ) = 0):

> rank E₁^(d)(ℚ) = 0 for all but finitely many squarefree d.

Define **S₁ = {squarefree d > 1 : rank E₁^(d)(ℚ) > 0}**. This is a **finite** se
t.

### Ingredient III: Eigenspace decomposition in multiquadratic extensions

**Lemma.** Let K_n = ℚ(√d₁,…,√d_n) with distinct squarefree d_i, and G = Gal(K_n
/ℚ) ≅ (ℤ/2)ⁿ. Then:

$$\operatorname{rank} E(K_n) = \sum_{\chi \in \hat{G}} \operatorname{rank} E^{(d
_\chi)}(\mathbb{Q})$$

where d_χ is the squarefree product corresponding to character χ.

*Proof.* G acts on E(K_n) ⊗ ℚ. Since G is abelian of exponent 2 and ℚ has charac
teristic 0 (Maschke), E(K_n) ⊗ ℚ decomposes as ⊕_χ V_χ where V_χ = {v : σ·v = χ(
σ)v ∀σ ∈ G}. For the trivial character, V₁ = E(ℚ) ⊗ ℚ. For nontrivial χ: the twi
sting isomorphism ψ: E → E^(d_χ) defined over ℚ(√d_χ) ⊂ K_n sends V_χ isomorphic
ally to E^(d_χ)(ℚ) ⊗ ℚ (one checks: if σ(P) = χ(σ)P then σ(ψ(P)) = ψ(P), using t
hat ψ^σ = χ(σ)·ψ). So dim V_χ = rank E^(d_χ)(ℚ). ∎

### Construction of K

Let **P_bad = {primes p : p | s for some s ∈ S₁}** — a finite set.

Choose distinct primes p₁, p₂, p₃, … such that:
- **p_i ≡ 5 or 7 (mod 8)** — so rank E₂^(p_i)(ℚ) ≥ 1 by Ingredient I, and
- **p_i ∉ P_bad** — so no product of p_i's lies in S₁ (every element of S₁ has a
ll prime factors in P_bad, while our products have all prime factors outside P_b
ad).

This is possible: infinitely many primes ≡ 5, 7 (mod 8), only finitely many in P
_bad.

Set **K = ℚ(√p₁, √p₂, √p₃, …)** — an infinite algebraic extension of ℚ.

### E₂(K) has infinite rank

Let K_n = ℚ(√p₁,…,√p_n). By the Lemma:

$$\operatorname{rank} E_2(K_n) = \sum_\chi \operatorname{rank} E_2^{(d_\chi)}(\m
athbb{Q}) \geq \sum_{i=1}^{n} \operatorname{rank} E_2^{(p_i)}(\mathbb{Q}) \geq n
.$$

The inequality uses the n characters corresponding to individual √p_i, each givi
ng a twist E₂^(p_i) of rank ≥ 1. Since rank E₂(K) = sup_n rank E₂(K_n) ≥ sup_n n
 = **∞**.

### E₁(K) has finite (zero) rank

By the Lemma:

$$\operatorname{rank} E_1(K_n) = \sum_\chi \operatorname{rank} E_1^{(d_\chi)}(\m
athbb{Q}).$$

- **Trivial character:** rank E₁(ℚ) = 0.
- **Each nontrivial χ:** d_χ is a squarefree product of p_i's, so d_χ ∉ S₁ (by c
onstruction), hence rank E₁^(d_χ)(ℚ) = 0.

Therefore rank E₁(K_n) = 0 for all n, and rank E₁(K) = sup_n 0 = **0**.

### Conclusion

$$\operatorname{rank} E_1(K) = 0 \quad\text{(finite)}, \qquad \operatorname{rank
} E_2(K) = \infty \quad\text{(infinite)}.$$

Both E₁ and E₂ are defined over ℚ, and K/ℚ is algebraic. **Yes, it is possible.*
