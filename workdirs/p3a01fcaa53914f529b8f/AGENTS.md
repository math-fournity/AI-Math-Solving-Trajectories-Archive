# Problem

A digital archivist is organizing a massive database consisting of $n$ data blocks. For any given total number of blocks $n$, the system calculates a "Total Processing Load" by summing the fractional processing time of each block from the 1st to the $n$-th. Specifically, the load is the sum of the reciprocals of the integers from 1 to $n$.

The system represents this Total Processing Load as a fraction $p_n / q_n$ reduced to its simplest form (where $p_n$ and $q_n$ are positive integers with no common factors other than 1).

The archivist is specifically interested in "Stable Configurations." A configuration $n$ is considered stable if the denominator of the simplified load fraction, $q_n$, is not a multiple of 5.

Let $S$ be the set containing every positive integer $n$ that results in a Stable Configuration. Calculate the sum of all elements contained in the set $S$.
