## Proof

**Answer: Yes, such a space exists.**

Let $\mathfrak{c} = 2^{\aleph_0}$ denote the continuum, and let $\kappa = \mathf
rak{c}^+$ be its successor cardinal, so $\kappa > \mathfrak{c}$.

**Construction.** Define $X = \kappa^{\mathbb{N}}$, the set of all sequences $x
= (x_0, x_1, x_2, \dots)$ with each $x_n \in \kappa$. Equip $X$ with the metric
$$
d(x, y) = \begin{cases} 0 & \text{if } x = y, \\ 2^{-n} & \text{where } n = \min
\{k : x_k \neq y_k\} & \text{if } x \neq y. \end{cases}
$$
This is a well-defined ultrametric (it satisfies the strong triangle inequality
$d(x,z) \le \max(d(x,y), d(y,z))$).

**Claim 1: $X$ is complete.** Let $(x^{(m)})_{m \in \mathbb{N}}$ be a Cauchy seq
uence in $X$. For each $n \ge 0$, by the Cauchy property there exists $M_n$ such
 that for all $p, q \ge M_n$, $d(x^{(p)}, x^{(q)}) < 2^{-n}$, which means $x^{(p
)}_k = x^{(q)}_k$ for all $k < n$. Thus the first $n$ coordinates stabilize for
$m \ge M_n$. Define $x \in \kappa^{\mathbb{N}}$ by $x_n = x^{(m)}_n$ for any $m
\ge M_{n+1}$. Then for every $n$, once $m \ge M_n$ we have $d(x^{(m)}, x) < 2^{-
n}$, so $x^{(m)} \to x$. Hence $X$ is complete.

**Claim 2: $X$ has no isolated points.** Every open ball $B(x, 2^{-n}) = \{y \in
 X : y_k = x_k \text{ for all } k < n\}$ is determined by fixing the first $n$ c
oordinates and leaving the rest free, so it has cardinality $\kappa^{\mathbb{N}}
 \ge 2$. In particular no ball is a singleton, so no point is isolated.

**Claim 3: $|X| > \mathfrak{c}$.** We have $|X| = \kappa^{\aleph_0} \ge \kappa^1
 = \kappa = \mathfrak{c}^+ > \mathfrak{c}$.

**Conclusion.** $X = \kappa^{\mathbb{N}}$ with the metric $d$ is a complete metr
ic space, has no isolated points, and has cardinality $\kappa^{\aleph_0} \ge \ka
ppa > \mathfrak{c} = 2^{\aleph_0}$. Therefore, there exists a complete metric sp
ace without isolated points whose cardinality exceeds the continuum. $\blacksqua
re$
