Let $T(w)$ denote the expected number of fair bits that must be examined until t
he pattern $w = w_1w_2w_3w_4$ first appears (ending at the last bit examined). B
ob picks $w$ uniformly from the 16 binary strings of length 4, so

$$\mathbb{E}[N] = \frac{1}{16}\sum_{w} T(w).$$

**Standard waiting-time formula.** For a pattern $w$ of length $m$ in a stream o
f i.i.d. fair bits, let

$$\mathcal{B}(w) = \{\, k \in \{1,\dots,m\} : w_1\cdots w_k = w_{m-k+1}\cdots w_
m \,\}$$

be the set of *border lengths* (lengths $k$ for which the length-$k$ prefix equa
ls the length-$k$ suffix; $k=m$ always belongs). Then

$$T(w) = \sum_{k \in \mathcal{B}(w)} 2^k.$$

*Justification (sketch).* Conditioning on the first occurrence ending at a given
 position and using the renewal/overlap structure of the pattern gives the linea
r system $T(w) = 2^m + \sum_{k \in \mathcal{B}(w)\setminus\{m\}} 2^k$, i.e. $T(w
) = \sum_{k\in\mathcal{B}(w)}2^k$. A quick sanity check: $T(\text{HH}) = 2^1+2^2
 = 6$ and $T(\text{HT}) = 2^2 = 4$, both classical values. ✓

**Computing borders for each 4-bit pattern.** A border of length $k$ requires $w
_1\cdots w_k = w_{4-k+1}\cdots w_4$:

- $k=4$: always present.
- $k=3$: requires $w_1w_2w_3 = w_2w_3w_4$, i.e. all four bits equal — only `0000
`, `1111`.
- $k=2$: requires $w_1w_2 = w_3w_4$ — exactly `0000, 0101, 1010, 1111`.
- $k=1$: requires $w_1 = w_4$.

Enumerating all 16 patterns:

| pattern | borders $\mathcal{B}$ | $T(w)$ |
|---|---|---|
| `0000` | {1,2,3,4} | $2+4+8+16 = 30$ |
| `1111` | {1,2,3,4} | $30$ |
| `0101` | {2,4} | $4+16 = 20$ |
| `1010` | {2,4} | $20$ |
| `0010, 0100, 0110, 1001, 1011, 1101` | {1,4} | $2+16 = 18$ each (6 patterns) |
| `0001, 0011, 0111, 1000, 1100, 1110` | {4} | $16$ each (6 patterns) |

Let me verify the {1,4} group: e.g. `0010`: $w_1=w_4$ ($0=0$ ✓), $k=2$: $00$ vs
$10$ ✗, $k=3$: $001$ vs $010$ ✗. So $\{1,4\}$, $T=18$. ✓
And the {4}-only group: e.g. `0001`: $w_1=0\neq 1=w_4$, $k=2$: $00\neq 01$, $k=3
$: $000\neq 001$. So $\{4\}$, $T=16$. ✓

**Averaging.** Grouping by value:

$$\sum_w T(w) = 2\cdot 30 + 2\cdot 20 + 6\cdot 18 + 6\cdot 16 = 60 + 40 + 108 +
96 = 304.$$

The count of patterns is $2+2+6+6 = 16$, confirming completeness. Therefore

$$\mathbb{E}[N] = \frac{304}{16} = 19.$$
