**Claim:** $f$ is an affine function, i.e., $f(x)=ax+b$ for constants $a,b\in\ma
thbb{R}$.

---

**Step 1. Characterize the image of $\phi\mapsto\phi''$.**

For $\phi\in D(\mathbb{R})$, set $\psi=\phi''$. By integration by parts (all bou
ndary terms vanish since $\phi$ is compactly supported):
$$\int \psi=\int\phi''=0,\qquad \int x\,\psi=\int x\,\phi''=-\int\phi'=0.$$

Conversely, let $\psi\in D(\mathbb{R})$ with $\int\psi=0$ and $\int x\,\psi=0$.
Define
$$\phi'(x)=\int_{-\infty}^{x}\psi(t)\,dt.$$
Since $\int\psi=0$, $\phi'$ has compact support (it vanishes for $x$ far to the
left and far to the right). Next define $\phi(x)=\int_{-\infty}^{x}\phi'(s)\,ds$
. For $\phi$ to have compact support we need $\int\phi'=0$. Computing (with $\op
eratorname{supp}\psi\subseteq[a,b']$):
$$\int\phi'=\int_a^{b'}\!\int_a^x\psi(t)\,dt\,dx=\int_a^{b'}\psi(t)(b'-t)\,dt=b'
\int\psi-\int t\,\psi=0-0=0.$$
So $\phi\in D(\mathbb{R})$ and $\phi''=\psi$. Hence
$$\{\phi'':\phi\in D(\mathbb{R})\}=\Bigl\{\psi\in D(\mathbb{R}):\int\psi=0,\ \in
t x\,\psi=0\Bigr\}.$$

---

**Step 2. Reformulate the hypothesis.**

The hypothesis $\int f\,\phi''=0$ for all $\phi\in D$ becomes:
$$\int f(x)\,\psi(x)\,dx=0\quad\text{for all }\psi\in D(\mathbb{R})\text{ with }
\int\psi=0,\ \int x\,\psi=0.$$

---

**Step 3. Decompose an arbitrary test function.**

Fix $\eta_1,\eta_2\in D(\mathbb{R})$ with
$$\int\eta_1=1,\ \int x\,\eta_1=0,\qquad \int\eta_2=0,\ \int x\,\eta_2=1.$$
For any $\phi\in D(\mathbb{R})$ set $c_1=\int\phi$, $c_2=\int x\,\phi$, and $\ps
i=\phi-c_1\eta_1-c_2\eta_2$. Then
$$\int\psi=c_1-c_1=0,\qquad \int x\,\psi=c_2-c_2=0,$$
so by Step 2, $\int f\,\psi=0$. Therefore
$$\int f\,\phi=c_1\!\int f\,\eta_1+c_2\!\int f\,\eta_2.$$

Let $A=\int f\,\eta_1$ and $B=\int f\,\eta_2$. Then for every $\phi\in D(\mathbb
{R})$:
$$\int f(x)\phi(x)\,dx=A\!\int\phi+B\!\int x\,\phi=\int\bigl(A+Bx\bigr)\phi(x)\,
dx.$$

---

**Step 4. Conclude.**

Thus $\int\bigl(f(x)-A-Bx\bigr)\phi(x)\,dx=0$ for all $\phi\in D(\mathbb{R})$. T
he function $g(x)=f(x)-A-Bx$ is continuous, and a continuous function that annih
ilates every test function is identically zero (otherwise $g$ is nonzero at some
 point, hence on a neighborhood, and a non-negative bump supported there gives a
 positive integral). Therefore
$$f(x)=A+Bx\quad\text{for all }x\in\mathbb{R}.$$

---

**Step 5. Converse (verification).**

If $f(x)=ax+b$, then for every $\phi\in D(\mathbb{R})$:
$$\int(ax+b)\phi''=a\!\int x\,\phi''+b\!\int\phi''=a\cdot 0+b\cdot 0=0,$$
so affine functions do satisfy the hypothesis.

---

**Conclusion.** The continuous functions $f$ satisfying $\int f\,\phi''=0$ for a
ll $\phi\in D(\mathbb{R})$ are exactly the **affine (linear) functions** $f(x)=a
x+b$.
