## Proof

Let
$$L = \lim_{n \to \infty}\left(\frac{n^4-3n^3-n^2+2n-1}{n^5+n^4-n^3-3n^2-3n+1}\r
ight)^{\left(\frac{6n^5-2n^4-2n^3+n^2-2n}{9n^4-2n^3+n^2+3n}\right)}.$$

Denote the base by $a_n$ and the exponent by $b_n$.

**Asymptotics of the base.** Dividing numerator and denominator by the leading p
owers,

$$a_n = \frac{n^4\!\left(1-\frac{3}{n}-\frac{1}{n^2}+\frac{2}{n^3}-\frac{1}{n^4}
\right)}{n^5\!\left(1+\frac{1}{n}-\frac{1}{n^2}-\frac{3}{n^3}-\frac{3}{n^4}+\fra
c{1}{n^5}\right)} = \frac{1}{n}\cdot\frac{1+O(1/n)}{1+O(1/n)}.$$

Hence $a_n \sim \dfrac{1}{n}\to 0^{+}$ (positive for all sufficiently large $n$,
 since both leading coefficients are positive).

**Asymptotics of the exponent.** Similarly,

$$b_n = \frac{6n^5\!\left(1-\frac{1}{3n}-\frac{1}{3n^2}+\cdots\right)}{9n^4\!\le
ft(1-\frac{2}{9n}+\cdots\right)} = \frac{6n}{9}\cdot\frac{1+O(1/n)}{1+O(1/n)} =
\frac{2n}{3}\,(1+O(1/n)).$$

Thus $b_n \sim \dfrac{2n}{3}\to +\infty$.

**Combining.** For large $n$, $a_n \sim 1/n$ and $b_n \sim 2n/3$, so

$$a_n^{\,b_n} \sim \left(\frac{1}{n}\right)^{2n/3} = n^{-2n/3}.$$

More precisely, write $a_n = \frac{c_n}{n}$ with $c_n\to 1$, and $b_n = \frac{2n
}{3}\,d_n$ with $d_n\to 1$. Then

$$\ln\!\left(a_n^{\,b_n}\right) = b_n\ln a_n = \frac{2n}{3}\,d_n\left(-\ln n + \
ln c_n\right) = -\frac{2n}{3}\,d_n\ln n\;\underbrace{+\;\frac{2n}{3}\,d_n\ln c_n
}_{\to\,0\cdot\infty\text{?}}.$$

Since $c_n\to 1$, we have $\ln c_n = O(1/n)$ (as $c_n = 1+O(1/n)$), so $\frac{2n
}{3}d_n\ln c_n = O(1)\cdot O(1/n)\cdot n = O(1)$, i.e. bounded. Meanwhile the do
minant term $-\frac{2n}{3}d_n\ln n \to -\infty$.

Therefore $\ln\!\left(a_n^{\,b_n}\right)\to -\infty$, which gives

$$a_n^{\,b_n} = e^{\ln(a_n^{b_n})}\to e^{-\infty} = 0.$$

$$\boxed{L = 0}$$
