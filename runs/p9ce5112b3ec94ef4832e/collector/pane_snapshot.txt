# Solution

## Setup: Change of Variables

Let $u = xy$ and $v = x^2 - y^2$. The region is described by $1 < u < 3$ and $1
< v < 3$.

**Jacobian:**
$$\frac{\partial(u,v)}{\partial(x,y)} = \begin{vmatrix} y & x \\ 2x & -2y \end{v
matrix} = -2y^2 - 2x^2 = -2(x^2+y^2).$$

So $\left|\frac{\partial(u,v)}{\partial(x,y)}\right| = 2(x^2+y^2)$, giving $dx\,
dy = \frac{du\,dv}{2(x^2+y^2)}$.

## Expressing the Density in $(u,v)$

Let $s = x^2 + y^2$. Then:
$$s^2 = (x^2+y^2)^2 = (x^2-y^2)^2 + 4x^2y^2 = v^2 + 4u^2.$$

Also $x^4 + y^4 = (x^2+y^2)^2 - 2x^2y^2 = s^2 - 2u^2$.

The density becomes:
$$\sigma = s(s^2 - 2u^2) = s\,s^2 - 2u^2 s.$$

## Transforming the Integral

$$M = \iint_R \sigma\, dA = \iint_R s(s^2-2u^2)\cdot\frac{du\,dv}{2s} = \iint_R
\frac{s^2 - 2u^2}{2}\,du\,dv.$$

Substituting $s^2 = v^2 + 4u^2$:
$$\frac{s^2 - 2u^2}{2} = \frac{v^2 + 4u^2 - 2u^2}{2} = \frac{v^2 + 2u^2}{2}.$$

## Bijection Check

For $(u,v)$ with $u>0, v>0$: we get $x^2 = \frac{\sqrt{v^2+4u^2}+v}{2} > 0$ and
$y^2 = \frac{\sqrt{v^2+4u^2}-v}{2} > 0$ (since $u>0$). Taking positive roots giv
es a unique $(x,y)$ in the first quadrant. So the first-quadrant region maps bij
ectively onto the rectangle $\{1<u<3,\; 1<v<3\}$.

## Evaluating the Integral

$$M = \frac{1}{2}\int_1^3\!\int_1^3 (v^2 + 2u^2)\,du\,dv = \frac{1}{2}\left[\int
_1^3 v^2\,dv\int_1^3 du + 2\int_1^3 u^2\,du\int_1^3 dv\right].$$

Computing each piece:
- $\int_1^3 v^2\,dv = \frac{v^3}{3}\Big|_1^3 = \frac{27-1}{3} = \frac{26}{3}$, a
nd $\int_1^3 du = 2$, so the first term is $\frac{26}{3}\cdot 2 = \frac{52}{3}$.
- $\int_1^3 u^2\,du = \frac{26}{3}$, and $\int_1^3 dv = 2$, so the second term i
s $2\cdot\frac{26}{3}\cdot 2 = \frac{104}{3}$.

Therefore:
$$M = \frac{1}{2}\left(\frac{52}{3} + \frac{104}{3}\right) = \frac{1}{2}\cdot\fr
ac{156}{3} = \frac{1}{2}\cdot 52 = \boxed{26}.$$
