## Proof

Let
$$I = \int_{-\infty}^{\infty}\left[\frac{\arctan x}{x}\right]^{2}dx.$$
The integrand is even, so $I = 2\int_{0}^{\infty}\left[\frac{\arctan x}{x}\right
]^{2}dx$.

**Key representation.** Using
$$\arctan x = \int_{0}^{1}\frac{x}{1+x^{2}t^{2}}\,dt,$$
we get, for $x\neq 0$,
$$\frac{\arctan x}{x} = \int_{0}^{1}\frac{dt}{1+x^{2}t^{2}}.$$
(At $x=0$ both sides equal $1$ by continuity, so the identity holds everywhere.)

**Squaring and integrating.** By Tonelli's theorem (the integrand is non-negativ
e),
$$\int_{0}^{\infty}\left[\frac{\arctan x}{x}\right]^{2}dx = \int_{0}^{1}\!\int_{
0}^{1}\left(\int_{0}^{\infty}\frac{dx}{(1+x^{2}t^{2})(1+x^{2}s^{2})}\right)dt\,d
s.$$

**Inner integral.** For $s\neq t$, partial fractions give
$$\frac{1}{(1+t^{2}x^{2})(1+s^{2}x^{2})} = \frac{1}{s^{2}-t^{2}}\left(\frac{s^{2
}}{1+s^{2}x^{2}}-\frac{t^{2}}{1+t^{2}x^{2}}\right).$$
Hence, using $\int_{0}^{\infty}\frac{dx}{1+a^{2}x^{2}}=\frac{\pi}{2a}$ ($a>0$),
$$\int_{0}^{\infty}\frac{dx}{(1+t^{2}x^{2})(1+s^{2}x^{2})} = \frac{1}{s^{2}-t^{2
}}\left(s^{2}\cdot\frac{\pi}{2s}-t^{2}\cdot\frac{\pi}{2t}\right) = \frac{\pi}{2}
\cdot\frac{s-t}{s^{2}-t^{2}} = \frac{\pi}{2(s+t)}.$$
By continuity this formula also holds at $s=t$ (where the value is $\frac{\pi}{4
s}$). Therefore
$$\int_{0}^{\infty}\left[\frac{\arctan x}{x}\right]^{2}dx = \frac{\pi}{2}\int_{0
}^{1}\!\int_{0}^{1}\frac{dt\,ds}{s+t}.$$

**Evaluating the double integral.**
$$\int_{0}^{1}\frac{dt}{s+t} = \ln(s+1)-\ln s,$$
so
$$\int_{0}^{1}\!\int_{0}^{1}\frac{dt\,ds}{s+t} = \int_{0}^{1}\bigl(\ln(s+1)-\ln
s\bigr)\,ds.$$
Now
$$\int_{0}^{1}\ln(s+1)\,ds = \bigl[(s+1)\ln(s+1)-(s+1)\bigr]_{0}^{1} = (2\ln 2-2
)-(-1)=2\ln 2-1,$$
$$\int_{0}^{1}\ln s\,ds = \bigl[s\ln s - s\bigr]_{0}^{1} = -1.$$
Thus the double integral equals $(2\ln 2-1)-(-1)=2\ln 2$.

**Conclusion.**
$$\int_{0}^{\infty}\left[\frac{\arctan x}{x}\right]^{2}dx = \frac{\pi}{2}\cdot 2
\ln 2 = \pi\ln 2,$$
and by evenness,
$$I = 2\pi\ln 2.$$

$$\boxed{\displaystyle\int_{-\infty}^{\infty}\left[\frac{\arctan x}{x}\right]^{2
}dx = 2\pi\ln 2.}$$
