**Proof.**

**Setup.** Set $q = 1991$, so $1990 = q - 1$ and $1992 = q + 1$. Let $n = q^{199
2}$, $m = q^{1990}$, so $n = q^2 m$. Since $q$ is odd, $n$ is odd. Then:
$$S = (q-1)^n + (q+1)^m = (-1)^n(1-q)^n + (1+q)^m = (1+q)^m - (1-q)^n.$$

Since $n = q^2 m$, write $(1-q)^n = \big((1-q)^{q^2}\big)^m$. Set $A = 1+q$ and
$B = (1-q)^{q^2}$, so:
$$S = A^m - B^m = (A - B)\cdot T, \quad T = \sum_{i=0}^{m-1} A^{m-1-i}B^i.$$

**Valuation of $A - B$.** Expand $(1-q)^{q^2} = 1 - q^3 + \binom{q^2}{2}q^2 - \c
dots$, so:
$$A - B = (1+q) - (1-q)^{q^2} = q + q^3 - \binom{q^2}{2}q^2 + \cdots = q\big(1 +
 q^2 - \tbinom{q^2}{2}q + \cdots\big).$$
The parenthetical factor is $\equiv 1 \pmod{p}$ for $p \in \{11,181\}$ (since $q
 \equiv 0 \pmod p$). Thus $v_p(A-B) = v_p(q) = 1$.

**Valuation of $T$.** Write $A = 1+u$, $B = 1+w$ where $u = q$ ($v_p(u)=1$) and
$w = B-1 = (1-q)^{q^2}-1$.

Compute $v_p(w)$: the $j=1$ term of $(1-q)^{q^2}-1$ is $-q^3$ (valuation 3); the
 $j=2$ term is $\binom{q^2}{2}q^2$ (valuation $2+2=4$); higher terms have valuat
ion $\ge 5$. So $v_p(w) = 3$.

Expand each summand using the binomial theorem and apply the Vandermonde convolu
tion $\sum_{i=0}^{m-1}\binom{m-1-i}{a}\binom{i}{b} = \binom{m}{a+b+1}$:
$$T = \sum_{s=0}^{m-1}\binom{m}{s+1}\sum_{a=0}^{s} q^a\, w^{s-a}.$$

For the inner sum: $v_p(q^a w^{s-a}) = a + 3(s-a) = 3s - 2a$, minimized at $a =
s$ giving $v_p = s$ (the next term, $a = s-1$, has valuation $s+2$), so $v_p\!\l
eft(\sum_{a=0}^s q^a w^{s-a}\right) = s$.

For the binomial coefficient: since $m = q^{1990}$ and $m - j \equiv -j \pmod{p}
$, we get $v_p(m - j) = v_p(j)$, hence:
$$v_p\!\left(\binom{m}{s+1}\right) = v_p(m) + \sum_{j=1}^{s}v_p(m-j) - v_p((s+1)
!) = 1990 + v_p(s!) - v_p((s+1)!) = 1990 - v_p(s+1).$$

Therefore the $s$-th term has $p$-adic valuation $1990 - v_p(s+1) + s$.

- **$s = 0$:** valuation $= 1990 - 0 + 0 = 1990$. (This is the term $m = q^{1990
}$.)
- **$s \ge 1$:** Since $p \ge 11$ and $p^{v_p(s+1)} \le s+1 < 11^s \le p^s$, we
have $v_p(s+1) < s$, so the valuation is $\ge 1990 + 1 = 1991$.

The $s = 0$ term uniquely achieves the minimum valuation $1990$, so:
$$v_p(T) = 1990, \quad p \in \{11, 181\}.$$

**Conclusion.** For both $p = 11$ and $p = 181$:
$$v_p(S) = v_p(A - B) + v_p(T) = 1 + 1990 = 1991.$$

Since $1991 = 11 \times 181$ with both factors prime and appearing to the first
power:
$$v_{1991}(S) = \min\big(v_{11}(S),\, v_{181}(S)\big) = \min(1991, 1991) = 1991.
$$

The largest integer $k$ such that $1991^k \mid 1990^{1991^{1992}} + 1992^{1991^{
1990}}$ is $\boxed{1991}$.
