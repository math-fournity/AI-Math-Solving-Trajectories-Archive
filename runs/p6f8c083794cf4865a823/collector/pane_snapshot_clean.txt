## Solution

ns, or hints. Proceeding.

We find all triples $(m, p, q)$ with $m \in \mathbb{Z}_{>0}$ and $p, q$ prime sa
tisfying
$$2^m p^2 + 1 = q^5.$$

---

### Step 1: Factorization

Rewrite as
$$q^5 - 1 = 2^m p^2 \quad\Longrightarrow\quad (q-1)(q^4+q^3+q^2+q+1) = 2^m p^2.$
$

Set $A = q-1$ and $B = q^4+q^3+q^2+q+1$.

**$q = 2$:** Then $2^m p^2 = 31$, which is odd, but $2^m$ ($m \geq 1$) is even —
 contradiction. So $q$ is odd, $q \geq 3$.

For odd $q$: $A = q-1$ is even, $B$ is odd (sum of 5 odd terms). Hence every fac
tor of $2$ in $2^m p^2$ comes from $A$. Write $q - 1 = 2^m s$ with $s$ odd. Then
$$2^m p^2 = 2^m s \cdot B \quad\Longrightarrow\quad p^2 = s \cdot B.$$

### Step 2: GCD analysis

$\gcd(A, B) = \gcd(q-1,\, B)$. Since $q \equiv 1 \pmod{q-1}$, we get $B \equiv 5
 \pmod{q-1}$, so $\gcd(q-1, B) \mid 5$. In particular $\gcd(s, B) \mid 5$.

### Step 3: Classifying $s$ and $B$

Since $p$ is prime and $s \cdot B = p^2$ with $s, B$ positive integers, the only
 possibilities are
$$(s, B) \in \{(1,\, p^2),\;(p,\, p),\;(p^2,\, 1)\}.$$

- **$(s, B) = (p^2, 1)$:** $B = 1$ is impossible since $B \geq 5$ for $q \geq 1$
.
- **$(s, B) = (p, p)$:** Requires $B = p$ and $q - 1 = 2^m p = 2^m B$. But $B =
q^4+q^3+q^2+q+1 > q-1$ for all $q \geq 2$, so $2^m B > B > q-1$ — contradiction.
- **$(s, B) = (1, p^2)$:** This gives $q - 1 = 2^m$ (so $q = 2^m + 1$) and
$$q^4 + q^3 + q^2 + q + 1 = p^2. \tag{$\star$}$$

### Step 4: Solving $(\star)$ — bounding between consecutive squares

Multiply $(\star)$ by $4$:
$$4p^2 = 4q^4 + 4q^3 + 4q^2 + 4q + 4.$$

Compare with consecutive squares $(2q^2+q)^2$ and $(2q^2+q+1)^2$:
$$(2q^2+q)^2 = 4q^4 + 4q^3 + q^2,$$
$$(2q^2+q+1)^2 = 4q^4 + 4q^3 + 5q^2 + 2q + 1.$$

**Lower bound:**
$$4p^2 - (2q^2+q)^2 = 3q^2 + 4q + 4 > 0 \quad\text{for all } q \geq 1.$$

**Upper bound:**
$$4p^2 - (2q^2+q+1)^2 = -q^2 + 2q + 3 = -(q-3)(q+1).$$

- For $q > 3$: $-(q-3)(q+1) < 0$, so $(2q^2+q)^2 < 4p^2 < (2q^2+q+1)^2$. But $4p
^2 = (2p)^2$ is a perfect square lying **strictly between two consecutive perfec
t squares** — impossible.
- For $q = 3$: $-(q-3)(q+1) = 0$, so $4p^2 = (2q^2+q+1)^2 = 22^2$, giving $p = 1
1$.

### Step 5: Verification

With $q = 3$, $p = 11$: from $q = 2^m + 1$ we get $2^m = 2$, so $m = 1$. Check:
$$2^1 \cdot 11^2 + 1 = 2 \cdot 121 + 1 = 243 = 3^5 = q^5. \quad\checkmark$$

All three values ($m=1$, $p=11$, $q=3$) satisfy the requirements ($m$ positive i
nteger, $p$ and $q$ prime).

---

### Conclusion

The unique triple is

$$\boxed{(m,\, p,\, q) = (1,\, 11,\, 3)}.$$
