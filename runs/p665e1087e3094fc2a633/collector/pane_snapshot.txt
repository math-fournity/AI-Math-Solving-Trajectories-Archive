Yes, it is true. In fact the conclusion holds for *any* increasing family (count
able or uncountable) of subspaces whose union is $\mathbb{R}^n$; the uncountabil
ity hypothesis is unnecessary.

**Proof.** For each $t>0$ set $d(t)=\dim V_t\in\{0,1,\dots,n\}$. Since the famil
y is increasing ($s<t\Rightarrow V_s\subseteq V_t$), the function $d$ is non‑dec
reasing in $t$.

**Claim.** $\sup_{t>0} d(t)=\dim\!\left(\bigcup_{t>0}V_t\right)=\dim\mathbb{R}^n
=n$.

The inequality $\sup_t d(t)\le \dim\!\left(\bigcup_t V_t\right)$ is immediate si
nce each $V_t\subseteq\bigcup_t V_t$. For the reverse inequality, let $k=\sup_t
d(t)$ and pick any finite set of vectors $u_1,\dots,u_m\in\bigcup_t V_t$. Each $
u_i$ belongs to some $V_{t_i}$; because the index set $(0,\infty)$ is totally or
dered and the family is increasing, setting $T=\max_i t_i$ gives $u_1,\dots,u_m\
in V_T$. Hence $\operatorname{span}\{u_1,\dots,u_m\}\subseteq V_T$, so $m\le d(T
)\le k$. Thus every finite subset of the union has size at most $k$ when linearl
y independent, giving $\dim\!\left(\bigcup_t V_t\right)\le k=\sup_t d(t)$. (Equi
valently: the dimension of an increasing union equals the supremum of the dimens
ions.) The claim follows from the hypothesis $\bigcup_{t>0}V_t=\mathbb{R}^n$.

Now $d$ takes values in the finite set $\{0,1,\dots,n\}$. A non‑decreasing funct
ion valued in a finite set attains its supremum: if $\sup d(t)=n$ yet $d(t)\le n
-1$ for all $t$, then $\sup d(t)\le n-1<n$, contradiction. Hence there exists $T
>0$ with $d(T)=n$, i.e. $\dim V_T=n$. Since $V_T\subseteq\mathbb{R}^n$ and both
have dimension $n$, we conclude $V_T=\mathbb{R}^n$.

The argument used only that $\mathbb{R}^n$ is finite‑dimensional (so dimensions
are bounded integers) and that the index set is totally ordered; the uncountabil
ity of the family plays no role.
