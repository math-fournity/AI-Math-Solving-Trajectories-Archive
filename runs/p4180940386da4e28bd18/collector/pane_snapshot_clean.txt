## 解答

**设定。** 令 $\phi = \frac{1+\sqrt{5}}{2}$ 为黄金比例，并令 $\psi = \frac{1-\sq
rt{5}}{2} = -\phi^{-1}$，因此 $|\psi| = \phi^{-1} < 1$。

**第一步：将 $\phi^k$ 与 Lucas 数联系起来。** Lucas 数满足 Binet 公式：

$$L_k = \phi^k + \psi^k.$$

因此 $\phi^k = L_k - \psi^k$，且对于 $k \ge 2$：

$$|\psi^k| = \phi^{-k} \le \phi^{-2} = \frac{3-\sqrt{5}}{2} \approx 0.382 < \tfr
ac{1}{2}.$$

由于 $L_k$ 是一个整数，且 $\phi^k$ 与 $L_k$ 的距离在 $\phi^{-k} < \frac{1}{2}$
之内，因此对于所有 $k \ge 2$，最接近 $\phi^k$ 的整数即为 $L_k$：

$$\lfloor \phi^k \rceil = L_k, \qquad k \ge 2.$$

**第二步：计算该求和。** Lucas 数的生成函数为：

$$\sum_{k=0}^{\infty} L_k x^k = \frac{2-x}{1-x-x^2}.$$

（验证：$L_0=2$, $L_1=1$，且递推关系 $L_k = L_{k-1}+L_{k-2}$ 给出了分母 $1-x-x^2
$。）

我们需要 $x = \tfrac{1}{2}$ 时的 $S = \sum_{k=2}^{\infty} L_k x^k$：

$$\sum_{k=0}^{\infty} L_k \left(\tfrac{1}{2}\right)^k = \frac{2-\tfrac{1}{2}}{1-
\tfrac{1}{2}-\tfrac{1}{4}} = \frac{\tfrac{3}{2}}{\tfrac{1}{4}} = 6.$$

减去 $k=0$ 和 $k=1$ 的项（$L_0 = 2$, $L_1 = 1$）：

$$S = 6 - L_0 - L_1\cdot\tfrac{1}{2} = 6 - 2 - \tfrac{1}{2} = \frac{7}{2}.$$

**第三步：得出 $a+b$。** 我们有 $\frac{a}{b} = \frac{7}{2}$，其中 $\gcd(7,2)=1$
，因此 $a=7$, $b=2$，且

$$a + b = 9.$$
