## Proof

### Setup

We solve $(1 + m^n)^s = 1 + m^t$ for positive integers with $1 \le m \le 10$, $1
 \le n \le 10$.

**Case $m = 1$:** $(1+1^n)^s = 2^s = 1 + 1^t = 2$, so $s = 1$, $t$ arbitrary pos
itive integer. But $1^t = 1$ for all $t$, so $t$ can be any positive integer — h
owever, we need $t = n$ from $m^n = m^t$ (since $1^n = 1^t$ always). Actually wi
th $m=1$: $2^s = 2$ forces $s=1$, and $1+1^n = 1+1^t$ gives $t = n$. So quadrupl
es $(1, 1, n, n)$ for $n \in \{1,...,10\}$.

### Case $s = 1$ (general $m$)

$(1+m^n)^1 = 1 + m^n = 1 + m^t$ gives $m^n = m^t$, so $t = n$ (for $m \ge 2$; fo
r $m=1$ also $t=n$).

This yields **100 quadruples** $(m, 1, n, n)$ for $m \in \{1,...,10\}$, $n \in \
{1,...,10\}$.

### Case $s \ge 2$, $m \ge 2$

Set $a = 1 + m^n$. We need $a^s - 1 = m^t$, i.e., $m^t = m^n \cdot R$ where $R =
 \sum_{k=0}^{s-1}(1+m^n)^k = \sum_{j=0}^{s-1}\binom{s}{j+1}m^{nj}$, giving $R =
m^{t-n}$ with $t > n$ (since $R > 1$).

**Key constraint via order:** Since $R \equiv 1 \pmod{1+m^n}$ (all terms with $k
 \ge 1$ vanish mod $1+m^n$), we need $m^{t-n} \equiv 1 \pmod{1+m^n}$. Since $m^n
 \equiv -1 \pmod{1+m^n}$, the order of $m$ mod $1+m^n$ is exactly $2n$ (as $m^d
+ 1 < m^n + 1$ for $d < n$, so no smaller exponent gives $-1$). Thus $2n \mid (t
-n)$, so $t = n(2j+1)$ for some $j \ge 1$, and $R = m^{2nj}$.

**LTE analysis:** For each odd prime $p \mid m$: $v_p(a^s - 1) = v_p(a-1) + v_p(
s) = n\,v_p(m) + v_p(s) = t\,v_p(m)$, giving $v_p(s) = (t-n)\,v_p(m) = 2nj\,v_p(
m)$.

So $s$ is divisible by $\prod_{p \mid m,\, p\text{ odd}} p^{2nj\,v_p(p)} = (\tex
t{odd part of }m)^{2nj}$.

**If $m$ has any odd prime factor:** $(\text{odd part})^{2nj} \ge 3^2 = 9$, but
$s \le 2j$ (from $R > m^{n(s-1)}$ requiring $n(s-1) < 2nj$, i.e., $s \le 2j+1$,
combined with size bounds). Since $9 > 2j$ for $j \ge 1$, **no solution**.

**If $m = 2^a$ (pure power of 2):** For $s$ odd, LTE gives $v_2(a^s-1) = v_2(a-1
) = n\cdot a$, requiring $t = n$, contradicting $t > n$. So $s$ must be even.

For $s$ even: $v_2(s) = 2nja - v_2(2 + 2^{an}) + 1$.

- If $an = 1$ (i.e., $m=2, n=1$): $v_2(2+2) = 2$, so $v_2(s) = 2j - 1$. Need $2^
{2j-1} \le s \le 2j$. Only $j=1$: $2^1 = 2 \le 2$, giving $s = 2$.
  - **Check:** $R = 2 + 2 = 4 = 2^2 = m^{2\cdot1\cdot1}$. ✓ This gives $(m,s,n,t
) = (2, 2, 1, 3)$.
  - $j \ge 2$: $2^{2j-1} > 2j$. No solution.
- If $an \ge 2$: $v_2(2+2^{an}) = 1$, so $v_2(s) = 2nja$. Need $2^{2nja} \le 2j$
, but $2nja \ge 4$ gives $2^{2nja} \ge 16 > 2j$. No solution.
