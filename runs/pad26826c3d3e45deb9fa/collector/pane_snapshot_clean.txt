## Solution

**Problem.** Find all $f: \mathbb{R} \to \mathbb{R}$ with $f(x^2 + f(y)) = y + (
f(x))^2$ for all $x, y \in \mathbb{R}$.

**Answer check:** No leaked answers in the problem statement.

---

### Step 1: Surjectivity

Let $P(x,y)$ denote the assertion. Fixing $x$, as $y$ ranges over $\mathbb{R}$,
the right side $y + (f(x))^2$ attains every real value. Hence $f$ is **surjectiv
e**. Pick $a \in \mathbb{R}$ with $f(a) = 0$.

### Step 2: A key identity

$P(x, a)$: $f(x^2 + 0) = a + (f(x))^2$, i.e.,
$$f(x^2) = a + (f(x))^2. \tag{1}$$

Substituting $(f(x))^2 = f(x^2) - a$ into $P(x,y)$:
$$f(x^2 + f(y)) = y + f(x^2) - a.$$

Setting $t = x^2 \geq 0$:
$$f(t + f(y)) = f(t) + y - a, \quad \forall\, t \geq 0,\; y \in \mathbb{R}. \tag
{2}$$

### Step 3: Injectivity

If $f(y_1) = f(y_2)$, then by (2), $f(t + f(y_1)) = f(t + f(y_2))$ for all $t \g
eq 0$, giving $y_1 - a = y_2 - a$, so $y_1 = y_2$. Thus $f$ is **injective**, he
nce **bijective**.

### Step 4: Computing $f(f(y))$ and $f^{-1}$

Set $t = 0$ in (2): $f(f(y)) = f(0) + y - a$. Let $c = f(0)$. From (1) at $x=0$:
 $c = a + c^2$, so $a = c - c^2$. Therefore
$$f(f(y)) = y + c^2. \tag{3}$$

Since $f$ is bijective, write $u = f(y)$, $y = f^{-1}(u)$ in (2):
$$f(t + u) = f(t) + f^{-1}(u) - a, \quad \forall\, t \geq 0,\; u \in \mathbb{R}.
 \tag{$*$}$$

Setting $t = 0$: $f(u) = c + f^{-1}(u) - a = f^{-1}(u) + c^2$, so
$$f^{-1}(u) = f(u) - c^2. \tag{$**$}$$

Substituting back into ($*$):
$$f(t + u) = f(t) + f(u) - c, \quad \forall\, t \geq 0,\; u \in \mathbb{R}. \tag
{7}$$

### Step 5: Oddness on $\mathbb{R}\setminus\{0\}$

From (1): $f(x^2) = a + (f(x))^2 = a + (f(-x))^2$, so $(f(x))^2 = (f(-x))^2$. Fo
r $x \neq 0$, injectivity gives $f(-x) \neq f(x)$, hence
$$f(-x) = -f(x), \quad \forall\, x \neq 0. \tag{odd}$$

### Step 6: Proving $c = 0$

Set $g(x) = f(x) - c$, so $g(0) = 0$ and (7) becomes $g(t+u) = g(t) + g(u)$ for
$t \geq 0$, $u \in \mathbb{R}$. The oddness relation gives, for $x \neq 0$:
$$g(-x) = f(-x) - c = -f(x) - c = -g(x) - 2c.$$

Now test full additivity with $t < 0$, $u < 0$ (write $t = -s$, $u = -r$, $s, r
> 0$):
- $g(t+u) = g(-(s+r)) = -g(s+r) - 2c = -g(s) - g(r) - 2c$ (using additivity on p
ositive reals).
- $g(t) + g(u) = (-g(s)-2c) + (-g(r)-2c) = -g(s) - g(r) - 4c$.

Equating: $-2c = -4c$, so $c = 0$.

### Step 7: $f$ is additive and multiplicative on squares

With $c = 0$: $a = 0$, $f(0) = 0$, $g = f$, and $f$ is **additive** on all of $\
mathbb{R}$ (oddness now holds everywhere, extending additivity to negative first
 arguments). Equation (1) becomes
$$f(x^2) = (f(x))^2. \tag{$*$}$$

### Step 8: $f$ is the identity

Additivity gives $f(q) = q\,f(1)$ for all $q \in \mathbb{Q}$. From ($*$) at $x =
 1$: $f(1) = (f(1))^2$, so $f(1) \in \{0, 1\}$.

**If $f(1) = 0$:** then $f \equiv 0$ on $\mathbb{Q}$. For $x \geq 0$, $x = (\sqr
t{x})^2$, so $f(x) = (f(\sqrt{x}))^2 \geq 0$; by oddness $f(x) \leq 0$ for $x \l
eq 0$. Thus $f$ is monotone nondecreasing. An additive monotone function is line
ar: $f(x) = f(1)\cdot x = 0$. But $f \equiv 0$ fails the original equation ($0 \
neq y$). **Contradiction.**

**If $f(1) = 1$:** then $f(q) = q$ for all $q \in \mathbb{Q}$. The same sign arg
ument shows $f$ maps $[0,\infty) \to [0,\infty)$ and is monotone nondecreasing.
An additive monotone function is linear: $f(x) = f(1)\cdot x = x$.

### Verification

$f(x) = x$: $\;f(x^2 + f(y)) = x^2 + y = y + x^2 = y + (f(x))^2.$ ✓

---

**The unique solution is $\boxed{f(x) = x}$.**
