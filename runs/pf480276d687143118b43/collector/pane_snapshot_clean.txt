$$4f(0)^2 = 2f(0) \implies 2f(0)(2f(0)-1)=0$$
so $f(0)=0$ or $f(0)=\tfrac{1}{2}$.

**Case 1: $f(0)=0$.**

Set $z=0, t=0$ in $P$:
$$f(x)\,f(y) = f(xy). \tag{1}$$
So $f$ is multiplicative.

Set $x=0$ in $P$:
$$f(z)\bigl(f(y)+f(t)\bigr) = f(0)+f(yz) = f(yz) = f(y)\,f(z)$$

$$(f(x)+f(z))\bigl(f(y)+\tfrac{1}{2}\bigr) = f(xy)+f(yz).$$
