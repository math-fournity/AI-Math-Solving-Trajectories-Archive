## Proof

Let $H_n = I_n - \frac{1}{n}1_n 1_n^T$, where $1_n \in \mathbb{R}^n$ is the all-
ones column vector. We claim

$$H_n^{+} = H_n = I_n - \frac{1}{n}1_n 1_n^T.$$

We verify this by establishing two key properties of $H_n$ — **symmetry** and **
idempotency** — and then checking that $H_n$ itself satisfies the four Moore–Pen
rose conditions with $H_n^{+} = H_n$.

### Step 1. $H_n$ is symmetric.

Since $I_n^T = I_n$ and $(1_n 1_n^T)^T = 1_n 1_n^T$ (the outer product of a vect
or with itself is symmetric),

$$H_n^T = I_n^T - \frac{1}{n}(1_n 1_n^T)^T = I_n - \frac{1}{n}1_n 1_n^T = H_n.$$

### Step 2. $H_n$ is idempotent: $H_n^2 = H_n$.

Compute $H_n^2$:

$$H_n^2 = \left(I_n - \frac{1}{n}1_n 1_n^T\right)\left(I_n - \frac{1}{n}1_n 1_n^
T\right) = I_n - \frac{2}{n}1_n 1_n^T + \frac{1}{n^2}1_n 1_n^T 1_n 1_n^T.$$

Using $1_n^T 1_n = n$,

$$H_n^2 = I_n - \frac{2}{n}1_n 1_n^T + \frac{1}{n^2}\cdot n \cdot 1_n 1_n^T = I_
n - \frac{2}{n}1_n 1_n^T + \frac{1}{n}1_n 1_n^T = I_n - \frac{1}{n}1_n 1_n^T = H
_n.$$

### Step 3. Verification of the four Moore–Penrose conditions with $H_n^+ := H_n
$.

Recall that $A^+$ is the unique matrix satisfying, for $A = H_n$:

1. $A A^+ A = A$,
2. $A^+ A A^+ = A^+$,
3. $(A A^+)^T = A A^+$,
4. $(A^+ A)^T = A^+ A$.

Setting $A^+ = H_n$ and using $H_n^T = H_n$ and $H_n^2 = H_n$ (hence $H_n^k = H_
n$ for all $k \ge 1$):

**Condition 1.** $A A^+ A = H_n \cdot H_n \cdot H_n = H_n^3 = H_n = A$. ✓

**Condition 2.** $A^+ A A^+ = H_n \cdot H_n \cdot H_n = H_n^3 = H_n = A^+$. ✓

**Condition 3.** $A A^+ = H_n^2 = H_n$, and $(A A^+)^T = H_n^T = H_n = A A^+$. ✓

**Condition 4.** $A^+ A = H_n^2 = H_n$, and $(A^+ A)^T = H_n^T = H_n = A^+ A$. ✓

All four Moore–Penrose conditions hold. By uniqueness of the Moore–Penrose pseud
oinverse, we conclude

$$\boxed{\,H_n^{+} = H_n = I_n - \frac{1}{n}\,1_n 1_n^T\,.}$$

### Remark (geometric interpretation)

$H_n$ is the orthogonal projector onto the subspace $\{x \in \mathbb{R}^n : 1_n^
T x = 0\}$ (the space of zero-mean vectors), along the direction of $1_n$. Every
 orthogonal projector is symmetric and idempotent, and any symmetric idempotent
matrix is its own Moore–Penrose pseudoinverse. This is why $H_n^+ = H_n$: the ps
eudoinverse of an orthogonal projector is the projector itself.
