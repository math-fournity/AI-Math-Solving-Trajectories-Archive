## 证明

**结论：是的，$f(z) = cz$ 对于某个满足 $|c|=1$ 的 $c$ 成立。**

**设定。** 定义 $g(z) = \frac{f(rz)}{r}$。由于 $f$ 在 $\mathbb{D} = \{|z|<1\}$
上解析，$g$ 在 $\{|z| < 1/r\}$ 上解析（因为 $|rz|<1 \iff |z|<1/r$，且 $1/r > 1$
）。我们有 $g(0) = f(0)/r = 0$。

**步骤 1：$g$ 是更大圆盘的自映射。** 对于 $|z| < 1/r$，我们有 $|rz| < 1$，因此 $
|f(rz)| < 1$（因为 $f:\mathbb{D}\to\mathbb{D}$），从而得出
$$|g(z)| = \frac{|f(rz)|}{r} < \frac{1}{r}.$$
因此 $g: \{|z| < 1/r\} \to \{|z| < 1/r\}$ 且 $g(0)=0$。

**步骤 2：将 Schwarz 引理应用于更大的圆盘。** 将 Schwarz 引理应用于圆盘 $\{|z|<1
/r\}$ 上的自映射 $g$，我们得到
$$|g(z)| \le |z| \quad \text{对于所有 } |z| < \tfrac{1}{r},$$
且 $|g'(0)| \le 1$。定义 $h(z) = g(z)/z$（其中 $h(0)=g'(0)$）。则 $h$ 在 $\{|z|<
1/r\}$ 上解析，且
$$|h(z)| \le 1 \quad \text{对于所有 } |z| < \tfrac{1}{r}.$$

**步骤 3：$g$ 的满射性。** 条件 $f(\{|z|<r\}) = \{|z|<r\}$ 结合 $g$ 的定义，意味
着 $g(\mathbb{D}) = \mathbb{D}$（满射）。

**步骤 4：$h$ 必为常数。** 假设相反，即 $|h(z)| < 1$ 对于所有 $z \in \overline{\
mathbb{D}}$ 成立。由紧致性，$M := \max_{\overline{\mathbb{D}}}|h| < 1$。则对于 $
|z| \le 1$：
$$|g(z)| = |z|\cdot|h(z)| \le M < 1,$$
所以 $g(\mathbb{D}) \subseteq \{|w| \le M\} \subsetneq \mathbb{D}$，这与满射性 $
g(\mathbb{D}) = \mathbb{D}$ 矛盾。

因此，$\max_{\overline{\mathbb{D}}}|h| = 1$，这可以在某个 $z_0 \in \overline{\ma
thbb{D}}$ 处取到。由于 $\overline{\mathbb{D}} \subset \{|z|<1/r\}$（因为 $1/r>1$
），点 $z_0$ 位于 $h$ 解析且 $|h|\le 1$ 的区域 $\{|z|<1/r\}$ 的**内部**。根据最
大模原理，$h$ 在 $\{|z|<1/r\}$ 上为常数：$h \equiv c$，且 $|c|=1$。

**步骤 5：结论。** 由 $g(z) = cz$，我们得到 $f(rz) = rcz$，即对于所有 $|z|<1/r$
有 $f(rz) = cz \cdot r$。令 $w = rz$（所以 $|w|<1$），这得到 $f(w) = cw$ 对于所
有 $w \in \mathbb{D}$ 成立，其中 $|c|=1$。$\blacksquare$
