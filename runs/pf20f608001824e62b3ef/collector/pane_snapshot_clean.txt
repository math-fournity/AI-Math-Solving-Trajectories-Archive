## Proof

**Identity.** For any real $x$ with $\sin x \neq 0$,
$$1 + 2\cos 2x = \frac{\sin 3x}{\sin x},$$
since $\sin 3x = 3\sin x - 4\sin^3 x$, giving $\sin 3x/\sin x = 3-4\sin^2 x = 1+
2\cos 2x$.

**Reduction to a sign product.** Since $n>3$ and $(n,3)=1$, every $a_k$ satisfie
s $1 \le a_k \le n-1$ (as $(n,n)=n\neq 1$), so $\sin(a_k\pi/n)\neq 0$. Setting $
x = a_k\pi/n$:
$$P := \prod_{k=1}^{m}\left(1+2\cos\frac{2a_k\pi}{n}\right) = \prod_{\substack{1
\le a\le n-1\\(a,n)=1}} \frac{\sin(3a\pi/n)}{\sin(a\pi/n)}.$$

Because $(3,n)=1$, the map $a \mapsto 3a \bmod n$ is a bijection on the reduced
residue system modulo $n$. Writing $3a = q_a n + r_a$ with $q_a = \lfloor 3a/n\r
floor$ and $r_a \in \{1,\dots,n-1\}$ (note $r_a\neq 0$ since $(3a,n)=1$), we hav
e
$$\sin\frac{3a\pi}{n} = \sin\!\left(q_a\pi + \frac{r_a\pi}{n}\right) = (-1)^{q_a
}\sin\frac{r_a\pi}{n}.$$
As $a$ ranges over reduced residues, so does $r_a$, hence
$$\prod_{(a,n)=1}\sin\frac{r_a\pi}{n} = \prod_{(a,n)=1}\sin\frac{a\pi}{n}.$$
The denominator cancels, leaving
$$P = \prod_{(a,n)=1}(-1)^{\lfloor 3a/n\rfloor} = (-1)^{S}, \qquad S := \sum_{\s
ubstack{1\le a\le n-1\\(a,n)=1}}\left\lfloor\frac{3a}{n}\right\rfloor.$$

**Evaluating $S$ by pairing.** Pair each reduced residue $a$ with $n-a$ (also a
reduced residue, and $a\neq n-a$ since $2a=n$ would force $(a,n)=a/2\neq 1$ for
$n>2$). Since $(3a,n)=1$, the fraction $3a/n$ is never an integer, so $\lfloor -
3a/n\rfloor = -\lfloor 3a/n\rfloor - 1$. Therefore
$$\left\lfloor\frac{3a}{n}\right\rfloor + \left\lfloor\frac{3(n-a)}{n}\right\rfl
oor = \left\lfloor\frac{3a}{n}\right\rfloor + \left\lfloor 3 - \frac{3a}{n}\righ
t\rfloor = \left\lfloor\frac{3a}{n}\right\rfloor + 3 + \left\lfloor-\frac{3a}{n}
\right\rfloor = \left\lfloor\frac{3a}{n}\right\rfloor + 3 - \left\lfloor\frac{3a
}{n}\right\rfloor - 1 = 2.$$
The $\varphi(n)$ reduced residues form $\varphi(n)/2$ such pairs, so
$$S = 2\cdot\frac{\varphi(n)}{2} = \varphi(n).$$

**Conclusion.** For $n>2$, $\varphi(n)$ is even; since $n>3$, certainly $\varphi
(n)$ is even. Hence
$$P = (-1)^{\varphi(n)} = 1.$$

$$\boxed{\displaystyle\prod_{k=1}^{m}\left(1+2\cos\frac{2a_k\pi}{n}\right) = 1.}
$$
