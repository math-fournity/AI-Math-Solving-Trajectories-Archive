## Solution

**Setup.** The eight sensors sit at the vertices of a cube: $(x,y,z)$ with each
coordinate in $\{1,-1\}$. The distance between two vertices that differ in $k$ c
oordinates is $\sqrt{(2)^2 k} = 2\sqrt{k}$. So:
- differ in 1 coordinate → distance $2$,
- differ in 2 coordinates → distance $2\sqrt{2}$,
- differ in 3 coordinates → distance $2\sqrt{3}$.

The short-circuit condition forbids two Active sensors at distance $\le 2$. Sinc
e all distinct vertices are at distance $\ge 2$, the only forbidden case is dist
ance **exactly** $2$, i.e. two Active vertices that differ in exactly one coordi
nate — in other words, two adjacent vertices of the cube graph $Q_3$.

So the problem asks: **count the independent sets of the cube graph $Q_3$.**

**Bipartite structure.** $Q_3$ is bipartite by parity of the coordinate sum:
- Even: $E=\{a,b,c,d\}$ where $a=(1,1,1),\, b=(1,-1,-1),\, c=(-1,1,-1),\, d=(-1,
-1,1)$.
- Odd: $O=\{A,B,C,D\}$ where $A=(-1,1,1),\, B=(1,-1,1),\, C=(1,1,-1),\, D=(-1,-1
,-1)$.

There are no edges within $E$ or within $O$ (vertices in the same part differ in
 2 coordinates). Each even vertex is adjacent to exactly 3 of the 4 odd vertices
:

| even | neighbors in $O$ |
|------|------|
| $a$ | $\{A,B,C\}$ |
| $b$ | $\{B,C,D\}$ |
| $c$ | $\{A,C,D\}$ |
| $d$ | $\{A,B,D\}$ |

**Counting.** An independent set is $S_E\cup S_O$ with $S_E\subseteq E$, $S_O\su
bseteq O$, and $S_O\cap N(S_E)=\varnothing$. For a fixed $S_E$, the number of va
lid $S_O$ is $2^{\,|O\setminus N(S_E)|}$. Sum over all $S_E$:

- $|S_E|=0$: $N=\varnothing$, contributes $2^4 = 16$. (1 subset)
- $|S_E|=1$: each has 3 neighbors, $|O\setminus N|=1$, contributes $4\cdot 2^1 =
 8$.
- $|S_E|=2$: every pair of even vertices covers all 4 odd vertices (verified for
 all $\binom{4}{2}=6$ pairs), so contributes $6\cdot 2^0 = 6$.
- $|S_E|=3$: covers all of $O$, contributes $4\cdot 1 = 4$.
- $|S_E|=4$: contributes $1\cdot 1 = 1$.

**Total** $= 16+8+6+4+1 = 35$.

**Cross-check by size.**
- Size 0: $1$.
- Size 1: $8$.
- Size 2: two-from-same-part ($\binom{4}{2}+\binom{4}{2}=12$) plus one-even-one-
odd non-adjacent ($4\cdot1=4$) $=16$.
- Size 3: three-even ($4$) + three-odd ($4$) $=8$ (any mixed choice is blocked s
ince two vertices from one part cover all neighbors).
- Size 4: all-even ($1$) + all-odd ($1$) $=2$.

Sum: $1+8+16+8+2 = 35$. ✓

The number of valid configurations is $\boxed{35}$.
