### Step 2: Lemma (trapping near odd multiples of $\pi$)

**Lemma.** Suppose at some step $N$: $x_N < 0$ and $|y_N - 3\pi| < \pi/4$. Then
$x_n \to -\infty$ and $y_n \to 3\pi$.

**Proof.** Let $\delta_n = y_n - 3\pi$, so $|\delta_N| < \pi/4$. The recurrence
gives:
$$x_{n+1} = x_n + e^{x_n}\cos(3\pi+\delta_n) = x_n - e^{x_n}\cos\delta_n,$$
$$\delta_{n+1} = \delta_n + e^{x_n}\sin(3\pi+\delta_n) = \delta_n - e^{x_n}\sin\
delta_n.$$

**$x_n$ is strictly decreasing.** Since $|\delta_n| < \pi/4 \Rightarrow \cos\del
ta_n > 1/\sqrt{2} > 0$, we get $x_{n+1} = x_n - e^{x_n}\cos\delta_n < x_n$. By i
nduction $x_n < x_N < 0$ for all $n > N$, so $e^{x_n} < 1$.

**$|\delta_n|$ is strictly decreasing.** If $\delta_n > 0$: $\sin\delta_n > 0$,
so $\delta_{n+1} = \delta_n - e^{x_n}\sin\delta_n < \delta_n$, and $\delta_{n+1}
 > \delta_n(1 - e^{x_n}) > 0$ (since $e^{x_n} < 1$ and $\sin\delta_n < \delta_n$
). If $\delta_n < 0$: similarly $|\delta_{n+1}| < |\delta_n|$. So $|\delta_n|$ d
ecreases and $|\delta_n| < \pi/4$ for all $n \geq N$.

**$x_n \to -\infty$.** If instead $x_n \to L < 0$, then $e^{x_n} \to e^L > 0$, a
nd $x_{n+1} - x_n = -e^{x_n}\cos\delta_n \leq -e^{x_n}/\sqrt{2} \to -e^L/\sqrt{2
} < 0$, forcing $x_n \to -\infty$, contradiction.

**$\delta_n \to 0$.** Since $|\delta_n|$ is decreasing and bounded below, $\delt
a_n \to \delta^*$. If $\delta^* > 0$, then $\sin\delta_n \to \sin\delta^* > 0$,
so for large $n$, $\sin\delta_n > \sin\delta^*/2$. The telescoping sum gives:
$$\delta_N - \delta^* = \sum_{n=N}^{\infty} e^{x_n}\sin\delta_n \geq \frac{\sin\
delta^*}{2}\sum_{n=N}^{\infty} e^{x_n}.$$
But $\sum e^{x_n} \geq \sum (x_n - x_{n+1}) = x_N - \lim x_n = +\infty$ (using $
x_n - x_{n+1} = e^{x_n}\cos\delta_n \leq e^{x_n}$). This forces the right side t
o be $+\infty$, contradicting $\delta_N - \delta^* < \infty$. So $\delta^* = 0$.
 The case $\delta^* < 0$ is analogous. $\blacksquare$

### Step 3: Conclusion

By Step 1, at $N = 9$ the conditions of the Lemma hold: $x_9 < 0$ and $|y_9 - 3\
pi| < \pi/4$. By the Lemma, $y_n \to 3\pi$ (and $x_n \to -\infty$).

The sequence $a_n$ does not converge in $\mathbb{C}$ (since $\Re(a_n) \to -\inft
y$), but the imaginary part $\Im(a_n) = y_n$ **does converge**:

$$\lim_{n \to \infty} \Im(a_n) = 3\pi.$$
