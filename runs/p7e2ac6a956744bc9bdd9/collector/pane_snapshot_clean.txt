I'll derive the Schwarzschild metric by solving Einstein's vacuum equation for a
 static, spherically symmetric spacetime.

## Step 1: Most general static, spherically symmetric metric

Static means the metric is invariant under time reversal $t \to -t$ (no cross te
rms $dt\,dx^i$), and there is a timelike Killing vector. Spherical symmetry mean
s the metric is invariant under $SO(3)$ rotations, so spatial slices have $S^2$
orbits. The most general form is

$$ds^2 = -A(r)\,dt^2 + B(r)\,dr^2 + C(r)\,r^2\,d\Omega^2 + 2D(r)\,dt\,dr,$$

where $d\Omega^2 = d\theta^2 + \sin^2\theta\,d\phi^2$. The staticity condition (
invariance under $t\to -t$) kills the $dt\,dr$ term, so $D(r)=0$.

## Step 2: Coordinate freedom — redefine the radial coordinate

We still have the freedom to redefine the radial coordinate $r \to \tilde r$ via
 $\tilde r^2 = C(r)\,r^2$. Choosing $\tilde r$ as the new radial coordinate (and
 renaming it $r$), the angular part becomes the standard $r^2 d\Omega^2$. The me
tric becomes

$$ds^2 = -e^{2\alpha(r)}\,dt^2 + e^{2\beta(r)}\,dr^2 + r^2\,d\Omega^2,$$

where I've written $A = e^{2\alpha}$, $B = e^{2\beta}$ (positive functions, with
 $e^{2\beta}>0$ so that $r$ is a spacelike coordinate). This is the **standard f
orm** of a static, spherically symmetric metric.

## Step 3: Compute the Christoffel symbols and Ricci tensor

With coordinates $(t,r,\theta,\phi)$ and metric components $g_{tt}=-e^{2\alpha}$
, $g_{rr}=e^{2\beta}$, $g_{\theta\theta}=r^2$, $g_{\phi\phi}=r^2\sin^2\theta$, t
he nonvanishing Christoffel symbols are:

- $\Gamma^t_{tr} = \alpha'$
- $\Gamma^r_{tt} = \alpha' e^{2(\alpha-\beta)}$
- $\Gamma^r_{rr} = \beta'$
- $\Gamma^r_{\theta\theta} = -r\,e^{-2\beta}$
- $\Gamma^r_{\phi\phi} = -r\sin^2\theta\,e^{-2\beta}$
- $\Gamma^\theta_{r\theta} = 1/r$
- $\Gamma^\theta_{\phi\phi} = -\sin\theta\cos\theta$
- $\Gamma^\phi_{r\phi} = 1/r$
- $\Gamma^\phi_{\theta\phi} = \cot\theta$

(primes denote $d/dr$).

## Step 4: Ricci tensor components

Computing $R_{\mu\nu} = \partial_\rho \Gamma^\rho_{\mu\nu} - \partial_\nu \Gamma
^\rho_{\mu\rho} + \Gamma^\rho_{\rho\lambda}\Gamma^\lambda_{\mu\nu} - \Gamma^\rho
_{\nu\lambda}\Gamma^\lambda_{\mu\rho}$:

**$R_{tt}$**:
$$R_{tt} = e^{2(\alpha-\beta)}\left[\alpha'' + (\alpha')^2 - \alpha'\beta' + \fr
ac{2\alpha'}{r}\right].$$

**$R_{rr}$**:
$$R_{rr} = -\alpha'' - (\alpha')^2 + \alpha'\beta' + \frac{2\beta'}{r}.$$

**$R_{\theta\theta}$**:
$$R_{\theta\theta} = e^{-2\beta}\left[r(\beta'-\alpha') - 1\right] + 1.$$

**$R_{\phi\phi}$**:
$$R_{\phi\phi} = \sin^2\theta\, R_{\theta\theta}.$$

## Step 5: Solve $R_{\mu\nu}=0$

**From $R_{tt}=0$ and $R_{rr}=0$**:

Dividing $R_{tt}=0$ by $e^{2(\alpha-\beta)}$:
$$\alpha'' + (\alpha')^2 - \alpha'\beta' + \frac{2\alpha'}{r} = 0. \quad (1)$$

From $R_{rr}=0$:
$$-\alpha'' - (\alpha')^2 + \alpha'\beta' + \frac{2\beta'}{r} = 0. \quad (2)$$

Adding (1) and (2):
$$\frac{2(\alpha'+\beta')}{r} = 0 \implies \alpha' + \beta' = 0 \implies \alpha
+ \beta = \text{const}.$$

Asymptotic flatness (the metric must approach Minkowski as $r\to\infty$, i.e. $\
alpha,\beta\to 0$) sets the constant to zero:
$$\boxed{\beta = -\alpha}.$$

**From $R_{\theta\theta}=0$**: Substituting $\beta=-\alpha$ (so $\beta'=-\alpha'
$, $e^{-2\beta}=e^{2\alpha}$):
$$e^{2\alpha}\left[r(-\alpha'-\alpha')-1\right]+1 = 0 \implies e^{2\alpha}(2r\al
pha'+1)=1.$$

Let $m(r) = r(1-e^{-2\alpha})$, i.e. $e^{-2\alpha} = 1 - m/r$. Then:
$$e^{2\alpha}(2r\alpha'+1) = 1.$$

Note $e^{-2\alpha}=1-m/r$, so $\frac{d}{dr}e^{-2\alpha} = -m'/r + m/r^2 = -2\alp
ha' e^{-2\alpha}$. The equation $e^{2\alpha}(2r\alpha'+1)=1$ becomes $2r\alpha'
e^{2\alpha} = 1-e^{2\alpha}\cdot\frac{1}{e^{2\alpha}}\cdot... $

Let me verify directly: $e^{2\alpha}(2r\alpha'+1)=1$ means $2r\alpha' = e^{-2\al
pha}-1$. With $e^{-2\alpha}=1-m/r$:
$$2r\alpha' = -m/r.$$

Also $\frac{d}{dr}(e^{-2\alpha}) = -2\alpha' e^{-2\alpha} = -\frac{m'}{r}+\frac{
m}{r^2}$, giving $2\alpha' = \frac{m'/r - m/r^2}{e^{-2\alpha}} = \frac{m'r-m}{r^
2(1-m/r)}$.

So $2r\alpha' = \frac{m'r-m}{r(1-m/r)}$. Setting this equal to $-m/r$:
$$\frac{m'r-m}{r(1-m/r)} = -\frac{m}{r} \implies m'r - m = -m(1-m/r) = -m + m^2/
r$$
$$\implies m'r = m^2/r \implies m' = m/r \cdot... $$

Hmm, let me redo this more cleanly. The equation is:
$$e^{2\alpha}(2r\alpha'+1) = 1.$$

Equivalently $2r\alpha' + 1 = e^{-2\alpha}$, i.e. $2r\alpha' = e^{-2\alpha}-1$.

Now compute $\frac{d}{dr}(r e^{-2\alpha}) = e^{-2\alpha} + r(-2\alpha')e^{-2\alp
ha} = e^{-2\alpha} - 2r\alpha' e^{-2\alpha}$.

Using $2r\alpha' = e^{-2\alpha}-1$:
$$\frac{d}{dr}(r e^{-2\alpha}) = e^{-2\alpha} - (e^{-2\alpha}-1)e^{-2\alpha} = e
^{-2\alpha} - e^{-4\alpha} + e^{-2\alpha}.$$

That's not clean. Let me try a different substitution. Set $f = e^{2\alpha}$, so
 $\alpha' = f'/(2f)$. The equation $e^{2\alpha}(2r\alpha'+1)=1$ becomes:
$$f\left(\frac{r f'}{f} + 1\right) = 1 \implies r f' + f = 1 \implies \frac{d}{d
r}(rf) = 1.$$

Integrating: $rf = r + c$, so $f = 1 + c/r$ where $c$ is a constant.

Therefore:
$$e^{2\alpha} = 1 + \frac{c}{r}, \qquad e^{2\beta} = e^{-2\alpha} = \left(1+\fra
c{c}{r}\right)^{-1}.$$

## Step 6: Identify the constant

The constant $c$ is fixed by matching to Newtonian gravity in the weak-field lim
it. For a point mass $M$, the Newtonian potential is $\Phi = -GM/r$, and the wea
k-field metric has $g_{tt} \approx -(1+2\Phi) = -(1-2GM/r)$. Comparing with $-e^
{2\alpha} = -(1+c/r)$ gives:

$$c = -2GM.$$

(Using units where $c_{\text{light}}=1$; restoring the speed of light, $c = -2GM
/c^2$.)

## Step 7: Final result

Defining the **Schwarzschild radius** $r_s = 2GM$ (with $c=1$), the metric is:

$$\boxed{ds^2 = -\left(1-\frac{2GM}{r}\right)dt^2 + \left(1-\frac{2GM}{r}\right)
^{-1}dr^2 + r^2\left(d\theta^2 + \sin^2\theta\,d\phi^2\right).}$$

## Verification

- **Vacuum**: All four independent Ricci components $R_{tt}$, $R_{rr}$, $R_{\the
ta\theta}$, $R_{\phi\phi}$ vanish by construction (we used $R_{tt}=R_{rr}=R_{\th
eta\theta}=0$, and $R_{\phi\phi}=\sin^2\theta\,R_{\theta\theta}=0$ follows autom
atically). Since $R_{\mu\nu}=0$ in vacuum and $R=0$ follows, this also satisfies
 $G_{\mu\nu}=0$.
- **Static**: No $dt\,dr$ cross term; invariant under $t\to -t$. ✓
- **Spherically symmetric**: Angular part is $r^2 d\Omega^2$. ✓
- **Asymptotically flat**: As $r\to\infty$, $g_{tt}\to -1$, $g_{rr}\to 1$, recov

- **Weak-field limit**: Matches Newtonian gravity with $g_{tt}\approx -(1-2GM/r)
$. ✓
- **Birkhoff's theorem**: The solution is unique (up to coordinate transformatio
ns) — any spherically symmetric vacuum solution is static and equals Schwarzschi

This is the **Schwarzschild metric**, derived entirely from $R_{\mu\nu}=0$ with
the assumptions of staticity, spherical symmetry, and asymptotic flatness.
