## Proof

The proof has two steps.

### Step 1: Every measurable set of positive measure contains a non-measurable s
ubset.

Let $E$ be measurable with $m(E) > 0$. Define the equivalence relation on $E$:
$$x \sim y \iff x - y \in \mathbb{Q}.$$
By the Axiom of Choice, select exactly one representative from each equivalence
class, and let $W \subseteq E$ be the set of chosen representatives.

**Properties of $W$:**

(a) The translates $\{W + q : q \in \mathbb{Q}\}$ are pairwise disjoint. Indeed,
 if $(W+q_1) \cap (W+q_2) \neq \emptyset$, then $w_1 + q_1 = w_2 + q_2$ for some

_2$. Since $W$ contains one representative per class, $w_1 = w_2$, hence $q_1 =
q_2$.

(b) $E \subseteq \bigcup_{q \in \mathbb{Q}} (W + q)$. For any $x \in E$, its equ
ivalence class has a representative $w \in W$, so $x - w \in \mathbb{Q}$, i.e.,
$x \in W + q$ for some $q \in \mathbb{Q}$.

**$W$ is non-measurable.** Suppose for contradiction that $W$ is measurable.

- **If $m(W) = 0$:** Each translate $W + q$ has measure $0$. Then $\bigcup_{q \i
n \mathbb{Q}}(W+q)$ is a countable union of null sets, hence null. But $E \subse
teq \bigcup_{q \in \mathbb{Q}}(W+q)$ and $m(E) > 0$, contradiction.

- **If $m(W) > 0$:** By the **Steinhaus theorem**, $W - W$ contains an open neig
hborhood of $0$, hence contains some nonzero rational $r \in \mathbb{Q} \setminu

tminus \{0\}$, meaning $w_1 \sim w_2$ with $w_1 \neq w_2$. This contradicts $W$
having exactly one representative per equivalence class.

Both cases yield contradictions, so $W$ is **non-measurable**.

### Step 2: Decompose $E$ into two non-measurable sets.

Set $A = W$ and $B = E \setminus W$, so $E = A \cup B$ (disjoint union).

- $A = W$ is non-measurable (Step 1).
- $B = E \setminus W$ is non-measurable: if $B$ were measurable, then $W = E \se

Note $B \neq \emptyset$ (since $W \neq E$, as $E$ is measurable but $W$ is not)
and $B$ is non-measurable, hence automatically nonempty and non-null in the rele

### Conclusion

$$E = W \cup (E \setminus W)$$
is a union of two non-measurable sets, which is in particular a **countable unio
n of non-measurable sets**.

Therefore, **every measurable set of positive Lebesgue measure in $\mathbb{R}$ c
