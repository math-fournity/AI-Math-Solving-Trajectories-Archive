Looking at this problem, I need to determine whether $f^{(r)} \in L^2[0,1]$ impl
ies $f^{(r-1)} \in L^2[0,1]$.

**Answer: No**, it does not follow. I construct a counterexample for $r=1$.

## Counterexample Construction

Let $C \subset [0,1]$ be the Cantor set (Lebesgue measure 0). Its complement $[0
,1]\setminus C$ is a union of countably many disjoint open intervals. At stage $
k$ of the Cantor construction ($k=1,2,3,\dots$), there are $2^{k-1}$ open interv
als, each of length $3^{-k}$.

Define $f:[0,1]\to[0,\infty)$ by:
- On each open interval of length $3^{-k}$ (at stage $k$), set $f \equiv (3/2)^{
k/2}$.
- On the Cantor set $C$, set $f \equiv 0$.

## Verification

**$f$ is well-defined:** $f$ is non-negative, finite-valued, and measurable (it
is a step function, constant on each component of an open set). ✓

**$f$ is differentiable a.e. with $f'=0$ a.e.:** At every point $x$ in the inter
ior of some open interval in $[0,1]\setminus C$, the function $f$ is constant in
 a neighborhood of $x$, so $f'(x)=0$. The union of all such interiors is $[0,1]\
setminus C$, which has measure $1$. Since $C$ has measure $0$, $f$ is differenti
able a.e. with $f'=0$ a.e. ✓

**The $r$-th derivative is in $L^2$ (with $r=1$):**
$$\int_0^1 |f'(x)|^2\,dx = \int_0^1 0\,dx = 0 < \infty. \quad\checkmark$$

**The $(r-1)$-th derivative (i.e., $f$ itself) is NOT in $L^2$:**
$$\int_0^1 |f(x)|^2\,dx = \sum_{k=1}^{\infty} 2^{k-1}\cdot\left(\frac{3}{2}\righ
t)^{k}\cdot 3^{-k} = \sum_{k=1}^{\infty} 2^{k-1}\cdot\frac{3^k}{2^k}\cdot\frac{1
}{3^k} = \sum_{k=1}^{\infty}\frac{2^{k-1}}{2^k} = \sum_{k=1}^{\infty}\frac{1}{2}
 = \infty.$$

The key computation: there are $2^{k-1}$ intervals at stage $k$, each of length
$3^{-k}$, and $f$ takes value $(3/2)^{k/2}$ on each, so the contribution to $\in
t|f|^2$ from stage $k$ is $2^{k-1}\cdot(3/2)^k\cdot 3^{-k} = 2^{k-1}/2^k = 1/2$.
 Summing over all $k$ gives $\infty$. ✓

## Conclusion

We have exhibited a function $f:[0,1]\to[0,\infty)$ such that $\int_0^1|f'(x)|^2
\,dx < \infty$ (indeed $=0$) but $\int_0^1|f(x)|^2\,dx = \infty$. This provides
a counterexample with $r=1$.

**The key mechanism:** On a bounded interval, having derivative in $L^2$ control
s only the *absolutely continuous part* of a function (via $\int f'$). A functio
n can carry an arbitrary "singular part"—constant on each component of a full-me
asure open set, with values growing fast enough to escape $L^2$, while the deriv
ative remains $0$ a.e. The Cantor set complement provides exactly such a full-me
asure open set with countably many components on which to place growing constant
s.
