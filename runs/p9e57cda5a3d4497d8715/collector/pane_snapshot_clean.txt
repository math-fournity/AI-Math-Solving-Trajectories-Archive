**Yes.** Every total order (linear order) can be order-embedded into the surreal
 numbers **No**. The essential ingredients are that **No** is a *proper class* (
so there is no cardinality ceiling) and that it is *η_On-saturated* (every set-s
ized cut is realized). Here is the proof.

---

### Key property: **No** is an η_On-set

Recall the Conway cut construction of the surreals. Each surreal number is a for
mal cut $x = \{L_x \mid R_x\}$ where $L_x, R_x$ are *sets* of previously born su
rreals with $L_x < R_x$ (every element of $L_x$ is less than every element of $R
_x$). The surreals are built up by transfinite recursion over the ordinals: $\ma
thbf{No} = \bigcup_{\alpha \in \mathrm{On}} \mathbf{No}_\alpha$, where $\mathbf{
No}_\alpha$ is the set of surreals born before day $\alpha$.

**Lemma (cut-realization / η_On property).** For any two *sets* $L, R \subseteq
\mathbf{No}$ with $L < R$, there exists $x \in \mathbf{No}$ with $L < x < R$.

*Proof of lemma.* Since $L \cup R$ is a set, the collection of birthdays of its
elements is a set of ordinals, which has a supremum $\beta \in \mathrm{On}$. Thu
s $L \cup R \subseteq \mathbf{No}_\beta$. The pair $(L, R)$ is then an admissibl
e cut over the previously born surreals, and the construction produces a surreal
 $x = \{L \mid R\}$ born on day $\beta$ (or $\beta+1$, depending on convention)
satisfying, by the definition of the order on surreals,
$$\forall\, \ell \in L:\ \ell < x, \qquad \forall\, r \in R:\ x < r.$$
Hence $L < x < R$. ∎

This is precisely the statement that **No** is an *η_On-set*: it fills every cut
 whose left and right sides are sets (i.e., bounded in cardinality below every $
\aleph_\alpha$, for *every* $\alpha$).

### Embedding theorem

**Theorem.** Every linear order $(P, \le)$ admits an order-embedding $f : P \hoo
krightarrow \mathbf{No}$.

*Proof.* Let $\kappa = |P|$ and well-order the underlying set of $P$ as $\{p_\al
pha : \alpha < \kappa\}$ (using the axiom of choice). We define $f(p_\alpha)$ by
 transfinite recursion on $\alpha < \kappa$.

Assume $f(p_\beta)$ has been defined for all $\beta < \alpha$, and that $f$ is o
rder-preserving on $\{p_\beta : \beta < \alpha\}$. Define
$$L_\alpha = \{\, f(p_\beta) : \beta < \alpha,\ p_\beta < p_\alpha \,\}, \qquad
R_\alpha = \{\, f(p_\beta) : \beta < \alpha,\ p_\alpha < p_\beta \,\}.$$

Because $P$ is a *linear* order, every previously placed $p_\beta$ ($\beta < \al
pha$) falls into exactly one of $L_\alpha$ or $R_\alpha$ (or equals $p_\alpha$,
which doesn't occur since $\beta < \alpha$ and the $p_\beta$ are distinct). By t
he inductive hypothesis that $f$ is order-preserving so far, if $p_\beta < p_\al
pha < p_\gamma$ (with $\beta, \gamma < \alpha$) then $f(p_\beta) < f(p_\gamma)$;
 therefore
$$\forall\, \ell \in L_\alpha,\ \forall\, r \in R_\alpha : \ell < r,$$
i.e. $L_\alpha < R_\alpha$.

Both $L_\alpha$ and $R_\alpha$ are subsets of the set $\{f(p_\beta) : \beta < \a
lpha\}$, hence are *sets*. By the η_On lemma, there exists $x \in \mathbf{No}$ w
ith
$$L_\alpha < x < R_\alpha.$$
Set $f(p_\alpha) = x$.

We verify order-preservation with all earlier elements: for any $\beta < \alpha$
,
- if $p_\beta < p_\alpha$, then $f(p_\beta) \in L_\alpha$, so $f(p_\beta) < x =
f(p_\alpha)$;
- if $p_\alpha < p_\beta$, then $f(p_\beta) \in R_\alpha$, so $f(p_\alpha) = x <
 f(p_\beta)$.

Thus $f$ remains order-preserving after stage $\alpha$. By transfinite induction
, $f$ is defined on all of $P$ and is an order-embedding. ∎

### Why proper-class-ness is essential

A set-sized linear order, no matter how saturated, cannot be universal for *all*
 linear orders: it cannot embed any linear order of strictly larger cardinality.
 The surreals escape this obstruction precisely because they form a proper class
, so the transfinite recursion above never runs out of room, and the η_On proper
ty guarantees a fresh element fills every set-sized cut encountered along the wa
y. Together, these two facts make **No** a *universal domain for linear orders*:
 every total order embeds into it.
