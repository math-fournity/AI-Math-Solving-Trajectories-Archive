## Probability Generating Function for the Number of Cycles in a Random Permutat
ion

**Setup.** Let $\sigma$ be a uniformly random permutation of $\{1,\dots,n\}$, an
d let $C_n(\sigma)$ denote the number of cycles in $\sigma$. The number of permu
tations of size $n$ with exactly $k$ cycles is the unsigned Stirling number of t
he first kind, $c(n,k) = \left[{n\atop k}\right]$. The PGF is

$$G_n(x) \;=\; \sum_{k=0}^{n} \Pr[C_n = k]\, x^k \;=\; \frac{1}{n!}\sum_{k=0}^{n
} c(n,k)\, x^k.$$

It is convenient to work with the unnormalized version $F_n(x) := \sum_k c(n,k)\
,x^k = n!\, G_n(x)$.

**Claim.**

$$\boxed{\,G_n(x) \;=\; \frac{1}{n!}\,x(x+1)(x+2)\cdots(x+n-1) \;=\; \frac{x^{\o
verline{n}}}{n!}\,}$$

where $x^{\overline{n}} = x(x+1)\cdots(x+n-1)$ is the rising factorial.

**Proof by induction.**

The unsigned Stirling numbers of the first kind satisfy the recurrence

$$c(n,k) \;=\; c(n-1,\,k-1) \;+\; (n-1)\,c(n-1,\,k), \qquad n\ge 2,$$

with the convention $c(0,0)=1$. This recurrence has a direct combinatorial meani
ng: to form a permutation of $n$ elements with $k$ cycles, either insert element
 $n$ as a fixed point into a permutation of $\{1,\dots,n-1\}$ with $k-1$ cycles
(giving the $c(n-1,k-1)$ term), or insert element $n$ into one of the existing c
ycles of a permutation of $\{1,\dots,n-1\}$ with $k$ cycles — there are $n-1$ po
ssible insertion positions (after any of the $n-1$ existing elements), giving th
e $(n-1)\,c(n-1,k)$ term.

Multiplying the recurrence by $x^k$ and summing over $k$:

$$F_n(x) = \sum_k c(n,k)\,x^k = \sum_k c(n-1,k-1)\,x^k + (n-1)\sum_k c(n-1,k)\,x
^k.$$

The first sum is $x\,F_{n-1}(x)$ (shifting the index), and the second is $(n-1)\
,F_{n-1}(x)$. Hence

$$F_n(x) = \bigl(x + (n-1)\bigr)\,F_{n-1}(x).$$

**Base case.** $F_1(x) = c(1,1)\,x = x$, which equals $x^{\overline{1}} = x$. ✓

**Inductive step.** Assuming $F_{n-1}(x) = x^{\overline{n-1}} = x(x+1)\cdots(x+n
-2)$, the recurrence gives

$$F_n(x) = (x+n-1)\,x(x+1)\cdots(x+n-2) = x(x+1)(x+2)\cdots(x+n-1) = x^{\overlin
e{n}}.$$

This completes the induction, so $F_n(x) = x^{\overline{n}}$ for all $n\ge 1$.

**Normalization.** Since $\sum_k c(n,k) = n!$ (total number of permutations), we
 have $F_n(1) = n!$, consistent with $1^{\overline{n}} = 1\cdot 2\cdots n = n!$.
 Therefore

$$G_n(x) = \frac{F_n(x)}{n!} = \frac{x(x+1)(x+2)\cdots(x+n-1)}{n!}.$$

**Sanity checks.**

- $G_n(1) = \frac{n!}{n!} = 1$ — a valid PGF. ✓
- The mean is $G_n'(1) = \frac{1}{n!}\sum_{j=0}^{n-1}\frac{n!}{1+j}\cdot\prod_{i
\ne j}(1+i)\big|_{x=1}$; more cleanly, $\frac{d}{dx}\ln G_n(x)\big|_{x=1} = \sum
_{j=0}^{n-1}\frac{1}{1+j} = H_n$, the $n$-th harmonic number — the well-known ex
pected number of cycles. ✓
- For $n=2$: $G_2(x) = \frac{x(x+1)}{2} = \frac{1}{2}x + \frac{1}{2}x^2$, matchi
ng the two permutations (one with 1 cycle, one with 2 cycles), each with probabi
lity $1/2$. ✓
- For $n=3$: $G_3(x)=\frac{x(x+1)(x+2)}{6}=\frac{1}{6}x+\frac{3}{6}x^2+\frac{2}{
6}x^3$, matching $c(3,1)=2,\,c(3,2)=3,\,c(3,3)=1$. ✓

**Interpretation.** The factorization $G_n(x) = \prod_{j=1}^{n}\frac{x+j-1}{j}$
reveals that $C_n$ is distributed as a sum of $n$ independent Bernoulli random v
ariables, where the $j$-th (for $j=1,\dots,n$) has success probability $\frac{1}
{j}$. This is exactly the Chinese Restaurant / Feller coupling: when inserting e
lement $j$ into the permutation, it starts a new cycle with probability $\frac{1
}{j}$ and joins an existing cycle with probability $\frac{j-1}{j}$, independentl
y across $j$. The PGF of a sum of independent variables is the product of their
PGFs, recovering $\prod_{j=1}^{n}\frac{(j-1)+x}{j} = \frac{x^{\overline{n}}}{n!}
$.
