## Proof

**Yes**, $f^{-1}(E)$ has Lebesgue measure $0$ in $\mathbb{R}^n$.

We establish the result through four ingredients.

---

**Ingredient 1 (Lipschitz maps preserve null sets).** If $g:\mathbb{R}^k\to\math
bb{R}^k$ is locally Lipschitz, then $g$ maps sets of Lebesgue measure $0$ to set
s of Lebesgue measure $0$.

*Proof.* On any compact ball $B$, $g$ is Lipschitz with some constant $L_B$. If
$A\subset B$ has measure $0$ and $\{Q_j\}$ is a cover of $A$ by cubes with $\sum
_j \operatorname{vol}(Q_j)<\varepsilon$, then $g(A)\subset\bigcup_j g(Q_j)$, and
 each $g(Q_j)$ lies in a ball of radius $L_B\cdot\operatorname{diam}(Q_j)/2$, so
 $\operatorname{vol}(g(Q_j))\leq C\,L_B^k\operatorname{vol}(Q_j)$. Hence $\lambd
a_k(g(A))\leq C\,L_B^k\,\varepsilon$. Letting $\varepsilon\to 0$ gives $\lambda_
k(g(A))=0$. Covering $\mathbb{R}^k$ by countably many balls handles the global c
ase. $\square$

In particular, every $C^1$ diffeomorphism (being locally Lipschitz with locally
Lipschitz inverse) preserves null sets in both directions.

---

**Ingredient 2 (Preimage of a null set under a projection is null).** Let $\pi:\
mathbb{R}^n\to\mathbb{R}^m$ be $\pi(x_1,\dots,x_n)=(x_1,\dots,x_m)$ with $n>m$.
If $E\subset\mathbb{R}^m$ has measure $0$, then $\pi^{-1}(E)=E\times\mathbb{R}^{
n-m}$ has measure $0$ in $\mathbb{R}^n$.

*Proof.* By Fubini–Tonelli,
$$\lambda_n(E\times\mathbb{R}^{n-m})=\int_{\mathbb{R}^{n-m}}\lambda_m(E)\,dt=\in
t_{\mathbb{R}^{n-m}}0\,dt=0.\qquad\square$$

---

**Ingredient 3 (Submersion / Constant Rank Theorem).** Since $J(f)(x)$ has rank
$m$ for every $x$ and $J(f)$ is continuous, $f$ is a $C^1$ **submersion**. By th
e constant rank theorem, for every $x_0\in\mathbb{R}^n$ there exist

- an open neighborhood $U\ni x_0$ in $\mathbb{R}^n$ and an open set $W\supset f(
U)$ in $\mathbb{R}^m$,
- $C^1$ diffeomorphisms $\varphi:U\to\widetilde U\subset\mathbb{R}^n$ and $\psi:
W\to\widetilde W\subset\mathbb{R}^m$,

such that
$$(\psi\circ f\circ\varphi^{-1})(y_1,\dots,y_n)=(y_1,\dots,y_m)=\pi(y),\qquad y\
in\widetilde U.$$

---

**Ingredient 4 (Local nullity).** With the notation above,
$$f^{-1}(E)\cap U=\varphi^{-1}\!\Big(\pi^{-1}\big(\psi(E\cap W)\big)\cap\widetil
de U\Big).$$

We track nullity right to left:

1. $E\cap W$ has measure $0$ in $\mathbb{R}^m$ (subset of a null set).
2. $\psi$ is a $C^1$ diffeomorphism, so by Ingredient 1, $\psi(E\cap W)$ has mea
sure $0$ in $\mathbb{R}^m$.
3. By Ingredient 2, $\pi^{-1}(\psi(E\cap W))\cap\widetilde U$ has measure $0$ in
 $\mathbb{R}^n$ (intersecting the null set $E'\times\mathbb{R}^{n-m}$ with the o
pen set $\widetilde U$ keeps it null).
4. $\varphi^{-1}$ is a $C^1$ diffeomorphism, so by Ingredient 1 again, $f^{-1}(E
)\cap U$ has measure $0$ in $\mathbb{R}^n$.

---

**Global conclusion.** Since $\mathbb{R}^n$ is second countable, the open cover
$\{U_{x_0}\}_{x_0\in\mathbb{R}^n}$ admits a countable subcover $\{U_k\}_{k=1}^{\
infty}$. Then
$$f^{-1}(E)=\bigcup_{k=1}^{\infty}\bigl(f^{-1}(E)\cap U_k\bigr).$$
Each summand has measure $0$ by Ingredient 4, and a countable union of null sets
 is null. Therefore
$$\boxed{\lambda_n\!\bigl(f^{-1}(E)\bigr)=0.}$$
