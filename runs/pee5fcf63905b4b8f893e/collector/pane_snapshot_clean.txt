Looking at this problem, I need to count polynomials P of degree 2015 with coeff
icients in {0,...,2010} (i.e., in **F₂₀₁₁** since 2011 is prime) such that P map
s every integer into {20, 15, 1234} mod 2011, with all three values achieved.

## Setting up the parametrization

Since P(m) mod 2011 depends only on m mod 2011, the condition is about the funct
ion **P: F₂₀₁₁ → F₂₀₁₁**. The image must be exactly {20, 15, 1234}.

Divide P by (x²⁰¹¹ − x):
$$P(x) = Q(x)(x^{2011}-x) + R(x), \quad \deg R \le 2010.$$

As functions on F₂₀₁₁, P and R agree (since x²⁰¹¹ − x vanishes on F₂₀₁₁). The co
ndition depends only on R.

For **deg P = 2015**: since deg(x²⁰¹¹−x) = 2011 and deg R ≤ 2010 < 2011, we need
 deg Q = 4 with **nonzero leading coefficient**. The map (Q, R) ↦ P is a bijecti
on between:
- {Q : deg Q = 4, leading coeff ≠ 0, coeffs in F₂₀₁₁} × {R : deg R ≤ 2010, coeff
s in F₂₀₁₁}, and
- {P : deg P = 2015, coeffs in F₂₀₁₁}.

All coefficients stay in F₂₀₁₁ = {0,...,2010}, so the coefficient constraint is
automatic.

## Counting valid R

Every function F₂₀₁₁ → F₂₀₁₁ is represented by a **unique** polynomial of degree
 ≤ 2010 (standard fact: p^p functions = p^p polynomials, injective hence bijecti
ve). So valid R = number of **surjective** functions from a 2011-element set ont
o {20, 15, 1234}:

$$\text{Surj} = 3^{2011} - \binom{3}{1}2^{2011} + \binom{3}{2}1^{2011} = 3^{2011
} - 3\cdot 2^{2011} + 3.$$

## Counting valid Q

Degree exactly 4, leading coefficient nonzero: $2010 \cdot 2011^4$ choices.

## The formula

$$N = (3^{2011} - 3\cdot 2^{2011} + 3)\cdot 2010 \cdot 2011^4.$$

## Computing mod 1000

**2011⁴ mod 1000:** 2011 ≡ 11, so 11⁴ = 14641 ≡ **641**.

**2010 · 2011⁴ mod 1000:** 10 · 641 = 6410 ≡ **410**.

**2²⁰¹¹ mod 1000** (via CRT mod 8 and mod 125):
- mod 8: 2²⁰¹¹ ≡ 0 (since 2011 ≥ 3).
- mod 125: φ(125)=100, 2011 ≡ 11 mod 100, so 2²⁰¹¹ ≡ 2¹¹ = 2048 ≡ 48 mod 125.
- CRT: 48 ≡ 0 mod 8 ✓, so **2²⁰¹¹ ≡ 48 mod 1000**.

**3²⁰¹¹ mod 1000:**
- mod 8: 3² ≡ 1, so 3²⁰¹¹ ≡ 3 mod 8.
- mod 125: 3²⁰¹¹ ≡ 3¹¹ mod 125. Computing: 3¹¹ = 177147 ≡ 22 mod 125.
- CRT: x ≡ 3 (mod 8), x ≡ 22 (mod 125). x = 22 + 125t; 22 ≡ 6 mod 8, 125 ≡ 5 mod
 8, so 6+5t ≡ 3 → 5t ≡ 5 → t ≡ 1 mod 8. x = 147. Check: 147 mod 8 = 3 ✓, 147 mod
 125 = 22 ✓. So **3²⁰¹¹ ≡ 147 mod 1000**.

**Surjection count mod 1000:**
$$147 - 3\cdot 48 + 3 = 147 - 144 + 3 = 6.$$

**Final:**
$$N \equiv 6 \cdot 410 = 2460 \equiv \boxed{460} \pmod{1000}.$$
