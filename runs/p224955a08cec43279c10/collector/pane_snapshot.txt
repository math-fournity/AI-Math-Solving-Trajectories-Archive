Looking at this problem, I need to find the smallest N where 31 students (each k
nowing 3000 of N questions, every question known by ≥29 students) cannot find a
circular starting position so that all 31 consecutive questions land on question
s the respective students know.

## Proof

**Setup.** Number the questions $0, 1, \dots, N-1$ around the circle. Number stu
dents $0, 1, \dots, 30$. If the students point to question $s$, student $i$ rece
ives question $(s+i) \bmod N$. Let $S_i$ be the set of questions student $i$ kno
ws, with $|S_i| = 3000$.

**Lower bound: $N \geq 3100$.**

Define $B_i = \{s : (s+i) \bmod N \notin S_i\}$, the set of starting positions t
hat are *bad* for student $i$. Since student $i$ knows exactly 3000 questions, $
|B_i| = N - 3000$.

The students fail means every starting position is bad for at least one student:
$$\bigcup_{i=0}^{30} B_i = \{0, 1, \dots, N-1\}.$$

By the union bound:
$$N = \left|\bigcup_{i=0}^{30} B_i\right| \leq \sum_{i=0}^{30} |B_i| = 31(N-3000
).$$

This gives $N \leq 31N - 93000$, hence $30N \geq 93000$, so $N \geq 3100$.

**Construction: $N = 3100$ works.**

Set $N = 3100$. For student $i$ ($0 \leq i \leq 30$), define the set of question
s they do **not** know as:
$$U_i = \{(101i + j) \bmod 3100 : j = 0, 1, \dots, 99\}.$$

So $|U_i| = 100$ and $|S_i| = 3000$. ✓

*Each question is known by at least 29 students.* The sets $U_i$ are intervals o
f length 100 starting at $101i \bmod 3100$. Since $\gcd(101, 3100) = 1$ (as $310
0 = 2^2 \cdot 5^2 \cdot 31$ and 101 is prime), the 31 starting points $0, 101, 2
02, \dots, 3030$ are distinct. Consecutive intervals $[101i, 101i+99]$ and $[101
(i+1), 101(i+1)+99]$ have a gap of 1 (the point $101i+100$), so they do not over
lap. The only wrap-around overlap is between $U_{30} = [3030, 3099] \cup [0, 29]
$ and $U_0 = [0, 99]$, which overlap on $\{0, \dots, 29\}$. Thus every question
belongs to at most 2 of the $U_i$, meaning every question is unknown by at most
2 students, i.e., known by at least 29. ✓

*Every starting position is bad for some student.* Define $B_i = \{s : (s + i) \
bmod 3100 \in U_i\}$. Then $s \in B_i \iff (s+i) \bmod 3100 \in U_i \iff s \equi
v 101i + j - i = 100i + j \pmod{3100}$ for some $j \in \{0,\dots,99\}$. So:
$$B_i = \{100i, 100i+1, \dots, 100i+99\} \bmod 3100.$$

These 31 sets are $[0,99], [100,199], [200,299], \dots, [3000,3099]$, which part
ition $\{0, 1, \dots, 3099\}$. Therefore $\bigcup_{i=0}^{30} B_i = \{0, \dots, 3
099\}$, so every starting position is bad for exactly one student. ✓

All conditions are satisfied: $N = 3100 \geq 3000$, each student knows exactly 3
000 questions, every question is known by at least 29 students, and no starting
position works for all students.

**The smallest $N$ is $\boxed{3100}$.**
