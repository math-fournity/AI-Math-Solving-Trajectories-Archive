## Proof

**Claim:** The sequence $\{\ln n\}_{n=1}^{\infty}$ (fractional parts) is dense i
n $(0,1)$.

**Key observations.** (1) $\ln n \to \infty$, so the sequence sweeps through eve
ry unit interval $[k, k+1)$ for all sufficiently large integers $k$. (2) The ste
p size $\ln(n+1) - \ln n = \ln(1 + 1/n) \to 0$.

**Construction.** For each integer $k \ge 1$, consider the integers
$$n \in I_k := \bigl[\lceil e^k \rceil,\; \lfloor e^{k+1}\rfloor\bigr].$$
For every such $n$, we have $e^k \le n \le e^{k+1}$, hence $k \le \ln n \le k+1$
, so
$$\{\ln n\} = \ln n - k \in [0, 1].$$
Thus the fractional parts $\{\ln n\}$ for $n \in I_k$ form an **increasing** seq
uence contained in $[0,1]$.

**Endpoints tend to $0$ and $1$.** The smallest element is $n_k^- = \lceil e^k\r
ceil \le e^k + 1$, so
$$\{\ln n_k^-\} = \ln n_k^- - k \le \ln\!\Bigl(1 + \tfrac{1}{e^k}\Bigr) \le \tfr
ac{1}{e^k} \xrightarrow{k\to\infty} 0.$$
The largest element is $n_k^+ = \lfloor e^{k+1}\rfloor \ge e^{k+1} - 1$. Since $
e$ is transcendental, $e^{k+1}\notin\mathbb{Z}$, so $n_k^+ < e^{k+1}$ and $\ln n
_k^+ < k+1$, giving $\{\ln n_k^+\}\in(0,1)$. Moreover,
$$\{\ln n_k^+\} = \ln n_k^+ - k \ge \ln\!\Bigl(e^{k+1}\!\Bigl(1 - \tfrac{1}{e^{k
+1}}\Bigr)\Bigr) - k = 1 + \ln\!\Bigl(1 - \tfrac{1}{e^{k+1}}\Bigr) \ge 1 - \tfra
c{2}{e^{k+1}} \xrightarrow{k\to\infty} 1.$$

**Maximum gap tends to $0$.** Consecutive values satisfy, for $n \ge \lceil e^k\
rceil \ge e^k$,
$$\{\ln(n+1)\} - \{\ln n\} = \ln(n+1) - \ln n = \ln\!\Bigl(1+\tfrac{1}{n}\Bigr)
\le \tfrac{1}{n} \le \tfrac{1}{e^k} \xrightarrow{k\to\infty} 0.$$
Hence the maximum gap between successive fractional parts $\{\ln n\}$, $n \in I_
k$, is at most $1/e^k \to 0$.

**Density.** Let $\alpha \in (0,1)$ and $\varepsilon > 0$. Choose $k$ large enou
gh that:
- $1/e^k < \varepsilon$ (gap control),
- $\{\ln n_k^-\} < \alpha$ (left endpoint below $\alpha$),
- $\{\ln n_k^+\} > \alpha$ (right endpoint above $\alpha$).

All three hold for all sufficiently large $k$ by the limits above. The increasin
g sequence $\bigl\{\{\ln n\} : n \in I_k\bigr\}$ starts below $\alpha$ and ends
above $\alpha$ with consecutive gaps $< \varepsilon$. Therefore some term $\{\ln
 n\}$ with $n \in I_k$ satisfies $|\{\ln n\} - \alpha| < \varepsilon$.

Since $\alpha \in (0,1)$ and $\varepsilon > 0$ were arbitrary, the set $\bigl\{\
{\ln n\} : n \in \mathbb{N}\bigr\}$ is dense in $(0,1)$. $\blacksquare$
