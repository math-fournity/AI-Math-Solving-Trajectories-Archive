## Solution

Let $a$ = number of keys in Vault A, $b$ = number in Vault B. Then $a + b = 12$
with $a, b \geq 1$.

**Translating the constraints.** Condition 4 says $a$ is not equal to any ID in
A, so the key with ID $a$ is **not** in A, meaning key $a$ must be in **B**. Con
dition 5 says $b$ is not equal to any ID in B, so key $b$ must be in **A**. Sinc
e $1 \leq a, b \leq 11 \leq 12$, both IDs $a$ and $b$ are valid keys.

**The case $a = b = 6$.** Then key 6 must be in B (from A's constraint) and key
6 must be in A (from B's constraint) — a contradiction. So $a = 6$ yields **0**
valid distributions.

**The case $a \neq b$ (i.e., $a \in \{1,...,11\} \setminus \{6\}$).** Keys $a$ a
nd $b$ are distinct. Key $b$ is forced into A, key $a$ is forced into B. The rem
aining 10 keys (all except $a$ and $b$) are freely assigned, but we need exactly
 $a$ keys in A. Since key $b$ already occupies one slot in A, we choose $a - 1$
of the remaining 10 keys to join A:

$$\text{ways}(a) = \binom{10}{a-1}.$$

**Summing over all valid $a$:** Setting $k = a-1$, so $k$ ranges over $\{0,1,...
,10\} \setminus \{5\}$:

$$\text{Total} = \sum_{\substack{k=0\\k\neq 5}}^{10} \binom{10}{k} = \sum_{k=0}^
{10}\binom{10}{k} - \binom{10}{5} = 2^{10} - 252 = 1024 - 252 = \boxed{772}.$$

**Verification of a representative case.** Take $a = 1$: key 1 → B, key 11 → A,
A = {11} (1 key, and $1 \neq 11$ ✓), B = {1,2,...,10,12} (11 keys, and $11 \noti
n$ B ✓). This gives $\binom{10}{0}=1$ way, as expected. Take $a = 2$: key 2 → B,
 key 10 → A, choose 1 of the other 10 keys for A ($\binom{10}{1}=10$ ways); A ha
s 2 keys with $2 \notin$ A ✓, B has 10 keys with $10 \notin$ B ✓.

The total number of valid distributions is **772**.
