## Solution

**Setup.** Place the common tangent $CD$ on the $x$-axis with $N$ at the origin.
 Let $C = (c, 0)$ (on circle 1, radius $r_1$) and $D = (d, 0)$ (on circle 2, rad
ius $r_2$). The centers are $O_1 = (c, r_1)$ and $O_2 = (d, r_2)$ (both on the s
ame side of the tangent).

**Key fact: $NC = ND$.** Since $N$ lies on the radical axis $AB$, the power of $
N$ with respect to both circles is equal:
$$NC^2 = \operatorname{pow}(N, \bigcirc_1) = \operatorname{pow}(N, \bigcirc_2) =
 ND^2.$$
So $|c| = |d|$, and since $C \neq D$, we have $c = -d$. Set $d > 0$, so $C = (-d
, 0)$, $D = (d, 0)$, $O_1 = (-d, r_1)$, $O_2 = (d, r_2)$.

**Parametrize the radical axis.** The direction of $O_1O_2$ is $(2d,\, r_2 - r_1
)$, so the radical axis (through $N$, perpendicular to $O_1O_2$) has direction $
(\Delta, -2d)$ where $\Delta = r_2 - r_1$. Points on it: $P(t) = (t\Delta,\, -2d
t)$.

**Find $A$ and $B$.** Substituting $P(t)$ into circle 1: $(t\Delta + d)^2 + (2dt
 + r_1)^2 = r_1^2$, which simplifies to
$$t^2(\Delta^2 + 4d^2) + 2d(r_1+r_2)\,t + d^2 = 0.$$
Both roots are negative (product $> 0$, sum $< 0$), so $A$ and $B$ lie on the sa
me side of $N$. Let $t_A$ be the root with larger $|t|$ (point $A$, farther from
 $N$), so $B$ is between $A$ and $N$ as required.

**Compute the heights.** The height of $\triangle NAC$ from $N$ is the distance
from $N = (0,0)$ to line $AC$:
$$h_{NAC} = \frac{|A \times C|}{|AC|}, \qquad h_{NAD} = \frac{|A \times D|}{|AD|
},$$
where $\times$ is the 2D cross product. With $A = (t_A\Delta, -2dt_A)$:
$$A \times C = (t_A\Delta)(0) - (-2dt_A)(-d) = -2d^2 t_A, \qquad A \times D = (t
_A\Delta)(0) - (-2dt_A)(d) = 2d^2 t_A.$$
So $|A \times C| = |A \times D| = 2d^2|t_A|$, giving
$$\frac{h_{NAC}}{h_{NAD}} = \frac{|AD|}{|AC|}.$$

**Evaluate $|AC|^2$ and $|AD|^2$.**
$$|AC|^2 = (t_A\Delta + d)^2 + 4d^2 t_A^2 = t_A^2(\Delta^2+4d^2) + 2d\,\Delta\,
t_A + d^2.$$
$$|AD|^2 = (t_A\Delta - d)^2 + 4d^2 t_A^2 = t_A^2(\Delta^2+4d^2) - 2d\,\Delta\,
t_A + d^2.$$
Using the quadratic relation $t_A^2(\Delta^2+4d^2) = -2d(r_1+r_2)t_A - d^2$:
$$|AC|^2 = -2d(r_1+r_2)t_A + 2d\,\Delta\, t_A = 2d\,t_A(\Delta - r_1 - r_2) = 2d
\,t_A(-2r_1) = -4dr_1\,t_A.$$
$$|AD|^2 = -2d(r_1+r_2)t_A - 2d\,\Delta\, t_A = -2d\,t_A(r_1+r_2+\Delta) = -2d\,
t_A(2r_2) = -4dr_2\,t_A.$$
Since $t_A < 0$, both are positive. Therefore:
$$\frac{|AD|^2}{|AC|^2} = \frac{-4dr_2\,t_A}{-4dr_1\,t_A} = \frac{r_2}{r_1}.$$

**Result.**
$$\frac{h_{NAC}}{h_{NAD}} = \frac{|AD|}{|AC|} = \sqrt{\frac{r_2}{r_1}}.$$
