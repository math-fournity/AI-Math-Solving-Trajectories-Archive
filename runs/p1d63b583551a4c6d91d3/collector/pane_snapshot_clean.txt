## Setup

Let the arcs of the circumcircle (with vertices in order B, C, D, E, F) be:
- arc BC = *a*, arc CD = *b*, arc DE = *c*, arc EF = *d*, arc FB = *e*

So *a* + *b* + *c* + *d* + *e* = 360°.

Point A is external to the circle, with secant A–B–C (B nearer) and secant A–F–E
 (F nearer).

## Translating the Given Conditions

**∠BDC = 40°:** Inscribed angle at D subtending arc BC (not containing D), so *a
*/2 = 40°, giving **a = 80°**.

**∠EDF = 36°:** Inscribed angle at D subtending arc EF (not containing D), so *d
*/2 = 36°, giving **d = 72°**.

**arc DE = 3 · arc DC:** So **c = 3b**.

**∠EAC = 30°:** By the external secant angle theorem, the angle at A equals half
 the difference of the far arc and near arc:
- Far arc (between far points C and E, not containing B or F) = arc CD + arc DE
= *b* + *c*
- Near arc (between near points B and F, not containing C, D, E) = arc FB = *e*

So (∀b + *c*) − *e*)/2 = 30°, giving **(*b* + *c*) − *e* = 60°**. Substituting *
c* = 3*b*: **4*b* − *e* = 60**. ... (i)

**Arc sum:** 80 + *b* + 3*b* + 72 + *e* = 360, so **4*b* + *e* = 208**. ... (ii)

## Solving the System

Adding (i) and (ii): 8*b* = 268, so **b = 33.5°**.

From (ii): *e* = 208 − 4(33.5) = 208 − 134 = **74°**.

Then *c* = 3 × 33.5 = **100.5°**.

**Verification:** a + b + c + d + e = 80 + 33.5 + 100.5 + 72 + 74 = 360° ✓
- c = 3b: 100.5 = 3 × 33.5 ✓
- ∠EAC = (134 − 74)/2 = 30° ✓
- ∠EDF = 72/2 = 36° ✓
- ∠BDC = 80/2 = 40° ✓

## Computing ∠DBC

∠DBC is an inscribed angle at B subtending arc DC (the arc from D to C not conta
ining B), which is arc CD = *b* = 33.5°.

$$\angle DBC = \frac{b}{2} = \frac{33.5°}{2} = 16.75° = \frac{67}{4}°$$
