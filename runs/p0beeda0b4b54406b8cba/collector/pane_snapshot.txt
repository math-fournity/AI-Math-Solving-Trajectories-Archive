## Solution

**Answer-leak check:** The problem statement contains no leaked answers or solut
ion sketches. Proceeding.

**Reformulation.** Each element of $S$ is $10^n + 1000$. If we use $a_n \ge 0$ c
opies of $10^n+1000$ (finitely many nonzero), the sum is
$$m = \sum_n a_n(10^n + 1000) = N + 1000A, \quad \text{where } N = \sum a_n 10^n
,\; A = \sum a_n.$$
Here $N$ is any nonneg integer (with "digits" $a_n$ that may exceed 9), and $A$
is its digit-sum in this representation. The standard decimal representation min
imizes the digit sum, giving $A \ge s(N)$ (ordinary digit sum). "Un-carrying" (r
eplacing one unit at position $i{+}1$ by ten at position $i$) increases $A$ by 9
, up to a maximum of $A = N$ (everything at position 0). Since $10^n \equiv 1 \p
mod{9}$, we always have $A \equiv N \pmod{9}$.

**Key characterization.** A positive integer $m$ is representable iff there exis
t $N \ge 1$, $A \ge 1$ with:
$$m = N + 1000A, \quad A \equiv N \pmod{9}, \quad s(N) \le A \le N.$$

From $m = N + 1000A$: $N \equiv m \pmod{1000}$ and $A = (m-N)/1000$. The congrue
nce $A \equiv N \pmod 9$ becomes $(m-N) \equiv N \pmod 9$ (since $1000 \equiv 1$
), i.e., $N \equiv 5m \pmod 9$. By CRT ($\gcd(1000,9)=1$), $N$ is determined mod
ulo $9000$. The constraint $s(N) \le A$ is $f(N) := N + 1000\,s(N) \le m$, and $
A \le N$ is $m \le 1001N$.

**Coverage by residue classes.** For each residue class $r \pmod{9000}$, let $N_
0 \in [0, 8999]$ be the smallest $N$ producing that class. The representable num
bers in class $r$ are exactly those in the intervals
$$[f(N_0 + 9000k),\; 1001(N_0 + 9000k)], \quad k = 0, 1, 2, \ldots$$
(all numbers $\equiv r \pmod{9000}$ in these ranges), since $1001N \equiv f(N) \
pmod{9000}$ (as $1001N - f(N) = 1000(N - s(N)) \equiv 0 \pmod{9000}$).

**Gap analysis.** Consecutive intervals for $N_0 \ge 10$ overlap because:
$$f(N_0+9000) \le s(N_0) + 9 + (N_0+9000) \le (N_0 - 9) + 9 + N_0 + 9000 \le 100
1\,N_0 + 9000,$$
using $s(N_0+9000) \le s(N_0)+9$ and $s(N_0) \le N_0 - 9$ for $N_0 \ge 10$. So f
or $N_0 \ge 10$, the union is $[f(N_0), \infty)$ with **no gaps**. The only unco
vered numbers in such a class are those below $f(N_0)$, the largest being $f(N_0
) - 9000$.

For $N_0 \in \{1,\dots,9\}$ (single-digit): $f(N_0) = 1001\,N_0$ (single point),
 and the next interval starts at $f(N_0+9000) = 1001\,N_0 + 18000$, leaving a ga
p at $1001\,N_0 + 9000$.

For $N_0 = 0$: only $m=0$ is covered, then $[18000, \infty)$, leaving gap at $90
00$.

**Maximizing the largest gap.** The largest uncovered number overall is:
$$\max_{N_0 \in [10, 8999]} \bigl(f(N_0) - 9000\bigr) = \max_{N_0 \in [10,8999]}
 \bigl(N_0 + 1000\,s(N_0) - 9000\bigr).$$
Since the coefficient on $s(N_0)$ is $1000$, we maximize $s(N_0)$ first. For $N_
0 < 9000$, the maximum digit sum is $s(8999) = 35$, giving
$$f(8999) - 9000 = 8999 + 35000 - 9000 = 34999.$$
All gapped-class gaps are at most $18009 < 34999$.

**Verification that $34999$ is not representable.** We need $A \equiv 5 \cdot 34
999 \pmod 9$. Since $34999 \equiv 7 \pmod 9$, we get $A \equiv 35 \equiv 8 \pmod
 9$. Also $A \le \lfloor 34999/1001 \rfloor = 34$, so $A \in \{8, 17, 26\}$.

| $A$ | $N = 34999 - 1000A$ | $s(N)$ | $s(N) \le A$? |
|---|---|---|---|
| 8 | 26999 | 35 | No |
| 17 | 17999 | 35 | No |
| 26 | 8999 | 35 | No |

All fail ($s(N) = 35 > A$), so $34999$ is **not** representable.

**Verification that $35000$ is representable.** $35000 \equiv 8000 \pmod{9000}$,
 class $N_0 = 4000$, $f(4000) = 8000 \le 35000$. Take $A = 31$, $N = 4000$: $s(4
000)=4 \le 31 \le 4000$, $31 \equiv 4 \pmod 9$ ✓. Explicitly: $10 \cdot 1001 + 9
 \cdot 1010 + 9 \cdot 1100 + 3 \cdot 2000 = 10010 + 9090 + 9900 + 6000 = 35000$.
 ✓

**All $m \ge 35000$ are representable.** For any $m \ge 35000$ in a non-gapped c
lass ($N_0 \ge 10$): if $m < f(N_0)$ then $m \le f(N_0) - 9000 \le 43999 - 9000
= 34999 < 35000$, contradiction. So $m \ge f(N_0)$, hence covered. For gapped cl
asses, all $m \ge 18010$ are covered. ✓

$$\boxed{34999}$$
