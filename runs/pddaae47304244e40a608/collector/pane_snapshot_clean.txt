## Proof

**Step 1: The constraint is tight at the optimum.**

If $21ab + 2bc + 8ca < 11$, we can scale $a, b, c$ by a common factor $t > 1$ so
 that the constraint becomes tight. This scaling decreases each reciprocal term,
 hence decreases $P$. So at the minimum, $21ab + 2bc + 8ca = 11$.

**Step 2: Lagrange multiplier setup.**

Let $f = \frac{1}{a} + \frac{2}{b} + \frac{3}{c}$ and $g = 21ab + 2bc + 8ca - 11
 = 0$. At the optimum, $\nabla f = \mu \nabla g$ for some $\mu > 0$:

$$-\frac{1}{a^2} = \mu(21b+8c), \quad -\frac{2}{b^2} = \mu(21a+2c), \quad -\frac
{3}{c^2} = \mu(2b+8a)$$

Multiplying the first by $-a$, the second by $-b$, the third by $-c$:

$$\frac{1}{a} = \mu(21ab+8ac), \quad \frac{2}{b} = \mu(21ab+2bc), \quad \frac{3}
{c} = \mu(2bc+8ac)$$

Summing all three:

$$P = \mu\bigl(2\cdot 21ab + 2\cdot 2bc + 2\cdot 8ca\bigr) = 2\mu \cdot 11 = 22\
mu$$

So $\mu = P/22$.

**Step 3: Introduce $x = 21ab$, $y = 2bc$, $z = 8ca$.**

Then $x + y + z = 11$. From the equations above:

$$\frac{1}{a} = \mu(x+z), \quad \frac{2}{b} = \mu(x+y), \quad \frac{3}{c} = \mu(
y+z)$$

Solving for $a, b, c$:

$$a = \frac{1}{\mu(x+z)}, \quad b = \frac{2}{\mu(x+y)}, \quad c = \frac{3}{\mu(y
+z)}$$

Substituting back into $x = 21ab$, $y = 2bc$, $z = 8ca$ (with $t = \mu^2$):

$$x = \frac{42}{t(x+z)(x+y)}, \quad y = \frac{12}{t(x+y)(y+z)}, \quad z = \frac{
24}{t(y+z)(x+z)}$$

**Step 4: Solve the ratio system.**

Taking ratios eliminates $t$:

$$\frac{x(x+z)}{y(y+z)} = \frac{7}{2}, \qquad \frac{y(x+y)}{z(x+z)} = \frac{1}{2
}$$

Setting $p = y/x$ and $q = z/x$, these become:

$$4(1+p) = 7q(p+q) \quad \text{...(A)}, \qquad q(1+q) = 2p(1+p) \quad \text{...(
B)}$$

From (B): $q^2 + q = 2p^2 + 2p$. Substituting into (A) and eliminating $q$, we o
btain:

$$49p^4 + 140p^3 + 57p^2 - 40p - 6 = 0$$

This factors as $(7p - 3)(7p^3 + 23p^2 + 18p + 2) = 0$. The cubic has all positi
ve coefficients, so it has no positive roots. Thus $p = 3/7$, and from (B):

$$q = \frac{14p^2 + 10p - 4}{7(1-p)} = \frac{20/7}{4} = \frac{5}{7}$$

**Step 5: Determine $x, y, z$ and then $a, b, c$.**

With $y = \frac{3}{7}x$, $z = \frac{5}{7}x$, and $x + y + z = 11$:

$$x\left(1 + \frac{3}{7} + \frac{5}{7}\right) = \frac{15}{7}x = 11 \implies x =
\frac{77}{15}, \quad y = \frac{11}{5}, \quad z = \frac{11}{3}$$

So $x : y : z = 7 : 3 : 5$. Now:

$$ab = \frac{11}{45}, \quad bc = \frac{11}{10}, \quad ca = \frac{11}{24}$$

Computing $a^2 = \frac{(ab)(ca)}{bc} = \frac{11}{108}$, $b^2 = \frac{(ab)(bc)}{c
a} = \frac{44}{75}$, $c^2 = \frac{(bc)(ca)}{ab} = \frac{33}{16}$:

$$a = \frac{\sqrt{33}}{18}, \quad b = \frac{2\sqrt{33}}{15}, \quad c = \frac{\sq
rt{33}}{4}$$

**Step 6: Compute $P$ and verify.**

$$P = \frac{18}{\sqrt{33}} + \frac{15}{\sqrt{33}} + \frac{12}{\sqrt{33}} = \frac
{45}{\sqrt{33}} = \frac{15\sqrt{33}}{11}$$

**Constraint verification:**

$$21ab + 2bc + 8ca = \frac{77}{15} + \frac{11}{5} + \frac{11}{3} = \frac{77 + 33

**Step 7: Confirm this is a minimum.**

As $a \to 0^+$ (or $b \to 0^+$ or $c \to 0^+$), $P \to \infty$. As any variable
$\to \infty$, the constraint forces the others toward $0$, again sending $P \to
\infty$. The feasible set with $P \leq M$ is compact for any finite $M$, so the
unique critical point we found is the global minimum.
