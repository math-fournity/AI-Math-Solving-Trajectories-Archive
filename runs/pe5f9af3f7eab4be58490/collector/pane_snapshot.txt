## Solution

**Answer:** A function $f \in L^2(X,\mu)$ is cyclic (i.e., the closed linear spa
n of $\{\varphi^n f : n \ge 0\}$ equals $L^2(X,\mu)$) if and only if
$$|f(x)| > 0 \quad \text{for } \mu\text{-almost every } x \in X.$$

---

### Proof

**Setup and reduction.** Since $\varphi(x)=x$, the closed linear span in questio
n is
$$V_f := \overline{\{p \cdot f : p \text{ polynomial}\}}^{\,L^2(\mu)}.$$
We must determine when $V_f = L^2(\mu)$.

**An isometry.** Define the measure $\nu := |f|^2\,\mu$ on $X$ (a finite positiv
e Borel measure, absolutely continuous w.r.t. $\mu$). Consider the map
$$T: L^2(\nu) \longrightarrow L^2(\mu), \qquad T(g) := g\,f.$$
This is a linear isometry, since
$$\|T(g)\|_{L^2(\mu)}^2 = \int_X |g|^2 |f|^2\,d\mu = \int_X |g|^2\,d\nu = \|g\|_
{L^2(\nu)}^2.$$
Under $T$, the monomial $x^n \in L^2(\nu)$ is sent to $x^n f \in L^2(\mu)$. Henc
e
$$V_f = T\!\left(\overline{\{p : p \text{ polynomial}\}}^{\,L^2(\nu)}\right).$$

**Polynomials are dense in $L^2(\nu)$.** Since $X \subset \mathbb{R}$ is compact
, the restrictions of polynomials to $X$ form a subalgebra of $C(X)$ that contai
ns the constants and separates points (the function $x \mapsto x$ already separa
tes points). By the **Stone–Weierstrass theorem**, polynomials are dense in $C(X
)$ in the uniform norm. Every finite Borel measure on a compact metric space is
regular, so $C(X)$ is dense in $L^2(\nu)$. Consequently,
$$\overline{\{p : p \text{ polynomial}\}}^{\,L^2(\nu)} = L^2(\nu),$$
and therefore $V_f = T(L^2(\nu))$, i.e., $V_f$ is the **range of the isometry $T
$**.

**Characterizing the range of $T$.** We claim:
$$\operatorname{Ran}(T) = \Big\{h \in L^2(\mu) : h = 0 \;\;\mu\text{-a.e. on } \
{|f|=0\}\Big\}.$$

*Inclusion "$\subseteq$":* If $h = T(g) = gf$, then on the set $\{|f|=0\}$ we ha
ve $h = g \cdot 0 = 0$ $\mu$-a.e.

*Inclusion "$\supseteq$":* Let $h \in L^2(\mu)$ with $h=0$ on $\{|f|=0\}$. Set $
g := h/f$ on $\{|f|>0\}$ and $g:=0$ on $\{|f|=0\}$. Then
$$\|g\|_{L^2(\nu)}^2 = \int_{\{|f|>0\}} \frac{|h|^2}{|f|^2}\,|f|^2\,d\mu = \int_
{\{|f|>0\}} |h|^2\,d\mu = \|h\|_{L^2(\mu)}^2 < \infty,$$
so $g \in L^2(\nu)$, and $T(g) = gf = h$ (on $\{|f|>0\}$ we have $gf = h$; on $\
{|f|=0\}$ both sides are $0$). Thus $h \in \operatorname{Ran}(T)$.

**Conclusion.** We have $V_f = \operatorname{Ran}(T) = \{h \in L^2(\mu) : h = 0
\text{ on } \{|f|=0\}\}$. This equals all of $L^2(\mu)$ if and only if the const
raint "$h = 0$ on $\{|f|=0\}$" is vacuous, i.e., if and only if
$$\mu\big(\{x \in X : |f(x)| = 0\}\big) = 0.$$

Equivalently, $|f| > 0$ $\mu$-almost everywhere. $\blacksquare$

---

**Summary.** The cyclic vectors for the multiplication operator $M_x$ on $L^2(X,
\mu)$ are precisely those $f \in L^2(X,\mu)$ that vanish only on a $\mu$-null se
t. The key ingredients are: (1) the isometry $T(g)=gf$ between $L^2(|f|^2\mu)$ a
nd a subspace of $L^2(\mu)$, (2) Stone–Weierstrass density of polynomials in $L^
2$ of any finite Borel measure on compact $X\subset\mathbb{R}$, and (3) the expl
icit description of $\operatorname{Ran}(T)$, which is all of $L^2(\mu)$ exactly
when $|f|>0$ a.e.
