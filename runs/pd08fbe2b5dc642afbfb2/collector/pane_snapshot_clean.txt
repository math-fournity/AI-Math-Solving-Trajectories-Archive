## Solution

We find all functions $f: \mathbb{R} \to \mathbb{R}$ satisfying $f(f(x+y)) = f(x
) + y$ for all $x, y \in \mathbb{R}$.

**Step 1: Determine $f(f(y))$.**

Set $x = 0$. Let $c = f(0)$. The equation becomes
$$f(f(y)) = f(0) + y = y + c \quad \text{for all } y \in \mathbb{R}. \tag{1}$$

**Step 2: $f$ is bijective.**

From (1), the map $y \mapsto f(f(y)) = y+c$ is a bijection, so $f \circ f$ is bi
jective. This forces $f$ to be both injective and surjective.

**Step 3: Determine $f(x)$.**

Using (1) with $y$ replaced by $x+y$:
$$f(f(x+y)) = (x+y) + c.$$

But the original equation gives $f(f(x+y)) = f(x) + y$. Equating:
$$x + y + c = f(x) + y,$$
so
$$f(x) = x + c \quad \text{for all } x \in \mathbb{R}. \tag{2}$$

**Step 4: Determine $c$.**

Substitute $f(x) = x + c$ back into the original equation. The left side:
$$f(f(x+y)) = f(x+y+c) = (x+y+c) + c = x + y + 2c.$$
The right side:
$$f(x) + y = (x + c) + y = x + y + c.$$
Equating: $x + y + 2c = x + y + c$, hence $c = 0$.

**Step 5: Verify.**

With $c = 0$, $f(x) = x$. Then $f(f(x+y)) = f(x+y) = x+y$ and $f(x)+y = x+y$. ✓

**Conclusion.** The unique solution is $f(x) = x$.
