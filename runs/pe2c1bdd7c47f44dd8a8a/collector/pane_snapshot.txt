## Solution

The statement is **true**.

**Proof.** Since $\Omega$ is a bounded open subset of $\mathbb{R}^N$, the Rellic
h–Kondrachov theorem gives that the embedding $H^1_0(\Omega) \hookrightarrow L^2
(\Omega)$ is **compact**. (For $H^1_0$ this holds for any bounded open $\Omega$:
 extend functions by $0$ to $\mathbb{R}^N$, use the translation continuity of $H
^1(\mathbb{R}^N)$ functions together with the tightness provided by the boundedn
ess of $\Omega$, and apply the Fréchet–Kolmogorov criterion.)

A compact linear operator maps weakly convergent sequences to strongly convergen
t sequences. Since $u_n \rightharpoonup 0$ in $H^1_0(\Omega)$, we obtain
$$u_n \to 0 \quad\text{strongly in } L^2(\Omega),$$
that is, $\|u_n\|_{L^2(\Omega)} \to 0$.

Now observe the pointwise identity for the integrand. For each $x$:
- if $u_n(x) \geq 0$, then $u_n^+(x) = u_n(x)$, so $u_n^+(x)\,u_n(x) = u_n(x)^2
= (u_n^+(x))^2$;
- if $u_n(x) < 0$, then $u_n^+(x) = 0$, so $u_n^+(x)\,u_n(x) = 0 = (u_n^+(x))^2$
.

Hence $u_n^+\,u_n = (u_n^+)^2 \geq 0$ pointwise, and
$$\int_\Omega u_n^+\,u_n\,dx = \int_\Omega (u_n^+)^2\,dx = \|u_n^+\|^2_{L^2(\Ome
ga)}.$$

Since $0 \leq u_n^+ \leq |u_n|$, we have $(u_n^+)^2 \leq u_n^2$, and therefore
$$0 \;\leq\; \|u_n^+\|^2_{L^2(\Omega)} \;\leq\; \|u_n\|^2_{L^2(\Omega)} \;\longr
ightarrow\; 0.$$

By the squeeze theorem,
$$\int_\Omega u_n^+\,u_n\,dx = \|u_n^+\|^2_{L^2(\Omega)} \to 0 \quad\text{as } n
\to\infty.$$

The key mechanism is that weak convergence in $H^1_0$ is *upgraded* to strong co
nvergence in $L^2$ by the compact embedding, after which the nonlinear positive-
part map — which is continuous and bounded by the identity in $L^2$-norm — canno
t prevent the integral from vanishing. $\blacksquare$
