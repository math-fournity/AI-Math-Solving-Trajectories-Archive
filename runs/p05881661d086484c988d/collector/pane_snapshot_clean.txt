**Proof.**

Let $\Omega \subseteq \mathbb{C}$ be a starlike open set, and let $z_0 \in \Omeg
a$ be a star-center: for every $z \in \Omega$, the line segment $\{z_0 + t(z - z
_0) : t \in [0,1]\}$ lies entirely in $\Omega$.

Let $\gamma : [0,1] \to \Omega$ be an arbitrary closed curve, so $\gamma(0) = \g
amma(1)$. We construct an explicit homotopy that deforms $\gamma$ to the constan
t curve at $z_0$, with every intermediate curve remaining closed and lying entir
ely in $\Omega$.

Define $H : [0,1] \times [0,1] \to \mathbb{C}$ by

$$H(s, t) = (1 - t)\,\gamma(s) + t\,z_0 = z_0 + (1-t)\bigl(\gamma(s) - z_0\bigr)
.$$

**$H$ is continuous.** It is a linear combination of the continuous map $\gamma$
 and the constant $z_0$, hence continuous on $[0,1]\times[0,1]$.

**$H$ maps into $\Omega$.** Fix $s \in [0,1]$. The point $\gamma(s)$ belongs to
$\Omega$, and by star-likeness the entire segment from $z_0$ to $\gamma(s)$ is c
ontained in $\Omega$. As $t$ ranges over $[0,1]$, the point $H(s,t) = z_0 + (1-t
)(\gamma(s)-z_0)$ traces exactly this segment (with the parameter $1-t \in [0,1]
$). Therefore $H(s,t) \in \Omega$ for every $(s,t) \in [0,1]\times[0,1]$.

**Endpoints at $t = 0$ and $t = 1$.** We have
$$H(s, 0) = \gamma(s) \quad\text{for all } s,$$
so the curve at time $t=0$ is the original curve $\gamma$. We have
$$H(s, 1) = z_0 \quad\text{for all } s,$$
so the curve at time $t=1$ is the constant (point) curve at $z_0 \in \Omega$.

**Each intermediate curve is closed.** For every $t \in [0,1]$,
$$H(0, t) = (1-t)\,\gamma(0) + t\,z_0 = (1-t)\,\gamma(1) + t\,z_0 = H(1, t),$$
since $\gamma(0) = \gamma(1)$. Thus each time-slice $s \mapsto H(s,t)$ is a clos
ed curve.

We have exhibited a continuous map $H : [0,1]\times[0,1] \to \Omega$ satisfying
$H(s,0) = \gamma(s)$, $H(s,1) = z_0$, and $H(0,t) = H(1,t)$ for all $s, t$. This
 is precisely a homotopy of closed curves in $\Omega$ from $\gamma$ to the const
ant curve at $z_0$.

Since $\gamma$ was an arbitrary closed curve in $\Omega$, every closed curve in
$\Omega$ is homotopic to a point in $\Omega$. Hence the starlike open set $\Omeg
a$ is homotopically simply connected. $\blacksquare$
