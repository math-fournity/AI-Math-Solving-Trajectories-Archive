## 解答

设 $a, b > 0$ 且 $ab = 1$。直线为 $(ae^t)x + (be^{-t})y = 1$。从原点到直线 $Ax +
 By = 1$ 的距离为 $1/\sqrt{A^2 + B^2}$，因此

$$d(t) = \frac{1}{\sqrt{a^2 e^{2t} + b^2 e^{-2t}}}, \qquad \frac{1}{d(t)^2} = a^
2 e^{2t} + b^2 e^{-2t}.$$

我们需要最小化
$$I = \int_0^1 \!\bigl(a^2 e^{2t} + b^2 e^{-2t}\bigr)\,dt, \qquad ab = 1.$$

**计算积分。** 令 $u = a^2$， $v = b^2$，则 $uv = (ab)^2 = 1$，即 $v = 1/u$。积
分结果为

$$I = u\!\int_0^1 e^{2t}\,dt + v\!\int_0^1 e^{-2t}\,dt = u\cdot\frac{e^2-1}{2} +
 v\cdot\frac{1-e^{-2}}{2}.$$

设 $A = \dfrac{e^2-1}{2}$ 和 $B = \dfrac{1-e^{-2}}{2}$（均为正数）。利用 $v = 1/
u$，

$$I = uA + \frac{B}{u}, \qquad u > 0.$$

**在约束 $uv=1$ 下最小化。** 根据 AM–GM 不等式，

$$uA + \frac{B}{u} \;\ge\; 2\sqrt{AB},$$

当且仅当 $uA = B/u$，即 $u^2 = B/A$， $u = \sqrt{B/A}$ 时等号成立（这给出了有效
的 $a = u^{1/2}$， $b = 1/a$）。因此最小值为 $2\sqrt{AB}$。

**化简。**

$$4AB = (e^2-1)(1-e^{-2}) = (e^2-1)\cdot\frac{e^2-1}{e^2} = \frac{(e^2-1)^2}{e^2
},$$

所以

$$2\sqrt{AB} = \sqrt{4AB} = \frac{e^2-1}{e} = e - e^{-1}.$$

**验证。** 取 $u = \sqrt{B/A} = \sqrt{\frac{1-e^{-2}}{e^2-1}} = \sqrt{e^{-2}} =
e^{-1}$，则 $a^2 = e^{-1}$， $b^2 = e$，且 $ab = \sqrt{e^{-1}\cdot e} = 1$。 ✓

此时 $I = e^{-1}\cdot\dfrac{e^2-1}{2} + e\cdot\dfrac{1-e^{-2}}{2} = \dfrac{e - e
^{-1}}{2} + \dfrac{e - e^{-1}}{2} = e - e^{-1}.$ ✓

**最小值为 $\,e - e^{-1} = 2\sinh 1$.**

最终答案：$\boxed{e - e^{-1}}$
