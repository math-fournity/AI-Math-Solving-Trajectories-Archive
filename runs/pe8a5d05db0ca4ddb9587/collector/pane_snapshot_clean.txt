## Solution

tion or answer. Proceeding.

We count points on the elliptic curve $E: y^2 = x^3 + x + 1$ over $\mathbb{F}_{1
25} = \mathbb{F}_{5^3}$.

### Step 1: Count points over $\mathbb{F}_5$

For each $x \in \mathbb{F}_5$, compute $f(x) = x^3 + x + 1 \pmod 5$ and check wh
ether it is a quadratic residue (QR). The squares mod 5 are $\{0, 1, 4\}$.

| $x$ | $x^3+x+1 \pmod 5$ | QR? | # of $y$ |
|-----|-------------------|-----|----------|
| 0   | 1                 | yes | 2        |
| 1   | 3                 | no  | 0        |
| 2   | $11 \equiv 1$     | yes | 2        |
| 3   | $31 \equiv 1$     | yes | 2        |
| 4   | $69 \equiv 4$     | yes | 2        |

Affine points: $2+0+2+2+2 = 8$. Adding the point at infinity $\mathcal{O}$:

$$\#E(\mathbb{F}_5) = 9.$$

### Step 2: Trace of Frobenius

$$a_1 = q + 1 - \#E(\mathbb{F}_q) = 5 + 1 - 9 = -3.$$

The Frobenius eigenvalues $\alpha, \beta$ are roots of
$$T^2 - a_1 T + q = T^2 + 3T + 5 = 0,$$
so $\alpha + \beta = -3$ and $\alpha\beta = 5$.

### Step 3: Lift to $\mathbb{F}_{5^3}$

For any $n \ge 1$,
$$\#E(\mathbb{F}_{q^n}) = q^n + 1 - s_n, \qquad s_n = \alpha^n + \beta^n.$$

The sequence satisfies $s_n = -3\,s_{n-1} - 5\,s_{n-2}$ with $s_0 = 2,\; s_1 = -
3$. We need $s_3$:

$$s_3 = (\alpha+\beta)^3 - 3\alpha\beta(\alpha+\beta) = (-3)^3 - 3\cdot 5\cdot(-
3) = -27 + 45 = 18.$$

(Equivalently via recurrence: $s_2 = -3(-3)-5(2) = -1$, then $s_3 = -3(-1)-5(-3)
 = 3+15 = 18$.)

### Step 4: Final count

$$\#E(\mathbb{F}_{125}) = 5^3 + 1 - s_3 = 125 + 1 - 18 = \boxed{108}.$$
