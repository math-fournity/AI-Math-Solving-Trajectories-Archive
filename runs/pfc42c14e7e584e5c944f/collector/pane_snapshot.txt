## Solution

An interesting number is a 6-digit integer $d_1d_2d_3d_4d_5d_6$ with every $d_i\
in\{1,\dots,9\}$ (no zeros), satisfying:
- $d_1<d_2<d_3$ (first three strictly increasing),
- $d_4\ge d_5\ge d_6$ (last three non-increasing).

The first three and last three digits are chosen independently, so

$$\text{Average} = 1000\cdot E[\overline{d_1d_2d_3}] + E[\overline{d_4d_5d_6}].$
$

### First three digits

A strictly increasing triple from $\{1,\dots,9\}$ is exactly a 3-element subset,
 so there are $\binom{9}{3}=84$ choices, uniformly distributed. For a random $r$
-subset of $\{1,\dots,n\}$, the expected value of the $j$-th smallest element is
 $\dfrac{j(n+1)}{r+1}$. With $n=9,\ r=3$:

$$E[d_1]=\tfrac{1\cdot10}{4}=2.5,\quad E[d_2]=\tfrac{2\cdot10}{4}=5,\quad E[d_3]
=\tfrac{3\cdot10}{4}=7.5.$$

(Verified directly: $\sum_{v=1}^{7}v\binom{9-v}{2}/84 = 210/84 = 2.5$.)

Hence
$$E[\overline{d_1d_2d_3}]=100(2.5)+10(5)+7.5=307.5.$$

### Last three digits

A non-increasing triple from $\{1,\dots,9\}$ is exactly a multiset of size 3, so
 there are $\binom{9+3-1}{3}=\binom{11}{3}=165$ choices, uniformly distributed.

**Symmetry.** The map $(d_4,d_5,d_6)\mapsto(10-d_6,\,10-d_5,\,10-d_4)$ is a bije
ction on non-increasing triples, giving
$$E[d_4]=10-E[d_6],\qquad E[d_5]=5.$$

**Expected sum.** The same complement symmetry gives $E[d_4+d_5+d_6]=\tfrac{3\cd
ot10}{2}=15$, so $E[d_4]+E[d_6]=10$ (consistent). To separate them, compute $E[d
_4]$ directly. The number of multisets of size 3 from $\{1,\dots,v\}$ with maxim
um exactly $v$ is
$$\binom{v+2}{3}-\binom{v+1}{3}=\binom{v+1}{2}.$$

Thus
$$E[d_4]=\frac{1}{165}\sum_{v=1}^{9}v\binom{v+1}{2}=\frac{1}{330}\sum_{v=1}^{9}v
^2(v+1)=\frac{1}{330}\sum_{v=1}^{9}(v^3+v^2).$$

Using $\sum_{v=1}^{9}v^3=45^2=2025$ and $\sum_{v=1}^{9}v^2=285$:
$$E[d_4]=\frac{2025+285}{330}=\frac{2310}{330}=7.$$

Therefore $E[d_6]=10-7=3$ and $E[d_5]=5$, giving
$$E[\overline{d_4d_5d_6}]=100(7)+10(5)+3=753.$$

### Combining

The total number of interesting numbers is $84\times165=13{,}860$, and

$$\text{Average}=1000\cdot307.5+753=307500+753=\boxed{308253}.$$
