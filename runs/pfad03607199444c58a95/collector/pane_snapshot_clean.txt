## Proof

**Setup.** Let $a_1,\dots,a_{105}$ be a permutation of $\{1,\dots,105\}$ such th
at for every $m\in\{3,5,7\}$ and every $n$ with $1\le n<n+m\le 105$, we have $m\
mid(a_{n+m}-a_n)$.

**Step 1 — Residue classes of positions.** Fix $m\in\{3,5,7\}$. The condition $a
_{n+m}\equiv a_n\pmod m$ says that all positions in the same residue class modul
o $m$ carry values that are mutually congruent modulo $m$. Since $105=3\cdot5\cd
ot7$ is divisible by each $m$, the positions $1,\dots,105$ split into $m$ residu
e classes, each of size $105/m$:
- $m=3$: three classes of $35$ positions each;
- $m=5$: five classes of $21$ positions each;
- $m=7$: seven classes of $15$ positions each.

Among the values $\{1,\dots,105\}$, each residue class modulo $m$ contains exact
ly $105/m$ values (again because $m\mid 105$).

**Step 2 — Each position-class maps to a distinct value-class.** Within a single
 position residue class (mod $m$), all $105/m$ values are congruent mod $m$, so
they all lie in one value residue class mod $m$, which has only $105/m$ elements
. Hence that position-class uses *exactly* one full value-class. Two different p
osition-classes cannot share the same value-class (they would need $2\cdot 105/m
 > 105/m$ distinct values from a class of size $105/m$). Therefore there is a **
permutation** $\sigma_m$ of the residue classes mod $m$ such that

$$n\equiv r\pmod m \implies a_n\equiv \sigma_m(r)\pmod m.$$

**Step 3 — The value is fully determined by the three permutations.** For a posi
tion $n$, its residues $(n\bmod 3,\;n\bmod 5,\;n\bmod 7)$ determine
$$a_n \equiv \sigma_3(n\bmod 3)\pmod 3,\quad a_n\equiv\sigma_5(n\bmod 5)\pmod 5,
\quad a_n\equiv\sigma_7(n\bmod 7)\pmod 7.$$
Since $\gcd(3,5,7)=1$ and $\mathrm{lcm}(3,5,7)=105$, the Chinese Remainder Theor
em determines $a_n\pmod{105}$ uniquely. As $a_n\in\{1,\dots,105\}$ (a complete r
esidue system mod $105$, with $0$ represented by $105$), $a_n$ is determined uni
quely.

**Step 4 — Every triple of permutations gives a valid permutation.** As $n$ rang
es over $1,\dots,105$, the triple $(n\bmod3,n\bmod5,n\bmod7)$ ranges over all $3
\cdot5\cdot7=105$ combinations exactly once (CRT). The map
$$(r_3,r_5,r_7)\longmapsto\bigl(\sigma_3(r_3),\sigma_5(r_5),\sigma_7(r_7)\bigr)$
$
is a bijection on the set of $105$ triples precisely because each $\sigma_m$ is
a bijection. Hence $n\mapsto a_n$ is a bijection on residues mod $105$, i.e. a p
ermutation of $\{1,\dots,105\}$. The divisibility conditions hold by constructio
n. So every choice $(\sigma_3,\sigma_5,\sigma_7)$ yields a valid permutation.

**Step 5 — Injectivity of the correspondence.** A valid permutation determines e
ach $\sigma_m$ uniquely: pick any position $n\equiv r\pmod m$ and read off $a_n\
bmod m$. So distinct triples give distinct permutations.

**Counting.** The number of valid permutations equals the number of triples of p
ermutations:
$$|\sigma_3|\cdot|\sigma_5|\cdot|\sigma_7| = 3!\cdot 5!\cdot 7! = 6\cdot 120\cdo
t 5040 = 3\,628\,800.$$

### PROOF COMPLETE
