# Solution

## Setup

Let $\omega = e^{2\pi i/N}$, so $e_k^N = \omega^k$. We seek

$$S_N = \sum_{k=0}^{N-1}\sum_{\substack{n=0\\n\neq k}}^{N-1}\frac{1}{|e_k^N - e_
n^N|^2}.$$

## Step 1: Simplify the squared distance

$$|\omega^k - \omega^n|^2 = (\omega^k-\omega^n)(\omega^{-k}-\omega^{-n}) = 2 - \
omega^{k-n} - \omega^{-(k-n)} = 2 - 2\cos\!\left(\tfrac{2\pi(k-n)}{N}\right) = 4
\sin^2\!\left(\tfrac{\pi(k-n)}{N}\right).$$

## Step 2: Reduce to a single sum

Setting $m = k - n \pmod{N}$, the inner sum depends only on $m \in \{1,\dots,N-1
\}$, and each value of $m$ occurs once for each $k$:

$$S_N = \sum_{k=0}^{N-1}\sum_{m=1}^{N-1}\frac{1}{4\sin^2(\pi m/N)} = \frac{N}{4}
\sum_{m=1}^{N-1}\csc^2\!\left(\tfrac{\pi m}{N}\right).$$

## Step 3: Evaluate the cosecant-squared sum

**Claim.** $\displaystyle\sum_{m=1}^{N-1}\csc^2\!\left(\frac{\pi m}{N}\right) =
\frac{N^2-1}{3}.$

**Proof of claim.** We use the classical partial-fraction identity

$$\sum_{m=0}^{N-1}\cot\!\left(x + \frac{\pi m}{N}\right) = N\cot(Nx),$$

which follows from the product formula $\sin(Nx) = 2^{N-1}\prod_{m=0}^{N-1}\sin\
!\left(x+\frac{\pi m}{N}\right)$ by logarithmic differentiation. Differentiating
 both sides with respect to $x$:

$$\sum_{m=0}^{N-1}\csc^2\!\left(x + \frac{\pi m}{N}\right) = N^2\csc^2(Nx). \tag
{$\ast$}$$

Now take $x \to 0$. Isolate the $m=0$ term on the left:

$$\csc^2(x) + \sum_{m=1}^{N-1}\csc^2\!\left(\frac{\pi m}{N}\right) + O(x^2) = N^
2\csc^2(Nx).$$

Using the Laurent expansion $\csc^2(t) = \frac{1}{t^2} + \frac{1}{3} + O(t^2)$:

- Left side: $\frac{1}{x^2} + \frac{1}{3} + \sum_{m=1}^{N-1}\csc^2\!\left(\frac{
\pi m}{N}\right) + O(x^2)$.
- Right side: $N^2\!\left(\frac{1}{N^2 x^2} + \frac{1}{3} + O(x^2)\right) = \fra
c{1}{x^2} + \frac{N^2}{3} + O(x^2)$.

Equating the finite parts (the $\frac{1}{x^2}$ terms cancel):

$$\frac{1}{3} + \sum_{m=1}^{N-1}\csc^2\!\left(\frac{\pi m}{N}\right) = \frac{N^2
}{3},$$

hence $\displaystyle\sum_{m=1}^{N-1}\csc^2\!\left(\frac{\pi m}{N}\right) = \frac
{N^2-1}{3}$. $\square$

## Step 4: Assemble the answer

$$S_N = \frac{N}{4}\cdot\frac{N^2-1}{3} = \frac{N(N^2-1)}{12}.$$

## Asymptotic behavior

As $N \to \infty$:

$$\boxed{S_N = \frac{N(N^2-1)}{12} \sim \frac{N^3}{12}.}$$

The sum grows cubically, with leading coefficient $\frac{1}{12}$.
