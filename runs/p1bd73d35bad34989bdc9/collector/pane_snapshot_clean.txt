## Proof

Let $B_t$ be a standard Brownian motion, so $B_t \sim N(0, t)$ with density
$$p_t(x) = \frac{1}{\sqrt{2\pi t}} e^{-x^2/(2t)}.$$

We compute $\mathbb{E}[\sin(B_t)]$ by evaluating the characteristic function of
$B_t$.

**Step 1: Characteristic function of $B_t$.**

For $B_t \sim N(0, t)$, the characteristic function is
$$\varphi_{B_t}(\xi) = \mathbb{E}\!\left[e^{i\xi B_t}\right] = e^{-t\xi^2/2}.$$

This is a standard result: completing the square in the Gaussian integral,
$$\int_{-\infty}^{\infty} e^{i\xi x} \frac{1}{\sqrt{2\pi t}} e^{-x^2/(2t)}\,dx =
 \frac{1}{\sqrt{2\pi t}} \int_{-\infty}^{\infty} e^{-\frac{1}{2t}(x^2 - 2i\xi t
x)}\,dx = \frac{1}{\sqrt{2\pi t}} \int_{-\infty}^{\infty} e^{-\frac{1}{2t}(x - i
\xi t)^2 - \xi^2 t/2}\,dx = e^{-\xi^2 t/2}.$$

**Step 2: Extract the imaginary part.**

Setting $\xi = 1$,
$$\mathbb{E}\!\left[e^{i B_t}\right] = e^{-t/2}.$$

By Euler's formula $e^{iB_t} = \cos(B_t) + i\sin(B_t)$, so taking real and imagi
nary parts:
$$\mathbb{E}[\cos(B_t)] = e^{-t/2}, \qquad \mathbb{E}[\sin(B_t)] = \operatorname
{Im}\!\left(e^{-t/2}\right) = 0.$$

**Step 3: Direct verification via symmetry (sanity check).**

Since $B_t \sim N(0,t)$ is symmetric about $0$ (i.e., $B_t \stackrel{d}{=} -B_t$
), and $\sin$ is an odd function,
$$\mathbb{E}[\sin(B_t)] = \mathbb{E}[\sin(-B_t)] = -\mathbb{E}[\sin(B_t)],$$
hence $\mathbb{E}[\sin(B_t)] = 0$.

This confirms the result obtained from the characteristic function.

## Conclusion

$$\boxed{\mathbb{E}[X_t] = \mathbb{E}[\sin(B_t)] = 0, \quad \text{for all } t \g
eq 0.}$$
