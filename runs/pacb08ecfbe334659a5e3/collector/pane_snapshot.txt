## Proof

Let $K$ be a CW-complex (or simplicial complex) with $p$-skeleton $K^{(p)}$. We
determine for which $i$ the inclusion $\iota: K^{(p)} \hookrightarrow K$ induces
 an isomorphism $H_i(K^{(p)}) \xrightarrow{\;\sim\;} H_i(K)$.

### Setup: the relative homology long exact sequence

Consider the long exact sequence of the pair $(K, K^{(p)})$:

$$\cdots \longrightarrow H_{i+1}(K, K^{(p)}) \longrightarrow H_i(K^{(p)}) \xrigh
tarrow{\;\iota_*\;} H_i(K) \longrightarrow H_i(K, K^{(p)}) \longrightarrow H_{i-
1}(K^{(p)}) \longrightarrow \cdots$$

The map $\iota_*$ is an isomorphism if and only if both $H_{i+1}(K, K^{(p)}) = 0
$ and $H_i(K, K^{(p)}) = 0$.

### Computing $H_j(K, K^{(p)})$

The cellular chain complex of the pair $(K, K^{(p)})$ has

$$C_j(K, K^{(p)}) = C_j(K)\,/\,C_j(K^{(p)}).$$

Since $K^{(p)}$ contains all cells of dimension $\le p$, we have $C_j(K^{(p)}) =
 C_j(K)$ for $j \le p$ and $C_j(K^{(p)}) = 0$ for $j > p$. Therefore:

$$C_j(K, K^{(p)}) = \begin{cases} 0 & j \le p, \\ C_j(K) & j > p. \end{cases}$$

Since the relative cellular chain complex is identically zero in degrees $\le p$
:

$$\boxed{H_j(K, K^{(p)}) = 0 \quad \text{for all } j \le p.}$$

### Case 1: $i < p$ (isomorphism holds)

If $i < p$, then $i \le p$ and $i+1 \le p$, so

$$H_i(K, K^{(p)}) = 0 \quad \text{and} \quad H_{i+1}(K, K^{(p)}) = 0.$$

The long exact sequence reduces to

$$0 \longrightarrow H_i(K^{(p)}) \xrightarrow{\;\iota_*\;} H_i(K) \longrightarro
w 0,$$

so $\iota_*$ is an isomorphism:

$$H_i(K^{(p)}) \simeq H_i(K) \quad \text{for } i < p.$$

### Case 2: $i = p$ (isomorphism fails in general)

Here $H_p(K, K^{(p)}) = 0$ but $H_{p+1}(K, K^{(p)})$ may be nonzero. The long ex
act sequence gives

$$H_{p+1}(K, K^{(p)}) \xrightarrow{\;\partial\;} H_p(K^{(p)}) \xrightarrow{\;\io
ta_*\;} H_p(K) \longrightarrow 0,$$

so $\iota_*$ is **surjective** but has kernel $\operatorname{im}(\partial)$, whi
ch is generally nonzero.

Concretely, using the cellular chain complex of $K$:
- $H_p(K^{(p)}) = \ker(d_p: C_p \to C_{p-1})$ (since $K^{(p)}$ has no $(p{+}1)$-
cells, so there is no $d_{p+1}$ term in its chain complex).
- $H_p(K) = \ker(d_p) / \operatorname{im}(d_{p+1})$.

The map $\iota_*$ is the quotient $\ker(d_p) \twoheadrightarrow \ker(d_p)/\opera
torname{im}(d_{p+1})$, with kernel $\operatorname{im}(d_{p+1})$. This is an isom
orphism only if $d_{p+1} = 0$, which fails in general (e.g., any CW-complex with
 a nontrivial $(p{+}1)$-cell attaching map).

**Counterexample:** Take $K = S^{p+1}$ with its standard CW-structure (one $0$-c
ell, one $(p{+}1)$-cell). Then $K^{(p)}$ is a point, so $H_p(K^{(p)}) = 0$, whil
e $H_p(K) = 0$ as well — this happens to work. But take $K$ to be a CW-complex w
ith $H_p(K) \ne 0$ arising from a $(p{+}1)$-cell, e.g., a $(p{+}1)$-ball with it
s boundary identified appropriately. More directly: take $K$ with a $(p{+}1)$-ce
ll whose boundary attaches nontrivially to a $p$-cycle, so that $\operatorname{i
m}(d_{p+1}) \ne 0$ and $H_p(K^{(p)}) \not\cong H_p(K)$.

### Case 3: $i > p$ (isomorphism fails in general)

The $p$-skeleton $K^{(p)}$ has no cells of dimension $> p$, so

$$H_i(K^{(p)}) = 0 \quad \text{for } i > p.$$

But $H_i(K)$ can be nonzero (e.g., $K = S^{p+1}$, $i = p+1$: $H_{p+1}(K) = \math
bb{Z} \ne 0$). Hence no isomorphism holds in general.

### Conclusion

The isomorphism $H_i(K^{(p)}) \simeq H_i(K)$ holds precisely for

$$\boxed{i < p,}$$

i.e., for $i \le p-1$. For $i = p$ the inclusion induces only a surjection, and
for $i > p$ the group $H_i(K^{(p)})$ vanishes while $H_i(K)$ need not.
