We find all ordered triples of primes $(p,q,r)$ satisfying
$$p \mid q^r+1, \quad q \mid r^p+1, \quad r \mid p^q+1.$$

## Step 1: The primes are pairwise distinct

If $p = q$, then $p \mid p^r + 1 \equiv 1 \pmod{p}$, impossible. Similarly $q \n
eq r$ and $r \neq p$.

## Step 2: Order analysis (odd primes)

For an **odd** prime $p$ with $p \nmid q$: from $q^r \equiv -1 \pmod{p}$ we get
$q^{2r} \equiv 1$, so $\operatorname{ord}_p(q) \mid 2r$. Since $q^r \equiv -1 \n
ot\equiv 1 \pmod{p}$ (as $p$ is odd), $\operatorname{ord}_p(q) \nmid r$. The div
isors of $2r$ (with $r$ prime) are $\{1, 2, r, 2r\}$, so $\operatorname{ord}_p(q
) \in \{2, 2r\}$:
- **Small case:** $\operatorname{ord}_p(q) = 2 \Rightarrow q \equiv -1 \pmod{p}
\Rightarrow p \mid q+1$.
- **Large case:** $\operatorname{ord}_p(q) = 2r \Rightarrow 2r \mid p-1 \Rightar
row p \equiv 1 \pmod{2r}$.

The same dichotomy applies to each condition. Label each condition **S** (small)
 or **L** (large).

## Step 3: No solution with all three primes odd

**All Large (LLL):** $p \geq 2r+1$, $q \geq 2p+1$, $r \geq 2q+1$. Chaining: $r \
geq 2q+1 \geq 2(2p+1)+1 = 4p+3 \geq 4(2r+1)+3 = 8r+7$, contradiction.

**All Small (SSS):** $p \mid q+1$, $q \mid r+1$, $r \mid p+1$. Write $q+1 = ap$,
 $r+1 = bq$, $p+1 = cr$ with $a,b,c \geq 1$. Since all primes are odd, $q+1, r+1
, p+1$ are all even, while $p, q, r$ are odd, forcing $a, b, c$ all **even**. Se
tting $a=2a', b=2b', c=2c'$ ($a',b',c' \geq 1$) and eliminating gives
$$p = \frac{4b'c' + 2c' + 1}{8a'b'c' - 1}.$$
For $a' = b' = c' = 1$: $p = 7/7 = 1$, not prime. For any larger values, $8a'b'c
' - 1 > 4b'c' + 2c' + 1$ (since $8a'b'c' \geq 8b'c' > 4b'c' + 2c' + 1$ for $b',
c' \geq 1$ except the boundary case already checked), giving $p < 1$. So no solu
tion.

**Mixed cases (at least one S, at least one L):** In every mixed case, a "large"
 condition and a "small" condition share a variable, forcing a prime to equal 2:

- **LSS** or **LLS**: $p \equiv 1 \pmod{2r}$ (so $p = 2rk+1$) and $r \mid p+1 =
2(rk+1)$, giving $r \mid 2$, so $r = 2$ — contradicts odd.
- **SLS** or **SLL**: $q \equiv 1 \pmod{2p}$ (so $q = 2pk+1$) and $p \mid q+1 =
2(pk+1)$, giving $p \mid 2$, so $p = 2$ — contradicts odd.
- **SSL** or **LSL**: $r \equiv 1 \pmod{2q}$ (so $r = 2qk+1$) and $q \mid r+1 =
2(qk+1)$, giving $q \mid 2$, so $q = 2$ — contradicts odd.

All eight cases are exhausted, so **no solution exists with all primes odd**.

## Step 4: Solutions involving 2

**Two or three 2's:** Direct checking shows none work (e.g., $p=q=2$: $2 \mid 2^
r+1$ fails since $2^r+1$ is odd; etc.).

**Exactly one 2, say $p = 2$** ($q, r$ odd primes): The condition $2 \mid q^r +
1$ is automatic. We need $q \mid r^2 + 1$ and $r \mid 2^q + 1$.

From $r \mid 2^q + 1$: $2^q \equiv -1 \pmod{r}$, so $\operatorname{ord}_r(2) \in
 \{2, 2q\}$.
- $\operatorname{ord}_r(2) = 2$: $r \mid 3$, so $r = 3$. Then $q \mid 3^2 + 1 =
10$, giving $q \in \{2, 5\}$; since $q$ is odd and $q \neq 2$, we get $q = 5$.
- $\operatorname{ord}_r(2) = 2q$: $2q \mid r - 1$, so $r \equiv 1 \pmod{2q}$, i.
e., $r = 2qk + 1$. Then $q \mid r^2 + 1 = (2qk+1)^2 + 1 \equiv 2 \pmod{q}$, forc
ing $q \mid 2$, so $q = 2$ — contradicts $q$ odd.

Thus the unique solution with $p = 2$ is $(p, q, r) = (2, 5, 3)$.

**Verification of $(2, 5, 3)$:**
- $2 \mid 5^3 + 1 = 126$ ✓
- $5 \mid 3^2 + 1 = 10$ ✓
- $3 \mid 2^5 + 1 = 33$ ✓

## Step 5: Cyclic rotations

The system is invariant under the cyclic permutation $(p,q,r) \mapsto (q,r,p)$.
Applying this to $(2,5,3)$ yields $(5,3,2)$ and $(3,2,5)$. Direct verification c
onfirms both:

**$(5,3,2)$:** $5 \mid 3^2+1=10$ ✓, $3 \mid 2^5+1=33$ ✓, $2 \mid 5^3+1=126$ ✓.

**$(3,2,5)$:** $3 \mid 2^5+1=33$ ✓, $2 \mid 5^3+1=126$ ✓, $5 \mid 3^2+1=10$ ✓.

By the cyclic symmetry, any solution with exactly one 2 is a cyclic rotation of
a solution with $p=2$, so these three are all solutions involving 2.

## Conclusion

The complete set of ordered triples is:

$$\boxed{(p, q, r) \in \{(2, 5, 3),\; (5, 3, 2),\; (3, 2, 5)\}}.$$
