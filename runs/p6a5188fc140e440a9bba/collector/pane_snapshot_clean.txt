## Solution

**Setup.** Let $T_n(x)$ denote the expected time to reach state $n$ starting fro
m state $x$, with $0 < x < n$. The boundary/transition conditions are:

- **Reflecting boundary at 0:** $T_n(0) = 1 + T_n(1)$, since $p_{0,1}=1$.
- **Interior recurrence** for $1 \le x \le n-1$: $T_n(x) = 1 + \tfrac{1}{2}T_n(x
+1) + \tfrac{1}{2}T_n(x-1)$.
- **Absorbing boundary:** $T_n(n) = 0$.

**Solving the recurrence.** The interior recurrence rearranges to
$$T_n(x+1) - 2\,T_n(x) + T_n(x-1) = -2.$$

The homogeneous equation $T(x+1)-2T(x)+T(x-1)=0$ has general solution $Cx + D$.
A particular solution is $-x^2$ (since substituting gives $-(x+1)^2+2x^2-(x-1)^2
 = -2$). Thus for $1 \le x \le n$:
$$T_n(x) = -x^2 + Ax + B.$$

**Applying boundary conditions.**

1. $T_n(n) = 0 \Rightarrow -n^2 + An + B = 0 \Rightarrow B = n^2 - An$.

2. The reflecting condition $T_n(0) = 1 + T_n(1)$:
   - $T_n(0) = B$
   - $T_n(1) = -1 + A + B$
   - So $B = 1 + (-1 + A + B) = A + B$, giving $A = 0$.

Therefore $B = n^2$ and
$$T_n(x) = n^2 - x^2.$$

**Verification.**

- $T_n(n) = n^2 - n^2 = 0$ ✓
- $T_n(0) = n^2$, $T_n(1) = n^2 - 1$; check $n^2 = 1 + (n^2 - 1) = n^2$ ✓
- Interior: $1 + \tfrac{1}{2}(n^2-(x\!+\!1)^2) + \tfrac{1}{2}(n^2-(x\!-\!1)^2) =
 1 + n^2 - x^2 - 1 = n^2 - x^2$ ✓
- Small case $n=2, x=1$: direct computation gives $T_2(1)=3 = 4-1$ ✓
- Small case $n=3, x=1$: direct computation gives $T_3(1)=8 = 9-1$ ✓

**Answer.** The expected time to reach state $n$ from state $x$ is

$$\boxed{n^2 - x^2}$$
