## Proof

**Claim.** The least upper bound of the set of order types of countable unions o
f finite sets of ordinals is $\omega_1$, the first uncountable ordinal.

---

**Setup.** Let
$$\mathcal{S} = \Big\{\operatorname{otp}(A,\in) \;:\; A = \bigcup_{n<\omega} F_n
,\; \text{each } F_n \text{ a finite set of ordinals}\Big\}.$$
We show $\mathcal{S} = \omega_1 = \{\alpha : \alpha < \omega_1\}$, hence $\sup \
mathcal{S} = \omega_1$.

---

**Step 1: Every element of $\mathcal{S}$ is a countable ordinal (so $\mathcal{S}
 \subseteq \omega_1$).**

Let $A = \bigcup_{n<\omega} F_n$ with each $F_n$ finite. This is a countable uni
on of finite sets. In ZFC, a countable union of finite sets is countable: the ma
p $(n,k) \mapsto$ the $k$-th element of $F_n$ (under some fixed enumeration of e
ach finite $F_n$) surjects $\omega \times \omega$ onto $A$, and $\omega \times \
omega$ is countable. Hence $A$ is countable.

Since $A$ is a set of ordinals, it is well-ordered by $\in$ (the natural order o
n ordinals). Its order type $\operatorname{otp}(A)$ is an ordinal $\alpha$ with
$|A| = |\alpha|$. As $A$ is countable, $\alpha$ is a countable ordinal, i.e., $\
alpha < \omega_1$.

---

**Step 2: Every countable ordinal belongs to $\mathcal{S}$ (so $\omega_1 \subset
eq \mathcal{S}$).**

Let $\alpha < \omega_1$ be any countable ordinal. Then $\alpha$ is a countable s
et of ordinals (every ordinal is the set of its predecessors). Enumerate $\alpha
 = \{\beta_n : n < \omega\}$ and set $F_n = \{\beta_n\}$. Each $F_n$ is a finite
 (singleton) set of ordinals, and
$$\alpha = \bigcup_{n<\omega} F_n.$$
The order type of $\alpha$ under $\in$ is $\alpha$ itself. Therefore $\alpha \in
 \mathcal{S}$.

---

**Step 3: The least upper bound is $\omega_1$.**

From Steps 1 and 2, $\mathcal{S} = \{\alpha : \alpha < \omega_1\} = \omega_1$ (a
s a set of ordinals). The supremum of all ordinals below $\omega_1$ is $\omega_1
$ itself:

- $\omega_1$ is an upper bound: every $\alpha \in \mathcal{S}$ satisfies $\alpha
 < \omega_1$.
- No smaller ordinal is an upper bound: for any $\beta < \omega_1$, we have $\be
ta \in \mathcal{S}$ and $\beta + 1 \in \mathcal{S}$ with $\beta < \beta+1 < \ome
ga_1$, so $\beta$ is not an upper bound.

Hence $\sup \mathcal{S} = \omega_1$.

---

**Conclusion.** The least upper bound of the set of order types of countable uni
ons of finite sets of ordinals is $\boxed{\omega_1}$, the first uncountable ordi
nal. All the reasoning above is formalizable in ZFC: the countability of countab
le unions of finite sets, the fact that every set of ordinals is well-ordered by
 $\in$, and that $\omega_1$ is the supremum of the countable ordinals are all th
