## Solution

We find all $f:\mathbb{R}\to\mathbb{R}$ satisfying
$$(f(x)+f(y))(f(u)+f(v))=f(xu-yv)+f(xv+yu)\qquad(\star)$$
for all $x,y,u,v\in\mathbb{R}$.

### Step 1: Determine $f(0)$

Set $x=y=u=v=0$:
$$4f(0)^2 = 2f(0)\implies f(0)\bigl(2f(0)-1\bigr)=0,$$
so $f(0)=0$ or $f(0)=\tfrac12$.

### Step 2: Case $f(0)=\tfrac12$

Set $y=v=0$ in $(\star)$:
$$(f(x)+\tfrac12)(f(u)+\tfrac12)=f(xu)+\tfrac12.$$
Define $h(x)=f(x)+\tfrac12$. Substituting and simplifying:
$$h(xu)=h(x)\,h(u)\quad\text{for all }x,u.$$
Since $h(0)=f(0)+\tfrac12=1$, setting $u=0$ gives $h(0)=h(x)\,h(0)$, i.e. $1=h(x
)$. Hence $h\equiv 1$, so
$$f\equiv \tfrac12.$$
**Verification:** LHS $=(\tfrac12+\tfrac12)(\tfrac12+\tfrac12)=1$, RHS $=\tfrac1
2+\tfrac12=1$. ✓

### Step 3: Case $f(0)=0$ — multiplicativity

Set $y=v=0$:
$$f(x)\,f(u)=f(xu)\quad\text{for all }x,u.$$
So $f$ is multiplicative.

Set $u=1,\,v=0$:
$$(f(x)+f(y))\,f(1)=f(x)+f(y)\quad\text{for all }x,y.$$
Either $f(1)=1$, or $f(x)+f(y)=0$ for all $x,y$ (which forces $f\equiv 0$).

**Subcase 3a: $f\equiv 0$.** Verification: LHS $=0$, RHS $=0$. ✓

**Subcase 3b: $f(1)=1$.** We show $f(x)=x^2$.

### Step 4: $f$ is even

Set $x=0$ in $(\star)$ (with $f(0)=0$):
$$f(y)\bigl(f(u)+f(v)\bigr)=f(-yv)+f(yu).$$
Using multiplicativity $f(yu)=f(y)f(u)$:
$$f(y)f(u)+f(y)f(v)=f(-yv)+f(y)f(u)\implies f(y)f(v)=f(-yv).$$
But $f(yv)=f(y)f(v)$, so $f(-yv)=f(yv)$ for all $y,v$. Since $yv$ ranges over al
l reals,
$$f(-t)=f(t)\quad\text{for all }t.$$

### Step 5: A key identity

Set $u=x,\;v=-y$ in $(\star)$. Then $xu-yv=x^2+y^2$ and $xv+yu=-xy+yx=0$, so
$$f(x^2+y^2)+f(0)=\bigl(f(x)+f(y)\bigr)\bigl(f(x)+f(-y)\bigr).$$
Using $f(0)=0$ and $f(-y)=f(y)$:
$$\boxed{f(x^2+y^2)=\bigl(f(x)+f(y)\bigr)^2.}\qquad(\dagger)$$

### Step 6: $f\ge 0$ and reduction to an additive function

From multiplicativity, $f(t^2)=f(t)^2\ge 0$ for all $t$, so $f\ge 0$ on $[0,\inf
ty)$. By evenness, $f\ge 0$ everywhere.

Define $g:[0,\infty)\to[0,\infty)$ by $g(a)=\sqrt{f(a)}$. For $a,b\ge 0$, write
$a=s^2,\,b=t^2$ with $s,t\ge 0$. From $(\dagger)$:
$$g(a+b)^2=f(a+b)=\bigl(f(s)+f(t)\bigr)^2=\bigl(g(a)+g(b)\bigr)^2.$$
Both sides are non-negative, so
$$g(a+b)=g(a)+g(b)\quad\text{for all }a,b\ge 0.$$
Also $g$ is multiplicative on $[0,\infty)$: $g(ab)^2=f(ab)=f(a)f(b)=g(a)^2g(b)^2
$, and non-negativity gives $g(ab)=g(a)\,g(b)$.

### Step 7: $g$ is linear, hence $f(x)=x^2$

Since $g\ge 0$ and additive on $[0,\infty)$: if $a>b\ge 0$, then $g(a)=g(b)+g(a-
b)\ge g(b)$, so $g$ is non-decreasing. An additive, monotone function on $[0,\in
fty)$ is linear: $g(a)=ca$ for some $c\ge 0$.

Now $g(1)=\sqrt{f(1)}=\sqrt{1}=1$, so $c=1$ and $g(a)=a$ for all $a\ge 0$. There
fore
$$f(a)=g(a)^2=a^2\quad\text{for }a\ge 0,$$
and by evenness, $f(x)=x^2$ for all $x\in\mathbb{R}$.

**Verification of $f(x)=x^2$:** LHS $=(x^2+y^2)(u^2+v^2)$. RHS $=(xu-yv)^2+(xv+y
u)^2=x^2u^2-2xuyv+y^2v^2+x^2v^2+2xvyu+y^2u^2=(x^2+y^2)(u^2+v^2)$. ✓

### Conclusion

The three solutions are:
$$\boxed{f\equiv 0,\qquad f\equiv \tfrac12,\qquad f(x)=x^2.}$$
