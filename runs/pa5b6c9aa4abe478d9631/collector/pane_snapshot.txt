## Proof

We interpret "the sum of all ordinals up to ω" as the ordinal sum of every ordin
al strictly below ω, taken in their natural increasing order:

$$S = \sum_{\alpha < \omega} \alpha = 0 + 1 + 2 + 3 + \cdots$$

**Definition of transfinite ordinal sum.** For a sequence of ordinals $\langle \
alpha_i \rangle_{i < \lambda}$ indexed by an ordinal $\lambda$, the sum is defin
ed by transfinite recursion:

$$\sum_{i<0}\alpha_i = 0, \qquad \sum_{i<\beta+1}\alpha_i = \Big(\sum_{i<\beta}\
alpha_i\Big) + \alpha_\beta, \qquad \sum_{i<\lambda}\alpha_i = \sup_{\beta<\lamb
da}\sum_{i<\beta}\alpha_i \;\;(\lambda\text{ limit}).$$

Here the index set is $\lambda = \omega$ (a limit ordinal), and $\alpha_i = i$ f
or $i < \omega$.

**Compute the partial sums.** Let $S_n = \sum_{i<n} i$ for finite $n$.

- $S_0 = 0$
- $S_1 = 0 + 1 = 1$
- $S_2 = 1 + 2 = 3$
- $S_3 = 3 + 3 = 6$
- $S_4 = 6 + 4 = 10$

In general, by induction, $S_n = \frac{n(n-1)}{2}$, which is a **finite** ordina
l for every finite $n$.

**Take the supremum.** Since $\omega$ is a limit ordinal,

$$S = \sum_{i<\omega} i = \sup_{n<\omega} S_n = \sup_{n<\omega} \frac{n(n-1)}{2}
.$$

Each $S_n$ is a finite ordinal, and the sequence $\langle S_n\rangle_{n<\omega}$
 is strictly increasing and unbounded in $\omega$ (given any finite $k$, choose
$n$ large enough that $\frac{n(n-1)}{2} > k$). The supremum of a cofinal set of
finite ordinals in $\omega$ is exactly $\omega$:

$$\sup_{n<\omega} S_n = \omega.$$

**Why not larger.** Every partial sum $S_n$ is finite, so no partial sum reaches
 or exceeds $\omega$. The supremum of a set of ordinals all below $\omega$ that
is cofinal in $\omega$ is precisely $\omega$ — it cannot be $\omega+1$ or anythi
ng larger, since $\omega$ is already an upper bound and is itself the least uppe
r bound (no smaller ordinal bounds all the $S_n$).

**Conclusion.**

$$\boxed{\sum_{\alpha<\omega}\alpha = 0+1+2+3+\cdots = \omega.}$$

The sum of all ordinals up to (strictly below) $\omega$ is $\omega$ itself.
