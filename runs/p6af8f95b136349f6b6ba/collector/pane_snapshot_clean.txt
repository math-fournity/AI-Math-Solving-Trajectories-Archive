# Solution

**Yes, we can conclude that $a_i = 0$ for all $i \geq 1$.**

## Proof

Define $g(z) = |P(z)|$ for $|z|<1$ and $g(\omega)=1$ for $|\omega|=1$. We first
show $g$ is continuous on the closed disc $\overline{\mathbb{D}}$.

- **On the open disc**, $g=|P|$ is continuous since $P$ is analytic there.
- **At any boundary point** $\omega$ with $|\omega|=1$: by hypothesis $\lim_{z\t
o\omega,\, z\in\mathbb{D}}|P(z)|=1=g(\omega)$, and for $z$ on the boundary $g(z)
\equiv 1$. So for any sequence $z_n\to\omega$ in $\overline{\mathbb{D}}$ (interi
or or boundary), $g(z_n)\to 1=g(\omega)$.

Since $g$ is continuous on the compact set $\overline{\mathbb{D}}$, it is **unif
ormly continuous**. Because $g\equiv 1$ on $\partial\mathbb{D}$, uniform continu
ity gives: for every $\varepsilon>0$ there exists $\delta>0$ such that $1-\delta
<|z|<1$ implies $\bigl||P(z)|-1\bigr|<\varepsilon$.

(Indeed, for such $z$, set $\omega=z/|z|$; then $|z-\omega|=1-|z|<\delta$, so $|
g(z)-g(\omega)|<\varepsilon$.)

Therefore $\max_{|\zeta|=r}|P(\zeta)|\to 1$ as $r\to 1^-$.

**Applying the maximum modulus principle.** For any $r<1$ and $|z|\le r$:
$$|P(z)|\le \max_{|\zeta|=r}|P(\zeta)|.$$
Fixing $z\in\mathbb{D}$ and letting $r\to 1^-$ (so that $|z|<r$ for $r$ sufficie
ntly close to $1$):
$$|P(z)|\le \lim_{r\to 1^-}\max_{|\zeta|=r}|P(\zeta)|=1.$$

Hence $|P(z)|\le 1$ for all $z\in\mathbb{D}$.

**Conclusion.** Since $P(0)=1$, we have $|P(0)|=1$, so $|P|$ attains its maximum
 value $1$ at the **interior point** $z=0$. By the maximum modulus principle, $P
$ is constant on $\mathbb{D}$. Since $P(0)=1$, we get $P\equiv 1$, which forces
$$a_i=0 \quad\text{for all } i\ge 1. \qquad\blacksquare$$
