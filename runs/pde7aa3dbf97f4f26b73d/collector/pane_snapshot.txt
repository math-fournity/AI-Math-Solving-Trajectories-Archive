# Free Actions on ℝ Imply Abelian

**Answer: Yes.** A group acting freely on ℝ by homeomorphisms must be abelian (i
ndeed, isomorphic to a subgroup of (ℝ,+)).

---

## Proof

Let $G$ act freely on $\mathbb{R}$ by homeomorphisms, meaning: for every $g \neq
 e$, the homeomorphism $x \mapsto g\cdot x$ has no fixed point.

### Step 1. Every non-identity element is orientation-preserving.

A homeomorphism of $\mathbb{R}$ is either strictly increasing (orientation-prese
rving) or strictly decreasing (orientation-reversing). Let $f$ be orientation-re
versing. Then $f$ is a strictly decreasing bijection $\mathbb{R}\to\mathbb{R}$,
so $f(x)\to +\infty$ as $x\to -\infty$ and $f(x)\to -\infty$ as $x\to +\infty$.
The continuous function $f(x)-x$ satisfies $f(x)-x \to +\infty$ as $x\to -\infty
$ and $f(x)-x \to -\infty$ as $x\to +\infty$. By the Intermediate Value Theorem,
 $f(x_0)=x_0$ for some $x_0$, i.e., $f$ has a fixed point.

Since the action is free, no non-identity element has a fixed point. Therefore *
*every $g\neq e$ is orientation-preserving** (strictly increasing).

### Step 2. A bi-invariant total order on $G$.

Fix a basepoint $x_0\in\mathbb{R}$. The orbit map $g\mapsto g(x_0)$ is **injecti
ve**: if $g(x_0)=h(x_0)$, then $h^{-1}g(x_0)=x_0$, so $h^{-1}g=e$ by freeness, h
ence $g=h$.

Define $g < h \iff g(x_0) < h(x_0)$. This is a total order on $G$.

**Left-invariance.** If $g<h$, then $g(x_0)<h(x_0)$. Since $k$ is orientation-pr
eserving (hence order-preserving), $k(g(x_0))<k(h(x_0))$, i.e., $(kg)(x_0)<(kh)(
x_0)$, so $kg<kh$. ✓

**Right-invariance.** If $g<h$, then $h^{-1}g(x_0)<x_0$. The element $h^{-1}g$ i
s orientation-preserving (composition of orientation-preserving maps) and satisf
ies $h^{-1}g(x_0)<x_0$. By freeness, $h^{-1}g\neq e$ moves every point strictly
in one direction; since it moves $x_0$ to the left, it moves **every** point to
the left:
$$h^{-1}g(y) < y \quad\text{for all } y\in\mathbb{R},$$
i.e., $g(y)<h(y)$ for all $y$. In particular, for $y=k(x_0)$: $g(k(x_0))<h(k(x_0
))$, i.e., $gk(x_0)<hk(x_0)$, so $gk<hk$. ✓

Thus $(G,<)$ is a **bi-ordered group**.

### Step 3. The order is Archimedean.

We show: for any $g, h > e$, there exists $n\geq 1$ with $g^n > h$.

Since $g>e$, we have $g(x)>x$ for all $x$ (the element $g$ moves $x_0$ to the ri
ght, hence by the argument above moves every point to the right). The sequence $
a_n = g^n(x_0)$ is strictly increasing. If it were bounded, $a_n\to L<\infty$, a
nd by continuity $g(L)=L$, contradicting freeness. Hence $g^n(x_0)\to +\infty$.

Since $h(x_0)$ is a finite real number, there exists $n$ with $g^n(x_0) > h(x_0)
$, i.e., $g^n > h$. ✓

### Step 4. Apply Hölder's Theorem.

**Hölder's Theorem.** Every Archimedean bi-ordered group is order-isomorphic to
a subgroup of $(\mathbb{R},+)$.

By Steps 2–3, $G$ is an Archimedean bi-ordered group. By Hölder's theorem, $G$ e
mbeds into $(\mathbb{R},+)$, which is abelian. Therefore **$G$ is abelian**. $\b
lacksquare$

---

**Remark.** The hypothesis that the action is by *homeomorphisms* is essential.
For a purely set-theoretic (free) action on $\mathbb{R}$ as a set, any group of
cardinality $\leq |\mathbb{R}|$ acts freely (partition $\mathbb{R}$ into orbits
of size $|G|$), so non-abelian groups like $S_3$ act freely set-theoretically. T
he topological rigidity of $\mathbb{R}$—specifically, that orientation-reversing
 homeomorphisms always have fixed points and that iterates of fixed-point-free i
ncreasing homeomorphings diverge to $\pm\infty$—is what forces the Archimedean p
roperty and hence abelianness.
