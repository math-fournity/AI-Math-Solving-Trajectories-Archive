## Solution

**Setup.** Let $O$ be the foot of the perpendicular from $S$ to the base plane $
ABCD$, and let $h = SO$ be the height of the pyramid. For each base edge, say $A
B$, drop the perpendicular from $O$ to line $AB$ meeting it at $P_{AB}$; by the
three-perpendiculars theorem, $SP_{AB} \perp AB$, and the dihedral angle $\alpha
_{AB}$ at edge $AB$ satisfies
$$\tan \alpha_{AB} = \frac{h}{|OP_{AB}|}.$$

**Step 1: $O$ is equidistant from all four sides.** Since all four dihedral angl
es are equal,
$$\frac{h}{d_{AB}} = \frac{h}{d_{BC}} = \frac{h}{d_{CD}} = \frac{h}{d_{DA}},$$
so $d_{AB} = d_{BC} = d_{CD} = d_{DA} =: r$. Thus $O$ is the incenter of $ABCD$
and $r$ is its inradius; in particular $ABCD$ is tangential. Since $ABCD$ is als
o cyclic, it is **bicentric**.

**Step 2: Side lengths are proportional to face areas.** The altitude from $S$ t
o edge $AB$ in $\triangle SAB$ has length $SP_{AB} = \sqrt{h^2 + r^2}$, the same
 for every edge. Hence
$$[SAB] = \tfrac12|AB|\sqrt{h^2+r^2},\quad [SBC]=\tfrac12|BC|\sqrt{h^2+r^2},\qua
d \ldots$$
so $|AB|:|BC|:|CD|:|DA| = 9:9:27:27 = 1:1:3:3$. Set
$$|AB|=|BC|=a,\qquad |CD|=|DA|=3a.$$

**Step 3: Determine $a$ from the base area.** $ABCD$ is cyclic with sides $a,a,3
a,3a$. By Brahmagupta's formula, with semiperimeter $s = 4a$:
$$K = \sqrt{(4a-a)(4a-a)(4a-3a)(4a-3a)} = \sqrt{3a\cdot 3a\cdot a\cdot a} = 3a^2
.$$
Given $K = 36$: $3a^2 = 36$, so $a^2 = 12$, i.e. $a = 2\sqrt{3}$.

(Pitot's theorem $a+3a = a+3a$ holds, confirming tangentiality; for a cyclic qua
drilateral, Pitot is sufficient for bicentricity, so the configuration is consis
tent.)

**Step 4: Find the inradius $r$.** For a tangential quadrilateral, $K = r\cdot s
$:
$$r = \frac{K}{s} = \frac{36}{4a} = \frac{36}{8\sqrt{3}} = \frac{9}{2\sqrt{3}} =
 \frac{3\sqrt{3}}{2},\qquad r^2 = \frac{27}{4}.$$

**Step 5: Find the height $h$.** From $[SAB] = \frac12 a\sqrt{h^2+r^2} = 9$:
$$\sqrt{h^2+r^2} = \frac{18}{a} = \frac{18}{2\sqrt{3}} = 3\sqrt{3},\qquad h^2 +
r^2 = 27.$$
$$h^2 = 27 - \frac{27}{4} = \frac{81}{4},\qquad h = \frac{9}{2}.$$

(Check: $[SCD] = \frac12\cdot 3a\cdot 3\sqrt{3} = \frac12\cdot 6\sqrt{3}\cdot 3\
sqrt{3} = 27.$ ✓)

**Step 6: Volume.**
$$V = \frac13\,K\,h = \frac13\cdot 36\cdot\frac{9}{2} = \frac{324}{6} = 54.$$

Final Answer: $\boxed{54}$
