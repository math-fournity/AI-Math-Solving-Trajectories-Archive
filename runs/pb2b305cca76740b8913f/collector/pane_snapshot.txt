## Solution

We wish to maximize $f(\alpha,\beta,\gamma) = 3\cos\alpha + 4\cos\beta + 5\cos\g
amma$ subject to $\alpha+\beta+\gamma=\pi$, $\alpha,\beta,\gamma \geq 0$.

### Setting up the Lagrange conditions

Substitute $\gamma = \pi - \alpha - \beta$, so $\cos\gamma = -\cos(\alpha+\beta)
$:
$$f = 3\cos\alpha + 4\cos\beta - 5\cos(\alpha+\beta).$$

Setting partial derivatives to zero:
$$\frac{\partial f}{\partial \alpha} = -3\sin\alpha + 5\sin(\alpha+\beta) = 0, \
qquad \frac{\partial f}{\partial \beta} = -4\sin\beta + 5\sin(\alpha+\beta) = 0.
$$

Since $\alpha+\beta = \pi-\gamma$, we have $\sin(\alpha+\beta)=\sin\gamma$, givi
ng the elegant condition
$$3\sin\alpha = 4\sin\beta = 5\sin\gamma. \tag{$*$}$$

### Identifying the critical point via a triangle

Condition $(*)$ gives $\sin\alpha:\sin\beta:\sin\gamma = \tfrac{1}{3}:\tfrac{1}{
4}:\tfrac{1}{5} = 20:15:12$. By the **Law of Sines**, these are exactly the angl
es of a triangle with sides $a=20,\; b=15,\; c=12$ (opposite $\alpha,\beta,\gamm
a$ respectively). This is a valid triangle since $20 < 15+12$, etc. The angles a
re uniquely determined, so there is a **unique** interior critical point.

Using the Law of Cosines:
$$\cos\alpha = \frac{b^2+c^2-a^2}{2bc} = \frac{225+144-400}{360} = \frac{-31}{36
0},$$
$$\cos\beta = \frac{a^2+c^2-b^2}{2ac} = \frac{400+144-225}{480} = \frac{319}{480
},$$
$$\cos\gamma = \frac{a^2+b^2-c^2}{2ab} = \frac{400+225-144}{600} = \frac{481}{60
0}.$$

### Computing the value

$$f = 3\cdot\frac{-31}{360} + 4\cdot\frac{319}{480} + 5\cdot\frac{481}{600} = \f
rac{-31}{120} + \frac{319}{120} + \frac{481}{120} = \frac{769}{120}.$$

### Boundary analysis (verifying this is the global maximum)

The domain is compact, so $f$ attains its maximum. We check all three edges:

- **$\gamma=0$** ($\alpha+\beta=\pi$): $f = 3\cos\alpha - 4\cos\alpha + 5 = 5 -
\cos\alpha$, max $= 6$ at $\alpha=\pi$.
- **$\alpha=0$** ($\beta+\gamma=\pi$): $f = 3 + 4\cos\beta - 5\cos\beta = 3 - \c
os\beta$, max $= 4$ at $\beta=\pi$.
- **$\beta=0$** ($\alpha+\gamma=\pi$): $f = 3\cos\alpha + 4 - 5\cos\alpha = 4 -
2\cos\alpha$, max $= 6$ at $\alpha=\pi$.

The vertices give values $6, 4, 2$. Thus the **boundary maximum is $6$**.

Since $\dfrac{769}{120} \approx 6.408 > 6$, the unique interior critical point e
xceeds every boundary value, and therefore it is the **global maximum**.

### Answer

$$\boxed{\dfrac{769}{120}}$$
