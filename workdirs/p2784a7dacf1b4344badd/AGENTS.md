# Problem

In a remote industrial facility, there are exactly 2014 pressure valves. Each valve is set to an integer pressure level ranging from 1 to 6.

The facility operates under a specific protocol for adjusting these valves: an engineer must select exactly $t$ valves to adjust simultaneously. When a valve is adjusted, its pressure level increases by 1 (e.g., from 3 to 4). However, if a valve is already at the maximum pressure of 6, the adjustment cycles it back to the minimum pressure of 1.

A "synchronization constant" $t$ is considered "universal" if, regardless of the initial pressure settings of the 2014 valves, there exists a finite sequence of moves (each involving exactly $t$ valves) that results in every single valve in the facility being set to pressure level 6.

Let $S$ be the set of all possible universal synchronization constants $t$ such that $1 \leq t \leq 2014$. Find the sum of all elements in $S$.
