## Proof

### Setup and notation

Let $M$ be an $n$-dimensional smooth manifold with local coordinates $\{x^a\}$.
The **coordinate basis** for vector fields is $\{e_a = \partial/\partial x^a\}$
and the **dual basis** for covector fields is $\{e^a = dx^a\}$, satisfying $e^a(
e_b) = \delta^a_b$.

The components of the basis vector $e_a$ in the coordinate basis are:
$$(e_a)^b = \delta^b_a$$
and the components of the dual basis covector $e^a$ are:
$$(e^a)_c = \delta^a_c.$$
Both are (componentwise) constant functions — the Kronecker delta.

Let $\nabla$ be a general affine connection. The **connection coefficients** are
 defined by the action of $\nabla$ on the coordinate basis vectors:
$$\nabla_c \, e_a \;=\; \Gamma^b{}_{ac}\, e_b, \qquad \text{i.e., } \nabla_{\par
tial_c} \partial_a = \Gamma^b{}_{ac}\,\partial_b.$$
Here $c$ is the direction of differentiation, $a$ labels the vector being differ
entiated, and $b$ is the component index.

### Part 1: Obtaining $\Gamma^b{}_{ac}$ from $\nabla_c\,\delta^b_a$

Since $(e_a)^b = \delta^b_a$, taking the $b$-th component of $\nabla_c e_a = \Ga
mma^d{}_{ac}\,e_d$ gives:
$$(\nabla_c\, e_a)^b = \Gamma^d{}_{ac}\,(e_d)^b = \Gamma^d{}_{ac}\,\delta^b_d =
\Gamma^b{}_{ac}.$$

The left side is precisely the covariant derivative of the vector field whose co
mponents are $\delta^b_a$ (with $a$ held fixed as a label). We denote this $\nab
la_c\,\delta^b_a$. Therefore:

$$\boxed{\Gamma^b{}_{ac} = \nabla_c\,\delta^b_a.}$$

**Explicit verification via the vector covariant-derivative formula.** For a vec
tor field $V$ with components $V^b$, the covariant derivative is $(\nabla_c V)^b
 = \partial_c V^b + \Gamma^b{}_{dc}\,V^d$. Setting $V^b = \delta^b_a$ (constant,
 so $\partial_c \delta^b_a = 0$):
$$(\nabla_c\, \delta^\bullet_a)^b = \partial_c\,\delta^b_a + \Gamma^b{}_{dc}\,\d
elta^d_a = 0 + \Gamma^b{}_{ac} = \Gamma^b{}_{ac}. \quad\checkmark$$

The partial-derivative term vanishes precisely because the coordinate basis vect
ors have **constant** Kronecker-delta components. The entire content of the conn
ection is carried by the $\Gamma$ term. This is the key observation: **the conne
ction coefficients are exactly what $\nabla$ produces when acting on the constan
t-component basis vectors.**

### Part 2: Obtaining $\Gamma^b{}_{ac}$ from $\nabla_b\,\delta^a_c$ (the dual re

$$0 = \nabla_b\bigl(e^a(e_c)\bigr) = (\nabla_b\, e^a)(e_c) + e^a(\nabla_b\, e_c)

$$(\nabla_b\, e^a)(e_c) = -\,e^a\!\left(\Gamma^d{}_{cb}\,e_d\right) = -\,\Gamma^
d{}_{cb}\,\delta^a_d = -\,\Gamma^a{}_{cb}.$$

Thus the dual basis transforms as:
$$\nabla_b\, e^a = -\,\Gamma^a{}_{cb}\,e^c.$$

Now $(e^a)_c = \delta^a_c$, so taking the $c$-th component:

$$(\nabla_b\, e^a)_c = -\,\Gamma^a{}_{cb}.$$

We denote this $\nabla_b\,\delta^a_c$, giving:

$$\nabla_b\,\delta^a_c = -\,\Gamma^a{}_{cb}.$$

**Explicit verification via the covector covariant-derivative formula.** For a c

$$(\nabla_b\, \delta^a_\bullet)_c = \partial_b\,\delta^a_c - \Gamma^d{}_{cb}\,\d

### Part 3: Coordinate expression for $\nabla$ on a general tensor

A general $(r,s)$-tensor field is written in components as:
$$T = T^{a_1\cdots a_r}{}_{b_1\cdots b_s}\; e_{a_1}\otimes\cdots\otimes e_{a_r}\

Apply $\nabla_c$ using the Leibniz rule. The component functions $T^{a_1\cdots a

i$).

Collecting all terms, the components of the covariant derivative $\nabla_c T$ ar

$$\boxed{(\nabla_c\, T)^{a_1\cdots a_r}{}_{b_1\cdots b_s} = \partial_c\, T^{a_1\

s \underset{i}{d}\cdots a_r}{}_{b_1\cdots b_s} - \sum_{j=1}^{s} \Gamma^{d}{}_{b_
j c}\, T^{a_1\cdots a_r}{}_{b_1\cdots \underset{j}{d}\cdots b_s}.}$$

This is the **coordinate expression for the action of $\nabla$ on any tensor**.
It consists of:
1. The **ordinary partial derivative** $\partial_c$ of the components (the "coor

2. One **$+\Gamma$ correction** for each contravariant (upper) index, and
3. One **$-\Gamma$ correction** for each covariant (lower) index.

### Part 4: Consistency check — recovering the $\Gamma$ relations from the gener

$$(\nabla_c\, e_a)^b = \underbrace{\partial_c\,\delta^b_a}_{=\,0} + \Gamma^b{}_{

This recovers $\Gamma^b{}_{ac} = \nabla_c\,\delta^b_a$.

**Covector field** ($r=0, s=1$): The formula gives $(\nabla_b\,\omega)_c = \part

$$(\nabla_b\, e^a)_c = \underbrace{\partial_b\,\delta^a_c}_{=\,0} - \Gamma^d{}_{

This recovers $\nabla_b\,\delta^a_c = -\Gamma^a{}_{cb}$, i.e., $\Gamma^a{}_{cb}

$$\nabla_c\,\delta^a_b = \partial_c\,\delta^a_b + \Gamma^a{}_{dc}\,\delta^d_b -

The $+\Gamma$ from the upper index exactly cancels the $-\Gamma$ from the lower
