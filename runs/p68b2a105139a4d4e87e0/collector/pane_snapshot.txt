## Proof that $P_m \mid \text{size}_j, p_j = 1 \mid \sum T_i$ is polynomially so
lvable for fixed $m$

### Problem setup

We have $n$ tasks. Task $j$ requires $\text{size}_j \in \{1, 2, \dots, m\}$ proc
essors simultaneously, has unit processing time $p_j = 1$, and a due date $d_j$.
 There are $m$ identical parallel processors. At each integer time slot $t = 0,
1, 2, \dots$, the total processor demand of tasks scheduled in that slot must no
t exceed $m$. The objective is to minimize total tardiness $\sum_{j=1}^n T_j$ wh
ere $T_j = \max(0, C_j - d_j)$ and $C_j$ is the completion time of task $j$.

### Lemma 1 (EDD order within each size class)

*In an optimal schedule, tasks of the same size are processed in non-decreasing
due-date (EDD) order.*

**Proof.** Consider two tasks $i, j$ with $\text{size}_i = \text{size}_j = s$, $
d_i \le d_j$, scheduled in slots giving completion times $C_j = a$ and $C_i = a+
1$ (task $j$ before task $i$, in consecutive slots). Since both have the same si
ze, swapping their slots preserves feasibility. After swapping, $C_i' = a$, $C_j
' = a+1$. We show $T_i' + T_j' \le T_i + T_j$.

Define $f(d) = \max(0, a - d) - \max(0, a+1 - d)$. The swap does not increase to
tal tardiness iff $f(d_i) \le f(d_j)$, i.e., $f$ is non-decreasing. Computing:

- If $d \le a$: $f(d) = (a-d) - (a+1-d) = -1$.
- If $a < d \le a+1$: $f(d) = 0 - (a+1-d) = d - a - 1 \in [-1, 0]$.
- If $d > a+1$: $f(d) = 0 - 0 = 0$.

So $f$ is non-decreasing in $d$, confirming $f(d_i) \le f(d_j)$ when $d_i \le d_
j$. Repeated swaps eliminate all inversions without increasing total tardiness.
$\square$

If two same-size tasks share a slot, $C_i = C_j$ and no swap is needed. Thus EDD
 order within each size class is established.

### Lemma 2 (Bounded configurations per slot)

*For fixed $m$, the number of feasible slot configurations is bounded by a const
ant depending only on $m$.*

**Proof.** A slot configuration is a vector $(k_1, k_2, \dots, k_m)$ of non-nega
tive integers with $\sum_{s=1}^m s \cdot k_s \le m$, where $k_s$ is the number o
f size-$s$ tasks in the slot. The number of such vectors equals the number of pa
rtitions of all integers up to $m$ using parts from $\{1, \dots, m\}$, which is
at most $\sum_{q=0}^{m} p(q) \le (m+1)\cdot p(m)$, where $p(\cdot)$ is the parti
tion function. This is a constant for fixed $m$. $\square$

### Dynamic programming algorithm

**Preprocessing.** Partition tasks by size. For each size $s \in \{1, \dots, m\}
$, let $\mathcal{T}_s = \{j : \text{size}_j = s\}$ with $n_s = |\mathcal{T}_s|$.
 Sort each $\mathcal{T}_s$ by EDD: $d_{s,1} \le d_{s,2} \le \dots \le d_{s,n_s}$
.

**State.** $DP[t; i_1, i_2, \dots, i_m]$ = minimum total tardiness achievable ha
ving scheduled, in slots $0, 1, \dots, t-1$, the first $i_s$ tasks of each size
class $s$ (in EDD order).

**Base case.** $DP[0; 0, 0, \dots, 0] = 0$.

**Transition.** For each feasible configuration $(k_1, \dots, k_m)$ with $\sum_s
 s \cdot k_s \le m$ and $k_s \le n_s - i_s$:

$$DP\!\left[t+1;\; i_1+k_1,\; \dots,\; i_m+k_m\right] = \min\left\{ DP[t; i_1, \
dots, i_m] + \sum_{s=1}^{m} \sum_{\ell=1}^{k_s} \max\!\big(0,\; (t+1) - d_{s,\,
i_s + \ell}\big) \right\}.$$

This schedules tasks $i_s+1, \dots, i_s+k_s$ of size $s$ in slot $t$ (completing
 at $t+1$), with tardiness contributions computed from their EDD-ordered due dat
es.

**Answer.** $\min_{t} DP[t; n_1, n_2, \dots, n_m]$ (all tasks scheduled; $t$ ran
ges up to $n$).

### Correctness

By Lemma 1, restricting to EDD order within each size class incurs no loss of op
timality. The DP enumerates all ways to interleave the EDD-ordered sequences int
o slots, respecting the processor capacity constraint via feasible configuration
s (Lemma 2). Every feasible schedule respecting EDD-within-size-class correspond
s to a path through the DP, and vice versa. Thus the DP computes the optimal tot
al tardiness.

### Complexity analysis

- **State space:** $t \in \{0, \dots, n\}$ and $i_s \in \{0, \dots, n_s\}$ for e
ach $s$, giving
$$\text{States} \le (n+1) \cdot \prod_{s=1}^{m}(n_s + 1) \le (n+1)^{m+1} = O(n^{
m+1}).$$

- **Transitions per state:** At most $C(m) = O(p(m))$ feasible configurations, a
 constant for fixed $m$.

- **Cost per transition:** $O(m)$ to sum tardiness contributions (at most $m$ ta
sks per slot).

- **Total time:** $O(n^{m+1} \cdot m \cdot p(m)) = O(n^{m+1})$ for fixed $m$.

- **Space:** $O(n^{m+1})$ (or $O(n^m)$ with rolling arrays over $t$).

Since $m$ is a fixed constant, $n^{m+1}$ is polynomial in $n$. The algorithm is
**strongly polynomial** — its running time does not depend on the magnitude of t
he due dates.

### Conclusion

The problem $P_m \mid \text{size}_j, p_j = 1 \mid \sum T_i$ is **polynomially so
lvable** when the number of processors $m$ is fixed. Specifically, it can be sol
ved in $O(n^{m+1})$ time by dynamic programming, where $n$ is the number of task
s. The key ingredients are:

1. **Unit processing times** reduce the schedule to assigning tasks to discrete
time slots.
2. **The EDD exchange argument** (Lemma 1) fixes the task order within each size
 class, reducing the problem to interleaving $m$ sorted sequences.
3. **Fixed $m$** bounds the number of feasible slot configurations by a constant
 (Lemma 2), keeping the DP state space polynomial at $O(n^{m+1})$.

This places the problem in the class **P** for every fixed value of $m$.
