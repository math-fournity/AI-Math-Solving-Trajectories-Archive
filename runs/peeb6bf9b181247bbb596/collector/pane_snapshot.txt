# Morley Rank of $x = x$ in ACF$_0$

## Answer

The Morley rank of the type $x = x$ (equivalently, the formula $x = x$) in ACF$_
0$ is **1**.

## Proof

We work in a sufficiently saturated model $\mathbb{K} \models \text{ACF}_0$. Rec
all the inductive definition of Morley rank:

- $\mathrm{MR}(\varphi) \geq 0$ if $\varphi$ is consistent.
- $\mathrm{MR}(\varphi) \geq \alpha + 1$ if there exist infinitely many pairwise
 inconsistent formulas $\{\varphi_i\}_{i < \omega}$, each $\varphi_i \vdash \var
phi$, with $\mathrm{MR}(\varphi_i) \geq \alpha$.
- $\mathrm{MR}(\varphi) \geq \lambda$ (limit) if $\mathrm{MR}(\varphi) \geq \alp
ha$ for all $\alpha < \lambda$.

The key fact in ACF is that **Morley rank equals the Krull (Zariski) dimension**
 of the definable set (more precisely, of its Zariski closure). The formula $x =
 x$ defines the entire affine line $\mathbb{A}^1(\mathbb{K}) = \mathbb{K}$.

### Step 1: $\mathrm{MR}(x = x) \geq 1$

For each $a \in \mathbb{K}$, consider the formula $\varphi_a := (x = a)$. Each $
\varphi_a$ is consistent (so $\mathrm{MR}(\varphi_a) \geq 0$), each implies $x =
 x$, and the formulas $\{\varphi_a\}_{a \in \mathbb{K}}$ are pairwise inconsiste
nt. Since $\mathbb{K}$ is infinite (algebraically closed fields are infinite), t
here are infinitely many such formulas. By the definition, $\mathrm{MR}(x = x) \
geq 1$.

### Step 2: $\mathrm{MR}(x = x) \not\geq 2$

Suppose for contradiction that $\mathrm{MR}(x = x) \geq 2$. Then there exist inf
initely many pairwise inconsistent formulas $\{\psi_i\}_{i < \omega}$, each $\ps
i_i \vdash (x = x)$, with $\mathrm{MR}(\psi_i) \geq 1$.

Each $\psi_i$ defines a definable subset $D_i \subseteq \mathbb{K}$. By the corr
espondence between Morley rank and Zariski dimension in ACF, $\mathrm{MR}(\psi_i
) \geq 1$ means the Zariski closure $\overline{D_i}^{\,\text{Zar}}$ has Krull di
mension $\geq 1$.

The Zariski closed subsets of $\mathbb{A}^1$ are: the whole line $\mathbb{A}^1$
(dimension 1), and finite sets (dimension 0). So $\overline{D_i}^{\,\text{Zar}}$
 having dimension $\geq 1$ forces $\overline{D_i}^{\,\text{Zar}} = \mathbb{A}^1$
, i.e., $D_i$ is **Zariski dense** in $\mathbb{A}^1$.

In ACF, definable subsets of $\mathbb{A}^1$ are either finite or cofinite (this
is quantifier elimination plus the fact that a definable subset of the line is a
 Boolean combination of algebraic sets, which in dimension 1 are finite or the w
hole line). Since $D_i$ is Zariski dense, $D_i$ cannot be finite, so $D_i$ is **
cofinite**: $\mathbb{K} \setminus D_i$ is finite.

But the $D_i$ are pairwise disjoint (the $\psi_i$ are pairwise inconsistent). Tw
o cofinite subsets of an infinite set cannot be disjoint, since $|D_i \cap D_j|
\geq |\mathbb{K}| - |\mathbb{K} \setminus D_i| - |\mathbb{K} \setminus D_j|$, an
d both complements are finite while $\mathbb{K}$ is infinite. In particular, eve
n two cofinite sets must intersect. This contradicts pairwise disjointness, so w
e cannot have infinitely many pairwise inconsistent definable subsets of $\mathb
b{K}$ each of Morley rank $\geq 1$.

Therefore $\mathrm{MR}(x = x) \not\geq 2$.

### Conclusion

Combining Steps 1 and 2:

$$1 \leq \mathrm{MR}(x = x) < 2,$$

so $\mathrm{MR}(x = x) = 1$.

This agrees with the general principle: in ACF, the Morley rank of $\mathbb{A}^n
$ is $n$, and $x = x$ defines $\mathbb{A}^1$, which has Morley rank $1$.
