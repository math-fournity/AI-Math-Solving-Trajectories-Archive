Looking at this problem, I need to find the maximum dimension of $\ker(A - I)$ o
ver all symmetric zero-diagonal matrices $A \in \mathbb{F}_2^{n \times n}$.

## Proof

**Setup.** Over $\mathbb{F}_2$, we have $-1 = 1$, so the eigenvalue-1 subspace i
s
$$\ker(A - I) = \ker(A + I).$$
Set $B = A + I$. Since $A$ is symmetric with zero diagonal, $B$ is symmetric wit
h $B_{ii} = A_{ii} + 1 = 0 + 1 = 1$ for every $i$. Conversely, any symmetric $B$
 with all diagonal entries $1$ yields $A = B + I$ symmetric with zero diagonal.
Thus the problem is equivalent to:

> Maximize $\dim \ker(B)$ over symmetric $B \in \mathbb{F}_2^{n \times n}$ with
$B_{ii} = 1$ for all $i$.

**Upper bound.** Since every diagonal entry of $B$ equals $1 \neq 0$, the matrix
 $B$ is not the zero matrix, so $\operatorname{rank}(B) \geq 1$. By rank–nullity
,
$$\dim \ker(B) = n - \operatorname{rank}(B) \leq n - 1.$$

**Lower bound (construction).** Let $J$ be the $n \times n$ all-ones matrix. The
n $J$ is symmetric with $J_{ii} = 1$, and $J$ has rank $1$ (every row is identic
al). Take $A = J + I$:
- $A_{ii} = 1 + 1 = 0$, so $A$ has zero diagonal. ✓
- $A$ is symmetric. ✓
- $A + I = J + I + I = J$ (since $I + I = 0$ over $\mathbb{F}_2$).

Now $\ker(A + I) = \ker(J)$. Since every row of $J$ is $\mathbf{1}^T$, we have $
Jv = \left(\sum_{i} v_i\right) \mathbf{1}$, so
$$\ker(J) = \left\{v \in \mathbb{F}_2^n : \sum_{i=1}^n v_i = 0\right\},$$
the even-weight subspace, which has dimension $n - 1$.

**Conclusion.** The upper bound $n - 1$ is achieved by the construction, so the
maximal dimension of the eigenvalue-1 subspace is

$$\boxed{n - 1}.$$
