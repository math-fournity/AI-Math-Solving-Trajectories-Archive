## Proof

**Prefix sum reformulation.** Let $S_0 = 0$ and $S_k = a_1 + a_2 + \cdots + a_k$
 for $k = 1, \dots, n$. A consecutive block from zone $i+1$ to zone $j$ sums to
$S_j - S_i$. The ship is optimally balanced iff some $S_j - S_i = 30$, i.e., two
 prefix sums differ by exactly 30.

Thus the problem reduces to: find the smallest $n$ such that every $(n+1)$-eleme
nt subset $A = \{S_0, S_1, \dots, S_n\} \subseteq \{0, 1, \dots, 2007\}$ with $0
 \in A$, $2007 \in A$, and all elements distinct and increasing, must contain tw

Equivalently, find the **maximum** size of a subset $A \subseteq \{0, 1, \dots,
2007\}$ containing $0$ and $2007$ with **no** two elements differing by exactly
30. If this maximum is $M$, then the largest $n$ admitting a "bad" composition i
s $M - 1$, and the answer is $n = M$.

**Residue class decomposition.** Partition $\{0, 1, \dots, 2007\}$ by residue mo
dulo 30. Two elements in **different** residue classes mod 30 cannot differ by e
xactly 30 (their difference isn't divisible by 30). Two elements in the **same**
 residue class $r$ have the form $r + 30k$ and $r + 30m$; they differ by exactly
 30 iff $|k - m| = 1$, i.e., they are **consecutive** within that class.

So within each residue class, we need an **independent set** in a path graph (no
 two consecutive elements selected). The classes are mutually independent.

**Counting elements per class.** Since $2007 = 66 \times 30 + 27$:

- **Residues $r = 0, 1, \dots, 27$** (28 classes): elements are $r, r+30, \dots,
 r+1980$, giving **67 elements** each.
- **Residues $r = 28, 29$** (2 classes): elements are $r, r+30, \dots, r+1950$,
giving **66 elements** each.

**Maximum independent set in a path of $k$ vertices** is $\lceil k/2 \rceil$.

- For 67 elements: $\lceil 67/2 \rceil = 34$.
- For 66 elements: $\lceil 66/2 \rceil = 33$.

**Incorporating the forced elements.** We need $0 \in A$ (residue class 0) and $
2007 \in A$ (residue class 27, since $2007 \equiv 27 \pmod{30}$).

- **Residue 0** (67 elements: $0, 30, 60, \dots, 1980$): Including element $0$ (
index 0) forces us to skip index 1, then pick indices $0, 2, 4, \dots, 66$ — exa

- **Residue 27** (67 elements: $27, 57, \dots, 2007$): Including $2007$ (index 6

Neither constraint causes any loss, so the constrained maximum equals the uncons
trained maximum.

**Computing the total.**

$$M = \underbrace{28 \times 34}_{\text{residues 0–27}} + \underbrace{2 \times 33
