## Proof

Let $P(m)$ denote the set of prime divisors of a nonzero integer $m$ (with $P(\p
m 1) = \emptyset$ and $P(0)$ = all primes). We seek $f \in \mathbb{Z}[x]$ with $
P(f(n)) = P(n)$ for all positive integers $n$.

**Step 1: $f$ is nonconstant and $f(n) \neq 0$ for all $n \geq 1$.**

If $f$ were constant, say $f(x) = c$, then $P(c) = P(n)$ for all $n$, which is i
mpossible since $P(n)$ varies. Also, $f(n) = 0$ would give $P(f(n))$ = all prime
s $\neq P(n)$, so $f(n) \neq 0$ for all $n \geq 1$.

**Step 2: Evaluating at $n = 1$ and at primes.**

- $n = 1$: $P(f(1)) = P(1) = \emptyset$, so $f(1) = \pm 1$.
- $n = p$ (prime): $P(f(p)) = \{p\}$, so $f(p) = \pm p^{k(p)}$ for some integer
$k(p) \geq 1$.

**Step 3: The leading coefficient has absolute value 1, and $f(x) = \pm x^d$.**

Write $f(x) = a_d x^d + \cdots + a_0$ with $d \geq 1$ and $a_d \neq 0$. For a pr
ime $p$:

$$|f(p)| = p^{k(p)}, \qquad \frac{|f(p)|}{p^d} \to |a_d| \quad \text{as } p \to
\infty.$$

Thus $p^{k(p) - d} \to |a_d|$. Since $k(p)$ is a positive integer:

- If $k(p) \geq d+1$ for infinitely many large $p$, then $p^{k(p)-d} \geq p \to
\infty$, contradicting convergence.
- If $k(p) \leq d-1$ for infinitely many large $p$, then $p^{k(p)-d} \leq 1/p \t
o 0$, contradicting $|a_d| \geq 1$.

Therefore $k(p) = d$ for all sufficiently large primes $p$, and $|a_d| = 1$.

For large primes $p$, $f(p) = \pm p^d$ and $\operatorname{sgn}(f(p)) = \operator
name{sgn}(a_d)$ (since $a_d p^d$ dominates). Hence $f(p) = a_d\, p^d$ for all su
fficiently large primes $p$.

Define $g(x) = f(x) - a_d x^d$, which has degree $\leq d-1$. Then $g(p) = 0$ for
 infinitely many primes $p$, so $g \equiv 0$. Therefore:

$$f(x) = a_d\, x^d, \qquad a_d \in \{+1, -1\}.$$

**Step 4: Verification.**

For $f(x) = x^d$ ($d \geq 1$): $f(n) = n^d$, and $P(n^d) = P(n)$. ✓

For $f(x) = -x^d$ ($d \geq 1$): $f(n) = -n^d$, and $P(-n^d) = P(n^d) = P(n)$. ✓

Both satisfy the condition for every positive integer $n$ and every positive int
eger $d$.

## Conclusion

The polynomials $f \in \mathbb{Z}[x]$ satisfying the condition are exactly:

$$\boxed{f(x) = x^d \quad \text{or} \quad f(x) = -x^d, \qquad d \in \mathbb{Z}_{
\geq 1}.}$$
