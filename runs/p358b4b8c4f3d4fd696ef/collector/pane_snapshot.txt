## Proof

**Setup.** For column $j$, let $d_j$ = number of distinct values appearing in it
. We minimize $\sum_{j=1}^{100} d_j$.

**Upper bound construction (sum = 144).** Partition the 100 columns into 22 pair
s and 56 singletons. Match these to a partition of the 100 values into 22 pairs
and 56 singletons. For each pair of columns $(c_{2i-1}, c_{2i})$ with values $\{
v_{2i-1}, v_{2i}\}$, each row uses one of the two arrangements. Each singleton c
olumn always holds its singleton value.

This yields $2^{22} = 4{,}194{,}304$ distinct permutations. Select any $3{,}000{
,}000$ of them. Since $3{,}000{,}000 > 2^{21} = 2{,}097{,}152$, for each pair bo
th arrangements must appear (each arrangement occurs in exactly $2^{21}$ permuta
tions, so we cannot select $3{,}000{,}000$ using only one). Thus each paired col
umn has $d_j = 2$ and each singleton column has $d_j = 1$.

$$\sum d_j = 44 \times 2 + 56 \times 1 = \mathbf{144}$$

**Lower bound (sum ≥ 144) via Bregman's theorem.** Build a bipartite graph $G$:
left vertices = 100 columns, right vertices = 100 values, with edge $(j,v)$ iff
value $v$ appears in column $j$. Column $j$ has degree $d_j$. Each table row is
a perfect matching in $G$, so $G$ has at least $3{,}000{,}000$ perfect matchings
.

By the **Bregman–Minc theorem**, the number of perfect matchings is at most:
$$\prod_{j=1}^{100} (d_j!)^{1/d_j}$$

So we need $\prod (d_j!)^{1/d_j} \geq 3{,}000{,}000$.

Define $f(d) = \frac{\ln(d!)}{d}$ (with $f(1)=0$). The constraint becomes $\sum
f(d_j) \geq \ln(3{,}000{,}000)$.

**Concavity of $f$.** Note $f(d+1) = \frac{d\cdot f(d) + \ln(d+1)}{d+1}$, so $f(
d+1)-f(d) = \frac{\ln(d+1)-f(d)}{d+1}$. Since $f(d)$ is the average of $\ln 1, \
ldots, \ln d$ and $\ln$ is increasing and concave, one verifies that the increme
nts $f(d+1)-f(d)$ are decreasing (confirmed numerically: $0.347, 0.250, 0.198, 0
.162, 0.140, \ldots$), so $f$ is **concave**.

By concavity, for fixed $S = \sum d_j$, the sum $\sum f(d_j)$ is maximized when
all $d_j$ are as equal as possible. (Exchange argument: if $d_i \geq d_j + 2$, r
eplacing with $(d_i{-}1, d_j{+}1)$ does not decrease $\sum f$.)

**Checking $S = 143$:** The most equal distribution is 43 columns with $d_j=2$ a
nd 57 with $d_j=1$, giving:
$$\prod (d_j!)^{1/d_j} = (\sqrt{2})^{43} = 2^{21.5} = 2{,}097{,}152 \times \sqrt
{2} \approx 2{,}965{,}842$$

Since $2{,}965{,}842 < 3{,}000{,}000$, by Bregman's theorem **no** bipartite gra
ph with $\sum d_j = 143$ can have $3{,}000{,}000$ perfect matchings. Any less-eq
ual distribution with the same sum gives an even smaller product (by concavity),
 so $\sum d_j \leq 143$ is impossible.

**Checking $S = 144$:** The construction above achieves $\sum d_j = 144$ with $2
^{22} = 4{,}194{,}304 \geq 3{,}000{,}000$ perfect matchings (Bregman's bound is
tight for disjoint unions of complete bipartite graphs $K_{2,2}$ and $K_{1,1}$).

**Conclusion.** The minimum possible sum of the red numbers is:

$$\boxed{144}$$
