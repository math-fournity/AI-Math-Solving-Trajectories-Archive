## Proof

**Setup and normalization.** The expression $F = (\sum x_i)(\sum 1/x_i)$ is scal
e-invariant (replacing $x_i \mapsto \lambda x_i$ leaves $F$ unchanged), so WLOG
set $x_n = 1$. The constraints become $0 < x_1 \le x_2 \le \cdots \le x_{107} \l
e 1$ and $x_1 + x_2 \le 1$.

**Notation.** Let $s = x_1 + x_2 \in (0, 1]$, and let $y_1, \ldots, y_{105}$ den
ote $x_3, \ldots, x_{107}$ (the 105 "middle" variables). Set $P = \sum y_i$, $Q
= \sum 1/y_i$.

**Step 1: Reducing to $x_1 = x_2$.** By AM-HM (or Cauchy–Schwarz), for fixed $s
= x_1 + x_2$:
$$\frac{1}{x_1} + \frac{1}{x_2} \ge \frac{4}{x_1 + x_2} = \frac{4}{s},$$
with equality iff $x_1 = x_2 = s/2$. Since $F = (1 + s + P)(1 + \tfrac{1}{x_1} +
 \tfrac{1}{x_2} + Q)$ and the first factor $1 + s + P$ is fixed once $s$ and the
 middle variables are fixed, minimizing the second factor (via minimizing $1/x_1
 + 1/x_2$) minimizes $F$. Thus:
$$F \ge (1 + s + P)\!\left(1 + \frac{4}{s} + Q\right).$$

**Step 2: AM-GM lower bound for the middle variables.** Set $S_0 = 1 + s$ and $T
_0 = 1 + 4/s$. Expand:
$$(S_0 + P)(T_0 + Q) = S_0 T_0 + \sum_{i=1}^{105}\!\left(\frac{S_0}{y_i} + T_0\,
 y_i\right) + \sum_{1 \le i < j \le 105}\!\left(\frac{y_i}{y_j} + \frac{y_j}{y_i
}\right).$$

(The last term uses $PQ = 105 + \sum_{i<j}(y_i/y_j + y_j/y_i)$, accounting for t
he 105 diagonal terms.)

By AM-GM, each $\frac{y_i}{y_j} + \frac{y_j}{y_i} \ge 2$, so the double sum $\ge
 2\binom{105}{2} = 105 \cdot 104 = 10920$.

By AM-GM, each $\frac{S_0}{y_i} + T_0\, y_i \ge 2\sqrt{S_0 T_0}$, so the single
sum $\ge 210\sqrt{S_0 T_0}$.

Therefore:
$$F \ge S_0 T_0 + 210\sqrt{S_0 T_0} + 105 + 10920 = S_0 T_0 + 210\sqrt{S_0 T_0}
+ 11025.$$

**Step 3: Minimizing over $s$.** We have $S_0 T_0 = (1+s)\!\left(1 + \frac{4}{s}
\right) = 5 + s + \frac{4}{s}$. Let $w = S_0 T_0$. The function $h(w) = w + 210\
sqrt{w} + 11025$ is increasing for $w > 0$ (since $h'(w) = 1 + \frac{105}{\sqrt{
w}} > 0$), so we minimize $w$.

For $s \in (0, 1]$: $\frac{d}{ds}\!\left(s + \frac{4}{s}\right) = 1 - \frac{4}{s
^2} < 0$ (since $s \le 1 < 2$), so $w(s) = 5 + s + 4/s$ is decreasing on $(0,1]$
, attaining its minimum at $s = 1$:
$$w(1) = 5 + 1 + 4 = 10.$$

Thus:
$$F \ge 10 + 210\sqrt{10} + 11025 = 11035 + 210\sqrt{10}.$$

**Step 4: Equality is achieved.** All inequalities become equalities simultaneou
sly when:
- $s = 1$ (constraint $x_1 + x_2 = x_n$ is tight),
- $x_1 = x_2 = s/2 = 1/2$ (AM-HM equality),
- All $y_i$ equal (for the pairwise AM-GM),
- $\frac{S_0}{y_i} = T_0\, y_i$, i.e., $y_i = \sqrt{S_0/T_0} = \sqrt{2/5}$ (for
the single-sum AM-GM).

We verify feasibility: $\sqrt{2/5} \approx 0.632 \in [1/2, 1]$, so the ordering
$x_2 = 1/2 \le y_i = \sqrt{2/5} \le 1 = x_n$ is satisfied. ✓

**Verification of the value.** With $x_1 = x_2 = \tfrac{1}{2}$, $x_3 = \cdots =
x_{107} = \sqrt{2/5}$, $x_{108} = 1$:
$$\textstyle\sum x_i = 1 + 105\sqrt{2/5}, \qquad \sum \frac{1}{x_i} = 4 + 105\sq
rt{5/2} + 1 = 5 + 105\sqrt{5/2}.$$
$$F = (2 + 105\sqrt{2/5})(5 + 105\sqrt{5/2}) = 10 + 210\sqrt{5/2} + 525\sqrt{2/5
} + 11025.$$
Using $\sqrt{5/2} = \frac{\sqrt{10}}{2}$ and $\sqrt{2/5} = \frac{\sqrt{10}}{5}$:
$$210 \cdot \frac{\sqrt{10}}{2} + 525 \cdot \frac{\sqrt{10}}{5} = 105\sqrt{10} +
 105\sqrt{10} = 210\sqrt{10}.$$
$$F = 10 + 11025 + 210\sqrt{10} = 11035 + 210\sqrt{10}. \checkmark$$

The minimum value is $\boxed{11035 + 210\sqrt{10}}$.
