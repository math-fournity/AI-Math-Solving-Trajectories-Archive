# Problem

A specialized logistics company, Neo-Transit, is designing a modular cargo container system for a trans-continental bridge. The capacity of a standard shipment, denoted as $A$ units, is determined by a base engineering variable $n$, where $n$ is a positive integer representing the number of structural nodes. Due to the physical limitations of the bridge, the number of nodes must be at least 1 and cannot exceed 1998.

The total cargo capacity $A$ of the system is calculated using the following engineering formula:
$A = n^3 + 30n^2 + 100n$

A shipment is considered "perfectly balanced" if the total capacity $A$ has exactly 60 unique divisors (including 1 and the value $A$ itself). 

Find the value of the structural node variable $n$ that results in a perfectly balanced shipment.
