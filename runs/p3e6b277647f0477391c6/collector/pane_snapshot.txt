### Setup

Let $R(x) = P(x) - Q(x)$, which has degree $\le n$. After applying pulses, the d
ifference becomes:

$$D(x) = R(x) + ax^k - bx^l$$

The modified trajectories never intersect iff $D(x)$ has **no real roots**, i.e.
, $D(x) > 0$ for all $x$ or $D(x) < 0$ for all $x$.

The adversary (choosing $P, Q$) can realize **any** $R$ of degree $\le n$: set $
Q(x) = Mx^n$ for large $M$ and $P(x) = Mx^n + R(x)$, ensuring both have degree e
xactly $n$.

So $n$ is collision-proof iff: **for every polynomial $R$ of degree $\le n$, the
re exist $k, l \in \{0,\dots,n\}$ and $a, b \in \mathbb{R}$ such that $R(x) + ax
^k - bx^l$ has no real root.**

### Even $n$ is collision-proof

**Case 1: $R$ has even degree $d$ (with $d \le n$).** Choose $k = l = 0$, so $D(
x) = R(x) + C$ where $C = a - b$. Since $d$ is even, $R(x) + C$ has even degree
with leading coefficient $c_d \neq 0$. As $|C| \to \infty$ with the sign of $c_d
$, we get $R(x) + C \to +\infty$ (or $-\infty$) uniformly, so for large enough $
|C|$, $D(x)$ has constant sign — no real roots. ✓

**Case 2: $R$ has odd degree $d < n$.** Choose $k = n$ (even), $b = 0$. Then $D(
x) = R(x) + ax^n$ has degree $n$ (even, since $a \neq 0$). For $|a|$ large with
the right sign, $D(x) \to +\infty$ (or $-\infty$) uniformly — no real roots. ✓

**Case 3: $R$ is constant.** If $R \neq 0$, already no roots. If $R = 0$, choose
 $k=0, a=1$: $D(x) = 1$. ✓

### Odd $n$ is NOT collision-proof

For any odd $n$, the adversary chooses $R(x) = x^n + x$. We show **no** choice o
f pulses eliminates all real roots.

$D(x) = x^n + x + ax^k - bx^l$. We consider all cases:

**If $D$ has degree $n$ (odd):** Any odd-degree polynomial has a real root. This
 occurs whenever the $x^n$ coefficient is nonzero, i.e., $1 + [k=n]\cdot a - [l=
n]\cdot b \neq 0$.

**If $D$ has degree $< n$ (the $x^n$ term is cancelled):** We need $1 + [k=n]\cd
ot a - [l=n]\cdot b = 0$. There are three sub-cases:

- **$k = n, l < n$ (with $a = -1$):** $D(x) = x - bx^l$.
  - $l = 0$: $D = x - b$, linear → has root $x = b$. ✗
  - $l \ge 1$: $D = x(1 - bx^{l-1})$ → always has root $x = 0$. ✗

- **$k < n, l = n$ (with $b = 1$):** $D(x) = x + ax^k$.
  - $k = 0$: $D = x + a$, linear → has root $x = -a$. ✗
  - $k \ge 1$: $D = x(1 + ax^{k-1})$ → always has root $x = 0$. ✗

- **$k = n, l = n$ (with $a - b = -1$):** $D(x) = x$ → root at $x = 0$. ✗

In every case, $D(x)$ has a real root. The key obstruction: after cancelling $x^
n$, the remainder $x$ is **odd-degree** and **vanishes at $x = 0$**. Any monomia
l $x^l$ with $l \ge 1$ also vanishes at $0$ (preserving the root), while $l = 0$
 yields an odd-degree polynomial (which must have a root).
