**Claim:** G(S) is definable in PA.

**Proof:**

**Step 1: Variable-free sentences are quantifier-free ground formulas.**

A variable-free sentence in the language {+, ·, <, 0, 1} is a formula that
contains no variables whatsoever. Since quantifiers bind variables, a variable-
free formula contains no quantifiers. Thus, a variable-free sentence is a
Boolean combination (using ¬, ∧, ∨, →) of atomic formulas of the form $t_1 =
t_2$ or $t_1 < t_2$, where $t_1, t_2$ are ground terms built from the constants
0 and 1 using the function symbols + and ·.

**Step 2: The truth of every variable-free sentence is decidable.**

Every ground term (built from 0, 1, +, ·) evaluates to a specific natural
number. This evaluation is effective: we can compute the value of any ground
term by recursively evaluating subterms. Given the values of $t_1$ and $t_2$,
the truth of $t_1 = t_2$ and $t_1 < t_2$ in $\mathbb{N}$ is decidable by direct
comparison. The truth of a Boolean combination of decidable statements is
decidable. Therefore, there is an algorithm that, given any variable-free
sentence $\sigma$, determines whether $\mathbb{N} \models \sigma$.

**Step 3: G(S) is recursive.**

A Gödel numbering $G$ is by definition an effective (computable) encoding: there
is an algorithm that computes $G(\sigma)$ from $\sigma$, and an algorithm that,
given $n$, determines whether $n$ is the Gödel number of some sentence and, if
so, recovers that sentence.

Given $n$, we can decide membership in $G(S)$ as follows:
1. Check whether $n$ is the Gödel number of a sentence $\sigma$ (computable,
since $G$ is effective).
2. Check whether $\sigma$ is variable-free (a syntactic property, decidable by
inspection of the parse tree).
3. If $\sigma$ is variable-free, compute its truth value in $\mathbb{N}$
(decidable by Step 2).
4. $n \in G(S)$ iff $\sigma$ is a variable-free true sentence.

This is a decision procedure, so $G(S)$ is recursive (computable).

**Step 4: Every recursive set is definable in PA.**

This is a fundamental theorem of mathematical logic (the Representability
Theorem). It states:

*For every recursive relation $R \subseteq \mathbb{N}^k$, there exists a formula
$\varphi(x_1, \ldots, x_k)$ in the language of PA such that:*
- *If $R(n_1, \ldots, n_k)$ holds, then $\text{PA} \vdash \varphi(\bar{n}_1,
\ldots, \bar{n}_k)$.*
- *If $\neg R(n_1, \ldots, n_k)$, then $\text{PA} \vdash \neg \varphi(\bar{n}_1,
\ldots, \bar{n}_k)$.*

In particular, for every recursive set $A \subseteq \mathbb{N}$, there is a
formula $\varphi(x)$ such that for all $n \in \mathbb{N}$: $n \in A \iff
\text{PA} \vdash \varphi(\bar{n})$, and $n \notin A \iff \text{PA} \vdash \neg

This implies $n \in A \iff \mathbb{N} \models \varphi(\bar{n})$, so $A$ is
definable in the standard model by a formula of PA, and moreover $A$ is strongly
represented in PA.

The proof of the Representability Theorem proceeds by showing that PA can
represent all primitive recursive functions (via the β-function lemma and coding
of sequences), and since every recursive function can be expressed using
primitive recursive functions plus minimization (and PA can handle the relevant

主张： $G(S)$ 在 PA 中是可定义的。

第 1 步：无变量句子是无量词的基公式。

语言 ${+, \cdot, <, 0, 1}$ 中的无变量句子是指完全不包含变量的公式。由于量词绑定
变量，因此无量词的公式也不含量词。因此，无变量句子是原子公式 $t_1 = t_2$ 或 $t_1
< t_2$ 的布尔组合（使用 $\neg, \land, \lor, \to$），其中 $t_1, t_2$ 是由常量 $0$
和 $1$ 通过函数符号 $+$ 和 $\cdot$ 构成的基项。

第 2 步：每个无变量句子的真值都是可判定的。

每个基项（由 $0, 1, +, \cdot$ 构成）通过递归计算其子项，可以有效地求值为一个特定
的自然数。给定 $t_1$ 和 $t_2$ 的值，原子公式 $t_1 = t_2$ 和 $t_1 < t_2$ 在 $
\mathbb{N}$ 中的真值可以通过直接比较来判定。可判定陈述的布尔组合也是可判定的。因
此，存在一种算法，对于任何无变量句子 $\sigma$，都能确定 $\mathbb{N} \models
\sigma$ 是否成立。

第 3 步：$G(S)$ 是递归的。

根据定义，哥德尔编号 $G$ 是一种有效（可计算）的编码：存在一种算法可以从 $\sigma$
计算 $G(\sigma)$，也存在一种算法可以在给定 $n$ 时确定 $n$ 是否为某个句子的哥德尔
数，并在是的情况下恢复该句子。

给定 $n$，我们可以通过以下步骤判定 $n \in G(S)$：

  1. 确定 $n$ 是否是某个句子 $\sigma$ 的哥德尔数，如果是，则恢复 $\sigma$（可计
  算，因为 $G$ 是有效的）。
  2. 检查 $\sigma$ 是否无变量——这是一种语法属性，可以通过检查其解析树来判定（无
  变量节点，无量词节点）。
  3. 如果 $\sigma$ 是无变量的，则计算其在 $\mathbb{N}$ 中的真值（根据第 2 步，这
  是可判定的）。
  4. 当且仅当 $\sigma$ 是一个无变量的真句子时，$n \in G(S)$。

这是一个判定过程，因此 $G(S)$ 是递归的（可计算的）。

第 4 步：每个递归集在 PA 中都是可定义的。

这是可表示性定理（Theorem of Representability），是数理逻辑的基础结果（参见
Boolos–Burgess–Jeffrey，《可计算性与逻辑》，第 16 章；或 Mendelson，《数理逻辑导
论》）：

│ 对于每个递归关系 $R \subseteq \mathbb{N}^k$，存在 PA 语言中的一个公式 $
│ \varphi(x_1, \ldots, x_k)$，使得：
│   • 如果 $R(n_1, \ldots, n_k)$ 成立，则 $\mathrm{PA} \vdash \varphi(\bar{n}_1,
│   \ldots, \bar{n}_k)$。
│   • 如果 $\neg R(n_1, \ldots, n_k)$，则 $\mathrm{PA} \vdash \neg
│   \varphi(\bar{n}_1, \ldots, \bar{n}_k)$。

特别地，对于每个递归集 $A \subseteq \mathbb{N}$，存在一个公式 $\varphi(x)$，使得
对于所有 $n$： $$n \in A \iff \mathrm{PA} \vdash \varphi(\bar{n}), \qquad n

这特别意味着 $n \in A \iff \mathbb{N} \models \varphi(\bar{n})$，因此 $A$ 在标准

该定理的证明大纲：PA 通过哥德尔 $\beta$-函数引理（它允许在 PA 内部编码有限序列）

索），而 PA 通过存在量化来处理极小化。因此，所有递归关系在 PA 中都是可表示的。
