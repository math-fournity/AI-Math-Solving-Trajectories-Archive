## Proof

A permutation $\sigma$ satisfies $\sigma^f = \mathrm{Id}$ if and only if every c
ycle of $\sigma$ has length dividing $f$.

**Why.** Write $\sigma$ as a product of disjoint cycles. A cycle of length $\ell
$ has order $\ell$, and the order of $\sigma$ is the lcm of its cycle lengths. T
hus $\sigma^f = \mathrm{Id}$ iff $\ell \mid f$ for every cycle length $\ell$ of
$\sigma$, i.e. iff every cycle length is a divisor of $f$.

**Exponential formula.** The class of permutations whose cycle lengths are restr
icted to a set $S \subseteq \mathbb{Z}_{\ge 1}$ has EGF

$$\exp\!\left(\sum_{\ell \in S} \frac{x^\ell}{\ell}\right),$$

since a permutation is a (labelled) set of cycles, the EGF of a single cycle of
length $\ell$ is $x^\ell/\ell$, and the "set" construction contributes the expon
ential.

**Applying it.** Here $S = \{d : d \mid f\}$, the set of positive divisors of $f
$. Therefore the EGF of permutations $\sigma$ with $\sigma^f = \mathrm{Id}$ is

$$\boxed{\displaystyle \exp\!\left(\sum_{d \mid f} \frac{x^d}{d}\right).}$$

**Sanity checks.**

- $f = 1$: only the identity, divisors $\{1\}$, EGF $= e^x = \sum_{n\ge 0} x^n/n
!$, correct (one permutation of each size).
- $f = 2$: involutions; divisors $\{1,2\}$, EGF $= e^{x + x^2/2}$, the classical
 EGF for involutions.
- $f$ prime $p$: divisors $\{1,p\}$, EGF $= e^{x + x^p/p}$, counting permutation
s made of fixed points and $p$-cycles.
