## Proof

Let $\angle ABC = \beta$ and $\angle ACB = \gamma$. Since $\angle BAC = 30°$, we
 have $\beta + \gamma = 150°$, i.e., $\gamma = 150° - \beta$.

Since $D \in [BC]$, the points $B, D, C$ are collinear, so $\angle ADC$ and $\an
gle ADB$ are supplementary:
$$\angle ADB = 180° - 150° = 30°.$$

**Triangle $ABD$.** The angles are $\angle ADB = 30°$, $\angle ABD = \beta$, so
$$\angle BAD = 180° - 30° - \beta = 150° - \beta.$$

**Triangle $ADC$.** The angles are $\angle ADC = 150°$, $\angle ACD = \gamma = 1
50° - \beta$, so
$$\angle DAC = 180° - 150° - (150° - \beta) = \beta - 120°.$$

For both $\angle BAD$ and $\angle DAC$ to be positive: $120° < \beta < 150°$.

**Applying the sine rule.** In $\triangle ABD$:
$$\frac{AB}{\sin 30°} = \frac{AD}{\sin\beta} \implies AB = \frac{AD\sin 30°}{\si
n\beta}.$$

In $\triangle ADC$:
$$\frac{DC}{\sin(\beta - 120°)} = \frac{AD}{\sin(150° - \beta)} \implies DC = \f
rac{AD\sin(\beta - 120°)}{\sin(150° - \beta)}.$$

The condition $DC = AB$ gives:
$$\frac{\sin(\beta - 120°)}{\sin(150° - \beta)} = \frac{\sin 30°}{\sin\beta},$$
$$\sin(\beta - 120°)\sin\beta = \sin 30°\sin(150° - \beta).$$

**Product-to-sum.** Left side:
$$\sin(\beta-120°)\sin\beta = \tfrac{1}{2}\big[\cos 120° - \cos(2\beta - 120°)\b
ig] = \tfrac{1}{2}\big[-\tfrac{1}{2} - \cos(2\beta-120°)\big].$$

Right side:
$$\sin 30°\sin(150°-\beta) = \tfrac{1}{2}\big[\cos(\beta - 120°) - \cos(180° - \
beta)\big] = \tfrac{1}{2}\big[\cos(\beta-120°) + \cos\beta\big].$$

Equating and simplifying:
$$-\tfrac{1}{2} - \cos(2\beta - 120°) = \cos(\beta - 120°) + \cos\beta.$$

Using sum-to-product: $\cos(\beta-120°) + \cos\beta = 2\cos(\beta - 60°)\cos 60°
 = \cos(\beta - 60°)$. Thus:
$$\cos(2\beta - 120°) + \cos(\beta - 60°) = -\tfrac{1}{2}.$$

**Substitution.** Let $\theta = \beta - 60°$, so $2\beta - 120° = 2\theta$:
$$\cos 2\theta + \cos\theta = -\tfrac{1}{2},$$
$$2\cos^2\theta - 1 + \cos\theta = -\tfrac{1}{2},$$
$$4\cos^2\theta + 2\cos\theta - 1 = 0,$$
$$\cos\theta = \frac{-1 \pm \sqrt{5}}{4}.$$

Since $\beta \in (120°, 150°)$, we have $\theta \in (60°, 90°)$, so $\cos\theta
\in (0, \tfrac{1}{2})$. The root $\frac{-1-\sqrt{5}}{4} < 0$ is rejected, leavin
g:
$$\cos\theta = \frac{\sqrt{5}-1}{4} = \cos 72° \implies \theta = 72°.$$

Therefore:
$$\beta = 60° + 72° = 132°.$$

**Verification.** With $\beta = 132°$: $\gamma = 18°$, $\angle BAD = 18°$, $\ang
le DAC = 12°$, and $\angle BAD + \angle DAC = 30° = \angle BAC$ ✓. Setting $AD =
 1$: $AB = \frac{\sin 30°}{\sin 132°}$ and $DC = \frac{\sin 12°}{\sin 18°}$. Usi
ng $\sin 132° = \sin 48°$ and the identity $\sin 48° \sin 12° = \sin 30° \sin 18
°$ (verified by product-to-sum), both equal, confirming $DC = AB$ ✓.

$$\boxed{\angle ABC = 132°}$$
