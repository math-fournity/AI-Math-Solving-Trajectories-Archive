Looking at this problem, I need to find all values of N such that any collection
 of N coins with positive integer masses summing to 300 can be partitioned into
three piles of exactly 100 grams each.

**Answer: N ≥ 201 (i.e., 201 ≤ N ≤ 300).**

---

## Proof

### Necessary condition: N ≥ 201

If N ≤ 200, consider the mass assignment: one coin of mass 301 − N and N−1 coins
 of mass 1. The total is (301−N) + (N−1) = 300. Since N ≤ 200, the large coin ha
s mass ≥ 101 > 100, so it cannot belong to any pile of mass 100. Thus the partit
ion is impossible for this assignment, so N ≤ 200 does not guarantee success.

### Sufficient condition: N ≥ 201

Assume N ≥ 201. Each coin has mass ≥ 1, so the maximum coin mass is at most 300
− (N−1) ≤ 100. Thus **every coin has mass at most 100**.

**Counting ones.** Let k be the number of coins with mass ≥ 2. Then the total ma
ss is at least 2k + 1·(N−k) = N + k, so k ≤ 300 − N ≤ 99. Hence at least N − 99
≥ 102 coins have mass exactly 1.

**Reduction.** Separate the coins into "ones" (mass 1) and "non-ones" (mass ≥ 2)
. The non-ones have total mass 300 − (number of ones) ≤ 300 − 102 = 198. If we c
an partition the non-ones into three groups each with sum ≤ 100, then we fill ea
ch group with ones to reach exactly 100. The total number of ones needed is 300
− (sum of non-ones) = number of ones available, and each group's deficit is non-
negative. So it suffices to prove:

> **Lemma.** Given items with positive integer sizes, each ≤ 100, with total sum
 ≤ 198, they can be partitioned into 3 groups each with sum ≤ 100.

**Proof of Lemma.** Sort items in decreasing order: a₁ ≥ a₂ ≥ … ≥ aₘ. Process th
em greedily: place each item into the group with the smallest current sum.

Suppose for contradiction that item j (size aⱼ) is the first to cause some group
 to exceed 100. Before placing it, let the group sums be s₁, s₂, s₃ with s₃ mini
mal. Item j goes into group 3, so s₃ + aⱼ > 100.

Since group 3 had the smallest sum: s₁ ≥ s₃ and s₂ ≥ s₃, so the total before ite
m j is at least 3s₃. Including item j, the total exceeds 3s₃ + aⱼ > 3s₃ + (100 −
 s₃) = 2s₃ + 100.

Since the total is at most 198: 2s₃ + 100 < 198, giving s₃ < 49.

Then aⱼ > 100 − s₃ > 51, so aⱼ ≥ 52 (integer). Since items are sorted decreasing
ly, items 1 through j all have size ≥ 52, so the total is at least 52j. From 52j
 ≤ 198 we get j ≤ 3 (since 52·4 = 208 > 198).

But for j ≤ 3, the first j items are each placed into an empty group (sum 0), so
 the resulting group sum is aⱼ ≤ 100 — contradicting s₃ + aⱼ > 100. ∎

**Completing the proof.** Apply the Lemma to the non-one coins (each ≤ 100, tota
l ≤ 198) to obtain three groups each with sum ≤ 100. Fill each group with mass-1
 coins to reach exactly 100. This uses exactly all the one-coins (since total de
ficit = 300 − sum of non-ones = number of ones), and every group reaches exactly
 100 grams. ∎
