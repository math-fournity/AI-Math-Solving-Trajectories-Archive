# Solution

**Answer: 4**

## Setup

Let the 8×8 grid have entries in {0,1}, where 1 = Idle and 0 = Active. The const
raint is: every 3×3 consecutive block has an even number of 1s (Idle sensors). W
e minimize the number of 0s (Active sensors).

**Reformulation via flipping.** Start from the all-Idle grid (all 1s). Each 3×3
block then contains 9 Idle sensors (odd). To fix this, flip a set $F$ of cells t
o Active; a block's Idle-parity changes from odd to even iff the block contains
an **odd** number of flipped cells. So we need a set $F \subseteq \{0,\dots,7\}^
2$ such that every 3×3 block contains an odd number of cells of $F$, and we mini
mize $|F|$. The number of Active sensors equals $|F|$.

## Lower bound: $|F| \ge 4$

Consider four specific 3×3 blocks among the 36 required blocks (top-left corner
$(i,j)$ with $i,j \in \{0,\dots,5\}$):

- $B_{0,0}$: rows $\{0,1,2\}$, cols $\{0,1,2\}$
- $B_{0,5}$: rows $\{0,1,2\}$, cols $\{5,6,7\}$
- $B_{5,0}$: rows $\{5,6,7\}$, cols $\{0,1,2\}$
- $B_{5,5}$: rows $\{5,6,7\}$, cols $\{5,6,7\}$

These four blocks are **pairwise disjoint** (the row-sets $\{0,1,2\}$ and $\{5,6
,7\}$ are disjoint, and likewise the column-sets). Each block must contain an od
d number of cells of $F$, hence at least one. By disjointness, these cells are a
ll distinct, so:

$$|F| \ge 1 + 1 + 1 + 1 = 4.$$

## Construction: $|F| = 4$ is achievable

Take $F = \{(2,2),\, (2,5),\, (5,2),\, (5,5)\}$.

A 3×3 block with top-left corner $(i,j)$ covers rows $\{i,i+1,i+2\}$ and columns
 $\{j,j+1,j+2\}$. Observe:
- Row $2$ lies in the block's row-range iff $i \in \{0,1,2\}$; row $5$ iff $i \i
n \{3,4,5\}$.
- Column $2$ lies in the block's col-range iff $j \in \{0,1,2\}$; column $5$ iff
 $j \in \{3,4,5\}$.

Since $\{0,1,2\} \cup \{3,4,5\} = \{0,1,2,3,4,5\}$, every valid block corner $(i
,j)$ falls into exactly one of four cases:

| $i$ range | $j$ range | F-cell in block | Count |
|-----------|-----------|-----------------|-------|
| $\{0,1,2\}$ | $\{0,1,2\}$ | $(2,2)$ | 1 |
| $\{0,1,2\}$ | $\{3,4,5\}$ | $(2,5)$ | 1 |
| $\{3,4,5\}$ | $\{0,1,2\}$ | $(5,2)$ | 1 |
| $\{3,4,5\}$ | $\{3,4,5\}$ | $(5,5)$ | 1 |

Every one of the 36 blocks contains **exactly one** cell of $F$, which is odd. ✓

## Verification in original terms

With $F = \{(2,2),(2,5),(5,2),(5,5)\}$ as the only Active sensors:
- Active count = $|F| = 4$.
- Idle count = $64 - 4 = 60$.
- Each 3×3 block contains exactly 1 Active sensor, so $9 - 1 = 8$ Idle sensors,
which is **even**. ✓

## Conclusion

The lower bound $|F| \ge 4$ matches the construction achieving $|F| = 4$. Theref
ore the minimum possible number of Active sensors is $\boxed{4}$.
