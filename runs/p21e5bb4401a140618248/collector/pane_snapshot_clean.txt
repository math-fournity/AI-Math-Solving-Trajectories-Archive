## Algorithm for the $p^q$-th Matrix Root

### Key Observations

**Observation 1 (Cyclicity).** Since $A$ has $n$ distinct eigenvalues in $\bar{K
}$, its minimal polynomial $m_A$ equals its characteristic polynomial $\chi_A$,
has degree $n$, and is separable. Thus $A$ is *cyclic*: its centralizer in $M_n(
K)$ is exactly the algebra $K[A] \cong R := K[t]/(m_A(t))$, an $n$-dimensional $
K$-vector space with basis $\{1, t, \ldots, t^{n-1}\}$.

**Observation 2 (Commutativity).** If $X^{p^q} = A$, then $X$ commutes with $A$:
$$XA = X \cdot X^{p^q} = X^{p^q+1} = X^{p^q} \cdot X = AX.$$
By Observation 1, $X = f(A)$ for a unique $f \in R$.

**Observation 3 (Frobenius linearity).** In $R$, the equation becomes $f^{p^q} =
 t$. Since $\text{char}(K)=p$, the Frobenius is a ring homomorphism, so for $f =
 \sum_{i=0}^{n-1} c_i\, t^i$:
$$f^{p^q} = \sum_{i=0}^{n-1} c_i^{p^q}\, t^{i\,p^q}.$$

**Observation 4 (Reduction to linear system).** Let $g := t^{p^q} \bmod m_A(t) \
in R$. Then $t^{i p^q} \equiv g^i \pmod{m_A}$, so the equation $f^{p^q} = t$ bec
omes:
$$\sum_{i=0}^{n-1} d_i\, g^i = t, \qquad \text{where } d_i := c_i^{p^q}. \tag{$\
star$}$$

**Observation 5 (Invertibility).** The matrix $A^{p^q}$ has eigenvalues $\lambda
_1^{p^q}, \ldots, \lambda_n^{p^q}$ (where $\lambda_j$ are eigenvalues of $A$). S
ince Frobenius is injective, these are $n$ distinct values, so $A^{p^q}$ is also
 cyclic with minimal polynomial of degree $n$. Therefore $K[A^{p^q}] = K[A]$ (bo
th $n$-dimensional, one contained in the other), and $\{1, g, g^2, \ldots, g^{n-
1}\}$ is a basis of $R$. The linear system ($\star$) thus has a **unique** solut
ion $\mathbf{d} = (d_0, \ldots, d_{n-1})$.

**Observation 6 (Frobenius inverse).** Since the problem guarantees $X \in M_n(K
)$ exists, the values $c_i = d_i^{1/p^q}$ lie in $K$ ( $K$ is perfect for the re
levant elements). The inverse Frobenius is unique, giving unique $c_i$.

### The Algorithm

**Input:** $A \in M_n(K)$, prime $p = \text{char}(K)$, integer $q \geq 1$.
**Output:** $X \in M_n(K)$ with $X^{p^q} = A$.

**Step 1 — Characteristic polynomial.** Compute $m_A(t) = \chi_A(t)$ via the Ber
kowitz algorithm (division-free, works in any characteristic).

**Step 2 — Compute $g = t^{p^q} \bmod m_A(t)$.** Use binary exponentiation in $R
 = K[t]/(m_A(t))$. The exponent $p^q$ has $O(\log(p^q)) = O(q \log p)$ bits, so
this requires $O(q \log p)$ multiplications in $R$, each costing $O(n^2)$ (polyn
omial multiplication + reduction mod $m_A$).

**Step 3 — Powers of $g$.** Compute $g^0, g^1, \ldots, g^{n-1}$ in $R$ by repeat
ed multiplication. Express each $g^i = \sum_j B_{ji}\, t^j$ in the standard basi
s to form the $n \times n$ matrix $B = [g^0 \mid g^1 \mid \cdots \mid g^{n-1}]$
(column $i$ is the coordinate vector of $g^i$).

**Step 4 — Solve linear system.** Solve $B\,\mathbf{d} = \mathbf{e}_1$ where $\m
athbf{e}_1 = (0,1,0,\ldots,0)^T$ is the coordinate vector of $t$, via Gaussian e
limination. This yields $d_0, \ldots, d_{n-1}$.

**Step 5 — Frobenius inverse.** For each $i$, compute $c_i = d_i^{1/p^q}$ (apply
 the inverse Frobenius $q$ times; each application costs $O(\log p)$ field opera
tions via exponentiation).

**Step 6 — Evaluate $f(A)$.** Compute $X = \sum_{i=0}^{n-1} c_i A^i$ via Horner'
s method:
$$X = c_0 I + A\bigl(c_1 I + A\bigl(c_2 I + \cdots + A(c_{n-1} I)\cdots\bigr)\bi
gr),$$
requiring $n-1$ matrix multiplications and $n-1$ matrix additions.

### Correctness

By Observation 2, any solution must satisfy $X = f(A)$ for some $f \in R$. The e
quation $f^{p^q} = t$ in $R$ is equivalent to the linear system ($\star$) by Obs
ervations 3–4. By Observation 5, $B$ is invertible, so ($\star$) has a unique so
lution $\mathbf{d}$. By Observation 6, the Frobenius inverse gives unique $c_i \
in K$. The resulting $f$ satisfies $f(A)^{p^q} = A$, i.e., $X^{p^q} = A$. **Uniq
ueness** follows from uniqueness at each stage (unique $f$ in $R$, unique linear
 system solution, unique Frobenius inverse).

### Complexity Analysis

| Step | Operation | Cost (field ops) |
|------|-----------|-------------------|
| 1 | Characteristic polynomial (Berkowitz) | $O(n^4)$ |
| 2 | Binary exponentiation in $R$: $O(q\log p)$ mults × $O(n^2)$ | $O(n^2\, q\l
og p)$ |
| 3 | $n$ multiplications in $R$ × $O(n^2)$ | $O(n^3)$ |
| 4 | Gaussian elimination ($n \times n$) | $O(n^3)$ |
| 5 | $n$ inverse Frobenius × $O(q\log p)$ | $O(n\, q\log p)$ |
| 6 | Horner: $n$ matrix mults × $O(n^3)$ | $O(n^4)$ |

**Total:** $O(n^4 + n^2\, q\log p)$ field operations.

Since $n^4 \leq n^4 \cdot q\log p$ and $n^2\, q\log p \leq n^4\, q\log p$ for al
l $n \geq 1$, $p \geq 2$, $q \geq 1$:

$$\boxed{O(n^4 + n^2\, q\log p) \;\subseteq\; O\!\left(n^4 \log(p)\, q\right).}$
$

The bound $O(n^4 + n^2\, q\log p)$ is in fact **strictly better** than $O(n^4 \l
og(p)\, q)$ in most parameter regimes (e.g., when $q\log p \ll n^2$, the cost is
 dominated by $O(n^4)$, independent of $p$ and $q$). $\blacksquare$
