## Setup

Place the unit circle in the complex plane. Let $P_i$ correspond to $z_i$ with $
|z_i|=1$, and $M$ correspond to $z$ with $|z|=1$. Write $z = e^{it}$, $z_i = e^{

## Part (a): $k = 2018$

Since $2018$ is even, $k/2 = 1009$. We compute:

$$|z - z_i|^2 = (z-z_i)(\bar z - \bar z_i) = (z-z_i)\!\left(\frac{1}{z}-\frac{1}
{z_i}\right) = -\frac{(z-z_i)^2}{z\,z_i}.$$

Therefore

$$MP_i^{2018} = |z-z_i|^{2018} = \bigl(|z-z_i|^2\bigr)^{1009} = \left(-\frac{(z-
z_i)^2}{z\,z_i}\right)^{1009} = -\,\frac{(z-z_i)^{2018}}{z^{1009}\,z_i^{1009}}.$
$

Summing over $i$:

$$\sum_{i=1}^n MP_i^{2018} = -\frac{1}{z^{1009}}\sum_{i=1}^n \frac{(z-z_i)^{2018
}}{z_i^{1009}}.$$

**Expansion.** Define the power sums $S_m = \sum_{i=1}^n z_i^m$ (with $S_0 = n$)
. Expanding $(z - z_i)^{2018}$ via the binomial theorem:

$$\sum_{i=1}^n \frac{(z-z_i)^{2018}}{z_i^{1009}} = \sum_{j=0}^{2018}\binom{2018}
{j}(-1)^{2018-j}\,z^j \sum_{i=1}^n z_i^{1009-j} = \sum_{j=0}^{2018}\binom{2018}{
j}(-1)^{2018-j}\,S_{1009-j}\,z^j.$$

This is a polynomial $P(z)$ of degree $\le 2018$, and $\sum_i MP_i^{2018} = -P(z
)/z^{1009}$ is a Laurent polynomial in $z$. For a Laurent polynomial to be const
ant on the unit circle, it must be identically constant, so we need $P(z) = C\,z
^{1009}$ for some constant $C$.

**Condition.** The coefficient of $z^j$ in $P(z)$ is $\binom{2018}{j}(-1)^{2018-
j}S_{1009-j}$. For $j \ne 1009$, we need $S_{1009-j} = 0$. As $j$ ranges over $\
{0,\ldots,2018\}\setminus\{1009\}$, the index $1009 - j$ ranges over $\{-1009,\l
dots,-1,1,\ldots,1009\}$. Since $|z_i|=1$, we have $S_{-m} = \overline{S_m}$, so
 $S_{-m}=0 \iff S_m = 0$. Thus the condition reduces to:

$$\boxed{S_m = 0 \quad \text{for } m = 1, 2, \ldots, 1009.}$$

When this holds, the $j=1009$ coefficient gives $C = \binom{2018}{1009}(-1)^{100
9}\cdot n = -\binom{2018}{1009}\,n$, and the constant value is $\sum_i MP_i^{201
8} = -C = \binom{2018}{1009}\,n$.

**Necessity: $n \ge 1010$.** Suppose $n \le 1009$. Then $S_1 = S_2 = \cdots = S_
n = 0$ (since $n \le 1009$). Consider the monic polynomial $f(z) = \prod_{i=1}^n
 (z - z_i) = z^n - e_1 z^{n-1} + e_2 z^{n-2} - \cdots + (-1)^n e_n$, where $e_k$
 are the elementary symmetric polynomials in the $z_i$. By **Newton's identities
**, for $k \le n$:

$$S_k - e_1 S_{k-1} + e_2 S_{k-2} - \cdots + (-1)^{k-1} e_{k-1} S_1 + (-1)^k k\,
 e_k = 0.$$

Since $S_1 = \cdots = S_n = 0$, induction on $k$ gives $e_1 = e_2 = \cdots = e_n
 = 0$. Hence $f(z) = z^n$, so all $z_i = 0$, contradicting $|z_i| = 1$. Therefor
e $n \ge 1010$ is necessary.

**Sufficiency: $n \ge 1010$.** For $n \ge 1010$, take the vertices of the regula
r $n$-gon: $z_j = e^{2\pi i j/n}$, $j = 0, 1, \ldots, n-1$. Then

$$S_m = \sum_{j=0}^{n-1} e^{2\pi i jm/n} = \begin{cases} n & \text{if } n \mid m
, \\ 0 & \text{if } n \nmid m. \end{cases}$$

For $m = 1, \ldots, 1009$ and $n \ge 1010$, we have $n \nmid m$ (since $m < n$),
 so $S_m = 0$. The condition is satisfied. $\checkmark$

**Answer to (a):** All positive integers $n \ge 1010$.

## Part (b): $k = 2019$

Since $2019$ is odd, $MP_i^{2019} = |z - z_i|^{2019} \ge 0$. Using $z = e^{it}$,
 $z_i = e^{it_i}$:

$$MP_i = |z - z_i| = 2\left|\sin\frac{t - t_i}{2}\right|, \qquad MP_i^{2019} = 2
^{2019}\left|\sin\frac{t - t_i}{2}\right|^{2019}.$$

Define $g(u) = 2^{2019}|\sin(u/2)|^{2019}$, so $\sum_i MP_i^{2019} = \sum_{i=1}^
n g(t - t_i) =: F(t)$.

**Key smoothness claim.** $g(u)$ is $C^{2018}$ but **not** $C^{2019}$ at $u = 0$
, and the jump of $g^{(2019)}$ at $u = 0$ is strictly positive.

*Proof of claim.* Write $g(u) = 2^{2019}|\sin(u/2)|^{2019}$. Since $\sin(u/2) =
\frac{u}{2}\operatorname{sinc}(u/2)$ where $\operatorname{sinc}(x) = \sin(x)/x$
is analytic and positive near $0$:

$$g(u) = 2^{2019}\cdot\frac{|u|^{2019}}{2^{2019}}\cdot|\operatorname{sinc}(u/2)|
^{2019} = |u|^{2019}\,\phi(u),$$

where $\phi(u) = (\operatorname{sinc}(u/2))^{2019}$ is analytic near $0$ with $\
phi(0) = 1$. Write $\phi(u) = 1 + \psi(u)$ with $\psi$ analytic, $\psi(0) = 0$.
Then:

$$g(u) = |u|^{2019} + |u|^{2019}\,\psi(u).$$

- The first term $|u|^{2019}$ has 2019th derivative $2019!\operatorname{sgn}(u)$
, which jumps by $2\cdot 2019!$ at $u=0$.
- The second term: since $\psi(u) = O(u)$, we get $|u|^{2019}\psi(u) = |u|^{2019
}\cdot u\cdot\eta(u) = \operatorname{sgn}(u)|u|^{2020}\eta(u)$ for some analytic
 $\eta$. Since $|u|^{2020} = u^{2020}$ (even power), this equals $\operatorname{
sgn}(u)\,u^{2020}\eta(u)$, which is $C^{2019}$ (its 2019th derivative is continu
ous at $0$). So this term contributes **no jump** to the 2019th derivative.

Therefore $g^{(2019)}$ has a jump of exactly $2\cdot 2019! > 0$ at $u = 0$. $\sq
uare$

**Impossibility.** Suppose $F(t) = \sum_{i=1}^n g(t - t_i)$ is constant. Then $F
$ is $C^\infty$, so $F^{(2019)}$ is continuous (identically zero). However, $F^{
(2019)}$ is the sum of the 2019th derivatives of each $g(t - t_i)$. At $t = t_i$
, the term $g(t - t_i)$ contributes a jump of $+2\cdot 2019!$. If $k$ of the poi
nts $t_j$ coincide with $t_i$, the total jump at $t = t_i$ is $k \cdot 2\cdot 20
19! > 0$. All other terms $g(t - t_j)$ (with $t_j \ne t_i$) are $C^{2019}$ near
$t = t_i$ and contribute no jump.

Since every $t_i$ appears in the list (each point contributes at least one term)
, there is at least one location with a strictly positive jump. This contradicts
 $F^{(2019)}$ being continuous.

Therefore **no** configuration of $n \ge 1$ points can make $\sum_i MP_i^{2019}$
 constant.

**Answer to (b):** There is no positive integer $n$ satisfying the condition.

- **(a) $k = 2018$:** All positive integers $n \ge 1010$.
