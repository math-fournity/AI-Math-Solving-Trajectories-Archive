Looking at this problem, I need to find the probability that there exist $b,c \g
eq 1$ with $f^b(1)=a$ and $f^c(a)=1$, over a random function $f:[n]\to[n]$ and r
andom $a\in[n]$.

## Analysis of the Condition

**Claim:** The condition "$\exists\, b,c\geq 1: f^b(1)=a$ and $f^c(a)=1$" holds
if and only if $1$ lies on a cycle of the functional graph of $f$ and $a$ lies o
n that same cycle.

*Proof of claim:* If both conditions hold, then $f^{b+c}(1) = f^c(f^b(1)) = f^c(
a) = 1$, so $1$ is a periodic point (on a cycle). Since $a = f^b(1)$ with $b\geq
 1$, $a$ is also on this cycle. Conversely, if $1$ is on a cycle of length $L$ a
nd $a$ is on the same cycle, then $a = f^j(1)$ for some $1 \leq j \leq L$ (or $a
=1$ with $j=L$), giving $b=j\geq 1$; and $1 = f^{L-j}(a)$ (or $f^L(a)$ if $a=1$)
, giving $c = L-j \geq 1$ (or $c=L\geq 1$). $\square$

## Setting Up the Probability

Let $L$ denote the length of the cycle containing $1$ in the functional graph of
 $f$ (set $L=0$ if $1$ is not on a cycle). Given $f$, the number of values $a\in
[n]$ on the same cycle as $1$ is exactly $L$. Since $a$ is chosen uniformly from
 $[n]$ independently of $f$:

$$P = \mathbb{E}_f\!\left[\frac{L}{n}\right] = \frac{\mathbb{E}[L]}{n}.$$

## Computing $\mathbb{E}[L]$

For $k \geq 1$, the probability that $1$ lies on a cycle of length exactly $k$ i
s computed as follows: choose $k-1$ companions from $\{2,\dots,n\}$ in $\binom{n
-1}{k-1}$ ways, arrange them with $1$ into a single cycle in $(k-1)!$ ways, and
let the remaining $n-k$ elements map anywhere in $n^{n-k}$ ways. Dividing by $n^
n$ total functions:

$$\Pr(\text{cycle length } = k) = \binom{n-1}{k-1}(k-1)!\cdot\frac{n^{n-k}}{n^n}
 = \frac{(n-1)^{\underline{k-1}}}{n^k},$$

where $(n-1)^{\underline{k-1}} = (n-1)(n-2)\cdots(n-k+1)$ is the falling factori
al (equal to $1$ when $k=1$).

Set $a_k = \frac{(n-1)^{\underline{k-1}}}{n^k}$ for $k=1,\dots,n$, and $a_{n+1}=
0$. The ratio:

$$\frac{a_{k+1}}{a_k} = \frac{n-k}{n} \quad\text{for } k=1,\dots,n,$$

so $n\,a_{k+1} = (n-k)\,a_k$, which rearranges to:

$$k\,a_k = n\,(a_k - a_{k+1}) \quad\text{for } k=1,\dots,n.$$

Now telescope:

$$\mathbb{E}[L] = \sum_{k=1}^{n} k\,a_k = n\sum_{k=1}^{n}(a_k - a_{k+1}) = n\,(a
_1 - a_{n+1}) = n\cdot\frac{1}{n} - 0 = \boxed{1}.$$

## Result

$$P = \frac{\mathbb{E}[L]}{n} = \frac{1}{n}.$$

**Verification for $n=2$:** The four functions give cycle-lengths-containing-$1$
 of $\{1,1,2,0\}$, so $\mathbb{E}[L]=1$. The probabilities of success (over unif
orm $a$) are $\{1/2,\, 1/2,\, 1,\, 0\}$, averaging to $1/2 = 1/n$. ✓

The probability is $\dfrac{1}{n}$.
