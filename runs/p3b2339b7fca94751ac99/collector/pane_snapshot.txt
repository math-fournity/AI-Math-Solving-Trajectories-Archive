## Proof

**Setup.** Model the handshakes as a graph $G$ on 294 vertices. The condition st
ates: for every edge $uv$, at least one of $\deg(u), \deg(v)$ is $\leq 6$.

Call a vertex **heavy** if $\deg \geq 7$, and **light** if $\deg \leq 6$. The co
ndition implies **no edge joins two heavy vertices**.

Let $s$ = number of heavy vertices, $t = 294 - s$ = number of light vertices. Le
t:
- $a$ = number of edges between heavy and light vertices,
- $b$ = number of edges within light vertices,
- (edges within heavy vertices = 0).

**Bounding the total.** Each light vertex has degree $\leq 6$, so the sum of deg
rees of light vertices satisfies:
$$a + 2b \leq 6t.$$

The total number of edges is $E = a + b$. From the constraint:
$$b \leq \frac{6t - a}{2}, \quad \text{so} \quad E = a + b \leq a + \frac{6t - a
}{2} = 3t + \frac{a}{2}.$$

Since $b \geq 0$, we have $a \leq 6t$. Also $a \leq st$ (at most $s \cdot t$ cro
ss-edges). Therefore:
$$a \leq t \cdot \min(s,\, 6).$$

**Case 1: $s \leq 6$.** Then $a \leq st$, giving:
$$E \leq 3t + \frac{st}{2} = \frac{t(6+s)}{2} = \frac{(294-s)(6+s)}{2}.$$

Let $f(s) = \frac{(294-s)(6+s)}{2}$. Then $f'(s) = \frac{288 - 2s}{2} = 144 - s
> 0$ for $s \leq 6$, so $f$ is increasing on this range. The maximum is at $s =
6$:
$$f(6) = \frac{288 \times 12}{2} = 1728.$$

**Case 2: $s \geq 7$.** Then $a \leq 6t$, giving:
$$E \leq 3t + 3t = 6t = 6(294 - s) \leq 6 \times 287 = 1722 < 1728.$$

**Conclusion of upper bound.** In all cases, $E \leq 1728$.

**Construction achieving 1728.** Choose 6 people to be heavy and 288 to be light
. Each heavy person shakes hands with all 288 light people (and not with each ot
her). Each light person shakes hands with exactly those 6 heavy people.

- Each heavy person has degree $288 \geq 7$. ✓
- Each light person has degree $6 \leq 6$. ✓
- Every edge connects a heavy person (degree 288) to a light person (degree 6),
so at least one endpoint has degree $\leq 6$. ✓
- Total handshakes $= 6 \times 288 = 1728$.

**Therefore, the greatest number of possible handshakes is $\boxed{1728}$.**
