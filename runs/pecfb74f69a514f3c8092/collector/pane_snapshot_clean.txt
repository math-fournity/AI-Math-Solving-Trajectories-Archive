## Answer

**No.** There does not exist a non-principal ultrafilter over an infinite set $I
$ that contains a finite subset of $I$.

## Proof

Recall the relevant definitions and facts:

- A **filter** $F$ over $I$ is a nonempty family of subsets of $I$ closed under
finite intersection and upward closure, with $\emptyset \notin F$.
- An **ultrafilter** is a maximal filter, equivalently a filter $F$ such that fo
r every $A \subseteq I$, either $A \in F$ or $I \setminus A \in F$.
- An ultrafilter $F$ is **principal** if $F = \{A \subseteq I : a \in A\}$ for s
ome fixed $a \in I$ (equivalently, $F$ contains a singleton $\{a\}$).
- An ultrafilter is **non-principal** (free) if it is not principal.

**Key fact.** A non-principal ultrafilter $F$ over $I$ contains every cofinite s
ubset of $I$.

*Proof of key fact.* Since $F$ is non-principal, it contains no singleton $\{a\}
$. By the ultrafilter property, for each $a \in I$, since $\{a\} \notin F$, we h
ave $I \setminus \{a\} \in F$. Now any cofinite set $C = I \setminus \{a_1, \dot
s, a_n\}$ satisfies
$$C = \bigcap_{i=1}^{n} (I \setminus \{a_i\}),$$
and since $F$ is closed under finite intersection, $C \in F$. $\square$

**Main argument.** Suppose for contradiction that $F$ is a non-principal ultrafi
lter over $I$ containing a finite set $S \subseteq I$ with $S = \{s_1, s_2, \dot
s, s_n\}$ (where $n \geq 1$).

By the key fact, $I \setminus \{s_1\} \in F$ (it is cofinite). Since $F$ is clos
ed under finite intersection,
$$S \cap (I \setminus \{s_1\}) = S \setminus \{s_1\} \in F.$$
Repeating this argument inductively for $s_2, s_3, \dots, s_n$, each time inters
ecting with the cofinite set $I \setminus \{s_i\} \in F$, we obtain
$$S \setminus \{s_1, \dots, s_{n-1}\} = \{s_n\} \in F.$$

Thus $F$ contains the singleton $\{s_n\}$. But an ultrafilter containing a singl
eton $\{s_n\}$ is precisely the principal ultrafilter generated by $s_n$:
$$F = \{A \subseteq I : s_n \in A\}.$$

This contradicts the assumption that $F$ is non-principal. Therefore, no non-pri
ncipal ultrafilter over $I$ can contain a finite subset of $I$.

**Conclusion.** The answer is **no**: every non-principal ultrafilter over an in
finite set $I$ contains no finite subsets of $I$ (equivalently, it contains exac
tly the cofinite sets and extends the Fréchet filter).
