### Step 1 — Symmetry

**Lemma.** If $mn - 1 \mid n^3 + 1$, then $mn - 1 \mid m^3 + 1$.

*Proof.* Let $d = mn - 1$. Then $mn \equiv 1 \pmod{d}$, so $m \equiv n^{-1} \pmo
d{d}$ (since $\gcd(n, d) = \gcd(n, mn-1) = 1$). The hypothesis gives $n^3 \equiv
 -1 \pmod{d}$, so $n \cdot n^2 \equiv -1$, meaning $n^{-1} \equiv -n^2 \pmod{d}$
. Thus $m^3 \equiv n^{-3} \equiv (n^3)^{-1} \equiv (-1)^{-1} \equiv -1 \pmod{d}$
. $\square$

### Step 2 — The Descent

**Lemma.** Let $(m, n)$ be a solution with $m \ge 2$, $n \ge 2$, $(m,n) \ne (2,2
)$. Define
$$t = \frac{n^2 + m}{mn - 1}.$$
Then $t$ is a positive integer with $1 \le t < n$, and $(n, t)$ is also a soluti

*Proof.* Since $n^3 \equiv -1 \pmod{d}$ (where $d = mn-1$), we get $n^{-1} \equi
v -n^2 \pmod{d}$, and $m \equiv n^{-1} \equiv -n^2 \pmod{d}$. Therefore $n^2 + m
 \equiv n^2 - n^2 = 0 \pmod{d}$, so $d \mid n^2 + m$ and $t$ is a positive integ
er.

**(n, t) is a solution:** From $t(mn-1) = n^2 + m$ we get $m(tn - 1) = n^2 + t$,
 so $tn - 1 \mid n^2 + t$. Since $tn \equiv 1 \pmod{tn - 1}$, we have $n \equiv
t^{-1} \pmod{tn-1}$, so $n^2 + t \equiv t^{-2} + t = (1 + t^3)/t^2 \pmod{tn-1}$.
 As $\gcd(t, tn-1) = 1$, we conclude $tn - 1 \mid t^3 + 1$.

**$t < n$:** This is equivalent to $n^2 + m < n(mn - 1) = mn^2 - n$, i.e., $n <
m(n-1)$, i.e., $\frac{n}{n-1} < m$. For $n \ge 2$, $\frac{n}{n-1} \le 2$ with eq
uality iff $n = 2$. Since $m \ge 2$, we have $t < n$ unless $m = n = 2$. $\squar

### Step 4 — Reverse Step

**Lemma.** If $(a, b)$ is a solution, the unique preimage under the descent is $
(m, a)$ where $m = \frac{a^2 + b}{ab - 1}$, and this is always a positive intege

*Proof.* By the same modular argument as Step 2 (using $a^3 \equiv -1 \pmod{ab-1

$$ma - 1 = \frac{a(a^2 + b)}{ab - 1} - 1 = \frac{a^3 + 1}{ab - 1},$$

e verifies the descent from $(m, a)$ returns to $(a, b)$:
$$\frac{a^2 + m}{ma - 1} = \frac{a^2(ab-1) + a^2 + b}{a^3 + 1} = \frac{a^3 b + b
