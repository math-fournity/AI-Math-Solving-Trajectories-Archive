# Proof

**Claim:** Yes, there exists a second category set $S \subseteq X = \{0,1\}^{\ma
thbb{N}}$ with empty interior.

**Construction.** Let $M \subseteq X$ be the set of all eventually-zero sequence
s, i.e., sequences $x = (x_n)_{n \in \mathbb{N}}$ such that $x_n = 0$ for all su
fficiently large $n$. Define $S = X \setminus M$.

**Step 1: $M$ is meager.**

Each eventually-zero sequence $x$ is determined by a finite binary string $s$ (t
he prefix before the infinite tail of zeros). Hence $M$ is countable. Since $X$
is the Cantor space (compact, metrizable, perfect — no isolated points), every s
ingleton $\{x\}$ is nowhere dense in $X$: $\{x\}$ is closed, and its interior is
 empty because $x$ is not isolated. Therefore $M = \bigcup_{x \in M} \{x\}$ is a
 countable union of nowhere dense sets, so $M$ is meager (first category).

**Step 2: $M$ is dense in $X$.**

Every basic open set in $X$ is a cylinder set $[s] = \{x \in X : x \text{ extend
s the finite string } s\}$ for some finite binary string $s$. The sequence $s0^\
infty$ (extend $s$ with all zeros) belongs to $[s] \cap M$. Hence every nonempty
 open set meets $M$, so $M$ is dense.

**Step 3: $S = X \setminus M$ has empty interior.**

Since $M$ is dense, every nonempty open set $U \subseteq X$ satisfies $U \cap M
\neq \emptyset$, i.e., $U \not\subseteq S$. Hence $S$ contains no nonempty open
set, so $\operatorname{int}(S) = \emptyset$.

**Step 4: $S = X \setminus M$ is second category.**

Since $M$ is meager, $S = X \setminus M$ is comeager. The Cantor space $X$ is a
Baire space (it is compact Hausdorff, equivalently completely metrizable), so by
 the Baire category theorem, $X$ is not meager in itself. If $S$ were meager, th
en $X = S \cup M$ would be a union of two meager sets, hence meager — contradict
ing the Baire property. Therefore $S$ is not meager, i.e., $S$ is of second cate
gory.

**Conclusion.** The set $S = X \setminus M$, where $M$ is the (countable, dense,
 meager) set of eventually-zero sequences, is a second category subset of $X$ wi
th empty interior.
