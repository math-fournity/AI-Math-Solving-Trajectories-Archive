t)^2 dx$ using Parseval's identity for the Fourier transform.

**Fourier transform convention.** Define
$$\widehat{f}(\xi) = \int_{-\infty}^{\infty} f(x)\,e^{-2\pi i x\xi}\,dx.$$
With this convention, Parseval's (Plancherel's) identity states
$$\int_{-\infty}^{\infty} |f(x)|^2\,dx = \int_{-\infty}^{\infty} |\widehat{f}(\x
i)|^2\,d\xi.$$

**Choose the test function.** Let $f(x) = \mathbf{1}_{[-1/2,\,1/2]}(x)$, the ind
icator of the interval $\left[-\tfrac12,\tfrac12\right]$. Its Fourier transform
is
$$\widehat{f}(\xi) = \int_{-1/2}^{1/2} e^{-2\pi i x\xi}\,dx = \frac{e^{-2\pi i x
\xi}}{-2\pi i\xi}\Bigg|_{-1/2}^{1/2} = \frac{e^{\pi i\xi}-e^{-\pi i\xi}}{2\pi i\
xi} = \frac{\sin(\pi\xi)}{\pi\xi}.$$

**Apply Parseval.** The left-hand side is
$$\int_{-\infty}^{\infty}|f(x)|^2\,dx = \int_{-1/2}^{1/2}1\,dx = 1.$$
The right-hand side is
$$\int_{-\infty}^{\infty}|\widehat{f}(\xi)|^2\,d\xi = \int_{-\infty}^{\infty}\le
ft(\frac{\sin(\pi\xi)}{\pi\xi}\right)^2 d\xi.$$
Parseval's identity therefore gives
$$\int_{-\infty}^{\infty}\left(\frac{\sin(\pi\xi)}{\pi\xi}\right)^2 d\xi = 1.$$

**Change of variables.** Set $x = \pi\xi$, so $dx = \pi\,d\xi$ and $\dfrac{d\xi}
{1} = \dfrac{dx}{\pi}$. Then
$$\int_{-\infty}^{\infty}\left(\frac{\sin(\pi\xi)}{\pi\xi}\right)^2 d\xi = \int_
{-\infty}^{\infty}\left(\frac{\sin x}{x}\right)^2 \frac{dx}{\pi} = \frac{1}{\pi}
\int_{-\infty}^{\infty}\left(\frac{\sin x}{x}\right)^2 dx.$$

Combining with the value $1$ from Parseval:
$$\frac{1}{\pi}\int_{-\infty}^{\infty}\left(\frac{\sin x}{x}\right)^2 dx = 1,$$

hence

$$\boxed{\displaystyle\int_{-\infty}^{\infty}\left(\frac{\sin x}{x}\right)^2 dx
