## Proof

Let $p \in M_n(\mathbb{C})$ with $\|p - p^*\| < \varepsilon$ and $\|p - p^2\| <
\varepsilon$.

### Step 1: Bounding $\|p\|$

Set $\delta = p^* - p$, so $\|\delta\| < \varepsilon$. Compute:
$$p^*p - p^2 = (p^* - p)p = \delta p, \quad \text{so } \|p^*p - p^2\| \le \|\del
ta\|\|p\| < \varepsilon\|p\|.$$
$$p^*p - p = (p^*p - p^2) + (p^2 - p), \quad \text{so } \|p^*p - p\| < \varepsil
on\|p\| + \varepsilon.$$
Since $p^*p$ is positive, $\|p\|^2 = \|p^*p\| \le \|p^*p - p\| + \|p\| < (1+\var
epsilon)\|p\| + \varepsilon$.

So $\|p\|$ satisfies $x^2 - (1+\varepsilon)x - \varepsilon < 0$, giving:
$$\|p\| < \frac{(1+\varepsilon) + \sqrt{(1+\varepsilon)^2 + 4\varepsilon}}{2}.$$

For $\varepsilon \le 1$: $(1+\varepsilon)^2 + 4\varepsilon = 1 + 6\varepsilon +
\varepsilon^2 \le 1 + 7\varepsilon$, and $\sqrt{1+7\varepsilon} \le 1 + \frac{7\
varepsilon}{2}$, so $\|p\| < 1 + \frac{9\varepsilon}{4} \le 1 + 3\varepsilon$.

For $\varepsilon > 1$: $(1+\varepsilon)^2 + 4\varepsilon \le 4\varepsilon^2 + 4\
varepsilon^2 = 8\varepsilon^2$, so $\sqrt{\cdot} \le 3\varepsilon$, giving $\|p\
| < \frac{2\varepsilon + 3\varepsilon}{2} = \frac{5\varepsilon}{2} < 1 + 3\varep
silon$.

**In all cases:** $\|p\| < 1 + 3\varepsilon$. $\quad(\star)$

### Step 2: Pass to the self-adjoint part

Let $a = \frac{p + p^*}{2}$. Then $a = a^*$ and $\|a - p\| = \|\delta/2\| < \var
epsilon/2$.

Compute $\|a - a^2\|$:
$$a - a^2 = (p - p^2) + \frac{\delta}{2} - \frac{p\delta}{2} - \frac{\delta p}{2
} - \frac{\delta^2}{4}.$$
$$\|a - a^2\| \le \|p - p^2\| + \frac{\|\delta\|}{2} + \|p\|\|\delta\| + \frac{\
|\delta\|^2}{4} < \frac{3\varepsilon}{2} + \|p\|\varepsilon + \frac{\varepsilon^
2}{4}.$$

Using $(\star)$: $\|a - a^2\| < \frac{3\varepsilon}{2} + (1+3\varepsilon)\vareps
ilon + \frac{\varepsilon^2}{4} = \frac{5\varepsilon}{2} + \frac{13\varepsilon^2}
{4}$.

For $\varepsilon < 1$: $\frac{13\varepsilon^2}{4} < \frac{13\varepsilon}{4}$, so
 $\|a - a^2\| < \frac{5\varepsilon}{2} + \frac{13\varepsilon}{4} = \frac{23\vare
psilon}{4} < 6\varepsilon$. $\quad(\star\star)$

### Step 3: Spectral construction of $q$ (small $\varepsilon$)

Assume $\varepsilon < \frac{1}{24}$, so $6\varepsilon < \frac{1}{4}$.

Since $a$ is self-adjoint, $a - a^2$ is self-adjoint, and $\|a - a^2\| = \max_\l
ambda |\lambda(1-\lambda)|$ over eigenvalues $\lambda$ of $a$. By $(\star\star)$
, every eigenvalue satisfies $|\lambda(1-\lambda)| < 6\varepsilon$.

Since $\lambda(1-\lambda) = \frac{1}{4} - (\lambda - \frac{1}{2})^2$, the condit
ion $|\lambda(1-\lambda)| < 6\varepsilon < \frac{1}{4}$ forces $(\lambda - \frac
{1}{2})^2 > \frac{1}{4} - 6\varepsilon$, so every eigenvalue satisfies $|\lambda
 - \frac{1}{2}| > \sqrt{\frac{1}{4} - 6\varepsilon} > 0$. The spectrum is separa
ted from $\frac{1}{2}$.

Define $q = \chi_{(1/2,\infty)}(a)$ via functional calculus. Then $q = q^* = q^2
$ is a projection.

- For eigenvalues $\lambda < \frac{1}{2}$: $q$ acts as $0$, and $|\lambda| = \fr
ac{|\lambda(1-\lambda)|}{|1-\lambda|} < \frac{6\varepsilon}{1/2} = 12\varepsilon
$ (since $|1-\lambda| > 1/2$).
- For eigenvalues $\lambda > \frac{1}{2}$: $q$ acts as $1$, and $|1-\lambda| = \
frac{|\lambda(1-\lambda)|}{|\lambda|} < \frac{6\varepsilon}{1/2} = 12\varepsilon
$ (since $|\lambda| > 1/2$).

Therefore $\|q - a\| < 12\varepsilon$, and:
$$\|q - p\| \le \|q - a\| + \|a - p\| < 12\varepsilon + \frac{\varepsilon}{2} =
\frac{25\varepsilon}{2} < 13\varepsilon.$$

### Step 4: Large $\varepsilon$ case

For $\varepsilon \ge \frac{1}{24}$: by $(\star)$, $\|p\| < 1 + 3\varepsilon \le
24\varepsilon + 3\varepsilon = 27\varepsilon$ (using $1 \le 24\varepsilon$). Tak
e $q = 0$ (the zero projection):
$$\|q - p\| = \|p\| < 27\varepsilon.$$

### Conclusion

In both cases, there exists a projection $q$ with $\|q - p\| < 27\varepsilon$. T
he constant $k = 27$ is independent of $\varepsilon$ (and of $n$). $\blacksquare
