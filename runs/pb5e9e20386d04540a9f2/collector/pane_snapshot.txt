## Theorem (Jackson)

Let $f \in C([-1,1])$ satisfy $|f(x)-f(y)| \le M|x-y|^{\alpha}$ with $M, \alpha
> 0$. Let

$$E_n(f) := \inf_{p \in \Pi_n} \|f - p\|_{\infty}$$

denote the best uniform approximation error by polynomials of degree $\le n$. Th
en there exists a constant $C = C(\alpha) > 0$ such that

$$\boxed{E_n(f) \le C\, M\, n^{-\alpha} \quad \text{for all } n \ge 1.}$$

This rate is **sharp**: there exist Hölder-$\alpha$ functions for which $E_n(f)
\ge c\, n^{-\alpha}$, so the exponent $-\alpha$ cannot be improved in general.

---

## Proof

**Preliminary observation.** If $\alpha > 1$, then for any $x$, $|f(x)-f(y)|/|x-
y| \le M|x-y|^{\alpha-1} \to 0$ as $y \to x$, so $f'(x)=0$ everywhere; since $[-
1,1]$ is connected and $f$ is continuous, $f$ is constant and $E_n(f)=0$ trivial
ly. Hence we assume $0 < \alpha \le 1$ (the bound holds regardless).

### Step 1 — Reduction to a periodic problem

Define $g(\theta) = f(\cos\theta)$. Then $g$ is $2\pi$-periodic and continuous.
Since $|\cos\theta - \cos\varphi| \le |\theta-\varphi|$ and, being $2\pi$-period
ic in both arguments, $|\cos\theta-\cos\varphi| \le d(\theta,\varphi)$ (the peri
odic distance), we get

$$|g(\theta)-g(\varphi)| = |f(\cos\theta)-f(\cos\varphi)| \le M\,d(\theta,\varph
i)^{\alpha}.$$

So $g$ is Hölder-$\alpha$ on the circle with the **same** constant $M$.

### Step 2 — The Jackson kernel

Define

$$K_n(t) = c_n\left(\frac{\sin(nt/2)}{\sin(t/2)}\right)^{\!4}, \qquad c_n = \fra
c{3}{\,n(2n^2+1)\,},$$

where $c_n$ is chosen so that $\frac{1}{2\pi}\int_0^{2\pi} K_n(t)\,dt = 1$. (The
 normalization follows from $\frac{1}{2\pi}\int_0^{2\pi}\!\left[\frac{\sin(nt/2)
}{\sin(t/2)}\right]^4 dt = \frac{n(2n^2+1)}{3}$, computed via $[\sin(nt/2)/\sin(
t/2)]^2 = n\,F_{n-1}(t)$ with $F_{n-1}$ the Fejér kernel, and $\frac{1}{2\pi}\in
t F_{n-1}^2 = \frac{2n^2+1}{3n}$.)

$K_n$ is a **non-negative** trigonometric polynomial of degree $2n-2$.

### Step 3 — Convolution approximation

Set

$$g_n(\theta) = \frac{1}{2\pi}\int_0^{2\pi} g(\theta - t)\,K_n(t)\,dt.$$

Then $g_n$ is a trigonometric polynomial of degree $2n-2$. Using $\frac{1}{2\pi}
\int K_n = 1$ and the Hölder bound:

$$|g(\theta) - g_n(\theta)| \le \frac{1}{2\pi}\int_0^{2\pi} |g(\theta)-g(\theta-
t)|\,K_n(t)\,dt \le \frac{M}{2\pi}\int_0^{2\pi} d(t,0)^{\alpha}\,K_n(t)\,dt.$$

By evenness and periodicity of $K_n$, this equals

$$\frac{M}{\pi}\int_0^{\pi} t^{\alpha}\,K_n(t)\,dt =: M\,I_n.$$

### Step 4 — Estimating $I_n$

**Bound on $K_n$.** For $t \in (0,\pi]$, $\sin(t/2) \ge t/\pi$, so $\sin(nt/2)^4
 \le 1$ gives

$$K_n(t) \le c_n\left(\frac{\pi}{t}\right)^{\!4}.$$

Also $K_n(0) = c_n n^4 = \frac{3n^3}{2n^2+1} \le \frac{3}{2}\,n$.

**Split** $I_n = \frac{1}{\pi}\bigl(\int_0^{1/n} + \int_{1/n}^{\pi}\bigr)$.

*First piece:*
$$\frac{1}{\pi}\int_0^{1/n} t^{\alpha}K_n(t)\,dt \le \frac{1}{\pi}\cdot\frac{3n}
{2}\cdot\frac{(1/n)^{\alpha+1}}{\alpha+1} = \frac{3}{2\pi(\alpha+1)}\,n^{-\alpha
}.$$

*Second piece* (using $K_n(t) \le c_n \pi^4 t^{-4}$ and $\alpha < 3$):
$$\frac{1}{\pi}\int_{1/n}^{\pi} t^{\alpha}K_n(t)\,dt \le \frac{c_n\pi^3}{1}\int_
{1/n}^{\pi} t^{\alpha-4}\,dt = c_n\pi^3\cdot\frac{(1/n)^{\alpha-3} - \pi^{\alpha
-3}}{3-\alpha} \le \frac{c_n\pi^3}{3-\alpha}\,n^{3-\alpha}.$$

Since $c_n = \frac{3}{n(2n^2+1)} \le \frac{3}{2n^3}$, this is at most

$$\frac{3\pi^3}{2(3-\alpha)}\,n^{-\alpha}.$$

Combining,

$$I_n \le \left(\frac{3}{2\pi(\alpha+1)} + \frac{3\pi^3}{2(3-\alpha)}\right) n^{
-\alpha} =: C_1(\alpha)\,n^{-\alpha}.$$

### Step 5 — Trigonometric to algebraic

We have shown $\|g - g_n\|_{\infty} \le C_1(\alpha)\,M\,n^{-\alpha}$, where $g_n
$ has degree $2n-2$. Setting $m = 2n-2$ (so $n = (m+2)/2 \ge m/2$ for $m\ge 2$):

$$\|g - g_m^{\text{trig}}\|_{\infty} \le C_1(\alpha)\,M\left(\tfrac{m+2}{2}\righ
t)^{-\alpha} \le C_2(\alpha)\,M\,m^{-\alpha}.$$

Since $g(\theta) = f(\cos\theta)$ is **even** in $\theta$, we may take $g_m^{\te
xt{trig}}$ to be even: $g_m^{\text{trig}}(\theta) = \sum_{k=0}^{m} b_k \cos(k\th
eta)$. Using $\cos(k\theta) = T_k(\cos\theta)$ (Chebyshev polynomials),

$$g_m^{\text{trig}}(\theta) = \sum_{k=0}^{m} b_k\,T_k(\cos\theta) =: P_m(\cos\th
eta),$$

where $P_m$ is an algebraic polynomial of degree $\le m$. Therefore

$$E_m(f) \le \|f - P_m\|_{\infty} = \sup_{\theta}\,|g(\theta) - g_m^{\text{trig}
}(\theta)| \le C_2(\alpha)\,M\,m^{-\alpha}. \qquad\square$$

## Sharpness (Bernstein's converse)

The rate $n^{-\alpha}$ is **best possible**. By Bernstein's theorem: if $E_n(f)
= O(n^{-\beta})$ for some $0 < \beta < 1$, then $f$ satisfies a Hölder condition
 of order $\beta$. Consequently, a function that is Hölder-$\alpha$ but **not**
Hölder-$\alpha+\varepsilon$ for any $\varepsilon > 0$ (e.g. $f(x) = |x|^{\alpha}
$ on $[-1,1]$, $0 < \alpha < 1$) must have $E_n(f) \not= O(n^{-\alpha-\varepsilo
n})$ for any $\varepsilon > 0$. Combined with the upper bound, $E_n(f) = \Theta(
n^{-\alpha})$ for such functions.

(For $\alpha = 1$, the exact converse involves the Zygmund class $\lambda_*$; Li
pschitz functions satisfy $E_n(f) = O(n^{-1})$ and this is sharp for, e.g., $f(x
) = |x|$.)

---

**Summary.** A Hölder-$\alpha$ function on $[-1,1]$ admits polynomial approximat
ion in the uniform norm at rate $E_n(f) \le C(\alpha)\,M\,n^{-\alpha}$, and this
 exponent $\alpha$ is optimal in general — establishing a precise correspondence
 between the smoothness parameter $\alpha$ and the algebraic rate of convergence
 $n^{-\alpha}$.
