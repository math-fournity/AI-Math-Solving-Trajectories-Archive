# Problem

A specialized digital vault uses a security protocol based on a "digit-shuffling" algorithm. For any positive integer $n$ entered into the system, the computer generates every possible sequence of digits that can be formed by rearranging the digits of $n$ (this includes sequences that begin with one or more zeros). The system then calculates $f(n)$, which is the greatest common divisor of all these generated sequences.

The vault’s integrity is maintained by a "Self-Identity Rule," where for most numbers, $f(n)$ is equal to the original number $n$ itself. However, there are rare cases where the security protocol produces a value such that $f(n) \neq n$. 

Among all such positive integers $n$ that violate the Self-Identity Rule ($f(n) \neq n$), find the largest possible value that $f(n)$ can achieve.
