## 解答

**问题：** 设 $a, b, c \in \mathbb{R}$ 满足 $a^2 + b^2 + c^2 = 3$。求 $P = abc +
 2(ab+bc+ca) + 4(a+b+c)$ 的最小值。

### 步骤 1：拉格朗日乘数法 (Lagrange Multiplier) 设置

设 $g = a^2+b^2+c^2-3$。在临界点处，$\nabla P = \lambda \nabla g$，即：

$$\frac{\partial P}{\partial a} = bc + 2(b+c) + 4 = 2\lambda a, \quad \text{(对
} b, c \text{ 同理)}$$

### 步骤 2：减法消元法

用 $a$ 的方程减去 $b$ 的方程：

$$[bc - ac] + 2[(b+c)-(a+c)] = 2\lambda(a - b)$$
$$(b-a)(c+2) = -2\lambda(b-a)$$
$$(b-a)(c + 2 + 2\lambda) = 0.$$

同理可得 $(c-b)(a+2+2\lambda)=0$ 和 $(a-c)(b+2+2\lambda)=0$。

**如果 $a, b, c$ 互不相等**，则 $c+2+2\lambda = a+2+2\lambda = b+2+2\lambda = 0$
，这意味着 $a=b=c$，产生矛盾。因此，**至少有两个变量必须相等**。

### 步骤 3：情况 $a = b = t$, $c = u$

约束条件：$2t^2 + u^2 = 3$。

根据 $a$ 的方程：$tu + 2(t+u) + 4 = 2\lambda t$，得出 $2\lambda = u + 2 + \frac{
2(u+2)}{t}$ (当 $t \neq 0$ 时)。

根据 $c$ 的方程：$t^2 + 4t + 4 = 2\lambda u$，得出 $2\lambda = \frac{(t+2)^2}{u}
$ (当 $u \neq 0$ 时)。

令两者相等：$(u+2)\left(1 + \frac{2}{t}\right) = \frac{(t+2)^2}{u}$，化简为 $\fr
ac{(u+2)(t+2)}{t} = \frac{(t+2)^2}{u}$。

当 $t + 2 \neq 0$ 时：$u(u+2) = t(t+2)$，即 $(u-t)(u+t+2) = 0$。

- $u = t$：所有变量相等（情况 1）。
- $u = -t - 2$：代入约束条件：$2t^2 + (t+2)^2 = 3 \Rightarrow 3t^2 + 4t + 1 = 0
\Rightarrow (3t+1)(t+1) = 0$。

  - $t = -1 \Rightarrow u = -1$：所有变量等于 $-1$（情况 1）。
  - $t = -\tfrac{1}{3} \Rightarrow u = -\tfrac{5}{3}$：**新临界点**。

边界情况 $t = 0$, $u = 0$, $t = -2$ 均不产生实数解（已验证）。

### 步骤 4：计算 $P$

**情况 1：** $a = b = c = 1$: $P = 1 + 6 + 12 = 19$.
**情况 1：** $a = b = c = -1$: $P = -1 + 6 - 12 = -7$.

**情况 2：** $a = b = -\tfrac{1}{3}$, $c = -\tfrac{5}{3}$ (及其所有排列)：

$$abc = \left(-\tfrac{1}{3}\right)^2\!\left(-\tfrac{5}{3}\right) = -\tfrac{5}{27
}, \quad ab+bc+ca = \tfrac{1}{9} + \tfrac{5}{9} + \tfrac{5}{9} = \tfrac{11}{9},
\quad a+b+c = -\tfrac{7}{3}.$$

$$P = -\tfrac{5}{27} + \tfrac{22}{9} - \tfrac{28}{3} = \frac{-5 + 66 - 252}{27}
= -\frac{191}{27}.$$

### 步骤 5：全局最小值

球面 $\{a^2+b^2+c^2=3\}$ 是紧致的，且 $P$ 是连续函数，因此全局最小值在临界点处取
得。我们已经列举了所有临界点：

$$P \in \left\{19,\; -7,\; -\tfrac{191}{27}\right\}, \qquad -\tfrac{191}{27} \ap
prox -7.074 < -7.$$

因此，全局最小值为 $\boxed{-\dfrac{191}{27}}$。
