## Proof

**Claim.** The least upper bound is $\omega_1$, the first uncountable ordinal.

---

**Upper bound.** Let $S = \bigcup_{n<\omega} F_n$ where each $F_n$ is a finite s
et of ordinals. In ZFC, the Axiom of Choice implies that a countable union of fi
nite (hence countable) sets is countable. Therefore $S$ is a countable set of or
dinals. Any set of ordinals is well-ordered by $\in$, and a countable well-order
ed set has a countable order type. Hence $\operatorname{otp}(S) < \omega_1$ for
every such $S$. So $\omega_1$ is an upper bound on the set of achievable order t
ypes.

**Lower bound.** Let $\alpha$ be any countable ordinal. Then $\alpha$ itself is
a countable set of ordinals. Enumumerate its elements as $\alpha = \{a_0, a_1, a
_2, \dots\}$ (possible since $\alpha$ is countable). Set $F_n = \{a_n\}$ for eac
h $n < \omega$; each $F_n$ is finite (a singleton), and
$$\alpha = \bigcup_{n<\omega} F_n.$$
The order type of $\alpha$ as a set of ordinals under $\in$ is $\alpha$ itself.
Thus every countable ordinal is realized as the order type of some countable uni
on of finite sets of ordinals.

**Conclusion.** The set of achievable order types is exactly the class of all co
untable ordinals, i.e., $\omega_1$ itself (viewed as the set of all countable or
dinals). Its supremum is $\omega_1$. Note that $\omega_1$ is not itself achieved
 (it is uncountable), so it is a supremum, not a maximum.

The role of ZFC is essential: the implication "countable union of finite sets is
 countable" requires a choice principle (countable choice for finite sets), whic
h is guaranteed by the full Axiom of Choice in ZFC.

$$\boxed{\omega_1}$$
