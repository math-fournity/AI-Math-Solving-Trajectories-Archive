# Problem

In a remote industrial refinery, a central storage tank initially holds a single chemical compound with a concentration level of $x$. The refinery's processing unit can synthesize new concentrations from existing ones stored in the system according to two strict protocols:

1.  **The Inversion Protocol:** If a compound with a non-zero concentration $f$ is currently stored, a new compound with the reciprocal concentration $\frac{1}{f}$ can be synthesized and added to the storage.
2.  **The Combining Protocol:** If two compounds with concentrations $f$ and $g$ are stored, the unit can create new batches with concentrations equal to their sum ($f + g$) and their difference ($f - g$).

Engineers are investigating the "Power Set" $S$, which consists of all natural numbers $n$ such that a concentration of exactly $x^n$ can be successfully synthesized for any initial concentration $x$. 

Find the sum of the four smallest elements contained in the set $S$.
