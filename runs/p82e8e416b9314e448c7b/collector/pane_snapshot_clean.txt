## Proof

Let $f_\alpha(x) = \sum_{n=1}^\infty n^\alpha\, x\, e^{-nx} = x\, g_\alpha(x)$,
where $g_\alpha(x) := \sum_{n=1}^\infty n^\alpha e^{-nx}$.

### Step 1: Well-definedness

For every $x > 0$ and every $\alpha \in \mathbb{R}$, the series converges absolu
tely since $n^\alpha e^{-nx}$ decays exponentially. At $x=0$, every term is $0$,
 so $f_\alpha(0)=0$. Thus $f_\alpha$ is defined on all of $[0,\infty)$ for every
 $\alpha$.

### Step 2: Continuity on $(0,\infty)$

On any $[\delta, \infty)$ with $\delta > 0$, the Weierstrass $M$-test gives unif
orm convergence: $|n^\alpha x e^{-nx}| \le n^\alpha e^{-n\delta}$ (for $x \ge \d
elta$, using $x e^{-nx} \le C_\delta e^{-n\delta/2}$, or more simply $n^\alpha e
^{-nx} \le n^\alpha e^{-n\delta}$ and $x$ bounded on compact subintervals). Each
 term is continuous, so $f_\alpha$ is continuous on $(0,\infty)$ for **all** $\a
lpha$.

### Step 3: Continuity at $x = 0$

We need $\lim_{x\to 0^+} f_\alpha(x) = f_\alpha(0) = 0$, i.e., $\lim_{x\to 0^+}
x\, g_\alpha(x) = 0$.

**Case $\alpha < -1$:** The series $\sum n^\alpha$ converges. Since $0 < e^{-nx}
 \le 1$ and $n^\alpha e^{-nx} \le n^\alpha$ (summable), dominated convergence gi
ves $g_\alpha(x) \to \sum_{n=1}^\infty n^\alpha < \infty$. Hence $x\,g_\alpha(x)
 \to 0$. ✓

**Case $\alpha = -1$:** $g_{-1}(x) = \sum \frac{e^{-nx}}{n} = -\ln(1-e^{-x})$. A
s $x\to 0^+$, $1-e^{-x}\sim x$, so $g_{-1}(x)\sim -\ln x$, and $x\,g_{-1}(x) \si
m -x\ln x \to 0$. ✓

**Case $-1 < \alpha < 0$:** We use the standard asymptotic. For $\alpha > -1$,
$$\sum_{n=1}^\infty n^\alpha e^{-nx} \;\sim\; \int_0^\infty t^\alpha e^{-tx}\,dt
 = \frac{\Gamma(\alpha+1)}{x^{\alpha+1}} \quad (x\to 0^+).$$
(Justification: the sum is a Riemann-type sum for the integral; the function $t\
mapsto t^\alpha e^{-tx}$ has its mass concentrated near $t\sim 1/x$, and the rel
ative error $\to 0$.) Therefore
$$x\,g_\alpha(x) \sim \Gamma(\alpha+1)\, x^{-\alpha} \to 0 \quad\text{since } -\
alpha > 0.\;\checkmark$$

**Case $\alpha = 0$:** $g_0(x) = \frac{1}{e^x - 1}$, so $f_0(x) = \frac{x}{e^x-1
} \to 1 \neq 0$. ✗

**Case $\alpha > 0$:** From the same asymptotic, $x\,g_\alpha(x) \sim \Gamma(\al
pha+1)\,x^{-\alpha} \to +\infty$. ✗

**Conclusion:** $f_\alpha$ is continuous on $[0,\infty)$ **iff $\alpha < 0$**.

### Step 4: Lebesgue integrability on $[0,\infty)$

Since every term $n^\alpha x e^{-nx} \ge 0$ on $[0,\infty)$, $f_\alpha \ge 0$, s
o integrability means $\int_0^\infty f_\alpha < \infty$. By Tonelli's theorem (n
on-negative terms, justifying termwise integration):
$$\int_0^\infty f_\alpha(x)\,dx = \sum_{n=1}^\infty n^\alpha \int_0^\infty x\, e
^{-nx}\,dx = \sum_{n=1}^\infty n^\alpha \cdot \frac{1}{n^2} = \sum_{n=1}^\infty
n^{\alpha-2}.$$
This $p$-series converges iff $\alpha - 2 < -1$, i.e., **$\alpha < 1$**.

When $\alpha < 1$, the integral is finite, so $f_\alpha$ is finite a.e. and Lebe
sgue integrable. When $\alpha \ge 1$, the integral is $+\infty$, so $f_\alpha$ i
s not integrable.

### Step 5: Combining both conditions

- Continuity on $[0,\infty)$: $\alpha < 0$.
- Integrability on $[0,\infty)$: $\alpha < 1$.

Both conditions hold simultaneously iff $\alpha < 0$ (since $\alpha < 0 \implies
 \alpha < 1$).
