The statement is **TRUE**. Here is the proof.

---

**Claim.** A non-negative real-valued function $f$ on $[0,1]$ is measurable if a
nd only if there exist measurable sets $E_n \subseteq [0,1]$ and non-negative co
nstants $c_n$ (with the index $n$ ranging over a finite or countable set) such t
hat
$$f(x) = \sum_n c_n\,\chi_{E_n}(x) \quad \text{for every } x \in [0,1].$$

---

### Proof of "$\Longleftarrow$" (such a representation implies measurability)

Suppose $f = \sum_n c_n \chi_{E_n}$ with each $c_n \ge 0$ and each $E_n$ measura
ble. Define the partial sums
$$S_N(x) = \sum_{n=1}^{N} c_n\,\chi_{E_n}(x).$$
Each $S_N$ is a finite sum of measurable functions (constants times characterist
ic functions of measurable sets), hence measurable. Since every $c_n \ge 0$, the
 sequence $\{S_N\}$ is non-decreasing, and $S_N(x) \to f(x)$ pointwise. A pointw
ise limit of measurable functions is measurable, so $f$ is measurable. $\checkma
rk$

---

### Proof of "$\Longrightarrow$" (measurability implies such a representation)

Suppose $f \ge 0$ is measurable. By the **Simple Function Approximation Theorem*
*, there exists a sequence $\{s_n\}_{n=1}^{\infty}$ of non-negative simple funct
ions such that:

- $0 \le s_1 \le s_2 \le \cdots \le f$,
- $s_n(x) \to f(x)$ for every $x \in [0,1]$.

(For instance, one may take the standard construction $s_n = \sum_{k=0}^{n2^n -
1} \frac{k}{2^n}\,\chi_{\{k/2^n \le f < (k+1)/2^n\}} + n\,\chi_{\{f \ge n\}}$.)

Now **telescope** the series. Set $t_1 = s_1$ and $t_n = s_n - s_{n-1}$ for $n \
ge 2$. Then:

1. **Each $t_n$ is a non-negative simple function.** It is simple because the si
mple functions form a vector space (a difference of simple functions is simple).
 It is non-negative because $s_n \ge s_{n-1}$.

2. **The series telescopes to $f$:** for every $x$,
$$\sum_{n=1}^{N} t_n(x) = s_N(x) \xrightarrow{N\to\infty} f(x),$$
so $f(x) = \sum_{n=1}^{\infty} t_n(x)$.

3. **Each $t_n$ admits a standard representation.** Since $t_n$ is a non-negativ
e simple function, it can be written as
$$t_n = \sum_{j=1}^{m_n} a_{n,j}\,\chi_{A_{n,j}},$$
where $m_n < \infty$, each $a_{n,j} \ge 0$ is a non-negative constant, and each
$A_{n,j}$ is a measurable set (one may take the $A_{n,j}$ to be the disjoint lev
el sets $\{t_n = a_{n,j}\}$).

Combining steps 2 and 3, we obtain
$$f(x) = \sum_{n=1}^{\infty} \sum_{j=1}^{m_n} a_{n,j}\,\chi_{A_{n,j}}(x).$$

The double sum ranges over a countable index set (a countable union of finite se
ts). Re-indexing this countable family as a single sequence $\{(c_n, E_n)\}$ yie
lds
$$f(x) = \sum_n c_n\,\chi_{E_n}(x) \quad \text{for all } x \in [0,1],$$
with every $c_n \ge 0$ and every $E_n$ measurable. $\checkmark$

---

**Remark.** If $f$ is itself a simple function, the construction terminates afte
r finitely many terms, giving a *finite* sequence. In general, the sequence is c
ountably infinite. The problem's phrasing "finite or infinite" covers both cases
.

---

Both directions have been established, so the statement is **true**.
