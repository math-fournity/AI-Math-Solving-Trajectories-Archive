## Solution

The expression is $E = a_1 - a_2 + a_3 - a_4 + \cdots + a_{19} - a_{20}$, where
positions $1,3,5,\dots,19$ carry a $+$ sign and positions $2,4,\dots,20$ carry a
 $-$ sign. There are $10$ positive positions and $10$ negative positions.

Let $S$ be the sum of the $10$ numbers placed in the positive positions. Since t
he $a_i$ form a permutation of $1,\dots,20$, the sum of the numbers in the negat
ive positions is $210 - S$ (because $1+2+\cdots+20 = 210$). Hence

$$E = S - (210 - S) = 2S - 210.$$

So the number of distinct values of $E$ equals the number of distinct values of
$S$, where $S$ ranges over the sums of all $10$-element subsets of $\{1,2,\dots,
20\}$.

**Range of $S$.** The minimum is $1+2+\cdots+10 = 55$ and the maximum is $11+12+
\cdots+20 = 155$.

**Every integer in $[55,155]$ is achievable.** Represent a $10$-element subset a
s $x_1 < x_2 < \cdots < x_{10}$ with $1 \le x_1$, $x_i < x_{i+1}$, $x_{10} \le 2
0$. Set $y_i = x_i - i$, so

$$0 \le y_1 \le y_2 \le \cdots \le y_{10} \le 10,$$

and $S = 55 + (y_1 + y_2 + \cdots + y_{10})$. Thus the achievable values of $S$
are exactly $55 + T$, where $T$ is the sum of a non-decreasing $10$-tuple of int
egers each in $[0,10]$.

We claim every integer $T \in [0, 100]$ is achievable. For any $T$ with $0 \le T
 \le 100$, write $T = 10q + r$ with $0 \le r < 10$. Then $q \le 10$.
- If $q < 10$ and $r > 0$: take the tuple $(\underbrace{0,\dots,0}_{9-q},\, r,\,
 \underbrace{10,\dots,10}_{q})$, which is non-decreasing with $10$ entries, each
 in $[0,10]$, summing to $r + 10q = T$.
- If $r = 0$: take $(\underbrace{0,\dots,0}_{10-q},\, \underbrace{10,\dots,10}_{
q})$, summing to $10q = T$.
- If $q = 10$: then $T = 100$ and $r = 0$, take $(10,10,\dots,10)$.

Hence every $T \in [0,100]$ is achievable, so $S$ attains every integer value fr
om $55$ to $155$ — a total of $155 - 55 + 1 = 101$ values.

**Conclusion.** Since $E = 2S - 210$ and $S$ ranges over all $101$ integers from
 $55$ to $155$, the expression $E$ ranges over

$$2\cdot 55 - 210 = -100,\quad -98,\quad \dots,\quad 98,\quad 2\cdot 155 - 210 =
 100,$$

i.e., all even integers from $-100$ to $100$, giving

$$\boxed{101}$$

distinct values.
