Looking at this problem, I need to find all pairs $(n, m)$ with $n > m \geq 1$ a
nd $n < 50$ satisfying the tournament condition.

## Setting Up the Key Equation

Let $L$ be the set of $m$ lowest-scoring teams and $W$ the remaining $n-m$ teams
. Each game awards 2 total points, so the tournament total is $n(n-1)$.

**Points within $L$:** Each team $i \in L$ earns $T_i/2$ from games against $L$
(the other $m-1$ teams). Summing over all $L$ teams, each intra-$L$ game contrib
utes to two $L$ teams, so:
$$\sum_{i \in L} T_i/2 = m(m-1) \implies \sum_{i \in L} T_i = 2m(m-1)$$

**Points from $L$-$W$ games:** Each $L$ team also earns $T_i/2$ from $W$ games,
so $L$'s total vs $W$ is $m(m-1)$. The $L$-$W$ games have total $2m(n-m)$ points
, so $W$ earns $2m(n-m) - m(m-1) = m(2n-3m+1)$ from these games. Since each $W$
team earns $T_j/2$ against $L$:
$$\sum_{j \in W} T_j = 2m(2n-3m+1)$$

**Total:** $\sum_L T_i + \sum_W T_j = 2m(m-1) + 2m(2n-3m+1) = 4m(n-m) = n(n-1)$.

## Solving the Equation

$$n(n-1) = 4m(n-m) \implies n^2 - (4m+1)n + 4m^2 = 0$$

By the quadratic formula: $n = \frac{(4m+1) \pm \sqrt{8m+1}}{2}$.

For $n$ to be an integer, $8m+1 = k^2$ with $k$ odd. Setting $k = 2t+1$ gives $m
 = \frac{t(t+1)}{2}$ (triangular numbers), and:

- **Case 1 (+):** $n = (t+1)^2$
- **Case 2 (−):** $n = t^2$

## Ruling Out Case 2

For Case 2 ($n = t^2$, $m = t(t+1)/2$, $t \geq 2$):

- Average $L$ score: $\frac{2m(m-1)}{m} = 2(m-1) = t^2 + t - 2$
- Average $W$ score: $\frac{2m(2n-3m+1)}{n-m} = t^2 - t - 2$

Since average $W$ < average $L$ for all $t \geq 2$, it is **impossible** for all
 $W$ scores to exceed all $L$ scores. Case 2 is ruled out.

## Verifying Case 1

For Case 1 ($n = (t+1)^2$, $m = t(t+1)/2$):

- Average $L$ score: $t^2 + t - 2$
- Average $W$ score: $t^2 + 3t$

Since $t^2 + 3t > t^2 + t - 2$ for $t \geq 1$, the ordering constraint is satisf
iable.

**Construction:** Assign uniform scores — all $L$ teams score $s_L = 2(m-1)$, al
l $W$ teams score $s_W = t(t+3)$.

- **Intra-$L$ games:** All ties → each $L$ team gets $m-1 = s_L/2$ points. ✓
- **Intra-$W$ games:** All ties → each $W$ team gets $n-m-1 = t(t+3)/2 = s_W/2$
points. ✓
- **$L$-$W$ games:** Need a matrix (rows = $L$ teams, columns = $W$ teams) with
entries in $\{0,1,2\}$, row sums $= (t-1)(t+2)/2$, column sums $= t(t-1)/2$.

The matrix existence follows from a network flow argument: source→rows (capacity
 = row sum), rows→columns (capacity 2), columns→sink (capacity = column sum). I
verified the max-flow min-cut condition holds for all $t \geq 1$ — specifically,
 the critical cut inequality reduces to $b \leq (t+1)(t+2)/2 = n-m$, which is al
ways satisfied since $b$ is at most the number of columns. Both $s_L$ and $s_W$
are even (products of consecutive integers), and $s_L < s_W$ strictly, so $L$ is
 unambiguously the bottom $m$.
