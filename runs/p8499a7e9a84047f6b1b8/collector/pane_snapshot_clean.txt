# Christoffel Symbols of the Levi-Civita Connection

## Setup

Let $(M, g_{ab})$ be a (pseudo-)Riemannian manifold. The **Levi-Civita connectio
n** $\nabla$ is the unique affine connection on $TM$ that is:

1. **Torsion-free**: $\nabla_a \nabla_b f = \nabla_b \nabla_a f$ for all smooth
$f$, equivalently $\Gamma^d_{bc} = \Gamma^d_{cb}$.
2. **Metric-compatible**: $\nabla_c g_{ab} = 0$.

We work in a coordinate basis $\{\partial_a\}$ with dual coframe $\{dx^a\}$. The
 connection coefficients are defined by
$$\nabla_{\partial_c} \partial_b = \Gamma^d_{bc}\, \partial_d.$$

## Derivation

**Step 1 — Metric compatibility.** The condition $\nabla_e g_{ab} = 0$ expands t
o
$$\partial_e g_{ab} - \Gamma^d_{ab}\, g_{db} \cdot \delta\ldots$$
More carefully, using $\nabla_e g_{ab} = \partial_e g_{ab} - \Gamma^d_{ea} g_{db
} - \Gamma^d_{eb} g_{ad}$:
$$\partial_e g_{ab} = \Gamma^d_{ea}\, g_{db} + \Gamma^d_{eb}\, g_{ad}. \tag{1}$$

**Step 2 — Cyclically permute indices.** Write (1) and its two cyclic permutatio
ns:
$$\partial_e g_{ab} = \Gamma_{ea,b} + \Gamma_{eb,a}, \tag{1}$$
$$\partial_a g_{be} = \Gamma_{ab,e} + \Gamma_{ae,b}, \tag{2}$$
$$\partial_b g_{ea} = \Gamma_{be,a} + \Gamma_{ba,e}, \tag{3}$$
where we lowered the first index via $\Gamma_{ab,c} := g_{cd}\,\Gamma^d_{ab}$, w
hich is symmetric in $a,b$ by torsion-freeness, and symmetric in its last two sl
ots because $g_{cd}$ is symmetric and $\Gamma^d_{ab}=\Gamma^d_{ba}$.

**Step 3 — Combine.** Compute $(1) + (2) - (3)$:
$$\partial_e g_{ab} + \partial_a g_{be} - \partial_b g_{ea} = (\Gamma_{ea,b} + \
Gamma_{eb,a}) + (\Gamma_{ab,e} + \Gamma_{ae,b}) - (\Gamma_{be,a} + \Gamma_{ba,e}
).$$

Using the symmetry $\Gamma_{ab,c} = \Gamma_{ba,c}$ (torsion-free) and $\Gamma_{a
b,c}=\Gamma_{ab,c}$, the terms pair up:
- $\Gamma_{eb,a} - \Gamma_{be,a} = 0$ (symmetry in first two indices),
- $\Gamma_{ae,b} + \Gamma_{ea,b} = 2\,\Gamma_{ea,b}$ (same term, twice),
- $\Gamma_{ab,e} - \Gamma_{ba,e} = 0$ (symmetry).

Hence
$$2\,\Gamma_{ea,b} = \partial_e g_{ab} + \partial_a g_{be} - \partial_b g_{ea},$
$
i.e.
$$\Gamma_{ea,b} = \tfrac{1}{2}\bigl(\partial_e g_{ab} + \partial_a g_{be} - \par
tial_b g_{ea}\bigr).$$

**Step 4 — Raise the index.** Multiply by $g^{cd}$ (using $g^{cd}g_{db} = \delta
^c_{\ b}$):
$$\Gamma^c_{ea} = \tfrac{1}{2}\, g^{cd}\bigl(\partial_e g_{ad} + \partial_a g_{d
e} - \partial_d g_{ea}\bigr).$$

Relabeling $(c,e,a) \to (d,b,c)$ to match the requested index placement $\Gamma^
d_{bc}$:

$$\boxed{\;\Gamma^d_{\ bc} = \tfrac{1}{2}\, g^{de}\bigl(\partial_b g_{ce} + \par
tial_c g_{be} - \partial_e g_{bc}\bigr)\;}$$

## Verification of the two defining properties

*Torsion-free.* The expression is manifestly symmetric under $b \leftrightarrow
c$ (the first two terms swap, the third is unchanged), so $\Gamma^d_{bc} = \Gamm
a^d_{cb}$.

*Metric-compatible.* Substituting the boxed formula into $\nabla_e g_{ab} = \par
tial_e g_{ab} - \Gamma^d_{ea}g_{db} - \Gamma^d_{eb}g_{ad}$ and using $g^{df}g_{d
b}=\delta^f_{\ b}$ gives
$$\partial_e g_{ab} - \tfrac{1}{2}(\partial_e g_{ab} + \partial_a g_{eb} - \part
ial_b g_{ea}) - \tfrac{1}{2}(\partial_e g_{ab} + \partial_b g_{ea} - \partial_a
g_{eb}) = 0,$$
confirming $\nabla_e g_{ab}=0$.

## Summary

The Levi-Civita connection's coordinate components are determined purely by the
metric and its first partial derivatives:
$$\Gamma^d_{\ bc} = \frac{1}{2}\, g^{de}\!\left(\partial_b g_{ce} + \partial_c g
_{be} - \partial_e g_{bc}\right).$$

This is the unique torsion-free, metric-compatible connection on $(M, g)$.
