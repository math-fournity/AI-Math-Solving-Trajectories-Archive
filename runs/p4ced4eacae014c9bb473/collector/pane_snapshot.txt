Looking at this problem, I need to find the minimum number of integer terms in a
 "complete" sequence of $n$ (even) real numbers.

## Proof

Let $a_1, \dots, a_n$ be the sequence. Define prefix sums $P_m = \sum_{i=1}^m a_
i$ and suffix sums $Q_m = \sum_{i=n-m+1}^n a_i$ (with $P_0 = Q_0 = 0$). Note $P_
m + Q_{n-m} = P_n = Q_n = T$ for all $m$.

Let $p_m = \{P_m\}, q_m = \{Q_m\} \in [0,1)$. Completeness means: for each $m \i
n \{1,\dots,n\}$, $p_m = 0$ or $q_m = 0$.

**Step 1: Reformulation.** Since $P_m + Q_{n-m} = T \in \mathbb{R}$, we get $p_m
 + q_{n-m} \in \{0,1\}$. This gives $q_m = 0 \iff p_{n-m} = 0$. So the condition
 "$p_m = 0$ or $q_m = 0$" becomes:

$$p_m = 0 \text{ or } p_{n-m} = 0 \quad \text{for each } m \in \{1,\dots,n\}.$$

- $m = n$: forces $p_n = 0$ (total sum is an integer).
- $m = n/2$: forces $p_{n/2} = 0$.
- For $1 \le m \le n/2 - 1$: at least one of $p_m, p_{n-m}$ is $0$.

**Step 2: Lower bound of 2.** Let $N = \{m \in \{1,\dots,n-1\} : p_m \ne 0\}$. B
y Step 1, $n/2 \notin N$, and from each pair $\{m, n-m\}$ ($m = 1,\dots,n/2-1$)
at most one element is in $N$. So $|N| \le n/2 - 1$.

Term $a_m$ is an integer iff $p_m = p_{m-1}$ (a "stay"). If both $p_{m-1} = 0$ a
nd $p_m = 0$, step $m$ is a stay. Since $p_0 = p_n = 0$ and nonzero positions li
e in $N \subseteq \{1,\dots,n-1\}$, step $m$ has both endpoints zero iff $\{m-1,
 m\} \cap N = \emptyset$. The number of steps with $\{m-1,m\} \cap N \ne \emptys
et$ is at most $2|N| \le n-2$. So at least $n - (n-2) = 2$ steps are zero-zero s
tays.

**Every complete sequence has at least 2 integer terms.**

**Step 3: Construction achieving exactly 2.** Let $k = n/2$. Define
$$N = \{m \in \{1,\dots,k-1\} : m \text{ odd}\} \cup \{n - m : m \in \{1,\dots,k
-1\},\; m \text{ even}\}.$$

From each pair $\{m, n-m\}$ exactly one element is selected, so $|N| = k-1 = n/2
 - 1$.

*Non-adjacency:* Odd selected elements are $1, 3, 5, \dots$ (distance 2 apart);
even selected are $n-2, n-4, \dotsots$ (distance 2 apart). The largest odd selec
ted is $\le k-1$ and the smallest even selected is $\ge k+1$; checking both pari
ties of $k-1$, the cross-distance is exactly $3$. So all elements of $N$ are pai
rwise non-adjacent, and $N \subseteq \{1,\dots,n-1\}\setminus\{k\}$.

Assign distinct nonzero values $\alpha_j \in (0,1)$ to each $j \in N$. Set $p_0
= 0$, $p_j = \alpha_j$ for $j \in N$, and $p_j = 0$ otherwise (including $p_k =
0$, $p_n = 0$). Define $a_m = p_m - p_{m-1}$.

*Completeness:* For each $m$, at most one of $p_m, p_{n-m}$ is nonzero (one per
pair), and $p_{n/2} = 0$, so $p_m = 0$ or $p_{n-m} = 0$ holds. By Step 1, the se
quence is complete.

*Integer count:* A stay requires $p_m = p_{m-1}$. Since all nonzero values are d
istinct and no two nonzero positions are adjacent, stays occur exactly at zero-z
ero steps. The count is $n - 2|N| = n - 2(k-1) = 2$.

**Verification for small cases:** For $n=2$: $N = \emptyset$, giving $a_1 = a_2
= 0$ (2 integers, complete). For $n=6$: $N = \{1, 4\}$, giving e.g. $(0.3, -0.3,
 0, 0.7, -0.7, 0)$ — one checks all $m$ satisfy the condition, with exactly 2 in
tegers ($a_3, a_6).

**Conclusion.** The lower bound is 2 and the construction achieves 2, so the min
imum number of integers in a complete sequence of $n$ (even) real numbers is $\b
oxed{2}$.
