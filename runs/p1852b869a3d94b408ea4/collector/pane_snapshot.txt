## Solution

**Define the transformation.** Let $T(x) = \dfrac{x-1}{x} = 1 - \dfrac{1}{x}$. W
e verify that $T$ has order $3$ on $\mathbb{R}\setminus\{0,1\}$:

$$T(x) = \frac{x-1}{x}, \qquad T^2(x) = T(T(x)) = \frac{\frac{x-1}{x}-1}{\frac{x
-1}{x}} = \frac{-1/x}{(x-1)/x} = \frac{-1}{x-1},$$

$$T^3(x) = T(T^2(x)) = T\!\left(\frac{-1}{x-1}\right) = \frac{\frac{-1}{x-1}-1}{
\frac{-1}{x-1}} = \frac{\frac{-x}{x-1}}{\frac{-1}{x-1}} = x.$$

**Domain check.** If $x \in \mathbb{R}\setminus\{0,1\}$, then $T(x)=0 \Leftright
arrow x=1$ (excluded) and $T(x)=1 \Leftrightarrow x-1=x$ (impossible), so $T(x)\
in\mathbb{R}\setminus\{0,1\}$. Likewise $T^2(x)=0$ never occurs and $T^2(x)=1\Le
ftrightarrow x=0$ (excluded). Thus all three values $x, T(x), T^2(x)$ lie in the
 domain, and the functional equation applies to each.

**Set up the system.** Substituting $x$, $T(x)$, and $T^2(x)$ into $F(u)+F(T(u))
=1+u$:

$$\begin{cases} F(x) + F(T(x)) = 1 + x & (I)\\ F(T(x)) + F(T^2(x)) = 1 + T(x) &
(II)\\ F(T^2(x)) + F(x) = 1 + T^2(x) & (III) \end{cases}$$

This is a linear system in the three unknowns $F(x), F(T(x)), F(T^2(x))$ with co
efficient matrix $\begin{pmatrix}1&1&0\\0&1&1\\1&0&1\end{pmatrix}$, whose determ
inant is $1\cdot(1-0)-1\cdot(0-1)+0 = 2 \neq 0$. Hence the solution is **unique*
*.

**Solve for $F(x)$.** Compute $(I)-(II)+(III)$:

$$2F(x) = (1+x) - (1+T(x)) + (1+T^2(x)) = 1 + x - T(x) + T^2(x).$$

Substituting $T(x)=\frac{x-1}{x}$ and $T^2(x)=\frac{-1}{x-1}$:

$$2F(x) = 1 + x - \frac{x-1}{x} - \frac{1}{x-1} = 1 + x - 1 + \frac{1}{x} - \fra
c{1}{x-1} = x + \frac{1}{x} - \frac{1}{x-1}.$$

Therefore

$$\boxed{F(x) = \frac{1}{2}\!\left(x + \frac{1}{x} - \frac{1}{x-1}\right) = \fra
c{x^3 - x^2 - 1}{2x(x-1)}.}$$

**Verification.** We confirm $F(x)+F(T(x))=1+x$ directly. With $T(x)=\frac{x-1}{
x}$:

$$F(T(x)) = \frac{1}{2}\!\left(\frac{x-1}{x} + \frac{x}{x-1} - \frac{1}{\frac{x-
1}{x}-1}\right) = \frac{1}{2}\!\left(\frac{x-1}{x} + \frac{x}{x-1} - \frac{x}{-1
}\right) = \frac{1}{2}\!\left(\frac{x-1}{x} + \frac{x}{x-1} + x\right).$$

Then

$$F(x)+F(T(x)) = \frac{1}{2}\!\left(x+\frac{1}{x}-\frac{1}{x-1}\right) + \frac{1
}{2}\!\left(\frac{x-1}{x}+\frac{x}{x-1}+x\right)$$

$$= \frac{1}{2}\!\left(2x + \frac{1}{x}+\frac{x-1}{x} - \frac{1}{x-1}+\frac{x}{x
-1}\right) = \frac{1}{2}\!\left(2x + \frac{x}{x} + \frac{x-1}{x-1}\right) = \fra
c{1}{2}(2x+1+1) = 1+x. \checkmark$$

Since the linear system has a unique solution and this $F$ satisfies the equatio
n, it is the **unique** solution.
