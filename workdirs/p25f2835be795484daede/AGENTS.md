# Problem

In the galactic logistics hub of Sector 2010, there are 2010 identical energy canisters distributed across 100 storage vaults. At the start of the shift, every canister is located in one of the vaults. 

An automated sorting protocol begins to relocate the canisters according to a strict efficiency rule: every minute, as long as the canisters are not all concentrated in a single vault, a robotic arm moves exactly one canister from its current vault into a different vault. However, the protocol dictates that a canister can only be moved into a vault that already contains a number of canisters greater than or equal to the number of canisters in the vault it is leaving (calculated immediately before the move).

The sorting process continues until all 2010 canisters are successfully moved into the same vault, at which point the protocol terminates. This termination occurs after exactly $M$ minutes. 

Calculate the maximum possible value of $M$.
