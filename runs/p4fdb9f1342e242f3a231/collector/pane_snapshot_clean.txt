## Proof

Let $P(x,y)$ denote the assertion of the equation for given $x,y$.

**Step 1. Key substitution $x = f(y)$.**

$P(f(y), y)$: $f(0) = 2f(f(y)) + f(y)^2 - 1$, so $2f(f(y)) + f(y)^2 = f(0)+1$ is
 constant. Set $c := f(0)+1$, giving
$$f(f(y)) = \tfrac{c - f(y)^2}{2}. \tag{$*$}$$

**Step 2. Shift relation.** Replace $x$ by $x + f(y)$ in the original equation:
$$f(x) = f(f(y)) + (x+f(y))f(y) + f(x+f(y)) - 1,$$
so $f(x+f(y)) = f(x) - xf(y) - f(f(y)) - f(y)^2 + 1$. Using $(*)$:
$$\boxed{f(x+t) = f(x) - xt - \tfrac{c+t^2}{2} + 1} \quad \text{for all } x\in\m
athbb{R},\; t\in R, \tag{$**$}$$
where $R := f(\mathbb{R})$ is the range of $f$.

**Step 3. $f$ on its range.** Setting $x=0$ in $(**)$: $f(t) = f(0) - \frac{c+t^
2}{2} + 1 = (c-1) - \frac{c+t^2}{2}+1 = \frac{c-t^2}{2}$ for $t \in R$. So
$$f(t) = \tfrac{c-t^2}{2} \quad \text{for } t \in R. \tag{$***$}$$

**Step 4. $f$ is not constant.** If $f \equiv a$, the original equation gives $a
 = 2a + xa - 1$ for all $x$, forcing $a=0$ (coefficient of $x$) and then $0 = -1
$, contradiction. So $|R| \geq 2$.

**Step 5. The range satisfies $R - R = \mathbb{R}$.** Pick distinct $t_1, t_2 \i
n R$. Define $h_i(x) := f(x) - xt_i$. From $(**)$, $f(x) - xt_i = f(x+t_i) + \fr
ac{c+t_i^2}{2} - 1$, so as $x$ ranges over $\mathbb{R}$, $h_i$ ranges over $R +
\frac{c+t_i^2}{2} - 1$ (a translate of $R$). Now
$$h_1(x) - h_2(x) = x(t_2 - t_1),$$
which ranges over all of $\mathbb{R}$ since $t_1 \neq t_2$. Therefore $\mathbb{R
} \subseteq (R+\alpha_1)-(R+\alpha_2) = R - R + (\alpha_1-\alpha_2)$, giving $R
- R = \mathbb{R}$.

**Step 6. Determining $c$.** Since $R - R = \mathbb{R}$, pick any $s_0 \in R$; t
hen $s_0 \in \mathbb{R} = R - R$, so there exist $a, b \in R$ with $a - b = s_0$
, i.e., $a = s_0 + b$. Thus $s_0 + b \in R$ with $s_0, b \in R$.

For $s, t \in R$, apply $(**)$ twice (with $t$ then $t$) to get $f(x+2t) = f(x)
- 2xt - 2t^2 - c + 2$, and by induction:
$$f(x+nt) = f(x) - nxt - \tfrac{n^2 t^2}{2} - \tfrac{nc}{2} + n \quad (n \geq 0)
.$$
Setting $x=0$: $f(nt) = -\frac{n^2t^2}{2} + n(1-\frac{c}{2}) + (c-1)$.

If $nt \in R$ for some $n \geq 2$, then by $(***)$, $f(nt) = \frac{c - n^2t^2}{2
} = -\frac{n^2t^2}{2} + \frac{c}{2}$. Comparing: $n(1-\frac{c}{2}) + (c-1) = \fr
ac{c}{2}$, i.e., $(n-1)(1 - \frac{c}{2}) = 0$. Since $n \geq 2$, this gives $c =
 2$.

From Step 5, $s_0 + b \in R$ with $s_0, b \in R$; taking $n=2$, $t = s_0$, we ne
ed $2s_0 \in R$. More directly: since $s_0 + b \in R$ and $s_0, b \in R$, set $t
_1 = s_0, t_2 = b$; then $t_1 + t_2 \in R$. Apply $(**)$ with $t = t_1$ to $x =
t_2$: $f(t_1+t_2) = f(t_2) - t_2 t_1 - \frac{c+t_1^2}{2}+1$. Using $(***)$ for $
f(t_2) = \frac{c-t_2^2}{2}$:
$$f(t_1+t_2) = \tfrac{c-t_2^2}{2} - t_1 t_2 - \tfrac{c+t_1^2}{2} + 1 = 1 - \tfra
c{(t_1+t_2)^2}{2}.$$
Since $t_1+t_2 \in R$, $(***)$ gives $f(t_1+t_2) = \frac{c-(t_1+t_2)^2}{2}$. Com
paring: $\frac{c}{2} = 1$, so $c = 2$.

**Step 7. $f(x) = 1 - \frac{x^2}{2}$ for all $x$.** With $c=2$: $f(0)=1$, and $(
**)$ becomes $f(x+t) = f(x) - xt - \frac{t^2}{2}$ for $t \in R$, while $(***)$ g
ives $f(t) = 1 - \frac{t^2}{2}$ for $t \in R$.

For any $x \in \mathbb{R}$, since $R - R = \mathbb{R}$, write $x = a - b$ with $
a, b \in R$. Then $x + b = a \in R$, and $(**)$ gives:
$$f(a) = f(x) - xb - \tfrac{b^2}{2} \implies f(x) = f(a) + xb + \tfrac{b^2}{2} =
 \left(1 - \tfrac{a^2}{2}\right) + xb + \tfrac{b^2}{2}.$$
Since $x = a - b$: $xb = (a-b)b = ab - b^2$, so $f(x) = 1 - \frac{a^2}{2} + ab -
 b^2 + \frac{b^2}{2} = 1 - \frac{a^2 - 2ab + b^2}{2} = 1 - \frac{(a-b)^2}{2} = 1
 - \frac{x^2}{2}$.

**Step 8. Verification.** For $f(x) = 1 - \frac{x^2}{2}$:
- LHS: $f(x - f(y)) = 1 - \frac{(x - f(y))^2}{2} = 1 - \frac{x^2}{2} + xf(y) - \
frac{f(y)^2}{2}$.
- RHS: $f(f(y)) + xf(y) + f(x) - 1 = \left(1 - \frac{f(y)^2}{2}\right) + xf(y) +
 \left(1 - \frac{x^2}{2}\right) - 1 = 1 - \frac{f(y)^2}{2} + xf(y) - \frac{x^2}{
2}$.

LHS $=$ RHS. ✓
