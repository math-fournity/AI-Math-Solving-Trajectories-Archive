## Solution

**Inner limit.** Define $S_n(x) = 1 + \sum_{k=1}^{n}\sin^2(kx)$. We compute
$$L_n = \lim_{x\to 0} S_n(x)^{\,1/(n^3 x^2)}.$$

Using $\sin(kx) = kx - \tfrac{(kx)^3}{6} + O(x^5)$, we get
$$\sin^2(kx) = k^2 x^2 - \tfrac{k^4 x^4}{3} + O(x^6),$$
hence, with $A_n = \sum_{k=1}^{n} k^2 = \dfrac{n(n+1)(2n+1)}{6}$,
$$S_n(x) = 1 + A_n x^2 + O(x^4) \quad (x\to 0).$$

Therefore
$$\ln S_n(x) = \ln\!\big(1 + A_n x^2 + O(x^4)\big) = A_n x^2 + O(x^4),$$
and
$$\frac{\ln S_n(x)}{n^3 x^2} = \frac{A_n x^2 + O(x^4)}{n^3 x^2} = \frac{A_n}{n^3
} + O(x^2) \xrightarrow{x\to 0} \frac{A_n}{n^3}.$$

So the inner limit is
$$L_n = \exp\!\left(\frac{A_n}{n^3}\right) = \exp\!\left(\frac{n(n+1)(2n+1)}{6n^
3}\right).$$

**Outer limit.** Now
$$\frac{n(n+1)(2n+1)}{6n^3} = \frac{(n+1)(2n+1)}{6n^2} = \frac{2n^2+3n+1}{6n^2}
= \frac{1}{3} + \frac{1}{2n} + \frac{1}{6n^2} \xrightarrow{n\to\infty} \frac{1}{
3}.$$

By continuity of the exponential,
$$\lim_{n\to\infty} L_n = \exp\!\left(\frac{1}{3}\right) = \boxed{e^{1/3}}.$$
