## Proof

Let $\xi = e^{2\pi i/13}$, a primitive 13th root of unity, and set $\alpha = \xi
 + \xi^5 + \xi^8$.

**Galois group.** The extension $\mathbb{Q}(\xi)/\mathbb{Q}$ has degree $\varphi
(13)=12$, with Galois group $G = \mathrm{Gal}(\mathbb{Q}(\xi)/\mathbb{Q}) \cong
(\mathbb{Z}/13\mathbb{Z})^\times \cong \mathbb{Z}/12$. Each $k \in (\mathbb{Z}/1
3\mathbb{Z})^\times$ gives the automorphism $\sigma_k : \xi \mapsto \xi^k$.

**Degree via orbit–stabilizer.** The degree $[\mathbb{Q}(\alpha):\mathbb{Q}]$ eq
uals the number of distinct conjugates $\sigma_k(\alpha)$, i.e. the orbit size $
|G|/|\mathrm{Stab}(\alpha)|$, where
$$\mathrm{Stab}(\alpha) = \{ k \in (\mathbb{Z}/13\mathbb{Z})^\times : \sigma_k(\
alpha) = \alpha \}.$$

**Linear relations among powers of $\xi$.** The minimal polynomial of $\xi$ is t
he 13th cyclotomic polynomial $\Phi_{13}(x) = 1 + x + x^2 + \cdots + x^{12}$, so
 the only $\mathbb{Q}$-linear relation among $\{1, \xi, \xi^2, \dots, \xi^{12}\}
$ is (a scalar multiple of)
$$1 + \xi + \xi^2 + \cdots + \xi^{12} = 0.$$
Equivalently, an integer-coefficient relation $\sum_{i=0}^{12} c_i \xi^i = 0$ ho
lds if and only if all $c_i$ are equal.

**Computing the stabilizer.** The condition $\sigma_k(\alpha)=\alpha$ is
$$\xi^k + \xi^{5k} + \xi^{8k} = \xi + \xi^5 + \xi^8 \pmod{13}.$$
This is a linear relation with coefficients $+1$ at positions $\{k, 5k, 8k\}$ an
d $-1$ at positions $\{1,5,8\}$ (all exponents reduced mod 13, with position 0 g
iving the constant term). The total coefficient sum is $3 - 3 = 0$. By the relat
ion criterion above, this vanishes only if every coefficient is $0$ (the only co
nstant value consistent with total sum $0$ is $0$). Hence we need the multisets
to coincide:
$$\{k,\, 5k,\, 8k\} \equiv \{1,\, 5,\, 8\} \pmod{13}.$$

Checking all $k \in \{1,2,\dots,12\}$:

| $k$ | $\{k,5k,8k\} \bmod 13$ | $= \{1,5,8\}$? |
|-----|------------------------|----------------|
| 1 | $\{1,5,8\}$ | yes |
| 2 | $\{2,10,3\}$ | no |
| 3 | $\{3,2,11\}$ | no |
| 4 | $\{4,7,6\}$ | no |
| 5 | $\{5,12,1\}$ | no |
| 6 | $\{6,4,9\}$ | no |
| 7 | $\{7,9,4\}$ | no |
| 8 | $\{8,1,12\}$ | no |
| 9 | $\{9,6,7\}$ | no |
| 10 | $\{10,11,2\}$ | no |
| 11 | $\{11,3,10\}$ | no |
| 12 | $\{12,8,5\}$ | no |

Only $k=1$ fixes $\alpha$. Thus $|\mathrm{Stab}(\alpha)| = 1$, and the orbit has
 size
$$|G|/|\mathrm{Stab}(\alpha)| = 12/1 = 12.$$

All twelve conjugates $\sigma_k(\alpha)$ are distinct, so $\alpha$ has $12$ dist
inct conjugates and its minimal polynomial over $\mathbb{Q}$ has degree $12$.

**Conclusion.** Since $[\mathbb{Q}(\alpha):\mathbb{Q}] = 12 = [\mathbb{Q}(\xi):\
mathbb{Q}]$ and $\mathbb{Q}(\alpha) \subseteq \mathbb{Q}(\xi)$, we have $\mathbb
{Q}(\alpha) = \mathbb{Q}(\xi)$, and

$$\boxed{[\mathbb{Q}(\xi+\xi^5+\xi^8):\mathbb{Q}] = 12}.$$

### PROOF COMPLETE
