### 通用设置

考虑顶点在原点、方程为 $y = cx^2$ 的抛物线。设 $O = (0,0)$，$P = (a, ca^2)$（$a
> 0$），$Q = (b, cb^2)$（$b < 0$），且 $Q$ 处为直角，$|QP| = |QO|$。

向量：$\vec{QP} = (a-b,\, c(a^2-b^2))$，$\vec{QO} = (-b,\, -cb^2)$。

**垂直条件：**
$$(a-b)(-b) + c(a^2-b^2)(-cb^2) = 0 \implies (a-b)\bigl[-b - c^2 b^2(a+b)\bigr]
= 0.$$
由于 $a \ne b$：$c^2 b(a+b) = -1$，即
$$c^2 b(a+b) = -1. \tag{1}$$

**等腰条件** $|QO|^2 = |QP|^2$：
$$b^2(1+c^2 b^2) = (a-b)^2\bigl(1 + c^2(a+b)^2\bigr). \tag{2}$$

由 (1) 式得，$a+b = -\tfrac{1}{c^2 b}$，因此 $c^2(a+b)^2 = \tfrac{1}{c^2 b^2}$
且 $a - b = -\tfrac{1}{c^2 b} - 2b = -\tfrac{1+2c^2 b^2}{c^2 b}$。代入 (2) 式并
消去 $(1+c^2 b^2)$：
$$c^6 b^6 = (1 + 2c^2 b^2)^2.$$

令 $w = cb$（由于 $c>0, b<0$，故 $w < 0$）。则 $c^3 b^3 = w^3$ 且 $c^2 b^2 = w^2
$，得出：
$$w^3 = \pm(1 + 2w^2).$$
由于 $w < 0$，有 $w^3 < 0$ 且 $1+2w^2 > 0$，因此取负号：
$$\boxed{w^3 + 2w^2 + 1 = 0}. \tag{$\star$}$$

### 分析三次方程 ($\star$)

$f(w) = w^3 + 2w^2 + 1$。则 $f'(w) = w(3w+4)$，临界点为 $w = -\tfrac{4}{3}$（局
部最小值）和 $w = 0$（局部最大值）。$f(-\tfrac{4}{3}) = \tfrac{59}{27} > 0$，$f(
-2) = 1 > 0$，$f(-3) = -8 < 0$。因此，($\star$) 在 $(-3,-2)$ 内有**唯一的实根**
$r$，且为负数。

### 两个三角形

**第一个三角形** $\triangle PQO$，抛物线 $y = 12x^2$：此处 $c = 12$，所以 $w = 1
2b_1$。因此 $r = 12b_1$，即
$$q := b_1 = \frac{r}{12}, \qquad r = 12q. \tag{3}$$

**第二个三角形** $\triangle ABV$，抛物线 $y = \tfrac{x^2}{5} + 1$，顶点 $V = (0,
1)$。平移 $Y = y - 1$ 得到 $Y = \tfrac{x^2}{5}$，所以 $c = \tfrac{1}{5}$。此处 $
w = \tfrac{b_2}{5}$，因此 $r = \tfrac{b_2}{5}$，即 $b_2 = 5r$。

由 (1) 式，$a_2 + b_2 = -\tfrac{1}{c^2 b_2} = -\tfrac{25}{5r} = -\tfrac{5}{r}$，
所以
$$a_2 = -\frac{5}{r} - 5r = -5\!\left(\frac{1}{r} + r\right).$$
（因为 $r < 0$，$a_2 > 0$：在第一象限。✓）

### $A$ 的 $y$ 坐标

$$y_A = \frac{a_2^2}{5} + 1 = \frac{25\!\left(\frac{1}{r}+r\right)^{\!2}}{5} + 1
 = 5\!\left(\frac{1}{r^2} + 2 + r^2\right) + 1 = 5r^2 + 11 + \frac{5}{r^2}. \tag
{4}$$

利用三次方程消去 $\tfrac{1}{r^2}$：由 $r^3 + 2r^2 + 1 = 0$ 得 $r^2(r+2) = -1$，
因此
$$\frac{1}{r^2} = -(r+2), \qquad \frac{5}{r^2} = -5r - 10.$$

代入 (4) 式：
$$y_A = 5r^2 + 11 - 5r - 10 = 5r^2 - 5r + 1.$$

利用 (3) 式，$r = 12q$：
$$y_A = 5(144q^2) - 5(12q) + 1 = 720\,q^2 - 60\,q + 1.$$

### 结论

读取得 $u = 720$，$v = -60$，$w = 1$，因此
$$u + v + w = 720 - 60 + 1 = \boxed{661}.$$
