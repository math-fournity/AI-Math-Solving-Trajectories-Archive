## Solution

**Goal:** Find the smallest positive integer $n$ such that $2^{2002} \mid 2001^n
 - 1$, i.e., $v_2(2001^n - 1) \geq 2002$.

**Step 1: Compute the building blocks.**

$$2001 - 1 = 2000 = 2^4 \cdot 125, \quad \text{so } v_2(2001-1) = 4.$$
$$2001 + 1 = 2002 = 2 \cdot 1001, \quad \text{so } v_2(2001+1) = 1.$$

Since $2001$ is odd, we apply the **Lifting the Exponent (LTE) lemma** for $p=2$
.

**Step 2: Apply LTE for $p = 2$.**

For odd $a, b$ with $a \neq b$ and positive integer $n$:

- If $n$ is **odd**: $v_2(a^n - b^n) = v_2(a - b)$.
- If $n$ is **even**: $v_2(a^n - b^n) = v_2(a-b) + v_2(a+b) + v_2(n) - 1$.

With $a = 2001$, $b = 1$:

**Case $n$ odd:** $v_2(2001^n - 1) = v_2(2001-1) = 4 < 2002$. So no odd $n$ work
s.

**Case $n$ even:**
$$v_2(2001^n - 1) = v_2(2001-1) + v_2(2001+1) + v_2(n) - 1 = 4 + 1 + v_2(n) - 1
= 4 + v_2(n).$$

**Step 3: Determine the constraint on $n$.**

We need
$$4 + v_2(n) \geq 2002 \implies v_2(n) \geq 1998.$$

So $n$ must be even with $v_2(n) \geq 1998$, i.e., $n = 2^{1998} \cdot m$ for so
me positive odd integer $m$.

**Step 4: Minimize $n$.**

The smallest such $n$ is achieved at $m = 1$:
$$n = 2^{1998}.$$

**Verification.** For $n = 2^{1998}$ (which is even, $v_2(n) = 1998$):
$$v_2(2001^{2^{1998}} - 1) = 4 + 1998 = 2002 \geq 2002. \checkmark$$

For any smaller $n$: if $n$ is odd, $v_2 = 4 < 2002$; if $n$ is even with $v_2(n
) \leq 1997$, then $v_2(2001^n-1) = 4 + v_2(n) \leq 2001 < 2002$. Hence no small
er $n$ works.

**Sanity check with $n=2$:** $v_2(2001^2-1) = v_2(2000\cdot 2002) = v_2(2^4\cdot
 125 \cdot 2\cdot 1001) = 5 = 4 + v_2(2) = 4+1$. ✓

$$\boxed{n = 2^{1998}}$$
