# Proof

**Claim:** The order type η of the rationals is the smallest nontrivial dense or
der type, in the sense that every dense order embedding into η also admits an em
bedding of η.

We prove this in two steps.

## Step 1: Characterization of dense orders embedding into η

**Lemma 1.** A linear order embeds into η = (ℚ, <) if and only if it is countabl
e.

*Proof.* (⟸) Let L be a countable linear order, enumerated as L = {ℓ₀, ℓ₁, ℓ₂, …
}. We construct an order-embedding f: L → ℚ inductively. Place ℓ₀ at 0. At stage
 n, the element ℓₙ has a definite position relative to the already-placed elemen
ts {ℓ₀, …, ℓₙ₋₁}: it is either below all of them, above all of them, or between
two consecutive ones in the induced order on the placed elements. Since ℚ is den
se and has no endpoints, there is always a rational available in the appropriate
 open interval (or in (−∞, min) or (max, +∞)). Set f(ℓₙ) to such a rational. Thi
s gives an order-embedding.

(⟹) If L embeds into ℚ, then L is in bijection with a subset of ℚ, hence countab
le. □

**Corollary.** The dense orders embedding into η are exactly the countable dense
 linear orders.

## Step 2: η embeds into every nontrivial countable dense linear order

**Lemma 2 (Cantor's Isomorphism Theorem).** Any two countable dense linear order
s without endpoints are order-isomorphic.

*Proof (sketch).* Let A, B be countable dense linear orders without endpoints. E
numerate A = {a₀, a₁, …} and B = {b₀, b₁, …}. Build a partial isomorphism by *ba
ck-and-forth*: at odd stages, map the least unmapped aᵢ to some unmapped bⱼ pres
erving order (possible by density and lack of endpoints); at even stages, map th
e least unmapped bⱼ back to some unmapped aᵢ. The limit is an order-isomorphism
A ≅ B. □

**Lemma 3.** η embeds into every countable dense linear order D with at least tw
o elements.

*Proof.* Let D be a countable dense linear order with |D| ≥ 2. Pick any a < b in
 D. Consider the open interval

$$(a, b) = \{x \in D : a < x < b\}.$$

Since D is dense, (a, b) is nonempty. Since D is dense, (a, b) has no minimum or
 maximum (for any x ∈ (a,b), density gives some y with a < y < x, so y ∈ (a,b) a
nd y < x; similarly above). The interval (a, b) is countable (as a subset of the
 countable D) and dense (inheriting density from D), with no endpoints.

By Lemma 2, $(a, b) \cong \eta$. The inclusion $(a, b) \hookrightarrow D$ compos
ed with this isomorphism gives an embedding $\eta \hookrightarrow D$. □

## Conclusion

Let D be any nontrivial dense order that embeds into η. By the Corollary to Lemm
a 1, D is a countable dense linear order. Since D is nontrivial, |D| ≥ 2. By Lem
ma 3, η embeds into D.

Therefore, there is **no** dense order D such that D embeds into η but η does no
t embed into D. The order type η is the smallest nontrivial dense order type in
the stated sense. **The answer is yes.**
