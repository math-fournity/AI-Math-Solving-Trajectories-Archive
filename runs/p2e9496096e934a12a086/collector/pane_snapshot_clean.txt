## Solution

**Family tree structure (16 women total):**
- **Alice** (root): 1 woman
- **Level 1**: Alice has 3 daughters ($D_1, D_2, D_3$): 3 women
- **Level 2**: Each $D_i$ has 2 daughters → 6 granddaughters ($G_1, \dots, G_6$)
: 6 women
- **Level 3**: Each $G_j$ has 1 daughter → 6 great-granddaughters ($H_1, \dots,
H_6$): 6 women

Total: $1 + 3 + 6 + 6 = 16$. ✓

The family forms a rooted tree. We count **independent sets** (no woman and her
daughter both chosen) using the standard tree recurrence. For each node $v$, def
ine:
- $f(v)$ = number of independent sets of the subtree rooted at $v$ **with $v$ ex
cluded**
- $g(v)$ = number of independent sets of the subtree rooted at $v$ **with $v$ in
cluded**

Recurrences:
$$g(v) = \prod_{c \in \text{children}(v)} f(c) \qquad \text{(v in ⇒ no child in)
}$$
$$f(v) = \prod_{c \in \text{children}(v)} \bigl(f(c) + g(c)\bigr) \qquad \text{(
v out ⇒ each child free)}$$

**Bottom-up computation:**

**Leaves** ($H_1, \dots, H_6$, no children):
$$f(H_j) = 1,\quad g(H_j) = 1$$

**Level 2** ($G_j$, each has one child $H_j$):
$$f(G_j) = f(H_j) + g(H_j) = 1 + 1 = 2$$
$$g(G_j) = f(H_j) = 1$$

**Level 1** ($D_i$, each has two children $G_{2i-1}, G_{2i}$):
$$f(D_i) = (f(G_{2i-1}) + g(G_{2i-1}))(f(G_{2i}) + g(G_{2i})) = (2+1)(2+1) = 9$$
$$g(D_i) = f(G_{2i-1})\,f(G_{2i}) = 2 \cdot 2 = 4$$

**Root** (Alice, three children $D_1, D_2, D_3$):
$$f(\text{Alice}) = (f(D_1)+g(D_1))(f(D_2)+g(D_2))(f(D_3)+g(D_3)) = (9+4)^3 = 13
^3 = 2197$$
$$g(\text{Alice}) = f(D_1)\,f(D_2)\,f(D_3) = 9^3 = 729$$

**Total independent sets** (including the empty set):
$$f(\text{Alice}) + g(\text{Alice}) = 2197 + 729 = \boxed{2926}$$
