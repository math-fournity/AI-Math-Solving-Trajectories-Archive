## Proof

The answer is **yes** — *provided one works in the standard axiomatic foundation
 ZFC (Zermelo–Fraenkel set theory with the Axiom of Choice)*. In the weaker theo
ry ZF (without Choice) the statement is independent and, in fact, not provable.
Below I give the ZFC argument, then clarify exactly what "can" does and does not
 deliver, since the question is notorious precisely for that subtlety.

### 1. The Well-Ordering Theorem (Zermelo, 1904)

**Theorem (Zermelo).** In ZFC, every set can be well-ordered. Equivalently (and
this equivalence itself is a theorem of ZF): *the Axiom of Choice holds if and o
nly if every set admits a well-ordering.*

Recall the relevant definitions:

- A **well-ordering** of a set $S$ is a total order $\prec$ on $S$ such that eve
ry non-empty subset $T\subseteq S$ has a $\prec$-least element.
- The **Axiom of Choice (AC)** states: for every family $\{A_i\}_{i\in I}$ of no
n-empty pairwise-disjoint sets, there exists a choice function $f:I\to\bigcup_i
A_i$ with $f(i)\in A_i$.

### 2. Applying Zermelo's theorem to $[0,1]$

The closed unit interval $[0,1]\subseteq\mathbb{R}$ is a set (a subset of the se
t $\mathbb{R}$, which is a set in ZF via, e.g., the construction $\mathbb{R}\con
g\mathcal{P}(\omega)$ mod an equivalence relation, or Dedekind cuts). Since $[0,
1]$ is a set, Zermelo's theorem — available in ZFC — yields a binary relation $\
prec$ on $[0,1]$ that well-orders it.

Therefore, **in ZFC, $[0,1]$ can be well-ordered.** ∎ (conditional on AC)

### 3. Why the question is subtle: three precise qualifications

The bare "yes" above is correct *as a theorem of ZFC*, but it hides three facts
that any honest answer must state.

**(a) The well-ordering is not the usual order.** The natural order $\leq$ on $[
0,1]$ is *not* a well-ordering: the subset $(0,1]\subseteq[0,1]$ has no $\leq$-l
east element (its infimum $0$ does not belong to it). Any well-ordering of $[0,1
]$ must therefore be a radically non-standard order with no relation to the topo
logy or arithmetic of the reals.

**(b) No explicit well-ordering of $[0,1]$ can be exhibited in ZFC.** More sharp
ly:

**Theorem (Feferman–Levy, Cohen, Solovay).** In ZFC one cannot define any formul
a $\varphi(x,y)$ in the language of set theory, with no parameters other than pe
rhaps countably many ordinals, such that ZFC proves "$\varphi$ defines a well-or
dering of $\mathbb{R}$."

Sketch of why. If such a parameter-free (or countable-parameter) $\varphi$ prova
bly well-ordered $\mathbb{R}$ in ZFC, then in *every* model of ZFC the relation
it defines would be a well-ordering. But Cohen's forcing produces models $M\subs
eteq N$ of ZFC with the *same* ordinals and the *same* reals for any fixed count
able parameter set, yet in which the putative order would have to be simultaneou
sly a well-order and not — contradiction. Concretely, one can force to add a "fr
esh" real $r$ that is $\varphi$-below some already-present real in $M$ but is no
t $\varphi$-least in any definable cut, breaking well-orderedness. (The Solovay
result makes this precise: every definable, provably total order on the reals in
 ZFC has countable cofinality on some initial segment, hence is not a well-order
.)

Consequently, **ZFC proves the *existence* of a well-ordering of $[0,1]$ but doe
s not — and cannot — exhibit one concretely.** The well-order is obtained purely
 by an existential application of AC.

**(c) The "yes" is equivalent to Choice; dropping AC makes it independent.** The
 equivalence "every set is well-orderable $\Longleftrightarrow$ AC" is a theorem
 of ZF. Hence:

- **ZF + AC (i.e. ZFC) $\vdash$ "$[0,1]$ is well-orderable."** (Shown above.)
- **ZF + $\neg$AC is consistent with "$[0,1]$ is well-orderable"** (e.g. ZF + De
pendent Choice + "every set of reals is Lebesgue measurable", the Solovay model,
 still has $\mathbb{R}$ well-orderable *as a set* only if an inaccessible is col
lapsed — actually in the Solovay model DC holds and $\mathbb{R}$ is *not* well-o
rderable). More cleanly:
- **ZF + "all sets of reals have the Baire property" $\vdash$ "$\mathbb{R}$ is n
ot well-orderable"** (Shelah–Solovay, in the appropriate model). In such models
$[0,1]$ provably admits *no* well-ordering.

So in ZF alone the statement "$[0,1]$ can be well-ordered" is **independent**: i
t is true in some models of ZF (all models of ZFC) and false in others (models o
f ZF + $\neg$AC strong enough, e.g. the Feferman–Levy model where $\mathbb{R}$ i
s a countable union of countable sets, or the Solovay model).

### 4. Direct construction under AC (Zermelo's argument, for completeness)

To make the "yes" fully explicit as a ZFC theorem, here is Zermelo's proof speci
alized to $S=[0,1]$.

Let $\mathcal{P}^*(S)=\mathcal{P}(S)\setminus\{\varnothing\}$. By AC, choose a f
unction $c:\mathcal{P}^*(S)\to S$ with $c(T)\in T$ for every non-empty $T\subset
eq S$. Using Hartogs' theorem (a theorem of ZF: every set $S$ admits an ordinal
$\alpha$ that does not inject into $S$), let $\alpha$ be the least ordinal that
does not inject into $S$. Define by transfinite recursion on $\beta<\alpha$:
$$x_\beta \;=\; c\bigl(S\setminus\{x_\gamma:\gamma<\beta\}\bigr),\qquad\text{pro
vided }S\setminus\{x_\gamma:\gamma<\beta\}\neq\varnothing.$$
If for some $\beta<\alpha$ the remainder $S\setminus\{x_\gamma:\gamma<\beta\}$ w
ere empty, then $\beta$ would be in bijection with $S$ via $\gamma\mapsto x_\gam
ma$, contradicting the choice of $\alpha$ (since $\beta<\alpha$ and $\alpha$ is
the least ordinal not injecting into $S$, every $\beta<\alpha$ *does* inject int
o $S$, but here we would have a *surjection* $\beta\to S$, equivalently an injec
tion $S\to\beta$, forcing $|S|\leq|\beta|<|\alpha|$ — contradiction). Hence the
recursion never halts before $\alpha$; but it cannot run through all of $\alpha$
 either, since that would inject $\alpha$ into $S$. So it halts at some $\beta^*
\leq\alpha$ exactly when the remainder is empty, yielding a bijection $\beta^*\l
eftrightarrow S$. Transporting the natural well-order of the ordinal $\beta^*$ a
long this bijection gives a well-ordering of $S=[0,1]$.

This is a fully formal ZFC proof that a well-ordering of $[0,1]$ exists.

### 5. Conclusion

- **In ZFC (the standard foundation of modern mathematics): yes.** By Zermelo's
Well-Ordering Theorem, $[0,1]$ admits a well-ordering. An explicit construction
via a choice function and Hartogs' ordinal was given in §4.
- **The "yes" is non-constructive:** ZFC cannot define any concrete well-orderin
g of $[0,1]$ (§3b, Solovay).
- **The "yes" is equivalent to the Axiom of Choice:** in ZF without AC the state
ment is independent — true in ZFC models, false in, e.g., the Solovay model (§3c
).

So the mathematically precise answer to "Can $[0,1]$ be well-ordered?" is:

> **Yes, in ZFC — and this is exactly equivalent to assuming the Axiom of Choice
. Without Choice, the question is independent of ZF.**
