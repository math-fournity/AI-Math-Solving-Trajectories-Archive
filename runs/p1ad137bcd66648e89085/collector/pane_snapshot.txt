## Proof

We wish to compute the operator norm

$$\|S\| = \sup_{\|x\|_1 = 1} \|Sx\|_2.$$

**Upper bound.** For $x = (x_k) \in \ell^1$,

$$\|Sx\|_2^2 = \sum_{k=1}^{\infty} \frac{|x_k|^2}{4^k}.$$

Since $\frac{1}{4^k} \leq \frac{1}{4}$ for all $k \geq 1$,

$$\|Sx\|_2^2 \leq \frac{1}{4}\sum_{k=1}^{\infty} |x_k|^2.$$

Using $|x_k|^2 \leq |x_k|\cdot\Big(\sum_j |x_j|\Big)$, i.e. $\sum |x_k|^2 \leq \
big(\sum |x_k|\big)^2 = \|x\|_1^2$ (valid since all terms are non-negative), we
get

$$\|Sx\|_2^2 \leq \frac{1}{4}\|x\|_1^2,$$

hence $\|Sx\|_2 \leq \frac{1}{2}\|x\|_1$, giving $\|S\| \leq \frac{1}{2}$.

**Lower bound (attainment).** Take $x = e_1 = (1, 0, 0, \dots)$. Then $\|e_1\|_1
 = 1$ and

$$Se_1 = \left(\tfrac{1}{2}, 0, 0, \dots\right), \qquad \|Se_1\|_2 = \frac{1}{2}
.$$

Therefore $\|S\| \geq \frac{1}{2}$.

Combining both bounds,

$$\boxed{\|S\| = \frac{1}{2}}.$$
