he limit exists since the sum converges conditionally (the sign alternation prov

Consider the Green's function $G$ on the unit square torus $T^2 = \mathbb{R}^2/\
mathbb{Z}^2$, satisfying $-\Delta G = \delta_0 - 1$ with $\int_{T^2} G\,dA = 0$.
 Its Fourier expansion is:
$$G(x,y) = \sum_{(m,n)\neq(0,0)} \frac{e^{2\pi i(mx+ny)}}{4\pi^2(m^2+n^2)}.$$

Therefore:
$$S = \sum_{(m,n)\neq 0} \frac{e^{2\pi i(m/2+n/2)}}{m^2+n^2} = 4\pi^2\, G\!\left
(\tfrac{1}{2},\tfrac{1}{2}\right). \tag{1}$$

**Step 2: Express $G$ via the Jacobi theta function.**

Identify $T^2 = \mathbb{C}/(\mathbb{Z}+i\mathbb{Z})$ with $z = x+iy$. The functi
on $-\frac{1}{2\pi}\log|\theta_1(z|\tau)|$ has a logarithmic singularity at latt
ice points and is harmonic elsewhere (since $\theta_1$ has simple zeros exactly
at the lattice). The function $\frac{y^2}{2\,\mathrm{Im}\,\tau}$ has $\Delta\fra
c{y^2}{2\,\mathrm{Im}\,\tau} = \frac{1}{\mathrm{Im}\,\tau}$. For $\tau = i$ ($\m
athrm{Im}\,\tau = 1$, area $= 1$):

$$G(z) = -\frac{1}{2\pi}\log|\theta_1(z|i)| + \frac{y^2}{2} + C, \tag{2}$$

where $C$ is fixed by $\int_0^1\!\int_0^1 G\,dx\,dy = 0$.

**Step 3: Compute the constant $C$ via the mean-zero condition.**

Using the product formula $\theta_1(z|\tau) = 2q^{1/4}\sin(\pi z)\prod_{n\geq 1}
(1-q^{2n})(1-2q^{2n}\cos 2\pi z + q^{4n})$ with $q = e^{-\pi}$:

- **$\sin$ term:** Since $|\sin\pi(x+iy)|^2 = \sin^2\pi x + \sinh^2\pi y$, one s

standard integral $\int_0^\pi\log(a+b\cos\theta)\,d\theta$). Integrating over $y
\in[0,1]$: $\iint \log|\sin\pi z|\,dx\,dy = \frac{\pi}{2}-\log 2$.

- **Product terms:** Each factor $|1-2q^{2n}\cos 2\pi z+q^{4n}| = |1-q^{2n}e^{2\
pi iz}|^2$. For $n\geq 1$, $q^{2n}e^{-2\pi y} < 1$ on $y\in[0,1]$, so by the mea
n-value property $\int_0^1\log|1-q^{2n}e^{2\pi iz}|\,dx = 0$. Hence all product
terms integrate to $0$.

- **Constant terms:** $\iint \log(2e^{-\pi/4})\,dx\,dy = \log 2 - \frac{\pi}{4}$
, and $\iint \sum_{n\geq 1}\log(1-e^{-2\pi n})\,dx\,dy = \sum_{n\geq 1}\log(1-e^
{-2\pi n}) = \frac{\pi}{12}+\log\eta(i)$ (using $\eta(i) = e^{-\pi/12}\prod(1-e^

Combining: $\iint \log|\theta_1(z|i)|\,dx\,dy = \frac{\pi}{4} + \frac{\pi}{12} +

Also $\iint \frac{y^2}{2}\,dx\,dy = \frac{1}{6}$. The mean-zero condition gives:
$$0 = -\frac{1}{2\pi}\!\left(\frac{\pi}{3}+\log\eta(i)\right) + \frac{1}{6} + C
\implies C = \frac{\log\eta(i)}{2\pi}. \tag{3}$$

**Step 4: Evaluate $\theta_1$ at the half-period $z = (1+i)/2$.**

From the series $\theta_1(z|\tau) = -i\sum_n (-1)^n q^{(n+1/2)^2}e^{(2n+1)\pi iz

$$\theta_1\!\left(\tfrac{1+\tau}{2}\bigg|\tau\right) = q^{-1/4}\,\theta_3(0|\tau

For $\tau = i$: $|\theta_1((1+i)/2|i)| = e^{\pi/4}\,\theta_3(0|i)$ (since $\thet
a_3(0|i) > 0$).

**Step 5: Combine.**

From (2) and (3) at $z = (1+i)/2$ (where $y = 1/2$):
$$G\!\left(\tfrac{1}{2},\tfrac{1}{2}\right) = -\frac{1}{2\pi}\!\left(\frac{\pi}{
4}+\log\theta_3(0|i)\right) + \frac{1}{8} + \frac{\log\eta(i)}{2\pi} = \frac{1}{
2\pi}\log\frac{\eta(i)}{\theta_3(0|i)}. \tag{4}$$

**Step 6: Evaluate $\eta(i)/\theta_3(0|i)$ using self-duality.**

$$\eta(i)^3 = \tfrac{1}{2}\,\theta_3^3\cdot 2^{-1/2} = \theta_3^3\cdot 2^{-3/2}
\implies \eta(i) = \frac{\theta_3(0|i)}{\sqrt{2}}. \tag{5}$$

**Step 7: Final computation.**

$$\frac{\eta(i)}{\theta_3(0|i)} = \frac{1}{\sqrt{2}}, \qquad G\!\left(\tfrac{1}{
2},\tfrac{1}{2}\right) = \frac{1}{2\pi}\log\frac{1}{\sqrt{2}} = -\frac{\log 2}{4
\pi},$$

$$S = 4\pi^2\cdot\left(-\frac{\log 2}{4\pi}\right) = -\pi\log 2.$$

$$\boxed{\lim_{R\to\infty}\sum_{(a,b)\in\mathcal{D}_R}\frac{(-1)^{a+b}}{a^2+b^2}
 = -\pi\log 2.}$$
