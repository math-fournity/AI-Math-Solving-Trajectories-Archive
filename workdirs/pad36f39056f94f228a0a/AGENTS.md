# Problem

In a remote high-tech facility, there are 54 modular power terminals arranged in a perfect ring. Each terminal can exist in one of two states: "Active" or "Inactive." 

To prevent power surges, the facility’s automated maintenance system is programmed with a specific reconfiguration protocol. In a single operation, the system can select any two adjacent terminals in the ring and simultaneously toggle their states—flipping them both from Active to Inactive, or both from Inactive to Active.

The facility’s security logic dictates that two configurations of the 54 terminals are considered "equivalent" if one can be transformed into the other through any number of these maintenance operations.

Based on this protocol, how many distinct, non-equivalent configurations of the terminal ring exist?
