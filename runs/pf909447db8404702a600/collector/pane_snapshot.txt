## Setup

Let angles be $A, B, C$ with $B - C = 30°$. Set $2R = 1$ (so $R = \frac{1}{2}$),
 giving sides $a = \sin A$, $b = \sin B$, $c = \sin C$.

Place $B = (0,0)$, $C = (a, 0)$. Then:
- $A = (\sin C \cos B,\; \sin C \sin B)$ (altitude foot at $BH = c\cos B$, heigh
t $h_a = \sin C \sin B$)
- $O = \left(\frac{a}{2},\; \frac{\cos A}{2}\right)$ (circumcenter; standard res
ult with $R = \frac{1}{2}$)
- $D = (s - c,\; 0)$ (A-excircle contact: $BD = s - c$, $CD = s - b$)

## Collinearity Condition

Computing the determinant for collinearity of $A, O, D$:

$$y_O(p - (s-c)) = h_a\!\left(\tfrac{a}{2} - s + c\right)$$

**Right side:** $\frac{a}{2} - s + c = \frac{\sin C - \sin B}{2} = \sin\!\tfrac{
A}{2}\sin\!\tfrac{C-B}{2}$

**Left side:** Using half-angle identities, $p - s + c = -2\cos\!\tfrac{B}{2}\co
s\!\tfrac{C}{2}\sin\!\tfrac{B-C}{2}$

Dividing by $-\sin\!\frac{B-C}{2} \neq 0$ and simplifying (using $\sin B \sin C
= 4\sin\!\frac{B}{2}\cos\!\frac{B}{2}\sin\!\frac{C}{2}\cos\!\frac{C}{2}$):

$$\cos A = 4\sin\!\tfrac{A}{2}\sin\!\tfrac{B}{2}\sin\!\tfrac{C}{2}$$

By the identity $\cos A + \cos B + \cos C = 1 + 4\sin\!\frac{A}{2}\sin\!\frac{B}
{2}\sin\!\frac{C}{2}$, this gives:

$$\boxed{\cos B + \cos C = 1}$$

## Solving for the Angles

With $B - C = 30°$: $\cos(\gamma + 30°) + \cos\gamma = 1$ becomes $2\cos(\gamma
+ 15°)\cos 15° = 1$, so:

$$\cos\theta = \frac{\sqrt{6} - \sqrt{2}}{2}, \quad \text{where } \theta = C + 1
5°$$

Then $A = 180° - 2\theta$, $B = \theta + 15°$, $C = \theta - 15°$, and $\sin^2\t
heta = \sqrt{3} - 1$.

## Computing the Key Quantities

**Inradius** (with $2R=1$): $r = 2\sin\!\frac{A}{2}\sin\!\frac{B}{2}\sin\!\frac{
C}{2}$

$$\sin\!\tfrac{A}{2} = \cos\theta = \tfrac{\sqrt{6}-\sqrt{2}}{2}, \quad \sin\!\t
frac{B}{2}\sin\!\tfrac{C}{2} = \tfrac{\cos 15° - \cos\theta}{2} = \tfrac{3\sqrt{

$$r = 2\cdot\tfrac{\sqrt{6}-\sqrt{2}}{2}\cdot\tfrac{3\sqrt{2}-\sqrt{6}}{8} = \fr
ac{(\sqrt{6}-\sqrt{2})(3\sqrt{2}-\sqrt{6})}{8} = \frac{4(2\sqrt{3}-3)}{8} = \fra
c{2\sqrt{3}-3}{2}$$

**Altitude:** $h_a = \sin B\sin C = \frac{\cos 30° - \cos 2\theta}{2}$. Since $\
cos 2\theta = 2\cos^2\theta - 1 = 3 - 2\sqrt{3}$:

$$h_a = \frac{\frac{\sqrt{3}}{2} - (3-2\sqrt{3})}{2} = \frac{5\sqrt{3}-6}{4}$$

**Critical difference:** $h_a - r = \frac{5\sqrt{3}-6}{4} - \frac{2\sqrt{3}-3}{2

**Horizontal offset** of incenter from altitude: $d = \sin C\cos B - (s-b)$. Com

**The incircle intersection:** The altitude ($x = p$) meets the incircle $(x - (

$$r^2 = \frac{21 - 12\sqrt{3}}{4}, \quad d^2 = \frac{21-12\sqrt{3}}{16}$$

$$r^2 - d^2 = \frac{3(21-12\sqrt{3})}{16} = \frac{63-36\sqrt{3}}{16} = \frac{(6-

$$\sqrt{r^2 - d^2} = \frac{6 - 3\sqrt{3}}{4}$$

**Point X** (upper intersection, between $A$ and $Y$): $y_X = r + \sqrt{r^2 - d^

$$AX = h_a - y_X = (h_a - r) - \sqrt{r^2 - d^2} = \frac{\sqrt{3}}{4} - \frac{6-3

## Final Ratio

$$\frac{AO}{AX} = \frac{\frac{1}{2}}{\frac{2\sqrt{3}-3}{2}} = \frac{1}{2\sqrt{3}
