## Proof

Let $A, B, C$ denote the Artificial Intelligence, Biotechnology, and Cybersecuri
ty divisions respectively. We are given:

$$|A|=128,\quad |B|=291,\quad |C|=318,\quad |A\cup B\cup C|=427,\quad |A\cap B\c
ap C|=36.$$

Define:
- $y$ = number of researchers in **exactly one** division,
- $x$ = number of researchers in **exactly two** divisions,
- $z$ = number of researchers in **all three** divisions $= 36$.

**Counting researchers.** Every researcher belongs to at least one division, so
partitioning the 427 researchers by how many divisions they belong to:

$$y + x + z = 427 \implies y + x = 427 - 36 = 391. \quad (1)$$

**Counting division memberships.** The sum $|A|+|B|+|C|$ counts each researcher
once per division they belong to. A researcher in exactly one division contribut
es 1, in exactly two contributes 2, in all three contributes 3:

$$|A|+|B|+|C| = y + 2x + 3z.$$

Computing the left side:

$$128 + 291 + 318 = 737,$$

so

$$y + 2x + 3(36) = 737 \implies y + 2x + 108 = 737 \implies y + 2x = 629. \quad
(2)$$

**Solving.** Subtract equation (1) from equation (2):

$$(y + 2x) - (y + x) = 629 - 391,$$
$$x = 238.$$

**Verification.** With $x = 238$: $y = 391 - 238 = 153$. Check membership count:
 $153 + 2(238) + 3(36) = 153 + 476 + 108 = 737$. ✓ Check total: $153 + 238 + 36
= 427$. ✓

The number of researchers assigned to exactly two of the three divisions is $\bo
xed{238}$.
