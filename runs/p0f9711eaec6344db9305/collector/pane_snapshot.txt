## Proof

We compute $\mathbb{E}(X_s \mid X_t = 1)$ for $0 \le s < t \le 1$, where $X_t =
B_t - tB_1$.

**Step 1: Joint Gaussianity.** Since $B_t$ is a Gaussian process, any linear fun
ctional of it is jointly Gaussian. In particular $(X_s, X_t)$ is jointly Gaussia
n. For jointly Gaussian random variables, the conditional expectation is linear:

$$\mathbb{E}[X_s \mid X_t] = \frac{\operatorname{Cov}(X_s, X_t)}{\operatorname{V
ar}(X_t)}\, X_t.$$

Hence $\mathbb{E}[X_s \mid X_t = 1] = \dfrac{\operatorname{Cov}(X_s, X_t)}{\oper
atorname{Var}(X_t)}.$

**Step 2: Compute $\operatorname{Cov}(X_s, X_t)$.** Using $\operatorname{Cov}(B_
a, B_b) = \min(a,b)$ and expanding:

$$\operatorname{Cov}(X_s, X_t) = \operatorname{Cov}(B_s - sB_1,\; B_t - tB_1).$$

Expanding by bilinearity:

$$= \operatorname{Cov}(B_s,B_t) - t\operatorname{Cov}(B_s,B_1) - s\operatorname{
Cov}(B_1,B_t) + st\operatorname{Cov}(B_1,B_1).$$

Since $s < t \le 1$, we have $\min(s,t)=s$, $\min(s,1)=s$, $\min(1,t)=t$, $\min(
1,1)=1$:

$$= s - t\cdot s - s\cdot t + st\cdot 1 = s - ts - st + st = s(1-t).$$

**Step 3: Compute $\operatorname{Var}(X_t)$.**

$$\operatorname{Var}(X_t) = \operatorname{Var}(B_t - tB_1) = \operatorname{Var}(
B_t) - 2t\operatorname{Cov}(B_t,B_1) + t^2\operatorname{Var}(B_1).$$

$$= t - 2t\cdot\min(t,1) + t^2\cdot 1 = t - 2t^2 + t^2 = t(1-t).$$

**Step 4: Combine.**

$$\mathbb{E}[X_s \mid X_t = 1] = \frac{\operatorname{Cov}(X_s,X_t)}{\operatornam
e{Var}(X_t)} = \frac{s(1-t)}{t(1-t)} = \frac{s}{t}.$$

**Sanity check.** The process $X_t = B_t - tB_1$ is the standard Brownian bridge
 pinned to $0$ at $t=0$ and $t=1$. Conditioning on $X_t = 1$ pins the bridge to
value $1$ at time $t$. The conditional mean at $s < t$ is the linear interpolati
on between the two pins $X_0 = 0$ and $X_t = 1$, namely $s/t$, which is consiste
nt with the Markov/Gaussian structure of the bridge. $\checkmark$

$$\boxed{\mathbb{E}(X_s \mid X_t = 1) = \dfrac{s}{t}}$$
