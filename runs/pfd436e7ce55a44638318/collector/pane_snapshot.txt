# Proof

**Claim:** A σ-finite measure space in which every set of strictly positive meas
ure contains an atom is equivalent (mod 0) to a countable disjoint union of atom
s. The answer is **yes**.

---

## Setup and Definitions

Let $(X, \mathcal{A}, \mu)$ be a σ-finite measure space such that every measurab
le set $E$ with $\mu(E) > 0$ contains an atom. Recall:

- A set $A \in \mathcal{A}$ is an **atom** if $\mu(A) > 0$ and for every measura
ble $B \subseteq A$, either $\mu(B) = 0$ or $\mu(B) = \mu(A)$.
- **σ-finite** means $X = \bigcup_{n=1}^{\infty} X_n$ with $\mu(X_n) < \infty$.
- **Equivalent (mod 0)** means there exist full-measure subsets that are measure
-theoretically isomorphic.

## Step 1: Reduce to a disjoint finite-measure decomposition

Since $X$ is σ-finite, write $X = \bigcup_{n=1}^{\infty} X_n$ with $\mu(X_n) < \
infty$. Set
$$Y_1 = X_1, \qquad Y_n = X_n \setminus \bigcup_{k=1}^{n-1} X_k \quad (n \geq 2)
.$$
Then the $Y_n$ are pairwise disjoint, $\mu(Y_n) \le \mu(X_n) < \infty$, and $X =
 \bigcup_{n=1}^{\infty} Y_n$ (up to a null set, since the $Y_n$ exactly partitio
n $X$).

The key property — *every positive-measure set contains an atom* — is inherited
by each $Y_n$: if $E \subseteq Y_n$ with $\mu(E)>0$, then $E \subseteq X$ with $
\mu(E)>0$, so $E$ contains an atom.

## Step 2: Finite-measure case — maximal disjoint atomic decomposition

**Lemma.** *Let $(Y, \mathcal{A}|_Y, \mu)$ be a finite measure space in which ev
ery positive-measure set contains an atom. Then $Y$ is the union of a countable
collection of disjoint atoms and a null set.*

*Proof of Lemma.* Consider the collection $\mathcal{F}$ of all families of pairw
ise disjoint atoms contained in $Y$, partially ordered by inclusion. Every chain
 in $\mathcal{F}$ has an upper bound (its union is again a family of pairwise di
sjoint atoms). By **Zorn's Lemma**, there exists a maximal family $\{A_i\}_{i \i
n I}$ of pairwise disjoint atoms in $Y$.

**Countability of $I$:** Since the $A_i$ are disjoint and $\mu(Y) < \infty$, for
 each $k \in \mathbb{N}$ the set $\{i \in I : \mu(A_i) \ge 1/k\}$ has cardinalit
y at most $k \cdot \mu(Y) < \infty$. Since every $i \in I$ satisfies $\mu(A_i) >
 0$ and hence $\mu(A_i) \ge 1/k$ for some $k$, we have
$$I = \bigcup_{k=1}^{\infty} \{i \in I : \mu(A_i) \ge 1/k\},$$
which is a countable union of finite sets. Thus $I$ is **countable**.

**The remainder is null:** Set $N = Y \setminus \bigcup_{i \in I} A_i$. If $\mu(
N) > 0$, then by hypothesis $N$ contains an atom $A$. But then $\{A_i\}_{i \in I
} \cup \{A\}$ is a strictly larger family of disjoint atoms, contradicting maxim
ality. Therefore $\mu(N) = 0$, and
$$Y = \left(\bigcup_{i \in I} A_i\right) \cup N, \qquad \mu(N) = 0. \qquad \blac
ksquare$$

## Step 3: Assemble the global decomposition

Apply the Lemma to each $Y_n$. We obtain, for each $n$, a countable index set $I
_n$ and disjoint atoms $\{A^{(n)}_i\}_{i \in I_n}$ in $Y_n$ with
$$Y_n = \left(\bigcup_{i \in I_n} A^{(n)}_i\right) \cup N_n, \qquad \mu(N_n) = 0
.$$

Since the $Y_n$ are pairwise disjoint, the entire collection
$$\{A^{(n)}_i : n \in \mathbb{N},\; i \in I_n\}$$
is a **pairwise disjoint** family of atoms. It is countable (countable union of
countable sets). Let
$$N = \bigcup_{n=1}^{\infty} N_n,$$
which is a countable union of null sets, hence $\mu(N) = 0$. Then
$$X = \left(\bigcup_{n=1}^{\infty} \bigcup_{i \in I_n} A^{(n)}_i\right) \cup N,$
$
where the union of atoms is a **countable disjoint union** and $\mu(N) = 0$.

## Step 4: Equivalence

Set $X^* = X \setminus N = \bigcup_{n,i} A^{(n)}_i$. Then $\mu(X \setminus X^*)
= \mu(N) = 0$, so $X^*$ is a full-measure subset. The restricted measure space $
(X^*, \mathcal{A}|_{X^*}, \mu|_{X^*})$ is **literally** a countable disjoint uni
on of atoms (each $A^{(n)}_i$ is an atom in the restricted space). Therefore $(X
, \mathcal{A}, \mu)$ is equivalent (mod 0) to a measure space that is a countabl
e disjoint union of atoms.

## Remark on necessity of σ-finiteness

The σ-finiteness hypothesis is essential. Without it, one could take $X = \mathb
b{R}$ with counting measure: every nonempty set has positive measure and contain
s a singleton (which is an atom), but $\mathbb{R}$ cannot be written as a counta
ble union of atoms (it is uncountable), and the space is not σ-finite. The count
ability argument in Step 2 relies crucially on $\mu(Y_n) < \infty$.

---

**Conclusion:** A σ-finite measure space in which every set of strictly positive
 measure contains an atom **is** equivalent to a countable disjoint union of ato
ms.
