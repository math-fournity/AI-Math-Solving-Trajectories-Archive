## Solution

**Computing initial terms.** We have $S_1 = 1$, $S_2 = 1$, and for $n \geq 3$:
$$a_n = (S_{n-1}+1)\,S_{n-2}, \qquad S_n = S_{n-1} + a_n.$$

Computing:
- $a_3 = (1+1)\cdot 1 = 2$, $S_3 = 3$
- $a_4 = (3+1)\cdot 1 = 4$, $S_4 = 7$
- $a_5 = (7+1)\cdot 3 = 24$, $S_5 = 31$
- $a_6 = (31+1)\cdot 7 = 224$, $S_6 = 255$
- $a_7 = (255+1)\cdot 31 = 7936$, $S_7 = 8191$

The partial sums are $S_n = 1, 1, 3, 7, 31, 255, 8191, \dots = 2^{F_n}-1$ where
$(F_n)$ is the Fibonacci sequence $1,1,2,3,5,8,13,\dots$ (with $F_1=F_2=1$).

**Claim:** $S_n = 2^{F_n}-1$ for all $n \geq 1$.

*Proof by induction.* Base cases $n=1,2$: $2^{F_1}-1 = 2^1-1 = 1 = S_1$ and $2^{
F_2}-1 = 1 = S_2$. Inductive step: assuming the formula holds for indices $n-1$
and $n-2$,
$$a_n = (S_{n-1}+1)\,S_{n-2} = 2^{F_{n-1}}\bigl(2^{F_{n-2}}-1\bigr),$$
$$S_n = S_{n-1}+a_n = \bigl(2^{F_{n-1}}-1\bigr) + 2^{F_{n-1}}\bigl(2^{F_{n-2}}-1
\bigr) = 2^{F_{n-1}}\cdot 2^{F_{n-2}} - 1 = 2^{F_n}-1,$$
using $F_n = F_{n-1}+F_{n-2}$. ∎

**Factoring $a_n$.** For $n \geq 3$:
$$a_n = 2^{F_{n-1}}\bigl(2^{F_{n-2}}-1\bigr).$$

**Divisibility by 127.** Since $127 = 2^7 - 1$ is a Mersenne prime, and $\gcd(2^
{F_{n-1}}, 127)=1$ (as 127 is odd), we need:
$$127 \mid 2^{F_{n-2}}-1 \iff 2^{F_{n-2}} \equiv 1 \pmod{127}.$$

The multiplicative order of $2$ modulo the Mersenne prime $2^p-1$ is exactly $p$
. Hence $\operatorname{ord}_{127}(2) = 7$, and
$$2^k \equiv 1 \pmod{127} \iff 7 \mid k.$$

So we need $7 \mid F_{m-2}$.

**Fibonacci modulo 7.** Computing the Fibonacci sequence mod 7:
$$F_1\equiv1,\; F_2\equiv1,\; F_3\equiv2,\; F_4\equiv3,\; F_5\equiv5,\; F_6\equi
v1,\; F_7\equiv6,\; F_8\equiv 0 \pmod 7.$$

The Pisano period mod 7 is 16, and $F_n \equiv 0 \pmod{7}$ precisely when $n \eq
uiv 0 \pmod{8}$ (the zeros occur at $n = 8, 16, 24, \dots$).

**Finding the smallest $m > 2$.** We need $m - 2 \equiv 0 \pmod{8}$, i.e., $m \e
quiv 2 \pmod{8}$. The smallest $m > 2$ is $m = 10$.

**Verification.** For $m = 10$: $F_{m-2} = F_8 = 21$, and $7 \mid 21$. Indeed $2
^{21}-1 = (2^7)^3 - 1 = 128^3 - 1 = (128-1)(128^2+128+1) = 127 \cdot 16513$, so
$127 \mid a_{10}$.

Checking all smaller candidates $m = 3,\dots,9$: the values $F_{m-2} = F_1,\dots
,F_7 = 1,1,2,3,5,8,13$ are respectively $\equiv 1,1,2,3,5,1,6 \pmod{7}$, none di
visible by 7. Hence none of $a_3,\dots,a_9$ is divisible by 127.

**The smallest integer $m > 2$ such that $127 \mid a_m$ is $\boxed{10}$.**
