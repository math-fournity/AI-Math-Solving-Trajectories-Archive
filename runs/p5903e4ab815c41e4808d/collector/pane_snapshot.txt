## Proof

**Claim:** The only entire function satisfying $f\!\left(\tfrac{1}{n}\right)=\tf
rac{1}{n^{2}}$ for all positive integers $n$ is $f(z)=z^{2}$.

**Existence.** The function $g(z)=z^{2}$ is entire (a polynomial), and for every
 positive integer $n$,
$$g\!\left(\tfrac{1}{n}\right)=\tfrac{1}{n^{2}},$$
so $g$ satisfies the required condition.

**Uniqueness.** Let $f$ be any entire function satisfying $f\!\left(\tfrac{1}{n}
\right)=\tfrac{1}{n^{2}}$ for all $n\in\mathbb{Z}_{>0}$. Define
$$h(z)=f(z)-z^{2}.$$
Since both $f$ and $z^{2}$ are entire, $h$ is entire. Moreover, for every positi
ve integer $n$,
$$h\!\left(\tfrac{1}{n}\right)=f\!\left(\tfrac{1}{n}\right)-\tfrac{1}{n^{2}}=\tf
rac{1}{n^{2}}-\tfrac{1}{n^{2}}=0.$$

The set $S=\left\{\tfrac{1}{n}:n\in\mathbb{Z}_{>0}\right\}$ is an infinite subse
t of $\mathbb{C}$ with an accumulation point at $0$, and $0\in\mathbb{C}$ (the d
omain of $h$). Since $h$ is holomorphic on all of $\mathbb{C}$ (entire) and vani
shes on $S$, the **identity theorem** for holomorphic functions applies: a holom
orphic function that vanishes on a set with an accumulation point inside its dom
ain must be identically zero.

Therefore $h\equiv 0$, i.e.,
$$f(z)=z^{2}\quad\text{for all }z\in\mathbb{C}.$$

**Conclusion.** The unique entire function satisfying the given condition is
$$\boxed{f(z)=z^{2}}.$$
