## Proof

**Claim.** A finite ring $R$ in which every element satisfies $r^2 = r$ is isomo
rphic to a direct product of copies of the field $\mathbb{F}_2$:

$$R \cong \underbrace{\mathbb{F}_2 \times \mathbb{F}_2 \times \cdots \times \mat
hbb{F}_2}_{n \text{ copies}}$$

for some $n \ge 0$. Equivalently, $R$ is isomorphic to the power-set ring $(\mat
hcal{P}(S), \triangle, \cap)$ of some finite set $S$ with $|S| = n$.

We prove this in four steps.

---

### Step 1. $R$ has characteristic $2$ (i.e., $r + r = 0$ for all $r$).

For any $r \in R$, the element $r + r$ is also in $R$, so it is idempotent:

$$(r + r)^2 = r + r.$$

Expanding the left side (using only the distributive law, no commutativity neede
d):

$$(r+r)(r+r) = r^2 + r^2 + r^2 + r^2 = 4r.$$

Since $r^2 = r$, this gives $4r = 2r$, hence $2r = 0$ for every $r \in R$. In pa
rticular, $-r = r$ for all $r$.

---

### Step 2. $R$ is commutative.

For any $a, b \in R$, the element $a + b$ is idempotent:

$$(a+b)^2 = a + b.$$

Expanding: $a^2 + ab + ba + b^2 = a + b$. Using $a^2 = a$ and $b^2 = b$:

$$ab + ba = 0, \quad \text{i.e., } ab = -ba.$$

By Step 1, $-ba = ba$, so $ab = ba$. Thus $R$ is commutative.

---

### Step 3. $R$ is reduced (has no nonzero nilpotent elements).

Suppose $x \in R$ with $x^k = 0$ for some $k \ge 1$. Since $x$ is idempotent, $x
 = x^2 = x^3 = \cdots = x^k = 0$. So $x = 0$. Hence $R$ is reduced.

---

### Step 4. Structure theorem: $R \cong \mathbb{F}_2^n$.

Since $R$ is finite, it is Artinian. A classical theorem of commutative algebra
states:

> **A reduced Artinian commutative ring is a finite direct product of fields.**

*Proof of this fact (for completeness):* An Artinian ring has finitely many maxi
mal ideals $\mathfrak{m}_1, \dots, \mathfrak{m}_n$, and the Jacobson radical $J
= \bigcap \mathfrak{m}_i$ is nilpotent. Since $R$ is reduced, $J = 0$. By the Ch
inese Remainder Theorem,

$$R \cong R/\mathfrak{m}_1 \times \cdots \times R/\mathfrak{m}_n,$$

where each $R/\mathfrak{m}_i$ is a field.

Now each factor $F_i = R/\mathfrak{m}_i$ is a finite field. Since $R$ has charac
teristic $2$ (Step 1), each $F_i$ has characteristic $2$. Moreover, the idempote
nt property $r^2 = r$ passes to every quotient, so every element of $F_i$ satisf
ies $x^2 = x$, i.e., $x^2 - x = 0$.

In a field, the polynomial $t^2 - t = t(t-1)$ has at most $2$ roots. Since every
 element of $F_i$ is a root, $|F_i| \le 2$. Since $F_i$ is a field of characteri
stic $2$, $|F_i| \ge 2$, so $|F_i| = 2$, meaning $F_i \cong \mathbb{F}_2$.

Therefore:

$$R \cong \mathbb{F}_2 \times \mathbb{F}_2 \times \cdots \times \mathbb{F}_2 \qu
ad (n \text{ copies}).$$

---

### Equivalence with the power-set ring.

The ring $\mathbb{F}_2^n$ is isomorphic to the power-set ring of an $n$-element
set $S = \{1, \dots, n\}$, via the map

$$(a_1, \dots, a_n) \longmapsto \{i \in S : a_i = 1\},$$

where addition in $\mathbb{F}_2^n$ (componentwise mod $2$) corresponds to symmet
ric difference $\triangle$, and multiplication (componentwise) corresponds to in
tersection $\cap$. This is the standard Boolean ring of subsets.

---

### Conclusion.

Every finite ring $R$ satisfying $r^2 = r$ for all $r \in R$ is a **Boolean ring
**, and is isomorphic to

$$\boxed{R \cong \mathbb{F}_2^{\,n} \cong (\mathcal{P}(S),\, \triangle,\, \cap)}
$$

for some finite set $S$ with $|S| = n$, where $n$ is determined by $|R| = 2^n$.
The integer $n$ equals the number of maximal ideals of $R$ (equivalently, the nu
mber of atoms in the corresponding Boolean algebra).
