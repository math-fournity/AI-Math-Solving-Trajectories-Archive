Looking at this problem, I need to find the maximum number of drones on a 19×19
grid where each drone moves every minute to an adjacent cell, no two drones shar
e a cell, and no drone moves along the same directional line (horizontal or vert
ical) in two consecutive minutes.

## Proof

**Rule 3 means H/V alternation.** After a horizontal move (east or west), the ne
xt move must be vertical (north or south), and vice versa. So every drone altern
ates between horizontal and vertical moves.

**Upper bound via cell-type counting.** Classify each cell $(r,c)$ by its type $
(r \bmod 2, c \bmod 2)$. There are four types. In a $19 \times 19$ grid (1-index
ed):
- Odd rows: 10, even rows: 9; odd cols: 10, even cols: 9.
- Type (odd, odd): $10 \times 10 = 100$ cells
- Type (odd, even): $10 \times 9 = 90$ cells
- Type (even, odd): $9 \times 10 = 90$ cells
- Type (even, even): $9 \times 9 = 81$ cells

**Each drone visits all four types with period 4.** A horizontal move flips colu
mn parity; a vertical move flips row parity. Since moves alternate H, V, H, V, .
.., over any 4 consecutive time steps each drone's type sequence is a permutatio
n of all four types — each type visited exactly once.

**Counting constraint.** Let $n_T(t)$ be the number of drones on cells of type $
T$ at time $t$. Since drones on different types occupy disjoint cells, collision
 avoidance requires $n_T(t) \le |T|$ for each type $T$ at every time $t$.

Over any 4 consecutive time steps, each drone visits each type exactly once, so:
$$\sum_{s=0}^{3} n_T(t+s) = N \quad \text{for each type } T.$$

Since each term is at most $|T|$:
$$N \le 4|T| \quad \text{for each type } T.$$

The binding constraint comes from the smallest type, (even, even) with $|T| = 81
$:
$$N \le 4 \times 81 = 324.$$

**Construction achieving 324.** Partition rows $1$–$18$ and columns $1$–$18$ int
o $9 \times 9 = 81$ disjoint $2 \times 2$ blocks. In each block with cells $A=(r
,c)$, $B=(r,c+1)$, $C=(r+1,c+1)$, $D=(r+1,c)$, place 4 drones and have them all
cycle clockwise:
$$A \to B \to C \to D \to A \to \cdots$$

The moves are: $A\to B$ (east, H), $B\to C$ (south, V), $C\to D$ (west, H), $D\t
o A$ (north, V) — alternating H/V correctly. Each drone starts at a different ce
ll, offset by one in the cycle, so at every time step the four drones occupy fou
r distinct cells. Drones never leave their block, so no inter-block collisions o
ccur. All blocks lie within rows 1–18, columns 1–18, so no drone leaves the grid
. The cycle repeats indefinitely.

This gives $81 \times 4 = 324$ drones, matching the upper bound.

**The maximum number of drones is $\boxed{324}$.**
