## Proof

**Answer: No.** $N(A)=0$ does not imply $A=0$. In fact, $N(A)=0$ if and only if
$A$ is a scalar multiple of the identity.

---

**Step 1: $N(A)=0$ forces every unit vector to be an eigenvector.**

By Cauchy–Schwarz, for any unit vector $x$,
$$|\langle Ax,x\rangle| \le \|Ax\|\,\|x\| = \|Ax\|,$$
so $\|Ax\|^2 \ge |\langle Ax,x\rangle|^2$ always. The condition $N(A)=0$ means e
quality holds for **every** unit vector $x$:
$$\|Ax\|^2 = |\langle Ax,x\rangle|^2 \quad\text{for all } \|x\|=1.$$

Equality in Cauchy–Schwarz $|\langle Ax,x\rangle| \le \|Ax\|\|x\|$ occurs precis
ely when $Ax$ and $x$ are linearly dependent. Hence for every unit vector $x$ th
ere exists a scalar $\lambda(x)$ with
$$Ax = \lambda(x)\,x. \tag{1}$$

**Step 2: The eigenvalue $\lambda(x)$ is constant.**

Let $u, v$ be two linearly independent unit vectors. Applying (1) to $u$, $v$, a
nd the unit vector $\frac{u+v}{\|u+v\|}$:

From $u$ and $v$: $Au = \lambda(u)\,u$, $Av = \lambda(v)\,v$.

The vector $u+v$ is also an eigenvector, so there is a scalar $\mu$ with
$$A(u+v) = \mu(u+v).$$

But by linearity,
$$A(u+v) = Au + Av = \lambda(u)\,u + \lambda(v)\,v.$$

Equating:
$$\lambda(u)\,u + \lambda(v)\,v = \mu\,u + \mu\,v.$$

Since $u,v$ are linearly independent, $\lambda(u) = \mu = \lambda(v)$.

Thus any two linearly independent unit vectors share the same eigenvalue. Now ta
ke any unit vector $w$. If $w$ is not parallel to some fixed unit vector $u$, th
en $\lambda(w)=\lambda(u)$. If $w = \pm u$, then $A(-u)=-Au=-\lambda(u)u=\lambda
(u)(-u)$, so $\lambda(w)=\lambda(u)$ as well. Hence $\lambda(x)\equiv c$ is cons
tant, and
$$Ax = c\,x \quad\text{for all } x\in E,$$
i.e., $A = cI$ for some scalar $c$. (The case $\dim E = 1$ is trivial.)

**Step 3: Conversely, every $A=cI$ satisfies $N(A)=0$.**

For $A = cI$ and $\|x\|=1$:
$$\|Ax\|^2 = |c|^2\|x\|^2 = |c|^2, \qquad |\langle Ax,x\rangle|^2 = |c\langle x,
x\rangle|^2 = |c|^2.$$
So $\|Ax\|^2 - |\langle Ax,x\rangle|^2 = 0$ for all unit $x$, giving $N(A)=0$.

**Conclusion.** $N(A)=0 \iff A = cI$ for some scalar $c$. Taking $c=1$ gives $A=
I\neq 0$ with $N(A)=0$. Therefore $N(A)=0$ does **not** imply $A=0$.
