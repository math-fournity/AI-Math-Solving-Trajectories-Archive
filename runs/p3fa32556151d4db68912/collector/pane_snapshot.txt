**Theorem.** If $\gcd(|G|, |\operatorname{Aut}(G)|) = 1$, then $G$ is cyclic.

**Proof.**

**Step 1: $G$ is abelian.**

The inner automorphism group $\operatorname{Inn}(G) \cong G/Z(G)$ is a subgroup
of $\operatorname{Aut}(G)$, so $|G/Z(G)|$ divides $|\operatorname{Aut}(G)|$. Sin
ce $|G/Z(G)|$ also divides $|G|$, we have $|G/Z(G)| \mid \gcd(|G|, |\operatornam
e{Aut}(G)|) = 1$. Hence $|G/Z(G)| = 1$, so $G = Z(G)$ and $G$ is abelian.

**Step 2: $|G|$ is squarefree.**

Since $G$ is abelian, $G = \prod_{p \mid |G|} G_p$ where $G_p$ is the (character
istic) Sylow $p$-subgroup. Any automorphism of $G$ preserves each $G_p$, so $\op
eratorname{Aut}(G) \cong \prod_p \operatorname{Aut}(G_p)$ and $|\operatorname{Au
t}(G)| = \prod_p |\operatorname{Aut}(G_p)|$.

The condition $\gcd(|G|, |\operatorname{Aut}(G)|) = 1$ requires, for every prime
 $p \mid |G|$, that $p \nmid |\operatorname{Aut}(G)|$. In particular, $p \nmid |
\operatorname{Aut}(G_p)|$.

**Lemma.** If $P$ is an abelian $p$-group of order $p^n$ with $n \geq 2$, then $
p \mid |\operatorname{Aut}(P)|$.

*Proof of Lemma.* Write $P = \mathbb{Z}/p^{a_1} \times \cdots \times \mathbb{Z}/
p^{a_k}$ with $a_1 \geq \cdots \geq a_k \geq 1$ and $\sum a_i = n \geq 2$.

Define $K = \{\alpha \in \operatorname{Aut}(P) : \alpha \equiv \mathrm{id} \pmod
{pP}\}$, the kernel of the natural map $\operatorname{Aut}(P) \to \operatorname{
Aut}(P/pP)$.

**$|K|$ is a power of $p$:** Set $K_i = \{\alpha \in \operatorname{Aut}(P) : \al
pha \equiv \mathrm{id} \pmod{p^i P}\}$, giving a filtration $K = K_1 \supseteq K
_2 \supseteq \cdots \supseteq K_m = \{1\}$ (where $p^m P = 0$). The map $\psi_i:
 K_i \to \operatorname{Hom}(P/pP,\; p^i P / p^{i+1}P)$ defined by $\alpha \mapst
o (\bar{x} \mapsto \overline{\alpha(x) - x})$ is a well-defined homomorphism wit
h kernel $K_{i+1}$. (Well-definedness: if $x = y + pz$, then $\alpha(x)-x = (\al
pha(y)-y) + p(\alpha(z)-z)$, and $\alpha(z)-z \in p^i P$ gives $p(\alpha(z)-z) \
in p^{i+1}P$.) Since both $P/pP$ and $p^i P/p^{i+1}P$ are $\mathbb{F}_p$-vector
spaces, $|\operatorname{Hom}(P/pP, p^i P/p^{i+1}P)|$ is a power of $p$, so each
$|K_i/K_{i+1}|$ is a power of $p$. Thus $|K| = \prod |K_i/K_{i+1}|$ is a power o
f $p$.

**$|K| > 1$ when $P$ is not elementary abelian (i.e., $a_1 \geq 2$):** We exhibi
t a non-trivial element of $K$. Note that any $\alpha \equiv \mathrm{id} \pmod{p
P}$ is automatically an automorphism: $\alpha(P) + pP = P$ implies $P/\alpha(P)
= p(P/\alpha(P))$, which forces $P/\alpha(P) = 0$ for a finite $p$-group, so $\a
lpha$ is surjective hence bijective.

- *If $a_2 \geq 2$:* Define $\alpha(g_1) = g_1 + pg_2$, $\alpha(g_i) = g_i$ for
$i \geq 2$. This is a valid homomorphism ($p^{a_1}(g_1 + pg_2) = p^{a_1+1}g_2 =
0$ since $a_1 + 1 > a_2$), lies in $K$ ($pg_2 \in pP$), and is non-trivial ($pg_
2 \neq 0$ since $a_2 \geq 2$).

- *If $a_2 = 1$ (so $a_2 = \cdots = a_k = 1$, $a_1 \geq 2$):* Define $\alpha(g_1
) = g_1 + p^{a_1-1}g_2$, $\alpha(g_i) = g_i$ for $i \geq 2$. This is a valid hom
omorphism ($p^{a_1}(g_1 + p^{a_1-1}g_2) = p^{2a_1-1}g_2 = 0$ since $g_2$ has ord
er $p$ and $2a_1 - 1 \geq 3$), lies in $K$ ($p^{a_1-1}g_2 = p \cdot p^{a_1-2}g_2
 \in pP$), and is non-trivial ($p^{a_1-1}g_2 \neq 0$ since $g_2$ has order $p$ a
nd $a_1 - 1 \geq 1$).

In both subcases, $|K| > 1$ and $|K|$ is a power of $p$, so $p \mid |K| \mid |\o
peratorname{Aut}(P)|$.

**If $P = (\mathbb{Z}/p)^k$ with $k \geq 2$** (elementary abelian, $a_1 = 1$): T
hen $\operatorname{Aut}(P) = \mathrm{GL}(k, \mathbb{F}_p)$ and $|\mathrm{GL}(k,p
)| = \prod_{i=0}^{k-1}(p^k - p^i)$. Since $p \mid (p^k - p) = p(p^{k-1}-1)$, we
get $p \mid |\operatorname{Aut}(P)|$.

**If $P = \mathbb{Z}/p^n$ with $n \geq 2$** (cyclic, $k = 1$): $|\operatorname{A
ut}(P)| = \varphi(p^n) = p^{n-1}(p-1)$, so $p \mid |\operatorname{Aut}(P)|$.

This covers all cases with $n \geq 2$, completing the Lemma. $\square$

Applying the Lemma: $p \nmid |\operatorname{Aut}(G_p)|$ forces $|G_p| = p$ for e
very $p \mid |G|$, i.e., each $G_p \cong \mathbb{Z}/p$. Thus $|G|$ is squarefree

**Step 3: $G$ is cyclic.**

$G$ is abelian with squarefree order, so $G \cong \prod_{p \mid |G|} \mathbb{Z}/
p$. Since the factors have pairwise coprime orders, this direct product is cycli
c. $\blacksquare$

**Answer: Yes, $G$ must be cyclic.**
