Looking at this problem, I need to find DX given that A, B, C, D, X lie on a cir
cle with ∠AXB = ∠BXC = ∠CXD, and AX = a, BX = b, CX = c.

## Proof

**Setup.** Let the circle have radius R. By the inscribed angle theorem, ∠AXB =
∠BXC = ∠CXD = θ implies that the arcs AB, BC, CD (not containing X) are all equa
l to 2θ. So A, B, C, D are equally spaced on the arc not containing X, with cons
ecutive arc measure 2θ.

**Parameterization.** Let the arc from X to A (not passing through B, C, D) have
 measure 2p, where p > 0. Then the arcs from X to A, B, C, D (each measured alon
g the arc not passing through the other labeled points) are:

- Arc XA = 2p
- Arc XB = 2p + 2θ
- Arc XC = 2p + 4θ
- Arc XD = 2p + 6θ

Since the total circumference is 2π and all five arcs (XA, AB, BC, CD, DX) are p
ositive, we have 2p + 6θ < 2π, hence **0 < p < p + 3θ < π**.

**Chord lengths.** The chord between two points separated by a central angle ψ h
as length 2R sin(ψ/2). (This is the same for either arc since sin(ψ/2) = sin(π −
 ψ/2).) Therefore:

$$a = 2R\sin p, \quad b = 2R\sin(p+\theta), \quad c = 2R\sin(p+2\theta), \quad d
 = 2R\sin(p+3\theta).$$

Since 0 < p < p+3θ < π, all four sines are **positive**, so no absolute values a
re needed.

**Key identity.** Using the sum-to-product formula:

$$\sin u + \sin(u + 2\theta) = 2\sin(u+\theta)\cos\theta.$$

Applying this with u = p:

$$a + c = 2b\cos\theta \quad \Longrightarrow \quad \cos\theta = \frac{a+c}{2b}.
\tag{1}$$

Applying the same identity with u = p + θ:

$$\sin(p+\theta) + \sin(p+3\theta) = 2\sin(p+2\theta)\cos\theta,$$

$$b + d = 2c\cos\theta. \tag{2}$$

**Solving for d.** Substituting (1) into (2):

$$d = 2c\cdot\frac{a+c}{2b} - b = \frac{c(a+c)}{b} - b = \frac{ac + c^2 - b^2}{b
}.$$

**Verification.** Check with R = 1, θ = π/6, p = π/6:
- a = 2sin(π/6) = 1, b = 2sin(π/3) = √3, c = 2sin(π/2) = 2, d = 2sin(2π/3) = √3.
- Formula: (4 + 1·2 − 3)/√3 = 3/√3 = √3. ✓

Check symmetric case p = π/2 − 3θ/2 (gives a = d, b = c):
- Formula: (b² + ab − b²)/b = a = d. ✓

## Answer

$$\boxed{DX = \frac{c^2 + ac - b^2}{b}}$$
