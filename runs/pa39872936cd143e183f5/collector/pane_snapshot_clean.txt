## Proof

**Problem.** Determine the minimum number of values needed to describe the orien
tation of a 3-dimensional rigid body in $n$-dimensional space.

### Setup

A 3-dimensional rigid body carries an intrinsic orthonormal frame — three mutual
ly orthogonal unit vectors (its body axes). Describing the body's **orientation*
* in $\mathbb{R}^n$ amounts to specifying where these three body axes land in th
e ambient $n$-dimensional space, relative to a fixed reference frame. No transla
tion is involved (orientation only), so we need exactly an ordered orthonormal 3
-tuple in $\mathbb{R}^n$.

The set of all such ordered orthonormal 3-tuples is the **Stiefel manifold** $V_
3(\mathbb{R}^n)$:
$$V_3(\mathbb{R}^n) = \bigl\{(v_1, v_2, v_3) : v_i \in \mathbb{R}^n,\; \langle v
_i, v_j\rangle = \delta_{ij}\bigr\}.$$

The minimum number of real values (coordinates) needed to describe a generic ori
entation is the **dimension** of this manifold.

### Counting dimensions

We build an orthonormal 3-frame one vector at a time and count free parameters a
t each step.

**First vector $v_1$.** It must be a unit vector in $\mathbb{R}^n$, i.e., a poin
t of the unit sphere $S^{n-1}$. This contributes
$$\dim S^{n-1} = n - 1$$
free parameters.

**Second vector $v_2$.** It must be a unit vector orthogonal to $v_1$. The ortho
gonal complement $v_1^\perp$ is an $(n-1)$-dimensional subspace, and $v_2$ range
s over the unit sphere inside it, $S^{n-2}$. This contributes
$$n - 2$$
free parameters.

**Third vector $v_3$.** It must be a unit vector orthogonal to both $v_1$ and $v
_2$. The common orthogonal complement $\{v_1, v_2\}^\perp$ is an $(n-2)$-dimensi
onal subspace, and $v_3$ ranges over its unit sphere, $S^{n-3}$. This contribute
s
$$n - 3$$
free parameters.

### Total

Summing the free parameters:
$$(n-1) + (n-2) + (n-3) = 3n - 6.$$

### Verification against known cases

- **$n = 3$:** $3\cdot 3 - 6 = 3$. A 3D rigid body in 3D space needs 3 values (E
uler angles / axis-angle). ✓
- **$n = 4$:** $3\cdot 4 - 6 = 6$. A 3D rigid body in 4D space needs 6 values —
three to orient it within a 3D subspace, plus three more to choose which 3D subs
pace of $\mathbb{R}^4$ it lies in (the Grassmannian $Gr(3,4)$ has dimension $3$,
 and $3 + 3 = 6$). ✓

Both agree with the formula, confirming the count.

### Minimality

The Stiefel manifold $V_3(\mathbb{R}^n)$ is a smooth manifold of dimension $3n -
 6$, so any local coordinate chart on it uses exactly $3n - 6$ real parameters.
No fewer than $\dim V_3(\mathbb{R}^n)$ continuous parameters can parametrize a n
eighborhood of any orientation, since a continuous injective map from $\mathbb{R
}^m$ into a manifold of dimension $d$ requires $m \geq d$ (by invariance of doma
in / Sard's theorem). Hence $3n - 6$ is both sufficient and necessary.

### Answer

$$\boxed{3n - 6}$$
