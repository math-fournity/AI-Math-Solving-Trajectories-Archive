## Upper Bound: $n \leq 10$

Suppose an $(n+1) \times (n-1)$ board is 3-colored with no monochromatic $2 \tim
es 2$. For each color $c \in \{0,1,2\}$, let $e_c$ be the number of cells of col
or $c$, so $e_0 + e_1 + e_2 = (n+1)(n-1) = n^2 - 1$.

For color $c$, define the bipartite graph $G_c$ on rows and columns where edge $
(r,j)$ exists iff cell $(r,j)$ has color $c$. The no-monochromatic-$2\times2$ co
ndition means each $G_c$ is $K_{2,2}$-free.

**Key counting.** In a $K_{2,2}$-free bipartite graph with $n+1$ rows and $n-1$
columns, any two columns share at most one common row-neighbor. If $d_c(r)$ is t
he number of columns of color $c$ in row $r$, then:
$$\sum_{r=1}^{n+1} \binom{d_c(r)}{2} \leq \binom{n-1}{2} = \frac{(n-1)(n-2)}{2}.
$$

By convexity of $\binom{x}{2}$ (Jensen's inequality):
$$\frac{e_c^2 - (n+1)e_c}{2(n+1)} \leq \frac{(n-1)(n-2)}{2},$$
which gives:
$$e_c \leq \frac{(n+1) + \sqrt{(n+1)^2 + 4(n+1)(n-1)(n-2)}}{2}.$$

**Checking $n = 11$:** We get $e_c \leq \frac{12 + \sqrt{144 + 4320}}{2} = \frac
{12 + \sqrt{4464}}{2}$. Since $66^2 = 4356 < 4464 < 4489 = 67^2$, we have $e_c \
leq 39$. Then $e_0 + e_1 + e_2 \leq 117 < 120 = 11^2 - 1$. **Contradiction.** So
 $n \leq 10$.

## Construction for $n = 10$

We construct an $11 \times 9$ grid (in fact, a $12 \times 9$ grid, then drop one
 row).

**Setup.** Index the 9 columns by $\mathbb{F}_3^2 = \{(x,y) : x,y \in \{0,1,2\}\
}$. Choose 4 directions, one from each antipodal pair in $\mathbb{F}_3^2$:
$$D = \{(1,0),\; (0,1),\; (1,1),\; (1,2)\}.$$
These are pairwise non-proportional (no two are scalar multiples).

Index the 12 rows by $(a,b,c) \in D \times \mathbb{F}_3$. Define the color of ro
w $(a,b,c)$ at column $(x,y)$ as:
$$f\big((a,b,c),\, (x,y)\big) = ax + by + c \pmod{3}.$$

**Verification.** Take two distinct rows $(a,b,c) \neq (a',b',c')$ and any color
 $\alpha \in \mathbb{F}_3$.

- **Same direction** $(a,b) = (a',b')$, $c \neq c'$: Then $f - f' = c - c' \neq
0$ is constant, so the two rows never agree in any column. No monochromatic $2 \
times 2$. ✓

- **Different directions** $(a,b) \neq (a',b')$: Since we chose one direction pe
r antipodal pair, $(a,b)$ and $(a',b')$ are not proportional. The equations $ax
+ by = \alpha - c$ and $a'x + b'y = \alpha - c'$ define two non-parallel lines i
n $\mathbb{F}_3^2$, which intersect in **exactly one point**. So there is exactl
y **one** column where both rows have color $\alpha$.

  Since for each color $\alpha$ there is at most one column where both rows equa
l $\alpha$, no two columns can both have both rows equal to the same color. Henc
e no monochromatic $2 \times 2$. ✓

This gives a valid $12 \times 9$ coloring. Taking any 11 rows yields a valid $11
 \times 9$ coloring, achieving $n = 10$.
