## Proof

Let $y=1/x$ with $x>0$. The function is symmetric in $x,y$, so it suffices to an
alyze by cases based on the floor values.

**Key observation.** Since $xy=1$ and $x,y>0$:
- If $x<1$ then $y>1$, so $[x]=0$.
- If $x>1$ then $y<1$, so $[y]=0$.
- If $x=1$ then $y=1$, so $[x]=[y]=1$.

So either exactly one of $[x],[y]$ is $0$ (when $x\neq 1$), or both equal $1$ (w
hen $x=1$).

---

**Case 1: $x=1$.** Then $y=1$, and
$$f(1,1)=\frac{2}{1\cdot1+1+1+1}=\frac{2}{4}=\frac12.$$

So $\tfrac12$ is an isolated value.

---

**Case 2: $x\neq 1$.** By symmetry assume $x<1<y$, so $[x]=0$. Let $m=[y]=\bigl[
\tfrac1x\bigr]\ge 1$. The condition $m\le \tfrac1x < m+1$ gives
$$\frac{1}{m+1}<x\le\frac{1}{m}.$$
On this interval,
$$f(x,1/x)=\frac{x+1/x}{m+1}.$$

Let $g(x)=x+\tfrac1x$. Since $g'(x)=1-\tfrac1{x^2}<0$ for $x\in(0,1)$, $g$ is st
rictly decreasing. Hence on $\bigl(\tfrac1{m+1},\tfrac1m\bigr]$:
- supremum (not attained, since the left endpoint is open): $\displaystyle\lim_{
x\to \frac1{m+1}^{+}} \frac{g(x)}{m+1}=\frac{\frac1{m+1}+(m+1)}{m+1}=1+\frac1{(m
+1)^2}$;
- minimum (attained at $x=\tfrac1m$): $\displaystyle\frac{\frac1m+m}{m+1}=\frac{
m^2+1}{m(m+1)}$.

Thus for each $m\ge 1$,
$$f\in\left[\frac{m^2+1}{m(m+1)},\; 1+\frac1{(m+1)^2}\right).$$

Computing the endpoints:
- $m=1$: $\bigl[1,\;\tfrac54\bigr)$;
- $m=2$: $\bigl[\tfrac56,\;\tfrac{10}{9}\bigr)$;
- $m=3$: $\bigl[\tfrac56,\;\tfrac{17}{16}\bigr)$;
- $m=4$: $\bigl[\tfrac{17}{20},\;\tfrac{26}{25}\bigr)$;

and as $m\to\infty$, both endpoints $\to 1$.

The lower bound $L(m)=\tfrac{m^2+1}{m(m+1)}$ satisfies $L(1)=1$, $L(2)=L(3)=\tfr
ac56$ (the global minimum), and $L(m)$ increases for $m\ge 3$. The upper bound $
U(m)=1+\tfrac1{(m+1)^2}$ is maximized at $m=1$ with $U(1)=\tfrac54$ and decrease
s to $1$.

Since the $m=2$ interval $\bigl[\tfrac56,\tfrac{10}{9}\bigr)$ and the $m=1$ inte
rval $\bigl[1,\tfrac54\bigr)$ overlap (both contain $(1,\tfrac{10}{9})$), and ev
ery $m\ge 3$ interval lies inside $\bigl[\tfrac56,\tfrac54\bigr)$, the union ove
r all $m\ge 1$ is
$$\bigcup_{m\ge 1}\left[\frac{m^2+1}{m(m+1)},\,1+\frac1{(m+1)^2}\right)=\left[\f
rac56,\frac54\right).$$

The value $\tfrac56$ is attained (e.g. $x=\tfrac12,y=2$: $f=\tfrac{5/2}{3}=\tfra
c56$; or $x=\tfrac13,y=3$). The value $\tfrac54$ is the supremum but is not atta
ined (it would require $x=\tfrac12$ with $m=1$, but at $x=\tfrac12$ we have $m=[
2]=2$, giving $\tfrac56$ instead).

By symmetry the case $x>1$ yields the same set.

---

**Combining both cases**, the range of $f$ is
$$\boxed{\left\{\frac12\right\}\;\cup\;\left[\frac56,\frac54\right).}$$
