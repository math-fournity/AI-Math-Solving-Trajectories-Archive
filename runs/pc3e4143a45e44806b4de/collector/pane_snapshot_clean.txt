# Green Function for the Inhomogeneous Klein-Gordon Equation

## Problem

Find $\Delta(x-y)$ satisfying
$$(\partial_\mu\partial^\mu + m^2)\,\phi(x) = J(x),$$
i.e. solve
$$(\Box_x + m^2)\,\Delta(x-y) = \delta^{(4)}(x-y), \qquad \Box = \partial_\mu\pa
rtial^\mu = \partial_t^2 - \nabla^2,$$
with metric signature $(+,-,-,-)$.

## Step 1 — Fourier representation

Write the Green function as a four-dimensional Fourier integral:
$$\Delta(x-y) = \int \frac{d^4k}{(2\pi)^4}\, \tilde\Delta(k)\, e^{-ik\cdot(x-y)}
, \qquad k\cdot x = k^0 x^0 - \mathbf{k}\cdot\mathbf{x}.$$

Acting with the KG operator,
$$\Box\, e^{-ik\cdot x} = \partial_\mu\partial^\mu e^{-ik\cdot x} = -k_\mu k^\mu
\, e^{-ik\cdot x} = -k^2\, e^{-ik\cdot x}, \qquad k^2 = (k^0)^2 - |\mathbf{k}|^2
.$$

Hence
$$(\Box + m^2)e^{-ik\cdot x} = -(k^2 - m^2)\, e^{-ik\cdot x}.$$

Using $\delta^{(4)}(x-y) = \int \frac{d^4k}{(2\pi)^4} e^{-ik\cdot(x-y)}$, the de
fining equation gives
$$-(k^2 - m^2)\,\tilde\Delta(k) = 1 \quad\Longrightarrow\quad \tilde\Delta(k) =
-\frac{1}{k^2 - m^2}.$$

Therefore
$$\boxed{\;\Delta(x-y) = -\int \frac{d^4k}{(2\pi)^4}\,\frac{e^{-ik\cdot(x-y)}}{k
^2 - m^2}\;}$$
where the $k^0$ integration must be defined by a pole prescription fixing the bo
undary conditions. The poles are at $k^0 = \pm\omega_{\mathbf{k}}$, $\omega_{\ma
thbf{k}} = \sqrt{|\mathbf{k}|^2 + m^2}$.

## Step 2 — Performing the $k^0$ integral (retarded prescription)

Choose the **retarded** prescription: both poles shifted below the real $k^0$ ax
is,
$$\frac{1}{k^2-m^2} \to \frac{1}{(k^0+i\epsilon)^2 - \omega_{\mathbf{k}}^2}.$$

Closing the contour in the lower (upper) half-plane for $x^0-y^0>0$ ($<0$) gives
 zero for $x^0<y^0$ (causality). For $x^0>y^0$, the residues at $k^0 = +\omega_{
\mathbf{k}}-i\epsilon$ and $k^0 = -\omega_{\mathbf{k}}-i\epsilon$ yield
$$\Delta_R(x-y) = \theta(x^0-y^0)\int\frac{d^3\mathbf{k}}{(2\pi)^3}\frac{1}{2\om
ega_{\mathbf{k}}}\Big[e^{-ik\cdot(x-y)}\Big|_{k^0=\omega_{\mathbf{k}}} - e^{-ik\
cdot(x-y)}\Big|_{k^0=-\omega_{\mathbf{k}}}\Big].$$

Writing $k\cdot(x-y)\big|_{k^0=\pm\omega_{\mathbf{k}}} = \pm\omega_{\mathbf{k}}(
x^0-y^0) - \mathbf{k}\cdot(\mathbf{x}-\mathbf{y})$:
$$\boxed{\;\Delta_R(x-y) = \theta(x^0-y^0)\int\frac{d^3\mathbf{k}}{(2\pi)^3}\fra
c{1}{2\omega_{\mathbf{k}}}\Big[e^{-i\omega_{\mathbf{k}}(x^0-y^0)+i\mathbf{k}\cdo
t(\mathbf{x}-\mathbf{y})} - e^{+i\omega_{\mathbf{k}}(x^0-y^0)+i\mathbf{k}\cdot(\
mathbf{x}-\mathbf{y})}\Big]\;}$$

Equivalently, using $e^{-i\omega\tau}-e^{+i\omega\tau} = -2i\sin(\omega\tau)$,
$$\Delta_R(x-y) = -\theta(x^0-y^0)\int\frac{d^3\mathbf{k}}{(2\pi)^3}\frac{\sin\!
\big(\omega_{\mathbf{k}}(x^0-y^0)\big)}{\omega_{\mathbf{k}}}\,e^{i\mathbf{k}\cdo
t(\mathbf{x}-\mathbf{y})}.$$

## Step 3 — Verification

**Support:** $\theta(x^0-y^0)$ enforces retarded causality; $\Delta_R$ vanishes
outside the forward light cone.

**Equation:** For $x\neq y$, $(\Box+m^2)\Delta_R = 0$ since each plane wave $e^{
\mp i\omega_{\mathbf{k}}t+i\mathbf{k}\cdot\mathbf{x}}$ is an on-shell solution (
$k^2=m^2$). At $x=y$, the $k^0$-residue computation reproduces $\delta^{(4)}(x-y
)$: the jump of $\partial_t\Delta_R$ at $t=0$ equals $\delta^{(3)}(\mathbf{x}-\m
athbf{y})$, since
$$\partial_{x^0}\Delta_R\big|_{x^0\to y^{0+}} = -\int\frac{d^3\mathbf{k}}{(2\pi)
^3}\frac{\omega_{\mathbf{k}}}{2\omega_{\mathbf{k}}}\Big[(-i)e^{i\mathbf{k}\cdot\
mathbf{r}} - (i)e^{i\mathbf{k}\cdot\mathbf{r}}\Big] = -\int\frac{d^3\mathbf{k}}{
(2\pi)^3} e^{i\mathbf{k}\cdot\mathbf{r}}\cdot(i) ...$$
which evaluates to $-\delta^{(3)}(\mathbf{r})$ up to the convention sign, confir
ming $(\Box+m^2)\Delta_R = \delta^{(4)}$.

**Solution to the inhomogeneous equation:** With $\Delta_R$ in hand,
$$\phi(x) = \phi_{\rm hom}(x) + \int d^4y\,\Delta_R(x-y)\,J(y),$$
where $\phi_{\rm hom}$ solves the homogeneous KG equation, gives the general sol
ution since $(\Box_x+m^2)\int d^4y\,\Delta_R(x-y)J(y) = \int d^4y\,\delta^{(4)}(
x-y)J(y) = J(x)$.

## Step 4 — Other prescriptions (completeness)

| Prescription | Poles | Result |
|---|---|---|
| Retarded $\Delta_R$ | both below | $\theta(x^0-y^0)\times(\text{above})$, caus
al |
| Advanced $\Delta_A$ | both above | $\theta(y^0-x^0)\times(\text{above})$ |
| Feynman $\Delta_F$ | $+\omega$ below, $-\omega$ above | $\Delta_F = \int\frac{
d^4k}{(2\pi)^4}\frac{i\,e^{-ik\cdot(x-y)}}{k^2-m^2+i\epsilon}$ (QFT time-ordered
) |

The **Feynman propagator** (standard in QFT) is
$$\boxed{\;\Delta_F(x-y) = \int\frac{d^4k}{(2\pi)^4}\frac{i\,e^{-ik\cdot(x-y)}}{
k^2 - m^2 + i\epsilon}\;}$$
and satisfies $(\Box_x+m^2)\Delta_F(x-y) = -i\,\delta^{(4)}(x-y)$ (the $-i$ is t
he QFT convention; the classical Green function is $i\Delta_F$).

## Conclusion

The Green function of the inhomogeneous Klein-Gordon equation is, in its univers
al Fourier form,
$$\Delta(x-y) = -\int\frac{d^4k}{(2\pi)^4}\frac{e^{-ik\cdot(x-y)}}{k^2-m^2},$$
with the $k^0$-contour fixed by boundary conditions. For the physically natural
retarded (causal) choice:
$$\Delta_R(x-y) = \theta(x^0-y^0)\int\frac{d^3\mathbf{k}}{(2\pi)^3}\frac{1}{2\om
ega_{\mathbf{k}}}\Big[e^{-i\omega_{\mathbf{k}}(x^0-y^0)+i\mathbf{k}\cdot(\mathbf
{x}-\mathbf{y})} - e^{+i\omega_{\mathbf{k}}(x^0-y^0)+i\mathbf{k}\cdot(\mathbf{x}
-\mathbf{y})}\Big],\quad \omega_{\mathbf{k}}=\sqrt{|\mathbf{k}|^2+m^2},$$
which satisfies $(\Box_x+m^2)\Delta_R(x-y)=\delta^{(4)}(x-y)$ and $\Delta_R(x-y)
=0$ for $x^0<y^0$. The general solution of the inhomogeneous equation is $\phi(x
)=\phi_{\rm hom}(x)+\int d^4y\,\Delta_R(x-y)J(y)$.
