Let $(a_n)$ be positive reals with $\sum_{n=1}^\infty a_n = \infty$ and $a_n \to
 0$. Fix $a > 0$. We construct a subsequence $(a_{n_k})$ with $\sum_{k=1}^\infty
 a_{n_k} = a$.

**Greedy construction.** Set $n_0 := 0$ and $S_0 := 0$. Inductively, having chos
en $n_1 < \dots < n_{k-1}$ with partial sum $S_{k-1} = \sum_{j=1}^{k-1} a_{n_j}
\le a$, define

$$n_k := \min\{\, n > n_{k-1} : S_{k-1} + a_n \le a \,\}.$$

*The minimum exists.* If $S_{k-1} < a$, then $a - S_{k-1} > 0$, and since $a_n \
to 0$, all sufficiently large $n$ satisfy $a_n < a - S_{k-1}$, so the set is non
empty. (If $S_{k-1} = a$ we are already done; the argument below shows this cann
ot happen prematurely.)

By construction $S_k \le a$ for every $k$, and $(S_k)$ is increasing, so $S_k \t
o L$ for some $L \le a$.

**Claim: $L = a$.** Suppose for contradiction that $L < a$, and set $\delta := a
 - L > 0$.

Since $a_n \to 0$, choose $N$ so that $a_n < \delta/2$ for all $n \ge N$. Since
$S_{k-1} \to L$ and $n_{k-1} \to \infty$, choose $K$ large enough that $n_{K-1}
\ge N$ and $a - S_{k-1} > \delta/2$ for all $k \ge K$. Then for every $k \ge K$,

$$a_{n_{k-1}+1} < \frac{\delta}{2} < a - S_{k-1},$$

so the index $n_{k-1}+1$ belongs to the set $\{n > n_{k-1} : S_{k-1}+a_n \le a\}
$. Being the smallest admissible index, the greedy rule gives $n_k = n_{k-1}+1$
for all $k \ge K$. Hence $n_k = n_{K-1} + (k - K + 1)$ for $k \ge K$; the select
ed subsequence is, from step $K$ onward, just a consecutive tail of $(a_n)$.

Therefore

$$\sum_{k=K}^{\infty} a_{n_k} \;=\; \sum_{n\,=\,n_{K-1}+1}^{\infty} a_n \;=\; \i
nfty,$$

because deleting finitely many terms from a divergent series of positive terms l
eaves it divergent. But this contradicts $\sum_{k=1}^{\infty} a_{n_k} = L \le a
< \infty$.

The contradiction forces $L = a$, i.e.,

$$\sum_{k=1}^{\infty} a_{n_k} = a. \qquad \blacksquare$$
