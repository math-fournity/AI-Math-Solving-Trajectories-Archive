## Solution

We find all functions $f: \mathbb{R} \to \mathbb{R}$ satisfying
$$f(f(x+1) + y - 1) = f(x) + y \quad \text{for all } x, y \in \mathbb{R}. \tag{$
\star$}$$

### Step 1: Rewrite as a relation between $f(t)$ and $t$.

Fix $x \in \mathbb{R}$. As $y$ ranges over $\mathbb{R}$, the expression $t := f(
x+1) + y - 1$ ranges over all of $\mathbb{R}$, and correspondingly $y = t - f(x+
1) + 1$. Substituting into $(\star)$:

$$f(t) = f(x) + t - f(x+1) + 1 \quad \text{for all } t, x \in \mathbb{R}.$$

### Step 2: Extract the constant.

Rearrange:

$$f(t) - t = f(x) - f(x+1) + 1 \quad \text{for all } t, x \in \mathbb{R}.$$

The left-hand side depends only on $t$, while the right-hand side depends only o
n $x$. Since they are equal for **all** pairs $(t,x)$, both sides must equal a s
ingle constant $k \in \mathbb{R}$:

- $f(t) - t = k$ for all $t$, i.e. $f(t) = t + k$;
- $f(x) - f(x+1) + 1 = k$ for all $x$.

### Step 3: Determine $k$.

From $f(t) = t + k$ we compute
$$f(x) - f(x+1) + 1 = (x + k) - (x + 1 + k) + 1 = 0.$$

Hence $k = 0$, giving $f(t) = t$.

### Step 4: Verification.

With $f(x) = x$:
$$f(f(x+1) + y - 1) = f(x+1) + y - 1 = (x+1) + y - 1 = x + y,$$
$$f(x) + y = x + y.$$
Both sides agree. ✓

### Conclusion.

The unique solution is $\boxed{f(x) = x}$.
