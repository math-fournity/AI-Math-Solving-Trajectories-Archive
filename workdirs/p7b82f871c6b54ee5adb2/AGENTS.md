# Problem

A high-tech server farm is organized into an $8 \times 8$ grid of 64 data nodes. Each node has a specific power output measured in megawatts (MW). The outputs are assigned row by row, from top to bottom and left to right: the first row contains nodes with outputs 1 through 8, the second row 9 through 16, and so on, until the eighth row, which contains nodes 57 through 64.

The facility manager wants to activate a subset of these nodes to maximize the total power output. However, due to electromagnetic interference, certain nodes cannot be active simultaneously. Specifically, if two active nodes are positioned such that they form the opposite corners of any $2 \times 3$ or $3 \times 2$ rectangle within the grid, the system will short-circuit.

The manager must select a configuration of active nodes that obeys this interference constraint while achieving the highest possible combined power output. What is the maximum total sum of megawatts that can be attained?
