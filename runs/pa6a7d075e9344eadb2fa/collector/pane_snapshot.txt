## Proof

### $k = 2$ is impossible

case:

**(i) Only $e_5 \neq 0$:** $p(x) = x^5 - e_5$. The equation $x^5 = e_5$ has exac
tly one real root (since 5 is odd), so we cannot have 5 distinct integer roots.

**(ii) Only $e_4 \neq 0$:** $p(x) = x^5 + e_4 x = x(x^4 + e_4)$. One root is $0$
; the others satisfy $x^4 = -e_4$, yielding at most $2$ real roots. We need $4$
more distinct integer roots — impossible.

**(iii) Only $e_3 \neq 0$:** $p(x) = x^5 - e_3 x^2 = x^2(x^3 - e_3)$. The root $
0$ has multiplicity $\geq 2$, contradicting distinctness.

**(iv) Only $e_2 \neq 0$:** $p(x) = x^5 + e_2 x^3 = x^3(x^2 + e_2)$. The root $0
$ has multiplicity $\geq 3$, contradicting distinctness.

**(v) Only $e_1 \neq 0$:** $p(x) = x^5 - e_1 x^4 = x^4(x - e_1)$. The root $0$ h
as multiplicity $4$, contradicting distinctness.

Therefore $k \geq 3$.

### $k = 3$ is achievable

Take $m_1 = 0,\; m_2 = 1,\; m_3 = -1,\; m_4 = 2,\; m_5 = -2$. These are five dis
tinct integers. Then:

$$p(x) = x(x-1)(x+1)(x-2)(x+2) = x(x^2-1)(x^2-4).$$

Expanding:
$$(x^2-1)(x^2-4) = x^4 - 5x^2 + 4,$$
$$p(x) = x^5 - 5x^3 + 4x.$$
