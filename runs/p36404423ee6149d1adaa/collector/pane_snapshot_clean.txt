## Solution

**Problem.** Find all $f: \mathbb{R} \to \mathbb{R}$ such that for all $x, y \in
 \mathbb{R}$:
$$f(x - f(x - y)) + x = f(x + y). \tag{P}$$

**Claim.** The only solution is $f(x) = x$.

### Step 1: Key substitutions

Let $P(x,y)$ denote the assertion. Substitute $u = x - y$ (so $y = x - u$), whic
h ranges over all reals as $y$ does. Then (P) becomes, for all $x, u \in \mathbb
{R}$:
$$f(x - f(u)) = f(2x - u) - x. \tag{$\ast$}$$

**Setting $u = 0$** (let $c := f(0)$):
$$f(x - c) = f(2x) - x, \quad\text{i.e.,}\quad f(2x) = f(x-c) + x. \tag{1}$$

**Setting $x = 0$** in (P): $f(-f(-y)) = f(y)$ for all $y$. $\tag{2}$

**Setting $x = u$** in ($\ast$): $f(u - f(u)) = f(u) - u$. $\tag{3}$

### Step 2: If $f(a)=f(b)$, then $f$ is periodic with period $a-b$

Suppose $f(a) = f(b)$. From ($\ast$), for every $x$:
$$f(x - f(a)) = f(2x - a) - x, \qquad f(x - f(b)) = f(2x - b) - x.$$
Since $f(a) = f(b)$, the left sides are equal, so $f(2x - a) = f(2x - b)$ for al
l $x$. Setting $t = 2x$ and then $s = t - a$:
$$f(s) = f(s + (a - b)) \quad \text{for all } s \in \mathbb{R}. \tag{4}$$
Thus $f$ is periodic with period $p := a - b$.

### Step 3: $f$ has no nonzero period, hence is injective

Suppose $f$ has a period $p \neq 0$. From (1), replacing $x$ by $x + p/2$:
$$f(2x + p) = f\!\left(x + \tfrac{p}{2} - c\right) + x + \tfrac{p}{2}.$$
Using periodicity $f(2x+p) = f(2x)$ on the left, and comparing with (1) $f(2x) =
 f(x-c) + x$:
$$f(x - c) + x = f\!\left(x + \tfrac{p}{2} - c\right) + x + \tfrac{p}{2}.$$
Setting $s = x - c$:
$$f(s) = f\!\left(s + \tfrac{p}{2}\right) + \tfrac{p}{2} \quad \text{for all } s
. \tag{5}$$
Now apply (5) with $s$ replaced by $s + p/2$:
$$f\!\left(s + \tfrac{p}{2}\right) = f(s + p) + \tfrac{p}{2} = f(s) + \tfrac{p}{
2},$$
using periodicity $f(s+p) = f(s)$. Substituting back into (5):
$$f(s) = \left(f(s) + \tfrac{p}{2}\right) + \tfrac{p}{2} = f(s) + p.$$
This gives $p = 0$, contradicting $p \neq 0$. Hence $f$ has no nonzero period.

By Step 2, $f(a) = f(b) \Rightarrow a - b = 0$, so **$f$ is injective**.

### Step 4: Determine $f$

From (2): $f(-f(-y)) = f(y)$ for all $y$. By injectivity:
$$-f(-y) = y \quad \text{for all } y,$$
i.e., $f(-y) = -y$ for all $y$. As $y$ ranges over $\mathbb{R}$, so does $-y$; t
herefore
$$f(t) = t \quad \text{for all } t \in \mathbb{R}.$$

### Step 5: Verification

For $f(x) = x$:
- LHS: $f(x - f(x-y)) + x = (x - (x - y)) + x = y + x = x + y$.
- RHS: $f(x+y) = x + y$.

LHS $=$ RHS for all $x, y$. ✓
