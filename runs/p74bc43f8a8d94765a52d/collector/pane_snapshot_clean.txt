## Proof

**Reduction to the unit disk.** Set $w = z - 2$ and $g(w) = f(w+2)$. Then $G = \
{|z-2|<1\}$ maps to the unit disk $D = \{|w|<1\}$, and $g$ is meromorphic in a n
eighborhood of $\overline{D}$ with exactly one simple pole at $w_0 = z_0 - 2 \in
 D$. The boundary condition becomes $|g(w)| = 1$ for all $|w| = 1$. The claim re
duces to: for every $a$ with $|a|>1$, the equation $g(w) = a$ has exactly one so
lution in $D$.

**Applying the argument principle.** Fix $a$ with $|a| > 1$ and set $h(w) = g(w)
 - a$. Then $h$ is meromorphic in a neighborhood of $\overline{D}$ with exactly
one simple pole (at $w_0$, inherited from $g$) and no poles on $\partial D$. On
$\partial D$ we have $|g(w)| = 1$ while $|a| > 1$, so $h(w) = g(w) - a \neq 0$ o
n $\partial D$. Thus the argument principle applies:

$$\frac{1}{2\pi i}\oint_{\partial D} \frac{h'(w)}{h(w)}\,dw \;=\; N_a - P,$$

where $N_a$ is the number of zeros of $h$ in $D$ (counting multiplicity) and $P$
 is the number of poles of $h$ in $D$ (counting multiplicity). Since $h'(w) = g'
(w)$ and $h(w) = g(w)-a$, the left-hand side is

$$\frac{1}{2\pi i}\oint_{\partial D} \frac{g'(w)}{g(w)-a}\,dw,$$

which equals the winding number of the image curve $g(\partial D)$ around the po
int $a$.

**The winding number is zero.** The curve $g(\partial D)$ is contained in the un
it circle $\{|\zeta|=1\}$, since $|g(w)|=1$ on $\partial D$. Because $|a| > 1$,
the function $\frac{1}{\zeta - a}$ is holomorphic on the closed unit disk $\{|\z
eta| \leq 1\}$ (a simply connected domain not containing $a$). By Cauchy's theor
em, for any closed curve $\gamma$ in $\{|\zeta| \leq 1\}$:

$$\oint_\gamma \frac{d\zeta}{\zeta - a} = 0.$$

Applying this to $\gamma = g(\partial D)$ (via the substitution $\zeta = g(w)$,
$d\zeta = g'(w)\,dw$):

$$\frac{1}{2\pi i}\oint_{\partial D} \frac{g'(w)}{g(w)-a}\,dw = \frac{1}{2\pi i}
\oint_{g(\partial D)} \frac{d\zeta}{\zeta - a} = 0.$$

**Conclusion.** The argument principle gives $N_a - P = 0$. Since $g$ has exactl
y one simple pole in $D$, we have $P = 1$, and therefore $N_a = 1$. This means $
g(w) = a$ has exactly one solution in $D$ (counting multiplicity), hence exactly
 one point.

Translating back to the original variables: for every $a$ with $|a| > 1$, the se
t $f^{-1}(a) \cap G$ consists of exactly one point. $\blacksquare$
