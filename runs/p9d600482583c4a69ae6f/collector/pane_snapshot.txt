## Proof

**Yes**, such a function exists. We construct one explicitly using the Cantor fu
nction.

### Construction

Let $c:[0,1]\to[0,1]$ be the Cantor function (devil's staircase), and let $C\sub
seteq[0,1]$ be the Cantor set ($m(C)=0$). Define
$$h:[0,1]\to[0,2],\qquad h(x)=c(x)+x.$$

**Claim 1.** $h$ is a homeomorphism from $[0,1]$ onto $[0,2]$.

*Proof.* $h$ is continuous (sum of continuous functions) and strictly increasing
: for $x<y$,
$$h(y)-h(x)=\underbrace{(c(y)-c(x))}_{\ge 0}+\underbrace{(y-x)}_{>0}>0.$$
Since $h(0)=0$ and $h(1)=2$, by the intermediate value theorem $h$ maps $[0,1]$
bijectively onto $[0,2]$, and being continuous and strictly monotone on a compac
t interval, it is a homeomorphism. $\square$

**Claim 2.** $h(C)$ has Lebesgue measure $1$.

*Proof.* The complement $[0,1]\setminus C=\bigcup_{n} I_n$ is a countable union
of disjoint open intervals with $\sum_n |I_n|=1$. On each removed interval $I_n=
(a_n,b_n)$, the Cantor function $c$ is constant, say $c\equiv k_n$, so $h(x)=x+k
_n$ on $I_n$—a translation. Thus $h(I_n)=(a_n+k_n,\,b_n+k_n)$, an interval of le
ngth $|I_n|$. Since $h$ is injective, the images $h(I_n)$ are disjoint, so
$$m\bigl(h([0,1]\setminus C)\bigr)=\sum_n |I_n|=1.$$
Therefore $h(C)=[0,2]\setminus h([0,1]\setminus C)$ has measure $2-1=1$. $\squar
e$

Now set $f:=h^{-1}:[0,2]\to[0,1]$, so that $f^{-1}=h$.

### Verification

**Condition 1: $f^{-1}=h$ maps every Borel set to a Lebesgue measurable set.**

A homeomorphism maps Borel sets to Borel sets (the image of a Borel set under a
homeomorphism is Borel, since homeomorphisms preserve the Borel $\sigma$-algebra
). Hence for every Borel set $B\subseteq[0,1]$, $f^{-1}(B)=h(B)$ is Borel, and t
herefore Lebesgue measurable. $\checkmark$

**Condition 2: $f^{-1}=h$ does not map every Lebesgue measurable set to a Lebesg
ue measurable set.**

Since $D:=h(C)$ has measure $1>0$, it contains a non–Lebesgue-measurable subset
$V\subseteq D$. (Any set of positive outer measure contains a non-measurable sub
set: restricting the classical Vitali equivalence relation $x\sim y\iff x-y\in\m
athbb{Q}$ to $D$ and choosing one representative per class via the Axiom of Choi
ce yields such a $V$; the standard countable-additivity argument shows $V$ canno
t be measurable.)

Set $M:=h^{-1}(V)\subseteq C$. Since $m(C)=0$, **every** subset of $C$ is Lebesg
ue measurable, so $M$ is Lebesgue measurable. However,
$$f^{-1}(M)=h(M)=h\bigl(h^{-1}(V)\bigr)=V,$$
which is **not** Lebesgue measurable. $\checkmark$

### Conclusion

The function $f=h^{-1}:[0,2]\to[0,1]$, where $h(x)=c(x)+x$ and $c$ is the Cantor
 function, is a bijection whose inverse $f^{-1}=h$ maps every Borel set to a (Bo
rel, hence) measurable set, yet maps the measurable set $M=h^{-1}(V)\subseteq C$
 to the non-measurable set $V\subseteq h(C)$.

Therefore, **yes**, such a function exists. $\blacksquare$
