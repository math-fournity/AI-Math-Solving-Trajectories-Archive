## Solution

The answer is: **all integers $M$ except $M = 3$**.

### Analysis of $f$

For even $n = 2m$: $f(n) = 2m \cdot m = 2m^2$, which is even.

For odd $n = 2m+1$: $f(n) = (2m+1) \cdot m = m(2m+1)$. This is even iff $m$ is e
ven, i.e., $n \equiv 1 \pmod{4}$.

### Case 1: $M$ even

$f(M) = 2m^2$ is even. Done ($k=1$). ✓

### Case 2: $M$ positive odd

**Subcase 2a: $M \equiv 1 \pmod{4}$.** Then $\frac{M-1}{2}$ is even, so $f(M)$ i
s even. ✓

**Subcase 2b: $M \equiv 3 \pmod{4}$.** Here $\frac{M-1}{2}$ is odd, so $f(M)$ is
 odd. Note $f(3) = 1 \cdot 3 = 3$, so **$M = 3$ is a fixed point** — $f^k(3) = 3
$ for all $k$, never even. ✗

For $M \equiv 3 \pmod{4}$, $M \geq 5$: since $\frac{M-1}{2} \geq 2$, we have $f(
M) \geq 2M > M$, so the sequence is strictly increasing while it remains odd.

**Key Lemma.** *For odd $n \equiv 3 \pmod{4}$ with $n \neq 3$, setting $j = v_2(
n-3) \geq 2$, the value $f(n)$ is odd and $v_2(f(n)-3) = j - 1$.*

*Proof.* Since $n \equiv 3 \pmod{4}$, $\frac{n-1}{2}$ is odd, so $f(n) = \frac{n
-1}{2}\cdot n$ is odd. Compute:
$$f(n) - 3 = \frac{n-1}{2}\cdot n - 3 = \frac{n^2 - n - 6}{2} = \frac{(n-3)(n+2)
}{2}.$$
Since $n$ is odd, $n+2$ is odd, so $v_2(f(n)-3) = v_2(n-3) + v_2(n+2) - 1 = v_2(
n-3) - 1 = j-1$. $\square$

**Applying the Lemma.** Define $n_0 = M$, $n_{i+1} = f(n_i)$ while $n_i \equiv 3
 \pmod{4}$. By the Lemma, $v_2(n_i - 3) = j - i$ as long as $n_i \equiv 3 \pmod{
4}$.

At $i = j-1$: $v_2(n_{j-1}-3) = 1$, meaning $n_{j-1} - 3 \equiv 2 \pmod{4}$, so
$n_{j-1} \equiv 1 \pmod{4}$. Then $\frac{n_{j-1}-1}{2}$ is even, so $f(n_{j-1})$
 is **even**. ✓

Thus every positive odd $M \neq 3$ reaches an even value in finitely many steps.

### Case 3: $M$ negative odd

For $n \leq -1$ odd, $\lfloor n/2 \rfloor \leq -1$, so $f(n) = n \cdot \lfloor n
/2\rfloor \geq 1$ (product of two negatives).

- $M = -1$: $f(-1) = (-1)(-1) = 1$, then $f(1) = 0$, even. ✓
- $M \leq -3$ odd: $|M| \geq 3$ and $|\lfloor M/2\rfloor| \geq 2$, so $f(M) \geq
 6$. The value $f(M)$ is a positive integer. If even, done. If odd, by Case 2 it
 reaches even unless $f(M) = 3$ — but $f(M) \geq 6 > 3$, so this never happens.
✓

### Case 4: $M = 0$

$f(0) = 0$, which is even. ✓

### Conclusion

- $M = 3$: fixed point, $f^k(3) = 3$ (odd) for all $k$. **Fails.**
- All other integers: reach an even value in finitely many steps. **Succeed.**

$$\boxed{M \in \mathbb{Z} \setminus \{3\}}$$

The set of all integers $M$ such that $f^k(M)$ is even for some $k \in \mathbb{N
}$ is **all integers except $3$**.
