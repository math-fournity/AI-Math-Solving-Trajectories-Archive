## Proof

**Yes**, such a function exists.

### Construction

Let $\psi(t) = e^{-1/t}$ for $t > 0$ and $\psi(t) = 0$ for $t \le 0$. Define the
 standard smooth step:

$$h_0(u) = \begin{cases} 0 & u \le 0 \\ \dfrac{\psi(u)}{\psi(u)+\psi(1-u)} & 0 <
 u < 1 \\ 1 & u \ge 1 \end{cases}$$

This is $C^\infty$, non-decreasing, $0$ on $(-\infty,0]$, $1$ on $[1,\infty)$, w
ith all derivatives vanishing at $u=0$ and $u=1$. By the symmetry $h_0(u)+h_0(1-
u)=1$, we have $\int_0^1 h_0(u)\,du = \tfrac{1}{2}$.

Set $h := h_0^2$. Then $h$ is also a $C^\infty$ smooth step (all derivatives van
ish at the endpoints), and

$$C := \int_0^1 h(u)\,du = \int_0^1 h_0(u)^2\,du < \int_0^1 h_0(u)\,du = \tfrac{
1}{2},$$

since $0 \le h_0 < 1$ on a set of positive measure in $(0,1)$.

Define $a := \frac{1-2C}{1-C} > 0$ (positivity follows from $C < \frac{1}{2}$),
and set

$$g(x) = \begin{cases} h\!\left(\frac{2-|x|}{2-a}\right) & |x| \le 2, \\ 0 & |x|
 > 2. \end{cases}$$

**Properties of $g$:**

- **$C^\infty$:** On $[0,a]$, the argument $\frac{2-x}{2-a} \ge 1$ so $g=1$; on
$[a,2]$, $g = h\bigl(\frac{2-x}{2-a}\bigr)$ which transitions smoothly to $0$; a
t $x=2$, $h(0)=0$ with all derivatives $0$, so $g$ glues smoothly to $0$ outside
 $[-2,2]$. Evenness preserves smoothness at $x=0$.
- **Non-negative:** $0 \le h \le 1$, so $0 \le g \le 1$.
- **$g=1$ on $[-a,a]$:** For $|x|\le a$, $\frac{2-|x|}{2-a} \ge \frac{2-a}{2-a}=
1$, so $h=1$.
- **$g=0$ on $(-\infty,-2]\cup[2,\infty)$:** Clear from construction.

**Integral computation:** By evenness, $\int_{-2}^{0} g = \int_0^2 g$. On $[0,2]
$:

$$\int_0^2 g(x)\,dx = \int_0^a 1\,dx + \int_a^2 h\!\left(\tfrac{2-x}{2-a}\right)
dx = a + (2-a)\int_0^1 h(u)\,du = a + (2-a)C.$$

Substituting $a = \frac{1-2C}{1-C}$:

$$a + (2-a)C = \frac{1-2C}{1-C} + \left(2 - \frac{1-2C}{1-C}\right)C = \frac{1-2
C}{1-C} + \frac{2(1-C)-(1-2C)}{1-C}\,C = \frac{1-2C + C}{1-C} = \frac{1-C}{1-C}
= 1.$$

So $\int_0^2 g = 1$ and $\int_{-2}^{0} g = 1$, giving $\int_{-2}^{2} g = 2$.

### Definition of $f$

Set

$$f(x) := -1 + \int_{-\infty}^{x} g(t)\,dt.$$

**Verification of all conditions:**

1. **$C^\infty$:** $g$ is $C^\infty$, so $f$ is $C^\infty$ with $f' = g$.

2. **Monotonically non-decreasing:** $f'(x) = g(x) \ge 0$ for all $x$.

3. **$f((-\infty,-2]) = \{-1\}$:** For $x \le -2$, $g=0$ on $(-\infty, x]$, so $
f(x) = -1$.

4. **$f([2,\infty)) = \{1\}$:** $f(2) = -1 + \int_{-2}^{2} g = -1 + 2 = 1$, and
$g=0$ on $[2,\infty)$, so $f\equiv 1$ there.

5. **$f(x) = x$ near $0$:** We have $f(0) = -1 + \int_{-2}^{0} g = -1 + 1 = 0$,
and $g \equiv 1$ on $[-a,a]$, so for $x \in [-a,a]$:
$$f(x) = f(0) + \int_0^x g(t)\,dt = 0 + x = x.$$

All conditions are satisfied. $\blacksquare$
