问题

计算 $\mathbb{CP}^2$ 中亏格 0、度 1 曲线的 Gromov-Witten 不变量 $\langle p, p,
\ell\rangle_{0,1}$，其中 $p$ 是点的 Poincaré 对偶类（余维 2），$\ell$ 是直线的
Poincaré 对偶类（余维 1）。

答案泄漏检查

题目文本仅陈述问题，不含任何解答、证明梗概或形式化提示。无泄漏。

维数核算

亏格 0、度 $d$、$n$ 个标记点的稳定映射模空间 $\overline{M}_{0,n}(\mathbb{CP}^2,
d)$ 的预期维数为

$$\dim^{\mathrm{vir}} = (\dim X - 3)(1-g) + c_1(T_{\mathbb{CP}^2})\cdot d + n =
(2-3)\cdot 1 + 3d + n = -1 + 3d + n.$$

代入 $d=1,\ n=3$：

$$\dim^{\mathrm{vir}} = -1 + 3 + 3 = 5.$$

三个插入类的余维之和：

$$\mathrm{codim}(p) + \mathrm{codim}(p) + \mathrm{codim}(\ell) = 2 + 2 + 1 = 5.$
$

余维之和等于预期维数，不变量有定义且可能非零。

模空间的几何描述

$\overline{M}{0,3}(\mathbb{CP}^2, 1)$ 参数化亏格 0、度 1、3 标记点的稳定映射。度
1 映射 $f:\mathbb{P}^1\to\mathbb{CP}^2$ 是到一条直线的同构嵌入。由于 3 个标记点
固定了 $\mathbb{P}^1$ 的参数化（$\overline{M}{0,3} = \mathrm{pt}$，无自同构），
模空间同构于

$${\text{直线 } L\subset\mathbb{CP}^2}\times{\text{L 上 3 个有序点}}.$$

直线空间 $(\mathbb{CP}^2)^*\cong\mathbb{CP}^2$ 维数 2；3 个有序点取值于
$L\cong\mathbb{P}^1$ 的开子集，维数 3。总维数 $2+3=5$，与预期维数一致。模空间光
滑、无障碍，故虚拟基本类等于基本类。

直接计数

取两个一般点 $P_1, P_2\in\mathbb{CP}^2$ 和一条一般直线 $M\subset\mathbb{CP}^2$。
不变量计数满足以下条件的稳定映射：

  • $\mathrm{ev}_1(f) = P_1$，即第一个标记点映到 $P_1$；
  • $\mathrm{ev}_2(f) = P_2$，即第二个标记点映到 $P_2$；
  • $\mathrm{ev}_3(f) \in M$，即第三个标记点映到 $M$ 上。

第一步：确定直线。 像 $L = f(\mathbb{P}^1)$ 必须同时经过 $P_1$ 和 $P_2$。$
\mathbb{CP}^2$ 中过两个不同点的直线唯一，记为 $L_0$。

第二步：确定第三个标记点。 第三个标记点必须映到 $L_0\cap M$。$\mathbb{CP}^2$ 中
任意两条直线必相交于恰好一点（一般位置下 $L_0\neq M$），故 $L_0\cap M = {Q}$ 为
单点。第三个标记点必须映到 $Q$。

第三步：确定参数化。 直线 $L_0$ 和三个像点 $P_1, P_2, Q$ 唯一确定了从
$(\mathbb{P}^1, x_1, x_2, x_3)$ 到 $(L_0, P_1, P_2, Q)$ 的同构（3 个标记点固定 $
\mathrm{PGL}(2)$ 作用），故稳定映射唯一。

横截性： 对一般的 $P_1, P_2, M$，上述交截在模空间中横截，计数的重数为 1。

因此

$$\langle p, p, \ell\rangle_{0,1} = 1.$$

用量子上同调交叉验证

$\mathbb{CP}^2$ 的亏格 0 量子上同调环为

$$\mathbb{Z}[\ell, q]/(\ell^3 - q),\qquad \deg q = 3.$$

由 $\ell^3 = q$，展开 $\ell * \ell * \ell$。由于 $\ell * \ell = p$（度 1 量子修
正因余维不足而为零），有

$$\ell * p = \sum_{c}\langle \ell, p, c\rangle_{0,1}, q, c^\vee.$$

按维数筛选：$\langle\ell,p,1\rangle_{0,1}$（余维 $1+2+0=3<5$，为零）、$
\langle\ell,p,\ell\rangle_{0,1}$（余维 $1+2+1=4<5$，为零）、$
\langle\ell,p,p\rangle_{0,1}$（余维 $1+2+2=5$，非零）。

故

$$\ell * p = \langle\ell, p, p\rangle_{0,1}, q, p.$$

而 $\ell^3 = q$ 的 $q,p$ 项系数为 1，因此

$$\langle\ell, p, p\rangle_{0,1} = 1.$$

$$\boxed{\langle p, p, \ell\rangle_{0,1} = 1}$$
