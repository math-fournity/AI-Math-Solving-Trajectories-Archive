# Problem

A specialized supercomputer is tasked with processing a linear data sequence consisting of exactly $2020$ identical units of energy, each valued at $3$ terajoules. Between each adjacent pair of energy units, the system must install a "Logic Gate." There are $2019$ such gates in total.

For every individual gate, the computer's motherboard randomly and uniformly selects one of four possible operations—Addition, Subtraction, Multiplication, or Division—to process the energy values. Each gate is chosen independently.

The final output of the sequence is the result of these operations performed strictly from left to right. Let $E$ represent the expected value of the final energy output. If $E$ is expressed as a reduced fraction $\frac{m}{n}$, determine the remainder when $m+n$ is divided by $2017$.
