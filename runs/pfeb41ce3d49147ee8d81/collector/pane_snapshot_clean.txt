## Proof

**Claim.** The largest $k$ is $\left\lceil \dfrac{n}{2}\right\rceil = \left\lflo
or \dfrac{n+1}{2}\right\rfloor$.

---

### Upper bound

Let $S = 1 + 2 + \cdots + n = \dfrac{n(n+1)}{2}$. If the numbers are split into
$k$ boxes with equal sum, then $k \mid S$, and each box has sum $S/k$.

The largest number $n$ must be placed in some box. Since every box contains only
 positive integers, that box's sum satisfies $S/k \geq n$, giving

$$k \le \frac{S}{n} = \frac{n+1}{2}.$$

Since $k$ is a positive integer:

- If $n$ is odd, $(n+1)/2$ is an integer, so $k \le (n+1)/2 = \lceil n/2 \rceil$
.
- If $n$ is even, $(n+1)/2$ is not an integer, so $k \le \lfloor (n+1)/2 \rfloor
 = n/2 = \lceil n/2 \rceil$.

In both cases, $k \le \left\lceil \dfrac{n}{2}\right\rceil$.

---

### Construction achieving the bound

**Case 1: $n = 2m$ (even).** Set $k = m = n/2 = \lceil n/2 \rceil$. Pair the num
bers as

$$\{1,\, n\},\ \{2,\, n-1\},\ \dots,\ \{m,\, m+1\}.$$

Each pair $\{i,\, n+1-i\}$ sums to $n+1$, and $S/k = m(2m+1)/m = 2m+1 = n+1$. ✓

**Case 2: $n = 2m+1$ (odd).** Set $k = m+1 = \lceil n/2 \rceil$. Place $n = 2m+1
$ alone in one box, and pair the remaining numbers $1, 2, \dots, 2m$ as

$$\{1,\, 2m\},\ \{2,\, 2m-1\},\ \dots,\ \{m,\, m+1\}.$$

Each pair $\{i,\, 2m+1-i\}$ sums to $2m+1 = n$, and the singleton $\{n\}$ also s
ums to $n$. The common sum is $S/k = (2m+1)(m+1)/(m+1) = 2m+1 = n$. ✓

---

### Conclusion

The upper bound $k \le \lceil n/2 \rceil$ and the matching construction show tha
t the largest $k$ is

$$\boxed{\left\lceil \dfrac{n}{2}\right\rceil}.$$
