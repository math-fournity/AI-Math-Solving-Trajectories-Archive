## Proof

**Notation.** For a polynomial f and modulus n, let R_n(f) = {x mod n : f(x) ≡ 0
 (mod n)}. We say n has property P if for every subset T ⊆ ℤ/nℤ, there exists an
 integer polynomial f with R_n(f) = T.

### Step 1: Primes satisfy P

If n = p is prime, then ℤ/pℤ is a field. For any subset T = {a₁,…,a_k}, the poly
nomial f(x) = ∏(x − a_i) has degree k, and over a field a degree-k polynomial ha
s at most k roots. Since each a_i is a root, R_p(f) = T exactly.

### Step 2: n = 4 satisfies P

For any T ⊆ {0,1,2,3}, set f(x) = ∏_{a∈T}(x − a). Clearly every a ∈ T is a root.
 For b ∉ T, each factor (b − a) ∈ {1,2,3} mod 4. A factor equals 2 mod 4 iff a ≡
 b−2 mod 4; since the a's are distinct elements of {0,1,2,3}, **at most one** fa
ctor is ≡ 2 mod 4. All other factors are odd. So the product is either odd or ≡
2·(odd) ≡ 2 mod 4 — in either case ≢ 0 mod 4. Hence R₄(f) = T. ✓

### Step 3: n with ≥ 2 distinct prime factors fail P

Let n = ab with gcd(a,b)=1, a,b ≥ 2. By CRT, ℤ/nℤ ≅ ℤ/aℤ × ℤ/bℤ, and for any pol
ynomial f, R_n(f) = R_a(f) × R_b(f) (a product). Consider T = {0, 1}, which in C
RT coordinates is {(0,0), (1,1)}. If this were a product R_a × R_b, then |R_a|·|
R_b| = 2, so one factor has size 1 and the other size 2. If |R_a| = 1, say R_a =
 {α}, then R_a × R_b = {(α,·),(α,·)} requires α = 0 and α = 1 simultaneously — c
ontradiction. So {0,1} is not a product, hence not realizable. ✗

This eliminates: 6, 10, 12, 14, 15, 18, 20.

### Step 4: n = p² for odd prime p fails P

Consider T = {0, p} mod p². Suppose f(0) ≡ 0 and f(p) ≡ 0 (mod p²). Define g(y)
= f(py) mod p². Then:

g(y) = c₀ + c₁py + c₂p²y² + … ≡ c₀ + c₁py (mod p²)

- g(0) = c₀ ≡ 0 (mod p²)
- g(1) = c₀ + c₁p ≡ 0 (mod p²), so c₁p ≡ 0 (mod p²), hence c₁ ≡ 0 (mod p).

Then g(2) = c₁·2p ≡ 0 (mod p²) since c₁ = pm gives g(2) = 2mp² ≡ 0. So f(2p) ≡ 0
 (mod p²). Since p ≥ 3, 2p ≢ 0, p (mod p²), so 2p is an extra root. Thus {0,p} i
s not realizable. ✗

This eliminates n = 9.

From g(1) ≡ 0 (mod 2ᵉ): 2c₁ + 4c₂ + 8c₃ + … ≡ 0 (mod 2ᵉ), which gives 2c₁ ≡ 0 (m

The corresponding residue is 2·2ᵉ⁻² = 2ᵉ⁻¹, and for e ≥ 3, 2ᵉ⁻¹ ≥ 4 ∉ {0, 2}. So
