We need positive integers $a < 100$ such that $6 \mid (4a^2 + 3a + 5)$.

Since $6 = 2 \times 3$, we require divisibility by both $2$ and $3$.

**Modulo 2:**
$$4a^2 + 3a + 5 \equiv 0 + a + 1 \equiv a + 1 \pmod{2}$$
So $a + 1 \equiv 0 \pmod{2}$, i.e., $a$ must be **odd**.

**Modulo 3:**
$$4a^2 + 3a + 5 \equiv a^2 + 0 + 2 \equiv a^2 + 2 \pmod{3}$$
So $a^2 + 2 \equiv 0 \pmod{3}$, i.e., $a^2 \equiv 1 \pmod{3}$. This holds iff $a
 \not\equiv 0 \pmod{3}$, i.e., $a \equiv 1$ or $2 \pmod{3}$.

**Combining via CRT (mod 6):** The odd residues mod 6 are $1, 3, 5$. Among these
, $3 \equiv 0 \pmod{3}$ is excluded. So $a \equiv 1$ or $5 \pmod{6}$.

**Counting in $\{1, 2, \ldots, 99\}$:**

- $a \equiv 1 \pmod{6}$: $1, 7, 13, \ldots, 97$. Count $= \frac{97-1}{6}+1 = 17$
.
- $a \equiv 5 \pmod{6}$: $5, 11, 17, \ldots, 95$. Count $= \frac{95-5}{6}+1 = 16
$.

**Total** $= 17 + 16 = 33$.

**Verification:** $a=1$: $4+3+5=12=6\times2$ ✓. $a=5$: $100+15+5=120=6\times20$
✓. $a=7$: $196+21+5=222=6\times37$ ✓. $a=3$ (excluded): $36+9+5=50$, not divisib
le by 6 ✓.

The number of positive integers $a < 100$ such that $4a^2+3a+5$ is divisible by
$6$ is $\boxed{33}$.
