## Solution

We solve the first-order nonlinear PDE

$$u_x^2\, u_t - 1 = 0, \qquad u(x,0) = x,$$

using the method of characteristics for a fully nonlinear equation $F(x,t,u,p,q)
=0$ with $p=u_x$, $q=u_t$.

**Step 1. Set up the characteristic system.**

Here $F(x,t,u,p,q) = p^2 q - 1$. The characteristic ODEs are

$$\dot x = F_p = 2pq, \qquad \dot t = F_q = p^2, \qquad \dot u = pF_p + qF_q = 2
p^2q + p^2q = 3p^2q,$$
$$\dot p = -F_x - pF_u = 0, \qquad \dot q = -F_t - qF_u = 0.$$

Since $F=0$ gives $p^2 q = 1$ along every characteristic, we may replace $p^2 q$
 by $1$:

$$\dot x = 2pq = \frac{2}{p}, \qquad \dot t = p^2, \qquad \dot u = 3, \qquad \do
t p = 0, \qquad \dot q = 0.$$

Thus $p$ and $q$ are **constant** along each characteristic, and consequently $\
dot x,\dot t,\dot u$ are all constant: every characteristic is a straight line i
n $(x,t,u)$-space.

**Step 2. Impose the initial data.**

Parametrize the initial curve at $t=0$ by $x_0$: $(x,t,u)\big|_{s=0} = (x_0, 0,
x_0)$. From $u(x,0)=x$ we get the initial slope $p_0 = u_x(x,0) = 1$. The PDE co
nstraint $p_0^2 q_0 = 1$ then forces $q_0 = 1$.

So along the characteristic issuing from $(x_0,0)$:

$$p \equiv 1, \qquad q \equiv 1, \qquad \dot x = 2, \qquad \dot t = 1, \qquad \d
ot u = 3.$$

Integrating with the initial conditions:

$$x = x_0 + 2s, \qquad t = s, \qquad u = x_0 + 3s.$$

**Step 3. Eliminate the parameters.**

From $t = s$ and $x = x_0 + 2s$ we get $x_0 = x - 2t$. Substituting into $u$:

$$u(x,t) = (x - 2t) + 3t = x + t.$$

**Step 4. Verify.**

With $u(x,t) = x + t$:
- $u_x = 1$, $u_t = 1$, so $u_x^2 u_t - 1 = 1\cdot 1 - 1 = 0$. ✓
- $u(x,0) = x$. ✓

**Step 5. Uniqueness.**

The characteristics are the parallel lines $x - 2t = x_0$ (constant slope $dx/dt
 = 2$). They never intersect, so through every point $(x,t)$ with $t\ge 0$ there
 passes exactly one characteristic, carrying a unique value of $u$. Hence the so
lution is uniquely determined on the entire half-plane $t\ge 0$.

$$\boxed{u(x,t) = x + t}$$
