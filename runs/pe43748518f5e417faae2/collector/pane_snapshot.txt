**Problem.** Let $p, q$ be Hilbert space projections ($p=p^2=p^*$, $q=q^2=q^*$).
 Can $r := pq+qp$ be a non-zero projection?

**Answer: No.** Whenever $pq+qp$ is a projection, it must be $0$.

---

**Proof.** Suppose $r = pq+qp$ is a projection, so $r = r^2 = r^*$. (Self-adjoin
tness $r^*=r$ is automatic.) Set
$$a := pqp, \qquad b := qpq,$$
both positive operators since $a = (pq)(pq)^* \ge 0$ and $b = (qp)(qp)^* \ge 0$.

**Step 1. A quadratic relation for $a$ (and $b$).** Compute
$$pr = p(pq+qp) = pq + pqp = pq + a, \quad rp = (pq+qp)p = pqp + qp = a + qp.$$
Hence
$$pr^2p = (pr)(rp) = (pq+a)(a+qp).$$
Expanding and using $p^2=p$, $q^2=q$:
- $pq\cdot a = pqpqp = a^2$,
- $pq\cdot qp = pqp = a$,
- $a\cdot a = a^2$,
- $a\cdot qp = pqpqp = a^2$,

so $pr^2p = 3a^2 + a$. On the other hand $r^2=r$ gives $pr^2p = prp = 2a$. There
fore
$$3a^2 = a. \tag{1}$$
By symmetry ($p\leftrightarrow q$), $3b^2 = b$.

**Step 2. Relating $(pq)^2$ to $a$.** From $r^2=r$, i.e.
$$(pq)^2 + a + b + (qp)^2 = pq + qp, \tag{$*$}$$
compress by $p$ on the left and $p^\perp = I-p$ on the right. Using $pa=a=ap$ an
d $a^2=a/3$:
- $p(pq)^2p^\perp = (pq)^2 - a^2$,
- $p\,a\,p^\perp = 0$,
- $p\,b\,p^\perp = p\,qpq\,p^\perp = (pq)^2 - a^2$,
- $p(qp)^2p^\perp = a^2 p^\perp = 0$,
- $p\,pq\,p^\perp = pq - a$,
- $p\,qp\,p^\perp = 0$.

Thus $2\bigl((pq)^2 - a^2\bigr) = pq - a$, i.e. (using $a^2=a/3$)
$$2(pq)^2 = pq - \tfrac{a}{3}. \tag{2}$$
Symmetrically, $2(qp)^2 = qp - \tfrac{b}{3}$.

**Step 3. Expressing $r$ in terms of $a+b$.** Substituting (2) and its symmetric
 form into ($*$):
$$\tfrac{1}{2}(pq - \tfrac{a}{3}) + a + b + \tfrac{1}{2}(qp - \tfrac{b}{3}) = pq
 + qp,$$
$$\tfrac{1}{2}(pq+qp) + \tfrac{5}{6}(a+b) = pq+qp,$$
giving
$$pq + qp = \tfrac{5}{3}(a+b), \quad\text{i.e.}\quad r = \tfrac{5}{3}(a+b). \tag
{3}$$

**Step 4. A second relation from $r^2=r$.** Using $r=\frac{5}{3}(a+b)$ and (1):
$$r^2 = \tfrac{25}{9}(a+b)^2 = \tfrac{25}{9}\bigl(\tfrac{a}{3} + ab + ba + \tfra
c{b}{3}\bigr).$$
Setting $r^2 = r = \frac{5}{3}(a+b)$ and simplifying:
$$ab + ba = \tfrac{4}{15}(a+b). \tag{4}$$

**Step 5. Computing $ab+ba$ directly.** Note $ab = (pqp)(qpq) = (pq)^3$ and $ba
= (qp)^3$. From (2), $(pq)^2 = \frac{1}{2}(pq - a/3)$, and $pq\cdot a = a^2 = a/
3$, so
$$(pq)^3 = (pq)(pq)^2 = \tfrac{1}{2}\bigl((pq)^2 - \tfrac{1}{3}pq\,a\bigr) = \tf
rac{1}{2}\bigl(\tfrac{pq}{2} - \tfrac{a}{6} - \tfrac{a}{9}\bigr) = \tfrac{pq}{4}
 - \tfrac{5a}{36}.$$
Symmetrically $(qp)^3 = \frac{qp}{4} - \frac{5b}{36}$. Therefore, using (3):
$$ab + ba = \tfrac{pq+qp}{4} - \tfrac{5(a+b)}{36} = \tfrac{5(a+b)}{12} - \tfrac{
5(a+b)}{36} = \tfrac{5(a+b)}{18}. \tag{5}$$

**Step 6. Conclusion.** Combining (4) and (5):
$$\tfrac{5}{18}(a+b) = \tfrac{4}{15}(a+b) \implies (a+b)\Bigl(\tfrac{5}{18}-\tfr
ac{4}{15}\Bigr) = 0.$$
Since $\frac{5}{18}-\frac{4}{15} = \frac{75-72}{270} = \frac{1}{90} \neq 0$, we
get
$$a + b = 0.$$
But $a = pqp \ge 0$ and $b = qpq \ge 0$, so $a+b=0$ forces $a = b = 0$. Finally
$$a = (pq)(pq)^* = 0 \implies pq = 0, \qquad b = (qp)(qp)^* = 0 \implies qp = 0.
$$
Hence $r = pq + qp = 0$.

Therefore $pq+qp$ can never be a **non-zero** Hilbert space projection. $\blacks
quare$
