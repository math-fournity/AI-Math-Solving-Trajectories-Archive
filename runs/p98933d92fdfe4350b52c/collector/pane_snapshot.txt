## Proof of the Variant (`bdd_power`)

**Theorem.** *There exists $O > 0$ such that $\frac{3^n}{n^O} = O(g_3(n))$ as $n
 \to \infty$. In fact, $O = 1$ works: $g_3(n) \geq \frac{3^n - 1}{2n}$ for all $
n \geq 1$.*

**Proof.** Let $A = \{a_1, \ldots, a_n\} \subseteq \{1, \ldots, N\}$ with $|A| =
 n$, and suppose $\langle A \rangle = \bigl\{\sum_{a \in A} \epsilon_a\, a : \ep
silon_a \in \{0,1\}\bigr\}$ contains no non-trivial 3-term arithmetic progressio
n.

### Step 1: All $3^n$ signed sums are distinct

Consider the $3^n$ **signed sums** $\Sigma(\sigma) := \sum_{i=1}^n \sigma_i a_i$
 where $\sigma_i \in \{-1, 0, 1\}$.

**Claim:** All these signed sums are pairwise distinct.

Suppose for contradiction that $\Sigma(\sigma) = \Sigma(\sigma')$ with $\sigma \
neq \sigma'$. Set $c_i = \sigma_i - \sigma_i' \in \{-2, -1, 0, 1, 2\}$, not all
zero. Then:
$$\sum_{i=1}^n c_i\, a_i = 0. \tag{$\star$}$$

We construct a non-trivial 3-AP in $\langle A \rangle$ from $(\star)$. For each
$i$, choose $(\epsilon_i, \epsilon_i', \epsilon_i'') \in \{0,1\}^3$ satisfying $
\epsilon_i + \epsilon_i'' - 2\epsilon_i' = c_i$:

| $c_i$ | $(\epsilon_i, \epsilon_i', \epsilon_i'')$ | $\epsilon_i \neq \epsilon_
i'$? |
|-------|------------------------------------------|----------------------------
---|
| $2$   | $(1, 0, 1)$                              | Yes
   |
| $1$   | $(1, 0, 0)$                              | Yes
   |
| $0$   | $(0, 0, 0)$                              | No
   |
| $-1$  | $(0, 1, 1)$                              | Yes
   |
| $-2$  | $(0, 1, 0)$                              | Yes
   |

Define $x = \sum \epsilon_i a_i$, $y = \sum \epsilon_i' a_i$, $z = \sum \epsilon
_i'' a_i$. Then $x, y, z \in \langle A \rangle$ and $x + z - 2y = \sum c_i a_i =
 0$, so $x + z = 2y$.

Since not all $c_i = 0$, there exists $i$ with $c_i \neq 0$, forcing $\epsilon_i
 \neq \epsilon_i'$, hence $\epsilon \neq \epsilon'$ as vectors.

**Case 1: $x \neq y$.** Then $x, y, z$ are three distinct elements (since $x+z=2
y$ and $x \neq y$ implies $z = 2y - x \neq y$ and $z \neq x$), forming a non-tri
vial 3-AP. Contradiction.

**Case 2: $x = y$.** Then $\sum (\epsilon_i - \epsilon_i') a_i = 0$ is a non-tri
vial $\{-1, 0, 1\}$-relation. Let $P = \{i : \epsilon_i - \epsilon_i' = 1\}$ and
 $Q = \{i : \epsilon_i - \epsilon_i' = -1\}$. Both $P$ and $Q$ are non-empty: if
 $P = \emptyset$ then $\sum_{i \in Q} a_i = 0$, impossible since $a_i \geq 1$; s
imilarly $Q \neq \emptyset$. Set $s = \sum_{i \in P} a_i = \sum_{i \in Q} a_i \g
eq 1$.

Now observe:
- $0 \in \langle A \rangle$ (the empty subset sum),
- $s = \sum_{i \in P} a_i \in \langle A \rangle$,
- $2s = \sum_{i \in P} a_i + \sum_{i \in Q} a_i = \sum_{i \in P \cup Q} a_i \in
\langle A \rangle$ (since $P \cap Q = \emptyset$).

Thus $0, s, 2s$ is a 3-AP in $\langle A \rangle$, non-trivial since $s \geq 1$.
Contradiction.

In both cases we contradict the 3-AP-freeness of $\langle A \rangle$. Therefore
all $3^n$ signed sums are distinct. $\square$

### Step 2: Counting argument

The signed sums $\Sigma(\sigma)$ are integers in the range $[-S, S]$ where $S =
\sum_{i=1}^n a_i$. Since $a_i \leq N$ for all $i$:
$$S \leq nN.$$

All $3^n$ signed sums are distinct integers in $\{-S, \ldots, S\}$, a set of siz
e $2S + 1 \leq 2nN + 1$. Therefore:
$$3^n \leq 2nN + 1.$$

### Step 3: Lower bound on $g_3(n)$

Solving for $N$:
$$N \geq \frac{3^n - 1}{2n}.$$

This holds for **every** $A \subseteq \{1, \ldots, N\}$ with $|A| = n$ whose sub
set sum set is 3-AP-free. Since $g_3(n)$ is the minimal such $N$:
$$g_3(n) \geq \frac{3^n - 1}{2n}.$$

For $n \geq 1$: since $3^{n-1} \geq 1$, we have $3^n - 1 \geq \frac{2}{3} \cdot
3^n$, so:
$$g_3(n) \geq \frac{3^n}{3n} \qquad \text{for all } n \geq 1.$$

Equivalently:
$$\frac{3^n}{n} \leq 3 \cdot g_3(n) \qquad \text{for all } n \geq 1.$$

This means $\displaystyle\left(\text{fun } n \mapsto \frac{3^n}{n^1}\right) = O[
\text{atTop}]\;(\text{fun } n \mapsto g\;3\;n)$ with implicit constant $3$.

Taking $O = 1$ (and any positive constant, say the leading constant is $3$), the
 theorem is proved. $\blacksquare$

## On the Main Conjecture (`erdos_817`)

The main conjecture asks whether the factor of $n$ can be removed, i.e., whether
 $g_3(n) \geq c \cdot 3^n$ for some constant $c > 0$.

The proof above gives $g_3(n) \geq \frac{3^n}{3n}$. The sole source of the $n$-l
oss is the bound $S = \sum a_i \leq nN$ on the range of signed sums. Removing th
is factor would require showing that the signed sums cannot spread over the full
 range $[-nN, nN]$ while remaining distinct — in other words, that the additive
structure of subset sums forces additional collisions (3-APs) beyond what the pi

This is the **open problem**. The Erdős–Sárközy result (the variant) achieves $3
^n / n^{O(1)}$ but the conjectured $3^n$ bound remains unproven. I cannot solve
