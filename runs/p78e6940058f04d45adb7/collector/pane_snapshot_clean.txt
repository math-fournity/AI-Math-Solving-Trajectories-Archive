## Proof

Let $f \colon \mathbb{N} \to \mathbb{N}$ be a (total) function such that for eve
ry recursively enumerable (r.e.) set $A \subseteq \mathbb{N}$, the preimage
$$f^{-1}(A) \;=\; \{\, n \in \mathbb{N} : f(n) \in A \,\}$$
is also r.e. We show that $f$ is computable.

**Key observation.** For every $k \in \mathbb{N}$, the singleton $\{k\}$ is recu
rsive, hence r.e. By the hypothesis, the fiber
$$f^{-1}(\{k\}) \;=\; \{\, n : f(n) = k \,\}$$
is r.e. Let $E_k$ be a fixed effective enumeration of $f^{-1}(\{k\})$.

**Computing $f$.** Given input $n$, dovetail the enumerations $E_0, E_1, E_2, \d
ots$ as follows. At stage $s = 0, 1, 2, \dots$, advance one step of each of $E_0
, E_1, \dots, E_s$. Whenever some $E_k$ emits the value $n$, halt and output $k$
.

**Correctness.** Since $f$ is total, $n$ belongs to exactly one fiber, namely $f
^{-1}(\{f(n)\})$. Hence $n$ eventually appears in the enumeration $E_{f(n)}$, at
 which point the algorithm halts and outputs $f(n)$. The algorithm always halts
and returns the correct value, so $f$ is computable.

**Remark (partial case).** If $f$ is allowed to be partial, the same dovetailing
 enumerates the graph $\{\,(n, f(n)) : f(n)\!\downarrow\,\}$: whenever $E_k$ emi
ts $n$, output the pair $(n, k)$. This shows the graph is r.e., so $f$ is partia
l computable. Moreover, taking $A = \mathbb{N}$ (which is r.e.) gives $\mathrm{d
om}(f) = f^{-1}(\mathbb{N})$ r.e., consistent with partial computability. If $f$
 is in fact total, the argument above yields total computability.

**Conclusion.** Yes — the condition "every preimage of an r.e. set is r.e." forc
es the function to be computable (total computable if total, partial computable
if partial).
