## Proof

Define the difference sequence $d_i = a_i - a_{i-1}$ for $i \ge 1$, so $d_1 = a_
1 - a_0$.

For each $i \ge 2$, the recurrence gives $a_i$ as one of $2a_{i-1} - a_{i-2}$ or
 $2a_{i-2} - a_{i-1}$. Computing $d_i = a_i - a_{i-1}$ in each case:

- **Choice 1:** $a_i = 2a_{i-1} - a_{i-2}$, so $d_i = a_i - a_{i-1} = a_{i-1} -
a_{i-2} = d_{i-1}$.
- **Choice 2:** $a_i = 2a_{i-2} - a_{i-1}$, so $d_i = a_i - a_{i-1} = 2a_{i-2} -
 2a_{i-1} = -2\,d_{i-1}$.

Thus for every $i \ge 2$:
$$d_i \in \{d_{i-1},\; -2\,d_{i-1}\}.$$

Applying this repeatedly from $d_1$ through $d_{2024}$, each step either leaves
the value unchanged or multiplies it by $-2$. Hence there exists a non-negative
integer $k$ (the number of times the "$-2$" option is chosen among the steps $i
= 2, 3, \dots, 2024$) such that
$$d_{2024} = (-2)^k \cdot d_1.$$

Taking absolute values:
$$|d_{2024}| = 2^k \cdot |d_1|.$$

Now $a_{2023}$ and $a_{2024}$ are consecutive integers, so
$$|d_{2024}| = |a_{2024} - a_{2023}| = 1.$$

Therefore
$$2^k \cdot |d_1| = 1.$$

Since $d_1 = a_1 - a_0$ is an integer, $|d_1|$ is a non-negative integer, and $2
^k$ is a positive integer ($k \ge 0$). The only way a product of a positive powe
r of $2$ and a non-negative integer equals $1$ is
$$k = 0 \quad\text{and}\quad |d_1| = 1.$$

In particular,
$$|a_1 - a_0| = |d_1| = 1,$$

which means $a_0$ and $a_1$ are consecutive integers. $\blacksquare$
