## Solution

**Answer:** The Hausdorff dimension of $F$ is $\dfrac{\log 2}{\log 3}$.

### Proof

**Setup.** For each integer $k \geq 1$, define
$$F_k = \{x \in [0,1] : x = 0.a_1 a_2 \ldots \text{ in base 3, with } a_i \neq 1
 \text{ for all } i \geq k\}.$$
Then $F = \bigcup_{k=1}^{\infty} F_k$.

**Step 1: $\dim_H(F_k) = \frac{\log 2}{\log 3}$ for every $k$.**

Fix $k$. The first $k-1$ digits $a_1, \ldots, a_{k-1}$ are free (each in $\{0,1,
2\}$), while every digit $a_i$ with $i \geq k$ is restricted to $\{0,2\}$. For e
ach fixed prefix $(a_1,\ldots,a_{k-1}) \in \{0,1,2\}^{k-1}$, the set of numbers
with that prefix and tail-digits in $\{0,2\}$ is a scaled copy of the standard m
iddle-thirds Cantor set $C$, lying inside an interval of length $3^{-(k-1)}$.

Recall that the Cantor set $C = \{x : a_i \in \{0,2\} \text{ for all } i\}$ has
Hausdorff dimension $\dim_H(C) = \frac{\log 2}{\log 3}$. Scaling by a factor $3^
{-(k-1)}$ does not change Hausdorff dimension. Since $F_k$ is the union of $3^{k
-1}$ such scaled copies (one per prefix), and Hausdorff dimension is stable unde
r finite unions,
$$\dim_H(F_k) = \dim_H(C) = \frac{\log 2}{\log 3}.$$

**Step 2: $\dim_H(F) = \frac{\log 2}{\log 3}$.**

Since $F = \bigcup_{k=1}^{\infty} F_k$ is a countable union, countable stability
 of Hausdorff dimension gives
$$\dim_H(F) = \sup_{k \geq 1} \dim_H(F_k) = \frac{\log 2}{\log 3}.$$

**Step 3: Verification that the bound is attained (not merely an upper bound).**

Each $F_k \subseteq F$, and $\dim_H(F_k) = \frac{\log 2}{\log 3}$, so $\dim_H(F)
 \geq \frac{\log 2}{\log 3}$. The countable-union property gives the matching up
per bound $\dim_H(F) \leq \sup_k \dim_H(F_k) = \frac{\log 2}{\log 3}$. Hence equ
ality holds.
