## Proof

$P(0,n)$: $f(f(n)) = f(f(0)) + f(n)$ for all $n$. Setting $c = f(0)$ and $a = f(
c) = f(f(0))$:
$$f(f(n)) = a + f(n) \quad \forall\, n. \tag{1}$$

$P(m,0)$: $f(m+c) = f(f(m)) + c = a + f(m) + c$ for all $m$, using (1). \tag{2}

The original equation becomes, using (1):
$$f(m + f(n)) = a + f(m) + f(n) \quad \forall\, m,n. \tag{3}$$

**Step 2: Determine $c$ and $a$.**

Set $m=0$ in (3): $f(f(n)) = a + f(0) + f(n) = a + c + f(n)$. Comparing with (1)

Then $a = f(f(0)) = f(0) = 0$, so (1) gives $\boxed{f(f(n)) = f(n)}$ (idempotenc
e) and (3) gives:
$$f(m + f(n)) = f(m) + f(n) \quad \forall\, m,n. \tag{4}$$

**Step 3: Structure of the image.**

Let $S = f(\mathbb{N}_0)$ be the image. From (4) with $m=0$: $f(f(n)) = f(n)$, c
onfirming idempotence, so $f(s) = s$ for all $s \in S$.

From (4): for every $s \in S$, $f(m+s) = f(m) + s$ for all $m$. In particular, $
S$ is closed under addition (if $s, t \in S$, then $f(s+t) = f(s)+t = s+t$, so $
s+t \in S$), and $0 \in S$.

**Case 1: $S = \{0\}$.** Then $f \equiv 0$, which satisfies the equation.

**Case 2: $S$ contains a positive element.** Let $d = \gcd(S) \geq 1$.

**Step 4: $g(m) := f(m) - m$ is periodic with period $d$.**

Define $g(m) = f(m) - m$. From $f(m+s) = f(m) + s$ for $s \in S$, we get $g(m+s)

eriod of $g$.

**Claim:** If $g$ has periods $a, b > 0$ (i.e., $g(m+a)=g(m)$ and $g(m+b)=g(m)$
for all $m \geq 0$), then $g$ has period $\gcd(a,b)$.

*Proof of claim:* WLOG $a > b$. For all $m \geq 0$: $g(m+a) = g(m)$, and $g(m+a)
 = g((m+a-b)+b) = g(m+a-b)$ (using period $b$, valid since $m+a-b \geq 0$). So $
g(m) = g(m+a-b)$, meaning $a - b$ is a period. Iterating via the Euclidean algor
ithm yields $\gcd(a,b)$ as a period. $\square$

Since $d = \gcd(S)$, there exist $s_1, \dots, s_k \in S$ with $\gcd(s_1, \dots,
s_k) = d$. By repeatedly applying the claim, $g$ has period $d$ on all of $\math
bb{N}_0$.

**Step 5: Determine $S$ and the form of $f$.**

Since $g$ has period $d$ and $g(0) = f(0) - 0 = 0$, we have $g(m) = 0$ for all $
m \equiv 0 \pmod{d}$, so $f(m) = m$ for all $m \in d\mathbb{N}_0$. Thus $d\mathb
b{N}_0 \subseteq S$.

Since $d \mid s$ for every $s \in S$ (as $d = \gcd(S)$), we have $S \subseteq d\
mathbb{N}_0$. Therefore $S = d\mathbb{N}_0$.

For each $r \in \{0, 1, \dots, d-1\}$, set $a_r = f(r)$. Since $f(r) \in S = d\m
athbb{N}_0$, each $a_r$ is a nonneg multiple of $d$, and $a_0 = f(0) = 0$. By pe
riodicity ($f(m+d) = f(m) + d$):
$$f(qd + r) = a_r + qd \quad \forall\, q \geq 0,\; 0 \leq r \leq d-1. \tag{5}$$

Writing $a_r = c_r \cdot d$ with $c_r \in \mathbb{N}_0$ and $c_0 = 0$:
$$f(qd + r) = (q + c_r)\,d.$$

**Step 6: Verification.**

For $f$ given by (5) with $a_0 = 0$ and each $a_r \in d\mathbb{N}_0$:

- $f(n) \in d\mathbb{N}_0$ for all $n$, so $f(n)$ is a multiple of $d$.
- $f(f(m))$: since $f(m) \in d\mathbb{N}_0$, write $f(m) = kd$; then $f(kd) = a_
0 + kd = kd = f(m)$. ✓

f(m) + f(n)$. ✓

So $f(m+f(n)) = f(m) + f(n) = f(f(m)) + f(n)$. ✓

For $f \equiv 0$: $f(m+f(n)) = f(m) = 0 = f(0) + 0 = f(f(m)) + f(n)$. ✓
