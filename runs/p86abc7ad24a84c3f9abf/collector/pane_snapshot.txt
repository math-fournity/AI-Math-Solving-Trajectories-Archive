## Answer

**No.** Such a set $B$ need not exist. The standard Vitali set provides a counte
rexample.

### Proof

Take $X = \mathbb{R}$ with the Borel $\sigma$-algebra $\mathcal B$ and $\mu = $
Lebesgue measure. This is a positive Radon measure on the locally compact space
$\mathbb{R}$.

**Construction of $A$ (Vitali set).** Define an equivalence relation on $[0,1]$
by $x \sim y \iff x - y \in \mathbb{Q}$. By the axiom of choice, let $A \subset
[0,1]$ contain exactly one representative from each equivalence class.

**Claim 1: Every measurable subset of $A$ has measure zero.**

Let $E \subset A$ be Lebesgue measurable with $\mu(E) > 0$. By Steinhaus's theor
em, the difference set $E - E = \{x - y : x, y \in E\}$ contains an open interva
l around $0$, hence contains a nonzero rational $q \neq 0$. But $E \subset A$, s
o $x - y = q$ with $x, y \in A$ and $q \in \mathbb{Q}\setminus\{0\}$, which mean
s $x \sim y$ with $x \neq y$—contradicting that $A$ contains exactly one represe
ntative per class. Hence $\mu(E) = 0$.

**Claim 2: There is no measurable null set $B \supset A$.**

Consider the countable family $\{A + q : q \in \mathbb{Q} \cap [-1,1]\}$. These
sets are pairwise disjoint (if $(A+q_1) \cap (A+q_2) \neq \emptyset$, then $a_1
+ q_1 = a_2 + q_2$, so $a_1 - a_2 = q_2 - q_1 \in \mathbb{Q}$, forcing $a_1 = a_
2$ and thus $q_1 = q_2$). Moreover,
$$[0,1] \subset \bigcup_{q \in \mathbb{Q} \cap [-1,1]} (A + q),$$
since every $x \in [0,1]$ is equivalent to some $a \in A$, giving $x - a = q \in
 \mathbb{Q} \cap [-1,1]$.

Suppose for contradiction that some measurable $B \supset A$ satisfies $\mu(B) =
 0$. Then $B + q \supset A + q$ and $\mu(B+q) = 0$ for each $q$. Since $\mathbb{
Q} \cap [-1,1]$ is countable,
$$[0,1] \subset \bigcup_{q \in \mathbb{Q}\cap[-1,1]} (B+q),$$
and the right-hand side is a countable union of null sets, hence has measure $0$
. But $\mu([0,1]) = 1 > 0$—contradiction.

**Conclusion.** The set $A$ satisfies the hypothesis (every measurable subset ha
s measure zero), yet there is no measurable set $B$ of measure zero containing $
A$. Therefore the answer to the question is **no**; the condition that every mea
surable subset of $A$ has zero measure (i.e., $\mu_*(A) = 0$, inner measure zero
) does not imply that $A$ is contained in a null set (i.e., does not imply $\mu^
*(A) = 0$, outer measure zero).
