## Solution

The equation in base $X$ is:

$$\overline{ABBC}_X \times \overline{CCA}_X = \overline{CCCCAC}_X$$

Expanding positionally:

$$(AX^3 + BX^2 + BX + C)(CX^2 + CX + A) = CX^5 + CX^4 + CX^3 + CX^2 + AX + C$$

**Expanding the left side:**

$$AC\cdot X^5 + C(A+B)\cdot X^4 + (A^2+2BC)\cdot X^3 + (AB+BC+C^2)\cdot X^2 + (A
B+C^2)\cdot X + AC$$

Since the result is a six-digit number with leading digit $C \neq 0$, and the fa
ctors are four- and three-digit (so $A \neq 0$, $C \neq 0$), I track carries fro
m the lowest position upward. Let $k_i$ be the carry from position $i$ to positi
on $i+1$.

**Key constraint from the highest position:** The $X^5$ digit is exactly $C$ wit
h no overflow, so $AC + k_4 = C$ (exactly). Since $A \geq 1$, $C \geq 1$, $k_4 \
geq 0$, this forces $A = 1$ and $k_4 = 0$.

**From $k_4 = 0$:** Position 4 gives $C(1+B) + k_3 = C$ (since the value is $< X
$ and $\equiv C \pmod{X}$), so $CB + k_3 = 0$. Since $C \neq 0$, we get $B = 0$
and $k_3 = 0$.

**From $k_3 = 0$:** Position 3 gives $1 + k_2 = C$ (value $< X$, $\equiv C \pmod
 X$).

**From $k_0 = 0$** (since $A=1$ gives $AC = C < X$): Position 1 requires $C^2 \e
quiv 1 \pmod{X}$, with $k_1 = \lfloor C^2/X \rfloor$. Position 2 then gives $k_2
 = \lfloor(C^2 + k_1)/X\rfloor$, and we need $C = 1 + k_2$.

So the condition reduces to: **$C^2 \equiv 1 \pmod{X}$**, with $C = 1 + \lfloor(
C^2 + \lfloor C^2/X \rfloor)/X \rfloor$ (which is automatically satisfied as ver
ified below).

---

### Configuration 1: $X = 10$

$C^2 \equiv 1 \pmod{10}$ with $1 \leq C \leq 9$: $C \in \{1, 9\}$.

- $C = 1$: $k_1 = 0$, $k_2 = 0$, $C = 1+0 = 1$ ✓
- $C = 9$: $k_1 = \lfloor 81/10 \rfloor = 8$, $k_2 = \lfloor 89/10 \rfloor = 8$,
 $C = 1+8 = 9$ ✓

**Verification:** $1009 \times 991 = 999919$ ✓

**Sum = $1 + 9 = 10$.**

### Configuration 2: $X = 2$

Digits are $\{0,1\}$ with $A \neq 0, C \neq 0$, so $A = 1, C = 1$. Then $B = 0$.

**Verification:** $\overline{1001}_2 \times \overline{111}_2 = 9 \times 7 = 63 =
 \overline{111111}_2 = \overline{CCCCAC}_2$ ✓

**Value = $1$.**

### Configuration 3: $X = 5$

$C^2 \equiv 1 \pmod{5}$ with $1 \leq C \leq 4$: $C \in \{1, 4\}$.

- $C = 1$: $k_1 = 0$, $k_2 = 0$, $C = 1$ ✓
- $C = 4$: $k_1 = \lfloor 16/5 \rfloor = 3$, $k_2 = \lfloor 19/5 \rfloor = 3$, $
C = 1+3 = 4$ ✓

**Verification:** $\overline{1004}_5 = 129$, $\overline{441}_5 = 121$, $129 \tim
es 121 = 15609 = \overline{444414}_5 = \overline{CCCCAC}_5$ ✓

**Sum = $1 + 4 = 5$.**
