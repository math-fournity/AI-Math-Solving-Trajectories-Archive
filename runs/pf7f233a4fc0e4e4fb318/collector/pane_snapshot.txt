Looking at this problem, I need to determine the parity of the number of ordered
 10-tuples of positive integers whose reciprocal sum equals 1.

## Proof

**Setup.** Let $S$ be the set of ordered 10-tuples $(a_1, \ldots, a_{10})$ of po
sitive integers with $\sum_{i=1}^{10} \frac{1}{a_i} = 1$. The symmetric group $S
_{10}$ acts on $S$ by permuting coordinates. Each orbit corresponds to a multise
t $\{a_1, \ldots, a_{10}\}$ (an unordered collection with multiplicities) satisf
ying the equation. The orbit of a multiset with distinct values $v_1, \ldots, v_
k$ having multiplicities $m_1, \ldots, m_k$ (where $\sum m_i = 10$) has size:

$$|\text{orbit}| = \frac{10!}{\prod_{i=1}^k m_i!}.$$

**Key reduction.** Since $|S| = \sum_{\text{orbits}} |\text{orbit}|$, we have $|
S| \equiv \#\{\text{orbits with odd size}\} \pmod{2}$.

**When is an orbit odd?** Using $v_2(n!) = n - s_2(n)$ (where $s_2(n)$ is the nu
mber of 1-bits in the binary expansion of $n$), and $v_2(10!) = 5 + 2 + 1 = 8$:

$$v_2(|\text{orbit}|) = 8 - \sum_{i=1}^k v_2(m_i!) = 8 - \sum_{i=1}^k (m_i - s_2
(m_i)) = 8 - \left(10 - \sum_{i=1}^k s_2(m_i)\right) = \sum_{i=1}^k s_2(m_i) - 2
.$$

So the orbit size is **odd** if and only if $\sum_{i=1}^k s_2(m_i) = 2$.

Since each $m_i \geq 1$ gives $s_2(m_i) \geq 1$, we need $\sum s_2(m_i) = 2$, wh
ich forces either:

- **Case 1:** $k = 1$ (one distinct value), $m_1 = 10$, and $s_2(10) = s_2(1010_
2) = 2$. ✓
- **Case 2:** $k = 2$ (two distinct values), both multiplicities are powers of 2
 (so $s_2 = 1$ each), with $m_1 + m_2 = 10$. The only power-of-2 pair summing to
 10 is $\{2, 8\}$.

(Three or more distinct values would require $\sum s_2(m_i) \geq 3 > 2$, impossi
ble.)

**Case 1: All entries equal.** We need $\frac{10}{a} = 1$, so $a = 10$. This giv
es one multiset: $\{10, 10, \ldots, 10\}$, with orbit size 1 (odd). **Count: 1.*
*

**Case 2: Multiplicities $\{2, 8\}$.** Let value $a$ appear 2 times and value $b
$ appear 8 times, $a \neq b$, both positive integers. The equation is:

$$\frac{2}{a} + \frac{8}{b} = 1 \implies 2b + 8a = ab \implies (a-2)(b-8) = 16.$
$

We enumerate positive divisor pairs $(d, 16/d)$ of 16 with $a = d+2 \geq 1$, $b
= 16/d + 8 \geq 1$, and $a \neq b$:

| $d$ | $a = d+2$ | $b = 16/d + 8$ | $a \neq b$? | Valid? |
|-----|-----------|-----------------|-------------|--------|
| 1   | 3         | 24              | ✓           | ✓      |
| 2   | 4         | 16              | ✓           | ✓      |
| 4   | 6         | 12              | ✓           | ✓      |
| 8   | 10        | 10              | ✗ ($a=b$)   | ✗      |
| 16  | 18        | 9               | ✓           | ✓      |

Negative divisors yield non-positive values, so they are excluded. This gives **
4 valid multisets**, each with orbit size $\frac{10!}{2!\cdot 8!} = 45$ (odd). *
*Count: 4.**

**Verification of solutions:**
- $(a,b) = (3,24)$: $\frac{2}{3} + \frac{8}{24} = \frac{2}{3} + \frac{1}{3} = 1$
 ✓
- $(a,b) = (4,16)$: $\frac{2}{4} + \frac{8}{16} = \frac{1}{2} + \frac{1}{2} = 1$
 ✓
- $(a,b) = (6,12)$: $\frac{2}{6} + \frac{8}{12} = \frac{1}{3} + \frac{2}{3} = 1$
 ✓
- $(a,b) = (18,9)$: $\frac{2}{18} + \frac{8}{9} = \frac{1}{9} + \frac{8}{9} = 1$
 ✓

**Conclusion.** The total number of odd-sized orbits is $1 + 4 = 5$. Since $5$ i
s odd:

$$|S| \equiv 5 \equiv 1 \pmod{2}.$$

The number of ordered 10-tuples of positive integers $(a_1, \ldots, a_{10})$ sat
isfying $\frac{1}{a_1} + \cdots + \frac{1}{a_{10}} = 1$ is **odd**.
