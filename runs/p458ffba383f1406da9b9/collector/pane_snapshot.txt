## Proof

**Setup.** There are 50 cards, each bearing two distinct numbers, and the 100 nu
mbers used across all sides are exactly {1, 2, …, 100}. Each card initially show
s one side; we may flip any subset. Since we can flip every card independently,
for each card we can always choose to display the larger of its two numbers. Thu
s the maximum achievable sum for any given pairing is $\sum_{i=1}^{50} \max(a_i,
 b_i)$, where the pairs $(a_i, b_i)$ partition $\{1,\dots,100\}$.

The question asks for the **largest sum we can be sure to achieve**, i.e., the m
inimum over all pairings of $\sum \max(a_i,b_i)$.

**Reformulation.** For any pairing, let $L = \{\text{larger element of each pair
}\}$ and $S = \{\text{smaller element of each pair}\}$. Then $|L|=|S|=50$, $L \c
up S = \{1,\dots,100\}$, $L \cap S = \emptyset$, and each $s \in S$ is paired wi
th some $l \in L$ with $s < l$.

A valid matching (each $s$ paired to a larger $l$) exists if and only if, writin
g $S = \{s_1 < \cdots < s_{50}\}$ and $L = \{l_1 < \cdots < l_{50}\}$, we have $
s_i < l_i$ for all $i$. This is equivalent to the ballot-type condition:

$$|L \cap \{1,\dots,k\}| \le \lfloor k/2 \rfloor \quad \text{for all } k = 1, \d
ots, 100.$$

**Lower bound on $\sum L$.** Let $L = \{l_1 < l_2 < \cdots < l_{50}\}$. The cons
traint at $k = 2j-1$ gives $|L \cap \{1,\dots,2j-1\}| \le j-1$, so the $j$-th sm
allest element of $L$ satisfies $l_j \ge 2j$. Therefore:

$$\sum_{j=1}^{50} l_j \ge \sum_{j=1}^{50} 2j = 2 \cdot \frac{50 \cdot 51}{2} = 2
550.$$

**Tightness.** The pairing $(1,2),\, (3,4),\, (5,6),\, \dots,\, (99,100)$ gives
$L = \{2, 4, 6, \dots, 100\}$ with $\sum L = 2+4+\cdots+100 = 2550$. This pairin
g is valid and achieves exactly 2550, so no pairing forces a smaller sum of maxi
ma.

**Conclusion.** No matter how the 100 numbers are distributed onto the 50 cards,
 we can always flip cards to display the larger number on each, achieving a sum
of at least **2550**. The consecutive pairing shows this bound is tight, so 2550
 is the largest sum we can guarantee.
