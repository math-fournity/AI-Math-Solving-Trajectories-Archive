## Derivation of the Neyman–Pearson Test

### Setup

Consider a binary hypothesis test between:
- $H_0$: observation $x \sim f(x \mid H_0)$ (null)
- $H_1$: observation $x \sim f(x \mid H_1)$ (alternative)

with the likelihood ratio
$$\Lambda(x) = \frac{f(x \mid H_1)}{f(x \mid H_0)}.$$

A decision rule partitions the observation space $\mathcal{X}$ into an acceptanc
e region $\mathcal{R}_0$ (decide $H_0$) and a rejection (detection) region $\mat
hcal{R}_1 = \mathcal{X} \setminus \mathcal{R}_0$ (decide $H_1$).

The two error probabilities are:
- **Probability of false alarm** (Type I): $\alpha = P_{H_0}(\mathcal{R}_1) = \i
nt_{\mathcal{R}_1} f(x \mid H_0)\,dx$
- **Probability of miss** (Type II): $\beta = P_{H_0}(\mathcal{R}_0) = \int_{\ma
thcal{R}_0} f(x \mid H_1)\,dx$

The detection probability is $1 - \beta = P_{H_1}(\mathcal{R}_1) = \int_{\mathca
l{R}_1} f(x \mid H_1)\,dx$.

### The Optimization Problem (Neyman–Pearson)

Maximize the detection probability $1 - \beta$ subject to a false-alarm constrai
nt $\alpha \le \alpha_0$:

$$\max_{\mathcal{R}_1}\; \int_{\mathcal{R}_1} f(x \mid H_1)\,dx \quad \text{s.t.
} \quad \int_{\mathcal{R}_1} f(x \mid H_0)\,dx \le \alpha_0.$$

### Lagrangian Formulation

Introducing a Lagrange multiplier $\lambda \ge 0$ for the inequality constraint,
 the Lagrangian is

$$\mathcal{L}(\mathcal{R}_1, \lambda) = \int_{\mathcal{R}_1} f(x \mid H_1)\,dx -
 \lambda\!\left(\int_{\mathcal{R}_1} f(x \mid H_0)\,dx - \alpha_0\right).$$

Rewrite using the likelihood ratio:

$$\mathcal{L} = \int_{\mathcal{R}_1}\!\bigl[f(x \mid H_1) - \lambda\, f(x \mid H
_0)\bigr]\,dx + \lambda \alpha_0 = \int_{\mathcal{R}_1}\! f(x \mid H_0)\bigl[\La
mbda(x) - \lambda\bigr]\,dx + \lambda \alpha_0.$$

### Maximizing Over the Decision Region

For a fixed $\lambda$, the integrand $f(x \mid H_0)[\Lambda(x) - \lambda]$ is no
n-negative exactly where $\Lambda(x) \ge \lambda$. To maximize $\mathcal{L}$, we
 therefore include in $\mathcal{R}_1$ precisely those points $x$ where the integ
rand is positive, and exclude those where it is negative. This gives the **most
powerful region**:

$$\mathcal{R}_1^* = \{x : \Lambda(x) \ge \lambda\}.$$

The threshold $\lambda$ is then chosen so the false-alarm constraint is met with
 equality (the constraint is active at the optimum, since enlarging $\mathcal{R}
_1$ always increases detection power):

$$\alpha = P_{H_0}\!\bigl(\Lambda(x) \ge \lambda\bigr) = \int_{\{x:\,\Lambda(x)\
,\ge\,\lambda\}} f(x \mid H_0)\,dx = \alpha_0.$$

### Randomization (Handling the Equality Case)

When $\Lambda(x)$ has a discrete distribution under $H_0$, the equation $P_{H_0}
(\Lambda \ge \lambda) = \alpha_0$ may have no exact solution. Let $\eta$ be the
largest threshold with $P_{H_0}(\Lambda > \eta) \le \alpha_0$, and define

$$\gamma = \frac{\alpha_0 - P_{H_0}(\Lambda > \eta)}{P_{H_0}(\Lambda = \eta)}.$$

The randomized test decides $H_1$ when $\Lambda(x) > \eta$, decides $H_0$ when $
\Lambda(x) < \eta$, and randomizes (decides $H_1$ with probability $\gamma$) whe
n $\Lambda(x) = \eta$. This achieves $\alpha = \alpha_0$ exactly.

### The Neyman–Pearson Lemma (Statement)

Among all tests satisfying $P_{H_0}(\text{reject } H_0) \le \alpha_0$, the likel
ihood-ratio test

$$\Lambda(x) \underset{H_0}{\overset{H_1}{\gtrless}} \eta$$

(with randomization on the boundary if needed) is **most powerful**, i.e., it ma
ximizes $P_{H_1}(\text{reject } H_0) = 1 - \beta$.

### Proof of Optimality (Most-Powerful Argument)

Let $\mathcal{R}_1^*$ be the N–P region and let $\mathcal{R}_1$ be any other reg
ion with $P_{H_0}(\mathcal{R}_1) \le \alpha_0 = P_{H_0}(\mathcal{R}_1^*)$. Consi
der the difference in detection power:

$$P_{H_1}(\mathcal{R}_1^*) - P_{H_1}(\mathcal{R}_1) = \int_{\mathcal{R}_1^*} f_1
\,dx - \int_{\mathcal{R}_1} f_1\,dx.$$

Using $f_1 = \Lambda\, f_0$ and splitting the integrals over the symmetric diffe
rence $\mathcal{R}_1^* \setminus \mathcal{R}_1$ and $\mathcal{R}_1 \setminus \ma
thcal{R}_1^*$:

$$= \int_{\mathcal{R}_1^*\setminus\mathcal{R}_1}\! f_1\,dx - \int_{\mathcal{R}_1
\setminus\mathcal{R}_1^*}\! f_1\,dx = \int_{\mathcal{R}_1^*\setminus\mathcal{R}_
1}\! \Lambda\, f_0\,dx - \int_{\mathcal{R}_1\setminus\mathcal{R}_1^*}\! \Lambda\
, f_0\,dx.$$

On $\mathcal{R}_1^*$ we have $\Lambda \ge \eta$, and on $\mathcal{R}_1 \setminus
 \mathcal{R}_1^*$ (which lies outside $\mathcal{R}_1^*$) we have $\Lambda \le \e
ta$. Hence

$$\ge \eta\!\int_{\mathcal{R}_1^*\setminus\mathcal{R}_1}\! f_0\,dx - \eta\!\int_
{\mathcal{R}_1\setminus\mathcal{R}_1^*}\! f_0\,dx = \eta\bigl[P_{H_0}(\mathcal{R
}_1^*) - P_{H_0}(\mathcal{R}_1)\bigr] \ge \eta\,(\alpha_0 - \alpha_0) = 0,$$

where the last inequality uses $P_{H_0}(\mathcal{R}_1^*) = \alpha_0 \ge P_{H_0}(
\mathcal{R}_1)$ and $\eta \ge 0$. Therefore $P_{H_1}(\mathcal{R}_1^*) \ge P_{H_1
}(\mathcal{R}_1)$ for every competitor $\mathcal{R}_1$, proving the N–P test is
most powerful. $\blacksquare$

### Summary

The Neyman–Pearson test that maximizes detection probability $1-\beta$ at fixed
false-alarm level $\alpha_0$ is the **likelihood-ratio test**

$$\boxed{\;\Lambda(x) = \frac{f(x\mid H_1)}{f(x\mid H_0)} \;\underset{H_0}{\over
set{H_1}{\gtrless}}\; \eta\;}$$

where the threshold $\eta$ (and, if necessary, a randomization probability $\gam
ma$ on the boundary $\Lambda = \eta$) is selected so that $P_{H_0}(\Lambda \ge \
eta) = \alpha_0$. The proof of optimality rests on the fact that the region $\{\
Lambda \ge \eta\}$ collects exactly those observations where the per-unit-false-
alarm gain in detection power, $\Lambda(x)$, is largest, so no other region of e
qual or smaller $H_0$-mass can yield greater $H_1$-mass.
