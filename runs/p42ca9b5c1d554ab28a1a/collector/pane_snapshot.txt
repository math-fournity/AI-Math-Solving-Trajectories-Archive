Looking at this problem, I need to find which integers $b \in \{1, \ldots, 2012\
}$ can be the unique non-zero of $f(x) = \prod_{i=1}^n f_i(a_i x)$.

## Analyzing Zero Sets on Integers

Each factor $f_i(a_i x)$ vanishes at integer $x$ as follows. Let $\alpha_i = \pi
/a_i$ (with $a_i \neq 0$).

**Sine factor** $\sin(a_i x) = 0 \iff x/\alpha_i \in \mathbb{Z}$. If $\alpha_i =
 p/q$ (lowest terms), the zero set on $\mathbb{Z}$ is $p\mathbb{Z}$, i.e., the r
esidue class $0 \pmod{p}$. If $\alpha_i$ is irrational, only $x=0$ is covered (u
seless).

**Cosine factor** $\cos(a_i x) = 0 \iff 2x/\alpha_i \in 2\mathbb{Z}+1$. If $\alp
ha_i = p/q$ (lowest terms), this requires $p \mid 2x$. When $p$ is odd: no integ
er solutions (the quotient is always even). When $p = 2p'$ (even, $q$ odd): the
zero set on $\mathbb{Z}$ is $\{p'm : m \text{ odd}\}$, i.e., the residue class $
p' \pmod{2p'}$. If $\alpha_i$ is irrational: empty zero set on $\mathbb{Z}$.

**Summary:** Each factor covers either the residue class $0 \pmod{d}$ (sine) or
$d/2 \pmod{d}$ for even $d$ (cosine), or nothing useful.

## Key Characterization

The product vanishes at $x$ iff **some** factor vanishes at $x$. So we need:
- Every $x \in \{1,\ldots,2012\}\setminus\{b\}$ is covered by at least one facto
r's zero set.
- $b$ is covered by **no** factor's zero set.

**When can $x$ be covered without covering $b$?**

*Sine* ($0 \pmod{d}$): covers $x$ iff $d \mid x$; covers $b$ iff $d \mid b$. We
can avoid $b$ iff there exists $d \mid x$ with $d \nmid b$, which holds iff $x \
nmid b$ (take $d = x$).

*Cosine* ($p' \pmod{2p'}$): covers $x$ iff $p' \mid x$ and $x/p'$ odd; covers $b
$ iff $p' \mid b$ and $b/p'$ odd.

**Case 1: $x \nmid b$.** Sine with $d = x$ covers $x$ but not $b$. ✓

**Case 2: $x \mid b$, $x \neq b$.** Every sine factor covering $x$ also covers $
b$ (since $d \mid x \mid b$). For cosine: if $p' \mid x$ and $x/p'$ is odd, then
 $p' \mid b$ and $b/p' = (x/p')\cdot(b/x)$. This is odd iff $b/x$ is odd. So:
- If $b/x$ is **even**: cosine with $p' = x$ covers $x$ ($x/x = 1$ odd ✓) but no
t $b$ ($b/x$ even ✗). ✓
- If $b/x$ is **odd**: every cosine factor covering $x$ also covers $b$. **Impos
sible to separate.** ✗

## Determining Achievable $b$

Write $b = 2^a \cdot m$ with $m$ odd. The integers $x$ with $x \mid b$ and $b/x$
 odd are exactly $x = 2^a \cdot d$ where $d \mid m$.

**If $m > 1$ (i.e., $b$ is not a power of 2):** Take $d = 1$, giving $x = 2^a$.
Since $b \leq 2012$ and $m \geq 3$, we have $2^a \leq 2012/3 < 670$, so $x = 2^a
 \leq 512 \leq 2012$. Also $x \neq b$ (since $m > 1$) and $b/x = m$ is odd. This
 $x$ **cannot** be covered without covering $b$. So $b$ is **impossible**.

**If $m = 1$ (i.e., $b = 2^a$ is a power of 2):** The only divisor of $m = 1$ is
 $d = 1 = m$, giving $x = 2^a = b$ itself, which is excluded. So there is **no**
 problematic $x$. For every $x \neq b$:
- If $x \nmid b$: use $\sin(\pi x / x) = \sin(\pi) = 0$ via sine with $d = x$. S
ince $x \nmid b$, $b$ is not covered.
- If $x \mid b$ (so $x = 2^c$, $c < a$): $b/x = 2^{a-c}$ is even. Use cosine wit
h $p' = x$: $\cos(\pi x/(2x)) = \cos(\pi/2) = 0$ ✓, and $\cos(\pi b/(2x)) = \cos
(\pi \cdot 2^{a-c-1}) = \pm 1 \neq 0$ ✓.

So $b$ is **achievable** iff $b$ is a power of 2.

## Verification

- **$b = 3$** (not a power of 2): $b = 2^0 \cdot 3$, $x = 1$ divides 3, $3/1 = 3
$ odd. Every factor covering 1 (sine $0 \pmod 1$ covers all; cosine $1 \pmod 2$
covers all odds including 3) also covers 3. Impossible. ✓
- **$b = 4 = 2^2$**: $x = 2$ divides 4, $4/2 = 2$ even → cosine with $p'=2$ sepa
rates them. $x = 1$ divides 4, $4/1 = 4$ even → cosine with $p'=1$ (odd numbers)
 covers 1 but not 4. All other $x$ use sine. Achievable. ✓

## Computing the Sum

The powers of 2 in $\{1, \ldots, 2012\}$ are $1, 2, 4, 8, 16, 32, 64, 128, 256,
512, 1024$ (since $2^{11} = 2048 > 2012$).

$$\text{Sum} = 2^0 + 2^1 + 2^2 + \cdots + 2^{10} = 2^{11} - 1 = \boxed{2047}$$
