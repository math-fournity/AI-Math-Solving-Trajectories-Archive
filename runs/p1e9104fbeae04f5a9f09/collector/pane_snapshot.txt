# Christoffel Symbols for the Cone x(u,v) = (u cos v, u sin v, u)

## Setup: First and Second Fundamental Forms

**Tangent vectors:**
- x_u = (cos v, sin v, 1)
- x_v = (−u sin v, u cos v, 0)

**First fundamental form coefficients:**
- E = x_u · x_u = cos²v + sin²v + 1 = **2**
- F = x_u · x_v = −u cos v sin v + u sin v cos v = **0**
- G = x_v · x_v = u² sin²v + u² cos²v = **u²**

**Second partial derivatives:**
- x_uu = (0, 0, 0)
- x_uv = (−sin v, cos v, 0)
- x_vv = (−u cos v, −u sin v, 0)

**Unit normal:**
x_u × x_v = (−u cos v, −u sin v, u), with |x_u × x_v| = u√2, so
n = (−cos v, −sin v, 1)/√2.

**Second fundamental form coefficients:**
- e = x_uu · n = **0**
- f = x_uv · n = (sin v cos v − cos v sin v)/√2 = **0**
- g = x_vv · n = u(cos²v + sin²v)/√2 = **u/√2**

---

## Method 1: Direct Definition

The Gauss equations (defining relations of the Christoffel symbols) are:
- x_uu = Γ¹₁₁ x_u + Γ²₁₁ x_v + e n
- x_uv = Γ¹₁₂ x_u + Γ²₁₂ x_v + f n
- x_vv = Γ¹₂₂ x_u + Γ²₂₂ x_v + g n

**From x_uu = 0:**
0 = Γ¹₁₁ x_u + Γ²₁₁ x_v + 0. Since x_u, x_v are linearly independent, Γ¹₁₁ = 0 a
nd Γ²₁₁ = 0.

**From x_uv = (−sin v, cos v, 0):**
(−sin v, cos v, 0) = Γ¹₁₂ (cos v, sin v, 1) + Γ²₁₂ (−u sin v, u cos v, 0) + 0·n.

- Third component: 0 = Γ¹₁₂ ⟹ **Γ¹₁₂ = 0**.
- First component: −sin v = −u Γ²₁₂ sin v ⟹ **Γ²₁₂ = 1/u** (confirmed by the sec
ond component: cos v = u Γ²₁₂ cos v).

**From x_vv = (−u cos v, −u sin v, 0):**
(−u cos v, −u sin v, 0) = Γ¹₂₂ (cos v, sin v, 1) + Γ²₂₂ (−u sin v, u cos v, 0) +
 (u/√2) n.

- Third component: 0 = Γ¹₂₂ + (u/√2)(1/√2) = Γ¹₂₂ + u/2 ⟹ **Γ¹₂₂ = −u/2**.
- First component: −u cos v = (−u/2) cos v − u Γ²₂₂ sin v − (u/2) cos v = −u cos
 v − u Γ²₂₂ sin v ⟹ Γ²₂₂ sin v = 0 ⟹ **Γ²₂₂ = 0**.
- Second component (check): −u sin v = (−u/2) sin v + 0 − (u/2) sin v = −u sin v
. ✓

---

## Method 2: Standard Formulas via E, F, G

With E = 2, F = 0, G = u², and the simplification that E, F are constant while G
 depends only on u (G_u = 2u, all other first partials vanish), the standard for
mulas (with F = 0) give:

| Symbol | Formula | Value |
|--------|---------|-------|
| Γ¹₁₁ | E_u / (2E) | 0 / 4 = **0** |
| Γ¹₁₂ = Γ¹₂₁ | E_v / (2E) | 0 / 4 = **0** |
| Γ¹₂₂ | −G_u / (2E) | −2u / 4 = **−u/2** |
| Γ²₁₁ | −E_v / (2G) | 0 / (2u²) = **0** |
| Γ²₁₂ = Γ²₂₁ | G_u / (2G) | 2u / (2u²) = **1/u** |
| Γ²₂₂ | G_v / (2G) | 0 / (2u²) = **0** |

---

## Result (Both Methods Agree)

The six independent Christoffel symbols of the cone x(u,v) = (u cos v, u sin v,
u) are:

$$\Gamma^1_{11} = 0, \quad \Gamma^1_{12} = \Gamma^1_{21} = 0, \quad \Gamma^1_{22
} = -\frac{u}{2}$$

$$\Gamma^2_{11} = 0, \quad \Gamma^2_{12} = \Gamma^2_{21} = \frac{1}{u}, \quad \G
amma^2_{22} = 0$$

The only nonzero symbols are **Γ¹₂₂ = −u/2** and **Γ²₁₂ = Γ²₂₁ = 1/u**. Both met
hods—direct decomposition of the second partials into the {x_u, x_v, n} basis, a
nd the E, F, G formulas—yield identical results, as expected.
