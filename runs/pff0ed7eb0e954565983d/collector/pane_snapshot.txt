## Solution

**Claim.** Let $U \subset \mathbb{R}^3$ be open, bounded, and of class $C^2$. Th
ere exists a constant $C = C(U,p) > 0$ such that
$$\|u\|_{L^{p}(U)} \leq C\,\|u\|_{H^{1}(U)} \qquad \forall\, u \in H^{1}(U)$$
if and only if $1 < p \leq 6$. In particular, the inequality **does hold** for $
p = 6$.

Here $H^{1}(U) = W^{1,2}(U)$ with norm $\|u\|_{H^{1}(U)} = \bigl(\|u\|_{L^{2}(U)
}^{2} + \|\nabla u\|_{L^{2}(U)}^{2}\bigr)^{1/2}$.

---

### Part 1. The inequality holds for $p = 6$ (critical Sobolev embedding)

This is the **Sobolev embedding theorem** in dimension $n = 3$. Since $U$ is bou
nded with $C^{2}$ (hence $C^{1}$) boundary, the classical theorem (see, e.g., Ev
ans, *PDE*, §5.6, or Adams–Fournier) gives the continuous embedding
$$W^{1,2}(U) \hookrightarrow L^{2^{*}}(U), \qquad 2^{*} = \frac{2n}{n-2} = \frac
{6}{1} = 6,$$
i.e. there exists $C_{1} = C_{1}(U) > 0$ with
$$\|u\|_{L^{6}(U)} \leq C_{1}\,\|u\|_{W^{1,2}(U)} = C_{1}\,\|u\|_{H^{1}(U)} \qqu
ad \forall\, u \in H^{1}(U). \tag{1}$$

*Sketch of the argument behind (1).* For smooth $u$ one uses the Gagliardo–Niren
berg–Sobolev inequality on $\mathbb{R}^{3}$,
$$\|u\|_{L^{6}(\mathbb{R}^{3})} \leq K\,\|\nabla u\|_{L^{2}(\mathbb{R}^{3})},$$
then extends to $H^{1}(U)$ via an extension operator $E: W^{1,2}(U) \to W^{1,2}(
\mathbb{R}^{3})$ (which exists because $\partial U$ is $C^{1}$), applying the in
equality to $Eu$ and using $\|Eu\|_{W^{1,2}(\mathbb{R}^{3})} \leq C_{E}\|u\|_{W^
{1,2}(U)}$. Density of $C^{\infty}(\overline{U})$ in $H^{1}(U)$ extends (1) to a
ll of $H^{1}(U)$. $\square$

---

### Part 2. The inequality holds for $1 < p < 6$

Since $U$ is bounded, $|U| < \infty$. On a finite-measure space, $L^{q} \hookrig
htarrow L^{p}$ continuously whenever $1 \leq p \leq q < \infty$, with
$$\|u\|_{L^{p}(U)} \leq |U|^{\frac{1}{p}-\frac{1}{q}}\|u\|_{L^{q}(U)}.$$
Taking $q = 6$ and using (1):
$$\|u\|_{L^{p}(U)} \leq |U|^{\frac{1}{p}-\frac{1}{6}}\|u\|_{L^{6}(U)} \leq \unde
rbrace{|U|^{\frac{1}{p}-\frac{1}{6}}\,C_{1}}_{=:C(U,p)}\,\|u\|_{H^{1}(U)}, \qqua
d 1 < p \leq 6. \tag{2}$$
So the desired inequality holds for every $1 < p \leq 6$.

---

### Part 3. The inequality FAILS for $p > 6$

We exhibit $u \in H^{1}(U)$ with $u \notin L^{p}(U)$, which rules out any such $
C$. Take $U = B(0,1) \subset \mathbb{R}^{3}$ (a $C^{\infty}$, hence $C^{2}$, bou
nded open set) and set
$$u(x) = |x|^{-\alpha}, \qquad \alpha \in \bigl[\tfrac{3}{p},\,\tfrac{1}{2}\bigr
).$$
Such an $\alpha$ exists because $p > 6 \Rightarrow 3/p < 1/2$.

**$u \in H^{1}(B(0,1))$:** We have $\nabla u = -\alpha\,|x|^{-\alpha-1}\,\hat{x}
$, so $|\nabla u| = \alpha\,|x|^{-\alpha-1}$. Using spherical coordinates ($r =
|x|$, $dV = 4\pi r^{2}\,dr$):
$$\|u\|_{L^{2}}^{2} = 4\pi\int_{0}^{1} r^{-2\alpha}\,r^{2}\,dr = 4\pi\int_{0}^{1
} r^{2-2\alpha}\,dr < \infty \iff 2 - 2\alpha > -1 \iff \alpha < \tfrac{3}{2},$$
$$\|\nabla u\|_{L^{2}}^{2} = 4\pi\alpha^{2}\int_{0}^{1} r^{-2\alpha-2}\,r^{2}\,d
r = 4\pi\alpha^{2}\int_{0}^{1} r^{-2\alpha}\,dr < \infty \iff -2\alpha > -1 \iff
 \alpha < \tfrac{1}{2}.$$
Since $\alpha < 1/2$, both integrals are finite, so $u \in H^{1}(B(0,1))$.

**$u \notin L^{p}(B(0,1))$:**
$$\|u\|_{L^{p}}^{p} = 4\pi\int_{0}^{1} r^{-\alpha p}\,r^{2}\,dr = 4\pi\int_{0}^{
1} r^{2-\alpha p}\,dr.$$
This diverges iff $2 - \alpha p \leq -1$, i.e. $\alpha p \geq 3$, i.e. $\alpha \
geq 3/p$. By our choice $\alpha \geq 3/p$, the integral diverges, so $u \notin L
^{p}(B(0,1))$.

Hence no constant $C$ can make $\|u\|_{L^{p}} \leq C\|u\|_{H^{1}}$ hold for all
$u \in H^{1}(U)$ when $p > 6$.

---

### Conclusion

For $U \subset \mathbb{R}^{3}$ open, bounded, of class $C^{2}$:

| Range of $p$ | Inequality $\|u\|_{L^{p}(U)} \leq C\|u\|_{H^{1}(U)}$ |
|---|---|
| $1 < p \leq 6$ | **Holds** (Sobolev embedding $W^{1,2}\hookrightarrow L^{6}$ +
 finite-measure interpolation) |
| $p > 6$ | **Fails** (counterexample $|x|^{-\alpha}$, $\alpha\in[3/p,1/2)$) |

**In particular, for $p = 6$ the answer is yes**: such a constant $C = C(U)$ exi
sts, by the critical Sobolev embedding $H^{1}(U) = W^{1,2}(U) \hookrightarrow L^
{6}(U)$ in dimension $3$, valid because $U$ is bounded with $C^{2}$ (hence $C^{1
}$) boundary.
