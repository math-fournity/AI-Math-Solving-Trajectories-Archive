## Solution

We claim that

$$I(Y) = (x^q - y^p) \subset \mathbb{C}[x,y].$$

(Here we take $p,q$ positive coprime integers; the case where one of them is $0$
 or negative is degenerate and excluded by the parametrization being a curve in
$\mathbb{C}^2$.)

---

### Step 1. Setup: the kernel of an evaluation map

Define the $\mathbb{C}$-algebra homomorphism

$$\varphi : \mathbb{C}[x,y] \longrightarrow \mathbb{C}[t], \qquad x \mapsto t^p,
\;\; y \mapsto t^q.$$

A polynomial $f \in \mathbb{C}[x,y]$ vanishes on every point of $Y$ (i.e. $f(t^p
,t^q)=0$ for all $t\in\mathbb{C}$) if and only if $\varphi(f)=0$ in $\mathbb{C}[
t]$. Since $\mathbb{C}$ is infinite, a polynomial in $t$ that vanishes at every
$t\in\mathbb{C}$ is the zero polynomial. Hence

$$I(Y) = \ker\varphi.$$

So it suffices to compute $\ker\varphi$.

---

### Step 2. The polynomial $x^q - y^p$ lies in the kernel

$$\varphi(x^q - y^p) = (t^p)^q - (t^q)^p = t^{pq}-t^{qp}=0.$$

Thus $(x^q - y^p)\subseteq\ker\varphi$, and consequently $(x^q-y^p)\subseteq I(Y
)$.

---

### Step 3. The kernel is contained in $(x^q - y^p)$

Equip $\mathbb{C}[x,y]$ with the lexicographic monomial order with $x > y$. We u
se the **division algorithm**.

**Claim (key division step).** For every monomial $x^a y^b$,

$$x^a y^b \equiv x^{a'} y^{b'} \pmod{x^q - y^p}$$

for some monomial $x^{a'}y^{b'}$ with $a' < q$.

*Proof of claim.* If $a < q$ we are done (take $a'=a, b'=b$). If $a\ge q$, write
 $a = q + r$ with $r\ge 0$. Then

$$x^a y^b = x^{q+r}y^b = x^r y^b\cdot x^q = x^r y^b\cdot\bigl((x^q-y^p)+y^p\bigr
) \equiv x^r y^{b+p}\pmod{x^q-y^p}.$$

This replaces the exponent pair $(a,b)$ by $(a-q,\, b+p)$. Repeating, the $x$-ex
ponent drops by $q$ each step while the $y$-exponent rises by $p$, until the $x$
-exponent is $<q$. So eventually we reach $a'<q$. $\square$

Applying the claim term-by-term, every $f\in\mathbb{C}[x,y]$ has a unique remain
der

$$f \equiv \sum_{i<q} c_i\, y^{n_i}\, x^i \pmod{x^q-y^p}, \qquad \text{i.e. } f
\equiv g(x,y),\;\deg_x g < q.$$

Now suppose $f\in\ker\varphi$. Reducing modulo $x^q-y^p$ gives $f \equiv g$ with
 $\deg_x g<q$ and $g\in\ker\varphi$ (since $x^q-y^p\in\ker\varphi$). Write

$$g(x,y) = \sum_{i=0}^{q-1} x^i\, h_i(y), \qquad h_i\in\mathbb{C}[y].$$

Applying $\varphi$:

$$0 = \varphi(g) = \sum_{i=0}^{q-1} t^{pi}\, h_i(t^q) \in \mathbb{C}[t].$$

**Exponent separation.** Each term $t^{pi}\,h_i(t^q)$ is a sum of monomials $t^{
pi+qm}$ with $m\ge 0$. Because $\gcd(p,q)=1$, the residues $pi \pmod q$ for $i=0
,1,\dots,q-1$ are **all distinct** (they are a complete set of residues mod $q$)
. Therefore the sets of exponents

$$\{pi + qm : m\ge 0\}, \qquad i=0,\dots,q-1,$$

are **pairwise disjoint**. Hence no cancellation can occur between terms belongi
ng to different $i$. So each summand must vanish individually:

$$t^{pi}\,h_i(t^q) = 0 \quad\Longrightarrow\quad h_i = 0 \quad\text{for every }
i.$$

Thus $g=0$, i.e. $f\in(x^q-y^p)$.

---

### Step 4. Conclusion

We have shown

$$\ker\varphi \subseteq (x^q-y^p) \subseteq \ker\varphi,$$

so $\ker\varphi = (x^q-y^p)$. Since $I(Y)=\ker\varphi$,

$$\boxed{\,I(Y) = (x^q - y^p)\,}.$$

**Sanity checks.**
- $p=1,q=1$: $Y=\{(t,t)\}$, the diagonal; $I(Y)=(x-y)$. ✓
- $p=2,q=3$: $Y=\{(t^2,t^3)\}$, the cusp; $I(Y)=(x^3-y^2)$. ✓
- $p=1,q=n$: $Y=\{(t,t^n)\}$, the graph of $y=x^n$; $I(Y)=(x^n-y)=(y-x^n)$. ✓ (m
atches $x^q-y^p = x^n - y$).
