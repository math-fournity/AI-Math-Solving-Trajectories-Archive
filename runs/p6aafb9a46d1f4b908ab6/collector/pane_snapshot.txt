## Proof

**Setup.** Let $t_j = j \cdot 2^{-n}$ for $j \geq 0$. The process
$$\phi_2(t,\omega) = \sum_{j \geq 0} B_{t_{j+1}}(\omega)\,\chi_{[t_j, t_{j+1}]}(
t)$$
is a *simple* (piecewise-constant) integrand that on each subinterval $[t_j, t_{
j+1}]$ takes the value $B_{t_{j+1}}$ — the Brownian value at the **right** endpo
int. The stochastic integral is defined as the sum
$$\int_0^T \phi_2(t,\omega)\,dB_t(\omega) = \sum_{j:\, [t_j,t_{j+1}]\subseteq [0
,T]} B_{t_{j+1}}\bigl(B_{t_{j+1}} - B_{t_j}\bigr).$$
(For simplicity assume $T\cdot 2^n \in \mathbb{N}$, so the sum runs over $j = 0,
 1, \dots, 2^n T - 1$; the general case differs only by a harmless boundary term
 that vanishes in the limit.)

**Step 1 — Decompose each summand.** Write $B_{t_{j+1}} = B_{t_j} + (B_{t_{j+1}}
 - B_{t_j})$, so
$$B_{t_{j+1}}\bigl(B_{t_{j+1}} - B_{t_j}\bigr) = B_{t_j}\bigl(B_{t_{j+1}} - B_{t
_j}\bigr) + \bigl(B_{t_{j+1}} - B_{t_j}\bigr)^2.$$

**Step 2 — The cross term has zero expectation.** By the independent-increments
property of Brownian motion, the increment $\Delta B_j := B_{t_{j+1}} - B_{t_j}$
 is independent of $\mathcal{F}_{t_j}$, hence independent of $B_{t_j}$. Moreover
 $\mathbb{E}[\Delta B_j] = 0$. Therefore
$$\mathbb{E}\!\left[B_{t_j}\,\Delta B_j\right] = \mathbb{E}[B_{t_j}]\,\mathbb{E}
[\Delta B_j] = 0 \cdot 0 = 0.$$

**Step 3 — The quadratic-variation term.** Since $\Delta B_j \sim \mathcal{N}(0,
\, t_{j+1}-t_j) = \mathcal{N}(0,\, 2^{-n})$,
$$\mathbb{E}\!\left[(\Delta B_j)^2\right] = \operatorname{Var}(\Delta B_j) = t_{
j+1} - t_j = 2^{-n}.$$

Combining Steps 2 and 3:
$$\mathbb{E}\!\left[B_{t_{j+1}}\bigl(B_{t_{j+1}} - B_{t_j}\bigr)\right] = 0 + (t
_{j+1} - t_j) = t_{j+1} - t_j.$$

**Step 4 — Sum over the partition.** Taking expectation of the integral (justifi
ed since the sum is finite for fixed $n$):
$$\mathbb{E}\!\left[\int_0^T \phi_2\,dB_t\right] = \sum_{j=0}^{2^n T - 1} \mathb
b{E}\!\left[B_{t_{j+1}}\bigl(B_{t_{j+1}} - B_{t_j}\bigr)\right] = \sum_{j=0}^{2^
n T - 1} \mathbb{E}\!\left[(B_{t_{j+1}} - B_{t_j})^2\right].$$

**How $\sum_j \mathbb{E}[(B_{t_{j+1}} - B_{t_j})^2] = T$ is obtained.** Using th
e variance of Gaussian increments from Step 3,
$$\sum_{j=0}^{2^n T - 1} \mathbb{E}\!\left[(B_{t_{j+1}} - B_{t_j})^2\right] = \s
um_{j=0}^{2^n T - 1} (t_{j+1} - t_j).$$
This is a **telescoping sum** of the partition lengths:
$$\sum_{j=0}^{2^n T - 1} (t_{j+1} - t_j) = t_{2^n T} - t_0 = T - 0 = T.$$

Equivalently, each of the $2^n T$ subintervals contributes $2^{-n}$, giving $2^n
 T \cdot 2^{-n} = T$. This is precisely the statement that the **quadratic varia
tion of Brownian motion on $[0,T]$ equals $T$** in expectation.

**Conclusion.**
$$\boxed{\mathbb{E}\!\left[\int_0^T \phi_2(t,\omega)\,dB_t(\omega)\right] = T.}$
$

**Remark on anticipativity.** Note that $\phi_2$ uses the *right*-endpoint value
 $B_{t_{j+1}}$, so it is **not** $\mathcal{F}_t$-adapted and the integral above
is not the Itô integral (for which the expectation would be $0$). The nonzero ex
pectation $T$ arises entirely from the quadratic-variation term $(\Delta B_j)^2$
; the cross term $B_{t_j}\,\Delta B_j$ vanishes by independence. This is the dis
crete precursor of the Itô–Stratonovich correction: evaluating the integrand at
the right endpoint rather than the left endpoint injects an extra $\tfrac{1}{2}\
langle B\rangle_T = \tfrac{T}{2}$ per "symmetric" convention, and the full right
-endpoint sum yields $T$.
