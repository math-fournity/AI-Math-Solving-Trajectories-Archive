# Solution

## Setup

Place the center of Zone Alpha at the origin $O_1 = (0,0)$ and the center of Zon
e Beta at $O_2 = (r, 0)$. Both circles have radius $r$ and their centers are $r$
 apart, so $\triangle O_1 O_2 A$ is equilateral.

**Intersection points:** Solving $x^2 + y^2 = r^2$ and $(x-r)^2 + y^2 = r^2$ giv
es $x = r/2$, $y = \pm r\sqrt{3}/2$. So:
$$A = \left(\tfrac{r}{2},\, \tfrac{r\sqrt{3}}{2}\right), \quad B = \left(\tfrac{
r}{2},\, -\tfrac{r\sqrt{3}}{2}\right), \quad |AB| = r\sqrt{3}$$

The drone $C = (r\cos\theta, r\sin\theta)$ traverses Zone Alpha. Point $A$ corre
sponds to $\theta = \pi/3$ and $B$ to $\theta = -\pi/3$. The function $f(C)$ is
the **incenter** of $\triangle ABC$ (center of the largest inscribed circle).

## Side Lengths

Using the chord formula on a circle of radius $r$:
- $|AC| = 2r\left|\sin\frac{\theta - \pi/3}{2}\right|$, $\quad |BC| = 2r\left|\s
in\frac{\theta + \pi/3}{2}\right|$

We split the circle into two arcs at $A$ and $B$.

## Arc 2: $\theta \in (\pi/3,\, 5\pi/3)$ (major arc, outside Zone Beta)

Both sine terms are positive, so $a = |BC| = 2r\sin\frac{\theta+\pi/3}{2}$, $b =
 |AC| = 2r\sin\frac{\theta-\pi/3}{2}$.

Using sum-to-product: $a + b = 2r\sqrt{3}\sin\frac{\theta}{2}$, $\;a - b = 2r\co
s\frac{\theta}{2}$.

The incenter $I = \frac{aA + bB + cC}{a+b+c}$ with $c = r\sqrt{3}$. Computing th
e numerator:

$$aA + bB = \left(\tfrac{(a+b)r}{2},\, \tfrac{(a-b)r\sqrt{3}}{2}\right) = \left(
r^2\sqrt{3}\sin\tfrac{\theta}{2},\; r^2\sqrt{3}\cos\tfrac{\theta}{2}\right)$$
$$cC = \left(r^2\sqrt{3}\cos\theta,\; r^2\sqrt{3}\sin\theta\right)$$

Denominator: $r\sqrt{3}(2\sin\frac{\theta}{2} + 1)$. Using $\cos\theta = 1 - 2\s
in^2\frac{\theta}{2}$ and $\sin\theta = 2\sin\frac{\theta}{2}\cos\frac{\theta}{2
}$, the numerators factor as:

$$x\text{-num} = (2\sin\tfrac{\theta}{2}+1)(1-\sin\tfrac{\theta}{2}), \quad y\te
xt{-num} = (2\sin\tfrac{\theta}{2}+1)\cos\tfrac{\theta}{2}$$

Canceling the common factor:

$$\boxed{I = r\left(1 - \sin\tfrac{\theta}{2},\; \cos\tfrac{\theta}{2}\right)}$$

Setting $u = \theta/2 \in (\pi/6, 5\pi/6)$, this is a **circle of radius $r$ cen
tered at $(r, 0)$**: $(x-r)^2 + y^2 = r^2$. The speed is $\left|\frac{dI}{du}\ri
ght| = r$, so:

$$\text{Arc 2 length} = \int_{\pi/6}^{5\pi/6} r\,du = \frac{2\pi r}{3}$$

## Arc 1: $\theta \in (-\pi/3,\, \pi/3)$ (minor arc, inside Zone Beta)

Here $|AC| = 2r\sin\frac{\pi/3 - \theta}{2}$ (sign flip). Setting $t = \theta/2
\in (-\pi/6, \pi/6)$:

$a + b = 2r\cos t$, $\;a - b = 2r\sqrt{3}\sin t$. Similar computation gives:

$$aA + bB = (r^2\cos t,\; 3r^2\sin t), \quad cC = (r^2\sqrt{3}\cos 2t,\; r^2\sqr
t{3}\sin 2t)$$

Denominator: $r(2\cos t + \sqrt{3})$. The numerators factor as:

$$x\text{-num} = (2\cos t + \sqrt{3})(\sqrt{3}\cos t - 1), \quad y\text{-num} =
\sqrt{3}\sin t\,(2\cos t + \sqrt{3})$$

Canceling:

$$\boxed{I = r\left(\sqrt{3}\cos t - 1,\; \sqrt{3}\sin t\right)}$$

This is a **circle of radius $r\sqrt{3}$ centered at $(-r, 0)$**: $(x+r)^2 + y^2
 = 3r^2$. The speed is $r\sqrt{3}$, so:

$$\text{Arc 1 length} = \int_{-\pi/6}^{\pi/6} r\sqrt{3}\,dt = \frac{\pi r\sqrt{3
}}{3}$$

## Continuity Check

- At $\theta = \pi/3$ ($C \to A$): Arc 2 gives $I = (r/2, r\sqrt{3}/2) = A$; Arc
 1 gives $I = (r/2, r\sqrt{3}/2) = A$. ✓
- At $\theta = 5\pi/3$ ($C \to B$): Arc 2 gives $I = (r/2, -r\sqrt{3}/2) = B$; A
rc 1 gives $I = (r/2, -r\sqrt{3}/2) = B$. ✓

The path is continuous and closed: $A \xrightarrow{\text{circle 1}} B \xrightarr
ow{\text{circle 2}} A$.

## Total Path Length

$$S = \frac{2\pi r}{3} + \frac{\pi r\sqrt{3}}{3} = \frac{(2 + \sqrt{3})\,r}{3}\,
\pi$$

For $S$ to be expressible as $\frac{a + b\sqrt{c}}{d}\pi$ with nonnegative integ
ers $a, b, c, d$, we take $r = 1$:

$$S = \frac{2 + 1\cdot\sqrt{3}}{3}\,\pi$$

**Verification of conditions:** $c = 3$ is square-free ✓, $\gcd(2, 1, 3) = 1$ ✓.

## Answer

$$a = 2,\quad b = 1,\quad c = 3,\quad d = 3$$
$$a + b + c + d = 2 + 1 + 3 + 3 = \boxed{9}$$
