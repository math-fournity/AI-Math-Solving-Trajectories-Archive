# Proof

**Yes.** An almost unital Banach algebra can always be renormed to become a unit
al Banach algebra.

## Setup and Definitions

Let $A$ be an almost unital Banach algebra: $A$ is a Banach algebra (Banach spac
e with associative multiplication satisfying $\|ab\| \le \|a\|\,\|b\|$) possessi
ng a multiplicative identity $e$ (so $ea = ae = a$ for all $a \in A$), but possi
bly with $\|e\| \ne 1$.

A *unital* Banach algebra requires $\|e\| = 1$ in addition to the above. The que
stion is whether an equivalent norm $\|\cdot\|'$ exists making $A$ a unital Bana
ch algebra.

**Note:** $\|e\| \ge 1$ always holds, since $\|e\| = \|e \cdot e\| \le \|e\|^2$
and $e \ne 0$.

## Construction via the Left Regular Representation

For each $a \in A$, let $L_a : A \to A$ denote left multiplication: $L_a(b) = ab
$. Since $\|L_a(b)\| = \|ab\| \le \|a\|\,\|b\|$, the operator $L_a$ is bounded w
ith $\|L_a\| \le \|a\|$.

Define the new norm:
$$\|a\|' := \|L_a\| = \sup_{\|b\| \le 1} \|ab\|.$$

## Verification

**1. $\|\cdot\|'$ is a norm.**
If $\|a\|' = 0$, then $L_a = 0$, so $ab = 0$ for all $b \in A$. Taking $b = e$ g
ives $a = ae = 0$. Homogeneity and the triangle inequality follow from linearity
 of $a \mapsto L_a$ and the operator norm properties.

**2. Submultiplicativity.**
$$\|ab\|' = \|L_{ab}\| = \|L_a \circ L_b\| \le \|L_a\|\,\|L_b\| = \|a\|'\,\|b\|'
.$$

**3. The identity has norm 1.**
$$\|e\|' = \|L_e\| = \|I\| = 1,$$
where $I$ is the identity operator on the Banach space $A$, which has operator n
orm $1$.

**4. Equivalence of norms.**

*Upper bound:*
$$\|a\|' = \sup_{\|b\| \le 1} \|ab\| \le \sup_{\|b\| \le 1} \|a\|\,\|b\| = \|a\|
.$$

*Lower bound:* Using $a = ae$ and $\|ae\| \le \|a\|'\,\|e\|$:
$$\|a\| = \|ae\| \le \|a\|'\,\|e\| \implies \|a\|' \ge \frac{\|a\|}{\|e\|}.$$

Combining:
$$\frac{1}{\|e\|}\|a\| \le \|a\|' \le \|a\| \quad \text{for all } a \in A.$$

Since $\|e\|$ is a fixed finite constant, $\|\cdot\|'$ and $\|\cdot\|$ are equiv
alent norms.

**5. Completeness.**
Because $\|\cdot\|'$ is equivalent to $\|\cdot\|$ and $A$ is complete under $\|\
cdot\|$, the space $A$ is complete under $\|\cdot\|'$.

## Conclusion

$(A, \|\cdot\|')$ is a Banach algebra (submultiplicative norm, complete) with id
entity $e$ satisfying $\|e\|' = 1$. Hence it is a **unital Banach algebra**.

The answer is **yes**: every almost unital Banach algebra admits an equivalent n
orm under which it becomes a unital Banach algebra. The renorming is given expli
citly by the left regular representation $\|a\|' = \|L_a\|$.
