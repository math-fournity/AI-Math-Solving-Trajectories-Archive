Define two metrics on $\mathbb{R}$:

- $d(x,y) = |x - y|$ (the usual Euclidean metric),
- $d'(x,y) = |\arctan x - \arctan y|$.

### Step 1. $d'$ is a metric.

The function $\arctan : \mathbb{R} \to (-\pi/2, \pi/2)$ is injective. Since $d'$
 is the pullback of the Euclidean metric on $(-\pi/2,\pi/2)$ through an injectiv
e map, it inherits non-negativity, symmetry, the triangle inequality, and defini
teness ($d'(x,y)=0 \iff \arctan x = \arctan y \iff x = y$). Hence $d'$ is a metr
ic.

### Step 2. $d$ and $d'$ induce the same topology.

The map $\arctan : \mathbb{R} \to (-\pi/2, \pi/2)$ is a homeomorphism (it is con
tinuous with continuous inverse $\tan$). A set $U \subseteq \mathbb{R}$ is $d'$-
open iff $\arctan(U)$ is open in $(-\pi/2,\pi/2)$ (with the subspace topology fr
om $\mathbb{R}$) iff $U = \arctan^{-1}(V)$ for some open $V \subseteq (-\pi/2,\p
i/2)$, which (since $\arctan$ is a homeomorphism) is exactly the condition that
$U$ is open in the usual topology. Thus the two metrics generate the same topolo
gy.

### Step 3. $(\mathbb{R}, d)$ is complete.

This is the standard fact that $\mathbb{R}$ with the Euclidean metric is complet
e.

### Step 4. $(\mathbb{R}, d')$ is **not** complete.

Consider the sequence $x_n = n$. Then
$$d'(x_n, x_m) = |\arctan n - \arctan m|.$$
Since $\arctan n \to \pi/2$ as $n \to \infty$, the sequence $\{\arctan n\}$ is C
auchy in $\mathbb{R}$, hence $\{x_n\}$ is $d'$-Cauchy.

Suppose for contradiction that $x_n \to L$ in $(\mathbb{R}, d')$ for some $L \in
 \mathbb{R}$. Then $d'(x_n, L) = |\arctan n - \arctan L| \to 0$, so $\arctan n \
to \arctan L$. But $\arctan n \to \pi/2$, giving $\arctan L = \pi/2$, which is i
mpossible since $\arctan$ takes values strictly in $(-\pi/2, \pi/2)$. Contradict
ion.

Therefore $\{x_n\}$ is a $d'$-Cauchy sequence with no $d'$-limit in $\mathbb{R}$
, so $(\mathbb{R}, d')$ is not complete.

### Conclusion.

The metrics $d(x,y) = |x-y|$ and $d'(x,y) = |\arctan x - \arctan y|$ induce the
same topology on $\mathbb{R}$, yet $\mathbb{R}$ is complete under $d$ and not co
mplete under $d'$.
