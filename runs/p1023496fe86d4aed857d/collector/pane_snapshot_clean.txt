## Analysis via the Chinese Remainder Theorem

**Key observation:** $U_n + k = U_n$ iff for every $a$ coprime to $n$, $a+k$ is
also coprime to $n$.

Let $n = p_1^{e_1} \cdots p_r^{e_r}$. By CRT, $\mathbb{Z}/n\mathbb{Z} \cong \pro
d_i \mathbb{Z}/p_i^{e_i}\mathbb{Z}$, and $U_n$ corresponds to the product of the
 $U_{p_i^{e_i}}$. Translation by $k$ acts componentwise, so:

$$U_n + k = U_n \iff U_{p_i^{e_i}} + k_i = U_{p_i^{e_i}} \text{ for all } i$$

where $k_i = k \bmod p_i^{e_i}$.

**Prime power case:** In $\mathbb{Z}/p^e\mathbb{Z}$, the non-units are exactly t
he multiples of $p$ (a subgroup). Translation by $k$ preserves the set of units
iff it preserves the complement (the multiples of $p$), which happens iff $k$ is
 itself a multiple of $p$, i.e., $p \mid k$.

**Combining:** $U_n + k = U_n$ iff $p_i \mid k$ for every prime $p_i \mid n$, i.
e., $\operatorname{rad}(n) \mid k$, where $\operatorname{rad}(n) = p_1 \cdots p_
r$.

## Stability criterion

The set of shifts preserving $U_n$ is $H = \{k \in \{0,\ldots,n-1\} : \operatorn
ame{rad}(n) \mid k\}$.

- If $n$ is **squarefree**: $\operatorname{rad}(n) = n$, so $H = \{0\}$. No nonz
ero shift preserves $U_n$. **Stable.**
- If $n$ is **not squarefree**: $\operatorname{rad}(n) < n$, so $k = \operatorna
me{rad}(n) \in \{1,\ldots,n-1\}$ lies in $H$. **Not stable.**

($n=1$: $\mathbb{N}_1 = \emptyset$, condition is vacuous; $1$ is squarefree. Sta
ble.)

**Conclusion:** $n$ is stable $\iff$ $n$ is squarefree.
