# Problem

In a specialized logistics hub, a cargo manager is processing exactly 1,200 standard shipping containers. Within this fleet, there are a series of "fractional crates" identified by the codes $n/1000$, where $n$ represents every positive integer less than 1,000.

The manager’s protocol requires three distinct steps for each of these 999 crates:
1.  **Standardization:** The fractional code $n/1000$ must be reduced to its simplest form (lowest terms).
2.  **Indexing:** For each reduced fraction, the manager calculates a "Priority Value" by adding the resulting numerator and the resulting denominator together.
3.  **Inventory Check:** The manager then records every unique Priority Value generated by this process.

How many different Priority Values are recorded in the manager's final inventory?
