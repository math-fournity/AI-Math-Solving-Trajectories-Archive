No. The claim is false. A monotone map on a complete lattice that fixes both bou
nds need not fix every element.

**Counterexample.**

Let $X = \{\bot, a, \top\}$ be the three-element chain
$$\bot \le a \le \top,$$
which is a complete lattice (every subset has a join and meet: the join of a sub
set is its maximum, the meet its minimum).

Define $f: X \to X$ by
$$f(\bot) = \bot, \qquad f(a) = \top, \qquad f(\top) = \top.$$

**$f$ is monotonic.** We check the two nontrivial comparable pairs:

- $\bot \le a$: $f(\bot) = \bot \le \top = f(a)$. ✓
- $a \le \top$: $f(a) = \top \le \top = f(\top)$. ✓

(The pairs $\bot \le \top$ and the reflexive pairs are immediate.)

**Both bounds are fixed points.** $f(\bot) = \bot$ and $f(\top) = \top$. ✓

**But $a$ is not a fixed point.** $f(a) = \top \ne a$.

Hence $X \ne \{x \in X : f(x) = x\}$, since $a \in X$ but $a \notin \{x \in X :
f(x) = x\}$.

**Remark.** The intuition one might have — that fixing the extremes forces a mon
otone map to be the identity — is wrong. Monotonicity only constrains $f$ to pre
serve order; it does not prevent $f$ from "jumping up" over intermediate element
s. The Knaster–Tarski theorem guarantees that the set of fixed points of a monot
one map on a complete lattice is itself a (nonempty) complete lattice, but it pl
aces no requirement that this fixed-point lattice equal $X$. In the example abov
e, the fixed-point lattice is the two-element sublattice $\{\bot, \top\}$, which
 is complete but is a proper subset of $X$.
