## Proof

We show that $f(\tau, x)$ depends only on $\tau^2 + x^2$, hence is $SO(2)$-invar
iant.

**Step 1: Substitution.** Set $p = \sinh\theta$, so $\sqrt{p^2+1} = \cosh\theta$
 and $dp = \cosh\theta\,d\theta$. Then $\frac{dp}{\sqrt{p^2+1}} = d\theta$, and

$$f(\tau,x) = \int_{-\infty}^{+\infty} d\theta\; e^{-\tau\cosh\theta + ix\sinh\t
heta}.$$

**Step 2: Rewrite the exponent.** Let $R = \sqrt{\tau^2+x^2}$ (well-defined and
positive since $\tau>0$). Define $\phi$ by
$$\cos\phi = \frac{\tau}{R}, \qquad \sin\phi = \frac{x}{R}.$$
Since $\tau > 0$, we have $\cos\phi > 0$, so $\phi \in (-\pi/2,\,\pi/2)$. Then
$$\tau\cosh\theta - ix\sinh\theta = R\bigl(\cos\phi\cosh\theta - i\sin\phi\sinh\
theta\bigr) = R\cosh(\theta - i\phi),$$
using $\cosh(a-b) = \cosh a\cos b - \sinh a\sin b$ with $b = i\phi$ (so $\cos(i\
phi)=\cos\phi$, $\sin(i\phi)=i\sin\phi$). Therefore
$$f(\tau,x) = \int_{-\infty}^{+\infty} d\theta\; e^{-R\cosh(\theta - i\phi)}.$$

**Step 3: Contour shift.** We shift the integration contour from $\operatorname{
Im}\theta = 0$ to $\operatorname{Im}\theta = -\phi$ (i.e., substitute $\theta \m
apsto \theta + i\phi$). Consider the rectangle with vertices $-A,\; A,\; A-i\phi
,\; -A-i\phi$. The integrand $g(\theta)=e^{-R\cosh\theta}$ is entire, so by Cauc
hy's theorem the contour integral vanishes. It remains to check the vertical sid
es vanish as $A\to\infty$.

On the right side, $\theta = A - is$ for $s\in[0,\phi]$ (WLOG $\phi\geq 0$):
$$\operatorname{Re}\cosh(A-is) = \cosh A\cos s.$$
Since $|\phi|<\pi/2$ and $s\in[0,\phi]$, we have $\cos s \geq \cos\phi = \tau/R
> 0$. Hence
$$|e^{-R\cosh(A-is)}| = e^{-R\cosh A\cos s} \leq e^{-\tau\cosh A} \to 0 \quad\te
xt{as } A\to\infty,$$
and the vertical integral is bounded by $\phi\cdot e^{-\tau\cosh A}\to 0$. The l
eft side is identical. Thus the shift is valid:

$$f(\tau,x) = \int_{-\infty}^{+\infty} d\theta\; e^{-R\cosh\theta}.$$

**Step 4: Evaluate.** The integrand is even in $\theta$, so
$$f(\tau,x) = 2\int_0^{\infty} d\theta\; e^{-R\cosh\theta} = 2K_0(R) = 2K_0\!\le
ft(\sqrt{\tau^2+x^2}\right),$$
where $K_0(z)=\int_0^\infty e^{-z\cosh t}\,dt$ is the modified Bessel function (
valid for $\operatorname{Re}z>0$, and $R>0$).

**Conclusion.** Since $f(\tau,x) = 2K_0\!\left(\sqrt{\tau^2+x^2}\right)$ depends
 only on $\tau^2+x^2$, the function is invariant under $SO(2)$ rotations of the
$(\tau,x)$ plane. $\blacksquare$
