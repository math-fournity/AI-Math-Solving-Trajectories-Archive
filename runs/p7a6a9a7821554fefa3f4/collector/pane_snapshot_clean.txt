### Setup

We need $V(t) = at^3 + bt$ to be a permutation modulo $2013$ for $t = 1, 2, \ldo
ts, 2013$. Since $2013 = 3 \times 11 \times 61$, by CRT this holds iff $f(t) = a
t^3 + bt$ is a permutation modulo each of $3, 11, 61$.

Note $\{1, \ldots, 2013\}$ covers every residue class mod $2013$ exactly once, s
o the count of valid $(a,b)$ pairs equals the count of valid $(a \bmod 2013,\; b
 \bmod 2013)$ pairs, which by CRT is the product of the counts mod each prime.

### Collision condition

$f(t_1) \equiv f(t_2) \pmod{p}$ with $t_1 \neq t_2$ gives
$$(t_1 - t_2)\bigl[a(t_1^2 + t_1 t_2 + t_2^2) + b\bigr] \equiv 0 \pmod{p}.$$
Setting $t_2 = t_1 + h$ ($h \neq 0$) and completing the square:
$$a\bigl(3(t_1 + h/2)^2 + h^2/4\bigr) + b \equiv 0.$$
Writing $u = t_1 + h/2$, $v = h/2 \neq 0$, the condition for **no** collision is
:

> For all $u \in \mathbb{F}_p$ and $v \in \mathbb{F}_p^*$: $\;a(3u^2 + v^2) + b
\not\equiv 0$.

**Case $a \equiv 0 \pmod{p}$:** Then $f(t) = bt$, a permutation iff $b \not\equi
v 0 \pmod{p}$.

**Case $a \not\equiv 0 \pmod{p}$:** Set $c = -b/a$. We need $c \neq 3u^2 + v^2$
for all $u$, all $v \neq 0$. Equivalently, for every $w \in \{3u^2 : u \in \math
bb{F}_p\}$, the value $c - w$ is **not** a nonzero quadratic residue.

### Prime $p = 3$

Here $3 \equiv 0$, so $\{3u^2\} = \{0\}$. The condition reduces to $c \notin \te
xt{QR}^* = \{1\}$, i.e. $c \in \{0, 2\}$.

- $a \equiv 0$: $b \not\equiv 0$ → **2 choices**.
- $a \not\equiv 0$: $c = 0$ gives $b \equiv 0$; $c = 2$ gives $b \equiv a \pmod{
3}$ → **2 choices each**.

**Total mod 3:** $1 \times 2 + 2 \times 2 = \mathbf{6}$.

### Prime $p = 11$

Here $3$ is a QR ($5^2 \equiv 3$), so $\{3u^2\} = \{0\} \cup \text{QR}^* =: A$ w
ith $|A| = 6$. We need $c - A \subseteq B := \{0\} \cup \text{NQR}^*$ with $|B|
= 6$, forcing $c - A = B$.

Since $11 \equiv 3 \pmod{4}$, $-1$ is a NQR, so $-\text{QR}^* = \text{NQR}^*$. T
hen $c = 0$ gives $-A = \{0\} \cup \text{NQR}^* = B$. ✓

For $c \in \text{QR}^*$: $c \in A$ so $0 \in c-A$, but also $c \in \text{QR}^* \
cap (c-A)$, requiring $c \in B$, contradiction. For $c \in \text{NQR}^*$: $c \no
tin A$ so $0 \notin c-A \neq B$. So **only $c = 0$** works.

- $a \equiv 0$: $b \not\equiv 0$ → **10 choices**.
- $a \not\equiv 0$: $b \equiv 0$ → **1 choice each**.

**Total mod 11:** $1 \times 10 + 10 \times 1 = \mathbf{20}$.

### Prime $p = 61$

Again $3$ is a QR ($61 \equiv 1 \pmod{12}$), so $\{3u^2\} = A$ with $|A| = 31$,
and we need $c - A = B$ with $|B| = 31$.

But $61 \equiv 1 \pmod{4}$, so $-1$ is a **QR**, giving $-\text{QR}^* = \text{QR
}^*$.

- $c = 0$: $-A = \{0\} \cup \text{QR}^* = A \neq B$. ✗
- $c \in \text{QR}^*$: $0 \in c-A$ and $c \in c-A \cap \text{QR}^*$, forcing $c
\in B$, contradiction. ✗
- $c \in \text{NQR}^*$: $0 \notin c-A$ so $c-A \neq B$. ✗

**No valid $c$** when $a \not\equiv 0 \pmod{61}$.

- $a \equiv 0$: $b \not\equiv 0$ → **60 choices**.
- $a \not\equiv 0$: **0 choices**.

**Total mod 61:** $1 \times 60 = \mathbf{60}$.

### Verification of key cases

- **Mod 11, $a=1, b=1$ (bad):** $f(1)=2,\; f(4)=64+4=68\equiv 2$. Collision ✓
- **Mod 61, $a=1, b=1$ (bad):** $-1$ is QR so $\exists\, t\neq 0: t^2=-1$, givin
g $f(t)=t(t^2+1)=0=f(0)$. Collision ✓
- **Mod 61, $a=1, b=59$ ($c=2\in\text{NQR}^*$, bad):** $3u^2+v^2=2$ has solution
 $u\cdot s=1, v=1$ (since $3=s^2$), collision ✓
- **Mod 3, $a=1, b=1$ (good):** $f(0)=0, f(1)=2, f(2)=10\equiv 1$. Permutation ✓

### Final count

By CRT, the total number of valid pairs is:
$$6 \times 20 \times 60 = \boxed{7200}$$
