## Proof

We seek all $x \in [0, 2\pi]$ such that $\cos(2^n x) < 0$ for every positive int
eger $n$.

**Reduction to the doubling map.** Write $x = 2\pi\alpha$ with $\alpha \in [0,1]
$. Then $\cos(2^n x) = \cos(2\pi \cdot 2^n\alpha)$, and $\cos(2\pi\beta)<0$ iff
the fractional part $\{\beta\}\in(1/4,\,3/4)$. Thus the condition becomes:

$$\{2^n\alpha\}\in\left(\tfrac14,\tfrac34\right)\quad\text{for all }n\geq 1.$$

**Binary expansion analysis.** Let $\alpha = 0.d_1 d_2 d_3\dots$ in binary (the
solutions we find will be non-dyadic, so the expansion is unique). Then $\{2^n\a
lpha\} = 0.d_{n+1}d_{n+2}d_{n+3}\dots\,$. The first two bits of this expansion d
etermine which quarter the value lies in:

- $(d_{n+1},d_{n+2})=(0,0)$: value $\in[0,\tfrac14]$ — **excluded**.
- $(d_{n+1},d_{n+2})=(1,1)$: value $\in[\tfrac34,1)$ — **excluded**.
- $(d_{n+1},d_{n+2})=(0,1)$: value $\in[\tfrac14,\tfrac12)$ — works unless value
 $=\tfrac14$ exactly.
- $(d_{n+1},d_{n+2})=(1,0)$: value $\in[\tfrac12,\tfrac34)$ — always works.

For the condition to hold for **every** $n\geq 1$, every consecutive pair $(d_{n
+1},d_{n+2})$ with $n\geq 1$ — i.e. every pair $(d_k,d_{k+1})$ with $k\geq 2$ —
must be $(0,1)$ or $(1,0)$. This forces

$$d_k \neq d_{k+1}\quad\text{for all }k\geq 2,$$

so the digits from position 2 onward **strictly alternate**. The only freedom is
 $d_1\in\{0,1\}$ and whether $d_2=0$ or $d_2=1$, giving exactly four candidates.

**Computing the four values.** Under strict alternation, each tail $0.d_{n+1}d_{
n+2}\dots$ is either $0.\overline{01}_2=\tfrac13$ or $0.\overline{10}_2=\tfrac23
$, both strictly inside $(\tfrac14,\tfrac34)$ — so no boundary exclusion occurs.
 The four candidates are:

| $d_1$ | tail from $d_2$ | $\alpha$ |
|---|---|---|
| $0$ | $010101\dots$ | $\sum_{k\geq3,\,k\text{ odd}}2^{-k}=\frac{1/8}{3/4}=\fra
c16$ |
| $1$ | $010101\dots$ | $\frac12+\frac16=\frac23$ |
| $0$ | $101010\dots$ | $\sum_{k\geq2,\,k\text{ even}}2^{-k}=\frac{1/4}{3/4}=\fr
ac13$ |
| $1$ | $101010\dots$ | $\frac12+\frac13=\frac56$ |

Hence $\alpha\in\{\tfrac16,\tfrac13,\tfrac23,\tfrac56\}$, giving

$$x\in\left\{\frac{\pi}{3},\,\frac{2\pi}{3},\,\frac{4\pi}{3},\,\frac{5\pi}{3}\ri
ght\}.$$

**Verification.** For each of these, $2^n x \equiv \pm\tfrac{2\pi}{3}\pmod{2\pi}
$ for all $n\geq 1$ (since $2^n\cdot\frac{1}{3}$ and $2^n\cdot\frac{2}{3}$ reduc
e to $\frac{2}{3}$ or $\frac{4}{3}$ modulo $2$), so $\cos(2^n x)=-\tfrac12<0$ fo
r every $n$. ✓

**Sum.**

$$\frac{\pi}{3}+\frac{2\pi}{3}+\frac{4\pi}{3}+\frac{5\pi}{3}=\frac{12\pi}{3}=4\p
i.$$
