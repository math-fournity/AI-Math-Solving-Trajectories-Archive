## Solution

We compute the Lie bracket $[X,Y] = XY - YX$ using the component formula. In coo
rdinates $(x,y,z)$, write

$$X = X^x\partial_x + X^y\partial_y + X^z\partial_z = -y\,\partial_x + x\,\parti
al_y + 0\,\partial_z,$$
$$Y = Y^x\partial_x + Y^y\partial_y + Y^z\partial_z = z\,\partial_x + 0\,\partia
l_y + x\,\partial_z.$$

The $i$-th component of the Lie bracket is

$$[X,Y]^i = X(Y^i) - Y(X^i) = \sum_j X^j\partial_j Y^i - \sum_j Y^j\partial_j X^
i.$$

**$x$-component:**
$$X(Y^x) = X(z) = (-y)\partial_x z + (x)\partial_y z + 0\cdot\partial_z z = 0,$$
$$Y(X^x) = Y(-y) = (z)\partial_x(-y) + 0\cdot\partial_y(-y) + (x)\partial_z(-y)

Hence $[X,Y]^x = 0 - 0 = 0$.

**$y$-component:**
$$X(Y^y) = X(0) = 0,$$
$$Y(X^y) = Y(x) = (z)\partial_x x + 0\cdot\partial_y x + (x)\partial_z x = z\cdo

Hence $[X,Y]^y = 0 - z = -z$.

$$X(Y^z) = X(x) = (-y)\partial_x x + (x)\partial_y x + 0\cdot\partial_z x = -y\c

$$Y(X^z) = Y(0) = 0.$$
Hence $[X,Y]^z = -y - 0 = -y$.
