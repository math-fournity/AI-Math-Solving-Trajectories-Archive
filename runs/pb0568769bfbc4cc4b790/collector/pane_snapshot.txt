Looking at this problem, I need to find the minimum of $d_1^2 + d_2^2 + d_3^2 +
d_4^2$ where $d_i$ are distances from the nine-point center $N$ to the incenter
$I$ and three excenters $I_A, I_B, I_C$.

## Proof

**Step 1: Apply Feuerbach's Theorem.**

The nine-point circle has center $N$ and radius $R/2$. By Feuerbach's theorem, t
he nine-point circle is internally tangent to the incircle and externally tangen
t to each excircle. Therefore:

$$d_1 = NI = \frac{R}{2} - r, \qquad d_2 = NI_A = \frac{R}{2} + r_A, \qquad d_3
= NI_B = \frac{R}{2} + r_B, \qquad d_4 = NI_C = \frac{R}{2} + r_C$$

where $r$ is the inradius and $r_A, r_B, r_C$ are the exradii.

**Step 2: Expand the sum.**

$$S = \left(\frac{R}{2}-r\right)^2 + \left(\frac{R}{2}+r_A\right)^2 + \left(\fra
c{R}{2}+r_B\right)^2 + \left(\frac{R}{2}+r_C\right)^2$$

$$= R^2 + R(r_A+r_B+r_C - r) + (r^2 + r_A^2+r_B^2+r_C^2)$$

**Step 3: Use standard identities.**

The following are well-known (verified via $r_X = \Delta/(s-X)$ and $\Delta^2 =
s(s-a)(s-b)(s-c)$):

- **Identity 1:** $r_A + r_B + r_C = 4R + r$, so $r_A + r_B + r_C - r = 4R$.
- **Identity 2:** $r_A r_B + r_B r_C + r_C r_A = s^2$.
- **Identity 3:** $ab + bc + ca = s^2 + r^2 + 4Rr$.

From Identities 1–2:
$$r_A^2 + r_B^2 + r_C^2 = (4R+r)^2 - 2s^2 = 16R^2 + 8Rr + r^2 - 2s^2$$

So:
$$S = R^2 + 4R^2 + r^2 + 16R^2 + 8Rr + r^2 - 2s^2 = 5R^2 + (r^2 + r_A^2+r_B^2+r_
C^2)$$
$$= 21R^2 + 8Rr + 2r^2 - 2s^2$$

**Step 4: Eliminate $s^2$ and $r$.**

From Identity 3: $4s^2 = (a+b+c)^2 = (a^2+b^2+c^2) + 2(ab+bc+ca) = (a^2+b^2+c^2)
 + 2(s^2+r^2+4Rr)$, giving:

$$2s^2 = (a^2+b^2+c^2) + 2r^2 + 8Rr$$

Substituting:

$$S = 21R^2 + 8Rr + 2r^2 - (a^2+b^2+c^2) - 2r^2 - 8Rr = 21R^2 - (a^2+b^2+c^2)$$

**Step 5: Apply the sine-squared inequality.**

Since $a = 2R\sin A$ etc.:

$$a^2+b^2+c^2 = 4R^2(\sin^2 A + \sin^2 B + \sin^2 C)$$

Using the identity (for $A+B+C=\pi$):
$$\cos 2A + \cos 2B + \cos 2C = -1 - 4\cos A\cos B\cos C$$

we get:
$$\sin^2 A + \sin^2 B + \sin^2 C = \frac{3 - (\cos 2A+\cos 2B+\cos 2C)}{2} = 2 +
 2\cos A\cos B\cos C$$

We need $\cos A\cos B\cos C \leq \frac{1}{8}$:

- **Obtuse triangle:** one cosine is negative, so the product is negative $< 1/8
$. ✓
- **Acute triangle:** all cosines positive. By Jensen's inequality ($\cos$ is co
ncave on $(0,\pi/2)$):
$$\frac{\cos A + \cos B + \cos C}{3} \leq \cos\!\left(\frac{A+B+C}{3}\right) = \
cos\frac{\pi}{3} = \frac{1}{2}$$

By AM-GM: $\cos A\cos B\cos C \leq \left(\frac{\cos A+\cos B+\cos C}{3}\right)^3
 \leq \left(\frac{1}{2}\right)^3 = \frac{1}{8}$.

Therefore:
$$\sin^2 A + \sin^2 B + \sin^2 C \leq 2 + 2\cdot\frac{1}{8} = \frac{9}{4}$$

with equality if and only if $A = B = C = \frac{\pi}{3}$ (equilateral triangle).

**Step 6: Conclude.**

$$S = 21R^2 - 4R^2(\sin^2 A+\sin^2 B+\sin^2 C) \geq 21R^2 - 4R^2\cdot\frac{9}{4}
 = 21R^2 - 9R^2 = 12R^2$$

**Verification at equality (equilateral triangle):** Here $N = I$ (all centers c
oincide), so $d_1 = 0$. Each exradius $r_A = r_B = r_C = \frac{3R}{2}$, giving $
d_2 = d_3 = d_4 = \frac{R}{2}+\frac{3R}{2} = 2R$. Thus $S = 0 + 3\cdot(2R)^2 = 1
2R^2$. ✓

The minimum value is $\boxed{12R^2}$.
