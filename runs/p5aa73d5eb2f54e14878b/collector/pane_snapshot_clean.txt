## Solution

**Answer:** The sequence is eventually constant if and only if $A$ is a perfect
square.

### Proof

Write any non-negative integer $n$ uniquely as $n = m^2 + r$, where $m = \lfloor
\sqrt{n}\rfloor \geq 0$ and $0 \le r \le 2m$. Then $S(n) = r$.

The sequence satisfies $a_{k+1} = a_k + S(a_k)$. It is eventually constant if an
d only if for some $K$, $S(a_K)=0$, i.e., $a_K$ is a perfect square (after which
 $a_{k+1}=a_k$ forever).

**Key observation.** Suppose $a_k = m^2 + r$ with $0 \le r \le 2m$. Then $a_{k+1
} = m^2 + 2r$. We determine the new remainder:

- **Case 1: $0 \le r \le m$.** Then $m^2 \le m^2+2r \le m^2+2m < (m+1)^2$, so th
e floor of the square root is still $m$, and the new remainder is $r' = 2r$.

- **Case 2: $m < r \le 2m$.** Then $m^2+2r \ge m^2+2m+2 > (m+1)^2$. Also $m^2+2r
 \le m^2+4m < m^2+4m+4 = (m+2)^2$. So the new floor is $m' = m+1$, and the new r
emainder is $r' = (m^2+2r)-(m+1)^2 = 2r - 2m - 1$.

**Critical claim:** If $r > 0$, then $r' > 0$.

- In Case 1: $r' = 2r \ge 2 > 0$.
- In Case 2: $r' = 2r - 2m - 1$. Since $r \ge m+1$, we get $r' \ge 2(m+1) - 2m -
 1 = 1 > 0$.

Also, in both cases $r' \le 2m'$ (in Case 1, $r' = 2r \le 2m = 2m'$; in Case 2,
$r' = 2r-2m-1 \le 2(2m)-2m-1 = 2m-1 \le 2(m+1) = 2m'$), so the representation re
mains valid.

**Conclusion.** If $A = m^2$ is a perfect square, then $r_0 = 0$, so $S(A)=0$ an
d the sequence is constant from the start.

If $A$ is not a perfect square, then $r_0 > 0$, and by the claim, every subseque
nt remainder $r_k > 0$ for all $k$. Hence $S(a_k) = r_k > 0$ for all $k$, so $a_
{k+1} > a_k$ strictly for all $k$, and the sequence is strictly increasing—never
 constant.

Therefore the sequence is eventually constant **if and only if $A$ is a perfect
square**.
