Looking at the recurrence $a_k \cdot a_{k+2} = a_{k+1}+1$, i.e. $a_{k+2} = (a_{k
+1}+1)/a_k$, with $a_1=a, a_2=b$ positive integers.

- $a_3 = (b+1)/a$
- $a_4 = \dfrac{a_3+1}{b} = \dfrac{(b+1)/a+1}{b} = \dfrac{a+b+1}{ab}$
- $a_5 = \dfrac{a_4+1}{a_3} = \dfrac{\frac{a+b+1}{ab}+1}{\frac{b+1}{a}} = \dfrac
{ab+a+b+1}{ab}\cdot\dfrac{a}{b+1} = \dfrac{(a+1)(b+1)}{b(b+1)} = \dfrac{a+1}{b}$
- $a_6 = \dfrac{a_5+1}{a_4} = \dfrac{\frac{a+1}{b}+1}{\frac{a+b+1}{ab}} = \dfrac
{a+b+1}{b}\cdot\dfrac{ab}{a+b+1} = a$
- $a_7 = \dfrac{a_6+1}{a_5} = \dfrac{a+1}{(a+1)/b} = b$

**The sequence is periodic with period 5:** $a_6=a_1,\; a_7=a_2$, and the recurr
ence then repeats identically.

**Indexing:** $2014 = 5\cdot 402 + 4$, so $a_{2014} = a_4 = \dfrac{a+b+1}{ab}$.

**Positivity check:** Since $a,b>0$, every term $a_3,a_4,a_5$ is automatically p

**Maximizing** $\dfrac{a+b+1}{ab} = \dfrac{1}{a}+\dfrac{1}{b}+\dfrac{1}{ab}$:

This is strictly decreasing in both $a$ and $b$ (for positive integers), so the

$$a_{2014} = \frac{1+1+1}{1\cdot 1} = 3.$$
