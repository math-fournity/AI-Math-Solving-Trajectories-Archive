- $A = 2B$
- $C > 90°$
- $a, b, c \in \mathbb{Z}^+$

Since $A + B + C = 180°$, we get $3B + C = 180°$, so $C = 180° - 3B$. The condit

**Deriving side ratios.** By the Law of Sines, $a : b : c = \sin A : \sin B : \s
in C$. With $A = 2B$ and $C = 180° - 3B$:

$$a : b : c = \sin 2B : \sin B : \sin 3B = 2\sin B\cos B : \sin B : \sin B(4\cos

Setting $t = 2\cos B$, the ratio becomes:

$$a : b : c = t : 1 : t^2 - 1$$

Since $0 < B < 30°$, we have $\cos B \in (\cos 30°, 1) = (\sqrt{3}/2, 1)$, so $t

**Integer side condition.** Let $b = n$ (positive integer). Then $a = nt$ and $c

Writing $d = \gcd(n, p)$, $n = dm$, $p = dq$ with $\gcd(m, q) = 1$, the conditio

$$(a, b, c) = s \cdot (mq,\; m^2,\; q^2 - m^2)$$

with $\gcd(m, q) = 1$ and $\sqrt{3} < q/m < 2$.
