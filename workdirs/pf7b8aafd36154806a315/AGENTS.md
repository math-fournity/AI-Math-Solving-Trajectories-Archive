# Problem

In a futuristic data-transmission facility, a central computer generates streams of integer signals from the set $\{1, 2, \ldots, n\}$. For any positive real-valued "frequency" $\beta$, a filtered sequence is generated by the rule $\lfloor \beta m \rfloor$ for all positive integers $m$. We define $K_\beta$ as the set of all integers produced by this rule.

For a given network capacity $n$, a "representative subset" $S \subseteq \{1, 2, \ldots, n\}$ is defined as a set with the following property: for any frequency $\beta > 0$, if every signal in $S$ is contained within the sequence $K_\beta$, then the entire range of signals $\{1, 2, \ldots, n\}$ must also be contained within $K_\beta$.

Let $f(n)$ represent the minimum possible number of signals required to form such a representative subset $S$ for a given capacity $n$. 

Calculate the total sum of these minimum requirements as the capacity $n$ ranges from 1 to 100:
\[ \sum_{n=1}^{100} f(n) \]
