## Proof

the drift of $M_t$ vanishes (a necessary and sufficient condition for an Itô pro
cess to be a local martingale, and necessary for it to be a true martingale).

**Itô decomposition of $3W_t^4$.** With $f(x)=3x^4$: $f'(x)=12x^3$, $f''(x)=36x^
2$, so
$$d(3W_t^4) = 12W_t^3\,dW_t + \tfrac12\cdot 36 W_t^2\,dt = 12W_t^3\,dW_t + 18W_t
^2\,dt.$$

**Itô decomposition of $\alpha t^2 W_t^2$.** With $g(t,x)=\alpha t^2 x^2$:
$$g_t = 2\alpha t\,x^2,\qquad g_x = 2\alpha t^2 x,\qquad g_{xx}=2\alpha t^2.$$
Hence
$$d(\alpha t^2 W_t^2) = 2\alpha t\,W_t^2\,dt + 2\alpha t^2 W_t\,dW_t + \alpha t^
2\,dt.$$

**Total drift and diffusion.**
$$dM_t = \underbrace{\bigl[(18+2\alpha t)\,W_t^2 + \alpha t^2\bigr]}_{\text{drif
t}}dt \;+\; \underbrace{\bigl(12W_t^3 + 2\alpha t^2 W_t\bigr)}_{\text{diffusion}
}dW_t.$$

For $M_t$ to be a (local) martingale, the drift must vanish almost surely for ev
ery $t\ge 0$:
$$(18+2\alpha t)\,W_t^2 + \alpha t^2 = 0 \quad \text{a.s., for all } t\ge 0. \ta
g{$\ast$}$$

**Checking $t=0$.** At $t=0$: $(18+0)\cdot 0 + 0 = 0$. ✓ (automatic, since $W_0=
0$).

**Checking any $t>0$.** At a fixed $t>0$, $W_t\sim N(0,t)$, so $W_t^2$ has a con

$$(18+2\alpha t)\,W_t^2 = -\alpha t^2 \quad \text{a.s.}$$
The right-hand side is a deterministic constant, while the left-hand side is a s

1. $18 + 2\alpha t = 0 \;\Longrightarrow\; \alpha = -\dfrac{9}{t}$, and

$$\mathbb{E}[M_t] = 3\cdot 3t^2 + \alpha t^2\cdot t = 9t^2 + \alpha t^3 = t^2(9+
