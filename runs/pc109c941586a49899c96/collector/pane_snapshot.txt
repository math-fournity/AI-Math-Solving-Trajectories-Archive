## Proof

**Answer: Yes, such a field exists.**

**Key observation.** In a field $K$ of characteristic $2$, the Frobenius map $x
\mapsto x^2$ is a ring homomorphism, so for any polynomial $h \in K[T]$,
$$(h+1)^2 = h^2 + 2h + 1 = h^2 + 1,$$
since $2h = 0$ in characteristic $2$.

**Construction.** Let $K = \mathbb{F}_2$ (the field with two elements), and let
$$f = T^2 + T + 1 \in \mathbb{F}_2[T].$$
This is a quadratic polynomial (degree $2$, monic). Setting $g = f + 1 = T^2 + T
$, we compute:
$$g^2 = (f+1)^2 = f^2 + 1.$$
Therefore $f^2 + 1 = g^2 = (T^2+T)^2$ is a square in $K[T]$.

**Verification.** Explicitly, in $\mathbb{F}_2[T]$:
$$f^2 = (T^2+T+1)^2 = T^4 + T^2 + 1,$$
$$f^2 + 1 = T^4 + T^2 + 1 + 1 = T^4 + T^2 = T^2(T^2+1) = T^2(T+1)^2 = \bigl(T(T+
1)\bigr)^2 = (T^2+T)^2. \;\checkmark$$

**Remark (why characteristic $\neq 2$ fails).** Suppose $\operatorname{char} K \
neq 2$ and $f^2+1 = g^2$ for some $g\in K[T]$. Then
$$(g-f)(g+f) = 1.$$
Since $K[T]$ is an integral domain whose only units are nonzero constants, both
$g-f$ and $g+f$ must be nonzero constants $c, d \in K^\times$ with $cd=1$. But t
hen $f = (d-c)/2$ is a constant, contradicting $\deg f = 2$. Hence no such $f$ e
xists in characteristic $\neq 2$.

Thus the existence holds **exactly** in characteristic $2$, and the field $K = \
mathbb{F}_2$ with $f = T^2+T+1$ provides an explicit example.
