────────────────────────────────────────────────────────────────────────────────

Proof

Claim. There exists a continuous function $f:\mathbb{R}\to\mathbb{R}$ and a set
$E\subseteq\mathbb{R}$ with Lebesgue measure $m(E)=0$ such that $m(f(E))>0$.

We construct such a function explicitly: the Cantor (devil's staircase)
function.

────────────────────────────────────────────────────────────────────────────────

Step 1. The Cantor set $C$ has measure zero.

Define a nested sequence of closed sets $C_0\supseteq C_1\supseteq
C_2\supseteq\cdots$ by repeatedly removing the open middle third of every
remaining interval:

  • $C_0=[0,1]$,
  • $C_1=[0,\tfrac13]\cup[\tfrac23,1]$,
  • and in general $C_n$ is the union of $2^n$ closed intervals, each of length
  $3^{-n}$.

The Cantor set is $C=\bigcap_{n=0}^{\infty}C_n$. By countable subadditivity,

$$m(C)\le m(C_n)=2^n\cdot 3^{-n}=\left(\tfrac{2}
{3}\right)^n\xrightarrow[n\to\infty]{}0.$$

Hence $m(C)=0$.

────────────────────────────────────────────────────────────────────────────────

Step 2. Construction of the Cantor function $f:[0,1]\to[0,1]$.

Define $f$ in stages. At stage $n$, the set $C_n\setminus C_{n+1}$ consists of
$2^n$ open intervals (the "middle thirds" removed at step $n+1$). On each such
removed interval $I$, define $f$ to be constant, equal to the value $
\dfrac{2k+1}{2^{n+1}}$ for the appropriate $k\in{0,1,\dots,2^n-1}$, chosen so
that $f$ is non-decreasing. Concretely:

  • On $[\tfrac13,\tfrac23]$, set $f\equiv\tfrac12$.
  • On $[\tfrac19,\tfrac29]$, set $f\equiv\tfrac14$; on $[\tfrac79,\tfrac89]$,
  set $f\equiv\tfrac34$.
  • Continue inductively: each removed interval at stage $n$ receives a constant
  value of the form $k/2^n$.

On the Cantor set $C$ itself, define $f$ by continuity/monotonicity: for $x\in
C$,

$$f(x)=\sup{,f(y):y\notin C,\ y\le x,}=\inf{,f(y):y\notin C,\ y\ge x,}.$$

Equivalently, writing $x\in C$ in its ternary expansion $x=\sum_{n=1}^{\infty}
a_n,3^{-n}$ with $a_n\in{0,2}$, set

$$f(x)=\sum_{n=1}^{\infty}\frac{a_n/2}{2^{n}}=\sum_{n=1}^{\infty}\frac{a_n}
{2^{n+1}},$$

which is a binary expansion of a number in $[0,1]$.

Extend $f$ to all of $\mathbb{R}$ by setting $f(x)=0$ for $x\le 0$ and $f(x)=1$
for $x\ge 1$.

────────────────────────────────────────────────────────────────────────────────

Step 3. $f$ is continuous.

The function $f$ is non-decreasing by construction. On each $C_n$, the values of
$f$ range over a set of dyadic rationals with mesh $2^{-n}$; more precisely, the
oscillation of $f$ on any component interval of $C_n$ is at most $2^{-n}$. Since
every point of $[0,1]$ lies within distance $3^{-n}$ of a point where $f$ is
pinned to a dyadic value of granularity $2^{-n}$, we have for all $x,y\in[0,1]$:

$$|x-y|<3^{-n}\implies |f(x)-f(y)|\le 2^{-n}.$$

Given $\varepsilon>0$, choose $n$ with $2^{-n}<\varepsilon$ and set $\delta=3^{-
n}$. Then $|x-y|<\delta\Rightarrow|f(x)-f(y)|<\varepsilon$. So $f$ is
(uniformly) continuous on $[0,1]$, and the constant extensions outside $[0,1]$
are continuous at $0$ and $1$ as well. Hence $f:\mathbb{R}\to\mathbb{R}$ is
continuous.

────────────────────────────────────────────────────────────────────────────────

Step 4. $f(C)=[0,1]$, so $m(f(C))=1>0$.

Every $x\in C$ has a ternary expansion $x=\sum a_n 3^{-n}$ with $a_n\in{0,2}$,
and $f(x)=\sum (a_n/2),2^{-n}$. As $(a_n/2)$ ranges over all binary sequences
${0,1}^{\mathbb{N}}$, the values $f(x)$ range over all of $[0,1]$ (every number
in $[0,1]$ has a binary expansion). Therefore

$$f(C)=[0,1].$$

Consequently,

$$m(f(C))=m([0,1])=1>0=m(C).$$

────────────────────────────────────────────────────────────────────────────────

Conclusion

The Cantor set $C$ has Lebesgue measure $0$, and the Cantor function $f$ is
continuous with $f(C)=[0,1]$, a set of Lebesgue measure $1$. Therefore yes,
there exists a continuous function that maps a set of Lebesgue measure zero to a
set of positive Lebesgue measure.
