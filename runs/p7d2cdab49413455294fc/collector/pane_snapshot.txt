Write $G_\psi = \langle r, s \mid r^n = 1,\; s^2 = 1,\; srs^{-1} = r^a\rangle$.

**Key invariant: the center.** I compute $Z(G_\psi)$.

An element $r^j s^\varepsilon$ is central iff it commutes with both $r$ and $s$.

*Commuting with $r$:* requires $a^\varepsilon \equiv 1 \pmod n$. If $\varepsilon
 = 0$: always. If $\varepsilon = 1$: requires $a \equiv 1 \pmod n$, i.e., $S = \

*Commuting with $s$:* requires $(a-1)j \equiv 0 \pmod n$, i.e., $(a-1)j \equiv 0

- For $i \in S$: $a - 1 \equiv -2 \pmod{p_i}$, and since $p_i$ is odd, $\gcd(2,
p_i) = 1$, forcing $j \equiv 0 \pmod{p_i}$.
- For $i \notin S$: $a - 1 \equiv 0 \pmod{p_i}$, so $j$ is free mod $p_i$.

**Case $S = \emptyset$:** $\psi = \mathrm{id}$, so $G_\psi = \mathbb{Z}/n\mathbb
