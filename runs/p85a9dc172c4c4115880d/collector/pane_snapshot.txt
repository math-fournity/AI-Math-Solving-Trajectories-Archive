Looking at this problem, I need to determine whether continuity of $f$ plus smoo
thness of $g(t)=e^{2\pi i f(t)}$ forces $f$ to be smooth.

**Answer: Yes, $f$ must be smooth.**

**Proof.**

Let $\phi:\mathbb{R}\to S^1\subset\mathbb{R}^2$ denote the map $\phi(s)=(\cos 2\
pi s,\,\sin 2\pi s)$. This is a smooth covering map and, crucially, a **local di
ffeomorphism**: its derivative $\phi'(s)=2\pi(-\sin 2\pi s,\,\cos 2\pi s)$ never
 vanishes, so for every $s_0\in\mathbb{R}$ there exist an open interval $V\ni s_
0$ and an open arc $U\ni \phi(s_0)$ in $S^1$ such that $\phi|_V:V\to U$ is a dif
feomorphism, with smooth inverse $\psi:U\to V$.

We are given that $f:[0,1]\to\mathbb{R}$ is continuous and $g:=\phi\circ f:[0,1]
\to S^1$ is $C^\infty$.

**Claim:** $f$ is $C^\infty$ on $[0,1]$.

Fix any $t_0\in[0,1]$ and set $s_0=f(t_0)$. Choose a local smooth inverse $\psi:
U\to V$ of $\phi$ near $s_0$ as above, so $\phi\circ\psi=\operatorname{id}_U$ an
d $\psi\circ\phi|_V=\operatorname{id}_V$. Since $g$ is continuous (being smooth)
, there exists $\varepsilon>0$ such that $g(t)\in U$ for all $t\in I:=(t_0-\vare
psilon,\,t_0+\varepsilon)\cap[0,1]$.

On $I$, we have:
$$\phi(f(t)) = g(t) = \phi(\psi(g(t))),$$
so $f(t)-\psi(g(t))\in\ker\phi=\mathbb{Z}$ for every $t\in I$. The function $h(t
):=f(t)-\psi(g(t))$ is continuous (both $f$ and $\psi\circ g$ are continuous) an
d takes values in the discrete set $\mathbb{Z}$. Since $I$ is connected, $h$ mus
t be constant: $h(t)\equiv n$ for some $n\in\mathbb{Z}$. Therefore
$$f(t) = \psi(g(t)) + n, \qquad t\in I.$$

The right-hand side is a composition of smooth maps ($\psi$ is smooth as a local
 inverse of a local diffeomorphism, and $g$ is $C^\infty$ by hypothesis), so $f$
 is $C^\infty$ on $I$.

Since $t_0\in[0,1]$ was arbitrary, $f$ is $C^\infty$ at every point of $[0,1]$ (
with one-sided smoothness at the endpoints, which the same argument provides). $
\blacksquare$

**Key idea:** The exponential map $\phi:\mathbb{R}\to S^1$ is a local diffeomorp
hism (its derivative never vanishes), so it faithfully reflects all local regula
rity: any non-smoothness of $f$ would be transmitted to $g=\phi\circ f$. The cov
ering-space structure ensures that a continuous lift of a smooth map through a l
ocal diffeomorphism is automatically smooth, because locally the lift differs fr
om a smooth branch of the inverse by a (locally constant, hence constant) intege
r.
