## Proof

Let $H$ be an $N\times N$ Hermitian matrix whose eigenvalues all lie in $[-n_0,
n_0]$. We show that every matrix element satisfies $|H_{ij}|\le n_0$, a bound in
dependent of $N$.

**Step 1: Spectral bound on the operator norm.** Since $H$ is Hermitian, it is u
nitarily diagonalizable: $H = U\Lambda U^*$, where $U$ is unitary and $\Lambda =
 \mathrm{diag}(\lambda_1,\dots,\lambda_N)$ with $\lambda_k\in[-n_0,n_0]$. Hence
the spectral radius equals the operator norm:
$$\|H\| = \max_k |\lambda_k| \le n_0.$$

**Step 2: Bound each entry via the operator norm.** Let $e_i,e_j$ be standard ba
sis vectors (unit norm). Then
$$H_{ij} = e_i^*\, H\, e_j = \langle e_i, H e_j\rangle.$$
By Cauchy–Schwarz and the definition of the operator norm,
$$|H_{ij}| = |\langle e_i, H e_j\rangle| \le \|e_i\|\,\|H e_j\| \le \|e_i\|\,\|H
\|\,\|e_j\| = \|H\| \le n_0.$$

**Step 3: Explicit verification via the spectral decomposition (equivalent route
).** Writing it out,
$$H_{ij} = \sum_{k=1}^{N} U_{ik}\,\lambda_k\,\overline{U_{jk}}.$$
Therefore
$$|H_{ij}| \le \sum_k |U_{ik}|\,|\lambda_k|\,|U_{jk}| \le n_0 \sum_k |U_{ik}|\,|
U_{jk}| \le n_0\Bigl(\sum_k |U_{ik}|^2\Bigr)^{1/2}\Bigl(\sum_k |U_{jk}|^2\Bigr)^
{1/2} = n_0\cdot 1\cdot 1 = n_0,$$
where the last equality uses the fact that $U$ is unitary, so every row has unit
 $\ell^2$-norm.

**Conclusion.** For every pair of indices $(i,j)$, $|H_{ij}|\le n_0$. The bound
$n_0$ depends only on the prescribed spectral interval, not on the dimension $N$
 of the matrix. Hence the answer is **yes**: bounding all eigenvalues of a Hermi
tian matrix in a fixed interval $[-n_0,n_0]$ does imply that all matrix elements
 are bounded by a constant ($n_0$) independent of the matrix size.
