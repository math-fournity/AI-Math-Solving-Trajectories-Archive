## Solution

**Answer: $\dfrac{2}{3}$**

**Setup.** Since the dyadic rationals $m/2^n$ are invariant under integer transl
ation, $a_n$ is periodic in $a$ with period 1. So we may assume $a \in [0,1)$.

Write the fractional part as $x = a - \lfloor a \rfloor \in [0,1)$. Define $f_0
= x$ and $f_{n+1} = \{2f_n\}$ (the fractional part of $2f_n$, i.e., the doubling
 map). Then $f_n = \{x \cdot 2^n\}$, and the nearest multiple of $1/2^n$ to $x$
gives:

$$a_n = \frac{\min(f_n,\, 1 - f_n)}{2^n}.$$

Set $g_n = \min(f_n, 1 - f_n) \in [0, 1/2]$, so $S := \sum_{n=0}^{\infty} a_n =
\sum_{n=0}^{\infty} \frac{g_n}{2^n}$.

**Key inequality.** For all $f \in [0,1)$:

$$2\,g(f) + g(\{2f\}) \le 1, \quad \text{where } g(f) = \min(f, 1-f).$$

*Proof by cases:*

- $f \in [0, \tfrac{1}{4}]$: $g(f) = f$, $\{2f\} = 2f \in [0,\tfrac{1}{2}]$, $g(
\{2f\}) = 2f$. Sum $= 4f \le 1$. ✓
- $f \in [\tfrac{1}{4}, \tfrac{1}{2}]$: $g(f) = f$, $\{2f\} = 2f \in [\tfrac{1}{
2},1]$, $g(\{2f\}) = 1-2f$. Sum $= 2f + 1 - 2f = 1$. ✓
- $f \in [\tfrac{1}{2}, \tfrac{3}{4}]$: $g(f) = 1-f$, $\{2f\} = 2f-1 \in [0,\tfr
ac{1}{2}]$, $g(\{2f\}) = 2f-1$. Sum $= 2(1-f) + (2f-1) = 1$. ✓
- $f \in [\tfrac{3}{4}, 1]$: $g(f) = 1-f$, $\{2f\} = 2f-1 \in [\tfrac{1}{2},1]$,
 $g(\{2f\}) = 2-2f$. Sum $= 4 - 4f \le 1$. ✓

**Bounding the sum.** Applying the inequality with $f = f_{2k}$ (so $\{2f_{2k}\}
 = f_{2k+1}$):

$$2\,g_{2k} + g_{2k+1} \le 1 \quad \Longrightarrow \quad \frac{g_{2k}}{2^{2k}} +
 \frac{g_{2k+1}}{2^{2k+1}} \le \frac{1}{2^{2k+1}}.$$

Summing over $k = 0, 1, 2, \ldots$ (the pairs $(g_{2k}, g_{2k+1})$ partition all
 terms):

$$S = \sum_{k=0}^{\infty}\left(\frac{g_{2k}}{2^{2k}} + \frac{g_{2k+1}}{2^{2k+1}}
\right) \le \sum_{k=0}^{\infty} \frac{1}{2^{2k+1}} = \frac{1/2}{1 - 1/4} = \frac
{2}{3}.$$

**Achieving the bound.** Take $a = \frac{1}{3} = 0.\overline{01}_2$. Then $f_0 =
 \frac{1}{3}$, $f_1 = \frac{2}{3}$, $f_2 = \frac{1}{3}$, … (period 2), and $g_n
= \frac{1}{3}$ for all $n$. Thus:

$$S = \sum_{n=0}^{\infty} \frac{1/3}{2^n} = \frac{1/3}{1 - 1/2} = \frac{2}{3}.$$

Equality in the bound requires $f_{2k} \in [\tfrac{1}{4}, \tfrac{3}{4}]$ for all
 $k$; this is satisfied since $\frac{1}{3}, \frac{2}{3} \in [\tfrac{1}{4}, \tfra
c{3}{4}]$.

**Conclusion.** The maximum possible value of $\sum_{n=0}^{\infty} a_n$ is $\box
ed{\dfrac{2}{3}}$.
