## Solution

**Yes**, such a sequence exists. The key obstruction is that the classical conti
nuity-from-above theorem for Lebesgue *measure* requires the sets to be **measur
able**; for outer measure applied to arbitrary (possibly non-measurable) sets, t
he conclusion fails.

---

### Construction

Define an equivalence relation on $[0,1)$ by $x \sim y \iff x - y \in \mathbb{Q}
$. By the Axiom of Choice, let $V \subseteq [0,1)$ be a set containing exactly o
ne representative from each equivalence class (a **Vitali set**). Denote additio
n modulo $1$ by $\oplus$.

**Standard facts about $V$:**

- The sets $\{V \oplus r : r \in \mathbb{Q} \cap [0,1)\}$ are pairwise disjoint
and $\bigcup_{r \in \mathbb{Q} \cap [0,1)} (V \oplus r) = [0,1)$.
- $V$ is not Lebesgue measurable.
- **$m^*(V) > 0$:** If $m^*(V) = 0$, then by countable subadditivity,
$$m^*([0,1)) \le \sum_{r \in \mathbb{Q}\cap[0,1)} m^*(V \oplus r) = \sum_{r} m^*
(V) = 0,$$
contradicting $m^*([0,1)) = 1$. (Here we used translation-invariance of $m^*$: t
he map $x \mapsto x \oplus r$ is a measure-preserving bijection of $[0,1)$, so $
m^*(V\oplus r) = m^*(V)$.)

Set $a := m^*(V) > 0$.

Enumerate $\mathbb{Q} \cap [0,1) = \{r_1, r_2, r_3, \dots\}$ and define, for eac
h $n \in \mathbb{N}$,
$$A_n := \bigcup_{k=n}^{\infty} (V \oplus r_k) \;\subseteq\; [0,1) \;\subseteq\;
 \mathbb{R}.$$

---

### Verification

**(1) Decreasing:** $A_{n+1} = \bigcup_{k=n+1}^{\infty}(V \oplus r_k) \subseteq
\bigcup_{k=n}^{\infty}(V \oplus r_k) = A_n$. ✓

**(2) Finite outer measure:** $A_n \subseteq [0,1)$, so $m^*(A_n) \le m^*([0,1))
 = 1 < \infty$. ✓

**(3) The intersection is empty:** Suppose $x \in \bigcap_{n=1}^{\infty} A_n$. S
ince $\bigcup_{k=1}^{\infty}(V \oplus r_k) = [0,1)$ and the sets $V \oplus r_k$
are pairwise disjoint, there is a **unique** $k_0$ with $x \in V \oplus r_{k_0}$
. Then $x \notin V \oplus r_k$ for every $k \ne k_0$, so in particular $x \notin
 A_{k_0+1} = \bigcup_{k=k_0+1}^{\infty}(V \oplus r_k)$, contradicting $x \in \bi
gcap_n A_n$. Hence
$$\bigcap_{n=1}^{\infty} A_n = \emptyset, \qquad m^*\!\left(\bigcap_{n=1}^{\inft
y} A_n\right) = 0.$$

**(4) The limit of outer measures is strictly positive:** For each $n$,
$$V \oplus r_n \subseteq A_n \implies m^*(A_n) \ge m^*(V \oplus r_n) = m^*(V) =
a > 0.$$
Since $\{A_n\}$ is decreasing, $\{m^*(A_n)\}$ is a decreasing sequence bounded b
elow by $a$, so
$$\lim_{n\to\infty} m^*(A_n) \ge a > 0.$$

---

### Conclusion

$$m^*\!\left(\bigcap_{n=1}^{\infty} A_n\right) = 0 \;<\; a \;\le\; \lim_{n\to\in
fty} m^*(A_n).$$

Thus the decreasing sequence $\{A_n\}$ satisfies all the required conditions: $A
_{n+1} \subseteq A_n$, $m^*(A_n) < \infty$ for every $n$, and the outer measure
of the intersection is strictly less than the limit of the outer measures. $\bla
cksquare$
