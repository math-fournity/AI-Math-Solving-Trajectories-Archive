## Proof

Let $\alpha = \lim_{n\to\infty} \frac{f(n)}{n}$ and $\beta = \lim_{n\to\infty} \
frac{g(n)}{n}$. By hypothesis both limits exist and $\alpha + \beta < 1$. Since
$f(n), g(n) \geq 0$ (mapping into $\mathbb{N}$), we have $\alpha, \beta \geq 0$.

Let $L = \lim_{n\to\infty} \frac{a_n}{n}$, which exists by assumption.

**Key claim.** If $\frac{a_n}{n} \to L$ and $\frac{f(n)}{n} \to \alpha$, then $\
frac{a_{f(n)}}{n} \to L\,\alpha$.

*Proof of claim.* We consider two cases.

**Case $\alpha > 0$.** Then for sufficiently large $n$, $f(n) \geq \frac{\alpha}
{2}\,n \to \infty$, so $f(n) \to \infty$. Hence $\frac{a_{f(n)}}{f(n)} \to L$ (c
omposing the convergent sequence $\frac{a_k}{k} \to L$ with $k = f(n) \to \infty
$). Therefore
$$\frac{a_{f(n)}}{n} = \frac{a_{f(n)}}{f(n)} \cdot \frac{f(n)}{n} \;\longrightar
row\; L \cdot \alpha.$$

**Case $\alpha = 0$.** We show $\frac{a_{f(n)}}{n} \to 0 = L \cdot \alpha$ direc
tly. Since $\frac{a_n}{n} \to L$, there exists $N_1$ such that $|a_n| \leq (|L|+
1)\,n$ for all $n \geq N_1$. Set $M_1 = \max_{1 \le k < N_1} |a_k|$ (a finite co
nstant). Given $\varepsilon > 0$:

- Choose $N_2$ so that $\frac{f(n)}{n} < \frac{\varepsilon}{2(|L|+1)}$ for $n \g
eq N_2$ (possible since $f(n)/n \to 0$).
- Choose $N_3$ so that $\frac{M_1}{n} < \frac{\varepsilon}{2}$ for $n \geq N_3$.

For $n \geq \max(N_2, N_3)$:
- If $f(n) \geq N_1$: $\displaystyle\frac{|a_{f(n)}|}{n} \leq (|L|+1)\,\frac{f(n
)}{n} < (|L|+1)\cdot\frac{\varepsilon}{2(|L|+1)} = \frac{\varepsilon}{2} < \vare
psilon.$
- If $f(n) < N_1$: $\displaystyle\frac{|a_{f(n)}|}{n} \leq \frac{M_1}{n} < \frac
{\varepsilon}{2} < \varepsilon.$

(If $f(n)=0$ for some $n$, then $a_{f(n)}=a_0$ is constant and $\frac{a_0}{n}\to
 0$, which is also covered.) Hence $\frac{a_{f(n)}}{n} \to 0 = L\alpha$. $\squar
e$

By the same argument, $\frac{a_{g(n)}}{n} \to L\,\beta$.

**Taking the limit.** Divide the recurrence $a_n = a_{f(n)} + a_{g(n)}$ by $n$:
$$\frac{a_n}{n} = \frac{a_{f(n)}}{n} + \frac{a_{g(n)}}{n}.$$
Taking $n \to \infty$ and applying the claim:
$$L = L\,\alpha + L\,\beta = L(\alpha + \beta).$$
Rearranging:
$$L\,(1 - \alpha - \beta) = 0.$$
Since $\alpha + \beta < 1$, the factor $1 - \alpha - \beta > 0$, so we conclude
$$L = 0.$$

Therefore **yes**, it follows that $\lim_{n\to\infty} \frac{a_n}{n} = 0$. $\blac
ksquare$
