## Proof

Let $f(n) := r(\underbrace{3,3,\dots,3}_{n})$ denote the $n$-color Ramsey number
 in which every color is required to contain a monochromatic triangle. We prove

$$f(n) \;\le\; \bigl\lfloor e\cdot n!\bigr\rfloor + 1.$$

---

### Step 1. A general multicolor recursion

**Lemma (multicolor Ramsey recursion).** For positive integers $k_1,\dots,k_r$ w
ith $k_i\ge 2$,

$$R(k_1,\dots,k_r)\;\le\;\sum_{i=1}^{r} R(k_1,\dots,k_i-1,\dots,k_r)\;-\;r\;+\;2
.$$

*Proof.* Set $R_i := R(k_1,\dots,k_i-1,\dots,k_r)$ and $N := \sum_i R_i - r + 2$
, so that $N-1 = \sum_i (R_i-1)+1$. In any $r$-coloring of the edges of $K_N$, f
ix a vertex $v$ and let $d_i$ be the number of edges from $v$ of color $i$, so $
\sum_i d_i = N-1$. If every $d_i \le R_i-1$, then $\sum_i d_i \le \sum_i(R_i-1)
= N-2 < N-1$, a contradiction. Hence $d_j \ge R_j$ for some $j$. Among those $\g
e R_j$ neighbors of $v$, by definition of $R_j = R(k_1,\dots,k_j-1,\dots,k_r)$,
either there is a monochromatic $K_{k_i}$ in some color $i\ne j$ (and we are don
e), or there is a monochromatic $K_{k_j-1}$ in color $j$, which together with $v
$ forms a monochromatic $K_{k_j}$ in color $j$. In either case a monochromatic c
lique of the required size exists. $\square$

---

### Step 2. Reducing a "2" entry

**Lemma.** $R(2,k_2,\dots,k_r)=R(k_2,\dots,k_r)$.

*Proof.* Let $M=R(k_2,\dots,k_r)$. For the upper bound, color $K_M$ with $r$ col
ors. If any edge has color $1$, we have a color-$1$ $K_2$. Otherwise all edges u
se only colors $2,\dots,r$, and since $M=R(k_2,\dots,k_r)$ some color $j\ge 2$ c
ontains a $K_{k_j}$. For the lower bound, take an $(r-1)$-coloring of $K_{M-1}$
with colors $2,\dots,r$ avoiding every $K_{k_j}$; using no color-$1$ edge gives
an $r$-coloring avoiding a color-$1$ $K_2$ as well. $\square$

---

### Step 3. The recursion for $f(n)$

Applying Step 1 with $k_1=\cdots=k_n=3$ and using Step 2 to replace each $R(3,\d
ots,2,\dots,3)$ by $f(n-1)$,

$$\boxed{\,f(n)\;\le\; n\,f(n-1)\;-\;n\;+\;2,\qquad f(1)=3.\,}$$

(Indeed $f(2)=6=2\cdot3-2+2$ and $f(3)=17=3\cdot6-3+2$, both equal to the true v
alues $r(3,3)=6$, $r(3,3,3)=17$.)

---

### Step 4. Solving the recursion

Recall $e\cdot n! = \sum_{k=0}^{\infty}\frac{n!}{k!}$. For $n\ge 1$ the tail sat
isfies

$$0<\sum_{k=n+1}^{\infty}\frac{n!}{k!}=\frac1{n+1}+\frac1{(n+1)(n+2)}+\cdots<\fr
ac1n\le 1,$$

so $\lfloor e\cdot n!\rfloor = \sum_{k=0}^{n}\frac{n!}{k!}=:\,g(n)$, an integer.
 Observe the exact identity

$$g(n)=\sum_{k=0}^{n}\frac{n!}{k!}=n\sum_{k=0}^{n-1}\frac{(n-1)!}{k!}+\frac{n!}{
n!}=n\,g(n-1)+1.$$

**Claim.** $f(n)\le g(n)+1=\lfloor e\cdot n!\rfloor+1$ for all $n\ge 1$.

*Proof by induction.*
Base: $f(1)=3=g(1)+1=\lfloor e\rfloor+1=2+1$. ✓
Inductive step: using $f(n-1)\le g(n-1)+1$ and the recursion,

$$f(n)\le n\,f(n-1)-n+2\le n\bigl(g(n-1)+1\bigr)-n+2=n\,g(n-1)+2=\bigl(n\,g(n-1)
+1\bigr)+1=g(n)+1.$$

$\square$

---

### Conclusion

$$\boxed{\,r(\underbrace{3,3,\dots,3}_{n})\;\le\;\bigl\lfloor e\cdot n!\bigr\rfl
oor+1.\,}$$
