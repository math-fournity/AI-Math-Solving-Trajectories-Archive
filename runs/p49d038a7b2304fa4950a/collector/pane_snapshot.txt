## Proof

**Setup.** Let $f_K, f_L, f_P \in [0,1]$ be the fraction of the day each machine
 type (Kiln, Lathe, Press) devotes to Azure tiles. By symmetry, all units of the
 same type use the same fraction.

**Production functions.** With 3 Kilns, 3 Lathes, 1 Press:

$$A = 30f_K + 60f_L + 30f_P \quad \text{(Azure)}$$

$$B = 60(1-f_K) + 90(1-f_L) + 80(1-f_P) = 230 - 60f_K - 90f_L - 80f_P \quad \tex
t{(Bronze)}$$

**Balance constraint** $A = B$:

$$30f_K + 60f_L + 30f_P = 230 - 60f_K - 90f_L - 80f_P$$

$$90f_K + 150f_L + 110f_P = 230$$

**Objective.** Total tiles $T = A + B = 2A$, so we maximize:

$$T = 60f_K + 120f_L + 60f_P$$

subject to $90f_K + 150f_L + 110f_P = 230$ and $0 \le f_K, f_L, f_P \le 1$.

**Solving the LP.** The objective-to-constraint ratios are:

| Variable | Ratio (obj/constraint) |
|----------|----------------------|
| $f_L$ | $120/150 = 2/5 = 0.400$ |
| $f_K$ | $60/90 = 1/3 \approx 0.333$ |
| $f_P$ | $60/110 = 3/11 \approx 0.273$ |

To maximize $T$, allocate the constraint "budget" (230) to variables with the hi
ghest ratio first:

1. **Set $f_L = 1$** (highest ratio): uses $150$, leaving $80$.
2. **Set $f_P = 0$** (lowest ratio): uses $0$, leaving $80$ for $f_K$.
3. **$f_K = 80/90 = 8/9$**: uses the remaining $80$.

All values lie in $[0,1]$. ✓

**Verification:**

$$A = 30 \cdot \tfrac{8}{9} + 60 \cdot 1 + 30 \cdot 0 = \tfrac{80}{3} + 60 = \tf
rac{260}{3}$$

$$B = 60\!\left(1 - \tfrac{8}{9}\right) + 90(0) + 80(1) = \tfrac{60}{9} + 80 = \
tfrac{20}{3} + 80 = \tfrac{260}{3}$$

$A = B = \tfrac{260}{3}$. ✓

$$T = 2 \cdot \tfrac{260}{3} = \frac{520}{3}$$

**Optimality check (all feasible vertices):**

| $(f_K, f_L, f_P)$ | $T$ |
|---|---|
| $(8/9,\, 1,\, 0)$ | $520/3 \approx 173.33$ |
| $(1,\, 14/15,\, 0)$ | $172$ |
| $(0,\, 1,\, 8/11)$ | $1800/11 \approx 163.64$ |
| $(0,\, 4/5,\, 1)$ | $156$ |

The vertex $(8/9, 1, 0)$ gives the maximum.

**Interpretation.** The Lathes (exchange rate 1.5 Bronze/Azure — most balanced)
run fully on Azure. The Press (exchange rate $8/3$ Bronze/Azure — most Bronze-fa
voring) runs fully on Bronze. The Kilns (exchange rate 2:1) split their day $8/9
$ on Azure, $1/9$ on Bronze to balance the totals.

**The maximum total number of tiles is $\dfrac{520}{3}$.**
