## Solution

We work in affine space $\mathbb{A}^3_F$ with coordinate ring $F[x,y,z]$. The al
gebraic set is
$$X = V(y - x^2,\; y^2 - y + z^2).$$

**Step 1: Eliminate $y$.** The ideal is $I = (y - x^2,\; y^2 - y + z^2)$. Substi
tuting $y = x^2$ into the second generator gives
$$x^4 - x^2 + z^2 = 0.$$
Hence the coordinate ring is
$$A = F[x,y,z]/I \cong F[x,z]/(x^4 - x^2 + z^2),$$
via the isomorphism sending $y \mapsto x^2$ (the relation $y - x^2$ is used to e
liminate $y$, and the second relation becomes $x^4 - x^2 + z^2$).

**Step 2: Irreducibility.** We claim $f = x^4 - x^2 + z^2 = z^2 + (x^4 - x^2)$ i
s irreducible in $F[x,z]$. View $f$ as a polynomial in $z$ over the UFD $F[x]$:
$$f = z^2 - \bigl(x^2 - x^4\bigr) = z^2 - x^2(1-x)(1+x).$$
A quadratic $z^2 - g(x)$ over $F[x]$ factors iff $g(x)$ is a square in $F[x]$. H
ere
$$g(x) = x^2(1-x)(1+x) = x^2(1 - x^2).$$
The factor $1 - x^2 = (1-x)(1+x)$ is squarefree (its two roots $\pm 1$ are simpl
e, since $\operatorname{char} F \neq 2$ is not forced, but even in characteristi
c $2$, $1-x^2 = (1-x)^2$; we handle this below).

- If $\operatorname{char} F \neq 2$: $1 - x^2$ is squarefree, so $g = x^2(1-x^2)
$ is **not** a perfect square (the exponent of $(1-x)$ is $1$). Thus $f$ is irre
ducible in $F[x][z]$, hence irreducible in $F[x,z]$ by Gauss's lemma.

- If $\operatorname{char} F = 2$: then $x^4 - x^2 + z^2 = x^4 + x^2 + z^2 = (x^2
 + x + z)(x^2 + x + z)$... let us check: $(x^2+x+z)^2 = x^4 + x^2 + z^2$ in char
acteristic $2$ (since cross terms vanish). So $f = (x^2 + x + z)^2$, which is a
perfect square. In this case $V(f) = V(x^2 + x + z)$ set-theoretically, and $x^2
 + x + z$ is irreducible (linear in $z$). The underlying set is still an irreduc
ible hypersurface.

In both cases, the underlying algebraic set $X$ is irreducible (in characteristi
c $2$ the ideal is non-reduced, but the *set* $V(f) = V(x^2+x+z)$ is irreducible
).

**Step 3: Compute the dimension.** Since $X$ is irreducible, its dimension is th
e transcendence degree of its rational function field $F(X) = \operatorname{Frac
}(A)$ over $F$.

The ring $A \cong F[x,z]/(f)$ is the coordinate ring of a plane curve (a hypersu
rface in $\mathbb{A}^2$). A hypersurface in $\mathbb{A}^n$ defined by a single n
onzero nonconstant equation has dimension $n - 1$. Here $n = 2$, so
$$\dim X = 2 - 1 = 1.$$

Equivalently, $F(X) = F(x,z)$ with the single algebraic relation $z^2 = x^2 - x^
4$, so $x$ is a transcendental parameter and $z$ is algebraic over $F(x)$. Thus
$\operatorname{trdeg}_F F(X) = 1$.

## Answer

$$\boxed{\dim X = 1}$$
