## Proof

Let $F = \mathbb{F}_q$ and let $U = U(3, F)$ be the group of $3 \times 3$ upper-
unitriangular matrices over $F$. Every element of $U$ has the form
$$g(a,b,c) = \begin{pmatrix} 1 & a & b \\ 0 & 1 & c \\ 0 & 0 & 1 \end{pmatrix},
\qquad a, b, c \in F,$$
so $|U| = q^3$.

**Step 1: The center.** A direct computation shows that $g(a,b,c)$ commutes with
 every element of $U$ if and only if $a = c = 0$. Hence
$$Z(U) = \{g(0,b,0) : b \in F\}, \qquad |Z(U)| = q.$$

**Step 2: Conjugation formula.** For $h = g(x,y,z)$ and $g = g(a,b,c)$, a direct
 matrix calculation gives
$$h\, g\, h^{-1} = g\!\bigl(a,\; b + xc - az,\; c\bigr).$$
Indeed, the commutator $[h,g] = hgh^{-1}g^{-1}$ lies in $Z(U)$ and equals $g(0,\
, xc - az,\, 0)$, so conjugation by $h$ changes only the $(1,3)$-entry $b$, repl
acing it by $b + (xc - az)$.

**Step 3: Conjugacy class sizes.** The set of achievable adjustments to $b$ is
$$\{xc - az : x, z \in F\}.$$

- **Central case** $(a, c) = (0, 0)$: the expression $xc - az$ is identically $0
$, so the conjugacy class of $g(0,b,0)$ is the singleton $\{g(0,b,0)\}$. This gi
ves $q$ conjugacy classes (one per central element).

- **Non-central case** $(a, c) \neq (0, 0)$: the linear map $(x,z) \mapsto xc -
az$ from $F^2 \to F$ is nonzero (since $(a,c) \neq (0,0)$), hence surjective. Th
erefore the conjugacy class of $g(a,b,c)$ is
$$\{g(a, b', c) : b' \in F\},$$
which has exactly $q$ elements.

**Step 4: Counting classes.** The number of non-central elements is $q^3 - q$. S
ince each non-central conjugacy class has size $q$, the number of non-central co
njugacy classes is
$$\frac{q^3 - q}{q} = q^2 - 1.$$
Adding the $q$ central (singleton) classes, the total number of conjugacy classe
s is
$$k(U) = q + (q^2 - 1) = q^2 + q - 1.$$

**Step 5: Verification.** For $q = 2$: $|U| = 8$, $|Z| = 2$, and $k(U) = 4 + 2 -
 1 = 5$. The group $U(3,\mathbb{F}_2)$ is isomorphic to the dihedral group $D_4$
 (order 8, center of order 2), which indeed has 5 conjugacy classes. ✓

For $q = 3$: $|U| = 27$, $|Z| = 3$, and $k(U) = 9 + 3 - 1 = 11$. The non-central
 classes number $(27-3)/3 = 8$, plus 3 central classes, giving 11. ✓

**Conclusion.** The number of distinct conjugacy classes of $U(3, F)$ is
$$k\bigl(U(3,F)\bigr) = q^2 + q - 1,$$
which is a polynomial in $q$ with integer coefficients.
