## Proof

**Yes, it is possible.** We construct an explicit example.

**Construction.** Let $X = \ell^2(\mathbb{N})$ with the standard norm $\|x\|^2 =
 \sum_{n=1}^\infty |x_n|^2$. Define the diagonal operator
$$T: \ell^2 \to \ell^2, \qquad T(x_1, x_2, x_3, \dots) = (a_1 x_1,\, a_2 x_2,\,
a_3 x_3, \dots), \quad \text{where } a_n = \frac{n}{n+1} = 1 - \frac{1}{n+1}.$$

**$T$ is bounded.** For any $x \in \ell^2$,
$$\|Tx\|^2 = \sum_{n=1}^\infty a_n^2 |x_n|^2 \le \sum_{n=1}^\infty |x_n|^2 = \|x
\|^2,$$
since $|a_n| < 1$ for all $n$. Hence $\|T\| \le 1$.

**$\|T\| = 1$.** Let $e_n$ be the $n$-th standard basis vector. Then $\|e_n\| =
1$ and $\|Te_n\| = a_n = \frac{n}{n+1} \to 1$ as $n \to \infty$. Therefore $\|T\
| \ge \sup_n \|Te_n\| = 1$, and combined with the upper bound, $\|T\| = 1$.

**$T$ is injective.** If $Tx = 0$, then $a_n x_n = 0$ for every $n$. Since $a_n
\neq 0$ for all $n$, we get $x_n = 0$ for all $n$, so $x = 0$.

**$T$ does not attain its norm on the closed unit ball.** Suppose, for contradic
tion, that there exists $x \in \ell^2$ with $\|x\| \le 1$ and $\|Tx\| = \|T\| =
1$. Since $\|Tx\| \le \|x\| \le 1$, we must have $\|x\| = 1$ and $\|Tx\| = 1$. N
ow
$$\|Tx\|^2 = \sum_{n=1}^\infty a_n^2 |x_n|^2 = 1 = \sum_{n=1}^\infty |x_n|^2 = \
|x\|^2.$$
Rearranging,
$$\sum_{n=1}^\infty \underbrace{(1 - a_n^2)}_{> \, 0} |x_n|^2 = 0.$$
Each term is non-negative, so every term must vanish: $(1 - a_n^2)|x_n|^2 = 0$ f
or all $n$. Since $1 - a_n^2 > 0$ (because $a_n < 1$), this forces $x_n = 0$ for
 every $n$, i.e., $x = 0$. But then $\|x\| = 0 \neq 1$, a contradiction.

Hence no vector in the closed unit ball attains the norm of $T$.

**Conclusion.** The operator $T$ is a bounded, injective linear operator on the
Banach space $\ell^2$ that does not attain its norm on the closed unit ball. $\b
lacksquare$
