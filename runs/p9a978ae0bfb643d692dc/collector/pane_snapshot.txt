## Setting Up the Reflections in Trilinear Coordinates

Let the triangle have angles A, B, C and circumradius R, with O the circumcenter
 and H the orthocenter (the "Harmonic Point").

In trilinear coordinates, reflecting a point (x : y : z) over side BC (the line
x = 0) gives:
$$P' = (-x,\; y + 2x\cos C,\; z + 2x\cos B)$$

Applying this to each vertex:

- **D** = reflection of A = (1:0:0) over BC: $\quad D = (-1,\; 2\cos C,\; 2\cos
B)$
- **E** = reflection of B = (0:1:0) over AC: $\quad E = (2\cos C,\; -1,\; 2\cos
A)$
- **F** = reflection of C = (0:0:1) over AB: $\quad F = (2\cos B,\; 2\cos A,\; -
1)$

## Collinearity Condition

D, E, F are collinear iff the determinant vanishes:

$$\det\begin{pmatrix} -1 & 2\cos C & 2\cos B \\ 2\cos C & -1 & 2\cos A \\ 2\cos
B & 2\cos A & -1 \end{pmatrix} = 0$$

**Expanding along the first row:**

$$= -1(1 - 4\cos^2 A) - 2\cos C(-2\cos C - 4\cos A\cos B) + 2\cos B(4\cos A\cos
C + 2\cos B)$$

$$= -1 + 4\cos^2 A + 4\cos^2 C + 8\cos A\cos B\cos C + 8\cos A\cos B\cos C + 4\c
os^2 B$$

$$= -1 + 4(\cos^2 A + \cos^2 B + \cos^2 C) + 16\cos A\cos B\cos C = 0$$

## Applying the Triangle Identity

Using the well-known identity (valid when $A + B + C = \pi$):
$$\cos^2 A + \cos^2 B + \cos^2 C + 2\cos A\cos B\cos C = 1$$

Substituting $\cos^2 A + \cos^2 B + \cos^2 C = 1 - 2\cos A\cos B\cos C$:

$$4(1 - 2\cos A\cos B\cos C) + 16\cos A\cos B\cos C = 1$$
$$4 + 8\cos A\cos B\cos C = 1$$
$$\cos A\cos B\cos C = -\frac{3}{8}$$

## Connecting to OH via Euler's Formula

Euler's formula relates the circumcenter–orthocenter distance to the circumradiu
s:
$$OH^2 = R^2(1 - 8\cos A\cos B\cos C)$$

Substituting the collinearity condition:
$$OH^2 = R^2\!\left(1 - 8\cdot\!\left(-\frac{3}{8}\right)\right) = R^2(1 + 3) =
4R^2$$

## Identifying n and k

The power-balance equation is $(OH)^k = nR^k$. From $OH^2 = 4R^2$:

$$(OH)^2 = 4R^2 \quad\Longrightarrow\quad k = 2,\; n = 4$$

Therefore:
$$n + k = 4 + 2 = \boxed{6}$$
