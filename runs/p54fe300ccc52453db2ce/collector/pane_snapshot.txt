## Solution

We evaluate $L = \lim_{x\to\infty}\left(xe^x\int_x^{\infty}\frac{e^{-t}}{t^2}\,d
t\right)$.

**Asymptotic expansion via integration by parts.**

Let $I(x) = \int_x^{\infty}\frac{e^{-t}}{t^2}\,dt$. Integrate by parts with $u =
 t^{-2}$, $dv = e^{-t}\,dt$, so $du = -2t^{-3}\,dt$, $v = -e^{-t}$:

$$I(x) = \left[-\frac{e^{-t}}{t^2}\right]_x^{\infty} - \int_x^{\infty}\frac{2e^{
-t}}{t^3}\,dt = \frac{e^{-x}}{x^2} - 2\int_x^{\infty}\frac{e^{-t}}{t^3}\,dt.$$

Multiplying by $xe^x$:

$$xe^x\, I(x) = \frac{1}{x} - 2xe^x\int_x^{\infty}\frac{e^{-t}}{t^3}\,dt.$$

**Bounding the remainder.** For $t \geq x > 0$, we have $t^{-3} \leq x^{-3}$, so

$$0 \leq \int_x^{\infty}\frac{e^{-t}}{t^3}\,dt \leq \frac{1}{x^3}\int_x^{\infty}
e^{-t}\,dt = \frac{e^{-x}}{x^3}.$$

Therefore

$$0 \leq 2xe^x\int_x^{\infty}\frac{e^{-t}}{t^3}\,dt \leq 2xe^x\cdot\frac{e^{-x}}
{x^3} = \frac{2}{x^2}\xrightarrow{x\to\infty} 0.$$

**Conclusion.** Since $xe^x\, I(x) = \frac{1}{x} - (\text{term bounded by }2/x^2
)$, and both $\frac{1}{x}\to 0$ and $\frac{2}{x^2}\to 0$, by the squeeze theorem
:

$$L = \lim_{x\to\infty}\left(xe^x\int_x^{\infty}\frac{e^{-t}}{t^2}\,dt\right) =
0.$$
