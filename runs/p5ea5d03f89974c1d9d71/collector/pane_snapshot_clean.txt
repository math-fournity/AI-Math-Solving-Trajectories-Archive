## Solution

**Setup.** Place the circle with center $O$ at the origin, radius $r = d/2$. Let
 $A$ be at angle $\pi$ and $D$ at angle $0$, so $AD = 2r = d$ is the diameter. S
ince $ABCD$ is convex with vertices in order along the semicircular arc, let $B$
 be at angle $\beta$ and $C$ at angle $\gamma$ with $\pi > \beta > \gamma > 0$.

**Chord lengths.** Using the chord formula $\text{chord} = 2r\sin(\Delta\theta/2
)$:

$$AB = d\sin\!\tfrac{\pi-\beta}{2},\quad BC = d\sin\!\tfrac{\beta-\gamma}{2},\qu
ad CD = d\sin\!\tfrac{\gamma}{2}.$$

Set $x = \frac{\pi-\beta}{2},\; y = \frac{\beta-\gamma}{2},\; z = \frac{\gamma}{
2}$. Then $x + y + z = \frac{\pi}{2}$, with $x,y,z > 0$.

**Equal-length constraint.** Since $AB = BC = a$, we get $\sin x = \sin y$. As $
x,y \in (0,\pi/2)$, this forces $x = y$. Hence $2x + z = \pi/2$, so $z = \pi/2 -
 2x$.

**Deriving the key relation.** Now:
$$a = d\sin x, \qquad b = d\sin z = d\sin\!\left(\tfrac{\pi}{2}-2x\right) = d\co
s(2x) = d\left(1-2\sin^2 x\right) = d - \frac{2a^2}{d}.$$

Multiplying by $d$:
$$\boxed{d^2 - bd - 2a^2 = 0}\quad\Longleftrightarrow\quad d(d-b) = 2a^2.$$

**Validity conditions.** Let $c = d - b > 0$ (positivity of $b = d\cos 2x$ requi
res $x < \pi/4$, giving $b < d$). We need:
- $a, b, d \in \mathbb{Z}_{>0}$, $a \neq b$,
- $dc = 2a^2$ for some integer $c$ with $1 \le c \le d-1$ (so $b = d-c \ge 1$),
- $a \neq d - c$.

**Search for minimal $d$.**

| $d$ | valid $c$ giving $2a^2 = dc$ | result |
|-----|------------------------------|--------|
| 2 | $c{=}1{:}\,a{=}1,\;b{=}1$ | $a=b$ ✗ |
| 3 | none (no $c$ makes $dc/2$ a square) | — |
| 4 | $c{=}2{:}\,a{=}2,\;b{=}2$ | $a=b$ ✗ |
| 5 | none | — |
| 6 | $c{=}3{:}\,a{=}3,\;b{=}3$ | $a=b$ ✗ |
| 7 | none | — |
| **8** | $c{=}1{:}\,a{=}2,\;b{=}7$ | **$a\neq b$ ✓** |

**Verification of $d=8$, $a=2$, $b=7$:**
- $dc = 8\cdot 1 = 8 = 2\cdot 4 = 2a^2$ ✓
- $b = 8 - 1 = 7 \ge 1$ ✓, $a = 2 \neq 7 = b$ ✓
- $\sin x = a/d = 1/4$, so $x = \arcsin(1/4) \approx 14.5°$; then $2x \approx 29
° < 90°$, giving $z = 90° - 2x > 0$ — all angles valid, quadrilateral non-degene
rate ✓
- $b = d\cos 2x = 8\cdot(1 - 2/16) = 8\cdot 7/8 = 7$ ✓

**Conclusion.** The least possible integer value of the diameter is:

$$\boxed{d = 8}$$
