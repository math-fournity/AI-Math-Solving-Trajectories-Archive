## Proof

**Construction.** Let $A$ be an infinite set (e.g., $A = \mathbb{N}$). Let $S =
M(A)$ be the **free magma** on $A$: the set of all finite binary trees whose lea
ves are labeled by elements of $A$. Define $b: S \times S \to S$ by setting $b(s
, t)$ to be the tree whose root has left subtree $s$ and right subtree $t$.

**Step 1: $S$ is infinite and $|S| = |A|$.**

Since $A \subseteq S$ (each $a \in A$ is a leaf/tree of depth 0), $S$ is infinit
e. Every element of $S$ is a finite binary tree with leaves in $A$. A tree with
$n$ leaves is determined by its shape (one of finitely many binary tree shapes o
n $n$ leaves) and an ordered labeling of leaves by elements of $A$, giving $|A|^
n = |A|$ labelings (for infinite $A$). Summing over all $n \geq 1$ (countably ma
ny), $|S| = \aleph_0 \cdot |A| = |A|$.

**Step 2: $b$ is almost-everywhere non-constant (in fact, everywhere non-constan
t).**

For any fixed $s \in S$, the map $t \mapsto b(s,t)$ is **injective**: if $t_1 \n
eq t_2$, then $b(s, t_1)$ and $b(s, t_2)$ are trees with different right subtree
s, hence distinct. Since $|S| \geq 2$, injectivity implies non-constancy. By sym
metry, $s \mapsto b(s, t)$ is injective (hence non-constant) for every fixed $t
\in S$. Thus $b$ is non-constant in each argument at **every** point, so it is a
lmost-everywhere non-constant.

**Step 3: The number of $b$-closed subsets exceeds $|S|$.**

For each subset $X \subseteq A$, define $\langle X \rangle$ to be the **submagma
 generated by $X$**: the smallest subset of $S$ containing $X$ and closed under
$b$. Concretely, $\langle X \rangle$ is the set of all finite binary trees whose
 leaves are all labeled by elements of $X$. This is closed under $b$ by construc
tion.

**Claim:** $\langle X \rangle \cap A = X$ for every $X \subseteq A$.

*Proof of claim.* The inclusion $X \subseteq \langle X \rangle \cap A$ is immedi
ate since $X \subseteq A$ and $X \subseteq \langle X \rangle$. For the reverse i
nclusion, let $a \in A \cap \langle X \rangle$. Then $a$ is a leaf (an element o
f $A$) that belongs to $\langle X \rangle$. Every element of $\langle X \rangle$
 is a finite binary tree built from elements of $X$ using $b$, and the operation
 $b$ always produces an internal node (never a leaf). Therefore, the only leaves
 appearing in any tree in $\langle X \rangle$ are elements of $X$. Since $a$ is
a leaf in $\langle X \rangle$, we conclude $a \in X$. $\square$

By the claim, if $X \neq X'$ are distinct subsets of $A$, then $\langle X \rangl
e \cap A \neq \langle X' \rangle \cap A$, so $\langle X \rangle \neq \langle X'
\rangle$. Thus the map $X \mapsto \langle X \rangle$ injects $\mathcal{P}(A)$ in
to the family of $b$-closed subsets of $S$.

The number of $b$-closed subsets is therefore at least $|\mathcal{P}(A)| = 2^{|A
|} = 2^{|S|}$. Since the total number of subsets of $S$ is $2^{|S|}$, the number
 of $b$-closed subsets is exactly $2^{|S|}$.

By **Cantor's theorem**, $2^{|S|} > |S|$.

**Conclusion.** The infinite set $S = M(A)$ equipped with the free magma operati
on $b$ is almost-everywhere non-constant (indeed everywhere non-constant in each
 argument), and the number of $b$-closed subsets of $S$ is $2^{|S|} > |S|$. Ther
efore, **yes**, such $S$ and $b$ exist.
