## Setup and key facts

Let $\zeta = e^{2\pi i/257}$, a primitive $257$th root of unity. Then

$$\cos\!\left(\frac{2\pi}{257}\right) = \frac{\zeta + \zeta^{-1}}{2}.$$

**Fact 1.** $257 = 2^8 + 1$ is a Fermat prime (it is prime).

**Fact 2.** The cyclotomic field $\mathbb{Q}(\zeta)$ has degree $[\mathbb{Q}(\ze
ta):\mathbb{Q}] = \varphi(257) = 256 = 2^8$, and its Galois group is

$$\operatorname{Gal}(\mathbb{Q}(\zeta)/\mathbb{Q}) \cong (\mathbb{Z}/257\mathbb{
Z})^{\times},$$

which is cyclic of order $256$ (since $257$ is prime, $(\mathbb{Z}/257\mathbb{Z}
)^{\times}$ is cyclic).

**Fact 3.** The number $\cos(2\pi/257) = (\zeta+\zeta^{-1})/2$ is fixed by compl
ex conjugation $\zeta \mapsto \zeta^{-1}$, so it lies in the **maximal real subf
ield**

$$K := \mathbb{Q}(\zeta + \zeta^{-1}) \subset \mathbb{R}.$$

The fixed field of $\{\pm 1\} \subset (\mathbb{Z}/257\mathbb{Z})^{\times}$ (the
subgroup generated by complex conjugation) is exactly $K$, so

$$[K:\mathbb{Q}] = \frac{256}{2} = 128 = 2^7, \qquad \operatorname{Gal}(K/\mathb
b{Q}) \cong (\mathbb{Z}/257\mathbb{Z})^{\times}/\{\pm 1\},$$

which is cyclic of order $128 = 2^7$.

## The crucial group-theoretic argument

**$K/\mathbb{Q}$ is a Galois extension whose Galois group $G = \operatorname{Gal
}(K/\mathbb{Q})$ is a $2$-group** (cyclic of order $2^7$).

A finite $p$-group has a **composition series** with every composition factor of
 order $p$. Concretely, since $G$ is cyclic of order $2^7$, it has a unique chai
n of subgroups

$$1 = G_0 \;\triangleleft\; G_1 \;\triangleleft\; G_2 \;\triangleleft\; \cdots \
;\triangleleft\; G_7 = G, \qquad |G_i| = 2^i, \qquad |G_i/G_{i-1}| = 2.$$

By the **Galois correspondence**, this chain of subgroups corresponds to a tower
 of fields

$$\mathbb{Q} = K_0 \;\subset\; K_1 \;\subset\; K_2 \;\subset\; \cdots \;\subset\
; K_7 = K, \qquad [K_i : K_{i-1}] = 2.$$

Each step $K_i / K_{i-1}$ is a **quadratic extension**.

## Each quadratic extension adjoins a real square root

A quadratic extension $K_i = K_{i-1}(\sqrt{d_i})$ for some $d_i \in K_{i-1}$, $d
_i \notin (K_{i-1})^2$. Since $K \subset \mathbb{R}$ is a **totally real** field
 (every embedding into $\mathbb{C}$ lands in $\mathbb{R}$, because $K$ is genera
ted by the real number $\zeta + \zeta^{-1} = 2\cos(2\pi/257)$ and is the fixed f
ield of complex conjugation), every intermediate field $K_i$ is also a subfield
of $\mathbb{R}$.

Therefore each $d_i$ is a **positive** real number (it must be positive for $K_i
 \subset \mathbb{R}$ to hold, since adjoining $\sqrt{d_i}$ with $d_i < 0$ would
introduce non-real elements). Hence each $\sqrt{d_i}$ is a **real radical** (a r
eal square root of a positive real number).

## Conclusion: nested real radicals

Starting from $\mathbb{Q}$, we build $K_7 = K$ by successively adjoining real sq
uare roots:

$$K_1 = \mathbb{Q}\bigl(\sqrt{d_1}\bigr), \quad K_2 = K_1\bigl(\sqrt{d_2}\bigr)
= \mathbb{Q}\bigl(\sqrt{d_1},\, \sqrt{d_2}\bigr), \quad \ldots, \quad K_7 = \mat
hbb{Q}\bigl(\sqrt{d_1}, \ldots, \sqrt{d_7}\bigr),$$

where each $d_i$ is a positive element of $K_{i-1} \subset \mathbb{R}$, hence ea
ch $\sqrt{d_i}$ is a real number expressible as a radical nested inside the prev
ious ones. Since

$$\cos\!\left(\frac{2\pi}{257}\right) = \frac{\zeta + \zeta^{-1}}{2} \in K = K_7
,$$

it follows that $\cos(2\pi/257)$ can be written as a rational expression (using
$+$, $-$, $\times$, $\div$) in the elements $\sqrt{d_1}, \sqrt{d_2}, \ldots, \sq
rt{d_7}$, each of which is a **real** square root nested within the previous fie
ld. This is precisely a **finite tower of nested real radicals** (square roots).

## Comparison with $\cos(2\pi/17)$

The case $n = 17$ is identical in structure: $17 = 2^4 + 1$ is a Fermat prime, $
\varphi(17) = 16 = 2^4$, the maximal real subfield has degree $2^3 = 8$, and its
 cyclic Galois group of order $8 = 2^3$ yields a tower of $3$ quadratic extensio
ns — giving the famous $3$-level nested square-root expression for $\cos(2\pi/17
)$.

For $n = 257$, the same mechanism applies with $7$ levels of nesting (degree $2^
7 = 128$ for the real subfield) instead of $3$. The expression is far more unwie
ldy (it involves $7$ nested square roots and the intermediate quantities are com
plicated sums of cosines), but it **exists** by the same Galois-theoretic argume
nt.
