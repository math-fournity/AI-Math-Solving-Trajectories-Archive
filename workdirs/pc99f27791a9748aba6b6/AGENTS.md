# Problem

In a high-security server farm, a technician is configuring a $10 \times 10$ grid of data storage slots. Each slot can either be loaded with a Type-X drive, a Type-O drive, or left empty. 

To maintain system stability, the grid must adhere to two strict protocols:
1. Currently, no single row and no single column is entirely filled with drives of the same type.
2. The grid is at "maximal stability," meaning that if the technician were to install any drive (either Type-X or Type-O) into any currently empty slot, it would immediately cause at least one row or one column to consist entirely of identical drives.

Based on these constraints, what is the minimum total number of drives (Type-X and Type-O combined) that must be installed in the grid?
