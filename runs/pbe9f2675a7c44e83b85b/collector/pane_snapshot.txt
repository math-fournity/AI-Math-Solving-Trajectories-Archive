## Solution

**Goal:** Compute $\nu((0,1])$ given that $\nu$ is a measure on the Borel sets o
f $(0,\infty)$ satisfying $\nu((x,2x])=\sqrt{x}$ for all $x>0$.

**Step 1: Decompose $(0,1]$ into dyadic annuli.**

For each $n \ge 0$, set $x = 2^{-(n+1)}$, so that $2x = 2^{-n}$. Then
$$(x,2x] = (2^{-(n+1)},\, 2^{-n}].$$
These intervals are pairwise disjoint and
$$(0,1] = \bigcup_{n=0}^{\infty} (2^{-(n+1)},\, 2^{-n}].$$

**Step 2: Apply the hypothesis to each piece.**

By the given property,
$$\nu\big((2^{-(n+1)},\, 2^{-n}]\big) = \sqrt{2^{-(n+1)}} = 2^{-(n+1)/2}.$$

**Step 3: Sum by countable additivity.**

Since $\nu$ is a measure and the intervals are disjoint,
$$\nu((0,1]) = \sum_{n=0}^{\infty} 2^{-(n+1)/2} = 2^{-1/2}\sum_{n=0}^{\infty}\le
ft(2^{-1/2}\right)^n.$$

This is a geometric series with ratio $r = 2^{-1/2} = \tfrac{1}{\sqrt{2}} \in (0
,1)$, so
$$\nu((0,1]) = \frac{2^{-1/2}}{1 - 2^{-1/2}} = \frac{1/\sqrt{2}}{1 - 1/\sqrt{2}}
 = \frac{1}{\sqrt{2}-1} = \sqrt{2}+1.$$

**Verification of well-definedness.** The series converges (ratio $<1$), and the
 decomposition exhausts $(0,1]$ with disjoint measurable sets, so countable addi
tivity applies without issue. The value is finite and positive, consistent with
$\nu$ being a (positive) measure.

**Answer:**
$$\boxed{\nu((0,1]) = 1 + \sqrt{2}.}$$
