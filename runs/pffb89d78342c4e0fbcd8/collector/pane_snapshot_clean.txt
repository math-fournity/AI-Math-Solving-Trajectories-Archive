## Proof

**Setup.** Let $S(x) = \sum_{k=1}^n k^x$ and $T(x) = \sum_{k=1}^n (k^x - k) = S(
x) - \frac{n(n+1)}{2}$. The expression is

$$L = \lim_{x\to 0}\left(\frac{S(x)}{n}\right)^{\,E(x)}, \qquad E(x) = \frac{\su
m_{k=2}^{n}\frac{k^x-1}{x}}{T(x)}.$$

We assume $n \geq 2$ (for $n=1$ the sum $\sum_{k=2}^n$ is empty and the expressi
on is degenerate).

**Step 1: Taylor expansion of the base.** Using $k^x = e^{x\ln k} = 1 + x\ln k +
 O(x^2)$:

$$S(x) = \sum_{k=1}^n \left(1 + x\ln k + O(x^2)\right) = n + x\sum_{k=1}^n \ln k
 + O(x^2) = n + x\ln(n!) + O(x^2).$$

Therefore:

$$\frac{S(x)}{n} = 1 + \frac{x\ln(n!)}{n} + O(x^2).$$

In particular, $\frac{S(x)}{n} \to 1$ as $x \to 0$.

**Step 2: The exponent tends to a finite constant.** Evaluate $T(x)$ at $x = 0$:

$$T(0) = \sum_{k=1}^n (1 - k) = n - \frac{n(n+1)}{2} = \frac{n(1-n)}{2} = -\frac
{n(n-1)}{2} \neq 0 \quad \text{for } n \geq 2.$$

For the numerator of $E(x)$, using $\frac{k^x - 1}{x} = \ln k + O(x)$:

$$\sum_{k=2}^n \frac{k^x - 1}{x} = \sum_{k=2}^n \ln k + O(x) = \ln(n!) + O(x).$$

Since $T(0) \neq 0$, the denominator $T(x) = -\frac{n(n-1)}{2} + O(x)$ is bounde
d away from zero near $x = 0$. Thus:

$$E(x) \to \frac{\ln(n!)}{-\frac{n(n-1)}{2}} = \frac{-2\ln(n!)}{n(n-1)} := c, \q
uad \text{a finite constant.}$$

**Step 3: Evaluate the limit.** Since the base $\frac{S(x)}{n} = 1 + \frac{x\ln(
n!)}{n} + O(x^2) \to 1$ and the exponent $E(x) \to c$ (finite), we have:

$$L = \lim_{x\to 0} \exp\!\Big(E(x)\cdot \ln\!\Big(\tfrac{S(x)}{n}\Big)\Big).$$

Now $\ln\!\left(\frac{S(x)}{n}\right) = \ln\!\left(1 + \frac{x\ln(n!)}{n} + O(x^
2)\right) = \frac{x\ln(n!)}{n} + O(x^2) \to 0$, and $E(x) \to c$ (bounded). Ther
efore:

$$E(x)\cdot \ln\!\left(\frac{S(x)}{n}\right) \to c \cdot 0 = 0.$$

Hence:

$$L = e^0 = 1.$$

**Verification ($n=2$).** Base $= \frac{1+2^x}{2} \to 1$; exponent $= \frac{(2^x
-1)/x}{2^x - 2} \to \frac{\ln 2}{-1} = -\ln 2$ (finite). So $L = 1^{-\ln 2} = 1$
. Numerically at $x = 0.001$: base $\approx 1.000347$, exponent $\approx -0.6935
$, giving $\approx 0.99976 \to 1$. ✓

**Conclusion.** The base approaches $1$ linearly in $x$ (rate $\frac{\ln(n!)}{n}
$), while the exponent approaches the finite constant $\frac{-2\ln(n!)}{n(n-1)}$
. A quantity of the form $(1 + O(x))^{\,c + O(x)}$ with $c$ finite tends to $1$.
