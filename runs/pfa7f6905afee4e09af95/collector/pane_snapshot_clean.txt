 residue class a ∈ 𝔽_ℓ can be realized as #E(𝔽_q) mod ℓ for some elliptic curve
E/𝔽_q.

**Answer: Yes.** For every a ∈ 𝔽_ℓ, there exists an elliptic curve E/𝔽_q with #E
(𝔽_q) ≡ a (mod ℓ).

---

## Proof

**Key tools.** For an elliptic curve E/𝔽_q, we write #E(𝔽_q) = q + 1 − t, where
t is the trace of Frobenius, satisfying |t| ≤ 2√q (Hasse's bound). **Waterhouse'
s theorem** (1969) states that for q = p prime, an integer t is realized as the
trace of some elliptic curve over 𝔽_p if and only if |t| ≤ 2√p and one of severa
l conditions holds — in particular, **every** t with |t| ≤ 2√p and gcd(t, p) = 1
 is realized (the ordinary case).

**Construction.** Fix a prime ℓ and an arbitrary a ∈ 𝔽_ℓ.

**Step 1 (Choice of field).** By Dirichlet's theorem on primes in arithmetic pro
gressions, there exists a prime p with p ≡ 1 (mod ℓ) and p > ℓ². Set q = p. Note
 that p ≠ ℓ (since p ≡ 1 mod ℓ while ℓ ≡ 0 mod ℓ, and p > ℓ² > ℓ).

**Step 2 (Choice of trace).** Since p ≡ 1 (mod ℓ), we have:
$$\#E(\mathbb{F}_p) = p + 1 - t \equiv 0 + 1 - t \equiv 1 - t \pmod{\ell}.$$
To achieve #E(𝔽_p) ≡ a (mod ℓ), we need t ≡ 1 − a (mod ℓ). Set b = 1 − a (mod ℓ)
.

- **If a ≠ 1** (so b ∈ {1, 2, …, ℓ−1}): take t₀ = b. Then 0 < t₀ ≤ ℓ − 1 < ℓ < 2
√p (since p > ℓ² implies 2√p > 2ℓ > ℓ − 1).
- **If a = 1** (so b = 0): take t₀ = ℓ. Then 0 < t₀ = ℓ < 2√p (since p > ℓ² impl
ies 2√p > 2ℓ > ℓ).

In both cases, t₀ is a **nonzero** integer with |t₀| ≤ 2√p.

**Step 3 (Coprimality).** Since 0 < |t₀| ≤ 2√p < p (the last inequality holds fo
r p ≥ 5, which is guaranteed by p > ℓ² ≥ 4) and p is prime, we have p ∤ t₀, henc
e gcd(t₀, p) = 1.

**Step 4 (Existence of the curve).** By Waterhouse's theorem (ordinary case), si
nce |t₀| ≤ 2√p and gcd(t₀, p) = 1, there exists an elliptic curve E/𝔽_p whose tr
ace of Frobenius is t₀.

**Step 5 (Verification).** For this curve:
$$\#E(\mathbb{F}_p) = p + 1 - t_0 \equiv 1 - t_0 \equiv 1 - (1 - a) \equiv a \pm
od{\ell}.$$

**Conclusion.** Since a ∈ 𝔽_ℓ was arbitrary, for every residue class modulo ℓ th
ere exists an elliptic curve over a suitable finite field whose point count real
izes that class. ∎
