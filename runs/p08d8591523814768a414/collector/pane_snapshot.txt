## Solution

The answer is $n = 1{,}000{,}001$.

**Key observation.** Two lines in the plane are parallel if and only if they hav
e the same slope (direction). Thus the parallelism relation partitions any set o
f lines into *slope classes*, where each class consists of all lines sharing a c
ommon slope. A subset of lines is pairwise nonparallel exactly when no two of it
s members lie in the same slope class — i.e., it picks at most one line from eac
h class.

So the problem becomes a pure pigeonhole question:

> Given $n$ items partitioned into classes, find the least $n$ forcing either so
me class to have $\ge 1001$ members, or the number of classes to be $\ge 1001$.

**Lower bound: $n = 1{,}000{,}000$ does not suffice.**

Take exactly $1000$ distinct slopes, and for each slope draw exactly $1000$ para
llel lines. This gives $1000 \times 1000 = 1{,}000{,}000$ lines total. Then:
- Every slope class has exactly $1000 < 1001$ lines, so no $1001$ lines are all
parallel.
- There are only $1000 < 1001$ distinct slopes, so it is impossible to select $1
001$ pairwise nonparallel lines (any such selection needs $1001$ distinct slopes
).

Hence $n = 1{,}000{,}000$ does not guarantee the desired property, so the least
$n$ is at least $1{,}000{,}001$.

**Upper bound: $n = 1{,}000{,}001$ suffices.**

Consider any set of $1{,}000{,}001$ lines, partitioned into slope classes. Suppo
se, for contradiction, that neither desired subset exists. Then:
- No slope class contains $1001$ lines, so every class has at most $1000$ lines.
- There are fewer than $1001$ slope classes, so there are at most $1000$ classes
.

Therefore the total number of lines is at most
$$1000 \text{ (classes)} \times 1000 \text{ (lines per class)} = 1{,}000{,}000,$
$
which is strictly less than $1{,}000{,}001$ — a contradiction.

So at least one of the two alternatives must hold: either some slope class has $
\ge 1001$ lines (giving $1001$ parallel lines), or there are $\ge 1001$ slope cl
asses (and picking one line from each of $1001$ classes gives $1001$ pairwise no
nparallel lines).

**Conclusion.** The least integer with the required property is
$$\boxed{1{,}000{,}001}.$$
