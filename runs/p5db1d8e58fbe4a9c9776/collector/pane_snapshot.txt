## Proof that $\lim_{x\to\infty} \frac{\pi(x)}{x} = 0$

We give a fully elementary proof using properties of binomial coefficients. No h
eavy machinery (PNT, Mertens, etc.) is required.

### Setup: Chebyshev's theta function

Define $\theta(x) = \sum_{p \le x} \ln p$, the sum over primes $p \le x$. Note $
\theta$ is non-decreasing.

**Key inequality.** For every positive integer $n$:
$$\theta(2n) - \theta(n) \le n \ln 4.$$

*Proof.* Every prime $p$ with $n < p \le 2n$ divides $\binom{2n}{n} = \frac{(2n)
!}{(n!)^2}$, since $p \mid (2n)!$ (as $p \le 2n$) but $p \nmid n!$ (as $p > n$).
 Being distinct primes, their product divides $\binom{2n}{n}$:
$$\prod_{n < p \le 2n} p \;\le\; \binom{2n}{n}.$$
Since $\binom{2n}{n}$ is a single term in $\sum_{k=0}^{2n}\binom{2n}{k}=4^n$, we
 have $\binom{2n}{n}\le 4^n$. Taking logarithms:
$$\theta(2n)-\theta(n) = \ln\!\prod_{n<p\le 2n} p \le \ln\binom{2n}{n} \le n\ln
4. \qquad\blacksquare$$

### Bounding $\theta(x)$: $\theta(x) = O(x)$

Apply the key inequality with $n = 2^{k-1}$:
$$\theta(2^k) \le \theta(2^{k-1}) + 2^{k-1}\ln 4.$$
Telescoping from $\theta(1)=0$:
$$\theta(2^k) \le \ln 4\sum_{j=0}^{k-1}2^j = \ln 4\,(2^k - 1) < 2^k \ln 4.$$

For general $x\ge 2$, set $k=\lceil\log_2 x\rceil$ so that $x \le 2^k < 2x$. Sin
ce $\theta$ is non-decreasing:
$$\theta(x) \le \theta(2^k) < 2^k\ln 4 \le 2x\ln 4 = 4x\ln 2.$$

### From $\theta(x) = O(x)$ to $\pi(x)/x \to 0$

Split the sum defining $\theta$ at $\sqrt{x}$. Every prime $p > \sqrt{x}$ satisf
ies $\ln p > \tfrac12\ln x$, so:
$$\theta(x) \ge \sum_{\sqrt{x}<p\le x}\ln p \ge \bigl(\pi(x)-\pi(\sqrt{x})\bigr)
\cdot\tfrac12\ln x.$$
Rearranging and using $\theta(x) \le 4x\ln 2$ and the trivial bound $\pi(\sqrt{x
})\le\sqrt{x}$:
$$\pi(x) \le \frac{2\,\theta(x)}{\ln x} + \pi(\sqrt{x}) \le \frac{8\ln 2\cdot x}
{\ln x} + \sqrt{x}.$$

Dividing by $x$:
$$\frac{\pi(x)}{x} \le \frac{8\ln 2}{\ln x} + \frac{1}{\sqrt{x}}.$$

As $x\to\infty$, both terms on the right tend to $0$. Since $\pi(x)/x \ge 0$, by
 the squeeze theorem:

$$\boxed{\lim_{x\to\infty}\frac{\pi(x)}{x}=0.}$$
