答案：不一定。$c = d$ 并非必然成立。

下面给出一个反例。

────────────────────────────────────────────────────────────────────────────────

设置

取样本空间 $\Omega = {0,1}^{\mathbb{N}}$，配备乘积 $\sigma$-代数。设 $X_i :
\Omega \to {0,1}$ 为坐标投影，尾 $\sigma$-域为 $$B^{\infty} = \bigcap_{n=1}
^{\infty} \sigma(X_n, X_{n+1}, \ldots).$$

取两个无穷乘积测度：

  • $P = \mathrm{Bernoulli}(p)^{\otimes \mathbb{N}}$，其中 $p \in (0,1)$；
  • $Q = \mathrm{Bernoulli}(q)^{\otimes \mathbb{N}}$，其中 $q \in (0,1)$，$q
  \neq p$。

两个测度定义在同一个可测空间 $(\Omega, \mathcal{F})$ 上。

────────────────────────────────────────────────────────────────────────────────

构造尾可测随机变量

定义 $$Y = \limsup_{n\to\infty} \frac{1}{n}\sum_{i=1}^{n} X_i, \qquad Z =
\liminf_{n\to\infty} \frac{1}{n}\sum_{i=1}^{n} X_i,$$ 并令 $$X = Y \cdot
\mathbf{1}_{{Y = Z}}.$$

$X$ 是 $B^{\infty}$-可测的。 对任意固定的 $m \geq 1$， $$\frac{1}{n}\sum_{i=1}
^{n} X_i = \underbrace{\frac{1}{n}\sum_{i=1}^{m} X_i}{\to, 0 \text{ 当 }
n\to\infty} + \frac{1}{n}\sum{i=m+1}^{n} X_i.$$ 因此 $$Y = \limsup_{n\to\infty}
\frac{1}{n}\sum_{i=m+1}^{n} X_i,$$ 而后者是 $\sigma(X_{m+1}, X_{m+2}, \ldots)$-
可测的。由于这对所有 $m$ 成立，$Y$（同理 $Z$）是 $\bigcap_{m} \sigma(X_{m+1},
\ldots) = B^{\infty}$-可测的。集合 ${Y = Z}$ 也是 $B^{\infty}$-可测的，故 $X$ 是
$B^{\infty}$-可测的。

────────────────────────────────────────────────────────────────────────────────

应用强大数律

由 Kolmogorov 强大数律（独立同分布情形）：

  • 在 $P$ 下，$X_1, X_2, \ldots$ 独立同分布，$\mathbb{E}P[X_1] = p$，故 $$
  \frac{1}{n}\sum{i=1}^{n} X_i \xrightarrow{P\text{-a.s.}} p.$$ 因此 $Y = Z =
  p$，$P$-a.s.，即 $P(X = p) = 1$。
  • 在 $Q$ 下，$X_1, X_2, \ldots$ 独立同分布，$\mathbb{E}Q[X_1] = q$，故 $$
  \frac{1}{n}\sum{i=1}^{n} X_i \xrightarrow{Q\text{-a.s.}} q.$$ 因此 $Y = Z =
  q$，$Q$-a.s.，即 $Q(X = q) = 1$。

────────────────────────────────────────────────────────────────────────────────

结论

取 $c = p$，$d = q$。我们有：

  • $X$ 是 $B^{\infty}$-可测的；
  • $P(X = c) = 1$；
  • $Q(X = d) = 1$；
  • $c = p \neq q = d$。

因此 $c = d$ 不是必然的。 尾 $\sigma$-域在各个乘积测度下都是平凡的（Kolmogorov
0-1 律保证了每个尾事件概率为 0 或 1，从而每个尾可测随机变量在该测度下 a.s. 为常
数），但不同乘积测度下这个常数可以不同。强大数律给出的样本均值极限正是一个典型的
尾可测量，它在不同乘积测度下收敛到不同的值。
