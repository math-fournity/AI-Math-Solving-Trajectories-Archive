## Proof

), where a² + b² = 1 (hypotenuse AB = 1), a, b > 0.

**Key points:**
- E = midpoint of AC = (b/2, 0), so median BE goes from B(0,a) to E(b/2, 0).
- F = midpoint of BC = (0, a/2), so median AF goes from A(b,0) to F(0, a/2).
- N = midpoint of AB = (b/2, a/2).

**Angle bisector of ∠ACB.** Since C is the right angle with legs along the axes,
 the angle bisector is the line y = x.

**Finding P** (intersection of y = x with median BE):
Parametrize BE: (tb/2, a(1−t)). Setting tb/2 = a(1−t) gives t = 2a/(2a+b), so:
$$P = \left(\frac{ab}{2a+b},\; \frac{ab}{2a+b}\right)$$

**Finding M** (intersection of y = x with median AF):
Parametrize AF: (b(1−s), sa/2). Setting b(1−s) = sa/2 gives s = 2b/(2b+a), so:
$$M = \left(\frac{ab}{2b+a},\; \frac{ab}{2b+a}\right)$$

**Area of △MNP.** With M = (m,m), P = (p,p), N = (b/2, a/2), where m = ab/(2b+a)
, p = ab/(2a+b):

$$\text{Area} = \frac{1}{2}\left|m\!\left(\tfrac{a}{2}-p\right) + \tfrac{b}{2}(p
-m) + p\!\left(m-\tfrac{a}{2}\right)\right| = \frac{|a-b|}{4}\cdot|m-p|$$

Computing m − p:
$$m - p = \frac{ab}{2b+a} - \frac{ab}{2a+b} = \frac{ab(a-b)}{(2b+a)(2a+b)}$$

Therefore:
$$\text{Area} = \frac{ab\,(a-b)^2}{4\,(2b+a)(2a+b)}$$

**Simplification.** Note that (2b+a)(2a+b) = 5ab + 2(a²+b²) = 5ab + 2, and (a−b)
² = 1 − 2ab. Setting t = ab (where 0 < t ≤ 1/2 by AM-GM):

$$\text{Area}(t) = \frac{t(1-2t)}{4(5t+2)}$$

**Optimization.** Let h(t) = t(1−2t)/(5t+2). Then:

$$h'(t) = \frac{(1-4t)(5t+2) - 5(t-2t^2)}{(5t+2)^2} = \frac{-10t^2 - 8t + 2}{(5t
+2)^2}$$

Setting the numerator to zero: 10t² + 8t − 2 = 0, i.e., 5t² + 4t − 1 = 0:

$$t = \frac{-4 \pm \sqrt{16+20}}{10} = \frac{-4 \pm 6}{10}$$

The positive root is t = 1/5, which lies in (0, 1/2].

**Verification of maximum.** At the endpoints: Area → 0 as t → 0⁺, and Area(1/2)
 = (1/2)(0)/(4·(9/2)) = 0. Since there is a unique critical point in (0, 1/2) an
d the function is positive there, it is the global maximum.

**Computing the maximum:**
$$\text{Area}\!\left(\tfrac{1}{5}\right) = \frac{\frac{1}{5}\cdot\frac{3}{5}}{4\
cdot 3} = \frac{3/25}{12} = \frac{1}{100}$$

This value is achieved when ab = 1/5 and a² + b² = 1, e.g., when a and b are the
 roots of x² − √(7/5)x + 1/5 = 0 (which gives a valid triangle).
