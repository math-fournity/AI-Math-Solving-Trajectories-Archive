## Proof

**Step 1: A formula for the longest zigzag subsequence.**

For a sequence $x_1, \ldots, x_n$ of distinct reals ($n \ge 2$), define the *sig
n sequence* $s_i = \operatorname{sign}(x_{i+1} - x_i) \in \{+1, -1\}$ for $i = 1
, \ldots, n-1$. Decompose this into maximal runs of equal sign; let $r$ be the n
umber of runs. Each sign change $s_i \ne s_{i+1}$ corresponds to a local extremu
m at position $i+1$, and the number of sign changes is $r - 1$.

**Claim:** $a(x_1, \ldots, x_n) = r + 1$.

*Lower bound.* Let the runs be $R_1, \ldots, R_r$, where $R_j$ covers sign posit
ions $a_j$ through $b_j$ (so $R_j$ governs elements $x_{a_j}, \ldots, x_{b_j+1}$
, which are strictly monotone). The boundary element $x_{b_j+1}$ is a local extr
emum. Consider the subsequence
$$x_1,\; x_{b_1+1},\; x_{b_2+1},\; \ldots,\; x_{b_{r-1}+1},\; x_n,$$
which has $r+1$ elements. The difference $x_{b_j+1} - x_{b_{j-1}+1}$ (with $b_0
:= 0$) has sign equal to the sign of run $R_j$. Since consecutive runs have oppo
site signs, these differences alternate, so this subsequence is zigzag. Hence $a
 \ge r+1$.

*Upper bound.* Let $x_{i_1}, \ldots, x_{i_k}$ be any zigzag subsequence with alt
ernating difference signs $t_1, \ldots, t_{k-1}$. For each gap from $i_j$ to $i_
{j+1}$, the total displacement $x_{i_{j+1}} - x_{i_j} = \sum_{m=i_j}^{i_{j+1}-1}
(x_{m+1} - x_m)$ has sign $t_j$. If every sign $s_m$ in this gap were opposite t
o $t_j$, the sum would have the opposite sign—a contradiction. So each gap conta
ins at least one sign from a run with sign $t_j$.

The sign positions for gap $j$ are $\{i_j, \ldots, i_{j+1}-1\}$ and for gap $j+1
$ are $\{i_{j+1}, \ldots, i_{j+2}-1\}$; these ranges are disjoint. Since $t_j \n
e t_{j+1}$ and each run has a fixed sign, the run serving gap $j$ (with sign $t_
j$) cannot serve gap $j+1$ (which needs sign $t_{j+1}$). As the ranges are order
ed, the run index for gap $j+1$ strictly exceeds that for gap $j$. This gives $k
 - 1$ distinct runs, so $k - 1 \le r$, i.e., $k \le r + 1$.

Combining both bounds: $a = r + 1 = 2 + \sum_{i=1}^{n-2} \mathbf{1}[s_i \ne s_{i
+1}]$.

**Step 2: Computing the expectation.**

For i.i.d. continuous $X_1, \ldots, X_n$, the events $\{s_i \ne s_{i+1}\}$ need
not be independent, but by linearity of expectation:
$$E[a] = 2 + \sum_{i=1}^{n-2} P(s_i \ne s_{i+1}).$$

Now $s_i \ne s_{i+1}$ means $X_{i+1}$ is a local extremum of $(X_i, X_{i+1}, X_{
i+2})$:
- $P(s_i = +1, s_{i+1} = -1) = P(X_i < X_{i+1} > X_{i+2}) = P(X_{i+1} \text{ is
the max}) = \frac{1}{3},$
- $P(s_i = -1, s_{i+1} = +1) = P(X_i > X_{i+1} < X_{i+2}) = P(X_{i+1} \text{ is
the min}) = \frac{1}{3}.$

So $P(s_i \ne s_{i+1}) = \frac{2}{3}$ for every $i$, and:
$$E[a(X_1, \ldots, X_n)] = 2 + (n-2)\cdot\frac{2}{3} = 2 + \frac{2n-4}{3} = \fra
c{2n+2}{3} = \boxed{\dfrac{2(n+1)}{3}}.$$

**Verification.** For $n = 2$: $E[a] = 2$ (always zigzag since $X_1 \ne X_2$ a.s
.). For $n = 3$: $P(a=3) = \frac{2}{3}$, $P(a=2) = \frac{1}{3}$, giving $E[a] =
\frac{8}{3}$. Both match $\frac{2(n+1)}{3}$.
