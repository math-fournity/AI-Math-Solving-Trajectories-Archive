## Proof

**Yes, such a function exists.** We construct one explicitly using the Cantor se
t.

### Construction

Let $C \subset [0,1]$ be the middle-thirds Cantor set. The complement $[0,1]\set
minus C$ is a countable union of disjoint open intervals (gaps) $\{(a_n, b_n)\}_
{n=1}^{\infty}$. Let $\ell_n = b_n - a_n$ denote the length of the $n$-th gap. N
ote that $\sum_n \ell_n = 1$, so for any $\eta > 0$, only finitely many gaps hav
e length $\geq \eta$.

Define $f:[0,1]\to\mathbb{R}$ by:
- $f(x) = 0$ for $x \in C$,
- $f(x) = \ell_n \sin\!\left(\dfrac{2\pi(x - a_n)}{\ell_n}\right)$ for $x \in (a
_n, b_n)$.

On each gap, $f$ vanishes at the endpoints $a_n, b_n$, is **positive** on the le
ft half $(a_n,\, a_n + \ell_n/2)$, and **negative** on the right half $(a_n + \e
ll_n/2,\, b_n)$.

### Continuity

On each open gap, $f$ is a composition of continuous functions, hence continuous
. It remains to verify continuity at every $x_0 \in C$.

**Key bounds.** For $x \in (a_n, b_n)$:
1. $|f(x)| \leq \ell_n$ (since $|\sin| \leq 1$).
2. $|f(x)| = \ell_n\left|\sin\!\left(\frac{2\pi(x-a_n)}{\ell_n}\right)\right| \l
eq \ell_n \cdot \frac{2\pi(x-a_n)}{\ell_n} = 2\pi(x - a_n)$, using $|\sin t| \le
q |t|$.
3. Similarly, $|f(x)| \leq 2\pi(b_n - x)$.

Combining (2) and (3): $|f(x)| \leq 2\pi\,\min(x - a_n,\; b_n - x)$.

**Continuity at $x_0 \in C$.** Given $\epsilon > 0$, we find $\delta > 0$ such t
hat $|x - x_0| < \delta \implies |f(x)| < \epsilon$.

Call a gap **large** if $\ell_n \geq \epsilon$. There are finitely many large ga
ps. For each large gap $(a_n, b_n)$:
- If $x_0 \notin \{a_n, b_n\}$: since $x_0 \in C$ and $x_0$ is not an endpoint,
$d_n := d(x_0, [a_n, b_n]) > 0$.
- If $x_0 = a_n$ or $x_0 = b_n$: by bound (2)/(3), $|f(x)| \leq 2\pi|x - x_0|$ f
or $x$ in this gap, so $|f(x)| < \epsilon$ whenever $|x - x_0| < \epsilon/(2\pi)
$.

Set
$$\delta = \min\!\Big(\frac{\epsilon}{2\pi},\;\; \min\{d_n : \text{large gap }(a
_n,b_n),\; x_0 \notin \{a_n,b_n\}\}\Big),$$
where the inner minimum is over a finite set of positive numbers (hence positive
; if the set is empty, take $\delta = \epsilon/(2\pi)$).

Now suppose $|x - x_0| < \delta$:
- **$x \in C$:** $f(x) = 0 < \epsilon$. ✓
- **$x$ in a small gap** ($\ell_n < \epsilon$): $|f(x)| \leq \ell_n < \epsilon$.
 ✓
- **$x$ in a large gap with $x_0$ as endpoint:** $|f(x)| \leq 2\pi|x - x_0| < 2\
pi\delta \leq \epsilon$. ✓
- **$x$ in a large gap without $x_0$ as endpoint:** then $|x - x_0| < \delta \le
q d_n \leq d(x_0, [a_n,b_n])$, which is impossible since $x \in [a_n, b_n]$. ✗ (
contradiction, so this case cannot occur.)

Thus $|f(x)| < \epsilon$ in all possible cases, proving continuity at $x_0$. ∎

### The zero set is uncountable

The zero set is $Z = C \cup \{(a_n + b_n)/2 : n \geq 1\}$ (zeros on $C$ plus the
 midpoint of each gap where $\sin(\pi)=0$). Since $Z \supseteq C$ and the Cantor
 set $C$ is uncountable, $Z$ is uncountable.

### Sign-change condition at every zero

We verify: for every $x_0 \in Z$ and every neighborhood $U$ of $x_0$, there exis
t $a, b \in U$ with $f(a) > 0$ and $f(b) < 0$.

**Case 1: $x_0 \in C$.** Since $C$ is a perfect set (closed with no isolated poi
nts), every neighborhood of $x_0$ contains points of $C \setminus \{x_0\}$, and
more importantly, every neighborhood of $x_0$ contains an entire gap $(a_n, b_n)
$. (The gaps are dense in the complement, and $x_0$ is a limit point of gaps.) O
n this gap, $f > 0$ on the left half and $f < 0$ on the right half, so $U$ conta
ins points where $f > 0$ and points where $f < 0$. ✓

**Case 2: $x_0 = (a_n + b_n)/2$ is the midpoint of a gap.** Then $f(x_0) = \ell_
n \sin(\pi) = 0$. Any neighborhood of $x_0$ contains points in $(a_n, x_0)$ wher
e $f > 0$ and points in $(x_0, b_n)$ where $f < 0$. ✓

### Conclusion

The function $f$ is continuous on $[0,1]$, vanishes on the uncountable set $Z \s
upseteq C$, and at every zero, every neighborhood contains both positive and neg
ative values of $f$. Therefore, **such a function exists**.
