The complexity of these secret codes is restricted by two thresholds, $l$ and $m$. Specifically, the number of "on" bits in code $a$ must be strictly less than $l$, and the number of "on" bits in code $b$ must be strictly less than $m$ ($S_2(a) < l$ and $S_2(b) < m$). It is established that for any fixed integer thresholds $l, m > 2$, the maximum possible Key Value $K$ that can be formed follows the specific structure $2^{f(l, m)} + 1$.

$f(4, 5) + f(5, 6)$
