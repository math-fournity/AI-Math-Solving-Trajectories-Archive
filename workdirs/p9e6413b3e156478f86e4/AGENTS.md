# Problem

A specialized digital security system requires two access codes, $a$ and $b$, to be programmed into its memory. To generate these codes, a technician is provided with a physical set of 16 data tiles. Each tile is inscribed with a single-digit integer. The set contains exactly two tiles for every digit from 2 through 9 (i.e., two 2s, two 3s, two 4s, two 5s, two 6s, two 7s, two 8s, and two 9s).

The technician must use all 16 tiles to form two 8-digit numbers, $a$ and $b$, such that each tile is used exactly once. The system’s stability depends on the numerical discrepancy between these two codes. Specifically, the system calculates a "variance score" by taking the absolute difference between the first number $a$ and exactly twice the value of the second number $b$.

What is the minimum possible variance score $|a - 2b|$ that the technician can achieve?
