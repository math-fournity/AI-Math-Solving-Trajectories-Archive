## Solution

**Claim.** The function $f(n) = A(n,n)$, where $A$ is the Ackermann function, gr
ows faster than any finite composition of logarithms, inverse Ackermann function
s, and arithmetic operations, yet slower than the Busy Beaver function $\mathrm{
BB}(n)$.

### Definitions

**Ackermann function** (standard two-argument form):
$$A(0, n) = n+1, \quad A(m+1, 0) = A(m, 1), \quad A(m+1, n+1) = A(m,\, A(m+1, n)
).$$
Set $f(n) = A(n, n)$.

**Inverse Ackermann** $\alpha(n) = \min\{k : A(k,k) \geq n\}$.

**Busy Beaver** $\mathrm{BB}(n) = \max\{\text{number of 1s printed by a halting
$n$-state, 2-symbol TM on blank input}\}$.

**Class $\mathcal{C}$**: all functions obtained from $\log$, $\alpha$, $+$, $-$,
 $\times$, $/$ by finite composition and combination.

### Part 1: $f$ grows faster than every $g \in \mathcal{C}$

**Lemma 1.** Every $g \in \mathcal{C}$ satisfies $g(n) = O\big((\log n)^k\big)$
for some constant $k$ depending on $g$.

*Proof by structural induction on the construction of $g$.*

- **Base functions.** $\log n = O((\log n)^1)$. Since $\alpha(n) = o(\log^* n)$
and $\log^* n = o(\log n)$, we have $\alpha(n) = O((\log n)^1)$.
- **Arithmetic combination.** If $g = O((\log n)^a)$ and $h = O((\log n)^b)$, th
en:
  - $g + h,\; g - h = O((\log n)^{\max(a,b)})$,
  - $g \cdot h = O((\log n)^{a+b})$,
  - $g / h = O((\log n)^{a})$ (when defined and $h$ bounded away from $0$).
  Each result is still $O((\log n)^K)$ for some constant $K$.
- **Composition.** If $g = O((\log n)^a)$, then $\log(g(n)) = O(\log \log n) = O
((\log n)^1)$, and $\alpha(g(n)) = o(\log^* g(n)) = O((\log n)^1)$. More general
ly, $g(h(n))$ with $h = O((\log n)^b)$ gives $g(h(n)) = O((\log h(n))^a) = O((\l
og\log n)^a) = O((\log n)^a)$. Composition never *increases* the polylogarithmic
 degree.

By induction, every $g \in \mathcal{C}$ is $O((\log n)^k)$ for some fixed $k$. $
\square$

**Lemma 2.** $A(n,n)$ eventually dominates every primitive recursive function.

This is the classical theorem of Péter (1935): the Ackermann function is total r
ecursive but not primitive recursive, and $A(n,n) > p(n)$ for all sufficiently l
arge $n$, for every primitive recursive $p$. $\square$

**Combining.** For any $g \in \mathcal{C}$, by Lemma 1, $g(n) \leq C(\log n)^k$
for constants $C, k$. The function $n \mapsto C(\log n)^k$ is primitive recursiv
e. By Lemma 2, $A(n,n) > C(\log n)^k \geq g(n)$ for all sufficiently large $n$.
Therefore

$$\frac{A(n,n)}{g(n)} \to \infty \quad \text{for every } g \in \mathcal{C}.$$

### Part 2: $\mathrm{BB}(n)$ grows faster than $f(n) = A(n,n)$

**Theorem (Busy Beaver domination).** For every computable (total recursive) fun
ction $h$, there exists $N$ such that $\mathrm{BB}(n) > h(n)$ for all $n \geq N$
.

*Proof.* Let $M$ be a TM computing $h$, using $s$ states. For each $n$, construc
t a TM $T_n$ that (i) writes $n$ in binary on the tape — this requires $O(\log n
)$ states — and (ii) runs $M$ to compute and output $h(n)$. The total number of
states is $c\log n + s$ for a constant $c$. Hence

$$\mathrm{BB}(c\log n + s) \geq h(n) \quad \text{for all } n \geq 2.$$

Setting $m = c\log n + s$, so $n = 2^{(m-s)/c}$:

$$\mathrm{BB}(m) \geq h\!\left(2^{(m-s)/c}\right) \quad \text{for } m \geq s + c
.$$

Since $2^{(m-s)/c}$ grows exponentially in $m$ while $h$ is non-decreasing (repl
ace $h$ by its running max, still computable), we have $h(2^{(m-s)/c}) \geq h(m)
$ for all sufficiently large $m$. Therefore $\mathrm{BB}(m) > h(m)$ for all suff
iciently large $m$. $\square$

Since $f(n) = A(n,n)$ is total recursive (computable), the theorem applies: $\ma
thrm{BB}(n) > A(n,n)$ for all sufficiently large $n$.

$$\boxed{f(n) = A(n, n)}$$
