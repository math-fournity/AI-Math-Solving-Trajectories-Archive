The four sub-triangle areas are:
- **△BDF** = (BD/BC)(BF/BA)·S = x·(3/5)·S
- **△AEF** = (AE/AC)(AF/AB)·S = y·(2/5)·S
- **△CDE** = (CD/CB)(CE/CA)·S = (1−x)(1−y)·S
- **△DEF** = S − [△AEF + △BDF + △CDE] = (2x/5 + 3y/5 − xy)·S

**Given:** △BDF = 9, so (3x/5)S = 9, giving **xS = 15**, i.e., x = 15/S.

d = S − 9 − a − c = **6 + 3a/2 − 75a/(2S)**

The two unknowns are S and a. Each scenario provides equations; we check if S is
