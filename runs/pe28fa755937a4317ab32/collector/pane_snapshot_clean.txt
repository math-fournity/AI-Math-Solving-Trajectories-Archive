## Setting Up the Framework

**Key characterization:** Four points (no three collinear) form a concave quadri
lateral if and only if exactly one point lies strictly inside the triangle forme
d by the other three. (If all four are on the convex hull, the quadrilateral is
convex.)

**Which point can be interior?** Since $A$ and $B$ sit at $y=0$ while all grid p
oints have $y \geq 1$, neither $A$ nor $B$ can be the interior point — any trian
gle $BPQ$ or $APQ$ has its lowest point at $y=0$ (at $B$ or $A$), so its interio
r has $y>0$ everywhere, excluding $A$ or $B$.

So the interior point must be $P$ or $Q$. These cases are mutually exclusive (if
 $P \in \triangle ABQ$, then $Q$ is a convex hull vertex, so $Q \notin \triangle
 ABP$). Thus:

$$\text{Answer} = \#\{(P,Q) \text{ ordered, distinct: } P \in \operatorname{int}
(\triangle ABQ)\}$$

## Counting Interior Points

Fix $Q=(x_2, y_2)$ with $0 \le x_2 \le 59$, $1 \le y_2 \le 5$. I need $P=(x_1,y_
1)$ strictly inside $\triangle ABQ$.

Using cross-product orientation tests for the three edges:

1. **Edge $AB$** ($y=0$): requires $y_1 > 0$ — always satisfied since $y_1 \ge 1
$.
2. **Edge $AQ$**: requires $x_2 y_1 < y_2 x_1$, i.e., $x_1 > \frac{x_2 y_1}{y_2}
$.
3. **Edge $BQ$**: requires $y_2(x_1-1) < (x_2-1)y_1$, i.e., $x_1 < \frac{(x_2-1)
y_1}{y_2}+1$.

The interval for $x_1$ is:
$$\left(\frac{x_2 y_1}{y_2},\; \frac{(x_2-1)y_1 + y_2}{y_2}\right)$$

Its width is $\frac{y_2 - y_1}{y_2} = 1 - \frac{y_1}{y_2}$.

- If $y_1 \ge y_2$: width $\le 0$, no integer solution.
- If $y_1 < y_2$: width $\in (0,1)$, so **at most one** integer $x_1$ fits.

**When does exactly one integer fit?** The candidate is $x_1 = \lfloor x_2 y_1/y
_2 \rfloor + 1$. It lies in the open interval iff the fractional part $\{x_2 y_1
/y_2\} > y_1/y_2$ (this also ensures $x_2 y_1/y_2$ is not an integer, avoiding e
dge cases).

The grid bounds $0 \le x_1 \le 59$ are automatically satisfied since $x_1 < x_2
\le 59$ and $x_1 \ge 1$.

**No collinearity issues:** Strict inequalities exclude all edge points, so no t
hree of the four points are collinear — the quadrilateral is always non-degenera
te.

## Evaluating the Sum

$$\text{Answer} = \sum_{y_2=2}^{5}\sum_{y_1=1}^{y_2-1}\sum_{x_2=0}^{59} \mathbf{
1}\!\left[\left\{\frac{x_2 y_1}{y_2}\right\} > \frac{y_1}{y_2}\right]$$

Let $g=\gcd(y_1,y_2)$, $a=y_1/g$, $b=y_2/g$ with $\gcd(a,b)=1$. The condition be
