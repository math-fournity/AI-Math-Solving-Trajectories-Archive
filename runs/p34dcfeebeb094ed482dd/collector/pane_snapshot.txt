## Proof

**Construction of the Cantor set and removed intervals.** The Cantor set $C \sub
set [0,1]$ is built by iteratively removing open middle thirds:
- Stage 1: remove $(1/3,\, 2/3)$
- Stage 2: remove $(1/9,\, 2/9)$ and $(7/9,\, 8/9)$
- Stage $n$: remove $2^{n-1}$ open intervals, each of length $1/3^n$

The union of all removed open intervals is $[0,1]\setminus C$.

**Identifying the "adjacent" points.** A point $x \in C$ is *adjacent to a remov
ed interval* if $x$ is an endpoint of one of the removed open intervals. Let $E$
 denote this set.

**$E$ is countable.** At stage $n$, exactly $2^{n-1}$ open intervals are removed
, each contributing exactly $2$ endpoints, giving $2^n$ endpoints at that stage.
 The endpoints at stage $n$ are precisely the numbers in $[0,1]$ whose ternary e
xpansion terminates at position $n$ using only digits $0$ and $2$—i.e., numbers
of the form $a/3^n$ with $3 \nmid a$. Such a fraction $a/3^n$ (in lowest terms)
equals $b/3^m$ (in lowest terms) only when $n=m$ and $a=b$, so **all endpoints a
cross all stages are distinct**. Therefore:
$$|E| = \sum_{n=1}^{\infty} 2^n = \aleph_0.$$
The set $E$ is countably infinite.

**The irrational numbers are uncountable.** The set $\mathbb{R}\setminus\mathbb{
Q}$ has cardinality $2^{\aleph_0}$ (the continuum), which is strictly greater th
an $\aleph_0$.

**Homeomorphism requires equal cardinality.** A homeomorphism is, in particular,
 a bijection. A bijection can exist only between sets of the same cardinality. S
ince $|E| = \aleph_0 < 2^{\aleph_0} = |\mathbb{R}\setminus\mathbb{Q}|$, **no bij
ection**—and hence no homeomorphism—can exist between $E$ and $\mathbb{R}\setmin
us\mathbb{Q}$.

The set of all points in the Cantor set that are adjacent to (i.e., are endpoint
s of) removed intervals is **countable**, whereas the set of irrational numbers
is **uncountable**. Since a homeomorphism requires a bijection, and sets of diff
erent cardinalities cannot be in bijection, the two sets are **not homeomorphic*
