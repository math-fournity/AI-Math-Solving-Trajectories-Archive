## Solution

Label the cubicles as a 3×3 grid:

```
1 2 3
4 5 6
7 8 9
```

Two cubicles conflict (share a wall) exactly when they are horizontally or verti
cally adjacent. Diagonal contact is allowed. We count independent sets of size 3
 in this grid graph.

**Key observation:** No two chosen cubicles may lie in the same row *and* be adj
acent, and no chosen cubicle in one row may be vertically adjacent to a chosen c
ubicle in the row directly below/above. Cubicles in the top and bottom rows neve
r conflict (they are not edge-adjacent).

Within a single row of three cells {a,b,c} with edges a–b, b–c, the only indepen
dent set of size 2 is {a,c} (the two endpoints). No row can contribute 3 cells.

**Case analysis by how the 3 selections are distributed across the three rows**
(top, middle, bottom), denoted (a,b,c) with a+b+c=3.

**Rows of size 3 are impossible** in any row (a path of 3 admits no independent
set of size 3), so (3,0,0), (0,3,0), (0,0,3) and all permutations contribute 0.

**Distribution (2,1,0):** Top row must be {1,3}. Middle picks one cell not adjac
ent to 1 or 3. Since 1–4 and 3–6 are edges, the only option is 5.
→ **1 way:** {1,3,5}.

**Distribution (2,0,1):** Top = {1,3}. Bottom picks one cell; top and bottom row
s share no edges, so any of {7,8,9} works.
→ **3 ways:** {1,3,7}, {1,3,8}, {1,3,9}.

**Distribution (1,2,0):** Middle = {4,6}. Top picks one cell not adjacent to 4 o
r 6. Since 1–4 and 3–6, the only option is 2.
→ **1 way:** {2,4,6}.

**Distribution (0,2,1):** Middle = {4,6}. Bottom picks one cell not adjacent to
4 or 6. Since 4–7 and 6–9, the only option is 8.
→ **1 way:** {4,6,8}.

**Distribution (1,0,2):** Bottom = {7,9}. Top picks one cell; no top–bottom edge
s, so any of {1,2,3} works.
→ **3 ways:** {1,7,9}, {2,7,9}, {3,7,9}.

**Distribution (0,1,2):** Bottom = {7,9}. Middle picks one cell not adjacent to
7 or 9. Since 4–7 and 6–9, the only option is 5.
→ **1 way:** {5,7,9}.

**Distribution (1,1,1):** One cell per row. Top and bottom never conflict; the o
nly constraints are top–middle and middle–bottom non-adjacency. The vertical edg
es are 1–4, 2–5, 3–6 (top–middle) and 4–7, 5–8, 6–9 (middle–bottom).

For each choice of middle cell m, the top is forbidden from being the cell direc
tly above m, and the bottom is forbidden from being the cell directly below m:

- m = 4: top ∈ {2,3} (not 1), bottom ∈ {8,9} (not 7) → 2·2 = 4
- m = 5: top ∈ {1,3} (not 2), bottom ∈ {7,9} (not 8) → 2·2 = 4
- m = 6: top ∈ {1,2} (not 3), bottom ∈ {7,8} (not 9) → 2·2 = 4

→ **12 ways.**

**Total:**

$$1 + 3 + 1 + 1 + 3 + 1 + 12 = 22.$$

Each counted set was verified to have no two cells sharing an edge, and the case
 partition (by row-distribution) is exhaustive and disjoint, so every valid conf
iguration is counted exactly once.

$$\boxed{22}$$
