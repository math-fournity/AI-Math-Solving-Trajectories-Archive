## Key Lemma

**For all positive integers $x, y$: $s(x)\,s(y) \ge s(xy)$.**

*Proof.* Write $x = \sum_i a_i\,10^i$ and $y = \sum_j b_j\,10^j$ where $0 \le a_
i, b_j \le 9$. Then
$$xy = \sum_{i,j} a_i b_j\,10^{i+j}.$$
Since digit sum is subadditive ($s(p+q) \le s(p)+s(q)$, as carries only reduce d
igit sums), repeated application gives:
$$s(xy) \le \sum_{i,j} s(a_i b_j) = \sum_{i,j} a_i b_j = \Big(\sum_i a_i\Big)\Bi
g(\sum_j b_j\Big) = s(x)\,s(y). \quad\checkmark$$

So $n=xy$ is zesty iff $s(x)\,s(y) = s(n)$, i.e., the multiplication $x \cdot y$
 involves **no carries that reduce the digit sum**. Also, $s(x)s(y) \equiv xy \e
quiv s(n) \pmod{9}$ always, so $s(x)s(y) - s(n)$ is always a non-negative multip
le of 9.
