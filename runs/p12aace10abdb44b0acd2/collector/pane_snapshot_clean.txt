## Proof

**Reformulation.** Let $x_i = \mathbf{1}[i \in I]$ and $c_i = x_i - m/n$, so $\s
um c_i = 0$. We need non-decreasing $a_1 \le \cdots \le a_n$ with $\sum c_i a_i
> 0$.

**Summation by parts.** Set $C_i = \sum_{j=1}^i c_j$ (so $C_n = 0$). Then:
$$\sum_{i=1}^n c_i a_i = -\sum_{i=1}^{n-1} C_i\,(a_{i+1} - a_i).$$
Since $d_i := a_{i+1} - a_i \ge 0$ are free non-negative reals, this expression
can be made strictly positive **iff** some $C_i < 0$.

**Good vs. bad.** Define $f(i) = |I \cap \{1,\dots,i\}| - \frac{mi}{n} = C_i$. T
hen:
- $I$ is **good** (admissible assignment exists) iff $\min_{1 \le i \le n-1} f(i
) < 0$.
- $I$ is **bad** iff $f(i) \ge 0$ for all $1 \le i \le n-1$.

The desired $k$ is the maximum of $S(I) = \sum_{i \in I} i$ over all bad sets $I
$.

**Characterizing bad sets.** Since $\gcd(m,n)=1$, the value $\frac{mi}{n}$ is ne
ver an integer for $1 \le i \le n-1$. So $f(i) \ge 0$ is equivalent to $|I \cap
\{1,\dots,i\}| \ge \lceil mi/n \rceil$.

The binding constraints occur where $\lceil mi/n \rceil$ jumps to $j$. Define:
$$i_j = \left\lfloor \frac{(j-1)\,n}{m} \right\rfloor + 1, \quad j = 1, \dots, m
.$$
At position $i_j$, we need at least $j$ elements of $I$ in $\{1,\dots,i_j\}$, i.
e., the $j$-th smallest element of $I$ is $\le i_j$. Between consecutive jump po
ints the constraint is automatically weaker, so the full constraint reduces to:
**the $j$-th smallest element of $I$ is at most $i_j$** for each $j = 1, \dots,
m$.

**Maximizing the sum.** To maximize $S(I)$, place the $j$-th element at the late
st allowed position $i_j$. The positions are strictly increasing since $i_{j+1}
- i_j = \lfloor jn/m \rfloor - \lfloor (j-1)n/m \rfloor \ge 1$ (as $n/m > 1$). O
ne verifies directly that $I^* = \{i_1, \dots, i_m\}$ satisfies $f(i) \ge 0$ for
 all $i$, so it is bad.

The maximum sum is:
$$k = \sum_{j=1}^m i_j = \sum_{j=1}^m \left(\left\lfloor \frac{(j-1)n}{m} \right
\rfloor + 1\right) = m + \sum_{r=0}^{m-1} \left\lfloor \frac{rn}{m} \right\rfloo
r.$$

**Evaluating the floor sum.** By the classical lattice-point argument: since $\g
cd(m,n)=1$, no lattice point $(r,s)$ with $1 \le r \le m-1$, $1 \le s \le n-1$ l
ies on the line $sn = rm$. The $(m-1)(n-1)$ lattice points in this rectangle spl
it evenly above and below the line, giving:
$$\sum_{r=1}^{m-1} \left\lfloor \frac{rn}{m} \right\rfloor = \frac{(m-1)(n-1)}{2
}.$$
(The $r=0$ term is $0$.)

Therefore:
$$k = m + \frac{(m-1)(n-1)}{2} = \frac{2m + (m-1)(n-1)}{2} = \frac{mn + m - n +
1}{2}.$$

**Integrality.** $mn + m - n + 1 = (m-1)(n+1) + 2$. If both $m,n$ are odd, $m-1$
 is even so the product is even. If one is even, $mn$ is even and one checks par
ity directly. In all cases the numerator is even, so $k$ is an integer.

**Verification.** For $n=5, m=2$: $k = \frac{10+2-5+1}{2} = 4$. Bad sets are $\{
1,2\}$ (sum 3) and $\{1,3\}$ (sum 4); max is 4. ✓

For $n=5, m=3$: $k = \frac{15+3-5+1}{2} = 7$. The extremal bad set is $\{1,2,4\}
$ with sum 7; all 3-subsets with sum $\ge 8$ are good. ✓

## Answer

$$\boxed{k = \dfrac{mn + m - n + 1}{2}}$$
