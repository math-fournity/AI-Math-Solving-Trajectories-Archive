## Proof

twork and $G' = G - H$ the graph obtained by removing $H$. The $2010$ neighbors
of $H$ are distributed among the connected components of $G'$. Call a component
of $G'$ a **singleton component** if it contains exactly one neighbor of $H$, an
d a **multi-neighbor component** if it contains $\geq 2$ neighbors of $H$.

**Key observation on deletable edges.** For each multi-neighbor component with $
r$ neighbors of $H$, we can delete $r-1$ of those $r$ edges (keeping one maintai
ns connectivity to $H$). For each singleton component, we must keep its single e
dge. If there are $s$ singleton components and $t$ multi-neighbor components, th
e number of deletable edges is:
$$2010 - s - t = 2010 - (s+t).$$
Thus $k = 2010 - \max(s+t)$, where the maximum is over all valid configurations.

**Bounding $s$ via the parity condition.** The condition states: if two non-cent
ral vertices share the same degree, that degree is even. Equivalently, **each od

ble odd degrees in $\{1, 2, \ldots, 2009\}$ are $1, 3, 5, \ldots, 2009$ — exactl

**Each singleton component consumes at least one odd degree.** A singleton compo
nent contains one neighbor $v$ of $H$ and some non-neighbors. The sum of degrees
 (in $G$) of all vertices in this component equals:
$$1 + 2|E_{\text{internal}}|,$$
which is **odd** (the $1$ comes from the single edge to $H$). By the handshake l
emma, at least one vertex in the component has odd degree. So each singleton com
ponent uses $\geq 1$ odd degree value.

**Parity constraint on multi-neighbor components.** For a multi-neighbor compone
nt with $r$ neighbors, the sum of degrees (in $G$) equals $r + 2|E_{\text{intern
al}}|$, with parity equal to $r \bmod 2$. If $r$ is odd, this sum is odd, requir
ing at least one odd-degree vertex. The total sum of all non-central degrees is
even (since $\deg(H) = 2010$ is even and total degree sum is $2|E|$). Therefore:
$$s + (\text{number of multi-neighbor components with odd } r) \equiv 0 \pmod{2}
.$$

**Why $s \leq 1004$.** If $s = 1005$ (odd), then the number of multi-neighbor co
mponents with odd $r$ must be odd, hence $\geq 1$. Such a component requires $\g
eq 1$ odd degree. Total odd degrees needed: $1005 + 1 = 1006 > 1005$. **Impossib
le.**

If $s = 1006$, we'd need $1006$ odd degrees for singletons alone, exceeding $100
5$. **Impossible.**

So $s \leq 1004$.

**Bounding $s + t$.** Since each multi-neighbor component has $\geq 2$ neighbors

$$s + t \leq s + \frac{2010 - s}{2} = \frac{s + 2010}{2}.$$
This is maximized at $s = 1004$: $s + t \leq \frac{1004 + 2010}{2} = 1507$.

**Construction achieving $s + t = 1507$.** We build a graph with $s = 1004$ sing

- $\deg_G(a_j) = \deg_G(b_j) = 2$ (even).
