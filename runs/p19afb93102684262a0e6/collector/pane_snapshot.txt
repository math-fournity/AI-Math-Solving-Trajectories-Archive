## Proof

geq 0$. The logarithms $\ln(b/a)$ etc. require $a, b, c > 0$. Set $x = \sqrt{a},
\; y = \sqrt{b},\; z = \sqrt{c}$, so $x, y, z > 0$, $x + y + z = 1$, and $x, y,
z$ are distinct (since $a,b,c$ distinct and non-negative). Then $a = x^2, b = y^
2, c = z^2$.

**Rewriting via the logarithmic mean.** Recall the **logarithmic mean** of two p
ositive reals:
$$L(a,b) = \frac{b - a}{\ln b - \ln a} = \frac{b-a}{\ln(b/a)}, \quad a \neq b.$$

Each term of the expression rewrites as:
$$\frac{ab}{b-a}\ln\frac{b}{a} = \frac{ab}{L(a,b)}.$$

So the expression is $E = \frac{ab}{L(a,b)} + \frac{bc}{L(b,c)} + \frac{ca}{L(c,
a)}$.

**Key inequality: $L(a,b) \geq \sqrt{ab}$ (logarithmic mean ≥ geometric mean).**

*Proof.* WLOG $b > a > 0$. Let $t = b/a > 1$ and $u = \sqrt{t} > 1$. We need $\f
rac{t-1}{\ln t} \geq \sqrt{t}$, i.e., $u^2 - 1 \geq 2u\ln u$. Define $g(u) = \fr
ac{u^2 - 1}{2u} - \ln u$. Then $g(1) = 0$ and
$$g'(u) = \frac{1}{2} + \frac{1}{2u^2} - \frac{1}{u} = \frac{(u-1)^2}{2u^2} \geq
 0.$$
So $g(u) \geq 0$ for $u \geq 1$, proving the inequality. Moreover, $g'(u) > 0$ f
or $u > 1$, so the inequality is **strict** when $a \neq b$. $\square$

**Upper bound.** Applying the key inequality to each term (with $a = x^2, b = y^
2$, so $\sqrt{ab} = xy$):
$$\frac{ab}{L(a,b)} \leq \frac{ab}{\sqrt{ab}} = \sqrt{ab} = xy,$$
and similarly for the other two terms. Therefore:
$$E \leq xy + yz + zx.$$

By the well-known inequality $xy + yz + zx \leq \frac{(x+y+z)^2}{3}$ (which foll

$$E \leq xy + yz + zx \leq \frac{(x+y+z)^2}{3} = \frac{1}{3}.$$

**Strictness.** Both inequalities are strict when $a, b, c$ are distinct:
- $L(a,b) > \sqrt{ab}$ strictly when $a \neq b$ (since $g'(u) > 0$ for $u > 1$).
- $xy + yz + zx < \frac{1}{3}$ strictly when $x, y, z$ are not all equal.

Therefore $E < \frac{1}{3}$ for every valid configuration.

$$E \to 3 \cdot \frac{1}{9} = \frac{1}{3}.$$
