## Solution

We solve the first-order nonlinear PDE $v_x^2 + v_y^2 = v^2$ with the initial co
ndition $v(0,y)=1$ using the method of characteristics.

### Setting up the characteristic equations

Let $F(x,y,v,p,q) = p^2 + q^2 - v^2 = 0$, where $p = v_x$ and $q = v_y$. The Cha
rpit characteristic equations are:

$$\frac{dx}{ds} = F_p = 2p, \quad \frac{dy}{ds} = F_q = 2q, \quad \frac{dv}{ds}
= pF_p + qF_q = 2(p^2+q^2) = 2v^2,$$

$$\frac{dp}{ds} = -F_x - pF_v = 2pv, \quad \frac{dq}{ds} = -F_y - qF_v = 2qv.$$

### Determining initial data

Parameterize the initial curve as $x=0,\; y=t,\; v=1$. The compatibility conditi
on along the initial curve requires

$$\frac{dv}{dt} = v_x\frac{dx}{dt} + v_y\frac{dy}{dt} = p\cdot 0 + q\cdot 1 = q.
$$

Since $v(0,t)=1$ is constant, $\frac{dv}{dt}=0$, so $q=0$ on the initial curve.
The PDE then gives $p^2 = v^2 = 1$, so $p = \pm 1$.

### Solving the characteristic ODEs (taking $p=1$)

Initial data at $s=0$: $x=0,\; y=t,\; v=1,\; p=1,\; q=0$.

**Relation between $p$ and $v$:** From $\frac{dp}{ds}=2pv$ and $\frac{dv}{ds}=2v
^2$,

$$\frac{dp}{dv} = \frac{p}{v} \implies p = Cv.$$

At $s=0$: $1 = C\cdot 1$, so $C=1$, giving $\boxed{p = v}$.

**Relation between $q$ and $v$:** Similarly $\frac{dq}{dv} = \frac{q}{v} \implie
s q = Dv$. At $s=0$: $0 = D\cdot 1$, so $D=0$, giving $\boxed{q = 0}$.

**Solving for $v$:** $\frac{dv}{ds} = 2v^2$ separates to $-\frac{1}{v} = 2s + C_
1$. With $v(0)=1$: $C_1 = -1$, so

$$v = \frac{1}{1-2s}.$$

**Solving for $x$:** $\frac{dx}{ds} = 2p = 2v = \frac{2}{1-2s}$, giving $x = -\l
n(1-2s) + C_2$. With $x(0)=0$: $C_2=0$, so

$$x = -\ln(1-2s) \implies 1-2s = e^{-x} \implies v = \frac{1}{e^{-x}} = e^x.$$

**Solving for $y$:** $\frac{dy}{ds} = 2q = 0$, so $y = t$ (constant along each c
haracteristic).

### The solution

$$v(x,y) = e^x.$$

### Verification

- $v_x = e^x$, $v_y = 0$, so $v_x^2 + v_y^2 = e^{2x} = (e^x)^2 = v^2$. ✓
- $v(0,y) = e^0 = 1$. ✓

### The second branch

Taking $p = -1$ on the initial curve, the same computation yields $p = -v$, $\fr
ac{dv}{ds} = 2v^2$ (unchanged), and $\frac{dx}{ds} = 2p = -2v = \frac{-2}{1-2s}$
, giving $x = \ln(1-2s)$. Thus $1-2s = e^{x}$ and $v = \frac{1}{e^x} = e^{-x}$.

Verification: $v_x = -e^{-x}$, $v_x^2 + v_y^2 = e^{-2x} = v^2$. ✓, and $v(0,y)=1
$. ✓

### Conclusion

The method of characteristics yields two solutions satisfying the initial condit
ion $v(0,y)=1$:

$$\boxed{v(x,y) = e^x \quad \text{and} \quad v(x,y) = e^{-x}.}$$

Both are independent of $y$ (consistent with the initial data being constant alo
ng the $y$-axis), and both satisfy the PDE and the initial condition.
