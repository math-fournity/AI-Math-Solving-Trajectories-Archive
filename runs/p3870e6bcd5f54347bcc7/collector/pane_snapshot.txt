Set $A = \lfloor kx \rfloor$ and $y = kx - A \in [0,1)$. The digits of $x$ from
position $n+1$ onward are the decimal digits of $y$.

**Assume** all digits from position $n+1$ to $n+m$ are 2. Then the first $m$ dig

$$\frac{2(1-10^{-m})}{9} \le y < \frac{2}{9} + \frac{7}{9\cdot 10^m}.$$

Let $\eta = y - \tfrac{2}{9}$, so $|\eta| < \tfrac{1}{10^m}$.

Since $kx = A + \tfrac{2}{9} + \eta$, we get $x = \frac{9A+2+9\eta}{9k}$. Set $p

$$(p + 9\eta)^3 = 3(9k)^3 = 2187\,k^3 = 2187\cdot 10^{3n}.$$

Expanding: $2187\cdot 10^{3n} - p^3 = 27p^2\eta + 243p\,\eta^2 + 729\eta^3$.

**Bounding $p$:** Since $\sqrt[3]{3} < 1.45$ (as $1.45^3 = 3.048\ldots > 3$), we

$$|27p^2\eta| < 27\cdot 196\,k^2\cdot 10^{-m} = 5292\cdot 10^{2n-m}.$$

Now $2n - m = 2(999999) - 2141593 = -141595 < 0$, so $|27p^2\eta| < 5292\cdot 10

The remaining terms $|243p\,\eta^2| < 3402\cdot 10^{n-2m}$ and $|729\eta^3| < 10

Therefore $|2187\cdot 10^{3n} - p^3| < 1$.

$$p^3 = 2187\cdot 10^{3n} = 3^7 \cdot 2^{3n}\cdot 5^{3n}.$$

For $p$ to be an integer, $3^7\cdot 2^{3n}\cdot 5^{3n}$ must be a perfect cube.
However, the exponent of the prime $3$ is $7$, and $7 \not\equiv 0 \pmod{3}$. Th

Therefore, our assumption is false: not all digits from position $1{,}000{,}000$
