## Solution

**Setting up the system.** The three equations are:

$$
(y+z-x)^2 - \tfrac{1}{3} = 4(y-z)^2, \quad (x+z-y)^2 - \tfrac{1}{4} = 4(z-x)^2,
\quad (x+y-z)^2 - \tfrac{1}{5} = 4(x-y)^2.
$$

**Substitution.** Let $a = y+z-x$, $b = x+z-y$, $c = x+y-z$, and $s = a+b+c = x+
y+z$. Then:
$$x = \tfrac{b+c}{2},\quad y = \tfrac{a+c}{2},\quad z = \tfrac{a+b}{2},$$
and $y-z = \tfrac{c-b}{2}$, $z-x = \tfrac{a-c}{2}$, $x-y = \tfrac{b-a}{2}$.

The system becomes:
$$a^2 - \tfrac{1}{3} = (c-b)^2, \quad b^2 - \tfrac{1}{4} = (a-c)^2, \quad c^2 -
\tfrac{1}{5} = (b-a)^2.$$

**Difference of squares.** Each equation factors, e.g. $a^2-(c-b)^2 = (a-c+b)(a+
c-b)$. Setting $u = s-2a = b+c-a$, $v = s-2b = a+c-b$, $w = s-2c = a+b-c$:

$$wv = \tfrac{1}{3}, \quad uw = \tfrac{1}{4}, \quad uv = \tfrac{1}{5}.$$

**Solving for $u^2, v^2, w^2$.** Dividing products pairwise:
$$u^2 = \frac{uw \cdot uv}{vw} = \frac{\frac14 \cdot \frac15}{\frac13} = \frac{3
}{20}, \quad v^2 = \frac{vw \cdot uv}{uw} = \frac{4}{15}, \quad w^2 = \frac{vw \
cdot uw}{uv} = \frac{5}{12}.$$

Since $uv, vw, uw > 0$, all of $u,v,w$ share the same sign, so $s = u+v+w$ is de
termined up to sign — but only $s^2$ matters.

**Computing the symmetric sums.**
$$u^2+v^2+w^2 = \frac{9+16+25}{60} = \frac{50}{60} = \frac{5}{6},$$
$$uv+vw+uw = \frac{1}{5}+\frac{1}{3}+\frac{1}{4} = \frac{12+20+15}{60} = \frac{4
7}{60}.$$

Therefore:
$$s^2 = (u+v+w)^2 = \frac{5}{6} + 2\cdot\frac{47}{60} = \frac{50+94}{60} = \frac
{144}{60} = \frac{12}{5}.$$

**Expressing $xy+yz+zx$ in terms of $u,v,w$.** Since $a = \frac{s-u}{2}$, etc.,
and $u+v+w = s$:
$$ab+bc+ca = \tfrac14\big[3s^2 - 2s(u+v+w) + (uv+vw+wu)\big] = \tfrac14\big[s^2
+ (uv+vw+wu)\big].$$

Also $xy+yz+zx = \frac{s^2 + (ab+bc+ca)}{4}$ (verified by direct expansion: the
numerator equals $(a+b+c)^2 + (ab+bc+ca)$). Hence:
$$xy+yz+zx = \frac{s^2 + \frac14[s^2 + (uv+vw+wu)]}{4} = \frac{5s^2 + (uv+vw+wu)
}{16}.$$

**Final computation.**
$$xy+yz+zx = \frac{5\cdot\frac{12}{5} + \frac{47}{60}}{16} = \frac{12 + \frac{47
}{60}}{16} = \frac{\frac{767}{60}}{16} = \frac{767}{960}.$$

**Reducing.** $767 = 13 \times 59$ and $960 = 2^6 \times 3 \times 5$ are coprime
, so $\frac{767}{960}$ is already in lowest terms.

Thus $p = 767$, $q = 960$, and
$$p + q = \boxed{1727}.$$

### PROOF COMPLETE
