## Proof

**Claim:** The unit interval $[0,1]$ does **not** admit a finite partition into
sets, each of which contains no open interval.

**Proof.** Suppose for contradiction that $[0,1] = A_1 \cup A_2 \cup \cdots \cup
 A_n$, where the $A_i$ are pairwise disjoint and each $A_i$ contains no (nonempt
y) open interval.

**Step 1: Each $A_i$ has empty interior in $[0,1]$.**

The interior of $A_i$ in the subspace topology of $[0,1]$ consists of all points
 $x \in A_i$ for which there exists $\varepsilon > 0$ with $(x-\varepsilon,\, x+
\varepsilon)\cap[0,1] \subseteq A_i$.

- If $0 < x < 1$ is an interior point, then for small enough $\varepsilon$, the
entire interval $(x-\varepsilon, x+\varepsilon) \subseteq A_i$, so $A_i$ contain
s an open interval — contradiction.
- If $x = 0$ is an interior point, then $[0, \varepsilon) \subseteq A_i$ for som
e $\varepsilon > 0$, hence $(0, \varepsilon) \subseteq A_i$, an open interval —
contradiction.
- If $x = 1$ is an interior point, then $(1-\varepsilon, 1] \subseteq A_i$ for s
ome $\varepsilon > 0$, hence $(1-\varepsilon, 1) \subseteq A_i$, an open interva
l — contradiction.

Therefore $\operatorname{int}_{[0,1]}(A_i) = \emptyset$ for every $i$.

**Step 2: Apply the Baire Category Theorem.**

The space $[0,1]$ is a complete metric space (it is a closed subset of $\mathbb{
R}$). The Baire Category Theorem states that a complete metric space cannot be w
ritten as a countable union of closed sets with empty interior. More generally (
and in the form we need), a complete metric space is **not** a countable union o
f sets with empty interior — equivalently, it is a Baire space, meaning the inte
rsection of countably many dense open sets is dense, which implies it is not a c
ountable (in particular, finite) union of nowhere dense sets.

Since each $A_i$ has empty interior, it is nowhere dense (its closure has empty
interior as well, since $\overline{A_i} \subseteq [0,1]$ and if $\overline{A_i}$
 contained an open interval, so would a dense subset of it). Thus each $A_i$ is
nowhere dense in $[0,1]$.

By the Baire Category Theorem, $[0,1]$ cannot be the union of finitely (or count
ably) many nowhere dense subsets. This contradicts $[0,1] = A_1 \cup \cdots \cup
 A_n$.

**Conclusion.** No such finite partition exists. $\blacksquare$
