Looking at this problem, I need to determine whether $\mathbb{R}$ can be partiti
oned into uncountably many countably infinite subsets, each of which is discrete
 (contains none of its limit points).

**Answer: Yes**

**Proof.**

Consider the additive subgroup $\mathbb{Z} \subset \mathbb{R}$. The cosets of $\
mathbb{Z}$ in $\mathbb{R}$ form a partition of $\mathbb{R}$. Explicitly, for eac
h $x \in \mathbb{R}$, define
$$[x] = x + \mathbb{Z} = \{x + n : n \in \mathbb{Z}\}.$$
Two reals $x, y$ belong to the same coset if and only if $x - y \in \mathbb{Z}$.
 The collection of all distinct cosets $\{[x] : x \in \mathbb{R}\}$ partitions $
\mathbb{R}$.

We verify each required property:

1. **Each coset is countably infinite.** The map $n \mapsto x + n$ is a bijectio
n from $\mathbb{Z}$ to $[x]$, so each coset is countably infinite.

2. **There are uncountably many cosets.** The quotient $\mathbb{R}/\mathbb{Z}$ i
s in bijection with the interval $[0,1)$ (via the fractional-part map), so there
 are $\mathfrak{c} = 2^{\aleph_0}$ many cosets, which is uncountable.

3. **No coset contains any of its limit points (each coset is discrete).** Take
any point $x + n \in [x]$. The open interval $(x + n - \tfrac{1}{3},\; x + n + \
tfrac{1}{3})$ contains no other element of $[x]$, since the nearest other elemen
ts are $x + n - 1$ and $x + n + 1$, both at distance $1 > \tfrac{1}{3}$. Therefo
re every point of $[x]$ is isolated, meaning no point of $[x]$ is a limit point
of $[x]$. Equivalently, $[x]$ contains none of its limit points.

4. **The cosets partition $\mathbb{R}$.** This is immediate from the definition
of cosets of a subgroup.

Thus the partition of $\mathbb{R}$ into the cosets of $\mathbb{Z}$ yields uncoun
tably many countably infinite subsets, each discrete and therefore containing no
ne of its limit points. $\blacksquare$
