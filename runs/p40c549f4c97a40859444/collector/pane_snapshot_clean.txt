## Proof

We wish to compute $P(T_1 < T_{-1} < T_2)$ for a standard Brownian motion $B_t$
starting at $0$, where $T_a = \inf\{t \geq 0 : B_t = a\}$.

### Decomposition via the Strong Markov Property

The event $\{T_1 < T_{-1} < T_2\}$ means:
1. The Brownian motion hits $1$ before $-1$.
2. After hitting $1$, it then hits $-1$ before hitting $2$.

By the **strong Markov property**, the process restarted at the stopping time $T
_1$ is independent of the past. Setting $B'_t = B_{T_1 + t} - B_{T_1} = B_{T_1+t
} - 1$, this is a fresh standard Brownian motion. Thus:

$$P(T_1 < T_{-1} < T_2) = P(T_1 < T_{-1}) \cdot P_1(T_{-1} < T_2),$$

where $P_1$ denotes the law of Brownian motion started at position $1$.

### Step 1: $P(T_1 < T_{-1})$

For a standard Brownian motion starting at $0$, the harmonic function $h(x) = x$
 is harmonic for Brownian motion, so the standard gambler's ruin formula gives,
for $b < 0 < a$:

$$P(T_a < T_b) = \frac{-b}{a - b}.$$

With $a = 1$, $b = -1$:

$$P(T_1 < T_{-1}) = \frac{-(-1)}{1 - (-1)} = \frac{1}{2}.$$

### Step 2: $P_1(T_{-1} < T_2)$

For Brownian motion started at $x \in (b, a)$, the probability of hitting $b$ be
fore $a$ is:

$$P_x(T_b < T_a) = \frac{a - x}{a - b}.$$

With $x = 1$, $b = -1$, $a = 2$:

$$P_1(T_{-1} < T_2) = \frac{2 - 1}{2 - (-1)} = \frac{1}{3}.$$

### Step 3: Combine

$$P(T_1 < T_{-1} < T_2) = P(T_1 < T_{-1}) \cdot P_1(T_{-1} < T_2) = \frac{1}{2}
\cdot \frac{1}{3} = \boxed{\dfrac{1}{6}}.$$
