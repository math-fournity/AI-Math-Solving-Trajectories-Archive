Looking at this problem, I need to count isomorphism classes of degree 3 functio
n field extensions of $\mathbb{C}(t)$ branched only at $t = 1$ and $t = -1$.

## Proof

**Setup.** A degree 3 function field $K/\mathbb{C}(t)$ corresponds to a connecte
d degree 3 cover $\phi: X \to \mathbb{P}^1_t$. By the Riemann Existence Theorem,
 isomorphism classes of such covers (branched at a specified set $B$) are classi
fied by monodromy representations $\rho: \pi_1(\mathbb{P}^1 \setminus B) \to S_3
$, up to conjugation in $S_3$, with the transitivity condition ensuring connecte
dness.

**Riemann–Hurwitz constraint.** For a degree $d=3$ cover of $\mathbb{P}^1$ (genu
s 0):
$$2g(X) - 2 = -6 + R, \quad R = \sum_{P}(e_P - 1).$$

At each branch point, the ramification type is a partition of 3: either $(2,1)$
contributing 1, or $(3)$ contributing 2. With two branch points, $R \in \{2, 3,
4\}$.

- $R = 2$: $g = -1$ — impossible.
- $R = 3$: $g = -\tfrac{1}{2}$ — impossible.
- $R = 4$: $g = 0$ — valid.

So **both** branch points must have type $(3)$ (total ramification), and $X \con
g \mathbb{P}^1$.

**Monodromy analysis.** The fundamental group of $\mathbb{P}^1$ minus two points
 is:
$$\pi_1(\mathbb{P}^1 \setminus \{1, -1\}) \cong \mathbb{Z}.$$

The monodromy is determined by a single element $\sigma \in S_3$ (image of the g
enerator, i.e., the loop around $t=1$). The monodromy around $t = -1$ is $\sigma
^{-1}$ (since the product of all monodromies, including at infinity where there
is no branching, must be the identity).

**Connectedness** requires $\langle \sigma \rangle$ to act transitively on $\{1,
2,3\}$, so $\sigma$ must be a **3-cycle** (the only elements generating a transi
tive cyclic subgroup of $S_3$). This confirms type $(3)$ at both branch points,
consistent with $R = 4$.

- If $\sigma$ were a transposition: $\sigma^{-1} = \sigma$, type $(2,1)$ at each
 point, $R = 2$, genus $-1$ — impossible, and the cover is disconnected (orbits
$\{i,j\}$ and $\{k\}$).
- If $\sigma = \mathrm{id}$: unramified, disconnected — not a field extension.

**Counting conjugacy classes.** The 3-cycles in $S_3$ are $(1\,2\,3)$ and $(1\,3
\,2)$. These are conjugate in $S_3$:
$$(1\,2)(1\,2\,3)(1\,2) = (1\,3\,2).$$

So there is exactly **one** conjugacy class of transitive monodromy representati
ons $\mathbb{Z} \to S_3$.

**Conclusion.** By the Riemann Existence Theorem, isomorphism classes of degree
3 covers of $\mathbb{P}^1$ branched only at $\{1, -1\}$ are in bijection with co
njugacy classes of transitive monodromy representations. There is exactly one su
ch conjugacy class.

The number of isomorphism classes is $\boxed{1}$.
