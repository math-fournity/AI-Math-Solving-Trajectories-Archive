# Problem

A digital archivist is tasked with organizing a massive dataset stored across 2,016 distinct memory sectors, indexed from $i = 0$ to $i = 2015$. 

In each sector $i$, the system generates a raw data volume exactly equal to $2^i$ units. However, the storage hardware is organized into "blocks" of 25 units each. Due to fixed-sector formatting, any fractional remainder of a block in a sector is discarded; only the number of full 25-unit blocks is recorded for that sector. This recorded value for sector $i$ is calculated as the floor of the raw volume divided by 25.

The archivist needs to calculate the total number of full blocks across all 2,016 sectors. This total sum is then fed into a security algorithm that only utilizes the last two digits of the result.

What is the two-digit remainder when the total sum of these full blocks is divided by 100?
