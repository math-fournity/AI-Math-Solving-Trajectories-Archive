Proof: Existence of an Order-Complete Field

Claim. There exists an order-complete (ordered) field, namely the field of real
numbers $\mathbb{R}$.

I construct $\mathbb{R}$ as the collection of Dedekind cuts of $\mathbb{Q}$ and
verify it is an ordered field that is order-complete (Dedekind-complete).

────────────────────────────────────────────────────────────────────────────────

1. Construction

Definition. A Dedekind cut is a subset $\alpha \subseteq \mathbb{Q}$ satisfying:

  • (i) $\alpha \neq \emptyset$ and $\alpha \neq \mathbb{Q}$;
  • (ii) $\alpha$ is closed downward: if $p \in \alpha$ and $q < p$ (with $q \in
  \mathbb{Q}$), then $q \in \alpha$;
  • (iii) $\alpha$ has no greatest element: for every $p \in \alpha$ there
  exists $r \in \alpha$ with $p < r$.

Let $\mathbb{R} = {\alpha : \alpha \text{ is a Dedekind cut}}$.

Each rational $q$ embeds via $q \mapsto q^* = {p \in \mathbb{Q} : p < q}$, so $
\mathbb{Q} \hookrightarrow \mathbb{R}$.

────────────────────────────────────────────────────────────────────────────────

2. Order

Define $\alpha < \beta \iff \alpha \subsetneq \beta$ (proper subset). This is a
total order:

  • Trichotomy: Given cuts $\alpha, \beta$, either $\alpha = \beta$, $\alpha
  \subsetneq \beta$, or $\beta \subsetneq \alpha$. To see these are the only
  options: if $\alpha \not\subseteq \beta$, pick $p \in \alpha \setminus \beta$;
  then every $q \in \beta$ satisfies $q < p$ (else $p \in \beta$ by downward
  closure), so $q \in \alpha$, giving $\beta \subsetneq \alpha$.
  • Transitivity is immediate from subset inclusion.

────────────────────────────────────────────────────────────────────────────────

3. Field Operations

Addition. $\alpha + \beta = {p + q : p \in \alpha,; q \in \beta}$.

One checks this is a Dedekind cut: it is nonempty and proper; downward closed
(if $r < p+q$ then $r - q < p$, so $r - q \in \alpha$, hence $r = (r-q) + q$
with $r-q \in \alpha$, $q \in \beta$); and has no greatest element (given $p+q$,
pick $p' > p$ in $\alpha$, then $p'+q > p+q$).

The additive identity is $0^* = {p : p < 0}$. The additive inverse of $\alpha$
is $$-\alpha = {q \in \mathbb{Q} : \text{there exists } r > -q \text{ with } r
\notin \alpha},$$ i.e., ${q : -q < \sup(\mathbb{Q}\setminus\alpha)}$ adjusted so
the result is a cut. One verifies $\alpha + (-\alpha) = 0^*$.

Multiplication. For $\alpha, \beta > 0^*$: $$\alpha \cdot \beta = {p \in
\mathbb{Q} : p \leq 0} \cup {p \cdot q : p \in \alpha,; p > 0,; q \in \beta,; q
> 0}.$$ Extend to all signs by the usual rules: if exactly one of $\alpha,
\beta$ is negative, $\alpha\beta = -(|\alpha||\beta|)$; if both negative, $
\alpha\beta = |\alpha||\beta|$.

The multiplicative identity is $1^* = {p : p < 1}$. For $\alpha > 0^*$, the
inverse is $$\alpha^{-1} = {q \in \mathbb{Q} : q \leq 0} \cup {q > 0 :
\text{there exists } r \notin \alpha,; r > 0,; \text{with } q \cdot r < 1}.$$

Verification of field axioms. Commutativity, associativity, and distributivity
follow from the corresponding properties of $\mathbb{Q}$, since the operations
are defined elementwise on representatives. For instance, distributivity: $$
\alpha(\beta + \gamma) = {a(b+c)} = {ab + ac} = \alpha\beta + \alpha\gamma,$$
using $a(b+c) = ab + ac$ in $\mathbb{Q}$ and the definition of cut addition/
multiplication. The identity and inverse properties are verified by direct
computation against $0^$ and $1^$.

Order-field compatibility. If $\alpha < \beta$ then $\alpha + \gamma < \beta +
\gamma$ (since $\alpha + \gamma \subseteq \beta + \gamma$, and the inclusion is
proper). If $\alpha, \beta > 0^$ and $\alpha < \beta$, then $\alpha\gamma <
\beta\gamma$ for $\gamma > 0^$ (similar subset argument on positive parts).

Thus $(\mathbb{R}, +, \cdot, <)$ is an ordered field.

────────────────────────────────────────────────────────────────────────────────

4. Order-Completeness (Dedekind Completeness)

Theorem. Every nonempty subset $S \subseteq \mathbb{R}$ that is bounded above
has a least upper bound in $\mathbb{R}$.

Proof. Let $S \neq \emptyset$ be bounded above by some cut $\beta$. Define $$
\gamma = \bigcup_{\alpha \in S} \alpha = {p \in \mathbb{Q} : p \in \alpha \text{
for some } \alpha \in S}.$$

$\gamma$ is a Dedekind cut:

  • Nonempty: $S \neq \emptyset$, so some $\alpha \in S$ is nonempty, hence $
  \gamma \neq \emptyset$.
  • Proper: Since $S$ is bounded above by $\beta$, every $\alpha \in S$
  satisfies $\alpha \subseteq \beta \subsetneq \mathbb{Q}$, so $\gamma \subseteq
  \beta \subsetneq \mathbb{Q}$.
  • Downward closed: If $p \in \gamma$ and $q < p$, then $p \in \alpha$ for some
  $\alpha \in S$, so $q \in \alpha \subseteq \gamma$.
  • No greatest element: If $p \in \gamma$, then $p \in \alpha$ for some $\alpha
  \in S$. Since $\alpha$ has no greatest element, there exists $r \in \alpha$
  with $r > p$, and $r \in \gamma$.

$\gamma$ is an upper bound of $S$: For every $\alpha \in S$, $\alpha \subseteq
\gamma$, i.e., $\alpha \leq \gamma$.

$\gamma$ is the least upper bound: Suppose $\delta$ is any upper bound of $S$,
so $\alpha \subseteq \delta$ for all $\alpha \in S$. Then $\gamma =
\bigcup_{\alpha \in S} \alpha \subseteq \delta$, i.e., $\gamma \leq \delta$.

Therefore $\gamma = \sup S$ exists in $\mathbb{R}$. $\quad\blacksquare$

────────────────────────────────────────────────────────────────────────────────

5. Conclusion

The set $\mathbb{R}$ of Dedekind cuts of $\mathbb{Q}$, equipped with the
operations and order defined above, is an ordered field that is order-complete:
every nonempty bounded-above subset has a least upper bound.

Therefore, an order-complete field exists. (Moreover, it is unique up to order-
field isomorphism: any order-complete ordered field is isomorphic to $
\mathbb{R}$, since the rationals embed densely and every element is determined
by the cut it induces on $\mathbb{Q}$.)
