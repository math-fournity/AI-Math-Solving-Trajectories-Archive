## Proof

**Branch definition.** The principal branch of complex arccosine is
$$\arccos(z) = -i\,\mathrm{Log}\!\bigl(z + i\sqrt{1-z^{2}}\bigr),$$
where $\mathrm{Log}$ is the principal logarithm and $\sqrt{\cdot}$ is the princi
pal square root.

**Evaluating $\arccos(k)$ for integer $k\ge 1$.**

*Case $k=1$:* $\arccos(1) = -i\,\mathrm{Log}(1+i\sqrt{0}) = -i\,\mathrm{Log}(1)
= 0.$

*Case $k\ge 2$:* Here $1-k^{2}<0$ is a negative real number, so the principal sq
uare root gives
$$\sqrt{1-k^{2}} = i\sqrt{k^{2}-1}.$$
Therefore
$$k + i\sqrt{1-k^{2}} = k + i\cdot i\sqrt{k^{2}-1} = k - \sqrt{k^{2}-1}.$$

Since $k>\sqrt{k^{2}-1}>0$, the quantity $k-\sqrt{k^{2}-1}$ is a **positive real
 number**, and
$$k - \sqrt{k^{2}-1} = \frac{1}{k+\sqrt{k^{2}-1}} \in (0,\,1/k]\subseteq(0,1).$$

Hence $\mathrm{Log}(k-\sqrt{k^{2}-1}) = \log(k-\sqrt{k^{2}-1})$ is a **negative
real number**, and
$$\arccos(k) = -i\log\!\bigl(k-\sqrt{k^{2}-1}\bigr) = i\log\!\bigl(k+\sqrt{k^{2}
-1}\bigr) = i\,\operatorname{arccosh}(k).$$

So every term with $k\ge 2$ is **purely imaginary with strictly positive imagina
ry part**.

**The partial sums.** Let
$$S_n = \sum_{k=1}^{n}\arccos(k) = i\sum_{k=2}^{n}\operatorname{arccosh}(k) = i\
,A_n,\qquad A_n:=\sum_{k=2}^{n}\log\!\bigl(k+\sqrt{k^{2}-1}\bigr).$$

**Asymptotics of $A_n$.** For large $k$,
$$\sqrt{k^{2}-1}=k\sqrt{1-\tfrac{1}{k^{2}}}=k-\frac{1}{2k}+O(k^{-3}),$$
so
$$k+\sqrt{k^{2}-1}=2k-\frac{1}{2k}+O(k^{-3})=2k\bigl(1+O(k^{-2})\bigr),$$
and therefore
$$\log\!\bigl(k+\sqrt{k^{2}-1}\bigr)=\log(2k)+O(k^{-2}).$$

The $O(k^{-2})$ correction is summable, so
$$A_n = \sum_{k=2}^{n}\log(2k) + C + o(1) = (n-1)\log 2 + \log(n!) + C + o(1)$$
for some finite constant $C$. By Stirling's formula, $\log(n!)=n\log n - n + \tf
rac12\log(2\pi n)+o(1)$, giving
$$A_n = n\log n - n + (n-1)\log 2 + \tfrac12\log(2\pi n) + C + o(1)\;\xrightarro
w[n\to\infty]{}\;+\infty.$$

**Conclusion.** Since $A_n\to+\infty$,
$$S_n = i\,A_n \;\xrightarrow[n\to\infty]{}\; +\,i\infty.$$

The partial sums are purely imaginary with imaginary part growing without bound
(specifically $\sim n\log n$). Therefore the limit **does not exist** as a finit
e complex number; the series **diverges** (to $+i\infty$).

$$\boxed{\lim_{n\to\infty}\sum_{k=1}^{n}\arccos(k)\ \text{diverges (does not exi
st as a finite value).}}$$
