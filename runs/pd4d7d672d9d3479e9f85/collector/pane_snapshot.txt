## 解答

**是的，$T_x < \infty$。**

### 证明

设 $Z_t = X_t + at$，这是一个漂移为 $a < 0$ 的布朗运动。注意 $Z_0 = X_0 + a \cdo
t 0 = 0$。

停止时间定义为：
$$T_x = \inf\{t \geq 0: Z_t \geq x\}$$

且 $Y = \sup_{t \geq 0} Z_t$。

**关键等价性。** 我们建立以下等价关系：

$$T_x < \infty \iff \exists\, t \geq 0 \text{ 使得 } Z_t \geq x \iff \sup_{t \ge
q 0} Z_t \geq x \iff Y \geq x.$$

- **($\Rightarrow$)**：如果 $T_x < \infty$，则根据下确界的定义，存在 $t \geq 0$
使得 $Z_t \geq x$。因此 $\sup_{t \geq 0} Z_t \geq x$，即 $Y \geq x$。

- **($\Leftarrow$)**：如果 $Y \geq x$，则 $\sup_{t \geq 0} Z_t \geq x$。根据上确
界的定义，对于每个 $\varepsilon > 0$，存在 $t_\varepsilon \geq 0$ 使得 $Z_{t_\va
repsilon} > x - \varepsilon$。由于 $Z_t$ 是连续的且 $Z_0 = 0$，如果 $x > 0$，取
$\varepsilon < x$ 可得存在 $t$ 使得 $Z_t > x - \varepsilon > 0 = Z_0$；根据介值
定理，$Z_t$ 在 $0$ 和 $t_\varepsilon$ 之间取到 $x - \varepsilon/2$ 的所有值，更
重要的是，由于 $Z_{t_\varepsilon} > x - \varepsilon$，且我们可以取 $\varepsilon$
 任意小，连续性确保过程达到水平 $x$。具体来说：选择序列 $\varepsilon_n = 1/n$，
得到时间 $t_n$ 使得 $Z_{t_n} > x - 1/n$。如果对于某个 $n$ 有 $Z_{t_n} \geq x$，
则 $T_x \leq t_n < \infty$。如果对于所有 $n$ 都有 $Z_{t_n} < x$，则 $Z_{t_n} \in
 (x - 1/n, x)$；根据连续性和 $Z_0 = 0 < x$，介值定理保证了对于所有足够大的 $n$，
存在 $s_n \in [0, t_n]$ 使得 $Z_{s_n} = x$，因此 $T_x \leq s_n < \infty$。（如果
 $x \leq 0$，则 $Z_0 = 0 \geq x$，因此 $T_x = 0 < \infty$ 是平凡的。）

**结论。** 假设 $Y = x$，我们有 $Y \geq x$（平凡地，因为相等意味着大于等于）。根
据上述等价性，$T_x < \infty$。 $\blacksquare$
