先进行 Answer Leak Self-Check：问题文本仅要求确定是否对于任意 ε > 0，存在一个非
零的 f ∈ L¹(ℝ) 满足 ‖f̂‖_∞ ≤ ε‖f‖_1。没有泄露答案、证明草图或形式化说明。继续进行
求解。

**答案：是的。** 对于任意 ε > 0，都存在一个非零的 f ∈ L¹(ℝ) 满足 ‖f̂‖_∞ ≤ ε‖f‖_1
。

**证明。** 回顾基本不等式 ‖f̂‖_∞ ≤ ‖f‖_1（因为 |f̂(ξ)| ≤ ∫|f| = ‖f‖_1），因此该比
值始终 ≤ 1。问题在于下确界是否为 0。关键在于，对于任何 **非负** 的 f，我们有 f̂(0
) = ∫f = ‖f‖_1，因此 ‖f̂‖_∞ = ‖f‖_1，比值为 1；因此，任何比值较小的候选函数都必须
涉及大量符号抵消。我们通过 Rudin–Shapiro 多项式构造这样一个函数。

**步骤 1 — 一个固定凸起函数。** 设 g ∈ C_c(ℝ) 满足 supp g ⊂ [0, 1] 且 ‖g‖_1 = 1
。根据 Riemann–Lebesgue 引理，其傅里叶变换 ĝ 是连续的且在无穷远处趋于 0；此外，
对于所有 ξ，都有 |ĝ(ξ)| ≤ ‖g‖_1 = 1。

**步骤 2 — Rudin–Shapiro 符号。** 经典的 Rudin–Shapiro 构造（针对 N = 2^k）给出
了符号 δ_0, …, δ_{N-1} ∈ {±1}，使得对于绝对常数 C > 0，有
$$
\sup_{\theta\in[0,2\pi]}\Bigl|\sum_{n=0}^{N-1}\delta_n e^{in\theta}\Bigr| \le C\
sqrt{N}.
$$

**步骤 3 — 构造 f。** 固定 ε > 0。选择 R > 0 使得对于 |ξ| ≥ R，有 |ĝ(ξ)| < ε（根
据 ĝ → 0，这是可能的）。选择间距 L > 1，使得平移后的凸起函数 g(·−nL)（其支撑集为
 [nL, nL+1]）是成对不相交的。选择 N = 2^k 足够大，使得 C/√N < ε，并设 δ_n 为步骤
 2 中的 Rudin–Shapiro 符号。定义
$$
f(x) \;=\; \frac{1}{N}\sum_{n=0}^{N-1}\delta_n\, g(x-nL).
$$

**步骤 4 — L¹ 范数。** 由于支撑集 [nL, nL+1] 是不相交的（L > 1），我们有精确值
$$
\|f\|_1 \;=\; \sum_{n=0}^{N-1}\frac{1}{N}\|g(\cdot-nL)\|_1 \;=\; \sum_{n=0}^{N-1
}\frac{1}{N}\cdot 1 \;=\; 1.
$$
因此 f 是非零的，且 f ∈ L¹(ℝ)。

**步骤 5 — f̂ 的逐点界。** 根据线性性和平移的傅里叶公式，
$$
\hat f(\xi) \;=\; \hat g(\xi)\cdot \frac{1}{N}\sum_{n=0}^{N-1}\delta_n\, e^{-inL
\xi} \;=:\; \hat g(\xi)\,P(\xi),
$$
其中 P(ξ) = (1/N)Σ δ_n e^{-inLξ}。令 θ = Lξ；当 ξ 遍历一个长度为 2π/L 的区间时，
θ 遍历 [0, 2π]，因此根据 Rudin–Shapiro 界，
$$
\sup_{\xi\in\mathbb R}|P(\xi)| \;\le\; \frac{C\sqrt N}{N} \;=\; \frac{C}{\sqrt N
} \;<\;\varepsilon.
$$
此外，|P(ξ)| ≤ (1/N)Σ|δ_n| = 1。

**步骤 6 — 结论。** 我们对 ξ 进行分类讨论：
- 对于 |ξ| < R：|f̂(ξ)| = |ĝ(ξ)P(ξ)| ≤ |ĝ(ξ)|·|P(ξ)| ≤ 1 · (C/√N) < ε。
- 对于 |ξ| ≥ R：|f̂(ξ)| = |ĝ(ξ)P(ξ)| ≤ |ĝ(ξ)|·|P(ξ)| ≤ ε · 1 = ε。

因此 ‖f̂‖_∞ ≤ ε = ε·‖f‖_1。

由于 ε > 0 是任意的，我们得出结论
$$
\inf_{\substack{f\in L^1(\mathbb R)\\ f\ne 0}} \frac{\|\hat f\|_\infty}{\|f\|_1}
 \;=\; 0,
$$
即对于每一个 ε > 0，都存在一个非零的 f ∈ L¹(ℝ) 满足 ‖f̂‖_∞ ≤ ε‖f‖_1。
