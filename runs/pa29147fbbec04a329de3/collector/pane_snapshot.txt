**Answer: Yes, such a set $B$ and constant $M$ always exist.**

**Proof.**

Since $f:[0,1]\to\mathbb{R}$ is Lebesgue measurable and real-valued (finite at e
very point), define for each positive integer $n$ the set
$$E_n = \{x \in [0,1] : f(x) < n\}.$$

Because $f$ is measurable, each $E_n$ is a Lebesgue measurable set. Moreover, si
nce $f(x)$ is a finite real number for every $x\in[0,1]$, for each $x$ there exi
sts an integer $n$ (depending on $x$) with $f(x)<n$. Therefore
$$[0,1] = \bigcup_{n=1}^{\infty} E_n.$$

Taking Lebesgue measure of both sides and using countable subadditivity,
$$1 = \mu([0,1]) = \mu\!\left(\bigcup_{n=1}^{\infty} E_n\right) \le \sum_{n=1}^{
\infty} \mu(E_n).$$

If $\mu(E_n)=0$ for every $n$, then the right-hand side would be $0$, contradict
ing $1\le 0$. Hence there exists some positive integer $N$ with $\mu(E_N)>0$.

Set $B = E_N$ and $M = N$. Then $B$ is measurable, $\mu(B)>0$, and for every $x\
in B$ we have $f(x)<N=M$ by definition of $E_N$.

Thus the desired set $B$ and constant $M$ exist. $\blacksquare$
