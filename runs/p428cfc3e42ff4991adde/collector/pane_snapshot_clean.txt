## Proof

**Claim.** In the Zariski topology on the $n$-dimensional affine space $\mathbb{
A}^n_k$ (over an algebraically closed field $k$), no proper closed set can conta
in a non-empty open set.

**Key fact.** $\mathbb{A}^n_k$ is **irreducible**.

*Proof of irreducibility.* The closed sets of $\mathbb{A}^n_k$ are precisely the
 algebraic sets $V(I)$ for ideals $I \subseteq k[x_1,\dots,x_n]$. By the Nullste
llensatz, $V(I) = \mathbb{A}^n_k \iff I \subseteq \sqrt{(0)} = (0)$ (the last eq
uality because $k[x_1,\dots,x_n]$ is an integral domain, hence reduced). Now sup
pose $\mathbb{A}^n_k = V(I_1) \cup V(I_2) = V(I_1 \cap I_2)$ with both $V(I_1),
V(I_2)$ proper closed. Then $V(I_1 \cap I_2) = \mathbb{A}^n_k$, so $I_1 \cap I_2
 \subseteq (0)$, i.e. $I_1 \cap I_2 = (0)$. But $k[x_1,\dots,x_n]$ is a domain,
so $I_1 \cap I_2 = (0)$ with $I_1, I_2 \neq (0)$ is impossible: pick $0 \neq f \
in I_1$, $0 \neq g \in I_2$; then $0 \neq fg \in I_1 \cap I_2$, contradiction. H
ence $\mathbb{A}^n_k$ cannot be written as a union of two proper closed subsets,
 i.e. it is irreducible. $\square$

**Main argument.** In any irreducible topological space, every non-empty open su
bset is **dense**.

*Proof.* Let $X$ be irreducible and $U \subseteq X$ non-empty open. If $\overlin
e{U} \neq X$, then $X = \overline{U} \cup (X \setminus U)$ is a union of two pro
per closed sets ($\overline{U}$ is proper by assumption; $X \setminus U$ is prop
er because $U \neq \emptyset$), contradicting irreducibility. Hence $\overline{U
} = X$. $\square$

**Conclusion.** Suppose, for contradiction, that a proper closed set $C \subsetn
eq \mathbb{A}^n_k$ contains a non-empty open set $U \neq \emptyset$. Then
$$U \subseteq C \subsetneq \mathbb{A}^n_k \implies \overline{U} \subseteq C \sub
setneq \mathbb{A}^n_k.$$
But $U$ is a non-empty open subset of the irreducible space $\mathbb{A}^n_k$, so
 $\overline{U} = \mathbb{A}^n_k$. This gives $\mathbb{A}^n_k \subseteq C \subset
neq \mathbb{A}^n_k$, a contradiction.

Therefore, **no closed set other than the entire space can contain a non-empty o
pen set**. $\blacksquare$
