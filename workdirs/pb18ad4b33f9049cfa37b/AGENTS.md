# Problem

In a specialized digital data center, there is a linear array of $n$ memory cells, where $1 \le n \le 100$. Initially, a single "Active Signal" is stored in the $k$-th cell, where $1 \le k \le n$. The system undergoes a series of discrete processing cycles. In each cycle, the following operations occur simultaneously:

1. Every existing Active Signal is marked for deletion.
2. New Active Signals are generated in any cell that is currently adjacent to exactly one cell containing a signal marked for deletion.
3. All signals marked for deletion are permanently erased from the array.

The system is considered "Unstable" if a cycle results in an array with no Active Signals remaining. If the signals persist indefinitely through every future cycle, the configuration $(n, k)$ is considered "Permanent."

Let $S$ be the set of all possible pairs $(n, k)$ such that the configuration is Permanent. Calculate the total number of elements in $S$.
