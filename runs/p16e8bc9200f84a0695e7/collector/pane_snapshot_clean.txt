## 解答

**设置。** 设这六个点为：
- A = (0,0,0), B = (x,0,0), C = (2x,3x,0), E = (7,3,0) [均在 z=0 平面内]
- D = (5,5,2), F = (9,1,4) [在 z=0 平面上方]

其中 x ∈ (0,1] 为均匀分布。

**第一步：确定凸包结构。**

将所有点投影到 z=0 平面。二维凸包为五边形 A'→B'→F'→D'→C'（因为 E'=(7,3) 恰好位于
线段 F'D' 上，满足 x+y=10）。对于所有 x ∈ (0,1]，可以验证 C' 在四边形 A'B'F'D'
之外（条件 5x > 0 始终成立），且 B' 是极点。

z=0 平面内的底面是四边形 A-B-E-C（已验证对于所有 x ∈ (0,1] 均为凸包）。

**第二步：确定三个“上表面”面（法向量指向上方）。**

通过验证所有其他点均位于每个平面下方：

- **ABF**：平面 Z = 4Y。在 C 处：0 < 12x ✓；在 D 处：2 < 20 ✓；在 E 处：0 < 12 ✓
。
- **AFD**：平面 −18X + 2Y + 40Z = 0。在 B 处：−18x < 0 ✓；在 C 处：−30x < 0 ✓；
在 E 处：−120 < 0 ✓。
- **ADC**：平面 −6X + 4Y + 5Z = 0。在 B 处：−6x < 0 ✓；在 F 处：−30 < 0 ✓；在 E
处：−30 < 0 ✓。

**第三步：确定侧面。**

E 在 F'D' 上的投影产生了一个垂直面 **EFD** (X+Y=10)。另外两个侧面是 **BEF** 和 *
*ECD**（已验证所有其他点都在同一侧，对于所有 x ∈ (0,1] 均成立）。

这给出了 7 个面（1 个四边形 + 6 个三角形），11 条边，6 个顶点：V−E+F = 6−11+7 =
2 ✓。

**第四步：计算体积。**

从 A=(0,0,0) 开始，将凸包分解为三个四面体，每个四面体由 A 和一个不包含 A 的面组
成：

| 四面体 | 面 | 体积 = (1/6)|det| |
|---|---|---|
| A-B-E-F | BEF | (1/6)\|det(B,E,F)\| = (1/6)·12x = **2x** |
| A-E-F-D | EFD | (1/6)\|det(E,F,D)\| = (1/6)·120 = **20** |
| A-E-C-D | ECD | (1/6)\|det(E,C,D)\| = (1/6)·30x = **5x** |

**关键行列式：**
- det(B,E,F) = det[[x,0,0],[7,3,0],[9,1,4]] = x·(12) = 12x
- det(E,F,D) = det[[7,3,0],[9,1,4],[5,5,2]] = 7(−18) − 3(−2) = −120，所以 |−120|
 = 120
- det(E,C,D) = det[[7,3,0],[2x,3x,0],[5,5,2]] = 7(6x) − 3(4x) = 30x

**在 x=0（极限情况）下验证：** 退化为四面体 A-D-E-F，体积 = (1/6)|det(D,E,F)| =
(1/6)·120 = 20 = V(0) ✓

**在 x=1 下验证：** V = 27，通过散度定理确认：(1/6)(12+120+30) = 162/6 = 27 ✓

**第五步：计算期望值。**

$$V(x) = 20 + 7x$$

$$\mathbb{E}[V] = \int_0^1 (20 + 7x)\,dx = 20 + \frac{7}{2} = \frac{47}{2}$$

由于 47 是质数，gcd(47, 2) = 1，所以 m = 47，n = 2。

$$m + n = 49$$
