## Setting Up the Equation

Aida has a³ + b³ + c³ unit cubes. She needs (a+b+c)³ for the target cube. Since
(a+b+c)³ > a³+b³+c³ for positive a,b,c, she was **short** by 648:

$$(a+b+c)^3 - (a^3+b^3+c^3) = 648$$

Using the algebraic identity:

$$(a+b+c)^3 - (a^3+b^3+c^3) = 3(a+b)(b+c)(c+a)$$

So:

$$3(a+b)(b+c)(c+a) = 648 \implies (a+b)(b+c)(c+a) = 216$$

## Substitution

Let x = a+b, y = b+c, z = c+a. Then xyz = 216, and:

$$a = \frac{x+z-y}{2},\quad b = \frac{x+y-z}{2},\quad c = \frac{y+z-x}{2}$$

**Conditions for positive integer (a,b,c):**
1. **Parity:** x+y+z must be even (so all three numerators are even).
2. **Positivity (triangle inequality):** x+y > z, x+z > y, y+z > x.

The mapping (a,b,c) ↔ (x,y,z) is a bijection, so counting ordered (a,b,c) = coun
ting ordered (x,y,z) satisfying these conditions.
