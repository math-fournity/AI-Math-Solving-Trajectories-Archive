## Proof

We seek the smallest 8-digit number whose digits are all distinct and which is d
ivisible by 36.

**Divisibility setup.** Since 36 = 4 × 9 with gcd(4,9) = 1, the number must be:
- divisible by 9: the sum of its digits is divisible by 9;
- divisible by 4: its last two digits form a number divisible by 4.

**Digit-sum constraint.** The number uses 8 distinct digits chosen from {0,1,…,9
}, so exactly two digits are excluded. The total sum of all ten digits is 45. If
 the excluded digits are *a* and *b*, the sum of the eight used digits is 45 − *
a* − *b*. For divisibility by 9 we need 45 − *a* − *b* ≡ 0 (mod 9), i.e. *a* + *
b* ≡ 0 (mod 9). Since 0 ≤ *a* < *b* ≤ 9 and *a* + *b* ≤ 17, the only possibility
 is *a* + *b* = 9. The excluded pairs are therefore exactly:
{0,9}, {1,8}, {2,7}, {3,6}, {4,5}.

**Choosing the smallest prefix.** To minimize the number we want the lexicograph
ically smallest digit string (with nonzero leading digit). The ideal prefix is 1
023…, which requires digits 1, 0, 2, 3 all to be *included*. Checking each exclu
ded pair:
- {0,9} excludes 0 → cannot have prefix 10…
- {1,8} excludes 1 → leading digit ≥ 2
- {2,7} excludes 2 → prefix ≥ 103…
- {3,6} excludes 3 → prefix ≥ 1024…
- {4,5} excludes neither 0,1,2,3 → prefix 1023… is achievable.

So the only excluded pair that permits the prefix 1023 is {4,5}, giving availabl
e digits {0,1,2,3,6,7,8,9}. Every other excluded pair yields a strictly larger p
refix (103…, 1024…, 12…, or 2…), hence a larger number. We therefore only need t
o minimize within this digit set.

**Minimizing with digits {0,1,2,3,6,7,8,9}.** Fix the prefix 1023 (smallest poss
ible). The remaining four positions are filled by {6,7,8,9}, with the last two d
igits forming a multiple of 4. The two-digit endings from {6,7,8,9} that are div
isible by 4 are:
- 68 (68 = 4·17), 76 (76 = 4·19), 96 (96 = 4·24).

For each valid ending, the two earlier positions are filled by the remaining two
 digits in increasing order (to minimize):
- ending 68 → remaining {7,9} → sequence **7968**
- ending 76 → remaining {8,9} → sequence **8976**
- ending 96 → remaining {7,8} → sequence **7896**

The smallest of these four-digit tails is 7896, giving the candidate **10237896*
*.

**Verification.**
- Digits: 1, 0, 2, 3, 7, 8, 9, 6 — all distinct. ✓
- Digit sum: 1+0+2+3+7+8+9+6 = 36, divisible by 9. ✓
- Last two digits: 96 = 4·24, divisible by 4. ✓
- Hence divisible by 36; indeed 10237896 = 36 × 284386. ✓

Since every other excluded pair forces a larger prefix and within the optimal pa
ir {4,5} we selected the smallest valid tail, 10237896 is the smallest eight-dig
it number with all distinct digits divisible by 36.
