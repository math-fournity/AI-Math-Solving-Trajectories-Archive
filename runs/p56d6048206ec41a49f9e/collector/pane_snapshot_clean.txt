Looking at the problem, I need to determine whether three subgroups of a topolog
ical group can have all pairwise products closed while the triple product is non
-closed.

**Answer: Yes, it is possible.**

## Construction

Let $G = \mathbb{R}^2$ with the usual Euclidean topology and addition. Fix an ir
rational number $\alpha$. Define three subgroups:

$$A = \mathbb{Z} \times \{0\}, \qquad B = \{0\} \times \mathbb{Z}, \qquad C = \{
(n\alpha,\, n\alpha) : n \in \mathbb{Z}\}.$$

Each is a subgroup of $(\mathbb{R}^2, +)$.

## Pairwise sums are closed

**$A + B = \mathbb{Z}^2$**, which is discrete in $\mathbb{R}^2$, hence closed. ✓

**$A + C = \{(m + n\alpha,\; n\alpha) : m, n \in \mathbb{Z}\}$.** For each fixed
 $n$, the fiber at second coordinate $n\alpha$ is $(\mathbb{Z} + n\alpha) \times
 \{n\alpha\}$, a translate of $\mathbb{Z}$ — discrete. The set of second coordin
ates $\{n\alpha : n \in \mathbb{Z}\}$ is itself discrete in $\mathbb{R}$ (since
$|\alpha| > 0$, consecutive values are separated by $|\alpha|$). Any two distinc
t points of $A+C$ either share the same second coordinate (differing by $\geq 1$
 in the first) or differ by $\geq |\alpha|$ in the second coordinate. Thus $A +
C$ is **discrete**, hence closed. ✓

**$B + C = \{(n\alpha,\; m + n\alpha) : m, n \in \mathbb{Z}\}$**, which by the s
ame argument (roles of coordinates swapped) is discrete and closed. ✓

## The triple sum $A + B + C$ is not closed

Compute:
$$A + B + C = \{(m + n\alpha,\; k + n\alpha) : m, k, n \in \mathbb{Z}\}.$$

**Step 1: Identify the ambient closed set.** The difference of coordinates is $(
k + n\alpha) - (m + n\alpha) = k - m \in \mathbb{Z}$, so
$$A + B + C \;\subseteq\; S := \{(x, y) \in \mathbb{R}^2 : y - x \in \mathbb{Z}\
} = \bigcup_{j \in \mathbb{Z}} \ell_j, \quad \ell_j = \{(t, t+j) : t \in \mathbb
{R}\}.$$
The set $S$ is a union of parallel lines with spacing $1/\sqrt{2}$; it is closed
 in $\mathbb{R}^2$.

**Step 2: Rewrite the triple sum.** Setting $t = m + n\alpha$ and $j = k - m$ (b
oth ranging freely over $\mathbb{Z}$ as $m, k, n$ do), we get:
$$A + B + C = \{(t,\; t + j) : t \in \mathbb{Z} + \alpha\mathbb{Z},\; j \in \mat
hbb{Z}\}.$$

**Step 3: Density.** Since $\alpha$ is irrational, $\mathbb{Z} + \alpha\mathbb{Z
}$ is dense in $\mathbb{R}$. Therefore $A + B + C$ is dense in $S$.

**Step 4: Proper containment.** The set $\mathbb{Z} + \alpha\mathbb{Z}$ is count
able, so it is a proper subset of $\mathbb{R}$. Pick any $t_0 \in \mathbb{R} \se
tminus (\mathbb{Z} + \alpha\mathbb{Z})$. Then $(t_0, t_0) \in S = \overline{A +
B + C}$, but $(t_0, t_0) \notin A + B + C$.

Therefore $A + B + C$ is **not closed**: its closure is $S \supsetneq A + B + C$
.

## Conclusion

We have exhibited a topological group $G = \mathbb{R}^2$ and three subgroups $A,
 B, C$ such that $A+B$, $A+C$, and $B+C$ are all closed, yet $A+B+C$ is not clos
ed. Hence **yes, it is possible** for the product of three subgroups of a topolo
gical group to be non-closed even when every pairwise product is closed.
