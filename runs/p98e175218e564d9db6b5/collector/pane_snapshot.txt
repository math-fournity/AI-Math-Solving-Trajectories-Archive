## Key Observations

Note $2h = n - v$. The set $B$ consists of all integers $\equiv (n-v) \pmod{4}$
in $[-(n\!-\!v),\, n\!-\!v]$, spaced 4 apart. The set $A$ consists of all intege
rs $\equiv v \pmod{2}$ in $[-v, v]$, spaced 2 apart.

**Case 1: $n$ even.** Then $v$ is even, so $A$ contains only even numbers.

- **$v = 0$:** $A = \{0\}$, $B = \{-n, -n{+}4, \ldots, n\}$. Then $\operatorname
{dist}(0, B) = 0$ if $n \equiv 0 \pmod{4}$ (since $0 \in B$), and $= 2$ if $n \e
quiv 2 \pmod{4}$ (nearest elements are $\pm 2$).
- **$v \ge 2$:** $A$ contains both $\equiv 0$ and $\equiv 2 \pmod{4}$ elements (
since $v \ge 2$). Since $B$'s residue is $(n{-}v) \bmod 4 \in \{0, 2\}$, some $a
 \in A$ matches, giving $\operatorname{dist} = 0$. (When $v > n{-}v$, elements o
f $A$ within $[-(n{-}v), n{-}v]$ still include both residues as long as $n{-}v \
ge 2$; when $v = n$, $B = \{0\}$ and $0 \in A$.)

So for $n$ even: $V(2,n) = \begin{cases} 0 & n \equiv 0 \pmod{4} \\ 2 & n \equiv
 2 \pmod{4}\end{cases}$, with the maximum attained at $v = 0$ (all-horizontal ti
ling).

**Verification for $v=0$, $n\equiv 2\pmod{4}$:** All dominoes horizontal, one pe
r row position. Each row has $n$ dominoes each contributing $\pm 2$, so the imba
lance is $2 \cdot (\text{#Red} - \text{#Blue})$ in each row, which is a multiple
 of 4 only if $\text{#Red} - \text{#Blue}$ is even. With $n$ dominoes per row an
d $n \equiv 2 \pmod 4$, the best split is $(n/2 \pm 1)$ vs $(n/2 \mp 1)$, giving
 imbalance $\pm 2$. So $V = 2$. ✓

**Case 2: $n$ odd.** Then $v$ is odd, so $A$ contains only **odd** numbers, whil
e $B$ contains only **even** numbers. Thus $\operatorname{dist}(a, B) \ge 1$ for
 all $a$.

For any $a \in A$ with $|a| \le 2h = n{-}v$: the nearest element of $B$ is at $a
 \pm 1$ (whichever is $\equiv (n{-}v) \pmod 4$), giving $\operatorname{dist} = 1
$. Such $a$ always exists: when $v \le n/2$, all of $A \subseteq [-(n{-}v), n{-}
v]$; when $v > n/2$, the element $a = \pm 1$ (or any small odd $a$) lies within
range. When $v = n$, $B = \{0\}$ and $A \ni \pm 1$, giving $\operatorname{dist}
= 1$.

So for $n$ odd: $V(2,n) = 1$ for all valid $v$, hence $V(2,n) = 1$.
