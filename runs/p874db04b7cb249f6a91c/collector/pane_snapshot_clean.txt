## Key Claim

$$k(a,b) = \frac{a+b}{\gcd(a,b)}.$$

## Proof of the Formula

Let $g = \gcd(a,b)$, and set $a = g\alpha$, $b = g\beta$ with $\gcd(\alpha,\beta
)=1$. Since $f$ maps multiples of $g$ to multiples of $g$, we can divide all val
ues by $g$. This reduces to the case $\gcd(a,b)=1$ with $M = \lfloor(a+b)/2\rflo
or$, where we must show $k = a+b$.

**Step 1: The orbit stays in $[M-b,\; M+a-1]$.**

Since $a \ge 1$ and $b \ge 1$, we have $M \ge 1 > 0$, so $0 < M$ and $f(0) = a$.
 Note $0 \in [M-b, M+a-1]$ because $M - b \le \lfloor(a+b)/2\rfloor - b \le (a-b
)/2 \le 0$ and $M+a-1 \ge a \ge 1 > 0$.

If $v \in [M-b, M+a-1]$ with $v < M$: then $f(v) = v+a \in [M-b+a,\; M+a-1] \sub
seteq [M-b, M+a-1]$.

If $v \in [M-b, M+a-1]$ with $v \ge M$: then $f(v) = v-b \in [M-b,\; M+a-1-b]$.
Since $a \le b$, we get $M+a-1-b \le M-1 < M$, so $f(v) \in [M-b, M-1] \subseteq
 [M-b, M+a-1]$.

By induction, the entire orbit lies in $[M-b, M+a-1]$, an interval of exactly $a
+b$ consecutive integers.

**Step 2: Residues mod $(a+b)$ are all distinct.**

At every step, the value changes by $+a$ (up-step) or $-b$ (down-step). Since $-
b \equiv a \pmod{a+b}$, **every** step changes the value by $+a \pmod{a+b}$. Aft
er $k$ steps, the value is $\equiv ka \pmod{a+b}$.

Since $\gcd(a, a+b) = \gcd(a,b) = 1$, the values $0, a, 2a, \ldots, (a+b-1)a$ ar
e all distinct mod $(a+b)$. So the orbit visits $a+b$ distinct residues in steps
 $0, 1, \ldots, a+b-1$.

**Step 3: Return to 0 at step $a+b$.**

The orbit's first $a+b$ values (steps $0$ through $a+b-1$) are $a+b$ distinct in
tegers, all in $[M-b, M+a-1]$ (which has exactly $a+b$ integers). So they are **
exactly** all integers in $[M-b, M+a-1]$, one per residue class mod $(a+b)$.

At step $a+b$, the residue is $0 \pmod{a+b}$. The value must lie in $[M-b, M+a-1
]$, and the unique multiple of $(a+b)$ in this interval is $0$ (since $0 \in [M-
b, M+a-1]$ and the interval has length $a+b$). Therefore $f^{a+b}(0) = 0$.

No earlier return is possible: at steps $1, \ldots, a+b-1$, the residue is nonze
ro mod $(a+b)$, so the value cannot be $0$. Thus $k = a+b$ when $\gcd(a,b)=1$, a
nd $k(a,b) = (a+b)/\gcd(a,b)$ in general. $\blacksquare$
