## Step 1: Characterize Sortable Permutations

A permutation σ of {1,...,n} is **sortable** if deleting one element leaves an i
ncreasing sequence. This is equivalent to having a longest increasing subsequenc
e (LIS) of length ≥ n−1.

**Structure:** If we delete the element with value v at position i, the remainin
g n−1 elements must be 1, 2, ..., v−1, v+1, ..., n in order. Working out the pos
itions:

- **If i < v:** σ = (1, ..., i−1, **v**, i, i+1, ..., v−1, v+1, ..., n) — value
v moved left.
- **If i > v:** σ = (1, ..., v−1, v+1, ..., i, **v**, i+1, ..., n) — value v mov
ed right.
- **If i = v:** σ is the identity.

So every sortable permutation is the identity, or obtained by taking one value v
 and inserting it at a different position.

## Step 2: Count Distinct Sortable Permutations

**Non-adjacent moves (|v − i| ≥ 2):** The only descent is at the insertion point
, and only removing v fixes it. So each (v, i) pair gives a **unique** permutati
on. Count: n(n−1) − 2(n−1) = (n−1)(n−2).

**Adjacent moves (|v − i| = 1):** These are adjacent transpositions (v, v+1)↔swa
p. Each is generated by **two** pairs: (v, i=v−1) and (v+1, i=v). There are n−1
distinct adjacent transpositions.

**Identity:** 1 permutation.

**Total:** f(n) = (n−1)(n−2) + (n−1) + 1 = **(n−1)² + 1 = n² − 2n + 2**.
