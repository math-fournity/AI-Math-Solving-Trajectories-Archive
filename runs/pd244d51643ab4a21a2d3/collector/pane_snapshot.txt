**Claim.** For any proper subgroup $H$ of a finite group $G$, taking $n=[G:H]$ a
nd letting $f:G\to S_n$ be the action of $G$ on the left cosets $G/H$ gives $f(G
)$ transitive and $f(H)$ not transitive.

**Proof.**

Since $H<G$, the index $n=[G:H]$ is a positive integer $\ge 2$. Let $G/H=\{g_1H,
\dots,g_nH\}$ be the set of left cosets, and define
$$f:G\longrightarrow S_n,\qquad f(g)(g_iH)=gg_iH.$$
This is the usual left-coset (permutation) action, a well-defined homomorphism.

**$f(G)$ is transitive.** For any two cosets $g_iH,g_jH$, the element $g_jg_i^{-
1}\in G$ sends $g_iH$ to $g_jH$. Hence $f(G)$ acts transitively on $G/H$.

**$f(H)$ is not transitive.** Consider the coset $eH=H$ (the identity coset). Fo
r any $h\in H$,
$$f(h)(H)=hH=H.$$
So the point $H$ is fixed by every element of $f(H)$; its $f(H)$-orbit is the si
ngleton $\{H\}$. Since $n=[G:H]\ge 2$, the set $G/H$ contains at least one other
 coset, so $\{H\}\subsetneq G/H$. Thus $f(H)$ has an orbit of size $1$ inside a
set of size $\ge 2$, which means $f(H)$ is **not** transitive.

Therefore such an $n$ and $f$ always exist. $\blacksquare$
