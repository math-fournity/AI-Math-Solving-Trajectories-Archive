## Setup and Notation

- **Vertical edges**: $v_0, v_1, \ldots, v_{n-1}$ (edge $v_i$ connects top verte

Colors are $\{A, B, C\}$. Write $c(e)$ for the color of edge $e$.

## Step 1: Vertex Conditions Force Structure

At **top vertex** $i$, the three meeting edges are $t_{i-1}, t_i, v_i$. Conditio

- $c(t_{i-1}) \neq c(t_i)$ (the top base edges form a proper coloring of cycle $
C_n$),
- $c(v_i)$ is the unique third color not in $\{c(t_{i-1}), c(t_i)\}$.

At **bottom vertex** $i$, the three meeting edges are $b_{i-1}, b_i, v_i$. Simil
arly:
- $c(b_{i-1}) \neq c(b_i)$ (bottom base edges form a proper coloring of $C_n$),
- $c(v_i)$ is the unique third color not in $\{c(b_{i-1}), c(b_i)\}$.

Since $c(v_i)$ is determined by both, we get the **key constraint**:
$$\{c(t_{i-1}), c(t_i)\} = \{c(b_{i-1}), c(b_i)\} \quad \text{for all } i. \tag{
$\star$}$$

## Step 2: All Reversal Indicators Must Agree

For each $i$, since both $(c(t_{i-1}), c(t_i))$ and $(c(b_{i-1}), c(b_i))$ are o

**Consistency of $b_i$**: From pair $i$, $c(b_i) = c(t_i)$ if $\sigma_i=0$, or $
c(t_{i-1})$ if $\sigma_i=1$. From pair $i+1$, $c(b_i) = c(t_i)$ if $\sigma_{i+1}
=0$, or $c(t_{i+1})$ if $\sigma_{i+1}=1$. Equating:

| $\sigma_i$ | $\sigma_{i+1}$ | Requirement |
|---|---|---|
| 0 | 0 | Always OK |
| 0 | 1 | $c(t_i) = c(t_{i+1})$ — **impossible** (proper coloring) |
| 1 | 0 | $c(t_{i-1}) = c(t_i)$ — **impossible** (proper coloring) |
| 1 | 1 | $c(t_{i-1}) = c(t_{i+1})$ |

So **all $\sigma_i$ are equal**: either all 0 or all 1.

## Step 3: Case $\sigma_i = 1$ for All $i$ — Impossible

This requires $c(t_{i-1}) = c(t_{i+1})$ for all $i$, forcing $T$ to have period

colors**, violating Condition 1. So this case never works.

## Step 4: Case $\sigma_i = 0$ for All $i$ — Requires $3 \mid n$

Here $c(b_i) = c(t_i)$ for all $i$, so $B = T$.

$$c(t_{i-1}) \neq c(t_{i+1}) \quad \text{for all } i. \tag{$\dagger$}$$

Together with the proper coloring $c(t_{i-1}) \neq c(t_i) \neq c(t_{i+1})$, cond

$$c(t_i) = c(t_{i \bmod 3}).$$

**Wrap-around on $C_n$**: We need $c(t_{n-1}) \neq c(t_0)$, i.e., $(n-1) \bmod 3

**Base face condition**: The period-3 sequence uses all three colors (as long as

## Step 5: Verification for $3 \mid n$

A valid coloring exists if and only if $3 \mid n$. The set $S = \{n \in \mathbb{
