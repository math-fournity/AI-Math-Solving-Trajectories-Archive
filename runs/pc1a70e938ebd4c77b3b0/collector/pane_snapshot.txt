## Proof

**Claim:** Yes, such a surjective function exists.

**Step 1: The domain is countably infinite.**

The set $\{0,1\}^*$ of all finite binary strings is $\bigcup_{n=0}^{\infty}\{0,1
\}^n$. Each $\{0,1\}^n$ is finite (of size $2^n$), and a countable union of fini
te sets is countable. Since $\{0,1\}^*$ is infinite (it contains strings of ever
y length), it is **countably infinite**.

**Step 2: The codomain is countably infinite.**

Let $S = \{x \in \{0,1\}^{\omega} : x \text{ contains finitely many } 1\text{'s}
\}$. Every element $x \in S$ is completely determined by the finite set $P(x) =
\{n \in \mathbb{N} : x_n = 1\} \subseteq \mathbb{N}$, which is finite by definit
ion of $S$. Conversely, every finite subset $F \subseteq \mathbb{N}$ yields a un
ique element $x \in S$ with $P(x) = F$. Hence $S$ is in bijection with the set $
\{F \subseteq \mathbb{N} : F \text{ finite}\}$ of all finite subsets of $\mathbb
{N}$.

The set of finite subsets of $\mathbb{N}$ is countable: the map $F \mapsto \sum_
{n \in F} 2^n$ is an injection into $\mathbb{N}$ (every finite subset maps to a
distinct natural number via binary expansion). Since $S$ is also infinite (it co
ntains, e.g., the strings with a single $1$ at position $n$ for each $n \in \mat
hbb{N}$), $S$ is **countably infinite**.

**Step 3: A surjection exists.**

Both the domain $\{0,1\}^*$ and the codomain $S$ are countably infinite. Fix enu
merations
$$\{0,1\}^* = \{a_0, a_1, a_2, \dots\}, \qquad S = \{s_0, s_1, s_2, \dots\}.$$
Define $f : \{0,1\}^* \to S$ by $f(a_k) = s_k$. Then every $s \in S$ equals $s_k
$ for some $k$, so $f(a_k) = s$, proving $f$ is surjective.

**Conclusion.** Since both sets are countably infinite, a surjective function fr
om $\{0,1\}^*$ onto $S$ exists. $\blacksquare$
