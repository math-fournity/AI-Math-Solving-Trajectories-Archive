# 解法

## 设置

令 $P(x,y) = 4 + x^4y^2 + x^2y^4 - kx^2y^2$。假设 $P = \sum_i Q_i(x,y)^2$，其中
每个 $Q_i$ 为实系数多项式。由于 $\deg P = 6$，每个 $Q_i$ 的次数最多为 3。将每个
$Q_i$ 写成其齐次分量：

$$Q_i = f_i + \ell_i + s_i + t_i,$$

其中 $f_i$ 为常数，$\ell_i$ 为线性，$s_i$ 为二次，$t_i$ 为三次齐次多项式。

## 齐次度匹配

展开 $\sum Q_i^2$ 并按次数匹配 $P$ 的项：

**次数 6：** $\sum t_i^2 = x^4y^2 + x^2y^4 = x^2y^2(x^2+y^2)$。

由于当 $x=0$ 或 $y=0$ 时该式为零，因此每个 $t_i$ 都能被 $xy$ 整除。令 $t_i = xy(
\alpha_i x + \beta_i y)$，则 $\sum (\alpha_i x + \beta_i y)^2 = x^2 + y^2$，得到
：
$$\sum \alpha_i^2 = 1,\quad \sum \beta_i^2 = 1,\quad \sum \alpha_i\beta_i = 0. \
tag{1}$$

**次数 5：** $\sum 2s_i t_i = 0$，令 $s_i = a_i x^2 + b_i xy + c_i y^2$，得到 $\
sum b_i\alpha_i = 0$ 和 $\sum b_i\beta_i = 0$（其他约束在后续会被自动满足）。

**次数 4：** $\sum(2\ell_i t_i + s_i^2) = -kx^2y^2$。匹配 $x^4$ 和 $y^4$ 系数：$
\sum a_i^2 = 0$ 且 $\sum c_i^2 = 0$，因此 **对所有 $i$，$a_i = c_i = 0$**，即 $s
_i = b_i xy$。

此时 $x^3y$ 和 $xy^3$ 系数给出 $\sum d_i\alpha_i = 0$，$\sum e_i\beta_i = 0$（其
中 $\ell_i = d_i x + e_i y$），而 $x^2y^2$ 系数给出：
$$\sum\bigl[2(d_i\beta_i + e_i\alpha_i) + b_i^2\bigr] = -k. \tag{2}$$

**次数 2：** $\sum(2f_i s_i + \ell_i^2) = 0$。$x^2$ 和 $y^2$ 系数给出 $\sum d_i^
2 = 0$，$\sum e_i^2 = 0$，因此 **对所有 $i$，$d_i = e_i = 0$**（所有 $\ell_i = 0
$）。$xy$ 系数给出：
$$\sum f_i b_i = 0. \tag{3}$$

令 (2) 中的 $d_i = e_i = 0$：
$$\boxed{\sum b_i^2 = -k.} \tag{4}$$

**次数 3：** $\sum(2f_i t_i + 2\ell_i s_i) = 0$；令 $\ell_i = 0$：$\sum f_i\alph
a_i = 0$，$\sum f_i\beta_i = 0$。

**次数 0：** $\sum f_i^2 = 4$。

## 可行性分析

向量 $\boldsymbol{\alpha}, \boldsymbol{\beta}$ 是正交的（由 (1) 可知）。向量 $\m
athbf{b} = (b_i)$ 和 $\mathbf{f} = (f_i)$ 均与 $\boldsymbol{\alpha}$ 和 $\boldsy
mbol{\beta}$ 正交，且彼此正交（由 (3) 可知），范数分别为：
$$\|\mathbf{f}\|^2 = 4, \qquad \|\mathbf{b}\|^2 = -k.$$

由于 $\|\mathbf{b}\|^2 = \sum b_i^2 \geq 0$（平方和），方程 (4) 要求 $-k \geq 0$
，即 $k \leq 0$。

- **当 $k \leq 0$ 时：** 我们可以选择足够多的索引（例如 4 个），使得 $\boldsymbo
l{\alpha}, \boldsymbol{\beta}$ 的正交补空间维数 $\geq 2$，并在其中放置正交的 $\m
athbf{f}$ 和 $\mathbf{b}$，满足 $\|\mathbf{f}\|^2 = 4$ 且 $\|\mathbf{b}\|^2 = -k
$。因此 $P$ 是 SOS（平方和）。
- **当 $k > 0$ 时：** 方程 (4) 要求 $\sum b_i^2 = -k < 0$，这**在实数域中是不可
能的**——这就是问题中提到的矛盾。

## 结论

阈值出现在 $k = 0$ 处：在此值时，$\sum b_i^2 = 0$（可行，此时所有 $b_i = 0$）；
对于任何 $k > 0$，所需的平方和为负数，产生矛盾。因此，使得 $P$ 不能表示为 SOS 的
最小 $k$ 为：

$$\boxed{k = 0}$$

在该临界值下，如果假设 $P = \sum Q_i^2$，则 $s_i$ 中 $xy$ 项系数的平方和等于 $-k
 = 0$，而对于任何更大的 $k$，该和将需要为负数——这在 $\mathbb{R}$ 中是不可能的。
