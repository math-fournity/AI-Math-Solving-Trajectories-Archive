# Isomorphism between Hom(ℤ_n, ℚ/ℤ) and ℤ_n

## Setup

Let ℤ_n = ℤ/nℤ and let ℚ/ℤ be the quotient of the additive rationals by the inte
gers. We construct an explicit group isomorphism

$$\Phi : \mathbb{Z}_n \longrightarrow \mathrm{Hom}(\mathbb{Z}_n,\, \mathbb{Q}/\m
athbb{Z}).$$

## The map

For $k \in \mathbb{Z}_n$ (represented by an integer $k$, taken mod $n$), define

$$\Phi(k) : \mathbb{Z}_n \to \mathbb{Q}/\mathbb{Z}, \qquad \Phi(k)(j) \;=\; \fra
c{k\,j}{n} + \mathbb{Z}, \qquad j \in \mathbb{Z}_n.$$

Here $\frac{kj}{n}+\mathbb{Z}$ denotes the coset of the rational $\frac{kj}{n}$
in $\mathbb{Q}/\mathbb{Z}$.

## Well-definedness of $\Phi(k)$

The value $\frac{kj}{n}+\mathbb{Z}$ is independent of the representative of $j$:
 if $j' = j + tn$, then $\frac{kj'}{n} = \frac{kj}{n} + kt \in \frac{kj}{n}+\mat
hbb{Z}$, so the coset is unchanged. It is likewise independent of the representa
tive of $k$ (same argument). Hence $\Phi(k)$ is a well-defined function $\mathbb
{Z}_n \to \mathbb{Q}/\mathbb{Z}$.

## $\Phi(k)$ is a homomorphism

For $j_1, j_2 \in \mathbb{Z}_n$:

$$\Phi(k)(j_1+j_2) = \frac{k(j_1+j_2)}{n}+\mathbb{Z} = \frac{kj_1}{n}+\frac{kj_2
}{n}+\mathbb{Z} = \Phi(k)(j_1)+\Phi(k)(j_2).$$

So $\Phi(k) \in \mathrm{Hom}(\mathbb{Z}_n, \mathbb{Q}/\mathbb{Z})$.

## $\Phi$ is a homomorphism

For $k_1, k_2 \in \mathbb{Z}_n$ and any $j \in \mathbb{Z}_n$:

$$\Phi(k_1+k_2)(j) = \frac{(k_1+k_2)j}{n}+\mathbb{Z} = \frac{k_1 j}{n}+\frac{k_2
 j}{n}+\mathbb{Z} = \Phi(k_1)(j)+\Phi(k_2)(j) = (\Phi(k_1)+\Phi(k_2))(j).$$

Thus $\Phi(k_1+k_2) = \Phi(k_1)+\Phi(k_2)$, and $\Phi$ is a group homomorphism.

## Injectivity

Suppose $\Phi(k) = 0$, i.e. $\Phi(k)(j) = 0+\mathbb{Z}$ for all $j$. Taking $j=1
$:

$$\frac{k}{n}+\mathbb{Z} = 0+\mathbb{Z} \;\Longrightarrow\; \frac{k}{n}\in\mathb
b{Z} \;\Longrightarrow\; n \mid k \;\Longrightarrow\; k \equiv 0 \pmod n.$$

So $\ker\Phi = \{0\}$ and $\Phi$ is injective.

## Surjectivity

Let $f \in \mathrm{Hom}(\mathbb{Z}_n, \mathbb{Q}/\mathbb{Z})$ be arbitrary. Set
$f(1) = q + \mathbb{Z}$ for some $q \in \mathbb{Q}$. Since $1$ has order $n$ in
$\mathbb{Z}_n$,

$$0 = f(n\cdot 1) = n\,f(1) = nq + \mathbb{Z},$$

so $nq \in \mathbb{Z}$, i.e. $q = \frac{m}{n}$ for some $m \in \mathbb{Z}$. Then
 for every $j \in \mathbb{Z}_n$,

$$f(j) = j\,f(1) = \frac{mj}{n} + \mathbb{Z} = \Phi(m)(j).$$

Hence $f = \Phi(m)$, proving $\Phi$ is surjective.

## Conclusion

$\Phi : \mathbb{Z}_n \to \mathrm{Hom}(\mathbb{Z}_n, \mathbb{Q}/\mathbb{Z})$ defi
ned by

$$\boxed{\;\Phi(k)(j) = \tfrac{kj}{n} + \mathbb{Z}\;}$$

is a well-defined group isomorphism. In words: **every homomorphism $\mathbb{Z}_
n \to \mathbb{Q}/\mathbb{Z}$ sends the generator $1$ to a coset $\frac{m}{n}+\ma
thbb{Z}$ with $m \in \mathbb{Z}$, and $m$ is determined mod $n$; the corresponde
nce $k \mapsto \bigl(j \mapsto \frac{kj}{n}+\mathbb{Z}\bigr)$ is the desired iso
morphism.**
