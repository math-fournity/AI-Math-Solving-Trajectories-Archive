## Proof

We address the question: *Does the Risch algorithm provide a definitive answer t
o whether any composite function can be integrated to obtain an elementary funct
ion?*

The answer is **qualified**: the Risch algorithm is a complete decision procedur
e **within the class of elementary functions**, but it does **not** extend to ar
bitrary composite functions outside that class. We establish this in two parts.

---

### Part 1. The Risch algorithm is a decision procedure for elementary functions
.

**Definition (elementary function).** A function is *elementary* over a differen
tial field $K$ if it can be obtained from $K$ and the constants by a finite sequ
ence of the following operations: arithmetic ($+,-,\times,\div$), differentiatio
n, algebraic extension, exponentiation ($\exp$), and logarithm ($\log$).

**Liouville's Theorem (1835, refined by Rosenlicht 1972).** Let $K$ be a differe
ntial field with algebraically closed constant field, and let $f \in K$. If $f$
has an elementary antiderivative over $K$, then there exist constants $c_1,\dots
,c_n$ and elements $v, u_1,\dots,u_n \in K$ such that

$$f = Dv + \sum_{i=1}^{n} c_i \frac{Du_i}{u_i}.$$

This reduces the existence question to a finite, algebraic search: one must dete
rmine whether $f$ decomposes into a derivative in $K$ plus a constant linear com
bination of logarithmic derivatives in $K$.

**Risch (1969).** Risch turned Liouville's theorem into an **algorithm**. For a
function $f$ built in a *transcendental elementary extension* of $\mathbb{C}(x)$
 (i.e., built from $x$, rational operations, $\exp$, and $\log$ by a tower of tr
anscendental extensions), the Risch algorithm:

1. **Always terminates.** Each step either reduces the problem to a strictly sim
pler sub-problem (measured by the structure of the extension tower) or resolves
it via Hermite reduction and solving a system of linear equations over the const
ants.
2. **Always returns a correct answer.** Either it produces an elementary antider
ivative, or it proves (via the failure of the Liouville decomposition to exist)
that no elementary antiderivative exists.

The **algebraic case** (functions involving algebraic extensions, e.g., $\sqrt{1
-x^2}$) was completed by **Trager (1984)** and **Risch–Trager**, using integrati
on on algebraic curves and the resolution of singularities of the associated dif
ferential form. The combined algorithm is a **decision procedure** for the entir
e elementary class: given any elementary function $f$, it terminates and definit
ively answers whether $\int f\,dx$ is elementary.

**Conclusion of Part 1.** For every elementary function $f$, the Risch algorithm
 (with the Trager extension for the algebraic case) gives a definitive yes/no an
swer. This is a theorem, not a heuristic: termination and correctness are proven
.

---

### Part 2. The Risch algorithm does **not** apply to arbitrary composite functi
ons.

The algorithm's completeness is **intrinsic to the elementary class**. It cannot
 be applied to:

- **Non-elementary composite functions.** If $f = g \circ h$ where $g$ or $h$ in
volves a non-elementary function (e.g., $f(x) = \operatorname{erf}(\sin x)$, or
$f(x) = \Gamma(x^2)$), the function lies outside any elementary extension tower
of $\mathbb{C}(x)$. The Risch algorithm has no input representation for such fun
ctions and no Liouville-style structural theorem to exploit. There is no known d
ecision procedure for elementary integrability of arbitrary compositions involvi
ng special functions.

- **Functions defined by non-algebraic data.** A function given by, say, a power
 series with no closed form, or by an ODE solution not expressible elementarily,
 is outside the algorithm's scope entirely.

The phrase *"any composite function"* is therefore too broad. Composition alone
does not confine a function to the elementary class: composing $\operatorname{er
f}$ with $x^2$ yields a composite function that is not elementary, and the Risch
 algorithm says nothing about it.

---

### Synthesis

| Scope | Definitive answer? |
|---|---|
| $f$ elementary (transcendental tower) | **Yes** — Risch 1969 |
| $f$ elementary (with algebraic extensions) | **Yes** — Trager 1984 |
| $f$ arbitrary composite (incl. special functions) | **No** — outside the algor
ithm's domain |

The Risch algorithm provides a definitive answer **if and only if** the integran
d belongs to the elementary function class. For elementary composite functions,
the answer is always a proven yes or no. For composite functions that escape the
 elementary class, the Risch algorithm is silent — it neither confirms nor denie
s elementary integrability, because its theoretical foundation (Liouville's deco
mposition) does not extend to those domains.

Therefore, the Risch algorithm does **not** provide a definitive answer to wheth
er **any** (i.e., every possible) composite function has an elementary antideriv
ative. It provides a definitive answer only for the subclass of composite functi
ons that are themselves elementary. The universal quantifier "any" in the questi
on is not satisfied.
