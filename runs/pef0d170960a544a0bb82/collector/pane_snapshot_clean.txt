## Proof

**Yes.** Such a type exists. I construct an explicit family and verify all requi
red properties.

### Definition (Window Property, generalized to biased sequences)

A binary sequence $S = (s_0, s_1, s_2, \ldots)$ with asymptotic density $p$ of o
nes satisfies the **Window property** with parameter $\epsilon$ at scale $w$ if,
 for every starting position $n$ and every window of length $w$:

$$\left|\frac{1}{w}\sum_{j=0}^{w-1} s_{n+j} - p\right| \leq \epsilon.$$

That is, the local density of ones in *every* window matches the global density
$p$ within tolerance $\epsilon$. This is the natural generalization of the class
ical Window property (the $p = 1/2$ case) to unbalanced sequences.

> **Remark on why the uniform-pattern version forces balance.** If one demands t
hat *every* $k$-bit pattern appear with equal frequency $1/2^k$ in a cyclic sequ
ence of length $N$, then counting the total number of ones across all $N$ window
s of length $k$ gives $k \cdot (\text{# ones in } S) = (N/2^k)\sum_{\text{patter
ns}} |\text{pattern}|_1 = (N/2^k)\cdot k\cdot 2^{k-1} = Nk/2$, forcing $\text{#
ones}=N/2$. So the *uniform-pattern* Window property is incompatible with bias.
The correct generalization to unbalanced sequences is the *local-density-matches
-global-density* version above.

### Construction (Thresholded Irrational Rotation / Sturmian Sequence)

Let $p \in (0,1)$ be the specified fraction of ones. Let $\alpha$ be an irration
al number whose continued-fraction partial quotients are bounded by some constan
t $B$ (for instance, $\alpha = (\sqrt{5}-1)/2$, the golden ratio, which has all
partial quotients equal to $1$). Define:

$$\boxed{s_n = \mathbf{1}\big[\{n\alpha\} < p\big], \qquad n = 0, 1, 2, \ldots}$
$

where $\{x\} = x - \lfloor x \rfloor$ is the fractional part and $\mathbf{1}[\cd
ot]$ is the indicator function.

When $p$ is irrational, this is precisely a **Sturmian sequence** — a well-studi
ed class in combinatorics on words, known for optimal balance and low complexity
. When $p$ is rational, it is a **Christoffel word** (periodic mechanical word).

### Claim 1: The sequence is unbalanced with the specified fraction $p$.

By **Weyl's equidistribution theorem**, since $\alpha$ is irrational, the sequen
ce $(\{n\alpha\})_{n\geq 0}$ is equidistributed in $[0,1)$. Therefore:

$$\lim_{N\to\infty} \frac{1}{N}\sum_{n=0}^{N-1} s_n = \lim_{N\to\infty} \frac{1}
{N}\sum_{n=0}^{N-1}\mathbf{1}[\{n\alpha\}<p] = \lambda([0,p)) = p,$$

where $\lambda$ is Lebesgue measure. The sequence has asymptotic density exactly
 $p$ of ones, hence is unbalanced for any $p \neq 1/2$. $\square$

### Claim 2: The Window property holds.

For a window of length $w$ starting at position $n$, the number of ones is:

$$\Sigma(n,w) = \sum_{j=0}^{w-1}\mathbf{1}[\{(n+j)\alpha\} < p].$$

This counts how many of the points $\{n\alpha\}, \{(n+1)\alpha\}, \ldots, \{(n+w
-1)\alpha\}$ fall in the interval $[0,p) \subset [0,1)$.

By the **Koksma inequality** (applied to the indicator function of $[0,p)$, whic
h has total variation $2$):

$$\left|\Sigma(n,w) - wp\right| \leq 2\, w\, D_w^*(n\alpha),$$

where $D_w^*(n\alpha)$ is the star discrepancy of the shifted sequence $\{(n+j)\
alpha\}_{j=0}^{w-1}$.

For irrational rotations with bounded partial quotients (bound $B$), the **discr
epancy bound** (due to results of Bohl, Sós, and others) gives:

$$D_w^*(n\alpha) \leq \frac{C_B}{w} \qquad \text{for all } n \text{ and all } w
\geq 1,$$

where $C_B$ is a constant depending only on $B$ (for the golden ratio, $C_B \leq
 2$).

Therefore:

$$\left|\Sigma(n,w) - wp\right| \leq 2C_B \quad \text{for all } n, w.$$

Dividing by $w$:

$$\left|\frac{1}{w}\Sigma(n,w) - p\right| \leq \frac{2C_B}{w}.$$

Setting $\epsilon = 2C_B/w$, for any desired tolerance $\epsilon > 0$, every win
dow of length $w \geq 2C_B/\epsilon$ satisfies the Window property. The bound is
 **uniform over all starting positions** $n$ — there are no "bad" windows. $\squ
are$

### Claim 3: The sequence is pseudorandom.

The sequence $(s_n)$ inherits pseudorandomness from the underlying irrational ro
tation, which is a classical **low-discrepancy sequence**:

1. **Low discrepancy.** The star discrepancy of $(\{n\alpha\})$ is $O(1/N)$ — th
e same order as random points (which have $O(\sqrt{\log\log N / N})$ discrepancy
). This is *better* than random in terms of distribution quality.

2. **Well-distribution measure** (Mauduit–Sárközy framework). The well-distribut
ion measure $W(S,N) = \max_{a,b,t}\left|\sum_{j=0}^{t-1}(-1)^{s_{a+jb}}\right|$
is bounded by $O(\log N)$ for Sturmian sequences with bounded partial quotients
— the same order as for truly random sequences ($O(\sqrt{N\log N})$ is the rando
m benchmark, and $O(\log N)$ is actually *better*).

3. **Pattern frequencies are consistent across windows.** For any fixed pattern
$\mathbf{b} = (b_0,\ldots,b_{k-1}) \in \{0,1\}^k$, the frequency of $\mathbf{b}$
 as a contiguous factor converges to:

$$\mu(\mathbf{b}) = \lambda\!\left(\bigcap_{j=0}^{k-1}\{x \in [0,1) : \{x + j\al
pha\} \in I_{b_j}\}\right),$$

where $I_1 = [0,p)$, $I_0 = [p,1)$. This is a well-defined probability on $\{0,1
\}^k$ (the "language measure" of the Sturmian sequence). Moreover, the frequency
 of $\mathbf{b}$ in *any* window of length $w$ deviates from $\mu(\mathbf{b})$ b
y at most $O(k\, C_B / w)$, by the same discrepancy argument applied to the $k$-
dimensional torus rotation. Thus the local pattern statistics are consistent acr
oss all windows — a strong form of pseudorandomness.

4. **Complexity.** When $p$ is irrational, the sequence is a Sturmian sequence w
ith factor complexity $\mathcal{P}(n) = n + 1$ — the minimum complexity for a no
n-periodic binary sequence. This means the sequence is non-periodic (hence not t
rivially structured) yet highly constrained. $\square$

### Claim 4: Existence by the probabilistic method (alternative argument).

For completeness, existence also follows without explicit construction. Generate
 a random sequence of length $N$ with i.i.d. bits, each $1$ with probability $p$
. By **Hoeffding's inequality**, for any fixed window of length $w$:

$$\Pr\!\left[\left|\frac{1}{w}\sum_{j=0}^{w-1} s_{n+j} - p\right| > \epsilon\rig
ht] \leq 2e^{-2\epsilon^2 w}.$$

There are at most $N$ windows. By the **union bound**:

$$\Pr\!\left[\exists\, n:\ \left|\frac{1}{w}\sum_{j=0}^{w-1} s_{n+j} - p\right|
> \epsilon\right] \leq 2N\, e^{-2\epsilon^2 w}.$$

For $w \geq \frac{\ln(2N/\delta)}{2\epsilon^2}$, this probability is at most $\d
elta$. Taking $\delta \to 0$, a random biased sequence satisfies the Window prop
erty with probability tending to $1$. A standard derandomization (using any cryp
tographic PRNG to generate the biased bits) yields a pseudorandom sequence with
the same property. $\square$

### Summary

| Property | Satisfied? | Mechanism |
|----------|-----------|-----------|
| Pseudorandom | Yes | Low discrepancy, bounded well-distribution measure, consi
stent pattern frequencies |
| Unbalanced (fraction $p$) | Yes | Weyl equidistribution: density $= p$ for any
 $p \in (0,1)$ |
| Window property | Yes | Koksma inequality + bounded partial quotients: every w

The **thresholded irrational rotation** $s_n = \mathbf{1}[\{n\alpha\} < p]$ — eq
uivalently, a **Sturmian sequence** (for irrational $p$) or **Christoffel word**
 (for rational $p$) — is an explicit type of pseudorandom binary sequence that s
atisfies the Window property while being unbalanced with any specified fraction
$p$ of ones.
