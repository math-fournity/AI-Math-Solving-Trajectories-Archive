## Proof

Let $X_t = (\sin a)A_t + (\cos a)B_t$, where $A_t, B_t$ are independent Brownian
 motions and $a$ is a constant. We verify that $X_t$ satisfies the defining prop
erties of a Brownian motion.

**Property 1: $X_0 = 0$ a.s.**

Since $A_0 = 0$ and $B_0 = 0$ a.s.,
$$X_0 = (\sin a)\cdot 0 + (\cos a)\cdot 0 = 0. \quad\checkmark$$

**Property 2: Continuous sample paths.**

$A_t$ and $B_t$ each have continuous sample paths a.s., and $X_t$ is a fixed lin
ear combination of these, so $X_t$ has continuous sample paths a.s. $\checkmark$

**Property 3: Independent increments.**

Let $0 \le t_0 < t_1 < \cdots < t_n$. The increments of $X$ are
$$X_{t_k} - X_{t_{k-1}} = (\sin a)(A_{t_k} - A_{t_{k-1}}) + (\cos a)(B_{t_k} - B
_{t_{k-1}}).$$

The increments $\{A_{t_k} - A_{t_{k-1}}\}_{k=1}^n$ are independent (Brownian mot
ion property of $A$), and likewise $\{B_{t_k} - B_{t_{k-1}}\}_{k=1}^n$ are indep
endent. Since $A$ and $B$ are independent processes, the entire collection $\{A_
{t_k} - A_{t_{k-1}}\}$ and $\{B_{t_k} - B_{t_{k-1}}\}$ (all $2n$ random variable
s) is mutually independent. Each $X_{t_k} - X_{t_{k-1}}$ is a measurable functio
n of the pair $(A_{t_k}-A_{t_{k-1}},\, B_{t_k}-B_{t_{k-1}})$, and these pairs ar
e disjoint subsets of a mutually independent collection, hence the increments $\
{X_{t_k} - X_{t_{k-1}}\}_{k=1}^n$ are independent. $\checkmark$

**Property 4: Gaussian increments with the correct variance.**

For $s < t$, the increment $X_t - X_s = (\sin a)(A_t - A_s) + (\cos a)(B_t - B_s
)$ is a linear combination of the independent Gaussian random variables $A_t - A
_s \sim \mathcal{N}(0, t-s)$ and $B_t - B_s \sim \mathcal{N}(0, t-s)$, hence is
itself Gaussian with
$$\mathbb{E}[X_t - X_s] = 0,$$
$$\operatorname{Var}(X_t - X_s) = (\sin^2 a)\operatorname{Var}(A_t - A_s) + (\co
s^2 a)\operatorname{Var}(B_t - B_s) = (\sin^2 a)(t-s) + (\cos^2 a)(t-s).$$

Using the Pythagorean identity $\sin^2 a + \cos^2 a = 1$,
$$\operatorname{Var}(X_t - X_s) = (\sin^2 a + \cos^2 a)(t-s) = t - s.$$

Therefore $X_t - X_s \sim \mathcal{N}(0, t-s)$. $\checkmark$

**Conclusion.**

$X_t = (\sin a)A_t + (\cos a)B_t$ satisfies all four defining properties of a Br
ownian motion: it starts at $0$, has continuous paths, has independent increment
s, and has Gaussian increments $\mathcal{N}(0, t-s)$. The key step is that the c
oefficients $(\sin a, \cos a)$ form a unit vector, so the variances combine via
$\sin^2 a + \cos^2 a = 1$ to yield exactly $t-s$.

Therefore, **yes**, $(\sin a)A_t + (\cos a)B_t$ is a Brownian motion.
