Looking at this problem, I need to find all primes $p$ such that $p$'s represent
ation in some base $b > 1$ is a permutation of the digits $\{0, 1, \ldots, b-1\}
$ (each appearing exactly once, leading zeros allowed).

## Key Divisibility Analysis

If $p$ has a $b$-digit base-$b$ representation that is a permutation of $\{0, 1,
 \ldots, b-1\}$, the digit sum is:
$$S = 0 + 1 + \cdots + (b-1) = \frac{b(b-1)}{2}$$

Since $b \equiv 1 \pmod{b-1}$, we have $b^i \equiv 1 \pmod{b-1}$, so:
$$p \equiv S = \frac{b(b-1)}{2} \pmod{b-1}$$

**Case 1: $b$ even.** Then $S = \frac{b}{2}(b-1) \equiv 0 \pmod{b-1}$, so $(b-1)
 \mid p$.
- $b = 2$: $b-1 = 1$, no constraint.
- $b \geq 4$: $b - 1 \geq 3$ and $p \geq b^{b-1} \geq 64 > 3$, so $p$ is **compo
site**. ✗

**Case 2: $b$ odd.** Then $b-1$ is even, so $S = \frac{b-1}{2} \cdot b \equiv \f
rac{b-1}{2} \pmod{b-1}$.

This gives $p = \frac{b-1}{2}(1 + 2k)$ for some integer $k \geq 0$, meaning $\fr
ac{b-1}{2} \mid p$.
- $b = 3$: $\frac{b-1}{2} = 1$, no constraint. Primes possible. ✓
- $b \geq 5$ odd: $\frac{b-1}{2} \geq 2$ and $p \geq b^{b-1} \geq 625 > 2$, so $
p$ is **composite**. ✗

**Conclusion:** Only bases $b = 2$ and $b = 3$ can produce primes.

## Enumerating the Primes

**Base $b = 2$:** Permutations of $\{0,1\}$ give $01_2 = 1$ (not prime) and $10_
2 = 2$ (prime). → **$p = 2$**

**Base $b = 3$:** All $3! = 6$ permutations of $\{0,1,2\}$ as 3-digit base-3 num
bers:

| Digits | Value | Prime? |
|--------|-------|--------|
| $012_3$ | $0\cdot9 + 1\cdot3 + 2 = 5$ | ✓ |
| $021_3$ | $0\cdot9 + 2\cdot3 + 1 = 7$ | ✓ |
| $102_3$ | $1\cdot9 + 0\cdot3 + 2 = 11$ | ✓ |
| $120_3$ | $1\cdot9 + 2\cdot3 + 0 = 15 = 3\times5$ | ✗ |
| $201_3$ | $2\cdot9 + 0\cdot3 + 1 = 19$ | ✓ |
| $210_3$ | $2\cdot9 + 1\cdot3 + 0 = 21 = 3\times7$ | ✗ |

Primes from $b=3$: **$5, 7, 11, 19$**.

(Note: $15$ and $21$ are divisible by $3$ — consistent with $p \equiv \frac{b-1}
{2} \cdot (\text{odd factor}) \pmod{b-1}$; here $b-1=2$ gives no factor-of-3 con
straint, but these happen to be multiples of 3 since the base-3 digit sum $S=3$
implies $p \equiv 0 \pmod{3}$... actually $p \equiv S \pmod{b-1} = p \equiv 3 \p
mod{2} \equiv 1$, so they're odd. They're divisible by 3 because $p \equiv S \pm
od{b-1}$ uses $b-1=2$, but $p \equiv S \pmod{b-1}$ is mod 2. The factor of 3 com
es from $b=3$ itself: $p \equiv d_0 \pmod{3}$, and $15 \equiv 0, 21 \equiv 0 \pm
od{3}$ since their last digits are $0$. This is just coincidence of the permutat
ion, not a structural constraint.)

## Final Sum

All qualifying primes: $\{2, 5, 7, 11, 19\}$

$$2 + 5 + 7 + 11 + 19 = \boxed{44}$$
