or all $x$.

**$f$ is non-decreasing**: If $x < y$, then $\{q_i < x\} \subseteq \{q_i < y\}$,

**$f$ is strictly increasing**: If $x < y$, there exists a rational $q_j \in (x,
y)$, so $f(y) \ge f(x) + 2^{-j} > f(x)$.

**Limits at infinity**: $\lim_{x\to -\infty} f(x) = 0$ and $\lim_{x\to +\infty}
f(x) = 1$, since for any $\epsilon > 0$, choosing $N$ with $2^{-N} < \epsilon$,

### Step 2: Left-continuity everywhere

**Claim**: $f$ is left-continuous at every $x_0 \in \mathbb{R}$.

As $x \to x_0^-$, the sets $\{q_i < x\}$ increase to $\{q_i < x_0\}$ (if $q_i <
x_0$, then $q_i < x$ for $x$ sufficiently close to $x_0$ from the left). By the
monotone convergence theorem for series (all terms non-negative):

$$\lim_{x \to x_0^-} f(x) = \sum_{q_i < x_0} 2^{-i} = f(x_0). \quad \checkmark$$

### Step 3: Right limit and discontinuity at rationals

**Claim**: $\lim_{x \to x_0^+} f(x) = \sum_{q_i \le x_0} 2^{-i}$.

As $x \to x_0^+$, the sets $\{q_i < x\}$ decrease to $\{q_i \le x_0\}$. By domin

$$\lim_{x \to x_0^+} f(x) = \sum_{q_i \le x_0} 2^{-i}.$$

**Case 1: $x_0 = q_j$ is rational.** Since the enumeration is injective, $q_i =
x_0$ only when $i = j$. Thus:

$$\lim_{x \to q_j^+} f(x) = f(q_j) + 2^{-j} > f(q_j).$$

So $f$ has a **jump discontinuity of magnitude $2^{-j}$** at each rational $q_j$

-j}$.

**Case 2: $x_0$ is irrational.** No $q_i$ equals $x_0$, so $\{q_i \le x_0\} = \{
q_i < x_0\}$, giving:

$$\lim_{x \to x_0^+} f(x) = \sum_{q_i < x_0} 2^{-i} = f(x_0).$$

Combined with left-continuity, **$f$ is continuous at $x_0$**.

### Step 4: Conclusion on continuity

**$f$ is not continuous on $\mathbb{R}$.** It is continuous at every irrational
and discontinuous at every rational, with a jump of size $2^{-j}$ at $q_j$.

### Step 5: Non-differentiability at rationals

Since differentiability implies continuity, and $f$ is discontinuous at every ra

### Step 6: Differentiability almost everywhere with $f' = 0$ a.e.

To show $f' = 0$ a.e., decompose $f = f_N + R_N$ where:

$$f_N(x) = \sum_{\substack{i \le N \\ q_i < x}} 2^{-i}, \qquad R_N(x) = \sum_{\s
ubstack{i > N \\ q_i < x}} 2^{-i}.$$

- **$f_N$** is a step function with finitely many jumps (at $q_1, \dots, q_N$),
constant on each interval between consecutive jumps. Thus $f_N' = 0$ at every po

- **$R_N$** is non-decreasing with $0 \le R_N(x) \le \sum_{i > N} 2^{-i} = 2^{-N

ge 0$ a.e.

Since $f = f_N + R_N$, we have $f' = f_N' + R_N' = R_N'$ a.e.

For any interval $[a, b]$, the standard inequality for non-decreasing functions

$$\int_a^b f'(x)\,dx = \int_a^b R_N'(x)\,dx \le R_N(b) - R_N(a) \le 2^{-N}.$$

Since this holds for **every** $N$, taking $N \to \infty$:

$$\int_a^b f'(x)\,dx = 0 \quad \text{for all } [a,b].$$

Since $f' \ge 0$ a.e. and $\int_a^b f' = 0$ for all intervals $[a,b]$, we conclu

$$f' = 0 \quad \text{a.e. on } \mathbb{R}.$$
