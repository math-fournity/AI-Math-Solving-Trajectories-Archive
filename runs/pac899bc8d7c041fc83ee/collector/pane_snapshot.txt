## Solution

Let $\omega = e^{2\pi i/3}$, a primitive cube root of unity. Then $K = \{\omega,
 \omega^2\}$, and the key identities are:
- $\omega^3 = 1$, so $\omega^2 = \bar\omega$,
- $1 + \omega + \omega^2 = 0$,
- $(z-\omega)(z-\omega^2) = z^2 + z + 1$.

### Constructing the polynomial

Consider
$$p(z) = z^2 + z + 1.$$

**Check $p(0)=1$:** $p(0) = 0+0+1 = 1$. ✓

**Check $|p(z)|<1$ on $K$:**
$$p(\omega) = \omega^2 + \omega + 1 = 0, \qquad p(\omega^2) = (\omega^2)^2 + \om
ega^2 + 1 = \omega^4 + \omega^2 + 1 = \omega + \omega^2 + 1 = 0.$$

Both vanish, so $|p(\omega)| = |p(\omega^2)| = 0 < 1$. ✓

(The polynomial $z^2+z+1$ is exactly the minimal polynomial of $\omega$ over $\m
athbb{R}$, so it vanishes at both points of $K$ while taking the value $1$ at th
e origin — precisely the required conditions.)

### Sum of the coefficients

The sum of the coefficients of $p(z) = z^2 + z + 1$ is $1 + 1 + 1 = 3$ (equivale
ntly $p(1) = 3$).
