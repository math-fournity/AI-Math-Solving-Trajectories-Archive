## Solution

**Step 1: Simplify the integrand using Gamma function identities.**

Using $\Gamma(1+z) = z\,\Gamma(z)$:
$$\Gamma(1+ix)\Gamma(1-ix) = (ix)\Gamma(ix)\cdot(-ix)\Gamma(-ix) = x^2\,\Gamma(i
x)\Gamma(-ix).$$

Since $\Gamma(-ix) = \frac{\Gamma(1-ix)}{-ix}$, and applying the reflection form
ula $\Gamma(z)\Gamma(1-z) = \frac{\pi}{\sin(\pi z)}$ with $z = ix$:
$$\Gamma(ix)\Gamma(1-ix) = \frac{\pi}{\sin(\pi ix)} = \frac{\pi}{i\sinh(\pi x)}.
$$

Therefore:
$$\Gamma(ix)\Gamma(-ix) = \frac{\Gamma(ix)\Gamma(1-ix)}{-ix} = \frac{1}{-ix}\cdo
t\frac{\pi}{i\sinh(\pi x)} = \frac{\pi}{x\sinh(\pi x)},$$

and so
$$\Gamma(1+ix)\Gamma(1-ix) = x^2\cdot\frac{\pi}{x\sinh(\pi x)} = \frac{\pi x}{\s
inh(\pi x)}.$$

**Step 2: Reduce the integral.**

The integrand $\frac{\pi x}{\sinh(\pi x)}$ is even, so
$$I = \int_{-\infty}^{\infty}\frac{\pi x}{\sinh(\pi x)}\,dx = 2\int_0^\infty \fr
ac{\pi x}{\sinh(\pi x)}\,dx.$$

Substituting $u = \pi x$, $dx = du/\pi$:
$$I = 2\int_0^\infty \frac{u}{\sinh u}\,\frac{du}{\pi} = \frac{2}{\pi}\int_0^\in
fty \frac{u}{\sinh u}\,du.$$

**Step 3: Evaluate $\int_0^\infty \frac{u}{\sinh u}\,du$ via geometric series.**

For $u > 0$,
$$\frac{1}{\sinh u} = \frac{2e^{-u}}{1-e^{-2u}} = 2\sum_{n=0}^{\infty} e^{-(2n+1
)u}.$$

By Tonelli's theorem (all terms positive),
$$\int_0^\infty \frac{u}{\sinh u}\,du = 2\sum_{n=0}^{\infty}\int_0^\infty u\,e^{
-(2n+1)u}\,du = 2\sum_{n=0}^{\infty}\frac{1}{(2n+1)^2}.$$

The sum of reciprocals of odd squares is
$$\sum_{n=0}^{\infty}\frac{1}{(2n+1)^2} = \sum_{n=1}^{\infty}\frac{1}{n^2} - \su
m_{n=1}^{\infty}\frac{1}{(2n)^2} = \frac{\pi^2}{6} - \frac{1}{4}\cdot\frac{\pi^2
}{6} = \frac{\pi^2}{8}.$$

Hence
$$\int_0^\infty \frac{u}{\sinh u}\,du = 2\cdot\frac{\pi^2}{8} = \frac{\pi^2}{4}.
$$

**Step 4: Conclude.**

$$I = \frac{2}{\pi}\cdot\frac{\pi^2}{4} = \frac{\pi}{2}.$$

$$\boxed{\displaystyle\int_{-\infty}^{\infty}\Gamma(1+ix)\Gamma(1-ix)\,dx = \fra
c{\pi}{2}.}$$
