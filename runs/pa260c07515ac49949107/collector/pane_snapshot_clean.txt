## Proof

Let $b_i = \tan a_i > 0$ for $i = 0, 1, \ldots, n$. Using the subtraction formul
a,
$$\tan(a_i - \tfrac{\pi}{4}) = \frac{\tan a_i - 1}{1 + \tan a_i} = \frac{b_i - 1
}{b_i + 1}.$$
Set $t_i = \frac{b_i - 1}{b_i + 1} \in (-1, 1)$, so that $b_i = \frac{1 + t_i}{1
 - t_i}$. The hypothesis becomes
$$\sum_{i=0}^{n} t_i \geq n - 1,$$
and the desired conclusion $\prod b_i \geq n^{n+1}$ is equivalent to
$$\sum_{i=0}^{n} \phi(t_i) \geq (n+1)\ln n, \qquad \text{where } \phi(t) = \ln\f
rac{1+t}{1-t}.$$

Note that $\phi$ is strictly increasing on $(-1,1)$, with $\phi'(t) = \frac{2}{1
-t^2}$.

**Case $n = 0$:** The hypothesis $\tan(a_0 - \pi/4) \geq -1$ is equivalent to $b
_0 \geq 0$, which holds since $b_0 > 0$. The conclusion $\tan a_0 \geq 0^1 = 0$
holds. ✓

**Case $n = 1$:** The hypothesis $\frac{b_0-1}{b_0+1} + \frac{b_1-1}{b_1+1} \geq
 0$ simplifies to
$$\frac{2(b_0 b_1 - 1)}{(b_0+1)(b_1+1)} \geq 0 \implies b_0 b_1 \geq 1 = 1^2. \q
uad\checkmark$$

**Case $n \geq 2$:** Since $\phi$ is strictly increasing, the minimum of $\sum \
phi(t_i)$ subject to $\sum t_i \geq n-1$ is attained on the boundary $\sum t_i =
 n-1$. We minimize $F = \sum \phi(t_i)$ over the domain $D = \{t \in (-1,1)^{n+1
} : \sum t_i = n-1\}$.

*Boundary behavior.* We show $F \to +\infty$ as we approach $\partial D$ (some $
t_i \to \pm 1$):

- If any $t_i \to 1^-$, then $\phi(t_i) = \ln\frac{1+t_i}{1-t_i} \to +\infty$.
- If any $t_i \to -1^+$, the constraint $\sum t_j = n-1$ forces the remaining $n
$ variables toward $1$. Concretely, set $t_0 = -1 + \varepsilon$ and $t_j = 1 -
\delta_j$ for $j \geq 1$, so $\sum_{j=1}^n \delta_j = \varepsilon$. Then
$$\phi(t_0) = \ln\frac{\varepsilon}{2 - \varepsilon} \approx \ln\varepsilon - \l
n 2, \qquad \sum_{j=1}^n \phi(t_j) = \sum_{j=1}^n \ln\frac{2 - \delta_j}{\delta_
j}.$$
By AM–GM, $\sum \ln \delta_j \leq n \ln\frac{\varepsilon}{n}$, so
$$\sum_{j=1}^n \phi(t_j) \geq n\ln\frac{2n}{\varepsilon}.$$
Therefore $F \geq (1-n)\ln\varepsilon + n\ln(2n) - \ln 2 \to +\infty$ as $\varep
silon \to 0$ (since $n \geq 2$).

Since $F \to +\infty$ at every boundary approach, the infimum is attained at an
interior point.

*Interior critical points.* By Lagrange multipliers, at any interior minimizer,
$\phi'(t_i) = \lambda$ for all $i$ and some constant $\lambda$. Since $\phi'(t)
= \frac{2}{1-t^2}$, this gives $t_i^2 = 1 - \frac{2}{\lambda}$, so each $t_i$ eq
uals either $+\alpha$ or $-\alpha$, where $\alpha = \sqrt{1 - 2/\lambda} \in (0,
1)$ (the case $\lambda \leq 2$ gives $t_i = 0$ for all, yielding $\sum t_i = 0 \
neq n-1$).

Suppose $k$ of the $t_i$ equal $+\alpha$ and $n+1-k$ equal $-\alpha$. The constr
aint gives
$$(2k - n - 1)\,\alpha = n - 1.$$
For $\alpha \in (0,1)$, we need $2k - n - 1 > 0$ (so $\alpha > 0$) and $\alpha =
 \frac{n-1}{2k-n-1} < 1$ (so $2k - n - 1 > n - 1$, i.e., $k > n$). Since $k \leq
 n+1$, this forces $k = n+1$: **all** $t_i$ are equal, with
$$t_i = \frac{n-1}{n+1} \quad \text{for all } i.$$

*The minimum value.* At this unique critical point,
$$\sum_{i=0}^n \phi(t_i) = (n+1)\,\phi\!\left(\frac{n-1}{n+1}\right) = (n+1)\ln\
frac{1 + \frac{n-1}{n+1}}{1 - \frac{n-1}{n+1}} = (n+1)\ln\frac{\frac{2n}{n+1}}{\
frac{2}{n+1}} = (n+1)\ln n.$$

Since this is the only interior critical point and $F \to +\infty$ at the bounda
ry, it is the **global minimum**. Therefore
$$\sum_{i=0}^n \phi(t_i) \geq (n+1)\ln n,$$
which exponentiates to
$$\prod_{i=0}^n b_i = \prod_{i=0}^n \tan a_i \geq n^{n+1}.$$

Equality holds when $t_i = \frac{n-1}{n+1}$ for all $i$, i.e., $\tan a_i = n$ fo
r all $i$, i.e., $a_i = \arctan n$ for all $i$. $\blacksquare$
