## Solution

We compute $I = \int_0^\infty \frac{\log x}{1+x^2}\,dx$ using the keyhole contou
r with $f(z) = \frac{\log^2 z}{1+z^2}$.

### Branch choice

The keyhole contour encircles the **positive** real axis, so we place the branch
 cut there and define

$$\log z = \ln|z| + i\arg z, \qquad 0 < \arg z < 2\pi.$$

This is **not** the principal branch (which has $-\pi < \arg z \le \pi$). The br
anch-cut location is forced by the contour geometry: the keyhole wraps the posit
ive real axis, so the cut must lie there.

### Residues

The poles inside $\Gamma$ are $z = i$ and $z = -i$ (simple poles of $\frac{1}{1+
z^2} = \frac{1}{(z-i)(z+i)}$).

**At $z = i$:** $\arg(i) = \pi/2$, so $\log(i) = i\pi/2$, hence $\log^2(i) = -\p
i^2/4$.

$$\operatorname{Res}_{z=i} f(z) = \frac{\log^2(i)}{2i} = \frac{-\pi^2/4}{2i} = \
frac{-\pi^2}{8i}.$$

**At $z = -i$:** With our branch $0 < \arg z < 2\pi$, we have $\arg(-i) = 3\pi/2
$ (not $-\pi/2$!). Therefore

$$\log(-i) = i\cdot\frac{3\pi}{2} = \frac{3\pi i}{2}, \qquad \log^2(-i) = -\frac
{9\pi^2}{4}.$$

$$\operatorname{Res}_{z=-i} f(z) = \frac{\log^2(-i)}{-2i} = \frac{-9\pi^2/4}{-2i
} = \frac{9\pi^2}{8i}.$$

**Sum of residues:**

$$\frac{-\pi^2}{8i} + \frac{9\pi^2}{8i} = \frac{8\pi^2}{8i} = \frac{\pi^2}{i} =
-i\pi^2.$$

By the residue theorem:

$$\oint_\Gamma \frac{\log^2 z}{1+z^2}\,dz = 2\pi i\cdot(-i\pi^2) = 2\pi^3.$$

### Evaluating the contour integral

**Upper bank** ($\arg z = 0$, traversed $\varepsilon \to R$): $\log z = \ln x$,

$$\int_\varepsilon^R \frac{(\ln x)^2}{1+x^2}\,dx.$$

**Lower bank** ($\arg z = 2\pi$, traversed $R \to \varepsilon$): $\log z = \ln x
 + 2\pi i$, so $\log^2 z = (\ln x)^2 + 4\pi i\ln x - 4\pi^2$,

$$\int_R^\varepsilon \frac{(\ln x)^2 + 4\pi i\ln x - 4\pi^2}{1+x^2}\,dx = -\int_
\varepsilon^R \frac{(\ln x)^2 + 4\pi i\ln x - 4\pi^2}{1+x^2}\,dx.$$

**Adding the two banks:**

$$\int_\varepsilon^R \frac{-4\pi i\ln x + 4\pi^2}{1+x^2}\,dx = -4\pi i\int_\vare
psilon^R \frac{\ln x}{1+x^2}\,dx + 4\pi^2\int_\varepsilon^R \frac{dx}{1+x^2}.$$

The large circle ($|z|=R$) contribution vanishes as $R\to\infty$ since $|f(z)| =
 O((\ln R)^2/R^2)$ and length is $O(R)$. The small circle ($|z|=\varepsilon$) co
ntribution vanishes as $\varepsilon\to 0$ since $|f(z)| = O((\ln\varepsilon)^2)$
 and length is $O(\varepsilon)$.

Taking limits:

$$-4\pi i\, I + 4\pi^2\cdot\frac{\pi}{2} = 2\pi^3,$$

using $\int_0^\infty \frac{dx}{1+x^2} = \frac{\pi}{2}$. Thus

$$-4\pi i\, I + 2\pi^3 = 2\pi^3 \implies -4\pi i\, I = 0 \implies I = 0.$$

### The value of $\log(-i)$ and why it differs from $-i\pi/2$

With the **principal branch** ($-\pi < \arg z \le \pi$), one would get $\arg(-i)
 = -\pi/2$ and thus $\log(-i) = -i\pi/2$.

However, the keyhole contour forces the branch cut onto the **positive** real ax
is, requiring the branch $0 < \arg z < 2\pi$. Under this branch the point $-i$ (
in the lower half-plane) has argument $3\pi/2$, giving

$$\boxed{\log(-i) = \frac{3\pi i}{2}}.$$

The discrepancy is exactly the branch-jump:

$$\frac{3\pi i}{2} - \left(-\frac{\pi i}{2}\right) = 2\pi i,$$

which is the discontinuity across the branch cut. Using the wrong value $-i\pi/2
$ would give $\log^2(-i) = -\pi^2/4$ (same as $\log^2(i)$), making the residues
cancel and yielding the nonsensical result $0 = 2\pi^3$. The correct value $3\pi
 i/2$ is what produces the nonzero residue sum that makes the method work.

### Result

$$\int_0^\infty \frac{\log x}{1+x^2}\,dx = 0.$$

(This is consistent with the substitution $x \mapsto 1/x$, under which the integ
rand changes sign while the measure is preserved.)
