## Proof

Let $X = C[0,1]$ equipped with the supremum norm $\|\cdot\|_\infty$, and let $\L
ambda: X \to X$ be defined by
$$\Lambda(f)(x) = (1-x)\,f(x).$$

### Step 1. $\Lambda$ is a bounded linear operator

Linearity is immediate. For the norm,
$$\|\Lambda f\|_\infty = \sup_{x\in[0,1]} |(1-x)f(x)| \le \sup_{x\in[0,1]}|1-x|\
cdot\|f\|_\infty = \|f\|_\infty.$$
Taking $f \equiv 1$ gives $\|\Lambda f\|_\infty = \sup_{x\in[0,1]}(1-x) = 1 = \|
f\|_\infty$, so $\|\Lambda\| = 1$. Hence $\Lambda$ is bounded and its spectrum $
\sigma(\Lambda)$ is a nonempty compact subset of $\{z : |z|\le 1\}$.

### Step 2. The spectrum is contained in $[0,1]$

For $\lambda \in \mathbb{C}$, the operator $\Lambda - \lambda I$ is multiplicati
on by the function
$$h_\lambda(x) = (1-x) - \lambda.$$

**Claim.** If $\lambda \notin [0,1]$, then $\lambda$ belongs to the resolvent se
t $\rho(\Lambda)$.

*Proof of claim.* The function $g(x) = 1-x$ maps $[0,1]$ onto $[0,1]$. If $\lamb
da \notin [0,1]$, then $h_\lambda(x) = g(x) - \lambda \neq 0$ for every $x \in [
0,1]$. Since $[0,1]$ is compact and $h_\lambda$ is continuous, $|h_\lambda|$ att
ains a positive minimum $m > 0$. Therefore $1/h_\lambda \in C[0,1]$, and multipl
ication by $1/h_\lambda$ is a bounded operator on $X$ that is the inverse of $\L
ambda - \lambda I$. Hence $\lambda \in \rho(\Lambda)$. $\square$

### Step 3. Every $\lambda \in [0,1]$ belongs to $\sigma(\Lambda)$

Let $\lambda \in [0,1]$ and set $x_0 = 1 - \lambda \in [0,1]$. Then $h_\lambda(x
_0) = 0$.

The range of $\Lambda - \lambda I$ is
$$\operatorname{ran}(\Lambda - \lambda I) = \{h_\lambda \cdot f : f \in C[0,1]\}
.$$
Every function in this range vanishes at $x_0$ (since $h_\lambda(x_0)=0$). In pa
rticular, the constant function $\mathbf{1}$ is not in the range, so $\Lambda -
\lambda I$ is not surjective. Therefore $\lambda \in \sigma(\Lambda)$.

Combining Steps 2 and 3:
$$\boxed{\sigma(\Lambda) = [0,1].}$$

### Step 4. Spectral type classification

**Point spectrum (eigenvalues).** Suppose $(\Lambda - \lambda I)f = 0$ for some
$f \in C[0,1]$, i.e., $(1-x-\lambda)f(x) = 0$ for all $x \in [0,1]$.

- If $\lambda \notin [0,1]$: $h_\lambda$ never vanishes, so $f \equiv 0$.
- If $\lambda \in [0,1]$: $h_\lambda$ vanishes only at the single point $x_0 = 1
-\lambda$. Thus $f(x) = 0$ for all $x \neq x_0$, and by continuity $f(x_0) = 0$
as well, giving $f \equiv 0$.

In both cases $f \equiv 0$, so $\Lambda$ has **no eigenvalues**. The point spect
rum is empty.

**Residual spectrum.** For $\lambda \in [0,1]$, the range of $\Lambda - \lambda
I$ is contained in the closed proper subspace
$$M_{x_0} = \{g \in C[0,1] : g(x_0) = 0\}, \qquad x_0 = 1-\lambda.$$
Since $M_{x_0}$ is a closed hyperplane (kernel of the nonzero continuous linear
functional $g \mapsto g(x_0)$), it is **not dense** in $C[0,1]$. The operator $\
Lambda - \lambda I$ is injective (as shown above, its kernel is trivial), yet it
s range is not dense. By definition, this places $\lambda$ in the **residual spe
ctrum**.

**Continuous spectrum.** Since every $\lambda \in [0,1]$ is in the residual spec
trum and the point spectrum is empty, the continuous spectrum is empty.

### Conclusion

The spectrum of $\Lambda$ is
$$\sigma(\Lambda) = [0,1],$$
with the following decomposition:
- **Point spectrum:** $\varnothing$ (no eigenvalues),
- **Continuous spectrum:** $\varnothing$,
- **Residual spectrum:** $[0,1]$.

The entire spectrum $[0,1]$ consists of residual spectrum. This reflects the fac
t that $\Lambda$ is a multiplication operator by the continuous function $g(x) =
 1-x$, whose range is $g([0,1]) = [0,1]$, and the general principle that for a m
ultiplication operator $M_g$ on $C(K)$ (with $K$ compact), $\sigma(M_g) = g(K)$,
 with every interior value of $g$ giving rise to residual spectrum (since point-
evaluation functionals detect the non-density of the range).
