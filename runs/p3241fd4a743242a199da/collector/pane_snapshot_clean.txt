## Part (a): Extreme points for $1 < p < \infty$

**Claim.** $\mathcal{E}_p = \{f \in L^p(X,\mu) : \|f\|_p = 1\}$, the unit sphere
.

**Proof.** We assume $L^p(X,\mu)\neq\{0\}$ (which holds whenever there exists a
measurable set of finite positive measure; the degenerate case $L^p=\{0\}$ gives
 $B=\{0\}$ with $\mathcal{E}_p=\{0\}$ trivially).

**($\subseteq$) No interior point is extreme.** Let $\|f\|_p < 1$. Since $L^p\ne
q\{0\}$, pick nonzero $u\in L^p$ with $\|u\|_p < 1-\|f\|_p$. Then
$$f = \tfrac{1}{2}(f+u) + \tfrac{1}{2}(f-u),$$
with $\|f\pm u\|_p \le \|f\|_p + \|u\|_p < 1$ and $f+u \ne f-u$. So $f$ is not e
xtreme.

**($\supseteq$) Every unit vector is extreme.** Let $\|f\|_p=1$ and suppose $f=\
frac{g+h}{2}$ with $\|g\|_p\le 1$, $\|h\|_p\le 1$. By Minkowski's inequality:
$$1 = \|f\|_p = \left\|\tfrac{g+h}{2}\right\|_p \le \tfrac{1}{2}(\|g\|_p+\|h\|_p
) \le 1.$$
Equality holds throughout, so $\|g\|_p=\|h\|_p=1$ and $\|g+h\|_p = \|g\|_p+\|h\|
_p = 2$.

**Equality case in Minkowski's inequality for $1<p<\infty$:** Equality $\|g+h\|_
p = \|g\|_p+\|h\|_p$ holds if and only if $g$ and $h$ are nonnegatively linearly
 dependent, i.e., $g = \lambda h$ a.e. for some $\lambda \ge 0$ (the case $h=0$
is excluded since $\|h\|_p=1$). Since $\|g\|_p=\|h\|_p=1$, we get $\lambda=1$, h
ence $g=h=f$ a.e. Therefore $f$ is extreme. $\square$

## Part (b): The case $p=1$, $\mu$ nonatomic

**Claim.** If $\mu$ is nonatomic, the closed unit ball of $L^1(X,\mu)$ has **no*
* extreme points: $\mathcal{E}_1 = \emptyset$.

**Proof.** Let $f\in L^1$ with $\|f\|_1 \le 1$. We show $f$ is not extreme.

**Case $\|f\|_1 < 1$:** As in part (a), pick nonzero $u\in L^1$ with $\|u\|_1 <
1-\|f\|_1$ and write $f = \frac{(f+u)+(f-u)}{2}$.

**Case $\|f\|_1 = 1$:** Set $E = \{x : f(x)\ne 0\}$, so $\int_E |f|\,d\mu = 1$ a
nd in particular $\mu(E)>0$.

Define the measure $\nu(A) = \int_A |f|\,d\mu$. Since $\mu$ is nonatomic, $\nu$
is also nonatomic: if $A$ were a $\nu$-atom with $\nu(A)>0$, then $|f|>0$ on a s
ubset $A_0\subseteq A$ with $\mu(A_0)>0$. Since $\mu$ is nonatomic, there exists
 $B\subset A_0$ with $0<\mu(B)<\mu(A_0)$, and one checks that $0<\nu(B)<\nu(A)$,
 contradicting $A$ being a $\nu$-atom.

Since $\nu$ is nonatomic and $\nu(E)=1$, by the intermediate value property of n
onatomic measures (a consequence of Lyapunov's theorem), there exists $E'\subset
eq E$ with $\nu(E') = \frac{1}{2}$. Set $E'' = E\setminus E'$, so $\nu(E'')=\fra
c{1}{2}$ as well, and both $E',E''$ have positive $\nu$-measure.

Define:
$$g = 2f\cdot\mathbf{1}_{E'}, \qquad h = 2f\cdot\mathbf{1}_{E''}.$$

Then:
- $\frac{g+h}{2} = f\cdot\mathbf{1}_{E'} + f\cdot\mathbf{1}_{E''} = f\cdot\mathb
f{1}_E = f$ (since $f=0$ off $E$).
- $\|g\|_1 = 2\nu(E') = 1$.
- $\|h\|_1 = 2\nu(E'') = 1$.
- $g\ne h$: they are supported on the disjoint sets $E'$ and $E''$, each of posi
tive $\nu$-measure, so both are nonzero.

Thus $f$ is not extreme. Since $f$ was arbitrary, $\mathcal{E}_1 = \emptyset$. $
\square$

**Summary.**
- **(a)** For $1<p<\infty$: $\mathcal{E}_p = \{f\in L^p : \|f\|_p = 1\}$, the en
tire unit sphere. The key mechanism is strict convexity of $L^p$ for $1<p<\infty
$, which forces the equality case in Minkowski's inequality to yield $g=h$.
- **(b)** For $p=1$ with $\mu$ nonatomic: $\mathcal{E}_1 = \emptyset$. The nonat
omic property allows splitting the support of any unit vector into two pieces of
 equal $|f|$-integral, decomposing $f$ as a midpoint of two distinct unit vector
s. This reflects the failure of strict convexity in $L^1$.
