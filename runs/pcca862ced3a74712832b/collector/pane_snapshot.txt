## Solution

**Setup.** We have a 99×99 grid of points (x,y) with x,y ∈ {1,2,…,99}. Each poin
t (x,y) is assigned a value v(x,y) ∈ {1,2,…,100}. The constraints are:
- **Row y=k:** the 99 values are distinct and none equals k.
- **Column x=k:** the 99 values are distinct and none equals k.

**Key observation — fixed row/column sums.** In row y=k, we have 99 distinct val
ues from {1,…,100}, none equal to k. Therefore the row contains exactly the set
{1,…,100} \ {k}, and:
$$\sum_{x=1}^{99} v(x,k) = \frac{100 \cdot 101}{2} - k = 5050 - k.$$

Likewise, in column x=k, the 99 values are exactly {1,…,100} \ {k}, so:
$$\sum_{y=1}^{99} v(k,y) = 5050 - k.$$

**Total sum S.** Summing column sums:
$$S = \sum_{x=1}^{99}\sum_{y=1}^{99} v(x,y) = \sum_{k=1}^{99}(5050 - k) = 99 \cd
ot 5050 - \frac{99 \cdot 100}{2} = 499{,}950 - 4{,}950 = 495{,}000.$$

**Computing E[x+y].** We have:
$$E[x+y] = \frac{1}{S}\sum_{(x,y)}(x+y)\,v(x,y) = \frac{1}{S}\left(\sum_{(x,y)}
x\,v(x,y) + \sum_{(x,y)} y\,v(x,y)\right).$$

**Sum involving x.** Group by column:
$$\sum_{(x,y)} x\,v(x,y) = \sum_{k=1}^{99} k \cdot \left(\sum_{y=1}^{99} v(k,y)\
right) = \sum_{k=1}^{99} k(5050 - k).$$

Expanding:
$$= 5050\sum_{k=1}^{99} k - \sum_{k=1}^{99} k^2 = 5050 \cdot 4950 - \frac{99 \cd
ot 100 \cdot 199}{6}.$$

Computing each term:
- $5050 \cdot 4950 = 24{,}997{,}500$
- $\frac{99 \cdot 100 \cdot 199}{6} = \frac{1{,}970{,}100}{6} = 328{,}350$

So:
$$\sum_{(x,y)} x\,v(x,y) = 24{,}997{,}500 - 328{,}350 = 24{,}669{,}150.$$

**Sum involving y.** Group by row:
$$\sum_{(x,y)} y\,v(x,y) = \sum_{k=1}^{99} k \cdot \left(\sum_{x=1}^{99} v(x,k)\
right) = \sum_{k=1}^{99} k(5050 - k) = 24{,}669{,}150.$$

This equals the x-sum since both row and column sums are $5050 - k$ — the result
 is independent of the particular valid filling.

**Combining:**
$$E[x+y] = \frac{2 \cdot 24{,}669{,}150}{495{,}000} = \frac{49{,}338{,}300}{495{
,}000}.$$

**Simplification.** Dividing numerator and denominator by 300:
$$\frac{49{,}338{,}300}{495{,}000} = \frac{164{,}461}{1{,}650}.$$

Since $164{,}461 = 11 \cdot 14{,}951$ and $1{,}650 = 11 \cdot 150$:
$$= \frac{14{,}951}{150}.$$

The number 14,951 is prime (verified by trial division up to $\sqrt{14951} \appr
ox 122$), and $\gcd(14951, 150) = 1$ since 14,951 is odd, not divisible by 3 (di
git sum 20), and not divisible by 5. So the fraction is fully reduced.

 values in {1,2,3}: the unique valid grid is v(1,1)=2, v(2,1)=3, v(1,2)=3, v(2,2
)=1, giving S=9 and E[x+y] = 26/9. The formula gives $2 \cdot (1 \cdot 5 + 2 \cd
