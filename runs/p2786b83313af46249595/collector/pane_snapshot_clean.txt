设置：八元数乘法

通过 Cayley-Dickson 构造，$\mathbb{O} = \mathbb{H} \oplus \mathbb{H}\ell$，其中
$\ell$ 是一个新的虚单位，乘法规则为：

$$(a + b\ell)(c + d\ell) = (ac - \bar{d},b) + (d,a + b,\bar{c})\ell,$$

其中 $a,b,c,d \in \mathbb{H}$，上划线表示四元数共轭。复数嵌入为 $\mathbb{C} =
\mathbb{R} \oplus \mathbb{R}i \subset \mathbb{H} \subset \mathbb{O}$，因此 $i$
既是复数的虚单位，也是（四元数，然后是八元数的）虚单位。

反例

取：

  • $z = i \in \mathbb{S}^1$（复单位圆），
  • $x = \ell \in \mathbb{S}^7$（八元数单位球面），
  • $y = j \in \mathbb{S}^7$（四元数虚单位，视为八元数）。

所有三个元素都是单位的，因此它们属于所需的球面。

计算 $z \cdot (x \ast y) = i(\ell, j)$

首先计算 $\ell, j$。将 $\ell = 0 + 1\cdot\ell$ 和 $j = j + 0\cdot\ell$ 代入，因
此 $a=0, b=1, c=j, d=0$：

$$\ell, j = (0\cdot j - \bar{0}\cdot 1) + (0\cdot 0 + 1\cdot\bar{j})\ell = 0 +
(-j)\ell = -j\ell.$$

现在计算 $i(-j\ell)$。将 $i = i + 0\ell$ 和 $-j\ell = 0 + (-j)\ell$ 代入，因此
$a=i, b=0, c=0, d=-j$：

$$i(-j\ell) = (i\cdot 0 - \overline{(-j)}\cdot 0) + ((-j)\cdot i +
0\cdot\bar{0})\ell = 0 + (-ji)\ell.$$

由于在四元数中 $ji = -ij = -k$，我们得到 $-ji = k$，因此：

$$i(\ell, j) = k\ell.$$

计算 $(z \cdot x) \ast y = (i\ell),j$

首先计算 $i\ell$。将 $i = i + 0\ell$ 和 $\ell = 0 + 1\ell$ 代入，因此 $a=i, b=0,
c=0, d=1$：

$$i\ell = (i\cdot 0 - \bar{1}\cdot 0) + (1\cdot i + 0\cdot\bar{0})\ell = 0 +

现在计算 $(i\ell),j$。将 $i\ell = 0 + i\ell$ 和 $j = j + 0\ell$ 代入，因此 $a=0,

$$(i\ell),j = (0\cdot j - \bar{0}\cdot i) + (0\cdot 0 + i\cdot\bar{j})\ell = 0 +
(i\cdot(-j))\ell = (-ij)\ell.$$

由于 $ij = k$，我们得到 $-ij = -k$，因此：

$$(i\ell),j = -k\ell.$$

$$z\cdot(x\ast y) = i(\ell, j) = k\ell, \qquad (z\cdot x)\ast y = (i\ell),j = -

$$i\cdot(\ell \ast j) \neq (i\cdot\ell)\ast j.$$
