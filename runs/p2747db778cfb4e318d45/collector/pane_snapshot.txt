## Solution

**Substitution.** Let $x = e^t$, so $t \in [0,1]$, $dx = e^t\,dt$. Then
$$a_n = \int_1^e \ln^n(x)\,dx = \int_0^1 t^n e^t\,dt.$$

**Asymptotics of $a_n$.** Integrating by parts with $u = e^t$, $dv = t^n\,dt$:
$$a_n = \Big[\tfrac{t^{n+1}}{n+1}e^t\Big]_0^1 - \int_0^1 \tfrac{t^{n+1}}{n+1}e^t
\,dt = \frac{e}{n+1} - \frac{a_{n+1}}{n+1}.$$

Since $0 \le e^t \le e$ on $[0,1]$:
$$0 \le a_{n+1} = \int_0^1 t^{n+1}e^t\,dt \le e\int_0^1 t^{n+1}\,dt = \frac{e}{n
+2},$$
so $\frac{a_{n+1}}{n+1} = O(1/n^2)$. Therefore
$$a_n = \frac{e}{n+1} + O\!\left(\tfrac{1}{n^2}\right) = \frac{e}{n} + O\!\left(
\tfrac{1}{n^2}\right).$$

**Summing.** Let $S_n = a_1 + a_2 + \cdots + a_n$. Then
$$S_n = \sum_{k=1}^n \left(\frac{e}{k} + O\!\left(\tfrac{1}{k^2}\right)\right) =
 e\,H_n + O(1),$$
where $H_n = \sum_{k=1}^n \frac{1}{k}$ is the $n$-th harmonic number (the $O(1)$
 uses convergence of $\sum 1/k^2$).

Since $H_n = \ln n + \gamma + o(1)$:
$$S_n = e\ln n + O(1).$$

**The limit.**
$$\lim_{n\to\infty}\frac{S_n}{\ln n} = \lim_{n\to\infty}\frac{e\ln n + O(1)}{\ln
 n} = e.$$

$$\boxed{e}$$
