## Proof

Let the 1987 sets be $B_1, B_2, \ldots, B_{1987}$, each with $|B_i| = 45$, and $
|B_i \cup B_j| = 89$ for all $i \neq j$.

**Step 1: Pairwise intersection size.** By inclusion-exclusion, $|B_i \cap B_j|
= |B_i| + |B_j| - |B_i \cup B_j| = 45 + 45 - 89 = 1$. So every two sets share ex
actly one element.

**Step 2: Replication numbers.** For each element $x$ in the universe, let $r_x$
 = number of sets containing $x$. Fix a set $B_i$. The other 1986 sets each meet
 $B_i$ in exactly one element, and each element $x \in B_i$ is shared with exact
ly $r_x - 1$ other sets. Therefore:
$$\sum_{x \in B_i} (r_x - 1) = 1986 \implies \sum_{x \in B_i} r_x = 1986 + 45 =
2031. \tag{$\star$}$$

**Step 3: Bounding $r_x$ in the non-sunflower case.** Suppose not all sets share
 a common element (non-sunflower case). Then for every element $x$, $r_x < 1987$
, so there exists some set $B_j$ not containing $x$.

Now $B_j$ must meet each of the $r_x$ sets containing $x$. These meeting points
are all distinct: if $B_j$ met two sets $B_a, B_b$ (both containing $x$) at the
same element $z$, then $z \in B_a \cap B_b = \{x\}$, forcing $z = x$, contradict
ing $x \notin B_j$. So $B_j$ uses $r_x$ distinct elements to meet these sets, gi
ving:
$$r_x \leq |B_j| = 45 \quad \text{for all } x. \tag{$\star\star$}$$

**Step 4: Deriving the contradiction.** Applying $(\star\star)$ to $(\star)$:
$$2031 = \sum_{x \in B_i} r_x \leq 45 \cdot 45 = 2025.$$
This is a contradiction ($2031 > 2025$). Therefore the non-sunflower case is imp
ossible.

**Step 5: The sunflower (near-pencil) structure.** All 1987 sets must share a si
ngle common element $p$. Since every pair intersects in exactly one element and
all contain $p$, each pair intersects *only* at $p$. Thus the remaining 44 eleme
nts of each set are unique to that set (appear in no other set).

**Step 6: Counting the union.**
$$\left|\bigcup_{i=1}^{1987} B_i\right| = \underbrace{1}_{\text{common } p} + \u
nderbrace{1987 \times 44}_{\text{unique elements}} = 1 + 87428 = 87429.$$
