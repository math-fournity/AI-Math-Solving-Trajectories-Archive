## Solution

We want the limit of
$$P_{n,k} = \frac{\binom{k-1}{n}}{\binom{n+k-1}{n}}$$
as $n,k\to\infty$ with $k/n^2 \to a > 0$.

**Step 1: Rewrite as a product.**

Since $k \sim an^2 \gg n$, we have $k-1 \ge n$ for all large $n$, so the binomia
l coefficients are well-defined. Writing $m = k-1$,

$$P_{n,k} = \frac{(m!)^2}{(m-n)!\,(m+n)!} = \prod_{i=1}^{n}\frac{m-n+i}{m+i} = \
prod_{i=1}^{n}\left(1 - \frac{n}{m+i}\right),$$
where $m = k-1$. Setting $x_i = \dfrac{n}{k-1+i}$ for $i=1,\dots,n$, we have $P_
{n,k} = \prod_{i=1}^n (1-x_i)$, so
$$\log P_{n,k} = \sum_{i=1}^{n}\log(1-x_i).$$

**Step 2: Estimate $x_i$.**

Since $k/n^2\to a$, for large $n$ we have $k = an^2(1+o(1))$, and $1\le i\le n \
ll k$, so
$$x_i = \frac{n}{k-1+i} = \frac{n}{k}\cdot\frac{1}{1+(i-1)/k}.$$
Moreover $\max_i x_i \le \frac{n}{k-n} \sim \frac{1}{an}\to 0$, so all $x_i\to 0
$ uniformly.

**Step 3: Compute $\sum x_i$.**

$$\sum_{i=1}^{n} x_i = n\sum_{i=1}^{n}\frac{1}{k-1+i} = \frac{n}{k}\sum_{i=1}^{n
}\frac{1}{1+(i-1)/k}.$$

Using $\frac{1}{1+t} = 1 - t + O(t^2)$ for $t = (i-1)/k = O(n/k) = O(1/n)\to 0$:

$$\sum_{i=1}^{n}\frac{1}{k-1+i} = \frac{1}{k}\left(n - \frac{1}{k}\cdot\frac{n(n
-1)}{2} + O\!\left(\frac{n^3}{k^2}\right)\right) = \frac{n}{k} - \frac{n^2}{2k^2
} + O\!\left(\frac{n^3}{k^3}\right).$$

Multiplying by $n$:
$$\sum_{i=1}^{n} x_i = \frac{n^2}{k} - \frac{n^3}{2k^2} + O\!\left(\frac{n^4}{k^
3}\right).$$

With $k\sim an^2$: $\frac{n^2}{k}\to\frac{1}{a}$, $\frac{n^3}{k^2}\sim\frac{1}{a
^2 n}\to 0$, $\frac{n^4}{k^3}\sim\frac{1}{a^3 n^2}\to 0$. Hence
$$\sum_{i=1}^{n} x_i \;\longrightarrow\; \frac{1}{a}.$$

**Step 4: Bound $\sum x_i^2$.**

$$\sum_{i=1}^{n} x_i^2 \le n\cdot\frac{n^2}{(k-n)^2} \sim \frac{n^3}{k^2} \sim \
frac{1}{a^2 n}\to 0.$$

**Step 5: Conclude.**

For large $n$, all $x_i < 1/2$, so $\log(1-x_i) = -x_i + O(x_i^2)$ uniformly. Th
erefore
$$\log P_{n,k} = -\sum_{i=1}^{n} x_i + O\!\left(\sum_{i=1}^{n} x_i^2\right) = -\
frac{1}{a} + o(1) + o(1) \;\longrightarrow\; -\frac{1}{a}.$$

Exponentiating:
$$\lim_{\substack{n,k\to\infty\\ k/n^2\to a}} \frac{\binom{k-1}{n}}{\binom{n+k-1
}{n}} = e^{-1/a}.$$
