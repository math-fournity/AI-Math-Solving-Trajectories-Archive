## Proof

**Step 1: Express the curve in surface coordinates.**

Since X(u,v) = (u cos v, u sin v, v), comparing with γ_α(t) = (t cos(αt), t sin(
αt), αt), we identify u = t, v = αt. So in parameter space the curve is the line
 v = αu, traversed with u(t) = t, v(t) = αt.

**Step 2: Compute the first fundamental form.**

X_u = (cos v, sin v, 0), X_v = (−u sin v, u cos v, 1).

E = 1, F = 0, G = u² + 1.

**Step 3: Compute the Christoffel symbols** (orthogonal coordinates, F = 0):

Γ^u_{uu} = 0, Γ^u_{uv} = 0, Γ^u_{vv} = −G_u/(2E) = −u,

Γ^v_{uu} = 0, Γ^v_{uv} = G_u/(2G) = u/(u²+1), Γ^v_{vv} = 0.

**Step 4: Apply the geodesic equations with general (possibly non-affine) parame
ter.**

For a curve to be a geodesic as an *unparametrized* curve, there must exist a fu
nction f(t) such that:

u'' + Γ^u_{ij} (x^i)'(x^j)' = f(t) u',
v'' + Γ^v_{ij} (x^i)'(x^j)' = f(t) v'.

Substituting u = t, v = αt (so u' = 1, u'' = 0, v' = α, v'' = 0):

**Equation (1):** 0 + (−u)(v')² = f(t)·1 ⟹ −t·α² = f(t), so **f(t) = −α²t**.

**Equation (2):** 0 + 2·(u/(u²+1))·u'·v' = f(t)·v' ⟹ 2·(t/(t²+1))·α = f(t)·α.

**Step 5: Solve for α.**

*Case α ≠ 0:* From Equation (2), divide by α: f(t) = 2t/(t²+1). From Equation (1
): f(t) = −α²t. Equating:

2t/(t²+1) = −α²t for all t.

For t ≠ 0: 2/(t²+1) = −α². But the left side is strictly positive while −α² ≤ 0.
 **Contradiction.** So no α ≠ 0 works.

*Case α = 0:* Equation (1) gives f(t) = 0; Equation (2) gives 0 = 0. Both are co
nsistent. ✓

**Step 6: Verify α = 0 geometrically.**

When α = 0, γ(t) = (t, 0, 0) = X(t, 0), which is the ruling v = 0 — a straight l
ine contained in the surface. Straight lines on a surface are always geodesics (
zero normal curvature contribution from the line itself; γ'' = 0 so the geodesic
 equation is trivially satisfied with affine parameter). ✓

**Conclusion.**

The only value of α for which γ_α is a geodesic on the helicoid is:

$$\boxed{\alpha = 0}$$

The "range of values" is the singleton set {0}.
