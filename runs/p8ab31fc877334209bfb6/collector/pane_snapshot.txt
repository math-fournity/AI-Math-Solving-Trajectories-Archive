## Solution

**Key Lemma (Carry–digit-sum relation).** For any natural number $N$ with digits
 $d_0, d_1, \dots, d_{n-1}$ (position $0$ = units), let $C$ be the total number
of carries produced when computing $2N$ (counting each carry-out, including a fi
nal carry that becomes a new leading digit). Then

$$S(2N) = 2\,S(N) - 9\,C.$$

*Proof.* Writing $2d_i + c_i^{\text{in}} = e_i + 10\,c_i^{\text{out}}$ with $c_0
^{\text{in}}=0$ and $c_{i+1}^{\text{in}} = c_i^{\text{out}}$, summing the output
 digits $e_i$ plus the final carry $c_{n-1}^{\text{out}}$ gives $S(2N) = 2S(N) -
 9\sum_i c_i^{\text{out}} = 2S(N) - 9C$. $\square$

**Carry characterization.** A carry is produced at position $i$ iff $d_i \ge 5$,
 *independently* of the incoming carry:
- $c_i^{\text{in}} = 0$: carry out iff $2d_i \ge 10 \iff d_i \ge 5$.
- $c_i^{\text{in}} = 1$: carry out iff $2d_i + 1 \ge 10 \iff d_i \ge 5$ (since $
2\cdot 4 + 1 = 9 < 10$).

Hence $C = \#\{i : d_i \ge 5\}$, the count of digits of $N$ that are $\ge 5$.

**Applying the constraints.** With $S(N) = 2021$:

$$S(2N) = 2\cdot 2021 - 9C = 4042 - 9C \le 1202 \implies 9C \ge 2840 \implies C
\ge 316$$

(since $9\cdot 315 = 2835 < 2840 \le 2844 = 9\cdot 316$). So at least $316$ digi
ts of $N$ must be $\ge 5$.

**Maximizing the number of digits.** Let $n$ be the number of digits and $k = C
\ge 316$ the number of digits $\ge 5$. Since every digit is in $\{1,\dots,9\}$ (
no $0$), the minimum possible digit sum for $n$ digits with $k$ of them $\ge 5$
is

$$5k + 1\cdot(n - k) = n + 4k.$$

Requiring $n + 4k \le 2021$ and $k \ge 316$:

$$n \le 2021 - 4k \le 2021 - 4\cdot 316 = 2021 - 1264 = 757.$$

**Achievability.** Take $k = 316$ digits equal to $5$ and $n - k = 441$ digits e
qual to $1$. Then
- digit sum $= 316\cdot 5 + 441\cdot 1 = 1580 + 441 = 2021$ ✓
- no digit is $0$ ✓
- $C = 316$, so $S(2N) = 4042 - 9\cdot 316 = 4042 - 2844 = 1198 \le 1202$ ✓
- $n = 316 + 441 = 757$.

Any arrangement of these digits gives a valid $N$ (the value of $C$, hence $S(2N
)$, depends only on *which* digits are $\ge 5$, not on their positions). The num
erically largest such $N$ places the larger digits first, but in any case it has
 $757$ digits.

**Upper bound is tight.** For $n \ge 758$ we would need $n + 4k \ge 758 + 1264 =
 2022 > 2021$, impossible. So no valid $N$ has $758$ or more digits, while a val
id $N$ with $757$ digits exists.

The number of digits in the largest such $N$ is $\boxed{757}$.
