# Conformal Mappings Between Annuli

**Notation.** Let $A = A(r_1, r_2) = \{z : r_1 < |z| < r_2\}$ and $B = A(p_1, p_
2) = \{z : p_1 < |z| < p_2\}$, with $0 < r_1 < r_2$ and $0 < p_1 < p_2$. Define
the **modulus** $M(A) = \log(r_2/r_1)$ and $M(B) = \log(p_2/p_1)$.

**Theorem.** A conformal equivalence $f : A \to B$ exists if and only if
$$\frac{r_2}{r_1} = \frac{p_2}{p_1} \qquad (\text{equivalently } M(A) = M(B)).$$
When this holds, every conformal mapping $f : A \to B$ is of one of the two form

$$\boxed{f(z) = e^{i\theta}\,\frac{p_1}{r_1}\,z} \qquad\text{or}\qquad \boxed{f(
z) = e^{i\theta}\,\frac{p_1\,r_2}{z}}, \qquad \theta \in \mathbb{R}.$$
The first maps the inner boundary $\{|z|=r_1\}$ to $\{|w|=p_1\}$ (orientation-pr
eserving on the modulus); the second swaps inner and outer boundaries.

## Sufficiency

Assume $r_2/r_1 = p_2/p_1 =: R$. Both candidate maps are clearly holomorphic and
 injective on $A$.

- **Linear map** $f(z) = e^{i\theta}\frac{p_1}{r_1}z$: for $|z| \in (r_1, r_2)$,
$$|f(z)| = \tfrac{p_1}{r_1}|z| \in \bigl(\tfrac{p_1}{r_1}r_1,\; \tfrac{p_1}{r_1}
r_2\bigr) = (p_1,\; p_1 R) = (p_1, p_2).$$
So $f(A) \subseteq B$; the inverse $f^{-1}(w) = e^{-i\theta}\frac{r_1}{p_1}w$ gi
ves $f(B) = A$, hence $f$ is a biholomorphism $A \to B$.

- **Inversion map** $f(z) = e^{i\theta}\frac{p_1 r_2}{z}$: for $|z| \in (r_1, r_
2)$,
$$|f(z)| = \frac{p_1 r_2}{|z|} \in \Bigl(\frac{p_1 r_2}{r_2},\; \frac{p_1 r_2}{r
_1}\Bigr) = (p_1,\; p_1 R) = (p_1, p_2).$$
Again $f(A) = B$ with inverse $f^{-1}(w) = e^{-i\theta}\frac{p_1 r_2}{w}$, a bih
olomorphism.

Thus equal modulus is sufficient, and both families are valid.
