## Solution

We evaluate
$$I = \int_{0}^{\infty} \frac{\log x}{1+x^2}\,dx.$$

**Convergence.** Near $x=0^+$, $\log x \to -\infty$ but $\frac{|\log x|}{1+x^2}\
sim |\log x|$, and $\int_0^1 |\log x|\,dx = 1 < \infty$. Near $x\to\infty$, $\fr
ac{\log x}{1+x^2}\sim \frac{\log x}{x^2}$, and $\int_1^\infty \frac{\log x}{x^2}
\,dx = 1 < \infty$. So the integral converges absolutely.

**The substitution $x \mapsto 1/u$.** Set $x = 1/u$, so $dx = -du/u^2$. When $x:
0\to\infty$, $u:\infty\to 0$. Then
$$
I = \int_{\infty}^{0} \frac{\log(1/u)}{1+1/u^2}\cdot\left(-\frac{du}{u^2}\right)
  = \int_{0}^{\infty} \frac{-\log u}{\,\dfrac{u^2+1}{u^2}\,}\cdot\frac{du}{u^2}
  = \int_{0}^{\infty} \frac{-\log u}{u^2+1}\,du
  = -\int_{0}^{\infty}\frac{\log u}{1+u^2}\,du.
$$

Since $u$ is a dummy variable, the last integral is exactly $I$. Hence
$$I = -I \implies 2I = 0 \implies I = 0.$$

**Verification (sanity check via symmetry).** The substitution $x = \tan\theta$
gives $dx = \sec^2\theta\,d\theta$, $1+x^2 = \sec^2\theta$, and $\theta:0\to\pi/
2$:
$$I = \int_0^{\pi/2}\log(\tan\theta)\,d\theta = \int_0^{\pi/2}\log(\sin\theta)\,
d\theta - \int_0^{\pi/2}\log(\cos\theta)\,d\theta.$$
By the substitution $\theta\mapsto \pi/2-\theta$, $\int_0^{\pi/2}\log(\cos\theta
)\,d\theta = \int_0^{\pi/2}\log(\sin\theta)\,d\theta$, so the two terms cancel a
nd $I=0$. This confirms the result.

$$\boxed{\displaystyle\int_{0}^{\infty}\frac{\log x}{1+x^2}\,dx = 0.}$$
