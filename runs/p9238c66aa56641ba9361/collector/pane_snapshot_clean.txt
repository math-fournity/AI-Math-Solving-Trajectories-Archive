## Solution

We minimize $F(u)=\int_0^1 (1+x^2)\,u^2(x)\,dx$ subject to $\int_0^1 u(x)\,dx=1$
, over $u\in L^2(0,1)$.

**Key tool — Cauchy–Schwarz.** Write $w(x)=1+x^2>0$ on $[0,1]$. Using $\int u =
\int \big(\sqrt{w}\,u\big)\cdot\frac{1}{\sqrt{w}}$,

$$\left(\int_0^1 u(x)\,dx\right)^{\!2} = \left(\int_0^1 \sqrt{w}\,u \cdot \frac{
1}{\sqrt{w}}\,dx\right)^{\!2} \le \left(\int_0^1 w\,u^2\,dx\right)\!\left(\int_0
^1 \frac{1}{w}\,dx\right).$$

Since $\int_0^1 u = 1$,

$$1 \le F(u)\cdot \int_0^1 \frac{dx}{1+x^2}.$$

**Compute the constant.** $\displaystyle\int_0^1 \frac{dx}{1+x^2} = \arctan x\Bi
g|_0^1 = \arctan 1 - \arctan 0 = \frac{\pi}{4}-0 = \frac{\pi}{4}.$

Hence

$$F(u) \ge \frac{1}{\pi/4} = \frac{4}{\pi}.$$

**Equality is attained.** Equality in Cauchy–Schwarz holds iff $\sqrt{w}\,u$ is
proportional to $1/\sqrt{w}$, i.e. $u(x) = \frac{c}{w(x)} = \frac{c}{1+x^2}$ for
 some constant $c$. Imposing the constraint:

$$\int_0^1 \frac{c}{1+x^2}\,dx = c\cdot\frac{\pi}{4} = 1 \implies c = \frac{4}{\
pi}.$$

So $u_*(x) = \frac{4/\pi}{1+x^2}\in L^2(0,1)$ is admissible, and

$$F(u_*) = \int_0^1 (1+x^2)\cdot\frac{(4/\pi)^2}{(1+x^2)^2}\,dx = \frac{16}{\pi^
2}\int_0^1 \frac{dx}{1+x^2} = \frac{16}{\pi^2}\cdot\frac{\pi}{4} = \frac{4}{\pi}
.$$

This matches the lower bound, so the minimum is achieved.

$$\boxed{\min F(u) = \dfrac{4}{\pi}}$$
