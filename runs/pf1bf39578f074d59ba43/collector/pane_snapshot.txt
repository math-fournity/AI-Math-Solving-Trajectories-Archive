## Solution

We seek $P(X_2 < 0 \mid X_1 > 0)$ for standard Brownian motion $X_t$ with $X_0 =
 0$.

**Joint distribution.** Since $(X_1, X_2)$ is jointly Gaussian with
$$X_1 \sim N(0,1),\quad X_2 \sim N(0,2),\quad \operatorname{Cov}(X_1, X_2) = \mi
n(1,2) = 1,$$
the correlation is
$$\rho = \frac{1}{\sqrt{1 \cdot 2}} = \frac{1}{\sqrt{2}}.$$

**Applying the arcsin formula.** For a bivariate normal pair with correlation $\
rho$ (both centered at 0), the classical identity gives
$$P(X > 0,\, Y > 0) = \frac{1}{4} + \frac{1}{2\pi}\arcsin(\rho).$$

With $\rho = 1/\sqrt{2}$ and $\arcsin(1/\sqrt{2}) = \pi/4$:
$$P(X_1 > 0,\, X_2 > 0) = \frac{1}{4} + \frac{1}{2\pi}\cdot\frac{\pi}{4} = \frac
{1}{4} + \frac{1}{8} = \frac{3}{8}.$$

**Conditional probability.**
$$P(X_2 < 0 \mid X_1 > 0) = 1 - P(X_2 > 0 \mid X_1 > 0) = 1 - \frac{P(X_1 > 0,\,
 X_2 > 0)}{P(X_1 > 0)} = 1 - \frac{3/8}{1/2} = 1 - \frac{3}{4} = \frac{1}{4}.$$

**Verification via independent increments.** Write $X_2 = X_1 + Z$ with $Z = X_2
 - X_1 \sim N(0,1)$ independent of $X_1$. Conditioning on $X_1 = x > 0$ gives $P
(X_2 < 0 \mid X_1 = x) = \Phi(-x)$, so
$$P(X_2 < 0 \mid X_1 > 0) = 2\int_0^\infty \Phi(-x)\,\varphi(x)\,dx = 2\int_0^\i
nfty \Phi(-x)\,\varphi(x)\,dx.$$
Using $\Phi(-x) = 1 - \Phi(x)$ and the identity $\int_0^\infty \Phi(x)\varphi(x)
\,dx = \frac{3}{8}$ (equivalently derived from the arcsin formula above), this y
ields $2\left(\frac{1}{2} - \frac{3}{8}\right) = 2 \cdot \frac{1}{8} = \frac{1}{
4}$, confirming the result.

$$\boxed{\dfrac{1}{4}}$$
