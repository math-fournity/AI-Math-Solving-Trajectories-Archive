## Solution

**Setup and field assumptions.** Let $K$ be a field with $\operatorname{char} K
\neq 2,3$. Consider the smooth plane cubic
$$C:\; X^3 + Y^3 + Z^3 = 0 \;\subset\; \mathbb{P}^2_K.$$
(Smoothness: the partial derivatives $3X^2,3Y^2,3Z^2$ vanish simultaneously only
 at $(0:0:0)$, which is not a point of $\mathbb{P}^2$, provided $3\neq 0$ in $K$
.)

**Choosing the origin.** The points at infinity ($Z=0$) satisfy $X^3+Y^3=0$. The
 point
$$O = (1:-1:0)$$
is $K$-rational (since $1^3+(-1)^3 = 0$) and lies on $C$. We take $O$ as the neu
tral element of the group law; it is a flex of $C$.

**Affine chart and the key substitution.** Set $Z=1$, giving the affine model
$$x^3 + y^3 = -1.$$
Introduce the sum/difference coordinates
$$s = x+y, \qquad d = x-y \qquad (x=\tfrac{s+d}{2},\; y=\tfrac{s-d}{2}).$$
Then
$$x^3+y^3 = \frac{(s+d)^3+(s-d)^3}{8} = \frac{s^3+3sd^2}{4} = \frac{s(s^2+3d^2)}
{4},$$
so the equation $x^3+y^3=-1$ becomes
$$s\bigl(s^2+3d^2\bigr) = -4. \tag{$\ast$}$$

**The birational transformation.** Define
$$\boxed{\;X = -\frac{12}{s} = -\frac{12}{x+y}, \qquad Y = \frac{36\,d}{s} = \fr
ac{36(x-y)}{x+y}.\;}$$
(The denominators are nonzero away from the line $x+y=0$, which meets $C$ at inf
inity at $O$; this is exactly the point sent to the point at infinity of the Wei
erstrass model.) Inverting,
$$s = -\frac{12}{X}, \qquad d = -\frac{Y}{3X}, \qquad x = -\frac{Y+36}{6X}, \qqu
ad y = \frac{Y-36}{6X}.$$

**Deriving the Weierstrass equation.** Substitute $s=-12/X$ and $d=-Y/(3X)$ into
 $(\ast)$:
$$s^2+3d^2 = \frac{144}{X^2} + \frac{3Y^2}{9X^2} = \frac{144+Y^2/3}{X^2},$$
$$s(s^2+3d^2) = \frac{-12}{X}\cdot\frac{144+Y^2/3}{X^2} = \frac{-1728-4Y^2}{X^3}
.$$
Setting this equal to $-4$ gives
$$-1728 - 4Y^2 = -4X^3 \;\;\Longrightarrow\;\; 4Y^2 = 4X^3 - 1728 \;\;\Longright
arrow\;\; \boxed{\,Y^2 = X^3 - 432.\,}$$

**Verification of the inverse.** From the inverse formulas,
$$x^3+y^3 = \frac{(Y-36)^3-(Y+36)^3}{(6X)^3}.$$
Using $A^3-B^3=(A-B)(A^2+AB+B^2)$ with $A=Y-36,\;B=Y+36$:
$$(Y-36)^3-(Y+36)^3 = (-72)\bigl(3Y^2+1296\bigr) = -216\,(Y^2+432).$$
Since $(6X)^3 = 216X^3$,
$$x^3+y^3 = -\frac{Y^2+432}{X^3}.$$
On the Weierstrass curve $Y^2 = X^3-432$ we have $Y^2+432 = X^3$, hence $x^3+y^3
 = -X^3/X^3 = -1$, confirming the inverse map lands back on $C$. The two rationa
l maps are mutual inverses, so they define a birational equivalence. Since both
curves are smooth, this birational equivalence is in fact an isomorphism.

**Consistency check via the $j$-invariant.** The model $Y^2 = X^3 - 432$ has Wei
erstrass coefficients $a=0,\; b=-432$, so
$$j = \frac{-1728\,(4a^3)}{4a^3+27b^2} = 0,$$
which matches the well-known $j$-invariant $0$ of the Fermat cubic (it carries a
n automorphism of order $3$ from cyclic permutation of $X,Y,Z$). This confirms t

$$\boxed{\,Y^2 \;=\; X^3 \;-\; 432\,}.$$
