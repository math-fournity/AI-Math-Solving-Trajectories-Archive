## Proof

**Step 1: Factor the expression.**

Expanding:
$$ab(a^2-b^2)+bc(b^2-c^2)+ca(c^2-a^2) = a^3b - ab^3 + b^3c - bc^3 + c^3a - ca^3.
$$
Grouping terms:
$$= a^3(b-c) + b^3(c-a) + c^3(a-b).$$

We use the well-known identity (verified by expansion):
$$a^3(b-c)+b^3(c-a)+c^3(a-b) = -(a-b)(b-c)(c-a)(a+b+c).$$

Therefore:
$$\left|ab(a^2-b^2)+bc(b^2-c^2)+ca(c^2-a^2)\right| = |(a-b)(b-c)(c-a)(a+b+c)|.$$

**Step 2: Reduce by homogeneity.**

Both sides are homogeneous of degree 4, so we may normalize $a^2+b^2+c^2 = 1$. W
e seek:
$$M = \max_{a^2+b^2+c^2=1} |(a-b)(b-c)(c-a)(a+b+c)|.$$

**Step 3: Express in terms of elementary symmetric polynomials.**

Set $p = a+b+c$, $q = ab+bc+ca$, $r = abc$. Then $a^2+b^2+c^2 = p^2 - 2q = 1$, s
o $q = \frac{p^2-1}{2}$.

The discriminant of the cubic with roots $a,b,c$ is:
$$\Delta = (a-b)^2(b-c)^2(c-a)^2 = p^2q^2 - 4q^3 - 4p^3r - 27r^2 + 18pqr.$$

Our objective is $p^2 \Delta$ (since $|(a-b)(b-c)(c-a)\cdot p|^2 = p^2\Delta$),
and we want $M = \sqrt{\max\, p^2\Delta}$.

**Step 4: Maximize $\Delta$ over $r$ for fixed $p$.**

For fixed $p$ (hence fixed $q$), $\Delta$ is a concave quadratic in $r$ (coeffic
ient of $r^2$ is $-27<0$). Setting $\partial\Delta/\partial r = 0$:
$$-54r - 4p^3 + 18pq = 0 \implies r = \frac{-4p^3+18pq}{54} = \frac{5p^3-9p}{27}
\cdot\frac{1}{2} = \frac{5p^3-9p}{54}.$$

(Here $B = -4p^3+18pq = -4p^3+9p(p^2-1) = 5p^3-9p$.)

The maximum value is $\Delta_{\max} = C + B^2/108$ where $C = q^2(p^2-4q) = q^2(
2-p^2)$:
$$\Delta_{\max} = \frac{(p^2-1)^2(2-p^2)}{4} + \frac{p^2(5p^2-9)^2}{108}.$$

**Step 5: Maximize $p^2\Delta_{\max}$ over $p$.**

Set $u = p^2$. Then:
$$f(u) = u\,\Delta_{\max} = \frac{u(u-1)^2(2-u)}{4} + \frac{u^2(5u-9)^2}{108}.$$

Bringing to common denominator 108:
$$f(u) = \frac{27u(-u^3+4u^2-5u+2) + u^2(25u^2-90u+81)}{108} = \frac{-2u^4+18u^3
-54u^2+54u}{108}.$$

$$f(u) = \frac{-u^4+9u^3-27u^2+27u}{54} = \frac{u\left(-u^3+9u^2-27u+27\right)}{
54} = \frac{u(3-u)^3}{54},$$

using the factorization $-u^3+9u^2-27u+27 = -(u-3)^3 = (3-u)^3$.

**Step 6: Optimize $g(u) = u(3-u)^3$ on $[0,3]$.**

$$g'(u) = (3-u)^2(3-u) - 3u(3-u)^2 = (3-u)^2(3-4u).$$

Setting $g'(u)=0$: $u=3$ (boundary, $g=0$) or $u=\frac{3}{4}$.

$$g\!\left(\tfrac{3}{4}\right) = \tfrac{3}{4}\left(\tfrac{9}{4}\right)^3 = \tfra
c{3}{4}\cdot\tfrac{729}{64} = \tfrac{2187}{256}.$$

Therefore:
$$\max\, p^2\Delta = f\!\left(\tfrac{3}{4}\right) = \frac{2187}{256\cdot 54} = \
frac{2187}{13824} = \frac{81}{512}.$$

**Step 7: Verify the maximum is attained.**

At $u = p^2 = 3/4$, we have $p = \frac{\sqrt{3}}{2}$, $q = -\frac{1}{8}$, $r = \
frac{5p^3-9p}{54} = \frac{-7\sqrt{3}}{144}$. The discriminant is $\Delta_{\max}
= \frac{f(3/4)}{3/4} = \frac{81/512}{3/4} = \frac{27}{128} > 0$, so the cubic $t
^3 - pt^2 + qt - r = 0$ has three distinct real roots $a,b,c$ satisfying $a^2+b^
2+c^2=1$. The maximum is achieved.

**Step 8: Conclusion.**

$$M = \sqrt{\frac{81}{512}} = \frac{9}{\sqrt{512}} = \frac{9}{16\sqrt{2}} = \fra
c{9\sqrt{2}}{32}.$$

The least real number $M$ is:

$$\boxed{\dfrac{9\sqrt{2}}{32}}.$$

### PROOF COMPLETE
