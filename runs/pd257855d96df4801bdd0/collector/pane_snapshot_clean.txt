## Solution

**Setting up the functional equation.** Let $y=x$:
$$f(x)^2 = f(x^2) + f(1).$$
Let $x=y=1$: $f(1)^2 = 2f(1)$, so $f(1)=2$ (since $f>0$). Hence
$$f(x^2) = f(x)^2 - 2. \tag{$\star$}$$

**Identifying the form.** The ansatz $f(x) = x^a + x^{-a}$ satisfies $f(x)f(y) =
 f(xy)+f(x/y)$. From $f(2)=3$:
$$2^a + 2^{-a} = 3 \implies t + t^{-1} = 3, \quad t = 2^a = \tfrac{3+\sqrt5}{2}.
$$

**Reducing to a linear recurrence.** Define $S_n = t^n + t^{-n}$. Then $S_0=2,\;
 S_1=3$, and using $t+t^{-1}=3$:
$$S_n = 3\,S_{n-1} - S_{n-2}.$$
Our target is $f\!\left(2^{2^{2020}}\right) = t^{2^{2020}} + t^{-2^{2020}} = S_{
2^{2020}}$, so we need $S_{2^{2020}} \bmod 100$.

**Computing mod 4.** $S_0=2,\,S_1=3,\,S_2=3\cdot3-2=7\equiv3,\,S_3=3\cdot3-3=6\e
quiv2,\,S_4\equiv3,\dots$ giving the period-3 cycle $(2,3,3)$. Since $2^{2020}\e
quiv (-1)^{2020}\equiv 1\pmod 3$, we get
$$S_{2^{2020}} \equiv 3 \pmod 4.$$

**Computing mod 25.** Iterating $S_n = 3S_{n-1}-S_{n-2}\pmod{25}$:
$$2,\;3,\;7,\;18,\;22,\;23,\;22,\;18,\;7,\;3,\;\underbrace{2}_{S_{10}},\;3,\dots
$$
The sequence has period $10$ (since $S_{10}=2=S_0,\;S_{11}=3=S_1$). Now $2^{2020
}\bmod 10$: the cycle of $2^n\bmod 10$ (for $n\ge1$) is $2,4,8,6$ with period $4
$, and $2020=4\cdot505$, so $2^{2020}\equiv 6\pmod{10}$. Therefore
$$S_{2^{2020}} \equiv S_6 \equiv 22 \pmod{25}.$$

**Chinese Remainder Theorem.** Solve
$$x\equiv 22\pmod{25},\qquad x\equiv 3\pmod 4.$$
Since $22\equiv 2\pmod 4$, set $x=22+25k$: $2+k\equiv 3\pmod 4\Rightarrow k\equi
v1\pmod4$. Taking $k=1$:
$$x = 22 + 25 = 47.$$
Check: $47\bmod 4 = 3$ ✓, $47\bmod 25 = 22$ ✓.

**Answer.** The last two digits of $f\!\left(2^{2^{2020}}\right)$ are $\boxed{47
}$.
