\{X_t\}_{t \in [0,1]}$ can be constructed so that almost every sample path $t \m
apsto X_t(\omega)$ is **not** Borel-measurable.

**Answer: Yes.**

## Proof

**Construction.** Let $\Omega = \mathbb{R}^{[0,1]}$, $\mathcal{F} = \bigotimes_{
t \in [0,1]} \mathcal{B}(\mathbb{R})$ the product $\sigma$-algebra, and $P = \ga
mma^{\otimes [0,1]}$ the product of standard Gaussian measures (existing by Kolm
ogorov's extension theorem). Set $X_t(\omega) = \omega(t)$; these are i.i.d. $N(
0,1)$ under $P$.

Define $M = \{\omega \in \Omega : t \mapsto \omega(t) \text{ is Borel-measurable
}\}$.

**Step 1: Every $\mathcal{F}$-measurable subset of $M$ is null.**

We use the standard fact that every $A \in \mathcal{F}$ depends on only countabl
y many coordinates: there exists countable $S \subset [0,1]$ such that $\omega|_
S = \omega'|_S$ implies $\omega \in A \iff \omega' \in A$. (The collection of su
ch sets forms a $\sigma$-algebra containing all cylinder sets, hence contains $\
mathcal{F}$.)

Let $B \in \mathcal{F}$ with $B \subset M$, depending on countable $S \subset [0
,1]$. Suppose $B \neq \emptyset$ and pick $\omega_0 \in B$. Then $\omega_0 \in M
$, so $\omega_0$ is a Borel-measurable function.

Since $[0,1] \setminus S$ is uncountable, choose a non-Borel set $V \subset [0,1
] \setminus S$. Define:
$$\omega_1(t) = \begin{cases} \omega_0(t) & t \in S, \\ \mathbf{1}_V(t) & t \in
[0,1]\setminus S. \end{cases}$$

Since $\omega_1|_S = \omega_0|_S$ and $B$ depends only on $S$, we have $\omega_1
 \in B \subset M$. But $t \mapsto \omega_1(t)$ is **not** Borel-measurable: if i
t were, $\omega_1^{-1}(\{1\})$ would be Borel. Now $\omega_1^{-1}(\{1\}) = \unde
rbrace{(\omega_0^{-1}(\{1\}) \cap S)}_{\text{countable, hence Borel}} \cup V$, s
o $V$ would be Borel—a contradiction.

Thus $\omega_1 \notin M$, contradicting $\omega_1 \in B \subset M$. Therefore $B
 = \emptyset$, proving:
$$P_*(M) := \sup\{P(B) : B \in \mathcal{F},\; B \subset M\} = 0.$$

**Step 2: Extend the measure with $P'(M) = 0$.**

Let $\mathcal{G} = \sigma(\mathcal{F} \cup \{M\})$. Every $A \in \mathcal{G}$ ha
s the form $A = (B_1 \cap M) \cup (B_2 \cap M^c)$ for $B_1, B_2 \in \mathcal{F}$
. Define $P'(A) = P(B_2)$.

*Well-defined:* If $(B_1 \cap M) \cup (B_2 \cap M^c) = (B_1' \cap M) \cup (B_2'
\cap M^c)$, then $B_2 \cap M^c = B_2' \cap M^c$, so $(B_2 \triangle B_2') \subse
t M$. Since $B_2 \triangle B_2' \in \mathcal{F}$ and $B_2 \triangle B_2' \subset
 M$, Step 1 gives $P(B_2 \triangle B_2') = 0$, hence $P(B_2) = P(B_2')$.

*Countable additivity:* If $A_n = (B_{n,1} \cap M) \cup (B_{n,2} \cap M^c)$ are
pairwise disjoint, then for $n \neq m$, $(B_{n,2} \cap B_{m,2}) \cap M^c = \empt
yset$, so $B_{n,2} \cap B_{m,2} \subset M$. By Step 1, $P(B_{n,2} \cap B_{m,2})
= 0$, so the $B_{n,2}$ are pairwise disjoint mod $P$. Thus:
$$P'\!\left(\bigcup_n A_n\right) = P\!\left(\bigcup_n B_{n,2}\right) = \sum_n P(
B_{n,2}) = \sum_n P'(A_n).$$

*Extends $P$:* For $B \in \mathcal{F}$, $B = (B \cap M) \cup (B \cap M^c)$, so $
P'(B) = P(B)$. ✓

*$P'(M) = 0$:* $M = (\Omega \cap M) \cup (\emptyset \cap M^c)$, so $P'(M) = P(\e
mptyset) = 0$. ✓

**Step 3: Verification.**

In $(\Omega, \mathcal{G}, P')$:

- Each $X_t(\omega) = \omega(t)$ is $\mathcal{F}$-measurable, hence $\mathcal{G}
$-measurable.
- For any finite $\{t_1, \dots, t_n\}$, the joint law of $(X_{t_1}, \dots, X_{t_
n})$ under $P'$ equals that under $P$ (since $P'|_\mathcal{F} = P$), which is $\
gamma^{\otimes n}$. So the $\{X_t\}$ are i.i.d. standard Gaussian.
- $M^c = \{\omega : t \mapsto X_t(\omega) \text{ is not Borel-measurable}\} \in
\mathcal{G}$ and $P'(M^c) = 1$.

**Conclusion.** The probability space $(\Omega, \mathcal{G}, P')$ supports i.i.d
. standard Gaussians $\{X_t\}_{t \in [0,1]}$ such that $P'(\{\omega : t \mapsto
X_t(\omega) \text{ is not Borel-measurable}\}) = 1$.

The key insight is that the product $\sigma$-algebra is too coarse to detect pat
h measurability: any measurable set contained in the collection of measurable pa
ths must be null, because it can depend on only countably many coordinates, and
one can always destroy measurability by modifying the path outside those coordin
ates. This forces the inner measure of the measurable-path set to be zero, allow
ing a measure extension that assigns it probability zero. $\blacksquare$
