证明

设定

设 $x_1, x_2, \ldots, x_n$ 是 Collatz 映射的一个非平凡循环中的奇数项，且每一项
$x_i > 1$（因此 $x_i \geq 3$，因为它们是奇数）。循环关系为：

$$x_{i+1} = \frac{3x_i + 1}{2^{a_i}}, \quad a_i = \nu_2(3x_i + 1), \quad x_{n+1}
= x_1$$

且 $m = \sum_{i=1}^n a_i$。我们要证明 $m < 2n$。

证明

第一步：连乘积的伸缩性。

由于这是一个循环，$x_{n+1} = x_1$，因此：

$$\prod_{i=1}^n \frac{x_{i+1}}{x_i} = \frac{x_2}{x_1} \cdot \frac{x_3}{x_2}
\cdots \frac{x_{n+1}}{x_n} = \frac{x_{n+1}}{x_1} = 1$$

第二步：用 $a_i$ 表示每个比值。

$$\frac{x_{i+1}}{x_i} = \frac{3x_i + 1}{x_i \cdot 2^{a_i}} = \frac{3 + \frac{1}
{x_i}}{2^{a_i}}$$

第三步：利用 $x_i \geq 3$ 进行放缩。

由于每个 $x_i$ 都是大于 1 的奇数，所以 $x_i \geq 3$，因此 $\frac{1}{x_i} \leq
\frac{1}{3}$，从而：

$$3 + \frac{1}{x_i} \leq 3 + \frac{1}{3} = \frac{10}{3}$$

这给出了：

$$\frac{x_{i+1}}{x_i} \leq \frac{10/3}{2^{a_i}}$$

第四步：对连乘积进行放缩。

$$1 = \prod_{i=1}^n \frac{x_{i+1}}{x_i} \leq \prod_{i=1}^n \frac{10/3}{2^{a_i}}
= \frac{(10/3)^n}{2^{a_1 + a_2 + \cdots + a_n}} = \frac{(10/3)^n}{2^m}$$

因此：

$$2^m \leq \left(\frac{10}{3}\right)^n$$

第五步：与 $2n$ 进行比较。

由于 $\frac{10}{3} < 4 = 2^2$，我们得到：

$$2^m \leq \left(\frac{10}{3}\right)^n < 4^n = 2^{2n}$$

因此 $2^m < 2^{2n}$，由此可得：

$$\boxed{m < 2n}$$

注：非平凡性条件的必要性

平凡循环 ${1}$（其中 $n=1$, $x_1=1$, $a_1 = \nu_2(4) = 2$, $m=2$）满足 $m =
2n$，这与结论不符。放缩的关键步骤 $3 + 1/x_i \leq 10/3$ 依赖于 $x_i \geq 3$；当
$x_i = 1$ 时，$3 + 1/1 = 4 > 10/3$，放缩失效。这证实了假设“每一项都大于 1”是必要
的。
