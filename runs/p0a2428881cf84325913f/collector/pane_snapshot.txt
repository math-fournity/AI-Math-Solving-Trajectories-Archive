## Proof

**Setup.** Using the identity $\cot z = i\,\dfrac{e^{2iz}+1}{e^{2iz}-1}$, with $
z = t - ia$ we get $2iz = 2it + 2a$, so

$$\cot(t - ia) = i\,\frac{e^{2a}\,e^{2it}+1}{e^{2a}\,e^{2it}-1}.$$

**Substitution.** Set $w = e^{it}$, so $dw = i\,e^{it}\,dt = iw\,dt$, giving $dt
 = \frac{dw}{iw}$. As $t$ ranges over $[0, 2\pi]$, $w$ traverses the unit circle
 $|w|=1$ once counterclockwise. Since $e^{2it} = w^2$:

$$\int_0^{2\pi} \cot(t-ia)\,dt = \oint_{|w|=1} i\,\frac{e^{2a}w^2+1}{e^{2a}w^2-1
}\cdot\frac{dw}{iw} = \oint_{|w|=1} \frac{e^{2a}w^2+1}{w\,(e^{2a}w^2-1)}\,dw.$$

**Identifying poles.** The integrand $f(w) = \dfrac{e^{2a}w^2+1}{w\,(e^{2a}w^2-1
)}$ has singularities where:
- $w = 0$ (simple pole), and
- $e^{2a}w^2 - 1 = 0 \implies w = \pm\, e^{-a}$ (simple poles).

Since $a > 0$, we have $e^{-a} < 1$, so all three poles $w = 0,\; e^{-a},\; -e^{
-a}$ lie inside $|w| = 1$.

**Computing residues.**

*Residue at $w = 0$:*
$$\operatorname{Res}_{w=0} f = \lim_{w\to 0}\, w\cdot\frac{e^{2a}w^2+1}{w\,(e^{2
a}w^2-1)} = \frac{0+1}{0-1} = -1.$$

*Residue at $w = e^{-a}$:* Factor $e^{2a}w^2 - 1 = e^{2a}(w - e^{-a})(w + e^{-a}
)$:
$$\operatorname{Res}_{w=e^{-a}} f = \lim_{w\to e^{-a}} \frac{e^{2a}w^2+1}{w\cdot
 e^{2a}(w+e^{-a})} = \frac{e^{2a}\,e^{-2a}+1}{e^{-a}\cdot e^{2a}\,(e^{-a}+e^{-a}
)} = \frac{1+1}{e^{a}\cdot 2\,e^{-a}} = \frac{2}{2} = 1.$$

*Residue at $w = -e^{-a}$:*
$$\operatorname{Res}_{w=-e^{-a}} f = \lim_{w\to -e^{-a}} \frac{e^{2a}w^2+1}{w\cd
ot e^{2a}(w - e^{-a})} = \frac{1+1}{(-e^{-a})\cdot e^{2a}\,(-e^{-a}-e^{-a})} = \
frac{2}{(-e^{a})(-2\,e^{-a})} = \frac{2}{2} = 1.$$

**Applying the residue theorem.**

$$\int_0^{2\pi} \cot(t-ia)\,dt = 2\pi i\left[\operatorname{Res}_{0} + \operatorn
ame{Res}_{e^{-a}} + \operatorname{Res}_{-e^{-a}}\right] = 2\pi i\,[-1 + 1 + 1] =
 2\pi i.$$

**Consistency check.** As $a \to \infty$, $\cot(t - ia) = i\,\frac{e^{2a}e^{2it}
+1}{e^{2a}e^{2it}-1} \to i$ uniformly on $[0,2\pi]$ (since $|e^{2it}|=1 \neq 0$)
, so $\int_0^{2\pi} \cot(t-ia)\,dt \to \int_0^{2\pi} i\,dt = 2\pi i$, confirming
 our result.

---

$$\boxed{\int_0^{2\pi}\cot(t-ia)\,dt = 2\pi i, \quad a > 0.}$$
