## Proof

**Setup.** Let $I = \{h \in \mathbb{Z}[x] : p^2 \mid h(n) \text{ for all } n \in
 \mathbb{Z}\}$. The desired maximum equals $|\mathbb{Z}[x]/I|$, the number of co
sets of $I$.

**Key observation.** For $h \in \mathbb{Z}[x]$, the value $h(n) \bmod p^2$ depen
ds only on $n \bmod p^2$ (since $n \equiv m \pmod{p^2} \Rightarrow n^k \equiv m^
k \pmod{p^2}$). So $I = \ker \phi$ where $\phi: \mathbb{Z}[x] \to (\mathbb{Z}/p^
2\mathbb{Z})^{p^2}$ evaluates at $n = 0, 1, \ldots, p^2-1$. Thus $|\mathbb{Z}[x]
/I| = |\operatorname{im} \phi|$.

**Step 1: Image mod $p$.** Reducing $\phi$ mod $p$ gives $\bar\phi: \mathbb{F}_p
[x] \to \mathbb{F}_p^{p^2}$. Since $f(n+p) \equiv f(n) \pmod{p}$ for $f \in \mat
hbb{F}_p[x]$, the image is $\{(a_0, \ldots, a_{p-1}, a_0, \ldots) : a_i \in \mat
hbb{F}_p\} \cong \mathbb{F}_p^p$, with size $p^p$.

**Step 2: The kernel of reduction.** The kernel of $\operatorname{im}\phi \to \o
peratorname{im}\bar\phi$ consists of elements $p(b_0, \ldots, b_{p^2-1})$ with $
b_n \in \mathbb{F}_p$ achievable. An element $h$ with $h(n) \equiv 0 \pmod{p}$ f
or all $n$ lies in the ideal $(p,\, x^p - x)$ (since $h \bmod p$ vanishes at all
 of $\mathbb{F}_p$ iff divisible by $x^p - x$). So write $h = pg + (x^p - x)q$ w
ith $g, q \in \mathbb{Z}[x]$. Then:
$$b_n = \frac{h(n)}{p} \equiv g(n) + \alpha(n)\, q(n) \pmod{p}, \quad \alpha(n)
:= \frac{n^p - n}{p}.$$

**Step 3: Computing $\alpha$ mod $p$.** For $n = r + kp$ with $0 \le r < p$, $0
\le k < p$, the binomial theorem gives $(r+kp)^p \equiv r^p \pmod{p^2}$ (all cro
ss terms contain $p^2$). Therefore:
$$\alpha(r+kp) = \frac{(r+kp)^p - (r+kp)}{p} \equiv \frac{r^p - r}{p} - k = \alp
ha(r) - k \pmod{p}.$$

**Step 4: Counting kernel elements.** Set $a_r = g(r) \bmod p$ and $c_r = q(r) \
bmod p$. By Lagrange interpolation over $\mathbb{F}_p$, the values $(a_0, \ldots
, a_{p-1})$ and $(c_0, \ldots, c_{p-1})$ are freely chosen in $\mathbb{F}_p^p \t
imes \mathbb{F}_p^p$. For each $r$, the tuple of $p$ values at $n = r, r+p, \ldo
ts, r+(p-1)p$ is:
$$\bigl(a_r + (\alpha(r) - k)\, c_r\bigr)_{k=0}^{p-1} \in \mathbb{F}_p^p.$$

The map $(a_r, c_r) \mapsto \bigl(a_r + (\alpha(r)-k)\,c_r\bigr)_{k=0}^{p-1}$ is
 **injective**: if two pairs $(a_r, c_r)$, $(a_r', c_r')$ yield the same tuple,
subtracting the $k=0$ and $k=1$ components gives $c_r = c_r'$, then $a_r = a_r'$
. So each $r$ contributes exactly $p^2$ distinct tuples, and the $p$ values of $
r$ are independent. Hence:
$$|\ker| = (p^2)^p = p^{2p}.$$

**Step 5: Conclusion.** Since $\operatorname{im}\phi$ is an additive group and t
he reduction $\operatorname{im}\phi \to \operatorname{im}\bar\phi$ is a surjecti
ve homomorphism with kernel of size $p^{2p}$:
$$|\mathbb{Z}[x]/I| = |\operatorname{im}\phi| = |\operatorname{im}\bar\phi| \cdo
t |\ker| = p^p \cdot p^{2p} = p^{3p}.$$

**Verification for $p=2$:** Image mod 2 has size $2^2 = 4$. Kernel: $\alpha(0)=0
, \alpha(2)=1$; for $r=0$, tuples $(a_0, a_0+c_0)$ give $4$ options; for $r=1$,
similarly $4$. So $|\ker| = 16 = 2^4$ and $|\operatorname{im}\phi| = 64 = 2^6 =
2^{3\cdot 2}$. ✓

**Verification for $p=3$:** Image mod 3 has size $3^3 = 27$. Each $r$ gives $9$
tuples, so $|\ker| = 9^3 = 729 = 3^6$ and $|\operatorname{im}\phi| = 27 \cdot 72
9 = 19683 = 3^9 = 3^{3\cdot 3}$. ✓

The largest number of such polynomials is $\boxed{p^{3p}}$.
