## Solution

**Setup:** We have a cyclic quadrilateral $ABCD$ (inscribed in a circle) with si
des:
- $AB = 3$, $BC = 5$, $CD = 8$, $DA = 5$.

**Area via Brahmagupta's formula.** The semiperimeter is
$$s = \frac{3+5+8+5}{2} = \frac{21}{2}.$$

The area $K$ of a cyclic quadrilateral is
$$K = \sqrt{(s-a)(s-b)(s-c)(s-d)} = \sqrt{\tfrac{15}{2}\cdot\tfrac{11}{2}\cdot\t
frac{5}{2}\cdot\tfrac{11}{2}} = \frac{1}{4}\sqrt{15\cdot 121\cdot 5} = \frac{1}{
4}\sqrt{9075}.$$

Since $9075 = 25\cdot 363 = 25\cdot 3\cdot 121 = (55)^2\cdot 3$,
$$K = \frac{55\sqrt{3}}{4}.$$

**Circumradius formula.** For a cyclic quadrilateral with sides $a,b,c,d$ and ar
ea $K$,
$$R = \frac{1}{4K}\sqrt{(ab+cd)(ac+bd)(ad+bc)}.$$

Computing each factor:
- $ab+cd = 3\cdot 5 + 8\cdot 5 = 15+40 = 55$
- $ac+bd = 3\cdot 8 + 5\cdot 5 = 24+25 = 49$
- $ad+bc = 3\cdot 5 + 5\cdot 8 = 15+40 = 55$

Thus
$$R = \frac{1}{4\cdot \frac{55\sqrt{3}}{4}}\sqrt{55\cdot 49\cdot 55} = \frac{1}{
55\sqrt{3}}\cdot 55\cdot 7 = \frac{7}{\sqrt{3}} = \frac{7\sqrt{3}}{3}.$$

**Identifying $a, b, c$.** We have $R = \dfrac{a\sqrt{b}}{c} = \dfrac{7\sqrt{3}}
{3}$, so $a=7$, $b=3$, $c=3$. We verify: $\gcd(a,c)=\gcd(7,3)=1$ ✓, and $b=3$ is
 square-free ✓.

**Final answer:**
$$a+b+c = 7+3+3 = \boxed{13}.$$
