## Solution

**Setup.** Let the 2019 file sizes be distinct positive integers $a_1, \dots, a_
{2019}$. The condition states: for every subset $T$ of size 100, $\prod_{i \in T
} a_i \mid \prod_{j \notin T} a_j$.

**Prime-wise reduction.** For each prime $p$, let $v_i = v_p(a_i)$. The divisibi
lity condition for every 100-subset $T$ is equivalent to: for every prime $p$,
$$\sum_{i \in T} v_i \le \sum_{j \notin T} v_j \quad \text{for all } T, |T|=100.
$$
Setting $V = \sum_{i=1}^{2019} v_i$, this becomes $\sum_{i\in T} v_i \le V/2$ fo
r all 100-subsets $T$. The binding constraint is the **worst-case** $T$ (the 100
 largest valuations), so the condition is:

$$\text{(sum of 100 largest } v_p\text{-valuations)} \le \frac{V_p}{2}. \quad (\
star)$$

**Key lemma.** If a prime $p$ appears with valuation 1 in exactly $n_p$ files (a
nd 0 elsewhere), then $(\star)$ requires:
- If $n_p \le 100$: $\min(n_p,100) = n_p \le n_p/2$, impossible for $n_p \ge 1$.
- If $n_p > 100$: $100 \le n_p/2$, so $n_p \ge 200$.

**Upper bound: $k \le 1819$.** Suppose $k$ files have prime sizes $q_1, \dots, q
_k$ (distinct primes). For each $q_i$, the prime file contributes $v_{q_i}=1$, a
nd the other $k-1$ prime files contribute $0$. So $q_i$ must appear in enough of
 the $2019-k$ composite files.

For $k = 1820$: there are $199$ composite files. For any prime $q_i$, the 2019 v
aluations consist of 1819 zeros (other prime files) and 200 values from $\{1\} \
cup \{v_{q_i}(\text{composite}_j)\}$.

**Claim:** all 200 of these values must be positive. If only $t < 200$ are posit

tive values), while $V = $ (same sum), requiring sum $\le$ sum/2 — impossible. I
f $t = 200$, the top 100 are the 100 largest and the bottom 100 are the 100 smal
lest among 200 positive values. Condition $(\star)$ forces:

$$\text{(100 largest)} \le \text{(100 smallest)}.$$

Since the 100 largest $\ge$ the 100 smallest, equality holds, so **all 200 value
s are equal**. Since one value is 1 (the prime file), all are 1. This must hold
for **every** prime $q_i$, so every composite file has $v_{q_i} = 1$ for all $i
= 1,\dots,1820$. All 199 composite files equal $\prod_{i=1}^{1820} q_i$ — **not
distinct**. Contradiction.

Moreover, no new prime $r$ can be introduced: it would appear in at most 199 com
posite files ($< 200$), violating the lemma. So $k = 1820$ is impossible.

This ensures:
