## Proof

**Setup.** Place the circumcircle $(O)$ as the unit circle in the complex plane,
 with $A = a$, $B = b$, $C = c$ where $|a| = |b| = |c| = 1$.

**The point T.** The tangent to the unit circle at point $p$ has equation $z\bar
{p} + \bar{z}p = 2$. Solving the tangents at $B$ and $C$ simultaneously yields:
$$T = \frac{2bc}{b+c}, \qquad \bar{T} = \frac{2}{b+c}.$$

**Parametrizing δ.** Since $M \in AB$ and $N \in AC$, write $M = (1-s)a + sb$ an
d $N = (1-u)a + uc$ for real parameters $s, u$ (with $s, u \neq 0$ to avoid $M=A
$ or $N=A$, and the line $\delta = MN$ distinct from $BC$).

**Circle (ABN).** A circle through $a, b$ satisfies $\bar{\alpha} = \alpha ab$ a
nd $d = -1 - \alpha(a+b)$. Imposing passage through $N = (1-u)a + uc$ and comput
ing (using $|N|^2 - 1 = u(1-u)\frac{(a-c)^2}{ac}$ and the factorization $c - a -
 b + ab/c = \frac{(c-a)(c-b)}{c}$), we obtain:
$$\alpha_1 = \frac{(1-u)(a-c)}{a(c-b)}, \qquad \bar{\alpha}_1 = \alpha_1 ab, \qq
uad d_1 = -1 - \alpha_1(a+b).$$

**Circle (ACM).** By the identical computation with $b \leftrightarrow c$ and $u
 \leftrightarrow s$ (circle through $a, c$ and $M = (1-s)a + sb$):
$$\alpha_2 = \frac{(1-s)(a-b)}{a(b-c)}, \qquad \bar{\alpha}_2 = \alpha_2 ac, \qq
uad d_2 = -1 - \alpha_2(a+c).$$

**The radical axis (line AJ).** Both circles pass through $A$, so their radical
axis is the line through $A$ and $J$:
$$(\alpha_1 - \alpha_2)z + (\bar{\alpha}_1 - \bar{\alpha}_2)\bar{z} + (d_1 - d_2
) = 0.$$

**Collinearity condition.** The point $T$ lies on line $AJ$ if and only if $T$ s
atisfies the radical axis equation:
$$(\alpha_1 - \alpha_2)T + (\alpha_1 ab - \alpha_2 ac)\bar{T} - \alpha_1(a+b) +
\alpha_2(a+c) = 0.$$

Substituting $T = \frac{2bc}{b+c}$ and $\bar{T} = \frac{2}{b+c}$, and multiplyin
g through by $(b+c)$:
$$2bc(\alpha_1 - \alpha_2) + 2(\alpha_1 ab - \alpha_2 ac) - (b+c)\bigl(\alpha_1(
a+b) - \alpha_2(a+c)\bigr) = 0.$$

**Collecting coefficients.** The coefficient of $\alpha_1$ is:
$$2bc + 2ab - (b+c)(a+b) = 2bc + 2ab - ab - b^2 - ac - bc = ab + bc - ac - b^2 =
 (a-b)(b-c).$$

The coefficient of $\alpha_2$ is:
$$-2bc - 2ac + (b+c)(a+c) = -2bc - 2ac + ab + bc + ac + c^2 = ab - ac - bc + c^2
 = (a-c)(b-c).$$

So the condition becomes:
$$(b-c)\bigl[\alpha_1(a-b) + \alpha_2(a-c)\bigr] = 0.$$

Since $B \neq C$ (so $b \neq c$), this reduces to:
$$\alpha_1(a-b) + \alpha_2(a-c) = 0.$$

**Substituting the α values.** Using $b - c = -(c-b)$:
$$\alpha_1(a-b) = \frac{(1-u)(a-c)(a-b)}{a(c-b)}, \qquad \alpha_2(a-c) = \frac{(
1-s)(a-b)(a-c)}{a(b-c)} = -\frac{(1-s)(a-b)(a-c)}{a(c-b)}.$$

Therefore:
$$\frac{(a-b)(a-c)}{a(c-b)}\bigl[(1-u) - (1-s)\bigr] = \frac{(a-b)(a-c)}{a(c-b)}
(s - u) = 0.$$

Since $a \neq b$, $a \neq c$, $a \neq 0$, and $c \neq b$, we conclude:
$$\boxed{s = u.}$$

**Geometric interpretation.** The condition $s = u$ means $M = (1-s)a + sb$ and
$N = (1-s)a + sc$, so $\vec{MN} = s(b - c)$, which is parallel to $\vec{BC}$. By
 the converse of the basic proportionality theorem, $s = u$ if and only if $MN \
parallel BC$.

**Conversely**, if $s = u$ (i.e., $\delta \parallel BC$), then the collinearity
condition is satisfied, so $A$, $J$, $T$ are collinear.

**Degenerate cases.** When $s = u = 1$, we get $M = B$, $N = C$, so $\delta = BC
$ — excluded by hypothesis ("$\delta$ not congruent to $BC$"). When $s = u = 0$,
 we get $M = N = A$ — excluded by hypothesis ("$\delta$ not through $A$"). For a
ll other values $s = u \notin \{0, 1\}$, we obtain a valid line parallel to $BC$
, distinct from $BC$, and not passing through $A$.

**Verification.** For the triangle $A = 1$, $B = i$, $C = -1$ on the unit circle
: $T = 2i(-1)/(i-1) = -1+i$. Taking $s = u = 1/2$ gives $M = (1+i)/2$, $N = 0$ (
line parallel to $BC$). Computing the two circumcircles and their second interse
ction yields $J = -1/5 + 3i/5$. The directions $\vec{AJ} = (-6/5, 3/5) \propto (
-2, 1)$ and $\vec{AT} = (-2, 1)$ are parallel, confirming collinearity. Taking $
s = 1/3, u = 1/2$ (non-parallel $\delta$) yields a radical axis $3x + 7y = 3$, o
n which $T = (-1, 1)$ does not lie ($3(-1)+7(1) = 4 \neq 3$), confirming the con
verse.

## Conclusion

The locus of line $\delta$ is the set of all lines **parallel to $BC$** (excludi
ng $BC$ itself and the line through $A$ parallel to $BC$, which are already excl
uded by the problem's hypotheses).
