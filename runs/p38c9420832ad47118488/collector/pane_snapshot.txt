$$\pi(a_1)^2 + \pi(a_2)^2 = \pi(1) = 1_{A/I_2},$$

hence

$$\pi(a_1)^2 = 1_{A/I_2}.$$

- $x^2 = 1$, so $\sigma(x^2) = \{1\}$, which forces $\sigma(x) \subseteq \{-1, 1

$$\sigma(x) \subseteq [0,\infty) \cap \{-1, 1\} = \{1\}.$$

$$\sigma(x - 1) = \sigma(x) - 1 = \{0\},$$

so the spectral radius $r(x-1) = 0$. As $x - 1$ is normal, $\|x - 1\| = r(x-1) =
 0$, giving $x = 1_{A/I_2}$.

Therefore $\pi(a_1) = \pi(1)$, i.e., $a_1$ and $1$ define the same class in $A/I
_2$. $\blacksquare$
