# Problem

In a futuristic data center, a supercomputer is processing a hierarchical security archive. The archive is organized into 30 distinct levels, indexed from $n = 1$ to $n = 30$. However, due to protocol restrictions, data analysis only begins at level $n = 3$.

For each level $n$, the system performs a two-stage selection process to generate "Validation Keys":
1. First, the system identifies every possible unique trio of data packets that can be formed from the $n$ packets available at that level.
2. Second, from the set of all trios identified in the first stage, the system calculates how many unique pairs of those trios can be formed.

To finalize the security handshake, the system must sum the total number of unique pairs of trios generated across all active levels (from level 3 through level 30).

Find the largest prime divisor of this total sum.
