**证明。**

设 $r$ 为内切圆 $\Omega$ 的半径。通过缩放，设 $r=1$。将 $K$ 置于原点，$BC$ 置于
$x$ 轴上，圆心 $I$ 位于 $(0,1)$，因此 $\Omega: x^2+y^2=2y$。

设 $\beta = B/2$, $\gamma = C/2$, 并设 $t=\tan\beta$, $s=\tan\gamma$。从 $B$ 和
$C$ 到 $\Omega$ 的切线长度给出 $BK = \cot\beta = 1/t$ 和 $CK = \cot\gamma = 1/s$
，因此：
$$B=(-1/t,\,0),\quad C=(1/s,\,0),\quad K=(0,0),\quad I=(0,1).$$

**求 $A$ 的坐标。** 直线 $AB$ 过 $B$ 点，且与 $BC$ 的夹角为 $2\beta$：$y=\tan(2\
beta)(x+1/t)$。直线 $AC$：$y=-\tan(2\gamma)(x-1/s)$。利用 $\tan(2\beta)=2t/(1-t^
2)$ 和 $\tan(2\gamma)=2s/(1-s^2)$ 求解交点，得到：
$$x_A = \frac{s-t}{1-ts},\qquad y_A = \frac{2}{1-ts}.$$

**直线 $KM$。** 从 $A$ 到 $BC$ 的高线的垂足为 $D=(x_A,0)$，因此 $M=(x_A,\, y_A/2
)=\bigl(\frac{s-t}{1-ts},\,\frac{1}{1-ts}\bigr)$。由于 $K=(0,0)$，直线 $KM$ 的方
向为 $(s-t,\,1)$，即：
$$KM:\; x=(s-t)\,y.$$

**求 $N$。** 将 $x=(s-t)y$ 代入 $\Omega: x^2+y^2=2y$：
$$(s-t)^2 y^2 + y^2 = 2y \;\;\Longrightarrow\;\; y\bigl((s-t)^2+1\bigr) = 2.$$
根 $y=0$ 对应 $K$；另一个根给出 $N$。设 $d = s-t$：
$$N = \left(\frac{2d}{d^2+1},\;\frac{2}{d^2+1}\right).$$

**$\triangle BCN$ 的外接圆。** 设其方程为 $x^2+y^2+Dx+Ey+F=0$。代入 $B$ 和 $C$（
其中 $y=0$）：
- 从 $B=(-1/t,0)$ 得：$1/t^2 - D/t + F = 0$。
- 从 $C=(1/s,0)$ 得：$1/s^2 + D/s + F = 0$。

两式相减并求解：$D = \frac{s-t}{ts} = \frac{d}{ts}$ 且 $F = -\frac{1}{ts}$。

由于 $N \in \Omega$，我们知道 $x_N^2+y_N^2 = 2y_N$。将 $N$ 代入外接圆方程：
$$2y_N + D\,x_N + E\,y_N + F = 0 \;\;\Longrightarrow\;\; E = \frac{1-d^2-4ts}{2t
s}.$$

外接圆的圆心为：
$$O' = \left(-\frac{D}{2},\,-\frac{E}{2}\right) = \left(-\frac{d}{2ts},\;\frac{d
^2+4ts-1}{4ts}\right).$$

**$N$ 处的切线。** 两个圆在公共点 $N$ 处相切当且仅当它们的圆心与 $N$ 共线（此时
在 $N$ 处的切线重合，因为它们都垂直于圆心连线）。我们验证 $I=(0,1)$, $O'$, $N$
是否共线：
$$O'-I = \left(-\frac{d}{2ts},\;\frac{d^2-1}{4ts}\right),\qquad N-I = \left(\fra
c{2d}{d^2+1},\;\frac{1-d^2}{d^2+1}\right).$$

叉积：
$$\left(-\frac{d}{2ts}\right)\!\cdot\!\frac{1-d^2}{d^2+1} \;-\; \frac{d^2-1}{4ts
}\!\cdot\!\frac{2d}{d^2+1} = \frac{-d(1-d^2)}{2ts(d^2+1)} - \frac{d(d^2-1)}{2ts(
d^2+1)} = \frac{-d(1-d^2)}{2ts(d^2+1)} + \frac{d(1-d^2)}{2ts(d^2+1)} = 0.$$

因此 $I$, $O'$, $N$ 共线。由于 $N$ 同时位于 $\Omega$（由构造可知）和 $\triangle
BCN$ 的外接圆（由构造可知）上，且连接两个圆心的直线经过 $N$，这两个圆在 $N$ 处有
相同的切线——即它们在 $N$ 处相切。$\blacksquare$
