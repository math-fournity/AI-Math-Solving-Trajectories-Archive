# The Nerve of a Groupoid is a Kan Complex

## Setup and Statement

A category $\mathcal{C}$ in which every morphism is invertible is a **groupoid**
 (a category enriched in isomorphisms). The **nerve** $\operatorname{N}_{\bullet
}(\mathcal{C})$ is the simplicial set whose $n$-simplices are functors $[n]\to\m
athcal{C}$, i.e. chains of $n$ composable morphisms in $\mathcal{C}$:

$$\operatorname{N}_n(\mathcal{C})=\operatorname{Fun}([n],\mathcal{C}),\qquad [n]
=0\to 1\to\cdots\to n.$$

The structural property is:

> **Theorem.** $\mathcal{C}$ is a groupoid if and only if $\operatorname{N}_{\bu
llet}(\mathcal{C})$ is a **Kan complex**.

Recall that a simplicial set $X$ is a Kan complex if every horn $\Lambda^n_k\to
X$ ($0\le k\le n$, $n\ge 1$) admits a filler $\Delta^n\to X$. The horns come in
two flavors: **inner horns** ($0<k<n$) and **outer horns** ($k=0$ or $k=n$).

## Preliminary: Inner Horns and the Nerve of Any Category

For *any* category $\mathcal{C}$ (not necessarily a groupoid), the nerve $\opera
torname{N}_{\bullet}(\mathcal{C})$ satisfies the **inner Kan** (quasi-category)
condition: every *inner* horn $\Lambda^n_k$ with $0<k<n$ has a unique filler. Th
is is the classical characterization:

- An inner horn $\Lambda^n_k\to\operatorname{N}_{\bullet}(\mathcal{C})$ is a com
posable diagram missing the $k$-th face, i.e. a collection of objects $x_0,\dots
,x_n$ and morphisms filling every face except the one opposite vertex $k$.
- Filling it amounts to composing the morphisms along the two paths through vert
ex $k$, which is possible by the composition law in $\mathcal{C}$, and the fille
r is unique because composition in a category is uniquely defined.

So the nerve of *any* category is a quasi-category. The question is when the **o
uter** horn-filling conditions also hold, which is what upgrades "quasi-category
" to "Kan complex."

## The Key Direction: Groupoid $\Rightarrow$ Kan Complex

We must show that if every morphism in $\mathcal{C}$ is invertible, then every o
uter horn $\Lambda^n_0\to\operatorname{N}_{\bullet}(\mathcal{C})$ and $\Lambda^n
_n\to\operatorname{N}_{\bullet}(\mathcal{C})$ admits a filler. By duality (rever
sing the category), it suffices to handle the **inner-most** outer horn, say $\L
ambda^n_n$ (the horn missing the last face); the $\Lambda^n_0$ case is dual.

**The $\Lambda^n_n$ horn.** A map $\Lambda^n_n\to\operatorname{N}_{\bullet}(\mat
hcal{C})$ specifies:
- objects $x_0,\dots,x_n$,
- for every face $d_i$ with $i<n$, a compatible morphism, i.e. a composable chai
n
$$x_0\to x_1\to\cdots\to x_{n-1}$$
(together with all the composites $x_i\to x_j$ for $i<j<n$ encoded by the lower-
dimensional faces),
- and a morphism $x_0\to x_n$ (the face $d_0$, which is present in $\Lambda^n_n$
 since only the face $d_n$ opposite vertex $n$ is missing).

Concretely, the data is: morphisms $f_i:x_{i-1}\to x_i$ for $i=1,\dots,n-1$, and
 a morphism $g:x_0\to x_n$, all compatible. The missing face $d_n$ is the edge $
x_{n-1}\to x_n$. To fill the horn we must supply a morphism $h:x_{n-1}\to x_n$ s
uch that the resulting $n$-simplex is consistent, i.e. such that $g = h\circ f_{
n-1}\circ\cdots\circ f_1$.

Let $F = f_{n-1}\circ\cdots\circ f_1 : x_0\to x_{n-1}$. We need $h:x_{n-1}\to x_
n$ with $h\circ F = g$. Since $\mathcal{C}$ is a groupoid, $F$ is invertible; se
t

$$h = g\circ F^{-1} : x_{n-1}\to x_n.$$

Then $h\circ F = g\circ F^{-1}\circ F = g$, as required. This supplies the missi
ng face and completes the $n$-simplex, filling the horn.

**The $\Lambda^n_0$ horn** is handled dually (or directly): the missing face is
$x_0\to x_1$, and we solve for it by inverting the composite along $x_1\to\cdots
\to x_0$ (using the given edge $x_0\to x_n$ and the chain $x_1\to\cdots\to x_n$)
. Explicitly, given $f_i:x_{i-1}\to x_i$ for $i=2,\dots,n$ and $g:x_0\to x_n$, s
et $G=f_n\circ\cdots\circ f_2:x_1\to x_n$ and define the missing edge $x_0\to x_
1$ as $G^{-1}\circ g$.

**Induction / all dimensions.** The argument above was for the top-dimensional m
issing face. For a general outer horn, the same inversion trick supplies whichev
er face is missing: at each step, the missing face is an edge whose composite wi
th a known chain must equal a known edge, and invertibility lets us solve for it
. The lower-dimensional compatibility is automatic because composition in a cate
gory is associative and unital. Thus every outer horn in every dimension $n\ge 1
$ fills. Combined with the always-true inner horn filling, $\operatorname{N}_{\b
ullet}(\mathcal{C})$ is a Kan complex.

## The Converse: Kan Complex $\Rightarrow$ Groupoid

Suppose $\operatorname{N}_{\bullet}(\mathcal{C})$ is a Kan complex; we show ever

- the edge $f:x\to y$ as the face $d_1$ (the edge $0\to 2$),
- the identity $\operatorname{id}_x:x\to x$ as the face $d_0$ (the edge $1\to 2$

More cleanly, use the **outer** $2$-horn $\Lambda^2_2$: it specifies edges $x\xr

- $d_2$ = the edge $0\to 1$ given by $\operatorname{id}_x:x\to x$.

The missing face $d_1$... — to avoid index confusion, here is the cleanest versi

e{id}_y\circ g=g$; this is trivial and not useful.

The correct horn to use is $\Lambda^2_0$: faces $d_1$ (edge $0\to 2$) and $d_2$

filler is a $2$-simplex, i.e. a composable pair $x\xrightarrow{\operatorname{id}

Let me set up the horn that genuinely yields an inverse. We want to find $g:y\to
 x$ with $g\circ f=\operatorname{id}_x$ or $f\circ g=\operatorname{id}_y$. Consi

Dually, using $\Lambda^2_2$ with $d_0 = f:y\to\cdots$ — set $d_0 = f$ (edge $1\t

Having both a left inverse $g$ and a right inverse $g'$, we get $g=g'$ (since $g

## Why the Condition is Both Necessary and Sufficient — Summary of the Mechanism

The logical core is a perfect correspondence between **algebraic invertibility**
 in $\mathcal{C}$ and **geometric horn-filling** in the nerve:

| Horn type | What filling it requires | Category-theoretic meaning |
|---|---|---|
| Inner $\Lambda^n_k$, $0<k<n$ | Composing morphisms along a path | Composition
in $\mathcal{C}$ (always available) |
| Outer $\Lambda^n_0$, $\Lambda^n_n$ | Solving $h\circ F = g$ or $G\circ h=g$ fo
r an unknown edge $h$ | **Inverting** a morphism |

In a plain category, inner horns fill because composition is defined, but outer
horns fail because solving $h\circ F=g$ for $h$ requires $F^{-1}$, which need no
t exist. The moment *every* morphism is invertible, every such equation is solva
ble by $h=g\circ F^{-1}$ (resp. $h=G^{-1}\circ g$), and so **every** horn — inne
r and outer, in every dimension — fills. That is exactly the Kan condition.

Conversely, the Kan condition forces the outer $2$-horns to fill, and filling th
ose specific horns is *literally* the construction of left and right inverses fo
r an arbitrary morphism. So the Kan condition is equivalent to "every morphism i
s invertible."

## Conclusion

The structural property of $\operatorname{N}_{\bullet}(\mathcal{C})$ when every
morphism of $\mathcal{C}$ is invertible is that **the nerve is a Kan complex**.
The context is: $\mathcal{C}$ is a **groupoid**, and the nerve construction embe
ds the category of groupoids fully faithfully into the category of Kan complexes
 (in fact, into the category of *1-coskeletal* Kan complexes, since the nerve of
 a $1$-category is $2$-coskeletal). The guarantee is the equivalence proved abov
e:

$$\mathcal{C}\text{ is a groupoid}\iff \operatorname{N}_{\bullet}(\mathcal{C})\t
ext{ is a Kan complex},$$

where the forward direction holds because invertibility of morphisms lets one so

on holds because outer $2$-horn filling constructs left and right inverses for e
very morphism, forcing invertibility.
