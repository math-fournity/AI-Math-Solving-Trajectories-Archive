## Setup

Place the regular tetrahedron with vertices P₁, P₂, P₃, P₄ (side length 1). The
recurrence is:

$$P_i = \frac{P_{i-1} + P_{i-2} + P_{i-3} + P_{i-4}}{4}, \quad i > 4$$

## Computing P₅

By definition:

$$P_5 = \frac{P_4 + P_3 + P_2 + P_1}{4}$$

This is exactly the **centroid** G of the original tetrahedron.

## Finding P∞

The recurrence is linear with characteristic equation:

$$4x^4 = x^3 + x^2 + x + 1 \implies 4x^4 - x^3 - x^2 - x - 1 = 0$$

**Factoring out the root x = 1** (since 4−1−1−1−1 = 0):

$$4x^4 - x^3 - x^2 - x - 1 = (x-1)(4x^3 + 3x^2 + 2x + 1)$$

The general solution is:

$$P_n = A \cdot 1^n + B\,r_1^n + C\,r_2^n + D\,r_3^n$$

where r₁, r₂, r₃ are roots of 4x³ + 3x² + 2x + 1 = 0.

**Convergence check (Jury stability criterion)** for p(x) = 4x³ + 3x² + 2x + 1 (
coefficients a₀=1, a₁=2, a₂=3, a₃=4):

1. p(1) = 10 > 0 ✓
2. (−1)³p(−1) = −(−2) = 2 > 0 ✓

4. Jury table: b₀ = 1²−4² = −15, b₂ = 1·3−4·2 = −5; |b₀| > |b₂|: 15 > 5 ✓
5. c₀ = (−15)²−(−5)² = 200, c₁ = (−15)(−10)−(−5)(−10) = 100; |c₀| > |c₁|: 200 >
100 ✓

All Jury conditions are satisfied, so **all three roots lie strictly inside the
unit circle**: |rᵢ| < 1.

Therefore, as n → ∞, all terms rᵢⁿ → 0, and:

$$P_\infty = A = G = \frac{P_1 + P_2 + P_3 + P_4}{4}$$

This is the **centroid of the original tetrahedron** — the unique fixed point of
