## Proof

**Answer: Yes.** There necessarily exists a finite subset $F' \subseteq I$ gener
ating the same equational theory as $F$.

**Key fact (finite support of derivability).** In equational logic (equivalently
, first-order logic restricted to universal equations), if an equation $e$ is a
consequence of a (possibly infinite) set $S$ of equations, then $e$ is a consequ
ence of some *finite* subset $S_0 \subseteq S$.

This follows from the compactness of the proof system. A proof of $e$ from $S$ —
 whether formalized via Birkhoff's five derivation rules (reflexivity, symmetry,
 transitivity, congruence, substitution) or via a first-order derivation — is a
*finite* object: a finite sequence (or finite tree) of steps, each invoking only
 finitely many axioms from $S$. Collecting all axioms from $S$ that appear in th
is proof yields a finite $S_0 \subseteq S$ that already proves $e$.

Equivalently, by the semantic route: $S \models e$ iff $S \cup \{\neg e\}$ is un
satisfiable; by the Compactness Theorem of first-order logic, some finite $S_0 \
cup \{\neg e\}$ is already unsatisfiable, so $S_0 \models e$.

**Construction of $F'$.** Since $I$ generates the same equational theory as $F$,
 we have $\mathrm{Th}(I) = \mathrm{Th}(F)$. In particular, every $f \in F$ belon
gs to $\mathrm{Th}(F) = \mathrm{Th}(I)$, so each $f \in F$ is a logical conseque
nce of $I$.

By the key fact, for each $f \in F$, there exists a finite subset $I_f \subseteq
 I$ such that $I_f \models f$ (equivalently, $I_f \vdash f$).

Now set
$$F' = \bigcup_{f \in F} I_f.$$

Since $F$ is finite and each $I_f$ is finite, $F'$ is a **finite** subset of $I$
.

**Verification that $\mathrm{Th}(F') = \mathrm{Th}(F)$.**

- **$\mathrm{Th}(F') \subseteq \mathrm{Th}(F)$:** Since $F' \subseteq I$, every
model of $I$ is a model of $F'$, so $\mathrm{Th}(F') \subseteq \mathrm{Th}(I) =
\mathrm{Th}(F)$.

- **$\mathrm{Th}(F) \subseteq \mathrm{Th}(F')$:** For each $f \in F$, we have $I
_f \models f$ and $I_f \subseteq F'$, so $F' \models f$. Thus $F' \models F$, wh
ich gives $\mathrm{Th}(F) \subseteq \mathrm{Th}(F')$.

Combining both inclusions, $\mathrm{Th}(F') = \mathrm{Th}(F)$. $\blacksquare$
