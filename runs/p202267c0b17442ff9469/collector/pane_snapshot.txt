## Proof

Let $P(x,y)$ denote the given equation.

**Step 1: $f(1)=1$.**

$P(1,1)$: $f(1)\cdot\gcd(f(1)^2,f(1)^2)=f(1)^2$, so $f(1)^3=f(1)^2$, giving $f(1
)=1$.

**Step 2: Key relations from $y=1$.**

$P(x,1)$: $f(x)\cdot\gcd(f(x),f(1/x))=x\cdot f(1/x)$. $\quad\text{(A)}$

Replacing $x$ by $1/x$ in (A): $f(1/x)\cdot\gcd(f(1/x),f(x))=\tfrac{1}{x}\cdot f
(x)$. $\quad\text{(B)}$

Set $a=f(x),\ b=f(1/x),\ g=\gcd(a,b)$. From (A): $ag=xb$. From (B): $bg=a/x$, i.
e. $a=xbg$. Substituting into (A): $xbg\cdot g=xb$, so $g^2=1$, hence $g=1$.

Therefore
$$\gcd(f(x),f(1/x))=1 \quad\text{and}\quad f(x)=x\cdot f(1/x) \qquad\forall\,x\i
n\mathbb{Q}_{>0}. \tag{$\star$}$$

**Step 3: Determining $f$ uniquely.**

Write $x=\prod_p p^{e_p}$ (prime factorization, $e_p\in\mathbb{Z}$, finitely man
y nonzero). From $(\star)$, for each prime $p$:
$$v_p(f(x))-v_p(f(1/x))=e_p,\qquad \min\!\big(v_p(f(x)),\,v_p(f(1/x))\big)=0.$$

- If $e_p>0$: $v_p(f(x))=e_p$, $v_p(f(1/x))=0$.
- If $e_p<0$: $v_p(f(x))=0$, $v_p(f(1/x))=-e_p$.
- If $e_p=0$: $v_p(f(x))=v_p(f(1/x))=0$.

Hence $f(x)=\prod_{e_p>0}p^{e_p}$, which is exactly the **numerator of $x$ in lo
west terms**. Denote this $\operatorname{num}(x)$.

**Step 4: Verification.**

Let $x=a/b$, $y=c/d$ with $\gcd(a,b)=\gcd(c,d)=1$. Then
$$f(x)=a,\quad f(y)=c,\quad f(1/x)=b,\quad f(1/y)=d.$$

Set $g=\gcd(ac,bd)$. Since $xy=ac/(bd)$, we have $f(xy)=\operatorname{num}(xy)=a
c/g$.

**LHS** $= f(xy)\cdot\gcd\!\big(f(x)f(y),\,f(1/x)f(1/y)\big)=\dfrac{ac}{g}\cdot\
gcd(ac,bd)=\dfrac{ac}{g}\cdot g=ac.$

**RHS** $= xy\cdot f(1/x)\cdot f(1/y)=\dfrac{ac}{bd}\cdot b\cdot d=ac.$

LHS $=$ RHS. $\checkmark$

**Conclusion.** The unique function satisfying the equation is

$$\boxed{f(x)=\text{numerator of }x\text{ in lowest terms}.}$$
