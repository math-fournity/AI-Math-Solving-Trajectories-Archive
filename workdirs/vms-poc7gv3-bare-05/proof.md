# 解答：确定所有素数 $p$ 和正整数 $x, y$ 满足 $x^3 + y^3 = p(xy + p)$

## 答案

所有解为（不计 $x, y$ 顺序）：

$$\boxed{(p, x, y) \in \{(7, 4, 5),\; (13, 2, 7),\; (19, 1, 8)\}}$$

连同对称交换 $x, y$ 后的解：$(7, 5, 4)$, $(13, 7, 2)$, $(19, 8, 1)$。

---

## 证明

### 第一步：建立上界 $x, y \leq p$

**引理 1.** 若正整数 $x, y$ 和素数 $p$ 满足 $x^3 + y^3 = p(xy + p)$，则 $x \leq p$ 且 $y \leq p$。

**证明.** 由对称性，不妨设 $x \leq y$。由方程，

$$y^3 \leq x^3 + y^3 = p(xy + p) \leq p \cdot y \cdot y + p^2 = py^2 + p^2,$$

其中用到 $x \leq y$。因此

$$y^3 - py^2 \leq p^2, \quad \text{即} \quad y^2(y - p) \leq p^2.$$

若 $y > p$，则 $y - p \geq 1$，故 $y^2 \leq p^2$，即 $y \leq p$，与 $y > p$ 矛盾。因此 $y \leq p$，从而 $x \leq y \leq p$。$\square$

### 第二步：用 $s = x + y$, $q = xy$ 化简方程

令 $s = x + y$，$q = xy$（$s, q$ 为正整数，$s \geq 2$，$q \geq 1$）。利用 $x^3 + y^3 = (x+y)^3 - 3xy(x+y) = s^3 - 3sq$，原方程化为

$$s^3 - 3sq = p(q + p),$$

整理得

$$s^3 - p^2 = q(3s + p), \quad \text{即} \quad q = \frac{s^3 - p^2}{3s + p}. \tag{$\star$}$$

因此 $3s + p \mid s^3 - p^2$，且 $q$ 为正整数。

### 第三步：建立 $s$ 的上界

**引理 2.** $s \leq p + 3$。

**证明.** 由于 $x, y$ 为正整数，$q = xy \leq \frac{s^2}{4}$（AM-GM）。由 $(\star)$，

$$\frac{s^3 - p^2}{3s + p} \leq \frac{s^2}{4},$$

即 $4(s^3 - p^2) \leq s^2(3s + p)$，化简得

$$s^2(s - p) \leq 4p^2. \tag{$\dagger$}$$

若 $s \leq p$，结论显然成立。若 $s > p$，则 $s \geq p + 1$，由 $(\dagger)$，

$$(p+1)^2 \cdot 1 \leq s^2(s - p) \leq 4p^2,$$

且 $s - p \leq \frac{4p^2}{s^2} \leq \frac{4p^2}{(p+1)^2} < 4$，

故 $s - p \leq 3$，即 $s \leq p + 3$。$\square$

### 第四步：关键整除条件

**引理 3.** $3s + p \mid p^2(p + 27)$。

**证明.** 我们建立恒等式

$$27(s^3 - p^2) = (3s + p)(9s^2 - 3ps + p^2) - p^2(p + 27). \tag{$\ddagger$}$$

**验证**：将右端展开，

$$(3s+p)(9s^2 - 3ps + p^2) = 27s^3 - 9ps^2 + 3p^2 s + 9ps^2 - 3p^2 s + p^3 = 27s^3 + p^3.$$

因此右端 $= 27s^3 + p^3 - p^2(p + 27) = 27s^3 + p^3 - p^3 - 27p^2 = 27s^3 - 27p^2 = 27(s^3 - p^2)$。$\checkmark$

由 $(\star)$，$3s + p \mid s^3 - p^2$，故 $3s + p \mid 27(s^3 - p^2)$。而 $3s + p \mid (3s+p)(9s^2 - 3ps + p^2)$，由 $(\ddagger)$ 得 $3s + p \mid p^2(p + 27)$。$\square$

### 第五步：枚举候选 $D = 3s + p$

记 $D = 3s + p$。由引理 1 和 2：

- $D > p$（因为 $s \geq 2$，$D = 3s + p \geq p + 6$）；
- $D \leq 3(p+3) + p = 4p + 9$；
- $D \equiv p \pmod{3}$（因为 $D = 3s + p$）；
- $D \mid p^2(p + 27)$（引理 3）。

由于 $p$ 是素数，$p^2(p+27)$ 的因数形如 $p^a \cdot d$，其中 $a \in \{0, 1, 2\}$，$d \mid (p + 27)$。

**情形 $p \geq 7$ 的分析。**

**(A) $D = p \cdot d$，$d \mid (p+27)$，$d \geq 2$。**

由 $D \leq 4p + 9$ 得 $d \leq 4 + 9/p < 5$（$p \geq 7$），故 $d \in \{2, 3, 4\}$。

由 $D \equiv p \pmod{3}$，当 $p \not\equiv 0 \pmod{3}$（即 $p \neq 3$，对 $p \geq 7$ 自动满足），需 $d \equiv 1 \pmod{3}$，故 $d = 4$。

此时 $D = 4p$，$s = p$，$q = \frac{p^3 - p^2}{4p} = \frac{p(p-1)}{4}$。

判别式 $s^2 - 4q = p^2 - p(p-1) = p$。要使 $x, y$ 为整数，需 $p$ 为完全平方数，但 $p$ 是素数，不可能。**此情形无解。**

**(B) $D = d$，$d \mid (p+27)$，$d > p$。**

设 $p + 27 = d \cdot e$，$e \geq 1$。由 $d > p$ 得 $e < \frac{p+27}{p} = 1 + \frac{27}{p} \leq 1 + \frac{27}{7} < 5$，故 $e \in \{1, 2, 3, 4\}$。

- $e = 1$：$d = p + 27$，恒满足 $d \equiv p \pmod{3}$（因 $27 \equiv 0 \pmod{3}$）。
- $e = 2$：$d = (p+27)/2$，需 $d \equiv p \pmod{3}$，即 $(p+27)/2 \equiv p \pmod{3}$，即 $p + 27 \equiv 2p \pmod{6}$... 更精确地，$d \equiv 2(p+27) \equiv 2p \pmod{3}$（因 $2^{-1} \equiv 2 \pmod{3}$），需 $2p \equiv p \pmod{3}$，即 $p \equiv 0 \pmod{3}$，即 $p = 3$，与 $p \geq 7$ 矛盾。
- $e = 3$：需 $3 \mid (p + 27)$，即 $3 \mid p$，即 $p = 3$，矛盾。
- $e = 4$：需 $4 \mid (p + 27)$ 且 $d = (p+27)/4 > p$，即 $p + 27 > 4p$，即 $p < 9$，故 $p = 7$。但 $4 \mid (7 + 27) = 34$？$34 / 4$ 不是整数。矛盾。

因此对 $p \geq 7$，**唯一可能的 $D$ 为 $D = p + 27$**（即 $e = 1$）。

**(C) $D = p^2 \cdot d$ 或 $D = p^2$。**

对 $p \geq 7$，$p^2 \geq 49 > 4 \cdot 7 + 9 = 37 \geq 4p + 9$（当 $p \geq 7$ 时 $p^2 > 4p + 9$），超出范围。**无候选。**

### 第六步：求解 $D = p + 27$（即 $s = 9$）

当 $D = p + 27$ 时，$3s + p = p + 27$，故 $s = 9$。

$$q = \frac{9^3 - p^2}{p + 27} = \frac{729 - p^2}{p + 27} = \frac{(27 - p)(27 + p)}{p + 27} = 27 - p.$$

需要：

1. **$q > 0$**：$p < 27$，即 $p \leq 23$（$p$ 为素数）。
2. **$q \geq 1$**：$p \leq 26$，同上。
3. **判别式 $s^2 - 4q = 81 - 4(27 - p) = 4p - 27 \geq 0$**：$p \geq 7$。
4. **$4p - 27$ 为完全平方数**：设 $4p - 27 = k^2$，则 $p = \frac{k^2 + 27}{4}$。需 $k$ 为奇数（保证 $p$ 为整数），且 $p$ 为素数，$7 \leq p \leq 23$。

枚举奇数 $k$：

| $k$ | $p = \frac{k^2 + 27}{4}$ | 素数？ | $p \leq 23$？ |
|-----|--------------------------|--------|---------------|
| 1   | 7                        | ✓      | ✓             |
| 3   | 9                        | ✗      | —             |
| 5   | 13                       | ✓      | ✓             |
| 7   | 19                       | ✓      | ✓             |
| 9   | 27                       | ✗      | ✗             |

因此 $p \in \{7, 13, 19\}$。

对应的解：

- **$p = 7$**：$s = 9$，$q = 20$，$4p - 27 = 1$，$x, y = \frac{9 \pm 1}{2} = 5, 4$。
  验证：$4^3 + 5^3 = 64 + 125 = 189 = 7 \times (20 + 7) = 7 \times 27 = 189$。✓

- **$p = 13$**：$s = 9$，$q = 14$，$4p - 27 = 25$，$x, y = \frac{9 \pm 5}{2} = 7, 2$。
  验证：$2^3 + 7^3 = 8 + 343 = 351 = 13 \times (14 + 13) = 13 \times 27 = 351$。✓

- **$p = 19$**：$s = 9$，$q = 8$，$4p - 27 = 49$，$x, y = \frac{9 \pm 7}{2} = 8, 1$。
  验证：$1^3 + 8^3 = 1 + 512 = 513 = 19 \times (8 + 19) = 19 \times 27 = 513$。✓

### 第七步：验证小素数 $p = 2, 3, 5$

对 $p < 7$，需单独检查（因第四步的 $4p - 27 < 0$ 排除了 $D = p + 27$ 的情形，但可能有其他 $D$）。

**$p = 2$**：$D \mid 4 \times 29 = 116$，$D > 2$，$D \leq 17$，$D \equiv 2 \pmod{3}$。116 在 $(2, 17]$ 中的因数：4。$4 \equiv 1 \pmod{3} \neq 2$。无候选。

**$p = 3$**：$D \mid 9 \times 30 = 270$，$D > 3$，$D \leq 21$，$D \equiv 0 \pmod{3}$。270 在 $(3, 21]$ 中被 3 整除的因数：6, 9, 15, 18。

- $D = 6$：$s = 1 < 2$，舍去。
- $D = 9$：$s = 2$，$q = (8 - 9)/9 < 0$，舍去。
- $D = 15$：$s = 4$，$q = (64 - 9)/15 = 55/15$，非整数，舍去。
- $D = 18$：$s = 5$，$q = (125 - 9)/18 = 116/18$，非整数，舍去。

无解。

**$p = 5$**：$D \mid 25 \times 32 = 800$，$D > 5$，$D \leq 29$，$D \equiv 2 \pmod{3}$。800 在 $(5, 29]$ 中满足 $D \equiv 2 \pmod{3}$ 的因数：8, 20。

- $D = 8$：$s = 1 < 2$，舍去。
- $D = 20$：$s = 5$，$q = (125 - 25)/20 = 5$，判别式 $25 - 20 = 5$，非完全平方数，舍去。

无解。

### 结论

综合以上所有情形，满足 $x^3 + y^3 = p(xy + p)$ 的所有素数 $p$ 和正整数 $x, y$ 为：

| $p$ | $(x, y)$ | $x^3 + y^3$ | $p(xy + p)$ |
|-----|-----------|-------------|-------------|
| 7   | (4, 5) 或 (5, 4) | 189 | 189 |
| 13  | (2, 7) 或 (7, 2) | 351 | 351 |
| 19  | (1, 8) 或 (8, 1) | 513 | 513 |

**证毕。** $\blacksquare$

---

**注记.** 所有解共享一个优美的结构：$x + y = 9 = 3^2$，$xy + p = 27 = 3^3$，且 $p = m^2 + m + 7$（$m = 0, 1, 2$ 分别给出 $p = 7, 9, 13$，但 $p = 9$ 非素数；$m = 3$ 给出 $p = 19$）。素数 $p$ 取 $\{7, 13, 19\}$，恰好是 $6k + 1$ 型素数中不超过 23 且使 $4p - 27$ 为完全平方数者。
