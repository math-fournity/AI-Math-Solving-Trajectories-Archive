## Proof

**Setup.** Let $N_0 > 0$ be an arbitrary positive starting value. Define the ite
rative process
$$N_{n+1} = N_n \cdot X_n, \qquad n = 0, 1, 2, \dots$$
where $X_0, X_1, X_2, \dots$ are i.i.d. random variables, each uniformly distrib
uted on $[0, p]$, with $p > 0$ the constant to be determined.

The value after $n$ steps is
$$N_n = N_0 \prod_{i=1}^{n} X_i.$$

**Logarithmic transform.** Taking natural logarithms,
$$\ln N_n = \ln N_0 + \sum_{i=1}^{n} \ln X_i.$$

The sum $\sum_{i=1}^{n} \ln X_i$ is a sum of i.i.d. random variables. By the Str
ong Law of Large Numbers,
$$\frac{1}{n}\sum_{i=1}^{n} \ln X_i \;\xrightarrow{\text{a.s.}}\; E[\ln X],$$
where $X \sim \mathrm{Uniform}(0, p)$.

Therefore:
- If $E[\ln X] > 0$, then $\sum \ln X_i \to +\infty$ a.s., so $N_n \to +\infty$
a.s. (diverges).
- If $E[\ln X] < 0$, then $\sum \ln X_i \to -\infty$ a.s., so $N_n \to 0$ a.s. (
converges to zero).
- If $E[\ln X] = 0$, the sum is a zero-drift random walk; it oscillates and $N_n
$ neither diverges to infinity nor converges to zero (almost surely it does not
tend to either limit).

**Computing $E[\ln X]$.** With $X \sim \mathrm{Uniform}(0,p)$,
$$E[\ln X] = \frac{1}{p}\int_0^p \ln x\, dx.$$
Using $\int \ln x\, dx = x\ln x - x + C$,
$$E[\ln X] = \frac{1}{p}\Big[x\ln x - x\Big]_0^p = \frac{1}{p}\big(p\ln p - p\bi
g) = \ln p - 1,$$
where the lower limit at $0$ vanishes since $\lim_{x\to 0^+} x\ln x = 0$.

**Solving the critical condition.** Setting $E[\ln X] = 0$:
$$\ln p - 1 = 0 \implies \ln p = 1 \implies p = e.$$

**Verification that $p = e$ gives the desired behavior.** With $p = e$, $E[\ln X
] = 0$. The log-product $S_n = \sum_{i=1}^n \ln X_i$ is a zero-mean random walk
with i.i.d. increments. Since $\ln X$ is non-degenerate (it takes a continuum of
 values), $S_n$ does not converge to $+\infty$ or $-\infty$; it is recurrent/osc
illatory. Consequently $N_n = N_0 e^{S_n}$ neither diverges to $+\infty$ nor con
verges to $0$.

**Uniqueness.** The function $\ln p - 1$ is strictly increasing in $p$, so $p =
e$ is the unique value satisfying the critical condition. Any $p > e$ forces div
ergence to $+\infty$; any $0 < p < e$ forces convergence to $0$.

**Conclusion.** The unique constant is

$$\boxed{p = e}.$$
