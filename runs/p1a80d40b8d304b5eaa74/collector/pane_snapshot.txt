# 证明：+ 是一个双函子

我们需要验证 $+: \mathscr{C} \times \mathscr{C} \longrightarrow \mathscr{C}$ 满
足范畴论中关于（双）函子的公理。回顾一下，$\mathscr{C} \times \mathscr{C}$ 中的
态射是一个对子 $[f_1, f_2]$，其中 $f_i: C_i \to C'_i$（$i=1,2$），且积范畴中的复
合是按分量进行的：$[g_1, g_2] \circ [f_1, f_2] = [g_1 \circ f_1,\, g_2 \circ f_2
]$。$\mathscr{C} \times \mathscr{C}$ 中对象 $(C_1, C_2)$ 上的单位元是 $[\mathrm{
id}_{C_1}, \mathrm{id}_{C_2}]$。

我们需要检查函子的两条公理：(i) 保持单位元，(ii) 保持复合。

---

## (i) 保持单位元

设 $(C_1, C_2)$ 为 $\mathscr{C} \times \mathscr{C}$ 中的一个对象。根据定义，$+$
在态射上的作用为

$$+\big([\mathrm{id}_{C_1}, \mathrm{id}_{C_2}]\big) = \mathrm{id}_{C_1} + \mathr
m{id}_{C_2}.$$

余积的函子性（即对每个分量应用态射 $C_1 \to C'_1$ 和 $C_2 \to C'_2$ 会得到一个态
射 $C_1 + C_2 \to C'_1 + C'_2$，这由余积的泛性质产生）给出了一个典范态射

$$\mathrm{id}_{C_1} + \mathrm{id}_{C_2}: C_1 + C_2 \longrightarrow C_1 + C_2.$$

为了确认 $\mathrm{id}_{C_1} + \mathrm{id}_{C_2} = \mathrm{id}_{C_1 + C_2}$，我们
使用余积的泛性质。态射 $\mathrm{id}_{C_1 + C_2}: C_1 + C_2 \to C_1 + C_2$ 是唯一
的态射 $\ell: C_1 + C_2 \to C_1 + C_2$，满足对于余积余内射 $\iota_1: C_1 \to C_1
 + C_2$ 和 $\iota_2: C_2 \to C_1 + C_2$，有

$$\ell \circ \iota_1 = \iota_1, \qquad \ell \circ \iota_2 = \iota_2.$$

现在计算 $\mathrm{id}_{C_1} + \mathrm{id}_{C_2}$ 在余内射上的作用。根据定义，$f_
1 + f_2$ 是满足

$$(f_1 + f_2) \circ \iota^{C_1,C_2}_j = \iota^{C'_1,C'_2}_j \circ f_j, \quad j =
 1, 2$$

的唯一态射，其中 $\iota^{C_1,C_2}_j$ 和 $\iota^{C'_1,C'_2}_j$ 是相应余积的余内射
。取 $f_1 = \mathrm{id}_{C_1}$ 且 $f_2 = \mathrm{id}_{C_2}$（因此 $C'_i = C_i$）
，这变为

$$(\mathrm{id}_{C_1} + \mathrm{id}_{C_2}) \circ \iota_j = \iota_j \circ \mathrm{
id}_{C_j} = \iota_j, \quad j = 1, 2.$$

因此 $\mathrm{id}_{C_1} + \mathrm{id}_{C_2}$ 满足与 $\mathrm{id}_{C_1 + C_2}$ 相
同的刻画性质。由余积态射的唯一性可知，

$$\mathrm{id}_{C_1} + \mathrm{id}_{C_2} = \mathrm{id}_{C_1 + C_2}.$$

因此 $+\big([\mathrm{id}_{C_1}, \mathrm{id}_{C_2}]\big) = \mathrm{id}_{+(C_1, C_
2)}$。单位元保持性成立。✓

---

## (ii) 保持复合

设 $\mathscr{C} \times \mathscr{C}$ 中的态射为 $[f_1, f_2]: (C_1, C_2) \to (C'_1
, C'_2)$ 和 $[g_1, g_2]: (C'_1, C'_2) \to (C''_1, C''_2)$，因此 $f_j: C_j \to C'
_j$ 且 $g_j: C'_j \to C''_j$。我们需要证明

$$+\big([g_1, g_2] \circ [f_1, f_2]\big) = +[g_1, g_2] \circ +[f_1, f_2],$$

即

$$(g_1 \circ f_1) + (g_2 \circ f_2) = (g_1 + g_2) \circ (f_1 + f_2).$$

两边都是 $C_1 + C_2 \to C''_1 + C''_2$ 的态射。我们再次通过它们在余内射上的作用
来验证它们相等，利用余积态射的唯一性。

设 $\iota_j = \iota^{C_1,C_2}_j$、$\iota'_j = \iota^{C'_1,C'_2}_j$、$\iota''_j =
 \iota^{C''_1,C''_2}_j$ 为相应的余内射。根据 $f_1 + f_2$ 的定义，

$$(f_1 + f_2) \circ \iota_j = \iota'_j \circ f_j, \quad j = 1, 2.$$

根据 $g_1 + g_2$ 的定义，

$$(g_1 + g_2) \circ \iota'_j = \iota''_j \circ g_j, \quad j = 1, 2.$$

计算右边的复合：

$$(g_1 + g_2) \circ (f_1 + f_2) \circ \iota_j = (g_1 + g_2) \circ \iota'_j \circ
 f_j = \iota''_j \circ g_j \circ f_j, \quad j = 1, 2.$$

现在根据 $(g_1 \circ f_1) + (g_2 \circ f_2)$ 的定义（应用于态射 $g_j \circ f_j:
C_j \to C''_j$）：

$$\big((g_1 \circ f_1) + (g_2 \circ f_2)\big) \circ \iota_j = \iota''_j \circ (g
_j \circ f_j), \quad j = 1, 2.$$

因此 $(g_1 \circ f_1) + (g_2 \circ f_2)$ 和 $(g_1 + g_2) \circ (f_1 + f_2)$ 在 $
\iota_1$ 和 $\iota_2$ 上的限制相同：

$$(g_1 + g_2) \circ (f_1 + f_2) \circ \iota_j = \iota''_j \circ g_j \circ f_j =
\big((g_1 \circ f_1) + (g_2 \circ f_2)\big) \circ \iota_j, \quad j = 1, 2.$$

由余积的泛性质，存在**唯一**的态射 $h: C_1 + C_2 \to C''_1 + C''_2$，使得对于 $j
=1,2$，有 $h \circ \iota_j = \iota''_j \circ g_j \circ f_j$。由于两个态射都满足
这一刻画性质，它们必定相等：

$$(g_1 + g_2) \circ (f_1 + f_2) = (g_1 \circ f_1) + (g_2 \circ f_2).$$

因此 $+\big([g_1, g_2] \circ [f_1, f_2]\big) = +[g_1, g_2] \circ +[f_1, f_2]$。
复合保持性成立。✓

---

## 结论

映射 $+$ 将 $\mathscr{C} \times \mathscr{C}$ 的对象映射到 $\mathscr{C}$ 的对象，
将 $\mathscr{C} \times \mathscr{C}$ 的态射映射到 $\mathscr{C}$ 的态射，保持了单
位元，并保持了复合。因此，$+: \mathscr{C} \times \mathscr{C} \longrightarrow \ma
thscr{C}$ 是一个函子，即一个双函子。$\blacksquare$
