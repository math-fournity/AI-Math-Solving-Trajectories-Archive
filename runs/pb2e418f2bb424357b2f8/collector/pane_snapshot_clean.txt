## Poincaré-Bendixson Theorem

**Setup.** Let $M \subset \mathbb{R}^2$ be a compact, positively invariant regio
n for a $C^1$ vector field $f$ on the plane. Suppose $M$ contains only finitely
many fixed points (equilibria) of $f$. Let $p \in M$, and let $\omega(p)$ denote
 the $\omega$-limit set of the forward orbit $\gamma^+(p) = \{\varphi_t(p) : t \
geq 0\}$, where $\varphi_t$ is the flow generated by $f$.

**Theorem (Poincaré–Bendixson).** If $\omega(p)$ contains no fixed points, then
$\omega(p)$ is a periodic orbit (closed trajectory).

More generally, when $M$ is compact and positively invariant and contains only f
initely many fixed points, the $\omega$-limit set $\omega(p)$ of any point $p \i
n M$ must be one of the following **three mutually exclusive types**:

1. **A single fixed point** (equilibrium). The orbit converges to one equilibriu
m $x^*$ as $t \to \infty$, i.e. $\omega(p) = \{x^*\}$.

2. **A periodic orbit** (closed trajectory / limit cycle). The $\omega$-limit se
t is a nontrivial closed orbit $\Gamma$, i.e. $\omega(p) = \Gamma$ where $\Gamma
$ is a periodic solution of $\dot{x} = f(x)$. (This is the case when $\omega(p)$
 contains no fixed points.)

3. **A finite union of fixed points and connecting orbits (a heteroclinic or hom
oclinic graph).** The $\omega$-limit set consists of a finite collection of fixe
d points $\{x_1, \dots, x_k\}$ together with a set of orbits, each of which conn
ects one fixed point to another (or back to itself). That is, $\omega(p)$ is a g
raph whose vertices are equilibria and whose edges are trajectories $\gamma$ wit
h $\alpha(\gamma) = x_i$ and $\omega(\gamma) = x_j$ for some $i, j$ (possibly $i
 = j$, giving a homoclinic loop). No other structure is possible.

**Why these three exhaust all possibilities.** The key ingredients are:

- Since $M$ is compact and positively invariant, $\omega(p)$ is nonempty, compac
t, connected, and invariant.
- The classical Poincaré–Bendixson lemma shows that if an $\omega$-limit set con
tains only finitely many fixed points and is not itself a single fixed point, th
en it either is a periodic orbit (when it contains no fixed points) or consists
of fixed points together with orbits connecting them.
- The Jordan Curve Theorem (planarity) rules out chaotic $\omega$-limit sets: a
transverse section can be crossed at most once by each trajectory, forcing the l
imiting behavior to be regular. This is what restricts the outcomes to the three
 listed above, in contrast to higher-dimensional or non-planar systems where str
ange attractors can occur.

Thus, under the stated hypotheses, $\omega(p)$ is exactly one of: **(1) a fixed
point, (2) a periodic orbit, or (3) a heteroclinic/homoclinic cycle (graph of eq
uilibria joined by connecting orbits).**
