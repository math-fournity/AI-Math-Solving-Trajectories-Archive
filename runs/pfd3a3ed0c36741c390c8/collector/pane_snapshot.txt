# Solution

## Setup

Place the four collinear markers on a line. Let $w$ be a signed distance paramet
er along the line, centered so the closest point to the origin is at $w=0$. With
 gaps $Z_1Z_2=5$, $Z_2Z_3=1$, $Z_3Z_4=3$, the markers sit at:

$$w_1=-5,\quad w_2=0,\quad w_3=1,\quad w_4=4.$$

Let $D=d^2$ be the squared distance from the origin to the line. Then $r^2 = D +
 w^2$ at each marker, giving $R_1=D+25,\; R_2=D,\; R_3=D+1,\; R_4=D+9$.

## The quartic curve

With $d_1^2+d_2^2 = 2(x^2+y^2+a^2)$ and $d_1^2 d_2^2 = (x^2+y^2+a^2)^2 - 4a^2y^2
$, both boundary equations (after squaring $d_1 d_2$) yield the same curve:

$$4a^2 y^2 = (3r^2-a^2)(3a^2-r^2), \qquad r^2=x^2+y^2.$$

The sign split is: **"+" curve** ($Z_1,Z_4$) requires $r^2 \ge a^2$; **"–" curve
** ($Z_2,Z_3$) requires $r^2 \le a^2$. This forces $1 \le a^2 - D \le 9$.

## Restricting to the line

Write $y = c + \delta w$ (linear in $w$) and $r^2 = D+w^2$. Substituting into th
e quartic gives a degree-4 polynomial in $w$:

$$F(w) = 3w^4 + (4a^2\delta^2 - 10a^2 + 6D)\,w^2 + 8a^2 c\delta\, w + (4a^2 c^2
- 10a^2 D + 3D^2 + 3a^4).$$

Since $F$ vanishes at $w=-5,0,1,4$ and has leading coefficient $3$:

$$F(w) = 3w(w+5)(w-1)(w-4) = 3w^4 - 63w^2 + 60w.$$

## Extracting equations

Matching coefficients (with $c^2 = D(1-\delta^2)$ from the perpendicularity of t
he line to the radius at the closest point):

| Power | Equation |
|-------|----------|
| $w^2$ | $4a^2\delta^2 - 10a^2 + 6D = -63$ |
| $w^1$ | $8a^2 c\delta = 60$ |
| $w^0$ | $4a^2 c^2 - 10a^2 D + 3D^2 + 3a^4 = 0$ |

Setting $v = a^2 - D$, the constant-term equation becomes:

$$3v^2 - 10Dv - 4D^2 + 63D = 0. \tag{A}$$

From the $w^1$ and $w^2$ equations, using $a^2\delta^2 = \tfrac{10a^2-6D-63}{4}$
 and $a^4 c^2 \delta^2 = \tfrac{225}{4}$, one obtains after eliminating $\delta$
:

$$D(10v+4D-63)(6v-63) = -900. \tag{B}$$

## Solving the system

From (A), express $D = \frac{S - (10v-63)}{8}$ where $S = \sqrt{148v^2 - 1260v +
 3969}$. Substituting into (B) and using $S^2 - (10v-63)^2 = 48v^2$:

$$\frac{48v^2}{8}\cdot(6v-63) = -1800 \;\;\Longrightarrow\;\; 6v^2(6v-63)=-1800
\;\;\Longrightarrow\;\; 2v^3 - 21v^2 + 100 = 0.$$

Factoring: $2v^3-21v^2+100 = (v-10)(2v-5)(v+2)$. The roots are $v=10,\;5/2,\;-2$
. Only $v=5/2$ lies in $[1,9]$.

## Computing $a^2$

With $v=5/2$:
$$S = \sqrt{148\cdot\tfrac{25}{4} - 1260\cdot\tfrac{5}{2} + 3969} = \sqrt{925-31
50+3969} = \sqrt{1744} = 4\sqrt{109},$$
$$D = \frac{38 + 4\sqrt{109}}{8} = \frac{19+2\sqrt{109}}{4},$$
$$a^2 = D + v = \frac{19+2\sqrt{109}}{4} + \frac{10}{4} = \frac{29+2\sqrt{109}}{
4}.$$

## Verification

- **Sign conditions**: $a^2 \approx 12.47$; $R_2\approx 9.97$, $R_3\approx 10.97
$ (both $\le a^2$ ✓); $R_4\approx 18.97$, $R_1\approx 34.97$ (both $\ge a^2$ ✓).
- **Equation (A)**: $75/4 + 38D - 4D^2 = \frac{75+722+76\sqrt{109}-797-76\sqrt{1
09}}{4}=0$ ✓.
- **Equation (B)**: $D(2\sqrt{109}-19)(-48) = -48\cdot\frac{(2\sqrt{109})^2-19^2
}{4} = -48\cdot\frac{75}{4} = -900$ ✓.
- **Quartic at $Z_2$**: $4a^2c^2 = 12(19+2\sqrt{109}) = 228+24\sqrt{109}$; $(3D-
a^2)(3a^2-D)=(7+\sqrt{109})(17+\sqrt{109})=228+24\sqrt{109}$ ✓.

## Result

$$a^2 = \frac{29 + 2\sqrt{109}}{4}, \quad m=29,\; n=2,\; p=109,\; q=4.$$

Here $\gcd(29,2,4)=1$ and $109$ is prime (hence squarefree). Therefore:

$$m+n+p+q = 29+2+109+4 = \boxed{144}.$$
