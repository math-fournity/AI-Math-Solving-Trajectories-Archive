## Setup and Reformulation

Index rows and columns $1$ to $5$. Let the cell $(i,j)$ contain value $v = L(i,j
)$. The table is a Latin square: each row and column is a permutation of $\{1,2,
3,4,5\}$.

**Claim:** Cell $(i,j)$ with value $v$ is *good positioned* if and only if
$$i \in \{v,\, 6-v\} \quad\text{and}\quad j \in \{v,\, 6-v\}.$$

*Proof of claim.* Consider the row condition. The row is a permutation of $\{1,\
dots,5\}$; position $j$ holds value $v$, with $j-1$ values to the left and $5-j$
 to the right.

- "All left $< v <$ all right": all $v-1$ values smaller than $v$ must be on the
 left, so $j-1 = v-1$, i.e., $j = v$.
- "All left $> v >$ all right" (vice versa): all $5-v$ values larger than $v$ mu
st be on the left, so $j-1 = 5-v$, i.e., $j = 6-v$.

Thus row-good $\iff j \in \{v, 6-v\}$. The column condition is identical with $i
$ in place of $j$. $\square$
