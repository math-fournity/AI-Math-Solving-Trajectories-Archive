# Perpetual American Put Option

## Setup

The underlying asset follows geometric Brownian motion under the risk-neutral me
asure:

$$dS = rS\,dt + \sigma S\,dW$$

Since the option is **perpetual** (infinite maturity), the value function $V(S)$
 is time-independent. In the continuation region $S > S^*$ (where $S^*$ is the o
ptimal exercise boundary), $V$ satisfies the stationary Black–Scholes ODE:

$$\frac{1}{2}\sigma^2 S^2 V''(S) + rS V'(S) - rV(S) = 0 \tag{1}$$

with the free-boundary conditions:

- **Value matching:** $V(S^*) = K - S^*$
- **Smooth pasting:** $V'(S^*) = -1$
- **Far-field:** $V(S) \to 0$ as $S \to \infty$
- **Early-exercise constraint:** $V(S) \geq (K - S)_+$

## Solving the ODE

Equation (1) is a Cauchy–Euler equation. Trying $V(S) = S^\alpha$:

$$\frac{1}{2}\sigma^2 \alpha(\alpha-1) + r\alpha - r = 0$$

$$\frac{1}{2}\sigma^2 \alpha^2 + \left(r - \frac{\sigma^2}{2}\right)\alpha - r =
 0$$

The discriminant is:

$$\left(r - \frac{\sigma^2}{2}\right)^2 + 2\sigma^2 r = r^2 - r\sigma^2 + \frac{
\sigma^4}{4} + 2r\sigma^2 = \left(r + \frac{\sigma^2}{2}\right)^2$$

so the two roots are:

$$\alpha_1 = \frac{-(r - \sigma^2/2) + (r + \sigma^2/2)}{\sigma^2} = 1, \qquad \
alpha_2 = \frac{-(r - \sigma^2/2) - (r + \sigma^2/2)}{\sigma^2} = -\frac{2r}{\si
gma^2}$$

The general solution is $V(S) = A\,S + B\,S^{-\gamma}$ where $\gamma := \frac{2r
}{\sigma^2}$.

The far-field condition $V(\infty) = 0$ forces $A = 0$ (since $S \to \infty$). T
hus:

$$\boxed{V(S) = B\,S^{-\gamma}, \qquad \gamma = \frac{2r}{\sigma^2}} \tag{2}$$

## Determining $S^*$ and $B$

**Smooth pasting** $V'(S^*) = -1$:

$$B(-\gamma)(S^*)^{-\gamma - 1} = -1 \implies B = \frac{(S^*)^{\gamma+1}}{\gamma
} \tag{3}$$

**Value matching** $V(S^*) = K - S^*$:

$$\frac{(S^*)^{\gamma+1}}{\gamma}\,(S^*)^{-\gamma} = K - S^* \implies \frac{S^*}
{\gamma} = K - S^*$$

$$S^*\!\left(1 + \frac{1}{\gamma}\right) = K \implies S^* = \frac{\gamma}{1+\gam
ma}\,K = \frac{2rK}{2r + \sigma^2} \tag{4}$$

Substituting (3) into (2):

$$V(S) = \frac{(S^*)^{\gamma+1}}{\gamma}\,S^{-\gamma} = (K - S^*)\left(\frac{S}{
S^*}\right)^{-\gamma}$$

where $K - S^* = K - \frac{\gamma K}{1+\gamma} = \frac{K}{1+\gamma} = \frac{K\si
gma^2}{2r + \sigma^2}$.

## Verification

1. **Value matching:** $V(S^*) = (K-S^*)(S^*/S^*)^{-\gamma} = K - S^*$. ✓
2. **Smooth pasting:** $V'(S) = -(K-S^*)\gamma\,S^{-\gamma-1}(S^*)^\gamma$, so $
V'(S^*) = -\frac{(K-S^*)\gamma}{S^*} = -\frac{/(1+\gamma)]\cdot\gamma}{\gamma
K/(1+\gamma)} = -1$. ✓
3. **Far-field:** $\gamma = 2r/\sigma^2 > 0$ (for $r>0$), so $V(S)\to 0$ as $S\t
o\infty$. ✓
4. **Convexity / early-exercise constraint:** $V''(S) = (K-S^*)\gamma(\gamma+1)S
^{-\gamma-2}(S^*)^\gamma > 0$, so $V$ is convex; combined with value matching an
d smooth pasting at $S^*$, the graph of $V$ lies above the payoff $K-S$ for $S >
 S^*$, confirming the continuation region is optimal there. ✓
5. **$S^* < K$:** $S^* = \frac{2r}{2r+\sigma^2}K < K$, so exercise only occurs w
hen the option is in the money, as required. ✓

## Result

For $r > 0$, the price of the perpetual American put is:

$$\boxed{V(S) = \begin{cases} K - S, & S \leq S^*, \\[6pt] \dfrac{K\sigma^2}{2r
+ \sigma^2}\left(\dfrac{S}{S^*}\right)^{-2r/\sigma^2}, & S > S^*, \end{cases}}$$

where the optimal exercise boundary is

$$\boxed{S^* = \frac{2r}{2r + \sigma^2}\,K.}$$

Equivalently, in the continuation region $S > S^*$:

$$V(S) = (K - S^*)\left(\frac{S}{S^*}\right)^{-2r/\sigma^2}, \qquad S^* = \frac{
2rK}{2r+\sigma^2}.$$
