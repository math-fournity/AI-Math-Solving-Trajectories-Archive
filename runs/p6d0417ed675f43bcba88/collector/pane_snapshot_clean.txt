## Proof

We determine the automorphisms of the structure $\langle \omega, < \rangle$, whe
re $\omega = \{0, 1, 2, \ldots\}$ is the set of natural numbers and $<$ is the u
sual strict linear order.

**Definition.** An automorphism of $\langle \omega, < \rangle$ is a bijection $f
 : \omega \to \omega$ such that for all $a, b \in \omega$,
$$a < b \iff f(a) < f(b).$$

**Claim.** The only automorphism is the identity map, so the number of automorph
isms is $1$.

**Proof.** Let $f : \omega \to \omega$ be an automorphism. We show by induction
that $f(n) = n$ for all $n \in \omega$.

*Base case ($n = 0$).* The element $0$ is the unique least element of $\omega$:
$0 < m$ for every $m \in \omega \setminus \{0\}$, and no other element has this
property. Since $f$ is an order-preserving bijection, it must send the least ele
ment to the least element. Concretely, suppose for contradiction that $f(0) = k
> 0$. Then $0 < k$, so by order-preservation $f(0) < f(k)$, i.e., $k < f(k)$. Bu
t also, since $f$ is a bijection, there exists some $j$ with $f(j) = 0$. We cann
ot have $j = 0$ (since $f(0) = k \neq 0$), so $j > 0$, meaning $0 < j$, hence $f
(0) < f(j) = 0$, i.e., $k < 0$, a contradiction. Therefore $f(0) = 0$.

*Inductive step.* Suppose $f(0) = 0, f(1) = 1, \ldots, f(n) = n$ for some $n \ge
q 0$. We show $f(n+1) = n+1$.

Since $f$ is a bijection and $f$ maps $\{0, 1, \ldots, n\}$ onto $\{0, 1, \ldots
, n\}$ (by the induction hypothesis), $f$ maps $\omega \setminus \{0, 1, \ldots,
 n\} = \{n+1, n+2, \ldots\}$ onto itself. The element $n+1$ is the least element
 of $\{n+1, n+2, \ldots\}$: it is $<\, m$ for every $m \in \{n+2, n+3, \ldots\}$
, and no other element of this set has this property. By the same argument as in
 the base case (applied to the restricted order on $\{n+1, n+2, \ldots\}$, which
 $f$ preserves), $f$ must send the least element of this set to itself. Therefor
e $f(n+1) = n+1$.

By induction, $f(n) = n$ for all $n \in \omega$, so $f$ is the identity.

**Conclusion.** The identity map is the unique automorphism of $\langle \omega,
< \rangle$. The number of automorphisms is $\boxed{1}$.
