## 证明

设 $A = \mathbb{C}(x)$ 为复系数有理函数域。我们将证明 $\dim_{\mathbb{C}} A = 2^{
\aleph_0}$，方法是通过建立两个不依赖于 GCH 的界限。

**上界：** $\dim_{\mathbb{C}} A \leq |A| = 2^{\aleph_0}$。

每个有理函数都是一对多项式 $(p, q)$ 的商，其中 $q \neq 0$。由于 $\mathbb{C}[x]$
中的多项式是复数的有限序列，我们有
$$|\mathbb{C}[x]| = \bigcup_{n=0}^{\infty} \mathbb{C}^n = \aleph_0 \cdot 2^{\ale
ph_0} = 2^{\aleph_0}.$$
因此 $|A| \leq |\mathbb{C}[x]|^2 = 2^{\aleph_0}$，且由于 $A \supseteq \mathbb{C}
$，我们有 $|A| = 2^{\aleph_0}$。任何基的基数最多为 $|A|$，因此 $\dim_{\mathbb{C}
} A \leq 2^{\aleph_0}$。

**下界：** 我们构造一个大小为 $2^{\aleph_0}$ 的 $\mathbb{C}$-线性无关族。

考虑族 $\mathcal{F} = \left\{\dfrac{1}{x - a} : a \in \mathbb{C}\right\} \subset
 A$，其基数为 $|\mathbb{C}| = 2^{\aleph_0}$。

**$\mathcal{F}$ 的线性无关性证明：** 假设存在非平凡关系
$$\sum_{i=1}^{n} c_i \cdot \frac{1}{x - a_i} = 0 \quad \text{在 } \mathbb{C}(x)
\text{ 中},$$
其中 $a_1, \ldots, a_n$ 是互不相同的复数，且每个 $c_i \in \mathbb{C}^\*$。两边同
乘 $\prod_{j=1}^{n}(x - a_j)$ 得到多项式恒等式
$$\sum_{i=1}^{n} c_i \prod_{j \neq i}(x - a_j) = 0 \quad \text{在 } \mathbb{C}[x
] \text{ 中}.$$
代入 $x = a_k$：除了 $i = k$ 的项外，每一项都包含因子 $(a_k - a_k) = 0$，因此
$$c_k \prod_{j \neq k}(a_k - a_j) = 0.$$
由于 $a_j$ 互不相同，乘积 $\prod_{j \neq k}(a_k - a_j) \neq 0$，从而 $c_k = 0$。
这对所有 $k$ 都成立，产生矛盾。因此 $\mathcal{F}$ 在 $\mathbb{C}$ 上是线性无关的
。

**结论：** 我们有
$$2^{\aleph_0} = |\mathcal{F}| \leq \dim_{\mathbb{C}} A \leq |A| = 2^{\aleph_0},
$$
因此 $\dim_{\mathbb{C}} A = 2^{\aleph_0}$。

该论证仅使用了 ZFC 中的基本基数算术（可数个有限序列的并集，以及 $2^{\aleph_0} \c
dot 2^{\aleph_0} = 2^{\aleph_0}$）；不需要 GCH 或任何连续统假设的变体。下界来自
一个大小为 $|\mathbb{C}|$ 的显式线性无关族，而上界来自空间本身的基数。两者重合于
 $2^{\aleph_0}$，完全不需要对 $\aleph_0$ 和 $2^{\aleph_0}$ 之间的基数做出假设。
