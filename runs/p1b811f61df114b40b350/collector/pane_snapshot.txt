## Solution

We compare logarithms (base 2). The comparison $2^{p_n}$ vs $p_{2^n}$ is equival
ent to comparing

$$p_n \quad \text{vs} \quad \log_2 p_{2^n}.$$

**Estimating $p_n$ from below.** By the Prime Number Theorem, $p_k \sim k\ln k$.
 A standard effective bound (Rosser's theorem) gives, for all $k \geq 1$:

$$p_k > k\ln k.$$

In particular $p_n > n \ln n$ for all $n \geq 1$.

**Estimating $p_{2^n}$ from above.** Rosser's theorem also gives $p_k < k(\ln k
+ \ln\ln k)$ for $k \geq 6$. For $k = 2^n$ with $n$ large:

$$p_{2^n} < 2^n\bigl(n\ln 2 + \ln(n\ln 2)\bigr) < 2^n \cdot 2n\ln 2 = n\ln 2 \cd
ot 2^{n+1},$$

where we used $\ln(n\ln 2) < n\ln 2$ for large $n$. Therefore

$$\log_2 p_{2^n} < \log_2\!\bigl(n\ln 2 \cdot 2^{n+1}\bigr) = n + 1 + \log_2 n +
 \log_2\ln 2.$$

**Comparing.** We need to verify

$$n\ln n \;<\; p_n \quad\text{and}\quad \log_2 p_{2^n} \;<\; n + 1 + \log_2 n +
\log_2\ln 2,$$

so it suffices to show

$$n\ln n \;>\; n + 1 + \log_2 n + \log_2\ln 2 \qquad\text{for large } n.$$

The left side is $n\ln n$ and the right side is $n + O(\log n)$. Since

$$\frac{n\ln n}{n + O(\log n)} \;\longrightarrow\; \ln n \;\longrightarrow\; \in
fty,$$

the inequality holds for all sufficiently large $n$. Concretely, for $n \geq 20$

n 2 \approx 20 + 1 + 4.3 - 0.53 \approx 24.8$, and the gap only widens.

**Conclusion.** For all sufficiently large $n$,

$$p_n \;>\; \log_2 p_{2^n},$$

which is equivalent to

$$\boxed{2^{p_n} > p_{2^n}}.$$

The growth rates make this clear: $2^{p_n} = 2^{\Theta(n\ln n)}$ grows super-exp
onentially in $n$, while $p_{2^n} = \Theta(2^n \cdot n)$ grows only exponentiall
y in $n$.
