Looking at this problem, I need to determine whether there exists a smooth, comp
actly supported $f$ with $|\partial^{N+1}f(x)| > C\sum_{k=0}^{N}|\partial^k f(x)
|$ at a given point $x$.

**Answer: Yes, such a function always exists.**

**Proof.**

Let $\psi \in C_c^\infty(\mathbb{R})$ be any nonzero smooth bump function with $
\psi(0) \neq 0$ (for instance, $\psi(t) = e^{-1/(1-t^2)}$ for $|t|<1$, $\psi(t)=
0$ for $|t|\geq 1$, scaled so $\psi(0)\neq 0$).

Define
$$\phi(t) = t^{N+1}\,\psi(t).$$

Since $\psi$ has compact support, so does $\phi$ (as $\phi(t)=0$ whenever $\psi(
t)=0$). Clearly $\phi$ is smooth.

**Claim:** $\phi^{(k)}(0) = 0$ for $k = 0, 1, \dots, N$, and $\phi^{(N+1)}(0) =
(N+1)!\,\psi(0) \neq 0$.

By the Leibniz rule:
$$\phi^{(k)}(0) = \sum_{j=0}^{k} \binom{k}{j}\, (t^{N+1})^{(j)}\big|_{t=0} \cdot
 \psi^{(k-j)}(0).$$

For $j < N+1$, the derivative $(t^{N+1})^{(j)}$ is a polynomial whose lowest-deg
ree term is $t^{N+1-j}$, so $(t^{N+1})^{(j)}\big|_{t=0} = 0$. For $k \leq N$, ev
ery term has $j \leq k \leq N < N+1$, so all terms vanish:

$$\phi^{(k)}(0) = 0, \quad k = 0, 1, \dots, N.$$

For $k = N+1$, the only surviving term is $j = N+1$:
$$\phi^{(N+1)}(0) = \binom{N+1}{N+1}(N+1)!\,\psi(0) = (N+1)!\,\psi(0) \neq 0.$$

Now set
$$f(t) = \phi(t - x) = (t-x)^{N+1}\,\psi(t-x).$$

This $f$ is smooth and compactly supported. At $t = x$:
$$\partial^k f(x) = \phi^{(k)}(0).$$

Therefore:
- For $k = 0, 1, \dots, N$: $\partial^k f(x) = 0$.
- $\partial^{N+1} f(x) = (N+1)!\,\psi(0) \neq 0$.

The right-hand side of the desired inequality is:
$$C\sum_{k=0}^{N}|\partial^k f(x)| = C \cdot 0 = 0,$$

while the left-hand side is:
$$|\partial^{N+1} f(x)| = (N+1)!\,|\psi(0)| > 0.$$

Thus $|\partial^{N+1}f(x)| > C\sum_{k=0}^{N}|\partial^k f(x)|$ holds.

**Key idea:** By choosing $f$ to vanish to exactly order $N+1$ at the point $x$
(via the factor $(t-x)^{N+1}$), all derivatives of order $\leq N$ are zero there
, making the right-hand side vanish while the $(N+1)$-th derivative remains nonz
ero. This works for every $N \geq 0$, every $C > 0$, and every $x \in \mathbb{R}
$. $\blacksquare$
