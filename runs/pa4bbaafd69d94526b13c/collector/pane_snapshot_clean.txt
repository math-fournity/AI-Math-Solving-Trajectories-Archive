### Setup

Let $\alpha = 2\cos(2\pi/7)$, $\beta = 2\cos(4\pi/7)$, $\gamma = 2\cos(6\pi/7)$.
 These are the three roots of the polynomial
$$p(t) = t^3 + t^2 - 2t - 1.$$

### The roots are irrational

By the Rational Root Theorem, the only possible rational roots of $p(t)$ are $\p
m 1$. Since $p(1) = 1+1-2-1 = -1 \neq 0$ and $p(-1) = -1+1+2-1 = 1 \neq 0$, the
polynomial has no rational roots. Being a cubic with no rational root, it is irr
educible over $\mathbb{Q}$, so all three roots $\alpha, \beta, \gamma$ are **irr
ational**.

### Vieta's formulas

From $p(t) = t^3 + t^2 - 2t - 1$:
$$\alpha + \beta + \gamma = -1, \qquad \alpha\beta + \alpha\gamma + \beta\gamma
= -2, \qquad \alpha\beta\gamma = 1.$$

### Construction

Define three linear forms in variables $x, y, z$:
$$f_1 = \alpha\, x + y + z, \qquad f_2 = \beta\, x + y + z, \qquad f_3 = \gamma\
, x + y + z.$$

Each $f_i$ is a linear form in three variables with an irrational coefficient (t
he coefficient of $x$), so each is an **irrational linear form**.

### Computing the product

Set $u = y + z$. Then:
$$f_1 f_2 f_3 = (\alpha x + u)(\beta x + u)(\gamma x + u).$$

Expanding as a polynomial in $u$ and $x$:
$$= u^3 + (\alpha+\beta+\gamma)\,u^2 x + (\alpha\beta+\alpha\gamma+\beta\gamma)\
,u\,x^2 + \alpha\beta\gamma\, x^3.$$

Substituting Vieta's formulas:
$$= u^3 - u^2 x - 2u\,x^2 + x^3.$$

Replacing $u = y+z$ and expanding:
$$= (y+z)^3 - (y+z)^2 x - 2(y+z)x^2 + x^3$$
$$= x^3 + y^3 + z^3 + 3y^2z + 3yz^2 - xy^2 - 2xyz - xz^2 - 2x^2 y - 2x^2 z.$$

**Every coefficient is an integer.** $\blacksquare$
