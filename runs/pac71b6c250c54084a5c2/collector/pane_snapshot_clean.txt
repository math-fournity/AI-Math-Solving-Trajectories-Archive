## Solution

Let $N = 10^n - 1$, so we study $N^N = (10^n-1)^{10^n-1}$.

**Step 1: Compute $\log_{10}(N^N)$.**

$$\log_{10}(N^N) = (10^n-1)\log_{10}(10^n-1).$$

Since $\log_{10}(10^n-1) = n + \log_{10}(1-10^{-n})$,

$$\log_{10}(N^N) = (10^n-1)n + (10^n-1)\log_{10}(1-10^{-n}).$$

The first term is the integer $n\cdot 10^n - n$.

**Step 2: Asymptotics of the second term.**

Let $x = 10^{-n}$. Using $\log_{10}(1-x) = -\frac{1}{\ln 10}\sum_{k\ge 1}\frac{x
^k}{k}$ and $10^n - 1 = \frac{1-x}{x}$:

$$(10^n-1)\log_{10}(1-10^{-n}) = \frac{1-x}{x}\cdot\frac{-\sum_{k\ge1}x^k/k}{\ln
 10}.$$

Now $(1-x)\sum_{k\ge1}\frac{x^k}{k} = x - \frac{x^2}{2} - \frac{x^3}{6}-\cdots$,
 so dividing by $x$:

$$= \frac{-(1 - x/2 - x^2/6 - \cdots)}{\ln 10} \xrightarrow{n\to\infty} -\frac{1
}{\ln 10}.$$

Therefore
$$\log_{10}(N^N) = \underbrace{n\cdot 10^n - n}_{\text{integer}} - \frac{1}{\ln
10} + \varepsilon_n, \qquad \varepsilon_n \to 0^+.$$

**Step 3: Fractional part.**

Since $n\cdot 10^n - n$ is an integer, the fractional part of $\log_{10}(N^N)$ i
s
$$\alpha_n = \left\{-\frac{1}{\ln 10} + \varepsilon_n\right\} \to \left\{-\frac{
1}{\ln 10}\right\} = 1 - \frac{1}{\ln 10},$$
using $\frac{1}{\ln 10} = \log_{10} e \approx 0.4343\ldots \in (0,1)$.

**Step 4: Extract the first $n$ digits.**

Writing $\log_{10}(N^N) = D_n + \alpha_n$ with $D_n = \lfloor\log_{10}(N^N)\rflo
or$, the number of digits is $D_n+1$, and the first $n$ digits are

$$f(n) = \left\lfloor \frac{N^N}{10^{D_n+1-n}}\right\rfloor = \left\lfloor 10^{\
alpha_n + n - 1}\right\rfloor.$$

Hence
$$\frac{f(n)}{10^n} = \frac{\lfloor 10^n\cdot 10^{\alpha_n-1}\rfloor}{10^n} = 10
^{\alpha_n-1} - \frac{\{10^n\cdot 10^{\alpha_n-1}\}}{10^n}.$$

The fractional-part term is bounded by $1/10^n \to 0$, so

$$\lim_{n\to\infty}\frac{f(n)}{10^n} = \lim_{n\to\infty}10^{\alpha_n - 1} = 10^{
-1/\ln 10}.$$

**Step 5: Simplify.**

Since $10 = e^{\ln 10}$,
$$10^{-1/\ln 10} = e^{(\ln 10)\cdot(-1/\ln 10)} = e^{-1} = \frac{1}{e}.$$

$$\boxed{\lim_{n\to\infty}\frac{f(n)}{10^n} = \frac{1}{e}}$$
