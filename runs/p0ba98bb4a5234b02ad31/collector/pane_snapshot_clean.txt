Yes, such a polynomial-time algorithm exists. Here is the proof.

## Proof

Recall the definition. For the polyhedron $P = \{x \in \mathbb{R}^n : Ax \leq b\
}$ with $A \in \mathbb{R}^{m \times n}$, a point $z \in \mathbb{R}^n$ is a **bas
ic feasible solution** (BFS) if and only if:

1. **Feasibility:** $Az \leq b$ (i.e., $z \in P$), and
2. **Subspace condition:** the set of active constraints at $z$ contains $n$ lin
early independent ones. Equivalently, letting
$$I(z) = \{i \in \{1,\dots,m\} : a_i^\top z = b_i\}$$
be the active set (where $a_i^\top$ is the $i$-th row of $A$), the submatrix $A_
{I(z)} \in \mathbb{R}^{|I(z)| \times n}$ has rank $n$.

We give an explicit polynomial-time algorithm to test both conditions.

### Step 1 — Feasibility check

Compute the matrix–vector product $Az$ (cost $O(mn)$) and verify $Az \leq b$ com
ponentwise (cost $O(m)$). If any component $(Az)_i > b_i$, output **"not a BFS"*
* and halt. Otherwise $z$ is feasible.

### Step 2 — Identify the active set

For each $i \in \{1,\dots,m\}$, check whether $a_i^\top z = b_i$ (exact equality
 of real numbers; in a bit-complexity / rational-input model this is an exact co
mparison, cost $O(n)$ per row, total $O(mn)$). Collect
$$I(z) = \{i : a_i^\top z = b_i\}.$$

### Step 3 — Rank check

Form the submatrix $A_{I(z)}$ consisting of the rows of $A$ indexed by $I(z)$. T
his matrix has $|I(z)| \leq m$ rows and $n$ columns. Compute its rank via Gaussi
an elimination (row reduction to row-echelon form). The cost is $O(m n \min(m,n)
)$ arithmetic operations, which is polynomial in $m$ and $n$.

- If $\operatorname{rank}(A_{I(z)}) = n$, then $z$ is a BFS — output **"yes, $z$
 is a BFS."**
- If $\operatorname{rank}(A_{I(z)}) < n$, then $z$ is not a BFS — output **"no."
**

### Correctness

The algorithm is correct because it directly implements the definition of a BFS:

- Step 1 verifies feasibility, which is necessary for being a BFS.
- Steps 2–3 verify the subspace condition: a feasible point $z$ is a vertex (BFS
) of $P$ exactly when the active constraint normals span $\mathbb{R}^n$, i.e., w
hen $\operatorname{rank}(A_{I(z)}) = n$. (This is the standard characterization:
 $z$ is a BFS iff it is feasible and the active constraints at $z$ determine it
uniquely, which happens iff the active normals span the whole space.)

A feasible point that is not a BFS is either not a vertex at all (active normals
 span a subspace of dimension $< n$, so $z$ lies in the relative interior of a f
ace of dimension $\geq 1$) or infeasible — both cases are caught.

### Complexity

All three steps use only polynomial-time operations:
- Matrix–vector product and comparison: $O(mn)$.
- Active-set identification: $O(mn)$.
- Gaussian elimination for rank: $O(m n \min(m,n))$ arithmetic operations (polyn
omial, and polynomial in bit complexity when the input is rational).

The total running time is polynomial in $m$ and $n$.

### Conclusion

There exists a polynomial-time algorithm to check whether a given point $z \in \
mathbb{R}^n$ is a basic feasible solution of $P = \{x : Ax \leq b\}$: verify fea
sibility ($Az \leq b$), identify the active constraints, and check that the acti
ve constraint matrix has rank $n$ via Gaussian elimination. Each step is polynom
ial time.
