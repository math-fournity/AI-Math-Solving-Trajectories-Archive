## Proof

The velocity profile is $v(t) = \frac{1}{3}t^3 + \frac{p}{2}t^2 + qt + 10$.

**Step 1: Monotonicity condition.**

A cubic is one-to-one over $\mathbb{R}$ if and only if it is strictly monotonic.
 Taking the derivative:

$$v'(t) = t^2 + pt + q.$$

This is a quadratic in $t$ with leading coefficient $1 > 0$, so $v'(t) \to +\inf
ty$ as $t \to \pm\infty$. Therefore $v'(t) \leq 0$ for all $t$ is impossible. Th
e only possibility is $v'(t) \geq 0$ for all $t$.

For $v'(t) = t^2 + pt + q \geq 0$ for all real $t$, the discriminant must satisf
y:

$$\Delta = p^2 - 4q \leq 0 \quad \Longleftrightarrow \quad q \geq \frac{p^2}{4}.
$$

When $\Delta < 0$, we have $v'(t) > 0$ everywhere (strictly increasing). When $\
Delta = 0$, $v'(t) = (t + p/2)^2 \geq 0$ with equality at the single point $t =
-p/2$; since $v'$ vanishes only at an isolated point, $v$ is still strictly incr
easing (as with $t^3$ at the origin). Thus the condition is exactly $q \geq p^2/
4$.

**Step 2: Count valid pairs.**

For each $p \in \{1, \ldots, 10\}$, count $q \in \{1, \ldots, 10\}$ with $q \geq
 p^2/4$:

| $p$ | $p^2/4$ | Valid $q$ range | Count |
|-----|---------|-----------------|-------|
| 1 | 0.25 | $\{1,\ldots,10\}$ | 10 |
| 2 | 1 | $\{1,\ldots,10\}$ | 10 |
| 3 | 2.25 | $\{3,\ldots,10\}$ | 8 |
| 4 | 4 | $\{4,\ldots,10\}$ | 7 |
| 5 | 6.25 | $\{7,\ldots,10\}$ | 4 |
| 6 | 9 | $\{9, 10\}$ | 2 |
| 7 | 12.25 | none | 0 |
| 8 | 16 | none | 0 |
| 9 | 20.25 | none | 0 |
| 10 | 25 | none | 0 |

**Step 3: Total.**

$$10 + 10 + 8 + 7 + 4 + 2 = 41.$$

The number of unique pairs $(p, q)$ is $\boxed{41}$.
