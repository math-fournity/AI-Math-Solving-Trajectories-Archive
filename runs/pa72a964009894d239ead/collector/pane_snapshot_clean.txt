## Proof

**Step 1: Analyze the given parametrization.**

With r(θ,φ) = (3cosθ sinφ, 3sinθ sinφ, cosφ), the normal is ∂r/∂θ × ∂r/∂φ, whose
 third component is:

$$(-3\sin\theta\sin\varphi)(3\sin\theta\cos\varphi) - (3\cos\theta\sin\varphi)(3
\cos\theta\cos\varphi) = -9\sin\varphi\cos\varphi$$

Over φ ∈ [π/2, 3π/2], the sign of −9 sinφ cosφ is **not consistent**: it is posi
tive for φ ∈ (π/2, π) and negative for φ ∈ (π, 3π/2). Furthermore, the parametri
zation **double-covers** the lower hemisphere — the point (3√3/2, 0, −1/2) is hi
t by both (θ,φ)=(0, 2π/3) and (θ,φ)=(π, 4π/3) — with opposite orientations on ea
ch cover. So a naive pullback integral over the full domain [0,2π]×[π/2, 3π/2] y
ields 0 due to cancellation, which is **not** the correct oriented integral.

**Step 2: Use the graph parametrization with correct orientation.**

Write the lower hemisphere as z = g(x,y) = −√(1 − x²/9 − y²/9) over the disk D =
 {(x,y) : x² + y² ≤ 9}.

$$g_x = \frac{x}{9\sqrt{1 - x^2/9 - y^2/9}}, \quad g_y = \frac{y}{9\sqrt{1 - x^2
/9 - y^2/9}}$$

Rewrite ω in standard form: ω = x dx∧dy + x dy∧dz + dz∧dx (since −dx∧dz = dz∧dx)
, so P = x, Q = 1, R = x.

For the parametrization (x, y, g(x,y)), the pullback of P dy∧dz + Q dz∧dx + R dx
∧dy is R − Pg_x − Qg_y (this corresponds to the **upward** normal (−g_x, −g_y, 1
)). Since we want the **downward** orientation (negative third component), we ne
gate:

$$\iint_S \omega = -\iint_D \left(x - \frac{x^2}{9\sqrt{u}} - \frac{y}{9\sqrt{u}
}\right) dx\,dy$$

where u = 1 − (x²+y²)/9.

**Step 3: Convert to polar coordinates.**

Set x = r cosθ, y = r sinθ, r ∈ [0,3], θ ∈ [0,2π]:

$$= -\int_0^{2\pi}\int_0^3 \left(r\cos\theta - \frac{r^2\cos^2\theta}{9\sqrt{1-r
^2/9}} - \frac{r\sin\theta}{9\sqrt{1-r^2/9}}\right) r\,dr\,d\theta$$

Integrating over θ: ∫₀²π cosθ dθ = 0, ∫₀²π sinθ dθ = 0, ∫₀²π cos²θ dθ = π. Only
the cos²θ term survives:

$$= \pi \int_0^3 \frac{r^3}{9\sqrt{1 - r^2/9}}\,dr$$

**Step 4: Evaluate the radial integral.**

Substitute t = r²/9, so r = 3√t, dr = 3/(2√t) dt, r³ = 27t^{3/2}:

$$\int_0^3 \frac{r^3}{9\sqrt{1-r^2/9}}\,dr = \int_0^1 \frac{27t^{3/2}}{9\sqrt{1-
t}} \cdot \frac{3}{2\sqrt{t}}\,dt = \frac{9}{2}\int_0^1 t(1-t)^{-1/2}\,dt$$

By the Beta function: ∫₀¹ t^{a−1}(1−t)^{b−1} dt = B(a,b). Here a = 2, b = 1/2:

$$B(2, \tfrac{1}{2}) = \frac{\Gamma(2)\,\Gamma(1/2)}{\Gamma(5/2)} = \frac{1 \cdo
t \sqrt{\pi}}{3\sqrt{\pi}/4} = \frac{4}{3}$$

So the radial integral = (9/2)(4/3) = **6**.

**Step 5: Final result.**

$$\iint_S \omega = \pi \cdot 6 = 6\pi$$

**Verification via the given parametrization (corrected domain):** Using φ ∈ [π/
2, π] only (single cover), the pullback is −27cosθ sin²φ cosφ − 9cos²θ sin³φ − 3
sinθ sin²φ. The θ-integration kills the first and third terms, leaving −9π ∫_{π/
2}^{π} sin³φ dφ = −9π · (2/3) = −6π. Since this domain gives the **upward** norm
al, we negate for the downward orientation: −(−6π) = **6π**. ✓

The two approaches agree.

$$\boxed{\iint_S \omega = 6\pi}$$
