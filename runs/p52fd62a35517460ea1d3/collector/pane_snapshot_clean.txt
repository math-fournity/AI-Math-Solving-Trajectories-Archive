**Setup.** Let $B$ be the origin. Set $\vec{BA} = \vec{a}$, $\vec{BC} = \vec{c}$

\cos\beta$ where $\beta = \angle ABC$.

Since $M$ is the midpoint of $AC$: $M = \frac{\vec{a}+\vec{c}}{2}$, so $BM^2 = \
frac{|\vec{a}+\vec{c}|^2}{4} = \frac{a^2 + 2\vec{a}\cdot\vec{c} + c^2}{4}$.

Since $P$ lies on side $AB$ and $Q$ on side $BC$, write $P = t\,\vec{a}$, $Q = s
\,\vec{c}$ for some $t, s > 0$.

Since $BPTQ$ is a parallelogram (vertices in order $B, P, T, Q$), we get $\vec{B
T} = \vec{BP} + \vec{BQ}$, so:
$$T = t\,\vec{a} + s\,\vec{c}, \qquad BT^2 = t^2 a^2 + 2ts\,(\vec{a}\cdot\vec{c}
) + s^2 c^2.$$

**Concyclicity of $B, P, Q, M$.** A circle through the origin has equation $|x|^
2 = \vec{d}\cdot x$ for some vector $\vec{d}$. Requiring $P$, $Q$, $M$ to lie on
 it:

- From $P$: $\vec{d}\cdot\vec{a} = t\,a^2$
- From $Q$: $\vec{d}\cdot\vec{c} = s\,c^2$
- From $M$: $\vec{d}\cdot\frac{\vec{a}+\vec{c}}{2} = \frac{|\vec{a}+\vec{c}|^2}{
4}$, i.e., $\vec{d}\cdot\vec{a} + \vec{d}\cdot\vec{c} = \frac{|\vec{a}+\vec{c}|^
2}{2}$.

Combining:
$$t\,a^2 + s\,c^2 = \frac{a^2 + 2\,\vec{a}\cdot\vec{c} + c^2}{2}. \tag{1}$$

**Circumcircle condition.** The circumcircle of $ABC$ passes through $B=0$, $A=\
vec{a}$, $C=\vec{c}$, so it has equation $|x|^2 = \vec{e}\cdot x$ with $\vec{e}\
cdot\vec{a} = a^2$ and $\vec{e}\cdot\vec{c} = c^2$. The condition $T$ lies on th

$$BT^2 = \vec{e}\cdot T = t\,a^2 + s\,c^2. \tag{2}$$

**Combining (1) and (2):**
$$BT^2 = t\,a^2 + s\,c^2 = \frac{a^2 + 2\,\vec{a}\cdot\vec{c} + c^2}{2} = \frac{
|\vec{a}+\vec{c}|^2}{2} = 2\cdot\frac{|\vec{a}+\vec{c}|^2}{4} = 2\,BM^2.$$

Therefore:
$$\frac{BT^2}{BM^2} = 2 \implies \frac{BT}{BM} = \sqrt{2}.$$
