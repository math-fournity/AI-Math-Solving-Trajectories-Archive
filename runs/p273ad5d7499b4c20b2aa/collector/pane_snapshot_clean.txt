## Proof

**Claim:** Yes, there exist positive integer solutions.

**Construction.** Let $a_i = i$ for $i = 1, 2, \ldots, 1985$. These are 1985 dis
tinct positive integers. Define
$$S_2 = \sum_{i=1}^{1985} a_i^2 = \sum_{i=1}^{1985} i^2, \qquad S_3 = \sum_{i=1}
^{1985} a_i^3 = \sum_{i=1}^{1985} i^3.$$
Both $S_2$ and $S_3$ are fixed positive integers. We will find a positive intege
r $t$ such that, setting $x_i = t \cdot a_i = t \cdot i$, the two required condi
tions are satisfied.

Since the $a_i$ are distinct and $t > 0$, the $x_i = ti$ are also 1985 distinct
positive integers. We compute:
$$\sum_{i=1}^{1985} x_i^2 = t^2 \sum_{i=1}^{1985} a_i^2 = t^2 S_2, \qquad \sum_{
i=1}^{1985} x_i^3 = t^3 \sum_{i=1}^{1985} a_i^3 = t^3 S_3.$$

We need $t^2 S_2 = y^3$ and $t^3 S_3 = z^2$ for some positive integers $y, z$.

**Choosing $t$ via prime factorizations and CRT.** Write the prime factorization
s
$$S_2 = \prod_p p^{\alpha_p}, \qquad S_3 = \prod_p p^{\beta_p},$$
where $\alpha_p, \beta_p \geq 0$ and only finitely many are nonzero. We seek $t
= \prod_p p^{\gamma_p}$ (over primes dividing $S_2 S_3$) with each $\gamma_p \ge
q 0$ satisfying:

1. **Cube condition** $t^2 S_2 = y^3$: for every prime $p$,
$$\alpha_p + 2\gamma_p \equiv 0 \pmod{3}.$$

2. **Square condition** $t^3 S_3 = z^2$: for every prime $p$,
$$\beta_p + 3\gamma_p \equiv 0 \pmod{2}.$$

**Simplifying the congruences.**

- From condition 1: $2\gamma_p \equiv -\alpha_p \pmod{3}$. Multiplying by $2$ (t
he inverse of $2$ mod $3$): $\gamma_p \equiv -2\alpha_p \equiv \alpha_p \pmod{3}
$ (since $-2 \equiv 1 \pmod{3}$).

- From condition 2: $3\gamma_p \equiv \gamma_p \pmod{2}$, so $\beta_p + \gamma_p
 \equiv 0 \pmod{2}$, i.e., $\gamma_p \equiv \beta_p \pmod{2}$.

Thus for each prime $p$ we need:
$$\gamma_p \equiv \alpha_p \pmod{3}, \qquad \gamma_p \equiv \beta_p \pmod{2}.$$

**Applying the Chinese Remainder Theorem.** Since $\gcd(2, 3) = 1$, by CRT there
 exists a unique residue class $\gamma_p$ modulo $6$ satisfying both congruences
 simultaneously. We choose the representative $\gamma_p \in \{0, 1, 2, 3, 4, 5\}
$, which is non-negative. This works for every prime $p$ dividing $S_2$ or $S_3$
:

- If $p \mid S_2$ but $p \nmid S_3$: then $\beta_p = 0$, so $\gamma_p \equiv 0 \
pmod{2}$ and $\gamma_p \equiv \alpha_p \pmod{3}$ — solvable by CRT.
- If $p \mid S_3$ but $p \nmid S_2$: then $\alpha_p = 0$, so $\gamma_p \equiv 0
\pmod{3}$ and $\gamma_p \equiv \beta_p \pmod{2}$ — solvable by CRT.
- If $p \mid \gcd(S_2, S_3)$: both congruences are nontrivial but CRT still appl
ies.

Set $t = \prod_{p \mid S_2 S_3} p^{\gamma_p}$, a positive integer.

**Verification.**

- **Cube:** $t^2 S_2 = \prod_p p^{\alpha_p + 2\gamma_p}$. By construction $\alph
a_p + 2\gamma_p \equiv 0 \pmod{3}$ for all $p$, and $\alpha_p + 2\gamma_p \geq 0
$. Hence $y = \prod_p p^{(\alpha_p + 2\gamma_p)/3}$ is a positive integer with $
y^3 = t^2 S_2$. ✓

- **Square:** $t^3 S_3 = \prod_p p^{\beta_p + 3\gamma_p}$. By construction $\bet
a_p + 3\gamma_p \equiv 0 \pmod{2}$ for all $p$, and $\beta_p + 3\gamma_p \geq 0$
. Hence $z = \prod_p p^{(\beta_p + 3\gamma_p)/2}$ is a positive integer with $z^
2 = t^3 S_3$. ✓

- **Distinctness:** $x_i = ti$ for $i = 1, \ldots, 1985$ are distinct positive i
ntegers since $t \geq 1$. ✓

**Conclusion.** The positive integers $x_i = ti$ ($i = 1, \ldots, 1985$), togeth
er with $y$ and $z$ as constructed above, satisfy both equations with all $x_i$
distinct. Therefore, positive integer solutions exist.
