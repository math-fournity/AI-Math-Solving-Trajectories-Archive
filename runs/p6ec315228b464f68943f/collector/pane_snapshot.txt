Looking at this problem, I need to find all integer angle triples (A, B, C) with
 A+B+C=180°, no right angle, satisfying three geometric conditions involving the
 circumcenter O.

## Setting Up Conditions (a) and (b)

**Condition (a):** Circle through P, O, A tangent to line BO, with P on segment
AB (P ≠ A).

Since O lies on both the circle and line BO, tangency must occur at O. By the **
power of point B** with respect to this circle: the tangent BO gives BO² = BP ·
BA (secant through A and P).

With circumradius R: BO = R, BA = 2R sin C, so:
$$BP = \frac{R^2}{2R\sin C} = \frac{R}{2\sin C}, \quad AP = 2R\sin C - \frac{R}{
2\sin C}$$

For P on segment AB with P ≠ A: need 0 < BP < BA, i.e., $\frac{R}{2\sin C} < 2R\
sin C$, giving $\sin C > \frac{1}{2}$, i.e., **C > 30°**.

**Condition (b):** By identical reasoning with point C and line CO: **B > 30°**,
 with $CQ = \frac{R}{2\sin B}$, $AQ = 2R\sin B - \frac{R}{2\sin B}$.

## Analyzing Condition (c)

Condition (c) requires: AP + PQ + QA ≥ AB + AC.

Since AP = AB − BP and AQ = AC − CQ, this becomes:
$$PQ \geq BP + CQ = \frac{R}{2\sin C} + \frac{R}{2\sin B}$$

Setting R = 1 and using the law of cosines in triangle APQ (with angle A at vert
ex A), I compute:

$$PQ^2 - (BP+CQ)^2$$

After extensive algebraic simplification — substituting $u = \sin B$, $v = \sin
C$, using $uv = \frac{\cos(B-C)+\cos A}{2}$ and $u^2+v^2 = 1 + \cos A\cos(B-C)$
— all intermediate terms cancel dramatically, yielding:

$$PQ^2 - (BP+CQ)^2 = \frac{-(\cos 3A + 1)}{2\sin B\sin C}$$

Since $\sin B, \sin C > 0$, the sign depends entirely on $-(\cos 3A + 1)$.

**Key observation:** $\cos 3A + 1 \geq 0$ always (since $\cos 3A \geq -1$), so $
PQ^2 - (BP+CQ)^2 \leq 0$, meaning $PQ \leq BP + CQ$ always.

**Equality** (which satisfies the ≥ condition) holds iff $\cos 3A = -1$, i.e., $
3A = 180° + 360°k$, i.e., $A = 60° + 120°k$.

With $0 < A < 120°$ (since B, C > 30°), the only solution is **A = 60°**.

## Verification

For A = 60° (any valid B, C): $\cos 180° = -1$, so $PQ^2 - (BP+CQ)^2 = 0$, givin
g PQ = BP + CQ exactly, hence AP + PQ + QA = AB + AC. ✓

For A ≠ 60°: $PQ < BP + CQ$ strictly, so condition (c) fails. ✗

## Counting Valid Triples

With A = 60° fixed, B + C = 120°, and constraints:
- B > 30° (integer): B ≥ 31
- C > 30° (integer): C = 120 − B ≥ 31, so B ≤ 89
- No right angle: B ≠ 90° (automatic since B ≤ 89), C ≠ 90° (C = 90 iff B = 30,
excluded), A = 60 ≠ 90 ✓

B ranges from **31 to 89** inclusive, giving $89 - 31 + 1 = \mathbf{59}$ valid o
rdered triples.

Each pair (B, 120−B) with B ∈ [31, 89] yields a distinct ordered triple (60, B,
120−B), including the equilateral case (60, 60, 60) at B = 60.
