Looking at this problem, I need to find the minimum α for the strict Hahn–Banach
 separation of a point from a closed convex set, expressed via the distance.

**Answer:** α = −d(x₀, C), where d(x₀, C) = inf_{c∈C} ‖x₀ − c‖.

**Proof.**

Let d = d(x₀, C) = inf_{c ∈ C} ‖x₀ − c‖. Since C is closed and x₀ ∉ C, we have d
 > 0.

**Step 1 (Translation to the origin).** Set K = C − x₀ = {c − x₀ : c ∈ C}. Then
K is closed, convex, nonempty, and 0 ∉ K, with d(0, K) = d. The open ball B(0, d
) is open and convex, and B(0, d) ∩ K = ∅ (since every point of K is at distance
 ≥ d from 0).

**Step 2 (Existence of a separating functional with gap d).** By the Hahn–Banach
 separation theorem applied to the disjoint pair (K, B(0, d)) — a closed convex
set and an open convex set — there exists g ∈ E\* with ‖g‖ = 1 such that

  sup_{y ∈ K} Re g(y) ≤ inf_{z ∈ B(0,d)} Re g(z).

The right-hand side equals Re g(0) − d·‖g‖ = 0 − d = −d, since the infimum of Re
 g over the open ball of radius d is −d·‖g‖ = −d. Therefore

  sup_{y ∈ K} Re g(y) ≤ −d < 0 = Re g(0).

In particular, setting α = −d, we have Re g(y) ≤ α < Re g(0) for every y ∈ K.

**Step 3 (The minimum is exactly −d).** We show no value of α strictly less than
 −d can work (with ‖g‖ = 1). Suppose f ∈ E\* with ‖f‖ = 1 and Re f(y) ≤ α < Re f
(0) = 0 for all y ∈ K. Then for every y ∈ K,

  −α ≤ Re f(0) − Re f(y) = Re f(−y) ≤ |f(−y)| ≤ ‖f‖·‖y‖ = ‖y‖.

Taking the infimum over y ∈ K:

  −α ≤ inf_{y ∈ K} ‖y‖ = d(0, K) = d,

so α ≥ −d. Hence −d is a lower bound.

Combining Steps 2 and 3: α = −d is achievable (Step 2) and is a lower bound (Ste
p 3), so it is the minimum.

**Step 4 (Returning to the original coordinates).** For c ∈ C, write c = x₀ + y
with y ∈ K. With f = g,

  Re f(c) = Re g(x₀) + Re g(y) ≤ Re g(x₀) − d = Re f(x₀) − d.

Thus Re f(c) ≤ Re f(x₀) − d < Re f(x₀) for all c ∈ C, and the separating gap is

  Re f(x₀) − α = d = d(x₀, C).

The invariant content is: **the minimum separating gap Re f(x₀) − α equals d(x₀,
 C)**, attained by the Hahn–Banach functional of norm 1. Measuring α relative to
 Re f(x₀) (equivalently, after translating x₀ to the origin so that Re f(x₀) = 0
), the minimum value is

  **α = −d(x₀, C).**
