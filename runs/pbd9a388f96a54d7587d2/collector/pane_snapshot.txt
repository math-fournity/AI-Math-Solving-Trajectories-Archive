## Proof

**Setup.** Let $f(X) = X^3 + 3X^2 + aX$. The extension $\mathbb{C}(X)/\mathbb{C}
(Y)$ has degree $[ \mathbb{C}(X) : \mathbb{C}(Y) ] = \deg f = 3$ (for all $a$, s
ince the leading term is $X^3$). Since $\operatorname{char}\mathbb{C} = 0$, the
extension is separable. Thus it is Galois $\iff$ it is normal $\iff$ $|\operator
name{Aut}(\mathbb{C}(X)/\mathbb{C}(Y))| = 3$.

The automorphisms of $\mathbb{C}(X)/\mathbb{C}(Y)$ are precisely the Möbius tran
sformations $\phi \in \operatorname{PGL}_2(\mathbb{C})$ satisfying $f(\phi(X)) =
 f(X)$.

**Reduction to depressed cubic.** Set $U = X + 1$, so $X = U - 1$. Then:
$$f(X) = (U-1)^3 + 3(U-1)^2 + a(U-1) = U^3 + (a-3)U + (2-a).$$
Let $g(U) = U^3 + bU + c$ with $b = a-3$, $c = 2-a$. Since $\mathbb{C}(X) = \mat
hbb{C}(U)$ and $\mathbb{C}(Y) = \mathbb{C}(g(U))$, we seek Möbius transformation
s $\phi$ with $g(\phi(U)) = g(U)$.

**Möbius transformations must be affine.** Suppose $\phi(U) = \frac{\alpha U + \
beta}{\gamma U + \delta}$ with $\gamma \neq 0$. Then:
$$g(\phi(U)) = \frac{(\alpha U+\beta)^3 + b(\alpha U+\beta)(\gamma U+\delta)^2 +
 c(\gamma U+\delta)^3}{(\gamma U+\delta)^3}.$$
The numerator has degree $\leq 3$, while $(U^3+bU+c)(\gamma U+\delta)^3$ has deg
ree $6$ when $\gamma \neq 0$. Equality $g(\phi(U)) = g(U)$ would require the num
erator to equal $(U^3+bU+c)(\gamma U+\delta)^3$, impossible by degree comparison
. Hence $\gamma = 0$ and $\phi(U) = pU + q$ is affine.

**Solving the functional equation.** We need $g(pU+q) = g(U)$:
$$(pU+q)^3 + b(pU+q) + c = U^3 + bU + c.$$
Expanding and comparing coefficients:
- **$U^3$:** $p^3 = 1$, so $p \in \{1, \omega, \omega^2\}$ where $\omega = e^{2\
pi i/3}$.
- **$U^2$:** $3p^2 q = 0 \implies q = 0$ (since $p \neq 0$).
- **$U^1$:** $3pq^2 + bp = b \implies bp = b \implies b(p-1) = 0$.
- **$U^0$:** $q^3 + bq + c = c$, automatically satisfied since $q=0$.

**Case 1: $b = 0$ (i.e., $a = 3$).** The condition $b(p-1)=0$ is vacuous. All th
ree cube roots of unity give valid automorphisms: $U \mapsto U$, $U \mapsto \ome
ga U$, $U \mapsto \omega^2 U$. The automorphism group has order $3 = [\mathbb{C}
(X):\mathbb{C}(Y)]$, so the extension is **Galois**.

*Verification:* When $a=3$, $Y = X^3+3X^2+3X = (X+1)^3 - 1$, so $\mathbb{C}(Y) =
 \mathbb{C}((X+1)^3) \subset \mathbb{C}(X+1) = \mathbb{C}(X)$, which is the stan
dard cyclic Kummer extension of degree 3.

**Case 2: $b \neq 0$ (i.e., $a \neq 3$).** Then $p = 1$ (forced), and $q = 0$, g
iving only the identity automorphism. The group has order $1 < 3$, so the extens
ion is **not Galois**.

**Conclusion.** The extension $\mathbb{C}(X)/\mathbb{C}(Y)$ is Galois if and onl
y if $\boxed{a = 3}$.
