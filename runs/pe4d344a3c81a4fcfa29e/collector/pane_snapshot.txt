## Proof

**Goal:** Show $f(x) \sim \dfrac{1}{x}$ as $x \to 0^+$.

### Step 1 — Lower bound

For $n \geq 1$ and $x > 0$, we have $n^x \geq 1$, so:

$$f(x) = \sum_{n=1}^{\infty} n^x\, e^{-nx} \geq \sum_{n=1}^{\infty} e^{-nx} = \f
rac{e^{-x}}{1 - e^{-x}} = \frac{1}{e^x - 1} \sim \frac{1}{x} \quad (x \to 0^+).
\tag{1}$$

### Step 2 — Upper bound: showing $\sum (n^x - 1)\,e^{-nx} = o(1/x)$

Write $f(x) = \sum e^{-nx} + \sum (n^x - 1)\,e^{-nx}$. We show the correction te
rm is $o(1/x)$.

**Key inequality.** For $u \geq 0$, $e^u - 1 = \int_0^u e^t\,dt \leq e\,u$. Appl
ying with $u = x \ln n \geq 0$:

$$n^x - 1 = e^{x \ln n} - 1 \leq e\, x \ln n, \qquad n \geq 1.$$

Hence:

$$0 \leq \sum_{n=1}^{\infty} (n^x - 1)\,e^{-nx} \leq e\,x \sum_{n=1}^{\infty} \l
n n \cdot e^{-nx}. \tag{2}$$

**Using the hint** $\ln n = o(n)$: for any $\varepsilon > 0$, there exists $N =
N(\varepsilon)$ such that $\ln n \leq \varepsilon\, n$ for all $n \geq N$. Split
 the sum in (2):

$$\sum_{n=1}^{\infty} \ln n \cdot e^{-nx} = \underbrace{\sum_{n=1}^{N-1} \ln n \
cdot e^{-nx}}_{S_1} + \underbrace{\sum_{n=N}^{\infty} \ln n \cdot e^{-nx}}_{S_2}
.$$

- **$S_1$ (finitely many terms, $N$ fixed):** $S_1 \leq \sum_{n=1}^{N-1} \ln n =
 C(N)$, a constant independent of $x$.

- **$S_2$ (tail, using $\ln n \leq \varepsilon\, n$):**

$$S_2 \leq \varepsilon \sum_{n=N}^{\infty} n\, e^{-nx} \leq \varepsilon \sum_{n=
1}^{\infty} n\, e^{-nx} = \varepsilon \cdot \frac{e^{-x}}{(1 - e^{-x})^2} \sim \
frac{\varepsilon}{x^2} \quad (x \to 0^+).$$

Substituting back into (2):

$$\sum_{n=1}^{\infty} (n^x - 1)\,e^{-nx} \leq e\,x \left( C(N) + \frac{\varepsil
on}{x^2}\,(1 + o(1)) \right) = \frac{e\,\varepsilon}{x}\,(1 + o(1)) \;+\; \under
brace{e\,x\, C(N)}_{= o(1/x)}.$$

Therefore:

$$\limsup_{x \to 0^+}\; x \sum_{n=1}^{\infty} (n^x - 1)\,e^{-nx} \;\leq\; e\,\va
repsilon.$$

Since $\varepsilon > 0$ is **arbitrary**, taking $\varepsilon \to 0$:

$$\lim_{x \to 0^+}\; x \sum_{n=1}^{\infty} (n^x - 1)\,e^{-nx} = 0, \qquad\text{i
.e.,}\quad \sum_{n=1}^{\infty} (n^x - 1)\,e^{-nx} = o\!\left(\frac{1}{x}\right).
 \tag{3}$$

### Step 3 — Conclusion

Combining (1) and (3):

$$f(x) = \sum_{n=1}^{\infty} e^{-nx} + \sum_{n=1}^{\infty}(n^x - 1)\,e^{-nx} = \
frac{1}{e^x - 1} + o\!\left(\frac{1}{x}\right) \sim \frac{1}{x} \quad (x \to 0^+
).$$

**Remark on the method.** The hint $\ln n = o(n)$ (stated as "$n \ln n \sim n$")
 is the essential ingredient: it ensures that the factor $n^x = e^{x \ln n}$ is
asymptotically $1$ for the dominant range of $n \sim 1/x$, since $x \ln n \sim x
 \ln(1/x) = -x \ln x \to 0$. This allows us to replace $n^x$ by $1$ and reduce t
he problem to the geometric series $\sum e^{-nx} \sim 1/x$, **without invoking t
he $\Gamma$ function**. The convexity of $f$ guarantees the series is well-defin
ed on $(0,\infty)$ (each term $n^x e^{-nx}$ decays exponentially since $nx$ domi
nates $x \ln n$), but is not needed for the asymptotic itself.

$$\boxed{f(x) = \sum_{n=1}^{\infty} n^x\, e^{-nx} \;\sim\; \frac{1}{x} \quad \te
xt{as } x \to 0^+.}$$
