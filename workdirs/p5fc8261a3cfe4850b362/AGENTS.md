# Problem

In a specialized laboratory, a set of 100 chemical vials is arranged, each containing a unique concentrated solution labeled with a discrete integer concentration from 1 to 100 mg/L, such that every integer in that range is represented exactly once.

The lead chemist performs a sequence of reactions to consolidate these vials into a single final compound. In each step, the chemist selects any two vials currently on the shelf with concentrations $a$ and $b$, empties them, and replaces them with a new vial. The concentration of the new vial is determined by a specific stability formula:
$$f(a, b) = \gcd(a^2 + b^2 + 2, \ a^2b^2 + 3)$$

This procedure is repeated 99 times until only one vial remains on the shelf. Let $S$ represent the set containing every possible concentration value that this final vial could potentially possess, depending on the order in which the vials were combined.

Calculate the total number of elements within the set $S$ that are perfect squares.
