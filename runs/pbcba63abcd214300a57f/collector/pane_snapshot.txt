## Proof

The functional $T(f) = \int_0^2 f(x)\,dx - \int_3^{10} f(x)\,dx$ is linear on $L
^2[0,10]$. We identify its norm via the Riesz representation theorem.

Define $g \in L^2[0,10]$ by

$$g(x) = \begin{cases} 1, & 0 \le x \le 2, \\ 0, & 2 < x < 3, \\ -1, & 3 \le x \
le 10. \end{cases}$$

Then for every $f \in L^2[0,10]$,

$$T(f) = \int_0^2 f(x)\,dx - \int_3^{10} f(x)\,dx = \int_0^{10} f(x)\,g(x)\,dx =
 \langle f, g \rangle.$$

By the Cauchy–Schwarz inequality,

$$|T(f)| = |\langle f, g\rangle| \le \|f\|\cdot\|g\|,$$

so $\|T\| \le \|g\|$.

Conversely, taking $f = g$ (which belongs to $L^2[0,10]$) gives

$$T(g) = \langle g, g\rangle = \|g\|^2,$$

hence $|T(g)|/\|g\| = \|g\|$, so $\|T\| \ge \|g\|$.

Therefore $\|T\| = \|g\|$. Now compute:

$$\|g\|^2 = \int_0^{10} g(x)^2\,dx = \int_0^2 1\,dx + \int_2^3 0\,dx + \int_3^{1
0} 1\,dx = 2 + 0 + 7 = 9.$$

Thus $\|g\| = \sqrt{9} = 3$, and

$$\boxed{\|T\| = 3}.$$
