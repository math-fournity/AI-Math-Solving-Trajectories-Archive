# Problem

In the city of Arithmos, the Central Vault is protected by a unique digital passcode system. To set the master override code, the Chief Engineer must generate a sequence that satisfies a specific set of security protocols:

1. **Uniqueness Protocol**: The code must be a natural number where every individual digit used (0 through 9) appears exactly once. No digit can be repeated, and no digit can be omitted.
2. **Standardization Protocol**: To be recognized by the system’s legacy hardware, the entire number must be perfectly divisible by 990.
3. **Efficiency Protocol**: Among all possible numbers that satisfy the first two protocols, the engineer must select the smallest possible value.

What is the smallest natural number that satisfies these security requirements?
