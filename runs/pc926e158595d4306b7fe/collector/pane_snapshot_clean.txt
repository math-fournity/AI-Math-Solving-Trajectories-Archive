## Proof

### 1. Steady-State Formulation

Steady states satisfy the ODE boundary-value problem

$$u'' + \lambda e^{u} = 0, \qquad u(-1) = u(1) = 0.$$

The PDE and boundary/initial data are symmetric under $x \mapsto -x$, so we seek
 symmetric steady states with $u'(0)=0$. Set $a = u(0) \geq 0$ (the maximum of $
u$). It suffices to solve on $[0,1]$ with

$$u'(0) = 0, \quad u(0) = a, \quad u(1) = 0.$$

### 2. First Integral

Multiply $u'' + \lambda e^u = 0$ by $u'$:

$$\frac{d}{dx}\!\left[\tfrac{1}{2}(u')^2 + \lambda e^u\right] = 0 \implies \tfra
c{1}{2}(u')^2 + \lambda e^u = C.$$

Evaluating at $x=0$ ($u=a$, $u'=0$) gives $C = \lambda e^a$, hence

$$(u')^2 = 2\lambda\,(e^a - e^u).$$

On $[0,1]$, $u$ decreases from $a$ to $0$, so $u' = -\sqrt{2\lambda(e^a - e^u)}$
. Separating variables and integrating:

$$1 = \int_0^1 dx = \int_0^a \frac{du}{\sqrt{2\lambda\,(e^a - e^u)}} = \frac{1}{
\sqrt{2\lambda}}\int_0^a \frac{du}{\sqrt{e^a - e^u}}. \tag{$\star$}$$

### 3. Evaluating the Integral

Substitute $e^u = e^a \cos^2\!\varphi$, i.e., $u = a + 2\ln\cos\varphi$, $du = -
2\tan\varphi\,d\varphi$. Then $e^a - e^u = e^a\sin^2\!\varphi$, and the limits $
u=a \Rightarrow \varphi=0$, $u=0 \Rightarrow \cos^2\!\varphi_0 = e^{-a}$, i.e.,
$\varphi_0 = \arccos(e^{-a/2})$. The integral becomes

$$\int_0^a \frac{du}{\sqrt{e^a - e^u}} = \frac{2}{e^{a/2}}\int_0^{\varphi_0}\sec
\varphi\,d\varphi = \frac{2}{e^{a/2}}\ln\!\bigl(\sec\varphi_0 + \tan\varphi_0\bi
gr).$$

Now $\sec\varphi_0 = e^{a/2}$ and $\tan\varphi_0 = \sqrt{e^a - 1}$. Introduce $s
 \geq 0$ via $e^{a/2} = \cosh s$ (valid since $e^{a/2}\geq 1$). Then $\sqrt{e^a-
1} = \sinh s$, and

$$\sec\varphi_0 + \tan\varphi_0 = \cosh s + \sinh s = e^s, \qquad e^{-a/2} = \fr
ac{1}{\cosh s}.$$

So the integral equals $2s/\cosh s$, and $(\star)$ becomes

$$1 = \frac{1}{\sqrt{2\lambda}}\cdot\frac{2s}{\cosh s} = \sqrt{\frac{2}{\lambda}
}\,\frac{s}{\cosh s}.$$

Solving for $\lambda$:

$$\boxed{\lambda = f(s) := \frac{2s^2}{\cosh^2 s}, \qquad s \geq 0.}$$

Each $s \geq 0$ corresponds to a unique steady state with amplitude $a = 2\ln\co
sh s$, and conversely every symmetric steady state arises this way.

### 4. Existence of a Critical $\lambda_c$

Analyze $f(s) = 2s^2/\cosh^2 s$ on $[0,\infty)$:

- **Endpoints:** $f(0) = 0$; as $s\to\infty$, $\cosh s \sim \tfrac{1}{2}e^s$ so
$f(s)\sim 8s^2 e^{-2s}\to 0$.
- **Derivative:**

$$f'(s) = \frac{4s(\cosh s - s\sinh s)}{\cosh^3 s}.$$

So $f'(s)=0$ iff $s=0$ or $\cosh s = s\sinh s$, i.e.,

$$s\tanh s = 1. \tag{$\star\star$}$$

- **Uniqueness of the critical point:** Let $g(s) = s\tanh s$. Then $g(0)=0$, $g
'(s)=\tanh s + s\,\mathrm{sech}^2\!s > 0$ for $s>0$, and $g(s)\to\infty$. Hence
$g$ is strictly increasing and $(\star\star)$ has a **unique** positive solution
 $s^*$.

Therefore $f$ increases on $(0,s^*)$ and decreases on $(s^*,\infty)$, attaining
a **global maximum**

$$\lambda_c = f(s^*) = \frac{2(s^*)^2}{\cosh^2 s^*}.$$

### 5. Closed-Form Simplification

At $s^*$ we have $\tanh s^* = 1/s^*$, so

$$\cosh^2 s^* = \frac{1}{1-\tanh^2 s^*} = \frac{1}{1-1/(s^*)^2} = \frac{(s^*)^2}
{(s^*)^2-1}.$$

Substituting:

$$\lambda_c = \frac{2(s^*)^2}{(s^*)^2/((s^*)^2-1)} = 2\bigl((s^*)^2 - 1\bigr).$$

### 6. Numerical Value

Solving $s\tanh s = 1$:

| $s$ | $s\tanh s$ |
|-----|-----------|
| 1.19 | 0.9883 |
| 1.20 | 1.0004 |

gives $s^* \approx 1.1997$, hence

$$\lambda_c = 2(s^*)^2 - 2 \approx 2(1.4393) - 2 \approx 0.878.$$

### 7. Conclusion: Number of Steady States

Since $f:[0,\infty)\to[0,\lambda_c]$ is unimodal (increasing then decreasing) wi
th $f(0)=0$ and $f(\infty)=0$:

| Range of $\lambda$ | Number of steady states |
|---|---|
| $\lambda > \lambda_c$ | **0** (no steady state exists) |
| $\lambda = \lambda_c$ | **1** (the critical solution at $s=s^*$) |
| $0 < \lambda < \lambda_c$ | **2** (one lower-amplitude branch $s<s^*$, one upp
er-amplitude branch $s>s^*$) |
| $\lambda = 0$ | **1** (trivial solution $u\equiv 0$) |

**Yes**, there exists a critical value $\lambda_c$ such that for $\lambda > \lam
bda_c$ no steady-state solutions exist. It is

$$\boxed{\lambda_c = \frac{2(s^*)^2}{\cosh^2 s^*} = 2\bigl((s^*)^2 - 1\bigr) \ap
prox 0.878,}$$

where $s^*$ is the unique positive root of $s\tanh s = 1$ (equivalently $s = \co
th s$), numerically $s^* \approx 1.1997$.

For $\lambda > \lambda_c$ the nonlinear source $\lambda e^u$ is too strong to be
 balanced by diffusion over the domain $[-1,1]$, so no steady state can exist; t
he time-dependent solution blows up in finite time. For $0 < \lambda < \lambda_c
$ there are exactly two steady states (a stable lower branch and an unstable upp
er branch), and at $\lambda = \lambda_c$ they coalesce in a saddle-node bifurcat
ion.
