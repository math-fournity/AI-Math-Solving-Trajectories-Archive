## Proof

**Step 2: Reduce to semisimplicity of $A$.** A standard result (via Morita equiv
alence) states:

> $M_k(R)$ is semisimple as a left module over itself if and only if $R$ is semi
simple as a left module over itself.

*Justification:* The functor $F: R\text{-Mod} \to M_k(R)\text{-Mod}$ given by $F
(N) = N^k$ (column vectors) is an equivalence of categories, with inverse $G(M)
= e_{11}M$. This equivalence preserves simple modules, direct sums, and submodul
es. In particular, ${}_{M_k(R)}M_k(R)$ is semisimple if and only if ${}_R R$ is
semisimple.

Applying this with $k=2$: $R_n = M_2(A)$ is semisimple if and only if $A$ is sem
isimple.

**Step 3: Analyze $A = \mathbb{C}[x]/(x-\alpha)^n$.** The ring $A$ is a commutat

- Unique maximal ideal $\mathfrak{m} = (x-\alpha)/(x-\alpha)^n$,
- Residue field $A/\mathfrak{m} \cong \mathbb{C}$,
- Jacobson radical $J(A) = \mathfrak{m}$.

A commutative Artinian ring is semisimple if and only if its Jacobson radical is
 zero (equivalently, it is a finite direct product of fields). Since $A$ is loca
l, it is semisimple if and only if $\mathfrak{m} = 0$.

**Step 4: Determine when $\mathfrak{m} = 0$.**

- **$n = 1$:** $A = \mathbb{C}[x]/(x-\alpha) \cong \mathbb{C}$, a field. Here $\
mathfrak{m} = (x-\alpha)/(x-\alpha) = 0$, so $A$ is semisimple.

For $n \geq 2$: As a left $M_2(A)$-module, $M_2(A) \cong (A^2)^{\oplus 2}$ (two

**Conclusion.** The ring $R_n$ is semisimple if and only if $n = 1$.
