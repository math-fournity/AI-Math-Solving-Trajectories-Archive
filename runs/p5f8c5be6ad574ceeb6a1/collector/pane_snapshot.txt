## Proof

**Setup and relabeling.** The condition states: for every n, d(P_n, P_m) ≥ r_n^α
 for all m ≠ n. Since distance is symmetric, applying the condition to m gives d
(P_m, P_n) ≥ r_m^α, so d(P_n, P_m) ≥ max(r_n^α, r_m^α). This is a condition on t
he *set* of points, invariant under relabeling. We relabel so that r_1 ≤ r_2 ≤ ⋯
 ≤ r_n ≤ ⋯. Then for i < j, d(P_i, P_j) ≥ r_j^α.

### Lower Bound: r_n ≥ C n^{1/(2(1−α))}

**Packing argument.** For each i, the open ball B(P_i, r_i^α) contains no other
point. For i < j, since d(P_i, P_j) ≥ r_j^α ≥ r_i^α ≥ (r_i^α + r_j^α)/2, the bal
ls B(P_i, r_i^α/2) are pairwise disjoint. All P_1, …, P_n lie in B(O, r_n), so t
hese balls are contained in B(O, r_n + r_n^α/2) ⊂ B(O, 3r_n/2) for r_n ≥ 1. Comp
aring areas:

$$\sum_{i=1}^{n} r_i^{2\alpha} \leq 9\, r_n^2. \tag{1}$$

**Induction.** Let γ = 1/(2(1−α)). We prove r_n ≥ C n^γ for all n, for a suitabl
e C > 0.

Assume r_i ≥ C i^γ for all i < n. Then r_i^{2α} ≥ C^{2α} i^{2αγ} = C^{2α} i^{α/(
1−α)}. Since α/(1−α) > 0:

$$\sum_{i=1}^{n-1} r_i^{2\alpha} \geq C^{2\alpha} \sum_{i=1}^{n-1} i^{\alpha/(1-
\alpha)} \geq C^{2\alpha} \int_0^{n-1} x^{\alpha/(1-\alpha)}\,dx = C^{2\alpha}(1
-\alpha)(n-1)^{1/(1-\alpha)}.$$

For n ≥ 2, (n−1)^{1/(1−α)} ≥ n^{1/(1−α)} / 2^{1/(1−α)}. From (1), dropping the n
on-negative r_n^{2α} term:

$$9\,r_n^2 \geq \sum_{i=1}^{n-1} r_i^{2\alpha} \geq \frac{C^{2\alpha}(1-\alpha)}
{2^{1/(1-\alpha)}} \, n^{1/(1-\alpha)}.$$

Therefore:

$$r_n \geq \left(\frac{C^{2\alpha}(1-\alpha)}{9 \cdot 2^{1/(1-\alpha)}}\right)^{
1/2} n^{1/(2(1-\alpha))}.$$

For the induction to close, we need the coefficient to be ≥ C, i.e.:

$$C^{2(\alpha-1)} \geq \frac{9 \cdot 2^{1/(1-\alpha)}}{1-\alpha}, \quad\text{i.e
.,}\quad C \leq \left(\frac{1-\alpha}{9 \cdot 2^{1/(1-\alpha)}}\right)^{1/(2(1-\
alpha))}.$$

Choosing C strictly below this threshold, the induction closes. The finitely man
y base cases are handled by taking C small enough. ∎

### Upper Bound: Construction achieving r_n ≤ C' n^{1/(2(1−α))}

**Concentric circles.** Pick R_0 sufficiently large. Define radii R_{k+1} = R_k
+ 3 R_k^α for k = 0, 1, 2, …. On the circle of radius R_k, place m_k = ⌊R_k^{1−α
}/4⌋ equally spaced points.

**Same-circle distances.** All points on circle k have r = R_k, requiring pairwi
se distance ≥ R_k^α. The chord distance between adjacent points is 2R_k sin(π/m_
k) ≥ 2R_k · (2/m_k) (for m_k ≥ 2) = 4R_k/m_k ≥ 4R_k/(R_k^{1−α}/4) = 16 R_k^α > R
_k^α. ✓

**Cross-circle distances (circles k > l).** The minimum distance between a point
 on circle k and a point on circle l is R_k − R_l (angular alignment). For l = k
−1: R_k − R_{k−1} = 3 R_{k−1}^α. We need this ≥ R_k^α = R_{k−1}^α (1 + 3 R_{k−1}
^{α−1})^α. Since α < 1, R_{k−1}^{α−1} → 0 as R_{k−1} → ∞, so (1 + 3 R_{k−1}^{α−1
})^α → 1 < 3. For R_0 large enough, 3 R_{k−1}^α ≥ R_k^α for all k. ✓

For l < k−1: R_k − R_l = ∑_{j=l}^{k−1} 3 R_j^α ≥ 3 R_l^α. Since R_k ≤ R_l + 3(k−
l) R_{k−1}^α and R_k^α ≈ R_l^α for R_0 large (increments are o(R)), we get R_k −
 R_l ≥ 3 R_l^α ≥ R_k^α. ✓

**Growth rate.** The recurrence R_{k+1} − R_k = 3 R_k^α gives dR/dk = 3 R^α, hen
ce R_k^{1−α} = 3(1−α)k + O(1), so R_k ~ (3(1−α)k)^{1/(1−α)}.

Points per circle: m_k ~ R_k^{1−α}/4 ~ 3(1−α)k/4 = c_0 k.

Total points through circle K: N_K = ∑_{k=0}^K m_k ~ c_0 K²/2.

The n-th point (ordered by increasing r) lies on circle k with n ~ c_0 k²/2, so
k ~ √(2n/c_0), and:

$$r_n = R_k \sim \bigl(3(1-\alpha)\,k\bigr)^{1/(1-\alpha)} \sim C'\, n^{1/(2(1-\
alpha))}.$$

Thus r_n ≤ C' n^{1/(2(1−α))} for some constant C', showing no larger β is possib
le.

### Conclusion

The lower bound proves r_n ≥ C n^{1/(2(1−α))} for every valid sequence, and the
construction proves this exponent cannot be improved. Therefore:

$$\boxed{\beta = \dfrac{1}{2(1-\alpha)}}$$
