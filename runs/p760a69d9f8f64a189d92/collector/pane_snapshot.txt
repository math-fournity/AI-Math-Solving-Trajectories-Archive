## 证明

设 ∠BAC = α, ∠ABC = β, ∠ACB = γ，外接圆半径为 R。由于 △ABC 是锐角三角形，BC 的劣
弧长度为 2α < 180°。

将 C 点置于原点，射线 CA 沿正 x 轴方向。则：
- A = (2R sin β, 0),
- B = (2R sin α cos γ, 2R sin α sin γ),
- 外心 O = (R sin β, R cos β)。

**参数化 D。** 设 D 在劣弧 BC 上，且弧 BD = 2x，弧 DC = 2y，其中 x + y = α。则 ∠
BCD = x，∠DBC = y，且 |CD| = 2R sin y，因此
$$D = (2R\sin y\cos(\gamma+x),\; 2R\sin y\sin(\gamma+x)).$$

**求 G。** 由于 B, G, C, D 共圆于 Ω 且 BG ∥ DC，四边形 BGCD 是等腰梯形，故 BD =
GC。等弦对等弧：弧 GC = 弧 BD = 2x。由于 G 在劣弧 AC（长度为 2β）上，弧 AG = 2(β
−x)，因此 ∠GAC = x。从 A 发出的射线 AG 在射线 AC 下方成角度 x；与圆 |P−O| = R 求
交（非平凡根）得到：
$$G = (2R\sin x\cos(\beta-x),\; -2R\sin x\sin(\beta-x)).$$

**求 F。** 设 E = A + t(B−A) 在 AB 上，F = (f, 0) 在 AC 上。平行四边形条件 F = E
 + C − D = E − D（因为 C 是原点）给出，通过 y 坐标：
$$t = \frac{\sin y\sin(\gamma+x)}{\sin\alpha\sin\gamma}.$$
通过 x 坐标，利用 $\sin\beta = \sin(\alpha+\gamma) = \sin\alpha\cos\gamma + \cos
\alpha\sin\gamma$（因此 $\sin\alpha\cos\gamma - \sin\beta = -\cos\alpha\sin\gamm
a$）：
$$\frac{f}{2R} = \sin\beta + t(\sin\alpha\cos\gamma - \sin\beta) - \sin y\cos(\g
amma+x)$$
$$= \sin\beta - \frac{\sin y\sin(\gamma+x)\cos\alpha}{\sin\alpha} - \sin y\cos(\
gamma+x)$$
$$= \sin\beta - \sin y\cdot\frac{\sin(\gamma+x)\cos\alpha + \cos(\gamma+x)\sin\a
lpha}{\sin\alpha}$$
$$= \sin\beta - \sin y\cdot\frac{\sin(\gamma+x+\alpha)}{\sin\alpha}.$$
由于 $\gamma+x+\alpha = 180°-\beta+x$，$\sin(\gamma+x+\alpha)=\sin(\beta-x)$，且
 $y = \alpha-x$：
$$f = 2R\!\left[\sin\beta - \frac{\sin(\alpha-x)\sin(\beta-x)}{\sin\alpha}\right
].$$

**计算 ∠GFC。** 我们有 $\vec{FC} = (-f, 0)$ 且 $\vec{FG} = (G_x - f,\; G_y)$。计
算 $G_x - f$：
$$G_x - f = 2R\!\left[\sin x\cos(\beta-x) - \sin\beta + \frac{\sin(\alpha-x)\sin
(\beta-x)}{\sin\alpha}\right].$$
利用 $\sin\beta = \sin x\cos(\beta-x) + \cos x\sin(\beta-x)$：
$$\sin x\cos(\beta-x) - \sin\beta = -\cos x\sin(\beta-x).$$
利用 $\sin(\alpha-x) = \sin\alpha\cos x - \cos\alpha\sin x$：
$$\frac{\sin(\alpha-x)}{\sin\alpha} - \cos x = -\frac{\cos\alpha\sin x}{\sin\alp
ha}.$$
因此：
$$G_x - f = 2R\sin(\beta-x)\!\left[-\cos x + \frac{\sin(\alpha-x)}{\sin\alpha}\r
ight] = -\frac{2R\sin x\sin(\beta-x)\cos\alpha}{\sin\alpha},$$
且 $G_y = -2R\sin x\sin(\beta-x)$。因此：
$$\vec{FG} = -2R\sin x\sin(\beta-x)\cdot\!\left(\frac{\cos\alpha}{\sin\alpha},\;
 1\right),$$
所以 $\vec{FG}$ 平行于 $(\cos\alpha, \sin\alpha)$。$\vec{FC}$（方向 $(-1,0)$）与
 $\vec{FG}$（方向 $(\cos\alpha,\sin\alpha)$）之间的夹角为 $\alpha$。因此：
$$\angle GFC = \alpha = \angle BAC. \qquad\blacksquare$$
