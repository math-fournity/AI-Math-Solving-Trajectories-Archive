## Solution

**Setup and notation.** Let $a = BC$, $b = CA$, $c = AB$, and let $A$ denote the
 angle at vertex $A$. Let $R$ be the circumradius of $\triangle ABC$.

**Locating $M$ and $N$ via Stewart's Theorem.**

$M$ is on $AB$ with $AM = MC = x$. By Stewart's theorem (cevian from $C$ to $M$
on $AB$):
$$b^2(c-x) + a^2 x = c(x^2 + x(c-x)) = c^2 x$$
Solving: $x = \frac{b^2 c}{b^2 + c^2 - a^2} = \frac{b^2 c}{2bc\cos A} = \frac{b}
{2\cos A}.$

Similarly, $N$ is on $AC$ with $AN = NB = y$. By Stewart's theorem (cevian from
$B$ to $N$ on $AC$):
$$y = \frac{c^2 b}{c^2 + b^2 - a^2} = \frac{c}{2\cos A}.$$

**The tangent point $P$.** $P$ is the intersection of the tangents to the circum
circle at $B$ and $C$. Then $PB = PC$ (equal tangent lengths), and in $\triangle
 PBC$, the angle $\angle BPC = 180° - 2A$ with $\angle PBC = \angle PCB = A$. By
 the law of cosines:
$$a^2 = 2\,PB^2(1 + \cos 2A) = 4\,PB^2 \cos^2 A$$
so $PB = \frac{a}{2\cos A}$. Since $PB = 5$:
$$\cos A = \frac{a}{10}, \qquad x = \frac{5b}{a}, \qquad y = \frac{5c}{a}.$$

**Computing $MN$.** In $\triangle AMN$ with $\angle MAN = A$:
$$MN^2 = x^2 + y^2 - 2xy\cos A = \frac{25}{a^2}(b^2 + c^2 - 2bc\cos A) = \frac{2
5a^2}{a^2} = 25$$
so $\boxed{MN = 5}$.

**Computing $PM$ and $PN$ via coordinates.** Place $B = (-a/2, 0)$, $C = (a/2, 0
)$. The circumcenter lies at $O = (0,\, a\cos A/(2\sin A))$, and the tangent int
ersection is:
$$P = \left(0,\; -\frac{a\tan A}{2}\right) = (0,\, -5\sin A).$$

The vertex $A = \left(\frac{c^2-b^2}{2a},\; \frac{bc\sin A}{a}\right)$. Using $b
/a = \sin B/\sin A$, $c/a = \sin C/\sin A$, and $R = 5\cos A/\sin A$, a direct (
but careful) coordinate computation yields:

$$M = \left(-\frac{5\sin C\cos C}{\sin A},\; \frac{5\sin B\sin(C-A)}{\sin A}\rig
ht), \qquad N = \left(\frac{5\sin B\cos B}{\sin A},\; \frac{5\sin C\sin(B-A)}{\s
in A}\right).$$

Then:
$$PM^2 = \frac{25\sin^2 C\cos^2 C}{\sin^2 A} + \left(\frac{5\sin B\sin(C-A)}{\si
n A} + 5\sin A\right)^2.$$

Using the identity $\sin B\sin(C-A) = \sin(A+C)\sin(C-A) = \sin^2 C - \sin^2 A$,
 the $y$-component simplifies to $\frac{5\sin^2 C}{\sin A}$, giving:
$$PM^2 = \frac{25\sin^2 C}{\sin^2 A}(\cos^2 C + \sin^2 C) = \frac{25\sin^2 C}{\s
in^2 A} \implies PM = \frac{5\sin C}{\sin A} = \frac{5c}{a}.$$

By the identical argument (swapping $B \leftrightarrow C$): $PN = \frac{5\sin B}
{\sin A} = \frac{5b}{a}$.

**Applying the perimeter conditions.**

*Condition 1* (perimeter of $\triangle PMN = 21$):
$$PM + MN + PN = \frac{5c}{a} + 5 + \frac{5b}{a} = \frac{5(b+c)}{a} + 5 = 21 \im
plies \frac{b+c}{a} = \frac{16}{5} \implies b+c = \frac{16a}{5}.$$

*Condition 2* (perimeter of quadrilateral $BCNM = 29$):
$$a + (b - y) + MN + (c - x) = a + b + c + 5 - \frac{5(b+c)}{a} = 29.$$
Let $s = a + b + c$. Then $s + 5 - \frac{5(s-a)}{a} = 29$, i.e., $s\left(1 - \fr
ac{5}{a}\right) = 19$, so:
$$s = \frac{19a}{a - 5}.$$

**Solving for $a$.** From Condition 1: $s = a + \frac{16a}{5} = \frac{21a}{5}$.
Equating:
$$\frac{21a}{5} = \frac{19a}{a-5} \implies 21(a-5) = 95 \implies 21a = 200 \impl
ies a = \frac{200}{21}.$$

**Verification.** With $a = 200/21$: $\cos A = 20/21$, $b + c = 640/21$, $s = 40
$.

- $PB = \frac{a}{2\cos A} = \frac{200/21}{40/21} = 5$. ✓
- Perimeter $PMN = \frac{5 \cdot 640/21}{200/21} + 5 = 16 + 5 = 21$. ✓
- Perimeter $BCNM = 40 + 5 - 16 = 29$. ✓
- A valid triangle exists: $bc = 8800/41$ with positive discriminant $(b+c)^2 -
4bc > 0$, and the ratio $b/c$ lies in $[21/40,\, 40/21]$, ensuring $M \in AB$ an
d $N \in AC$. ✓

**Answer.** The distance $BC = \dfrac{200}{21}$.
