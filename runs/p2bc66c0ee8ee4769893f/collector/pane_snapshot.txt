## Proof

We claim the infimum is **0**.

**Lower bound.** Since $|f'| \geq 0$ wherever $f'$ is defined, any admissible bo
und must satisfy $M \geq 0$. Hence the infimum is at least $0$.

**Achievability with $M = 0$.** It suffices to exhibit an unbounded, real-valued
 function on $(0,1)$ that is differentiable almost everywhere with $f' = 0$ a.e.
 (so that $|f'| \leq 0$ holds wherever $f'$ is defined).

Choose a strictly increasing sequence $(x_n)_{n \geq 1}$ in $(0,1)$ converging t
o $1$, for instance $x_n = 1 - 2^{-n}$. Define
$$
f(x) = \sum_{n=1}^{\infty} \mathbf{1}_{[x_n, 1)}(x) = \#\{n : x_n \leq x\}, \qqu
ad x \in (0,1).
$$

*Real-valued and finite.* For any $x \in (0,1)$, since $x_n \to 1$ and $x < 1$,
only finitely many terms $x_n$ satisfy $x_n \leq x$; hence $f(x)$ is a finite no
n-negative integer. So $f$ is real-valued on all of $(0,1)$.

*Unbounded.* As $x \to 1^{-}$, the count $\#\{n : x_n \leq x\} \to \infty$, so $
f$ is unbounded on $(0,1)$.

*Differentiable a.e. with $f' = 0$.* The function $f$ is a step function: it is
constant on each interval $(x_n, x_{n+1})$ and jumps by $1$ at each $x_n$. At ev
ery $x \notin \{x_n : n \geq 1\}$, some neighborhood of $x$ avoids all the $x_n$
 (the $x_n$ are isolated), so $f$ is constant there and $f'(x) = 0$. The excepti
onal set $\{x_n\}$ is countable, hence of Lebesgue measure zero. Therefore $f$ i
s differentiable almost everywhere and $f' = 0$ a.e., giving $|f'| \leq 0 = M$.

**Conclusion.** $M = 0$ is admissible, and no negative value of $M$ can be admis
sible. Therefore
$$
\inf\{M : \text{an unbounded such } f \text{ exists with } |f'| \leq M \text{ a.
e.}\} = 0.
$$
