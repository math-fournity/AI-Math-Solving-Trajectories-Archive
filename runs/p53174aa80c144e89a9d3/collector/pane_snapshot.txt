# Solution

**Claim:** Yes, $\sum_{i=1}^{k} \cos^{2n}\!\left(\frac{\pi i}{k}\right)$ is alwa
ys a dyadic rational.

## Proof

**Step 1: Binomial expansion.** Using $\cos x = \frac{e^{ix}+e^{-ix}}{2}$, we ex
pand:

$$\cos^{2n}(x) = \frac{1}{2^{2n}}\sum_{j=0}^{2n}\binom{2n}{j}e^{i(2n-2j)x}.$$

Setting $x = \frac{\pi i}{k}$ and summing over $i=1,\dots,k$:

$$S = \frac{1}{2^{2n}}\sum_{j=0}^{2n}\binom{2n}{j}\sum_{i=1}^{k} e^{i(2n-2j)\pi
i/k}.$$

**Step 2: Evaluate the inner geometric sum.** Let $m = 2n-2j$ (an even integer)
and $\omega = e^{im\pi/k}$. The inner sum is $\sum_{i=1}^{k}\omega^i$. Since $m$
 is even, $\omega^k = e^{im\pi} = (-1)^m = 1$.

- If $\omega = 1$ (i.e., $k \mid \frac{m}{2}$, equivalently $k \mid (n-j)$): the
 sum equals $k$.
- If $\omega \neq 1$: the sum equals $\omega\cdot\frac{\omega^k - 1}{\omega - 1}
 = 0$.

**Step 3: Collect surviving terms.** Only terms with $j \equiv n \pmod{k}$ survi
ve:

$$S = \frac{k}{2^{2n}}\sum_{\substack{0 \le j \le 2n \\ j \equiv n\,(\mathrm{mod
}\;k)}}\binom{2n}{j}.$$

**Step 4: Conclude.** The inner sum $M := \sum_{\substack{j \equiv n\,(\mathrm{m
od}\,k)}}\binom{2n}{j}$ is a non-negative integer (it is a sum of binomial coeff
icients, and $j=n$ always contributes $\binom{2n}{n}\geq 1$). Therefore

$$S = \frac{k \cdot M}{2^{2n}},$$

which is an integer divided by a power of $2$ — a **dyadic rational**. $\blacksq
uare$
