## 证明

**设定。** 设 $P = (a,b)$ 满足 $0 < b < a$。我们寻找一个三角形，其顶点分别为 $P$
、$Q$（在 $x$ 轴上）和 $R$（在直线 $y=x$ 上），且周长最小。

**反射。** 设 $P_1$ 为 $P$ 关于 $x$ 轴的反射点，即 $P_1 = (a,-b)$。设 $P_2$ 为 $
P$ 关于直线 $y=x$ 的反射点，即 $P_2 = (b,a)$。

对于 $Q$ 在 $x$ 轴上的任意点，有 $|PQ| = |P_1 Q|$（因为 $P_1$ 是 $P$ 关于 $x$ 轴
的反射点）。对于 $R$ 在 $y=x$ 上的任意点，有 $|PR| = |P_2 R|$（因为 $P_2$ 是 $P$
 关于 $y=x$ 的反射点）。

因此周长为
$$|PQ| + |QR| + |RP| = |P_1 Q| + |QR| + |P_2 R|,$$
即从 $P_1$ 到 $P_2$ 经过 $Q \in \text{$x$ 轴}$ 和 $R \in \{y=x\}$ 的路径长度。

**下界。** 根据三角不等式，
$$|P_1 Q| + |QR| + |P_2 R| \ge |P_1 P_2|,$$
当且仅当 $P_1, Q, R, P_2$ 按顺序共线时等号成立。

**计算 $|P_1 P_2|$：**
$$|P_1 P_2| = \sqrt{(a-b)^2 + (-b-a)^2} = \sqrt{(a-b)^2 + (a+b)^2} = \sqrt{2a^2
+ 2b^2} = \sqrt{2(a^2+b^2)}.$$

**达到下界。** 我们验证直线 $\overline{P_1 P_2}$ 是否在正确的顺序下依次穿过 $x$
轴和 $y=x$，从而得到有效的 $Q$ 和 $R$。

将直线参数化为 $(x(t), y(t)) = (a + t(b-a),\; -b + t(a+b))$，其中 $t \in [0,1]$
。

- **与 $x$ 轴的交点** ($y=0$)：$-b + t(a+b) = 0 \implies t_Q = \frac{b}{a+b}$。
因为 $0 < b < a$，所以 $0 < t_Q < \tfrac{1}{2}$。此时 $x_Q = \frac{a^2+b^2}{a+b}
$。

- **与 $y=x$ 的交点**：$a + t(b-a) = -b + t(a+b) \implies (a+b) = 2at \implies t
_R = \frac{a+b}{2a}$。因为 $0 < b < a$，所以 $\tfrac{1}{2} < t_R < 1$。此时 $x_R
 = y_R = \frac{a^2+b^2}{2a}$。

由于 $0 < t_Q < t_R < 1$，点 $P_1, Q, R, P_2$ 按顺序共线，因此三角不等式等号成立
。

**非退化性。** 点 $P=(a,b)$, $Q=(\frac{a^2+b^2}{a+b},0)$, $R=(\frac{a^2+b^2}{2a}
,\frac{a^2+b^2}{2a})$ 是互不相同的（$b>0 \Rightarrow P \notin x\text{-axis}$；$a
>b \Rightarrow P \notin \{y=x\}$；$Q \neq R$，因为一个在 $x$ 轴上，另一个在 $y=x
$ 上且均不为原点）。此外，$P$ 不在直线 $\overline{P_1 P_2}$ 上（在 $P$ 处 $y$ 坐
标要求 $t = \frac{2b}{a+b}$，但 $x$ 坐标要求 $t=0$，因为 $b \neq a$），因此这三
个点不共线。这是一个真正的三角形。

**结论。** 最小周长为
$$\boxed{\sqrt{2(a^2+b^2)}}.$$
