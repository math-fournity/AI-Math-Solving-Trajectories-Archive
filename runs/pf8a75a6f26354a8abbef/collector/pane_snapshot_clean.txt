## Proof

**Step 1: Vieta jumping structure.**

View the equation as a quadratic in $d$:
$$d^2 - (ab+ac+bc)\,d + (a^2+b^2+c^2-abc) = 0.$$
If $(a,b,c,d)$ is a solution, then by Vieta's formulas the other root is
$$d' = ab+ac+bc - d,$$
which is an integer, and $(a,b,c,d')$ is also a solution. The same "jump" applie
s to any variable: e.g., replacing $a$ gives $a' = bc+bd+cd-a$.

**Step 2: Initial solutions.**

Setting $a=b=c=d=t$: $4t^2=4t^3$, so $t=0$ or $t=1$. Thus $(1,1,1,1)$ is a solut
ion (check: $4=4$).

Jump on $d$: $d' = 1+1+1-1 = 2$, giving $(1,1,1,2)$. (Check: $1+1+1+4=7$, $1+2+2
+2=7$. ✓)

Jump on $c$: $c' = 1\cdot1+1\cdot2+1\cdot2-1 = 4$, giving $(1,1,2,4)$. (Check: $
1+1+4+16=22$, $2+4+8+8=22$. ✓)

**Step 3: Growth strategy — always jump on the smallest.**

Given a solution with sorted values $x \le y \le z \le w$ (all $\ge 1$), jump on
 $x$:
$$v = yz + yw + zw - x.$$

*Claim:* $v > w$, so the new sorted tuple is $(y, z, w, v)$.

*Proof of claim:*
$$v - w = yz + w(y+z-1) - x.$$
Since $y,z \ge 1$: $yz \ge 1$ and $y+z-1 \ge 1$, so $w(y+z-1) \ge w \ge x$. Ther
efore $v - w \ge 1 + x - x = 1 > 0$. ✓

*Positivity:* $v \ge yz + w(y+z-1) - x \ge 1 + x - x = 1 > 0$. ✓

So the jump on the smallest always produces a valid positive-integer solution, a
nd the new sorted tuple is $(y, z, w, v)$ with $v > w$.

**Step 4: The smallest value is strictly increasing (eventually) and unbounded.*
*

Define the sequence of sorted tuples $(x_n, y_n, z_n, w_n)$ starting from $(x_0,
y_0,z_0,w_0) = (1,1,2,4)$, where at each step we jump on $x_n$:
$$(x_{n+1}, y_{n+1}, z_{n+1}, w_{n+1}) = (y_n,\, z_n,\, w_n,\, y_nz_n + y_nw_n +
 z_nw_n - x_n).$$

By the claim, $w_{n+1} > w_n \ge z_n \ge y_n$, so $x_{n+1} < y_{n+1} < z_{n+1} <
 w_{n+1}$ whenever $x_n < y_n < z_n < w_n$.

**Base case:** $(1, 2, 4, 13)$ (obtained by jumping on $x_0=1$: $v = 2+4+8-1=13$
) satisfies $1 < 2 < 4 < 13$. ✓

**Induction:** If $x_n < y_n < z_n < w_n$, then $x_{n+1} = y_n > x_n$ and $x_{n+
1} < y_{n+1} < z_{n+1} < w_{n+1}$, preserving strict ordering.

Therefore, for all $n \ge 1$:
$$x_{n+1} = y_n > x_n,$$
so $(x_n)$ is a **strictly increasing** sequence of positive integers. Hence $x_
n \to \infty$.

**Step 5: Explicit verification of the first steps.**

| $n$ | Sorted tuple | Smallest $x_n$ |
|-----|-------------|----------------|
| 0 | $(1, 1, 2, 4)$ | 1 |
| 1 | $(1, 2, 4, 13)$ | 1 |
| 2 | $(2, 4, 13, 85)$ | 2 |
| 3 | $(4, 13, 85, 1495)$ | 4 |
| 4 | $(13, 85, 1495, 147611)$ | 13 |

(Step 2: $v = 2\cdot4+2\cdot13+4\cdot13-1 = 85$. Step 3: $v = 4\cdot13+4\cdot85+
13\cdot85-2 = 52+340+1105-2 = 1495$. Step 4: $v = 13\cdot85+13\cdot1495+85\cdot1
495-4 = 1105+19435+127075-4 = 147611$.)

The smallest values $1, 1, 2, 4, 13, 85, \ldots$ grow without bound.

**Conclusion.** Starting from the solution $(1,1,1,1)$, repeated Vieta jumps on
the smallest variable produce an infinite family of integer solutions $(x_n, y_n
, z_n, w_n)$ to $a^2+b^2+c^2+d^2 = abc+abd+acd+bcd$ whose minimum $x_n$ is a str
ictly increasing (hence unbounded) sequence of positive integers. Therefore, the
 smallest of $a, b, c, d$ can be made arbitrarily large. $\blacksquare$
