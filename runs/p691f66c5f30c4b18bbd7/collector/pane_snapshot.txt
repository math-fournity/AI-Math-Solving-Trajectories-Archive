$$r_a = \frac{|c-b|}{3},\quad r_b = \frac{|a-c|}{3},\quad r_c = \frac{|b-a|}{3}.

Squaring removes the absolute values: $r_a^2 = \frac{(c-b)^2}{9}$, etc.

**Radical center equations.** The radical center $\mathbf{r}$ satisfies equal po

$$|\mathbf{r}-\mathbf{a}|^2 - r_a^2 = |\mathbf{r}-\mathbf{b}|^2 - r_b^2 = |\math

Expanding $|\mathbf{r}-\mathbf{a}|^2 - r_a^2 = |\mathbf{r}-\mathbf{b}|^2 - r_b^2

$$2\,\mathbf{r}\cdot(\mathbf{b}-\mathbf{a}) = r_a^2 - r_b^2 = \frac{(c-b)^2 - (a

Similarly:
$$2\,\mathbf{r}\cdot(\mathbf{c}-\mathbf{b}) = r_b^2 - r_c^2 = \frac{(2a-b-c)(b-c

$$\mathbf{n} = \frac{(s-a)\,\mathbf{a} + (s-b)\,\mathbf{b} + (s-c)\,\mathbf{c}}{

$$2\,\mathbf{n}\cdot(\mathbf{b}-\mathbf{a}) = \frac{1}{s}\Big[(a-b)\,c^2 + (s-c)

$$c^2 - (s-c)(b+a) = c^2 - \frac{(a+b-c)(a+b)}{2} = \frac{2c^2 + c(a+b) - (a+b)^

Therefore:
$$2\,\mathbf{n}\cdot(\mathbf{b}-\mathbf{a}) = \frac{(a-b)}{s}\cdot s(2c-a-b) = (
a-b)(2c-a-b). \tag{3}$$
