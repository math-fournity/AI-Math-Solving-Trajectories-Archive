# Problem

In a futuristic data-processing center, a security engineer is designing a tiered firewall protocol. The system's vulnerability is determined by a specific performance index, $a$, which must be a positive whole number. This index is the leading coefficient of a quadratic efficiency function $f(t) = at^2 + bt + c$, where the secondary tuning parameter $b$ and the baseline offset $c$ must also be integers.

For the firewall to remain stable, the function must have two distinct synchronization points, $\alpha$ and $\beta$. These points represent the moments in a one-second cycle ($t$) where the efficiency function hits zero. Due to hardware limitations, both synchronization points must occur strictly after the cycle starts but before it ends, such that $0 < \alpha < \beta < 1$.

What is the smallest possible integer value for the performance index $a$ that allows such a firewall protocol to exist?
