# Problem

A specialized computer server rack has $N$ dual-socket processing slots. To function, each slot must be occupied by exactly one pair of processors. These pairs can be formed under one of two exclusive configurations: either every slot must contain a pair of "Synchronized" processors (which have identical clock speeds), or every slot must contain a pair of "Independent" processors (which have different clock speeds).

A shipment of $M$ processors is delivered to a data center. Upon inspection, the technician discovers that it is mathematically impossible to select any $2N$ processors from this batch that can satisfy either the "all Synchronized" configuration or the "all Independent" configuration for the $N$ slots.

However, the delivery driver realizes one processor was left in the truck. Once this $(M+1)$-th processor is added to the batch, it becomes possible to select $2N$ processors from the total set to fully occupy the rack under one of the two configurations.

Find the largest possible value of $M$ in terms of $N$.
