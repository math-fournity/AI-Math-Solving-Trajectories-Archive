## Proof

**Claim:** Yes, such a function exists.

**Construction.** Let $g(x) = e^{-x^2}$.

**Verification of the hypotheses.**

1. **Real-valued:** For every $x \in \mathbb{R}$, $e^{-x^2}$ is a positive real
number. ✓

2. **Nonconstant:** $g(0) = e^{0} = 1$ while $g(1) = e^{-1} \neq 1$. ✓

3. **Differentiable:** $g$ is smooth (infinitely differentiable) on all of $\mat
hbb{R}$, with $g'(x) = -2x\,e^{-x^2}$. ✓

4. **Integrability (both improper integrals converge):** For $|x| \geq 1$ we hav
e $x^2 \geq |x|$, hence $0 < e^{-x^2} \leq e^{-|x|}$. Since $\int_1^{\infty} e^{
-x}\,dx$ and $\int_{-\infty}^{-1} e^{x}\,dx$ both converge, by comparison both $
\int_0^{\infty} e^{-x^2}\,dx$ and $\int_{-\infty}^{0} e^{-x^2}\,dx$ converge (ab
solutely). ✓

**Verification of the equality.**

Since $g$ is real-valued and both integrals converge, each integral is a real nu
mber, so the $\operatorname{Re}$ operator is the identity:

$$\operatorname{Re}\int_{-\infty}^{0} g(x)\,dx = \int_{-\infty}^{0} e^{-x^2}\,dx
, \qquad \operatorname{Re}\int_{0}^{\infty} g(x)\,dx = \int_{0}^{\infty} e^{-x^2
}\,dx.$$

The function $e^{-x^2}$ is **even**: $g(-x) = e^{-(-x)^2} = e^{-x^2} = g(x)$. Ap
plying the substitution $x = -u$ (so $dx = -du$) to the left integral:

$$\int_{-\infty}^{0} e^{-x^2}\,dx = \int_{+\infty}^{0} e^{-u^2}(-du) = \int_{0}^
{\infty} e^{-u^2}\,du = \int_{0}^{\infty} e^{-x^2}\,dx.$$

Therefore

$$\operatorname{Re}\int_{-\infty}^{0} g(x)\,dx = \operatorname{Re}\int_{0}^{\inf
ty} g(x)\,dx.$$

(Both equal $\tfrac{\sqrt{\pi}}{2}$ by the classical Gaussian integral, though t
he exact value is irrelevant—only the equality matters, and it follows purely fr
om evenness.)

**Conclusion.** The function $g(x) = e^{-x^2}$ is real-valued, nonconstant, diff
erentiable, and satisfies $\operatorname{Re}\int_{-\infty}^{0} g(x)\,dx = \opera
torname{Re}\int_{0}^{\infty} g(x)\,dx$. Hence such a function exists. $\blacksqu
are$
