## Proof

**Spherical coordinates.** Let $x = r\sin\theta\cos\phi$, $y = r\sin\theta\sin\p
hi$, $z = r\cos\theta$, so $x^2+y^2+z^2 = r^2$ and $xyz = r^3\sin^2\theta\cos\th
eta\cos\phi\sin\phi$.

**Determining the boundary.** The surface $(x^2+y^2+z^2)^3 = 3xyz$ becomes
$$r^6 = 3r^3\sin^2\theta\cos\theta\cos\phi\sin\phi.$$
For $r\neq 0$ this gives the radial boundary
$$r_{\max}^3 = 3\sin^2\theta\cos\theta\cos\phi\sin\phi.$$
For $r_{\max}$ to be a nonneg real radius we need $\cos\theta\cos\phi\sin\phi \g
e 0$ (since $\sin^2\theta\ge 0$ always). The solid is the region $0\le r\le r_{\
max}$ over the angular domain where this inequality holds.

**Setting up the integral.** The volume element is $dV = r^2\sin\theta\,dr\,d\th
eta\,d\phi$, so
$$V = \iint_{\Omega}\int_0^{r_{\max}} r^2\sin\theta\,dr\,d\theta\,d\phi = \iint_
{\Omega}\frac{r_{\max}^3}{3}\sin\theta\,d\theta\,d\phi,$$
where $\Omega = \{(\theta,\phi): \cos\theta\cos\phi\sin\phi\ge 0\}$. Substitutin
g $r_{\max}^3$:
$$V = \iint_{\Omega}\sin^3\theta\cos\theta\cos\phi\sin\phi\,d\theta\,d\phi.$$

**Identifying the angular domain.** The condition $\cos\theta\cos\phi\sin\phi\ge
 0$ (equivalently $\cos\theta\sin 2\phi\ge 0$) splits into two cases, each with
two $\phi$-subintervals:

- **Case A:** $\cos\theta\ge 0$ ($\theta\in[0,\pi/2]$) and $\sin 2\phi\ge 0$ ($\
phi\in[0,\pi/2]\cup[\pi,3\pi/2]$).
- **Case B:** $\cos\theta\le 0$ ($\theta\in[\pi/2,\pi]$) and $\sin 2\phi\le 0$ (
$\phi\in[\pi/2,\pi]\cup[3\pi/2,2\pi]$).

This gives four rectangular angular blocks. On each block the integrand is nonne
g, so we integrate directly.

**Evaluating one block.** Take $\theta\in[0,\pi/2]$, $\phi\in[0,\pi/2]$:
$$I_1 = \left(\int_0^{\pi/2}\sin^3\theta\cos\theta\,d\theta\right)\!\left(\int_0
^{\pi/2}\cos\phi\sin\phi\,d\phi\right).$$
Using $u=\sin\theta$ and $v=\sin\phi$:
$$\int_0^{\pi/2}\sin^3\theta\cos\theta\,d\theta = \left[\frac{\sin^4\theta}{4}\r
ight]_0^{\pi/2} = \frac14,\qquad \int_0^{\pi/2}\cos\phi\sin\phi\,d\phi = \left[\
frac{\sin^2\phi}{2}\right]_0^{\pi/2} = \frac12.$$
Hence $I_1 = \tfrac14\cdot\tfrac12 = \tfrac18$.

**Symmetry of the four blocks.** Each of the other three blocks yields the same
value $\tfrac18$. For instance, for $\theta\in[\pi/2,\pi]$, $\phi\in[\pi/2,\pi]$
:
$$\int_{\pi/2}^{\pi}\sin^3\theta\cos\theta\,d\theta = \left[\frac{\sin^4\theta}{
4}\right]_{\pi/2}^{\pi} = -\frac14,\quad \int_{\pi/2}^{\pi}\cos\phi\sin\phi\,d\p
hi = \left[\frac{\sin^2\phi}{2}\right]_{\pi/2}^{\pi} = -\frac12,$$
and the product is again $\tfrac18$. The remaining two blocks are identical by t
he analogous sign pairing. Therefore
$$V = 4\cdot\frac18 = \frac12.$$

**Answer:** the volume of the enclosed solid is $\boxed{\dfrac12}$.
