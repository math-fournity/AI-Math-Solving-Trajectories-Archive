Since $x_1 = 1 > 0$ and each increment $\frac{n}{P_n^{1/n}}$ is positive (where
$P_n = x_1 \cdots x_n > 0$), we have $x_{n+1} > x_n$ for all $n$. In particular
$x_n \geq x_k$ for all $k \leq n$.

**Step 2: Upper bound on $P_n^{1/n}$.**

Since $x_k \leq x_n$ for all $k \leq n$:
$$P_n = \prod_{k=1}^n x_k \leq x_n^n \implies P_n^{1/n} \leq x_n.$$

**Step 3: Lower bound recurrence.**

$$x_{n+1} = x_n + \frac{n}{P_n^{1/n}} \geq x_n + \frac{n}{x_n}.$$

**Step 4: Square and telescope.**

Squaring both sides (all quantities positive):
$$x_{n+1}^2 \geq \left(x_n + \frac{n}{x_n}\right)^2 = x_n^2 + 2n + \frac{n^2}{x_
n^2} \geq x_n^2 + 2n.$$

$$x_n^2 \geq x_1^2 + \sum_{k=1}^{n-1} 2k = 1 + n(n-1) = n^2 - n + 1.$$

$$n^2 - n + 1 \geq \frac{n^2}{2} \iff n^2 - 2n + 2 \geq 0 \iff (n-1)^2 + 1 \geq
0,$$
which always holds. Therefore:
$$x_n \geq \sqrt{n^2 - n + 1} \geq \frac{n}{\sqrt{2}}.$$
