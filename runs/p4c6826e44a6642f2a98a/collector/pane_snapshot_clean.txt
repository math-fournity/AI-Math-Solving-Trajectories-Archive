# Solution

**Interpretation.** For an integral operator $A$ on $L^2(0,1)$, "the kernel" ref
ers to the kernel function $K(x,y)$ with $(Af)(x)=\int_0^1 K(x,y)\,f(y)\,dy$. Th
e question asks whether knowing $K$ is enough to decide if $A$ is self-adjoint.

**Answer: Yes.** The kernel $K$ is sufficient, and the criterion is $K(x,y)=\ove
rline{K(y,x)}$ a.e.

---

## Proof

Let $A$ be a bounded integral operator on $L^2(0,1)$ with kernel $K\in L^2\bigl(
(0,1)\times(0,1)\bigr)$, i.e., a Hilbert–Schmidt operator:
$$(Af)(x)=\int_0^1 K(x,y)\,f(y)\,dy.$$

### Step 1 — The kernel uniquely determines the operator

Suppose $K_1, K_2\in L^2$ define the same operator. Then for every $f\in L^2$ an
d a.e. $x$,
$$\int_0^1 \bigl(K_1(x,y)-K_2(x,y)\bigr)\,f(y)\,dy = 0.$$
Since this holds for all $f\in L^2(0,1)$, we get $K_1(x,\cdot)=K_2(x,\cdot)$ in
$L^2$ for a.e. $x$, hence $K_1=K_2$ a.e. on $(0,1)^2$. So $K$ determines $A$ com
pletely (up to a.e. equivalence, which is the natural identification in $L^2$).

### Step 2 — Compute $\langle Af,g\rangle$ and $\langle f,Ag\rangle$

For $f,g\in L^2(0,1)$:
$$\langle Af,g\rangle = \int_0^1 (Af)(x)\,\overline{g(x)}\,dx = \int_0^1\!\!\int
_0^1 K(x,y)\,f(y)\,\overline{g(x)}\,dy\,dx.$$

For the adjoint pairing:
$$\langle f,Ag\rangle = \int_0^1 f(x)\,\overline{(Ag)(x)}\,dx = \int_0^1 f(x)\,\
overline{\int_0^1 K(x,y)\,g(y)\,dy}\,dx = \int_0^1\!\!\int_0^1 \overline{K(x,y)}
\,f(x)\,\overline{g(y)}\,dx\,dy.$$

Swapping the dummy variables $x\leftrightarrow y$:
$$\langle f,Ag\rangle = \int_0^1\!\!\int_0^1 \overline{K(y,x)}\,f(y)\,\overline{
g(x)}\,dy\,dx.$$

### Step 3 — Self-adjointness $\iff$ $K(x,y)=\overline{K(y,x)}$ a.e.

$A$ is self-adjoint iff $\langle Af,g\rangle=\langle f,Ag\rangle$ for all $f,g\i
n L^2$. By Steps 2, this is equivalent to
$$\int_0^1\!\!\int_0^1 \bigl(x,y)-\overline{K(y,x)}\bigr]\,f(y)\,\overline{g(x
)}\,dy\,dx = 0 \quad\text{for all } f,g\in L^2.$$

Set $H(x,y):=K(x,y)-\overline{K(y,x)}\in L^2\bigl((0,1)^2\bigr)$. The condition
becomes $\langle H, \overline{g}\otimes f\rangle_{L^2((0,1)^2)}=0$ for all $f,g\
in L^2$, where $(\overline{g}\otimes f)(x,y)=\overline{g(x)}\,f(y)$. The linear
span of such rank-one functions is dense in $L^2((0,1)^2)$ (this is the standard
 density of finite-rank / simple tensors in the Hilbert-space tensor product $L^
2\otimes L^2 \cong L^2((0,1)^2)$). Therefore $H=0$ in $L^2$, i.e.,
$$K(x,y)=\overline{K(y,x)}\quad\text{a.e. on }(0,1)\times(0,1).$$

### Conclusion

The kernel $K$ is **sufficient** to determine whether $A$ is self-adjoint. The e
xplicit test is:

> $A$ is self-adjoint if and only if $K(x,y)=\overline{K(y,x)}$ for a.e. $(x,y)\
in(0,1)\times(0,1)$.

The forward direction uses the density of rank-one tensors in $L^2((0,1)^2)$; th
e reverse direction is immediate from the computation in Step 2. $\blacksquare$
