## Solution

Let the 7-digit number be $d_1d_2d_3d_4d_5d_6d_7$, where each $d_i \in \{0,1,\do
ts,9\}$.

**Conditions:**
- All seven digits are distinct.
- First four descending: $d_1 > d_2 > d_3 > d_4$.
- Last four ascending: $d_4 < d_5 < d_6 < d_7$.

**Key observation.** From the descending chain, $d_4 < d_3 < d_2 < d_1$. From th
e ascending chain, $d_4 < d_5 < d_6 < d_7$. Therefore $d_4$ is strictly smaller
than all six other digits — i.e., **$d_4$ is the minimum** of the seven chosen d
igits.

**Counting.** We construct every valid number as follows:

1. **Choose the 7 distinct digits** from $\{0,\dots,9\}$: $\binom{10}{7}$ ways.
Once chosen, the smallest is forced to be $d_4$ (it is the only digit that can s
it below all the others).

2. **Partition the remaining 6 digits** into a left group of 3 (for $d_1,d_2,d_3
$) and a right group of 3 (for $d_5,d_6,d_7$): $\binom{6}{3}$ ways.

3. **Arrange each group.** The left group must be placed in descending order — u
niquely determined. The right group must be placed in ascending order — uniquely
 determined.

No further constraints exist (there is no required relationship between $d_3$ an
d $d_5$, since both are already $> d_4$). Conversely, every valid number arises
uniquely from this construction, so there is no over- or under-counting.

**Computation:**

$$\binom{10}{7}\cdot\binom{6}{3} = 120 \cdot 20 = 2400.$$

**Answer:** $\boxed{2400}$.
