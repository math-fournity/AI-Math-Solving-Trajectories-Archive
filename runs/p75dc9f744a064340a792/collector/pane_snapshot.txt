## Proof

Let $U$ denote the open unit disc. Define

$$h(z) = \frac{f'(z)}{f(z)} - \frac{g'(z)}{g(z)}.$$

Since $f$ and $g$ are analytic and **never zero** on $U$, the quotients $f'/f$ a
nd $g'/g$ are each analytic on $U$ (the only possible singularities would be at
zeros of $f$ or $g$, which are absent). Hence $h$ is analytic on $U$.

By hypothesis, for every integer $n \geq 5$,

$$h\!\left(\frac{1}{n}\right) = \frac{f'}{f}\!\left(\frac{1}{n}\right) - \frac{g
'}{g}\!\left(\frac{1}{n}\right) = 0.$$

The set $\left\{\frac{1}{n} : n \geq 5\right\}$ is an infinite set of **distinct
** points of $U$, and it accumulates at $0$, which lies in $U$. By the **Identit
y Theorem** for analytic functions, an analytic function that vanishes on a set
with an accumulation point inside its domain must vanish identically. Therefore

$$h \equiv 0 \quad \text{on } U,$$

i.e.,

$$\frac{f'(z)}{f(z)} = \frac{g'(z)}{g(z)} \quad \text{for all } z \in U.$$

Now consider the quotient $\varphi(z) = \frac{f(z)}{g(z)}$. Since $g$ never vani
shes on $U$, $\varphi$ is analytic on $U$, and

$$\varphi'(z) = \frac{f'(z)g(z) - f(z)g'(z)}{g(z)^2} = \frac{f(z)}{g(z)}\left(\f
rac{f'(z)}{f(z)} - \frac{g'(z)}{g(z)}\right) = \varphi(z)\cdot h(z) = 0$$

for all $z \in U$. Since $U$ is connected, $\varphi$ is constant: there exists a
 constant $c \in \mathbb{C}$ with

$$f(z) = c\, g(z) \quad \text{for all } z \in U.$$

Because $f$ is never zero on $U$, the constant $c$ must be nonzero ($c \neq 0$).

**Conclusion.** The precise relationship is

$$\boxed{f = c\, g \text{ on } U \text{ for some nonzero constant } c \in \mathb
b{C}\setminus\{0\}.}$$

The Identity Theorem promotes the equality of logarithmic derivatives on the acc
umulating sequence $\{1/n\}_{n\geq 5}$ to equality on all of $U$, and the vanish
ing of $f'/f - g'/g$ forces $f/g$ to be constant.
