- **If $i < j$:** $|j - i| = j - i \equiv -i \pmod{j}$, so $c(i) = c(j - i)$. Th
is means residue class $r$ and residue class $-r \pmod{j}$ share the same color.

Combining both cases: the color of any $i \in N$ depends only on the pair $\{r,
-r\}$ where $r \equiv i \pmod{j}$. Equivalently, the color classes induced by co

hbb{Z}$:
$$\mathcal{C}_r = \{i \in N : i \equiv r \text{ or } i \equiv -r \pmod{j}\}, \qu
ad r \in \mathbb{Z}/j\mathbb{Z},$$

Condition (A) states $c(i) = c(n - i)$ for all $i \in N$. If $i \equiv r \pmod{j

Here the first equality uses (B) (class of $-r$ = class of $r$), and the second

Therefore:
$$\text{color}(\mathcal{C}_r) = \text{color}(\mathcal{C}_{r + n}) \quad \text{fo
r every } r \in \mathbb{Z}/j\mathbb{Z}. \tag{2}$$
