## Problem

Derive the tightest bound for the inequality $\|x\|_q \leq C\|x\|_p$ in finite-d
imensional normed linear spaces when $p < q$.

## Proof

We work in $\mathbb{R}^n$ (or $\mathbb{C}^n$) with the $\ell_p$ norm $\|x\|_p =
\left(\sum_{i=1}^n |x_i|^p\right)^{1/p}$. We claim the tightest constant is

$$C = 1.$$

---

### Upper bound: $\|x\|_q \leq \|x\|_p$ for all $x$ when $0 < p < q$

Let $x \in \mathbb{R}^n$. If $x = 0$ the inequality is trivial, so assume $x \ne
q 0$.

**Normalize.** Set $y_i = \dfrac{|x_i|}{\|x\|_p}$ for each $i = 1, \ldots, n$. T
hen

$$\sum_{i=1}^n y_i^p = \frac{\sum_{i=1}^n |x_i|^p}{\|x\|_p^p} = \frac{\|x\|_p^p}
{\|x\|_p^p} = 1,$$

and since each $|x_i| \leq \|x\|_p$ (a single term is at most the $\ell_p$ norm)
, we have $0 \leq y_i \leq 1$ for every $i$.

**Key observation.** For $0 \leq y_i \leq 1$ and $p < q$, raising to a higher po
wer can only decrease the value:

$$y_i^q = y_i^p \cdot y_i^{q-p} \leq y_i^p \cdot 1^{q-p} = y_i^p,$$

since $y_i^{q-p} \leq 1$ when $y_i \leq 1$ and $q - p > 0$.

**Sum and conclude.** Summing over all $i$:

$$\sum_{i=1}^n y_i^q \leq \sum_{i=1}^n y_i^p = 1.$$

Taking the $1/q$ power (which is monotone increasing on $[0, \infty)$):

$$\left(\sum_{i=1}^n y_i^q\right)^{1/q} \leq 1^{1/q} = 1.$$

Substituting back $y_i = |x_i| / \|x\|_p$:

$$\frac{\|x\|_q}{\|x\|_p} = \left(\sum_{i=1}^n y_i^q\right)^{1/q} \leq 1.$$

Therefore $\|x\|_q \leq 1 \cdot \|x\|_p$ for all $x$, establishing that $C = 1$
is a valid bound.

---

### Tightness: $C = 1$ cannot be reduced

Consider the standard basis vector $x = e_1 = (1, 0, 0, \ldots, 0) \in \mathbb{R
}^n$. Then

$$\|e_1\|_q = \left(1^q + 0^q + \cdots + 0^q\right)^{1/q} = 1,$$
$$\|e_1\|_p = \left(1^p + 0^p + \cdots + 0^p\right)^{1/p} = 1.$$

Hence $\|e_1\|_q = 1 = 1 \cdot \|e_1\|_p$, so equality is achieved. Any constant
 $C < 1$ would violate the inequality at $x = e_1$.

---

### Conclusion

The tightest constant in the inequality $\|x\|_q \leq C\|x\|_p$ for $p < q$ in $
\mathbb{R}^n$ (equipped with $\ell_p$ norms) is

$$\boxed{C = 1}.$$

The bound is dimension-independent: it holds for every $n \geq 1$ with the same
constant, and equality is attained at any standard basis vector $e_k$.
