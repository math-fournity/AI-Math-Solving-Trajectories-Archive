## Proof

The expression $S$ is invariant under cyclic permutation $(a,b,c) \to (b,c,a)$,
since $S(b,c,a) = b^2c(b-c) + c^2a(c-a) + a^2b(a-b) = S(a,b,c)$. Thus, WLOG assu
me $a$ is the largest side. Two cases arise.

---

### Case 1: $a \geq b \geq c$

Set $s = a - b \geq 0$, $t = b - c \geq 0$, so $a = c + t + s$, $b = c + t$, wit
h $c > 0$.

Substituting into $S = a^2b(a-b) + b^2c(b-c) + c^2a(c-a)$ and expanding (with $u
 = c+t$):

$$S = s(u+s)^2 u + t u^2 c - (t+s)c^2(u+s).$$

Expanding each piece using $u = c + t$ and collecting terms:

$$S = c^2(s^2 + st + t^2) + c(s^3 + 4s^2 t + 3st^2 + t^3) + st(s+t)^2.$$

**Each summand is non-negative:** $c > 0$ and $s^2 + st + t^2 \geq 0$; every ter
m in $s^3 + 4s^2 t + 3st^2 + t^3$ is non-negative for $s, t \geq 0$; and $st(s+t
)^2 \geq 0$. Hence $S \geq 0$.

---

### Case 2: $a \geq c \geq b$

Set $s = a - c \geq 0$, $t = c - b \geq 0$, so $a = b + t + s$, $c = b + t$. The
 triangle inequality $a < b + c$ gives $b + t + s < b + (b+t)$, i.e., $s < b$. W
rite $b = s + r$ with $r > 0$.

Substituting into $S$ (with $v = b + t = c$):

$$S = b(t+s)(v+s)^2 - t b^2 v - s v^2(v+s).$$

Expanding with $v = b + t$ and collecting:

$$S = b^2(s^2 + st + t^2) + b(s^3 + s^2 t + t^3) - st^2(s+t).$$

Now substitute $b = s + r$ ($r > 0$) and expand:

$$S = 2s^4 + 2s^3 t + 3s^3 r + 3s^2 r t + 2s r t^2 + r^2 s^2 + r^2 s t + r^2 t^2
 + r t^3.$$

**Every term is non-negative** since $s, t \geq 0$ and $r > 0$. Hence $S \geq 0$
.

---

### Equality

**Case 1:** $S = 0$ requires $c^2(s^2 + st + t^2) = 0$. Since $c > 0$, this forc
es $s^2 + st + t^2 = 0$, which for $s, t \geq 0$ gives $s = t = 0$, i.e., $a = b
 = c$.

**Case 2:** $S = 0$ requires $2s^4 = 0$ (so $s = 0$), and then $rt^3 = 0$ with $
r > 0$ forces $t = 0$, again giving $a = b = c$.

Conversely, $a = b = c$ gives $S = 0$ directly.

---

Therefore, for all side lengths $a, b, c$ of a triangle:

$$a^2b(a-b) + b^2c(b-c) + c^2a(c-a) \geq 0,$$

with equality if and only if $a = b = c$ (the equilateral triangle). $\blacksqua
