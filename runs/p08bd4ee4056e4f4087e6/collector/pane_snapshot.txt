Yes, there exists an injective mapping from $\mathbb{R}$ to the unit disk $\{(x,
y)\in\mathbb{R}^2 : x^2+y^2\le 1\}$.

**Construction.** Define $f:\mathbb{R}\to\mathbb{R}^2$ by
$$f(t)=\left(\frac{t}{1+|t|},\, 0\right).$$

**The image lies in the unit disk.** For every $t\in\mathbb{R}$, the first coord
inate satisfies
$$\left|\frac{t}{1+|t|}\right|=\frac{|t|}{1+|t|}<1,$$
so $f(t)=(u,0)$ with $|u|<1$, hence $u^2+0^2<1\le 1$. Thus $f(t)$ lies in the (o
pen, hence also closed) unit disk.

**Injectivity.** Suppose $f(s)=f(t)$. Then
$$\frac{s}{1+|s|}=\frac{t}{1+|t|}.$$
Call this common value $u$. Note $|u|<1$, and the map $g:\mathbb{R}\to(-1,1)$ gi
ven by $g(t)=t/(1+|t|)$ is strictly increasing: for $s<t$, if both are non-negat
ive then $g(s)<g(t)$ since $h(r)=r/(1+r)$ is increasing on $[0,\infty)$; if both
 are non-positive then $g(s)<g(t)$ since $g$ is odd and increasing on $(-\infty,
0]$; if $s<0<t$ then $g(s)<0<g(t)$. In all cases $s<t\Rightarrow g(s)<g(t)$, so
$g$ is injective. Therefore $g(s)=g(t)$ implies $s=t$.

Hence $f$ is injective. $\blacksquare$
