# Problem

In a specialized testing facility, a 10x10 grid of server racks is arranged, where each rack contains a specific number of encrypted data packets (each represented by an integer). A data maintenance protocol defines a "Stable Zone" as any rectangular block of racks where the total sum of all data packets within that block is exactly divisible by 5.

A technician is tasked with activating a cooling system for these Stable Zones. The cooling system can be activated for any Stable Zone at any time, but due to power constraints, no individual rack can be cooled more than once. The technician’s goal is to protect as many racks as possible by incorporating them into cooled Stable Zones.

What is the maximum number $d$ such that, regardless of the number of packets stored in each rack or how they are distributed across the 10x10 grid, the technician is always guaranteed to be able to cool at least $d$ racks?
