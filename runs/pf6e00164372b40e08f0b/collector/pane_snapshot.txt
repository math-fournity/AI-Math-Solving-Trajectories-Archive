Yes. Any homomorphism $f: H \to D$ with $H \le A$ and $D$ divisible can be exten
ded to $g: A \to D$. This is the classical theorem that **divisible abelian grou
ps are injective objects in the category of abelian groups** (equivalently, inje
ctive $\mathbb{Z}$-modules).

## Proof

We use Zorn's lemma. Consider the collection $\mathcal{F}$ of all pairs $(K, \va
rphi)$ where

- $H \le K \le A$, and
- $\varphi: K \to D$ is a homomorphism with $\varphi|_H = f$.

$\mathcal{F}$ is nonempty (it contains $(H, f)$). Partially order $\mathcal{F}$
by
$$(K_1, \varphi_1) \le (K_2, \varphi_2) \iff K_1 \le K_2 \text{ and } \varphi_2|
_{K_1} = \varphi_1.$$

**Every chain has an upper bound.** Let $\{(K_i, \varphi_i)\}_{i \in I}$ be a ch
ain. Set $K = \bigcup_i K_i$; this is a subgroup of $A$ containing $H$. Define $
\varphi: K \to D$ by $\varphi(x) = \varphi_i(x)$ for any $i$ with $x \in K_i$. T
his is well-defined because the chain is totally ordered, so any two indices are
 comparable and the corresponding maps agree on the overlap. It is a homomorphis
m extending $f$, so $(K, \varphi) \in \mathcal{F}$ is an upper bound.

By Zorn's lemma, $\mathcal{F}$ has a maximal element $(M, \psi)$.

**Claim: $M = A$.** Suppose for contradiction that $M \subsetneq A$. Pick $a \in
 A \setminus M$ and let $M' = \langle M, a \rangle = M + \mathbb{Z}a$. We extend
 $\psi$ to $M'$, contradicting maximality.

Consider the subgroup $M \cap \mathbb{Z}a$ of the cyclic group $\mathbb{Z}a$. Tw
o cases:

**Case 1: $M \cap \mathbb{Z}a = \{0\}$.** Then $M' = M \oplus \mathbb{Z}a$. Defi
ne $\psi'(m + ka) = \psi(m)$ (equivalently, send $a \mapsto 0$). This is a well-
defined homomorphism $M' \to D$ extending $\psi$.

**Case 2: $M \cap \mathbb{Z}a \neq \{0\}$.** Then $M \cap \mathbb{Z}a = n\mathbb
{Z}a$ for a unique integer $n \ge 1$ (the smallest positive integer with $na \in
 M$). Define $\alpha := \psi(na) \in D$. Since $D$ is divisible, there exists $d
 \in D$ with $nd = \alpha$. Now define
$$\psi': M' \to D, \qquad \psi'(m + ka) = \psi(m) + k\,d.$$

We must check this is well-defined. Suppose $m_1 + k_1 a = m_2 + k_2 a$, i.e. $(
m_1 - m_2) = (k_2 - k_1)a \in M \cap \mathbb{Z}a = n\mathbb{Z}a$. So $k_2 - k_1
= nq$ for some $q \in \mathbb{Z}$, and $m_1 - m_2 = q(na)$. Then
$$\psi(m_1) - \psi(m_2) = \psi(m_1 - m_2) = \psi(q\cdot na) = q\,\psi(na) = q\,\
alpha = q(nd) = (nq)d = (k_2 - k_1)d.$$
Hence $\psi(m_1) + k_1 d = \psi(m_2) + k_2 d$, so $\psi'$ is well-defined. It is
 clearly a homomorphism and $\psi'|_M = \psi$, so $(M', \psi') \in \mathcal{F}$
strictly extends $(M, \psi)$.

In both cases we obtain a strict extension of $(M, \psi)$, contradicting maximal
ity. Therefore $M = A$, and $g := \psi: A \to D$ is the desired extension of $f$
. $\blacksquare$
