## Spectrum of the Multiplication Operator $M_b$ on $L_2(\mathbb{R}^n)$

### Setup

The operator $M_b: L_2(\mathbb{R}^n) \to L_2(\mathbb{R}^n)$ is defined by $(M_b
f)(x) = b(x) f(x)$ with $b(x) = e^{|x|^2}$. Since $b$ is unbounded ($b(x) \to \i
nfty$ as $|x|\to\infty$), $M_b$ is an **unbounded** operator with domain

$$D(M_b) = \{f \in L_2(\mathbb{R}^n) : b\,f \in L_2(\mathbb{R}^n)\}.$$

This domain is dense in $L_2(\mathbb{R}^n)$ (it contains $C_c^\infty(\mathbb{R}^
n)$), and $M_b$ is self-adjoint on this domain (being a multiplication operator
by a real-valued measurable function).

### Key Theorem

For a (possibly unbounded) multiplication operator $M_b$ on $L_2(\mathbb{R}^n)$,
 the spectrum equals the **essential range** of $b$:

$$\sigma(M_b) = \operatorname{ess\,range}(b).$$

The essential range is the set of all $\lambda \in \mathbb{C}$ such that for eve
ry $\varepsilon > 0$, the set $\{x \in \mathbb{R}^n : |b(x) - \lambda| < \vareps
ilon\}$ has positive Lebesgue measure.

### Proof of the Theorem (applied to our $b$)

**Step 1: $\lambda \notin \operatorname{ess\,range}(b) \Rightarrow \lambda \in \
rho(M_b)$.**

If $\lambda \notin \operatorname{ess\,range}(b)$, there exists $\varepsilon > 0$
 such that $|b(x) - \lambda| \geq \varepsilon$ for a.e. $x$. Then $g(x) := 1/(b(
x)-\lambda)$ satisfies $|g(x)| \leq 1/\varepsilon$ a.e., so $g \in L_\infty(\mat
hbb{R}^n)$. The multiplication operator $M_g$ is bounded (with $\|M_g\| \leq 1/\
varepsilon$) and serves as the inverse of $M_b - \lambda I$: for $f \in D(M_b)$,

$$(M_b - \lambda I)f = (b - \lambda)f, \qquad M_g\bigl[(b-\lambda)f\bigr] = f,$$

and for any $h \in L_2$, $M_g h \in D(M_b)$ since $b \cdot g \cdot h = h \in L_2
$. Hence $M_b - \lambda I$ is bijective $D(M_b) \to L_2$ with bounded inverse, s
o $\lambda \in \rho(M_b)$.

**Step 2: $\lambda \in \operatorname{ess\,range}(b) \Rightarrow \lambda \in \sig
ma(M_b)$.**

If $\lambda \in \operatorname{ess\,range}(b)$, then for every $\varepsilon > 0$
the set $E_\varepsilon = \{x : |b(x) - \lambda| < \varepsilon\}$ has positive me
asure. The function $1/(b - \lambda)$ is not essentially bounded (it exceeds $1/
\varepsilon$ on $E_\varepsilon$ for every $\varepsilon$), so $M_{1/(b-\lambda)}$
 is not a bounded operator on $L_2$. Therefore $M_b - \lambda I$ cannot have a b
ounded inverse, and $\lambda \in \sigma(M_b)$.

### Computing the Essential Range of $b(x) = e^{|x|^2}$

The function $b(x) = e^{|x|^2}$ is continuous with range $[1, \infty)$:
- $b(0) = e^0 = 1$ (minimum value),
- $b(x) \to \infty$ as $|x| \to \infty$,
- $b$ is continuous, so by the intermediate value theorem it attains every value
 in $[1, \infty)$.

**For $\lambda \in [1, \infty)$ and any $\varepsilon > 0$:** The set $\{x : |e^{
|x|^2} - \lambda| < \varepsilon\}$ is open (by continuity of $b$) and nonempty (
since $\lambda$ is in the range of $b$). An open nonempty subset of $\mathbb{R}^
n$ has positive Lebesgue measure. Hence $\lambda \in \operatorname{ess\,range}(b
)$.

**For $\lambda \notin [1, \infty)$ (i.e., $\lambda < 1$ or $\lambda \in \mathbb{
C} \setminus \mathbb{R}$):** Since $b(x) \geq 1$ for all $x$, choosing $\varepsi
lon = \frac{1}{2}\operatorname{dist}(\lambda, [1,\infty)) > 0$ gives $\{x : |b(x
) - \lambda| < \varepsilon\} = \varnothing$, which has measure zero. Hence $\lam
bda \notin \operatorname{ess\,range}(b)$.

Therefore:

$$\operatorname{ess\,range}(b) = [1, \infty).$$

### The Spectrum is Purely Continuous

There are **no eigenvalues**. If $M_b f = \lambda f$ for some $f \in D(M_b)$, th
en $(b(x) - \lambda) f(x) = 0$ a.e., so $f = 0$ a.e. on $\{x : b(x) \neq \lambda
\}$. For $\lambda \in [1, \infty)$:
- If $\lambda = 1$: $\{x : b(x) = 1\} = \{0\}$, a single point (measure zero), s
o $f = 0$ a.e.
- If $\lambda > 1$: $\{x : b(x) = \lambda\} = \{x : |x|^2 = \ln\lambda\}$, a sph
ere of radius $\sqrt{\ln\lambda}$ (measure zero in $\mathbb{R}^n$), so $f = 0$ a
.e.

Thus $\ker(M_b - \lambda I) = \{0\}$ for all $\lambda$, and the entire spectrum
is **continuous spectrum**.

### Conclusion

$$\boxed{\sigma(M_b) = [1, \infty)}$$

The spectrum of $M_b$ is the closed interval $[1, \infty)$, consisting entirely
of continuous spectrum (no point spectrum, no residual spectrum).
