## Theorem

Every $k$-algebra automorphism of $M_n(k)$ is inner. That is, for every $k$-alge
bra automorphism $\varphi: M_n(k)\to M_n(k)$, there exists $P\in \mathrm{GL}_n(k
)$ such that
$$\varphi(X)=PXP^{-1}\quad\text{for all }X\in M_n(k).$$

Conversely, every map $X\mapsto PXP^{-1}$ with $P\in\mathrm{GL}_n(k)$ is a $k$-a
lgebra automorphism. Hence
$$\operatorname{Aut}_{k\text{-alg}}(M_n(k))\cong \mathrm{PGL}_n(k)=\mathrm{GL}_n
(k)/k^{\times}.$$

## Proof

### Step 1. Reduction to fixing a rank-one idempotent

Let $E=e_{11}$ be the matrix with $1$ in position $(1,1)$ and $0$ elsewhere. The
n $E$ is a rank-one idempotent ($E^2=E$), and $\varphi(E)$ is again an idempoten
t since $\varphi$ is a ring homomorphism. We claim $\varphi(E)$ has rank one.

Indeed, $E\cdot M_n(k)\cdot E = k\cdot E$ is one-dimensional over $k$ (it consis
ts of scalar multiples of $E$). Since $\varphi$ is an algebra automorphism,
$$\varphi(E)\,M_n(k)\,\varphi(E)=\varphi(E\,M_n(k)\,E)=\varphi(k\cdot E)=k\cdot\
varphi(E),$$
so $\varphi(E)\,M_n(k)\,\varphi(E)$ is one-dimensional. For an idempotent $F$ of
 rank $r$, the space $F\,M_n(k)\,F\cong M_r(k)$ has dimension $r^2$. Hence $r^2=
1$, so $r=1$.

### Step 2. Conjugate $\varphi(E)$ back to $E$

Any two rank-one idempotents in $M_n(k)$ are conjugate: if $F$ has rank one, the
n $F=uv^{T}$ for nonzero $u,v\in k^n$ with $v^{T}u=1$ (since $F^2=F$ forces $v^{
T}u=1$). Extending $u$ to a basis and using $v^{T}$ as the first row of an inver
tible matrix gives $P_0 FP_0^{-1}=E$ for some $P_0\in\mathrm{GL}_n(k)$.

Define $\psi(X)=P_0\,\varphi(X)\,P_0^{-1}$. Then $\psi$ is a $k$-algebra automor
phism (composition of $\varphi$ with an inner automorphism) and $\psi(E)=E$. It
suffices to show $\psi=\mathrm{id}$, for then $\varphi(X)=P_0^{-1}XP_0$, which i
s inner.

### Step 3. $\psi$ fixes $E$ implies $\psi$ preserves the "corner" decomposition

With $E=e_{11}$, write the standard matrix units $e_{ij}$. The identity $\psi(E)
=E$ plus $\psi$ being a homomorphism gives:
- $\psi(e_{1j})=\psi(E\,e_{1j})=\psi(E)\psi(e_{1j})=E\,\psi(e_{1j})$, so $\psi(e
_{1j})$ has nonzero entries only in row $1$;
- $\psi(e_{1j})=\psi(e_{1j}\,E)=\psi(e_{1j})\psi(E)=\psi(e_{1j})E$ (for $j=1$; f
or $j\ge 2$ use $e_{1j}=e_{1j}\,e_{jj}$ and handle column index).

More systematically: from $e_{ij}e_{kl}=\delta_{jk}e_{il}$ and $\psi$ preserving
 products, the images $f_{ij}:=\psi(e_{ij})$ satisfy $f_{ij}f_{kl}=\delta_{jk}f_
{il}$ and $\sum_i f_{ii}=I$. So $\{f_{ij}\}$ is a full system of matrix units.

### Step 4. A full system of matrix units with $f_{11}=E$ is the standard one, u
p to the diagonal

Since $f_{11}=E=e_{11}$, the relation $f_{1j}=f_{11}f_{1j}=e_{11}f_{1j}$ forces
$f_{1j}$ to be supported in row $1$, and $f_{1j}=f_{1j}f_{jj}$ forces $f_{jj}$ t
o have a $1$ in the $(j,j)$ position pattern. Concretely, $f_{1j}=\alpha_j e_{1j
}$ for some $\alpha_j\in k^{\times}$ (nonzero since $f_{1j}f_{j1}=f_{11}=e_{11}\
ne 0$). Then $f_{j1}=\alpha_j^{-1}e_{j1}$ (from $f_{1j}f_{j1}=e_{11}$), and $f_{
ij}=f_{i1}f_{1j}=\alpha_j\alpha_i^{-1}\,e_{ij}$.

### Step 5. $\psi$ is $k$-linear and fixes scalars, forcing all $\alpha_j=1$

Since $\psi$ is a **$k$-algebra** automorphism, it fixes $k$ pointwise: $\psi(\l
ambda I)=\lambda I$. Now $\alpha_j e_{1j}=f_{1j}=\psi(e_{1j})$. Consider $\lambd
a e_{1j}=\psi(\lambda e_{1j})$ (because $\psi$ is $k$-linear and $\psi(e_{1j})=\
alpha_j e_{1j}$, so $\psi(\lambda e_{1j})=\lambda\alpha_j e_{1j}$). Wait — we ne
ed to use $k$-linearity directly: $\psi(\lambda e_{1j})=\lambda\psi(e_{1j})=\lam
bda\alpha_j e_{1j}$.

But also $\lambda e_{1j}=(\lambda e_{11})e_{1j}$, and $\lambda e_{11}=\lambda E\
cdot (\text{something})$... Let me use the cleaner argument: $\psi$ is $k$-linea
r, so $\psi(\lambda e_{1j})=\lambda\psi(e_{1j})=\lambda\alpha_j e_{1j}$. On the
other hand, $\lambda e_{1j}=e_{1j}\cdot(\lambda e_{jj})$. Hmm, this requires kno
wing $\psi(\lambda e_{jj})$.

The cleanest route: **$\psi$ is $k$-linear and unital**, so for the scalar matri
x $\lambda I$ we have $\psi(\lambda I)=\lambda I$. Now
$$\psi(\lambda e_{1j})=\psi((\lambda e_{11})e_{1j})=\psi(\lambda e_{11})\,\psi(e
_{1j}).$$
Since $\lambda e_{11}=\lambda E$ and $\psi(E)=E$, and $\psi$ is $k$-linear: $\ps
i(\lambda E)=\lambda\psi(E)=\lambda E$. Therefore
$$\psi(\lambda e_{1j})=(\lambda E)(\alpha_j e_{1j})=\lambda\alpha_j e_{1j}.$$
But $k$-linearity also gives $\psi(\lambda e_{1j})=\lambda\psi(e_{1j})=\lambda\a
lpha_j e_{1j}$ — consistent but not yet forcing $\alpha_j=1$.

The key point: $\psi$ being a **$k$-algebra** map means it is $k$-**linear**, an
d we've used that. The relation $f_{ij}=\alpha_j\alpha_i^{-1}e_{ij}$ already use
d $k$-linearity. To pin down $\alpha_j$, we use that $\psi$ fixes the **center**

Here is the decisive argument. We have $f_{jj}=\psi(e_{jj})$. Since $\sum_j e_{j
j}=I$ and $\psi(I)=I$, we get $\sum_j f_{jj}=I$. With $f_{jj}=\alpha_j\alpha_j^{
-1}e_{jj}=e_{jj}$ (from Step 4's formula $f_{ij}=\alpha_j\alpha_i^{-1}e_{ij}$ wi
th $i=j$), we get $f_{jj}=e_{jj}$. Good — the diagonal is fixed. Now use $e_{1j}

$$f_{1j}f_{j1}=(\alpha_j e_{1j})(\alpha_j^{-1}e_{j1})=e_{11}=E\;\checkmark,\qqua
d f_{j1}f_{1j}=(\alpha_j^{-1}e_{j1})(\alpha_j e_{1j})=e_{jj}\;\checkmark.$$
These are automatically satisfied for any $\alpha_j$. So the matrix-unit relatio

^{\times})^{n-1}$.

The forcing comes from **$k$-algebra** structure (not just ring structure). Cons
ider the element $e_{11}+e_{22}+\dots+e_{nn}=I$ (already used). Consider instead

The correct forcing: $\psi$ is $k$-**linear**, and $k$-linearity with $\psi(e_{j

$$\psi(e_{1j})=\psi(e_{1j}\,e_{jj})=\psi(e_{1j})\,\psi(e_{jj})=(\alpha_j e_{1j})
\,e_{jj}=\alpha_j e_{1j}.\;\checkmark\text{ (consistent)}$$
Still consistent. The genuine constraint is $k$-linearity applied to **sums mixi
ng different matrix units**: e.g. $e_{11}+e_{12}$. We have
$$\psi(e_{11}+e_{12})=\psi(e_{11})+\psi(e_{12})=e_{11}+\alpha_2 e_{12}.$$
This is fine for any $\alpha_2$.

**The real forcing uses the center.** The center of $M_n(k)$ is $k\cdot I$, and
$\psi$ fixes it pointwise. But that is already built in. So in fact, for a **rin
g** automorphism (not $k$-algebra), the $\alpha_j$ can be nontrivial — these are
 the "Galois-twisted" automorphisms when $k$ has automorphisms. For a **$k$-alge

 which we've fully exploited, and it does **not** by itself kill the $\alpha_j$.

Let me reconsider. The $\alpha_j$ arise from the choice of basis vectors in Step

a_2,\dots,\alpha_n)$:
$$\mathrm{diag}(1,\alpha_2,\dots,\alpha_n)\,e_{ij}\,\mathrm{diag}(1,\alpha_2,\do
ts,\alpha_n)^{-1}=\alpha_j\alpha_i^{-1}e_{ij}=f_{ij}.$$
So **any** such system $\{f_{ij}\}$ is realized by an inner automorphism (conjug
ation by a diagonal matrix). Therefore $\psi$ equals conjugation by $D=\mathrm{d
iag}(1,\alpha_2,\dots,\alpha_n)$, which is inner. Combined with Step 2's conjuga
tion by $P_0$, we get $\varphi$ = conjugation by $P_0^{-1}D$, which is inner.

### Step 6. Conclusion

We have shown: given any $k$-algebra automorphism $\varphi$, after composing wit
h a suitable inner automorphism (conjugation by $P_0$ to send $\varphi(E)$ to $E
$), the resulting $\psi$ sends the standard matrix units $\{e_{ij}\}$ to another
 full system $\{f_{ij}\}$ with $f_{11}=e_{11}$, and every such system is realize
d by conjugation by a diagonal matrix $D$. Hence $\psi$ is inner (conjugation by
 $D$), and therefore $\varphi$ is inner (conjugation by $P_0^{-1}D$).

The converse (every inner automorphism is a $k$-algebra automorphism) is immedia
te: $X\mapsto PXP^{-1}$ is $k$-linear, unital, and multiplicative.

Two invertible matrices $P,Q$ give the same inner automorphism iff $P^{-1}Q$ is
central, i.e. $P^{-1}Q\in k^{\times}\cdot I$. Hence
$$\operatorname{Aut}_{k\text{-alg}}(M_n(k))\cong \mathrm{GL}_n(k)/k^{\times}=\ma
thrm{PGL}_n(k).$$

$\blacksquare$
