## Proof

We seek the minimum of

$$J(y) = \int_a^b \sqrt{1 + y'(x)^2}\, dx$$

over all continuously differentiable functions $y \in C^1([a,b])$, with **no bou
ndary conditions** imposed on $y(a)$ or $y(b)$.

**Lower bound.** For every real number $t$, we have $\sqrt{1+t^2} \geq 1$, with
equality if and only if $t = 0$. Applying this pointwise with $t = y'(x)$,

$$\sqrt{1 + y'(x)^2} \geq 1 \quad \text{for all } x \in [a,b],$$

with equality at any point $x$ where $y'(x) = 0$. Integrating,

$$J(y) = \int_a^b \sqrt{1 + y'(x)^2}\, dx \geq \int_a^b 1\, dx = b - a.$$

This holds for every $y \in C^1([a,b])$, so $b - a$ is a lower bound for $J$.

**Attainment.** The constant function $y(x) = c$ (for any constant $c$) belongs
to $C^1([a,b])$ and satisfies $y'(x) = 0$ for all $x$. For this function,

$$J(y) = \int_a^b \sqrt{1 + 0}\, dx = \int_a^b 1\, dx = b - a.$$

Thus the lower bound is achieved.

**Uniqueness of the minimizer (up to additive constant).** Equality in $J(y) = b
-a$ requires $\sqrt{1+y'(x)^2} = 1$ almost everywhere, hence $y'(x) = 0$ everywh
ere (by continuity of $y'$). Therefore $y$ must be constant. So the minimizers a
re exactly the constant functions, and the minimum value is unique.

**Conclusion.** The minimum value of the functional is

$$\boxed{b - a}.$$
