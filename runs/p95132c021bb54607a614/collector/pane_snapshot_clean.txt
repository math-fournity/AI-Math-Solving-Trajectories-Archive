Looking at this problem, I need to determine whether finite **L-normal** strings
 exist for L > 2, where a string is L-normal if every length-L string over the a
lphabet appears the same number of times as a contiguous (overlapping) substring
.

---

## Proof

**Yes**, such finite strings exist for every L ≥ 1, including all L > 2.

**Definition.** A finite string $w$ over an alphabet $\Sigma$ of size $k$ is *L-
normal* if every string of length $L$ over $\Sigma$ appears the same number of t
imes as a contiguous substring of $w$ (counting overlaps).

**Construction via de Bruijn sequences.** A *de Bruijn sequence* $B(k, L)$ is a
cyclic sequence of length $k^L$ over a $k$-symbol alphabet in which every possib
le length-$L$ string appears exactly once as a contiguous substring (wrapping ar
ound cyclically). Such sequences exist for all $k \ge 2$ and $L \ge 1$.

To obtain a *linear* L-normal string from a de Bruijn sequence: take the cyclic
sequence of length $k^L$ and append its first $L-1$ symbols to the end. The resu
lting linear string has length $k^L + L - 1$ and contains exactly $k^L$ substrin
gs of length $L$, each appearing exactly once. Hence it is L-normal (with multip
licity $m = 1$).

**Existence of de Bruijn sequences (Eulerian circuit argument).** Consider the d
e Bruijn graph $G(k, L-1)$: its vertices are all $(L-1)$-strings over $\Sigma$,
and for each $L$-string $a_1 a_2 \cdots a_L$ there is a directed edge from $a_1
\cdots a_{L-1}$ to $a_2 \cdots a_L$. Every vertex has in-degree $k$ and out-degr
ee $k$, and the graph is (strongly) connected. By Euler's theorem, an Eulerian c
ircuit exists. Reading off the edge labels along such a circuit yields a de Brui
jn sequence $B(k, L)$.

**Explicit example for $L = 3$, $k = 2$.** The de Bruijn sequence $B(2,3) = 0001
0111$ (cyclic). Appending the first $L-1 = 2$ symbols gives the linear string:

$$w = 0001011100$$

Its length-3 substrings (at positions 1 through 8) are:

$$000,\; 001,\; 010,\; 101,\; 011,\; 111,\; 110,\; 100$$

These are all $2^3 = 8$ binary strings of length 3, each appearing exactly once.
 Thus $w$ is 3-normal.

**Conclusion.** Since de Bruijn sequences $B(k, L)$ exist for every order $L \ge
 1$ and every alphabet size $k \ge 2$ (by the Eulerian circuit argument), and th
eir linearizations are L-normal, finite L-normal strings exist for all $L > 2$.
