# Sobolev H¹ Inner Product: Solution

## (a) Explicit Formulae

The induced norm is $\|f\| = \sqrt{\langle f, f\rangle} = \sqrt{\int_0^1\!\bigl[
f(x)^2 + f'(x)^2\bigr]\,dx}$.

**Cauchy–Schwarz inequality** ($|\langle f,g\rangle|^2 \le \langle f,f\rangle\,\
langle g,g\rangle$), written out explicitly:

$$\left|\int_0^1\!\bigl[f(x)\,g(x)+f'(x)\,g'(x)\bigr]\,dx\right|^2 \;\le\; \left
(\int_0^1\!\bigl[f(x)^2+f'(x)^2\bigr]\,dx\right)\!\left(\int_0^1\!\bigl[g(x)^2+g
'(x)^2\bigr]\,dx\right).$$

**Triangle inequality** ($\|f+g\|\le\|f\|+\|g\|$), written out explicitly:

$$\sqrt{\int_0^1\!\Bigl[\bigl(f(x)+g(x)\bigr)^2+\bigl(f'(x)+g'(x)\bigr)^2\Bigr]\
,dx} \;\le\; \sqrt{\int_0^1\!\bigl[f(x)^2+f'(x)^2\bigr]\,dx} \;+\; \sqrt{\int_0^
1\!\bigl[g(x)^2+g'(x)^2\bigr]\,dx}.$$

---

## (b) Direct Verification for $f(x)=1$, $g(x)=e^x$

We have $f(x)=1,\; f'(x)=0$ and $g(x)=e^x,\; g'(x)=e^x$.

**Three inner products.**

$$\langle f,f\rangle = \int_0^1\!\bigl[1^2+0^2\bigr]\,dx = \int_0^1 1\,dx = 1.$$

$$\langle g,g\rangle = \int_0^1\!\bigl[e^{2x}+e^{2x}\bigr]\,dx = 2\int_0^1 e^{2x
}\,dx = 2\cdot\frac{e^{2x}}{2}\Big|_0^1 = e^2-1.$$

$$\langle f,g\rangle = \int_0^1\!\bigl[1\cdot e^x+0\cdot e^x\bigr]\,dx = \int_0^
1 e^x\,dx = e-1.$$

**Cauchy–Schwarz check.** We need $|\langle f,g\rangle|^2 \le \langle f,f\rangle
\,\langle g,g\rangle$, i.e.

$$(e-1)^2 \le 1\cdot(e^2-1).$$

Expanding: $e^2-2e+1 \le e^2-1 \iff -2e+1\le -1 \iff e\ge 1$, which holds since
$e\approx 2.718$. Numerically: LHS $\approx 2.952$, RHS $\approx 6.389$. ✓

**Triangle inequality check.** First compute $\|f+g\|^2$. Since $f+g = 1+e^x$ an
d $(f+g)'=e^x$,

$$\|f+g\|^2 = \int_0^1\!\bigl[(1+e^x)^2+e^{2x}\bigr]\,dx = \int_0^1\!\bigl[1+2e^
x+2e^{2x}\bigr]\,dx = \Bigl[x+2e^x+e^{2x}\Bigr]_0^1.$$

Evaluating: $(1+2e+e^2)-(0+2+1) = e^2+2e-2$.

So $\|f+g\|=\sqrt{e^2+2e-2}$, $\|f\|=1$, $\|g\|=\sqrt{e^2-1}$.

We need $\sqrt{e^2+2e-2}\le 1+\sqrt{e^2-1}$. Both sides are positive, so square:

$$e^2+2e-2 \le 1+2\sqrt{e^2-1}+(e^2-1) = e^2+2\sqrt{e^2-1},$$

giving $e-1\le\sqrt{e^2-1}$. Squaring again (both sides positive since $e>1$):

$$(e-1)^2 \le e^2-1 \iff e^2-2e+1\le e^2-1 \iff e\ge 1. \quad\checkmark$$

Numerically: $\|f+g\|\approx\sqrt{10.825}\approx 3.290$, $\|f\|+\|g\|\approx 1+\
sqrt{6.389}\approx 3.528$. ✓

---

## (c) The Angle Between $f$ and $g$

The angle $\theta\in[0,\pi]$ is defined by

$$\cos\theta = \frac{\langle f,g\rangle}{\|f\|\,\|g\|} = \frac{e-1}{1\cdot\sqrt{
e^2-1}}.$$

Since $e^2-1=(e-1)(e+1)$,

$$\cos\theta = \frac{e-1}{\sqrt{(e-1)(e+1)}} = \sqrt{\frac{e-1}{e+1}}.$$

Therefore

$$\boxed{\theta = \arccos\!\sqrt{\dfrac{e-1}{e+1}}}.$$

Numerically, $\frac{e-1}{e+1}\approx\frac{1.718}{3.718}\approx 0.4621$, so $\cos
\theta\approx\sqrt{0.4621}\approx 0.6798$, giving

$$\theta \approx 0.8248\ \text{rad}\approx 47.26^\circ.$$
