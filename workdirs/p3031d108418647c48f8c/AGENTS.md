# Problem

A high-tech server farm consists of $2^n$ individual processing nodes and one central master controller. The system operates on internal data packets: high-capacity "Blocks" representing $2^n$ terabytes and smaller "Fragments" of size $2^a$ terabytes, where $a \in \{0, 1, \dots, n-1\}$.

Each processing node has access to an infinite supply of high-capacity Blocks. However, the system relies on a fixed total pool of $S$ Fragments distributed among the nodes. Every midnight, the system performs a mandatory data redistribution cycle. During this cycle, every node must transmit a finite total amount of data to either another node or to the master controller. The protocol requires that for every individual node, the total data it sends out must be exactly 1 terabyte greater than the total data it received from other nodes during that same cycle.

Determine the minimum total number of Fragments $S$ that must be present in the system to ensure that the master controller can receive a non-zero amount of data every night indefinitely.
