## Solution

We evaluate $I = \int_0^\infty \frac{\log x}{(x^2+1)^2}\,dx$ using a parametric
(differentiation under the integral sign) approach.

**Step 1: Introduce a parameter.** Define
$$I(a) = \int_0^\infty \frac{x^a}{(x^2+1)^2}\,dx, \qquad -1 < a < 3,$$
so that $I'(0) = \int_0^\infty \frac{x^a \log x}{(x^2+1)^2}\,dx\Big|_{a=0} = I$,
 the desired integral.

**Step 2: Evaluate $I(a)$ via the Beta function.** Substitute $t = x^2$, so $x =
 t^{1/2}$, $dx = \frac{1}{2}t^{-1/2}\,dt$:
$$I(a) = \frac{1}{2}\int_0^\infty \frac{t^{(a-1)/2}}{(t+1)^2}\,dt.$$
Using the standard identity $\int_0^\infty \frac{t^{p-1}}{(1+t)^{p+q}}\,dt = B(p
,q) = \frac{\Gamma(p)\,\Gamma(q)}{\Gamma(p+q)}$, we identify
$$p = \frac{a+1}{2}, \qquad p+q = 2 \implies q = \frac{3-a}{2}.$$
Since $\Gamma(2)=1$,
$$I(a) = \frac{1}{2}\,\Gamma\!\left(\tfrac{a+1}{2}\right)\Gamma\!\left(\tfrac{3-
a}{2}\right).$$

**Step 3: Differentiate.** Using $\Gamma'(s) = \Gamma(s)\,\psi(s)$ (digamma func
tion):
$$I'(a) = \frac{1}{2}\left[\frac{1}{2}\Gamma'\!\left(\tfrac{a+1}{2}\right)\Gamma
\!\left(\tfrac{3-a}{2}\right) - \frac{1}{2}\Gamma\!\left(\tfrac{a+1}{2}\right)\G
amma'\!\left(\tfrac{3-a}{2}\right)\right].$$
At $a=0$: $\Gamma(1/2)=\sqrt{\pi}$, $\Gamma(3/2)=\frac{\sqrt{\pi}}{2}$, so
$$I'(0) = \frac{1}{4}\left[\Gamma'(1/2)\,\Gamma(3/2) - \Gamma(1/2)\,\Gamma'(3/2)
\right] = \frac{\pi}{8}\left[\psi(1/2)-\psi(3/2)\right].$$

**Step 4: Use the digamma recurrence.** $\psi(z+1) = \psi(z) + 1/z$ with $z=1/2$
 gives
$$\psi(3/2) = \psi(1/2) + 2 \implies \psi(1/2)-\psi(3/2) = -2.$$

**Step 5: Conclude.**
$$I = I'(0) = \frac{\pi}{8}\cdot(-2) = -\frac{\pi}{4}.$$

**Consistency check.** The substitution $x \mapsto 1/x$ gives $I = -\int_0^\inft
y \frac{x^2\log x}{(1+x^2)^2}\,dx$, so $I + (-I) = \int_0^\infty \frac{\log x}{1
+x^2}\,dx = 0$ (the well-known value), confirming consistency. The negative sign
 is expected since the integrand is negative and singular near $x=0$ while the p
ositive tail on $(1,\infty)$ decays like $\frac{\log x}{x^4}$.

$$\int_0^\infty \frac{\log x}{(x^2+1)^2}\,dx = -\frac{\pi}{4}.$$
