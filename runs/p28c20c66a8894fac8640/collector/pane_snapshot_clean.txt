**Setup.** Let $\psi \in C^\infty(\mathbb{R})$ with $\psi(x)=1$ for $|x|\le 1/2$

Define the sequence:
$$x_n = 2^n, \qquad h_n = \frac{2^{-n/2}}{n}, \qquad w_n = h_n, \qquad n\ge 1.$$

Set
$$f(x) = \sum_{n=1}^{\infty} h_n\,\psi\!\left(\frac{x - x_n}{w_n}\right), \qquad
 f(x)=0 \text{ for } x\le 1.$$

**Disjoint supports.** The $n$-th bump has support $[x_n - w_n,\, x_n + w_n]$. S
ince $w_n = 2^{-n/2}/n \ll 2^n = x_n$ and $x_{n+1}-x_n = 2^n \gg h_n + h_{n+1}$,
 all supports are pairwise disjoint and lie in $(1,\infty)$. The sum is locally
finite, so $f\in C^\infty(\mathbb{R})$.

**Verification of hypotheses:**

1. **$f$ differentiable:** $f\in C^\infty$ as noted. ✓

2. **$f$ bounded:** On each bump $|f|\le h_n$, and $h_n = 2^{-n/2}/n$ is maximiz
ed at $n=1$: $h_1 = 1/\sqrt{2}$. Elsewhere $f=0$. So $\|f\|_\infty = 1/\sqrt{2}$
. ✓

3. **$f'$ bounded:** On the $n$-th bump, $|f'(x)| = \frac{h_n}{w_n}|\psi'((x-x_n
)/w_n)| \le \frac{h_n}{h_n}\cdot 2 = 2$. Between bumps $f'=0$. So $\|f'\|_\infty
 \le 2$. ✓

4. **$\int_{\mathbb{R}} |x\,f(x)|\,dx < \infty$:** By disjoint supports,
$$\int_{\mathbb{R}} |x\,f(x)|\,dx = \sum_{n=1}^{\infty} \int_{x_n-w_n}^{x_n+w_n}

$$x_n\, f(x_n) = 2^n \cdot h_n = 2^n \cdot \frac{2^{-n/2}}{n} = \frac{2^{n/2}}{n
