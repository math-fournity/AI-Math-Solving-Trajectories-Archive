## Solution

**Claim:** $\det(A) = \dfrac{(-1)^{n-1}}{(n-1)!\,n!}$.

### Setup and row operations

The entry $a_{ij} = 1/\min(i,j)$ means that row $i$ of $A$ is
$$R_i = \Bigl(\underbrace{1,\; 1/2,\; \dots,\; 1/i}_{\text{columns }1,\dots,i},\
; \underbrace{1/i,\; \dots,\; 1/i}_{\text{columns }i+1,\dots,n}\Bigr).$$

**Row reduction.** Replace $R_i \leftarrow R_i - R_{i+1}$ for $i = 1, \dots, n-1
$, leaving $R_n$ unchanged. These operations preserve the determinant. For $j \l
e i$: both rows have $1/j$, so the difference is $0$. For $j \ge i+1$: row $i$ h
as $1/i$ and row $i+1$ has $1/(i+1)$, giving $1/i - 1/(i+1) = 1/(i(i+1))$. Thus
the new row $i$ ($1 \le i \le n-1$) is:
$$\Bigl(\underbrace{0,\dots,0}_{i \text{ zeros}},\; \underbrace{\tfrac{1}{i(i+1)
},\dots,\tfrac{1}{i(i+1)}}_{n-i \text{ copies}}\Bigr).$$

Factor out $\frac{1}{i(i+1)}$ from row $i$ for each $i=1,\dots,n-1$:
$$\det(A) = \prod_{i=1}^{n-1}\frac{1}{i(i+1)}\;\cdot\;\det(B),$$
where $B$ has:
- **Row $i$** ($1 \le i \le n-1$): zeros in columns $1,\dots,i$; ones in columns
 $i+1,\dots,n$.
- **Row $n$**: $(1,\; 1/2,\; 1/3,\; \dots,\; 1/n)$.

### Column operations on $B$

Apply $C_j \leftarrow C_j - C_{j+1}$ for $j = n-1, n-2, \dots, 1$ (right to left
), leaving $C_n$ unchanged. These operations preserve $\det(B)$.

**For row $i \le n-1$:** The entry in new column $j < n$ is $B_{i,j} - B_{i,j+1}
$. Since row $i$ has $0$ in columns $1,\dots,i$ and $1$ in columns $i+1,\dots,n$
:
- $j < i$: $0 - 0 = 0$;
- $j = i$: $0 - 1 = -1$;
- $i < j < n$: $1 - 1 = 0$.

Column $n$ stays $1$. So row $i$ becomes: $-1$ in column $i$, $1$ in column $n$,
 $0$ elsewhere.

**For row $n$:** New column $j < n$ is $\frac{1}{j} - \frac{1}{j+1} = \frac{1}{j
(j+1)}$; column $n$ stays $\frac{1}{n}$.

Call the resulting matrix $B'$. Then $\det(B) = \det(B')$.

### Computing $\det(B')$

Expand along column $n$, whose entries are $B'_{i,n}=1$ for $i=1,\dots,n-1$ and
$B'_{n,n}=1/n$.

**Terms $i = 1, \dots, n-1$:** The minor $M_{i,n}$ is the $(n{-}1)\times(n{-}1)$
 matrix (deleting row $i$, column $n$) with:
- Rows $k \in \{1,\dots,n{-}1\}\setminus\{i\}$: $-1$ in column $k$, $0$ elsewher
e (unit vectors).
- Row $n$: $\frac{1}{j(j+1)}$ in each column $j = 1,\dots,n{-}1$.

Column $i$ has no unit vector, so only row $n$ contributes: entry $\frac{1}{i(i+
1)}$ at position (row $n-1$ in the minor, column $i$). The remaining $(n{-}2)\ti
mes(n{-}2)$ submatrix is $-I_{n-2}$ with determinant $(-1)^{n-2}$. Thus:
$$M_{i,n} = (-1)^{(n-1)+i}\cdot\frac{1}{i(i+1)}\cdot(-1)^{n-2} = (-1)^{i+1}\cdot
\frac{1}{i(i+1)}.$$

**Term $i = n$:** The minor $M_{n,n}$ is the $(n{-}1)\times(n{-}1)$ matrix of ro
ws $1,\dots,n{-}1$ and columns $1,\dots,n{-}1$, which is $-I_{n-1}$, so $M_{n,n}
 = (-1)^{n-1}$.

**Assembling:**
$$\det(B') = \sum_{i=1}^{n-1}(-1)^{i+n}\cdot 1\cdot(-1)^{i+1}\frac{1}{i(i+1)} \;
+\; (-1)^{2n}\cdot\frac{1}{n}\cdot(-1)^{n-1}.$$

Since $(-1)^{2i+n+1} = (-1)^{n+1} = (-1)^{n-1}$ and $(-1)^{2n}=1$:
$$\det(B') = (-1)^{n-1}\sum_{i=1}^{n-1}\frac{1}{i(i+1)} + (-1)^{n-1}\cdot\frac{1
}{n}.$$

The sum telescopes: $\sum_{i=1}^{n-1}\frac{1}{i(i+1)} = \sum_{i=1}^{n-1}\!\left(
\frac{1}{i}-\frac{1}{i+1}\right) = 1 - \frac{1}{n} = \frac{n-1}{n}$. Therefore:
$$\det(B') = (-1)^{n-1}\!\left(\frac{n-1}{n}+\frac{1}{n}\right) = (-1)^{n-1}\cdo
t\frac{n}{n} = (-1)^{n-1}.$$

### Final assembly

$$\det(A) = \prod_{i=1}^{n-1}\frac{1}{i(i+1)}\cdot(-1)^{n-1} = \frac{(-1)^{n-1}}
{\prod_{i=1}^{n-1}i\;\cdot\;\prod_{i=1}^{n-1}(i+1)} = \frac{(-1)^{n-1}}{(n-1)!\;
\cdot\; n!}.$$

**Verification:** $n=1$: $1/(0!\cdot1!)=1$ ✓. $n=2$: $-1/(1!\cdot2!) = -1/2$ ✓.
$n=3$: $1/(2!\cdot3!) = 1/12$ ✓.

$$\boxed{\det(A) = \frac{(-1)^{n-1}}{(n-1)!\,n!}}$$
