## Proof

We seek rational pairs (x, y) with y = √(x² + 1/1999). This is equivalent to:
- y² = x² + 1/1999, and
- y ≥ 0 (since y is a principal square root).

Rearranging: **y² − x² = 1/1999**, i.e., **(y − x)(y + x) = 1/1999**.

**Substitution.** Let u = y − x and v = y + x. Then:
- uv = 1/1999,
- y = (u + v)/2,
- x = (v − u)/2.

**Rationality.** The pair (x, y) is rational if and only if (u, v) is rational,
since the transformations are linear with rational coefficients (and invertible)
.

**Sign analysis.** Since uv = 1/1999 > 0, the numbers u and v share the same sig
n.
- If u, v < 0: then y = (u+v)/2 < 0, contradicting y ≥ 0.
- If u = 0 or v = 0: then uv = 0 ≠ 1/1999, impossible.
- Therefore **u > 0 and v > 0**.

**Constructing solutions.** For **any** positive rational u, set v = 1/(1999u),
which is also a positive rational. This yields:
$$x = \frac{1/(1999u) - u}{2}, \qquad y = \frac{u + 1/(1999u)}{2},$$
both rational, with y > 0. One verifies directly:
$$y^2 - x^2 = \left(\frac{u+v}{2}\right)^2 - \left(\frac{v-u}{2}\right)^2 = uv =
 \frac{1}{1999},$$
so y² = x² + 1/1999, and y > 0 ensures y = √(x² + 1/1999). ✓

**Injectivity.** The map u ↦ (x, y) is injective: from any solution pair we reco
ver u = y − x uniquely.

**Infinitely many solutions.** There are infinitely many positive rationals u. F
or instance, taking u = 1/n for each positive integer n gives a distinct solutio
n:

- *Example (u = 1):* v = 1/1999, giving x = (1/1999 − 1)/2 = −999/1999, y = (1 +
 1/1999)/2 = 1000/1999.

001 = 1000000/3996001 = (1000/1999)² = y². ✓

  - Verification: x² + 1/1999 = 1995²/7996² + 16·1999/7996² = (3980025 + 31984)/
63936016 = 4012009/63936016 = 2003²/7996² = y². ✓

Since each positive rational u yields a distinct valid rational pair, and there
are **infinitely many** positive rationals, the number of pairs (x, y) is **infi
