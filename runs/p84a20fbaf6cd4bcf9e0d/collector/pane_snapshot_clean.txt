For $n \in [2^k, 2^{k+1})$, we have $\lfloor \log_2 n \rfloor = k$, so $\mathbb{

$$\sum_{n=1}^{\infty} \mathbb{P}(A_n) = \sum_{k=0}^{\infty} \sum_{n=2^k}^{2^{k+1

**Step 4: Block construction.** For each $k \geq 2$, define the index set
$$\mathcal{S}_k = \left\{ n_{k,j} = 2^k + k + 1 + j(k+2) : j = 0, 1, \ldots, J_k

All $n_{k,j} \in [2^k, 2^{k+1})$, so $\mathbb{P}(A_{n_{k,j}}) = 2^{-k}$.

**Independence within a block:** For $j < j'$, we have $n_{k,j'} - n_{k,j} \geq
k+2 > k = \lfloor \log_2 n_{k,j}\rfloor$. Thus the coin index sets $[n_{k,j}+1,\

1] \subseteq [2^{k+1}+k+2,\, 2^{k+2}+k+1]$. Since $2^{k+1}+k < 2^{k+1}+k+2$, the

Therefore $\{A_{n_{k,j}}\}$ over all $k, j$ are **mutually independent**.

$$\sum_{k=2}^{\infty} \sum_{j=0}^{J_k} \mathbb{P}(A_{n_{k,j}}) = \sum_{k=2}^{\in

$$(J_k+1) \cdot 2^{-k} \geq \frac{2^k - k - 1}{(k+2) \cdot 2^k} = \frac{1}{k+2}\

$$\sum_{k=2}^{\infty} (J_k+1) \cdot 2^{-k} \geq \sum_{k \text{ large}} \frac{1}{
2(k+2)} = \infty.$$

$$\mathbb{P}\!\left(A_{n_{k,j}} \text{ occurs infinitely often}\right) = 1.$$

$$\mathbb{P}(A_n \text{ i.o.}) \geq \mathbb{P}(A_{n_{k,j}} \text{ i.o.}) = 1.$$

Since probabilities are at most 1:
$$\boxed{\mathbb{P}\!\left(\bigcap_{i=1}^{\log_2(n)} H_{n+i} \text{ occurs infin
