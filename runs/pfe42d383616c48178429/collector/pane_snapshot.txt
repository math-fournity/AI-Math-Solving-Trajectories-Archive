## Setting up the structure

**Street segments.** An $n \times n$ grid of blocks has $(n+1)\times(n+1)$ grid
intersections. The street segments are the unit-length grid edges:
- Horizontal: $(n+1)$ rows × $n$ segments each = $n(n+1)$
- Vertical: $(n+1)$ columns × $n$ segments each = $n(n+1)$
- **Total: $2n(n+1)$ street segments**

**Canopy geometry.** An isosceles right triangle with hypotenuse 2 has two legs
of length $\sqrt{2}$ each. All three vertices must be grid intersections.

**Hypotenuse placement.** The hypotenuse connects two grid points at distance 2.
 Integer solutions to $x^2+y^2=4$ are only $(\pm 2, 0)$ and $(0, \pm 2)$, so **t
he hypotenuse is always axis-aligned** (horizontal or vertical), spanning exactl
y 2 consecutive unit street segments.

**Leg placement.** If the hypotenuse runs from $(x,y)$ to $(x+2,y)$, the right-a
ngle vertex is at $(x+1, y\pm 1)$ — always a valid grid intersection. The legs a

ntal/vertical unit edges, **no street segment lies along a diagonal leg**. The l

**Conclusion:** Each canopy covers exactly **2 street segments** (via its hypote
nuse), and these 2 segments are consecutive and collinear (both horizontal on th

## Reducing to a tiling problem

The problem reduces to: **partition all street segments into pairs of consecutiv
e collinear unit segments**, where each pair becomes a canopy hypotenuse (with t
he right-angle vertex automatically landing on a grid intersection).

- Horizontal segments on each row form a path of $n$ edges; we must tile this $1
 \times n$ path with dominoes (pairs of adjacent edges).
- Vertical segments on each column form a path of $n$ edges; same requirement.

A path of $n$ edges can be tiled by dominoes (pairs of adjacent edges) **if and
only if $n$ is even**.

## Verifying necessity and sufficiency

**Necessity ($n$ even):** If $n$ is odd, each row has an odd number of horizonta
l segments that cannot be fully paired — at least one segment per row is left un
covered. So no perfect covering exists.

**Sufficiency ($n$ even):** If $n$ is even, pair segments $(1,2), (3,4), \ldots,
 (n-1, n)$ on every row and every column. Each pair forms a valid hypotenuse; th
e right-angle vertex is always a grid intersection. No segment is left uncovered
 or doubled. The diagonal legs of different canopies never coincide with street
segments, so no double-covering occurs. ✓
