## Setting Up the Framework

**Notation:** Dwarves have weights 1, 2, ..., n. Boat capacity is n. The boat st
arts on the left. Each R→L trip has exactly one oarsman, and each dwarf rows R→L

R trips.

**Trip counts per dwarf:** If dwarf i is an oarsman, they go L→R, then R→L, then
 L→R again — exactly **2** L→R trips. If not an oarsman, exactly **1** L→R trip.
 So:
$$\sum t_i = n + m, \qquad \sum i \cdot t_i = \frac{n(n+1)}{2} + \sum_{i \in O}
i \leq (m+1)n$$

where O is the set of oarsmen, |O| = m.

**Bounding m:** Since $\sum_{i\in O} i \geq \frac{m(m+1)}{2}$, we need:
$$\frac{m(m+1)}{2} \leq \frac{n(2m+1-n)}{2}$$
$$m^2 - (2n-1)m + (n^2-n) \leq 0$$

The discriminant is $(2n-1)^2 - 4(n^2-n) = 1$, giving roots $m = n$ and $m = n-1
$.

**Both cases force equality everywhere**, meaning every L→R trip carries **exact
ly weight n**, and:

- **Case m = n−1:** O = {1, ..., n−1}, non-oarsman = n. We must partition the mu
ltiset {1,1, 2,2, ..., (n−1),(n−1)} into n−1 groups (distinct elements, sum n ea
ch), plus one group {n}.
- **Case m = n:** O = {1, ..., n}. Dwarf n appears twice, forcing two groups {n}
, reducing to the **same sub-problem**.

So the **necessary and sufficient condition** reduces to: *Can we partition {1,1
, 2,2, ..., (n−1),(n−1)} into n−1 groups of distinct elements, each summing to n

## Even n is Impossible

- **Element n−1** needs remaining sum 1; only element 1 works. So both copies fo

- **Element n−2** needs remaining sum 2; only element 2 works (1 is exhausted).
Groups {2, n−2}, using both copies of 2.
- **Cascading:** {k, n−k} × 2 for k = 1, 2, ..., q−1.
- **Remaining:** {q, q} — two copies of q = n/2. No valid group sums to n: {q, q

**Contradiction.** No valid partition exists for any even n.
