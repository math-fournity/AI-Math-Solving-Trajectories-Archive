## Solution

**Setting up the parabolas.** Let the hub be $H = (20, 22)$.

**Zone 1** (equidistant from $H$ and line $y = 0$): For point $(x, y)$,
$$\sqrt{(x-20)^2 + (y-22)^2} = |y|$$
Squaring and simplifying: $(x-20)^2 + (y-22)^2 = y^2$, which gives
$$(x-20)^2 = 44y - 484 \quad\Longrightarrow\quad y = \frac{(x-20)^2 + 484}{44}.$
$

**Zone 2** (equidistant from $H$ and line $x = 0$): For point $(x, y)$,
$$\sqrt{(x-20)^2 + (y-22)^2} = |x|$$
Squaring: $(x-20)^2 + (y-22)^2 = x^2$, which gives
$$(y-22)^2 = 40x - 400 \quad\Longrightarrow\quad x = \frac{(y-22)^2 + 400}{40}.$
$

**Substitution.** Let $u = x - 20$, $v = y - 22$. Then:
$$u^2 = 44(v + 11) \quad \text{(Zone 1)} \tag{1}$$
$$v^2 = 40(u + 10) \quad \text{(Zone 2)} \tag{2}$$

**Key observation: both intersections lie on $x = y$.** If $x = y$, then $u = x
- 20$ and $v = y - 22 = x - 22 = u - 2$, so $v = u - 2$. Substituting into (1):
$$u^2 = 44(u - 2 + 11) = 44(u + 9)$$
$$u^2 - 44u - 396 = 0 \quad\Longrightarrow\quad u = \frac{44 \pm \sqrt{1936 + 15
84}}{2} = \frac{44 \pm \sqrt{3520}}{2} = 22 \pm 4\sqrt{55}.$$

**Verification with (2):** With $v = u - 2 = 20 \pm 4\sqrt{55}$:
$$v^2 = (20 \pm 4\sqrt{55})^2 = 400 \pm 160\sqrt{55} + 880 = 1280 \pm 160\sqrt{5
5}.$$
$$40(u + 10) = 40(32 \pm 4\sqrt{55}) = 1280 \pm 160\sqrt{55}. \quad\checkmark$$

**Confirming these are the only real intersections.** Substituting $v = \frac{u^
2}{44} - 11$ from (1) into (2) yields the quartic:
$$u^4 - 968u^2 - 77440u - 540144 = 0.$$

Since $u = 22 \pm 4\sqrt{55}$ are roots, $(u^2 - 44u - 396)$ is a factor. Polyno
mial division gives:
$$(u^2 - 44u - 396)(u^2 + 44u + 1364) = 0.$$

The second factor has discriminant $44^2 - 4(1364) = 1936 - 5456 = -3520 < 0$, s
o it has **no real roots**. Thus the only two real intersection points are:
$$\text{Tower X} = (42 + 4\sqrt{55},\; 42 + 4\sqrt{55}), \qquad \text{Tower Y} =
 (42 - 4\sqrt{55},\; 42 - 4\sqrt{55}).$$

**Computing the squared distance:**
$$\Delta x = \Delta y = (42 + 4\sqrt{55}) - (42 - 4\sqrt{55}) = 8\sqrt{55}.$$
$$d^2 = (\Delta x)^2 + (\Delta y)^2 = (8\sqrt{55})^2 + (8\sqrt{55})^2 = 2 \times
 64 \times 55 = 2 \times 3520 = \boxed{7040}.$$
