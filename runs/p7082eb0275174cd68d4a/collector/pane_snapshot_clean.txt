## Solution

**Goal.** Find the global maximum of $f(x) = J_2(x)/x^2$ (defined at $x=0$ by it
s limit).

**Step 1. A useful integral representation.**

We use Poisson's integral representation for Bessel functions, valid for $\nu >
-\tfrac12$:

$$J_\nu(x) = \frac{(x/2)^{\nu}}{\sqrt{\pi}\,\Gamma(\nu+\tfrac12)}\int_{-1}^{1}(1
-t^2)^{\nu-1/2}\cos(xt)\,dt.$$

Setting $\nu = 2$, with $\Gamma(\tfrac52)=\tfrac{3\sqrt\pi}{4}$, the prefactor b
ecomes

$$\frac{(x/2)^2}{\sqrt\pi\cdot\frac{3\sqrt\pi}{4}}=\frac{x^2/4}{3\pi/4}=\frac{x^
2}{3\pi},$$

so

$$J_2(x)=\frac{x^2}{3\pi}\int_{-1}^{1}(1-t^2)^{3/2}\cos(xt)\,dt.$$

Dividing by $x^2$ (and taking the continuous extension at $x=0$):

$$\boxed{\;f(x)=\frac{J_2(x)}{x^2}=\frac{1}{3\pi}\int_{-1}^{1}(1-t^2)^{3/2}\cos(
xt)\,dt.\;}$$

**Step 2. The value at $x=0$.**

$$f(0)=\frac{1}{3\pi}\int_{-1}^{1}(1-t^2)^{3/2}\,dt.$$

Substituting $t=\sin\theta$, $dt=\cos\theta\,d\theta$, $(1-t^2)^{3/2}=\cos^3\the
ta$:

$$\int_{-1}^{1}(1-t^2)^{3/2}\,dt=\int_{-\pi/2}^{\pi/2}\cos^4\theta\,d\theta=2\in
t_0^{\pi/2}\cos^4\theta\,d\theta=2\cdot\frac{3\pi}{16}=\frac{3\pi}{8},$$

using Wallis' formula. Hence

$$f(0)=\frac{1}{3\pi}\cdot\frac{3\pi}{8}=\frac18.$$

(This agrees with the series $J_2(x)/x^2=\tfrac18-\tfrac{x^2}{96}+\cdots$.)

**Step 3. Upper bound for all $x$.**

For every real $x$ and every $t\in[-1,1]$, we have $\cos(xt)\le 1$. The weight $
(1-t^2)^{3/2}$ is nonnegative on $[-1,1]$ and strictly positive on $(-1,1)$. The
refore

$$\int_{-1}^{1}(1-t^2)^{3/2}\cos(xt)\,dt\;\le\;\int_{-1}^{1}(1-t^2)^{3/2}\,dt=\f
rac{3\pi}{8},$$

so

$$f(x)=\frac{J_2(x)}{x^2}\le\frac{1}{3\pi}\cdot\frac{3\pi}{8}=\frac18\qquad\text
{for all }x\in\mathbb{R}.$$

**Step 4. Equality holds only at $x=0$.**

Equality in the bound requires $\cos(xt)=1$ for (Lebesgue-)almost every $t\in(-1
,1)$ with respect to the strictly positive weight $(1-t^2)^{3/2}\,dt$. Since $\c
os(xt)=1$ on an interval of $t$ forces $x=0$ (otherwise $\cos(xt)$ is a nonconst
ant analytic function of $t$, taking the value $1$ only at isolated points), equ
ality holds **if and only if** $x=0$.

**Conclusion.**

The function $f(x)=J_2(x)/x^2$ satisfies $f(x)\le \tfrac18$ for all real $x$, wi
th equality attained (in the limiting sense) at $x=0$. Hence the global maximum
value is

$$\boxed{\dfrac18}.$$
