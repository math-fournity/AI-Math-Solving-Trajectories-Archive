## Proof

**Claim:** Yes, there exists a point $x \in \{0,1\}^{\mathbb{Z}}$ that is generi
c for some $\sigma$-invariant measure but not for others.

**Key fact.** A point $x$ is *generic* for a $\sigma$-invariant measure $\mu$ if
 the empirical measures
$$\mu_N^x := \frac{1}{N}\sum_{n=0}^{N-1}\delta_{\sigma^n x}$$
converge to $\mu$ in the weak-* topology. Since weak-* limits are unique (when t
hey exist), **a point is generic for at most one invariant measure**. Therefore,
 once we exhibit a generic point for some invariant measure $\mu$ and a *differe
nt* invariant measure $\nu$, the point is automatically not generic for $\nu$.

**Construction.** Let $x = 0^{\infty} = (\ldots, 0, 0, 0, \ldots) \in \{0,1\}^{\
mathbb{Z}}$ be the all-zeros sequence. Since $\sigma(x) = x$, every empirical me
asure is
$$\mu_N^x = \frac{1}{N}\sum_{n=0}^{N-1}\delta_{\sigma^n x} = \delta_{0^\infty} \
quad \text{for all } N \geq 1.$$
Hence $\mu_N^x \to \delta_{0^\infty}$, and $x$ is generic for the Dirac measure
$\delta_{0^\infty}$, which is $\sigma$-invariant (it is a fixed point of $\sigma
$).

**Not generic for a different measure.** Consider the Bernoulli measure $\nu = \
bigl(\tfrac{1}{2},\tfrac{1}{2}\bigr)^{\mathbb{Z}}$, the product measure assignin
g each coordinate independently the value $0$ or $1$ with probability $1/2$. Thi
s is $\sigma$-invariant. The cylinder set $C_1 = \{y : y_0 = 1\}$ satisfies $\nu
(C_1) = 1/2$. But for our point $x = 0^\infty$,
$$\mu_N^x(C_1) = \frac{1}{N}\sum_{n=0}^{N-1}\mathbf{1}\{(\sigma^n x)_0 = 1\} = \
frac{1}{N}\sum_{n=0}^{N-1}\mathbf{1}\{x_n = 1\} = 0 \quad \text{for all } N.$$
Since $\mu_N^x(C_1) = 0 \not\to 1/2 = \nu(C_1)$, the point $x$ is **not** generi
c for $\nu$.

**Conclusion.** The point $x = 0^\infty$ is generic for the $\sigma$-invariant m
easure $\delta_{0^\infty}$ but not for the distinct $\sigma$-invariant measure $
\nu = (\frac{1}{2},\frac{1}{2})^{\mathbb{Z}}$. Hence such a point exists.

*Remark.* More generally, by Birkhoff's ergodic theorem, for any ergodic $\sigma
$-invariant measure $\mu$, $\mu$-almost every point is generic for $\mu$. Since
there are uncountably many distinct ergodic $\sigma$-invariant measures on $\{0,
1\}^{\mathbb{Z}}$ (e.g., the Bernoulli measures $(p,1-p)^{\mathbb{Z}}$ for $p \i
n (0,1)$, plus the Dirac measures on periodic orbits), generic points for each e
xist abundantly, and each is generic for exactly one measure—hence not generic f
or all the others.
