## Proof

**Yes**, the double arrow space $A = [0,1]\times\{1,2\}$ with the dictionary (le
xicographic) order has the greatest lower bound property.

**Setup.** The order on $A$ is: $(x,i) < (y,j)$ iff $x < y$, or $x = y$ and $i <
 j$ (with $1 < 2$). Let $\pi:A\to[0,1]$ be the projection $\pi(x,i)=x$. We show
every nonempty subset $S\subseteq A$ that is bounded below has a greatest lower
bound in $A$.

**Construction.** Let $T = \pi(S)\subseteq[0,1]$. Then $T$ is nonempty and bound
ed below (since $S$ is), so by the GLB property of $[0,1]$, $\alpha = \inf T$ ex
ists in $[0,1]$. We consider two cases.

**Case 1: $\alpha \in T$.** Then there is some $i\in\{1,2\}$ with $(\alpha,i)\in
 S$. Let $i_0 = \min\{i : (\alpha,i)\in S\}$, so $m := (\alpha, i_0)\in S$. Ever
y element of $S$ either has first coordinate $>\alpha$ (hence is $> m$) or first
 coordinate $=\alpha$ (hence is $\geq m$ by minimality of $i_0$). Thus $m = \min
 S$, so $m = \inf S$.

**Case 2: $\alpha \notin T$.** We claim $\inf S = (\alpha, 2)$.

*Lower bound:* For any $(x,i)\in S$, we have $x\in T$ so $x \geq \alpha$. If $x
> \alpha$, then $(x,i) > (\alpha,2)$. If $x = \alpha$, then $\alpha\in T$, contr
adicting the case hypothesis. Hence every element of $S$ is $> (\alpha,2)$, so $
(\alpha,2)$ is a lower bound of $S$.

*Greatest lower bound:* Suppose $b = (\beta, j)$ is a lower bound of $S$ with $b
 > (\alpha,2)$. Since there is no index above $2$, this forces $\beta > \alpha$.
 But $\alpha = \inf T$, so there exists $x\in T$ with $\alpha \leq x < \beta$; p
ick $(x,i)\in S$. Then $(x,i) < (\beta,j) = b$, contradicting that $b$ is a lowe
r bound of $S$. Hence no lower bound of $S$ exceeds $(\alpha,2)$, so $(\alpha,2)
 = \inf S$.

In both cases $\inf S$ exists in $A$, so $A$ has the greatest lower bound proper
ty. $\blacksquare$

**Remark.** Note this is consistent with the fact that the double arrow space is
 *not* a linear continuum: it has the GLB (equivalently LUB) property but fails
the betweenness property, since there is no point strictly between $(x,1)$ and $
(x,2)$ for any $x\in[0,1]$.
