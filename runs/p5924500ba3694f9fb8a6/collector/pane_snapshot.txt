Kolmogorov Extension Theorem Without Topological Assumptions

Answer: False

Proof

The Kolmogorov Extension Theorem (also called the Kolmogorov Consistency
Theorem) states:

│ Given a family of standard Borel spaces ${S_t}{t \in T}$ and a consistent
│ family of finite-dimensional probability measures ${\mu_F}{F \subset T
│ \text{ finite}}$, there exists a unique probability measure $\mu$ on the
│ product space $\left(\prod_{t \in T} S_t,, \bigotimes_{t \in T} \mathcal{B}
│ (S_t)\right)$ whose finite-dimensional marginals recover the $\mu_F$.

The theorem does not hold for arbitrary measurable spaces. The hypothesis that
each $S_t$ is a standard Borel space (equivalently, a measurable space Borel-
isomorphic to a Borel subset of a Polish space) is essential. This is
fundamentally a topological requirement: one needs a topology under which $S_t$
is Polish (or a Borel subset thereof).

Why Topology Is Essential

The standard proof proceeds as follows (for $S_t = \mathbb{R}$, the classical
case):

  1. Inner regularity: On $\mathbb{R}^n$, every probability measure is inner
  regular with respect to compact sets. This is a topological fact relying on
  local compactness / Polish structure.
  2. Compact class argument: One exhibits a compact class $\mathcal{K}$ of
  subsets of $S = \prod_t S_t$ (built from compact sets in finite-dimensional
  projections) such that:
    • $\mathcal{K}$ is stable under finite intersections,
    • For every measurable cylinder $C$ and every $\varepsilon > 0$, there
    exists $K \in \mathcal{K}$ with $K \subset C$ and $\mu_F(C) - \mu_F(K) <
    \varepsilon$.
  3. Extension via the Carathéodory / Daniell–Kolmogorov method: The compact
  class ensures that the pre-measure defined on the cylinder algebra is
  countably additive (not merely finitely additive), which is the crucial step.
  Specifically, the compact class property guarantees that if a decreasing
  sequence of cylinder sets has empty intersection, then their measures tend to
  zero — this is exactly where compactness (a topological notion) is used.

Without a topology furnishing compact sets and inner regularity, step 2 fails:
there is no compact class, and one cannot rule out the pathology where a
finitely additive set function on the cylinder algebra is not countably
additive.

Concrete Counterexample

Let $S$ be an uncountable set equipped with the countable–cocountable $\sigma$-
algebra: $$\mathcal{A} = {A \subset S : A \text{ is countable or } A^c \text{ is
countable}}.$$ This is a measurable space with no standard Borel structure (it
is not countably generated).

Let $T = \mathbb{N}$. For each finite $F = {t_1, \dots, t_n} \subset
\mathbb{N}$, define $\mu_F$ on $(S^n, \mathcal{A}^{\otimes n})$ by: $$\mu_F(A) =
\begin{cases} 1 & \text{if } {(s, s, \dots, s) : s \in S} \subset A, \ 0 &
\text{if } {(s, s, \dots, s) : s \in S} \cap A = \emptyset, \end{cases}$$ i.e.,
$\mu_F$ is the "diagonal" measure concentrating all mass on the set $D_F = {(s,
\dots,s) : s \in S}$, distributing it via the cocountable measure on $S$
(assigning 1 to cocountable sets, 0 to countable sets).

Consistency: For $F \subset F'$, the projection of $\mu_{F'}$ onto $S^F$ is $
\mu_F$, since projecting the diagonal in $S^{F'}$ onto $S^F$ gives the diagonal
in $S^F$. The family ${\mu_F}$ is consistent.

No extension exists: Suppose a probability measure $\mu$ on $(S^{\mathbb{N}},
\mathcal{A}^{\otimes \mathbb{N}})$ existed with these marginals. Then $\mu$
would concentrate on the grand diagonal $\Delta = {(s, s, s, \dots) : s \in S}$.
However, $\Delta$ is not measurable in the product $\sigma$-algebra $\mathcal{A}
^{\otimes \mathbb{N}}$ (the product $\sigma$-algebra of a non-countably-
generated $\sigma$-algebra does not contain the diagonal). More precisely, one
can show that any set in $\mathcal{A}^{\otimes \mathbb{N}}$ that contains $
\Delta$ must also contain points off the diagonal, forcing $\mu$ to assign
positive mass to sets that should have measure zero under the marginal
constraints — a contradiction. The measure cannot be consistently defined.

insufficient to guarantee an extension when the state space lacks the requisite
topological (standard Borel) structure.

probability measure on the product space. Therefore, the statement that the
