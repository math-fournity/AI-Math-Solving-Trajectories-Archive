## Solution

We evaluate $I = \int_{-\infty}^{\infty} \frac{\sin x}{x+i}\,dx$ using the hint
$\sin x = \frac{e^{ix}-e^{-ix}}{2i}$.

**Decomposition.** Splitting the integral:

$$I = \frac{1}{2i}\left[\underbrace{\int_{-\infty}^{\infty}\frac{e^{ix}}{x+i}\,d
x}_{I_1}\;-\;\underbrace{\int_{-\infty}^{\infty}\frac{e^{-ix}}{x+i}\,dx}_{I_2}\r
ight]$$

The integrand has a single simple pole at $z = -i$ (in the **lower** half-plane)
.

**Evaluating $I_1$ via contour integration.** For $e^{iz}$, write $z = x+iy$, so
 $|e^{iz}| = e^{-y}$, which decays when $y > 0$. We close the contour in the **u
pper** half-plane. The pole at $z=-i$ lies outside this region, so by Cauchy's t
heorem (the arc contribution vanishes by Jordan's lemma):

$$I_1 = 0.$$

**Evaluating $I_2$ via contour integration.** For $e^{-iz}$, we have $|e^{-iz}|
= e^{y}$, which decays when $y < 0$. We close the contour in the **lower** half-
plane. The pole at $z = -i$ is now enclosed. Traversing the lower half-plane giv
es a **clockwise** (negatively oriented) contour, introducing a factor of $-2\pi
 i$.

The residue at $z = -i$:

$$\operatorname{Res}_{z=-i}\frac{e^{-iz}}{z+i} = \lim_{z\to -i}(z+i)\frac{e^{-iz
}}{z+i} = e^{-i(-i)} = e^{-1} = \frac{1}{e}.$$

Therefore:

$$I_2 = -2\pi i \cdot \frac{1}{e} = -\frac{2\pi i}{e}.$$

**Combining.**

$$I = \frac{1}{2i}\Big[I_1 - I_2\Big] = \frac{1}{2i}\left[0 - \left(-\frac{2\pi
i}{e}\right)\right] = \frac{1}{2i}\cdot\frac{2\pi i}{e} = \frac{\pi}{e}.$$

**Verification (sanity check).** The result $\pi/e$ is real and positive. This i
s consistent: writing $\frac{\sin x}{x+i} = \frac{\sin x\,(x-i)}{x^2+1} = \frac{
x\sin x}{x^2+1} - i\frac{\sin x}{x^2+1}$. The imaginary part $\int_{-\infty}^{\i
nfty}\frac{\sin x}{x^2+1}\,dx = 0$ (odd integrand), confirming the result is pur
ely real. The real part $\int_{-\infty}^{\infty}\frac{x\sin x}{x^2+1}\,dx$ is a
standard integral equal to $\pi/e$ (computable by the same residue method, pole
at $z=i$ in the upper half-plane with residue $\frac{e^{-1}}{2}$, giving $\pi e^
{-1}$). ✓

$$\boxed{\int_{-\infty}^{\infty}\frac{\sin x}{x+i}\,dx = \frac{\pi}{e}}$$
