## Proof

We prove that the lower bound of the computational complexity for generating the
 first $n$ Bell numbers $B_0, B_1, \ldots, B_n$ is

$$\boxed{\Omega(n^2 \log n)}$$

in the bit-complexity (Turing machine / bit-operation) model, and we show this i
s information-theoretically tight (it equals the output size). In the unit-cost
arithmetic model, the corresponding lower bound is $\Omega(n)$ with a matching $
O(n \log n)$ upper bound via fast power-series exponentiation.

---

### Step 1 — Asymptotic size of $B_k$

The Bell number $B_k$ counts the number of set partitions of a $k$-element set.
The classical asymptotic expansion (de Bruijn, 1970) gives:

$$\ln B_k = k \ln k - k \ln\ln k - k + \frac{k\,\ln\ln k}{\ln k} + O\!\left(\fra
c{k}{\ln k}\right).$$

In particular,

$$\ln B_k = \Theta(k \ln k),$$

so the number of bits required to represent $B_k$ in binary is

$$\operatorname{bits}(B_k) = \lfloor \log_2 B_k \rfloor + 1 = \Theta(k \log k).$
$

### Step 2 — Total output size

The total number of bits in the output $\{B_0, B_1, \dots, B_n\}$ is

$$S(n) = \sum_{k=1}^{n} \Theta(k \log k).$$

By integral comparison (the function $x \log x$ is increasing for $x \geq 1$):

$$\sum_{k=1}^{n} k \log k \;\geq\; \int_1^n x \log x \, dx = \frac{n^2 \log n}{2
} - \frac{n^2}{4\ln 2} + O(1) = \Theta(n^2 \log n).$$

Therefore

$$S(n) = \Theta(n^2 \log n).$$

### Step 3 — Lower bound from output size

Any algorithm that **generates** (computes and writes out) the first $n$ Bell nu
mbers must produce at least $S(n) = \Theta(n^2 \log n)$ bits of output. Since ea
ch bit of output requires at least one bit-level operation (a write to memory or
 tape), the running time $T(n)$ satisfies

$$T(n) \;\geq\; S(n) \;=\; \Omega(n^2 \log n).$$

This is an **information-theoretic lower bound**: it holds for every possible al
gorithm, regardless of the method used, because the output itself has $\Theta(n^
2 \log n)$ bits.

### Step 4 — The lower bound is tight (matching upper bound)

We show the lower bound is achievable up to logarithmic factors, confirming it i
s the correct order.

**Arithmetic model (upper bound $O(n^2)$, tight at $\Theta(n^2)$ for naive arith
metic):**
The Bell triangle (Aitken's array) computes all of $B_0, \ldots, B_n$ using $\su
m_{k=1}^{n} k = \Theta(n^2)$ additions:

- Row $0$: $a_{0,0} = 1 = B_0$.
- Row $k$ ($k \geq 1$): $a_{k,0} = a_{k-1,k-1}$, and $a_{k,j} = a_{k,j-1} + a_{k
-1,j-1}$ for $j = 1, \ldots, k$.
- Then $B_k = a_{k,0}$.

This uses $\Theta(n^2)$ arithmetic operations.

**Bit-complexity of the Bell triangle:** Each addition in row $k$ operates on in
tegers of size $O(k \log k)$ bits, so each costs $O(k \log k)$ bit operations. T
he total is

$$\sum_{k=1}^{n} k \cdot O(k \log k) = O(n^3 \log n).$$

**Faster method via generating functions:** The exponential generating function
of Bell numbers is

$$\sum_{k=0}^{\infty} B_k \frac{x^k}{k!} = e^{e^x - 1}.$$

Using fast power-series operations (Newton's method for series exponentiation),
$\exp(g(x))$ for a degree-$n$ series $g$ can be computed in $O(n \log n)$ arithm
etic operations and $O(n \log n \cdot M(n \log n))$ bit operations, where $M(m)$
 is the cost of $m$-bit multiplication. With FFT-based multiplication $M(m) = O(
m \log m)$, the bit complexity becomes $O(n^2 \log^2 n \cdot \log\log n)$, which
 is within a polylogarithmic factor of the $\Omega(n^2 \log n)$ lower bound.

### Step 5 — Conclusion

| Model | Lower bound | Upper bound |
|-------|------------|------------|
| Bit operations | $\Omega(n^2 \log n)$ | $O(n^2 \log^2 n \log\log n)$ (fast ser
ies exp) |
| Arithmetic operations | $\Omega(n)$ | $O(n \log n)$ (fast series exp) / $O(n^2
)$ (Bell triangle) |

The **rigorous, model-independent lower bound** is

$$\Omega(n^2 \log n)$$

bit operations, established by the information-theoretic argument that the outpu
t $\{B_0, \ldots, B_n\}$ contains $\Theta(n^2 \log n)$ bits (since $B_k$ has $\T
heta(k \log k)$ bits and $\sum_{k=1}^n k \log k = \Theta(n^2 \log n)$). This low
er bound is tight up to polylogarithmic factors, as fast power-series exponentia
tion of $e^{e^x - 1}$ achieves near-matching complexity.
