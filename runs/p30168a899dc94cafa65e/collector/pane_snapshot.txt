## Proof

**Problem restatement.** Find all odd integers $n$ with $1 < n < 250$ such that
for every prime $p \mid n$, we have $(p-2) \mid n$.

**Key observation.** Since $n$ is odd, all prime factors of $n$ are odd. For any
 odd prime $p$, $\gcd(p-2, p) = \gcd(p-2, 2) = 1$ (because $p-2$ is odd). This m
eans if $n = p^a$ (a prime power), then $(p-2) \mid p^a$ forces $p-2 = 1$, i.e.,
 $p = 3$.

**Closure structure.** Let $S$ be the set of prime factors of $n$. For each $p \
in S$, every prime factor of $(p-2)$ must also lie in $S$ (since $(p-2) \mid n$)
. This creates a dependency chain that must terminate at $p=3$ (since $3-2=1$ ha
s no prime factors).

**Bounding the largest prime factor.** I trace the minimal closure for each prim
e $p$:

| Largest prime $p$ | Closure of $\{p\}$ | Min $n$ (with required powers) | $< 2
50$? |
|---|---|---|---|
| 3 | $\{3\}$ | 3 | ✓ |
| 5 | $\{3,5\}$ (since $5-2=3$) | 15 | ✓ |
| 7 | $\{3,5,7\}$ (since $7-2=5\to 3$) | 105 | ✓ |
| 11 | $\{3,11\}$, need $3^2\mid n$ (since $11-2=9$) | 99 | ✓ |
| 13 | $\{3,11,13\}$, need $3^2\mid n$ | $9\cdot11\cdot13=1287$ | ✗ |
| 17 | $\{3,5,17\}$ (since $17-2=15=3\cdot5$) | $3\cdot5\cdot17=255$ | ✗ |
| $\geq 19$ | closure grows rapidly | $>250$ | ✗ |

So the only primes that can appear as factors of $n < 250$ are $\{3, 5, 7, 11\}$
.

**Enumerating all valid sets $S \subseteq \{3,5,7,11\}$:**

**$S = \{3\}$:** Condition: $(3-2)=1 \mid n$, always true. So $n = 3^a$, $a \geq
 1$, $n < 250$:
$$3,\; 9,\; 27,\; 81,\; 243 \quad (3^5=243<250,\; 3^6=729>250)$$
**5 values.**

**$S = \{3, 5\}$:** Conditions: $1\mid n$ ✓, $(5-2)=3\mid n$ ✓ (automatic since
$3\mid n$). So $n = 3^a \cdot 5^b$, $a,b \geq 1$, $n < 250$:
$$15,\; 45,\; 75,\; 135,\; 225$$
(Checking: $3\cdot5=15$, $9\cdot5=45$, $3\cdot25=75$, $27\cdot5=135$, $9\cdot25=
225$; next values $81\cdot5=405$, $3\cdot125=375$ exceed 250.)
**5 values.**

**$S = \{3, 5, 7\}$:** Conditions: $1\mid n$ ✓, $3\mid n$ ✓, $(7-2)=5\mid n$ ✓.
So $n = 3^a\cdot5^b\cdot7^c$, $a,b,c\geq 1$, $n<250$:
$$105 \quad (3\cdot5\cdot7=105;\; 9\cdot5\cdot7=315>250)$$
**1 value.**

**$S = \{3, 11\}$:** Conditions: $1\mid n$ ✓, $(11-2)=9\mid n$, so $3^2\mid n$ (
i.e., $a\geq 2$). So $n = 3^a\cdot 11^b$, $a\geq 2$, $b\geq 1$, $n<250$:
$$99 \quad (9\cdot11=99;\; 27\cdot11=297>250)$$
**1 value.**

**$S = \{3, 5, 11\}$:** Need $3^2\mid n$ (from $11-2=9$). Minimum: $9\cdot5\cdot
11 = 495 > 250$. **0 values.**

**$S = \{3, 7, 11\}$:** $(7-2)=5\mid n$ forces $5\in S$, so this reduces to $\{3
,5,7,11\}$, minimum $1155>250$. **0 values.**

**$S = \{3, 5, 7, 11\}$:** Minimum $3\cdot5\cdot7\cdot11 = 1155 > 250$. **0 valu
es.**

**Verification of all 12 values:**

| $n$ | Factorization | Prime factors | Check $(p-2)\mid n$ |
|---|---|---|---|
| 3 | $3$ | $\{3\}$ | $1\mid 3$ ✓ |
| 9 | $3^2$ | $\{3\}$ | $1\mid 9$ ✓ |
| 15 | $3\cdot5$ | $\{3,5\}$ | $1\mid15$, $3\mid15$ ✓ |
| 27 | $3^3$ | $\{3\}$ | $1\mid27$ ✓ |
| 45 | $3^2\cdot5$ | $\{3,5\}$ | $1\mid45$, $3\mid45$ ✓ |
| 75 | $3\cdot5^2$ | $\{3,5\}$ | $1\mid75$, $3\mid75$ ✓ |
| 81 | $3^4$ | $\{3\}$ | $1\mid81$ ✓ |
| 99 | $3^2\cdot11$ | $\{3,11\}$ | $1\mid99$, $9\mid99$ ✓ |
| 105 | $3\cdot5\cdot7$ | $\{3,5,7\}$ | $1\mid105$, $3\mid105$, $5\mid105$ ✓ |
| 135 | $3^3\cdot5$ | $\{3,5\}$ | $1\mid135$, $3\mid135$ ✓ |
| 225 | $3^2\cdot5^2$ | $\{3,5\}$ | $1\mid225$, $3\mid225$ ✓ |
| 243 | $3^5$ | $\{3\}$ | $1\mid243$ ✓ |

All 12 values are odd, greater than 1, strictly less than 250, and satisfy the P
erfectly Balanced condition.

**Answer:** $\boxed{12}$
