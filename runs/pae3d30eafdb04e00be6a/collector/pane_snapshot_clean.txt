证明：设 $X$ 是 G.T. 空间，$Y$ 是 $X$ 的补子空间，$P: X \to Y$ 为有界投影，$i: Y
\hookrightarrow X$ 为包含映射，$P \circ i = \mathrm{id}Y$。设 $(y_n^)$ 在 $Y^$
中弱$^$收敛于 $y^$（即 $\sigma(Y^,Y)$-收敛）。因 $P^$ 是弱$^$-到-弱$^$连续
的，$P^* y_n^* \to P^* y^$ 在 $\sigma(X^,X)$ 中收敛。由 $X$ 是 G.T. 空间，$P^*
y_n^* \to P^* y^$ 在 $\sigma(X^,X^)$ 中收敛（弱收敛）。而 $i^: X^* \to Y^$ 是弱-
到-弱连续的，故 $i^(P^* y_n^) \to i^(P^* y^)$ 在 $\sigma(Y^,Y^{**})$ 中收敛。由
$i^* \circ P^* = (P \circ i)^* = \mathrm{id}{Y^}$，得 $y_n^ \to y^*$ 弱收敛。$
\square$

────────────────────────────────────────────────────────────────────────────────

第一步：$\ell_\infty$ 是 Grothendieck 空间

由 Grothendieck 定理（1953），当 $K$ 是 Stonian 空间（即极不连通紧 Hausdorff 空
间）时，$C(K)$ 是 Grothendieck 空间。

  • $\ell_\infty \cong C(\beta\mathbb{N})$，其中 $\beta\mathbb{N}$ 是 $
  \mathbb{N}$ 的 Stone-Čech 紧化。
  • $\beta\mathbb{N}$ 是极不连通的（经典结论：离散空间的 Stone-Čech 紧化是极不连
  通的）。

因此 $\ell_\infty$ 是 Grothendieck 空间。$\checkmark$

────────────────────────────────────────────────────────────────────────────────

第二步：$\ell_1$ 不是 Grothendieck 空间

需证明 $\ell_1^* = \ell_\infty$ 中存在弱$^*$收敛但不弱收敛的序列。

构造：令 $x_n = \sum_{k=1}^{n} e_k \in \ell_\infty$，即 $x_n = (\underbrace{1,
\ldots,1}_{n}, 0, 0, \ldots)$，并令 $\mathbf{1} = (1,1,1,\ldots)$。

弱$^*$收敛：对任意 $a = (a_k) \in \ell_1$， $$\langle x_n, a \rangle =
\sum_{k=1}^{n} a_k \longrightarrow \sum_{k=1}^{\infty} a_k = \langle \mathbf{1},
a \rangle.$$ 故 $x_n \to \mathbf{1}$ 在 $\sigma(\ell_\infty, \ell_1)$ 中收敛。

不弱收敛：取 Banach 极限 $L \in \ell_\infty^*$（由 Hahn-Banach 定理保证其存
在）。Banach 极限满足：

  • $L(\mathbf{1}) = 1$；
  • 若序列 $(u_k)$ 通常收敛，则 $L((u_k)) = \lim_{k\to\infty} u_k$。

对每个固定的 $n$，$x_n$ 作为 $k$ 的序列 $(1,\ldots,1,0,0,\ldots)$ 通常收敛于
$0$，故 $L(x_n) = 0$。而 $L(\mathbf{1}) = 1$。因此 $$L(x_n) = 0 \not\to 1 =
L(\mathbf{1}),$$ 即 $x_n \not\to \mathbf{1}$ 弱收敛。

因此 $\ell_1$ 不是 Grothendieck 空间。$\checkmark$

────────────────────────────────────────────────────────────────────────────────

第三步：$\ell_1$ 在 $\ell_\infty^*$ 中是 1-补的

$\ell_\infty^* = ba(\mathbb{N})$（$\mathbb{N}$ 上有界有限可加测度的空间）。由
Yosida–Hewitt 分解定理（1952），每个 $\mu \in ba(\mathbb{N})$ 唯一分解为 $$\mu =
\mu_c + \mu_p,$$ 其中 $\mu_c$ 是可数可加测度，$\mu_p$ 是纯有限可加测度，且全变差
范数满足 $|\mu| = |\mu_c| + |\mu_p|$。

在 $\mathbb{N}$ 上，可数可加测度通过 $\mu_c \leftrightarrow (a_n)$，$a_n =
\mu_c({n})$，与 $\ell_1$ 等距同构。映射 $P: ba(\mathbb{N}) \to \ell_1$，$P(\mu)
= \mu_c$，是范数为 1 的投影（因 $|\mu| = |\mu_c| + |\mu_p|$，投影的范数为 1）。
因此 $$\ell_\infty^* = \ell_1 \oplus_1 ba_s(\mathbb{N}),$$ $\ell_1$ 是 $
\ell_\infty^*$ 的 1-补子空间。$\checkmark$

────────────────────────────────────────────────────────────────────────────────

第四步：$\ell_\infty^*$ 不是 Grothendieck 空间

假设 $\ell_\infty^*$ 是 G.T. 空间。由关键引理，其 1-补子空间 $\ell_1$ 也是 G.T.
空间。但第二步已证 $\ell_1$ 不是 G.T. 空间，矛盾。

因此 $\ell_\infty^*$ 不是 Grothendieck 空间。$\checkmark$

────────────────────────────────────────────────────────────────────────────────

结论

$X = \ell_\infty$ 是一个 Grothendieck 空间（第一步），但其对偶 $X^* =
\ell_\infty^*$ 不是 Grothendieck 空间（第四步）。

因此，存在一个满足 Grothendieck 定理的 Banach 空间，其对偶不是 G.T. 空间。 $
\blacksquare$
