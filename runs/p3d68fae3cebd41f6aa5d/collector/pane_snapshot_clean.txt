## Theoretical Analysis

**Algebraic approach:** If n+1 = a³ (a perfect cube, hence 3-full), then n = (a−
1)(a²+a+1). Since gcd(a−1, a²+a+1) | 3, these factors are nearly coprime. For n
to be 2-full, both factors must individually be 2-full (up to shared factors of
3). The factor a²+a+1 = (a³−1)/(a−1) tends to have large prime factors with expo
nent 1, making this extremely restrictive. Checking all powerful values of a−1 u
p to 256 yielded no 2-full a²+a+1.

**ABC conjecture heuristic:** If n is 2-full and n+1 is 3-full, then rad(n) ≤ n^
{1/2} and rad(n+1) ≤ (n+1)^{1/3}. By ABC: n+1 ≲ K_ε · (rad(n)·rad(n+1))^{1+ε} ≤
K_ε · n^{(5/6)(1+ε)}. For ε < 1/5, this bounds n, implying only finitely many su
ch pairs exist. The heuristic density of such pairs up to N is ~N^{1/2}·N^{1/3}/
N = N^{−1/6} → 0, suggesting very few (possibly zero) examples.
