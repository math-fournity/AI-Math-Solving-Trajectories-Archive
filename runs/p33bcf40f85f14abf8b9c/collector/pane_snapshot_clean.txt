## 解题思路

**建立坐标系。** 将 A 置于原点，AD 沿 z 轴方向，故 D = (0, 0, 2√3)。

由角度条件 ∠BAD = ∠CAD = 45°，∠BAC = 60°，可设：
- B = (b/√2, 0, b√2/2)，C = (0, c/√2, c√2/2)（b, c > 0）

验证：AB·AC = b²/2，|AB||AC| = bc，cos∠BAC = (b²/2)/(bc) · ... 逐项验证所有点积
满足 ∠BAC=60°, ∠BAD=∠CAD=45°。✓

**平面 ABC 的方程。** 法向量 AB×AC ∝ (-1,-1,1)，过原点，故平面 ABC: x + y − z =
0。

**外接球。** 设外接球中心 O = (x₀, y₀, z₀)，半径 R。

- A、D 在外接球上：z₀² = (z₀−2√3)² → **z₀ = √3**
- R² = x₀² + y₀² + 3
- B 在外接球上：b = √2(x₀ + √3)
- C 在外接球上：c = √2(y₀ + √3)

**小球 S 的条件。** S 半径为 1，与外接球内切于点 D（D 在外接球上），且与平面 ABC
 相切。

S 的中心位于 OD 连线上、距 D 为 1 处：
$$S_{\text{center}} = D + \frac{O - D}{R} = \left(\frac{x_0}{R},\; \frac{y_0}{R}
,\; \sqrt{3}\!\left(2 - \frac{1}{R}\right)\right)$$

S 与平面 ABC 相切，故 S_center 到平面距离 = 1：

$$\frac{\left|\frac{x_0+y_0}{R} - \sqrt{3}\!\left(2-\frac{1}{R}\right)\right|}{\
sqrt{3}} = 1$$

令 s = x₀ + y₀，得 |(s+√3)/R − 2√3| = √3，两种情形：

- **情形 1**：(s+√3)/R = 3√3 → s = √3(3R−1)
- **情形 2**：(s+√3)/R = √3 → s = √3(R−1)

**用 Cauchy–Schwarz 消元。** 由 s² = (x₀+y₀)² ≤ 2(x₀²+y₀²) = 2(R²−3)：

**情形 1**：3(3R−1)² ≤ 2(R²−3) → 25R² − 18R + 9 ≤ 0，判别式 = 324 − 900 < 0，**
无解**。

**情形 2**：3(R−1)² ≤ 2(R²−3) → R² − 6R + 9 ≤ 0 → **(R−3)² ≤ 0**，故 **R = 3**，
等号成立时 x₀ = y₀ = √3。

**验证。** R = 3 时：
- O = (√3, √3, √3)，R² = 3+3+3 = 9 ✓
- b = c = 2√6 > 0，四面体有效 ✓
- S_center = (√3/3, √3/3, 5√3/3)，到平面距离 = |√3/3+√3/3−5√3/3|/√3 = √3/√3 = 1
✓
- D 到平面 ABC 距离 = 2√3/√3 = 2 = 2×1，确认 D 是小球上与切点直径相对的点 ✓
- |O − S_center| = 2 = R − 1，内切于外接球 ✓

所有角度条件亦逐一验证通过。

## 结论

外接球半径为 **3**。
