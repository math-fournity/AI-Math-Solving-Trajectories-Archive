# Problem

A high-security data center consists of an $n \times n$ grid of server racks. Security bots are stationed at specific racks within this grid. A bot monitors all racks located in the same row or column as its own position, but its line of sight is blocked by any other bot; therefore, it only monitors a rack if every rack between itself and that target rack is currently unoccupied.

The facility operates under a "Redundancy Protocol": for any two bots that cannot see each other (i.e., they are not in the same row/column, or there is another bot positioned between them), there must exist at least one empty rack in the grid that is simultaneously monitored by both bots.

Let $R(n)$ represent the maximum number of security bots that can be deployed on an $n \times n$ grid while strictly adhering to this protocol.

Calculate the value of $\sum_{n=1}^{50} R(n)$.
