## 解法

我们计算上抛物面 $x^2 + y^2 + 2az = a^2$（即 $z = \frac{a^2 - x^2 - y^2}{2a}$）
在第二卦限（$x<0, y>0, z>0$）上的面积分，其中 $\mathbf{n}$ 为**上**法线。

**步骤 1：通过投影化简。**

对于 $z = f(x,y)$，上法线的方向余弦满足 $\cos(\mathbf{n},\mathbf{i})\,ds = -f_x\
,dx\,dy$，$\cos(\mathbf{n},\mathbf{j})\,ds = -f_y\,dx\,dy$，$\cos(\mathbf{n},\ma
thbf{k})\,ds = dx\,dy$。这里 $f_x = -x/a$，$f_y = -y/a$，因此：

$$I = \iint_{S_z}\left[x^2\!\left(\tfrac{x}{a}\right) + y^2\!\left(\tfrac{y}{a}\
right) + z^2\right]dx\,dy = \iint_{S_z}\frac{x^3+y^3+az^2}{a}\,dx\,dy,$$

这与提示一致。投影 $S_z$ 是位于第二象限（$x<0, y>0$）的圆盘 $x^2+y^2\le a^2$ 的
部分。

**步骤 2：极坐标。**

令 $x = r\cos\varphi$，$y = r\sin\varphi$，其中 $\varphi\in[\pi/2,\pi]$，$r\in[0
,a]$。则 $z = \frac{a^2-r^2}{2a}$，故 $az^2 = \frac{(a^2-r^2)^2}{4a}$。被积函数
为

$$\frac{r^3(\cos^3\varphi+\sin^3\varphi)}{a} + \frac{(a^2-r^2)^2}{4a^2}.$$

乘以雅可比行列式 $r$ 并分离变量：

$$I = \underbrace{\frac{1}{a}\int_{\pi/2}^{\pi}(\cos^3\varphi+\sin^3\varphi)\,d\
varphi\int_0^a r^4\,dr}_{I_1} + \underbrace{\frac{1}{4a^2}\int_{\pi/2}^{\pi}d\va
rphi\int_0^a (a^2-r^2)^2 r\,dr}_{I_2}.$$

**计算 $I_1$：**

$$\int_{\pi/2}^{\pi}\cos^3\varphi\,d\varphi = \left[\sin\varphi - \tfrac{\sin^3\
varphi}{3}\right]_{\pi/2}^{\pi} = 0 - \tfrac{2}{3} = -\tfrac{2}{3},$$

$$\int_{\pi/2}^{\pi}\sin^3\varphi\,d\varphi = \left[-\cos\varphi + \tfrac{\cos^3
\varphi}{3}\right]_{\pi/2}^{\pi} = \tfrac{2}{3} - 0 = \tfrac{2}{3}.$$

它们的和为 $0$，因此 $I_1 = \frac{1}{a}\cdot 0 \cdot \frac{a^5}{5} = 0$.

**计算 $I_2$：**

$$\int_{\pi/2}^{\pi}d\varphi = \frac{\pi}{2}, \qquad \int_0^a (a^2-r^2)^2 r\,dr
= \frac{a^6}{6} \quad (u = a^2-r^2).$$

因此

$$I_2 = \frac{1}{4a^2}\cdot\frac{\pi}{2}\cdot\frac{a^6}{6} = \frac{\pi a^4}{48}.
$$

**结果：**

$$\boxed{I = \frac{\pi a^4}{48}}.$$
