# 证明：最大的 $k$ 为 $\boxed{2}$

## 问题重述

对正整数 $a$，定义 $x_1 = a$，$x_{n+1} = 2x_n + 1$（$n \geq 1$），$y_n = 2^{x_n} - 1$。求最大的 $k$，使得存在某个正整数 $a$，$y_1, y_2, \ldots, y_k$ 全为素数。

## 第一步：$x_n$ 的显式公式

由递推 $x_{n+1} + 1 = 2(x_n + 1)$，令 $z_n = x_n + 1$，则 $z_{n+1} = 2z_n$，$z_1 = a + 1$，故 $z_n = 2^{n-1}(a+1)$，即

$$x_n = 2^{n-1}(a+1) - 1.$$

特别地：$x_1 = a$，$x_2 = 2a+1$，$x_3 = 4a+3$，$x_4 = 8a+7$。

## 第二步：必要条件——$x_n$ 必须为素数

**引理：** 若 $y_n = 2^{x_n} - 1$ 为素数，则 $x_n$ 必须为素数。

**证明：** 若 $x_n = mn$，$m, n > 1$，则 $2^m - 1 \mid 2^{mn} - 1 = 2^{x_n} - 1 = y_n$，且 $1 < 2^m - 1 < y_n$，故 $y_n$ 为合数。矛盾。$\square$

因此，若 $y_1, \ldots, y_k$ 全为素数，则 $x_1, \ldots, x_k$ 全为素数。

## 第三步：$a$ 的限制

- 若 $a = 1$：$y_1 = 2^1 - 1 = 1$，不是素数，$k = 0$。
- 若 $a$ 为偶数且 $a > 2$：$x_1 = a$ 为合数，故 $y_1$ 为合数，$k = 0$。
- 若 $a = 2$：$x_1 = 2$（素数），需要进一步检查。
- 若 $a$ 为奇素数（$a \geq 3$）：$x_1 = a$ 为素数，需要进一步检查。

所以只需考虑 $a = 2$ 和 $a$ 为奇素数两种情形。

## 第四步：$a = 2$ 的情形

$$x_1 = 2,\quad x_2 = 5,\quad x_3 = 11,\quad x_4 = 23, \ldots$$

$$y_1 = 2^2 - 1 = 3 \text{（素数）},\quad y_2 = 2^5 - 1 = 31 \text{（素数）},\quad y_3 = 2^{11} - 1 = 2047 = 23 \times 89 \text{（合数）}.$$

所以 $a = 2$ 时 $k = 2$。

## 第五步：$a$ 为奇素数的情形——核心论证

设 $a \geq 3$ 为奇素数。我们要证明 $y_1, y_2, y_3$ 不可能全为素数。

**关键观察：** $x_3 = 4a + 3$。由于 $a$ 为奇数，$4a \equiv 4 \pmod{8}$，故

$$x_3 = 4a + 3 \equiv 7 \equiv -1 \pmod{8}.$$

分两种情况讨论：

### 情况 A：$x_3$ 为合数

由引理，$y_3 = 2^{x_3} - 1$ 为合数。故 $k \leq 2$。

### 情况 B：$x_3$ 为素数

此时 $x_3$ 为奇素数且 $x_3 \equiv -1 \pmod{8}$。

**利用二次剩余理论：** 对奇素数 $p$，$2$ 是模 $p$ 的二次剩余当且仅当 $p \equiv \pm 1 \pmod{8}$（这是二次互反律的补充定理）。

由于 $x_3 \equiv -1 \pmod{8}$，$2$ 是模 $x_3$ 的二次剩余。由 **Euler 准则**：

$$2^{(x_3 - 1)/2} \equiv 1 \pmod{x_3}.$$

计算指数：

$$\frac{x_3 - 1}{2} = \frac{4a + 3 - 1}{2} = \frac{4a + 2}{2} = 2a + 1 = x_2.$$

因此

$$x_3 \mid 2^{x_2} - 1 = y_2.$$

现在需要说明 $y_2 > x_3$，从而 $y_2$ 是合数（有非平凡因子 $x_3$）。由于 $a \geq 3$：

$$y_2 = 2^{x_2} - 1 = 2^{2a+1} - 1 \geq 2^7 - 1 = 127, \qquad x_3 = 4a + 3 \leq 4a + 3.$$

对 $a \geq 3$，$2^{2a+1} - 1 > 4a + 3$（因为 $2^{2a+1}$ 指数增长而 $4a+3$ 线性增长，$a = 3$ 时 $127 > 15$ 已成立，且差距随 $a$ 增大而增大）。

故 $1 < x_3 < y_2$，$y_2$ 为合数。因此 $k \leq 1$。

### 综合

对任意奇素数 $a \geq 3$：
- 情况 A（$x_3$ 合数）：$y_3$ 合数，$k \leq 2$。
- 情况 B（$x_3$ 素数）：$y_2$ 合数，$k \leq 1$。

无论哪种情况，$y_1, y_2, y_3$ 不可能全为素数，即 $k \leq 2$。

## 第六步：$k = 2$ 可达

取 $a = 2$：

$$y_1 = 3 \text{（素数）}, \quad y_2 = 31 \text{（素数）}, \quad y_3 = 2047 = 23 \times 89 \text{（合数）}.$$

故 $k = 2$ 可达。

（亦可取 $a = 3$：$y_1 = 7$（素数），$y_2 = 127$（素数），$y_3 = 2^{15} - 1 = 32767 = 7 \times 31 \times 151$（合数），同样 $k = 2$。）

## 结论

- 对所有正整数 $a$，$k \leq 2$（$a = 2$ 时 $y_3$ 合数；$a$ 为奇素数时由二次剩余论证 $y_2$ 或 $y_3$ 合数；其余 $a$ 时 $y_1$ 已合数）。
- $k = 2$ 可达（如 $a = 2$ 或 $a = 3$）。

因此，最大的 $k$ 为

$$\boxed{k = 2}.$$

QED
