## Example of a Set with Order Type $\omega^\omega$

**The example.** Let $S = \mathbb{N}[x]$ be the set of all polynomials with natu
ral-number coefficients:
$$S = \left\{\, a_0 + a_1 x + \dots + a_d x^d : d \in \mathbb{N},\ a_i \in \math
bb{N}\,\right\}.$$

Define an order $<$ on $S$ by: $p < q$ if and only if the polynomial $q - p$ (wh
ich has integer coefficients) has its **leading nonzero coefficient positive**.
(Equivalently: compare by degree first — higher degree is larger; for equal degr
ee, compare leading coefficients; then the next coefficient; and so on.)

**Claim.** $(S, <)$ has order type $\omega^\omega$.

omega^d,$$
computed using ordinal arithmetic (so the sum is in decreasing order of exponent
s, i.e. Cantor normal form).

By the **Cantor normal form theorem**, every ordinal $\alpha < \omega^\omega$ ca
n be written uniquely as
$$\alpha = \omega^{n_1} c_1 + \omega^{n_2} c_2 + \dots + \omega^{n_k} c_k, \qqua
d n_1 > n_2 > \dots > n_k \ge 0,\ c_i \ge 1.$$
Setting $a_{n_i} = c_i$ and $a_j = 0$ for $j \notin \{n_1, \dots, n_k\}$ recover

 **bijection** from $S$ onto the set of ordinals $\{\alpha : \alpha < \omega^\om

**Step 2: $\varphi$ is order-preserving.**

- In $S$: $p < q \iff$ the leading coefficient of $q - p$ is positive $\iff b_d

## Structure of Such a Set

A well-ordered set of order type $\omega^\omega$ has the following structure:

1. **Countable and well-ordered.** $\omega^\omega$ is a countable limit ordinal;
 the set is well-ordered with no largest element.

2. **Supremum of a tower.** It is the supremum of the strictly increasing chain
$$\omega \;<\; \omega^2 \;<\; \omega^3 \;<\; \dots$$
where each $\omega^n$ is a **proper initial segment** of $\omega^{n+1}$ (since $
\omega^{n+1} = \omega^n \cdot \omega$, and the ordinals below $\omega^n$ form th
e first block). Thus $\omega^\omega = \sup_{n < \omega} \omega^n$, and every pro
per initial segment of $\omega^\omega$ has order type some $\alpha < \omega^\ome
ga$.

3. **Grading by degree.** Via the polynomial model, the set is naturally graded:
 for each $n \ge 0$, the "level-$n$" part
$$\{\alpha : \omega^n \le \alpha < \omega^{n+1}\}$$
has order type $\omega^{n+1}$ and is itself a concatenation of $\omega$-many blo
cks, each of order type $\omega^n$. Level $0$ is just $\omega$ (the natural numb
ers); level $1$ is $\omega$ copies of $\omega$; level $2$ is $\omega$ copies of
$\omega^2$; and so on.

4. **Cantor normal form.** Every element $\alpha < \omega^\omega$ has a unique C
antor normal form
$$\alpha = \omega^{n_1} c_1 + \dots + \omega^{n_k} c_k, \qquad n_1 > \dots > n_k
 \ge 0,\ c_i \in \mathbb{N}^+,$$
with **all exponents finite**. This is exactly what distinguishes $\omega^\omega
$ from larger ordinals: it is the smallest ordinal whose Cantor normal form requ
ires an infinite exponent.

5. **Cofinality $\omega$.** The sequence $\omega, \omega^2, \omega^3, \dots$ is
cofinal in $\omega^\omega$, so $\operatorname{cf}(\omega^\omega) = \omega$. The
set is not a successor ordinal and cannot be reached in finitely many successor
steps from $0$.

6. **Closed under ordinal addition on the left by smaller ordinals.** For any $\
beta < \omega^\omega$ and any $\alpha < \omega^\omega$, we have $\alpha + \beta
< \omega^\omega$ (since the Cantor normal form of $\alpha + \beta$ still has onl
y finite exponents). However $\omega^\omega + 1 > \omega^\omega$, so the set is
not closed under successor beyond its supremum.

In summary: **a canonical example is $\mathbb{N}[x]$ under degree-lexicographic
order**, and the structure is that of a countable limit ordinal built as an $\om
ega$-indexed tower of powers $\omega^n$, with every element describable by a Can
tor normal form using only finite exponents.
