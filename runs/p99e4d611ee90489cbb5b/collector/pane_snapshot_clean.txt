## Solution

The answer is **98**.

### Setup

Number the rows and columns $1, \ldots, 98$. The board has cell $(i,j)$ colored
black if $i+j$ is even and white if $i+j$ is odd. To make the board monochromati
c, we must flip exactly the cells of one color — say the cells where $i+j$ is od
d (the other choice is symmetric). Define the target flip matrix $A_{ij} = (i+j)
 \bmod 2$.

### The Corner Transform

Define the $(n+1)\times(n+1) = 99\times 99$ matrix $D$ (indexed $1 \le i,j \le 9
9$) by
$$D_{ij} = A_{ij} + A_{i-1,j} + A_{i,j-1} + A_{i-1,j-1} \pmod{2},$$
where $A_{ij}=0$ outside $[1,98]^2$. This is an invertible linear map (recover $
A$ by 2D prefix sums), so minimizing clicks for $A$ is equivalent to minimizing
clicks for $D$.

**Key fact:** A single click on rectangle $[r_1,r_2]\times[c_1,c_2]$ produces a
$D$-matrix with exactly four 1's, at the corner positions
$$(r_1,\,c_1),\quad (r_1,\,c_2{+}1),\quad (r_2{+}1,\,c_1),\quad (r_2{+}1,\,c_2{+
}1).$$
These are the four corners of an axis-aligned rectangle on the $99\times 99$ gri
d (with $1 \le r_1 < r_2{+}1 \le 99$ and $1 \le c_1 < c_2{+}1 \le 99$). Converse
ly every such grid-rectangle corresponds to a valid click. So **each click contr
ibutes exactly 4 marks** to $D$.

### Computing the Target $D$

For the checkerboard $A_{ij}=(i+j)\bmod 2$:

**Interior** ($2\le i,j\le 98$): $D_{ij} = (i+j)+(i{-}1{+}j)+(i{+}j{-}1)+(i{-}1{
+}j{-}1) = 4(i{+}j)-2 \equiv 0 \pmod 2$.

**Boundary (non-corner):** For example, $D_{1,j} = A_{1,j}+A_{1,j-1} = (1{+}j)+(
j) \equiv 1 \pmod 2$ for $2\le j\le 98$. By symmetry, every non-corner boundary
point equals $1$.

**Corners:** $D_{1,1}=A_{1,1}=0$; $\;D_{1,99}=A_{1,98}=1$; $\;D_{99,1}=A_{98,1}=
1$; $\;D_{99,99}=A_{98,98}=0$.

So the target $D$ has all its 1's on the boundary: $4\cdot 98 - 4 = 388$ non-cor
ner boundary points (all 1) plus 2 corner 1's, giving **390 ones total**, all on
 the boundary of the $99\times 99$ grid.

### Lower Bound: $k \ge 98$

Each click places 4 marks. A mark is either on the boundary or in the interior.
Since the target has **no** interior 1's, every interior mark must be canceled (
appear an even number of times), but in any case:

- Total marks placed $= 4k$.
- Boundary marks $\le 4k$.
- The 390 boundary points that are 1 each require $\ge 1$ toggle, so boundary ma
rks $\ge 390$.

Therefore $4k \ge 390$, giving $k \ge \lceil 390/4\rceil = 98$.

### Construction: $k = 98$

**Flip every even-numbered column** (columns $2, 4, 6, \ldots, 98$), each as a f
ull-height $98\times 1$ rectangle — that's 49 clicks.

**Flip every even-numbered row** (rows $2, 4, 6, \ldots, 98$), each as a full-wi
dth $1\times 98$ rectangle — that's 49 clicks.

Total: $49 + 49 = 98$ clicks.

**Verification:** Cell $(i,j)$ is toggled once if $j$ is even (column flip) and
once if $i$ is even (row flip), so the total toggle count mod 2 is
$$[\,i\text{ even}\,] + [\,j\text{ even}\,] \;\equiv\; (i\bmod 2)+(j\bmod 2) \;\
equiv\; (i+j)\bmod 2,$$
which is exactly the checkerboard pattern $A_{ij}$. So after these 98 clicks, ev
ery cell $(i,j)$ with $i+j$ odd is flipped (and no others), turning the entire b
oard one color. ✓

### Conclusion

The lower bound is 98 and the construction achieves 98, so the minimum number of
 mouse clicks is $\boxed{98}$.
