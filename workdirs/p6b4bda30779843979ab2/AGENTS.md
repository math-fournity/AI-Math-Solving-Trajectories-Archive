# Problem

In a global logistics network, 80 regional distribution hubs are linked by specialized cargo drone routes. The network is designed such that every hub is guaranteed to have direct, two-way drone connections to at least 7 other hubs. Furthermore, the network is fully integrated, meaning a package can eventually reach any hub from any other hub through a sequence of these direct connections.

A logistics analyst needs to determine the maximum possible delivery time for the least efficient network configuration. Specifically, they define $k$ as the minimum number of flight legs required to ensure that, regardless of how the routes are distributed among the 80 hubs (provided they meet the minimum connection and integration rules), any hub can send a package to any other hub using no more than $k$ direct flights.

Find the smallest positive integer $k$.
