# Morphisms Between Integral Curves and Function Fields

**Setup.** Let $X, Y$ be integral curves (integral, separated schemes of finite
type over a field $k$, of dimension $1$). Denote by $\xi_X, \xi_Y$ their generic
 points and by $K(X) = \mathcal{O}_{X,\xi_X}$, $K(Y) = \mathcal{O}_{Y,\xi_Y}$ th
eir function fields. Let $f : X \to Y$ be a morphism.

**Claim.** The morphism $f$ induces a homomorphism $K(Y) \to K(X)$ of function f
ields **if and only if $f$ is dominant** (equivalently, $f$ does not contract $X
$ to a single closed point). When it exists, the induced map is an injective fie
ld homomorphism (a $k$-algebra embedding if $f$ is a $k$-morphism).

---

## Proof

### Step 1. Where the generic point goes

The morphism $f$ gives a continuous map on topological spaces and a sheaf map $f
^\# : \mathcal{O}_Y \to f_*\mathcal{O}_X$. Since $X$ is irreducible with generic
 point $\xi_X$ (i.e. $\overline{\{\xi_X\}} = X$), the image $f(X) \subseteq \ove
rline{\{f(\xi_X)\}}$. Hence $f(\xi_X)$ is the generic point of the (irreducible)
 subset $\overline{f(X)}$.

Because $Y$ is an integral curve, its underlying topological space has a unique
generic point $\xi_Y$ (whose closure is all of $Y$) and every proper closed subs
et is a finite set of closed points (zero-dimensional). Therefore:

- **If $f$ is dominant**, $\overline{f(X)} = Y$, so $f(\xi_X) = \xi_Y$.
- **If $f$ is not dominant**, $\overline{f(X)}$ is a proper closed subset of $Y$
, hence a finite set of closed points. Since $f(X)$ is irreducible (continuous i
mage of an irreducible space), $f(X)$ is a single closed point $p$, and $f(\xi_X
) = p$.

### Step 2. The dominant case: $K(Y) \hookrightarrow K(X)$

Assume $f$ is dominant, so $f(\xi_X) = \xi_Y$. The stalk map of $f^\#$ at $\xi_X
$ is a local homomorphism of local rings

$$f^\#_{\xi_X} : \mathcal{O}_{Y,\xi_Y} \longrightarrow \mathcal{O}_{X,\xi_X},$$

i.e. $K(Y) \to K(X)$. Both sides are fields (the local rings at generic points o
f integral schemes are fields). A local homomorphism between fields is necessari
ly **injective** (its kernel is a proper ideal, hence $0$). Thus $f$ induces an
embedding of fields

$$f^* : K(Y) \hookrightarrow K(X).$$

If $X, Y$ are $k$-curves and $f$ is a $k$-morphism, this is a $k$-algebra embedd
ing.

### Step 3. The non-dominant case: no field map $K(Y) \to K(X)$

Assume $f$ is not dominant. By Step 1, $f(X) = \{p\}$ for a closed point $p \in
Y$, and $f(\xi_X) = p$. The stalk map is

$$f^\#_{\xi_X} : \mathcal{O}_{Y,p} \longrightarrow \mathcal{O}_{X,\xi_X} = K(X).
$$

Since $f(X) = \{p\}$ set-theoretically, $f$ factors (scheme-theoretically) throu
gh the reduced closed subscheme $\{p\} = \operatorname{Spec} \kappa(p)$. Consequ
ently the map $\mathcal{O}_{Y,p} \to K(X)$ factors as

$$\mathcal{O}_{Y,p} \xrightarrow{\;\operatorname{res}\;} \kappa(p) \longrightarr
ow K(X),$$

where $\operatorname{res}$ is the residue map with kernel $\mathfrak{m}_p$, the
maximal ideal of the closed point $p$. On an integral curve, $\mathfrak{m}_p \ne
q 0$ (a closed point on a positive-dimensional scheme has a nonzero maximal idea
l). Hence $f^\#_{\xi_X}$ has nontrivial kernel and is **not injective**.

Now $K(Y) = \operatorname{Frac}(\mathcal{O}_{Y,p})$ (the local ring at a closed
point of a curve is a DVR with fraction field $K(Y)$). A ring homomorphism $\mat
hcal{O}_{Y,p} \to K(X)$ extends to $\operatorname{Frac}(\mathcal{O}_{Y,p}) = K(Y
)$ **only if** every nonzero element of $\mathcal{O}_{Y,p}$ maps to a unit in $K
(X)$, i.e. only if the map is injective (so that nonzero elements map to nonzero
, hence invertible, elements of the field $K(X)$). Since $f^\#_{\xi_X}$ is not i
njective, **no extension to $K(Y) \to K(X)$ exists**.

### Step 4. Equivalence for curves

For integral curves, "dominant" admits a simple equivalent formulation. The only
 non-dominant morphism is one that contracts $X$ to a single closed point of $Y$
 (Step 1). Such a morphism is precisely a "constant" morphism (one whose image i
s a point). Hence:

$$f \text{ induces } K(Y) \to K(X) \iff f \text{ is dominant} \iff f \text{ is n
on-constant}.$$

### Step 5. Summary

A morphism $f : X \to Y$ of integral curves induces a homomorphism of function f
ields $K(Y) \to K(X)$ **if and only if $f$ is dominant**. In that case the induc
ed map is the stalk map at the generic point $f^\#_{\xi_X} : \mathcal{O}_{Y,\xi_
Y} \to \mathcal{O}_{X,\xi_X}$, which is an **injective** field homomorphism (a $
k$-algebra embedding for $k$-curves). If $f$ is not dominant, it contracts $X$ t
o a closed point $p$, the stalk map $\mathcal{O}_{Y,p} \to K(X)$ factors through
 the residue field $\kappa(p)$ with nonzero kernel $\mathfrak{m}_p$, and therefo
re cannot be extended to a field homomorphism $K(Y) \to K(X)$.
