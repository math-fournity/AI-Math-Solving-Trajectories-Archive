# Problem

In the high-security Cyber-Vault, a digital access key is composed of two parallel data tracks, Track A and Track B. Each track contains exactly five sequential slots, forming five vertically aligned pairs of data packets. 

For each slot, a packet must be loaded with one of four distinct signal types: High-Frequency (H), Microwave (M), Near-Field (N), or Thermal (T). To ensure signal integrity, the system enforces the following two protocols:

1.  **Vertical Interference Protocol:** Within any of the five vertical pairs, the signal in Track A must be different from the signal in Track B.
2.  **Horizontal Stability Protocol:** On any single track, a High-Frequency (H) signal can never be placed in a slot immediately adjacent to a Microwave (M) signal. Similarly, a Near-Field (N) signal can never be placed in a slot immediately adjacent to a Thermal (T) signal.

How many unique configurations of this two-track access key are possible?
