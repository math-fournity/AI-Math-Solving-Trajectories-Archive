## Solution

**Goal:** Evaluate $I = \displaystyle\int_0^{+\infty} \frac{\sin^4 x}{x^4}\,dx$.

### Step 1 — Integration by parts (first reduction)

Set $u = \sin^4 x$, $dv = x^{-4}\,dx$, so $v = -\tfrac{1}{3}x^{-3}$ and $du = 4\
sin^3 x\cos x\,dx$.

The boundary term $\bigl[-\tfrac{\sin^4 x}{3x^3}\bigr]_0^\infty$ vanishes: at $\
infty$ since $|\sin^4 x|/x^3\to 0$, and at $0$ since $\sin^4 x \sim x^4$ gives $
\sin^4 x/x^3 \sim x \to 0$. Hence

$$I = \frac{4}{3}\int_0^\infty \frac{\sin^3 x\cos x}{x^3}\,dx.$$

### Step 2 — Integration by parts (second reduction)

Set $u = \sin^3 x\cos x$, $dv = x^{-3}\,dx$, so $v = -\tfrac{1}{2}x^{-2}$ and $d
u = (3\sin^2 x\cos^2 x - \sin^4 x)\,dx$.

Again the boundary term vanishes (the numerator is $O(x^3)$ near $0$ and bounded
 at $\infty$), giving

$$\int_0^\infty \frac{\sin^3 x\cos x}{x^3}\,dx = \frac{1}{2}\int_0^\infty \frac{
3\sin^2 x\cos^2 x - \sin^4 x}{x^2}\,dx.$$

Therefore

$$I = \frac{2}{3}\int_0^\infty \frac{3\sin^2 x\cos^2 x - \sin^4 x}{x^2}\,dx.$$

### Step 3 — Simplify the numerator

Using $\sin^2 x = \frac{1-\cos 2x}{2}$ and $\cos^2 x = \frac{1+\cos 2x}{2}$:

$$3\cos^2 x - \sin^2 x = \frac{3(1+\cos 2x)-(1-\cos 2x)}{2} = 1 + 2\cos 2x,$$

so

$$3\sin^2 x\cos^2 x - \sin^4 x = \sin^2 x\,(3\cos^2 x - \sin^2 x) = \frac{1-\cos
 2x}{2}(1+2\cos 2x).$$

Expanding and using $\cos^2 2x = \frac{1+\cos 4x}{2}$:

$$(1-\cos 2x)(1+2\cos 2x) = 1 + \cos 2x - 2\cos^2 2x = \cos 2x - \cos 4x.$$

Thus

$$3\sin^2 x\cos^2 x - \sin^4 x = \frac{\cos 2x - \cos 4x}{2},$$

and

$$I = \frac{2}{3}\cdot\frac{1}{2}\int_0^\infty \frac{\cos 2x - \cos 4x}{x^2}\,dx
 = \frac{1}{3}\int_0^\infty \frac{\cos 2x - \cos 4x}{x^2}\,dx.$$

### Step 4 — Evaluate the cosine integral

For $a,b>0$, integrate $\displaystyle\int_0^\infty \frac{\cos ax - \cos bx}{x^2}
\,dx$ by parts with $u=\cos ax-\cos bx$, $dv=x^{-2}dx$:

$$\int_0^\infty \frac{\cos ax - \cos bx}{x^2}\,dx = -\int_0^\infty \frac{a\sin a
x - b\sin bx}{x}\,dx = -a\cdot\frac{\pi}{2} + b\cdot\frac{\pi}{2} = \frac{\pi}{2
}(b-a),$$

using the Dirichlet integral $\displaystyle\int_0^\infty \frac{\sin kx}{x}\,dx =
 \frac{\pi}{2}$ for $k>0$ (boundary terms vanish since $\cos ax-\cos bx = O(x^2)
$ near $0$).

With $a=2,\,b=4$:

$$\int_0^\infty \frac{\cos 2x - \cos 4x}{x^2}\,dx = \frac{\pi}{2}(4-2) = \pi.$$

### Step 5 — Conclusion

$$I = \frac{1}{3}\cdot\pi = \frac{\pi}{3}.$$

**Numerical check:** $\pi/3 \approx 1.0472$, consistent with the known identity
$\displaystyle\int_{-\infty}^{\infty}\operatorname{sinc}^4(x)\,dx = \frac{2\pi}{
3}$, whose half is $\pi/3$.

$$\boxed{\displaystyle\int_0^{+\infty} \frac{\sin^4 x}{x^4}\,dx = \frac{\pi}{3}}
$$
