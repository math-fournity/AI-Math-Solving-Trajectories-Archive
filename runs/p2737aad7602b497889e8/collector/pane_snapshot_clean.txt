## Proof

Let $c = 2008$. The recurrence is:
$$a_n^2 - \left(\frac{a_{n-1}}{c} + \frac{1}{a_{n-1}}\right) a_n + \frac{1}{c} =
 0$$

**Step 1: Vieta's formulas.** If the two roots at step $n$ are $r$ and $s$, then
:
- $r + s = \frac{a_{n-1}}{c} + \frac{1}{a_{n-1}}$
- $rs = \frac{1}{c}$

So the two choices satisfy $s = \frac{1}{cr}$; if one root is $r$, the other is
$\frac{1}{cr}$.

**Step 2: Substitution.** Let $t_n = a_n\sqrt{c}$, so $a_n = t_n/\sqrt{c}$. Then
 the two roots in $t$-space satisfy:
$$t_n + t_n' = \frac{t_{n-1}}{c} + \frac{c}{t_{n-1}}, \qquad t_n \cdot t_n' = 1$
$

So $t_n' = 1/t_n$, and the recurrence becomes:
$$t_n + \frac{1}{t_n} = \frac{t_{n-1}}{c} + \frac{c}{t_{n-1}}$$

**Step 3: Logarithmic reduction.** Set $t_n = c^{u_n}$ (i.e., $u_n = \log_c t_n$
). Then:
$$c^{u_n} + c^{-u_n} = c^{u_{n-1}-1} + c^{1-u_{n-1}}$$

The function $h(x) = c^x + c^{-x} = 2\cosh(x\ln c)$ is even and strictly increas
ing in $|x|$. Therefore:
$$|u_n| = |u_{n-1} - 1|$$

At each step, we **choose the sign**: $u_n = +|u_{n-1}-1|$ or $u_n = -|u_{n-1}-1
|$.

The initial value is $t_1 = 2\sqrt{c}$, so $u_1 = \log_c(2\sqrt{c}) = \log_c 2 +
 \tfrac{1}{2} =: \alpha$.

Note $\alpha \approx 0.591 < 1$. We want to maximize $a_{2008} = c^{u_{2008} - 1
/2}$, equivalently maximize $u_{2008}$.

**Step 4: Optimal strategy.** Define $M_n$ = max achievable $u_n$ and $m_n$ = mi
n achievable $u_n$.

**Claim:** For $n \geq 2$: $M_n = (n-1) - \alpha$ and $m_n = \alpha - (n-1)$.

**Proof by induction.** Since $u_n = \pm|u_{n-1}-1|$, to maximize $u_n$ we choos

ign and maximize $|u_{n-1}-1|$.

*Base case* ($n=2$): $u_1 = \alpha$ is fixed, $|u_1 - 1| = 1 - \alpha$, so $M_2

 \geq 2$)

Since $(n-1)-\alpha > (n-3)-\alpha$, the maximum of $|u_{n-1}-1|$ is $(n-1)-\alp
ha$, achieved at $u_{n-1} = m_{n-1}$.

Therefore $M_n = (n-1)-\alpha$ and $m_n = \alpha-(n-1)$. ✓

**Step 5: Compute the answer.** The maximum $u_{2008} = M_{2008} = 2007 - \alpha
