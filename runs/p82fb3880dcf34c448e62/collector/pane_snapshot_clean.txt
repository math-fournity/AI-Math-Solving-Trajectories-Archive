## Proof

Following the hint, for $n > 2$ we write $I_n = A_n + B_n + C_n + D_n$ where:

$$A_n = \int_0^1,\quad B_n = \int_1^{n^2-n},\quad C_n = \int_{n^2-n}^{n^2+n},\qu
ad D_n = \int_{n^2+n}^{+\infty}.$$

### Part $A_n$: $\int_0^1$

On $[0,1]$, we have $|x - n^2| = n^2 - x \geq n^2 - 1$, so $\frac{1}{\sqrt{|x-n^
2|}} \leq \frac{1}{\sqrt{n^2-1}}$. Thus:
$$A_n \leq \frac{1}{\sqrt{n^2-1}}\int_0^1 e^{-n^2 x}\,dx = \frac{1}{\sqrt{n^2-1}
}\cdot\frac{1-e^{-n^2}}{n^2} \;\leq\; \frac{1}{n\sqrt{n^2-1}} \;\longrightarrow\
; 0.$$

### Part $B_n$: $\int_1^{n^2-n}$

On $[1,\, n^2-n]$, we have $|x-n^2| = n^2 - x \geq n$, so $\frac{1}{\sqrt{|x-n^2
|}} \leq \frac{1}{\sqrt{n}}$. Thus:
$$B_n \leq \frac{1}{\sqrt{n}}\int_1^{n^2-n} e^{-n^2 x}\,dx \leq \frac{1}{\sqrt{n
}}\int_1^{\infty} e^{-n^2 x}\,dx = \frac{1}{\sqrt{n}}\cdot\frac{e^{-n^2}}{n^2} \
;\longrightarrow\; 0.$$

### Part $D_n$: $\int_{n^2+n}^{+\infty}$

On $[n^2+n,\,+\infty)$, we have $|x-n^2| = x - n^2 \geq n$, so $\frac{1}{\sqrt{|
x-n^2|}} \leq \frac{1}{\sqrt{n}}$. Thus:
$$D_n \leq \frac{1}{\sqrt{n}}\int_{n^2+n}^{\infty} e^{-n^2 x}\,dx = \frac{1}{\sq
rt{n}}\cdot\frac{e^{-n^2(n^2+n)}}{n^2} \;\longrightarrow\; 0.$$

### Part $C_n$: $\int_{n^2-n}^{n^2+n}$ (the main term)

Substitute $x = n^2 + t$, so $t \in [-n, n]$, $dx = dt$, $|x - n^2| = |t|$, and
$e^{-n^2 x} = e^{-n^4}\,e^{-n^2 t}$:

$$C_n = e^{-n^4}\int_{-n}^{n} \frac{e^{-n^2 t}}{\sqrt{|t|}}\,dt = e^{-n^4}\!\lef
t(\int_0^n \frac{e^{n^2 s}}{\sqrt{s}}\,ds + \int_0^n \frac{e^{-n^2 s}}{\sqrt{s}}
\,ds\right),$$

where we set $s = -t$ in the first integral and $s = t$ in the second.

**Second integral:** With $u = n^2 s$,
$$\int_0^n \frac{e^{-n^2 s}}{\sqrt{s}}\,ds = \frac{1}{n}\int_0^{n^3}\frac{e^{-u}
}{\sqrt{u}}\,du \;\leq\; \frac{1}{n}\int_0^{\infty}\frac{e^{-u}}{\sqrt{u}}\,du =
 \frac{\sqrt{\pi}}{n}.$$

**First integral:** The function $f(s) = n^2 s - \tfrac{1}{2}\ln s$ (from the ex
ponent and the $\sqrt{s}$ denominator) is maximized on $[0,n]$ at $s = n$ (since
 $f'(s) = n^2 - \frac{1}{2s} > 0$ for $s \geq 1$). By the Laplace method, settin
g $s = n - v$:

$$\int_0^n \frac{e^{n^2 s}}{\sqrt{s}}\,ds = \int_0^n \frac{e^{n^2(n-v)}}{\sqrt{n
-v}}\,dv \leq \frac{e^{n^3}}{\sqrt{n}}\int_0^n e^{-n^2 v}\,dv \leq \frac{e^{n^3}
}{\sqrt{n}}\cdot\frac{1}{n^2} = \frac{e^{n^3}}{n^{5/2}}.$$

(Here we used $\frac{1}{\sqrt{n-v}} \leq \frac{1}{\sqrt{n}}$ is not valid for $v
$ near $n$; more carefully, split at $v = n/2$: for $v \in [0, n/2]$, $\frac{1}{
\sqrt{n-v}} \leq \frac{\sqrt{2}}{\sqrt{n}}$ and $\int_0^{n/2} e^{-n^2 v}dv \leq
\frac{1}{n^2}$, giving $\leq \frac{\sqrt{2}\,e^{n^3}}{n^{5/2}}$; for $v \in [n/2
, n]$, $e^{-n^2 v} \leq e^{-n^3/2}$ so the contribution is $\leq n \cdot e^{n^3
- n^3/2} = n\,e^{n^3/2}$, which is negligible compared to the first piece. Hence
 $\int_0^n \frac{e^{n^2 s}}{\sqrt{s}}ds = O\!\left(\frac{e^{n^3}}{n^{5/2}}\right
)$.)

Combining:
$$C_n = e^{-n^4}\!\left(O\!\left(\frac{e^{n^3}}{n^{5/2}}\right) + O\!\left(\frac
{1}{n}\right)\right) = O\!\left(\frac{e^{-n^4+n^3}}{n^{5/2}}\right) + O\!\left(\
frac{e^{-n^4}}{n}\right).$$

Since $n^4 - n^3 = n^3(n-1) \to +\infty$, both terms tend to $0$.

### Conclusion

All four parts satisfy $A_n, B_n, C_n, D_n \to 0$ as $n \to \infty$. Therefore:

$$\lim_{n\to\infty}\int_0^{+\infty}\frac{e^{-n^2 x}}{\sqrt{|x-n^2|}}\,dx = 0.$$
