## Proof

**Notation.** Place all 7n points on a line; let their sorted positions be $p_1
< p_2 < \cdots < p_{7n}$. The span is $b - a = p_{7n} - p_1 = \sum_{i=1}^{7n-1}(
p_{i+1} - p_i)$.

**Key observations on consecutive vs. non-consecutive constraints.**

Since every pair of distinct points must be at distance $\geq 1$, every consecut
ive gap $p_{i+1} - p_i \geq 1$. For same-color consecutive pairs the gap is larg
er: $\geq 2$ (red-red) or $\geq 3$ (blue-blue).

For **non-consecutive** same-color pairs, the only binding case is blue-blue wit
h exactly one point between them: if $B, R, B$ are consecutive in the sorted ord
er, the two gaps sum to the blue-blue distance, which must be $\geq 3$, while ea
ch gap individually is $\geq 1$, forcing an extra $+1$. For reds with one point
between them, the distance is $\geq 1+1 = 2$, already satisfied. For blues with
$\geq 2$ points between them, the distance is $\geq 3$, already satisfied.

**Slot decomposition.** The $3n$ blue points, in sorted order $B_1 < B_2 < \cdot
s < B_{3n}$, partition the line into $3n+1$ slots: two **end slots** (before $B_
1$ and after $B_{3n}$) and $3n - 1$ **interior slots** (between consecutive blue
s). Let $r_0, r_{3n}$ be the red counts in the end slots and $r_1, \dots, r_{3n-
1}$ the red counts in the interior slots, with $r_0 + r_{3n} + \sum_{i=1}^{3n-1}
 r_i = 4n$.

**Cost of each slot.** The contribution of each slot to the total span (sum of g
aps within that slot) is:

| Slot type | Reds $k$ | Gaps | Minimum cost |
|-----------|----------|------|-------------|
| End | $0$ | none | $0$ |
| End | $k \geq 1$ | $(k{-}1)$ gaps of $R$R ($\geq 2$) $+ 1$ gap of $RB$ ($\geq
1$) | $2k - 1$ |
| Interior | $0$ | $1$ gap $BB$ ($\geq 3$) | $3$ |
| Interior | $1$ | $2$ gaps $BR{+}RB$ ($\geq 1$ each), but $B$-to-$B$ $\geq 3$ |
 $3$ |
| Interior | $k \geq 2$ | $2$ gaps $BR/RB$ ($\geq 1$) $+\; (k{-}1)$ gaps $RR$ ($
\geq 2$); $B$-to-$B$ $= 2k \geq 3$ ✓ | $2k$ |

**Lower bound.** Define the *penalty* of an interior slot as its cost minus $2k$
 (the "baseline" for $k$ reds):
- $k = 0$: penalty $= 3 - 0 = 3$
- $k = 1$: penalty $= 3 - 2 = 1$
- $k \geq 2$: penalty $= 2k - 2k = 0$

Let $E = \#\{i : r_i = 0\}$, $S = \#\{i : r_i = 1\}$ (both over interior slots).
 The total span is:

$$\text{Span} = \underbrace{f(r_0) + f(r_{3n})}_{\text{end slots}} + \sum_{i=1}^
{3n-1} g(r_i)$$

where $f(0)=0$, $f(k)=2k-1$ for $k\geq 1$, and $g$ is the interior cost. Rewriti
ng:

$$\text{Span} = 2(r_0 + r_{3n}) - c_{\text{end}} + 2\sum_{i=1}^{3n-1} r_i + 3E +
 S = 2 \cdot 4n - c_{\text{end}} + 3E + S$$

where $c_{\text{end}} = \mathbf{1}_{r_0 \geq 1} + \mathbf{1}_{r_{3n} \geq 1} \in
 \{0, 1, 2\}$ counts non-empty end slots. Thus:

$$\text{Span} = 8n - c_{\text{end}} + 3E + S.$$

**Constraint on $E$ and $S$.** Assuming all interior slots have $r_i \in \{0, 1,
 2\}$ (using $r_i \geq 3$ only increases red usage without reducing penalty, so
it cannot help):

$$\sum_{i=1}^{3n-1} r_i = S + 2(3n - 1 - E - S) = 6n - 2 - 2E - S.$$

$$r_0 + r_{3n} = 4n - (6n - 2 - 2E - S) = -2n + 2 + 2E + S.$$

Since $r_0 + r_{3n} \geq c_{\text{end}}$ (each non-empty end slot has $\geq 1$ r
ed):

$$2E + S \geq 2n - 2 + c_{\text{end}}.$$

**Minimizing $3E + S$** subject to $2E + S \geq 2n - 2 + c_{\text{end}}$, $E, S
\geq 0$: Since $E$ costs $3$ per unit and contributes $2$ to the constraint, whi
le $S$ costs $1$ per unit and contributes $1$, we use $S$ first: set $E = 0$, $S
 = 2n - 2 + c_{\text{end}}$, giving $3E + S = 2n - 2 + c_{\text{end}}$.

(Using $E > 0$ gives $3E + S \geq 3E + (2n - 2 + c_{\text{end}} - 2E) = E + 2n -
 2 + c_{\text{end}} > 2n - 2 + c_{\text{end}}$, which is worse.)

Therefore:

$$\text{Span} \geq 8n - c_{\text{end}} + (2n - 2 + c_{\text{end}}) = 10n - 2.$$

This holds for every value of $c_{\text{end}} \in \{0, 1, 2\}$, so **$b - a \geq
 10n - 2$** regardless of configuration.

**Upper bound (construction).** We exhibit an arrangement achieving span $10n -
2$.

Set $c_{\text{end}} = 2$ (both end slots non-empty), $E = 0$, $S = 2n$. Concrete
ly:
- **End slots:** $1$ red each (cost $1 + 1 = 2$).
- **Interior slots:** $2n$ slots with $1$ red (cost $3$ each $= 6n$) and $n - 1$
 slots with $2$ reds (cost $4$ each $= 4n - 4$).

Red count: $2 + 2n + 2(n-1) = 4n$ ✓. Blue count: $3n$ ✓.

**Explicit positions.** Arrange the color sequence as:
$$\underbrace{R}_{\text{end}}\; B\; \underbrace{R}_{\text{int}}\; B\; \underbrac
e{R}_{\text{int}}\; B\; \cdots$$
with $2n$ single-red interior slots and $n-1$ double-red interior slots interspe
rsed, ending with $\cdots B\; R$.

Set gaps as follows:
- End slot ($1$ red $\to$ first blue): gap $= 1$.
- Single-red interior ($B \to R \to B$): gaps $1, 2$ (sum $= 3 \geq 3$ ✓).
- Double-red interior ($B \to R \to R \to B$): gaps $1, 2, 1$ (sum $= 4 \geq 3$
✓, red-red $= 2$ ✓).
- Last blue $\to$ end red: gap $= 1$.

**Verification of all constraints:**
- *Blue-blue:* Consecutive blues are separated by either $3$ (single-red interio
r) or $4$ (double-red interior) $\geq 3$ ✓. Non-consecutive blues are even farth
er ✓.
- *Red-red:* Reds in the same double-red slot are $2$ apart ✓. Reds in different
 slots are separated by at least one blue (distance $\geq 1 + 1 = 2$) ✓. End-slo
t reds are $\geq 1$ from the nearest blue and $\geq 2$ from the next red ✓.
- *Red-blue:* Every red-blue gap is $\geq 1$ ✓.

**Total span:**
$$2 \times 1 + 2n \times 3 + (n-1) \times 4 = 2 + 6n + 4n - 4 = 10n - 2.$$

**Conclusion.** The lower bound $b - a \geq 10n - 2$ and the matching constructi
on prove that the smallest possible value is:

$$\boxed{10n - 2}$$
