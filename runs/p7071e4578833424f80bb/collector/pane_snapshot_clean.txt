## Proof

**Yes, such a function exists.** We construct it explicitly using Beatty sequenc
es.

### Setup

Let $\phi = \frac{1+\sqrt{5}}{2}$ (golden ratio), so $\phi^2 = \phi + 1$ and $\f
rac{1}{\phi} + \frac{1}{\phi^2} = 1$.

Define the **lower** and **upper Wythoff sequences**:
$$a_n = \lfloor n\phi \rfloor, \qquad b_n = \lfloor n\phi^2 \rfloor = \lfloor n\
phi \rfloor + n = a_n + n.$$

Let $A = \{a_n : n \geq 1\}$ and $B = \{b_n : n \geq 1\}$.

**Beatty's Theorem:** Since $1/\phi + 1/\phi^2 = 1$ with $\phi, \phi^2$ positive
 irrationals, $A$ and $B$ partition $\mathbb{Z}^+$.

The first few values: $A = \{1, 3, 4, 6, 8, 9, 11, 12, 14, \ldots\}$, $B = \{2,
5, 7, 10, 13, 15, 18, 20, 23, \ldots\}$.

### Definition of $f$

Since $A \sqcup B = \mathbb{Z}^+$, every positive integer is uniquely $a_k$ or $
b_k$. Define:
$$f(a_k) = b_k, \qquad f(b_k) = a_k + b_k.$$

This is well-defined, and $f(n) \in \mathbb{Z}^+$ for all $n$.

### Verification of $f(1) = 2$

$1 = a_1 = \lfloor \phi \rfloor$, so $f(1) = b_1 = \lfloor \phi^2 \rfloor = \lfl
oor 2.618\ldots \rfloor = 2$. ✓

### Key Lemma: $a_{b_k} = a_k + b_k$

**Proof.** Write $k\phi = a_k + \alpha$ where $\alpha = \{k\phi\} \in (0,1)$ (si
nce $\phi$ is irrational). Then $b_k = a_k + k$ and:
$$b_k\phi = (a_k + k)\phi = a_k\phi + k\phi.$$
Since $a_k = k\phi - \alpha$:
$$a_k\phi = (k\phi - \alpha)\phi = k\phi^2 - \alpha\phi = k\phi + k - \alpha\phi
 = a_k + \alpha + k - \alpha\phi = a_k + k + \alpha(1-\phi).$$
Therefore:
$$b_k\phi = \bigl(a_k + k + \alpha(1-\phi)\bigr) + (a_k + \alpha) = a_k + b_k +
\alpha(2 - \phi).$$
Since $\alpha \in (0,1)$ and $2 - \phi = \frac{3-\sqrt{5}}{2} \in (0,1)$, we get
 $\alpha(2-\phi) \in (0,1)$. Hence:
$$\lfloor b_k\phi \rfloor = a_k + b_k,$$
i.e., $a_{b_k} = a_k + b_k$. $\square$

**Corollary:** $a_k + b_k \in A$ (it equals $a_{b_k}$), and $b_{b_k} = a_{b_k} +
 b_k = (a_k + b_k) + b_k = a_k + 2b_k$.

### Verification of $f(f(n)) = f(n) + n$

**Case 1: $n = a_k$.** Then $f(n) = b_k \in B$, so:
$$f(f(n)) = f(b_k) = a_k + b_k = b_k + a_k = f(n) + n. \quad\checkmark$$

**Case 2: $n = b_k$.** Then $f(n) = a_k + b_k = a_{b_k} \in A$ (by the Lemma), s
o:
$$f(f(n)) = f(a_{b_k}) = b_{b_k} = a_k + 2b_k = (a_k + b_k) + b_k = f(n) + n. \q
uad\checkmark$$

### Verification that $f$ is strictly increasing

We check $f(n) < f(n+1)$ for all $n$. Since $A, B$ interleave, there are four ca
ses for the pair $(n, n+1)$:

**Case A→A:** $n = a_k$, $n+1 = a_{k+1}$. Then $f(n) = b_k < b_{k+1} = f(n+1)$ s
ince $b$ is increasing. ✓

**Case B→B:** $n = b_k$, $n+1 = b_{k+1}$. Then $f(n) = a_k + b_k < a_{k+1} + b_{
k+1} = f(n+1)$ since both $a, b$ increase. ✓

**Case A→B:** $n = a_k$, $n+1 = b_j$ (so $b_j = a_k + 1$). We determine $j$: the
 number of elements of $A$ in $\{1,\ldots,a_k\}$ is $k$, so the number of elemen
ts of $B$ in $\{1,\ldots,a_k\}$ is $a_k - k$, giving $j = a_k - k + 1$. Then:
$$a_j = b_j - j = (a_k+1) - (a_k - k + 1) = k,$$
$$f(n+1) = f(b_j) = a_j + b_j = k + (a_k + 1) = a_k + k + 1 = b_k + 1 = f(n) + 1
 > f(n). \quad\checkmark$$

**Case B→A:** $n = b_k$, $n+1 = a_j$ (so $a_j = b_k + 1$). We determine $j$: the
 number of elements of $A$ in $\{1,\ldots,b_k\}$ equals $\lfloor (b_k+1)/\phi \r
floor$. Computing:
$$(b_k+1)/\phi = (a_k + k + 1)/\phi = a_k + \alpha(2-\phi) + 1/\phi,$$
where $\alpha = \{k\phi\} \in (0,1)$. Since $\alpha(2-\phi) + 1/\phi \in (1/\phi
,\, 1) \subset (0,1)$, we get $\lfloor(b_k+1)/\phi\rfloor = a_k$, so $j = a_k +
1$. Then:
$$f(n+1) = f(a_j) = b_j = a_j + j = (b_k + 1) + (a_k + 1) = a_k + b_k + 2 = f(n)
 + 2 > f(n). \quad\checkmark$$

All four cases give $f(n) < f(n+1)$, so $f$ is strictly increasing. ✓

### Conclusion

The function $f$ defined by $f(a_k) = b_k$ and $f(b_k) = a_k + b_k$ (where $a_k
= \lfloor k\phi \rfloor$, $b_k = \lfloor k\phi^2 \rfloor$) satisfies all three c
onditions: $f(1) = 2$, $f(f(n)) = f(n) + n$ for all $n \in \mathbb{Z}^+$, and $f
$ is strictly increasing. Therefore, **such a function exists**.
