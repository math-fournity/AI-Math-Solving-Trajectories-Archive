Yes, such a subset exists. Here is the proof.

## Proof

We construct an explicit example using the **Smith–Volterra–Cantor (SVC) set**,
a "fat Cantor set."

### Construction of the SVC set

Start with the closed interval $C_0 = [0,1]$. At step $n \geq 1$, remove from th
e middle of each component interval of $C_{n-1}$ an open interval of length $2^{
-2n}$. Explicitly:

- $C_0 = [0,1]$, measure $m(C_0)=1$.
- From $C_0$ remove the middle open interval of length $\frac{1}{4}$, leaving $C
_1$ with $m(C_1) = 1 - \frac{1}{4}$.
- From each of the 2 components of $C_1$ remove the middle open interval of leng
th $\frac{1}{16}$, so total removed $\frac{1}{8}$, leaving $m(C_2) = 1 - \frac{1
}{4} - \frac{1}{8}$.
- At step $n$, remove $2^{n-1}$ open intervals each of length $2^{-2n}$, total r
emoved $2^{n-1}\cdot 2^{-2n} = 2^{-n-1}$.

The total measure removed is
$$\sum_{n=1}^{\infty} 2^{-n-1} = \frac{1}{2}.$$

Define $A = \bigcap_{n=0}^{\infty} C_n$. Each $C_n$ is closed (a finite union of
 closed intervals), so $A$ is closed. The measure of $A$ is
$$m(A) = 1 - \frac{1}{2} = \frac{1}{2} > 0.$$

### $A$ has empty interior

At each step we remove an open interval from the middle of every component. The
remaining set $A$ contains no open interval: any open interval $(a,b) \subset [0
,1]$ must contain some removed open interval (since the removed intervals are de
nse in $[0,1]$ — their total complement has measure $1/2$ and they form a dense
open set $U = [0,1]\setminus A$). More carefully: $U = [0,1]\setminus A$ is open
 and dense in $[0,1]$ (at each stage we remove middle portions, so every basic o
pen interval eventually has a piece removed). Hence $A = [0,1]\setminus U$ is cl
osed and nowhere dense, in particular $\operatorname{int}(A) = \emptyset$.

### Conclusion

Since $\operatorname{int}(A) = \emptyset$,
$$A \setminus \operatorname{int}(A) = A \setminus \emptyset = A,$$
and therefore
$$m\!\left(A \setminus \operatorname{int}(A)\right) = m(A) = \frac{1}{2} > 0.$$

Thus there exists a subset $A \subset \mathbb{R}$ (the Smith–Volterra–Cantor set
) such that the Lebesgue measure of $A \setminus \operatorname{int}(A)$ is posit
ive. $\blacksquare$
