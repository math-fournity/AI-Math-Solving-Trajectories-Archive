## Solution

We are given that $t = f(x)$ is defined by $t^5 + t = x$, and we need to evaluat
e $\int_0^2 f(x)\,dx$.

**Step 1: Understand $f$ as an inverse function.**

Let $g(t) = t^5 + t$. Since $g'(t) = 5t^4 + 1 > 0$ for all $t$, the function $g$
 is strictly increasing, hence invertible. The function $f = g^{-1}$ is well-def
ined.

**Step 2: Determine the limits.**

- When $t = 0$: $x = g(0) = 0$, so $f(0) = 0$.
- When $t = 1$: $x = g(1) = 1 + 1 = 2$, so $f(2) = 1$.

**Step 3: Substitution.**

Set $x = g(t) = t^5 + t$, so $dx = (5t^4 + 1)\,dt$. As $x$ ranges from $0$ to $2
$, $t$ ranges from $0$ to $1$. Therefore:

$$\int_0^2 f(x)\,dx = \int_0^1 t\,(5t^4 + 1)\,dt = \int_0^1 (5t^5 + t)\,dt.$$

**Step 4: Evaluate.**

$$\int_0^1 (5t^5 + t)\,dt = \left[\frac{5t^6}{6} + \frac{t^2}{2}\right]_0^1 = \f
rac{5}{6} + \frac{1}{2} = \frac{5}{6} + \frac{3}{6} = \frac{8}{6} = \frac{4}{3}.
$$

Using the identity $\int_a^b f(x)\,dx = bf(b) - af(a) - \int_{f(a)}^{f(b)} g(t)\

Both methods agree.

$$\boxed{\int_0^2 f(x)\,dx = \dfrac{4}{3}}$$
