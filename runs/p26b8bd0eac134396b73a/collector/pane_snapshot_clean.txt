## Solution

We seek positive integers $(x, y)$ satisfying:
$$\frac{1}{\sqrt{x}} - \frac{1}{\sqrt{y}} = \frac{1}{2016}.$$

### Step 1: Reduce to the case where both $x, y$ are perfect squares

Rewrite the equation as $2016(\sqrt{y} - \sqrt{x}) = \sqrt{xy}$. Squaring both s
ides:
$$2016^2\bigl(y - 2\sqrt{xy} + x\bigr) = xy \implies 2016^2(x+y) - xy = 2\cdot 2
016^2\sqrt{xy}.$$

The left-hand side is an integer, so $\sqrt{xy}$ must be rational, hence $xy$ is
 a perfect square. This means $x$ and $y$ share the same squarefree part: $x = s
\,a^2$, $y = s\,b^2$ with $s$ squarefree, $a,b \in \mathbb{Z}_{>0}$.

Substituting: $\frac{b-a}{ab\sqrt{s}} = \frac{1}{2016}$, i.e. $2016(b-a) = ab\sq
rt{s}$.

- If $s \geq 2$ (squarefree): $\sqrt{s}$ is irrational while the left side is ra
tional — **contradiction** (since $ab \geq 1$).
- Therefore $s = 1$, so **both $x$ and $y$ are perfect squares**.

### Step 2: Count solutions with $x = a^2$, $y = b^2$

Set $a = \sqrt{x}$, $b = \sqrt{y}$ (positive integers with $b > a$). The equatio
n becomes:
$$2016(b - a) = ab \implies b(a - 2016) = -2016a \implies b = \frac{2016a}{2016
- a}.$$

We need $a < 2016$ (for $b > 0$) and $b \in \mathbb{Z}_{>0}$. Rewrite:
$$b = \frac{2016^2}{2016 - a} - 2016.$$

Let $d = 2016 - a$, so $1 \leq d \leq 2015$. Then $b = \frac{2016^2}{d} - 2016$,
 which is a positive integer iff $d \mid 2016^2$.

**Check $b > a$:** $b - a = \frac{2016^2}{d} - 2016 - (2016 - d) = \frac{2016^2
- 4032d + d^2}{d} = \frac{(d-2016)^2}{d} > 0$ for all $d \neq 2016$. Since $d \l
eq 2015$, this always holds. ✓

**Check $b > 0$:** $b = \frac{2016^2}{d} - 2016 > 0 \iff d < 2016$, which holds
since $d \leq 2015$. ✓

So the number of solutions equals the number of divisors of $2016^2$ that are st
rictly less than $2016$.

### Step 3: Count divisors of $2016^2$ below $2016$

Factor: $2016 = 2^5 \cdot 3^2 \cdot 7$, so $2016^2 = 2^{10} \cdot 3^4 \cdot 7^2$
.

$$\tau(2016^2) = (10+1)(4+1)(2+1) = 11 \cdot 5 \cdot 3 = 165.$$

Since $2016^2$ is a perfect square, its $165$ divisors pair symmetrically as $(d
,\; 2016^2/d)$ around the middle divisor $d = 2016$. Thus:
- $1$ divisor equals $2016$ (the middle),
- $82$ divisors are $< 2016$,
- $82$ divisors are $> 2016$.

Each of the $82$ divisors $d < 2016$ yields a unique valid pair $(a, b) = (2016
- d,\; 2016^2/d - 2016)$, hence a unique pair $(x, y) = (a^2, b^2)$.

### Answer

$$\boxed{82}$$

### PROOF COMPLETE
