## Solution

The question asks whether $\lambda(F) > 0$ for
$$F = \{(\xi_1,\xi_2,\xi_3,\xi_4)\in\mathbb{R}^4 : \xi_1\xi_4 - \xi_2\xi_3 \in \
mathbb{Q}\}.$$

**Answer: No. In fact $\lambda(F) = 0$.**

### Proof

Define the polynomial map
$$\varphi:\mathbb{R}^4\to\mathbb{R},\qquad \varphi(\xi_1,\xi_2,\xi_3,\xi_4)=\xi_
1\xi_4-\xi_2\xi_3.$$
Then $F = \varphi^{-1}(\mathbb{Q})$. Since $\mathbb{Q}$ is countable,
$$F = \bigcup_{q\in\mathbb{Q}} \varphi^{-1}(q).$$
It suffices to show each fiber $\varphi^{-1}(q)$ has Lebesgue measure zero; a co
untable union of null sets is null.

**Case $q\neq 0$.** The gradient is
$$\nabla\varphi = (\xi_4,\,-\xi_3,\,-\xi_2,\,\xi_1),$$
which vanishes only at the origin, where $\varphi=0$. Hence for $q\neq 0$, $\nab
la\varphi\neq 0$ at every point of $\varphi^{-1}(q)$, so $\varphi$ is a submersi
on on a neighborhood of $\varphi^{-1}(q)$. By the regular level set theorem, $\v
arphi^{-1}(q)$ is a smooth $3$-dimensional submanifold of $\mathbb{R}^4$, which
has $4$-dimensional Lebesgue measure zero.

**Case $q=0$.** Here $\varphi^{-1}(0)$ is the zero set of the nonzero polynomial
 $p(\xi)=\xi_1\xi_4-\xi_2\xi_3$. A standard fact: the zero set of any nonzero re
al polynomial in $\mathbb{R}^n$ has Lebesgue measure zero. For completeness, her
e is the argument by induction on $n$:

Write $p$ as a polynomial in the last variable $x_n$ with coefficients that are
polynomials in $x'=(x_1,\dots,x_{n-1})$:
$$p(x',x_n) = a_k(x')\,x_n^k + \cdots + a_0(x'),\qquad a_k\not\equiv 0.$$
By the induction hypothesis, $Z_k=\{a_k=0\}\subseteq\mathbb{R}^{n-1}$ has $(n-1)
$-dimensional measure zero, hence $Z_k\times\mathbb{R}$ has $n$-dimensional meas
ure zero. On the open set $\{a_k\neq 0\}$, for each fixed $x'$ the polynomial $p
(x',\,\cdot\,)$ is a nonzero univariate polynomial of degree $k$, so it has at m
ost $k$ real roots. By Fubini/Tonelli,
$$\lambda_n\bigl(\{p=0\}\cap (\{a_k\neq 0\}\times\mathbb{R})\bigr) = \int_{\{a_k
\neq 0\}} \lambda_1(\{x_n : p(x',x_n)=0\})\,dx' = 0.$$
Together with $\lambda_n(Z_k\times\mathbb{R})=0$, this gives $\lambda_n(\{p=0\})
=0$.

Applying this with $n=4$ and $p=\xi_1\xi_4-\xi_2\xi_3$ yields $\lambda_4(\varphi
^{-1}(0))=0$.

**Conclusion.** Every fiber $\varphi^{-1}(q)$, $q\in\mathbb{Q}$, has measure zer
o, so
$$\lambda(F) = \lambda\!\left(\bigcup_{q\in\mathbb{Q}}\varphi^{-1}(q)\right) \le
 \sum_{q\in\mathbb{Q}}\lambda(\varphi^{-1}(q)) = 0.$$
Thus $\lambda(F)=0$, which is **not** greater than zero.

The subset $E\subseteq\mathbb{R}^4$ of full measure mentioned in the statement d
oes not enter the definition of $F$; regardless of $E$, the set $F$ defined by t
he rationality of $\xi_1\xi_4-\xi_2\xi_3$ is a countable union of algebraic hype
rsurfaces and therefore has measure zero.
