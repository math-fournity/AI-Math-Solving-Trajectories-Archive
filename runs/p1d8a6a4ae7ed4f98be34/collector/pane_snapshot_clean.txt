## Proof

**Construction.** Fix $r > 0$. Select a maximal $(r/4)$-separated set $\{x_i\}_{
i=1}^{N} \subset K$, i.e., $|x_i - x_j| \ge r/4$ for $i \neq j$, and every point
 of $K$ lies within distance $r/4$ of some $x_i$. Such a set exists and is finit
e by compactness of $K$. Then the balls $\{B(x_i, r/4)\}$ cover $K$, and the bal
ls $\{B(x_i, r/8)\}$ are pairwise disjoint (since $r/8 + r/8 = r/4$).

Let $\psi \in C_c^\infty(\mathbb{R}^n)$ be a fixed non-negative bump function wi
th $\operatorname{supp} \psi \subset B(0,1)$ and $\psi > 0$ on $B(0,1)$; this si
ngle function depends only on $n$. Define
$$\psi_i(x) := \psi\!\Big(\frac{x - x_i}{r/2}\Big), \qquad \Psi(x) := \sum_{i=1}
^{N} \psi_i(x), \qquad \xi_i(x) := \frac{\psi_i(x)}{\Psi(x)}.$$

The sum $\Psi$ is well defined and smooth (locally finite), and we set $\xi_i =
0$ where $\Psi = 0$.

**Lower bound on $\Psi$ over $K$.** For any $x \in K$, by the covering property
there exists $i$ with $x \in B(x_i, r/4)$, so $\left|\frac{x-x_i}{r/2}\right| \l
e \frac{1}{2}$. Since $\psi$ is continuous and strictly positive on the compact
set $\overline{B(0,1/2)}$, there is a constant $c_0 = c_0(n) > 0$ with $\psi \ge
 c_0$ on $\overline{B(0,1/2)}$. Hence $\psi_i(x) \ge c_0$ and
$$\Psi(x) \ge c_0 > 0 \quad \text{on } K.$$

**Property 1 (support size).** Each $\psi_i$ is supported in $B(x_i, r/2)$, a ba
ll of radius $r/2 < r$. Thus $\operatorname{supp} \xi_i \subset B(x_i, r/2) \sub
set B(x_i, r)$, a ball of radius $r$. ✓

**Overlap bound.** We count how many $\psi_i$ are nonzero at a fixed $x$. If $\p
si_i(x) \neq 0$ then $x \in B(x_i, r/2)$, so $B(x_i, r/8) \subset B(x, r/2 + r/8
) = B(x, 5r/8)$. The balls $\{B(x_i, r/8)\}$ are pairwise disjoint and all lie i
nside $B(x, 5r/8)$, so by volume comparison their number is at most
$$\frac{\operatorname{vol}\big(B(x,\,5r/8)\big)}{\operatorname{vol}\big(B(x_i,\,
r/8)\big)} = 5^n.$$
Denote $M_0 := 5^n$; this depends only on $n$.

**Property 3 (bounded overlap).** The number of $i$ with $\xi_i(x) \neq 0$ equal
s the number of $i$ with $\psi_i(x) \neq 0$, which is at most $M_0 = 5^n \le C(n
)$. ✓

**Property 2 (derivative bound).** We have
$$D\xi_i = \frac{D\psi_i\,\Psi - \psi_i\,D\Psi}{\Psi^2}, \qquad\text{so}\qquad |
D\xi_i| \le \frac{|D\psi_i|}{\Psi} + \frac{\psi_i\,|D\Psi|}{\Psi^2}.$$

Bound each term on $K$:
- $|D\psi_i(x)| = \frac{2}{r}\big|D\psi\big(\frac{x-x_i}{r/2}\big)\big| \le \fra
c{2\|\nabla\psi\|_\infty}{r}$.
- $\Psi(x) \ge c_0$.
- $|D\Psi(x)| \le \sum_{j} |D\psi_j(x)| \le M_0 \cdot \frac{2\|\nabla\psi\|_\inf
ty}{r}$ (at most $M_0$ nonzero summands).
- $\psi_i(x) \le \|\psi\|_\infty$ and $\Psi(x) \ge c_0$.

Therefore
$$|D\xi_i(x)| \le \frac{2\|\nabla\psi\|_\infty}{c_0\, r} + \frac{\|\psi\|_\infty

where
$$C = \frac{2\|\nabla\psi\|_\infty}{c_0} + \frac{2\,M_0\,\|\psi\|_\infty\,\|\nab
la\psi\|_\infty}{c_0^2}$$
depends only on $n$ (through the fixed $\psi$, the constant $c_0(n)$, and $M_0 =

**Partition of unity.** By construction $\xi_i \ge 0$ and $\sum_i \xi_i(x) = \fr
ac{\sum_i \psi_i(x)}{\Psi(x)} = 1$ for every $x \in K$ (where $\Psi > 0$). ✓

**Answer to the question.** Yes. There exists an upper bound for the number of o
verlapping balls $M(x, r, n)$ that is independent of both $x$ and $r$, depending
 only on the dimension $n$. Concretely, the construction above gives
$$M(x, r, n) \le 5^n \qquad \text{for all } x \in K,\; r > 0.$$

The key mechanism is the **volume-packing argument**: a maximal $(r/4)$-separate
d set produces disjoint inner balls $B(x_i, r/8)$ that act as "witnesses" — any
point can be covered by only as many outer balls $B(x_i, r/2)$ as can fit (by di
sjoint inner balls) inside a slightly larger ball, and the ratio of volumes is a
 pure dimensional constant. This decouples the overlap count from both the locat
ion $x$ and the scale $r$.
