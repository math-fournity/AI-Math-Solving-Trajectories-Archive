## Solution

**Answer: No, it does not follow that $f(x) = 0$ almost everywhere.**

### Proof

The key observation is that **any countable subset of $[0,1]$ has Lebesgue measu
re zero**, regardless of whether it is dense. Density is a topological property
(about closure), while "almost everywhere" is a measure-theoretic property (abou
t sets of full measure). These are independent notions.

**Counterexample.** Let $A \subset [0,1]$ be any countable dense subset (for ins
tance, $A = \mathbb{Q} \cap [0,1]$). Define

$$f(x) = \begin{cases} 0 & \text{if } x \in A, \\ 1 & \text{if } x \in [0,1] \se
tminus A. \end{cases}$$

**Verification of the hypotheses:**

1. **$f(n) = 0$ for all $n \in A$:** By definition, $f$ vanishes on $A$. ✓

2. **$f$ is measurable:** Since $A$ is countable, it is a Borel set (a countable
 union of singletons, each of which is closed). Therefore $[0,1] \setminus A$ is
 also Borel, and $f = \mathbf{1}_{[0,1]\setminus A}$ is the indicator function o
f a Borel set, hence Lebesgue measurable. ✓

**Why $f \neq 0$ a.e.:**

Since $A$ is countable, we can enumerate it as $A = \{a_1, a_2, a_3, \dots\}$. E
ach singleton $\{a_k\}$ has Lebesgue measure $m(\{a_k\}) = 0$. By countable suba
dditivity,

$$m(A) = m\!\left(\bigcup_{k=1}^{\infty} \{a_k\}\right) \leq \sum_{k=1}^{\infty}
 m(\{a_k\}) = \sum_{k=1}^{\infty} 0 = 0.$$

Therefore $m([0,1] \setminus A) = m([0,1]) - m(A) = 1 - 0 = 1$.

The set where $f(x) \neq 0$ is exactly $[0,1] \setminus A$, which has measure $1
$. Thus $f = 1$ almost everywhere, and in particular $f \neq 0$ almost everywher
e. $\square$

### Remark

The essential point is that **density does not imply positive measure**. A count
able dense set like $\mathbb{Q} \cap [0,1]$ is "everywhere" topologically (its c
losure is all of $[0,1]$) but "nowhere" measure-theoretically (it has measure ze
ro). Since "almost everywhere" disregards sets of measure zero, the values of $f
$ on a countable set—even a dense one—are invisible to almost-everywhere stateme
nts. One would need $f = 0$ on a set of **full measure** (or additional regulari
ty assumptions such as continuity) to conclude $f = 0$ a.e.
