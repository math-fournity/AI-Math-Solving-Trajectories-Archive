## Proof

**Step 1: Show all off-diagonal entries are non-positive.**

For each row $i$, condition (2) gives $a_{ii} + \sum_{j \neq i} a_{ij} = 0$, so
$a_{ii} = -\sum_{j \neq i} a_{ij}$.

Condition (3) gives $a_{ii} = \sum_{j \neq i} |a_{ij}|$.

Equating: $\sum_{j \neq i} |a_{ij}| = -\sum_{j \neq i} a_{ij}$, hence $\sum_{j \
neq i} (|a_{ij}| + a_{ij}) = 0$.

Each summand satisfies $|a_{ij}| + a_{ij} \geq 0$, with equality iff $a_{ij} \le
q 0$. Therefore $a_{ij} \leq 0$ for all $i \neq j$.

**Step 2: Identify $A$ as a graph Laplacian.**

Define $w_{ij} = |a_{ij}| = -a_{ij} \geq 0$ for $i \neq j$, and $w_{ii} = 0$. Si
nce $A$ is symmetric, $w_{ij} = w_{ji}$. Then

$$a_{ii} = \sum_{j \neq i} |a_{ij}| = \sum_{j \neq i} w_{ij}, \qquad a_{ij} = -w
_{ij} \ (i \neq j).$$

This is exactly the Laplacian matrix $L_G$ of the weighted graph $G$ on vertices
 $\{1,\dots,n\}$ with edge weights $w_{ij}$.

**Step 3: The graph is connected.**

Condition (1) states $a_{1i} \neq 0$ for all $i$, so $w_{1i} = |a_{1i}| > 0$ for
 every $i \neq 1$. Vertex $1$ is adjacent to every other vertex, so $G$ is conne
cted.

**Step 4: Determine the eigenspace of the smallest eigenvalue.**

A Laplacian matrix is positive semidefinite (since $x^\top L x = \sum_{i<j} w_{i
j}(x_i - x_j)^2 \geq 0$), so its smallest eigenvalue is $\lambda_{\min} = 0$.

The eigenspace of eigenvalue $0$ is $\ker(L) = \{x : Lx = 0\}$. Using the quadra
tic form,

$$x^\top L x = \sum_{i < j} w_{ij}(x_i - x_j)^2 = 0 \iff x_i = x_j \text{ whenev
er } w_{ij} > 0.$$

Since $G$ is connected, this holds iff $x_1 = x_2 = \cdots = x_n$, i.e., $\ker(L
) = \operatorname{span}(\mathbf{1})$.

Therefore $\dim \ker(A) = 1$.

**Conclusion.** The smallest eigenvalue of $A$ is $0$, and the dimension of its
eigenspace is $\boxed{1}$.
