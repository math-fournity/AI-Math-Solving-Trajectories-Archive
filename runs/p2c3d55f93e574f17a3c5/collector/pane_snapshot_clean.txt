# Spectrum of \(T\) on \(\ell_2(\mathbb{Z})\)

## Setup

Let \(U\) be the **bilateral shift** on \(\ell_2(\mathbb{Z})\),
\[
(Ux)_n = x_{n-1}.
\]
\(U\) is unitary (\(U^* = U^{-1}\), with \((U^*x)_n = x_{n+1}\)).  The given ope
rator satisfies
\[
(Tx)_n = -x_{n-1} + x_n - x_{n+1} = x_n - (Ux)_n - (U^*x)_n,
\]
hence
\[
T = I - U - U^*.
\]
In particular \(T\) is bounded and **self-adjoint**, so \(\sigma(T)\subseteq\mat
hbb{R}\).

## Diagonalization via the Fourier transform

Let \(\mathcal{F}:\ell_2(\mathbb{Z})\to L^2(\mathbb{T})\) be the unitary Fourier
 transform
\[
(\mathcal{F}x)(\theta) = \sum_{n\in\mathbb{Z}} x_n\, e^{-in\theta},\qquad \theta
\in[0,2\pi).
\]
Under \(\mathcal{F}\), the shift \(U\) is conjugated to multiplication by \(e^{i
\theta}\):
\[
\mathcal{F}\,U\,\mathcal{F}^{-1} = M_{e^{i\theta}},\qquad
\mathcal{F}\,U^*\,\mathcal{F}^{-1} = M_{e^{-i\theta}}.
\]
Therefore
\[
\mathcal{F}\,T\,\mathcal{F}^{-1} = M_{m},\qquad
m(\theta) = 1 - e^{i\theta} - e^{-i\theta} = 1 - 2\cos\theta.
\]
So \(T\) is unitarily equivalent to the multiplication operator \(M_m\) on \(L^2
(\mathbb{T})\).

## Spectrum of a multiplication operator

For a multiplication operator \(M_m\) on \(L^2\) with \(m\in C(\mathbb{T})\),
\[
\sigma(M_m) = \operatorname{ess\,ran}(m) = m(\mathbb{T}),
\]
the (essential) range of the symbol.  Indeed:
- If \(\lambda\notin m(\mathbb{T})\), then \(m-\lambda\) is bounded away from \(
0\), so \(M_{m-\lambda}\) is invertible with bounded inverse \(M_{1/(m-\lambda)}
\); hence \(\lambda\notin\sigma(M_m)\).
- If \(\lambda\in m(\mathbb{T})\), then for every \(\varepsilon>0\) the set \(\{
\theta:|m(\theta)-\lambda|<\varepsilon\}\) has positive measure (it contains a n
ontrivial arc), so \(M_{m-\lambda}\) is **not** bounded below; hence \(\lambda\i
n\sigma(M_m)\).

## Computing the range

As \(\theta\) ranges over \([0,2\pi)\), \(\cos\theta\) ranges over \([-1,1]\), s
o
\[
m(\theta) = 1 - 2\cos\theta \in [\,1-2,\;1+2\,] = [-1,\,3].
\]
Thus
\[
\sigma(T) = \sigma(M_m) = m(\mathbb{T}) = [-1,\,3].
\]

## Point spectrum (for completeness)

For \(\lambda\in(-1,3)\), the level set \(\{\theta:m(\theta)=\lambda\}\) is fini
te (hence of measure zero), so \(\ker(M_m-\lambda)=\{0\}\).  At the endpoints \(
\lambda=\pm\) of the range, the level set is a single point (measure zero) as we
ll.  Hence \(T\) has **no eigenvalues**; the entire spectrum \([-1,3]\) is conti
nuous spectrum.

## Conclusion

\[
\boxed{\sigma(T) = [-1,\,3]}.
\]
