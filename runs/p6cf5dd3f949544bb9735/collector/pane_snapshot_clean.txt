## Solution

**Setup.** Let $X_1, X_2, \ldots$ be i.i.d. $\mathrm{Uniform}[0,1]$ and $S_n = X
_1 + \cdots + X_n$. The integral equals
$$I_n = n^2\, E\!\left[\frac{1}{S_n^2}\right].$$

**Finiteness for $n \ge 3$.** Using $\frac{1}{s^2} = \int_0^\infty t\,e^{-st}\,d
t$ and Fubini,
$$I_n = n^2 \int_0^\infty t\,\phi(t)^n\,dt, \qquad \phi(t) := \int_0^1 e^{-tx}\,
dx = \frac{1-e^{-t}}{t}.$$
Near $t=0$: $t\,\phi(t)^n \sim t$ (integrable). For large $t$: $t\,\phi(t)^n \si
m t^{1-n}$ (integrable iff $n\ge 3$). So $I_n<\infty$ for $n\ge 3$.

**Substitution $t = u/n$.**
$$I_n = \int_0^\infty u\,\exp\!\big(n\log\phi(u/n)\big)\,du.$$

**Pointwise limit.** Since $\phi(t) = 1 - \tfrac{t}{2} + \tfrac{t^2}{6} - \cdots
$, we have $\log\phi(t) = -\tfrac{t}{2} + O(t^2)$ as $t\to 0$. Thus for each fix
ed $u>0$,
$$n\log\phi(u/n) \;\longrightarrow\; -\tfrac{u}{2},$$
so the integrand converges pointwise to $u\,e^{-u/2}$.

**Key inequality.** Set $h(t) = \log\phi(t) + \tfrac{t}{2}$. Then $h(0)=h'(0)=0$
, $h''(0)=\tfrac{1}{12}$, so $h(t)=O(t^2)$. Hence there exists $\delta_0>0$ such
 that for all $t\in[0,\delta_0]$:
$$\log\phi(t) \;\le\; -\tfrac{t}{2} + \tfrac{t}{4} \;=\; -\tfrac{t}{4}. \qquad (
\star)$$

**Splitting.** Fix $\delta\in(0,\delta_0]$. Split $I_n = I_n^{(B)} + I_n^{(A)}$
with
$$I_n^{(B)} = n^2\!\int_\delta^\infty t\,\phi(t)^n\,dt, \qquad I_n^{(A)} = n^2\!
\int_0^\delta t\,\phi(t)^n\,dt = \int_0^{n\delta} u\,e^{n\log\phi(u/n)}\,du.$$

**Part B vanishes.** Since $\phi$ is strictly decreasing, for $t\ge\delta$: $\ph
i(t)\le\rho:=\phi(\delta)<1$, and also $\phi(t)\le 1/t$. With $t^*:=1/\rho$,
$$\int_\delta^\infty t\,\phi(t)^n\,dt \le \int_\delta^{t^*}\!t\,\rho^n\,dt + \in
t_{t^*}^\infty\! t^{1-n}\,dt = O(\rho^{n-2}).$$
So $I_n^{(B)} = n^2\cdot O(\rho^{n-2}) \to 0$.

**Part A — split at $u=A$.** Write $I_n^{(A)} = I_n^{(A_1)} + I_n^{(A_2)}$:
$$I_n^{(A_1)} = \int_0^A u\,e^{n\log\phi(u/n)}\,du, \qquad I_n^{(A_2)} = \int_A^
{n\delta} u\,e^{n\log\phi(u/n)}\,du = n^2\!\int_{A/n}^{\delta} t\,\phi(t)^n\,dt.
$$

**Part A₁ via DCT.** For $n \ge A/\delta_0$, we have $u/n \le \delta_0$ on $[0,A
]$, so by $(\star)$:
$$n\log\phi(u/n) \le -u/4 \;\;\Longrightarrow\;\; u\,e^{n\log\phi(u/n)} \le u\,e
^{-u/4},$$
which is integrable on $[0,\infty)$. By dominated convergence, $I_n^{(A_1)} \to
\int_0^A u\,e^{-u/2}\,du$.

**Part A₂ bound.** For $n \ge A/\delta_0$ (so $A/n \le \delta \le \delta_0$), us
ing $(\star)$ for $t\in[A/n,\delta]$:
$$I_n^{(A_2)} \le n^2\!\int_{A/n}^{\infty} t\,e^{-nt/4}\,dt \;\stackrel{s=nt/4}{
=}\; 16\int_{A/4}^{\infty} s\,e^{-s}\,ds = 16\,e^{-A/4}\!\Big(\tfrac{A}{4}+1\Big
).$$
This is independent of $n$ and $\to 0$ as $A\to\infty$.

**Conclusion.**
$$\limsup_{n\to\infty} I_n \;\le\; \int_0^A u\,e^{-u/2}\,du + 16\,e^{-A/4}\!\Big
(\tfrac{A}{4}+1\Big) \;\xrightarrow{A\to\infty}\; \int_0^\infty u\,e^{-u/2}\,du
= 4.$$
$$\liminf_{n\to\infty} I_n \;\ge\; \int_0^A u\,e^{-u/2}\,du \;\xrightarrow{A\to\
infty}\; 4.$$

Therefore $\displaystyle\lim_{n\to\infty} I_n = \int_0^\infty u\,e^{-u/2}\,du =
\frac{1}{(1/2)^2} = 4$.

$$\boxed{4}$$
