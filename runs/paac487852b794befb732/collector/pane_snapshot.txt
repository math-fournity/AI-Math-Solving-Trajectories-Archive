## Proof

Let $S = X + Y$. Since $X, Y$ are independent $\text{Poisson}(2)$, $S \sim \text
{Poisson}(4)$, and $S$ is independent of $Z$ (which is $\text{Poisson}(2)$).

**Key observation.** Given $S = s$, the conditional distribution of $X$ is $\tex
t{Binomial}(s, \tfrac{1}{2})$ (standard Poisson thinning/splitting property for
i.i.d. Poissons). Hence
$$E[X \mid S = s] = \tfrac{s}{2}, \qquad E[Y \mid S = s] = \tfrac{s}{2},$$
so
$$E[X - Y \mid S = s] = 0 \quad \text{for every } s.$$

Moreover, given $S$, the value of $X - Y$ depends only on how $S$ is split betwe
en $X$ and $Y$, which is independent of $Z$. Therefore
$$E[X - Y \mid S, Z] = E[X - Y \mid S] = 0.$$

**Conditioning on $S - Z = n$.** Using the tower property of conditional expecta
tion,
$$E[X - Y \mid S - Z = n] = E\big[\,E[X - Y \mid S, Z] \;\big|\; S - Z = n\,\big
] = E[\,0 \mid S - Z = n\,] = 0.$$

Thus the expected value is $\boxed{0}$, independent of $n$.

### PROOF COMPLETE
