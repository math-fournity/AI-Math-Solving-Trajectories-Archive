## 解答

Let $\alpha = \log_3 100$. Note $3^4 = 81 < 100 < 243 = 3^5$, so $4 < \alpha < 5
$, and in particular $\alpha < 9$.

**定义** $h_n := \log_3 b_n$。由于 $b_n = 100^{b_{n-1}} = 3^{\alpha\, b_{n-1}}$
，我们得到递推关系：
$$h_n = \alpha\, b_{n-1} = \alpha \cdot 3^{h_{n-1}} \quad (n \ge 2), \qquad h_1
= \alpha.$$

---

### 下界：对所有 $n \ge 1$，$b_n > a_{n+1}$

**基础步骤** ($n=1$)：$b_1 = 100 > 27 = 3^3 = a_2$。✓

**归纳步骤**：假设 $b_n > a_{n+1}$。那么
$$b_{n+1} = 100^{b_n} > 100^{a_{n+1}} = 3^{\alpha\, a_{n+1}} > 3^{a_{n+1}} = a_{
n+2},$$
因为 $\alpha > 1$。✓

---

### 上界：对所有 $n \ge 1$，$b_n < a_{n+2}$

我们通过归纳法证明更强的结论：**对所有 $n \ge 1$，$h_n < a_{n+1} - 2$**，这可以
推导出 $b_n = 3^{h_n} < 3^{a_{n+1}} = a_{n+2}$。

**基础步骤** ($n=1$)：$h_1 = \alpha < 5 < 25 = 27 - 2 = a_2 - 2$。✓

**归纳步骤**：假设 $h_n < a_{n+1} - 2$。那么
$$h_{n+1} = \alpha \cdot 3^{h_n} < \alpha \cdot 3^{a_{n+1}-2} = \frac{\alpha}{9}
\, a_{n+2}.$$
我们需要 $\frac{\alpha}{9}\, a_{n+2} \le a_{n+2} - 2$，即 $2 \le a_{n+2}\!\left(
1 - \frac{\alpha}{9}\right)$。由于 $\alpha < 9$，因子 $1 - \alpha/9 > 0$，且对于
 $n \ge 1$，$a_{n+2} \ge a_3 = 3^{27} \approx 7.6 \times 10^{12}$，所以右边远大
于 $2$。✓

因此 $h_n < a_{n+1} - 2 < a_{n+1}$，得证 $b_n = 3^{h_n} < 3^{a_{n+1}} = a_{n+2}$
。

---

### 结论

结合这两个界，我们得到：
$$a_{n+1} < b_n < a_{n+2} \quad \text{对所有 } n \ge 1.$$

令 $n = 98$：$a_{99} < b_{98} < a_{100}$，所以 $b_{98} < a_{100}$。

令 $n = 99$：$a_{100} < b_{99} < a_{101}$，所以 $b_{99} > a_{100}$。

使得 $b_n > a_{100}$ 的最小 $n$ 为 $\boxed{99}$。
