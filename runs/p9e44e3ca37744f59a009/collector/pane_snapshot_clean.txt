## 解答

**建立模型。** 设香蕉总数为 $N$。三只猴子依次从堆中取走 $a, b, c$ 根香蕉（$a + b
 + c = N$，$c = N - a - b$）。

- 猴 1 取 $a$ 根，留 $\tfrac{3}{4}a$，余 $\tfrac{1}{4}a$ 平分给猴 2、猴 3，各得
$\tfrac{a}{8}$。
- 猴 2 取 $b$ 根，留 $\tfrac{1}{4}b$，余 $\tfrac{3}{4}b$ 平分给猴 1、猴 3，各得
$\tfrac{3b}{8}$。
- 猴 3 取 $c$ 根，留 $\tfrac{1}{12}c$，余 $\tfrac{11}{12}c$ 平分给猴 1、猴 2，各
得 $\tfrac{11c}{24}$。

**整除条件。** "每次分配时每只猴子都收到整数根"要求：
- $\tfrac{a}{8}\in\mathbb{Z}$ 且 $\tfrac{3a}{4}\in\mathbb{Z}$ $\Rightarrow$ $8\m
id a$；
- $\tfrac{3b}{8}\in\mathbb{Z}$ 且 $\tfrac{b}{4}\in\mathbb{Z}$ $\Rightarrow$ $8\m
id b$（因 $\gcd(3,8)=1$）；
- $\tfrac{11c}{24}\in\mathbb{Z}$ 且 $\tfrac{c}{12}\in\mathbb{Z}$ $\Rightarrow$ $
24\mid c$（因 $\gcd(11,24)=1$）。

令 $a=8x,\ b=8y,\ c=24z$，其中 $x,y,z$ 为正整数。

**最终持有量。**
$$F_1 = 6x + 3y + 11z, \quad F_2 = x + 2y + 11z, \quad F_3 = x + 3y + 2z.$$

**代入比例 $F_1:F_2:F_3 = 3:2:1$。**

由 $F_2 = 2F_3$：
$$x + 2y + 11z = 2(x + 3y + 2z) \implies x + 4y = 7z. \tag{i}$$

由 $F_1 = 3F_3$：
$$6x + 3y + 11z = 3(x + 3y + 2z) \implies 3x = 6y - 5z. \tag{ii}$$

由 (i) 得 $x = 7z - 4y$，代入 (ii)：
$$3(7z - 4y) = 6y - 5z \implies 21z - 12y = 6y - 5z \implies 26z = 18y \implies
13z = 9y.$$

因 $\gcd(13,9)=1$，故 $9\mid z$。令 $z = 9t$（$t$ 为正整数），则
$$y = 13t, \quad x = 7(9t) - 4(13t) = 11t.$$

**总数。**
$$N = a + b + c = 8x + 8y + 24z = 8(11t) + 8(13t) + 24(9t) = 88t + 104t + 216t =
 408\,t.$$

取 $t=1$ 得最小值 $N = 408$。

**验证 ($t=1$)。** $a=88,\ b=104,\ c=216$。
- 猴 1：留 $66$，给猴 2、3 各 $11$。
- 猴 2：留 $26$，给猴 1、3 各 $39$。
- 猴 3：留 $18$，给猴 1、2 各 $99$。
- $F_1 = 66+39+99 = 204$，$F_2 = 11+26+99 = 136$，$F_3 = 11+39+18 = 68$。
- $204:136:68 = 3:2:1$ ✓，所有分配均为整数 ✓。

$$\boxed{N = 408}$$
