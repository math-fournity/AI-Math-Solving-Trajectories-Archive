## Solution

**Setting up the parameterization.** Let $A$ be the angle opposite side $a$, wit
h $t = \sin A$. The three constraints are:

1. $a + b + c = 4$
2. $a = bc\sin^2 A = bc\,t^2$
3. Positive area (non-degenerate triangle)

The area is $K = \tfrac{1}{2}bc\sin A = \tfrac{1}{2}bc\,t$. Since $a = bc\,t^2$,
 we get $bc = a/t^2$ and $K = a/(2t)$.

**Applying the Law of Cosines.** With $u = b+c = 4-a$ and $v = bc = a/t^2$:

$$a^2 = b^2 + c^2 - 2bc\cos A = u^2 - 2v - 2v\cos A = u^2 - 2v(1+\cos A)$$

Substituting $v = a/t^2 = a/((1-\cos A)(1+\cos A))$ and simplifying:

$$\frac{a}{1-\cos A} = \frac{u^2 - a^2}{2}$$

With $u = 4-a$, we get $u^2 - a^2 = (4-a)^2 - a^2 = 8(2-a)$, so:

$$\cos A = 1 - \frac{2a}{8(2-a)} = \frac{8-5a}{4(2-a)}$$

**Computing $\sin^2 A$:**

$$\sin^2 A = 1 - \cos^2 A = \frac{[4(2-a)]^2 - (8-5a)^2}{[4(2-a)]^2} = \frac{(8-
4a)^2-(8-5a)^2}{[4(2-a)]^2} = \frac{a(16-9a)}{16(2-a)^2}$$

This requires $a \in (0,\, 16/9)$ for $\sin^2 A > 0$.

**The critical reality constraint.** For $b, c$ to be real positive numbers with
 sum $u$ and product $v$, we need $v \le u^2/4$ (AM-GM), i.e.:

$$\frac{a}{t^2} \le \frac{(4-a)^2}{4}$$

Substituting $t^2 = a(16-9a)/[16(2-a)^2]$ and simplifying (dividing by $a > 0$):

$$64(2-a)^2 \le (16-9a)(4-a)^2$$

Expanding both sides:
- LHS: $256 - 256a + 64a^2$
- RHS: $256 - 272a + 88a^2 - 9a^3$

The inequality becomes:

$$0 \le -16a + 24a^2 - 9a^3 = -a(9a^2 - 24a + 16) = -a(3a-4)^2$$

Since $a > 0$ and $(3a-4)^2 \ge 0$, we have $-a(3a-4)^2 \le 0$. The inequality $
0 \le -a(3a-4)^2$ holds **only when $(3a-4)^2 = 0$**, i.e., $a = 4/3$.

**The unique triangle.** At $a = 4/3$:
- $u = 4 - 4/3 = 8/3$, and $v = u^2/4 = 16/9$, so $b = c = 4/3$.
- $\cos A = (8 - 20/3)/(4 \cdot 2/3) = (4/3)/(8/3) = 1/2$, so $A = 60°$.

This is the **equilateral triangle** $a = b = c = 4/3$.

**Verification of all constraints:**
1. $a + b + c = 4/3 + 4/3 + 4/3 = 4$ ✓
2. $bc\sin^2 A = \frac{16}{9} \cdot \frac{3}{4} = \frac{4}{3} = a$ ✓
3. Equilateral triangle has positive area ✓

**Computing the area.** Since there is exactly one valid triangle, $M = m$.

$$K = \frac{\sqrt{3}}{4}\left(\frac{4}{3}\right)^2 = \frac{\sqrt{3}}{4} \cdot \f
rac{16}{9} = \frac{4\sqrt{3}}{9}$$

$$M^2 + m^2 = 2K^2 = 2 \cdot \frac{48}{81} = \frac{96}{81} = \frac{32}{27}$$

Since $\gcd(32, 27) = 1$ (as $32 = 2^5$ and $27 = 3^3$), the fraction is already
 in lowest terms.

$$a + b = 32 + 27 = \boxed{59}$$
