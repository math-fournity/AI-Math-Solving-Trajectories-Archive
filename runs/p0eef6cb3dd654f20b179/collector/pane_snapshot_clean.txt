# Proof

**Claim.** No. There does not exist a set with non-empty interior whose Lebesgue
 measure is 0.

**Proof.** Suppose, for contradiction, that $E \subseteq \mathbb{R}^n$ is a set
with non-empty interior and $m(E) = 0$, where $m$ denotes the Lebesgue measure.

Since $E$ has non-empty interior, there exists a point $x_0 \in \mathbb{R}^n$ an
d a radius $r > 0$ such that the open ball

$$B(x_0, r) = \{x \in \mathbb{R}^n : \|x - x_0\| < r\}$$

is entirely contained in $E$; that is, $B(x_0, r) \subseteq E$.

By the monotonicity of the Lebesgue measure (which holds because Lebesgue measur
e is a positive measure: if $A \subseteq B$, then $m(A) \leq m(B)$), we have

$$m\bigl(B(x_0, r)\bigr) \leq m(E).$$

However, the Lebesgue measure of an open ball of radius $r$ in $\mathbb{R}^n$ is

$$m\bigl(B(x_0, r)\bigr) = \omega_n \, r^n > 0,$$

where $\omega_n = \frac{\pi^{n/2}}{\Gamma(n/2 + 1)}$ is the volume of the unit b
all in $\mathbb{R}^n$, which is a strictly positive constant. Since $r > 0$, we
conclude $m(B(x_0, r)) > 0$.

Combining the two relations:

$$0 < m\bigl(B(x_0, r)\bigr) \leq m(E) = 0,$$

which is a contradiction.

Therefore, no set with non-empty interior can have Lebesgue measure $0$. $\black
square$
