## Asymptotic Form of the Partition Numbers

**Theorem (Hardy–Ramanujan, 1918).** *As $n \to \infty$,*

$$P_n \sim \frac{1}{4n\sqrt{3}} \exp\!\left(\pi\sqrt{\frac{2n}{3}}\right).$$

---

### Proof

**Step 1: Generating function and the Dedekind eta function.**

The generating function for partitions is

$$F(q) = \sum_{n=0}^{\infty} P_n\, q^n = \prod_{m=1}^{\infty} \frac{1}{1-q^m}, \
qquad |q|<1.$$

Set $q = e^{2\pi i \tau}$ with $\text{Im}(\tau)>0$. The Dedekind eta function is

$$\eta(\tau) = e^{\pi i \tau/12}\prod_{m=1}^{\infty}(1-e^{2\pi i m\tau}),$$

so that

$$F(e^{2\pi i\tau}) = \frac{e^{\pi i\tau/12}}{\eta(\tau)}.$$

The key input is the **modular transformation** of $\eta$:

$$\eta\!\left(-\frac{1}{\tau}\right) = \sqrt{-i\tau}\;\eta(\tau),$$

which gives $\eta(\tau) = \eta(-1/\tau)/\sqrt{-i\tau}$ and hence

$$F(e^{2\pi i\tau}) = \frac{\sqrt{-i\tau}\; e^{\pi i\tau/12}}{\eta(-1/\tau)}. \t
ag{1}$$

---

**Step 2: Cauchy integral and choice of contour.**

By Cauchy's formula, with $q = e^{2\pi i\tau}$ and $dq = 2\pi i\, q\, d\tau$:

$$P_n = \int_{-1/2}^{1/2} F\!\left(e^{2\pi i(\sigma+it)}\right) e^{-2\pi i n(\si
gma+it)}\, d\sigma = e^{2\pi nt}\int_{-1/2}^{1/2} F\!\left(e^{2\pi i(\sigma+it)}
\right) e^{-2\pi i n\sigma}\, d\sigma, \tag{2}$$

where $t>0$ is a free parameter (the height of the contour) to be optimized.

---

**Step 3: Asymptotic evaluation of $F$ near the cusp.**

Set $\tau = \sigma + it$ with $t$ small. Then $-1/\tau = (-\sigma + it)/(\sigma^
2+t^2)$, so

$$\text{Im}\!\left(-\frac{1}{\tau}\right) = \frac{t}{\sigma^2+t^2} \gg 1$$

for $|\sigma|\le 1/2$ and $t\to 0^+$. Therefore $|e^{2\pi i k(-1/\tau)}| = e^{-2
\pi k\, t/(\sigma^2+t^2)} \to 0$ exponentially, and

$$\eta(-1/\tau) = e^{\pi i(-1/\tau)/12}\left(1 + O\!\left(e^{-2\pi t/(\sigma^2+t
^2)}\right)\right).$$

Substituting into (1):

$$F(e^{2\pi i\tau}) = \sqrt{-i\tau}\; \exp\!\left(\frac{\pi i}{12}\!\left(\tau +
 \frac{1}{\tau}\right)\right)\left(1 + O\!\left(e^{-2\pi/(\sigma^2+t^2)\cdot t}\
right)\right). \tag{3}$$

Computing the real and imaginary parts of $\frac{\pi i}{12}(\tau + 1/\tau)$ with
 $\tau = \sigma+it$:

$$\frac{\pi i}{12}\!\left(\tau+\frac{1}{\tau}\right) = \underbrace{\frac{\pi t}{
12}\!\left(\frac{1}{\sigma^2+t^2}-1\right)}_{\text{real part } R(\sigma,t)} \;+\
; i\underbrace{\frac{\pi\sigma}{12}\!\left(1+\frac{1}{\sigma^2+t^2}\right)}_{\te
xt{imaginary part } I(\sigma,t)}.$$

---

**Step 4: Saddle point in $t$.**

The real part of the full exponent in (2) at $\sigma=0$ is

$$\Phi(t) := 2\pi n t - \frac{\pi t}{12} + \frac{\pi}{12t}.$$

Setting $\Phi'(t) = 2\pi n - \frac{\pi}{12} - \frac{\pi}{12t^2} = 0$ yields

$$\frac{1}{t^2} = 24n - 1 \quad\Longrightarrow\quad t_* = \frac{1}{\sqrt{24n-1}}
.$$

At the saddle point:

$$\Phi(t_*) = \frac{\pi\sqrt{24n-1}}{6},$$

since the two terms $\frac{\pi}{12t_*} = \frac{\pi\sqrt{24n-1}}{12}$ and $2\pi n
 t_* - \frac{\pi t_*}{12} = \frac{\pi(24n-1)}{12\sqrt{24n-1}} = \frac{\pi\sqrt{2
4n-1}}{12}$ are equal.

---

**Step 5: Gaussian integral in $\sigma$.**

Expand the real part $R(\sigma, t_*)$ around $\sigma = 0$:

$$\frac{t_*}{\sigma^2+t_*^2} = \frac{1}{t_*} - \frac{\sigma^2}{t_*^3} + O(\sigma
^4/t_*^5),$$

so

$$R(\sigma,t_*) = \frac{\pi}{12t_*} - \frac{\pi t_*}{12} - \frac{\pi\sigma^2}{12
t_*^3} + O(\sigma^4).$$

The imaginary part $I(\sigma,t_*) - 2\pi n\sigma$ has its linear coefficient:

$$\frac{\pi}{12}\!\left(1+\frac{1}{t_*^2}\right) - 2\pi n = \frac{\pi}{12}(1 + 2
4n-1) - 2\pi n = 0,$$

so the linear phase vanishes at the saddle point (as expected). The integrand is
 therefore a Gaussian in $\sigma$:

$$\int_{-1/2}^{1/2} e^{-\pi\sigma^2/(12t_*^3)}\, d\sigma \;\sim\; \int_{-\infty}
^{\infty} e^{-\pi\sigma^2/(12t_*^3)}\, d\sigma = \sqrt{12\, t_*^3}\,.$$

(The extension to $\mathbb{R}$ is justified since the tails are exponentially sm
all: $R$ decreases as $|\sigma|$ grows.)

---

**Step 6: Assembling the pieces.**

The prefactor $\sqrt{-i\tau}\big|_{\sigma=0} = \sqrt{t_*}$. Combining:

$$P_n \sim e^{\Phi(t_*)}\cdot \sqrt{t_*}\cdot\sqrt{12\, t_*^3} = \frac{\pi\sqrt{
24n-1}}{6}\text{ (exponential)} \;\times\; \sqrt{12}\, t_*^2.$$

That is,

$$P_n \sim \sqrt{12}\, t_*^2\, e^{\pi\sqrt{24n-1}/6} = \frac{\sqrt{12}}{24n-1}\,
 e^{\pi\sqrt{24n-1}/6}. \tag{4}$$

---

**Step 7: Leading asymptotics.**

For $n\to\infty$, $24n-1 \sim 24n$ and $\sqrt{24n-1}\sim\sqrt{24n}$, so

$$\frac{\sqrt{12}}{24n} = \frac{2\sqrt{3}}{24n} = \frac{\sqrt{3}}{12n} = \frac{1
}{4n\sqrt{3}}, \qquad \frac{\pi\sqrt{24n}}{6} = \frac{\pi\cdot 2\sqrt{6n}}{6} =
\pi\sqrt{\frac{2n}{3}}.$$

Therefore

$$\boxed{P_n \sim \frac{1}{4n\sqrt{3}}\,\exp\!\left(\pi\sqrt{\frac{2n}{3}}\right
) \quad\text{as } n\to\infty.}$$

---

**Remark on error terms.** The approximations made are: (i) replacing $\eta(-1/\
tau)$ by its leading exponential, with relative error $O(e^{-2\pi/t_*}) = O(e^{-
2\pi\sqrt{24n}})$, which is super-exponentially small; (ii) the Gaussian approxi
mation in $\sigma$, with relative error $O(t_*^2) = O(1/n)$ from higher-order te
rms. Thus (4) is in fact a sharper form, and the relative error in the final asy
mptotic is $O(n^{-1})$. (Hardy and Ramanujan, and later Rademacher, showed that
summing over all cusps $h/k$ yields a convergent series giving $P_n$ exactly.)
