## Solution

We evaluate
$$L = \lim_{n\to\infty} n^2 \int_{1/(n+1)}^{1/n} \frac{\arctan(nx)}{\arcsin(nx)}
\,dx.$$

**Substitution.** Let $t = nx$, so $x = t/n$, $dx = dt/n$. The limits become $t
= n/(n+1)$ and $t = 1$:
$$L = \lim_{n\to\infty} n \int_{n/(n+1)}^{1} \frac{\arctan t}{\arcsin t}\,dt.$$

The interval $[n/(n+1),\, 1]$ has length $1/(n+1) \to 0$, and $t \to 1$ througho
ut. Set $t = 1 - u$, $u \in [0, 1/(n+1)]$:
$$L = \lim_{n\to\infty} n \int_0^{1/(n+1)} \frac{\arctan(1-u)}{\arcsin(1-u)}\,du
.$$

**Local expansion near $u = 0$.** Set $s = \sqrt{2u}$ (so $u = s^2/2$, $du = s\,
ds$), and the upper limit becomes $s = \sqrt{2/(n+1)}$.

- $\arcsin(1-u) = \frac{\pi}{2} - \arccos(1-u)$. Since $\arccos(1-u) = \sqrt{2u}
\,(1 + u/12 + \cdots) = s\,(1 + s^2/24 + \cdots)$:
$$\arcsin(1-u) = \frac{\pi}{2} - s - \frac{s^3}{24} - \cdots.$$

- $\arctan(1-u) = \frac{\pi}{4} - \frac{u}{2} + O(u^2) = \frac{\pi}{4} - \frac{s
^2}{4} + O(s^4)$ (using $\arctan'(1) = 1/2$).

**Ratio expansion.** With $a = \pi/2$, $b = \pi/4$:
$$\frac{\arctan(1-u)}{\arcsin(1-u)} = \frac{b - s^2/4 + O(s^4)}{a - s + O(s^3)}
= \frac{b}{a}\cdot\frac{1 - s^2/(4b) + O(s^4)}{1 - s/a + O(s^3)}.$$

Since $b/a = 1/2$, $1/a = 2/\pi$, $1/(4b) = 1/\pi$:
$$= \frac{1}{2}\left(1 - \frac{s^2}{\pi} + O(s^4)\right)\left(1 + \frac{2s}{\pi}
 + \frac{4s^2}{\pi^2} + O(s^3)\right) = \frac{1}{2} + \frac{s}{\pi} + O(s^2).$$

**Integrate.** Including the Jacobian $s\,ds$:
$$n \int_0^{\sqrt{2/(n+1)}} \left(\frac{1}{2} + \frac{s}{\pi} + O(s^2)\right) s\
,ds = n\left[\frac{s^2}{4} + \frac{s^3}{3\pi} + O(s^4)\right]_0^{\sqrt{2/(n+1)}}
.$$

Evaluating at the upper limit $s_0 = \sqrt{2/(n+1)}$:
$$= n\left[\frac{1}{4}\cdot\frac{2}{n+1} + \frac{1}{3\pi}\cdot\frac{2^{3/2}}{(n+
1)^{3/2}} + O\!\left(\frac{1}{(n+1)^2}\right)\right]$$
$$= \frac{n}{2(n+1)} + O\!\left(\frac{1}{\sqrt{n}}\right) + O\!\left(\frac{1}{n}
\right).$$

**Take the limit.** The correction terms vanish, and
$$L = \lim_{n\to\infty} \frac{n}{2(n+1)} = \frac{1}{2}.$$

**Sanity check.** The integrand $\arctan(nx)/\arcsin(nx) \to \arctan(1)/\arcsin(
1) = (\pi/4)/(\pi/2) = 1/2$ uniformly on the shrinking interval of length $1/(n(
n+1))$, giving $n^2 \cdot \frac{1}{n(n+1)} \cdot \frac{1}{2} = \frac{n}{2(n+1)}
\to \frac{1}{2}$. ✓

$$\boxed{L = \dfrac{1}{2}}$$
