## Solution

Define the auxiliary polynomial
$$Q(x) = x\,W(x) - 1.$$

Since $W$ has degree $2015$, the product $x\,W(x)$ has degree $2016$, so $Q$ is
a polynomial of degree $2016$.

**Step 1: Identify the roots of $Q$.**

For each $n \in \{1,2,\dots,2016\}$,
$$Q(n) = n\,W(n) - 1 = n\cdot\frac{1}{n} - 1 = 0.$$

So $Q$ has $2016$ distinct roots $1,2,\dots,2016$. Since $\deg Q = 2016$, we can
 write
$$Q(x) = c\prod_{n=1}^{2016}(x-n)$$
for some constant $c$.

**Step 2: Determine $c$ by evaluating at $x=0$.**

$$Q(0) = 0\cdot W(0) - 1 = -1.$$

On the other hand,
$$Q(0) = c\prod_{n=1}^{2016}(0-n) = c\,(-1)(-2)\cdots(-2016) = c\,(-1)^{2016}\cd
ot 2016! = c\cdot 2016!.$$

Therefore
$$c\cdot 2016! = -1 \implies c = -\frac{1}{2016!}.$$

**Step 3: Evaluate $W(2017)$.**

$$Q(2017) = 2017\,W(2017) - 1.$$

Using the factored form,
$$Q(2017) = c\prod_{n=1}^{2016}(2017-n) = c\,(2016)(2015)\cdots(1) = c\cdot 2016
!.$$

Substituting $c = -\dfrac{1}{2016!}$:
$$Q(2017) = -\frac{1}{2016!}\cdot 2016! = -1.$$

Hence
$$2017\,W(2017) - 1 = -1 \implies 2017\,W(2017) = 0 \implies W(2017) = 0.$$

$$\boxed{W(2017) = 0}$$

### PROOF COMPLETE
