# Problem

A galactic data network is composed of $M=10$ regional server clusters containing a total of $N=100$ individual server nodes. High-speed fiber-optic cables provide bidirectional communication between certain nodes. The network architecture is governed by the following protocols:

1. Every cluster must contain at least three nodes.
2. Within any single cluster, each node must be directly connected to at least half of the other nodes belonging to that same cluster.
3. Every node in the network is connected to exactly one node located in a different cluster.
4. Between any two distinct clusters, there can be at most two direct inter-cluster cable connections.
5. If the combined total of nodes in any two clusters is less than $2M$, there must be at least one cable connecting a node in the first cluster to a node in the second.

A "data loop" is a path of cables that starts and ends at the same node without traversing any cable or node more than once. What is the minimum length (number of cables) of the longest data loop that is guaranteed to exist within this network?
