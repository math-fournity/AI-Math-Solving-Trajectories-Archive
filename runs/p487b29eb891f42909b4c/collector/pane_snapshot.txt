Looking at this problem, I need to find when four distinct points on $y = H(x) =
 2x^3 - 2x$ form a rectangle, with $a > 0$.

## Setting Up the Rectangle Condition

**Key observation:** $H$ is odd ($H(-x) = -H(x)$), so the curve is symmetric abo
ut the origin.

**Diagonal analysis.** Four points form a rectangle iff their diagonals bisect e
ach other and are equal. I'll show the bisecting condition forces origin-symmetr
y.

Suppose diagonals pair $\{a,c\}$ and $\{b,d\}$. Bisecting requires:
$$a+c = b+d = s, \quad H(a)+H(c) = H(b)+H(d)$$

Computing: $H(a)+H(c) = 2(a+c)(a^2-ac+c^2) - 2(a+c) = 2s(s^2 - 3ac) - 2s$.

Setting equal for both pairs gives $s \cdot ac = s \cdot bd$. If $s \neq 0$, the
n $ac = bd$, which combined with $a+c=b+d$ forces $\{a,c\}=\{b,d\}$ (same quadra
tic roots) — contradicting distinctness. So **$s=0$**: $c=-a$, $d=-b$.

All three diagonal pairings yield the same conclusion. The rectangle must be **o
rigin-symmetric**: points $(a, H(a))$, $(-a,-H(a))$, $(b, H(b))$, $(-b,-H(b))$.

## Equal Diagonal Condition

Both diagonals pass through the origin. Equal lengths require:
$$a^2 + H(a)^2 = b^2 + H(b)^2$$

Define $f(x) = x^2 + H(x)^2 = x^2 + 4x^2(x^2-1)^2 = x^2[1+4(x^2-1)^2]$.

Setting $u = x^2 \geq 0$: $g(u) = 4u^3 - 8u^2 + 5u$.

We need $g(u_1) = g(u_2)$ with $u_1 = a^2 \neq u_2 = b^2$, both $\geq 0$.

## Analyzing $g(u)$ on $[0, \infty)$

$$g'(u) = 12u^2 - 16u + 5 = 0 \implies u = \tfrac{1}{2}, \quad u = \tfrac{5}{6}$
$

| $u$ | $g(u)$ | Type |
|-----|---------|------|
| $0$ | $0$ | endpoint |
| $1/2$ | $1$ | local max |
| $5/6$ | $25/27$ | local min |
| $\to\infty$ | $\to\infty$ | |

For $g(u_1)=g(u_2)$ with $u_1\neq u_2$: a horizontal line $y=k$ must hit $g$ at
$\geq 2$ points.

- $k \in (0, 25/27)$: only 1 intersection (in $(0,1/2)$) — **no pair exists** ✗
- $k = 25/27$: 2 intersections (one in $(0,1/2)$, one at $5/6$) ✓
- $k \in (25/27, 1)$: 3 intersections ✓
- $k = 1$: 2 intersections ($u=1/2$ and $u=1$) ✓
- $k > 1$: only 1 intersection ✗

**Valid range:** $25/27 \leq g(a^2) \leq 1$.

## Solving the Bounds

**Upper bound** $g(u) \leq 1$:
$$4u^3 - 8u^2 + 5u - 1 = 4(u-\tfrac{1}{2})^2(u-1) \leq 0 \implies u \leq 1 \impl
ies a \leq 1$$

**Lower bound** $g(u) \geq 25/27$:
$$108u^3 - 216u^2 + 135u - 25 = 108(u-\tfrac{5}{6})^2(u-\tfrac{1}{3}) \geq 0 \im
plies u \geq \tfrac{1}{3} \implies a \geq \tfrac{1}{\sqrt{3}}$$

## Verifying Endpoints

- **$a = 1/\sqrt{3}$** ($u=1/3$): $g(1/3) = 25/27$, partner $u_2 = 5/6$, giving
$b = \sqrt{5/6} \neq a$. ✓
- **$a = 1$** ($u=1$): $g(1) = 1$, partner $u_2 = 1/2$, giving $b = 1/\sqrt{2} \
neq a$. ✓

Both endpoints yield valid rectangles with four distinct points, confirming the
closed interval.

## Result

$$3L^2 + R^2 = 3 \cdot \frac{1}{3} + 1 = 1 + 1 = \boxed{2}$$
