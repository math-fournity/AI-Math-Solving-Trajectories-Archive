## Solution

**Answer:** The maximum number of super squares is $n(n - 2004)$.

---

### Setup

Let $k = 2004$. Since all numbers $1, 2, \ldots, n^2$ are distinct, in each row
there are exactly $k$ squares whose numbers are the $k$ smallest in that row, an
d similarly for each column.

Define:
- $A$ = set of squares that are among the $k$ smallest in their row. Then $|A| =
 nk$ (exactly $k$ per row, $n$ rows).
- $B$ = set of squares that are among the $k$ smallest in their column. Then $|B
| = nk$ (exactly $k$ per column, $n$ columns).

A square is **not** super if and only if it is among the $k$ smallest in its row
 **or** among the $k$ smallest in its column, i.e., it belongs to $A \cup B$.

Therefore:
$$\#\text{super squares} = n^2 - |A \cup B| = n^2 - |A| - |B| + |A \cap B| = n^2
 - 2nk + |A \cap B|.$$

### Upper Bound

Since $|A \cap B| \leq |A| = nk$, we get:
$$\#\text{super squares} \leq n^2 - 2nk + nk = n^2 - nk = n(n - k) = n(n - 2004)
.$$

### Construction Achieving the Bound

We show the bound is achievable. Since $n > 2004 = k$, we have $k < n$, so a $k$
-regular bipartite graph on $n + n$ vertices exists. Concretely, define:
$$A = \{(i, j) : (j - i) \bmod n \in \{0, 1, \ldots, k-1\}\}.$$
This set has exactly $k$ cells in each row and exactly $k$ cells in each column,
 with $|A| = nk$.

**Filling rule:** Place the numbers $1, 2, \ldots, nk$ into the cells of $A$ (in
 any order), and place the numbers $nk+1, nk+2, \ldots, n^2$ into the remaining
cells (in any order).

**Verification:**
- **Rows:** In each row, the $k$ cells belonging to $A$ carry numbers $\leq nk$,
 while the $n - k$ cells outside $A$ carry numbers $> nk$. Hence the $k$ smalles
t numbers in each row are exactly the $A$-cells of that row. So the set of "row-
$k$-smallest" squares is exactly $A$.
- **Columns:** By the identical argument (each column has exactly $k$ cells of $
A$, all with values $\leq nk$), the set of "column-$k$-smallest" squares is exac
tly $A$ as well.

Therefore $A = B$, giving $|A \cap B| = |A| = nk$, and:
$$\#\text{super squares} = n^2 - 2nk + nk = n(n - 2004).$$

Every cell outside $A$ has a number $> nk$, so it is larger than all $k$ cells o
f $A$ in its row (which are $\leq nk$) and all $k$ cells of $A$ in its column —
hence it is greater than at least $k = 2004$ other squares in its row and at lea
st $2004$ in its column, making it super. There are $n^2 - nk = n(n-2004)$ such
cells.

### Conclusion

The maximum number of super squares is $\boxed{n(n-2004)}$.
