## Proof

$$G = \begin{pmatrix} 1 & 0 & 1 & 1 & 0 & 0 \\ 0 & 1 & 1 & 0 & 1 & 1 \end{pmatri

**Codewords and minimum distance.** The four codewords are:

| Codeword | Weight |
|---|---|
| $000000$ | $0$ |
| $101100$ | $3$ |
| $011011$ | $4$ |
| $110111$ | $5$ |

The minimum distance is $d = 3$, so $\left\lfloor\frac{d-1}{2}\right\rfloor = 1$

**A coset with a unique leader of weight 2.** Take the vector $v = 110000$, whic

$$v + C = \{v + c : c \in C\} = \{110000,\; 011100,\; 101011,\; 000111\}.$$

The weights of these four coset elements are:

| Coset element | Weight |
|---|---|
| $110000$ | $2$ |
| $011100$ | $3$ |
| $101011$ | $4$ |
| $000111$ | $3$ |

The minimum weight in this coset is $2$, achieved **uniquely** by $v = 110000$.
Therefore $v$ is a **unique coset leader** of weight $2$.

**Conclusion.** We have exhibited a linear code $C$ with minimum distance $d = 3
$ and a vector $v$ of weight $2 > \left\lfloor\frac{d-1}{2}\right\rfloor = 1$ th
at is a unique coset leader. Hence such a code exists. $\blacksquare$
