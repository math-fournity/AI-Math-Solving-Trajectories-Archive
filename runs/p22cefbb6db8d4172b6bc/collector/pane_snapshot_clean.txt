## Proof

**Claim:** Yes, there exists a measure-preserving, non-trivial, ergodic map $T:\
mathbb{R}\to\mathbb{R}$ with respect to the Gaussian measure $\mu$.

### Step 1: Measure-space isomorphism

The Gaussian measure $\mu$ on $(\mathbb{R},\mathcal{B}(\mathbb{R}))$ is a non-at
omic probability measure on a standard Borel space. The Lebesgue measure $\lambd
a$ on $([0,1],\mathcal{B}([0,1]))$ is likewise a non-atomic probability measure
on a standard Borel space.

By the **isomorphism theorem for standard measure spaces** (von Neumann), any tw
o non-atomic standard probability spaces are isomorphic modulo null sets. Concre
tely, there exists a bimeasurable bijection $\varphi:\mathbb{R}\to[0,1]$ (define
d up to sets of measure zero) such that
$$\lambda(\varphi(B)) = \mu(B) \quad\text{for every Borel set } B\subseteq\mathb
b{R},$$
and likewise $\mu(\varphi^{-1}(A))=\lambda(A)$ for every Borel $A\subseteq[0,1]$
.

### Step 2: An ergodic transformation on $([0,1],\lambda)$

Consider the **doubling map** $S:[0,1)\to[0,1)$ defined by
$$S(x) = 2x \pmod{1}.$$

**$S$ preserves Lebesgue measure:** For any Borel $A\subseteq[0,1)$, $S^{-1}(A)
= \frac{A}{2}\cup\frac{A+1}{2}$, so $\lambda(S^{-1}(A))=\frac{1}{2}\lambda(A)+\f
rac{1}{2}\lambda(A)=\lambda(A)$.

**$S$ is ergodic:** Suppose $f\in L^2([0,1),\lambda)$ satisfies $f\circ S = f$ a
.e. Expand $f$ in the Fourier basis: $f(x)=\sum_{n\in\mathbb{Z}} a_n e^{2\pi i n
 x}$. Then
$$f(S(x)) = \sum_{n\in\mathbb{Z}} a_n e^{2\pi i n \cdot 2x} = \sum_{n\in\mathbb{
Z}} a_n e^{2\pi i (2n) x}.$$
The equality $f\circ S = f$ gives, by uniqueness of Fourier coefficients, $a_n =
 a_{2n}$ for all $n\in\mathbb{Z}$. In particular, for odd $n$, $a_n = a_{2n}$ wh
ere $2n$ is even; and iterating, $a_n = a_{2^k n}$ for all $k\geq 0$. Since $f\i
n L^2$, we have $\sum|a_n|^2<\infty$, so $a_{2^k n}\to 0$ as $k\to\infty$, hence
 $a_n=0$ for every $n\neq 0$. Thus $f$ is constant a.e., proving ergodicity.

### Step 3: Conjugation

Define
$$T = \varphi^{-1}\circ S\circ\varphi : \mathbb{R}\to\mathbb{R}.$$

**$T$ is measure-preserving:** For any Borel $B\subseteq\mathbb{R}$,
$$\mu(T^{-1}(B)) = \mu(\varphi^{-1}(S^{-1}(\varphi(B)))) = \lambda(S^{-1}(\varph
i(B))) = \lambda(\varphi(B)) = \mu(B).$$

**$T$ is ergodic:** Let $B\subseteq\mathbb{R}$ be Borel with $T^{-1}(B)=B$ (mod
$\mu$-null sets). Set $A=\varphi(B)\subseteq[0,1]$. Then
$$S^{-1}(A) = S^{-1}(\varphi(B)) = \varphi(T^{-1}(B)) = \varphi(B) = A \pmod{\la
mbda\text{-null sets}}.$$
Since $S$ is ergodic, $\lambda(A)\in\{0,1\}$, hence $\mu(B)=\lambda(A)\in\{0,1\}
$.

**$T$ is non-trivial:** The doubling map $S$ is not the identity (e.g., $S(1/3)=
2/3\neq 1/3$), so $T=\varphi^{-1}\circ S\circ\varphi$ is not the identity either
.

### Conclusion

There exists a measure-preserving, non-trivial, ergodic transformation $T:\mathb
b{R}\to\mathbb{R}$ with respect to the Gaussian measure $\mu$. For every Borel s
et $B$ with $T^{-1}(B)=B$, we have $\mu(B)\in\{0,1\}$.
