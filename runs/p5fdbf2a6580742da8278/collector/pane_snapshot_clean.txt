## Proof

**Claim:** $N = \sum_{n=0}^{\infty} b^{-n!}$ is a Liouville number for every int
eger $b \geq 2$.

Recall that a real number $\alpha$ is a **Liouville number** if (i) $\alpha$ is
irrational, and (ii) for every positive integer $m$, there exist integers $p, q$
 with $q > 1$ such that $0 < |\alpha - p/q| < 1/q^m$.

---

### Step 1: $N$ is irrational.

Write $N$ in base $b$. The nonzero digit positions are $n!$ for $n = 0, 1, 2, 3,
 \ldots$, where $0! = 1! = 1$, so position $1$ receives a contribution of $2$ (f
rom the $n=0$ and $n=1$ terms), and positions $2, 6, 24, 120, \ldots$ each recei
ve a contribution of $1$.

- **If $b \geq 3$:** the digit $2$ at position $1$ is a valid base-$b$ digit, so
 the base-$b$ expansion of $N$ has nonzero digits exactly at positions $\{1, 2,
6, 24, 120, \ldots\} = \{n! : n \geq 0\}$.
- **If $b = 2$:** the contribution $2 \cdot 2^{-1} = 1$ carries to the units pla
ce, giving $N = 1 + 2^{-2} + 2^{-6} + 2^{-24} + \cdots$, whose base-$2$ expansio
n has nonzero digits at positions $\{2, 6, 24, 120, \ldots\} = \{n! : n \geq 2\}
$.

In both cases, the gaps between consecutive nonzero digit positions are $(n+1)!
- n! = n \cdot n!$, which grow without bound. A rational number has an eventuall
y periodic base-$b$ expansion, which necessarily has bounded gaps between nonzer
o digits. Since the gaps here are unbounded, the expansion is not eventually per
iodic, so **$N$ is irrational**.

---

### Step 2: $N$ satisfies the Liouville approximation property.

For each integer $k \geq 1$, define the partial sum

$$N_k = \sum_{n=0}^{k} b^{-n!}.$$

Since every exponent $n!$ for $n \leq k$ satisfies $n! \leq k!$, all terms share
 the common denominator $b^{k!}$. Thus $N_k = p_k / q_k$ where $q_k = b^{k!}$ an
d $p_k$ is a positive integer. Note $q_k = b^{k!} \geq 2 > 1$.

The tail (remainder) is

$$R_k = N - N_k = \sum_{n=k+1}^{\infty} b^{-n!}.$$

**Lower bound:** $R_k > b^{-(k+1)!} > 0$, so $N \neq N_k$ and the approximation
is nontrivial.

**Upper bound:** For $n \geq k+1$, we have $(n+1)! \geq 2 \cdot n!$ (since $n \g
eq 2$), so the terms decrease super-exponentially. Bounding the geometric tail:

$$R_k = b^{-(k+1)!}\left(1 + b^{-((k+2)!-(k+1)!)} + \cdots\right) < b^{-(k+1)!}
\cdot \frac{1}{1 - b^{-1}} \leq 2\, b^{-(k+1)!},$$

since $b \geq 2$ gives $1/(1-b^{-1}) \leq 2$.

Therefore:

$$0 < \left|N - \frac{p_k}{q_k}\right| < \frac{2}{b^{(k+1)!}}.$$

---

### Step 3: Verifying the Liouville inequality.

Given any positive integer $m$, choose $k \geq \max(m+1,\, 1)$. Then:

$$(k+1)! = (k+1)\cdot k! \geq (m+2)\cdot k!.$$

Hence

$$b^{(k+1)!} \geq b^{(m+2)\,k!} = b^{2\,k!} \cdot b^{m\,k!} \geq 4 \cdot b^{m\,k
!},$$

using $b \geq 2$ and $k! \geq 1$. Therefore:

$$\frac{2}{b^{(k+1)!}} \leq \frac{2}{4 \cdot b^{m\,k!}} = \frac{1}{2\, b^{m\,k!}
} < \frac{1}{b^{m\,k!}} = \frac{1}{(b^{k!})^m} = \frac{1}{q_k^m}.$$

Combining:

$$0 < \left|N - \frac{p_k}{q_k}\right| < \frac{1}{q_k^m}, \qquad q_k = b^{k!} >
1.$$

This holds for every positive integer $m$ (by choosing $k$ sufficiently large),
confirming the Liouville approximation property.

---

### Conclusion

$N$ is irrational (Step 1) and satisfies the Liouville approximation property fo
r every $m$ (Steps 2–3). Therefore, **$N = \sum_{n=0}^{\infty} b^{-n!}$ is a Lio
uville number** for every integer $b \geq 2$.
