# Problem

In a secure digital archive, a unique identification code $N$ is defined as the smallest possible positive integer that satisfies two security protocols:
1. The sum of all individual digits making up the code must be exactly 2011.
2. The product of all individual digits making up the code must result in a value that is an integer power of 6 (i.e., $6^k$ for some non-negative integer $k$).

To analyze the composition of this code, let $n_d$ represent the frequency of each specific digit $d$ (where $d$ ranges from 1 to 9) appearing in the sequence of $N$.

Calculate the total weighted complexity of the code, defined by the sum of each digit multiplied by the square of its frequency:
$$\sum_{d=1}^{9} d \cdot n_d^2$$
