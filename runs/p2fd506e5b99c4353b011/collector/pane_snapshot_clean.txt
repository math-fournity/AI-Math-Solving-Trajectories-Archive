## Solution

**Computing $d(t)$:** The distance from the origin to the line $Ax + By = 1$ is
$\frac{1}{\sqrt{A^2+B^2}}$. With $A = ae^t$, $B = be^{-t}$:

$$d(t) = \frac{1}{\sqrt{a^2 e^{2t} + b^2 e^{-2t}}}, \qquad \frac{1}{d(t)^2} = a^
2 e^{2t} + b^2 e^{-2t}.$$

**Evaluating the integral:**

$$I = \int_0^1 \left(a^2 e^{2t} + b^2 e^{-2t}\right)dt = \frac{a^2}{2}(e^2-1) +
\frac{b^2}{2}(1-e^{-2}).$$

**Optimizing under $ab=1$:** Set $b = 1/a$ and let $u = a^2 > 0$:

$$I(u) = \underbrace{\frac{e^2-1}{2}}_{\alpha}\, u + \underbrace{\frac{1-e^{-2}}
{2}}_{\beta}\, \frac{1}{u}.$$

This is minimized when $u = \sqrt{\beta/\alpha}$, with minimum value $2\sqrt{\al
pha\beta}$.

**Computing the minimum:**

$$\alpha\beta = \frac{(e^2-1)(1-e^{-2})}{4} = \frac{(e^2-1)\cdot\frac{e^2-1}{e^2
}}{4} = \frac{(e^2-1)^2}{4e^2}.$$

$$2\sqrt{\alpha\beta} = 2\cdot\frac{e^2-1}{2e} = \frac{e^2-1}{e} = e - e^{-1}.$$

**Verification of the minimizer:** $u = \sqrt{\beta/\alpha} = \sqrt{\frac{(1-e^{
-2})}{(e^2-1)}} = \sqrt{\frac{1}{e^2}} = \frac{1}{e}$, so $a = e^{-1/2}$, $b = e
^{1/2}$, and $ab = 1$. ✓

Final Answer: $\boxed{e - e^{-1}}$
