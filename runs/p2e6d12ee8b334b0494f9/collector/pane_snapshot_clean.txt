## Proof

**Asymptotic expansion.** The Barnes G-function satisfies the well-known asympto
tic formula (as $z \to \infty$):

$$\log G(z+1) = \frac{z^2}{2}\log z - \frac{3z^2}{4} + \frac{z}{2}\log(2\pi) - \
frac{1}{12}\log z + \zeta'(-1) + O(1/z).$$

Setting $z = n + \alpha$ where $\alpha = a - 1$ (so that $G(n+a) = G(z+1)$), and
 expanding in powers of $n$, I obtain:

$$\log G(n+a) = \frac{n^2}{2}\log n - \frac{3n^2}{4} + \alpha\, n\log n + \left(
-\alpha + \tfrac{1}{2}\log 2\pi\right)n + \left(\tfrac{\alpha^2}{2} - \tfrac{1}{
12}\right)\log n + \tfrac{\alpha}{2}\log 2\pi + \zeta'(-1) + O(1/n).$$

**Setup.** Define the weights $w_i$ and shifts $a_i$:

| Factor | $a_i$ | $\alpha_i = a_i - 1$ | weight $w_i$ |
|---|---|---|---|
| $G(n+11/8)$ | $11/8$ | $3/8$ | $+1$ |
| $G(n+13/8)$ | $13/8$ | $5/8$ | $+2$ |
| $G(n+15/8)$ | $15/8$ | $7/8$ | $+1$ |
| $G(n+5/2)$ | $5/2$ | $3/2$ | $-2$ |
| $G(n+7/4)$ | $7/4$ | $3/4$ | $-2$ |

Taking logarithms, $\log L = \sum w_i \log G(n + a_i)$, and I examine each power
 of $n$.

**Cancellation of leading terms.**

- **$n^2 \log n$ coefficient:** $\frac{1}{2}\sum w_i = \frac{1}{2}(1+2+1-2-2) =
0$. ✓
- **$n^2$ coefficient:** $-\frac{3}{4}\sum w_i = 0$. ✓

(The total number of G-factors is equal: $4$ in numerator, $4$ in denominator.)

**The $n\log n$ term (decisive).** The coefficient is:

$$\sum w_i\,\alpha_i = \sum w_i\,(a_i - 1) = \sum w_i\, a_i - \sum w_i = \sum w_
i\, a_i.$$

Computing:
$$\sum w_i\, a_i = 1\cdot\frac{11}{8} + 2\cdot\frac{13}{8} + 1\cdot\frac{15}{8}
- 2\cdot\frac{5}{2} - 2\cdot\frac{7}{4} = \frac{11+26+15}{8} - 5 - \frac{7}{2} =
 \frac{52}{8} - \frac{17}{2} = \frac{13}{2} - \frac{17}{2} = -2.$$

Since $\sum w_i\, a_i = -2 \neq 0$, the $n\log n$ term in $\log L$ is $-2\,n\log
 n$.

**Subdominant terms.** For completeness:

- **$n$ coefficient:** $-\sum w_i\alpha_i + \frac{1}{2}\log(2\pi)\sum w_i = -(-2
) + 0 = 2$.
- **$\log n$ coefficient:** $\frac{1}{2}\sum w_i\alpha_i^2 - \frac{1}{12}\sum w_
i = \frac{1}{2}\sum w_i\alpha_i^2$.

Computing $\sum w_i \alpha_i^2 = \frac{9}{64} + \frac{50}{64} + \frac{49}{64} -
\frac{9}{2} - \frac{9}{8} = \frac{108}{64} - \frac{72}{16} - \frac{18}{16} = \fr
ac{27}{16} - \frac{90}{16} = -\frac{63}{16}$, giving $\log n$ coefficient $= -\f
rac{63}{32}$.

**Conclusion.** Assembling all terms:

$$\log L = -2\,n\log n + 2\,n - \frac{63}{32}\log n + C + o(1),$$

where $C$ is a finite constant (depending on $\zeta'(-1)$ and $\log 2\pi$). The
dominant term is $-2\,n\log n$, which tends to $-\infty$ as $n \to \infty$ (sinc
e $n\log n$ grows faster than the $+2n$ term). Therefore:

$$\log L \to -\infty \implies L = \lim_{n\to\infty} \frac{G(n+\frac{11}{8})\,G(n
+\frac{13}{8})^{2}\,G(n+\frac{15}{8})}{G(n+\frac{5}{2})^{2}\,G(n+\frac{7}{4})^{2
}} = \boxed{0}.$$
