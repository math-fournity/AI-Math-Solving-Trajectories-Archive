The integrand $\frac{1}{(x^2+4)^2}$ is positive, continuous, and decays as $O(1/
x^4)$ as $|x|\to\infty$, so the integral converges absolutely. Hence the Cauchy
principal value equals the ordinary improper integral.

## Proof via Contour Integration

Consider the complex function
$$f(z) = \frac{1}{(z^2+4)^2} = \frac{1}{(z-2i)^2(z+2i)^2}.$$

It has poles of order $2$ at $z = 2i$ and $z = -2i$.

**Contour.** Let $\Gamma_R$ be the closed contour consisting of the segment $[-R
, R]$ on the real axis together with the upper semicircle $C_R = \{Re^{i\theta}
: 0 \le \theta \le \pi\}$, for $R > 2$.

**Bounding the arc integral.** On $C_R$, with $|z|=R$:
$$|f(z)| = \frac{1}{|z^2+4|^2} \le \frac{1}{(|z|^2-4)^2} = \frac{1}{(R^2-4)^2}.$
$
Therefore
$$\left|\int_{C_R} f(z)\,dz\right| \le \frac{\pi R}{(R^2-4)^2} \xrightarrow{R\to
\infty} 0.$$

**Residue at $z = 2i$.** Only the pole at $z=2i$ lies inside $\Gamma_R$. Since i
t is a pole of order $2$:
$$\operatorname{Res}(f, 2i) = \lim_{z\to 2i}\frac{d}{dz}\left[(z-2i)^2 f(z)\righ
t] = \lim_{z\to 2i}\frac{d}{dz}\frac{1}{(z+2i)^2}.$$
Computing the derivative:
$$\frac{d}{dz}\frac{1}{(z+2i)^2} = \frac{-2}{(z+2i)^3},$$
so
$$\operatorname{Res}(f, 2i) = \frac{-2}{(4i)^3} = \frac{-2}{-64i} = \frac{1}{32i
}.$$

**Applying the residue theorem.**
$$\oint_{\Gamma_R} f(z)\,dz = 2\pi i \cdot \operatorname{Res}(f, 2i) = 2\pi i \c
dot \frac{1}{32i} = \frac{\pi}{16}.$$

**Taking $R\to\infty$.** The arc integral vanishes, leaving
$$\int_{-\infty}^{\infty}\frac{1}{(x^2+4)^2}\,dx = \frac{\pi}{16}.$$

Since the integral converges absolutely, this is also the Cauchy principal value
.

$$\boxed{\mathrm{P.V.}\int_{-\infty}^{\infty}\frac{1}{(x^2+4)^2}\,dx = \frac{\pi
}{16}}$$
