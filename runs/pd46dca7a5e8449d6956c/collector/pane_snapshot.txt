Looking at this problem, I need to find the smallest n such that drawing n chord
s parallel to each side of an equilateral triangle yields exactly 180 intersecti
on points.

## Setting Up Coordinates

Place the equilateral triangle with vertices A = (0, √3), B = (−1, 0), C = (1, 0
).

**Chord parametrization.** Each chord is parallel to one side with endpoints on
the other two sides. I parametrize each by its "level" in (0,1) — the fraction o
f the height from the side it's parallel to, toward the opposite vertex.

- **BC-parallel** at level α: horizontal segment at height α√3, from (α−1, α√3)
to (1−α, α√3).
- **CA-parallel** at level β: segment from (−1+β, β√3) on AB to (−1+2β, 0) on BC
.
- **AB-parallel** at level γ: by symmetry, segment on AC and BC.

## Intersection Condition

**Claim:** A BC-parallel chord at level α and a CA-parallel chord at level β int
ersect in the interior **if and only if α < β**.

*Proof:* The BC-parallel chord lies at height α√3. The CA-parallel chord spans h
eights from 0 to β√3. If α > β, the CA-parallel chord never reaches height α√3 —
 no intersection. If α = β, they meet at the point (α−1, α√3) on side AB — a sha
red endpoint, not an interior intersection. If α < β, direct coordinate computat
ion shows the intersection point (−1+2β−α, α√3) lies in the interior of both seg
ments (the x-coordinate satisfies α−1 < −1+2β−α < 1−α using α < β and β < 1).

By the 120° rotational symmetry of the equilateral triangle (mapping A→B→C→A and
 cycling the chord types):
- CA-parallel (β) and AB-parallel (γ) intersect iff **β < γ**
- AB-parallel (γ) and BC-parallel (α) intersect iff **γ < α**

## Counting Intersections

With n chords of each type at distinct levels α₁ < ... < αₙ, β₁ < ... < βₙ, γ₁ <
 ... < γₙ in (0,1), and choosing levels generically to avoid triple concurrency,
 the intersection count is:

$$N = \#\{(i,j): \alpha_i < \beta_j\} + \#\{(j,k): \beta_j < \gamma_k\} + \#\{(k
,i): \gamma_k < \alpha_i\}$$

This counts "forward" pairs in the cycle A→B→C→A among the 3n levels arranged on
 the line.

## Bounding N

**Maximum: N = 2n².** When all α-levels are below all β-levels, below all γ-leve
ls:
- #{α < β} = n², #{β < γ} = n², #{γ < α} = 0, giving N = 2n².

This is optimal: swapping any adjacent forward-labeled pair to backward decrease
s N by exactly 1 (only the swapped pair's contribution changes), and the cyclica
lly-sorted arrangement has no adjacent forward pair to improve.

**Minimum: N = n²** (at anti-cyclic arrangements).

**Every integer in [n², 2n²] is achievable:** Starting from N = 2n², each adjace
nt swap of a forward pair to backward decreases N by exactly 1. We can perform a
ny number of swaps from 0 to n², so every intermediate value is attainable.

## Finding the Smallest n

We need 180 ∈ [n², 2n²]:
- n² ≤ 180 ⟹ n ≤ 13
- 2n² ≥ 180 ⟹ n² ≥ 90 ⟹ n ≥ 10

**n = 9:** max N = 2·81 = 162 < 180. **Impossible.**

**n = 10:** N ∈ [100, 200], which includes 180. **Achievable.**

## Explicit Construction for n = 10

Choose levels in the order:
$$\alpha_1 < \cdots < \alpha_8 < \beta_1 < \cdots < \beta_{10} < \alpha_9 < \alp
ha_{10} < \gamma_1 < \cdots < \gamma_{10}$$

(with generic values in (0,1) to avoid triple concurrency). Then:
- #{αᵢ < βⱼ} = 8 × 10 = **80** (only α₁,...,α₈ are below all β's)
- #{βⱼ < γₖ} = 10 × 10 = **100** (all β's below all γ's)
- #{γₖ < αᵢ} = **0** (all γ's above all α's)

$$N = 80 + 100 + 0 = \mathbf{180} \checkmark$$

## Conclusion

The smallest n is $\boxed{10}$.
