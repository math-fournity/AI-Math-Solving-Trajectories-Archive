Looking at this problem, I need to solve Laplace's equation ∇²u = 0 in a semicir
cular cylinder (0 ≤ r ≤ a, 0 ≤ θ ≤ π, 0 ≤ z ≤ H) for three sets of boundary cond
itions, then determine existence conditions.

## Setup

In cylindrical coordinates:
$$\frac{\partial^2 u}{\partial r^2} + \frac{1}{r}\frac{\partial u}{\partial r} +
 \frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2} + \frac{\partial^2 u}{\part
ial z^2} = 0$$

Separation u = R(r)Θ(θ)Z(z) gives:
- Θ'' + n²Θ = 0
- Z'' = λZ
- r²R'' + rR' + (λr² − n²)R = 0 (Bessel-type)

---

## Part (a)

**BCs:** u=0 at z=0, θ=0, θ=π, r=a; u=α(r,θ) at z=H.

**Angular:** Θ(0)=Θ(π)=0 → Θ_n = sin(nθ), n = 1,2,3,…

**Axial:** Z(0)=0, and we need Z(H) to carry the nonhomogeneous data, so take λ
> 0: Z = sinh(√λ z).

**Radial:** R'' + (1/r)R' + (λ − n²/r²)R = 0, R(a)=0, R finite at 0 → R = J_n(√λ
 r). The condition J_n(√λ a) = 0 gives √λ = j_{n,k}/a where j_{n,k} is the k-th
positive zero of J_n.

**General solution:**
$$u(r,\theta,z) = \sum_{n=1}^{\infty}\sum_{k=1}^{\infty} A_{nk}\, J_n\!\left(\fr
ac{j_{n,k}\,r}{a}\right) \sin(n\theta)\, \sinh\!\left(\frac{j_{n,k}\,z}{a}\right
)$$

**Top BC** u(r,θ,H) = α(r,θ) determines the coefficients. Using orthogonality:
$$\int_0^a r\, J_n(j_{n,k}r/a)\, J_n(j_{n,l}r/a)\,dr = \frac{a^2}{2}\left[J_{n+1
}(j_{n,k})\right]^2 \delta_{kl}, \qquad \int_0^\pi \sin(n\theta)\sin(m\theta)\,d
\theta = \frac{\pi}{2}\delta_{nm}$$

$$\boxed{A_{nk} = \frac{4}{\pi\, a^2\, [J_{n+1}(j_{n,k})]^2\, \sinh(j_{n,k}H/a)}
 \int_0^a\!\int_0^\pi \alpha(r,\theta)\, J_n\!\left(\frac{j_{n,k}\,r}{a}\right)
\sin(n\theta)\; r\, d\theta\, dr}$$

## Part (b)

**BCs:** u=0 at z=0, θ=0, θ=π; ∂u/∂z=0 at z=H; u=β(θ,z) at r=a.

**Angular:** Θ(0)=Θ(π)=0 → Θ_n = sin(nθ), n = 1,2,3,…

**Axial:** Z(0)=0, Z'(H)=0. Take λ = −μ² < 0: Z = sin(μz), Z'(H) = μ cos(μH) = 0
 → μ_k = (2k+1)π/(2H), k = 0,1,2,…

**Radial:** R'' + (1/r)R' − (μ² + n²/r²)R = 0 (modified Bessel equation), R fini
te at 0 → R = I_n(μr).

**General solution:**
$$u(r,\theta,z) = \sum_{n=1}^{\infty}\sum_{k=0}^{\infty} B_{nk}\, I_n(\mu_k\, r)
\, \sin(n\theta)\, \sin(\mu_k\, z)$$

**Curved-surface BC** u(a,θ,z) = β(θ,z). Using ∫₀ᴴ sin²(μ_k z) dz = H/2 and ∫₀^π
 sin²(nθ) dθ = π/2:

$$\boxed{B_{nk} = \frac{4}{\pi\, H\, I_n(\mu_k\, a)} \int_0^\pi\!\!\int_0^H \bet
a(\theta,z)\, \sin(n\theta)\, \sin(\mu_k\, z)\; dz\, d\theta}$$

## Part (c)

**BCs:** u=0 at z=0; ∂u/∂z=0 at z=H; ∂u/∂θ=0 at θ=0,θ=π; ∂u/∂r=β(θ,z) at r=a.

**Angular:** Θ'(0)=Θ'(π)=0 → Θ_n = cos(nθ), n = 0,1,2,…

**Axial:** Same as (b): Z_k = sin(μ_k z), μ_k = (2k+1)π/(2H), k = 0,1,2,…

**Radial:** Same modified Bessel equation → R = I_n(μ_k r).

**General solution:**
$$u(r,\theta,z) = \sum_{n=0}^{\infty}\sum_{k=0}^{\infty} C_{nk}\, I_n(\mu_k\, r)
\, \cos(n\theta)\, \sin(\mu_k\, z)$$

**Curved-surface Neumann BC:** ∂u/∂r(a,θ,z) = β(θ,z) = Σ C_{nk} μ_k I_n'(μ_k a)
cos(nθ) sin(μ_k z).

Using ∫₀^π cos(nθ)cos(mθ) dθ = π δ_{nm} for n=m=0, and (π/2)δ_{nm} for n=m≥1; an
d ∫₀ᴴ sin²(μ_k z) dz = H/2:

**For n = 0:**
$$\boxed{C_{0k} = \frac{2}{\pi\, H\, \mu_k\, I_0'(\mu_k\, a)} \int_0^\pi\!\!\int
_0^H \beta(\theta,z)\, \sin(\mu_k\, z)\; dz\, d\theta}$$

**For n ≥ 1:**
$$\boxed{C_{nk} = \frac{4}{\pi\, H\, \mu_k\, I_n'(\mu_k\, a)} \int_0^\pi\!\!\int
_0^H \beta(\theta,z)\, \cos(n\theta)\, \sin(\mu_k\, z)\; dz\, d\theta}$$

where I_n'(x) = ½[I_{n−1}(x) + I_{n+1}(x)], and in particular I_0'(x) = I_1(x).
Since μ_k > 0 for all k (including k=0) and I_n'(x) > 0 for x > 0, all denominat
ors are nonzero — the series is well-defined for any sufficiently smooth β.

## Existence Conditions

A classical solution exists if and only if the boundary data is **compatible at
the edges** where different boundary surfaces meet. The boundary conditions on a
djacent faces must agree where those faces intersect.

**Part (a)** — The nonhomogeneous data α(r,θ) at z=H must vanish on the edges of
 the top face where it meets the zero-Dirichlet sides:
$$\alpha(a,\theta) = 0 \quad\text{(edge } r=a,\, z=H\text{)}, \qquad \alpha(r,0)
 = 0,\;\; \alpha(r,\pi) = 0 \quad\text{(edges } \theta=0,\pi,\, z=H\text{)}$$

**Part (b)** — The nonhomogeneous data β(θ,z) at r=a must be compatible with the
 conditions on z=0, z=H, θ=0, θ=π:
$$\beta(\theta,0) = 0 \quad\text{(edge } r=a,\,z=0\text{)}, \qquad \frac{\partia
l\beta}{\partial z}(\theta,H) = 0 \quad\text{(edge } r=a,\,z=H\text{)}$$
$$\beta(0,z) = 0,\quad \beta(\pi,z) = 0 \quad\text{(edges } r=a,\,\theta=0,\pi\t
ext{)}$$

**Part (c)** — The Neumann data β(θ,z) = ∂u/∂r at r=a must be compatible with th
e conditions on the adjacent faces. Differentiating the other boundary condition
s with respect to r and evaluating at r=a:
- From u(r,θ,0)=0 (all r): ∂u/∂r(a,θ,0) = 0 → **β(θ,0) = 0**
- From ∂u/∂z(r,θ,H)=0 (all r): ∂²u/∂r∂z(a,θ,H) = 0 → **∂β/∂z(θ,H) = 0**
- From ∂u/∂θ(r,0,z)=0 (all r): ∂²u/∂r∂θ(a,0,z) = 0 → **∂β/∂θ(0,z) = 0**
- From ∂u/∂θ(r,π,z)=0 (all r): ∂²u/∂r∂θ(a,π,z) = 0 → **∂β/∂θ(π,z) = 0**

These edge-compatibility conditions are necessary for a classical (continuously
differentiable) solution. When they hold and the boundary data is sufficiently s
mooth, the series solutions above converge to the unique solution. When they fai
l, the solution exists only in a weak sense and exhibits singularities (corner/e
dge singularities) near the non-compatible edges.
