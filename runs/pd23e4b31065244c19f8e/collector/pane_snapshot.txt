## Proof of `bounded_gap_legendre`

**Theorem.** Suppose there exists a constant $c > 0$ such that for all sufficien
tly large $n$,
$$p_{n+1} - p_n < p_n^{1/2 - c},$$
where $p_n$ denotes the $n$-th prime. Then for all sufficiently large $k$, there
 exists a prime $p$ with $k^2 < p < (k+1)^2$.

**Proof.**

**Step 0 (Preliminary observation on $c$).** The hypothesis requires $0 < c < \t
frac{1}{2}$. Indeed, if $c \geq \tfrac{1}{2}$, then $p_n^{1/2 - c} \to 0$ (or eq
uals 1) as $n \to \infty$, while $p_{n+1} - p_n \geq 1$ for all $n$, so the ineq
uality $p_{n+1} - p_n < p_n^{1/2-c}$ fails for large $n$, making the hypothesis
vacuously false. Thus any $c$ satisfying the hypothesis lies in $(0, \tfrac{1}{2
})$, giving $1 - 2c \in (0, 1)$.

**Step 1 (Setup).** By the hypothesis, there exists $N_0$ such that for all $n \
geq N_0$:
$$p_{n+1} - p_n < p_n^{1/2 - c}. \tag{H}$$

For each integer $k \geq 2$, define
$$m(k) := \max\{\, j \geq 1 : p_j \leq k^2 \,\}.$$
This is well-defined since $p_1 = 2 \leq k^2$ for $k \geq 2$, and the set is fin
ite since there are infinitely many primes (Euclid), so some prime exceeds $k^2$
. By definition:
$$p_{m(k)} \leq k^2 < p_{m(k)+1}. \tag{1}$$

**Step 2 ($m(k) \to \infty$).** As $k \to \infty$, we have $k^2 \to \infty$, so
$p_{m(k)} \to \infty$ (since $p_{m(k)} \leq k^2$ and $p_{m(k)+1} > k^2$). Becaus
e $p_j \to \infty$ as $j \to \infty$, this forces $m(k) \to \infty$. In particul
ar, there exists $K_1$ such that for all $k \geq K_1$:
$$m(k) \geq N_0. \tag{2}$$

**Step 3 (Apply the gap bound).** For $k \geq K_1$, condition (2) allows us to a
pply (H) with $n = m(k)$:
$$p_{m(k)+1} - p_{m(k)} < p_{m(k)}^{1/2 - c}. \tag{3}$$

Since $1/2 - c > 0$ (Step 0), the function $x \mapsto x^{1/2-c}$ is increasing o
n $(0, \infty)$. Using $p_{m(k)} \leq k^2$ from (1):
$$p_{m(k)}^{1/2 - c} \leq (k^2)^{1/2 - c} = k^{1 - 2c}. \tag{4}$$

Combining (3) and (4):
$$p_{m(k)+1} < p_{m(k)} + k^{1 - 2c} \leq k^2 + k^{1-2c}. \tag{5}$$

**Step 4 (Comparison with $(k+1)^2$).** Since $1 - 2c \in (0, 1)$, we have $k^{1
-2c} = o(k)$ as $k \to \infty$, i.e.,
$$\frac{k^{1-2c}}{k} = k^{-2c} \to 0.$$

Therefore there exists $K_2$ such that for all $k \geq K_2$:
$$k^{1-2c} < 2k + 1. \tag{6}$$

**Step 5 (Conclusion).** Set $K = \max(K_1, K_2, 2)$. For all $k \geq K$, combin
ing (1), (5), and (6):

- **Lower bound:** $p_{m(k)+1} > k^2$ (from (1)).
- **Upper bound:** $p_{m(k)+1} < k^2 + k^{1-2c} < k^2 + 2k + 1 = (k+1)^2$ (from
(5) and (6)).

Thus $p_{m(k)+1}$ is a prime satisfying
$$k^2 < p_{m(k)+1} < (k+1)^2,$$
i.e., $p_{m(k)+1} \in \mathrm{Ioo}(k^2, (k+1)^2)$.

This holds for all $k \geq K$, which in Lean's `Filter.atTop` language is precis

t.Prime}\ p. \qquad \blacksquare$$
